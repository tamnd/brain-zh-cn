[欧拉项目问题 543](https://projecteuler.net/problem=543)

 ## 解决方案

 **答案：**`199007746081234640`让$$P(n,k)= \begin{cases} 1 & \text{if } n \text{ can be written as a sum of } k \text{ primes}\\ 0 & \text{otherwise} \end{cases}$$和$$S(n)=\sum_{1\le i,k\le n} P(i,k).$$我们想要$$\sum_{k=3}^{44} S(F(k)).$$在哪里$F(k)$是斐波那契数列。 

## 1.数学分析

 我们首先表征什么时候$P(n,k)=1$。 

＃＃＃ 案件$k=1$这是立即的：$$P(n,1)=1 \iff n \text{ is prime}.$$贡献高达$n$：$$\sum_{i\le n} P(i,1)=\pi(n),$$在哪里$\pi(n)$是素数计数函数。 

- -

＃＃＃ 案件$k=2$我们问是否$n$是两个素数之和。 

- 如果$n$是 **偶数** 并且$n\ge 4$，对于我们需要的范围，（经过验证的）哥德巴赫性质确实如此。 
- 如果$n$是 **奇数**，必须有一个素数$2$， 所以：$$n=2+p$$对于一些素数$p$。 因此：$$P(n,2)=1 \iff \begin{cases} n\ge 4,\ n \text{ even},\\[4pt] \text{or } n-2 \text{ is prime}. \end{cases}$$因此，总贡献为$k=2$是：$$\left(\left\lfloor \frac n2 \right\rfloor-1\right) + (\pi(n-2)-1).$$说明：

 - 偶数值$4,6,8,\dots$贡献$\lfloor n/2\rfloor-1$,
 - 奇数由素数产生$p\le n-2$，不包括$p=2$。 

- -

＃＃＃ 案件$k\ge 3$的最小可能总和$k$素数是：$$2k.$$一个关键观察：

 > 对于每一个$n\ge 2k$，表示总是存在的。 

原因：

 - 写$n$一样多$2$的加上：

 - 一个奇素数（用于奇偶校验调整），或
 - 三个素数（通过弱哥德巴赫）。 

实际上这意味着：$$P(n,k)=1 \iff n\ge 2k \qquad (k\ge 3).$$所以对于固定的$i$，有效的$k\ge3$是：$$3\le k\le \left\lfloor \frac i2\right\rfloor.$$因此这样的数量$k$是$$\max\!\left(0,\left\lfloor\frac i2\right\rfloor-2\right).$$总结$i\le n$给出一个封闭的形式。 

让$m=\lfloor n/2\rfloor$。 

如果$n=2m$是偶数：$$C(n)=\sum_{i=1}^{n} \max\!\left(0,\left\lfloor\frac i2\right\rfloor-2\right) =(m-2)^2.$$如果$n=2m+1$是奇数：$$C(n)=(m-1)(m-2).$$---

 ### 最终公式为$S(n)$让$m=\lfloor n/2\rfloor$。$$S(n) = \pi(n) + \left(\left\lfloor \frac n2 \right\rfloor-1\right) + (\pi(n-2)-1) + C(n).$$在哪里$$C(n)= \begin{cases} (m-2)^2,& n \text{ even}\\[4pt] (m-1)(m-2),& n \text{ odd}. \end{cases}$$检查示例：

 -$S(10)=20$-$S(100)=2402$-$S(1000)=248838$——全部与问题陈述相符。 

## 2.Python实现```python
from functools import lru_cache
import math

# ---------- Prime counting: Lehmer pi(x) ----------

def sieve(limit):
    is_prime = bytearray(b'\x01') * (limit + 1)
    is_prime[0:2] = b'\x00\x00'

    for p in range(2, int(math.isqrt(limit)) + 1):
        if is_prime[p]:
            start = p * p
            is_prime[start:limit + 1:p] = (
                b'\x00' * (((limit - start) // p) + 1)
            )

    primes = [i for i in range(limit + 1) if is_prime[i]]

    pi = [0] * (limit + 1)
    count = 0
    for i in range(limit + 1):
        if is_prime[i]:
            count += 1
        pi[i] = count

    return primes, pi

# Enough for Lehmer recursion
PRIMES, PI_SMALL = sieve(5_000_000)

@lru_cache(None)
def phi(x, s):
    """Count integers <= x not divisible by first s primes."""
    if s == 0:
        return x
    return phi(x, s - 1) - phi(x // PRIMES[s - 1], s - 1)

@lru_cache(None)
def lehmer_pi(x):
    """Prime counting function pi(x)."""
    if x < len(PI_SMALL):
        return PI_SMALL[x]

    a = lehmer_pi(int(x ** 0.25))
    b = lehmer_pi(int(math.isqrt(x)))
    c = lehmer_pi(int(round(x ** (1 / 3))))

    result = phi(x, a)
    result += ((b + a - 2) * (b - a + 1)) // 2

    for i in range(a + 1, b + 1):
        w = x // PRIMES[i - 1]
        result -= lehmer_pi(w)

        if i <= c:
            lim = lehmer_pi(int(math.isqrt(w)))
            for j in range(i, lim + 1):
                result -= lehmer_pi(w // PRIMES[j - 1]) - (j - 1)

    return result

def S(n):
    m = n // 2

    # k = 1 contribution
    total = lehmer_pi(n)

    # k = 2 contribution
    if n >= 4:
        total += m - 1
    if n >= 5:
        total += lehmer_pi(n - 2) - 1

    # k >= 3 contribution
    if m >= 2:
        if n % 2 == 0:
            total += (m - 2) ** 2
        else:
            total += (m - 1) * (m - 2)

    return total

# Fibonacci numbers
fib = [0, 1]
while len(fib) <= 44:
    fib.append(fib[-1] + fib[-2])

answer = sum(S(fib[k]) for k in range(3, 45))

print(answer)
```## 3. 代码演练

 1. **Sieve**：构建素数和前缀数组$\pi(x)$对于小$x$。 
2. **莱默素数计数**：高效计算$\pi(x)$对于大值（最多$F(44)=701{,}408{,}733$）。 
3. **`S(n)`**：

 - 增加主要贡献（$k=1$),
 - 增加二素数贡献（$k=2$),
 - 添加所有$k\ge3$使用封闭形式。 
4. 计算斐波那契数$F(44)$。 
5. 总和$S(F(k))$为了$3\le k\le44$。 

健全性检查：

 -`S(10) = 20`-`S(100) = 2402`-`S(1000) = 248838`与陈述完全相符。 

## 4.最终验证

 涉及的最大斐波那契数仅约为$7\times10^8$，因此 Lehmer 素数计数很容易足够快。 结果是肯定的并且大约为$F(44)^2$，这是合理的，因为主导项$S(n)$是二次方（$\sim n^2/4$）。
