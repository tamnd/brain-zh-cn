[欧拉项目问题 7](https://projecteuler.net/problem=7)

 ## 解决方案

 为了找到$10{,}001^\text{st}$prime，我们依次生成素数并对它们进行计数，直到达到目标索引。 

标准方法是：

 - 开始于$2$- 使用试除法测试每个候选者的素性$\sqrt{n}$- 计算找到的素数
 - 当计数达到时停止$10{,}001$这是干净的 Python 代码：```python
def is_prime(n):
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2

    return True

count = 0
num = 1

while count < 10001:
    num += 1
    if is_prime(num):
        count += 1

print(num)
```追踪逻辑：

 - 素数开始：$2,3,5,7,11,13,\dots$- 仅当找到素数时计数器才会增加。 
- 继续这个过程直到$10{,}001^\text{st}$素数给出：

 **答案：104743**
