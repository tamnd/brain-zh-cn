[欧拉项目问题 155](https://projecteuler.net/problem=155)

 ## 解决方案

 **答案：**`3857447`让每个电容都有电容$C$。 

由于每个产生的电容都是有理数倍$C$，我们通过设置标准化$C=1$。 

因此，每个可实现的电容都是精确的有理数。 

我们定义：$$S_n = \{\text{all capacitances achievable using exactly } n \text{ capacitors}\}$$和$$D(n)=\left|\bigcup_{k=1}^n S_k\right|$$问题要求$D(18)$。 

---

 # 数学分析

 如果两个子电路有电容$x$和$y$，那么：

 ## 并联

 电容直接相加：$$C_{\text{parallel}} = x+y$$## 串联$$\frac1{C_{\text{series}}}=\frac1x+\frac1y$$所以$$C_{\text{series}}=\frac{xy}{x+y}$$因此每个电路都是由$n$电容器可以通过将电容器分成两个非空的尺寸组来形成$k$和$n-k$，从每组中构建一个子电路，并将它们串联或并联组合。 

所以：$$S_n = \bigcup_{k=1}^{n-1} \left\{ x+y,\ \frac{xy}{x+y} \;\middle|\; x\in S_k,\ y\in S_{n-k} \right\}$$基本情况：$$S_1=\{1\}$$因为所有值都是有理数，所以我们使用约简分数来精确地表示它们。 

---

 # 动态规划策略

 我们计算$S_1,S_2,\dots,S_{18}$。 

对于每个$n$:

 - 迭代所有分割$k$和$n-k$,
 - 将每一对组合起来$x\in S_k$,$y\in S_{n-k}$，
- 插入：

-$x+y$-$\dfrac{xy}{x+y}$到一个集合中（自动删除重复项）。 

一个有用的优化：

 因为结合$S_k$和$S_{n-k}$是对称的，我们只需要：$$k \le \frac n2$$这将工作量大约减少了一半。 

---

 # Python 实现```python
from math import gcd

N = 18

# S[n] = set of capacitances using exactly n capacitors
# Each capacitance stored as a reduced fraction (num, den)
S = [set() for _ in range(N + 1)]

# Base case: one capacitor => capacitance 1
S[1] = {(1, 1)}

# Global set of all distinct capacitances
all_values = {(1, 1)}

for n in range(2, N + 1):

    current = set()

    # Only need k <= n//2 because of symmetry
    for k in range(1, n // 2 + 1):

        other = n - k

        for a, b in S[k]:
            for c, d in S[other]:

                # -------------------------
                # Parallel:
                # a/b + c/d
                # -------------------------
                num = a * d + b * c
                den = b * d

                g = gcd(num, den)
                current.add((num // g, den // g))

                # -------------------------
                # Series:
                # (a/b * c/d) / (a/b + c/d)
                # = ac / (ad + bc)
                # -------------------------
                num = a * c
                den = a * d + b * c

                g = gcd(num, den)
                current.add((num // g, den // g))

    S[n] = current
    all_values |= current

print(len(all_values))
```---

 ## 分成两个子电路```python

```一个电路与$n$电容器由以下组合形成：

 - 一个子电路$k$电容器，
 - 另一个与$n-k$电容器。 

由于操作是对称的，因此只需要一半的拆分。 

---

 ## 并行组合```python
num = a * d + b * c
den = b * d
```这计算：$$\frac ab + \frac cd = \frac{ad+bc}{bd}$$然后我们减少使用`gcd`。 

---

 ##系列组合```python
num = a * c
den = a * d + b * c
```这计算：$$\frac{\frac ab \cdot \frac cd} {\frac ab + \frac cd} = \frac{ac}{ad+bc}$$再次降低到最低条件。

 # 小案例验证

 ##$n=1$仅有的：$$1$$所以：$$D(1)=1$$正确的。 

---

 ##$n=2$可能的值：

 - 并行：$1+1=2$- 系列：$\frac{1\cdot1}{1+1}=\frac12$最多 2 个电容器的不同值：$$\left\{1,2,\frac12\right\}$$因此：$$D(2)=3$$正确的。
