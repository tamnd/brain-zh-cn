[欧拉计划问题 129](https://projecteuler.net/problem=129)

 ## 解决方案

 **答案：**`1000023`让$$R(k)=\underbrace{111\ldots 1}_{k\text{ digits}}$$是长度的重新单位$k$。 自从$$R(k)=1+10+10^2+\cdots+10^{k-1}$$我们有封闭的形式$$R(k)=\frac{10^k-1}{9}.$$我们定义$A(n)$成为最小的$k$这样$R(k)\equiv 0\pmod n$，假设$\gcd(n,10)=1$。 

问题要求最少$n$这样$$A(n)>1{,}000{,}000.$$---

 # 1.数学分析

 我们想要最少的$n$其最小重装倍数长度超过一百万。 

---

 ## 步骤 1：重新表述整除条件

 我们需要$$R(k)\equiv 0 \pmod n.$$使用$$R(k)=\frac{10^k-1}{9},$$我们得到$$\frac{10^k-1}{9}\equiv 0 \pmod n.$$如果$\gcd(n,9)=1$，这相当于$$10^k\equiv 1 \pmod n.$$更一般地说，$A(n)$是乘法阶$10$模数$9n$（或取模$n$什么时候$9\nmid n$）。 

然而，对于计算，我们不需要先进的数论。 我们可以计算$A(n)$直接使用模块化递归。 

---

 ## 步骤 2：计算$A(n)$有效地

 与其构建巨大的重复，不如定义重复$$r_k = R(k)\bmod n.$$然后$$R(k+1)=10R(k)+1,$$所以$$r_{k+1}=(10r_k+1)\bmod n.$$我们从以下开始：$$r_1=1\bmod n.$$第一个$k$这样$r_k=0$正是$A(n)$。 

这仅需要模运算并运行在$O(A(n))$时间。 

---

 ## 步骤 3：重要观察结果

 自从$A(n)\le n$对于素数$n$不除 10（因为阶数除以$\varphi(n)=n-1$），我们立即知道：

 - 如果$A(n)>10^6$，那么必然$n>10^6$。 

所以我们开始搜索略高于一百万的内容。 

另外：

 - 可以整除的数字$2$或者$5$永远无法分割重聚，
 - 所以我们跳过这样的$n$。 

---

 ## 第四步：策略

 我们测试整数$n>10^6$和$\gcd(n,10)=1$：

 1. 计算$A(n)$通过迭代模块化递归。 
2.停在第一个$n$和$A(n)>10^6$。 

第一个这样的$n$就是答案。 

---

 # 2.Python实现```python
from math import gcd

LIMIT = 1_000_000

def A(n):
    """
    Compute the least k such that R(k) is divisible by n,
    where R(k) = 111...1 (k ones).
    Assumes gcd(n, 10) = 1.
    """
    remainder = 1 % n
    k = 1

    while remainder != 0:
        remainder = (remainder * 10 + 1) % n
        k += 1

    return k

n = LIMIT + 1

while True:

    # Repunits can only be divisible by numbers coprime to 10
    if gcd(n, 10) == 1:

        if A(n) > LIMIT:
            print(n)
            break

    n += 1
```---

 # 4. 小例子验证

 问题指出：$$A(7)=6.$$的确：$$111111 = 7 \times 15873.$$运行递归：

 -$1 \bmod 7 = 1$-$11 \bmod 7 = 4$-$111 \bmod 7 = 6$-$1111 \bmod 7 = 5$-$11111 \bmod 7 = 2$-$111111 \bmod 7 = 0$所以$A(7)=6$。 

还：$$A(17)=16>10,$$与 17 是第一个的语句相匹配$n$和$A(n)>10$。

 # 5.最终验证

 答案应该是：

 - 略大于$10^6$,
 - 与 10 互质，
 - 乘法阶数非常大，为 10。 

计算得出：$$n = 1{,}000{,}023.$$这确实是一百万出头，满足$$A(1{,}000{,}023) > 1{,}000{,}000.$$**答案：1000023**
