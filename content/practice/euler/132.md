[欧拉计划问题 132](https://projecteuler.net/problem=132)

 ## 解决方案

 **答案：**`843296`让$$R(k)=\underbrace{111\ldots1}_{k\text{ digits}}=\frac{10^k-1}{9}.$$我们被要求提供第一个的总和$40$的质因数$$R(10^9).$$关键点是表征素数何时$p$分割重聚。 

---

 # 1.数学分析

 素数$p \neq 2,5$划分$R(n)$当且仅当$$R(n)\equiv 0 \pmod p.$$使用$$R(n)=\frac{10^n-1}{9},$$自从$p\neq 3$意味着$9$是可逆模数$p$,$$R(n)\equiv 0 \pmod p \iff 10^n\equiv 1 \pmod p.$$因此：$$p\mid R(n) \iff \operatorname{ord}_p(10)\mid n,$$在哪里$\operatorname{ord}_p(10)$是乘法阶$10$模数$p$。 

对于这个问题，$$n=10^9=2^9\cdot 5^9.$$因此一个素数$p$划分$R(10^9)$当且仅当的顺序$10$模数$p$不包含除质因数以外的质因数$2$和$5$。 

等效地：$$\operatorname{ord}_p(10)\mid 10^9.$$另一个有用的事实：$$\operatorname{ord}_p(10)\mid p-1$$（费马/拉格朗日），因此任何这样的素数都满足$$p\equiv 1 \pmod{2^a5^b}$$的适当除数$10^9$。 

但在计算上最简单的测试是直接：$$10^{10^9}\equiv 1 \pmod p.$$因为 Python 通过重复平方来有效地计算模幂，所以速度非常快。 

所以算法是：

 1. 生成素数$p\neq 2,5$。 
2、测试是否$$10^{10^9}\equiv 1 \pmod p.$$3.收集第一个$40$这样的素数。 
4. 对它们求和。 

---

 # 2.Python实现```python
from sympy import primerange

TARGET = 40
N = 10**9

factors = []

# Generate primes in increasing order
for p in primerange(2, 10**7):

    # Repunits are never divisible by 2 or 5
    if p in (2, 5):
        continue

    # p divides R(N) iff 10^N ≡ 1 (mod p)
    if pow(10, N, p) == 1:
        factors.append(p)

        if len(factors) == TARGET:
            break

answer = sum(factors)

print(factors)
print(answer)
```---

 # 4. 小例子验证
