[欧拉项目 684 问题](https://projecteuler.net/problem=684)

 ## 解决方案

 **答案：**`922058210`让$s(n)$是数字和为的最小正整数$n$。 

例如：

-$s(1)=1$-$s(10)=19$-$s(20)=299$我们定义$$S(k)=\sum_{n=1}^k s(n).$$我们必须计算$$\sum_{i=2}^{90} S(f_i) \pmod{1\,000\,000\,007},$$在哪里$f_i$是斐波那契数列。 

---

 # 1.数学分析

 ## 步骤 1：公式$s(n)$求数字和中最小的数$n$，我们想要：

 - 尽可能少的数字，
 - 较大的数字被推到右侧。 

写$$n = 9q + r,\qquad 0 \le r \le 8.$$那么最优的数量是：

 - 一位前导数字$r$（如果$r>0$），
- 其次是$q$数字等于$9$。 

示例：

 -$10 = 9\cdot1+1 \Rightarrow s(10)=19$-$20 = 9\cdot2+2 \Rightarrow s(20)=299$因此$$s(n)=r\cdot 10^q + (10^q-1).$$所以：$$\boxed{s(n)=(r+1)10^q-1}$$和$n=9q+r$。 

---

 # 第 2 步：推导公式$S(k)$让$$k=9q+r,\qquad 0\le r\le 8.$$我们对 9 项的完整块求和。 

对于固定的$a\ge0$,$$s(9a+t)=(t+1)10^a-1,\qquad 1\le t\le8,$$和$$s(9a+9)=10^{a+1}-1.$$所以：$$\sum_{t=1}^{9} s(9a+t) = \sum_{t=1}^{8}\big((t+1)10^a-1\big) + (10^{a+1}-1).$$计算：$$\sum_{t=1}^{8}(t+1)=44,$$所以$$=44\cdot10^a-8+10^{a+1}-1 =54\cdot10^a-9.$$因此每个完整的块都贡献$$54\cdot10^a-9.$$求和$a=0,\dots,q-1$:$$\sum_{a=0}^{q-1}(54\cdot10^a-9) = 54\frac{10^q-1}{9}-9q.$$因此，整个区块的贡献是$$6(10^q-1)-9q.$$现在添加剩余的$r$条款：$$\sum_{t=1}^{r}\big((t+1)10^q-1\big).$$自从$$\sum_{t=1}^{r}(t+1)=\frac{r(r+3)}2,$$这变成$$\frac{r(r+3)}2\,10^q-r.$$结合：$$S(k) = 6(10^q-1)-9q + \frac{r(r+3)}2\,10^q-r.$$所以$$\boxed{ S(k)=\left(\frac{r(r+3)}2+6\right)10^q-9q-r-6 }$$在哪里$k=9q+r$。

 # 2.Python实现```python
MOD = 1_000_000_007

def S(k):
    """
    Compute S(k) modulo MOD using the closed formula.
    """
    q, r = divmod(k, 9)

    # Closed form:
    # S(k) = ((r(r+3))/2 + 6) * 10^q - 9q - r - 6
    value = (
        ((r * (r + 3)) // 2 + 6) * pow(10, q, MOD)
        - 9 * q
        - r
        - 6
    )

    return value % MOD

# Fibonacci iteration
f0, f1 = 0, 1

answer = 0

for _ in range(2, 91):
    f0, f1 = f1, f0 + f1
    answer = (answer + S(f1)) % MOD

print(answer)
```---
