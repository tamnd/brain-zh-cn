[欧拉项目问题 115](https://projecteuler.net/problem=115)

 ## 解决方案

 **答案：**`168`让$F(m,n)$表示填充一行长度的方法数$n$使用：

 - 长度为黑色的方块$1$,
 - 长度至少为红色的块$m$,
 - 限制是任何两个红色方块至少被一个黑色方块分开。 

我们追求最少$n$这样$$F(50,n) > 10^6.$$---

 # 数学分析

 我们推导出一个递归式$F(m,n)$。 

定义：$$F(n) := F(m,n)$$对于固定的$m$。 

---

 ## 步骤1：按第一个方块对馅料进行分类

 考虑一行的长度$n$。 

### 情况 1 — 第一个方块是黑色

 然后剩下的$n-1$方块可以用任何有效的方式填充：$$F(n-1)$$的可能性。 

---

 ### 情况 2 — 第一个块是红色

 假设第一个红色块的长度$k$， 在哪里$$k \ge m.$$出现两种子情况。 

---

 ### 子情况 2a — 红色块到达末尾

 发生这种情况时$k=n$。 

对于每一种这样的情况都有一种安排$k$。 

---

 ### 子情况 2b — 有剩余空间

 如果红色块没有结束该行，那么它后面必须至少有一个黑色方块。 

所以放置后：

 - 一个红色的长度块$k$,
 - 一个强制性的黑色方块，

 我们有$$n-k-1$$剩余的方块。 

这些都可以填写$F(n-k-1)$方式。 

因此对于每个$k$,$$F(n-k-1)$$贡献。 

---

 ## 第 2 步：完全复发

 包括全黑排列，我们得到：$$F(n) = F(n-1) + \sum_{k=m}^{n} 1 + \sum_{k=m}^{n-1} F(n-k-1).$$将“红块到达终点”情况均匀处理，得到更清洁的配方。 

放：$$F(t)=1 \quad \text{for } t<0.$$然后：$$F(n) = F(n-1) + \sum_{k=m}^{n} F(n-k-1).$$等价地，$$\boxed{ F(n)=F(n-1)+\sum_{j=0}^{n-m} F(j-1) }$$有基值$$F(0)=1.$$---

 ## 步骤 3：动态规划方法

 因为我们只需要第一个$n$在哪里$F(50,n)>10^6$，动态规划是理想的。 

我们逐步计算值：

 - 开始于$F(0)=1$,
 - 向上增加，直到价值超过一百万。 

增长足够快，只是适度$n$需要。 

---

 # Python 实现```python
def fill_count(m, limit):
    """
    Return the smallest n such that F(m, n) > limit.
    """

    # dp[n] = F(m, n)
    dp = [1]  # F(0) = 1

    n = 0

    while True:
        n += 1

        # Case 1: first square is black
        total = dp[n - 1]

        # Case 2: first block is red
        for k in range(m, n + 1):

            remaining = n - k - 1

            if remaining >= 0:
                total += dp[remaining]
            else:
                # red block reaches the end
                total += 1

        dp.append(total)

        if total > limit:
            return n

answer = fill_count(50, 1_000_000)
print(answer)
```---

 # 代码演练

 ## 初始化```python
dp = [1]
```这家店：$$F(0)=1$$（全黑空排列）。 

---

 ## 主循环```python
while True:
    n += 1
```我们计算$F(n)$依次。 

---

 ## 黑优先情况```python
total = dp[n - 1]
```如果第一个方块是黑色，则剩余行有长度$n-1$。 

---

 ## 红色优先案例```python
for k in range(m, n + 1):
```尝试每个允许的红色块长度。 

---

 ### 剩余空间```python
remaining = n - k - 1
```在红色块之后，需要一个黑色方块，除非该块结束了该行。 

---

 ### 如果还有空间```python
total += dp[remaining]
```其余的可以随意填写。 

---

 ### 如果块到达末尾```python
total += 1
```确实存在一种安排。 

---

 ## 存储结果```python
dp.append(total)
```现在$dp[n]=F(n)$。 

---

 ## 停止条件```python
if total > limit:
    return n
```我们返回第一个$n$其中计数超过一百万。 

---

 # 实例验证

 对于$m=3$：

 -$F(3,29)=673135$-$F(3,30)=1089155$所以至少$n$超过一百万的是：$$n=30.$$为了$m=10$：

 -$F(10,56)=880711$-$F(10,57)=1148904$所以至少$n$是：$$n=57.$$递归精确地再现了这两个值。 

运行相同的算法$m=50$给出：$$F(50,168)=1053389 > 10^6,$$尽管$$F(50,167)=978181 < 10^6.$$因此最不有效的$n$是$168$。 

---

 **答案：168**
