[欧拉项目 658 问题](https://projecteuler.net/problem=658)

 ## 解决方案

 **答案：**`958280177`让$$I(\alpha,n)=\#\{\text{incomplete words over an alphabet of size }\alpha\text{ with length }\le n\}.$$我们想要$$S(k,n)=\sum_{\alpha=1}^k I(\alpha,n)$$为了$k=10^7,\ n=10^{12}$, 取模$M=10^9+7$。 

---

 ## 1. 统计不完整的单词

 修复字母表的大小$\alpha$。 

对于固定长度$m$，总单词数为$\alpha^m$。 

一个单词是完整的，当且仅当每个字母至少出现一次。 通过包含-排除，$$\#\{\text{complete words of length }m\} = \sum_{j=0}^{\alpha}(-1)^j\binom{\alpha}{j}(\alpha-j)^m.$$因此，长度不完整的单词数$m$是$$\alpha^m- \sum_{j=0}^{\alpha}(-1)^j\binom{\alpha}{j}(\alpha-j)^m.$$简化后，$$\#\{\text{incomplete words of length }m\} = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}j^m.$$因此$$I(\alpha,n) = \sum_{m=0}^{n} \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}j^m.$$交换总和：$$I(\alpha,n) = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j} \sum_{m=0}^{n}j^m.$$定义$$G_n(j)=\sum_{m=0}^{n}j^m.$$然后$$I(\alpha,n) = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}G_n(j).$$---

 ## 2. 对所有字母大小求和

 现在总结一下$\alpha\le k$：$$S(k,n) = \sum_{\alpha=1}^{k} \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}G_n(j).$$再次交换顺序：$$S(k,n) = \sum_{j=0}^{k-1} G_n(j) \sum_{\alpha=j+1}^{k} (-1)^{\alpha-j+1}\binom{\alpha}{j}.$$定义$$c_{k,j} = \sum_{\alpha=j+1}^{k} (-1)^{\alpha-j+1}\binom{\alpha}{j}.$$使用生成函数，可以得到$$\sum_{j\ge0} c_{k,j}x^j = \frac{1+(-1)^{k+1}(1-x)^{k+2}} {(1-x)(2-x)}.$$这产生系数的线性递推$c_{k,j}$，允许生成所有系数$O(k)$。 

还，$$G_n(j)= \begin{cases} n+1,& j=1,\\[4pt] \dfrac{j^{n+1}-1}{j-1},& j\ne1. \end{cases}$$自从$n=10^{12}$，每个幂均通过快速模幂计算。 

完整的算法运行在$O(k\log n)$, 可行的$k=10^7$。 

---

 ## 3.Python实现```python
MOD = 10**9 + 7

def solve(k, n):
    inv = [1] * (k + 3)
    inv[1] = 1
    for i in range(2, k + 3):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # coefficients c_j generated from
    # (2 - x)C(x) = 1 + (-1)^(k+1)(1-x)^(k+2)

    c = [0] * (k + 1)

    sign = -1 if (k + 1) & 1 else 1

    # constant term
    rhs0 = 1 + sign
    c[0] = rhs0 * inv[2] % MOD

    # recurrence:
    # 2*c_j - c_{j-1} = sign * (-1)^j * C(k+2, j)

    comb = 1

    for j in range(1, k):
        comb = comb * (k + 3 - j) % MOD
        comb = comb * inv[j] % MOD

        rhs = comb
        if (j & 1):
            rhs = MOD - rhs

        if sign == -1:
            rhs = MOD - rhs

        c[j] = (c[j - 1] + rhs) * inv[2] % MOD

    ans = 0

    for j in range(k):
        coeff = c[j]

        if j == 0:
            g = 1
        elif j == 1:
            g = (n + 1) % MOD
        else:
            g = (pow(j, n + 1, MOD) - 1) % MOD
            g = g * inv[j - 1] % MOD

        ans = (ans + coeff * g) % MOD

    return ans

print(solve(10**7, 10**12))
```---
