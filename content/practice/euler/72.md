[项目欧拉问题 72](https://projecteuler.net/problem=72)

 ## 解决方案

 **答案：**`303963552391`## 1.数学分析

 我们想要**约简真分数**的数量$$\frac{n}{d}$$这样：

 -$n < d$,
 -$\gcd(n,d)=1$,
 -$d \le 1{,}000{,}000$。 

---

 ### 步骤 1：计算固定分母的约化分数

 固定分母$d$。 

有效分子$n$是整数：$$1 \le n < d$$互质于$d$。 

这些整数的数量正是欧拉的 totient 函数：$$\varphi(d)$$因为$\varphi(d)$计算小于的正整数$d$互质于$d$。 

例如：

-$d=8$: 互质分子是$1,3,5,7$， 所以$\varphi(8)=4$。 
-$d=7$： 全部$1,2,3,4,5,6$工作，所以$\varphi(7)=6$。 

因此，约化真分数的总数为$d \le N$是：$$\sum_{d=2}^{N} \varphi(d)$$对于这个问题：$$\sum_{d=2}^{1{,}000{,}000} \varphi(d)$$---

 ### 步骤 2：高效计算受众

 对每对进行直接 gcd 检查$(n,d)$会慢得不可思议：$$O(N^2)$$相反，计算直到$N$使用筛子（类似于埃拉托色尼筛子）。 

关键事实：

 如果$p$是素数，那么对于$p$,$$\varphi(n) = n\left(1-\frac1p\right)$$我们初始化：$$\varphi(n)=n$$那么对于每个素数$p$，更新所有倍数：$$\varphi(k) \leftarrow \varphi(k)-\frac{\varphi(k)}{p}$$这将计算所有 totients 最多$10^6$大致为：$$O(N\log\log N)$$这很容易足够快。 

---

 ## 2.Python实现```python
def count_reduced_proper_fractions(limit):
    # Initialize phi[n] = n
    phi = list(range(limit + 1))

    # Sieve to compute Euler's totient for every number
    for p in range(2, limit + 1):
        # If phi[p] == p, then p is prime
        if phi[p] == p:
            # Update all multiples of p
            for multiple in range(p, limit + 1, p):
                phi[multiple] -= phi[multiple] // p

    # Sum φ(d) for d >= 2
    return sum(phi[2:])

# Problem limit
N = 1_000_000

answer = count_reduced_proper_fractions(N)
print(answer)
```---

 ## 3. 代码演练

 ### 初始化客户端```python
phi = list(range(limit + 1))
```我们从以下开始：$$\phi(n)=n$$对于每一个$n$。 

例子：```python
phi = [0,1,2,3,4,5,6,7,8]
```为了$N=8$。 

---

 ### 检测素数```python
if phi[p] == p:
```只有素数仍然满足：$$\phi(p)=p$$在这个阶段。 

因此，这在筛选过程中充当素性测试。 

---

 ### 应用客户端更新```python
phi[multiple] -= phi[multiple] // p
```实现：$$\phi(n) = \phi(n)\left(1-\frac1p\right)$$对于每个素数的倍数$p$。 

示例$N=8$:

 处理素数后：$$\phi = [0,1,1,2,2,4,2,6,4]$$意义：$$\phi(2)=1,\; \phi(3)=2,\; \phi(4)=2,\; \phi(5)=4,\; \phi(6)=2,\; \phi(7)=6,\; \phi(8)=4$$---

 ### 将所有计数相加```python
sum(phi[2:])
```对于样品$d \le 8$:$$1+2+2+4+2+6+4 = 21$$与问题陈述完全匹配。

 ## 4.最终验证

 渐近估计为：$$\sum_{n\le N}\varphi(n) \approx \frac{3}{\pi^2}N^2$$为了$N=10^6$:$$\frac{3}{\pi^2}(10^{12}) \approx 3.04\times10^{11}$$因此，我们预计答案约为几千亿，这是正确的数量。 

运行筛子给出：$$303963552391$$这是欧拉计划问题 72 的一个众所周知的验证值。
