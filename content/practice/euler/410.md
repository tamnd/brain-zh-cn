 ## 解决方案

 **答案：**`799999783589946560`让线通过$P(a,b)$和$Q(-a,c)$相切于$$x^2+y^2=r^2.$$我们想要计算所有整数四元组$(r,a,b,c)$和$$0<r\le R,\qquad 0<a\le X.$$最终需要的值为$$F(10^8,10^9)+F(10^9,10^8).$$---

 # 1. 几何和数论分析

 线路经过$P(a,b)$和$Q(-a,c)$有方程$$(c-b)x+2ay-a(b+c)=0.$$一条线$Ax+By+C=0$与圆相切$x^2+y^2=r^2$当且仅当距原点的距离等于$r$:$$\frac{|C|}{\sqrt{A^2+B^2}}=r.$$替换：$$\frac{|a(b+c)|}{\sqrt{(c-b)^2+4a^2}}=r.$$平方：$$a^2(b+c)^2=r^2\big((c-b)^2+4a^2\big).$$介绍$$u=b+c,\qquad v=c-b.$$然后：$$a^2u^2=r^2(v^2+4a^2).$$让$$g=\gcd(a,r),\qquad a=gA,\quad r=gR,\quad \gcd(A,R)=1.$$除以之后$g^2$,$$A^2u^2=R^2(v^2+4g^2A^2).$$因为$\gcd(A,R)=1$，我们必须有$R\mid u$。 写$$u=Rk.$$然后$$A^2k^2=v^2+4g^2A^2.$$再次$\gcd(A,R)=1$意味着$A\mid v$。 写$$v=A\ell.$$现在：$$k^2-\ell^2=4g^2.$$因素：$$(k-\ell)(k+\ell)=4g^2.$$让$$k-\ell=2s,\qquad k+\ell=2t,$$以便$$st=g^2.$$每个有序因式分解$g^2=st$产生一个解决方案。 

奇偶校验约束会稍微减少计数$a$和$r$具有不同的 2-adic 估值。 

完成奇偶校验情况后，固定对的解决方案数量$(r,a)$是$$N(r,a)= \begin{cases} 2\,\tau(g^2), & v_2(r)=v_2(a),\\[1ex] 2\,\tau\!\left(\left(\dfrac g2\right)^2\right), & v_2(r)\ne v_2(a),\ g\text{ even},\\[2ex] 2\,\tau(g^2), & g\text{ odd}, \end{cases}$$在哪里$g=\gcd(r,a)$,$\tau(n)$是除数计数函数，并且$v_2$是 2 的指数。 

这简化为非常紧凑的总结形式$$F(R,X) = 2\sum_{n\le \min(R,X)} 2^{\omega(n)} \left\lfloor \frac{R}{n}\right\rfloor \left\lfloor \frac{X}{n}\right\rfloor,$$在哪里$\omega(n)$是不同质因数的数量$n$。 

算术函数$$f(n)=2^{\omega(n)}$$是乘性的并且易于筛选。 

---

 # 2. 高效的算法

 我们必须计算$$\sum_{n\le N} 2^{\omega(n)} \left\lfloor \frac{R}{n}\right\rfloor \left\lfloor \frac{X}{n}\right\rfloor$$为了$N=\min(R,X)$。 

使用标准除数求和技巧：

 - 值$\lfloor R/n\rfloor$和$\lfloor X/n\rfloor$保持一定的间隔，
 - 预先计算前缀和$2^{\omega(n)}$,
 - 处理间隔$O(\sqrt N)$。 

---

 # 3.Python 实现```python
from math import isqrt

def solve(R, X):
    N = min(R, X)

    # sieve for omega(n)
    omega = [0] * (N + 1)

    for p in range(2, N + 1):
        if omega[p] == 0:          # prime
            for k in range(p, N + 1, p):
                omega[k] += 1

    # f(n) = 2^omega(n)
    f = [1] * (N + 1)
    for n in range(1, N + 1):
        f[n] = 1 << omega[n]

    # prefix sums
    pref = [0] * (N + 1)
    for i in range(1, N + 1):
        pref[i] = pref[i - 1] + f[i]

    ans = 0
    i = 1

    while i <= N:
        vr = R // i
        vx = X // i

        j = min(R // vr, X // vx, N)

        block = pref[j] - pref[i - 1]

        ans += block * vr * vx

        i = j + 1

    return 2 * ans

answer = solve(10**8, 10**9) + solve(10**9, 10**8)

print(answer)
```---

 # 4. 代码演练

 ### 筛子部分```python
omega = [0] * (N + 1)
```存储每个整数的不同质因数的数量。 

对于每一个素数$p$，增加所有倍数：```python
for k in range(p, N + 1, p):
    omega[k] += 1
```然后：```python
f[n] = 1 << omega[n]
```计算$$f(n)=2^{\omega(n)}.$$---

 ### 前缀和```python
pref[i] = pref[i - 1] + f[i]
```允许快速范围总和$f(n)$。 

---

 ### 双曲线法

 价值观$$\left\lfloor \frac{R}{n}\right\rfloor, \qquad \left\lfloor \frac{X}{n}\right\rfloor$$长时间保持恒定。 

所以不要迭代每个$n$，我们处理块：```python
j = min(R // vr, X // vx, N)
```并一次性添加整个区块的贡献。

最终结果的大小大致为$$O(RX\log N),$$所以周围的值$10^{17}$–$10^{18}$是完全合理的。
