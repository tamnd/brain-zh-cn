[欧拉项目问题 21](https://projecteuler.net/problem=21)

 ## 解决方案

 **答案：**`31626`我们需要以下所有友好号码$10000$。 

定义$d(n)$作为真因数之和$n$。 

两个数字$a,b$形成友好的一对，如果：$$d(a)=b,\qquad d(b)=a,\qquad a\ne b$$例子：$$d(220)=284,\qquad d(284)=220$$所以220和284都包括在内。 

直接的方法：

 1. 计算$d(n)$对于每一个$n<10000$。 
2. 对于每个$a$：

- 让$b=d(a)$- 如果$b\neq a$和$d(b)=a$， 然后$a$是友善的。 
3. 将所有这些相加$a$。 

有效的除数求和可以通过迭代除数来完成$\sqrt n$。 

Python代码：```python
def divisor_sum(n):
    if n == 1:
        return 0

    total = 1
    p = 2

    while p * p <= n:
        if n % p == 0:
            total += p
            q = n // p
            if q != p:
                total += q
        p += 1

    return total

LIMIT = 10000

d = [0] * LIMIT
for i in range(1, LIMIT):
    d[i] = divisor_sum(i)

answer = 0

for a in range(1, LIMIT):
    b = d[a]

    if b != a and b > 0:
        if b < LIMIT:
            if d[b] == a:
                answer += a
        else:
            if divisor_sum(b) == a:
                answer += a

print(answer)
```已知的友好对$10000$：$$(220,284),\ (1184,1210),\ (2620,2924),\ (5020,5564),\ (6232,6368)$$对所有数字求和：$$220+284+1184+1210+2620+2924+5020+5564+6232+6368 = 31626$$**答案：31626**
