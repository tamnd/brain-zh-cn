[项目欧拉问题 380](https://projecteuler.net/problem=380)

 ## 解决方案

 **答案：**`6.3202e25093`对于一个$m\times n$迷宫, 条件

 > “从左上角的方块到任何其他方块只有一条路径”

 意味着迷宫是一个**生成树**$m\times n$网格图。 

所以问题要求矩形网格图的生成树数量$G_{m,n}$。 

根据**矩阵树定理**，图的生成树数量等于其拉普拉斯矩阵的任何辅因子。 

对于矩形网格图，可以使用离散傅里叶模式显式对角化该行列式，给出经典的闭合形式：$$C(m,n) = \frac1{mn} \prod_{x=0}^{m-1} \prod_{y=0}^{n-1} \!{}^{\prime} \left( 4 -2\cos\frac{\pi x}{m} -2\cos\frac{\pi y}{n} \right),$$其中素数表示术语$(x,y)=(0,0)$被省略。 

该公式与示例相匹配：$$C(2,2)=4, \qquad C(3,4)=2415,$$和$$C(9,12)\approx 2.5720\times 10^{46}.$$---

 一个干净的 Python 实现是：```python
import math

def maze_count(m, n):
    log10_value = 0.0

    for x in range(m):
        for y in range(n):
            if x == 0 and y == 0:
                continue

            term = (
                4
                - 2 * math.cos(math.pi * x / m)
                - 2 * math.cos(math.pi * y / n)
            )

            log10_value += math.log10(term)

    # divide by mn
    log10_value -= math.log10(m * n)

    exponent = int(math.floor(log10_value))
    mantissa = 10 ** (log10_value - exponent)

    return mantissa, exponent

# verification
print(maze_count(3, 4))   # 2.415e3  -> 2415
print(maze_count(9, 12))  # 2.5720e46

# target
print(maze_count(100, 500))
```为了$(m,n)=(100,500)$，这给出了$$C(100,500) \approx 6.320236505\ldots \times 10^{25093}.$$四舍五入到 5 位有效数字：

 **答案：6.3202e25093**
