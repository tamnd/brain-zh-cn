[欧拉项目问题 40](https://projecteuler.net/problem=40)

 ## 解决方案

 **答案：**`210`我们构造无理小数$$0.12345678910111213141516\cdots$$通过按顺序连接正整数。 

让$d_n$表示$n$小数点后第 - 位。 

我们必须计算$$d_1 d_{10} d_{100} d_{1000} d_{10000} d_{100000} d_{1000000}.$$---

 # 1.数学分析

 关键思想是找到哪个整数包含$n$第 - 位数字。 

我们按位数对整数进行分组。 

## 步骤1：统计每个区块贡献的数字

 ### 1 位数字

 数字：$$1,2,\dots,9$$有$9$数字，每个贡献$1$数字。 

总位数：$$9 \times 1 = 9$$---

 ### 2 位数字

 数字：$$10,11,\dots,99$$有$$90$$数字，每个贡献$2$数字。 

总位数：$$90 \times 2 = 180$$累计总数：$$9 + 180 = 189$$---

 ### 3 位数字$$100 \text{ to } 999$$数数：$$900$$贡献数字：$$900 \times 3 = 2700$$累计：$$2889$$- -

一般来说：

-$k$- 数字贡献$$9 \cdot 10^{k-1} \cdot k$$数字。 

---

 # 寻找$d_n$确定$d_n$：

 1. 判断哪个数字长度块包含位置$n$。 
2. 确定该块内的确切数字。 
3. 确定该数字的哪一位。 

- -

＃ 例子：$d_{12}$前 9 位数字来自$1$- 数字。 

所以位置$12$位于其中$2$- 数字。 

2 位数字块内的相对位置：$$12 - 9 = 3$$每个数字贡献 2 位数字。$$(3-1)//2 = 1$$所以我们现在是 10 后的第二个 2 位数字：$$11$$数字索引：$$(3-1)\bmod 2 = 0$$这是第一个数字$11$，即：$$1$$所以$d_{12}=1$，与语句相符。 

---

 # 计算所需的数字

 我们现在确定：$$d_1,d_{10},d_{100},d_{1000},d_{10000},d_{100000},d_{1000000}$$得到的数字是：$$1,\ 1,\ 5,\ 3,\ 7,\ 2,\ 1$$因此该产品是$$1 \times 1 \times 5 \times 3 \times 7 \times 2 \times 1$$

$$= 210$$---

 # 2.Python实现```python
def champernowne_digit(n):
    """
    Return the nth digit of Champernowne's constant:
    0.123456789101112...
    """

    digit_length = 1
    count = 9
    start = 1

    # Find which block contains the nth digit
    while n > digit_length * count:
        n -= digit_length * count
        digit_length += 1
        count *= 10
        start *= 10

    # Find the actual number containing the digit
    number = start + (n - 1) // digit_length

    # Find the digit inside that number
    digit_index = (n - 1) % digit_length

    return int(str(number)[digit_index])

# Required positions
positions = [1, 10, 100, 1000, 10000, 100000, 1000000]

product = 1

for p in positions:
    product *= champernowne_digit(p)

print(product)
```---
