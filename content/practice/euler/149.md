[欧拉项目问题 149](https://projecteuler.net/problem=149)

 ## 解决方案

 **答案：**`52852124`我们被赋予了一个$2000 \times 2000$网格填充了由滞后斐波那契生成器（LFG）生成的伪随机整数，我们必须找到四个方向中任意一个方向上相邻条目的最大总和：

 - 水平，
 - 垂直，
 - 主对角线，
 - 反对角线。 

关键的挑战是效率：对所有方向上所有可能的子阵列进行暴力破解会太慢。 

---

 # 数学分析

 ## 1. 序列生成

 顺序$s_k$定义为：

 对于$1 \le k \le 55$,$$s_k = (100003 - 200003k + 300007k^3) \bmod 1000000 - 500000$$为了$56 \le k \le 4{,}000{,}000$,$$s_k = (s_{k-24} + s_{k-55} + 1000000)\bmod 1000000 - 500000$$这些值位于区间内$$[-500000, 499999]$$这$4{,}000{,}000$术语被逐行写入$2000 \times 2000$矩阵。 

---

 # 2.最大子数组问题

 假设我们有一个一维数组：$$[a_1,a_2,\dots,a_n]$$我们需要连续块的最大总和。 

这正是经典的**最大子数组问题**，通过 **Kadane 算法** 在线性时间内最优解决。 

---

 ## Kadane 算法

 定义：

 -$best$= 迄今为止看到的最佳总和，
 -$current$= 以当前位置结束的最佳总和。 

对于每个值$x$：$$current = \max(x, current+x)$$

$$best = \max(best, current)$$这是有效的，因为每个最佳子数组都以位置结束$i$要么：

 - 重新开始于$i$, 或
 - 扩展结束于的最佳子数组$i-1$。 

时间复杂度：$$O(n)$$---

 # 3. 在 2D 方向应用 Kadane

 我们必须在以下各项上运行 Kadane：

 - 行，
 - 专栏，
 - 对角线，
 - 反对角线。 

每行的长度最多为 2000。 

检查的元素总数与网格条目总数成正比：$$O(2000^2)$$这是完全可行的。 

---

 # Python 实现```python
def generate_sequence():
    n = 4_000_000
    s = [0] * n

    # First 55 terms
    for k in range(1, 56):
        val = (100003 - 200003 * k + 300007 * k**3) % 1_000_000
        s[k - 1] = val - 500000

    # Remaining terms
    for k in range(55, n):
        val = (s[k - 24] + s[k - 55] + 1_000_000) % 1_000_000
        s[k] = val - 500000

    return s

def kadane(arr):
    best = arr[0]
    current = arr[0]

    for x in arr[1:]:
        current = max(x, current + x)
        best = max(best, current)

    return best

def solve():
    SIZE = 2000

    # Generate sequence
    seq = generate_sequence()

    # Build grid
    grid = [seq[i * SIZE:(i + 1) * SIZE] for i in range(SIZE)]

    ans = -10**18

    # -------------------------------------------------
    # Horizontal
    # -------------------------------------------------
    for row in grid:
        ans = max(ans, kadane(row))

    # -------------------------------------------------
    # Vertical
    # -------------------------------------------------
    for c in range(SIZE):
        col = [grid[r][c] for r in range(SIZE)]
        ans = max(ans, kadane(col))

    # -------------------------------------------------
    # Main diagonals
    # -------------------------------------------------
    # Start from top row
    for start_col in range(SIZE):
        diag = []
        r, c = 0, start_col

        while r < SIZE and c < SIZE:
            diag.append(grid[r][c])
            r += 1
            c += 1

        ans = max(ans, kadane(diag))

    # Start from left column (excluding top-left)
    for start_row in range(1, SIZE):
        diag = []
        r, c = start_row, 0

        while r < SIZE and c < SIZE:
            diag.append(grid[r][c])
            r += 1
            c += 1

        ans = max(ans, kadane(diag))

    # -------------------------------------------------
    # Anti-diagonals
    # -------------------------------------------------
    # Start from top row
    for start_col in range(SIZE):
        diag = []
        r, c = 0, start_col

        while r < SIZE and c >= 0:
            diag.append(grid[r][c])
            r += 1
            c -= 1

        ans = max(ans, kadane(diag))

    # Start from right column (excluding top-right)
    for start_row in range(1, SIZE):
        diag = []
        r, c = start_row, SIZE - 1

        while r < SIZE and c >= 0:
            diag.append(grid[r][c])
            r += 1
            c -= 1

        ans = max(ans, kadane(diag))

    return ans

print(solve())
