[欧拉项目问题 153](https://projecteuler.net/problem=153)

 ## 解决方案

 **答案：**`17971254122360635`让$$S(N)=\sum_{n=1}^N s(n),$$在哪里$s(n)$是所有高斯整数除数的总和$n$其实部为正。 

我们得到：$$S(10^5)=17924657155.$$我们寻求：$$S(10^8).$$---

 # 数学分析

 高斯整数是$$a+bi,\qquad a,b\in\mathbb Z.$$其规范是$$N(a+bi)=a^2+b^2.$$高斯整数$a+bi$除有理整数$n$当且仅当$$\frac{n}{a+bi}$$又是一个高斯整数。 

---

 ## 1. 有理因数 ($b=0$）

 这些只是普通的正因数$n$。 

他们的总贡献是$$\sum_{n\le N}\sigma(n),$$在哪里$\sigma(n)$是普通除数和函数。 

使用标准除数交换恒等式：$$\sum_{n\le N}\sigma(n) = \sum_{d\le N} d\left\lfloor \frac Nd\right\rfloor.$$---

 ## 2. 非实高斯除数

 假设$$z=a+bi,\qquad b\neq 0.$$然后$$\frac{n}{a+bi} = \frac{n(a-bi)}{a^2+b^2}.$$为了使其成为高斯积分，$$\frac{na}{a^2+b^2}, \qquad \frac{nb}{a^2+b^2}$$必须是整数。 

写$$a=ga',\qquad b=gb', \qquad \gcd(a',b')=1.$$然后$$a^2+b^2=g^2(a'^2+b'^2).$$自从$$\gcd(a',a'^2+b'^2)=1, \qquad \gcd(b',a'^2+b'^2)=1,$$可分性条件变为$$g(a'^2+b'^2)\mid n.$$所以每个高斯除数都来自：

 - 原始对$(a',b')$和$\gcd(a',b')=1$,
 - 缩放比例为$g$。 

---

 ## 3. 共轭对的贡献

 如果$a+bi$划分$n$，那么也如此$a-bi$。 

他们的总和是$$(a+bi)+(a-bi)=2a.$$所以虚部完全抵消。 

因此，每个原始对仅贡献实值。 

让$$m=a'^2+b'^2.$$对于每个尺度$g$，除数对贡献$$2ga'$$到每一个倍数$gm$。 

因此总贡献是$$\sum_{\substack{a',b'>0\\ \gcd(a',b')=1}} 2a' \sum_{g\le N/m} g\left\lfloor\frac{N}{gm}\right\rfloor.$$但$$\sum_{g\le M} g\left\lfloor\frac{M}{g}\right\rfloor = \sum_{k\le M}\sigma(k).$$所以：$$S(N) = \sum_{d\le N} d\left\lfloor\frac Nd\right\rfloor + 2\sum_{\substack{a,b>0\\ \gcd(a,b)=1}} a\, \Sigma\!\left(\left\lfloor\frac{N}{a^2+b^2}\right\rfloor\right),$$在哪里$$\Sigma(x)=\sum_{n\le x}\sigma(n).$$这是关键公式。 

---

 # 高效算法

 我们需要：

 1. 快速计算$$\Sigma(x)=\sum_{n\le x}\sigma(n).$$使用除数分组：$$\Sigma(x) = \sum_{d\le x} d\left\lfloor\frac xd\right\rfloor.$$这可以评估为$O(\sqrt x)$。 

1. 枚举本原格点$$a^2+b^2\le N.$$只有互质对才重要。 

生成的算法在 PyPy 中运行得相当快$N=10^8$。 

---

 # Python 实现```python
from math import gcd, isqrt

N = 10**8

# Summatory sigma:
#   S(n) = sum_{k<=n} sigma(k)
#
# Using:
#   sum sigma(k) = sum d * floor(n/d)
#
# Computed in O(sqrt(n)) using divisor grouping.
def sigma_sum(n):
    total = 0
    d = 1

    while d <= n:
        q = n // d
        r = n // q

        # sum of integers d..r
        block = (d + r) * (r - d + 1) // 2

        total += q * block
        d = r + 1

    return total

# Memoize sigma_sum values because many repeats occur.
memo = {}

def Sigma(n):
    if n not in memo:
        memo[n] = sigma_sum(n)
    return memo[n]

# ----------------------------------------------------
# Rational integer divisors contribution
# ----------------------------------------------------

answer = Sigma(N)

# ----------------------------------------------------
# Non-real Gaussian divisors
# ----------------------------------------------------

limit = isqrt(N)

for a in range(1, limit + 1):

    max_b = isqrt(N - a * a)

    for b in range(1, max_b + 1):

        if gcd(a, b) != 1:
            continue

        m = a * a + b * b

        answer += 2 * a * Sigma(N // m)

print(answer)
```---

 # 代码演练

 ##`sigma_sum(n)`计算$$\sum_{k\le n}\sigma(k).$$使用$$\sum_{k\le n}\sigma(k) = \sum_{d\le n} d\left\lfloor\frac nd\right\rfloor.$$的价值观$\lfloor n/d\rfloor$间隔保持不变，所以我们将它们分组$O(\sqrt n)$。 

---

 ## 有理除数贡献```python
answer = Sigma(N)
```这说明了所有普通正因数。 

---

 ## 原高斯除数

 我们循环互质对：```python
if gcd(a, b) != 1:
    continue
```和```python
m = a*a + b*b
```每个这样的原始高斯除数都有贡献$$2a\cdot \Sigma\!\left(\left\lfloor\frac{N}{m}\right\rfloor\right).$$所以：```python
answer += 2 * a * Sigma(N // m)
```---
