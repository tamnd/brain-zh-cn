[欧拉项目问题 279](https://projecteuler.net/problem=279)

 ## 解决方案

 **答案：**`416577688`令三角形有整数边$a,b,c$，并假设一个角度是整数度数。 

根据余弦定律，$$\cos \theta = \frac{a^2+b^2-c^2}{2ab},$$所以$\cos\theta$是理性的。 

尼文的一个经典定理说：

 > 如果$\theta/\pi$是理性的并且$\cos\theta$是有理数，那么
 >
 >
 >
 >
 >$$\cos\theta \in \left\{0,\pm \frac12,\pm1\right\}.$$对于非退化三角形，只剩下：

 -$60^\circ$,
 -$90^\circ$,
 -$120^\circ$。 

所以问题简化为计算这三种类型的所有整数三角形的周长$\le 10^8$。 

---

 # 1.直角三角形 ($90^\circ$）

 原始毕达哥拉斯三元组参数化为$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2,$$和$$m>n,\quad \gcd(m,n)=1,\quad m-n\text{ odd}.$$他们的周长是$$p=2m(m+n).$$每个非原始三元组都是原始三元组的倍数，因此贡献的数量是$$\sum \left\lfloor \frac{N}{2m(m+n)} \right\rfloor .$$---

 #2.$120^\circ$三角形

 假设$120^\circ$角是对边$c$。 然后$$c^2=a^2+b^2+ab.$$原始解的参数化为$$a=m^2-n^2,$$

$$b=2mn+n^2,$$

$$c=m^2+mn+n^2,$$和$$m>n,\qquad \gcd(m,n)=1,\qquad m\not\equiv n\pmod 3.$$周长是$$p=2m^2+3mn+n^2.$$因此贡献是$$\sum \left\lfloor \frac{N}{2m^2+3mn+n^2} \right\rfloor .$$---

 ＃3。$60^\circ$三角形

 除了等边三角形之外，每个基元$60^\circ$三角形源于一个原始的$120^\circ$三角形。 

从原始开始$120^\circ$三角形$(a,b,c)$,$$(a,c,a+b) \quad\text{and}\quad (b,c,a+b)$$是原始的$60^\circ$三角形。 

它们的原始周长变成$$p_1 = 3m(m+n),$$

$$p_2 = (2m+n)(m+2n).$$此外，等边三角形也有贡献$$\left\lfloor \frac{N}{3}\right\rfloor .$$所以总数为$60^\circ$三角形是$$\left\lfloor \frac{N}{3}\right\rfloor + \sum \left\lfloor \frac{N}{3m(m+n)} \right\rfloor + \sum \left\lfloor \frac{N}{(2m+n)(m+2n)} \right\rfloor .$$---

 # Python 实现```python
from math import gcd, isqrt

N = 10**8

# ------------------------------------------------------------
# Count 90-degree triangles
# ------------------------------------------------------------
def count_90(limit):
    total = 0

    for m in range(2, isqrt(limit // 2) + 2):
        for n in range(1, m):

            # Primitive Pythagorean conditions
            if gcd(m, n) != 1:
                continue

            if (m - n) % 2 == 0:
                continue

            perimeter = 2 * m * (m + n)

            if perimeter > limit:
                break

            total += limit // perimeter

    return total

# ------------------------------------------------------------
# Count 120-degree triangles
# ------------------------------------------------------------
def count_120(limit):
    total = 0

    for m in range(2, isqrt(limit) + 2):
        for n in range(1, m):

            # Primitive conditions
            if gcd(m, n) != 1:
                continue

            if (m - n) % 3 == 0:
                continue

            perimeter = 2 * m * m + 3 * m * n + n * n

            if perimeter > limit:
                break

            total += limit // perimeter

    return total

# ------------------------------------------------------------
# Count 60-degree triangles
# ------------------------------------------------------------
def count_60(limit):

    # Equilateral triangles
    total = limit // 3

    for m in range(2, isqrt(limit) + 2):
        for n in range(1, m):

            if gcd(m, n) != 1:
                continue

            if (m - n) % 3 == 0:
                continue

            p1 = 3 * m * (m + n)
            p2 = (2 * m + n) * (m + 2 * n)

            if p1 <= limit:
                total += limit // p1

            if p2 <= limit:
                total += limit // p2

    return total

c90 = count_90(N)
c120 = count_120(N)
c60 = count_60(N)

answer = c90 + c120 + c60

print(answer)
```---

 # 代码演练

 ###`count_90`实现原始毕达哥拉斯三元组的欧几里得公式。 

-`gcd(m,n)==1`确保原始性。 
-`(m-n)%2==1`确保相反的奇偶校验。 
- 每个倍数均使用以下方式计算：$$\left\lfloor \frac{N}{p} \right\rfloor .$$---

 ###`count_120`使用原始参数化$120^\circ$三角形。 

条件$$m\not\equiv n \pmod 3$$删除非原始重复项。 
---
 ###`count_60`计数：

 1.等边三角形，
 2. 两个$60^\circ$由每个原语生成的族$120^\circ$三角形。

 # 小验证

 对于$N=100$，程序给出：

 -$17$直角三角形，
 -$14$ $120^\circ$三角形，
 -$53$ $60^\circ$三角形，

 总共为$$17+14+53=84.$$直接暴力破解准确地证实了这一点。

 # 最终验证

 最终的数字约为数亿，这是合理的，因为：

 - 原始族是二参数晶格，
 - 每个原始三角形贡献许多倍数，
 - 周长范围非常大（$10^8$）。 

计算速度快并且只使用$O(\sqrt N)$-规模循环。
