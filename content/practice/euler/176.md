[欧拉项目问题 176](https://projecteuler.net/problem=176)

 ## 解决方案

 **答案：**`96818198400000`让$N(n)$表示具有一个内角的整数边直角三角形的数量等于$n$。 

我们被要求最小的$n$这样$$N(n)=47547.$$关键是推导除数函数公式$N(n)$。 

---

 # 1.数学分析

 假设直角三角形有边$n,b$和斜边$c$。 然后$$n^2+b^2=c^2.$$重新排列：$$c^2-b^2=n^2$$所以$$(c-b)(c+b)=n^2.$$定义$$u=c-b,\qquad v=c+b.$$然后$$uv=n^2,$$和$$c=\frac{u+v}{2},\qquad b=\frac{v-u}{2}.$$因此$u,v$必须具有相同的奇偶性。 

---

 ## 奇怪的情况

 如果$n$是奇数，那么$n^2$是奇数，所以每个除数对$(u,v)$自动为奇数。 

每个因式分解$$uv=n^2,\quad u<v$$给出一个三角形.

 因此：$$N(n)=\frac{d(n^2)-1}{2},$$在哪里$d(m)$是的约数$m$。 

---

 ## 偶数情况

 写$$n=2^a m,$$和$m$奇怪的。 

标准推导给出：$$N(n)=\frac{(2a-1)d(m^2)-1}{2}.$$等价地，如果$$n=2^{a_0}\prod p_i^{a_i},$$然后$$N(n)=\frac{\left(2a_0-1\right)\prod (2a_i+1)-1}{2}.$$这就是关键的公式。 

---

 # 2. 转换条件

 我们需要$$N(n)=47547.$$所以$$\left(2a_0-1\right)\prod (2a_i+1) = 2\cdot 47547+1.$$计算：$$2\cdot47547+1=95095.$$因素：$$95095 = 5\cdot 7\cdot 11\cdot 13\cdot 19.$$所以我们需要$$(2a_0-1)\prod (2a_i+1)=95095.$$尽量减少$n$，我们使用标准优化原则：

 - 较大的指数在较小的素数上，
 - 指数由因子确定$$2a_i+1=f_i.$$因此$$a_i=\frac{f_i-1}{2}.$$我们应该分配最大的$f_i$到最小的素碱基。 

这些因素是：$$19,\ 13,\ 11,\ 7,\ 5.$$对应的指数：$$9,\ 6,\ 5,\ 3,\ 2.$$现在我们必须决定哪个因子对应于$2$。 

对于$2$-我们使用的部分$$2a_0-1=f \quad\Rightarrow\quad a_0=\frac{f+1}{2}.$$尝试最大因素$19$:$$a_0=10.$$那么剩下的指数就是$$6,5,3,2$$在素数上$3,5,7,11$。 

因此$$n=2^{10}3^6 5^5 7^3 11^2.$$通过单调性论证（最小素数的最大指数），这是最小的。 

---

 # 3.Python实现```python
from math import prod

# Target number of triangles
target = 47547

# We need:
# (2*a0 - 1) * Π(2*ai + 1) = 2*target + 1
M = 2 * target + 1

# Prime factorization of 95095:
factors = [19, 13, 11, 7, 5]

# Assign the largest factor to the power of 2:
# 2*a0 - 1 = 19  => a0 = 10
a0 = (19 + 1) // 2

# Remaining exponents:
# ai = (factor - 1)//2
odd_exponents = [
    (13 - 1) // 2,  # 6
    (11 - 1) // 2,  # 5
    (7  - 1) // 2,  # 3
    (5  - 1) // 2   # 2
]

# Corresponding odd primes
primes = [3, 5, 7, 11]

# Construct n
n = 2**a0
for p, e in zip(primes, odd_exponents):
    n *= p**e

print(n)
```---

 # 5. 小例子验证

 对于$n=12$:$$12 = 2^2\cdot 3.$$公式给出：$$N(12) = \frac{(2\cdot2-1)(2\cdot1+1)-1}{2} = \frac{3\cdot3-1}{2} = 4.$$与问题陈述完全一致。
