[欧拉项目问题 133](https://projecteuler.net/problem=133)

 ## 解决方案

 **答案：**`453647705`让$$R(k)=\frac{10^k-1}{9}$$表示重聚$k$那些。 

我们被要求找到所有素数的和$p<100000$这样$$p \nmid R(10^n) \quad\text{for every } n\ge 0.$$---

 # 1.数学分析

 ## 步骤 1：素数何时整除重单位？ 

对于素数$p\neq 2,5$,$$p \mid R(k) \iff p \mid \frac{10^k-1}{9} \iff 10^k \equiv 1 \pmod p.$$因此关键对象是**乘法阶**$10 \pmod p$。 

定义：$$\operatorname{ord}_p(10)=\min\{d>0 : 10^d\equiv 1 \pmod p\}.$$然后：$$p \mid R(k) \iff \operatorname{ord}_p(10)\mid k.$$---

 ## 第 2 步：专注于$R(10^n)$我们现在要求：$$p \mid R(10^n) \iff \operatorname{ord}_p(10)\mid 10^n.$$但$$10^n = 2^n5^n,$$所以它唯一的素因数是$2$和$5$。 

所以：$$\operatorname{ord}_p(10)\mid 10^n$$对于某些人来说$n$**当且仅当**订单不包含除$2$和$5$。 

等效地：$$\operatorname{ord}_p(10)=2^a5^b$$对于某些整数$a,b\ge0$。 

因此：

 - 如果订单有任何其他素因数（例如$3,7,11,\dots$）， 然后$p$**永远不会**分割任何$R(10^n)$。 
- 否则，它最终会的。 

---

 ## 步骤 3：声明中的示例

 ### 总理$17$

$$\operatorname{ord}_{17}(10)=16=2^4.$$自从$16\mid 10^4$,$$17 \mid R(10^4).$$所以$17$是某些的有效除数$R(10^n)$。 

- -

＃＃＃ 主要的$19$

$$\operatorname{ord}_{19}(10)=18=2\cdot 3^2.$$因为这个因素$3$,$18\nmid 10^n$对于每一个$n$。 

因此$19$从不分割任何$R(10^n)$。

 # 2.Python实现```python
from sympy import primerange

def multiplicative_order_10(p):
    """
    Compute the multiplicative order of 10 modulo p.
    Assumes gcd(p, 10) = 1.
    """
    order = 1
    value = 10 % p

    while value != 1:
        value = (value * 10) % p
        order += 1

    return order

total = 0

for p in primerange(2, 100000):

    # 2 and 5 can never divide repunits
    if p in (2, 5):
        total += p
        continue

    order = multiplicative_order_10(p)

    # Remove all factors of 2
    while order % 2 == 0:
        order //= 2

    # Remove all factors of 5
    while order % 5 == 0:
        order //= 5

    # If anything remains, order had another prime factor
    # so p can never divide R(10^n)
    if order != 1:
        total += p

print(total)
```---
