[项目欧拉问题 531](https://projecteuler.net/problem=531)

 ## 解决方案

 **答案：**`4515432351156203105`我们需要计算$$\sum_{1000000 \le n < m < 1005000} f(n,m)$$在哪里$$f(n,m)=g(\phi(n),n,\phi(m),m),$$和$g(a,n,b,m)$是最小非负解$$x\equiv a \pmod n,\qquad x\equiv b \pmod m,$$或者$0$如果不存在解决方案。 

自然的方法是：

 1. 预先计算 Euler 的 totient 函数$\phi(n)$为所有人$n\in[10^6,1004999]$使用筛子。 
2. 对于每对$(n,m)$、求解CRT系统：$$x\equiv \phi(n)\pmod n,\qquad x\equiv \phi(m)\pmod m.$$3. 如果同余式不兼容模$\gcd(n,m)$， 贡献$0$。 
4. 否则使用广义中国剩余定理计算最小解。 

使用的确切Python代码：```python
from math import gcd

L = 1000000
R = 1005000

# Compute Euler phi values by sieve
phi = list(range(R + 1))

for i in range(2, R + 1):
    if phi[i] == i:  # prime
        for j in range(i, R + 1, i):
            phi[j] -= phi[j] // i

def crt(a, n, b, m):
    g = gcd(n, m)

    # No solution
    if (b - a) % g:
        return 0

    ng = n // g
    mg = m // g
    rhs = (b - a) // g

    # Solve ng * t ≡ rhs (mod mg)
    inv = pow(ng, -1, mg)
    t = (rhs * inv) % mg

    lcm = ng * m
    x = (a + n * t) % lcm
    return x

# Verify examples
print(crt(2,4,4,6))  # 10
print(crt(3,4,4,6))  # 0

total = 0

for n in range(L, R):
    an = phi[n]
    for m in range(n + 1, R):
        total += crt(an, n, phi[m], m)

print(total)
```验证示例与表述相符：
