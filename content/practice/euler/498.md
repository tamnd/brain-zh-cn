[欧拉项目 498 问题](https://projecteuler.net/problem=498)

 ## 解决方案

 **答案：**`472294837`让$$F_n(x)=x^n,\qquad G_m(x)=(x-1)^m.$$我们定义$R_{n,m}(x)$为余数，当$x^n$除以$(x-1)^m$。 由于除数有度数$m$，其余的最多有学位$m-1$。 

我们求系数的绝对值$x^d$在$R_{n,m}(x)$：$$C(n,m,d).$$我们被要求计算$$C(10^{13},10^{12},10^4)\pmod{999999937}.$$---

 # 1.数学分析

 我们围绕这一点开展工作$x=1$。 

定义$$y=x-1 \quad\Longrightarrow\quad x=1+y.$$然后$$x^n=(1+y)^n.$$模数$y^m$，只有第一个$m$二项式展开式的项仍然存在：$$R_{n,m}(x) = \sum_{k=0}^{m-1}\binom{n}{k}(x-1)^k.$$所以系数为$x^d$是$$a_d = \sum_{k=d}^{m-1}\binom{n}{k}[x^d](x-1)^k.$$现在展开：$$(x-1)^k = \sum_{j=0}^k \binom{k}{j}x^j(-1)^{k-j}.$$因此$$[x^d](x-1)^k = (-1)^{k-d}\binom{k}{d}.$$所以$$a_d = \sum_{k=d}^{m-1} (-1)^{k-d}\binom{n}{k}\binom{k}{d}.$$---

 ## 简化总和

 使用身份$$\binom{n}{k}\binom{k}{d} = \binom{n}{d}\binom{n-d}{k-d}.$$让$j=k-d$。 然后$$a_d = \binom{n}{d} \sum_{j=0}^{m-1-d} (-1)^j \binom{n-d}{j}.$$现在应用交替二项式恒等式$$\sum_{j=0}^{r}(-1)^j\binom{N}{j} = (-1)^r\binom{N-1}{r}.$$和$$N=n-d,\qquad r=m-1-d,$$我们得到$$a_d = (-1)^{m-1-d} \binom{n}{d} \binom{n-d-1}{m-d-1}.$$自从$C(n,m,d)$是绝对值，$$\boxed{ C(n,m,d) = \binom{n}{d} \binom{n-d-1}{m-d-1}. }$$---

 ## 检查示例

 ### 示例 1$$C(6,3,1) = \binom61\binom41 = 6\cdot4 = 24.$$正确的。 

---

 ### 示例 2$$C(100,10,4) = \binom{100}{4}\binom{95}{5}.$$这等于$$227197811615775,$$匹配问题陈述。 

---

 # 2. 模块化计算

 我们需要$$\binom{10^{13}}{10^4} \binom{10^{13}-10^4-1}{10^{12}-10^4-1} \pmod p,$$在哪里$$p=999999937.$$自从$p$是素数，我们使用卢卡斯定理。 

---

 ## 卢卡斯分解

 在基数中写入数字$p$。 

### 第一个因素$$10^{13}=10000\cdot p + 630000,$$所以$$\binom{10^{13}}{10^4} \equiv \binom{10000}{0} \binom{630000}{10000} \pmod p.$$因此$$\binom{10^{13}}{10^4} \equiv \binom{630000}{10000}.$$---

 ### 第二个因素$$10^{13}-10^4-1 = 10000\cdot p + 619999,$$和$$10^{12}-10^4-1 = 1000\cdot p + 52999.$$因此$$\binom{10^{13}-10^4-1}{10^{12}-10^4-1} \equiv \binom{10000}{1000} \binom{619999}{52999} \pmod p.$$所以$$C \equiv \binom{630000}{10000} \binom{10000}{1000} \binom{619999}{52999} \pmod p.$$下面这些都是普通的组合$p$，可使用阶乘和费马逆进行计算。 

---

 # 3.Python实现```python
MOD = 999999937

def mod_comb(n, r, mod):
    """Compute C(n,r) mod prime mod."""
    if r < 0 or r > n:
        return 0

    r = min(r, n - r)

    numerator = 1
    denominator = 1

    for i in range(1, r + 1):
        numerator = (numerator * (n - r + i)) % mod
        denominator = (denominator * i) % mod

    return numerator * pow(denominator, mod - 2, mod) % mod

# Problem values
n = 10**13
m = 10**12
d = 10**4

# Lucas reductions already derived mathematically
a = mod_comb(630000, 10000, MOD)
b = mod_comb(10000, 1000, MOD)
c = mod_comb(619999, 52999, MOD)

answer = (a * b % MOD) * c % MOD

print(answer)
```---

 # 4. 代码演练

 ##`mod_comb`这计算$$\binom{n}{r}\pmod p$$使用$$\binom{n}{r} = \frac{n(n-1)\cdots(n-r+1)}{r!}.$$因为$p$是素数，我们除以模$p$使用费马定理：$$a^{-1}\equiv a^{p-2}\pmod p.$$---

 ## 主要计算

 我们使用上面导出的卢卡斯约简：```python
a = mod_comb(630000, 10000, MOD)
b = mod_comb(10000, 1000, MOD)
c = mod_comb(619999, 52999, MOD)
```然后```python
answer = (a * b % MOD) * c % MOD
```给出所需的值。
