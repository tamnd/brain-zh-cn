[项目欧拉问题 853](https://projecteuler.net/problem=853)

 ## 解决方案

 **答案：**`44511058204`让$\pi(n)$表示皮萨诺周期模$n$，即斐波那契数列的周期模$n$。 

我们必须计算$$\sum_{\substack{n<10^9\\ \pi(n)=120}} n.$$---

 # 1.数学分析

 关于皮萨诺时期的主要事实是：

 ## A. 乘法

 如果$\gcd(a,b)=1$， 然后$$\pi(ab)=\operatorname{lcm}(\pi(a),\pi(b)).$$因此，一旦我们知道素数幂的周期，每个合数都可以从最小公倍数中得出。 

---

 ## B. 主要权力

 对于素数$p\neq 2,5$,$$\pi(p^k)=p^{k-1}\pi(p).$$特殊情况：$$\pi(2^k)=3\cdot 2^{k-1}\quad (k\ge1),$$

$$\pi(5^k)=20\cdot 5^{k-1}.$$---

 ## C. 如果$\pi(n)=120$， 然后$n\mid F_{120}$因为斐波那契数列模$n$重复每个$120$步骤，$$F_{120}\equiv 0 \pmod n.$$因此每个素数除法$n$必须划分$F_{120}$。 

现在因素$F_{120}$:$$F_{120} = 2^5\cdot 3^2\cdot 5\cdot 7\cdot 11\cdot 23\cdot 31\cdot 41\cdot 61\cdot 241\cdot 2161\cdot 2521\cdot 20641.$$我们现在计算每个相关素数的皮萨诺周期。 

---

 # 2. 黄金时期

 期间是：

 | 主要的$p$|$\pi(p)$|
 | --- | --- |
 |$2$|$3$|
 |$3$|$8$|
 |$5$|$20$|
 |$7$|$16$|
 |$11$|$10$|
 |$23$|$48$|
 |$31$|$30$|
 |$41$|$40$|
 |$61$|$60$|
 |$241$|$240$|
 |$2161$|$80$|
 |$2521$|$120$|
 |$20641$|$240$|

 仅以句号划分$120$可用。 

所以：

-$23,241,20641$是不可能的，因为它们的周期包含不划分的因素$120$。 

因此，允许的素数幂为：

 ### 的权力$2$

$$\pi(2)=3,\quad \pi(4)=6,\quad \pi(8)=12,\quad \pi(16)=24.$$（$2^5$已经有月经了$48$，实际上仍然除以 120，但是$32$不分开$F_{120}$; 等价地，因式分解只能得到最多 5 的指数。 直接计算可知$32$给出句号$48$，原则上仍然允许——但是$32\mid F_{120}$，所以我们必须将其包括在内。 让我们仔细重新计算一下。）

 使用精确的公式：$$\pi(2^k)=3\cdot 2^{k-1}.$$因此：$$\pi(2)=3,\; \pi(4)=6,\; \pi(8)=12,\; \pi(16)=24,\; \pi(32)=48.$$全部划分$120$， 所以$2^k$和$k\le5$是允许的。 

### 的权力$3$

$$\pi(3)=8,\quad \pi(9)=24.$$（$27$给出$72$，不除$120$.)

 ### 的权力$5$

$$\pi(5)=20.$$（$25$给出$100$，不除$120$.)

 ### 剩余素数$$7\to16,\quad 11\to10,\quad 31\to30,\quad 41\to40,\quad 61\to60,\quad 2161\to80,\quad 2521\to120.$$---

 # 3.构建所有$n$每一个可受理的$n$有形式$$n = 2^a3^b5^c7^d11^e31^f41^g61^h2161^i2521^j$$指数限制为：

 -$0\le a\le5$-$0\le b\le2$-$0\le c,d,e,f,g,h,i,j\le1$和满足$$\operatorname{lcm}(\pi(\text{each chosen prime power}))=120.$$这是一个很小的搜索空间，因此我们枚举了所有可能性。 

---

 # 4.Python实现```python
from math import lcm

LIMIT = 10**9

# For each prime, list all allowed prime powers together with their Pisano periods.
choices = [
    [(1, 1), (2, 3), (4, 6), (8, 12), (16, 24), (32, 48)],
    [(1, 1), (3, 8), (9, 24)],
    [(1, 1), (5, 20)],
    [(1, 1), (7, 16)],
    [(1, 1), (11, 10)],
    [(1, 1), (31, 30)],
    [(1, 1), (41, 40)],
    [(1, 1), (61, 60)],
    [(1, 1), (2161, 80)],
    [(1, 1), (2521, 120)],
]

answer = 0

def search(index, current_n, current_period):
    global answer

    if current_n >= LIMIT:
        return

    if index == len(choices):
        if current_period == 120:
            answer += current_n
        return

    for value, period in choices[index]:
        search(
            index + 1,
            current_n * value,
            lcm(current_period, period)
        )

search(0, 1, 1)

print(answer)
```---

 ## 递归搜索

 我们为每个素数递归地选择一个选项。 

每一步：

 - 乘以当前数字，
 - 使用更新整个皮萨诺时期`lcm`。 

在最后：```python
if current_period == 120:
    answer += current_n
```---
