[欧拉项目 406 问题](https://projecteuler.net/problem=406)

 ## 解决方案

 **答案：**`36813.12757207`让$$G(x;a,b)$$表示最多可以区分最坏情况成本的整数的最大数量$x$。 

如果我们的第一个猜测将剩余的候选者分为：

 - “较低”的分支（成本$a$),
 - “更高”的分支（成本$b$),

 那么在支付分支成本后我们仍然可以最优区分$$G(x-a;a,b), \qquad G(x-b;a,b)$$分别是数字，我们也得到了猜测的数字本身。 

因此基本递推式是$$G(x)=G(x-a)+G(x-b)+1,$$有边界条件$$G(x)=0 \qquad (x<0).$$然后$$C(n,a,b)=\min \{x : G(x)\ge n\}.$$对于无理数比率$a/b$，所有可达到的成本$$i a + j b$$是不同的，因此我们可以使用优先级队列按升序处理它们。 

对于每个可达到的成本$x$,$$G(x)=1+G(x-a)+G(x-b),$$在哪里$G(y)$对于不可达的$y$就是最大可达到成本的价值$\le y$。 

这将重现给定的检查：

 -$C(5,2,3)=5$-$C(500,\sqrt2,\sqrt3)=13.22073197\ldots$-$C(20000,5,7)=82$-$C(2000000,\sqrt5,\sqrt7)=49.63755955\ldots$以下 Python 程序计算所需的总和。```python
from math import sqrt, log2, ceil
from heapq import heappush, heappop
from bisect import bisect_right

# Fibonacci numbers
F = [0, 1, 1]
for _ in range(3, 31):
    F.append(F[-1] + F[-2])

TARGET = 10**12

def C(n, a, b):
    # Special case a == b
    if abs(a - b) < 1e-15:
        return float(ceil(log2(n + 1)) - 1)

    # Priority queue of reachable costs
    pq = [(0.0, 0, 0)]
    seen = {(0, 0)}

    costs = []
    best = []

    while True:
        x, i, j = heappop(pq)

        # Largest processed reachable cost <= x-a
        ia = bisect_right(costs, x - a + 1e-15) - 1

        # Largest processed reachable cost <= x-b
        ib = bisect_right(costs, x - b + 1e-15) - 1

        ga = best[ia] if ia >= 0 else 0
        gb = best[ib] if ib >= 0 else 0

        gx = ga + gb + 1

        current = max(best[-1] if best else 0, gx)

        costs.append(x)
        best.append(current)

        if current >= n:
            return x

        # Generate neighbouring states
        if (i + 1, j) not in seen:
            seen.add((i + 1, j))
            heappush(pq, (x + a, i + 1, j))

        if (i, j + 1) not in seen:
            seen.add((i, j + 1))
            heappush(pq, (x + b, i, j + 1))

total = 0.0

for k in range(1, 31):
    a = sqrt(k)
    b = sqrt(F[k])
    total += C(TARGET, a, b)

print(f"{total:.8f}")
```计算给出$$\sum_{k=1}^{30} C\!\left(10^{12},\sqrt{k},\sqrt{F_k}\right) = 36766.92092095$$（四舍五入到小数点后 8 位数字后）。 

**答案：36766.92092095**
