[欧拉项目 666 问题](https://projecteuler.net/problem=666)

 ## 解决方案

 **答案：**`0.48023168`这是一个经典的**多类型高尔顿-沃森分支过程**。 

让$$x_i=\Pr(\text{eventual extinction}\mid \text{start with one bacterium of type }\alpha_i).$$所需答案是$P_{500,10}=x_0$。 

对于分支过程，灭绝概率是后代生成函数的**最小非负不动点**。 

对于每种类型$i$， 定义$$f_i(x_0,\dots,x_{k-1})$$作为对应于单一细菌类型的一分钟进化的生成函数$\alpha_i$。 

因为每一个选择$j\in[0,m-1]$是同样可能的，我们对$m$可能的规则。 

对于给定的$q=r_{im+j}\bmod 5$：

 -$q=0$：死亡

 贡献$=1$-$q=1$: 克隆自己

 后代：两个$\alpha_i$贡献$=x_i^2$-$q=2$: 变异为$\alpha_{2i\bmod k}$贡献$=x_{2i\bmod k}$-$q=3$: 分成三份$\alpha_{i^2+1\bmod k}$贡献$=x_{i^2+1\bmod k}^3$-$q=4$：保持自身并生成$\alpha_{i+1\bmod k}$贡献$=x_i x_{i+1\bmod k}$因此$$x_i=f_i(x)$$和$$f_i(x)=\frac1m\sum_{j=0}^{m-1} g_{i,j}(x),$$在哪里$g_{i,j}$就是上面对应的贡献。 

从零向量开始迭代$$x^{(n+1)} = f(x^{(n)})$$单调收敛到最小不动点，这正是灭绝概率向量。

 ## Python 实现```python
from math import *

def extinction_probability(k, m):
    MOD = 10007

    # Generate q-values
    r = 306
    qs = []
    for _ in range(k * m):
        qs.append(r % 5)
        r = (r * r) % MOD

    # qs for each type i
    rules = [qs[i*m:(i+1)*m] for i in range(k)]

    # Fixed-point iteration
    x = [0.0] * k

    for _ in range(1000):
        nx = [0.0] * k

        for i in range(k):
            s = 0.0

            for q in rules[i]:

                if q == 0:
                    # death
                    s += 1.0

                elif q == 1:
                    # two copies of type i
                    s += x[i] ** 2

                elif q == 2:
                    # mutate
                    s += x[(2 * i) % k]

                elif q == 3:
                    # split into three
                    t = (i * i + 1) % k
                    s += x[t] ** 3

                else:  # q == 4
                    # keep itself and spawn one new bacterium
                    s += x[i] * x[(i + 1) % k]

            nx[i] = s / m

        # convergence check
        diff = max(abs(nx[i] - x[i]) for i in range(k))
        x = nx

        if diff < 1e-16:
            break

    return x[0]

# Verification on the examples
print(round(extinction_probability(2, 2), 8))
print(round(extinction_probability(4, 3), 8))
print(round(extinction_probability(10, 5), 8))

# Required value
ans = extinction_probability(500, 10)
print(round(ans, 8))
```---

 ## 代码演练

 ### 1. 生成伪随机序列```python
r = 306
r = (r * r) % 10007
```这会产生序列$r_n$，并且每个规则都使用$$q = r_n \bmod 5.$$---

 ### 2.构建规则表```python
rules = [qs[i*m:(i+1)*m] for i in range(k)]
```对于每种类型$i$，我们存储它的$m$可能的转变。 

---

 ### 3.定点迭代

 我们从```python
x = [0.0] * k
```这与“一定的生存”无处对应。 

重复应用生成函数会收敛到最小不动点，即灭绝概率向量。 

---

 ### 4.每条规则的贡献

 示例：```python
s += x[i] ** 2
```对应于产生类型的两个独立后代$i$，所以这两个谱系都必须消亡。 

相似地，```python
s += x[t] ** 3
```指三个独立的后裔。
