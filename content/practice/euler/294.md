[项目欧拉问题 294](https://projecteuler.net/problem=294)

 ## 解决方案

 **答案：**`789184709`设小数展开式为$k$是$$k=\sum_{i=0}^{n-1} a_i 10^i, \qquad 0\le a_i\le 9.$$我们想要数一下数字$k<10^n$这样

 1.$k\equiv 0 \pmod{23}$,
 2.$\sum a_i = 23$。 

将此计数表示为$S(n)$。 

---

 # 1.数学分析

 ## 1.1 条件编码

 数字和条件是$$\sum_{i=0}^{n-1} a_i = 23.$$可分性条件是$$\sum_{i=0}^{n-1} a_i 10^i \equiv 0 \pmod{23}.$$所以每个数字同时贡献：

 -$+a_i$到数字和，
 -$+a_i 10^i$模数$23$。 

这强烈建议采用生成函数方法。 

---

 ## 1.2 双变量生成函数

 对于固定位置$i$, 数字$d\in\{0,\dots,9\}$贡献$$x^d y^{d10^i}.$$因此位置$i$贡献多项式$$P_i(x,y)=\sum_{d=0}^9 x^d y^{d10^i}.$$乘以所有位置：$$F_n(x,y)=\prod_{i=0}^{n-1} P_i(x,y).$$然后：

 - 的指数$x$记录数字和，
 - 的指数$y$记录余数模$23$。 

所以，$$S(n)= [x^{23}y^0]\,F_n(x,y),$$其中的指数$y$被解释为模$23$。 

---

 ## 1.3 周期模 23

 一个关键的观察：$$10^{22}\equiv 1 \pmod{23},$$因为$23$是素数并且$10$是一个原始元素模$23$。 

因此序列$10^i \pmod{23}$有月经$22$。 

因此，这些因素每次都会重复$22$职位。 

让$$n = 22q + r,\qquad 0\le r<22.$$然后每个残基类别位置出现：

 -$q$次，或
 -$q+1$次。 

具体来说，对于$j=0,\dots,21$,$$P_j(x,y)=\sum_{d=0}^9 x^d y^{d10^j},$$和$$F_n(x,y) = \prod_{j=0}^{21} P_j(x,y)^{\,q+\mathbf 1_{j<r}}.$$---

 ## 1.4 截断奇迹

 我们只关心系数$x^{23}$。 

因此，在所有乘法过程中，我们可以丢弃每个次数项$>23$。 

所以整个计算都存在于一个微小的有限代数中：

 -$x$-程度：$0\ldots 23$,
 - 余数模$23$：$0\ldots 22$。 

州总数：$$24\times 23 = 552.$$求幂变得非常快。 

---

 # 2.Python实现```python
MOD = 10**9

# --------------------------------------------------------------------
# Polynomial representation:
# dictionary mapping (digit_sum, residue_mod_23) -> coefficient
# --------------------------------------------------------------------

def multiply(A, B):
    """
    Multiply two truncated polynomials.

    State:
        (s, r)
    means:
        x^s y^r

    We truncate all terms with s > 23.
    """
    C = {}

    for (s1, r1), v1 in A.items():
        for (s2, r2), v2 in B.items():

            s = s1 + s2

            # We only need digit sum <= 23
            if s <= 23:
                r = (r1 + r2) % 23

                key = (s, r)

                C[key] = (C.get(key, 0) + v1 * v2) % MOD

    return C

def power(P, e):
    """
    Fast exponentiation of a polynomial.
    """
    R = {(0, 0): 1}

    while e > 0:

        if e & 1:
            R = multiply(R, P)

        P = multiply(P, P)

        e >>= 1

    return R

def S(n):
    """
    Compute S(n) mod 1e9.
    """

    q, r = divmod(n, 22)

    # Start with multiplicative identity
    ans = {(0, 0): 1}

    # Build the 22 periodic factors
    for j in range(22):

        w = pow(10, j, 23)

        # P_j(x,y)
        P = {}

        for d in range(10):
            key = (d, (d * w) % 23)
            P[key] = P.get(key, 0) + 1

        exponent = q + (1 if j < r else 0)

        ans = multiply(ans, power(P, exponent))

    return ans.get((23, 0), 0)

# --------------------------------------------------------------------
# Verification on given examples
# --------------------------------------------------------------------

print(S(9))      # 263626
print(S(42))     # 878570056  (matches the last 9 digits)

# Final computation
N = 11**12

print(S(N))
```---

 # 3. 代码演练

 ##`multiply(A, B)`每个多项式都是稀疏存储的。 

一个术语```python
(s, r): value
```方法：$$\text{value}\cdot x^s y^r.$$乘法时：$$x^{s_1}y^{r_1}\cdot x^{s_2}y^{r_2} = x^{s_1+s_2}y^{r_1+r_2}.$$余数减少模$23$。 

我们丢弃所有带有数字和的项$>23$。 

---

 ##`power(P, e)`标准二进制求幂。 

这计算：$$P^e$$在$O(\log e)$乘法。 

自从$11^{12}\approx 3.1\times 10^{12}$，仅关于$42$需要平方步骤。 

---

 ##`S(n)`我们使用周期性：$$10^{22}\equiv 1 \pmod{23}.$$因此只有$22$不同的职位类型。 

如果$$n=22q+r,$$然后因素$P_j$出现：$$q+\mathbf 1_{j<r}$$次。 

最后我们提取系数：```python
ans[(23, 0)]
```这完全对应于：

 - 数字总和$23$,
 - 残留物$0\pmod{23}$。 

---
