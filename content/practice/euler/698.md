[欧拉项目 698 问题](https://projecteuler.net/problem=698)

 ## 解决方案

 **答案：**`57808202`让$S$是所有 123 个数字的集合。 

一个十进制数属于$S$当且仅当：

 1. 每个数字都在$\{1,2,3\}$, 和
 2. 对于每一个出现的数字，它的频率也属于$S$。 

例如：

-$33\in S$因为数字$3$出现$2$次和$2\in S$。 
-$1112\in S$因为计数是：

 - 数字$1$：$3$次，
 - 数字$2$：$1$时间，

 以及两者$1,3\in S$。 

我们寻求$$F(111111111111222333),$$这$111111111111222333$-rd 123-数字按升序排列。 

---

 # 1.数学分析

 ## 一个关键的递归观察

 如果一个号码有：

 -$a$数字的副本$1$,
 -$b$数字的副本$2$,
 -$c$数字的副本$3$,

 那么该号码是有效的当且仅当$$a,b,c \in \{0\}\cup S.$$对于固定三元组$(a,b,c)$，有效字符串的数量就是多项式计数$$\binom{a+b+c}{a,b,c} = \frac{(a+b+c)!}{a!b!c!}.$$所以整个问题简化为：

 1. 枚举可接受的计数三元组，
 2. 计算每个总长度存在多少个有效字符串，
 3. 按字典顺序取消排序。 

---

 ## 哪些计数值很重要？ 

目标指数约为$10^{17}$，所以答案长度并不大。 

按长度计算累积计数显示：

 - 所有长度有效的数字$\le 37$全部的$$85\,645\,659\,280\,376\,850,$$同时包括长度$38$超过目标。 

因此答案有长度$38$。 

现在观察：

 - 任何可接受的计数本身必须是 123 个数字$\le 38$,
 - 唯一这样的值是$$1,2,3,11,12,13,21,22,23,31,32,33.$$所以我们只需要这 12 个值（加上 0）。 

---

 ## 计算所有有效长度为 38 的数字

 我们考虑所有三元组$$(a,b,c)$$和$$a+b+c=38$$和每个组件$$\{0,1,2,3,11,12,13,21,22,23,31,32,33\}.$$对于每个三元组，添加$$\frac{38!}{a!b!c!}.$$这给出了$$84\,604\,808\,105\,550\,180$$有效长度为 123 个数字$38$。 

所需的索引内部长度$38$因此是$$111111111111222333 - 85645659280376850 = 25465451830845483.$$---

 ## 字典顺序取消排序

 固定长度的数字按字典顺序排序。 

我们逐位构造答案。 

在每个位置：

 - 尝试放置$1$,
 - 计算存在多少个完成，
 - 如果目标索引超过该计数，则减去并尝试$2$,
 - 否则保留$1$并继续。 

选择前缀后的完成次数再次是使用剩余数字频率的多项式计数。 

这会产生独特的结果：$$13312122322122222113311233331213131323.$$最后计算模$123123123$：$$13312122322122222113311233331213131323 \equiv 57808202 \pmod{123123123}.$$---

 # 2.Python实现```python
from math import comb
from functools import lru_cache

TARGET = 111_111_111_111_222_333
MOD = 123_123_123

# All 123-numbers <= 38
VALID = [0, 1, 2, 3, 11, 12, 13, 21, 22, 23, 31, 32, 33]

@lru_cache(None)
def multinomial(a, b, c):
    """
    Number of strings containing:
        a copies of '1'
        b copies of '2'
        c copies of '3'
    """
    n = a + b + c
    return comb(n, a) * comb(n - a, b)

def count_length(L):
    """
    Count all 123-numbers of total length L.
    """
    total = 0

    for a in VALID:
        for b in VALID:
            c = L - a - b

            if c in VALID:
                total += multinomial(a, b, c)

    return total

# ------------------------------------------------------------
# Step 1: determine the answer length
# ------------------------------------------------------------

cumulative = 0
length = 0

while True:
    length += 1
    cnt = count_length(length)

    if cumulative + cnt >= TARGET:
        break

    cumulative += cnt

# Index inside this length block
k = TARGET - cumulative

# ------------------------------------------------------------
# Step 2: enumerate all admissible count triples
# ------------------------------------------------------------

triples = []

for a in VALID:
    for b in VALID:
        c = length - a - b

        if c in VALID:
            triples.append((a, b, c))

# ------------------------------------------------------------
# Step 3: lexicographic unranking
# ------------------------------------------------------------

answer_digits = []

for _ in range(length):

    for digit in "123":

        total = 0
        next_triples = []

        for a, b, c in triples:

            aa, bb, cc = a, b, c

            if digit == "1":
                if aa == 0:
                    continue
                aa -= 1

            elif digit == "2":
                if bb == 0:
                    continue
                bb -= 1

            else:
                if cc == 0:
                    continue
                cc -= 1

            total += multinomial(aa, bb, cc)
            next_triples.append((aa, bb, cc))

        if k > total:
            k -= total
        else:
            answer_digits.append(digit)
            triples = next_triples
            break

answer = int("".join(answer_digits))

print("F(n) =", answer)
print("Modulo =", answer % MOD)
```---

 # 3. 代码演练

 ##`multinomial(a,b,c)`计算$$\frac{(a+b+c)!}{a!b!c!}$$使用二项式系数：```python
comb(n, a) * comb(n - a, b)
```---

 ##`count_length(L)`枚举每个可接受的三元组：```python
(a,b,c)
```与总长度$L$，然后对多项计数求和。 

---

 ## 确定答案长度

 我们按长度累加计数，直到累加总数达到目标索引。 

这揭示了：```python
length = 38
```---

 ## 词典结构

 对于每个数字位置：

 - 暂定地点`1`,
 - 计算所有完成情况，
 - 如果太小，跳过它们，
 - 否则保留`1`。 

重复进行`2`和`3`。 

这是标准的组合取消排序。
