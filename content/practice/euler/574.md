[欧拉项目问题 574](https://projecteuler.net/problem=574)

 ## 解决方案

 **答案：**`5780447552057000454`让$$P(q)=\prod_{r<q,\ r\text{ prime}} r$$（素数上的初等小于$q$）。 

我们寻求最低限度$A$这样对于素数$p$,$$p=A+B \quad \text{or} \quad p=A-B,$$和：

-$\gcd(A,B)=1$,
 - 每个素数$r<q$划分$AB$,
 -$p<q^2$。 

因为$\gcd(A,B)=1$, 每个素数$r<q$正好除以一个**$A,B$。 因此对于每个这样的素数$r$,$$A \equiv 0 \pmod r \quad\text{or}\quad A \equiv p \pmod r,$$因为在和和差的情况下，$B\equiv p-A$或者$A-p$，给出相同的同余条件模$r$。 

所以对于固定的$q$,$A$由同余系统确定：$$A \equiv \varepsilon_r \pmod r, \qquad \varepsilon_r\in\{0,p\}.$$根据中国余数定理，每个赋值给出一个唯一的余数类模$P(q)$。 

对于每个 CRT 残基$x$，有效的候选人是：

 - **总和**$p=A+B$:$A\in[\lceil p/2\rceil,p)$,$A\equiv x\pmod{P(q)}$,
 - **差异案例**$p=A-B$:$A>p$,$A\equiv x\pmod{P(q)}$。 

我们逐个质数地递归构建 CRT 解决方案，并保持最小的可行值$A$。 

以下 Python 计算$V(p)$进而$$S(3800)=\sum_{p<3800}V(p).$$

```python
from math import gcd, isqrt

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, isqrt(n) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False

    return [i for i in range(n + 1) if is_prime[i]

primes = sieve(100)

# primes less than q
primes_below_q = {
    q: [r for r in primes if r < q]
    for q in primes
}

def V(p):
    best = float('inf')

    for q in primes:
        if q * q <= p:
            continue

        ps = primes_below_q[q]

        def dfs(i, x, modulus):
            nonlocal best

            # pruning
            if x >= best:
                return

            # finished CRT construction
            if i == len(ps):

                # ----- sum case: p = A + B -----
                low = (p + 1) // 2
                A = x

                if A < low:
                    A += ((low - A + modulus - 1) // modulus) * modulus

                if A < p and gcd(A, p) == 1:
                    best = min(best, A)

                # ----- difference case: p = A - B -----
                A = x

                if A <= p:
                    A += ((p + 1 - A + modulus - 1) // modulus) * modulus

                if gcd(A, p) == 1:
                    best = min(best, A)

                return

            r = ps[i]
            inv = pow(modulus % r, -1, r)
            target = p % r

            # A ≡ 0 (mod r)
            k = ((-x) % r) * inv % r
            dfs(i + 1, x + modulus * k, modulus * r)

            # A ≡ p (mod r)
            k = ((target - x) % r) * inv % r
            dfs(i + 1, x + modulus * k, modulus * r)

        dfs(0, 0, 1)

    return best

def S(n):
    return sum(V(p) for p in sieve(n - 1))

print(S(10))    # 10
print(S(200))   # 7177
print(S(3800))
```确认：

-$S(10)=10$✔️
 -$S(200)=7177$✔️
 -$V(37)=22$✔️
 -$V(151)=165$✔️
