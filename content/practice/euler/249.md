[欧拉项目问题 249](https://projecteuler.net/problem=249)

 ## 解决方案

 **答案：**`9275262564250418`让$$S=\{2,3,5,\dots,4999\}$$是下面所有素数的集合$5000$。 我们必须计算的子集$S$其元素和本身是素数，并返回最后一个$16$数字。 

---

 # 数学分析

 我们正在计算具有指定总和属性的子集，因此这从根本上来说是一个**子集和计数**问题。 

---

 ## 1. 重新表述问题

 对于每个子集$A\subseteq S$， 定义$$\sigma(A)=\sum_{p\in A} p.$$我们想要子集的数量使得$\sigma(A)$是素数。 

如果我们定义$$f(n)=\#\{A\subseteq S:\sigma(A)=n\},$$那么所需的数量是$$\sum_{\substack{n\text{ prime}}} f(n).$$所以真正的任务是：

 > 计算有多少子集达到每个可能的总和。 

---

 ## 2. 生成函数观点

 每个素数$p\in S$可以：

 - 从子集中排除，
 - 或仅包含一次。 

因此每个质数贡献一个因子$$(1+x^p).$$因此生成函数是$$F(x)=\prod_{p<5000}(1+x^p).$$扩展此产品：$$F(x)=\sum_{n\ge0} f(n)x^n,$$在哪里$f(n)$正是子集的数量总和为$n$。 

于是系数提取问题就变成了：$$\text{Answer}=\sum_{\substack{n\text{ prime}}}[x^n]F(x).$$---

 ## 3.动态规划推导

 我们不会对多项式进行符号展开。 相反，我们迭代地计算系数。 

让$$dp[s]$$表示处理后的素数的子集的数量，其总和等于$s$。 

最初：$$dp[0]=1$$因为空子集有和$0$。 

现在处理一个新的素数$p$。 

每个旧的子集和$s$创建一个新的子集和$s+p$。 

因此：$$dp[s+p] \mathrel{+}= dp[s].$$为了避免多次重复使用相同的素数，我们**向下**迭代求和：```python
for s from MAX-p down to 0:
    dp[s+p] += dp[s]
```这是标准 0/1 子集 DP。 

---

 ## 4. 大小限制

 有$669$下面的素数$5000$。 

最大可能的子集和是$$\sum_{p<5000} p = 1,548,136.$$所以DP数组只需要大约大小$1.55\times10^6$，这是完全可行的。 

子集的数量是天文数字（$2^{669}$），但我们只需要最后一个$16$数字，所以在整个计算过程中我们减少模数$$10^{16}.$$---

 # Python 实现```python
import math
import numpy as np

MOD = 10**16

# ------------------------------------------------------------
# Step 1: Generate all primes below 5000
# ------------------------------------------------------------

n = 5000

is_prime = np.ones(n, dtype=bool)
is_prime[:2] = False

for i in range(2, math.isqrt(n - 1) + 1):
    if is_prime[i]:
        is_prime[i * i:n:i] = False

primes = np.nonzero(is_prime)[0]

# ------------------------------------------------------------
# Step 2: Subset-sum DP
# dp[s] = number of subsets with sum s
# ------------------------------------------------------------

max_sum = int(primes.sum())

dp = np.zeros(max_sum + 1, dtype=np.int64)
dp[0] = 1

MOD64 = np.int64(MOD)

for p in primes:
    p = int(p)

    # Vectorized backward-style update:
    # dp[p:] += dp[:-p]
    dp[p:] = (dp[p:] + dp[:-p]) % MOD64

# ------------------------------------------------------------
# Step 3: Sieve primes up to max_sum
# ------------------------------------------------------------

prime_sum = np.ones(max_sum + 1, dtype=bool)
prime_sum[:2] = False

for i in range(2, math.isqrt(max_sum) + 1):
    if prime_sum[i]:
        prime_sum[i * i:max_sum + 1:i] = False

# ------------------------------------------------------------
# Step 4: Add counts for prime sums
# ------------------------------------------------------------

answer = int(dp[prime_sum].sum() % MOD)

print(answer)
```---

```提取下面所有素数$5000$。

 ## DP初始化```python
dp[0] = 1
```恰好有一个子集（空子集）的和$0$。 

---

 ## DP 转换```python
dp[p:] = (dp[p:] + dp[:-p]) % MOD64
```该向量化操作实现：$$dp[s+p] \leftarrow dp[s+p] + dp[s]$$对于每一个$s$。 

从概念上讲：

 - 保留现有子集，
 - 每个现有子集都可以通过包括来扩展$p$。

 ## 素和筛

 我们再次使用埃拉托色尼筛法，现在达到最大可能的子集和。

 ## 最终积累```python
answer = int(dp[prime_sum].sum() % MOD)
