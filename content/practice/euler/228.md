[欧拉项目问题 228](https://projecteuler.net/problem=228)

 ## 解决方案

 **答案：**`86226`让多边形的边向外法线方向确定其边。 

关于凸多边形的 Minkowski 和的标准事实是：

 > 的边缘方向（等效于向外法线方向）的集合
 >
 >$P+Q$是边缘方向的并集$P$和$Q$。 

因此，问题归结为计算出现在其中的不同边缘方向$$S_{1864},S_{1865},\dots,S_{1909}.$$---

 # 1. 几何$S_n$的顶点$S_n$是$$v_k=\left(\cos\frac{(2k-1)\pi}{n},\, \sin\frac{(2k-1)\pi}{n}\right).$$它们围绕单位圆等距分布，旋转$\pi/n$。 

相邻顶点成角度$$\frac{(2k-1)\pi}{n},\qquad \frac{(2k+1)\pi}{n}.$$它们之间的边有中点方向$$\frac{2k\pi}{n}.$$因此，向外的法线方向$n$边正好是$$\frac{2k\pi}{n},\qquad k=0,1,\dots,n-1.$$所以$S_n$贡献方向$$\left\{\frac{k}{n}\pmod 1\right\}.$$---

 # 2. 闵可夫斯基和中的不同方向

 两个方向重合当且仅当$$\frac{k_1}{n_1}\equiv \frac{k_2}{n_2}\pmod 1.$$减少到最低项后，每个方向都唯一对应于减少的分数$$\frac{a}{d},\qquad \gcd(a,d)=1.$$这样的方向出现当且仅当$d\mid n$至少一个$n\in[1864,1909]$。 

对于每个分母$d$，正好有$\varphi(d)$用该分母减少分数。 

因此：

 \boxed{ \text{# 边} = \sum_{\substack{d\ge1\\ d\mid n\text{ 对于某些 }1864\le n\le1909}} \varphi(d) }

 哪里$\varphi$是欧拉的 totient 函数。 

---

 # 3.Python实现```python
from math import gcd

# Euler totient
def phi(n):
    result = n
    p = 2
    m = n

    while p * p <= m:
        if m % p == 0:
            while m % p == 0:
                m //= p
            result -= result // p
        p += 1

    if m > 1:
        result -= result // m

    return result

# Collect every divisor of numbers 1864..1909
divisors = set()

for n in range(1864, 1910):
    for d in range(1, int(n**0.5) + 1):
        if n % d == 0:
            divisors.add(d)
            divisors.add(n // d)

# Sum Euler totients
answer = sum(phi(d) for d in divisors)

print(answer)
```这打印：```python
86226
```---
