[项目欧拉问题 215](https://projecteuler.net/problem=215)

 ## 解决方案

 **答案：**`806844323190414`让$W(w,h)$表示宽度无裂缝墙的数量$w$和身高$h$。 

我们必须计算$W(32,10)$。 

关键的观察是：

 - 行完全由其内部垂直裂缝的位置决定。 
- 两行兼容，当且仅当它们不共享裂缝位置。 
- 这样问题就变成了：

 1.生成所有宽度有效的行$32$,
 2. 构建兼容性图，
 3. 计算该图中长度为 10 的路径。 

---

 # 步骤 1 — 表示一行

 砖块是$2\times1$和$3\times1$，水平放置。 

一排宽度$w$是以下任意组合$w$使用 2s 和 3s。 

宽度示例$9$：

 -$2+2+2+3$-$3+3+3$-$2+3+2+2$等等

 对于每一行，记录砖之间的裂缝位置。 

例子：$$2+3+2+2$$有累计金额$$2,5,7,9$$忽略墙边$9$，裂纹集为$$\{2,5,7\}$$两行兼容当且仅当它们的裂纹集不相交。 

---

 # 步骤 2 — 可能的行数

 让$R(w)$是宽度的行数$w$。 

然后$$R(w)=R(w-2)+R(w-3)$$和：$$R(0)=1,\quad R(1)=0,\quad R(2)=1,\quad R(3)=1$$为了$w=32$，这会产生：$$R(32)=3329$$因此只有 3329 种行类型——对于图形方法来说足够小了。 

---

 # 步骤 3 — 兼容性图

 创建一个图表：

 - 每个节点 = 一行模式，
 - 如果没有裂缝对齐，节点之间的边缘。 

如果行$i$与行兼容$j$，那么它们可以连续堆叠。 

我们现在需要高度为 10 的堆叠数。 

这相当于计算行走的长度$9$在兼容性图中。 

---

 # 第 4 步 — 动态规划

 让：$$dp_k(i)$$是无裂缝墙体高度的数量$k$以行结尾$i$。 

初始化：$$dp_1(i)=1$$然后：$$dp_{k+1}(j)=\sum_{i\sim j} dp_k(i)$$在哪里$i\sim j$意味着兼容。 

最后：$$W(32,10)=\sum_i dp_{10}(i)$$---

 # Python 实现```python
from collections import defaultdict

WIDTH = 32
HEIGHT = 10

# ---------------------------------------------------------
# Generate all possible rows
# Each row is represented by a tuple of crack positions
# ---------------------------------------------------------

rows = []

def build(pos, cracks):
    """
    Recursively build rows of total width WIDTH.

    pos     = current filled width
    cracks  = crack positions so far
    """
    if pos == WIDTH:
        rows.append(tuple(cracks))
        return

    # place a 2-brick
    if pos + 2 <= WIDTH:
        new_pos = pos + 2
        build(
            new_pos,
            cracks + ([new_pos] if new_pos < WIDTH else [])
        )

    # place a 3-brick
    if pos + 3 <= WIDTH:
        new_pos = pos + 3
        build(
            new_pos,
            cracks + ([new_pos] if new_pos < WIDTH else [])
        )

build(0, [])

# ---------------------------------------------------------
# Build compatibility graph
# Two rows are compatible if they share no cracks
# ---------------------------------------------------------

n = len(rows)

compat = [[] for _ in range(n)]

crack_sets = [set(r) for r in rows]

for i in range(n):
    for j in range(i + 1, n):
        if crack_sets[i].isdisjoint(crack_sets[j]):
            compat[i].append(j)
            compat[j].append(i)

# ---------------------------------------------------------
# DP over wall height
# dp[i] = number of ways ending with row i
# ---------------------------------------------------------

dp = [1] * n   # height = 1

for _ in range(HEIGHT - 1):
    new_dp = [0] * n

    for i in range(n):
        for j in compat[i]:
            new_dp[j] += dp[i]

    dp = new_dp

answer = sum(dp)

print(answer)
```---

 # 代码演练

 ## 行生成

 递归函数：```python
build(pos, cracks)
```尝试添加：

 - 一块宽度为 2 的砖块，
 - 或宽度为 3 的砖块。 

每当我们精确地完成宽度 32 时，我们就会存储裂缝位置。 

例子：```python
2 + 3 + 2 + 2
```产生：```python
(2, 5, 7)
```---

 ## 兼容性测试

 我们将每个裂纹元组转换为一个集合。 

如果满足以下条件，则两行兼容：```python
setA.isdisjoint(setB)
```意味着没有裂缝重合。 

---

 ## 动态规划

 最初每一行都可以是第一层：```python
dp = [1] * n
```对于每个附加层：```python
new_dp[j] += dp[i]
```每当行$i$和$j$是兼容的。 

经过 10 层后，将所有可能性相加即可得出答案。
