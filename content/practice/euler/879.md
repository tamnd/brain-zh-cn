[欧拉项目问题 879](https://projecteuler.net/problem=879)

 ## 解决方案

 **答案：**`4350069824940`设网格点为格点$(x,y)$和$0 \le x,y < n$。 

密码是屏幕解释跳过的中间点后的_触摸点的实际序列_。 

关键的微妙之处在于：

 - 如果从$A$到$B$通过未使用的中间点，这些点会自动插入到序列中。 
- 因此，在_最终解释的密码_中，每对连续的点必须彼此“可见”：段上它们之间严格不能有未使用的格点。 

所以我们应该直接计算解释的序列。 

---

 # 1.数学分析

 假设我们现在处于这个点$P$，已经使用的点的集合是$S$。 

我们可能会移动到一个未使用的点旁边$Q$**当且仅当**每个格点严格位于$P$和$Q$已经在$S$。 

---

 ## 线段上的中间格点

 让$$P=(x_1,y_1), \qquad Q=(x_2,y_2)$$并定义$$dx=x_2-x_1,\qquad dy=y_2-y_1.$$沿直线的相等子线段的数量为$$g=\gcd(|dx|,|dy|).$$- 如果$g=1$，没有中间格点。 
- 如果$g>1$，中间格点是$$P + k\left(\frac{dx}{g},\frac{dy}{g}\right), \qquad k=1,2,\dots,g-1.$$这些正是我们在跳转之前必须使用的点$P$到$Q$。 

---

 # 2.动态规划

 我们使用DFS+记忆。 

状态：$$(\text{mask},\text{last})$$在哪里

-`mask`= 使用点的位掩码，
 -`last`= 当前端点。 

定义：$$f(\text{mask},\text{last})$$= 有效继续的数量，包括立即停止的选项。 

过渡：

 对于每个未使用的点$q$,

 - 如果之间的所有中间点`last`和`q`已经使用过，
 - 那么我们可以扩展到$$f(\text{mask}\cup\{q\},q).$$因此$$f(mask,last) = 1 + \sum_{\text{valid } q} f(mask\cup\{q\},q).$$这`1`计数停止在当前序列。 

最后，从每个起点开始，减去长度为 1 的密码。 

---

 # 3.Python实现```python
from functools import lru_cache
from math import gcd

def count_passwords(n):
    # Enumerate grid points
    points = [(x, y) for x in range(n) for y in range(n)]
    index = {p: i for i, p in enumerate(points)}

    N = n * n

    # between[a][b] = bitmask of lattice points strictly
    # between point a and point b
    between = [[0] * N for _ in range(N)]

    for a, (x1, y1) in enumerate(points):
        for b, (x2, y2) in enumerate(points):

            if a == b:
                continue

            dx = x2 - x1
            dy = y2 - y1

            g = gcd(abs(dx), abs(dy))

            # If g > 1, there are intermediate lattice points
            if g > 1:
                step_x = dx // g
                step_y = dy // g

                mask = 0

                for k in range(1, g):
                    p = (x1 + k * step_x,
                         y1 + k * step_y)
                    mask |= 1 << index[p]

                between[a][b] = mask

    FULL = (1 << N) - 1

    @lru_cache(None)
    def dfs(mask, last):
        """
        Number of valid continuations from this state,
        including the option to stop immediately.
        """
        total = 1

        unused = FULL ^ mask

        while unused:
            bit = unused & -unused
            q = bit.bit_length() - 1

            # Valid iff all intermediate points are already used
            if between[last][q] & ~mask == 0:
                total += dfs(mask | bit, q)

            unused ^= bit

        return total

    ans = 0

    # Start from every initial point
    for s in range(N):
        ans += dfs(1 << s, s) - 1   # remove length-1 password

    return ans

# Verification against the problem statement
print(count_passwords(3))   # 389488

# Required answer
print(count_passwords(4))
```---

points = [(x, y) for x in range(n) for y in range(n)]
```创建所有晶格点。

 ## 计算中间点

 对于每一个订购的对$(A,B)$，我们计算：```python
g = gcd(abs(dx), abs(dy))
```如果$g>1$，线段上有格点。 

我们将所有此类中间点作为位掩码存储在：```python
between[a][b]
```---

 ## DFS状态```python
dfs(mask, last)
```意思是：

 - 我们已经使用了中的积分`mask`,
 - 当前手指位置是`last`。 

---

 ## 有效移动测试```python
if between[last][q] & ~mask == 0:
```这会检查每个中间点是否已被使用。 

这完全符合触摸屏规则。
