[欧拉项目问题 14](https://projecteuler.net/problem=14)

 ## 解决方案

 **答案：**`837799`我们求起始数$n < 1{,}000{,}000$生成最长的 Collat​​z 链。 

对于每个整数：

 - 如果$n$是偶数：$n \to n/2$- 如果$n$是奇数：$n \to 3n+1$关键的优化是**记忆**：一旦知道数字的链长度，就可以重复使用它，而不是重复重新计算整个序列。 

例如：$$13 \to 40 \to 20 \to 10 \to 5 \to 16 \to 8 \to 4 \to 2 \to 1$$有$10$条款。 

一个干净的 Python 解决方案：```python
def collatz_length(n, cache):
    if n in cache:
        return cache[n]

    if n % 2 == 0:
        length = 1 + collatz_length(n // 2, cache)
    else:
        length = 1 + collatz_length(3 * n + 1, cache)

    cache[n] = length
    return length

cache = {1: 1}

best_n = 1
best_len = 1

for n in range(1, 1_000_000):
    length = collatz_length(n, cache)

    if length > best_len:
        best_len = length
        best_n = n

print(best_n)
```追踪已知结果：

 -$13$给出长度$10$- 随着搜索的进行，会出现更大的记录
 - 低于 100 万的最大链出现在：$$837799$$链长为$525$。 

**答案：837799**
