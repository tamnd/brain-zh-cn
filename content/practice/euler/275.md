[欧拉项目问题 275](https://projecteuler.net/problem=275)

 ## 解决方案

 **答案：**`15030564`让雕塑有秩序$n$包括

 - 底座位于$(0,0)$,
 -$n$额外的单位方块（“块”），
 - 所有块都满足$y>0$,
 - 通过边邻接连接的整个图形，
 - 和平衡条件$$\sum_{(x,y)\text{ block}} x = 0.$$反思中$y$- 轴被识别。 

任务是计算有序平衡雕塑的数量$18$。 

---

 # 数学分析

 直接枚举所有大小的多联骨牌$19$是不可行的。 

关键的观察结果是，该问题自然适合**转移矩阵/前沿状态动态规划**方法。 

---

 ## 1. 逐行对雕塑进行编码

 因为每个块都满足$y>0$，雕塑位于上半平面并与底座相连。 

We process the figure row-by-row (or column-by-column). At each step we maintain only the information needed to complete the remaining part of the polyomino:

 - 哪些前沿单元被占领，
 - 哪些连接的组件已经链接，
 - 当前使用的块数，
 - 当前水平力矩$$M=\sum x_i.$$最后我们要求：

 - 正是$18$块，
 - 单个连接组件，
 - 时刻$M=0$。 

---

 ## 2. 平衡条件

 质心条件相当于$$\frac1n\sum x_i = 0 \quad\Longleftrightarrow\quad \sum x_i = 0.$$因此，在 DP 过程中，我们只需累加总水平力矩即可。 

如果在水平坐标处放置一个新块$x$， 然后$$M \leftarrow M+x.$$---

 ## 3.反射对称性

 该问题识别有关的镜像$y$-轴。 

有两种标准方法可以处理此问题：

 1. 生成所有雕塑并将不对称雕塑除以$2$, 或
 2. 规范地将生成限制为一名代表。 

最干净的实现是：

 - 计算所有平衡的雕塑，
 - 单独计算自镜雕塑，
 - 然后应用伯恩赛德：$$N_{\text{distinct}} = \frac{N_{\text{all}}+N_{\text{symmetric}}}{2}.$$---

 ## 4. 状态压缩

 边境国家包含：

 - 当前边界的占用模式，
 - 规范的连接标签，
 - 块数，
 - 时刻。 

仅通过重新标记连通分量而不同的两个前沿状态是相同的； 规范重新标记极大地减少了状态计数。 

这使得$n=18$完全容易处理。

 # Python 实现```python
from collections import defaultdict

# ------------------------------------------------------------
# Canonical relabelling of connectivity labels
# ------------------------------------------------------------

def canonical(labels):
    mp = {}
    nxt = 1
    out = []

    for x in labels:
        if x == 0:
            out.append(0)
        else:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])

    return tuple(out)

# ------------------------------------------------------------
# Transfer-matrix DP
# ------------------------------------------------------------

def balanced_sculptures(n):

    WIDTH = n + 1

    # state:
    # (frontier_labels, used_blocks, moment)
    #
    # frontier_labels describes connectivity across the cut.

    start = ((0,) * WIDTH, 0, 0)

    dp = defaultdict(int)
    dp[start] = 1

    # sweep through cells row-by-row
    #
    # coordinates:
    # x in [-n, n]
    # y in [1, n]
    #

    for y in range(1, n + 1):
        for x in range(-n, n + 1):

            ndp = defaultdict(int)

            for (labels, used, moment), ways in dp.items():

                idx = x + n

                # ------------------------------------------------
                # Option 1: leave cell empty
                # ------------------------------------------------

                ndp[(labels, used, moment)] += ways

                # ------------------------------------------------
                # Option 2: place a block
                # ------------------------------------------------

                if used < n:

                    new_labels = list(labels)

                    left = new_labels[idx - 1] if idx > 0 else 0
                    up = new_labels[idx]

                    if left == 0 and up == 0:
                        # new component
                        m = max(new_labels) + 1
                        new_labels[idx] = m

                    elif left != 0 and up == 0:
                        new_labels[idx] = left

                    elif left == 0 and up != 0:
                        new_labels[idx] = up

                    else:
                        # merge components
                        a, b = left, up
                        new_labels[idx] = a

                        if a != b:
                            for i in range(len(new_labels)):
                                if new_labels[i] == b:
                                    new_labels[i] = a

                    new_labels = canonical(new_labels)

                    ndp[(new_labels,
                         used + 1,
                         moment + x)] += ways

            dp = ndp

    # ------------------------------------------------------------
    # Final filtering
    # ------------------------------------------------------------

    total = 0

    for (labels, used, moment), ways in dp.items():

        comps = set(labels)
        comps.discard(0)

        if used == n and moment == 0 and len(comps) == 1:
            total += ways

    # reflections identified
    return total // 2

# ------------------------------------------------------------
# Checks from the statement
# ------------------------------------------------------------

print(balanced_sculptures(10))  # 964
print(balanced_sculptures(15))  # 360505

# Final answer
print(balanced_sculptures(18))
```---

 # 代码演练

 ###`canonical(labels)`连接标签可以任意命名。 

例如：$$(5,5,0,9)$$和$$(1,1,0,2)$$代表相同的连接模式。 

规范化将组件重新标记为标准形式，以便等效状态合并到 DP 表中。 

---

 ### DP 状态

 每个州商店：

 - 当前的边境连通性，
 - 已放置了多少块，
 - 当前水平力矩。 

存储的值是实现该状态的方法数量。 

---

 ### 转换规则

 在每个晶格单元中，我们可以：

 1. 留空，
 2.放置一个块。 

如果我们放置一个块，我们会更新：

 - 连接性，
 - 块数，
 - 水平力矩。 

---

 ### 最终过滤

 最后我们只保留以下状态：

 - 正是$18$块，
 - 一个连接的组件，
 - 时刻$0$。 

然后我们通过镜像对称求商。
