[项目欧拉问题 101](https://projecteuler.net/problem=101)

 ## 解决方案

 **答案：**`37076114526`让$$u_n = 1-n+n^2-n^3+\cdots-n^9+n^{10}.$$我们被要求计算从最优次数多项式 (OP) 获得的 FIT 之和（“第一个不正确项”）$k-1$拟合第一个$k$序列项，对于$k=1,\dots,10$。 

---

 # 第 1 步 — 理解数学

 该序列由 10 次多项式生成$$u(n)=\sum_{i=0}^{10}(-1)^i n^i.$$我们被赋予了第一个$k$价值观$$u(1),u(2),\dots,u(k),$$并构造唯一多项式$P_k(n)$最多学位$k-1$对它们进行插值。 

该多项式称为“最优多项式”：$$\operatorname{OP}(k,n)=P_k(n).$$因为真实的生成函数有度数$10$：

- 为了$k<11$,$P_k(n)\neq u(n)$,
 - 因此第一个不匹配发生在$n=k+1$,
 - 适合度是$$P_k(k+1).$$我们必须计算$$\sum_{k=1}^{10} P_k(k+1).$$---

 # 步骤 2 — 计算序列值

 首先评价$u(n)$为了$n=1,\dots,11$。 

一个有用的简化是有限几何级数恒等式：$$1-n+n^2-\cdots+n^{10} = \frac{1+n^{11}}{1+n}.$$的确，$$\sum_{i=0}^{10}(-n)^i = \frac{1-(-n)^{11}}{1-(-n)} = \frac{1+n^{11}}{1+n}.$$所以：$$u(n)=\frac{n^{11}+1}{n+1}.$$第一个值是：$$\begin{aligned} u(1)&=1\\ u(2)&=683\\ u(3)&=44287\\ u(4)&=838861\\ u(5)&=8138021\\ u(6)&=51828151\\ u(7)&=247165843\\ u(8)&=954437177\\ u(9)&=3138105961\\ u(10)&=9090909091. \end{aligned}$$---

 # 步骤 3 — 插值思想

 对于每个$k$，我们插值一个次数多项式$k-1$通过第一个$k$点：$$(1,u_1),\dots,(k,u_k).$$最简洁的公式是拉格朗日插值：$$P_k(x)= \sum_{i=1}^{k} u_i \prod_{\substack{1\le j\le k\\j\ne i}} \frac{x-j}{i-j}.$$那么 FIT 是$$P_k(k+1).$$我们将这些求和为$k=1,\dots,10$。 

---

 # 第 4 步 — Python 实现```python
from fractions import Fraction

# True generating function
def u(n):
    return sum(((-1) ** i) * (n ** i) for i in range(11))

# Lagrange interpolation evaluated at x
def interpolate(xs, ys, x):
    total = Fraction(0, 1)

    for i in range(len(xs)):
        term = Fraction(ys[i], 1)

        for j in range(len(xs)):
            if i != j:
                term *= Fraction(x - xs[j], xs[i] - xs[j])

        total += term

    return total

answer = 0

# Compute FITs for k = 1..10
for k in range(1, 11):

    xs = list(range(1, k + 1))
    ys = [u(n) for n in xs]

    # First incorrect term occurs at n = k+1
    fit = interpolate(xs, ys, k + 1)

    answer += fit

print(answer)
```---

 ##`interpolate(xs, ys, x)`使用精确有理算术 (`Fraction`）以避免浮点错误。 

对于每个插值基础多项式：```python
term *= Fraction(x - xs[j], xs[i] - xs[j])
```这构造了$$\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}.$$对所有基本项求和给出了在以下位置评估的唯一插值多项式$x$。
