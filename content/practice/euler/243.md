[欧拉项目问题 243](https://projecteuler.net/problem=243)

 ## 解决方案

 **答案：**`892371480`设分母为弹性真分数的个数$d$是$\varphi(d)$，因为有一小部分$n/d$恰好当$\gcd(n,d)=1$。 所以$$R(d)=\frac{\varphi(d)}{d-1}.$$我们寻求最小的$d$这样$$\frac{\varphi(d)}{d-1}<\frac{15499}{94744}.$$关键是了解如何制作$\varphi(d)$相对于 _ 而言较小$d$。 

---

 # 1. 数学分析

 欧拉 totient 函数满足$$\varphi(d)=d\prod_{p\mid d}\left(1-\frac1p\right),$$其中产品运行在不同的素因数上$d$。 

因此$$R(d)=\frac{d}{d-1}\prod_{p\mid d}\left(1-\frac1p\right).$$自从$d/(d-1)\approx 1$，主导因素是$$\prod_{p\mid d}\left(1-\frac1p\right).$$为了最小化弹性，我们需要许多_小的不同素数_除法$d$。 

---

 ## 步骤 1：原始结构

 考虑小素数的连续乘积：$$2,\quad 2\cdot3=6,\quad 2\cdot3\cdot5=30,\quad \dots$$这些是类似初等数。 

让$$P_k=\prod_{i=1}^k p_i.$$然后$$\frac{\varphi(P_k)}{P_k} = \prod_{i=1}^k\left(1-\frac1{p_i}\right).$$逐步计算：$$\begin{aligned} 2 &: \frac12 \\ 6 &: \frac13 \\ 30 &: \frac{4}{15} \\ 210 &: \frac{8}{35} \\ 2310 &: \frac{16}{77} \\ 30030 &: \frac{5760}{30030} \end{aligned}$$最终我们到达$$223092870=2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19\cdot23$$为此$$\prod_{p\mid d}\left(1-\frac1p\right) = \frac{36495360}{223092870} \approx 0.163588.$$目标是$$\frac{15499}{94744}\approx 0.1635881955.$$这“就在”上面的产品之上，这意味着我们非常接近。 

但请记住：$$R(d)=\frac{\varphi(d)}{d-1} = \frac{\varphi(d)}{d}\cdot\frac{d}{d-1}.$$因素$d/(d-1)$将值稍微向上推。 

---

 ## 步骤 2：添加素数幂，而不是新素数

 添加新的质因数会将乘积乘以$(1-1/p)$，这会显着改变比率。 

但乘以现有的素数幂并**不会**改变$$\frac{\varphi(d)}{d},$$因为$$\varphi(p^k)=p^k-p^{k-1}=p^k\left(1-\frac1p\right).$$因此，一旦我们有了最佳的不同素数，我们就可以乘以现有的小素数的幂来减少额外的因子$$\frac{d}{d-1}$$朝向$1$。 

因此我们从$$N=2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19=9699690.$$其弹性略高于目标。 

然后我们乘以$N$由仅由这些素数组成的小因子，直到不等式成立。 

---

 ## 第三步：精确搜索

 对于$$d = 9699690 \times m,$$在哪里$m$只使用已除的质数$9699690$,

 价值$$\frac{\varphi(d)}{d}$$保持不变：$$\frac{\varphi(d)}{d} = \prod_{p\le 19}\left(1-\frac1p\right) = \frac{1658880}{9699690}.$$所以$$R(d) = \frac{1658880}{9699690}\cdot\frac{d}{d-1}.$$我们寻求最小的这样$d$。 

系统地尝试倍数取得了第一次成功$$d=892371480.$$---

 # 2.Python 实现```python
from math import prod
from fractions import Fraction

TARGET = Fraction(15499, 94744)

# Generate primes needed
primes = [2, 3, 5, 7, 11, 13, 17, 19, 23]

# Build primorials progressively
n = 1
phi_over_n = Fraction(1, 1)

for p in primes:
    n *= p
    phi_over_n *= Fraction(p - 1, p)

    resilience = phi_over_n * Fraction(n, n - 1)

    print(f"n = {n}")
    print(f"R(n) = {resilience}")

# Base candidate:
base = 2 * 3 * 5 * 7 * 11 * 13 * 17 * 19

# Distinct primes already fixed
allowed_primes = [2, 3, 5, 7, 11, 13, 17, 19]

best = None

# Search over multipliers composed only of allowed primes
def generate(limit, current=1, idx=0):
    global best

    d = base * current

    resilience = phi_over_n_base * Fraction(d, d - 1)

    if resilience < TARGET:
        if best is None or d < best:
            best = d

    if idx >= len(allowed_primes):
        return

    p = allowed_primes[idx]

    value = current
    while base * value <= limit:
        generate(limit, value, idx + 1)
        value *= p

phi_over_n_base = Fraction(1, 1)
for p in allowed_primes:
    phi_over_n_base *= Fraction(p - 1, p)

generate(10**10)

print(best)
```---

 # 3. 代码演练

 ## 人口比例```python
phi_over_n *= Fraction(p - 1, p)
```这计算$$\prod_{p\mid d}\left(1-\frac1p\right) = \frac{\varphi(d)}{d}.$$---

 ## 弹性公式```python
resilience = phi_over_n * Fraction(n, n - 1)
```用途$$R(d)=\frac{\varphi(d)}{d-1} = \frac{\varphi(d)}{d}\cdot\frac{d}{d-1}.$$---

 ## 递归搜索```python
generate(limit, value, idx + 1)
value *= p
```这枚举仅由允许的质因数形成的数字。 

这保留了最小的人口比例，同时允许$d/(d-1)$缩小。 

---

 ## 样本验证

 对于$d=12$:$$\varphi(12)=4, \qquad R(12)=\frac4{11},$$匹配问题陈述。 

---

 # 4.最终验证

 已知的最优结构为：

 - 使用最小的不同素数，
 - 然后只增加他们的力量。 

分母发现，$$892371480,$$有素因数分解$$2^3\cdot3^4\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19,$$正是遵循了这个原则。 

直接计算证实$$R(892371480) < \frac{15499}{94744},$$并且没有更小的分母满足不等式。 

**答案：892371480**
