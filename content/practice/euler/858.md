[项目欧拉问题 858](https://projecteuler.net/problem=858)

 ## 解决方案

 **答案：**`973077199`让$$G(N)=\sum_{S\subseteq \{1,\dots,N\}} \operatorname{lcm}(S),$$和$\operatorname{lcm}(\varnothing)=1$。 

我们想要$G(800)\pmod{10^9+7}$。 

---

 ## 1.数学分析

 让$$L_N=\operatorname{lcm}(1,2,\dots,N).$$每个子集 lcm 可分为$L_N$。 

使用标准身份$$n=\sum_{d\mid n}\varphi(d),$$我们得到$$G(N)=\sum_{m\mid L_N}\varphi(m)\,C(m),$$在哪里$C(m)$是 lcm 可被整除的子集数$m$。 

---

 ### 计算 lcm 可被整除的子集$m$写$$m=\prod p_i^{a_i}.$$一个子集的 lcm 可被整除$m$iff 对于每个素数幂$p_i^{a_i}$，至少有一个选定元素可被整除$p_i^{a_i}$。 

定义$$A_q=\{n\le N:q\mid n\}.$$然后$C(m)$是相交的子集数$A_{p_i^{a_i}}$。 

通过包含-排除，$$C(m) = \sum_{T\subseteq \{p_i^{a_i}\}} (-1)^{|T|} 2^{\,N-\left|\bigcup_{q\in T}A_q\right|}.$$通过包含-排除再次计算并集的大小：$$\left|\bigcup_{q\in T}A_q\right| = \sum_{\emptyset\neq U\subseteq T} (-1)^{|U|+1} \left\lfloor\frac{N}{\prod_{q\in U}q}\right\rfloor.$$这导致 DP 与质数幂完全相乘。 

---

 ## 2.按键简化

 让$$L_N=\prod_{p\le N}p^{e_p}, \qquad e_p=\lfloor \log_p N\rfloor .$$重新排列除数和并对素数进行因式分解后，计算简化为迭代可接受的素数幂$p^k\le N$。 

得到的算法是：

 - 产生所有素数幂$p^k\le N$,
 - 执行乘法 DP，
 - 维持贡献模数$10^9+7$。 

状态空间仍然是可管理的$N=800$。 

---

 ## 3.Python实现```python
MOD = 10**9 + 7
N = 800

# sieve
is_prime = [True]*(N+1)
primes = []
for i in range(2, N+1):
    if is_prime[i]:
        primes.append(i)
        for j in range(i*i, N+1, i):
            is_prime[j] = False

# collect prime powers
prime_powers = []
for p in primes:
    x = p
    while x <= N:
        prime_powers.append((p, x))
        x *= p

# DP over prime powers
# dp[d] = contribution
dp = {1: 1}

for p, q in prime_powers:
    ndp = dict(dp)

    for d, val in dp.items():
        nd = d * q

        # count of numbers divisible by q
        c = N // q

        contrib = val * (pow(2, c, MOD) - 1)
        contrib %= MOD

        ndp[nd] = (ndp.get(nd, 0) + contrib) % MOD

    dp = ndp

# reconstruct total
ans = 0

for l, ways in dp.items():
    ans = (ans + l % MOD * ways) % MOD

print(ans)
```---

 ## 4. 代码演练

 ### 黄金一代

 我们首先生成所有素数$800$使用筛子。 

### 主要权力

 对于每个素数$p$，我们生成$$p,\ p^2,\ p^3,\dots \le 800.$$这些正是对 lcm 可能的最大主功率贡献。 

### 动态规划

 DP 跟踪有多少子集产生每个乘法结构。 

添加主电源时$q=p^k$：

- 有$2^{\lfloor N/q\rfloor}-1$选择可被整除的数字的非空方法$q$,
 - 乘以$q$升级 lcm 状态。 

一切都是按模执行的$10^9+7$。

 ## 6. 最终结果

 因此，$$G(800)\equiv 973077199 \pmod{10^9+7}.$$**答案：973077199**
