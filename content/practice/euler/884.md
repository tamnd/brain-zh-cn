 ## 解决方案

 **答案：**`1105985795684653500`让$$D(n)=\text{number of greedy cube-subtractions needed to reduce }n\text{ to }0.$$例如，$$100\to 36\to 9\to 1\to 0$$所以$D(100)=4$。 

我们必须计算$$S(N)=\sum_{1\le n<N} D(n)$$为了$$N=10^{17}.$$---

 # 1.数学分析

 ## 核心观察

 假设$$m^3 \le n < (m+1)^3.$$然后贪心算法先减去$m^3$， 所以$$D(n)=1+D(n-m^3).$$写$$n=m^3+r,\qquad 0\le r<(m+1)^3-m^3.$$然后$$D(m^3+r)=1+D(r).$$这是关键的递归结构。 

---

 # 重复执行$S(N)$让$$N=m^3+r,\qquad 0\le r<(m+1)^3-m^3.$$然后$$S(N) = \sum_{n=1}^{m^3-1}D(n) + \sum_{t=0}^{r-1}D(m^3+t).$$使用$D(m^3+t)=1+D(t)$,$$\sum_{t=0}^{r-1}D(m^3+t) = \sum_{t=0}^{r-1}(1+D(t)) = r+S(r),$$因为$D(0)=0$。 

定义$$C(m):=S(m^3).$$然后我们得到$$\boxed{S(m^3+r)=C(m)+r+S(r)}.$$那么一次$C(m)$已知，评估$S(N)$变得非常快。 

---

 # 重复执行$C(m)$我们计算整个区块的贡献$$[m^3,(m+1)^3).$$它的长度是$$L=(m+1)^3-m^3=3m^2+3m+1.$$对于该块中的每个数字，$$D(m^3+t)=1+D(t).$$因此$$\sum_{n=m^3}^{(m+1)^3-1}D(n) = L+S(L).$$所以$$C(m+1)-C(m)=L+S(L),$$IE。$$\boxed{ C(m+1)=C(m)+(3m^2+3m+1)+S(3m^2+3m+1) }.$$基本情况：$$C(1)=S(1)=0.$$---

 # 复杂度

 对于$N=10^{17}$,$$\lfloor \sqrt[3]{10^{17}}\rfloor \approx 464158.$$所以我们只需要大约$4.6\times10^5$预先计算的值。 

递归深度为$S(N)$很小，因为每个递归调用都会替换$N$大约由$3N^{2/3}$。 

在 Python 中，这可以轻松地在不到一秒的时间内运行。 

---

 # 2.Python实现```python
from functools import cache

# ------------------------------------------------------------
# Integer cube root:
# returns floor(n^(1/3))
# ------------------------------------------------------------
def icbrt(n: int) -> int:
    lo, hi = 0, int(n ** (1 / 3)) + 3

    while lo < hi:
        mid = (lo + hi + 1) // 2

        if mid ** 3 <= n:
            lo = mid
        else:
            hi = mid - 1

    return lo

TARGET = 10**17

# Maximum cube root needed
MAX_M = icbrt(TARGET - 1) + 1

# ------------------------------------------------------------
# C[m] = S(m^3)
# ------------------------------------------------------------
C = [0] * (MAX_M + 1)

# ------------------------------------------------------------
# Recursive computation of S(N)
# ------------------------------------------------------------
@cache
def S(N: int) -> int:
    if N <= 1:
        return 0

    m = icbrt(N - 1)
    cube = m ** 3

    # Exact cube boundary
    if N == cube:
        return C[m]

    r = N - cube

    # S(m^3 + r) = C(m) + r + S(r)
    return C[m] + r + S(r)

# ------------------------------------------------------------
# Build C iteratively
# ------------------------------------------------------------
# C(1) = 0 already

for m in range(2, MAX_M + 1):

    mm = m - 1

    # Length of interval [mm^3, m^3)
    L = 3 * mm * mm + 3 * mm + 1

    # C(m) = C(m-1) + L + S(L)
    C[m] = C[mm] + L + S(L)

# Final answer
print(S(TARGET))
```---
