[欧拉项目 944 问题](https://projecteuler.net/problem=944)

 ## 解决方案

 **答案：**`1228599511`让$E \subseteq \{1,2,\dots,n\}$。 一个元素$x\in E$有助于$\operatorname{sev}(E)$当且仅当 **另一个** 元素$E$可以整除$x$。 

对于固定$x$， 让$$m=\left\lfloor \frac{n}{x}\right\rfloor$$所以有$m-1$其他的倍数$x$在$\{1,\dots,n\}$。 

子集数量$E$在哪里$x$是 elevisor 是：

 - 包括$x$,
 - 至少包括其中一项$m-1$其他倍数，
 - 所有剩余元素都是任意的。 

因此：$$N_x = 2^{\,n-m}\left(2^{m-1}-1\right) = 2^{n-1}-2^{n-m}$$所以$$S(n) = \sum_{x=1}^{n} x\left(2^{n-1}-2^{n-\lfloor n/x\rfloor}\right)$$重新排列可以更快地求和：$$S(n) = \sum_{d=2}^{n} 2^{n-d}\cdot \frac{\lfloor n/d\rfloor(\lfloor n/d\rfloor+1)}{2}$$这可以评估为$O(\sqrt n)$使用标准楼层划分间隔技巧：

 的值$\lfloor n/d\rfloor$间隔恒定。 

干净的 Python 实现：```python
import math

MOD = 1234567891
INV2 = (MOD + 1) // 2

def solve(n):
    D = math.isqrt(n)
    res = 0

    # Small d: direct
    p = pow(2, (n - 2) % (MOD - 1), MOD)

    for d in range(2, D + 1):
        q = n // d
        tri = (q * (q + 1) // 2) % MOD
        res += p * tri
        p = (p * INV2) % MOD

    res %= MOD

    # Large d grouped by equal floor(n/d)
    cache = {1: INV2}

    cur = D + 1
    pcur = pow(2, (n - cur) % (MOD - 1), MOD)

    for q in range(D - 1, 0, -1):
        R = n // q
        if R < cur:
            continue

        length = R - cur + 1

        if length not in cache:
            cache[length] = pow(INV2, length, MOD)

        ip = cache[length]

        tri = (q * (q + 1) // 2) % MOD
        interval_sum = (2 * pcur * (1 - ip)) % MOD

        res += interval_sum * tri
        pcur = (pcur * ip) % MOD
        cur = R + 1

    return res % MOD

print(solve(10**14))
```检查样品：$$S(10)=4927$$与问题陈述相匹配。
