[欧拉项目795问题](https://projecteuler.net/problem=795)

 ## 解决方案

 **答案：**`955892601606483`让$$g(n)=\sum_{i=1}^{n}(-1)^i\gcd(n,i^2).$$我们寻求$$G(N)=\sum_{n=1}^N g(n), \qquad G(12345678).$$---

 # 1.数学分析

 ## 步骤 1：使用 Euler 的 totient 恒等式扩展 gcd

 标准身份是$$\gcd(a,b)=\sum_{d\mid \gcd(a,b)}\varphi(d).$$所以，$$g(n) = \sum_{i=1}^n (-1)^i \sum_{\substack{d\mid n\\ d\mid i^2}} \varphi(d).$$交换求和顺序：$$g(n) = \sum_{d\mid n}\varphi(d) \sum_{\substack{1\le i\le n\\ d\mid i^2}} (-1)^i.$$定义$$S(n,d)=\sum_{\substack{1\le i\le n\\ d\mid i^2}}(-1)^i.$$然后$$g(n)=\sum_{d\mid n}\varphi(d)\,S(n,d).$$---

 ## 第 2 步：描述状况$d\mid i^2$写$$d=\prod p^{a_p}.$$然后$d\mid i^2$当且仅当$$p^{a_p}\mid i^2 \iff p^{\lceil a_p/2\rceil}\mid i.$$因此条件等价于$$q(d)\mid i,$$在哪里$$q(d)=\prod p^{\lceil a_p/2\rceil}.$$所以有效的$i$正好是$q(d)$。 

---

 ## 步骤 3：评估交替和

 ### 案例A：$q(d)$奇数

 那么的倍数为$q(d)$替代奇偶校验。 

- 如果$n$是偶数，偶数和奇数的倍数相等，所以$$S(n,d)=0.$$- 如果$n$是奇数，有一个额外的奇数项，给出$$S(n,d)=-1.$$因此对于奇数$n$,$$g(n) = -\sum_{d\mid n}\varphi(d) = -n.$$（使用$\sum_{d\mid n}\varphi(d)=n$）。 

---

 ### 情况 B：$q(d)$甚至

 那么每一个的倍数$q(d)$是偶数，所以每一项都有贡献$+1$。 

倍数的个数是$$\frac{n}{q(d)}$$（因为$q(d)\mid n$每当$d\mid n$）。 

因此$$S(n,d)=\frac{n}{q(d)}.$$这只发生在即使$d$。 

因此，对于即使$n$,$$g(n) = \sum_{\substack{d\mid n\\ d\text{ even}}} \varphi(d)\frac{n}{q(d)}.$$---

 # 2.求和得到$G(N)$奇数和偶数分开$n$。 

对于奇数$n$,$$g(n)=-n.$$奇数为止$N$总和为$$1+3+5+\cdots+(2m-1)=m^2, \quad m=\left\lfloor\frac{N+1}{2}\right\rfloor.$$所以奇怪的贡献是$$-\left\lfloor\frac{N+1}{2}\right\rfloor^2.$$现在处理均匀$n$:$$\sum_{\substack{n\le N\\ n\text{ even}}}g(n) = \sum_{d\text{ even}\le N} \varphi(d) \sum_{\substack{n\le N\\ d\mid n}} \frac{n}{q(d)}.$$写$n=dk$。 然后$$= \sum_{d\text{ even}\le N} \frac{\varphi(d)d}{q(d)} \sum_{k\le N/d}k.$$自从$$\sum_{k\le m}k=\frac{m(m+1)}2,$$我们得到$$G(N) = -\left\lfloor\frac{N+1}{2}\right\rfloor^2 + \sum_{d\text{ even}\le N} \frac{\varphi(d)d}{q(d)} \cdot \frac{m(m+1)}2,$$在哪里$$m=\left\lfloor\frac{N}{d}\right\rfloor.$$---

 # 3.乘法系数

 定义$$f(d)=\frac{\varphi(d)d}{q(d)}.$$这是乘法。 

对于主要力量$p^e$,$$q(p^e)=p^{\lceil e/2\rceil},$$所以$$f(p^e) = (p-1)p^{e-1} \cdot p^{e-\lceil e/2\rceil} = (p-1)p^{2e-1-\lceil e/2\rceil}.$$这允许线性筛计算$O(N)$。 

---

 # 4.Python实现```python
from array import array

N = 12345678

# f(n) = phi(n) * n / q(n)
# where q(p^e) = p^ceil(e/2)

f = array('Q', [0]) * (N + 1)
exp = array('B', [0]) * (N + 1)
pp  = array('I', [0]) * (N + 1)

primes = []
f[1] = 1

def local_value(p, e):
    # f(p^e) = (p-1) * p^(2e-1-ceil(e/2))
    return (p - 1) * (p ** (2 * e - 1 - ((e + 1) // 2)))

# Linear sieve
for i in range(2, N + 1):

    if pp[i] == 0:
        primes.append(i)
        pp[i] = i
        exp[i] = 1
        f[i] = local_value(i, 1)

    for p in primes:
        v = i * p

        if v > N:
            break

        if i % p == 0:
            # extend prime power
            pp[v] = pp[i] * p
            exp[v] = exp[i] + 1

            e = exp[v]

            new_local = local_value(p, e)
            old_local = local_value(p, e - 1)

            f[v] = (f[i] // old_local) * new_local
            break

        else:
            # new prime factor
            pp[v] = p
            exp[v] = 1
            f[v] = f[i] * local_value(p, 1)

# Odd contribution
m = (N + 1) // 2
G = -m * m

# Even divisor contribution
for d in range(2, N + 1, 2):
    t = N // d
    G += f[d] * t * (t + 1) // 2

print(G)
```---

 # 5. 代码演练

 ### 数组

 -`f[n]`商店$$f(n)=\frac{\varphi(n)n}{q(n)}.$$-`exp[n]`存储最小质因数的指数。 
-`pp[n]`存储相应的原功率。 

这是线性筛的标准结构。 

---

 ###`local_value(p,e)`实施$$f(p^e)=(p-1)p^{2e-1-\lceil e/2\rceil}.$$因为$f$是乘法的，每个值都可以由素数幂构建。 

---

 ### 最终总结

 所实现的公式正是$$G(N) = -\left\lfloor\frac{N+1}{2}\right\rfloor^2 + \sum_{d\text{ even}\le N} f(d)\cdot \frac{\lfloor N/d\rfloor(\lfloor N/d\rfloor+1)}2.$$---

它还重现：$$g(4)=6, \qquad g(1234)=1233.$$---
