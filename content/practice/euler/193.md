[项目欧拉问题 193](https://projecteuler.net/problem=193)

 ## 解决方案

 **答案：**`684465067343069`让$$N = 2^{50}.$$我们想要计算正整数$n < N$是 **squarefree**，意味着没有素数平方除法$n$。 

计算无平方数的经典方法是使用莫比乌斯函数和包含-排除。 

---

 # 1.数学分析

 如果一个数字可以被整除，那么它**不是**无平方数$p^2$对于一些素数$p$。 

因此，我们希望计算整数以避免所有素数平方整除性约束。 

关键身份是：$$Q(x)=\sum_{d=1}^{\lfloor \sqrt{x}\rfloor}\mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor,$$在哪里：

-$Q(x)$= 无平方整数的数量$\le x$,
 -$\mu(d)$是莫比乌斯函数。 

由于问题要求提供**下方的数字**$2^{50}$，我们需要$$Q(2^{50}-1).$$---

 ## 步骤 1 — 包含 - 排除

 定义：$$A_p = \{n : p^2 \mid n\}.$$我们想要不属于任何整数的计数$A_p$。 

通过包含-排除：$$Q(x) = x -\sum_p \left\lfloor \frac{x}{p^2}\right\rfloor +\sum_{p<q}\left\lfloor \frac{x}{p^2q^2}\right\rfloor -\cdots$$观察每一个 squarefree 产品$$d=p_1p_2\cdots p_k$$贡献$$(-1)^k\left\lfloor \frac{x}{d^2}\right\rfloor.$$该符号模式正是莫比乌斯函数：$$\mu(d)= \begin{cases} 1 & d=1\\ (-1)^k & d \text{ is product of } k \text{ distinct primes}\\ 0 & d \text{ divisible by a square} \end{cases}$$因此：$$Q(x)=\sum_{d\le \sqrt{x}} \mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor.$$---

 ## 第 2 步 — 申请$x=2^{50}-1$我们计算：$$\sum_{d=1}^{\lfloor\sqrt{2^{50}-1}\rfloor} \mu(d)\left\lfloor \frac{2^{50}-1}{d^2}\right\rfloor.$$自从$$\sqrt{2^{50}} = 2^{25}=33\,554\,432,$$求和只需要$d \le 33{,}554{,}431$。 

通过计算莫比乌斯函数的筛子，这很容易实现。 

---

 # 2.Python实现```python
from math import isqrt

# We want squarefree numbers below 2^50
N = 2**50 - 1

# Maximum d needed in the Möbius summation
limit = isqrt(N)

# Linear sieve for Möbius function
mu = [0] * (limit + 1)
mu[1] = 1

primes = []
is_composite = [False] * (limit + 1)

for i in range(2, limit + 1):

    if not is_composite[i]:
        primes.append(i)
        mu[i] = -1

    for p in primes:
        if i * p > limit:
            break

        is_composite[i * p] = True

        # p divides i -> square factor appears
        if i % p == 0:
            mu[i * p] = 0
            break
        else:
            mu[i * p] = -mu[i]

# Count squarefree numbers
answer = 0

for d in range(1, limit + 1):
    answer += mu[d] * (N // (d * d))

print(answer)
```---

 ## 莫比乌斯筛

 我们计算$\mu(d)$为所有人$d \le \sqrt N$。 

###素数检测```python
if not is_composite[i]:
    primes.append(i)
    mu[i] = -1
```素数具有莫比乌斯值$-1$。 

---

 ### 倍数

 如果$p \mid i$， 然后$i p$包含一个平方因子$p^2$， 所以：```python
mu[i * p] = 0
```否则：```python
mu[i * p] = -mu[i]
```因为添加一个不同的素数会翻转符号。

 ## 最终总结```python
answer += mu[d] * (N // (d * d))
```这直接评估$$\sum_d \mu(d)\left\lfloor\frac{N}{d^2}\right\rfloor.$$---

 # 4. 小型健全性检查

 对于$x=12$:

 无平方数是：$$1,2,3,5,6,7,10,11$$有$8$。 

使用公式：$$\begin{aligned} Q(12) &= \left\lfloor\frac{12}{1^2}\right\rfloor -\left\lfloor\frac{12}{2^2}\right\rfloor -\left\lfloor\frac{12}{3^2}\right\rfloor -\left\lfloor\frac{12}{5^2}\right\rfloor +\cdots \\ &=12-3-1=8. \end{aligned}$$正确的。
