[欧拉计划问题 130](https://projecteuler.net/problem=130)

 ## 解决方案

 **答案：**`149253`让$R(k)$表示重新单位$$R(k)=\frac{10^k-1}{9}=111\ldots1$$（和$k$的）。 对于任意整数$n$互质于$10$，存在一些$k$这样$$R(k)\equiv 0 \pmod n.$$定义$A(n)$成为_最小的_这样的$k$。 

我们寻求第一$25$**复合**整数$n$这样$$A(n)\mid (n-1),$$和$\gcd(n,10)=1$。 然后我们必须对它们求和。 

---

 # 1.数学分析

 关键的观察是：$$R(k)\equiv 0 \pmod n \iff \frac{10^k-1}{9}\equiv 0 \pmod n.$$自从$\gcd(n,10)=1$，这相当于$$10^k \equiv 1 \pmod{9n}$$（除了以下因素$3$，但是使用$9n$统一工作正常）。 

因此$A(n)$是乘法阶$10$模数$9n$：$$A(n)=\operatorname{ord}_{9n}(10).$$我们正在寻找复合材料$n$满意的$$n-1 \equiv 0 \pmod{A(n)}.$$---

 ## 素数的重要性质

 对于素数$p>5$,$$A(p)\mid p-1$$根据费马小定理，因为乘法阶数除以群的大小。 

该问题要求具有相同性质的罕见合数。 

这些与类伪素数行为有关。 

---

 # 2.高效算法

 我们测试整数$n$按递增顺序。 

条件：

 1.$n$复合材料
 2.$\gcd(n,10)=1$3.$(n-1)\bmod A(n)=0$计算挑战是评估$A(n)$。 

---

 ## 计算$A(n)$我们可以直接计算乘法阶：

 开始于$$x = 10 \bmod (9n)$$并反复乘以$10$：$$x \leftarrow (10x)\bmod (9n)$$直到$x=1$。 

步数为$A(n)$。 

这是足够有效的，因为所需的数量相对较小。 

---

 # 3.Python实现```python
from math import gcd

# Simple primality test
def is_prime(n):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2

    return True

# Compute A(n):
# the smallest k such that R(k) is divisible by n
def A(n):
    # modulus used for multiplicative order
    mod = 9 * n

    x = 10 % mod
    k = 1

    while x != 1:
        x = (x * 10) % mod
        k += 1

    return k

count = 0
total = 0
n = 1

while count < 25:
    n += 1

    # must be coprime to 10
    if gcd(n, 10) != 1:
        continue

    # only composite numbers
    if is_prime(n):
        continue

    an = A(n)

    if (n - 1) % an == 0:
        count += 1
        total += n
        print(count, n)

print("Answer =", total)
```---
