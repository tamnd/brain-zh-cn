[项目欧拉问题 71](https://projecteuler.net/problem=71)

 ## 解决方案

 **答案：**`428570`我们寻求紧邻左侧的约化真分数$$\frac37$$在所有带分母的分数中$d \le 1{,}000{,}000$。 

问题本质上是关于**法雷序列**和有理逼近。 

---

 # 数学分析

 我们想要最大的约简分数$$\frac nd < \frac37$$和$$d \le 1{,}000{,}000.$$同样，我们想要最接近的分数$\frac37$从下面。 

---

 ## 步骤 1：测量分数与$3/7$考虑：$$\frac37 - \frac nd.$$计算：$$\frac37 - \frac nd = \frac{3d-7n}{7d}.$$自从$\frac nd < \frac37$,$$3d - 7n > 0.$$因此最小化距离相当于最小化正整数$$3d - 7n.$$最小可能的正值是：$$3d - 7n = 1.$$所以最优分数必须满足$$3d - 7n = 1.$$重新排列：$$7n = 3d - 1,$$所以$$n = \frac{3d-1}{7}.$$所以$3d-1$必须能整除$7$。 

---

 ## 第二步：解决同余问题

 我们需要：$$3d \equiv 1 \pmod 7.$$的逆$3 \pmod 7$是$5$， 因为：$$3 \cdot 5 = 15 \equiv 1 \pmod 7.$$因此：$$d \equiv 5 \pmod 7.$$我们想要**最大**分母$d \le 1{,}000{,}000$满足这一点。 

计算：$$1{,}000{,}000 \bmod 7 = 1.$$所以最大的$d \equiv 5 \pmod 7$一百万以下的是：$$999{,}997.$$---

 ## 步骤 3：计算分子

 使用$$n = \frac{3d-1}{7},$$我们得到：$$n = \frac{3(999{,}997)-1}{7} = \frac{2{,}999{,}991-1}{7} = \frac{2{,}999{,}990}{7} = 428{,}570.$$因此分数是：$$\frac{428570}{999997}.$$查看：$$3(999997)-7(428570)=2999991-2999990=1,$$所以确实它紧邻$\frac37$。 

---

 # Python 实现```python
from math import gcd

LIMIT = 1_000_000

best_n = 0
best_d = 1

# For each denominator d, choose the largest n such that n/d < 3/7
for d in range(2, LIMIT + 1):

    # Largest integer strictly less than 3d/7
    n = (3 * d - 1) // 7

    # Fraction must be reduced
    if gcd(n, d) == 1:

        # Compare n/d with current best using cross multiplication
        if n * best_d > best_n * d:
            best_n = n
            best_d = d

print(best_n)
```---
