[欧拉项目 815 问题](https://projecteuler.net/problem=815)

 ## 解决方案

 **答案：**`54.12691621`让进程的状态描述为

 -$u$：尚未看到的值的数量，
 -$a$: 尺寸的堆数$1$,
 -$b$: 尺寸的堆数$2$,
 -$c$: 尺寸的堆数$3$。 

那么当前非空堆的数量是$$s=a+b+c.$$最初状态是$$(u,a,b,c)=(n,0,0,0).$$堆达到一定尺寸后就会消失$4$。 

---

 # 1.数学分析

 在状态$(u,a,b,c)$，剩下的牌是$$4u+3a+2b+c.$$确实：

 - 每个看不见的价值都有贡献$4$卡片、
 - 每个 size-1 堆贡献$3$剩余卡牌，
 - 每个 2 号桩都有贡献$2$,
 - 每个尺寸 3 堆都有贡献$1$。 

过渡是：

 ### 绘制一个新值

 概率$$\frac{4u}{4u+3a+2b+c}.$$状态变化：$$(u,a,b,c)\to(u-1,a+1,b,c).$$桩数增加$1$。 

---

 ### 扩展 1 号堆

 概率$$\frac{3a}{4u+3a+2b+c}.$$过渡：$$(u,a,b,c)\to(u,a-1,b+1,c).$$桩数不变。 

---

 ### 扩展 2 号堆

 概率$$\frac{2b}{4u+3a+2b+c}.$$过渡：$$(u,a,b,c)\to(u,a,b-1,c+1).$$桩数不变。 

---

 ### 完成 3 号堆

 概率$$\frac{c}{4u+3a+2b+c}.$$过渡：$$(u,a,b,c)\to(u,a,b,c-1).$$桩数减少$1$。 

---

 我们必须计算整个过程中预期的最大同时堆数。 

最简洁的方法是动态规划：$$(u,a,b,c,m),$$在哪里$m$是迄今为止看到的最大桩数。 

我们将概率传播到所有$4n$抽牌。 

最后，所有状态都$(0,0,0,0,m)$， 所以$$E(n)=\sum_m m\Pr(M=m).$$---

 # 2.Python实现```python
from collections import defaultdict

def expected_max_piles(n):
    # state = (u, a, b, c, m)
    # u = unseen values
    # a = piles of size 1
    # b = piles of size 2
    # c = piles of size 3
    # m = maximum number of piles seen so far

    dp = {(n, 0, 0, 0, 0): 1.0}

    # There are exactly 4n card draws
    for _ in range(4 * n):

        nxt = defaultdict(float)

        for (u, a, b, c, m), prob in dp.items():

            remaining = 4*u + 3*a + 2*b + c
            piles = a + b + c

            # Draw a new value
            if u:
                new_piles = piles + 1
                nxt[(u-1, a+1, b, c,
                     max(m, new_piles))] += prob * (4*u / remaining)

            # Extend a size-1 pile
            if a:
                nxt[(u, a-1, b+1, c, m)] += prob * (3*a / remaining)

            # Extend a size-2 pile
            if b:
                nxt[(u, a, b-1, c+1, m)] += prob * (2*b / remaining)

            # Complete a size-3 pile
            if c:
                nxt[(u, a, b, c-1, m)] += prob * (c / remaining)

        dp = nxt

    # Expected value of the maximum
    ans = 0.0

    for (u, a, b, c, m), prob in dp.items():
        ans += m * prob

    return ans

# Check the example
print(f"{expected_max_piles(2):.8f}")

# Compute E(60)
print(f"{expected_max_piles(60):.8f}")
```---

 # 3. 代码演练

 ## 初始化```python
dp = {(n, 0, 0, 0, 0): 1.0}
```最初：

 - 全部$n$价值观是看不见的，
 - 不存在桩，
 - 到目前为止最大堆数是$0$。 

---

 ## 状态转换

 对于每个状态，我们计算：```python
remaining = 4*u + 3*a + 2*b + c
```这是这副牌中剩余的牌数。 

然后我们根据四种可能的卡类型分配概率质量。 

---

 ## 跟踪最大值

 当创建新堆时：```python
new_piles = piles + 1
max(m, new_piles)
```更新运行最大值。 

---

 ## 最终期望

 毕竟$4n$卡片处理完毕，每条路径都结束了。 

我们计算：```python
ans += m * prob
```这正是$$E(M)=\sum_m m\,P(M=m).$$---

 # 4. 验证

 对于$n=2$，程序给出$$E(2)=1.97142857,$$匹配问题陈述中给出的值。 

为了$n=60$，计算稳定并产生略低于$60$，正如预期的那样。
