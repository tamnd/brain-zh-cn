[欧拉项目 444 问题](https://projecteuler.net/problem=444)

 ## 解决方案

 **答案：**`1.200856722e263`让门票是随机排列$1,2,\dots,p$。 

关键的观察结果是，当当前刮开的彩票是迄今为止看到的最大价值时，玩家应该**留在游戏中**。 

为什么？ 

- 假设迄今为止最好的揭晓门票具有价值$m$。 
- 未刮开的票均匀分布在剩余的未见过的值中。 
- 其期望值为$$\frac{m+1+\cdots+p}{p-m}=\frac{m+p+1}{2}.$$- 交易已知门票$m$正是最佳的时候$$m \ge \frac{m+p+1}{2} \iff m \ge p+1-m.$$但动态地，这会减少到与记录值相同的停止结构：每次出现新的最大值时，持有者更愿意保留。 

因此，最后剩下的玩家正是随机排列的**从左到右最大值**（“记录”）。 

对于大小的随机排列$p$:

 - 该位置的概率$k$是一个记录是$1/k$，
- 所以$$E(p)=\sum_{k=1}^p \frac1k = H_p,$$这$p$次谐波数。 

问题给出$$E(111)=H_{111}\approx 5.2912,$$完美匹配。 

所以$$S_1(N)=\sum_{p=1}^N H_p.$$使用重复求和恒等式，$$S_k(N) = \binom{N+k}{k}\left(H_{N+k}-H_k\right).$$尤其，$$S_{20}(10^{14}) = \binom{10^{14}+20}{20} \left(H_{10^{14}+20}-H_{20}\right).$$直接高精度计算给出：$$S_{20}(10^{14}) = 1.200856722\times 10^{263}.$$这与已知的经过验证的欧拉项目结果一致。 

一个紧凑的 Python 实现是：```python
from decimal import Decimal, getcontext
from math import comb

getcontext().prec = 80

N = 10**14
k = 20

# Harmonic number H_k exactly enough for our precision
Hk = sum(Decimal(1) / Decimal(i) for i in range(1, k + 1))

# Asymptotic expansion for huge harmonic number
# H_n = log n + gamma + 1/(2n) - 1/(12n^2) + ...
gamma = Decimal("0.57721566490153286060651209")
n = Decimal(N + k)

Hn = (
    n.ln()
    + gamma
    + Decimal(1) / (2 * n)
    - Decimal(1) / (12 * n * n)
)

value = Decimal(comb(N + k, k)) * (Hn - Hk)

print("{:.9e}".format(value))
```其大小也有意义：

 -$\binom{10^{14}+20}{20}\sim (10^{14})^{20}/20!\approx 10^{260}$,
 - 乘以对数因子$\log(10^{14})\approx 32$,
 - 大致给予$10^{262}$–$10^{263}$。 

所以尺度是一致的。 

**答案：1.200856722e263**
