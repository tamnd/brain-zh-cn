[欧拉项目问题 469](https://projecteuler.net/problem=469)

 ## 解决方案

 **答案：**`0.56766764161831`让$M_N$是进程停止时占用的椅子数量$N$椅子。 然后$$E(N)=\mathbb E\!\left[\frac{N-M_N}{N}\right] =1-\frac{\mathbb E[M_N]}{N}.$$所以任务是计算渐进预期占据密度。 

---

 # 1.数学分析

 ## 步骤一：将循环问题转化为线性问题

 首先研究**行**会更容易$n$椅子。 

定义：$$a_n=\text{expected number of occupied chairs on a line of } n \text{ chairs}.$$当第一位骑士选择椅子时$k$（$1\le k\le n$）：

- 椅子$k$被占用，
 - 椅子$k-1$和$k+1$成为禁止的，
 - 剩余的可用椅子分为两个独立的子问题：$$k-2 \quad\text{and}\quad n-k-1.$$所以，$$a_n = 1+\frac1n\sum_{k=1}^n\left(a_{k-2}+a_{n-k-1}\right),$$和$a_m=0$为了$m<0$。 

根据对称性，$$a_n = 1+\frac{2}{n}\sum_{i=0}^{n-2} a_i. \tag{1}$$初始值：$$a_0=0,\qquad a_1=1.$$---

 ## 第二步：生成函数

 定义$$A(x)=\sum_{n\ge0} a_n x^n.$$从(1)，$$n a_n = n+2\sum_{i=0}^{n-2} a_i.$$乘以$x^n$并总结$n\ge2$：$$\sum_{n\ge2} n a_n x^n = \sum_{n\ge2} n x^n + 2\sum_{n\ge2}\sum_{i=0}^{n-2} a_i x^n.$$使用标准生成函数恒等式：$$xA'(x)-x = \frac{x}{(1-x)^2}-x + \frac{2x^2}{1-x}A(x).$$因此$$A'(x)-\frac{2x}{1-x}A(x)=\frac{1}{(1-x)^2}.$$求解这个线性常微分方程。 

积分因子是$$\mu(x)=e^{2x}(1-x)^2.$$因此，$$\frac{d}{dx}\!\left(\mu(x)A(x)\right)=e^{2x}.$$积分：$$e^{2x}(1-x)^2A(x)=\frac{e^{2x}-1}{2}.$$所以，$$A(x)=\frac{1-e^{-2x}}{2(1-x)^2}. \tag{2}$$---

 ## 步骤 3：提取渐近密度

 近$x=1$,$$A(x)\sim \frac{1-e^{-2}}{2(1-x)^2}.$$自从$$[x^n]\frac1{(1-x)^2}=n+1,$$我们得到$$a_n \sim \frac{1-e^{-2}}{2}\,n.$$所以长线上的渐进占据分数是$$\frac{1-e^{-2}}{2}.$$---

 ## 第四步：回到圈子

 对于一个周期$N$椅子：

 - 第一个被占用的椅子挡住了自己和它的两个邻居，
 - 其余的椅子形成一条长度线$N-3$。 

因此$$\mathbb E[M_N]=1+a_{N-3}.$$所以，$$E(N) = 1-\frac{1+a_{N-3}}{N}.$$作为$N\to\infty$,$$\frac{1+a_{N-3}}{N} \to \frac{1-e^{-2}}{2}.$$所以$$\boxed{ \lim_{N\to\infty} E(N) = 1-\frac{1-e^{-2}}{2} = \frac{1+e^{-2}}{2} }.$$自从$10^{18}$是巨大的，$E(10^{18})$等于此限制，远远超过小数点后 14 位。

 # 2.Python实现```python
from decimal import Decimal, getcontext

# high precision arithmetic
getcontext().prec = 50

# compute limiting value
ans = (Decimal(1) + (-Decimal(2)).exp()) / Decimal(2)

# print to 14 decimal places
print(f"{ans:.14f}")
```---

 # 4. 小案例验证

 问题指出：$$E(4)=\frac12.$$确实：

 - 恰好有 2 张椅子被占用，
 - 所以 2 仍然是空的，$$E(4)=\frac24=\frac12.$$还：$$E(6)=\frac59,$$这与递归计算相匹配。 

极限值$$\frac{1+e^{-2}}{2}\approx 0.5676676$$是合理的：

 - 超过一半的椅子仍然空着，
 - 因为每张被占用的椅子都会迫使相邻的空位。
