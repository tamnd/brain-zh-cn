[项目欧拉问题 114](https://projecteuler.net/problem=114)

 ## 解决方案

 **答案：**`16475640049`让$F(n)$表示填充一行长度的方法数$n$使用：

 - 长度为灰色的方块$1$,
 - 长度至少为红色的块$3$,
 - 任意两个红色方块之间至少有一个灰色方块。 

我们被要求计算$F(50)$。 

---

 # 数学分析

 我们从第一原理推导出来。 

## 第 1 步：了解结构

 考虑一行长度的最左边位置$n$。 

有两种可能：

 ### 情况 1 — 第一个方块是灰色的

 然后剩下的$n-1$职位可以填补$F(n-1)$方式。 

贡献：$$F(n-1)$$---

 ### 情况 2 — 第一块是红色块

 假设第一个红色块的长度$k$， 在哪里$$k \ge 3$$有两个子情况。 

#### 子情况 A：块到达末尾

 如果$k=n$，这恰好贡献了一种排列。 

#### 子情况 B：块后剩余空间

 如果$k<n$，那么下一个方格必须是灰色的（分隔符），消耗一个额外的单位。 

所以放置后：

 - 红色长度块$k$,
 - 一个强制性的灰色方块，

 剩余长度为$$n-k-1$$可以填写$$F(n-k-1)$$方式。 

因此对于固定的$k<n$，贡献为：$$F(n-k-1)$$---

 ## 第 2 步：构建重复周期

 结合所有情况：$$F(n) = F(n-1) + 1 + \sum_{k=3}^{n-1} F(n-k-1)$$这$+1$对应于长度正好的红色块的排列$n$填充该行。 

---

 ## 步骤 3：初始条件

 如果行长度小于$3$，没有红色块可以容纳。 

所以只有全灰色的排列存在：$$F(0)=F(1)=F(2)=1$$问题陈述说的是$n=7$有$17$方式，所以我们可以用它来验证。 

---

 # Python 实现```python
def count_ways(n):
    # F[i] = number of valid fillings for length i
    F = [0] * (n + 1)

    # Base cases
    F[0] = 1
    if n >= 1:
        F[1] = 1
    if n >= 2:
        F[2] = 1

    # Compute values bottom-up
    for length in range(3, n + 1):

        # Case 1: first square is grey
        total = F[length - 1]

        # Case 2: first block is red
        for block_len in range(3, length + 1):

            if block_len == length:
                # Red block fills the entire row
                total += 1
            else:
                # Need one grey separator after the block
                total += F[length - block_len - 1]

        F[length] = total

    return F[n]

# Verify small example
print(count_ways(7))   # should be 17

# Compute required answer
print(count_ways(50))
```---

for length in range(3, n + 1):
```我们从较小的长度开始逐步计算答案。

 ## 灰色优先情况```python
total = F[length - 1]
```先放一个灰色方块，留一排尺寸$length-1$。 

---

 ## 红色优先案例```python
for block_len in range(3, length + 1):
```尝试每个允许的红色块长度。 

### 整行已填充```python
if block_len == length:
    total += 1
```完全是一种安排。 

---

 ### 空间依然存在```python
total += F[length - block_len - 1]
```必须使用一个分隔符灰色方块。
