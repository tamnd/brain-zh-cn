[项目欧拉问题 575](https://projecteuler.net/problem=575)

 ## 解决方案

 **答案：**`0.000989640561`设网格大小为$N \times N$， 和$N=1000$。 

一个房间有：

 - 学位$2$在拐角处，
 - 学位$3$在边缘（非角落），
 - 学位$4$在室内。 

我们必须计算莱昂哈德在一个正方形房间中的长期概率，对两种可能的移动规则进行平均。 

---

 # 1. 规则 (i) 的平稳分布

 在规则 (i) 中，莱昂哈德统一选择：

 - 留在原地，
 - 每个相邻的房间。 

所以有度的房间$d$有$d+1$同样可能的选择。 

对于这种类型的无向图，平稳分布与$d+1$。 

因此权重是：

 - 角落：$3$，
- 边缘：$4$，
- 内部的：$5$。 

总重量：$$4\cdot 3 + 4(N-2)\cdot 4 + (N-2)^2\cdot 5$$为了$N=1000$,$$W_1 = 5N^2 - 4N = 4{,}996{,}000.$$---

 # 2. 规则 (ii) 的平稳分布

 在规则(ii)中：

 - 概率$1/2$留下来，
 - 剩余$1/2$邻居之间平均分配。 

平稳分布与程度成正比$d$。 

因此权重是：

 - 角落：$2$，
- 边缘：$3$，
- 内部的：$4$。 

总重量：$$W_2 = 4N^2 - 4N = 3{,}996{,}000.$$---

 # 3. 按位置类型计算平方编号的房间

 正方形编号的房间是：$$1^2,2^2,\dots,1000^2.$$有$1000$房间总数为平方数。 

检查他们在$1000\times1000$网格给出：

 - 角落：$2$,
 - 边缘（非角）：$46$，
- 内部的：$952$。 

（的确$2+46+952=1000$.)

 ---

 # 4. 每个规则下的概率

 ## 规则 (i)

 加权平方房间总计：$$3\cdot2 + 4\cdot46 + 5\cdot952 = 4950.$$因此$$P_1=\frac{4950}{4{,}996{,}000}.$$---

 ## 规则 (ii)

 加权平方房间总计：$$2\cdot2 + 3\cdot46 + 4\cdot952 = 3950.$$因此$$P_2=\frac{3950}{3{,}996{,}000}.$$---

 # 5. 抛硬币的平均值$$P=\frac{P_1+P_2}{2} = \frac12\left( \frac{4950}{4{,}996{,}000} + \frac{3950}{3{,}996{,}000} \right).$$这简化为$$P=\frac{49393}{49910040} \approx 0.000989640561297887\ldots$$四舍五入到小数点后 12 位：$$0.000989640561$$**答案：0.000989640561**
