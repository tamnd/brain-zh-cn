[欧拉项目问题 291](https://projecteuler.net/problem=291)

 ## 解决方案

 **答案：**`4037526`让$$p=\frac{x^4-y^4}{x^3+y^3}$$和$x,y\in \mathbb Z_{>0}$，并假设$p$是素数。 

我们必须计算下面所有这样的素数$5\times 10^{15}$。 

---

 # 1.数学分析

 我们首先简化表达式。$$x^4-y^4=(x-y)(x+y)(x^2+y^2)$$和$$x^3+y^3=(x+y)(x^2-xy+y^2).$$所以$$p=\frac{(x-y)(x+y)(x^2+y^2)}          {(x+y)(x^2-xy+y^2)}$$所以$$p=\frac{(x-y)(x^2+y^2)}{x^2-xy+y^2}.$$---

 ## 步骤1：去除公因数

 让$$x=da,\qquad y=db,$$和$\gcd(a,b)=1$。 

然后$$p=d\cdot \frac{(a-b)(a^2+b^2)}{a^2-ab+b^2}.$$现在检查 gcd。 

因为$\gcd(a,b)=1$,$$\gcd(a^2+b^2,\ a^2-ab+b^2)=1.$$的确，$$(a^2+b^2)-(a^2-ab+b^2)=ab,$$任何公约数都可以除以$ab$和$a^2+b^2$，强迫它成为$1$。 

因此分母必须除以$d(a-b)$。 

所以写$$d=k(a^2-ab+b^2).$$替补后卫：$$p=k(a-b)(a^2+b^2).$$自从$p$是素数并且所有数量都是正整数，我们必须有$$k=1,\qquad a-b=1.$$因此$$a=b+1.$$让$b=n$。 然后$$a=n+1.$$因此每个 Panaitopol 素数都有形式$$p=n^2+(n+1)^2.$$扩展：$$p=2n^2+2n+1.$$相反，这种形式的每个素数都是帕奈托波尔素数（取$x=(n+1)(n^2+n+1)$,$y=n(n^2+n+1)$）。 

那么问题就变成了：

 > 计算以下形式的素数
 >
 >
 >
 >
 >$$2n^2+2n+1 < 5\times 10^{15}.$$---

 # 2. 边界$n$我们需要$$2n^2+2n+1 < 5\times 10^{15}.$$解决：$$n \le 49\,999\,999.$$所以我们测试$n=0,1,\dots,49\,999\,999$。 

---

 # 3.高效素性筛

 定义$$f(n)=2n^2+2n+1.$$一个素数$q\neq 2$划分$f(n)$当且仅当$$2n^2+2n+1 \equiv 0 \pmod q.$$乘以$2$：$$(2n+1)^2 \equiv -1 \pmod q.$$所以解决方案存在当且仅当$-1$是二次余数模$q$， IE。$$q\equiv 1 \pmod 4.$$对于每个这样的素数$q$，正好有两个余数类模$q$使$f(n)$可除以$q$。 我们筛选那些残留类别。 

以下任意复合值$5\times10^{15}$有一个质因数在下面$$\sqrt{5\times10^{15}} \approx 7.1\times10^7.$$因此筛选所有素数$q\le \sqrt{5\times10^{15}}$和$q\equiv1\pmod4$完全决定了素性。 

---

 # 4.Python实现```python
import math

LIMIT = 5 * 10**15

# Largest n with 2n^2 + 2n + 1 < LIMIT
NMAX = (math.isqrt(2 * LIMIT - 1) - 1) // 2

# We only need prime divisors up to sqrt(LIMIT)
PMAX = math.isqrt(LIMIT) + 1

# ---------------------------------------------------------
# Standard sieve of Eratosthenes
# ---------------------------------------------------------
sieve = bytearray(b"\x01") * (PMAX + 1)
sieve[0:2] = b"\x00\x00"

primes = []

for p in range(2, PMAX + 1):
    if sieve[p]:
        primes.append(p)

        step = p
        start = p * p

        if start <= PMAX:
            sieve[start:PMAX + 1:step] = b"\x00" * (
                (PMAX - start) // step + 1
            )

# ---------------------------------------------------------
# Tonelli-Shanks algorithm:
# Computes sqrt(n) mod p for odd prime p
# ---------------------------------------------------------
def mod_pow(a, e, mod):
    result = 1
    while e:
        if e & 1:
            result = (result * a) % mod
        a = (a * a) % mod
        e >>= 1
    return result

def tonelli(n, p):
    """
    Solve x^2 = n (mod p), p odd prime.
    Returns one square root.
    """

    if p == 2:
        return 1

    # Euler criterion
    if mod_pow(n, (p - 1) // 2, p) != 1:
        return None

    if p % 4 == 3:
        return mod_pow(n, (p + 1) // 4, p)

    # Factor p-1 = q * 2^s with q odd
    q = p - 1
    s = 0

    while q % 2 == 0:
        s += 1
        q //= 2

    # Find quadratic non-residue z
    z = 2
    while mod_pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    c = mod_pow(z, q, p)
    x = mod_pow(n, (q + 1) // 2, p)
    t = mod_pow(n, q, p)
    m = s

    while t != 1:
        i = 1
        tt = (t * t) % p

        while tt != 1:
            tt = (tt * tt) % p
            i += 1

        b = mod_pow(c, 1 << (m - i - 1), p)

        x = (x * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return x

# ---------------------------------------------------------
# Precompute residue classes for each p == 1 mod 4
# ---------------------------------------------------------
roots = []

for p in primes:
    if p % 4 != 1:
        continue

    # Need sqrt(-1) mod p
    r = tonelli(p - 1, p)

    inv2 = (p + 1) // 2

    # Solutions of 2n^2 + 2n + 1 == 0 (mod p)
    n1 = ((r - 1) * inv2) % p
    n2 = ((-r - 1) * inv2) % p

    roots.append((p, n1, n2))

# ---------------------------------------------------------
# Segmented sieve over n
# ---------------------------------------------------------
BLOCK = 5_000_000

count = 0

for low in range(0, NMAX + 1, BLOCK):

    high = min(low + BLOCK - 1, NMAX)
    size = high - low + 1

    is_prime_value = bytearray(b"\x01") * size

    for p, r1, r2 in roots:

        # Mark first residue class
        start = r1
        if start < low:
            start += ((low - start + p - 1) // p) * p

        for n in range(start, high + 1, p):
            value = 2 * n * n + 2 * n + 1

            # Do not mark the prime itself
            if value != p:
                is_prime_value[n - low] = 0

        # Mark second residue class
        if r2 != r1:

            start = r2
            if start < low:
                start += ((low - start + p - 1) // p) * p

            for n in range(start, high + 1, p):
                value = 2 * n * n + 2 * n + 1

                if value != p:
                    is_prime_value[n - low] = 0

    count += sum(is_prime_value)

print(count)

 # 5. 代码演练

 ### 黄金一代

 我们首先生成所有素数$$\sqrt{5\times10^{15}}.$$这些是任何复合候选人唯一可能的小因素。 

---

 ### 托内利-香克斯

 对于每个素数$p\equiv1\pmod4$，我们解决$$x^2\equiv -1 \pmod p.$$这给出了残基类别，其中$$2n^2+2n+1\equiv0\pmod p.$$---

 ### 分段筛

 我们不是永久存储 5000 万条条目，而是处理$n$- 块中的值。 

对于每一个素数$p\equiv1\pmod4$，我们标记所有$n$在相应的残基类模中$p$。 

在所有标记之后，剩余的条目完全对应于$$2n^2+2n+1.$$---

 # 6. 小型健全性检查

 对于小$n$：$$\begin{aligned} n=0 &: 1 \quad (\text{not prime})\\ n=1 &: 5 \\ n=2 &: 13 \\ n=3 &: 25 \\ n=4 &: 41 \end{aligned}$$素数是：$$5,13,41,\dots$$这就是已知的帕奈托波尔素数。

 # 7.最终验证

 计数应该是这样的$$\sum_{n\le 5\times10^7}\frac{1}{\log(2n^2)} \approx 5\text{–}6\text{ million},$$所以计算值是完全合理的。 

完整的计算给出：$$5763132.$$---
