[项目欧拉问题 107](https://projecteuler.net/problem=107)

 ## 解决方案

 **答案：**`259679`这个问题是一个经典的**最小生成树**问题。 

给定一个连通加权无向图。 

我们希望在保持图连接的同时删除尽可能多的冗余边。 

关键事实是：

 > 在所有连通的子图中，总权重最小的就是**最小生成树（MST）**。 

所以：$$\text{maximum saving} = \text{(total weight of original graph)} - \text{(weight of MST)}$$---

 # 数学分析

 假设该图有：

 -$V$顶点
 -$E$加权无向边

 生成树：

 - 连接所有顶点，
 - 不包含循环，
 - 总是有确切的$V-1$边缘。 

如果保留连接性，则超出此范围的任何额外边缘都是多余的。 

所以我们必须计算：

 1、原网络总权重
 2. 最小生成树的权重

 然后减去。 

---

 ## 克鲁斯卡尔算法

 标准 MST 算法是 **Kruskal 算法**。 

### 原理

 1. 通过增加权重对所有边进行排序。 
2. 重复添加**不**创建循环的最小边。 
3. 选择后停止$V-1$边缘。 

为了有效地检测循环，我们使用**不相交集并集（并集查找）**结构。 

---

 # 问题中的小例子

 原始图权重为：$$243$$最优连接网络的权重为：$$93$$因此节省的是：$$243 - 93 = 150$$与声明相符。

 # Python 实现```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        # Path compression
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)

        if ra == rb:
            return False

        # Union by rank
        if self.rank[ra] < self.rank[rb]:
            self.parent[ra] = rb
        elif self.rank[ra] > self.rank[rb]:
            self.parent[rb] = ra
        else:
            self.parent[rb] = ra
            self.rank[ra] += 1

        return True

# Read the matrix
with open("network.txt") as f:
    rows = [line.strip().split(",") for line in f]

n = len(rows)

edges = []
total_weight = 0

# Extract undirected edges once (i < j)
for i in range(n):
    for j in range(i + 1, n):
        if rows[i][j] != "-":
            w = int(rows[i][j])
            edges.append((w, i, j))
            total_weight += w

# Kruskal's algorithm
edges.sort()

dsu = DSU(n)
mst_weight = 0

for w, u, v in edges:
    if dsu.union(u, v):
        mst_weight += w

saving = total_weight - mst_weight

print(saving)
```---
