[欧拉项目问题 61](https://projecteuler.net/problem=61)

 ## 解决方案

 **答案：**`28684`我们寻找一组**六个不同的 4 位多边形数字**，每种类型各有一个：

 - 三角形$P_{3,n}$- 正方形$P_{4,n}$- 五边形$P_{5,n}$- 六角形$P_{6,n}$- 七边形$P_{7,n}$- 八角形$P_{8,n}$这样：

 1. 每个数字都是**4位**。 
2. 该集合是**循环**：$$\text{last two digits of } a_i = \text{first two digits of } a_{i+1}$$最后一个链接回到第一个。 
3. 每个多边形类型**恰好出现一次**。 

---

 ## 1.数学分析

 ### 第 1 步：生成多边形数

 公式为：$$P_{3,n}=\frac{n(n+1)}{2}$$

$$P_{4,n}=n^2$$

$$P_{5,n}=\frac{n(3n-1)}{2}$$

$$P_{6,n}=n(2n-1)$$

$$P_{7,n}=\frac{n(5n-3)}{2}$$

$$P_{8,n}=n(3n-2)$$我们只关心 **4 位数字**，即$$1000 \le P_{k,n} \le 9999$$---

 ### 第 2 步：建模为图形问题

 像这样的数字$8128$可以连接到前两位数字相等的另一个号码$28$。 

例子：$$8128 \to 2882$$因为：$$8128 \mod 100 = 28$$和$$\left\lfloor \frac{2882}{100} \right\rfloor = 28$$因此，每个数字的行为就像以下之间的有向边：

 - 前缀 = 前两位数字
 - 后缀 = 最后两位数字

 我们搜索 **长度为 6** 的循环，其中：

 - 每个多边形类型使用一次，
 - 数字不同，
 - 邻接规则成立，
 - 循环结束。 

这自然可以通过对多边形类型的排列进行**深度优先搜索（DFS）**来解决。 

---

 ### 步骤 3：限制无效转换

 一个有用的观察：

 如果后缀小于 10，则它不能是 4 位数字的前两位。 

例子：$$8120$$结束于$20$， 有效的。 

但$$8105$$结束于$05$，不可能，因为没有以“05”开头的 4 位数字。 

所以我们只保留最后两位数字至少为 10 的数字。

 ## 2.Python实现```python
from collections import defaultdict

# Polygonal formulas
def polygonal(s, n):
    if s == 3:
        return n * (n + 1) // 2
    elif s == 4:
        return n * n
    elif s == 5:
        return n * (3 * n - 1) // 2
    elif s == 6:
        return n * (2 * n - 1)
    elif s == 7:
        return n * (5 * n - 3) // 2
    elif s == 8:
        return n * (3 * n - 2)

# Generate all valid 4-digit polygonal numbers
poly = {}

for s in range(3, 9):
    nums = []
    n = 1

    while True:
        x = polygonal(s, n)

        if x >= 10000:
            break

        # Keep only valid 4-digit cyclic candidates
        if 1000 <= x <= 9999 and x % 100 >= 10:
            nums.append(x)

        n += 1

    poly[s] = nums

def dfs(path, used_types):
    # If we have 6 numbers, check cyclic closure
    if len(path) == 6:
        return path if path[-1] % 100 == path[0] // 100 else None

    suffix = path[-1] % 100

    # Try unused polygonal types
    for s in range(3, 9):
        if s not in used_types:
            for num in poly[s]:
                if num // 100 == suffix:
                    result = dfs(
                        path + [num],
                        used_types | {s}
                    )
                    if result:
                        return result

    return None

# Start search from octagonal numbers
# (any type works, but this reduces symmetry)
answer_cycle = None

for start in poly[8]:
    result = dfs([start], {8})
    if result:
        answer_cycle = result
        break

print(answer_cycle)
print(sum(answer_cycle))
```---

 ## 3. 代码演练

 ### 生成多边形数

 我们将这六个公式应用到`polygonal(s, n)`。 

对于每种类型：```python
for s in range(3, 9):
```我们生成值直到超过 9999。 

我们只保留：```python
1000 <= x <= 9999
```和```python
x % 100 >= 10
```确保最后两位数字可以组成另一个 4 位数字的前两位数字。 

---

 ### DFS 搜索

 递归函数：```python
dfs(path, used_types)
```认为：

 -`path`→ 当前的数字链
 -`used_types`→ 已选择的多边形类别

 每一步：```python
suffix = path[-1] % 100
```我们尝试每种未使用的多边形类型并使用以下命令搜索数字：```python
num // 100 == suffix
```表示前两位数字匹配。 

当收集到六个数字时：```python
len(path) == 6
```我们验证循环关闭：```python
path[-1] % 100 == path[0] // 100
```---

 ### 验证示例

 问题的例子：$$8128, 2882, 8281$$有效是因为：

 -$8128 \to 2882$通过 28
 -$2882 \to 8281$通过82
 -$8281 \to 8128$通过81

 数字分别是三角形、五边形、正方形。 

DFS 逻辑准确地再现了六种类型的这种行为。

 ## 4.最终验证

 Running the program finds the unique cyclic set:$$1281,\ 8128,\ 2882,\ 8256,\ 5625,\ 2512$$（仅使用每个多边形族中的一个数字一次）。 

他们的总和是：$$1281+8128+2882+8256+5625+2512=28684$$大小是合理的（六个 4 位数字的总和约为$6\times 5000\approx 30000$）并匹配问题中的唯一性条件。 

**答案：28684**
