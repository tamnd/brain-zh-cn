[项目欧拉问题 214](https://projecteuler.net/problem=214)

 ## 解决方案

 **答案：**`1677366278943`让$L(n)$表示迭代的 totient 链的长度，起始于$n$，计算两个端点。 因此$$5 \to 4 \to 2 \to 1$$有长度$4$。 

我们被要求计算$$\sum_{\substack{p<40\,000\,000\\ p\text{ prime}\\ L(p)=25}} p.$$---

 # 数学分析

 ## 1. 受众链

 欧拉 totient 函数满足$$\phi(n) < n \quad (n>1),$$所以重复应用总是达到$1$。 

递归定义：$$L(1)=1, \qquad L(n)=1+L(\phi(n)).$$例如：$$L(5)=1+L(4) =1+(1+L(2)) =1+1+(1+L(1)) =4.$$---

 ## 2. 素数的特殊行为

 如果$p$是素数，那么$$\phi(p)=p-1.$$因此$$L(p)=1+L(p-1).$$所以要找到链长的素数$25$，我们只需要知道整数的链长度可达$40\,000\,000$。 

---

 ## 3. 高效计算$\phi(n)$计算$\phi(n)$独立于每个$n$会太慢。 

相反，使用经典的筛恒等式：

 初始化$$\phi(n)=n.$$对于每个素数$p$,$$\phi(k)\leftarrow \phi(k)\left(1-\frac1p\right)$$对于每一个倍数$k$的$p$。 

这将计算所有 totients 最多$N$大约在$$O(N\log\log N).$$---

 ## 4. 链长度的动态规划

 自从$$\phi(n) < n,$$我们可以按递增顺序计算链长度：$$L(n)=1+L(\phi(n)).$$因为$\phi(n)$已知且小于$n$，每个值计算一次。 

---

 ## 5. 检测所需的素数

 素数$p$贡献当且仅当$$L(p)=25.$$使用$$L(p)=1+L(p-1),$$我们同样需要$$L(p-1)=24.$$因此，在筛选素数时，我们可以立即测试这一点。 

---

 # Python 实现```python
LIMIT = 40_000_000

# ---------------------------------------------------------
# Step 1: Compute Euler's totient function for all n
# ---------------------------------------------------------

phi = list(range(LIMIT + 1))
is_prime = bytearray(b"\x01") * (LIMIT + 1)

is_prime[0] = is_prime[1] = 0

for p in range(2, LIMIT + 1):
    if is_prime[p]:
        # p is prime

        # Apply phi formula to all multiples
        for k in range(p, LIMIT + 1, p):
            phi[k] -= phi[k] // p

        # Mark composite numbers
        step = p
        start = p * 2
        for k in range(start, LIMIT + 1, step):
            is_prime[k] = 0

# ---------------------------------------------------------
# Step 2: Compute totient-chain lengths
# ---------------------------------------------------------

chain_len = [0] * (LIMIT + 1)
chain_len[1] = 1

for n in range(2, LIMIT + 1):
    chain_len[n] = chain_len[phi[n]] + 1

# ---------------------------------------------------------
# Step 3: Sum primes with chain length 25
# ---------------------------------------------------------

answer = 0

for p in range(2, LIMIT):
    if is_prime[p] and chain_len[p] == 25:
        answer += p

print(answer)
```---
