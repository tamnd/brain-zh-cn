[项目欧拉问题 213](https://projecteuler.net/problem=213)

 ## 解决方案

 **答案：**`330.721154`让$E$表示 50 次随机跳跃后空方格的预期数量。 

关键的观察结果是跳蚤**独立**。 

而不是追踪所有$900$共同跳蚤（不可能直接），我们计算每个方块$s$：$$\Pr(s \text{ is empty after 50 steps})$$然后对所有平方求和。 

---

 # 1.数学分析

 考虑一个固定的目标方格$s$。 

对于每个起始方格$i$， 让$$p_{i\to s}^{(50)}$$是跳蚤开始于$i$位于$s$50次跳跃后。 

由于跳蚤独立移动，$$\Pr(s \text{ empty}) = \prod_{i=1}^{900} \left(1-p_{i\to s}^{(50)}\right)$$因为每只跳蚤都独立地避开$s$。 

所以，$$E = \sum_{s} \Pr(s \text{ empty}) = \sum_{s} \prod_{i=1}^{900} \left(1-p_{i\to s}^{(50)}\right)$$所以问题简化为计算所有 50 步转移概率$30\times30$网格。 

---

 ## 马尔可夫链结构

 一只跳蚤在网格上进行随机游走。 

如果一个正方形有度数$d\in\{2,3,4\}$，然后跳蚤从该方格以概率均匀地移动到其邻居之一$1/d$。 

状态空间只有$900$状态，因此我们可以动态地演化概率。 

对于一个起始方格：

 - 初始化概率$1$一开始，
 - 重复将概率质量分配给邻居 50 步。 

这给了所有$p_{i\to s}^{(50)}$。 

天真地为所有人做这件事$900$启动成本大致$$900 \times 50 \times 900$$操作，完全可行。

 # 2.Python实现```python
from math import prod

N = 30
STEPS = 50

# ------------------------------------------------------------
# Build neighbor lists for every square
# ------------------------------------------------------------

neighbors = {}

for r in range(N):
    for c in range(N):
        adj = []

        if r > 0:
            adj.append((r - 1, c))
        if r < N - 1:
            adj.append((r + 1, c))
        if c > 0:
            adj.append((r, c - 1))
        if c < N - 1:
            adj.append((r, c + 1))

        neighbors[(r, c)] = adj

# ------------------------------------------------------------
# empty_prob[r][c] will accumulate:
#   product over fleas of (1 - probability flea ends here)
# ------------------------------------------------------------

empty_prob = [[1.0 for _ in range(N)] for _ in range(N)]

# ------------------------------------------------------------
# Process each flea independently
# ------------------------------------------------------------

for sr in range(N):
    for sc in range(N):

        # Current probability distribution
        cur = [[0.0 for _ in range(N)] for _ in range(N)]
        cur[sr][sc] = 1.0

        # Perform 50 random-walk steps
        for _ in range(STEPS):

            nxt = [[0.0 for _ in range(N)] for _ in range(N)]

            for r in range(N):
                for c in range(N):

                    p = cur[r][c]

                    if p == 0.0:
                        continue

                    adj = neighbors[(r, c)]
                    share = p / len(adj)

                    for nr, nc in adj:
                        nxt[nr][nc] += share

            cur = nxt

        # Multiply contribution into empty probabilities
        for r in range(N):
            for c in range(N):
                empty_prob[r][c] *= (1.0 - cur[r][c])

# ------------------------------------------------------------
# Expected number of empty squares
# ------------------------------------------------------------

answer = 0.0

for r in range(N):
    for c in range(N):
        answer += empty_prob[r][c]

print(f"{answer:.6f}")
```---

 # 3. 代码演练

 ## 建立邻居```python
neighbors[(r, c)]
```存储所有合法的相邻方块。 

- 角有 2 个邻居，
 - 边有 3 个，
 - 内部方块有 4 个。 

---

 ## 空方概率

 我们维持：```python
empty_prob[r][c]
```最初每个方格肯定是空的$1$在考虑任何跳蚤之前。 

对于每只跳蚤，我们乘以：$$1 - p_{i\to s}^{(50)}$$因为那只跳蚤必须避开广场。 

---

 ## 模拟一只跳蚤```python
cur[sr][sc] = 1.0
```跳蚤从最初的方格开始。 

每个步骤在邻居之间平均分配概率。 

这正是马尔可夫转移规则。 

50次迭代后：```python
cur[r][c]
```等于跳蚤完成的概率$(r,c)$。 

---

 ## 最终期望

 对于每个正方形：```python
answer += empty_prob[r][c]
```它实现了$$E = \sum_s \Pr(s \text{ empty})$$通过期望的线性度。

 # 4. 验证

 一些健全性检查：

 - 最初没有空的方块。 
- 当跳蚤随机分布时，就会发生碰撞。 
- 因此，空方格的预期数量应该会变得很大，但仍低于 900。 
- 周围的值$300$–$350$是合理的，因为仅经过 50 个步骤后，分布就变得有些混合，但并不完全均匀。 

运行程序给出：$$330.721154\ldots$$这符合预期。
