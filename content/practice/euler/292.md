[欧拉项目问题 292](https://projecteuler.net/problem=292)

 ## 解决方案

 **答案：**`3600060866`设多边形的边为向量$$v_i=(x_i,y_i)\in \mathbb Z^2, \qquad |v_i| \in \mathbb Z.$$由于多边形是凸多边形，并且没有三个连续顶点共线，因此边缘方向在多边形周围严格增加。 

因此，毕达哥拉斯多边形完全由总和为零的整数长度晶格向量的循环排序序列确定（直到平移）。 

关键的观察是：

 > 每个允许的边缘向量都是一个（可能是缩放的）原始毕达哥拉斯向量：
 >
 >
 >
 >
 >$$(a,b)=k(m^2-n^2,\,2mn)$$>
 >
 >
 >
 > 连同符号更改和坐标交换。 

For perimeter$\le 120$，可能的边缘向量总数足够小，可以预先计算。 

---

 # 1. 数学公式

 假设多边形边按极角递增排序：$$v_1,v_2,\dots,v_r.$$凸性+“没有三者对齐”意味着：

 - 所有方向都是不同的，
 - 角度顺序严格，
 - 多边形闭合当且仅当$$\sum_{i=1}^r v_i = (0,0).$$周长条件为$$\sum_{i=1}^r |v_i| \le 120.$$那么问题就变成了：

 > 严格计数向量和为零且欧氏总长度至多的整数长度格向量的角度增加序列$120$。 

为了避免循环过度计数：

 - 选择角度最小的边作为第一条边，
 - 那么所有后面的边都有更大的角度。 

这给每个多边形恰好一次。 

---

 # 2.动态规划思想

 生成所有具有整数长度的有向格向量$\le 120$。 

对于每个向量存储：$$(x,y,\ell,\theta).$$按角度排序。 

现在对状态执行 DFS/记忆 DP：$$(\text{last index},\; s_x,\; s_y,\; p)$$含义：

 - 最后选择的边有角度索引`last`,
 - 当前向量和是$(s_x,s_y)$,
 - 当前周长是$p$。 

过渡附加一个具有更大角度的新向量。 

每当需要闭合向量时$$(-s_x,-s_y)$$仍然存在较大的角度和周长$\le 120$，我们得到一个多边形。 

因为$120$很小，可以通过记忆来管理可到达的状态。

 # 3.Python实现```python
from math import gcd, isqrt, atan2
from functools import lru_cache

LIMIT = 120

# ------------------------------------------------------------
# Generate all integer-length lattice vectors with length <= 120
# ------------------------------------------------------------

vectors = []

for x in range(-LIMIT, LIMIT + 1):
    for y in range(-LIMIT, LIMIT + 1):

        if x == 0 and y == 0:
            continue

        s = x * x + y * y
        r = isqrt(s)

        if r * r == s and r <= LIMIT:
            ang = atan2(y, x)
            if ang < 0:
                ang += 2.0 * 3.141592653589793

            vectors.append((ang, x, y, r))

# sort by polar angle
vectors.sort()

M = len(vectors)

# map vector -> (index,length)
lookup = {}

for i, (_, x, y, r) in enumerate(vectors):
    lookup[(x, y)] = (i, r)

# ------------------------------------------------------------
# DFS with memoization
# ------------------------------------------------------------

@lru_cache(None)
def dfs(last, sx, sy, perim, edges):

    total = 0

    # Can we close the polygon?
    need = (-sx, -sy)

    if edges >= 2 and need in lookup:
        idx, r = lookup[need]

        if idx > last and perim + r <= LIMIT:
            total += 1

    # Try extending with another edge
    for nxt in range(last + 1, M):

        _, x, y, r = vectors[nxt]

        if perim + r > LIMIT:
            continue

        total += dfs(
            nxt,
            sx + x,
            sy + y,
            perim + r,
            edges + 1
        )

    return total

# ------------------------------------------------------------
# Start from each possible first edge
# ------------------------------------------------------------

answer = 0

for i, (_, x, y, r) in enumerate(vectors):
    answer += dfs(i, x, y, r, 1)

print(answer)
```---

 # 4. 代码演练

 ### 向量生成

 我们枚举所有格向量$(x,y)$这样$$x^2+y^2$$是一个完美的正方形。 

这些正是具有整数欧几里得长度的向量。 

---

 ### 按角度排序

 凸多边形对应于以严格递增的极角顺序获取的向量。 

排序一次可以让我们自动强制凸性。 

---

 ### DFS状态

 记忆的状态存储：

 - 最后使用的角度索引，
 - 当前向量和，
 - 当前周长，
 - 已选择的边数。 

---

 ### 结束条件

 多边形闭合当且仅当所需的剩余向量为$$(-s_x,-s_y).$$如果该向量存在并且具有比前一条边更大的角度，则我们有一个有效的凸多边形。
