[欧拉项目问题 347](https://projecteuler.net/problem=347)

 ## 解决方案

 **答案：**`11109800204052`我们需要计算$$S(N)=\sum_{\substack{p<q\\ p,q\text{ primes}}} M(p,q,N),$$在哪里$M(p,q,N)$是最大的整数$\le N$其素因数恰好是 _$p$和$q$。 

例如，$$M(2,3,100)=96=2^5\cdot 3,$$

$$M(3,5,100)=75=3\cdot 5^2.$$我们被要求$$S(10^7).$$---

 # 数学分析

 计算出的数字$M(p,q,N)$有形式$$p^a q^b,$$和$$a\ge1,\qquad b\ge1,$$并且没有其他主要因素。 

所以对于固定的不同素数$p,q$,$$M(p,q,N)=\max \{p^a q^b \le N\}.$$如果不存在这样的数字，则$M=0$。 

---

 ## 关键观察

 假设$p q > N$。 

那么即使是能被两者整除的最小数$p$和$q$超过$N$， 所以$$M(p,q,N)=0.$$因此我们只需要满足素数对$$pq \le N.$$为了$N=10^7$，这是可以管理的。 

---

 ## 高效计算$M(p,q,N)$对于固定$p,q$，我们想要$$\max p^a q^b \le N.$$对所有指数的暴力破解足够快，因为幂呈指数级增长。 

算法：

 - 产生所有的力量$p$:$$p,p^2,p^3,\dots$$最多$N$。 
- 产生所有的力量$q$:$$q,q^2,q^3,\dots$$最多$N$。 
- 检查每件产品$p^a q^b\le N$，保持最大值。 

权力的数量很少：$$\log_2(10^7)\approx 23.$$因此每对只需要几百次操作。 

---

 ## 素数对的数量

 我们需要所有素数$N$，但仅与$$pq\le N.$$对于每个素数$p$， 有效的$q$满足$$q\le \frac{N}{p}.$$这导致了大约几十万对——完全可行。 

---

 # Python 实现```python
from math import isqrt

N = 10_000_000

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
def prime_sieve(limit):
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"

    for i in range(2, isqrt(limit) + 1):
        if sieve[i]:
            step = i
            start = i * i
            sieve[start:limit + 1:step] = b"\x00" * (((limit - start) // step) + 1)

    return [i for i in range(limit + 1) if sieve[i]]

primes = prime_sieve(N // 2)

# ------------------------------------------------------------
# Compute M(p,q,N)
# ------------------------------------------------------------
def M(p, q, N):
    best = 0

    # Generate powers of p
    pp = p
    p_powers = []
    while pp <= N:
        p_powers.append(pp)
        pp *= p

    # Generate powers of q
    qq = q
    q_powers = []
    while qq <= N:
        q_powers.append(qq)
        qq *= q

    # Try all products
    for a in p_powers:
        for b in q_powers:
            val = a * b
            if val <= N:
                if val > best:
                    best = val

    return best

# ------------------------------------------------------------
# Compute S(N)
# ------------------------------------------------------------
total = 0

L = len(primes)

for i in range(L):
    p = primes[i]

    if p * p > N:
        break

    for j in range(i + 1, L):
        q = primes[j]

        if p * q > N:
            break

        total += M(p, q, N)

print(total)
```---

```如果满足$$val \le N,$$我们最大化它。

 ## 主求和循环

 对于每个素数对：```python
if p * q > N:
    break
```我们立即停下来，因为更大$q$只增加产品。 

每个有效对仅贡献一个值$M(p,q,N)$。
