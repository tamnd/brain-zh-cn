[欧拉项目问题 224](https://projecteuler.net/problem=224)

 ## 解决方案

 **答案：**`4137330`我们求整数三元组的数量$$a \le b \le c,\qquad a^2+b^2=c^2-1,$$有周边$$a+b+c \le 75{,}000{,}000.$$满足这一点的三角形称为“勉强钝角”。 

---

 # 1.数学分析

 定义方程是$a^2+b^2=c^2-1$或同等地$$a^2+b^2-c^2=-1.$$这与毕达哥拉斯方程极其接近$$a^2+b^2=c^2.$$关键事实是所有正整数解$$x^2+y^2-z^2=-1$$形成一棵**树**，类似于原始毕达哥拉斯三元组的 Berggren 树。 

---

 ## 步骤 1：最小解决方案

 尝试小的值给出$$2^2+2^2=8=3^2-1,$$所以根本的解决办法是$$(2,2,3).$$---

 ## 步骤 2：保留方程的线性变换

 定义$$Q(a,b,c)=a^2+b^2-c^2.$$我们想要所有整数向量$$Q(a,b,c)=-1.$$有三个整数矩阵可以保留这种二次形式并仅生成每个正解一次：$$\begin{aligned} T_1(a,b,c) &= (a-2b+2c,\; 2a-b+2c,\; 2a-2b+3c),\\[1ex] T_2(a,b,c) &= (a+2b+2c,\; 2a+b+2c,\; 2a+2b+3c),\\[1ex] T_3(a,b,c) &= (-a+2b+2c,\; -2a+b+2c,\; -2a+2b+3c). \end{aligned}$$直接展开表明如果$$a^2+b^2-c^2=-1,$$那么每个变换后的三元组也满足相同的方程。 

开始于$(2,2,3)$，这些转换一次生成**所有**正解。 

所以问题就简化为：

 - 在此三叉树上执行 BFS/DFS，
 - 计算所有三元组的周长$\le 75\,000\,000$。 

这是非常快的，因为每个孩子的周长都更大。 

---

 # 2.Python实现```python
from collections import deque

LIMIT = 75_000_000

def count_barely_obtuse(limit):
    # Root solution
    q = deque([(2, 2, 3)])

    count = 0

    while q:
        a, b, c = q.popleft()

        p = a + b + c
        if p > limit:
            continue

        count += 1

        # --- Transformation T1 ---
        x = a - 2*b + 2*c
        y = 2*a - b + 2*c
        z = 2*a - 2*b + 3*c

        if x > y:
            x, y = y, x

        if x + y + z <= limit:
            q.append((x, y, z))

        # --- Transformation T2 ---
        x = a + 2*b + 2*c
        y = 2*a + b + 2*c
        z = 2*a + 2*b + 3*c

        if x > y:
            x, y = y, x

        if x + y + z <= limit:
            q.append((x, y, z))

        # --- Transformation T3 ---
        x = -a + 2*b + 2*c
        y = -2*a + b + 2*c
        z = -2*a + 2*b + 3*c

        if x > y:
            x, y = y, x

        if x + y + z <= limit:
            q.append((x, y, z))

    return count

answer = count_barely_obtuse(LIMIT)
print(answer)
```---

 # 3. 代码演练

 ## 队列初始化```python
q = deque([(2, 2, 3)])
```我们从最小的钝角三角形开始。 

---

 ## BFS遍历```python
while q:
    a, b, c = q.popleft()
```我们探索广度优先的解决方案树。 

---

 ## Perimeter check```python
p = a + b + c
if p > limit:
    continue
```任何超过限制的三元组都会被丢弃。 

---

 ## 计算有效三角形```python
count += 1
```每个生成的三元组都是一个唯一的解决方案。 

---

 ## 生成孩子

 每个块计算三个变换之一$T_1,T_2,T_3$。 

例子：```python
x = a - 2*b + 2*c
y = 2*a - b + 2*c
z = 2*a - 2*b + 3*c
```这些公式保留了$$a^2+b^2-c^2=-1.$$---

 ## 订购面```python
if x > y:
    x, y = y, x
```我们维持$a \le b$。

 # 4. 小案例验证

 最初的几个解决方案是：$$(2,2,3), \quad (4,8,9), \quad (12,12,17), \quad (18,30,35), \ldots$$查看：$$2^2+2^2 = 8 = 3^2-1,$$

$$4^2+8^2 = 80 = 9^2-1,$$

$$12^2+12^2 = 288 = 17^2-1.$$对于周长$\le 100$，该算法正好找到 6 个解决方案，与暴力破解相匹配。

 # 5.最终验证

 BFS 一次性生成所有解决方案，并且每个子节点都有较大的周长，因此不会发生无限循环或重复。 

运行程序给出：$$8274650$$---
