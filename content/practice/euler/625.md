[项目欧拉问题 625](https://projecteuler.net/problem=625)

 ## 解决方案

 **答案：**`551614306`让$$G(N)=\sum_{j=1}^N\sum_{i=1}^j \gcd(i,j).$$我们使用标准身份$$\sum_{i=1}^n \gcd(i,n)=\sum_{d\mid n} d\,\varphi\!\left(\frac nd\right),$$在哪里$\varphi$是欧拉函数。 

因此$$G(N) =\sum_{n=1}^N \sum_{d\mid n} d\,\varphi\!\left(\frac nd\right).$$写$n=dk$。 然后$$G(N) =\sum_{k\le N}\varphi(k)\sum_{d\le N/k} d.$$使用$$\sum_{d\le m} d = \frac{m(m+1)}2,$$我们得到$$G(N)=\sum_{k=1}^N \varphi(k)\,\frac{t(t+1)}2, \qquad t=\left\lfloor \frac Nk \right\rfloor.$$为了有效地评估这一点$N=10^{11}$，我们将相等的值分组$\left\lfloor N/k\right\rfloor$并使用 summatory totient 函数$$\Phi(x)=\sum_{n\le x}\varphi(n).$$标准递归是$$\Phi(n)=\frac{n(n+1)}2-\sum_{l=2}^{n}(r-l+1)\Phi\!\left(\left\lfloor\frac nl\right\rfloor\right),$$商分组$r=\left\lfloor n/\lfloor n/l\rfloor\right\rfloor$。 

以下 Python 程序计算答案：```python
from functools import lru_cache

MOD = 998244353
N = 10**11

# Precompute phi and prefix sums up to a cutoff
M = 3_000_000

phi = [0] * (M + 1)
primes = []
is_comp = bytearray(M + 1)

phi[1] = 1

# Linear sieve for Euler phi
for i in range(2, M + 1):
    if not is_comp[i]:
        primes.append(i)
        phi[i] = i - 1

    for p in primes:
        x = i * p
        if x > M:
            break

        is_comp[x] = 1

        if i % p == 0:
            phi[x] = phi[i] * p
            break
        else:
            phi[x] = phi[i] * (p - 1)

# Prefix sums: phi[n] = sum_{k<=n} phi(k)
for i in range(2, M + 1):
    phi[i] += phi[i - 1]

@lru_cache(maxsize=None)
def Phi(n):
    """Summatory totient function."""
    if n <= M:
        return phi[n]

    res = n * (n + 1) // 2

    l = 2
    while l <= n:
        v = n // l
        r = n // v
        res -= (r - l + 1) * Phi(v)
        l = r + 1

    return res

def G(N):
    ans = 0
    l = 1

    while l <= N:
        v = N // l
        r = N // v

        # sum phi(k) over [l, r]
        block_phi = Phi(r) - Phi(l - 1)

        tri = v * (v + 1) // 2

        ans = (ans + (block_phi % MOD) * (tri % MOD)) % MOD

        l = r + 1

    return ans

print(G(10))        # 122
print(G(10**11))
```该程序重现给定的检查：$$G(10)=122.$$运行它$10^{11}$给出$$G(10^{11}) \bmod 998244353 = 551614306.$$**答案：551614306**
