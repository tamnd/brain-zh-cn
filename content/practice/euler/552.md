[欧拉项目问题 552](https://projecteuler.net/problem=552)

 ## 解决方案

 **答案：**`326227335`让$$A_n \equiv i \pmod{p_i}\qquad (1\le i\le n),$$在哪里$p_i$是$i$-第一个素数，并且$A_n$是_最小正_解。 

我们必须计算$$S(300000)=\sum_{\substack{p\le 300000\\ p\mid A_n\text{ for some }n}} p.$$---

 # 1.数学分析

 ## 1.1 构建$A_n$定义$$P_n=\prod_{i=1}^n p_i .$$假设我们已经知道$A_n$。 

然后第一个的每个解决方案$n$同余式是$$A_n+kP_n.$$获得$A_{n+1}$，我们需要$$A_n+kP_n \equiv n+1 \pmod{p_{n+1}}.$$自从$P_n$互质于$p_{n+1}$，有唯一解：$$k \equiv (n+1-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$选择最小的非负数$k$给出$A_{n+1}$。 

因此：$$A_{n+1}=A_n+t_nP_n,$$在哪里$$t_n=((n+1)-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$---

 # 1.2 关于整除性的关键观察

 修复素数$q=p_k$。 

对于每一个$n\ge k$,$$A_n \equiv k \pmod{p_k},$$因为定义系统已经包含同余模$p_k$。 

因此：

 - 如果$p_k\mid A_n$，那么必然$n<k$。 

所以对于每个素数$p_k$，我们只需要追踪残基$$A_1,A_2,\dots,A_{k-1}\pmod{p_k}.$$---

 # 1.3 高效更新残差

 我们永远不需要巨大的整数$A_n$他们自己。 

对于每个未来素数$p_k$， 维持：

-$r_k = A_n \bmod p_k$,
 -$c_k = P_n \bmod p_k$。 

最初：$$A_1=1,\qquad P_1=2.$$因此对于所有人来说$k>1$：$$r_k=1,\qquad c_k=2.$$现在假设我们从$A_n$到$A_{n+1}$。 

我们已经计算过：$$A_{n+1}=A_n+t_nP_n.$$因此对任何未来素数取模$p_k$,$$r_k \leftarrow r_k+t_n c_k \pmod{p_k},$$

$$c_k \leftarrow c_k\,p_{n+1}\pmod{p_k}.$$每当$r_k=0$，我们找到了一个素数除以一些$A_n$。 

---

 # 1.4 复杂性

 有$$\pi(300000)=25997$$素数可达$300000$。 

该算法执行一组三角形更新：$$\sum_{i=1}^{m} (m-i)=O(m^2),$$这是关于$3.4\times 10^8$模块化更新。 

使用矢量化 NumPy 运算，在实践中运行速度很快。 

---

 # 2.Python实现```python
import numpy as np
from math import isqrt

LIMIT = 300000

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
is_prime = bytearray(b"\x01") * (LIMIT + 1)
is_prime[0:2] = b"\x00\x00"

for p in range(2, isqrt(LIMIT) + 1):
    if is_prime[p]:
        is_prime[p * p : LIMIT + 1 : p] = (
            b"\x00" * (((LIMIT - p * p) // p) + 1)
        )

primes_list = [i for i, v in enumerate(is_prime) if v]
primes = np.array(primes_list, dtype=np.int64)

m = len(primes)

# ------------------------------------------------------------
# r[k] = current A_n mod p_k
# c[k] = current P_n mod p_k
# ------------------------------------------------------------
r = np.ones(m, dtype=np.int64)

c = np.empty(m, dtype=np.int64)
c[0] = 0
c[1:] = 2

# hit[k] becomes True if p_k divides some A_n
hit = np.zeros(m, dtype=bool)

# ------------------------------------------------------------
# Main recurrence
# ------------------------------------------------------------
for n in range(1, m - 1):

    q = int(primes[n])  # p_(n+1)

    # t_n = ((n+1) - A_n) * P_n^{-1} mod p_(n+1)
    t = ((n + 1) - int(r[n])) * pow(int(c[n]), -1, q) % q

    # Update all future residues simultaneously
    sl = slice(n + 1, m)

    r[sl] = (r[sl] + t * c[sl]) % primes[sl]
    c[sl] = (c[sl] * q) % primes[sl]

    # Any zero residue means divisibility
    hit |= (r == 0)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------
answer = int(primes[hit].sum())

print(answer)
```---

 # 3. 代码演练

 ## 素数生成

 筛子将所有素数构建为$300000$。```python
primes_list = [i for i, v in enumerate(is_prime) if v]
```这给出：$$2,3,5,7,11,\dots$$---

 ## 残基数组```python
r[k]
```商店$$A_n \bmod p_k.$$

```python
c[k]
```商店$$P_n \bmod p_k.$$这些足以更新所有未来的残留物，而无需构建$A_n$。 

---

 ## 计算$t_n$

```python
t = ((n + 1) - int(r[n])) * pow(int(c[n]), -1, q) % q
```实施$$t_n=((n+1)-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$---

 ## 矢量化更新```python
r[sl] = (r[sl] + t * c[sl]) % primes[sl]
```实施$$A_{n+1}\equiv A_n+t_nP_n.$$相似地：```python
c[sl] = (c[sl] * q) % primes[sl]
```更新$$P_{n+1}=P_n\cdot p_{n+1}.$$---

 # 4. 示例验证

 对于$n\le 50$，程序准确地找到：$$5,\ 23,\ 41$$作为素数除以一些$A_n$。 

因此$$S(50)=5+23+41=69,$$与声明相符。

 # 5.最终验证

 计算产生：$$S(300000)=326227335.$$结果是合理的：

 - 只有相对较小的一部分素数可以整除一些素数$A_n$,
 - 总和大大低于所有素数的总和$300000$,
 - 样品盒完美匹配。 

**答案：326227335**
