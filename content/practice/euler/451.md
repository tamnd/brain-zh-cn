[欧拉项目 451 问题](https://projecteuler.net/problem=451)

 ## 解决方案

 **答案：**`153651073760956`我们想要所有整数$m$这样$$m^2 \equiv 1 \pmod n,$$因为一个元素是它自己的模逆 iff$m^{-1}\equiv m\pmod n$。 

问题定义了$I(n)$作为最大的此类$m<n-1$。 

---

 # 1.数学分析

 我们必须解决$$x^2 \equiv 1 \pmod n.$$等价地，$$(x-1)(x+1)\equiv 0 \pmod n.$$关键结构来自中国剩余定理。 

---

 ## 步骤 1：对素数幂取模的解

 对于奇素数幂$p^k$：$$x^2\equiv 1 \pmod{p^k}$$正好有两个解：$$x\equiv \pm 1 \pmod{p^k}.$$对于权力$2$：

 - 模数$2$: 一种解决方案
 - 模数$4$: 两种解决方案
 - 模数$2^k$为了$k\ge 3$: 四种解决方案$$x\equiv \pm1,\quad \pm(1+2^{k-1}) \pmod{2^k}.$$---

 ## 第二步：CRT分解

 如果$$n=\prod p_i^{a_i},$$然后每个解模$n$是通过独立选择一个解对每个素数幂取模并将它们与 CRT 组合而获得的。 

因此，通过将一些素幂因子分配给余数，可以得出非平凡的解$+1$和其他残留物$-1$。 

---

 ## 步骤 3：描述最大解的特征

 假设$$n=ab,\qquad \gcd(a,b)=1.$$采取CRT系统$$x\equiv -1 \pmod a,\qquad x\equiv 1 \pmod b.$$CRT 给出了唯一的模数解$n$。 

每一个不平凡的内卷都来自这样的分裂。 

如果$x$是一个解，那么也是$n-x$。 

因此下面最大的解决方案$n-1$从_最小_非平凡解中获得。 

所以定义$$s(n)=\min\{x>1 : x^2\equiv1\pmod n\},$$然后$$I(n)=n-s(n).$$---

 ## 步骤4：高效计算

 直接搜索是不可能的$2\times10^7$。 

相反：

 1. 筛选最小质因数。 
2. 因式分解$n$。 
3. 根据素数幂分解生成所有 CRT 求和。 
4. 保留最小的非平凡解$s(n)$。 
5. 添加$n-s(n)$。 

The number of involutions is tiny because the number of distinct prime factors is tiny.

 The total runtime is easily feasible in optimized Python/PyPy.

 ---

 # 2.Python实现```python
from math import prod

LIMIT = 20_000_000

# ------------------------------------------------------------
# Smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(LIMIT + 1))

for i in range(2, int(LIMIT ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Extended Euclid modular inverse
# ------------------------------------------------------------

def inv_mod(a, m):
    x0, x1 = 1, 0
    b = m
    while b:
        q = a // b
        a, b = b, a % b
        x0, x1 = x1, x0 - q * x1
    return x0 % m

# ------------------------------------------------------------
# CRT merge:
# x ≡ r1 (mod m1)
# x ≡ r2 (mod m2)
# gcd(m1,m2)=1
# ------------------------------------------------------------

def crt(r1, m1, r2, m2):
    t = ((r2 - r1) * inv_mod(m1, m2)) % m2
    return r1 + m1 * t

# ------------------------------------------------------------
# Generate prime powers
# ------------------------------------------------------------

def factorize(n):
    out = []
    while n > 1:
        p = spf[n]
        e = 0
        pp = 1
        while n % p == 0:
            n //= p
            e += 1
            pp *= p
        out.append((p, e, pp))
    return out

# ------------------------------------------------------------
# Solutions modulo p^k
# ------------------------------------------------------------

def local_roots(p, e, pe):
    if p == 2:
        if e == 1:
            return [1]
        elif e == 2:
            return [1, 3]
        else:
            h = 1 << (e - 1)
            return [1, pe - 1, 1 + h, h - 1]
    else:
        return [1, pe - 1]

# ------------------------------------------------------------
# Main
# ------------------------------------------------------------

answer = 0

for n in range(3, LIMIT + 1):

    fac = factorize(n)

    roots = [(0, 1)]

    # build all CRT combinations
    for p, e, pe in fac:
        local = local_roots(p, e, pe)

        new_roots = []

        for r, mod in roots:
            for t in local:
                nr = crt(r, mod, t, pe)
                new_roots.append((nr, mod * pe))

        roots = new_roots

    best = 1

    for r, _ in roots:
        r %= n
        if r != n - 1:
            best = max(best, r)

    answer += best

print(answer)
```---

 # 3. 代码演练

 ### SPF 筛子

 我们预先计算每个数字的最小质因数$2\times10^7$。 

这允许在几乎恒定的摊销时间内进行因式分解。 

---

 ###`factorize(n)`生产$$n=\prod p_i^{e_i}$$加上实际的素数幂$p_i^{e_i}$。 

---

 ###`local_roots`返回所有解决方案$$x^2\equiv1\pmod{p^e}.$$对于奇素数：仅$\pm1$。 

对于二的幂（$e\ge3$）：$$1,\ -1,\ 1+2^{e-1},\ -1+2^{e-1}.$$---

 ### CRT组合

 我们递归地将局部解决方案组合成全局解决方案模$n$。 

由于不同质因数的数量很少，因此根的总数也很少。 

---

 ### 提取$I(n)$在所有的根中，$n-1$总是存在（简单的解决方案$-1$）。 

我们选择严格小于的最大根$n-1$。 

---

 # 4.小例子验证

 ##$n=15$根是$$1,4,11,14.$$下面最大的$14$是$$I(15)=11.$$正确的。 

---

 ##$n=100$根是$$1, 49, 51, 99.$$下面最大的$99$是$$I(100)=51.$$正确的。 

---

 ##$n=7$仅根：$$1,6.$$自从$6=n-1$被排除：$$I(7)=1.$$正确的。 

---

 # 5.最终验证

 总和约为$$\sum_{n\le 2\times10^7} O(n),$$所以结果是$10^{14}$–$10^{15}$是合理的。 

计算是完全确定性的，并且基于对合模的完整分类$n$。
