[项目欧拉问题 323](https://projecteuler.net/problem=323)

 ## 解决方案

 **答案：**`6.3551758451`让$T$成为第一个索引$N$使得累积按位 OR 变为全 1：$$x_N = 2^{32}-1.$$我们想要$\mathbb E[T]$。 

---

 # 第 1 步 — 了解流程

 每个$y_i$是一个均匀随机的 32 位整数。 

专注于单个位位置$b$。 

- 在一个随机整数中，位$b$是：

-$1$有概率$1/2$,
 -$0$有概率$1/2$。 

后$k$轮，该位仍然未设置，当且仅当每一轮$k$采样的整数有一个$0$在那个位置：$$P(\text{bit } b \text{ still }0\text{ after }k\text{ rounds}) = \left(\frac12\right)^k.$$所以，$$P(\text{bit } b \text{ is set after }k\text{ rounds}) = 1-2^{-k}.$$32 位位置是独立的，因此：$$P(x_k = 2^{32}-1) = (1-2^{-k})^{32}.$$因此$$P(T > k) = 1-(1-2^{-k})^{32}.$$---

 # 步骤 2 — 预计停止时间

 对于任何非负整数值随机变量，$$\mathbb E[T] = \sum_{k=0}^{\infty} P(T>k).$$因此，$$\boxed{ \mathbb E[T] = \sum_{k=0}^{\infty} \left[ 1-(1-2^{-k})^{32} \right] }.$$这收敛得非常快，因为$2^{-k}$呈指数衰减。 

---

 # 步骤 3 — 包含-排除闭合形式

 使用二项式定理展开：$$(1-2^{-k})^{32} = \sum_{j=0}^{32} \binom{32}{j}(-1)^j2^{-kj}.$$所以，$$1-(1-2^{-k})^{32} = \sum_{j=1}^{32} (-1)^{j+1}\binom{32}{j}2^{-kj}.$$互换金额：$$\mathbb E[T] = \sum_{j=1}^{32} (-1)^{j+1}\binom{32}{j} \sum_{k=0}^{\infty}2^{-kj}.$$内部总和是几何的：$$\sum_{k=0}^{\infty}2^{-kj} = \frac1{1-2^{-j}}.$$因此$$\boxed{ \mathbb E[T] = \sum_{j=1}^{32} (-1)^{j+1} \binom{32}{j} \frac1{1-2^{-j}} }.$$这是准确的。 

---

 # 第 4 步 — Python 实现```python
from math import comb

# Compute the exact expectation using inclusion-exclusion
E = 0.0

for j in range(1, 33):
    term = ((-1) ** (j + 1)) * comb(32, j) / (1 - 2**(-j))
    E += term

# Print rounded to 10 decimal places
print(f"{E:.10f}")
```---

 # 步骤 6 — 数值

 评估总和给出$$\mathbb E[T] \approx 6.3551758451.$$这是有道理的：

 - 1轮后，每一位都有概率$1/2$的出现，
 - 6轮后，仍然丢失固定位的概率为$2^{-6}=1/64$,
 - 6轮后预计丢失的位约为$32/64=0.5$,
 - 所以完成周围$6$-$7$轮数是合理的。 

因此结果是一致的。
