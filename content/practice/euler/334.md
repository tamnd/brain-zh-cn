[项目欧拉问题 334](https://projecteuler.net/problem=334)

 ## 解决方案

 **答案：**`150320021261690835`让碗由整数索引，并让$a_i$表示碗中豆子的数量$i$。 

我们被允许搬家$$(\ldots,a_{i-1},a_i,a_{i+1},\ldots) \to (\ldots,a_{i-1}+1,a_i-2,a_{i+1}+1,\ldots)$$每当$a_i\ge 2$。 

关键是要避免模拟数十亿次动作。 

## 1.数学分析

 ### 第 1 步：识别不变量

 每一步都保留：

 #### 豆子总数$$N=\sum_i a_i$$因为我们移除 2 个豆子并添加 2 个豆子。 

#### 一阶矩（质心）$$M=\sum_i i\,a_i$$自从$$(i-1)+(i+1)-2i=0.$$因此两者$N$和$M$是不变的。 

---

 ### 第 2 步：找到可预测变化的数量

 考虑二次矩$$Q=\sum_i i^2 a_i.$$位置一动$i$变化$Q$经过$$(i-1)^2+(i+1)^2-2i^2.$$扩展：$$(i^2-2i+1)+(i^2+2i+1)-2i^2=2.$$所以**每一步都会增加$Q$正好 2**。 

因此：$$\boxed{ \text{moves} = \frac{Q_{\text{final}}-Q_{\text{initial}}}{2} }$$所以我们只需要最终的稳定配置即可。 

---

 ### 步骤 3：表征最终稳定状态

 稳定状态下每碗只有 0 或 1 颗豆子。 

在所有具有固定的稳定状态中$N$和$M$，可达的是最小化的唯一排列$$\sum x_i^2$$受：

 -$N$占据的位置，
 - 不同的整数，
 - 总金额$M$。 

因为平方函数是凸函数，所以占用的碗必须**尽可能连续**。 

因此最终的位置是：$$a,\ a+1,\ \ldots,\ a+N-1$$除了最大的$r$位置移动了$+1$。 

让$$T=\frac{N(N-1)}{2}.$$然后写$$M-T = aN + r, \qquad 0\le r < N.$$最终占用的位置为：$$a,\ a+1,\ldots,a+N-r-1,$$和$$a+N-r+1,\ldots,a+N.$$这让我们可以计算$Q_{\text{final}}$直接地。 

---

 ### 步骤 4：生成序列

 我们得到：$$t_0=123456$$和$$t_i= \begin{cases} t_{i-1}/2 & \text{if even}\\ \lfloor t_{i-1}/2\rfloor \oplus 926252 & \text{if odd} \end{cases}$$和$$b_i=(t_i\bmod 2^{11})+1.$$第一项是：$$b_1=289,\qquad b_2=145$$与声明相符。 

对于只有两个碗的示例，该公式准确给出$$3419100$$移动，验证正确性。 

---

 ## 2.Python实现```python
def generate_b(n=1500):
    t = 123456
    b = []

    for _ in range(n):
        if t % 2 == 0:
            t //= 2
        else:
            t = (t // 2) ^ 926252

        b.append((t % (2 ** 11)) + 1)

    return b

def sum_squares_arithmetic(start, length):
    """
    Sum of:
        start^2 + (start+1)^2 + ... + (start+length-1)^2
    """
    if length <= 0:
        return 0

    n = length
    return (
        n * start * start
        + 2 * start * (n * (n - 1) // 2)
        + (n - 1) * n * (2 * n - 1) // 6
    )

# Generate the 1500 bowls
b = generate_b(1500)

# Invariants
N = sum(b)
M = sum(i * x for i, x in enumerate(b))

# Initial quadratic moment
Q_initial = sum(i * i * x for i, x in enumerate(b))

# Determine final stable configuration
T = N * (N - 1) // 2
a = (M - T) // N
r = (M - T) % N

# Final occupied bowls:
# a, a+1, ..., a+N-r-1
# a+N-r+1, ..., a+N
left_count = N - r

Q_final = (
    sum_squares_arithmetic(a, left_count)
    + sum_squares_arithmetic(a + left_count + 1, r)
)

# Each move increases Q by exactly 2
moves = (Q_final - Q_initial) // 2

print(moves)
```---

 ## 3. 代码演练

 ### 生成序列

 我们计算$t_i$递归并转换为$$b_i=(t_i \bmod 2048)+1.$$这会产生：$$b_1=289,\quad b_2=145,$$匹配问题陈述。 

### 计算不变量

 我们计算：

 - 豆类总量：$$N=\sum b_i$$- 第一时刻：$$M=\sum i\,b_i$$- 初始二次矩：$$Q_{\text{initial}}$$### 构建最终配置

 我们解决：$$M-T=aN+r,$$在哪里$$T=\frac{N(N-1)}{2}.$$这决定了独特的稳定排列。 

### 计算移动次数

 因为每一步都会增加$Q$正好 2：$$\text{moves} = \frac{Q_{\text{final}}-Q_{\text{initial}}}{2}.$$对于样本$289,145$，这再现了：$$3419100.$$---
