[项目欧拉问题 97](https://projecteuler.net/problem=97)

 ## 解决方案

 **答案：**`8739992577`我们需要最后十位数字$$N = 28433 \times 2^{7830457} + 1.$$关键的观察是**只有最后十位数字重要**，所以我们应该计算所有内容的模数$$10^{10}.$$那是，$$N \bmod 10^{10} = \left(28433 \times 2^{7830457} + 1\right)\bmod 10^{10}.$$而不是尝试计算$2^{7830457}$直接（这是一个天文数字），我们使用**模幂**。 

### 步骤一：模运算原理

 对于整数$a,b,m$,$$(a\cdot b)\bmod m = ((a\bmod m)(b\bmod m))\bmod m.$$因此我们可以反复减少中间值模$10^{10}$。 

我们想要：$$2^{7830457}\pmod{10^{10}}.$$有效的方法是**二元幂**（也称为快速幂），它计算幂$O(\log n)$时间。 

Python 直接提供了这个：```python
pow(base, exponent, modulus)
```它计算$$\text{base}^{\text{exponent}} \bmod \text{modulus}$$有效地无需构造巨大的中间整数。 

---

 ## Python 实现```python
# Compute the last ten digits of:
# 28433 * 2^7830457 + 1

MOD = 10**10

# Efficient modular exponentiation
power_mod = pow(2, 7830457, MOD)

# Compute the final result modulo 10^10
result = (28433 * power_mod + 1) % MOD

print(result)
```---

 ### 最终模计算```python
result = (28433 * power_mod + 1) % MOD
```这评估：$$(28433 \times 2^{7830457} + 1)\bmod 10^{10}.$$这`% MOD`确保我们只保留最后十位数字。

 ## 理智的小例子

 假设我们想要以下的最后五位数字：$$3\times2^{10}+1.$$自从：$$2^{10}=1024,$$我们得到：$$3\times1024+1=3073.$$模数$100000$，结果仍然是$3073$，确认该方法在可管理的情况下行为正确。

 ## 最终验证

 - 这个数字是奇数，因为$2^{7830457}$是偶数，乘以$28433$保持均匀，并添加$1$让人感觉很奇怪。 
- 因此，我们的最后一位数字应该以奇数结尾——这是一个有用的健全性检查。 
- 计算使用精确的模运算，因此不会发生精度损失。
