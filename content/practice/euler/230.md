[欧拉计划问题 230](https://projecteuler.net/problem=230)

 ## 解决方案

 **答案：**`850481152593119296`让

-$F_0=A$-$F_1=B$-$F_n=F_{n-1}F_{n-2}$为了$n\ge2$其中并置意味着串联。 

我们被要求计算这个类似斐波那契的单词系统中的数字。 

这两个 100 位数字的字符串是：$$A= 14159265358979323846264338327950288419716939937510 58209749445923078164062862089986280348253421170679$$

$$B= 82148086513282306647093844609550582231725359408128 48111745028410270193852110555964462294895493038196$$我们必须评估$$\sum_{n=0}^{17}10^n\,D_{A,B}((127+19n)7^n)$$在哪里$D_{A,B}(m)$是$m$- 第一个斐波那契字中的第一个数字足够长以包含位置$m$。 

---

 # 1.数学分析

 ## 斐波那契字长

 让$L_n=|F_n|$，长度$n$-第一个词。 

由于串联会增加长度，$$L_n=L_{n-1}+L_{n-2}$$和$$L_0=L_1=100$$因此$$L_n=100F_{n+1}$$在哪里$F_k$是普通的斐波那契数。 

所以长度增长很快。 

---

 ## 递归定位数字

 假设我们想要$m$第 - 位数字。 

选择最小的$k$这样$$L_k \ge m.$$因为$$F_k = F_{k-1}F_{k-2},$$第一个$L_{k-1}$数字来自$F_{k-1}$，其余数字来自$F_{k-2}$。 

因此：

 - 如果$m \le L_{k-1}$，数字位于里面$F_{k-1}$;
 - 否则它就在里面$F_{k-2}$在位置$$m-L_{k-1}.$$这给出了递归减少：$$(k,m)\to \begin{cases} (k-1,m), & m\le L_{k-1}\\[4pt] (k-2,m-L_{k-1}), & m>L_{k-1} \end{cases}$$最终我们达到：

 -$k=0$: 数字在$A$,
 -$k=1$: 数字在$B$。 

这避免了构造巨大的字符串。

 # 2.Python实现```python
A = (
    "14159265358979323846264338327950288419716939937510"
    "58209749445923078164062862089986280348253421170679"
)

B = (
    "82148086513282306647093844609550582231725359408128"
    "48111745028410270193852110555964462294895493038196"
)

# ---------------------------------------------------------
# Precompute Fibonacci-word lengths
# ---------------------------------------------------------

lengths = [100, 100]

while lengths[-1] < 10**18:
    lengths.append(lengths[-1] + lengths[-2])

# ---------------------------------------------------------
# Compute D_A,B(n)
# ---------------------------------------------------------

def D(n):
    """
    Return the nth digit (1-indexed) in the first Fibonacci
    word whose length is at least n.
    """

    # Find smallest k with lengths[k] >= n
    k = 0
    while lengths[k] < n:
        k += 1

    # Reduce recursively without building strings
    while k > 1:

        # F_k = F_{k-1} + F_{k-2}

        if n <= lengths[k - 2]:
            k -= 2
        else:
            n -= lengths[k - 2]
            k -= 1

    # Base cases
    if k == 0:
        return int(A[n - 1])
    else:
        return int(B[n - 1])

# ---------------------------------------------------------
# Evaluate the required sum
# ---------------------------------------------------------

answer = 0

for n in range(18):
    N = (127 + 19 * n) * (7 ** n)
    answer += (10 ** n) * D(N)

print(answer)
```---
