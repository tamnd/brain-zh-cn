[欧拉项目问题 140](https://projecteuler.net/problem=140)

 ## 解决方案

 **答案：**`5673835352990`让$$A_G(x)=\sum_{k\ge1} G_k x^k,$$在哪里$$G_k=G_{k-1}+G_{k-2},\qquad G_1=1,\;G_2=4.$$我们寻找所有正整数$n$这样$$A_G(x)=n$$对于一些理性的$x$。 这些整数就是“金块”。 

---

 # 步骤 1 — 找到生成函数

 因为$G_k$满足斐波那契型递推，其生成函数是有理数。 

写$$A(x)=x+4x^2+5x^3+9x^4+\cdots.$$使用递归$G_k=G_{k-1}+G_{k-2}$,$$A(x)-x-4x^2 =\sum_{k\ge3}(G_{k-1}+G_{k-2})x^k.$$分割总和：$$=\sum_{k\ge3}G_{k-1}x^k+\sum_{k\ge3}G_{k-2}x^k.$$因素：$$=x\sum_{k\ge3}G_{k-1}x^{k-1} +x^2\sum_{k\ge3}G_{k-2}x^{k-2}.$$认识生成函数：$$=x(A(x)-x)+x^2A(x).$$因此$$A(x)-x-4x^2=xA(x)-x^2+x^2A(x).$$重新排列：$$A(x)(1-x-x^2)=x+3x^2.$$所以$$A(x)=\frac{x+3x^2}{1-x-x^2}.$$---

 # 步骤 2 — 施加金块条件

 假设$$A(x)=n$$和$n\in\mathbb N$。 

然后$$n=\frac{x+3x^2}{1-x-x^2}.$$叉乘：$$n(1-x-x^2)=x+3x^2.$$扩张：$$n-nx-nx^2=x+3x^2.$$把一切都放在一边：$$(n+3)x^2+(n+1)x-n=0.$$为了$x$为了有理数，判别式必须是完全平方数：$$(n+1)^2+4n(n+3).$$计算：$$= n^2+2n+1+4n^2+12n =5n^2+14n+1.$$因此我们需要整数解$$m^2=5n^2+14n+1.$$完成正方形$n$:$$5n^2+14n+1 =5\left(n+\frac75\right)^2-\frac{44}{5}.$$乘以$5$:$$5m^2=(5n+7)^2-44.$$因此$$(5n+7)^2-5m^2=44.$$让$$u=5n+7.$$然后我们得到Pell型方程$$u^2-5m^2=44.$$每个正解都会给出一个金块$$n=\frac{u-7}{5}.$$---

 # 第 3 步 — 生成解决方案

 积极的金块序列开始$$2,5,21,42,152,296,\dots$$事实上，问题表明$20$-这$211345365$。 

这些解满足由佩尔方程导出的线性递推。 掘金的一种方便的重现是：$$a_k = 7a_{k-2}-a_{k-4}+7,$$但在计算上最简单的方法是迭代 Pell 解。 

按升序生成所有正块的标准递归是：$$\begin{aligned} u' &= 9u+20m,\\ m' &= 4u+9m. \end{aligned}$$从基本的积极解决方案开始，就会产生金块。 

---

 # 第 4 步 — Python 实现```python
from math import isqrt

# We solve:
#   u^2 - 5m^2 = 44
# and golden nuggets are:
#   n = (u - 7) // 5
#
# Pell transformation:
#   u' = 9u + 20m
#   m' = 4u + 9m

# Fundamental positive solutions producing nuggets
seeds = [
    (17, 7),
    (32, 14),
    (112, 50),
    (217, 97),
    (767, 343),
    (1487, 665),
]

nuggets = set()

for u, m in seeds:
    # Generate enough terms from each branch
    for _ in range(10):
        n = (u - 7) // 5

        # Verify integrality and Pell equation
        if (u - 7) % 5 == 0 and u*u - 5*m*m == 44:
            if n > 0:
                nuggets.add(n)

        # Pell recurrence
        u, m = 9*u + 20*m, 4*u + 9*m

# Take first 30 nuggets
nuggets = sorted(nuggets)

answer = sum(nuggets[:30])

print(nuggets[:30])
print(answer)
```---
