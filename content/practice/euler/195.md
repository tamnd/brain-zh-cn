[项目欧拉问题 195](https://projecteuler.net/problem=195)

 ## 解决方案

 **答案：**`75085391`设三角形各边为$a,b,c$，并假设$60^\circ$角是对边$c$。 

根据余弦定律，$$c^2=a^2+b^2-ab.$$我们必须用 1 来计算所有整数解$60^\circ$角度和半径$r\le n$。 

---

 # 1.数学分析

 ## 步骤 1：参数化所有$60^\circ$-三角形

 二次形式$$a^2-ab+b^2$$是爱森斯坦整数的范数形式，以及$$c^2=a^2-ab+b^2$$由互质整数参数化$m>n>0$。 

标准参数化是$$\begin{aligned} a &= d(m^2-n^2),\\ b &= d(2mn-n^2),\\ c &= d(m^2-mn+n^2), \end{aligned}$$和$\gcd(m,n)=1$。 

然而：

 - 如果$m+n\not\equiv0\pmod3$，这个三元组是原始的；
 - 如果$m+n\equiv0\pmod3$，每条边都可以被整除$3$，除以之后$3$我们获得了另一个原始家庭。 

避免对同一个三角形进行两次计数（因为替换$n$经过$m-n$给出相同的三角形），我们强加$$m>2n.$$---

 ## 步骤 2：内半径公式

 有夹角的三角形的面积$60^\circ$是$$\Delta=\frac{\sqrt3}{4}ab.$$内半径满足$$\Delta = rs,$$在哪里$s$是半周长。 

替换参数化并简化得到：

 ### 家庭A：$m+n\not\equiv0\pmod3$

$$r=\frac{\sqrt3}{2}d\,n(m-n).$$因此$$d\le \frac{2N}{\sqrt3\,n(m-n)}.$$贡献：$$\left\lfloor \frac{2N}{\sqrt3\,n(m-n)} \right\rfloor.$$---

 ### B 家庭：$m+n\equiv0\pmod3$将原始三元组除以$3$,$$r=\frac{\sqrt3}{6}d\,n(m-n).$$因此$$d\le \frac{6N}{\sqrt3\,n(m-n)} = \frac{2\sqrt3\,N}{n(m-n)}.$$贡献：$$\left\lfloor \frac{2\sqrt3\,N}{n(m-n)} \right\rfloor.$$---

 ## 第三步：最终计数公式

 因此$$T(N)= \sum_{\substack{m>2n\\ \gcd(m,n)=1}} \begin{cases} \left\lfloor\dfrac{2N}{\sqrt3\,n(m-n)}\right\rfloor, & m+n\not\equiv0\pmod3,\\[1.5ex] \left\lfloor\dfrac{2\sqrt3\,N}{n(m-n)}\right\rfloor, & m+n\equiv0\pmod3. \end{cases}$$这运行得很快，因为$$n(m-n)\le 2\sqrt3\,N.$$---

 # 2.Python实现```python
from math import gcd, sqrt

def T(N):
    # Bounds appearing in the counting formulas
    limit1 = 2 * N / sqrt(3)
    limit2 = 2 * sqrt(3) * N

    max_k = int(limit2)

    total = 0

    # We need:
    #   k = n(m-n) <= max_k
    #
    # Since m > 2n, we iterate efficiently.

    for n in range(1, max_k + 1):

        # From n(m-n) <= max_k:
        #     m <= max_k/n + n
        m_max = max_k // n + n

        # m > 2n avoids duplicate triangles
        for m in range(2 * n + 1, m_max + 1):

            if gcd(m, n) != 1:
                continue

            k = n * (m - n)

            if k > max_k:
                break

            # Family B
            if (m + n) % 3 == 0:
                total += int(limit2 // k)

            # Family A
            else:
                total += int(limit1 // k)

    return total

# Verification against the problem statement
print(T(100))     # 1234
print(T(1000))    # 22767
print(T(10000))   # 359912

# Required answer
print(T(1053779))
```---

 ## 外循环结束$n$

 ## 前往$m$从$$n(m-n)\le \text{max}_k,$$我们得出$$m \le \frac{\text{max}_k}{n}+n.$$因此：```python

```---

限制于$m>2n$每个只计数一次。
