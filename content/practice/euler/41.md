[项目欧拉问题 41](https://projecteuler.net/problem=41)

 ## 解决方案

 **答案：**`7652413`## 1.数学分析

 我们想要**最大的泛数字素数**，其中$n$-digit 泛数字使用每个数字$1$到$n$正好一次。 

例如：$$2143$$是$4$- 数字泛数字和素数。 

天真的想法是：

 - 生成所有泛数字，
 - 检查素数，
 - 取最大值。 

但使用数论我们可以做得更好。 

### 关键见解 1：能被 3 整除

 一个数可以被$3$当且仅当其数字之和能被整除$3$。 

对于一个$n$-digit 泛数字，其数字和为：$$1+2+\cdots+n=\frac{n(n+1)}{2}$$让我们检查一下值$n$:$$n=9:\quad \frac{9\cdot10}{2}=45$$可除以$3$，所以**每个9位泛数字都可以被3整除** → 不可能是质数。$$n=8:\quad \frac{8\cdot9}{2}=36$$也可除以$3$→ **每个 8 位泛数字都是合数**。$$n=7:\quad \frac{7\cdot8}{2}=28$$不能整除$3$，因此 7 位泛数字素数**可能存在**。 

因此，最大的泛数字素数必须是 **7 位或更小**。 

我们只需要在以下排列中搜索：$$1,2,3,4,5,6,7$$### 关键见解2：按降序搜索

 我们想要**最大的**这样的素数。 

不是生成所有泛数字并取最大值，而是按**降序字典顺序**生成排列并在找到的第一个素数处停止。 

这保证了最优性。 

### 关键见解 3：快速素性测试

 测试是否有一个数$n$是质数：

 - 拒绝$n < 2$,
 - 拒绝偶数，
 - 仅尝试除数：$$\sqrt{n}$$因为如果$n = ab$, 最多只能有一个因素$\sqrt{n}$。 

因此，对于每个候选者，测试是否能被奇数整除：$$\lfloor \sqrt{n} \rfloor$$因为只有：$$7! = 5040$$7位排列，蛮力很小。

 ## 2.Python实现```python
from itertools import permutations
import math

def is_prime(n):
    """Return True if n is prime, otherwise False."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = int(math.isqrt(n))

    # Check odd divisors only
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False

    return True

def largest_pandigital_prime():
    # Try n from largest to smallest
    for n in range(9, 0, -1):

        # Skip digit lengths whose digit sum is divisible by 3
        digit_sum = n * (n + 1) // 2
        if digit_sum % 3 == 0:
            continue

        digits = ''.join(str(i) for i in range(n, 0, -1))

        # Generate permutations in descending order
        for perm in permutations(digits):
            number = int(''.join(perm))

            if is_prime(number):
                return number

answer = largest_pandigital_prime()
print(answer)
```---

 ## 4.最终验证

 我们证明：

 - 8 位和 9 位泛数字是不可能的，因为数字和可以被 3 整除。 
- 因此答案必须是 7 位数字。 
- 我们按降序搜索所有 7 位泛数字。 
- 遇到的第一个素数是：$$7652413$$检查：

 - 使用数字$1$–$7$恰好一次 ✓
 - 奇数且不能被 3 整除 ✓
 - 总理 ✓
 - 按降序搜索最大 ✓
