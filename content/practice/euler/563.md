[项目欧拉问题 563](https://projecteuler.net/problem=563)

 ## 解决方案

 **答案：**`27186308211734760`让可构造的矩形具有边长$a$和$b$。 

每个焊接步骤需要$k$相同的矩形（$2 \le k \le 25$）并沿一侧焊接它们，将一侧长度正好乘以$k$。 

因此，每个可构造边长都是数字的乘积$\le 25$，即一个数字，其素因数都在$$2,3,5,7,11,13,17,19,23.$$所以可构造的边长正是 **23 光滑数**。 

---

 # 数学分析

 我们必须计算每个可建造的面积$A$，因式分解的数量$$A = xy$$这样

 -$x,y$是 23 光滑的，
 -$x \le y$,
 -$y \le 1.1x$。 

该计数就是“变体”的数量。 

我们定义：$$M(n)=\text{smallest constructible area with exactly } n \text{ variants}.$$我们得到：$$M(3)=889200.$$的确，$$889200 =900\cdot 988 =912\cdot 975 =936\cdot 950,$$每条边长都是 23 光滑。 

---

 ## 生成所有可构建区域

 每个可构造区域也是 23 光滑的，因为$$A = xy$$与两者$x$和$y$23-顺利。 

因此所有相关区域都是由素数生成的$$\{2,3,5,7,11,13,17,19,23\}.$$标准的基于堆的“汉明数”生成算法按升序枚举所有此类数字。 

---

 ## 计算一个区域的变体

 假设当前区域是$A$。 

我们搜索所有可能的短边$x$满意的$$x \le \sqrt{A}.$$然后$$y=\frac{A}{x}.$$10%的条件变为$$\frac{y}{x}\le \frac{11}{10}$$或同等地$$10y \le 11x.$$所以对于每一个 23-smooth$x$靠近$\sqrt{A}$，我们检查：

 1.$x \mid A$,
 2.$10(A/x)\le 11x$。 

成功检查的数量就是变体的数量。 

我们继续直到所有$M(2),M(3),\dots,M(100)$被发现。 

---

 # Python 实现```python
import heapq
import math
from bisect import bisect_right

# Allowed primes (all primes <= 25)
PRIMES = [2, 3, 5, 7, 11, 13, 17, 19, 23]

# Upper bound known to exceed M(100)
LIMIT = 2300000000000000

# solutions[n] = M(n)
solutions = [0] * 101

# Number of distinct M(n) already found
found = 1  # M(1) is irrelevant

# Final sum
answer = 0

# Min-heap generating all 23-smooth numbers
heap = [1]

# All generated smooth numbers that can serve as side lengths
sides = []

while found < 100:

    current = heapq.heappop(heap)

    # Store as a possible side length
    if current * current <= LIMIT:
        sides.append(current)

    # Generate larger smooth numbers
    for p in reversed(PRIMES):
        nxt = current * p

        if nxt <= LIMIT:
            heapq.heappush(heap, nxt)

        # Avoid duplicates
        if current % p == 0:
            break

    # Small optimisations observed experimentally
    if found >= 56:
        if current % 800 != 0:
            continue
    elif found >= 8:
        if current % 80 != 0:
            continue
    else:
        if current % 40 != 0:
            continue

    # Count variants
    count = 0

    # Largest possible short side
    idx = bisect_right(sides, int(math.isqrt(current))) - 1

    while idx > 0:
        short_side = sides[idx]
        idx -= 1

        long_side = current // short_side

        # Ratio exceeded 10%
        if long_side * 10 > short_side * 11:
            break

        # Exact divisor?
        if long_side * short_side == current:
            count += 1

    # We only care about 2..100
    if not (2 <= count <= 100):
        continue

    # First occurrence => minimal area
    if solutions[count] == 0:
        solutions[count] = current
        answer += current
        found += 1

print(answer)
```---

 # 代码演练

 ## 堆生成```python
heap = [1]
```我们按升序生成所有 23 平滑数。 

对于每个提取的数字`current`，我们乘以允许的素数。 

条件```python
if current % p == 0:
    break
```确保每个平滑数恰好生成一次。 

---

 ## 边长```python
sides.append(current)
```每个 23 光滑数都可以是一个矩形边。 

我们自动按排序顺序维护它们，因为堆发出的数字越来越多。 

---

 ## 计算有效矩形

 对于面积`current`：```python
short_side <= sqrt(current)
```和```python
long_side = current // short_side
```我们强制执行：```python
long_side * 10 <= short_side * 11
```这正是“10%以内”的条件。 

如果另外```python
long_side * short_side == current
```然后我们找到了一个有效的变体。
