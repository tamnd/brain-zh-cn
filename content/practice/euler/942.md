[欧拉项目 942 问题](https://projecteuler.net/problem=942)

 ## 解决方案

 **答案：**`557539756`让$$p = 2^q-1$$和$q=74\,207\,281$， 和$p$主要的。 

我们寻求最小正解$$x^2 \equiv q \pmod p.$$对于梅森素数，$2$有订单$q$模数$p$，所以$q$统一的第 根$\mathbb F_p$是$$1,2,2^2,\dots,2^{q-1}.$$经典的二次高斯和恒等式给出，对于$q\equiv1\pmod4$,$$G=\sum_{a=0}^{q-1}\left(\frac aq\right)2^a$$满意的$$G^2=q.$$自从$$\left(\frac 0q\right)=0, \qquad \left(\frac aq\right)= \begin{cases} 1 & a \text{ quadratic residue mod } q,\\ -1 & \text{otherwise}, \end{cases}$$我们可以重写：$$G = 1+2\sum_{r\in QR(q)}2^r \pmod p,$$在哪里$QR(q)$是非零二次余数模的集合$q$。 

为了$q\equiv1\pmod8$（这里正确），这个高斯和是_larger_平方根，所以$$R(q)=p-G.$$因此$$R(q) = 2^{q+1}-3 - 2\sum_{r\in QR(q)}2^r.$$我们只需要这个模$M=10^9+7$，因此所有计算均以模进行$M$。 

直接一个$O(q)$计算是可行的。 

Python代码：```python
q = 74207281
MOD = 10**9 + 7

# mark quadratic residues mod q
qr = bytearray(q)
half = (q - 1) // 2

for i in range(1, half + 1):
    qr[(i * i) % q] = 1

s = 0
p2 = 2

for r in range(1, q):
    if qr[r]:
        s = (s + p2) % MOD
    p2 = (p2 * 2) % MOD

# p2 == 2^q mod MOD
ans = (2 * p2 - 3 - 2 * s) % MOD

print(ans)
```这评估为：
