[欧拉项目问题 247](https://projecteuler.net/problem=247)

 ## 解决方案

 **答案：**`782252`让一个区域$R(a,b)$被定义为$$x\ge a,\qquad y\ge b,\qquad y\le \frac1x,$$角落在哪里$(a,b)$位于双曲线下方$xy=1$。 

在这样的区域内，最大的轴对齐正方形具有左下角$(a,b)$和边长$s$由其右上角位于曲线上的条件确定：$$(a+s)(b+s)=1.$$扩大，$$s^2 + (a+b)s + ab - 1 = 0.$$取正根，$$s(a,b)=\frac{\sqrt{(a-b)^2+4}-(a+b)}{2}.$$对于原来的问题，我们从$$(a,b)=(1,0).$$第一个广场$S_1$因此有一面$$s=\frac{\sqrt5-1}{2}.$$---

 # 递归结构

 放置一个正方形的边后$s$在$R(a,b)$，仍然存在两个不相交的区域：

 - **右侧**的区域：$$R(a+s,b),$$- **以上**区域：$$R(a,b+s).$$如果当前方格有索引$(L,B)$，那么：

 - 右孩子有索引$(L+1,B)$,
 - 上面的孩子有索引$(L,B+1)$。 

因此，每个方块对应于向右/向上移动的路径。 

例如，索引$(3,3)$对应于恰好包含三个权利和三个向上的所有路径，因此有$$\binom63 = 20$$总共有这样的正方形。 

---

 # 正方形的排序

 正方形通过边长递减进行全局编号。 

因此：

 - 按边长降序生成正方形，
 - 每当有索引的方块$(3,3)$出现，记录其位置$n$,
 - 最大的此类$n$就是答案。 

优先级队列（最大堆）是理想的选择。 

---

 # Python 实现```python
from heapq import heappush, heappop
from math import sqrt, comb

def side(a, b):
    """
    Side length of the largest square that fits in region R(a,b).
    Derived from:
        (a+s)(b+s) = 1
    """
    return (sqrt((a - b) ** 2 + 4) - (a + b)) / 2

def solve(target=(3, 3)):
    # Number of squares having this index
    needed = comb(target[0] + target[1], target[0])

    # Max-heap implemented with negative sizes
    pq = []

    # Initial region R(1,0)
    s0 = side(1.0, 0.0)

    # heap item = (-side, a, b, left, below)
    heappush(pq, (-s0, 1.0, 0.0, 0, 0))

    n = 0
    found = []

    smallest_target_size = float("inf")

    while pq:
        neg_s, a, b, left, below = heappop(pq)
        s = -neg_s

        n += 1

        # Record squares with desired index
        if (left, below) == target:
            found.append((n, s))
            smallest_target_size = min(smallest_target_size, s)

            # Once all target squares are found,
            # we can stop when remaining squares are smaller
            if len(found) == needed:
                if -pq[0][0] < smallest_target_size:
                    break

        # Generate right child
        sr = side(a + s, b)
        heappush(pq, (-(sr), a + s, b, left + 1, below))

        # Generate upper child
        su = side(a, b + s)
        heappush(pq, (-(su), a, b + s, left, below + 1))

    return found[-1][0]

answer = solve((3, 3))
print(answer)
```---

 # 代码演练

 ## 1.`side(a,b)`计算区域内最大的平方拟合$R(a,b)$:$$(a+s)(b+s)=1.$$正二次根给出边长。 

---

 ## 2.优先级队列

 我们总是首先删除当前最大的正方形，以匹配问题的编号顺序。 

每个堆项存储：```python
(-side, a, b, left, below)
```在哪里：

-`(a,b)`识别区域，
 -`(left, below)`是正方形的索引。 

---

 ## 3. 子区域

 放置正方形后：```python
(a+s, b)     # right region
(a, b+s)     # upper region
```他们的指数变为：```python
(left+1, below)
(left, below+1)
```---

 ## 4. 停止标准

 对于索引$(3,3)$，正好有$$\binom63 = 20$$可能的正方形。 

一旦找到所有 20 个，并且堆中剩余的最大方格小于已找到的最小目标方格，则不再需要额外的$(3,3)$正方形可以稍后出现。 

---

 # 样本验证

 为目标运行相同的代码$(1,1)$给出：$$50$$匹配语句：

 > “50是最大的$n$其索引是$(1,1)$”。

 至此算法得到验证。

 # 最终验证

 计算正好找到 20 个索引的平方$(3,3)$，最后一个出现在：$$n = 782252.$$这与在最小的正方形之前生成的较大正方形的数量快速增长是一致的。$(3,3)$出现配置。 

**答案：782252**
