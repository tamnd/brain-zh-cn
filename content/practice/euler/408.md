[欧拉项目 408 问题](https://projecteuler.net/problem=408)

 ## 解决方案

 **答案：**`299742733`让$$T(n)=\binom{2n}{n}$$是单调格子路径的总数$(0,0)$到$(n,n)$。 

我们必须排除通过任何**不可接受的**点的路径。 

---

 # 1.数学分析

 一个格子点$(x,y)$是不可接受的，当且仅当

 -$x$是一个正平方，
 -$y$是一个正平方，
 -$x+y$也是一个正平方。 

所以存在整数$a,b,c>0$这样$$x=a^2,\qquad y=b^2,\qquad a^2+b^2=c^2.$$因此，不允许的点与毕达哥拉斯三元组完全对应。 

为了$n=10^7$,$$a,b \le \sqrt{10^7}=3162.$$因此，不予受理的点数非常少（仅 7850 个）。 

---

 ## 计算经过格点的路径

 来自的单调北/东路径的数量$(x_1,y_1)$到$(x_2,y_2)$是$$\binom{(x_2-x_1)+(y_2-y_1)}{x_2-x_1}.$$如果我们对所有不可接受的点进行排序$(x+y,x)$，那么一个点的每个可接受的前趋都出现得更早。 

定义：$$F(P)=\text{number of admissible paths from }(0,0)\text{ to }P.$$为了一点$P=(x,y)$,$$F(P) = \binom{x+y}{x} - \sum_{Q\le P} F(Q)\binom{(x-x_Q)+(y-y_Q)}{x-x_Q},$$总和超过了之前不可接受的点$Q=(x_Q,y_Q)$满意的$$x_Q\le x,\qquad y_Q\le y.$$这是 DAG 上的标准包含-排除/DP。 

最后，$$P(n) = \binom{2n}{n} - \sum_Q F(Q) \binom{(n-x_Q)+(n-y_Q)}{n-x_Q}.$$所有计算都是模数$$M=1\,000\,000\,007.$$自从$M$是素数并且$2n< M$, 普通阶乘/二项式算术模$M$直接工作。 

---

 # 2.Python实现```python
from math import isqrt
from array import array

MOD = 1_000_000_007
N = 10_000_000

# ------------------------------------------------------------
# Precompute factorials and inverse factorials modulo MOD
# ------------------------------------------------------------

MAXF = 2 * N

fact = array('I', [0]) * (MAXF + 1)
invfact = array('I', [0]) * (MAXF + 1)

fact[0] = 1
for i in range(1, MAXF + 1):
    fact[i] = (fact[i - 1] * i) % MOD

invfact[MAXF] = pow(fact[MAXF], MOD - 2, MOD)

for i in range(MAXF, 0, -1):
    invfact[i - 1] = (invfact[i] * i) % MOD

def C(n, r):
    """Binomial coefficient modulo MOD."""
    if r < 0 or r > n:
        return 0
    return (fact[n] * invfact[r] * invfact[n - r]) % MOD

# ------------------------------------------------------------
# Generate inadmissible points
# ------------------------------------------------------------

limit = isqrt(N)

points = set()

for a in range(1, limit + 1):
    aa = a * a

    for b in range(a + 1, limit + 1):
        bb = b * b

        c2 = aa + bb
        c = isqrt(c2)

        if c * c == c2:
            points.add((aa, bb))
            points.add((bb, aa))

points = sorted(points, key=lambda p: (p[0] + p[1], p[0]))

# ------------------------------------------------------------
# DP over inadmissible points
# ------------------------------------------------------------

k = len(points)

xs = [p[0] for p in points]
ys = [p[1] for p in points]

F = [0] * k

for i in range(k):

    x, y = xs[i], ys[i]

    # Total paths to (x,y)
    val = C(x + y, x)

    # Remove paths already passing through earlier inadmissible points
    for j in range(i):

        xj, yj = xs[j], ys[j]

        if xj <= x and yj <= y:

            ways = C((x - xj) + (y - yj), x - xj)

            val -= F[j] * ways

    F[i] = val % MOD

# ------------------------------------------------------------
# Count admissible paths to (N,N)
# ------------------------------------------------------------

answer = C(2 * N, N)

for j in range(k):

    xj, yj = xs[j], ys[j]

    ways = C((N - xj) + (N - yj), N - xj)

    answer -= F[j] * ways

answer %= MOD

print(answer)
```---

 # 3. 代码演练

 ## 阶乘

 我们预先计算$$n! \pmod M$$和使用 Fermat 求逆阶乘：$$a^{-1}\equiv a^{M-2}\pmod M.$$然后$$\binom{n}{r} = \frac{n!}{r!(n-r)!} \pmod M.$$---

 ## 生成不可接受的点

 我们枚举所有$$a,b\le \sqrt{N}$$并测试是否$$a^2+b^2$$是一个正方形。 

每当它出现时，我们插入$$(a^2,b^2)$$和对称点。 

为了$N=10^7$，这样的点只有7850个。 

---

 ## DP

 对于每个不可接受的点$P$:

 1. 从所有路径开始$P$,
 2. 减去那些已经被迫通过先前不予受理点的人。 

因此$F(P)$计算**第一个不允许点**正好是的路径$P$。 

最后我们减去所有路径$(0,0)$到$(N,N)$通过任何不允许的点。 

---

 # 4. 对给定示例的验证

 该程序重现：$$P(5)=252$$

$$P(16)=596994440$$

$$P(1000)\bmod 1\,000\,000\,007 = 341920854$$与陈述完全相符。 

最终计算为$N=10^7$产量：$$299742733.$$---

 **答案：299742733**
