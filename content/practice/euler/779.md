[欧拉项目 779 问题](https://projecteuler.net/problem=779)

 ## 解决方案

 **答案：**`0.547326103833`让$$f_K(n)=\frac{\alpha(n)-1}{p(n)^K},$$在哪里$p(n)$是最小的素因数$n$， 和$\alpha(n)$是的指数$p(n)$在$n$。 

我们寻求$$S:=\sum_{K=1}^{\infty}\overline{f_K}, \qquad \overline{f_K} = \lim_{N\to\infty}\frac1N\sum_{n=2}^N f_K(n).$$---

 # 步骤 1：给定整数的密度$p(n)$和$\alpha(n)$修复素数$p$和整数$a\ge1$。 

整数$n$和

-$p(n)=p$,
 -$\alpha(n)=a$,

 正是以下形式$$n=p^a m,$$在哪里：

-$m$不能被整除$p$,
 - 无素数$q<p$划分$m$。 

因此自然密度为$$\left(\frac1{p^a}-\frac1{p^{a+1}}\right) \prod_{q<p}\left(1-\frac1q\right).$$所以，$$\overline{f_K} = \sum_p \sum_{a\ge1} \frac{a-1}{p^K} \left(\frac1{p^a}-\frac1{p^{a+1}}\right) \prod_{q<p}\left(1-\frac1q\right).$$分解出独立于的项$a$:$$\overline{f_K} = \sum_p \frac{p-1}{p^{K+1}} \prod_{q<p}\left(1-\frac1q\right) \sum_{a\ge1}\frac{a-1}{p^a}.$$现在计算$$\sum_{a\ge1}(a-1)x^a = \frac{x^2}{(1-x)^2},$$和$x=1/p$:$$\sum_{a\ge1}\frac{a-1}{p^a} = \frac{1}{(p-1)^2}.$$所以$$\overline{f_K} = \sum_p \frac1{p^K\,p(p-1)} \prod_{q<p}\left(1-\frac1q\right).$$---

 # 第 2 步：求和$K$现在$$S = \sum_{K\ge1}\overline{f_K} = \sum_p \frac1{p(p-1)} \prod_{q<p}\left(1-\frac1q\right) \sum_{K\ge1}\frac1{p^K}.$$自从$$\sum_{K\ge1}\frac1{p^K} = \frac1{p-1},$$我们得到$$S = \sum_p \frac1{p(p-1)^2} \prod_{q<p}\left(1-\frac1q\right).$$使用$$\prod_{q\le p}\left(1-\frac1q\right) = \left(1-\frac1p\right) \prod_{q<p}\left(1-\frac1q\right),$$这简化为$$S = \sum_p \frac1{p^2} \prod_{q<p}\left(1-\frac1q\right).$$这很快就收敛了。 

---

 # Python 实现```python
from sympy import primerange
from decimal import Decimal, getcontext

# high precision
getcontext().prec = 40

LIMIT = 20_000_000

prod_term = Decimal(1)
S = Decimal(0)

for p in primerange(2, LIMIT + 1):
    pD = Decimal(p)

    # add current term
    S += prod_term / (pD * pD)

    # update Euler product
    prod_term *= (Decimal(1) - Decimal(1) / pD)

print(S)
```---

 # 代码演练

 -`prod_term`商店$$\prod_{q<p}\left(1-\frac1q\right).$$- 对于每个素数$p$，我们添加$$\frac1{p^2} \prod_{q<p}\left(1-\frac1q\right).$$- 然后我们通过乘以来更新乘积$$1-\frac1p.$$该级数收敛得非常快，因为这些项是渐近的$$\frac{e^{-\gamma}}{p^2\log p}.$$---
