[项目欧拉问题 198](https://projecteuler.net/problem=198)

 ## 解决方案

 **答案：**`52374425`让我们准确地描述有理数何时_不明确_。 

假设两个约简分数$$\frac ab < \frac cd$$是连续的 Farey 邻居，即$$bc-ad=1.$$一个经典定理说，它们之间的每个有理数与分母$< b+d$距区间中任意点的距离都比其中一个端点的距离远。 特别是，两个端点同样接近的唯一点是中位区间中点$$x=\frac{\frac ab+\frac cd}{2}.$$数量$x$正是当$\frac ab$和$\frac cd$是连续的 Farey 分数，分母界是$b+d-1$。 那么两个端点都是最佳近似值。 

现在我们推导出模糊理性的确切形式。 

---

 # 1.数学分析

 让$$\frac ab < \frac cd,\qquad bc-ad=1.$$中点是$$x=\frac12\left(\frac ab+\frac cd\right)   =\frac{ad+bc}{2bd}.$$使用$bc-ad=1$,$$ad+bc = 2ad+1.$$因此$$x=\frac{2ad+1}{2bd}.$$现在计算 gcd：$$\gcd(2ad+1,\,2bd).$$自从$2ad+1$是奇数，任何公约数都必须整除$bd$。 但$$2ad+1 \equiv 1 \pmod d,$$和$$2ad+1 \equiv 1 \pmod b,$$因为$bc-ad=1\Rightarrow ad\equiv -1\pmod b$等。因此 gcd 是$1$。 所以每个不明确的数字都会减少分母$$q=2bd.$$相反，每个 Farey 邻居对都会产生一个不明确的数字。 

于是问题就变成了：

 计算 Farey 邻居对的数量$(a,b),(c,d)$这样$$bc-ad=1,$$

$$0<\frac{2ad+1}{2bd}<\frac1{100},$$

$$2bd\le 10^8.$$我们简化了不等式。 

自从$$\frac{2ad+1}{2bd}<\frac1{100},$$乘以：$$100(2ad+1)<2bd.$$使用$bc-ad=1\Rightarrow ad=bc-1$,$$100(2bc-1)<2bd.$$重新排列：$$200bc-100<2bd,$$

$$100c+\frac{-50}{b}<d.$$自从$b,d,c$是整数并且$b>0$,$$d>100c.$$所以条件正好是$$d>100c.$$行列式条件给出$$bc-ad=1.$$对于固定互质$b,d$，只有一个解$a,c$和$$0<c<b,$$即$$cd\equiv 1\pmod b.$$因此$c$是模逆$d$模组$b$。 

因此我们必须计算互质对$(b,d)$这样$$2bd\le 10^8,$$如果$c=d^{-1}\pmod b$和$1\le c<b$， 然后$$d>100c.$$---

 ## 关键对称技巧

 写$$d = kb + r,\qquad 1\le r<b,\qquad \gcd(r,b)=1.$$然后$$c \equiv r^{-1}\pmod b.$$条件变为$$kb+r > 100c.$$对于大型$k$，这自动成立。 

显着的简化来自双射$$r \leftrightarrow c=r^{-1}\pmod b.$$作为$r$通过减少残留物模式运行$b$，也是如此$c$。 因此对于固定的$b$, 在可受理的范围内$d$'是，满足的比例$d>100c$是渐进的$1/100$。 

但我们需要准确的计数。 

高效解决方案使用的更直接的推导是：

 对于每个互质对$(b,c)$, 全部有效$d$数字是否满足$$d \equiv c^{-1}\pmod b,$$

$$d>100c,$$

$$d\le \frac{10^8}{2b}.$$写$$d=d_0+tb,$$在哪里$d_0$是最小正逆数$c$模数$b$。 那么有效数量$d$是$$\max\left( 0,\; \left\lfloor \frac{10^8/(2b)-d_0}{b} \right\rfloor - \left\lfloor \frac{100c-d_0}{b} \right\rfloor \right).$$直接对所有互质求和$(b,c)$最多$b\le \sqrt{5\times10^7}\approx 7071$是可行的。

 # 2.Python实现```python
from math import gcd

LIMIT = 10**8
ans = 0

# Since 2*b*d <= LIMIT and d > b,
# we only need b up to sqrt(LIMIT/2)
BMAX = int((LIMIT // 2) ** 0.5) + 1

for b in range(1, BMAX + 1):

    max_d = LIMIT // (2 * b)

    for c in range(1, b):

        if gcd(b, c) != 1:
            continue

        # d0 = inverse of c modulo b
        d0 = pow(c, -1, b)

        # smallest d congruent to d0 mod b
        # and strictly greater than 100*c
        if d0 > 100 * c:
            first = d0
        else:
            t = (100 * c - d0) // b + 1
            first = d0 + t * b

        if first <= max_d:
            ans += (max_d - first) // b + 1

print(ans)
```---

 ## 小例子验证
