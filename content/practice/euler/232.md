[欧拉项目问题 232](https://projecteuler.net/problem=232)

 ## 解决方案

 **答案：**`0.83648556`让

-$P(a,b)$= 当轮到**玩家 1 的回合**时，玩家 2 最终获胜的概率（得分）$$\text{Player 1}=a,\qquad \text{Player 2}=b.$$-$Q(a,b)$= 当**玩家 2 回合**时，玩家 2 最终获胜的概率。 

如果任一玩家到达，游戏立即结束$100$点：$$P(a,b)=Q(a,b)=0 \quad (a\ge 100),$$

$$P(a,b)=Q(a,b)=1 \quad (b\ge 100).$$我们寻求$$P(0,0).$$---

 # 1.数学分析

 ## 玩家 1 的动作

 玩家 1 掷一枚公平的硬币。 

- 头（$\frac12$)：玩家 1 获得 1 分。 
- 尾巴 ($\frac12$）：没有意义。 

之后就轮到玩家 2 了。 

所以$$P(a,b)=\frac12\,Q(a+1,b)+\frac12\,Q(a,b).$$---

 ## 玩家 2 的动作

 玩家 2 选择一个整数$T\ge1$。 

他抛硬币$T$次。 

- 所有正面的概率：$$2^{-T}.$$- 如果成功，他将获得$$2^{T-1}$$点。 
- 否则他什么也得不到。 

玩家 2 移动后，又轮到玩家 1 移动。 

因此，对于固定的$T$,$$Q_T(a,b) = 2^{-T} P(a,b+2^{T-1}) + (1-2^{-T})P(a,b).$$由于玩家 2 总是发挥最佳状态，$$Q(a,b)=\max_{T\ge1} Q_T(a,b).$$---

 # 消除相互递归

 替补$$P(a,b)=\frac12Q(a+1,b)+\frac12Q(a,b)$$代入公式为$Q_T$。 

让$$p=2^{-T},\qquad g=2^{T-1}.$$然后$$Q_T(a,b) = p\,P(a,b+g)+(1-p)P(a,b).$$还，$$P(a,b) = \frac12Q(a+1,b)+\frac12Q(a,b).$$替换：$$Q_T(a,b) = p\,P(a,b+g) + (1-p)\left(\frac12Q(a+1,b)+\frac12Q_T(a,b)\right).$$求解$Q_T(a,b)$:$$Q_T(a,b)\left(1-\frac12(1-p)\right) = p\,P(a,b+g)+\frac12(1-p)Q(a+1,b).$$因此$$Q_T(a,b) = \frac{ p\,P(a,b+g)+\frac12(1-p)Q(a+1,b) }{ 1-\frac12(1-p) }.$$我们为所有状态动态计算这一点。 

---

 # 为什么只有小$T$价值观很重要

 最大有用的奖励是第一个可以立即赢得比赛的奖励。 

由于目标是$100$,$$2^{T-1}\ge100$$已经保证了胜利。 

最小的这样$T$是$8$因为$$2^7=128.$$所以检查$T=1,\dots,8$就足够了。 

---

 # 2.Python实现```python
N = 100

# P[a][b] = probability Player 2 wins
#           when it is Player 1's turn
#
# Q[a][b] = probability Player 2 wins
#           when it is Player 2's turn

P = [[0.0 for _ in range(N + 129)] for _ in range(N + 1)]
Q = [[0.0 for _ in range(N + 129)] for _ in range(N + 1)]

# Terminal states:
# If Player 2 already has >=100 points, he has won.
for a in range(N + 1):
    for b in range(100, N + 129):
        P[a][b] = 1.0
        Q[a][b] = 1.0

# Fill tables backwards
for a in range(99, -1, -1):
    for b in range(99, -1, -1):

        # Q(a+1,b), unless Player 1 already wins
        if a + 1 >= 100:
            next_q = 0.0
        else:
            next_q = Q[a + 1][b]

        best = 0.0

        # Try all meaningful T values
        for T in range(1, 9):

            p = 2.0 ** (-T)
            gain = 2 ** (T - 1)

            # P(a,b+gain)
            if b + gain >= 100:
                success_value = 1.0
            else:
                success_value = P[a][b + gain]

            # Derived closed-form recurrence
            numerator = (
                p * success_value
                + 0.5 * (1 - p) * next_q
            )

            denominator = 1 - 0.5 * (1 - p)

            value = numerator / denominator

            best = max(best, value)

        Q[a][b] = best

        # Player 1 turn recurrence
        P[a][b] = 0.5 * next_q + 0.5 * Q[a][b]

print("{:.8f}".format(P[0][0]))
```---

```如果玩家 2 已经达到 100，他就已经赢了。

 ### 向后动态规划

 我们向下迭代$99$到$0$因为每次重复都只取决于更大的分数。

```玩家 2 检查每一种可能的投掷次数，并选择使获胜概率最大化的一次。
