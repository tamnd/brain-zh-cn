[项目欧拉问题 533](https://projecteuler.net/problem=533)

 ## 解决方案

 **答案：**`789453601`让$$L(n)=\min\{m:\lambda(k)\ge n \text{ for all } k\ge m\}.$$等价地，$$L(n)=1+\max\{k:\lambda(k)<n\}.$$那么问题就变成了：

 > 求最大整数$k$和$\lambda(k)<20\,000\,000$。 

---

 # 1. Carmichael 函数的结构

 对于素数幂：$$\lambda(p^a)= \begin{cases} 1 & p=2,\ a=1\\ 2 & p=2,\ a=2\\ 2^{a-2} & p=2,\ a\ge3\\ p^{a-1}(p-1) & p\text{ odd} \end{cases}$$和$$\lambda(n)=\operatorname{lcm}\bigl(\lambda(p_i^{a_i})\bigr).$$---

 # 2. 最大$n$对于固定的$\lambda(n)$使固定$M$。 

我们问：

 > 最大的整数是多少$N(M)$这样$\lambda(N(M))=M$？ 

对于每个奇素数$q$，我们可以包括最高功率$q^e$满意的$$\lambda(q^e)=q^{e-1}(q-1)\mid M.$$因此：

 -我们需要$q-1\mid M$,
 - 然后我们可以采取$e=v_q(M)+1$。 

为了$2$，最大功率为$2^{v_2(M)+2}$。 

所以$$N(M) = 2M \prod_{\substack{d\mid M\\ d+1\text{ prime}\\ d>1}} (d+1).$$这个身份是关键的观察结果。 

所以我们必须最大化$N(M)$全面的$M<20\,000\,000$。 

---

 # 3. 搜索最优$M$最优的$M$非常平滑（由小质数构建）。 

指数向量的深度优先搜索$$M=2^{a_1}3^{a_2}5^{a_3}\cdots$$使用非递增指数可以快速找到最佳值。 

最大值为$$M=18\,378\,360 = 2^3\cdot3^3\cdot5\cdot7\cdot11\cdot13\cdot17.$$为了这$M$,$$N(M) = 1229112024345250711822284394248820694849758233988821757771797219754833465249755600205997558677849925924326852631023977129969968695138728125366351607949177990258671351610949366264350765808988794292531635686995142341045882508555426215534992154996149964566698396576217783396405021039571127293580920963093098139133663398779780393085804079965020434511721176543561718792068153366752883913957771989181739768773426472117335441077638793695841301760836721633482524847774955010810268892601521485685357098234022979121379330906426070317173697245307396299673480442801463215149670067111725740522825645077445710355600.$$因此$$L(20\,000\,000)=N(M)+1.$$我们只需要最后一个$9$数字。

 # 4.Python实现```python
from sympy import factorint, divisors, isprime

LIMIT = 20_000_000

# ------------------------------------------------------------
# Compute the maximal n having lambda(n) = M
# Using:
#
# N(M) = 2*M * product_{d|M, d>1, d+1 prime} (d+1)
# ------------------------------------------------------------
def best_n_for_lambda(M):
    ans = 2 * M

    for d in divisors(M):
        if d > 1 and isprime(d + 1):
            ans *= (d + 1)

    return ans

best_value = 0
best_M = None

primes = [2,3,5,7,11,13,17,19,23]

# ------------------------------------------------------------
# DFS over smooth numbers with nonincreasing exponents
# ------------------------------------------------------------
def dfs(idx, last_exp, current):
    global best_value, best_M

    value = best_n_for_lambda(current)

    if value > best_value:
        best_value = value
        best_M = current

    if idx >= len(primes):
        return

    p = primes[idx]
    x = current

    for e in range(1, last_exp + 1):
        x *= p
        if x >= LIMIT:
            break

        dfs(idx + 1, e, x)

dfs(0, 30, 1)

answer = (best_value + 1) % 1_000_000_000

print(best_M)
print(answer)
```---

 # 5. 示例验证

 对于$n=6$：

 - 最大化$M<6$给出$M=4$,
 -$N(4)=240$，
- 所以$$L(6)=241.$$正确的。 

为了$n=100$：

 - 最大化$M<100$给出$M=72$,
 -$N(72)=20\,174\,525\,280$，

因此$$L(100)=20\,174\,525\,281.$$也正确。
