[欧拉项目问题 145](https://projecteuler.net/problem=145)

 ## 解决方案

 **答案：**`608720`我们寻求正整数$n$这样$$n+\operatorname{reverse}(n)$$仅具有奇数小数位。 

具有这种性质的数称为**可逆**。 

我们必须计算下面所有可逆的数字$10^9$。 

---

 # 1.数学分析

 关键的难点是正确处理携带。 

设小数位为$n$是$$d_0,d_1,\dots,d_{k-1}$$从最不重要到最重要，所以$$n=\sum_{i=0}^{k-1} d_i10^i.$$然后$$\operatorname{reverse}(n)$$具有相反顺序的数字。 

我们添加数字对：$$d_i + d_{k-1-i} + \text{carry}.$$为了使结果数字为奇数，每列总和必须为奇数。 

---

 ## 关键奇偶观察

 小数位为奇数当且仅当列和为奇数模$2$。 

由于携带贡献$0$或者$1$，奇偶性很重要。 

假设一列没有传入进位。 然后：$$d_i+d_j$$一定是奇数。 

因此，一个数字是偶数，另一个数字是奇数。 

假设有一个传入进位。 然后：$$d_i+d_j+1$$一定是奇数，所以$$d_i+d_j$$必须是均匀的。 

因此两个数字具有相同的奇偶校验。 

这立即造成了强有力的结构性限制。 

---

 # 逐长度分析

 我们按照位数来分析。 

该问题的标准结果是：

 - 即使数字长度也能提供许多解决方案，
 - 奇数位长度大多会失败，因为中间的数字会导致奇偶校验问题。 

我们仔细推导这一点。 

---

 # 2 位数字

 设数字为$a,b$和$a\neq 0$,$b\neq 0$（反向时没有前导零）。 

然后：$$(a+b)$$必须是奇数且小于$10$（否则进位产生偶数十位）。 

所以：

 - 一位偶数，
 - 一个奇怪的，
 - 总和$<10$。 

计算有序对的数量$(a,b)$：

 对于每个第一位数字$a\in\{1,\dots,9\}$, 计算相反奇偶校验$b\in\{1,\dots,9\}$和$a+b<10$。 

这正好给出了$20$。 

---

 # 一般偶数位数

 考虑一个$2m$- 数字。 

出现了显着的简化：

 - 每列均可免携带，
 - 每个镜像对的总和必须小于奇数$10$。 

对于每个镜像对：

 - 一位奇数，
 - 一个甚至，
 - 最外层对中都不可以为零，
 - 总和$<10$。 

有效有序对的数量为：$$20.$$对于内部对，允许使用零，给出：$$30$$选择。 

因此对于$2m$- 数字：$$20\cdot 30^{m-1}.$$让我们验证一下：

 - 2 位数字：$20$- 4 位数字：$20\cdot30=600$总计如下$1000$：$$20+100=120,$$与声明相符，因为 3 位可逆数字有贡献$100$。 所以我们仍然需要奇数长度。 

---

 # 奇数位数

 现在考虑$2m+1$- 数字。 

中间的数字加上自己：$$2d + c.$$如果没有传入进位，这是不可能的。 

因此中间的列必须接收进位。 

这会强制执行一系列进位。 

仔细的进位传播分析得出：

 - 长度$1,5,9,\dots$不可能的，
 - 长度$3,7,\dots$可能的。 

对于长度$4k+3$，计数为：$$100 \cdot 500^k.$$我们来推导出第一种情况。 

---

 # 3 位数字

 数字：$$abc$$添加：$$abc+cba.$$单位栏：$$a+c.$$要创建中间进位：$$a+c\ge10.$$然后中间一栏：$$b+b+1=2b+1,$$总是很奇怪。 

但我们必须避免另一种进位：$$2b+1<10 \Rightarrow b\le4.$$现在计算可能性。 

为了$a,c\in\{1,\dots,9\}$具有相反的奇偶校验和$a+c\ge10$：

有$20$有序对。 

中间数字：$$5$$选择。 

因此：$$20\cdot5=100.$$这与问题陈述相符：$$20+100=120$$以下$1000$。 

---

 # 下面是哪些长度$10^9$？ 

下面的数字$10^9$有长度：$$1,2,3,4,5,6,7,8,9.$$有效长度为：

 -$2$：$20$-$3$：$100$-$4$：$600$-$6$：$18000$-$7$：$50000$-$8$：$540000$长度$1,5,9$贡献$0$。 

使用以下公式：

 ## 长度均匀$$2m:\quad 20\cdot30^{m-1}$$- 2 位数字：$20$- 4 位数字：$600$- 6 位数字：$18000$- 8 位数字：$540000$全部的：$$558620.$$## 奇数长度$4k+3$公式：$$100\cdot500^k$$- 3 位数字：$100$- 7 位数字：$50000$全部的：$$50100.$$累计：$$558620+50100=608720.$$---

 # 2.Python实现```python
def reversible_count(limit_power=9):
    """
    Count reversible numbers below 10^limit_power.
    """

    total = 0

    # Count by digit length
    for digits in range(1, limit_power + 1):

        # Even number of digits: 2m
        if digits % 2 == 0:
            m = digits // 2

            # Formula:
            # 20 * 30^(m-1)
            total += 20 * (30 ** (m - 1))

        else:
            # Odd lengths:
            # only lengths congruent to 3 mod 4 work
            if digits % 4 == 3:

                # digits = 4k + 3
                k = (digits - 3) // 4

                # Formula:
                # 100 * 500^k
                total += 100 * (500 ** k)

    return total

print(reversible_count(3))   # should be 120
print(reversible_count(9))   # final answer
```---
