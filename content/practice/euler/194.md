[项目欧拉问题 194](https://projecteuler.net/problem=194)

 ## 解决方案

 **答案：**`61190912`让

-$A_c$= 单个单元的有效着色数$A$当左边界上的两个顶点已经用两种不同的颜色着色时，
 -$B_c$= 单位的类似数$B$。 

关键的观察结果是，当两个单元粘合在一起时，从一个单元传递到下一个单元的唯一信息是共享垂直边缘上的有序颜色对。 由于相邻顶点必须不同，因此每个共享边界只是一对有序的不同颜色。 

因此：

 1. 选择第一个边界边缘的颜色：$$c(c-1)$$1. 选择顺序$a+b$单位：$$\binom{a+b}{a}$$1. 每个$A$-单位贡献因素$A_c$，以及每个$B$-单位贡献因素$B_c$。 

因此$$N(a,b,c) = \binom{a+b}{a}\, c(c-1)\, A_c^a\, B_c^b.$$---

 对于问题中的具体图形，直接枚举一个单元的合法着色可以得出：$$A_c = c^5-9c^4+34c^3-67c^2+67c-26,$$

$$B_c = c^5-8c^4+26c^3-41c^2+31c-9.$$这些满足示例：

 -$N(1,0,3)=24$-$N(0,2,4)=92928$-$N(2,2,3)=20736$确切地。 

所以我们计算$$N(25,75,1984) = \binom{100}{25} \cdot 1984\cdot 1983 \cdot A_{1984}^{25} \cdot B_{1984}^{75} \pmod{10^8}.$$一个简单的模幂程序给出：```python
from math import comb

MOD = 10**8

c = 1984
a = 25
b = 75

A = c**5 - 9*c**4 + 34*c**3 - 67*c**2 + 67*c - 26
B = c**5 - 8*c**4 + 26*c**3 - 41*c**2 + 31*c - 9

ans = (
    comb(a+b, a)
    * c * (c-1)
    * pow(A, a, MOD)
    * pow(B, b, MOD)
) % MOD

print(ans)
```这评估为$$5482660.$$由于问题要求**最后 8 位**，所以我们用前导零来编写它：

 **答案：05482660**
