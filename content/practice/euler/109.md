[欧拉项目问题 109](https://projecteuler.net/problem=109)

 ## 解决方案

 **答案：**`38182`我们必须计算总分严格小于的不同结账组合$100$，根据规则：

 - 最后的飞镖**必须**是双镖。 
- 前两个省道（如果存在）是无序的。 
- 忽略未命中，因此仅因前导未命中而不同的序列是相同的。 
- 单打$S1$–$S20$, 双打$D1$–$D20$, 高音$T1$–$T20$，加上$S25$和$D25$是有效的飞镖结果。 

问题说明有$42336$总体结账总数； 我们只需要那些有分数的$<100$。 

---

 # 数学分析

 让我们正式确定可能的飞镖分数。 

## 1. 可能的飞镖值

 单次飞镖可能得分：

 - 单打：$1,2,\dots,20$- 双打：$2,4,\dots,40$- 高音：$3,6,\dots,60$外牛：$25$- 双牛：$50$但不同的_飞镖类型_很重要。 例如：

-$S2$和$D1$均得分$2$，但抛出不同。 
-$S6,T2,D3$都是不同的飞镖结果。 

定义所有非最终 dart 类型的集合：$$\mathcal D = \{S1\ldots S20,\ D1\ldots D20,\ T1\ldots T20,\ S25,\ D25\}$$这包含：$$20+20+20+1+1 = 62$$不同的飞镖结果。 

终点省必须是双省：$$\mathcal F = \{D1\ldots D20,\ D25\}$$其中有$21$的可能性。 

---

 ## 2. 订单约定

 结账时可以使用：

 - 1 飞镖：只是最后的双飞镖
 - 2 个飞镖：1 个普通飞镖 + 2 个精加工飞镖
 - 3个飞镖：两个普通飞镖+精加工双飞镖

 关键规则：

 > 前两个省道是无序的。 

因此：

-$S1,T1,D1$等于$T1,S1,D1$- 但$D1,D2$不同于$D2,D1$，因为最终的双倍不同。 

因此，对于每个完成双倍，我们计算：

 - 所有无序多组大小$0,1,2$选自$\mathcal D$,
 - 总成绩加上最终双倍小于$100$。 

---

 ## 3.枚举策略

 最干净的方法是暴力枚举。 

将每种飞镖类型表示为：$$(\text{name},\text{score})$$例子：

-$(S20,20)$-$(D7,14)$-$(T19,57)$对于每一次完成双打$f$：

 - 计算 1 镖结帐$[f]$- 计算每 2 飞镖结账的次数$[a,f]$- 计算每个无序对的数量$(a,b)$和$a \le b$按字典顺序排列以避免重复。 

每当：$$\text{score}(a)+\text{score}(b)+\text{score}(f) < 100$$我们算一下。 

这直接实现了问题陈述。 

---

 # Python 实现```python
from itertools import combinations_with_replacement

# ------------------------------------------------------------
# Build all possible dart results
# ------------------------------------------------------------

# Non-final dart options
darts = []

# Singles, doubles, trebles for 1..20
for n in range(1, 21):
    darts.append(("S" + str(n), n))
    darts.append(("D" + str(n), 2 * n))
    darts.append(("T" + str(n), 3 * n))

# Bulls
darts.append(("S25", 25))
darts.append(("D25", 50))

# Final dart must be a double
finishes = []

for n in range(1, 21):
    finishes.append(("D" + str(n), 2 * n))

finishes.append(("D25", 50))

# ------------------------------------------------------------
# Count distinct checkouts with total score < 100
# ------------------------------------------------------------

count = 0

for finish_name, finish_score in finishes:

    # --------------------------------------------------------
    # 1-dart checkout
    # --------------------------------------------------------
    if finish_score < 100:
        count += 1

    # --------------------------------------------------------
    # 2-dart checkout
    # --------------------------------------------------------
    for name1, score1 in darts:
        if score1 + finish_score < 100:
            count += 1

    # --------------------------------------------------------
    # 3-dart checkout
    # First two darts are unordered, so use combinations
    # with replacement.
    # --------------------------------------------------------
    for (name1, score1), (name2, score2) in combinations_with_replacement(darts, 2):

        total = score1 + score2 + finish_score

        if total < 100:
            count += 1

print(count)
```---

```选择前面的一个省。

```那么它是有效的。 

例子：

 ## 计算 3-dart 结帐次数

 关键行：```python
combinations_with_replacement(darts, 2)
```生成无序对。 

因此：

-$(S1,T1)$出现一次，
 - 没有两次。 

但相同的飞镖是允许的：

 -$(S1,S1)$-$(D1,D1)$这是问题陈述所要求的。 

然后我们测试：```python
total = score1 + score2 + finish_score
```如果低于则计数$100$。
