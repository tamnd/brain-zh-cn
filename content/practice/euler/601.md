 ## 解决方案

 **答案：**`1617243`让$$\operatorname{streak}(n)=k$$意思是：

 - 对于每一个$1\le j\le k$,$$n+j-1 \text{ is divisible by } j,$$- 但$$n+k \text{ is NOT divisible by } k+1.$$等效地：$$\begin{aligned} n+1 &\equiv 0 \pmod 2\\ n+2 &\equiv 0 \pmod 3\\ &\vdots\\ n+(k-1) &\equiv 0 \pmod k \end{aligned}$$每个同余都变成$$n \equiv 1 \pmod j.$$所以对于所有人来说$2\le j\le k$,$$n\equiv 1 \pmod j.$$所以：$$n\equiv 1 \pmod{\operatorname{lcm}(1,2,\dots,k)}.$$定义$$L_k=\operatorname{lcm}(1,2,\dots,k).$$然后：

-$\operatorname{streak}(n)\ge k$当且仅当$$n\equiv 1 \pmod{L_k}.$$拥有**完全**的连胜$k$，我们还要求步骤失败$k+1$， IE。$$n\not\equiv 1 \pmod{L_{k+1}}.$$因此$$P(k,N) = \left\lfloor \frac{N-1}{L_k}\right\rfloor - \left\lfloor \frac{N-1}{L_{k+1}}\right\rfloor.$$---

 检查示例$P(3,14)$:$$L_3=\operatorname{lcm}(1,2,3)=6,\qquad L_4=12.$$所以$$P(3,14) = \left\lfloor\frac{13}{6}\right\rfloor - \left\lfloor\frac{13}{12}\right\rfloor = 2-1=1.$$正确的。 

---

 现在计算$$\sum_{i=1}^{31} P(i,4^i).$$# Python 实现```python
from math import gcd

def lcm(a, b):
    return a * b // gcd(a, b)

total = 0
L = 1  # L_i = lcm(1..i)

for i in range(1, 32):
    # Compute L_i
    L = lcm(L, i)

    # Compute L_{i+1}
    L_next = lcm(L, i + 1)

    N = 4 ** i

    # P(i, N)
    p = (N - 1) // L - (N - 1) // L_next

    total += p

print(total)
```---

 ###`lcm(a, b)`使用计算最小公倍数$$\operatorname{lcm}(a,b)=\frac{ab}{\gcd(a,b)}.$$---

 ###`L = 1`商店$$L_i=\operatorname{lcm}(1,2,\dots,i).$$我们逐步更新它。

 ### 循环`i = 1..31`对于每个$i$:

 1. 计算$L_i$。 
2. 计算$L_{i+1}$。 
3. 设置$N=4^i$。 
4. 使用公式$$P(i,N) = \left\lfloor \frac{N-1}{L_i}\right\rfloor - \left\lfloor \frac{N-1}{L_{i+1}}\right\rfloor.$$1. 添加到运行总计中。
