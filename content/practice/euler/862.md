[欧拉项目 862 问题](https://projecteuler.net/problem=862)

 ## 解决方案

 **答案：**`6111397420935766740`设a的多组数字为$k$- 位数$n$被修复。 假设数字$d$出现$c_d$时间、地点$$\sum_{d=0}^9 c_d = k.$$我们想要计算这个数字多重集的所有数字对$S(k)$。 

## 1.数学分析

 对于给定的多组数字，定义：$$P(c_0,\dots,c_9)$$是**有效的数量$k$-可以形成的数字整数**（无前导零）。 

### 步骤 1：计算有效排列

 忽略前导零限制，不同排列的数量为$$\frac{k!}{\prod_{d=0}^9 c_d!}.$$如果$c_0>0$，有些安排是从零开始的。 前面补一个零，其余的置换$k-1$数字：$$\frac{(k-1)!}{(c_0-1)!\prod_{d=1}^9 c_d!}.$$因此$$P = \frac{k!}{\prod c_d!} - \frac{(k-1)!}{(c_0-1)!\prod_{d=1}^9 c_d!}.$$因式分解给出$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}.$$---

 ### 第 2 步：求和$T(n)$超过一位数的多重集

 按升序列出所有有效排列：$$a_1 < a_2 < \cdots < a_P.$$对于$i$第 - 个数字，$$T(a_i)=P-i,$$因为后面的数字更大。 

因此这个多重集的总贡献是$$\sum_{i=1}^{P}(P-i) = 0+1+\cdots+(P-1) = \frac{P(P-1)}{2}.$$因此$$S(k) = \sum_{\substack{c_0+\cdots+c_9=k\\ c_d\ge 0}} \frac{P(P-1)}{2},$$在哪里$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}.$$位计数向量的数量仅为$$\binom{k+9}{9},$$这对于$k=12$是$$\binom{21}{9}=293930,$$小到可以直接枚举。

 ## 2.Python实现```python
from math import factorial

def S(k):
    # Precompute factorials
    fact = [factorial(i) for i in range(k + 1)]

    counts = [0] * 10
    total = 0

    def dfs(digit, remaining):
        nonlocal total

        # Last digit count is forced
        if digit == 9:
            counts[9] = remaining

            # Compute denominator: product(c_i!)
            denom = 1
            for c in counts:
                denom *= fact[c]

            # Number of valid k-digit permutations
            P = (k - counts[0]) * fact[k - 1] // denom

            # Contribution of this multiset
            total += P * (P - 1) // 2
            return

        # Try all counts for this digit
        for c in range(remaining + 1):
            counts[digit] = c
            dfs(digit + 1, remaining - c)

    dfs(0, k)
    return total

# Check given example
print(S(3))   # 1701

# Required answer
print(S(12))
```---

 ## 3. 代码演练

 -`factorial(i)`值是预先计算的以避免重复工作。 
- 我们递归地枚举所有数字计数向量$(c_0,\dots,c_9)$总计$k$。 
- 对于每个向量：

 - 计算$$\prod c_d!$$- 评价$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}$$- 添加$$\frac{P(P-1)}{2}$$至总数。 

### 验证

 该程序重现给定值：$$S(3)=1701.$$举个例子$2302$：

 - 数字计数：$c_0=1,c_2=2,c_3=1$- 有效排列：$$P = \frac{(4-1)\cdot 3!}{1!\,2!\,1!} = 9$$因此这个多重集的总贡献是$$\frac{9\cdot 8}{2}=36.$$事实上，排序后的列表已经产生了排名$$8+7+\cdots+0=36.$$自从$2302$是第 5 项，$T(2302)=4$，与语句相符。
