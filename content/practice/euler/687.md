[项目欧拉问题 687](https://projecteuler.net/problem=687)

 ## 解决方案

 **答案：**`0.3285320869`让$X$是均匀洗牌的牌组中完美等级的数量。 

我们与$52!$**不同**卡片的排列。 

如果该等级中没有两张牌相邻，则该等级是_完美_的。 

---

 # 1.数学分析

 对于每个等级，有$4$牌。 

定义：$$A_r = \{\text{rank } r \text{ is perfect}\}.$$我们需要$$\Pr(X \text{ is prime}).$$可能的质数值是$$2,3,5,7,11,13.$$---

 ## 步骤 1：一组固定排名完美的概率

 假设有一组固定的$t$等级必须都是完美的。 

我们通过包含-排除来计算满足这些条件的排列。 

---

 ### 某一等级的包含-排除

 用卡牌获得一个等级$$a_1,a_2,a_3,a_4.$$为了强制相邻，我们将相邻的卡合并成块。 

如果确切地说$j$邻接被强制执行（$j=0,1,2,3$），那么这四张牌就变成了$$4-j$$块。 

选择这些邻接的方法的数量是$$\binom{3}{j}.$$合并后，对象总数变为$$52-j.$$因此贡献是$$(-1)^j \binom{3}{j}\frac{(52-j)!}{(4-j)!}.$$- -

＃＃＃ 为了$t$指定等级

 让排名$i$贡献$j_i\in\{0,1,2,3\}$。 

然后：

 - 总合并：$$s=j_1+\cdots+j_t,$$- 总对象：$$52-s,$$- 每个约束等级贡献一个因素$$(-1)^{j_i}\binom{3}{j_i}\frac1{(4-j_i)!}.$$其余$13-t$排名贡献$(4!)^{-(13-t)}$。 

因此有利排列的数量是$$N_t = \sum_{j_1,\dots,j_t} (52-s)! \prod_{i=1}^t \left( (-1)^{j_i} \binom{3}{j_i} \frac1{(4-j_i)!} \right) \frac1{(4!)^{13-t}}.$$排名模式排列的总数是$$\frac{52!}{(4!)^{13}}.$$所以$$p_t = \Pr(\text{a fixed set of }t\text{ ranks are perfect}) = \frac{N_t}{52!/(4!)^{13}}.$$---

 ## 第 2 步：恢复分布$X$根据对称性，$$\binom{13}{t}p_t = \mathbb E\!\left[\binom Xt\right].$$因此$$\binom{13}{t}p_t = \sum_{k=t}^{13}\binom{k}{t}\Pr(X=k).$$这是二项式变换。 反转它给出$$\Pr(X=k) = \sum_{t=k}^{13} (-1)^{t-k} \binom{t}{k} \binom{13}{t} p_t.$$然后我们对质数求和$k$。 

---

 # 2.Python实现```python
from math import factorial, comb
from collections import defaultdict

# Total number of rank-pattern permutations
TOTAL = factorial(52) / (factorial(4) ** 13)

# p[t] = probability that a fixed set of t ranks are perfect
p = []

for t in range(14):

    # DP over total number of merges s
    dp = {0: 1.0}

    for _ in range(t):
        ndp = defaultdict(float)

        for s, val in dp.items():
            for j in range(4):
                ndp[s + j] += (
                    val
                    * ((-1) ** j)
                    * comb(3, j)
                    / factorial(4 - j)
                )

        dp = ndp

    favorable = 0.0

    for s, coeff in dp.items():
        favorable += (
            factorial(52 - s)
            * coeff
            / (factorial(4) ** (13 - t))
        )

    p.append(favorable / TOTAL)

# Recover exact distribution of X
P = [0.0] * 14

for k in range(14):
    total = 0.0

    for t in range(k, 14):
        total += (
            ((-1) ** (t - k))
            * comb(t, k)
            * comb(13, t)
            * p[t]
        )

    P[k] = total

# Prime values
primes = [2, 3, 5, 7, 11, 13]

answer = sum(P[k] for k in primes)

print(f"{answer:.10f}")
```---

 # 3. 代码演练

 ### 计算$p_t$字典`dp[s]`准确存储总包含-排除系数$s$合并。 

对于每个约束等级：```python
for j in range(4):
```对应于执行$j$邻接关系。 

因素```python
((-1) ** j) * comb(3, j) / factorial(4 - j)
```正是包含-排除贡献。 

全部处理完后$t$排名，每个州`s`贡献```python
factorial(52 - s)
```因为合并后的配置有$52-s$对象。

 ### 恢复分配

 我们使用反演公式$$\Pr(X=k) = \sum_{t=k}^{13} (-1)^{t-k} \binom{t}{k} \binom{13}{t} p_t.$$这会产生每个可能值的精确概率$X$。
