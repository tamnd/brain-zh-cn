[项目欧拉问题 199](https://projecteuler.net/problem=199)

 ## 解决方案

 **答案：**`0.00396087`解决这个问题的关键工具是**笛卡尔圆定理**。 

如果四个互相相切的圆有曲率（弯曲）$$k_i=\frac1{r_i}$$（给定的封闭圆具有**负**曲率），则：$(k_1+k_2+k_3+k_4)^2 = 2(k_1^2+k_2^2+k_3^2+k_4^2)$求解第四曲率给出$$k_4 = k_1+k_2+k_3 \pm 2\sqrt{k_1k_2+k_2k_3+k_3k_1}.$$对于填充圆圈，我们使用 **加号** 。 

---

 # 1. 几何设置

 设三个初始相等的圆有半径$1$，所以它们的曲率是$$k=1.$$外外接圆具有负曲率$k_0$。 

将笛卡尔应用到四个互相相切的圆上：$$(k_0+1+1+1)^2 = 2(k_0^2+1+1+1).$$简化：$$(k_0+3)^2 = 2(k_0^2+3)$$

$$k_0^2-6k_0-3=0$$

$$k_0 = 3\pm2\sqrt3.$$外接圆必须有负曲率，所以$$k_0 = 3-2\sqrt3 = -(2\sqrt3-3).$$因此它的半径是$$R=\frac1{2\sqrt3-3}.$$因此总面积为$$A_{\text{outer}}=\pi R^2.$$初步覆盖面积：$$3\pi.$$---

 # 2. 递归间隙填充

 每个间隙由三个具有曲率的相互相切的圆确定$(a,b,c)$。 

适合该间隙的最大圆的曲率是$$d=a+b+c+2\sqrt{ab+bc+ca}.$$新的圆有面积$$\frac{\pi}{d^2}.$$插入后，间隙分裂成三个较小的间隙：$$(a,b,d),\quad (a,c,d),\quad (b,c,d).$$所以我们递归地处理这些。 

---

 # 3. 初始差距

 有 4 个初始间隙：

 - 1 个中心间隙：$(1,1,1)$- 3个外部间隙：$(-(2\sqrt3-3),1,1)$我们递归 10 次迭代。 

---

 # 4.Python实现```python
from math import sqrt, pi

# Curvature magnitude of enclosing circle
k0 = 2 * sqrt(3) - 3

# Total area of enclosing circle
A_outer = pi / (k0 ** 2)

def added_area(a, b, c, depth):
    """
    Total area added by recursively filling the gap
    determined by circles with curvatures a,b,c.
    """

    if depth == 0:
        return 0.0

    # Descartes theorem (new circle curvature)
    d = a + b + c + 2 * sqrt(a*b + b*c + c*a)

    # Area of newly inserted circle
    area = pi / (d ** 2)

    # Recurse into the 3 new gaps
    area += added_area(a, b, d, depth - 1)
    area += added_area(a, c, d, depth - 1)
    area += added_area(b, c, d, depth - 1)

    return area

# Initial three circles
covered = 3 * pi

# Fill the central gap
covered += added_area(1, 1, 1, 10)

# Fill the three outer gaps
covered += 3 * added_area(-k0, 1, 1, 10)

# Fraction not covered
fraction_uncovered = 1 - covered / A_outer

print(f"{fraction_uncovered:.8f}")
```---
