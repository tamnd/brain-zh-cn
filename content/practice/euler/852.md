[项目欧拉问题 852](https://projecteuler.net/problem=852)

 ## 解决方案

 **答案：**`130.313496`让$V(f,u)$表示当存在时的最佳预期未来分数$f$公平的硬币和$u$盒子里留下不公平的硬币。 

一枚公平的硬币有$$P(H)=\tfrac12,$$虽然一枚不公平的硬币有$$P(H)=\tfrac34.$$如果当前所选硬币不公平的后验概率为$q$，那么：

 - 猜测“不公平”给出预期奖励$$20q-50(1-q)=70q-50,$$- 猜测“公平”给出预期奖励$$20(1-q)-50q=20-70q.$$所以最优的立即停止收益是$$G(q)=\max(70q-50,\;20-70q).$$---

 ## 贝叶斯更新

 让$$r=\frac{q}{1-q}$$是硬币不公平的优势比。 

最初，$$r_0=\frac{u}{f}.$$观察后：

 - 正面：似然比乘以$\frac{3/4}{1/2}=\frac32$,
 - 尾部：似然比乘以$\frac{1/4}{1/2}=\frac12$。 

因此：$$r \to \frac32 r \quad (\text{head}), \qquad r \to \frac12 r \quad (\text{tail}).$$正面的预测概率为$$P(H)=\frac34 q+\frac12(1-q) =\frac{2+3r}{4(1+r)}.$$---

 ## 一枚硬币的动态规划

 假设本轮之后连续值相差$$A = V(f,u-1)-V(f-1,u).$$那么如果我们立即停在后面$q$，从本轮开始的总期望值是$$\max\Big(q(70+A)-50,\; q(A-70)+20\Big).$$让$F(r)$是从优势比开始的最佳期望值$r$。 然后$$F(r)=\max\left( S(r), -1 + P(H)F\!\left(\tfrac32 r\right)      + P(T)F\!\left(\tfrac12 r\right) \right),$$在哪里$S(r)$是上面的停止值。 

最后，$$V(f,u)=V(f-1,u)+F\!\left(\frac{u}{f}\right).$$边界条件：$$V(0,u)=20u,\qquad V(f,0)=20f,$$因为一旦知道了所有剩余的硬币，未来的每个猜测都是正确的，无需抛掷。

 ## 验证$N=1$运行 DP 给出$$S(1)=20.558587\ldots$$与问题陈述相匹配：$$20.558591$$（四舍五入至小数点后 6 位后）。

 ## Python 实现```python
from math import *

def solve(N, depth=160):
    V = [[0.0]*(N+1) for _ in range(N+1)]

    pow2 = [1.0]
    pow3 = [1.0]

    for _ in range(depth + 2):
        pow2.append(pow2[-1] * 2.0)
        pow3.append(pow3[-1] * 3.0)

    for total in range(1, 2*N + 1):

        lo = max(0, total - N)
        hi = min(N, total)

        for f in range(lo, hi + 1):

            u = total - f

            if f == 0:
                V[f][u] = 20.0 * u
                continue

            if u == 0:
                V[f][u] = 20.0 * f
                continue

            A = V[f][u-1] - V[f-1][u]

            r0 = u / f

            # H[a][b]:
            # after b tosses with a heads
            H = [[0.0]*(depth+2) for _ in range(depth+2)]

            for b in range(depth, -1, -1):

                for a in range(b, -1, -1):

                    r = r0 * pow3[a] / pow2[b]
                    q = r / (1.0 + r)

                    stop = max(
                        q*(70.0 + A) - 50.0,
                        q*(A - 70.0) + 20.0
                    )

                    if b < depth:

                        pH = (2.0 + 3.0*r) / (4.0*(1.0 + r))

                        cont = (
                            -1.0
                            + pH * H[a+1][b+1]
                            + (1.0-pH) * H[a][b+1]
                        )

                        stop = max(stop, cont)

                    H[a][b] = stop

            V[f][u] = V[f-1][u] + H[0][0]

    return V[N][N]

ans = solve(50)
print(f"{ans:.6f}")

**答案：130.313496**
