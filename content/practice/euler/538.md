[欧拉项目问题 538](https://projecteuler.net/problem=538)

 ## 解决方案

 **答案：**`22472871503401097`令选定的四个边长为$a \le b \le c \le d$。 

对于一组固定的边长，面积最大的四边形是循环四边形，因此根据 Brahmagupta 公式$$A^2=(s-a)(s-b)(s-c)(s-d), \qquad s=\frac{a+b+c+d}{2}.$$等价地，$$16A^2= (a+b+c-d) (a+b-c+d) (a-b+c+d) (-a+b+c+d).$$定义$$F(a,b,c,d)= (a+b+c-d) (a+b-c+d) (a-b+c+d) (-a+b+c+d).$$最大化面积相当于最大化$F$，并且关系被周长打破$P=a+b+c+d$。 

---

 # 1. 关键结构观察

 假设可用长度的多重集已排序。 

如果最优四元组跳过了两个选定值之间的某些可用值，则用跳过的较大值替换较小的选定值会增加每个因素$F$，因此增加了面积。 

因此：

 > **最佳四元组始终是排序多重集中的四个连续元素。**

 因此，在将新值插入到排序序列中之后，只有最多四个包含该新值的连续窗口才可能提高最优值。 

这将问题从“所有四元组”减少到仅$O(1)$每个插入的候选人。 

---

 # 2. 生成序列$$u_n = 2^{B(3n)} + 3^{B(2n)} + B(n+1),$$在哪里$B(k)$是二进制 popcount。 

为了$n \le 3\,000\,000$，只有 1614 个不同的值$u_n$，因此我们对它们进行协调压缩并使用 Fenwick 树（二元索引树）维护有序多重集。 

芬威克树支持：

 - 插入，
 - 排名查询，
 -$k$-th 元素查询，

 全部投入$O(\log M)$， 在哪里$M=1614$。 

因此整个计算本质上是线性的。 

---

 # 3.Python实现```python
from bisect import bisect_left

N = 3_000_000

# ---------- generate all u_n ----------
pow3 = [3 ** k for k in range(30)]

vals = []
distinct = set()

for n in range(1, N + 1):
    v = (1 << ((3 * n).bit_count())) \
        + pow3[(2 * n).bit_count()] \
        + (n + 1).bit_count()

    vals.append(v)
    distinct.add(v)

# ---------- coordinate compression ----------
coord = sorted(distinct)
idx = {v: i + 1 for i, v in enumerate(coord)}
M = len(coord)

# ---------- Fenwick tree ----------
bit = [0] * (M + 1)

def add(i, delta):
    while i <= M:
        bit[i] += delta
        i += i & -i

def prefix_sum(i):
    s = 0
    while i:
        s += bit[i]
        i -= i & -i
    return s

def kth(k):
    """
    Smallest index i such that prefix_sum(i) >= k
    """
    i = 0
    step = 1 << (M.bit_length() - 1)

    while step:
        ni = i + step
        if ni <= M and bit[ni] < k:
            k -= bit[ni]
            i = ni
        step >>= 1

    return i + 1

def value_at_rank(r):
    return coord[kth(r) - 1]

# ---------- Brahmagupta comparison quantity ----------
def score(q):
    a, b, c, d = q

    x1 = a + b + c - d
    if x1 <= 0:
        return -1

    return (
        x1
        * (a + b - c + d)
        * (a - b + c + d)
        * (-a + b + c + d)
    )

best_F = -1
best_P = 0

answer = 0
total = 0

# ---------- process U_n incrementally ----------
for n, v in enumerate(vals, start=1):

    i = idx[v]

    # rank of inserted element
    rank = prefix_sum(i) + 1

    add(i, 1)
    total += 1

    # only windows containing the new element matter
    start_lo = max(1, rank - 3)
    start_hi = min(rank, total - 3)

    for s in range(start_lo, start_hi + 1):

        q = [
            value_at_rank(s),
            value_at_rank(s + 1),
            value_at_rank(s + 2),
            value_at_rank(s + 3),
        ]

        F = score(q)
        P = sum(q)

        if F > best_F or (F == best_F and P > best_P):
            best_F = F
            best_P = P

    if n >= 4:
        answer += best_P

print(answer)
```---

 # 4. 代码演练

 ### 序列生成```python
v = (1 << ((3 * n).bit_count())) \
    + pow3[(2 * n).bit_count()] \
    + (n + 1).bit_count()
```直接实现定义$u_n$。 

---

 ### 芬威克树

 我们维护每个压缩值的计数。 

-`add(i,1)`插入一次出现，
 -`prefix_sum(i)`计算有多少个元素$\le i$,
 -`kth(k)`检索$k$-第一个最小的元素。 

---

 ### 连续窗口

 如果插入的元素已排序`rank`，那么只有这些窗口可能会改变：$$[rank-3, rank],\ [rank-2, rank+1],\ [rank-1, rank+2],\ [rank, rank+3].$$因此最多仅检查四个候选四元组。 

---

 ### 面积比较

 我们比较的不是浮点区域$$F = 16A^2,$$这是整数值并且是精确的。 

打破平局使用外围。
