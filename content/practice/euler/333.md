[项目欧拉问题 333](https://projecteuler.net/problem=333)

 ## 解决方案

 **答案：**`3053105`让一项由它的指数对表示$$(i,j)\quad\leftrightarrow\quad 2^i3^j.$$一个划分是有效的当且仅当没有项可以划分另一个项。 

两学期$$2^a3^b,\qquad 2^c3^d,$$我们有$$2^a3^b \mid 2^c3^d \iff a\le c \text{ and } b\le d.$$因此，有效的分区完全对应于一组指数对，其中没有对是坐标的$\le$其他。 

等效地：

 - 如果$i$-指数增加，
 - 那么$j$- 指数必须严格递减。 

所以每个有效分区都可以写成一条链$$(i_1,j_1),(i_2,j_2),\dots,(i_k,j_k)$$和$$i_1<i_2<\cdots<i_k,\qquad j_1>j_2>\cdots>j_k.$$这将问题转换为结构化组合搜索。 

---

 # 1. 数学分析

 我们需要：$$\sum_{\substack{q<10^6\\ q\text{ prime}\\ P(q)=1}} q.$$---

 ## 指数的界限

 自从$2^i3^j<10^6$,

 -$i\le 19$因为$2^{20}>10^6$,
 -$j\le 12$因为$3^{13}>10^6$。 

所以可能的基本术语很少。 

---

 ## 动态规划思想

 处理权力$3$从大$j$降到小$j$。 

在每个$j$，我们可以：

 - 跳过那个$j$, 或
 - 准确选择一个$i$比之前选择的每个都大$i$。 

这会自动强制执行：$$i_1<i_2<\cdots,\qquad j_1>j_2>\cdots,$$因此有效性。 

我们维持状态：$$(\text{largest chosen } i,\ \text{sum})$$并计算每个和可以出现的方式有多少种。 

最后：

 - 计算$P(n)$,
 - 筛质数，
 - 将所有素数相加$P(q)=1$。

 # 2.Python 实现```python
from collections import defaultdict

LIMIT = 10**6

# ------------------------------------------------------------
# Generate powers of 2 and 3
# ------------------------------------------------------------

pow2 = [1]
while pow2[-1] * 2 < LIMIT:
    pow2.append(pow2[-1] * 2)

pow3 = [1]
while pow3[-1] * 3 < LIMIT:
    pow3.append(pow3[-1] * 3)

I = len(pow2)
J = len(pow3)

# ------------------------------------------------------------
# DP states:
#
# states[k] is a dictionary:
#   sum -> number of valid partitions
#
# where the largest chosen i-exponent equals (k-1).
#
# k = 0 represents "no exponent chosen yet", i.e. last_i = -1.
# ------------------------------------------------------------

states = [defaultdict(int) for _ in range(I + 1)]
states[0][0] = 1

# Process j from large to small
for j in range(J - 1, -1, -1):

    new_states = [defaultdict(int) for _ in range(I + 1)]

    for idx, d in enumerate(states):

        last_i = idx - 1

        for current_sum, ways in d.items():

            # Option 1: skip this j
            new_states[idx][current_sum] += ways

            # Option 2: choose an i > last_i
            for new_i in range(last_i + 1, I):

                value = pow2[new_i] * pow3[j]
                new_sum = current_sum + value

                if new_sum < LIMIT:
                    new_states[new_i + 1][new_sum] += ways

    states = new_states

# ------------------------------------------------------------
# Collect P(n)
# ------------------------------------------------------------

P = [0] * LIMIT

for d in states:
    for s, cnt in d.items():
        P[s] += cnt

# Remove empty partition
P[0] -= 1

# ------------------------------------------------------------
# Prime sieve
# ------------------------------------------------------------

is_prime = bytearray(b"\x01") * LIMIT
is_prime[0:2] = b"\x00\x00"

for p in range(2, int(LIMIT**0.5) + 1):
    if is_prime[p]:
        is_prime[p*p:LIMIT:p] = b"\x00" * (
            ((LIMIT - 1 - p*p) // p) + 1
        )

# ------------------------------------------------------------
# Compute answer
# ------------------------------------------------------------

answer = sum(
    n for n in range(LIMIT)
    if is_prime[n] and P[n] == 1
)

print(answer)
```---

 # 3. 代码演练

 ## 发电能力```python
pow2 = [1]
while pow2[-1] * 2 < LIMIT:
    pow2.append(pow2[-1] * 2)
```创造一切力量$2^i<10^6$。 

同样对于权力$3$。 

---

 ## DP 结构```python
states[k][s]
```意思是：

 - 我们已经形成总和$s$,
 - 使用的最大指数$i$等于$k-1$。 

加工$j$按降序排列保证未来选择$j$的较小。 

只选择$i > \text{last}_i$保证增加$i$的。 

因此不可能发生可分性。 

- -

＃＃ 过渡```python
# skip this j
new_states[idx][current_sum] += ways
```或者```python
value = pow2[new_i] * pow3[j]
new_sum = current_sum + value
```包括一个术语。 

- -

＃＃ 建筑$P(n)$毕竟$j$的处理：```python
P[s] += cnt
```计算有效分区的数量$s$。
