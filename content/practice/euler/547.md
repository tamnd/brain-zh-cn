[欧拉项目问题 547](https://projecteuler.net/problem=547)

 ## 解决方案

 **答案：**`11730879.0023`让$$E(R)=\frac1{\operatorname{area}(R)^2}\iint_{R\times R} \|P-Q\|\,dP\,dQ$$是区域中两个均匀随机点之间的预期距离$R$。 

对于空心方形薄板，该区域为$$L = O\setminus H,$$在哪里

-$O$是外层$n\times n$正方形，
-$H$是被移除的$x\times y$长方形。 

我们必须计算$$S(n)=\sum_{\text{all laminae}} E(L).$$为了$n=40$，除非我们导出封闭式矩形积分，否则强力几何积分是不可能的。 

---

 # 1.数学分析

 ## 步骤 1 — 矩形对积分

 定义$$I(A,B)=\iint_{A\times B}\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}\,dA\,dB.$$然后$$E(R)=\frac{I(R,R)}{\operatorname{area}(R)^2}.$$所以对于椎板$L=O\setminus H$,$$I(L,L) = I(O,O)-2I(O,H)+I(H,H).$$因此一切都归结为评估$I$for axis-aligned rectangles.

 ---

 ## Step 2 — Antiderivative

 让$$r=\sqrt{x^2+y^2}.$$一个有用的身份是$$\frac{\partial^2}{\partial x\,\partial y} \left( \frac{xyr}{3} +\frac{x^3}{6}\operatorname{asinh}\frac{y}{x} +\frac{y^3}{6}\operatorname{asinh}\frac{x}{y} \right) =r.$$对两个变量再次积分得到四阶原语：$$Q(x,y)= \frac{x^4y}{24}\operatorname{asinh}\frac{y}{x} +\frac{xy^4}{24}\operatorname{asinh}\frac{x}{y} -\frac{x^4r}{60} +\frac{x^2y^2r}{20} -\frac{y^4r}{60}.$$然后通过反复的包含-排除，

 对于矩形$$R_1=[a,b]\times[c,d], \qquad R_2=[e,f]\times[g,h],$$我们得到$$I(R_1,R_2) = \sum (-1)^{i+j+k+l} Q(x_i-u_j,\; y_k-v_l),$$在哪里$$x_i\in\{a,b\}, \quad u_j\in\{e,f\}, \quad y_k\in\{c,d\}, \quad v_l\in\{g,h\}.$$这给出了只有 16 个评估的精确封闭形式。 

---

 ## 步骤 3 — 枚举所有层板

 对于固定$n$：

 - 孔宽$x$：$1\le x\le n-2$,
 - 孔高度$y$：$1\le y\le n-2$,
 - 左偏移$a$：$1\le a\le n-x-1$,
 - 底部偏移$b$：$1\le b\le n-y-1$。 

每个位置单独计算，包括完全按照规定的旋转/反射。 

对于每个层：$$E(L) = \frac{ I(O,O)-2I(O,H)+I(H,H) }{ (n^2-xy)^2 }.$$将所有这些值相加得出$S(n)$。

 # 2.Python实现```python
import math

# Fourth-order primitive
def Q(x, y):
    x = abs(x)
    y = abs(y)

    r = math.hypot(x, y)

    val = 0.0

    if x > 0:
        val += x**4 * y * math.asinh(y / x) / 24.0

    if y > 0:
        val += x * y**4 * math.asinh(x / y) / 24.0

    val += (
        -x**4 * r / 60.0
        + x**2 * y**2 * r / 20.0
        - y**4 * r / 60.0
    )

    return val

# Rectangle pair integral
# rectangle format: (x1, x2, y1, y2)
def rect_pair_integral(R1, R2):

    a, b, c, d = R1
    e, f, g, h = R2

    xs = [a, b]
    us = [e, f]
    ys = [c, d]
    vs = [g, h]

    total = 0.0

    for i, X in enumerate(xs):
        for j, U in enumerate(us):
            for k, Y in enumerate(ys):
                for l, V in enumerate(vs):

                    total += (
                        (-1) ** (i + j + k + l)
                        * Q(X - U, Y - V)
                    )

    return total

def S(n):

    outer = (0, n, 0, n)

    # Cache repeated rectangle computations
    cache = {}

    def RP(A, B):
        key = (A, B)

        if key not in cache:
            cache[key] = rect_pair_integral(A, B)

        return cache[key]

    outer_outer = RP(outer, outer)

    total = 0.0

    for x in range(1, n - 1):
        for y in range(1, n - 1):

            # self-integral of hole depends only on x,y
            HH = RP((0, x, 0, y), (0, x, 0, y))

            area = n * n - x * y

            for a in range(1, n - x):
                if a + x > n - 1:
                    continue

                for b in range(1, n - y):
                    if b + y > n - 1:
                        continue

                    hole = (a, a + x, b, b + y)

                    I = (
                        outer_outer
                        - 2 * RP(outer, hole)
                        + HH
                    )

                    total += I / (area * area)

    return total

print(round(S(3), 4))
print(round(S(4), 4))
print(round(S(40), 4))
```---

 # 3. 代码演练

 ###`Q(x,y)`实现上面导出的封闭形式四阶原语。 

---

 ###`rect_pair_integral`使用 16 角包含-排除公式：$$\sum (-1)^{i+j+k+l}Q(\cdots).$$这正是评估$$I(R_1,R_2).$$---

 ###`S(n)`枚举每个有效的内部矩形放置。 

对于每个层：

 1. 计算$I(O,O)$,
 2. 减法$2I(O,H)$,
 3.添加$I(H,H)$,
 4. 除以面积的平方。 

然后对所有层板进行求和。
