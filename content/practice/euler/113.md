[欧拉项目问题 113](https://projecteuler.net/problem=113)

 ## 解决方案

 **答案：**`51161058134250`我们来数一下下面的正整数$10^{100}$**没有弹性**，即以下数字之一：

 - **增加**：数字从左到右永远不会减少，
 - **递减**：数字从左到右永远不会增加。 

关键是这是一个纯粹的组合问题。 

---

 # 步骤 1 — 计算不断增加的数字

 越来越多的人满足$$d_1 \le d_2 \le \cdots \le d_n$$数字来自哪里$0$到$9$。 

例子：$$134468$$我们计算**最多 100 位**的递增数字（不包括相同数字的前导零表示）。 

标准组合技巧是：

 - 长度递增的序列$n$使用数字$0$–$9$- 相当于选择尺寸的多重集$n$从 10 个符号开始。 

因此计数为$$\binom{n+9}{9}$$然而，这包括全零序列，它不代表正整数。 

所以增加的正整数的数量恰好是$n$数字（允许在组合表示内部使用前导零）是$$\binom{n+9}{9} - 1$$---

 # 步骤 2 — 计算递减的数字

 递减的数量满足$$d_1 \ge d_2 \ge \cdots \ge d_n$$例子：$$66420$$我们再次使用星条形。 

长度弱递减的数字串的个数$n$超过数字$0$–$9$是$$\binom{n+10-1}{10-1} = \binom{n+9}{9}$$但对于减少的数字，我们必须小心对待前导零。 

一个更清晰的已知公式是：$$\binom{n+10}{10} - 1$$减少正整数至多$n$数字。 

等价地，对于恰好$n$数字：$$\binom{n+10-1}{10-1} = \binom{n+9}{9}$$对多计数的零表示进行修正。 

标准欧拉计划推导得出：$$\text{decreasing up to } n \text{ digits} = \binom{n+10}{10} - (n+1)$$因为字符串就像$$0000,\ 1111,\ 2222,\dots$$创建重复的表示。 

---

 # 步骤 3 — 重复计算的数字

 数字全部相同的数字都在递增和递减：$$1,2,\dots,9,11,22,333,\dots$$对于每个数字长度$n$，正好有$9$如此正数。 

所以当合并计数时我们减去$$9n$$为了$n$- 数字范围。 

---

 # 步骤 4 — 封闭公式

 下面非弹力数字的个数$10^n$是$$\binom{n+10}{10} + \binom{n+9}{9} - 10n - 2$$为了$n=100$：$$\binom{110}{10} + \binom{109}{9} - 1000 - 2$$我们现在计算它。 

---

 # Python 实现```python
from math import comb

def non_bouncy_below_10_pow(n):
    """
    Count positive integers below 10^n
    that are either increasing or decreasing.
    """

    increasing = comb(n + 9, 9)
    decreasing = comb(n + 10, 10)

    # Remove duplicates and zero-count issues
    return increasing + decreasing - 10 * n - 2

# Verify the example from the problem
print(non_bouncy_below_10_pow(6))   # below one million
print(non_bouncy_below_10_pow(10))  # below 10^10

# Compute the required answer
print(non_bouncy_below_10_pow(100))
```---

 # 最终计算

 对于$n=100$：$$\binom{110}{10} + \binom{109}{9} -1000-2$$其评估结果为$$51161058134250$$这个幅度是合理的：

 - 总数如下$10^{100}$是一个天文数字般的巨大，
 - 非弹性数仅以多项式增长$n$,
 - 因此计数相对较小。
