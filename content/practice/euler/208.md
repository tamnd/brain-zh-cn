[欧拉项目问题 208](https://projecteuler.net/problem=208)

 ## 解决方案

 **答案：**`331951449665644800`让机器人的航向为五个方向之一$$0,1,2,3,4 \pmod 5$$对应于由$72^\circ$。 

每一个动作：

 - 机器人穿过$72^\circ$圆弧，
 - 必须顺时针或逆时针转动，
 - 因此其标题更改为$\pm 1 \pmod 5$。 

我们必须计算所有长度为 70 的步行：

 1.开始面向北，
 2. 在起始位置结束，
 3.可以重复使用弧线，
 4. 恰好由 70 条弧组成。 

---

 # 1. 关键的数学见解

 关键的观察是：

 > 机器人的最终位置仅取决于五个航向中每个航向的使用次数。 

---

 ## 一举贡献的位移

 假设机器人当前面向方向$d$。 

顺时针或逆时针圆弧产生位移矢量，该矢量是同一基本矢量的旋转副本。 在所有五个方向上，这些向量是正五边形的五个旋转。 

让$v_d$是与航向相关的位移$d$。 

因为五个方向围绕一个圆等距分布，$$v_0+v_1+v_2+v_3+v_4=0.$$它们之间唯一的线性关系就是这个。 

因此，为了使总位移消失，所有的系数$v_d$必须相等。 

所以如果$c_d$是面向方向时进行的移动次数$d$, 闭包需要$$c_0=c_1=c_2=c_3=c_4.$$由于总共有 70 步，$$c_d = \frac{70}{5}=14.$$因此：

 > 当且仅当每个方向都使用了 14 次时，路径被关闭。 

这完全消除了几何问题。 

---

 # 2. 重新表述为纯粹的计数问题

 我们现在只需要计算左转/右转的序列，这样：

 - 标题开始于$0$,
 - 每次移动后标题都会改变$\pm1 \pmod5$,
 - 每个标题恰好使用了 14 次，
 - 70 次移动后，标题返回到$0$。 

---

 # 3.动态规划

 定义DP状态：$$(a,b,c,d,e,\text{dir})$$在哪里

-$a,b,c,d,e$标题有多少次$0,1,2,3,4$已被使用，
 -`dir`是当前标题。 

从标题`dir`我们：

 1. 增加该标题的计数，
 2. 左转或右转：$$\text{dir}\to \text{dir}\pm1 \pmod5.$$当所有 70 次移动都用完时，递归结束。 

---

 # 4.Python实现```python
from functools import lru_cache

TOTAL = 70
PER = 14   # each of the 5 directions must be used 14 times

@lru_cache(None)
def dp(a, b, c, d, e, direction):
    """
    Counts the number of valid continuations from this state.

    a,b,c,d,e = number of times directions 0..4
                have already been used
    direction = current heading
    """

    counts = [a, b, c, d, e]

    # impossible state
    if any(x > PER for x in counts):
        return 0

    steps_used = sum(counts)

    # all 70 moves completed
    if steps_used == TOTAL:
        return (
            1
            if direction == 0 and all(x == PER for x in counts)
            else 0
        )

    # current move uses the current heading
    counts[direction] += 1

    na, nb, nc, nd, ne = counts

    # next heading is left or right
    return (
        dp(na, nb, nc, nd, ne, (direction + 1) % 5)
        +
        dp(na, nb, nc, nd, ne, (direction - 1) % 5)
    )

answer = dp(0, 0, 0, 0, 0, 0)

print(answer)
```---

 # 5. 代码演练

 ## 记忆```python
@lru_cache(None)
```缓存每个状态，因此仅计算一次。 

如果没有记忆，递归将是指数级的。 

---

 ## 状态变量```python
dp(a, b, c, d, e, direction)
```曲目：

 - 每个标题被使用了多少次，
 - 当前标题。 

这已经足够了，因为闭合仅取决于标题计数。 

---

 ## 不可能的状态```python
if any(x > PER for x in counts):
    return 0
```任何标题的使用次数不得超过 14 次。

 ## 完成测试```python

```有效的封闭步行必须满足：```python
direction == 0
```和```python
all(x == PER for x in counts)
```含义：

 - 我们回到原来的标题，
 - 每个方向的使用频率相同。 

- -

＃＃ 过渡```python

```当前步骤使用当前标题。 

然后我们分支：```python

```对应于逆时针或顺时针旋转。
