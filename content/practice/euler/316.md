[欧拉项目问题 316](https://projecteuler.net/problem=316)

 ## 解决方案

 **答案：**`542934735751917735`设目标十进制字符串为$w=w_1w_2\dots w_m$， 在哪里$m$是的位数$n$。 

我们扫描随机数字流，直到第一次出现$w$。 

这是经典的“随机流中的模式匹配”问题，使用自动机/KMP 重叠结构来解决。 

# 1.数学分析

 一句话$w$，定义一个 **border** 为一个非空字符串，同时：

 - 前缀$w$,
 - 以及后缀$w$。 

如果边框有长度$b$，然后在部分匹配模式并失败后，我们可以重用该重叠部分。 

自动机/更新理论的标准结果给出：$$E(w)=\sum_{b \in B(w)} 10^b,$$在哪里：

-$E(w)$是完成模式之前所需的预期位数，
 -$B(w)$是一组边界长度，包括全长$m$。 

然而，问题定义了$g(n)$作为预期的**起始位置**$k$，不是终点位置。 

如果比赛结束于位置$t$， 然后$$k=t-m+1.$$因此$$g(n)=E(w)-m+1.$$所以：$$\boxed{ g(n)=\sum_{b \in B(w)} 10^b - m + 1 }$$在哪里$w$是十进制展开式$n$。 

- -

＃＃ 例子：$n=535$的边界`"535"`：

 -`"5"`（长度$1$）
 -`"535"`（长度$3$）

因此$$g(535)=10^1+10^3-3+1 =10+1000-2 =1008.$$这与声明相符。 

---

 # 2. 高效计算

 我们必须评估$$\sum_{n=2}^{999999} g\!\left(\left\lfloor\frac{10^{16}}{n}\right\rfloor\right).$$对于每个值：

 1. 转换为十进制字符串。 
2. 使用 KMP 前缀函数计算所有边界长度。 
3. 总和$10^b$跨越所有边界。 
4. 减法$m-1$。 

总的工作量很小，因为每个字符串最多有 16 位数字。 

---

 # 3.Python实现```python
def g_value(x):
    s = str(x)
    m = len(s)

    # KMP prefix function
    pi = [0] * m

    for i in range(1, m):
        j = pi[i - 1]

        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]

        if s[i] == s[j]:
            j += 1

        pi[i] = j

    # Full word always contributes 10^m
    ans = 10 ** m - m + 1

    # Add contributions from proper borders
    j = pi[-1]

    while j > 0:
        ans += 10 ** j
        j = pi[j - 1]

    return ans

total = 0

for n in range(2, 1_000_000):
    total += g_value(10 ** 16 // n)

print(total)
```---

 # 4. 代码演练

 ###`g_value(x)`- 将数字转换为其十进制字符串。 
- 计算 KMP 前缀表：

 -`pi[i]`= 最长的专有前缀的长度，它也是后缀`s[:i+1]`。 

示例`"535"`：

 - 前缀函数以值结尾`1`,
 - 对应边界`"5"`。 

然后我们：

 - 添加$10^m$对于完整的图案，
 - 使用前缀表向后遍历边界链，
 - 添加$10^b$对于每个适当的边框长度$b$,
 - 减去$m-1$。
