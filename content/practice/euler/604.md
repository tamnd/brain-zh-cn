[欧拉项目 604 问题](https://projecteuler.net/problem=604)

 ## 解决方案

 **答案：**`1398582231101`让图形经过格点$$P_0,P_1,\dots,P_m$$严格增加$x$- 坐标和$y$- 坐标。 

定义步向量$$v_i=P_i-P_{i-1}=(a_i,b_i),\qquad a_i,b_i\in \mathbb Z_{>0}.$$对于严格凸递增函数，斜率必须满足$$\frac{b_1}{a_1}<\frac{b_2}{a_2}<\cdots<\frac{b_m}{a_m}.$$因此，每个斜率最多可以出现一次，因此每个向量都可以取原语：$$\gcd(a_i,b_i)=1.$$还，$$\sum a_i\le N,\qquad \sum b_i\le N.$$于是问题就变成了：

 > 选择尽可能多的原始正格向量，斜率严格递增，并满足
 >
 >
 >
 >
 >$$\sum a_i\le N,\qquad \sum b_i\le N.$$---

 # 1. 排序依据$a+b$对于原始向量$(a,b)$，定义其“成本”$$c=a+b.$$为了最大化向量的数量，我们显然采用具有最小可能值的向量$a+b$。 

对于固定的$s$，原始向量$a+b=s$是$$(a,s-a),\qquad 1\le a<s,\quad \gcd(a,s)=1.$$正好有$$\varphi(s)$$这样的向量。 

---

 # 2. 一个完整 shell 的成本

 考虑采用 **所有** 原始向量$a+b=s$。 

因为该集合是对称的$a\leftrightarrow b$,$$\sum a=\sum b=\frac{s\varphi(s)}2$$（为了$s=2$，这等于$1$）。 

因此，如果我们拿走所有的贝壳$2,3,\dots,m$， 然后$$X(m)=Y(m)=\frac12\sum_{s=2}^m s\varphi(s).$$使用的向量数量为$$V(m)=\sum_{s=2}^m \varphi(s).$$因此格点的数量是$$F=V(m)+1.$$---

 # 3. 部分最终 shell

 让$m$最大使得$$X(m)\le N.$$定义剩余容量$$R=N-X(m).$$现在我们还可以从下一个壳中获取向量$s=m+1$。 

每个这样的向量都有总成本$s$，所以每个添加的向量正好消耗$s$合并预算单位$$(\sum a_i)+(\sum b_i)\le 2N.$$剩余的合并预算为$2R$，因此最大额外向量是$$\left\lfloor \frac{2R}{s}\right\rfloor .$$所以$$\boxed{ F(N)=1+\sum_{k=2}^m\varphi(k) +\left\lfloor \frac{2\left(N-\frac12\sum_{k=2}^m k\varphi(k)\right)} {m+1} \right\rfloor }$$在哪里$m$最大的是$$\frac12\sum_{k=2}^m k\varphi(k)\le N.$$这将重现所有给定值：

 -$F(3)=3$-$F(9)=6$-$F(11)=7$-$F(100)=30$-$F(50000)=1898$---

 # 4.Python实现```python
from array import array

N = 10**18

# ---------------------------------------------------------
# Compute Euler phi up to a sufficient limit.
# The required m is about (pi^2 N)^(1/3) ~ 2.15e6.
# ---------------------------------------------------------

LIMIT = 3_000_000

phi = array('Q', range(LIMIT + 1))

for p in range(2, LIMIT + 1):
    if phi[p] == p:                 # p is prime
        for k in range(p, LIMIT + 1, p):
            phi[k] -= phi[k] // p

# ---------------------------------------------------------
# Accumulate complete shells
# ---------------------------------------------------------

used = 0          # X(m)
count = 1         # initial lattice point
s = 2

while True:

    # contribution of the complete shell a+b=s
    add = (s * phi[s]) // 2

    if used + add > N:
        break

    used += add
    count += phi[s]
    s += 1

# ---------------------------------------------------------
# Partial next shell
# ---------------------------------------------------------

remaining = N - used
extra = (2 * remaining) // s

answer = count + extra

print(answer)
```---

 # 5. 代码演练

 ### 筛子```python
phi = array('Q', range(LIMIT + 1))
```初始化$\phi(n)=n$。 

对于每一个素数$p$,```python
phi[k] -= phi[k] // p
```实现欧拉乘积公式$$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$---

 ### 构建完整的 shell

 外壳用$s$,```python
add = (s * phi[s]) // 2
```是添加到两者的金额$x$- 和$y$-总计。 

在预算允许的情况下，我们会继续购买整个贝壳。 

添加的向量数量为```python
count += phi[s]
```因为壳$s$恰好包含$\varphi(s)$原始向量。 

---

 ### 部分最终外壳

 最后一个完整的 shell 之后：```python
remaining = N - used
extra = (2 * remaining) // s
```添加来自下一个壳的尽可能多的向量。 

最后，```python
answer = count + extra
```给出格点总数.
