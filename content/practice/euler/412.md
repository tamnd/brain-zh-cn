[欧拉项目 412 问题](https://projecteuler.net/problem=412)

 ## 解决方案

 **答案：**`38788800`让$a=m-n$。 

形状$L(m,n)$是$m\times m$与右上角的正方形$n\times n$方块被移除。 

如果我们将图表旋转$180^\circ$，条件

 - 每个条目都小于其下方和左侧的条目

 成为标准的Young画面条件

 - 条目向右和向下增加。 

所以$\operatorname{LC}(m,n)$正是该分区的标准Young画面数$$\lambda=(\underbrace{m,\dots,m}_{a\text{ rows}}, \underbrace{a,\dots,a}_{n\text{ rows}}).$$细胞总数为$$|\lambda|=m^2-n^2.$$因此我们可以使用普通的钩长公式：$$f^\lambda=\frac{(|\lambda|)!}{\prod_{c\in\lambda} h(c)}.$$---

 # 1. 钩子长度

 将图分成三个区域。 

让行和列从$1$。 

## A区：$1\le i\le a,\ 1\le j\le a$这些单元格位于左上角$a\times a$堵塞。 

他们的钩子长度是$$h(i,j)=2m-i-j+1.$$对于固定$i$,$$\prod_{j=1}^{a} h(i,j) = \frac{(2m-i)!}{(m+n-i)!}.$$---

 ## B 区：$1\le i\le a,\ a<j\le m$这些是右上角的矩形单元格。 

他们的钩子长度是$$h(i,j)=2m-n-i-j+1.$$对于固定$i$,$$\prod_{j=a+1}^{m} h(i,j) = \frac{(m-i)!}{(a-i)!}.$$---

 ## C 区：$a<i\le m,\ 1\le j\le a$这些是左下角的单元格。 

他们的钩子长度又是$$h(i,j)=2m-n-i-j+1.$$写作$i=a+k$（$1\le k\le n$),$$\prod_{j=1}^{a} h(i,j) = \frac{(m-k)!}{(n-k)!}.$$---

 结合一切：$$\boxed{ \operatorname{LC}(m,n) = \frac{(m^2-n^2)!}{ \left( \prod_{i=1}^{a} \frac{(2m-i)!}{(m+n-i)!} \frac{(m-i)!}{(a-i)!} \right) \left( \prod_{k=1}^{n} \frac{(m-k)!}{(n-k)!} \right) } }$$和$a=m-n$。 

---

 # 2. 模算术技巧

 我们需要$$\operatorname{LC}(10000,5000)\pmod{76543217}.$$让$$p=76543217.$$事实证明$p$是素数。 

还，$$10000^2-5000^2=75\,000\,000 < p.$$所以每个分母项都是模可逆的$p$。 

唯一的大阶乘是$$75\,000\,000!.$$使用威尔逊定理：$$(p-1)! \equiv -1 \pmod p.$$因此$$N! \equiv -\left(\prod_{k=N+1}^{p-1} k\right)^{-1} \pmod p,$$在哪里$$N=75\,000\,000.$$尾部长度仅$$p-1-N = 1\,543\,216,$$这是非常容易管理的。 

---

 # 3.Python实现```python
MOD = 76543217

m = 10000
n = 5000
a = m - n

# Total number of cells
N = m * m - n * n

# ------------------------------------------------------------
# Compute N! mod MOD using Wilson's theorem
#
# (MOD-1)! = -1 (mod MOD)
#
# Therefore:
# N! = -1 / product(N+1 ... MOD-1)
# ------------------------------------------------------------

tail = 1
for x in range(N + 1, MOD):
    tail = (tail * x) % MOD

num = (-pow(tail, MOD - 2, MOD)) % MOD

# ------------------------------------------------------------
# Precompute factorials up to 2m
# ------------------------------------------------------------

limit = 2 * m

fac = [1] * (limit + 1)
for i in range(1, limit + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (limit + 1)
invfac[limit] = pow(fac[limit], MOD - 2, MOD)

for i in range(limit, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

# ------------------------------------------------------------
# Compute hook product denominator
# ------------------------------------------------------------

den = 1

# Region A and Region B
for i in range(1, a + 1):

    # (2m-i)! / (m+n-i)!
    den = den * fac[2 * m - i] % MOD
    den = den * invfac[m + n - i] % MOD

    # (m-i)! / (a-i)!
    den = den * fac[m - i] % MOD
    den = den * invfac[a - i] % MOD

# Region C
for k in range(1, n + 1):

    # (m-k)! / (n-k)!
    den = den * fac[m - k] % MOD
    den = den * invfac[n - k] % MOD

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

answer = num * pow(den, MOD - 2, MOD) % MOD

print(answer)
```---
