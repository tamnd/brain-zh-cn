[欧拉项目 423 问题](https://projecteuler.net/problem=423)

 ## 解决方案

 **答案：**`653972374`让$$C(n)=\#\{\text{length-}n\text{ die sequences with }c\le \pi(n)\},$$在哪里$c$是相邻相等对的数量。 

我们必须计算$$S(50\,000\,000)=\sum_{n=1}^{50\,000\,000} C(n) \pmod{1\,000\,000\,007}.$$---

 # 1.数学分析

 ## 精确计数序列$k$等邻接

 长度序列$n$有$n-1$相邻的间隙。 

假设准确地说$k$这些差距是相等的。 

- 选择$k$等间隙：$$\binom{n-1}{k}.$$- 选择第一个骰子值：$$6.$$- 每一个不平等的差距都会迫使改变，给予$5$各有选择。 

有$n-1-k$这样的差距。 

因此：$$\boxed{ N(n,k)=6\binom{n-1}{k}5^{\,n-1-k} }$$所以$$\boxed{ C(n)=6\sum_{k=0}^{\pi(n)} \binom{n-1}{k}5^{\,n-1-k} }$$这立即验证：$$C(4)=6\left(5^3+3\cdot 5^2+3\cdot 5\right)=1290.$$---

 # 2. 快速复发

 定义$$D(n)=\frac{C(n)}{6} = \sum_{k=0}^{\pi(n)} \binom{n-1}{k}5^{\,n-1-k}.$$还定义$$p=\pi(n), \qquad B_n=\binom{n-1}{p}5^{\,n-1-p}.$$---

 ## 复合过渡

 如果$n+1$是复合的，那么$\pi(n+1)=p$。 

使用帕斯卡：$$\binom{n}{k}=\binom{n-1}{k}+\binom{n-1}{k-1}.$$然后$$D(n+1) = 6D(n)-B_n.$$因此$$\boxed{ C(n+1)=6C(n)-6B_n }$$---

 ## 素数过渡

 如果$n+1$是素数，那么$\pi(n+1)=p+1$。 

新的求和上限增加了一项：$$D(n+1) = 6D(n) + \binom{n-1}{p+1}5^{\,n-1-p}.$$使用$$\binom{n-1}{p+1} = \binom{n-1}{p}\frac{n-1-p}{p+1},$$我们得到$$\boxed{ C(n+1) = 6C(n) + 6B_n\frac{n-1-p}{p+1} }$$---

 # 3. 更新$B_n$我们还需要重复$B_n$。 

- -

＃＃ 如果$n+1$是复合的

 然后$p$保持固定：$$B_{n+1} = \binom{n}{p}5^{n-p} = B_n\cdot \frac{5n}{n-p}.$$所以$$\boxed{ B_{n+1}=B_n\frac{5n}{n-p} }$$- -

＃＃ 如果$n+1$是素数

 然后$p\to p+1$:$$B_{n+1} = \binom{n}{p+1}5^{\,n-1-p} = B_n\frac{n}{p+1}.$$因此$$\boxed{ B_{n+1}=B_n\frac{n}{p+1} }$$---

 # 4. 复杂性

 一切都变成了$O(L)$每一步仅需要恒定工作量的循环。 

我们筛选素数至$50\,000\,000$，预先计算模逆，并迭代一次。 

在优化的 C++ 中，这可以在几秒钟内轻松运行。 

---

 # 5.Python实现```python
MOD = 1_000_000_007
L = 50_000_000

# ---------- sieve ----------
is_prime = bytearray(b"\x01") * (L + 1)
is_prime[0] = is_prime[1] = 0

p = 2
while p * p <= L:
    if is_prime[p]:
        step = p
        start = p * p
        is_prime[start:L + 1:step] = b"\x00" * (((L - start) // step) + 1)
    p += 1

# ---------- modular inverses ----------
inv = [0] * (L + 1)
inv[1] = 1

for i in range(2, L + 1):
    inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

# ---------- recurrence ----------
# C(1) = 6
C = 6

# B_1 = binom(0,0) * 5^0 = 1
B = 1

S = 6
pi_n = 0

for n in range(1, L):

    if is_prime[n + 1]:
        # prime transition

        extra = (
            6
            * B
            % MOD
            * (n - 1 - pi_n)
            % MOD
            * inv[pi_n + 1]
        ) % MOD

        C = (6 * C + extra) % MOD

        pi_n += 1

        B = B * n % MOD * inv[pi_n] % MOD

    else:
        # composite transition

        C = (6 * C - 6 * B) % MOD

        B = (
            B
            * 5
            % MOD
            * n
            % MOD
            * inv[n - pi_n]
        ) % MOD

    S += C
    S %= MOD

print(S)
```---

 # 6. 代码演练

 ### 优质筛

 我们计算所有整数的素性$50\,000\,000$。 

这让我们知道是否$\pi(n)$每一步都增加。 

---

 ### 模逆

 递归除以数字，例如$p+1$和$n-p$。 

使用：$$\text{inv}[i] = -(M//i)\cdot \text{inv}[M\bmod i] \pmod M$$我们预先计算线性时间内的所有逆。 

---

 ### 主循环

 我们维持：

 -`C = C(n)`-`B = B_n`-`pi_n = π(n)`每一步：

 - 如果$n+1$是质数：

 使用素数递推，
 - 否则：

 使用复合递归。 

我们积累成`S`。
