[项目欧拉问题 592](https://projecteuler.net/problem=592)

 ## 解决方案

 **答案：**`13415DF2BE9C`让$$M = 20! = 2432902008176640000.$$我们想要最后 12 个十六进制数字$M!$在尾随十六进制零之前。 

尾随十六进制零对应于一个因子$16=2^4$。 

所以如果$$v_2(M!)=\sum_{k\ge1}\left\lfloor \frac{M}{2^k}\right\rfloor,$$那么尾随十六进制零的数量是$$\left\lfloor \frac{v_2(M!)}{4}\right\rfloor.$$因此我们计算$$\frac{M!}{16^{\lfloor v_2(M!)/4\rfloor}} \pmod{16^{12}}.$$等效地，工作模$$16^{12}=2^{48},$$我们删除所有因素$2$从阶乘积中，保留剩余的奇数部分模$2^{48}$，最后恢复剩余电量$2^{v_2(M!)\bmod 4}$。 

执行此操作的有效方法是标准递归奇阶乘算法对 2 求模幂：$$G(n)=\frac{n!}{2^{v_2(n!)}},$$带有递归$$G(n)=G\!\left(\left\lfloor \frac n2\right\rfloor\right)\cdot \prod_{\substack{1\le k\le n\\ k\text{ odd}}}k \pmod{2^{48}}.$$使用奇数余数的周期性模$2^{48}$，这减少了$O(\log n)$递归深度。 

一个干净的 Python 实现是：```python
from functools import cache
from math import factorial

MOD = 1 << 48
N = factorial(20)

def v2_factorial(n):
    s = 0
    while n:
        n //= 2
        s += n
    return s

@cache
def odd_fact(n):
    if n == 0:
        return 1

    # recursive odd-part reduction
    res = odd_fact(n // 2)

    # multiply odd terms
    p = 1
    for k in range(1, n + 1, 2):
        p = (p * k) % MOD

    return (res * p) % MOD

v2 = v2_factorial(N)

# odd part
g = odd_fact(N)

# restore remaining twos after removing hexadecimal zeros
g = (g * pow(2, v2 % 4, MOD)) % MOD

answer = f"{g:012X}"
print(answer)
```对于样本：```python
20! = 21C3677C82B40000 (hex)
```删除四个尾随的十六进制零给出：```python
21C3677C82B4
```与声明相符。
