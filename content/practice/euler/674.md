[项目欧拉问题 674](https://projecteuler.net/problem=674)

 ## 解决方案

 **答案：**`416678753`让$$\mathcal I(x,y)=(1+x+y)^2+y-x.$$关键的观察是$\mathcal I$是非负整数有序对的单射编码。 

确实，写$$s=1+x+y.$$然后$$\mathcal I(x,y)=s^2+(y-x).$$自从$0\le y-x\le s-1$在绝对值中，每个值都位于正方形周围的唯一区间内$s^2$。 因此从$n=\mathcal I(x,y)$我们可以独特地恢复：

 -$s=\lfloor \sqrt n\rfloor$,
 -$d=n-s^2=y-x$,
 - 因此$$x=\frac{s-1-d}{2},\qquad y=\frac{s-1+d}{2}.$$所以：$$\mathcal I(a,b)=\mathcal I(c,d)\iff a=c\text{ and }b=d.$$这意味着$\mathcal I$其行为与一阶项统一中的构造函数符号完全相同。 

---

 # 1. 将问题转化为统一问题

 每个表达式都是：

 - 变量，或
 -$\mathcal I(A,B)$。 

因此求解$$e_1=e_2$$递归地减少到：$$\mathcal I(A,B)=\mathcal I(C,D) \iff A=C \text{ and } B=D.$$这是标准罗宾逊统一。 

示例：

 -$A=\mathcal I(x,\mathcal I(z,t))$-$B=\mathcal I(\mathcal I(y,z),y)$匹配参数给出：$$x=\mathcal I(y,z), \qquad \mathcal I(z,t)=y.$$替换：$$x=\mathcal I(\mathcal I(z,t),z).$$最少设置自由变量（$z=t=0$) 给出：$$y=\mathcal I(0,0)=1,$$

$$x=\mathcal I(1,0)=3,$$因此$$A=B=\mathcal I(3,1)=23.$$正如所述。 

---

 # 2. 为什么当所有自由变量都满足时会出现最小值$0$对于非负整数，$$\mathcal I(x+1,y)-\mathcal I(x,y)=2(1+x+y)>0,$$

$$\mathcal I(x,y+1)-\mathcal I(x,y)=2(2+x+y)>0.$$所以$\mathcal I$每个参数都是严格递增的。 

统一后，任何不受约束强制的变量都是自由非负整数。 由于每个变量的表达式都是单调的，因此通过将每个剩余的自由变量设置为来获得最小同时值$0$。 

因此算法是：

 1. 将表达式解析成树。 
2. 尝试统一。 
3. 如果不可能→贡献$0$。 
4. 否则使用所有剩余变量评估统一表达式$0$。 

只有最后一个$9$需要数字，因此计算是模数完成的$10^9$。

 # 3.Python实现```python
from __future__ import annotations
import sys

MOD = 10**9

# -------------------------------------------------
# Term representation
# -------------------------------------------------

class Var:
    __slots__ = ("name",)

    def __init__(self, name: str):
        self.name = sys.intern(name)

class INode:
    __slots__ = ("a", "b")

    def __init__(self, a, b):
        self.a = a
        self.b = b

# -------------------------------------------------
# Parsing
# -------------------------------------------------

def parse_expr(s: str):
    i = 0
    n = len(s)

    def parse():
        nonlocal i

        if s[i] == "I":
            i += 2  # skip "I("

            left = parse()

            i += 1  # skip ','

            right = parse()

            i += 1  # skip ')'

            return INode(left, right)

        start = i
        while i < n and s[i].isalpha():
            i += 1

        return Var(s[start:i])

    return parse()

# -------------------------------------------------
# Unification
# -------------------------------------------------

def unify(t1, t2):
    subs = {}
    occurs_cache = {}

    def deref(t):
        while isinstance(t, Var) and t.name in subs:
            nxt = subs[t.name]

            # path compression
            if isinstance(nxt, Var) and nxt.name in subs:
                subs[t.name] = subs[nxt.name]

            t = nxt

        return t

    def occurs(vname, t):
        t = deref(t)

        key = (vname, id(t))
        if key in occurs_cache:
            return occurs_cache[key]

        stack = [t]
        seen = set()

        while stack:
            cur = deref(stack.pop())

            if isinstance(cur, Var):
                if cur.name == vname:
                    occurs_cache[key] = True
                    return True
            else:
                nid = id(cur)

                if nid in seen:
                    continue

                seen.add(nid)

                stack.append(cur.a)
                stack.append(cur.b)

        occurs_cache[key] = False
        return False

    stack = [(t1, t2)]

    while stack:
        a, b = stack.pop()

        a = deref(a)
        b = deref(b)

        if a is b:
            continue

        if isinstance(a, Var) and isinstance(b, Var):
            if a.name == b.name:
                continue

        if isinstance(a, Var):
            if occurs(a.name, b):
                return None

            subs[a.name] = b
            continue

        if isinstance(b, Var):
            if occurs(b.name, a):
                return None

            subs[b.name] = a
            continue

        if isinstance(a, INode) and isinstance(b, INode):
            stack.append((a.a, b.a))
            stack.append((a.b, b.b))
            continue

        return None

    return subs

# -------------------------------------------------
# Evaluation
# -------------------------------------------------

def i_op(x, y):
    s = (1 + x + y) % MOD
    return (s * s + y - x) % MOD

def evaluate(root, subs):
    memo = {}

    def deref(t):
        while isinstance(t, Var) and t.name in subs:
            t = subs[t.name]
        return t

    def rec(t):
        t = deref(t)

        if isinstance(t, Var):
            return 0

        tid = id(t)

        if tid in memo:
            return memo[tid]

        x = rec(t.a)
        y = rec(t.b)

        val = i_op(x, y)

        memo[tid] = val
        return val

    return rec(root)

# -------------------------------------------------
# Solve
# -------------------------------------------------

def least_simultaneous_value(e1, e2):
    subs = unify(e1, e2)

    if subs is None:
        return 0

    return evaluate(e1, subs)

def main():
    with open("I-expressions.txt") as f:
        terms = [parse_expr(line.strip())
                 for line in f if line.strip()]

    total = 0

    n = len(terms)

    for i in range(n):
        for j in range(i + 1, n):
            total += least_simultaneous_value(
                terms[i], terms[j]
            )

    print(total % MOD)

if __name__ == "__main__":
    main()
```---

 # 4. 代码演练

 ## 解析`parse_expr`将字符串转换为$$I(x,I(z,t))$$转化为二叉树：

 -`Var(name)`-`INode(left,right)`---

 ## 统一`unify(t1,t2)`实现罗宾逊统一：

 - 变量与变量，
 - 变量与复合项，
 - 复合与复合。 

发生检查可防止循环替换，例如：$$x = I(x,y).$$如果统一失败，则没有非负解。 

---

 ## 评价

 统一后，所有无约束变量均设置为$0$，这给出了最小可能的值，因为$\mathcal I$是单调递增的。

 # 5. 样本验证

 对于$$A = I(x,I(z,t)),$$

$$B = I(I(y,z),y),$$

$$C = I(I(x,z),y),$$程序获得：

 -$LSV(A,B)=23$,
 -$LSV(A,C)=0$,
 -$LSV(B,C)=3$,

 所以总数是$$23+0+3=26,$$与声明相符。
