[欧拉计划问题 62](https://projecteuler.net/problem=62)

 ## 解决方案

 **答案：**`127035954683`我们寻找**最小的立方体**，其中**其数字的五个排列也是立方体**。 

关键的观察是数字排列保留了数字的多重集。 因此，我们可以通过规范的“数字签名”对立方体进行分类，而不是成对比较立方体。 

一个自然的签名是：

 - 对立方体的数字进行排序。 
- 任何两个彼此排列的数字将共享相同的排序数字字符串。 

例如：$$345^3 = 41063625$$对数字进行排序：$$41063625 \to 01234566$$现在：$$384^3 = 56623104 \to 01234566$$

$$405^3 = 66430125 \to 01234566$$所以所有三个立方体都属于同一个签名类。 

---

 # 数学分析

 假设：$$n^3 = c$$定义签名：$$\sigma(c) = \text{sorted digits of } c$$然后：$$\sigma(a^3)=\sigma(b^3)$$当且仅当$a^3$和$b^3$是彼此的排列。 

因此，问题简化为：

 > 找到其签名类恰好包含五个立方体的最小立方体。 

---

 ## 高效策略

 所有立方体之间的强力比较将是昂贵的。 

相反：

 1. 依次生成立方体。 
2. 计算每个立方体的数字签名。 
3. 将按签名分组的多维数据集存储在字典中。 
4. 当一个签名累积到五个立方体时，记录下来。 
5. 确保班级有**正好**五个立方体（不能更多）。 

一个微妙的问题：

 - 如果我们在到达五个立方体后立即停止，则后面的立方体可能会创建第六种排列。 

为了避免这种情况，请处理按数字长度分组的立方体。 

为什么？ 

- 任何排列都具有相同的位数。 
- 一旦我们移动到具有更多数字的立方体，则不再有立方体可以属于之前的数字长度类别。 

因此：

 - 处理所有立方体$d$数字。 
- 完成该数字长度后，检查组。 
- 任何恰好有五个立方体的组都已完成。 

---

 # Python 实现```python
from collections import defaultdict

# Dictionary:
# key   -> sorted digit signature
# value -> list of cubes having that signature
groups = defaultdict(list)

n = 1
current_length = 1

while True:
    cube = n ** 3

    # Number of digits in the cube
    length = len(str(cube))

    # When digit length changes, previous groups are complete
    if length > current_length:

        # Check all groups from the previous digit length
        candidates = [
            cubes for cubes in groups.values()
            if len(cubes) == 5
        ]

        # If any valid group exists, return the smallest cube
        if candidates:
            answer = min(min(cubes) for cubes in candidates)
            print(answer)
            break

        # Reset for the next digit length
        groups.clear()
        current_length = length

    # Create canonical digit signature
    signature = ''.join(sorted(str(cube)))

    # Store cube in its group
    groups[signature].append(cube)

    n += 1
```---
