[欧拉项目 643 问题](https://projecteuler.net/problem=643)

 ## 解决方案

 **答案：**`968274154`让$$f(n)=\#\{(p,q):1\le p<q\le n,\ \gcd(p,q)=2^t,\ t>0\}.$$我们需要$f(10^{11}) \bmod 1\,000\,000\,007$。 

## 1.数学分析

 如果$\gcd(p,q)=2^t$和$t>0$， 写$$p=2^t a,\qquad q=2^t b,$$在哪里$\gcd(a,b)=1$。 

自从$p<q\le n$,$$1\le a<b\le \left\lfloor \frac{n}{2^t}\right\rfloor.$$因此对于每个$t\ge 1$，有效对的数量等于互质对的数量$(a,b)$和$a<b\le m$， 在哪里$$m=\left\lfloor \frac{n}{2^t}\right\rfloor.$$### 计算互质对

 对于固定$b$，数量$a<b$和$\gcd(a,b)=1$是欧拉的 totient：$$\varphi(b).$$因此$$C(m)=\sum_{b=2}^{m}\varphi(b).$$定义totient求和函数$$\Phi(m)=\sum_{k=1}^{m}\varphi(k).$$然后$$C(m)=\Phi(m)-1.$$所以，$$f(n) = \sum_{t\ge 1} \left( \Phi\!\left(\left\lfloor \frac{n}{2^t}\right\rfloor\right)-1 \right).$$自从$2^t>n$最终，仅$O(\log n)$条款存在。 

---

 ### 快速计算$\Phi(n)$使用经典身份$$\sum_{d\le n}\varphi(d)\left\lfloor \frac{n}{d}\right\rfloor = \frac{n(n+1)}{2}.$$重新排列：$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n} \Phi\!\left(\left\lfloor \frac{n}{d}\right\rfloor\right).$$关键的优化是将相等的值分组$\lfloor n/d\rfloor$：

如果$$v=\left\lfloor \frac{n}{d}\right\rfloor,$$然后所有$d\in[l,r]$分享相同的$v$， 在哪里$$r=\left\lfloor \frac{n}{v}\right\rfloor.$$这将复杂性降低到大约$O(n^{2/3})$- 风格记忆分而治之，足够快$10^{11}$。

 ## 2.Python实现```python
MOD = 1_000_000_007
LIMIT = 5_000_000

# Sieve Euler phi up to LIMIT
phi = list(range(LIMIT + 1))

for i in range(2, LIMIT + 1):
    if phi[i] == i:  # i is prime
        for j in range(i, LIMIT + 1, i):
            phi[j] -= phi[j] // i

# Prefix sums of phi
phi_prefix = [0] * (LIMIT + 1)

running = 0
for i in range(LIMIT + 1):
    running += phi[i]
    phi_prefix[i] = running

# Memoized summatory totient
memo = {0: 0}

def Phi(n):
    """Return sum_{k<=n} phi(k)."""
    if n <= LIMIT:
        return phi_prefix[n]

    if n in memo:
        return memo[n]

    result = n * (n + 1) // 2

    l = 2
    while l <= n:
        v = n // l
        r = n // v

        result -= (r - l + 1) * Phi(v)
        l = r + 1

    memo[n] = result
    return result

def f(n):
    total = 0
    t = 1

    while True:
        m = n >> t  # floor(n / 2^t)

        if m == 0:
            break

        total += Phi(m) - 1
        total %= MOD

        t += 1

    return total

print(f(10**11))
```---

 ## 3. 代码演练

 ### 步骤 1：Totient 筛

 我们计算所有$\varphi(k)$直至截止（`LIMIT = 5_000_000`）使用标准欧拉筛。 

### 步骤 2：前缀和

 我们建造$$\Phi(n)=\sum_{k\le n}\varphi(k)$$对于所有小$n$。 

### 步骤 3：递归求和 totient

 对于大型$n$，我们使用$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n} \Phi\!\left(\left\lfloor \frac{n}{d}\right\rfloor\right),$$将相同的商分组以提高效率。 

### 步骤 4：计算$f(n)$我们求和$$\Phi\!\left(\left\lfloor n/2^t\right\rfloor\right)-1$$为了$t=1,2,\dots$。 

---

 ### 对给定示例的验证

 对于$n=100$:$$f(100)=1031,$$与声明相符。 

为了$n=10^6$:$$f(10^6)\equiv 321418433 \pmod{1\,000\,000\,007},$$也符合说法。 

所以推导和实现是一致的。
