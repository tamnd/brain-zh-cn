[欧拉项目 421 问题](https://projecteuler.net/problem=421)

 ## 解决方案

 **答案：**`2304215802083466198`让$$S=\sum_{n=1}^{10^{11}} s(n,10^8),$$在哪里$s(n,m)$是**不同**素因数的总和$p\le m$的$n^{15}+1$。 

关键是求和的顺序颠倒过来。 

---

 ## 1. 重写求和

 素数$p$有助于$s(n,10^8)$当且仅当$$p\mid n^{15}+1,$$IE。$$n^{15}\equiv -1 \pmod p.$$所以，$$S=\sum_{p\le 10^8} p\cdot \#\{1\le n\le 10^{11}: n^{15}\equiv -1 \pmod p\}.$$所以对于每个素数$p$，我们只需要计算剩余类别的模数$p$满意的$$x^{15}\equiv -1 \pmod p.$$---

 # 2. 解决方案的结构

 对于奇素数$p$, 乘法群$$(\mathbb Z/p\mathbb Z)^\times$$是有序循环的$p-1$。 

观察：$$x^{15}\equiv -1 \iff (-x)^{15}\equiv 1.$$所以解完全对应于 15 次单位根。 

因此解的数量为$$d=\gcd(15,p-1),$$因此$d\in\{1,3,5,15\}$。 

对于素数$p>5$，这仅取决于$p\bmod 30$:

 |$p\bmod 30$|$d$|
 | --- | --- |
 |$1$|$15$|
 |$11$|$5$|
 |$7,13,19$|$3$|
 |$17,23,29$|$1$|

 ---

 # 3. 计算出现次数$10^{11}$修复素数$p$。 

写$$10^{11}=qp+t,\qquad 0\le t<p.$$每个有效残基类模$p$出现：

 - 正是$q$次之间$1,\dots,10^{11}$,
 - 如果残基是，则再加上一次出现$\le t$。 

所以如果有效的残基是$r_1,\dots,r_d$， 然后$$\#\{n\le 10^{11}: p\mid n^{15}+1\} = dq+\#\{i:r_i\le t\}.$$因此，计算是完全模块化的。 

---

 # 4. 根的高效生成

 如果$u^{15}\equiv1$， 然后$n\equiv -u\pmod p$解决了一致性问题。 

因此我们生成了 15 次单位根的子群。 

获得阶子群的生成元$d$，我们计算$$g=a^{(p-1)/d}\pmod p$$用于小型试验基地$a$。 

然后$$1,g,g^2,\dots,g^{d-1}$$正好是 15 次方根。 

对应的解决方案是$$n\equiv -1,-g,-g^2,\dots \pmod p.$$---

 # 5.Python实现```python
from math import isqrt

# ---------------------------------------------------------
# Odd-only sieve of Eratosthenes
# ---------------------------------------------------------
def iter_odd_primes_upto(limit):
    size = (limit + 1) // 2
    sieve = bytearray(b"\x01") * size
    sieve[0] = 0

    r = isqrt(limit)

    for i in range(1, (r // 2) + 1):
        if sieve[i]:
            p = 2 * i + 1
            start = (p * p) // 2
            sieve[start::p] = b"\x00" * (((size - start - 1) // p) + 1)

    idx = sieve.find(1, 1)

    while idx != -1:
        yield 2 * idx + 1
        idx = sieve.find(1, idx + 1)

# ---------------------------------------------------------
# Test whether g has exact order 15 mod p
# ---------------------------------------------------------
def is_order_15(g, p):
    return (
        g != 1 and
        pow(g, 3, p) != 1 and
        pow(g, 5, p) != 1
    )

# ---------------------------------------------------------
# Find generator of subgroup of order d
# ---------------------------------------------------------
def find_generator(p, d):
    exp = (p - 1) // d

    for a in range(2, 100):
        g = pow(a, exp, p)

        if d in (3, 5):
            if g != 1:
                return g

        else:  # d == 15
            if is_order_15(g, p):
                return g

    raise RuntimeError("generator not found")

# ---------------------------------------------------------
# Main solver
# ---------------------------------------------------------
def solve(L=10**11, M=10**8):

    # d = gcd(15, p-1) determined by p mod 30
    d_table = [1] * 30
    d_table[1] = 15
    d_table[11] = 5
    d_table[7] = d_table[13] = d_table[19] = 3

    ans = 0

    # prime 2
    ans += 2 * ((L + 1) // 2)

    for p in iter_odd_primes_upto(M):

        d = d_table[p % 30]

        q, t = divmod(L, p)

        # only residue is -1 mod p
        if d == 1:
            cnt = q + (1 if t == p - 1 else 0)
            ans += p * cnt
            continue

        # subgroup generator
        g = find_generator(p, d)

        threshold = p - t

        u = 1
        extra = 0

        for _ in range(d):
            if u >= threshold:
                extra += 1
            u = (u * g) % p

        cnt = d * q + extra

        ans += p * cnt

    return ans

print(solve())
