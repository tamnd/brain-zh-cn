[项目欧拉问题 197](https://projecteuler.net/problem=197)

 ## 解决方案

 **答案：**`1.710637717`让$$f(x)=\left\lfloor 2^{30.403243784-x^2}\right\rfloor \cdot 10^{-9}, \qquad u_{n+1}=f(u_n),\qquad u_0=-1.$$我们必须计算$$u_{10^{12}}+u_{10^{12}+1}$$到小数点后 9 位。 

关键的观察结果是序列**不**收敛到单个固定点。 相反，它极其快速地收敛到 **2 周期**：$$u_{2k}\to a,\qquad u_{2k+1}\to b,$$和$$a=f(b),\qquad b=f(a).$$因此，对于巨大的$n$,$$u_n+u_{n+1}\approx a+b.$$所以我们只需要迭代直到交替项稳定。 

---

 # 数学分析

 定义$$u_{n+1}=f(u_n).$$一个不动点满足$$u=f(u),$$但在数值上，迭代在两个附近的值之间振荡。 

因此我们转而寻求 2 周期：$$a=f(b),\qquad b=f(a).$$等价地，$$f(f(a))=a.$$由于floor操作使得图在极限环附近强烈收缩，收敛速度非常快。 

问题陈述中建议的停止标准是$$|u_{n+2}-u_n|<10^{-12}.$$一旦发生这种情况，该序列就有效地进入了交替对。 

---

 # Python 实现```python
from decimal import Decimal, getcontext, ROUND_FLOOR

# Use high precision
getcontext().prec = 50

TEN_NEG_9 = Decimal('1e-9')
C = Decimal('30.403243784')
TWO = Decimal(2)

def f(x):
    """
    Compute:
        floor(2^(30.403243784 - x^2)) * 1e-9
    using Decimal arithmetic.
    """
    exponent = C - x * x

    # Decimal power
    value = TWO ** exponent

    # floor(value)
    floored = value.to_integral_value(rounding=ROUND_FLOOR)

    return floored * TEN_NEG_9

# Initial value
u0 = Decimal(-1)

u_prev2 = u0
u_prev1 = f(u_prev2)

while True:
    u = f(u_prev1)

    # Check convergence to a 2-cycle
    if abs(u - u_prev2) < Decimal('1e-12'):
        break

    u_prev2, u_prev1 = u_prev1, u

# The 2-cycle values
a = u_prev2
b = u_prev1

answer = a + b

# Print with exactly 9 digits after decimal
print(format(answer, '.9f'))
```---
