[欧拉项目问题 148](https://projecteuler.net/problem=148)

 ## 解决方案

 **答案：**`2129970655314432`让行$n$帕斯卡三角形的$$\binom{n}{0},\binom{n}{1},\dots,\binom{n}{n}.$$我们希望条目数**不能被整除$7$**位居第一$10^9$行（行$0$通过$10^9-1$）。 

关键工具是**卢卡斯定理**。 

---

 # 1. 数学分析

 ## 步骤 1 — 卢卡斯定理

 对于素数$p$,$$\binom{n}{k} \not\equiv 0 \pmod p$$当且仅当每个碱基-$p$的数字$k$最多是对应的数字$n$。 

写$$n = n_r n_{r-1}\dots n_0 \quad \text{(base }7\text{)}.$$然后是行中系数的数量$n$不能被整除$7$是$$\prod_{i=0}^{r}(n_i+1).$$为什么？ 

对于每个数字位置$i$, 数字$k_i$可以是任何整数$$0 \le k_i \le n_i,$$准确地给予$n_i+1$独立选择。 

所以：$$f(n)=\#\{\text{entries in row }n\text{ not divisible by }7\} =\prod (n_i+1).$$---

 ## 步骤 2 — 小示例

 采取$n=6$。 

在基地$7$,$$6 = (6)_7.$$所以$$f(6)=6+1=7.$$事实上，第 6 行是：$$1,\ 6,\ 15,\ 20,\ 15,\ 6,\ 1$$并且都不能被 7 整除。 

---

 采取$n=8$。$$8=(11)_7.$$因此$$f(8)=(1+1)(1+1)=4.$$事实上，第 8 行只有 4 个不能被 7 整除的条目。 

---

 # 2. 高效求和

 我们需要$$S(N)=\sum_{n=0}^{N-1} f(n),$$和$N=10^9$。 

---

 ## 步骤 3 — 完整块

 考虑所有最多有$m$以 7 为基数的数字：$$0 \le n < 7^m.$$然后$$S(7^m) = \sum_{n_0=0}^{6}\cdots\sum_{n_{m-1}=0}^{6} \prod (n_i+1).$$因为产品分离：$$S(7^m) = \left(\sum_{d=0}^{6}(d+1)\right)^m.$$但$$1+2+3+4+5+6+7 = 28.$$因此$$S(7^m)=28^m.$$这是关键的简化。 

---

 # 3.递归数字DP

 现在写$N$在基地7。 

我们从最高有效位到最低有效位处理数字。 

假设当前数字是$d$，我们已经积累了一个乘法前缀$P$。 

对于较小的前导数字$x<d$：

 - 剩余位置计数：$$28^{\text{remaining digits}}$$- 当前数字的贡献：$$(x+1)$$- 前面数字的贡献：$$P$$所以我们添加$$P \cdot (1+2+\cdots+d)\cdot 28^r.$$然后继续：$$P \leftarrow P(d+1).$$---

 # 4. Base-7 表示$10^9$计算能力：$$7^{10}=282475249,$$

$$7^{11}=1977326743.$$因此$10^9$有 11 个以 7 为基数的数字。 

转换：$$10^9=(3353160061)_7.$$数字：$$3,3,5,3,1,6,0,0,6,1.$$（省略前导零）。 

---

 # 5.Python 实现```python
def count_not_divisible(N, p=7):
    """
    Returns the number of entries not divisible by p
    in the first N rows of Pascal's triangle.
    """

    # Convert N to base p digits
    digits = []
    x = N
    while x > 0:
        digits.append(x % p)
        x //= p

    digits.reverse()

    # Precompute powers of 28
    # because sum_{d=0}^{6} (d+1) = 28
    powers = [1]
    for _ in range(len(digits)):
        powers.append(powers[-1] * 28)

    ans = 0
    prefix_product = 1
    m = len(digits)

    for i, d in enumerate(digits):
        remaining = m - i - 1

        # Sum of (x+1) for x = 0..d-1
        # = d(d+1)/2
        smaller_sum = d * (d + 1) // 2

        ans += (
            prefix_product
            * smaller_sum
            * powers[remaining]
        )

        # Extend prefix with actual digit
        prefix_product *= (d + 1)

    return ans

print(count_not_divisible(10**9))
```---

 # 6. 代码演练

 ## 基数转换```python
while x > 0:
    digits.append(x % p)
    x //= p
```转换$N$进入基地 7。 

---

 ## 预计算能力```python
powers.append(powers[-1] * 28)
```用途：$$S(7^m)=28^m.$$---

 ## 主循环

 每个数字：```python
smaller_sum = d * (d + 1) // 2
```因为$$1+2+\cdots+d=\frac{d(d+1)}{2}.$$然后：```python
ans += prefix_product * smaller_sum * powers[remaining]
```计算该位置上数字较小的所有数字。 

最后：```python
prefix_product *= (d + 1)
```扩展有效的前缀。

 评估为$$N=10^9$$给出$$2129970655314432.$$这是有道理的：
