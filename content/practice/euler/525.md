[欧拉项目问题 525](https://projecteuler.net/problem=525)

 ## 解决方案

 **答案：**`44.69921807`设椭圆为$$\frac{x^2}{a^2}+\frac{(y-b)^2}{b^2}=1$$所以在身体坐标（以椭圆中心为中心）中，边界是$$r(t)=(a\cos t,\; b\sin t), \qquad -\frac{\pi}{2}\le t\le \frac{3\pi}{2}.$$在$t=-\pi/2$，底部点接触地面。 

## 1.数学分析

 当椭圆滚动而不滑移时，接触点围绕边界不断变化。 

### 第 1 步：接触几何形状

 为了点$r(t)$，切向量是$$r'(t)=(-a\sin t,\; b\cos t),$$其大小为$$q(t)=\sqrt{a^2\sin^2 t+b^2\cos^2 t}.$$这是无穷小的弧长因子：$$ds=q(t)\,dt.$$参数处椭圆的外向法线$t$正比于$$\left(\frac{\cos t}{a},\frac{\sin t}{b}\right).$$在水平线上滚动意味着该法线在世界坐标中垂直向下。 因此椭圆旋转角度$\phi(t)$满足$$\phi(t) = -\frac{\pi}{2} -\operatorname{atan2} \!\left(\frac{\sin t}{b},\frac{\cos t}{a}\right).$$为了使旋转连续一圈，我们展开这个角度，使椭圆旋转通过$2\pi$。 

### 步骤 2：中心坐标

 由于没有滑动，接地点前进了边界弧长：$$x_{\text{contact}}(t) = \int q(t)\,dt.$$如果旋转后的接触点在世界坐标系中为$$R_{\phi(t)}r(t) = (x_r(t),y_r(t)),$$那么椭圆的中心就是$$X(t)=x_{\text{contact}}(t)-x_r(t), \qquad Y(t)=-y_r(t).$$因此路径长度为$$C(a,b) = \int \sqrt{ \left(\frac{dX}{dt}\right)^2 + \left(\frac{dY}{dt}\right)^2 }\,dt.$$一整圈的数值积分给出了所需的值。 

作为检查、评估$C(2,4)$重现问题陈述：$$C(2,4)\approx 21.38816906.$$---

 ## 2.Python实现```python
import mpmath as mp

mp.mp.dps = 50  # high precision

def C(a, b):
    # Rotation angle of ellipse so tangent is horizontal
    def phi_raw(t):
        return -mp.pi / 2 - mp.atan2(mp.sin(t) / b,
                                      mp.cos(t) / a)

    # Unwrap angle to make one continuous full turn
    def phi(t):
        p = phi_raw(t)
        if t > -mp.pi / 2:
            while p > 0:
                p -= 2 * mp.pi
        return p

    # Arc-length factor of ellipse boundary
    def q(t):
        return mp.sqrt(a*a * mp.sin(t)**2 +
                       b*b * mp.cos(t)**2)

    # Rotated boundary point in world coordinates
    def x_rel(t):
        p = phi(t)
        x = a * mp.cos(t)
        y = b * mp.sin(t)
        return x * mp.cos(p) - y * mp.sin(p)

    def y_rel(t):
        p = phi(t)
        x = a * mp.cos(t)
        y = b * mp.sin(t)
        return x * mp.sin(p) + y * mp.cos(p)

    # Speed of ellipse center
    def integrand(t):
        dx = q(t) - mp.diff(x_rel, t)
        dy = -mp.diff(y_rel, t)
        return mp.sqrt(dx*dx + dy*dy)

    return mp.quad(integrand,
                   [-mp.pi/2, 3*mp.pi/2])

# Verify sample
print(C(2, 4))

# Required quantity
ans = C(1, 4) + C(3, 4)
print(ans)
print(f"{ans:.8f}")
```---

 ## 3. 代码演练

 -`phi_raw(t)`计算所需的旋转角度，使接触点处的切线处于水平位置。 
-`phi(t)`展开角度以确保连续完整旋转。 
-`q(t)`计算微分弧长$ds/dt$的椭圆边界。 
-`x_rel(t), y_rel(t)`计算旋转后的接触点位置。 
- 中心位置来自：

 - 按边界弧长前进（无滑动），
 - 减去旋转的接触点偏移。 
-`integrand(t)`计算中心的瞬时速度。 
- 一次完整遍历边界的数值积分$C(a,b)$。 

### 样本验证

 该程序给出：$$C(2,4)=21.3881690605786\ldots$$与提供的值匹配$$21.38816906.$$---
