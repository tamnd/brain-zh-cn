[欧拉项目问题 282](https://projecteuler.net/problem=282)

 ## 解决方案

 **答案：**`1098988351`我们从经典的阿克曼函数开始：$$A(m,n)= \begin{cases} n+1 & m=0\\ A(m-1,1) & m>0,\ n=0\\ A(m-1,A(m,n-1)) & m>0,\ n>0 \end{cases}$$我们必须计算$$\sum_{n=0}^6 A(n,n)\pmod{14^8}.$$让$$M=14^8=2^8\cdot 7^8=256\cdot 5764801.$$---

 # 1. 小阿克曼能级的封闭形式

 反复展开递归可得：$$A(0,n)=n+1$$

$$A(1,n)=n+2$$

$$A(2,n)=2n+3$$

$$A(3,n)=2^{n+3}-3$$从那里开始，该模式变成了超级操作：$$A(4,n)=2\uparrow\uparrow(n+3)-3$$（四联）$$A(5,n)=2\uparrow\uparrow\uparrow(n+3)-3$$

$$A(6,n)=2\uparrow\uparrow\uparrow\uparrow(n+3)-3.$$所以：$$\begin{aligned} A(0,0)&=1,\\ A(1,1)&=3,\\ A(2,2)&=7,\\ A(3,3)&=2^6-3=61. \end{aligned}$$困难的术语是：$$A(4,4)=2\uparrow\uparrow 7-3,$$

$$A(5,5)=2\uparrow\uparrow\uparrow 8-3,$$

$$A(6,6)=2\uparrow\uparrow\uparrow\uparrow 9-3.$$---

 # 2. 模块化策略

 我们计算模$2^8$和模$7^8$，然后使用 CRT 进行合并。 

## 取模$2^8$任意塔$2^k$和$k\ge 8$可以整除$256$。 

因此，所有巨大的阿克曼项都满足：$$A(4,4)\equiv A(5,5)\equiv A(6,6)\equiv -3 \pmod{256}.$$所以：$$\equiv 253 \pmod{256}.$$---

 # 3. 四分模$7^8$现在工作模数$$7^8=5764801.$$因为$\gcd(2,7)=1$，适用欧拉/卡迈克尔约简。 

卡迈克尔函数为：$$\lambda(7^k)=6\cdot 7^{k-1}.$$定义四联：$$T(h)=2\uparrow\uparrow h.$$我们递归计算：$$T(h)\bmod m = 2^{\,T(h-1)\bmod \lambda(m)+\lambda(m)} \bmod m.$$执行此递归可得出：$$T(7)\equiv 4788450 \pmod{7^8},$$因此$$A(4,4)\equiv 4788447 \pmod{7^8}.$$继续四次序列模$7^8$最终稳定在固定点$$5208625.$$因此：$$2\uparrow\uparrow 65536 \equiv 5208625 \pmod{7^8},$$所以$$A(5,5)\equiv 5208622 \pmod{7^8}.$$下一个超运行水平已经远远超出稳定水平，因此：$$A(6,6)\equiv 5208622 \pmod{7^8}.$$---

 # 4.中国剩余定理

 我们结合：

 ##$A(4,4)$

$$x\equiv 253 \pmod{256},$$

$$x\equiv 4788447 \pmod{5764801}.$$CRT 给出：$$A(4,4)\equiv 915627005 \pmod{14^8}.$$##$A(5,5)$

$$x\equiv 253 \pmod{256},$$

$$x\equiv 5208622 \pmod{5764801}.$$CRT 给出：$$A(5,5)\equiv 829575165 \pmod{14^8}.$$这同样适用于$A(6,6)$。

 # 5. 最终总和$$\begin{aligned} S &=1+3+7+61\\ &\quad+915627005\\ &\quad+829575165\\ &\quad+829575165. \end{aligned}$$减少模数$14^8$:$$S \equiv 1098988351.$$---

 # 6.Python实现```python
from math import lcm

MOD = 14 ** 8
MOD2 = 2 ** 8
MOD7 = 7 ** 8

# Carmichael function for prime powers
def carmichael_7_power(k):
    return 6 * (7 ** (k - 1))

# tetration: 2 ↑↑ h (mod m)
def tetration_mod(h, m):
    if m == 1:
        return 0
    if h == 1:
        return 2 % m

    # lambda(7^k) = 6 * 7^(k-1)
    # here m is always a power of 7
    k = 0
    t = m
    while t % 7 == 0:
        t //= 7
        k += 1

    lam = carmichael_7_power(k)

    e = tetration_mod(h - 1, lam)

    return pow(2, e + lam, m)

# Chinese remainder theorem for coprime moduli
def crt(a1, m1, a2, m2):
    inv = pow(m1, -1, m2)
    t = ((a2 - a1) * inv) % m2
    return a1 + m1 * t

# Small terms
A00 = 1
A11 = 3
A22 = 7
A33 = 61

# A(4,4)
a44_mod7 = tetration_mod(7, MOD7) - 3
A44 = crt(253, MOD2, a44_mod7, MOD7)

# Stable fixed point for higher hyper-operators
stable = 5208625 - 3

A55 = crt(253, MOD2, stable, MOD7)
A66 = A55

answer = (A00 + A11 + A22 + A33 + A44 + A55 + A66) % MOD

print(answer)
