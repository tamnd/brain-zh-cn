[欧拉项目 811 问题](https://projecteuler.net/problem=811)

 ## 解决方案

 **答案：**`327287526`一个关键的观察结果是，递归仅取决于 1 位之间的零游程模式$n$。 

为了$$n=(2^t+1)^r,$$什么时候$t$足够大（这里$t=10^{14}+31$)，来自二项式展开的二进制块$$(1+2^t)^r=\sum_{k=0}^r \binom{r}{k}2^{kt}$$不要重叠。 因此 1 位位置$n$直接从二项式系数的二元展开式获得。 

使用由此产生的封闭式评估$A(n)$,可以计算出$$H(10^{14}+31,62)\pmod{1\,000\,062\,031}.$$以下 Python 程序可以有效地对其进行评估：```python
MOD = 1_000_062_031

def b(n):
    return n & -n

def max_binom_bitlen(r):
    c = 1
    mx = 1
    for k in range(r + 1):
        mx = max(mx, c.bit_length())
        if k < r:
            c = c * (r - k) // (k + 1)
    return mx

def one_positions_via_binom(t, r):
    pos = []
    c = 1
    for k in range(r + 1):
        x = c
        while x:
            lsb = x & -x
            bit = lsb.bit_length() - 1
            pos.append(k * t + bit)
            x -= lsb
        if k < r:
            c = c * (r - k) // (k + 1)
    return pos

def A_from_positions(pos, mod):
    m = len(pos)

    v = [0] * m
    v[0] = 1
    for k in range(1, m):
        v[k] = (5 * v[k - 1] + 3) % mod

    ans = 1
    desc = pos[::-1]

    for i in range(m - 1):
        gap = desc[i] - desc[i + 1] - 1
        if gap > 0:
            ans = ans * pow(v[i + 1], gap, mod) % mod

    return ans

def H(t, r, mod):
    pos = one_positions_via_binom(t, r)
    return A_from_positions(pos, mod)

print(H(10**14 + 31, 62, MOD))
```对照样品验证：$$H(3,2)=A(81)=636056,$$程序正确再现。 

因此，

 **答案：327287526**
