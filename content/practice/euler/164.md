[欧拉项目问题 164](https://projecteuler.net/problem=164)

 ## 解决方案

 **答案：**`378158756814587`我们想要计算 20 位整数，如下所示：

 - 第一个数字非零，
 - 对于每三个连续数字，它们的总和最多为 9。 

设数字为$$d_1 d_2 \cdots d_{20},$$和$d_1 \neq 0$，并且对于每个$i$,$$d_i + d_{i+1} + d_{i+2} \le 9.$$这是一个经典的有限状态动态规划问题。 

---

 # 数学分析

 条件仅取决于前两位数字。 

如果我们已经知道最后两位数字$(a,b)$，然后是下一个数字$c$被允许当且仅当$$a+b+c \le 9.$$因此：$$c \in \{0,1,\dots,9-a-b\}.$$因此，整个过程可以建模为由最后两位数字组成的状态之间的转换。 

---

 ## 定义DP

 让$$DP(k,a,b)$$是有效的数量$k$- 以数字结尾的数字序列$a,b$，满足所有三元组的条件。 

过渡是：$$DP(k+1,b,c) += DP(k,a,b)$$对于每一个$c$这样$$a+b+c \le 9.$$---

 ## 初始化

 对于 2 位数字前缀：

 - 第一个数字$a \in \{1,\dots,9\}$,
 - 第二个数字$b \in \{0,\dots,9\}$。 

目前还不存在三元组，因此每个这样的对最初都是有效的。 

因此：$$DP(2,a,b)=1.$$---

 ## 状态计数

 状态空间很小：

 -$a,b \in \{0,\dots,9\}$，
- 仅有的$100$州。 

对于每个状态，最多$10$存在过渡。 

所以计算是微不足道的。 

---

 # Python 实现```python
from collections import defaultdict

# dp[(a,b)] = number of valid sequences ending with digits a,b
dp = defaultdict(int)

# Initialize all valid 2-digit beginnings
for a in range(1, 10):      # first digit cannot be zero
    for b in range(10):
        dp[(a, b)] = 1

# Extend sequences until length 20
for length in range(2, 20):
    new_dp = defaultdict(int)

    for (a, b), count in dp.items():

        # Next digit c must satisfy a+b+c <= 9
        max_c = 9 - a - b

        for c in range(max_c + 1):
            new_dp[(b, c)] += count

    dp = new_dp

# Total number of valid 20-digit numbers
answer = sum(dp.values())

print(answer)
```---

 # 小型健全性检查

 对于 3 位数字：

 我们数三倍$(a,b,c)$和：

-$a \ge 1$,
 -$a+b+c \le 9$。 

对于每个$a$,$$\#(b,c)=\sum_{s=0}^{9-a}(s+1).$$这给出：$$45+36+28+21+15+10+6+3+1 = 165.$$DP 正确地再现了这一点。
