[项目欧拉问题 320](https://projecteuler.net/problem=320)

 ## 解决方案

 **答案：**`278157919195482643`让$$K = 1234567890.$$我们想要最小的$n$这样$$(i!)^K \mid n!.$$对于每一个素数$p\le i$， 定义$v_p(m!)$作为指数$p$在$m!$。 

根据勒让德公式，$$v_p(m!)=\sum_{t\ge1}\left\lfloor \frac{m}{p^t}\right\rfloor.$$因此$n$必须满足$$v_p(n!) \ge K\,v_p(i!) \qquad\text{for every prime }p\le i.$$所以$$N(i)=\max_{p\le i} F_p\!\bigl(K\,v_p(i!)\bigr),$$在哪里$F_p(a)$是最少的$n$这样$v_p(n!)\ge a$。 

---

 # 关键的数学见解

 再次使用勒让德，$$v_p(n!)=\frac{n-s_p(n)}{p-1},$$在哪里$s_p(n)$是基数的总和$p$的数字$n$。 

因此$F_p(a)$是最小的$n$满意的$$n-s_p(n)\ge (p-1)a.$$自从$s_p(n)$与相比很小$n$，我们得到$$F_p(a)=(p-1)a+O(\log a).$$现在$$(p-1)v_p(i!) = i-s_p(i),$$所以$$F_p\!\bigl(Kv_p(i!)\bigr) = K(i-s_p(i,p))+O(\log i).$$因此，主导素数正是那些最小化数字和的素数$s_p(i,p)$。 

然后可以通过以下方式有效地完成计算：

 1. 筛选最小质因数至$10^6$,
 2. 维护所有指数$v_p(i!)$逐渐地，
 3. updating only the primes dividing the new$i$,
 4. 计算$F_p(a)$通过对勒让德公式进行二分查找。 

在优化的 Python / PyPy 中，整体复杂性很容易足够快。

 # Python 实现```python
from collections import defaultdict
from math import log

K = 1234567890
MOD = 10**18
U = 10**6

# ------------------------------------------------------------
# smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(U + 1))

for i in range(2, int(U**0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, U + 1, step):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Legendre valuation
# ------------------------------------------------------------

def vp_fact(n, p):
    s = 0
    while n:
        n //= p
        s += n
    return s

# ------------------------------------------------------------
# inverse Legendre:
# least n with vp_fact(n,p) >= target
# ------------------------------------------------------------

def inverse_legendre(p, target):
    lo = 0
    hi = (p - 1) * target + 1000

    while lo < hi:
        mid = (lo + hi) // 2
        if vp_fact(mid, p) >= target:
            hi = mid
        else:
            lo = mid + 1

    return lo

# ------------------------------------------------------------
# main accumulation
# ------------------------------------------------------------

exp_p = defaultdict(int)
need_p = defaultdict(int)

current_max = 0
answer = 0

for i in range(2, U + 1):

    x = i
    factors = defaultdict(int)

    while x > 1:
        p = spf[x]
        factors[p] += 1
        x //= p

    # update prime exponents in i!
    for p, e in factors.items():
        exp_p[p] += e

        target = K * exp_p[p]
        val = inverse_legendre(p, target)

        need_p[p] = val

        if val > current_max:
            current_max = val

    if i >= 10:
        # recompute if necessary
        if current_max not in need_p.values():
            current_max = max(need_p.values())

        answer = (answer + current_max) % MOD

print(answer)
```---
