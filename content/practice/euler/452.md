[欧拉项目 452 问题](https://projecteuler.net/problem=452)

 ## 解决方案

 **答案：**`345558983`让$$F(m,n)=\#\{(a_1,\dots,a_n)\in \mathbb Z_{>0}^n:\ a_1a_2\cdots a_n\le m\}.$$我们被要求$$F(10^9,10^9)\pmod{1234567891}.$$---

 ## 1.数学分析

 对于固定整数$t$， 定义$$d_n(t)=\#\{(a_1,\dots,a_n)\in \mathbb Z_{>0}^n:\ a_1a_2\cdots a_n=t\}.$$那么清楚$$F(m,n)=\sum_{t\le m} d_n(t).$$---

 ### 第 1 步：解释$d_n(t)$认为$$t=\prod p_i^{e_i}.$$来形成一个有序的$n$-其乘积为的元组$t$，我们分配指数$e_i$每个素数的$p_i$其中$n$职位。 

分配方式数量$e_i$相同的物体变成$n$盒子是$$\binom{n+e_i-1}{e_i}.$$所以$$d_n(t)=\prod_i \binom{n+e_i-1}{e_i}.$$这就是广义除数函数。 

---

 ## 步骤 2：删除 1

 一个更有用的观点是：

 - 准确选择$k$职位是$>1$,
 - 所有剩余位置均$1$。 

让$T_k(m)$表示订购的数量$k$- 整数元组$>1$谁的产品是$\le m$。 

然后$$F(m,n)=\sum_{k\ge0}\binom{n}{k}T_k(m).$$为什么？ 

- 选择$k$非 1 位置：$\binom nk$,
 - 用有效的订单填写它们$k$- 元组计数$T_k(m)$。 

因为每个因素至少$2$,$$2^k\le m.$$为了$m=10^9$,$$k\le \lfloor \log_2(10^9)\rfloor = 29.$$因此只需要 30 个术语。 

---

 ## 步骤 3：重复$T_k(m)$定义$$T_0(m)=1.$$为了$k\ge1$,$$T_k(m)=\sum_{a=2}^{m} T_{k-1}\!\left(\left\lfloor \frac{m}{a}\right\rfloor\right).$$这是因为第一个因素可以是任何$a\ge2$，以及剩余的$k-1$因素最多必须有乘积$m/a$。 

---

 ## 步骤 4：双曲线优化

 的价值观$$\left\lfloor \frac{m}{a}\right\rfloor$$只改变$O(\sqrt m)$次。 

如果$$q=\left\lfloor \frac{m}{a}\right\rfloor,$$然后所有$a$在一个区间内$[i,j]$给出相同的商$q$。 

所以我们计算$$T_k(m)=\sum_{\text{blocks }[i,j]} (j-i+1)\,T_{k-1}(q).$$通过记忆，这变得非常快。 

---

 # 2.Python实现```python
import math
from functools import lru_cache

MOD = 1234567891
N = 10**9
M = 10**9

@lru_cache(maxsize=None)
def T(k, x):
    """
    Number of ordered k-tuples of integers > 1
    whose product is <= x, modulo MOD.
    """

    if k == 0:
        return 1

    # minimum possible product is 2^k
    if x < (1 << k):
        return 0

    total = 0

    i = 2
    while i <= x:
        q = x // i
        j = x // q

        # all a in [i, j] give floor(x/a) = q
        total += (j - i + 1) * T(k - 1, q)
        total %= MOD

        i = j + 1

    return total

def solve():
    ans = 0

    # only k <= floor(log2(M)) matter
    for k in range(30):
        ans += math.comb(N, k) % MOD * T(k, M)
        ans %= MOD

    return ans

print(solve())
```---

 # 3. 代码演练

 ## 记忆递归```python
@lru_cache(maxsize=None)
def T(k, x):
```存储先前计算的状态。 

---

 ## 基本情况```python
if k == 0:
    return 1
```恰好有一个空元组。 

---

 ## 修剪```python
if x < (1 << k):
    return 0
```任何$k$- 带有条目的元组$>1$至少有产品$2^k$。 

---

 ## 商分组```python
q = x // i
j = x // q
```中的所有整数$[i,j]$产生相同的商。 

这降低了复杂性$O(x)$粗略地$O(\sqrt x)$。 

---

 ## 最终总结```python
for k in range(30):
    ans += math.comb(N, k) % MOD * T(k, M)
```实施$$F(M,N)=\sum_{k=0}^{29}\binom Nk T_k(M).$$---
