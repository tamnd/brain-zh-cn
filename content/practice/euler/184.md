[项目欧拉问题 184](https://projecteuler.net/problem=184)

 ## 解决方案

 **答案：**`1725323624056`让$S_r$严格位于圆内的非零格点集合$$x^2+y^2<r^2 .$$我们必须计算顶点为$S_{105}$其起源严格地包含在其内部。 

---

 # 1.数学分析

 ## 步骤 1 — 原始条件的几何形状

 取三个非零点并查看它们的极角$$0 \le \theta_1 < \theta_2 < \theta_3 < 2\pi.$$三角形包含原点当且仅当三个点**不包含在任何闭合半圆**中。 

等效地：$$\theta_3-\theta_1 > \pi.$$如果相反$$\theta_3-\theta_1 \le \pi,$$那么所有三个点都位于半圆内，因此原点在外部（或在边界上）。 

于是问题就变成了：

 > 计算角跨度**严格大于**的所有格点三元组$\pi$。 

---

 ## 步骤 2 — 按方向对点进行分组

 许多晶格点位于来自原点的同一条射线上。 

例如：$$(1,1), (2,2), (3,3), \dots$$都有相同的角度。 

包含原点的三角形永远不能使用同一射线上的两个点，因为这样原点就不能严格位于三角形内部。 

所以我们通过**原始方向**来压缩点。 

对于每个点$(x,y)$， 定义$$g=\gcd(|x|,|y|), \qquad \left(\frac{x}{g},\frac{y}{g}\right)$$这是它的原始方向。 

对于每个方向$d_i$， 让：$$c_i = \text{number of lattice points on that ray}.$$我们按角度对所有原始方向进行排序。 

---

 ## 步骤 3 — 计算坏三元组

 如果所有三个方向都位于闭合半圆内，则三元组是“坏”的。 

确定起始方向$i$。 

让指示严格执行后$i$但在角度之内$\pi$成为窗户。 

假设该窗口中的总点数为$$W_i.$$但我们必须从**不同的方向**选择点，否则三角形是退化的。 

如果窗口中的重数是$c_j$，则来自不同方向的无序点对的数量为$$\frac{W_i^2-\sum c_j^2}{2}.$$乘以$c_i$（第一个方向的选择）给出了最小角度方向为的坏三元组的数量$i$。 

总结一切$i$将每个坏三元组精确计数一次。 

---

 ## 步骤 4 — 不同方向三元组总数

 让$$N=\sum_i c_i$$是非零格点的总数。 

所有三元组：$$\binom{N}{3}.$$但是我们必须使用相同的方向两次（或三次）删除三元组。 

对于具有多重性的方向$c_i$：

 - 该射线上恰好有两个点的三元组：$$\binom{c_i}{2}(N-c_i)$$- 三元组，所有三个都在那条射线上：$$\binom{c_i}{3}$$从中减去这些$\binom{N}{3}$给出使用不同方向的三元组的数量.

 最后：$$\text{good}= \text{distinct-direction triples} - \text{bad triples}.$$---

 # 2.Python实现```python
from math import gcd, atan2, pi, comb
from collections import Counter

R = 105

# Count how many lattice points lie on each primitive direction
direction_count = Counter()

for x in range(-(R - 1), R):
    for y in range(-(R - 1), R):

        if x == 0 and y == 0:
            continue

        if x * x + y * y < R * R:

            g = gcd(abs(x), abs(y))
            dx = x // g
            dy = y // g

            direction_count[(dx, dy)] += 1

# Sort primitive directions by polar angle
dirs = sorted(
    (atan2(y, x) % (2 * pi), cnt)
    for (x, y), cnt in direction_count.items()
)

angles = [a for a, c in dirs]
counts = [c for a, c in dirs]

m = len(dirs)

# Duplicate arrays for circular two-pointer sweep
angles2 = angles + [a + 2 * pi for a in angles]
counts2 = counts + counts

# Prefix sums of counts and counts^2
pref = [0]
pref_sq = [0]

for v in counts2:
    pref.append(pref[-1] + v)
    pref_sq.append(pref_sq[-1] + v * v)

# Total number of lattice points (excluding origin)
N = sum(counts)

# Total triples
total = comb(N, 3)

# Remove triples using repeated directions
duplicate_direction_triples = 0

for c in counts:
    duplicate_direction_triples += comb(c, 2) * (N - c)
    duplicate_direction_triples += comb(c, 3)

distinct_direction_triples = total - duplicate_direction_triples

# Count bad triples (contained in a semicircle)
bad = 0

j = 0

for i in range(m):

    if j < i + 1:
        j = i + 1

    while j < i + m and angles2[j] <= angles[i] + pi + 1e-15:
        j += 1

    # Window excludes i itself
    W = pref[j] - pref[i + 1]
    SQ = pref_sq[j] - pref_sq[i + 1]

    # Number of unordered pairs from distinct directions
    pairs = (W * W - SQ) // 2

    bad += counts[i] * pairs

answer = distinct_direction_triples - bad

print(answer)
```---

 # 3. 代码演练

 ## 原始方向```python
g = gcd(abs(x), abs(y))
dx = x // g
dy = y // g
```这会将每个晶格点转换为其原始光线。 

例子：$$(6,9)\to(2,3).$$---

 ## 按角度排序```python
atan2(y, x)
```让我们按循环顺序处理方向。 

---

 ## 两指针扫掠

 对于每个起始方向$i$, 指针`j`前进直至角度差超过$\pi$。 

Thus all directions in$$[i+1,\; j-1]$$适合在半圆内$i$。 

---

 ## 从不同方向计数对

 如果计数是$a_1,a_2,\dots$， 然后$$\sum_{u<v} a_u a_v = \frac{ \left(\sum a_u\right)^2 - \sum a_u^2 }{2}.$$那正是：```python
pairs = (W * W - SQ) // 2
```---
