 ## 解决方案

 **答案：**`984291849`## 问题陈述

 来自[Project Euler Problem 976](https://projecteuler.net/problem%3D976)：

 > 两个玩家 X 和 O 一起玩游戏$k$长度为正方形的条带$n_1,\dots,n_k$，原本都是空白的。 
>
 >
 >
 >
 > 从 X 开始，他们依次移动。 轮到X时，X画一个“X”符号； 轮到 O 时，O 画一个“O”符号。 
>
 > 该符号必须用红色或蓝色笔绘制在一个空白方块中，但须遵守以下限制：
 >
 >
 >
 >
 > 1. 一条条上相邻方格中的两个符号必须是不同的符号并且必须具有不同的颜色；
 > 2. 如果至少有一个空白条，则必须在空白条上绘画。 
>
 >
 >
 >
 > 谁没有有效的举动，谁就输了游戏。 
>
 >
 >
 >
 > 让$P(K, N)$是元组的数量$(n_1,\dots,n_k)$这样
 >
 >$1 \leq k \leq K$,
 >
 >$1\leq n_1\leq\cdots\leq n_k\leq N$>
 > 并且X有对应游戏的获胜策略。 
>
 >
 >
 >
 > 例如，
 >
 >$P(2, 4)=7$>
 > 和
 >
 >$P(5, 10) = 901$。 
>
 >
 >
 >
 > 查找
 >
 >$P(10^7, 10^7)\bmod 1234567891$。 

---

 # 数学分析

 关键的观察结果是游戏完全崩溃为平价分类。 

让$$N=10^7,\qquad N_o=\frac N2,\qquad N_a=\frac N4.$$自从$N\equiv 0\pmod 4$，完整的计数公式变为：$$\boxed{ \text{Ans} = E_{\text{tot}} - E_{\text{lost}} + O_{\text{win}} \pmod M }$$在哪里$M=1234567891$。 

这三块是：$$E_{\text{tot}} = \sum_{m=0}^{N_o} \binom{N+2m-1}{2m},$$

$$E_{\text{lost}} = \frac12 \sum_{r=0}^{N_a} \binom{N_o}{2r} \binom{3N_o-r}{N_o-r} + \frac12 \binom{5N_a}{N_o},$$

$$O_{\text{win}} = \frac12 \sum_{r=0}^{N_a-1} \binom{N_o}{2r+1} \binom{3N_o-1-r}{N_o-1-r}.$$因此$$\boxed{ \text{Ans} = \sum_{m=0}^{N_o}\binom{N+2m-1}{2m} -\frac12\sum_{r=0}^{N_a}\binom{N_o}{2r}\binom{3N_o-r}{N_o-r} -\frac12\binom{5N_a}{N_o} +\frac12\sum_{r=0}^{N_a-1}\binom{N_o}{2r+1}\binom{3N_o-1-r}{N_o-1-r} }$$模数$M$。 

---

 # 高效计算

 直接阶乘表高达$2\times 10^7$是可能的，但内存很重。 

相反，递归地计算每个求和项。 

例如：$$T_m=\binom{N+2m-1}{2m}$$满足$$T_{m+1} = T_m \cdot \frac{(N+2m)(N+2m+1)}{(2m+1)(2m+2)}.$$相似地：$$A_r = \binom{N_o}{2r} \binom{3N_o-r}{N_o-r}$$满足$$A_{r+1} = A_r \cdot \frac{(N_o-2r)(N_o-2r-1)} {(2r+1)(2r+2)} \cdot \frac{N_o-r}{3N_o-r}.$$和$$B_r = \binom{N_o}{2r+1} \binom{3N_o-1-r}{N_o-1-r}$$满足$$B_{r+1} = B_r \cdot \frac{(N_o-2r-1)(N_o-2r-2)} {(2r+2)(2r+3)} \cdot \frac{N_o-1-r}{3N_o-1-r}.$$因为模数是素数，所以所有除法都是模逆。 

---

 # Python 实现```python
MOD = 1234567891

N = 10_000_000
No = N // 2
Na = N // 4

# modular inverses up to 20,000,000
LIMIT = 20_000_001
inv = [0] * LIMIT
inv[1] = 1

for i in range(2, LIMIT):
    inv[i] = (MOD - MOD // i) * inv[MOD % i] % MOD

inv2 = (MOD + 1) // 2

# ---------------------------------------------------
# S1 = sum C(N+2m-1, 2m)
# ---------------------------------------------------

t = 1
S1 = 1

for m in range(No):
    t = t * (N + 2*m) % MOD
    t = t * (N + 2*m + 1) % MOD
    t = t * inv[2*m + 1] % MOD
    t = t * inv[2*m + 2] % MOD

    S1 += t
    S1 %= MOD

# ---------------------------------------------------
# Compute C(3No, No)
# ---------------------------------------------------

C3 = 1
for k in range(1, No + 1):
    C3 = C3 * (2*No + k) % MOD
    C3 = C3 * inv[k] % MOD

# ---------------------------------------------------
# L1 terms
# ---------------------------------------------------

A = C3
sumA = A

for r in range(Na):
    A = A * (No - 2*r) % MOD
    A = A * (No - 2*r - 1) % MOD
    A = A * inv[2*r + 1] % MOD
    A = A * inv[2*r + 2] % MOD
    A = A * (No - r) % MOD
    A = A * inv[3*No - r] % MOD

    sumA += A
    sumA %= MOD

# ---------------------------------------------------
# L2 = C(5Na, No)
# ---------------------------------------------------

L2 = 1
for k in range(1, No + 1):
    L2 = L2 * (5*Na - No + k) % MOD
    L2 = L2 * inv[k] % MOD

# ---------------------------------------------------
# Odd winning terms
# ---------------------------------------------------

inv3 = pow(3, MOD - 2, MOD)

B = C3 * inv3 % MOD
sumB = B

for r in range(Na - 1):
    B = B * (No - 2*r - 1) % MOD
    B = B * (No - 2*r - 2) % MOD
    B = B * inv[2*r + 2] % MOD
    B = B * inv[2*r + 3] % MOD
    B = B * (No - 1 - r) % MOD
    B = B * inv[3*No - 1 - r] % MOD

    sumB += B
    sumB %= MOD

# ---------------------------------------------------
# Final answer
# ---------------------------------------------------

ans = (
    S1
    - (sumA + L2) * inv2
    + sumB * inv2
) % MOD

print(ans)
```---
