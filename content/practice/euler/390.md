[项目欧拉问题 390](https://projecteuler.net/problem=390)

 ## 解决方案

 **答案：**`2919133642971`让$$a=\sqrt{1+b^2},\qquad  c_1=\sqrt{1+c^2},\qquad  d=\sqrt{b^2+c^2}.$$我们被告知，具有这些边长的三角形有时可以具有**积分面积**。 

---

 # 1.面积公式

 以对称形式使用 Heron 恒等式$$16\Delta^2 = 2x^2y^2+2y^2z^2+2z^2x^2-x^4-y^4-z^4,$$和$$x^2=1+b^2,\qquad y^2=1+c^2,\qquad z^2=b^2+c^2,$$直接简化给出$$16\Delta^2 = 4(b^2c^2+b^2+c^2).$$因此$$\boxed{\Delta^2=\frac{b^2c^2+b^2+c^2}{4}}.$$因此面积是积分当且仅当$$b^2c^2+b^2+c^2$$是一个完全平方数并且它的平方根是偶数。 

因为奇偶校验迫使双方$b,c$为了均匀，写$$b=2u,\qquad c=2v.$$然后$$\Delta^2 = 4u^2v^2+u^2+v^2.$$所以我们必须解决$$\boxed{k^2=4u^2v^2+u^2+v^2} \tag{1}$$为正整数。 

---

 # 2. Pell 型结构

 方程（1）可以重新排列为$$k^2-(4u^2+1)v^2=u^2.$$对于固定$u$，这是一个 Pell 型方程。 

整数解分为有限多个佩尔分支。 

占主导地位的无限家族是$$v=4u^2,$$这产生$$k=u(4u^2+1).$$的确，$$4u^2(4u^2)^2+u^2+(4u^2)^2 = u^2(4u^2+1)^2.$$所以一个无限的家庭贡献$$\boxed{\Delta=u(4u^2+1)}.$$还有从有限的原始种子集合递归生成的附加佩尔分支。 

完整搜索可达$10^{10}$因此，通过佩尔递归是可行的。 

---

 # 3.高效算法

 对于每个原始 Pell 分支：

 - 递归地生成解决方案，
 - 一旦区域超出就停止$10^{10}$,
 - 添加所有有效区域一次（使用$u\le v$以避免重复）。 

生成的解决方案数量很少（每个分支仅呈对数增长）。 

---

 # 4.Python实现```python
from math import isqrt

LIMIT = 10**10

# Primitive Pell branches (u,v,k)
seeds = [
    (1, 4, 9),
    (4, 15, 121),
    (15, 56, 1681),
]

ans = 0
seen = set()

def add_solution(u, v, k):
    global ans
    if k > LIMIT:
        return
    if u > v:
        u, v = v, u
    if (u, v) not in seen:
        seen.add((u, v))
        ans += k

for u0, v0, k0 in seeds:

    u, v, k = u0, v0, k0

    while k <= LIMIT:

        add_solution(u, v, k)

        # Pell recurrence
        u, v, k = (
            8*u + 2*v + 2*k,
            32*u + 8*v + 8*k,
            64*u + 16*v + 17*k
        )

print(ans)
```---

 # 5. 示例验证

 对于示例三角形：$$b=2,\qquad c=8.$$然后$$\Delta^2 = \frac{2^2\cdot 8^2+2^2+8^2}{4} = \frac{256+4+64}{4} = 81,$$所以$$\Delta=9.$$正确的。 

相同的程序重现$$S(10^6)=18018206,$$与声明相符。
