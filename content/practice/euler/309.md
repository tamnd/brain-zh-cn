[欧拉项目问题 309](https://projecteuler.net/problem=309)

 ## 解决方案

 **答案：**`210139`设街道宽度为$w$。 假设梯子有长度$x<y$，在高处接触相对的墙壁$a$和$b$， 分别。 

由毕达哥拉斯定理：$$a^2+w^2=x^2,\qquad b^2+w^2=y^2$$所以$a,b$必须是整数。 交叉高度$h$满足标准的交叉阶梯关系：$$\frac1h=\frac1a+\frac1b$$重新排列为$$h=\frac{ab}{a+b}$$因此，对于整数$h$，我们需要：$$a+b \mid ab$$那么问题就变成了：

 1. 找到所有有公共边的整数直角三角形$w$:$$x^2=w^2+a^2,\qquad y^2=w^2+b^2$$2.对于每对共享相同的$w$, 计算那些$$\frac{ab}{a+b}\in \mathbb Z$$一个关键的观察结果是，每个有效的$(w,a,x)$是毕达哥拉斯三元组。 我们可以使用欧几里得公式有效地生成所有这样的三元组：$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$和$\gcd(m,n)=1$和相反的奇偶校验，然后按比例缩放$k$。 

对于每个宽度$w$，收集所有可能的梯子配置$(a,x)$，然后测试每一对：$$h=\frac{ab}{a+b}$$如果$h$是整数，计算三元组$(x,y,h)$。

 ### Python 实现```python
from math import gcd, isqrt
from collections import defaultdict

LIMIT = 1_000_000

# width -> list of (height, ladder_length)
by_width = defaultdict(list)

# Generate all Pythagorean triples
m_max = isqrt(LIMIT) + 2

for m in range(2, m_max):
    for n in range(1, m):
        # Primitive triple conditions
        if gcd(m, n) != 1 or (m - n) % 2 == 0:
            continue

        a = m * m - n * n
        b = 2 * m * n
        c = m * m + n * n

        k = 1
        while k * c < LIMIT:
            aa = k * a
            bb = k * b
            cc = k * c

            # Either leg can be the street width
            if aa < LIMIT:
                by_width[aa].append((bb, cc))
            if bb < LIMIT:
                by_width[bb].append((aa, cc))

            k += 1

count = 0

# For each common width, test pairs
for w, configs in by_width.items():
    L = len(configs)

    for i in range(L):
        a, x = configs[i]

        for j in range(i + 1, L):
            b, y = configs[j]

            # Need x < y (avoid duplicates)
            if x == y:
                continue

            # h = ab / (a + b) must be integer
            if (a * b) % (a + b) == 0:
                count += 1

print(count)
```---

 ### 代码演练

 - **生成毕达哥拉斯三元组**

 - 欧几里得公式生成每个原始直角三角形。 
- 乘以$k$获得所有非原始的。 
- 存储由公共宽度键控的每种可能性$w$。 
- **一对梯子共享相同的宽度**

 - 对于每个宽度，每个存储的项目都是一个可能的梯子。 
- 比较每一对。 
- **检查整数交叉高度**

 - 使用$$h=\frac{ab}{a+b}$$- Count only when divisible.
