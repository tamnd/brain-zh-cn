[项目欧拉问题 883](https://projecteuler.net/problem=883)

 ## 解决方案

 **答案：**`14854003484704`让六方格子用爱森斯坦整数来标识$$\Lambda=\{a+b\omega : a,b\in \mathbb Z,\ \omega=e^{i\pi/3}\},$$具有二次范数$$N(a+b\omega)=a^2+ab+b^2.$$因此，格点之间的距离的平方正是以下值$$Q(x,y)=x^2+xy+y^2.$$我们必须数三角形：

 - 顶点位于$\Lambda$,
 - 中心也在$\Lambda$,
 - 至少有一个$60^\circ$角度，
 - 仅计算翻译，
 - 但旋转/反射单独计算。 

---

 # 1. a 的几何形状$60^\circ$六方格子上的三角形

 把$60^\circ$顶点位于原点。 

设与该角相邻的两条边为向量$u,v\in\Lambda$，有角度$60^\circ$他们之间。 

使用格基，每个这样的对都可以由两个互质整数参数化$k>l>0$:$$u=(k,l),\qquad v=(l,k).$$边长变为$$|u|=\sqrt{k^2+kl+l^2},\qquad |v|=\sqrt{k^2+kl+l^2},$$第三条边的长度$$|u-v|=\sqrt{k^2-kl+l^2}.$$定义$$s=\sqrt{k^2-kl+l^2}.$$三角形具有晶格向心力的条件$s\in\mathbb Z$。 

a 的内半径$60^\circ$三角形满足$$r=\frac{\sqrt3}{2}\cdot \frac{ab}{a+b+c},$$代入上述参数后可得$$r^2=\frac{Q(p)}{12d^2},$$在哪里$$d=k+l-s,$$和$p$是一个本原晶格向量。 

因此，对显着三角形的计数减少为对满足以下条件的格向量的计数：$$Q(p)\le \frac{12R^2}{d^2}.$$---

 # 2. 算术结构

 的整数解$$k^2-kl+l^2=s^2$$分裂成两个家庭。 

---

 ## 家庭 1$$d=3uv,$$在哪里$$u>v,\qquad \gcd(u,v)=1,\qquad u\not\equiv v\pmod3.$$对于固定$t=uv$，此类对的数量等于$$2^{\omega(t)-1},$$在哪里$\omega(t)$是不同质因数的数量。 

这个家庭只存在于$$t\not\equiv 1\pmod3.$$---

 ## 家庭 2

 让$$a=u-v.$$然后$$d=a(a+3v),$$和$$\gcd(u,v)=1,\qquad u\not\equiv v\pmod3.$$所以每一个可受理的$d$具有多重性$M[d]$。 

---

 # 3. 计算格点

 我们需要满足的整数对的数量$$x^2+xy+y^2\le B.$$拨打此数量$N(B)$。 

古典身份赋予$$N(B) = 1+6\sum_{n\le B}\chi(n)\Big\lfloor\frac{B}{n}\Big\rfloor,$$在哪里$\chi$是非平凡狄利克雷特征模$3$:$$\chi(n)= \begin{cases} 1,&n\equiv1\pmod3,\\ -1,&n\equiv2\pmod3,\\ 0,&n\equiv0\pmod3. \end{cases}$$这可以评估为$O(\sqrt B)$使用除数块分组。 

---

 # 4. 等边三角形

 等边三角形也很引人注目。 

如果半径为$r$，然后是一个顶点向量$A$满足$$Q(A)\le 4R^2.$$每个等边三角形被表示三次（旋转$120^\circ$）， 所以：$$T_{\text{eq}}(R)=\frac{N(4R^2)-1}{3}.$$---

 # 5.最终计数公式

 对于每一个可受理的$d$,$$B=\left\lfloor \frac{12R^2}{d^2}\right\rfloor.$$如果$3\mid d$，允许所有格点； 否则只有索引 3 的子格有贡献。 

因此$$T(R) = 2\sum_d M[d]\cdot P_d(R) + \frac{N(4R^2)-1}{3},$$在哪里$$P_d(R)= \begin{cases} N(B)-1,&3\mid d,\\[4pt] N(\lfloor B/3\rfloor)-1,&3\nmid d. \end{cases}$$因素$2$考虑反映的配置。 

---

 # 6.Python实现```python
from array import array
from math import gcd, isqrt

def count_hex_points_leq(B, cache):
    """
    Count integer pairs (x,y) with x^2 + x*y + y^2 <= B.
    """

    if B <= 0:
        return 1

    if B in cache:
        return cache[B]

    def chi_prefix(m):
        # count of 1 mod 3 minus count of 2 mod 3
        return (m + 2) // 3 - (m + 1) // 3

    total = 0
    i = 1

    while i <= B:
        q = B // i
        j = B // q

        total += q * (chi_prefix(j) - chi_prefix(i - 1))
        i = j + 1

    ans = 1 + 6 * total
    cache[B] = ans
    return ans

def remarkable_triangles(R_num, R_den=1):

    Dmax = isqrt((12 * R_num * R_num) // (R_den * R_den))

    # multiplicity for each d
    M = array("I", [0]) * (Dmax + 1)

    #
    # ---- Family 1 ----
    #

    Nmax = Dmax // 3

    omega = array("B", [0]) * (Nmax + 1)

    for p in range(2, Nmax + 1):
        if omega[p] == 0:
            for k in range(p, Nmax + 1, p):
                omega[k] += 1

    for t in range(2, Nmax + 1):

        if t % 3 == 1:
            continue

        M[3 * t] += 1 << (omega[t] - 1)

    #
    # ---- Family 2 ----
    #

    vmax = Dmax // 3

    for v in range(1, vmax + 1):

        disc = 9 * v * v + 4 * Dmax
        amax = (isqrt(disc) - 3 * v) // 2

        for a in range(1, amax + 1):

            u = v + a

            if u % 3 == v % 3:
                continue

            if gcd(u, v) != 1:
                continue

            d = a * (a + 3 * v)
            M[d] += 1

    #
    # ---- Main summation ----
    #

    cache = {}

    total_scalene = 0

    C_num = 12 * R_num * R_num
    C_den = R_den * R_den

    for d in range(1, Dmax + 1):

        mult = M[d]

        if mult == 0:
            continue

        B = C_num // (C_den * d * d)

        if B == 0:
            continue

        if d % 3 == 0:
            pts = count_hex_points_leq(B, cache) - 1
        else:
            pts = count_hex_points_leq(B // 3, cache) - 1

        total_scalene += 2 * mult * pts

    #
    # ---- Equilateral triangles ----
    #

    Beq = (4 * R_num * R_num) // (R_den * R_den)

    equi_points = count_hex_points_leq(Beq, cache) - 1
    total_equilateral = equi_points // 3

    return total_scalene + total_equilateral

# verification
print(remarkable_triangles(1, 2))   # 2
print(remarkable_triangles(2))      # 44
print(remarkable_triangles(10))     # 1302

# final answer
print(remarkable_triangles(10**6))
```---

 # 7. 代码演练

除数块技巧将相等的值分组$$\left\lfloor \frac{B}{i}\right\rfloor,$$给予$O(\sqrt B)$复杂。 

- -

＃＃＃ 建筑`M[d]`

`M[d]`存储有多少个原始三角形对应于给定参数$d$。 

列举了两个独立的参数化：

 - 通过因式分解的族 1$uv=t$,
 - 家庭 2 通过$d=a(a+3v)$。

一个因数$2$单独计算反射版本。
