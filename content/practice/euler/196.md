[项目欧拉问题 196](https://projecteuler.net/problem=196)

 ## 解决方案

 **答案：**`322303240771079935`让行的条目$n$是$$T(n,k)=\frac{n(n-1)}2+k,\qquad 1\le k\le n.$$所以排$n$包含连续整数$$\frac{n(n-1)}2+1,\dots,\frac{n(n+1)}2.$$我们必须计算$$S(5678027)+S(7208785),$$在哪里$S(n)$是行中素数的总和$n$属于至少一个_素数三元组_。 

---

 # 数学分析

 ## 1. 邻居结构

 对于位置处的数字$(n,k)$，邻居都是其中的有效位置$$(n+\delta_n,\;k+\delta_k),$$和$$\delta_n,\delta_k\in\{-1,0,1\},$$排除$(0,0)$。 

因此，内部元素最多有$8$邻居。 

---

 ## 2. 属于素数三元组是什么意思？ 

素数三元组是三个素数的集合，其中一个素数与另外两个素数相邻。 

定义素数的**素数**$p$是相邻素数的个数。 

然后：

 - 如果素数有度数$\ge 2$，它本身就是素数三元组的中心；
 - 如果素数有度数$1$，如果它的唯一素邻有度数，它仍然可以属于三元组$\ge 2$。 

因此：

 > 素数$p$属于某个素数三元组 iff
 >
 >
 >
 >
 > -$p$至少有两个主要邻居，或者
 > - 它的相邻素数之一至少有两个素数邻居。 

这将问题简化为纯粹的本地计算。 

---

 ## 3. 地点

 判断行中是否有素数$n$属于一个三元组，我们只需要行中的信息$$n-2,\ n-1,\ n,\ n+1,\ n+2.$$确实：

 - 行的邻居$n$排成一排躺着$n-1,n,n+1$;
 - 要知道这些素数的邻域度，我们还需要一层。 

因此，即使对于$n\approx 7\times10^6$。 

---

 ## 4.素数生成

 涉及的数字约为$$\frac{n^2}{2}\approx 2.6\times10^{13},$$对于整个范围内的普通筛分来说太大了。 

但仅约$5n$需要连续的整数，因此**分段筛**是理想的。

 # Python 实现```python
from math import isqrt

def row_start(n):
    return n * (n - 1) // 2 + 1

def value(n, k):
    return row_start(n) + k - 1

def neighbours(n, k):
    """
    Generate all neighbouring coordinates of (n,k).
    """
    out = []

    for dn in (-1, 0, 1):
        rn = n + dn
        if rn < 1:
            continue

        for dk in (-1, 0, 1):
            if dn == 0 and dk == 0:
                continue

            kk = k + dk

            if 1 <= kk <= rn:
                out.append((rn, kk))

    return out

def segmented_sieve(lo, hi):
    """
    Return a boolean array is_prime[x - lo]
    for all x in [lo, hi].
    """

    size = hi - lo + 1
    is_prime = [True] * size

    if lo <= 1 <= hi:
        is_prime[1 - lo] = False

    limit = isqrt(hi)

    # ordinary sieve up to sqrt(hi)
    base = [True] * (limit + 1)
    base[0] = base[1] = False

    for p in range(2, isqrt(limit) + 1):
        if base[p]:
            for m in range(p * p, limit + 1, p):
                base[m] = False

    primes = [i for i, v in enumerate(base) if v]

    # segmented marking
    for p in primes:
        start = max(p * p, ((lo + p - 1) // p) * p)

        for m in range(start, hi + 1, p):
            is_prime[m - lo] = False

    return is_prime

def S(n):
    """
    Sum of primes in row n that belong to some prime triplet.
    """

    # enough rows to determine all local structures
    lo = row_start(n - 2)
    hi = row_start(n + 3) - 1

    is_prime_segment = segmented_sieve(lo, hi)

    def is_prime(x):
        return is_prime_segment[x - lo]

    # prime neighbour counts
    degree = {}

    for r in range(n - 1, n + 2):
        for k in range(1, r + 1):

            x = value(r, k)

            if not is_prime(x):
                continue

            cnt = 0

            for rr, kk in neighbours(r, k):
                y = value(rr, kk)

                if is_prime(y):
                    cnt += 1

            degree[(r, k)] = cnt

    total = 0

    for k in range(1, n + 1):

        x = value(n, k)

        if not is_prime(x):
            continue

        ok = False

        # case 1: x itself is centre of a triplet
        if degree.get((n, k), 0) >= 2:
            ok = True

        # case 2: some neighbour is centre
        else:
            for rr, kk in neighbours(n, k):

                y = value(rr, kk)

                if is_prime(y) and degree.get((rr, kk), 0) >= 2:
                    ok = True
                    break

        if ok:
            total += x

    return total

answer = S(5678027) + S(7208785)

print(answer)
```---

 ## 坐标系```python
row_start(n)
```计算行中的第一个数字$n$:$$1+\frac{n(n-1)}2.$$然后```python
value(n, k)
```给出位置处的实际整数$(n,k)$。

 ## 邻居生成```python
neighbours(n, k)
```使用偏移量枚举所有相邻单元格$-1,0,+1$在行和列方向上。 

无效坐标将被丢弃。

 ## 分段筛

 而不是筛选所有整数$2.6\times10^{13}$，我们只筛选实际需要的短间隔。 

这使得计算变得实用。

 ## 度计算

 对于行中的每个素数$n-1,n,n+1$，我们计算有多少相邻条目是素数。 

该号码存储在：```python
degree[(r, k)]
```---

 ## 会员测试

 如果满足以下任一条件，素数属于三元组：```python
degree[(n,k)] >= 2
```或者它的相邻素数之一至少有度数$2$。
