[欧拉计划问题 68](https://projecteuler.net/problem=68)

 ## 解决方案

 **答案：**`6531031914842725`## 1.数学分析

 我们需要**最大 16 位字符串**使用数字来描述**神奇的 5 边形环**$1$通过$10$。 

5 边形环具有：

 - **5个外部节点**
 - **5个内部节点**

 每行包含：$$(\text{external}, \text{internal}_i, \text{internal}_{i+1})$$所有五行的总和必须相同。 

让：

 - 外部节点：$e_1,\dots,e_5$- 内部节点：$i_1,\dots,i_5$那么每一行都满足：$$e_k + i_k + i_{k+1} = S$$（指数模 5）。 

---

 ### 关键观察1：为什么只有16位数字？ 

每个数字都出现一次，但内部节点在串联中出现**两次**（因为每个数字属于两行）。 

数量$10$贡献**两位数**。 

如果$10$是一个**内部节点**，它出现两次→总字符串长度变为**17位**。 

我们需要一个 **16 位**字符串，所以：$$10 \text{ must be external.}$$---

 ### 关键观察2：规范表示

 该问题消除了旋转对称性：

 - 从**外部节点最小**的组开始
 - **顺时针**阅读

 因此，每个有效的排列都有一个唯一的编码。 

---

 ### 关键观察3：最大化数量

 由于字符串是按顺序连接的，因此我们需要**尽可能大的前导数字**。 

但第一组必须从**最小的外部节点**开始。 

因此，要最大化总字符串：

 - 最小的外部节点应该尽可能大，
 - 同时仍然是外部人员中最低的。 

自从$10$必须是外部的，最好的策略是将**最大的数量放在外部**。 

自然的候选人是：$$\{6,7,8,9,10\}$$作为外部节点，留下$$\{1,2,3,4,5\}$$里面。 

然后我们搜索所有有效的魔法环并取出最大有效的16位字符串。 

---

 ## 2.Python实现```python
from itertools import permutations

def solve():
    nums = set(range(1, 11))
    best = 0

    # Choose the 5 internal nodes and arrange them cyclically
    for inner in permutations(range(1, 11), 5):
        inner_set = set(inner)
        outer_nums = nums - inner_set

        # Try all permutations of outer nodes
        for outer in permutations(outer_nums):
            # Enforce canonical form:
            # first outer node must be the smallest
            if outer[0] != min(outer):
                continue

            # Compute target sum using first line
            target = outer[0] + inner[0] + inner[1]

            valid = True
            groups = []

            for i in range(5):
                a = outer[i]
                b = inner[i]
                c = inner[(i + 1) % 5]

                if a + b + c != target:
                    valid = False
                    break

                groups.append(f"{a}{b}{c}")

            if not valid:
                continue

            candidate = int("".join(groups))

            # Only keep 16-digit strings
            if len(str(candidate)) == 16:
                best = max(best, candidate)

    return best

print(solve())
```---
