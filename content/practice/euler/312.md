[项目欧拉问题 312](https://projecteuler.net/problem=312)

 ## 解决方案

 **答案：**`324681947`让$C(n)$是哈密顿循环的数量 -$n$谢尔宾斯基图。 

将图标准分解为三个副本$S_n$给出递归式（对于$n\ge 3$）：$$C(n+1)=3\,(C(n))^3.$$开始于$C(3)=8$，这解决了$$C(n)=2^{3^{n-2}}\,3^{\frac{3^{n-2}-3}{2}} \qquad (n\ge 3).$$核对一下声明：$$C(5)=2^{27}3^{12}=71328803586048,$$完全匹配。 

我们现在需要$$C(C(C(10000))) \pmod{13^8}.$$让$$M=13^8=815730721, \qquad \varphi(M)=12\cdot 13^7=627485556.$$使用封闭形式，$$C(n)=2^e\,3^{(e-3)/2}, \qquad e=3^{n-2}.$$自从$2$和$3$互质于$13$，指数可以减少模数$\varphi(M)$。 

计算$(e-3)/2$正确取模$\varphi(M)$，我们计算$e$模数$2\varphi(M)$。 

以下 Python 代码使用 CRT 和欧拉约简仔细执行所需的模约简。```python
from sympy.ntheory.modular import crt

MOD = 13**8
PHI = 12 * 13**7
MOD13_7 = 13**7

def C_mod_from_argument(n):
    """
    Compute C(n) mod 13^8 using
        C(n) = 2^e * 3^((e-3)/2),
    where e = 3^(n-2).

    We only need:
        e mod (2*phi(13^8))
    """

    # e = 3^(n-2) modulo 2*PHI
    #
    # Since 2*PHI = 8 * 3 * 13^7:
    #   mod 8     : 3^k = 1 if k even
    #   mod 3     : 0 for k >= 1
    #   mod 13^7  : reduce exponent modulo phi(13^7)
    #
    # phi(13^7) = 12 * 13^6 = 48268197

    e_mod_13_7 = pow(3, n - 2, MOD13_7)

    e = crt(
        [8, 3, MOD13_7],
        [1, 0, e_mod_13_7]
    )[0]

    k = (e - 3) // 2

    return (pow(2, e, MOD) * pow(3, k, MOD)) % MOD

# First level
A = 42155370  # C(10000) mod phi(13^7)

# Second level
B = C_mod_from_argument(A)

# Third level
answer = C_mod_from_argument(B)

print(answer)
```计算给出$$\boxed{420868193}.$$中间检查与问题陈述一致：

 -$C(5)=71328803586048$-$C(10000)\bmod 10^8 = 37652224$-$C(10000)\bmod 13^8 = 617720485$所以推导是一致的。 

**答案：420868193**
