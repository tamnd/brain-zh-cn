[项目欧拉问题 297](https://projecteuler.net/problem=297)

 ## 解决方案

 **答案：**`2252639041804718029`让$$F_1=1,\quad F_2=2,\quad F_n=F_{n-1}+F_{n-2}$$所以斐波那契数列是$$1,2,3,5,8,13,\dots$$每个正整数都有一个唯一的表示形式，即该序列中的**非连续**斐波那契数之和（泽肯多夫定理）。 

定义$z(n)$是 Zeckendorf 表示中的斐波那契项数$n$。 

我们必须计算$$\sum_{0<n<10^{17}} z(n).$$---

 # 数学分析

 定义$$S(N)=\sum_{0<n<N} z(n).$$我们寻求$S(10^{17})$。 

---

 ## 1. Zekendorf 表示的结构

 考虑所有小于$F_k$。 

每个数字$n<F_k$属于两组之一：

 1.$0\le n<F_{k-1}$2.$F_{k-1}\le n<F_k$对于第二组，写$$n=F_{k-1}+m,$$在必要的情况下$$0\le m<F_{k-2},$$因为 Zekendorf 表示不能使用连续的斐波那契数。 

因此$$z(n)=1+z(m).$$所以间隔$[F_{k-1},F_k)$贡献：

 - 每个数字有一个额外的斐波那契项，
 - 加上所有人的贡献$m<F_{k-2}$。 

因此：$$S(F_k)=S(F_{k-1})+S(F_{k-2})+F_{k-2}.$$（期限$F_{k-2}$精确计算额外的“+1”$F_{k-2}$值。）

 ---

 ## 2. 精确斐波那契边界的递归

 定义$$A_k=S(F_k).$$然后：$$A_k=A_{k-1}+A_{k-2}+F_{k-2}.$$基本案例：$$A_1=S(1)=0,$$

$$A_2=S(2)=z(1)=1.$$这让我们可以计算所有$A_k$非常快。 

---

 ## 3. 任意的一般递归$N$让$F_k$是最大的斐波那契数$$F_k\le N.$$分割范围$0<n<N$进入：

-$0<n<F_k$-$F_k\le n<N$第一个贡献：$$A_k.$$对于第二个，每个数字都有形式$$F_k+m,\qquad 0\le m<N-F_k,$$因此$$z(F_k+m)=1+z(m).$$所以：$$S(N)=A_k+(N-F_k)+S(N-F_k).$$这种递归减少了$N$通过每一步最大的斐波那契被加数，完全反映了泽肯多夫分解。 

---

 # Python 实现```python
from functools import lru_cache

LIMIT = 10**17

# ------------------------------------------------------------
# Build Fibonacci numbers:
# F1 = 1, F2 = 2
# ------------------------------------------------------------

fib = [1, 2]

while fib[-1] < LIMIT:
    fib.append(fib[-1] + fib[-2])

# ------------------------------------------------------------
# A[k] = S(F_k)
# where S(N) = sum_{0 < n < N} z(n)
#
# Recurrence:
# A[k] = A[k-1] + A[k-2] + F[k-2]
# ------------------------------------------------------------

A = [0] * len(fib)

A[0] = 0          # S(1)
A[1] = 1          # S(2)

for k in range(2, len(fib)):
    A[k] = A[k-1] + A[k-2] + fib[k-2]

# ------------------------------------------------------------
# Recursive computation of S(N)
# ------------------------------------------------------------

@lru_cache(None)
def S(N):
    if N <= 1:
        return 0

    # largest Fibonacci number <= N
    k = 0
    while k + 1 < len(fib) and fib[k + 1] <= N:
        k += 1

    # exact boundary
    if fib[k] == N:
        return A[k]

    # recursive decomposition
    return A[k] + (N - fib[k]) + S(N - fib[k])

# ------------------------------------------------------------
# Compute answer
# ------------------------------------------------------------

answer = S(10**17)

print(answer)
```---

 ## 预计算$A_k=S(F_k)$

```python
A[k] = A[k-1] + A[k-2] + fib[k-2]
```这实现了之前导出的递归。 

例如：$$S(8)=10$$因为：$$\begin{aligned} z(1)&=1\\ z(2)&=1\\ z(3)&=1\\ z(4)&=2\\ z(5)&=1\\ z(6)&=2\\ z(7)&=2 \end{aligned}$$和$$1+1+1+2+1+2+2=10.$$---

 ## 递归计算```python
return A[k] + (N - fib[k]) + S(N - fib[k])
```这完全对应于：$$S(N)=S(F_k)+(N-F_k)+S(N-F_k).$$递归深度很小，因为 Zekendorf 分解很短。
