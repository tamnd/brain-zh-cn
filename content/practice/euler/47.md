[项目欧拉问题 47](https://projecteuler.net/problem=47)

 ## 解决方案

 **答案：**`134043`我们寻找**四个连续整数**的第一次运行，每个整数恰好具有**四个不同的质因数**。 

让$\omega(n)$表示不同质因数的数量$n$。 

我们想要最小的$n$这样$$\omega(n)=\omega(n+1)=\omega(n+2)=\omega(n+3)=4.$$---

 # 数学分析

 如果一个数的素因数分解包含四个不同的素数，则无论指数大小如何，该数都有四个不同的素因数。 

例如：$$644 = 2^2 \cdot 7 \cdot 23$$有不同的质数$\{2,7,23\}$，所以它正好有$3$不同的质因数。 

蛮力策略是：

 1. 对每个整数进行因式分解。 
2. 计算不同的素因数。 
3. 搜索满足条件的四个连续整数。 

然而，如果简单地进行重复因式分解会很慢。 

---

 ## 高效思路：改良筛

 我们可以使用类似筛子的方法，而不是独立地分解每个数字。 

创建一个数组：$$\text{count}[n]$$在哪里`count[n]`将存储不同质因数的数量$n$。 

最初所有条目都是$0$。 

现在迭代整数$p$：

- 如果`count[p] == 0`， 然后$p$是素数。 
- 对于每个倍数$p$，将其计数增加$1$。 

这是有效的，因为每个素数对每个倍数只贡献一次。 

示例：

 - 总理$2$递增所有偶数。 
- 主要的$3$递增所有倍数$3$。 
- 等

 筛完后：$$\text{count}[n] = \omega(n)$$对于每一个$n$。 

然后扫描四个连续条目等于$4$。 

这是非常有效的并且反映了经典的埃拉托斯特尼筛法。 

---

 # Python 实现```python
def first_consecutive_integers(target_factors=4, consecutive=4, limit=200000):
    """
    Find the first integer in the first run of `consecutive`
    consecutive integers each having exactly `target_factors`
    distinct prime factors.
    """

    # count[n] will store the number of distinct prime factors of n
    count = [0] * (limit + 1)

    # Modified sieve
    for p in range(2, limit + 1):

        # If count[p] == 0, then p is prime
        if count[p] == 0:

            # Add this prime factor to all multiples of p
            for multiple in range(p, limit + 1, p):
                count[multiple] += 1

    # Search for consecutive integers
    streak = 0

    for n in range(2, limit + 1):

        if count[n] == target_factors:
            streak += 1

            if streak == consecutive:
                return n - consecutive + 1
        else:
            streak = 0

    return None

# Compute the Project Euler answer
answer = first_consecutive_integers()

print(answer)
```---
