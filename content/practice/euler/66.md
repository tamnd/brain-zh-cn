[欧拉计划问题 66](https://projecteuler.net/problem=66)

 ## 解决方案

 **答案：**`661`对于佩尔方程$$x^2 - Dy^2 = 1,$$和$D$一个非平方正整数，我们求$D \le 1000$其_最小_解决方案$x$尽可能大。 

关键事实是，佩尔方程的最小解是通过连分式展开生成的$\sqrt D$。 

---

 # 数学分析

 我们想要整数解$$x^2 - Dy^2 = 1.$$这就是佩尔方程。 

对于方形$D$，我们没有非平凡整数解，因为$$x^2 - Dy^2=(x-\sqrt D\,y)(x+\sqrt D\,y),$$和$\sqrt D$是理性的。 所以我们只考虑非正方形。 

---

 ## 连分数和佩尔方程

 一个经典定理指出：

 > 最小解决方案$(x,y)$的
 >
 >
 >
 >
 >$$x^2-Dy^2=1$$>
 >
 >
 >
 > 由周期性连分式展开式的收敛性获得$\sqrt D$。 

的连分数$\sqrt D$有形式$$\sqrt D = [a_0;\overline{a_1,a_2,\dots,a_k}],$$该块定期重复的地方。 

收敛式是分数$$\frac{p_n}{q_n},$$递归生成$$p_n = a_n p_{n-1} + p_{n-2},$$

$$q_n = a_n q_{n-1} + q_{n-2}.$$当满足 Pell 方程时，收敛性恰好满足$$p_n^2 - D q_n^2 = 1.$$第一个这样的收敛给出了最小解。 

---

 ## 计算连分数$\sqrt D$对于非正方形$D$， 定义$$a_0 = \lfloor \sqrt D \rfloor.$$然后迭代$$m_{n+1} = d_n a_n - m_n,$$

$$d_{n+1} = \frac{D - m_{n+1}^2}{d_n},$$

$$a_{n+1} = \left\lfloor \frac{a_0 + m_{n+1}}{d_{n+1}} \right\rfloor.$$开始于$$m_0=0,\quad d_0=1,\quad a_0=\lfloor\sqrt D\rfloor.$$在每一步中，我们都会构建收敛点，直到满足佩尔方程为止。 

---

 # Python 实现```python
import math

def minimal_pell_solution_x(D):
    """
    Return the minimal x satisfying:
        x^2 - D*y^2 = 1
    for a non-square D.
    """

    a0 = int(math.isqrt(D))

    # Ignore perfect squares
    if a0 * a0 == D:
        return None

    # Continued fraction variables
    m = 0
    d = 1
    a = a0

    # Convergent recurrence:
    # p/q are convergents
    p_minus2, p_minus1 = 0, 1
    q_minus2, q_minus1 = 1, 0

    while True:
        # Current convergent
        p = a * p_minus1 + p_minus2
        q = a * q_minus1 + q_minus2

        # Check Pell equation
        if p * p - D * q * q == 1:
            return p

        # Advance continued fraction
        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        # Shift recurrence variables
        p_minus2, p_minus1 = p_minus1, p
        q_minus2, q_minus1 = q_minus1, q

max_x = 0
answer_D = 0

for D in range(2, 1001):
    x = minimal_pell_solution_x(D)

    if x is not None and x > max_x:
        max_x = x
        answer_D = D

print(answer_D)
```---

 ## 初始化连分数变量```python
m = 0
d = 1
a = a0
```这些产生了连续分数展开式$\sqrt D$。 

---

 ## 初始化收敛递归```python
p_minus2, p_minus1 = 0, 1
q_minus2, q_minus1 = 1, 0
```这些是收敛的标准起始值。 

---

 ## 构建收敛```python
p = a * p_minus1 + p_minus2
q = a * q_minus1 + q_minus2
```这将计算下一个收敛$p/q$。 

---

 ## 检查佩尔方程```python
if p * p - D * q * q == 1:
    return p
```满足方程的第一个收敛给出最小解。 

---

 ## 前进连分数```python
m = d * a - m
d = (D - m * m) // d
a = (a0 + m) // d
```这些是二次无理数连分数的标准递推公式。

 # 小例子验证

 对于$D=13$，代码发现：$$649^2 - 13 \cdot 180^2 = 1.$$的确，$$649^2 = 421201,$$

$$13 \cdot 180^2 = 13 \cdot 32400 = 421200,$$不同之处$=1$。 

这与问题陈述相符。 

为了$D \le 7$，最小的$x$- 值为：

 |$D$| 最小的$x$|
 | ---| ---|
 | 2 | 3 |
 | 3 | 2 |
 | 5 | 9 |
 | 6 | 5 |
 | 7 | 8 |

 最大的是$9$在$D=5$，再次匹配提示。

 # 最终验证

 问题 66 的已知欧拉计划结果是最大最小解$x$为了$D \le 1000$发生在$$D = 661.$$相应的最小$x$非常大（超过 30 位），这与 Pell 方程偶尔会产生巨大的极小解是一致的。 

**答案：661**
