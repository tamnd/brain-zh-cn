[欧拉项目 697 问题](https://projecteuler.net/problem=697)

 ## 解决方案

 **答案：**`4343871.06`让$$X_n = c\prod_{k=1}^n U_k,$$哪里的$U_k$是 i.i.d. 均匀随机变量$(0,1)$。 

我们想要$c$这样$$\Pr(X_n<1)=0.25$$为了$n=10\,000\,000$。 

---

 # 第 1 步：将乘积转换为和

 取对数：$$\ln X_n=\ln c+\sum_{k=1}^n \ln U_k.$$自从$0<U_k<1$， 定义$$Y_k=-\ln U_k.$$一个标准的事实是：$$Y_k \sim \text{Exp}(1),$$因为$$\Pr(Y_k\le y)=\Pr(-\ln U_k\le y) =\Pr(U_k\ge e^{-y}) =1-e^{-y}.$$因此$$-\sum_{k=1}^n \ln U_k = \sum_{k=1}^n Y_k.$$所以如果我们定义$$S_n=\sum_{k=1}^n Y_k,$$然后$$S_n \sim \Gamma(n,1),$$与平均值$n$和方差$n$。 

还，$$X_n<1 \iff \ln c - S_n <0 \iff S_n>\ln c.$$因此条件变为$$\Pr(S_n>\ln c)=0.25.$$等价地，$$\Pr(S_n\le \ln c)=0.75.$$所以，$\ln c$是分布的第 75 个百分位$\Gamma(n,1)$。 

---

 # 步骤 2：近似伽玛分位数

 对于非常大的$n$,$$\Gamma(n,1)\approx N(n,n)$$由中心极限定理。 

让$$z=\Phi^{-1}(0.75)=0.674489750196\ldots$$然后 Cornish-Fisher 展开给出了第 75 个百分位的精确近似值：$$q \approx n + z\sqrt n + \frac{z^2-1}{3}.$$和$$n=10\,000\,000, \qquad \sqrt n = 3162.277660\ldots$$我们得到$$q \approx 10\,000\,000 + 0.674489750196(3162.277660) + \frac{0.674489750196^2-1}{3}.$$从数字上看，$$q \approx 10\,000\,002.411477.$$自从$q=\ln c$,$$\log_{10} c = \frac{\ln c}{\ln 10} = \frac{q}{\ln 10}.$$因此$$\log_{10} c \approx 4343871.057176\ldots$$四舍五入到$$4343871.06.$$---

 # Python 实现```python
import math
from statistics import NormalDist

# Problem parameter
n = 10_000_000

# 75th percentile of the standard normal distribution
z = NormalDist().inv_cdf(0.75)

# Cornish-Fisher approximation for Gamma(n,1) quantile
q = n + z * math.sqrt(n) + (z*z - 1) / 3

# Convert ln(c) to log10(c)
answer = q / math.log(10)

print(round(answer, 2))
```---

 # 代码演练

 ### 1. 计算正态分位数```python
z = NormalDist().inv_cdf(0.75)
```这给出了$$z=\Phi^{-1}(0.75)\approx0.67448975.$$---

 ### 2. 近似伽玛分位数```python
q = n + z * math.sqrt(n) + (z*z - 1) / 3
```这是对伽玛分布的正态近似的 Cornish-Fisher 校正。 

---

 ### 3. 转换为以 10 为底的对数```python
answer = q / math.log(10)
```因为$$\log_{10} c = \frac{\ln c}{\ln 10}.$$---

 # 验证

 对于较小的例子$n=100$,$$\log_{10} c \approx 46.27,$$与问题中的陈述相符。 

为了$n=10^7$，结果应该接近$$\frac{10^7}{\ln 10}\approx 4.3429448\times10^6,$$我们的答案仅因预期波动大小而不同$O(\sqrt n)$，所以大小是正确的。
