[欧拉项目问题 319](https://projecteuler.net/problem=319)

 ## 解决方案

 **答案：**`268457129`让$$x_1,x_2,\dots,x_n$$满足

 -$x_1=2$,
 -$x_{i-1}<x_i$,
 - 对于所有人$i,j$,$$x_i^j<(x_j+1)^i.$$我们寻求$t(n)$，此类序列的数量，对于$n=10^{10}$, 取模$10^9$。 

## 1.数学分析

 关键的观察是条件$$x_i^j < (x_j+1)^i$$可以重写为$$x_i^{1/i} < (x_j+1)^{1/j}.$$因此所有间隔$$I_i=\left(x_i^{1/i},\,(x_i+1)^{1/i}\right)$$必须有非空交集。 

因此存在实数$\lambda\in(2,3)$这样对于每个$i$,$$x_i < \lambda^i < x_i+1.$$所以$$x_i=\lfloor \lambda^i\rfloor.$$所以每个有效序列都唯一对应于某个区间$\lambda\in(2,3)$，并且序列仅在以下情况下改变$\lambda$跨越边界$$\lambda = k^{1/i}, \qquad 2^i \le k < 3^i.$$因此：$$t(n) = \#\left\{ k^{1/i} : 1\le i\le n,\, 2^i\le k<3^i \right\}.$$（注意$\lambda=2$本身包含通过$k=2^i$.)

 ---

 ### 规范计数

 定义**最小分母**$d$的边界值$r$作为最小的正整数，使得$r^d\in\mathbb Z$。 

让$g(d)$是其最小分母恰好为的边界点的数量$d$。 

然后$$t(n)=\sum_{d\le n} g(d).$$对于固定$d$，每个候选人看起来都像$$r = m^{1/d}, \qquad 2^d\le m<3^d.$$它的分母不是最小的当且仅当$m$是一个$e$某个除数的次方$e\mid d$,$e>1$。 

通过莫比乌斯反演：$$g(d) = \sum_{e\mid d} \mu(e) \left(3^{d/e}-2^{d/e}\right),$$在哪里$\mu$是莫比乌斯函数。 

所以$$t(n) = \sum_{d\le n} \sum_{e\mid d} \mu(e) \left(3^{d/e}-2^{d/e}\right).$$交换求和与$d=ek$:$$t(n) = \sum_{e\le n} \mu(e) \sum_{k\le n/e} (3^k-2^k).$$定义$$F(m) = \sum_{k=1}^{m}(3^k-2^k).$$使用几何和：$$F(m) = \frac{3^{m+1}-3}{2} - (2^{m+1}-2).$$所以：$$t(n) = \sum_{e\le n} \mu(e)\, F\!\left(\left\lfloor \frac ne \right\rfloor\right).$$这可以计算为大约$O(\sqrt n)$使用总和莫比乌斯函数（Mertens 函数）计算不同的下限值。

 ## 2.Python实现```python
from functools import lru_cache

MOD = 10**9
MOD2 = 2 * MOD

def solve(n):
    # Precompute Möbius up to a cutoff
    LIMIT = 2_000_000

    mu = [0] * (LIMIT + 1)
    mu[1] = 1

    primes = []
    composite = [False] * (LIMIT + 1)

    # Linear sieve for Möbius
    for i in range(2, LIMIT + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > LIMIT:
                break

            composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break
            else:
                mu[v] = -mu[i]

    # Prefix Mertens values
    mertens_prefix = [0] * (LIMIT + 1)
    for i in range(1, LIMIT + 1):
        mertens_prefix[i] = mertens_prefix[i - 1] + mu[i]

    @lru_cache(None)
    def M(x):
        """Summatory Möbius function."""
        if x <= LIMIT:
            return mertens_prefix[x]

        result = 1
        l = 2

        while l <= x:
            q = x // l
            r = x // q
            result -= (r - l + 1) * M(q)
            l = r + 1

        return result

    def F(m):
        """Sum_{k=1..m} (3^k - 2^k) modulo 1e9."""
        s3 = ((pow(3, m + 1, MOD2) - 3) % MOD2) // 2
        s2 = (pow(2, m + 1, MOD) - 2) % MOD
        return (s3 - s2) % MOD

    ans = 0
    l = 1

    # Group equal floor(n / i)
    while l <= n:
        q = n // l
        r = n // q

        coeff = M(r) - M(l - 1)
        ans = (ans + coeff * F(q)) % MOD

        l = r + 1

    return ans

print(solve(10**10))
```---

 ## 3. 代码演练

 1. **线性筛**计算莫比乌斯值$\mu(n)$。 
2. **前缀和**构建 Mertens 函数$$M(x)=\sum_{k\le x}\mu(k).$$1.`M(x)`对于大$x$使用标准的分治恒等式：$$M(x) = 1-\sum_{l=2}^{x} (r-l+1)M\!\left(\left\lfloor \frac{x}{l}\right\rfloor\right),$$分组相等的商。 

1.`F(m)`计算$$\sum_{k=1}^{m}(3^k-2^k)$$通过几何和模$10^9$。 

1. 主循环将相等的值分组$$\left\lfloor \frac{n}{i}\right\rfloor$$达到近$O(\sqrt n)$复杂。
