[欧拉项目问题 39](https://projecteuler.net/problem=39)

 ## 解决方案

 **答案：**`840`我们寻找周界$p \le 1000$产生**最大数量的整数直角三角形解**$(a,b,c)$满意的$$a^2+b^2=c^2,\qquad a+b+c=p$$在哪里$a,b,c$是正整数。 

## 1.数学分析

 具有整数边长的直角三角形是一个**毕达哥拉斯三元组**：$$a^2+b^2=c^2$$我们想要计算每个周长有多少个三元组$p\le 1000$。 

由于顺序并不重要，因此假设：$$a \le b < c$$然后：$$a+b+c=p$$代替：$$c = p-a-b$$代入毕达哥拉斯方程：$$a^2+b^2=(p-a-b)^2$$扩展：$$a^2+b^2 = p^2+a^2+b^2-2pa-2pb+2ab$$取消$a^2+b^2$：$$0=p^2-2p(a+b)+2ab$$重新排列：$$2ab = 2p(a+b)-p^2$$对于固定周长$p$，我们可以有效地枚举整数值$a,b$并检查是否$$c=\sqrt{a^2+b^2}$$是积分并且是否$$a+b+c=p.$$### 搜索范围

 自从$a \le b < c$,$$a < \frac{p}{3}$$和$$b < \frac{p-a}{2}$$这显着减少了搜索空间。 

＃＃＃ 例子：$p=120$该问题提出了三种解决方案：$$(20,48,52)$$

$$(24,45,51)$$

$$(30,40,50)$$的确：

-$20^2+48^2=52^2$-$24^2+45^2=51^2$-$30^2+40^2=50^2$所以$p=120$正好有 3 个解。

 ## 2.Python实现```python
def count_solutions(p):
    """
    Count the number of integer right-triangle solutions
    with perimeter p.
    """
    count = 0

    # Ensure a <= b < c
    for a in range(1, p // 3 + 1):
        for b in range(a, (p - a) // 2 + 1):
            c = p - a - b

            # Check Pythagorean condition
            if a * a + b * b == c * c:
                count += 1

    return count

max_count = 0
best_p = 0

# Test every perimeter up to 1000
for p in range(1, 1001):
    solutions = count_solutions(p)

    if solutions > max_count:
        max_count = solutions
        best_p = p

print(best_p)
```---

 ## 4.最终验证

 最大化周长应该：

 - **均匀**，因为几乎所有毕达哥拉斯三重周长都是均匀的；
 - 具有多种因素组合（高可除性）；
 - 可能是几个原始三元组的倍数。 

执行搜索给出：$$p = 840$$它有 **8 个不同的整数直角三角形解**，最大为$p \le 1000$。 

**答案：840**
