[欧拉项目734问题](https://projecteuler.net/problem=734)

 ## 解决方案

 **答案：**`557988060`让$P_n$是素数集$\le n$，并定义$$f(x)= \begin{cases} 1 & x\in P_n\\ 0 & \text{otherwise} \end{cases}$$我们想要的数量$k$-按位或运算也是素数的素数元组。 

关键的观察是按位或卷积在子集 zeta 变换下变得简单。 

对于面膜来说$m$， 定义$$F(m)=\sum_{s\subseteq m} f(s)$$计算其集合位包含在中的素数$m$。 

然后：

-$F(m)^k$已订购计数$k$- 素数元组，其 OR 是以下子集$m$。 
- 对子集应用莫比乌斯求逆可以恢复 OR 恰好为的元组数量$m$。 

因此：

 1. 构建素数指标数组。 
2. 应用 OR-zeta 变换。 
3. 将每个变换后的值提高到$k$次幂。 
4. 应用 OR-zeta 逆变换。 
5. 对素数掩模求和。 

以下 Python 代码精确计算答案。```python
from math import isqrt

MOD = 1_000_000_007
n = 10**6
k = 999983

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
sieve = bytearray(b'\x01') * (n + 1)
sieve[0] = sieve[1] = 0

for p in range(2, isqrt(n) + 1):
    if sieve[p]:
        sieve[p * p:n + 1:p] = b'\x00' * (((n - p * p) // p) + 1)

primes = [i for i, v in enumerate(sieve) if v]

# ------------------------------------------------------------
# OR convolution via subset zeta transform
# ------------------------------------------------------------
BITS = 20                  # since 2^20 > 10^6
SIZE = 1 << BITS

# f[x] = 1 if x is prime else 0
F = [0] * SIZE
for p in primes:
    F[p] = 1

# ------------------------------------------------------------
# OR-zeta transform
# After this:
# F[m] = number of primes s with s ⊆ m (bitwise)
# ------------------------------------------------------------
for b in range(BITS):
    bit = 1 << b
    for mask in range(SIZE):
        if mask & bit:
            F[mask] += F[mask ^ bit]
            F[mask] %= MOD

# ------------------------------------------------------------
# k-th OR convolution power
# ------------------------------------------------------------
for i in range(SIZE):
    F[i] = pow(F[i], k, MOD)

# ------------------------------------------------------------
# Möbius inversion for OR transform
# ------------------------------------------------------------
for b in range(BITS):
    bit = 1 << b
    for mask in range(SIZE):
        if mask & bit:
            F[mask] -= F[mask ^ bit]
            F[mask] %= MOD

# ------------------------------------------------------------
# Sum counts whose OR is prime
# ------------------------------------------------------------
answer = sum(F[p] for p in primes) % MOD

print(answer)
```对照例子验证：

 -$T(5,2)=5$-$T(100,3)=3355$-$T(1000,10)\equiv 2071632 \pmod{10^9+7}$全部与问题陈述相符。
