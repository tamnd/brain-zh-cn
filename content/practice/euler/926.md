[项目欧拉问题 926](https://projecteuler.net/problem=926)

 ## 解决方案

 **答案：**`40410219`对于一个号码$n$，底座的圆度$b$是最大的$k$这样$b^k \mid n$。 

因此：$$R(n)=\sum_{b\ge2} v_b(n)$$在哪里$v_b(n)$是的指数$b$划分$n$。 

现在观察：$$v_b(n)=\sum_{k\ge1} [b^k\mid n]$$所以$$R(n)=\sum_{k\ge1} \#\{b\ge2 : b^k\mid n\}.$$如果$$n=\prod p_i^{a_i},$$然后$b^k\mid n$当且仅当每个素数指数$b$至多是$\left\lfloor a_i/k\right\rfloor$。 

因此这样的数量$b$是$$\prod_i \left(\left\lfloor \frac{a_i}{k}\right\rfloor+1\right)-1,$$（这 ”$-1$” 排除$b=1$）。 

所以：$$R(n)=\sum_{k\ge1} \left( \prod_i \left(\left\lfloor \frac{a_i}{k}\right\rfloor+1\right)-1 \right).$$为了$n=N!$，指数是$$a_p=v_p(N!)=\sum_{j\ge1}\left\lfloor \frac{N}{p^j}\right\rfloor.$$以下 Python 代码有效地计算该值。```python
MOD = 10**9 + 7
N = 10_000_000

# exponent of 2 in N! gives the maximum possible k
a2 = 0
t = N
while t:
    t //= 2
    a2 += t

# D[k] = product over primes p of (floor(v_p(N!)/k) + 1)
D = [1] * (a2 + 1)

# sieve of Eratosthenes
sieve = bytearray(b"\x01") * (N + 1)
sieve[0] = sieve[1] = 0

limit = int(N**0.5)
for i in range(2, limit + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:N + 1:step] = b"\x00" * (((N - start) // step) + 1)

primes = [i for i in range(2, N + 1) if sieve[i]]

# process each prime exponent in N!
for p in primes:
    a = 0
    t = N
    while t:
        t //= p
        a += t

    for k in range(1, a + 1):
        D[k] = (D[k] * (a // k + 1)) % MOD

answer = sum(x - 1 for x in D) % MOD
print(answer)
```样品验证：

 -$R(20)=6$-$R(10!)=312$两者都与声明相符。
