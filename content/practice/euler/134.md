[欧拉项目问题 134](https://projecteuler.net/problem=134)

 ## 解决方案

 **答案：**`18613426663617118`设连续素数为$p_1$和$p_2$， 和$p_2 > p_1$。 

我们寻找最小的整数$S$这样：

 1.$S \equiv p_1 \pmod{10^d}$， 在哪里$d$是小数位数$p_1$,
 2.$S \equiv 0 \pmod{p_2}$。 

例如，与$p_1=19$,$p_2=23$：$$1219 \equiv 19 \pmod{100}, \qquad 1219 \equiv 0 \pmod{23}.$$我们必须计算$$\sum S$$在所有连续素数对上$$5 \le p_1 \le 10^6.$$---

 # 数学分析

 假设$d$是的位数$p_1$，并定义$$m = 10^d.$$任何以以下数字结尾的数字$p_1$可以写成$$S = m k + p_1$$对于某个整数$k \ge 0$。 

我们要求$S$可以被整除$p_2$：$$mk + p_1 \equiv 0 \pmod{p_2}.$$因此，$$mk \equiv -p_1 \pmod{p_2}.$$因为$p_2$是素数并且$p_2 \ne 2,5$，我们有$$\gcd(m,p_2)=1,$$所以$m$有一个模逆模$p_2$。 所以，$$k \equiv -p_1 \cdot m^{-1} \pmod{p_2}.$$最小的非负解是$$k = (-p_1)\,m^{-1} \bmod p_2.$$然后$$S = mk + p_1.$$所以整个问题简化为重复的模逆。 

---

 ## 计算模逆

 自从$p_2$是素数，$$m^{-1} \equiv m^{p_2-2} \pmod{p_2}$$由费马小定理。 

Python 直接提供了这个：```python
pow(m, -1, p2)
```它可以有效地计算模逆。 

---

 # 算法

 1. 生成稍高于一点的所有素数$10^6$。 
2. 对于每个连续的对$(p_1,p_2)$：

- 跳过$p_1 < 5$,
 - 停止一次$p_1 > 10^6$，
- 让$m = 10^{\text{digits}(p_1)}$,
 - 计算：$$k = (-p_1)\cdot m^{-1} \bmod p_2,$$- 计算：$$S = mk + p_1,$$- 添加到总数。 
3. 输出总计。 

复杂性由筛子决定：$$O(n \log\log n)$$这很容易足够快$10^6$。 

---

 # Python 实现```python
from math import isqrt

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
def sieve(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, isqrt(limit) + 1):
        if is_prime[i]:
            step = i
            start = i * i
            is_prime[start:limit + 1:step] = [False] * (
                ((limit - start) // step) + 1
            )

    return [i for i, v in enumerate(is_prime) if v]

# We need primes slightly beyond 1,000,000
LIMIT = 1_100_000
primes = sieve(LIMIT)

total = 0

for i in range(len(primes) - 1):
    p1 = primes[i]
    p2 = primes[i + 1]

    if p1 < 5:
        continue

    if p1 > 1_000_000:
        break

    # 10^d where d = number of digits of p1
    m = 10 ** len(str(p1))

    # Solve m*k + p1 ≡ 0 (mod p2)
    inv = pow(m, -1, p2)

    k = (-p1 * inv) % p2

    S = m * k + p1

    total += S

print(total)
```---

 # 举例验证

 对于$p_1=19$,$p_2=23$：$$m = 100.$$我们解决：$$100k + 19 \equiv 0 \pmod{23}.$$自从$$100 \equiv 8 \pmod{23},$$我们解决：$$8k \equiv -19 \equiv 4 \pmod{23}.$$的逆$8$模组$23$是$3$， 所以：$$k \equiv 12 \pmod{23}.$$因此$$S = 100 \cdot 12 + 19 = 1219,$$与问题陈述相匹配。
