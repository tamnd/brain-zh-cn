[项目欧拉问题 301](https://projecteuler.net/problem=301)

 ## 解决方案

 **答案：**`2178309`对于正常玩的 Nim，获胜/失败条件完全由 **nim-sum** （堆大小的按位异或）来表征。 

一个位置$(n_1,n_2,n_3)$正在失败当且仅当$$n_1 \oplus n_2 \oplus n_3 = 0.$$所以我们想要正整数的个数$n \le 2^{30}$这样$$n \oplus 2n \oplus 3n = 0.$$关键是简化这个按位条件。 

---

 ## 1.数学分析

 Nim 失败条件给出：$$X(n,2n,3n)=0 \iff n\oplus 2n\oplus 3n = 0.$$现在观察：$$3n = n + 2n.$$一个有用的按位恒等式是：$$a+b = (a\oplus b) + 2(a\&b).$$因此：$$a\oplus b = a+b \quad\Longleftrightarrow\quad a\&b = 0.$$应用此与$a=n$,$b=2n$。 

如果$$n\oplus 2n = 3n,$$然后$$n\oplus 2n\oplus 3n = 0.$$自从$3n=n+2n$，当二进制加法中**没有进位**时，就会发生这种情况$n+2n$， IE。$$n\&2n = 0.$$但乘以 2 只是左移：$$2n = n \ll 1.$$所以：$$n \& (n\ll1)=0.$$这意味着：

 > **没有两个相邻位$n$可能都是 1.**

 那么问题就变成了：

 > 计算整数$1\le n\le 2^{30}$其二进制表示不包含连续的 1。 

---

 ### 斐波那契结构

 让$f(k)$是长度为二进制字符串的数量$k$没有相邻的 1。 

按第一位分割：

 - 以 0 开头：$f(k-1)$- 以 10 开头：$f(k-2)$因此：$$f(k)=f(k-1)+f(k-2),$$斐波那契递推。 

和：$$f(0)=1,\qquad f(1)=2$$我们得到：$$f(k)=F_{k+2},$$在哪里$F_1=1,F_2=1$。 

现在考虑数字$0\le n<2^{30}$。 这些完全对应于长度最多为 30 的二进制字符串，因此计数为$$F_{32}.$$但我们的范围是$$1\le n\le 2^{30}.$$注意：

-$n=0$包含在$F_{32}$计数但必须排除。 
-$n=2^{30}$（二进制$1000\ldots0$) 有效且必须包含在内。 

这些完全取消。 

所以最终的计数仍然是：$$F_{32}.$$计算：$$F_{32}=2178309.$$---

 ## 2.Python实现```python
def solve(limit_power=30):
    # We need F_(limit_power + 2)
    # Fibonacci with F1 = 1, F2 = 1

    a, b = 1, 1  # F1, F2

    # Compute F32 for limit_power = 30
    target = limit_power + 2

    for _ in range(3, target + 1):
        a, b = b, a + b

    return b

print(solve())
```---

### 小健全性检查

 声明中的示例：$$(1,2,3)$$二进制：

 -$1=001$-$2=010$-$3=011$异或：$$1\oplus2\oplus3=0$$所以$X(1,2,3)=0$，匹配问题陈述。 

检查几个$n$:

 -$n=1$：二进制`1`→ 有效
 -$n=2$：二进制`10`→ 有效
 -$n=3$：二进制`11`→ 无效（相邻的）
 -$n=5$：二进制`101`→ 有效
 -$n=6$：二进制`110`→ 无效

 正是“没有连续的 1”规则。

 ## 4.最终验证

 答案应该围绕斐波那契增长：$$F_{32}\approx 2.1\times10^6,$$这是合理的，因为有$2^{30}\approx10^9$没有连续 1 的候选者和有效位串呈指数稀疏。 

取消排除$0$并包括$2^{30}$是一个重要的边缘情况，并确认计数保持准确$F_{32}$。 

**答案：2178309**
