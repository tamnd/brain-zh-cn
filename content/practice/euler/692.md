[欧拉项目 692 问题](https://projecteuler.net/problem=692)

 ## 解决方案

 **答案：**`842043391019219959`让斐波那契数列定义为$$F_1=1,\qquad F_2=2,\qquad F_n=F_{n-1}+F_{n-2}.$$所以：$$1,2,3,5,8,13,21,\dots$$这个游戏背后的关键事实是它正是**Fibonacci Nim**。 

## 1.数学分析

 ### 步骤1：亏损头寸是斐波那契数列

 斐波那契 Nim 的经典结果指出：

 > 一个职位$N$卵石正在失去 iff$N$是一个斐波那契数列$F_k$。 

这解释了这些例子：

 -$H(8)=8$因为$8$是斐波那契，所以齐格伯特必须立即拿走所有的鹅卵石。 
-$H(18)=5$因为$$18 = 13+5,$$并删除$5$树叶$13$，亏损的斐波那契位置。 

---

 ### 步骤 2：Zeckendorf 表示

 每个正整数都有一个唯一的表示形式，即**非连续斐波那契数**的总和：$$N = F_{a_1}+F_{a_2}+\cdots$$这就是 **Zeckendorf 分解**。 

对于斐波那契尼姆：

 > 最小获胜动作$H(N)$等于 Zeckendorf 分解中的**最小斐波那契被加数**$N$。 

示例：$$4=3+1 \Rightarrow H(4)=1$$

$$17=13+3+1 \Rightarrow H(17)=1$$

$$18=13+5 \Rightarrow H(18)=5$$这与问题陈述完全吻合。 

---

 ### 步骤 3：区间结构

 对于区间内的数字$$F_m \le n < F_{m+1},$$每个数字都可以唯一地写为$$n = F_m + r, \qquad 0\le r < F_{m-1}.$$如果$r>0$，最小的 Zekendorf 项$n$恰好是最小项$r$。 因此$$H(F_m+r)=H(r) \quad (r>0),$$尽管$$H(F_m)=F_m.$$因此区间和为$$B_m = \sum_{n=F_m}^{F_{m+1}-1}H(n) = F_m + G(F_{m-1}-1).$$让$$S_m = G(F_m).$$然后就得到了递归式$$S_m = S_{m-1}+S_{m-2}+F_{m-1},$$具有初始值$$S_1=1,\qquad S_2=3.$$查看：$$S_6 = S_5+S_4+F_5 = 23+12+8 = 43,$$自从$F_6=13$,$$G(13)=43,$$匹配问题陈述。 

---

 ### 步骤 4：目标值

 我们被给予$$N=23416728348467685.$$这正是斐波那契数列$$F_{79}.$$所以我们计算$S_{79}=G(F_{79})$使用递归。 

---

 ## 2.Python实现```python
# Fibonacci numbers with F1 = 1, F2 = 2
F = [1, 2]

TARGET = 23416728348467685

# Build Fibonacci sequence until target
while F[-1] < TARGET:
    F.append(F[-1] + F[-2])

m = len(F)  # target is F_m

# S[m] = G(F_m)
S = [0] * (m + 1)

S[1] = 1  # G(1)
S[2] = 3  # G(2)

# Recurrence:
# S_m = S_(m-1) + S_(m-2) + F_(m-1)
for i in range(3, m + 1):
    S[i] = S[i - 1] + S[i - 2] + F[i - 2]

print(S[m])
```---
