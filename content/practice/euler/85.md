[项目欧拉问题 85](https://projecteuler.net/problem=85)

 ## 解决方案

 **答案：**`2772`让网格有宽度$m$和身高$n$，以单位平方测量。 

我们想要计算网格内可以形成多少个不同的矩形。 

# 第 1 步：计算一个矩形中的矩形$m \times n$网格

 矩形通过选择来确定：

 - 两条不同的垂直网格线，
 - 两条不同的水平网格线。 

一个$m \times n$网格有：

 -$m+1$垂直网格线，
 -$n+1$水平网格线。 

所以矩形的数量是$$\binom{m+1}{2}\binom{n+1}{2}.$$使用$$\binom{k}{2}=\frac{k(k-1)}2,$$我们得到$$R(m,n) = \frac{m(m+1)}2 \cdot \frac{n(n+1)}2.$$所以$$R(m,n)=\frac{m(m+1)n(n+1)}4.$$目标是：$$R(m,n)\approx 2{,}000{,}000.$$我们被要求提供网格面积$$A=mn$$其矩形数量最接近 200 万。 

---

 # 第二步：验证小例子

 对于一个$3\times2$网格：$$R(3,2) = \frac{3\cdot4}{2}\cdot\frac{2\cdot3}{2} = 6\cdot3 = 18.$$这与问题陈述相符。 

---

 # 第三步：策略

 矩形计数的增长大致如下$$\frac{m^2n^2}{4},$$因此，接近目标的值的尺寸将在几十左右。 

在合理范围内进行强力搜索是完全可行的。 

对于每对$(m,n)$:

 1. 计算矩形数量，
 2. 计算与$2{,}000{,}000$,
 3.保持最佳网格。 

---

 # Python 实现```python
TARGET = 2_000_000

best_diff = float('inf')
best_area = None
best_dims = None

# Search reasonable grid sizes.
# 100 is safely large enough.
for m in range(1, 101):
    for n in range(1, 101):

        # Number of rectangles in an m x n grid
        rectangles = (m * (m + 1) * n * (n + 1)) // 4

        diff = abs(rectangles - TARGET)

        # Update best solution if closer
        if diff < best_diff:
            best_diff = diff
            best_area = m * n
            best_dims = (m, n)

print("Best dimensions:", best_dims)
print("Area:", best_area)
print("Rectangle count:",
      (best_dims[0] * (best_dims[0] + 1) *
       best_dims[1] * (best_dims[1] + 1)) // 4)
print("Difference:", best_diff)
```---

 # 搜索结果

 最接近的矩形计数出现在网格中：$$36 \times 77$$与面积$$36 \cdot 77 = 2772.$$其矩形数量为：$$\frac{36\cdot37\cdot77\cdot78}{4} = 1{,}999{,}998,$$这只是$2$距离两百万。 

不存在精确的解决方案。

 # 最终验证

 - 矩形计数非常接近$2{,}000{,}000$。 
- 面积大小对于周围尺寸来说是合理的$40$-$80$。 
- 对称性检查：$36\times77$和$77\times36$给出相同的结果。
