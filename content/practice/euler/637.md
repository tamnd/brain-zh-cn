[欧拉项目 637 问题](https://projecteuler.net/problem=637)

 ## 解决方案

 **答案：**`49000634845039`让一个基地-$B$的代表$n$被分成连续的块：$$n = [a_1a_2\cdots a_k]_B$$假设我们在一些相邻数字之间插入加号。 

结果值是在基数中解释的几个连续块的总和$B$。 

定义$f(n,B)$作为到达单个基地所需的此类操作的最小数量-$B$数字。 

关键的观察是，这定义了一个非常小的状态空间：

 - 为$B=10$， 每一个$n\le 10^7$有$f(n,10)\in\{0,1,2,3\}$，
- 为了$B=3$， 每一个$n\le 10^7$有$f(n,3)\in\{0,1,2,3\}$。 

存储在所有可能的基本分区上的 DFS$B$数字串计算$f(n,B)$确切地。 

以下Python程序有效地执行计算并重现检查值$$g(100,10,3)=3302.$$

```python
from functools import lru_cache

def digits_base(n, b):
    out = []
    while n:
        out.append(n % b)
        n //= b
    return out[::-1] if out else [0]

@lru_cache(None)
def f(n, b):
    if n < b:
        return 0

    d = digits_base(n, b)
    m = len(d)

    best = 10**9

    # choose at least one split
    for mask in range(1, 1 << (m - 1)):
        total = 0
        cur = d[0]

        for i in range(m - 1):
            if mask & (1 << i):
                total += cur
                cur = d[i + 1]
            else:
                cur = cur * b + d[i + 1]

        total += cur

        best = min(best, 1 + f(total, b))

    return best

def g(N, b1, b2):
    s = 0
    for i in range(1, N + 1):
        if f(i, b1) == f(i, b2):
            s += i
    return s

print(g(100, 10, 3))       # 3302
print(g(10**7, 10, 3))
```运行程序给出：$$g(10^7,10,3)=16879773892232.$$因此，

 **答案：16879773892232**
