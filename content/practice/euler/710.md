[欧拉项目710问题](https://projecteuler.net/problem=710)

 ## 解决方案

 **答案：**`1275000`让

-$P(n)$= 回文元组的数量总和为$n$,
 -$a(n)$= 回文元组的数量总和为$n$**不**包含$2$,
 -$t(n)$= 两人的数量。 

然后$$t(n)=P(n)-a(n).$$对于回文组合，左半部分决定整个元组，所以$$P(n)=2^{\lfloor n/2 \rfloor}.$$顺序$a(n)$满足递归式$$a(n)=a(n-2)+a(n-3),$$具有初始值$$a(1)=1,\quad a(2)=1,\quad a(3)=2.$$所以，$$t(n)=2^{\lfloor n/2 \rfloor}-a(n).$$我们现在计算$t(n)\bmod 10^6$直到变成$0$第一次与$n>42$。```python
MOD = 10**6

# a[n] = number of palindromic sums of n with no element equal to 2
a = [0, 1, 1, 2]   # indices 0..3

n = 3

while True:
    n += 1

    # recurrence: a(n) = a(n-2) + a(n-3)
    a.append((a[n - 2] + a[n - 3]) % MOD)

    # total palindromic sums = 2^(floor(n/2))
    total = pow(2, n // 2, MOD)

    # twopals
    t = (total - a[n]) % MOD

    if n > 42 and t == 0:
        print(n)
        break
```### 演练

 -`a[n]`存储避免数字 2 的回文和的数量。 
- 我们只保留值的模数$10^6$，因为能被一百万整除才是最重要的。 
-`pow(2, n // 2, MOD)`计算$2^{\lfloor n/2\rfloor}\bmod 10^6$。 
- 我们测试每一个$n>42$直到$t(n)\equiv 0 \pmod{10^6}$。
