[欧拉项目问题 278](https://projecteuler.net/problem=278)

 ## 解决方案

 **答案：**`1228215747273908452`让$$a_1=pq,\qquad a_2=pr,\qquad a_3=qr$$对于不同的素数$p<q<r$。 

我们需要$$\sum_{p<q<r<5000} f(pq,pr,qr).$$关键是推导出一个封闭式$f(pq,pr,qr)$。 

---

 ## 1.数学分析

 我们正在寻找**最大不可能的非负整数组合**$$x(pq)+y(pr)+z(qr)=b, \qquad x,y,z\ge 0.$$这是一个弗罗贝尼乌斯型问题。 

### 步骤 1：观察成对 gcd 结构

 对于$$a=pq,\quad b=pr,\quad c=qr,$$我们有$$\gcd(a,b)=p,\qquad \gcd(a,c)=q,\qquad \gcd(b,c)=r,$$和$$\gcd(a,b,c)=1.$$这些三元组形成一个特殊的数值半群。 

形式三元组的经典结果$$(ab,ac,bc)$$与成对互质$a,b,c$给出弗罗贝尼乌斯数：$$f(ab,ac,bc)=2abc-ab-ac-bc.$$这里的成对互质参数正好是$p,q,r$， 所以：$$f(pq,pr,qr) = 2pqr-pq-pr-qr.$$### 步骤 2：对照示例进行验证

 #### 示例 1$$(6,10,15)=(2\cdot3,\ 2\cdot5,\ 3\cdot5)$$公式给出：$$2(2)(3)(5)-6-10-15 = 60-31 = 29.$$与问题陈述相匹配。 

#### 示例 2$$(14,22,77)=(2\cdot7,\ 2\cdot11,\ 7\cdot11)$$

$$2(2)(7)(11)-14-22-77 = 308-113 = 195.$$再次比赛。 

所以总和变成$$S = \sum_{p<q<r<5000} \left(2pqr-pq-pr-qr\right).$$---

 ## 2.Python实现```python
from sympy import primerange

# Generate all primes < 5000
primes = list(primerange(2, 5000))

# Prefix sums of primes for fast summation
prefix_sum = [0]
for p in primes:
    prefix_sum.append(prefix_sum[-1] + p)

total = 0

# O(n^2) summation over q,r
for k in range(2, len(primes)):
    r = primes[k]

    for j in range(1, k):
        q = primes[j]

        # Sum of p for p < q
        sum_p = prefix_sum[j]
        count_p = j

        # Sum over all p < q:
        # Σ (2pqr - pq - pr - qr)
        total += (
            (2 * q * r - q - r) * sum_p
            - q * r * count_p
        )

print(total)
```---

 ### 主要总结

 对于固定$q,r$,$$\sum_{p<q} (2pqr-pq-pr-qr)$$变成$$(2qr-q-r)\sum_{p<q}p - qr\cdot \#\{p<q\}.$$这降低了复杂性$O(n^3)$到$O(n^2)$。 

---

 ### 检查示例

 对于$(2,3,5)$:```python
2*2*3*5 - 6 - 10 - 15
```给出：$$60-31=29$$匹配$f(6,10,15)=29$。

 ## 4.最终验证

 - 公式与两个示例完全匹配。 
- 质数三元组的数量是$$\binom{669}{3}\approx 5\times 10^7,$$所以$O(n^3)$暴力会造成浪费； 这$O(n^2)$方法合适。 

- 结果是积极的并且具有合理的规模（大约$10^{18}$）给定三次素数乘积。
