[欧拉项目问题 42](https://projecteuler.net/problem=42)

 ## 解决方案

 **答案：**`162`关键任务是确定提供的文件中有多少单词的**单词值**等于**三角形数**。 

三角形数定义为$$t_n = \frac{n(n+1)}{2}$$前几个是：$$1,3,6,10,15,21,28,36,45,55,\dots$$例如：

-$S=19$-$K=11$-$Y=25$所以$$19+11+25 = 55$$自从$$55 = \frac{10\cdot 11}{2}$$SKY是一个三角形词。 

---

 # 步骤 1 — 数学分析

 ## 将单词转换为数字

 每个字母映射到其字母索引：$$A=1,\;B=2,\;\dots,\;Z=26$$如果一个单词有字母$c_1,c_2,\dots,c_k$，其值为$$V = \sum_{i=1}^{k} \text{value}(c_i)$$例子：$$\text{SKY}=19+11+25=55$$---

 ## 判断一个数是否是三角形

 我们需要知道是否某个整数$x$满足$$x=\frac{n(n+1)}2$$重新排列：$$n^2+n-2x=0$$使用二次公式：$n=\frac{-1+\sqrt{1+8x}}{2}$所以$x$恰好是三角形的时候$$1+8x$$是一个完全平方数，所得结果$n$是一个整数。 

---

 ## 最大可能的单词值

 单词文件包含常用英语单词； 最大字长很小。 即使一个单词有 20 个字母都等于 Z：$$20\cdot 26 = 520$$因此只需要一组适度的三角形数。 

实用的方法：

 1. 读所有单词
 2. 计算每个单词的值
 3. 预先计算所有三角形数直至最大值
 4. 计算匹配数

 这是有效的，因为在集合中查找是$O(1)$。

 # 第 2 步 — Python 实现```python
from math import sqrt

# Read the words file
with open("0042_words.txt") as f:
    content = f.read()

# The file format is:
# "WORD1","WORD2","WORD3",...
words = [w.strip('"') for w in content.split(",")]

# Function to compute word value
def word_value(word):
    return sum(ord(c) - ord('A') + 1 for c in word)

# Compute all word values
values = [word_value(w) for w in words]

# Find the largest value
max_value = max(values)

# Generate all triangle numbers up to max_value
triangle_numbers = set()

n = 1
while True:
    t = n * (n + 1) // 2
    if t > max_value:
        break
    triangle_numbers.add(t)
    n += 1

# Count triangle words
count = sum(1 for v in values if v in triangle_numbers)

print(count)
```---

 ## 计算单词值```python
def word_value(word):
    return sum(ord(c) - ord('A') + 1 for c in word)
```

`ord('A')`给出 ASCII 代码 65。 

所以：

 - A →$65-65+1=1$- B →$66-65+1=2$- …
 - Z → 26

 示例：```python

```给出$$19+11+25=55$$与问题陈述相匹配。

 ## 生成三角形数```python
t = n * (n + 1) // 2
```这实现了$$t_n = \frac{n(n+1)}2$$一旦三角形数量超过最大字值，我们就停止。 

使用`set`允许非常快速的成员资格测试。

 ## 计算三角形单词```python
count = sum(1 for v in values if v in triangle_numbers)
```对于每个单词值：

 - 否则加0
