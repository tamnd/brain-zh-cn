[项目欧拉问题 624](https://projecteuler.net/problem=624)

 ## 解决方案

 **答案：**`984524441`让$M$是第一次出现两个连续正面时的抛掷索引（因此抛掷$M-1,M$是HH）。 我们寻求$$P(n)=\Pr(n\mid M)$$为了$n=10^{18}$，然后计算$$Q(P(n),p) \quad\text{with}\quad p=1{,}000{,}000{,}009.$$---

 ## 1.数学分析

 ### 第 1 步：分配$M$拥有$M=m$，序列：

 - 必须以 HH 结尾，
 - 必须包含**不包含较早的HH**。 

长度有效的二进制字符串的数量$m$以第一个 HH 结尾的是斐波那契计数。 

让$A_m$是以抛掷结束的有效序列的数量$m$。 

如果第一个 HH 发生在抛掷时$m$，然后扔$m-1$和$m$是 H,H，第一个$m-2$抛掷必须避免连续的正面并以 T 结束。 

这给出：$$A_m = F_{m-1}$$在哪里$F_k$是斐波那契数列（$F_0=0,F_1=1$）。 

因此$$\Pr(M=m)=\frac{F_{m-1}}{2^m}.$$所以$$P(n) = \sum_{k\ge1} \frac{F_{kn-1}}{2^{kn}}.$$---

 ### 第 2 步：转换为封闭形式

 使用比奈公式：$$F_m=\frac{\phi^m-\psi^m}{\sqrt5},$$在哪里$$\phi=\frac{1+\sqrt5}{2}, \qquad \psi=\frac{1-\sqrt5}{2}.$$然后$$F_{kn-1} = \frac{\phi^{kn-1}-\psi^{kn-1}}{\sqrt5}.$$代入总和：$$P(n) = \sum_{k\ge1} \frac{1}{2^{kn}} \cdot \frac{\phi^{kn-1}-\psi^{kn-1}}{\sqrt5}.$$每个部分都是几何的，所以求和简化后：$$P(n) = \frac{ 2^nF_{n-1}-(-1)^n }{ 4^n-2^nL_n+(-1)^n },$$在哪里$L_n$是卢卡斯数：$$L_n = F_{n-1}+F_{n+1}.$$检查示例：

 对于$n=2$:$$P(2)=\frac{4\cdot1-1}{16-4\cdot3+1} =\frac35.$$为了$n=3$:$$P(3)=\frac{8\cdot1-(-1)}{64-8\cdot4-1} = \frac{9}{31}.$$两者都与陈述相符。 

---

 ### 步骤 3：模块化解释

 我们需要$$Q\!\left(P(n),p\right)$$这是独特的残基$q$满意的$$a \equiv bq \pmod p$$为了$P(n)=a/b$。 

因此$$Q(P(n),p) = a\,b^{-1}\pmod p.$$所以我们只需要分子和分母模$p$。 

为了$n=10^{18}$，计算：

 -$F_{n-1}\pmod p$,
 -$F_{n+1}\pmod p$,
 -$L_n=F_{n-1}+F_{n+1}\pmod p$,
 -$2^n\pmod p$,
 -$4^n\pmod p$,

 使用**快速翻倍斐波那契**$O(\log n)$。

 ## 2.Python实现```python
MOD = 1_000_000_009
N = 10**18

def fib(n, mod):
    """Fast doubling Fibonacci.
    Returns (F_n, F_{n+1}) modulo mod.
    """
    if n == 0:
        return (0, 1)

    a, b = fib(n >> 1, mod)

    # F(2k)
    c = (a * ((2 * b - a) % mod)) % mod

    # F(2k+1)
    d = (a * a + b * b) % mod

    if n & 1:
        return d, (c + d) % mod
    return c, d

# Fibonacci values
Fn_minus_1 = fib(N - 1, MOD)[0]
Fn, Fn_plus_1 = fib(N, MOD)

# Lucas number: L_n = F_{n-1} + F_{n+1}
Ln = (Fn_minus_1 + Fn_plus_1) % MOD

# Powers
pow2 = pow(2, N, MOD)
pow4 = pow(4, N, MOD)

# Since N = 10^18 is even, (-1)^N = 1
sign = 1

# Numerator and denominator modulo MOD
numerator = (pow2 * Fn_minus_1 - sign) % MOD
denominator = (pow4 - pow2 * Ln + sign) % MOD

# Modular division
answer = numerator * pow(denominator, MOD - 2, MOD) % MOD

print(answer)
```---

 ## 3. 代码演练

 ### 快速翻倍

 身份：$$F_{2k}=F_k(2F_{k+1}-F_k),$$

$$F_{2k+1}=F_k^2+F_{k+1}^2$$允许斐波那契计算$O(\log n)$。 

该函数返回：$$(F_n,F_{n+1})$$这样我们就可以恢复所需的一切。 

### 卢卡斯数

 我们使用：$$L_n = F_{n-1}+F_{n+1}.$$### 概率公式

 自从$N$是偶数：$$(-1)^N=1.$$因此：$$a = 2^N F_{N-1}-1,$$

$$b = 4^N - 2^N L_N + 1.$$最后：$$Q(P(N),p)=a\,b^{-1}\pmod p.$$### 小例子验证

 对于$n=2$:$$P(2)=\frac35$$和模$109$:$$5^{-1}\cdot3 \equiv 66.$$为了$n=3$:$$P(3)=\frac9{31}$$和模$109$:$$31^{-1}\cdot9 \equiv 46.$$两人都同意问题陈述。
