[项目欧拉问题 104](https://projecteuler.net/problem=104)

 ## 解决方案

 **答案：**`329468`我们寻求第一个斐波那契指数$k$这样：

 - **前 9 位数字**$F_k$是泛数字化的$1\text{-}9$,
 - 以及 **最后 9 位**$F_k$也是泛数字的$1\text{-}9$。 

9 位数字是泛数字当且仅当它包含每个数字$1,\dots,9$正好一次。 

---

 # 数学分析

 斐波那契数列满足$$F_n = F_{n-1}+F_{n-2}, \qquad F_1=F_2=1.$$计算完整斐波那契数的简单方法是不可行的，因为相关项有数十万位数字。 因此，我们分别对待**前**和**尾随**数字。 

---

 ## 1. 尾随 9 位数字

 为了跟踪最后 9 位数字，我们使用模运算。 

自从$$F_n \equiv F_{n-1}+F_{n-2}\pmod{10^9},$$我们只存储：$$F_n \bmod 10^9.$$这使得每次计算都小而快。 

在每一步中，我们都会测试最后 9 位数字是否是泛数字：```python
set(str(b).zfill(9)) == set('123456789')
```这`zfill(9)`确保保留前导零； 任何零都会自动失败泛数字测试。 

---

 ## 2. 通过对数求前导数字

 关键恒等式是比奈公式：$$F_n = \frac{\phi^n-\psi^n}{\sqrt5},$$在哪里$$\phi=\frac{1+\sqrt5}{2}, \qquad \psi=\frac{1-\sqrt5}{2}.$$因为$|\psi|<1$，对于大$n$,$$F_n \approx \frac{\phi^n}{\sqrt5}.$$取以 10 为底的对数：$$\log_{10}(F_n) \approx n\log_{10}(\phi)-\log_{10}(\sqrt5).$$将其写为$$\log_{10}(F_n)=I+f,$$在哪里：

-$I$是整数部分，
 -$f\in[0,1)$是小数部分。 

然后$$F_n = 10^{I+f}=10^I\cdot 10^f.$$因此，前 9 位数字是：$$\left\lfloor 10^{f+8}\right\rfloor.$$所以我们计算：```python
log_fk = k * log_phi - log_sqrt5
frac = log_fk - int(log_fk)
first9 = int(10**(frac + 8))
```并测试是否`first9`是泛数字化的。 

这避免了计算巨大的斐波那契数本身。 

---

 # Python 实现```python
from math import log10, sqrt

# Constants from Binet's formula
phi = (1 + sqrt(5)) / 2
log_phi = log10(phi)
log_sqrt5 = log10(sqrt(5))

# Target pandigital digit set
pan = set('123456789')

# Fibonacci values modulo 10^9
a, b = 1, 1
k = 2

while True:
    # Advance Fibonacci sequence modulo 10^9
    a, b = b, (a + b) % 10**9
    k += 1

    # Check trailing 9 digits
    if set(str(b).zfill(9)) == pan:

        # Approximate leading digits using logarithms
        log_fk = k * log_phi - log_sqrt5
        frac = log_fk - int(log_fk)

        # Extract first 9 digits
        first9 = int(10**(frac + 8))

        # Check leading 9 digits
        if set(str(first9)) == pan:
            print(k)
            break
```---

 该算法非常有效，因为：

 - 尾随数字使用模算术，
 - 前导数字使用对数，
 - 从未存储过巨大的斐波那契数。
