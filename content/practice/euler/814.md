[欧拉项目 814 问题](https://projecteuler.net/problem=814)

 ## 解决方案

 **答案：**`307159326`让$N=4n$。 

每个人都选择三个方向之一：

 -$L$: 向左看，
 -$R$: 看对了，
 -$O$: 看看截然相反的人。 

如果一个人看到的人也回头看他，他就会尖叫。 

我们必须计算恰好有一半人尖叫的配置，即恰好$2n$尖叫者。 

由于尖叫总是成对出现，尖叫者是不相交的，所以我们需要准确地$$n$$互看的一对。 

---

 # 1. 结构调整

 给人们贴上标签$0,1,\dots,4n-1$绕圈。 

结对人$i$与人$i+2n$（模$4n$）； 这些是彼此相对的。 

定义两行：

 - 顶行：$T_i=i$,
 - 底行：$B_i=i+2n$，

为了$i=0,\dots,2n-1$。 

现在每一列$i$包含相反的对$(T_i,B_i)$。 

互视配对可以通过三种方式出现：

 1.$T_i$看起来不错并且$T_{i+1}$看起来向左，
 2.$B_i$看起来不错并且$B_{i+1}$看起来向左，
 3.$T_i$和$B_i$两者都选择$O$。 

唯一的微妙之处是环绕：

 -$T_{2n-1}$毗邻于$B_0$,
 -$B_{2n-1}$毗邻于$T_0$。 

因此，其几何形状是莫比乌斯梯，而不是普通的圆柱体。 

---

 # 2. 传递矩阵公式

 对于每一列，我们记录一对选择$$(a_i,b_i)\in\{L,R,O\}^2,$$所以有$9$州。 

设一个状态为$s=(a,b)$。 

对于两个连续列$s=(a,b)$和$t=(c,d)$， 定义$$w(s,t) = [a=R\land c=L] + [b=R\land d=L] + [a=O\land b=O].$$这会计算在该步骤中创建了多少尖叫对。 

对于最终的环绕过渡，我们使用$$w_{\text{wrap}}(s,t) = [a=R\land d=L] + [b=R\land c=L] + [a=O\land b=O].$$如果尖叫对的总数是$k$，那么尖叫者的数量就是$2k$。 

我们需要$k=n$。 

因此：$$S(n) = [x^n] \sum_{\text{closed walks}} x^{\text{total screaming pairs}}.$$这成为标准 DP：

 - 位置，
 - 当前状态，
 - 累积的尖叫对数量。 

状态空间仅$9$，所需的度数仅为$n=1000$，所以计算很容易。 

---

 # 3.Python实现```python
MOD = 998244353

def solve(n):
    m = 2 * n

    dirs = "LRO"
    states = [(a, b) for a in dirs for b in dirs]
    S = len(states)   # 9 states

    # Normal transitions
    normal = [[] for _ in range(S)]

    # Wrap-around transition contribution
    wrap = [[0] * S for _ in range(S)]

    for i, s in enumerate(states):
        a, b = s

        for j, t in enumerate(states):
            c, d = t

            # Internal transitions
            deg = 0

            # Top-row mutual look
            if a == 'R' and c == 'L':
                deg += 1

            # Bottom-row mutual look
            if b == 'R' and d == 'L':
                deg += 1

            # Opposite mutual look
            if a == 'O' and b == 'O':
                deg += 1

            normal[i].append((j, deg))

            # Wrap-around transition
            wdeg = 0

            if a == 'R' and d == 'L':
                wdeg += 1

            if b == 'R' and c == 'L':
                wdeg += 1

            if a == 'O' and b == 'O':
                wdeg += 1

            wrap[i][j] = wdeg

    ans = 0

    # Fix a starting state and count closed walks
    for start in range(S):

        dp = [[0] * (n + 1) for _ in range(S)]
        dp[start][0] = 1

        # Process the first 2n-1 ordinary transitions
        for step in range(m - 1):

            ndp = [[0] * (n + 1) for _ in range(S)]

            limit = min(n, 3 * (step + 1))

            for s in range(S):
                row = dp[s]

                for t, add in normal[s]:

                    upto = limit - add + 1

                    for k in range(upto):
                        val = row[k]
                        if val:
                            ndp[t][k + add] = (
                                ndp[t][k + add] + val
                            ) % MOD

            dp = ndp

        # Close the cycle with the Möbius wrap
        for end in range(S):
            add = wrap[end][start]

            if add <= n:
                ans = (ans + dp[end][n - add]) % MOD

    return ans

print(solve(10))     # 420121075
print(solve(1000))
```---

 # 4. 代码演练

 ### 国家建设```python
states = [(a, b) for a in dirs for b in dirs]
```Each column stores the choices of the top and bottom people.

 有$3^2=9$的可能性。 

---

 ### 过渡权重```python
if a == 'R' and c == 'L':
    deg += 1
```这会在顶排形成一对尖叫的组合。 

对于底行也是如此。```python
if a == 'O' and b == 'O':
    deg += 1
```这会在纵队内形成一对尖叫的组合。 

---

 ### DP 含义```python
dp[state][k]
```= 迄今为止构建带的方法数量$k$尖叫对。 

---

 ### 环绕式

 由于图表在最后发生扭曲，因此最后一列通过交叉顶部/底部与第一列交互。 

这是由`wrap`。
