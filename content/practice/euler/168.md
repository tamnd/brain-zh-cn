[欧拉计划问题 168](https://projecteuler.net/problem=168)

 ## 解决方案

 **答案：**`59206`让$$n = 10a+b$$以十进制表示，其中$b$是最后一位数字。 

右旋$n$动作$b$到前面：$$R(n)=b\cdot 10^{k-1}+a$$在哪里$k$是的位数$n$。 

我们被告知$$R(n)=m n$$对于某些整数乘数$m$。 

我们寻求一切$n$和$$10<n<10^{100}$$满足这个属性，我们想要最后一个$5$它们的总和的位数。 

---

 # 数学分析

 假设$n$有$k$数字。 

写$$n=10a+b,$$在哪里：

-$b\in\{1,\dots,9\}$（最后一位数字不能是$0$，否则旋转会丢失一位数字），
 -$0\le a<10^{k-1}$。 

旋转后的数为$$R(n)=b\cdot 10^{k-1}+a.$$条件是$$b\cdot 10^{k-1}+a = m(10a+b).$$重新排列：$$b\cdot 10^{k-1}+a = 10ma+mb,$$所以$$b(10^{k-1}-m)=a(10m-1).$$因此$$a=\frac{b(10^{k-1}-m)}{10m-1}.$$然后$$n=10a+b$$变成$$n =10\cdot \frac{b(10^{k-1}-m)}{10m-1}+b.$$合并术语：$$n = \frac{10b(10^{k-1}-m)+b(10m-1)}{10m-1}.$$这$-10bm$和$+10bm$取消：$$n = \frac{b(10^k-1)}{10m-1}.$$所以每个解决方案都必须具有以下形式$$\boxed{ n=\frac{b(10^k-1)}{10m-1} }$$和：

-$1\le b\le 9$,
 -$1\le m\le 9$,
 - 分母除分子。 

---

 ## 关键的整除条件

 我们需要$$10m-1 \mid b(10^k-1).$$自从$$10m-1 \in \{9,19,29,39,49,59,69,79,89\},$$我们可以分析乘法阶$10$对这些数字取模。 

对于每个$m$， 定义$$d=10m-1.$$如果$$10^k\equiv 1 \pmod d,$$然后$d\mid (10^k-1)$，以及每个数字$b$作品。 

否则只有一些$b$可以弥补缺失的因素。 

因为$k<100$，我们可以暴力破解所有：

 -$k=2,\dots,99$,
 -$m=1,\dots,9$,
 -$b=1,\dots,9$,

 并测试可分性。 

总的搜索空间很小：$$98\times 9\times 9 = 7938.$$---

 # Python 实现```python
MOD = 100000

total = 0

# k = number of digits
for k in range(2, 100):

    ten_k_minus_1 = pow(10, k) - 1

    # multiplier m
    for m in range(1, 10):

        d = 10 * m - 1

        # final digit b
        for b in range(1, 10):

            numerator = b * ten_k_minus_1

            # n must be integer
            if numerator % d == 0:

                n = numerator // d

                # verify the property directly
                s = str(n)

                rotated = int(s[-1] + s[:-1])

                if rotated == m * n:
                    total = (total + n) % MOD

print(total)
```---
