[欧拉项目问题 206](https://projecteuler.net/problem=206)

 ## 解决方案

 **答案：**`1389019170`我们寻求唯一的正整数$n$这样$$n^2 = 1\_2\_3\_4\_5\_6\_7\_8\_9\_0$$其中每个下划线是任意数字。 

这意味着正方形必须具有小数模式$$1x2x3x4x5x6x7x8x9x0$$对于数字$x\in\{0,\dots,9\}$。 

---

 # 步骤 1 — 理解结构

 号码结尾为$0$， 所以：$$n^2 \equiv 0 \pmod{10}$$因此$n$必须结束于$0$。 

写$$n = 10m$$然后$$n^2 = 100m^2$$从方形图案中删除最后两个零可以得出：$$m^2 = 1\_2\_3\_4\_5\_6\_7\_8\_9$$更重要的是，由于原来的正方形以$900$,$$n^2 \equiv 900 \pmod{1000}$$因此$$n^2 \equiv 9 \pmod{10}$$所以$n/10$必须结束于$3$或者$7$， 因为：$$3^2 \equiv 9 \pmod{10},\qquad 7^2 \equiv 9 \pmod{10}$$所以：$$n \text{ ends in } 30 \text{ or } 70$$这已经极大地减少了搜索空间。 

---

 # 步骤 2 — 确定数值范围

 可能的最小正方形是$$1020304050607080900$$最大的是$$1929394959697989990$$所以：$$\sqrt{1020304050607080900} \le n \le \sqrt{1929394959697989990}$$计算大约：$$1010101010 \lesssim n \lesssim 1389026623$$自从$n$必须结束于$30$或者$70$，我们只测试那些候选人。 

---

 # 步骤 3 — 高效的模式检查

 我们可以直接检查数字，而不是重复转换为字符串。 

认为$$s = n^2$$我们需要：

 - 个位 = 0
 - 百位数 = 9
 - 万位数 = 8
 - 等

 同样，从右向左阅读：$$0,9,8,7,6,5,4,3,2,1$$每个所需数字之间有一个任意数字。 

一个方便的方法是字符串匹配：```python
str(s)[::2] == "1234567890"
```因为所需的数字占据了每隔一个的位置。 

---

 # 第 4 步 — Python 实现```python
import math

# Lower and upper bounds for the square root
low = int(math.isqrt(1020304050607080900))
high = int(math.isqrt(1929394959697989990)) + 1

# Force the search to numbers ending in 30 or 70
for n in range(low, high, 10):

    # Only numbers ending in 30 or 70 are possible
    if n % 100 not in (30, 70):
        continue

    sq = n * n

    # Check the required pattern
    if str(sq)[::2] == "1234567890":
        print(n)
        break
```---
