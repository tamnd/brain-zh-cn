[欧拉项目问题 35](https://projecteuler.net/problem=35)

 ## 解决方案

 **答案：**`55`## 1.数学分析

 **循环素数**是一个素数，使得**其数字的每次循环旋转也是素数**。 

例如：$$197 \to 971 \to 719$$三个都是素数，所以$197$是圆形的。 

我们想要计算下面所有的圆形素数**$10^6$**。 

### 关键见解 1：轮换

 如果一个数字有数字$d_1d_2\dots d_k$，那么它的旋转是通过将前导数字移动到末尾来形成的。 

例如：$$197 \to 971 \to 719$$从算法上来说：

 - 将数字转换为字符串。 
- 旋转：

 -`"197"`→`"971"`-`"971"`→`"719"`- 转换回整数。 

一个数是循环素数当且仅当**所有旋转都是素数**。 

---

 ### 关键见解 2：数字消除

 对于多于一位数字的数字：

 如果任意数字是：$$0,2,4,5,6,8$$那么一些旋转将以偶数结束或$5$，使其复合。 

例子：$$23 \to 32$$

$32$是偶数 → 非素数。 

例子：$$157 \to 571 \to 715$$

$715$结束于$5$→ 复合。 

所以，**除了个位数质数$2$和$5$**，每个循环素数必须仅使用数字：$$\{1,3,7,9\}$$这大大减少了搜索空间。 

---

 ### 关键见解 3：快速素性测试

 我们需要进行多次素数检查，因此最好的方法是**埃拉托色尼筛法**。 

我们生成一百万以下的所有素数：

 - 创建素数布尔数组。 
- 将每个质数的倍数标记为合数。 
- 素数查找变为$O(1)$。 

时间复杂度：$$O(n \log\log n)$$对于筛子，随后进行廉价的旋转检查。 

---

 ### 算法

 1. 建立一个基本筛子$10^6$。 
2. 对于每个素数：

 - 生成所有数字旋转。 
- 检查每次旋转是否为素数。 
3. 计算有效数字。 

优化：

 - 跳过包含禁止数字的号码$0,2,4,5,6,8$（除了$2,5$）。 

---

 ## 2.Python实现```python
def count_circular_primes(limit):
    # Build sieve of Eratosthenes
    sieve = [True] * limit
    sieve[0] = sieve[1] = False

    for i in range(2, int(limit ** 0.5) + 1):
        if sieve[i]:
            # Mark multiples as composite
            for j in range(i * i, limit, i):
                sieve[j] = False

    def rotations(n):
        """Generate all cyclic rotations of n."""
        s = str(n)
        return [int(s[i:] + s[:i]) for i in range(len(s))]

    circular_count = 0

    for n in range(2, limit):
        if not sieve[n]:
            continue

        # Skip impossible candidates
        if n > 10 and any(d in "024568" for d in str(n)):
            continue

        # Check all rotations
        if all(sieve[r] for r in rotations(n)):
            circular_count += 1

    return circular_count

# Compute answer
print(count_circular_primes(1_000_000))
```---
