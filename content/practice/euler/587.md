[项目欧拉问题 587](https://projecteuler.net/problem=587)

 ## 解决方案

 **答案：**`2240`让圆都有半径$1$。 

放置矩形，使其左下角位于$(0,0)$，宽度$2n$和身高$2$。 

线路从$(0,0)$到$(2n,2)$，所以它的方程是$$y=\frac{x}{n}.$$第一个圆的中心位于$(1,1)$，用方程$$(x-1)^2+(y-1)^2=1.$$“凹三角形”是以下区域所包围的区域：

 - 线$y=x/n$,
 - 四分之一圆弧，
 - 以及左/下边缘。 

关键的观察是只有第一个圆圈很重要； 所有后面的圆圈都是无关紧要的，因为该线在到达第二个圆圈之前退出第一个圆圈。 

---

 # 1. L 形截面的面积

 L 形截面是单位正方形减去四分之一圆。 

因此它的面积是$$A_L = 1-\frac{\pi}{4}.$$我们被告知，对于$n=1$，凹三角形正好是这个的一半，这是一致的。 

---

 # 2.直线与圆的交点

 我们同时解决$$y=\frac{x}{n}$$和$$(x-1)^2+(y-1)^2=1.$$代替$y=x/n$:$$(x-1)^2+\left(\frac{x}{n}-1\right)^2=1.$$扩张：$$x^2-2x+1+\frac{x^2}{n^2}-\frac{2x}{n}+1=1.$$所以$$x^2\left(1+\frac1{n^2}\right)-2x\left(1+\frac1n\right)+1=0.$$乘以$n^2$:$$(n^2+1)x^2-2n(n+1)x+n^2=0.$$相关根是$$x=\frac{n(n+1)-n\sqrt{2n}}{n^2+1}.$$一种更简洁的方法是使用线斜率进行参数化。 

设交点为$(x_0,y_0)$， 在哪里$y_0=x_0/n$。 

求解给出$$x_0=\frac{n(n+1-\sqrt{2n})}{n^2+1}, \qquad y_0=\frac{n+1-\sqrt{2n}}{n^2+1}.$$---

 # 3. 凹三角形的面积

 凹三角形由以下部分组成：

 1. 线下的三角形$0$到$x_0$,
 2.减去圆弧和弦之间的圆弧段。 

更方便的表述：$$A(n) = \int_0^{x_0} \frac{x}{n}\,dx + \int_{x_0}^{1} \left( 1-\sqrt{1-(x-1)^2} \right)\,dx.$$第一个积分是$$\frac{x_0^2}{2n}.$$对于第二个，替换$u=x-1$:$$\int_{x_0}^{1} \left(1-\sqrt{1-(x-1)^2}\right)\,dx = (1-x_0) - \int_{x_0-1}^{0}\sqrt{1-u^2}\,du.$$使用$$\int \sqrt{1-u^2}\,du = \frac12\left(u\sqrt{1-u^2}+\arcsin u\right),$$简化后，我们得到大多数解决方案中使用的紧凑公式：$$A(n) = \frac12\left( \arcsin(1-y_0) + (1-y_0)\sqrt{2y_0-y_0^2} \right) + \frac{x_0^2}{2n} - x_0.$$然而，在数值上积分形式是最简单和最安全的。 

我们追求最少$n$这样$$\frac{A(n)}{A_L}<0.001.$$---

 # 4.Python实现```python
import math

# Area of the L-section
L = 1 - math.pi / 4

def concave_area(n):
    # Intersection point between line and circle
    x = (n * (n + 1 - math.sqrt(2 * n))) / (n * n + 1)

    # Area under the line from 0 to x
    tri = x * x / (2 * n)

    # Integral of lower quarter-circle boundary
    u = x - 1

    # Integral of sqrt(1-u^2)
    F = 0.5 * (u * math.sqrt(1 - u * u) + math.asin(u))

    # Area between curve and top edge
    curved = (1 - x) + F

    return tri + curved

n = 1

while True:
    ratio = concave_area(n) / L

    if ratio < 0.001:
        print(n)
        break

    n += 1
```---

```计算$$\int_0^x \frac{t}{n}dt.$$---

 ### 弯曲部分

 四分之一圆是$$y = 1-\sqrt{1-(x-1)^2}.$$将此整合自$x$到$1$给出弯曲面积.

 我们递增$n$直到$$\frac{A(n)}{L} < 0.001.$$---
