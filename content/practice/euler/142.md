[欧拉项目问题 142](https://projecteuler.net/problem=142)

 ## 解决方案

 **答案：**`1006193`我们寻求整数$x>y>z>0$这样所有六个量$$x+y,\quad x-y,\quad x+z,\quad x-z,\quad y+z,\quad y-z$$是完美的正方形。 

让我们表示$$\begin{aligned} x+y &= a^2,\\ x-y &= b^2, \end{aligned} \qquad a>b>0.$$然后$$x=\frac{a^2+b^2}{2},\qquad y=\frac{a^2-b^2}{2}.$$同样，写$$x+z=c^2,\qquad x-z=d^2,$$以便$$x=\frac{c^2+d^2}{2},\qquad z=\frac{c^2-d^2}{2}.$$使两个表达式相等$x$,$$a^2+b^2=c^2+d^2.$$最后我们还要求$$y+z,\quad y-z$$成为正方形。 

---

 # 第 1 步：重新制定条件

 来自$$y=\frac{a^2-b^2}{2},\qquad z=\frac{c^2-d^2}{2},$$我们得到$$\begin{aligned} y+z &= \frac{a^2-b^2+c^2-d^2}{2},\\ y-z &= \frac{a^2-b^2-c^2+d^2}{2}. \end{aligned}$$使用$$a^2+b^2=c^2+d^2,$$我们简化：$$\begin{aligned} y+z &= a^2-d^2,\\ y-z &= c^2-a^2. \end{aligned}$$于是问题就变成了：

 寻找方块$a^2,b^2,c^2,d^2$这样$$a^2+b^2=c^2+d^2$$另外$$a^2-d^2,\qquad c^2-a^2$$是完美的正方形。 

---

 # 第二步：重点观察

 所有所需数量都是平方差。 

因此，我们搜索具有平方差的平方三元组。 

让$$\begin{aligned} a^2-d^2 &= e^2,\\ c^2-a^2 &= f^2. \end{aligned}$$然后$$a^2=e^2+d^2,\qquad c^2=a^2+f^2.$$This strongly suggests generating Pythagorean-type relations.

 直接暴力破解$x,y,z$这是没有希望的，但是迭代平方对已经足够快了。 

---

 # 第三步：高效的计算策略

 我们使用：$$x=\frac{a^2+b^2}{2}, \qquad y=\frac{a^2-b^2}{2}, \qquad z=\frac{c^2-d^2}{2}.$$算法：

 1. 预先计算平方。 
2. 枚举对$(a,d)$这样$a^2-d^2$是正方形的。 
3. 枚举对$(c,a)$这样$c^2-a^2$是正方形的。 
4. 检查是否$$a^2+b^2=c^2+d^2$$给出$b^2$一个完美的正方形。 

5. 构建$x,y,z$。 

6. 保持最低限度$x+y+z$。 

这运行得非常快。 

---

 # Python 实现```python
from math import isqrt

# ------------------------------------------------------------
# Helper function
# ------------------------------------------------------------

def is_square(n):
    """Return True iff n is a perfect square."""
    if n < 0:
        return False
    r = isqrt(n)
    return r * r == n

# ------------------------------------------------------------
# Search
# ------------------------------------------------------------

LIMIT = 2000

# Precompute squares
sq = [i * i for i in range(LIMIT + 1)]

best = None

# We use:
#
# x + y = a^2
# x - y = b^2
# x + z = c^2
# x - z = d^2
#
# Then:
#
# x = (a^2 + b^2)/2
# y = (a^2 - b^2)/2
# z = (c^2 - d^2)/2
#
# Additional conditions:
#
# y + z = a^2 - d^2 must be square
# y - z = c^2 - a^2 must be square
#

for a in range(1, LIMIT + 1):

    a2 = sq[a]

    for c in range(a + 1, LIMIT + 1):

        c2 = sq[c]

        # y - z must be square
        if not is_square(c2 - a2):
            continue

        for d in range(1, a):

            d2 = sq[d]

            # y + z must be square
            if not is_square(a2 - d2):
                continue

            # From:
            # a^2 + b^2 = c^2 + d^2
            b2 = c2 + d2 - a2

            if not is_square(b2):
                continue

            b = isqrt(b2)

            # Construct x,y,z
            x = (a2 + b2) // 2
            y = (a2 - b2) // 2
            z = (c2 - d2) // 2

            if not (x > y > z > 0):
                continue

            s = x + y + z

            if best is None or s < best:
                best = s
                print("Found:", x, y, z, "sum =", s)

print("Answer =", best)
```---
