[项目欧拉问题 596](https://projecteuler.net/problem=596)

 ## 解决方案

 **答案：**`734582049`让$$T(r)=\#\{(x,y,z,t)\in \mathbb Z^4:\ x^2+y^2+z^2+t^2\le r^2\}.$$关键的观察结果是，这是表示形式的累积计数，作为四个平方和。 如果$r_4(n)$表示满足以下条件的整数四元组的数量$$x^2+y^2+z^2+t^2=n,$$然后$$T(r)=\sum_{n=0}^{r^2} r_4(n).$$根据经典的雅可比四平方定理，$$r_4(n)=8\sum_{\substack{d\mid n\\4\nmid d}} d$$可以重写为$$r_4(n)=8\sigma(n)-32\sigma(n/4),$$在哪里$\sigma(n)$是除数和，$\sigma(n/4)=0$除非$4\mid n$。 

因此，对于$N=r^2$,$$T(r) = 1 + 8\sum_{n\le N}\sigma(n) - 32\sum_{n\le N/4}\sigma(n).$$定义求和除数函数$$S(N)=\sum_{n\le N}\sigma(n) = \sum_{d\le N} d\left\lfloor \frac{N}{d}\right\rfloor.$$使用除数分组（事实是$\lfloor N/d\rfloor$是恒定的间隔），这可以粗略地计算$O(\sqrt N)$时间：```python
MOD = 1_000_000_007

def summatory_sigma_mod(N):
    res = 0
    i = 1
    while i <= N:
        q = N // i
        j = N // q

        # sum of integers from i to j
        segment_sum = (i + j) * (j - i + 1) // 2

        res = (res + (q % MOD) * (segment_sum % MOD)) % MOD
        i = j + 1

    return res

def T_mod(r):
    N = r * r
    s1 = summatory_sigma_mod(N)
    s2 = summatory_sigma_mod(N // 4)

    return (1 + 8 * s1 - 32 * s2) % MOD

# Verification
print(T_mod(2))      # 89
print(T_mod(5))      # 3121
print(T_mod(100))    # 493490641
print(T_mod(10**4))  # 49348022079085897 mod MOD
print(T_mod(10**8))
```推导准确地再现了给定的检查：

 -$T(2)=89$-$T(5)=3121$-$T(100)=493490641$-$T(10^4)=49348022079085897$匹配问题陈述。 

因此，

 **答案：734582049**
