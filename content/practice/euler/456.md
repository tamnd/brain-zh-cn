[欧拉项目问题 456](https://projecteuler.net/problem=456)

 ## 解决方案

 **答案：**`333333208685971546`设点为$$P_n=\{(x_k,y_k)\}_{k=1}^n,$$在哪里$$x_k=(1248^k \bmod 32323)-16161,\qquad y_k=(8421^k \bmod 30103)-15051.$$我们必须计算这些点所形成的三角形的数量，这些点严格地将原点包含在其内部。 

---

 # 1.数学分析

 经典的几何事实是关键：

 > 由三点组成的三角形$A,B,C$包含原点当且仅当这三个点**并非全部包含在以原点为中心的任何开放半圆**中。 

因此，我们不是直接计算“好”三角形，而是计算适合某个半圆的“坏”三元组。 

---

 ## 步骤一：按极角排序

 对于每个点$$p_i=(x_i,y_i),$$计算它的极角$$\theta_i=\operatorname{atan2}(y_i,x_i).$$按围绕原点的角度对所有点进行排序。 

现在想象一下按角度顺序绕圈行走。 

---

 ## 步骤 2：数出半圆内的三元组

 固定一个点$p_i$。 

让$m_i$是其角度差从后面的点的数量$p_i$严格小于$\pi$。 

然后其中的每一对$m_i$点一起形成一个坏三角形$p_i$，因为所有三个顶点都位于一个开放的半圆内。 

因此坏三角形的数量由$p_i$是$$\binom{m_i}{2}.$$总结一切$i$,$$\text{Bad}=\sum_i \binom{m_i}{2}.$$最后，$$C(n)=\binom{n}{3}-\text{Bad}.$$---

 ## 第三步：两指针扫过

 因为点是按角度循环排序的，所以我们可以计算所有$m_i$使用旋转指针在线性时间内。 

对于每个$i$, 前进指针$j$而角度差是$<\pi$。 

我们不使用浮点角度减法，而是使用叉积：

 对于向量$a=(a_x,a_y)$和$b=(b_x,b_y)$,$$a\times b = a_xb_y-a_yb_x.$$然后：

-$a\times b>0$表示 CCW 角度$a$到$b$是在$(0,\pi)$,
 -$a\times b=0$和$a\cdot b>0$表示同一方向，
 - 相反方向（$\pi$) 被排除在外。 

这避免了精度问题。 

总复杂度为：

 - 生成点：$O(n)$,
 - 排序：$O(n\log n)$,
 - 扫：$O(n)$。 

这足够快了$n=2{,}000{,}000$。 

---

 # 2.Python实现```python
import math

def count_triangles(n):
    # Generate points
    x = 1
    y = 1
    pts = []

    for _ in range(n):
        x = (x * 1248) % 32323
        y = (y * 8421) % 30103
        pts.append((x - 16161, y - 15051))

    # Sort by polar angle
    pts.sort(key=lambda p: math.atan2(p[1], p[0]))

    # Duplicate list for circular sweep
    ext = pts + pts

    bad = 0
    j = 1

    for i in range(n):
        if j < i + 1:
            j = i + 1

        ax, ay = ext[i]

        # Advance while angular difference < pi
        while j < i + n:
            bx, by = ext[j]

            cross = ax * by - ay * bx
            dot   = ax * bx + ay * by

            # angle in [0, pi)
            if cross > 0 or (cross == 0 and dot > 0):
                j += 1
            else:
                break

        m = j - i - 1
        bad += m * (m - 1) // 2

    total = math.comb(n, 3)

    return total - bad

# Verification
print(count_triangles(8))      # 20
print(count_triangles(600))    # 8950634
print(count_triangles(40000))  # 2666610948988

# Final answer
print(count_triangles(2000000))
```---

 # 3. 代码演练

 ### 点生成```python
x = (x * 1248) % 32323
y = (y * 8421) % 30103
```这将生成完全按照定义的递归模块序列。 

然后我们按常数移动：```python
(x - 16161, y - 15051)
```以获得实际坐标。 

---

 ### 角度排序```python
pts.sort(key=lambda p: math.atan2(p[1], p[0]))
```将所有向量按逆时针顺序放置在原点周围。 

---

 ### 循环复制```python
ext = pts + pts
```允许两指针扫描自然环绕圆圈。 

---

 ### 半圆测试

 对于向量$a,b$,```python
cross = ax * by - ay * bx
dot   = ax * bx + ay * by
```条件```python
cross > 0 or (cross == 0 and dot > 0)
```表示角度从$a$到$b$严格小于$\pi$。 

---

 ### 计算坏三角形

 如果有$m$指向前方半圆内，则```python
m * (m - 1) // 2
```计算其中的所有对。
