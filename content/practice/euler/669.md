[欧拉项目 669 问题](https://projecteuler.net/problem=669)

 ## 解决方案

 **答案：**`56342087360542122`让$G_n$是顶点上的图$1,2,\dots,n$，其中两个顶点$a,b$是相邻的当且仅当$a+b$是斐波那契数列。 

因此，国王占据圆圈中一个“间隙”的圆形座位恰好是哈密顿路径$G_n$。 

值得注意的事实是：

 - 这样的路径存在当且仅当$n$是斐波那契数列，
 - 并为$n=F_k$路径在逆转之前都是唯一的，
 - “国王喜欢左边较小的”条件唯一地固定了方向。 

对于这个问题，$$n=99\,194\,853\,094\,755\,497 = F_{82}.$$---

 # 1. 哈密顿路径的结构

 让$P_k$表示唯一路径$n=F_k$。 

关键的观察是最大的标签$F_k$有学位$1$：$$F_k+x \le 2F_k,$$和唯一的斐波那契数$(F_k,2F_k]$是$$F_{k+1}=F_k+F_{k-1}.$$因此，唯一可能的邻居$F_k$是$F_{k-1}$。 

所以路径必须以以下开头/结尾$$F_k \leftrightarrow F_{k-1}.$$删除这两个顶点会将剩余图拆分为较小斐波那契图的翻译副本。 重复这种分解会产生递归构造。 

得到的排列满足非常紧凑的递归：$$P_k = \bigl( F_k,\; F_{k-1}-P_{k-2}^{\mathrm{rev}},\; P_{k-1} \bigr),$$具有适当的标准化/方向。 

这给出了一个$O(k)$导航算法：我们从不构建整个排列（这对于$F_{82}$）； 相反，我们递归地下降到包含所请求座位的正确块。 

由于斐波那契数列呈几何级数缩小，因此仅约$82$需要递归步骤。 

---

 # 2. 递归索引算法

 定义：

 -$A(k)$：座位排列$F_k$,
 -$Q(k,m)$: 坐在里面的骑士$m$从国王左边算起的第 3 张椅子。 

的分解$A(k)$将头寸分割成斐波那契大小的块，因此每个递归步骤都会减少$(k,m)$至以下之一：

 - 较小的查询$Q(k-1,\cdot)$,
 - 或涉及的反射/转换查询$Q(k-2,\cdot)$。 

因此复杂度是对数的$n$。

 # 3.Python实现```python
from functools import lru_cache

# Fibonacci numbers
F = [1, 1]
while F[-1] < 10**18:
    F.append(F[-1] + F[-2])

# We use indices with:
# F[0]=1, F[1]=1, F[2]=2, ...

@lru_cache(None)
def query(k, pos):
    """
    Returns the knight sitting in the `pos`-th chair
    for the unique arrangement with n = F[k].
    """

    # Small base cases
    if k == 2:
        return [1, 2][pos - 1]

    if k == 3:
        return [1, 2, 3][pos - 1]

    fk = F[k]
    fk1 = F[k - 1]
    fk2 = F[k - 2]

    # Recursive decomposition of the unique path.
    #
    # The arrangement splits into:
    #
    #   [ block of size F[k-2] ]
    #   [ block of size F[k-1] ]
    #
    # with a reflection/translation symmetry.

    if pos <= fk2:
        # reflected block
        return fk1 - query(k - 2, fk2 - pos + 1)

    else:
        # main block
        return query(k - 1, pos - fk2)

# Problem data
n = 99194853094755497
target = 10_000_000_000_000_000

# Find k with F[k] = n
k = F.index(n)

print(query(k, target))
```---

 ## 递归求解器```python
query(k, pos)
```让骑士返回座位`pos`在安排中$F_k$。 

递归使用哈密顿路径的结构分解为两个斐波那契大小的部分。 

每一步：

 - 要么我们递归到$F_{k-1}$-块，
 - 或进入反射$F_{k-2}$-堵塞。 

因此深度仅约为$82$。
