 ## 解决方案

 **答案：**`2944730`### 1.数学分析

 我们想要计算**100类型的广义汉明数**不超过$10^9$。 

数字是广义汉明数类型$n$如果**所有质因数都是$\le n$**。 

适用类型$100$，允许的素数为：$$2,3,5,7,11,\dots,97$$也就是说，**所有素数$\le 100$**。 

我们需要计算以下形式的整数$$m = \prod_{p\le 100} p^{e_p}$$这样$$m \le 10^9, \qquad e_p \ge 0.$$---

 #### 关键见解：素数幂递归生成

 对最大整数的暴力搜索$10^9$将会毫无希望。 

相反，观察每个有效数字都有一个**唯一的质因数分解**，因此我们可以递归地构建所有可能性。 

假设素数是：$$p_1,p_2,\dots,p_k$$对于每个素数$p_i$，我们可以选择指数$$e_i = 0,1,2,\dots$$须保持在限制以下。 

在每个递归步骤：

 - 选择当前素数的幂，
 - 将其乘以当前的乘积，
 - 递归到下一个素数。 

因为素因数分解是唯一的：

 - **每个有效数字仅生成一次**，并且
 - **没有生成无效号码**。 

这本质上是指数向量的深度优先枚举。 

例如，使用类型$5$，允许的素数是：$$2,3,5$$我们生成以下形式的数字$$2^a3^b5^c \le N.$$为了$N=10^8$，计数应为 **1105**，与问题陈述相符。

 ### 2.Python实现```python
from sympy import primerange

LIMIT = 10**9

# All allowed prime factors (primes <= 100)
primes = list(primerange(1, 101))

def count_hamming(index, current):
    """
    Recursively count generalised Hamming numbers.

    index   : which prime we are currently processing
    current : current product formed so far
    """
    # If all primes processed, we found one valid number
    if index == len(primes):
        return 1

    total = 0
    p = primes[index]

    # Try all powers of p that keep us <= LIMIT
    value = current
    while value <= LIMIT:
        total += count_hamming(index + 1, value)
        value *= p

    return total

answer = count_hamming(0, 1)
print(answer)
```---
