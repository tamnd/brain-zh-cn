[欧拉项目问题 234](https://projecteuler.net/problem=234)

 ## 解决方案

 **答案：**`1259187438574927161`让$p<q$是连续的素数。 

对于每个整数$n$和$$p^2 < n < q^2,$$我们有$$\operatorname{lps}(n)=p,\qquad \operatorname{ups}(n)=q,$$因为之间不存在严格的素数$p$和$q$。 

所以在区间内$(p^2,q^2)$，当满足以下条件时，一个数是半整除的：

 - 它可以被整除$p$异或可除以$q$,
 - 即可以被其中之一整除。 

这立即将问题转化为连续素数对的求和。 

---

 # 1.数学分析

 对于连续素数$p<q$， 定义$$I_{p,q}=\{n : p^2<n<q^2\}.$$在这个区间内：

 - 可以整除的半数$p$:$$p\cdot k,\qquad k=p+1,\dots,\left\lfloor\frac{q^2-1}{p}\right\rfloor$$- 可以整除的半数$q$:$$q\cdot k,\qquad k=\left\lfloor\frac{p^2}{q}\right\rfloor+1,\dots,q-1$$但能被两者整除的数$p$和$q$是的倍数$pq$，并且这些是**不可**半整除的，因为两个素数平方根都可以整除它们。 

因此，对于每个素数对，我们使用包含-排除：$$S(p,q) = \sum_{\substack{p^2<n<q^2\\ p\mid n}} n + \sum_{\substack{p^2<n<q^2\\ q\mid n}} n - 2\sum_{\substack{p^2<n<q^2\\ pq\mid n}} n.$$因素$2$删除重复计算的倍数$pq$完全。 

---

 ## 有效求和倍数

 的倍数之和$m$在一个区间内$[A,B]$是：$$m\sum_{k=\lceil A/m\rceil}^{\lfloor B/m\rfloor} k.$$使用算术级数公式，$$\sum_{k=L}^{R} k = \frac{(L+R)(R-L+1)}{2}.$$所以：$$\operatorname{sumMultiples}(m,A,B) = m\cdot \frac{(L+R)(R-L+1)}{2},$$在哪里$$L=\left\lceil\frac{A}{m}\right\rceil,\qquad R=\left\lfloor\frac{B}{m}\right\rfloor.$$---

 # 2.Python实现```python
from math import isqrt

LIMIT = 999966663333

# ------------------------------------------------------------
# Generate all primes up to sqrt(LIMIT)
# ------------------------------------------------------------

max_prime = isqrt(LIMIT) + 1000

sieve = bytearray(b'\x01') * (max_prime + 1)
sieve[0] = sieve[1] = 0

for i in range(2, isqrt(max_prime) + 1):
    if sieve[i]:
        sieve[i * i : max_prime + 1 : i] = (
            b'\x00' * (((max_prime - i * i) // i) + 1)
        )

primes = [i for i, v in enumerate(sieve) if v]

# ------------------------------------------------------------
# Sum of multiples of m inside [A, B]
# ------------------------------------------------------------

def sum_multiples(m, A, B):
    L = (A + m - 1) // m
    R = B // m

    if L > R:
        return 0

    count = R - L + 1
    return m * (L + R) * count // 2

# ------------------------------------------------------------
# Main computation
# ------------------------------------------------------------

total = 0

for p, q in zip(primes, primes[1:]):

    # numbers with lps = p and ups = q
    A = p * p + 1
    B = min(q * q - 1, LIMIT)

    if A > B:
        break

    total += (
        sum_multiples(p, A, B)
        + sum_multiples(q, A, B)
        - 2 * sum_multiples(p * q, A, B)
    )

print(total)
```---
