[欧拉项目问题 32](https://projecteuler.net/problem=32)

 ## 解决方案

 **答案：**`45228`我们寻求所有身份$$a \times b = c$$这样当小数位$a$,$b$， 和$c$连接起来，我们得到一个$1$-通过-$9$泛数字：每一位数字$1,2,\dots,9$恰好出现一次。 

我们必须将所有不同的产品相加$c$。 

---

 # 数学分析

 让：

 - 被乘数$= a$- 乘数$= b$- 产品$= c$的串联$a,b,c$总共使用了 9 位数字。 

## 步骤 1 — 确定可能的数字长度

 假设：

 -$a$有$m$数字
 -$b$有$n$数字
 -$c$有$p$数字

 然后：$$m+n+p=9$$此外，乘法大致满足：$$p \approx m+n \quad \text{or} \quad m+n-1$$因为乘以$m$- 数字$n$-digit 数字产生一个$(m+n)$-数字或$(m+n-1)$- 数字。 

代入数字条件：$$m+n+p=9$$如果$p=m+n$， 然后：$$2(m+n)=9$$不可能的。 

因此必然：$$p=m+n-1$$所以：$$m+n+(m+n-1)=9$$

$$2(m+n)=10$$

$$m+n=5$$因此：$$p=4$$所以乘积必须是4位数字，被乘数一起使用5位数字。 

可能的分裂：

 -$1$-数字×$4$-数字$=4$-数字
 -$2$-数字×$3$-数字$=4$-数字

 其他情况都不起作用。 

---

 # 步骤 2 — 暴力搜索策略

 我们可以直接测试所有的可能性。 

对于每个候选对$(a,b)$:

 1. 计算：$$c=a\times b$$2. 形成字符串：$$s = \text{str}(a)+\text{str}(b)+\text{str}(c)$$3. 检查：

 - 长度为 9
 - 数字准确无误$1,\dots,9$- 没有出现零
 - 没有重复的数字

 为了避免多次计算重复产品，请将有效产品存储在一个集合中。 

最后计算：$$\sum \text{(distinct products)}$$---

 # Python 实现```python
def is_pandigital(a, b, c):
    """
    Return True if concatenating a, b, c produces
    a 1-through-9 pandigital number.
    """
    s = str(a) + str(b) + str(c)

    # Must use exactly 9 digits
    if len(s) != 9:
        return False

    # Digits must be exactly 1..9
    return set(s) == set("123456789")

products = set()

# Case 1:
# 1-digit × 4-digit = 4-digit
for a in range(1, 10):
    for b in range(1000, 10000):
        c = a * b

        if is_pandigital(a, b, c):
            products.add(c)

# Case 2:
# 2-digit × 3-digit = 4-digit
for a in range(10, 100):
    for b in range(100, 1000):
        c = a * b

        if is_pandigital(a, b, c):
            products.add(c)

# Sum all distinct products
answer = sum(products)

print(answer)
```---
