[项目欧拉问题 321](https://projecteuler.net/problem=321)

 ## 解决方案

 **答案：**`2470433131948040`让$M(n)$是交换红色和蓝色计数器所需的最少移动次数。 

## 1.数学分析

 这是经典的“交换计数器”（或青蛙和蟾蜍）谜题。 

为了$n$每边都有计数器，最小移动次数为：$$M(n)=n(n+2)$$我们可以通过例子来验证这一点：$$M(3)=3(3+2)=15$$与问题陈述相匹配。 

我们寻求那些$n$这样$M(n)$是一个三角形数。 

三角形数的形式为$$T_k=\frac{k(k+1)}{2}$$所以我们要求$$n(n+2)=\frac{k(k+1)}{2}$$乘以 2：$$2n(n+2)=k(k+1)$$扩张：$$2n^2+4n=k^2+k$$### 转换为佩尔方程

 让$$x=2k+1,\qquad y=n+1$$然后$$x^2=(2k+1)^2=4k^2+4k+1$$和$$8y^2=8(n+1)^2=8n^2+16n+8$$减去：$$x^2-8y^2 = (4k^2+4k+1)-(8n^2+16n+8)$$使用$$k^2+k=2n^2+4n$$我们得到$$x^2-8y^2=-7$$因此我们需要正整数解$$x^2-8y^2=-7$$和$$n=y-1.$$第一个相关解决方案是：$$(5,2)\Rightarrow n=1$$

$$(11,4)\Rightarrow n=3$$所有进一步的解都是通过乘以基本佩尔单位生成的$$3+\sqrt 8.$$如果$$x+y\sqrt8$$是一个解决方案，下一个是$$(3+\sqrt8)(x+y\sqrt8)$$给出了递归式：$$x' = 3x+8y$$

$$y' = x+3y$$使用两个起始分支$(5,2)$和$(11,4)$，对结果进行合并和排序$n=y-1$价值观。 

序列开始：$$1,\ 3,\ 10,\ 22,\ 63,\dots$$匹配问题陈述。

 ## 2.Python实现```python
def generate_branch(x, y, count):
    """Generate n-values from one Pell branch."""
    values = []

    for _ in range(count):
        values.append(y - 1)  # n = y - 1

        # Pell recurrence
        x, y = 3 * x + 8 * y, x + 3 * y

    return values

# Generate sufficiently many terms from both branches
branch1 = generate_branch(5, 2, 50)
branch2 = generate_branch(11, 4, 50)

# Merge, deduplicate, and sort
sequence = sorted(set(branch1 + branch2))

# Sum first 40 terms
answer = sum(sequence[:40])

print(answer)
```---
