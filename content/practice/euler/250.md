[项目欧拉问题 250](https://projecteuler.net/problem=250)

 ## 解决方案

 **答案：**`1425480602091519`让$$a_n = n^n \pmod{250}$$为了$n=1,2,\dots,250250$。 

我们想要**非空子集**的数量$$\{1^1,2^2,3^3,\dots,250250^{250250}\}$$其总和可除以$250$。 等价地，我们寻求总和等于的子集的数量$0 \pmod{250}$。 

因为只能整除$250$重要的是，每个数字都可以模数减少$250$。 

---

 ## 1.数学分析

 这是一个模数子集和计数问题$250$。 

定义：$$r_n = n^n \bmod 250.$$我们需要计算子集，以便$$\sum r_n \equiv 0 \pmod{250}.$$暴力搜索结束$2^{250250}$子集是不可能的，所以我们使用**对余数模 250** 进行动态规划。 

###动态规划思想

 让$$dp[k]$$是其总和全等的子集的数量$k \pmod{250}$。 

最初，在选择任何元素之前：$$dp[0]=1$$（空子集），所有其他条目都是$0$。 

现在处理每个残留物$r_n$。 

对于每个现有的残留物$s$：

- **排除**$r_n$：保持残留状态$s$，
- **包括**$r_n$：移至残渣$$(s+r_n)\bmod 250.$$因此：$$dp_{\text{new}}[(s+r_n)\bmod 250] \;+=\; dp[s].$$毕竟$250250$处理条款：

 -$dp[0]$计算总和可被整除的所有子集$250$,
 - 包括空子集。 

所以最终的答案是$$dp[0]-1.$$---

 ### 为什么这是可行的

 我们只跟踪 **250 个状态**，而不是所有子集总和。 

复杂性：

 -$250250$数字，
 -$250$残留物。 

总工作量：$$250250 \times 250 \approx 6.25\times 10^7$$操作简单，实用。 

由于只需要**最右边的 16 位**，我们计算模$$10^{16}$$自始至终。

 ## 2.Python实现```python
MOD = 10**16
M = 250

# dp[r] = number of subsets with sum ≡ r (mod 250)
dp = [0] * M
dp[0] = 1  # empty subset

# Process n^n for n = 1..250250
for n in range(1, 250251):
    residue = pow(n, n, M)

    # Copy current DP state
    new_dp = dp[:]

    # Include current element in existing subsets
    for r in range(M):
        new_dp[(r + residue) % M] = (
            new_dp[(r + residue) % M] + dp[r]
        ) % MOD

    dp = new_dp

# Exclude the empty subset
answer = (dp[0] - 1) % MOD

print(answer)
```---

 ## 3. 代码演练

 ### 初始化```python
dp = [0] * 250
dp[0] = 1
```在处理任何事情之前，只有一个子集：

 - 空子集，
 - 总和$=0$。 

---

 ### 高效计算残数```python
residue = pow(n, n, 250)
```Python 的 3 参数`pow`有效计算模幂：$$n^n \bmod 250$$无需构造巨大的整数。 

---

 ### DP 转换```python
new_dp = dp[:]
```我们首先复制旧计数（不包括当前数字）。 

然后：```python
for r in range(250):
    new_dp[(r + residue) % 250] += dp[r]
```这将添加由**包括**新元素形成的所有子集。 

我们减少模数$10^{16}$每一步都保持较小的数字。 

---

 ### 最终调整```python
answer = (dp[0] - 1) % MOD
```减去 1，因为空子集被计算在内，但问题要求**非空子集**。

 ## 4.最终验证

 健全性检查：

- 空子集已正确删除。 
- 模幂确保正确性$n^n$。
