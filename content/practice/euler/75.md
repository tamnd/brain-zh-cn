[欧拉计划问题 75](https://projecteuler.net/problem=75)

 ## 解决方案

 **答案：**`161667`这个问题的关键是所有整数直角三角形的结构。 

毕达哥拉斯三元组$(a,b,c)$满足$$a^2+b^2=c^2$$它的周长是$$L=a+b+c.$$我们需要数一下有多少个$L \le 1{,}500{,}000$对应于**恰好一个**整数直角三角形。 

---

 # 数学分析

 每个原始毕达哥拉斯三元组都可以通过欧几里得公式唯一生成：$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$在哪里

-$m>n>0$,
 -$\gcd(m,n)=1$,
 - 其中之一$m,n$一个是偶数，另一个是奇数。 

那么周长是$$L=a+b+c.$$代替：$$L=(m^2-n^2)+(2mn)+(m^2+n^2)$$这简化为$$L=2m(m+n).$$每个非原始三元组只是一个倍数：$$(k a,\; k b,\; k c)$$有周边$$kL.$$所以策略是：

 1. 生成每个原始周长$$p=2m(m+n)\le1{,}500{,}000.$$2. 对于每一个倍数$kp$，增加一个计数器。 
3. 计算有多少个周边被恰好击中一次。 

---

 ## 界限$m$自从$$2m(m+n)\le N$$和$n\ge1$,$$2m(m+1)\le N.$$因此大约$$m \lesssim \sqrt{N/2}.$$为了$N=1{,}500{,}000$,$$m \lesssim 866.$$所以暴力破解有效$(m,n)$配对是非常可行的。 

---

 # Python 实现```python
from math import gcd

LIMIT = 1_500_000

# counts[L] = number of different right triangles with perimeter L
counts = [0] * (LIMIT + 1)

m = 2

# Generate primitive triples using Euclid's formula
while 2 * m * (m + 1) <= LIMIT:

    for n in range(1, m):

        # Primitive triple conditions:
        # 1. m and n coprime
        # 2. opposite parity
        if ((m - n) % 2 == 1) and gcd(m, n) == 1:

            primitive_perimeter = 2 * m * (m + n)

            # Add all multiples of this primitive perimeter
            for p in range(primitive_perimeter, LIMIT + 1, primitive_perimeter):
                counts[p] += 1

    m += 1

# Count perimeters with exactly one representation
answer = sum(1 for x in counts if x == 1)

print(answer)
```---

 搜索空间足够小，算法运行速度很快。

- 每个整数直角三角形都是从唯一的原始源加上缩放因子生成一次。
