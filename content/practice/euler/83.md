[项目欧拉问题 83](https://projecteuler.net/problem=83)

 ## 解决方案

 **答案：**`425185`将矩阵视为加权图：

 - 每个单元格都是一个顶点。 
- 在每个单元格中，您可以**向上、向下、向左或向右移动**。 
- 输入一个单元格将该单元格的值添加到总路径成本中。 

我们想要从左上角到右下角的最小成本路径。 

因为所有权重都是正数，所以这是**Dijkstra最短路径算法**的经典应用。 

---

 # 数学分析

 令矩阵为$A$尺寸的$n \times n$。 

定义：$$d(i,j)$$是到达单元格所需的最小路径总和$(i,j)$。 

与问题 81 不同的是，我们被允许向**四个方向**移动，因此不存在简单的动态规划递归，例如$$d(i,j)=A_{i,j}+\min(d(i-1,j),d(i,j-1)).$$为什么？ 因为允许向上和向左移动会产生循环。 

因此，我们将矩阵建模为图表。 

---

 ## 图表制定

 每个细胞$(i,j)$是一个节点。 

正交相邻单元之间存在边：$$(i,j)\leftrightarrow(i+1,j),\quad (i,j)\leftrightarrow(i-1,j),\quad (i,j)\leftrightarrow(i,j+1),\quad (i,j)\leftrightarrow(i,j-1)$$当这些坐标位于矩阵内部时。 

移动到相邻小区的成本等于该相邻小区的价值。 

如果起始单元格是$(0,0)$，那么初始距离为$$d(0,0)=A_{0,0}.$$所有边权重均为正，因此Dijkstra算法保证了最优的最短路径。 

---

 # Dijkstra 算法

 维护：

 - 按当前最佳距离排序的优先级队列，
 - 初始化为无穷大的距离表。 

每一步：

 1. 提取暂定距离最小的节点。 
2. 放松所有邻居：$$\text{newdist} = d(u) + A(v)$$3. 如果新距离较小，则更新并推入堆。 

当目标节点从堆中删除时，我们就得到了最优答案。 

复杂度是$$O(V\log V + E\log V).$$对于一个$80\times80$矩阵：$$V = 6400,\qquad E \approx 4V,$$这是非常容易管理的。

 # Python 实现```python
import heapq

# Read matrix from file
with open("0083_matrix.txt") as f:
    matrix = [list(map(int, line.strip().split(",")))
              for line in f]

n = len(matrix)

# Distance table
INF = float('inf')
dist = [[INF] * n for _ in range(n)]

# Starting point
dist[0][0] = matrix[0][0]

# Priority queue: (distance, row, col)
pq = [(matrix[0][0], 0, 0)]

# Possible movements
dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

while pq:
    d, r, c = heapq.heappop(pq)

    # Ignore outdated entries
    if d != dist[r][c]:
        continue

    # Reached destination
    if (r, c) == (n - 1, n - 1):
        print(d)
        break

    # Relax neighbors
    for dr, dc in dirs:
        nr, nc = r + dr, c + dc

        if 0 <= nr < n and 0 <= nc < n:
            nd = d + matrix[nr][nc]

            if nd < dist[nr][nc]:
                dist[nr][nc] = nd
                heapq.heappush(pq, (nd, nr, nc))
```---

 ## 读取矩阵```python
matrix = [list(map(int, line.strip().split(",")))

```文件中的每一行都包含以逗号分隔的整数。 

---

 ## 距离初始化```python
dist = [[INF] * n for _ in range(n)]
dist[0][0] = matrix[0][0]
```最初，除了起始节点之外，每个节点都是不可访问的。 

---

 ## 优先队列```python
pq = [(matrix[0][0], 0, 0)]
```堆存储：$$(\text{current distance}, \text{row}, \text{column})$$所以首先处理距离最小的节点。 

---

 ## 主 Dijkstra 循环```python
d, r, c = heapq.heappop(pq)
```取暂定距离最小的节点。 

---

 ## 忽略过时的堆条目```python
if d != dist[r][c]:
    continue
```可能已经发现了更好的道路。 

---

 ## 邻居放松```python
nd = d + matrix[nr][nc]
```搬入邻居会增加该邻居的单元格值。 

如果这条路径改善了已知的最佳距离：```python
if nd < dist[nr][nc]:
    dist[nr][nc] = nd
```更新并推入堆中。
