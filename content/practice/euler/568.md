[欧拉项目问题 568](https://projecteuler.net/problem=568)

 ## 解决方案

 **答案：**`4228020`让$$D(n)=J_B(n)-J_A(n).$$我们将证明问题可以归结为非常简单的恒等式$$\boxed{D(n)=\frac{H_n}{2^n}}$$在哪里$$H_n=\sum_{k=1}^n \frac1k$$是$n$次谐波数。 

那么我们只需要前导数字$$\frac{H_{123456789}}{2^{123456789}}.$$---

 # 1.数学分析

 ## 游戏A

 一回合：

 - 一个数字$k\in\{1,\dots,n\}$是统一选择的，
 - 杰瑞获胜$\frac1k$当且仅当$k$灯泡亮了。 

对于固定$k$,$$\Pr(\text{exactly }k\text{ bulbs on}) =\frac{\binom nk}{2^n}.$$因此，该回合的预期收益为$$\frac1k\cdot \frac{\binom nk}{2^n}.$$由于每个$k$以概率选择$1/n$，每回合的预期收益为$$\frac1n\sum_{k=1}^n \frac1k\frac{\binom nk}{2^n}.$$游戏有$n$转，所以$$J_A(n) = n\cdot \frac1n \sum_{k=1}^n \frac{\binom nk}{k2^n} = \sum_{k=1}^n \frac{\binom nk}{k2^n}.$$因此$$\boxed{ J_A(n)=\frac1{2^n}\sum_{k=1}^n \frac{\binom nk}{k} }.$$---

 ## 游戏B

 修复$k$。 

汤姆重复生成随机模式，直到恰好$k$灯泡亮了。 

条件是“恰好$k$灯泡打开”，每个$k$- 子集的可能性相同。 有$\binom nk$这样的子集。 

杰瑞独立地做了同样的事情。 

因此，杰瑞获得与汤姆完全相同的子集的概率为$$\frac1{\binom nk}.$$回报是$\frac1k$，所以对于固定的$k$预期收益是$$\frac1k\cdot \frac1{\binom nk}.$$对统一选择的进行平均$k$，并乘以$n$轮流：$$J_B(n) = \sum_{k=1}^n \frac1{k\binom nk}.$$所以$$\boxed{ J_B(n)=\sum_{k=1}^n \frac1{k\binom nk} }.$$---

 # 2. 简化$D(n)$我们需要$$D(n) = \sum_{k=1}^n \left( \frac1{k\binom nk} - \frac{\binom nk}{k2^n} \right).$$关键身份是$$\boxed{ \frac1{k\binom nk} = \frac1n\cdot \frac1{\binom{n-1}{k-1}} }$$因为$$\binom nk = \frac nk\binom{n-1}{k-1}.$$所以$$J_B(n) = \frac1n \sum_{k=1}^n \frac1{\binom{n-1}{k-1}} = \frac1n \sum_{j=0}^{n-1} \frac1{\binom{n-1}{j}}.$$现在我们使用经典恒等式$$\boxed{ \sum_{k=1}^n \frac{\binom nk}{k} = \sum_{m=1}^n \frac{2^m-1}{m} }$$（接下来通过整合$(1+x)^n-1$除以$x$）。 

因此$$J_A(n) = \frac1{2^n} \sum_{m=1}^n \frac{2^m-1}{m}.$$美丽的取消发生了：$$\boxed{ D(n)=\frac{H_n}{2^n} }$$在哪里$$H_n=\sum_{m=1}^n \frac1m.$$检查$n=6$:$$H_6=1+\frac12+\frac13+\frac14+\frac15+\frac16 =\frac{49}{20}.$$因此$$D(6)=\frac{49}{20\cdot 64} =\frac{49}{1280} =0.03828125,$$完全如所述。 

---

 # 3. 渐近$n=123456789$我们需要第一个$7$的有效数字$$D(n)=\frac{H_n}{2^n}.$$对于大型$n$,$$H_n = \log n+\gamma+\frac1{2n}-\frac1{12n^2}+O(n^{-4}),$$在哪里$\gamma$是欧拉常数。 

为了$n=123456789$,$$H_n \approx 19.210680695\dots$$我们计算$$\log_{10} D(n) = \log_{10}(H_n)-n\log_{10}2.$$使用高精度算术：$$\log_{10} D(n) = -37164195.3738629342333\dots$$小数部分是$$0.6261370657666\dots$$所以$$D(n) = 10^{-37164195}\times 10^{0.6261370657\dots} = 10^{-37164195}\times 4.228020318\dots$$所以前七位有效数字是$$4228020.$$---

 # 4.Python实现```python
from mpmath import mp

# required precision
mp.dps = 80

n = 123456789

# harmonic number asymptotic
gamma = mp.euler
H = mp.log(n) + gamma + 1/(2*n) - 1/(12*n**2)

# log10(D(n)) where D(n) = H_n / 2^n
x = mp.log10(H) - n * mp.log10(2)

# fractional part determines leading digits
frac = x - mp.floor(x)

# mantissa
mantissa = 10 ** frac

# first 7 significant digits
answer = int(mp.floor(mantissa * 10**6))

print(answer)
```---

 # 5. 代码演练

 -`mp.dps = 80`设置高精度算术。 
- 我们使用渐近展开式$$H_n \approx \log n+\gamma+\frac1{2n}-\frac1{12n^2}$$这比需要的要准确得多。 
- 自从$$D(n)=H_n2^{-n},$$我们计算$$\log_{10} D(n).$$- 对数的小数部分决定前导数字。 
- 如果$$D = m\times 10^e,\qquad 1\le m<10,$$然后$m=10^{\{\log_{10} D\}}$。 
- 乘法$m$经过$10^6$发言给出了第一个$7$有效数字。

 # 6.最终验证

 对于样本：$$D(6)=\frac{H_6}{2^6} =\frac{49/20}{64} =0.03828125,$$这与声明完全相符。 

计算出的尾数为$n=123456789$是$$4.228020318\dots$$所以前七位有效数字确实是$$4228020.$$**答案：4228020**
