[欧拉项目问题 177](https://projecteuler.net/problem=177)

 ## 解决方案

 **答案：**`129325`设八个角为

 - 在$A$:$\alpha=\angle CAB$,$\beta=\angle DAC$，
- 在$B$:$\gamma=\angle ABD$,$\delta=\angle CBD$，
- 在$C$:$\varepsilon=\angle BCA$,$\zeta=\angle DCA$，
- 在$D$:$\eta=\angle CDB$,$\theta=\angle ADB$。 

均为正整数。 

四边形由这些角度确定（直到相似），但它们不是独立的。 关键是推导几何兼容条件。 

---

 # 1. 几何和相容方程

 考虑对角线$AC$。 

呈三角形$ABC$,$$\frac{AB}{AC}=\frac{\sin \varepsilon}{\sin(\alpha+\varepsilon)}.$$呈三角形$ADC$,$$\frac{AD}{AC}=\frac{\sin \zeta}{\sin(\beta+\zeta)}.$$现在考虑对角线$BD$。 

呈三角形$ABD$,$$\frac{AB}{BD}=\frac{\sin \theta}{\sin(\alpha+\beta)}.$$呈三角形$CBD$,$$\frac{CD}{BD}=\frac{\sin \delta}{\sin(\delta+\gamma)}.$$更简洁的方法是利用四边形周围的边长比必须一致相乘的事实。 

在所有四个三角形中应用正弦规则给出了标准兼容性条件$$\frac{\sin\alpha \sin\gamma \sin\varepsilon \sin\eta} {\sin\beta \sin\delta \sin\zeta \sin\theta}=1.$$另外，每个顶点的角度满足$$\alpha+\beta+\gamma+\delta+\varepsilon+\zeta+\eta+\theta=360^\circ.$$而且，$$\alpha+\beta < 180,\quad \gamma+\delta < 180,\quad \varepsilon+\zeta < 180,\quad \eta+\theta < 180.$$一个非常有用的参数化是：$$\begin{aligned} A &= \alpha+\beta,\\ B &= \gamma+\delta,\\ C &= \varepsilon+\zeta,\\ D &= \eta+\theta, \end{aligned}$$和$$A+B+C+D=360.$$固定七个角度就决定了第八个角度。 

---

 # 2. 减少搜索

 对所有 8 元组进行强力搜索是不可能的：$$O(180^7).$$相反，我们利用几何形状。 

假设我们选择$$\alpha,\beta,\gamma,\delta,\varepsilon.$$然后：$$\zeta = C-\varepsilon,$$并根据总角度和：$$\eta+\theta = 360-(A+B+C).$$兼容性方程变成一个未知角度的单一三角方程。 该角度可以通过数值求解并测试完整性。 

欧拉计划注释说：

 > 如果在以下范围内，则将值视为整数$10^{-9}$。 

因此，我们使用浮点三角函数计算隐含角度，并检查它是否在整数的公差范围内。 

---

 # 3. 对称/相似性消除

 许多角度元组代表相同的四边形：

 - 旋转，
 - 反思，
 - 重新标记顶点。 

为了仅计算不相似的四边形，我们通过生成四边形的所有 8 个对称性并仅存储字典顺序最小的表示来规范化每个有效的解决方案。 

这是关键的组合步骤。 

---

 # 4. 高效配方

 标准有效推导使用：

 选择整数$$a,b,c,d,e$$对应于$$\alpha,\beta,\gamma,\delta,\varepsilon.$$然后定义$$x = 180-(a+b+c+d+e).$$利用正弦规则相容性，可以得出$$\tan \eta = \frac{ \sin b \sin(c+d)\sin e - \sin c \sin(a+b)\sin x }{ \sin c \sin(a+b)\cos x - \sin b \sin(c+d)\cos e }.$$由此我们计算$\eta$， 进而$$\theta = 180-(x+\eta).$$两者都必须是正整数。 

---

 # 5.Python实现```python
import math

DEG = math.pi / 180.0
EPS = 1e-9

# ------------------------------------------------------------
# Canonical representative under the 8 symmetries of a quadrilateral
# ------------------------------------------------------------

def canonical(t):
    t = list(t)

    rots = []
    for k in range(4):
        r = t[2*k:] + t[:2*k]
        rots.append(tuple(r))

    rev = [t[1], t[0], t[7], t[6], t[5], t[4], t[3], t[2]]

    for k in range(4):
        r = rev[2*k:] + rev[:2*k]
        rots.append(tuple(r))

    return min(rots)

# ------------------------------------------------------------
# Main search
# ------------------------------------------------------------

sol = set()

sin = lambda x: math.sin(x * DEG)
cos = lambda x: math.cos(x * DEG)
atan2 = math.atan2

for a in range(1, 180):
    for b in range(1, 180 - a):

        A = a + b

        for c in range(1, 180):
            for d in range(1, 180 - c):

                B = c + d

                # Remaining total for C + D
                rem = 360 - A - B

                if rem < 2:
                    continue

                for e in range(1, rem):

                    x = rem - e

                    if x <= 0:
                        continue

                    # Formula for eta
                    num = (
                        sin(b) * sin(c + d) * sin(e)
                        - sin(c) * sin(a + b) * sin(x)
                    )

                    den = (
                        sin(c) * sin(a + b) * cos(x)
                        - sin(b) * sin(c + d) * cos(e)
                    )

                    eta = math.degrees(atan2(num, den))

                    if eta <= 0:
                        eta += 180

                    r = round(eta)

                    if abs(eta - r) > EPS:
                        continue

                    eta = r

                    theta = 180 - (x + eta)

                    if theta <= 0:
                        continue

                    if abs(theta - round(theta)) > EPS:
                        continue

                    theta = int(round(theta))

                    tup = (a, b, c, d, e, x, eta, theta)

                    sol.add(canonical(tup))

print(len(sol))
```---
