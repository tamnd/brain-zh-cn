[项目欧拉问题 495](https://projecteuler.net/problem=495)

 ## 解决方案

 **答案：**`789107601`让$$N=n!=\prod_{p\le n} p^{e_p}, \qquad e_p=\sum_{j\ge1}\left\lfloor \frac n{p^j}\right\rfloor .$$我们必须计算这个数字$W(N,k)$无序因式分解$$N=a_1a_2\cdots a_k$$进入$k$**不同**正整数。 

对于这个问题：$$N=10000!,\qquad k=30.$$---

 # 1.数学分析

 ## 步骤 1：有序分解

 假设我们计算有序数$k$-元组$(a_1,\dots,a_k)$与产品$N$。 

对于每个素数$p$,$$a_i=\prod_p p^{x_{i,p}}, \qquad \sum_{i=1}^k x_{i,p}=e_p.$$因此对于固定素数$p$，指数分布是星条计数：$$\binom{e_p+k-1}{k-1}.$$因此，有序分解的数量是$$F_k(N)=\prod_{p\mid N}\binom{e_p+k-1}{k-1}.$$但这允许相同的因素。 我们需要所有因素都截然不同。 

---

 ## 步骤 2：平等的包容与排斥

 我们对所有条目都不同的有序元组进行计数。 

让$\sigma\in S_k$。 

如果一个元组是固定的$\sigma$，则同一循环中的条目$\sigma$必须相等。 

认为$\sigma$有周期长度$$\lambda=(\lambda_1,\lambda_2,\dots,\lambda_r), \qquad \sum \lambda_i=k.$$那么每个周期对应一个自变量$b_i$， 和$$N=\prod_{i=1}^r b_i^{\lambda_i}.$$对于素数指数$e$，我们需要的解的数量$$\lambda_1x_1+\cdots+\lambda_rx_r=e, \qquad x_i\ge0.$$这正好是系数$t^e$在$$\prod_{i=1}^r \frac1{1-t^{\lambda_i}}.$$定义$$A_\lambda(e) = [t^e]\prod_i \frac1{1-t^{\lambda_i}}.$$然后通过循环类型的排列固定元组的数量$\lambda$是$$\prod_{p\mid N} A_\lambda(e_p).$$---

 ## 步骤 3：分区格上的莫比乌斯反演

 所有条目不同的有序元组的数量是$$D_k(N) = \sum_{\lambda\vdash k} (-1)^{k-\ell(\lambda)} \frac{k!}{z_\lambda} \prod_{p\mid N} A_\lambda(e_p),$$在哪里$$z_\lambda=\prod_j j^{m_j}m_j!,$$和$m_j$是部分的重数$j$在$\lambda$。 

最后，无序因式分解除以$k!$:$$W(N,k)=\frac{D_k(N)}{k!}.$$所以：$$\boxed{ W(N,k) = \sum_{\lambda\vdash k} \frac{(-1)^{k-\ell(\lambda)}}{z_\lambda} \prod_{p\mid N} A_\lambda(e_p) }$$（模数$10^9+7$）。

 # 2.Python实现```python
from collections import Counter
from math import factorial
from sympy import primerange

MOD = 1_000_000_007

# ------------------------------------------------------------
# Generate integer partitions of n
# ------------------------------------------------------------
def partitions(n, mx=None):
    if mx is None or mx > n:
        mx = n

    if n == 0:
        yield []
        return

    for first in range(mx, 0, -1):
        for rest in partitions(n - first, first):
            yield [first] + rest

# ------------------------------------------------------------
# Prime exponents in n!
# ------------------------------------------------------------
def factorial_prime_exponents(n):
    exps = []

    for p in primerange(1, n + 1):
        e = 0
        m = n

        while m:
            m //= p
            e += m

        exps.append(e)

    return exps

# ------------------------------------------------------------
# Compute W(n!, k) modulo MOD
# ------------------------------------------------------------
def W_factorial(n, k):
    exps = factorial_prime_exponents(n)
    max_e = max(exps)

    fact_k = factorial(k)
    inv_fact_k = pow(fact_k, MOD - 2, MOD)

    answer = 0

    for lam in partitions(k):

        # ----------------------------------------------------
        # Compute A_lambda(e) for all e <= max_e
        #
        # dp[e] = coefficient of:
        #   product 1/(1 - x^part)
        # ----------------------------------------------------
        dp = [0] * (max_e + 1)
        dp[0] = 1

        for part in lam:
            for e in range(part, max_e + 1):
                dp[e] += dp[e - part]
                dp[e] %= MOD

        # Product over all prime exponents
        prod = 1
        for e in exps:
            prod = (prod * dp[e]) % MOD

        # z_lambda
        c = Counter(lam)

        z = 1
        for part, mult in c.items():
            z *= (part ** mult) * factorial(mult)

        # permutation count k!/z_lambda
        term = (fact_k // z) % MOD

        # sign
        if (k - len(lam)) % 2:
            term = -term

        answer = (answer + term * prod) % MOD

    answer %= MOD

    # divide by k!
    answer = (answer * inv_fact_k) % MOD

    return answer

# ------------------------------------------------------------
# Checks from the statement
# ------------------------------------------------------------
print(W_factorial(100, 10))
# 287549200

# Final answer
print(W_factorial(10000, 30))
```---

 # 3. 代码演练

 ###`partitions(n)`生成所有整数分区$n$。 

为了$k=30$，只有$5604$分区。 

---

 ###`factorial_prime_exponents(n)`使用勒让德公式：$$e_p(n!)=\sum_{j\ge1}\left\lfloor\frac{n}{p^j}\right\rfloor.$$为了$10000!$， 有$1229$素数。 

---

 ### 动态规划$A_\lambda(e)$对于分区$\lambda=(\lambda_1,\dots,\lambda_r)$,$$\prod_i \frac1{1-x^{\lambda_i}}$$由无界背包DP展开：```python
for part in lam:
    for e in range(part, max_e + 1):
        dp[e] += dp[e - part]
```然后：```python
dp[e]
```等于$$A_\lambda(e).$$---

 ### 包含-排除术语

 对于循环类型$\lambda$,$$\frac{k!}{z_\lambda}$$计算该循环结构的排列。 

标志是：$$(-1)^{k-\ell(\lambda)}.$$---
