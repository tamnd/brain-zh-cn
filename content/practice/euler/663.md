[项目欧拉问题 663](https://projecteuler.net/problem=663)

 ## 解决方案

 **答案：**`1884138010064752`关键的观察结果是，这是一个**点更新下的动态最大子数组问题**。 

让$$A_n = (A[0],A[1],\dots,A[n-1])$$和步骤之后$i$,$$M_n(i)=\max_{0\le p\le q<n}\sum_{j=p}^q A[j]$$（最大连续子数组和，即 Kadane 问题）。 

每一步仅**一个位置发生变化**，因此重新计算$M_n(i)$从头开始在$O(n)$是不可能的$$n=10{,}000{,}003,\qquad l=10{,}200{,}000.$$有效的解决方案是：

 1. 生成 tribonacci 值模$n$逐渐地。 
2. 维护$A_n$与点更新。 
3. 使用**线段树**维护全局最大子数组和。 

对于每个段，我们存储四个数量：$$(\text{sum},\text{pref},\text{suff},\text{best})$$在哪里：

-`sum`= 段总和
 -`pref`= 最大前缀和
 -`suff`= 最大后缀和
 -`best`= 最大子数组和

 两个子段$L,R$结合在$O(1)$：$$\text{sum}=L_s+R_s$$

$$\text{pref}=\max(L_p,L_s+R_p)$$

$$\text{suff}=\max(R_u,R_s+L_u)$$

$$\text{best}= \max(L_b,R_b,L_u+R_p)$$内存高效的实现使用**块分解**：保留完整数组$A$在紧凑的 64 位数组中，并在块而不是单个元素上维护线段树。 由于问题只要求$$S(n,10{,}200{,}000)-S(n,10{,}000{,}000),$$我们只需要$M_n(i)$最后$200{,}000$步骤。 所以：

 - 应用第一个$10^7$直接更新，
 - 一次构建结构，
 - 处理最终结果$200{,}000$积累的同时更新$M_n(i)$。 

正确的 Python 实现是：```python
from array import array

NEG_INF = -(10**18)

def block_summary(A, start, end):
    r = 0
    max_pref = NEG_INF
    min_pref_best = 0
    best = NEG_INF
    min_pref_suff = 0
    last = end - 1

    for k in range(start, end):
        r += A[k]

        max_pref = max(max_pref, r)
        best = max(best, r - min_pref_best)
        min_pref_best = min(min_pref_best, r)

        if k != last:
            min_pref_suff = min(min_pref_suff, r)

    total = r
    max_suff = total - min_pref_suff
    return total, max_pref, max_suff, best

def build_block_tree(A, n, B):
    m = (n + B - 1) // B
    size = 1
    while size < m:
        size <<= 1

    total = array("q", [0]) * (2 * size)
    pref  = array("q", [NEG_INF]) * (2 * size)
    suff  = array("q", [NEG_INF]) * (2 * size)
    best  = array("q", [NEG_INF]) * (2 * size)

    # Leaves
    for b in range(m):
        s = b * B
        e = min(n, s + B)
        ts, tp, tu, tb = block_summary(A, s, e)

        pos = size + b
        total[pos] = ts
        pref[pos] = tp
        suff[pos] = tu
        best[pos] = tb

    # Internal nodes
    for pos in range(size - 1, 0, -1):
        l = pos * 2
        r = l + 1

        total[pos] = total[l] + total[r]
        pref[pos] = max(pref[l], total[l] + pref[r])
        suff[pos] = max(suff[r], total[r] + suff[l])
        best[pos] = max(best[l], best[r],
                         suff[l] + pref[r])

    return (m, size, total, pref, suff, best)

def update_block(tree, A, n, B, b):
    m, size, total, pref, suff, best = tree

    s = b * B
    e = min(n, s + B)

    ts, tp, tu, tb = block_summary(A, s, e)

    pos = size + b
    total[pos] = ts
    pref[pos] = tp
    suff[pos] = tu
    best[pos] = tb

    pos //= 2

    while pos:
        l = pos * 2
        r = l + 1

        total[pos] = total[l] + total[r]
        pref[pos] = max(pref[l], total[l] + pref[r])
        suff[pos] = max(suff[r], total[r] + suff[l])
        best[pos] = max(best[l], best[r],
                         suff[l] + pref[r])

        pos //= 2

def solve():
    n = 10_000_003
    start = 10_000_000
    end = 10_200_000
    B = 256

    A = array("q", [0]) * n

    # tribonacci window modulo n
    u0, u1, u2 = 0, 0, 1 % n

    tree = None
    ans = 0

    for i in range(1, end + 1):
        idx = u0
        delta = (u1 << 1) - n + 1
        A[idx] += delta

        if i == start:
            tree = build_block_tree(A, n, B)

        elif i > start:
            update_block(tree, A, n, B, idx // B)
            ans += tree[5][1]   # root maximum subarray sum

        # advance tribonacci by 2 steps
        t3 = u0 + u1 + u2
        if t3 >= n:
            t3 -= n
        if t3 >= n:
            t3 -= n

        t4 = u1 + u2 + t3
        if t4 >= n:
            t4 -= n
        if t4 >= n:
            t4 -= n

        u0, u1, u2 = u2, t3, t4

    return ans

print(solve())
