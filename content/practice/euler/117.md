[欧拉项目问题 117](https://projecteuler.net/problem=117)

 ## 解决方案

 **答案：**`100808458960497`让$F(n)$表示平铺一行长度的方式数$n$使用：

 - 长度为灰色的方块$1$,
 - 长度为红色的长方形$2$,
 - 长度为绿色的长方形$3$,
 - 长度为蓝色的长方形$4$。 

我们想要$F(50)$。 

---

 # 数学分析

 ## 第 1 步：构建递归

 考虑有效长度平铺中的 **最左边的平铺**$n$。 

有四种可能：

 1. 一个灰色的长方形$1$剩余长度：$n-1$2. 一块长度为红色的瓷砖$2$剩余长度：$n-2$3. 一块绿色的长瓷砖$3$剩余长度：$n-3$4. 一块长度为蓝色的瓷砖$4$剩余长度：$n-4$所以，$$F(n)=F(n-1)+F(n-2)+F(n-3)+F(n-4)$$这是广义的斐波那契递推。 

---

 ## 第 2 步：确定基本情况

 我们定义：$$F(0)=1$$为什么？ 因为只有一种方法可以平铺一行长度$0$：不使用瓷砖。 

现在计算小值：

 ###$n=1$只有一种可能：

 -$1$所以：$$F(1)=1$$---

 ###$n=2$可能性：

 -$1+1$-$2$因此：$$F(2)=2$$---

 ###$n=3$可能性：

 -$1+1+1$-$1+2$-$2+1$-$3$因此：$$F(3)=4$$---

 ###$n=4$可能性：

 -$1+1+1+1$-$2+1+1$-$1+2+1$-$1+1+2$-$2+2$-$3+1$-$1+3$-$4$所以：$$F(4)=8$$The recurrence now generates all later values.

 ---

 ## Step 3: Verify the example$n=5$使用递归：$$F(5)=F(4)+F(3)+F(2)+F(1)$$

$$F(5)=8+4+2+1=15$$与问题陈述相匹配。 

---

 # Python 实现```python
def count_tilings(n):
    # dp[i] = number of tilings of length i
    dp = [0] * (n + 1)

    # Base case:
    # one way to tile an empty row
    dp[0] = 1

    for i in range(1, n + 1):
        # Place a grey tile of length 1
        dp[i] += dp[i - 1]

        # Place a red tile of length 2
        if i >= 2:
            dp[i] += dp[i - 2]

        # Place a green tile of length 3
        if i >= 3:
            dp[i] += dp[i - 3]

        # Place a blue tile of length 4
        if i >= 4:
            dp[i] += dp[i - 4]

    return dp[n]

print(count_tilings(50))
```---

 # 小值验证

 递归生成：$$\begin{aligned} F(0)&=1\\ F(1)&=1\\ F(2)&=2\\ F(3)&=4\\ F(4)&=8\\ F(5)&=15 \end{aligned}$$问题明确指出有$15$瓷砖长度$5$，所以我们的递归是正确的。 

继续复发直至$50$给出：$$F(50)=100808458960497$$---

 # 最终验证

 该序列呈指数增长，因此$15$- 数字答案$n=50$是合理的。 

递归是详尽且不重叠的：

 - 每个瓷砖都以四种瓷砖类型中的一种开始，
