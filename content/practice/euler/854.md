[项目欧拉问题 854](https://projecteuler.net/problem=854)

 ## 解决方案

 **答案：**`29894398`让$\pi(n)$表示皮萨诺周期模$n$，并定义$$M(p)=\max\{n:\pi(n)=p\},$$和$M(p)=1$如果没有这样的$n$存在。 

我们必须计算$$P(10^6)=\prod_{p=1}^{10^6} M(p)\pmod{1234567891}.$$---

 # 1.数学分析

 关于皮萨诺时期的主要事实是：

 ## A. 皮萨诺周期和斐波那契整除性

 一个经典恒等式是：$$\pi(n)=\text{ord}_n \begin{pmatrix} 1&1\\1&0 \end{pmatrix}.$$另一个重要结果是：$$N(p):=\max\{n:\pi(n)\mid p\} = \gcd(F_p,F_{p+1}-1),$$在哪里$F_k$是斐波那契数列。 

对于偶数周期，这会大大简化。 

---

 ## B. 封闭式$N(2m)$使用斐波那契/卢卡斯恒等式：$$\gcd(F_{2m},F_{2m+1}-1)= \begin{cases} F_m, & m \text{ even},\\ L_m, & m \text{ odd}, \end{cases}$$在哪里$L_m$是卢卡斯序列：$$L_0=2,\quad L_1=1,\quad L_n=L_{n-1}+L_{n-2}.$$因此$$N(2m)= \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd}. \end{cases}$$重要的额外事实是这些数字实际上恰好达到了周期$2m$， 所以：$$M(2m)=N(2m).$$---

 ## C. 奇数周期

 对于每一个$n>2$，皮萨诺周期是偶数。 

唯一出现的奇怪的皮萨诺时期是：$$\pi(2)=3.$$所以：$$M(3)=2,$$对于每一个奇数$p>3$,$$M(p)=1.$$因此整个产品只减少到偶数周期。 

---

 # 2.最终公式

 对于$p=2m$和$m\ge3$,$$M(2m)= \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd}. \end{cases}$$因此$$P(10^6) = 2 \prod_{m=3}^{500000} \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd} \end{cases} \pmod{1234567891}.$$现在可以直接迭代计算模数$1234567891$。 

---

 # 3.Python实现```python
MOD = 1234567891
TARGET = 1_000_000

def solve():
    # M(3) = 2
    result = 2

    max_m = TARGET // 2

    # Fibonacci:
    # F0 = 0, F1 = 1
    f_prev, f_cur = 0, 1

    # Lucas:
    # L0 = 2, L1 = 1
    l_prev, l_cur = 2 % MOD, 1 % MOD

    for m in range(2, max_m + 1):

        # advance Fibonacci
        f_prev, f_cur = f_cur, (f_prev + f_cur) % MOD

        # advance Lucas
        l_prev, l_cur = l_cur, (l_prev + l_cur) % MOD

        if m < 3:
            continue

        if m % 2 == 0:
            # M(2m) = F_m
            result = (result * f_cur) % MOD
        else:
            # M(2m) = L_m
            result = (result * l_cur) % MOD

    return result

print(solve())
```---

 # 4. 代码演练

 ### 初始化```python
result = 2
```占：$$M(3)=2.$$---

 ### 斐波那契迭代```python
f_prev, f_cur = 0, 1
```存储连续的斐波那契数。 

每一步：```python
f_prev, f_cur = f_cur, (f_prev + f_cur) % MOD
```更新到下一个斐波那契数模$MOD$。 

---

 ### 卢卡斯迭代

 同样：```python
l_prev, l_cur = 2, 1
```追踪卢卡斯号码。 

---

 ### 乘法步骤

 对于每个$m\ge3$：

- 如果$m$是偶数，乘以$F_m$,
 - 否则乘以$L_m$。 

这确切地实现了：$$M(2m)= \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd}. \end{cases}$$---

 # 5. 样本验证

 问题指出：$$P(10)=264.$$重要的值是：$$M(3)=2,\quad M(6)=4,\quad M(8)=3,\quad M(10)=11.$$因此$$P(10)=2\cdot4\cdot3\cdot11=264,$$完美匹配。 

还：$$M(18)=L_9=76,$$完全按照给定的。

 # 6. 最终计算

 运行程序给出：$$P(1\,000\,000)\bmod 1\,234\,567\,891 = 29894398.$$**答案：29894398**
