[欧拉项目905问题](https://projecteuler.net/problem=905)

 ## 解决方案

 **答案：**`70228218`让

-$F_A(x,y)=F(x+y,x,y)$(A穿和)，
 -$F_B(x,y)=F(x,x+y,y)$,
 -$F_C(x,y)=F(x,y,x+y)$。 

我们需要$$\sum_{a=1}^7 \sum_{b=1}^{19} F_C(a^b,b^a).$$关键的观察是：

 - 如果玩家看到数字$u,v$，他们自己的号码是$|u-v|$或者$u+v$。 
- 如果较小的可能性已经导致更早的声明，那么玩家推断他们必须具有较大的价值。 

这产生了递归$$F_P(a,b)=1+F_{P-1}(a,b-a)$$（玩家循环的地方$A\to B\to C\to A$），排序后$a\le b$。 

我们可以批量执行欧几里得算法步骤，而不是一次减去一个步骤。 

如果$b=qa+r$：

- 什么时候$r>0$，我们可以执行$q$立即减法；
 - 什么时候$r=0$，最后的减法达到相等，所以只有$q-1$步骤在基本情况之前执行。 

基本情况是：$$F_A(a,a)=1,\qquad F_B(a,a)=2,\qquad F_C(a,a)=3.$$这是准确的 Python 代码。```python
from functools import lru_cache

# players: A=0, B=1, C=2
@lru_cache(None)
def F(player, a, b):
    if a > b:
        a, b = b, a

    # base case: equal numbers
    if a == b:
        return player + 1

    q, r = divmod(b, a)

    if r == 0:
        # equality reached after q-1 subtractions
        k = q - 1
        return k + F((player - k) % 3, a, a)
    else:
        # perform q subtractions at once
        k = q
        return k + F((player - k) % 3, min(a, r), max(a, r))

total = 0

for a in range(1, 8):
    for b in range(1, 20):
        x = a ** b
        y = b ** a
        total += F(2, x, y)   # player C has the sum

print(total)
```实例验证：

 -$F(2,1,1)=1$✔
 -$F(2,7,5)=5$✔
