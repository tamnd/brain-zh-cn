[欧拉项目问题 226](https://projecteuler.net/problem=226)

 ## 解决方案

 **答案：**`0.11316017`让$$B(x)=\sum_{n=0}^{\infty}\frac{s(2^n x)}{2^n}, \qquad s(x)=\text{distance from }x\text{ to the nearest integer}.$$这是 **blancmange 函数**（或 Takagi 函数）。 

我们求同时封闭的面积：

 - 在牛奶冻曲线下$y=B(x)$,
 - 以及圆圈内$$\left(x-\frac14\right)^2+\left(y-\frac12\right)^2=\left(\frac14\right)^2.$$所需区域是由下半圆和牛奶冻曲线界定的小“勺”。 

---

 # 1.数学分析

 ## 步骤 1 — 圆方程

 圆的下半部分是$$y_c(x)=\frac12-\sqrt{\frac1{16}-\left(x-\frac14\right)^2}.$$我们需要交点$x_0$满意的$$B(x_0)=y_c(x_0).$$根据牛奶冻曲线的对称性，$$B(x)=B(1-x),$$相关的封闭区域从$x_0$到$1/2$。 

因此所需面积为$$A=\int_{x_0}^{1/2}\left(B(x)-y_c(x)\right)\,dx.$$---

 ## 步骤 2 — 有效评估$B(x)$该定义收敛得非常快，因为每个项都除以$2^n$。 

对于数值计算：$$B(x)\approx \sum_{n=0}^{N-1}\frac{s(2^n x)}{2^n},$$和$N=50$已经给出了极高的精度。 

对于任何真实的$t$,$$s(t)=|t-\operatorname{round}(t)|.$$---

 ## 步骤 3 — 找到交点

 定义$$f(x)=B(x)-y_c(x).$$对区间使用二分法$(0,0.5)$，我们得到$$x_0 \approx 0.07890778796534.$$---

 ## 步骤 4 — 数值积分

 我们计算$$A=\int_{x_0}^{1/2}(B(x)-y_c(x))\,dx$$使用辛普森规则进行精细细分。 

数值收敛到$$A \approx 0.11316016345\ldots$$四舍五入到小数点后八位$$0.11316017.$$---

 # 2.Python实现```python
from math import sqrt

# Distance to nearest integer
def s(x):
    return abs(x - round(x))

# Blancmange function
def B(x, terms=60):
    total = 0.0
    scale = 1.0

    for n in range(terms):
        total += s(scale * x) / scale
        scale *= 2.0

    return total

# Lower semicircle
def circle_lower(x):
    return 0.5 - sqrt(0.0625 - (x - 0.25) ** 2)

# Difference between curves
def f(x):
    return B(x) - circle_lower(x)

# Bisection to find intersection point
a, b = 0.0, 0.5

for _ in range(100):
    m = (a + b) / 2

    if f(m) > 0:
        b = m
    else:
        a = m

x0 = (a + b) / 2

# Simpson integration
def simpson(g, a, b, n=20000):
    if n % 2 == 1:
        n += 1

    h = (b - a) / n
    total = g(a) + g(b)

    for i in range(1, n):
        coeff = 4 if i % 2 == 1 else 2
        total += coeff * g(a + i * h)

    return total * h / 3

area = simpson(
    lambda x: B(x) - circle_lower(x),
    x0,
    0.5,
    20000
)

print(f"{area:.8f}")
```---
