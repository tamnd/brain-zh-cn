[欧拉项目 121 问题](https://projecteuler.net/problem=121)

 ## 解决方案

 **答案：**`2269`让游戏持续$n=15$轮流。 

转弯时$k$（从$k=1$）：

 - 绘画前，袋子里装有$1$蓝色光盘和$k$红色光盘，
 - 所以画蓝色的概率是$$\frac{1}{k+1},$$画红色的概率是$$\frac{k}{k+1}.$$如果蓝色抽牌数量严格大于红色抽牌数量，则玩家获胜。 

为了$15$转，这意味着至少获得$8$蓝色光盘。 

---

 # 数学分析

 定义：

 -$B_k$：回合时画蓝色$k$,
 -$R_k$：转牌时画红$k$。 

特定结果序列的概率是每轮概率的乘积。 

一个关键的简化来自于分解出共同点：$$\prod_{k=1}^{15} (k+1)=16!.$$事实上，每个结果概率都有分母$16!$。 

如果一组$S\subseteq\{1,\dots,15\}$表示绘制蓝色的匝数，则：

 - 蓝色贡献分子$1$,
 - 转弯时呈红色$k$贡献分子$k$。 

因此：$$P(S)=\frac{\prod_{k\notin S} k}{16!}.$$自从$$\prod_{k=1}^{15} k = 15!,$$我们可以重写：$$P(S)=\frac{15!}{16!\prod_{k\in S}k} =\frac{1}{16\prod_{k\in S}k}.$$因此总获胜概率为$$P(\text{win}) = \sum_{\substack{S\subseteq\{1,\dots,15\}\\ |S|\ge 8}} \frac{1}{16\prod_{k\in S}k}.$$然而，使用动态规划来计算这一点在计算上更容易。 

---

 # 奖金条件

 假设银行家分配的奖金为$F$磅。 

- 玩家支付 1 英镑即可玩。 
- 支出$F$包括退回的 1 英镑。 

预期支出：$$F\cdot P(\text{win}).$$为避免预期损失：$$F\cdot P(\text{win}) \le 1.$$因此，允许的最大整数奖金是$$\left\lfloor \frac{1}{P(\text{win})} \right\rfloor.$$因此，我们的任务简化为计算准确的获胜概率。 

---

 # 动态规划方法

 让：$$dp[j]$$表示恰好具有的总概率$j$处理一些回合后绘制蓝色。 

最初：$$dp[0]=1.$$为转弯$k$：

 - 蓝色概率$= \frac1{k+1}$,
 - 红色概率$= \frac{k}{k+1}$。 

向后更新：$$dp[j] = dp[j]\cdot \frac{k}{k+1} + dp[j-1]\cdot \frac1{k+1}.$$15 轮后，计算概率总和$j\ge 8$。 

---

 # Python 实现```python
from fractions import Fraction

# Number of turns
N = 15

# dp[j] = probability of getting exactly j blue discs
dp = [Fraction(0, 1) for _ in range(N + 1)]
dp[0] = Fraction(1, 1)

# Process each turn
for k in range(1, N + 1):

    p_blue = Fraction(1, k + 1)
    p_red = Fraction(k, k + 1)

    # Update backwards to avoid overwriting needed values
    for j in range(k, 0, -1):
        dp[j] = dp[j] * p_red + dp[j - 1] * p_blue

    dp[0] *= p_red

# Need strictly more blue than red
# For 15 turns, that means at least 8 blues
win_probability = sum(dp[8:])

# Maximum prize fund
prize_fund = int(Fraction(1, 1) / win_probability)

print(win_probability)
print(prize_fund)
```---

 # 最终计算

 对于$N=15$，确切的获胜概率是$$\frac{9219406943}{20922789888000}.$$因此：$$\left\lfloor \frac{20922789888000}{9219406943} \right\rfloor = 2269.$$这是合理的：

 - 获胜概率约为$0.0004406$,
 - 所以倒数是围绕$2269.4$,
 - 因此最大的安全整数支付是$2269$。
