[欧拉项目问题 182](https://projecteuler.net/problem=182)

 ## 解决方案

 **答案：**`399788195976`让$$n=pq,\qquad p=1009,\quad q=3643,$$所以$$\phi=(p-1)(q-1)=1008\cdot 3642.$$我们寻找所有有效的 RSA 指数$e$这样$$1<e<\phi,\qquad \gcd(e,\phi)=1,$$其中未隐藏消息的数量最少。 

---

 # 1.数学分析

 一条消息$m$当$$m^e \equiv m \pmod n.$$自从$n=pq$对于不同的素数，根据中国剩余定理，这相当于同时$$m^e \equiv m \pmod p, \qquad m^e \equiv m \pmod q.$$重写为$$m(m^{e-1}-1)\equiv 0 \pmod p.$$越过田野$\mathbb F_p$：

 -$m=0$总有解决办法，
 - 为$m\neq0$，我们需要$$m^{e-1}\equiv1\pmod p.$$乘法群模$p$有订单$p-1$，所以解的数量是$$\gcd(e-1,p-1).$$包括$m=0$，解总数取模$p$是$$1+\gcd(e-1,p-1).$$类似地取模$q$，数字是$$1+\gcd(e-1,q-1).$$因此，未隐藏消息的总数模$n$是$$U(e)=\bigl(1+\gcd(e-1,p-1)\bigr)       \bigl(1+\gcd(e-1,q-1)\bigr).$$所以对于我们的质数：$$U(e)=\bigl(1+\gcd(e-1,1008)\bigr)       \bigl(1+\gcd(e-1,3642)\bigr).$$---

 ## 最小化未隐藏消息的数量

 自从$e$必须满足$\gcd(e,\phi)=1$,$e$很奇怪，因为$\phi$是均匀的。 

因此$e-1$是偶数，所以$$\gcd(e-1,1008)\ge2, \qquad \gcd(e-1,3642)\ge2.$$因此最小可能值$U(e)$是$$(1+2)(1+2)=9.$$所以我们需要$$\gcd(e-1,1008)=2, \qquad \gcd(e-1,3642)=2.$$因式分解模数：$$1008=2^4\cdot 3^2\cdot 7,$$

$$3642=2\cdot 3\cdot 607.$$所以$e-1$必须：

 - 可以整除$2$,
 - 不能被整除$3$,
 - 不能被整除$7$,
 - 不能被整除$607$。 

还$e$必须互质于$$\phi=1008\cdot3642 =2^5\cdot3^4\cdot7\cdot607.$$因此$e$另外必须不能被整除$3,7,607$。 

自从$e$是奇数，自动$e-1$恰好有一个因数$2$共同之处在于$3642$，前提是没有出现奇数公因数。 

所以有效的$e$正是那些互质的$\phi$为此$$e\not\equiv1\pmod3, \qquad e\not\equiv1\pmod7, \qquad e\not\equiv1\pmod{607}.$$为什么？ 

因为：

-$3\mid(e-1)\iff e\equiv1\pmod3$,
 -$7\mid(e-1)\iff e\equiv1\pmod7$,
 -$607\mid(e-1)\iff e\equiv1\pmod{607}$。 

但$e$已经不能$0$对这些素数取模，因为$\gcd(e,\phi)=1$。 

因此对于每个素因数$r\in\{3,7,607\}$，在残基之间互质$r$，我们必须排除残留物$1$。 

剩下：

 - 模数$3$：$1$允许残留量，
 - 模数$7$：$5$允许残留量，
 - 模数$607$：$605$允许残留。 

的力量$2$贡献所有奇数残基模$32$， IE。$16$选择。 

因此最小化指数的数量是$$16\cdot1\cdot5\cdot605=48400.$$现在我们需要所有这些的**总和**$e$。 

---

 # 2. 计算总和

 有效指数形成对称子集模$$\phi=3671136.$$对于每个有效的$e$, 数量$$\phi-e$$也有效：

 - 很奇怪，
 - 互质于$\phi$,
 - 并保留禁止的同余。 

因此，有效指数对的总和为$\phi$。 

由于有$48400$这样的指数，总和是$$\frac{48400}{2}\phi = 24200\cdot 3671136.$$计算：$$3671136\cdot24200 = 88854291200.$$---

 # 3.Python实现```python
from math import gcd

p = 1009
q = 3643

phi = (p - 1) * (q - 1)

best = None
total = 0

for e in range(2, phi):
    # RSA validity condition
    if gcd(e, phi) != 1:
        continue

    # number of unconcealed messages
    u = (1 + gcd(e - 1, p - 1)) * \
        (1 + gcd(e - 1, q - 1))

    if best is None or u < best:
        best = u
        total = e
    elif u == best:
        total += e

print(best)
print(total)
```---

 ## 小例子验证

 以声明中的例子为例：$$p=19,\quad q=37,\quad e=181.$$我们得到$$\gcd(180,18)=18, \qquad \gcd(180,36)=36.$$因此$$U(181)=(1+18)(1+36)=19\cdot37=703.$$这等于所有消息取模$703$，与描述的完全一样。
