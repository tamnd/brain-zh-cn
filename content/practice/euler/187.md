[项目欧拉问题 187](https://projecteuler.net/problem=187)

 ## 解决方案

 **答案：**`17427258`我们正在计算整数$$n < 10^8$$**恰好有两个质因数**，以重数计算。 

这样的数字称为**半素数**。 

示例：

 -$15 = 3\cdot 5$-$9 = 3^2$-$12 = 2^2\cdot 3$→ 不允许（三个素因数计算重数）

 所以我们想要以下形式的所有数字$$n = pq$$在哪里$p,q$是素数并且$p \le q$。 

---

 # 数学分析

 我们需要计算素数对$(p,q)$这样$$pq < 10^8.$$为了避免重复计算，强制执行$$p \le q.$$因此对于每个素数$p$，我们计算素数$q$满意的$$q \ge p,\qquad q < \frac{10^8}{p}.$$---

 ## 关键观察

 如果$p > \sqrt{10^8} = 10^4$， 然后$$p^2 > 10^8,$$所以没有有效的$q \ge p$存在。 

因此我们只需要素数$$p \le 10^4.$$对于每个这样的素数$p$：

 1.让$$M = \left\lfloor \frac{10^8-1}{p} \right\rfloor.$$2. 计算素数$q$和$$p \le q \le M.$$如果$\pi(x)$表示素数的数量$\le x$，如果$p$是$i$-第一个素数（0索引），则允许的个数$q$是$$\pi(M) - i.$$总结所有有效的$p$给出了答案。 

---

 # 高效算法

 我们需要：

 1. 所有素数达到$10^8 / 2 = 5\times10^7$。 
2. 快速素数计数$\pi(x)$。 

埃拉托色尼筛直至$5\times10^7$在优化的 Python/PyPy 中是可行的，但从概念上讲，该方法很简单。 

伪过程：

 - 生成所有素数$5\times10^7$。 
- 对于每个素数$p \le 10^4$：

 - 找出有多少个素数$\le (10^8-1)/p$。 
- 减去索引$p$强制执行$q \ge p$。 

复杂性主要由筛子决定。 

---

 # Python 实现```python
from bisect import bisect_right
from math import isqrt

LIMIT = 10**8

# We only need primes up to LIMIT // 2
MAXP = LIMIT // 2

# Sieve of Eratosthenes
sieve = bytearray(b"\x01") * (MAXP + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(MAXP) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:MAXP + 1:step] = b"\x00" * (((MAXP - start) // step) + 1)

# Extract primes
primes = [i for i in range(2, MAXP + 1) if sieve[i]]

answer = 0

# Only need p <= sqrt(LIMIT)
root = isqrt(LIMIT)

for i, p in enumerate(primes):
    if p > root:
        break

    max_q = (LIMIT - 1) // p

    # Number of primes <= max_q
    count = bisect_right(primes, max_q)

    # Enforce q >= p
    answer += count - i

print(answer)
```---
