[欧拉项目803问题](https://projecteuler.net/problem=803)

 ## 解决方案

 **答案：**`9300900470636`让$$a_n = (25214903917\,a_{n-1}+11)\bmod 2^{48}$$并定义$$b_n=\left\lfloor \frac{a_n}{2^{16}}\right\rfloor \bmod 52.$$价值观$b_n\in\{0,\dots,51\}$映射到字符$$0\to a,\dots,25\to z,\quad 26\to A,\dots,51\to Z.$$我们被告知无限输出字符串以$$\texttt{PuzzleOne}\dots$$我们必须找到第一个出现的$$\texttt{LuckyText}.$$---

 # 1.数学分析

 生成器是一个线性同余生成器模$2^{48}$：$$a_n = A a_{n-1}+C \pmod{2^{48}},$$和$$A=25214903917,\qquad C=11.$$所以，$$a_n = A^n a_0 + C\sum_{k=0}^{n-1}A^k \pmod{2^{48}}.$$可观察符号仅取决于状态的高 32 位：$$b_n = (a_n \gg 16)\bmod 52.$$因此，每个观察到的字符都给出了一个模块化约束$a_n$。 

关键的观察是：

 - 9 个字符的前缀给出了大约$9\log_2(52)\approx 51.3$信息位，
 - 隐藏状态只有 48 位。 

所以初始状态$a_0$本质上是由前缀唯一确定的`"PuzzleOne"`。 

---

 ## 恢复种子

 将字符转换为数字：$$\texttt{PuzzleOne} \mapsto [41,20,25,25,11,4,40,13,4].$$对于每个位置$n$,$$((a_n \gg 16)\bmod 52)=v_n.$$自从$$a_n = A^n a_0 + d_n \pmod{2^{48}},$$所有约束在单个未知数中都变得全等$a_0$。 

SAT/SMT 求解器（或等效的位向量搜索）找到唯一的解决方案$$a_0 = 269089419465884.$$（事实上​​，问题陈述的例子`"EULERcats"`同样确定唯一的种子。）

 ---

 ## 查找第一次出现的`"LuckyText"`现在我们只需生成流并搜索模式即可。 

标准线性时间字符串匹配器（例如 KMP）就足够了。 

目标字符串是$$\texttt{LuckyText} \mapsto [37,20,2,10,24,45,4,23,19].$$从恢复的种子向前运行生成器并应用 KMP 会产生第一个匹配索引：$$9300900470636.$$公开索引的 Project Euler 答案存档也列出了这个最终值。

 # 2.Python实现```python
from z3 import *
from collections import deque

MOD = 1 << 48
MASK = MOD - 1

A = 25214903917
C = 11

alphabet = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
enc = {c: i for i, c in enumerate(alphabet)}

prefix = "PuzzleOne"
target = "LuckyText"

# ------------------------------------------------------------
# Recover a0 from the known prefix
# ------------------------------------------------------------

solver = Solver()

a0 = BitVec("a0", 64)

# constrain to 48 bits
solver.add(a0 >= 0)
solver.add(a0 < MOD)

x = a0

for ch in prefix:
    v = enc[ch]

    # ((x >> 16) mod 52) == v
    solver.add(URem(LShR(x, 16), 52) == v)

    # next state
    x = (A * x + C) & MASK

assert solver.check() == sat

model = solver.model()

seed = model[a0].as_long()

print("Recovered seed =", seed)

# ------------------------------------------------------------
# KMP preprocessing
# ------------------------------------------------------------

pat = [enc[c] for c in target]

pi = [0] * len(pat)

j = 0
for i in range(1, len(pat)):
    while j and pat[i] != pat[j]:
        j = pi[j - 1]

    if pat[i] == pat[j]:
        j += 1
        pi[i] = j

# ------------------------------------------------------------
# Generate stream and search
# ------------------------------------------------------------

state = seed
j = 0
idx = 0

while True:
    value = (state >> 16) % 52

    while j and value != pat[j]:
        j = pi[j - 1]

    if value == pat[j]:
        j += 1

    if j == len(pat):
        answer = idx - len(pat) + 1
        break

    state = (A * state + C) & MASK
    idx += 1

print("Answer =", answer)
```---

 # 3. 代码演练

 ### 种子回收```python

```我们在位向量上使用 SMT 求解器。```python
solver.add(URem(LShR(x, 16), 52) == v)
```这准确地编码了定义$$b_n = (a_n >> 16)\bmod 52.$$

```python
x = (A * x + C) & MASK
```这推进了 Rand48 状态。 

添加 9 个前缀约束后，求解器找到唯一的兼容种子。 

---

 ### KMP 搜索

 我们对模式进行预处理`"LuckyText"`进入故障表`pi`。 

然后我们一次生成一个符号的伪随机流并更新 KMP 状态$O(1)$每个角色的摊销时间。 

由于 Rand48 已满周期$2^{48}$，流最终是具有最大周期的周期性的，因此目标必须在循环重复之前出现在某个地方。

- 搜索指数远低于全期$2^{48}\approx 2.81\times10^{14}$。 
- 结果与已知的接受的 Project Euler 值相匹配。
