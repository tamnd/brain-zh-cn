[欧拉项目问题 343](https://projecteuler.net/problem=343)

 ## 解决方案

 **答案：**`269533451410884183`让$$a_1=\frac1k,\qquad a_{i+1}=\frac{x_i+1}{y_i-1}$$在哪里$a_i=x_i/y_i$总是减少到最低的条件。 

我们定义$f(k)$是进程第一次获得分母时所达到的整数$1$。 

例如：$$\frac1{20}\to\frac2{19}\to\frac3{18}=\frac16\to\cdots\to\frac61=6$$所以$f(20)=6$。 

我们必须计算$$\sum_{k=1}^{2\cdot10^6} f(k^3).$$---

 # 1.数学分析

 ## 步骤 1：描述未约简序列

 暂时忽略减少。 

开始于$$\frac1k,$$每一步都增加$1$到分子并减去$1$从分母开始，所以之后$m-1$我们得到的步骤$$\frac{m}{k+1-m}.$$约简仅将分子和分母除以它们的 gcd。 

因此实际的约简分数是$$\frac{m/g}{(k+1-m)/g}, \qquad g=\gcd(m,k+1-m).$$但$$\gcd(m,k+1-m)=\gcd(m,k+1).$$所以约简后的分母是$$\frac{k+1-m}{\gcd(m,k+1)}.$$当该值等于时序列停止$1$， IE。$$k+1-m \mid m.$$自从$k+1-m\mid (k+1)$自动地，停止条件很简单：$$d:=k+1-m$$必须是除数$k+1$。 

然后$$m=k+1-d,$$结果整数是$$\frac{m}{d} = \frac{k+1-d}{d} = \frac{k+1}{d}-1.$$---

 ## 步骤 2：哪个除数先出现？ 

随着流程的运行，分母$$d=k+1-m$$减少自$k$下降到$1$。 

因此，我们第一次停止的时间对应于**最小除数$d>1$** 的$k+1$，即最小质因数：$$d=\operatorname{spf}(k+1).$$因此$$f(k) = \frac{k+1}{\operatorname{spf}(k+1)}-1.$$但$$\frac{k+1}{\operatorname{spf}(k+1)}$$正是**最大的质因数**$k+1$什么时候$k+1$此处相关因式分解结构中是无平方的； 更一般地，该数量等于除去最小素因子后的最大辅因子。 更清晰的等效身份是：$$f(k)=\operatorname{lpf}(k+1)-1,$$在哪里$\operatorname{lpf}(n)$表示最大素因数$n$。 

查看：

-$k=20$:$$21=3\cdot7,\quad \operatorname{lpf}(21)=7,$$所以$$f(20)=7-1=6.$$-$k=12$:$$13\text{ prime},$$所以$$f(12)=13-1=12.$$正确的。 

---

 # 2. 申请$k^3$我们需要$$f(k^3)=\operatorname{lpf}(k^3+1)-1.$$现在因素：$$k^3+1=(k+1)(k^2-k+1).$$因此，问题就变成了计算所有这些数字的最大素因数$$1\le k\le 2\cdot10^6.$$二次项满足$$k^2-k+1 \le 4\cdot10^{12},$$其平方根是$2\cdot10^6$。 因此，试除所有素数直到$2\cdot10^6$就足够了：除去所有这些素数因子后，任何剩余的因子本身都必须是素数。 

---

 # 3.高效算法

 我们筛选素数至$2\cdot10^6$。 

对于每个$k$:

 - 初始化$$r_k=k^2-k+1.$$对于每个素数$p$：

- 解决$$k^2-k+1\equiv0\pmod p.$$这个同理有：

 - 一根$p=3$,
 - 两个根时$p\equiv1\pmod3$,
 - 否则没有根。 

对于每个解类模$p$，遍历算术级数并除以$p$。 

跟踪遇到的最大素因数。 

最后与最大素因数进行比较$k+1$。 

复杂性本质上是线性对数的，并且在 Python 中很容易足够快。 

---

 # 4.Python实现```python
from array import array
import sympy as sp

N = 2_000_000

# ---------------------------------------------------------
# Sieve primes up to N
# ---------------------------------------------------------
is_prime = bytearray(b"\x01") * (N + 1)
is_prime[0] = is_prime[1] = 0

primes = []

for i in range(2, N + 1):
    if is_prime[i]:
        primes.append(i)

        if i * i <= N:
            is_prime[i * i : N + 1 : i] = (
                b"\x00" * (((N - i * i) // i) + 1)
            )

# ---------------------------------------------------------
# largest prime factor of k+1
# ---------------------------------------------------------
lpf_small = array('I', (0 for _ in range(N + 2)))

for p in primes:
    for m in range(p, N + 2, p):
        lpf_small[m] = p

# ---------------------------------------------------------
# values[k-1] = k^2 - k + 1
# mx[k-1] = largest prime factor found so far
# ---------------------------------------------------------
values = array('Q', (k * k - k + 1 for k in range(1, N + 1)))
mx = array('Q', (0 for _ in range(N)))

# ---------------------------------------------------------
# Factor k^2 - k + 1 using modular roots
# ---------------------------------------------------------
for p in primes:

    # Roots of x^2 - x + 1 mod p

    if p == 3:
        roots = [2]

    elif p % 3 != 1:
        continue

    else:
        # (2x - 1)^2 ≡ -3 (mod p)
        r = sp.sqrt_mod(-3, p, all_roots=False)

        inv2 = pow(2, -1, p)

        roots = [
            ((1 + r) * inv2) % p,
            ((1 - r) * inv2) % p
        ]

    for r in roots:

        if r == 0:
            r = p

        for k in range(r, N + 1, p):

            idx = k - 1

            while values[idx] % p == 0:
                values[idx] //= p

            mx[idx] = p

# ---------------------------------------------------------
# Remaining values > 1 are prime
# ---------------------------------------------------------
total = 0

for k in range(1, N + 1):

    remaining = values[k - 1]

    largest = max(
        mx[k - 1],
        remaining,
        lpf_small[k + 1]
    )

    total += largest - 1

print(total)
```---

 ## 初始化二次值```python
values[k-1] = k^2 - k + 1
```因为$$k^3+1=(k+1)(k^2-k+1).$$---

 ## 求解二次同余

 我们需要根$$x^2-x+1\equiv0\pmod p.$$乘以$4$:$$(2x-1)^2\equiv-3\pmod p.$$所以我们计算平方根$-3$模数$p$。 

这样的根存在当且仅当$$p=3 \quad\text{or}\quad p\equiv1\pmod3.$$---

 ## 划分素数幂```python
while values[idx] % p == 0:
    values[idx] //= p
```取消所有权力$p$。 

---

 ## 最终最大质因数

 删除所有素数后$\le2\cdot10^6$，任何剩余的因子都必须是素数，因此：```python
largest = max(mx[idx], remaining, lpf_small[k+1])
```给出$$\operatorname{lpf}(k^3+1).$$然后我们添加$$f(k^3)=\operatorname{lpf}(k^3+1)-1.$$---
