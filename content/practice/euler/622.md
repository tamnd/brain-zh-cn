[欧拉项目 622 问题](https://projecteuler.net/problem=622)

 ## 解决方案

 **答案：**`3010983666182123972`设甲板尺寸为$n$（偶数），以及指数位置$0$到$n-1$， 在哪里$0$是顶牌。 

所描述的洗牌是**完美的出洗牌**（顶牌和底牌保持固定）。 

## 1.数学分析

 ### 第 1 步：描述排列

 将甲板分成两半：

 - 左手：位置$0,1,\dots,\frac n2-1$- 右手：位置$\frac n2,\dots,n-1$交错给出：$$0,\frac n2,1,\frac n2+1,2,\frac n2+2,\dots$$出局洗牌的标准事实是：

 - 底卡保持固定，
 - 每个其他位置都变换为$$i \mapsto 2i \pmod{n-1}$$为了$0 \le i < n-1$。 

因此之后$k$洗牌，$$i \mapsto 2^k i \pmod{n-1}.$$甲板恰好在以下时间返回到原始配置：$$2^k \equiv 1 \pmod{n-1}.$$因此：$$s(n)=\operatorname{ord}_{n-1}(2),$$的乘法顺序$2$模数$n-1$。 

这与示例相匹配：$$n=52 \implies n-1=51.$$自从$$2^8 \equiv 1 \pmod{51},$$并且没有更小的指数起作用，$$s(52)=8.$$---

 ### 第 2 步：转换问题

 我们想要：$$s(n)=60.$$让$$m=n-1.$$然后：$$\operatorname{ord}_m(2)=60.$$根据乘法阶的定义：$$m \mid (2^{60}-1),$$但$m$一定**不**除法$2^d-1$对于任何真除数$d\mid 60$。 

所以算法是：

 1. 计算$$M=2^{60}-1.$$1. 枚举每个除数$m$的$M$。 
2. 保留那些$$\operatorname{ord}_m(2)=60.$$1. 总和$$n=m+1.$$---

 ## 2.Python实现```python
from sympy import divisors, n_order

def solve(target_order=60):
    # All valid m = n - 1 must divide 2^target_order - 1
    M = 2**target_order - 1

    total = 0

    # Check every divisor m of M
    for m in divisors(M):
        if m <= 1:
            continue

        # Multiplicative order of 2 modulo m
        if n_order(2, m) == target_order:
            total += (m + 1)

    return total

# Verify the example
example = solve(8)
print("s(n)=8 sum:", example)   # should be 412

# Final answer
answer = solve(60)
print(answer)
```---

 ## 3. 代码演练

 ###`M = 2**target_order - 1`如果$s(n)=k$， 然后：$$n-1 \mid 2^k-1.$$所以每个候选人都必须划分$2^k-1$。 

为了$k=60$:$$M = 2^{60}-1.$$---

 ###`divisors(M)`枚举每个正因数$M$。 

我们测试每个除数的可能值：$$m=n-1.$$---

 ###`n_order(2, m)`计算乘法阶数：$$\min\{t>0 : 2^t \equiv 1 \pmod m\}.$$我们只保留那些顺序准确的$60$。 

---

 ###`total += (m + 1)`自从：$$m=n-1,$$恢复：$$n=m+1.$$---

 ### 检查示例

 对于$k=8$，程序发现：$$n = 18,\ 52,\ 86,\ 256$$其总和为：$$18+52+86+256=412,$$与问题陈述完全匹配。
