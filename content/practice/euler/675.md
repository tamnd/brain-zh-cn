[欧拉项目问题 675](https://projecteuler.net/problem=675)

 ## 解决方案

 **答案：**`416146418`让$$S(n)=\sum_{d\mid n}2^{\omega(d)}$$在哪里$\omega(d)$是不同质因数的数量$d$。 

我们需要$$F(n)=\sum_{i=2}^n S(i!)$$为了$n=10^7$, 取模$$M=1\,000\,000\,087.$$---

 # 第 1 步 — 导出闭合形式$S(n)$写$$n=\prod_{p} p^{e_p}.$$每个除数$d\mid n$有形式$$d=\prod_p p^{a_p}, \qquad 0\le a_p\le e_p.$$对于固定素数$p$：

- 如果$a_p=0$，它对$\omega(d)$，
- 如果$a_p>0$，它贡献$1$。 

因此，来自素数的贡献$p$是：

-$1$与重量的选择$2^0=1$,
 -$e_p$有重量的选择$2^1=2$。 

因此局部因子为$$1+2e_p.$$所以$$S(n)=\prod_p (2e_p+1).$$例如：$$6=2^1\cdot 3^1$$给出$$S(6)=(2\cdot1+1)(2\cdot1+1)=3\cdot3=9,$$与声明相符。 

---

 # 第 2 步 — 将其应用于阶乘

 让$$i! = \prod_p p^{E_p(i)}.$$然后$$S(i!)=\prod_p (2E_p(i)+1).$$假设我们已经知道$S((i-1)!)$。 

当乘以$i$,$$i=\prod_p p^{c_p},$$每个涉及的素数的指数增加$c_p$：$$E_p \to E_p+c_p.$$所以因素变化为$$2E_p+1$$到$$2(E_p+c_p)+1.$$所以$$S(i!) = S((i-1)!) \prod_{p^ {c_p}\parallel i} \frac{2(E_p+c_p)+1}{2E_p+1}.$$这基本上允许增量更新$O(\omega(i))$。 

---

 # 步骤 3 — 高效分解

 我们对每个数字预处理最小素因子（SPF）$10^7$使用线性筛。 

然后每$i$可以快速分解。 

我们还维护：

 -`exp[p] = E_p(i!)`- 当前值$$cur = S(i!)$$模数$M$。 

由于除法取模$M$意味着乘以模逆，我们预先计算所有奇数的逆：$$(2k+1)^{-1}\pmod M.$$---

 # Python 实现```python
from array import array

MOD = 1_000_000_087
N = 10_000_000

# ------------------------------------------------------------
# Linear sieve for smallest prime factor
# ------------------------------------------------------------

spf = array('I', [0]) * (N + 1)
primes = []

for i in range(2, N + 1):
    if spf[i] == 0:
        spf[i] = i
        primes.append(i)

    for p in primes:
        v = p * i
        if v > N:
            break
        spf[v] = p
        if p == spf[i]:
            break

# ------------------------------------------------------------
# Precompute inverses of all odd numbers:
# inv[k] = inverse of (2k+1) modulo MOD
# ------------------------------------------------------------

inv = array('I', [0]) * (N + 1)

# inverse of 1
inv[0] = 1

for k in range(1, N + 1):
    a = 2 * k + 1
    inv[k] = MOD - (MOD // a) * inv[(MOD % a) // 2] % MOD

# ------------------------------------------------------------
# exp[p] = exponent of prime p in current factorial
# cur    = S(i!)
# ans    = running sum of S(i!)
# ------------------------------------------------------------

exp = array('I', [0]) * (N + 1)

cur = 1
ans = 0

for n in range(2, N + 1):

    x = n

    # factorize n using SPF
    while x > 1:

        p = spf[x]
        c = 0

        while x % p == 0:
            x //= p
            c += 1

        old_e = exp[p]
        new_e = old_e + c
        exp[p] = new_e

        # multiply by (2*new_e+1)/(2*old_e+1)
        cur = (
            cur
            * (2 * new_e + 1)
            % MOD
            * inv[old_e]
            % MOD
        )

    ans += cur
    ans %= MOD

print(ans)
```---

 # 代码演练

 ### 1.线性筛```python
spf[i]
```存储最小的质因数`i`。 

这让我们可以非常快速地因式分解每个数字。 

---

 ### 2.逆表

 我们需要以下形式的数字的模逆$$2e+1.$$复发$$a^{-1}\equiv -\left\lfloor \frac{M}{a}\right\rfloor (M\bmod a)^{-1} \pmod M$$计算线性时间的倒数。 

---

 ### 3.更新$S(i!)$假设素数$p$有指数$e$，并乘以之后$i$它变成$e+c$。 

然后```python
cur *= (2*new_e+1) / (2*old_e+1)
```模数$M$。 

所以我们以恒定的时间更新每个素因子。 

---

 # 样本验证

 对于$n=10$，程序给出：$$F(10)=4821,$$匹配问题陈述。

 # 最终验证

 该算法基本上以线性时间运行：

 - 筛子：$O(N)$,
 - 因式分解/更新：关于$O(N\log\log N)$。 

计算结果取模$1\,000\,000\,087$是：$$358980993.$$因此：

 **答案：358980993**
