[欧拉项目 462 问题](https://projecteuler.net/problem=462)

 ## 解决方案

 **答案：**`5.5350769703e1512`让$3$- 平滑数可写为$$2^a3^b \qquad (a,b\ge 0).$$对于固定$N$， 定义$$\mathcal P_N=\{(a,b)\in \mathbb Z_{\ge0}^2 : 2^a3^b\le N\}.$$整除关系变为$$2^{a_1}3^{b_1}\mid 2^{a_2}3^{b_2} \iff a_1\le a_2 \text{ and } b_1\le b_2.$$所以$F(N)$正是偏序集的线性扩展的数量$(\mathcal P_N,\le)$按组件顺序。 

---

 # 1. 转换为 Ferrers 图

 对于每个$b$， 定义$$\lambda_b = \left\lfloor \log_2\!\left(\frac{N}{3^b}\right)\right\rfloor + 1.$$然后行$b$包含细胞$$(a,b),\qquad 0\le a<\lambda_b.$$因此形状就是 Ferrers 图$$\lambda=(\lambda_0,\lambda_1,\ldots).$$例子：$N=20$。$$\lambda=(5,3,2),$$对应于$$1,2,4,8,16;\quad 3,6,12;\quad 9,18.$$偏序集阶正是杨氏图阶。 

所以：$$F(N)=f^\lambda,$$标准年轻造型的数量$\lambda$。 

---

 # 2. 钩长公式

 对于费雷尔形状$\lambda$和$n$细胞，$$f^\lambda=\frac{n!}{\prod_{c\in\lambda} h(c)},$$在哪里$h(c)$是细胞的钩长度$c$。 

因此$$F(N)=\frac{n!}{\prod h(c)}.$$---

 # 3. 验证小例子

 对于$N=20$,$$\lambda=(5,3,2), \qquad n=10.$$钩子长度为$$\begin{matrix} 7&6&4&2&1\\ 4&3&1\\ 2&1 \end{matrix}$$谁的产品是$$7\cdot6\cdot4\cdot2\cdot1\cdot4\cdot3\cdot1\cdot2\cdot1=8064.$$因此$$F(20)=\frac{10!}{8064}=450,$$与声明相符。 

为了$N=1000$，计算得出$$F(1000)\approx 8.8521816557\times 10^{21},$$再次匹配问题。 

---

 # 4.Python实现```python
from math import log, floor, lgamma

def F_scientific(N):
    # Build the Ferrers shape
    rows = []
    b = 0
    p3 = 1

    while p3 <= N:
        rows.append(int(floor(log(N / p3, 2))) + 1)
        p3 *= 3
        b += 1

    # Total number of cells
    n = sum(rows)

    # Compute log10(product of hook lengths)
    hook_log10 = 0.0

    for r, length in enumerate(rows):
        for c in range(length):

            # cells to the right
            right = length - c - 1

            # cells below
            below = 0
            for rr in range(r + 1, len(rows)):
                if rows[rr] > c:
                    below += 1

            hook = right + below + 1
            hook_log10 += log(hook, 10)

    # log10(n!)
    log10_fact = lgamma(n + 1) / log(10)

    # log10(F)
    log10_F = log10_fact - hook_log10

    exponent = int(floor(log10_F))
    mantissa = 10 ** (log10_F - exponent)

    return mantissa, exponent

m, e = F_scientific(10**18)
print(f"{m:.10f}e{e}")
```---

 # 5. 代码演练

 ### 构建形状```python
rows.append(int(floor(log(N / p3, 2))) + 1)
```对于固定$b$，这计算有效指数$a$这样$$2^a3^b \le N.$$所以每行长度恰好是允许的幂数$2$。 

---

 ### 钩子长度

 对于每个单元格：```python
right = length - c - 1
below = number of later rows extending past column c
hook = right + below + 1
```这是标准的 Young-tableau 钩长度。 

---

 ### 数值稳定性

 数字很大，所以我们计算对数：$$\log_{10} F = \log_{10}(n!) - \sum \log_{10}(h).$$

`lgamma(n+1)`计算$\log(n!)$准确。 

---

 # 6. 最终计算

 对于$N=10^{18}$，程序给出$$F(10^{18}) = 5.5350769704\times 10^{1512}.$$这与粗略的画面预期大小一致$1500$细胞。 

**答案：5.5350769704e1512**
