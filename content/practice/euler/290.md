[欧拉项目问题 290](https://projecteuler.net/problem=290)

 ## 解决方案

 **答案：**`20444710234716473`让$s(n)$表示小数位的总和$n$。 

我们求整数的个数$$0 \le n < 10^{18}$$这样$$s(n)=s(137n).$$---

 # 数学分析

 让$$n=\sum_{i=0}^{17} d_i 10^i, \qquad 0\le d_i\le 9.$$我们处理乘法$137$逐位从最低有效位到最高有效位。 

---

 ## 1. 进位下的数和行为

 假设在某个步骤我们计算$$137d_i + c_i,$$在哪里$c_i$是传入进位。 

写$$137d_i+c_i = 10c_{i+1}+e_i,$$和$e_i$的输出数字$137n$。 

然后：$$e_i = (137d_i+c_i)\bmod 10, \qquad c_{i+1}=\left\lfloor \frac{137d_i+c_i}{10}\right\rfloor.$$对数和差的贡献为$$d_i-e_i.$$处理完所有 18 位数字后，还剩下一些进位。 它的小数位也对数字和有贡献$137n$。 

因此$$s(n)-s(137n) = \sum_{i=0}^{17}(d_i-e_i) - s(c_{18}),$$在哪里$s(c_{18})$是最后进位的数字和。 

因此我们需要$$\sum_{i=0}^{17}(d_i-e_i)=s(c_{18}).$$这对于数字 DP 来说是理想的选择。 

---

 ## 2. 状态压缩

 在每个位置我们只需要：

 - 当前进位，
 - 累计差值$$\Delta=\sum(d_i-e_i).$$所以定义：$$\text{DP}(pos, carry, \Delta)$$= 从位置填充数字的方法数`pos`向前。 

在最后 （`pos = 18`），我们接受当且仅当$$\Delta = s(carry).$$进位仍然很小：$$137\cdot 9 + \text{carry} < 1400,$$所以状态空间很小。 

---

 # Python 实现```python
from functools import lru_cache

LENGTH = 18
MULTIPLIER = 137

@lru_cache(None)
def dp(pos, carry, diff):
    """
    pos   : current digit position (0 = least significant)
    carry : carry entering this position
    diff  : accumulated value of sum(d_i - e_i)
    """

    # All 18 digits processed
    if pos == LENGTH:

        # Remaining carry contributes digits to 137n
        carry_digit_sum = 0
        c = carry

        while c > 0:
            carry_digit_sum += c % 10
            c //= 10

        # Need total digit sums to match
        return 1 if diff == carry_digit_sum else 0

    total = 0

    # Choose next digit of n
    for d in range(10):

        value = MULTIPLIER * d + carry

        # Output digit of 137n
        out_digit = value % 10

        # Next carry
        next_carry = value // 10

        # Update digit-sum difference
        next_diff = diff + d - out_digit

        total += dp(pos + 1, next_carry, next_diff)

    return total

answer = dp(0, 0, 0)

print(answer)
```---

 # 小的健全性检查

 采取$n=1$：$$137n = 137.$$数字和：$$s(1)=1,\qquad s(137)=1+3+7=11.$$不相等。 

我们的 DP 拒绝这一点，因为累积的差值没有被最终进位数字平衡。
