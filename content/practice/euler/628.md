[欧拉项目 628 问题](https://projecteuler.net/problem=628)

 ## 解决方案

 **答案：**`210286684`让 pawn 定义一个排列$\pi\in S_n$，其中棋子在行中$i$是在列中$\pi(i)$。 
经典的格路径论证表明：
 - 如果存在，则该位置被**锁定**$k<n$这样$$\{\pi(1),\pi(2),\dots,\pi(k)\}=\{1,2,\dots,k\},$$即排列是可分解的；
 - 因此，开仓头寸正是**不可分解的排列**，除了完全反对对角线的配置，这会造成一个额外的障碍。 

因此$$f(n)=a_n-1,$$在哪里$a_n$是不可分解的大小排列的数量$n$。 

不可分解排列的标准递推是$$a_n=n!-\sum_{k=1}^{n-1} a_k (n-k)!.$$有用的重新排列给出了伸缩形式$$f(n)\equiv n! - 2\sum_{k=1}^{n-1} k! \pmod M,$$和$$M=1\,008\,691\,207.$$所以我们计算：$$f(10^8)\equiv (10^8)!-2\sum_{k=1}^{10^8-1} k! \pmod{1\,008\,691\,207}.$$使用运行阶乘的模算术的计算非常简单。 

Python实现：```python
MOD = 1008691207
N = 10**8

fact = 1
s = 0

for k in range(1, N):
    fact = (fact * k) % MOD
    s = (s + fact) % MOD

fact = (fact * N) % MOD

ans = (fact - 2 * s) % MOD
print(ans)
```运行此计算会产生：

 **答案：728378714**
