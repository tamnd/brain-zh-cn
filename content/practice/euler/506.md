[项目欧拉问题 506](https://projecteuler.net/problem=506)

 ## 解决方案

 **答案：**`18934502`设无限数字流为$$123432123432123432\cdots$$我们将其划分为连续的整数$v_n$使得数字和$v_n$等于$n$。 

第一项是：$$1,2,3,4,32,123,43,2123,432,1234,32123,\dots$$我们想要$$S(n)=\sum_{k=1}^{n} v_k$$特别是$$S(10^{14}) \bmod 123454321.$$---

 ## 1.数学分析

 ### 第 1 步：观察周期结构

 重复块是$$123432$$其数字和为$$1+2+3+4+3+2 = 15.$$这是关键的见解。 

由于重复块的总和为 15，因此将目标数字总和增加 15 只是附加一整个数字周期。 

例如：

 |$n$|$v_n$|
 | --- | --- |
 | 1 | 1 |
 | 16 | 16 1234321 |
 | 31 | 1234321234321 |

 同样：

 |$n$|$v_n$|
 | --- | --- |
 | 5 | 32 | 32
 | 20 | 32123432 |
 | 35 | 35 32123432123432 |

 所以对于固定残差$r=n\bmod 15$,$$n=15q+r$$数量$v_n$具有以下形式：$$v_{15q+r} = \underbrace{C_rC_r\cdots C_r}_{q\text{ copies}}\,B_r$$在哪里：

-$B_r=v_r$（基本模式），
 -$C_r$是一个6位循环块。 

例如：$$B_5=32,\qquad C_5=321234$$所以$$v_{20}=32123432.$$---

 ### 步骤 2：十进制值公式

 如果$L_r$是数字长度$B_r$， 然后$$v_{15q+r} = \left( C_r\sum_{i=0}^{q-1}10^{6i} \right)10^{L_r} + B_r.$$几何部分是$$R_q = \sum_{i=0}^{q-1}10^{6i} = \frac{10^{6q}-1}{10^6-1}.$$因此$$v_{15q+r} = C_r\,10^{L_r}R_q+B_r.$$---

 ### 第 3 步：总结所有内容$q$用于固定残留物$r$， 让$$m_r = \left\lfloor\frac{N-r}{15}\right\rfloor+1$$是项数。 

然后$$S_r = \sum_{q=0}^{m_r-1} v_{15q+r}.$$代入公式：$$S_r = m_rB_r + C_r10^{L_r} \sum_{q=0}^{m_r-1}R_q.$$现在$$\sum_{q=0}^{m-1}R_q = \frac{ \sum_{q=0}^{m-1}10^{6q}-m }{ 10^6-1 }$$和$$\sum_{q=0}^{m-1}10^{6q} = \frac{10^{6m}-1}{10^6-1}.$$一切都可以计算模$$M=123454321$$使用模逆。 

因为$$\gcd(999999,M)=1,$$模除法$M$是有效的。

 ## 2.Python实现```python
MOD = 123454321
BASE = 10**6
D = BASE - 1  # 999999

# First 15 base values v_r
B = [
    None,
    "1", "2", "3", "4", "32",
    "123", "43", "2123", "432",
    "1234", "32123", "43212",
    "34321", "23432", "123432"
]

# Corresponding repeating 6-digit blocks
C = [
    None,
    "123432", "234321", "343212", "432123",
    "321234", "123432", "432123", "212343",
    "432123", "123432", "321234", "432123",
    "343212", "234321", "123432"
]

def solve(N):
    inv_D = pow(D, -1, MOD)
    inv_geom = pow(BASE - 1, -1, MOD)

    total = 0

    for r in range(1, 16):
        if r > N:
            break

        # number of q-values
        m = (N - r) // 15 + 1

        b = int(B[r])
        c = int(C[r])
        L = len(B[r])

        # geometric sum:
        # sum_{q=0}^{m-1} 10^(6q)
        geom = (
            (pow(BASE, m, MOD) - 1)
            * inv_geom
        ) % MOD

        # sum of R_q
        sum_R = ((geom - m) % MOD) * inv_D % MOD

        contribution = (
            (m % MOD) * (b % MOD)
            + c * pow(10, L, MOD) * sum_R
        ) % MOD

        total = (total + contribution) % MOD

    return total

# Checks
print(solve(11))    # 36120
print(solve(1000))  # 18232686

# Final answer
print(solve(10**14))
```---

 ## 3. 代码演练

 -`B[r]`存储基本模式$v_r$。 
-`C[r]`存储剩余的重复 6 位循环$r$。 
- 对于每个残留类别$r=1,\dots,15$:

 - 计算最多出现多少个术语$N$,
 - 计算几何级数模$M$,
 - 计算该残基类别的总贡献，
 - 将其添加到答案中。 

### 验证

 该程序重现了示例：$$S(11)=36120$$和$$S(1000)\bmod 123454321=18232686.$$两者都与问题陈述完全匹配。
