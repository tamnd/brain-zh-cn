 ## 解决方案

 **答案：**`124999683766`## 欧拉项目 980 — “四元组 I”

 ---

 # 数学分析

 标题就是关键提示：这是四元数群$Q_8$。 

地图$$x \mapsto i,\qquad y \mapsto j,\qquad z \mapsto k$$具有四元数关系$$i^2=j^2=k^2=-1,\qquad ij=k,\quad jk=i,\quad ki=j,$$

$$ji=-k,\quad kj=-i,\quad ik=-j.$$---

 ## 步骤 1 — 解释允许的动作

 ### 移动A：插入$xx,yy,zz$例子：$$xx \mapsto i^2=-1.$$所以这将四元数值乘以$-1$。 

---

 ### 移动 B：替换$$x\to yz,\qquad y\to zx,\qquad z\to xy$$因为$$jk=i,\qquad ki=j,\qquad ij=k.$$所以四元数值不变。 

---

 ### 移动 C：交换相邻的不同字母

 示例：$$xy \leftrightarrow yx.$$但$$ij=k,\qquad ji=-k.$$交换不同的相邻字母将值乘以$-1$。 

---

 ## 步骤 2 — 奇偶校验不变量

 每个操作将四元数值的符号翻转一次：

 - 插入$aa$: 乘以$-1$,
 - 替换：步长奇偶校验发生变化，而值不变，
 - 交换：乘以$-1$。 

从有值的空字符串开始$1$，之后：

 - 偶数步→值$1$,
 - 奇数步→值$-1$。 

因此：

 > 字符串是中性的，当且仅当其四元数乘积等于$1$。 

这完全是中立的特征。 

---

 # 步骤 3 — 计算$F(N)$每个区块$c(i)$有长度$50$。 

定义其四元数值：$$q_i \in Q_8.$$然后$$c(i)c(j)\text{ is neutral} \iff q_i q_j = 1 \iff q_j = q_i^{-1}.$$所以我们只需要计算每个四元数元素有多少个块进行计算。 

---

 # 步骤 4 — 四元数乘法表

 这八个元素是$$1,-1,i,-i,j,-j,k,-k.$$它们的倒数是：$$1^{-1}=1,\quad (-1)^{-1}=-1,$$

$$i^{-1}=-i,\quad (-i)^{-1}=i,$$

$$j^{-1}=-j,\quad (-j)^{-1}=j,$$

$$k^{-1}=-k,\quad (-k)^{-1}=k.$$如果$cnt[g]$是有值的块的数量$g$， 然后$$F(N)=\sum_{g\in Q_8} cnt[g]\cdot cnt[g^{-1}].$$---

 # Python 实现```python
MOD = 888_888_883
A = 88_888_888
MULT = 8888

# Quaternion elements:
# 0:  1
# 1: -1
# 2:  i
# 3: -i
# 4:  j
# 5: -j
# 6:  k
# 7: -k

# Multiplication table
mul = [[0] * 8 for _ in range(8)]

names = ["1", "-1", "i", "-i", "j", "-j", "k", "-k"]
idx = {v: i for i, v in enumerate(names)}

base = {
    ("1", "1"): "1",
    ("1", "i"): "i",
    ("1", "j"): "j",
    ("1", "k"): "k",

    ("i", "1"): "i",
    ("j", "1"): "j",
    ("k", "1"): "k",

    ("i", "i"): "-1",
    ("j", "j"): "-1",
    ("k", "k"): "-1",

    ("i", "j"): "k",
    ("j", "k"): "i",
    ("k", "i"): "j",

    ("j", "i"): "-k",
    ("k", "j"): "-i",
    ("i", "k"): "-j",
}

def qmul(a, b):
    sa = -1 if a.startswith("-") else 1
    sb = -1 if b.startswith("-") else 1

    aa = a[1:] if a.startswith("-") else a
    bb = b[1:] if b.startswith("-") else b

    r = base[(aa, bb)]

    sr = -1 if r.startswith("-") else 1
    rr = r[1:] if r.startswith("-") else r

    sign = sa * sb * sr

    if rr == "1":
        return "1" if sign == 1 else "-1"

    return rr if sign == 1 else "-" + rr

# Build numeric multiplication table
for i, a in enumerate(names):
    for j, b in enumerate(names):
        mul[i][j] = idx[qmul(a, b)]

# map:
# x -> i
# y -> j
# z -> k
letter_map = [2, 4, 6]

N = 10**6

counts = [0] * 8
a = A

for _ in range(N):

    q = 0  # quaternion value starts at 1

    for _ in range(50):
        b = a % 3
        q = mul[q][letter_map[b]]
        a = (MULT * a) % MOD

    counts[q] += 1

inverse = [0, 1, 3, 2, 5, 4, 7, 6]

answer = 0
for g in range(8):
    answer += counts[g] * counts[inverse[g]]

print(answer)
```---

 ## RNG生成

 顺序是：$$a_n = 8888 a_{n-1}\pmod{888888883}.$$对于每个生成的值：```python
b = a % 3
```我们绘制地图：

 - 0 →$i$,
 - 1 →$j$,
 - 2 →$k$。 

每个块恰好使用 50 个符号。 

---

 ## 计算块数

 对于每个块，我们计算其四元数乘积`q`。 

然后：```python
counts[q] += 1
```---

 ## 最终计数

 一对贡献当且仅当：$$q_i q_j = 1.$$因此：```python
counts[g] * counts[inverse[g]]
```对于每个组元素$g$。
