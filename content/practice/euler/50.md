[项目欧拉问题 50](https://projecteuler.net/problem=50)

 ## 解决方案

 **答案：**`997651`## 1.数学分析

 我们想要下面的素数$10^6$可以写成 **最连续素数的总和**。 

例如：$$41 = 2+3+5+7+11+13$$它使用 6 个连续的素数。 

蛮力方法是：

 - 生成一百万以下的所有素数。 
- 尝试每个连续的子序列。 
- 检查总和是否为质数。 

但天真的这太慢了，因为下面有数以万计的素数$10^6$。 

### 步骤 1：高效生成所有素数

 我们使用**埃拉托斯特尼筛**来生成每一个百万以下的素数。 

只有：$$\pi(10^6)=78498$$质数低于 100 万，这是可以管理的。 

我们还将它们存储在**集合**中$O(1)$素性查找。 

---

 ### 步骤 2：使用前缀和进行连续求和

 假设素数是：$$p_0,p_1,p_2,\dots$$定义前缀和数组：$$S_k = \sum_{i=0}^{k-1} p_i$$和：$$S_0=0$$那么任意连续的素数和就变成：$$p_i+p_{i+1}+\cdots+p_{j-1} = S_j-S_i$$这是关键的优化。 

我们可以在常数时间内获得任意区间和，而不是重复地重新计算和。 

---

 ### 第三步：搜索最长有效链

 我们寻求**最大长度**$L$这样：$$S_j - S_i$$是：

 1. 小于$10^6$2. 总理

 对于某些人来说$j-i=L$。 

优化思路：

 #### (a) 只检查比当前最佳序列更长的序列

 如果我们已经找到长度为 100 的序列，则没有必要检查长度低于 100 的序列。 

#### (b) 当金额超过一百万时停止

 因为素数是递增的，一旦总和超过限制，延长间隔只会使其变得更大。 

这使搜索保持高效。 

---

 ## 2.Python实现```python
LIMIT = 1_000_000

# -----------------------------
# Sieve of Eratosthenes
# -----------------------------
is_prime = [True] * LIMIT
is_prime[0] = is_prime[1] = False

for i in range(2, int(LIMIT ** 0.5) + 1):
    if is_prime[i]:
        for multiple in range(i * i, LIMIT, i):
            is_prime[multiple] = False

# List of primes
primes = [i for i, prime in enumerate(is_prime) if prime]

# Fast primality lookup
prime_set = set(primes)

# -----------------------------
# Prefix sums
# prefix[i] = sum of first i primes
# -----------------------------
prefix = [0]

for p in primes:
    prefix.append(prefix[-1] + p)

# -----------------------------
# Find longest consecutive sum
# -----------------------------
best_length = 0
best_prime = 0

n = len(primes)

for start in range(n):
    # No need to check lengths shorter than current best
    for end in range(start + best_length + 1, n + 1):

        current_sum = prefix[end] - prefix[start]

        # Stop if over limit
        if current_sum >= LIMIT:
            break

        # Check if prime
        if current_sum in prime_set:
            best_length = end - start
            best_prime = current_sum

print(best_prime)
```---

```我们只需要筛选到$\sqrt{10^6}$。 

对于每个素数$i$，将倍数标记为合数。

```这给出了一百万以下的所有素数。

prime_set = set(primes)

```---

 ### 搜索最长序列

 对于每个起始位置：```python

```我们尝试结束立场。 

关键优化：```python

```如果：```python

```我们立即停止，因为更长的间隔只会增加总和。 

如果总和是素数：```python

```我们更新最好的结果。
