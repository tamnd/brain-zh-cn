[欧拉项目问题 141](https://projecteuler.net/problem=141)

 ## 解决方案

 **答案：**`878454337159`让$$n = dq + r,\qquad 0 \le r < d$$并假设$d,q,r$是几何级数的连续项（按某种顺序）。 

我们想要所有这样的$n$也是完全平方数，其中$$n < 10^{12}.$$---

 # 1.数学分析

 我们首先对几何级数进行参数化。 

假设这三个项是$$a,\quad ar,\quad ar^2$$对于某个合理的比例$r$。 

自从$d,q,r$是整数，将比率写成最低项$$\frac{u}{v}, \qquad \gcd(u,v)=1.$$那么连续的 GP 项可以写为$$kv^2,\quad kuv,\quad ku^2$$对于正整数$k,u,v$和$\gcd(u,v)=1$。 

因为商大于余数，所以唯一可能的排序是$$r = kv^2,\qquad d = kuv,\qquad q = ku^2,$$因为否则$r\ge d$， 不可能的。 

现在代入$$n = dq + r.$$我们得到$$n = (kuv)(ku^2) + kv^2$$所以$$n = k^2u^3v + kv^2.$$因素：$$n = kv(ku^2 + v).$$所以每个渐进数都有这样的形式$$\boxed{n = kv(ku^3 + v)}.$$---

 ## 强制平方条件

 我们现在要求$n$成为一个完美的正方形。 

一个关键的见解是分离无方形零件。 

让$$k = a b^2,$$在哪里$a$是无平方的。 

然后$$n = ab^2v(ab^2u^3 + v).$$因为$\gcd(u,v)=1$, 可以显示$$\gcd(v,\,ab^2u^3+v)=1.$$因此这两个因素$$v,\qquad ab^2u^3+v$$是互质的。 

自从他们的产品时代以来$a$是一个正方形，每个互素分量必须适当地吸收无正方形部分。 

放$$v = ac^2,$$然后$$ab^2u^3 + v = ad^2.$$代替$v=ac^2$:$$ab^2u^3 + ac^2 = ad^2.$$除以$a$:$$b^2u^3 + c^2 = d^2.$$因此$$d^2 - c^2 = b^2u^3.$$因素：$$(d-c)(d+c)=b^2u^3.$$此时暴力搜索就变得可行了。 

---

 # 更实用的参数化

 标准简化直接来自$$n = kv(ku^3+v).$$因为$\gcd(v,ku^3)=1$，我们还有$$\gcd(v,ku^3+v)=1.$$如果$n$是平方，两个互质因子必须各自平方到一个公共的无平方因子。 

所以让$$v = as^2,\qquad ku^3+v = at^2,$$和$a$无平方。 

减去：$$ku^3 = a(t^2-s^2)=a(t-s)(t+s).$$这自然会导致有效的枚举。 

然而，大多数快速解决方案都使用更干净的路线。 

---

 # 关键代数约简

 写$$k = m^2 n, \qquad v = n r^2,$$和$n$无平方。 

然后$$N = kv(ku^3+v)$$变成$$N = m^2 n^2 r^2(m^2u^3+r^2).$$因此$N$是平方当且仅当$$m^2u^3+r^2$$是正方形的。 

让$$m^2u^3+r^2=s^2.$$然后$$(s-r)(s+r)=m^2u^3.$$现在设置$$s-r=a,\qquad s+r=b,$$所以$$ab=m^2u^3.$$自从$a,b$具有相同的奇偶性，$$r=\frac{b-a}{2}, \qquad s=\frac{a+b}{2}.$$这给出了完整的参数化。 

---

 # 高效枚举

 计算上更方便的公式来自恒等式$$n = x^2 y^3 z^2 + xyz^2$$和$$\gcd(x,y)=1.$$搜索范围足够小，因为$$x^2 y^3 z^2 < 10^{12}.$$可以列举：

 -$y$最多约$10^4$,
 -$x$最多$\sqrt{10^{12}/y^3}$,
 -$z$同样有界。 

对找到的所有方块进行重复数据删除。 

---

 # 2.Python实现```python
from math import isqrt, gcd

LIMIT = 10**12

# Use a set to avoid duplicates
progressive_squares = set()

# From:
# n = k*v*(k*u^3 + v)
#
# Let:
#   k = a*b^2
#   v = a*c^2
#
# Then:
#   n = a^2 * b^2 * c^2 * (a*b^2*u^3 + c^2)
#
# Therefore n is square iff:
#   a*b^2*u^3 + c^2
# is a square.
#
# We enumerate:
#   u, a, b, c
# under the size bound.

max_u = int(LIMIT ** (1/3)) + 2

for u in range(1, max_u):

    u3 = u**3

    # minimal contribution already grows like a^2*b^2*c^2*u^3
    # so a,b,c ranges are small.

    max_ab = isqrt(LIMIT // u3) + 1

    for a in range(1, max_ab + 1):

        # c must remain manageable
        for b in range(1, max_ab + 1):

            base = a * b * b * u3

            if base >= LIMIT:
                break

            # derive c bound from:
            # n = a^2*b^2*c^2*(base + c^2) < LIMIT

            max_c = isqrt(LIMIT // (a*a*b*b)) + 1

            for c in range(1, max_c + 1):

                # coprimality condition inherited from GP structure
                if gcd(u, c) != 1:
                    continue

                t = base + c*c
                s = isqrt(t)

                if s*s != t:
                    continue

                n = a*a*b*b*c*c*t

                if n >= LIMIT:
                    break

                root = isqrt(n)
                if root * root == n:
                    progressive_squares.add(n)

answer = sum(progressive_squares)

print(answer)
```---
