[欧拉项目问题 223](https://projecteuler.net/problem=223)

 ## 解决方案

 **答案：**`61614848`让$$a^2+b^2=c^2+1, \qquad a\le b\le c$$有周边$$a+b+c\le 25{,}000{,}000.$$我们想要计算所有边长为整数的“勉强锐角”三角形。 

## 1.数学分析

 重新排列定义方程：$$a^2+b^2=c^2+1$$作为$$a^2-1=c^2-b^2=(c-b)(c+b).$$定义$$x=c-b,\qquad y=c+b.$$然后$$xy=a^2-1.$$自从$$b=\frac{y-x}{2},\qquad c=\frac{y+x}{2},$$我们要求：

 1.$x,y$具有相同的奇偶性（所以$b,c$是整数），
 2.$x>0$,
 3.$a\le b$， IE。$$a \le \frac{y-x}{2}$$这变成$$y-x\ge 2a.$$周长条件也变为$$a+b+c=a+y\le N,$$在哪里$N=25{,}000{,}000$。 

所以对于每个固定的$a$，我们正在计算除数$x\mid(a^2-1)$这样$$x\le y=\frac{a^2-1}{x},$$

$$\frac{a^2-1}{x}-x\ge 2a,$$和$$a+\frac{a^2-1}{x}\le N.$$因为$y=(a^2-1)/x$，约束条件变为：

 ### 上限$x$从$y-x\ge 2a$:$$\frac{a^2-1}{x}-x\ge 2a.$$乘以$x$:$$a^2-1\ge x^2+2ax.$$重新排列：$$(x+a)^2\le 2a^2-1.$$因此$$x\le \sqrt{2a^2-1}-a.$$### 下界$x$从周边：$$a+\frac{a^2-1}{x}\le N$$所以$$x\ge \frac{a^2-1}{N-a}.$$因此，对于每个$a$，我们计算除数$x$的$a^2-1$躺在间隔中$$\left\lceil \frac{a^2-1}{N-a} \right\rceil \le x\le \left\lfloor \sqrt{2a^2-1}-a \right\rfloor,$$有奇偶条件$x+y$甚至。 

### 特殊情况$a=1$如果$a=1$,$$1+b^2=c^2+1 \Rightarrow b=c.$$所以每个三角形$(1,b,b)$提供的作品$$1+2b\le N.$$这有助于$$\left\lfloor\frac{N-1}{2}\right\rfloor$$解决方案。

 ## 2.Python实现```python
from math import isqrt

N = 25_000_000
A_MAX = N // 3 + 1

def build_spf(limit):
    """Smallest prime factor sieve."""
    spf = list(range(limit + 1))

    for i in range(2, isqrt(limit) + 1):
        if spf[i] == i:  # i is prime
            for j in range(i * i, limit + 1, i):
                if spf[j] == j:
                    spf[j] = i

    return spf

spf = build_spf(A_MAX + 1)

# Special case a = 1
count = (N - 1) // 2

for a in range(2, A_MAX + 1):
    n = a * a - 1

    # Bounds on divisor x
    lower = (n + (N - a) - 1) // (N - a)
    upper = isqrt(2 * a * a - 1) - a

    # Factorise (a-1)(a+1)
    factors = {}

    for z in (a - 1, a + 1):
        while z > 1:
            p = spf[z]
            e = 0

            while z % p == 0:
                z //= p
                e += 1

            factors[p] = factors.get(p, 0) + e

    factor_items = list(factors.items())

    # Enumerate divisors <= upper
    stack = [(0, 1)]

    while stack:
        idx, cur = stack.pop()

        if idx == len(factor_items):
            if cur >= lower:
                y = n // cur

                # Same parity condition
                if ((cur + y) & 1) == 0:
                    count += 1
        else:
            p, e = factor_items[idx]
            value = 1

            for _ in range(e + 1):
                nxt = cur * value

                if nxt <= upper:
                    stack.append((idx + 1, nxt))
                else:
                    break

                value *= p

print(count)

 ## 3. 代码演练

 ### SPF 筛子

 我们预先计算每个整数的**最小质因数**$$\frac{N}{3}$$自从$a \le N/3$。 

这允许非常快速地分解$a-1$和$a+1$。 

### 循环$a$对于每个$a$:

 - 计算$$n=a^2-1$$- 导出有效除数区间$[L,U]$，
- 因素$$n=(a-1)(a+1),$$- 生成除数$x$的$n$最多$U$,
 - 检查奇偶校验和周长约束。 

每个有效除数恰好对应一个三角形。 

### 小健全性检查

 对于周长$\le 100$，该方法找到 72 个三角形，包括：$$(4,7,8), \quad (5,5,7), \quad (8,9,12), \quad (29,29,41),$$和无限的家庭$$(1,b,b).$$这与暴力枚举相匹配。
