[项目欧拉问题 686](https://projecteuler.net/problem=686)

 ## 解决方案

 **答案：**`193060223`让$$x_j = j\log_{10}2.$$然后$$2^j = 10^{x_j}.$$写$$x_j = k + f_j,$$在哪里$k=\lfloor x_j\rfloor$和$f_j\in[0,1)$是小数部分。 

然后$$2^j = 10^k\cdot 10^{f_j},$$所以前导数字$2^j$完全由$10^{f_j}$。 

我们想要十进制展开$2^j$首先$L=123$。 

---

 # 1.数学分析

 数字以数字开头$123$当且仅当它位于区间内$$[123\cdot 10^m,\;124\cdot 10^m)$$对于某个整数$m$。 

所以$2^j$开始于$123$当且仅当$$123 \le 10^{f_j} < 124.$$除以$100$,$$1.23 \le 10^{f_j} < 1.24.$$服用$\log_{10}$,$$\log_{10}(1.23)\le f_j < \log_{10}(1.24).$$定义$$a=\log_{10}(1.23),\qquad b=\log_{10}(1.24).$$那么我们需要$$\{j\log_{10}2\}\in[a,b).$$那么问题就变成了：

 > 找到$678910$第一个整数$j$这样的小数部分
 >
 >
 >
 >
 >$$j\alpha,\qquad \alpha=\log_{10}2$$>
 >
 >
 >
 > 位于区间内$[a,b)$。 

因为$\alpha$是无理数，则序列$$\{j\alpha\}$$是均匀分布的 mod 1。 

区间长度为$$b-a = \log_{10}(1.24)-\log_{10}(1.23) = \log_{10}\!\left(\frac{124}{123}\right) \approx 0.003516.$$所以大约有百分之一$$\frac1{0.003516}\approx 284$$权力有效。 

因此我们期望答案接近$$678910\times 284 \approx 1.93\times 10^8.$$这与实际答案的已知范围相匹配。 

---

 # 2.高效算法

 在 Python 中，直接暴力扫描实际上已经足够快了，因为只有大约$2\times10^8$需要迭代，每次迭代只是一次浮点加法模 1。 

我们迭代：$$f_{j+1} = (f_j+\alpha)\bmod 1.$$每当$$a\le f_j < b,$$我们增加一个计数器。 

当计数器达到$678910$，当前的$j$就是答案。 

---

 # 3.Python实现```python
import math

# Constants
alpha = math.log10(2)

# Interval corresponding to leading digits 123
a = math.log10(1.23)
b = math.log10(1.24)

target = 678910

count = 0
frac = 0.0
j = 0

while True:
    j += 1

    # fractional part of j * log10(2)
    frac += alpha
    frac -= math.floor(frac)

    # check whether leading digits are 123
    if a <= frac < b:
        count += 1

        if count == target:
            print(j)
            break
```---
