[欧拉项目问题 34](https://projecteuler.net/problem=34)

 ## 解决方案

 **答案：**`40730`我们寻找所有整数$n$这样$$n = \sum (\text{factorial of each digit of } n).$$例如，$$145 = 1! + 4! + 5! = 1 + 24 + 120.$$我们必须找到所有这些数字的总和，排除琐碎的一位数情况$1$和$2$。 

---

 # 数学分析

 ## 步骤 1：预先计算数字阶乘

 数字的阶乘$0$通过$9$是：$$\begin{aligned} 0! &= 1\\ 1! &= 1\\ 2! &= 2\\ 3! &= 6\\ 4! &= 24\\ 5! &= 120\\ 6! &= 720\\ 7! &= 5040\\ 8! &= 40320\\ 9! &= 362880 \end{aligned}$$由于每个数字都是由十进制数字组成的，因此可以通过对这些值求和来检查任何候选数字。 

---

 ## 步骤 2：找到上限

 除非我们首先建立一个有限范围，否则不可能对所有整数进行强力搜索。 

假设一个数有$d$数字。 

当每个数字都是时，其数字的阶乘之和就会出现_最大可能_$9$：$$d \times 9!$$因为$9! = 362880$。 

所以任何$d$-数字解必须满足$$n \le d \cdot 9!$$但一个$d$-位数至少为$$10^{d-1}.$$因此我们要求$$10^{d-1} \le d \cdot 9!.$$现在测试值$d$：

 -$7 \cdot 9! = 2540160$，这只是一个 7 位数字。 
-$8 \cdot 9! = 2903040$，这仍然只是一个 7 位数字。 

但每个8位数字至少$10^7 = 10000000$。 

因此对于$d \ge 8$,$$d \cdot 9! < 10^{d-1},$$所以不存在 8 位（或更大）的解。 

因此我们只需要搜索到$$7 \cdot 9! = 2540160.$$这使得暴力破解完全可行。 

---

 ## 步骤 3：算法

 对于每个整数$n$从$10$到$2540160$：

 1. 分裂$n$化为十进制数字。 
2. 将每个数字替换为其阶乘。 
3. 对这些阶乘求和。 
4. 检查总和是否等于$n$。 

收集所有这些数字并求和。 

已知的例子有：$$145,\quad 40585$$他们的总和是$$145 + 40585 = 40730.$$---

 # Python 实现```python
# Precompute factorials of digits 0-9
factorials = [1] * 10

for i in range(1, 10):
    factorials[i] = factorials[i - 1] * i

# Maximum possible candidate:
# 7 * 9! because larger digit counts cannot work
upper_bound = 7 * factorials[9]

total = 0
curious_numbers = []

# Start from 10 because 1 and 2 are excluded
for n in range(10, upper_bound + 1):

    # Sum factorials of digits
    digit_factorial_sum = sum(factorials[int(d)] for d in str(n))

    # Check if n satisfies the condition
    if digit_factorial_sum == n:
        curious_numbers.append(n)
        total += n

print("Curious numbers:", curious_numbers)
print("Sum:", total)
```---

 # 小例子验证

 对于$145$：$$1! + 4! + 5! = 1 + 24 + 120 = 145$$为了$40585$：$$4! + 0! + 5! + 8! + 5! = 24 + 1 + 120 + 40320 + 120 = 40585$$这些正是不平凡的解决方案。 

他们的总和是：$$145 + 40585 = 40730.$$---
