[欧拉项目问题 235](https://projecteuler.net/problem=235)

 ## 解决方案

 **答案：**`1.002322108633`我们给出了算术几何数列$$u(k)=(900-3k)r^{k-1},$$和$$s(n)=\sum_{k=1}^n u(k).$$我们必须找到价值$r$这样$$s(5000)=-600000000000.$$答案必须四舍五入为$12$小数位。 

---

 # 数学分析

 我们想要解决$$\sum_{k=1}^{5000}(900-3k)r^{k-1}=-6\times10^{11}.$$定义$$S(r)=\sum_{k=1}^{5000}(900-3k)r^{k-1}.$$我们寻求根源$$F(r)=S(r)+6\times10^{11}=0.$$---

 ## 为什么二分查找有效

 观察：

 - 在$r=1$,$$S(1)=\sum_{k=1}^{5000}(900-3k),$$与$6\times10^{11}$。 

- 作为$r$增加以上$1$，后面的否定项占主导地位，因为：

 - 最终$900-3k<0$，
- 和$r^{k-1}$呈指数级增长。 

因此$S(r)$迅速且持续地减少。 

因此，在某个区间内存在唯一解，例如$[1,2]$，使二分查找变得理想。 

---

 # 数值策略

 我们计算$$S(r)=\sum_{k=1}^{5000}(900-3k)r^{k-1}$$直接使用浮点运算。 

然后：

 - 如果$S(r)>-6\times10^{11}$，我们需要更大的$r$,
 - 否则我们需要更小的$r$。 

我们反复平分区间，直到$$|r_{\text{high}}-r_{\text{low}}|<10^{-15}.$$最后我们四舍五入到$12$小数位。 

---

 # Python 实现```python
TARGET = -600000000000.0

def S(r):
    total = 0.0
    power = 1.0  # r^(k-1)

    for k in range(1, 5001):
        total += (900 - 3 * k) * power
        power *= r

    return total

# Binary search interval
low = 1.0
high = 2.0

# Perform binary search
while high - low > 1e-15:
    mid = (low + high) / 2.0

    if S(mid) > TARGET:
        low = mid
    else:
        high = mid

r = (low + high) / 2.0

print(f"{r:.12f}")
```---
