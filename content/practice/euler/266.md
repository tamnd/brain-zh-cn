[欧拉项目问题 266](https://projecteuler.net/problem=266)

 ## 解决方案

 **答案：**`1096883702440585`让$$p=\prod_{\substack{q\text{ prime}\\ q<190}} q.$$我们求最大的除数$p$不超过$\sqrt p$。 自从$p$是无平方的，每个除数对应于选择下面素数的子集$190$。 

于是问题就变成了：

 > 选择下面素数的子集$190$其乘积尽可能大，同时剩余$\le \sqrt p$。 

等价地，取对数：$$\log d=\sum_{q\in S}\log q$$必须尽可能接近$$\frac12 \log p.$$这是一个经典的**平衡子集产品/背包**问题，正确的方法是**中间相遇**搜索。 

---

 # 1.数学分析

 下面的素数$190$是$$2,3,5,7,\dots,181.$$有$42$这样的素数，所以对所有子集的暴力破解需要检查$$2^{42}\approx 4.4\times 10^{12}$$子集——直接不可能。 

---

 ## 重新制定

 让$$p=\prod_{i=1}^{42} p_i.$$的每个除数$p$有形式$$d=\prod_{i\in S} p_i$$对于某些子集$S$。 

我们想要$$d\le \sqrt p$$和$d$最大。 

获取日志：$$\log d=\sum_{i\in S}\log p_i.$$自从$$\log \sqrt p=\frac12\sum_{i=1}^{42}\log p_i,$$我们希望对数的子集和尽可能接近总数的一半，但不超过它。 

---

 # 2. 中间会面

 将素数分成两半：

 - 左半边$L$- 右半边$R$每一半大约有$21$素数。 

对于每个子集$L$，计算：

 - 其对数和
 - 其确切的产品

 同样对于$R$。 

每一方只有$$2^{21}=2,097,152$$子集，这是可管理的。 

---

 ## 关键思想

 假设左子集具有对数和$x$。 

那么右子集必须满足$$y \le T-x$$在哪里$$T=\frac12\log p.$$因此，对于每个左子集，我们对右子集进行二分搜索以获得最大的可行值$y$。 

相应的精确乘积相乘，我们保留最大的有效乘积。 

---

 # 3.Python实现```python
from math import log
from bisect import bisect_right

# Generate primes below 190
def primes_below(n):
    sieve = [True] * n
    sieve[0] = sieve[1] = False

    for i in range(2, int(n**0.5) + 1):
        if sieve[i]:
            for j in range(i * i, n, i):
                sieve[j] = False

    return [i for i, v in enumerate(sieve) if v]

primes = primes_below(190)

# Total logarithmic target
total_log = sum(log(p) for p in primes)
target = total_log / 2

# Split primes into two halves
mid = len(primes) // 2
A = primes[:mid]
B = primes[mid:]

# Enumerate all subset products and log sums
def subset_data(arr):
    n = len(arr)
    out = []

    for mask in range(1 << n):
        prod = 1
        s = 0.0

        for i in range(n):
            if mask & (1 << i):
                prod *= arr[i]
                s += log(arr[i])

        out.append((s, prod))

    return out

left = subset_data(A)
right = subset_data(B)

# Sort right subsets by logarithmic sum
right.sort()

right_logs = [x[0] for x in right]

best = 0

# For each left subset, binary search best compatible right subset
for ls, lp in left:

    remain = target - ls

    idx = bisect_right(right_logs, remain) - 1

    if idx >= 0:
        rp = right[idx][1]
        candidate = lp * rp

        if candidate > best:
            best = candidate

# Required modulo
answer = best % (10**16)

print(answer)
```---
