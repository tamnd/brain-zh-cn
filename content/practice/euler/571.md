[欧拉项目问题 571](https://projecteuler.net/problem=571)

 ## 解决方案

 **答案：**`30510390701978`让$N$是一个$12$-超泛数字。 

数字是泛数字基数$b$如果每个数字$0,1,\dots,b-1$在其基地中至少出现一次$b$表示。 

我们求总和$10$每个碱基中泛数字的最小数字$2$通过$12$。 

---

 # 1.数学分析

 ## 步骤 1：基础结构$12$一个基地-$12$泛数字号码必须包含所有数字$$0,1,2,\dots,11$$至少一次。 

_最小的_此类数字显然将仅使用每个数字一次，因为：

 - 使用任何数字两次会强制使用更长的表示形式，
 - 较长的表示会自动变大。 

因此，最小解决方案中的每个候选都是 12 个碱基的排列$12$数字：$$(0,1,2,\dots,11)$$前导数字非零。 

因此每个候选者恰好有 12 个碱基$12$数字。 

因此有$$11 \cdot 11! = 39,916,800$$可能的候选人。 

这听起来很大，但通过优化搜索完全可以管理。 

---

 ## 步骤 2：有效测试泛数字性

 对于每个候选整数$N$，以及每个碱基$b\in\{2,\dots,11\}$:

 1. 反复除以$b$,
 2.使用位掩码记录遇到的数字，
 3. 验证每个数字$0,\dots,b-1$出现了。 

如果最终位掩码等于$$(1 \ll b)-1,$$那么该数字在基数中是泛数字的$b$。 

由于我们以递增的数字顺序（基本的字典顺序）生成候选者$12$数字），遇到的前 10 个有效数字恰好是最小的 10 个$12$-超泛数字。

 # 2.Python实现```python
from itertools import permutations

# ---------------------------------------------------------
# Check whether n is pandigital in base b
# ---------------------------------------------------------
def is_pandigital(n, b):
    seen = 0

    while n > 0:
        digit = n % b
        seen |= (1 << digit)
        n //= b

    # all digits 0..b-1 must appear
    return seen == (1 << b) - 1

# ---------------------------------------------------------
# Search for the 10 smallest 12-super-pandigital numbers
# ---------------------------------------------------------
found = []
total = 0

digits = range(12)

for perm in permutations(digits):

    # leading digit cannot be zero
    if perm[0] == 0:
        continue

    # interpret permutation as a base-12 number
    n = 0
    for d in perm:
        n = n * 12 + d

    # test bases 11 down to 2
    ok = True
    for b in range(11, 1, -1):
        if not is_pandigital(n, b):
            ok = False
            break

    if ok:
        found.append(n)
        total += n

        if len(found) == 10:
            break

print(found)
print(total)
```---
