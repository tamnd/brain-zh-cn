[欧拉项目问题 9](https://projecteuler.net/problem=9)

 ## 解决方案

 我们寻求一个满足的毕达哥拉斯三元组$a^2+b^2=c^2⟦PROTECT_2⟧b⟦PROTECT_3⟧a^2 + b^2 = c^2 \approx 225.00 + 225.00 = 450.00$调整 a 和 b 更新三角形和 c.abc 的导出值

 与$$a+b+c=1000.$$代替$c = 1000-a-b$代入毕达哥拉斯方程：$$a^2+b^2=(1000-a-b)^2.$$扩展和简化：$$a^2+b^2=1000000+a^2+b^2+2ab-2000a-2000b,$$所以$$0=1000000+2ab-2000a-2000b.$$除以$2$:$$ab-1000a-1000b=-500000.$$重新排列：$$(a-1000)(b-1000)=500000.$$搜索因子对会产生：$$a=200,\quad b=375,\quad c=425.$$查看：$$200^2+375^2=40000+140625=180625=425^2.$$和：$$200+375+425=1000.$$所以，$$abc = 200 \times 375 \times 425 = 31875000.$$Python代码：```python
for a in range(1, 1000):
    for b in range(a + 1, 1000):
        c = 1000 - a - b
        if a*a + b*b == c*c:
            print(a * b * c)
```追踪逻辑找到唯一的三元组$(200,375,425)$，生产：```python
31875000
```**答案：31875000**
