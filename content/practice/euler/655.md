[项目欧拉问题 655](https://projecteuler.net/problem=655)

 ## 解决方案

 **答案：**`2000008332`让$M=10{,}000{,}019$。 

我们必须计算回文数$<10^{32}$可除以$M$。 

---

 # 数学分析

 长度的回文$L$完全由它的第一个决定$$h=\left\lceil \frac L2 \right\rceil$$数字。 

设这些数字为$$d_0,d_1,\dots,d_{h-1}$$在哪里$d_0\neq 0$。 

---

 ## 1. 写回文模$M$数字$d_j$出现在两个对称位置：

 - 位置$j$- 位置$L-1-j$除了中间的数字$L$很奇怪。 

因此$$P \equiv \sum_{j=0}^{h-1} d_j c_j \pmod M$$在哪里$$c_j = \begin{cases} 10^j + 10^{L-1-j} \pmod M, & \text{normally}\\[4pt] 10^j \pmod M, & \text{middle digit of odd }L \end{cases}$$那么问题就变成了：

 > 计算数字分配，使得
 >
 >
 >
 >
 >$$\sum d_j c_j \equiv 0 \pmod M$$和$d_0\in\{1,\dots,9\}$和所有其他数字$\{0,\dots,9\}$。 

---

 ## 2. 留数动态规划

 定义：$$dp[r] = \text{number of ways to obtain residue } r$$最初：$$dp[0]=1$$对于每个数字位置$j$，通过尝试所有允许的数字进行转换。 

如果我们放置数字$d$,$$r \to (r+d\,c_j)\bmod M$$最后给出长度的答案$L$是$dp[0]$。 

我们对所有长度重复此操作$1\le L\le 32$。 

---

 ## 3. 复杂性

 -$M=10{,}000{,}019$- 最大半长是$16$因此 DP 在优化的低级代码（或带有数组的 PyPy）中是可行的。 

获得的总计数为：$$\boxed{2{,}000{,}008{,}332}$$---

 # Python 实现```python
from array import array

MOD = 10_000_019

# Precompute powers of 10 modulo MOD
pow10 = [1] * 40
for i in range(1, 40):
    pow10[i] = (pow10[i - 1] * 10) % MOD

def count_length(L):
    """
    Count palindromes of exact length L divisible by MOD.
    """
    h = (L + 1) // 2

    # coefficients c_j
    coeff = []

    for j in range(h):
        # middle digit in odd length
        if (L % 2 == 1) and (j == h - 1):
            c = pow10[j]
        else:
            c = (pow10[j] + pow10[L - 1 - j]) % MOD

        coeff.append(c)

    # DP over residues
    dp = array('I', [0]) * MOD
    dp[0] = 1

    for j, c in enumerate(coeff):

        ndp = array('I', [0]) * MOD

        # leading digit cannot be zero
        digits = range(1, 10) if j == 0 else range(10)

        for r in range(MOD):
            cur = dp[r]
            if cur == 0:
                continue

            for d in digits:
                nr = (r + d * c) % MOD
                ndp[nr] += cur

        dp = ndp

    return dp[0]

answer = 0

for L in range(1, 33):
    answer += count_length(L)

print(answer)
```---

 # 代码演练

 ## 预计算能力```python
pow10[i] = 10^i mod MOD
```需要这些来确定每个数字在回文中的贡献位置。 

---

 ## 建筑系数

 对于每个镜像数字对：```python
10^j + 10^(L-1-j)
```因为数字出现在两个位置。 

对于奇数长度，中间数字仅出现一次。 

---

 ## DP 状态```python
dp[r]
```存储有多少个部分回文产生残留`r`。 

---

 ## 过渡

 尝试数字`d`更新：```python
nr = (r + d * c) % MOD
```---

 ## 最终计数

 处理完所有位置后：```python
dp[0]
```是该长度的可整除回文数。
