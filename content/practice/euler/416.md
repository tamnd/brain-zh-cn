[欧拉项目 416 问题](https://projecteuler.net/problem=416)

 ## 解决方案

 **答案：**`898082747`让$L=n-1$。 

一次完整的去程或归程只是以下内容的组合$L$分成几部分$1,2,3$。 

为了$m$往返有$$p=2m$$独立的单调路径$0$到$L$。 

关键的观察是，我们可以从左到右扫描棋盘，只需要知道每条路径的下一个着陆点距离多远。 

对于位置处的单个路径$t$：

- 状态$0$：路径着陆于$t$，
- 状态$1$: 下一次着陆是在$t+1$，
- 状态$2$: 下一次着陆是在$t+2$。 

如果路径当前处于状态$0$，然后落地后选择长度的跳跃$1,2,3$，产生新的状态$0,1,2$分别。 

对于所有人$p$路径在一起，整个系统仅由计数来描述$$(a,b,c),$$在哪里

-$a$路径处于状态$0$,
 -$b$路径处于状态$1$,
 -$c$路径处于状态$2$，

和$$a+b+c=p.$$因此自动机状态的数量是$$\binom{p+2}{2}.$$为了$p=20$，这只是$231$。 

---

 在一个室内广场$t$，当且仅当访问该正方形$a>0$。 

因此，我们通过一点信息来增强状态，告诉我们是否已经看到了一个未访问过的方块。 

所以状态总数只有$$231 \times 2 = 462.$$这给出了有限线性过渡系统，所以$F(m,n)$可以通过快速矩阵求幂来计算$O(\log n)$。 

因为所需的模数是$$10^9 = 2^9\cdot 5^9,$$我们分别计算模$512$和模$1953125$，其中 64 位矩阵乘法是安全的，然后与 CRT 结合。 

转移规则为：

 如果当前状态是$(a,b,c)$，那么其中$a$着陆路径选择

 -$x$跳跃长度$1$,
 -$y$跳跃长度$2$,
 -$z$跳跃长度$3$，

和$x+y+z=a$。 

下一个状态是$$(b+x,\; c+y,\; z),$$具有多重性$$\binom{a}{x,y,z}.$$---

 Python实现：```python
import numpy as np
from math import comb

MOD1 = 512
MOD2 = 1953125

def solve_mod(mod):
    m = 10
    p = 2 * m
    L = 10**12 - 1

    # Enumerate all (a,b,c), a+b+c=p
    states = []
    idx = {}

    for a in range(p + 1):
        for b in range(p + 1 - a):
            c = p - a - b
            idx[(a, b, c)] = len(states)
            states.append((a, b, c))

    S = len(states) * 2   # extra bit = already used one unvisited square

    A = np.zeros((S, S), dtype=np.int64)
    B = np.zeros((S, S), dtype=np.int64)

    # Build transition matrices
    for si, (a, b, c) in enumerate(states):

        trans = []

        for x in range(a + 1):
            for y in range(a - x + 1):
                z = a - x - y

                mult = comb(a, x) * comb(a - x, y)
                mult %= mod

                nxt = (b + x, c + y, z)
                ni = idx[nxt]

                trans.append((ni, mult))

        for used in range(2):

            row = si * 2 + used

            for ni, mult in trans:

                # First step: no interior-square check
                A[row, ni * 2 + used] += mult
                A[row, ni * 2 + used] %= mod

                # Interior steps
                nused = used + (1 if a == 0 else 0)

                if nused <= 1:
                    B[row, ni * 2 + nused] += mult
                    B[row, ni * 2 + nused] %= mod

    start = idx[(p, 0, 0)] * 2

    vec = np.zeros(S, dtype=np.int64)
    vec[start] = 1

    # First step (position 0 is not interior)
    vec = (vec @ A) % mod

    # Remaining steps
    e = L - 1
    P = B.copy()

    while e:
        if e & 1:
            vec = (vec @ P) % mod

        e >>= 1

        if e:
            P = (P @ P) % mod

    ans = (vec[start] + vec[start + 1]) % mod
    return int(ans)

a1 = solve_mod(MOD1)
a2 = solve_mod(MOD2)

# CRT
inv = pow(MOD1, -1, MOD2)

answer = (
    a1
    + MOD1 * (((a2 - a1) * inv) % MOD2)
) % (10**9)

print(answer)
```实例验证：

 -$F(1,3)=4$-$F(1,4)=15$-$F(1,5)=46$-$F(2,3)=16$-$F(2,100)\bmod 10^9 = 429619151$均与声明相符。 

因此，

 **答案：898082747**
