[欧拉项目问题 327](https://projecteuler.net/problem=327)

 ## 解决方案

 **答案：**`34315549139516`让$M(C,R)$是通过所需的最少卡片数量$R$我们最多可以携带的房间$C$牌。 

关键是导出通过**一扇门**移动卡片的递归。 

### 第 1 步：通过一扇门传送卡片

 假设我们需要$x$隔壁房间有卡。 

通过门的**往返**：

 - 开始于$C$卡片、
 - 使用1张卡进入，
 - 尽可能多地留在隔壁房间，
 - 使用1张卡返回。 

这个存款最多$C-2$卡片进入隔壁房间。 

**最后的单程旅行**：

 - 开始于$y+1$卡片、
 - 使用一个进入，
 - 在下一个房间结束$y$牌。 

所以如果$$x=t(C-2)+y,\qquad 1\le y\le C-1,$$然后：

-$t$往返押金$t(C-2)$,
 - 一笔最后旅行押金$y$。 

当前房间所需卡牌总数：$$g_C(x)=tC+(y+1).$$我们选择最小化这个数量的分解。 

### 步骤 2：递归结构

 穿越$R$房间，有$R+1$门（包括出口门）。 

让$f_k$是之前需要的最少卡片$k$剩余的门。 

基本情况：$$f_0=0.$$复发：$$f_{k+1}=g_C(f_k).$$然后：$$M(C,R)=f_{R+1}.$$这重现了示例：

 -$M(3,6)=123$,
 -$M(4,6)=23$,
 -$\sum_{C=3}^{10}M(C,10)=10382$。

 ## Python 实现```python
def transport_cost(C, x):
    """
    Minimum cards needed in the current room
    to end up in the next room with x cards.
    """
    # One trip is enough
    if x <= C - 1:
        return x + 1

    best = float("inf")

    # Try all possible sizes of the final trip
    for y in range(1, C):
        remaining = x - y

        # Must be exactly covered by round trips
        if remaining % (C - 2) == 0:
            t = remaining // (C - 2)
            cost = t * C + (y + 1)
            best = min(best, cost)

    return best

def M(C, R):
    """
    Minimum cards needed to traverse R rooms.
    """
    f = 0  # no doors remaining

    # R rooms => R+1 doors (including exit)
    for _ in range(R + 1):
        f = transport_cost(C, f)

    return f

# Compute the required sum
answer = sum(M(C, 30) for C in range(3, 41))

print(answer)
```### 代码演练

 -`transport_cost(C, x)`计算移动所需的最少牌数$x$卡通过一扇门。 

- 如果$x \le C-1$，一趟就够了，所以费用是`x + 1`。 
- 否则，尝试所有可能的最终行程尺寸$y\in[1,C-1]$。 
- 剩余的卡必须来自完整的往返存款准确$C-2$每张卡片。 
-`M(C, R)`重复应用此传输规则。 

- 有`R + 1`门总数。 
- 开始于`f = 0`（最终退出后不需要任何东西）。
