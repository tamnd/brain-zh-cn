[欧拉项目 491 问题](https://projecteuler.net/problem=491)

 ## 解决方案

 **答案：**`194505988824000`设一个20位数字为$$d_1d_2\dots d_{20}$$其中每个数字$0,1,\dots,9$正好出现两次，并且$d_1\neq 0$。 

我们希望这些数字的数量可以被$11$。 

标准的整除性测试表明：$$(d_1+d_3+\cdots+d_{19})-(d_2+d_4+\cdots+d_{20}) \equiv 0 \pmod{11}.$$由于每个数字出现两次，所以所有数字的总和是$$2(0+1+\cdots+9)=2\cdot 45=90.$$如果我们让

 -$S_{\text{odd}}$= 奇数位置的数字之和，
 -$S_{\text{even}}$= 偶数位置上的数字之和，

 然后$$S_{\text{odd}}+S_{\text{even}}=90,$$和整除性$11$需要$$S_{\text{odd}}-S_{\text{even}}\equiv 0\pmod{11}.$$将两个方程相加：$$2S_{\text{odd}} \equiv 90 \pmod{11}.$$自从$90\equiv 2\pmod{11}$,$$2S_{\text{odd}}\equiv 2 \pmod{11}.$$乘以 的倒数$2$模数$11$（这是$6$）：$$S_{\text{odd}}\equiv 1\pmod{11}.$$但$S_{\text{odd}}$是从多重集中选择的 10 位数字的总和$$\{0,0,1,1,\dots,9,9\}.$$总的可能范围约为$45$，并且因为总数是$90$，满足同余的唯一可行值是$$S_{\text{odd}}=45.$$因此：

 > 10 个奇数位数字之和必须正好为 45。

 # 1. 表征有效的奇数/偶数选择

 对于每个数字$k\in\{0,\dots,9\}$， 让$x_k$是数字的副本数$k$放置在奇数位置。 

由于每个数字出现两次：$$x_k\in\{0,1,2\}.$$我们需要：$$\sum_{k=0}^9 x_k = 10$$（因为有10个奇数位置）

 和$$\sum_{k=0}^9 kx_k = 45.$$现在观察：$$\sum_{k=0}^9 k = 45.$$定义$$y_k = x_k-1.$$然后$y_k\in\{-1,0,1\}$， 和$$\sum y_k = 0,$$

$$\sum ky_k = 0.$$这意味着：

 - 数字与$x_k=2$和数字$x_k=0$必须有相等的金额。 

等效地：

 > 选择一个子集$A$奇数位置重复的数字和子集$B$不存在奇数位置，使得
 >
 >
 >
 >
 >$$\sum A = \sum B.$$所有剩余的数字在奇数位置出现一次。

 # 2. 固定分布的计数安排

 假设我们已经固定了向量$(x_0,\dots,x_9)$。 

然后：

 - 奇数位置包含$x_k$数字的副本$k$,
 - 甚至位置包含$2-x_k$副本。 

有：$$\frac{10!}{\prod x_k!}$$安排奇数位置的方法，以及$$\frac{10!}{\prod (2-x_k)!}$$排列均匀位置的方法。 

但这些是平等的，因为$x_k!$和$(2-x_k)!$是相同的$x_k=0,1,2$。 

让

-$t$= 的位数$x_k=2$。 

然后还有$t$数字有$x_k=0$， 和$10-2t$数字有$x_k=1$。 

因此$$\prod x_k! = 2^t.$$所以这个分布的总安排是$$\left(\frac{10!}{2^t}\right)^2.$$---

 # 3. 前导零校正

 我们必须排除以$0$。 

第一个数字是奇数位数字，因此我们要区分大小写。 

---

 ## 案例A：$x_0=0$奇数位置不存在零，因此第一位数字不能为零。 

无需修正。 

贡献：$$\left(\frac{10!}{2^t}\right)^2.$$---

 ## 情况 B：$x_0=1$零在奇数位置中出现一次。 

在所有奇数位置排列中，恰好$1/10$从零开始。 

因此有效的奇数排列是$$\frac{9}{10}\cdot \frac{10!}{2^t}.$$即使安排不变：$$\frac{10!}{2^t}.$$贡献：$$\frac{9}{10}\left(\frac{10!}{2^t}\right)^2.$$---

 ## 情况 C：$x_0=2$两个零都位于奇数位置。 

将零视为相同，以零开头的分数是$2/10=1/5$。 

因此有效的奇数排列是$$\frac45\cdot \frac{10!}{2^t}.$$贡献：$$\frac45\left(\frac{10!}{2^t}\right)^2.$$---

 # 4. 枚举有效的分布

 我们现在计算所有向量$(x_0,\dots,x_9)$满足约束条件。 

紧凑的方式是暴力破解$3^{10}=59049$的可能性。 

---

 # Python 实现```python
from itertools import product
from math import factorial

# Precompute 10!
F = factorial(10)

answer = 0

# x_k = number of copies of digit k in odd positions
# each x_k is 0,1,2
for xs in product((0, 1, 2), repeat=10):

    # Need exactly 10 digits in odd positions
    if sum(xs) != 10:
        continue

    # Need odd-position digit sum = 45
    if sum(d * xs[d] for d in range(10)) != 45:
        continue

    # t = number of digits appearing twice in odd positions
    t = sum(1 for x in xs if x == 2)

    base = (F // (2 ** t)) ** 2

    x0 = xs[0]

    # Leading-zero correction
    if x0 == 0:
        contribution = base

    elif x0 == 1:
        contribution = base * 9 // 10

    else:  # x0 == 2
        contribution = base * 4 // 5

    answer += contribution

print(answer)
```---
