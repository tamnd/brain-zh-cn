[欧拉项目 499 问题](https://projecteuler.net/problem=499)

 ## 解决方案

 **答案：**`0.8660312`让

-$m$= 每场比赛的成本，
 -$S_n$= 赌徒之后的财富$n$游戏，
 -$X$= 一场比赛的净收益。 

一场比赛结束后$k\ge 0$头跟尾，所以：$$P(X = 2^k - m)=2^{-(k+1)}.$$如果财富永远不低于赌徒的水平，那么赌徒就永远生存$m$。 

我们必须计算$p_{15}(10^9)$。 

---

 ## 1.数学分析

 定义**破产概率**$$q_m(s)=1-p_m(s),$$赌徒最终输光钱的概率。 

为了$s<m$,$$q_m(s)=1.$$为了$s\ge m$，以第一场比赛为条件给出$$q_m(s) = \sum_{k=0}^{\infty} 2^{-(k+1)} q_m(s-m+2^k).$$我们寻找指数解决方案$$q_m(s)=r^{\,s-m+1} \qquad (0<r<1).$$替换：$$r^{s-m+1} = \sum_{k=0}^{\infty} 2^{-(k+1)} r^{s-m+1-m+2^k}.$$取消公因数$r^{s-m+1}$：$$1 = r^{-m} \sum_{k=0}^{\infty} 2^{-(k+1)}r^{2^k}.$$等价地，$$r^m = \sum_{k=0}^{\infty} \frac{r^{2^k}}{2^{k+1}}.$$这有一个独特的根源$r\in(0,1)$。 

递推和边界条件唯一确定解，给出$$q_m(s)=r^{s-m+1},$$因此$$p_m(s)=1-r^{s-m+1}.$$### 对照示例进行健全性检查

 对于$m=2$，求解$$r^2=\sum_{k\ge0}\frac{r^{2^k}}{2^{k+1}}$$给出$$r\approx 0.74779150275.$$然后：$$p_2(2)=1-r\approx 0.2522,$$

$$p_2(5)=1-r^4\approx 0.6873,$$匹配问题陈述。 

为了$m=6$,$$p_6(10000)\approx 0.9952,$$再次匹配给定值。

 ## 2.Python实现```python
import mpmath as mp

mp.mp.dps = 50  # high precision

def survival_probability(m, s):
    # Equation:
    # r^m = sum_{k>=0} r^(2^k) / 2^(k+1)
    def equation(r):
        total = mp.nsum(
            lambda k: r ** (2 ** k) / (2 ** (k + 1)),
            [0, mp.inf]
        )
        return total - r ** m

    # Root in (0, 1)
    r = mp.findroot(
        equation,
        (mp.mpf('0.99999999'),
         mp.mpf('0.999999999'))
    )

    # p_m(s) = 1 - r^(s-m+1)
    return 1 - r ** (s - m + 1)

ans = survival_probability(15, 10**9)

print(ans)
print(f"{ans:.7f}")
```---
