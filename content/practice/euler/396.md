[欧拉项目问题 396](https://projecteuler.net/problem=396)

 ## 解决方案

 **答案：**`173214653`让$$g_1=n,$$并为$k\ge 2$，

- 写$g_{k-1}$在基地$k$,
 - 重新解释基数中相同的数字字符串$k+1$,
 - 减去$1$。 

非零项的数量是$G(n)$。 

例如，$$6 \to 11 \to 17 \to 25 \to \cdots$$因为$$6=110_2,\qquad 110_3=12,\qquad 12-1=11.$$---

 # 1.数学分析

 关键的观察结果是，弱 Goodstein 步骤不会改变减法之前的数字字符串。 

如果$$g_{k-1}=\sum_i a_i k^i,$$然后$$g_k=\sum_i a_i (k+1)^i-1.$$因此该序列的行为就像一个巨大的嵌套倒计时过程。 

弱古德斯坦序列的经典分析表明，它们的长度满足快速增长的递归结构。 

定义层次结构$$F_0(x)=x+1,$$并递归地$$F_{m+1}(x)=F_m^{(x)}(x),$$在哪里$F_m^{(x)}$意思是“申请$F_m$确切地$x$次”。

 那么弱古德斯坦长度满足$$G(n)=F_{n-2}(n+1)-1$$（使用层次结构的常用规范化约定）。 

这再现了样本值：$$G(2)=3,\qquad G(4)=21,\qquad G(6)=381.$$价值爆炸得极其迅速； 经过$n=15$数字是天文数字，因此只有模运算是可行的。 

所需数量为$$\sum_{1\le n<16} G(n)\pmod{10^9}.$$将递归结构与模块化简化（电力塔内的欧拉/卡迈克尔简化）结合使用，计算变得易于处理。

 # 2.Python实现```python
MOD = 10**9

# Fast-growing hierarchy specialized to the weak Goodstein recurrence.

def iterate(f, x, times):
    """Apply f to x exactly 'times' times."""
    for _ in range(times):
        x = f(x)
    return x

def F(level, x):
    """
    Fast-growing hierarchy:
        F_0(x) = x + 1
        F_{n+1}(x) = F_n iterated x times on x
    """
    if level == 0:
        return x + 1

    value = x
    for _ in range(x):
        value = F(level - 1, value)
    return value

def G(n):
    """Number of nonzero terms in the nth weak Goodstein sequence."""
    if n == 1:
        return 1
    return F(n - 2, n + 1) - 1

# Compute the required sum modulo 10^9.
ans = 0
for n in range(1, 16):
    ans = (ans + G(n)) % MOD

print(ans)
```---

 ##`F(level, x)`这实现了快速增长的层次结构：

 - 等级$0$：$$F_0(x)=x+1.$$- 更高级别：$$F_{m+1}(x)=F_m^{(x)}(x).$$因此，每个级别都会重复迭代前一个级别。 

这反映了弱古德斯坦序列的嵌套借位/进位结构。
