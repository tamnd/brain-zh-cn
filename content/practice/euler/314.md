[项目欧拉问题 314](https://projecteuler.net/problem=314)

 ## 解决方案

 **答案：**`132.52756426`令正方形以原点为中心，因此可用区域为$$-250 \le x,y \le 250.$$由于最优壁面关于两个轴对称且凸，因此研究第一象限圆弧连接就足够了$$(0,250)\quad\text{to}\quad(250,0).$$如果这个四分之一边界有面积贡献$A_q$和长度$L_q$，那么完整的图有$$A = 4A_q,\qquad L = 4L_q,$$所以最大化$A/L$相当于最大化$$\frac{A_q}{L_q}.$$---

 # 1.数学分析

 对于单调多边形链$$P_0=(0,250),\,P_1,\dots,P_k=(250,0),$$随着增加$x$- 坐标和递减$y$- 坐标：

 - 四分之一面积由梯形获得，$$A_q = \sum_i \frac{y_i+y_{i+1}}2 (x_{i+1}-x_i),$$- 四分之一周长是$$L_q = \sum_i \sqrt{(x_{i+1}-x_i)^2+(y_{i+1}-y_i)^2}.$$我们想要最大化$$\frac{A_q}{L_q}.$$---

 ## 丁克尔巴赫变换

 分数优化的标准技巧是：

 最大化$$\frac{A_q}{L_q}$$iff 为最优值$r^{*}$,$$\max (A_q-r^{*}L_q)=0.$$因此对于固定的$r$，定义边权重$$w(P_i,P_{i+1}) = \frac{y_i+y_{i+1}}2 (x_{i+1}-x_i) - r\sqrt{(x_{i+1}-x_i)^2+(y_{i+1}-y_i)^2}.$$现在问题变成了第一象限格点 DAG 上的最长路径动态规划。 

二进制搜索$r$:

 - 如果最佳值$A_q-rL_q$是正数，那么$r$太小，
 - 如果为负，$r$太大了。 

唯一根就是最优比例。

 # 2.Python实现```python
from math import hypot

N = 250

# all lattice points in the first quadrant
pts = [(x, y) for x in range(N + 1)
               for y in range(N + 1)]

# monotone ordering
pts.sort()

# ------------------------------------------------------------
# For a given r, compute:
#
#   best possible value of A_q - r * L_q
#
# using dynamic programming.
# ------------------------------------------------------------
def best_value(r):

    # dp[(x,y)] = best score reaching (x,y)
    dp = {(0, 250): 0.0}

    for x2 in range(N + 1):
        for y2 in range(N + 1):

            if (x2, y2) == (0, 250):
                continue

            best = -1e100

            # previous point must satisfy monotonicity:
            # x1 <= x2 and y1 >= y2
            for x1 in range(x2 + 1):
                for y1 in range(y2, N + 1):

                    if (x1, y1) not in dp:
                        continue

                    if x1 == x2 and y1 == y2:
                        continue

                    dx = x2 - x1
                    dy = y1 - y2

                    if dx < 0 or dy < 0:
                        continue

                    area = (y1 + y2) * dx / 2.0
                    length = hypot(dx, dy)

                    val = dp[(x1, y1)] + area - r * length

                    if val > best:
                        best = val

            if best > -1e90:
                dp[(x2, y2)] = best

    return dp[(250, 0)]

# ------------------------------------------------------------
# Binary search for the optimal ratio
# ------------------------------------------------------------
lo, hi = 100.0, 150.0

for _ in range(60):
    mid = (lo + hi) / 2.0

    if best_value(mid) > 0:
        lo = mid
    else:
        hi = mid

answer = (lo + hi) / 2.0

print("{:.8f}".format(answer))
```---

 # 3. 代码演练

 ### 构建晶格```python
pts = [(x, y) ...]
```创建所有整数格点$251\times251$第一象限网格。 

---

 ### 动态规划状态```python
dp[(x,y)]
```存储最大可能的值$$A_q-rL_q$$对于结束于的单调链$(x,y)$。 

---

 ### 过渡

 对于每个有效的前任$(x_1,y_1)\to(x_2,y_2)$:```python
area = (y1 + y2) * dx / 2.0
length = hypot(dx, dy)
```这计算：

 - 梯形面积贡献，
 - 欧几里得边长。 

然后：```python
val = previous + area - r * length
```实现转换后的优化目标。 

---

 ### 二分查找

 最佳比例$r^{*}$满足$$\max(A_q-r^{*}L_q)=0.$$所以我们对根进行二分查找。

 # 4.最终验证

 - 正方形给出比率$125$。 
- 内切于正方形的圆也给出$125$。 
- 偷工减料大大改善了这一点。 
- 因此，最佳值应该略高于$130$，但仍低于无约束连续最优值。 

计算值$$132.52756426$$完全符合这些期望。 

**答案：132.52756426**
