[欧拉项目问题 128](https://projecteuler.net/problem=128)

 ## 解决方案

 **答案：**`14516824220`让瓷砖排列成同心六边形环。 

戒指$r$（和$r\ge 1$) 包含$6r$瓷砖，以及环中的最后一块瓷砖$r$是$$1+\sum_{k=1}^{r}6k =1+3r(r+1).$$解决这个问题的关键是几乎所有的图块都有太多的复合邻居差异而无法实现$\operatorname{PD}(n)=3$。 事实上，可以证明每个环只需要两块瓷砖就可以工作。 

---

 # 1.数学分析

 对于一块瓷砖$n$， 定义$\operatorname{PD}(n)$作为之间的六个绝对差之间的质数的数量$n$及其邻居。 

该问题指出最大可能值为$3$。 

值得注意的观察是：

 - 如果$\operatorname{PD}(n)=3$， 然后$n$必须位于特殊的角落位置。 
- 具体来说，环中只有以下两名候选人$r$可以工作：$$A_r = 3r(r-1)+2$$（环的第一块牌$r$）

和$$B_r = 3r(r+1)+1$$（环的最后一块牌$r$）。 

我们现在推导出这些的主要条件。 

---

 ## 候选 1：环的第一块

 考虑$$A_r = 3r(r-1)+2.$$它的六个邻居差异简化为$$1,\quad 6r-1,\quad 6r+1,\quad 12r-7,$$加上两个明显的复合/非质数值。 

因此$$\operatorname{PD}(A_r)=3$$当且仅当所有三个数字$$6r-1,\qquad 6r+1,\qquad 12r-7$$是素数。 

---

 ## 候选 2：环的最后一块

 现在考虑$$B_r = 3r(r+1)+1.$$其相关邻居差异减少为$$6r-1,\quad 6r+5,\quad 12r+5.$$因此$$\operatorname{PD}(B_r)=3$$当且仅当$$6r-1,\qquad 6r+5,\qquad 12r+5$$都是素数。 

---

 ## 序列生成

 因此，该序列包括：

 -$1$，
- 全部$A_r$满足第一个素数三元组，
 - 全部$B_r$满足第二素数三元组。 

第 10 项给出为$271$，这提供了有用的检查。 

因为我们只需要第 2000 项，所以通过快速素性测试直接搜索环就足够了。

 # 2.Python实现```python
from math import isqrt

def is_prime(n):
    """Deterministic primality test for positive integers."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    if n % 3 == 0:
        return n == 3

    limit = isqrt(n)
    f = 5
    step = 2

    while f <= limit:
        if n % f == 0:
            return False
        f += step
        step = 6 - step

    return True

def solve(target):
    # The sequence starts with tile 1
    values = [1]

    r = 1

    while len(values) < target:

        # First tile in ring r
        a = 3 * r * (r - 1) + 2

        if (
            is_prime(6 * r - 1)
            and is_prime(6 * r + 1)
            and is_prime(12 * r - 7)
        ):
            values.append(a)

        # Last tile in ring r
        b = 3 * r * (r + 1) + 1

        if (
            is_prime(6 * r - 1)
            and is_prime(6 * r + 5)
            and is_prime(12 * r + 5)
        ):
            values.append(b)

        r += 1

    values.sort()
    return values[target - 1]

answer = solve(2000)
print(answer)
```---
