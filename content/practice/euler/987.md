 > 在扑克中，顺子恰好是五张顺序排列的牌，而不是全部相同花色的牌。 在此问题中，A 可以排名较高（如 A-K-Q-J-10）或较低（如 5-4-3-2-A），但不能同时排名较高和较低，因此不允许 Q-K-A-2-3。

>

 # 数学分析

 顺子正好有 10 种可能的排名模式：$$A2345,\ 23456,\ 34567,\ \dots,\ TJQKA$$调用这些窗口$W_0,\dots,W_9$。 

顺子是通过为 5 个等级中的每一个等级选择一种花色来获得的，但限制是 5 张牌**不都是相同的花色**。 

因此对于单顺子：$$4^5 - 4 = 1024 - 4 = 1020$$和$$10 \cdot 1020 = 10200$$与声明相符。 

---

 # 步骤 1 — 多重向量

 假设 8 条顺子中：

 -$p_0$使用$A2345$,
 -$p_1$使用$23456$,
 - …
 -$p_9$使用$TJQKA$。 

然后：$$p_0+p_1+\cdots+p_9=8$$对于每个等级，最多有 4 张牌（每种花色一张），因此使用给定等级的顺子总数不能超过 4。 

这严重限制了有效向量$p$。 

对于固定重数向量：

 - 8 个标记的直线到窗口的有序分配数量为$$\frac{8!}{\prod p_i!}$$---

 # 步骤 2 — 计算花色分配

 对于 Windows 的固定顺序配置：

 - 每个顺子每个等级都需要一套花色，
 - 卡片不能重复，
 - 没有顺子可以是同花顺。 

执行“并非所有同花色”的简洁方法是包含-排除。 

---

 ## 包含-排除

 设一个子集$T$顺子被迫成为同花顺。 

如果顺子是单色的，那么它的所有等级都使用相同的花色。 

现在检查单个排名$r$。 

认为：

-$c_r$总顺子使用排名$r$,
 -$k_r$其中属于$T$。 

这$k_r$单色直道已经消耗$k_r$该级别的独特套装。 

其余$c_r-k_r$顺子可以在剩余花色中使用任何单射分配：$$P(4-k_r,\ c_r-k_r) = \frac{(4-k_r)!}{(4-c_r)!}$$乘以所有 13 个等级即可得出该子集的完成数量$T$。 

剩下的唯一任务是计算单色直线的有效颜色。 

等级重叠的两条单色顺子不能共用相同的花色。 

因此，我们得到了区间重叠图上的图着色问题。 

由于总共只有 8 条顺子，因此对所有子集进行暴力破解$T\subseteq\{1,\dots,8\}$是完全可行的。 

---

 # Python 实现```python
from functools import lru_cache
from math import factorial

# ------------------------------------------------------------
# Build the 10 straight windows
# ------------------------------------------------------------

windows = []

# A2345
windows.append([12, 0, 1, 2, 3])

# 23456 ... TJQKA
for s in range(1, 10):
    windows.append(list(range(s - 1, s + 4)))

# ------------------------------------------------------------
# Overlap graph between straight windows
# ------------------------------------------------------------

overlap = [[False] * 10 for _ in range(10)]

for i in range(10):
    for j in range(10):
        overlap[i][j] = bool(set(windows[i]) & set(windows[j]))

# ------------------------------------------------------------
# Generate all valid multiplicity vectors p
# satisfying:
#
#   sum p_i = 8
#   every rank used at most 4 times
# ------------------------------------------------------------

vectors = []

def gen(i, rem, p, rank_count):
    if i == 10:
        if rem == 0:
            vectors.append(tuple(p))
        return

    for x in range(rem + 1):

        new_count = rank_count[:]
        ok = True

        for r in windows[i]:
            new_count[r] += x
            if new_count[r] > 4:
                ok = False
                break

        if ok:
            p.append(x)
            gen(i + 1, rem - x, p, new_count)
            p.pop()

gen(0, 8, [], [0] * 13)

# ------------------------------------------------------------
# Count suit assignments for a fixed multiplicity vector
# using inclusion-exclusion
# ------------------------------------------------------------

@lru_cache(None)
def count_vector(p):

    p = list(p)

    # Expand into individual labeled straights
    copies = []

    for w, cnt in enumerate(p):
        copies += [w] * cnt

    m = len(copies)

    # Total usage count of each rank
    total_rank_use = [0] * 13

    for w in copies:
        for r in windows[w]:
            total_rank_use[r] += 1

    answer = 0

    # Inclusion-exclusion over monochromatic straights
    for mask in range(1 << m):

        chosen = [i for i in range(m) if (mask >> i) & 1]

        # k_r
        mono_use = [0] * 13

        for i in chosen:
            for r in windows[copies[i]]:
                mono_use[r] += 1

        # Count remaining injective assignments
        ways = 1
        ok = True

        for r in range(13):

            a = 4 - mono_use[r]
            b = total_rank_use[r] - mono_use[r]

            if b > a:
                ok = False
                break

            # falling factorial P(a,b)
            for t in range(a - b + 1, a + 1):
                ways *= t

        if not ok:
            continue

        # Count proper colorings of monochromatic straights
        color_count = 0
        colors = {}

        order = chosen

        def dfs(idx):
            nonlocal color_count

            if idx == len(order):
                color_count += 1
                return

            i = order[idx]

            forbidden = set()

            for j, c in colors.items():
                if overlap[copies[i]][copies[j]]:
                    forbidden.add(c)

            for c in range(4):
                if c not in forbidden:
                    colors[i] = c
                    dfs(idx + 1)
                    del colors[i]

        dfs(0)

        answer += ((-1) ** len(chosen)) * ways * color_count

    return answer

# ------------------------------------------------------------
# Total count
# ------------------------------------------------------------

total = 0

for p in vectors:

    mult = factorial(8)

    for x in p:
        mult //= factorial(x)

    total += count_vector(p) * mult

# unordered straights
total //= factorial(8)

print(total)
```---

```我们计算：
