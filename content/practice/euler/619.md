[欧拉项目 619 问题](https://projecteuler.net/problem=619)

 ## 解决方案

 **答案：**`857810883`让$$S=\{a,a+1,\dots,b\}$$对于每个整数$n$，将其质因数分解写为$$n=\prod p_i^{e_i}.$$数字的乘积是完全平方，当且仅当总乘积中的每个素数指数都是偶数。 

定义 **squarefree 奇偶校验向量**$n$超过$\mathbb F_2$:$$v(n)=(e_i \bmod 2).$$那么对于一个子集$T\subseteq S$,$$\prod_{x\in T} x \text{ is a square} \iff \sum_{x\in T} v(x)=0 \quad (\text{over }\mathbb F_2).$$那么问题就变成了：

 > 计算向量总和为零的非空子集。 

---

 # 1. 线性代数公式

 假设有$$N=b-a+1$$总数和向量$v(x)$跨越秩向量空间$r$。 

地图$$\phi:\mathbb F_2^N \to \mathbb F_2^m$$将子集指示符向量发送到奇偶校验和具有内核大小$$2^{N-r}.$$这些正是乘积为正方形的子集，包括空子集。 

所以$$C(a,b)=2^{N-r}-1.$$所以整个问题简化为计算排名$r$超过$\mathbb F_2$。 

---

 # 2. 计算向量

 对于每个数字$n$:

 - 因素它，
 - 只保留奇数指数的素数，
 - 这组素数是奇偶校验向量。 

例子：$$72=2^3\cdot 3^2$$有奇偶校验向量$$\{2\}$$因为只有$2$很奇怪。 

---

 # 3. 稀疏高斯消去法$\mathbb F_2$每个向量都是稀疏的（很少有奇数素数因子），因此我们将其存储为一组素数。 

高斯消去法：

 - 选择向量中最大的素数作为主元，
 - 消除现有的基本向量，
 - 如果仍然存在非零，则插入到基础中。 

这可以有效地计算排名。 

---

 # 4.Python实现```python
from math import isqrt

MOD = 1_000_000_007

def compute_C(a, b):
    N = b - a + 1

    # ------------------------------------------------------------
    # Smallest prime factor sieve
    # ------------------------------------------------------------
    spf = list(range(b + 1))

    for p in range(2, isqrt(b) + 1):
        if spf[p] == p:  # p is prime
            for x in range(p * p, b + 1, p):
                if spf[x] == x:
                    spf[x] = p

    # ------------------------------------------------------------
    # Sparse Gaussian elimination over F2
    # basis[pivot_prime] = set representing basis vector
    # ------------------------------------------------------------
    basis = {}
    rank = 0

    for value in range(a, b + 1):

        n = value
        vec = set()

        # Build squarefree parity vector
        while n > 1:
            p = spf[n]
            parity = 0

            while n % p == 0:
                n //= p
                parity ^= 1

            if parity:
                vec.symmetric_difference_update({p})

        # Eliminate using existing basis
        while vec:
            pivot = max(vec)

            if pivot in basis:
                vec ^= basis[pivot]
            else:
                basis[pivot] = vec
                rank += 1
                break

    # Number of square-product subsets
    return (pow(2, N - rank, MOD) - 1) % MOD

# ------------------------------------------------------------
# Checks from the problem statement
# ------------------------------------------------------------
print(compute_C(40, 55))       # 15
print(compute_C(1000, 1234))   # 975523611

# ------------------------------------------------------------
# Required answer
# ------------------------------------------------------------
print(compute_C(1_000_000, 1_234_567))
```---

 # 5. 代码演练

 ### SPF 筛子```python
spf = list(range(b + 1))
```最初假设每个数字都是质数。 

然后：```python
if spf[x] == x:
    spf[x] = p
```存储每个合数的最小质因数。 

这允许快速分解。 

---

 ### 构建奇偶校验向量

 对于每个数字：```python
while n % p == 0:
    n //= p
    parity ^= 1
```仅跟踪指数奇偶校验。 

如果奇偶校验为奇数，则素数属于向量。 

---

 ### 高斯消去法

 每个向量都会针对现有枢轴进行缩减：```python
vec ^= basis[pivot]
```因为加法超过$\mathbb F_2$是异或/对称差。 

如果保留一个非零向量，它将贡献一个新的独立维度。
