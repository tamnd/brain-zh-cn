[欧拉项目 422 问题](https://projecteuler.net/problem=422)

 ## 解决方案

 **答案：**`92060460`让$$Q(x,y)=12x^2+7xy-12y^2.$$双曲线是$$H:\quad Q(x,y)=625,$$和$X=(7,1)\in H$。 

我们定义$P_n$由几何条件递归：

 -$P_1=(13,\tfrac{61}{4})$,
 -$P_2=(-\tfrac{43}{6},-4)$，
- 为了$n>2$,$P_n$是第二个交集$H$与线通过$P_{n-1}$平行于$XP_{n-2}$。 

我们必须计算$P_n$为了$$n=11^{14}$$并返回$$(a+b+c+d)\bmod 1{,}000{,}000{,}007$$在哪里$$P_n=\left(\frac ab,\frac cd\right)$$用最低的术语来说。 

---

 ## 1.数学分析

 ### 第 1 步：通过以下方式对双曲线进行参数化$X$走一条线穿过$X=(7,1)$有坡度$u$:$$(x,y)=(7+t,1+ut).$$代入$Q(x,y)=625$:$$12(7+t)^2+7(7+t)(1+ut)-12(1+ut)^2=625.$$因式分解给出：$$t\left(12tu^2-7tu-12t-25u-175\right)=0.$$一个根是$t=0$（这一点$X$）； 第二个交点是$$t=\frac{25u+175}{12u^2-7u-12}.$$因此上的每一点$H$（渐近方向除外）对应一个参数$u$。 

二次分母因子：$$12u^2-7u-12 = 12\left(u-\frac43\right)\left(u+\frac34\right).$$这表明替代$$z = \frac{u-\frac43}{u+\frac34}.$$解决$u$,$$u=\frac{\frac43+\frac34 z}{1-z}.$$代入点坐标可以完美地简化：$$x=3z+\frac4z, \qquad y=\frac{16}{3z}-\frac94 z.$$---

 ### 步骤 2：查找重复项$z_n$让$z_n$对应于$P_n$。 

条件“$P_nP_{n-1}$平行于$XP_{n-2}$” 可以用代数方式翻译。

 代入并化简后，递推式变为：$$z_n=\frac{4z_{n-2}}{3z_{n-1}}.$$初始值：$$z_1=\frac13, \qquad z_2=-\frac89.$$检查：$$z_3 = \frac{4(1/3)}{3(-8/9)} = -\frac12,$$

$$z_4 = \frac{4(-8/9)}{3(-1/2)} = \frac{64}{27},$$匹配问题数据。 

---

 ### 步骤 3：素数指数形式

 既然一切都始于权力$2$和$3$， 写$$z_n=\pm 2^{A_n}3^{B_n}.$$递归给出：$$A_n=A_{n-2}-A_{n-1}+2,$$

$$B_n=B_{n-2}-B_{n-1}-1,$$和$$A_1=0,\ A_2=3,$$

$$B_1=-1,\ B_2=-2.$$为了$n=11^{14}$:

 -$n$是奇数，
 -$n\equiv 1\pmod 3$，

所以$z_n>0$，对于大奇数$n$,$$A_n<0,\qquad B_n>0.$$因此$$z_n=\frac{3^{B_n}}{2^{-A_n}}.$$让$$p=3^{B_n}, \qquad q=2^{-A_n}.$$然后$$z_n=\frac pq.$$坐标变为：$$x=\frac{3p^2+4q^2}{pq},$$

$$y=\frac{64q^2-27p^2}{12pq}.$$对于奇数$n$在这里，两个分数都已经减少了。 

---

 ### 步骤 4：模指数计算

 我们只需要最后的求和模$$M=1{,}000{,}000{,}007.$$自从$M$是质数，指数按模减少$M-1$。 

仿射递推的快速矩阵求幂给出：$$A_n \equiv 852174610 \pmod{M-1},$$

$$B_n \equiv 218412851 \pmod{M-1}.$$自从$A_n<0$,$$-A_n \equiv 147825396 \pmod{M-1}.$$因此$$p\equiv 3^{218412851}\pmod M,$$

$$q\equiv 2^{147825396}\pmod M.$$然后：$$a=3p^2+4q^2,$$

$$b=pq,$$

$$c=64q^2-27p^2,$$

$$d=12pq.$$最后：$$(a+b+c+d)\bmod M = 92060460.$$---

 ## 2.Python实现```python
MOD = 1_000_000_007
PHI = MOD - 1

n = 11**14

def matrix_mul(A, B, mod):
    """Multiply two 3x3 matrices modulo mod."""
    return [
        [
            sum(A[i][k] * B[k][j] for k in range(3)) % mod
            for j in range(3)
        ]
        for i in range(3)
    ]

def recurrence_mod(n, x1, x2, c):
    """
    Solve:
        x_n = x_{n-2} - x_{n-1} + c
    modulo PHI.
    """
    if n == 1:
        return x1 % PHI
    if n == 2:
        return x2 % PHI

    # State vector:
    # [x_n, x_{n-1}, 1]
    M = [
        [-1 % PHI, 1, c % PHI],
        [1, 0, 0],
        [0, 0, 1]
    ]

    # Fast exponentiation
    power = n - 2
    result = [
        [1, 0, 0],
        [0, 1, 0],
        [0, 0, 1]
    ]

    while power:
        if power & 1:
            result = matrix_mul(result, M, PHI)
        M = matrix_mul(M, M, PHI)
        power >>= 1

    vec = [x2 % PHI, x1 % PHI, 1]

    xn = sum(result[0][i] * vec[i] for i in range(3)) % PHI
    return xn

# Compute exponent residues
A_mod = recurrence_mod(n, 0, 3, 2)
B_mod = recurrence_mod(n, -1, -2, -1)

# Since A_n is negative for this n
exp2 = (-A_mod) % PHI
exp3 = B_mod

p = pow(3, exp3, MOD)
q = pow(2, exp2, MOD)

# Coordinates modulo MOD
a = (3 * p * p + 4 * q * q) % MOD
b = (p * q) % MOD

c = (64 * q * q - 27 * p * p) % MOD
d = (12 * p * q) % MOD

answer = (a + b + c + d) % MOD

print(answer)
```---

 ## 3. 代码演练

 1. 将几何递推转化为简单有理递推$$z_n=\frac{4z_{n-2}}{3z_{n-1}}.$$2. 我们代表$z_n$作为权力$2$和$3$:$$z_n=\pm 2^{A_n}3^{B_n}.$$3. 指数递推是仿射线性的：$$A_n=A_{n-2}-A_{n-1}+2,$$

$$B_n=B_{n-2}-B_{n-1}-1.$$4.我们计算$A_n,B_n$模数$M-1$使用快速矩阵求幂。 
5. 重构模块化版本$p,q$。 
6. 计算简化形式模的有理坐标$M$。 
7. 分子和分母的总和。
