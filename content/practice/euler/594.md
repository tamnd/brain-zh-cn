[项目欧拉问题 594](https://projecteuler.net/problem=594)

 ## 解决方案

 **答案：**`47067598`让$$O_{a,b}$$是等角凸八边形，其边长交替$a$和$b$。 

我们必须计算$$t(O_{4,2}),$$单位正方形和单位菱形（带有角度）的平铺数量$45^\circ/135^\circ$）。 

解决这些平铺问题的标准方法是将它们转换为不相交的晶格路径族，然后应用 Lindström-Gessel-Viennot (LGV) 行列式定理。

 # 1.数学分析

 八边形$$(a,b,c,d,a,b,c,d)$$具有等角$135^\circ$承认 de Bruijn 线表示：每个平铺都唯一对应于单调路径的集合。 

对于这个族，埃尔尼茨基的行列式枚举公式给出：$$T_{a,b,c,d} = \sum_{X,Y} \left( \prod_{u=1}^{d+1}\det M^{(u)} \right) \left( \prod_{v=1}^{b+1}\det P^{(v)} \right),$$在哪里：

-$X=(x_{k,\ell})$是单调的$b\times d$矩阵中的条目$[0,a]$,
 -$Y=(y_{k,\ell})$是一个反单调$b\times d$矩阵中的条目$[0,c]$,
 - 行列式通过 LGV 计算非相交路径族。 

对于欧拉投影多边形，$$O_{a,b}=(a,b,a,b,a,b,a,b),$$所以我们设置$$(a,b,c,d)=(a,b,a,b).$$矩阵是：$$M^{(u)}_{ij} = \binom{ (x_{j,u}-x_{i,u-1})+(y_{j,u}-y_{i,u-1}) }{ (x_{j,u}-x_{i,u-1})+(j-i) },$$和$$P^{(v)}_{ij} = \binom{ (x_{v,j}-x_{v-1,i})+(y_{v-1,i}-y_{v,j}) }{ (x_{v,j}-x_{v-1,i})+(j-i) }.$$平铺的总数是通过对所有可接受的单调数组上这些行列式的乘积求和而获得的$X,Y$。

 # 2.Python实现```python
from math import comb

def gen_monotone_matrices(rows, cols, max_value):
    """
    Generate all matrices M such that:
        M[i][j] >= M[i-1][j]
        M[i][j] >= M[i][j-1]
    with entries in [0, max_value].
    """
    m = [[0] * cols for _ in range(rows)]

    def rec(pos):
        if pos == rows * cols:
            yield tuple(tuple(r) for r in m)
            return

        i, j = divmod(pos, cols)

        lo = 0
        if i > 0:
            lo = max(lo, m[i - 1][j])
        if j > 0:
            lo = max(lo, m[i][j - 1])

        for v in range(lo, max_value + 1):
            m[i][j] = v
            yield from rec(pos + 1)

    yield from rec(0)

def det_bareiss(mat):
    """
    Exact determinant using the Bareiss algorithm.
    """
    n = len(mat)

    if n == 0:
        return 1

    a = [row[:] for row in mat]
    sign = 1
    prev = 1

    for k in range(n - 1):

        if a[k][k] == 0:
            for i in range(k + 1, n):
                if a[i][k]:
                    a[k], a[i] = a[i], a[k]
                    sign = -sign
                    break
            else:
                return 0

        pivot = a[k][k]

        for i in range(k + 1, n):
            for j in range(k + 1, n):
                a[i][j] = (
                    a[i][j] * pivot
                    - a[i][k] * a[k][j]
                ) // prev

        prev = pivot

    return sign * a[-1][-1]

def count_tilings_octagon(a, b, c, d):

    X = list(gen_monotone_matrices(b, d, a))

    Y = []
    for y_rev in gen_monotone_matrices(b, d, c):
        y = tuple(
            tuple(y_rev[b - 1 - i][j] for j in range(d))
            for i in range(b)
        )
        Y.append(y)

    total = 0

    for x in X:

        x_full = [[0] * (d + 2) for _ in range(b + 2)]

        for k in range(1, b + 1):
            for l in range(1, d + 1):
                x_full[k][l] = x[k - 1][l - 1]

        for k in range(1, b + 1):
            x_full[k][d + 1] = a

        for l in range(d + 2):
            x_full[b + 1][l] = a

        for y in Y:

            y_full = [[0] * (d + 2) for _ in range(b + 2)]

            for k in range(1, b + 1):
                for l in range(1, d + 1):
                    y_full[k][l] = y[k - 1][l - 1]

            for k in range(1, b + 1):
                y_full[k][d + 1] = c

            for l in range(d + 2):
                y_full[0][l] = c

            prod = 1

            # Product of det(M^(u))
            for u in range(1, d + 2):

                M = []

                for i in range(1, b + 1):

                    row = []

                    for j in range(1, b + 1):

                        A = (
                            x_full[j][u] - x_full[i][u - 1]
                            + y_full[j][u] - y_full[i][u - 1]
                        )

                        B = (
                            x_full[j][u] - x_full[i][u - 1]
                            + (j - i)
                        )

                        row.append(comb(A, B) if 0 <= B <= A else 0)

                    M.append(row)

                prod *= det_bareiss(M)

                if prod == 0:
                    break

            if prod == 0:
                continue

            # Product of det(P^(v))
            for v in range(1, b + 2):

                P = []

                for i in range(1, d + 1):

                    row = []

                    for j in range(1, d + 1):

                        A = (
                            x_full[v][j] - x_full[v - 1][i]
                            + y_full[v - 1][i] - y_full[v][j]
                        )

                        B = (
                            x_full[v][j] - x_full[v - 1][i]
                            + (j - i)
                        )

                        row.append(comb(A, B) if 0 <= B <= A else 0)

                    P.append(row)

                prod *= det_bareiss(P)

                if prod == 0:
                    break

            total += prod

    return total

def t_O_ab(a, b):
    return count_tilings_octagon(a, b, a, b)

# Verify given examples
print(t_O_ab(1, 1))  # 8
print(t_O_ab(2, 1))  # 76
print(t_O_ab(3, 2))  # 456572

# Required value
print(t_O_ab(4, 2))

 # 3. 代码演练

 -`gen_monotone_matrices(...)`生成所有单调数组$X$和$Y$。 
-`det_bareiss(...)`使用无分数 Bareiss 算法精确计算行列式。 
-`count_tilings_octagon(...)`直接执行行列式。 
-`t_O_ab(a,b)`将一般八边形专门化为欧拉计划形状。 

验证输出为：$$t(O_{1,1})=8, \qquad t(O_{2,1})=76, \qquad t(O_{3,2})=456572,$$与问题陈述完全匹配。 

最后，计算得出：$$t(O_{4,2}) = 47067598.$$---
