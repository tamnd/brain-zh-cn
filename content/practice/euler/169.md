[欧拉项目问题 169](https://projecteuler.net/problem=169)

 ## 解决方案

 **答案：**`178653872807`我们必须计算表示的数量$$10^{25}$$作为权力的总和$2$，其中每个功率最多可以使用两次。 

定义$$f(n)=\#\left\{n=\sum_{k\ge0} a_k2^k \;\middle|\; a_k\in\{0,1,2\}\right\}.$$我们被要求$f(10^{25})$。 

---

 # 数学分析

 问题本质上是关于**二进制进位**。 

认为$$n=\sum_{k\ge0} b_k2^k$$是普通的二进制展开式$n$， 在哪里$b_k\in\{0,1\}$。 

我们求数字序列的数量$$a_k\in\{0,1,2\}$$这样$$\sum a_k2^k=n.$$关键的观察是相邻位之间的唯一交互来自进位。 

---

 ## 基于进位的动态规划

 从最低有效位到最高有效位处理位。 

在钻头位置$k$:

 - 目标位是$b_k\in\{0,1\}$,
 - 我们选择一个系数$a_k\in\{0,1,2\}$,
 - 我们也可能会收到携带$c_k$从上一点开始。 

我们要求$$a_k + c_k \equiv b_k \pmod 2.$$下一个进位是$$c_{k+1}=\frac{a_k+c_k-b_k}{2}.$$因为$a_k\le2$而且携带停留极小，状态空间极小。 

因此我们可以计算$f(n)$带有数字 DP。 

- -

＃＃ 例子：$f(10)$二进制：$$10 = 1010_2.$$运行进位递归恰好产生 5 种表示形式：$$\begin{aligned} 10 &= 8+2\\ &=8+1+1\\ &=4+4+2\\ &=4+4+1+1\\ &=4+2+2+1+1. \end{aligned}$$所以$f(10)=5$，与语句相符。

 # Python 实现```python
from functools import lru_cache

def f(n):
    # Binary digits of n
    bits = list(map(int, bin(n)[2:]))

    @lru_cache(None)
    def dp(pos, carry):
        """
        pos   : current bit position (from least significant upward)
        carry : incoming carry at this bit

        Returns the number of valid completions.
        """

        # All bits processed
        if pos == len(bits):
            return 1 if carry == 0 else 0

        # Current target bit of n
        bit = bits[-1 - pos]

        total = 0

        # Choose coefficient a_k in {0,1,2}
        for digit in (0, 1, 2):

            s = digit + carry

            # Parity must match the target bit
            if s % 2 == bit:

                # Compute next carry
                next_carry = (s - bit) // 2

                total += dp(pos + 1, next_carry)

        return total

    return dp(0, 0)

# Problem value
print(f(10**25))
```---
