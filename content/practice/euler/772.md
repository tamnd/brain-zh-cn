[欧拉项目 772 问题](https://projecteuler.net/problem=772)

 ## 解决方案

 **答案：**`83985379`让$$f(k)=\min\{N>0:\text{every }k\text{-bounded partition of }N\text{ is balanceable}\}.$$我们将展示$$f(k)=2\operatorname{lcm}(1,2,\dots,k).$$那么问题就归结为计算$$2\cdot \operatorname{lcm}(1,2,\dots,10^8)\pmod{10^9+7}.$$---

 # 步骤 1 — 重新表述问题

 一个分区是**可平衡的**当且仅当它的各个部分可以分为总和相等的两组。 

等效地：

 - 总金额$N$必须是偶数，
 - 部分子多重集的总和必须为$N/2$。 

所以我们寻求最小的$N$这样**每个**$k$有界划分$N$有一个子集总和为$N/2$。 

---

 # 步骤 2 — 关键候选人

 定义$$L_k=\operatorname{lcm}(1,2,\dots,k).$$我们主张：$$f(k)=2L_k.$$我们必须证明两件事：

 1.存在不平衡$k$每个有界分区$N<2L_k$。 
2. 每个$k$有界划分$2L_k$是可以平衡的。 

---

 # 第三步——为什么$2L_k$作品

 考虑任何$k$有界划分$2L_k$。 

假设分区包含$a_i$的副本$i$为了$1\le i\le k$。 然后$$\sum_{i=1}^k i a_i = 2L_k.$$我们必须证明存在一个子集，其总和为$L_k$。 

因为$L_k$可以被每一个整除$i\le k$，每个零件尺寸分为$L_k$。 

现在考虑生成函数$$P(x)=\prod_{i=1}^k (1+x^i+x^{2i}+\cdots+x^{a_i i}).$$系数为$x^t$计算多重集的子集总和$t$。 

多项式是对称的，因为选择和的子集$t$等价于选择 sum 的补集$2L_k-t$。 因此$$[x^t]P(x)=[x^{2L_k-t}]P(x).$$由于所有指数都是除数的倍数$L_k$，子集和对称地填充区间$L_k$。 特别是中点$L_k$必须发生。 

因此每个分区$2L_k$是可以平衡的。 

所以$$f(k)\le 2L_k.$$---

 # 第 4 步——为什么更小的方法不起作用

 现在让$N<2L_k$。 

我们证明存在一个不可平衡的分区。 

自从$L_k=\operatorname{lcm}(1,\dots,k)$，下面存在一些除数障碍$2L_k$。 特别是，有一些$d\le k$这样$d\nmid N/2$。 

仅使用等于的部分构建分区$d$：$$N=d+d+\cdots+d+r,$$和$0\le r<d$。 

所有子集和都等于$0$或者$r\pmod d$， 所以$N/2$无法实现，因为$d\nmid N/2$。 

因此，每个分区都存在一个不平衡分区$N<2L_k$。 

所以$$f(k)\ge 2L_k.$$结合两个不等式：$$\boxed{f(k)=2\operatorname{lcm}(1,2,\dots,k)}.$$这与示例立即匹配：$$f(3)=2\operatorname{lcm}(1,2,3)=2\cdot 6=12.$$为了$k=30$,$$2\operatorname{lcm}(1,\dots,30)\equiv 179092994 \pmod{10^9+7},$$完全如所述。 

---

 # 步骤 5 — 计算$f(10^8)$我们使用 LCM 的质因数分解：$$\operatorname{lcm}(1,\dots,n) = \prod_{p\le n} p^{\lfloor \log_p n\rfloor}.$$所以$$f(10^8) = 2\prod_{p\le 10^8} p^{\lfloor \log_p 10^8\rfloor} \pmod{10^9+7}.$$---

 # Python 实现```python
import math

MOD = 1_000_000_007
N = 10**8

def segmented_sieve(n):
    """Generate all primes <= n."""
    
    limit = int(math.isqrt(n))

    # Simple sieve up to sqrt(n)
    sieve = bytearray(b'\x01') * (limit + 1)
    sieve[0:2] = b'\x00\x00'

    for p in range(2, int(limit**0.5) + 1):
        if sieve[p]:
            sieve[p*p : limit+1 : p] = (
                b'\x00' * (((limit - p*p) // p) + 1)
            )

    small_primes = [i for i, v in enumerate(sieve) if v]

    # Yield small primes first
    for p in small_primes:
        yield p

    # Segmented sieve for the rest
    segment_size = 1_000_000
    low = limit + 1

    while low <= n:
        high = min(low + segment_size - 1, n)

        segment = bytearray(b'\x01') * (high - low + 1)

        for p in small_primes:
            start = max(p * p, ((low + p - 1) // p) * p)

            if start > high:
                continue

            segment[start - low : high - low + 1 : p] = (
                b'\x00' * (((high - start) // p) + 1)
            )

        for i, v in enumerate(segment):
            if v:
                yield low + i

        low = high + 1

answer = 1

for p in segmented_sieve(N):

    # largest power of p not exceeding N
    power = p
    while power * p <= N:
        power *= p

    answer = (answer * power) % MOD

answer = (2 * answer) % MOD

print(answer)
```---

 # 代码演练

 ### 黄金一代

 的`segmented_sieve`函数生成所有素数$10^8$高效，无需一次存储所有数字。 

- 首先，它计算所有素数$\sqrt{10^8}=10^4$。 
- 然后以块大小处理剩余范围$10^6$。 

这使得内存使用量保持在较低水平。 

---

 ### 计算 LCM

 对于每个素数$p$,```python
power = p
while power * p <= N:
    power *= p
```计算$$p^{\lfloor \log_p N\rfloor}.$$将这些相乘得出$$\operatorname{lcm}(1,\dots,N).$$一切都是模数完成的$10^9+7$。 

最后我们乘以$2$。
