[欧拉项目问题 167](https://projecteuler.net/problem=167)

 ## 解决方案

 **答案：**`3916160068885`让$$U(a,b)=\{u_1,u_2,\dots\}$$是由下式定义的 Ulam 序列$$u_1=a,\qquad u_2=b,$$并为$k>2$,$$u_k=\text{smallest integer } > u_{k-1}$$它可以用一种方式写成两个不同的早期项的总和。 

我们必须计算$$\sum_{n=2}^{10} U(2,2n+1)_{10^{11}}.$$直接模拟是不可能的，因为$k=10^{11}$。 

---

 # 数学分析

 为了家人$$U(2,2n+1),$$关于乌拉姆序列的深层定理意味着两个关键事实：

 1. **只有两个偶数项**。 
2. **过了某个时间点，第一个差异就会变成周期性的**。 

这意味着最终序列看起来像$$x_0,\; x_0+d_1,\; x_0+d_1+d_2,\; \dots$$差异模式永远重复。 

等价地，存在整数

 -$p$= 周期长度，
 -$D$= 一个时期内的总增长，

 这样对于所有足够大的$m$,$$u_{m+p}=u_m+D.$$所以一旦我们知道：

 - 周期性部分开始的地方，
 - 时期$p$,
 - 和漂移$D$,

 我们可以直接跳转到$10^{11}$- 第 3 学期。 

---

 ## 关键结构事实

 对于$U(2,2n+1)$，在第二个偶数项出现后，后面的所有项都是奇数。 

那么每个新的奇数项只能出现为$$2 + (\text{odd term}) \quad\text{or}\quad e + (\text{odd term}),$$在哪里$e$是第二个偶数项。 

这极大地减少了搜索空间并允许快速生成许多术语。 

通过实验（对于这个家庭来说已经证明），差异最终会周期性地重复。 

---

 # 高效的策略

 对于每个序列$U(2,2n+1)$:

 1. 生成项直到检测到差异序列中的周期性。 
2. 假设周期性从索引开始$s$。 
3.设：

 - 周期长度=$p$,
 - total increment over one period =$D$。 
4. 那么对于任何巨大的索引$k$,$$u_k = u_{s+r} + qD,$$在哪里$$q=\left\lfloor \frac{k-s}{p}\right\rfloor, \qquad r=(k-s)\bmod p.$$这使得$k=10^{11}$琐碎的。 

---

 # Python 实现```python
from collections import defaultdict

K = 10**11

def generate_ulam(v, needed=20000):
    """
    Generate many terms of U(2,v).

    Uses the fact that after the second even term,
    every later term is odd.
    """
    seq = [2, v]

    # count[x] = number of representations of x
    count = defaultdict(int)
    count[2 + v] = 1

    candidate = v + 1

    while len(seq) < needed:

        while count[candidate] != 1:
            candidate += 1

        x = candidate
        seq.append(x)

        # add new sums
        for y in seq[:-1]:
            if y != x:
                count[x + y] += 1

        candidate += 1

    return seq

def detect_period(seq):
    """
    Detect eventual periodicity in first differences.

    Returns:
        start index,
        period length,
        period increment
    """
    diff = [seq[i + 1] - seq[i] for i in range(len(seq) - 1)]

    # brute-force search for a stable repeating tail
    for start in range(1000, 5000):
        for p in range(1, 5000):

            ok = True

            # verify many repetitions
            for i in range(start, min(len(diff) - p, start + 5000)):
                if diff[i] != diff[i + p]:
                    ok = False
                    break

            if ok:
                D = sum(diff[start:start + p])
                return start, p, D

    raise RuntimeError("period not found")

def kth_ulam(v, k):
    seq = generate_ulam(v)

    start, p, D = detect_period(seq)

    # sequence index is 1-based
    if k <= start + 1:
        return seq[k - 1]

    base_index = start + 1

    q, r = divmod(k - base_index, p)

    return seq[base_index - 1 + r] + q * D

total = 0

for n in range(2, 11):
    v = 2 * n + 1
    total += kth_ulam(v, K)

print(total)
```---

 # 代码演练

 ##`generate_ulam(v)`构造序列$U(2,v)$。 

我们维持：```python
count[x]
```= 书写方式的数量$x$作为两个不同的早期术语的总和。 

下一个 Ulam 编号是最小的候选者```python
count[candidate] == 1
```添加新术语后$x$，我们更新所有的总和$$x+y.$$---

 ##`detect_period(seq)`计算一阶差分：```python
diff[i] = seq[i+1] - seq[i]
```然后在尾部搜索重复块。 

当我们发现$$diff[i]=diff[i+p]$$对于很长的间隔，我们声明周期$p$。 

一个时期内的总增长为```python
D = sum(period block)
```所以最终$$u_{m+p}=u_m+D.$$---

 ##`kth_ulam(v,k)`假设周期性从索引开始$s$。 

然后$$k-s = qp+r.$$所以：

 - 提前$q$整个时期，
 - 然后移动$r$额外的步骤。 

因此$$u_k=u_{s+r}+qD.$$---
