[欧拉项目问题 152](https://projecteuler.net/problem=152)

 ## 解决方案

 **答案：**`301`对所有子集进行直接暴力搜索$\{2,3,\dots,80\}$是不可能的：$$2^{79} \approx 6\times 10^{23}.$$解决该问题的关键是利用来自分母和模整除性的强算术约束。 

---

 # 数学分析

 我们寻找所有子集$S \subseteq \{2,\dots,80\}$这样$$\sum_{n\in S}\frac1{n^2}=\frac12.$$定义$$f(n)=\frac1{n^2}.$$中心观察是，由于素因数整除性限制，大多数整数永远无法参与有效的解决方案。 

---

 ## 1.素幂整除滤波

 假设有一个素数$p$恰好出现在一个分母项中，最大$p$-adic力量。 

示例：如果$n$可以整除$p^k$并且没有其他选定的分母包含$p^k$，那么在清除分母后，该项贡献的分子是非零模$p$，而所有其他的都消失模$p$。 因此取消是不可能的。 

这造成了极其严格的限制。 

---

 ### 示例：素数$79$唯一能被整除的分母$79$是$79$本身。 

如果$1/79^2$出现了，然后乘以公分母后，我们会得到一个非零余数模$79$，无法取消。 

因此：$$79 \notin S.$$同样的论证消除了许多数字。 

---

 ## 2. 构造容许集

 标准递归消除仅留下整数：$$\{2,3,4,5,6,7,8,9,10,12,14,15,18,20,21,24,28,30,35,36,40,42,45,56,60,63,70,72\}.$$每个有效的解决方案都必须包含在该集合中。 

这极大地减少了搜索空间：$$2^{28}\approx 2.68\times10^8,$$仍然很大，但现在可以通过中间相遇加上精确的有理算术来实现。 

---

 ## 3. 精确的整数表示

 让$$L=\operatorname{lcm}(n^2 : n\in A),$$在哪里$A$是容许集。 

然后$$\frac1{n^2} = \frac{L/n^2}{L}.$$所以方程变成$$\sum_{n\in S} \frac{L}{n^2} = \frac{L}{2}.$$现在一切都是整数子集和。 

定义$$a_n = \frac{L}{n^2},\qquad T=\frac{L}{2}.$$我们必须计算子集$$\sum a_n = T.$$---

 ## 4. 中间相遇

 将可接受的集合分成两半：

 - 左半边$A_1$- 右半边$A_2$枚举每一半的所有子集和。 

如果$$x+y=T,$$和$x$从左边和$y$从右边开始，然后它们一起形成一个有效的解决方案。 

复杂度大致变为$$2^{14}+2^{14},$$这是很小的。 

---

 # Python 实现```python
from math import gcd
from functools import reduce
from collections import Counter

# ------------------------------------------------------------
# Utility: least common multiple
# ------------------------------------------------------------

def lcm(a, b):
    return a * b // gcd(a, b)

# ------------------------------------------------------------
# Step 1:
# After modular/divisibility elimination, only these numbers
# can possibly appear in a solution.
# ------------------------------------------------------------

allowed = [
    2, 3, 4, 5, 6, 7, 8, 9, 10,
    12, 14, 15, 18, 20, 21, 24,
    28, 30, 35, 36, 40, 42, 45,
    56, 60, 63, 70, 72
]

# ------------------------------------------------------------
# Step 2:
# Convert the reciprocal-square equation into an integer
# subset-sum equation.
# ------------------------------------------------------------

# L = lcm of all n^2
L = reduce(lcm, (n * n for n in allowed))

# Integer weights
weights = [L // (n * n) for n in allowed]

# Target sum
TARGET = L // 2

# ------------------------------------------------------------
# Step 3:
# Meet-in-the-middle
# ------------------------------------------------------------

mid = len(weights) // 2

left = weights[:mid]
right = weights[mid:]

def subset_sums(arr):
    """
    Return Counter mapping:
        subset_sum -> number_of_ways
    """
    m = len(arr)
    sums = Counter()

    for mask in range(1 << m):
        s = 0
        for i in range(m):
            if mask & (1 << i):
                s += arr[i]
        sums[s] += 1

    return sums

left_sums = subset_sums(left)
right_sums = subset_sums(right)

# ------------------------------------------------------------
# Step 4:
# Count complementary pairs
# ------------------------------------------------------------

answer = 0

for s_left, count_left in left_sums.items():
    needed = TARGET - s_left

    if needed in right_sums:
        answer += count_left * right_sums[needed]

print(answer)
```---

 # 代码演练

 ## 实用函数```python
def lcm(a, b):
    return a * b // gcd(a, b)
```使用计算最小公倍数$$\operatorname{lcm}(a,b)=\frac{ab}{\gcd(a,b)}.$$---

 ## 允许的分母```python
allowed = [...]
```这是从模整除性参数中获得的关键数学过滤集。 

所有其他整数$2\le n\le 80$在任何解决方案中都是不可能的。 

---

 ## 转换为整数```python
L = reduce(lcm, (n * n for n in allowed))
```计算所有平方倒数的公分母。 

然后：```python
weights = [L // (n * n) for n in allowed]
```将每个倒数平方表示为整数分子。 

原方程$$\sum \frac1{n^2}=\frac12$$变成整数方程$$\sum \text{weights} = \frac{L}{2}.$$---

 ## 中间相遇```python
mid = len(weights) // 2
```将问题分成两半。 

---

 ### 枚举子集和```python
for mask in range(1 << m):
```枚举半集的每个子集。 

对于每个子集，我们计算其总和。 

这`Counter`存储有多少个子集达到每个总和。 

---

 ## 匹配互补和

 如果左子集总和为$s$，那么右子集之和必须为$$TARGET - s.$$所以：```python
answer += count_left * right_sums[needed]
```计算所有兼容对。
