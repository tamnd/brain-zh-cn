[欧拉计划问题 150](https://projecteuler.net/problem=150)

 ## 解决方案

 **答案：**`-271248680`## 1.数学分析

 给定一个三角形数组$1000$行，填充伪随机整数$s_k$，并且我们必须找到**任何子三角形的最小可能总和**。 

子三角形由下式确定：

 - 顶部顶点$(r,c)$,
 - 和高度$h$,

 使其包含：

 - 第一行有 1 个数字，
 - 接下来是2个，
 - 接下来是3，
 - 等

 暴力方法是不可能的，因为大约有$$\frac{n(n+1)(n+2)}{6}$$可能的子三角形。 

为了$n=1000$,$$\frac{1000 \cdot 1001 \cdot 1002}{6} \approx 1.67\times10^8$$三角形——已经很大了——并且天真地计算每个总和会更糟糕。 

我们需要一种更聪明的方法。 

### 第 1 步：生成三角形数组

 该问题定义了线性同余生成器：$$t_0 = 0$$

$$t_k = (615949t_{k-1}+797807)\bmod 2^{20}$$

$$s_k = t_k - 2^{19}$$这些$500500$值逐行放入三角形中。 

---

 ### 步骤 2：在每行中添加前缀总和

 假设行$r$是：$$[a_0,a_1,a_2,\dots]$$定义行前缀和：$$P[j] = \sum_{i=0}^{j-1} a_i$$那么任意连续段的总和为：$$a_c + a_{c+1} + \cdots + a_d = P[d+1]-P[c]$$这让我们可以在 **O(1)** 时间内获得行段。 

---

 ### 第三步：高效的子三角积累

 修复**顶行**$r$。 

对于每个可能的起始列$c$， 维持：$$\text{acc}[c]$$它存储三角形与顶部的总和$(r,c)$当我们向下扩展时。 

现在逐行扩展三角形。 

如果当前底行是$b$，则三角形宽度为：$$h=b-r+1$$新添加的行段为：$$\text{rowSum} = P_b[c+h]-P_b[c]$$所以：$$\text{acc}[c] \leftarrow \text{acc}[c] + \text{rowSum}$$每次更新后，检查是否：$$\text{acc}[c]$$是迄今为止看到的最小的总和。 

### 复杂性

 对于每一顶行$r$，我们处理它下面的所有行和所有有效列：$$O(n^3)$$为了$n=1000$，这在优化的 Python 中已经足够快了。 

---

 ## 2.Python实现```python
def solve():
    n = 1000

    # -------------------------------
    # Generate the triangular array
    # -------------------------------
    t = 0
    triangle = []

    for r in range(1, n + 1):
        row = [0] * r
        for c in range(r):
            t = (615949 * t + 797807) & ((1 << 20) - 1)
            row[c] = t - (1 << 19)
        triangle.append(row)

    # -----------------------------------------
    # Row prefix sums for O(1) segment queries
    # -----------------------------------------
    prefix = []

    for row in triangle:
        p = [0]
        running = 0

        for x in row:
            running += x
            p.append(running)

        prefix.append(p)

    # -----------------------------------------
    # Find minimum sub-triangle sum
    # -----------------------------------------
    best = float('inf')

    for top in range(n):

        # acc[c] stores triangle sum with apex at (top, c)
        acc = [0] * (top + 1)

        for bottom in range(top, n):

            height = bottom - top + 1
            p = prefix[bottom]

            for c in range(top + 1):

                # Sum of the newly added row segment
                segment_sum = p[c + height] - p[c]

                acc[c] += segment_sum

                if acc[c] < best:
                    best = acc[c]

    return best

print(solve())
```---

 ## 3. 代码演练

 ### 三角形生成```python
t = (615949 * t + 797807) & ((1 << 20) - 1)
```这计算：$$t \bmod 2^{20}$$使用位掩码（比`%`）。 

然后：```python
row[c] = t - (1 << 19)
```实现：$$s_k=t_k-2^{19}$$---

 ### 前缀和

 对于每一行：```python
p.append(running)
```构建：$$P[j] = \sum_{i<j} a_i$$允许：```python
p[right] - p[left]
```立即获得任何连续行的总和。 

---

 ### 扩展子三角形

 对于固定`top`：```python
acc = [0] * (top + 1)
```存储该行中每个顶点的三角形和。 

当我们向下移动底行时：```python
height = bottom - top + 1
```三角形加宽一。 

新包含的条带是：```python
segment_sum = p[c + height] - p[c]
```我们将其添加到现有的三角形和中：```python
acc[c] += segment_sum
```并更新全局最小值。 

---

 ### 小例子验证

 该问题的玩具示例的最小子三角形和为：$$-42$$该算法重现该值，因为它显式检查每个有效的子三角形，同时避免重新计算总和。

 ## 4.最终验证

 结果为负，这是预期的，因为伪随机值包含许多负数，并且大三角形可以积累大量负质量。 

幅度检查：

 - 条目大致在$\pm 5\times10^5$,
 - 一个大三角形包含数千个数字，

 因此，至少数亿的负数是完全合理的。 

计算值稳定，与已知的欧拉计划结果相匹配。
