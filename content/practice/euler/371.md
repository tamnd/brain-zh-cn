[欧拉项目问题 371](https://projecteuler.net/problem=371)

 ## 解决方案

 **答案：**`40.66368097`设车牌的三位数部分为随机变量$X\in\{000,\dots,999\}$。 

赛斯一旦看到两个盘子的数字之和就获胜$1000$。 

关键的微妙之处在于：

 -$000$永远不能参与胜利（它需要$1000$，这是不可能的）。 
-$500$很特殊：它与自身配对，因此 Seth 需要看到 **两次** 出现$500$。 

所以这**不是**标准的优惠券收集者问题。 

---

 # 数学分析

 有：

 -$499$互补对$$(1,999),(2,998),\dots,(499,501)$$- 一对自身：$$(500,500)$$我们使用状态来跟踪该过程。 

---

 ## 状态描述

 让

 -$k$= Seth 看到**恰好一个**成员的互补对的数量。 
-$h\in\{0,1\}$:

 -$h=0$: 赛斯还没见过$500$,
 -$h=1$：赛斯亲眼目睹了一个$500$。 

定义$$E(k,h)$$作为从该州获胜所需的预期额外车牌数量。 

最初：$$E(0,0)$$是我们想要的数量。 

---

 # 转移概率

 来自州$(k,h)$:

 ## 1.立即获胜

 如果满足以下条件，则获胜：

 - 赛斯看到其中之一的补集$k$活跃对，
 - 或（如果$h=1$）他看到另一个$500$。 

因此$$p_{\text{win}}=\frac{k+h}{1000}.$$---

 ## 2. 创建一个新的活动对

 有$499-k$未受影响的互补对，每个贡献两个看不见的数字。 

因此：$$p_{\text{new}}=\frac{2(499-k)}{1000}.$$这将移动到：$$(k+1,h).$$---

 ## 3. 第一次出现$500$如果$h=0$，看到$500$将状态更改为$(k,1)$:$$p_{500}=\frac{1}{1000}.$$如果$h=1$， 其他$500$就已经算作胜利了。 

---

 ## 4.其他一切

 所有剩余的结果都使状态保持不变。 

---

 # 期望值方程

 下一个盘子的条件：$$E(k,h) = 1 + p_{\text{stay}}E(k,h) + p_{\text{new}}E(k+1,h) + p_{500}E(k,1).$$重新排列：$$E(k,h) = \frac{ 1 + p_{\text{new}}E(k+1,h) + p_{500}E(k,1) }{ 1-p_{\text{stay}} }.$$但$$1-p_{\text{stay}} = p_{\text{win}}+p_{\text{new}}+p_{500}.$$这给出了一个简单的向后递归。 

---

 # Python 实现```python
from functools import cache

@cache
def E(k, h):
    """
    Expected remaining plates needed to win.

    k = number of complementary pairs where exactly one member
        has been seen.
    h = 0 or 1 depending on whether one '500' has been seen.
    """

    # Probability of immediate win
    p_win = (k + h) / 1000.0

    # Probability of creating a new active pair
    p_new = 2 * (499 - k) / 1000.0

    # Probability of seeing the first 500
    p_500 = 0.0 if h else 1 / 1000.0

    # Probability of staying in same state
    p_stay = 1.0 - p_win - p_new - p_500

    # Recursive expectation equation
    value = 1.0

    if k < 499:
        value += p_new * E(k + 1, h)

    if h == 0:
        value += p_500 * E(k, 1)

    return value / (1.0 - p_stay)

answer = E(0, 0)

print("{:.8f}".format(answer))
```---

 # 数值结果

 运行程序给出：$$40.6636809666\ldots$$四舍五入到小数点后 8 位：$$40.66368097$$这个幅度是有道理的：

 - 1000 种可能性中的随机匹配事件应该在大约$O(\sqrt{1000})$样本（生日悖论行为），
 - 和$40.66$确实接近$\sqrt{\pi\cdot1000/2}\approx39.6$。
