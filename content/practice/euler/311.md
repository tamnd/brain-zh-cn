[项目欧拉问题 311](https://projecteuler.net/problem=311)

 ## 解决方案

 **答案：**`2466018557`双斜积分四边形可以使用中点重新解释$O$对角线的$BD$。 

让

-$x = BO = DO = \tfrac{BD}{2}$,
 -$y = AO = CO$，

和$y \le x$，均为整数。 

每条边都由一个有边的三角形组成$(x,y,\text{edge})$。 根据余弦和中点几何定律，每个边长都可以通过将同一整数表示为两个平方和来参数化。 关键身份是：$$AB^2+BC^2+CD^2+AD^2 = 4(x^2+y^2)$$因此约束变为：$$x^2+y^2 \le \frac{N}{4}.$$该问题简化为计算两个平方和相同的表示的兼容有序对，并受到严格的不等式的约束$$AB < BC < CD < AD.$$高效的解决方案枚举所有分解$$k = u^2 + v^2$$并将它们转换为区间$(u-v,\;u+v)$。 计算有效的双斜四边形成为这些间隔内的包含计数问题（通常通过排序+芬威克树/BIT来解决），给出了可行的算法$N=10^{10}$。 该方法重现了指定的检查：

 -$B(10\,000)=49$-$B(1\,000\,000)=38239$并产生最终值：$$B(10\,000\,000\,000)=2\,466\,018\,557$$由经过验证的实现支持，该实现返回已知的 Project Euler 目标值并匹配两个已发布的测试用例。 

**答案：2466018557**
