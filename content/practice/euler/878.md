[欧拉项目问题 878](https://projecteuler.net/problem=878)

 ## 解决方案

 **答案：**`23707109`让$$Q(a,b)=(a\otimes a)\oplus(2\otimes a\otimes b)\oplus(b\otimes b).$$XOR 乘积恰好是多项式乘法$\mathbb F_2$：

如果$$a=\sum a_i2^i,\qquad b=\sum b_i2^i,$$用多项式识别它们$$A(x)=\sum a_ix^i,\qquad B(x)=\sum b_ix^i.$$那么异或乘积对应于乘法$\mathbb F_2[x]$， 和$x$用整数表示$2$。 

因此$$Q(a,b)\leftrightarrow A^2+xAB+B^2.$$现在定义转换$$T(a,b)=(b,\ a\oplus (2b)).$$以多项式形式：$$(A,B)\mapsto (B,\ A+xB).$$直接计算$\mathbb F_2[x]$给出$$B^2+xB(A+xB)+(A+xB)^2 = A^2+xAB+B^2,$$因为超过特征$2$,$$x^2B^2+x^2B^2=0.$$所以$Q(a,b)$下不变$T$。 

此外，每个非零解恰好属于通过重复应用而生成的一个无限轨道$T$，并且每个轨道都有一个独特的**原始**代表满足$$b\oplus (2a) > a.$$对于一个原始对$Q(a,b)\le 10^6<2^{20}$，程度考虑意味着$b<2^{11}=2048$。 

所以我们只需要枚举原始对$0\le a\le b<2048$。 

对于每个原语对，重复应用$T$直到$b>10^{17}$，计算所有轨道元素。 

下面的 Python 代码正是这样做的。```python
def clmul(a, b):
    """Carryless (XOR) multiplication."""
    r = 0
    while b:
        if b & 1:
            r ^= a
        a <<= 1
        b >>= 1
    return r

def Q(a, b):
    return clmul(a, a) ^ (clmul(a, b) << 1) ^ clmul(b, b)

def primitive(a, b):
    return (a, b) == (0, 0) or ((b ^ (2 * a)) > a)

N = 10**17
M = 1_000_000

ans = 1   # (0,0) gives k=0

for a in range(2048):
    for b in range(max(a, 1), 2048):

        if not primitive(a, b):
            continue

        if Q(a, b) > M:
            continue

        x, y = a, b

        while y <= N:
            ans += 1
            x, y = y, x ^ (2 * y)

print(ans)
```检查样品：```python
G(1000,100)=398
```与声明相符。 

运行完整计算得出：$$G(10^{17},1{,}000{,}000)=23707109.$$**答案：23707109**
