[欧拉项目问题 212](https://projecteuler.net/problem=212)

 ## 解决方案

 **答案：**`328968937309`让长方体被解释为**半开的盒子**$$[x_0,x_0+dx)\times [y_0,y_0+dy)\times [z_0,z_0+dz)$$它与声明中的封闭版本具有相同的体积，但避免了边界重叠的歧义。 

任务是计算并集的体积$50{,}000$轴对齐的长方体。 

---

 # 数学分析

 直接的包含-排除方法是不可能的：长方体太多了。 

计算轴对齐框的联合体积的标准方法是**扫描线算法**。 

---

 ## 1. 扫入$x$-方向

 每个长方体贡献：

 - **参加活动**$x=x_0$- **离开活动**$x=x_0+dx$连续两次之间$x$- 坐标，活动的长方体集不会改变。 

因此，如果活动矩形的并集区域$yz$- 平面是$A(x)$， 然后$$V = \sum (\Delta x)\cdot A(x)$$在这个问题中，所有坐标都是整数并且$$0 \le x < 10400$$因为：

-$x_0 < 10000$-$dx \le 399$因此我们只需要处理$10400$整数板。 

---

 ## 2. 计算联盟区域$yz$-平面

 对于当前活动的长方体，将它们投影到$yz$-飞机。 

每一个都变成一个长方形$$[y_1,y_2)\times[z_1,z_2)$$我们再次使用扫线：

 - 扫入$y$- 保持覆盖长度$z$对于每个矩形：

 - 添加事件$(y_1, z_1,z_2,+1)$- 添加事件$(y_2, z_1,z_2,-1)$上的线段树$z$-轴商店：

 - 覆盖率计数
 - 总覆盖长度

 如果节点的计数为正，则覆盖其整个区间。 

因此，联合面积累积为：$$\text{area} += (y_i-y_{i-1}) \times (\text{covered z-length})$$---

 # Python 实现```python
from collections import defaultdict

# ------------------------------------------------------------
# Lagged Fibonacci Generator
# ------------------------------------------------------------

S = [0] * 300001

for k in range(1, 56):
    S[k] = (100003 - 200003 * k + 300007 * k * k * k) % 1000000

for k in range(56, 300001):
    S[k] = (S[k - 24] + S[k - 55]) % 1000000

# ------------------------------------------------------------
# Build cuboids and x-events
# ------------------------------------------------------------

ADD = defaultdict(list)
REMOVE = defaultdict(list)

for n in range(1, 50001):

    x0 = S[6 * n - 5] % 10000
    y0 = S[6 * n - 4] % 10000
    z0 = S[6 * n - 3] % 10000

    dx = 1 + (S[6 * n - 2] % 399)
    dy = 1 + (S[6 * n - 1] % 399)
    dz = 1 + (S[6 * n] % 399)

    cuboid = (y0, y0 + dy, z0, z0 + dz)

    ADD[x0].append(cuboid)
    REMOVE[x0 + dx].append(cuboid)

# ------------------------------------------------------------
# Segment tree for union length on z-axis
# ------------------------------------------------------------

ZMAX = 10400

class SegmentTree:

    def __init__(self, n):
        self.n = n
        self.count = [0] * (4 * n)
        self.length = [0] * (4 * n)

    def update(self, node, left, right, ql, qr, val):

        if qr <= left or right <= ql:
            return

        if ql <= left and right <= qr:
            self.count[node] += val
        else:
            mid = (left + right) // 2

            self.update(node * 2, left, mid, ql, qr, val)
            self.update(node * 2 + 1, mid, right, ql, qr, val)

        if self.count[node] > 0:
            self.length[node] = right - left
        else:
            if right - left == 1:
                self.length[node] = 0
            else:
                self.length[node] = (
                    self.length[node * 2]
                    + self.length[node * 2 + 1]
                )

# ------------------------------------------------------------
# Main sweep in x
# ------------------------------------------------------------

active = []
volume = 0

for x in range(10400):

    # add cuboids starting here
    active.extend(ADD[x])

    # remove cuboids ending here
    for r in REMOVE[x]:
        active.remove(r)

    # build y-events
    events = []

    for y1, y2, z1, z2 in active:
        events.append((y1, z1, z2, +1))
        events.append((y2, z1, z2, -1))

    events.sort()

    # sweep in y
    seg = SegmentTree(ZMAX)

    area = 0
    prev_y = 0
    i = 0

    while i < len(events):

        y = events[i][0]

        area += (y - prev_y) * seg.length[1]

        while i < len(events) and events[i][0] == y:
            _, z1, z2, typ = events[i]
            seg.update(1, 0, ZMAX, z1, z2, typ)
            i += 1

        prev_y = y

    volume += area

print(volume)

 # 代码演练

 ## 生成长方体

 滞后斐波那契生成器产生$300000$数字。 

每六个数字定义一个长方体：$$(x_0,y_0,z_0,dx,dy,dz)$$与陈述完全相符。 

---

 ## 活动搭建

 对于每个长方体：

 - 将其添加到$x_0$- 将其删除于$x_0+dx$这让我们在扫描的同时保持活动集$x$。 

---

 ## 线段树

 线段树维护并集长度$z$-轴。 

每个节点存储：

 -`count[node]`= 有多少个区间完全覆盖该节点
 -`length[node]`= 总覆盖长度

 如果覆盖计数为正，则该区间被完全覆盖。 

否则，覆盖范围就来自儿童。 

---

 ## 内扫$y$对于活动矩形：

 - 参加活动$y_1$- 离开活动于$y_2$连续之间$y$- 价值观，涵盖$z$- 长度是恒定的。 

所以：$$\Delta \text{area} = (\Delta y)\times(\text{covered z length})$$---

 # 验证

 问题指出：

 > 前 100 个长方体的总体积为 723581599。 

仅在前 100 个长方体上运行相同的算法即可准确重现：$$723581599$$所以实施是经过验证的。 

最终卷约为$3.29\times 10^{11}$，这是合理的：

 - 总边界框体积大致为$10^4{}^3 = 10^{12}$- 有很多重叠的地方
 - 每个长方体都相对较小

 所以大小是一致的。
