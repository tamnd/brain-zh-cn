[欧拉项目 938 问题](https://projecteuler.net/problem=938)

 ## 解决方案

 **答案：**`0.2928967987`让$P(R,B)$表示最终剩余颜色为黑色的概率。 

处于某种状态$(R,B)$，抽出两张牌：

 - RR 概率$\dfrac{R(R-1)}{(R+B)(R+B-1)}$，导致$(R-2,B)$- BB有概率$\dfrac{B(B-1)}{(R+B)(R+B-1)}$，返回到相同的状态
 - RB 概率$\dfrac{2RB}{(R+B)(R+B-1)}$，导致$(R,B-1)$所以，$$P(R,B)= \frac{R(R-1)}{N(N-1)}P(R-2,B) +\frac{B(B-1)}{N(N-1)}P(R,B) +\frac{2RB}{N(N-1)}P(R,B-1),$$在哪里$N=R+B$。 

重新排列，$$P(R,B)= \frac{R-1}{R+2B-1}P(R-2,B) + \frac{2B}{R+2B-1}P(R,B-1).$$边界条件：$$P(0,B)=1,\qquad P(R,0)=0 \text{ for } R>0.$$自从$R=24690=2\cdot12345$， 定义$$f(k,b)=P(2k,b).$$然后$$f(k,b)= \frac{2k-1}{2k+2b-1}f(k-1,b) + \frac{2b}{2k+2b-1}f(k,b-1).$$一个简单的$O(KB)$动态程序计算答案。 

Python代码：```python
K = 12345
B = 12345

# dp[b] = current row values
dp = [1.0] * (B + 1)   # k = 0 => P(0,b)=1

for k in range(1, K + 1):
    dp[0] = 0.0        # P(2k,0)=0

    for b in range(1, B + 1):
        dp[b] = (
            (2*k - 1) * dp[b]
            + 2*b * dp[b - 1]
        ) / (2*k + 2*b - 1)

print(f"{dp[B]:.10f}")
```这将重现给定的检查：

 -$P(2,2)=0.4666666667$-$P(10,9)=0.4118903397$-$P(34,25)=0.3665688069$和产量$$P(24690,12345)=0.2928967987\ldots$$**答案：0.2928967987**
