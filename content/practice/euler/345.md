[欧拉项目问题 345](https://projecteuler.net/problem=345)

 ## 解决方案

 **答案：**`13938`这是一个经典的**分配问题**：

 - 我们必须从每一行中恰好选择一个数字。 
- 两个选定的数字不能来自同一列。 
- 我们想要**最大可能的金额**。 

从数学上来说，如果矩阵是$A=(a_{ij})$，我们寻求$$\max_{\sigma \in S_n} \sum_{i=1}^{n} a_{i,\sigma(i)}$$在哪里$S_n$是排列的集合$\{0,1,\dots,n-1\}$。 

对于一个$15\times 15$矩阵，暴力破解一切$15!$排列是不可能的：$$15! \approx 1.3\times 10^{12}$$所以我们需要动态规划。 

---

 # 数学分析

 让：

 -$n = 15$-$dp(mask)$= 将一些行分配给由 表示的列集后可实现的最大总和`mask`。 

长度为 15 的位掩码表示哪些列已被使用。 

如果`mask`有$k$位设置，那么我们已经分配了行$0,1,\dots,k-1$。 

过渡：

 对于每个未使用的列$j$,$$dp(mask \cup \{j\}) = \max\left( dp(mask \cup \{j\}), \; dp(mask)+a_{k,j} \right)$$在哪里$$k = \text{number of set bits in } mask$$状态总数为：$$2^{15} = 32768$$每个状态最多尝试 15 次转换，因此复杂度大致为$$15 \cdot 2^{15} \approx 5\times 10^5$$这是很小的。

n = len(matrix)

# dp[mask] = best sum achievable using columns in mask
dp = [-1] * (1 << n)
dp[0] = 0

for mask in range(1 << n):

    # Number of rows already assigned
    row = bin(mask).count("1")

    # If all rows assigned, skip transitions
    if row == n:
        continue

    # Try assigning current row to any unused column
    for col in range(n):

        # If column not used yet
        if not (mask & (1 << col)):

            new_mask = mask | (1 << col)

            dp[new_mask] = max(
                dp[new_mask],
                dp[mask] + matrix[row][col]
            )

answer = dp[(1 << n) - 1]

print(answer)
