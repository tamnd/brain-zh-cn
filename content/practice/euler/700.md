[欧拉项目700问题](https://projecteuler.net/problem=700)

 ## 解决方案

 **答案：**`1517926517777556`让$$a = 1504170715041707,\qquad m = 4503599627370517.$$我们研究序列$$E_n = an \pmod m.$$Eulercoin 是一个严格小于之前所有术语的术语。 

我们必须计算所有 Eulercoin 的总和。 

---

 # 1.数学分析

 顺序是$$E_n = an - m\left\lfloor \frac{an}{m}\right\rfloor.$$因为$\gcd(a,m)=1$，该序列是整数的排列$1,\dots,m-1$。 

关键的观察结果是，Eulercoins 正是这个模块化序列的连续最小值。 

前几个术语是：$$\begin{aligned} E_1 &= 1504170715041707,\\ E_2 &= 3008341430083414,\\ E_3 &= 8912517754604. \end{aligned}$$自从$$8912517754604 < 1504170715041707,$$第三项是第二个Eulercoin。 

---

 ## 核心数论洞察

 直接模拟是不可能的，因为$m \approx 4.5\times10^{15}$。 

突破来自模逆。 

自从$\gcd(a,m)=1$, 存在$a^{-1}$这样$$aa^{-1}\equiv 1\pmod m.$$使用扩展欧几里得算法：$$a^{-1} \equiv 3451657199285664 \pmod m.$$这意味着：$$n \equiv a^{-1}E_n \pmod m.$$---

 ## 两个互补的搜索

 Eulercoins自然地分为两个阶段。 

### 第一阶段：大额 Eulercoin

 生成正向序列：$$E_n = (E_{n-1}+a)\bmod m,$$只保留新的最小值。 

这些最小值迅速下降。 

经过相对较少的迭代后，Eulercoin 变得很小。 

---

 ### 第 2 阶段：小型 Eulercoins

 假设$x$是一种欧拉币。 

那么它的索引就是$$n_x \equiv a^{-1}x \pmod m.$$一个数字$x$是 Eulercoin 当且仅当其对应的索引$n_x$小于已检查的所有较小正整数的索引。 

所以对于小$x$，我们可以测试：$$n_x = (a^{-1}x)\bmod m.$$如果这个指数是迄今为止看到的最小的，那么$x$是一种欧拉币。 

第二种方法可以非常快速地找到微小的 Eulercoins。 

---

 ## 为什么这有效

 假设$x<y$。 

如果$$n_x < n_y,$$然后$x$在序列中出现早于$y$， 所以$y$不能是第一次出现以下最小值$x$。 

因此，Eulercoins 精确地对应于模逆指数为新最小值的值。 

这将困难的前向模块化扫描转换为对小整数的非常便宜的搜索。 

---

 # 2.Python实现```python
from math import gcd

A = 1504170715041707
M = 4503599627370517

# ------------------------------------------------------------
# Extended Euclidean algorithm
# ------------------------------------------------------------

def egcd(a, b):
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = egcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)

# modular inverse of A mod M
g, x, y = egcd(A, M)
A_INV = x % M

# ------------------------------------------------------------
# Phase 1: generate large Eulercoins directly
# ------------------------------------------------------------

coins = []

current = A
minimum = A

coins.append(A)

while current > 10_000_000:
    current = (current + A) % M

    if current < minimum:
        minimum = current
        coins.append(current)

# ------------------------------------------------------------
# Phase 2: generate small Eulercoins using inverse mapping
# ------------------------------------------------------------

best_index = M

for x in range(1, minimum):
    idx = (A_INV * x) % M

    if idx < best_index:
        best_index = idx
        coins.append(x)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

answer = sum(coins)

print(answer)
```---

 ## 步骤2：正向搜索大额Eulercoin```python

```这会生成连续的序列项。 

每当：```python
if current < minimum:
```我们发现了一种新的 Eulercoin。 

最小值序列开始：$$1504170715041707,\; 8912517754604,\; 2044785486369,\; 1311409677241,\dots$$---

 ## 第三步：反向搜索小欧拉币

 对于每个小整数$x$，计算它出现的位置：```python
idx = (A_INV * x) % M
```如果这个指数是迄今为止看到的最小的，那么$x$必须出现在所有较小的候选者之前，因此是 Eulercoin。 

这可以有效地发现所有剩余的小型 Eulercoins，直至$1$。
