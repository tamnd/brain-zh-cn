[欧拉项目问题 352](https://projecteuler.net/problem=352)

 ## 解决方案

 **答案：**`378563.260589`让$p$为每只羊的感染概率，令$$q = 1-p.$$我们必须计算最佳的预期测试数量$T(s,p)$为了$s=10000$, 总结$$p=0.01,0.02,\dots,0.50.$$关键的困难在于，在汇总测试结果呈阳性后，我们获得信息：我们知道该池中**至少一只**羊被感染。 

该条件信息改变了最优延续策略。 

---

 # 1.数学分析

 我们定义了两个 DP 函数。 

---

 ## A.$T(n)$

$T(n)$= 完全分类所需的最小预期测试数量$n$当每只羊独立感染的概率$p$。 

---

 ## B.$C(n)$

$C(n)$= 分类所需的**额外**测试的最小预期数量$n$羊**鉴于我们已经知道至少一只被感染**。 

清楚地，$$C(1)=0$$因为如果已知一只羊属于阳性池，那么它一定是被感染的。 

还，$$T(0)=0,\qquad T(1)=1.$$---

 # 2. 复发$T(n)$假设第一个动作是：

 - 选择一组大小$m$,
 - 对这些进行一项汇总测试$m$羊。 

### 案例 1：汇总测试呈阴性

 概率：$$q^m.$$然后全部$m$羊已经干净了，剩下的还得处理$n-m$羊：$$T(n-m).$$### 案例 2：汇总测试呈阳性

 概率：$$1-q^m.$$现在我们必须彻底解决这些问题$m$知道至少一只羊被感染：$$C(m),$$然后仍然处理剩余的$n-m$:$$T(n-m).$$包括汇总测试本身：$$T(n) = \min_{1\le m\le n} \left[ 1 + T(n-m) + (1-q^m)C(m) \right].$$---

 # 3. 复发$C(n)$现在假设：

 - 我们已经知道其中的$n$羊,
 - 至少有一人被感染。 

我们分成一个大小的子组$m$并测试它。 

---

 ## 条件概率

 测试的子组为负而整个组为正的概率：$$\frac{q^m-q^n}{1-q^n}.$$为什么？ 

- 负亚组：$q^m$，
- 全部$n$消极的：$q^n$,
 - 减去不可能的重叠。 

同样，子组检验为正的概率：$$\frac{1-q^m}{1-q^n}.$$---

 ## 如果子组为负

 然后：

 - 子组已完全解决，
 - 剩余的$n-m$羊群中仍至少有一只受感染的羊。 

成本：$$C(n-m).$$---

 ## 如果子组为正

 然后：

 - 子组要求$C(m)$,
 - 剩下的羊现在再次无条件，成本$T(n-m)$。 

---

 包括测试本身：$$C(n) = \min_{1\le m<n} \left[ 1 + \frac{q^m-q^n}{1-q^n}C(n-m) + \frac{1-q^m}{1-q^n}\left(C(m)+T(n-m)\right) \right].$$这两次递归完全确定了最优值。 

---

 # 4.Python实现```python
from math import inf

def optimal_tests(p, nmax):
    q = 1.0 - p

    # T[n] = optimal expected tests for n sheep
    T = [0.0] * (nmax + 1)

    # C[n] = optimal expected additional tests
    #        given at least one infected among n sheep
    C = [0.0] * (nmax + 1)

    T[1] = 1.0
    C[1] = 0.0

    # Empirically the optimal split sizes stay small.
    # This bound is safely above all optimal values needed.
    LIMIT = min(nmax, int(2 / p) + 50)

    for n in range(2, nmax + 1):

        # ---- Compute C[n] ----
        denom = 1.0 - q ** n
        best = inf

        upper = min(n - 1, LIMIT)

        for m in range(1, upper + 1):

            prob_negative = (q ** m - q ** n) / denom
            prob_positive = (1.0 - q ** m) / denom

            value = (
                1.0
                + prob_negative * C[n - m]
                + prob_positive * (C[m] + T[n - m])
            )

            if value < best:
                best = value

        C[n] = best

        # ---- Compute T[n] ----
        best = inf
        upper = min(n, LIMIT)

        for m in range(1, upper + 1):

            value = (
                1.0
                + T[n - m]
                + (1.0 - q ** m) * C[m]
            )

            if value < best:
                best = value

        T[n] = best

    return T[nmax]

# Verify examples
print(round(optimal_tests(0.02, 25), 6))
print(round(optimal_tests(0.10, 25), 6))

# Final computation
answer = 0.0

for k in range(1, 51):
    p = k / 100.0
    answer += optimal_tests(p, 10000)

print(f"{answer:.6f}")
```---

 # 5. 代码演练

 ### 数组```python
T = [0.0] * (nmax + 1)
C = [0.0] * (nmax + 1)
```存储 DP 值。 

---

 ### 计算$C[n]$

```python
prob_negative = (q ** m - q ** n) / denom
prob_positive = (1.0 - q ** m) / denom
```这些是假设整个群体已经感染的条件概率。 

---

 ### 计算$T[n]$

```python
value = (
    1.0
    + T[n - m]
    + (1.0 - q ** m) * C[m]
)
```这准确地实现了：$$1 + T(n-m) + (1-q^m)C(m).$$---
