[欧拉项目问题 135](https://projecteuler.net/problem=135)

 ## 解决方案

 **答案：**`4989`设等差数列的连续三项为$$x = a+d,\qquad y=a,\qquad z=a-d,$$在哪里$a>d>0$。 

我们被要求计算有多少个整数$n<10^6$满足$$x^2-y^2-z^2=n$$正好有十种不同的方式。 

---

 # 步骤 1 — 代数简化

 代入等差数列形式：$$(a+d)^2-a^2-(a-d)^2.$$扩张：$$(a^2+2ad+d^2)-a^2-(a^2-2ad+d^2).$$简化：$$= a^2+2ad+d^2-a^2-a^2+2ad-d^2$$

$$=4ad-a^2.$$因此$$n=4ad-a^2.$$因素：$$n=a(4d-a).$$定义$$k=4d-a.$$然后$$n=ak.$$自从$d=\frac{a+k}{4}$，我们要求：

 1.$a+k\equiv 0\pmod 4$,
 2.$k>0$（因为$n>0$),
 3.$a>d$。 

从$a>d$:$$a>\frac{a+k}{4}$$

$$4a>a+k$$

$$3a>k.$$所以每个解都对应一个因式分解$$n=ak$$和$$0<k<3a, \qquad a+k\equiv 0\pmod 4.$$每个有效对$(a,k)$给出恰好一个算术级数解.

 所以任务就变成了：

 > 数一数有多少个$n<10^6$正好有十个除数对$(a,k)$满足这些约束条件。 

---

 # 步骤 2 — 高效计数策略

 我们迭代所有可能的$a$和$k$。 

自从$$n=ak<10^6,$$对于每个$a$,$$k<\frac{10^6}{a}.$$我们还需要$$k<3a.$$因此$$k < \min\left(3a,\frac{10^6}{a}\right).$$最后$$a+k\equiv0\pmod4.$$我们维护一个数组`count[n]`每个存储多少个有效表示$n$有。 

---

 # 第 3 步 — Python 实现```python
LIMIT = 1_000_000

# count[n] = number of valid solutions producing n
count = [0] * LIMIT

# Iterate over a
for a in range(1, LIMIT):

    # k must satisfy:
    #   k < 3a
    #   a*k < LIMIT
    k_max = min(3 * a, (LIMIT - 1) // a)

    # We need a + k ≡ 0 (mod 4)
    # so k ≡ -a (mod 4)
    start = (4 - (a % 4)) % 4
    if start == 0:
        start = 4

    for k in range(start, k_max + 1, 4):
        n = a * k
        count[n] += 1

# Count how many n have exactly 10 solutions
answer = sum(1 for n in range(1, LIMIT) if count[n] == 10)

print(answer)
```---
