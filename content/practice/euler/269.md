[欧拉项目问题 269](https://projecteuler.net/problem=269)

 ## 解决方案

 **答案：**`1311109198529286`让$$P_n(x)=a_mx^m+a_{m-1}x^{m-1}+\cdots+a_0$$在哪里$a_ma_{m-1}\cdots a_0$是小数位$n$。 

我们寻求$$Z(10^{16})$$= 正整数的数量$n\le 10^{16}$这样$P_n(x)$有**至少一个整数根**。 

---

 ## 1.数学分析

 ### 步骤 1：限制可能的整数根

 由于系数是数字$0,\dots,9$，所有系数均为非负且首项系数为正。 

如果$r>0$， 然后$$P_n(r)>0$$因为每项都是非负的，并且首项是正的。 

所以**正根是不可能的**。 

根据整数根定理，任何整数根必须整除常数项（最后一位数字），因此任何整数根必须位于$$\{0,-1,-2,\dots,-9\}.$$所以只有 **10 个候选根**。 

---

 ### 步骤 2：重新表述多项式评估

 假设小数位数为$n$是$$d_1d_2\cdots d_L.$$然后$$P_n(r) = (((d_1r+d_2)r+d_3)\cdots)r+d_L.$$这是霍纳重现。 

我们想要：$$P_n(r)=0.$$对于固定根$r$，向后定义状态：

 如果在某些后缀之后我们需要值$t$，那么之前的状态$p$必须满足$$pr+d=t.$$因此$$p=\frac{t-d}{r}.$$对于每个数字$d\in\{0,\dots,9\}$，这个前身要么是唯一确定的，要么是不可能的。 

这使得动态规划非常高效。 

---

 ### 步骤 3：包含 - 排除

 我们需要多项式具有**至少一个**整数根的数字$$R=\{0,-1,-2,\dots,-9\}.$$对于任意子集$S\subseteq R$， 让$N(S)$是其多项式在**每个**根处消失的整数的数量$S$。 

然后通过包含-排除：$$Z = \sum_{\emptyset\neq S\subseteq R} (-1)^{|S|+1}N(S).$$只有$$2^{10}-1=1023$$非空子集，所以这是可行的。 

---

 ## 2.Python实现```python
from functools import lru_cache

# Candidate integer roots:
# index 0 -> root 0
# index i -> root -i for i=1..9
ROOTS = [0] + [-i for i in range(1, 10)]

cache = {}

def count_subset(mask, length):
    """
    Count length-digit numbers whose polynomial
    vanishes at every root specified by 'mask'.
    """

    key = (mask, length)
    if key in cache:
        return cache[key]

    # Root 0 means last digit must be 0
    need_zero_root = (mask & 1) != 0

    # Negative roots included in this subset
    roots = [-i for i in range(1, 10) if (mask >> i) & 1]

    @lru_cache(None)
    def dp(rem_digits, targets):
        """
        rem_digits = number of digits still to place
        targets = tuple of required evaluation states
                  for each root
        """
        if rem_digits == 0:
            return 1 if all(t == 0 for t in targets) else 0

        total = 0

        for d in range(10):

            # Leading digit cannot be zero
            if rem_digits == 1 and d == 0:
                continue

            # Root 0 condition: LSD must be zero
            if need_zero_root and rem_digits == length and d != 0:
                continue

            prev_states = []
            ok = True

            # Backward transition:
            # p * r + d = target
            for r, t in zip(roots, targets):
                numerator = t - d

                if numerator % r != 0:
                    ok = False
                    break

                prev_states.append(numerator // r)

            if ok:
                total += dp(rem_digits - 1, tuple(prev_states))

        return total

    result = dp(length, tuple([0] * len(roots)))
    cache[key] = result
    return result

def compute_Z(limit_power):
    total = 0

    # Count numbers < 10^limit_power
    for length in range(1, limit_power + 1):
        union_count = 0

        for mask in range(1, 1 << 10):
            c = count_subset(mask, length)

            # Inclusion–exclusion
            if mask.bit_count() % 2 == 1:
                union_count += c
            else:
                union_count -= c

        total += union_count

    # Add 10^16 itself
    # P_{10^16}(x) = x^16, root x=0
    total += 1

    return total

print(compute_Z(16))
```---

 ## 3. 代码演练

 ### 候选根

 我们只测试$$0,-1,-2,\dots,-9$$因为不可能有其他整数根。 

###`count_subset(mask, length)`这才算$L$-多项式在**子集中的所有根**处消失的数字。 

位掩码对子集进行编码。 

示例：

 - 位 0 → 根$0$- 位 1 → 根$-1$- 位 2 → 根$-2$等等

 ### 动态规划

 我们**从最低有效数字开始向后构建数字**。 

假设我们当前需要：$$P(r)=t.$$选择数字$d$强制前驱状态：$$p=\frac{t-d}{r}.$$如果不可整除，则该数字是不可能的。 

记忆使重复状态变得非常快。 

### 包含-排除

 我们对所有非空子集求和：$$\sum (-1)^{|S|+1}N(S).$$这可以正确计算具有**至少一个**整数根的数字。

 ## 4.验证

 问题给出：$$Z(100000)=14696.$$运行相同的算法$10^5$准确地再现：$$14696.$$因此实现与提供的检查相匹配。 

最终计算为$10^{16}$给出：$$1311109198529286.$$这个幅度是合理的：$10^{16}$数字，大致$13\%$至少满足一个整数根条件。 

**答案：1311109198529286**
