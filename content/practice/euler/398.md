[欧拉项目问题 398](https://projecteuler.net/problem=398)

 ## 解决方案

 **答案：**`2010.59096`设线段长度为$$X_1,\dots,X_m \in \mathbb Z_{>0}, \qquad X_1+\cdots+X_m=n.$$选择$m-1$之间统一切点$n-1$内部格点相当于选择一个组合$n$进入$m$阳性部分均匀随机。 

此类组合物的总数为$$\binom{n-1}{m-1}.$$让$Y$是第二小的线段长度。 

我们对正整数随机变量使用标准尾部和恒等式：$$\mathbb E[Y] = \sum_{k\ge1}\Pr(Y\ge k).$$因此，整个问题归结为计算第二小的部分至少是的成分$k$。 

---

 # 1. 计数$\Pr(Y\ge k)$条件$Y\ge k$意思是：

 - **所有**段至少$k$,
 - 或 **恰好一个** 段是$<k$，而所有其他人至少$k$。 

---

 ## 情况 A：所有段$\ge k$写$$X_i = k + Z_i, \qquad Z_i\ge0.$$然后$$Z_1+\cdots+Z_m = n-mk.$$解决方案数量：$$A_k = \binom{n-mk+m-1}{m-1}.$$---

 ## 情况 B：恰好一个段$<k$选择较小的段：$m$选择。 

假设小部分有价值$t\in\{1,\dots,k-1\}$。 

对于剩余的$m-1$段写入$$X_i = k + Z_i,\qquad Z_i\ge0.$$然后$$\sum Z_i = n-t-(m-1)k.$$因此可能性的数量是$$\binom{n-t-(m-1)k+m-2}{m-2}.$$总结$t=1,\dots,k-1$并使用曲棍球棒恒等式给出$$B_k = \binom{n-(m-1)(k-1)-1}{m-1} - \binom{n-m(k-1)-1}{m-1}.$$因此，有利的组合的数量是$$N_k = A_k + mB_k.$$化简后：$$N_k = m\binom{n-(m-1)(k-1)-1}{m-1} - (m-1)\binom{n-m(k-1)-1}{m-1}.$$所以$$\Pr(Y\ge k) = \frac{ m\binom{n-(m-1)(k-1)-1}{m-1} - (m-1)\binom{n-m(k-1)-1}{m-1} }{ \binom{n-1}{m-1} }.$$最后，$$E(n,m) = \sum_{k\ge1}\Pr(Y\ge k).$$---

 # 2.Python实现```python
from math import comb

def E(n, m):
    total = comb(n - 1, m - 1)

    ans = 0.0
    k = 1

    while True:
        a_top = n - m * (k - 1) - 1
        b_top = n - (m - 1) * (k - 1) - 1

        if a_top < m - 1 and b_top < m - 1:
            break

        A = comb(a_top, m - 1) if a_top >= m - 1 else 0
        B = comb(b_top, m - 1) if b_top >= m - 1 else 0

        favorable = m * B - (m - 1) * A

        ans += favorable / total
        k += 1

    return ans

# sanity checks
print(E(3, 2))   # 2.0
print(E(8, 3))   # 16/7 = 2.285714285714...

# target
value = E(10**7, 100)
print(f"{value:.5f}")
```---

 # 3. 代码演练

 -`total`是组合的总数：$$\binom{n-1}{m-1}.$$- 对于每个$k$，我们计算：

 -`A`= 所有部分至少为的组合数$k$,
 -`B`= 辅助曲棍球棒术语，
 -`favorable = m*B - (m-1)*A`。 
- 除以`total`给出$\Pr(Y\ge k)$。 
- 总结所有$k$产生期望。 

检查：$$E(3,2)=2$$和$$E(8,3)=\frac{16}{7}$$与陈述完全相符。

 # 4.最终验证

 对于$n=10^7$和$m=100$：

 - 平均段长度为$10^5$,
 - 最小值和第二最小值应该小得多，
 - 周围的值$2000$对于第二小阶统计量来说是完全合理的。 

计算给出$$E(10^7,100)=2010.590959579\ldots$$四舍五入到小数点后 5 位：

 **答案：2010.59096**
