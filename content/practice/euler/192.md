[项目欧拉问题 192](https://projecteuler.net/problem=192)

 ## 解决方案

 **答案：**`57060635927998347`对于无理数$x$，连分数理论告诉我们，每个**最佳近似**（就问题陈述的意义而言）是

 - 的连分数的收敛$x$, 或
 - 中间分数（也称为半收敛）。 

对于二次无理数，例如$\sqrt n$，连分式展开是周期性的，并且可以非常有效地生成收敛。 

---

 # 1.数学分析

 让$$x = [a_0;a_1,a_2,a_3,\dots]$$是 的连分数$x$。 

其收敛式为$$\frac{p_k}{q_k},$$产生于$$p_k=a_k p_{k-1}+p_{k-2},\qquad q_k=a_k q_{k-1}+q_{k-2},$$具有初始值$$p_{-2}=0,\; p_{-1}=1,\qquad q_{-2}=1,\; q_{-1}=0.$$---

 ## 的连分数$\sqrt n$对于非正方形$n$,$$\sqrt n = [a_0;\overline{a_1,a_2,\dots,a_t}]$$是周期性的。 

标准复发率是：$$m_{k+1}=d_k a_k-m_k,$$

$$d_{k+1}=\frac{n-m_{k+1}^2}{d_k},$$

$$a_{k+1}=\left\lfloor\frac{a_0+m_{k+1}}{d_{k+1}}\right\rfloor.$$---

 ## 分母界的最佳近似$D$假设我们有连续收敛$$\frac{p_{k-1}}{q_{k-1}}, \qquad \frac{p_k}{q_k}, \qquad \frac{p_{k+1}}{q_{k+1}},$$和$$q_k \le D < q_{k+1}.$$然后每个候选者与分母的最佳近似$\le D$必须是：

 1. 收敛性$\frac{p_k}{q_k}$, 或
 2. 最大容许半收敛$$\frac{t p_k+p_{k-1}}{t q_k+q_{k-1}},$$在哪里$$t=\left\lfloor\frac{D-q_{k-1}}{q_k}\right\rfloor.$$因此只需要检查**两名候选人**。 

- -

＃＃ 例子：$\sqrt{13}$连分数是$$\sqrt{13}=[3;\overline{1,1,1,1,6}].$$收敛：$$3,\ \frac41,\ \frac72,\ \frac{11}3,\ \frac{18}5,\ \frac{119}{33},\dots$$为了$D=20$:

 -$5 \le 20 < 33$- 最大半收敛分母是$18$候选人是：$$\frac{18}5,\qquad \frac{65}{18}.$$从数字上看，$$\left|\sqrt{13}-\frac{18}5\right| < \left|\sqrt{13}-\frac{65}{18}\right|,$$所以答案是$\frac{18}5$。 

为了$D=30$，最大的半收敛变为$$\frac{101}{28},$$这比$\frac{18}5$。

 # 2.Python实现```python
from math import isqrt
from decimal import Decimal, getcontext

# We need very high precision because denominators go up to 10^12
getcontext().prec = 80

LIMIT = 10**12

def best_denominator_sqrt(n, D):
    """
    Returns the denominator of the best approximation to sqrt(n)
    with denominator bound D.
    """

    a0 = isqrt(n)

    # Ignore perfect squares
    if a0 * a0 == n:
        return 0

    x = Decimal(n).sqrt()

    # Continued fraction state
    m = 0
    d = 1
    a = a0

    # Convergents:
    # p[-2]=0, p[-1]=1
    # q[-2]=1, q[-1]=0
    p0, p1 = 1, a
    q0, q1 = 0, 1

    while True:

        # Generate next continued-fraction term
        m = d * a - m
        d = (n - m * m) // d
        a = (a0 + m) // d

        # Next convergent
        p2 = a * p1 + p0
        q2 = a * q1 + q0

        # Stop when next denominator exceeds D
        if q2 > D:

            # Largest admissible semiconvergent
            t = (D - q0) // q1

            # Candidate 1: convergent
            cand1_p, cand1_q = p1, q1

            # Candidate 2: semiconvergent
            cand2_p = t * p1 + p0
            cand2_q = t * q1 + q0

            # Compare distances to sqrt(n)
            err1 = abs(Decimal(cand1_p) / cand1_q - x)
            err2 = abs(Decimal(cand2_p) / cand2_q - x)

            if err1 <= err2:
                return cand1_q
            else:
                return cand2_q

        # Advance
        p0, p1 = p1, p2
        q0, q1 = q1, q2

def solve():
    total = 0

    for n in range(2, 100001):
        r = isqrt(n)

        # Skip perfect squares
        if r * r == n:
            continue

        total += best_denominator_sqrt(n, LIMIT)

    return total

print(solve())
```---
