[Project Euler Problem 362](https://projecteuler.net/problem=362)

 ## 解决方案

 **答案：**`457895958010`让**平方自由因式分解**$n$表示无序因式分解为整数$>1$，其中每个因子都是无平方的。 

我们定义：$$\operatorname{Fsf}(n)$$作为此类因式分解的数量，以及$$S(N)=\sum_{k=2}^{N}\operatorname{Fsf}(k).$$我们得到：$$S(100)=193.$$我们必须计算：$$S(10^{10}).$$---

 ## 1.数学分析

 ### 重新解释$S(N)$而不是总结$n$，直接计算所有有效的无平方因式分解。 

每一份贡献$\operatorname{Fsf}(n)$是无平方整数的无序多重集$>1$谁的产品是$n$。 

所以：$$S(N)$$正是无平方整数的无序多重集的数量$>1$谁的产品最多$N$。 

---

 ### 规范排序

 为了避免计数过多，对因子施加非递减顺序：$$q_1 \le q_2 \le \cdots \le q_r,$$哪里每个$q_i$是无平方的。 

定义：$$A(N,m)$$是这样的因式分解的数量，其中所有因式至少$m$，和产品$\le N$。 

然后：$$S(N)=A(N,2).$$---

 ### 递归公式

 选择最小的因子$q$，它必须是无平方的并且满足：$$m \le q \le N.$$选择后$q$:

 - 我们得到一个有效的因式分解，仅包含$q$,
 - 或者我们继续分解剩余的界限$N/q$, 保持因子$\ge q$。 

因此：$$A(N,m) = \sum_{\substack{q\ \text{squarefree}\\ q\ge m\\ q\le N}} \Bigl(1+A(\lfloor N/q\rfloor,q)\Bigr).$$现在观察：

 如果$$q>\sqrt N,$$然后$$\lfloor N/q\rfloor<q,$$所以递归是不可能的。 

因此：$$A(N,m) = Q(N)-Q(m-1) + \sum_{\substack{m\le q\le \sqrt N\\ q\ \text{squarefree}}} A(\lfloor N/q\rfloor,q),$$在哪里$Q(x)$计算无平方整数$>1$最多$x$。 

---

 ### 计算无平方整数

 使用莫比乌斯反演：$$Q(x) = \sum_{d\le \sqrt x}\mu(d) \left\lfloor \frac{x}{d^2}\right\rfloor -1.$$（这$-1$排除号码$1$。）

自从：$$\sqrt{10^{10}}=100000,$$我们只需要莫比乌斯值达到$10^5$。 

记住递归使得计算变得可行。 

---

 ## 2.Python实现```python
from math import isqrt
from bisect import bisect_right
from functools import lru_cache

N = 10_000_000_000
LIMIT = isqrt(N)

# -------------------------------
# Möbius function (linear sieve)
# -------------------------------
mu = [0] * (LIMIT + 1)
mu[1] = 1

primes = []
composite = [False] * (LIMIT + 1)

for i in range(2, LIMIT + 1):
    if not composite[i]:
        primes.append(i)
        mu[i] = -1

    for p in primes:
        v = i * p
        if v > LIMIT:
            break

        composite[v] = True

        if i % p == 0:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# --------------------------------
# List of squarefree numbers <= LIMIT
# --------------------------------
squarefree = [x for x in range(2, LIMIT + 1) if mu[x] != 0]

# Prefix count of squarefree numbers (>1)
prefix_sf = [0] * (LIMIT + 1)
count = 0

for i in range(LIMIT + 1):
    if i >= 2 and mu[i] != 0:
        count += 1
    prefix_sf[i] = count

# --------------------------------
# Count squarefree numbers <= x
# --------------------------------
@lru_cache(None)
def Q(x):
    if x <= LIMIT:
        return prefix_sf[x]

    r = isqrt(x)
    total = 0

    for d in range(1, r + 1):
        if mu[d] != 0:
            total += mu[d] * (x // (d * d))

    return total - 1   # exclude 1

# --------------------------------
# Recursive counting
# --------------------------------
@lru_cache(None)
def A(n, idx):
    """
    Count squarefree factorizations
    using factors >= squarefree[idx].
    """
    m = squarefree[idx]

    # Count one-factor factorizations
    total = Q(n) - Q(m - 1)

    # Recursive part only needed up to sqrt(n)
    limit = isqrt(n)
    end = bisect_right(squarefree, limit)

    for j in range(idx, end):
        q = squarefree[j]
        total += A(n // q, j)

    return total

answer = A(N, 0)
print(answer)
```---

 ## 3. 代码演练

 ### 步骤 1：莫比乌斯筛

 我们计算$\mu(n)$最多$100000$使用线性筛。 

这可以有效评估：$$Q(x) = \sum \mu(d)\left\lfloor x/d^2\right\rfloor - 1.$$---

 ### 步骤 2：生成无平方数

 一个数是无平方的当且仅当：$$\mu(n)\neq 0.$$我们存储所有无平方整数$100000$。 

---

 ### 步骤 3：递归计数`A(n, idx)`计算所有有效因式分解，其最小因数至少为：```python
squarefree[idx]
```期限：```python
Q(n) - Q(m - 1)
```计算所有单因素选择。 

然后我们只递归：$$q \le \sqrt n,$$因为更大$q$后面不能跟其他因素。 

记忆化避免了重新计算。 

---

 ### 样品验证

 对于$N=100$:```python
A(100, 0)
```返回：$$193$$匹配问题陈述。
