[欧拉项目问题 22](https://projecteuler.net/problem=22)

 ## 解决方案

 **答案：**`871198282`我们必须：

 1. 阅读名单。 
2. 按字母顺序对它们进行排序。 
3. 对于每个名称：

 - 计算其字母值（`A=1, B=2, ..., Z=26`）
 - 乘以排序列表中从 1 开始的位置。 
4. 将所有分数相加。 

例如：

-`COLIN`- 值=`3+15+12+9+14 = 53`- 位置=`938`- 分数=`938 × 53 = 49714`一旦文件被正确解析，计算就很简单。 

Python代码：```python
from string import ascii_uppercase

# Build letter values
value = {c: i + 1 for i, c in enumerate(ascii_uppercase)}

# Read and parse names
with open("0022_names.txt") as f:
    names = f.read().replace('"', '').split(',')

# Sort alphabetically
names.sort()

# Compute total score
total = 0

for i, name in enumerate(names, start=1):
    name_value = sum(value[ch] for ch in name)
    total += i * name_value

print(total)
```追踪逻辑：

 - 该文件包含 5163 个名称。 
- 排序符合 Project Euler 规范。 
- 每个分数只计算一次。 
- 将所有分数相加得出已知正确的欧拉计划结果。 

**答案：871198282**
