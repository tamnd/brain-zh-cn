[欧拉项目问题 49](https://projecteuler.net/problem=49)

 ## 解决方案

 **答案：**`296962999629`我们寻求素数的第二个 4 位算术级数，使得：

 1. 所有三项都是素数。 
2. 它们构成一个等差数列。 
3. 这三个数字是彼此的排列。 
4.它不同于$1487,4817,8147$。 

---

 # 数学分析

 让这三个术语为$$a,\quad a+d,\quad a+2d$$其中都是 4 位质数。 

排列条件意味着所有三个数字都包含完全相同的数字，但顺序不同。 一个有用的结果是：

 - 任何数字的排列都具有相同的数字和。 
- 因此所有三个数的模全等$9$。 

因此：$$(a+d)-a=d$$必须能整除$9$。 

由于所有涉及的素数都是奇数（它们是大于 2 的 4 位素数），因此公差也必须是偶数。 

所以：$$d \text{ is divisible by } 18.$$这大大减少了搜索空间。 

自然算法是：

 1. 生成所有 4 位素数。 
2. 按素数的排序数字对素数进行分组。 

- 例子：$$1487 \to "1478"$$

$$4817 \to "1478"$$3. 在每个排列组中，搜索 3 项算术级数。 
4. 忽略已知的例子。 
5. 连接三个数字。

 # Python 实现```python
from collections import defaultdict
from itertools import combinations

# ------------------------------------------------------------
# Sieve of Eratosthenes to generate primes up to 9999
# ------------------------------------------------------------
limit = 10000
is_prime = [True] * limit
is_prime[0] = is_prime[1] = False

for i in range(2, int(limit ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i * i, limit, i):
            is_prime[j] = False

# Keep only 4-digit primes
primes = [p for p in range(1000, 10000) if is_prime[p]]

# ------------------------------------------------------------
# Group primes by sorted digit signature
# Example: 4817 -> "1478"
# ------------------------------------------------------------
groups = defaultdict(list)

for p in primes:
    key = ''.join(sorted(str(p)))
    groups[key].append(p)

# ------------------------------------------------------------
# Search each group for arithmetic sequences
# ------------------------------------------------------------
for group in groups.values():

    # Need at least 3 numbers to form a sequence
    if len(group) < 3:
        continue

    group.sort()
    group_set = set(group)

    # Try every pair as potential first two terms
    for a, b in combinations(group, 2):
        d = b - a
        c = b + d

        # Check if third term exists
        if c in group_set:

            # Ignore the known sequence
            if (a, b, c) != (1487, 4817, 8147):

                result = f"{a}{b}{c}"
                print(result)
```---
