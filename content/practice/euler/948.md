[欧拉项目 948 问题](https://projecteuler.net/problem=948)

 ## 解决方案

 **答案：**`1033654680825334184`让

-$L(w)$： 左词胜出$w$当左先移动时。 
-$R(w)$: 右胜于言$w$当右方先移动时。 

一句话$w$,$$L(w)=\exists \text{ proper suffix } s \text{ of } w \text{ such that } \neg R(s),$$因为 Left 删除了一个非空的左前缀并留下了一个后缀。 

相似地，$$R(w)=\exists \text{ proper prefix } p \text{ of } w \text{ such that } \neg L(p).$$我们想要号码$F(n)$长度的单词$n$为此，两者$L(w)$和$R(w)$是真的。 

对亏损头寸的仔细归纳/分类给出了封闭形式$$F(n)=2^n-\binom{n}{\lfloor n/2\rfloor}-C_{\lfloor (n-1)/2\rfloor},$$在哪里$$C_k=\frac1{k+1}\binom{2k}{k}$$是$k$-th 加泰罗尼亚号码。 

检查：

 -$F(3)=8-3-1=4$-$F(8)=256-70-5=181$两者都符合声明。 

为了$n=60$：$$F(60)=2^{60}-\binom{60}{30}-C_{29}.$$Python代码：```python
from math import comb

n = 60
catalan_29 = comb(58, 29) // 30

F60 = 2**60 - comb(60, 30) - catalan_29
print(F60)
```这评估为：$$1033654680825334184$$**答案：1033654680825334184**
