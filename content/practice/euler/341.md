[项目欧拉问题 341](https://projecteuler.net/problem=341)

 ## 解决方案

 **答案：**`56098610614277014`让$G(n)=1+G\bigl(n-G(G(n-1))\bigr)$是哥伦布序列的标准递推（适用于$n>1$）， 和$G(1)=1$。 

我们想要计算$$\sum_{1 \le n < 10^6} G(n^3).$$挑战在于$n^3$几乎达到$10^{18}$，因此直接生成直到该索引的序列是不可能的。 

## 1.数学分析

 ### 步骤 1：理解哥伦布序列

 定义属性说：

 > 整数$k$准确地出现$G(k)$次。 

所以如果$G(k)=4$，那么值$k$在序列中出现四次。 

定义累积终点函数$$S(k)=\sum_{i=1}^{k} G(i).$$然后：

-$k$占据位置$$S(k-1)+1,\dots,S(k),$$- 所以$$G(n)=k \quad\Longleftrightarrow\quad S(k-1)<n\le S(k).$$所以计算$G(n^3)$减少到找到第一个$k$和$$S(k)\ge n^3.$$---

 ### 第 2 步：避免生成最多$10^{18}$一种简单的方法会计算所有$S(k)$直到$10^{18}$，但这需要大约$10^{11}$价值观——不可能。 

关键的观察是：

 如果$G(r)=L$，那么值$r$恰好发生$L$指数之间的时间$k$。 

这意味着有一整个**块**$L$连续的$k$- 其值$$G(k)=r.$$在该块内：

 -$S(k)$正好增加$r$每一步，
 - 因此累积值形成算术级数。 

因此我们可以一次处理整个块而不是一个$k$一次。 

自从$G(r)$仅增长到几百万左右，产生$G(r)$达到必要的尺寸是完全可行的。 

---

 ### 步骤3：高效的块处理

 假设我们在一个区块中：

 -$G(k)=r$,
 - 块长度为$L=G(r)$。 

然后：$$S(k)$$增量推进$r$。 

如果我们已经知道块之前的累积和，比如说$S_0$，那么块的末尾是$$S_0 + Lr.$$对于一个立方体$c=n^3$在此范围内，正确的索引是$$k = k_0 + \left\lceil \frac{c-S_0}{r} \right\rceil,$$在哪里$k_0$是块开始之前的索引。 

由于只有$999{,}999$立方体，我们可以扫过它们一次。

 ## 2.Python实现```python
def solve(limit=10**6):
    """
    Compute:
        sum(G(n^3)) for 1 <= n < limit
    where G is Golomb's self-describing sequence.
    """

    # Golomb values, 1-indexed
    G = [0, 1]  # G(1) = 1

    total = 0

    # Current cube pointer: n^3
    n = 1
    cube = 1

    # We have already processed k = 1
    # S(1) = 1
    current_k = 1
    current_S = 1

    # Handle cubes <= S(1)
    while n < limit and cube <= 1:
        total += 1
        n += 1
        cube = n**3

    r = 2

    while n < limit:
        # Generate G(r)
        g_r = 1 + G[r - G[G[r - 1]]]
        G.append(g_r)

        # This block has length G(r)
        block_length = g_r

        # End of cumulative range for this block
        block_end_S = current_S + block_length * r

        # Process all cubes that fall in this block
        while n < limit and cube <= block_end_S:
            # Ceiling division:
            # j = ceil((cube - current_S) / r)
            j = (cube - current_S + r - 1) // r

            # Corresponding k-value
            total += current_k + j

            n += 1
            cube = n**3

        # Move to next block
        current_k += block_length
        current_S = block_end_S
        r += 1

    return total

# Verification checks
print(solve(1000))     # should be 153506976
print(solve(10**6))
```---

 ## 3. 代码演练

 ### 建立哥伦布价值观```python
g_r = 1 + G[r - G[G[r - 1]]]
```这是经典的哥伦布递归：$$G(r) = 1 + G(r - G(G(r-1))).$$我们仅根据需要生成尽可能多的术语。 

---

 ### 处理块

 如果$G(r)=L$，那么值$r$重复$L$连续指数之间的次数$k$。 

而不是迭代每个$k$，我们处理整个块：```python
block_end_S = current_S + block_length * r
```因为每一步都会增加$S(k)$正是通过$r$。 

---

 ### 寻找立方体落地的位置

 如果$c=n^3$位于当前块中：```python
j = (cube - current_S + r - 1) // r
```计算$$\left\lceil \frac{c-S_0}{r} \right\rceil,$$块内的偏移量。 

然后：```python
total += current_k + j
```添加正确的哥伦布值。
