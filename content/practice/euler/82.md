[项目欧拉问题 82](https://projecteuler.net/problem=82)

 ## 解决方案

 **答案：**`260324`## 1.数学分析

 我们被赋予了一个$80\times 80$矩阵并希望从**左列中的任何单元格**到**右列中的任何单元格**的**最小路径和**，仅移动：

 - **对**
 - **向上**
 - **向下**

 这比问题 81 更难，因为现在允许在两个方向上进行垂直运动。 

### 步骤 1：重新表述为最短路径问题

 将每个矩阵条目视为一个节点，其成本等于其值。 

如果满足以下条件，则允许从一个单元格移动到另一个单元格：

 - 对，
 - 向上，
 - 或向下。 

我们希望最小成本路径从列中的任意位置开始$0$并在最后一列的任意位置结束。 

对路径进行强力搜索是没有希望的，因为可能性的数量呈爆炸式增长。 

---

 ### 步骤 2：按列动态规划

 关键的见解是：

 由于运动**永远不会向左**，因此路径从左到右单调前进。 

假设我们已经知道到达列中每个单元格的最小成本$c-1$。 我们希望柱的成本最小$c$。 

让：$$dp[r]$$表示到达行的最小成本$r$当前列的。 

如果只允许正确的行动：$$dp[r] = \text{prev}[r] + M[r][c]$$But we may also move **up/down within the column** after entering it.

 因此对于每一列：

 1. **初始右移**：$$dp[r] = \text{prev}[r] + M[r][c]$$2. **放松向下的动作**：

 如果我们可以来自行$r-1$:$$dp[r] = \min(dp[r],\, dp[r-1] + M[r][c])$$1. **放松向上动作**：

 如果我们可以来自行$r+1$:$$dp[r] = \min(dp[r],\, dp[r+1] + M[r][c])$$为什么这有效？ 

进入一列的最小路径可以垂直摆动任意次数，但由于所有成本都是正数，因此一列内的最佳路径只是一个单调的垂直段（进入后仅向上或仅向下）。 因此：

 - 向下一扫，
 - 向上扫一扫

 足以传播所有最优值。 

这给出了一个复杂的算法：$$O(n^2)$$对于一个$n\times n$矩阵。 

为了$n=80$，这速度非常快。 

---

 ## 2.Python实现```python
def minimal_path_sum(matrix):
    n = len(matrix)

    # Base case:
    # cost to reach left column is just the cell itself
    dp = [matrix[r][0] for r in range(n)]

    # Process one column at a time
    for c in range(1, n):

        # Step 1: move right into this column
        new_dp = [dp[r] + matrix[r][c] for r in range(n)]

        # Step 2: relax downward paths
        for r in range(1, n):
            new_dp[r] = min(
                new_dp[r],
                new_dp[r - 1] + matrix[r][c]
            )

        # Step 3: relax upward paths
        for r in range(n - 2, -1, -1):
            new_dp[r] = min(
                new_dp[r],
                new_dp[r + 1] + matrix[r][c]
            )

        dp = new_dp

    # End in any row of the rightmost column
    return min(dp)

# Read the matrix file
with open("0082_matrix.txt") as f:
    matrix = [
        list(map(int, line.strip().split(",")))
        for line in f
    ]

answer = minimal_path_sum(matrix)
print(answer)
```---

 ## 3. 代码演练

 ### 初始化```python
dp = [matrix[r][0] for r in range(n)]
```由于我们可以**从左列的任何位置开始**，到达行的最小成本$r$列数$0$就是细胞本身的价值。 

---

 ### 输入新列```python
new_dp = [dp[r] + matrix[r][c] for r in range(n)]
```这假设我们直接向右移动。 

---

 ### 向下放松```python
for r in range(1, n):
    new_dp[r] = min(
        new_dp[r],
        new_dp[r - 1] + matrix[r][c]
    )
```检查是否到达行$r$上面那排的比较便宜。 

---

 ### 向上放松```python
for r in range(n - 2, -1, -1):
    new_dp[r] = min(
        new_dp[r],
        new_dp[r + 1] + matrix[r][c]
    )
```然后我们允许在柱内向上移动。 

---

 ###最终结果```python
return min(dp)
```我们可能会在**最右列的任何行中完成**，因此取最小值。

 ## 4.最终验证

 - 结果为正，因为所有矩阵条目均为正。 
- 大小对于$80\times80$值通常为数百的矩阵。 
- 动态规划方法是该约束最短路径问题的标准最优解。 
- 计算出的 Project Euler 值已知且一致。
