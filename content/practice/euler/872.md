[欧拉项目 872 问题](https://projecteuler.net/problem=872)

 ## 解决方案

 **答案：**`2903144925319290239`让$$P_n$$表示构建过程中追踪的特殊路径$T_{n+1}$: 从根开始$T_n$，反复跟随编号最大的孩子。 

问题的关键在于这些树具有非常严格的二元结构。 

# 1.数学分析

 ## 步骤 1：计算前几棵树

 开始于$T_1$:

 -$T_2$:$2 \to 1$-$T_3$： 根$3$带孩子$2,1$-$T_4$:$4\to 3\to1$， 和$4\to2$-$T_5$:$5\to4\to2$， 和$5\to3,1$-$T_6$:$6\to5\to1$， 和$6\to4\to2$,$5\to3$从声明中：$$f(6,1)=6+5+1=12$$和$$f(10,3)=10+9+7+3=29.$$现在看看差异：

 -$6-1=5=101_2$- 小路：$6,5,1$- 减法：$1,4$和

-$10-3=7=111_2$- 小路：$10,9,7,3$- 减法：$1,2,4$这强烈暗示了二元规则。 

---

 # 第二步：实际结构

 让$$d=n-k.$$写$d$作为二的幂之和：$$d=2^{a_1}+2^{a_2}+\cdots+2^{a_m}, \qquad a_1<a_2<\cdots<a_m.$$定义累积和$$s_j=\sum_{i=1}^j 2^{a_i}.$$然后路径从$n$到$k$是$$n,\; n-s_1,\; n-s_2,\; \ldots,\; n-s_m=k.$$等效地：

 > 开始于$n$，减去设置的位$n-k$从最小到最大。 

---

 ## 为什么这是真的？ 

我们从构造规则归纳证明。 

假设跟踪路径为$T_n$是$$n,\;n-b_1,\;n-b_1-b_2,\ldots$$其中每个$b_i$是 2 的幂且严格递增。 

施工时$T_{n+1}$，该路径上的每个节点都成为新根的直接子节点$n+1$。 因此，新的追踪路径总是从减去 2 的最小可用幂开始。 

这准确地反映了重复删除最低设置位的过程$n-k$。 因此，祖先们$k$通过依次添加回位得到$n-k$从最大到最小，或者等效地从最小到最大减去它们。 

这些例子完全匹配。 

---

 # 步骤 3：公式$f(n,k)$让设置的位$d=n-k$是$$b_1<b_2<\cdots<b_m.$$定义$$c_j=b_1+\cdots+b_j.$$然后$$f(n,k) = \sum_{j=0}^{m} (n-c_j), \qquad c_0=0.$$所以$$f(n,k) = (m+1)n-\sum_{j=1}^{m} c_j.$$这就是整个问题。 

---

 # 2.Python实现```python
def f(n, k):
    """
    Compute the sum of node labels along the path
    from the root of T_n to node k.
    """

    d = n - k

    cumulative = 0
    cumulative_sum = 0
    bit_count = 0

    # Process set bits from smallest to largest
    while d:
        lowest_bit = d & -d

        cumulative += lowest_bit
        cumulative_sum += cumulative
        bit_count += 1

        d -= lowest_bit

    return (bit_count + 1) * n - cumulative_sum

# Small checks from the statement
print(f(6, 1))    # 12
print(f(10, 3))   # 29

# Required value
print(f(10**17, 9**17))
```---

 # 4. 示例验证

 ## 示例 1$$n=6,\quad k=1$$然后$$d=5=1+4.$$累计金额：$$1,\ 5.$$小路：$$6,\ 5,\ 1.$$所以$$f(6,1)=6+5+1=12.$$正确的。 

---

 ## 示例2$$n=10,\quad k=3$$然后$$d=7=1+2+4.$$累计金额：$$1,\ 3,\ 7.$$小路：$$10,\ 9,\ 7,\ 3.$$所以$$f(10,3)=10+9+7+3=29.$$正确的。

 # 5. 计算所需值

 对于$$n=10^{17}, \qquad k=9^{17},$$该算法给出$$f(10^{17},9^{17}) = 2903144925319290239.$$该值合理：

 - 路径长度等于设置的位数$10^{17}-9^{17}$加一，
 - 这个数字是$29+1=30$,
 - 所以总数应该大约是$30\times10^{17}\approx3\times10^{18}$,
 - 匹配计算的幅度。
