[项目欧拉问题 87](https://projecteuler.net/problem=87)

 ## 解决方案

 **答案：**`1097343`我们想要下面的整数个数$50{,}000{,}000$可以写成$$n = p_2^2 + p_3^3 + p_4^4$$在哪里$p_2,p_3,p_4$是素数。 

关键的挑战是**计算不同的值**，因为多个素数三元组可能会生成相同的总和。 

## 1.数学分析

 设极限为$$L = 50{,}000{,}000.$$我们需要所有数字$$p^2 + q^3 + r^4 < L$$和$p,q,r$主要的。 

### 第 1 步：限制搜索

 由于所有项都是正数，因此每个素数只需要生成到某个最大值。 

对于四次方：$$r^4 < L \Rightarrow r < L^{1/4}.$$自从$$50{,}000{,}000^{1/4} \approx 84,$$我们只需要 83 以内的素数。 

对于立方体：$$q^3 < L \Rightarrow q < L^{1/3}.$$自从$$50{,}000{,}000^{1/3} \approx 368,$$我们只需要 367 以内的素数。 

对于正方形：$$p^2 < L \Rightarrow p < \sqrt{L}.$$自从$$\sqrt{50{,}000{,}000}\approx 7071,$$我们只需要 7071 以内的素数。 

所以搜索空间实际上很小：

 - 素数平方：大约900个素数，
 - 素数立方体：约70个素数，
 - 质数的四次方：大约20个质数。 

总组合大致为$$900 \times 70 \times 20 \approx 1.26\times10^6,$$这在计算上是微不足道的。 

### 第 2 步：避免重复

 不同的三元组可能产生相同的和。 

例子：$$p_1^2 + q_1^3 + r_1^4 = p_2^2 + q_2^3 + r_2^4.$$我们只计算一次。 

最干净的方法是将每个有效的总和存储在**集合**中，因为集合会自动删除重复项。 

### 步骤 3：高效生成

 预计算：

 - 下面所有素数正方形$L$,
 - 下面所有素数立方体$L$,
 - 以下所有素四次方$L$。 

然后循环：$$s = a+b+c$$并插入到集合中$$s < L.$$我们可以提前修剪，因为列表是排序的：

 - 如果$a+b \ge L$，停止内循环，
 - 如果$a+b+c \ge L$，停止最深循环。

 ## 2.Python实现```python
from math import isqrt

LIMIT = 50_000_000

def sieve(n):
    """Return list of primes <= n using Sieve of Eratosthenes."""
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(n) + 1):
        if is_prime[p]:
            for multiple in range(p * p, n + 1, p):
                is_prime[multiple] = False

    return [i for i, prime in enumerate(is_prime) if prime]

# Generate primes only up to the needed maximum
max_prime = isqrt(LIMIT)
primes = sieve(max_prime)

# Precompute prime powers under LIMIT
prime_squares = [p**2 for p in primes if p**2 < LIMIT]
prime_cubes = [p**3 for p in primes if p**3 < LIMIT]
prime_fourths = [p**4 for p in primes if p**4 < LIMIT]

# Store distinct representable numbers
values = set()

for square in prime_squares:
    for cube in prime_cubes:
        partial = square + cube

        if partial >= LIMIT:
            break

        for fourth in prime_fourths:
            total = partial + fourth

            if total >= LIMIT:
                break

            values.add(total)

print(len(values))
```---
