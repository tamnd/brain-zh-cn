[欧拉项目 409 问题](https://projecteuler.net/problem=409)

 ## 解决方案

 **答案：**`253223948`让$$q = 2^n.$$我们正在清点订单$n$-元组$$(x_1,x_2,\dots,x_n)$$这样：

 - 每个$x_i\in\{1,2,\dots,q-1\}$，
- 全部$x_i$是不同的，
 - nim 中的位置是**获胜**，即$$x_1\oplus x_2\oplus \cdots \oplus x_n \ne 0.$$定义：

-$A_k$：有序的不同非零数$k$-元组，
 -$L_k$：有序的不同非零数$k$-带有异或的元组$0$,
 -$W_k=A_k-L_k$。 

我们最终需要$W_n$为了$q=2^n$。 

---

 # 1.数学分析

 ## 元组总数

 有序不同非零的总数$k$-元组很简单$$A_k=(q-1)(q-2)\cdots(q-k)$$（使用下降阶乘表示法$A_k=(q-1)_k$）。 

尤其，$$A_n=(2^n-1)(2^n-2)\cdots(2^n-n).$$---

 # 计算亏损仓位

 我们现在推导出$L_k$。 

考虑一下失败$k$-元组：$$x_1\oplus x_2\oplus\cdots\oplus x_k=0.$$然后最后一个元素被强制：$$x_k=x_1\oplus x_2\oplus\cdots\oplus x_{k-1}.$$所以我们从任何有序的不同非零开始$(k-1)$-tuple 并询问强制值何时有效。 

有$A_{k-1}$可能的$(k-1)$-元组。 

必须排除两种不良情况。 

---

 ## 坏情况 1：异或是$0$然后$x_k=0$，禁止。 

这恰好发生在第一次$k-1$条目已经异或到$0$。 

数数：$$L_{k-1}.$$---

 ## 坏情况 2：异或等于现有条目

 假设$$x_1\oplus\cdots\oplus x_{k-1}=x_i.$$然后删除$x_i$留下一个$(k-2)$-异或为的元组$0$。 

反之：

 - 选择失败的$(k-2)$-元组，
 - 选择位置$i$（$k-1$选择），
 - 选择$x_i$是尚未使用的任何非零值。 

这$(k-2)$-元组已经使用$k-2$不同的非零值，因此有$$(q-1)-(k-2)=q-k+1$$选择$x_i$。 

因此，坏情况 2 中的元组数量是$$(k-1)(q-k+1)L_{k-2}.$$---

 # 重复

 因此：$$\boxed{ L_k = A_{k-1} - L_{k-1} - (k-1)(q-k+1)L_{k-2} }$$具有初始条件$$L_0=1,\qquad L_1=0.$$最后，$$W_n=A_n-L_n.$$这种递归是线性时间的并且足够快$n=10^7$。 

---

 # 2.Python实现```python
MOD = 1_000_000_007

def solve(n):
    q = pow(2, n, MOD)

    # n = 1 is trivial
    if n == 1:
        return 1

    # A1 = q - 1
    A_prev = (q - 1) % MOD

    # L0 = 1, L1 = 0
    L_prev2 = 1
    L_prev1 = 0

    # Build up to Ln
    for k in range(2, n + 1):

        # Recurrence:
        # Lk = A_{k-1}
        #      - L_{k-1}
        #      - (k-1)(q-k+1)L_{k-2}
        Lk = (
            A_prev
            - L_prev1
            - ((k - 1) * (q - k + 1) % MOD) * L_prev2
        ) % MOD

        # Update A_k from A_{k-1}
        A_curr = (A_prev * (q - k)) % MOD

        # Shift states
        A_prev = A_curr
        L_prev2, L_prev1 = L_prev1, Lk

    # Wn = An - Ln
    return (A_prev - L_prev1) % MOD

print(solve(5))      # 19764360
print(solve(100))    # 384777056
print(solve(10_000_000))
```---

 # 3. 代码演练

 ## 步骤 1```python
q = pow(2, n, MOD)
```计算$2^n \bmod MOD$。 

---

 ## 步骤 2```python
A_prev = q - 1
```商店$$A_1=q-1.$$---

 ## 步骤 3```python
L_prev2 = 1
L_prev1 = 0
```初始化：$$L_0=1,\qquad L_1=0.$$---

 ## 步骤 4

 循环内部：```python
Lk = (
    A_prev
    - L_prev1
    - ((k - 1) * (q - k + 1) % MOD) * L_prev2
) % MOD
```实施$$L_k=A_{k-1}-L_{k-1}-(k-1)(q-k+1)L_{k-2}.$$---

 ## 步骤 5```python
A_curr = (A_prev * (q - k)) % MOD
```更新$$A_k=A_{k-1}(q-k).$$---

 ## 步骤 6

 最后：```python
(A_prev - L_prev1) % MOD
```回报$$W_n=A_n-L_n.$$---
