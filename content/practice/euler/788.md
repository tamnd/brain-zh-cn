[欧拉项目788问题](https://projecteuler.net/problem=788)

 ## 解决方案

 **答案：**`471745499`设若干长度$n$如果某个数字严格出现超过$n/2$次。 

我们必须计算$$D(2022)\pmod{1\,000\,000\,007}.$$关键是要算有效$n$- 位数字的组合。 

---

 # 1.数学分析

 对于固定长度$n$，定义：

 A(n)=\text{# 支配 } n\text{-位数字}。 

然后$$D(N)=\sum_{n=1}^{N} A(n).$$因此我们需要$A(n)$。 

---

 ## 步骤 1：主导数字是唯一的

 假设一个数字有两个不同的数字，每个数字出现的次数超过$n/2$次。 

那么总位数将超过$n$， 不可能的。 

因此，每个主数都有一个**唯一的**主数。 

因此我们可以：

 1.选择主导数字$d$,
 2.选择出现的次数，
 3. 放置剩余的数字。 

---

 # 第 2 步：计数$n$-digit 数字，其中数字$d$出现$k$次

 我们要求$$k>\frac n2.$$我们必须分别对待：

 -$d\neq 0$,
 -$d=0$,

 因为前导零是被禁止的。 

---

 # 情况 A：主导数字$d\neq 0$选择其中一项$9$非零数字。 

认为$d$准确地出现$k$次。 

我们数数$n$- 数字字符串：

 - 第一个数字非零，
 - 正是$k$的副本$d$,
 - 其余数字除了$d$。 

我们根据第一位数字是否为$d$。 

---

 ## A1。 第一个数字是$d$然后剩下的当中$n-1$我们需要的职位：

 -$k-1$的额外副本$d$,
 - 另一个$n-k$职位可以是以下任何一个$9$数字（除了$d$）。 

数数：$$\binom{n-1}{k-1}9^{\,n-k}.$$---

 ## A2。 第一个数字不是$d$第一个数字：

 - 不能是$0$,
 - 不能是$d$,

 所以有$8$选择。 

剩下的当中$n-1$职位：

 - 选择$k$职位为$d$,
 - 另一个$n-1-k$职位有$9$各有选择。 

数数：$$8\binom{n-1}{k}9^{\,n-1-k}.$$---

 因此对于固定非零$d$,$$\binom{n-1}{k-1}9^{n-k} + 8\binom{n-1}{k}9^{n-1-k}.$$乘以$9$的选择$d$:$$9\binom{n-1}{k-1}9^{n-k} + 72\binom{n-1}{k}9^{n-1-k}.$$---

 # 情况 B：主导数字$d=0$零不能作为前导数字。 

所以：

 - 第一个数字：$9$选择，
 - 剩余的$n-1$职位选择$k$零，
 - 所有其他职位：$9$选择。 

因此：$$9\binom{n-1}{k}9^{n-1-k}.$$---

 # 第三步：合并

 固定总计$n,k$:$$9\binom{n-1}{k-1}9^{n-k} + 81\binom{n-1}{k}9^{n-1-k}.$$使用帕斯卡：$$\binom{n}{k} = \binom{n-1}{k-1}+\binom{n-1}{k}.$$因素：$$9^{n-k+1} \left( \binom{n-1}{k-1}+\binom{n-1}{k} \right) = 9^{n-k+1}\binom{n}{k}.$$所以：$$A(n)= \sum_{k=\lfloor n/2\rfloor+1}^{n} \binom{n}{k}9^{n-k+1}.$$所以$$D(N) = \sum_{n=1}^{N} \sum_{k=\lfloor n/2\rfloor+1}^{n} \binom{n}{k}9^{n-k+1}.$$我们计算模$$M=1\,000\,000\,007.$$---

 # 2.Python实现```python
MOD = 1_000_000_007
N = 2022

# Precompute factorials and inverse factorials
fact = [1] * (N + 1)
for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact = [1] * (N + 1)
invfact[N] = pow(fact[N], MOD - 2, MOD)

for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

# powers of 9
pow9 = [1] * (N + 2)
for i in range(1, N + 2):
    pow9[i] = pow9[i - 1] * 9 % MOD

ans = 0

for n in range(1, N + 1):
    start = n // 2 + 1

    for k in range(start, n + 1):
        ans += C(n, k) * pow9[n - k + 1]
        ans %= MOD

print(ans)
```---

 # 3. 代码演练

 ## 阶乘

 我们预先计算：

 -$n!$,
 - 逆阶乘，

 所以二项式系数可以计算为$O(1)$:$$\binom{n}{k} = \frac{n!}{k!(n-k)!}.$$使用费马：$$a^{-1}\equiv a^{M-2}\pmod M.$$---

 ## 9 的幂

 我们需要许多条款：$$9^{n-k+1}.$$所以我们预先计算所有的权力。 

---

 ## 主要求和

 对于每个数字长度$n$:

 - 主导多重性开始于$$\left\lfloor \frac n2 \right\rfloor +1,$$- 总结所有有效的$k$。 

每个贡献是：$$\binom{n}{k}9^{n-k+1}.$$---
