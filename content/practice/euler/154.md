[欧拉项目问题 154](https://projecteuler.net/problem=154)

 ## 解决方案

 **答案：**`479742450`对于系数$x^i y^j z^k$在$$(x+y+z)^{200000}, \qquad i+j+k=200000,$$多项式系数为$$\binom{200000}{i,j,k} = \frac{200000!}{i!\,j!\,k!}.$$我们必须计算有多少个系数可以被整除$10^{12}=2^{12}5^{12}$。 

所以我们需要$$v_2\!\left(\binom{200000}{i,j,k}\right)\ge 12 \quad\text{and}\quad v_5\!\left(\binom{200000}{i,j,k}\right)\ge 12.$$内联，多项式系数为：$\binom{n}{i,j,k}=\frac{n!}{i!j!k!}$---

 # 1.数学分析

 对于任意素数$p$,$$v_p(n!) = \sum_{m\ge1}\left\lfloor \frac{n}{p^m}\right\rfloor.$$因此$$v_p\!\left(\binom{n}{i,j,k}\right) = v_p(n!) - v_p(i!) - v_p(j!) - v_p(k!).$$对于这个问题：$$n=200000.$$所以定义：$$A_p(t)=v_p(t!).$$然后$$v_p\!\left(\binom{200000}{i,j,k}\right) = A_p(200000)-A_p(i)-A_p(j)-A_p(k).$$我们要求：$$A_2(i)+A_2(j)+A_2(k)\le A_2(200000)-12,$$和$$A_5(i)+A_5(j)+A_5(k)\le A_5(200000)-12.$$---

 ## 高效计算

 直接三重循环$$(i,j,k), \quad i+j+k=200000$$这是不可能的。 

相反：

 - 预先计算所有阶乘估值$A_2(t)$和$A_5(t)$,
 - 迭代$i$，
- 放$k=200000-i-j$,
 - 检验两个不等式。 

关键的优化是对称性：

 - 大多数三元组以大小排列的形式出现$6$,
 - 只有具有相同索引的情况才有较少的排列。 

这极大地减少了运行时间。

 # 2.Python实现```python
N = 200000
MIN_V = 12

# ---------------------------------------------------------
# Compute v_p(n!) for all n <= N
# ---------------------------------------------------------
def cumval(p):
    v = [0] * (N + 1)

    pk = p
    while pk <= N:
        for x in range(pk, N + 1, pk):
            v[x] += 1
        pk *= p

    # Prefix sums => v[n] = v_p(n!)
    for n in range(1, N + 1):
        v[n] += v[n - 1]

    return v

v2 = cumval(2)
v5 = cumval(5)

vN2 = v2[N]
vN5 = v5[N]

# ---------------------------------------------------------
# Count valid multinomial coefficients
# using symmetry i <= j <= k
# ---------------------------------------------------------
count = 0

for i in range(N + 1):

    t2 = vN2 - v2[i] - MIN_V
    t5 = vN5 - v5[i] - MIN_V

    if t2 < 0 or t5 < 0:
        continue

    # j ranges from i to k
    # because we enforce i <= j <= k
    maxj = (N - i) // 2

    for j in range(i, maxj + 1):

        k = N - i - j

        if v2[j] + v2[k] <= t2 and \
           v5[j] + v5[k] <= t5:

            # multiplicity from permutations
            if i == j == k:
                count += 1
            elif i == j or j == k or i == k:
                count += 3
            else:
                count += 6

print(count)
```---

 # 3. 代码演练

 ## 步骤 1 — 阶乘主要估值

 功能：```python
cumval(p)
```计算$$v_p(n!)$$对于每一个$0\le n\le 200000$。 

它通过以下方式做到这一点：

 - 增加权力的贡献$p,p^2,p^3,\dots$,
 - 然后取前缀和。 

---

 ## 步骤 2 — 将整除性转化为不等式

 对于每个$i$,```python
t2 = vN2 - v2[i] - 12
t5 = vN5 - v5[i] - 12
```代表允许的最大贡献$j!$和$k!$。 

然后我们测试：```python
v2[j] + v2[k] <= t2
v5[j] + v5[k] <= t5
```这完全相当于要求整除$2^{12}$和$5^{12}$。 

---

 ## 步骤 3 — 对称性

 而不是迭代所有有序三元组：$$(i,j,k),$$我们只迭代：$$i \le j \le k.$$然后：

 - 所有不同的指数都有贡献$6$排列，
 - 两个相等的指数贡献$3$,
 - 人人平等的贡献$1$。 

这将搜索空间减少了大约一个因子$6$。 

---

 # 4. 小型健全性检查

 对于更小的指数，比如$n=10$，同样的方法再现了可被 的幂整除的多项系数的精确蛮力计数$2$和$5$。 

所以估值逻辑和对称性处理是正确的。 

---

 # 5.最终验证

 系数总数为$$\binom{200002}{2} = 20\,000\,30001.$$最终计数约为$4.8\times10^8$，这是完全合理的，因为整除$10^{12}$是一个非常强的条件。 

该计算与已知的欧拉计划结果相匹配。
