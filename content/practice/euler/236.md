[欧拉项目问题 236](https://projecteuler.net/problem=236)

 ## 解决方案

 **答案：**`123/59`让

-$A_i$= 供应商 A 提供的产品编号$i$,
 -$B_i$= 供应商 B 提供的数量，
 -$a_i$= A 的损坏物品，
 -$b_i$= B 的损坏物品。 

该表是：$$\begin{array}{c|cc}  & A & B\\\hline 1 & 5248 & 640\\ 2 & 1312 & 1888\\ 3 & 2624 & 3776\\ 4 & 5760 & 3776\\ 5 & 3936 & 5664 \end{array}$$定义公因数$m>1$使得 B 的每个产品损坏率比 A 差一个因子$m$:$$\frac{b_i}{B_i}=m\frac{a_i}{A_i}$$同时，A 的总体损坏率比 B 差相同的因素：$$\frac{\sum a_i}{\sum A_i} = m\frac{\sum b_i}{\sum B_i}.$$我们必须找到最大可能的有理值$m$。 

---

 # 1.数学分析

 来自$$\frac{b_i}{B_i}=m\frac{a_i}{A_i},$$我们得到$$b_iA_i = m\,a_iB_i.$$写$$m=\frac{u}{v}$$用最低的术语来说。 然后$$v\,b_iA_i = u\,a_iB_i.$$对于整数解，定义$$g_i=\gcd(uB_i,\;vA_i).$$那么一般整数解就是$$a_i=\frac{vA_i}{g_i}k_i,\qquad b_i=\frac{uB_i}{g_i}k_i,$$对于正整数$k_i$。 

---

 总体情况是$$\frac{\sum a_i}{\sum A_i} = \frac{u}{v}\frac{\sum b_i}{\sum B_i}.$$自从$$\sum A_i = 18880,\qquad \sum B_i = 15744,$$将公式代入$a_i,b_i$给出$$15744\,v^2 \sum_i \frac{A_i}{g_i}k_i = 18880\,u^2 \sum_i \frac{B_i}{g_i}k_i.$$等价地，$$\sum_i \left( 15744\,v^2\frac{A_i}{g_i} - 18880\,u^2\frac{B_i}{g_i} \right)k_i =0.$$所以对于每个候选减少分数$u/v$，我们只需要判断是否存在正整数$k_i$满足这个线性方程和界限$$1\le k_i \le \frac{g_i}{u}.$$---

 ## 边界$m$产品比例为$$\frac{B_i}{A_i}= \left( \frac5{41}, \frac{59}{41}, \frac{59}{41}, \frac{59}{90}, \frac{59}{41} \right).$$从整体方程来看，$$m^2 = \frac{\sum B_i}{\sum A_i} \cdot \frac{\sum a_i}{\sum a_i(B_i/A_i)}.$$由于加权平均$B_i/A_i$严格高于最小值$5/41$,$$m^2 < \frac{246/295}{5/41} = \frac{10086}{1475},$$因此$$m<2.615.$$这给出了有限搜索。 

---

 # 2.Python实现```python
from fractions import Fraction
from math import gcd

A = [5248, 1312, 2624, 5760, 3936]
B = [640, 1888, 3776, 3776, 5664]

SA = sum(A)   # 18880
SB = sum(B)   # 15744

values = set()
best = Fraction(0, 1)

# m < sqrt(10086/1475) < 2.615
LIMIT = 2.615

for v in range(1, 5000):

    max_u = int(LIMIT * v) + 2

    for u in range(v + 1, max_u):

        # reduced fraction only
        if gcd(u, v) != 1:
            continue

        # g_i = gcd(u*B_i, v*A_i)
        g = [gcd(u * B[i], v * A[i]) for i in range(5)]

        # need k_i >= 1 and k_i <= g_i/u
        max_k = [gi // u for gi in g]

        if min(max_k) < 1:
            continue

        # coefficients of the linear equation
        coeff = [
            SB * v * v * A[i] // g[i]
            - SA * u * u * B[i] // g[i]
            for i in range(5)
        ]

        # Meet-in-the-middle search for:
        # sum(coeff[i] * k_i) = 0

        left = set()

        for k1 in range(1, max_k[0] + 1):
            for k2 in range(1, max_k[1] + 1):
                left.add(coeff[0] * k1 + coeff[1] * k2)

        found = False

        for k3 in range(1, max_k[2] + 1):
            for k4 in range(1, max_k[3] + 1):

                partial = coeff[2] * k3 + coeff[3] * k4

                for k5 in range(1, max_k[4] + 1):

                    if -(partial + coeff[4] * k5) in left:
                        found = True
                        break

                if found:
                    break

            if found:
                break

        if found:
            m = Fraction(u, v)
            values.add(m)

            if m > best:
                best = m

print(len(values))
print(best)
```---

 # 3. 代码演练

 ### 步骤 1

 我们循环遍历所有约简分数$$m=\frac{u}{v}$$和$1<m<2.615$。 

---

 ### 步骤 2

 对于每个产品：```python
g = gcd(u * B[i], v * A[i])
```这产生了一般整数解$$a_i=\frac{vA_i}{g_i}k_i,\qquad b_i=\frac{uB_i}{g_i}k_i.$$---

 ### 步骤 3

 我们从整体腐败情况中得出线性约束。 

系数为：```python
coeff[i] =
SB * v^2 * A[i] / g[i]
-
SA * u^2 * B[i] / g[i]
```我们搜索正整数$k_i$满意的$$\sum coeff_i\,k_i = 0.$$---

 ### 步骤 4

 中间相遇搜索使计算速度更快。 

该程序准确地发现：```python
35
123/59
```与正好有 35 个可能值的陈述相匹配。 

---

 # 4.最终验证

 我们得到了$$m=\frac{123}{59}\approx 2.08474576.$$这安全地低于理论上限$2.615$，程序确认：

 - 正好 35 个有效值$m$,
 - 最大值$=123/59$。 

因此计算与问题中的每个条件都是一致的。
