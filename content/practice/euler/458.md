[欧拉项目 458 问题](https://projecteuler.net/problem=458)

 ## 解决方案

 **答案：**`423341841`令字母表为 **project** 的 7 个不同字母：$$A=\{c,e,j,o,p,r,t\}$$禁止的子字符串是**“project”的任何排列**，即任何长度为 7 的块包含**所有 7 个字母恰好一次**。 

## 1.数学分析

 ### 关键观察

 由于字母表本身正好有 7 个字母，因此禁止使用长度为 7 的子串**当且仅当所有 7 个字母都不同**。 

那么问题就变成了：

 > 计算字符串的长度$n$在 7 个字母的字母表中，**没有长度为 7 的连续块具有所有不同的字母**。 

---

 ### 状态压缩

 确定附加字母是否创建禁止块所需的唯一信息是：

 > **不同连续字母**的最长后缀的长度。 

定义状态$k$（$0\le k\le 6$） 作为：

-$k=0$：空字符串，
 -$k\ge1$：当前字符串以后缀结尾$k$不同的字母。 

我们永远不允许状态 7，因为那意味着出现禁止的排列。 

#### 转换规则

 假设我们处于状态$k\ge1$, 带后缀$$x_1x_2\cdots x_k$$（全部不同）。 

如果我们附加：

 - **后缀中没有新字母**：

 后缀长度变为$k+1$， 和$7-k$选择。 
- 现有后缀字母之一$x_i$：

 新的独特后缀变为$$x_{i+1}\cdots x_kx_i$$其长度为$$k-i+1.$$因此从状态$k$：

 - 每个状态只有一次转换$1,2,\dots,k$，
- 和$7-k$转换到状态$k+1$（如果$k<6$）。 

状态$6$无法过渡到$7$，因为这会创建一个禁止的子字符串。 

这产生了一个$7\times7$转移矩阵，所以$$T(n)$$可以使用快速矩阵求幂来计算$$O(7^3\log n).$$快速检查：$$T(7)=7^7-7!=818503,$$匹配问题陈述。

 ## 2.Python实现```python
MOD = 10**9
SIZE = 7

# Build transition matrix
M = [[0] * SIZE for _ in range(SIZE)]

for k in range(SIZE):
    if k == 0:
        # First character: 7 choices -> state 1
        M[1][0] = 7
    else:
        # Repeating one of the suffix letters
        for new_len in range(1, k + 1):
            M[new_len][k] += 1

        # Add a new distinct letter
        if k < 6:
            M[k + 1][k] += (7 - k)

def mat_mul(A, B):
    """Matrix multiplication mod MOD."""
    n = len(A)
    C = [[0] * n for _ in range(n)]

    for i in range(n):
        for k in range(n):
            if A[i][k]:
                a = A[i][k]
                for j in range(n):
                    if B[k][j]:
                        C[i][j] = (C[i][j] + a * B[k][j]) % MOD

    return C

def mat_pow(M, exp):
    """Binary exponentiation of matrix."""
    n = len(M)
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while exp:
        if exp & 1:
            R = mat_mul(R, M)
        M = mat_mul(M, M)
        exp >>= 1

    return R

def T(n):
    # Initial vector: empty string in state 0
    v = [0] * SIZE
    v[0] = 1

    P = mat_pow(M, n)

    result = [0] * SIZE
    for i in range(SIZE):
        total = 0
        for j in range(SIZE):
            total += P[i][j] * v[j]
        result[i] = total % MOD

    return sum(result) % MOD

# Verification
print(T(7))          # 818503
print(T(10**12))     # final answer
```---

 ## 3. 代码演练

 1. **构建转移矩阵**

 对附加字符后不同后缀长度如何变化进行编码。 
2. **矩阵乘法（`mat_mul`)**

 矩阵乘以模$10^9$，因为只需要最后 9 位数字。 
3. **快速求幂(`mat_pow`)**

 计算$$M^n$$在对数时间内。 

1. **初始向量**

 从状态 0（空字符串）开始。 
2. **最终金额**

 将所有有效的结束状态相加即可得到$T(n)$。 

### 小例子检查

 对于$n=7$：```python
T(7) = 818503
```哪个匹配：$$7^7 - 7! = 823543 - 5040 = 818503.$$所以自动机的行为是正确的。

 ## 4.最终验证

 - 我们只跟踪 7 个状态，因此矩阵求幂是准确且高效的。 
- 这$n=7$健全性检查完全匹配。 
- 模数$10^9$算术有效，因为只需要最后 9 位数字。
