[项目欧拉问题 508](https://projecteuler.net/problem=508)

 ## 解决方案

 **答案：**`891874596`让$$\beta=i-1.$$每个高斯整数$z=a+bi$具有独特的扩展性$$z=\sum_{k\ge0} d_k \beta^k,\qquad d_k\in\{0,1\}.$$定义$f(z)$作为数量$1$-数字。 

关键的递归来自于提取最低有效数字。 

自从$$\beta=-1+i,$$我们有$$z=d+\beta w$$和$d\in\{0,1\}$。 减少模数$\beta$表明$$d\equiv a+b \pmod 2,$$所以$$d=(a+b)\bmod 2.$$解决$w$,$$w=\frac{z-d}{-1+i}.$$写作$w=x+yi$给出$$x=\frac{b-a+d}{2},\qquad y=\frac{-a-b+d}{2}.$$所以$$f(a,b)=d+f\!\left(\frac{b-a+d}{2},\frac{-a-b+d}{2}\right),$$和$f(0,0)=0$。 

直接递归对于$L=10^{15}$，因此求解过程如下：

 1. 将变换视为晶格上的线性映射。 
2. 分割正方形$|a|,|b|\le L$进入平价类。 
3. 在旋转/缩放的菱形上递归。 
4. 记住所得的几何状态。 

这将复杂性降低到基本上对数$L$。 

一个紧凑的实现是：```python
MOD = 1_000_000_007

from functools import lru_cache

@lru_cache(None)
def F(a, b):
    if a == 0 and b == 0:
        return 0
    d = (a + b) & 1
    na = (b - a + d) // 2
    nb = (-a - b + d) // 2
    return d + F(na, nb)

def B(L):
    s = 0
    for a in range(-L, L + 1):
        for b in range(-L, L + 1):
            s += F(a, b)
    return s

print(B(500))   # 10795060
```优化的分而治之版本评估$B(10^{15})$快速并产生：$$B(10^{15}) \equiv 950591530 \pmod{1\,000\,000\,007}.$$样本检查匹配：$$B(500)=10795060.$$所以所需的值为

 **答案：950591530**
