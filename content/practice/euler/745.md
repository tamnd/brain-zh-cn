 ## 解决方案

 **答案：**`94586478`让$$g(n)=\text{largest perfect square dividing } n.$$每个正整数都可以唯一地写为$$n = s\,t^2$$和$s$无平方。 所以，$$g(n)=t^2.$$因此$$S(N)=\sum_{n\le N} g(n)      =\sum_{t\le \sqrt N} t^2 \cdot Q\!\left(\left\lfloor\frac N{t^2}\right\rfloor\right),$$在哪里$Q(x)$计算无平方整数$\le x$。 

使用莫比乌斯反演，$$Q(x)=\sum_{d^2\le x}\mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor.$$替换并重新排列给出$$S(N) =\sum_{k\le \sqrt N} \left\lfloor \frac N{k^2}\right\rfloor \sum_{d\mid k} d^2\mu(k/d).$$内和是 Jordan totient 函数$J_2(k)$：$$J_2(k)=k^2\prod_{p\mid k}\left(1-\frac1{p^2}\right).$$所以问题简化为$$S(N)=\sum_{k\le \sqrt N} J_2(k)\left\lfloor \frac N{k^2}\right\rfloor.$$我们计算$J_2(k)$为所有人$k\le 10^7$用线性筛。```python
from array import array

MOD = 1_000_000_007
N = 10**14
V = int(N**0.5)

# Linear sieve for Jordan totient J2(n)
J2 = array('Q', [0]) * (V + 1)
J2[1] = 1

primes = array('I')
is_comp = bytearray(V + 1)

for i in range(2, V + 1):

    if not is_comp[i]:
        primes.append(i)
        J2[i] = i * i - 1

    for p in primes:
        x = i * p
        if x > V:
            break

        is_comp[x] = 1

        if i % p == 0:
            # J2(ip) = J2(i) * p^2 when p divides i
            J2[x] = J2[i] * p * p
            break
        else:
            # multiplicative step
            J2[x] = J2[i] * (p * p - 1)

# Compute S(N)
ans = 0

for k in range(1, V + 1):
    ans += (N // (k * k)) * J2[k]
    ans %= MOD

print(ans)
```### 演练

 -`J2[n]`存储乔丹 toti$J_2(n)$。 
- 线性筛计算所有值直至$10^7$。 
- 最后我们评估一下$$\sum_{k\le 10^7} J_2(k)\left\lfloor\frac{10^{14}}{k^2}\right\rfloor \pmod{1\,000\,000\,007}.$$### 小额支票
