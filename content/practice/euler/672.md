[欧拉项目 672 问题](https://projecteuler.net/problem=672)

 ## 解决方案

 **答案：**`91627537`让$$g(1)=0,\qquad  g(n)= \begin{cases} g(n/7), & 7\mid n,\\[4pt] 1+g(n+1), & 7\nmid n. \end{cases}$$和$$S(N)=\sum_{n=1}^N g(n),\qquad H(K)=S\!\left(\frac{7^K-1}{11}\right).$$我们必须计算$$H(10^9)\pmod{1117117717}.$$---

 # 1.数学分析

 ## 1.1 递归$g(n)$写$$n=7a+r,\qquad 0\le r\le 6.$$如果$r=0$， 然后$$g(7a)=g(a).$$如果$1\le r\le 6$，我们必须添加$7-r$达到下一个倍数$7$：$$7a+r \to 7(a+1).$$然后除以$7$, 给予$a+1$。 因此$$g(7a+r)=(7-r)+g(a+1),\qquad 1\le r\le 6.$$所以：$$\boxed{ g(7a+r)= \begin{cases} g(a), & r=0,\\ 7-r+g(a+1), & 1\le r\le 6. \end{cases}}$$---

 # 1.2 递归$S(N)$让$N=7a+r$。 

首先计算整个块：$$\sum_{i=0}^6 g(7a+i) = g(a)+\sum_{i=1}^6 (7-i+g(a+1)).$$自从$$\sum_{i=1}^6 (7-i)=21,$$我们得到$$\sum_{i=0}^6 g(7a+i)=g(a)+21+6g(a+1).$$现在展开$S(7a+r)$：$$S(7a+r) = S(7a-1)+g(a)+\sum_{i=1}^r (7-i+g(a+1)).$$化简后：$$\boxed{ S(7a+r) = 7S(a)+21a-6 +r\,g(a+1) +7r-\frac{r(r+1)}2 }$$为了$0\le r\le 6$。 

---

 # 1.3 追踪$g(a+1)$定义$$x(a)=g(a+1).$$如果$N=7a+r$， 然后$$N+1= \begin{cases} 7a+r+1, & r<6,\\ 7(a+1), & r=6. \end{cases}$$所以：$$g(N+1)= \begin{cases} 6-r+g(a+1), & r<6,\\ g(a+1), & r=6. \end{cases}$$所以$$\boxed{ x'= \begin{cases} x+6-r, & r<6,\\ x, & r=6. \end{cases}}$$---

 # 1.4 基数 7 的数字$\dfrac{7^K-1}{11}$计算基数中的几个例子$7$：$$\begin{aligned} H(2):&\quad 4_7\\ H(3):&\quad 43_7\\ H(4):&\quad 431_7\\ H(5):&\quad 4311_7\\ H(6):&\quad 43116_7 \end{aligned}$$数字以句点重复$10$：$$4311623550\,4311623550\cdots$$的确，$$\frac1{11} = 0.\overline{04311623550}_7,$$所以$$\frac{7^K-1}{11}$$是第一个$K-1$重复的数字。 

这样我们只需要处理重复的数字循环$$(4,3,1,1,6,2,3,5,5,0).$$---

 # 1.5 状态转换

 维持状态$$(S,x,a,1),$$在哪里

-$S=S(a)$,
 -$x=g(a+1)$,
 -$a$是当前的前缀值。 

追加数字$r$变换：$$a' = 7a+r,$$

$$x' = \begin{cases} x+6-r,& r<6,\\ x,& r=6, \end{cases}$$

$$S' = 7S+21a-6+r x+7r-\frac{r(r+1)}2.$$这是一个仿射线性变换，因此可以用$4\times4$矩阵并快速求幂。 

自从$K=10^9$，我们处理$$K-1=999999999$$数字。 

数字周期长度为$10$，因此我们对矩阵求一整周期的幂。 

---

 # 2.Python实现```python
MOD = 1117117717

# Repeating base-7 digit cycle of (7^K - 1) / 11
cycle = [4, 3, 1, 1, 6, 2, 3, 5, 5, 0]

def mat_mul(A, B):
    """Multiply two 4x4 matrices modulo MOD."""
    n = 4
    C = [[0] * n for _ in range(n)]

    for i in range(n):
        for k in range(n):
            if A[i][k]:
                aik = A[i][k]
                for j in range(n):
                    C[i][j] = (C[i][j] + aik * B[k][j]) % MOD

    return C

def mat_pow(A, e):
    """Fast exponentiation of a 4x4 matrix."""
    n = 4
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while e > 0:
        if e & 1:
            R = mat_mul(A, R)

        A = mat_mul(A, A)
        e >>= 1

    return R

def digit_matrix(r):
    """
    Matrix for appending one base-7 digit r.

    State vector:
        [S, x, a, 1]^T
    """
    const = (-6 + 7 * r - r * (r + 1) // 2) % MOD
    add_x = 0 if r == 6 else (6 - r)

    return [
        [7, r, 21, const],
        [0, 1, 0, add_x],
        [0, 0, 7, r],
        [0, 0, 0, 1],
    ]

# Build matrix for one full 10-digit cycle
cycle_matrix = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

for d in cycle:
    cycle_matrix = mat_mul(digit_matrix(d), cycle_matrix)

K = 10**9
L = K - 1

q, rem = divmod(L, 10)

# Apply full cycles
M = mat_pow(cycle_matrix, q)

# Apply remaining digits
R = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

for d in cycle[:rem]:
    R = mat_mul(digit_matrix(d), R)

# Total transformation
T = mat_mul(R, M)

# Initial state: S=0, x=g(1)=0, a=0
v = [0, 0, 0, 1]

result = sum(T[0][i] * v[i] for i in range(4)) % MOD

print(result)
```---

 # 3. 代码演练

 ## 矩阵状态

 我们存储：$$[S,\ x,\ a,\ 1]$$在哪里：

-$S=S(a)$,
 -$x=g(a+1)$,
 -$a$是当前的基于 7 的前缀。 

额外的尾随$1$让我们以矩阵形式对常量进行编码。 

---

 ##`digit_matrix(r)`这对递归进行编码：$$\begin{aligned} S' &= 7S + r x + 21a + c_r,\\ x' &= x + (6-r)\quad (r<6),\\ a' &= 7a+r. \end{aligned}$$---

 ## 周期性

 数字每重复一次$10$，所以代替处理$10^9$单独的数字，我们：

 1. 构建一个完整循环的矩阵，
 2. 用二进制指数将其提高到适当的幂，
 3. 处理剩余的数字。 

复杂度仅$O(\log K)$。
