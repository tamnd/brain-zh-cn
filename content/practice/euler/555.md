[欧拉项目问题 555](https://projecteuler.net/problem=555)

 ## 解决方案

 **答案：**`208517717451208352`让$$M(n)=M_{m,k,s}(n)= \begin{cases} n-s & (n>m),\\ M(M(n+k)) & (0\le n\le m). \end{cases}$$我们必须计算$$S(p,m)=\sum_{1\le s<k\le p} SF(m,k,s),$$在哪里$SF(m,k,s)$是所有不动点的总和$M_{m,k,s}$。 

我们被要求$$S(10^6,10^6).$$---

 # 步骤 1 — 理解递归

 我们从结构上分析该函数。 

为了$n\le m$， 如果$n+k>m$，那么第一个递归调用立即退出递归：$$M(n+k)=n+k-s.$$定义$$d=k-s.$$然后$$M(n+k)=n+d.$$所以对于$m-k<n\le m$,$$M(n)=M(n+d).$$现在考虑重复添加时会发生什么$d$。 

最终我们跨越了上面$m$，然后函数通过减去返回$s$。 

关键的观察是：

 - 如果$d\nmid s$，该过程循环通过残差类别并且不存在固定点。 
- 如果$d\mid s$，那么不动点确实存在。 

写$$s=cd,\qquad k=(c+1)d.$$那么不动点正好是$$m-s+1,\; m-s+2,\;\dots,\; m-s+d.$$所以：

 - 固定点数 =$d$,
 - 他们的总和是$$SF(m,k,s) = \sum_{i=1}^{d}(m-s+i).$$计算这个总和：$$SF(m,k,s) = d(m-s)+\frac{d(d+1)}2.$$自从$s=cd$,$$SF = d(m-cd)+\frac{d(d+1)}2.$$---

 # 步骤 2 — 重新参数化总和

 因为$$k=(c+1)d,$$每个有效对$(k,s)$固定点唯一对应于：

 -$d\ge1$,
 -$c\ge1$,
 -$(c+1)d\le p$。 

等价地，定义$$t=c+1,$$所以$t\ge2$和$$k=td,\qquad s=(t-1)d.$$然后$$SF = d\left(m-(t-1)d\right)+\frac{d(d+1)}2.$$简化：$$SF = \frac d2\Bigl(2m-(2t-3)d+1\Bigr).$$所以$$S(p,m) = \sum_{d=1}^{p} \sum_{t=2}^{\lfloor p/d\rfloor} \frac d2\Bigl(2m-(2t-3)d+1\Bigr).$$---

 # 步骤 3 — 封闭式内求和

 让$$N=\left\lfloor\frac pd\right\rfloor.$$然后$$S(p,m) = \sum_{d=1}^{p} \left[ \frac{d(N-1)(2m+1+3d)}2 - d^2\left(\frac{N(N+1)}2-1\right) \right].$$这只是$O(p)$，足够快$p=10^6$。 

---

 # 第 4 步 — Python 实现```python
def S(p, m):
    total = 0

    for d in range(1, p + 1):
        N = p // d
        cnt = N - 1

        total += (
            d * cnt * (2 * m + 1 + 3 * d) // 2
            - d * d * (N * (N + 1) // 2 - 1)
        )

    return total

# Verify the examples
print(S(10, 10))         # 225
print(S(1000, 1000))     # 208724467

# Required answer
print(S(10**6, 10**6))
```---
