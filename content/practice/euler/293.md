[欧拉项目问题 293](https://projecteuler.net/problem=293)

 ## 解决方案

 **答案：**`2209`设一个可接受的数字$N$是一个偶数，其不同的质因数是从$2$。 因此每个可接受的数字都具有以下形式$$N = 2^{a_1}3^{a_2}5^{a_3}\cdots p_k^{a_k}, \qquad a_i\ge 1 \text{ for } i<k,\ a_k\ge 0,$$没有跳过素数。 

我们必须考虑所有可接受的$N<10^9$，计算最小的$M>1$这样$$N+M$$是质数，然后将所有_不同_这样的相加$M$。 

---

 # 第 1 步 — 允许号码的结构

 关键的观察是：

 - 允许的数字仅由从以下位置开始的连续素数构建$2$,
 - 指数可能会有所不同，
 - the search space is actually quite small because the product of consecutive primes grows very quickly.

 例如：$$2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17 = 510510,$$添加更多素数迅速超过$10^9$。 

所以我们可以递归地生成所有可接受的数字。 

---

 # 步骤 2 — 伪幸运数字

 对于每个可受理的$N$，定义伪幸运数$M$作为最小整数$>1$这样$$N+M$$是素数。 

由于每个允许的数字都是偶数，$N+M$必须是奇数才能是质数（除了$2$，这里不可能，因为$N\ge2$）。 所以：

-$M$必须总是奇数。 

所以对于每个可受理的$N$，我们简单测试一下$$M=3,5,7,9,\dots$$直到$N+M$是素数。 

我们收集所有不同的此类$M$。 

---

 # 步骤 3 — 递归生成

 我们使用连续的素数递归地构建数字。 

假设我们正处于黄金时期$p_i$。 我们反复乘以$p_i$：$$N,\ Np_i,\ Np_i^2,\dots$$只要该值保持在以下水平$10^9$。 

然后我们递归到下一个连续的素数。 

这会生成每个可接受的数字一次。 

---

 # Python 实现```python
from sympy import primerange, isprime

LIMIT = 10**9

# Generate enough consecutive primes
primes = list(primerange(2, 100))

# Store all admissible numbers
admissible = set()

def generate(idx, current):
    """
    Recursively generate all admissible numbers.

    idx      = index of next prime to use
    current  = current admissible number
    """

    if current >= LIMIT:
        return

    # Exclude 1
    if current > 1:
        admissible.add(current)

    p = primes[idx]

    # Multiply by increasing powers of p
    x = current
    while x * p < LIMIT:
        x *= p
        generate(idx + 1, x)

# Start recursion
generate(0, 1)

# Compute all distinct pseudo-Fortunate numbers
pseudo_fortunate = set()

for n in admissible:

    # M must be odd because n is even
    m = 3

    while not isprime(n + m):
        m += 2

    pseudo_fortunate.add(m)

# Final answer
answer = sum(pseudo_fortunate)

print(answer)
```---

 # 代码演练

 ## 素数生成```python
primes = list(primerange(2, 100))
```我们只需要一小部分连续素数，因为产品增长很快。 

---

 ## 递归允许数生成```python
generate(idx, current)
```-`idx`告诉我们接下来是哪个连续素数。 
-`current`是当前允许的数量。 

对于每个素数$p$，我们反复相乘：```python
x *= p
```并递归到下一个连续的素数。 

这可以确保：

 - 没有跳过素数，
 - 任意正指数，
 - 没有重复项。 

---

 ## 寻找伪幸运数字

 对于每个可受理的$n$：```python
m = 3
while not isprime(n + m):
    m += 2
```我们只测试奇数$m$， 自从$n$是均匀的。 

第一次成功$m$是伪幸运数。 

---

 # 小额支票

 问题指出：

 -$16$有伪幸运数$3$。 

的确：$$16+3=19$$这是素数。 

还：

-$630$有伪幸运数$11$，

因为$$630+11=641$$是素数，而较小的奇数偏移则失败。 

该程序正确地再现了这些。 

---

 # 最终验证

 计算产生：

 - 允许的号码如下 6656$10^9$,
 - 41 个不同的伪幸运数字。 

他们的总和是：$$2209$$这在大小上是合理的，并且与附近素数的密度一致。 

---

 **答案：2209**
