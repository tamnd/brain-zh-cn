[项目欧拉问题 630](https://projecteuler.net/problem=630)

 ## 解决方案

 **答案：**`9669182880384`设一组独特的线为$L$。 

对于一条线$\ell\in L$， 定义$c(\ell)$作为穿过它的其他线的数量。 

然后$$S(L)=\sum_{\ell\in L} c(\ell).$$两条不同的线无法交叉**当且仅当**它们是平行的。 

因此，对于每一行，$$c(\ell)=M(L)-(\text{number of lines parallel to }\ell).$$所以问题就简化为：

 1. 计算所有不同的行。 
2. 按坡度对它们进行分组。 

---

 # 步骤 1 — 生成点

 顺序是：$$S_0=290797,\qquad S_{n+1}=S_n^2 \bmod 50515093$$和$$T_n=(S_n \bmod 2000)-1000.$$要点是$$(T_1,T_2),(T_3,T_4),\dots$$为了$n=2500$，我们生成 2500 点。 

前三个确实是：$$(527,144),\ (-488,732),\ (-454,-947).$$---

 # 步骤 2 — 唯一地表示一条线

 通过点的线$(x_1,y_1)$和$(x_2,y_2)$有方向向量$$(dx,dy)=(x_2-x_1,\ y_2-y_1).$$通过除以标准化$$g=\gcd(dx,dy),$$因此斜率表示变得原始。 

我们还强制执行一个独特的符号约定：

 -$dx>0$， 或者
-$dx=0$和$dy>0$。 

因此，每个斜率都只有一个规范表示。 

---

 ## 规范线型

 使用归一化$(dx,dy)$, 数量$$c = dy\cdot x - dx\cdot y$$沿着这条线是恒定的，因为$$dy\,x - dx\,y = \text{constant}$$等价于直线方程。 

因此，一条独特的线表示为$$(dy,dx,c).$$这会自动删除重复项。 

---

 # 步骤 3 — 计算交叉点

 假设坡度等级$i$包含$m_i$线。 

然后：

 - 总行数：$$M=\sum_i m_i$$- 课堂上的每一行$i$恰好与$M-m_i$线。 

因此$$S=\sum_i m_i(M-m_i).$$扩展：$$S=M^2-\sum_i m_i^2.$$所以我们只需要：

 1. 唯一行的数量，
 2. 各坡度等级的线数。 

---

 # Python 实现```python
from math import gcd
from collections import defaultdict

MOD = 50515093

# ------------------------------------------------------------
# Generate the 2500 points
# ------------------------------------------------------------

s = 290797
points = []

for _ in range(2500):
    s = (s * s) % MOD
    x = (s % 2000) - 1000

    s = (s * s) % MOD
    y = (s % 2000) - 1000

    points.append((x, y))

# ------------------------------------------------------------
# Build all unique lines
# ------------------------------------------------------------

lines = set()
slope_count = defaultdict(int)

n = len(points)

for i in range(n):
    x1, y1 = points[i]

    for j in range(i + 1, n):
        x2, y2 = points[j]

        dx = x2 - x1
        dy = y2 - y1

        # normalize slope
        g = gcd(dx, dy)
        dx //= g
        dy //= g

        # canonical sign
        if dx < 0 or (dx == 0 and dy < 0):
            dx = -dx
            dy = -dy

        # canonical line constant
        c = dy * x1 - dx * y1

        line = (dy, dx, c)

        # count only unique lines
        if line not in lines:
            lines.add(line)
            slope_count[(dy, dx)] += 1

# ------------------------------------------------------------
# Compute M and S
# ------------------------------------------------------------

M = len(lines)

S = M * M - sum(v * v for v in slope_count.values())

print(M)
print(S)
```---

 ### 斜率标准化```python

dx //= g

```将方向向量简化为原始形式。 

---

 ### 符号标准化```python
if dx < 0 or (dx == 0 and dy < 0):
```确保$(1,2)$和$(-1,-2)$被视为相同的斜率。 

---

 ### 独特的线条表示```python
c = dy * x1 - dx * y1
line = (dy, dx, c)
```给出无限线的规范标识符.

 ---

 ### 计算交叉口

 如果坡度等级包含$v$线，这些线不彼此相交，但与其他线相交。 

因此：```python
S = M*M - sum(v*v for v in slope_count.values())
```实施$$S=M^2-\sum_i m_i^2.$$---

 # 小例子验证

 对于$n=3$:

 - 有3条独特的线路，
 - 没有两个是平行的，

 所以$$M=3,\qquad S=3^2-3=6,$$与声明相符。 

为了$n=100$，程序给出：$$M(L_{100})=4948,$$

$$S(L_{100})=24477690,$$再次匹配问题陈述。
