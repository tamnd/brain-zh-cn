[欧拉项目问题 25](https://projecteuler.net/problem=25)

 ## 解决方案

 **答案：**`4782`我们寻求索引$n$第一个斐波那契数列的$1000$数字。 

斐波那契数列满足：$$F_n = F_{n-1}+F_{n-2}, \qquad F_1=1,\;F_2=1$$一个号码有$1000$数字如果：$$F_n \ge 10^{999}$$使用比奈公式的近似：$F_n\approx \frac{\varphi^n}{\sqrt{5}}$在哪里$\varphi = \frac{1+\sqrt5}{2}$。 

我们解决：$$\frac{\varphi^n}{\sqrt5} \ge 10^{999}$$取对数：$$n\log_{10}(\varphi)-\log_{10}(\sqrt5)\ge 999$$

$$n \ge \frac{999+\log_{10}(\sqrt5)} {\log_{10}(\varphi)}$$评估给出：$$n \ge 4781.859\ldots$$所以第一个有效索引是：$$n = 4782$$### Python代码```python
a, b = 1, 1
index = 2

while len(str(b)) < 1000:
    a, b = b, a + b
    index += 1

print(index)
```心理追踪：

 -$F_{12}=144$确实是第一个 3 位斐波那契数（与示例匹配）。 
- 循环递增，直到第一项达到 1000 位。 
- 计算出的索引为**4782**。 

**答案：4782**
