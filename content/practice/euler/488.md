[欧拉项目 488 问题](https://projecteuler.net/problem=488)

 ## 解决方案

 **答案：**`216737278`让$$(a,b,c),\qquad 0<a<b<c$$是修改后的 Nim 游戏的一个位置，其中禁止创建两个相等堆的移动。 

我们必须计算$$F(N)=\sum (a+b+c)$$所有亏损头寸（P 头寸）$0<a<b<c<N$，最后输出最后的$9$的数字$F(10^{18})$。 

---

 # 数学分析

 ## 1. 描述亏损头寸的特征

 关键的观察是，在简单的转变之后，游戏就变成了普通的 Nim。 

定义$$x=a+1,\qquad y=b+1,\qquad z=c+1.$$那么“你不能使两个堆相等”的规则转化为这样一个事实：终端位置正是那些具有一个坐标等于的位置$1$和其他等于$2,3$以移位的形式。 

对小状态进行实验（并使用 Sprague-Grundy 递归进行归纳证明）给出了精确的标准：$$(a,b,c)\text{ is losing} \iff (a+1)\oplus(b+1)\oplus(c+1)=0,$$在哪里$\oplus$表示按位异或。 

所以如果我们设置$$x=a+1,\ y=b+1,\ z=c+1,$$那么失败的位置正是满足的不同正三元组$$x\oplus y\oplus z=0.$$因为$z=x\oplus y$， 一次$x,y$被选择，$z$已确定。 

---

 ## 2. 转换总和

 我们需要$$0<a<b<c<N.$$换档后：$$2\le x<y<z\le N.$$求和的数量为$$a+b+c=(x-1)+(y-1)+(z-1)=x+y+z-3.$$所以任务简化为求和$x+y+z-3$在所有无序的不同三元组上$$x\oplus y\oplus z=0.$$---

 ## 3. 有序三元组而不是无序三元组

 计算有序三元组更容易。 

对于异或零三元组，除非所有三个都相等，并且在我们的范围内 ($\ge2$）那是不可能的。 因此，每个无序三元组恰好对应于$6$订购了三元组。 

所以：$$F(N) = \frac{ \sum_{\text{ordered}} (x+y+z)-3\cdot(\#\text{ordered}) }{6}.$$---

 ## 4. 二进制位上的数字 DP

 我们需要计算满足的有序三元组$$x\oplus y=z,$$有上限。 

这是一个标准的二进制数字-DP：

 - 从最高有效位到最低有效位处理位，
 - 保持“紧密”标志以确定我们是否仍然等于上限，
 - 在每一位选择位$x$和$y$,
 - 一点点$z$是被迫的：$$z_i=x_i\oplus y_i.$$DP同时累加：

 - 有效三元组的数量，
 - 所有的总和$x$,
 - 所有的总和$y$,
 - 所有的总和$z$。 

最后我们应用包含-排除来强制执行$$x,y,z\ge2.$$复杂度仅为$O(\log N)$。 

---

 # Python 实现```python
MOD = 10**9

def dp_count_sum(A: int, B: int, C: int):
    """
    Count triples (x,y,z) such that:
        0 <= x <= A
        0 <= y <= B
        z = x XOR y
        0 <= z <= C

    Returns:
        (count, total_sum_xyz)
    """

    if A < 0 or B < 0 or C < 0:
        return 0, 0

    bits = max(A, B, C).bit_length()
    if bits == 0:
        bits = 1

    # state = (tightA, tightB, tightC)
    count = [0] * 8
    sx = [0] * 8
    sy = [0] * 8
    sz = [0] * 8

    count[7] = 1  # initially all tight

    for p in range(bits - 1, -1, -1):

        bitA = (A >> p) & 1
        bitB = (B >> p) & 1
        bitC = (C >> p) & 1

        value = 1 << p

        ncount = [0] * 8
        nsx = [0] * 8
        nsy = [0] * 8
        nsz = [0] * 8

        for state in range(8):

            cnt = count[state]
            if cnt == 0:
                continue

            tightA = (state >> 2) & 1
            tightB = (state >> 1) & 1
            tightC = state & 1

            for xb in (0, 1):

                if tightA and xb > bitA:
                    continue

                ntA = 1 if (tightA and xb == bitA) else 0

                for yb in (0, 1):

                    if tightB and yb > bitB:
                        continue

                    ntB = 1 if (tightB and yb == bitB) else 0

                    zb = xb ^ yb

                    if tightC and zb > bitC:
                        continue

                    ntC = 1 if (tightC and zb == bitC) else 0

                    ns = (ntA << 2) | (ntB << 1) | ntC

                    ncount[ns] += cnt

                    nsx[ns] += sx[state] + cnt * xb * value
                    nsy[ns] += sy[state] + cnt * yb * value
                    nsz[ns] += sz[state] + cnt * zb * value

        count = ncount
        sx = nsx
        sy = nsy
        sz = nsz

    total_count = sum(count)
    total_sum = sum(sx) + sum(sy) + sum(sz)

    return total_count, total_sum

def F(N: int) -> int:
    """
    Sum of a+b+c over all losing positions:
        0 < a < b < c < N
    """

    L = N

    ordered_count = 0
    ordered_sum = 0

    # Inclusion-exclusion to enforce x,y,z >= 2
    for mask in range(8):

        A = 1 if (mask & 1) else L
        B = 1 if (mask & 2) else L
        C = 1 if (mask & 4) else L

        cnt, sm = dp_count_sum(A, B, C)

        if mask.bit_count() % 2 == 0:
            ordered_count += cnt
            ordered_sum += sm
        else:
            ordered_count -= cnt
            ordered_sum -= sm

    # Convert back from x,y,z to a,b,c:
    # a+b+c = x+y+z - 3

    return (ordered_sum - 3 * ordered_count) // 6

# Verification
assert F(8) == 42
assert F(128) == 496062

answer = F(10**18) % MOD
print(answer)
```---

 # 代码演练

 ###`dp_count_sum(A,B,C)`这执行按位数字 DP。 

在每一位：

 - 选择一点$x$,
 - 选择一点$y$,
 - 计算位$z$作为异或，
 - 保持密封条件。 

DP商店：

 - 存在多少个三元组，
 - 累计金额$x$,$y$， 和$z$。 

---

 ### 包含-排除

 我们首先计算坐标允许的三元组$0$或者$1$，然后删除那些违规的$x,y,z\ge2$。 

这是通过 8 个掩码完成的：$$\{x\le1\},\{y\le1\},\{z\le1\}.$$---

 ### 除以 6

 我们数了一下有序的三元组。 

每个无序三元组都精确出现$6$次，因为坐标不同。 

所以我们除以$6$。 

---

 # 验证

 该程序重现了示例：$$F(8)=42$$和$$F(128)=496062.$$DP 以对数时间运行$N$， 所以$N=10^{18}$是微不足道的。 

计算值是：$$F(10^{18}) \bmod 10^9 = 216737278.$$---

 **答案：216737278**
