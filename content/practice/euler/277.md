[欧拉项目问题 277](https://projecteuler.net/problem=277)

 ## 解决方案

 **答案：**`1125977393124310`令所需的步骤字符串为$$S=\texttt{UDDDUdddDDUDDddDdDddDDUDDdUUDd}$$我们寻找最小的整数$a_1>10^{15}$其修改后的 Collat​​z 轨迹正是从这些步骤开始的。 

---

 # 1.数学分析

 规则是：

 -$D:\quad a_{n+1}=\dfrac{a_n}{3}$，有效时$a_n\equiv0\pmod3$-$U:\quad a_{n+1}=\dfrac{4a_n+2}{3}$，有效时$a_n\equiv1\pmod3$-$d:\quad a_{n+1}=\dfrac{2a_n-1}{3}$，有效时$a_n\equiv2\pmod3$关键的观察是：

 > 每一步都是仿射线性变换。 

因此，经过一整串步骤后，起始值是结束值的仿射函数。 

---

 ## 逆向工作

 假设在所有步骤之后我们以某个整数结束$x$。 

我们反转每个操作。 

### 的逆$D$

$$a_n = 3a_{n+1}$$### 的逆$U$

$$a_{n+1}=\frac{4a_n+2}{3}$$所以$$a_n=\frac{3a_{n+1}-2}{4}$$### 的逆$d$

$$a_{n+1}=\frac{2a_n-1}{3}$$所以$$a_n=\frac{3a_{n+1}+1}{2}$$---

 我们现在向后处理所需的字符串。 

令所有步骤后的最终值为$x$。 

将所有逆映射进行符号组合后，我们得到$$a_1 = \frac{205891132094649\,x+21110037246199}{2^{22}}$$因此$a_1$是一个整数当且仅当$$205891132094649\,x+21110037246199 \equiv 0 \pmod{2^{22}}$$自从$2^{22}=4194304$，减少系数模$4194304$:$$686265x+356599\equiv0\pmod{4194304}$$因为$$\gcd(686265,4194304)=1,$$存在唯一解模$4194304$。 

求解给出$$x\equiv 1966289 \pmod{4194304}.$$所以写$$x=1966289+4194304k.$$代入仿射表达式$a_1$:$$a_1 = 96521732651065 + 205891132094649\,k.$$我们现在选择最小的$k$这样$$a_1>10^{15}.$$那是，$$96521732651065+205891132094649\,k>10^{15}.$$这给出了$$k=5.$$因此$$a_1 = 96521732651065 + 5\cdot205891132094649 = 1125977393124310.$$---

 # 2.Python实现```python
from math import gcd

# Required step sequence
s = "UDDDUdddDDUDDddDdDddDDUDDdUUDd"

# We derive:
# a1 = (A*x + B) / M
# where x is the value AFTER all steps.

A = 1
B = 0
M = 1

# Process inverses in reverse order
for ch in reversed(s):

    if ch == 'D':
        # x -> 3x
        A *= 3
        B *= 3

    elif ch == 'U':
        # x -> (3x - 2)/4
        A *= 3
        B = 3 * B - 2
        M *= 4

    elif ch == 'd':
        # x -> (3x + 1)/2
        A *= 3
        B = 3 * B + 1
        M *= 2

# Need:
# A*x + B ≡ 0 (mod M)

a = A % M
b = B % M

# modular inverse since gcd(a, M)=1
inv = pow(a, -1, M)

x0 = (-b * inv) % M

# General solution:
# x = x0 + M*k
#
# Then:
# a1 = (A*x + B)/M
#
# = base + A*k

base = (A * x0 + B) // M
step = A

LIMIT = 10**15

k = (LIMIT - base + step) // step

answer = base + step * k

print(answer)
```---

 # 3. 代码演练

 ### 构建仿射形式

 我们向后处理序列，因为逆公式是简单的线性映射。 

我们维持：$$a_1 = \frac{A x + B}{M}$$在哪里$x$是整个序列之后的未知终点。 

每个逆步骤都会更新$A,B,M$。 

---

 ### 解决完整性问题

 对于$a_1$为整数：$$A x + B \equiv 0 \pmod M.$$这是线性同余。 

因为$A$是可逆模数$M$，恰好存在一个余数类模$M$。 

---

 ### 生成所有解决方案

 每个有效的解决方案是：$$x=x_0+Mk.$$代入仿射公式可得：$$a_1=\text{base}+A k.$$因此有效的起始值形成一个算术级数。 

我们选择最小的一个超过$10^{15}$。
