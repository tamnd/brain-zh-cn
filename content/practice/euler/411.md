[欧拉项目 411 问题](https://projecteuler.net/problem=411)

 ## 解决方案

 **答案：**`9936352`让$$P_i = \left(2^i \bmod n,\; 3^i \bmod n\right), \qquad 0 \le i \le 2n.$$删除重复项后，这些就是“站”。 

我们想要最长的路径$(0,0)$到$(n,n)$其坐标永远不会减少。 

同样，在所有站点中，我们想要可以排序的最大子集，使得两个坐标都是非递减的。 

---

 # 关键的数学见解

 假设我们通过增加对所有不同的站点进行排序$x$-坐标（然后通过$y$-协调）。 

那么一条有效的上坡路径恰好对应于一个子序列，其$y$- 坐标不减。 

所以：$$S(n)=\text{length of the Longest Nondecreasing Subsequence (LNDS)}$$的$y$-对电台进行排序后的值$x$。 

那么问题就变成了：

 1. 生成所有不同的点$$(2^i \bmod n,\; 3^i \bmod n).$$2. 按字典顺序对它们进行排序。 
3. 计算 LANDS$y$- 坐标。 

标准耐心排序 LIS 算法计算此$O(m\log m)$， 在哪里$m$是不同站点的数量。 

因为平等$y$- 允许值（非递减，不严格递增），我们必须使用`upper_bound`， 不是`lower_bound`。 

---

 # Python 实现```python
from bisect import bisect_right

def S(n):
    # Generate all distinct stations
    seen = set()
    points = []

    x = 1 % n
    y = 1 % n

    while (x, y) not in seen:
        seen.add((x, y))
        points.append((x, y))

        x = (2 * x) % n
        y = (3 * y) % n

    # Sort by x, then y
    points.sort()

    # Longest nondecreasing subsequence on y
    lis = []

    for _, yy in points:
        pos = bisect_right(lis, yy)

        if pos == len(lis):
            lis.append(yy)
        else:
            lis[pos] = yy

    return len(lis)

total = 0

for k in range(1, 31):
    total += S(k ** 5)

print(total)
```---

 # 代码演练

 ### 生成电台```python
x = 1 % n
y = 1 % n
```这些对应于$i=0$:$$(2^0 \bmod n,\;3^0 \bmod n)=(1,1).$$每次迭代乘以 2 和 3 模$n$:```python
x = (2 * x) % n
y = (3 * y) % n
```一旦一对重复，我们就停止，因为序列是周期性的。 

---

 ### 对点进行排序```python
points.sort()
```这按字典顺序排序$x$， 然后$y$。 

任何上坡路都必须遵守这个顺序。 

---

 ### 最长非减子序列

 我们现在只需要最长的非减序列$y$-价值观。 

耐心排序技术坚持：```python
lis[i]
```= 长度不减的子序列的最小可能尾部$i+1$。 

我们使用：```python
bisect_right
```因为平等$y$- 允许值。
