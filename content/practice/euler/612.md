[欧拉项目 612 问题](https://projecteuler.net/problem=612)

 ## 解决方案

 **答案：**`819963842`让$$N=10^{18}$$并考虑所有整数$$1 \le x < N.$$如果两个数字的十进制表示形式至少共用一位数字，则它们是**朋友**。 

我们想要$$f(N)=\#\{(p,q):1\le p<q<N,\; p,q\text{ are friends}\}$$模数$1000267129$。 

## 1.数学分析

 不要直接计算朋友对，而是计算补集：

 > **非好友对** = 与**不相交的数字组**配对。 

然后$$f(N)=\binom{N-1}{2}-\text{(non-friend pairs)}.$$自从$N=10^{18}$，下面的每个正整数$N$最多有 18 位小数。 

### 第 1 步：按数字集对数字进行分类

 对于一个号码$x$， 定义$D(x)\subseteq \{0,\dots,9\}$作为出现在的数字集$x$。 

让$$F(S)=\#\{x:1\le x<10^{18},\ D(x)=S\}$$对于每个子集$S\subseteq \{0,\dots,9\}$。 

然后是一对$(p,q)$是非朋友当且仅当$$D(p)\cap D(q)=\varnothing.$$因此$$\text{non-friend pairs} = \frac12 \sum_{\substack{A,B\\A\cap B=\varnothing}} F(A)F(B).$$因素$1/2$消除重复计算。 

---

 ### 步骤 2：仅使用一组数字来计算数字

 定义$$G(T)$$作为正整数的数量$<10^{18}$其数字全部在$T$。 

认为$T$包含：

 -$k=|T|$总位数，
 -$nz$非零数字（前导数字不能为 0）。 

对于一个长度$L$:

 - 第一个数字：$nz$选择，
 - 剩余$L-1$:$k$各有选择。 

所以$$G(T) = \sum_{L=1}^{18} nz\cdot k^{L-1}.$$这对数字集**包含在**中的数字进行计数$T$。 

---

 ### 步骤 3：包含-排除（莫比乌斯反演）

 我们需要**精确的**数字集。 

自从$$G(T)=\sum_{S\subseteq T}F(S),$$我们康复了$F$通过子集莫比乌斯反演：$$F(S) = \sum_{T\subseteq S} (-1)^{|S|-|T|} G(T).$$只有$2^{10}=1024$子集，因此计算量很小。 

---

 ## 2.Python实现```python
MOD = 1000267129

def solve():
    LIMIT = 10**18
    MAX_LEN = 18
    FULL_MASK = (1 << 10) - 1  # digits 0..9

    # G[mask] = count of numbers using only digits in mask
    G = [0] * 1024

    for mask in range(1, 1024):
        k = mask.bit_count()
        has_zero = mask & 1
        nonzero_digits = k - (1 if has_zero else 0)

        # Cannot start with zero
        if nonzero_digits == 0:
            continue

        total = 0
        for length in range(1, MAX_LEN + 1):
            total += nonzero_digits * (k ** (length - 1))

        G[mask] = total

    # Möbius inversion to get exact digit-set counts
    F = G[:]

    for bit in range(10):
        for mask in range(1024):
            if mask & (1 << bit):
                F[mask] -= F[mask ^ (1 << bit)]

    # Total unordered pairs
    M = LIMIT - 1
    total_pairs = M * (M - 1) // 2

    # Count non-friend pairs (disjoint digit sets)
    non_friend = 0

    for A in range(1, 1024):
        fa = F[A]
        if fa == 0:
            continue

        complement = FULL_MASK ^ A
        B = complement

        while B:
            non_friend += fa * F[B]
            B = (B - 1) & complement

    # Each unordered pair counted twice
    non_friend //= 2

    friend_pairs = total_pairs - non_friend

    return friend_pairs % MOD

print(solve())
```---

 ## 3. 代码演练

 ### 构建`G`对于每个数字子集（`mask`）：

 - 计算它包含多少个数字（`k`）
 - 计算有多少个非零（`nonzero_digits`）
 - 对于每个长度$1$到$18$,$$\text{count} = \text{nonzero\_digits}\cdot k^{L-1}$$将它们加在一起。 

---

 ### 莫比乌斯反演`F`开始为`G`。 

对于每一位（数字），减去较小的子集：```python
F[mask] -= F[mask ^ (1 << bit)]
```此后，```python
F[S]
```计算数字集**完全**的数字`S`。 

---

 ### 计算不相交对的数量

 对于每个子集`A`，枚举子集`B`其补数：```python
complement = FULL_MASK ^ A
```然后`A`和`B`是不相交的。 

积累：```python
F[A] * F[B]
```并除以 2，因为无序对被计数两次。 

---

 ### 验证样本

 对于$n=100$，程序给出：$$f(100)=1539$$与问题陈述相匹配。
