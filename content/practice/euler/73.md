 ## 解决方案

 **答案：**`7295372`## 1.数学分析

 我们想要**约简真分数**的数量$$\frac{n}{d}$$这样$$\frac13 < \frac nd < \frac12 \quad\text{and}\quad \gcd(n,d)=1,$$对于所有分母$$d \le 12000.$$### 步骤 1：找到每个分母的分子范围

 固定分母$d$。 我们需要：$$\frac13 < \frac nd < \frac12.$$乘以通过$d$：$$\frac d3 < n < \frac d2.$$所以有效的分子是整数$$\left(\left\lfloor \frac d3 \right\rfloor + 1\right) \le n \le \left\lceil \frac d2 \right\rceil - 1.$$但我们还必须要求：$$\gcd(n,d)=1.$$因此对于每个分母$d$，我们计算整数$n$在此区间内互质于$d$。 

---

 ### 步骤 2：直接计数法

 一个简单的算法是：

 对于每个分母$d=2,3,\dots,12000$：

 1. 计算尽可能小的分子：$$n_{\min}=\left\lfloor \frac d3 \right\rfloor +1$$2. 计算最大可能的分子：$$n_{\max}=\left\lfloor \frac{d-1}{2}\right\rfloor$$3. 对于每个整数$n\in[n_{\min},n_{\max}]$：

 - 检查是否$$\gcd(n,d)=1.$$- 如果是的话，数一下。 

搜索空间是可管理的，因为：

 -$d \le 12000$- 平均间隔长度约为$d/6$总工作量大约是几千万次 gcd 检查，Python 可以轻松处理。 

更复杂的数论解决方案使用 **Farey 序列** 或莫比乌斯反演计数，但强力 gcd 方法已经足够快了。 

---

 ## 2.Python实现```python
from math import gcd

def count_fractions(limit):
    total = 0

    # Check every denominator
    for d in range(2, limit + 1):

        # Numerators strictly between 1/3 and 1/2
        n_min = d // 3 + 1
        n_max = (d - 1) // 2

        # Count reduced fractions
        for n in range(n_min, n_max + 1):
            if gcd(n, d) == 1:
                total += 1

    return total

# Problem answer
result = count_fractions(12000)
print(result)
```---
