[项目欧拉问题 325](https://projecteuler.net/problem=325)

 ## 解决方案

 **答案：**`54672965`设位置为$(x,y)$和$0<x<y$。 

一个动作取代$(x,y)$经过$(x,y-kx)$对于某个整数$k\ge1$，然后根据需要重新排序。 

我们寻找所有**亏损头寸**（P 头寸），然后计算$$S(N)=\sum_{\substack{(x,y)\text{ losing}\\0<x<y\le N}} (x+y).$$---

 # 1.数学分析

 ## 步骤 1：描述亏损头寸的特征

 让$$\varphi=\frac{1+\sqrt5}{2}.$$我们主张：$$(x,y)\text{ is losing } \iff y<\varphi x.$$等价地，$$x<y<x+\frac{x}{\varphi},$$自从$\varphi=1+\frac1\varphi$。 

- -

＃＃ 为什么？ 

认为$y\ge \varphi x$。 

那么存在一个整数$k\ge1$这样$$y-kx<\varphi x$$重新排序后，新位置正在丢失。 

所以每一个这样的位置都是胜利的。 

相反，如果$y<\varphi x$，那么任何合法的移动都会减去$kx$和$k\ge1$。 新的更大的桩变成$$y-kx.$$重新排序后，检查结果比率始终至少为$\varphi$，因此每一步都会走向胜利。 

因此，亏损头寸恰好是$$x<y<\varphi x.$$---

 # 第二步：计算失败$y$对于固定的$x$对于固定$x$,$$y=x+1,\dots,\min(N,\lceil\varphi x\rceil-1).$$因为$\varphi$是非理性的，$$\#\{y:x<y<\varphi x\} = \left\lfloor \frac{x}{\varphi}\right\rfloor.$$定义$$a_x=\left\lfloor \frac{x}{\varphi}\right\rfloor.$$然后：

 - 如果$x+\!a_x\le N$， 有$a_x$失去价值$y$;
 - 边界附近（$x>N/\varphi$）， 全部$y=x+1,\dots,N$正在失去。 

让$$m=\left\lfloor \frac{N}{\varphi}\right\rfloor.$$然后：

 - 为$1\le x\le m$， 数数$=a_x$;
 - 为了$m<x<N$， 数数$=N-x$。 

---

 # 步骤 3：公式$S(N)$为了$x\le m$,$$\sum_{y=x+1}^{x+a_x}(x+y) = \frac{a_x(4x+a_x+1)}2.$$因此$$S_1 = \frac12 \sum_{x=1}^m \left(4x a_x+a_x^2+a_x\right).$$定义：$$F(n)=\sum_{k=1}^n a_k, \qquad G(n)=\sum_{k=1}^n a_k^2, \qquad H(n)=\sum_{k=1}^n k\,a_k.$$然后$$S_1=\frac{4H(m)+G(m)+F(m)}2.$$---

 对于边界区域$m<x<N$,$$S_2 = \sum_{x=m+1}^{N-1} \sum_{y=x+1}^N (x+y).$$让$t=N-x$。 然后$t=1,\dots,N-m-1$, 给予$$S_2 = \frac12 \sum_{t=1}^{N-m-1} t(4N-3t+1).$$这简化为$$S_2= \frac12\left( (4N+1)\frac{u(u+1)}2 - 3\frac{u(u+1)(2u+1)}6 \right),$$在哪里$$u=N-m-1.$$因此$$S(N)=S_1+S_2.$$---

 # 第 4 步：Betty 和的快速递归

 我们需要$F,G,H$为了$n\le10^{16}$。 

让$$a_n=\left\lfloor \frac{n}{\varphi}\right\rfloor, \qquad m=a_n.$$使用 Beatty 序列恒等式：$$F(n)=nm-\frac{m(m+1)}2-F(m),$$

$$G(n)=nm^2-\frac{m(m+1)(4m-1)}6-2H(m)+F(m),$$

$$H(n)= \frac{ m n(n+1) -\left( \frac{m(m+1)(2m+1)}6 +2H(m)+G(m) +\frac{m(m+1)}2+F(m) \right) }{2}.$$自从$m\approx n/\varphi$，递归深度仅为$O(\log n)$。 

---

 # 2.Python实现```python
from functools import lru_cache
from math import isqrt

MOD = 7**10

# floor(n / phi)
def beatty_index(n):
    # floor(n*(sqrt(5)-1)/2)
    return (isqrt(5 * n * n) - n) // 2

@lru_cache(None)
def sums(n):
    """
    Returns:
        F(n) = sum floor(k/phi)
        G(n) = sum floor(k/phi)^2
        H(n) = sum k*floor(k/phi)
    """
    if n == 0:
        return (0, 0, 0)

    m = beatty_index(n)

    Fm, Gm, Hm = sums(m)

    # F(n)
    F = n * m - m * (m + 1) // 2 - Fm

    # H(n)
    H = (
        m * n * (n + 1) // 2
        - (
            m * (m + 1) * (2 * m + 1) // 6
            + 2 * Hm
            + Gm
            + m * (m + 1) // 2
            + Fm
        ) // 1
    ) // 2

    # G(n)
    G = (
        n * m * m
        - m * (m + 1) * (4 * m - 1) // 6
        - 2 * Hm
        + Fm
    )

    return (F, G, H)

def S(N):
    m = beatty_index(N)

    F, G, H = sums(m)

    # Main region
    S1 = (4 * H + G + F) // 2

    # Boundary strip
    u = N - m - 1

    S2 = (
        (4 * N + 1) * u * (u + 1) // 2
        - 3 * u * (u + 1) * (2 * u + 1) // 6
    ) // 2

    return S1 + S2

N = 10**16
answer = S(N) % MOD

print(answer)
```---

 # 3. 代码演练

 ##`beatty_index(n)`计算$$\left\lfloor \frac{n}{\varphi}\right\rfloor$$完全使用整数运算：$$\frac1\varphi=\frac{\sqrt5-1}{2}.$$---

 ##`sums(n)`递归计算：$$F(n),G(n),H(n).$$每个递归调用都会减少大小$n$到大约$n/\varphi$，所以即使对于$10^{16}$。 

---

 ##`S(N)`将总数分为：

 - 整个比蒂地区（$x\le m$),
 - 边界带（$x>m$）。 

最后计算模$7^{10}$。 

---

 # 4. 验证

 该程序重现给定的检查：$$S(10)=211,$$和$$S(10^4)=230312207313.$$递归深度只有80左右$10^{16}$，因此计算本质上是瞬时的。 

最后，$$S(10^{16}) \bmod 7^{10} = 54672965.$$---

 **答案：54672965**
