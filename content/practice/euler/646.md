[项目欧拉问题 646](https://projecteuler.net/problem=646)

 ## 解决方案

 **答案：**`845218467`让$$n=\prod_{i=1}^k p_i^{\alpha_i}, \qquad \lambda(n)=(-1)^{\sum \alpha_i}.$$我们想要$$S(n,L,H)=\sum_{\substack{d\mid n\\L\le d\le H}}\lambda(d)\,d.$$对于这个问题：$$S(70!,10^{20},10^{60}) \pmod{1\,000\,000\,007}.$$## 1.数学分析

 如果$$d=\prod_i p_i^{\beta_i}, \qquad 0\le \beta_i\le \alpha_i,$$然后$$\lambda(d) = (-1)^{\sum_i \beta_i}.$$所以$$\lambda(d)d = \prod_i (-p_i)^{\beta_i}.$$因此，每个除数都会贡献一个乘法符号权重。 

挑战在于$70!$有大量的约数：$$\tau(70!) = \prod_i (\alpha_i+1) = 3\,543\,845\,437\,440,$$所以暴力是不可能的。 

### 中间相遇

 拆分素数$70!$分为两组$A,B$。 

对于群中的每个部分除数$A$，计算：

 - 它的价值$a$,
 - 其签署的贡献$t_A=\lambda(a)a$。 

对于团体也同样如此$B$:

 - 除数$b$,
 - 签署贡献$t_B=\lambda(b)b$。 

那么每个除数$70!$是独一无二的：$$d=a\cdot b,$$并做出贡献$$\lambda(d)d = t_A t_B.$$对于固定的$a$， 有效的$b$满足$$\frac{L}{a}\le b\le \frac{H}{a}.$$如果全部$b$-值已排序，我们可以对区间进行二分搜索并使用前缀和$t_B$要得到：$$\sum_{\frac{L}{a}\le b\le \frac{H}{a}} t_B$$在$O(\log N)$。 

因此总复杂度大致变为：$$O(N\log N),$$其中每一半只有大约$1.88\times 10^6$状态——完全可行。 

## 2.Python实现```python
from math import factorial
from bisect import bisect_left, bisect_right
from sympy import factorint

MOD = 1_000_000_007

def generate_divisors(items):
    """
    Generate all partial divisors and their signed values.

    Returns list of tuples:
        (d, lambda(d) * d)
    """
    arr = [(1, 1)]

    for p, a in items:
        powers = []

        value = 1
        sign = 1

        for _ in range(a + 1):
            powers.append((value, sign * value))
            value *= p
            sign *= -1

        new_arr = []

        for d, t in arr:
            for v, tv in powers:
                new_arr.append((d * v, t * tv))

        arr = new_arr

    return arr

def S(n, L, H):
    # Prime factorization of n!
    fac = factorint(factorial(n))
    items = list(fac.items())

    # Find balanced split minimizing max(side size)
    divisor_counts = [a + 1 for _, a in items]

    total_divisors = 1
    for c in divisor_counts:
        total_divisors *= c

    best_mask = None
    best_size = float("inf")

    m = len(items)

    for mask in range(1 << m):
        left_size = 1

        for i in range(m):
            if (mask >> i) & 1:
                left_size *= divisor_counts[i]

        right_size = total_divisors // left_size
        worst = max(left_size, right_size)

        if worst < best_size:
            best_size = worst
            best_mask = mask

    A = [items[i] for i in range(m)
         if (best_mask >> i) & 1]

    B = [items[i] for i in range(m)
         if not ((best_mask >> i) & 1)]

    # Generate both halves
    left = generate_divisors(A)
    right = generate_divisors(B)

    # Sort right side by divisor value
    right.sort(key=lambda x: x[0])

    right_divs = [d for d, _ in right]

    # Prefix sums of signed contributions
    prefix = [0]
    running = 0

    for _, t in right:
        running += t
        prefix.append(running)

    total = 0

    for a, ta in left:
        lo = (L + a - 1) // a
        hi = H // a

        i = bisect_left(right_divs, lo)
        j = bisect_right(right_divs, hi)

        total += ta * (prefix[j] - prefix[i])

    return total

# Verification against examples
print(S(10, 100, 1000))           # 1457
print(S(15, 10**3, 10**5))        # -107974
print(S(30, 10**8, 10**12))       # 9766732243224

# Final computation
ans = S(70, 10**20, 10**60)
print(ans % MOD)
```## 3. 代码演练

 -`factorint(factorial(n))`计算素数指数$n!$。 
-`generate_divisors()`递归枚举所有部分除数并存储：$$(d,\lambda(d)d).$$- 我们将素数分成两个平衡组，这样每一方都有大约$1.88$万个州。 
- 右半部分按除数大小排序。 
- 前缀和允许在二分搜索后在恒定时间内进行间隔求和。 
- 对于每个左除数$a$，我们发现所有兼容的$b$满意：$$L \le ab \le H.$$- 将所有签署的捐款相加。

## 4.最终验证

 所有除数的无限制总和$70!$将乘因式分解为：$$\sum_{d\mid 70!}\lambda(d)d = \prod_p (1-p+p^2-\cdots),$$预计会有如此大规模的取消。 结果取模$10^9+7$在残留范围的中间是完全合理的。
