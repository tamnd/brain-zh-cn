[项目欧拉问题 231](https://projecteuler.net/problem=231)

 ## 解决方案

 **答案：**`7526965179680`我们想要质因数（具有重数）的总和$$\binom{20\,000\,000}{15\,000\,000}.$$等价地，如果$$\binom{n}{k}=\prod_p p^{e_p},$$我们寻求$$\sum_p p\,e_p.$$对于这个小例子，$$\binom{10}{3}=120=2^3\cdot3\cdot5,$$所以所需的总和是$$2\cdot3+3\cdot1+5\cdot1=14.$$---

 # 1.数学分析

 关键思想是使用勒让德公式计算阶乘中每个素数的指数。 

对于素数$p$,$$v_p(n!)=\sum_{i\ge1}\left\lfloor \frac{n}{p^i}\right\rfloor.$$所以，$$v_p\!\left(\binom{n}{k}\right) = v_p(n!) - v_p(k!) - v_p((n-k)!).$$对于这个问题：$$n=20\,000\,000,\qquad k=15\,000\,000,\qquad n-k=5\,000\,000.$$因此$$e_p = \sum_{i\ge1} \left( \left\lfloor \frac{20\,000\,000}{p^i}\right\rfloor - \left\lfloor \frac{15\,000\,000}{p^i}\right\rfloor - \left\lfloor \frac{5\,000\,000}{p^i}\right\rfloor \right).$$想要的答案是$$\sum_{p\le 20\,000\,000} p\,e_p.$$所以算法是：

 1. 生成直到$20\,000\,000$使用筛子。 
2. 对于每个素数$p$:

 - 计算$e_p$用勒让德公式。 
- 添加$p\cdot e_p$至总数。 

这是有效的，因为：

 - 只有大约$1.27$百万素数最多$20$万，
 - 每个素数仅贡献$O(\log_p n)$条款。

 # 2.Python实现```python
from math import isqrt

N = 20_000_000
K = 15_000_000

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------
# Generate all primes <= N
sieve = bytearray(b"\x01") * (N + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(N) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:N + 1:step] = b"\x00" * (((N - start) // step) + 1)

primes = [i for i in range(2, N + 1) if sieve[i]]

# ---------------------------------------------------------
# Legendre exponent for p in n!
# ---------------------------------------------------------
def vp_factorial(n, p):
    total = 0
    while n:
        n //= p
        total += n
    return total

# ---------------------------------------------------------
# Compute the required sum
# ---------------------------------------------------------
answer = 0

for p in primes:
    exponent = (
        vp_factorial(N, p)
        - vp_factorial(K, p)
        - vp_factorial(N - K, p)
    )

    answer += p * exponent

print(answer)
```---

```用途$$v_p\!\left(\binom{N}{K}\right) = v_p(N!) -v_p(K!) -v_p((N-K)!).$$然后：```python

 - 3 的指数是$1$,
 - 5 的指数是$1$。
