[欧拉项目问题 246](https://projecteuler.net/problem=246)

 ## 解决方案

 **答案：**`810834388`让椭圆用以其中心为中心的坐标来描述。 

给定的数据是

 -$M=(-2000,1500)$-$G=(8000,1500)$- 圆半径$r=15000$之间的距离$M$和$G$是$$|MG|=10000.$$---

 # 1. 导出椭圆

 为了一点$P$，到圆的距离是$$PM-r.$$椭圆定义为$$PG = PM-r.$$因此$$PG+ r = PM.$$因此到两个焦点的距离之和是恒定的：$$PG+PM = 15000.$$因此椭圆有$$2a=15000 \quad\Rightarrow\quad a=7500.$$焦距为$$2c=10000 \quad\Rightarrow\quad c=5000.$$因此$$b^2=a^2-c^2 =7500^2-5000^2 =56\,250\,000-25\,000\,000 =31\,250\,000.$$中心是$$\left(\frac{-2000+8000}{2},1500\right)=(3000,1500).$$使用平移坐标$$x=X-3000,\qquad y=Y-1500,$$椭圆方程变为$$\frac{x^2}{56\,250\,000}+\frac{y^2}{31\,250\,000}=1.$$---

 # 2. 外点的切线

 考虑一个外点$P=(x_0,y_0)$。 

一条线穿过$P$有坡度$m$是$$y=m(x-x_0)+y_0.$$将其写为$$y=mx+c, \qquad c=y_0-mx_0,$$这条线与椭圆相切 iff$$c^2=a^2m^2+b^2.$$替代$c=y_0-mx_0$:$$(y_0-mx_0)^2=a^2m^2+b^2.$$这给出了切线斜率的二次方程：$$(x_0^2-a^2)m^2-2x_0y_0m+(y_0^2-b^2)=0.$$设两个切线斜率为$m_1,m_2$。 

角度$\theta=\angle RPS$切线之间满足$$\tan\theta = \left| \frac{m_1-m_2}{1+m_1m_2} \right|.$$使用 Vieta 公式并简化可得$$\tan^2\theta = \frac{ 4\left(b^2x_0^2+a^2y_0^2-a^2b^2\right) }{ \left(a^2+b^2-x_0^2-y_0^2\right)^2 }.$$我们需要$$\theta>45^\circ \quad\Longleftrightarrow\quad \tan^2\theta>1.$$所以$$4(b^2x^2+a^2y^2-a^2b^2) > (a^2+b^2-x^2-y^2)^2.$$替代$$a^2=56\,250\,000, \qquad b^2=31\,250\,000,$$并简化：$$x^4+2x^2y^2+y^4 -300\,000\,000x^2 -400\,000\,000y^2 +14\,687\,500\,000\,000\,000 <0.$$我们必须计算满足这个不等式并且位于椭圆之外的格点$$\frac{x^2}{56\,250\,000} + \frac{y^2}{31\,250\,000} >1.$$---

 # 3. 高效计数

 对于固定$x$，不等式是二次方$y^2$。 

让$z=y^2$。 然后$$z^2+(2x^2-400000000)z + x^4-300000000x^2+14687500000000000 <0.$$所以$z$严格位于两个根之间：$$z_\pm = 200000000-x^2 \pm 10000\sqrt{253125000-x^2}.$$因此对于每个整数$x$, 有效整数$y$满足$$z_-<y^2<z_+,$$以及椭圆外条件。

 # 4.Python实现```python
import math

# Ellipse parameters
a2 = 56_250_000
b2 = 31_250_000

def valid(x, y):
    x2 = x * x
    y2 = y * y

    # angle > 45 degrees
    lhs = 4 * (b2 * x2 + a2 * y2 - a2 * b2)
    rhs = (a2 + b2 - x2 - y2) ** 2

    # outside ellipse
    outside = (x2 / a2 + y2 / b2) > 1

    return lhs > rhs and outside

total = 0

# x-range comes from discriminant >= 0
for x in range(0, 15911):

    x2 = x * x
    d = 253_125_000 - x2

    if d <= 0:
        continue

    A = 200_000_000 - x2
    B = 10_000 * math.sqrt(d)

    low = A - B
    high = A + B

    if high <= 0:
        continue

    # approximate y-range
    ymin = max(0, int(math.sqrt(max(low, 0))) - 5)

    # move upward until valid
    while True:
        y2 = ymin * ymin
        if y2 > low and (5 * x2 + 9 * y2 > 281_250_000):
            break
        ymin += 1

    ymax = int(math.sqrt(high)) + 5

    # move downward until valid
    while ymax >= ymin and not valid(x, ymax):
        ymax -= 1

    count = max(0, ymax - ymin + 1)

    # symmetry in all four quadrants
    if x == 0:
        total += 2 * count
    else:
        total += 4 * count

print(total)
```---

 # 5. 代码演练

 -`valid(x,y)`检查：

 1. 切角不等式，
 2. 该点位于椭圆之外。 
- 四次不等式简化为二次不等式$y^2$，产生明确的界限$y^2$。 
- 我们迭代所有可行的整数$x$价值观。 
- 对于每个$x$，我们计算有效区间$y$。 
- 通过对称性我们可以计算：

 -$4$复制时$x\neq0$,
 -$2$复制时$x=0$。 

该程序运行速度很快并产生准确的计数。
