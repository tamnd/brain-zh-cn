[项目欧拉问题 910](https://projecteuler.net/problem=910)

 ## 解决方案

 **答案：**`547480666`让$$C_0=Z,\qquad C_n=S(C_{n-1}).$$我们首先确定其含义$C_n$。 

使用$$S(u)(v)(w)\to v(u(v)(w)),$$我们得到：$$C_{n+1}(f)(x) = S(C_n)(f)(x) \to f(C_n(f)(x)).$$自从$C_0(f)(x)=Z(f)(x)\to x$，归纳给出$$C_n(f)(x)=f^{\,n}(x),$$这$n$-折叠迭代$f$。 

现在$$D_n=C_n(S)(S).$$应用同样的想法，$$D_n(x)(y)(z)=y^{\,n+1}(x(y)(z)).$$我们现在简化$$F(a,b,c,d,e)=D_a(D_b)(D_c)(C_d)(A)(e).$$---

 ## 步骤 1：计算$D_b(D_c)(C_d)$使用上面的公式，$$D_b(D_c)(C_d) = C_d^{\,b+1}(D_c(C_d)).$$下一个，$$D_c(C_d)(A)(x) = A^{\,c+1}(C_d(A)(x)).$$但$C_d(A)(x)=x+d$， 所以$$D_c(C_d)(A)(x)=x+d+c+1.$$因此$D_c(C_d)$充当“添加$d+c+1$”。

 正在申请$C_d$一旦迭代这个加法$d$次，将增量乘以$d$。 重复$b+1$次乘以$d^{b+1}$。 所以$$D_b(D_c)(C_d)(A)(x) = x+(d+c+1)d^{\,b+1}.$$---

 ## 第 2 步：申请$D_a(\cdot)(D_c)$再次，$$D_a(f)(D_c)(A)(x) = A^{\,a+1}(f(A)(x)).$$所以这只是添加$a+1$的副本$c+1$， IE。$$(a+1)(c+1).$$因此$$F(a,b,c,d,e) = e+(d+c+1)d^{\,b+1}+(a+1)(c+1).$$代替：$$a=12,\quad b=345678,\quad c=9012345,\quad d=678,\quad e=90.$$我们需要：$$90+9013024\cdot 678^{345679}+13\cdot 9012346 \pmod{10^9}.$$Python计算：```python
MOD = 10**9

a, b, c, d, e = 12, 345678, 9012345, 678, 90

ans = (
    e
    + (d + c + 1) * pow(d, b + 1, MOD)
    + (a + 1) * (c + 1)
) % MOD

print(ans)
```这打印：```python
597715596
```该值已经是最后九位数字。 

**答案：597715596**
