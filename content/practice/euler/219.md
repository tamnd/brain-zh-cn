[欧拉项目问题 219](https://projecteuler.net/problem=219)

 ## 解决方案

 **答案：**`64564225042`让每个码字对应于二叉树中的一个叶子：

 - 采取`0`边缘成本`1`- 采取`1`边缘成本`4`因此，码字的成本是从根开始的加权路径长度。 

无前缀代码正是这样一棵树中的一组叶子。 

我们寻求最小可能的总叶子成本$n$树叶。 

---

 # 1.数学分析

 假设我们目前有一个成本叶子$x$。 

如果我们将其扩展为两个孩子，那么：

 - 留下孩子的成本=$x+1$- 右子成本 =$x+4$叶子的数量增加$1$，总成本变化为$$(x+1)+(x+4)-x = x+5.$$因此：

 > 为了尽可能便宜地增加叶子的数量，我们应该始终扩展当前最便宜的叶子。 

这种贪婪策略是最优的，因为每次扩展都恰好添加一个新叶子，并且增量$x+5$通过选择最小的可用值来最小化$x$。 

---

 ## 扩展过程

 从一个空的成本代码字开始$0$。 

扩大成本$c$:$$c \to (c+1,\ c+4)$$让$t_c$是成本的叶子的次数$c$被扩展。 

成本节点$c$只能产生于：

 - 成本 -$(c-1)$节点通过`0`边缘
 - 成本 -$(c-4)$节点通过`1`边缘

 因此：$$t_c = t_{c-1} + t_{c-4},$$和$$t_0=1,\qquad t_c=0 \text{ for } c<0.$$序列开始：$$1,1,1,1,2,3,4,5,7,10,14,19,\dots$$---

 ## 将其与叶子的数量联系起来

 每次扩展都会增加叶子的数量$1$。 

充分处理好所有费用后$<k$，叶子的数量是$$1+\sum_{i=0}^{k-1} t_i.$$累计总成本为$$\sum_{i=0}^{k-1} t_i(i+5),$$因为每次扩张都要付出代价$i$总成本增加$i+5$。 

如果我们还需要$r$按成本进行额外扩展$k$， 然后$$\text{Cost}(n) = \sum_{i=0}^{k-1} t_i(i+5) + r(k+5),$$在哪里$$r = n-\left(1+\sum_{i=0}^{k-1} t_i\right).$$---

 # 2.Python实现```python
def cost(n):
    # t[c] = number of leaves of cost c that get expanded
    t = [1]   # t_0 = 1

    leaves = 1   # current number of leaves
    total = 0
    c = 0

    while True:
        # extend recurrence if needed
        if c >= len(t):
            val = t[c - 1]
            if c >= 4:
                val += t[c - 4]
            t.append(val)

        # If processing all nodes of cost c would reach/exceed n,
        # finish partially here.
        if leaves + t[c] >= n:
            remaining = n - leaves
            return total + remaining * (c + 5)

        # fully process all nodes of cost c
        leaves += t[c]
        total += t[c] * (c + 5)

        c += 1

print(cost(6))        # 35
print(cost(10**9))    # final answer
```---
