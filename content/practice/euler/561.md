[项目欧拉问题 561](https://projecteuler.net/problem=561)

 ## 解决方案

 **答案：**`452480999988235494`让$$n=\prod_{j=1}^m p_j^{\,r_j}.$$的每个除数$n$对应于一个向量$$(e_1,\dots,e_m), \qquad 0\le e_j\le r_j.$$对于两个除数$a,b$，条件$a\mid b$相当于$$e_j(a)\le e_j(b)\quad \text{for all }j.$$我们被问及$$S(n)=\#\{(a,b): a\ne b,\ a\mid b,\ a,b\mid n\}.$$对于欧拉 561 项目，$$n=(p_m)^k=\prod_{j=1}^m p_j^k,$$所以所有指数都等于$k$。 

---

 # 第 1 步：封闭公式$S((p_m)^k)$对于一个素数坐标，对的数量$(x,y)$和$$0\le x\le y\le k$$是$$\frac{(k+1)(k+2)}2.$$由于坐标是独立的，因此除数对的总数$a\mid b$是$$\left(\frac{(k+1)(k+2)}2\right)^m.$$这包括$a=b$案例，其中有$(k+1)^m$。 因此$$\boxed{ S((p_m)^k)= \left(\frac{(k+1)(k+2)}2\right)^m-(k+1)^m }$$或同等地$$\boxed{ S((p_m)^k) =(k+1)^m\left(\left(\frac{k+2}{2}\right)^m-1\right). }$$内联公式可视化：$S\left((p_m)^k\right)=\left(\frac{(k+1)(k+2)}{2}\right)^m-(k+1)^m$我们需要$$E(m,k)=v_2\!\left(S((p_m)^k)\right),$$在哪里$v_2(x)$是 2 除法的指数$x$。 

这里$$m=904961,$$这很奇怪。 

---

 # 第 2 步：确定$E(m,k)$我们分为平价情况。 

## 案例A：$k=2r+1$（奇数）

 然后$$k+1=2(r+1),$$所以$$S=(r+1)^m\bigl((2r+3)^m-2^m\bigr).$$自从$(2r+3)^m$是奇数并且$2^m$是偶数，$$(2r+3)^m-2^m$$很奇怪。 

所以$$E(m,k)=m\,v_2(r+1).$$因为$$r+1=\frac{k+1}{2},$$我们得到$$\boxed{ E(m,k)=m\left(v_2(k+1)-1\right) \qquad (k\text{ odd}). }$$---

 ## 情况 B：$k=2r$（偶数）

 然后$$S=(2r+1)^m\bigl((r+1)^m-1\bigr).$$第一个因数是奇数，所以$$E(m,k)=v_2((r+1)^m-1).$$自从$m$是奇数：

 - 如果$r$是奇数，那么$r+1$是偶数，所以$(r+1)^m-1$是奇数：$$E=0.$$- 如果$r$是偶数，那么$r+1$是奇数，LTE 给出$$v_2((r+1)^m-1)=v_2(r)+v_2(m)=v_2(r),$$因为$m$很奇怪。 

因此：$$\boxed{ E(m,k)= \begin{cases} v_2(k)-1, & 4\mid k,\\[4pt] 0, & k\equiv2\pmod4. \end{cases} }$$---

 # 第三步：求和$Q(n)$我们需要$$Q(N)=\sum_{k=1}^N E(904961,k), \qquad N=10^{12}.$$分开奇数和偶数贡献。 

- -

＃＃ 奇怪的$k$写$$k=2j-1.$$然后$$v_2(k+1)-1=v_2(2j)-1=v_2(j).$$所以奇怪的贡献是$$904961\sum_{j\le N/2} v_2(j).$$- -

＃＃ 甚至$k$只有 4 的倍数有贡献。 写$$k=4j.$$然后$$v_2(k)-1=v_2(4j)-1=v_2(j)+1.$$因此均匀贡献是$$\sum_{j\le N/4}(v_2(j)+1).$$所以$$\boxed{ Q(N)=904961\,A(N/2)+A(N/4)+N/4 }$$在哪里$$A(n)=\sum_{j\le n} v_2(j).$$但$$A(n)=v_2(n!)=n-s_2(n),$$和$s_2(n)$二进制数字和。 

所以$$Q(N)=904961\,(N/2-s_2(N/2)) +(N/4-s_2(N/4)) +N/4.$$---

 # 第 4 步：评估$N=10^{12}$我们需要：$$N/2=500000000000, \qquad N/4=250000000000.$$二进制数字和：$$s_2(500000000000)=13, \qquad s_2(250000000000)=13.$$因此$$A(500000000000)=499999999987,$$

$$A(250000000000)=249999999987.$$现在计算：$$Q(10^{12}) = 904961\cdot 499999999987 +249999999987 +250000000000.$$这等于$$\boxed{452480999988235494}.$$---

 # Python 实现```python
def v2_sum(n):
    # Sum_{k<=n} v2(k) = n - popcount(n)
    return n - bin(n).count("1")

def Q(N):
    m = 904961
    return (
        m * v2_sum(N // 2)
        + v2_sum(N // 4)
        + N // 4
    )

print(Q(8))          # 2714886
print(Q(10**12))     # 452480999988235494
```---

 # 代码演练`v2_sum(n)`使用古典身份$$\sum_{k=1}^n v_2(k)=v_2(n!)=n-s_2(n).$$然后函数`Q(N)`直接计算导出的封闭公式：$$Q(N)=904961\,A(N/2)+A(N/4)+N/4.$$样品检查：```python
Q(8)
```回报$$2714886,$$匹配问题陈述。
