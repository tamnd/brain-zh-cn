[欧拉项目问题 298](https://projecteuler.net/problem=298)

 ## 解决方案

 **答案：**`1.76882294`让

-$L$= 拉里的分数，
 -$R$= 罗宾的得分。 

我们必须计算$$\mathbb E(|L-R|)$$50回合后。 

关键是游戏是**有限状态**。 

---

 # 1.数学分析

 每一次：

 - 一个随机数$1,\dots,10$是统一绘制的，
 - 每个玩家可以：

 - 如果该数字已被记住，则得分，或者
 - 插入号码并可能逐出一个旧号码。 

继续该过程所需的唯一信息是：

 1.拉里的记忆状态，
 2.罗宾的记忆状态，
 3.当前分数差$d=L-R$,
 4.轮数。 

---

 ## Larry 的策略 (LRU)

 Larry 删除了最近最少使用的号码。 

所以 Larry 的记忆可以用一个有序元组来表示$$(a_1,a_2,\dots,a_k)$$从最近到最近。 

如果数字已经存在，则将其移动到末尾。 

---

 ## Robin 的策略（先进先出）

 罗宾删除了记忆中最长的数字。 

所以罗宾的记忆只是一个从最旧到最新排序的队列。 

点击不会改变顺序。 

---

 # 状态压缩

 实际标签$1,\dots,10$是无关紧要的。 

只有平等结构才重要。 

例如，包含数字的状态$$(3,7,9)$$和$$(1,4,6)$$是等价的。 

因此，在每次转换之后，我们都会按照规范重新标记符号：

 - 第一个出现的符号$\to 0$- 下一个新符号$\to 1$- 等

 这极大地减少了状态空间。 

---

 # 动态规划递归

 定义$$F(t,S_L,S_R,d)$$作为预期最终值$|L-R|$50 回合后，给出：

 - 转$t$,
 - 拉里州$S_L$,
 - 罗宾州$S_R$,
 - 当前分数差$d$。 

基本情况：$$F(50,\cdot,\cdot,d)=|d|.$$过渡：

 对于每个可能的下一个数字$x\in\{1,\dots,10\}$,

 - 更新拉里记忆，
 - 更新罗宾记忆，
 - 更新分数差异$$d' = d + (\text{Larry hit}) - (\text{Robin hit}),$$然后对 10 个同样可能的平局进行平均。 

因此，$$F=\frac1{10}\sum_x F(\text{next state}).$$记忆化准确地计算所有可到达的状态。 

---

 # 2.Python实现```python
from functools import cache

N = 50          # number of turns
NUMS = 10       # numbers 1..10
CAP = 5         # memory size

def canonicalize(lru, fifo):
    """
    Renumber symbols canonically so equivalent states merge.
    """
    mp = {}
    nxt = 0

    def conv(seq):
        nonlocal nxt
        out = []
        for x in seq:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])
        return tuple(out)

    return conv(lru), conv(fifo)

@cache
def dp(turn, lru, fifo, diff):
    """
    Expected final |L-R| from this state.
    """

    # after 50 turns
    if turn == N:
        return abs(diff)

    lru = list(lru)
    fifo = list(fifo)

    # currently used canonical symbols
    used = max([-1] + lru + fifo) + 1

    total = 0.0

    # existing symbols each represent one actual number
    choices = [(i, 1) for i in range(used)]

    # all unseen numbers are equivalent
    unseen = NUMS - used
    if unseen > 0:
        choices.append(("new", unseen))

    for x, weight in choices:

        value = used if x == "new" else x

        # ----- Larry (LRU) -----
        nlru = lru.copy()

        if value in nlru:
            l_hit = 1
            nlru.remove(value)
            nlru.append(value)
        else:
            l_hit = 0
            if len(nlru) == CAP:
                nlru.pop(0)
            nlru.append(value)

        # ----- Robin (FIFO) -----
        nfifo = fifo.copy()

        if value in nfifo:
            r_hit = 1
        else:
            r_hit = 0
            if len(nfifo) == CAP:
                nfifo.pop(0)
            nfifo.append(value)

        ndiff = diff + l_hit - r_hit

        clru, cfifo = canonicalize(tuple(nlru), tuple(nfifo))

        total += weight * dp(turn + 1, clru, cfifo, ndiff)

    return total / NUMS

answer = dp(0, (), (), 0)

print(f"{answer:.8f}")
```---

 # 3. 代码演练

 ## 规范化```python
canonicalize(lru, fifo)
```一致地对符号重新编号：

 - 第一个看到的符号变为 0，
 - 接下来变成1，
 - 等

 这合并了等效状态并使 DP 可行。 

---

 ## DP 状态```python
dp(turn, lru, fifo, diff)
```存储预期的未来值。 

参数：

-`turn`= 当前回合，
 -`lru`=拉里记忆顺序，
 -`fifo`= 罗宾记忆顺序，
 -`diff = L - R`。 

---

 ## 现有数字与未见过的数字

 假设当前仅出现 4 个不同的标签。 

然后：

 - 每个现有标签恰好对应一个实数，
 - 所有看不见的数字都表现相同。 

因此，我们不是单独对所有 10 个数字进行分支，而是将未见过的数字聚合到一个具有多重性的转换中。 

这大大减少了计算量。 

---

 ## 更新拉里

 命中时：```python
nlru.remove(value)
nlru.append(value)
```因为该号码已成为最近使用过的号码。 

错过了：

 - 如果已满则驱逐最近最少使用的，
 - 附加新号码。 

---

 ## 更新罗宾

 先进先出行为：

 - 命中没有任何作用，
 - 错过附加，
 - 如果已满，则驱逐最旧的。

 # 4. 验证

 期望必须满足：$$0 \le \mathbb E(|L-R|) \le 50.$$由于两种策略非常相似，因此预期差异应该很小。 

计算值：$$1.76882294$$是完全合理的。 

该 DP 的独立实现会产生相同的结果。
