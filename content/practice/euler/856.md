[项目欧拉问题 856](https://projecteuler.net/problem=856)

 ## 解决方案

 **答案：**`17.09661501`让$T$是直到第一次两张连续的牌具有相同点数或直到牌组用完为止所抽取的牌数。 

我们想要$$\mathbb E[T].$$---

 # 1. 关键概率思想

 非负整数值随机变量的标准恒等式是$$\mathbb E[T] = \sum_{n\ge0}\Pr(T>n).$$这里，$T>n$意思是：

 > 在第一个之后$n$抽牌时，没有连续的牌具有相同的等级。 

由于这副牌只有 52 张牌，$$\mathbb E[T] = \sum_{n=0}^{51} q_n,$$在哪里$$q_n=\Pr(\text{no adjacent equal ranks among first }n\text{ cards}).$$清楚地，$$q_0=q_1=1.$$所以整个问题归结为计算概率$q_n$。 

---

 # 2.状态压缩

 对所有套牌命令进行直接暴力破解是不可能的。 

相反，我们观察到：

 任何时候，未来只取决于

 - 目前有多少等级已使用 0、1、2、3、4 卡，
 - 以及有多少张_最后抽取的等级_的牌已经被使用。 

定义状态$$(c_0,c_1,c_2,c_3,c_4;\ell),$$在哪里

-$c_i$= 确切的排名数$i$牌已抽出，
 -$\ell\in\{1,2,3,4\}$= 最后抽出的牌数已被使用。 

最初，在抽完一张牌后：$$(12,1,0,0,0;1).$$---

 # 3. 转换规则

 假设我们处于状态$$(c_0,c_1,c_2,c_3,c_4;\ell)$$后$n$画画。 

有$52-n$剩余卡数。 

为了避免形成一对，下一张牌不能与前一张牌具有相同的等级。 

如果我们选择当前使用的等级$j$次数：

 - 有$4-j$剩余该等级的牌，
 - 还有$$c_j - \mathbf 1_{\{\ell=j\}}$$该类型的可用排名（不包括之前的排名本身）。 

因此转移概率为$$\frac{ \left(c_j-\mathbf 1_{\{\ell=j\}}\right)(4-j) }{ 52-n }.$$选择这样的排名后：

 - 从班级中调出一个等级$j$去上课$j+1$,
 - 新的最后排名计数变为$j+1$。 

这给出了一个很小的 ​​DP 状态空间并计算所有$q_n$确切地。 

---

 # 4.Python实现```python
from collections import defaultdict

# dist[state] = probability of being in that state
# after n draws with no adjacent equal ranks
#
# state = (c0, c1, c2, c3, c4, lastk)

dist = {
    (12, 1, 0, 0, 0, 1): 1.0
}

# q[n] = probability that first n draws contain no adjacent equal ranks
q = [1.0, 1.0]

# We already handled n = 1.
# Build q[2] ... q[51].
for draws in range(1, 51):

    next_dist = defaultdict(float)
    survive_prob = 0.0

    remaining = 52 - draws

    for state, prob in dist.items():

        c = list(state[:5])
        lastk = state[5]

        # Choose a new rank type j = 0,1,2,3
        for j in range(4):

            # Number of usable ranks with j used cards,
            # excluding the previous rank if necessary
            usable_ranks = c[j] - (1 if lastk == j else 0)

            if usable_ranks <= 0:
                continue

            ways = usable_ranks * (4 - j)

            p = prob * ways / remaining

            # Update occupancy counts
            nc = c.copy()
            nc[j] -= 1
            nc[j + 1] += 1

            new_state = tuple(nc + [j + 1])

            next_dist[new_state] += p
            survive_prob += p

    dist = next_dist
    q.append(survive_prob)

# Expected value
E = sum(q)

print("{:.12f}".format(E))
```---

 # 5. 代码演练

 ### 初始化```python

```第一张卡之后：

 - 12个等级有0张已用卡，
 - 1 等级有 1 张已用卡，
 - 最后排名目前有 1 张已用卡。 

---

 ### 主循环```python
for draws in range(1, 51):
```在步骤`draws`，经过多次抽奖后我们已经知道所有安全状态。 

我们在再进行一次安全抽签后计算分布。 

---

 ### 计算安全选择```python
usable_ranks = c[j] - (1 if lastk == j else 0)
```如果之前的排名也在班级$j$，我们必须排除它。 

每个可用等级都有贡献$4-j$剩余的卡。 

---

 ### 状态更新```python
nc[j] -= 1
nc[j + 1] += 1
```排名与$j$使用过的卡牌将成为一个等级$j+1$用过的卡。 

---

 ### 期望值```python
E = sum(q)
```使用$$\mathbb E[T] = \sum_{n=0}^{51} q_n.$$---

 # 6. 健全性检查

 - 前两张牌形成一对的概率是$$\frac{3}{51}=\frac1{17},$$与声明相符。 

- 如果抽签与概率无关$1/13$匹配先前的排名，期望大致为$13$。 

由于抽牌时_无需更换_，因此早期重复的可能性较小，因此真正的期望应该稍大一些。 

获得值：$$17.09661501\ldots$$这是完全合理的。

 **答案：17.09661501**
