[项目欧拉问题 77](https://projecteuler.net/problem=77)

 ## 解决方案

 **答案：**`71`我们被要求提供第一个可以以**超过 5000 种不同方式**写成素数之和的整数。 

这是一个经典的**整数划分**问题，只不过允许的部分只是素数。 

---

 # 数学分析

 让$f(n)$表示写法的数量$n$作为素数之和，其中顺序**不**重要。 

例如，对于$10$：$$\begin{aligned} 10 &= 7+3\\ &=5+5\\ &=5+3+2\\ &=3+3+2+2\\ &=2+2+2+2+2 \end{aligned}$$所以$f(10)=5$。 

---

 ## 关键见解：硬币找零动态规划

 这个问题在结构上与经典的“硬币找零”问题相同。 

假设可用的素数是$$2,3,5,7,11,\dots$$我们想要产生的无序总和的数量$n$。 

定义：$$dp[k]$$作为形成总数的方式数量$k$。 

最初：$$dp[0]=1$$因为只有一种方法可以使零：什么都不选择。 

那么对于每个素数$p$， 更新：$$dp[k] \mathrel{+}= dp[k-p]$$为所有人$k\ge p$。 

为什么这有效？ 

- 处理底料时$p$,
 - 各种制作方法$k-p$- 成为一种方式$k$添加一个$p$。 

由于素数是按升序处理的，因此无论排列如何，每个组合都只计算一次。 

---

 ## 生成素数

 我们只需要相对较小的数字，因此简单的素性测试就足够了。 

一个数字$n$如果没有整数则为素数$d \le \sqrt n$划分它。 

---

 ## 策略

 我们递增$n$从较小的值向上：

 1. 生成所有素数$\le n$2. 计算素数分区的数量$n$3. 计数超过后停止$5000$---

 # Python 实现```python
from math import isqrt

# Check whether a number is prime
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, isqrt(n) + 1):
        if n % d == 0:
            return False
    return True

# Generate all primes up to limit
def primes_up_to(limit):
    return [x for x in range(2, limit + 1) if is_prime(x)]

target = 5000
n = 2

while True:
    primes = primes_up_to(n)

    # dp[k] = number of ways to write k as a sum of primes
    dp = [0] * (n + 1)
    dp[0] = 1

    # Coin-change style dynamic programming
    for p in primes:
        for k in range(p, n + 1):
            dp[k] += dp[k - p]

    # Check whether we've exceeded the target
    if dp[n] > target:
        print(n)
        break

    n += 1
```---
