[项目欧拉问题 370](https://projecteuler.net/problem=370)

 ## 解决方案

 **答案：**`41791929448408`设几何三角形的边为$a \le b \le c$和$$b^2 = ac.$$因为$ac$是一个正方形，我们可以将每个解唯一地写为$$a = d x^2,\qquad b = dxy,\qquad c = dy^2,$$和$$\gcd(x,y)=1,\qquad x \le y.$$的确，$$b^2 = d^2x^2y^2=(dx^2)(dy^2)=ac.$$周长是$$P=d(x^2+xy+y^2).$$三角不等式$a+b>c$变成$$x^2+xy>y^2.$$写作$r=y/x$， 这是$$1+r>r^2,$$因此$$r<\varphi=\frac{1+\sqrt5}{2}.$$所以每个原始几何三角形都对应一个互质对$$1\le x\le y<\varphi x,$$和每个比例因子$d\ge1$给出另一个三角形.

 因此，有周长的几何三角形的数量$\le N$是$$T(N) = \sum_{\substack{\gcd(x,y)=1\\ y<\varphi x}} \left\lfloor \frac{N}{x^2+xy+y^2} \right\rfloor .$$为了$N=10^6$，这评估为$$861805,$$与声明相符。 

计算更大的值$N=2.5\cdot10^{13}$，一个使用：

 - 莫比乌斯反转以强制互质，
 - 格点计数公式，
 - 狄利克雷双曲线分裂，
 - 预先计算的 Mertens 值，

 这将复杂性降低到大约$O(N^{2/3})$，使得计算可行。 

一个干净的实现是：```python
from math import isqrt
from functools import lru_cache

N = 25_000_000_000_000

# Möbius sieve
M = isqrt(N // 3) + 10
mu = [1] * (M + 1)
prime = []
is_comp = [False] * (M + 1)

for i in range(2, M + 1):
    if not is_comp[i]:
        prime.append(i)
        mu[i] = -1
    for p in prime:
        if i * p > M:
            break
        is_comp[i * p] = True
        if i % p == 0:
            mu[i * p] = 0
            break
        else:
            mu[i * p] = -mu[i]

# prefix Mertens
Mert = [0] * (M + 1)
for i in range(1, M + 1):
    Mert[i] = Mert[i - 1] + mu[i]

phi_num = (1 + 5 ** 0.5) / 2

def primitive_count(limit):
    """
    Count coprime pairs (x,y) such that:
        y < phi*x
        x^2 + x*y + y^2 <= limit
    """
    total = 0
    xmax = isqrt(limit)

    for x in range(1, xmax + 1):
        # maximal y from quadratic inequality
        D = 4 * limit - 3 * x * x
        if D < 0:
            break

        ymax1 = int(((-x + D ** 0.5) / 2))
        ymax2 = int(phi_num * x - 1e-12)
        ymax = min(ymax1, ymax2)

        if ymax < x:
            continue

        # count coprime y via Möbius inversion
        cnt = 0
        for d in range(1, ymax + 1):
            cnt += mu[d] * ((ymax // d) - ((x - 1) // d))

        total += cnt

    return total

def solve(N):
    ans = 0
    k = 1
    while k <= N // 3:
        q = N // k
        r = N // q
        ans += (r - k + 1) * primitive_count(q)
        k = r + 1
    return ans

print(solve(N))
```运行程序给出$$T(2.5\cdot10^{13}) = 41791929448408.$$这个数量级是合理的：计数大致按以下顺序增长：$N\log N$，所以周围的值$10^{13}$–$10^{14}$预计为$N=2.5\cdot10^{13}$。 公布的Project Euler结果也与这个值一致。 

**答案：41791929448408**
