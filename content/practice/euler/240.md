[欧拉项目问题 240](https://projecteuler.net/problem=240)

 ## 解决方案

 **答案：**`7448717393364181966`让$20$骰子滚动以非递增顺序重新排序：$$x_1 \ge x_2 \ge \cdots \ge x_{20},$$其中每个$x_i \in \{1,\dots,12\}$。 

问题中的条件是$$x_1+x_2+\cdots+x_{10}=70.$$关键的观察是骰子的顺序仅在最后才重要。 

通过每个面值的**重数**来计数要容易得多。 

---

 # 1.数学分析

 假设：$$c_v = \text{number of dice showing value } v$$为了$v=1,\dots,12$。 

然后：$$c_1+c_2+\cdots+c_{12}=20.$$对于任意固定重数向量$(c_1,\dots,c_{12})$，订购的卷数为$$\frac{20!}{c_1!c_2!\cdots c_{12}!}.$$所以问题就简化为：

 > 哪些重数向量具有以下性质：十个最大的骰子之和为$70$？ 

---

 ## 确定每个值对前十名的贡献

 过程值从高到低。 

假设我们正在考虑价值$v$。 

让$$H_v = c_{v+1}+c_{v+2}+\cdots+c_{12}$$骰子数量严格大于$v$。 

那么其中$c_v$骰子等于$v$， 确切地$$t_v = \min(c_v,\; 10-H_v)$$属于前十名（前提是$H_v<10$; 否则没有人这样做）。 

因此前十和条件变为$$\sum_{v=1}^{12} v\, t_v = 70.$$所以我们简单地枚举所有满足以下条件的重数向量：

 - 骰子总数 =$20$,
 - 诱导前十总和 =$70$,

 并积累$$\frac{20!}{\prod_v c_v!}.$$---

 # 2.Python实现```python
from math import factorial

def count_ways(num_dice, sides, top_count, target_sum):
    fact = [factorial(i) for i in range(num_dice + 1)]

    answer = 0

    def search(v, remaining_dice, top_used, top_sum, counts):
        """
        v               current face value being assigned
        remaining_dice  dice still unassigned
        top_used        how many of the top dice are already determined
        top_sum         current sum of the top dice
        counts          list of multiplicities chosen so far
        """
        nonlocal answer

        # Finished assigning all face values
        if v == 0:
            if (
                remaining_dice == 0
                and top_used == top_count
                and top_sum == target_sum
            ):
                ways = fact[num_dice]
                for c in counts:
                    ways //= fact[c]
                answer += ways
            return

        # Try all possible counts for face value v
        for c in range(remaining_dice + 1):

            # How many of these c dice appear in the top group?
            take = min(c, max(0, top_count - top_used))

            new_sum = top_sum + v * take

            # Prune impossible branches
            if new_sum > target_sum:
                break

            counts.append(c)

            search(
                v - 1,
                remaining_dice - c,
                top_used + take,
                new_sum,
                counts,
            )

            counts.pop()

    search(sides, num_dice, 0, 0, [])

    return answer

# Check the small example from the statement
print(count_ways(5, 6, 3, 15))

# Solve the actual problem
print(count_ways(20, 12, 10, 70))
```---

 ## 递归搜索

 我们为值分配计数$12,11,\dots,1$。 

每个阶段：```python
for c in range(remaining_dice + 1):
```我们选择有多少骰子显示价值$v$。 

---

 ## 确定有多少属于前十名```python
take = min(c, max(0, top_count - top_used))
```如果已经存在的较大骰子少于十个，则当前值的一些-$v$骰子进入顶部组。 

---

 ## 更新前十名总和```python

```添加当前值的贡献。 

---

 ## 计数安排

 一旦找到有效的重数向量：```python
ways = fact[num_dice]
for c in counts:
    ways //= fact[c]
```计算$$\frac{20!}{\prod c_v!}.$$---
