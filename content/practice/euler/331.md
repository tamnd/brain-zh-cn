[项目欧拉问题 331](https://projecteuler.net/problem=331)

 ## 解决方案

 **答案：**`467178235146843549`让$b_{x,y}\in\{0,1\}$表示磁盘的初始状态$(x,y)$， 在哪里$1$意味着黑色和$0$意思是白色。 

如果我们翻转位置$(i,j)$，然后行中的每个磁盘$i$和列$j$被切换，与$(i,j)$整体只切换一次。 

我们在现场工作$\mathbb F_2$（异或运算）。 

---

 # 1. 线性代数公式

 让$$f_{i,j}\in\{0,1\}$$指示我们是否执行移动$(i,j)$。 

定义$$R_i=\bigoplus_k f_{i,k}, \qquad C_j=\bigoplus_k f_{k,j},$$移动矩阵的行/列异或奇偶校验。 

一个细胞$(i,j)$被翻转：

 - 一旦移动$(i,j)$,
 - 行中每移动一次$i$,
 - 列中的每一步移动一次$j$。 

因此最终的奇偶条件是$$R_i \oplus C_j \oplus f_{i,j}=b_{i,j}.$$所以$$f_{i,j}=b_{i,j}\oplus R_i\oplus C_j.$$---

 #2. 甚至$N$对于甚至$N$，对一行方程求和得出$$R_i = \bigoplus_j b_{i,j} \oplus \bigoplus_j C_j.$$让$$r_i=\bigoplus_j b_{i,j}$$是行的奇偶校验$i$。 

根据构型的对称性，$$r_i=c_i,$$消除全局平价自由后，得到唯一解$$f_{i,j}=b_{i,j}\oplus r_i\oplus r_j.$$因此，移动次数等于$1$在此矩阵中。 

---

 #3.奇数$N$对于奇数$N$，当且仅当所有行奇偶校验都相等时，系统是可解的。 

对于环形配置$C_N$，这种情况仅发生在$N=5$在出现的所有奇数值中$$2^i-i.$$因此：$$T(5)=3, \qquad T(N)=0 \text{ for all other odd } N \text{ in the sum}.$$因此，只有价值观才有贡献。 

---

 # 4. 环面的几何形状

 单元格是黑色的 iff$$(N-1)^2 \le x^2+y^2 < N^2.$$对于固定$x$，黑色单元格形成一个连续的区间$y$:$$y_{\min}(x)\le y\le y_{\max}(x),$$在哪里$$y_{\max}(x)=\left\lfloor\sqrt{N^2-1-x^2}\right\rfloor,$$

$$y_{\min}(x)= \left\lfloor\sqrt{N^2-2N-x^2}\right\rfloor+1.$$因此，行中黑色单元格的数量$x$是$$L(x)=y_{\max}(x)-y_{\min}(x)+1.$$其奇偶性为$$r_x=L(x)\bmod 2.$$因此移动矩阵是$$f_{x,y}=b_{x,y}\oplus r_x\oplus r_y.$$我们可以计算出总数$1$在$O(N)$使用前缀和的时间。 

---

 # 5.Python实现```python
import math

def T(N):
    # Odd N: only N=5 is solvable in our range
    if N & 1:
        return 3 if N == 5 else 0

    n2 = N * N

    # r[x] = parity of black cells in row x
    r = [0] * N

    y_outer = [0] * N
    y_inner = [0] * N

    total_black = 0
    A = 0  # number of rows with odd parity

    # Compute row intervals
    for x in range(N):
        x2 = x * x

        # outer boundary
        yout = math.isqrt(n2 - 1 - x2)
        y_outer[x] = yout

        # inner boundary
        if x == N - 1:
            yin = -1
        else:
            v = n2 - 2 * N - x2
            yin = math.isqrt(v) if v >= 0 else -1

        y_inner[x] = yin

        L = yout - yin

        total_black += L

        r[x] = L & 1
        A += r[x]

    # Prefix sums of row parities
    pref = [0] * (N + 1)

    for i in range(N):
        pref[i + 1] = pref[i] + r[i]

    # Count black cells with r[x] XOR r[y] = 1
    Bxor1 = 0

    for x in range(N):
        y0 = y_inner[x] + 1
        y1 = y_outer[x]

        if y0 > y1:
            continue

        ones = pref[y1 + 1] - pref[y0]
        length = y1 - y0 + 1

        if r[x] == 0:
            Bxor1 += ones
        else:
            Bxor1 += length - ones

    # Total number of 1's in solution matrix
    return 2 * A * (N - A) + total_black - 2 * Bxor1

ans = sum(T((1 << i) - i) for i in range(3, 32))

print(ans)
```---

 # 6. 代码演练

 ### 步骤 1

 对于奇数$N$， 返回：

-$3$为了$N=5$,
 -$0$否则。 

---

 ### 步骤 2

 对于甚至$N$，逐行计算环面。 

对于每个$x$:

 -`yout`是最大的有效值$y$,
 -`yin`是最后一个$y$严格在内圈内。 

因此黑色区间为：```python
yin + 1 ... yout
```它的长度是：```python
L = yout - yin
```---

 ### 步骤 3

 平价```python
r[x] = L & 1
```正是线性代数解决方案中使用的行奇偶校验。 

---

 ### 步骤 4

 使用前缀和，我们计算有多少黑色单元格满足$$r_x \oplus r_y = 1.$$这给出了总移动计数公式中的修正项。 

---

 ### 步骤 5

 最后：```python
return 2*A*(N-A) + total_black - 2*Bxor1
```计算数量$1$位于移动矩阵中。
