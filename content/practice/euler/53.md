[欧拉项目问题 53](https://projecteuler.net/problem=53)

 ## 解决方案

 **答案：**`4075`我们必须计算有多少个二项式系数$$\binom{n}{r}$$和$1 \le n \le 100$大于$1{,}000{,}000$。 

---

 # 数学分析

 二项式系数为$$\binom{n}{r}=\frac{n!}{r!(n-r)!}.$$使用阶乘进行直接计算是可能的，但还有更重要的结构观察。 

## 1.二项式系数的对称性

 我们有身份$$\binom{n}{r}=\binom{n}{n-r}.$$所以值是对称的$r=n/2$。 

例如，$$\binom{23}{10}=\binom{23}{13}.$$这种对称性有助于减少工作量。 

---

 ## 2. 成长行为

 对于固定$n$，序列$$\binom{n}{0}, \binom{n}{1}, \dots, \binom{n}{n}$$到中间增加，然后对称减少。 

因此，一旦某个系数超过一百万，所有靠近中间的系数也将超过一百万。 

所以对于每一个$n$:

 1.找到第一个$r$这样$$\binom{n}{r} > 1{,}000{,}000.$$1. 然后所有值来自$r$通过$n-r$超过一百万。 

因此该行贡献的计数是$$(n-r) - r + 1 = n - 2r + 1.$$---

 ## 3.高效复现

 使用迭代计算系数而不是阶乘$$\binom{n}{r} = \binom{n}{r-1}\cdot\frac{n-r+1}{r}.$$这避免了巨大的阶乘计算。 

开始于$$\binom{n}{0}=1.$$然后重复生成下一个系数。 

---

 # Python 实现```python
# Count binomial coefficients greater than one million

LIMIT = 1_000_000
count = 0

# Loop through all n from 1 to 100
for n in range(1, 101):

    # Start with C(n,0) = 1
    c = 1

    # Compute coefficients iteratively
    for r in range(1, n + 1):

        # Recurrence relation:
        # C(n,r) = C(n,r-1) * (n-r+1) / r
        c = c * (n - r + 1) // r

        # Once we exceed the limit,
        # all coefficients up to C(n,n-r) also exceed it
        if c > LIMIT:
            count += (n - 2 * r + 1)
            break

print(count)
```---
