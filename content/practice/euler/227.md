[欧拉项目问题 227](https://projecteuler.net/problem=227)

 ## 解决方案

 **答案：**`3780.618622`让两个骰子可以区分，并仅跟踪它们之间围绕圆圈的**距离**。 

因为桌子上有 100 个玩家循环排列，所以相关状态是：

 -$d =$两个骰子固定器之间的最小圆距离，
 -所以$d \in \{0,1,2,\dots,50\}$。 

状态$d=0$很有趣：一名玩家拥有两个骰子，因此游戏结束。 

最初，骰子彼此相对，所以$$d_0 = 50.$$---

 # 1.数学分析

 每个骰子在回合中独立地表现如下：

 - 以概率向左移动$1/6$,
 - 以概率向右移动$1/6$,
 - 保持原地不动的概率$4/6$。 

假设当前距离为$d$。 

让第一个骰子移动过去$X\in\{-1,0,+1\}$,

 第二个由$Y\in\{-1,0,+1\}$。 

然后定向分离改变$$d \mapsto d + (Y-X).$$数量$Y-X$可以是：$$-2,-1,0,+1,+2$$通过卷积获得的概率：$$\begin{aligned} P(\pm2) &= \frac1{36},\\ P(\pm1) &= \frac{8}{36}=\frac29,\\ P(0) &= \frac{18}{36}=\frac12. \end{aligned}$$因此，对于内部状态$2\le d\le 48$,$$E_d = 1 +\frac1{36}E_{d-2} +\frac29E_{d-1} +\frac12E_d +\frac29E_{d+1} +\frac1{36}E_{d+2},$$在哪里$E_d$是从距离开始的预计剩余时间$d$。 

重新排列：$$\frac12E_d -\frac29E_{d-1} -\frac29E_{d+1} -\frac1{36}E_{d-2} -\frac1{36}E_{d+2} =1.$$---

 ## 边界行为

 ### 吸收状态$$E_0 = 0.$$＃＃＃ 状态$d=1$的转变$-1$或者$-2$两者都会在绕圈折叠后导致吸收，给出：$$E_1 = 1 +\frac{19}{36}E_1 +\frac29E_2 +\frac1{36}E_3.$$＃＃＃ 状态$d=50$在相反的位置，从任一侧“靠近”会产生相同的距离：$$E_{50} = 1 +\frac12E_{50} +\frac49E_{49} +\frac1{18}E_{48}.$$这会产生一个由 50 个未知方程组成的线性系统$$E_1,E_2,\dots,E_{50}.$$解决它给出了期望的期望：$$E_{50}\approx 3780.61862178446.$$四舍五入到 10 位有效数字：$$3780.618622.$$---

 # 2.Python实现```python
import numpy as np
from collections import defaultdict

N = 100
MAX_D = N // 2   # 50

def transitions(d):
    """
    Return transition probabilities from distance d.
    States are folded using circular symmetry.
    """
    probs = defaultdict(float)

    # Possible moves of one die:
    # -1 with prob 1/6
    #  0 with prob 4/6
    # +1 with prob 1/6
    moves = [(-1, 1/6), (0, 4/6), (1, 1/6)]

    for a, pa in moves:
        for b, pb in moves:

            # new oriented separation
            nd = (d + b - a) % N

            # fold to minimal circular distance
            nd = min(nd, N - nd)

            probs[nd] += pa * pb

    return probs

# Build linear system A x = b
# x[i] = expected time starting from distance i+1
A = np.zeros((MAX_D, MAX_D))
b = np.ones(MAX_D)

for d in range(1, MAX_D + 1):

    row = d - 1

    # E_d coefficient
    A[row, row] = 1.0

    # Move all transition terms to left side
    for nd, p in transitions(d).items():

        # E_0 = 0, so omit absorbing state
        if nd == 0:
            continue

        A[row, nd - 1] -= p

# Solve system
E = np.linalg.solve(A, b)

answer = E[MAX_D - 1]

print(f"{answer:.12f}")
```---

 ## 更新距离```python
nd = (d + b - a) % N
```如果有一个骰子经过$a$另一个由$b$,

 它们的相对间隔变化$b-a$。 

因为玩家围成一圈，所以我们减少模 100。 

---

 ## 折叠对称```python
nd = min(nd, N - nd)
```距离$d$和$100-d$在圆上是等价的。 

因此状态空间从 100 个状态减少到只有 51 个状态。

 ## 线性方程

 期望方程始终具有以下形式：$$E_d = 1 + \sum p_{d\to k} E_k.$$我们重新排列成矩阵形式：$$(I-P)E = 1.$$---

 ## 解决```python
E = np.linalg.solve(A, b)
```这同时给出了所有预期的持续时间。 

期望的答案是：```python
E[49]
```因为索引从 0 开始，状态 50 是初始状态。
