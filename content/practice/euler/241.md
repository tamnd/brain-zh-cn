[欧拉项目问题 241](https://projecteuler.net/problem=241)

 ## 解决方案

 **答案：**`482316491800641154`让$$p(n)=\frac{\sigma(n)}{n}, \qquad \sigma(n)=\sum_{d\mid n} d.$$我们想要全部$n\le 10^{18}$这样$$p(n)=k+\frac12$$对于某个整数$k$。 等价地，$$\frac{\sigma(n)}{n}=\frac{2k+1}{2},$$所以减少的分母$p(n)$必须完全是$2$。 

---

 # 1.数学分析

 写$$n=\prod p_i^{a_i}.$$利用乘法$\sigma$,$$\frac{\sigma(n)}{n} = \prod_i \frac{p_i^{a_i+1}-1}{p_i^{a_i}(p_i-1)}.$$定义$$R(n)=\frac{\sigma(n)}{n}.$$我们需要简化形式$R(n)$有分母$2$。 

---

 ## 关键的递归思想

 假设在某个阶段我们有$$\frac{\sigma(n)}{n}=\frac{A}{B}$$用最低的术语来说。 

我们希望最终$B=2$。 

而不是建造$R(n)$直接地，我们递归地跟踪达到半整数所需的“缺失因子”。 

让$$\frac{rn}{rs}$$是减少的分数，这样$$R(n)\cdot \frac{rn}{rs}$$仍然是候选半整数。 

最初，如果目标半整数是$$\frac{x}{2} \qquad (x \text{ odd}),$$然后我们开始$$(rn,rs)=(x,2).$$现在假设我们乘以$n$经过$p^e$。 然后$$R(np^e) = R(n)\cdot \frac{p^{e+1}-1}{p^e(p-1)}.$$所以我们更新$$rn \leftarrow rn\cdot p^e,$$

$$rs \leftarrow rs\cdot \frac{p^{e+1}-1}{p-1},$$并通过 gcd 减少。 

如果最终$$rn=rs=1,$$那么剩下的所需因子是$1$，因此我们获得了有效的半整数完美商。 

---

 ## 为什么递归是有限的

 每一步：

 - 我们选择最小的素因数$rs$,
 - 强制将该素数分解$n$,
 - 分母结构迅速崩溃。 

这将创建一个非常小的搜索树。 事实上，下面只有**22**个有效数字$10^{18}$。 

他们的总和就是所需的答案。

 # 2.Python实现```python
from math import gcd

LIMIT = 10**18

def smallest_prime_factor(n):
    """Return the smallest prime factor of n."""
    if n % 2 == 0:
        return 2

    d = 3
    while d * d <= n:
        if n % d == 0:
            return d
        d += 2

    return n

solutions = []

def dfs(n, rn, rs):
    """
    Recursive search.

    n  = current integer being built
    rn/rs = remaining correction factor
    """

    # Prune: even the minimal remaining multiplier is too large
    if n * rs > LIMIT:
        return

    # Success condition
    if rn == 1 and rs == 1:
        solutions.append(n)

    # Nothing more to do
    if rs == 1:
        return

    # Force the smallest prime dividing rs
    p = smallest_prime_factor(rs)

    # p must not already divide n
    if gcd(p, n) != 1:
        return

    # exponent of p inside rs
    e = 1
    while rs % (p ** (e + 1)) == 0:
        e += 1

    power = p ** e

    # Try larger exponents as well
    for exp in range(e, 60):

        new_n = n * power

        if new_n > LIMIT:
            break

        # Multiply correction fraction appropriately
        new_rn = rn * power

        sigma_part = (power * p - 1) // (p - 1)

        new_rs = rs * sigma_part

        g = gcd(new_rn, new_rs)

        dfs(new_n, new_rn // g, new_rs // g)

        power *= p

# The target numerator must be odd.
# Small odd starting values are sufficient.
for odd in range(3, 13, 2):
    dfs(1, odd, 2)

answer = sum(solutions)

print(sorted(solutions))
print(answer)
```---

 # 4. 小例子验证

 对于$n=24$,$$24=2^3\cdot 3.$$然后$$\sigma(24)=1+2+3+4+6+8+12+24=60.$$所以$$\frac{\sigma(24)}{24} = \frac{60}{24} = \frac52 = 2+\frac12.$$所以$24$是有效的。
