[Project Euler Problem 613](https://projecteuler.net/problem=613)

 ## 解决方案

 **答案：**`0.3916721504`设直角三角形有顶点

 -$A=(0,0)$,
 -$B=(30,0)$,
 -$C=(0,40)$,

 so the longest side is the hypotenuse$BC$长度$50$。 

为了一点$P=(x,y)$在三角形内部，如果蚂蚁选择均匀随机方向，则它从边退出的概率$BC$等于撞击方向的角宽度$BC$，除以$2\pi$。 

该角宽度正是线段所对的角度$BC$在$P$:$$p(P)=\frac{\angle BPC}{2\pi}.$$因此，所需的概率是整个三角形上该数量的平均值：$$\Pr(BC) = \frac{1}{\text{Area}(\triangle)} \iint_{\triangle} \frac{\angle BPC}{2\pi} \,dA.$$三角形面积为$$\frac{30\cdot 40}{2}=600.$$为了$P=(x,y)$,$$\angle BPC = \cos^{-1} \!\left( \frac{(B-P)\cdot(C-P)} {|B-P||C-P|} \right).$$明确地：$$B-P=(30-x,-y), \qquad C-P=(-x,40-y).$$所以我们用数值来评估$$\frac{1}{600} \int_0^{30} \int_0^{40-\frac43x} \frac{ \cos^{-1} \left( \frac{(30-x)(-x)+(-y)(40-y)} {\sqrt{(30-x)^2+y^2}\sqrt{x^2+(40-y)^2}} \right) }{2\pi} \,dy\,dx.$$### Python 实现```python
import mpmath as mp

# High precision
mp.mp.dps = 50

def subtended_angle(x, y):
    # vectors from P=(x,y) to B and C
    bx, by = 30 - x, -y
    cx, cy = -x, 40 - y

    # dot product
    dot = bx * cx + by * cy

    # magnitudes
    norm_b = mp.sqrt(bx * bx + by * by)
    norm_c = mp.sqrt(cx * cx + cy * cy)

    # angle BPC
    cos_theta = dot / (norm_b * norm_c)
    return mp.acos(cos_theta)

def integrand(y, x):
    # probability from point (x,y)
    return subtended_angle(x, y) / (2 * mp.pi)

# upper boundary of the triangle:
# y = 40 - (4/3)x
def integrate_x(x):
    ymax = 40 - (4 * x / 3)
    return mp.quad(lambda y: integrand(y, x), [0, ymax])

# integrate over triangle and divide by area
area = 600
result = mp.quad(lambda x: integrate_x(x), [0, 30]) / area

print(result)
print(round(result, 10))
```### 代码演练

 1. **`subtended_angle(x, y)`**

 计算角度$\angle BPC$使用点积公式：$$\cos\theta = \frac{u\cdot v}{|u||v|}.$$2. **`integrand(y, x)`**

 通过除以将角度转换为概率$2\pi$。 
3. **三角形边界**

 斜边是$$y = 40-\frac43x,$$所以对于每个$x\in[0,30]$,$$0\le y\le 40-\frac43x.$$4. **双重整合**

 我们对三角形进行数值积分并除以面积$600$对所有起始位置进行平均。
