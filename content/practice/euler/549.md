[欧拉项目问题 549](https://projecteuler.net/problem=549)

 ## 解决方案

 **答案：**`476001479068717`对于正整数$n$， 定义$s(n)$作为最小整数$m$这样$$n \mid m!.$$我们必须计算$$S(10^8)=\sum_{n=2}^{10^8} s(n).$$关键是要理解$s(n)$通过质因数分解。 

---

 # 1.数学分析

 假设$$n=\prod p_i^{a_i}.$$然后$n\mid m!$iff 对于每个素数幂$p_i^{a_i}$,$$v_{p_i}(m!)\ge a_i,$$在哪里$v_p(x)$是的指数$p$在$x$。 

因此：$$s(n)=\max_i s(p_i^{a_i}),$$所以整个问题就简化为素数幂。 

---

 ## 主要权力

 对于固定素数$p$， 定义：$$f(p,a)=s(p^a).$$我们需要最小的$m$这样$$v_p(m!)\ge a.$$根据勒让德公式：$v_p(m!)=\sum_{k\ge1}\left\lfloor\frac{m}{p^k}\right\rfloor$所以$f(p,a)$是最小的$m$满足这个不等式。 

示例：

 -$f(5,1)=5$-$f(5,2)=10$因为$10!$恰好包含两个因素$5$---

 ## 计算所有$s(n)$对于每一个原功率$q=p^a\le N$：

 1. 计算$m=f(p,a)$2. 的每一个倍数$q$必须满足$s(k)\ge m$因此我们可以筛选：$$s(k)=\max(s(k),\,f(p,a)) \quad\text{for all }k\equiv0\pmod{p^a}.$$这与素筛非常相似。 

总复杂度约为$$N\sum_{p^a\le N}\frac1{p^a},$$这足够快了$N=10^8$在优化的代码中。 

---

 # 2.Python实现```python
from math import isqrt

N = 10**8

# ------------------------------------------------------------
# Legendre valuation: exponent of prime p inside m!
# ------------------------------------------------------------
def vp_fact(m, p):
    s = 0
    while m:
        m //= p
        s += m
    return s

# ------------------------------------------------------------
# Smallest m such that v_p(m!) >= a
# ------------------------------------------------------------
def min_m(p, a):
    lo, hi = 1, p * a

    while lo < hi:
        mid = (lo + hi) // 2

        if vp_fact(mid, p) >= a:
            hi = mid
        else:
            lo = mid + 1

    return lo

# ------------------------------------------------------------
# Sieve primes up to N
# ------------------------------------------------------------
is_comp = bytearray(N + 1)
primes = []

for i in range(2, N + 1):
    if not is_comp[i]:
        primes.append(i)

        if i <= isqrt(N):
            step = i
            start = i * i
            for j in range(start, N + 1, step):
                is_comp[j] = 1

# ------------------------------------------------------------
# Compute s(n) for all n <= N
# ------------------------------------------------------------
s = [0] * (N + 1)

for p in primes:

    power = p
    a = 1

    while power <= N:

        m = min_m(p, a)

        # every multiple of p^a needs at least m
        for k in range(power, N + 1, power):
            if s[k] < m:
                s[k] = m

        if power > N // p:
            break

        power *= p
        a += 1

# ------------------------------------------------------------
# Sum all values
# ------------------------------------------------------------
answer = sum(s[2:])
print(answer)
```---

 ## 主筛

 对于每一个原功率$p^a$：```python
for k in range(power, N + 1, power):
```的每一个倍数$p^a$必须有$$s(k)\ge s(p^a).$$我们保持所有素数除法的最大值$k$。 

这完全等于：$$s(k)=\max_{p^a\mid k} s(p^a).$$---
