[欧拉项目问题 59](https://projecteuler.net/problem=59)

 ## 解决方案

 **答案：**`129448`### 1.数学分析

 我们得到一个使用长度为 3** 的重复异或密钥加密的密文，其中每个密钥字符都是一个小写英文字母 (`a`–`z`）。 

如果：

 - 明文字节=$p_i$- 密钥字节 =$k_i$- 密文字节=$c_i$那么加密就是：$$c_i = p_i \oplus k_{i \bmod 3}$$在哪里$\oplus$表示异或。 

由于 XOR 是其自身的逆：$$p_i = c_i \oplus k_{i \bmod 3}$$所以解密很简单**如果密钥已知**。 

挑战是找到未知的 3 字符密钥。 

---

 #### 关键观察：蛮力很小

 每个关键字符都是一个小写字母：$$26^3 = 17576$$可能的键。 

这是很小的，所以我们可以尝试每个键。 

对于每个候选键：

 1. 循环异或解密密文。 
2. 检查结果是否与英文文本相似。 

英文文本包含常见单词，例如：

 -`" the "`-`" and "`-`" of "`-`" to "`以及大多数可打印的 ASCII 字符。 

一旦我们找到可读的英语，就计算：$$\sum \text{ASCII values of plaintext}$$该总数就是所需的答案。 

---

 ### 2.Python实现```python
from itertools import product
import requests

# Download the cipher text
url = "https://projecteuler.net/resources/documents/0059_cipher.txt"
cipher = list(map(int, requests.get(url).text.strip().split(",")))

best_score = -1
best_sum = None
best_text = None
best_key = None

# Try all 3-letter lowercase keys
for key_chars in product(range(ord('a'), ord('z') + 1), repeat=3):
    # Decrypt
    plaintext = [
        c ^ key_chars[i % 3]
        for i, c in enumerate(cipher)
    ]

    # Convert to text
    text = ''.join(map(chr, plaintext))

    # Reject obviously bad plaintext
    if not all(32 <= x <= 126 or x in (10, 13) for x in plaintext):
        continue

    # Score based on common English words
    score = (
        text.count(" the ") * 10 +
        text.count(" and ") * 5 +
        text.count(" of ") * 3 +
        text.count(" to ") * 2 +
        text.count(" in ")
    )

    # Keep best candidate
    if score > best_score:
        best_score = score
        best_sum = sum(plaintext)
        best_text = text
        best_key = ''.join(map(chr, key_chars))

print("Key:", best_key)
print("ASCII sum:", best_sum)
print(best_text[:300])
```---
