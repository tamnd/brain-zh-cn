[项目欧拉问题 322](https://projecteuler.net/problem=322)

 ## 解决方案

 **答案：**`999998760323313995`让$$T(m,n)=\#\left\{\, i \mid n\le i<m,\ 10\mid \binom{i}{n}\right\}.$$我们被给予$$T(10^9,10^7-10)=989697000$$我们必须计算$$T(10^{18},10^{12}-10).$$---

 # 1.数学分析

 我们需要计算二项式系数何时能被整除$10$，即由两者$2$和$5$。 

所以定义：

 -$A_2$: 数量$i$这样$\binom{i}{n}$**不能被整除$2$**。 
-$A_5$: 数量$i$这样$\binom{i}{n}$**不能被整除$5$**。 
-$A_{10}$: 数量$i$这样$\binom{i}{n}$不能被任何一个整除$2$也不$5$。 

然后通过包含-排除，$$T(m,n) = (m-n)-A_2-A_5+A_{10}.$$So the problem reduces to computing these three quantities.

 ---

 ## 卢卡斯/库默定理

 对于素数$p$,$$\binom{i}{n}\not\equiv 0 \pmod p$$当且仅当每个碱基-$p$的数字$n$最多是对应的数字$i$。 

等价地，如果$i=n+x$，然后添加$n$和$x$在基地$p$产生**无进位**。 

---

 # 计算$A_2$让$$n=10^{12}-10.$$在二进制中，$\binom{i}{n}$是奇数当且仅当每个二进制 1 位$n$也是 1 位$i$。 

以 2 为基数的数字 DP 给出：$$A_2 = 238418395136.$$---

 # 计算$A_5$在基数 5 中，卢卡斯给出了类似的条件。 

以 5 为基数的 DP 产生：$$A_5 = 1258291200.$$---

 # 计算$A_{10}$现在我们需要同时满足这两个条件的数字。 

写$$i=n+x.$$然后：

 - 基数 2 中没有进位$\iff x\& n =0$,
 - 基数 5 中没有进位$\iff$每个以 5 为基数的数字$x$的边界是$4-d_k(n)$。 

以 5 为底的展开$n=10^{12}-10$是$$(1,1,2,3,4,0,4,4,4,4,4,4,4,4,4,4,3,0)_5$$（从高到低读）。 

大多数数字是$4$，强制对应的数字$x$成为$0$。 

仅有的$4800$低部分的可能性仍然存在。 

让$$5^{18}=3814697265625.$$每一个可受理的$x$可以唯一地写为$$x=y\cdot 5^{18}+z,$$在哪里：

-$0\le y<262144$,
 -$z$是其中之一$4800$允许的低零件。 

检查二进制条件$(x\& n)=0$在所有这些对上给出$$A_{10}=321.$$---

 # 最终计算

 现在应用包含-排除：$$\begin{aligned} T &=(10^{18}-(10^{12}-10))  -238418395136  -1258291200  +321 \\ &=999999000000000010  -238418395136  -1258291200  +321 \\ &=999998760323313995. \end{aligned}$$---

 # 2.Python实现```python
from functools import lru_cache
from itertools import product
import numpy as np

def count_not_divisible(m, n, p):
    """
    Count i in [n, m) such that C(i,n) is NOT divisible by p.
    Lucas theorem:
    every base-p digit of n must be <= corresponding digit of i.
    """

    # digits of n
    nd = []
    x = n
    while x:
        nd.append(x % p)
        x //= p

    # digits of m-1
    md = []
    x = m - 1
    while x:
        md.append(x % p)
        x //= p

    L = max(len(nd), len(md))
    nd += [0] * (L - len(nd))
    md += [0] * (L - len(md))

    @lru_cache(None)
    def dp(pos, tight):
        if pos < 0:
            return 1

        limit = md[pos] if tight else (p - 1)

        total = 0
        for d in range(nd[pos], limit + 1):
            total += dp(pos - 1, tight and d == limit)

        return total

    return dp(L - 1, True)

def count_not_divisible_by_10(m, n):
    """
    Count i such that C(i,n) is divisible by neither 2 nor 5.
    """

    L = m - n

    # base-5 digits of n
    digits = []
    x = n
    while x:
        digits.append(x % 5)
        x //= 5

    # admissible low-part digits
    positions = [i for i, d in enumerate(digits) if d < 4]
    choices = [range(5 - digits[i]) for i in positions]

    zs = []

    for tup in product(*choices):
        z = 0
        for v, k in zip(tup, positions):
            z += v * (5 ** k)
        zs.append(z)

    zs = np.array(zs, dtype=np.uint64)

    p5 = 5 ** len(digits)

    Y = (L - 1) // p5 + 1

    ys = np.arange(Y, dtype=np.uint64) * np.uint64(p5)

    total = 0

    for z in zs:
        total += np.count_nonzero(((ys + z) & np.uint64(n)) == 0)

    return int(total)

def solve():
    m = 10 ** 18
    n = 10 ** 12 - 10

    A2 = count_not_divisible(m, n, 2)
    A5 = count_not_divisible(m, n, 5)
    A10 = count_not_divisible_by_10(m, n)

    T = (m - n) - A2 - A5 + A10

    return T

print(solve())
```---

 # 3. 代码演练

 ##`count_not_divisible`这是标准的卢卡斯数字 DP。 

对于每个基地 -$p$数字位置：

 - 的数字$i$必须至少是以下数字$n$,
 - 且不得超过以下数字$m-1$。 

DP统计所有有效的$i<m$。 

---

 ##`count_not_divisible_by_10`这处理同时$2$- 和$5$-状况。 

以 5 为底的条件极大地限制了低位数字$x=i-n$，仅留下$4800$的可能性。 

然后我们枚举较高的块系数$y$，并使用以下方法测试二进制无进位条件：```python
((ys + z) & n) == 0
```它准确地编码了“无重叠 1 位”。
