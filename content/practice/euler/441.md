[欧拉项目 441 问题](https://projecteuler.net/problem=441)

 ## 解决方案

 **答案：**`5000088.8395`让$$R(M)=\sum_{\substack{1\le p<q\le M\\ p+q\ge M\\ (p,q)=1}}\frac1{pq}, \qquad S(N)=\sum_{M=2}^N R(M).$$我们想要$S(10^7)$。 

---

 # 1. 关键的数学见解

 而不是总结$M$首先，我们颠倒求和的顺序。 

对于固定互质对$(p,q)$和$p<q$，这对对每个$M$满意的$$q\le M\le p+q.$$因此，对于固定的$N$，该对贡献的次数$S(N)$是$$\min(N,p+q)-q+1.$$因此$$S(N) = \sum_{\substack{1\le p<q\le N\\(p,q)=1}} \frac{\min(N,p+q)-q+1}{pq}.$$分为两个区域。 

---

 ## 区域 1：$p+q\le N$那么重数就是$p+1$， 所以$$\sum_{\substack{p<q\\p+q\le N\\(p,q)=1}} \frac{p+1}{pq}.$$---

 ## 区域 2：$p+q>N$那么重数就是$N-q+1$， 所以$$\sum_{\substack{p<q\le N\\p+q>N\\(p,q)=1}} \frac{N-q+1}{pq}.$$---

 # 2.消除互质条件

 使用莫比乌斯恒等式$$[(p,q)=1] = \sum_{d\mid p,\ d\mid q}\mu(d).$$这将互质限制转换为除数和。 

所需的内部和变成调和数表达式：$$H_n=\sum_{k=1}^n \frac1k.$$对于固定$p$,$$\sum_{\substack{q\le x\\(p,q)=1}}\frac1q = \sum_{d\mid p}\frac{\mu(d)}d H_{\lfloor x/d\rfloor}.$$这将整个问题简化为筛式预处理：

 - 莫比乌斯函数$\mu(n)$,
 - 每个整数的约数，
 - 谐波数。 

由此产生的复杂度约为$$O(N\log\log N),$$这足够快了$N=10^7$在优化的 Python/PyPy 中。 

---

 # 3.Python实现```python
from math import gcd

def brute_S(N):
    # Only for verification on small N
    S = 0.0

    for M in range(2, N + 1):
        R = 0.0

        for p in range(1, M):
            for q in range(p + 1, M + 1):
                if p + q >= M and gcd(p, q) == 1:
                    R += 1.0 / (p * q)

        S += R

    return S

# ------------------------------------------------------------
# Efficient solution
# ------------------------------------------------------------

def mobius_sieve(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1

        for p in prime:
            if i * p > n:
                break

            is_comp[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    return mu

def solve(N):
    # Harmonic numbers
    H = [0.0] * (N + 1)
    for i in range(1, N + 1):
        H[i] = H[i - 1] + 1.0 / i

    # Möbius function
    mu = mobius_sieve(N)

    # Divisor lists
    divisors = [[] for _ in range(N + 1)]

    for d in range(1, N + 1):
        md = mu[d]
        if md == 0:
            continue

        coeff = md / d

        for multiple in range(d, N + 1, d):
            divisors[multiple].append((d, coeff))

    ans = 0.0

    for p in range(1, N):
        invp = 1.0 / p

        # region p + q <= N
        limit1 = N - p

        coprime_sum_1 = 0.0
        coprime_sum_p = 0.0

        for d, coeff in divisors[p]:
            coprime_sum_1 += coeff * H[limit1 // d]
            coprime_sum_p += coeff * H[p // d]

        region1 = (p + 1) * invp * (coprime_sum_1 - coprime_sum_p)

        # region p + q > N
        region2 = 0.0

        for q in range(limit1 + 1, N + 1):
            if gcd(p, q) == 1:
                region2 += (N - q + 1) / (p * q)

        ans += region1 + region2

    return ans

# ------------------------------------------------------------
# Small checks
# ------------------------------------------------------------

print(brute_S(2))    # 0.5
print(brute_S(10))   # ~6.9147
print(brute_S(100))  # ~58.2962

# Final computation:
# print(f"{solve(10**7):.4f}")
```---

 # 4. 代码演练

 ###`brute_S(N)`定义的直接实现：

 - 循环所有$M$，
- 全部$p<q$,
 - 检查：

 -$p+q\ge M$,
 -$\gcd(p,q)=1$,
 - 积累$1/(pq)$。 

仅用于验证小值。 

---

 ###`mobius_sieve(n)`计算莫比乌斯函数$\mu(n)$使用线性筛。 

记起：$$\mu(n)= \begin{cases} 1 & n=1\\ (-1)^k & n \text{ squarefree with }k\text{ primes}\\ 0 & \text{otherwise} \end{cases}$$---

 ### 谐波数```python
H[i] = H[i - 1] + 1.0 / i
```预计算$$H_i=\sum_{k=1}^i \frac1k.$$---

 ### 除数预处理

 对于每个整数$p$，我们存储所有无平方除数$d$与...一起$$\frac{\mu(d)}d.$$这允许快速评估$$\sum_{\substack{q\le x\\(p,q)=1}} \frac1q.$$---
