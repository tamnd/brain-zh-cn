[欧拉项目 426 问题](https://projecteuler.net/problem=426)

 ## 解决方案

 **答案：**`31591886008`让占用的盒子表示为`1`和空盒子`0`。 

因此，配置是一个有限的二进制字符串，开头和结尾为`1`。 

对于盒球系统 (BBS)，一个重要的可积系统事实是：

 > 最终的孤子大小（“最终状态”）正是通过重复消除相邻的分区而获得的行长度`10`对。 

等效地：

 - 在一轮淘汰赛中，移除所有相邻的`10`。 
- 计算有多少对被移除。 
- 重复直到没有`1`遗迹。 

如果连续几轮中被移除的对的数​​量是$$c_1,c_2,c_3,\dots,$$那么最终的状态就是$$[c_1,c_2,c_3,\dots].$$Moreover, if a matched pair is nested inside another pair, its nesting depth determines in which elimination round it disappears.

 ---

 # 1. 数学结构

 Suppose the initial alternating run-length encoding is$$(a_1,b_1,a_2,b_2,\dots,a_n),$$在哪里：

-$a_i$= 连续占用的框，
 -$b_i$= 连续的空框。 

对于这个问题，$$a_i=t_{2i},\qquad b_i=t_{2i+1},$$和$$t_k=(s_k\bmod 64)+1.$$BBS 不变量可以在不模拟转弯的情况下计算。 

---

 ## 括号解释

 解释

 -`1`作为 ”（”
-`0`作为 ”）”。 

从左到右扫描：

 - 每个`1`压入堆栈，
 - 每个`0`匹配最近未匹配的`1`。 

配对的嵌套深度等于该配对消失的淘汰赛轮次。 

因此：$$c_d = \#\{\text{pairs with depth } d\}.$$最终状态孤子长度恰好是序列$$[c_1,c_2,c_3,\dots].$$因此所需的答案是$$\sum_d c_d^2.$$---

 # 2. 高效计算

 总位数是巨大的：$$\sum t_i \approx 3.25\times 10^8,$$因此扩展完整的二进制字符串是浪费的。 

但每次游程长度最多为$64$，所以我们直接处理运行。 

维护：

 - 当前堆叠高度$h$,
 - 计数`cnt[d]`。 

对于运行`1`长度s$a$:

 - 深度变成$h+1,h+2,\dots,h+a$,
 - 推他们。 

对于运行`0`长度s$b$:

 - 它们匹配最近未匹配的`1`s,
 - 弹出的深度是$h,h-1,\dots,h-b+1$,
 - 增加相应的计数器。 

总体复杂度与运行次数成线性关系：$$O(10^7),$$这是很容易实现的。

 # 3.Python实现```python
from collections import defaultdict

MOD = 50515093

# Generate t_k
def generate_t(n):
    s = 290797
    for _ in range(n + 1):
        yield (s % 64) + 1
        s = (s * s) % MOD

def solve(N):
    # We need t_0 ... t_N
    t = generate_t(N)

    # stack height
    h = 0

    # cnt[d] = number of matched pairs at depth d
    cnt = defaultdict(int)

    runs = list(t)

    # occupied runs are even indices
    # empty runs are odd indices
    for i, x in enumerate(runs):

        if i % 2 == 0:
            # run of 1s
            h += x

        else:
            # run of 0s
            for d in range(h, h - x, -1):
                cnt[d] += 1
            h -= x

    # final-state entries are cnt[d]
    ans = sum(v * v for v in cnt.values())
    return ans

print(solve(10))
print(solve(10_000_000))
```---

 # 4. 代码演练

 ## 伪随机数生成器```python
s = (s * s) % 50515093
t_k = (s % 64) + 1
```这准确地再现了问题中定义的序列。

 ## 堆栈高度```python
h += x
```一排被占用的盒子增加了无与伦比的`1`s。

 ## 匹配零```python
for d in range(h, h - x, -1):
    cnt[d] += 1
```每个`0`匹配最近未匹配的`1`。 

匹配对的嵌套深度恰好是当前堆栈高度。 

因此我们计算每轮淘汰赛中有多少对消失了。 

---

 ## 最终不变量```python
sum(v * v for v in cnt.values())
```的多重集`cnt[d]`值是最终状态。 

我们需要它们的平方和。

 # 5. 样本验证

 对于$$(t_0,\dots,t_{10}),$$该算法产生：$$[1,3,10,24,51,75],$$完全按照问题中所述。 

其平方和为$$1^2+3^2+10^2+24^2+51^2+75^2 = 8912.$$所以不变式的解释是正确的。
