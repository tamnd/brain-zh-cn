[欧拉项目问题 37](https://projecteuler.net/problem=37)

 ## 解决方案

 **答案：**`748317`## 1.数学分析

 我们寻找**仅有的十一个素数**，它们是：

 - 做好自我准备，
 - 当重复截断数字**从左到右**时保持素数，并且
 - 重复截断数字时保持素数**从右到左**。 

例子：$$3797 \to 797 \to 97 \to 7$$和$$3797 \to 379 \to 37 \to 3$$一切都保持原始状态。 

我们必须找到所有这些素数的**和**，不包括$2,3,5,7$。 

### 主要观察结果

 #### 观察 1：数字限制

 对于任何多位可截断素数：

 - **最后一位数字**必须是$3$或者$7$, 由于素数$>5$不能以偶数或 5 结尾。 
- 内部数字不能是偶数或 5，否则某些截断会变成合数。 

因此，候选人仅使用以下数字：$$\{1,3,7,9\}$$（可能除了前导数字）。 

这极大地减少了搜索空间。 

---

 #### 观察 2：截断测试

 对于一个号码$n$，定义：

 ### 右截断

 重复删除最后一位数字：$$3797,\ 379,\ 37,\ 3$$使用整数除以 10 很容易：```python
n
n // 10
n // 100
...
```一切都必须是素数。 

---

 ### 左截断

 重复删除第一位数字：$$3797,\ 797,\ 97,\ 7$$这可以通过转换为字符串并切片来检查：```python
"3797"
"797"
"97"
"7"
```所有结果整数必须是质数。 

---

 #### 观察 3：只有 11 个

 该问题保证恰好有 **11** 这样的素数，所以我们可以：

 1. 生成素数，
 2. 测试可截断性，
 3. 找到十一点就停下来。 

---

 ### 高效的素性测试

 我们使用试除法直至：$$\sqrt{n}$$因为如果$n = ab$, 至多至少有一个因素$\sqrt n$。 

算法：

 - 拒绝$n<2$,
 - 快速处理偶数，
 - 测试奇数除数$\sqrt n$。 

复杂性很小，因为只有 11 个有效数字。

 ## 2.Python实现```python
import math

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    limit = int(math.sqrt(n))
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False
    return True

def is_truncatable_prime(n):
    """Check if n is truncatable from both directions."""
    s = str(n)

    # Exclude single-digit primes
    if len(s) == 1:
        return False

    # Left-to-right truncations
    for i in range(len(s)):
        if not is_prime(int(s[i:])):
            return False

    # Right-to-left truncations
    for i in range(len(s), 0, -1):
        if not is_prime(int(s[:i])):
            return False

    return True

found = []
n = 11  # smallest possible multi-digit prime

while len(found) < 11:
    if is_prime(n) and is_truncatable_prime(n):
        found.append(n)
    n += 2  # skip even numbers

answer = sum(found)

print(found)
print(answer)
```---
