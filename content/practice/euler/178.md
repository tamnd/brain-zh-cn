[欧拉项目问题 178](https://projecteuler.net/problem=178)

 ## 解决方案

 **答案：**`126461847755`我们求下面**泛数字步数**的数量$10^{40}$。 

**步数**是相邻数字精确相差的数字$1$。 

示例：

 -$45656$是一个步数，因为$$|4-5|=|5-6|=|6-5|=|5-6|=1.$$- 数字本身不允许有前导零。 

如果每个数字都是**泛数字**$0,1,\dots,9$至少出现一次。 

我们必须计算所有泛数字步数最多为$40$数字。 

---

 # 数学分析

 步骤号的定义属性完全是本地的：

 - 从数字$d$，下一个数字只能是$d-1$或者$d+1$。 

这自然意味着**动态编程**。 

附加的泛数字条件意味着我们必须跟踪到目前为止出现了哪些数字。 

---

 ## 1. 国家代表

 假设我们正在逐位构建一个步骤号。 

任何时候我们都需要知道：

 1.当前最后一位数字，
 2. 哪些数字已经出现过。 

我们使用 10 位掩码对所使用的数字集进行编码：$$\text{mask} \in [0,2^{10}-1].$$少量$k$是$1$当且仅当数字$k$已经出现了。 

例如：

 - 面具$= 0000000011_2$表示数字$0,1$出现了，
 - 面具$=1111111111_2 = 1023$表示所有数字都出现了。 

定义$$dp[\ell][d][m]$$作为步数：

 - 长度$\ell$,
 - 以数字结尾$d$,
 - 使用了数字集$m$。 

---

 ## 2. 初始条件

 有效数字不能以零开头。 

所以对于长度$1$:$$dp[1][d][1\ll d]=1 \quad\text{for } d=1,\dots,9.$$---

 ## 3. 过渡

 如果当前最后一位数字是$d$，那么下一个数字可以是：

 -$d-1$如果$d>0$,
 -$d+1$如果$d<9$。 

假设我们扩展到数字$nd$。 然后：$$\text{newmask}=m\cup\{nd\} = m \,|\, (1\ll nd).$$因此：$$dp[\ell+1][nd][newmask] \;+=\; dp[\ell][d][m].$$---

 ## 4. 计算泛数字

 一个数字是泛数字当且仅当所有数字都出现了：$$m = 2^{10}-1 = 1023.$$因此对于每个长度$\ell$,$$\text{count}(\ell) = \sum_{d=0}^{9} dp[\ell][d][1023].$$我们需要所有长度$1$通过$40$。 

---

 # 复杂性

 有：

 -$40$长度，
 -$10$可能的结束数字，
 -$2^{10}=1024$面具。 

所以总状态：$$40 \times 10 \times 1024 \approx 4\times 10^5,$$这是很小的。 

---

 # Python 实现```python
from collections import defaultdict

FULL = (1 << 10) - 1   # 1023, all digits used

# dp[digit][mask] = count
dp = defaultdict(int)

# Initialize 1-digit numbers (no leading zero)
for d in range(1, 10):
    dp[(d, 1 << d)] = 1

answer = 0

# Build lengths from 1 up to 40
for length in range(1, 41):

    # Count pandigital numbers of this length
    for (digit, mask), cnt in dp.items():
        if mask == FULL:
            answer += cnt

    # Build next layer
    new_dp = defaultdict(int)

    for (digit, mask), cnt in dp.items():

        # Move to digit-1
        if digit > 0:
            nd = digit - 1
            new_mask = mask | (1 << nd)
            new_dp[(nd, new_mask)] += cnt

        # Move to digit+1
        if digit < 9:
            nd = digit + 1
            new_mask = mask | (1 << nd)
            new_dp[(nd, new_mask)] += cnt

    dp = new_dp

print(answer)
```---
