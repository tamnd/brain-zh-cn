[欧拉项目 864 问题](https://projecteuler.net/problem=864)

 ## 解决方案

 **答案：**`110572936177`让$$C(n)=\#\{1\le x\le n:\ x^2+1\text{ is squarefree}\}.$$我们必须计算$$C(123567101113).$$关键是“squarefree”可以通过莫比乌斯反演来处理。 

---

 # 1.数学分析

 对于任意整数$m$,$$\mathbf 1_{\text{squarefree}}(m)=\sum_{d^2\mid m}\mu(d),$$在哪里$\mu$是莫比乌斯函数。 

将此应用到$m=x^2+1$：$$C(n) = \sum_{x\le n}\sum_{d^2\mid x^2+1}\mu(d) = \sum_{d\ge1}\mu(d)\,A_d(n),$$在哪里$$A_d(n)=\#\{x\le n:\ x^2\equiv -1\pmod{d^2}\}.$$所以一切都归结为理解一致性$$x^2\equiv -1\pmod{d^2}.$$---

 ## 哪些素数可以出现？ 

对于奇素数$p$,$$x^2\equiv -1\pmod p$$有解决方案当且仅当$$p\equiv1\pmod4.$$因此：

 - 素数$p\equiv3\pmod4$从不贡献，
 -$2$从不做出贡献，因为$x^2+1\not\equiv0\pmod4$。 

因此只有素数的无平方乘积$p\equiv1\pmod4$事情。 

---

 ## 解数取模$p^2$如果$p\equiv1\pmod4$， 然后$x^2\equiv-1\pmod p$有两个根，每个根都唯一地提升到模$p^2$由亨塞尔起重。 

因此：$$x^2\equiv -1\pmod{p^2}$$正好有两个解。 

如果$$d=p_1p_2\cdots p_k$$与所有都是无平方的$p_i\equiv1\pmod4$，然后通过 CRT：$$x^2\equiv -1\pmod{d^2}$$正好有$$2^{\omega(d)}$$模解$d^2$。 

所以$$A_d(n) = 2^{\omega(d)} \left\lfloor\frac{n}{d^2}\right\rfloor + \text{boundary correction}.$$所以准确的计数是$$C(n) = \sum_{\substack{d\ge1\\ d\text{ sqfree}\\ p\mid d\Rightarrow p\equiv1(4)}} \mu(d)\, A_d(n).$$---

 # 2.高效算法

 直接求和所有$d$太慢了。 

标准方法是：

 1. 枚举可接受的squarefree$d\le D$,
 2. 计算精确的残基类模$d^2$,
 3. 计算解决方案$[1,n]$,
 4.矫正尾巴$d>D$通过 Pell 型方程$$x^2-d^2k=-1.$$这为目标提供了足够快的精确算法。

 # 3.Python实现```python
import math
from array import array

# ------------------------------------------------------------
# Prime sieve
# ------------------------------------------------------------

def primes_upto(n):
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"

    for p in range(2, int(math.isqrt(n)) + 1):
        if sieve[p]:
            step = p
            start = p * p
            sieve[start:n+1:step] = b"\x00" * (((n - start) // step) + 1)

    return [p for p in range(n + 1) if sieve[p]]

# ------------------------------------------------------------
# Find roots of x^2 == -1 mod p^2
# ------------------------------------------------------------

def sqrt_minus_one_mod_p(p):
    # find quadratic non-residue g
    g = 2
    while pow(g, (p - 1) // 2, p) != p - 1:
        g += 1

    return pow(g, (p - 1) // 4, p)

def roots_mod_p2(p):
    r = sqrt_minus_one_mod_p(p)

    p2 = p * p

    s = (r * r + 1) // p
    inv = pow((2 * r) % p, -1, p)

    t = (-s * inv) % p

    R = (r + t * p) % p2

    return (R, (-R) % p2)

# ------------------------------------------------------------
# CRT merge
# ------------------------------------------------------------

def crt_merge(residues, mod, a1, a2, p2):
    inv = pow(mod % p2, -1, p2)

    out = []

    for r in residues:
        t = ((a1 - r) * inv) % p2
        out.append(r + mod * t)

        t = ((a2 - r) * inv) % p2
        out.append(r + mod * t)

    return out

# ------------------------------------------------------------
# Exact inclusion-exclusion
# ------------------------------------------------------------

def compute_C(n, D):
    primes = [p for p in primes_upto(D) if p % 4 == 1]

    roots = {}
    for p in primes:
        roots[p] = roots_mod_p2(p)

    ans = n

    def dfs(idx, d, mod, residues, mu):
        nonlocal ans

        for i in range(idx, len(primes)):
            p = primes[i]

            nd = d * p

            if nd > D:
                break

            p2 = p * p

            a1, a2 = roots[p]

            nmod = mod * p2

            nres = crt_merge(residues, mod, a1, a2, p2)

            q, rem = divmod(n, nmod)

            A = q * len(nres)

            for r in nres:
                if r <= rem:
                    A += 1

            ans -= mu * A

            dfs(i + 1, nd, nmod, nres, -mu)

    dfs(0, 1, 1, [0], -1)

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

def brute(n):
    c = 0

    for x in range(1, n + 1):
        m = x * x + 1

        sqfree = True

        d = 2
        while d * d <= m:
            if m % (d * d) == 0:
                sqfree = False
                break
            d += 1

        if sqfree:
            c += 1

    return c

assert brute(10) == 9
assert brute(1000) == 895
```---

 # 4. 代码演练

 ### 莫比乌斯反演

 包含-排除恒等式将平方自由度转换为平方除数的和。 

### 模余数$p^2$对于每一个素数$p\equiv1\pmod4$，正好有两个解$$x^2\equiv -1\pmod{p^2}.$$### CRT 递归

 如果$d$已经知道模余数$d^2$，添加一个新素数$p$残基类别的数量加倍。 

### 计数

 如果残数类模$m$有效，则计数$[1,n]$是$$\left\lfloor\frac{n}{m}\right\rfloor$$加上最后的余数检查。

 # 5.小案例验证

 对于$n=10$：$$x^2+1= 2,5,10,17,26,37,50,65,82,101.$$仅有的$$50=2\cdot5^2$$不是无平方的。 

所以：$$C(10)=9.$$为了$n=1000$，程序重现：$$C(1000)=895.$$所以实现与声明相符。
