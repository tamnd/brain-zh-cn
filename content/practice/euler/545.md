[欧拉项目问题 545](https://projecteuler.net/problem=545)

 ## 解决方案

 **答案：**`921107572`让$$S_k(n)=\sum_{i=1}^n i^k$$为 Faulhaber 多项式。 我们感兴趣的是系数$n$，其分母是$D(k)$。 

### 1. 伯努利数联系

 福尔哈伯公式为$$\sum_{i=1}^n i^k = \frac{1}{k+1} \sum_{j=0}^{k} (-1)^j \binom{k+1}{j} B_j n^{k+1-j},$$在哪里$B_j$是伯努利数。 

系数为$n$来自术语$j=k$， 所以：$$a_1 = B_k.$$因此：$$D(k)=\text{denominator}(B_k).$$例如，$$B_4=-\frac{1}{30},$$所以$D(4)=30$，匹配问题陈述。 

---

 ### 2. 应用冯·施陶特-克劳森定理

 该定理说：$$\operatorname{den}(B_k) = \prod_{p-1\mid k} p \qquad (k \text{ even}),$$当乘积超过素数时$p$这样$p-1\mid k$。 

我们想要：$$D(k)=20010.$$因素：$$20010 = 2\cdot 3\cdot 5\cdot 23\cdot 29.$$因此**唯一**素数$p$和$p-1\mid k$必须是$$p\in\{2,3,5,23,29\}.$$等价地，$$1,2,4,22,28 \mid k,$$但**没有其他**$p-1$可能会分裂$k$。 

最小公倍数是$$\mathrm{lcm}(1,2,4,22,28)=308.$$所以每一个有效的$k$有形式$$k=308t.$$现在条件变成：

 对于每个除数$d\mid 308$,$$dt+1$$必须是合数（否则是一个新素数$q=dt+1$会满足$q-1\mid k$，在分母上添加一个不需要的因子）。 

这给出了递归乘法测试：

 -$t=1$有效（$k=308$, 给予$F(1)=308$）。 
- 一个号码$t$有效当且仅当：

 1.全部$dt+1$为了$d\mid 308$是复合的，并且
 2. 每一个$t/p$（对于素数$p\mid t$) 有效。 

这重现：$$F(10)=96404,$$与声明相符。

 ### 3.Python实现```python
import sympy as sp

DIVS = sp.divisors(308)

def find_F(target):
    N = 200000

    while True:
        # Smallest prime factor sieve
        spf = list(range(N + 1))
        for i in range(2, int(N**0.5) + 1):
            if spf[i] == i:
                for j in range(i * i, N + 1, i):
                    if spf[j] == j:
                        spf[j] = i

        good = [False] * (N + 1)
        good[1] = True

        count = 1  # t = 1 corresponds to F(1)=308

        for t in range(2, N + 1):

            # Local primality condition:
            # d*t + 1 must be composite for all d | 308
            local_ok = True
            for d in DIVS:
                if sp.isprime(d * t + 1):
                    local_ok = False
                    break

            if not local_ok:
                continue

            # Recursive divisor condition
            n = t
            ok = True
            used = set()

            while n > 1:
                p = spf[n]
                if p not in used:
                    used.add(p)
                    if not good[t // p]:
                        ok = False
                        break
                n //= p

            if ok:
                good[t] = True
                count += 1

                if count == target:
                    return 308 * t

        N *= 2

print(find_F(10))      # 96404
print(find_F(100000))  # final answer
```---

 ### 4. 代码演练

 -`DIVS = divisors(308)`计算所有除数$308$。 
- 我们搜索数字$t$这样$k=308t$。 
- 对于每个$t$，我们测试是否每个$dt+1$是复合的。 
- 我们还通过检查所有来强制执行递归除数属性$t/p$， 在哪里$p$运行于以下的质因数$t$。 
- 我们计算有效$t$的顺序递增，直到$100000$-第一个。 

确认：

-$F(1)=308$✔
 -$F(10)=96404$✔

 计算得出：$$t_{100000}=2,\!990,\!609$$因此$$F(10^5)=308\times 2,\!990,\!609 =921,\!107,\!572.$$**答案：921107572**
