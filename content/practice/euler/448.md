[欧拉项目 448 问题](https://projecteuler.net/problem=448)

 ## 解决方案

 **答案：**`106467648`让$$A(n)=\frac1n\sum_{i=1}^n \operatorname{lcm}(n,i), \qquad S(n)=\sum_{k=1}^n A(k).$$我们需要$$S(99999999019)\pmod{999999017}.$$---

 # 1.数学分析

 我们从身份开始$$\operatorname{lcm}(a,b)=\frac{ab}{\gcd(a,b)}.$$所以$$A(n) = \frac1n \sum_{i=1}^n \frac{ni}{\gcd(n,i)} = \sum_{i=1}^n \frac{i}{\gcd(n,i)}.$$---

 ## 步骤 1：按 gcd 分组

 让$$d=\gcd(n,i).$$写$$i=d m,\qquad n=d t,$$和$\gcd(m,t)=1$。 

然后$$\frac{i}{\gcd(n,i)}=\frac{dm}{d}=m.$$因此$$A(n) = \sum_{d\mid n} \sum_{\substack{1\le m\le n/d\\ \gcd(m,n/d)=1}} m.$$让$t=n/d$。 然后$$A(n) = \sum_{t\mid n} \sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m.$$---

 ## 步骤 2：减少残差的总和

 一个经典的结果：

 对于$t>1$,$$\sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m = \frac{t\varphi(t)}2.$$（残基成对出现$m$和$t-m$。）

为了$t=1$，总和是$1$。 

定义$$f(t)= \sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m.$$然后$$f(1)=1,\qquad f(t)=\frac{t\varphi(t)}2 \quad (t>1).$$所以$$A(n)=\sum_{d\mid n} f(d).$$因此$$S(N) = \sum_{n\le N}\sum_{d\mid n} f(d).$$交换顺序：$$S(N) = \sum_{d\le N} f(d)\left\lfloor \frac{N}{d}\right\rfloor.$$代替$f(d)$:$$S(N) = 1\cdot N + \frac12 \sum_{d=2}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$等价地，$$S(N) = \frac12 \left( N+ \sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor \right).$$所以整个问题归结为计算$$F(N)=\sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$---

 # 2.快速求和

 我们需要$$H(n)=\sum_{k\le n} k\varphi(k).$$然后我们可以评估$F(N)$使用除数分组：$$F(N) = \sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$的价值观$\left\lfloor N/d\right\rfloor$间隔不变：$$\left\lfloor \frac{N}{d}\right\rfloor = q$$为了$$d\in[L,R].$$因此$$F(N) = \sum q\,(H(R)-H(L-1)).$$这给出了一个$O(\sqrt N)$算法。 

---

 ## 第三步：计算$H(n)$使用身份$$\sum_{d\mid n}\varphi(d)=n.$$乘以$n$,$$\sum_{d\mid n} d\varphi(d)$$具有导致递归的狄利克雷卷积结构$$H(n) = \sum_{k=1}^n k^2 - \sum_{l=2}^n \left(\sum_{i=l}^r i\right) H\!\left(\left\lfloor\frac nl\right\rfloor\right).$$将等商分组给出$O(\sqrt n)$记忆递归。 

---

 # 3.Python实现```python
MOD = 999999017
N = 99999999019

INV2 = pow(2, MOD - 2, MOD)
INV6 = pow(6, MOD - 2, MOD)

# Sieve limit
M = 20_000_000

# ------------------------------------------------------------
# Euler phi sieve
# ------------------------------------------------------------

phi = list(range(M + 1))

for p in range(2, M + 1):
    if phi[p] == p:          # p is prime
        for k in range(p, M + 1, p):
            phi[k] -= phi[k] // p

# ------------------------------------------------------------
# Prefix sums:
# H(n) = sum_{k<=n} k * phi(k)
# ------------------------------------------------------------

prefix = [0] * (M + 1)

for i in range(1, M + 1):
    prefix[i] = (prefix[i - 1] + i * phi[i]) % MOD

# ------------------------------------------------------------
# Sum of squares:
# 1^2 + 2^2 + ... + n^2
# ------------------------------------------------------------

def sum_sq(n):
    n %= MOD
    return n * (n + 1) % MOD * (2 * n + 1) % MOD * INV6 % MOD

# ------------------------------------------------------------
# Memoized computation of H(n)
# ------------------------------------------------------------

memo = {}

def H(n):
    if n <= M:
        return prefix[n]

    if n in memo:
        return memo[n]

    ans = sum_sq(n)

    l = 2
    while l <= n:
        q = n // l
        r = n // q

        # sum_{i=l}^r i
        block_sum = (l + r) % MOD
        block_sum = block_sum * ((r - l + 1) % MOD) % MOD
        block_sum = block_sum * INV2 % MOD

        ans -= block_sum * H(q)
        ans %= MOD

        l = r + 1

    memo[n] = ans
    return ans

# ------------------------------------------------------------
# Compute:
# F(N) = sum d*phi(d)*floor(N/d)
# using quotient grouping
# ------------------------------------------------------------

def solve(N):
    total = 0

    l = 1
    while l <= N:
        q = N // l
        r = N // q

        total += q * (H(r) - H(l - 1))
        total %= MOD

        l = r + 1

    # S(N) = (N + F(N)) / 2
    return ((total + N) % MOD) * INV2 % MOD

print(solve(N))
```---

 # 4. 代码演练

 ### 菲筛```python
phi = list(range(M + 1))
```初始化$\varphi(n)=n$。 

对于每一个素数$p$,```python
phi[k] -= phi[k] // p
```适用$$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$---

 ### 前缀和```python
prefix[i] = prefix[i - 1] + i * phi[i]
```商店$$H(i)=\sum_{k\le i} k\varphi(k).$$---

 ### 递归$H(n)$递归计算大值$H(n)$大约在$O(\sqrt n)$使用商分组的时间。 

记忆化避免了重新计算。 

---

 ### 最终总结

 循环```python
q = N // l
r = N // q
```将具有相同商的所有索引分组。 

这降低了复杂性$O(N)$粗略地$O(\sqrt N)$。
