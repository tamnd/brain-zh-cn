[项目欧拉问题 96](https://projecteuler.net/problem=96)

 ## 解决方案

 **答案：**`24702`这个问题的关键不是深奥的数论，而是设计一种可靠且高效的精确搜索算法来解决数独难题。 

数独网格是一个**约束满足问题**：

 - 每行必须包含数字$1$–$9$正好一次。 
- 每列必须包含数字$1$–$9$正好一次。 
- 每个$3\times3$方框中必须包含数字$1$–$9$正好一次。 

Project Euler 任务提供 50 个谜题，每个谜题都有独特的解决方案。 对于每个已解决的谜题，我们提取由顶行的前三位数字组成的 3 位数字并将它们相加。 

---

 # 数学分析

 假设一个单元格是空的。 

让：

-$R$= 其行中已使用的数字，
 -$C$= 其列中已使用的数字，
 -$B$= 已在其中使用的数字$3\times3$盒子。 

那么允许的候选人是$$\{1,\dots,9\}\setminus (R\cup C\cup B).$$当每个单元格都只有一个值时，难题就解决了。 

---

 ## 回溯搜索

 一般情况下，纯粹的逻辑推演是不够的，所以我们使用递归搜索。 

### 策略

 1. 找到**最少候选人**的空单元格。 
2. 尝试每个候选者。 
3. 递归。 
4、如果出现矛盾，则原路返回。 

这种“最小剩余值”启发式非常重要，因为它极大地修剪了搜索树。 

---

 # 高效表示

 我们可以使用集合来表示约束。 

对于每一行、每一列和每个方框，保留已使用的数字。 

对于一个细胞$(r,c)$：$$\text{box}(r,c)=3\left\lfloor \frac r3 \right\rfloor+\left\lfloor \frac c3 \right\rfloor.$$根据设置的差异快速计算候选数字。

 # Python 实现```python
from urllib.request import urlopen

# Download the Sudoku file
url = "https://projecteuler.net/project/resources/p096_sudoku.txt"
data = urlopen(url).read().decode().strip().splitlines()

# Parse puzzles
puzzles = []
for i in range(0, len(data), 10):
    grid = [list(map(int, data[i + j + 1])) for j in range(9)]
    puzzles.append(grid)

DIGITS = set(range(1, 10))

def solve(grid):
    """
    Solve a Sudoku puzzle using recursive backtracking
    with minimum-candidate heuristic.
    """

    # Track used digits
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]

    # Initialize constraint sets
    for r in range(9):
        for c in range(9):
            v = grid[r][c]
            if v:
                rows[r].add(v)
                cols[c].add(v)
                boxes[(r // 3) * 3 + (c // 3)].add(v)

    def backtrack():
        best = None
        best_candidates = None

        # Find empty cell with fewest candidates
        for r in range(9):
            for c in range(9):
                if grid[r][c] == 0:
                    b = (r // 3) * 3 + (c // 3)

                    candidates = (
                        DIGITS
                        - rows[r]
                        - cols[c]
                        - boxes[b]
                    )

                    if len(candidates) == 0:
                        return False

                    if best is None or len(candidates) < len(best_candidates):
                        best = (r, c, b)
                        best_candidates = candidates

        # No empty cells => solved
        if best is None:
            return True

        r, c, b = best

        # Try each candidate
        for v in best_candidates:
            grid[r][c] = v
            rows[r].add(v)
            cols[c].add(v)
            boxes[b].add(v)

            if backtrack():
                return True

            # Undo move
            grid[r][c] = 0
            rows[r].remove(v)
            cols[c].remove(v)
            boxes[b].remove(v)

        return False

    backtrack()
    return grid

total = 0

for puzzle in puzzles:
    solved = solve(puzzle)

    # Extract top-left 3-digit number
    value = (
        solved[0][0] * 100
        + solved[0][1] * 10
        + solved[0][2]
    )

    total += value

print(total)
```---

 # 代码演练

 ## 解析文件

 文本文件中的每个谜题都有：

 - 一个标题行，例如`Grid 01`- 随后是 9 行数字。 

我们一次处理 10 行的块。```python
for i in range(0, len(data), 10):
```并将行转换为整数列表。 

---

 ## 约束跟踪

 我们维持：```python
rows = [set() for _ in range(9)]
cols = [set() for _ in range(9)]
boxes = [set() for _ in range(9)]
```这些存储哪些数字已被使用。 

盒子索引为：```python
(r // 3) * 3 + (c // 3)
```赋予价值$0$通过$8$。 

---

 ## 候选计算

 对于空单元格：```python
candidates = DIGITS - rows[r] - cols[c] - boxes[b]
```这直接实现了数独的合法性约束。 

---

 ## 最小候选启发式

 我们首先搜索最难的单元格：```python
if best is None or len(candidates) < len(best_candidates):
```这大大减少了分支。 

---

 ## 递归回溯

 For each candidate:```python
grid[r][c] = v
```我们更新约束、递归并在必要时撤消。 

这保证了精确的解决方案，因为每一种法律可能性都经过系统探索。
