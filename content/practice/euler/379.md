[欧拉项目问题 379](https://projecteuler.net/problem=379)

 ## 解决方案

 **答案：**`132314136838185`让$$f(n)=\#\{(x,y):x,y\in \mathbb Z_{>0},\ x\le y,\ \operatorname{lcm}(x,y)=n\}.$$我们想要$$g(N)=\sum_{n\le N} f(n),$$特别是$g(10^{12})$。 

---

 ## 步骤 1：使用固定 LCM 对数对进行计数

 首先计数**有序**对$(x,y)$这样$$\operatorname{lcm}(x,y)=n.$$写$$n=\prod p_i^{a_i}.$$对于每个素数$p^a$，如果指数$p$在$x,y$是$(u,v)$，那么我们需要$$\max(u,v)=a.$$指数对的数量是$$(a+1)^2-a^2 = 2a+1.$$因此有序对的数量是$$\prod (2a_i+1)=d(n^2),$$在哪里$d(m)$是除数计数函数。 

现在转换为无序对$x\le y$。 

唯一的对称有序对是$(n,n)$， 所以：$$f(n)=\frac{d(n^2)+1}{2}.$$因此$$g(N)=\sum_{n\le N}\frac{d(n^2)+1}{2} =\frac12\sum_{n\le N}d(n^2)+\frac N2.$$所以问题归结为计算$$S(N)=\sum_{n\le N} d(n^2).$$---

 ## 步骤 2：一个有用的身份$d(n^2)$标准身份是$$d(n^2)=\sum_{d\mid n}2^{\omega(d)},$$在哪里$\omega(d)$是不同质因数的数量$d$。 

确实，对于$n=p^a$,$$d(p^{2a})=2a+1,$$尽管$$\sum_{k=0}^{a}2^{\omega(p^k)} =1+2a.$$因此$$S(N)=\sum_{n\le N}\sum_{d\mid n}2^{\omega(d)} =\sum_{d\le N}2^{\omega(d)}\Bigl\lfloor\frac Nd\Bigr\rfloor.$$这是关键总结形式。 

---

 ## 步骤 3：更快的评估

 使用狄利克雷级数$$\sum_{n\ge1}\frac{d(n^2)}{n^s} =\frac{\zeta(s)^3}{\zeta(2s)},$$推导出卷积恒等式$$d(n^2)=\sum_{k^2\mid n}\mu(k)\,d_3\!\left(\frac{n}{k^2}\right),$$在哪里：

-$\mu$是莫比乌斯函数，
 -$d_3(m)$计数代表$abc=m$。 

所以$$S(N) = \sum_{k\le \sqrt N} \mu(k)\, \sum_{m\le N/k^2} d_3(m).$$总结函数为$d_3$可以评估为$O(N^{2/3})$使用双曲线分解的式复杂性。 

这使得$N=10^{12}$计算上可行。 

---

 ## Python 实现```python
import math
from sympy import mobius

N = 10**12

def D3_sum(n):
    """
    Returns:
        sum_{k <= n} d3(k)

    using a 3-dimensional hyperbola decomposition.
    """

    total = 0
    c = int(round(n ** (1/3)))

    while (c + 1) ** 3 <= n:
        c += 1
    while c ** 3 > n:
        c -= 1

    for a in range(1, c + 1):
        s = math.isqrt(n // a)

        total += n // (a * a)

        total += 2 * sum((n // (a * b)) for b in range(a + 1, s + 1))

        total -= s * s

    total += c ** 3

    return total

S = 0

root = math.isqrt(N)

for k in range(1, root + 1):
    S += mobius(k) * D3_sum(N // (k * k))

g = (S + N) // 2

print(g)
```---

 ## 代码演练

 ###`D3_sum(n)`计算$$\sum_{m\le n} d_3(m).$$自从$d_3(m)$数三倍$(a,b,c)$和$abc=m$，求和函数计算满足的三元组$$abc\le n.$$该代码使用对称双曲线分解来有效地计算这些。 

---

 ### 莫比乌斯逆循环```python
for k in range(1, root + 1):
    S += mobius(k) * D3_sum(N // (k * k))
```这实现了$$S(N)=\sum_{k\le \sqrt N}\mu(k)\sum_{m\le N/k^2} d_3(m).$$---

 ### 最后一步

 自从$$g(N)=\frac{S(N)+N}{2},$$最终答案是：```python
g = (S + N) // 2
```---
