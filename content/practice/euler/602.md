[欧拉项目 602 问题](https://projecteuler.net/problem=602)

 ## 解决方案

 **答案：**`269496760`让$q=1-p$是正面的概率。 

我们求系数$c(n,k)$的$p^k$在多项式中$e(n,p)$。 

# 第 1 步：推导期望

 假设爱丽丝有$n$朋友们。 

游戏循环进行：

 - 爱丽丝抛掷，
 - 然后每个朋友抛一次，
 - 重复直到爱丽丝得到头。 

假设爱丽丝在恰好之后得到了她的第一个头$m$以前的失败。 

然后：

 - 爱丽丝制作$m$尾巴后面跟着一个头，
 - 该事件发生的概率：$$p^m q.$$那些期间$m$失败的回合，每个朋友都掷得准确$m$独立次数。 

对于任何朋友$i$,$$X_i \sim \text{Binomial}(m,q),$$所以$$\mathbb E[X_i]=mq.$$既然朋友都是独立的，$$\mathbb E\!\left[\prod_{i=1}^n X_i \,\middle|\, m\right] = (mq)^n.$$所以$$e(n,p) = \sum_{m\ge0} p^m q (mq)^n = q^{n+1}\sum_{m\ge0} m^n p^m.$$因为$q=1-p$,$$e(n,p) = (1-p)^{n+1}\sum_{m\ge0} m^n p^m.$$---

 # 步骤 2：欧拉多项式

 一个经典恒等式指出：$$\sum_{m\ge0} m^n x^m = \frac{A_n(x)}{(1-x)^{n+1}},$$在哪里$A_n(x)$是欧拉多项式。 

因此$$e(n,p)=A_n(p).$$因此系数$c(n,k)$正是欧拉数：$$c(n,k)=\left\langle {n \atop k} \right\rangle .$$标准显式公式是$$\boxed{ c(n,k) = \sum_{i=0}^{k} (-1)^i \binom{n+1}{i} (k-i)^n }.$$我们被要求$$c(10^7,4\cdot10^6)\pmod{10^9+7}.$$---

 # 第三步：高效的模块化计算

 自从$$10^9+7$$是素数并且$n+1 < 10^9+7$，我们可以迭代地计算所有二项式系数的模$M=10^9+7$。 

计算公式为：```python
MOD = 10**9 + 7

n = 10_000_000
k = 4_000_000

# modular inverses up to k+1
inv = [0] * (k + 2)
inv[1] = 1
for i in range(2, k + 2):
    inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

ans = 0
binom = 1   # C(n+1, 0)

for i in range(k + 1):

    term = pow(k - i, n, MOD)

    if i & 1:
        ans -= binom * term
    else:
        ans += binom * term

    ans %= MOD

    # Update:
    # C(n+1, i+1) from C(n+1, i)
    binom = (
        binom
        * (n + 1 - i)
        % MOD
        * inv[i + 1]
        % MOD
    )

print(ans % MOD)
```---

 # Step 4: Verification on the small example

 对于$n=3$,$$e(3,p)=p^3+4p^2+p.$$我们的公式给出：$$c(3,1)=1,\qquad c(3,2)=4,\qquad c(3,3)=1,$$完全符合声明。

 # 步骤5：最终计算

 评估公式模数$10^9+7$给出$$c(10000000,4000000) \equiv 269496760 \pmod{10^9+7}.$$**答案：269496760**
