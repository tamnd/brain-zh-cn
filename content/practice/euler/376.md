[欧拉项目问题 376](https://projecteuler.net/problem=376)

 ## 解决方案

 **答案：**`973059630185670`让$$W(X,Y)=\#\{(x,y)\in X\times Y:x>y\},$$所以对于两个六面骰子$X,Y$,$$P(X\text{ beats }Y)=\frac{W(X,Y)}{36}.$$不可传递的三元组$(A,B,C)$满足$$W(B,A)>18,\qquad W(C,B)>18,\qquad W(A,C)>18.$$由于关系被忽略，这三个不等式等价于循环支配条件。 

---

 ## 1. 对骰子进行编码

 不是显式存储六个面，而是通过多重性对每个骰子进行编码。 

为了$1\le v\le N$， 让$$a_v,b_v,c_v\in\{0,\dots,6\}$$是值出现的次数$v$在骰子上$A,B,C$， 分别。 

他们满足$$\sum_{v=1}^N a_v=\sum_{v=1}^N b_v=\sum_{v=1}^N c_v=6.$$现在定义优势边际$$M_{AB}=W(A,B)-W(B,A),$$

$$M_{BC}=W(B,C)-W(C,B),$$

$$M_{CA}=W(C,A)-W(A,C).$$期望的条件变为$$M_{AB}<0,\qquad M_{BC}<0,\qquad M_{CA}<0.$$---

 # 2.增量过渡公式

 处理点值来自$1$到$N$。 

假设之前的值$v$我们已经放置了：$$A_<,\ B_<,\ C_<$$三个骰子上的面使用较小的值。 

当我们放置$a_v,b_v,c_v$价值的副本$v$，只有与_较小_值的比较才会被重新确定。 

因此保证金更新为：$$\Delta M_{AB}=a_v B_< - b_v A_<,$$

$$\Delta M_{BC}=b_v C_< - c_v B_<,$$

$$\Delta M_{CA}=c_v A_< - a_v C_<.$$这是关键的观察结果：每个步骤仅取决于当前的累积计数，因此动态程序是可能的。 

---

 # 3.动态规划状态

 使用状态$$(A_<,B_<,C_<,M_{AB},M_{BC},M_{CA})$$之间的计数$0$和$6$，以及之间的边距$-36$和$36$。 

对于每个点值$v$，迭代所有选择$$a_v,b_v,c_v\in\{0,\dots,6\}$$总面数不超过六张。 

这算**有序**三元组$(A,B,C)$。 

最后：

 - 仅保留所有三个边距均为负的状态，
 - 除以$3$， 因为$$(A,B,C), (B,C,A), (C,A,B)$$代表同一个循环集。 

（反转不会重复计算，因为相反的方向也不能满足不等式。）

 ---

 # 4.Python实现```python
from collections import defaultdict

def count_nontransitive(N):
    # state:
    # (a_used, b_used, c_used, mab, mbc, mca)

    dp = defaultdict(int)
    dp[(0, 0, 0, 0, 0, 0)] = 1

    for v in range(1, N + 1):
        nxt = defaultdict(int)

        for (au, bu, cu, mab, mbc, mca), ways in dp.items():

            for av in range(7 - au):
                for bv in range(7 - bu):
                    for cv in range(7 - cu):

                        nmab = mab + av * bu - bv * au
                        nmbc = mbc + bv * cu - cv * bu
                        nmca = mca + cv * au - av * cu

                        key = (
                            au + av,
                            bu + bv,
                            cu + cv,
                            nmab,
                            nmbc,
                            nmca,
                        )

                        nxt[key] += ways

        dp = nxt

    total = 0

    for (au, bu, cu, mab, mbc, mca), ways in dp.items():
        if (
            au == bu == cu == 6 and
            mab < 0 and
            mbc < 0 and
            mca < 0
        ):
            total += ways

    # quotient by cyclic rotations
    return total // 3

print(count_nontransitive(7))   # 9780
print(count_nontransitive(30))
```---

 # 5. 样本验证

 对于$N=7$，程序返回$$9780,$$与声明中给出的值匹配。 

运行相同的计算$N=30$给出$$973059630185670.$$这个大小是合理的，因为来自的六重集的数量$1$到$30$已经是$$\binom{35}{6}=1,623,160,$$因此循环非传递三元组的数量自然是巨大的。 

因此最终的结果是：

 **答案：973059630185670**
