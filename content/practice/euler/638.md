[欧拉项目 638 问题](https://projecteuler.net/problem=638)

 ## 解决方案

 **答案：**`18423394`令路径包含$a$正确的步骤和$b$上台阶。 

如果我们根据右步发生的高度对路径进行编码，那么路径下方的面积正是这些高度的总和。 

关键的观察是这是一个**$q$-二项式系数**（高斯二项式）。 

对于一条路径$P_{a,b}$,$$C(a,b,k) = \sum_{P_{a,b}} k^{A(P)}$$是按面积加权的晶格路径的生成函数。 这是经典恒等式：$$C(a,b,k) = \binom{a+b}{a}_k = \prod_{i=1}^{a} \frac{k^{b+i}-1}{k^i-1}.$$这是因为单调格路径上的面积统计对应于逆计数/费雷尔图面积，其生成函数是高斯二项式。 

为了$k=1$，表达式变为普通二项式系数：$$C(a,b,1)=\binom{a+b}{a},$$与给定的示例匹配：$$C(10,10,1)=\binom{20}{10}=184756.$$我们可以验证另一个样本：$$C(15,10,3) = \prod_{i=1}^{15} \frac{3^{10+i}-1}{3^i-1} \equiv 880419838 \pmod{10^9+7},$$与声明相符。 

### 高效算法

 我们需要$$\sum_{k=1}^{7} C(10^k+k,10^k+k,k) \pmod{10^9+7}.$$自从$$C(n,n,k) = \prod_{i=1}^{n} \frac{k^{n+i}-1}{k^i-1},$$我们以迭代方式评估乘积$$M=1\,000\,000\,007.$$因为$M$是素数，除法是使用模逆来完成的：$$x^{-1}\equiv x^{M-2}\pmod M.$$Python实现：```python
MOD = 1_000_000_007

def C(a, b, k):
    # Special case q = 1:
    # ordinary binomial coefficient C(a+b, a)
    if k == 1:
        res = 1
        for i in range(1, a + 1):
            res = res * (b + i) % MOD
            res = res * pow(i, MOD - 2, MOD) % MOD
        return res

    q = k % MOD
    q_to_b = pow(k, b, MOD)

    res = 1
    q_pow_i = 1

    # Product:
    # ∏_{i=1}^{a} (k^(b+i)-1)/(k^i-1)
    for i in range(1, a + 1):
        q_pow_i = q_pow_i * q % MOD

        numerator = (q_to_b * q_pow_i - 1) % MOD
        denominator = (q_pow_i - 1) % MOD

        res = (
            res
            * numerator
            % MOD
            * pow(denominator, MOD - 2, MOD)
            % MOD
        )

    return res

answer = 0

for k in range(1, 8):
    n = 10**k + k
    answer = (answer + C(n, n, k)) % MOD

print(answer)
```### 代码演练

 -`C(a, b, k)`计算加权格路径和。 
- 如果`k == 1`，我们计算普通二项式系数$\binom{a+b}{a}$。 
- 否则我们使用高斯二项式乘积公式。 
-`q_pow_i`商店$k^i$逐渐地。 
- 每个因素$$\frac{k^{b+i}-1}{k^i-1}$$乘以模$10^9+7$，使用费马逆。 

健全性检查：

 -`C(2,2,1) = 6`-`C(2,2,2) = 35`-`C(10,10,1) = 184756`-`C(15,10,3) ≡ 880419838 (mod 10^9+7)`-`C(10000,10000,4) ≡ 395913804 (mod 10^9+7)`全部与问题陈述相符。 

计算值$k=1,\dots,7$总和为：$$18\,423\,394 \pmod{1\,000\,000\,007}.$$**答案：18423394**
