[欧拉项目问题 172](https://projecteuler.net/problem=172)

 ## 解决方案

 **答案：**`227485267000992000`我们必须计算 18 位数字，其中没有数字出现超过 3 次。 

设数字为$0,1,\dots,9$。 

我们求长度为 18 的字符串的数量：

 - 第一个数字非零，
 - 每个数字最多使用 3 次。 

这是一个有约束的多项式计数问题。 

---

 # 1.数学分析

 假设数字$i$发生$a_i$时间、地点$$0 \le a_i \le 3, \qquad \sum_{i=0}^9 a_i = 18.$$如果算的话$(a_0,\dots,a_9)$是固定的，那么：

 - 18位数字的总排列：$$\frac{18!}{a_0!a_1!\cdots a_9!}$$- 但有些开始于$0$，这是禁止的。 

## 计算没有前导零的排列

 如果$a_0=0$，则所有安排均有效。 

如果$a_0>0$，通过首先固定非零数字来计算有效排列。 

更清洁的方法是：$$\text{valid} = \frac{18!}{\prod a_i!} - \frac{17!}{(a_0-1)!\prod_{i=1}^9 a_i!}.$$将第二项因式分解：$$\frac{17!}{(a_0-1)!\prod_{i=1}^9 a_i!} = \frac{17!a_0}{\prod a_i!}.$$因此$$\text{valid} = \frac{17!(18-a_0)}{\prod a_i!}.$$由于有 9 个非零数字，$18-a_0 = a_1+\cdots+a_9$，完全符合预期。 

因此总的答案是$$\boxed{ \sum_{\substack{a_0+\cdots+a_9=18\\0\le a_i\le3}} \frac{17!(18-a_0)}{a_0!a_1!\cdots a_9!} }$$这是有限的，因为每个$a_i\in\{0,1,2,3\}$。 

---

 ## 生成函数观点

 分母结构暗示了生成函数。 

对于数字$1$–$9$， 定义$$f(x)=1+x+\frac{x^2}{2!}+\frac{x^3}{3!}.$$对于前导零校正，我们需要$$g(x)=1+\frac{x}{1!}+\frac{x^2}{2!}.$$为什么？ 因为乘以$a_0$皈依者$$\frac{a_0}{a_0!}=\frac1{(a_0-1)!}.$$然后$$\sum \frac{18-a_0}{\prod a_i!} = 9 \,[x^{17}]\, g(x)f(x)^9.$$最后，$$N = 17!\cdot 9 \cdot [x^{17}]\,g(x)f(x)^9.$$这很优雅，但对于实现来说，直接枚举所有计数向量是最简单的。

 # 2.Python实现```python
from math import factorial
from itertools import product

# Precompute factorials
fact = [factorial(i) for i in range(19)]

total = 0

# Each digit count can be 0,1,2,3
# Enumerate all 4^10 possibilities
for counts in product(range(4), repeat=10):

    # Total digits must be 18
    if sum(counts) != 18:
        continue

    a0 = counts[0]

    # Compute denominator product a0! a1! ... a9!
    denom = 1
    for c in counts:
        denom *= fact[c]

    # Number of valid 18-digit numbers for this count pattern
    ways = fact[17] * (18 - a0) // denom

    total += ways

print(total)
```---

 # 4.小型健全性检查

 对于较小的玩具版本：

 - 2 位数字，
 - 没有数字重复一次以上，

 计数应该是：

 - 第一个数字：9 个选择，
 - 第二位数字：剩余 9 个选择，

 所以$9\times 9=81$。 

相同的多项式方法准确地再现了这一点。

 # 5.最终验证

 18位数字的个数不受限制的是$$9\times10^{17}.$$我们的限制（“数字不能超过三倍”）删除了很多数字，但仍然留下了很大的比例，所以答案应该仍然是这样的$10^{17}$。 

计算值是：$$227485267000992000$$这确实是正确的大小。
