[欧拉项目问题 342](https://projecteuler.net/problem=342)

 ## 解决方案

 **答案：**`5943040885644`让$$n=\prod_{p} p^{a_p}.$$我们想要全部$1<n<10^{10}$这样$\phi(n^2)$是一个完美的立方体。 

关键是要理解素数指数$\phi(n^2)$。 

---

 # 1.数学分析

 我们使用$$\phi(p^k)=p^{k-1}(p-1),$$所以$$\phi(n^2) =\prod_p \phi\!\left(p^{2a_p}\right) =\prod_p p^{2a_p-1}(p-1).$$等价地，$$\phi(n^2)=n\phi(n).$$条件是：

 > 中的每个素数指数$\phi(n^2)$必须能整除$3$。 

---

 ## 质数指数方程

 让$$R=\operatorname{rad}(n)=\prod_{p\mid n} p$$（无平方核$n$）。 

定义$$d_q = v_q(\phi(R))      = v_q\!\left(\prod_{p\mid R}(p-1)\right).$$现在检查素数的指数$q$里面$\phi(n^2)$。 

---

 ### 案例 1：$q\mid n$认为$q^{a_q}\parallel n$。 然后：

-$q^{2a_q-1}$来自$\phi(q^{2a_q})$,
 - 额外的权力$q$来自因素$(p-1)$对于其他素数$p\mid n$。 

因此$$v_q(\phi(n^2)) = 2a_q-1+d_q.$$我们要求它可以被整除$3$:$$2a_q-1+d_q \equiv 0 \pmod 3.$$自从$2^{-1}\equiv 2 \pmod 3$,$$a_q \equiv 2+d_q \pmod 3.$$那么一次$R$是固定的，每个素数除法的指数$n$被确定为模$3$。 

因此最小的正指数是$$r_q= \begin{cases} 1,& d_q\equiv 2 \pmod 3,\\ 2,& d_q\equiv 0 \pmod 3,\\ 3,& d_q\equiv 1 \pmod 3. \end{cases}$$---

 ### 案例 2：$q\nmid n$那么唯一的贡献来自于$\phi(R)$，所以我们需要$$d_q \equiv 0 \pmod 3.$$因此，出现在的每个“外部”素数$\prod(p-1)$必须出现在可被整除的指数上$3$。 

---

 # 2.所有解决方案的结构

 一旦激进$R$是固定的：

 - 每个素数$p\mid R$有一个最小指数$r_p\in\{1,2,3\}$,
 - 添加多个$3$到指数保留立方条件。 

所以每个解都有形式$$n=n_0\prod_{p\mid R} p^{3k_p},$$在哪里$$n_0=\prod_{p\mid R} p^{r_p}.$$因此问题简化为：

 1. 枚举所有允许的部首$R$,
 2. 计算最小基数$n_0$,
 3. 乘以任意素数的立方$R$,
 4. 保持数值低于$10^{10}$。 

---

 # 3.高效的搜索策略

 我们递归地构建部首$R$。 

添加新素数时$q$:

 - 更新因式分解$\phi(R)$使用因式分解$q-1$,
 - 重新计算最小可能值$n_0$,
 - 修剪如果$n_0>10^{10}$。 

一个关键的界限：

 - 中最大的素数$R$总是有指数$2$,
 - 因此每个素数$R$至多是$10^5$。 

所以搜索空间很小。 

---

 # 4.Python实现```python
from sympy import primerange, factorint

LIMIT = 10**10

# All primes that could possibly appear.
# The largest prime must appear with exponent at least 2,
# so p^2 < LIMIT => p < 1e5.
primes = list(primerange(2, 100000))

# Precompute factorizations of p - 1
fac = {p: factorint(p - 1) for p in primes}

solutions = set()

def minimal_base(R, d):
    """
    Given:
        R = set of primes dividing n
        d[q] = exponent of q in phi(R) modulo 3

    compute the smallest possible n having radical R.
    """
    n0 = 1

    for p in R:
        r = (2 + d.get(p, 0)) % 3

        # residue 0 means exponent 3
        if r == 0:
            r = 3

        n0 *= p ** r

        if n0 > LIMIT:
            return n0

    return n0

def generate_all_from_base(base, prime_list, idx=0):
    """
    From the minimal solution, multiply by arbitrary cubes
    of existing primes.
    """
    if base > LIMIT:
        return

    if idx == len(prime_list):
        solutions.add(base)
        return

    p = prime_list[idx]

    value = base
    while value <= LIMIT:
        generate_all_from_base(value, prime_list, idx + 1)
        value *= p ** 3

def dfs(start, R, d):
    """
    Recursive generation of admissible radicals.
    """
    n0 = minimal_base(R, d)

    if n0 > LIMIT:
        return

    # Check external-prime condition:
    # every prime not in R must have exponent 0 mod 3.
    ok = True
    for q, v in d.items():
        if q not in R and v % 3 != 0:
            ok = False
            break

    # If valid, generate all solutions from this radical
    if ok and R:
        generate_all_from_base(
            n0,
            sorted(R)
        )

    # Try adding larger primes
    for i in range(start, len(primes)):
        q = primes[i]

        # Safe pruning:
        # any new prime contributes at least q^2 overall.
        if n0 * q * q > LIMIT:
            break

        R2 = set(R)
        R2.add(q)

        d2 = dict(d)

        # Update d using factorization of q-1
        for p, e in fac[q].items():
            d2[p] = (d2.get(p, 0) + e) % 3

        dfs(i + 1, R2, d2)

dfs(0, set(), {})

answer = sum(solutions)

print(answer)
```---

 ## 预计算```python

```我们反复需要对$p-1$，所以我们计算它们一次。

 ## 字典`d`

`d[q]`商店$$v_q(\phi(R)) \pmod 3.$$添加素数时$p$对于根式，我们乘以$\phi(R)$经过$p-1$，所以我们只需添加因式分解$p-1$模数$3$。 

---

 ## 最小指数```python
r = (2 + d.get(p, 0)) % 3
```这实现了$$a_p \equiv 2+d_p \pmod 3.$$如果残留物是$0$，最小的正指数是$3$。 

---

 ## 外部素数条件```python
if q not in R and v % 3 != 0:
```任何不能整除的素数$n$必须已经出现在可被整除的指数上$3$在$\phi(R)$。 

---

 ## 立方乘数

 一旦最小解$n_0$找到后，我们可以添加任意倍数$3$到指数，即乘以现有素数的立方。 

---

 # 6. 小型健全性检查

 声明中的示例：$$50 = 2^1 \cdot 5^2.$$然后$$\phi(50^2)=\phi(2500)=1000=10^3.$$正确的。 

另一个例子：$$225=3^2\cdot 5^2.$$然后$$\phi(225^2) = 2^3\cdot 3^3\cdot 5^3 = 30^3.$$也正确。
