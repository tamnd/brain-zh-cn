[欧拉项目问题 123](https://projecteuler.net/problem=123)

 ## 解决方案

 **答案：**`21035`让$$r_n = (p_n-1)^n + (p_n+1)^n \pmod{p_n^2},$$在哪里$p_n$是$n$-th素数。 

我们追求最少$n$这样$$r_n > 10^{10}.$$---

 # 数学分析

 关键的观察是使用二项式定理可以大大简化表达式。 

让$p=p_n$。 

我们扩展：$$(p+1)^n = \sum_{k=0}^{n} \binom{n}{k} p^k$$和$$(p-1)^n = \sum_{k=0}^{n} \binom{n}{k} p^k(-1)^{n-k}.$$我们只关心模数$p^2$，所以每个项包含$p^2$或更高消失。 

因此取模$p^2$,$$(p+1)^n \equiv 1 + np$$和$$(p-1)^n \equiv (-1)^n + n(-1)^{n-1}p.$$添加：$$r_n \equiv (1+(-1)^n) + np\left(1+(-1)^{n-1}\right)\pmod{p^2}.$$现在分为奇偶校验情况。 

## 情况 1：$n$甚至

 然后$$(-1)^n=1,\qquad (-1)^{n-1}=-1.$$所以$$r_n \equiv 2 + np(1-1)=2 \pmod{p^2}.$$因此对于即使$n$,$$r_n = 2.$$这永远不能超过$10^{10}$。 

---

 ## 情况2：$n$奇数

 然后$$(-1)^n=-1,\qquad (-1)^{n-1}=1.$$所以$$r_n \equiv 0 + np(1+1)=2np \pmod{p^2}.$$因此，对于奇数$n$,$$r_n = 2p_n n$$（只要$2np_n < p_n^2$，这在相关范围内是正确的）。 

所以问题归结为寻找最小的奇数$n$这样$$2n p_n > 10^{10}.$$---

 ## 估计范围

 使用素数定理，$$p_n \sim n\log n.$$因此$$2n p_n \sim 2n^2\log n.$$我们大约求解：$$2n^2\log n \approx 10^{10}.$$这表明$n$就在附近$2\times 10^4$。 

我们现在精确计算。 

---

 # Python 实现```python
from math import isqrt

LIMIT = 10**10

def generate_primes(limit_count):
    """
    Generate the first 'limit_count' primes using
    a standard incremental primality test.
    """
    primes = [2]
    candidate = 3

    while len(primes) < limit_count:
        is_prime = True
        root = isqrt(candidate)

        for p in primes:
            if p > root:
                break
            if candidate % p == 0:
                is_prime = False
                break

        if is_prime:
            primes.append(candidate)

        candidate += 2

    return primes

# We know the answer is around 2e4, so 30000 primes is plenty.
primes = generate_primes(30000)

answer = None

for n in range(1, len(primes) + 1, 2):   # only odd n matter
    p = primes[n - 1]                    # p_n (1-indexed)

    remainder = 2 * n * p

    if remainder > LIMIT:
        answer = n
        break

print(answer)
```---

 # 实例验证

 对于$n=3$：

 -$p_3 = 5$- 公式给出$$r = 2 \cdot 3 \cdot 5 = 30.$$模数$25$,$$30 \equiv 5 \pmod{25},$$匹配问题陈述：$$4^3 + 6^3 = 280 \equiv 5 \pmod{25}.$$正确的。 

另外，问题说得最少$n$为了$10^9$是$7037$。 代入公式：$$2 \cdot 7037 \cdot p_{7037}$$确实首先超过$10^9$，确认一致性。
