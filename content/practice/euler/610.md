[项目欧拉问题 610](https://projecteuler.net/problem=610)

 ## 解决方案

 **答案：**`319.30207833`让$E(s)$表示当当前写入的字符串是罗马数字前缀时预期的最终值$s$。 

关键的观察是：

 - 如果附加字母使字符串保持_最小_罗马数字的有效前缀，我们将进入新状态。 
- 否则该字母将被忽略。 
- 什么时候`#`出现（概率$0.02$），我们立即停下来。 

最小形式的罗马数字有标准的分解$$M^a \cdot H \cdot T \cdot O$$在哪里：

-$a \ge 0$,
 -$H \in \{ "", C, CC, CCC, CD, D, DC, DCC, DCCC, CM \}$,
 -$T \in \{ "", X, XX, XXX, XL, L, LX, LXX, LXXX, XC \}$,
 -$O \in \{ "", I, II, III, IV, V, VI, VII, VIII, IX \}$。 

因此，有效数字的整个语言是有限前缀自动机，除了无界前导$M$的。 

---

 # 1. 复发

 假设一个州$s$有价值$v(s)$， 和$k$接下来的字母有效。 

然后$$E(s) = 0.02\,v(s) + 0.14\sum_{t} E(t) + (0.98-0.14k)E(s)$$其中总和涵盖所有有效的下一个状态$t$。 

重新排列：$$(0.02+0.14k)E(s) = 0.02\,v(s)+0.14\sum_t E(t)$$并除以$0.02$,$$(1+7k)E(s) = v(s)+7\sum_t E(t).$$因此$$\boxed{ E(s)=\frac{v(s)+7\sum_t E(t)}{1+7k} }$$对于每个非空后缀状态。 

---

 # 2. 处理无限$M$-链

 设当前数字为$$M^a s$$在哪里$s$不包含$M$。 

写$$E(M^a s)=1000a+F(s).$$代入递归式显示出对$a$完全取消，留下后缀状态的有限系统$s$。 

对于空后缀状态：$$F(\varepsilon) = \frac{7000+7\sum F(t)}{43}$$其中总和超过六个单字母开头$$I,V,X,L,C,D.$$所有其他状态都满足上述有限递归。 

---

 # 3.Python实现```python
from functools import lru_cache

# Minimal Roman blocks
ones = ["", "I", "II", "III", "IV",
        "V", "VI", "VII", "VIII", "IX"]

tens = ["", "X", "XX", "XXX", "XL",
        "L", "LX", "LXX", "LXXX", "XC"]

hundreds = ["", "C", "CC", "CCC", "CD",
            "D", "DC", "DCC", "DCCC", "CM"]

# All minimal numerals from 0..999
nums = [
    hundreds[h] + tens[t] + ones[o]
    for h in range(10)
    for t in range(10)
    for o in range(10)
]

# Value of each suffix numeral
value = {}
prefixes = {""}

for n, s in enumerate(nums):
    value[s] = n
    for i in range(len(s) + 1):
        prefixes.add(s[:i])

letters = "IVXLCD"

# Valid transitions
trans = {}

for p in prefixes:
    nxt = []
    for ch in letters:
        q = p + ch
        if q in prefixes:
            nxt.append(q)
    trans[p] = nxt

# Solve backwards by decreasing length
states = sorted(prefixes, key=len, reverse=True)

F = {}

for s in states:
    if s == "":
        continue

    k = len(trans[s])

    F[s] = (
        value[s]
        + 7 * sum(F[t] for t in trans[s])
    ) / (1 + 7 * k)

# Empty state:
# one transition to another M,
# six transitions to I,V,X,L,C,D
F0 = (
    7000
    + 7 * sum(F[t] for t in trans[""])
) / 43

print("{:.8f}".format(F0))
```---

 结果是合理的：
