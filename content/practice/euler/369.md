[欧拉项目问题 369](https://projecteuler.net/problem=369)

 ## 解决方案

 **答案：**`862400558448`我们按照 13 个等级对每手牌进行建模。 

对于每个等级，我们可以选择 4 个花色的任何子集（包括空花色），因此每个等级贡献 16 个花色子集之一。 

一个$4$-card Badugi 存在，当且仅当我们可以选择四个 **不同的等级** 一次覆盖所有四种花色 - 等效地，在等级和花色之间的二部图中，存在大小匹配$4$。 

以下 Python 程序对所有等级配置执行动态编程搜索，同时跟踪可实现哪些花色匹配。```
from collections import defaultdict
from functools import lru_cache

# All possible suit subsets for a rank:
# bit 0 = clubs, bit 1 = diamonds, bit 2 = hearts, bit 3 = spades
subs = list(range(16))

# Number of cards represented by each subset
sizes = [bin(x).count("1") for x in subs]

@lru_cache(None)
def trans(A, T):
    """
    A = bitmask describing which suit-sets can already be matched.
        If bit M is set, then suit-set M is achievable.

    T = suit subset available for the current rank.

    Return updated achievable mask after processing this rank.
    """
    reachable = [i for i in range(16) if (A >> i) & 1]

    B = A

    # Use current rank to extend a matching by one suit
    for M in reachable:
        for s in range(4):
            if (T >> s) & 1 and not ((M >> s) & 1):
                B |= 1 << (M | (1 << s))

    return B

# Initial state:
# only the empty matching is achievable
dp = {(1 << 0, 0): 1}

# Process all 13 ranks
for _ in range(13):
    nd = defaultdict(int)

    for (A, n), cnt in dp.items():
        for T in subs:
            nd[(trans(A, T), n + sizes[T])] += cnt

    dp = nd

# f[n] = number of n-card hands containing a Badugi
f = [0] * 53

for (A, n), cnt in dp.items():
    # bit 15 means all 4 suits can be matched
    if (A >> 15) & 1:
        f[n] += cnt

answer = sum(f[n] for n in range(4, 14))

print("f(5) =", f[5])
print("Answer =", answer)
```### 代码的作用

 - 每个等级独立选择一组花色。 
-`A`使用不同的排名跟踪当前可匹配的所有花色组合。 
- 处理新的排名子集时`T`，我们可以通过添加一套未使用的套装来扩展任何先前的匹配`T`。 
- 如果套装`1111₂ = 15`变为可达，则存在完整的 4 套匹配，这意味着这手牌包含巴杜吉 (Badugi)。 
- 我们按手总大小累积计数$n$。 

### 验证

 该程序重现问题陈述中给出的值：$$f(5)=514800$$这证实了正确性。 

计算出的总数为：$$\sum_{n=4}^{13} f(n) = 862400558448$$**答案：862400558448**
