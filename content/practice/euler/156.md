[欧拉项目问题 156](https://projecteuler.net/problem=156)

 ## 解决方案

 **答案：**`21295121502550`让$$f(n,d)=\text{number of occurrences of digit }d\text{ in }1,2,\dots,n.$$我们必须计算$$\sum_{d=1}^9 s(d), \qquad s(d)=\sum_{n:\,f(n,d)=n} n.$$关键的困难在于解决方案非常庞大（最多大约$10^{11}$–$10^{13}$），所以暴力破解是不可能的。 

---

 # 1.数学分析

 对于固定数字$d$， 定义$$g_d(n)=f(n,d)-n.$$我们寻求所有零点$g_d(n)$。 

---

 ## 有效地计算数字出现次数

 对于小数点位置$10^k$， 让

-`higher`= 当前位置左边的数字，
 -`current`= 当前位置的数字，
 -`lower`= 当前位置右侧的数字。 

那么这个职位的贡献$f(n,d)$是：$$\begin{cases} (higher+1)\cdot 10^k, & current>d,\\[4pt] higher\cdot 10^k + lower +1, & current=d,\\[4pt] higher\cdot 10^k, & current<d. \end{cases}$$对所有小数位求和得出$f(n,d)$在$O(\log n)$。 

---

 ## 结构$g_d(n)$观察：$$g_d(n+1)-g_d(n) = (\text{number of }d\text{'s in }n+1)-1.$$因此：

 - 功能变化缓慢，
 - 在连续整数之间最多可以减少$1$。 

这给出了一个关键的区间剪枝规则。 

假设我们检查一个区间$[a,b]$。 

如果$$g_d(a) > b-a,$$然后甚至减少最大可能的量（$-1$每一步），函数无法达到$0$区间内。 

同样，如果$$g_d(b) < a-b,$$那么该函数无法爬回$0$。 

因此这样的区间不包含解。 

这允许在巨大范围内进行分而治之的搜索。

 # 2.Python实现```python
from functools import lru_cache

def count_digit(n, d):
    """Count occurrences of digit d in 1..n."""
    if n <= 0:
        return 0

    count = 0
    factor = 1

    while factor <= n:
        higher = n // (factor * 10)
        current = (n // factor) % 10
        lower = n % factor

        if current > d:
            count += (higher + 1) * factor
        elif current == d:
            count += higher * factor + lower + 1
        else:
            count += higher * factor

        factor *= 10

    return count

@lru_cache(None)
def g(n, d):
    return count_digit(n, d) - n

def solve_digit(d, limit=10**13):
    """
    Find all n such that f(n,d)=n.
    Uses recursive interval pruning.
    """
    solutions = []

    def search(a, b):
        ga = g(a, d)
        gb = g(b, d)

        # Impossible to hit zero inside interval
        if ga > (b - a):
            return

        if gb < (a - b):
            return

        # Small interval: check directly
        if b - a <= 1:
            if ga == 0:
                solutions.append(a)

            if b != a and gb == 0:
                solutions.append(b)

            return

        mid = (a + b) // 2

        search(a, mid)
        search(mid + 1, b)

    search(0, limit)

    return sorted(set(solutions))

total = 0

for d in range(1, 10):
    sols = solve_digit(d)
    sd = sum(sols)

    print(f"d={d}")
    print("solutions:", sols[:10], "...")
    print("s(d) =", sd)
    print()

    total += sd

print("FINAL =", total)
```---

 # 3. 代码演练

 ##`count_digit`这计算$f(n,d)$逐个数字位置。 

示例$n=12,d=1$:

 数字：$$1,10,11,12$$包含$1+1+2+1=5$的，所以：$$f(12,1)=5.$$该函数返回的正是这个。 

---

 ##`g(n,d)`我们定义$$g(n,d)=f(n,d)-n.$$解决方案恰好在以下情况下出现：$$g(n,d)=0.$$---

 ## 递归区间搜索

 对于每个间隔$[a,b]$：

- 评价$g(a)$和$g(b)$,
 - 修剪不可能的间隔，
 -否则分成两半。 

由于修剪非常强烈，实际上只需探索巨大范围中的一小部分。
