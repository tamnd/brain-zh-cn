[项目欧拉问题 191](https://projecteuler.net/problem=191)

 ## 解决方案

 **答案：**`1918080160`设长度为有效（“奖品”）的出勤字符串$n$满足：

 - 没有连续三个$A$的，
 - 最多一个$L$。 

我们必须计算这样的字符串$n=30$。 

---

 # 步骤 1 — 重新表述问题

 每天可以是：

 -$O$=准时，
 -$A$=缺席，
 -$L$= 迟到了。 

限制条件是：

 1.没有子串$AAA$,
 2. 最多一个$L$。 

这是一个经典的有限状态动态规划问题。 

解决这个问题的一个干净方法是：

 - 首先计算带有 **no 的字符串$L$**,
 - 然后插入一个$L$。 

---

 # 步骤 2 — 计算没有的字符串$L$定义：$$f(n)=\text{number of length-}n\text{ strings using only }O,A$$没有连续三​​个$A$的。 

我们推导出一个递归式。 

长度有效的字符串$n$必须以以下之一结尾：

 -$O$,
 -$AO$,
 -$AAO$,
 - 或者可能全部$A$如果足够短的话。 

更系统地：

 如果字符串以以下形式结尾：

 -$O$: 前一部分贡献$f(n-1)$,
 -$AO$: 前一部分贡献$f(n-2)$,
 -$AAO$: 前一部分贡献$f(n-3)$。 

因此对于$n\ge3$,$$f(n)=f(n-1)+f(n-2)+f(n-3).$$这是 Tribonacci 重现。 

初始值：$$f(0)=1$$（空字符串）$$f(1)=2$$($O,A$）$$f(2)=4$$($OO,OA,AO,AA$）

所以：$$f(3)=4+2+1=7.$$事实上，唯一无效的长度为 3 的字符串是$AAA$。 

---

 # 第 3 步 — 介绍单曲$L$现在计算奖品字符串最多有一个$L$。 

两种情况：

 ---

 ## 情况 1：否$L$简单来说有：$$f(30)$$这样的字符串。 

---

 ## 情况 2：恰好一个$L$放置$L$在位置$k$($1\le k\le 30$）。 

然后：

 - 左侧有长度$k-1$,
 - 右侧有长度$30-k$,

 并且双方都是独立有效的$L$字符串。 

所以计数是：$$\sum_{k=1}^{30} f(k-1)f(30-k).$$因此奖品串总数为$$P(30)=f(30)+\sum_{k=1}^{30} f(k-1)f(30-k).$$等效地：$$P(30)=f(30)+\sum_{i=0}^{29} f(i)f(29-i).$$---

 # 第 4 步 — Python 实现```python
def prize_strings(n):
    # f[i] = number of valid strings of length i
    # using only O and A, with no AAA
    f = [0] * (n + 1)

    # Base cases
    f[0] = 1
    if n >= 1:
        f[1] = 2
    if n >= 2:
        f[2] = 4

    # Tribonacci recurrence
    for i in range(3, n + 1):
        f[i] = f[i - 1] + f[i - 2] + f[i - 3]

    # Case 1: no L
    total = f[n]

    # Case 2: exactly one L
    for i in range(n):
        total += f[i] * f[n - 1 - i]

    return total

# Verify the example in the problem
print(prize_strings(4))   # should be 43

# Compute the required answer
print(prize_strings(30))
```---

 # 第 5 步 — 代码演练

 ## 构建数组`f`

```python
f = [0] * (n + 1)
```存储有效的数量$L$各长度的字符串。 

---

 ## 基本情况```python
f[0] = 1
f[1] = 2
f[2] = 4
```这些对应于：

 - 长度0：空字符串，
 - 长度1：$O,A$,
 - 长度 2：所有四个二进制字符串。 

---

 ## 复发```python
f[i] = f[i - 1] + f[i - 2] + f[i - 3]
```有效的字符串结尾为：

 -$O$,
 -$AO$,
 -$AAO$。 

- -

＃＃ 不-$L$贡献```python
total = f[n]
```计算所有有效字符串，没有任何迟到的天数。 

---

 ## 正好一个$L$

```python
for i in range(n):
    total += f[i] * f[n - 1 - i]
```选择在哪里$L$去。 

- 左侧长度=$i$,
 - 右侧长度 =$n-1-i$。 

乘法是因为两边独立。

 # 第 7 步 — 计算$n=30$递归产生：$$f(30)=53798080$$添加一后$L$案例：$$P(30)=1918080160.$$这个幅度是合理的：
