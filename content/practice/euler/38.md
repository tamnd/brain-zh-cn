[欧拉项目问题 38](https://projecteuler.net/problem=38)

 ## 解决方案

 **答案：**`932718654`我们寻找由连接形成的最大的9位泛数字$$x \times 1,\; x \times 2,\; \dots,\; x \times n$$对于某个整数$x$还有一些$n>1$。 

如果一个数字使用每个数字，则它是 **1 到 9 的泛数字**$1,2,\dots,9$正好一次。 

---

 # 数学分析

 让$$P(x,n)=\text{concat}(x,2x,3x,\dots,nx).$$我们想要尽可能最大的$P(x,n)$那：

 1. 恰好有 9 位数字，
 2. 包含数字$1$–$9$恰好一次，
 3.用途$n>1$。 

---

 ## 第 1 步：限制大小$x$认为$x$有$d$数字。 

因为我们连接了至少两个数字 ($n>1$)，总长度必须为 9。 

### 如果$d=5$然后：

-$x\times1$已经有5位数字了，
 -$x\times2$至少有 5 位数字，

 所以串联至少有 10 位数字。 

不可能的。 

- -

＃＃＃ 如果$d=4$然后串联$x$和$2x$给出：

 -$4+4=8$数字，或
 -$4+5=9$数字。 

为了得到 9 位数字，我们需要：$$\text{len}(x)=4,\qquad \text{len}(2x)=5.$$因此$x\ge 5000$。 

另外，由于我们想要_最大_泛数字，因此 4 位前缀是有利的，因为串联以$x$本身。 

因此，最优解很可能是 4 位值$n=2$。 

---

 ## 第二步：搜索策略

 我们测试整数$x$并形成：$$s = \text{str}(x) + \text{str}(2x) + \cdots$$直到连接的字符串长度至少为 9。 

然后检查：

 - 长度正好是 9，
 - 数字准确无误$\{1,2,\dots,9\}$。 

快速泛数字测试是：```python
set(s) == set("123456789")
```和`len(s) == 9`。 

---

 ## 步骤 3：关于最大值的原因

 因为连接的数字以$x$，最大化结果意味着最大化前导数字。 

在 4 位候选中，我们从 9876 开始向下搜索。 

已知的强力候选人：$$9327 \times (1,2)$$给出$$9327\;18654 = 932718654.$$使用的数字：$$1,2,3,4,5,6,7,8,9$$正好一次。 

所以这就是泛数字化。 

然后我们验证不存在更大的有效候选者。 

---

 # Python 实现```python
def is_pandigital_1_to_9(s):
    """
    Return True if s contains each digit 1-9 exactly once.
    """
    return len(s) == 9 and set(s) == set("123456789")

largest = 0

# Try possible base integers
for x in range(1, 10000):

    concatenated = ""
    n = 1

    # Keep appending x*n until length reaches 9
    while len(concatenated) < 9:
        concatenated += str(x * n)
        n += 1

    # Check if we formed a valid pandigital number
    if is_pandigital_1_to_9(concatenated):
        largest = max(largest, int(concatenated))

print(largest)
```---

$$192\times2=384$$

$$192\times3=576$$级联：$$192384576$$这就是泛数字化。 

---

 ## 示例2

 对于$x=9$：$$9\times(1,2,3,4,5)$$给出：$$918273645$$也是泛数字。

 ## 最大候选者

 搜索发现：$$932718654$$生成者：$$9327 \times (1,2)$$自从：$$9327 \times 1 = 9327$$

$$9327 \times 2 = 18654$$级联：$$932718654$$这是 1-9 泛数字。 

不存在更大的有效串联积。
