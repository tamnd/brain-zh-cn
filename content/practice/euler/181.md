[Project Euler Problem 181](https://projecteuler.net/problem=181)

 ## 解决方案

 **答案：**`83735848679360680`让一个**组**仅通过它包含多少个黑色和白色对象来描述。 

所以组类型是一对$$(b,w)\neq(0,0)$$意味着该组包含$b$黑色物体和$w$白色物体。 

我们必须计算这些组的多重集的数量，其总数为$$(60,40).$$例如，与$3$黑色和$1$白色物体，这七种可能性恰好是七个多重对的总和$(3,1)$。 

---

 # 1.数学分析

 这是一个二维划分问题。 

---

 ## 生成函数

 对于每种可能的团体类型$(b,w)\neq(0,0)$，我们可以使用该类型：

 - 零次，
 - 有一次，
 - 两次，
 - 等

 因此它对生成函数的贡献是$$1+x^b y^w+x^{2b}y^{2w}+\cdots = \frac1{1-x^b y^w}.$$乘以所有可能的非零对给出$$F(x,y) = \prod_{(b,w)\neq(0,0)} \frac1{1-x^b y^w}.$$所需答案是系数$$x^{60}y^{40}.$$---

 ## 动态规划解释

 这与经典的整数分区 DP（“硬币找零”）完全相似，只不过现在每个“硬币”都有两个坐标。 

定义$$dp[i][j]$$是形成总数的方法的数量$(i,j)$。 

最初：$$dp[0][0]=1.$$对于每种团体类型$(b,w)\neq(0,0)$， 更新：$$dp[i+b][j+w] += dp[i][j].$$循环必须**向前**，以便组类型可以任意多次重用。 

因为我们只需要总计$(60,40)$，我们只考虑$$0\le b\le 60,\qquad 0\le w\le 40,$$排除$(0,0)$。 

复杂性很容易管理。 

---

 # 2.Python实现```python
# Project Euler 181
# Count ways to group 60 black objects and 40 white objects.

B = 60
W = 40

# dp[i][j] = number of ways to form i black and j white objects
dp = [[0] * (W + 1) for _ in range(B + 1)]

# Empty grouping
dp[0][0] = 1

# Process every possible nonempty group type (b, w)
for b in range(B + 1):
    for w in range(W + 1):

        # Skip the empty group
        if b == 0 and w == 0:
            continue

        # Forward iteration => unlimited reuse allowed
        for i in range(B - b + 1):
            for j in range(W - w + 1):
                dp[i + b][j + w] += dp[i][j]

print(dp[B][W])
```---

 # 3. 代码演练

 ### 第 1 步 — 创建 DP 表```python
dp = [[0] * (W + 1) for _ in range(B + 1)]
```

`dp[i][j]`准确地使用以下方式存储有效分组的数量：

 -`i`黑色物体，
 -`j`白色物体。 

---

 ### 步骤 2 — 基本情况```python
dp[0][0] = 1
```有一种方法可以不进行任何分组：不使用任何组。 

---

 ### 步骤 3 — 迭代所有组类型```python
for b in range(B + 1):
    for w in range(W + 1):
```每对`(b,w)`代表一种可能的群体组成。 

我们排除`(0,0)`因为不允许空组。 

---

 ### 第 4 步 — 过渡```python
dp[i + b][j + w] += dp[i][j]
```如果我们能够形成`(i,j)`，然后再添加一组`(b,w)`我们可以形成`(i+b,j+w)`。 

循环继续进行：```python
for i in range(B - b + 1):
    for j in range(W - w + 1):
```它允许无限制地重复使用相同的组类型。 

---

 ## 样本验证

 运行相同的算法$B=3$,$W=1$给出：$$7$$与问题陈述完全匹配。

 # 4.最终验证

 计数应该非常大，因为：

 - 有许多可能的团体类型，
 - 重复次数不受限制，
 - 这本质上是一个二维配分函数。 

计算值是：$$83{,}735{,}848{,}679{,}360{,}680$$这是预期的幅度。
