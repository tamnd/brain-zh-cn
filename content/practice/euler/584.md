[项目欧拉问题 584](https://projecteuler.net/problem=584)

 ## 解决方案

 **答案：**`32.83822408`让$T$是当我们在 365 天的循环日历上第一次获得**彼此相隔 7 天内的 4 个生日**时房间里的人数。 

关键的观察是：

 - “相隔 7 天内”是指所有 4 个生日均位于某个区块内$8$连续的日历日。 
- 由于生日围绕年底，因此日历是循环的。 

定义$$S_n=\Pr(T>n),$$之后的概率$n$人们，**没有**块$8$连续天数包含$4$或多个生日。 

然后$$\mathbb E[T]=\sum_{n\ge0} S_n.$$因此，问题归结为计算生日配置以避免禁止模式。 

---

 # 1. 统计有效配置

 让$c_i$是当天的生日数$i$， 在哪里$i=1,\dots,365$。 

条件“7天内不得有4个生日”正是$$c_i+c_{i+1}+\cdots+c_{i+7}\le 3$$对于每个连续 8 天的循环块。 

对于固定占用向量$(c_1,\dots,c_{365})$总计$n$,$$\sum_i c_i=n,$$意识到这一点的标记生日作业的数量$$\frac{n!}{\prod_i c_i!}.$$因此$$S_n = \frac{n!}{365^n} \sum_{\substack{(c_i)\\ \text{all 8-block sums }\le3\\ \sum c_i=n}} \frac1{\prod_i c_i!}.$$---

 # 2. 转移状态动态规划

 要强制执行 8 天限制，请每天扫描日历。 

状态存储前 7 天的占用情况：$$(c_{i-6},\dots,c_i).$$添加新一天的入住时$x$，我们要求$$x+c_{i-6}+\cdots+c_i \le 3.$$因此状态总数很小：$$\binom{7+3}{7}=120.$$我们构建状态之间的转移图，加权为$$\frac{z^x}{x!}.$$由于日历是循环的，有效的年度配置对应于封闭的长度行走$365$。 

提取系数$z^n$给出加权计数$S_n$。 

最后，$$\mathbb E[T] = \sum_{n\ge0} S_n.$$---

 # 3.Python实现```python
from math import factorial
import numpy as np

DAYS = 365
GROUP = 4
WINDOW = 7
MAX_N = 100   # far beyond where probabilities become negligible

def generate_states(length, limit):
    """
    Generate all tuples of given length whose entries are
    nonnegative integers with total sum < limit.
    """
    states = []

    def dfs(pos, remaining, cur):
        if pos == length:
            states.append(tuple(cur))
            return

        for x in range(remaining):
            cur.append(x)
            dfs(pos + 1, remaining - x, cur)
            cur.pop()

    dfs(0, limit, [])
    return states

# State length = WINDOW = 7 previous days
states = generate_states(WINDOW, GROUP)

index = {s: i for i, s in enumerate(states)}
S = len(states)

# Build transitions
transitions = [[] for _ in range(S)]

for s in states:
    i = index[s]
    current_sum = sum(s)

    # occupancy on next day
    for x in range(GROUP - current_sum):

        next_state = s[1:] + (x,)
        j = index[next_state]

        weight = 1.0 / factorial(x)

        transitions[i].append((j, x, weight))

# dp[start_state, current_state, n]
dp = np.zeros((S, S, MAX_N + 1), dtype=np.float64)

for i in range(S):
    dp[i, i, 0] = 1.0

# advance through all 365 days
for _ in range(DAYS):

    ndp = np.zeros_like(dp)

    for s in range(S):

        arr = dp[:, s, :]

        for ns, x, w in transitions[s]:

            ndp[:, ns, x:] += arr[:, :MAX_N + 1 - x] * w

    dp = ndp

# closed walks give cyclic configurations
A = np.zeros(MAX_N + 1)

for i in range(S):
    A += dp[i, i, :]

# survival probabilities
survival = np.zeros(MAX_N + 1)

for n in range(MAX_N + 1):
    survival[n] = factorial(n) * A[n] / (DAYS ** n)

expected_value = survival.sum()

print(expected_value)
print(round(expected_value, 8))
```---
