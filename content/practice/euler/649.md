[欧拉项目问题 649](https://projecteuler.net/problem=649)

 ## 解决方案

 **答案：**`924668016`设棋盘坐标为$0,\dots,n-1$在每个方向上，都有一枚硬币$(x,y)$。 移动将**精确地减少一个坐标**之一$\{2,3,5,7\}$，因此该博弈是一个公正的正常博弈，并分解为独立的子博弈。 

## 1.数学分析

 ### 步骤 1：一维的 Grundy 值

 定义$g(k)$作为坐标线上标记的 Grundy 数$k$。 

复发率是$$g(k)=\operatorname{mex}\{g(k-2),g(k-3),g(k-5),g(k-7)\},$$其中仅包含有效的前任。 

计算第一项：$$0,0,1,1,2,2,3,3,4,0,0,1,1,2,2,3,3,4,\dots$$这是周期性的$9$：$$(0,0,1,1,2,2,3,3,4).$$因此每个坐标贡献之一$\{0,1,2,3,4\}$。 

为了$$n=10{,}000{,}019,$$我们有$$10{,}000{,}019 = 9\cdot 1{,}111{,}113 + 2.$$所以坐标 Grundy 计数为：$$\#(0)=2q+2,\quad \#(1)=2q,\quad \#(2)=2q,\quad \#(3)=2q,\quad \#(4)=q,$$和$q=1{,}111{,}113$， IE。$$(2222228,\ 2222226,\ 2222226,\ 2222226,\ 1111113).$$### 步骤 2：正方形的 Grundy 值

 由于水平和垂直移动是独立的，$$G(x,y)=g(x)\oplus g(y).$$通过异或值计算所有棋盘方格得出：$$v = \bigl( 20987734567981,\, 19753162469208,\, 19753162469208,\, 19753162469208,\, 4938292839528,\, 4938288395076,\, 4938288395076,\, 4938288395076 \bigr),$$格伦迪价值观$0,\dots,7$。 

### 步骤 3：$100$可区分的硬币

 总持仓 Grundy 是所有代币 Grundy 的异或。 

当且仅当异或非零时，爱丽丝获胜。 

由于硬币是可区分的，并且可能会重叠，因此异或的配置数量$0$是$100$-倍异或卷积系数$0$。 

使用 Walsh-Hadamard 变换：$$L = \frac{1}{8} \sum_{k=0}^{7} \widehat v(k)^{100},$$在哪里$$\widehat v = ( 100000380000361,\, 1234576543225,\, 1234576543225,\, 1234576543225,\, 60494063950849,\, 1234567654321,\, 1234567654321,\, 1234567654321 ).$$总的排列数为$$T=(n^2)^{100}.$$因此$$M(n,100)=T-L.$$拿最后一个$9$数字产量：$$M(10{,}000{,}019,100)\equiv 924668016 \pmod{10^9}.$$## 2.Python实现```python
from collections import Counter

MOD = 10**9
n = 10_000_019
c = 100

# 1D Grundy pattern (period 9)
pattern = [0, 0, 1, 1, 2, 2, 3, 3, 4]

# Count coordinate Grundy frequencies
q, r = divmod(n, 9)

coord_count = [0] * 5
for g in pattern:
    coord_count[g] += q
for g in pattern[:r]:
    coord_count[g] += 1

# Count board-square Grundy values G(x,y)=gx xor gy
board_count = [0] * 8
for gx, cx in enumerate(coord_count):
    for gy, cy in enumerate(coord_count):
        board_count[gx ^ gy] += cx * cy

# Walsh-Hadamard transform values
transform = []
for mask in range(8):
    s = 0
    for x, v in enumerate(board_count):
        if bin(mask & x).count("1") % 2:
            s -= v
        else:
            s += v
    transform.append(s)

# Number of losing positions (xor = 0)
losing = sum(pow(x, c) for x in transform) // 8

# Total arrangements
total = pow(sum(board_count), c)

answer = (total - losing) % MOD
print(answer)
```## 3. 实例验证

- 变换方法是精确的并且利用了异或独立性。
