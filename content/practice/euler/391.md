[欧拉项目问题 391](https://projecteuler.net/problem=391)

 ## 解决方案

 **答案：**`61029882288`让$$s_k=\sum_{i=0}^k \operatorname{popcount}(i),$$在哪里$\operatorname{popcount}(i)$是二进制展开中 1 位的数量$i$。 

合法的游戏位置就是数值$$S=\{s_0,s_1,s_2,\dots\}.$$连续元素之间的差异是$$s_{k+1}-s_k=\operatorname{popcount}(k+1).$$所以从$s_a$到$s_b$是合法的，当且仅当$$s_b-s_a\le n.$$---

 # 1.数学分析

 ## 公正的游戏结构

 这是一场正常的公平游戏，所以位置分为：

 - **P-位置**（前一个玩家获胜/失败的位置），
 - **N 个位置**（下一个玩家获胜/获胜位置）。 

当且仅当每次合法的移动都指向获胜位置时，该位置就会失败。 

由于游戏图是全序的，因此可以贪婪地生成失败的位置。 

---

 ## 关键观察

 假设亏损头寸是$$p_0 < p_1 < p_2 < \cdots.$$然后：

 - 每个位置$S$距离内$\le n$失败的位置是获胜的位置，
 - 因此下一个失败的位置只是第一个元素$S$这比$n$远离之前的亏损位置。 

所以：$$p_{k+1}=\min\{x\in S : x-p_k>n\}.$$这种重复完全决定了比赛的胜负。 

第一步是获胜，当且仅当它落在失败的位置上，因此$$M(n)=\max\{p_k : p_k\le n\}.$$---

 ## 高效生成$S$我们不会显式地将每个整数转换为二进制。 

使用：$$s_{k+1}=s_k+\operatorname{popcount}(k+1).$$使用 Python 计算 popcount 的速度非常快`bit_count()`。 

---

 ## 高效计算$M(n)$对于固定的$n$：

 1. 生成足够的值$S$。 
2. 贪婪地生成亏损仓位：

 - 从第一个亏损位置开始，
 - 重复跳转到第一个元素$S$比$n$。 
3、最大亏损仓位$\le n$是$M(n)$。 

这样做是为了$1\le n\le1000$速度非常快。 

问题陈述给出了检查：$$\sum_{n=1}^{20} M(n)^3 = 8150.$$我们的程序准确地再现了这一点。 

---

 # 2.Python实现```python
from bisect import bisect_right

# ---------------------------------------------------------
# Generate the sequence S = {s_k}
# s_k = total number of 1-bits appearing in 0..k
# ---------------------------------------------------------

LIMIT = 300000

S = [0]
cur = 0

for k in range(1, LIMIT + 1):
    cur += k.bit_count()
    S.append(cur)

# ---------------------------------------------------------
# Compute M(n)
# ---------------------------------------------------------

def M(n):
    # Generate losing positions greedily.
    losing = []

    # First losing position:
    # the first element of S having no predecessor within distance <= n
    p = next(x for x in S if x > n)
    losing.append(p)

    # Generate more losing positions
    idx = bisect_right(S, p + n)

    while idx < len(S):
        p = S[idx]
        losing.append(p)
        idx = bisect_right(S, p + n)

        # We only care about losing positions <= n
        if p > n:
            break

    # Largest losing position <= n
    ans = 0
    for x in losing:
        if x <= n:
            ans = x

    return ans

# ---------------------------------------------------------
# Verify the sample
# ---------------------------------------------------------

check = sum(M(n) ** 3 for n in range(1, 21))
print(check)   # 8150

# ---------------------------------------------------------
# Final computation
# ---------------------------------------------------------

answer = sum(M(n) ** 3 for n in range(1, 1001))
print(answer)
```---

 # 3. 代码演练

 ## 生成$S$

```python
cur += k.bit_count()
S.append(cur)
```自从$$s_k=s_{k-1}+\operatorname{popcount}(k),$$我们逐步构建序列。 

---

 ## 建立亏损头寸

 关键的一行是：```python
idx = bisect_right(S, p + n)
```每一个合法的举动$p$降落在$$[p+1,\;p+n].$$所有这些职位都在获胜。 

所以下一个失败的位置是第一个元素$S$严格大于$p+n$。 

二分查找使得这个$O(\log |S|)$。 

---

 ## 样本验证

 该程序重现：```python
sum(M(n)^3 for 1<=n<=20) = 8150
```完全按照问题中所述。
