[欧拉项目问题 528](https://projecteuler.net/problem=528)

 ## 解决方案

 **答案：**`779027989`让$$S(n,k,b)=\#\left\{(x_1,\dots,x_k)\in \mathbb Z_{\ge 0}^k: x_1+\cdots+x_k\le n,\;\;0\le x_m\le b^m \right\}.$$我们需要$$\left(\sum_{10\le k\le 15} S(10^k,k,k)\right)\bmod 1{,}000{,}000{,}007.$$## 1.数学分析

 我们想要计算有界整数解$$x_1+\cdots+x_k\le n$$和$$0\le x_m\le b^m.$$标准技巧将不平等转化为平等。 

引入松弛变量$$x_{k+1}=n-(x_1+\cdots+x_k)\ge 0.$$然后计算解决方案$$x_1+\cdots+x_k\le n$$相当于计算非负解$$x_1+\cdots+x_k+x_{k+1}=n$$上限仅在$x_1,\dots,x_k$。 

### 第 1 步：无限制计数

 如果没有上限，则非负解的数量$$x_1+\cdots+x_{k+1}=n$$是经典的星条结果：$$\binom{n+k}{k}.$$### 第 2 步：包含 - 排除

 我们必须强制执行$$x_m\le b^m.$$让$$u_m=b^m.$$对于一个子集$A\subseteq \{1,\dots,k\}$，假设每个变量$A$违反了它的界限：$$x_i\ge u_i+1 \qquad (i\in A).$$放$$y_i=x_i-(u_i+1)$$为了$i\in A$。 那么方程就变成了$$\sum y_i + \sum_{i\notin A}x_i + x_{k+1} = n-\sum_{i\in A}(u_i+1).$$因此此类解的数量为$$\binom{ n-\sum_{i\in A}(u_i+1)+k }{k},$$解释为$0$如果最高值为$<k$。 

通过包含-排除：$$S(n,k,b) = \sum_{A\subseteq \{1,\dots,k\}} (-1)^{|A|} \binom{ n-\sum_{i\in A}(b^i+1)+k }{k}.$$自从$k\le 15$， 仅有的$2^{15}=32768$需要子集，这使得速度非常快。

 ## 2.Python实现```python
from math import comb

MOD = 1_000_000_007

def S(n, k, b):
    # Upper bounds u_i = b^i
    bounds = [b ** i for i in range(1, k + 1)]

    total = 0

    # Inclusion-exclusion over subsets
    for mask in range(1 << k):
        shift = 0
        bits = 0

        for i in range(k):
            if (mask >> i) & 1:
                shift += bounds[i] + 1
                bits += 1

        top = n - shift + k

        # Binomial coefficient contributes only if top >= k
        ways = comb(top, k) if top >= k else 0

        if bits % 2:
            total -= ways
        else:
            total += ways

    return total

# Verify examples
print(S(14, 3, 2))                  # 135
print(S(200, 5, 3))                 # 12949440
print(S(1000, 10, 5) % MOD)         # 624839075

# Compute Euler 528 answer
answer = sum(S(10**k, k, k) for k in range(10, 16)) % MOD

print(answer)
```---

 ## 3. 代码演练

 ###`bounds = [b ** i for i in range(1, k + 1)]`创建：$$[b^1,b^2,\dots,b^k].$$这些是每个变量的上限。 

###`for mask in range(1 << k)`使用位掩码迭代变量的所有子集。 

每个子集代表违反其上限的变量。 

###`shift += bounds[i] + 1`如果变量$x_i$被迫超过其限制，我们减去：$$b^i+1$$因为我们替代$$x_i = y_i + (b^i+1).$$###`top = n - shift + k`平移后，剩余方程为$$k+1$$非负变量的总和较小。 

星条给出：$$\binom{\text{top}}{k}.$$### 包含-排除符号

 奇数大小的子集相减； 偶数大小的子集添加：```python
if bits % 2:
    total -= ways
else:
    total += ways
```---
