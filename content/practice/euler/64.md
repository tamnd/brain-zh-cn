[欧拉计划问题 64](https://projecteuler.net/problem=64)

 ## 解决方案

 **答案：**`1322`对于非平方整数$N$，继续分式展开$\sqrt N$是周期性的。 生成连分数的标准算法是：$$a_0=\lfloor \sqrt N \rfloor$$然后递归地$$m_{k+1}=d_k a_k-m_k$$

$$d_{k+1}=\frac{N-m_{k+1}^2}{d_k}$$

$$a_{k+1}=\left\lfloor \frac{a_0+m_{k+1}}{d_{k+1}} \right\rfloor$$具有初始值$$m_0=0,\qquad d_0=1,\qquad a_0=\lfloor\sqrt N\rfloor.$$的顺序为$a_k$最终重复。 对于平方根，经典定理指出，周期恰好在以下时间结束：$$a_k = 2a_0.$$所以对于每个非正方形$N$，我们可以生成项直到$a_k=2a_0$，并计算发生了多少步。 该计数就是周期长度。 

我们需要数一下有多少个$N \le 10000$周期长度为**奇数**。 

---

 ## 数学推导

 连分数算法来自于对以下形式的表达式的反复有理化$$\frac1{\sqrt N - m}.$$假设在某个步骤我们有$$\frac{\sqrt N + m_k}{d_k}.$$我们将整数部分分开：$$a_k = \left\lfloor \frac{a_0+m_k}{d_k}\right\rfloor,$$并重写：$$\frac{\sqrt N + m_k}{d_k} = a_k + \frac{\sqrt N - m_{k+1}}{d_{k+1}},$$从而产生上面的递推公式。 

对于二次无理数，例如$\sqrt N$，状态对$(m_k,d_k)$最终必须重复，因此连分数是周期性的。 

平方根特有的一个有用属性是：$$\text{period ends when } a_k = 2a_0.$$因此，计算周期很简单。

 ## Python 实现```python
import math

def continued_fraction_period(n):
    """
    Return the period length of the continued fraction
    expansion of sqrt(n).
    """
    
    a0 = int(math.isqrt(n))
    
    # Perfect squares have no periodic continued fraction
    if a0 * a0 == n:
        return 0
    
    m = 0
    d = 1
    a = a0
    
    period = 0
    
    while True:
        # Recurrence relations
        m = d * a - m
        d = (n - m * m) // d
        a = (a0 + m) // d
        
        period += 1
        
        # For square roots, the period completes at 2*a0
        if a == 2 * a0:
            break
    
    return period

count = 0

for n in range(2, 10001):
    if continued_fraction_period(n) % 2 == 1:
        count += 1

print(count)
```---

 ### 功能设置```python
a0 = int(math.isqrt(n))

 ### 完美的方形格子```python
if a0 * a0 == n:
    return 0
```完全平方有终止展开，而不是周期性无理展开。 

---

 ### 初始状态```python
m = 0
d = 1
a = a0
```这些是重复的标准初始值。 

---

 ### 主要复发```python
m = d * a - m
d = (n - m * m) // d
a = (a0 + m) // d
```这会生成下一个连分数项。 

---

 ### 经期计数```python
period += 1
```每次迭代都会向重复块添加一项。 

---

 ### 检测完成```python
if a == 2 * a0:
    break
```对于平方根，这标志着一个完整周期的结束。
