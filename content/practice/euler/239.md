[欧拉项目问题 239](https://projecteuler.net/problem=239)

 ## 解决方案

 **答案：**`0.001887854841`有$100$磁盘，其中素数$1,\dots,100$是：$$2,3,5,7,11,\dots,97$$素数的个数$\le 100$是$$\pi(100)=25.$$我们想要**恰好的概率$22$质数磁盘未处于其自然位置**。 

等效地：

 - 其中$25$主磁盘，
 - 正是$3$是固定的，
 - 另一个$22$被感动了。 

非主磁盘不受限制。 

---

 # 步骤 1 — 重新表述计数问题

 让：

 -$P$= 一组主要位置，$|P|=25$,
 -$C$= 一组复合/非素数位置，$|C|=75$。 

我们寻求：$$\Pr(\text{exactly 3 prime disks fixed})$$全面的$100!$排列。 

选择哪个$3$主磁盘保持固定：$$\binom{25}{3}.$$现在剩下的$22$主磁盘不得**被修复。 

没有任何限制$75$非主磁盘。 

所以修复这些之后$3$素数，我们必须计算剩余的排列$97$其中指定的元素$22$主盘避开自己的位置。 

这是一个标准的包含-排除问题。 

---

 # 第 2 步 — 包含 - 排除

 让剩下的$22$主盘要区分。 

对于每个这样的磁盘$i$，定义事件：$$A_i = \{\text{disk } i \text{ is fixed}\}.$$我们想要避免所有的排列$A_i$。 

剩余的总排列$97$对象：$$97!.$$如果我们强制一个特定的子集$k$其中$22$要修复的磁盘，然后：$$(97-k)!$$排列仍然存在。 

因此，通过包含-排除：$$N = \sum_{k=0}^{22} (-1)^k \binom{22}{k} (97-k)!.$$包括选择$3$固定素数：$$\#(\text{desired permutations}) = \binom{25}{3} \sum_{k=0}^{22} (-1)^k \binom{22}{k} (97-k)!.$$因此概率是$$\boxed{ \frac{ \binom{25}{3} \displaystyle\sum_{k=0}^{22} (-1)^k \binom{22}{k} (97-k)! }{ 100! } }.$$---

 # 第 3 步 — Python 实现```python
from math import comb, factorial
from decimal import Decimal, getcontext

# use high precision
getcontext().prec = 50

total = factorial(100)

# inclusion-exclusion sum
s = 0
for k in range(23):
    s += (-1)**k * comb(22, k) * factorial(97 - k)

count = comb(25, 3) * s

prob = Decimal(count) / Decimal(total)

print(prob)
print(round(prob, 12))
```---

 # 步骤 5 — 数值评估

 计算表达式得出：$$0.001887854841\dots$$四舍五入到小数点后 12 位：$$\boxed{0.001887854841}$$这个幅度是合理的：

 - 25 个中预期的固定素数大约是$25 \cdot \frac1{100}=0.25$,
 - 恰好有 3 个固定素数的情况很少见，但也不是天文数字，
 - 周围的概率$10^{-3}$是有道理的。
