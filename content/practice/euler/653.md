[欧拉项目 653 问题](https://projecteuler.net/problem=653)

 ## 解决方案

 **答案：**`1130658687`设大理石直径为$D=20$。 

我们表示为$x_i(t)$的中心$i$第 -th 大理石（从西边开始算）。 

最初弹珠满足$$x_{i+1}(0)-x_i(0)\ge D.$$关键的难点是处理碰撞。 标准的“相同粒子”技巧是关键的见解。 

# 1. 碰撞等价

 对于具有完全弹性碰撞的相等质量，两个碰撞的弹珠只是交换速度。 

因此：

 - 如果我们忽略身份，弹珠的行为就像相互穿过的粒子一样；
 - 碰撞的唯一影响是身份被交换。 

所以我们可以研究永远不会碰撞的**幽灵粒子**。 

---

 # 2. 移除直径限制

 定义变换后的坐标$$y_i = x_i - Di.$$由于相邻中心总是至少$D$分开，减去$Di$完全消除硬核排除。 

最初：$$x_i = 10 + \sum_{k=1}^i g_k + D(i-1),$$在哪里$$g_k = (r_k \bmod 1000)+1.$$因此$$y_i = \sum_{k=1}^i g_k - 10.$$所以变换后的位置独立于$D$。 

---

 # 3. 反射墙技巧

 一个向西移动的粒子在西墙上反射相当于一个从$-y_i$并且总是向东移动。 

由此定义$$s_i = \begin{cases} +y_i,& r_i\le 10^7 \quad (\text{east})\\ -y_i,& r_i>10^7 \quad (\text{west}) \end{cases}$$现在每个幽灵粒子都以单位速度向东移动。 

---

 # 4. 退出时间

 在变换后的坐标中，东出口边界位于$$L-D.$$因此大理石产生的鬼粒子$i$准时退出$$t_i^{(\text{ghost})} = (L-D)-s_i.$$排序$s_i$按降序排列：$$s_{(1)} \ge s_{(2)} \ge \cdots \ge s_{(N)}.$$然后相应的幽灵退出时间按递增顺序出现。 

因为真正的弹珠保持有序，$j$第 - 个弹珠出口位于$j$-th 退出事件。 

每个较早退出的弹珠都会缩短占用的管子$D$，所以真正的退出时间减少了$$D(j-1)-D = D(j-2).$$因此$$\boxed{ d(L,N,j)=L+20-20j-s_{(j)} }$$在哪里$s_{(j)}$是$j$其中第一个最大的值$s_i$。 

---

 # 5. 示例验证

 对于$(L,N,j)=(5000,3,2)$：$$s=\{107,-539,-712\}.$$第二大值是$-539$。 

因此$$d=5000+20-40-(-539)=5519.$$正确的。 

为了$(10000,11,6)$，公式给出：$$11780.$$正确的。 

为了$(100000,101,51)$，公式给出：$$114101.$$正确的。 

---

 # 6.Python实现```python
import heapq

MOD = 32745673

def d(L, N, j):
    r = 6563116

    gap_sum = 0
    signed_positions = []

    for _ in range(N):
        gap = (r % 1000) + 1
        gap_sum += gap

        # y_i = sum(gaps) - 10
        y = gap_sum - 10

        # east => +y, west => -y
        if r <= 10_000_000:
            signed_positions.append(y)
        else:
            signed_positions.append(-y)

        r = (r * r) % MOD

    # j-th largest signed position
    s_j = heapq.nlargest(j, signed_positions)[-1]

    return L + 20 - 20 * j - s_j

print(d(5000, 3, 2))         # 5519
print(d(10000, 11, 6))       # 11780
print(d(100000, 101, 51))    # 114101

print(d(1_000_000_000, 1_000_001, 500_001))
```---
