[欧拉计划问题 118](https://projecteuler.net/problem=118)

 ## 解决方案

 **答案：**`44680`我们必须计算使用每个数字形成的素数集的数量$1,\dots,9$正好一次。 

例如，$$\{2,5,47,89,631\}$$有效，因为：

 - 每个元素都是素数，
 - 数字$1$通过$9$总共只使用一次，
 - 顺序并不重要，因为这是一个**集合**。 

挑战在于计算所有这些不同的集合。 

---

 # 数学分析

 ## 1. 关于素数的观察

 我们将数字连接起来形成整数。 

由不同数字组成的数字只能是质数，如果：

 - 它**不**以偶数结尾，
 - 它**不**结束于$5$,
 - 它不能被整除$3$。 

能被 3 整除的观察尤其重要。 

对于任何整数，能被$3$取决于数字之和。 

数字$1$通过$9$总和为$$1+2+\cdots+9 = 45.$$自从$45\equiv 0 \pmod 3$, _ 整个串联 _ 可以被整除$3$。 

因此我们不能将所有数字放入一个素数中。 

更一般地说：

 - 其数字总和可被整除的任何数字子集$3$不能形成素数（除了$3$本身）。 

这极大地减少了搜索空间。 

---

 # 2. 策略

 我们将：

 1. 生成满足以下条件的每个素数：

 - 使用不同的数字$1$–$9$,
 - 不使用任何数字两次，
 - 不包含零。 
2. 用所用数字的位掩码表示每个素数。 
3. 使用递归搜索/回溯来组合不相交的掩码，直到使用所有九个数字。 
4. 强制执行订购条件以避免多次计数同一组。 

---

 # 3.素数一代

 只有$$\sum_{k=1}^9 P(9,k)$$可能的数字排列，其中$$P(9,k)=\frac{9!}{(9-k)!}.$$这个总数是可以管理的。 

对于每个长度排列$k$：

 - 转换为整数，
 - 测试素性，
 - 如果是素数则存储。 

---

 # 4. 避免重复集

 假设我们递归地选择素数。 

如果我们允许任意顺序，那么$$\{2,5,47\}$$将被计为：

 -$2,5,47$-$2,47,5$-$5,2,47$- 等

 为了防止这种情况，我们要求按升序选择素数。 

因此，每个集合只生成一次。

 # Python 实现```python
from itertools import permutations
from math import isqrt

# ------------------------------------------------------------
# Primality test
# ------------------------------------------------------------

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    if n % 3 == 0:
        return n == 3

    r = isqrt(n)
    f = 5
    while f <= r:
        if n % f == 0 or n % (f + 2) == 0:
            return False
        f += 6
    return True

# ------------------------------------------------------------
# Generate all usable primes
# ------------------------------------------------------------

digits = '123456789'

# primes_by_mask[mask] = list of primes using exactly those digits
primes = []

for length in range(1, 10):
    for perm in permutations(digits, length):

        # quick divisibility-by-3 pruning
        digit_sum = sum(ord(c) - ord('0') for c in perm)
        if digit_sum % 3 == 0:
            # only possible prime is 3 itself
            if not (length == 1 and perm[0] == '3'):
                continue

        # last digit cannot be even or 5
        if perm[-1] in '24568':
            if not (length == 1 and perm[0] in '25'):
                continue

        n = int(''.join(perm))

        if is_prime(n):

            # build bitmask
            mask = 0
            for ch in perm:
                mask |= 1 << (ord(ch) - ord('1'))

            primes.append((n, mask))

# ------------------------------------------------------------
# Sort primes so recursive generation is canonical
# ------------------------------------------------------------

primes.sort()

FULL_MASK = (1 << 9) - 1

answer = 0

# ------------------------------------------------------------
# Backtracking search
# ------------------------------------------------------------

def search(start_index, used_mask):
    """
    Choose increasing primes whose digit masks are disjoint
    until all digits are used.
    """
    global answer

    if used_mask == FULL_MASK:
        answer += 1
        return

    for i in range(start_index, len(primes)):
        p, mask = primes[i]

        # disjoint digit sets only
        if used_mask & mask:
            continue

        search(i + 1, used_mask | mask)

search(0, 0)

print(answer)
```---
