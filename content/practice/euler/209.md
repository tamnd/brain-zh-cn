[项目欧拉问题 209](https://projecteuler.net/problem=209)

 ## 解决方案

 **答案：**`15964587728784`让$$T(a,b,c,d,e,f)=(b,c,d,e,f,a\oplus (b\land c)).$$问题中的条件是$$\tau(x)\land \tau(T(x))=0$$对于每一个$6$位状态$x$。 

我们必须计算所有布尔函数$$\tau:\{0,1\}^6\to\{0,1\}$$这样任何国家及其形象都不会受到$T$都被分配$1$。 

关键是要理解排列的结构$T$于$64$州。 

---

 # 步骤 1 — 从理论上解释条件图

 定义 64 个状态的有向图：$$x\to T(x).$$自从$T$是可逆的（它是线性反馈移位寄存器类型的变换），每个节点都有入度$1$和出度$1$。 因此，该图分解为不相交的有向循环。 

对于每条边$x\to T(x)$，条件表示：$$(\tau(x),\tau(T(x)))\neq (1,1).$$所以在每个周期，我们必须分配$0/1$标签使得没有相邻顶点同时存在$1$。 

因此：

 - 每个周期独立贡献，
 - 对于一个周期长度$n$，有效赋值的个数就是长度为二进制循环串的个数$n$没有相邻的$1$的。 

这个数量是众所周知的：$$N(n)=F_{n-1}+F_{n+1},$$在哪里$F_n$是斐波那契数列。 

（等效地，这是卢卡斯数$L_n$.)

 所以问题就简化为：

 1. 求循环分解$T$,
 2. 乘以相应的卢卡斯数。 

---

 # 第 2 步 — 分析转变

 地图是$$(a,b,c,d,e,f)\mapsto (b,c,d,e,f,a\oplus (b\land c)).$$我们现在确定 64 个状态的循环结构。 

直接计算（如下代码所示）给出：

 - 一个周期的长度$1$,
 - 一个周期的长度$2$,
 - 一个周期的长度$3$,
 - 两个周期的长度$6$,
 - 一个周期的长度$46$。 

查看：$$1+2+3+6+6+46=64.$$因此有效真值表的总数是$$L_1L_2L_3L_6^2L_{46}.$$使用卢卡斯数：$$L_1=1,\quad L_2=3,\quad L_3=4,\quad L_6=18.$$还，$$L_{46}=4106118243.$$因此$$1\cdot 3\cdot 4\cdot 18^2\cdot 4106118243.$$计算：$$3\cdot 4=12,$$

$$18^2=324,$$

$$12\cdot 324=3888,$$

$$3888\cdot 4106118243=15964587728784.$$---

 # 步骤 3 — 为什么周期盘点公式是正确的

 对于一个周期长度$n$，令二进制标签为$$x_1,x_2,\dots,x_n,$$带有索引循环模$n$。 

约束条件是$$x_i x_{i+1}=0.$$避免连续的二元循环串的数量$1$等于$$F_{n-1}+F_{n+1}.$$快速推导：

 - 长度的线性字符串$m$没有相邻的$1$的计算方式为$F_{m+2}$,
 - 对于循环字符串：

 - 第一位是$0$：$F_{n+1}$,
 - 或者第一位是$1$: 邻居强迫$0$，离开$F_{n-1}$,
 - 给予$$F_{n+1}+F_{n-1}.$$---

 # 第 4 步 — Python 实现```python
from collections import defaultdict

# ---------------------------------------------------------
# Transformation T on 6-bit states
# ---------------------------------------------------------

def T(x):
    """
    x is an integer from 0..63 representing bits abcdef.
    Returns T(x).
    """

    # Extract bits
    a = (x >> 5) & 1
    b = (x >> 4) & 1
    c = (x >> 3) & 1
    d = (x >> 2) & 1
    e = (x >> 1) & 1
    f = x & 1

    # New last bit
    g = a ^ (b & c)

    # Shift left
    y = (b << 5) | (c << 4) | (d << 3) | (e << 2) | (f << 1) | g

    return y

# ---------------------------------------------------------
# Find cycle decomposition
# ---------------------------------------------------------

visited = [False] * 64
cycle_lengths = []

for start in range(64):

    if visited[start]:
        continue

    cur = start
    cycle = []

    while not visited[cur]:
        visited[cur] = True
        cycle.append(cur)
        cur = T(cur)

    cycle_lengths.append(len(cycle))

print(sorted(cycle_lengths))

# ---------------------------------------------------------
# Fibonacci / Lucas
# ---------------------------------------------------------

def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

def lucas(n):
    return fibonacci(n - 1) + fibonacci(n + 1)

# ---------------------------------------------------------
# Compute total count
# ---------------------------------------------------------

answer = 1

for n in cycle_lengths:
    answer *= lucas(n)

print(answer)
```---
