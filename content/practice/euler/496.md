[欧拉项目 496 问题](https://projecteuler.net/problem=496)

 ## 解决方案

 **答案：**`2042473533769142717`让

-$a = BC$,
 -$b = CA$,
 -$c = AB$，

和$a,b,c\in \mathbb Z_{>0}$。 

我们寻找满足以下条件的所有整数三角形$$b = DI,$$在哪里$I$是心并且$D$是角平分线的第二个交点$AI$与外接圆。 

---

 ## 1.数学分析

 ### 第 1 步：表达$DI$几何地

 自从$A,I,D$共线并且$D$位于外接圆上，使用一点的幂$I$。 

心心相对于外接圆的幂为$$IA\cdot ID = 2Rr,$$在哪里$R$是外接圆半径并且$r$是内半径。 

还，$$IA = \frac{r}{\sin(A/2)}.$$因此$$ID = \frac{2Rr}{IA} = 2R\sin(A/2).$$条件$AC = DI$变成$$b = 2R\sin(A/2).$$但根据正弦定律，$$b = 2R\sin B.$$因此$$\sin B = \sin(A/2).$$由于三角形的内角位于$(0,\pi)$，唯一有效的可能性是$$B = \frac A2.$$所以条件等价于：$$A = 2B.$$---

 ### 步骤 2：将角度条件转换为丢番图方程

 由正弦定律，$$\frac{a}{\sin A} = \frac{b}{\sin B}.$$自从$A=2B$,$$a = b\frac{\sin(2B)}{\sin B} = 2b\cos B.$$所以$$\cos B = \frac{a}{2b}.$$现在$$c = b\frac{\sin(3B)}{\sin B} = b(4\cos^2B-1).$$代替$\cos B = a/(2b)$：$$c = b\left(\frac{a^2}{b^2}-1\right) = \frac{a^2-b^2}{b}.$$重新排列给出关键方程：$$a^2 = b(b+c).$$这就是准确的表征。 

---

 ### 步骤 3：参数化

 让$$g = \gcd(b,b+c).$$写$$b = g u,\qquad b+c = gv,$$和$\gcd(u,v)=1$。 

然后$$a^2 = g^2 uv.$$自从$u$和$v$互质并且它们的乘积是正方形，两者都必须是正方形：$$u=m^2,\qquad v=n^2,$$和$\gcd(m,n)=1$。 

因此每个解都是$$\boxed{ a = gmn,\quad b = gm^2,\quad c = g(n^2-m^2) }$$和$$m<n<2m, \qquad \gcd(m,n)=1.$$（不等式$n<2m$来自三角不等式/角度正性。）

 示例：

 -$m=2,n=3,g=1$给出$$(a,b,c)=(6,4,5),$$匹配示例。 

---

 ### 第四步：求和公式

 对于固定互质$(m,n)$,$$a = gmn.$$所有倍数$$gmn \le L$$是允许的。 

让$$K=\left\lfloor \frac{L}{mn}\right\rfloor.$$该原始对的贡献：$$\sum_{g=1}^{K} gmn = mn\cdot \frac{K(K+1)}2.$$因此$$F(L) = \sum_{\substack{m<n<2m\\ \gcd(m,n)=1}} mn\cdot \frac{K(K+1)}2, \quad K=\left\lfloor\frac{L}{mn}\right\rfloor.$$有效评估$L=10^9$，我们避免迭代所有$n$直接并使用莫比乌斯反演对范围内的互质整数求和：$$\sum_{\substack{x\le n\le y\\(n,m)=1}} n.$$这将运行时间减少到几秒钟。

 ## 2.Python实现```python
from math import isqrt

def F(L):
    M = isqrt(L)

    # Möbius function up to sqrt(L)
    mu = [0] * (M + 1)
    mu[1] = 1
    primes = []
    composite = [False] * (M + 1)

    for i in range(2, M + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > M:
                break

            composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break

            mu[v] = -mu[i]

    # divisors with nonzero Möbius values
    divisors = [[] for _ in range(M + 1)]

    for d in range(1, M + 1):
        if mu[d] == 0:
            continue

        coeff = mu[d] * d

        for m in range(d, M + 1, d):
            divisors[m].append((d, coeff))

    def triangular(k):
        return k * (k + 1) // 2

    total = 0

    for m in range(1, M + 1):

        limit = min(2 * m - 1, L // m)
        if limit <= m:
            continue

        divs = divisors[m]

        # Sum of integers <= N coprime to m
        def coprime_sum(N):
            s = 0
            for d, coeff in divs:
                t = N // d
                s += coeff * (t * (t + 1) // 2)
            return s

        n = m + 1

        # Group intervals where floor(L/(m*n)) is constant
        while n <= limit:
            k = L // (m * n)
            r = min(limit, L // (m * k))

            sum_n = coprime_sum(r) - coprime_sum(n - 1)

            total += m * triangular(k) * sum_n

            n = r + 1

    return total

print(F(15))      # 45
print(F(10**9))
```---

 ## 3. 代码演练

 ### 莫比乌斯预计算

 我们对莫比乌斯函数进行筛选$\sqrt L$。 

这使我们能够评估：$$\sum_{\gcd(n,m)=1} n$$使用包含-排除：$$\sum_{d\mid m} \mu(d)d \cdot \frac{\lfloor N/d\rfloor(\lfloor N/d\rfloor+1)}2.$$---

 ### 枚举原始三角形

 我们迭代一遍$m$，并且对于每个：$$m<n<2m.$$自从$$mn\le L,$$我们上限$n$在$$\min(2m-1,\lfloor L/m\rfloor).$$而不是检查每一个$n$，我们对区间进行分组，其中$$\left\lfloor \frac{L}{mn}\right\rfloor$$是常数，使得算法速度很快。 

---

 ### 验证示例

 对于$L=15$，程序准确地找到：$$(6,4,5), (12,8,10), (12,9,7), (15,9,16),$$其总和$BC$值为：$$6+12+12+15=45.$$正确的。
