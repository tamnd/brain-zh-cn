 ## 解决方案

 **答案：**`0.5001817828`让船只建立索引$1,2,\dots,n$按照起始顺序从最低到最高。 

船$i$开始$40(i-1)$从最低的船向上游米数米，所以到终点的剩余距离是$$d_i=L-40(i-1).$$速度是 i.i.d.$$v_i=-\log X_i \sim \text{Exp}(1).$$我们想要最终排列为偶数的概率。 

---

 # 1. 关键的数学见解

 假设船$i$正在追船$i+1$。 

他们开始$40$相距数米，因此会发生碰撞 iff$$\frac{40}{v_i-v_{i+1}} \le \frac{d_i}{v_i}.$$重新整理后，$$d_{i+1}v_i \ge d_i v_{i+1}.$$定义$$w_i=\frac{v_i}{d_i}.$$那么凹凸条件就变得简单了$$w_i \ge w_{i+1}.$$现在观察：

 - 自从$v_i\sim \text{Exp}(1)$,
 - 缩放给出$$w_i \sim \text{Exp}(d_i).$$因此$w_i$与速率无关的指数$d_i$。 

---

 ## 递归结构

 引入“目标坐标”$$t=\frac{L}{40}+1.$$然后$$d_i=40(t-i).$$忽略公因数$40$，我们可以认为$$w_i \sim \text{Exp}(t-i).$$关于指数的一个重要事实：

 如果独立指数有比率$\lambda_i$，那么变量的概率$m$是 最小值是$$\frac{\lambda_m}{\sum \lambda_j}.$$最小的船$w_i$:

 - 永远不会撞到另一条船，
 - 因此仍然是最终订单中最低的船。 

假设最小值出现在位置$m$。 

然后：

 - 船$l,\dots,m-1$形成一个独立的子问题，其新目标变为$m$,
 - 船$m+1,\dots,r$在原目标不变的情况下，形成另一个独立的子问题。 

移动的船$m$到前面改变排列奇偶性$$(-1)^{m-l}.$$所以如果$E(l,r,t)$表示预期的排列符号

 （$+1$对于甚至，$-1$奇数），

 我们得到递归$$E(l,r,t) = \sum_{m=l}^r \Pr(m\text{ minimum}) (-1)^{m-l} E(l,m-1,m) E(m+1,r,t).$$最小概率是$$\Pr(m\text{ minimum}) = \frac{t-m} {\sum_{j=l}^r (t-j)}.$$最后，$$p(n,L)=\frac{1+E(1,n,L/40+1)}{2}.$$---

 # 2.Python实现```python
from fractions import Fraction
from functools import lru_cache

def probability_even(n, L, spacing=40):
    # target coordinate
    t0 = Fraction(L, spacing) + 1

    @lru_cache(None)
    def expected_sign(l, r, t):
        """
        Expected permutation sign (+1 even, -1 odd)
        for boats l..r with target coordinate t.
        """

        # empty or single boat => identity permutation
        if l >= r:
            return Fraction(1, 1)

        count = r - l + 1

        # S = sum_{j=l}^r (t - j)
        S = Fraction(count, 1) * t - (l + r) * count // 2

        total = Fraction(0, 1)

        for m in range(l, r + 1):

            # probability that m is the minimum
            pm = (t - m) / S

            # parity change caused by moving m to front
            sign_flip = -1 if ((m - l) & 1) else 1

            # left and right independent subproblems
            left = expected_sign(l, m - 1, Fraction(m, 1))
            right = expected_sign(m + 1, r, t)

            total += pm * sign_flip * left * right

        return total

    e = expected_sign(1, n, t0)

    # convert expected sign to probability of even permutation
    return (Fraction(1, 1) + e) / 2

def rounded_decimal(frac, digits=10):
    scale = 10 ** digits
    x = frac * scale

    q = x.numerator // x.denominator
    r = x.numerator % x.denominator

    # round half up
    if 2 * r >= x.denominator:
        q += 1

    integer = q // scale
    decimal = q % scale

    return f"{integer}.{decimal:0{digits}d}"

# verification
print(probability_even(3, 160))          # 56/135
print(rounded_decimal(probability_even(4, 400), 10))
print(rounded_decimal(probability_even(13, 1800), 10))
```---

 # 3. 代码演练

 ##`expected_sign(l, r, t)`这会递归地计算船只产生的排列的预期符号$l$通过$r$。 

### 基本情况```python
if l >= r:
    return Fraction(1, 1)
```一艘船（或空间隔）贡献了均匀的排列。 

---

 ### 总指数率```python
S = sum(t - j)
```这是区间内所有指数的总速率。 

---

 ### 选择最小值```python
pm = (t - m) / S
```独立指数选择与其比率成比例的最小值。 

---

 ### 平价贡献```python
sign_flip = (-1)^(m-l)
```将最小的船移到前面需要$m-l$互换。 

---

 ### 递归分解```python
left = expected_sign(...)
right = expected_sign(...)
```左右部分成为独立的子问题。
