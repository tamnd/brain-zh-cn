[欧拉计划问题 161](https://projecteuler.net/problem=161)

 ## 解决方案

 **答案：**`20574308184277971`让董事会成为$9\times 12$，所以有$108$细胞总数。 

由于每个三联板恰好覆盖$3$单元格，每个平铺都精确使用$$108/3 = 36$$三联骨牌。 

关键的困难在于三联骨牌可以跨越行边界，因此简单的逐行 DP 是不够的。 标准解决方案是**断面动态规划**方法。 

---

 # 1.数学分析

 我们有三联骨牌的六个方向：

 - 两个直的特罗米诺：

 - 水平$1\times 3$- 垂直的$3\times 1$- 四个 L 形特罗米诺骨牌。 

我们按行优先顺序逐个单元地处理电路板。 

---

 ## 前沿代表

 在任何时候，一些未来的单元已经被之前开始的部分占据。 

因为垂直三联骨牌最多可以向下延伸两行，所以记住以下内容就足够了：

 - 当前行
 - 下一行
 - 下一行之后

 对于宽度$9$，这自然由位掩码表示。 

常见的优化是：

 - 一次处理一个细胞，
 - 保持相对于当前位置的接下来两行的占用率。 

存在等效配方； 最干净的递归是：$$F(pos, mask_0, mask_1, mask_2)$$在哪里：

-$pos$= 当前行索引，
 -$mask_0$= 当前行的占用情况，
 -$mask_1$= 下一行的占用情况，
 -$mask_2$= 下一行之后的行占用情况。 

每个掩码有 9 位。 

当当前行已满时：$$mask_0 = 2^9 - 1 = 511$$我们推进：$$(mask_0,mask_1,mask_2)\to(mask_1,mask_2,0)$$并移至下一行。 

---

 ## 填充第一个空单元格

 每个阶段：

 1. 找到最左边的空位$mask_0$。 
2. 尝试覆盖该单元的每个三联骨方向。 
3. 相应地更新掩码。 

这保证：

 - 无重叠，
 - 无遗漏，
 - 每个平铺都只计算一次。 

---

 ## 为什么这有效

 这是一个经典的transfer-DP / profile-DP 论点。 

未来仅取决于已处理细胞和未处理细胞之间的边界。 

因为三联骨牌的高度最多为 3，所以状态只需要 3 行信息。 

可达状态的数量是可控的（最多几十万），并且记忆使搜索速度更快。

 # 2.Python实现```python
from functools import lru_cache

W = 9
H = 12
FULL = (1 << W) - 1

# ---------------------------------------------------------
# Helper routines
# ---------------------------------------------------------

def bit(mask, c):
    return (mask >> c) & 1

def setbit(mask, c):
    return mask | (1 << c)

# ---------------------------------------------------------
# Recursive profile DP
# ---------------------------------------------------------

@lru_cache(None)
def solve(row, m0, m1, m2):
    """
    row = current row index

    m0 = occupancy mask for current row
    m1 = occupancy mask for next row
    m2 = occupancy mask for row+2
    """

    # Finished all rows
    if row == H:
        return 1 if (m0, m1, m2) == (0, 0, 0) else 0

    # If current row is completely filled,
    # advance frontier downward
    if m0 == FULL:
        return solve(row + 1, m1, m2, 0)

    # Find first empty column
    c = 0
    while bit(m0, c):
        c += 1

    ans = 0

    # -------------------------------------------------
    # Try all 6 triomino orientations
    # -------------------------------------------------

    # 1) Horizontal 1x3
    if c + 2 < W:
        if (not bit(m0, c + 1)
                and not bit(m0, c + 2)):
            ans += solve(
                row,
                setbit(setbit(setbit(m0, c), c + 1), c + 2),
                m1,
                m2
            )

    # 2) Vertical 3x1
    if row + 2 < H:
        if (not bit(m1, c)
                and not bit(m2, c)):
            ans += solve(
                row,
                setbit(m0, c),
                setbit(m1, c),
                setbit(m2, c)
            )

    # 3) L-shape: cells
    # (r,c), (r+1,c), (r,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m1, c)
                and not bit(m0, c + 1)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c),
                m2
            )

    # 4) L-shape:
    # (r,c), (r+1,c), (r+1,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m1, c)
                and not bit(m1, c + 1)):
            ans += solve(
                row,
                setbit(m0, c),
                setbit(setbit(m1, c), c + 1),
                m2
            )

    # 5) L-shape:
    # (r,c), (r,c+1), (r+1,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m0, c + 1)
                and not bit(m1, c + 1)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c + 1),
                m2
            )

    # 6) L-shape:
    # (r,c), (r,c+1), (r+1,c)
    if c + 1 < W and row + 1 < H:
        if (not bit(m0, c + 1)
                and not bit(m1, c)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c),
                m2
            )

    return ans

print(solve(0, 0, 0, 0))

 ## 行进步```python
if m0 == FULL:
    return solve(row + 1, m1, m2, 0)
```当当前行完成时：

 - 下一行成为当前行，
 - 第三行成为下一个，
 - 添加一个新的空行。

 ## 第一个空单元格```python
c = 0
while bit(m0, c):
    c += 1
```规范化至关重要：

 始终首先填充最左边的空单元格。 

这可以防止重复计数。

 ## 棋子位置

 每个方向都会检查：

 - 界限，
 - 重叠约束。 

然后设置相应的位。 

示例：垂直多米诺骨牌```python
if row + 2 < H:
    if (not bit(m1, c)
            and not bit(m2, c)):
```要求接下来两行中的同一列为空。
