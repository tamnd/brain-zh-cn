[欧拉项目问题 283](https://projecteuler.net/problem=283)

 ## 解决方案

 **答案：**`28038042525570324`设三角形各边为$a,b,c$, 半周长$s$，和面积$K$。 

我们被告知$$\frac{K}{a+b+c}=n$$对于某个整数$1\le n\le 1000$。 

自从$a+b+c=2s$,$$K = 2ns.$$使用海伦公式，$$K^2=s(s-a)(s-b)(s-c).$$定义$$x=s-a,\qquad y=s-b,\qquad z=s-c.$$然后$$a=y+z,\quad b=z+x,\quad c=x+y,$$和$$s=x+y+z.$$代入 Heron：$$K^2=sxyz.$$但$K=2ns$， 所以$$4n^2s^2=sxyz.$$自从$s=x+y+z$,$$xyz = 4n^2(x+y+z).$$两边除以$xyz$,$$\frac1x+\frac1y+\frac1z=\frac1{4n^2}.$$那么问题就变成了：

 > 求所有正整数解
 >
 >
 >
 >
 >$$\frac1x+\frac1y+\frac1z=\frac1{4n^2},$$>
 >
 >
 >
 > 对于$1\le n\le1000$，然后将所有相应周长相加
 >
 >
 >
 >
 >$$P=2(x+y+z).$$---

 # 关键因式分解

 让$$d=4n^2.$$然后$$\frac1x+\frac1y+\frac1z=\frac1d.$$认为$x\le y\le z$。 

重新排列：$$yz=d(x+y+z).$$移动条款：$$yz-dy-dz=d x.$$添加$d^2$:$$(y-d)(z-d)=d(d+x).$$现在对于每个$x$，每个约数对$d(d+x)$给出了一个解决方案：$$y=d+u,\qquad z=d+v,$$在哪里$$uv=d(d+x).$$这产生了快速枚举算法。 

边界是可以管理的，因为：$$x\le 3d$$（从$3/x\ge 1/d$）。 

---

 # Python 实现```python
from math import isqrt

LIMIT = 1000

total = 0

for n in range(1, LIMIT + 1):

    d = 4 * n * n

    # From x <= y <= z and
    # 1/x + 1/y + 1/z = 1/d
    # we get x <= 3d
    for x in range(1, 3 * d + 1):

        target = d * (d + x)

        # Enumerate divisor pairs
        r = isqrt(target)

        for u in range(1, r + 1):

            if target % u != 0:
                continue

            v = target // u

            y = d + u
            z = d + v

            # enforce ordering
            if x > y or y > z:
                continue

            # verify equation (safety check)
            if x * y * z != d * (x + y + z):
                continue

            perimeter = 2 * (x + y + z)

            total += perimeter

print(total)
```---
