[欧拉项目 463 问题](https://projecteuler.net/problem=463)

 ## 解决方案

 **答案：**`808981553`我们给出了递归定义的函数$$\begin{aligned} f(1)&=1,\\ f(3)&=3,\\ f(2n)&=f(n),\\ f(4n+1)&=2f(2n+1)-f(n),\\ f(4n+3)&=3f(2n+1)-2f(n), \end{aligned}$$和$$S(n)=\sum_{i=1}^n f(i).$$我们必须计算$$S(3^{37}) \pmod{10^9}.$$---

 # 1.数学分析

 ## 步骤 1：了解结构$f(n)$递归大致通过以下因子减少参数$2$或者$4$，因此记忆递归即使对于$3^{37}$。 

让$$a_n=f(2n+1)$$（奇数索引值）。 

由定义关系可知：$$\begin{aligned} a_{2n} &=f(4n+1) =2f(2n+1)-f(n) =2a_n-f(n), \\[1ex] a_{2n+1} &=f(4n+3) =3f(2n+1)-2f(n) =3a_n-2f(n). \end{aligned}$$这些恒等式使我们能够推导出$S(n)$。 

---

 ## 步骤 2：推导递归$S(n)$我们按残差类模来分割数字$4$。 

经过代数运算（使用上述关系和恒等式）$f(2n)=f(n)$），得到：$$\boxed{ S(4n) = 6S(2n)-8S(n)+3f(n)-1 }$$

$$\boxed{ S(4n+1) = 6S(2n)-8S(n)+2f(n)+2f(2n+1)-1 }$$

$$\boxed{ S(4n+2) = 6S(2n)-8S(n)+2f(n)+3f(2n+1)-1 }$$

$$\boxed{ S(4n+3) = 6S(2n)-8S(n)+6f(2n+1)-1 }$$这些公式减少了问题的规模$n$粗略地$n/2$，给出对数复杂度。 

---

 ## 步骤 3：复杂性

 对于$N=3^{37}$,$$3^{37}\approx 4.5\times 10^{17},$$但每个递归调用都会将参数除以$2$或者$4$，所以记忆化使得计算速度非常快。 

我们只需要最后一个$9$数字，因此所有算术都可以模数执行$$10^9.$$---

 # 2.Python实现```python
from functools import lru_cache

MOD = 10**9

# -------------------------------------------------------
# f(n)
# -------------------------------------------------------

@lru_cache(None)
def f(n):
    if n == 1:
        return 1
    if n == 3:
        return 3

    # even case
    if n % 2 == 0:
        return f(n // 2)

    # n = 4k + 1
    if n % 4 == 1:
        k = (n - 1) // 4
        return 2 * f(2 * k + 1) - f(k)

    # n = 4k + 3
    k = (n - 3) // 4
    return 3 * f(2 * k + 1) - 2 * f(k)

# -------------------------------------------------------
# Small exact values for S(n)
# -------------------------------------------------------

small = [0]
s = 0
for i in range(1, 20):
    s += f(i)
    small.append(s)

# -------------------------------------------------------
# S(n)
# -------------------------------------------------------

@lru_cache(None)
def S(n):
    if n < 20:
        return small[n]

    q, r = divmod(n, 4)

    if r == 0:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 3 * f(q)
            - 1
        )

    elif r == 1:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 2 * f(q)
            + 2 * f(2 * q + 1)
            - 1
        )

    elif r == 2:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 2 * f(q)
            + 3 * f(2 * q + 1)
            - 1
        )

    else:  # r == 3
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 6 * f(2 * q + 1)
            - 1
        )

    return ans

# -------------------------------------------------------
# Required value
# -------------------------------------------------------

N = 3**37

print(S(N) % MOD)
```---

 # 3. 代码演练

 ## 功能`f(n)`直接实现递归定义。 

- 如果$n$是偶数：$$f(2n)=f(n)$$- 如果$n=4k+1$:$$f(4k+1)=2f(2k+1)-f(k)$$- 如果$n=4k+3$:$$f(4k+3)=3f(2k+1)-2f(k)$$记忆（`@lru_cache`) ensures every value is computed once.

 - -

＃＃ 功能`S(n)`使用每个残差模的派生递推$4$。 

示例：

 如果$n=4q+2$,```python
6 * S(2*q)
- 8 * S(q)
+ 2 * f(q)
+ 3 * f(2*q + 1)
- 1
```这将问题简化为更小的参数。 

---

 ## 对给定示例的验证

 该程序重现：$$S(8)=22$$和$$S(100)=3604.$$所以递归系统与问题陈述是一致的。

 # 4.最终验证

 递归深度仅为$O(\log n)$，因此评估$S(3^{37})$记忆化在计算上是微不足道的。 

计算值取模$10^9$是：$$808981553.$$因此最后$9$数字是：

 **答案：808981553**
