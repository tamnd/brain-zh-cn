[项目欧拉问题 92](https://projecteuler.net/problem=92)

 ## 解决方案

 **答案：**`8581146`让$f(n)$表示数字的平方和$n$。 

例如，$$f(44)=4^2+4^2=32.$$反复申请$f$产生一条链：$$44 \to 32 \to 13 \to 10 \to 1,$$

$$85 \to 89 \to 145 \to 42 \to \cdots \to 89.$$问题问：

 > 起始号码有多少$1 \le n < 10^7$最终到达$89$？ 

---

 # 数学分析

 ## 1. 关键观察：链条迅速收缩

 假设$n < 10^7$。 然后$n$最多有$7$数字。 

平方和的最大可能值出现在：$$9,999,999$$其数位平方和为$$7 \cdot 9^2 = 7 \cdot 81 = 567.$$因此，**一步**之后，千万以下的数字都会映射到范围内$$1 \le f(n) \le 567.$$这是至关重要的见解。 

我们不需要独立研究一千万条长链，我们只需要确定，对于每个值$1,\dots,567$，最终是否达到：

 -$1$， 或者
-$89$。 

然后，每个较大的数字都会继承其第一个数字平方和的命运。 

---

 ## 2. 末期循环

 通过实验（并且可以证明），每条链都以两个周期之一结束：$$1 \to 1$$或者$$89 \to 145 \to 42 \to 20 \to 4 \to 16 \to 37 \to 58 \to 89.$$所以每个起始数字最终都会落入其中$1$或者$89$。 

---

 ## 3.动态规划/记忆

 定义：$$g(x)= \begin{cases} 1 & \text{if the chain reaches }1,\\ 89 & \text{if the chain reaches }89. \end{cases}$$我们计算$g(x)$为所有人$x \le 567$使用记忆法。 

然后对于每个数字$n < 10^7$:

 1. 计算$s=f(n)$。 
2、查看是否$s$结束于$89$。 

这给出了一个$O(10^7)$解决方案，这在Python中是完全可行的。 

---

 # Python 实现```python
def digit_square_sum(n):
    """Return the sum of the squares of the digits of n."""
    total = 0
    while n > 0:
        digit = n % 10
        total += digit * digit
        n //= 10
    return total

# Memo table:
# memo[x] = True  if x eventually reaches 89
# memo[x] = False if x eventually reaches 1
memo = {1: False, 89: True}

def arrives_at_89(n):
    """
    Determine whether n eventually reaches 89.
    Uses memoization to avoid recomputation.
    """
    chain = []

    while n not in memo:
        chain.append(n)
        n = digit_square_sum(n)

    result = memo[n]

    # Store results for all numbers seen in the chain
    for x in chain:
        memo[x] = result

    return result

LIMIT = 10_000_000

count = 0

for n in range(1, LIMIT):
    if arrives_at_89(digit_square_sum(n)):
        count += 1

print(count)
```---
