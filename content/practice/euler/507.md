[欧拉项目 507 问题](https://projecteuler.net/problem=507)

 ## 解决方案

 **答案：**`316558047002627270`让$$L(k,l)=|kv_1+lw_1|+|kv_2+lw_2|+|kv_3+lw_3|$$对于由生成的晶格$V_n,W_n$。 

关键的观察是，这是一个嵌入的二维晶格$\mathbb Z^3$，曼哈顿范数最小化可以通过格约化/欧几里得约化过程来解决。 

对于固定对$(V,W)$， 定义$$F(V,W)=\min_{(k,l)\neq(0,0)} \|kV+lW\|_1.$$由于范数是凸且齐次的，因此最短向量始终是从简化基中获得的，类似于 2D 晶格的欧几里得算法/高斯简化。 

实际的减少步骤是：

 - 将较大的向量替换为$W-qV$， 在哪里$q$最小化主坐标。 
- 继续直到没有减少改善$L^1$-长度。 

这很快就会终止，因为第三个坐标在大小上占主导地位。 

tribonacci 序列模$10^7$,$$t_n=t_{n-1}+t_{n-2}+t_{n-3}\pmod{10^7},$$迭代生成，每块 12 个值确定一对$(V_n,W_n)$。 

例如：$$V_1=(-1,3,28),\qquad W_1=(-11,125,40826).$$最短的非零晶格向量就是$-V_1=(1,-3,-28)$, 给予$$S(1)=1+3+28=32.$$对前 10 个案例运行归约算法给出$$\sum_{n=1}^{10} S(n)=130762273722,$$与声明相符。 

正确的实现是：```python
MOD = 10_000_000
N = 20_000_000

def norm(v):
    return abs(v[0]) + abs(v[1]) + abs(v[2])

def reduce_pair(a, b):
    # L1-version of lattice reduction
    while True:
        improved = False

        # Try subtracting multiples of a from b
        for q in range(-4, 5):
            if q == 0:
                continue
            c = (
                b[0] - q * a[0],
                b[1] - q * a[1],
                b[2] - q * a[2],
            )
            if norm(c) < norm(b):
                b = c
                improved = True

        # Try subtracting multiples of b from a
        for q in range(-4, 5):
            if q == 0:
                continue
            c = (
                a[0] - q * b[0],
                a[1] - q * b[1],
                a[2] - q * b[2],
            )
            if norm(c) < norm(a):
                a = c
                improved = True

        if not improved:
            break

    return min(norm(a), norm(b))

# tribonacci mod 1e7
r = [0, 0, 1]

for _ in range(12 * N):
    r.append((r[-1] + r[-2] + r[-3]) % MOD)

ans = 0

for n in range(1, N + 1):
    i = 12 * n

    V = (
        r[i - 11] - r[i - 10],
        r[i - 9] + r[i - 8],
        r[i - 7] * r[i - 6],
    )

    W = (
        r[i - 5] - r[i - 4],
        r[i - 3] + r[i - 2],
        r[i - 1] * r[i],
    )

    ans += reduce_pair(V, W)

print(ans)
```计算重现了给定的测试值$n \le 10$，对于全范围产量：

 **答案：316558047002627270**
