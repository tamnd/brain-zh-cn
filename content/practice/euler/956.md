[项目欧拉问题 956](https://projecteuler.net/problem=956)

 ## 解决方案

 **答案：**`882086212`让$$F(n,m)=D(n,m)=\sum_{\substack{d\mid n\\ m\mid \Omega(d)}} d.$$为了$$n=\prod p_i^{e_i},$$生成函数$$\prod_i (1+p_i x+p_i^2x^2+\cdots+p_i^{e_i}x^{e_i})$$系数为$x^k$等于除数之和$d\mid n$和$\Omega(d)=k$。 

因此$D(n,m)$是其索引可被整除的系数之和$m$。 

使用单位根滤波器，$$D(n,m)=\frac1m\sum_{j=0}^{m-1} \prod_i\left(\sum_{k=0}^{e_i}(p_i\omega^j)^k\right),$$在哪里$\omega$是一个原始的$m$单位模的次方根$999999001$。 

---

 对于超级因素：$$n\bigstar=\prod_{t=1}^n t^{\binom{n-t+2}{2}},$$所以素数的指数$p$是$$e_p=\sum_{a\ge1}\sum_{\substack{t\le n\\ p^a\mid t}} \binom{n-t+2}{2}.$$为了$n=1000$，我们计算所有$e_p$，然后评估单位根公式模$$999999001.$$Python实现：```python
from sympy import primerange, primitive_root

MOD = 999_999_001
m = 1000
n = 1000

# prime exponents in n★
E = {}
for p in primerange(1, n + 1):
    e = 0
    pk = p
    while pk <= n:
        for t in range(pk, n + 1, pk):
            e += (n - t + 1) * (n - t + 2) // 2
        pk *= p
    E[p] = e

g = primitive_root(MOD)
w = pow(g, (MOD - 1) // m, MOD)
inv_m = pow(m, MOD - 2, MOD)

ans = 0

for j in range(m):
    omega = pow(w, j, MOD)
    prod = 1

    for p, e in E.items():
        r = p * omega % MOD

        if r == 1:
            s = e + 1
        else:
            s = (pow(r, e + 1, MOD) - 1) * pow(r - 1, MOD - 2, MOD)

        prod = (prod * s) % MOD

    ans = (ans + prod) % MOD

ans = (ans * inv_m) % MOD
print(ans)
```这评估为：
