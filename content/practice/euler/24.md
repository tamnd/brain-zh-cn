[欧拉项目问题 24](https://projecteuler.net/problem=24)

 ## 解决方案

 **答案：**`2783915460`找到数字的第一百万个字典排列`0–9`，我们使用**阶乘系统**而不是生成所有`10! = 3,628,800`排列。 

我们想要 **1,000,000th** 排列，但索引来自`0`让数学变得更容易：$$999,999$$在每一步中，使用阶乘块确定哪个数字属于下一个位置：

 -$9! = 362880$:$999999 \div 362880 = 2$余$274239$→ 选择第三位数字：`2`剩余位数：`0,1,3,4,5,6,7,8,9`-$8! = 40320$:$274239 \div 40320 = 6$余$32319$→ 挑选`7`其余的：`0,1,3,4,5,6,8,9`-$7! = 5040$:$32319 \div 5040 = 6$余$2079$→ 挑选`8`继续这个过程会产生：`2783915460`### 干净的 Python 代码```python
from math import factorial

digits = list("0123456789")
n = 999999  # zero-based index

result = []

for i in range(9, -1, -1):
    f = factorial(i)
    index = n // f
    result.append(digits.pop(index))
    n %= f

answer = "".join(result)
print(answer)
```跟踪阶乘选择可确认排列：`2783915460`**答案：2783915460**
