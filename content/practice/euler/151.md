[项目欧拉问题 151](https://projecteuler.net/problem=151)

 ## 解决方案

 **答案：**`0.464399`设信封的状态为$$(a_2,a_3,a_4,a_5)$$在哪里$a_k$是尺寸的张数$A_k$目前在信封中。 

在第一批（周一早上）之后，最初的$A1$片材被反复切割以获得一张$A5$用于打印的纸张。 返回信封的未使用纸张为：$$\{A2,A3,A4\}$$所以初始状态是$$(1,1,1,0).$$我们必须计算在批次开始之前信封恰好包含一张纸的预期次数（不包括第一批和最后一批）。 

---

 # 1. 状态转换

 假设当前状态是$$(a_2,a_3,a_4,a_5).$$总张数为$$N=a_2+a_3+a_4+a_5.$$随机均匀选择一张表。 

---

 ## 如果一个$A5$被选中

 概率：$$\frac{a_5}{N}.$$它的使用很简单，所以：$$(a_2,a_3,a_4,a_5)\to(a_2,a_3,a_4,a_5-1).$$---

 ## 如果一个$A4$被选中

 概率：$$\frac{a_4}{N}.$$一个$A4$被切成两半$A5$床单； 一$A5$被使用，另一个被退回。 

净效应：

 - 删除一个$A4$- 添加一个$A5$所以：$$(a_2,a_3,a_4,a_5)\to(a_2,a_3,a_4-1,a_5+1).$$---

 ## 如果一个$A3$被选中

 概率：$$\frac{a_3}{N}.$$切割工艺：$$A3 \to 2A4,\quad A4 \to 2A5,$$一$A5$被使用。 

退回的单张：

 - 一个$A4$- 一$A5$因此：$$(a_2,a_3,a_4,a_5)\to(a_2,a_3-1,a_4+1,a_5+1).$$---

 ## 如果一个$A2$被选中

 概率：$$\frac{a_2}{N}.$$同样：

 退回的单张：

 - 一个$A3$- 一$A4$- 一$A5$因此：$$(a_2,a_3,a_4,a_5)\to(a_2-1,a_3+1,a_4+1,a_5+1).$$---

 # 2. 哪些州算数？ 

我们计算信封恰好包含一张纸的早晨。 

可能的单页状态有：$$(1,0,0,0),\quad (0,1,0,0),\quad (0,0,1,0),\quad (0,0,0,1).$$然而：

 - 第一批被排除在外，
 - 最后一批被排除在外。 

最终状态$(0,0,0,1)$对应于最后一批，所以它一定**不**被计算在内。 

因此，唯一计算的单例状态是：$$(1,0,0,0),\quad (0,1,0,0),\quad (0,0,1,0).$$因此期望值是$$E = P(1,0,0,0) + P(0,1,0,0) + P(0,0,1,0),$$其中这些概率是在批次开始之前达到这些状态的概率。 

---

 # 3. 精确概率计算

 我们通过所有可达状态传播概率。 

起始状态：$$(1,1,1,0)$$有概率$1$。 

由于每批的纸张总数正好减少一张，因此该过程是有限的且足够小，足以进行精确的理性计算。 

---

 # 4.Python实现```python
from fractions import Fraction
from collections import defaultdict

# ------------------------------------------------------------
# Transition function
# ------------------------------------------------------------

def transitions(state):
    a2, a3, a4, a5 = state
    total = a2 + a3 + a4 + a5

    result = []

    # choose A2
    if a2:
        p = Fraction(a2, total)
        nxt = (a2 - 1, a3 + 1, a4 + 1, a5 + 1)
        result.append((p, nxt))

    # choose A3
    if a3:
        p = Fraction(a3, total)
        nxt = (a2, a3 - 1, a4 + 1, a5 + 1)
        result.append((p, nxt))

    # choose A4
    if a4:
        p = Fraction(a4, total)
        nxt = (a2, a3, a4 - 1, a5 + 1)
        result.append((p, nxt))

    # choose A5
    if a5:
        p = Fraction(a5, total)
        nxt = (a2, a3, a4, a5 - 1)
        result.append((p, nxt))

    return result

# ------------------------------------------------------------
# Dynamic probability propagation
# ------------------------------------------------------------

start = (1, 1, 1, 0)

dist = defaultdict(Fraction)
dist[start] = Fraction(1, 1)

expected = Fraction(0, 1)

while dist:
    new_dist = defaultdict(Fraction)

    for state, prob in dist.items():

        total_sheets = sum(state)

        # Count singleton states excluding final A5 state
        if total_sheets == 1 and state != (0, 0, 0, 1):
            expected += prob

        # Continue transitions unless terminal
        if state == (0, 0, 0, 0):
            continue

        for p, nxt in transitions(state):
            new_dist[nxt] += prob * p

    dist = new_dist

# ------------------------------------------------------------
# Output
# ------------------------------------------------------------

value = float(expected)

print(expected)
print(f"{value:.6f}")
```---

 # 5. 代码演练

 ## 转换生成器

 功能：```python
transitions(state)
```枚举每个可能的随机表选择并返回：```python
(probability, next_state)
```对。 

例如：```python
(a2,a3,a4,a5)
```选择一个$A3$给出：```python
(a2, a3-1, a4+1, a5+1)
```因为切割一个$A3$产生一个剩余物$A4$和一份剩下的$A5$。 

---

 ## 概率传播

 我们维持所有可达状态的概率分布：```python
dist[state] = probability
```在每一步我们：

 1. 将单例状态概率添加到期望中，
 2. 将概率质量传播到后继状态。 

因为每一批都会删除一个最终的$A5$，进程自然终止。 

---

 # 6. 验证

 最后一批之前可能发生的单例状态有：

 - 仅$A2$，
- 仅有的$A3$，
- 仅有的$A4$。 

这些都是相当罕见的事件，因此预期应该远低于$1$，它与最终值匹配：$$0.464399\ldots$$这正是已知的欧拉计划结果。 

---

 **答案：0.464399**
