[欧拉项目 434 问题](https://projecteuler.net/problem=434)

 ## 解决方案

 **答案：**`863253606`关键的见解是，这**并不是一个真正的刚性问题**——它变成了**图连接计数问题**。 

向网格单元添加对角线会将相应的行和列“锁定”在一起。 这产生了二分图：

 - 一个分区 =$m$行方向，
 - 另一个分区=$n$列方向，
 - 边 = 添加到单元格的对角线。 

网格刚性定理指出：

 > 安$m\times n$支撑网格是刚性的**当且仅当**其关联的二部图是相连的。 

因此：$$R(m,n)$$正是**连接的标记二部图**的数量，其中部分的大小$m$和$n$。 

让$B(m,n)$表示这个计数。 由于两个部分之间的每个可能的边缘都可能独立地存在或不存在，因此有$$2^{mn}$$总二部图。 

要对连接的组件进行计数，请通过隔离包含固定行顶点的连接组件来使用包含-排除：$$B(m,n) = 2^{mn} - \sum_{\substack{1\le a\le m\\0\le b\le n\\(a,b)\neq(m,n)}} \binom{m-1}{a-1} \binom{n}{b} B(a,b) 2^{(m-a)(n-b)}$$说明：

 - 选择$a-1$附加行顶点来连接区分行，
 - 选择$b$柱顶点，
 - 要求这些选定的顶点形成一个连接的组件：$B(a,b)$,
 - 其余顶点之间可以具有任意边：$2^{(m-a)(n-b)}$,
 - 组件和外部之间不得有任何边缘交叉。 

我们计算所有的 DP$1\le m,n\le100$，然后求和$$S(100)=\sum_{i=1}^{100}\sum_{j=1}^{100}R(i,j) \pmod{1000000033}.$$一个干净的 Python 实现是：```python
from math import comb

MOD = 1000000033
N = 100

# R[m][n] = number of rigid m x n grids
R = [[0] * (N + 1) for _ in range(N + 1)]

# Precompute powers of 2^(mn)
pow2 = [[pow(2, i * j, MOD) for j in range(N + 1)]
        for i in range(N + 1)]

for m in range(1, N + 1):
    # boundary case needed by recurrence
    R[m][0] = 1 if m == 1 else 0

    for n in range(1, N + 1):
        total = pow2[m][n]

        # subtract disconnected graphs
        for a in range(1, m + 1):
            for b in range(n + 1):

                # skip the full graph itself
                if a == m and b == n:
                    break

                ways_choose = (
                    comb(m - 1, a - 1)
                    * comb(n, b)
                )

                contribution = (
                    ways_choose
                    * R[a][b]
                    * pow2[m - a][n - b]
                )

                total -= contribution

        R[m][n] = total % MOD

# Compute S(100)
answer = 0
for i in range(1, N + 1):
    for j in range(1, N + 1):
        answer += R[i][j]

answer %= MOD
print(answer)
```对照问题陈述进行验证：

 -$R(2,3)=19$✓
 -$R(5,5)=23679901$✓
 -$S(5)=25021721$✓

 运行 DP 至$100\times100$给出：

 **答案：863253606**
