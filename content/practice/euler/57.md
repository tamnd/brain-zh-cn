[欧拉项目问题 57](https://projecteuler.net/problem=57)

 ## 解决方案

 **答案：**`153`继续分数展开式为$\sqrt2$是$$\sqrt2 = 1 + \cfrac1{2+\cfrac1{2+\cfrac1{2+\cdots}}}.$$我们被问到：

 > 在前 1000 个收敛（展开）中，有多少个分数的分子位数多于分母？ 

---

 # 数学分析

 收敛点是：$$\frac32,\ \frac75,\ \frac{17}{12},\ \frac{41}{29},\dots$$我们需要一种系统的方法来生成它们。 

## 1. 推导递推式

 让$n$第-次收敛为$$\frac{p_n}{q_n}.$$观察模式：$$\frac32,\ \frac75,\ \frac{17}{12},\ \frac{41}{29}.$$连分式结构给出：$$x_{n+1} = 1 + \frac1{1+x_n}.$$但对于分子和分母来说，还有更清晰的直接递归式。 

开始于$$\frac{p_n}{q_n},$$下一个扩展是$$1+\frac1{1+\frac{p_n}{q_n}} = 1+\frac{q_n}{p_n+q_n} = \frac{p_n+2q_n}{p_n+q_n}.$$所以，$$p_{n+1}=p_n+2q_n,$$

$$q_{n+1}=p_n+q_n.$$初始值：$$p_1=3,\qquad q_1=2.$$---

 ## 2. 检查重复情况

 来自$\frac32$:$$p_2 = 3 + 2\cdot2 = 7,$$

$$q_2 = 3+2 = 5.$$所以我们得到$\frac75$。 

下一个：$$p_3 = 7 + 2\cdot5 = 17,$$

$$q_3 = 7+5 = 12.$$再次正确。 

---

 ## 3. 数字比较

 我们必须数数有多少次$$\text{digits}(p_n) > \text{digits}(q_n).$$正整数的位数$x$是$$\lfloor \log_{10}(x)\rfloor + 1,$$但在Python中我们可以简单地比较：```python
len(str(p)) > len(str(q))
```由于只有 1000 次迭代，因此效率非常高。 

---

 # Python 实现```python
# Project Euler Problem 57

# Initial convergent of sqrt(2)
p = 3  # numerator
q = 2  # denominator

count = 0

# Check the first 1000 expansions
for _ in range(1000):

    # Count cases where numerator has more digits
    if len(str(p)) > len(str(q)):
        count += 1

    # Generate next convergent:
    # p_{n+1} = p_n + 2*q_n
    # q_{n+1} = p_n + q_n
    p, q = p + 2*q, p + q

print(count)
```---

 # 小案例验证

 生成的前几个收敛是：$$\frac32,\ \frac75,\ \frac{17}{12},\ \frac{41}{29}, \frac{99}{70},\ \frac{239}{169},\ \frac{577}{408},\ \frac{1393}{985}.$$第 8 个收敛确实是第一个分子数字超过分母数字的收敛：

 -$1393$: 4 位数字
 -$985$: 3 位数字

 所以递归是正确的。 

运行 1000 次展开的完整计算得出：$$153$$---

 结果是合理的：这种数字溢出偶尔会发生，但并非极少。 

**答案：153**
