[欧拉项目 431 问题](https://projecteuler.net/problem=431)

 ## 解决方案

 **答案：**`23.386029052`让筒仓有半径$R$，然后让谷物从该点倒出$(x,0)$在气缸的顶部。 

如果休止角为$\alpha$，则颗粒的自由表面形成斜率$$\tan\alpha$$与水平。 

对于任意点$(u,v)$在圆形横截面中，谷物上方的垂直空高度因此为$$h(u,v)=\tan\alpha\;\sqrt{(u-x)^2+v^2}.$$因此浪费的体积是$$V(x)=\tan\alpha\iint_D \sqrt{(u-x)^2+v^2}\,dA,$$在哪里$D$是磁盘$u^2+v^2\le R^2$。 

---

 # 1. 积分转换

 使用以倾点为中心的极坐标：$$u=x+r\cos\theta,\qquad v=r\sin\theta.$$沿方向$\theta$，当光线离开筒仓时$$(x+r\cos\theta)^2+(r\sin\theta)^2=R^2.$$解决$r$,$$r_{\max}(\theta) = -x\cos\theta+\sqrt{R^2-x^2\sin^2\theta}.$$由于被积函数很简单$r$,$$V(x) = \tan\alpha \int_0^{2\pi}\int_0^{r_{\max}(\theta)} r\cdot r\,dr\,d\theta.$$所以$$\boxed{ V(x)= \frac{\tan\alpha}{3} \int_0^{2\pi} \left( -x\cos\theta+\sqrt{R^2-x^2\sin^2\theta} \right)^3 d\theta }.$$---

 # 2. 检查示例

 该声明的第一个示例使用：

 - 直径$6\Rightarrow R=3$,
 -$\alpha=30^\circ$,
 -$x=0$。 

然后$$V(0) = \frac{\tan30^\circ}{3} \int_0^{2\pi} 3^3\,d\theta = 18\pi\tan30^\circ = 6\pi\sqrt3 \approx 32.648388556,$$与问题陈述完全匹配。 

所以这个公式是正确的。 

---

 # 3.实际问题数据

 现在使用：$$R=6,\qquad \alpha=40^\circ.$$我们寻求一切$x\in[0,6]$这样$V(x)$是一个完美的正方形。 

自从$V(x)$严格增加$x$，每个方格最多有一个解。 

计算范围：$$V(0)\approx 379.60, \qquad V(6)\approx 644.43.$$因此唯一可能的完美平方是$$20^2,21^2,22^2,23^2,24^2,25^2.$$数值求解$V(x)=n^2$对于每个$n=20,\dots,25$给出：$$\begin{aligned} x_{20}&\approx1.6097585009208716,\\ x_{21}&\approx2.8060119465435142,\\ x_{22}&\approx3.6783279154320040,\\ x_{23}&\approx4.4264032917821366,\\ x_{24}&\approx5.1094202074447333,\\ x_{25}&\approx5.7561071894994169. \end{aligned}$$总结：$$\sum x = 23.386029051622676\ldots$$四舍五入为$9$小数位数：$$\boxed{23.386029052}$$---

 # 4.Python实现```python
import mpmath as mp

mp.mp.dps = 50

R = mp.mpf(6)
alpha = mp.radians(40)
T = mp.tan(alpha)

# Volume function
def V(x):
    def integrand(theta):
        return (
            -x * mp.cos(theta)
            + mp.sqrt(R*R - x*x * mp.sin(theta)**2)
        ) ** 3

    return (T / 3) * mp.quad(integrand, [0, 2 * mp.pi])

# Solve V(x) = n^2 by bisection
def solve_for_square(n):
    target = n * n

    lo = mp.mpf(0)
    hi = R

    for _ in range(100):
        mid = (lo + hi) / 2

        if V(mid) < target:
            lo = mid
        else:
            hi = mid

    return (lo + hi) / 2

roots = []

for n in range(20, 26):
    x = solve_for_square(n)
    roots.append(x)
    print(n, x)

answer = mp.fsum(roots)

print("Sum =", answer)
print("Rounded =", mp.nstr(answer, 12))
```---

 # 5. 代码演练

 -`V(x)`实现上面导出的精确积分公式。 
- 对于每个角度`theta`，圆盘内的光线长度为```python
-x*cos(theta) + sqrt(R^2 - x^2*sin(theta)^2)
```- 内径向积分贡献一个因素$r^3/3$。 
- 我们对以上进行数值积分$[0,2\pi]$。 
- 自从$V(x)$是单调的，二分安全地解决$$V(x)=n^2.$$- 仅限正方形$20^2$到$25^2$都在可达到的范围之内。
