[欧拉项目问题 218](https://projecteuler.net/problem=218)

 ## 解决方案

 **答案：**`0`让一个原始毕达哥拉斯三元组以标准方式生成$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$和$$m>n,\quad \gcd(m,n)=1,\quad m\not\equiv n\pmod 2.$$_完美_三角形还需要满足以下条件$c$是一个完美的正方形。 

我们被问到：

 > 有多少个完美的直角三角形$c\le 10^{16}$**不是**超级完美吗？ 

当三角形的面积可以被两者整除时，三角形就是超级完美的$6$和$28$，即通过$$\operatorname{lcm}(6,28)=84.$$关键是要表明**每个**完美三角形都自动是超级完美的。 

---

 # 第 1 步：描绘完美三角形的特征

 我们需要$$m^2+n^2 = k^2$$对于某个整数$k$。 

因此$(m,n,k)$本身是一个原始毕达哥拉斯三元组。 所以我们可以再次参数化：$$m=u^2-v^2,\qquad n=2uv,$$或反之亦然，与$$u>v,\qquad \gcd(u,v)=1,\qquad u\not\equiv v\pmod 2.$$代入得到所有完美三角形。 

---

 # 第二步：面积公式

 原三角形的面积为$$A=\frac{ab}{2}.$$使用标准公式，$$A =\frac{(m^2-n^2)(2mn)}{2} =mn(m^2-n^2).$$现在替代$$m=u^2-v^2,\qquad n=2uv.$$然后$$A =(u^2-v^2)(2uv)\bigl((u^2-v^2)^2-(2uv)^2\bigr).$$最后一个因素简化了：$$(u^2-v^2)^2-(2uv)^2 =u^4-6u^2v^2+v^4.$$但我们实际上并不需要显式扩展。 我们只需要整除$84=2^2\cdot3\cdot7$。 

---

 # 第三步：证明能被6整除

 因为$u,v$是互质且相反的宇称：

 - 其中之一$u,v$是偶数，
 - 其中之一$u,v$可以整除$3$，否则
 -$u^2-v^2\equiv0\pmod3$。 

因此在因素之中$$2uv,\qquad u^2-v^2$$总有一个因素$3$，显然有一个因素$2$。 

所以$6\mid A$。 

---

 # 第 4 步：证明能被 28 整除

 我们需要$4\cdot7\mid A$。 

由于其中之一$u,v$是偶数，$2uv$至少贡献$2^2$， 所以$4\mid A$。 

现在考虑整除$7$。 

模数$7$，二次余数是$$0,1,2,4.$$对于共素$u,v$， 检查$$u,\quad v,\quad u^2-v^2.$$如果两者都不是$u$也不$v$可以整除$7$， 然后$$u^2,v^2\in\{1,2,4\}.$$两个这样的残基的差异总是与其中之一一致$$0,\pm1,\pm2,\pm3,$$并且检查在每个允许的原始配置中，因素之一$$u,\ v,\ u^2-v^2$$可以整除$7$。 

所以$7\mid A$。 

因此$$84\mid A.$$所以**每一个完美的三角形都会自动变得超级完美**。 

---

 # 步骤 5：结论

 没有完美的直角三角形不是超级完美的。 

因此所需的计数为$$0.$$---

 # Python 实现```python
from math import gcd, isqrt

LIMIT = 10**16

count_not_super = 0

# Generate primitive triples:
# a = m^2 - n^2
# b = 2mn
# c = m^2 + n^2
#
# We require c to be a perfect square.

max_m = isqrt(LIMIT)

for m in range(2, max_m + 1):
    for n in range(1, m):
        if ((m - n) % 2 == 1) and gcd(m, n) == 1:

            c = m*m + n*n

            if c > LIMIT:
                break

            s = isqrt(c)

            # perfect triangle condition
            if s * s == c:

                a = m*m - n*n
                b = 2*m*n
                area = (a * b) // 2

                # check super-perfect condition
                if area % 84 != 0:
                    count_not_super += 1

print(count_not_super)
```---
