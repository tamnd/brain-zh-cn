[欧拉项目问题 349](https://projecteuler.net/problem=349)

 ## 解决方案

 **答案：**`115384615384614952`这个问题的关键在于，虽然蚂蚁的运动最初看起来很混乱，但**兰顿的蚂蚁最终进入了完美重复的“高速公路”模式**。 一旦发生这种情况，黑色方块的数量就会线性增长，使我们能够从几千个模拟步骤一直跳到$10^{18}$。 

## 1.数学分析

 让$B(n)$是之后黑色方块的数量$n$移动。 

蚂蚁服从：

 - **白色**：翻转为黑色，右转，移动。 
- **黑色**：翻转为白色，向左转，移动。 

网格开始时完全是白色的。 

### 步骤 1：观察涌现结构

 直接模拟$10^{18}$步骤是不可能的。 

然而，兰顿蚂蚁因一个深刻的现象而闻名：

 > 经过一个混乱的瞬态阶段，它最终建立了一条重复的“高速公路”。 

根据经验（并可通过模拟验证），蚂蚁在 **9977 次移动**后进入周期性状态。 

在这个制度下：

 - 每**104步**，
 - 配置重复直至翻译，
 - 黑色方块的数量恰好增加了 **12**。 

所以对于足够大的$n$,$$B(n+104)=B(n)+12.$$这给出了线性递推。 

### 第 2 步：确定转变点

 模拟前几千步显示：$$B(9977)=715.$$在那之后，$$B(n+104)=B(n)+12.$$现在写$$10^{18}-9977 = 104q + r.$$计算：$$q = \left\lfloor \frac{10^{18}-9977}{104}\right\rfloor, \qquad r=(10^{18}-9977)\bmod 104.$$然后$$B(10^{18}) = 715 + 12q + \bigl(B(9977+r)-715\bigr).$$剩下的$r$由第一个模拟周期中存储的值处理。 

执行此操作会产生：$$B(10^{18}) = 115384615384614952.$$---

 ## 2.Python实现```python
def solve():
    N = 10**18

    # Directions: up, right, down, left
    directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]

    black = set()

    x = y = 0
    direction = 0  # start facing up

    black_counts = []

    # Simulate enough steps to reach stable highway behavior
    LIMIT = 20000

    for step in range(1, LIMIT + 1):

        if (x, y) in black:
            # Black square: flip to white, turn left
            black.remove((x, y))
            direction = (direction - 1) % 4
        else:
            # White square: flip to black, turn right
            black.add((x, y))
            direction = (direction + 1) % 4

        # Move forward
        dx, dy = directions[direction]
        x += dx
        y += dy

        black_counts.append(len(black))

    # Highway begins after 9977 moves
    START = 9977
    PERIOD = 104
    GAIN = 12

    base = black_counts[START - 1]

    q, r = divmod(N - START, PERIOD)

    answer = base + q * GAIN

    if r:
        answer += black_counts[START + r - 1] - base

    return answer

print(solve())
```---

 ## 3. 代码演练

 ### 模拟

 我们用 a 来表示黑色方块`set`。 

- 如果当前方块是黑色：

 - 从集合中删除（变白），
 - 向左旋转。 
- 否则：

 - 添加到集合（变黑），
 - 向右旋转。 

然后向新的方向迈出一步。 

我们记录：```python
black_counts.append(len(black))
```所以`black_counts[n-1]`商店$B(n)$。 

### 检测周期性

 通过检查：

 - 从**9977开始**，
 - 每**104步**，
 - 黑色计数增加 **12**。 

因此：```python
START = 9977
PERIOD = 104
GAIN = 12
```我们将大量的动作分为：```python
q, r = divmod(N - START, PERIOD)
```意义：

-`q`完整的高速公路循环，
 -`r`剩下的动作。 

每个周期贡献+12 个黑色方块。

 ## 4.最终验证

 健全性检查：$$\frac{12}{104}=\frac{3}{26}\approx 0.11538$$所以对于$10^{18}$我们大致预期的步骤$$0.11538 \times 10^{18} \approx 1.1538\times10^{17},$$它与计算结果的大小相匹配：$$115384615384614952.$$这个数字也与已知的兰顿蚂蚁的稳定线性生长一致。 

**答案：115384615384614952**
