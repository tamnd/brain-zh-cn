[欧拉项目问题 186](https://projecteuler.net/problem=186)

 ## 解决方案

 **答案：**`2325629`设用户为图的顶点$10^6$节点。 

每次成功的通话都会在两个用户之间增加一条无向的边缘。 

问题问：

 > 包含总理 (PM)、号码的连接组件在成功呼叫多少次后$524287$,首先至少包含$99\%$所有用户的？ 

Since there are$10^6$用户，我们寻求 PM 的连接组件至少具有大小的第一时刻$$0.99 \times 10^6 = 990000.$$因此，自然的数据结构是一个**不相交集联合结构**（Union–Find）。 

---

 # 1.数学分析

 该序列由滞后斐波那契生成器生成：

 对于$1 \le k \le 55$,$$S_k = (100003 - 200003k + 300007k^3)\bmod 1000000.$$为了$k \ge 56$,$$S_k = (S_{k-24} + S_{k-55}) \bmod 1000000.$$每条通话记录为$$\operatorname{Caller}(n)=S_{2n-1}, \qquad \operatorname{Called}(n)=S_{2n}.$$如果主叫方 = 被叫（误拨），则呼叫将被忽略。 

否则，我们在这两个用户之间添加一条边。 

所以流程是：

 - 生成对$(a,b)$,
 - ignore if$a=b$,
 - 联合连接的组件$a$和$b$,
 - 跟踪 PM 组件的大小，
 - 一旦到达就停止$990000$。 

---

 ## 为什么 Union–Find 有效

 假设每个用户都属于一个连接的组件。 

当成功的呼叫发生在$a$和$b$：

 - 如果已经连接，则没有任何变化，
 - 否则两个组件合并。 

联合查找支持：

 -`find(x)`= 代表含有$x$,
 -`union(x,y)`=合并组件，
 - 元件尺寸跟踪。 

通过路径压缩和按大小/等级联合，每个操作实际上都是恒定时间：$$O(\alpha(n)),$$在哪里$\alpha$是阿克曼反函数。 

这对于数百万次操作来说是理想的选择。

 # 2.Python实现```python
MOD = 1000000
PM = 524287
TARGET = 990000

# ------------------------------------------------------------
# Lagged Fibonacci Generator
# ------------------------------------------------------------

S = [0] * 56  # use indices 1..55

for k in range(1, 56):
    S[k] = (100003 - 200003 * k + 300007 * k * k * k) % MOD

idx = 1

def next_S():
    global idx

    # First 55 values
    if idx <= 55:
        val = S[idx]
    else:
        # recurrence
        val = (S[(idx - 24 - 1) % 55 + 1] +
               S[(idx - 55 - 1) % 55 + 1]) % MOD

        # overwrite cyclic buffer
        S[(idx - 1) % 55 + 1] = val

    idx += 1
    return val

# ------------------------------------------------------------
# Union-Find
# ------------------------------------------------------------

parent = list(range(MOD))
size = [1] * MOD

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b):
    ra = find(a)
    rb = find(b)

    if ra == rb:
        return

    # union by size
    if size[ra] < size[rb]:
        ra, rb = rb, ra

    parent[rb] = ra
    size[ra] += size[rb]

# ------------------------------------------------------------
# Main simulation
# ------------------------------------------------------------

successful_calls = 0

while True:

    caller = next_S()
    called = next_S()

    # misdial
    if caller == called:
        continue

    successful_calls += 1

    union(caller, called)

    pm_root = find(PM)

    if size[pm_root] >= TARGET:
        print(successful_calls)
        break
```---

 # 4.最终验证

 一些健全性检查：

 - 有$10^6$用户。 
- 我们停在$990000$连接到 PM 的用户。 
- 答案应该是数百万次调用，与随机图连接阈值一致。 
- Union–Find 可在近线性时间内有效地处理此问题。 

运行计算得出：$$2325629$$这是已知正确的欧拉计划结果。 

**答案：2325629**
