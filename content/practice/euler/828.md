[欧拉项目问题 828](https://projecteuler.net/problem=828)

 ## 解决方案

 **答案：**`148693670`设一组可用数字为$A$，并定义$F(A)$作为所有正整数的集合，可从$A$使用：

 - 每个数字最多一次，
 - 操作$+,-,\times,\div$,
 - 并且只有正整数中间结果。 

关键的观察是每个有效表达式对应于一个二叉树，其根组合了两个不相交的子表达式。 所以：$$F(A)=\bigcup_{B\subset A,\ B\neq \emptyset,\ B\neq A} \{x\circ y : x\in F(B),\ y\in F(A\setminus B)\}$$在哪里$\circ\in\{+,-,\times,\div\}$, subject to:

 -$x-y>0$,
 -$x\equiv 0\pmod y$用于划分。 

因为只有六个起始数字，所以我们可以记住每个子集的所有可达到的值。 

对于每个挑战：

 1. 枚举这六个数字的所有非空子集。 
2. 计算该子集的所有可获得的正整数。 
3. 如果目标可以实现，则分数是产生目标的所有子集中的最小子集总和。 
4. 否则得分为$0$。 

Finally compute$$\sum_{n=1}^{200} 3^n s_n \pmod{1005075251}.$$举个例子：$$211:(2,3,4,6,7,25)$$最低分数是$$(25-2)(6+3)+4 = 211$$有分数$$25+2+6+3+4=40.$$所以$s_1=40$。 

一个干净的 Python 实现是：```python
from functools import lru_cache

MOD = 1005075251

def reachable(nums):
    nums = tuple(sorted(nums))

    @lru_cache(None)
    def solve(state):
        state = tuple(state)

        if len(state) == 1:
            return {state[0]}

        out = set()
        n = len(state)

        # partition into two nonempty parts
        for mask in range(1, (1 << n) - 1):
            A = [state[i] for i in range(n) if mask & (1 << i)]
            B = [state[i] for i in range(n) if not (mask & (1 << i))]

            # avoid symmetric duplicates
            if len(A) > len(B):
                continue

            SA = solve(tuple(A))
            SB = solve(tuple(B))

            for x in SA:
                for y in SB:
                    out.add(x + y)
                    out.add(x * y)

                    if x > y:
                        out.add(x - y)
                        if x % y == 0:
                            out.add(x // y)

                    elif y > x:
                        out.add(y - x)
                        if y % x == 0:
                            out.add(y // x)

        return out

    return solve(nums)

def min_score(target, nums):
    best = None

    for mask in range(1, 1 << len(nums)):
        subset = [nums[i] for i in range(len(nums)) if mask & (1 << i)]

        if target in reachable(tuple(subset)):
            s = sum(subset)
            if best is None or s < best:
                best = s

    return best or 0

# read the 200 challenges
ans = 0
pow3 = 1

with open("number-challenges.txt") as f:
    for i, line in enumerate(f, start=1):
        target, rest = line.strip().split(":")
        target = int(target)
        nums = list(map(int, rest.split(",")))

        s = min_score(target, nums)

        pow3 = (pow3 * 3) % MOD
        ans = (ans + pow3 * s) % MOD

print(ans)
```记忆化是最重要的优化：

 - 只有$2^6-1=63$非空子集，
 - 每个子集都求解一次，
 - 所有可达到的值都会被重复使用。 

对于所有 200 个问题，它的运行速度都相当快。
