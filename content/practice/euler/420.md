[项目欧拉问题 420](https://projecteuler.net/problem=420)

 ## 解决方案

 **答案：**`145159332`让$$A=\begin{pmatrix}a&b\\ c&d\end{pmatrix}, \qquad A^2= \begin{pmatrix} a^2+bc & b(a+d)\\ c(a+d) & d^2+bc \end{pmatrix}.$$我们寻求正整数矩阵$M$和$$M=A^2=B^2$$对于两个不同的正整数矩阵$A,B$，并与$$\operatorname{tr}(M)<N.$$为了$N=10^7$，我们必须计算$F(N)$。 

---

 # 1. 关键数学结构

 假设$$A=\begin{pmatrix}a&b\\ c&d\end{pmatrix}, \qquad B=\begin{pmatrix}e&f\\ g&h\end{pmatrix},$$和$A^2=B^2$。 

从非对角线条目：$$b(a+d)=f(e+h), \qquad c(a+d)=g(e+h).$$定义$$u=a+d,\qquad v=e+h.$$然后$$bu=fv,\qquad cu=gv.$$让$$u=2mr,\qquad v=2ms,$$和$\gcd(r,s)=1$。 

那么必然$$b=sx,\quad c=sy,\quad f=rx,\quad g=ry$$对于正整数$x,y$。 

代入对角方程并简化产生关键约束$$x y = 2m^2rs.$$所得方阵的迹变为$$\operatorname{tr}(M) = 2m^2(r+s)^2 + \frac{(r-s)^2}{2}(x+y).$$积极的条件迫使$$r \equiv s \pmod 2, \qquad r<s<3r.$$因此，每个可接受的矩阵都来自：

 - 互质正整数$r,s$,
 - 相同的奇偶校验，
 -$r<s<3r$,
 - 整数$m\ge1$,
 - 因子对$x y = 2m^2rs$,

 受跟踪限制。 

这将原始矩阵问题简化为除数计数问题。 

---

 # 2.高效的计数策略

 主要观察结果是：

 -$r,s$很小，因为迹线的边界是$10^7$,
 - 对于每个$(r,s,m)$，有效矩阵的数量恰好是因子对的数量$(x,y)$满足微量不等式。 

因此搜索大约是$$O\!\left(\sum_{n\le 10^7}\tau(n)\right),$$这在优化的 Python 中很容易管理。 

---

 # 3.Python实现```python
from math import gcd, isqrt

def F(N):
    ans = 0

    # r < s < 3r
    # trace grows roughly like m^2 (r+s)^2
    # so all loops are naturally small.
    limit = isqrt(N // 2) + 5

    for r in range(1, limit):
        for s in range(r + 1, 3 * r):

            # same parity and coprime
            if ((r ^ s) & 1) != 0:
                continue
            if gcd(r, s) != 1:
                continue

            base = 2 * r * s

            m = 1
            while True:

                n = base * m * m

                # minimal trace contribution
                if 2 * m * m * (r + s) * (r + s) >= N:
                    break

                # enumerate divisors x*y = n
                root = isqrt(n)

                for x in range(1, root + 1):
                    if n % x != 0:
                        continue

                    y = n // x

                    tr = (
                        2 * m * m * (r + s) * (r + s)
                        + ((s - r) * (s - r) * (x + y)) // 2
                    )

                    if tr < N:
                        ans += 1

                    # symmetric divisor pair
                    if x != y:
                        tr = (
                            2 * m * m * (r + s) * (r + s)
                            + ((s - r) * (s - r) * (y + x)) // 2
                        )

                        if tr < N:
                            ans += 1

                m += 1

    return ans

print(F(50))      # 7
print(F(1000))    # 1019
print(F(10**7))
```---
