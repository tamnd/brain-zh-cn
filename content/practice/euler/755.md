[项目欧拉问题 755](https://projecteuler.net/problem=755)

 ## 解决方案

 **答案：**`2877071595975576960`让$$F=\{1,2,3,5,8,\dots\}$$并让$f(n)$是子集的数量$F$其元素总和为$n$。 

然后$$S(N)=\sum_{k=0}^N f(k)$$计数**斐波那契数列的所有子集，其总和最多为$N$**。 

所以任务是：

 > 用总和计算不同斐波那契数的子集$\le 10^{13}$。 

一个非常有效的递归工作。 

如果可用的斐波那契数是$F_0,\dots,F_i$，那么：

 - 要么我们**不**使用$F_i$,
 - 或者我们**确实**使用$F_i$。 

因此：$$C(i,x)=C(i-1,x)+C(i-1,x-F_i).$$我们还使用一个关键的快捷方式：

 如果$$x \ge \sum_{k=0}^i F_k,$$那么每个子集都是允许的，所以$$C(i,x)=2^{i+1}.$$这大大减少了状态的数量。 

Python代码：```python
from functools import lru_cache

N = 10**13

# Build Fibonacci numbers: 1,2,3,5,...
fibs = [1, 2]
while fibs[-1] + fibs[-2] <= N:
    fibs.append(fibs[-1] + fibs[-2])

# Prefix sums
prefix = []
s = 0
for x in fibs:
    s += x
    prefix.append(s)

@lru_cache(None)
def count_subsets(i, limit):
    # Number of subsets using fibs[0..i] with sum <= limit

    if limit < 0:
        return 0

    if i < 0:
        return 1  # empty subset

    # If limit already exceeds total possible sum,
    # every subset is valid.
    if limit >= prefix[i]:
        return 1 << (i + 1)

    # Can't use fibs[i]
    if fibs[i] > limit:
        return count_subsets(i - 1, limit)

    # Exclude or include fibs[i]
    return (
        count_subsets(i - 1, limit)
        + count_subsets(i - 1, limit - fibs[i])
    )

answer = count_subsets(len(fibs) - 1, N)

print(answer)
```对给定示例的验证：

 -$S(100)=415$-$S(10^4)=312807$两者均被准确复制。
