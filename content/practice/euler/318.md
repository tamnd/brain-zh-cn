[欧拉项目问题 318](https://projecteuler.net/problem=318)

 ## 解决方案

 **答案：**`709313889`让$$\alpha=\sqrt p+\sqrt q,\qquad \beta=\sqrt q-\sqrt p$$和$p<q$,$p,q\in \mathbb Z_{>0}$。 

我们正在学习$$\alpha^{2n}.$$关键的观察是$\alpha\beta=q-p$， 和$$(\sqrt p+\sqrt q)^{2n}+(\sqrt q-\sqrt p)^{2n}$$始终是整数。 

事实上，由于奇怪的无理项在二项展开式中被抵消，$$A_n=\alpha^{2n}+\beta^{2n}\in \mathbb Z.$$因此$$\alpha^{2n}=A_n-\beta^{2n}.$$自从$0<\beta<1$（这个条件很重要），小数部分是$$\{\alpha^{2n}\}=1-\beta^{2n}.$$因此小数部分接近$1$当且仅当$$\beta<1.$$因为$\beta=\sqrt q-\sqrt p$，可接受的对正是那些满足$$\sqrt q-\sqrt p<1.$$---

 我们想要$C(p,q,n)\ge 2011$，即小数点后至少有 2011 个连续的 9。 

这意味着$$1-\beta^{2n}$$必须不同于$1$至多$10^{-2011}$：$$\beta^{2n}\le 10^{-2011}.$$获取日志：$$2n\ln\beta \le -2011\ln 10.$$自从$\ln\beta<0$,$$n \ge \frac{2011\ln 10}{-2\ln \beta}.$$所以$$N(p,q) = \left\lceil \frac{2011\ln 10} {-2\ln(\sqrt q-\sqrt p)} \right\rceil.$$我们总结一下$$p<q,\qquad p+q\le 2011,\qquad \sqrt q-\sqrt p<1.$$---

 ### Python 实现```python
from math import sqrt, log, ceil

LIMIT = 2011
K = 2011
LN10 = log(10)

total = 0

for p in range(1, LIMIT):
    # q must satisfy p < q and p + q <= LIMIT
    for q in range(p + 1, LIMIT - p + 1):

        beta = sqrt(q) - sqrt(p)

        # Only these pairs have fractional part -> 1
        if beta < 1:
            n = ceil(K * LN10 / (-2 * log(beta)))
            total += n

print(total)
```### 代码演练

 - 循环所有整数对$(p,q)$和$p<q$和$p+q\le 2011$。 
- 计算$$\beta=\sqrt q-\sqrt p.$$- 仅保留$\beta<1$，因为否则$\beta^{2n}$不倾向于$0$，因此小数部分无法逼近$1$。 
- 计算$$N(p,q)= \left\lceil \frac{2011\ln 10} {-2\ln \beta} \right\rceil.$$- 添加所有值。
