[欧拉项目 952 问题](https://projecteuler.net/problem=952)

 ## 解决方案

 **答案：**`794394453`让$$M = 10^7!, \qquad p = 10^9+7.$$我们需要乘法顺序$$R(p,10^7)=\operatorname{ord}_{M}(p).$$因为$M=\prod q^{a_q}$过素数$q\le 10^7$,$$\operatorname{ord}_{M}(p) = \operatorname{lcm}_{q\le 10^7} \operatorname{ord}_{q^{a_q}}(p),$$在哪里$$a_q=v_q(10^7!).$$对于奇素数$q\neq p$， 如果$$d_q=\operatorname{ord}_q(p),$$那么标准提升定理给出$$\operatorname{ord}_{q^{a_q}}(p) = d_q\, q^{\max(0,a_q-s_q)},$$在哪里$$s_q=v_q(p^{d_q}-1).$$几乎总是$s_q=1$; 唯一的例外是$10^7$是$$q\in\{3,5,43,109\},$$为此$s_q=2$。 

为了$q=2$， 自从$p=10^9+7\equiv 7\pmod 8$,$$\operatorname{ord}_{2^a}(p)=2^{a-3}\qquad (a\ge 3).$$所以任务减少为：

 1. 筛分至$10^7$,
 2. 计算$d_q\mid (q-1)$,
 3. 按素数指数组装 LCM，
 4. 减少模数$10^9+7$。 

一个干净的 Python 实现是：```python
from array import array

N = 10_000_000
MOD = 1_000_000_007
P = MOD

# ---------- smallest prime factor sieve ----------
spf = array('I', [0]) * (N + 1)
primes = array('I')

for i in range(2, N + 1):
    if spf[i] == 0:
        spf[i] = i
        primes.append(i)
    for p in primes:
        v = p * i
        if p > spf[i] or v > N:
            break
        spf[v] = p

# ---------- build lcm prime exponents ----------
maxexp = {}

# q = 2
a2 = 0
t = N
while t:
    t //= 2
    a2 += t

maxexp[2] = a2 - 3

# odd primes
for q in primes[1:]:

    # exponent of q in N!
    a = 0
    t = N
    while t:
        t //= q
        a += t

    # d = ord_q(P), starting from q-1
    d = q - 1
    x = q - 1
    last = 0

    while x > 1:
        r = spf[x]
        if r != last:
            while d % r == 0 and pow(P, d // r, q) == 1:
                d //= r
            last = r
        x //= r

    # factor d into global lcm
    x = d
    while x > 1:
        r = spf[x]
        e = 0
        while x % r == 0:
            x //= r
            e += 1
        if e > maxexp.get(r, 0):
            maxexp[r] = e

    # lifting exponent s_q
    s = 1
    if pow(P, d, q * q) == 1:
        s = 2

    e = max(0, a - s)

    if e > maxexp.get(q, 0):
        maxexp[q] = e

# ---------- reconstruct answer mod MOD ----------
ans = 1
for r, e in maxexp.items():
    ans = (ans * pow(r, e, MOD)) % MOD

print(ans)
```这评估为：
