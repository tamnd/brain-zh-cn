[欧拉项目 475 问题](https://projecteuler.net/problem=475)

 ## 解决方案

 **答案：**`75780067`让$12n$音乐家可分为$3n$从第一天开始固定四重奏：$$Q_1,Q_2,\dots,Q_{3n}, \qquad |Q_i|=4.$$在第 2 天，我们必须将所有音乐家分为$4n$无序三重奏，使得**没有三重奏包含来自同一四重奏的两个成员**。 

我们寻求$$f(12n).$$---

 # 1.数学分析

 ## 步骤 1：从所有三分区开始

 分区方式的数量$12n$给人们贴上标签$4n$无序三重奏是$$\frac{(12n)!}{(3!)^{4n}(4n)!} = \frac{(12n)!}{6^{4n}(4n)!}.$$现在施加限制。 

---

 ## 步骤 2：包含-排除

 每个四重奏里面都有$$\binom{4}{2}=6$$禁止对。 

让一个事件$E_{ab}$意思是：

 > 音乐家$a,b$（来自同一个四重奏）出现在同一个三重奏中。 

我们对所有禁止对应用包含-排除。 

---

 # 步骤 3：禁止对的哪些子集是可行的？ 

修复一个带有顶点的四重奏$\{1,2,3,4\}$。 

我们选择一个子集$S$其 6 个边。 

选定的边意味着该对必须位于公共三重奏中。 

由于三元组的大小为 3，因此图中的每个连通分量$(\{1,2,3,4\},S)$大小必须最多为 3。 

唯一可行的图形类型是：

 | 类型 | 计数 | 标志 | 效果|
 | ---| ---| ---| ---|
 | 空 | 1 |$+$| 什么都没有|
 | 一个边缘 | 6 |$-$| 一对被迫的|
 | 两条不相交的边 | 3 |$+$| 两个被迫对|
 | 具有 2 条边的连通 3 顶点图 | 12 | 12$+$| 一个强制三重|
 | 三角形| 4 |$-$| 一个强制三重|

 最后两个都强制执行相同的操作：所有 3 个顶点必须位于一个三重奏中。 

因此，一个四重奏的净贡献是$$P(x,y)=1-6x+3x^2+8y,$$在哪里

-$x$计算强制对分量，
 -$y$计算强制三分量。 

由于四重奏是独立的，因此对于所有$3n$四重奏：$$P(x,y)^{3n}.$$让$$[x^a y^b]P(x,y)^{3n}=c_{a,b}.$$然后：

-$a$= 强制对的数量，
 -$b$= 强制三元组的数量。 

---

 # 第 4 步：计算固定的完成情况$(a,b)$强制三人组已经占据了一个三人组。 

强制配对必须由一个额外的单例来完成。 

修复后：

 -$a$对组件，
 -$b$三元组份，

 剩余的免费单例数量是$$12n-2a-3b.$$我们必须选择独特的单身伙伴$a$对：$$\frac{(12n-2a-3b)!}{(12n-3a-3b)!}.$$其余$$12n-3a-3b = 3(4n-a-b)$$单例被划分为$$4n-a-b$$无序三重奏：$$\frac{(12n-3a-3b)!}{6^{4n-a-b}(4n-a-b)!}.$$乘法：$$\frac{(12n-2a-3b)!}{6^{4n-a-b}(4n-a-b)!}.$$所以$$\boxed{ f(12n)= \sum_{a,b} c_{a,b} \frac{(12n-2a-3b)!} {6^{\,4n-a-b}(4n-a-b)!} }$$在哪里$$c_{a,b}=[x^a y^b](1-6x+3x^2+8y)^{3n}.$$---

 # 2.Python实现```python
MOD = 1_000_000_007

def solve(n):
    # DP for coefficients of:
    # (1 - 6x + 3x^2 + 8y)^(3n)

    from collections import defaultdict

    dp = {(0, 0): 1}

    for _ in range(3 * n):
        ndp = defaultdict(int)

        for (a, b), v in dp.items():

            # 1
            ndp[(a, b)] = (ndp[(a, b)] + v) % MOD

            # -6x
            ndp[(a + 1, b)] = (ndp[(a + 1, b)] - 6 * v) % MOD

            # +3x^2
            ndp[(a + 2, b)] = (ndp[(a + 2, b)] + 3 * v) % MOD

            # +8y
            ndp[(a, b + 1)] = (ndp[(a, b + 1)] + 8 * v) % MOD

        dp = ndp

    # factorials
    N = 12 * n

    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (4 * n + 1)

    invfact[4 * n] = pow(fact[4 * n], MOD - 2, MOD)

    for i in range(4 * n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    inv6 = pow(6, MOD - 2, MOD)

    pow_inv6 = [1] * (4 * n + 1)
    for i in range(1, 4 * n + 1):
        pow_inv6[i] = pow_inv6[i - 1] * inv6 % MOD

    ans = 0

    for (a, b), c in dp.items():

        m = 12 * n - 2 * a - 3 * b
        k = 4 * n - a - b

        if m < 0 or k < 0:
            continue

        term = c
        term %= MOD

        term *= fact[m]
        term %= MOD

        term *= pow_inv6[k]
        term %= MOD

        term *= invfact[k]
        term %= MOD

        ans += term
        ans %= MOD

    return ans % MOD

# Checks from the problem statement
print(solve(1))   # 576
print(solve(2))   # 509089824

# Required answer
print(solve(50))
```---

 # 3. 代码演练

 ### 多项式 DP

 我们建立系数$$(1-6x+3x^2+8y)^{3n}$$使用动态规划。 

每个四重奏都贡献一个因素。 

国家：```python
dp[(a,b)]
```存储系数$x^a y^b$。 

---

 ### 阶乘

 我们需要以下形式的条款$$\frac{m!}{6^k k!}.$$模运算使用费马逆，因为$$10^9+7$$是素数。 

---

 ### 最终总结

 对于每个系数$c_{a,b}$，我们添加$$c_{a,b} \cdot \frac{(12n-2a-3b)!} {6^{4n-a-b}(4n-a-b)!}.$$---

 # 4. 验证

 该程序重现两个给定值：$$f(12)=576$$和$$f(24)\bmod 10^9+7 = 509089824.$$所以推导是一致的。 

运行计算$n=50$给出：$$f(600)\bmod 1\,000\,000\,007 = 75780067.$$---

 **答案：75780067**
