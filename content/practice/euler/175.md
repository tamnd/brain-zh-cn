[欧拉项目问题 175](https://projecteuler.net/problem=175)

 ## 解决方案

 **答案：**`1137174208`让$$F(x)=\prod_{k\ge 0}(1+x^{2^k}+x^{2^{k+1}})$$使得系数为$x^n$正是$f(n)$, 写法的数量$n$作为权力的总和$2$每个能量最多使用两次。 

我们寻求最小的$n$这样$$\frac{f(n)}{f(n-1)}=\frac{123456789}{987654321}.$$---

 # 1. 重复出现$f(n)$根据奇偶校验进行分割。 

## 奇怪的参数

 如果$n=2m+1$，那么$2^0$术语必须恰好出现一次。 删除它并除以$2$给出双射，表示为$m$。 因此$$f(2m+1)=f(m).$$## 偶数参数

 如果$n=2m$，那么数量$1$是$0$或者$2$。 

- 如果有$0$，将所有内容除以$2$:$f(m)$的可能性。 
- 如果有$2$，删除它们并除以$2$:$f(m-1)$的可能性。 

所以$$f(2m)=f(m)+f(m-1).$$---

 # 2. 比率和二元构造

 定义$$R(n)=\frac{f(n)}{f(n-1)}.$$使用递归：

 ## 如果$n=2m$

$$R(2m)=\frac{f(m)+f(m-1)}{f(m)}       =1+\frac{1}{R(m)}.$$＃＃ 如果$n=2m+1$

$$R(2m+1)=\frac{f(m)}{f(m)+f(m-1)}        =\frac{R(m)}{R(m)+1}.$$这些与附加二进制数字完全对应：

 - 追加$0$:$x \mapsto 1+\frac1x$- 追加$1$:$x \mapsto \frac{x}{x+1}$开始于$R(1)=1$，每个正理性都可以通过 Stern-Brocot/Calkin-Wilf 树中的一条路径唯一地达到。 

因此，要恢复最小的$n$从一个分数$p/q$，我们向后推算：

 - 如果$p<q$，最后一位是$1$，我们替换$$\frac pq \mapsto \frac p{q-p};$$- 如果$p>q$，最后一位是$0$，我们替换$$\frac pq \mapsto \frac{p-q}q.$$这就是简单的欧几里得算法。 

---

 # 3. 应用于给定的分数

 首先减少：$$\frac{123456789}{987654321} = \frac{13717421}{109739369}.$$现在执行欧几里得过程。 

自从$$109739369 = 8\cdot 13717421 + 1,$$我们减去$13717421$八次：$$\frac{13717421}{109739369} \to \frac{13717421}{1}.$$这贡献了八个尾随$1$-位。 

下一个，$$13717421 = 13717420\cdot 1 + 1,$$所以我们减去$1$总共$13717420$次数：$$\frac{13717421}{1} \to \frac11.$$这有助于$13717420$尾随$0$-位。 

终于我们到达了根源$1/1$，对应首位二进制数字$1$。 

因此二进制展开式为$$1\underbrace{00\cdots0}_{13717420} \underbrace{11\cdots1}_{8}.$$因此，其缩短的二进制展开式为$$1,13717420,8.$$---

 # 4.Python实现```python
from math import gcd

p = 123456789
q = 987654321

# Reduce fraction
g = gcd(p, q)
p //= g
q //= g

runs_reversed = []

while not (p == 1 and q == 1):

    if p < q:
        # We are undoing an appended '1'
        k = (q - 1) // p
        q -= k * p
        runs_reversed.append(("1", k))

    else:
        # We are undoing an appended '0'
        k = (p - 1) // q
        p -= k * q
        runs_reversed.append(("0", k))

# Reconstruct binary string
binary = "1"
for bit, count in reversed(runs_reversed):
    binary += bit * count

# Convert to shortened binary expansion
sbe = []
count = 1

for i in range(1, len(binary) + 1):
    if i < len(binary) and binary[i] == binary[i - 1]:
        count += 1
    else:
        sbe.append(count)
        count = 1

print(",".join(map(str, sbe)))
```---

 # 5. 代码演练

 - 首先减少目标分数。 
- 使用欧几里德算法逆向工作。 
- 每个重复减法块对应于重复的相同二进制数字。 
- 从这些运行中重建二进制扩展。 
- 将连续的相等位压缩为缩短的二进制扩展。 

对于样品$13/17$:

 -$17 = 1\cdot 13 + 4$→ 尾随一$1$-$13 = 3\cdot 4 + 1$→ 三个尾随$0$的
 -$4 = 3\cdot 1 + 1$→ 三个尾随$1$的

 给出二进制$$11110001_2 = 241,$$其缩写形式是$$4,3,1,$$完全如所述。

 # 6.最终验证

 欧几里得算法终止于$(1,1)$，保证最小化。 

二进制模式包括：

 - 一位领先$1$,
 -$13717420$零，
 -$8$那些，

 因此缩短的二进制展开是一致且完整的。 

**答案：1,13717420,8**
