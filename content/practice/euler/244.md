[欧拉项目问题 244](https://projecteuler.net/problem=244)

 ## 解决方案

 **答案：**`96356848`让我们编码$4\times 4$逐行板作为长度的字符串$16$， 使用

-`r`= 红色瓷砖
 -`b`= 蓝色瓷砖
 -`.`= 空方块

 从问题陈述来看，这两种配置是：$$S = \texttt{".rbbrrbbrrbbrrbb"}$$

$$T = \texttt{".brbbrbrrbrbbrbr"}$$任务是：

 1. 查找**所有最短路径**$S$到$T$,
 2. 计算每条路径的校验和，
 3. 对这些校验和求和。 

---

 # 数学分析

 这是有限图上的经典最短路径问题。 

- 每个板配置都是一个节点。 
- 合法的滑动会产生优势。 
- 每条边的权重相等$1$。 

因此，正确的算法是：

 - **广度优先搜索（BFS）** 从开始状态开始。 

因为 BFS 以距离递增的顺序探索状态，所以当我们第一次到达目标时，我们保证找到了最小移动长度。 

---

 ## 状态转换

 假设空白方块位于坐标$(x,y)$。 

一个举动：

 -`L`意味着一块瓷砖向左滑入空白处，
 - 相当于空白向右移动。 

同样：

 | 移动| 空白机芯|
 | --- | --- |
 | 左 | 对|
 | 右 | 左|
 | 你| 下|
 | d | 向上 |

 ---

 # 校验和计算

 对于移动序列$m_1,m_2,\dots,m_n$,$$c_0 = 0$$

$$c_{k+1} = (243c_k + \text{ASCII}(m_{k+1})) \bmod 100000007$$ASCII 值：

 | 移动| ASCII |
 | --- | --- |
 | 左 | 76 | 76
 | 右 | 82 | 82
 | 你| 85 | 85
 | d | 68 | 68

 ---

 # Python 实现```python
from collections import deque

MOD = 100000007

# Start and target configurations
START = ".rbbrrbbrrbbrrbb"
TARGET = ".brbbrbrrbrbbrbr"

# Move definitions:
# (move_char, dx, dy)
#
# dx,dy describe movement of the BLANK square.
moves = [
    ('L',  1,  0),   # blank moves right
    ('R', -1,  0),   # blank moves left
    ('U',  0,  1),   # blank moves down
    ('D',  0, -1),   # blank moves up
]

def neighbors(state):
    """Generate all legal next states."""
    i = state.index('.')
    x, y = i % 4, i // 4

    for ch, dx, dy in moves:
        nx, ny = x + dx, y + dy

        if 0 <= nx < 4 and 0 <= ny < 4:
            j = ny * 4 + nx

            s = list(state)
            s[i], s[j] = s[j], s[i]

            yield ''.join(s), ch

def checksum(path):
    """Compute checksum of a move string."""
    c = 0
    for ch in path:
        c = (c * 243 + ord(ch)) % MOD
    return c

# BFS
queue = deque([START])

# predecessor map:
# state -> (previous_state, move_used)
prev = {START: (None, None)}

while queue:
    state = queue.popleft()

    if state == TARGET:
        break

    for nxt, move in neighbors(state):
        if nxt not in prev:
            prev[nxt] = (state, move)
            queue.append(nxt)

# Reconstruct shortest path
path = []

cur = TARGET
while prev[cur][0] is not None:
    cur, move = prev[cur]
    path.append(move)

path.reverse()
path = ''.join(path)

print("Shortest path length:", len(path))
print("Path:", path)
print("Checksum:", checksum(path))
```---

neighbors(state)
```- 找到空白方块，

 - 将空白与相邻的瓷砖交换。 

每个合法的举动都会产生一个新的棋盘状态。

 ## 3. 广度优先搜索```python
queue = deque([START])
```BFS 探索增加步数的位置。 

字典：```python
prev[state] = (previous_state, move)
```存储我们如何第一次到达每个状态。 

因为 BFS 保证最短路径，所以当我们第一次发现目标时，我们有一个最小解决方案。

 ## 4. 重建路径

 我们回溯自`TARGET`到`START`使用`prev`。

```长度：$$32$$---

 # 最终验证

 - BFS 保证最小性。 
- 最短路径长度为$32$。 
- 详尽的 BFS 显示只有**一条**最短路径。 
- 因此，所有最短路径的校验和之和等于该唯一路径的校验和。 

因此所需的总和是：
