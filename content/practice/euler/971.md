[项目欧拉问题 971](https://projecteuler.net/problem=971)

 ## 解决方案

 **答案：**`33626723890930`让$$p=5k-4 \qquad\Longrightarrow\qquad k=\frac{p+4}{5},$$所以$$k-1=\frac{p-1}{5}.$$定义$$d=\frac{p-1}{5}.$$对于非零$x\in\mathbb F_p$,$$f_p(x)=x^k+x=x\left(x^{k-1}+1\right)=x\left(x^d+1\right).$$现在$x^d$始终是 5 次单位根$\mathbb F_p$， 自从$$(x^d)^5=x^{p-1}=1.$$因此，非零元素分为由值确定的五个陪集$x^d$。 

对于固定的 5 次方根$r$,$$x^d=r$$意味着$$f_p(x)=x(1+r).$$因此，五个陪集上的诱导作用完全由映射决定$$r \mapsto r(1+r)^d.$$周期陪集中的每个元素都是周期的，非周期陪集中的每个元素最终都会永远离开它。 因此：

 - 每个周期陪集准确贡献$d=(p-1)/5$点,
 -$x=0$总是固定的。 

所以如果$c$是五个非零陪集中周期陪集的数量，$$C(p)=1+c\cdot \frac{p-1}{5}.$$以下 Python 程序可以有效地计算此值。```python
import math

def S(N):
    # odd-only sieve
    sieve = bytearray(b'\x01') * (N // 2)

    limit = int(math.isqrt(N))
    for i in range(3, limit + 1, 2):
        if sieve[i // 2]:
            start = i * i // 2
            sieve[start::i] = b'\x00' * (((N // 2 - 1 - start) // i) + 1)

    total = 0

    # only primes p == 1 (mod 5) matter
    for p in range(11, N + 1, 10):
        if not sieve[p // 2]:
            continue

        d = (p - 1) // 5

        # find a primitive 5th root of unity
        a = 2
        while True:
            t = pow(a, d, p)
            if t != 1:
                break
            a += 1

        t2 = (t * t) % p
        t3 = (t2 * t) % p
        t4 = (t2 * t2) % p

        roots = (1, t, t2, t3, t4)
        idx = {roots[i]: i for i in range(5)}

        # induced map on the 5 cosets
        T = [0] * 5
        for i, r in enumerate(roots):
            nxt = (r * pow(1 + r, d, p)) % p
            T[i] = idx[nxt]

        # count periodic states in the 5-state graph
        periodic = 0
        for i in range(5):
            j = i
            seen = 0
            while not ((seen >> j) & 1):
                seen |= 1 << j
                j = T[j]
            if j == i:
                periodic += 1

        total += 1 + periodic * d

    return total

print(S(100))      # 127
print(S(10**8))
```该程序重现了该示例：$$S(100)=127.$$运行它$10^8$给出：$$S(10^8)=33626723890930.$$**答案：33626723890930**
