[欧拉项目778问题](https://projecteuler.net/problem=778)

 ## 解决方案

 **答案：**`146133880`让$$a=(\dots a_2a_1a_0),\qquad b=(\dots b_2b_1b_0)$$并定义新生的产品$a\boxtimes b$按数字$$(a\boxtimes b)_i \equiv a_i b_i \pmod{10}.$$对于几个数字，$$x_1\boxtimes x_2\boxtimes \cdots \boxtimes x_R$$有数字$i$

$$d_i \equiv \prod_{k=1}^R (x_k)_i \pmod{10}.$$我们必须计算$$F(R,M)=\sum_{0\le x_1,\dots,x_R\le M} x_1\boxtimes\cdots\boxtimes x_R.$$对于问题：$$R=234567,\qquad M=765432.$$所有计算都是模数$$P=1\,000\,000\,009.$$---

 # 1. 关键的数学见解

 小数点位置是完全独立的。 

如果位置上的数字$j$贡献$c_j$， 然后$$F(R,M)=\sum_{j\ge0} 10^j c_j.$$所以我们分别求解每个小数位。 

---

 ## 计算一个位置上的数字

 修复小数点位置$j$。 

让$C_j(d)$是整数的个数$x\in[0,M]$谁$j$第-位数字等于$d$。 

这些计数是通过标准数字计数公式获得的。 

对于位置值$p=10^j$:

 -$\text{high} = \lfloor M/(10p)\rfloor$-$\text{cur} = \lfloor M/p\rfloor \bmod 10$-$\text{low} = M\bmod p$然后最初出现每个数字$$\text{high}\cdot p$$次，并且部分块贡献通常的校正。 

---

 ## 残留动力学 mod 10

 在一位数字位置，每个选定的数字贡献一位数字$d\in\{0,\dots,9\}$。 

结果得到的数字是$$r \equiv d_1d_2\cdots d_R \pmod{10}.$$我们只关心残差mod$10$，所以只有 10 个状态。 

定义转移矩阵$T$经过$$T[a][b] = \sum_{\substack{d=0\\ ad\equiv b\pmod{10}}}^{9} C_j(d).$$释义：

 - 当前剩余量=$a$- 选择一个新数字$d$- 新残留=$ad\bmod 10$如果起始残基是$1$，然后之后$R$选择：$$\text{dp} = e_1 T^R.$$这里$\text{dp}[r]$等于产生残基的序列数$r$。 

因此，该小数位的总贡献为$$S_j=\sum_{r=0}^9 r\cdot \text{dp}[r].$$最后，$$F(R,M)=\sum_j 10^j S_j \pmod P.$$由于矩阵只有$10\times10$，快速求幂是微不足道的。 

---

 # 2.Python实现```python
MOD = 1_000_000_009

R = 234567
M = 765432

# Count how many numbers in [0, M]
# have digit d at decimal position pos.
def digit_counts(M, pos):
    p = 10 ** pos

    high = M // (p * 10)
    cur = (M // p) % 10
    low = M % p

    cnt = [high * p] * 10

    for d in range(cur):
        cnt[d] += p

    cnt[cur] += low + 1

    return [x % MOD for x in cnt]

def mat_mul(A, B):
    n = len(A)
    m = len(B[0])
    k = len(B)

    C = [[0] * m for _ in range(n)]

    for i in range(n):
        for t in range(k):
            if A[i][t]:
                a = A[i][t]
                for j in range(m):
                    C[i][j] = (C[i][j] + a * B[t][j]) % MOD

    return C

def mat_pow(MAT, e):
    n = len(MAT)

    # identity matrix
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while e:
        if e & 1:
            R = mat_mul(R, MAT)

        MAT = mat_mul(MAT, MAT)
        e >>= 1

    return R

def solve(R, M):
    ans = 0
    pow10 = 1

    pos = 0
    while 10 ** pos <= M:

        cnt = digit_counts(M, pos)

        # transition matrix
        T = [[0] * 10 for _ in range(10)]

        for a in range(10):
            for d in range(10):
                b = (a * d) % 10
                T[a][b] = (T[a][b] + cnt[d]) % MOD

        # T^R
        P = mat_pow(T, R)

        # start state is residue 1
        dp = P[1]

        # weighted digit sum
        Sj = sum(r * dp[r] for r in range(10)) % MOD

        ans = (ans + pow10 * Sj) % MOD

        pow10 = (pow10 * 10) % MOD
        pos += 1

    return ans

print(solve(R, M))
```---

 # 3. 代码演练

 ##`digit_counts`计算每个数字出现的频率$0\ldots9$出现在所有数字中固定的小数位置$0\le x\le M$。 

这是标准的位置数字计数技术。 

---

 ##`mat_mul`矩阵乘以模$10^9+9$。 

由于矩阵仅$10\times10$，这速度非常快。 

---

 ##`mat_pow`矩阵的二进制求幂：$$T^R$$在$O(\log R)$矩阵乘法。 

---

 ## 转移矩阵

 对于每个当前残差$a$和新数字$d$,$$b=(ad)\bmod 10.$$发生这种情况的次数是位数$d$。 

因此：```python
T[a][b] += cnt[d]
```---

 ## 恢复答案

 起始残差为$1$，因为尚未相乘的数字对应于乘法恒等式。 

求幂后：```python
dp = P[1]
```包含每个最终残基的计数。 

然后：```python
Sj = sum(r * dp[r])
```是该小数位的总贡献。 

最后我们乘以$10^j$。 

---

 # 4. 示例验证

 该程序给出：$$F(2,7)=204$$与声明相符。 

还：$$F(23,76)\equiv 5870548 \pmod{1\,000\,000\,009}$$再次与声明完全匹配。 

所以该方法是有效的。
