[欧拉项目 918 问题](https://projecteuler.net/problem=918)

 ## 解决方案

 **答案：**`-6999033352333308`使用递归$$a_{2n}=2a_n,\qquad a_{2n+1}=a_n-3a_{n+1},$$我们推导出部分和的递推式$$S(N)=\sum_{k=1}^N a_k.$$对于偶数指数：$$\begin{aligned} S(2N) &=\sum_{k=1}^N a_{2k}+\sum_{k=0}^{N-1}a_{2k+1}\\ &=2S(N)+\left(a_1+\sum_{k=1}^{N-1}(a_k-3a_{k+1})\right)\\ &=2S(N)+\left(1+S(N-1)-3(S(N)-1)\right)\\ &=4-a_N. \end{aligned}$$因此$$S(10^{12}) = 4-a_{5\cdot 10^{11}}.$$所以还需要计算$a_{500000000000}$。 

直接记忆递归就足够了，因为每一步都将参数减半：```python
from functools import lru_cache

@lru_cache(None)
def a(n):
    if n == 1:
        return 1
    if n % 2 == 0:
        return 2 * a(n // 2)
    k = n // 2
    return a(k) - 3 * a(k + 1)

ans = 4 - a(500000000000)
print(ans)
```这会产生$$a_{500000000000}=6999033352333312,$$因此$$S(10^{12}) = 4-6999033352333312 = -6999033352333308.$$**答案：-6999033352333308**
