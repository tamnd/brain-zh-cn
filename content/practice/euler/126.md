[欧拉项目问题 126](https://projecteuler.net/problem=126)

 ## 解决方案

 **答案：**`18522`设长方体尺寸为$a \times b \times c$和$a \ge b \ge c \ge 1$，并让$L_k(a,b,c)$表示立方体的数量$k$围绕长方体的第 3 层。 

我们被要求找到最少的$n$这样正好$1000$不同的长方体/层的使用$n$立方体。 

---

 # 1.数学分析

 ## 第一层

 对于长方体$a\times b\times c$，第一层覆盖每个可见的面。 

实心长方体有表面积$$2(ab+bc+ca)$$所以第一层需要$$L_1 = 2(ab+bc+ca)$$立方体。 

例子：$$3\times2\times1$$给出$$2(3\cdot2+2\cdot1+3\cdot1)=2(6+2+3)=22$$匹配问题陈述。 

---

 ## 更高层

 当我们添加另一层时：

 - 每张暴露的脸都会扩大，
 - 边缘贡献线性增长，
 - 角落贡献额外的立方体。 

标准推导给出：$$L_k(a,b,c) = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$为了$k\ge1$。 

---

 ## 验证公式

 对于$3\times2\times1$：

 ### 第一层（$k=1$）$$22$$### 第二层（$k=2$）$$22 + 4(1)(3+2+1)+4(1)(0) =22+24 =46$$### 第三层（$k=3$）$$22+4(2)(6)+4(2)(1) =22+48+8 =78$$### 第四层（$k=4$）$$22+4(3)(6)+4(3)(2) =22+72+24 =118$$全部与问题陈述相匹配。 

---

 # 计算表示次数

 我们定义$$C(n)$$作为三元组的数量$(a,b,c,k)$准确地生产$n$立方体：$$n = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$我们必须找到最小的$n$这样$$C(n)=1000.$$---

 # 限制搜索

 我们系统地搜索：

 -$a \ge b \ge c \ge 1$- 层数$k\ge1$并计算每个可能的层大小，直到足够大的限制。 

已知欧拉计划问题 126 的答案如下$30000$，所以周围有一个极限$50000$非常安全。 

一旦最小的可能层已经超过限制，我们就停止循环。 

---

 # 2.Python实现```python
from collections import defaultdict

LIMIT = 50000

# count[n] = number of cuboids/layers producing n cubes
count = defaultdict(int)

# Enumerate cuboid dimensions with a >= b >= c >= 1
for a in range(1, LIMIT):
    
    # Minimum layer for b=c=1
    if 2 * (a + 1 + a) > LIMIT:
        break

    for b in range(1, a + 1):

        # Minimum layer for c=1
        first = 2 * (a*b + a + b)
        if first > LIMIT:
            break

        for c in range(1, b + 1):

            # First layer
            base = 2 * (a*b + a*c + b*c)

            if base > LIMIT:
                break

            k = 1

            while True:
                n = (
                    base
                    + 4*(k-1)*(a+b+c)
                    + 4*(k-1)*(k-2)
                )

                if n > LIMIT:
                    break

                count[n] += 1
                k += 1

# Find smallest n with exactly 1000 representations
answer = min(n for n in count if count[n] == 1000)

print(answer)
```---

 # 3. 代码演练

 ## 数据结构```python
count = defaultdict(int)
```这家店$C(n)$, 获取层大小的方法数量$n$。 

---

 ## 枚举维度```python
for a in range(1, LIMIT):
```我们以非递增顺序迭代长方体维度：$$a \ge b \ge c$$以避免重复的长方体。 

---

 ## 第一层绑定```python
first = 2 * (a*b + a + b)
```这是固定的最小可能层$a,b$什么时候$c=1$。 

如果甚至超过限制，则更大$c$也会的。 

---

 ## 图层公式```python
n = (
    base
    + 4*(k-1)*(a+b+c)
    + 4*(k-1)*(k-2)
)
```这直接实现了$$L_k(a,b,c) = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$---

 ## 计算出现次数```python
count[n] += 1
```每个有效$(a,b,c,k)$贡献一种代表性。 

---

 ## 最终提取```python
answer = min(n for n in count if count[n] == 1000)
```我们寻找最小的$n$恰好与$1000$交涉。
