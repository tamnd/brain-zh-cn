[项目欧拉问题 207](https://projecteuler.net/problem=207)

 ## 解决方案

 **答案：**`44043947822`让$$4^t = 2^t + k.$$我们被问及正整数$k$存在这样的分区，并且其中，那些$t\in\mathbb Z$（“完美”分区）。 

我们想要最小的$m$这样$$P(m) < \frac1{12345},$$在哪里$P(m)$是分区的比例$k\le m$那是完美的。 

---

 # 第 1 步：重写方程

 套装$$x = 2^t.$$然后$$4^t = (2^t)^2 = x^2,$$所以定义方程变成$$x^2 = x + k.$$因此$$k = x^2 - x = x(x-1).$$自从$k$必须是整数，$x$也必须是整数（因为$x$满足单调多项式$x^2-x-k=0$; 整数根条件给出$x\in\mathbb Z$）。 

因此每个分区精确对应一个整数$$x=n\ge2,$$和$$k=n(n-1).$$所以可以受理的$k$正是$$2,6,12,20,30,\dots$$匹配示例。 

---

 # 第 2 步：描述完美分区的特征

 分区是完美的，当$t$是一个整数。 

但$x=2^t$。 所以：

-$t\in\mathbb Z$- 当且仅当$x$是二的幂。 

所以完美分区对应于$$x=2^a \quad (a\ge1),$$给予$$k = 2^a(2^a-1).$$---

 # 第 3 步：计算分区数量$m$所有分区均按整数索引$n\ge2$和$$k=n(n-1)\le m.$$假设最大的这样$n$是$N$。 然后$$N(N-1)\le m < (N+1)N.$$因此分区总数最多为$m$是$$N-1$$（自从$n=2,3,\dots,N$）。 

现在计算完美分区。 

完美分区发生在$n$是二的幂：$$n=2,4,8,\dots,2^A\le N.$$所以完美分区的数量是$$A,$$在哪里$$A=\lfloor \log_2 N\rfloor.$$所以$$P(m)=\frac{\lfloor \log_2 N\rfloor}{N-1}.$$---

 # 第四步：解决不等式

 我们需要$$\frac{\lfloor \log_2 N\rfloor}{N-1}<\frac1{12345}.$$让$$a=\lfloor \log_2 N\rfloor.$$然后$$2^a \le N < 2^{a+1}.$$不等式变为$$12345a < N-1,$$或者$$N > 12345a+1.$$尽量减少$m$，我们最小化$N$。 所以对于每个$a$，最小的候选者是$$N = 12345a+2.$$但这$N$必须满足$$\lfloor \log_2 N\rfloor = a,$$IE。$$2^a \le 12345a+2 < 2^{a+1}.$$我们测试的值$a$。 

-$a=16$：$$12345\cdot16+2=197522,$$但$$2^{16}=65536,\qquad 2^{17}=131072.$$太大了。 

-$a=17$：$$12345\cdot17+2=209867,$$和$$2^{17}=131072,\qquad 2^{18}=262144.$$这有效。 

因此最小有效$N$是$$N=209867.$$那么对应的最小的$m$正是与此相符的最小值$N$，即$$m=N(N-1).$$所以$$m=209867\cdot209866.$$计算：$$209867^2 = 44\,044\,151\,689,$$因此$$m=209867^2-209867 =44\,044\,151\,689-209\,867 =44\,043\,941\,822.$$---

 # Python 实现```python
import math

TARGET = 12345

a = 1

while True:
    # smallest N satisfying:
    # a / (N - 1) < 1 / TARGET
    N = TARGET * a + 2

    # check whether floor(log2(N)) == a
    if (1 << a) <= N < (1 << (a + 1)):
        m = N * (N - 1)
        print(m)
        break

    a += 1
```---

 # 小例子验证

 采取$m=30$。 

有效的分区是：$$2,6,12,20,30$$对应于$n=2,3,4,5,6$。 

完美的发生在$n=2,4$， IE。$k=2,12$。 

所以$$P(30)=\frac25,$$与声明相符。 

还：

-$m=180$对应于$N=14$，
- 完美的$n$是$2,4,8$，
- 所以$P(180)=3/12=1/4$,

 再次匹配问题。 

---

 # 最终验证

 我们发现：$$N=209867,$$给予$$P(m)=\frac{17}{209866}.$$的确，$$17\cdot12345=209865<209866,$$所以$$\frac{17}{209866}<\frac1{12345}.$$对于之前的$N=209866$,$$\frac{17}{209865}=\frac1{12345},$$所以我们的值正是低于阈值的第一个值。 

因此，结果是一致且最小的。
