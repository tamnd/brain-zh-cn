[项目欧拉问题 261](https://projecteuler.net/problem=261)

 ## 解决方案

 **答案：**`238890850232021`让$$S(a,b)=a^2+(a+1)^2+\cdots+b^2$$并假设$k$是一个方枢轴。 那么存在整数$m>0$和$n\ge k$这样$$(k-m)^2+\cdots+k^2=(n+1)^2+\cdots+(n+m)^2.$$我们必须找到所有不同的此类的总和$k\le 10^{10}$。 

---

 # 1.数学分析

 平方和公式为$$\sum_{i=1}^{t} i^2=\frac{t(t+1)(2t+1)}6.$$所以$$S(k-m,k)=S(n+1,n+m).$$用前缀和来写这个并简化给出$$k^2(m+1)-km(m+1)-mn(m+n+1)=0.$$除以$m(m+1)$给出更对称的形式$$\frac{k^2}{m}-k-n-\frac{n^2}{m+1}=0. \tag{1}$$---

 ## 边界$m$自从$n\ge k$,$$\frac{k^2}{m}-2k-\frac{k^2}{m+1}\ge0.$$化简后：$$k\ge 2m(m+1).$$因此对于$k\le N=10^{10}$,$$2m(m+1)\le N.$$所以$$m \le \frac{-1+\sqrt{1+2N}}2 \approx 70710.$$因此仅关于$7\times 10^4$的值$m$需要检查。 

---

 # 2. 转换为 Pell 方程

 引入整数$x,t$经过$$\begin{cases} 2k = m(x+1)+t,\\ 2n = (m+1)(x-1)+t. \end{cases}$$代入(1)并简化产量$$m(m+1)(x^2-1)=t^2. \tag{2}$$现在写$$m=r p^2,\qquad m+1=s q^2,$$在哪里$r,s$是无平方的。 

因为连续的整数是互质的，$r,s$也是互质的。 

方程（2）变为$$r s p^2 q^2 (x^2-1)=t^2.$$因此$rpsq\mid t$。 让$$t=rpsq\,y.$$然后$$x^2-rs\,y^2=1. \tag{3}$$这是佩尔方程。 

所以对于每一个$m$，我们：

 1. 计算无平方部分$r,s$的$m,m+1$。 
2. 求解佩尔方程$$x^2-Dy^2=1, \qquad D=rs.$$3. 生成所有 Pell 解决方案。 
4. 恢复$$k=\frac{m(x+1)+t}{2}, \qquad t=rpsq\,y.$$5. 保持所有不同$k\le 10^{10}$。 

---

 # 3.Python实现```python
from math import isqrt

N = 10**10

# ---------------------------------------------------------
# Compute squarefree part and square part of every integer
# n = sf[n] * sq[n]^2
# ---------------------------------------------------------

M = (-1 + isqrt(1 + 2 * N)) // 2

sf = [0] * (M + 3)   # squarefree part
sq = [0] * (M + 3)   # square root of square part

for n in range(1, M + 3):

    x = 1
    y = 1
    t = n

    d = 2
    while d * d <= t:

        if t % d == 0:

            e = 0
            while t % d == 0:
                t //= d
                e += 1

            # odd exponent contributes to squarefree part
            if e & 1:
                x *= d

            # floor(e/2) contributes to square part
            y *= d ** (e >> 1)

        d += 1 if d == 2 else 2

    if t > 1:
        x *= t

    sf[n] = x
    sq[n] = y

# ---------------------------------------------------------
# Fundamental Pell solution x^2 - D y^2 = 1
# via continued fractions
# ---------------------------------------------------------

def pell_fundamental(D):

    a0 = isqrt(D)

    if a0 * a0 == D:
        return None

    m = 0
    d = 1
    a = a0

    num_prev, num = 1, a
    den_prev, den = 0, 1

    while num * num - D * den * den != 1:

        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        num_prev, num = num, num_prev + a * num
        den_prev, den = den, den_prev + a * den

    return num, den

# ---------------------------------------------------------
# Enumerate all square-pivots
# ---------------------------------------------------------

ans_set = set()

for m in range(1, M + 1):

    D = sf[m] * sf[m + 1]

    x1, y1 = pell_fundamental(D)

    # Generate all Pell solutions
    x, y = x1, y1

    # t = sf[m]*sf[m+1]*sq[m]*sq[m+1]*y
    mult = sf[m] * sf[m + 1] * sq[m] * sq[m + 1]

    while True:

        t = mult * y

        kk = m * (x + 1) + t

        if kk > 2 * N:
            break

        nn = (m + 1) * (x - 1) + t

        # parity checks + n >= k
        if kk % 2 == 0 and nn % 2 == 0 and nn >= kk:
            ans_set.add(kk // 2)

        # Next Pell solution
        x, y = (
            x1 * x + D * y1 * y,
            x1 * y + y1 * x
        )

answer = sum(ans_set)

print(answer)
```---

 # 4. 代码演练

 ## 步骤 1 — 限制搜索```python
M = (-1 + isqrt(1 + 2 * N)) // 2
```从$$2m(m+1)\le N,$$这给出了最大可能$m$。 

---

 ## 步骤 2 — 分解整数

 对于每个整数$n$,$$n = \text{squarefree}(n)\times (\text{square part})^2.$$我们存储：

 -`sf[n]`= 无正方形部分
 -`sq[n]`= 平方部分的平方根

 这些是形成佩尔判别式所必需的。 

---

 ## 步骤 3 — 求解佩尔方程

 对于每个$m$,$$D = \operatorname{sf}(m)\operatorname{sf}(m+1).$$我们解决$$x^2 - D y^2 = 1.$$功能`pell_fundamental`使用连分数计算基本解。 

---

 ## 步骤 4 — 生成所有解决方案

 所有佩尔解决方案均来自基本单位的力量：$$x+y\sqrt D=(x_1+y_1\sqrt D)^n.$$复发```python
x, y = (
    x1 * x + D * y1 * y,
    x1 * y + y1 * x
)
```依次生成它们。 

---

 ## 步骤 5 — 恢复$k$使用$$k=\frac{m(x+1)+t}{2},$$和$$t=\operatorname{sf}(m)\operatorname{sf}(m+1)    \operatorname{sq}(m)\operatorname{sq}(m+1)\,y.$$我们验证奇偶性并$n\ge k$，然后存储不同的$k$。
