[项目欧拉问题 395](https://projecteuler.net/problem=395)

 ## 解决方案

 **答案：**`28.2453753155`设初始正方形为有角的单位正方形$$(0,0),\ (1,0),\ (1,1),\ (0,1).$$顶边用作斜边$3\text{-}4\text{-}5$直角三角形。 

---

 # 1. 两个子方块的几何形状

 让顶面从$$A=(0,1),\qquad B=(1,1).$$三角形的顶点$C$满足$$|AC|=\frac45,\qquad |BC|=\frac35.$$求解给出$$C=\left(\frac{16}{25},\frac{37}{25}\right).$$因此两条腿向量是$$v_L=C-A=\frac{16+12i}{25},$$

$$v_R=B-C=\frac{9-12i}{25}.$$它们的长度是$$|v_L|=\frac45,\qquad |v_R|=\frac35.$$因此，树中的每个方块都会通过仿射映射生成两个较小的方块$$T_L(z)=i+\frac{16+12i}{25}z,$$

$$T_R(z)=\frac{16+37i}{25}+\frac{9-12i}{25}z.$$所以整个毕达哥拉斯树就是这个迭代函数系统的吸引子。 

---

 # 2. 边界矩形

 我们需要包含吸引子的最小轴对齐矩形（与原始正方形对齐）。 

关键的观察是：

 - 每个后代方块都是原始单位方块的仿射图像，
 - 宫缩是$4/5$和$3/5$,
 - 因此极值$x$- 和$y$- 坐标快速收敛。 

因此，我们递归地生成所有平方到足够小的尺度并跟踪全局极值。 

如果一个正方形有左下角$p$和边向量$u$，那么它的角是$$p,\quad p+u,\quad p+u+iu,\quad p+iu.$$两个子方块是：

 ### 左孩子

 底座侧$AC$：$$u_L=\frac{16+12i}{25}u, \qquad p_L=p+iu.$$### 右孩子

 底座侧$CB$：$$u_R=\frac{9-12i}{25}u, \qquad p_R=p+iu+u_L.$$因为缩放因子是$0.8$和$0.6$，递归收敛得很快。

 # 3.Python实现```python
from math import *

# ------------------------------------------------------------
# Generate the Pythagorean tree recursively and track bounds
# ------------------------------------------------------------

# child transformations
LEFT  = complex(16, 12) / 25.0
RIGHT = complex(9, -12) / 25.0

# global bounds
xmin = 1e100
xmax = -1e100
ymin = 1e100
ymax = -1e100

def update_bounds(p, u):
    """
    Update bounding box using the four corners
    of the square defined by lower-left corner p
    and side vector u.
    """
    global xmin, xmax, ymin, ymax

    corners = [
        p,
        p + u,
        p + u + 1j * u,
        p + 1j * u
    ]

    for z in corners:
        xmin = min(xmin, z.real)
        xmax = max(xmax, z.real)
        ymin = min(ymin, z.imag)
        ymax = max(ymax, z.imag)

def recurse(p, u, eps):
    """
    Recursively generate child squares.
    Stop once the square side length becomes tiny.
    """
    update_bounds(p, u)

    if abs(u) < eps:
        return

    # top-left corner of current square
    A = p + 1j * u

    # left child
    uL = LEFT * u
    pL = A

    # right child
    pR = A + uL
    uR = RIGHT * u

    recurse(pL, uL, eps)
    recurse(pR, uR, eps)

# initial unit square
recurse(0 + 0j, 1 + 0j, 1e-15)

area = (xmax - xmin) * (ymax - ymin)

print("xmin =", xmin)
print("xmax =", xmax)
print("ymin =", ymin)
print("ymax =", ymax)
print("area =", area)
print(round(area, 10))
```---

 # 4. 代码演练

 ### 常量```python
LEFT  = complex(16, 12) / 25.0
RIGHT = complex(9, -12) / 25.0
```这正是来自$3\text{-}4\text{-}5$三角形几何。 

---

 ###`update_bounds`对于每个正方形，我们计算它的四个角并更新全局最小值/最大值$x$和$y$。 

---

 ###`recurse`每个正方形生成两个较小的正方形：

 - 左孩子缩放$4/5$,
 - 右孩子缩放$3/5$。 

当正方形变得非常小时，递归终止。

 - 但仍然受到限制，因为每一代人都会缩小。
