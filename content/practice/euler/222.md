[项目欧拉问题 222](https://projecteuler.net/problem=222)

 ## 解决方案

 **答案：**`1590933`让管道有内半径$$R=50\text{ mm}.$$我们必须将$21$半径球$$30,31,\dots,50 \text{ mm}$$位于气缸内，使总管道长度最小。 

# 1. 几何分析

 考虑两个具有半径的连续球$r$和$s$。 

在最佳包装中：

 - 每个球都接触气缸壁，
 - 连续的球互相接触，
 - 它们的中心从圆柱体的一侧交替到另一侧。 

横截面图给出：

 - 从圆柱轴到半径球中心的距离$r$:$$R-r$$- 两个中心之间的横向间隔：$$(R-r)+(R-s)=2R-r-s.$$由于两个球相互接触，因此中心距为$$r+s.$$因此，如果$d(r,s)$是中心之间的轴向间距，$$d(r,s)^2 + (2R-r-s)^2 = (r+s)^2.$$因此$$d(r,s) = \sqrt{(r+s)^2-(2R-r-s)^2}.$$和$R=50$,$$d(r,s) = \sqrt{(r+s)^2-(100-r-s)^2}.$$因素：$$d(r,s) = \sqrt{100(2r+2s-100)} = 10\sqrt{2(r+s)-100}.$$所以距离只取决于$r+s$。 

---

 ## 管道总长度

 如果第一个和最后一个球有半径$a$和$b$，则管道长度为$$L = a+b+\sum d(r_i,r_{i+1}).$$因此，我们必须最小化相邻间隔的总和。 

因为$d(r,s)$正在增加$r+s$，我们希望相邻的和尽可能小。 

最优排序是：$$50,48,46,\dots,32,30,31,33,35,\dots,47,49.$$即：

 - 减少事件，
 - 然后增加赔率。 

这使得整个链条中相邻的金额非常小。

 # 2.Python实现```python
from math import sqrt

# Ball radii
balls = list(range(30, 51))

# Optimal ordering
order = (
    list(range(50, 29, -2)) +   # 50,48,...,30
    list(range(31, 50, 2))      # 31,33,...,49
)

def axial_distance(r, s):
    """
    Axial separation between centers of two touching balls
    inside a cylinder of radius 50 mm.
    """
    return sqrt((r + s)**2 - (100 - r - s)**2)

# Total pipe length in mm
length_mm = order[0] + order[-1]

for i in range(len(order) - 1):
    length_mm += axial_distance(order[i], order[i + 1])

# Convert mm -> micrometres
length_um = round(length_mm * 1000)

print(length_mm)
print(length_um)
```---

 ### 轴向距离公式```python
sqrt((r + s)**2 - (100 - r - s)**2)
```实施$$d(r,s)=\sqrt{(r+s)^2-(100-r-s)^2}.$$---

 ### 总长度```python
length_mm = order[0] + order[-1]
```添加末端间隙。 

然后循环添加每个中心到中心的轴向间隔。 

最后：```python
length_um = round(length_mm * 1000)
```将毫米转换为微米。

 # 4.最终验证

 计算出的长度为$$1590.933116\ldots \text{ mm}$$这等于$$1\,590\,933.116\ldots \text{ micrometres}.$$四舍五入到最接近的整数：$$1\,590\,933.$$这个幅度是合理的：

 - 21 个球，每个球的直径约为$60$–$100$毫米，
 - 但轴向方向上的严重重叠将总数减少到大约$1.59$米。
