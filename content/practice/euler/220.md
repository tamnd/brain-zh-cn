[项目欧拉问题 220](https://projecteuler.net/problem=220)

 ## 解决方案

 **答案：**`139776963904`让

-$A_n$表示符号的展开`a`后$n$重写，
 -$B_n$表示符号的展开`b`后$n$重写。 

重写规则是$$a \to aRbFR,\qquad b \to LFaLb$$完整的龙是$$D_n = F A_n$$因为$D_0 = Fa$。 

关键的观察是：

 - 每一代前进的次数都会加倍，
 - 但字符串总长度呈指数增长，
 - 所以我们无法生成$D_{50}$明确地。 

相反，我们递归计算：

 1. 每个块的位移矢量，
 2.执行后方向改变，
 3.里面的前进步数。 

然后我们尽可能“跳过”整个递归块。 

---

 # 数学分析

 我们使用方向$$0=\text{up},\quad 1=\text{right},\quad 2=\text{down},\quad 3=\text{left}.$$朝着前进的方向前进$d$是：$$(0,1),(1,0),(0,-1),(-1,0).$$对于我们存储的每个递归块：$$(\Delta x,\Delta y,\Delta d,\text{steps})$$含义：

 - 净排水量，
 - 净旋转，
 - 数量`F`指示。 

---

 ## 递归结构

 对于$n\ge1$,$$A_n = A_{n-1} \; R \; B_{n-1} \; F \; R$$

$$B_n = L \; F \; A_{n-1} \; L \; B_{n-1}$$符号`a,b`他们自己在水平上什么也不做$0$， 所以$$A_0=B_0=\varepsilon$$零位移和零步长。 

---

 ## 前进步数

 让$f_n$是`F`命令在$A_n$。 

由递归可知：$$f_n=f_{n-1}+f_{n-1}+1$$和$f_0=0$。 

因此$$f_n = 2^n-1.$$所以$D_{50}$包含$$1+(2^{50}-1)=2^{50}$$向前迈出的步伐，舒适地大于$10^{12}$。 

---

 # 高效的递归跳过

 假设我们想要第一个$k$走进去$A_n$。 

对于每个子块：

 - 如果整个子块包含$\le k$步骤，我们使用其预先计算的位移立即跳过它；
 - 否则我们递归到该块。 

这仅给出了复杂性$O(n)$。 

---

 # Python 实现```python
from functools import lru_cache

# Rotate a vector clockwise by 90 degrees d times
def rotate(v, d):
    x, y = v
    for _ in range(d % 4):
        x, y = y, -x
    return x, y

# ------------------------------------------------------------
# Precompute properties of A_n and B_n
#
# Returns:
#   (dx, dy, dir_change, steps)
# ------------------------------------------------------------

@lru_cache(None)
def props(symbol, n):

    # Base case: a and b do nothing at level 0
    if n == 0:
        return (0, 0, 0, 0)

    if symbol == 'a':
        seq = ['a', 'R', 'b', 'F', 'R']
    else:
        seq = ['L', 'F', 'a', 'L', 'b']

    x = y = 0
    d = 0
    steps = 0

    for t in seq:

        if t in 'ab':

            dx, dy, dd, ss = props(t, n - 1)

            # Rotate displacement into current orientation
            rdx, rdy = rotate((dx, dy), d)

            x += rdx
            y += rdy

            d = (d + dd) % 4
            steps += ss

        elif t == 'F':

            move = [(0, 1), (1, 0), (0, -1), (-1, 0)][d]

            x += move[0]
            y += move[1]
            steps += 1

        elif t == 'L':
            d = (d - 1) % 4

        elif t == 'R':
            d = (d + 1) % 4

    return (x, y, d, steps)

# ------------------------------------------------------------
# Walk the first k forward steps inside symbol_n
# ------------------------------------------------------------

def walk(symbol, n, k, pos=(0, 0), direction=0):

    x, y = pos
    d = direction

    if n == 0 or k == 0:
        return (x, y, d, k)

    if symbol == 'a':
        seq = ['a', 'R', 'b', 'F', 'R']
    else:
        seq = ['L', 'F', 'a', 'L', 'b']

    for t in seq:

        if k == 0:
            break

        if t in 'ab':

            dx, dy, dd, ss = props(t, n - 1)

            # Skip whole block if possible
            if ss <= k:

                rdx, rdy = rotate((dx, dy), d)

                x += rdx
                y += rdy

                d = (d + dd) % 4
                k -= ss

            else:
                x, y, d, k = walk(t, n - 1, k, (x, y), d)

        elif t == 'F':

            move = [(0, 1), (1, 0), (0, -1), (-1, 0)][d]

            x += move[0]
            y += move[1]

            k -= 1

        elif t == 'L':
            d = (d - 1) % 4

        elif t == 'R':
            d = (d + 1) % 4

    return (x, y, d, k)

# ------------------------------------------------------------
# Full dragon D_n = F + A_n
# ------------------------------------------------------------

def solve(n, steps):

    # Initial instruction F
    x, y = (0, 1)
    steps -= 1

    if steps > 0:
        x, y, d, rem = walk('a', n, steps, (x, y), 0)

    return x, y

# ------------------------------------------------------------
# Verification against the example
# ------------------------------------------------------------

print(solve(10, 500))      # should be (18, 16)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

print(solve(50, 10**12))
```---

 # 代码演练

 ##`props(symbol, n)`这递归地计算了完整的效果$A_n$或者$B_n$:

 - 位移，
 - 最终方向，
 - 前进的步数。 

这些值会被记忆，因此每个状态都会计算一次。 

---

 ##`walk(symbol, n, k, ...)`这仅递归执行第一个$k$向前移动。 

重点优化：```python
if ss <= k:
```意思是：

 > 整个递归块适合剩余预算，
 >
 > 所以我们立即跳过它。 

否则我们会更深地递归。 

---

 ##`solve(n, steps)`龙以首字母开头`F`，然后执行$A_n$。 

所以我们：

 1.移动一次到$(0,1)$,
 2. 递归处理剩余步骤。
