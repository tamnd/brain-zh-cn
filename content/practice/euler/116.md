[欧拉项目问题 116](https://projecteuler.net/problem=116)

 ## 解决方案

 **答案：**`20492570929`让$F_m(n)$表示平铺一行长度的方式数$n$使用：

 - 长度为灰色的方块$1$, 和
 - 固定长度的彩色长方形瓷砖$m$,

 条件是**至少使用一块彩色瓷砖**。 

对于这个问题：

 - 红色瓷砖有长度$2$,
 - 绿色瓷砖有长度$3$,
 - 蓝色瓷砖有长度$4$,

 并且颜色不能混合，所以最终答案是$$F_2(50)+F_3(50)+F_4(50).$$---

 # 步骤 1 — 推导递归式

 固定瓷砖长度$m$。 

我们首先计算所有平铺（包括全灰色排列），然后减去$1$在最后。 

让$$T_m(n)$$是一行长度的平铺总数$n$使用：

 - 长度为灰色的方块$1$,
 - 长度的彩色瓷砖$m$。 

我们从最左边的位置推导递归。 

---

 ## 案例分析

 考虑第一块瓷砖。 

### 情况 1：第一个图块是灰色的

 然后我们消耗一个单位，留下一行长度$n-1$：$$T_m(n-1).$$### 情况 2：第一个图块是彩色的

 彩色瓷砖占据$m$单位，留下一行长度$n-m$：$$T_m(n-m).$$这些是唯一的可能性，所以对于$n \ge m$,$$T_m(n)=T_m(n-1)+T_m(n-m).$$对于小$n<m$，没有适合的彩色瓷砖，所以唯一的排列是全灰色的：$$T_m(n)=1 \qquad (0\le n<m).$$还，$$T_m(0)=1.$$最后，由于问题需要**至少一个彩色瓷砖**，我们减去全灰色排列：$$F_m(n)=T_m(n)-1.$$因此所需的答案是$$(T_2(50)-1)+(T_3(50)-1)+(T_4(50)-1).$$---

 # 第 2 步 — 检查示例$n=5$## 红色瓷砖 ($m=2$）

使用$$T_2(n)=T_2(n-1)+T_2(n-2),$$和$$T_2(0)=1,\quad T_2(1)=1,$$我们得到：$$\begin{aligned} T_2(2)&=2\\ T_2(3)&=3\\ T_2(4)&=5\\ T_2(5)&=8 \end{aligned}$$因此$$F_2(5)=8-1=7,$$与声明相符。 

---

 ## 绿色瓷砖 ($m=3$）$$\begin{aligned} T_3(0)&=1\\ T_3(1)&=1\\ T_3(2)&=1\\ T_3(3)&=2\\ T_3(4)&=3\\ T_3(5)&=4 \end{aligned}$$因此$$F_3(5)=4-1=3.$$正确的。 

---

 ## 蓝色瓷砖 ($m=4$）$$\begin{aligned} T_4(0)&=1\\ T_4(1)&=1\\ T_4(2)&=1\\ T_4(3)&=1\\ T_4(4)&=2\\ T_4(5)&=3 \end{aligned}$$所以$$F_4(5)=3-1=2.$$全部的：$$7+3+2=12,$$完全按照给定的。

 # 第 3 步 — Python 实现```python
def count_ways(n, m):
    """
    Count tilings of a row of length n using:
      - grey tiles of length 1
      - coloured tiles of fixed length m

    At least one coloured tile must be used.
    """

    # dp[i] = total tilings of length i, including all-grey
    dp = [0] * (n + 1)

    # Base case
    dp[0] = 1

    for i in range(1, n + 1):

        # Put a grey tile first
        dp[i] += dp[i - 1]

        # Put a coloured tile first (if it fits)
        if i >= m:
            dp[i] += dp[i - m]

    # Exclude the all-grey arrangement
    return dp[n] - 1

answer = (
    count_ways(50, 2) +
    count_ways(50, 3) +
    count_ways(50, 4)
)

print(answer)
```---
