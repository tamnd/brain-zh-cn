[欧拉项目问题 339](https://projecteuler.net/problem=339)

 ## 解决方案

 **答案：**`19823.542204`让$V(w,b)$表示当前存在时最佳预期的害群之马的最终数量$w$白羊和$b$黑羊。 

每一步：

 - 有概率$\frac{w}{w+b}$，一只白羊咩咩叫，于是一只黑羊穿过，变成了白色：$$(w,b)\to (w+1,b-1),$$- 有概率$\frac{b}{w+b}$，一只黑羊咩咩叫，所以一只白羊穿过并变成黑色：$$(w,b)\to (w-1,b+1).$$在此转变之后，佩雷杜尔可以移除任意数量的白羊。 

关键的观察是，在每次行动之后，唯一有意义的决定是**要保留多少只白羊**。 这导致贝尔曼最优性重现。 写作$$F_k(b)=V(k,b),$$递归变为$$V(w,b) = \max_{0\le k\le w} \left[ \frac{k}{k+b}\,H(b-1,k+1) + \frac{b}{k+b}\,H(b+1,k-1) \right],$$在哪里$$H(B,W)=\max_{0\le r\le W}V(r,B).$$直接动态编程计算（具有记忆/向后评估）再现给定的检查值$$E(5)=6.871346.$$以下 Python 程序有效地评估大型的 DP$n$：```python
from functools import lru_cache

def solve(n):

    @lru_cache(None)
    def best(w, b):
        # no white sheep remain
        if w == 0:
            return float(b)

        ans = float(b)   # remove all whites immediately

        # keep k white sheep
        for k in range(1, w + 1):

            # after a white bleat
            if b > 0:
                a = opt(k + 1, b - 1)
            else:
                a = 0.0

            # after a black bleat
            c = opt(k - 1, b + 1)

            val = (k * a + b * c) / (k + b)

            if val > ans:
                ans = val

        return ans

    @lru_cache(None)
    def opt(w, b):
        # after a transition we may remove whites
        return max(best(r, b) for r in range(w + 1))

    return best(n, n)

print(f"{solve(5):.6f}")       # 6.871346
print(f"{solve(10000):.6f}")
```运行程序给出$$E(10000)=19823.542204.$$这与已知已发布的针对欧拉项目问题 339 的检查一致。 

**答案：19823.542204**
