[项目欧拉问题 188](https://projecteuler.net/problem=188)

 ## 解决方案

 **答案：**`95962097`我们需要最后一个$8$的数字$$1777 \uparrow\uparrow 1855$$那是，$$1777^{(1777^{(1777^{\cdot^{\cdot^\cdot}})})}$$和$1855$的副本$1777$。 

关键的难点在于指数大得难以想象，无法直接计算。 该解决方案依赖于模算术和欧拉定理。 

---

 # 数学分析

 我们想要$$1777 \uparrow\uparrow 1855 \pmod{10^8}.$$让$$T_n = 1777 \uparrow\uparrow n.$$然后$$T_{n+1} = 1777^{T_n}.$$所以我们需要$$T_{1855} \bmod 10^8.$$---

 ## 步骤1：欧拉定理

 自从$$10^8 = 2^8 \cdot 5^8,$$和$1777$互质于$10^8$，欧拉定理适用：$$a^{\phi(m)} \equiv 1 \pmod m \quad\text{if}\quad \gcd(a,m)=1.$$因此指数可以减少模数$\phi(m)$。 

为了$m=10^8$,$$\phi(10^8) =10^8\left(1-\frac12\right)\left(1-\frac15\right) =10^8\cdot \frac12\cdot \frac45 =40\,000\,000.$$所以，$$1777^k \pmod{10^8}$$仅取决于$$k \pmod{40\,000\,000}.$$但现在指数本身是另一个四次幂，所以我们递归。 

---

 ## 步骤 2：递归模约化

 定义递归函数$$f(h,m)=1777\uparrow\uparrow h \pmod m.$$然后$$f(1,m)=1777\bmod m,$$并为$h>1$,$$f(h,m) = 1777^{\,f(h-1,\phi(m))} \pmod m.$$为什么这有效？ 

因为计算时$$1777^E \pmod m,$$指数$E$只关心模数$\phi(m)$。 

因此，我们不是精确地计算巨大的指数，而是计算它的模$\phi(m)$，然后再次递归。 

链条变成：$$10^8 \to \phi(10^8)=40\,000\,000 \to \phi(40\,000\,000)=16\,000\,000 \to \cdots$$最终模量变得足够小，使得递归很快稳定下来。 

---

 ## 步骤 3：高效模幂

 Python 提供：```python
pow(base, exponent, modulus)
```它使用对数时间内的重复平方有效地计算模幂。 

所以每个递归层都很快。 

---

 # Python 实现```python
from math import gcd

def phi(n):
    """Compute Euler's totient function."""
    result = n
    p = 2

    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1

    if n > 1:
        result -= result // n

    return result

def tetration_mod(a, height, mod):
    """
    Compute a ↑↑ height (tetration) modulo mod.
    """

    # Base case
    if mod == 1:
        return 0

    if height == 1:
        return a % mod

    # Recursively compute exponent modulo phi(mod)
    exponent = tetration_mod(a, height - 1, phi(mod))

    # Euler reduction
    return pow(a, exponent, mod)

answer = tetration_mod(1777, 1855, 10**8)

print(answer)
```---
