[欧拉项目问题 356](https://projecteuler.net/problem=356)

 ## 解决方案

 **答案：**`28010159`让根$$g_n(x)=x^3-2^n x^2+n$$是$a_n,b_n,c_n$， 在哪里$a_n$是最大实根。 

我们寻求$$\sum_{n=1}^{30}\left\lfloor a_n^{987654321}\right\rfloor$$模数$10^8$。 

## 1.数学分析

 ### 第 1 步：将下限与幂和相关联

 根据 Viète 的公式，$$a_n+b_n+c_n = 2^n,$$

$$a_nb_n+a_nc_n+b_nc_n=0,$$

$$a_nb_nc_n=-n.$$为了$n\ge 2$，多项式有一个大的正根$a_n$, 一个小的正根$b_n\in(0,1)$，和一个负根$c_n\in(-1,0)$。 为了$n=1$，根是$$\phi,\quad 1,\quad -\frac1\phi.$$因此在每种情况下：$$0<b_n\le 1,\qquad -1<c_n<0,$$并且由于指数$$m=987654321$$是奇数，$$0<b_n^m+c_n^m<1.$$定义整数幂和$$S_k = a_n^k+b_n^k+c_n^k.$$然后$$a_n^m=S_m-(b_n^m+c_n^m),$$和$0<b_n^m+c_n^m<1$。 所以：$$\boxed{\lfloor a_n^m\rfloor = S_m-1.}$$所以我们只需要$S_m$。 

---

 ### 步骤 2：推导递归$S_k$每根$r$满足$$r^3=2^n r^2-n.$$乘以$r^{k-3}$,$$r^k = 2^n r^{k-1} - n r^{k-3}.$$对所有三个根求和：$$\boxed{ S_k = 2^n S_{k-1} - n S_{k-3} } \qquad (k\ge 3).$$初始值：$$S_0=3,$$

$$S_1=a_n+b_n+c_n=2^n,$$

$$S_2=(a_n+b_n+c_n)^2 -2(a_nb_n+a_nc_n+b_nc_n) =2^{2n}.$$因此：$$S_0=3,\qquad S_1=2^n,\qquad S_2=2^{2n}.$$由于我们只需要**最后八位**，我们计算递归模$$10^8.$$使用矩阵求幂：$$\begin{pmatrix} S_k\\ S_{k-1}\\ S_{k-2} \end{pmatrix} = \begin{pmatrix} 2^n & 0 & -n\\ 1&0&0\\ 0&1&0 \end{pmatrix} \begin{pmatrix} S_{k-1}\\ S_{k-2}\\ S_{k-3} \end{pmatrix}.$$求幂$3\times3$矩阵幂$m-2$给出$S_m$在$O(\log m)$。

 ## 2.Python实现```python
MOD = 10**8
M = 987654321

def mat_mul(A, B):
    """Multiply two 3x3 matrices modulo MOD."""
    return [
        [
            (
                A[i][0] * B[0][j]
                + A[i][1] * B[1][j]
                + A[i][2] * B[2][j]
            ) % MOD
            for j in range(3)
        ]
        for i in range(3)
    ]

def mat_pow(A, exponent):
    """Fast matrix exponentiation."""
    result = [
        [1, 0, 0],
        [0, 1, 0],
        [0, 0, 1]
    ]

    while exponent:
        if exponent & 1:
            result = mat_mul(result, A)

        A = mat_mul(A, A)
        exponent >>= 1

    return result

answer = 0

for n in range(1, 31):

    two_n = pow(2, n, MOD)

    # Transition matrix for:
    # S_k = 2^n * S_{k-1} - n * S_{k-3}
    transition = [
        [two_n, 0, (-n) % MOD],
        [1, 0, 0],
        [0, 1, 0]
    ]

    # Initial vector [S_2, S_1, S_0]
    initial = [
        pow(2, 2 * n, MOD),
        two_n,
        3
    ]

    # Compute S_M
    power_matrix = mat_pow(transition, M - 2)

    S_M = (
        power_matrix[0][0] * initial[0]
        + power_matrix[0][1] * initial[1]
        + power_matrix[0][2] * initial[2]
    ) % MOD

    # floor(a_n^M) = S_M - 1
    answer = (answer + S_M - 1) % MOD

print(answer)
```---

 ## 3. 代码演练

 -`mat_mul`乘以二$3\times3$矩阵模$10^8$。 
-`mat_pow`使用二进制求幂计算矩阵幂$O(\log M)$。 
- 对于每个$n=1,\dots,30$:

 - 构建递归矩阵$$\begin{pmatrix} 2^n & 0 & -n\\ 1&0&0\\ 0&1&0 \end{pmatrix}.$$- 使用初始值：$$(S_2,S_1,S_0)=(2^{2n},2^n,3).$$- 计算$S_M$。 
- 添加$S_M-1$， 因为$$\lfloor a_n^M\rfloor=S_M-1.$$### 小例子检查

 对于$n=2$:$$a_2 = 3.86619826\ldots$$递归给出整数值$S_k$，而且确实$$\lfloor a_2^{11}\rfloor = S_{11}-1,$$匹配直接数值计算。

 ## 4.最终验证

 - 我们只需要最后 8 位数字，所以取模$10^8$算术有效。 
- 修正项总是准确的$-1$因为另外两个根贡献的数字严格介于$0$和$1$。 
- 矩阵求幂得到巨大的指数$987654321$计算上微不足道。
