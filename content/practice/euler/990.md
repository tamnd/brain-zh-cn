[项目欧拉问题 990](https://projecteuler.net/problem=990)

 ## 解决方案

 **答案：**`50322750`---

 # 数学分析

 我们必须计算总长度最多的所有有效方程$50$。 

一个典型的方程看起来像$$a_1+a_2+\cdots+a_p = b_1+b_2+\cdots+b_q$$和$$a_1+\cdots+a_p=b_1+\cdots+b_q$$每个数字都是不带前导零的正十进制整数。 

---

 ## 1. 反转观点：数字列DP

 不要考虑整个整数，而是从最低有效数字开始逐列处理方程。 

在任何小数列：

 - 一些数字仍然“有效”（它们继续更高的数字），
 - 一些数字在此列终止（它们的最高有效数字在这里）。 

认为：

-$p$左侧数字仍然有效，
 -$q$右侧号码仍然有效。 

对于每个活跃号码：

 - 如果继续向上，这个数字可能是$0\ldots9$,
 - 如果它在这里终止，这个数字必须是$1\ldots9$。 

这恰好执行了“无前导零”规则。 

---

 ## 2. 进位方程

 让

 -$S_L$= 此列中左侧数字的总和，
 -$S_R$= 右边数字之和，
 -$c$=传入进位。 

那么我们需要$$S_L - S_R + c = 10c'$$对于一些外出携带$c'$。 

因此，整个问题变成了一个有限状态动态程序：$$(p,q,c)$$在哪里：

-$p,q$随着数字终止而减少，
 -$c$是小数进位。 

---

 ## 3.长度核算

 如果一个数字有$d$数字，它贡献：

 -$d$数字字符，
 - 以及一个分隔符的总体贡献。 

对于方程$m=p+q$总数：

 - 有$m-2$加号，
 - 一个等号，

 所以分隔符计数是$$m-1.$$因此总长度是$$(\text{total digits}) + (m-1).$$DP 单独跟踪数字列，我们在初始化时添加分隔符贡献。 

---

 ## 4. 转换计数

 假设其中$p$活跃左号码：

 -$p'$继续，
-$p-p'$在此终止。 

同样对于右侧：

 -$q'$继续，
-$q-q'$终止。 

数字生成组是：

 - 连续数字：数字$0\ldots9$,
 - 终止号码：数字$1\ldots9$。 

我们计算产生给定列差异的所有数字分配$$S_L-S_R.$$然后进位条件唯一地确定下一个进位。 

因为总长度只有$50$，状态空间足够小，足以进行记忆递归。 

---

 # Python 实现```
from functools import lru_cache
from collections import defaultdict
from math import comb

MOD = 10**9 + 7
N = 50
MAX_TERMS = 25   # worst case: 1-digit numbers separated by symbols

# ------------------------------------------------------------
# dist(p, pp)
#
# p  = active numbers
# pp = numbers that continue upward
#
# Returns:
#   dictionary {digit_sum : count}
#
# Continuing numbers contribute digits 0..9.
# Terminating numbers contribute digits 1..9.
# ------------------------------------------------------------

@lru_cache(None)
def dist(p, pp):

    ways = {0: 1}

    # continuing numbers
    for _ in range(pp):
        nxt = defaultdict(int)
        for s, v in ways.items():
            for d in range(10):
                nxt[s + d] += v
        ways = nxt

    # terminating numbers
    for _ in range(p - pp):
        nxt = defaultdict(int)
        for s, v in ways.items():
            for d in range(1, 10):
                nxt[s + d] += v
        ways = nxt

    # choose which numbers continue
    choose = comb(p, pp)

    return {k: v * choose for k, v in ways.items()}

# ------------------------------------------------------------
# trans(p, q, pp, qq)
#
# Returns all possible values of:
#
#   (left digit sum) - (right digit sum)
#
# together with their multiplicities.
# ------------------------------------------------------------

@lru_cache(None)
def trans(p, q, pp, qq):

    A = dist(p, pp)
    B = dist(q, qq)

    out = defaultdict(int)

    for a, va in A.items():
        for b, vb in B.items():
            out[a - b] += va * vb

    return list(out.items())

# ------------------------------------------------------------
# F(rem, p, q, carry)
#
# rem   = remaining digit-character budget
# p,q   = active numbers on each side
# carry = incoming carry
#
# Returns number of ways.
# ------------------------------------------------------------

@lru_cache(None)
def F(rem, p, q, carry):

    # success state
    if rem == 0:
        return 1 if p == 0 and q == 0 and carry == 0 else 0

    # impossible
    if p == 0 and q == 0:
        return 0

    column_cost = p + q

    if column_cost > rem:
        return 0

    ans = 0

    # choose survivors
    for pp in range(p + 1):
        for qq in range(q + 1):

            for diff, cnt in trans(p, q, pp, qq):

                t = diff + carry

                # must be divisible by 10
                if t % 10 != 0:
                    continue

                next_carry = t // 10

                ans += (
                    cnt *
                    F(rem - column_cost, pp, qq, next_carry)
                )

    return ans % MOD

# ------------------------------------------------------------
# Build A(n)
# ------------------------------------------------------------

exact = [0] * (N + 1)

for total_len in range(N + 1):

    value = 0

    # p left terms, q right terms
    for p in range(1, MAX_TERMS + 1):
        for q in range(1, MAX_TERMS + 1):

            separator_cost = p + q - 1

            if separator_cost > total_len:
                break

            digit_budget = total_len - separator_cost

            value += F(digit_budget, p, q, 0)

    exact[total_len] = value % MOD

# cumulative A(n)
A = [0] * (N + 1)

running = 0
for i in range(N + 1):
    running = (running + exact[i]) % MOD
    A[i] = running

print(A[3])   # 9
print(A[5])   # 171
print(A[7])   # 4878
print(A[50])
```---

 # 代码演练

 ##`dist(p, pp)`计算单个小数列中一侧的所有可能的数字总和。 

例子：

-$p=3$,
 -$pp=1$,

 意思是：

 - 1 个号码继续，
 - 2 个数字在此终止。 

所以数字是：

 - 一位数来自$0..9$,
 - 两位数来自$1..9$。 

我们计算每一个可能的总数字和。 

---

 ##`trans(...)`组合左右数字分布。 

如果留下贡献总和$a$和权利贡献总和$b$，该列贡献：$$a-b.$$我们存储多样性。 

---

 ##`F(rem,p,q,carry)`核心记忆DP。 

状态含义：

 -`rem`剩余数字字符预算，
 -`p,q`活跃号码，
 -`carry`小数进位。 

每一步：

 1. 选择继续的数字，
 2. 枚举所有列差异，
 3. 强制整除性$10$,
 4.递归。
