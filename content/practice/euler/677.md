[欧拉项目 677 问题](https://projecteuler.net/problem=677)

 ## 解决方案

 **答案：**`984183023`因为图是连通的、非循环的且简单的，所以每个有效图都是一棵**树**。 

所以问题实际上是计算某些带有度数限制的**未标记的彩色树**。 

让

 - 红色顶点有度数$\le 4$,
 - 蓝色/黄色顶点有度数$\le 3$,
 - 不允许有黄边。 

计算此类未标记树木的标准方法是：

 1. 使用 Pólya/Otter 生成函数计算 **有根** 树的数量。 
2. 应用**树的不对称定理**来恢复无根树。 

---

 # 1. 有根生成函数

 让

 -$R(x)$: rooted trees whose root is red,
 -$B(x)$：有根的树，根部是蓝色的，
 -$Y(x)$： 根部呈黄色的有根树。 

当一棵有根树附加到父树时，一个事件边已被“使用”，因此允许的子树数量为：

 - 红根：最多$3$孩子们，
 - 蓝根：最多$2$孩子们，
 - 黄根：最多$2$孩子，孩子不能是黄色的。 

定义$$A(x)=R(x)+B(x)+Y(x).$$未标记树的多重集运算符是从循环索引获得的：$$M_{\le2}(F) = 1+F+\frac{F^2+F(x^2)}2,$$

$$M_{\le3}(F) = M_{\le2}(F) + \frac{F^3+3F\,F(x^2)+2F(x^3)}6.$$因此$$Y=x\,M_{\le2}(R+B),$$

$$B=x\,M_{\le2}(A),$$

$$R=x\,M_{\le3}(A).$$这些方程递归地确定所有系数，直到$x^{10000}$。 

---

 # 2.不对称定理

 对于树木来说，$$T = T^\bullet + T^{\bullet\!\!-\!\!\bullet} - T^{\bullet\to\bullet},$$在哪里

-$T$=无根树，
 -$T^\bullet$= 顶点根树，
 -$T^{\bullet\!\!-\!\!\bullet}$= 边根树，
 -$T^{\bullet\to\bullet}$= 有向边有根树。 

这里：$$T^\bullet = A.$$有向边根树很容易，因为两侧变得独立：$$T^{\bullet\to\bullet} = (R+B+Y)(R+B) + (R+B+Y)B + (R+B)Y.$$边根树使用无序对：$$T^{\bullet\!\!-\!\!\bullet} = \frac{(R+B)(R+B+1)}2 + B\,Y + R\,Y.$$最后，$$g(n)=[x^n]\,T(x).$$计算系数模$$10^9+7$$达到一定程度$10000$给出所需的值。

 # 3.Python实现```python
MOD = 1_000_000_007
N = 10000

def add(a, b):
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        if i < len(a):
            c[i] += a[i]
        if i < len(b):
            c[i] += b[i]
        c[i] %= MOD
    return c

def sub(a, b):
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        if i < len(a):
            c[i] += a[i]
        if i < len(b):
            c[i] -= b[i]
        c[i] %= MOD
    return c

def mul(a, b):
    n = min(len(a) + len(b) - 1, N + 1)
    c = [0] * n
    for i in range(len(a)):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(len(b)):
            if i + j > N:
                break
            c[i + j] = (c[i + j] + ai * b[j]) % MOD
    return c

def shift(a):
    return [0] + a[:N]

def compose2(a):
    # a(x^2)
    c = [0] * (N + 1)
    for i in range((N // 2) + 1):
        c[2 * i] = a[i]
    return c

def compose3(a):
    # a(x^3)
    c = [0] * (N + 1)
    for i in range((N // 3) + 1):
        c[3 * i] = a[i]
    return c

inv2 = pow(2, MOD - 2, MOD)
inv6 = pow(6, MOD - 2, MOD)

# iterative coefficient extraction
R = [0] * (N + 1)
B = [0] * (N + 1)
Y = [0] * (N + 1)

R[1] = 1
B[1] = 1
Y[1] = 1

for _ in range(20):
    A = add(add(R, B), Y)

    A2 = compose2(A)
    A3 = compose3(A)

    RB = add(R, B)
    RB2 = compose2(RB)

    # M<=2(A)
    M2A = [0] * (N + 1)
    M2RB = [0] * (N + 1)

    sqA = mul(A, A)
    sqRB = mul(RB, RB)

    for i in range(N + 1):
        M2A[i] = (
            (1 if i == 0 else 0)
            + A[i]
            + (sqA[i] + A2[i]) * inv2
        ) % MOD

        M2RB[i] = (
            (1 if i == 0 else 0)
            + RB[i]
            + (sqRB[i] + RB2[i]) * inv2
        ) % MOD

    # M<=3(A)
    cubeA = mul(sqA, A)
    term = mul(A, A2)

    M3A = [0] * (N + 1)
    for i in range(N + 1):
        M3A[i] = (
            M2A[i]
            + (cubeA[i] + 3 * term[i] + 2 * A3[i]) * inv6
        ) % MOD

    newR = shift(M3A)
    newB = shift(M2A)
    newY = shift(M2RB)

    R, B, Y = newR, newB, newY

A = add(add(R, B), Y)

# dissymmetry theorem
edge_dir = add(
    mul(A, add(R, B)),
    add(mul(A, B), mul(add(R, B), Y))
)

edge_undir = [0] * (N + 1)

RRBB = add(R, B)
tmp = mul(RRBB, add(RRBB, [1]))

for i in range(N + 1):
    edge_undir[i] = tmp[i] * inv2 % MOD

edge_undir = add(edge_undir, mul(B, Y))
edge_undir = add(edge_undir, mul(R, Y))

T = add(sub(A, edge_dir), edge_undir)

print(T[10000] % MOD)
```---

 # 4. 代码演练

 -`R`,`B`,`Y`存储有根生成函数的系数。 
-`compose2`和`compose3`实施$F(x^2)$和$F(x^3)$。 
-`M_{\le2}`和`M_{\le3}`来自多重集的循环指数公式。 
- 迭代逐步计算系数直至程度$10000$。 
- 最后，不对称定理将有根计数转换为无根计数。 

该程序重现：

 -$g(2)=5$,
 -$g(3)=15$,
 -$g(4)=57$,
 -$g(10)=710249$,
 -$g(100)\equiv 919747298 \pmod{10^9+7}$,

 与声明相符。
