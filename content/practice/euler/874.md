[欧拉项目问题 874](https://projecteuler.net/problem=874)

 ## 解决方案

 **答案：**`4992775389`让$$p(t)=\text{the }(t+1)\text{th prime},$$所以$$p(0)=2,\quad p(1)=3,\quad \dots$$我们必须计算$$M(7000,p(7000)).$$---

 # 1.数学分析

 我们得到：

 -$k=7000$,
 -$n=p(7000)$。 

自从$p(t)$是$(t+1)$-第一个质数，$$n=p(7000)=\text{7001st prime}=70663.$$还，$$p(6999)=70657.$$我们寻求最大可能的价值$$\sum_{i=1}^n p(a_i)$$受：

 -$0\le a_i<7000$,
 -$\sum a_i\equiv 0\pmod{7000}$。 

---

 ## 步骤 1：从明显的最大值开始

 在不满足整除条件的情况下，最好的选择是$$a_i=6999 \quad \forall i,$$给分$$70663\cdot 70657.$$但后来$$\sum a_i = 70663\cdot 6999.$$自从$6999\equiv -1\pmod{7000}$,$$70663\cdot 6999 \equiv -70663 \equiv 6337 \pmod{7000}.$$因此，我们必须将总和减少等于$6337\pmod{7000}$。 

---

 # 第2步：转换为最小化问题

 定义赤字$$d_i = 6999-a_i.$$然后$d_i\ge 0$， 和$$\sum d_i \equiv 6337 \pmod{7000}.$$分数变为$$\sum p(a_i) = n\,p(6999)-\sum \bigl(p(6999)-p(6999-d_i)\bigr).$$定义惩罚函数$$f(d)=p(6999)-p(6999-d).$$那么最大化分数就相当于最小化$$\sum f(d_i)$$受$$\sum d_i \equiv 6337 \pmod{7000}.$$因为每个素数间隙至少是$2$,$$f(d)\ge 2d.$$添加另一个完整的$7000$赤字将增加罚款至少$14000$，因此最优总赤字是允许的最小赤字：$$\sum d_i = 6337.$$因此我们只需要：

 > 最小化$\sum f(d_i)$受$\sum d_i=6337$。 

---

 # 第 3 步：计算小惩罚

 顶部附近的相关素数是：$$\begin{aligned} p(6999)&=70657,\\ p(6998)&=70639,\\ p(6997)&=70627,\\ p(6996)&=70621,\\ p(6995)&=70619. \end{aligned}$$因此：$$\begin{aligned} f(1)&=18,\\ f(2)&=30,\\ f(3)&=36,\\ f(4)&=38. \end{aligned}$$关键的观察是：$$\frac{f(4)}4=\frac{38}4=9.5$$是每单位赤字的最佳平均成本。 

电脑检查全部$1\le d<7000$显示：$$f(d)\ge \frac{19d}{2},$$只有当$d$是的倍数$4$。 

自从$$6337\equiv 1\pmod 4,$$我们不能只使用$4$'是。 
最好的残渣——$1$选项是$$f(9)=86,$$因为$$86-\frac{19\cdot 9}{2}=0.5$$是所有之中最小的$d\equiv 1\pmod 4$。 

因此最优分解为：$$6337 = 1582\cdot 4 + 9.$$总罚款：$$1582\cdot 38 + 86 = 60116+86 = 60202.$$---

 # 第四步：最终得分

 因此$$M = 70663\cdot 70657 - 60202.$$计算：$$70663\cdot 70657 = 4992835591.$$因此$$M = 4992835591 - 60202 = 4992775389.$$---

 # 2.Python实现```python
# Project Euler 874

def sieve(limit):
    """Return list of all primes <= limit."""
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    p = 2
    while p * p <= limit:
        if is_prime[p]:
            for x in range(p * p, limit + 1, p):
                is_prime[x] = False
        p += 1

    return [i for i, v in enumerate(is_prime) if v]

# We need primes up to around the 7001st prime (~70663)
primes = sieve(80000)

# p(t) = (t+1)th prime
def p(t):
    return primes[t]

k = 7000
n = p(7000)       # 7001st prime
top = p(6999)     # largest allowed prime score term

# Required deficit
D = (-n) % k

# Penalty function
# f(d) = p(6999) - p(6999-d)
f = [0] * (k)

for d in range(1, k):
    f[d] = top - p(6999 - d)

# Unbounded knapsack DP:
# dp[s] = minimum penalty to obtain total deficit s
INF = 10**18
dp = [INF] * (D + 1)
dp[0] = 0

for s in range(1, D + 1):
    best = INF
    for d in range(1, s + 1):
        best = min(best, dp[s - d] + f[d])
    dp[s] = best

penalty = dp[D]

answer = n * top - penalty

print(answer)
```---

 # 3. 代码演练

 ### 黄金一代```python
primes = sieve(80000)
```生成足够的素数，以便包含第 7001 个素数。 

---

 ### 素数索引```python
def p(t):
    return primes[t]
```因为 Python 列表是从 0 索引的，`primes[t]`正是$(t+1)$-th素数。 

---

 ### 所需赤字```python
D = (-n) % k
```由于我们最初设置了所有$a_i=6999$,$$\sum a_i \equiv -n \pmod{k}.$$所以我们必须精确地减去$D$。 

---

 ### 处罚表```python
f[d] = top - p(6999 - d)
```如果我们将索引减少$d$，这是主要分数减少的量。 

---

 ### 动态规划```python
dp[s]
```存储实现总赤字的最低罚款$s$。 

过渡：```python
dp[s] = min(dp[s-d] + f[d])
```因为我们可能会再增加一大块赤字$d$。

 # 5.最终验证

 我们的最优分解：$$6337 = 1582\cdot 4 + 9$$用途：

 - 减少了 1582 个变量$4$,
 - 1 个变量减少$9$,
 - 所有剩余变量不变。 

惩罚：$$1582\cdot 38 + 86 = 60202.$$最终成绩：$$70663\cdot 70657 - 60202 = 4992775389.$$一切都是一致的。

 **答案：4992775389**
