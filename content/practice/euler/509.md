[欧拉项目问题 509](https://projecteuler.net/problem=509)

 ## 解决方案

 **答案：**`151725678`让$g(n)$是一堆大小的 Sprague-Grundy 值$n$。 

移动包括选择合适的除数$d\mid n$,$d<n$，并替换$n$经过$n-d$。 

对于三桩，位置$(a,b,c)$正在失败当且仅当$$g(a)\oplus g(b)\oplus g(c)=0,$$在哪里$\oplus$是按位异或。 

所以整个问题归结为理解$g(n)$。 

---

 # 1.数学分析

 ## 步骤 1：计算 Grundy 值

 让$v_2(n)$表示指数$2$在$n$， IE。$$n = 2^{v_2(n)} \cdot m \quad (m \text{ odd}).$$我们主张：$$g(n)=v_2(n).$$我们证明了这一点。 

---

 ## 步骤 2：动作结构

 假设$$n = 2^k m,\qquad m\text{ odd}.$$每个真除数$d$的$n$可以写成$$d=2^t u,$$在哪里$0\le t\le k$,$u\mid m$。 

新的桩尺寸为$$n-d.$$我们只关心它的 2-adic 估值。 

---

 ### 较小 Grundy 值的可达性

 采取任何$t<k$。 

选择$$d = 2^t m.$$自从$t<k$，这是一个真除数$n$。 

然后$$n-d =2^k m-2^t m =2^t m(2^{k-t}-1).$$因为$2^{k-t}-1$是奇数，$$v_2(n-d)=t.$$所以从一堆估值中$k$，每一个较小的估值$0,1,\dots,k-1$是可达的。 

---

 ### 没有任何举动可以维持估值$k$写$$n=2^k m,\qquad d=2^t u.$$如果$t<k$， 然后$$n-d=2^t(\text{odd}),$$所以估值正好是$t<k$。 

如果$t=k$， 然后$$d=2^k u,$$和$u\mid m$。 自从$u<m$对于一个真除数，$$n-d = 2^k(m-u),$$和$m-u$是偶数（奇数减奇数），因此$$v_2(n-d)\ge k+1.$$所以估值$k$其本身是永远无法到达的。 

因此可达到的 Grundy 值恰好是$$\{0,1,\dots,k-1\}.$$所以$$g(n)=\operatorname{mex}\{0,1,\dots,k-1\}=k.$$因此$$\boxed{g(n)=v_2(n)}.$$---

 # 2. 计算亏损仓位

 定义$$c_k = \#\{1\le x\le n : v_2(x)=k\}.$$这些是可被整除的整数$2^k$但不是由$2^{k+1}$:$$c_k = \left\lfloor \frac{n}{2^k}\right\rfloor - \left\lfloor \frac{n}{2^{k+1}}\right\rfloor.$$三元组正在输 iff$$v_2(a)\oplus v_2(b)\oplus v_2(c)=0.$$所以失败的三元组的数量是$$L = \sum_{i,j\ge0} c_i c_j c_{i\oplus j}.$$所以$$S(n)=n^3-L.$$---

 # 3.Python实现```python
def S(n):
    # c[k] = count of numbers with v2(x) = k
    c = []
    k = 0

    while (1 << k) <= n:
        ck = n // (1 << k) - n // (1 << (k + 1))
        c.append(ck)
        k += 1

    # Count losing triples:
    # v2(a) xor v2(b) xor v2(c) = 0
    losing = 0

    for i, a in enumerate(c):
        for j, b in enumerate(c):
            x = i ^ j
            if x < len(c):
                losing += a * b * c[x]

    return n**3 - losing

# Check the examples
print(S(10))    # 692
print(S(100))   # 735494

# Required value
MOD = 1234567890
n = 123456787654321

print(S(n) % MOD)
```---

 # 4. 代码演练

 ### 建立计数```python
ck = n // (1 << k) - n // (1 << (k + 1))
```以精确的 2-adic 估值计算整数$k$。 

示例：

 - 可除以$2^k$- 但不是由$2^{k+1}$---

 ### 计算输掉的三元组

 如果$$i \oplus j \oplus k = 0,$$然后$$k=i\oplus j.$$所以对于每一对$(i,j)$，所需的第三次估值是唯一确定的。 

这些估值的三倍数的数量是$$c_i c_j c_{i\oplus j}.$$求和得出所有亏损头寸。 

---

 ###最终结果

 所有三元组：$$n^3.$$获胜三连胜：$$S(n)=n^3-L.$$---
