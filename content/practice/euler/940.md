[项目欧拉问题 940](https://projecteuler.net/problem=940)

 ## 解决方案

 **答案：**`969134784`让$$A(m,n)=\alpha\, r_1^m s_1^n+\beta\, r_2^m s_2^n$$其中递归决定了常数和基数。 

从$$A(m+1,n)=A(m,n+1)+A(m,n)$$我们得到$$r=s+1.$$从$$A(m+1,n+1)=2A(m+1,n)+A(m,n)$$我们得到$$rs=2r+1.$$替代$r=s+1$:$$s(s+1)=2(s+1)+1$$

$$s^2-s-3=0.$$因此$$s_{1,2}=\frac{1\pm\sqrt{13}}2, \qquad r_{1,2}=1+s_{1,2}=\frac{3\pm\sqrt{13}}2.$$使用$A(0,0)=0$和$A(0,1)=1$,$$A(m,n)=\frac{r_1^m s_1^n-r_2^m s_2^n}{\sqrt{13}}.$$所以$$S(k) = \sum_{i=2}^k\sum_{j=2}^k A(f_i,f_j) = \frac{ \left(\sum r_1^{f_i}\right)\left(\sum s_1^{f_j}\right) - \left(\sum r_2^{f_i}\right)\left(\sum s_2^{f_j}\right) }{\sqrt{13}}.$$我们计算所有内容的模数$$M=1123581313$$二次环内$\mathbb Z_M[\sqrt{13}]$，将数字表示为对$$a+b\sqrt{13}.$$共轭减法正好留下系数$\sqrt{13}$。 

Python代码：```python
MOD = 1123581313

# arithmetic in Z_MOD[sqrt(13)]
def add(x, y):
    return ((x[0] + y[0]) % MOD,
            (x[1] + y[1]) % MOD)

def mul(x, y):
    a, b = x
    c, d = y
    return ((a * c + 13 * b * d) % MOD,
            (a * d + b * c) % MOD)

def power(x, n):
    r = (1, 0)
    while n:
        if n & 1:
            r = mul(r, x)
        x = mul(x, x)
        n >>= 1
    return r

inv2 = pow(2, -1, MOD)

# s1 = (1 + sqrt(13))/2
# r1 = (3 + sqrt(13))/2
s1 = ((1 * inv2) % MOD, inv2)
r1 = ((3 * inv2) % MOD, inv2)

# Fibonacci numbers
fib = [0, 1]
for _ in range(2, 51):
    fib.append(fib[-1] + fib[-2])

T = (0, 0)
U = (0, 0)

for i in range(2, 51):
    T = add(T, power(r1, fib[i]))
    U = add(U, power(s1, fib[i]))

E = mul(T, U)

# If E = a + b*sqrt(13),
# then (E - conjugate(E))/sqrt(13) = 2b
answer = (2 * E[1]) % MOD

print(answer)
```验证：
