[欧拉项目 868 问题](https://projecteuler.net/problem=868)

 ## 解决方案

 **答案：**`3832914911887589`该问题是铃声规则生成的排列顺序的排序问题。 关键是要认识到该过程正是 **Steinhaus-Johnson-Trotter (SJT)** 排列顺序（也称为“简单更改”）。 

我们被要求提供从最初的字母顺序达到给定排列所需的交换次数。 由于每一步都执行**恰好一个相邻交换**，因此交换数量等于 SJT 排序中目标排列的**基于 0 的索引**。 

---

 ## 1.数学分析

 让$R(P)$是达到排列所需的交换次数$P$。 

我们想要：$$R(\texttt{NOWPICKBELFRYMATHS})$$按字母顺序从字母开始。 

### SJT阶的递归结构

 假设我们有$n$字母，并让最大的字母是$L$。 

SJT 一代$n$字母是根据以下顺序递归构建的$n-1$字母：

 - 取较小的每个排列$n-1$字母。 
- 插入$L$到所有可能的位置。 
- 插入方向交替：

 如果较小的排列具有**偶数索引**，则移动$L$从**右到左**。 

如果较小的排列具有**奇数索引**，则移动$L$从**左到右**。 

示例$ABC$:

 从排列$AB$:

 -$AB$（索引 0，偶数）：插入$C$右→左$$ABC,\ ACB,\ CAB$$-$BA$（索引 1，奇数）：插入$C$左→右$$CBA,\ BCA,\ BAC$$与问题陈述中完全相同。 

---

 ### 推导递归式

 让：

 -$n$= 字母数
 -$L$= 最大的字母
 -$p$= 的位置$L$（0-从左侧开始索引）
 -$r$= 移除后排列的等级$L$然后：

 - 如果$r$是**偶数**，$L$向右→向左移动，因此块偏移量为$$(n-1)-p$$- 如果$r$是**奇怪**，$L$向左→向右移动，因此块偏移量为$$p$$因此：$$R(P)=n\cdot r + b$$在哪里$$b= \begin{cases} (n-1)-p & \text{if } r \text{ even}\\[4pt] p & \text{if } r \text{ odd} \end{cases}$$这给出了一个$O(n^2)$递归排序算法。

 ## 2.Python实现```python
def sjt_rank(word):
    """
    Return the 0-based index of `word`
    in Steinhaus-Johnson-Trotter order.
    """

    def rank_recursive(letters):
        n = len(letters)

        # Base case
        if n <= 1:
            return 0

        # Largest letter
        largest = max(letters)

        # Position of largest letter
        pos = letters.index(largest)

        # Remove largest letter
        reduced = [x for x in letters if x != largest]

        # Rank of reduced permutation
        r = rank_recursive(reduced)

        # Offset within this block
        if r % 2 == 0:
            offset = (n - 1) - pos
        else:
            offset = pos

        return n * r + offset

    return rank_recursive(list(word))

# Verify examples
print(sjt_rank("CBA"))      # 3
print(sjt_rank("BELFRY"))   # 59

# Compute Project Euler answer
target = "NOWPICKBELFRYMATHS"
print(sjt_rank(target))
```---

 ## 3. 代码演练

 ### 基本情况```python
if n <= 1:
    return 0
```单个字母不需要交换。 

---

 ### 找到最大的字母```python
largest = max(letters)
pos = letters.index(largest)
```SJT递归取决于当前最大字母的位置。 

---

 ### 减少问题```python
reduced = [x for x in letters if x != largest]
r = rank_recursive(reduced)
```删除最大的字母并递归计算剩余排列的排名。 

---

 ### 确定移动方向```python
if r % 2 == 0:
    offset = (n - 1) - pos
else:
    offset = pos
```甚至子排名 → 最大的字母也从右→左扫过。 

奇数子排名→最大字母向左→向右扫。 

---

 ### 结合块号和偏移量```python
return n * r + offset
```每个递归块恰好包含$n$排列。
