[欧拉计划问题 170](https://projecteuler.net/problem=170)

 ## 解决方案

 **答案：**`9857164023`令整数乘数为$m$，并令其他整数为$a_1,a_2,\dots,a_k$和$k\ge2$。 

我们要求：

 1. 输入的串联$$m\,a_1\,a_2\cdots a_k$$是一个$0$-到-$9$泛数字 10 位数字。 
2. 产品的串联$$(m a_1)(m a_2)\cdots(m a_k)$$也是一个$0$-到-$9$泛数字 10 位数字。 

我们寻求**最大**可能的级联产品。 

---

 # 数学分析

 我们想要通过连接乘积形成字典顺序最大的 10 位泛数字。 

因为结果是使用数字的泛数字$0$–$9$恰好一次，理想情况下第一个数字应该尽可能大$9$。 

蛮力搜索空间看似巨大，但一些结构观察大大减少了它。 

---

 ## 1. 级联积的结构

 假设：$$P = \text{concat}(m a_1, m a_2,\dots,m a_k)$$是目标泛数字。 

由于所有数字$0$–$9$恰好出现一次$P$，总位数正好是 10。 

同样，$$I = \text{concat}(m,a_1,\dots,a_k)$$也必须是 10 位泛数字。 

因此，每个数字$0$到$9$在输入中只出现一次。 

---

 ## 2. 关键观察：划分数字

 如果我们选择数字的排列$0$–$9$，我们可以将其分成几部分：$$m,\ a_1,\ a_2,\dots,a_k$$然后计算：$$m a_1,\ m a_2,\dots,m a_k$$并测试它们的串联是否是另一种泛数字排列。 

这建议搜索：

 - 数字的排列，
 - 划分为块。 

但$10! = 3,628,800$，所以我们需要修剪。 

---

 ## 3. 最大化输出

 连接的乘积按数字进行比较，因此按字典顺序进行比较。 

因此：

 - 我们应该按降序生成候选输出，
 - 停在第一个有效的位置。 

与其先生成输入，不如按降序生成 _output_ 排列要聪明得多。 

---

 ## 4. 重构乘法器

 假设串联产品是：$$P = p_1p_2\dots p_{10}$$我们分区$P$分成块：$$b_1,b_2,\dots,b_k$$其中每个$b_i = m a_i$。 

然后$m$必须划分每个块。 

因此：$$m = \gcd(b_1,b_2,\dots,b_k)$$或者至少是该 gcd 的除数。 

这变得高度限制。 

---

 ## 5.高效的搜索策略

 我们按如下方式进行：

 1. 按降序枚举 10 位泛数字。 
2. 尝试将每个分区至少分成两个块。 
3. 计算块的gcd。 
4. 枚举除数$m>1$那个gcd。 
5. 恢复：$$a_i = b_i/m$$6. 检查是否串联$$m,a_1,\dots,a_k$$产生 0-9 的泛数字字符串。 

找到的第一个有效输出是最大值。 

---

 # Python 实现```python
from math import gcd
from itertools import permutations

DIGITS = "9876543210"

def is_pandigital_0_9(s):
    """Check whether s contains digits 0-9 exactly once."""
    return len(s) == 10 and set(s) == set("0123456789")

def divisors(n):
    """Return all divisors of n greater than 1."""
    ds = set()
    d = 2
    while d * d <= n:
        if n % d == 0:
            ds.add(d)
            ds.add(n // d)
        d += 1
    ds.add(n)
    return sorted(ds, reverse=True)

# Generate pandigital outputs in descending order
for perm in permutations(DIGITS):
    s = ''.join(perm)

    # Try all ways to partition into >=2 pieces
    # There are 2^9 possible cut patterns
    for mask in range(1, 1 << 9):

        parts = []
        start = 0

        for i in range(9):
            if mask & (1 << i):
                parts.append(int(s[start:i+1]))
                start = i + 1

        parts.append(int(s[start:]))

        # Need at least two multiplicands
        if len(parts) < 2:
            continue

        # Compute gcd of all chunks
        g = parts[0]
        for x in parts[1:]:
            g = gcd(g, x)

        if g <= 1:
            continue

        # Try divisors of gcd as multiplier
        for m in divisors(g):

            inputs = []
            ok = True

            for x in parts:
                if x % m != 0:
                    ok = False
                    break
                inputs.append(str(x // m))

            if not ok:
                continue

            candidate = str(m) + ''.join(inputs)

            if is_pandigital_0_9(candidate):
                print(s)
                raise SystemExit
```---
