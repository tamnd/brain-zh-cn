[欧拉项目问题 52](https://projecteuler.net/problem=52)

 ## 解决方案

 **答案：**`142857`我们寻求最小的正整数$x$这样$$2x,\;3x,\;4x,\;5x,\;6x$$全部包含完全相同的数字$x$，只是排列。 

具有此属性的数字有时称为_排列倍数_。 

---

 # 数学分析

 关键条件是：$$\text{digits}(x)=\text{digits}(2x)=\cdots=\text{digits}(6x)$$其中“digits”表示多组十进制数字。 

测试两个数字是否包含相同数字的自然方法是：

 - 转换为字符串，
 - 对数字进行排序，
 - 比较排序后的字符串。 

例如：$$125874 \to "125874" \to "124578"$$

$$251748 \to "251748" \to "124578"$$所以它们匹配。 

---

 ## 重要观察：相同的数字位数

 如果$x$有$d$数字，那么$6x$还必须有$d$数字。 

认为$x$有$d$数字。 然后$$10^{d-1} \le x < 10^d$$为了$6x$也有$d$数字：$$6x < 10^d$$所以$$x < \frac{10^d}{6}$$这大大缩小了搜索范围。 

例如，6位数字中：$$100000 \le x < \frac{1000000}{6} \approx 166666$$所以只需要检查一小部分。 

---

 ## 算法

 对于每个正整数$x$:

 1. 计算其数字的规范表示：$$s(x)=\text{sorted digits of }x$$2. 检查是否$$s(x)=s(2x)=s(3x)=s(4x)=s(5x)=s(6x)$$3.第一个这样的$x$就是答案。 

这种强力搜索非常有效，因为解决方案出现得相当早。 

---

 # Python 实现```python
def signature(n):
    """
    Return a canonical representation of the digits of n.
    Numbers with the same digits will have the same signature.
    """
    return ''.join(sorted(str(n)))

x = 1

while True:
    # Compute the digit signature of x
    sig = signature(x)

    # Check whether 2x through 6x have identical digit signatures
    if all(signature(k * x) == sig for k in range(2, 7)):
        print(x)
        break

    x += 1
```---

 ## 功能：`signature`

```python
def signature(n):
    return ''.join(sorted(str(n)))
```这会将数字转换为字符串，对其数字进行排序，然后将它们重新连接在一起。 

例子：```python
signature(125874)
```-`str(125874)`→`"125874"`-`sorted(...)`→`['1','2','4','5','7','8']`-`join(...)`→`"124578"`同样地：```python

```还生产`"124578"`。 

因此，这两个数字包含完全相同的数字。
