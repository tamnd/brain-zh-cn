[欧拉计划问题 105](https://projecteuler.net/problem=105)

 ## 解决方案

 **答案：**`73702`放一套$A$逐渐排序：$$a_1 < a_2 < \cdots < a_n$$我们必须测试它是否是一个**特殊和集**，意思是：

 1. 没有两个不同的非空子集具有相等的和。 
2. 如果一个子集的元素多于另一个子集，则其总和必须更大。 

输入文件包含 100 个候选集，每个候选集包含$7$–$12$元素。 我们必须识别所有有效的特殊和集并对它们的总和进行求和。 

---

 # 数学分析

 ## 性质 2：快速必要和充分检查

 假设该集合已排序。 

如果最小的$k$元素**不**超过最大的$k-1$元素，那么我们可以形成：

 - 一个$k$-总和较小的元素子集，
 - 一个$(k-1)$- 总和较大的元素子集，

 违反条件（2）。 

因此我们要求：$$a_1 + a_2 + \cdots + a_k > a_n + a_{n-1} + \cdots + a_{n-k+2}$$对于每一个$k = 2,3,\dots,\lfloor n/2 \rfloor +1$。 

这已经足够了，因为：

 - 尽可能最小的$k$-子集是第一个$k$元素，
 - 最大可能$(k-1)$-子集是最后一个$k-1$元素。 

因此，如果即使是最小的较大子集也击败了最大的较小子集，则条件（2）始终成立。 

---

 ## 属性 1：子集和的唯一性

 我们必须确保：$$S(B) \ne S(C)$$对于所有不同的非空子集$B,C$。 

蛮力方法之所以有效，是因为集合很小（$n \le 12$）。 

最多有：$$2^{12}=4096$$子集。 

对于每个子集：

 - 计算其总和，
 - 将其存储在一个集合中，
 - 如果总和已经出现，则性质 (1) 失败。 

这在计算上是微不足道的。

 # Python 实现```python
from itertools import combinations
import urllib.request

URL = "https://projecteuler.net/resources/documents/0105_sets.txt"

# Download the file
data = urllib.request.urlopen(URL).read().decode()

sets_list = [
    list(map(int, line.split(",")))
    for line in data.strip().splitlines()
]

def satisfies_rule_2(nums):
    """
    Check:
    if |B| > |C| then S(B) > S(C)

    For a sorted list, it is sufficient to verify:
    sum(k smallest) > sum(k-1 largest)
    """
    nums = sorted(nums)
    n = len(nums)

    for k in range(2, n // 2 + 2):
        if sum(nums[:k]) <= sum(nums[-(k - 1):]):
            return False

    return True

def satisfies_rule_1(nums):
    """
    Check that all subset sums are unique.
    """
    n = len(nums)
    seen = set()

    # Enumerate all non-empty subsets
    for mask in range(1, 1 << n):
        subset_sum = 0

        for i in range(n):
            if mask & (1 << i):
                subset_sum += nums[i]

        if subset_sum in seen:
            return False

        seen.add(subset_sum)

    return True

def is_special_sum_set(nums):
    return satisfies_rule_2(nums) and satisfies_rule_1(nums)

answer = 0

for s in sets_list:
    if is_special_sum_set(s):
        answer += sum(s)

print(answer)
```---
