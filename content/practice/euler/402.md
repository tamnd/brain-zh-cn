[项目欧拉问题 402](https://projecteuler.net/problem=402)

 ## 解决方案

 **答案：**`356019862`让$$P(n)=n^4+an^3+bn^2+cn.$$我们求最大的整数$m$这样$P(n)\equiv 0\pmod m$对于**所有**整数$n$。 

---

 # 1.数学分析

 ## 步骤 1：表征$M(a,b,c)$关于整数值多项式的标准事实是：

 > 多项式在整数上的所有值的 gcd 等于其前向差分的 gcd$0$。 

计算前向差异$P(n)$：$$\Delta P(0)=1+a+b+c,$$

$$\Delta^2 P(0)=14+6a+2b,$$

$$\Delta^3 P(0)=36+6a,$$

$$\Delta^4 P(0)=24.$$所以$$M(a,b,c)=\gcd(1+a+b+c,\ 14+6a+2b,\ 36+6a,\ 24).$$所以$M(a,b,c)$总是分裂$24$。 

因此$M$仅取决于$a,b,c \pmod{24}$。 

---

 ## 步骤 2：周期性$M$因为只有模余数$24$事情，$$M(a+24,b,c)=M(a,b,c)$$（同样对于$b,c$）。 

因此$S(N)$是一个具有周期的三次拟多项式$24$。 

写$$N=24q+r,\qquad 0\le r<24.$$对于每个残留类别$t\in\{1,\dots,24\}$, 整数个数$\le N$一致于$t\pmod{24}$是$q$或者$q+1$。 

对残基类求和得出$$S(N)=Aq^3+B_r q^2+C_r q+D_r,$$其中常数由下式确定$24^3$残留物立方体。 

全期总计为$$A=\sum_{1\le a,b,c\le 24} M(a,b,c)=27984.$$这将重现检查：$$S(10)=1972,$$

$$S(10000)=2024258331114.$$---

 ## 步骤 3：斐波那契输入

 我们需要$$\sum_{k=2}^{1234567890123} S(F_k)\pmod{10^9}.$$由于斐波那契数模$24$有皮萨诺时期$24$,$$F_{k+24}\equiv F_k\pmod{24},$$系数$B_r,C_r,D_r$重复句号$24$。 

因此$S(F_k)$变为线性组合$$1,\quad F_k,\quad F_k^2,\quad F_k^3$$系数周期模$24$。 

这些序列满足线性递推，因此整个序列可以用矩阵求幂来计算：$O(\log n)$。

 # 2.Python实现```python
from math import gcd
import numpy as np

MOD = 10**9
BIGMOD = 288 * MOD

# ------------------------------------------------------------
# Compute M(a,b,c)
# ------------------------------------------------------------

def M(a, b, c):
    return gcd(
        gcd(
            gcd(1 + a + b + c,
                14 + 6*a + 2*b),
            36 + 6*a),
        24
    )

# ------------------------------------------------------------
# Precompute the 24x24x24 residue cube
# ------------------------------------------------------------

cube = np.zeros((25, 25, 25), dtype=object)

for a in range(1, 25):
    for b in range(1, 25):
        for c in range(1, 25):
            cube[a, b, c] = M(a, b, c)

# 3D prefix sums
pref = cube.cumsum(0).cumsum(1).cumsum(2)

# ------------------------------------------------------------
# S(N)
# ------------------------------------------------------------

def S(N):
    q, r = divmod(N, 24)

    return (
        q**3 * pref[24,24,24]
        + q*q * (
            pref[r,24,24]
            + pref[24,r,24]
            + pref[24,24,r]
        )
        + q * (
            pref[r,r,24]
            + pref[r,24,r]
            + pref[24,r,r]
        )
        + pref[r,r,r]
    )

# ------------------------------------------------------------
# Verify examples
# ------------------------------------------------------------

assert S(10) == 1972
assert S(10000) == 2024258331114

# ------------------------------------------------------------
# Fibonacci residues mod 24
# ------------------------------------------------------------

fib24 = [0, 1]
for _ in range(22):
    fib24.append((fib24[-1] + fib24[-2]) % 24)

# ------------------------------------------------------------
# Build polynomial coefficients
# We work with 288*S(F_n) to avoid fractions.
# ------------------------------------------------------------

import sympy as sp

q = sp.Symbol('q')
x = sp.Symbol('x')

# Recover cubic polynomials for each residue
poly_by_r = {}

for r in range(24):
    vals = [S(24*k + r) for k in range(4)]
    poly = sp.interpolate(
        [(k, vals[k]) for k in range(4)],
        q
    )
    poly_by_r[r] = sp.expand(poly)

coeffs = []

for r in range(24):
    expr = sp.expand(
        288 * poly_by_r[r].subs(q, (x-r)/24)
    )
    P = sp.Poly(expr, x)

    # const, x, x^2, x^3
    coeffs.append([
        int(P.nth(0)),
        int(P.nth(1)),
        int(P.nth(2)),
        int(P.nth(3)),
    ])

# ------------------------------------------------------------
# State vector:
#
# [F_n^3,
#  F_n^2 F_{n+1},
#  F_n F_{n+1}^2,
#  F_{n+1}^3,
#  F_n^2,
#  F_n F_{n+1},
#  F_{n+1}^2,
#  F_n,
#  F_{n+1},
#  1,
#  accumulated_sum]
# ------------------------------------------------------------

mons = [
    (3,0),(2,1),(1,2),(0,3),
    (2,0),(1,1),(0,2),
    (1,0),(0,1),(0,0)
]

idx = {m:i for i,m in enumerate(mons)}

T = np.zeros((10,10), dtype=object)

# Fibonacci transition:
# (x,y) -> (y, x+y)

from math import comb

for j, (a,b) in enumerate(mons):
    for k in range(b+1):
        coef = comb(b, k)
        mon = (k, a+b-k)
        i = idx[mon]
        T[i,j] += coef

# ------------------------------------------------------------
# Phase-dependent matrices
# ------------------------------------------------------------

def make_matrix(t):
    A = np.zeros((11,11), dtype=object)

    A[:10,:10] = T
    A[10,10] = 1

    c = coeffs[(t+1) % 24]

    # depends only on F_{n+1}
    A[10,3] = c[3]
    A[10,6] = c[2]
    A[10,8] = c[1]
    A[10,9] = c[0]

    return A % BIGMOD

phase = [make_matrix(t) for t in range(24)]

# ------------------------------------------------------------
# Multiply matrices
# ------------------------------------------------------------

def matmul(A, B):
    return (A.dot(B)) % BIGMOD

# 24-step block
B = np.identity(11, dtype=object)

for t in range(24):
    B = matmul(phase[t], B)

# ------------------------------------------------------------
# Fast exponentiation
# ------------------------------------------------------------

def mpow(M, n):
    R = np.identity(11, dtype=object)

    while n:
        if n & 1:
            R = matmul(M, R)

        M = matmul(M, M)
        n >>= 1

    return R

# ------------------------------------------------------------
# Initial state at n=0
# ------------------------------------------------------------

state0 = np.array([
    0,0,0,1,
    0,0,1,
    0,1,
    1,
    0
], dtype=object)

K = 1234567890123

blocks, rem = divmod(K, 24)

state = mpow(B, blocks).dot(state0) % BIGMOD

for t in range(rem):
    state = phase[t].dot(state) % BIGMOD

# state[10] = 288 * sum_{k=1}^K S(F_k)

answer = ((state[10] // 288) - 2) % MOD

print(answer)

 # 3. 代码演练

 ### 计算$M(a,b,c)$我们使用有限差分表征：```python
gcd(1+a+b+c,
    14+6a+2b,
    36+6a,
    24)
```这立即意味着周期性模$24$。 

---

 ### 计算$S(N)$自从$M$仅取决于残基模$24$，我们预先计算整个$24^3$立方体一次。 

那么对于$$N=24q+r,$$我们计算每个残基出现的次数。 

这将整个问题简化为评估三次拟多项式。 

---

 ### 斐波那契加速

 依赖于$F_k$是三次方，所以我们跟踪所有单项式的次数$3$：$$F_k^3,\quad F_k^2F_{k+1},\quad \dots$$斐波那契转变$$(F_k,F_{k+1})\to(F_{k+1},F_k+F_{k+1})$$对这些单项式进行线性变换。 

然后我们使用快速矩阵求幂直接跳转到$$k=1234567890123.$$---

 # 4.最终验证

 该程序准确地重现给定的检查：$$S(10)=1972,$$

$$S(10000)=2024258331114.$$最终计算是模数完成的$10^9$，结果是有效的 9 位余数。
