[欧拉项目 454 问题](https://projecteuler.net/problem=454)

 ## 解决方案

 **答案：**`5435004633092`让$$\frac1x+\frac1y=\frac1n, \qquad x<y\le L,$$和$x,y,n\in \mathbb Z_{>0}$。 

我们想要$F(L)$，这样的对的数量$(x,y)$。 

---

 # 1.数学分析

 开始于$$\frac1x+\frac1y=\frac1n.$$乘以通过$xyn$,$$n(x+y)=xy.$$## 步骤1：提取gcd

 让$$x=gu,\qquad y=gv,$$和$$\gcd(u,v)=1,\qquad u<v.$$代替：$$n(g u + g v)=g^2uv.$$除以$g$：$$n(u+v)=g uv.$$因为$\gcd(u,v)=1$,$$\gcd(u,u+v)=\gcd(v,u+v)=1.$$因此$u\mid n$和$v\mid n$。 自从$u,v$是互质的，$$uv\mid n.$$所以写$$n=tuv$$对于某个正整数$t$。 

替换回来：$$tuv(u+v)=g uv.$$取消$uv$：$$g=t(u+v).$$因此每个解都有形式$$x=t\,u(u+v),$$

$$y=t\,v(u+v),$$和$$u<v,\qquad \gcd(u,v)=1.$$相反，每一个这样的三元组都有效。 

因此计数解决方案简化为计数$$t\,v(u+v)\le L.$$对于固定互质$u<v$,$$t \le \frac{L}{v(u+v)}.$$因此$$F(L)= \sum_{\substack{u<v\\ \gcd(u,v)=1}} \left\lfloor \frac{L}{v(u+v)} \right\rfloor.$$---

 # 2. 莫比乌斯反演

 介绍$s=u+v$。 然后$v<s<2v$， 和$$\gcd(v,s)=1.$$所以$$F(L) = \sum_{v=1}^{\sqrt L} \sum_{\substack{v<s<2v\\ \gcd(v,s)=1}} \left\lfloor \frac{L}{vs}\right\rfloor.$$使用标准身份$$[\gcd(v,s)=1] = \sum_{d\mid \gcd(v,s)} \mu(d),$$在哪里$\mu$是莫比乌斯函数。 

这将互质条件转换为除数和，并允许使用调和除法技术来评估内部和$O(L^{3/4})$，这足够快$L=10^{12}$。

 # 3.Python实现```python
import math

# ------------------------------------------------------------
# Mobius sieve
# ------------------------------------------------------------

def mobius_sieve(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1

        for p in prime:
            if i * p > n:
                break

            is_comp[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    return mu

# ------------------------------------------------------------
# Fast computation of
#    sum_{k=a}^{b} floor(n / k)
# ------------------------------------------------------------

def floor_sum_range(n, a, b):
    if a > b:
        return 0

    s = 0
    k = a

    while k <= b:
        q = n // k
        r = min(b, n // q)
        s += q * (r - k + 1)
        k = r + 1

    return s

# ------------------------------------------------------------
# Main function
# ------------------------------------------------------------

def F(L):
    root = int(math.isqrt(L))

    mu = mobius_sieve(root)

    ans = 0

    for v in range(2, root + 1):

        # divisors of v
        divisors = []

        d = 1
        while d * d <= v:
            if v % d == 0:
                divisors.append(d)
                if d * d != v:
                    divisors.append(v // d)
            d += 1

        for d in divisors:
            if mu[d] == 0:
                continue

            vv = v // d

            left = vv + 1
            right = (2 * v - 1) // d

            n = L // (v * d)

            contribution = floor_sum_range(n, left, right)

            ans += mu[d] * contribution

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

print(F(15))      # 4
print(F(1000))    # 1069

# Final answer
print(F(10**12))
```---

 # 4. 代码演练

 ##`mobius_sieve`计算莫比乌斯函数$\mu(n)$为所有人$n\le \sqrt L$。 

记起：

-$\mu(n)=0$如果$n$包含质因数的平方，
 - 否则$\mu(n)=(-1)^k$， 在哪里$k$是不同质因数的数量。 

这是莫比乌斯反演所需要的。 

---

 ##`floor_sum_range`高效计算$$\sum_{k=a}^{b} \left\lfloor \frac{n}{k}\right\rfloor.$$仅商改变$O(\sqrt n)$次，因此我们将间隔以相等的商进行分组。 

---

 ## 主循环

 对于每个$v$：

 - 枚举除数$d\mid v$,
 - 应用莫比乌斯反演，
 - 评估谐波下限总和，
 - 积累贡献。 

这避免了直接迭代所有互质对。
