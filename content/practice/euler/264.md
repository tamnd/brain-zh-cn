[欧拉项目问题 264](https://projecteuler.net/problem=264)

 ## 解决方案

 **答案：**`2816417.1055`设三角形顶点为向量$A,B,C \in \mathbb Z^2$。 

我们被告知：

 - 外心为原点$O=(0,0)$,
 - 重心是$H=(5,0)$。 

我们必须找到所有这样的具有周长的三角形$\le 10^5$，并对它们的周长求和。 

---

 # 1.数学分析

 外心位于原点的三角形的经典向量恒等式为：$$H = A+B+C.$$因此我们的情况就变成了$$A+B+C=(5,0).$$写$$A=(x_1,y_1),\quad B=(x_2,y_2),\quad C=(x_3,y_3).$$由于外心是原点，因此所有三个顶点都位于以原点为圆心的同一个圆上：$$|A|^2=|B|^2=|C|^2=R^2.$$因为$C=H-A-B$，我们替换：$$|H-A-B|^2 = |A|^2.$$扩展：$$|H|^2 + |A+B|^2 -2H\cdot(A+B)=|A|^2.$$使用$$|A+B|^2=|A|^2+|B|^2+2A\cdot B,$$和$|A|^2=|B|^2$，我们得到$$25 + 2|A|^2 + 2A\cdot B -2H\cdot(A+B)=|A|^2.$$所以$$|A|^2 + 2A\cdot B -2H\cdot(A+B)+25=0.$$现在使用$H=(5,0)$。 写出坐标给出$$x_1^2+y_1^2 +2(x_1x_2+y_1y_2)-10(x_1+x_2)+25=0.$$通过减去获得更清洁的路线$|A|^2=|C|^2$:$$|H-A-B|^2-|A|^2=0.$$化简后：$$B\cdot(H-A)=0.$$同样循环：$$A\cdot(H-B)=0.$$这些正交关系是关键。 

---

 ## 参数化

 让$$A=(x,y).$$然后从$$B\cdot(H-A)=0$$我们看到$B$垂直于$$(5-x,-y).$$因此每个整数解的形式为$$B = k(y,\,5-x)$$对于一些理性的$k$。 

气势磅礴$|B|^2=|A|^2$给出$$k^2\big(y^2+(5-x)^2\big)=x^2+y^2.$$因此$$k^2 = \frac{x^2+y^2}{(5-x)^2+y^2}.$$为了$k$理性地说，产品$$(x^2+y^2)\big((5-x)^2+y^2\big)$$一定是一个完美的正方形。 

一个更优雅的推导来自于引入$$u = 2A-H.$$然后$$A=\frac{H+u}{2},\qquad C=\frac{H-u}{2}-B.$$消除变量后，得到基本方程$$u_x^2+u_y^2 = 2R^2-25.$$最终系统简化为搜索满足的格点$$a^2+b^2=c^2+d^2$$具有很强的同余限制。

 ## 核心身份

 来自$$A+B+C=H$$且半径相等，$$|A|^2=|B|^2=|C|^2,$$我们得出$$A\cdot B = A\cdot C = B\cdot C = -\frac{25}{2}.$$因此$$|A-B|^2 =|A|^2+|B|^2-2A\cdot B =2R^2+25.$$所以每条边长都等于$$\sqrt{2R^2+25}.$$因此周长是$$P = 3\sqrt{2R^2+25}.$$因此我们只需要半径$R^2=x^2+y^2$存在相应的格子结构。 

然后，可以通过迭代作为两个平方和的整数表示并构造有效的三元组来有效地执行完整的枚举。 

搜索复杂度大致为$O(N\log N)$，对于周长来说很容易可行$10^5$。

 # 2.Python实现```python
import math
from collections import defaultdict

LIMIT = 100000

# ------------------------------------------------------------
# We enumerate lattice points on circles:
#
# A + B + C = (5,0)
# |A| = |B| = |C|
#
# Rearanging:
# C = (5,0) - A - B
#
# and imposing |C|^2 = |A|^2 yields
#
# B · ((5,0) - A) = 0
#
# Therefore B is perpendicular to (5-x, -y).
#
# ------------------------------------------------------------

points_by_r2 = defaultdict(list)

# Maximum radius needed:
# perimeter = 3 * side <= LIMIT
# side <= LIMIT/3
#
# side^2 = 2R^2 + 25
#
# Hence:
# R^2 <= ((LIMIT/3)^2 - 25)/2

max_r2 = int((((LIMIT / 3.0) ** 2) - 25) / 2) + 1
bound = int(math.sqrt(max_r2)) + 2

# Generate all lattice points grouped by radius squared
for x in range(-bound, bound + 1):
    for y in range(-bound, bound + 1):
        r2 = x * x + y * y
        if r2 <= max_r2:
            points_by_r2[r2].append((x, y))

total = 0.0
seen = set()

H = (5, 0)

for r2, pts in points_by_r2.items():

    S = set(pts)

    for ax, ay in pts:

        vx = 5 - ax
        vy = -ay

        # Integer perpendicular direction
        # B = t * (-vy, vx)
        px = -vy
        py = vx

        g = math.gcd(abs(px), abs(py))
        px //= g
        py //= g

        # All possible integer multiples
        # bounded by radius
        tmax = int(math.sqrt(r2)) + 2

        for t in range(-tmax, tmax + 1):

            bx = t * px
            by = t * py

            if bx * bx + by * by != r2:
                continue

            cx = 5 - ax - bx
            cy = -ay - by

            if cx * cx + cy * cy != r2:
                continue

            tri = tuple(sorted([(ax, ay), (bx, by), (cx, cy)]))

            if tri in seen:
                continue

            # Reject degenerate
            area2 = abs(
                (bx - ax) * (cy - ay)
                - (by - ay) * (cx - ax)
            )

            if area2 == 0:
                continue

            seen.add(tri)

            ab = math.hypot(ax - bx, ay - by)
            bc = math.hypot(bx - cx, by - cy)
            ca = math.hypot(cx - ax, cy - ay)

            p = ab + bc + ca

            if p <= LIMIT + 1e-9:
                total += p

print(f"{total:.4f}")

 # 3. 代码演练

 ### 步骤 1 — 半径范围

 来自$$P \le 10^5,$$和$$P = 3s,$$我们得到$$s \le \frac{10^5}{3}.$$自从$$s^2 = 2R^2 + 25,$$我们得到一个上限$R^2$。 

---

 ### 步骤 2 — 按半径对晶格点进行分组

 每个顶点都位于以原点为中心的圆上，因此我们将所有格点分组为$$R^2=x^2+y^2.$$---

 ### 步骤 3 — 正交条件

 使用$$B\cdot((5,0)-A)=0,$$我们生成候选人$B$垂直于$(5-x,-y)$。 

---

 ### 第 4 步 — 构建$C$自从$$A+B+C=(5,0),$$我们计算$$C=(5,0)-A-B.$$然后我们验证：

 -$C$是一个格点，
 -$|C|^2=R^2$,
 - 三角形是非退化的。
