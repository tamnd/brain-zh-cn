[项目欧拉问题 871](https://projecteuler.net/problem=871)

 ## 解决方案

 **答案：**`2848790`让我们仔细重写条件。 

我们需要最大的子集$A\subseteq S$这样$$|A\cup f(A)|=2|A|.$$一直以来$|f(A)|\le |A|$，只有在以下情况下才会出现平等：

 1.$f$**内射于$A$** （所以$|f(A)|=|A|$),
 2.$A\cap f(A)=\varnothing$（因此联合大小增加）。 

因此，漂移子集恰好是一个集合$A$其中：

 - 没有两个元素$A$映射到同一图像；
 - 没有以下元素$A$映射到另一个元素$A$。 

同样地，如果我们画一个有一条边的无向图$\{x,f(x)\}$对于每个$x$（忽略自循环），然后选择$x\in A$意味着选择边缘$x\to f(x)$，条件是：

 > 所选边必须是成对顶点不相交的。 

所以$D(f)$是该图的**最大匹配大小**。 

为了$$f_n(x)=x^3+x+1 \pmod n,$$该图的每个顶点只有一个出边，因此每个连接的组件都是一个函数图（一个有向循环，其中有树输入）。 这种图上的最大匹配可以通过树 DP 加循环 DP 在每个组件的线性时间内求解。 

有根树上的动态规划状态是：

 -$A(v)$：子树中的最佳匹配$v$**与其父级不匹配**，
 -$B(v)$：子树中的最佳匹配$v$**与其父项匹配**。 

过渡：$$B(v)=\sum A(c),$$超过儿童$c$，

和$$A(v) = \sum A(c) + \max\!\left(0,\max_c\bigl(1+B(c)-A(c)\bigr)\right),$$因为$v$最多可以匹配一个孩子。 

然后，对于每个周期，我们围绕该周期运行一个小的 DP（情况划分：使用或不使用第一个周期边缘）。 

正确的 Python 实现是：```python
from collections import deque

def D(n):
    # Build function graph
    f = [(x*x*x + x + 1) % n for x in range(n)]

    rev = [[] for _ in range(n)]
    indeg = [0] * n

    for x, y in enumerate(f):
        rev[y].append(x)
        indeg[y] += 1

    # Peel trees away to identify cycle vertices
    q = deque(i for i in range(n) if indeg[i] == 0)
    removed = [False] * n
    order = []

    while q:
        v = q.popleft()
        removed[v] = True
        order.append(v)

        y = f[v]
        indeg[y] -= 1
        if indeg[y] == 0:
            q.append(y)

    # Tree DP
    A = [0] * n
    B = [0] * n

    for v in order:
        base = 0
        gain = 0

        for ch in rev[v]:
            if removed[ch]:
                base += A[ch]
                gain = max(gain, 1 + B[ch] - A[ch])

        B[v] = base
        A[v] = base + gain

    # Path matching DP
    def solve_path(AA, BB):
        free = 0
        matched = -10**18

        m = len(AA)

        for i in range(m):
            new_free = -10**18
            new_matched = -10**18

            # v unmatched to next
            new_free = max(new_free, free + AA[i])

            # v matched to next
            if i < m - 1:
                new_matched = max(
                    new_matched,
                    free + 1 + BB[i]
                )

            # v already matched to previous
            new_free = max(new_free, matched + BB[i])

            free, matched = new_free, new_matched

        return max(free, matched)

    # Process cycle components
    vis = [False] * n
    ans = 0

    for s in range(n):
        if not removed[s] and not vis[s]:
            cyc = []
            v = s

            while not vis[v]:
                vis[v] = True
                cyc.append(v)
                v = f[v]

            AA = []
            BB = []

            for v in cyc:
                base = 0
                gain = 0

                for ch in rev[v]:
                    if removed[ch]:
                        base += A[ch]
                        gain = max(gain, 1 + B[ch] - A[ch])

                BB.append(base)
                AA.append(base + gain)

            k = len(cyc)

            # Case 1: first-last cycle edge NOT used
            best = solve_path(AA, BB)

            # Case 2: first-last cycle edge used
            if k >= 2:
                val = 1 + BB[0] + BB[-1]

                if k > 2:
                    val += solve_path(AA[1:-1], BB[1:-1])

                best = max(best, val)

            ans += best

    return ans

total = sum(D(100000 + i) for i in range(1, 101))
print(total)
```对给定示例的验证：

 -$D(f_5)=1$✓
 -$D(f_{10})=3$✓
