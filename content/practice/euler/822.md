[欧拉项目 822 问题](https://projecteuler.net/problem=822)

 ## 解决方案

 **答案：**`950591530`让$$x_i(k)=i^{2^k}$$是从初始数获得的值$i$平方后$k$次。 

在每一步中，我们都会选择最小的当前值并再次对其进行平方。 

我们必须计算$$S(10^4,10^{16}) \pmod{1234567891}.$$---

 # 1.数学分析

 对于每个$i$， 定义$$L_i(k)=\log_2(\log x_i(k)).$$自从$$x_i(k)=i^{2^k},$$我们有$$\log x_i(k)=2^k\log i,$$因此$$L_i(k) =\log_2(2^k\log i) = k+\log_2(\log i).$$定义$$c_i=\log_2(\log i).$$然后之后$k_i$平方，“优先值”$i$简直就是$$k_i+c_i.$$对当前最小值进行平方将其优先级精确地提高$1$。 

那么整个流程就变成了：

 - 从数字开始$c_i$。 
- 每个操作选取最小的当前值。 
- 按值替换$+1$。 

这是一个经典的平衡/注水过程。 

---

 ## 最终计数的结构

 假设在所有操作之后，数字$i$被平方$k_i$次。 

然后使用序列中的值$i$是：$$c_i,\ c_i+1,\ c_i+2,\ \dots,\ c_i+k_i-1.$$在全局范围内，该算法选择$m$所有这些算术级数中最小的元素。 

写$$c_i=q_i+f_i,$$在哪里$$q_i=\lfloor c_i\rfloor,\qquad 0\le f_i<1.$$对于足够大的$Y$,$$k_i = Y-q_i$$对于每个人来说，可能还需要对某些指数进行一项额外的操作。 

的确，$$\sum_i (Y-q_i) = (n-1)Y-\sum_i q_i.$$让$$B(Y)=(n-1)Y-\sum_i q_i.$$选择最大的$Y$这样$$B(Y)\le m.$$然后定义$$d=m-B(Y).$$确切地$d$索引接受一次额外的平方，即那些具有最小小数部分的索引$f_i$。 

因此：$$k_i= Y-q_i+\varepsilon_i,$$在哪里$\varepsilon_i\in\{0,1\}$， 和$\varepsilon_i=1$为$d$最小的$f_i$。 

---

 # 2. 模块化评估

 我们需要$$\sum_{i=2}^{10000} i^{2^{k_i}} \pmod{1234567891}.$$让$$M=1234567891.$$自从$M$是素数并且$i<M$,

 费马给出$$i^{a\bmod (M-1)} \equiv i^a \pmod M.$$所以我们计算：$$e_i = 2^{k_i}\bmod (M-1),$$然后$$i^{e_i}\bmod M.$$---

 # 3.Python实现```python
from math import log, log2, floor

MOD = 1234567891

def solve(n, m):
    data = []
    sum_q = 0

    # Compute c_i = log2(log(i))
    for i in range(2, n + 1):
        c = log2(log(i))

        q = floor(c)
        f = c - q

        data.append((f, i, q))
        sum_q += q

    N = n - 1

    # Largest Y with base_count <= m
    Y = (m + sum_q) // N

    base_count = N * Y - sum_q
    extra = m - base_count

    # Smallest fractional parts get one extra operation
    data.sort()

    extra_indices = set(i for _, i, _ in data[:extra])

    ans = 0

    for f, i, q in data:
        k = Y - q

        if i in extra_indices:
            k += 1

        # exponent = 2^k mod (MOD-1)
        exponent = pow(2, k, MOD - 1)

        ans = (ans + pow(i, exponent, MOD)) % MOD

    return ans

# Checks from the statement
print(solve(5, 3))      # 34
print(solve(10, 100))   # 845339386

# Final problem
print(solve(10_000, 10**16))
```---

 # 4. 代码演练

 ### 步骤 1

 对于每个初始值$i$:```python
c = log2(log(i))
q = floor(c)
f = c - q
```我们分解$$c_i=q_i+f_i.$$---

 ### 步骤 2

 找到平衡水平$Y$:```python
Y = (m + sum_q) // N
```因为$$B(Y)=NY-\sum q_i.$$---

 ### 步骤 3

 剩余的$$d=m-B(Y)$$运算被分配给最小的小数部分。```python
data.sort()
extra_indices = set(i for _, i, _ in data[:extra])
```---

 ### 步骤 4

 计算最终平方数：```python
k = Y - q
if i in extra_indices:
    k += 1
```---

 ### 步骤 5

 计算$$i^{2^{k_i}} \pmod{MOD}$$使用费马还原：```python
exponent = pow(2, k, MOD - 1)
pow(i, exponent, MOD)
```---
