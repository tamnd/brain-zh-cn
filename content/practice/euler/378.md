[欧拉项目问题 378](https://projecteuler.net/problem=378)

 ## 解决方案

 **答案：**`147534623725724718`让$$T(n)=\frac{n(n+1)}2$$并让$dT(n)$表示除数的个数$T(n)$。 

我们想要$$Tr(N)=\#\{(i,j,k):1\le i<j<k\le N,\ dT(i)>dT(j)>dT(k)\}$$为了$N=60\,000\,000$。 

---

 # 1.数学分析

 ## 步骤 1：公式$dT(n)$因为连续的整数是互质的，$$\gcd(n,n+1)=1.$$因此：

 - 如果$n$是偶数，$$T(n)=\frac n2 (n+1),$$和$\frac n2$互质于$n+1$;

 - 如果$n$是奇数，$$T(n)=n\cdot \frac{n+1}{2},$$和$n$互质于$\frac{n+1}{2}$。 

由于除数计数函数$\tau(n)$与互质参数相乘，$$dT(n)= \begin{cases} \tau(n/2)\tau(n+1), & n\text{ even},\\[4pt] \tau(n)\tau((n+1)/2), & n\text{ odd}. \end{cases}$$因此，整个问题归结为有效生成除数计数。 

---

 ## 步骤 2：计算递减三元组

 定义$$a_n=dT(n).$$我们必须数三倍$$i<j<k,\qquad a_i>a_j>a_k.$$使固定$j$。 然后：

 - 让$L_j$是$i<j$和$a_i>a_j$，
- 让$R_j$是$k>j$和$a_k<a_j$。 

然后每个具有中间索引的有效三元组$j$只贡献一次，所以$$Tr(N)=\sum_{j=1}^N L_jR_j.$$因此我们只需要：

 1. 顺序$a_n$,
 2.快速前缀/后缀频率查询。 

这是一个经典的芬威克树（二叉索引树）问题。 

---

 ## 步骤 3：计算除数计数

 我们筛选最小的质因数$N+1$。 

从 SPF 表中我们计算所有除数计数$\tau(n)$在线性时间内。 

然后：$$a_n= \begin{cases} \tau(n/2)\tau(n+1), & n\equiv0\pmod2,\\ \tau(n)\tau((n+1)/2), & n\equiv1\pmod2. \end{cases}$$的价值观$a_n$相对较小，因此我们对它们进行坐标压缩并使用 Fenwick 树。 

复杂性：

 - 除数筛：$O(N)$,
 - 芬威克通行证：$O(N\log M)$，

在哪里$M$是不同除数计数的数量。 

这在优化的 Python / PyPy 或 C++ 中已经足够快了。 

---

 # 2.Python实现```python
from array import array

N = 60_000_000

# ---------------------------------------------------------
# Smallest prime factor sieve
# ---------------------------------------------------------

spf = array('I', [0]) * (N + 2)
primes = []

for i in range(2, N + 2):
    if spf[i] == 0:
        spf[i] = i
        primes.append(i)

    for p in primes:
        v = p * i
        if v > N + 1 or p > spf[i]:
            break
        spf[v] = p

# ---------------------------------------------------------
# divisor-count function tau(n)
# ---------------------------------------------------------

tau = array('I', [0]) * (N + 2)
tau[1] = 1

exp = array('I', [0]) * (N + 2)
core = array('I', [0]) * (N + 2)

for n in range(2, N + 2):
    p = spf[n]
    m = n // p

    if spf[m] == p:
        exp[n] = exp[m] + 1
        core[n] = core[m]
    else:
        exp[n] = 1
        core[n] = m

    tau[n] = tau[core[n]] * (exp[n] + 1)

# ---------------------------------------------------------
# Build dT(n)
# ---------------------------------------------------------

A = array('I', [0]) * (N + 1)

for n in range(1, N + 1):
    if n & 1:
        A[n] = tau[n] * tau[(n + 1) // 2]
    else:
        A[n] = tau[n // 2] * tau[n + 1]

# ---------------------------------------------------------
# Coordinate compression
# ---------------------------------------------------------

vals = sorted(set(A[1:]))
rank = {v: i + 1 for i, v in enumerate(vals)}
M = len(vals)

# ---------------------------------------------------------
# Fenwick tree
# ---------------------------------------------------------

class BIT:
    def __init__(self, n):
        self.n = n
        self.bit = array('Q', [0]) * (n + 1)

    def add(self, idx, val):
        while idx <= self.n:
            self.bit[idx] += val
            idx += idx & -idx

    def sum(self, idx):
        s = 0
        while idx > 0:
            s += self.bit[idx]
            idx -= idx & -idx
        return s

# ---------------------------------------------------------
# Left counts
# ---------------------------------------------------------

L = array('Q', [0]) * (N + 1)

bit = BIT(M)

for j in range(1, N + 1):
    r = rank[A[j]]
    total = j - 1
    not_greater = bit.sum(r)
    L[j] = total - not_greater
    bit.add(r, 1)

# ---------------------------------------------------------
# Right counts and final answer
# ---------------------------------------------------------

bit = BIT(M)

ans = 0

for j in range(N, 0, -1):
    r = rank[A[j]]
    R = bit.sum(r - 1)
    ans += L[j] * R
    bit.add(r, 1)

print(ans % (10**18))
```---

 # 3. 代码演练

 ## SPF 筛

 The first block builds the smallest-prime-factor table.

 例子：

-$spf[12]=2$,
 -$spf[35]=5$。 

这允许快速分解每个整数。 

---

 ## 除数计数表

 使用递归$$\tau(p^e m)=\tau(m)(e+1),$$我们在线性时间内计算所有除数计数。 

例子：$$28=2^2\cdot7$$所以$$\tau(28)=(2+1)(1+1)=6.$$因此$dT(7)=6$，与语句相符。 

---

 ## 构建$dT(n)$我们使用$$dT(n)= \begin{cases} \tau(n/2)\tau(n+1), & n\text{ even},\\ \tau(n)\tau((n+1)/2), & n\text{ odd}. \end{cases}$$这避免了构造巨大的三角形数本身。 

---

 ## Fenwick 树计数

 对于每个位置$j$:

 - 第一遍计算有多少较早的值较大，
 - 第二遍计算有多少个后面的值较小。 

然后$$Tr(N)=\sum_j L_jR_j.$$---
