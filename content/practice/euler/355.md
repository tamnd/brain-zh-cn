[项目欧拉问题 355](https://projecteuler.net/problem=355)

 ## 解决方案

 **答案：**`1726545007`让$$\operatorname{Co}(n)$$是子集的最大可能和$\{1,2,\dots,n\}$其元素是**成对互质**。 

关键的观察是成对互质意味着：

 > 质因数不得出现在多个选定的数字中。 

所以问题实际上是关于将素数分配给选定的整数。 

### 步骤 1：自然基线

 对于每一个素数$p \le n$，如果我们使用$p$总而言之，最好的独立贡献是**最大的力量$p$** 不超过$n$:$$M(p)=\max\{p^k\le n\}.$$由于不同素数的素数幂互质，因此有效的基线集是$$\{1\}\cup \{M(p): p\le n\},$$与总和$$B = 1 + \sum_{p\le n} M(p).$$示例$n=10$:$$M(2)=8,\quad M(3)=9,\quad M(5)=5,\quad M(7)=7$$给予$$1+8+9+5+7=30,$$这是最佳的。 

然而，有时，将素数组合成一个复合数会击败单独的素数幂。 

例子 （$n=30$）：

- 分离：$16+25=41$对于素数$2,5$,
 - 合并：$27?$不可能（仅包含$3$），
- 但$2\cdot 13=26$可能会打败$16+13=29$？ 不。 

一般来说，对于任何无平方素数集$S$， 定义：$$V(S)=\max\{x\le n:\text{ prime factors of }x\text{ are exactly }S\}.$$将单独的素数幂替换为$V(S)$将分数更改为$$\Delta(S) = V(S)-\sum_{p\in S} M(p).$$仅设置有$\Delta(S)>0$事情。 

优化后变为：

 > 选择不相交素数集$S$最大化总体改进$\sum \Delta(S)$。 

这是一个**加权集合打包/二进制整数优化**问题：

 - 变量$x_S\in\{0,1\}$,
 - 每个质数最多可以出现在一个选定的集合中，
 - 最大化总增益。 

自从$n=200000$，盈利集的数量很少（~25k），现代 MILP 可以立即解决它。 

### Python 实现```python
from sympy import primerange
from scipy.optimize import milp, LinearConstraint, Bounds
import scipy.sparse as sp
import numpy as np

def Co(n):
    primes = list(primerange(2, n + 1))

    # Largest prime power <= n for each prime
    M = {}
    for p in primes:
        x = p
        while x * p <= n:
            x *= p
        M[p] = x

    baseline = 1 + sum(M.values())

    # Smallest prime factor sieve
    spf = list(range(n + 1))
    for i in range(2, int(n**0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, n + 1, i):
                if spf[j] == j:
                    spf[j] = i

    # For each prime set, keep the largest number <= n using exactly those primes
    best = {}

    for x in range(2, n + 1):
        y = x
        prime_set = []

        while y > 1:
            p = spf[y]
            prime_set.append(p)
            while y % p == 0:
                y //= p

        prime_set = tuple(prime_set)

        if x > best.get(prime_set, 0):
            best[prime_set] = x

    # Keep only profitable replacements
    candidates = []

    for prime_set, x in best.items():
        gain = x - sum(M[p] for p in prime_set)

        if gain > 0 and len(prime_set) >= 2:
            candidates.append((gain, prime_set))

    # Build sparse constraint matrix:
    # each prime may be used at most once
    p_index = {p: i for i, p in enumerate(primes)}

    rows, cols, data = [], [], []

    for j, (_, prime_set) in enumerate(candidates):
        for p in prime_set:
            rows.append(p_index[p])
            cols.append(j)
            data.append(1)

    A = sp.coo_matrix(
        (data, (rows, cols)),
        shape=(len(primes), len(candidates))
    ).tocsr()

    # MILP:
    # maximize gains == minimize negative gains
    c = -np.array([gain for gain, _ in candidates], dtype=float)

    constraints = LinearConstraint(
        A,
        -np.inf * np.ones(len(primes)),
        np.ones(len(primes))
    )

    integrality = np.ones(len(candidates), dtype=int)
    bounds = Bounds(
        np.zeros(len(candidates)),
        np.ones(len(candidates))
    )

    result = milp(
        c=c,
        constraints=constraints,
        integrality=integrality,
        bounds=bounds
    )

    return int(round(baseline - result.fun))

# Verification
print(Co(30))   # 193
print(Co(100))  # 1356

# Final answer
print(Co(200000))
```### 代码演练

 1. **计算$M(p)$**

 对于每个素数，找到它的最大幂$\le n$。 这些构成了基线解决方案。 
2. **对每个整数进行因式分解$x\le n$**

 使用最小素因子筛，确定不同的素因子$x$。 
3. **记录每个素数组的最佳代表**

 对于素数子集$S$，仅保留最大的数字$S$。 
4. **计算增益**

 如果用合成倍数替换单独的素数倍数会增加总和，则记录正增益。 
5. **MILP优化**

 每个候选替换的二进制变量。 约束强制每个素数最多出现一次。 
6. **将收益添加到基线**

 最终最优：$$\operatorname{Co}(n) = B+\max \sum \Delta(S).$$### 验证
