[Project Euler Problem 165](https://projecteuler.net/problem=165)

 ## 解决方案

 **答案：**`2868868`我们必须从 Blum-Blum-Shub 序列生成 5000 条线段，然后计算所有线段对中**不同的真实交点**的数量。 

主要困难是：

 1. 正确检测两条线段是否相交于两条线段的**单个内点**。 
2. 避免端点接触和共线重叠。 
3. 精确计算**不同**的交点，这需要理性算术而不是浮点数。 

---

 # 数学分析

 ## 1. 生成段

 我们被给予$$s_0 = 290797,\qquad s_{n+1} = s_n^2 \pmod{50515093}$$和$$t_n = s_n \bmod 500.$$每四个连续值定义一个段：$$(x_1,y_1)=(t_{4k+1},t_{4k+2}), \qquad (x_2,y_2)=(t_{4k+3},t_{4k+4}).$$由于我们需要 5000 个段，因此我们需要$20000$价值观$t_n$。 

---

 # 2.线段相交的几何形状

 考虑两个部分$$A=(x_1,y_1),\quad B=(x_2,y_2),$$

$$C=(x_3,y_3),\quad D=(x_4,y_4).$$定义向量$$\mathbf r = B-A, \qquad \mathbf s = D-C.$$两条无限直线相交 iff$$\mathbf r \times \mathbf s \neq 0.$$如果叉积为零，则直线平行（可能共线），并且不存在真正的交点。 

---

 ## 参数形式

 将各行写为$$A+t\mathbf r, \qquad C+u\mathbf s.$$交叉点发生在$$A+t\mathbf r = C+u\mathbf s.$$使用叉积：$$t = \frac{(C-A)\times \mathbf s}{\mathbf r\times \mathbf s},$$

$$u = \frac{(C-A)\times \mathbf r}{\mathbf r\times \mathbf s}.$$一个点是一个线段的**内部**点，当且仅当参数严格位于 0 和 1 之间：$$0<t<1,\qquad 0<u<1.$$这会自动排除端点交叉点。 

---

 # 3. 精确算术

 交点坐标是有理数：$$P = A+t\mathbf r.$$使用浮点会带来微小的舍入差异的风险，导致重复的点被单独计算。 

所以我们使用 Python 的精确有理算术`Fraction`。 

每个交点存储为：$$\left(\frac{p_x}{q_x},\frac{p_y}{q_y}\right)$$自动以简化形式显示。 

然后可以用Python计算不同的点`set`。 

---

 # 4. 复杂性

 有$$\binom{5000}{2}=12,\!497,\!500$$线段对。 

对于每一对，我们进行常数时间整数运算，这在优化的 Python 中是可行的。 

---

 # Python 实现```python
from fractions import Fraction

# ------------------------------------------------------------
# Generate the 5000 line segments
# ------------------------------------------------------------

MOD = 50515093

s = 290797
t = []

# Need 20000 values
for _ in range(20000):
    s = (s * s) % MOD
    t.append(s % 500)

segments = []

for i in range(0, 20000, 4):
    x1, y1, x2, y2 = t[i:i+4]
    segments.append((x1, y1, x2, y2))

# ------------------------------------------------------------
# Helper: 2D cross product
# ------------------------------------------------------------

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

# ------------------------------------------------------------
# Compute all distinct true intersection points
# ------------------------------------------------------------

points = set()

n = len(segments)

for i in range(n):
    x1, y1, x2, y2 = segments[i]

    rx = x2 - x1
    ry = y2 - y1

    for j in range(i + 1, n):
        x3, y3, x4, y4 = segments[j]

        sx = x4 - x3
        sy = y4 - y3

        denom = cross(rx, ry, sx, sy)

        # Parallel or collinear -> no unique true intersection
        if denom == 0:
            continue

        qpx = x3 - x1
        qpy = y3 - y1

        t_num = cross(qpx, qpy, sx, sy)
        u_num = cross(qpx, qpy, rx, ry)

        # We need strict interior intersections:
        # 0 < t < 1 and 0 < u < 1
        if denom > 0:
            if not (0 < t_num < denom and 0 < u_num < denom):
                continue
        else:
            if not (0 > t_num > denom and 0 > u_num > denom):
                continue

        # Compute exact rational coordinates
        t_frac = Fraction(t_num, denom)

        px = Fraction(x1) + t_frac * rx
        py = Fraction(y1) + t_frac * ry

        points.add((px, py))

print(len(points))
```---

 # 代码演练

 ## 序列生成```python
s = (s * s) % MOD
t.append(s % 500)
```这完全实现了 Blum-Blum-Shub 递归。 

---

 ## 构建细分```python
x1, y1, x2, y2 = t[i:i+4]
```每四个连续值定义一个段。 

---

 ## 叉积```python
def cross(ax, ay, bx, by):
    return ax * by - ay * bx
```叉积确定方向以及两个方向是否平行。 

---

 ## 检测平行线```python
if denom == 0:
    continue
```如果$$\mathbf r \times \mathbf s = 0,$$这些线是平行或共线的，因此不可能存在唯一的真实内部交点。 

---

 ## 内部交叉测试

 参数为：```python
t_num = cross(qpx, qpy, sx, sy)
u_num = cross(qpx, qpy, rx, ry)
```带分母`denom`。 

我们不进行除法，而是直接比较符号：```python
0 < t_num < denom
```（或者如果分母为负则反转不等式）。 

这避免了不必要的分数创建。 

---

 ## Exact coordinates```python
t_frac = Fraction(t_num, denom)
```然后```python
px = x1 + t_frac * rx
py = y1 + t_frac * ry
```给出精确的有理交点.

 该集合会自动删除重复项。

 # 小例子验证

 该问题给出了三个部分：

 -$L_1=(27,44)\to(12,32)$-$L_2=(46,53)\to(17,62)$-$L_3=(46,70)\to(22,40)$成对检查：

 -$L_2$和$L_3$intersect at one interior point.
 -$L_1$和$L_3$只在终点相遇$(22,40)$，不是真正的交集。 
-$L_1$和$L_2$不相交。 

因此，恰好有一个真正的交点，与陈述相匹配。
