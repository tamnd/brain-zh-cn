[项目欧拉问题 205](https://projecteuler.net/problem=205)

 ## 解决方案

 **答案：**`0.5731441`令 Peter 的总数为$P$和 Colin 的总和$C$。 

我们想要$$\Pr(P>C).$$彼得·罗尔斯$9$四面骰子，所以：$$P = X_1+\cdots+X_9, \qquad X_i\in\{1,2,3,4\}.$$科林卷$6$六面骰子，所以：$$C = Y_1+\cdots+Y_6, \qquad Y_i\in\{1,2,3,4,5,6\}.$$关键思想是：

 1. 计算 Peter 所有可能总和的分布。 
2. 计算 Colin 所有可能和的分布。 
3. 计算所有获胜对$(p,c)$和$p>c$。 
4. 除以结果总数。 

---

 # 1. 计算骰子的总和

 对于独立骰子，可以逐步构建分布。 

如果`ways[s]`是求和的方法数$s$，然后添加另一个带有面孔的骰子之后$1$到$k$,$$\text{new\_ways}[s+f] += \text{ways}[s]$$对于每一张脸$f\in\{1,\dots,k\}$。 

这是标准的卷积/动态编程方法。 

---

 # 2. Peter 的分布

 彼得的每个骰子都有 4 个面。 

最初：$$\text{ways}_0(0)=1.$$处理完 9 个骰子后，我们获得了使每个骰子总数一致的方法数：$9$到$36$。 

总成果：$$4^9 = 262144.$$---

 # 3. Colin 的分布

 同样，Colin 有 6 个六面骰子。 

可能的金额范围为$6$到$36$。 

总成果：$$6^6 = 46656.$$---

 # 4. 计算获胜概率

 如果彼得投掷总数$p$，科林投掷总数$c$，那么彼得获胜时$$p>c.$$因此$$\Pr(P>C) = \frac{ \sum_{p>c} N_P(p)\,N_C(c) }{ 4^9 6^6 },$$在哪里：

-$N_P(p)$= Peter 结果的数量总和为$p$,
 -$N_C(c)$= Colin 结果的数量总和为$c$。

 # 5.Python实现```python
from collections import defaultdict

def distribution(num_dice, faces):
    """
    Return a dictionary:
        sum -> number of ways
    """
    ways = {0: 1}

    for _ in range(num_dice):
        new_ways = defaultdict(int)

        for current_sum, count in ways.items():
            for face in range(1, faces + 1):
                new_ways[current_sum + face] += count

        ways = dict(new_ways)

    return ways

# Peter: 9 four-sided dice
peter = distribution(9, 4)

# Colin: 6 six-sided dice
colin = distribution(6, 6)

# Count winning outcomes
wins = 0

for p_sum, p_count in peter.items():
    for c_sum, c_count in colin.items():
        if p_sum > c_sum:
            wins += p_count * c_count

# Total outcomes
total = (4 ** 9) * (6 ** 6)

probability = wins / total

print(f"{probability:.7f}")
```---
