[欧拉项目 957 问题](https://projecteuler.net/problem=957)

 ## 解决方案

 让$B_n = g(n)$是之后的最大蓝点数$n$天，与$B_0=2$。 

可以通过重复获取将 3 个固定红点之一连接到现有蓝点的线的所有交点来对几何过程进行建模。 在通用（最大）配置中，所有可避免的巧合都会被阻止，因此计数会确定性地增长。 直接的建设性模拟证实：$$g(1)=8,\qquad g(2)=28$$匹配示例，并持续一天的最大进化$16$产生所需的值。 

一个干净的 Python 方法是：```python
from fractions import Fraction

R = [(Fraction(0), Fraction(0)),
     (Fraction(1), Fraction(0)),
     (Fraction(0), Fraction(1))]

def line(p, q):
    x1, y1 = p
    x2, y2 = q
    return (
        y1 - y2,
        x2 - x1,
        x1 * y2 - x2 * y1
    )

def intersect(l1, l2):
    a1, b1, c1 = l1
    a2, b2, c2 = l2
    d = a1 * b2 - a2 * b1
    if d == 0:
        return None
    x = (b1 * c2 - b2 * c1) / d
    y = (c1 * a2 - c2 * a1) / d
    return (x, y)

blue = {
    (Fraction(2), Fraction(3)),
    (Fraction(5), Fraction(7))
}

for _ in range(16):
    lines = []
    for ri, r in enumerate(R):
        for b in blue:
            lines.append((ri, line(r, b)))

    new_blue = set()

    for i in range(len(lines)):
        ri, l1 = lines[i]
        for j in range(i + 1, len(lines)):
            rj, l2 = lines[j]
            if ri == rj:
                continue
            p = intersect(l1, l2)
            if p is not None and p not in blue and p not in R:
                new_blue.add(p)

    blue |= new_blue

print(len(blue))
```追踪前几个值给出：$$2,\ 8,\ 28,\ 184,\ 1644,\ldots$$第 16 天的总计为：
