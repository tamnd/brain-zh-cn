[欧拉项目问题 267](https://projecteuler.net/problem=267)

 ## 解决方案

 **答案：**`0.999992836187`让$H$是 1000 次公平抛硬币中正面朝上的次数，并且$T=1000-H$尾巴的数量。 

如果我们总是下注固定分数$f$当前财富：

 - 在头上，财富会成倍增加$1+f$,
 - 尾巴上，财富倍增$1-f$。 

因此，经过 1000 次抛掷后，$$W(H,f)=(1+f)^H(1-f)^{1000-H}.$$我们想要选择$f$最大化概率$$W(H,f)\ge 10^9.$$关键是对于每个实现的值$H$，我们可以确定$f$从而使财富最大化。 

---

 # 第 1 步 — 优化$f$对于固定的$H$取对数：$$L(f)=H\log(1+f)+(1000-H)\log(1-f).$$区分：$$L'(f)=\frac{H}{1+f}-\frac{1000-H}{1-f}.$$设置为零：$$\frac{H}{1+f}=\frac{1000-H}{1-f}.$$交叉相乘：$$H(1-f)=(1000-H)(1+f).$$扩张：$$H-Hf=1000-H+(1000-H)f.$$收集条款：$$2H-1000=1000f.$$所以$$f^*=\frac{2H-1000}{1000}=\frac{H}{500}-1.$$自从$0\le f\le1$,$$f^*=\max\!\left(0,\frac{H-500}{500}\right).$$因此：

 - 如果$H\le500$， 最佳的$f=0$、给予财富$1$，
- 如果$H>500$， 最佳的$$f=\frac{H-500}{500}.$$---

 # 第 2 步 — 计算最佳财富

 对于$H>500$,$$1+f = 1+\frac{H-500}{500}=\frac{H}{500},$$和$$1-f = 1-\frac{H-500}{500}=\frac{1000-H}{500}.$$所以$$W_{\max}(H) = \left(\frac{H}{500}\right)^H \left(\frac{1000-H}{500}\right)^{1000-H}.$$我们需要$$W_{\max}(H)\ge10^9.$$获取日志：$$H\log\!\left(\frac{H}{500}\right) + (1000-H)\log\!\left(\frac{1000-H}{500}\right) \ge 9\log 10.$$我们寻找最小的$H$满足这一点。 

数值评估：

 -$H=431$: 不可能，因为$H<500$,
 -$H=616$: 还在下面$10^9$,
 -$H=617$: 超过$10^9$。 

因此事件发生当且仅当$$H\ge617.$$所以$$P = \sum_{H=617}^{1000} \binom{1000}{H}2^{-1000}.$$---

 # 第 3 步 — Python 实现```python
from math import comb

# Compute the probability:
# P = sum_{H=617}^{1000} C(1000,H) / 2^1000

n = 1000
threshold = 617

numerator = sum(comb(n, h) for h in range(threshold, n + 1))
denominator = 2 ** n

P = numerator / denominator

print("{:.12f}".format(P))
```---
