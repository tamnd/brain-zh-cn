[欧拉项目问题 336](https://projecteuler.net/problem=336)

 ## 解决方案

 **答案：**`CAGBIHEFJDK`让操作$R_k$意思是：

 - 保留第一个$k$车厢固定，
 - 反转从位置开始的后缀的顺序$k$。 

例如：$$R_1(DACB)=DBCA$$因为后缀$ACB$变成$BCA$。 

---

 # 1.数学分析

 ## 西蒙的策略

 西蒙从左到右修理火车。 

假设我们正在修理马车$A_i$就位$i$。 

有两种情况：

 1.如果$A_i$已经到最后了，一个反转就够了：$$R_i$$2. 否则Simon先发送$A_i$到最后，然后到最终位置：$$R_j,\quad R_i$$在哪里$j$是当前位置$A_i$。 

因此：

 - 每个阶段最多使用2次逆转，
 - 除了最后阶段，只能使用1个。 

所以对于$n$车厢最大可能的反转次数是$$2(n-2)+1=2n-3.$$实现此目的的排列称为**maximix排列**。 

---

 ## maximix 排列的递归结构

 假设我们对字母进行 maximix 排列$$B,C,D,\dots$$并称之为$q$。 

我们现在插入$A$。 

西蒙需要的最大移动次数：

 -$A$必须既不是第一个也不是最后一个。 

将排列写为$$P\,A\,S$$与两者$P,S\neq\emptyset$。 

西蒙表演：

 1. 反向后缀始于$A$：$$P\,A\,S \to P\,S^R\,A$$2、全车倒车：$$P\,S^R\,A \to A\,S\,P^R$$修复后$A$，剩余的后缀本身必须是 maximix 排列。 所以：$$q = S\,P^R.$$因此，每一种 maximix 排列都是通过以下方式从较小的排列中获得的：$$P\,A\,S$$在哪里$q=S\,P^R$。 

如果$q$有长度$m=n-1$，选择分割点$k$和$$1 \le k \le m-1.$$然后：

-$S=q[:k]$-$P^R=q[k:]$-$P=(q[k:])^R$给予$$p=(q[k:])^R + A + q[:k].$$这会递归地生成**所有** maximix 排列。 

计数满足：$$M_n=(n-2)M_{n-1}, \qquad M_2=1,$$所以$$M_n=(n-2)!.$$为了$n=11$：$$M_{11}=9!=362880,$$小到可以直接生成。

 # 2.Python实现```python
def maximix(chars):
    n = len(chars)

    # Base case: for two letters, only the reversed order is maximix
    if n == 2:
        return [chars[1] + chars[0]]

    first = chars[0]
    result = []

    # Generate all maximix arrangements of the remaining letters
    for q in maximix(chars[1:]):

        m = n - 1

        # Split q into S + P^R
        for k in range(1, m):

            # Reconstruct P A S
            p = q[k:][::-1] + first + q[:k]

            result.append(p)

    return sorted(result)

arrangements = maximix("ABCDEFGHIJK")

answer = arrangements[2010]   # 2011th lexicographic (1-indexed)

print(answer)
```---
