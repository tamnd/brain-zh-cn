[项目欧拉问题 120](https://projecteuler.net/problem=120)

 ## 解决方案

 **答案：**`333082500`我们求最大余数$$r = (a-1)^n + (a+1)^n \pmod{a^2}$$对于每个整数$3 \le a \le 1000$，然后计算$$\sum_{a=3}^{1000} r_{\max}.$$关键是简化表达式模$a^2$。 

---

 # 步骤 1 — 用二项式定理展开

 考虑$$(a+1)^n.$$使用二项式定理，$$(a+1)^n = \sum_{k=0}^n \binom{n}{k} a^k.$$模数$a^2$，每个术语包含$a^2$或更高的消失，所以只有前两项重要：$$(a+1)^n \equiv 1 + na \pmod{a^2}.$$相似地，$$(a-1)^n = \sum_{k=0}^n \binom{n}{k} a^k (-1)^{n-k}.$$再次仅保留以下条款$a^2$,$$(a-1)^n \equiv (-1)^n + n(-1)^{n-1}a \pmod{a^2}.$$现在添加两个表达式：$$r \equiv \left[1 + na\right] + \left[(-1)^n + n(-1)^{n-1}a\right] \pmod{a^2}.$$我们通过奇偶性来区分案例$n$。 

---

 # 第 2 步 — 偶数和奇数$n$## 情况 1：$n$甚至

 然后$$(-1)^n = 1, \qquad (-1)^{n-1} = -1.$$所以$$r \equiv (1+na)+(1-na)=2 \pmod{a^2}.$$因此每一个偶数$n$给出$$r=2.$$---

 ## 情况2：$n$奇数

 然后$$(-1)^n=-1, \qquad (-1)^{n-1}=1.$$因此$$r \equiv (1+na)+(-1+na)=2na \pmod{a^2}.$$所以对于奇数$n$,$$r \equiv 2an \pmod{a^2}.$$因此问题简化为最大化$$2an \bmod a^2.$$分解因素$a$：$$r = a(2n \bmod a).$$因此我们想要最大可能的倍数$a$以下$a^2$。 

因为$2n$是偶数，可达到的最大余数取决于奇偶校验$a$。 

---

 # 第 3 步 — 确定$r_{\max}$＃＃ 如果$a$很奇怪

 然后$a-1$是偶数，所以我们可以选择$$2n \equiv a-1 \pmod a.$$这给出了$$r_{\max}=a(a-1).$$- -

＃＃ 如果$a$是偶数

 那么下面最大的偶数余数$a$是$a-2$， 所以$$r_{\max}=a(a-2).$$---

 我们可以巧妙地将这两种情况结合起来：$$r_{\max} = \begin{cases} a(a-1), & a \text{ odd},\\ a(a-2), & a \text{ even}. \end{cases}$$---

 # 第 4 步 — 计算总和

 我们现在评估$$\sum_{a=3}^{1000} r_{\max}.$$---

 # Python 实现```python
total = 0

for a in range(3, 1001):

    # If a is odd:
    # r_max = a(a - 1)
    if a % 2 == 1:
        r_max = a * (a - 1)

    # If a is even:
    # r_max = a(a - 2)
    else:
        r_max = a * (a - 2)

    total += r_max

print(total)
```---

 # 小例子检查

 问题表明对于$a=7$,$$r_{\max}=42.$$我们的公式给出：$$7(7-1)=42,$$完美匹配。 

为了$a=6$,$$r_{\max}=6(6-2)=24.$$事实上，奇次幂会产生留数$$2an \bmod 36,$$其最大值为$24$。 

---

 # 最终验证

 主项大约是$a^2$，所以总数应该是$$\sum_{a=1}^{1000} a^2 \approx \frac{1000^3}{3}\approx 3.3\times10^8.$$我们的最终值正好在这个范围内，这是一个很好的健全性检查。 

计算总和得出：$$333082500.$$**答案：333082500**
