[欧拉项目问题 86](https://projecteuler.net/problem=86)

 ## 解决方案

 **答案：**`1818`令长方体的边长为整数$$a \le b \le c.$$我们希望沿着曲面从一个角到对角的最短路径具有整数长度。 

关键的观察是，当我们展开长方体时，三个候选最短路径是：$$\sqrt{(a+b)^2+c^2},\qquad \sqrt{(a+c)^2+b^2},\qquad \sqrt{(b+c)^2+a^2}.$$自从$a \le b \le c$，我们有$$a+b \le a+c \le b+c,$$所以最矮的候选人总是$$\sqrt{(a+b)^2+c^2}.$$因此，我们需要整数解$$(a+b)^2 + c^2 = k^2$$对于某个整数$k$。 

---

 # 1. 数学分析

 定义$$s = a+b.$$然后我们求毕达哥拉斯三元组$$s^2 + c^2 = k^2,$$有限制$$1 \le a \le b \le c.$$对于固定的最大边长$M$，我们计算所有长方体$$c \le M.$$所以对于每一个$c$，我们计算所有值$s$这样$$s^2 + c^2$$是一个完美的正方形。 

然后我们数一下有多少对$(a,b)$满足$$a+b=s,\qquad 1\le a\le b\le c.$$---

 ## 计数$(a,b)$对

 对于固定$s$和$c$：$$a+b=s,\qquad a\le b,\qquad b\le c.$$因为$b=s-a$,$$a \le s-a \quad\Rightarrow\quad a \le \frac{s}{2}.$$还，$$s-a \le c \quad\Rightarrow\quad a \ge s-c.$$因此$$\max(1,s-c)\le a \le \left\lfloor \frac{s}{2}\right\rfloor.$$所以有效对的数量是$$\left\lfloor \frac{s}{2}\right\rfloor-\max(1,s-c)+1.$$这简化为标准紧凑形式：

 - 如果$s\le c$：$$\#=\left\lfloor \frac{s}{2}\right\rfloor.$$- 如果$s>c$：$$\#=\left\lfloor \frac{s}{2}\right\rfloor-(s-c)+1.$$---

 # 2. 高效的算法

 我们递增$M=c$一次一个。 

对于每一个新$c$：

 1. 循环遍历$$s=2,3,\dots,2c$$因为$a,b\le c$。 
2. 检查是否$$s^2+c^2$$是一个完美的正方形。 
3. 如果有，请添加有效数量$(a,b)$对。 

累计总数超过后停止$1,000,000$。 

复杂度大致为$$O(M^2),$$这足够快，因为答案就在附近$1800$。 

---

 # 3.Python 实现```python
from math import isqrt

TARGET = 1_000_000

count = 0
M = 0

while count <= TARGET:
    M += 1

    # s = a + b
    for s in range(2, 2 * M + 1):

        # Check whether s^2 + M^2 is a perfect square
        n = s * s + M * M
        r = isqrt(n)

        if r * r == n:

            # Count valid (a,b) pairs
            if s <= M:
                count += s // 2
            else:
                count += (s // 2) - (s - M) + 1

print(M)
```---

 ## 计算有效分解

 ### 案例 1：$s \le M$

```python
count += s // 2
```例子：$$s=6$$有效对：$$(1,5),(2,4),(3,3)$$确切地$6//2=3$。 

---

 ### 案例 2：$s > M$

```python
count += (s // 2) - (s - M) + 1
```这强制执行$b \le M$。 

例子：$$M=5,\quad s=8$$可能的配对：$$(3,5),(4,4)$$数数$=2$。 

公式给出：$$8//2-(8-5)+1 =4-3+1 =2.$$---
