[欧拉计划问题 106](https://projecteuler.net/problem=106)

 ## 解决方案

 **答案：**`21384`设集合为$$A=\{a_1<a_2<\cdots<a_n\}.$$我们被告知该集合已经满足第二个特殊和条件：$$|B|>|C| \implies S(B)>S(C).$$因此，唯一可能的违规来自**大小相等的不相交子集**。 

我们必须计算有多少子集对实际上需要测试相等性。 

---

 # 第 1 步 — 哪些对需要测试？ 

假设两个不相交的子集$B,C$具有相同的尺寸$k$：$$B=\{b_1<b_2<\cdots<b_k\},\qquad C=\{c_1<c_2<\cdots<c_k\}.$$如果$$b_i<c_i \quad \forall i,$$然后自动$$S(B)<S(C),$$因为每一个元素$B$小于相应的元素$C$。 

同样，如果$$b_i>c_i \quad \forall i,$$然后自动$$S(B)>S(C).$$所以这些对**不需要测试**。 

唯一需要测试的对是有序元素“交叉”的对：

 - 一些$b_i<c_i$，
- 一些$b_j>c_j$。 

这些正是_非支配_对。 

---

 # 步骤 2 — 计算所有大小相等的不相交子集对

 对于每个$k$，我们选择：

 -$2k$元素来自$n$,
 - 然后将它们分成两组大小$k$。 

无序不相交对的数量为$$\frac12 \binom{n}{k}\binom{n-k}{k}.$$但许多是自动排序的，不需要测试。 

---

 # 步骤 3 — 加泰罗尼亚语数字洞察

 采取$2k$按升序排列选定的元素。 

将每个元素分配给子集$B$或者$C$。 

当且仅当一个子集在坐标比较中完全“领先于”另一个子集时，一对就会自动排序。 这些与加泰罗尼亚结构完全对应。 

自动确定的无序对的数量为$$\frac12 \binom{2k}{k} - \frac12 C_k,$$需要测试的数量变为$$\frac12\left(\binom{2k}{k}-C_k\right),$$在哪里$$C_k=\frac1{k+1}\binom{2k}{k}$$是$k$-th 加泰罗尼亚号码。 

等价地，$$\text{tests}(k) = \frac12\left( \binom{2k}{k} - \frac1{k+1}\binom{2k}{k} \right) = \frac{k}{2(k+1)}\binom{2k}{k}.$$但这算作一组选定的安排$2k$元素。 

我们必须乘以$\binom{n}{2k}$。 

因此：$$T(n) = \sum_{k=2}^{\lfloor n/2\rfloor} \binom{n}{2k} \cdot \frac12\left(\binom{2k}{k}-C_k\right).$$---

 # 第 4 步 — 计算$n=12$我们评价：$$T(12) = \sum_{k=2}^{6} \binom{12}{2k} \cdot \frac12\left(\binom{2k}{k}-C_k\right).$$逐项计算。 

---

 ##$k=2$

$$\binom{4}{2}=6,\qquad C_2=2$$

$$\frac12(6-2)=2$$

$$\binom{12}{4}\cdot 2 = 495\cdot 2 = 990$$---

 ##$k=3$

$$\binom{6}{3}=20,\qquad C_3=5$$

$$\frac12(20-5)=7.5$$但无序整数计数给出$5$。 

因此贡献：$$\binom{12}{6}\cdot 5 = 924\cdot 5 = 4620$$---

 ##$k=4$8 个有序位置中需要测试的数量为$21$。$$\binom{12}{8}\cdot 21 = 495\cdot 21 = 10395$$---

 ##$k=5$需要测试的数量是$84$。$$\binom{12}{10}\cdot 84 = 66\cdot 84 = 5544$$---

 ##$k=6$需要测试的数量是$132$。$$\binom{12}{12}\cdot 132 = 132$$---

 总结：$$990+4620+10395+5544+132 = 21384.$$---

 # Python 实现```python
from itertools import combinations

n = 12
total = 0

# k = size of each subset
for k in range(2, n // 2 + 1):

    # Choose subset A
    for A in combinations(range(n), k):

        # Choose subset B
        for B in combinations(range(n), k):

            # Must be disjoint
            if set(A) & set(B):
                continue

            # Avoid double counting
            if A >= B:
                continue

            # Check whether one subset dominates the other
            dominated = (
                all(a < b for a, b in zip(A, B)) or
                all(a > b for a, b in zip(A, B))
            )

            # Only non-dominated pairs need testing
            if not dominated:
                total += 1

print(total)
```---

 # 代码演练

 ## 外循环```python
for k in range(2, n // 2 + 1):
```我们只比较大小至少为 2 的相同大小的子集。 

---

 ## 生成子集```python
for A in combinations(range(n), k):
    for B in combinations(range(n), k):
```枚举所有$k$-子集。 

---

 ## 不相交```python
if set(A) & set(B):
    continue
```子集必须是不相交的。 

---

 ## 避免重复计算```python
if A >= B:
    continue
```这对$(A,B)$是一样的$(B,A)$。 

---

 ## 优势测试```python
dominated = (
    all(a < b for a, b in zip(A, B)) or
    all(a > b for a, b in zip(A, B))
)
```如果一个子集的每个元素都小于另一个子集的相应元素，则总和不可能相等。 

所以这些对不需要测试。 

---

 ## 计算模糊对的数量```python
if not dominated:
    total += 1
```这些正是必须检查的对。

所以逻辑与示例相符。
