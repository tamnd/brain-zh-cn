[欧拉项目问题 51](https://projecteuler.net/problem=51)

 ## 解决方案

 **答案：**`121313`### 1.数学分析

 我们想要属于**八素数族**的**最小素数**，通过用**相同的数字**替换一些数字子集而形成。 

例如：

-`*3`给出六个素数：$$13,23,43,53,73,83$$-`56**3`给出七个素数：$$56003,56113,56333,56443,56663,56773,56993$$我们寻找**第一个素数**，它可以从 10 个替换素数中生成 **8 个素数**。 

---

 #### 关键观察 1：我们只替换相等的数字

 假设我们独立地更换位置。 然后搜索会以组合方式爆炸。 

但请注意问题陈述说：

 > 用**相同的数字**替换部分数字

 所以如果我们选择职位$i_1, i_2, \dots$，它们必须全部替换为一个共同的数字$d\in\{0,\dots,9\}$。 

自然策略：

 1. 生成素数。 
2. 对于每个素数，选择数字位置的子集。 
3. 将这些位置同时替换为数字$0$–$9$。 
4. 计算有多少个结果是素数。 
5. 在第一个 8 号家庭停下来。 

---

 #### 关键观察 2：替换的位置应包含相同的原始数字

 假设我们替换包含不同数字的位置。 

例子：`12345`, 替换位置`(1,3)`。 

家庭变成：$$10305,11315,\dots$$但这很少能保留结构并重复工作。 

相反，我们只考虑已经包含**相同数字**的位置上的掩码。 对于像这样的素数`56003`，我们会考虑替换这两个`0`s。 

这极大地减少了搜索空间并捕获了预期的家庭。 

---

 #### 关键观察 3：被 3 整除的限制

 这是微妙的数学技巧。 

假设我们替换$k$数字由$d$。 

数字和线性变化：$$S(d)=S_0+k d$$如果$k \not\equiv 0 \pmod 3$，那么作为$d$从 0 到 9 运行：$$S(d)\pmod 3$$循环所有残留物。 因此**至少有 3 个值**可以被 3 整除。 

但我们需要 **8 个素数**，意味着最多 **2 个合数**。 

所以：$$k \equiv 0 \pmod 3$$是必要的。 

因此，替换的位数通常应为：$$3,6,\dots$$这极大地减少了搜索。 

---

 #### 算法

 对于每个素数$p$:

 1. 转换为字符串。 
2. 按数字对索引进行分组 (`0`–`9`）。 
3. 对于每个数字组：

 - 考虑大小可被 3 整除的子集。 
4. 用数字替换这些位置`0..9`。 
5. 跳过前导零结果。 
6. 计算族中的素数。 
7. 如果 count = 8，则返回该族中最小的素数。 

因为我们按升序扫描素数，所以找到的第一个有效素数自动就是答案。 

---

 ### 2.Python实现```python
from itertools import combinations
from math import isqrt

def sieve(limit):
    """Return boolean prime table and list of primes."""
    is_prime = [True] * limit
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(limit) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            is_prime[start:limit:step] = [False] * (
                (limit - start - 1) // step + 1
            )

    primes = [i for i, flag in enumerate(is_prime) if flag]
    return is_prime, primes

def find_smallest_prime_in_family(target_family_size=8):
    # Large enough upper bound for Problem 51
    LIMIT = 1_000_000

    is_prime, primes = sieve(LIMIT)

    for p in primes:
        if p < 10:
            continue

        s = str(p)
        n = len(s)

        # Group positions by digit
        digit_positions = {}
        for i, ch in enumerate(s):
            digit_positions.setdefault(ch, []).append(i)

        # Try replacement masks
        for digit, positions in digit_positions.items():

            # Replace counts divisible by 3
            for r in range(1, len(positions) + 1):
                if r % 3 != 0:
                    continue

                for mask in combinations(positions, r):

                    family = []

                    for replacement_digit in "0123456789":
                        chars = list(s)

                        for idx in mask:
                            chars[idx] = replacement_digit

                        # No leading zero
                        if chars[0] == "0":
                            continue

                        candidate = int("".join(chars))

                        if is_prime[candidate]:
                            family.append(candidate)

                    if len(family) == target_family_size:
                        return min(family)

    return None

answer = find_smallest_prime_in_family()
print(answer)
```---
