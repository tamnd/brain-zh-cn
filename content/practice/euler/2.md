[欧拉项目问题2](https://projecteuler.net/problem=2)

 ## 解决方案

 我们需要斐波那契偶数的总和不超过$4{,}000{,}000$。 

斐波那契数列开始：$$1,2,3,5,8,13,21,34,\dots$$偶值项是：$$2,8,34,144,\dots$$一种直接的方法是生成斐波那契数$4{,}000{,}000$并累积偶数。 

Python代码：```python
a, b = 1, 2
total = 0

while a <= 4_000_000:
    if a % 2 == 0:
        total += a
    a, b = b, a + b

print(total)
```跟踪计算得出偶数斐波那契项：$$2 + 8 + 34 + 144 + 610 + 2584 + 10946 + 46368 + 196418 + 832040 + 3524578$$他们的总和是：$$4613732$$**答案：4613732**
