[欧拉项目 832 问题](https://projecteuler.net/problem=832)

 ## 解决方案

 **答案：**`552839586`让块内的回合被索引$0$。 

定义$$T_k=\frac{4^k-1}{3}.$$后$T_k$轮，纸张恰好包含整数$$1,2,\dots,4^k-1.$$从例子中可以看出这一点：

 -$T_1=1$：数字$1..3$,
 -$T_2=5$：数字$1..15$,
 -$T_3=21$：数字$1..63$。 

因此，该过程以大小块进行$4^k$。 

对于开始于$4^k$，将轮索引写为$r\in[0,4^k)$，在基数$4$:$$r = \sum d_i 4^i.$$该构造递归地导出数字映射$$0\mapsto(0,0),\quad 1\mapsto(2,3),\quad 2\mapsto(3,1),\quad 3\mapsto(1,2).$$如果$x_r,y_r$是相应的低部分$b,c$， 然后$$x_r+y_r = \sum t(d_i)4^i,$$在哪里$$t(0)=0,\quad t(1)=5,\quad t(2)=4,\quad t(3)=3.$$所以$$r + (x_r+y_r) = 6\sum_{d_i\neq 0}4^i.$$所以回合的贡献$r$在块中$k$是$$6\cdot 4^k + 6\sum_{d_i\neq 0}4^i.$$定义$$\operatorname{supp}(r)=\sum_{d_i\neq 0}4^i.$$那么对于$n=T_k+m$和$0\le m<4^k$,$$M(n) = \frac{4^k(4^k-1)}2 + 6m4^k + 6\sum_{r=0}^{m-1}\operatorname{supp}(r).$$递归计算剩余总和。 

使用的Python实现：```python
MOD = 10**9 + 7

from functools import lru_cache

@lru_cache(None)
def fullS(k):
    # Sum of supp(r) for 0 <= r < 4^k
    if k == 0:
        return 0
    p = 4 ** (k - 1)
    return 4 * fullS(k - 1) + 3 * p * p

def S(k, m):
    # Sum of supp(r) for 0 <= r < m, with r < 4^k
    if k == 0 or m == 0:
        return 0

    p = 4 ** (k - 1)
    a, b = divmod(m, p)

    return (
        a * fullS(k - 1)
        + max(0, a - 1) * p * p
        + (p * b if a else 0)
        + S(k - 1, b)
    )

def M(n):
    k = 0
    while (4 ** (k + 1) - 1) // 3 <= n:
        k += 1

    T = (4 ** k - 1) // 3
    m = n - T

    base = 4 ** k * (4 ** k - 1) // 2

    return base + 6 * m * 4 ** k + 6 * S(k, m)

ans = M(10**18) % MOD
print(ans)
```检查：

 -$M(10)=642$-$M(1000)=5432148$两者都符合声明。 

因此，

 **答案：552839586**
