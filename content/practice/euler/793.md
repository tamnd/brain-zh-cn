[欧拉项目 793 问题](https://projecteuler.net/problem=793)

 ## 解决方案

 **答案：**`475808650131120`让$$S_0=290797,\qquad S_{i+1}=S_i^2 \bmod 50515093$$并定义$$P(n)=\{S_iS_j \mid 0\le i<j<n\}.$$有$$N=\binom n2$$成对产品。 自从$N$是奇数$n=1{,}000{,}003$，中位数是唯一的元素$N//2$其下方的产品。 

我们被要求$$M(1{,}000{,}003).$$---

 # 1.数学分析

 ## 步骤1：生成序列并排序

 伪随机生成器产生小于的正整数$50515093$。 

让$$A = \text{sorted}(S_0,S_1,\dots,S_{n-1}).$$排序至关重要，因为它可以让我们有效地计数产品。 

---

 ## 步骤2：将中位数问题转化为计数问题

 定义$$f(x)=\#\{(i,j): i<j,\ A_iA_j\le x\}.$$然后$f(x)$是单调递增的。 

如果我们可以计算$f(x)$很快，那么中位数是最小的$x$这样$$f(x)\ge \frac{N+1}{2}.$$为了$$N=\binom{1{,}000{,}003}{2}=500002500003,$$目标排名是$$K=\frac{N+1}{2}=250001250002.$$所以我们求最小的整数$x$和$$f(x)\ge K.$$---

 ## 第三步：两指针计数

 因为$A$排序后，我们可以在线性时间内对对进行计数。 

使固定$i$。 我们想要最大的$j>i$满意的$$A_iA_j\le x.$$作为$i$增加，这个最大$j$永远不会增加，因此我们使用递减指针。 

算法：

 - 开始$j=n-1$。 
- 对于每个$i$：

- 尽管$A_iA_j>x$, 递减$j$。 
- 然后是所有索引$i+1,\dots,j$工作。 
- 添加$j-i$到计数。 

这计算$f(x)$在$O(n)$。 

---

 ## 第四步：二分查找

 产品范围从$$0 \le A_iA_j \le A_{n-1}A_{n-2}.$$自从$f(x)$是单调的，二分查找在大约 51 次迭代中找到中值，因为搜索范围低于$2^{52}$。 

总复杂度：

 - 排序：$O(n\log n)$- 每项计数：$O(n)$- 二分查找：$O(n\log V)$这足够快了$n=1{,}000{,}003$。 

---

 # 2.Python实现```python
MOD = 50515093
N = 1_000_003

# ------------------------------------------------------------
# Generate the sequence
# ------------------------------------------------------------
S = [0] * N

x = 290797
for i in range(N):
    S[i] = x
    x = (x * x) % MOD

# ------------------------------------------------------------
# Sort values
# ------------------------------------------------------------
A = sorted(S)

# Number of pairwise products
total_pairs = N * (N - 1) // 2

# We want the lower/true median rank (1-based)
target = total_pairs // 2 + 1

# ------------------------------------------------------------
# Count how many pairs have product <= value
# ------------------------------------------------------------
def count_leq(value):
    count = 0
    j = N - 1

    for i, a in enumerate(A):

        while i < j and a * A[j] > value:
            j -= 1

        if j <= i:
            break

        count += (j - i)

    return count

# ------------------------------------------------------------
# Binary search for the median product
# ------------------------------------------------------------
lo = 0
hi = A[-1] * A[-2]

while lo < hi:
    mid = (lo + hi) // 2

    if count_leq(mid) >= target:
        hi = mid
    else:
        lo = mid + 1

print(lo)
```---

 ## 计数对```python
while i < j and a * A[j] > value:
    j -= 1
```对于每个固定$i$， 移动$j$向下直到乘积约束成立。 

然后：```python
count += (j - i)
```因为之间的每个索引$i+1$和$j$作品。 

总体运行时间是线性的，因为$j$只会减少。 

---

    hi = mid
else:
    lo = mid + 1
```这会找到排名至少为中位排名的最小值。
