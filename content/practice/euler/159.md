[欧拉项目问题 159](https://projecteuler.net/problem=159)

 ## 解决方案

 **答案：**`14489159`让$drs(n)$表示的数字根$n$。 

一个有用的封闭形式是：$$drs(n)= \begin{cases} 0 & n=0\\ 1+((n-1)\bmod 9) & n>0 \end{cases}$$所以对于所有正整数，$drs(n)\in\{1,\dots,9\}$， 和：

-$drs(24)=2+4=6$-$drs(467)=4+6+7=17\to1+7=8$我们定义：$$mdrs(n)=\max\{\text{digital root sums over all factorizations of } n\}$$包括平凡因式分解$n$本身。 

例如：$$24 = 3\times 8$$给出$$drs(3)+drs(8)=3+8=11$$并且没有更好的因式分解，所以：$$mdrs(24)=11$$---

 # 关键见解

 假设我们分手了$n$作为：$$n=d\cdot \frac{n}{d}$$然后任意最优因式分解$n$可以看作：

 - 选择一个除数$d\ge2$,
 - 然后最优因式分解$n/d$。 

所以：$$mdrs(n)=\max\left(drs(n),\ \max_{d\mid n,\ 2\le d<n}\left(drs(d)+mdrs\left(\frac{n}{d}\right)\right)\right)$$这是经典的动态规划/筛递归。 

因为每个递归项都涉及较小的数$n/d < n$，我们可以按升序计算值。 

---

 # 高效的筛选策略

 我们需要：$$\sum_{n=2}^{999999} mdrs(n)$$对每个都进行简单的因式分解$n$会太慢。 

相反：

 1. 预计算$drs(n)$为所有人$n<10^6$。 
2.初始化：$$mdrs(n)=drs(n)$$1. 对于每个除数$d$，将更新传播到倍数：

 如果$n=d\cdot q$， 然后：$$mdrs(n)\ge drs(d)+mdrs(q)$$所以：```python
for d in 2..N:
    for q in 2..N/d:
        n = d*q
        mdrs[n] = max(mdrs[n], drs[d] + mdrs[q])
```这就像除数筛一样，运行速度足够快$10^6$。 

---

 # Python 实现```python
LIMIT = 10**6

# ---------------------------------------------------------
# Compute digital roots
# drs(n) = 1 + ((n - 1) % 9) for n > 0
# ---------------------------------------------------------

drs = [0] * LIMIT

for n in range(1, LIMIT):
    drs[n] = 1 + (n - 1) % 9

# ---------------------------------------------------------
# Initialize mdrs with the trivial factorization: n itself
# ---------------------------------------------------------

mdrs = drs[:]

# ---------------------------------------------------------
# Dynamic programming sieve
#
# If n = d * q, then:
# mdrs[n] >= drs[d] + mdrs[q]
# ---------------------------------------------------------

for d in range(2, LIMIT):
    dd = drs[d]

    max_q = (LIMIT - 1) // d

    for q in range(2, max_q + 1):
        n = d * q

        candidate = dd + mdrs[q]

        if candidate > mdrs[n]:
            mdrs[n] = candidate

# ---------------------------------------------------------
# Sum all mdrs values for 2 <= n < 10^6
# ---------------------------------------------------------

answer = sum(mdrs[2:])

print(answer)
```---

 ## 数字根表```python
drs[n] = 1 + (n - 1) % 9
```这会在恒定时间内计算数字根。 

示例：

 -$drs(8)=8$-$drs(24)=6$-$drs(999)=9$---

 ## 初始化`mdrs`

```python
mdrs = drs[:]
```每个数字都至少具有平凡的因式分解：$$n$$所以最初：$$mdrs(n)\ge drs(n)$$---

 ## 除数 DP

 对于每个除数$d$，我们迭代所有倍数：```python
n = d * q
candidate = drs[d] + mdrs[q]
```这对应于：$$n=d\times q$$并使用_best_因式分解$q$。 

因为$q<n$，其价值是已知的。
