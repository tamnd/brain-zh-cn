[欧拉项目问题 546](https://projecteuler.net/problem=546)

 ## 解决方案

 **答案：**`215656873`让$$f_k(n)=\sum_{i=0}^{n} f_k\!\left(\left\lfloor \frac{i}{k}\right\rfloor\right), \qquad f_k(0)=1.$$我们被要求计算$$\sum_{k=2}^{10} f_k(10^{14}) \pmod{10^9+7}.$$---

 ## 1.数学分析

 定义$$F_k(x)=\sum_{n\ge 0} f_k(n)x^n.$$从复发来看，$$f_k(n)-f_k(n-1)=f_k\!\left(\left\lfloor \frac nk\right\rfloor\right) \quad (n\ge1).$$乘以$x^n$求和得到$$(1-x)F_k(x) = \sum_{n\ge0} f_k\!\left(\left\lfloor \frac nk\right\rfloor\right)x^n.$$现在按大小块对术语进行分组$k$：$$\sum_{n\ge0} f_k\!\left(\left\lfloor \frac nk\right\rfloor\right)x^n = (1+x+\cdots+x^{k-1})F_k(x^k).$$因此$$(1-x)F_k(x) = \frac{1-x^k}{1-x}F_k(x^k),$$所以$$F_k(x)=\frac{1-x^k}{(1-x)^2}F_k(x^k).$$迭代收益率$$F_k(x) = \frac1{(1-x)^2} \prod_{j\ge1}\frac1{1-x^{k^j}}.$$因此$f_k(n)$是累积的$k$-ary 配分函数。 

从块结构中获得快速分治递归：

 如果$$n=km+r,\qquad 0\le r<k,$$然后$$f_k(n) = k\sum_{i=0}^{m-1} f_k(i) + (r+1)f_k(m).$$对两者都使用记忆递归$f_k(n)$其前缀和给出$O(\log n)$-深度算法。

 ## 2.Python实现```python
MOD = 10**9 + 7

from functools import lru_cache

def solve_k(k, N):

    @lru_cache(None)
    def F(n):
        # returns f_k(n) mod MOD
        if n == 0:
            return 1

        m, r = divmod(n, k)

        return (k * S(m - 1) + (r + 1) * F(m)) % MOD

    @lru_cache(None)
    def S(n):
        # prefix sum: sum_{i=0}^n F(i)
        if n < 0:
            return 0
        if n == 0:
            return 1

        m, r = divmod(n, k)

        # sum over complete blocks
        total = 0

        for t in range(m):
            base = (k * S(t - 1) + F(t)) % MOD
            block = (k * base + (k * (k - 1) // 2) * F(t)) % MOD
            total += block

        total %= MOD

        # partial block
        base = (k * S(m - 1) + F(m)) % MOD

        partial = (
            (r + 1) * base
            + (r * (r + 1) // 2) * F(m)
        ) % MOD

        return (total + partial) % MOD

    return F(N)

N = 10**14

ans = 0
for k in range(2, 11):
    ans = (ans + solve_k(k, N)) % MOD

print(ans)
```---

 ## 3. 代码演练

 ###`F(n)`计算$f_k(n)$。 

如果$n=km+r$,$$f_k(n) = k\sum_{i=0}^{m-1} f_k(i) + (r+1)f_k(m).$$前缀和由以下提供`S(m-1)`。 

---

 ###`S(n)`计算$$S(n)=\sum_{i=0}^{n} f_k(i).$$区间被分解为大小的块$k$：$$[k t,\; kt+k-1].$$在一个街区内，$$f_k(kt+j)=A_t+jf_k(t),$$在哪里$$A_t=kS(t-1)+f_k(t).$$这使得每个块和可以以封闭形式计算。
