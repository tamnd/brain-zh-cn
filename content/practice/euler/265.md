[欧拉项目问题 265](https://projecteuler.net/problem=265)

 ## 解决方案

 **答案：**`209110240768`我们寻找长度为的所有二元循环序列$2^N$这样每个长度的二进制字$N$作为连续的顺时针子序列仅出现一次。 

这些正是顺序的二进制 **de Bruijn 循环**$N$。 

为了$N=5$，我们必须计算问题陈述中描述的所有不同编码的总和。 

---

 # 数学分析

 二进制 de Bruijn 有序循环$N$是一个循环二进制序列，其中每个可能的$N$- 位字符串只出现一次。 

有$2^N$这样的子串，所以循环长度必须是$2^N$。 

---

 ## 1. 图形解释

 定义一个有向图：

 - 顶点=所有长度的二进制字符串$N-1$- 有向边=所有长度的二进制字符串$N$一个边缘$$b_1b_2\dots b_N$$来自$$b_1b_2\dots b_{N-1}$$到$$b_2b_3\dots b_N$$每个顶点有：

 - 出度$2$- 入度$2$德布鲁因循环与该图中的欧拉循环完全对应。 

---

 ## 2. 规范表示

 该问题通过要求序列以以下开头来删除旋转重复项$$00000$$因此，我们可以将起始节点固定为全零，并生成从那里开始的所有欧拉循环。 

如果生成的循环序列是$$a_0a_1\dots a_{31}$$那么编码后的整数是$$\sum_{i=0}^{31} a_i 2^{31-i}$$---

 ## 3.DFS构建

 维护：

 - 当前$(N-1)$-位后缀
 - 访问过的集合$N$- 位串

 最初：

 - 访问过的包含$00000$- 序列以五个零开始

 每一步：

 - 附加位$0$或者$1$- 形成下一个$N$位字
 - 仅当该单词之前未出现过时才继续

 当所有$2^N$单词被访问过，我们就得到一个有效周期。 

为了$N=5$，这个搜索是完全可行的。 

---

 # Python 实现```python
from collections import defaultdict

def debruijn_sum(n):
    target = 1 << n                 # total N-bit strings
    mask = (1 << (n - 1)) - 1      # keeps last N-1 bits

    visited = {0}                  # start with 000...0 already used
    seq = [0] * n                  # initial sequence = N zeros

    total = 0

    def dfs(node):
        nonlocal total

        # If every N-bit word has appeared exactly once,
        # we have a complete de Bruijn cycle.
        if len(visited) == target:
            bits = seq[:target]
            value = int("".join(map(str, bits)), 2)
            total += value
            return

        suffix = node & mask

        # Try appending 0 or 1
        for bit in (0, 1):
            nxt = (suffix << 1) | bit

            if nxt not in visited:
                visited.add(nxt)
                seq.append(bit)

                dfs(nxt)

                seq.pop()
                visited.remove(nxt)

    dfs(0)
    return total

# Verify the example
print(debruijn_sum(3))   # should be 52

# Solve the problem
print(debruijn_sum(5))
```---

 # DFS步骤

 假设当前后缀是$(N-1)$-位数`suffix`。 

附加位`bit`创建：```python
nxt = (suffix << 1) | bit
```这是下一个$N$位字。 

如果还没有出现，我们继续递归。 

---

 # 完成

 当所有$2^N$已使用以下词语：```python
bits = seq[:target]
value = int("".join(map(str, bits)), 2)
```这会将规范的二进制表示形式转换为其整数值。

 对于$N=3$，程序返回：$$23 + 29 = 52$$匹配问题陈述。

 对于$N=5$:

 - 生成的有效周期数为$2048$- 对所有规范编码求和得出$$209110240768$$这是已知的正确的欧拉计划值。
