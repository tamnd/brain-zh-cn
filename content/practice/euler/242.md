[欧拉项目问题 242](https://projecteuler.net/problem=242)

 ## 解决方案

 **答案：**`997104142249036713`让$$f(n,k)=\#\left\{A\subseteq \{1,2,\dots,n\}:\ |A|=k,\ \sum_{a\in A} a \text{ is odd}\right\}.$$我们求三元组的数量$$[n,k,f(n,k)]$$使得所有三个量都是奇数，其中$n\le 10^{12}$。 

---

 # 第 1 步 — 表达$f(n,k)$之中$1,2,\dots,n$:

 - 奇数贡献奇校验，
 - 偶数贡献奇偶校验。 

子集具有奇数和当且仅当它包含奇数个奇数元素。 

---

 ## 案例分析$n$写：

-$o=\#\text{odd numbers}$,
 -$e=\#\text{even numbers}$。 

然后$$f(n,k)=\sum_{\substack{j\ \text{odd}}} \binom{o}{j}\binom{e}{k-j}.$$我们只关心奇偶性（奇/偶）。 

---

 # 步骤 2 — 减少模 2

 我们现在工作模数$2$。 

标准身份是$$(1+x)^{2m}\equiv (1+x^2)^m \pmod 2,$$因为所有中间二项式系数都是偶数。 

相似地，$$(1+x)^{2m+1}\equiv (1+x)(1+x^2)^m \pmod 2.$$---

 # 步骤 3 — 分离两个同余类$n$自从$n$本身必须是奇数，可以写成$$n=4r+1 \quad\text{or}\quad n=4r+3.$$还$k$一定是奇数。 

---

 ## 案例A：$n=4r+1$然后：

 - 奇数个数 =$2r+1$,
 - 偶数个数 =$2r$。 

写$$k=4s+1 \quad\text{or}\quad k=4s+3.$$的奇系数部分$$(1+x)^{2r+1}$$模数$2$是$$x(1+x^2)^r.$$偶数生成多项式是$$(1+x)^{2r}\equiv (1+x^2)^r.$$所以，$$f(4r+1,k) \equiv [x^k]\, x(1+x^2)^{2r} \pmod 2.$$但$$(1+x^2)^{2r}\equiv (1+x^4)^r \pmod2.$$因此$$f(4r+1,k) \equiv [x^{k-1}](1+x^4)^r.$$仅当该系数不为零时$k-1$可以整除$4$， IE。$$k=4s+1.$$然后$$f(4r+1,4s+1) \equiv \binom{r}{s} \pmod2.$$所以：$$f(4r+1,4s+1)\text{ is odd} \iff \binom{r}{s}\text{ is odd}.$$---

 ## 情况 B：$n=4r+3$现在：

 - 赔率 =$2r+2$,
 - 偶数 =$2r+1$。 

类似的计算给出$$f(4r+3,k)\equiv 0 \pmod2$$对于每一个奇数$k$。 

所以**当以下情况时不会出现奇数三元组$n\equiv 3\pmod4$**。 

---

 # 步骤 4 — 计算奇数二项式系数

 因此，每个奇数三元组完全对应于：$$n=4r+1,\qquad k=4s+1,$$和$$\binom{r}{s}\ \text{odd}.$$---

 ## 卢卡斯定理

 二项式系数是奇数当且仅当每个二进制数字$s$最多是对应的数字$r$。 

等效地：$$s \subseteq r \quad\text{bitwise}.$$如果$r$有$t$二进制，那么每个 1 位可以独立地是：

 - 用于$s$,
 - 或未使用。 

因此，行中奇数系数的数量$r$是$$2^{\operatorname{popcount}(r)}.$$---

 # 步骤 5 — 最终求和

 我们需要$$4r+1\le 10^{12}.$$因此$$r\le \frac{10^{12}-1}{4}=249999999999.$$所以答案是$$\sum_{r=0}^{249999999999} 2^{\operatorname{popcount}(r)}.$$---

 # 第 6 步 — 评估总和

 定义$$S(N)=\sum_{r=0}^{N}2^{\operatorname{popcount}(r)}.$$标准二进制 DP 给出：

 如果最高剩余位位置是$m$，那么所有较小的数字都会贡献$$(1+2)^m = 3^m.$$处理位$N$从上到下产生精确值。 

---

 # Python 实现```python
def count_odd_triplets(limit):
    # Largest r such that 4r + 1 <= limit
    R = (limit - 1) // 4

    # Computes:
    # S(R) = sum_{r=0}^R 2^(popcount(r))
    ans = 0

    bits = bin(R)[2:]

    # Number of 1-bits already fixed in the prefix
    ones_so_far = 0

    for i, b in enumerate(bits):
        remaining = len(bits) - i - 1

        if b == '1':
            # Put 0 here instead of 1.
            # Remaining bits are arbitrary.
            #
            # Each remaining bit contributes factor:
            #   1 (bit = 0)
            #   2 (bit = 1)
            #
            # so total factor is 3^remaining.
            ans += (2 ** ones_so_far) * (3 ** remaining)

            # Continue along the actual prefix with this bit = 1
            ones_so_far += 1

    # Include R itself
    ans += 2 ** ones_so_far

    return ans

print(count_odd_triplets(10))       # should be 5
print(count_odd_triplets(10**12))
```---

 # 代码演练

 ### 1.转换问题

 我们证明了答案等于$$\sum_{r=0}^{R}2^{\operatorname{popcount}(r)},$$在哪里$$R=\frac{10^{12}-1}{4}.$$---

 ### 2. 二进制数DP

 假设我们从左到右处理位。 

每当当前位$R$是 1：

 - 我们可以在那里放一个 0，
 - 那么剩余的位是空闲的。 

对于每个空闲位：

 - 选择 0 贡献因子$1$,
 - 选择1个贡献因素$2$。 

所以每个免费位都会做出贡献$1+2=3$。 

因此有一个块$m$免费比特贡献$3^m$。 

---

 ### 3. 复杂性

 该算法仅使用二进制长度$R$:$$O(\log R).$$为了$R<2^{38}$，这个很小。 

---

 # 样本验证

 对于$n\le 10$:$$R=\left\lfloor \frac{10-1}{4}\right\rfloor=2.$$然后$$2^{\operatorname{popcount}(0)} + 2^{\operatorname{popcount}(1)} + 2^{\operatorname{popcount}(2)} = 1+2+2=5.$$正是问题陈述中列出的五个三元组。
