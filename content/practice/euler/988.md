 # 数学分析

 让$$S=\{ax+by:x,y\ge0\}$$是由下式生成的数值半群$a,b$。 

一只青蛙在$m$攻击青蛙$n>m$当且仅当$$n-m\in S.$$因此，青蛙之间所有允许的差异必须是**不可表示的**$ax+by$。 

---

 ## 1. 不可表示的数字

 对于共素$a,b$，每个不可表示的正整数都有唯一的形式$$ab-ai-bj$$和$$1\le i\le b-1,\qquad 1\le j\le a-1,$$和$$ai+bj<ab.$$所以每个不可表示的数字对应一个格点$(i,j)$。 

为了$(a,b)=(3,5)$，不可表示的是$$7,4,2,1.$$的确：$$7=15-3-5,\quad 4=15-6-5,\quad 2=15-3-10,\quad 1=15-9-5.$$---

 ## 2. 两只青蛙什么时候可以兼容？ 

假设我们有两个不可表示的$$u=ab-ai_1-bj_1,$$

$$v=ab-ai_2-bj_2.$$然后$$u-v=a(i_2-i_1)+b(j_2-j_1).$$当两个坐标差均为非负时，该差异是可表示的：$$i_2\ge i_1,\qquad j_2\ge j_1.$$因此，当两个青蛙的格点在乘积序上不可比较时，它们恰好是兼容的。 

因此，有效的青蛙配置恰恰是偏序集中的**反链**$$(i,j)\le(i',j') \iff i\le i',\ j\le j'.$$---

 # 动态规划公式

 对于每一行$j$， 定义$$L_j=\left\lfloor\frac{ab-bj-1}{a}\right\rfloor.$$然后行$j$包含细胞$$1\le i\le L_j.$$反链每行最多可以包含一个单元格，并选择$i$-值必须严格减小为$j$增加。 

我们对行执行 DP：

 - 要么从该行中不选择任何内容；
 - 或选择一个$i$比之前选择的小。 

每个选定的单元格都会贡献重量$$ab-ai-bj.$$---

 # Python 实现```python
from functools import cache

def F(a, b):
    # L[j-1] = maximum i allowed in row j
    L = [(a*b - b*j - 1) // a for j in range(1, a)]

    @cache
    def dp(j, prev_i):
        """
        Returns:
            (count, total_sum)

        considering rows j..a-1,
        where future chosen i-values must be < prev_i.
        """

        # no more rows
        if j == a:
            return (1, 0)

        total_count, total_sum = dp(j + 1, prev_i)

        max_i = min(prev_i - 1, L[j - 1])

        for i in range(1, max_i + 1):
            count2, sum2 = dp(j + 1, i)

            weight = a*b - a*i - b*j

            total_count += count2
            total_sum += sum2 + count2 * weight

        return total_count, total_sum

    return dp(1, b)[1]

print(F(3, 5))    # 23
print(F(5, 13))   # 16336
print(F(19, 53))
```---

 # 代码演练

 递归状态为：$$dp(j,\text{prev}_i)$$含义：

 - 我们正在处理行$j$,
 - 任何选择的未来$i$必须满足$$i<\text{prev}_i.$$这保证了不可比性。 

对于每一行，我们有两个选择：

 1. 跳行；
 2. 选择一个允许的单元格。 

如果我们选择$(i,j)$，我们添加对应的不可表示数$$ab-ai-bj.$$递归累加：

 - 配置数量，
 - 所有配置中青蛙位置的总和。
