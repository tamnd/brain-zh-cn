[项目欧拉问题 60](https://projecteuler.net/problem=60)

 ## 解决方案

 **答案：**`26033`我们寻求**五个素数的最低和集**，这样对于**任何两个不同的素数**$p,q$在集合中，两个串联$$pq \quad \text{and} \quad qp$$是素数。 

例如，集合$\{3,7,109,673\}$适用于尺寸$4$，总和$792$。 

我们现在解决尺寸$5$案件。 

---

 # 数学分析

 ## 1. 作为算术的连接

 如果$a$有$d$小数位，连接$p$其次是$a$给出$$p \| a = p \cdot 10^d + a$$例子：$$7 \| 109 = 7 \cdot 10^3 + 109 = 7109$$因此，对于每一对$(p,q)$，我们必须测试：$$p \cdot 10^{\text{digits}(q)} + q$$和$$q \cdot 10^{\text{digits}(p)} + p$$为了原始性。 

---

 ## 2. 图形解释

 如果将其视为图形问题，这个问题就会变得容易得多。 

- 每个素数都是一个顶点。 
- 连接素数$p,q$如果两个串联都是素数，则有一条边。 

我们寻求一个大小为 5** 的派系（五个顶点的完全连接集），其总和最小。 

这极大地减少了搜索空间。 

---

 ## 3. 重要观察

 ### (a) 排除 2 和 5

 任何以偶数结尾的串联都是偶数。 

所以如果一个集合包含$2$，然后一些串联结束于$2$，使其复合。 

同样，以$5$可以被整除$5$。 

所以：$$2,5 \text{ cannot appear in the set}$$---

 ### (b) 高效的素性测试

 连接变得相当大，因此我们需要快速的素性测试。 

对于欧拉计划，试除最多$\sqrt n$使用预先计算的素数列表就足够了。 

---

 ## 4. 搜索策略

 我们按如下方式进行：

 1. 生成素数。 
2.建立兼容关系：$$compatible(p,q) \iff pq \text{ and } qp \text{ are prime}$$3. 使用嵌套交集（集团搜索）：

 - 选择$a$- 选择$b$兼容于$a$- 选择$c$两者兼容
 - 等

 由于交叉点迅速缩小，搜索变得可行。

 # Python 实现```python
from math import isqrt

# ------------------------------------------------------------
# Basic primality test
# ------------------------------------------------------------

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = isqrt(n)
    d = 3
    while d <= limit:
        if n % d == 0:
            return False
        d += 2

    return True

# ------------------------------------------------------------
# Concatenation helper
# ------------------------------------------------------------

def concat(a, b):
    """Concatenate integers a and b."""
    return int(str(a) + str(b))

# ------------------------------------------------------------
# Compatibility test
# ------------------------------------------------------------

def compatible(a, b):
    """
    Two primes are compatible if both concatenations
    are prime.
    """
    return is_prime(concat(a, b)) and is_prime(concat(b, a))

# ------------------------------------------------------------
# Generate primes
# ------------------------------------------------------------

def generate_primes(limit):
    """Simple sieve of Eratosthenes."""
    sieve = [True] * limit
    sieve[0] = sieve[1] = False

    for i in range(2, isqrt(limit) + 1):
        if sieve[i]:
            step = i
            start = i * i
            sieve[start:limit:step] = [False] * len(range(start, limit, step))

    return [p for p in range(limit) if sieve[p]]

# ------------------------------------------------------------
# Main search
# ------------------------------------------------------------

primes = [p for p in generate_primes(10000) if p not in (2, 5)]

# Build compatibility graph
edges = {}

for i, p in enumerate(primes):
    edges[p] = set()

    for q in primes[:i]:
        if compatible(p, q):
            edges[p].add(q)
            edges[q].add(p)

best_sum = float('inf')
best_set = None

# Clique search of size 5
for a in primes:

    for b in edges[a]:

        ab = edges[a] & edges[b]

        for c in ab:

            abc = ab & edges[c]

            for d in abc:

                abcd = abc & edges[d]

                for e in abcd:

                    s = a + b + c + d + e

                    if s < best_sum:
                        best_sum = s
                        best_set = [a, b, c, d, e]

print(best_set)
print(best_sum)
```---

 ## 派系搜索

 优化的关键是重复交集：```python
ab = edges[a] & edges[b]
```含义：

 - 两者都兼容的候选人$a$和$b$然后：```python
abc = ab & edges[c]
```含义：

 - 兼容$a,b,c$等等。 

这避免了对所有 5 元组的暴力破解。

 # 验证示例

 对于问题的例子：$$\{3,7,109,673\}$$我们验证：

 -$7 \| 109 = 7109$是素数
 -$109 \| 7 = 1097$是素数

 每对都是如此。 

他们的总和：$$3+7+109+673=792$$与声明相符。
