[欧拉项目 673 问题](https://projecteuler.net/problem=673)

 ## 解决方案

 **答案：**`700325380`让$B$是描述床布置的对合，并且$D$描述桌子布置的对合。 

- 如果学生$a,b$是室友，那么$B(a)=b$和$B(b)=a$。 
- 如果是学生$a$有私人房间，那么$B(a)=a$。 

同样对于使用的办公桌$D$。 

新的分配是一个排列$\sigma$。 

条件

 > “室友仍然是室友”

 意思是：$$B(\sigma(k))=\sigma(B(k))$$对于每一个$k$， IE。$$\sigma B = B\sigma.$$同样，办公桌伙伴保持在一起可以提供$$\sigma D = D\sigma.$$所以我们必须计算与两个对合同时通勤的排列$B,D$。 

---

 # 1. 图的结构

 考虑学生的图，其中每个顶点具有：

 - 一个“床边”（可能是一个环），
 - 一个“桌子边缘”（可能是一个环）。 

因为两者$B$和$D$是对合，每个连通分量都是以下两种类型之一：

 ## A 型 — 交替循环

 不会出现环路。 

边缘交替$B,D,B,D,\dots$，所以该分量是一个长度为偶数的周期$2m$。 

例子：$$1 \xleftrightarrow{B} 2 \xleftrightarrow{D} 3 \xleftrightarrow{B} 4 \xleftrightarrow{D} 1.$$自同构群大小：$$2m$$（旋转保留边缘颜色）。 

---

 ## B 型 — 交替路径

 至少发生一个循环。 

该组件成为一条具有交替边缘颜色的路径。 

取决于端点颜色：

 - 反思可能被允许也可能不允许，
 - 自同构群的大小是$1$或者$2$。 

更准确地说：

 - 奇数长度路径：自同构计数$=1$,
 - 具有匹配端点颜色的偶数路径：自同构计数$=2$。 

---

 # 2. 计算所有通勤排列

 任何有效的排列：

 1. 可以置换整个同构连通分量，
 2. 每个组件内部可以应用其自同构之一。 

因此，如果一个组件类型$T$- 发生$m_T$次，
 - 有自同构计数$a_T$,

 那么它的贡献就是$$a_T^{m_T}\cdot m_T!.$$所以：$$\boxed{ \prod_T a_T^{m_T}\,m_T! }$$模数$999999937$。

 # 3.Python实现```python
from collections import defaultdict

MOD = 999_999_937

def parse_pairs(filename):
    pairs = []
    with open(filename) as f:
        for line in f:
            line = line.strip()
            if line:
                a, b = map(int, line.split(","))
                pairs.append((a, b))
    return pairs

def count_permutations(n, bed_pairs, desk_pairs):
    # Build involutions
    B = list(range(n + 1))
    D = list(range(n + 1))

    for a, b in bed_pairs:
        B[a] = b
        B[b] = a

    for a, b in desk_pairs:
        D[a] = b
        D[b] = a

    visited = [False] * (n + 1)

    # Count component types
    type_count = defaultdict(int)
    type_aut = {}

    for start in range(1, n + 1):
        if visited[start]:
            continue

        # DFS component
        stack = [start]
        visited[start] = True
        comp = []

        while stack:
            v = stack.pop()
            comp.append(v)

            for u in (B[v], D[v]):
                if not visited[u]:
                    visited[u] = True
                    stack.append(u)

        k = len(comp)

        # Does component contain a loop?
        has_loop = any(B[v] == v or D[v] == v for v in comp)

        if not has_loop:
            # alternating cycle
            key = ("C", k)
            aut = k
        else:
            # alternating path
            if k % 2 == 1:
                # asymmetric
                key = ("P", k, "odd")
                aut = 1
            else:
                # possible reflection symmetry
                endpoint_type = "mixed"

                for v in comp:
                    if B[v] == v and D[v] != v:
                        endpoint_type = "B"
                        break
                    if D[v] == v and B[v] != v:
                        endpoint_type = "D"
                        break

                key = ("P", k, endpoint_type)
                aut = 2

        type_count[key] += 1
        type_aut[key] = aut

    # factorials
    fact = [1] * (n + 1)
    for i in range(2, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    ans = 1

    for key, m in type_count.items():
        ans = ans * pow(type_aut[key], m, MOD) % MOD
        ans = ans * fact[m] % MOD

    return ans

# -------------------------
# Verification examples
# -------------------------

# n = 4 example
beds = [(2, 3)]
desks = [(1, 3), (2, 4)]
print(count_permutations(4, beds, desks))
# 2

# n = 6 example
beds = [(1, 2), (3, 4), (5, 6)]
desks = [(3, 6), (4, 5)]
print(count_permutations(6, beds, desks))
# 8
```---

 # 4. 代码演练

 ## 构建内卷```python
B = list(range(n + 1))
D = list(range(n + 1))
```最初，每个学生都映射到自己（私人房间/单人桌子）。 

然后列出的每对交换：```python
B[a] = b
B[b] = a
```---

 ## 寻找连接的组件

 生成的图表$B$- 边缘和$D$-edges 通过 DFS 进行探索。 

每个连接的分量确定一个独立的对称因子。 

---

 ## 检测组件类型```python
has_loop = any(B[v] == v or D[v] == v for v in comp)
```- 无循环$\Rightarrow$交替循环，
 - 否则交替路径。 

---

 ## 计算自同构

 长度周期$k$：$$a_T = k.$$对称路径：$$a_T = 2.$$非对称路径：$$a_T = 1.$$---

 ## 排列相同的组件

 如果出现组件类型$m$有时，它们可以任意排列：$$m!$$乘以答案。
