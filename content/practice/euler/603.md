[欧拉项目 603 问题](https://projecteuler.net/problem=603)

 ## 解决方案

 **答案：**`879476477`设数字/字符串的十进制数字为$d_1,d_2,\dots,d_N$。 

我们必须计算$$S(n)=\sum_{\text{all contiguous substrings}} \text{(substring value)}.$$对于问题：

 -$P(n)$= 第一个的串联$n$素数,
 -$C(n,k)$=$P(n)$重复$k$次，
 - 必需：$$S(C(10^6,10^{12})) \pmod{10^9+7}.$$---

 # 1.数学分析

 ## 1.1 一位数的贡献

 修正一个数字$d_i$在位置$i$（1-从左侧开始索引）。 

假设一个子串从某个位置开始$\le i$并结束于$j\ge i$。 

在该子串内，$d_i$贡献$$d_i \cdot 10^{j-i}.$$起始点有多少种选择？ 

确切地$i$选择。 

所以总贡献为$d_i$是$$d_i \cdot i \sum_{j=i}^{N} 10^{j-i}.$$让$t=j-i$。 然后$$\sum_{t=0}^{N-i}10^t = \frac{10^{N-i+1}-1}{9}.$$所以$$S = \sum_{i=1}^{N} d_i\, i \,\frac{10^{N-i+1}-1}{9}.$$所以$$S = \frac1{9} \left( 10^{N+1}\sum_{i=1}^{N} d_i i 10^{-i} - \sum_{i=1}^{N} d_i i \right).$$现在一切都被简化为加权数字和。 

---

 # 1.2 重复块

 设数字串为$P(n)$有长度$L$, 带数字$$a_1,a_2,\dots,a_L.$$我们重复这个块$k$次。 

副本中的数字$r$（在哪里$0\le r<k$) 和内部位置$i$具有全球地位$$rL+i.$$定义$$q=10^{-1}\pmod M, \qquad M=10^9+7.$$然后$$10^{- (rL+i)} = q^{rL+i}.$$我们需要$$T = \sum_{r=0}^{k-1}\sum_{i=1}^{L} a_i(rL+i)q^{rL+i}.$$因素：$$T = \sum_{r=0}^{k-1} q^{rL} \left( rL \sum_i a_i q^i + \sum_i a_i i q^i \right).$$定义$$B=\sum_i a_i q^i, \qquad C=\sum_i a_i i q^i.$$然后$$T = BL\sum_{r=0}^{k-1} r x^r + C\sum_{r=0}^{k-1} x^r,$$在哪里$$x=q^L.$$我们还需要$$U=\sum d_i i = kE + DL\frac{k(k-1)}2,$$在哪里$$D=\sum_i a_i, \qquad E=\sum_i a_i i.$$因此$$S = \frac{ 10^{N+1}T-U }{9}, \qquad N=Lk.$$---

 # 1.3 几何和

 我们使用$$G_0=\sum_{r=0}^{k-1}x^r = \frac{1-x^k}{1-x},$$和$$G_1=\sum_{r=0}^{k-1} r x^r = \frac{x(1-kx^{k-1}+(k-1)x^k)}{(1-x)^2}.$$所以$$T = BLG_1 + CG_0.$$现在一切都可以计算模$M$。 

---

 # 2.Python实现```python
MOD = 10**9 + 7

INV9 = pow(9, MOD - 2, MOD)
INV10 = pow(10, MOD - 2, MOD)
INV2 = pow(2, MOD - 2, MOD)

N_PRIMES = 10**6
K = 10**12

# ------------------------------------------------------------
# Sieve for first 1,000,000 primes
# ------------------------------------------------------------

import math

# Standard upper bound for nth prime
LIMIT = int(
    N_PRIMES * (
        math.log(N_PRIMES) +
        math.log(math.log(N_PRIMES))
    )
) + 100

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0] = sieve[1] = 0

for p in range(2, int(math.isqrt(LIMIT)) + 1):
    if sieve[p]:
        start = p * p
        sieve[start:LIMIT + 1:p] = b"\x00" * (
            ((LIMIT - start) // p) + 1
        )

# ------------------------------------------------------------
# Build digit statistics for P(10^6)
# ------------------------------------------------------------

L = 0

B = 0
C = 0
D = 0
E = 0

qpow = 1
count = 0

for p in range(2, LIMIT + 1):
    if sieve[p]:
        count += 1

        for ch in str(p):
            d = ord(ch) - 48

            L += 1

            # q^L
            qpow = (qpow * INV10) % MOD

            B = (B + d * qpow) % MOD
            C = (C + d * L * qpow) % MOD

            D = (D + d) % MOD
            E = (E + d * L) % MOD

        if count == N_PRIMES:
            break

# ------------------------------------------------------------
# Geometric sums
# ------------------------------------------------------------

x = pow(INV10, L, MOD)

den = (1 - x) % MOD
den_inv = pow(den, MOD - 2, MOD)

G0 = (1 - pow(x, K, MOD)) * den_inv
G0 %= MOD

G1 = (
    x *
    (1 - K * pow(x, K - 1, MOD) + (K - 1) * pow(x, K, MOD))
)

G1 %= MOD

G1 = (G1 * den_inv * den_inv) % MOD

# ------------------------------------------------------------
# Assemble formula
# ------------------------------------------------------------

T = (B * L % MOD) * G1
T += C * G0
T %= MOD

U = (
    (K % MOD) * E
    + D * (L % MOD) % MOD
      * ((K - 1) % MOD) % MOD
      * (K % MOD) % MOD
      * INV2
)
U %= MOD

# exponent reduced modulo MOD-1 by Fermat
N_mod = (L % (MOD - 1)) * (K % (MOD - 1))
N_mod %= (MOD - 1)

answer = (
    (pow(10, N_mod + 1, MOD) * T - U)
    * INV9
) % MOD

print(answer)
```---

 # 3. 代码演练

 ## 筛分部分

 我们使用标准字节数组筛生成前一百万个素数。 

第百万个素数是$15{,}485{,}863$，所以上限附近$1.65\times10^7$就足够了。 

---

 ## 构建数字统计

 当我们逐位连接素数时，我们保持：

 -$L$: 总位数，
 -$B=\sum a_i q^i$,
 -$C=\sum a_i i q^i$,
 -$D=\sum a_i$,
 -$E=\sum a_i i$。 

我们从不构造这个巨大的数字本身。 

---

 ## 几何和

 因为$C(n,k)$是一个重复块，所有重复复制效果都会崩溃为：$$G_0=\sum x^r, \qquad G_1=\sum r x^r.$$两者均计算为$O(\log k)$使用模幂计算时间。 

---

 ## 最终组装

 我们计算$$S=\frac{10^{N+1}T-U}{9}\pmod M.$$自从$N=Lk$是巨大的，我们减少指数模$M-1$使用费马定理。
