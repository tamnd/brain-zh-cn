[欧拉项目问题 26](https://projecteuler.net/problem=26)

 ## 解决方案

 **答案：**`983`对于一小部分$1/d$，十进制展开式中循环的长度由乘法顺序决定$10 \pmod d$，去除因素后$2$和$5$（因为这些仅有助于终止小数）。 

对于总理$d$（以外$2,5$），循环长度除以$d-1$。 最大化下的循环$1000$，我们寻找$d<1000$且周期最长。 

一种简洁的方法是模拟长除法：跟踪到目前为止看到的余数。 一旦余数重复，小数点就开始循环，循环长度就是出现次数之间的距离。 

### Python代码```python
def cycle_length(d):
    seen = {}
    remainder = 1 % d
    position = 0

    while remainder != 0 and remainder not in seen:
        seen[remainder] = position
        remainder = (remainder * 10) % d
        position += 1

    if remainder == 0:
        return 0  # terminating decimal
    return position - seen[remainder]

best_d = 0
max_cycle = 0

for d in range(2, 1000):
    length = cycle_length(d)
    if length > max_cycle:
        max_cycle = length
        best_d = d

print(best_d)
```### 心理痕迹/正确性检查

 - 小案例：

 -$1/3 = 0.(3)$→ 周期长度$1$-$1/7 = 0.(142857)$→ 周期长度$6$- 该算法正确检测重复的余数并测量周期长度。 
- 检查附近的值$1000$，最大循环出现在$d=983$，其周期长度为$982$（完全重复素数）。 

**答案：983**
