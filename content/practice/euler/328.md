[欧拉项目问题 328](https://projecteuler.net/problem=328)

 ## 解决方案

 **答案：**`260511850222`让$$F(a,b)$$表示识别区间中隐藏数字所需的最小最坏情况成本$[a,b]$。 

如果我们首先问$x$（$a\le x\le b$），那么：

 - 如果隐藏的数字较低，我们仍然必须解决$[a,x-1]$,
 - 如果更高，我们必须解决$[x+1,b]$,
 - 无论哪种情况我们都已经支付了费用$x$。 

所以$$F(a,b) = \min_{x\in[a,b]} \left( x+\max(F(a,x-1),F(x+1,b)) \right).$$所需的函数是$$C(n)=F(1,n).$$对于较小的值：$$C(1)=0,\quad C(2)=1,\quad C(3)=2,\quad C(8)=12.$$直接动态程序对于$n=200000$，因为这需要$O(n^3)$在所有间隔内工作。 

---

 # 关键结构洞察

 为了获得最佳发挥，第一个问题始终非常接近区间的上限。 

如果第一个猜测是$k$，然后是右分支$[k+1,n]$由几乎完整的二元决策树处理。 

这些“完整树”成本可以用仿射形式表示$$m\cdot a + c$$对于开始于的间隔$a$。 

这使得右侧成本能够在以下情况下进行评估：$O(1)$。 

根据经验（并且可证明），最佳距离$$d(n)=n-k(n)$$仅改变接近 2 的幂，因此只需为每个测试一小部分候选主元$n$。 

这将计算时间减少到基本上是线性的。

 # Python 实现```python
from bisect import bisect_left
from functools import lru_cache

# Numbers of the form 2^t - 1
G = []
x = 1
while x < 400000:
    G.append(x)
    x = x * 2 + 1

@lru_cache(None)
def complete_coeff(L):
    """
    Return (m, c) such that the complete-tree strategy
    on an interval [a, a+L] has worst-case cost:

        m*a + c
    """

    if L <= 0:
        return (0, 0)

    if L == 1:
        return (1, 0)

    if L == 2:
        return (1, 1)

    idx = bisect_left(G, L)
    t = G[idx - 1]

    # Pivot offset
    d = min(t, L - (t - 1) // 2)

    left_len = d - 1
    right_len = L - d - 1

    m1, c1 = complete_coeff(left_len)
    m2, c2 = complete_coeff(right_len)

    right_const = c2 + m2 * (d + 1)

    # Dominating branch
    if m1 > m2:
        md, cd = m1, c1
    elif m2 > m1:
        md, cd = m2, right_const
    else:
        if c1 >= right_const:
            md, cd = m1, c1
        else:
            md, cd = m2, right_const

    return (md + 1, d + cd)

def complete_cost(lo, hi):
    L = hi - lo
    m, c = complete_coeff(L)
    return m * lo + c

def solve(limit=200000):

    C = [0] * (limit + 1)

    # Small exact values
    seed = {
        1: 0,
        2: 1,
        3: 2,
        4: 4,
        5: 6,
        6: 8
    }

    for n, v in seed.items():
        if n <= limit:
            C[n] = v

    if limit <= 6:
        return sum(C[1:limit + 1])

    # Current optimal distance n-k
    dist = 3

    # Candidate perturbations
    q = [0]
    p = 4
    while p <= 131072:
        q.append(p)
        p *= 2

    i = 2

    total_sum = sum(C[1:7])

    for n in range(7, limit + 1):

        if dist > 4 ** i:
            i += 1

        best_cost = None
        best_dist = None

        for delta in q[:i]:

            k = n - dist - delta

            if not (0 < k < n):
                continue

            left = C[k - 1]
            right = complete_cost(k + 1, n)

            worst = max(left, right)

            cost = k + worst

            if best_cost is None or cost < best_cost:
                best_cost = cost
                best_dist = dist + delta

        C[n] = best_cost
        dist = best_dist

        total_sum += best_cost

    return total_sum

print(solve(100))      # 17575
print(solve(200000))

---

 ###`complete_coeff(L)`这会在长度间隔内递归计算完整树策略的仿射公式$L$。 

我们不是单独重新计算每个子树，而是通过以下方式记忆结果：```python
@lru_cache(None)
```---

 ###`complete_cost(lo, hi)`计算具体区间的仿射表达式。 

---

 ### 主要DP

 对于每个$n$:

 - 只尝试一小部分候选枢轴，
 - 计算$$k+\max(C(k-1),\text{right-cost})$$- 取最小值。 

由于最优枢轴移动缓慢，因此仅测试对数数量的候选。
