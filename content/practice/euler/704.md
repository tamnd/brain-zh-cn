[欧拉项目704问题](https://projecteuler.net/problem=704)

 ## 解决方案

 **答案：**`501985601490518144`使用库默尔定理：$$g(n,m)=v_2\!\binom{n}{m}$$等于加法时的进位数$m$和$n-m$以二进制形式。 

当我们强制进位通过最长可能的 1 后缀时，就会出现最大可能的进位数。$n$。 这给出了$$F(n)=\lfloor \log_2 n \rfloor - v_2(n+1) + \mathbf 1_{\,n+1\text{ is a power of }2}.$$等效地：

 - 如果$n\neq 2^k-1$,$$F(n)=\lfloor \log_2 n \rfloor-v_2(n+1),$$- 和$F(2^k-1)=0$。 

所以$$S(N)=\sum_{n=1}^N \lfloor \log_2 n \rfloor -\sum_{n=1}^N v_2(n+1) +\#\{k:2^k-1\le N\}.$$现在计算每一项。 

---

 ### 1. 下限对数之和

 让$L=\lfloor \log_2 N\rfloor$。$$\sum_{n=1}^N \lfloor \log_2 n \rfloor = \sum_{k=0}^{L-1} k\,2^k +L(N-2^L+1).$$使用$$\sum_{k=0}^{L-1} k2^k=(L-2)2^L+2,$$我们得到$$A=(L-2)2^L+2+L(N-2^L+1).$$---

 ### 2.总和$v_2(n+1)$

$$\sum_{n=1}^N v_2(n+1) = \sum_{m=2}^{N+1} v_2(m) = v_2((N+1)!).$$根据勒让德公式，$$v_2((N+1)!)=(N+1)-s_2(N+1),$$在哪里$s_2(x)$是二进制数字和。 

所以$$B=(N+1)-s_2(N+1).$$---

 ### 3.梅森数的计数$$C=\left\lfloor \log_2(N+1)\right\rfloor.$$- -

为了$N=10^{16}$:

 -$L=\lfloor \log_2(10^{16})\rfloor=53$,
 -$s_2(10^{16}+1)=27$。 

替换：$$S(10^{16}) = 501985601490518144.$$一个紧凑的 Python 实现是：```python
def S(N):
    L = N.bit_length() - 1

    A = ((L - 2) << L) + 2 + L * (N - (1 << L) + 1)
    B = (N + 1) - bin(N + 1).count("1")
    C = (N + 1).bit_length() - 1

    return A - B + C

print(S(10**16))
```这也重现了给定的检查：

 -$S(100)=389$-$S(10^7)=203222840$所以推导是一致的。 

**答案：501985601490518144**
