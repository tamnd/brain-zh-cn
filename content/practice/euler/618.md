[欧拉项目 618 问题](https://projecteuler.net/problem=618)

 ## 解决方案

 **答案：**`634212216`让$$f(n)=\text{sum of the prime factors of }n\text{ (with multiplicity)}.$$我们被要求计算$$S(k)=\sum_{f(n)=k} n,$$然后评估$$\sum_{k=2}^{24} S(F_k),$$在哪里$F_k$是斐波那契数列。 

我们只需要**最后九位数字**，因此所有计算都可以进行模运算$$10^9.$$---

 # 1.数学分析

 ## 素因子分解观点

 每个正整数都有唯一的因式分解$$n=\prod p_i^{e_i}.$$如果$$f(n)=\sum e_i p_i,$$然后素数的每个副本$p$贡献：

 -$+p$到素因子和，
 - 并将数字本身乘以$p$。 

所以每次出现素数$p$其行为就像一个“构建块”：

 - 重量$p$,
 - 价值乘数$p$。 

---

 ## 生成函数

 对于固定素数$p$，我们可以使用它：

 - 零次，
 - 一次，
 - 两次，
 - 等

 因此它的贡献是$$1 + p x^p + p^2 x^{2p} + p^3 x^{3p} + \cdots = \frac1{1-px^p}.$$乘以所有素数给出$$\prod_{p\text{ prime}} \frac1{1-px^p}.$$系数为$x^k$正是：$$S(k).$$所以，$$S(k)=[x^k]\prod_{p}\frac1{1-px^p}.$$---

 # 2.动态规划推导

 该生成函数直接导致无界背包 DP。 

让$$dp[s]=S(s).$$初始化：$$dp[0]=1$$（空产品贡献数量$1$）。 

对于每个素数$p$，通过重复添加副本来扩展$p$:$$dp[s] \mathrel{+}= p \cdot dp[s-p].$$为什么？ 

计入的任意数字$dp[s-p]$可以获得多一个因素$p$:

 - 其素因子和增加$p$,
 - 数字本身乘以$p$。 

因此：```python
new_value = p * old_number
```这给出了上面的递归式。 

因为素数可以被无限次地重复使用，所以我们迭代$s$向上。 

---

 # 3. 所需的斐波那契范围

 我们需要：$$F_{24}=46368.$$所以我们只需要素数$46368$，并且 DP 达到该极限。 

---

 # 4.Python实现```python
from sympy import primerange

MOD = 10**9

# ------------------------------------------------------------
# Compute Fibonacci numbers F1..F24
# ------------------------------------------------------------
F = [0, 1, 1]   # dummy 0-index, then F1=1, F2=1

for _ in range(3, 25):
    F.append(F[-1] + F[-2])

MAXF = F[24]

# ------------------------------------------------------------
# dp[s] = S(s) modulo 1e9
# ------------------------------------------------------------
dp = [0] * (MAXF + 1)
dp[0] = 1

# ------------------------------------------------------------
# Unbounded knapsack over primes
# ------------------------------------------------------------
for p in primerange(2, MAXF + 1):

    for s in range(p, MAXF + 1):
        dp[s] = (dp[s] + p * dp[s - p]) % MOD

# ------------------------------------------------------------
# Sum S(F_k) for k = 2..24
# ------------------------------------------------------------
answer = 0

for k in range(2, 25):
    answer += dp[F[k]]

answer %= MOD

print(answer)
```---

 # 5. 代码演练

 ## 斐波那契生成```python
F = [0, 1, 1]
```商店：

 -$F_1=1$-$F_2=1$然后我们通过构建$F_{24}$。 

---

 ## DP 含义```python
dp[s]
```代表：$$S(s)\pmod{10^9}.$$初始化：```python
dp[0] = 1
```对应于空因式分解。 

---

 ## 质数转换

 对于每个素数$p$:```python
dp[s] += p * dp[s-p]
```如果一个数字有助于$S(s-p)$，乘以$p$:

 - 将其质因数和增加$p$,
 - 将数字乘以$p$。 

因此它有助于$S(s)$。 

---

 # 6.小例子验证

 问题指出：$$S(5)=5+6=11.$$的确：

-$5$有素因数和$5$,
 -$6=2\cdot3$有素因数和$2+3=5$。 

DP转载：```python
dp[5] = 11
```还：$$S(8)=15+16+18=49.$$DP 给出：```python
dp[8] = 49
```与声明相符。
