[欧拉项目问题 158](https://projecteuler.net/problem=158)

 ## 解决方案

 **答案：**`409511334375`我们想要计算字符串的长度$n$由不同的字母组成，因此有 **恰好一个** 位置$i$和$$s_i < s_{i+1}.$$也就是说，恰好是一次“上升”。 

---

 # 第 1 步：重新表述问题

 选择任意$n$不同的字母$26$- 字母表。 

一旦选择了字母，它们的实际值就不再重要了——只有它们的相对顺序很重要。 

因此，在对所选字母进行排序后，我们可以重新标记它们$$1,2,\dots,n.$$现在问题变成：

 > 有多少种排列$1,\dots,n$正好有一次攀登吗？ 

这是一个经典的欧拉数问题。 

欧拉数$$A(n,k)$$计算排列$n$元素正好$k$攀登。 

我们需要$$A(n,1).$$标准身份给出：$$A(n,1)=2^n-n-1.$$所以，$$p(n)=\binom{26}{n}(2^n-n-1).$$任务是最大化这个$1\le n\le 26$。 

---

 # 第二步：在样本上验证公式$n=3$问题陈述说答案应该是$10400$。 

我们计算：$$A(3,1)=2^3-3-1=4.$$确实，其中$3!=6$排列：

 - 123 → 2 次攀登
 - 132 → 1 次上升
 - 213 → 1 次上升
 - 231 → 1 次上升
 - 312 → 1 次上升
 - 321 → 0 次攀登

 正好有四种排列有一次上升。 

现在选择 3 个字母：$$\binom{26}{3}=2600.$$因此$$p(3)=2600 \times 4 = 10400,$$与声明相符。 

---

 # 第三步：Python实现```python
from math import comb

# Eulerian number A(n,1) = 2^n - n - 1
# counts permutations of n elements with exactly 1 ascent

best = 0

for n in range(1, 27):

    # number of permutations with exactly one ascent
    eulerian_1 = 2**n - n - 1

    # choose which n letters are used
    p = comb(26, n) * eulerian_1

    if p > best:
        best = p

print(best)
```---
