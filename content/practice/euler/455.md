[欧拉项目 455 问题](https://projecteuler.net/problem=455)

 ## 解决方案

 **答案：**`450186511399999`我们寻求函数$$f(n)=\max\{x<10^9 : n^x \equiv x \pmod{10^9}\},$$和$f(n)=0$如果没有这样的$x$存在。 

我们必须计算$$\sum_{n=2}^{10^6} f(n).$$---

 # 1.数学分析

 我们正在解决同余问题$$n^x \equiv x \pmod{10^9}.$$自从$10^9 = 2^9 5^9$，这是一个以复合模为模的定点问题。 

关键的观察是地图$$T(x)=n^x \pmod{10^9}$$迭代时非常快速地收敛到固定点。 

---

 ## 定点迭代

 假设我们定义$$x_{k+1}=n^{x_k}\pmod{10^9}, \qquad x_0=1.$$根据经验（并且可以通过$2$-adic和$5$-adic lift)，这个序列非常快地稳定下来：$$x_{k+1}=x_k.$$一旦稳定下来，我们就有$$x=n^x \pmod{10^9},$$所以$x$正是一个有效的解决方案。 

此外，对于这个模数，迭代收敛到下面的_最大_固定点$10^9$。 

---

 ## 为什么能被 10 整除的数为零

 如果$10\mid n$，那么对于足够大的指数，$$n^x \equiv 0 \pmod{2^9} \quad\text{and}\quad n^x \equiv 0 \pmod{5^9}.$$因此$$n^x \equiv 0 \pmod{10^9}.$$一个固定点需要$$x\equiv 0 \pmod{10^9},$$但$0\le x<10^9$，所以唯一的可能是$x=0$，它被排除，因为问题要求一个正整数。 所以：$$f(n)=0 \qquad (10\mid n).$$---

 ## 实例验证

 ### 示例 1：$n=4$迭代：$$1 \to 4 \to 256 \to 719156736 \to \cdots \to 411728896.$$最终：$$4^{411728896}\equiv 411728896 \pmod{10^9}.$$因此$$f(4)=411728896.$$---

 ### 示例 2：$n=157$迭代收敛到$$743757,$$确实$$157^{743757}\equiv 743757 \pmod{10^9}.$$所以$$f(157)=743757.$$---

 # 2.Python实现```python
MOD = 10**9

def f(n):
    """
    Compute the largest x < 10^9 such that
        n^x ≡ x (mod 10^9)
    using fixed-point iteration.
    """

    # Numbers divisible by 10 have no positive solution
    if n % 10 == 0:
        return 0

    x = 1

    while True:
        nx = pow(n, x, MOD)

        if nx == x:
            return x

        x = nx

def solve(limit=10**6):
    total = 0

    for n in range(2, limit + 1):
        total += f(n)

    return total

# Verification against the example in the statement
check = sum(f(n) for n in range(2, 1001))
print(check)   # 442530011399

# Final answer
print(solve())
```---
