[项目欧拉问题 804](https://projecteuler.net/problem=804)

 ## 解决方案

 **答案：**`4921370551019052`让$$Q(x,y)=x^2+xy+41y^2.$$自从$g(n)$计算整数对的数量$(x,y)$和$Q(x,y)=n$，我们有$$T(N)=\sum_{n=1}^N g(n)$$这正是满足以下条件的整数格点数$$x^2+xy+41y^2 \le N,$$排除$(0,0)$（自从$n\ge 1$）。 

重写二次形式：$$4Q=(2x+y)^2+163y^2.$$因此我们计算整数对$(x,y)$这样$$(2x+y)^2+163y^2\le 4N.$$对于固定的$y$， 让$$r=\left\lfloor \sqrt{4N-163y^2}\right\rfloor.$$然后$t=2x+y$必须满足$|t|\le r$并具有相同的奇偶性$y$。 这样的数量$t$是$$r + \mathbf{1}_{r\equiv y \pmod 2}.$$总结所有有效的$y$给出一个$O(\sqrt N)$算法：```python
from math import isqrt

def T(N):
    M = 4 * N
    ymax = isqrt(M // 163)

    total = -1  # exclude (0,0)

    for y in range(ymax + 1):
        r = isqrt(M - 163 * y * y)
        count = r + ((r & 1) == (y & 1))

        total += count if y == 0 else 2 * count

    return total

print(T(10**3))   # 474
print(T(10**6))   # 492128
print(T(10**16))
```这将重现给定的检查：

 -$T(10^3)=474$-$T(10^6)=492128$并计算：$$T(10^{16}) = 4921370551019052.$$**答案：4921370551019052**
