[欧拉项目 377 问题](https://projecteuler.net/problem=377)

 ## 解决方案

 **答案：**`732385277`让

-$c(n)$= 不带零的正整数个数和数字和$n$,
 -$f(n)$= 所有这些整数的总和。 

我们被要求$$\sum_{i=1}^{17} f(13^i) \pmod{10^9}.$$---

 # 1.数学分析

 没有零位和数字和的数字$n$正是来自的数字序列$\{1,\dots,9\}$其总和是$n$。 

所以问题本质上是关于$n$使用零件$1$–$9$。 

---

 ## 计数序列：递归$c(n)$每个有效数字的位数和$n$以某个数字结尾$d\in\{1,\dots,9\}$。 

删除最后一位数字留下有效的数字总和$n-d$。 

所以，$$c(n)=\sum_{d=1}^{9} c(n-d),$$具有初始条件$$c(0)=1,\qquad c(n)=0\text{ for }n<0.$$对于较小的值：$$c(1)=1,\; c(2)=2,\; c(3)=4,\; c(4)=8,\; c(5)=16,$$这与有的陈述相匹配$16$这些数字的数字和$5$。 

---

 ## 重复发生$f(n)$认为$x$是一个具有数字和的有效数字$n-d$。 

追加数字$d$产生$$10x+d.$$总结所有可能性得出：$$f(n)=\sum_{d=1}^{9} \left( 10f(n-d)+d\,c(n-d) \right).$$重新排列：$$f(n) = 10\sum_{d=1}^{9} f(n-d) + \sum_{d=1}^{9} d\,c(n-d).$$出租$k=n-d$,$$f(n) = 10\sum_{k=n-9}^{n-1} f(k) + \sum_{k=n-9}^{n-1} (n-k)c(k).$$这是顺序的线性递推$9$。 

---

 ## 示例验证$n=5$使用递归：$$f(5) = 10(f(4)+f(3)+f(2)+f(1)+f(0)) + (1c(4)+2c(3)+3c(2)+4c(1)+5c(0)).$$使用$$f(0)=0,\quad f(1)=1,\quad f(2)=13,\quad f(3)=147,\quad f(4)=1625,$$和$$c(0)=1,\; c(1)=1,\; c(2)=2,\; c(3)=4,\; c(4)=8,$$我们得到$$f(5)=17891,$$完全按照给定的。 

---

 # 2. 矩阵公式

 因为$13^{17}$是巨大的，直接DP是不可能的。 

我们使用矩阵求幂。 

定义状态向量$$V(n)= \begin{bmatrix} f(n)\\ f(n-1)\\ \vdots\\ f(n-8)\\ c(n)\\ c(n-1)\\ \vdots\\ c(n-8) \end{bmatrix}.$$这是一个$18$维向量。 

递归是线性的，所以存在$18\times18$矩阵$M$这样$$V(n+1)=MV(n).$$然后$$V(N)=M^{N-8}V(8).$$二进制求幂计算如下$O(\log N)$。 

所有计算均以模进行$10^9$。 

---

 # 3.Python实现```python
MOD = 10**9

# ------------------------------------------------------------
# Build initial values c(n), f(n) for n = 0..8
# ------------------------------------------------------------

c = [0] * 9
f = [0] * 9

c[0] = 1

# c(n) recurrence
for n in range(1, 9):
    c[n] = sum(c[max(0, n - 9):n])

# f(n) recurrence
for n in range(1, 9):
    total = 0

    for d in range(1, 10):
        if n - d >= 0:
            total += 10 * f[n - d] + d * c[n - d]

    f[n] = total

# ------------------------------------------------------------
# Build the 18x18 transition matrix
# ------------------------------------------------------------

SIZE = 18

M = [[0] * SIZE for _ in range(SIZE)]

# First row: recurrence for f(n+1)
for j in range(9):
    M[0][j] = 10
    M[0][9 + j] = 9 - j

# Shift rows for f
for i in range(1, 9):
    M[i][i - 1] = 1

# Recurrence for c(n+1)
for j in range(9):
    M[9][9 + j] = 1

# Shift rows for c
for i in range(10, 18):
    M[i][i - 1] = 1

# ------------------------------------------------------------
# Matrix multiplication
# ------------------------------------------------------------

def mat_mul(A, B):
    C = [[0] * SIZE for _ in range(SIZE)]

    for i in range(SIZE):
        for k in range(SIZE):
            if A[i][k]:
                aik = A[i][k]

                for j in range(SIZE):
                    C[i][j] = (C[i][j] + aik * B[k][j]) % MOD

    return C

# ------------------------------------------------------------
# Matrix exponentiation
# ------------------------------------------------------------

def mat_pow(M, e):
    # Identity matrix
    R = [[0] * SIZE for _ in range(SIZE)]

    for i in range(SIZE):
        R[i][i] = 1

    A = M

    while e > 0:
        if e & 1:
            R = mat_mul(R, A)

        A = mat_mul(A, A)
        e >>= 1

    return R

# ------------------------------------------------------------
# Multiply matrix by vector
# ------------------------------------------------------------

def mat_vec_mul(A, v):
    out = [0] * SIZE

    for i in range(SIZE):
        s = 0

        for j in range(SIZE):
            s += A[i][j] * v[j]

        out[i] = s % MOD

    return out

# ------------------------------------------------------------
# Initial state V(8)
# ------------------------------------------------------------

state = (
    f[8::-1] +   # f(8),...,f(0)
    c[8::-1]     # c(8),...,c(0)
)

# ------------------------------------------------------------
# Compute f(N)
# ------------------------------------------------------------

def F(N):
    if N <= 8:
        return f[N]

    P = mat_pow(M, N - 8)
    result = mat_vec_mul(P, state)

    return result[0]

# ------------------------------------------------------------
# Final summation
# ------------------------------------------------------------

answer = 0

for i in range(1, 18):
    answer = (answer + F(13**i)) % MOD

print(answer)
```---

 # 4. 代码演练

 ### 初始DP

 我们首先计算：

 -$c(n)$：有效数字串的数量，
 -$f(n)$：所有有效数字的总和。 

例如：$$f(5)=17891,$$匹配问题陈述。 

---

 ### 转移矩阵

 矩阵存储：

 - 最后 9 个值$f$,
 - 最后 9 个值$c$。 

每次乘法都会前进$n$1.

 ---

 ### 快速求幂

 自从$13^{17}\approx 8.65\times10^{18}$，我们使用二进制求幂：$$M^N$$仅在$O(\log N)$矩阵乘法。
