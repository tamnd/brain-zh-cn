[欧拉项目问题 358](https://projecteuler.net/problem=358)

 ## 解决方案

 **答案：**`3284144505`让$N$是循环数。 关于循环数的一个经典事实是：

 - 每个循环数都来自循环小数$1/p$， 在哪里$p$是一个素数，其中$10$是原根模$p$（**完整的重复素数**）。 
- 循环数是$1/p$:$$N=\frac{10^{p-1}-1}{p}$$恰好与$p-1$数字。 

例如：$$\frac{1}{7}=0.\overline{142857}$$给出循环数$142857$。 

---

 ### 第 1 步：使用最左边的数字

 我们被告知十进制扩展开始：$$0.00000000137\cdots$$因此$$\frac{1}{p} \in \left[ 1.37\times 10^{-9}, 1.38\times 10^{-9} \right)$$所以$$\frac{10^{11}}{138} < p \le \frac{10^{11}}{137}.$$这给出：$$724\,637\,681 < p < 729\,927\,007.$$---

 ### 步骤 2：使用最后五位数字

 循环数结束于$56789$。 

自从$$pN = 10^{p-1}-1,$$我们有模数$100000$:$$p\cdot 56789 \equiv -1 \pmod{100000}.$$的模逆$56789$模数$100000$给出：$$p \equiv 9891 \pmod{100000}.$$搜索上面的区间仅给出三个候选：$$725509891,\quad 726509891,\quad 729809891.$$现在施加完整的 retend 条件（即$10$有订单$p-1$模组$p$）：

 -$725509891$: 不循环
 -$726509891$: 不循环
 -$729809891$: 循环 ✓

 因此$$p = 729809891.$$---

 ### 步骤 3：数字总和

 对于完整的repend Prime$p$，重复的长度$p-1$，根据米迪定理，后半部分是前半部分的 9 补码。 因此，每个配对数字之和为$9$。 

所以数字和是$$9\cdot \frac{p-1}{2}.$$代替$p=729809891$:$$9\cdot \frac{729809890}{2} = 9\cdot 364904945 = 3284144505.$$### Python 实现```python
from sympy import primerange, factorint

# Interval forced by leading digits 00000000137
lo = int(10**11 / 138) + 1
hi = int(10**11 / 137)

def is_full_reptend_prime(p):
    """Check whether 10 is a primitive root mod p."""
    factors = factorint(p - 1)
    return all(pow(10, (p - 1) // q, p) != 1 for q in factors)

def last_five_digits_match(p):
    """Check that repetend ends in 56789."""
    # N = (10^(p-1) - 1) / p
    mod = p * 100000
    n_mod = (pow(10, p - 1, mod) - 1) // p
    return n_mod % 100000 == 56789

candidate = None

for p in primerange(lo, hi + 1):
    # congruence from last five digits
    if p % 100000 != 9891:
        continue

    # first 11 digits must be 00000000137
    if 10**11 // p != 137:
        continue

    if last_five_digits_match(p) and is_full_reptend_prime(p):
        candidate = p
        break

# digit sum of cyclic number
answer = 9 * (candidate - 1) // 2
print(answer)
```### 代码演练

 - **范围缩小**：计算间隔$p$使用前缀`00000000137`。 
- **同余过滤器**：仅保留满足素数$$p\cdot 56789\equiv -1 \pmod{100000}.$$- **前缀测试**：验证前 11 位数字是否正确`00000000137`。 
- **循环测试**：检查$10$是一个原根 mod$p$，确保小数展开是循环的。 
- **数字和**：利用循环数的补码性质来计算$$9\cdot\frac{p-1}{2}.$$最终健全性检查：

 -$p$位于所需的区间内 ✓
 - 重复结束于`56789`✓
 - 全循环财产持有 ✓
 - 数字和公式与已知示例匹配（$1/7\to27$,$1/17\to72$) ✓
