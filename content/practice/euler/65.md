[欧拉计划问题 65](https://projecteuler.net/problem=65)

 ## 解决方案

 **答案：**`272`对于连续分数$e$,$$e=[2;1,2,1,1,4,1,1,6,1,\dots]$$系数遵循一个简单的模式：$$a_0=2,$$并为$n\ge1$,$$a_n= \begin{cases} 2k & \text{if } n=3k-1,\\ 1 & \text{otherwise}. \end{cases}$$我们需要的分子$100^\text{th}$收敛，然后求其数字之和。 

---

 # 数学分析

 连分数$$[a_0;a_1,a_2,\dots,a_n]$$有收敛$\frac{p_n}{q_n}$递归生成：$$p_n=a_n p_{n-1}+p_{n-2}$$

$$q_n=a_n q_{n-1}+q_{n-2}$$具有初始值$$p_{-2}=0,\quad p_{-1}=1$$

$$q_{-2}=1,\quad q_{-1}=0.$$这些递归直接来自从左到右重复评估连分数。 

- -

为了$e$，条款是：$$2,\ 1,\ 2,\ 1,\ 1,\ 4,\ 1,\ 1,\ 6,\ 1,\dots$$前几个分子是：

 -$2$-$3$-$8$-$11$-$19$匹配问题陈述。 

所以算法是：

 1. 生成前 100 个系数。 
2. 使用递归求收敛。 
3. 取第 100 次收敛的分子。 
4. 将其数字相加。 

---

 # Python 实现```python
# Generate the first 100 coefficients for e's continued fraction

terms = [2]

k = 1
while len(terms) < 100:
    terms.extend([1, 2 * k, 1])
    k += 1

terms = terms[:100]

# Recurrence for convergents
# p = numerator, q = denominator

p_minus2, p_minus1 = 0, 1
q_minus2, q_minus1 = 1, 0

for a in terms:
    p = a * p_minus1 + p_minus2
    q = a * q_minus1 + q_minus2

    p_minus2, p_minus1 = p_minus1, p
    q_minus2, q_minus1 = q_minus1, q

# Numerator of the 100th convergent
numerator = p_minus1

# Sum of digits
digit_sum = sum(int(d) for d in str(numerator))

print(digit_sum)
```---

 # 代码演练

 ## 构建连分数项```python
terms = [2]
```连分数开始于$2$。```python
terms.extend([1, 2 * k, 1])
```这会生成重复模式$$1,\ 2k,\ 1$$给予：$$1,2,1,1,4,1,1,6,1,\dots$$直到我们有 100 个术语。 

---

 ## 收敛递归

 我们存储以前的分子和分母：```python
p_minus2, p_minus1 = 0, 1
q_minus2, q_minus1 = 1, 0
```那么对于每个系数$a$：```python
p = a * p_minus1 + p_minus2
q = a * q_minus1 + q_minus2
```它实现了：$$p_n=a_n p_{n-1}+p_{n-2}$$

$$q_n=a_n q_{n-1}+q_{n-2}$$---

$$[2;1,2] = \frac83$$

$$[2;1,2,1] = \frac{11}{4}$$这些与问题陈述中给出的值完全匹配，确认重现是正确的。
