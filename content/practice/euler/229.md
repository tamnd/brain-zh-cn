[欧拉项目问题 229](https://projecteuler.net/problem=229)

 ## 解决方案

 **答案：**`11325263`让$$\begin{aligned} n&=x_1^2+y_1^2\\ n&=x_2^2+2y_2^2\\ n&=x_3^2+3y_3^2\\ n&=x_7^2+7y_7^2 \end{aligned}$$所有变量均为正整数。 

我们求整数的个数$n\le 2\cdot 10^9$满足**所有四个**条件。 

---

 # 1.数学分析

 关键是使用二元二次形式表示的素数的经典特征。 

对于素数$p\nmid 42$:

 -$p=x^2+y^2\iff p\equiv 1\pmod 4$-$p=x^2+2y^2\iff p\equiv 1,3\pmod 8$-$p=x^2+3y^2\iff p\equiv 1\pmod 3$-$p=x^2+7y^2\iff \left(\frac{-7}{p}\right)=1$组合所有同余条件正好给出三个残基类别模$$\operatorname{lcm}(4,8,3,7)=168:$$

$$p\equiv 1,\ 25,\ 121 \pmod{168}.$$因此，唯一可能出现在奇数指数上的奇数素数是那些残数类中的素数。 

等价地，如果$$n=\prod p_i^{e_i},$$然后集合外的每个素数$$\mathcal P=\{p:\ p\equiv 1,25,121\pmod{168}\}$$必须以偶数指数出现。 

因此，每一个可接受的$n$可以唯一地写为$$n=d\,m^2,$$在哪里$d$是无平方的并且每个素数除法$d$在于$\mathcal P$。 

所以计数问题就变成了$$\sum_{\substack{d\le N\\ d\text{ squarefree}\\ p\mid d\Rightarrow p\in\mathcal P}} \left\lfloor \sqrt{\frac{N}{d}} \right\rfloor .$$剩下的工作纯粹是计算性的。 

---

 # 2.Python实现```python
from math import isqrt
from sympy import primerange

LIMIT = 2_000_000_000

# primes allowed to occur to odd exponent
good_primes = [
    p for p in primerange(2, LIMIT + 1)
    if p % 168 in (1, 25, 121)
]

# generate all squarefree products of good primes <= LIMIT
squarefree = []

def dfs(start, current):
    squarefree.append(current)

    for i in range(start, len(good_primes)):
        p = good_primes[i]

        if current * p > LIMIT:
            break

        dfs(i + 1, current * p)

dfs(0, 1)

# count all numbers n = d * m^2
answer = 0

for d in squarefree:
    answer += isqrt(LIMIT // d)

# remove d = 1 (pure squares with no allowed odd prime factor)
answer -= isqrt(LIMIT)

print(answer)
```---

 # 3. 代码演练

 ### 步骤 1 — 确定可接受的素数```python

```这些正是所有四种二次形式都可以表示的素数。 

---

 ### 步骤 2 — 生成无方形内核

 每个可接受的数字都有以下形式$$n=d\,m^2$$和$d$无平方且仅由可接受的素数组成。 

DFS 递归地构建所有这些$d$。 

---

 ### 步骤 3 — 计算所有倍数的平方

 对于固定$d$,$$d\,m^2 \le N \iff m \le \sqrt{N/d}.$$因此正好有$$\left\lfloor \sqrt{N/d} \right\rfloor$$有效数字$d$。 

---

 ### 步骤 4 — 移除纯方形外壳

 案例$d=1$对应奇数部分为空的纯正方形； 这些不满足所有四种表示中的正性约束，因此我们将它们减去。
