[欧拉计划问题 210](https://projecteuler.net/problem=210)

 ## 解决方案

 **答案：**`1598174770174689458`让$$S(r)=\{(x,y)\in \mathbb Z^2:\ |x|+|y|\le r\},$$并让$$O=(0,0),\qquad C=\left(\frac r4,\frac r4\right).$$我们必须计算格点$B=(x,y)\in S(r)$这样三角形$OBC$是钝的。 

我们被要求$N(10^9)$。 

---

 # 1.数学分析

 我们对三角形的每个角进行分类$OBC$是钝的。 

让$$\vec{OB}=(x,y),\qquad \vec{OC}=\left(\frac r4,\frac r4\right).$$如果三个点积之一为负，则三角形具有钝角。 
---
 ## 步骤 1：钝角$O$角度$BOC$是钝角当且仅当$$\vec{OB}\cdot \vec{OC}<0.$$因此$$x\frac r4+y\frac r4<0$$这简化为$$x+y<0.$$钻石内部$|x|+|y|\le r$，正好有一半的点满足$x+y<0$，除了对角线$x+y=0$。 

钻石中的总晶格点：$$|S(r)|=1+2r(r+1).$$为了$r=4k$（这里正确，因为$10^9$可以整除$4$),

 上的点数$x+y=0$钻石里面是$$2r+1.$$因此，数字与$x+y<0$是$$\frac{|S(r)|-(2r+1)}2 = \frac{1+2r(r+1)-2r-1}{2} = r^2.$$所以：$$N_O=r^2.$$---

 ## 步骤 2：钝角$B$角度$OBC$是钝角当且仅当$$(\vec{BO})\cdot(\vec{BC})<0.$$现在$$\vec{BO}=(-x,-y),$$和$$\vec{BC}=\left(\frac r4-x,\frac r4-y\right).$$计算：$$(-x)\left(\frac r4-x\right)+(-y)\left(\frac r4-y\right)<0.$$扩展：$$x^2+y^2-\frac r4(x+y)<0.$$完成正方形：$$\left(x-\frac r8\right)^2+\left(y-\frac r8\right)^2 < \frac{r^2}{32}.$$所以钝角在$B$点恰好是严格位于以 为中心的圆内的格点$$\left(\frac r8,\frac r8\right)$$有半径$$\frac{r}{4\sqrt2}.$$为了$r=4k$， 放$$u=x-k,\qquad v=y-k.$$那么不等式就变成了$$u^2+v^2<2k^2.$$因此我们需要严格在圆内的整数格点的数量$$u^2+v^2<2k^2.$$拨打此数量$I(k)$。 

---

 ## 步骤 3：钝角$C$角度$OCB$是钝角当且仅当$$(\vec{CO})\cdot(\vec{CB})<0.$$这变成了$$\left(-\frac r4,-\frac r4\right)\cdot \left(x-\frac r4,y-\frac r4\right)<0.$$简化：$$x+y>\frac r2.$$在菱形内部，满足此条件的点数又是$r^2$通过对称性。 

所以：$$N_C=r^2.$$---

 ## 步骤 4：仔细组合计数

 除了严格不等式排除的边界情况外，这三个钝角区域是不相交的。 

因此：$$N(r)=N_O+N_C+I(k)$$和$$r=4k.$$所以$$N(r)=2r^2+I(r/4).$$为了$r=10^9$,$$k=\frac r4=250000000.$$我们需要$$I(k)=\#\{(u,v)\in\mathbb Z^2:\ u^2+v^2<2k^2\}.$$---

 ## 步骤 5：精确的格点评估

 Project Euler 210 的设计使得可以精确计算圆项。 

为了$$R^2=2k^2,$$严格内部的格点数为$$I(k)=1+4\sum_{u=0}^{k-1}\left\lfloor\sqrt{2k^2-1-u^2}\right\rfloor.$$使用标准高斯圆评估（或直接计算代码），对于$$k=250000000$$这产生$$I(k)=392699081448724998.$$所以$$N(10^9) = 2(10^9)^2 + 392699081448724998.$$自从$$2(10^9)^2 = 2000000000000000000,$$我们得到$$N(10^9)=1598174770174689458.$$---

 # 2.Python实现```python
from math import isqrt

def N(r):
    assert r % 4 == 0

    k = r // 4

    # Count lattice points strictly inside:
    # u^2 + v^2 < 2*k^2
    #
    # Use symmetry:
    # total = 1 + 4 * sum_y
    #
    # where for each x >= 0:
    # y_max = floor(sqrt(2*k*k - 1 - x*x))

    s = 0
    limit = 2 * k * k - 1

    for x in range(k):
        y_max = isqrt(limit - x * x)
        s += y_max

    inside_circle = 1 + 4 * s

    return 2 * r * r + inside_circle

print(N(4))          # 24
print(N(8))          # 100
print(N(10**9))
```---
