[欧拉项目 946 问题](https://projecteuler.net/problem=946)

 ## 解决方案

 **答案：**`585787007`让$$\alpha=[2;\underbrace{1,\dots,1}_{2},2,\underbrace{1,\dots,1}_{3},2, \underbrace{1,\dots,1}_{5},2,\ldots]$$其中块的长度$1$是连续的素数。 

我们定义$$\beta=\frac{2\alpha+3}{3\alpha+2}.$$任务是计算第一个的总和$10^8$的连分数系数$\beta$。 

莫比乌斯图下连续分数变换的标准方法$$x\mapsto \frac{ax+b}{cx+d}$$就是使用矩阵$$\begin{pmatrix}a&b\\ c&d\end{pmatrix}.$$对于每个传入的连分数数字$t$，矩阵更新为$$(a,b,c,d)\mapsto (at+b,\ a,\ ct+d,\ c).$$每当$$\left\lfloor \frac a c \right\rfloor = \left\lfloor \frac b d \right\rfloor,$$该公共值是变换后的数的下一个连分数系数。 

这里的初始矩阵是$$\begin{pmatrix}2&3\\3&2\end{pmatrix},$$因为$$\beta=\frac{2\alpha+3}{3\alpha+2}.$$在连续部分运行该传感器$\alpha$有效地生成系数$\beta$。 前十确实是$$[0;1,5,6,16,9,1,10,16,11],$$其总和是$75$，与语句相符。 

优化的实现（恒定大小的整数状态，不需要大整数）计算第一个$10^8$几秒钟内即可得出系数。 

Python版本核心逻辑：```python
from sympy import primerange

N = 10**8

a, b, c, d = 2, 3, 3, 2
count = 0
total = 0

def process(t):
    global a, b, c, d, count, total

    a, b, c, d = a*t + b, a, c*t + d, c

    while c and d and a // c == b // d:
        q = a // c
        total += q
        count += 1

        if count == N:
            return True

        a, b, c, d = c, d, a - q*c, b - q*d

    return False

# initial term of alpha
process(2)

for p in primerange(2, 10**9):
    for _ in range(p):
        if process(1):
            break
    else:
        if process(2):
            break
        continue
    break

print(total)
```这产生：

 **答案：585787007**
