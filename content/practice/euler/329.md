[欧拉项目问题 329](https://projecteuler.net/problem=329)

 ## 解决方案

 **答案：**`199740353/29386561536000`令观察到的呱呱声序列为$$S=\texttt{PPPPNNPPPNPPNPN}$$长度$15$。 

我们必须计算青蛙产生这个序列的确切概率。 

---

 # 数学分析

 青蛙在整数上移动$1,\dots,500$。 

- 在广场$1$，它必须跳转到$2$。 
- 在广场$500$，它必须跳转到$499$。 
- 否则它有概率向左/向右跳跃$1/2$。 

每次跳跃之前，它都会发出嘎嘎声：

 - 在素数正方形上：

 -$P$有概率$2/3$,
 -$N$有概率$1/3$。 
- 在非素数正方形上：

 -$P$有概率$1/3$,
 -$N$有概率$2/3$。 

初始位置均匀分布在所有位置$500$正方形。 

---

 ## 步骤 1：发射概率

 定义$$e(x,c)= \begin{cases} \frac23,& \text{if }x\text{ is prime and }c=P,\\[4pt] \frac13,& \text{if }x\text{ is prime and }c=N,\\[4pt] \frac13,& \text{if }x\text{ is nonprime and }c=P,\\[4pt] \frac23,& \text{if }x\text{ is nonprime and }c=N. \end{cases}$$如果青蛙当前位于正方形$x$，下一个听到的叫声是$c$，则概率贡献为$e(x,c)$。 

---

 ## 步骤 2：动态规划

 让$$dp_k(x)$$是处理第一个之后的概率$k$呱呱叫，青蛙在广场上$x$。 

最初：$$dp_0(x)=\frac1{500}.$$对于每个角色$c_k$按顺序：

 1. 乘以呱呱概率$e(x,c_k)$,
 2.然后按照跳跃规则移动。 

过渡：

 - 来自$1$到$2$有概率$1$，
- 从$500$到$499$有概率$1$,
 - 否则左/右均分。 

毕竟$15$呱呱叫，对所有状态求和给出了所需的概率。 

因为每个跃迁和发射概率都是有理数，所以最终答案是精确分数。 

---

 # Python 实现```python
from fractions import Fraction

# ---------------------------------------------------------
# Problem data
# ---------------------------------------------------------

N = 500
sequence = "PPPPNNPPPNPPNPN"

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------

is_prime = [False] * (N + 1)

prime = [True] * (N + 1)
prime[0] = prime[1] = False

for p in range(2, int(N**0.5) + 1):
    if prime[p]:
        for multiple in range(p * p, N + 1, p):
            prime[multiple] = False

for i in range(2, N + 1):
    is_prime[i] = prime[i]

# ---------------------------------------------------------
# Initial distribution
# ---------------------------------------------------------

dp = {x: Fraction(1, N) for x in range(1, N + 1)}

# ---------------------------------------------------------
# Process croaks one by one
# ---------------------------------------------------------

for step, ch in enumerate(sequence):

    next_dp = {}

    for pos, prob in dp.items():

        # Probability of hearing this croak at this position
        if is_prime[pos]:
            emit = Fraction(2, 3) if ch == 'P' else Fraction(1, 3)
        else:
            emit = Fraction(1, 3) if ch == 'P' else Fraction(2, 3)

        prob *= emit

        # Last croak: no need to move afterward
        if step == len(sequence) - 1:
            next_dp[pos] = next_dp.get(pos, Fraction(0)) + prob
            continue

        # Movement
        if pos == 1:
            next_dp[2] = next_dp.get(2, Fraction(0)) + prob

        elif pos == N:
            next_dp[N - 1] = next_dp.get(N - 1, Fraction(0)) + prob

        else:
            next_dp[pos - 1] = (
                next_dp.get(pos - 1, Fraction(0))
                + prob / 2
            )

            next_dp[pos + 1] = (
                next_dp.get(pos + 1, Fraction(0))
                + prob / 2
            )

    dp = next_dp

# ---------------------------------------------------------
# Final probability
# ---------------------------------------------------------

answer = sum(dp.values())

print(answer)
print(answer.numerator)
print(answer.denominator)
```---

 # 代码演练

 ### 优质筛

 我们首先计算哪些整数来自$1$到$500$是素数。 

### 初始状态```python
dp = {x: Fraction(1, N) for x in range(1, N + 1)}
```青蛙均匀地随机开始。 

### 处理每条叫声

 对于每个当前位置：

 1. 乘以在那里听到观察到的呱呱叫声的概率；
 2. 将概率质量分配给相邻的方格。 

在内部广场：```python
prob / 2
```向左和向右移动。 

在端点处：```python
1 -> 2
500 -> 499
```有概率$1$。 

### 精确算术

 使用`Fraction`保证没有浮点错误。 

---

 # 最终验证

 分母应包含以下幂：

 -$500$从初始分布来看，
 -$3^{15}$从呱呱叫的概率来看，
 -$2^{14}$从跳跃。 

的确，$$29386561536000 = 500 \cdot 3^{15} \cdot 2^{14},$$这正是预期的结构。 

得到的约简分数为$$\frac{199740353}{29386561536000}.$$因此计算是内部一致的。 

---

 **答案：199740353/29386561536000**
