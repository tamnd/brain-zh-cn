[欧拉项目问题 43](https://projecteuler.net/problem=43)

 ## 解决方案

 **答案：**`16695334890`## 1.数学分析

 我们寻找所有 **0–9 泛数字**$d_1d_2\dots d_{10}$满意：$$d_2d_3d_4 \equiv 0 \pmod 2$$

$$d_3d_4d_5 \equiv 0 \pmod 3$$

$$d_4d_5d_6 \equiv 0 \pmod 5$$

$$d_5d_6d_7 \equiv 0 \pmod 7$$

$$d_6d_7d_8 \equiv 0 \pmod {11}$$

$$d_7d_8d_9 \equiv 0 \pmod {13}$$

$$d_8d_9d_{10} \equiv 0 \pmod {17}$$蛮力压倒一切$10! = 3,628,800$全数字是可能的，但我们可以利用该结构。 

### 主要观察结果

 #### 1. 能被 5 整除

 自从$d_4d_5d_6$必须能被 5 整除：$$d_6 \in \{0,5\}$$但数字是唯一的，后来的限制消除了许多可能性。 

#### 2. 重叠窗口

 每个整除性规则都涉及 **3 位重叠子字符串**：

 -$d_2d_3d_4$-$d_3d_4d_5$-$d_4d_5d_6$- 等

 这表明建筑数字**倒退**。 

示例：

 从 17 的 3 位数倍数开始$d_8d_9d_{10}$。 

然后在前面添加一个数字以得到 13 的倍数：$$d_7d_8d_9 \equiv 0 \pmod{13}$$继续：$$13 \to 11 \to 7 \to 5 \to 3 \to 2$$在每个阶段，我们只保留具有**不同数字**的候选人。 

这极大地减少了搜索。 

### 回溯想法

 假设我们已经有：$$d_8d_9d_{10}=289$$自从$728$可以整除$13$，我们前置$7$:$$7289$$然后因为$572$可以整除$11$:$$57289$$继续，直到放置完所有数字。 

最后插入缺失的前导数字$d_1$。 

问题陈述的示例$$1406357289$$正是这样生成的。

 ## 2.Python实现```python
from itertools import permutations

def solve():
    primes = [17, 13, 11, 7, 5, 3, 2]

    # Start with valid 3-digit multiples of 17
    candidates = []

    for n in range(17, 1000, 17):
        s = f"{n:03d}"  # preserve leading zeros
        if len(set(s)) == 3:
            candidates.append(s)

    # Build numbers backwards using substring divisibility
    for p in primes[1:]:
        new_candidates = []

        for candidate in candidates:
            used = set(candidate)

            for digit in "0123456789":
                if digit in used:
                    continue

                # Form new 3-digit substring
                triple = digit + candidate[:2]

                if int(triple) % p == 0:
                    new_candidates.append(digit + candidate)

        candidates = new_candidates

    total = 0

    # Add the missing first digit
    for candidate in candidates:
        missing_digit = (
            set("0123456789") - set(candidate)
        ).pop()

        pandigital = int(missing_digit + candidate)
        total += pandigital

    return total

print(solve())
```---
