[项目欧拉问题 820](https://projecteuler.net/problem=820)

 ## 解决方案

 **答案：**`44967734`设小数展开式为$1/k$是$$\frac1k = 0.a_1a_2a_3\cdots$$然后$n$- 第一个小数位是$d_n(1/k)=a_n$。 

我们需要$$S(n)=\sum_{k=1}^n d_n\!\left(\frac1k\right)$$特别是$S(10^7)$。 

---

 # 1.数学分析

 ## 步骤1：提取小数位

 回想一下标准的长除法事实：$$a_n=\left\lfloor \frac{10\,r_n}{k}\right\rfloor$$在哪里$$r_n = 10^{n-1} \bmod k$$是在产生之前获得的余数$n$第 - 位数字。 

的确，$$\frac{10^{n-1}}{k} = q+\frac{r_n}{k}$$和$0\le r_n<k$。 乘以$10$,$$\frac{10^n}{k} = 10q+\frac{10r_n}{k}$$小数项的整数部分正是$n$- 第一个小数位。 

所以，$$d_n\!\left(\frac1k\right) = \left\lfloor \frac{10(10^{n-1}\bmod k)}{k}\right\rfloor$$所以$$\boxed{ S(n)=\sum_{k=1}^n \left\lfloor \frac{10(10^{n-1}\bmod k)}{k} \right\rfloor }$$这立即给出了一个有效的算法。 

---

 ## 步骤 2：验证示例$n=7$我们计算：$$d_7\!\left(\frac13\right) = \left\lfloor \frac{10(10^6\bmod 3)}{3} \right\rfloor = \left\lfloor\frac{10\cdot1}{3}\right\rfloor =3$$

$$d_7\!\left(\frac16\right) = \left\lfloor \frac{10(10^6\bmod 6)}{6} \right\rfloor = \left\lfloor\frac{10\cdot4}{6}\right\rfloor =6$$

$$d_7\!\left(\frac17\right) = \left\lfloor \frac{10(10^6\bmod 7)}{7} \right\rfloor = \left\lfloor\frac{10\cdot1}{7}\right\rfloor =1$$总结所有$k=1,\dots,7$给出$$S(7)=10$$与声明相符。 

---

 # 2.Python实现```python
def S(n: int) -> int:
    total = 0

    for k in range(1, n + 1):
        # r = 10^(n-1) mod k
        r = pow(10, n - 1, k)

        # nth decimal digit of 1/k
        digit = (10 * r) // k

        total += digit

    return total

# Check the examples
print(S(7))      # 10
print(S(100))    # 418

# Final answer
print(S(10**7))
```---

 # 4.最终验证

 总和有$10^7$项，每项之间$0$和$9$， 所以：$$0 \le S(10^7) \le 9\times10^7$$我们的计算结果：$$44\,967\,734$$舒适地在此范围内，并且与平均数字一致$4.5$，这对于循环小数扩展是合理的。 

因此计算是一致的。
