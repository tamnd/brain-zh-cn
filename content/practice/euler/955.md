[项目欧拉问题 955](https://projecteuler.net/problem=955)

 ## 解决方案

 **答案：**`6795261671274`设三角形数为$$T_m=\frac{m(m+1)}2.$$认为$a_r=T_m$是序列中出现的三角形数，下一个出现的三角形数是$a_{r+k}=T_n$。 

两个三角形数之间的递归式为$$a_{j+1}-a_j=(a_j-a_{j-1})+1,$$在三角形数字之后，差值立即重置为$1$。 

因此连续增量为$$1,2,3,\dots,k,$$所以$$T_n-T_m = 1+2+\cdots+k = T_k.$$所以$$T_n=T_m+T_k.$$使用$T_x=\frac{x(x+1)}2$,$$n(n+1)=m(m+1)+k(k+1).$$重新排列：$$(2n+1)^2=(2m+1)^2+(2k+1)^2-1.$$标准因式分解技巧给出$$m(m+1)=uv,$$和$$u=\frac{2n+1-(2k+1)}2,\qquad v=\frac{2n+1+(2k+1)}2.$$然后$$2k+1=v-u,\qquad 2n+1=u+v.$$所以对于给定的$m$，要获得序列中的下一个三角形编号，我们必须选择因子对$$uv=m(m+1)$$奇数差最小$v-u>1$。 然后$$k=\frac{v-u-1}{2},\qquad n=\frac{u+v-1}{2}.$$开始于$m=2$（自从$a_0=3=T_2$），我们迭代这个规则69次并累加相应的$k$-值（索引跳跃）。 

一个干净的 Python 实现是：```python
from math import isqrt
from sympy import divisors

def next_triangle(m):
    N = m * (m + 1)

    best = None
    for u in divisors(N):
        if u * u > N:
            break
        v = N // u
        d = v - u

        # need smallest odd difference > 1
        if d > 1 and d % 2 == 1:
            best = (u, v)

    u, v = best

    k = (v - u - 1) // 2
    n = (u + v - 1) // 2

    return n, k

m = 2          # T_2 = 3
index = 0      # a_0

for _ in range(69):   # move to the 70th triangle number
    m, jump = next_triangle(m)
    index += jump

print(index)
```这产生$$6795261671274.$$**答案：6795261671274**
