[欧拉项目 877 问题](https://projecteuler.net/problem=877)

 ## 解决方案

 **答案：**`336785000760344621`将每个非负整数解释为多项式$\mathbb F_2$通过将其二进制展开式读取为系数。 

例如$$13 = 1101_2 \longleftrightarrow x^3+x^2+1.$$在这封信函下：

 - XOR 变成多项式加法$\mathbb F_2$,
 - 异或乘积$\otimes$变成普通多项式乘法$\mathbb F_2$。 

所以问题确实发生在内部$\mathbb F_2[x]$。 

---

 # 1. 重写方程

 让$$A(x)\leftrightarrow a,\qquad B(x)\leftrightarrow b.$$等式$$(a\otimes a)\oplus (2\otimes a\otimes b)\oplus (b\otimes b)=5$$变成$$A^2+xAB+B^2=x^2+1.$$（这里的整数$2$对应于多项式$x$， 和$5=101_2$对应于$x^2+1$.)

 因此我们必须解决$$A^2+xAB+B^2=x^2+1. \tag{1}$$---

 # 2. 引入二次扩展

 让$u$满足$$u^2+xu+1=0.$$然后定义共轭$$\bar u = x+u.$$的确，$$u+\bar u=x,\qquad u\bar u=1.$$现在考虑$$z=A+Bu.$$其规范是$$N(z)=z\bar z=(A+Bu)(A+B\bar u).$$特征扩展$2$,$$N(z)=A^2+xAB+B^2.$$因此方程(1)正好是$$N(z)=x^2+1=(x+1)^2. \tag{2}$$---

 # 3. 生成所有解决方案

 因为$$N(u)=u\bar u=1,$$将任何解乘以$u$保留规范。 

一个基本的解决方案是$$(A,B)=(0,x+1),$$因为$$0^2+0+(x+1)^2=x^2+1.$$在整数中这是$(a,b)=(0,3)$。 

现在重复乘以$u$。 

认为$$A_n+B_nu=(x+1)u^n.$$然后$$(A_{n+1},B_{n+1})$$来自乘以$u$：$$(A_n+B_nu)u = B_n + (A_n+xB_n)u.$$因此$$A_{n+1}=B_n, \qquad B_{n+1}=A_n+xB_n.$$转换回整数：

 - 乘以$x$左移一位，
 - 加法是异或。 

所以$$a_{n+1}=b_n, \qquad b_{n+1}=a_n\oplus (2b_n). \tag{3}$$开始于$$(a_0,b_0)=(0,3),$$我们得到$$\begin{aligned} (0,3),\\ (3,6),\\ (6,15),\\ (15,24),\\ (24,63),\ldots \end{aligned}$$与示例完全匹配。 

人们可以从这个二次扩展中的独特因式分解看出，**所有**解都是这样产生的。 

因此$X(N)$只是所有的异或$b_n\le N$。 

---

 # 4. 高效计算

 其递归式为：$$(a,b)\mapsto (b,\ a\oplus (b\ll 1)).$$大约只有$60$以下条款$10^{18}$，所以直接迭代是微不足道的。 

---

 # 5.Python实现```python
def compute_X(N):
    # Initial solution
    a, b = 0, 3

    ans = 0

    while b <= N:
        ans ^= b

        # Next solution:
        # a' = b
        # b' = a XOR (b << 1)
        a, b = b, a ^ (b << 1)

    return ans

# Verification of the small example
print(compute_X(10))      # should be 5

# Final answer
print(compute_X(10**18))
```---

 # 7. 样本验证

 解决方案$b\le 10$：$$(0,3),\quad (3,6).$$因此$$X(10)=3\oplus 6=5,$$与声明相符。
