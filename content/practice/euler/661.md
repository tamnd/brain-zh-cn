[项目欧拉问题 661](https://projecteuler.net/problem=661)

 ## 解决方案

 **答案：**`646231.2177`让之后的分数差$n$游戏是$$S_n = (\#\text{wins by A})-(\#\text{wins by B}).$$然后每场比赛结束后：

 -$S\to S+1$有概率$a=p_A$,
 -$S\to S-1$有概率$b=p_B$,
 -$S\to S$有概率$d=1-a-b$。 

此外，每场比赛结束后，比赛都有概率停止$p$，所以它继续概率$$q=1-p.$$我们想要$$\mathbb E_A(a,b,p) =\sum_{n\ge1}\Pr(S_n>0,\text{ game }n\text{ is played}).$$自从比赛以来$n$当且仅当播放前一个$n-1$继续抛掷反面，$$\Pr(\text{game }n\text{ played})=q^{\,n-1}.$$因此$$\mathbb E_A(a,b,p) =\sum_{n\ge1} q^{n-1}\Pr(S_n>0).$$---

 # 1. 解决随机游走递归问题

 定义$F_i$为未来 A 领先的预期次数，从分数差开始$i$。 

为了$i\ge2$,$$F_i =1+q(aF_{i+1}+bF_{i-1}+dF_i),$$因为再打一局A肯定还是领先。 

为了$i\le -1$,$$F_i=q(aF_{i+1}+bF_{i-1}+dF_i),$$因为 A 目前没有领先。 

在边界处：$$F_1=a(1+qF_2)+b(qF_0)+d(1+qF_1),$$

$$F_0=a(1+qF_1)+b(qF_{-1})+d(qF_0).$$---

 ## 均质溶液

 特征方程为$$qa r^2-(1-qd)r+qb=0.$$让它的根是$\alpha,\beta$和$\alpha<1<\beta$：$$\alpha,\beta = \frac{1-qd\mp\sqrt{\Delta}}{2qa},$$在哪里$$\Delta=(1-qd)^2-4q^2ab.$$使用$d=1-a-b$,$$\Delta = p^2+2pq(a+b)+q^2(a-b)^2.$$有界解是$$F_i= \begin{cases} \dfrac1p + B\alpha^i, & i\ge1,\\[1ex] C\beta^i, & i\le -1. \end{cases}$$求解边界方程给出$$F_0 = \frac{1-\alpha}{pq(\beta-\alpha)}.$$使用$$\beta-\alpha=\frac{\sqrt{\Delta}}{qa},$$并简化，$$\boxed{ \mathbb E_A(a,b,p) = \frac{\sqrt{\Delta}-p+q(a-b)} {2pq\sqrt{\Delta}} }$$和$$\Delta = p^2+2pq(a+b)+q^2(a-b)^2.$$---

 # 2. 申请$H(50)$我们被给予$$a=\frac1{\sqrt{k+3}}, \qquad b=\frac1{\sqrt{k+3}}+\frac1{k^2}, \qquad p=\frac1{k^3}.$$所以$$H(50) = \sum_{k=3}^{50} \mathbb E_A(a,b,p).$$---

 # 3.Python实现```python
from math import sqrt

def EA(a, b, p):
    q = 1.0 - p

    Delta = (
        p * p
        + 2.0 * p * q * (a + b)
        + q * q * (a - b) * (a - b)
    )

    root = sqrt(Delta)

    return (root - p + q * (a - b)) / (2.0 * p * q * root)

H = 0.0

for k in range(3, 51):
    a = 1.0 / sqrt(k + 3)
    b = a + 1.0 / (k * k)
    p = 1.0 / (k ** 3)

    H += EA(a, b, p)

print("{:.10f}".format(H))
```---
