[项目欧拉问题 351](https://projecteuler.net/problem=351)

 ## 解决方案

 **答案：**`11762187201804552`让果园的中心作为原点。 如果另一个格点位于距中心相同的射线上并且更近，则该格点**隐藏**。 

关键的观察是：

 > 一个点从中心可见**当且仅当**它的方向向量是本原的（它的坐标是互质的）。 

我们将把几何转化为涉及欧拉 totient 函数的数论计数问题。 

---

 ## 1.数学分析

 ### 第 1 步：对六方晶格建模

 秩序井然的六边形果园$n$由边长为正六边形内的所有格点组成$n$。 

由于六边形对称，只需计算六个中之一的点即可$60^\circ$扇区并乘以 6。 

在一个扇区内，格点可以用整数坐标表示$$(a,b), \qquad a,b\ge 0,\qquad a+b\le n.$$中心$(0,0)$被排除在外。 

一点$(a,b)$从中心可见 iff$$\gcd(a,b)=1.$$为什么？ 因为如果$d=\gcd(a,b)>1$， 然后$$(a,b)=d\left(\frac a d,\frac b d\right),$$所以越接近格点$(a/d,b/d)$阻止它。 

因此隐藏点完全对应于**非原始向量**。 

---

 ### 第 2 步：计算一个扇区中的可见点

 修复$k=a+b$， 在哪里$$1 \le k \le n.$$我们想要原始对的数量$(a,b)$和$$a+b=k.$$自从$b=k-a$,$$\gcd(a,b)=\gcd(a,k).$$因此可见性意味着$a$互质于$k$。 

这样的数量$a\in\{1,\dots,k-1\}$正是$$\varphi(k),$$在哪里$\varphi$是欧拉的 totient 函数。 

因此：

 - 一个扇区内的可见点：$$\sum_{k=1}^{n} \varphi(k).$$乘以 6 得出可见非中心点总数：$$6\sum_{k=1}^{n}\varphi(k).$$---

 ### 第 3 步：计算所有点

 在一个扇区中，非中心格点的总数为$$1+2+\cdots+n = \frac{n(n+1)}{2}.$$横跨所有 6 个部门：$$6\cdot \frac{n(n+1)}{2}.$$因此隐藏点是$$H(n) = 6\left( \frac{n(n+1)}{2} - \sum_{k=1}^{n}\varphi(k) \right).$$所以问题归结为计算总和$$\Phi(n)=\sum_{k=1}^{n}\varphi(k)$$为了$n=10^8$。 

---

 ### 步骤 4：totient 求和函数的高效计算

 直接过筛$10^8$太贵了。 

使用经典的分治恒等式：$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{i=2}^{n}\Phi\!\left(\left\lfloor\frac{n}{i}\right\rfloor\right).$$下限值在范围内重复，因此将商分组为相等：

 如果$$q=\left\lfloor \frac{n}{l}\right\rfloor,$$那么所有的指数$$l \le i \le r=\left\lfloor \frac{n}{q}\right\rfloor$$共享相同的商。 

这将复杂性降低到大约$$O(n^{2/3})$$与记忆。 

---

 ## 2.Python实现```python
from functools import lru_cache

def hidden_points(n):
    @lru_cache(None)
    def totient_sum(x):
        # S(x) = sum_{k<=x} phi(k)
        if x == 1:
            return 1

        # Start with 1 + 2 + ... + x
        result = x * (x + 1) // 2

        l = 2
        while l <= x:
            q = x // l
            r = x // q

            # Subtract grouped contributions
            result -= (r - l + 1) * totient_sum(q)

            l = r + 1

        return result

    visible_sector = totient_sum(n)
    total_sector = n * (n + 1) // 2

    return 6 * (total_sector - visible_sector)

# Verification against examples
print(hidden_points(5))      # 30
print(hidden_points(10))     # 138
print(hidden_points(1000))   # 1177848

# Final answer
print(hidden_points(100000000))
```---

 ## 3. 代码演练

 ###`totient_sum(x)`计算$$\Phi(x)=\sum_{k\le x}\varphi(k).$$使用身份：$$\Phi(x) = \frac{x(x+1)}{2} - \sum_{i=2}^{x} \Phi\!\left(\left\lfloor \frac{x}{i}\right\rfloor\right).$$循环对相等的商值进行分组：```python
q = x // l
r = x // q
```中的每个索引`[l, r]`有相同的商`q`，所以我们减去：```python
(r - l + 1) * totient_sum(q)
```记忆化可以防止重新计算。 

---

 ### 最终计算

 我们使用：$$H(n) = 6\left( \frac{n(n+1)}{2} - \Phi(n) \right).$$---

 ## 4.验证

 -$H(5)=30$-$H(10)=138$-$H(1000)=1177848$最终结果是正数并且具有预期的数量级（大致与$n^2$）。
