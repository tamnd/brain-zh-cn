[项目欧拉问题 843](https://projecteuler.net/problem=843)

 ## 解决方案

 **答案：**`2816775424692`设圆上的数字为$a_0,a_1,\dots,a_{n-1}$, 索引模数$n$。 

该过程的一个步骤取代$$a_i \longmapsto |a_{i-1}-a_{i+1}|.$$关键事实是，可能的最终周期的集合完全由模确定$2$。 

模数$2$,$$|x-y|\equiv x+y \pmod 2,$$就这样结束了$\mathbb F_2$映射变成线性变换$$T(a_i)=a_{i-1}+a_{i+1}.$$这是经典的 Rule-90 元胞自动机。 

---

 # 1. 代数公式

 用多项式表示状态$$A(x)=\sum_{i=0}^{n-1} a_i x^i$$在环中$$R_n=\mathbb F_2[x]/(x^n-1).$$那么一次迭代就是简单的$$A(x)\mapsto (x+x^{-1})A(x).$$自从$x^{-1}=x^{n-1}$在商环中，$$T(A)=(x+x^{n-1})A.$$因此，动力学是乘以有限环的固定元素$R_n$。 

---

 # 2. 周期结构

 写$$n=2^s m,\qquad m\ \text{odd}.$$超过$\mathbb F_2$,$$x^n-1=(x^m-1)^{2^s}.$$因素$x^m-1$化为不可约式：$$x^m-1=\prod_i f_i(x).$$每个因素都给出了动态的独立组成部分。 

对于不可约因子$f$， 让$\alpha$是一个根$f$。 

在该组件上，映射通过乘以$$\beta=\alpha+\alpha^{-1}.$$该分量贡献的周期是$\beta$在由 生成的有限域中$\alpha$。 

如果$n$有一个因素$2^s$，重复的因子引入了额外的二次方乘数$2^b$和$0\le b\le s$。 

因此：

 - 每个不可约因子贡献一个基本奇数周期$o$,
 - 可能的周期是通过获取组成周期的 LCM 获得的，
 - 并乘以来自重复因子的二的幂。 

接管一切$3\le n\le N$给出总和为的集合$S(N)$。 

---

 # 3. 实例验证

 对于$3\le n\le 6$：

 -$n=3$： 期间$\{1\}$-$n=4$： 期间$\{1\}$-$n=5$： 期间$\{1,3\}$-$n=6$： 期间$\{1,2\}$联盟：$$\{1,2,3\}$$所以$$S(6)=1+2+3=6,$$与声明相符。 

为了$N=30$，计算准确地给出$$S(30)=20381,$$再次匹配问题陈述。

 # 4.Python实现```python
import math
import sympy as sp

x = sp.symbols('x')

# convert a GF(2) polynomial to bit representation
def poly_to_int(poly):
    v = 0
    for (e,), c in poly.terms():
        if int(c) & 1:
            v |= (1 << e)
    return v

# multiplication in GF(2)[x]/(modpoly)
def mul(a, b, modpoly, deg):
    r = 0
    while b:
        if b & 1:
            r ^= a
        b >>= 1
        a <<= 1
        if a >> deg:
            a ^= modpoly
    return r

def powmod(a, e, modpoly, deg):
    r = 1
    while e:
        if e & 1:
            r = mul(r, a, modpoly, deg)
        a = mul(a, a, modpoly, deg)
        e >>= 1
    return r

# multiplicative order in the finite field
def order(a, modpoly, deg):
    group_order = (1 << deg) - 1
    ans = group_order

    for p, e in sp.factorint(group_order).items():
        for _ in range(e):
            if powmod(a, ans // p, modpoly, deg) == 1:
                ans //= p
            else:
                break

    return ans

def periods_for_n(n):
    # n = 2^s * m  with m odd
    s = 0
    m = n
    while m % 2 == 0:
        s += 1
        m //= 2

    poly = sp.Poly(x**m - 1, x, modulus=2)
    factors = sp.factor_list(poly, modulus=2)[1]

    component_choices = []

    for f, _ in factors:

        # ignore x+1 (gives only the trivial fixed point)
        if f.degree() == 1:
            continue

        deg = f.degree()
        modpoly = poly_to_int(f)

        alpha = 2                      # polynomial x
        alpha_inv = powmod(alpha, m - 1, modpoly, deg)

        beta = alpha ^ alpha_inv       # alpha + alpha^{-1} over GF(2)

        odd_period = order(beta, modpoly, deg)

        choices = [1]
        for b in range(s + 1):
            choices.append(odd_period * (1 << b))

        component_choices.append(choices)

    periods = {1}

    for choices in component_choices:
        new_periods = set()
        for a in periods:
            for b in choices:
                new_periods.add(math.lcm(a, b))
        periods = new_periods

    return periods

def S(N):
    all_periods = set()

    for n in range(3, N + 1):
        all_periods |= periods_for_n(n)

    return sum(all_periods)

print(S(30))   # 20381
print(S(100))
```---

 运行程序给出$$S(100)=2816775424692.$$该值再现支票$S(30)=20381$，所以计算是一致的。 

**答案：2816775424692**
