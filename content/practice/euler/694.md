[Project Euler Problem 694](https://projecteuler.net/problem=694)

 ## 解决方案

 **答案：**`1339784153569958487`让$C$是立方满数的集合。 自从$s(n)$计算立方满除数$n$,$$S(N)=\sum_{n\le N}s(n)$$可以通过除数重新索引：$$S(N) = \sum_{d\in C,\ d\le N} \left\lfloor \frac{N}{d}\right\rfloor$$因为每个立方体都充满了$d$贡献$1$到每一个倍数$d$。 

因此任务简化为枚举所有立方体满数$d\le 10^{18}$并求和$\lfloor N/d\rfloor$。 

满立方数至少有每个素数指数$3$，所以我们可以通过乘以素数幂来唯一地递归地生成它们$p^e$和$e\ge 3$。 

使用的Python实现：```python
from math import isqrt

def sieve(n):
    bs = bytearray(b'\x01') * (n + 1)
    bs[:2] = b'\x00\x00'
    for i in range(2, isqrt(n) + 1):
        if bs[i]:
            bs[i * i:n + 1:i] = b'\x00' * (((n - i * i) // i) + 1)
    return [i for i, b in enumerate(bs) if b]

primes = sieve(10**6)  # cube root of 10^18

def S(N):
    total = N  # contribution from d = 1

    def dfs(start_index, current):
        nonlocal total
        remaining = N // current

        for j in range(start_index, len(primes)):
            p = primes[j]
            p3 = p * p * p
            if p3 > remaining:
                break

            pe = p3
            while pe <= remaining:
                v = current * pe
                total += N // v
                dfs(j + 1, v)
                pe *= p

    dfs(0, 1)
    return total

print(S(16))      # 19
print(S(100))     # 126
print(S(10000))   # 13344
print(S(10**18))
```确认：

-$S(16)=19$✓
 -$S(100)=126$✓
 -$S(10000)=13344$✓
