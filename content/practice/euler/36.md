[欧拉项目问题 36](https://projecteuler.net/problem=36)

 ## 解决方案

 **答案：**`872187`我们寻找所有整数$n < 10^6$这样：

 1.$n$是一个以 10 为基数的回文。 
2. 的二进制表示$n$也是一个回文。 
3. 两种表示形式均不允许有前导零。 

然后我们将所有这些数字相加。 

---

 # 数学分析

 回文从前向后读都是一样的。 

例如：

-$585$十进制表示为：$$585$$这是回文的。 
- 二进制：$$585 = 1001001001_2$$这也是回文。 

我们必须找到所有低于一百万的数字。 

## 主要观察结果

 ### 1. 十进制回文很少见

 而不是检查每个数字$1$到$999999$，仅生成十进制回文要快得多。 

6 位回文数的形式为：$$abc|cba$$5 位回文的形式为：$$ab|c|ba$$一百万以下的十进制回文数很少：

 - 1 位数字：$9$- 2 位数字：$9$- 3 位数字：$90$- 4 位数字：$90$- 5 位数字：$900$- 6 位数字：$900$全部的：$$9+9+90+90+900+900 = 1998$$因此，我们只检查大约 2000 个号码，而不是检查 100 万个号码。 

---

 ### 2.二进制回文不能以0结尾

 二进制回文不能有前导零。 

如果一个二进制数以$0$，那么根据对称性，它也会以$0$， 不可能的。 

因此每个二进制回文都是奇数。 

因此，每个有效数字都必须是奇数。 

这立即消除了所有偶数十进制回文。 

---

 ### 3.高效的回文测试

 一个字符串$s$是回文当且仅当：$$s = s[::-1]$$所以：

 - 十进制回文：```python
str(n) == str(n)[::-1]
```- 二进制回文：```python
b = bin(n)[2:]
b == b[::-1]
```---

 # Python 实现```python
def is_palindrome(s):
    """Return True if string s is a palindrome."""
    return s == s[::-1]

total = 0

# Check every odd number below one million
for n in range(1, 1_000_000, 2):

    # Check decimal palindrome
    if is_palindrome(str(n)):

        # Convert to binary without '0b'
        b = bin(n)[2:]

        # Check binary palindrome
        if is_palindrome(b):
            total += n

print(total)
```---

 # 代码演练

 ## 回文助手```python
def is_palindrome(s):
    return s == s[::-1]
```-`s[::-1]`反转字符串。 
- 相等意味着字符串向前和向后读取相同。 

示例：```python
is_palindrome("585")        # True
is_palindrome("1001001001") # True
is_palindrome("123")        # False
```---

 ## 初始化总和```python
total = 0
```这会累积所有符合条件的号码。
