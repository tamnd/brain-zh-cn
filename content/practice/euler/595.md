[项目欧拉问题 595](https://projecteuler.net/problem=595)

 ## 解决方案

 **答案：**`54.17529329`让$S(n)$表示从均匀随机排列开始时所需的预期洗牌次数$n$牌。 

## 1.数学分析

 ### 第 1 步：重新制定流程

 在任何阶段，已经按连续升序排列的卡片都会被**附加到捆绑包中**。 

例子：$$4123756 \to (4)(123)(7)(56)$$关键的观察：

 > 一旦卡片被捆绑，只有**捆绑的相对顺序**重要。 

如果有$k$束，然后将它们扔到空中并捡起来后，我们获得了**均匀随机排列$k$捆绑**。 

因此，状态仅取决于：$$k = \text{number of bundles}$$让：$$E_k = \text{expected additional shuffles needed from a random arrangement of } k \text{ bundles}.$$我们想要：$$S(n)=E_n.$$---

 ### 步骤 2：转移概率

 假设我们目前有$k$捆绑。 

当两个连续的束以正确的顺序相邻出现时，束边界消失。 

定义：$$r = \text{number of successful adjacencies}$$然后检查后：$$j = k-r$$捆绑仍然存在。 

我们需要概率$p_{k,j}$的随机排列$k$物体准确地产生$j$捆绑。 

等价地，我们精确地计算排列$r=k-j$相邻有序对：$$(i,i+1)$$为了$i=1,\dots,k-1$。 

使用包含-排除：$$N_{k,r} = \sum_{s=r}^{k-1} (-1)^{s-r} \binom{s}{r} \binom{k-1}{s} (k-s)!$$在哪里$N_{k,r}$是恰好具有的排列数$r$成功的邻接。 

因此$$p_{k,j} = \frac{N_{k,k-j}}{k!}.$$---

 ### 步骤 3：期望的重现

 如果排列已经排序，则不需要洗牌。 

只有当$j=1$，有概率$1/k!$。 

否则，恰好发生**一次洗牌**，并且我们从新的捆绑计数继续。 

因此：$$E_k = \left(1-\frac1{k!}\right) + \sum_{j=2}^{k} p_{k,j}E_j.$$自任期以来$j=k$包含$E_k$本身：$$E_k(1-p_{k,k}) = \left(1-\frac1{k!}\right) + \sum_{j=2}^{k-1} p_{k,j}E_j.$$所以：$$E_k = \frac{ 1-\frac1{k!} + \sum_{j=2}^{k-1} p_{k,j}E_j }{ 1-p_{k,k} }.$$基本情况：$$E_1=0.$$---

 ## 2.Python实现```python
from math import comb, factorial

def expected_shuffles(n):
    # E[k] = expected shuffles for k bundles
    E = [0.0] * (n + 1)

    # Precompute factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i

    # Build E[k] iteratively
    for k in range(2, n + 1):

        rhs = 1.0 - 1.0 / fact[k]

        # Contributions from smaller states
        for j in range(2, k):
            r = k - j

            # Inclusion-exclusion count N_{k,r}
            count = 0
            for s in range(r, k):
                count += (
                    (-1) ** (s - r)
                    * comb(s, r)
                    * comb(k - 1, s)
                    * fact[k - s]
                )

            p_kj = count / fact[k]
            rhs += p_kj * E[j]

        # Probability of staying at k bundles
        count_same = 0
        for s in range(k):
            count_same += (
                (-1) ** s
                * comb(k - 1, s)
                * fact[k - s]
            )

        p_kk = count_same / fact[k]

        E[k] = rhs / (1.0 - p_kk)

    return E[n]

# Check given examples
print(expected_shuffles(2))  # 1
print(expected_shuffles(5))  # 4213/871 ≈ 4.836969001148105

# Required answer
ans = expected_shuffles(52)
print(f"{ans:.8f}")
```---
