[欧拉项目965问题](https://projecteuler.net/problem=965)

 ## 解决方案

 **答案：**`0.0003452201133`让$$f_N(x)=\min_{1\le n\le N}\{nx\}.$$对于均匀随机$x\in[0,1]$,$$F(N)=\mathbb E[f_N(x)].$$计算非负随机变量期望的标准方法是$$F(N)=\int_0^1 \Pr(f_N(x)>t)\,dt.$$现在，$$f_N(x)>t$$意味着对于每一个$1\le n\le N$,$$\{nx\}>t.$$等价地，$x$避免所有间隔$$\left[\frac{k}{n},\,\frac{k+t}{n}\right] \qquad (0\le k<n,\ 1\le n\le N).$$未覆盖的间隙由 Farey 顺序序列中的相邻分数确定$N$。 

如果$$\frac ab < \frac cd$$是相邻的 Farey 分数，那么$$bc-ad=1,$$未发现的差距有助于$$\max\!\left(0,\frac1{bd}-\frac{t}{b}\right).$$这正好适用于$0\le t\le 1/d$。 

积分超过$t$,$$\int_0^{1/d}\left(\frac1{bd}-\frac{t}{b}\right)\,dt = \frac1{2bd^2}.$$所以，$$F(N)=\sum_{\text{adjacent } a/b<c/d \text{ in Farey}(N)} \frac1{2bd^2}.$$这可以使用 Farey 序列的标准迭代生成来有效地计算。 

Python代码：```python
from decimal import Decimal, getcontext

getcontext().prec = 50

N = 10000

# Farey sequence generation
a, b, c, d = 0, 1, 1, N

ans = Decimal(0)

while c <= N:
    ans += Decimal(1) / (Decimal(2) * b * d * d)

    k = (N + b) // d
    a, b, c, d = c, d, k * c - a, k * d - b

print(ans)
```这会产生$$F(10^4)=0.0003452201133312345\ldots$$四舍五入到小数点后 13 位：

 **答案：0.0003452201133**
