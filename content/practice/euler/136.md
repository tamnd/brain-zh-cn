[欧拉项目问题 136](https://projecteuler.net/problem=136)

 ## 解决方案

 **答案：**`2544559`让$$x,\ y,\ z$$是算术级数的连续项。 将它们写为$$x = y+d,\qquad z = y-d$$对于某个正整数$d$。 

我们被要求学习$$x^2-y^2-z^2=n.$$我们想数一下有多少个$n<50\,000\,000$有**恰好一个**正整数解。 

---

 # 1.数学分析

 替补$$x=y+d,\qquad z=y-d.$$然后$$n=(y+d)^2-y^2-(y-d)^2.$$扩张：$$(y+d)^2 = y^2+2yd+d^2,$$

$$(y-d)^2 = y^2-2yd+d^2.$$所以$$n = (y^2+2yd+d^2)-y^2-(y^2-2yd+d^2).$$简化：$$n = 4yd-y^2-d^2.$$如果我们切换变量，就会出现更清晰的因式分解。 

让$$a = y-d = z.$$然后$$y=a+d,\qquad x=a+2d.$$代替：$$n=(a+2d)^2-(a+d)^2-a^2.$$扩张：$$(a+2d)^2=a^2+4ad+4d^2,$$

$$(a+d)^2=a^2+2ad+d^2.$$因此$$n=a^2+4ad+4d^2-a^2-2ad-d^2-a^2.$$所以$$n=2ad+3d^2-a^2.$$因素：$$n=(3d-a)(a+d).$$现在定义$$u=3d-a,\qquad v=a+d.$$然后$$n=uv.$$还，$$u+v=4d,$$所以$u\equiv -v\pmod 4$, 等价地$$u+v\equiv0\pmod4.$$自从$$a=\frac{3v-u}{4}>0,$$我们必须有$$u<3v.$$---

 ## 更简单的参数化

 有一个标准的简化。 

开始于$$n=(3d-a)(a+d),$$放$$p=a+d,\qquad q=3d-a.$$然后$$n=pq,$$和$$p+q=4d.$$因此，每个解决方案都完全对应于因式分解$$n=pq$$这样$$p+q\equiv0\pmod4.$$此外，积极性$a$给出$$3p>q.$$---

 # 计算唯一的解决方案

 我们需要的数量$n<50\,000\,000$正好一对$(p,q)$满意：

 1.$$pq=n$$1.$$p+q\equiv0\pmod4$$1.$$q<3p$$直接除数计数方法仍然很大。 

欧拉计划的关键见解是，只有一个解的数字会分为三种不相交的形式。 

---

 # 2. 通过除数结构分类

 来自$$n=(3d-a)(a+d),$$让$$u=3d-a,\qquad v=a+d.$$然后$$u+v=4d.$$所以$u,v$具有相同的奇偶性，并且事实上两者模全等$2$。 

仔细分析除数条件得出：

 一个数字$n$只有一个解决方案，当且仅当它是以下之一：

 1.素数$p$和$$p\equiv3\pmod4$$1. 四次素数：$$n=4p$$在哪里$p$是素数

 1.素数十六次：$$n=16p$$在哪里$p$是素数并且$$p\equiv3\pmod4.$$这种分类是关键的突破。 

因此答案是：$$\pi_{3\bmod4}(50\,000\,000) + \pi\!\left(\frac{50\,000\,000}{4}\right) + \pi_{3\bmod4}\!\left(\frac{50\,000\,000}{16}\right)$$在哪里：

-$\pi(x)$= 素数个数$\le x$-$\pi_{3\bmod4}(x)$= 素数个数$\le x$一致于$3 \pmod 4$---

 # 3.Python实现```python
from math import isqrt

LIMIT = 50_000_000

def sieve(n):
    """Return list of primes up to n using sieve of Eratosthenes."""
    is_prime = bytearray(b"\x01") * (n + 1)
    is_prime[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            is_prime[start:n + 1:step] = b"\x00" * ((n - start) // step + 1)

    return is_prime

# We need primes up to 50,000,000
prime = sieve(LIMIT)

count = 0

# Case 1: n = p where p ≡ 3 (mod 4)
for p in range(3, LIMIT):
    if prime[p] and p % 4 == 3:
        count += 1

# Case 2: n = 4p
for p in range(2, LIMIT // 4):
    if prime[p]:
        count += 1

# Case 3: n = 16p where p ≡ 3 (mod 4)
for p in range(3, LIMIT // 16):
    if prime[p] and p % 4 == 3:
        count += 1

print(count)
```---
