[项目欧拉问题 517](https://projecteuler.net/problem=517)

 ## 解决方案

 **答案：**`581468882`让$a>1$是非理性的（对于$a=\sqrt p$什么时候$p$是素数）。 

我们被给予$$g_a(x)= \begin{cases} 1,&x<a,\\ g_a(x-1)+g_a(x-a),&x\ge a. \end{cases}$$我们必须计算$$G(n)=g_{\sqrt n}(n),$$最后$$\sum_{\substack{p\text{ prime}\\10^7<p<10010000}} G(p)\pmod{10^9+7}.$$---

 # 1.数学分析

 ## 1.1 组合解释

 复发$$g(x)=g(x-1)+g(x-a)$$类似于使用长度步数计算路径$1$和$a$。 

因为$a$是无理数，形式中的每个数字$$m+na$$具有独特的代表性。 这消除了递归树中的所有歧义。 

定义：

-$k$= 数量$a$-步骤，
 -$j$= 数量$1$-步骤。 

那么总长度是$$j+ka.$$对于固定$k$，条件$$j+ka\le x$$变成$$j\le \lfloor x-ka\rfloor.$$对于每个可受理的$j$，包含以下内容的序列数：

 -$k$的副本$a$,
 -$j$的副本$1$，

是$$\binom{j+k}{k}.$$所以$$g_a(x)= \sum_{k\ge0}\sum_{j=0}^{\lfloor x-ka\rfloor}\binom{j+k}{k}.$$现在使用曲棍球棒恒等式：$$\sum_{j=0}^{m}\binom{j+k}{k} = \binom{m+k+1}{k+1}.$$因此$$g_a(x) = \sum_{k\ge0} \binom{\lfloor x-ka\rfloor+k+1}{k+1}.$$重新索引$k\mapsto k-1$:$$\boxed{ g_a(x)= \sum_{k\ge0} \binom{\lfloor x-ka\rfloor+k}{k} }.$$---

 ## 1.2 公式$G(n)$放$a=\sqrt n$,$x=n$:$$\boxed{ G(n)= \sum_{k=0}^{\lfloor\sqrt n\rfloor} \binom{\lfloor n-k\sqrt n\rfloor+k}{k} }.$$问题给出$$G(90)=7564511.$$检查：$$G(90) = \sum_{k=0}^{9} \binom{\lfloor 90-k\sqrt{90}\rfloor+k}{k} = 7564511,$$所以公式是正确的。 

---

 # 2.高效的模块化计算

 我们需要所有素数$$10^7<p<10010000.$$它们只有几百个，并且对于每个素数$p$,$$k\le \lfloor\sqrt p\rfloor \approx 3162.$$所以二项式评估的总数大约只有$2\times10^6$。 

我们计算所有二项式系数的模$$M=10^9+7$$使用阶乘和逆阶乘。

 # 3.Python实现```python
import math

MOD = 1_000_000_007

LOW = 10_000_000
HIGH = 10_010_000

# ------------------------------------------------------------
# Segmented sieve for primes in (LOW, HIGH)
# ------------------------------------------------------------

limit = int(math.isqrt(HIGH)) + 1

base = [True] * (limit + 1)
base[0] = base[1] = False

for i in range(2, int(limit ** 0.5) + 1):
    if base[i]:
        step = i
        start = i * i
        for j in range(start, limit + 1, step):
            base[j] = False

small_primes = [i for i, v in enumerate(base) if v]

seg = [True] * (HIGH - LOW)

for p in small_primes:
    start = max(p * p, ((LOW + p - 1) // p) * p)
    for x in range(start, HIGH, p):
        seg[x - LOW] = False

primes = [LOW + i for i, v in enumerate(seg) if v and LOW + i > LOW]

# ------------------------------------------------------------
# Precompute factorials modulo MOD
# ------------------------------------------------------------

N = HIGH + 5000

fact = [1] * (N + 1)

for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact = [1] * (N + 1)

invfact[N] = pow(fact[N], MOD - 2, MOD)

for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    """Compute nCr modulo MOD."""
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

# ------------------------------------------------------------
# Compute G(p)
# ------------------------------------------------------------

def G(p):
    a = math.sqrt(p)

    total = 0

    for k in range(int(a) + 1):
        n = math.floor(p - k * a) + k
        total = (total + C(n, k)) % MOD

    return total

answer = 0

for p in primes:
    answer = (answer + G(p)) % MOD

print(answer)
```---
