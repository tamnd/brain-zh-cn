[欧拉项目问题 381](https://projecteuler.net/problem=381)

 ## 解决方案

 **答案：**`139602943319822`对于素数$p \ge 5$， 定义$$S(p)=\sum_{k=1}^{5}(p-k)! \pmod p.$$我们必须计算$$\sum_{5\le p<10^8} S(p),$$其中总和超过素数。 

---

 # 1.数学分析

 关键思想是使用威尔逊定理：$$(p-1)! \equiv -1 \pmod p$$对于每个素数$p$。 

我们反复“向后除”以用以下形式表达其他阶乘$(p-1)!$。 

---

 ## 步骤 1：表达每个阶乘模$p$自从$$(p-1)!=(p-1)(p-2)!,$$和$p-1\equiv -1 \pmod p$,$$- (p-2)! \equiv -1 \pmod p,$$所以$$(p-2)! \equiv 1 \pmod p.$$下一个，$$(p-2)!=(p-2)(p-3)! \equiv (-2)(p-3)!,$$因此$$(p-3)! \equiv -\frac12 \pmod p.$$相似地，$$(p-4)! \equiv \frac16 \pmod p,$$和$$(p-5)! \equiv -\frac1{24} \pmod p.$$所以，$$S(p)\equiv -1+1-\frac12+\frac16-\frac1{24}.$$前两项取消：$$S(p)\equiv -\frac12+\frac16-\frac1{24}.$$使用分母$24$,$$S(p)\equiv \frac{-12+4-1}{24} = -\frac9{24} = -\frac38 \pmod p.$$所以整个问题简化为$$\boxed{S(p)\equiv -3\cdot 8^{-1}\pmod p}.$$这是关键的简化。 

---

 ## 步骤2：高效计算

 我们只需要模逆，而不是阶乘：```python
S(p) = (-3 * pow(8, -1, p)) % p
```对于每个素数$p$。 

然后，复杂性由素数生成主导，直到$10^8$。 

有大约$5.76\times10^6$下面的素数$10^8$，因此埃拉托斯特尼筛法是完全可行的。 

---

 # 2.Python实现```python
from math import isqrt

LIMIT = 10**8

# Sieve of Eratosthenes (odd numbers only)
n = LIMIT
sieve = bytearray(b"\x01") * (n // 2)
sieve[0] = 0  # 1 is not prime

for i in range(3, isqrt(n) + 1, 2):
    if sieve[i // 2]:
        start = i * i
        step = 2 * i
        sieve[start // 2 :: i] = b"\x00" * (((n - start - 1) // step) + 1)

total = 0

# Iterate over odd primes
for p in range(5, n, 2):
    if sieve[p // 2]:
        total += (-3 * pow(8, -1, p)) % p

print(total)
```---

```这与问题的检查值一致。
