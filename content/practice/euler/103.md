 **答案：**`20313839404245`设定最佳的特殊和尺寸$n$是$$A=\{a_1<a_2<\cdots<a_n\}.$$我们需要最佳的特殊金额设置$n=7$，然后将元素连接成所需的集合字符串。

 # 1.数学分析

 一套$A$如果对于任意两个非空不相交子集，则它是一个**特殊和集**$B,C\subseteq A$：

 1.$S(B)\neq S(C)$2.如果$|B|>|C|$， 然后$S(B)>S(C)$我们想要总金额最小的特殊金额集。 

---

 ## 关键结构特性

 假设$$a_1<a_2<\cdots<a_n.$$可以有效地检查条件(2)。 

对于已排序的正数，违反条件 (2) 的最坏情况是：

 - 最小的$k+1$元素

 与
 - 最大的$k$元素。 

因此我们只需要：$$a_1+a_2+\cdots+a_{k+1} > a_n+a_{n-1}+\cdots+a_{n-k+1}$$对于所有相关的$k$。 

为了$n=7$，这变成：$$a_1+a_2 > a_7$$

$$a_1+a_2+a_3 > a_7+a_6$$

$$a_1+a_2+a_3+a_4 > a_7+a_6+a_5$$这些不平等极大地减少了搜索。 

---

 ## 近乎最佳的构造

 问题陈述给出了启发：

 如果$$A=\{a_1,\dots,a_n\}$$是最佳的，然后是接近最佳尺寸的集合$n+1$是$$B=\{b,a_1+b,\dots,a_n+b\},$$在哪里$b$是中间元素$A$。 

使用最优的$n=6$放$$\{11,18,19,20,22,25\},$$启发式给出：$$\{20,31,38,39,40,42,45\}.$$这非常接近真正的最优值，所以我们只需要在附近搜索即可。 

---

 ## 条件（1）：不同子集和

 对于一组尺寸$7$，只有$$2^7-1=127$$非空子集。 

我们可以计算每个子集的总和，并确保没有两个不相交的子集具有相等的总和。 

标准位掩码方法效果很好：

 - 用位掩码表示每个子集，
 - 计算其总和，
 - 如果两个子集具有相同的和且不相交的掩码，则拒绝该集合。 

---

 ## 搜索策略

 我们围绕启发式中心进行搜索：$$(20,31,38,39,40,42,45).$$由于最优集是紧密聚集的，因此有界 DFS/回溯搜索可以快速找到最小有效集。 

已知的最优结果是：$$\{20,31,38,39,40,42,45\}.$$其总和为$$20+31+38+39+40+42+45=255.$$因此，所需的设置字符串是：$$20313839404245.$$---

 # 2.Python实现```python
from itertools import combinations

def satisfies_rule_two(arr):
    """
    Check:
    If |B| > |C| then S(B) > S(C)

    For sorted positive arrays, it is enough to verify:
    sum(first k+1) > sum(last k)
    """
    n = len(arr)

    for k in range(1, n // 2 + 1):
        if sum(arr[:k + 1]) <= sum(arr[-k:]):
            return False

    return True

def satisfies_rule_one(arr):
    """
    Check:
    No two disjoint non-empty subsets have equal sums.
    """

    n = len(arr)

    # map: subset_sum -> list of masks producing that sum
    sums = {}

    for mask in range(1, 1 << n):

        s = 0
        for i in range(n):
            if mask & (1 << i):
                s += arr[i]

        if s not in sums:
            sums[s] = [mask]
        else:
            # equal sum found; ensure subsets are not disjoint
            for other in sums[s]:
                if (other & mask) == 0:
                    return False

            sums[s].append(mask)

    return True

def is_special_sum_set(arr):
    return (
        satisfies_rule_two(arr)
        and satisfies_rule_one(arr)
    )

best = None
best_sum = float('inf')

# Near-optimum template from the problem statement
base = [20, 31, 38, 39, 40, 42, 45]

# Search nearby
def search(pos, current):
    global best, best_sum

    n = len(base)

    if pos == n:

        if sum(current) >= best_sum:
            return

        if is_special_sum_set(current):
            best = current[:]
            best_sum = sum(current)

        return

    # small perturbations around the heuristic set
    for delta in range(-3, 4):

        val = base[pos] + delta

        if current and val <= current[-1]:
            continue

        current.append(val)

        # early pruning using rule two
        if satisfies_rule_two(current):
            search(pos + 1, current)

        current.pop()

search(0, [])

print(best)
print("set string =", "".join(str(x) for x in best))
```---
