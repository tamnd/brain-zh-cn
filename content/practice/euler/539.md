[欧拉项目问题 539](https://projecteuler.net/problem=539)

 ## 解决方案

 **答案：**`426334056`让$P(n)$成为交替淘汰过程的幸存者。 

我们得到：

 -$P(1)=1$-$P(9)=6$-$P(1000)=510$-$S(n)=\sum_{k=1}^n P(k)$-$S(1000)=268271$我们必须计算：$$S(10^{18}) \bmod 987654321$$---

 # 1.数学分析

 ## 步骤 1：重复$P(n)$第一次从左到右传递后$1,2,\dots,n$：

 - 所有奇数都被删除，
 - 剩余的列表是$$2,4,6,\dots,2\left\lfloor \frac n2 \right\rfloor$$将所有内容除以$2$。 剩下的问题变成同样的消除过程，但从相反的方向开始。 

如果我们将幸存者表示为$P(n)$，那么经典的消除游戏递归式为：$$P(n)=2\left(1+\left\lfloor\frac n2\right\rfloor-P\!\left(\left\lfloor\frac n2\right\rfloor\right)\right)$$带底座$$P(1)=1.$$等价地，对于$n\ge1$,$$P(2n)=P(2n+1)=2(n+1-P(n)).$$这立即解释了为什么连续的奇数/偶数对具有相等的值。 

---

 ## 步骤 2：推导递归$S(n)$定义$$A(n)=\sum_{k=1}^n P(2k).$$使用递归：$$P(2k)=2(k+1-P(k)),$$所以$$A(n) =\sum_{k=1}^n 2(k+1-P(k)).$$所以$$A(n) =2\sum_{k=1}^n k + 2n -2S(n).$$自从$$\sum_{k=1}^n k=\frac{n(n+1)}2,$$我们得到$$A(n)=n(n+1)+2n-2S(n) =n^2+3n-2S(n).$$---

 ## 第三步：表达$S(2n)$和$S(2n+1)$因为$$P(2k-1)=P(2k),$$我们有$$S(2n) =1+2\sum_{k=1}^{n-1}P(2k)+P(2n).$$那是，$$S(2n)=1+2A(n)-P(2n).$$代入公式：$$A(n)=n^2+3n-2S(n),$$和$$P(2n)=2(n+1-P(n)).$$化简后：$$\boxed{ S(2n)=2n^2+4n-1-2S(n)-2S(n-1) }$$相似地，$$S(2n+1)=S(2n)+P(2n+1).$$自从$P(2n+1)=P(2n)$,$$S(2n+1)=1+2A(n),$$因此$$\boxed{ S(2n+1)=2n^2+6n+1-4S(n) }$$这些递归每次都会将参数减少一半，因此复杂度仅为$O(\log n)$。 

---

 # 2.Python实现```python
from functools import lru_cache

MOD = 987654321

@lru_cache(None)
def S(n):
    # Base cases
    if n <= 0:
        return 0
    if n == 1:
        return 1

    # Even case: n = 2m
    if n % 2 == 0:
        m = n // 2
        return (
            2 * m * m
            + 4 * m
            - 1
            - 2 * S(m)
            - 2 * S(m - 1)
        ) % MOD

    # Odd case: n = 2m + 1
    else:
        m = n // 2
        return (
            2 * m * m
            + 6 * m
            + 1
            - 4 * S(m)
        ) % MOD

answer = S(10**18)
print(answer)
```---

 # 3. 代码演练

 ## 记忆```python
@lru_cache(None)
```存储先前计算的值$S(n)$，确保每个子问题都解决一次。 

因为每次递归都会使参数减半，所以只有大约 60 个不同的递归级别$10^{18}$。 

---

 ## 基本情况```python
if n <= 0:
    return 0
if n == 1:
    return 1
```这些对应于：$$S(0)=0,\qquad S(1)=1.$$---

 ## 偶数情况```python
if n % 2 == 0:
    m = n // 2
```然后$n=2m$，我们应用：$$S(2m)=2m^2+4m-1-2S(m)-2S(m-1).$$---

 ## 奇怪的情况```python
else:
    m = n // 2
```然后$n=2m+1$，我们应用：$$S(2m+1)=2m^2+6m+1-4S(m).$$---
