 ## 解决方案

 **答案：**`1533776805`我们给出了三个图形数字序列：$$T_n=\frac{n(n+1)}2,\qquad P_n=\frac{n(3n-1)}2,\qquad H_n=n(2n-1)$$我们知道：$$T_{285}=P_{165}=H_{143}=40755$$我们必须找到**下一个**同时是三角形、五边形和六边形的数字。 

---

 # 1.数学分析

 ## 步骤 1 — 关联六边形数和三角形数

 观察：$$H_n=n(2n-1)$$现在与三角形数进行比较：$$T_m=\frac{m(m+1)}2$$如果我们设置：$$m=2n-1$$然后$$T_{2n-1} = \frac{(2n-1)(2n)}2 = n(2n-1) = H_n$$所以**每个六边形数自动都是三角形**。 

因此，我们不需要检查所有三个条件，而只需要找到一个也是五边形的六边形数。 

---

 ## 步骤 2 — 五边形测试

 假设一个数字$x$是五边形：$$x=\frac{k(3k-1)}2$$两边同时乘以$24$:$$24x = 12k(3k-1)$$添加 1：$$24x+1 = 36k^2-12k+1 = (6k-1)^2$$因此：$$x \text{ is pentagonal} \iff 24x+1 \text{ is a perfect square}$$具体来说：$$\sqrt{24x+1}\equiv 5 \pmod 6$$所以对于每个六边形数$H_n$，我们可以测试是否：$$24H_n+1$$是一个完美的正方形。 

---

 ## 步骤 3 — 搜索已知解

 我们被告知：$$H_{143}=40755$$所以我们从以下位置开始检查：$$n=144$$计算：$$H_n=n(2n-1)$$并测试它是否是五边形。 

40755 之后的第一场比赛是：$$1533776805$$---

 # 2.Python实现```python
import math

def is_pentagonal(x):
    """
    Check whether x is pentagonal.

    A number x is pentagonal iff:
        24*x + 1
    is a perfect square and congruent to 5 mod 6.
    """
    d = 24 * x + 1
    s = math.isqrt(d)

    return s * s == d and (1 + s) % 6 == 0

n = 144  # Start just after H_143

while True:
    # Hexagonal number
    h = n * (2 * n - 1)

    # Since every hexagonal number is triangular,
    # only test pentagonality.
    if is_pentagonal(h):
        print(h)
        break

    n += 1
```---
