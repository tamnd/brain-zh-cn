[欧拉项目问题 348](https://projecteuler.net/problem=348)

 ## 解决方案

 **答案：**`1004195061`让一个数$N$可以表示为$$N = a^2 + b^3$$和$a>1$和$b>1$。 

我们寻求**五个最小的回文数**，它们允许这种形式的**恰好四种不同的表示**。 

---

 # 数学分析

 我们需要结合三个想法：

 1. 高效生成回文。 
2. 测试一个回文是否可以写成一个正方形加一个立方体。 
3. 准确计算表示次数。 

---

 ## 1.为什么直接生成回文？ 

检查每个整数是浪费的，因为回文是稀疏的。 

回文完全由其前半部分决定。 

示例：

 - 均匀长度：$$123321$$来自镜像$123$。 
- 奇数长度：$$12321$$来自镜像除最后一位数字之外的所有数字$123$。 

因此，我们可以非常便宜地生成递增顺序的回文。 

---

 ## 2. 计数表示

 对于固定回文$N$，我们想要所有对$$(a,b), \qquad a>1,\; b>1$$这样$$a^2 + b^3 = N.$$重新排列：$$a^2 = N - b^3.$$所以对于每个立方体$b^3 < N$:

 1. 计算$$r = N - b^3.$$2. 检查是否$r$是一个完美的正方形。 

快速完全平方检验是：$$a = \lfloor \sqrt{r} \rfloor,$$然后验证$$a^2 = r.$$每一次成功的检查都会给出一个表示。 

---

 ## 3. 复杂性

 假设$N$就在附近$10^9$。 

然后：$$b^3 \le N \quad\Rightarrow\quad b \le N^{1/3} \approx 1000.$$所以每个回文只需要大约$1000$立方体检查——非常易于管理。 

由于回文数很稀疏，因此这种蛮力变得实用。 

---

 # Python 实现```python
from math import isqrt

def generate_palindromes(limit):
    """
    Generate palindromes in increasing order up to 'limit'.
    """

    length = 1

    while True:
        # Number of digits used to build the first half
        start = 10 ** ((length - 1) // 2)
        end = 10 ** ((length + 1) // 2)

        for half in range(start, end):
            s = str(half)

            # Odd length palindrome
            if length % 2 == 1:
                p = int(s + s[-2::-1])

            # Even length palindrome
            else:
                p = int(s + s[::-1])

            if p > limit:
                return

            yield p

        length += 1

def count_representations(n):
    """
    Count representations of n as:
        n = a^2 + b^3
    with a > 1 and b > 1.
    """

    count = 0
    b = 2

    while b ** 3 < n - 4:
        cube = b ** 3
        remainder = n - cube

        a = isqrt(remainder)

        if a > 1 and a * a == remainder:
            count += 1

        b += 1

    return count

# Search for the first five palindromes
# having exactly four representations.

found = []

LIMIT = 2_000_000_000

for p in generate_palindromes(LIMIT):

    if count_representations(p) == 4:
        found.append(p)

        print("Found:", p)

        if len(found) == 5:
            break

answer = sum(found)

print("Sum =", answer)
```---

示例：

 如果`half = 123`- 奇数长度：```python
"123" + "21" -> 12321
```- 偶数长度：```python
"123" + "321" -> 123321
```这保证了回文以递增的顺序出现。

 ##`count_representations(n)`对于每个整数$b \ge 2$:

 1. 计算$$b^3$$2. 计算$$n - b^3$$3. 检查余数是否是完全平方数。 

整数平方根函数`isqrt()`使这变得精确而快速。
