[项目欧拉问题 480](https://projecteuler.net/problem=480)

 ## 解决方案

 **答案：**`turnthestarson`让$$S=\text{“thereisasyetinsufficientdataforameaningfulanswer”}$$并让$c_\ell$是每个字母的重数$S$。 

任务是处理**长度最多为 15** 的所有不同单词**，这些单词可以由多个字母集组成$S$，按字典顺序排列。 

---

 # 1.数学分析

 ## 计算前缀的完成情况

 假设我们还有可用的计数$$(c_1,c_2,\dots,c_m)$$对于其余的字母。 

我们需要一个函数：$$T(\mathbf c, r)$$= 最多长度的非空单词数$r$可以形成的。 

对于固定长度$k$，不同单词的数量是$$k!\sum_{\substack{a_i\le c_i\\ \sum a_i=k}} \frac{1}{a_1!a_2!\cdots a_m!}.$$这正是生成函数的系数形式$$\prod_i \left(\sum_{t=0}^{c_i}\frac{x^t}{t!}\right).$$因此，对于每个可达状态，我们计算所有长度计数$0\ldots 15$。 

---

 ## 对单词进行排名$P(w)$计算单词的字典顺序$w$：

 在每个位置：

 1. 尝试每个可能的较小字母。 
2. 计算以较小前缀开头的所有单词。 
3. 如果我们继续超过当前前缀，请添加 1，因为前缀本身也是一个有效单词，并且按字典顺序出现在其扩展名之前。 

例子：

-$P(\text{aaaaaacdee})=10$-$P(\text{euler})=115246685191495243$与声明相符。 

---

 ## 取消排名$W(p)$反转：

 给定一个等级$p$,

 - 按字母顺序迭代字母，
 - 确定每个前缀块中有多少个单词，
 - 减去块直到找到正确的块，
 - 递归下降。 

这会重建位置处的单词$p$。 

---

 # 2.Python实现```python
from collections import Counter
from functools import lru_cache
from fractions import Fraction
from math import factorial

S = "thereisasyetinsufficientdataforameaningfulanswer"

# Letter multiplicities
cnt = Counter(S)

alphabet = tuple(sorted(cnt))
initial = tuple(cnt[ch] for ch in alphabet)

index = {c: i for i, c in enumerate(alphabet)}

FACT = [factorial(i) for i in range(16)]

@lru_cache(None)
def total_words(state, rem):
    """
    Number of NONEMPTY words of length <= rem
    constructible from remaining multiset 'state'.
    """

    # Generating-function DP:
    # product (sum x^t / t!)
    poly = [Fraction(1, 1)] + [Fraction(0, 1) for _ in range(rem)]

    for c in state:
        nxt = [Fraction(0, 1) for _ in range(rem + 1)]

        for deg, val in enumerate(poly):
            if not val:
                continue

            for t in range(min(c, rem - deg) + 1):
                nxt[deg + t] += val / FACT[t]

        poly = nxt

    total = 0

    for k in range(1, rem + 1):
        total += int(poly[k] * FACT[k])

    return total

def rank_word(word):
    """
    Lexicographic position P(word), starting at 1.
    """

    state = initial
    rank = 1

    for i, ch in enumerate(word):

        # All smaller possible next letters
        for j, c in enumerate(alphabet):

            if c >= ch:
                break

            if state[j] == 0:
                continue

            ns = state[:j] + (state[j] - 1,) + state[j + 1:]

            # prefix itself + all continuations
            rank += 1 + total_words(ns, 14 - i)

        # Current prefix itself appears before extensions
        if i < len(word) - 1:
            rank += 1

        j = index[ch]
        state = state[:j] + (state[j] - 1,) + state[j + 1:]

    return rank

def unrank(rank):
    """
    Inverse map W(rank).
    """

    state = initial
    word = ""

    while True:

        for j, c in enumerate(alphabet):

            if state[j] == 0:
                continue

            ns = state[:j] + (state[j] - 1,) + state[j + 1:]

            block = 1 + total_words(ns, 15 - len(word) - 1)

            if rank > block:
                rank -= block
            else:
                word += c
                state = ns

                if rank == 1:
                    return word

                rank -= 1
                break

target = (
    rank_word("legionary")
    + rank_word("calorimeters")
    - rank_word("annihilate")
    + rank_word("orchestrated")
    - rank_word("fluttering")
)

answer = unrank(target)

print(answer)
```---

 # 3. 代码演练

 ##`total_words(state, rem)`使用指数生成函数$$\prod_i \left(\sum_{t=0}^{c_i}\frac{x^t}{t!}\right)$$计算所有遵守多重限制的不同字符串。 

乘法系数$x^k$经过$k!$将多项式分母转换为精确计数。 

---

 ##`rank_word(word)`在每个字符处：

 - 每个较小的有效下一个字母贡献整个词典块；
 - 当前前缀本身贡献了一个额外的较早单词。 

这重现：

 -$P(\text{aaaaaacdee})=10$-$P(\text{euler})=115246685191495243$确切地。 

---

 ##`unrank(rank)`贪婪地遍历词典块，直到所需的排名落入其中。 

这计算$W(p)$。 

---

 # 4.最终验证

 计算出的中间值是$$P(\text{legionary}) +P(\text{calorimeters}) -P(\text{annihilate}) +P(\text{orchestrated}) -P(\text{fluttering}) = 451023621685297214.$$应用逆映射给出：$$W(451023621685297214)=\text{turnthestarson}.$$这是一个可以从原始多重集构造的有效单词，并且具有长度$15$，满足所有约束条件。
