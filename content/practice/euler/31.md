[欧拉项目问题 31](https://projecteuler.net/problem=31)

 ## 解决方案

 **答案：**`73682`为了解决这个问题，我们必须计算总和为 200 便士的英国硬币的不同无序组合的数量。 

可用的硬币面额有：$$1,2,5,10,20,50,100,200$$我们希望非负整数解的数量为$$1a+2b+5c+10d+20e+50f+100g+200h=200$$其中每个变量代表该硬币的使用量。 

---

 # 数学分析

 这是一个经典的**整数分区/硬币找零**问题。 

关键的见解是：

 - 顺序**不**重要。 
- 我们计算的是组合，而不是排列。 

例如：

-$1p + 2p + 2p$-$2p + 1p + 2p$是相同的组合。 

强力排列搜索会严重超出计数。 

---

 ## 动态规划方法

 定义：$$dp[n]$$意思是：

 > 形成方式的数量$n$使用迄今为止处理过的硬币获得便士。 

最初：$$dp[0]=1$$因为只有一种方法可以赚 0p：不使用硬币。 

所有其他值都从 0 开始。 

---

 ## 转换规则

 假设我们一次处理一枚硬币。 

对于一个硬币的价值$c$, 每个金额$n \ge c$可以由下式组成：

 - 拿一枚硬币$c$,
 - 加上任何有效的形成方式$n-c$。 

所以：$$dp[n] \leftarrow dp[n] + dp[n-c]$$按递增顺序处理硬币可确保组合只计算一次。 

---

 ## 为什么这样可以避免过度计数

 考虑组成 7p。 

如果我们处理：

 1. 1便士硬币，
 2.然后2p硬币，
 3.然后5便士硬币，

 然后每个组合都按规范顺序生成。 

例如：$$5+2$$处理5便士硬币时计算。 

但：$$2+5$$稍后不会单独生成，因为该算法此后不会重新访问较小的硬币类型。 

因此，每个无序组合只出现一次。 

---

 # Python 实现```python
# Coin denominations in pence
coins = [1, 2, 5, 10, 20, 50, 100, 200]

# Target amount (£2 = 200p)
target = 200

# dp[n] = number of ways to make n pence
dp = [0] * (target + 1)

# Base case:
# There is exactly one way to make 0p
dp[0] = 1

# Process each coin
for coin in coins:
    # Update all reachable amounts
    for amount in range(coin, target + 1):
        dp[amount] += dp[amount - coin]

# Final answer
print(dp[target])
```---
