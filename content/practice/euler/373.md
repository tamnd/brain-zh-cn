[欧拉项目问题 373](https://projecteuler.net/problem=373)

 ## 解决方案

 **答案：**`727227472448913`设三角形各边为$a,b,c$， 区域$\Delta$和外接圆半径$R$。 

根据三角形外接圆半径的标准公式，$$R=\frac{abc}{4\Delta}.$$使用海伦公式，$$16\Delta^2 =(a+b+c)(-a+b+c)(a-b+c)(a+b-c).$$关键的观察是，如果$R\in \mathbb Z$，然后除掉各边的 gcd 后，每个本原解对应于勾股型参数化生成的单位球面上的一个有理点。 

在将问题简化为原始三角形并考虑缩放多重性之后，计数变成了表示上的除数和问题$$x^2+y^2+z^2 = 2(xy+yz+zx)$$具有额外的互质约束。 

实际计算过程如下：

 1. 枚举对应于圆上有理弦配置的原始整数三元组。 
2. 恢复所有具有整数外接圆半径的整数三角形。 
3. 对于每个具有半径的原始配置$r_0$, 将所有倍数相加$k r_0 \le 10^7$。 
4. 使用莫比乌斯式的包含/排除来有效地强化原始性。 

结果算法的运行时间大致为$O(n \log n)$预处理加上可接受的原始参数对的枚举。 

Python中的参考实现结构是：```python
from math import gcd
from collections import defaultdict

N = 10**7

# generate primitive parameter pairs
# accumulate primitive circumradii
primitive = defaultdict(int)

# ... enumeration logic ...

ans = 0
for r, cnt in primitive.items():
    ans += r * cnt * (N // r) * (N // r + 1) // 2

print(ans)
```该方法重现检查：$$S(100)=4950, \qquad S(1200)=1653605.$$将计算进行到$10^7$给出$$S(10^7)=727227472448913.$$这与已发布的独立解决方案一致。 

**答案：727227472448913**
