[欧拉项目问题 225](https://projecteuler.net/problem=225)

 ## 解决方案

 **答案：**`2009`让$$T_1=T_2=T_3=1,\qquad  T_n=T_{n-1}+T_{n-2}+T_{n-3}.$$这是 Tribonacci 序列：$$1,1,1,3,5,9,17,31,57,105,\dots$$我们寻求$124^\text{th}$奇数$m$这样序列的**没有项**可以被整除$m$。 

---

 # 1.数学分析

 我们只关心序列模$m$。 

定义状态向量$$S_n=(T_n,T_{n+1},T_{n+2}) \pmod m.$$因为$$T_{n+3}=T_{n+2}+T_{n+1}+T_n,$$下一个状态完全由当前状态决定：$$(a,b,c)\mapsto (b,c,a+b+c \bmod m).$$因此序列模$m$是一个确定性的有限状态过程。 

由于只有$m^3$可能的模三元组$m$，该序列最终必须重复。 事实上，因为变换是模可逆的$m$，序列是纯周期性的。 

因此：

 - 要么某个术语变成$0 \pmod m$,
 - 或者序列永远循环而不会命中$0$。 

因此要测试候选奇整数$m$，我们简单地生成 Tribonacci 值模$m$直到状态重复。 

如果我们在重复之前遇到零项，那么$m$除一些 Tribonacci 数。 

如果循环结束时没有看到零，那么$m$是所需的数字之一。 

问题陈述告诉我们：$$27$$是具有此属性的第一个奇数。 

我们继续这个过程，直到找到$124^\text{th}$这么奇数。

 # 2.Python实现```python
def tribonacci_has_zero_mod(m):
    """
    Return True if some Tribonacci number is divisible by m.
    Return False otherwise.
    """

    # Initial Tribonacci values modulo m
    a = b = c = 1 % m

    seen = set()

    while (a, b, c) not in seen:

        # If any current term is 0 mod m,
        # then m divides a Tribonacci number
        if a == 0 or b == 0 or c == 0:
            return True

        seen.add((a, b, c))

        # Advance recurrence:
        # T_{n+3} = T_n + T_{n+1} + T_{n+2}
        a, b, c = b, c, (a + b + c) % m

    # Cycle closed without seeing 0
    return False

target = 124
count = 0
n = 1

while True:

    if n % 2 == 1:  # odd numbers only

        if not tribonacci_has_zero_mod(n):
            count += 1

            if count == target:
                print(n)
                break

    n += 2
```---

 # 4. 小验证

 测试小奇数值：

 -$1$: 一切都分开了。 
-$3$: 划分$T_4=3$。 
-$5$: 划分$T_5=5$。 
-$27$：永远不会分割任何 Tribonacci 项。 

计算重现了这样的陈述：$27$是第一个有效的奇数。 

继续搜索结果：$$27,81,91,103,\dots$$和$124^\text{th}$值为：$$2009.$$这很奇怪，但与所需的顺序一致。
