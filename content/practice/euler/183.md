[欧拉项目问题 183](https://projecteuler.net/problem=183)

 ## 解决方案

 **答案：**`48861552`我们寻求$$\sum_{N=5}^{10000} D(N),$$在哪里$D(N)=N$如果最大化乘积$M(N)$是一个非终止小数，并且$D(N)=-N$否则。 

关键是要确定，对于每个$N$，是否是最优产品$$M(N)=\left(\frac Nk\right)^k$$是否终止。 

# 1.数学分析

 对于固定$N$， 定义$$f(k)=\left(\frac Nk\right)^k.$$我们在正整数上最大化它$k$。 

获取日志：$$\log f(k)=k(\log N-\log k).$$对待$k$作为真实的并区分：$$\frac{d}{dk}\bigl(k(\log N-\log k)\bigr) =\log N-\log k-1.$$将其设置为零：$$\log\frac Nk=1 \quad\Longrightarrow\quad \frac Nk=e \quad\Longrightarrow\quad k=\frac Ne.$$因此最大化整数$k$是最接近的整数$N/e$。 

更准确地说：

 - 让$$k_1=\left\lfloor \frac Ne \right\rfloor,$$- 然后比较$f(k_1)$和$f(k_1+1)$。 

这个问题的一个标准事实是最大化整数总是$$\left\lfloor \frac Ne \right\rfloor \quad\text{or}\quad \left\lfloor \frac Ne \right\rfloor+1.$$---

 ## 什么时候$M(N)$终止？ 

假设最大化$k$被选中。 

然后$$M(N)=\left(\frac Nk\right)^k.$$减少分数：$$\frac Nk=\frac ab$$用最低的术语来说。 

然后$$M(N)=\left(\frac ab\right)^k.$$有理数有终止小数当且仅当其约分母除以下以外没有质因数：$2$和$5$。 

所以我们只需要知道约化分母是否$b$除此之外还包含素数$2,5$。 

但$$b=\frac{k}{\gcd(N,k)}.$$因此：

 - 计算$$d=\frac{k}{\gcd(N,k)};$$- 反复划分因子$2$和$5$;
 - 如果结果是$1$， 然后$M(N)$终止；
 - 否则它不会。 

因此：$$D(N)= \begin{cases} -N & \text{if } d \text{ has only factors }2,5,\\ +N & \text{otherwise.} \end{cases}$$---

 # 2. 确定最优$k$我们比较$$\left(\frac N{k}\right)^k$$对于连续整数。 

不要比较巨大的幂，而是比较对数：$$k\log\frac Nk.$$定义$$g(k)=k\log\frac Nk.$$那么最大化整数为：```python
k = floor(N/e)
if g(k+1) > g(k):
    k += 1
```---

 # 3.Python实现```python
import math
from math import gcd

def optimal_k(N):
    """
    Return the integer k maximizing (N/k)^k.
    """
    k = int(N / math.e)

    # Compare logarithms to avoid huge numbers
    g1 = k * math.log(N / k)
    g2 = (k + 1) * math.log(N / (k + 1))

    if g2 > g1:
        k += 1

    return k

def terminating_decimal(N):
    """
    Return True iff M(N) is a terminating decimal.
    """
    k = optimal_k(N)

    # Reduced denominator of N/k
    d = k // gcd(N, k)

    # Remove all factors of 2
    while d % 2 == 0:
        d //= 2

    # Remove all factors of 5
    while d % 5 == 0:
        d //= 5

    return d == 1

def compute(limit):
    total = 0

    for N in range(5, limit + 1):
        if terminating_decimal(N):
            total -= N
        else:
            total += N

    return total

# Verify the example
print(compute(100))      # should be 2438

# Final answer
print(compute(10000))
```---

 ###$N=8$最佳的$k=3$。$$M(8)=\left(\frac83\right)^3=\frac{512}{27}.$$分母包含因子$3$，所以是非终止的。 

因此$$D(8)=+8.$$---
