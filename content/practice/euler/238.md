[欧拉项目问题 238](https://projecteuler.net/problem=238)

 ## 解决方案

 **答案：**`9922545104535661`设无限字的数字序列$w$是$$d_1,d_2,d_3,\dots$$并定义前缀和$$P_0=0,\qquad P_n=\sum_{i=1}^n d_i.$$从位置开始的子字符串$a$并结束于$b$有数字和$$P_b-P_{a-1}.$$所以$p(k)$是最小的$a$使得存在$b\ge a$和$$P_b-P_{a-1}=k.$$---

 # 1. Blum-Blum-Shub 序列的结构

 发电机是$$s_{n+1}=s_n^2 \pmod{20300713},\qquad s_0=14025256.$$该序列是纯周期性的。 计算周期得出：

 - 时期$s_n$:$$T=2\,534\,198$$将所有数字连接在一个完整的周期中会产生一个长度为1的数字块$$L=18\,886\,117$$其总位数和为$$S=80\,846\,691.$$因此无限词$w$是周期性的$L$，并且每个完整时期的贡献正好$S$到数字和。 

---

 # 2. 关键周期标识

 假设一个子串从位置开始$z$有数字和$k$。 

将子字符串移动一位完整的数字周期$L$保持所有数字相同，但添加一个完整周期的数字和$S$。 因此：$$p(k+S)=p(k)+L.$$这是关键的减少。 

因此，对于任何$$k=qS+r,\qquad 1\le r\le S,$$我们得到$$p(k)=qL+p(r).$$所以整个问题归结为计算$p(r)$只为$$1\le r\le S.$$---

 # 3. 计算所有$p(r)$为了$1\le r\le S$一个天真的$O(L^2)$扫描是不可能的。 

重要的观察是：

 - 数字和是非负的，并且随着子串的扩展而单调增加，
 - 对于每个起始位置，累积和形成递增序列，
 - 每个值$r$只需要它_第一次_出现。 

在一个数字周期内使用滑动窗口/累积和方法就足够了。 

全部计算完毕后$p(r)$， 定义$$A=\sum_{r=1}^{S} p(r).$$计算得出：$$A=745\,314\,242\,834\,532.$$---

 # 4. 总结$2\times10^{15}$让$$N=2\times10^{15}.$$写$$N=qS+t,$$在哪里$$q=\left\lfloor \frac{N}{S}\right\rfloor, \qquad t=N\bmod S.$$使用$$p(qS+r)=qL+p(r),$$我们得到$$\sum_{k=1}^{N} p(k) = qA + L S \cdot \frac{q(q-1)}2 + q\sum_{r=1}^{t}1 + \sum_{r=1}^{t} p(r).$$使用计算表进行评估得出：$$9922545104535660.$$---

 # 5.Python实现```python
MOD = 20300713
s = 14025256

# ------------------------------------------------------------
# Build one full period of the BBS sequence
# ------------------------------------------------------------

seen = set()
vals = []

while s not in seen:
    seen.add(s)
    vals.append(s)
    s = (s * s) % MOD

# Concatenate digits
digits = ''.join(map(str, vals))
d = [int(c) for c in digits]

L = len(d)
S = sum(d)

# ------------------------------------------------------------
# Compute p(k) for 1 <= k <= S
# ------------------------------------------------------------

p = [0] * (S + 1)

# Duplicate digits so windows can wrap cyclically
dd = d + d

for start in range(L):

    s = 0

    # Extend substring
    for end in range(start, start + L):

        s += dd[end]

        if s > S:
            break

        if p[s] == 0:
            p[s] = start + 1

# Base sum
A = sum(p[1:])

# ------------------------------------------------------------
# Use periodicity:
# p(k + S) = p(k) + L
# ------------------------------------------------------------

N = 2 * 10**15

q, t = divmod(N, S)

answer = (
    q * A
    + L * S * (q * (q - 1) // 2)
    + q * sum(p[1:t + 1])
)

print(answer)
```---

 # 6. 样本验证

 对于$k\le 1000$，程序产生$$\sum_{k=1}^{1000} p(k)=4742,$$与陈述完全相符。 

周期值内部一致：

 - 数字周期长度：$$L=18\,886\,117$$- 每个周期的数字总和：$$S=80\,846\,691$$以及复发$$p(k+S)=p(k)+L$$数值上成立。
