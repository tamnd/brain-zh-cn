[项目欧拉问题 800](https://projecteuler.net/problem=800)

 ## 解决方案

 **答案：**`1412403576`让$$H(p,q)=p^q q^p$$具有不同的素数$p\neq q$。 我们必须计算无序素数对的数量$(p,q)$这样$$p^q q^p \le 800800^{800800}.$$定义$$L = \log\left(800800^{800800}\right)=800800\log(800800).$$取对数将不等式转化为$$q\log p + p\log q \le L.$$那么问题就变成了：

 > 计算素数对$p<q$满意的
 >
 >
 >
 >
 >$$q\log p + p\log q \le L.$$---

 # 1.数学分析

 ## Step 1 — Rewrite using logarithms

 Because logarithm is strictly increasing,$$p^q q^p \le N \iff q\log p + p\log q \le \log N.$$对于目标值，$$N = 800800^{800800},$$所以$$L = 800800\log(800800).$$---

 ## 步骤 2 — 单调性

 对于固定$p$， 定义$$f_p(q)=q\log p + p\log q.$$为了$q>1$,$$f_p'(q)=\log p + \frac{p}{q}>0,$$所以$f_p(q)$严格递增于$q$。 

因此，对于每个素数$p$，存在一个最大素数$q$满足不等式。 这允许使用两指针方法。 

---

 ## 步骤 3 — 素数界

 最大可能$q$发生在$p=2$:$$q\log 2 + 2\log q \le L.$$因此大约$$q \lesssim \frac{L}{\log 2}.$$从数字上看，这大约是$1.57\times 10^7$，这对于埃拉托色尼筛是完全可行的。 

---

 ## 步骤 4 — 两指针计数

 设素数为$$p_0<p_1<\cdots<p_{m-1}.$$我们维护一个指针$j$从最大的素数索引开始。 

对于每个$i$：

- 减少$j$尽管$$p_j\log p_i + p_i\log p_j > L,$$- 然后索引之间的每个素数$i+1$和$j$作品。 

添加$$j-i$$到计数。 

因为$j$只向下移动，筛分后算法是线性的。 

---

 # 2.Python实现```python
from math import log, isqrt

def hybrid_count(base, exponent):
    # L = log(base^exponent)
    L = exponent * log(base)

    # Maximum possible q occurs roughly when p = 2
    limit = int(L / log(2)) + 10

    # Sieve of Eratosthenes
    sieve = bytearray(b'\x01') * (limit + 1)
    sieve[0:2] = b'\x00\x00'

    for p in range(2, isqrt(limit) + 1):
        if sieve[p]:
            start = p * p
            sieve[start:limit + 1:p] = (
                b'\x00' * (((limit - start) // p) + 1)
            )

    primes = [i for i, v in enumerate(sieve) if v]
    logs = [log(p) for p in primes]

    # Two-pointer counting
    total = 0
    j = len(primes) - 1

    for i, p in enumerate(primes):

        while j > i and primes[j] * logs[i] + p * logs[j] > L:
            j -= 1

        if j <= i:
            break

        total += (j - i)

    return total

# Checks from the problem statement
print(hybrid_count(800, 1))      # C(800)
print(hybrid_count(800, 800))    # C(800^800)

# Final answer
print(hybrid_count(800800, 800800))
```---

 # 3. 代码演练

 ## 计算$L$

```python
L = exponent * log(base)
```自从$$\log(base^{exponent}) = exponent \log(base),$$这完全避免了大整数。 

---

 ## 生成素数

 我们筛选所有素数直到大约$$\frac{L}{\log 2}.$$这安全地包括了所有可能的候选人$q$。 

---

 ## 两指针部分```python
while j > i and primes[j] * logs[i] + p * logs[j] > L:
    j -= 1
```这会缩小上限，直到不等式成立。 

然后索引中的所有素数$i+1$通过$j$是有效的。 

---
