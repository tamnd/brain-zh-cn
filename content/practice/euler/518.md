[欧拉计划问题 518](https://projecteuler.net/problem=518)

 ## 解决方案

 **答案：**`100315739184392`让$$x=a+1,\qquad y=b+1,\qquad z=c+1.$$条件是这样说的$x,y,z$形成几何级数：$$y^2=xz.$$自从$a,b,c$是素数，$$x,y,z>1.$$我们必须计算$$S(n)=\sum (a+b+c)$$在所有素数三元组上$(a,b,c)$满意的$$a<b<c<n,\qquad (a+1,b+1,c+1)\text{ geometric}.$$---

 # 1.数学分析

 我们从$$(b+1)^2=(a+1)(c+1).$$整数几何级数的标准参数化是通过用最低项写出比率来获得的。 

认为$$\frac{b+1}{a+1}=\frac{p}{q}$$和$\gcd(p,q)=1$,$p>q$。 

然后$$a+1=kq^2,\qquad b+1=kpq,\qquad c+1=kp^2$$对于某个整数$k\ge1$。 

的确，$$(kq^2)(kp^2)=(kpq)^2.$$因此每个有效的三元组都具有形式$$a=kq^2-1,$$

$$b=kpq-1,$$

$$c=kp^2-1,$$和$$p>q,\qquad \gcd(p,q)=1.$$相反，每个这样的构造都会自动满足几何条件。 

那么问题就变成了：

 查找所有三元组$$(kq^2-1,\;kpq-1,\;kp^2-1)$$都是素数且小于$n$。 

---

 ## 限制搜索

 自从$$c=kp^2-1<n,$$我们需要$$kp^2<n.$$因此对于每个$p$,$$1\le k<\frac{n}{p^2}.$$还$1\le q<p$。 

这大致给出了搜索复杂度$$\sum_{p\le \sqrt n}\frac{n}{p^2}\cdot p = n\sum_{p\le \sqrt n}\frac1p = O(n\log\log n),$$这很容易实现$10^8$用快速筛子。 

---

 # 2.高效的素性测试

 我们生成下面的所有素数$10^8$使用埃拉托色尼筛。 

然后素性检查就变成了$O(1)$。 

对于每个$(p,q,k)$:

 1. 计算$$A=kq^2-1,\quad B=kpq-1,\quad C=kp^2-1.$$2. 检查三个是否都是素数。 
3.添加$$A+B+C$$到运行总计。 

---

 # 3.Python实现```python
from math import gcd, isqrt

LIMIT = 10**8

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------
is_prime = bytearray(b"\x01") * LIMIT
is_prime[0] = is_prime[1] = 0

for p in range(2, isqrt(LIMIT) + 1):
    if is_prime[p]:
        start = p * p
        step = p
        is_prime[start:LIMIT:step] = b"\x00" * (
            (LIMIT - 1 - start) // step + 1
        )

# ---------------------------------------------------------
# Enumerate all geometric-progressions
# ---------------------------------------------------------
total = 0

# p corresponds to the larger coprime parameter
for p in range(2, isqrt(LIMIT) + 1):

    max_k = (LIMIT - 1) // (p * p)

    for q in range(1, p):

        # ratio must be reduced
        if gcd(p, q) != 1:
            continue

        qq = q * q
        pq = p * q
        pp = p * p

        for k in range(1, max_k + 1):

            a = k * qq - 1
            b = k * pq - 1
            c = k * pp - 1

            # ordering automatically holds:
            # q^2 < pq < p^2 because p > q

            if is_prime[a] and is_prime[b] and is_prime[c]:
                total += a + b + c

print(total)
```---

 # 4. 代码演练

 ## 筛子```python
is_prime = bytearray(b"\x01") * LIMIT
```创建布尔素数表。 

然后标准筛去除复合材料。 

预处理后：```python
is_prime[x]
```立即告诉是否$x$是素数。 

---

 ## 枚举参数三元组

 我们循环：```python
for p in range(2, sqrt(LIMIT)):
```因为$kp^2 < LIMIT$。 

然后：```python
for q in range(1, p):
```和```python
gcd(p, q) == 1
```以确保比例降低。 

对于每对$(p,q)$，我们迭代所有可接受的$k$。 

---

 ## 构造素数

 我们计算```python
a = k*q*q - 1
b = k*p*q - 1
c = k*p*p - 1
```它精确地参数化所有几何序列。 

如果都是素数，我们添加：```python
total += a + b + c
```---

 # 5. 样本验证

 对于$n=100$，程序准确地找到：$$\begin{aligned} &(2,5,11), (2,11,47), (5,11,23), (5,17,53), \\ &(7,11,17), (7,23,71), (11,23,47), \\ &(17,23,31), (17,41,97), (31,47,71), (71,83,97). \end{aligned}$$他们的总和是$$1035,$$与声明相符。

 # 6.最终验证

 该搜索涵盖了每一个独特的几何级数，因为：

 - 每个有理比都简化为互质整数$p/q$,
 - 每个几何三元组都有形式$$(kq^2,\;kpq,\;kp^2),$$- 互质可防止重复。 

所得总和为$n=10^8$是：$$100315739184392.$$这与已知的公认解决方案相匹配。 

**答案：100315739184392**
