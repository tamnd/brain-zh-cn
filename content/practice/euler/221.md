[项目欧拉问题 221](https://projecteuler.net/problem=221)

 ## 解决方案

 **答案：**`1884161251122450`让$$A=pqr$$并假设$$\frac1A=\frac1p+\frac1q+\frac1r.$$我们寻求$150000^\text{th}$正整数$A$满足这个条件。 

---

 # 步骤 1 — 代数变换

 开始于$$\frac1{pqr}=\frac1p+\frac1q+\frac1r,$$两边乘以$pqr$:$$1=qr+pr+pq.$$所以亚历山大整数对应于满足以下条件的整数三元组$$pq+pr+qr=1.$$我们现在参数化所有解决方案。 

---

 # 步骤 2 — 导出有用的参数化

 求解$r$:$$r(p+q) = 1-pq$$所以$$r=\frac{1-pq}{p+q}.$$我们想要整数解。 

遵循标准的欧拉计划方法，令$$p=a,\qquad q=-(a+d),$$在哪里$a>0$和$d>0$。 

然后$$p+q=a-(a+d)=-d,$$和$$1-pq =1-a(-(a+d)) =1+a(a+d) =a^2+ad+1.$$所以$$r=\frac{a^2+ad+1}{-d} =-\left(a+\frac{a^2+1}{d}\right).$$因此$r$恰好是一个整数，当$$d \mid (a^2+1).$$亚历山大整数变为$$A = pqr = a(a+d)\left(a+\frac{a^2+1}{d}\right).$$因此：

 > 对于每个正整数$a$和每个除数$d\mid (a^2+1)$,
 >
 >
 >
 >
 >$$A=a(a+d)\left(a+\frac{a^2+1}{d}\right)$$>
 >
 >
 >
 > 是亚历山大整数。 

这会生成所有正亚历山大整数。 

---

 # 步骤 3 — 检查示例

 采取$a=5$。 

然后$$a^2+1=26.$$选择除数$d=2$。 

然后$$p=5,\qquad q=-(5+2)=-7,$$和$$r=-\left(5+\frac{26}{2}\right)=-18.$$所以$$A=5\cdot(-7)\cdot(-18)=630,$$匹配问题陈述。 

---

 # 步骤 4 — 高效算法

 我们必须找到$150000^\text{th}$最小的独特值。 

算法：

 1.循环$a=1,2,3,\dots$2. 计算$n=a^2+1$3. 枚举所有除数$d\mid n$4. 生成$$A=a(a+d)\left(a+\frac{n}{d}\right)$$5.插入集合
 6. 对所有生成的值进行排序
 7. 采取$150000^\text{th}$一圈一圈$a=150000$就足够了。 

---

 # Python 实现```python
import math

LIMIT = 150000

# ------------------------------------------------------------
# Sieve of primes for fast factorization
# ------------------------------------------------------------
def prime_sieve(n):
    sieve = bytearray(b'\x01') * (n + 1)
    sieve[0:2] = b'\x00\x00'

    for i in range(2, int(n**0.5) + 1):
        if sieve[i]:
            sieve[i*i:n+1:i] = b'\x00' * (((n - i*i) // i) + 1)

    return [i for i, v in enumerate(sieve) if v]

primes = prime_sieve(500000)

# ------------------------------------------------------------
# Generate all divisors of n
# ------------------------------------------------------------
def divisors(n):
    factors = []
    temp = n

    for p in primes:
        if p * p > temp:
            break

        if temp % p == 0:
            e = 0
            while temp % p == 0:
                temp //= p
                e += 1
            factors.append((p, e))

    if temp > 1:
        factors.append((temp, 1))

    divs = [1]

    for p, e in factors:
        current = divs[:]
        mult = 1

        for _ in range(e):
            mult *= p
            for d in current:
                divs.append(d * mult)

    return divs

# ------------------------------------------------------------
# Generate Alexandrian integers
# ------------------------------------------------------------
alex = set()

MAX_A = 150000

for a in range(1, MAX_A + 1):
    n = a * a + 1

    for d in divisors(n):
        A = a * (a + d) * (a + n // d)
        alex.add(A)

# ------------------------------------------------------------
# Extract answer
# ------------------------------------------------------------
alex = sorted(alex)

print(alex[LIMIT - 1])
```---
