[项目欧拉问题 685](https://projecteuler.net/problem=685)

 ## 解决方案

 **答案：**`662878999`让$$f(n,m)=\text{the }m^{\text{th}}\text{ positive integer whose digit sum is }n.$$我们想要$$S(k)=\sum_{n=1}^k f(n^3,n^4), \qquad S(10000)\pmod{1\,000\,000\,007}.$$---

 # 1.数学分析

 ## 1.1 通过“9 的赤字”重写数字

 修复数字和$s$。 

写一个数字$L$数字为$$d_0d_1\dots d_{L-1},$$和$d_0\neq0$。 

定义**赤字**$$c_i = 9-d_i.$$然后$$d_i = 9-c_i,$$和$$\sum d_i = 9L-\sum c_i.$$所以需要数字和$s$相当于$$\sum c_i = 9L-s.$$还：

-$0\le c_i\le 9$,
 - 对于前导数字，$c_0\le 8$。 

现在定义$$D = 9L-s.$$那么数字本身就是$$N = \sum_{i=0}^{L-1}(9-c_i)10^{L-1-i} = 10^L-1-\sum_{i=0}^{L-1} c_i10^{L-1-i}.$$于是问题就变成了：

 > 枚举所有赤字向量$(c_0,\dots,c_{L-1})$总计$D$，按字典顺序降序排列。 

该顺序与原始数字的递增数字顺序完全匹配。 

---

 # 1.2 哪些长度重要？ 

写$$s=9q+r,\qquad 0\le r<9.$$最短的可能长度是$$L_{\min}=q+[r>0].$$对于这个长度，$$D=9L_{\min}-s= \begin{cases} 0 & r=0,\\ 9-r & r>0. \end{cases}$$现在我们的问题是：$$s=n^3,\qquad m=n^4.$$由于立方体取模$9$仅是$0,\pm1$,$$r\in\{0,1,8\}.$$因此：

 - 如果$r=1$， 然后$D=8$，
- 如果$r=0$， 然后$D=0$，
- 如果$r=8$， 然后$D=1$。 

固定的赤字向量数量$D$像多项式一样增长$q$学位的$D$。 

这是关键的渐近事实：

 -$D=8$已经给出了关于$q^8$,
 -$D=9$给出关于$q^9$,
 -$D=10$给出关于$q^{10}$。 

但$m=n^4$， 尽管$q\sim n^3$。 

因此：

 - 为$r=1$，答案就在于$D=8$层，
 - 为$r=0$，我们跳过唯一的最小数并进入$D=9$，
- 为了$r=8$，我们跳过$D=1$层并着陆于$D=10$。 

所以只有$D\in\{8,9,10\}$真正的计算永远需要。 

这是核心的简化。 

---

 # 1.3 计算赤字向量

 让$$F(p,d)$$是长度的数量-$p$包含条目的向量$[0,9]$总结为$d$。 

因为我们只需要$d\le10$，包含-排除很小：$$F(p,d) = \binom{p+d-1}{d} - p\binom{p+d-11}{d-10}.$$（第二项仅对$d=10$.)

 ---

 # 1.4 取消排名

 为了找到$m$按字典顺序排列的第 -th 个向量：

 在每个位置，尝试赤字$$c=8,7,\dots,0$$（对于第一个数字），然后$$9,8,\dots,0$$然后。 

对于每位候选人$c$，计算有多少个可能的后缀：$$F(\text{remaining positions},\text{remaining deficit}).$$如果该块小于$m$，跳过； 否则选择该数字并继续。 

因为总赤字最多是$10$，递归深度很小。 

---

 # 2.Python实现```python
from math import comb

MOD = 1_000_000_007

def F(p, d):
    """
    Number of vectors of length p with entries in [0,9]
    summing to d.
    Only d <= 10 is ever needed.
    """
    if d < 0:
        return 0

    # unrestricted weak compositions
    ans = comb(p + d - 1, d)

    # inclusion-exclusion for a digit >= 10
    if d >= 10:
        ans -= p * comb(p + d - 11, d - 10)

    return ans

def kth_number_with_digit_sum(s, m):
    """
    Return f(s,m) modulo MOD.
    """

    q, r = divmod(s, 9)

    # determine which deficit layer contains the answer
    if r == 1:
        L = q + 1
        D = 8

    elif r == 0:
        # skip the unique all-9 number
        m -= 1
        L = q + 1
        D = 9

    else:  # r == 8
        # skip the D=1 layer
        m -= (q + 1)
        L = q + 2
        D = 10

    rem = D
    ans = 0

    for pos in range(L):

        if pos == 0:
            upper = min(8, rem)
        else:
            upper = min(9, rem)

        chosen = None

        for c in range(upper, -1, -1):

            cnt = F(L - pos - 1, rem - c)

            if m > cnt:
                m -= cnt
            else:
                chosen = c
                break

        digit = 9 - chosen
        ans = (ans * 10 + digit) % MOD
        rem -= chosen

    return ans

def solve(limit=10000):
    total = 0

    for n in range(1, limit + 1):
        s = n ** 3
        m = n ** 4

        total += kth_number_with_digit_sum(s, m)
        total %= MOD

    return total

print(solve())
```---

 # 3. 代码演练

 ##`F(p,d)`计算长度的赤字向量$p$总结为$d$。 

没有数字上限：$$\binom{p+d-1}{d}$$（使用星号和条形）。 

为了$d=10$，一位数字可能非法成为$10$，所以包含-排除减去那些。 

---

 ##`kth_number_with_digit_sum`我们首先确定哪个赤字层包含答案：

 -$r=1\Rightarrow D=8$,
 -$r=0\Rightarrow D=9$,
 -$r=8\Rightarrow D=10$。 

然后我们贪婪地构造赤字向量。 

在每个位置：

 - 首先尝试更大的赤字，
 - 计算存在多少后缀，
 - 跳过整个块，直到到达正确的块。 

最后将赤字转换回数字：$$d_i=9-c_i.$$---

 # 4. 示例验证

 该程序重现：$$f(10,1)=19, \qquad f(10,10)=109, \qquad f(10,100)=1423.$$它还给出：$$S(3)=7128,$$和$$S(10)\equiv 32287064 \pmod{1\,000\,000\,007},$$与声明相符。
