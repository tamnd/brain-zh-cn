[欧拉项目问题 19](https://projecteuler.net/problem=19)

 ## 解决方案

 **答案：**`171`我们需要计算二十世纪期间，从 **1901 年 1 月 1 日到 2000 年 12 月 31 日**，**一个月的第一天**有多少次是**周日**。 

### 数学方法

 我们得到：

 - **1900 年 1 月 1 日是星期一**
 - 闰年规则：

 - 能被4整除 → 闰年
 - 世纪年**不是**闰年，除非能被 400 整除

 一个简单的方法是：

 1. 使用日偏移量跟踪每个日期的工作日。 
2. 从**1900年1月1日=星期一**开始。 
3. 逐月移动。 
4. 每当出现以下情况时进行计数：

 - 年份在 **1901 至 2000 年之间**，并且
 - **该月的第一天**是**周日**。 

表示工作日模 7，例如

 - 0 = 星期一
 - …
 - 6 = 星期日

 对于每个月，提前该月的天数。 

### 干净的 Python 代码```python
def is_leap(year):
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

month_days = [31, 28, 31, 30, 31, 30,
              31, 31, 30, 31, 30, 31]

day_of_week = 0  # 0 = Monday on 1 Jan 1900
count = 0

for year in range(1900, 2001):
    for month in range(12):
        # Count Sundays on the first of the month
        if year >= 1901 and day_of_week == 6:
            count += 1

        days = month_days[month]

        # February in leap year
        if month == 1 and is_leap(year):
            days += 1

        day_of_week = (day_of_week + days) % 7

print(count)
```这计算：```python
171
```### 心理检查/正确性

 - 我们从 **1900 年 1 月 1 日 = 星期一**开始。 
- 我们逐月正确传播工作日。 
- 闰年完全按照公历规则处理（特别是**1900 年不是闰年**，**2000 年是闰年**）。 
- 我们仅计算 **1901 年至 2000 年**（含）的月份。 

**答案：171**
