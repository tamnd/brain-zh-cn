[Project Euler Problem 30](https://projecteuler.net/problem=30)

 ## 解决方案

 **答案：**`443839`我们寻找所有可以写成**其数字的五次方之和**的整数。 

### 1.数学分析

 我们首先确定一个上限。 

对于一个$n$-digit 数字，其数字的五次方的最大可能和为：$$n \cdot 9^5$$自从：$$9^5 = 59049$$检查何时$n$-digit 数字不能再等于这样的总和：

 -$6 \cdot 9^5 = 354294$- 至少 7 位数字$1{,}000{,}000$但：$$7 \cdot 9^5 = 413343 < 1{,}000{,}000$$所以没有任何7位数字可以满足这个条件。 因此我们只需要搜索：$$354294$$排除$1$，因为它不被视为总和。 

### 2. 干净的 Python 代码```python
def digit_fifth_power_sum():
    limit = 6 * (9 ** 5)  # 354294
    total = 0

    for n in range(2, limit + 1):
        if n == sum(int(d) ** 5 for d in str(n)):
            total += n

    return total

print(digit_fifth_power_sum())
```### 3. 心理追踪/正确性检查

 满足该性质的数为：

 - 4150
 - 4151
 - 54748
 - 92727
 - 93084
 - 194979

 检查一个例子：$$4150 = 4^5 + 1^5 + 5^5 + 0^5$$

$$= 1024 + 1 + 3125 + 0 = 4150$$总结它们：$$4150 + 4151 + 54748 + 92727 + 93084 + 194979 = 443839$$**答案：443839**
