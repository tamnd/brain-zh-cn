[项目欧拉问题 512](https://projecteuler.net/problem=512)

 ## 解决方案

 **答案：**`50660591862310323`让$$f(n)=\left(\sum_{i=1}^{n}\varphi(n^i)\right)\bmod(n+1)$$和$$g(n)=\sum_{i=1}^{n} f(i).$$我们需要$g(5\times 10^8)$。 

## 1.数学分析

 ### 第 1 步：简化$f(n)$回忆患者身份：$$\varphi(n^k)=n^{k-1}\varphi(n)$$对于任意整数$k\ge1$。 

因此$$\sum_{i=1}^{n}\varphi(n^i) = \varphi(n)\sum_{i=0}^{n-1} n^i.$$我们只关心模数$n+1$。 自从$$n\equiv -1 \pmod{n+1},$$我们得到$$n^i \equiv (-1)^i \pmod{n+1}.$$因此$$\sum_{i=0}^{n-1}n^i \equiv \sum_{i=0}^{n-1}(-1)^i \pmod{n+1}.$$现在区分奇偶校验：

 - 如果$n$是**偶数**，交替和有同样多个$+1$和$-1$， 所以：$$\sum_{i=0}^{n-1}(-1)^i=0.$$因此$$f(n)=0.$$- 如果$n$是 **奇数**，交替和等于$1$， 所以：$$f(n)\equiv \varphi(n)\pmod{n+1}.$$因为对于$n>1$,$$0<\varphi(n)<n+1,$$残差很简单$$f(n)=\varphi(n).$$还$f(1)=1=\varphi(1)$。 

所以：$$f(n)= \begin{cases} \varphi(n), & n\text{ odd},\\[4pt] 0, & n\text{ even}. \end{cases}$$所以$$g(N)=\sum_{\substack{n\le N\\ n\text{ odd}}}\varphi(n).$$---

 ### 步骤2：转换为求和公式

 使用莫比乌斯反演公式：$$\varphi(n) = n\sum_{d\mid n}\frac{\mu(d)}{d}.$$自从$n$是奇数，所有除数都是奇数：$$g(N) = \sum_{\substack{n\le N\\ n\text{ odd}}} n \sum_{d\mid n}\frac{\mu(d)}{d}.$$写$n=dm$:$$g(N) = \sum_{\substack{d\le N\\ d\text{ odd}}} \mu(d) \sum_{\substack{m\le N/d\\ m\text{ odd}}} m.$$奇数整数之和可达$M$:$$1+3+\cdots+(2k-1)=k^2,$$在哪里$$k=\left\lfloor \frac{M+1}{2}\right\rfloor.$$因此$$g(N) = \sum_{\substack{d\le N\\ d\text{ odd}}} \mu(d) \left( \left\lfloor \frac{\lfloor N/d\rfloor+1}{2} \right\rfloor \right)^2.$$这可以计算为$O(\sqrt N)$使用除数分组和记忆求和莫比乌斯函数。

 ## 2.Python实现```python
from functools import lru_cache

def compute_g(N):
    # Sieve limit for fast Möbius prefix values
    LIMIT = int(N ** (2 / 3)) + 10

    # Linear sieve for Möbius function
    mu = [0] * (LIMIT + 1)
    mu[1] = 1
    primes = []
    is_composite = [False] * (LIMIT + 1)

    for i in range(2, LIMIT + 1):
        if not is_composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > LIMIT:
                break

            is_composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break
            else:
                mu[v] = -mu[i]

    # Prefix sum of Möbius
    mobius_prefix = [0] * (LIMIT + 1)
    for i in range(1, LIMIT + 1):
        mobius_prefix[i] = mobius_prefix[i - 1] + mu[i]

    @lru_cache(None)
    def mertens(n):
        """M(n) = sum_{k<=n} mu(k)"""
        if n <= LIMIT:
            return mobius_prefix[n]

        result = 1
        left = 2

        while left <= n:
            q = n // left
            right = n // q

            result -= (right - left + 1) * mertens(q)
            left = right + 1

        return result

    @lru_cache(None)
    def odd_mertens(n):
        """Sum of mu(k) over odd k <= n"""
        total = 0

        while n > 0:
            total += mertens(n)
            n //= 2

        return total

    answer = 0
    left = 1

    while left <= N:
        q = N // left
        right = N // q

        # Number of odd integers <= q
        k = (q + 1) // 2

        mobius_sum = odd_mertens(right) - odd_mertens(left - 1)
        answer += k * k * mobius_sum

        left = right + 1

    return answer

# Verification
print(compute_g(100))  # 2007

# Final result
print(compute_g(5 * 10**8))

 ## 3. 代码演练

 ### 莫比乌斯筛

 我们计算$\mu(n)$最多约$N^{2/3}$使用线性筛。 

这可以快速访问：$$M(n)=\sum_{k\le n}\mu(k)$$对于较小的$n$。 

###`mertens(n)`使用经典的分治递归：$$M(n) = 1 - \sum_{l=2}^{n} (r-l+1)M\!\left(\left\lfloor \frac{n}{l}\right\rfloor\right)$$对等商范围进行分组。 

###`odd_mertens(n)`我们只需要奇数$d$。 观察：$$M(n)=O(n)-O(n/2),$$在哪里$O(n)$是奇数莫比乌斯和。 

所以：$$O(n)=M(n)+O(n/2).$$这变成：$$O(n)=M(n)+M(n/2)+M(n/4)+\cdots.$$### 最终总结

 我们对间隔进行分组，其中$$\left\lfloor \frac{N}{d}\right\rfloor$$是常数，将复杂度降低到大约$O(\sqrt N)$。
