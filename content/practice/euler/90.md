[项目欧拉问题 90](https://projecteuler.net/problem=90)

 ## 解决方案

 **答案：**`1217`我们必须计算能够显示下面所有两位数平方数的无序的 6 位数立方体对$100$:$$01,\ 04,\ 09,\ 16,\ 25,\ 36,\ 49,\ 64,\ 81$$附加规则是$6$和$9$可以通过旋转互换。 

---

 # 数学分析

 立方体仅由其表面上写的一组数字决定。 

每个立方体恰好包含 6 个不同的数字，选自$\{0,1,\dots,9\}$。 

中心观察是：

 - 显示两位数$ab$，一个立方体必须包含$a$另一个必须包含$b$。 
- 由于立方体可以左/右交换，因此：$$a \in A,\ b \in B$$或者$$a \in B,\ b \in A$$---

 ## 第 1 步：处理$6/9$对称性

 因为一个$6$可以充当$9$反之亦然，我们将它们视为可互换的。 

因此：

 - 如果一个立方体包含$6$，它实际上还包含$9$,
 - 如果它包含$9$，它实际上还包含$6$。 

因此，出于测试目的，我们可以扩大包含以下之一的任何集合$\{6,9\}$包含两者。 

---

 ## 步骤 2：所需的方块对

 平方数施加以下数字对约束：

 | 广场| 所需配对 |
 | ---| ---|
 |$01$|$(0,1)$|
 |$04$|$(0,4)$|
 |$09$|$(0,6)$因为$9 \leftrightarrow 6$|
 |$16$|$(1,6)$|
 |$25$|$(2,5)$|
 |$36$|$(3,6)$|
 |$49$|$(4,6)$|
 |$64$|$(6,4)$|
 |$81$|$(8,1)$|

 注意$49$和$64$两者都减少到要求$4$和$6$在相对的立方体上。 

---

 ## 步骤 3：枚举所有立方体

 立方体是 10 个数字的任意 6 元素子集：$$\binom{10}{6} = 210$$所以只有$210$可能的立方体。 

我们可以暴力破解所有无序对：$$\binom{210+1}{2} = 22155$$这是很小的。 

---

 ## 步骤4：有效性测试

 对于每对立方体$(A,B)$:

 1. 扩展每个立方体：

 - 如果$6\in A$或者$9\in A$，将两者相加$6,9$,
 - 同样对于$B$。 
2. 对于每个所需的对$(x,y)$， 核实：$$(x\in A \land y\in B)\quad \text{or}\quad (x\in B \land y\in A)$$3. 计算满足每个平方约束的所有无序对。

 # Python 实现```python
from itertools import combinations

# All required square digit pairs
# 9 is replaced by 6 because 6/9 are interchangeable
required = [
    (0, 1),
    (0, 4),
    (0, 6),  # represents 09
    (1, 6),  # represents 16
    (2, 5),
    (3, 6),  # represents 36
    (4, 6),  # represents 49
    (6, 4),  # represents 64
    (8, 1),
]

digits = range(10)

# Generate all possible cubes (6 distinct digits)
cubes = list(combinations(digits, 6))

def extend(cube):
    """
    If a cube contains 6 or 9, add both,
    because they are interchangeable.
    """
    s = set(cube)

    if 6 in s or 9 in s:
        s.add(6)
        s.add(9)

    return s

def valid(c1, c2):
    """
    Check whether cubes c1 and c2
    can display all required square numbers.
    """
    a = extend(c1)
    b = extend(c2)

    for x, y in required:
        ok = ((x in a and y in b) or
              (x in b and y in a))

        if not ok:
            return False

    return True

count = 0

# Only unordered pairs
for i in range(len(cubes)):
    for j in range(i, len(cubes)):
        if valid(cubes[i], cubes[j]):
            count += 1

print(count)
```---

 # 代码演练

 ## 生成立方体配置```python
cubes = list(combinations(digits, 6))
```这会产生所有可能的 6 位数立方体。 

例子：```python
(0,1,2,3,4,5)
```代表一个立方体排列。 

确切地说有：$$\binom{10}{6} = 210$$这样的立方体。 

---

 ## 扩展为$6/9$

```python
if 6 in s or 9 in s:
    s.add(6)
    s.add(9)
```这实现了颠倒规则。 

所以：```python
{0,5,6,7,8,9}
```和```python
{0,5,6,7,8}
```对于形成数字来说，其行为是等效的。 

---

 ## 验证平方数

 对于每个所需的对：```python
(x in a and y in b) or (x in b and y in a)
```检查这两个数字是否可以放在相反的立方体上。 

示例：对于$25$,

 - 一个立方体必须包含$2$,
 - 另一个必须包含$5$。 

任一方向都是可以接受的。 

---

 ## 避免重复计算```python
for j in range(i, len(cubes)):
```确保：

 -$(A,B)$被计算一次，
 - 不再是$(B,A)$。 

这与立方体顺序无关紧要的说法相符。
