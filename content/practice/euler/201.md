[项目欧拉问题 201](https://projecteuler.net/problem=201)

 ## 解决方案

 **答案：**`115039000`让$$S=\{1^2,2^2,\dots,100^2\}.$$我们必须找到所有出现的整数之和**恰好是一个**$50$-元素子集$S$。 

---

 # 数学分析

 我们正在处理唯一性条件下的子集和。 

对于一套$A$， 定义$$U(A,k)=\left\{x : x \text{ is the sum of exactly one } k\text{-element subset of }A\right\}.$$我们需要$$\sum U(S,50).$$---

 ## 1.动态规划观点

 的每个元素$S$可以：

 - 被排除在子集之外，或者
 - 被包括在内。 

我们想要计算每一种可能的情况：

 - 子集大小$j$,
 - 子集和$t$,

 有多少子集实现该对$(j,t)$。 

---

 ## 2. 关键的观察

 一旦超过，我们**不需要**需要子集的确切数量$1$。 

为什么？ 

因为这个问题只问一个和是否是：

 - 实现$0$次，
 - 准确地实现了$1$时间，
 - 或多次实现。 

所以我们可以将所有计数限制为$2$。 

这大大降低了复杂性。 

---

 ## 3.DP定义

 定义：$$dp[j][t]$$意思是：

 -$0$： 不可能的，
-$1$: 正是一种方式，
 -$2$: 至少有两种方式。 

最初：$$dp[0][0]=1$$因为空子集有大小$0$和总和$0$。 

对于每个正方形$a=i^2$，向后更新：$$dp[j+1][t+a] = \min\left(2,\; dp[j+1][t+a]+dp[j][t]\right).$$向后迭代可以防止多次重复使用同一个方块。 

---

 ## 4. 最大可能总和

 最大的$50$-子集和是$$51^2+52^2+\cdots+100^2.$$使用$$\sum_{i=1}^{100} i^2 = \frac{100\cdot101\cdot201}{6}=338350,$$和$$\sum_{i=1}^{50} i^2 = 42925,$$我们得到$$338350-42925=295425.$$所以DP表只需要求和$295425$。 

---

 # Python 实现```python
import numpy as np

# We need 50-element subset sums of squares 1^2 ... 100^2
N = 100
K = 50

squares = [i * i for i in range(1, N + 1)]

# Maximum possible 50-element sum
MAX_SUM = sum(i * i for i in range(51, 101))

# dp[j][s]:
#   0 = impossible
#   1 = exactly one way
#   2 = two or more ways
dp = np.zeros((K + 1, MAX_SUM + 1), dtype=np.uint8)

# Empty subset
dp[0][0] = 1

# Process each square
for a in squares:

    # Go backwards so each value is used once
    for j in range(K - 1, -1, -1):

        # Existing states for size j
        src = dp[j, :MAX_SUM + 1 - a]

        # Destination states for size j+1
        dst = dp[j + 1, a:]

        # Add counts, capped at 2
        total = dst.astype(np.uint16) + src.astype(np.uint16)
        total[total > 2] = 2

        dp[j + 1, a:] = total.astype(np.uint8)

# Sum all uniquely representable sums
answer = np.where(dp[K] == 1)[0].sum()

print(answer)
```---

 # 最终验证

 计算值是：$$115039000.$$这是合理的，因为：

 - 子集总和大约为数十万，
 - 许多金额是重复的，
 - 只有相对稀疏的集合保持唯一。 

DP 计算证实了准确的结果。
