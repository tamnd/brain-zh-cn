[欧拉项目 609 问题](https://projecteuler.net/problem=609)

 ## 解决方案

 **答案：**`172023848`让$$\pi(n)=\#\{p\le n : p \text{ prime}\}.$$一个$\pi$-sequence是有限序列$$u=(u_0,u_1,\dots,u_m)$$和$m\ge1$,$u_{i+1}=\pi(u_i)$，且所有项均为正数。 

对于每个序列$u$， 让$c(u)$是非质数元素的数量$u$。 

我们定义：$$p(n,k)=\#\{u : u_0\le n,\ c(u)=k\},$$和$$P(n)=\prod_{k:\,p(n,k)>0} p(n,k).$$我们被要求：$$P(10^8)\pmod{1\,000\,000\,007}.$$---

 # 1.数学分析

 ## 1.1 的结构$\pi$-序列

 开始于$x=u_0$，序列是强制的：$$x,\ \pi(x),\ \pi(\pi(x)),\ \dots$$直到达到$1$， 因为$\pi(1)=0$并且序列必须保持正向。 

因此每个起始值$x\ge2$恰好生成一个最大链。 

例子：$$10\to4\to2\to1.$$有效的$\pi$-序列至少是长度的所有前缀$2$:$$(10,4),\quad (10,4,2),\quad (10,4,2,1).$$---

 ## 1.2 递归描述

 定义$V(x)$是所有值的多重集$c(u)$对于开始于$x$。 

如果$x>1$， 让$$y=\pi(x).$$让$$b(x)= \begin{cases} 0,&x\text{ prime}\\ 1,&x\text{ non-prime} \end{cases}$$然后：

 - 最短序列$(x,y)$贡献$$b(x)+b(y),$$- 每个较长的序列都是通过前置获得的$x$到一个序列$y$，添加$b(x)$到非素数计数。 

所以：$$V(x)=\{b(x)+b(y)\}\cup\{b(x)+t:t\in V(y)\}.$$这给出了非常小的递归深度，因为重复应用$\pi$数量急剧减少。 

为了$10^8$:$$10^8\to5761455\to412849\to\cdots\to1$$所以最大深度很小（远低于 16）。 

---

 ## 1.3 按相等分组$\pi(x)$一个关键的观察：$$\pi(x)=y$$适合所有人$$x\in[p_y,\ p_{y+1}-1],$$在哪里$p_y$是$y$-th素数。 

在这个区间内：

 - 恰好有一个数字是素数（$p_y$),
 - 其余的都是复合的。 

因此所有具有相同的数字$\pi(x)$仅分为两种：

 1. 素数$p_y$,
 2. 之间的复合$p_y$和$p_{y+1}$。 

所以我们只需要计算$V(y)$每人一次$y\le \pi(10^8)$。 

自从$$\pi(10^8)=5\,761\,455,$$这是完全可行的。 

---

 # 2.高效算法

 我们筛选所有素数直到$10^8$。 

那么对于每一个$y\le\pi(10^8)$:

 1. 计算$V(y)$由递归可知，
 2. 添加来自以下方面的贡献：

 - 总理$p_y$,
 - 合数$\pi(x)=y$。 

因为递归深度很小，所以我们只存储一个短的计数向量。 

复杂性：

 - 筛子：$O(n\log\log n)$,
 - DP：基本呈线性$\pi(n)$。 

---

 # 3.Python实现```python
MOD = 1_000_000_007
N = 10**8
K = 16                      # safely larger than maximum depth

# ------------------------------------------------------------
# Odd-only sieve
# ------------------------------------------------------------

size = N // 2
sieve = bytearray(b'\x01') * size
sieve[0] = 0

limit = int(N**0.5)

for i in range(3, limit + 1, 2):
    if sieve[i // 2]:
        start = i * i // 2
        sieve[start::i] = b'\x00' * (((size - start - 1) // i) + 1)

primes = [2] + [2 * i + 1 for i in range(1, size) if sieve[i]]

m = len(primes)             # pi(10^8)

# ------------------------------------------------------------
# primality up to m
# ------------------------------------------------------------

is_prime_small = bytearray(m + 1)

for p in primes:
    if p <= m:
        is_prime_small[p] = 1

# ------------------------------------------------------------
# pi(x) for x <= m
# ------------------------------------------------------------

pi_small = [0] * (m + 1)

c = 0
for i in range(1, m + 1):
    c += is_prime_small[i]
    pi_small[i] = c

# ------------------------------------------------------------
# DP storage
#
# C[y][k] = number of sequences starting at y
#            having exactly k non-primes
# ------------------------------------------------------------

C = [[0] * K for _ in range(m + 1)]

# final p(n,k)
P = [0] * K

for y in range(1, m + 1):

    # build V(y)
    if y > 1:
        z = pi_small[y]

        by = 0 if is_prime_small[y] else 1
        bz = 0 if is_prime_small[z] else 1

        # shortest sequence (y, z)
        C[y][by + bz] += 1

        # longer sequences
        for k in range(K - by):
            C[y][by + k] += C[z][k]

    # --------------------------------------------------------
    # Contributions from x with pi(x)=y
    # --------------------------------------------------------

    bz = 0 if is_prime_small[y] else 1

    # prime x = p_y
    P[bz] += 1
    for k in range(K):
        P[k] += C[y][k]

    # composite x with pi(x)=y
    if y < m:
        gap = primes[y] - primes[y - 1] - 1
    else:
        gap = N - primes[-1]

    P[1 + bz] += gap

    for k in range(K - 1):
        P[k + 1] += gap * C[y][k]

# ------------------------------------------------------------
# Final product
# ------------------------------------------------------------

ans = 1

for v in P:
    if v:
        ans = (ans * (v % MOD)) % MOD

print(ans)
```---

 # 4. 代码演练

 ## 筛子

 我们使用仅奇数筛：

 - 索引$i$代表数字$2i+1$,
 - 内存即使在$10^8$。 

这会产生直到$10^8$。 

---

 ## 计算$V(y)$对于每个$y$:```python
z = pi_small[y]
```然后：```python
C[y][by + bz] += 1
```添加最短序列$(y,z)$。 

下一个：```python
C[y][by + k] += C[z][k]
```扩展每个序列$z$。 

---

 ## 分组计数

 所有数字都带有$\pi(x)=y$一起处理。 

有：

 - 一个素数$x=p_y$,
 - 连续素数之间的许多复合。 

这极大地减少了工作量。
