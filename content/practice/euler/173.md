[欧拉项目问题 173](https://projecteuler.net/problem=173)

 ## 解决方案

 **答案：**`1572729`让外面的正方形有边长$n$，内部正方形（“孔”）的边长$m$。 

因为椎板是一个对称的方形边界：

 -$n > m$-$n$和$m$必须具有相同的奇偶性（否则边界厚度不完整）
 - 使用的瓷砖数量是$$n^2 - m^2$$我们想要：$$n^2 - m^2 \le 10^6$$我们必须计算所有有效对$(n,m)$。 

---

 # 数学分析

 ## 1. 重写图块计数

 因素：$$n^2 - m^2 = (n-m)(n+m)$$自从$n,m$具有相同的奇偶性，两个因子都是偶数。 

让$$n-m = 2k$$在哪里$k \ge 1$是边界厚度。 

然后：$$m = n-2k$$代替：$$n^2 - (n-2k)^2$$扩张：$$= n^2 - (n^2 - 4kn + 4k^2)$$

$$= 4k(n-k)$$所以每个层都唯一对应于整数：

 -$k \ge 1$-$n > 2k$与瓷砖计数$$T = 4k(n-k)$$我们需要$$4k(n-k) \le 10^6$$---

 ## 2. 计算可能性

 修复边框粗细$k$。 

然后：$$n-k \le \frac{10^6}{4k}$$所以$$n \le \frac{10^6}{4k} + k$$我们还需要：$$n \ge 2k+1$$因为内孔边长为$$m=n-2k \ge 1$$因此对于每个$k$，有效的$n$值为：$$2k+1 \le n \le \left\lfloor \frac{10^6}{4k} + k \right\rfloor$$因此，固定的层板数量$k$是$$\left\lfloor \frac{10^6}{4k} + k \right\rfloor - (2k+1) + 1$$这简化为$$\left\lfloor \frac{10^6}{4k} \right\rfloor - k$$前提是这个数量是正数。 

因此总数为$$\sum_{k\ge1} \max\left(0,\left\lfloor \frac{10^6}{4k}\right\rfloor-k\right)$$---

 # Python 实现```python
LIMIT = 1_000_000

count = 0
k = 1

while True:
    # Number of valid outer sizes for this thickness
    ways = LIMIT // (4 * k) - k

    # Once non-positive, no larger k can work
    if ways <= 0:
        break

    count += ways
    k += 1

print(count)
```---

 # 代码演练```python
LIMIT = 1_000_000
```允许的最大块数。 

---```python
count = 0
k = 1
```-`count`存储层板总数。 
-`k`是边界厚度。 

---```python
ways = LIMIT // (4 * k) - k
```由推导可知：$$\text{ways} = \left\lfloor \frac{LIMIT}{4k}\right\rfloor - k$$这将计算所有有效的外部方形尺寸的厚度$k$。 

---```python
if ways <= 0:
    break
```作为$k$增加，数量单调减少。 

一旦它变成非阳性，就不可能再有更多的层板。 

---```python
count += ways
```添加所有厚度的薄片$k$。 

---```python
k += 1
```移至下一个边框厚度。 

---```python
print(count)
```输出不同方形薄片的最终数量。

 # 最终验证

 计数应该是：

 - 远大于$10^5$，因为许多细边框是可能的，
 - 但比$10^7$，因为允许的厚度仅达到大约$$k^2 < \frac{10^6}{4} \Rightarrow k < 500$$结果值在预期范围内并且与已知的欧拉计划结果相匹配。
