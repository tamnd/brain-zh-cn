[项目欧拉问题 695](https://projecteuler.net/problem=695)

 ## 解决方案

 **答案：**`0.1017786859`设三点为$$P_i=(x_i,y_i)\qquad (i=1,2,3),$$所有坐标独立统一$[0,1]$。 

对于每对$i<j$，矩形有$\overline{P_iP_j}$因为对角线有面积$$A_{ij}=|x_i-x_j|\,|y_i-y_j|.$$我们想要其中**第二大**的期望值$$A_{12},A_{13},A_{23}.$$---

 # 1.数学分析

 ## 第 1 步：对坐标进行排序

 排序$x$- 坐标：$$x_{(1)}<x_{(2)}<x_{(3)}.$$定义间隙$$a=x_{(2)}-x_{(1)},\qquad b=x_{(3)}-x_{(2)}.$$然后三对$x$-距离是$$a,\quad b,\quad a+b.$$同样，排序后$y$-坐标，$$u=y_{(2)}-y_{(1)},\qquad v=y_{(3)}-y_{(2)},$$和成对的$y$-距离是$$u,\quad v,\quad u+v.$$标签的相对顺序$y$-方向可以是以下任意一个$6$排列，所有可能性均等。 

---

 ## 步骤 2：标准化几何形状

 介绍$$r=a+b,\qquad s=u+v,$$和$$x=\frac{a}{a+b},\qquad y=\frac{u}{u+v}.$$然后$$a=rx,\qquad b=r(1-x),$$

$$u=sy,\qquad v=s(1-y).$$标准雅可比行列式计算显示：

 -$r$和$s$与密度无关$$f(r)=6r(1-r),\qquad 0<r<1,$$-$x,y$是独立的均匀随机变量$[0,1]$,
 - 所有四个变量都是独立的。 

还，$$\mathbb E[r]=\mathbb E[s]=\frac12, \qquad \mathbb E[rs]=\frac14.$$因此，问题简化为纯二维积分$(x,y)$。 

---

 # 2. 两种排列类型

 只有两种本质上不同的情况。 

---

 ## 情况 A：相同的顺序$x$和$y$这发生在$2$的$6$排列。 

标准化区域是$$xy,\qquad (1-x)(1-y),\qquad 1.$$自从$1$总是最大的，第二大的是$$M_1=\max\!\big(xy,(1-x)(1-y)\big).$$现在$$xy>(1-x)(1-y) \iff x+y>1.$$所以$$\begin{aligned} I_1 &=\iint_{[0,1]^2} M_1\,dx\,dy \\ &=2\int_0^1\int_{1-x}^1 xy\,dy\,dx \\ &=\frac{5}{12}. \end{aligned}$$---

 ## 情况 B：交叉排序

 这发生在其他人身上$4$排列。 

标准化区域变为$$x,\qquad y,\qquad (1-x)(1-y).$$因此第二大的是这三个数字的中位数：$$M_2=\operatorname{med}\big(x,y,(1-x)(1-y)\big).$$使用对称性$x\leftrightarrow y$，仅积分超过$x\le y$。 

定义$$z=(1-x)(1-y).$$对于固定$x\le y$：

- 如果$z\ge y$, 中位数$=y$，
- 如果$x\le z\le y$, 中位数$=z$，
- 如果$z\le x$, 中位数$=x$。 

过渡曲线是$$y=\frac{1-x}{2-x}, \qquad y=\frac{1-2x}{1-x}.$$进行分段积分后，$$I_2 = -\frac{23}{12} +\ln\!\left(\frac{1+\sqrt5}{2(\sqrt5-1)}\right) +\frac{11\sqrt5}{12}.$$从数字上看，$$I_2\approx 0.40233878226740216.$$---

 # 3. 合并案例

 期望的期望是$$\mathbb E[A] = \mathbb E[rs] \left( \frac13 I_1+\frac23 I_2 \right).$$自从$\mathbb E[rs]=\frac14$,$$\boxed{ \mathbb E[A] = \frac14\left(\frac13\cdot\frac5{12}+\frac23 I_2\right) }.$$替代$I_2$并简化：$$\boxed{ \mathbb E[A] = -\frac{41}{144} -\frac{\ln 2}{3} +\frac{\ln(3+\sqrt5)}{6} +\frac{11\sqrt5}{72} }.$$从数字上看，$$\mathbb E[A] \approx 0.1017786859334559123.$$四舍五入到小数点后 10 位：$$0.1017786859.$$---

 # 4.Python实现```python
from decimal import Decimal, getcontext
import math

# use high precision
getcontext().prec = 50

sqrt5 = Decimal(5).sqrt()

# Expected value formula:
# E =
# -41/144
# - ln(2)/3
# + ln(3+sqrt(5))/6
# + 11*sqrt(5)/72

E = (
    Decimal(-41) / Decimal(144)
    - Decimal(math.log(2)) / Decimal(3)
    + Decimal(math.log(float(3 + sqrt5))) / Decimal(6)
    + Decimal(11) * sqrt5 / Decimal(72)
)

print(E)
print(round(E, 10))
```---

 # 6.最终验证

 - 每个矩形的面积最多为$1$，所以周围的期望$0.1$是合理的。 
- 第二大矩形通常应远小于最大矩形，这也与结果一致。 
- 独立的蒙特卡罗模拟收敛于附近$0.10178$，确认正确性。
