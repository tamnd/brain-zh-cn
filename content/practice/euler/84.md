[欧拉项目问题 84](https://projecteuler.net/problem=84)

 ## 解决方案

 **答案：**`101524`让大富翁棋盘的方格编号$0$–$39$：

- 去$=0$- 监狱$=10$- G2J$=30$- 抄送于$2,17,33$- 聊天$7,22,36$当使用**两个 4 面骰子**时，我们必须计算马尔可夫过程的平稳分布，包括：

 1.普通运动，
 2、双打三垒打$\to$监狱,
 3. CC/CH卡效果，
 4.G2J，
 5.“返回3格”等递归效果登陆CC。 

所需的答案是三个最可能的最终方块的串联。 

---

 # 数学分析

 解决这个问题的简洁方法是将垄断建模为**马尔可夫链**。 

一个状态必须包含：

 - 当前董事会位置$p\in\{0,\dots,39\}$,
 - 连续双打的次数$d\in\{0,1,2\}$。 

因此有：$$40 \times 3 = 120$$州。 

---

 ## 1. 骰子概率

 有两个 4 面骰子，每个骰子$1,2,3,4$。 

有$16$同样可能的结果。 

总和出现的概率为：

 | 总和| 方式|
 | ---| ---|
 | 2 | 1 |
 | 3 | 2 |
 | 4 | 3 |
 | 5 | 4 |
 | 6 | 3 |
 | 7 | 2 |
 | 8 | 1 |

 双打是：$$(1,1),(2,2),(3,3),(4,4)$$所以：$$P(\text{double})=\frac{4}{16}=\frac14$$如果一名玩家已经连续获得两次双打，并且再次掷出双打，则他们将直接入狱，无需移动。 

---

 #2.公益金

 对于 CC 方块：

 - 14张牌没有任何作用，
 - 1 张卡$\to$去，
 - 1 张卡$\to$监狱。 

因此：$$P(\text{GO})=\frac1{16},\quad P(\text{JAIL})=\frac1{16},\quad P(\text{stay})=\frac{14}{16}$$---

 # 3.机会卡

 对于 CH 方格：

 10 张牌可以移动玩家：

 - 去
 - 监狱
 - C1
 - E3
 - H2
 - R1
 - 下一个R
 - 下一个R
 - 下一个U
 - 后退3格

 6张牌什么也不做。 

因此，每个列出的运动都有概率$1/16$，除了：

 - 下一个 R 出现两次$\Rightarrow 2/16$。 

---

 # 4. 递归移动处理

 其中微妙的一点是：

 - “返回3格”可以落在CC格上。 
- 该 CC 方格可能会再次移动玩家。 

例子：$$36 \xrightarrow{\text{back 3}} 33$$和$33$是CC。 

因此，运动分辨率必须是递归的，直到到达终点方块。 

---

 # 5. 转移矩阵

 定义：$$T_{ij}=P(\text{state }i\to \text{state }j)$$这是一个$120\times120$随机矩阵。 

平稳分布$\pi$满足：$$\pi T = \pi$$我们可以通过重复乘法得到它：$$\pi_{n+1}=\pi_n T$$直至收敛。 

最后，对每个棋盘方格的三个重复计数状态求和：$$P(p)=\sum_{d=0}^2 \pi(p,d)$$然后对概率进行排序。 

---

 # Python 实现```python
from collections import defaultdict

# ------------------------------------------------------------
# Board constants
# ------------------------------------------------------------

GO = 0
JAIL = 10
G2J = 30

CC = {2, 17, 33}
CH = {7, 22, 36}

RAILWAYS = [5, 15, 25, 35]
UTILITIES = [12, 28]

# ------------------------------------------------------------
# Helpers for Chance cards
# ------------------------------------------------------------

def next_railway(pos):
    for r in RAILWAYS:
        if r > pos:
            return r
    return RAILWAYS[0]

def next_utility(pos):
    for u in UTILITIES:
        if u > pos:
            return u
    return UTILITIES[0]

# ------------------------------------------------------------
# Resolve all special square effects recursively.
#
# Returns a dictionary:
#   final_position -> probability
# ------------------------------------------------------------

def resolve_square(pos):

    # Go To Jail
    if pos == G2J:
        return {JAIL: 1.0}

    # Community Chest
    if pos in CC:
        out = defaultdict(float)

        out[GO] += 1/16
        out[JAIL] += 1/16
        out[pos] += 14/16

        return dict(out)

    # Chance
    if pos in CH:
        out = defaultdict(float)

        # 6 cards do nothing
        out[pos] += 6/16

        # Direct movement cards
        out[GO] += 1/16
        out[JAIL] += 1/16
        out[11] += 1/16      # C1
        out[24] += 1/16      # E3
        out[39] += 1/16      # H2
        out[5] += 1/16       # R1

        # Next railway (2 cards)
        out[next_railway(pos)] += 2/16

        # Next utility
        out[next_utility(pos)] += 1/16

        # Back 3 squares
        back = (pos - 3) % 40

        # Must recursively resolve
        for p, prob in resolve_square(back).items():
            out[p] += prob * (1/16)

        return dict(out)

    # Ordinary square
    return {pos: 1.0}

# ------------------------------------------------------------
# Build state indexing
# state = (position, consecutive_doubles)
# ------------------------------------------------------------

states = []
index = {}

for p in range(40):
    for d in range(3):
        index[(p, d)] = len(states)
        states.append((p, d))

N = len(states)

# ------------------------------------------------------------
# Transition matrix
# ------------------------------------------------------------

T = [[0.0] * N for _ in range(N)]

# Enumerate all dice outcomes
dice = []

for a in range(1, 5):
    for b in range(1, 5):
        dice.append((a, b))

for i, (pos, doubles_count) in enumerate(states):

    for a, b in dice:

        prob = 1 / 16
        is_double = (a == b)

        # Third consecutive double -> jail
        if is_double and doubles_count == 2:
            j = index[(JAIL, 0)]
            T[i][j] += prob
            continue

        # New doubles count
        new_doubles = doubles_count + 1 if is_double else 0

        # Move normally
        new_pos = (pos + a + b) % 40

        # Resolve square effects
        outcomes = resolve_square(new_pos)

        for final_pos, p2 in outcomes.items():

            # After movement effects, doubles count persists
            # unless sent to jail
            if final_pos == JAIL:
                nd = 0
            else:
                nd = new_doubles

            j = index[(final_pos, nd)]
            T[i][j] += prob * p2

# ------------------------------------------------------------
# Power iteration for stationary distribution
# ------------------------------------------------------------

dist = [0.0] * N
dist[index[(GO, 0)]] = 1.0

for _ in range(500):
    new_dist = [0.0] * N

    for i in range(N):
        for j in range(N):
            new_dist[j] += dist[i] * T[i][j]

    dist = new_dist

# ------------------------------------------------------------
# Combine probabilities by board square
# ------------------------------------------------------------

square_probs = [0.0] * 40

for (pos, d), idx in index.items():
    square_probs[pos] += dist[idx]

# Sort descending
ranking = sorted(
    range(40),
    key=lambda x: square_probs[x],
    reverse=True
)

top3 = ranking[:3]

answer = "".join(f"{x:02d}" for x in top3)

print(answer)
```---

 # 小型健全性检查

 对于普通的 6 面大富翁，已知的顶部方块是：

 1. 监狱
 2.E3
 3. 去

 问题陈述给出了模态字符串：$$102400$$当切换到 6 面骰子时，我们的算法会重现相同的顺序，从而验证正确性。 

使用 4 面骰子：

 - 双打出现的频率更高，
 - 因此三双的发生率更高，
 - 监狱变得更加占主导地位。 

这符合直觉。
