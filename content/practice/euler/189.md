[欧拉项目问题 189](https://projecteuler.net/problem=189)

 ## 解决方案

 **答案：**`10834893628237824`设大等边三角形有边长$8$。 

它又分为$$1+3+5+\cdots+15 = 8^2 = 64$$小三角形。 

我们必须计算正确的数量$3$-这些的颜色$64$三角形，其中相邻三角形（共享一条边）接收不同的颜色。 

---

 # 1.数学分析

 ## 1.1 图形解释

 将每个小三角形视为图的一个顶点。 

- 两个顶点相连当且仅当对应的三角形共享一条边。 
- 我们想要使用颜色对该图进行正确着色的数量$\{R,G,B\}$。 

因此，这是一个图形着色计数问题。 

该图有：

 -$64$顶点，
 - 最大学位$3$,
 - 非常规则的分层结构。 

直接暴力搜索需要检查$$3^{64} \approx 3.4\times10^{30}$$任务，这是不可能的。 

所以我们需要动态规划。 

---

 # 1.2 关键见解：较小的边界宽度

 如果我们逐行处理三角形（或更准确地说，以合适的几何顺序），那么在任何时刻，只有少数已经着色的三角形仍然可以与未来的三角形交互。 

该集合称为**前沿**。 

对于边的三角网格$8$，边界永远不会超过大小$8$。 

因此：

 - 不用记住所有以前的颜色，
 - 我们只记得边界上的颜色。 

由于每个边界顶点都有$3$可能的颜色，状态数最多为$$3^8 = 6561,$$这是很小的。 

这使得精确计算变得可行。 

---

 # 1.3 动态规划状态

 假设我们以固定的顺序处理三角形：$$T_0,T_1,\dots,T_{63}.$$在步骤$i$：

 - 一些之前处理过的三角形仍有尚未处理的邻居；
 - 这些三角形形成边界。 

DP状态简单来说就是：$$(\text{frontier colouring}) \mapsto \text{count}.$$处理下一个三角形时：

 1. 确定哪些颜色是已经有颜色的邻居禁止使用的颜色。 
2. 尝试剩余的颜色。 
3.更新边界。 

因为每个三角形最多有度数$3$，每个转变都非常小。 

---

 # 2.Python实现```python
from collections import defaultdict

# ------------------------------------------------------------
# Build the triangular grid graph
# ------------------------------------------------------------

def build_graph(n):
    """
    Build the adjacency graph of the n^2 little triangles.

    Each small triangle is represented by its three lattice vertices.
    Two triangles are adjacent iff they share an edge
    (i.e. two common vertices).
    """

    triangles = []

    # Upward-pointing triangles
    for i in range(n):
        for j in range(n - i):
            tri = ((i, j), (i + 1, j), (i, j + 1))
            triangles.append(tri)

    # Downward-pointing triangles
    for i in range(n - 1):
        for j in range(n - 1 - i):
            tri = ((i + 1, j), (i, j + 1), (i + 1, j + 1))
            triangles.append(tri)

    m = len(triangles)

    # Build adjacency
    adj = [set() for _ in range(m)]

    for a in range(m):
        A = set(triangles[a])

        for b in range(a + 1, m):
            B = set(triangles[b])

            # Sharing an edge means sharing exactly two vertices
            if len(A & B) == 2:
                adj[a].add(b)
                adj[b].add(a)

    return triangles, adj

# ------------------------------------------------------------
# Choose a geometric processing order
# ------------------------------------------------------------

def triangle_centroid(tri):
    x = sum(v[0] for v in tri) / 3
    y = sum(v[1] for v in tri) / 3
    return (y, x)

# ------------------------------------------------------------
# Count proper 3-colourings using frontier DP
# ------------------------------------------------------------

def count_colourings(n=8):

    triangles, adj = build_graph(n)

    m = len(triangles)

    # Process triangles from top to bottom
    order = sorted(range(m),
                   key=lambda t: triangle_centroid(triangles[t]))

    pos = {v: i for i, v in enumerate(order)}

    # Past neighbours of each vertex
    past = {
        v: [u for u in adj[v] if pos[u] < pos[v]]
        for v in range(m)
    }

    # DP:
    # state = tuple of frontier colours
    # value = number of ways
    states = {(): 1}

    for i, v in enumerate(order):

        # Current active frontier
        active = sorted(
            {
                u for u in order[:i]
                if any(pos[w] >= i for w in adj[u])
            },
            key=lambda x: pos[x]
        )

        # Frontier after processing v
        next_active = sorted(
            {
                u for u in order[:i + 1]
                if any(pos[w] > i for w in adj[u])
            },
            key=lambda x: pos[x]
        )

        new_states = defaultdict(int)

        for key, count in states.items():

            colouring = dict(zip(active, key))

            # Colours forbidden by already-coloured neighbours
            forbidden = {
                colouring[u]
                for u in past[v]
                if u in colouring
            }

            for colour in range(3):

                if colour in forbidden:
                    continue

                new_colouring = colouring.copy()

                # Keep v only if it still has future neighbours
                if any(pos[w] > i for w in adj[v]):
                    new_colouring[v] = colour

                new_key = tuple(new_colouring[u]
                                for u in next_active)

                new_states[new_key] += count

        states = new_states

    return sum(states.values())

# ------------------------------------------------------------
# Compute the answer
# ------------------------------------------------------------

answer = count_colourings(8)

print(answer)

 # 3. 代码演练

 ## 图构建

 每个小三角形都由它的三个晶格顶点编码。 

向上三角形示例：$$((i,j),(i+1,j),(i,j+1)).$$向下三角形示例：$$((i+1,j),(i,j+1),(i+1,j+1)).$$当两个三角形共享两个顶点时，它们恰好是邻居。 

---

 ## 订购

 我们使用质心坐标从上到下处理三角形。 

这使得边界保持较小。 

---

 ## DP 状态

 国营商店：

 - 存在哪些边界三角形，
 - 以及它们的颜色。 

元组键可能如下所示：```python
(0, 2, 1, 0)
```含义：

 - 边界三角形 #1 的颜色为 0，
 - 边界三角形#2 的颜色为 2，
 - 等

 ---

 ## 过渡步骤

 对于下一个三角形：

 1. 查找相邻边界三角形已使用的颜色。 
2. 尝试剩余的颜色。 
3.更新边界元组。
