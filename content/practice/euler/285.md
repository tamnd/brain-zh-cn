[欧拉项目问题 285](https://projecteuler.net/problem=285)

 ## 解决方案

 **答案：**`157055.80999`让$$x = ka+1,\qquad y = kb+1,$$在哪里$a,b\sim U[0,1]$。 

然后$(x,y)$均匀分布在正方形上$$[1,k+1]\times[1,k+1],$$谁的面积是$k^2$。 

阿尔伯特分数$k$准确地指出何时$$k-\tfrac12 \le \sqrt{x^2+y^2} < k+\tfrac12.$$所以我们需要位于环内的正方形部分的面积$$(k-\tfrac12)^2 \le x^2+y^2 < (k+\tfrac12)^2.$$---

 # 1.几何概率

 定义$$A(R)=\text{area}\left(\{(x,y)\in[1,\infty)^2:x^2+y^2\le R^2\}\right).$$为了$R>1$，圆与线相交$y=1$在$$x=\sqrt{R^2-1}.$$因此$$A(R)=\int_1^{\sqrt{R^2-1}} \left(\sqrt{R^2-x^2}-1\right)\,dx.$$使用$$\int \sqrt{R^2-x^2}\,dx = \frac12\left( x\sqrt{R^2-x^2} + R^2\arcsin\frac{x}{R} \right),$$化简后我们得到：$$A(R) = 1-\sqrt{R^2-1} + R^2\left( \frac{\pi}{4}-\arcsin\frac1R \right).$$所以对于固定的期望概率$k$是$$P_k = \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k^2}.$$回合中的预期得分贡献$k$因此是$$E_k = kP_k = \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k}.$$因此总期望是$$E = \sum_{k=1}^{10^5} \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k}.$$---

 # 2.Python实现```python
import math

def A(R):
    # For R <= 1 the region is empty
    if R <= 1.0:
        return 0.0

    return (
        1.0
        - math.sqrt(R * R - 1.0)
        + R * R * (math.pi / 4.0 - math.asin(1.0 / R))
    )

def expected_value(n):
    total = 0.0

    for k in range(1, n + 1):
        outer = A(k + 0.5)
        inner = A(k - 0.5)

        total += (outer - inner) / k

    return total

# Check the example from the problem
print(round(expected_value(10), 5))

# Compute the required answer
ans = expected_value(100000)

print(f"{ans:.5f}")
```---
