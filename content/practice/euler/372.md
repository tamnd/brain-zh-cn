 ## 解决方案

 **答案：**`301450082318807027`让$$R(M,N)=\#\left\{(x,y): M<x\le N,\; M<y\le N,\; \left\lfloor \frac{y^2}{x^2}\right\rfloor \text{ is odd} \right\}.$$我们想要$$R(2\cdot 10^6,10^9).$$---

 ## 1.数学分析

 我们必须计算满足的格点$$\left\lfloor \frac{y^2}{x^2}\right\rfloor = 2k+1$$对于某个整数$k\ge0$。 

等价地，$$2k+1 \le \frac{y^2}{x^2} < 2k+2,$$因此$$x\sqrt{2k+1}\le y < x\sqrt{2k+2}.$$所以对于一个固定的$x$，有效的$y$位于不相交的区间内$$[x\sqrt{1},x\sqrt{2}), [x\sqrt{3},x\sqrt{4}), [x\sqrt{5},x\sqrt{6}), \ldots$$仅限于$M<y\le N$。 

对于固定奇数$n$， 定义$$I_n(x)=\#\{y: n x^2\le y^2<(n+1)x^2,\; M<y\le N\}.$$然后$$R(M,N)=\sum_{\substack{n\ge1\\ n\text{ odd}}} \sum_{x=M+1}^{N} I_n(x).$$---

 ### 精确计算间隔

 对于奇数$n$,$$y \in \left[ \left\lceil x\sqrt n\right\rceil, \left\lceil x\sqrt{n+1}\right\rceil-1 \right].$$自从$n+1$是偶数且不是正方形，上端点总是无理数，所以$$\left\lceil x\sqrt{n+1}\right\rceil-1 = \left\lfloor x\sqrt{n+1}\right\rfloor.$$因此，贡献就变成了底额金额的差异：$$I_n(x) = \left\lfloor x\sqrt{n+1}\right\rfloor - \left\lfloor x\sqrt n\right\rfloor + \varepsilon_n(x),$$在哪里$\varepsilon_n(x)=1$仅当$n$是奇数平方（因为此时下端点是整数），否则$0$。 

因此，问题归结为评估以下形式的巨额金额$$\sum_{x\le X}\lfloor x\sqrt d\rfloor.$$这些是经典的 Beatty 序列/二次无理数下限和，可以用以下形式进行评估：$O(\log X)$使用递归互补 Beatty 关系计算时间。 

相关奇数总数$n$很小：$$n \le \left(\frac{N}{M+1}\right)^2 < 250000,$$所以整个计算是可行的。

 ## 2.Python实现```python
from math import isqrt

# Sum_{k=1}^n floor(k * sqrt(d))
# Uses recursive Beatty-style reduction.
def beatty_sqrt_sum(d, n):
    if n <= 0:
        return 0

    a = isqrt(d)
    if a * a == d:
        # perfect square
        return a * n * (n + 1) // 2

    # alpha = sqrt(d)
    # beta = alpha / (alpha - floor(alpha))
    m = int((isqrt(d * n * n) + a * n) // (d - a * a))

    # Recursive complementary Beatty identity
    return (
        n * m
        + n * (n + 1) // 2 * a
        - m * (m + 1) // 2
        - beatty_sqrt_sum(d, m)
    )

def F(d, L, R):
    # Sum_{x=L}^R floor(x * sqrt(d))
    if R < L:
        return 0
    return beatty_sqrt_sum(d, R) - beatty_sqrt_sum(d, L - 1)

def R(M, N):
    ans = 0

    max_n = (N // (M + 1)) ** 2

    for n in range(1, max_n + 1, 2):

        # largest x with x*sqrt(n) <= N
        x2 = N // isqrt(n)

        # largest x with x*sqrt(n+1) <= N
        x1 = N // isqrt(n + 1)

        L = M + 1

        # region where upper bound is floor(x*sqrt(n+1))
        if x1 >= L:
            ans += (
                F(n + 1, L, x1)
                - F(n, L, x1)
            )

        # region where upper bound saturates at N
        A = max(L, x1 + 1)
        if x2 >= A:
            cnt = x2 - A + 1
            ans += cnt * N - F(n, A, x2)

        # correction when n is an odd square
        s = isqrt(n)
        if s * s == n:
            ans += max(0, x2 - L + 1)

    return ans

print(R(0, 100))       # 3019
print(R(100, 10000))  # 29750422

print(R(2_000_000, 1_000_000_000))
```---

 ## 3. 代码演练

 ###`beatty_sqrt_sum(d, n)`计算$$\sum_{k=1}^{n}\lfloor k\sqrt d\rfloor$$使用递归互补 Beatty 恒等式。 

这避免了迭代$10^9$。 

---

 ###`F(d, L, R)`方便包装：$$\sum_{x=L}^{R}\lfloor x\sqrt d\rfloor.$$---

 ### 主循环

 我们迭代奇数$n$:```python
for n in range(1, max_n + 1, 2):
```每个奇数$n$对应一条带$$n \le \frac{y^2}{x^2} < n+1.$$我们分开了$x$-范围分为两部分：

 1.$x\sqrt{n+1}\le N$：普通间隔长度。 
2.$x\sqrt{n+1}>N$：上端点被裁剪$N$。 

两者都变成了下限总和表达式。
