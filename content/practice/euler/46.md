[欧拉项目问题 46](https://projecteuler.net/problem=46)

 ## 解决方案

 **答案：**`5777`## 1.数学分析

 我们寻求**不能**写成的**最小奇合数**：$$n = p + 2k^2$$在哪里：

-$n$是奇数复合物，
 -$p$是素数，
 -$k$是一个正整数。 

这是有时被称为**哥德巴赫其他猜想**的猜想的反例。 

### 第 1 步：我们必须测试哪些数字？ 

我们只关心：

 1. **奇数**
 2. 这是**合数**（不是素数）

 对于每个奇数复合$n$，我们检查是否存在：$$n - p = 2k^2$$对于一些素数$p$。 

重新排列：$$k^2 = \frac{n-p}{2}$$所以对于每个素数$p < n$，我们计算：$$m = \frac{n-p}{2}$$如果$m$是一个**完全平方**，则表示存在。 

如果 **没有** prime 有效，那么$n$是反例。 

---

 ### 第 2 步：高效策略

 对于每个奇数复合$n$:

 1. 生成下面所有素数$n$。 
2. 对于每个素数$p$:

 - 计算$n-p$。 
- 如果$n-p$是偶数：$$m = \frac{n-p}{2}$$- 检查是否$m$是一个完美的正方形。 

完全平方检验可以使用整数平方根来完成：$$r = \lfloor \sqrt{m} \rfloor$$然后检查：$$r^2 = m$$如果属实，我们就找到了一个代表。 

---

 ### 步骤 3：验证示例

 给出的例子：$$9 = 7 + 2\cdot1^2$$

$$15 = 7 + 2\cdot2^2$$

$$21 = 3 + 2\cdot3^2$$

$$25 = 7 + 2\cdot3^2$$

$$27 = 19 + 2\cdot2^2$$

$$33 = 31 + 2\cdot1^2$$都满足规则。 

因此算法应该继续向上直到失败。

 ## 2.Python实现```python
import math

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    limit = int(math.sqrt(n))
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False
    return True

def can_be_written(n):
    """
    Check if odd composite n can be written as:
    n = prime + 2 * square
    """
    for p in range(2, n):
        if is_prime(p):
            diff = n - p

            # Must equal 2*k^2
            if diff % 2 == 0:
                m = diff // 2
                root = math.isqrt(m)

                if root * root == m:
                    return True

    return False

def solve():
    n = 9

    while True:
        # Only test odd composite numbers
        if n % 2 == 1 and not is_prime(n):
            if not can_be_written(n):
                return n

        n += 2

print(solve())
```---
