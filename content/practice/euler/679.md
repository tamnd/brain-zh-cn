 # 1.数学分析

 该问题是一个经典的有限状态动态规划问题。 

主要观察结果是：

 1.每个关键词都有长度$4$。 
2.追加新字符是否创建关键字仅取决于最后一个字符$3$字符已经写好了。 
3.我们必须跟踪哪些关键词已经出现，因为：

 - 每个关键字必须至少出现一次，
 - 任何关键字不得出现多次。 

因此，一个词的整个历史可以压缩为：

 - 当前后缀的最大长度$3$,
 - 四个关键字中的哪一个已经出现。 

---

 ## 州代表

 通过以下方式定义 DP 状态：$$(\text{suffix}, b)$$在哪里

-`suffix`最多是最后 3 个字母，
 -$b$是一个4位掩码，记录哪些关键词出现过。 

例如：

 - 位 0 = 发生 FREE，
 - 位 1 = 发生票价，
 - 位 2 = 发生 AREA，
 - 位 3 = REEF 发生。 

只有$$1+4+4^2+4^3 = 85$$可能的后缀，并且仅$2^4=16$面具。 

所以总的状态空间很小：$$85 \times 16 = 1360.$$---

 ## 转换规则

 假设我们处于状态$$(\text{suffix}, b)$$并附加一个字符$c\in S$。 

让$$t = \text{suffix}+c.$$现在：

 - 如果$t$以其中一个关键字结尾，我们检测到它，
 - 如果该关键字之前已经出现过，则此转换无效，
 - 否则我们设置相应的位$b$。 

新后缀变为最后 3 个字母$t$。 

---

 ## 为什么这有效

 关键字的长度为 4，因此当附加新字母时，唯一可能的新创建关键字是以新位置结束的长度为 4 的后缀。 

因此，我们永远不需要检查单词的较旧部分。 

这正是用于子串计数问题的标准自动机技术。

 # 2.Python实现```python
from collections import defaultdict

# The four keywords
keywords = ["FREE", "FARE", "AREA", "REEF"]

# Alphabet
letters = "AEFR"

def transition(suffix, ch):
    """
    Append character ch to the current suffix.
    Return:
        (new_suffix, list_of_keywords_completed)
    """
    t = suffix + ch

    found = []

    for i, k in enumerate(keywords):
        if t.endswith(k):
            found.append(i)

    # Keep only the last 3 characters
    new_suffix = t[-3:]

    return new_suffix, found

# DP[state] = number of ways
# state = (suffix, mask)
dp = defaultdict(int)

# Start with empty word
dp[("", 0)] = 1

N = 30

for _ in range(N):

    ndp = defaultdict(int)

    for (suffix, mask), ways in dp.items():

        for ch in letters:

            new_suffix, found = transition(suffix, ch)

            new_mask = mask
            valid = True

            # Every keyword must occur at most once
            for idx in found:

                bit = 1 << idx

                # keyword already used -> invalid
                if new_mask & bit:
                    valid = False
                    break

                new_mask |= bit

            if valid:
                ndp[(new_suffix, new_mask)] += ways

    dp = ndp

# all four keywords seen exactly once
FULL = (1 << 4) - 1

answer = sum(
    ways
    for (suffix, mask), ways in dp.items()
    if mask == FULL
)

print(answer)
```---
