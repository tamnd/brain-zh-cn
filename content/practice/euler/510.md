 ## 解决方案

 **答案：**`315306518862563689`让

-$r_A=a$,
 -$r_B=b$,
 -$r_C=c$，

和$0<a\le b\le n$，以及所有半径整数。 

我们必须计算$$S(n)=\sum (a+b+c)$$覆盖所有有效的切线配置。 

---

 # 1.数学分析

 我们放置切线$L$作为$x$-轴。 

然后：

 - 圆圈$A$有中心$(0,a)$，
- 圆圈$B$有中心$(2\sqrt{ab},\,b)$,

 因为与同一条线相切并且彼此相切的两个圆满足：$$(\Delta x)^2=(a+b)^2-(a-b)^2=4ab.$$现在放置圆圈$C$与中心$(x,c)$。 

自从$C$与$A$,$$x^2=(a+c)^2-(a-c)^2=4ac,$$因此$$x=2\sqrt{ac}.$$同样，与$B$给出$$(2\sqrt{ab}-x)^2=4bc.$$代替$x=2\sqrt{ac}$:$$(2\sqrt{ab}-2\sqrt{ac})^2=4bc.$$除以$4$:$$(\sqrt{ab}-\sqrt{ac})^2=bc.$$对几何构型求平方根$$\sqrt{ab}=\sqrt{ac}+\sqrt{bc}.$$分解因素$\sqrt c$:$$\sqrt{ab}=\sqrt c(\sqrt a+\sqrt b).$$所以$$\boxed{\sqrt c=\frac{\sqrt{ab}}{\sqrt a+\sqrt b}}$$和$$\boxed{c=\frac{ab}{(\sqrt a+\sqrt b)^2}}.$$---

 ## 整数参数化

 对于$c$为整体，写$$a=dx^2,\qquad b=dy^2,$$在哪里$x,y$是互质的。 

然后$$c=\frac{d^2x^2y^2}{d(x+y)^2} =\frac{dx^2y^2}{(x+y)^2}.$$自从$$\gcd(x+y,xy)=1$$对于共素$x,y$，我们必须有$$(x+y)^2\mid d.$$所以让$$d=k(x+y)^2.$$那么每个解都是$$\boxed{ \begin{aligned} a&=k\,x^2(x+y)^2,\\ b&=k\,y^2(x+y)^2,\\ c&=k\,x^2y^2, \end{aligned}}$$和$$\gcd(x,y)=1,\qquad x\le y,\qquad k\ge1.$$---

 ## 贡献$S(n)$自从$b\le n$,$$k\,y^2(x+y)^2\le n.$$定义$$M=\left\lfloor \frac{n}{y^2(x+y)^2}\right\rfloor.$$对于固定互质$x,y$，有效值为$k=1,\dots,M$。 

现在$$a+b+c = k\Big((x+y)^2(x^2+y^2)+x^2y^2\Big).$$因此总贡献是$$\Big((x+y)^2(x^2+y^2)+x^2y^2\Big) \sum_{k=1}^{M}k.$$使用$$\sum_{k=1}^{M}k=\frac{M(M+1)}2,$$我们得到$$\boxed{ S(n)= \sum_{\substack{x\le y\\ \gcd(x,y)=1}} \left((x+y)^2(x^2+y^2)+x^2y^2\right) \frac{M(M+1)}2 }$$在哪里$$M=\left\lfloor \frac{n}{y^2(x+y)^2}\right\rfloor.$$这是有效的，因为$$y^2(x+y)^2\le n$$仅仅意味着关于$O(\sqrt n)$相关对。

 # 2.Python实现```python
from math import gcd, isqrt

def S(n):
    total = 0

    # y^2 (x+y)^2 <= n
    # so y is at most sqrt(n)
    limit = isqrt(n)

    for y in range(1, limit + 1):
        for x in range(1, y + 1):

            # primitive pairs only
            if gcd(x, y) != 1:
                continue

            denom = y * y * (x + y) * (x + y)

            if denom > n:
                break

            M = n // denom

            base = (x + y) * (x + y) * (x * x + y * y)
            base += x * x * y * y

            total += base * M * (M + 1) // 2

    return total

print(S(5))       # 9
print(S(100))     # 3072
print(S(10**9))
```---
