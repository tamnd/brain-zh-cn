[欧拉项目768问题](https://projecteuler.net/problem=768)

 ## 解决方案

 让 360 个烛台对应于 360 次单位根。 

当且仅当所选根的向量和为零时，配置是完美平衡的。 

将所选集合写为不同 360 次单位根的消失和。 

因为$$360 = 2^3\cdot 3^2\cdot 5$$蜡烛的数量是$20$，它**不能被 3** 整除，消失和的 Lam-Leung 分类意味着每个平衡配置必须分解为以下各项的不相交并集：

 - 对映体对（大小$2$），和/或
 - 正五边形（大小$5$）。 

不会发生其他原始消失配置。 

---

 定义正五边形$$P_r=\{r,r+72,r+144,r+216,r+288\} \qquad (0\le r<72).$$注意：

-$P_r$和$P_{r+36}$是相反的五边形。 
- 它们一起形成一个包含 10 个顶点的“十边形块”。 
- 在一个块内正好有 5 个对映体对。 

所以 360 个顶点分为$36$独立的块。 

---

 对于一个块，可能的平衡选择是：

 - 选择$k$对映体对（$0\le k\le 4$）：$$\binom{5}{k}x^{2k}$$- 选择一个五边形：$$2x^5$$- 选择整个十边形：$$x^{10}$$（选择所有 5 个对映体对给出的集合与选择两个相对的五边形相同，因此必须只计算一次。）

 因此，一个块的生成多项式是$$F(x)=1+5x^2+10x^4+2x^5+10x^6+5x^8+x^{10}.$$由于36个块是独立的，$$f(360,20)=[x^{20}]F(x)^{36}.$$---

 Python代码：```python
from collections import defaultdict

# generating polynomial for one 10-vertex block
F = {
    0: 1,
    2: 5,
    4: 10,
    5: 2,
    6: 10,
    8: 5,
    10: 1
}

# DP for coefficient extraction
dp = {0: 1}

for _ in range(36):
    nd = defaultdict(int)

    for a, va in dp.items():
        for b, vb in F.items():
            if a + b <= 20:
                nd[a + b] += va * vb

    dp = nd

print(dp[20])
```这会产生$$7631085872322540.$$检查：

 - 对于$f(12,4)$，同样的方法给出$15$。 
- 为了$f(36,6)$，它给出$876$。 

两者都与问题陈述相符。 

因此，

 **答案：7631085872322540**
