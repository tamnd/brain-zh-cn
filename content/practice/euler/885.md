[项目欧拉问题 885](https://projecteuler.net/problem=885)

 ## 解决方案

 **答案：**`827850196`设一个数的非零数字$d$是$$1^{c_1}2^{c_2}\cdots 9^{c_9},$$在哪里$c_i\ge 0$，并让$$k=c_1+\cdots+c_9$$是非零数字的数量。 

然后$$f(d)=\underbrace{11\ldots1}_{c_1} \underbrace{22\ldots2}_{c_2} \cdots \underbrace{99\ldots9}_{c_9},$$即数字逐渐排序并删除所有零。 

我们必须计算$$S(18)=\sum_{\substack{d\ge1\\ \text{at most 18 digits}}} f(d) \pmod{1123455689}.$$---

 # 1.数学分析

 ## 步骤 1 — 修复非零数字

 假设非零数字的多重集是固定的：$$(c_1,c_2,\dots,c_9).$$那么值$f(d)$是固定的。 

唯一剩下的自由是：

 - 有多少个零，
 - 所有数字如何排列。 

令数字包含$c_0$零，所以总长度是$$n=k+c_0.$$因为我们只考虑正整数，所以前导数字不能为零。 

---

 ## 步骤 2 — 计算有效数字

 多重集的排列总数为$$\frac{n!}{c_0!c_1!\cdots c_9!}.$$其中，第一位非零的分数是$$\frac{k}{n},$$因为正是因为$k$的$n$位置包含非零数字。 

因此有效的数量$n$-数字整数是$$\frac{k}{n}\cdot \frac{n!}{c_0!c_1!\cdots c_9!} = \frac{k(n-1)!}{c_0!c_1!\cdots c_9!}.$$现在重写：$$\frac{k(n-1)!}{c_0!} = \frac{k!}{1}\binom{n-1}{c_0}.$$的确，$$k\frac{(k+c_0-1)!}{c_0!} = k!\binom{k+c_0-1}{c_0}.$$因此计数变为$$\frac{k!}{c_1!\cdots c_9!} \binom{k+c_0-1}{c_0}.$$---

 ## 步骤 3 — 对所有可能的零计数求和

 对于固定非零计数$(c_1,\dots,c_9)$，零计数可能是$$0\le c_0\le 18-k.$$因此总重数为$$\frac{k!}{c_1!\cdots c_9!} \sum_{c_0=0}^{18-k} \binom{k+c_0-1}{c_0}.$$使用曲棍球棒身份，$$\sum_{t=0}^{m}\binom{k+t-1}{t} = \binom{k+m}{m}.$$和$m=18-k$,$$\sum_{c_0=0}^{18-k} \binom{k+c_0-1}{c_0} = \binom{18}{k}.$$所以每个多重集都有贡献$$f \cdot \frac{k!}{c_1!\cdots c_9!} \binom{18}{k}.$$因此$$S(18) = \sum_{k=1}^{18} \binom{18}{k} \sum_{c_1+\cdots+c_9=k} f(c_1,\dots,c_9) \frac{k!}{c_1!\cdots c_9!}.$$现在这是有限且很小的。 

总的 9 元组数量$k\le18$是$$\binom{18+9}{9}\approx 4.7\times10^4,$$这是很小的。 

---

 # 2.Python实现```python
from math import factorial, comb

MOD = 1123455689
N = 18

# Precompute factorials
fact = [factorial(i) for i in range(N + 1)]

answer = 0

def dfs(digit, remaining, counts):
    """
    Recursively generate all count vectors:
        c1 + c2 + ... + c9 <= N
    """
    global answer

    if digit == 10:
        k = sum(counts)

        # Ignore the empty multiset
        if k == 0:
            return

        # Build f(d):
        # digits sorted increasingly with repetitions
        s = []
        for d, c in enumerate(counts, start=1):
            s.extend(str(d) * c)

        f_value = int("".join(s))

        # multinomial factor = k! / (c1! c2! ... c9!)
        mult = fact[k]
        for c in counts:
            mult //= fact[c]

        # Contribution
        contribution = f_value * mult * comb(N, k)

        answer += contribution
        return

    # Choose count for current digit
    for c in range(remaining + 1):
        dfs(digit + 1, remaining - c, counts + [c])

dfs(1, N, [])

print(answer % MOD)
```---
