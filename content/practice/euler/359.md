[欧拉项目问题 359](https://projecteuler.net/problem=359)

 ## 解决方案

 **答案：**`40632119`让$$P(f,r)$$是占用房间的人$r$在地板上$f$。 

我们必须计算$$\sum_{fr=71328803586048} P(f,r)$$并返回最后一个$8$数字。 

---

 ## 1.数学分析

 ### 第 1 步：地板结构

 假设楼层以人开始$a$。 让居住者$$x_1=a,\ x_2,\ x_3,\dots$$通过施工，连续居住者满足$$x_n+x_{n+1}=k_n^2$$对于一系列连续的方块。 

从例子来看：

 - 1楼：$1,3,6,10,\dots$

$$1+3=2^2,\quad 3+6=3^2,\quad 6+10=4^2$$- 2楼：$2,7,9,16,\dots$

$$2+7=3^2,\quad 7+9=4^2,\quad 9+16=5^2$$- 3楼：$4,5,11,14,\dots$

$$4+5=3^2,\quad 5+11=4^2,\quad 11+14=5^2$$因此每层楼都有一个起始平方索引$s$， 和：$$x_{n+1}=(s+n-1)^2-x_n$$---

 ### 第 2 步：每层楼的第一个居住者

 对每层楼的第一个房间进行实验得出：$$1,2,4,8,12,18,24,32,40,50,\dots$$这遵循以下模式$$P(f,1)=\left\lfloor \frac{f^2}{2}\right\rfloor$$（为了$f=1$，这给出了$0$，所以 1 楼是一个特例）。 

另外：

 - 奇怪的楼层使用$s=f$,
 - 甚至地板使用$s=f+1$。 

所以对于$f>1$,$$a=\left\lfloor \frac{f^2}{2}\right\rfloor, \qquad s= \begin{cases} f & f\text{ odd}\\ f+1 & f\text{ even} \end{cases}$$---

 ### 第 3 步：封闭表格$P(f,r)$求解递归式可得：

 对于奇数房间$r=2m-1$,$$P(f,r) = a+(m-1)(2s+2m-3)$$对于均匀的房间$r=2m$,$$P(f,r) = -a+(s+m-1)^2+m(m-1)$$这些公式重现了所有示例：

 -$P(10,20)=440$-$P(25,75)=4863$-$P(99,100)=19454$确切地。 

---

 ### 步骤 4：除数求和

 我们需要所有正整数对$(f,r)$和$$fr=71328803586048$$因式分解：$$71328803586048 = 2^{27}3^{12}$$所以每个除数都是$$f=2^a3^b \quad (0\le a\le 27,\ 0\le b\le 12)$$和$$r=\frac{N}{f}$$有$$(27+1)(12+1)=364$$这样的对。 

我们求和$P(f,r)$对所有这些取模$10^8$。 

---

 ## 2.Python实现```python
from math import prod

MOD = 10**8
N = 71328803586048

def P(f, r):
    """Return P(f, r)."""

    # Floor 1 is special
    if f == 1:
        a = 1
        s = 2
    else:
        a = (f * f) // 2
        s = f if (f % 2 == 1) else (f + 1)

    if r % 2 == 1:
        # odd room: r = 2m - 1
        m = (r + 1) // 2
        return a + (m - 1) * (2 * s + 2 * m - 3)
    else:
        # even room: r = 2m
        m = r // 2
        return -a + (s + m - 1) ** 2 + m * (m - 1)

# Generate all divisors of N = 2^27 * 3^12
total = 0

for a in range(28):
    for b in range(13):
        f = (2 ** a) * (3 ** b)
        r = N // f
        total = (total + P(f, r)) % MOD

print(total)
```---

 ## 3. 代码演练

 1. **`P(f, r)`**

 - 计算第一个占用者：$$a=\left\lfloor \frac{f^2}{2}\right\rfloor$$- 选择起始平方索引$s$。 
- 根据奇偶校验使用封闭形式$r$。 
2. **除数生成**

 - 自从$$N=2^{27}3^{12},$$每个除数都是通过选择 2 和 3 的幂生成的。 
3. **总结**

 - 对于每个除数$f$, 计算$$r=\frac{N}{f}$$- 添加$P(f,r)$模数$10^8$。
