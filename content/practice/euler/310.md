[项目欧拉问题 310](https://projecteuler.net/problem=310)

 ## 解决方案

 **答案：**`2586528661783`让$G(n)$是大小堆的 Sprague-Grundy（尼数）值$n$在**尼姆广场**中，移动包括移除平方数的石子。 

一个位置$(a,b,c)$正在失败当且仅当$$G(a)\oplus G(b)\oplus G(c)=0,$$在哪里$\oplus$表示按位异或。 

## 1.数学分析

 对于减法游戏（例如消除平方数），Grundy 数满足：$$G(0)=0,$$并为$n\ge1$,$$G(n)=\operatorname{mex} \left( \{G(n-k^2)\mid k^2\le n\} \right),$$其中 **mex** 表示不在集合中的最小非负整数。 

所以我们计算$G(n)$为所有人$0\le n\le100000$。 
### 关键观察：按频率计数
 让$$f(x)=\#\{n\in[0,N]\mid G(n)=x\}.$$那么**有序**三元组的总数$(a,b,c)$异或零是$$T = \sum_{x,y} f(x)f(y)f(x\oplus y),$$因为有一次$G(a)=x$和$G(b)=y$，第三个数字必须是$$G(c)=x\oplus y.$$但问题只需要三倍$$a\le b\le c.$$我们将有序三元组转换为排序三元组。 

让：

-$E$= 所有相等的三元组$(x,x,x)$-$P$= 两个恰好相等的有序三元组
 -$D$= 所有不同的有序三元组

 然后$$T=D+P+E.$$排序的三元组贡献：

 -$6$如果全部不同，则有序排列，
 -$3$如果两个恰好相等，
 -$1$如果一切平等。 

因此，已排序的亏损头寸的数量为$$L = \frac{D}{6} + \frac{P}{3} + E.$$重新排列：$$L = \frac{T+P+5E}{6}.$$### 计算$P$和$E$对于所有人平等：$$x\oplus x\oplus x=x,$$所以唯一失败的全等三元组是带有数字的堆$0$:$$E=f(0).$$对于恰好两个相等：$$x\oplus x\oplus y=y,$$所以单例堆必须有编号$0$。 

如果$M=N+1$是堆大小的数量，则：$$P = 3\,f(0)(M-1),$$（因子 3 说明哪个位置是单例）。 

我们在示例中验证该方法$N=29$，得到：$$1160,$$匹配问题陈述。 

## 2.Python实现```python
import math

def nim_square_losing_positions(N):
    # All square moves
    squares = [i * i for i in range(1, int(math.isqrt(N)) + 1)]

    # Compute Grundy values
    grundy = [0] * (N + 1)
    max_g = 0

    for n in range(1, N + 1):
        seen = 0

        # Collect reachable Grundy values
        for s in squares:
            if s > n:
                break
            seen |= 1 << grundy[n - s]

        # mex(seen)
        mex = 0
        while (seen >> mex) & 1:
            mex += 1

        grundy[n] = mex
        max_g = max(max_g, mex)

    # Frequency of each Grundy value
    freq = [0] * (max_g + 1)
    for g in grundy:
        freq[g] += 1

    # Count ordered losing triples
    ordered_total = 0
    for x, fx in enumerate(freq):
        for y, fy in enumerate(freq):
            z = x ^ y
            if z <= max_g:
                ordered_total += fx * fy * freq[z]

    f0 = freq[0]
    M = N + 1

    # Exactly two equal
    P = 3 * f0 * (M - 1)

    # All equal
    E = f0

    # Convert ordered -> sorted
    losing_positions = (ordered_total + P + 5 * E) // 6

    return losing_positions

# Check the example
print(nim_square_losing_positions(29))      # 1160

# Solve the problem
print(nim_square_losing_positions(100000))

```因为 XOR 必须为零。 
6. **订购正确**
