[欧拉项目问题 849](https://projecteuler.net/problem=849)

 ## 解决方案

 **答案：**`936203459`让最终分数为$$s_1 \le s_2 \le \cdots \le s_n .$$每对球队比赛两次。 在这两场比赛中，两人的贡献完全一样$4$总分，分配为以下之一$$(4,0),(3,1),(2,2),(1,3),(0,4).$$因此，锦标赛相当于分配给每个无序对$\{i,j\}$整数$x_{ij},x_{ji}\ge 0$和$$x_{ij}+x_{ji}=4.$$团体总成绩$i$是$$s_i=\sum_{j\ne i} x_{ij}.$$---

 # 1.数学分析

 ## 广义朗道定理

 对于普通锦标赛，朗道定理描述了得分序列的特征。 

完全相同的证明在这里适用于“每对 4 点”。 

非减整数序列$$s_1\le s_2\le \cdots \le s_n$$是可实现的当且仅当$$\sum_{i=1}^k s_i \ge 4\binom{k}{2}=2k(k-1) \qquad (1\le k\le n),$$与平等在$k=n$:$$\sum_{i=1}^n s_i = 4\binom{n}{2}=2n(n-1).$$为什么？ 

- 在任何子集内$k$球队，内部比赛已经做出贡献$4\binom{k}{2}$点。 
- 外部游戏贡献非负金额。 
- 因此每个前缀必须满足上述不等式。 

相反，广义朗道定理认为这些条件是充分的。 

所以$F(n)$等于满足以下条件的非减整数序列的数量$$\boxed{ \begin{aligned} &s_1\le s_2\le \cdots \le s_n,\\ &\sum_{i=1}^k s_i \ge 2k(k-1)\quad (1\le k\le n),\\ &\sum_{i=1}^n s_i = 2n(n-1). \end{aligned} }$$---

 ## DP 配方

 我们从左到右构建序列。 

假设我们已经选择了第一个$i$值和它们的总和是$c$。 

下一个值$x=s_{i+1}$必须满足：

 ### 1.非递减条件$$x \ge s_i.$$### 2. 朗道下界

 选择后$x$,$$c+x \ge 2(i+1)i.$$因此$$x \ge 2(i+1)i - c.$$### 3. 其余条款的可行性

 如果$r$积分仍有待分配给其余的人$m=n-i$项，那么$$x \le \left\lfloor \frac{r}{m} \right\rfloor$$因为所有剩余项至少是$x$。 

这给出了一个记忆的 DP。 

状态是：$$(i,\text{prev},\text{rem})$$在哪里

-$i$= 已经确定了多少项，
 -`prev`= 之前的分数，
 -`rem`= 剩余总分尚未确定。 

当前前缀和是自动确定的：$$c = 2n(n-1)-\text{rem}.$$---

 # 2.Python实现```python
from functools import lru_cache

MOD = 10**9 + 7

def F(n):
    TOTAL = 2 * n * (n - 1)

    @lru_cache(None)
    def dp(i, prev, rem):
        """
        i    = number of scores already chosen
        prev = previous score (scores are nondecreasing)
        rem  = remaining total score still to distribute
        """

        # all scores chosen
        if i == n:
            return 1 if rem == 0 else 0

        # current prefix sum already fixed
        prefix_sum = TOTAL - rem

        # Landau lower bound
        lower = max(
            prev,
            2 * (i + 1) * i - prefix_sum
        )

        # all remaining entries are >= x
        upper = rem // (n - i)

        ans = 0

        for x in range(lower, upper + 1):
            ans += dp(i + 1, x, rem - x)

        return ans % MOD

    return dp(0, 0, TOTAL)

print(F(2))   # 3
print(F(7))   # 32923
print(F(100))
```---
