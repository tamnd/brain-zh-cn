[项目欧拉问题 605](https://projecteuler.net/problem=605)

 ## 解决方案

 **答案：**`59992576`让$T$是游戏结束的回合。 

如果玩家连续赢得两轮比赛，则该玩家获胜。 编码轮$r$一点点：

 -$b_r = 0$：本轮**第一个**玩家$r$获胜，
 -$b_r = 1$：**第二个**玩家获胜。 

对于回合$$(i,i+1),\ (i+1,i+2),$$玩家$i+1$双方获胜当且仅当结果是$$(1,0).$$所以游戏在**第一次出现该模式时结束$10$** 在无限公平硬币序列中$(b_r)$。 

### 第 1 步：分配第一个$10$假设第一个$10$发生在回合结束$r$。 然后：

 - 没有更早$10$出现在$b_1,\dots,b_{r-1}$,
 -$b_{r-1}=1,\ b_r=0$。 

避免二进制字符串$10$必须采用以下形式$$0^a1^b$$（单调：一次$1$出现，不迟$0$可以出现）。 

以第一个结束$10$在一轮$r$，第一个$r-1$位必须是$$0^a1^{r-1-a},$$结束于$1$，并且正好有$r-1$选择$a$。 

因此$$\Pr(T=r)=\frac{r-1}{2^r}.$$### 第 2 步：哪位玩家获胜？ 

玩家$k$当第一个获胜时$10$以一轮结束$$r \equiv k \pmod n.$$自从$k=10^4+7>1$，有效轮次为$$r = k + mn,\qquad m\ge0.$$因此$$P_n(k) = \sum_{m\ge0} \frac{k+mn-1}{2^{k+mn}}.$$让$$A=2^n-1.$$使用几何级数，$$P_n(k) = 2^{-k} \left( \frac{k-1}{1-2^{-n}} + \frac{n\,2^{-n}}{(1-2^{-n})^2} \right).$$自从$$1-2^{-n}=\frac{A}{2^n},$$这简化为$$P_n(k) = \frac{2^{\,n-k}\big((k-1)A+n\big)}{A^2}.$$为了$k>1$，分数已经减少，因为：

 -$A=2^n-1$是奇数，
 -$\gcd((k-1)A+n,A)=\gcd(n,A)=1$。 

所以$$M_n(k) = 2^{\,n-k} \big((k-1)A+n\big) A^2.$$我们只需要最后一个$8$数字，即模数$10^8$。 

Python代码：```python
MOD = 10**8

n = 10**8 + 7
k = 10**4 + 7

# A = 2^n - 1 (mod 10^8)
A = (pow(2, n, MOD) - 1) % MOD

# B = (k - 1)A + n (mod 10^8)
B = ((k - 1) * A + n) % MOD

# M_n(k) mod 10^8
answer = (
    pow(2, n - k, MOD)
    * B
    * A
    * A
) % MOD

print(answer)
```这评估为：$$59992576.$$快速验证：

 - 对于$n=6,k=2$，公式给出$$P_6(2)=\frac{368}{1323},$$匹配问题陈述。 

因此需要最后$8$数字是：

 **答案：59992576**
