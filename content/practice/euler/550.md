[项目欧拉问题 550](https://projecteuler.net/problem=550)

 ## 解决方案

 **答案：**`328104836`让$g(n)$表示单堆大小的 Sprague-Grundy 值$n$。 

一个位置与$k$当且仅当 的异或时，堆获胜$k$桩 Grundy 值非零。 

所以问题就简化为：

 1. 计算每个整数的 Grundy 值$2\le n\le 10^7$。 
2. 计算每个 Grundy 值有多少个数字。 
3. 数一数有多少个$k$-元组具有异或$=0$使用异或卷积/沃尔什-哈达玛变换。 
4. 从元组总数中减去。 

---

 # 1.数学分析

 ## 1.1 允许的移动

 从一堆大小$n$，一步选择两个真因数$a,b$的$n$满意的$$1<a<n,\qquad 1<b<n.$$得到的游戏位置是两个独立的桩，所以它的Grundy值为$$g(a)\oplus g(b).$$因此$$g(n)=\operatorname{mex}\{g(a)\oplus g(b)\}.$$---

 # 1.2 关键观察：$g(n)$仅取决于$\Omega(n)$让$$\Omega(n)=\text{total number of prime factors of }n$$（按多重数计算）。 

示例：$$\Omega(12)=\Omega(2^2\cdot3)=3, \qquad \Omega(72)=\Omega(2^3\cdot3^2)=5.$$认为$\Omega(n)=m$。 

的每个真因数$n$质因数介于$1$和$m-1$，并且该区间内的每个值都是可以实现的。 

确实，如果$$n=p_1p_2\cdots p_m$$（允许重复），然后采取任何$t$这些素因数的除数为$\Omega=t$。 

因此移动集仅取决于$m$。 

定义$$G(m)=g(n)\quad\text{whenever }\Omega(n)=m.$$然后$$G(1)=0$$（素数没有移动），并且对于$m\ge2$,$$G(m)=\operatorname{mex} \left( \{\,G(i)\oplus G(j)\;:\;1\le i,j<m\,\} \right).$$递归计算得出：$$\begin{aligned} G(1)&=0\\ G(2)&=1\\ G(3)&=2\\ G(4)&=4\\ G(5)&=7\\ G(6)&=8\\ &\dots \end{aligned}$$为了$n\le10^7$,$$\Omega(n)\le23$$因为$$2^{24}>10^7.$$因此只需要前 23 个 Grundy 值。 

---

 # 1.3 计算异或零元组

 让$$c_x=\#\{n\in[2,10^7]:g(n)=x\}.$$如果我们选择$k$独立堆积，异或为零的元组的数量是$k$-fold 异或卷积评估为零。 

标准工具是快速沃尔什-哈达玛变换 (FWHT)。 

如果$A$是频率向量$(c_x)$，那么：

 1.FWHT变换$A$,
 2. 将每个变换后的组件提升到$k$次方，
 3.逆变换。 

索引处的所得系数$0$正是异或零元组的数量。 

最后，$$f(n,k)=n^k-(\text{xor-zero tuples}).$$这里$n=10^7-1$可能的堆尺寸（$2$通过$10^7$）。 

一切都以模计算$$987654321.$$---

 # 2.Python实现```python
MOD = 987654321
N = 10_000_000
K = 10**12

# ------------------------------------------------------------
# Step 1: compute Omega(n) for all n <= N using a linear sieve
# ------------------------------------------------------------

omega = [0] * (N + 1)
primes = []

for i in range(2, N + 1):
    if omega[i] == 0:
        omega[i] = 1
        primes.append(i)

    for p in primes:
        v = i * p
        if v > N:
            break

        omega[v] = omega[i] + 1

        if i % p == 0:
            break

# ------------------------------------------------------------
# Step 2: compute Grundy values G(m)
# Only m <= 23 is needed
# ------------------------------------------------------------

MAX_OMEGA = max(omega)

G = [0] * (MAX_OMEGA + 1)

grundy_values_so_far = []

for m in range(1, MAX_OMEGA + 1):

    reachable = set()

    for a in grundy_values_so_far:
        for b in grundy_values_so_far:
            reachable.add(a ^ b)

    g = 0
    while g in reachable:
        g += 1

    G[m] = g
    grundy_values_so_far.append(g)

# ------------------------------------------------------------
# Step 3: count how many numbers have each Grundy value
# ------------------------------------------------------------

MAX_G = max(G)

SIZE = 1
while SIZE <= MAX_G:
    SIZE <<= 1

freq = [0] * SIZE

for n in range(2, N + 1):
    freq[G[omega[n]]] += 1

# ------------------------------------------------------------
# Step 4: FWHT for xor convolution
# ------------------------------------------------------------

def fwht(a, inverse=False):
    n = len(a)
    h = 1

    while h < n:
        for i in range(0, n, h * 2):
            for j in range(i, i + h):
                x = a[j]
                y = a[j + h]

                a[j] = (x + y) % MOD
                a[j + h] = (x - y) % MOD

        h <<= 1

    if inverse:
        inv_n = pow(n, -1, MOD)
        for i in range(n):
            a[i] = (a[i] * inv_n) % MOD

# transform
fwht(freq)

# raise pointwise to K
for i in range(SIZE):
    freq[i] = pow(freq[i], K, MOD)

# inverse transform
fwht(freq, inverse=True)

xor_zero = freq[0] % MOD

# total tuples
total = pow(N - 1, K, MOD)

answer = (total - xor_zero) % MOD

print(answer)
```---

 # 3. 代码演练

 ## 线性筛```python
omega[v] = omega[i] + 1
```乘以时加一个素因数$p$。 

因此我们计算$\Omega(n)$对于每一个$n\le10^7$在线性时间内。 

---

 ## 格伦迪递归

 递归：```python
reachable.add(a ^ b)
```实施$$G(m)=\operatorname{mex}\{G(i)\oplus G(j)\}.$$仅存在 23 个状态，因此这部分很小。 

---

 ## 频率表```python
freq[G[omega[n]]] += 1
```计算有多少堆大小产生每个 Grundy 值。 

---

 ## 预加热

 Walsh-Hadamard 变换使异或卷积对角化。 

改造后：```python
freq[i] = pow(freq[i], K, MOD)
```计算$K$频率空间中的折叠异或卷积。 

逆变换恢复元组计数。`freq[0]`变为异或零位置的数量。
