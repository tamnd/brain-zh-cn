[项目欧拉问题 532](https://projecteuler.net/problem=532)

 ## 解决方案

 **答案：**`827306.56`设球体有半径$1$，让机器人最初位于纬度圈上$$x^2+y^2 = 0.999^2,$$所以他们的共同余度是$$\theta_0=\arcsin(0.999).$$如果有$n$机器人，相邻机器人之间的经度间隔是$$\alpha=\frac{2\pi}{n}.$$通过对称性，在整个运动过程中，机器人在不断缩小的纬度圈上保持等距分布。 

对于位于该位置的一个机器人$P$，追逐下一个机器人$Q$，瞬时速度是沿大圆测地线的单位切向量$P$到$Q$。 

标准球面几何计算给出了演化方程$$\frac{d\theta}{dt} = -\frac{\cos\theta\,\sin(\alpha/2)} {\sqrt{1-\sin^2(\alpha/2)\sin^2\theta}}.$$由于每个机器人都在快速移动$1$，一个机器人绘制的长度等于直到$\theta=0$：$$L_n = \int_0^{\theta_0} \frac{\sqrt{1-\sin^2(\alpha/2)\sin^2\theta}} {\sin(\alpha/2)\cos\theta} \,d\theta .$$我们现在计算最小的$n$这样$L_n>1000$。 

使用高精度数值积分：```python
from mpmath import mp

mp.dps = 50

theta0 = mp.asin(mp.mpf('0.999'))

def length_per_bot(n):
    k = mp.sin(mp.pi / n)

    f = lambda th: (
        mp.sqrt(1 - k*k * mp.sin(th)**2)
        / (k * mp.cos(th))
    )

    return mp.quad(f, [0, theta0])

n = 1
while True:
    n += 1
    L = length_per_bot(n)
    if L > 1000:
        break

total = n * L

print(n)
print(L)
print(total)
```这产生：

 -$n=827$- 每个机器人的长度$=1000.370689492285\ldots$- 总长度$=827306.5602101203\ldots$为了$n=826$，每个机器人的长度仅为$999.1610\ldots$， 所以$827$确实是最小的。 

因此，所需的总长度（四舍五入到小数点后两位）为：

 **答案：827306.56**
