[项目欧拉问题 217](https://projecteuler.net/problem=217)

 ## 解决方案

 **答案：**`6273134`让$$t(n)=2n^2-1$$糟糕 - 错误的问题背景。 

相反，我们需要 Project Euler 217 数量：$$T(n)=\sum_{\substack{0\le x<10^n\\ x\text{ balanced}}} x$$如果一个数字的第一个数字之和是**平衡的**$\lceil k/2\rceil$数字等于最后一位数字之和$\lceil k/2\rceil$数字。 

我们寻求$$T(47)\bmod 3^{15}.$$---

 # 1.数学分析

 ## 1.1 了解平衡条件

 假设一个数有$k$数字。 

---

 ### 偶数长度：$k=2m$将数字写为$$N = L\cdot 10^m + R$$在哪里：

-$L$是第一个$m$数字，
 -$R$是最后一个$m$数字。 

平衡条件为：$$\text{digitSum}(L)=\text{digitSum}(R).$$---

 ### 奇数长度：$k=2m+1$将数字写为$$N = L\cdot 10^{m+1} + c\cdot 10^m + R$$在哪里$c$是中间的数字。 

定义比较第一个$m+1$数字和最后一个$m+1$数字：$$\text{digitSum}(L)+c = c+\text{digitSum}(R).$$中间的数字取消，所以再次：$$\text{digitSum}(L)=\text{digitSum}(R).$$因此偶数和奇数长度都减少到相同的核心条件。 

---

 # 1.2 数字和的 DP

 定义：$$A(m,s)=\#\{\text{length-}m\text{ digit strings with digit sum }s\}$$允许前导零。 

还定义：$$B(m,s)=\sum (\text{all such }m\text{-digit numbers}).$$这些满足转换：$$A(m+1,s+d) += A(m,s)$$和$$B(m+1,s+d) += 10B(m,s)+dA(m,s).$$为什么？ 

追加数字$d$转换每个旧数字$x$进入$$10x+d.$$总结所有这些$x$:$$\sum (10x+d) = 10\sum x + d\cdot(\#\text{numbers}).$$---

 # 1.3 偶数长度贡献

 对于$2m$-数字平衡数：

 - 左半边$L$必须没有前导零，
 - 右半边$R$可能有前导零，
 - 两者的数字总和必须相等$s$。 

让：

-$C_L(s)$= 有效左半部分的数量，
 -$S_L(s)$= 有效左半部分的总和。 

那么总贡献就是$$\sum_s \left( S_L(s)\cdot 10^m \cdot A(m,s) + C_L(s)\cdot B(m,s) \right).$$第一项占高位数字的左半部分； 第二个占右半部分。 

---

 # 1.4 奇数长度贡献

 对于$2m+1$-数字平衡数：$$N=L\cdot10^{m+1}+c\cdot10^m+R.$$对于固定$(L,R)$, 总结$c=0,\dots,9$:$$\sum_c N = 10(L\cdot10^{m+1}+R) + 45\cdot10^m.$$所以：$$\sum_s \left[ 10\left( S_L(s)\cdot10^{m+1}\cdot A(m,s) + C_L(s)\cdot B(m,s) \right) + 45\cdot10^m\cdot C_L(s)\cdot A(m,s) \right].$$---

 # 2.Python实现```python
MOD = 3**15
N = 47

# Maximum half-length needed:
# floor(47/2) = 23, but we use 24 safely.
MAXM = 24
MAXS = 9 * MAXM

# A[m][s] = count of m-digit strings with digit sum s
# B[m][s] = sum of all such m-digit numbers
A = [[0] * (MAXS + 1) for _ in range(MAXM + 1)]
B = [[0] * (MAXS + 1) for _ in range(MAXM + 1)]

A[0][0] = 1

# Precompute powers of 10
pow10 = [1]
for _ in range(60):
    pow10.append(pow10[-1] * 10)

# Build DP tables
for m in range(MAXM):
    for s in range(9 * m + 1):

        count = A[m][s]
        total = B[m][s]

        if count == 0 and total == 0:
            continue

        for d in range(10):

            A[m + 1][s + d] += count

            # Appending digit d:
            # new_number = old_number * 10 + d
            B[m + 1][s + d] += total * 10 + count * d

def left_tables(m, s):
    """
    Count/sum of m-digit numbers with no leading zero
    and digit sum s.
    """

    count = 0
    total = 0

    for first in range(1, 10):

        if s - first < 0 or s - first > 9 * (m - 1):
            continue

        cnt = A[m - 1][s - first]

        # Numbers formed as:
        # first * 10^(m-1) + tail
        sm = B[m - 1][s - first] + cnt * first * pow10[m - 1]

        count += cnt
        total += sm

    return count, total

def balanced_sum_length(length):

    # One-digit case
    if length == 1:
        return 45

    # -------------------------------------------------
    # EVEN LENGTH = 2m
    # -------------------------------------------------
    if length % 2 == 0:

        m = length // 2
        ans = 0

        for s in range(9 * m + 1):

            left_count, left_sum = left_tables(m, s)

            ans += (
                left_sum * pow10[m] * A[m][s]
                + left_count * B[m][s]
            )

        return ans

    # -------------------------------------------------
    # ODD LENGTH = 2m+1
    # -------------------------------------------------
    else:

        m = length // 2
        ans = 0

        for s in range(9 * m + 1):

            left_count, left_sum = left_tables(m, s)

            pair_count = left_count * A[m][s]

            ans += (
                10 * (
                    left_sum * pow10[m + 1] * A[m][s]
                    + left_count * B[m][s]
                )
                + 45 * pow10[m] * pair_count
            )

        return ans

# Compute T(47)
answer = sum(
    balanced_sum_length(k)
    for k in range(1, N + 1)
) % MOD

print(answer)
```---

 # 3. 代码演练

 ## DP 构建

 我们通过附加数字来构建所有数字字符串$0\ldots9$。`A[m][s]`存储多少个长度的字符串`m`有数字和`s`。`B[m][s]`存储解释为整数的所有此类字符串的总和。 

---

 ##`left_tables(m, s)`这计算：

 - 有效左半部分的计数，
 - 有效左半部分的总和，

 限制是第一位非零。 

我们明确选择前导数字$1\ldots9$。 

---

 ##`balanced_sum_length(length)`单独处理：

 - 长度均匀，
 - 奇数长度。 

使用上面推导的公式。
