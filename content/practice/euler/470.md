[欧拉项目问题 470](https://projecteuler.net/problem=470)

 ## 解决方案

 **答案：**`147668794`令当前可见的骰子面集合为$V\subseteq \{1,\dots,d\}$， 和$|V|=k$。 

### 1.Ramvok分析

 对于固定模具状态$V$， 定义$H_t(V)$作为最多时的最佳预期**奖品**（成本前）$t$允许转弯。 

我们有：

 -$H_0(V)=0$-$H_1(V)=\frac1k\sum_{x\in V}x$- 为了$t\ge 1$,$$H_{t+1}(V) = \frac1k\sum_{x\in V}\max(x,H_t(V))$$因为看到roll后$x$，我们要么停下来采取$x$，或继续使用值$H_t(V)$。 

如果前期成本是$ct$，那么预期**利润**是$$R_t(V,c)=H_t(V)-ct$$和$$R(V,c)=\max_{t\ge0} R_t(V,c).$$为了$c=0$，最优策略是永远等待直到最大可见面出现，所以：$$R(V,0)=\max(V).$$为了$c>0$，边际改进$$H_{t+1}(V)-H_t(V)$$单调递减，所以我们迭代直到它低于$c$。 

检查示例：$$R(\{1,2,3,4\},0.2)=2.65$$与声明相符。 

---

 ### 2.超级Ramvok分析

 设状态为子集$V$可见的面孔。 

每场 Ramvok 游戏结束后，都会切换一个均匀随机的面（可见 ↔ 空白）。 如果所有面都变成空白，则该过程结束。 

让$S(V,c)$是从状态开始的最优预期未来利润$V$。 然后：$$S(\varnothing,c)=0$$并为$V\neq\varnothing$,$$S(V,c) = R(V,c) + \frac1d \sum_{i=1}^{d} S(V\triangle \{i\},c)$$在哪里$\triangle$表示切换面。 

根据超立方体行走的对称性，当以汉明权为条件时，相同大小的所有子集的可能性相同。 所以：$$S(d,c) = \sum_{k=1}^{d} N_{d,k}\, \overline{R}_{d,k}(c)$$在哪里：

-$N_{d,k}$= 预计体重访问次数-$k$在空集吸收之前的状态，
 -$\overline{R}_{d,k}(c)$= Ramvok 总体平均利润$k$- 的子集$\{1,\dots,d\}$。 

这$N_{d,k}$值来自权重的生死链：$$k \to k-1 \text{ with prob } \frac{k}{d}, \qquad k \to k+1 \text{ with prob } \frac{d-k}{d}.$$求解这个瞬态马尔可夫系统给出了预期的访问计数。 

例子验证正确：$$S(6,1)=208.3$$匹配问题陈述。 

### 3.Python实现```python
import math
import itertools
import numpy as np

def expected_visits(d):
    """
    Expected number of visits to each weight k=1..d
    before absorption at 0, starting from weight d.
    """
    A = np.zeros((d, d))

    for k in range(1, d + 1):
        i = k - 1
        A[i, i] = 1.0

        # Transition to k-1
        if k > 1:
            A[i, k - 2] -= k / d

        # Transition to k+1
        if k < d:
            A[i, k] -= (d - k) / d

    # Fundamental matrix row for starting state d
    N = np.linalg.inv(A)
    return N[d - 1]

def ramvok_profit(values, c):
    """
    Optimal expected profit for a single Ramvok game
    with visible faces 'values' and cost c.
    """
    values = tuple(sorted(values))

    # c = 0 -> wait forever for max value
    if c == 0:
        return values[-1]

    k = len(values)
    H = 0.0
    best = 0.0
    turns = 0

    while True:
        turns += 1

        # H_{t+1} = E[max(x, H_t)]
        new_H = sum(max(x, H) for x in values) / k

        profit = new_H - c * turns
        best = max(best, profit)

        marginal_gain = new_H - H

        # Further turns can no longer improve value
        if marginal_gain < c:
            break

        H = new_H

    return best

def super_ramvok(d, c):
    visits = expected_visits(d)

    total = 0.0

    for k in range(1, d + 1):
        subset_sum = 0.0

        for subset in itertools.combinations(range(1, d + 1), k):
            subset_sum += ramvok_profit(subset, c)

        avg_profit = subset_sum / math.comb(d, k)
        total += visits[k - 1] * avg_profit

    return total

def F(n):
    total = 0.0

    for d in range(4, n + 1):
        for c in range(n + 1):
            total += super_ramvok(d, c)

    return round(total)

print(super_ramvok(6, 1))  # 208.3
print(F(20))
```### 4.验证
