[欧拉项目问题 276](https://projecteuler.net/problem=276)

 ## 解决方案

 **答案：**`5777137137739632912`让$$T(N)=\#\{(a,b,c): a\le b\le c,\ a+b>c,\ a+b+c\le N\}$$是所有周长最多为整数的三角形的数量$N$，并让$$P(N)$$是 **原始** 的数量（即$\gcd(a,b,c)=1$）。 

我们想要$P(10^7)$。 

---

 ## 1.数学分析

 ### 步骤 1：计算所有整数三角形的周长$n$让$t(n)$是周长精确的整数三角形的数量$n$。 

一个经典的结果给出：$$t(n)=\operatorname{round}\!\left(\frac{n^2}{12}\right) -\left\lfloor \frac n4 \right\rfloor \left\lfloor \frac{n+2}{4}\right\rfloor.$$我们可以通过小例子来验证：

 -$n=3$： 仅有的$(1,1,1)$， 所以$t(3)=1$-$n=5$： 仅有的$(1,2,2)$， 所以$t(5)=1$-$n=6$:$(1,2,3)$三角不等式不成立，但是$(2,2,2)$,$(1,2,3)$无效的，$(1,1,4)$无效，所以只能$(2,2,2)$和$(1,2,3)$排除 ⇒$t(6)=1$公式匹配。 

定义累计计数：$$A(N)=\sum_{n\le N} t(n).$$自从$t(n)$是带有周期性修正的二次函数（周期 12），$A(N)$变为三次拟多项式。 写作$$N=12q+r,\qquad 0\le r<12,$$我们得到一个精确的$O(1)$公式为$A(N)$。 例如：$$A(12q)=6q^2(2q+1),$$对于其他 11 个残基类别也是如此。 

---

 ### 步骤 2：通过莫比乌斯反演得到原始三角形

 每个三角形$(a,b,c)$拥有独特的gcd$d$:$$(a,b,c)=d(a',b',c')$$和$(a',b',c')$原始。 

因此：$$A(N)=\sum_{d\le N} P\!\left(\left\lfloor \frac Nd\right\rfloor\right).$$这是除数卷积。 

应用莫比乌斯反演：$$P(N) = \sum_{d\le N} \mu(d)\, A\!\left(\left\lfloor \frac Nd\right\rfloor\right),$$在哪里$\mu$是莫比乌斯函数。 

所以任务减少为：

 1. 计算$\mu(d)$最多$10^7$使用线性筛。 
2. 计算 Mertens 前缀和$$M(n)=\sum_{k\le n}\mu(k).$$1. 将相等的值分组$\lfloor N/d\rfloor$:$$P(N) = \sum A(v)\, \bigl(M(r)-M(l-1)\bigr),$$在哪里$v=\lfloor N/l\rfloor$和$r=\lfloor N/v\rfloor$。 

这将总和减少为$O(\sqrt N)$。

 ## 2.Python实现```python
from array import array

N = 10_000_000

def cumulative_triangles(n):
    """
    A(n) = number of integer-sided triangles
    with perimeter <= n.
    Exact O(1) quasipolynomial formula.
    """
    q, r = divmod(n, 12)

    if r == 0:
        return 6 * q * q * (2 * q + 1)
    elif r == 1:
        return q * (12 * q * q + 9 * q + 2)
    elif r == 2:
        return 3 * q * (2 * q + 1) ** 2
    elif r == 3:
        return 12 * q**3 + 15 * q**2 + 6 * q + 1
    elif r == 4:
        return (2 * q + 1) * (6 * q**2 + 6 * q + 1)
    elif r == 5:
        return 12 * q**3 + 21 * q**2 + 12 * q + 2
    elif r == 6:
        return 3 * (q + 1) * (2 * q + 1) ** 2
    elif r == 7:
        return (q + 1) * (12 * q**2 + 15 * q + 5)
    elif r == 8:
        return 6 * (q + 1) ** 2 * (2 * q + 1)
    elif r == 9:
        return 3 * (q + 1) ** 2 * (4 * q + 3)
    elif r == 10:
        return (q + 1) * (12 * q**2 + 24 * q + 11)
    else:  # r == 11
        return 3 * (q + 1) ** 2 * (4 * q + 5)

# ----- Linear sieve for Möbius function -----

mu = array('b', [0]) * (N + 1)
lp = array('I', [0]) * (N + 1)
primes = array('I')

mu[1] = 1

for i in range(2, N + 1):
    if lp[i] == 0:
        lp[i] = i
        primes.append(i)
        mu[i] = -1

    li = lp[i]

    for p in primes:
        v = i * p
        if v > N or p > li:
            break

        lp[v] = p

        if p == li:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# ----- Prefix sums of Möbius -----

M = array('i', [0]) * (N + 1)

running = 0
for i in range(1, N + 1):
    running += mu[i]
    M[i] = running

# ----- Möbius inversion with floor-division grouping -----

answer = 0
l = 1

while l <= N:
    v = N // l
    r = N // v

    answer += cumulative_triangles(v) * (M[r] - M[l - 1])

    l = r + 1

print(answer)
```---

 ## 3. 代码演练

 ###`cumulative_triangles(n)`计算$$A(n)=\sum_{k\le n} t(k)$$在常数时间内使用精确的残基类公式模 12。 

这可以避免存储所有三角形计数$10^7$。 

---

 ### 线性筛

 我们计算莫比乌斯函数：$$\mu(n)= \begin{cases} 1 & n=1\\ (-1)^k & n \text{ squarefree with }k\text{ primes}\\ 0 & \text{otherwise} \end{cases}$$使用一个$O(N)$线性筛。 

---

 ### 前缀 Mertens 函数

 我们存储：$$M(n)=\sum_{k\le n}\mu(k)$$允许快速范围求和：$$\sum_{d=l}^r \mu(d)=M(r)-M(l-1).$$---

 ### 谐波分组技巧

 自从$$\left\lfloor \frac Nd\right\rfloor$$只需要$O(\sqrt N)$不同的值，我们处理恒定的间隔。 

这减少了最终总和$10^7$迭代到粗略的$2\sqrt N$。
