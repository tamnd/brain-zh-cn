[项目欧拉问题 180](https://projecteuler.net/problem=180)

 ## 解决方案

 **答案：**`285196020571078987`我们寻求所有有理三元组$(x,y,z)$和$$0<x,y,z<1,\qquad x,y,z\in \left\{\frac ab:0<a<b\le 35\right\},$$这样对于某个整数$n$,$$f_n(x,y,z)=0.$$关键是简化代数结构$f_n$。 

---

 # 1.数学分析

 我们被给予$$\begin{aligned} f_{1,n}&=x^{n+1}+y^{n+1}-z^{n+1},\\ f_{2,n}&=(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1}),\\ f_{3,n}&=xyz(x^{n-2}+y^{n-2}-z^{n-2}), \end{aligned}$$和$$f_n=f_{1,n}+f_{2,n}-f_{3,n}.$$我们首先考虑这个表达式。 

## 1.1 扩展$f_n$扩张：$$\begin{aligned} f_n &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1})\\ &\quad -xyz(x^{n-2}+y^{n-2}-z^{n-2}). \end{aligned}$$涉及权力的集团条款$x$：$$x^{n-1}(x^2+xy+xz-yz).$$但$$x^2+xy+xz-yz=(x+y)(x+z)-2yz.$$更干净的路线是直接检查$$f_n=(x+y-z)(x^n+y^n-z^n).$$的确，$$\begin{aligned} (x+y-z)(x^n+y^n-z^n) &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +xy^n+yx^n-xz^n-zx^n\\ &\quad +xz^n+zy^n-zx^n-zy^n\\ &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +xy(x^{n-1}+y^{n-1})\\ &\quad +xz(x^{n-1}-z^{n-1})\\ &\quad +yz(y^{n-1}-z^{n-1}), \end{aligned}$$重组后完全匹配。 

所以，$$\boxed{f_n(x,y,z)=(x+y-z)(x^n+y^n-z^n).}$$因此，黄金三元组满足

 1.$x+y=z$, 或
 2.$x^n+y^n=z^n$。 

对于某个整数$n$。 

---

 # 1.2 哪些指数重要？ 

因为$0<x,y,z<1$是有理数：

 - 对于$n=1$：$$x+y=z.$$- 为了$n=2$：$$x^2+y^2=z^2.$$有理毕达哥拉斯三元组出现。 
- 为了$n\ge 3$：

 根据费马大定理，不存在非零有理解。 
- 为了$n=0$：$$x^0+y^0=z^0 \implies 1+1=1,$$不可能的。 
- 为了$n=-1$：$$\frac1x+\frac1y=\frac1z.$$等价地，$$z=\frac{xy}{x+y}.$$- 为了$n=-2$：$$\frac1{x^2}+\frac1{y^2}=\frac1{z^2},$$另一种毕达哥拉斯类型的条件。 
- 为了$n\le -3$：

 重写给出$$\left(\frac1x\right)^m+\left(\frac1y\right)^m =\left(\frac1z\right)^m,$$FLT 又是不可能的。 

所以只存在四种情况：$$n\in\{1,2,-1,-2\}.$$---

 # 1.3 枚举所有有效的三元组

 让$$S=\left\{\frac ab:0<a<b\le 35,\ \gcd(a,b)=1\right\}.$$我们需要所有不同的价值观$$s=x+y+z$$来自满足以下之一的三元组：

 1.$x+y=z$2.$x^2+y^2=z^2$3.$1/x+1/y=1/z$4.$1/x^2+1/y^2=1/z^2$和$x,y,z\in S$。 

最后总结所有不同的$s$。 

---

 # 1.4 合理参数化

 这两个二次方程由有理毕达哥拉斯三元组参数化。 

如果$$a^2+b^2=c^2,$$然后$$(a,b,c)=k(m^2-n^2,2mn,m^2+n^2).$$因此：

 - 案例$n=2$：

 选择里面有理毕达哥拉斯三元组$(0,1)$。 
- 案件$n=-2$：

 这些三元组的倒数。 

计算是有限的并且足够小，可以对带有分母的 Farey 分数进行暴力破解$\le 35$。

 # 2.Python实现```python
from fractions import Fraction
from math import gcd, isqrt

K = 35

# ------------------------------------------------------------
# Generate all reduced fractions a/b with 0 < a < b <= K
# ------------------------------------------------------------

vals = set()

for b in range(2, K + 1):
    for a in range(1, b):
        if gcd(a, b) == 1:
            vals.add(Fraction(a, b))

vals = sorted(vals)

# ------------------------------------------------------------
# Collect all distinct sums s = x + y + z
# ------------------------------------------------------------

sums = set()

for x in vals:
    for y in vals:

        # ----------------------------------------------------
        # Case n = 1 : x + y = z
        # ----------------------------------------------------
        z = x + y
        if z in vals:
            sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = -1 : 1/x + 1/y = 1/z
        # z = xy / (x + y)
        # ----------------------------------------------------
        z = x * y / (x + y)
        if z in vals:
            sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = 2 : x^2 + y^2 = z^2
        # ----------------------------------------------------
        z2 = x * x + y * y

        num = z2.numerator
        den = z2.denominator

        sn = isqrt(num)
        sd = isqrt(den)

        if sn * sn == num and sd * sd == den:
            z = Fraction(sn, sd)
            if z in vals:
                sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = -2 :
        # 1/x^2 + 1/y^2 = 1/z^2
        # ----------------------------------------------------
        inv2 = Fraction(1, x * x) + Fraction(1, y * y)

        num = inv2.numerator
        den = inv2.denominator

        sn = isqrt(den)
        sd = isqrt(num)

        if sn * sn == den and sd * sd == num:
            z = Fraction(sn, sd)
            if z in vals:
                sums.add(x + y + z)

# ------------------------------------------------------------
# Sum all distinct s-values
# ------------------------------------------------------------

total = sum(sums, Fraction(0, 1))

print(total)
print(total.numerator + total.denominator)
```---
