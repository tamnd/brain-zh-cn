[欧拉项目 407 问题](https://projecteuler.net/problem=407)

 ## 解决方案

 **答案：**`39782849136421`对于一个整数$a$, 一致性$$a^2 \equiv a \pmod n$$方法$$a(a-1)\equiv 0 \pmod n.$$关键的观察是$a$和$a-1$是互质的，所以每个素数幂因数$n$必须除掉其中的**恰好一个**。 

---

 # 1.数学分析

 我们寻求$$M(n)=\max\{a<n : a^2\equiv a \pmod n\}.$$我们必须计算$$\sum_{n=1}^{10^7} M(n).$$---

 ## 步骤 1 — 所有解决方案的结构

 让$$n=\prod_{i=1}^k p_i^{e_i}.$$因为$$a(a-1)\equiv 0 \pmod{p_i^{e_i}},$$和$\gcd(a,a-1)=1$，对于每个素数幂我们必须有：$$a\equiv 0 \pmod{p_i^{e_i}} \quad\text{or}\quad a\equiv 1 \pmod{p_i^{e_i}}.$$因此，每个解决方案都对应于独立地为每个主要功率因数选择，$0$或者$1$。 

By the Chinese Remainder Theorem, there are exactly$$2^{\omega(n)}$$解决方案，其中$\omega(n)$是不同质因数的数量。 

---

 ## 步骤 2 — 用互质因子重写

 划分素数幂$n$分为两个互质部分：$$n = uv,\qquad \gcd(u,v)=1.$$那么对应的幂等满足$$a\equiv 0\pmod u, \qquad a\equiv 1\pmod v.$$写$a=uk$。 然后$$uk\equiv 1\pmod v.$$所以$$k\equiv u^{-1}\pmod v.$$因此，唯一的解模$n$是$$a=u\cdot u^{-1}\pmod v.$$每个幂等都是这样产生的。 

所以$$M(n)=\max_{uv=n,\ \gcd(u,v)=1} \left(u\cdot u^{-1}\pmod v\right).$$---

 ## 步骤 3 — 高效计算

 对每个问题进行强力分解$n\le10^7$太慢了。 

相反：

 1. 构建最小素因子筛。 
2. 恢复每个不同的质因数$n$。 
3. 生成不同素数幂的所有子集。 
4. 对于每个互质分裂$n=uv$:

 - 计算模逆$u^{-1}\pmod v$,
 - 构造幂等，
 - 最大化。 

因为$10^7$最多有 8 个不同的质因数，子集枚举很小。 

总复杂度本质上是线性筛尺度的。

 # 2.Python实现```python
from math import prod

LIMIT = 10_000_000

# ---------------------------------------------------------
# Smallest prime factor sieve
# ---------------------------------------------------------
spf = list(range(LIMIT + 1))

for i in range(2, int(LIMIT ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            if spf[j] == j:
                spf[j] = i

# ---------------------------------------------------------
# Extended Euclidean algorithm
# ---------------------------------------------------------
def invmod(a, m):
    """Return inverse of a modulo m."""
    x0, x1 = 1, 0
    b = m

    while b:
        q = a // b
        a, b = b, a % b
        x0, x1 = x1, x0 - q * x1

    return x0 % m

# ---------------------------------------------------------
# Factorization into prime powers
# Example:
#   12 -> [4, 3]
#   72 -> [8, 9]
# ---------------------------------------------------------
def prime_powers(n):
    res = []

    while n > 1:
        p = spf[n]
        pp = 1

        while n % p == 0:
            n //= p
            pp *= p

        res.append(pp)

    return res

# ---------------------------------------------------------
# Compute M(n)
# ---------------------------------------------------------
def M(n):
    if n == 1:
        return 0

    pp = prime_powers(n)
    k = len(pp)

    best = 1

    # Enumerate all subset products u
    for mask in range(1 << k):
        u = 1

        for i in range(k):
            if mask & (1 << i):
                u *= pp[i]

        v = n // u

        # trivial solutions 0 and 1
        if v == 1 or u == 1:
            continue

        # Solve:
        #   a ≡ 0 (mod u)
        #   a ≡ 1 (mod v)
        inv = invmod(u % v, v)

        a = u * inv

        if a > best:
            best = a

    return best

# ---------------------------------------------------------
# Main summation
# ---------------------------------------------------------
ans = 0

for n in range(1, LIMIT + 1):
    ans += M(n)

print(ans)
```---

 # 3. 代码演练

 ## 筛子```python
spf = list(range(LIMIT + 1))
```最初，每个数字都被假定为素数。 

筛子满了`spf[n]`具有最小的质数除法$n$。 

这允许非常快速的因式分解。

 ##`prime_powers(n)`例子：$$72 = 2^3\cdot 3^2$$回报```python
[8, 9]
```因为 CRT 自然地与素数幂一起工作。

 ## 枚举 CRT 选择

 每个素数幂可以属于：

 - 因子除法$a$,
 - 或除以因数$a-1$。 

所以我们枚举所有子集产品$u$。 

然后：$$v = n/u.$$自从$u$和$v$是互质的，我们解决$$a \equiv 0 \pmod u, \qquad a \equiv 1 \pmod v.$$写作$a=uk$:$$uk \equiv 1 \pmod v$$所以$$k = u^{-1}\pmod v.$$因此```python
a = u * invmod(u % v, v)
```这是 CRT 解决方案。

 # 4. 小例子验证

 对于$n=6$:

 主要权力是：$$6=2\cdot3.$$可能的 CRT 选择：

 |$a \bmod 2$|$a \bmod 3$| 解决方案 |
 | --- | --- | --- |
 | 0 | 0 | 0 |
 | 1 | 1 | 1 |
 | 0 | 1 | 4 |
 | 1 | 0 | 3 |

 最大的是：$$M(6)=4.$$与声明相符。

 # 5.最终验证

 -$M(p)=1$对于素数$p$，因为只有$0,1$模素数幂等。 
- 具有多个不同质因数的复合数通常具有接近于的大的非平凡幂等性$n$。 
- 因此总和应约为$10^7 \times 10^7 = 10^{14}$，它与计算结果的大小相匹配。 

计算得出：$$\sum_{n=1}^{10^7} M(n) = 39782849136421.$$**答案：39782849136421**
