[项目欧拉问题 203](https://projecteuler.net/problem=203)

 ## 解决方案

 **答案：**`34029210557338`关键任务是计算行中出现的所有**不同的无平方二项式系数**$0$通过$50$帕斯卡三角形，然后将它们相加。 

如果没有素数平方能整除一个数字，那么它就是**无平方**。 

示例：

 -$6 = 2 \cdot 3$是无平方的。 
-$12 = 2^2 \cdot 3$不是。 
-$20 = 2^2 \cdot 5$不是。 

该问题明确提供了一个有效的暴力程序。 我们将准确分析它为什么起作用以及它产生什么结果。 

---

 # 数学分析

 帕斯卡三角形包含条目$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$对于行$n = 0,1,2,\dots$。 

我们需要：

 1. 出现在其中的每个不同值$$\binom{n}{k}, \quad 0 \le n \le 50$$2. 仅保留那些无正方形的。 
3. 对它们求和。 

---

 ## Squarefree 测试

 一个数字$m$是无平方的当且仅当没有**整数$d \ge 2$这样$$d^2 \mid m$$提供的函数直接检查这一点：```python
def is_squarefree(n):
    if n <= 1: return n == 1
    d = 2
    while d * d <= n:
        if n % (d*d) == 0: return False
        d += 1
    return True
```这是有效的，因为：

 - 如果有任何平方能整除$n$,
 - 然后是一些正方形$d^2$和$d \le \sqrt n$划分它。 

所以检查所有$d$最多$\sqrt n$就足够了。

 # Python 实现

 该问题明确要求我们运行以下代码：```python
from math import comb, isqrt

def is_squarefree(n):
    if n <= 1:
        return n == 1

    d = 2
    while d * d <= n:
        if n % (d * d) == 0:
            return False
        d += 1

    return True

seen = set()

for n in range(51):
    for k in range(n + 1):
        c = comb(n, k)

        if c not in seen and is_squarefree(c):
            seen.add(c)

print(sum(seen))
```---
