[欧拉项目问题 346](https://projecteuler.net/problem=346)

 ## 解决方案

 **答案：**`336108797689259276`## 1.数学分析

 基地的**回报**$b>1$是以下形式的数字$$111\ldots111_b$$仅有数字$1$的。 

如果重发有$k$数字，那么它的值就是几何和$$1+b+b^2+\cdots+b^{k-1} = \frac{b^k-1}{b-1}.$$我们被要求提供在**至少两个不同基地**重新部署的数字。 

### 关键观察

 每个整数$n>2$自动重新计算长度$2$:$$n = 11_{n-1}.$$的确，$$11_{n-1} = (n-1)+1=n.$$因此，要使一个数字成为**强重单位**，它也具有**至少 3 位**的重单位表示就足够了。 

因此我们只需要生成以下形式的数字$$1+b+b^2+\cdots+b^{k-1}, \qquad k\ge 3,$$以下$10^{12}$，并取所有这些值的并集（加上$1$，该问题明确被视为强问题）。 

---

 ### 限制搜索

 我们需要$$1+b+b^2 < 10^{12}$$对于最小允许长度$k=3$。 

自从$$b^2 < 10^{12},$$我们只需要$$b \le \sqrt{10^{12}} = 10^6.$$对于每个基地$b$，我们反复延长reunit：$$1+b+b^2,\; 1+b+b^2+b^3,\; \ldots$$直到超过$10^{12}$。 

由于相同的数字可能来自不同的基数，因此我们将结果存储在**集合**中。 

---

 ## 2.Python实现```python
LIMIT = 10**12

# 1 is explicitly counted as a strong repunit
strong_repunits = {1}

# Maximum base comes from the k=3 case: 1 + b + b^2 < LIMIT
max_base = int(LIMIT**0.5)

for b in range(2, max_base + 1):
    # Start with repunit length 3: 1 + b + b^2
    value = 1 + b + b * b
    power = b * b

    while value < LIMIT:
        strong_repunits.add(value)

        # Add next power of b to extend repunit length
        power *= b
        value += power

# Compute final sum
answer = sum(strong_repunits)

print(answer)
```---

问题很重要$1$，所以我们立即将其包含在内。

 ### 最大基数```python
max_base = int(LIMIT**0.5)
```最短的非平凡重聚具有长度$3$:$$1+b+b^2.$$所以$b^2 < 10^{12}$, 给予$b \le 10^6$。 

---

 ### 生成重播```python
for b in range(2, max_base + 1):
```尝试一切可能的基础。 

我们从```python
value = 1 + b + b * b
power = b * b
```对应于 3 位重复单位：$$111_b = 1+b+b^2.$$然后反复扩展：```python
power *= b
value += power
```这会产生$$1111_b,\;11111_b,\ldots$$直至超过限制。 

---

 ### 自动删除重复项```python
strong_repunits.add(value)
```有些数字出现在多个碱基中，例如$$31 = 11111_2 = 111_5.$$该集合确保我们只计算每个数字一次。
