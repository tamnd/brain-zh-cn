[项目欧拉问题 500](https://projecteuler.net/problem=500)

 ## 解决方案

 **答案：**`35407281`让$d(n)$表示正因数的数量$n$。 

该问题要求**最小**整数$N$这样$$d(N)=2^{500500}.$$我们必须计算$N \bmod 500500507$。 

---

 # 1.数学分析

 如果$$N=\prod_{i=1}^k p_i^{a_i},$$那么除数计数公式给出$$d(N)=\prod_{i=1}^k (a_i+1).$$我们希望它等于 2 的纯幂：$$\prod (a_i+1)=2^{500500}.$$因此每一个因素$a_i+1$本身必须是二的幂：$$a_i = 2^{b_i}-1.$$所以指数必须是以下形式$$1,3,7,15,31,\dots$$和$$\sum b_i = 500500.$$因此$$N=\prod p_i^{\,2^{b_i}-1}.$$问题变成：

 > 我们如何分配“预算”$500500$素数之间要最小化$N$？ 

---

 ## 关键的贪婪洞察力

 假设我们当前使用指数块$b$处于黄金时期$p$。 

增加$b$经过$1$改变指数$$2^b-1 \quad\to\quad 2^{b+1}-1.$$所以指数正好增加$2^b$。 

那会成倍增加$N$经过$$p^{2^b}.$$因此，除数指数预算的每一个额外单位都会花费一个乘法因子：$$p^{2^b}.$$尽量减少$N$，在每一步我们都应该选择**最小的可用乘数**。 

---

 # 重新制定

 最初，每个素数可以贡献一个因子$2$通过与指数一起出现来计算除数$1$。 

成本乘以$p$。 

如果我们稍后升级指数$$1 \to 3,$$我们乘以$p^2$。 

然后$$3 \to 7$$成本乘以$p^4$等

 所以候选人的成本是：$$2,3,5,7,11,\dots$$（首次亮相）

 然后$$2^2,3^2,5^2,\dots$$然后$$2^4,3^4,\dots$$等等。 

我们必须准确选择$500500$这样的成本，总是采取最小的可用下一个选择。 

这是一个经典的优先级队列/堆进程。 

---

 # 为什么贪心策略是正确的

 假设有两个选择：

 - 乘以$a$,
 - 乘以$b$，

和$a<b$。 

由于所有未来乘数都是独立且正的，因此选择$a$首先总是产生比选择更小的总产品$b$第一的。 

因此，重复采用最小的可用乘数是全局最优的。 

---

 # 2.高效算法

 我们维护一个最小堆，其中包含每个素数的下一个可用乘数。 

对于素数$p$：

 - 第一个乘数是$p$,
 - 服用后$p^{2^k}$，下一个乘数变为$$p^{2^{k+1}}=(p^{2^k})^2.$$所以每次我们弹出值$x$，我们向后推$$x^2.$$但我们只需要堆排序的值，而不是精确的大整数。 

尽管如此，Python 大整数可以很好地处理这个问题，因为堆大小仅约为$500500$。 

我们还保持答案模$500500507$。 

---

 # 3.Python实现```python
import heapq

MOD = 500500507
TARGET = 500500

# ------------------------------------------------------------
# Generate enough primes using a sieve
# ------------------------------------------------------------

# We need roughly the first 500500 primes.
# The 500500th prime is below 8,000,000.
LIMIT = 8000000

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, int(LIMIT ** 0.5) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start: LIMIT + 1: step] = b"\x00" * (
            (LIMIT - start) // step + 1
        )

primes = [i for i, is_prime in enumerate(sieve) if is_prime]

# ------------------------------------------------------------
# Greedy heap process
# ------------------------------------------------------------

heap = []

# Initially each prime contributes multiplier p
for p in primes[:TARGET]:
    heapq.heappush(heap, (p, p))

answer = 1

for _ in range(TARGET):
    value, prime = heapq.heappop(heap)

    # Multiply into answer modulo MOD
    answer = (answer * (value % MOD)) % MOD

    # Next upgrade cost for this prime:
    # p^(2^k) -> p^(2^(k+1)) by squaring
    next_value = value * value

    heapq.heappush(heap, (next_value, prime))

print(answer)
```---

 # 4. 代码演练

 ## 素数生成

 我们用埃拉托斯特尼筛法生成足够的素数。```python
LIMIT = 8000000
```这安全地超过了$500500$-th素数。 

---

 ## 堆初始化```python
heapq.heappush(heap, (p, p))
```每个堆条目存储：

 - 当前乘数，
 - 底层素数。 

最初的乘数很简单$p$。 

---

 ## 主循环

 我们准确地重复$500500$次，因为每个选定的乘数贡献一个因子$2$到除数计数。```python
value, prime = heapq.heappop(heap)
```取最小的可用乘数。 

将其乘以答案模$500500507$。 

然后推送下一次升级：```python
next_value = value * value
```因为$$p^{2^k} \mapsto p^{2^{k+1}}.$$---

 # 5. 小例子验证

 问题指出：

 - 最小的数字$16=2^4$除数是$120$。 

让我们模拟一下：

 Available multipliers initially:$$2,3,5,7,\dots$$取 4 个最小的选择：

 1.$2$2.$3$3.$2^2=4$4.$5$产品：$$2 \cdot 3 \cdot 4 \cdot 5 = 120.$$指数变为：$$2^3 \cdot 3^1 \cdot 5^1,$$其除数计数为$$(3+1)(1+1)(1+1)=16.$$正确的。 

---

 # 6.最终验证

 - 我们准确选择$500500$乘法升级，因此除数计数恰好是$2^{500500}$。 
- 贪婪的选择保证了最小性。 
- 模乘法使计算变得可行。 
- 这是问题的标准最优构造。 

运行该算法给出：$$35407281$$---
