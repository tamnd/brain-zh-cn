[欧拉项目问题 253](https://projecteuler.net/problem=253)

 ## 解决方案

 **答案：**`11.492847`让毛毛虫有$n$排列在位置上的碎片$1,2,\dots,n$。 

我们将这些碎片按照统一的随机顺序放置。 

在每个阶段，占据的位置形成几个连续的块（“段”）。 

我们感兴趣的是$$M = \max(\text{number of segments seen during the process}).$$为了$n=40$，我们必须计算$$\mathbb E[M].$$---

 # 1.数学分析

 ## 细分市场动态

 假设我们将一块放置在位置$x$。 

只有三种可能：

 - 两个邻居都没有被占用$\Rightarrow$创建一个新段$\Rightarrow \Delta S = +1$- 正好有一个邻居被占用$\Rightarrow$现有段已扩展$\Rightarrow \Delta S = 0$- 两个邻居都被占用$\Rightarrow$两个段合并$\Rightarrow \Delta S = -1$因此，该过程完全由空间隙的模式决定。 

---

 ## 间隙表示

 我们不存储占用的位置，而是存储_空间隙_。 

间隙表示为$$(g,L,R)$$在哪里：

-$g$= 间隙中的空单元格数量
 -$L \in \{0,1\}$: 左边界被占用了吗？ 
-$R \in \{0,1\}$: 右边界被占用了吗？ 

最初：$$[(40,0,0)]$$（一个完全空的间隔）。 

如果我们将一块放入间隙内，间隙就会分成两个较小的间隙。 

这给出了一个干净的递归 DP。 

---

 ## 概率DP

 定义$$F(state,s,m)$$作为从以下位置开始的概率：

 - 当前间隙配置 =`state`- 当前段数=$s$我们永远不会超过$m$未来的细分市场。 

然后：

 - 如果$s>m$， 返回$0$- 如果没有剩余间隙，则返回$1$否则对所有可能的展示位置进行平均。 

最后，$$P(M \le m)=F(\text{initial},0,m).$$使用身份$$\mathbb E[M] = \sum_{k\ge1} P(M\ge k) = \sum_{k\ge1} \left(1-P(M\le k-1)\right),$$我们准确地得到了期望。 

---

 # 2.Python实现```python
from functools import cache
from collections import defaultdict

N = 40

@cache
def transitions(state, segs):
    """
    Generate all transitions from a given state.

    state = tuple of gaps (g, L, R)
    segs  = current number of segments
    """

    total_empty = sum(g for g, _, _ in state)

    out = defaultdict(int)

    for idx, (g, L, R) in enumerate(state):

        others = list(state[:idx] + state[idx + 1:])

        for pos in range(1, g + 1):

            # Number of occupied neighbours
            c = 0
            if pos == 1 and L:
                c += 1
            if pos == g and R:
                c += 1

            # Segment count change
            if c == 0:
                new_segs = segs + 1
            elif c == 1:
                new_segs = segs
            else:
                new_segs = segs - 1

            new_state = others[:]

            left_len = pos - 1
            right_len = g - pos

            if left_len > 0:
                new_state.append((left_len, L, 1))

            if right_len > 0:
                new_state.append((right_len, 1, R))

            new_state = tuple(sorted(new_state))

            out[(new_state, new_segs)] += 1

    return total_empty, list(out.items())

def probability_max_at_most(m):

    @cache
    def F(state, segs):

        if segs > m:
            return 0.0

        if not state:
            return 1.0

        total_empty, trans = transitions(state, segs)

        ans = 0.0

        for (new_state, new_segs), count in trans:
            ans += count * F(new_state, new_segs)

        return ans / total_empty

    return F(((N, 0, 0),), 0)

# Compute expectation
expectation = 0.0

for k in range(1, N + 1):
    p_le = probability_max_at_most(k - 1)
    expectation += 1.0 - p_le

print(f"{expectation:.6f}")
```---

 # 3. 代码演练

 ##`transitions(state, segs)`对于每个间隙中的每个空位置：

 - 确定它接触了多少个被占用的邻居
 - 更新段计数
 - 将间隙分成左/右子间隙
 - 聚合相同的结果状态

 这大大减少了状态空间。 

---

 ##`F(state, segs)`递归记忆概率：$$F = \Pr(\text{never exceed } m)$$基本案例：

 - 已经超过$m$

$\Rightarrow 0$- 没有剩余的空单元格$\Rightarrow 1$否则对所有可能的下一个展示位置进行平均。 

---

 ## 最终期望

 我们使用$$\mathbb E[M] = \sum_{k=1}^{N} \left(1-P(M\le k-1)\right).$$---
