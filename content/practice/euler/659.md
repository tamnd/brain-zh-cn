[欧拉项目问题 659](https://projecteuler.net/problem=659)

 ## 解决方案

 **答案：**`238518915714422000`让$$a_n=n^2+k^2.$$我们想要**最大的质数**除**两个连续项**$a_n$和$a_{n+1}$。 

如果一个素数$p$将两者相除，然后$$n^2+k^2 \equiv 0 \pmod p$$和$$(n+1)^2+k^2 \equiv 0 \pmod p.$$减去得到$$(n+1)^2-n^2 = 2n+1 \equiv 0 \pmod p.$$所以$$2n\equiv -1 \pmod p.$$平方：$$4n^2 \equiv 1 \pmod p.$$从$n^2+k^2\equiv 0$,$$4n^2+4k^2\equiv 0 \pmod p.$$代替$4n^2\equiv 1$：$$1+4k^2\equiv 0 \pmod p.$$因此每个这样的素因数都满足$$p \mid (4k^2+1).$$反之，任何素因数$p\mid (4k^2+1)$允许解决方案$n$通过$$2n+1\equiv 0\pmod p,$$所以问题减少为：

 >$P(k)$是**最大的素因数**$4k^2+1$。 

因此我们需要$$\sum_{k=1}^{10^7} P(k) \pmod{10^{18}}.$$筛子的工作效率很高：

 - 初始化$f[k]=4k^2+1$。 
- 跟踪每个的最大质因数$k$。 
- 如果是素数$p\mid 4k^2+1$，然后通过模根：$$p \mid 4(tp\pm k)^2+1,$$所以沿着进度进行筛选$tp\pm k$。 

该实现重现了已发布的检查：

 -$\sum_{k\le 10^3}P(k)=299015732$-$\sum_{k\le 10^4}P(k)=223215627804$-$\sum_{k\le 10^5}P(k)=178688812032788$运行完整计算$10^7$给出最后 18 位数字：

 **答案：238518915714422000**
