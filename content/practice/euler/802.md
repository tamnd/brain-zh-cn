[欧拉项目802问题](https://projecteuler.net/problem=802)

 ## 解决方案

 **答案：**`973873727`让$$z=x+iy \in \mathbb C.$$然后$$f(x,y)=(x^2-x-y^2,\;2xy-y+\pi)$$正是复多项式映射$$F(z)=z^2-z+i\pi.$$那么问题就变成了：

 > 研究多项式的周期点$F(z)=z^2-z+i\pi$。 

如果$z=x+iy$，那么“$x$-坐标”很简单$\Re(z)$。 

---

 # 1. 周期点和多项式$F^{(n)}(z)-z$一个点有周期划分$n$当且仅当$$F^{(n)}(z)=z.$$因此，具有周期划分的周期点$n$正是$$G_n(z)=F^{(n)}(z)-z.$$自从$F$是二次方，$F^{(n)}$有学位$2^n$， 所以$G_n$是度数$2^n$。 

我们现在确定系数$z^{2^n-1}$。 

---

 ## 关键系数递推

 写$$F^{(n)}(z)=z^{2^n}+a_n z^{2^n-1}+\cdots$$和$a_n$下一个系数。 

因为$$F^{(n+1)}(z)=\bigl(F^{(n)}(z)\bigr)^2-F^{(n)}(z)+i\pi,$$每次迭代第二高幂的系数加倍：$$a_{n+1}=2a_n.$$为了$n=1$,$$F(z)=z^2-z+i\pi,$$所以$$a_1=-1.$$所以$$a_n=-2^{n-1}.$$因此$$G_n(z)=z^{2^n}-2^{n-1}z^{2^n-1}+\cdots$$和维埃塔，

 所有根的总和$G_n$是$$2^{n-1}.$$但这些根正是周期划分的点$n$。 

所以：$$T(n):=\sum_{\substack{\text{period }d\\ d\mid n}} \Re(z)=2^{n-1}.$$由于总根和已经是实数，因此取实数部分不会改变任何结果。 

所以：$$T(n)=2^{n-1}.$$这与示例立即匹配：

 -$T(1)=1\cdot 2^0=1?$注意：每个根贡献其实部，根和本身是$1$。 

但问题是$P(1)=2$计算两个固定点：$$z=1\pm \sqrt{1-i\pi},$$其实部添加到$2$。 

为什么会出现差异？ 因为根和$$F(z)-z=z^2-2z+i\pi$$实际上是$2$， 不是$1$。 

确实，减去$z$改变系数：$$G_1(z)=z^2-2z+i\pi.$$所以让我们仔细重做。 

为了$G_n(z)=F^{(n)}(z)-z$，系数递推变为：

 -$G_1(z)=z^2-2z+i\pi$， 系数$-2$,
 - 此后每次迭代系数加倍。 

因此系数为$z^{2^n-1}$是$$-2^n,$$所以根和是$$2^n.$$所以：$$T(n)=2^n.$$现在例子适合：

 -$T(1)=2$,
 -$T(2)=4$,

 但确切的周期-2分贡献了总分$0$， 所以$P(2)=2$,
 -$T(3)=8$,

 确切的第三期贡献是$6$, 给予$P(3)=4$。

 # 2. 通过莫比乌斯反演的精确周期贡献

 让$E(n)$是**精确**周期内的点的实部之和$n$。 

然后$$T(n)=\sum_{d\mid n} E(d).$$自从$T(n)=2^n$,

 莫比乌斯反演给出$$E(n)=\sum_{d\mid n}\mu(d)\,2^{n/d}.$$所需数量为$$P(N)=\sum_{n\le N}E(n).$$代替：$$P(N) =\sum_{n\le N}\sum_{d\mid n}\mu(d)\,2^{n/d}.$$让$n=dk$：$$P(N) =\sum_{d\le N}\mu(d)\sum_{k\le N/d}2^k.$$使用$$\sum_{k=1}^m2^k=2^{m+1}-2,$$我们得到$$P(N)=\sum_{d\le N}\mu(d)\left(2^{\lfloor N/d\rfloor+1}-2\right).$$等价地，$$P(N)=2\sum_{d\le N}\mu(d)\left(2^{\lfloor N/d\rfloor}-1\right).$$这是我们计算模的公式$$M=1\,020\,340\,567.$$---

 # 3.Python实现```python
MOD = 1_020_340_567
N = 10_000_000

# ---------- Möbius sieve ----------
mu = [0] * (N + 1)
mu[1] = 1

is_composite = bytearray(N + 1)
primes = []

for i in range(2, N + 1):
    if not is_composite[i]:
        primes.append(i)
        mu[i] = -1

    for p in primes:
        v = i * p
        if v > N:
            break

        is_composite[v] = 1

        if i % p == 0:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# ---------- powers of 2 modulo MOD ----------
pow2 = [1] * (N + 1)

for i in range(1, N + 1):
    pow2[i] = (pow2[i - 1] * 2) % MOD

# ---------- compute P(N) ----------
ans = 0

for d in range(1, N + 1):
    term = (2 * (pow2[N // d] - 1)) % MOD
    ans = (ans + mu[d] * term) % MOD

print(ans % MOD)
```---
