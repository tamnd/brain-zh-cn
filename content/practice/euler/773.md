[欧拉项目 773 问题](https://projecteuler.net/problem=773)

 ## 解决方案

 **答案：**`556206950`让$$S_k=\{2,5,p_1,p_2,\dots,p_k\},$$在哪里$p_i$是第一个$k$素数结尾为$7$，并定义$$M=\prod_{i=1}^k p_i,\qquad N_k=10M.$$一个$k$-Ruff 数是不能被 的任何元素整除的数$S_k$。 

我们寻求$$F(k)=\sum_{\substack{0\le n<N_k\\ n\equiv 7\pmod{10}\\ \gcd(n,M)=1}} n.$$问题给出$F(3)=76101452$。 

---

 # 1.数学分析

 每个以以下结尾的数字$7$可以唯一地写为$$n=10a+7,\qquad 0\le a<M.$$由于这些数字自动不能被整除$2$或者$5$，唯一的限制是：$$\gcd(n,M)=1.$$因此：$$F(k)=\sum_{\substack{0\le a<M\\ \gcd(10a+7,M)=1}} (10a+7).$$我们现在对素因数使用包含-排除$M$。 

---

 ## 步骤 1：以下所有以 7 结尾的数字的总和$10M$这些都是$$7,17,27,\dots,10M-3.$$正好有$M$项，所以$$U = \frac{M\bigl(7+(10M-3)\bigr)}2 = \frac{M(10M+4)}2 =5M^2+2M.$$---

 ## 步骤 2：可被除数整除的数字$d\mid M$对于无方形$d\mid M$， 定义$$A_d=\{n<10M : n\equiv 7\pmod{10},\ d\mid n\}.$$因为每一个素因数$M$是$7\bmod 10$，

- 如果$d\equiv 1\pmod{10}$， 然后$n=d(10t+7)$，
- 如果$d\equiv 7\pmod{10}$， 然后$n=d(10t+1)$。 

让$$\varepsilon(d)= \begin{cases} 7,& d\equiv1\pmod{10},\\ 1,& d\equiv7\pmod{10}. \end{cases}$$然后里面的数字$A_d$是$$d(\varepsilon(d)+10t), \qquad t=0,1,\dots,\frac{M}{d}-1.$$让$c=M/d$。 他们的总和是$$\sum_{n\in A_d} n = d\sum_{t=0}^{c-1}(\varepsilon(d)+10t).$$计算：$$= d\left(c\varepsilon(d)+10\frac{c(c-1)}2\right)$$

$$= M\varepsilon(d)+5M\left(\frac{M}{d}-1\right)$$

$$= \frac{5M^2}{d}+M(\varepsilon(d)-5).$$---

 ## 步骤 3：包含-排除

 自从$M$是无平方的，$$F(k) = \sum_{d\mid M}\mu(d) \left( \frac{5M^2}{d}+M(\varepsilon(d)-5) \right).$$分成两个总和：$$F(k) = 5M^2\sum_{d\mid M}\frac{\mu(d)}d + M\sum_{d\mid M}\mu(d)(\varepsilon(d)-5).$$---

 ## 步骤 4：计算第一个总和

 对于无方形$M$,$$\sum_{d\mid M}\frac{\mu(d)}d = \prod_{p\mid M}\left(1-\frac1p\right) = \frac{\varphi(M)}M.$$因此$$5M^2\sum_{d\mid M}\frac{\mu(d)}d = 5M\varphi(M).$$---

 ## 步骤 5：计算第二个总和

 如果$d$有偶数个素因数，那么$$d\equiv1\pmod{10}, \qquad \varepsilon(d)-5=2, \qquad \mu(d)=+1.$$贡献：$+2$。 

如果$d$有奇数个质因数，则$$d\equiv7\pmod{10}, \qquad \varepsilon(d)-5=-4, \qquad \mu(d)=-1.$$贡献：$+4$。 

有$2^{k-1}$偶校验因数和$2^{k-1}$奇偶校验因数，所以$$\sum_{d\mid M}\mu(d)(\varepsilon(d)-5) = 2\cdot2^{k-1}+4\cdot2^{k-1} = 3\cdot2^k.$$所以：$$\boxed{ F(k)=M\left(5\varphi(M)+3\cdot2^k\right) }$$和$$M=\prod_{i=1}^k p_i, \qquad \varphi(M)=\prod_{i=1}^k (p_i-1).$$---

 # 2.Python实现```python
from sympy import primerange

MOD = 1_000_000_007

# First 97 primes ending in 7
primes_7 = [p for p in primerange(1, 100000) if p % 10 == 7][:97]

# Compute:
# M = product of primes
# phi(M) = product of (p - 1)
M = 1
phi = 1

for p in primes_7:
    M = (M * p) % MOD
    phi = (phi * (p - 1)) % MOD

# F(k) = M * (5*phi(M) + 3*2^k)
k = 97

answer = M * (5 * phi + 3 * pow(2, k, MOD)) % MOD
answer %= MOD

print(answer)
```---

 # 3. 代码演练

 ### 生成素数```python
primes_7 = [p for p in primerange(1, 100000) if p % 10 == 7][:97]
```这收集了前 97 个以 7 结尾的素数。 

---

 ### 计算$M$

```python
M = (M * p) % MOD
```这计算$$M=\prod p_i \pmod{10^9+7}.$$---

 ### 计算欧拉的 toient

 因为$M$是无平方的，$$\varphi(M)=\prod (p_i-1).$$所以：```python
phi = (phi * (p - 1)) % MOD
```---

 ### 应用封闭公式```python
answer = M * (5 * phi + 3 * pow(2, k, MOD)) % MOD
```这评估$$F(k)=M\left(5\varphi(M)+3\cdot2^k\right).$$---

 # 4. 示例验证

 对于$k=3$：$$M=7\cdot17\cdot37=4403,$$

$$\varphi(M)=6\cdot16\cdot36=3456.$$然后$$F(3) = 4403(5\cdot3456+3\cdot8) = 4403(17280+24) = 4403\cdot17304 = 76101452,$$与问题陈述完全匹配。
