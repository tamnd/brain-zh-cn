[项目欧拉问题 307](https://projecteuler.net/problem=307)

 ## 解决方案

 **答案：**`0.7311720251`让

-$n = 1{,}000{,}000$chips,
 -$k = 20{,}000$defects,

 每个缺陷独立且统一地分配给其中一个$n$筹码。 

我们想要$$p(k,n)=\Pr(\text{some chip has at least }3\text{ defects}).$$等价地，$$p(k,n)=1-\Pr(\text{every chip has at most 2 defects}).$$主要挑战是准确计算大参数的概率。 

---

 # 1.数学分析

 We distribute$k$将缺陷标记为$n$标记的芯片。 

总作业：$$n^k.$$我们现在计算没有芯片收到超过 2 个缺陷的分配。 

认为：

-$a$芯片恰好有 2 个缺陷，
 -$b$chips receive exactly 1 defect.

 然后$$2a+b=k.$$因此$$b=k-2a.$$占用芯片数为$$a+b=k-a.$$---

 ## 计算有效配置

 For a fixed$a$:

 ### Step 1: choose the chips

 选择：

 -$a$chips that contain 2 defects,
 -$b=k-2a$包含 1 个缺陷的芯片。 

Number of ways:$$\binom{n}{a}\binom{n-a}{k-2a}.$$---

 ### 第 2 步：分配缺陷

 我们有$k$标记的缺陷。 

We must partition them into:

 -$a$无序对，
 -$k-2a$单身人士。 

方式数量:$$\frac{k!}{(2!)^a}.$$但配对组本身是无序的，因此除以$a!$:$$\frac{k!}{2^a a!}.$$单例组通过其芯片自动区分。 

因此固定的总有效分配$a$:$$\binom{n}{a} \binom{n-a}{k-2a} \frac{k!}{2^a}.$$除以$n^k$:$$\Pr(\text{no chip has } \ge 3) = \sum_{a=0}^{\lfloor k/2\rfloor} \frac{ \binom{n}{a} \binom{n-a}{k-2a} k! }{ 2^a n^k }.$$这很好地简化了。 

---

 ## 简化公式

 使用下降阶乘：$$\binom{n}{a}\binom{n-a}{k-2a} = \frac{n!}{a!(k-2a)!(n-k+a)!}.$$因此$$P_{\le2} = \sum_{a=0}^{\lfloor k/2\rfloor} \frac{ n! \, k! }{ a!(k-2a)!(n-k+a)!2^a n^k }.$$所以$$p(k,n)=1-P_{\le2}.$$---

 # 2. 数值稳定计算

 直接阶乘是不可能的。 

我们以对数方式计算每一项。 

定义$$T_a = \frac{ n! \, k! }{ a!(k-2a)!(n-k+a)!2^a n^k }.$$然后$$\log T_a = \log(n!) +\log(k!) -\log(a!) -\log((k-2a)!) -\log((n-k+a)!) -a\log 2 -k\log n.$$使用对数伽玛：$$\log(m!)=\ln\Gamma(m+1).$$最后使用 log-sum-exp 稳定性计算总和。 

---

 # 3.Python实现```python
import math

def p(k, n):
    """
    Probability that some chip receives at least 3 defects.
    """

    log_terms = []

    log_n_fact = math.lgamma(n + 1)
    log_k_fact = math.lgamma(k + 1)
    k_log_n = k * math.log(n)

    # Sum over number of double-occupied chips
    for a in range(k // 2 + 1):

        log_term = (
            log_n_fact
            + log_k_fact
            - math.lgamma(a + 1)
            - math.lgamma(k - 2 * a + 1)
            - math.lgamma(n - k + a + 1)
            - a * math.log(2)
            - k_log_n
        )

        log_terms.append(log_term)

    # Stable log-sum-exp
    m = max(log_terms)

    s = sum(math.exp(x - m) for x in log_terms)

    p_le_2 = math.exp(m) * s

    return 1.0 - p_le_2

# Example from problem statement
print(p(3, 7))

# Required value
ans = p(20000, 1000000)

print("{:.10f}".format(ans))
```---
