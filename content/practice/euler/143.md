[欧拉项目问题 143](https://projecteuler.net/problem=143)

 ## 解决方案

 **答案：**`30758397`让

-$x = p+q+r$,
 -$a = BC$,
 -$b = CA$,
 -$c = AB$。 

对于费马/托里拆利点$T$，角度满足$$\angle ATB=\angle BTC=\angle CTA=120^\circ.$$将余弦定律应用于周围的三角形$T$,$$\begin{aligned} c^2 &= p^2+r^2+pr,\\ a^2 &= q^2+r^2+qr,\\ b^2 &= p^2+q^2+pq. \end{aligned}$$因此，托里拆利三角形恰好对应于正整数$p,q,r$使得所有三个量$$p^2+q^2+pq,\quad q^2+r^2+qr,\quad r^2+p^2+rp$$是完美的正方形。 

该问题要求所有不同的值$$x=p+q+r\le 120000.$$---

 # 1.数学分析

 我们从丢番图方程开始$$u^2 = m^2+n^2+mn.$$这就是爱森斯坦范数形式。 我们需要所有整数对$(m,n)$生产正方形。 

---

 ## 参数化

 重写：$$4u^2 = (2m+n)^2 + 3n^2.$$这类似于毕达哥拉斯三元组并允许完整的参数化。 

原始解是由生成的$$\boxed{ \begin{aligned} m &= d(2ab+b^2-a^2),\\ n &= d(2ab+a^2-b^2),\\ u &= d(a^2+ab+b^2), \end{aligned}}$$具有适当的互质/宇称限制。 

计算上重要的事实不是导出每个代数细节，而是：

 > 所有有效对$(m,n)$和$m+n\le 120000$可以从该参数化中有效地生成。 

现在定义一个图：

 - 顶点 = 整数，
 - 边缘$m\leftrightarrow n$如果$m^2+n^2+mn$是一个正方形。 

然后是托里拆利三重$(p,q,r)$正是该图中的一个三角形。 

所以我们：

 1. 生成所有有效对$(m,n)$,
 2.建立邻接表，
 3. 找到所有三角形$(p,q,r)$,
 4. 记录所有不同的总和$p+q+r\le 120000$。

 # 2.Python实现```python
from math import gcd, isqrt
from collections import defaultdict

LIMIT = 120000

# ------------------------------------------------------------
# Generate all pairs (m,n) such that
# m^2 + n^2 + mn is a perfect square.
# ------------------------------------------------------------

pairs = defaultdict(set)

# Parametrisation:
# m = d(2ab + b^2 - a^2)
# n = d(2ab + a^2 - b^2)
# u = d(a^2 + ab + b^2)

max_a = 400

for a in range(1, max_a):
    for b in range(1, a):

        if gcd(a, b) != 1:
            continue

        m0 = 2*a*b + b*b - a*a
        n0 = 2*a*b + a*a - b*b

        if m0 <= 0 or n0 <= 0:
            continue

        m0, n0 = sorted((m0, n0))

        k = 1
        while k * (m0 + n0) <= LIMIT:
            m = k * m0
            n = k * n0

            pairs[m].add(n)
            pairs[n].add(m)

            k += 1

# ------------------------------------------------------------
# Find all triangles in the graph.
# ------------------------------------------------------------

values = set()

for p in pairs:
    neigh_p = pairs[p]

    for q in neigh_p:
        if q <= p:
            continue

        common = neigh_p & pairs[q]

        for r in common:
            if r <= q:
                continue

            s = p + q + r

            if s <= LIMIT:
                values.add(s)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

print(sum(values))
```---

 # 3. 代码演练

 ## 建立有效的配对关系

 我们生成所有整数对$(m,n)$满意的$$m^2+n^2+mn = \square.$$参数化产生所有原始解； 乘以$k$生成非原始的。 

我们将它们存储在邻接结构中：```python
pairs[m].add(n)
```意义$m$和$n$是兼容的。 

---

 ## 图表解读

 托里拆利三角形需要：$$\begin{aligned} p^2+q^2+pq &= \square,\\ q^2+r^2+qr &= \square,\\ r^2+p^2+rp &= \square. \end{aligned}$$所以$(p,q,r)$图中必须形成3圈。 

代码：```python
common = neigh_p & pairs[q]
```查找与两者相邻的所有顶点$p$和$q$。
