[欧拉项目问题 570](https://projecteuler.net/problem=570)

 ## 解决方案

 **答案：**`271197444`让

-$A(n)$= 恰好一层厚的单位三角形的数量，
 -$B(n)$= 正好三层厚的单位三角形的数量，
 -$G(n)=\gcd(A(n),B(n))$。 

我们被要求$$\sum_{n=3}^{10^7} G(n).$$---

 # 1.数学分析

 关键步骤是导出闭式$A(n)$和$B(n)$。 

通过分析递归覆盖操作如何从顺序增长$n-1$订购$n$，得到线性递推$$A(n)=4A(n-1)+2\cdot 3^{n-2},$$

$$B(n)=4B(n-1)+24(n-2)4^{n-3}-6\cdot 3^{n-2},$$初始值来自小雪花。 

解决这些递推式给出了明确的公式$$A(n)=3\cdot 4^{n-1}-2\cdot 3^{n-1},$$和$$B(n)=18(n-2)4^{n-2}+(4n+26)3^{n-1}-138\cdot 4^{n-2}.$$这些简化为$$B(n)= (18n-138)4^{n-2} + (4n+26)3^{n-1}.$$现在计算 gcd。 

因素$A(n)$:$$A(n)=3\left(4^{n-1}-2\cdot 3^{n-2}\right).$$之间的代数消除后$A(n)$和$B(n)$, 发现$$G(n) = 6\cdot \gcd\!\left( 2\cdot 4^{n-2}-3^{n-2}, \, 7n+3 \right).$$这是关键的简化。 

---

 ## 进一步的模块化简化

 让$$m=7n+3.$$如果$3\nmid n$， 然后$\gcd(3,m)=1$， 所以$3^{n-2}$是可逆模数$m$。 

定义$$b \equiv 4\cdot 3^{-1} \pmod m.$$然后$$2\cdot 4^{n-2}-3^{n-2} \equiv 3^{n-2}\left(2b^{n-2}-1\right) \pmod m.$$自从$3^{n-2}$是可逆模数$m$,$$\gcd\!\left(2\cdot 4^{n-2}-3^{n-2},m\right) = \gcd\!\left(2b^{n-2}-1,m\right).$$因此每一项都可以仅使用模幂来计算。 

复杂性本质上是$$O\!\left(N\log N\right),$$这很容易足够快$N=10^7$。

 # 2.Python实现```python
from math import gcd

def A(n):
    return 3 * pow(4, n - 1) - 2 * pow(3, n - 1)

def B(n):
    p4 = pow(4, n - 2)
    p3 = pow(3, n - 1)
    return (18 * n - 138) * p4 + (4 * n + 26) * p3

def G(n):
    m = 7 * n + 3

    # If gcd(3, m) = 1, cancel 3^(n-2) modulo m
    if n % 3 != 0:

        # modular inverse of 3 modulo m
        if m % 3 == 1:
            inv3 = (2 * m + 1) // 3
        else:
            inv3 = (m + 1) // 3

        b = (4 * inv3) % m

        t = pow(b, n - 2, m)

        return 6 * gcd((2 * t - 1) % m, m)

    # Otherwise compute directly
    x = (2 * pow(4, n - 2, m) - pow(3, n - 2, m)) % m

    return 6 * gcd(x, m)

def solve(N):
    total = 0

    for n in range(3, N + 1):
        total += G(n)

    return total

# Verification against the statement
assert A(3) == 30
assert B(3) == 6
assert G(3) == 6

assert A(11) == 3027630
assert B(11) == 19862070
assert G(11) == 30

assert G(500) == 186
assert solve(500) == 5124

print(solve(10_000_000))
```---
