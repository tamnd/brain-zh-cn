[项目欧拉问题 382](https://projecteuler.net/problem=382)

 ## 解决方案

 **答案：**`697003956`让$$s_1=1,\qquad s_2=2,\qquad s_3=3,\qquad s_n=s_{n-1}+s_{n-3}\ (n>3).$$对于一个子集$A\subseteq U_n=\{s_1,\dots,s_n\}$，递增排序，多边形条件恰好是$$\max(A)<\sum_{x\in A\setminus\{\max(A)\}}x.$$既然所有$s_i$是独特且递增的，每个子集都有一个唯一的最大元素。 

---

 # 1.数学分析

 定义：$$g(n)=\#\{\text{subsets of }U_{n-1}\text{ with sum }\le s_n\}.$$如果一个子集$U_n$有最大的元素$s_n$，然后它生成一个多边形当且仅当其余选定元素的总和$>s_n$。 

有$2^{n-1}$最大元素为的子集$s_n$， 因此$$f(n)=\sum_{k=1}^n \left(2^{k-1}-g(k)\right).$$所以问题归结为计算$g(k)$。 

---

 ## 计算第一个值

 序列开始$$1,2,3,4,6,9,13,19,28,41,\dots$$得到的多边形数量是$$\begin{aligned} f(1)&=0\\ f(2)&=0\\ f(3)&=0\\ f(4)&=2\\ f(5)&=7\\ f(6)&=19\\ f(7)&=47\\ f(8)&=108\\ f(9)&=236\\ f(10)&=501. \end{aligned}$$与声明相符。 

---

 ## 关键结构事实

 因为$s_n=s_{n-1}+s_{n-3}$，计数序列$f(n)$最终是线性递归的（C 有限序列上的子集计数问题的标准结果）。 

使用前几个精确值和 Berlekamp-Massey 给出最小递归：$$\boxed{ f(n)= 4f(n-1)-5f(n-2)+4f(n-3)-7f(n-4)+6f(n-5) +2f(n-7)-5f(n-8)+2f(n-9) }$$为了$n\ge 10$。 

特征多项式因子为$$(x-2)(x-1)^2(x^3-x-1)(x^3+x-1).$$所以我们可以计算$f(10^{18})$模数$10^9$使用快速线性递归求幂$O(r^2\log n)$和$r=9$。 

---

 # 2.Python实现```python
MOD = 10**9

# Initial values f(1)..f(9)
init = [
    0,   # f(1)
    0,   # f(2)
    0,   # f(3)
    2,   # f(4)
    7,   # f(5)
    19,  # f(6)
    47,  # f(7)
    108, # f(8)
    236  # f(9)
]

# Recurrence:
# f(n) =
# 4f(n-1)-5f(n-2)+4f(n-3)-7f(n-4)+6f(n-5)
# +2f(n-7)-5f(n-8)+2f(n-9)

rec = [4, -5, 4, -7, 6, 0, 2, -5, 2]

def combine(a, b, rec):
    """
    Multiply two polynomials modulo the recurrence.
    """
    m = len(rec)
    tmp = [0] * (2 * m)

    for i in range(m):
        for j in range(m):
            tmp[i + j] = (tmp[i + j] + a[i] * b[j]) % MOD

    # Reduce using the recurrence
    for i in range(2 * m - 2, m - 1, -1):
        if tmp[i] == 0:
            continue
        for j in range(m):
            tmp[i - 1 - j] = (tmp[i - 1 - j] +
                              tmp[i] * rec[j]) % MOD

    return tmp[:m]

def linear_recurrence(n, init, rec):
    """
    Returns f(n) where indexing is:
        init[0] = f(1)
    """

    m = len(rec)

    if n <= m:
        return init[n - 1] % MOD

    # Binary exponentiation on the companion polynomial
    pol = [1] + [0] * (m - 1)
    e = [0, 1] + [0] * (m - 2)

    k = n - 1

    while k:
        if k & 1:
            pol = combine(pol, e, rec)
        e = combine(e, e, rec)
        k >>= 1

    ans = 0
    for i in range(m):
        ans = (ans + pol[i] * init[i]) % MOD

    return ans

N = 10**18
print(linear_recurrence(N, init, rec))
```---
