[欧拉项目问题 127](https://projecteuler.net/problem=127)

 ## 解决方案

 **答案：**`18407904`让$R(n)=\operatorname{rad}(n)$，不同质因数的乘积$n$。 

我们寻求所有三元组$(a,b,c)$这样$$a+b=c,\qquad a<b,\qquad \gcd(a,b)=\gcd(a,c)=\gcd(b,c)=1,$$和$$R(abc)<c.$$我们必须计算$$\sum c \quad\text{for all abc-hits with } c<120000.$$---

 # 1.数学分析

 直接的暴力破解方法是没有希望的：

 -$c<120000$- 对于每个$c$, 潜在地$O(c)$分裂$a+b=c$这将是数十亿张支票。 

我们需要利用激进的条件。 

---

 ## 步骤1：简化gcd条件

 自从$$a+b=c,$$我们有标准的身份：$$\gcd(a,b)=1 \implies \gcd(a,c)=\gcd(b,c)=1.$$的确，$$\gcd(a,c)=\gcd(a,a+b)=\gcd(a,b),$$类似地对于$\gcd(b,c)$。 

所以要求就足够了$$\gcd(a,b)=1.$$---

 ## 步骤 2：使用根式乘法

 因为$a,b,c$是两两互质，$$R(abc)=R(a)R(b)R(c).$$因此 abc-hit 条件变为$$R(a)R(b)R(c)<c.$$等价地，$$R(a)R(b)<\frac{c}{R(c)}.$$这是极其严格的限制。 

---

 ## 步骤 3：预计算根式

 我们计算$R(n)$为所有人$n<120000$使用筛子。 

最初：$$R(n)=1.$$对于每个素数$p$, 乘以每个倍数$p$经过$p$。 

复杂：$$O(n\log\log n).$$---

 ## 第四步：按键优化

 假设$c$是固定的。 

我们需要：$$R(a)R(b)R(c)<c.$$自从$b=c-a$,$$R(a)R(c-a)<\frac{c}{R(c)}.$$现在注意：

 - 如果$R(c)$很大，那么$c/R(c)$很小。 
- 最多$c$因此无法工作。 

我们循环：$$1\le a < \frac c2, \qquad b=c-a.$$但我们很快就会拒绝，除非$$R(a)R(b) < \frac{c}{R(c)}.$$我们还要求：$$\gcd(a,b)=1.$$---

 ## 步骤 5：复杂性估计

 令人惊讶的是，点击率很少。 

优化搜索在 Python 中快速完成，因为：

 - 根数是微小的整数，
 - 大多数配对立即失败，
 - GCD检查很便宜。 

---

 # 2.Python实现```python
from math import gcd

LIMIT = 120000

# ---------------------------------------------------------
# Compute rad(n) for all n < LIMIT using a sieve
# ---------------------------------------------------------

rad = [1] * LIMIT

for p in range(2, LIMIT):
    # p is prime iff rad[p] == 1
    if rad[p] == 1:
        for multiple in range(p, LIMIT, p):
            rad[multiple] *= p

# ---------------------------------------------------------
# Search for abc-hits
# ---------------------------------------------------------

total = 0

for c in range(3, LIMIT):

    rc = rad[c]

    # We need:
    # rad(a) * rad(b) * rad(c) < c
    #
    # so:
    # rad(a) * rad(b) < c / rad(c)

    threshold = c // rc

    # If threshold == 1, impossible
    if threshold <= 1:
        continue

    # Only need a < b
    for a in range(1, c // 2 + 1):

        b = c - a

        # Fast radical rejection
        if rad[a] * rad[b] >= threshold:
            continue

        # Need coprime
        if gcd(a, b) != 1:
            continue

        total += c

print(total)
```---
