[欧拉项目问题 162](https://projecteuler.net/problem=162)

 ## 解决方案

 **答案：**`3D58725572C62302`我们最多计算长度的十六进制数$16$包含每个数字$0$,$1$， 和$\mathrm A$至少一次，没有前导零。 

关键思想是**包容-排除**。 

让：

-$S_n$= 一组有效的$n$- 十六进制数字（第一个数字非零），
 - 我们想要包含所有的数字$\{0,1,\mathrm A\}$。 

不要直接计数，而是计算_避免_这些数字的某些子集的数字。 

对于禁止组$F\subseteq\{0,1,\mathrm A\}$：

- 有$16-|F|$总共允许的十六进制数字，
 - 第一位数字不能是$0$。 

所以第一个数字有$$(16-|F|)-[0\notin F]$$选择，在哪里$[0\notin F]$是$1$如果允许零（因为这样我们必须将其排除在领先位置之外）。 

其余$n-1$各职位有$16-|F|$选择。 

因此：$$f(n,F) = \text{first}\times (16-|F|)^{n-1}$$现在应用包含-排除：$$\#(\text{contains }0,1,A) = \sum_{F\subseteq\{0,1,A\}} (-1)^{|F|} f(n,F)$$总结一下$n=1,\dots,16$。 

---

 提供的 Python 代码正是实现了这一点：```python
def f(n, fb):  # n-digit hex numbers avoiding digits in fb set
    a = 16 - len(fb)
    first = a - (0 not in fb)
    return (first * a**(n-1)) if first > 0 and a > 0 else 0

ans = 0
for n in range(1, 17):
    for mask in range(8):
        fb = {[0,1,10][i] for i in range(3) if mask>>i&1}
        ans += ((-1)**bin(mask).count('1')) * f(n, fb)

print(hex(ans)[2:].upper())
```## 代码演练

 ### 功能`f(n, fb)`

```python
a = 16 - len(fb)
```如果`fb`包含禁止数字，那么`a`是允许的十六进制数字的数量。 

示例：

 - 禁止`{0,1}`→$16-2=14$允许的数字。 

---```python
first = a - (0 not in fb)
```如果允许零，我们必须将其从前导数字中排除。 

所以：

 - 如果`0`不禁止，减1，
 - 否则全部`a`数字对于第一个位置有效。 

---```python
return (first * a**(n-1))
```选择：

 - 第一个数字`first`方式，
 - 剩余数字独立于`a`方式。 

---

 ### 包含-排除循环```python
for mask in range(8):
```有$2^3=8$的子集$\{0,1,A\}$。 

---```python
fb = {[0,1,10][i] for i in range(3) if mask>>i&1}
```构造禁止子集。 

-`10`代表十六进制数字`A`。 

---```python
ans += ((-1)**bin(mask).count('1')) * f(n, fb)
```应用包含-排除：

 - 添加均匀大小的子集，
 - 减去奇数大小的子集。
