[欧拉项目问题 288](https://projecteuler.net/problem=288)

 ## 解决方案

 **答案：**`605857431263981935`让$$N(p,q)=\sum_{n=0}^{q} T_n p^n,$$在哪里$$S_0=290797,\qquad S_{n+1}=S_n^2 \bmod 50515093,\qquad T_n=S_n\bmod p.$$我们想要$$\operatorname{NF}(p,q)=v_p(N(p,q)!),$$素数的指数$p$在$N(p,q)!$。 

对于这个问题：$$p=61,\qquad q=10^7,$$我们需要$$\operatorname{NF}(61,10^7)\bmod 61^{10}.$$---

 # 1.数学分析

 关键事实是**勒让德公式**：$$v_p(n!)=\sum_{k\ge1}\left\lfloor \frac{n}{p^k}\right\rfloor.$$源自基础的标准身份$p$数字和是$$v_p(n!)=\frac{n-s_p(n)}{p-1},$$在哪里$s_p(n)$是数字的总和$n$在基地$p$。 

---

 ## 步骤 1：基础-$p$的代表$N(p,q)$因为每个$$0\le T_n < p,$$数量$$N(p,q)=\sum_{n=0}^{q}T_n p^n$$已经_是_基地-$p$的扩展$N$。 

所以，$$s_p(N)=\sum_{n=0}^{q}T_n.$$因此$$\operatorname{NF}(p,q) = \frac{N-\sum T_n}{p-1}.$$代入定义$N$:$$\operatorname{NF}(p,q) = \frac{\sum_{n=0}^{q}T_n p^n-\sum_{n=0}^{q}T_n}{p-1}.$$逐项分解：$$\operatorname{NF}(p,q) = \sum_{n=0}^{q} T_n\frac{p^n-1}{p-1}.$$定义$$R_n=\frac{p^n-1}{p-1}=1+p+p^2+\cdots+p^{n-1}.$$所以$$\boxed{ \operatorname{NF}(p,q)=\sum_{n=0}^{q}T_nR_n }.$$---

 ## 步骤 2：减少模数$p^{10}$我们只需要取模$61^{10}$。 

观察：$$R_n = 1+p+\cdots+p^{n-1}.$$对于任何$n\ge 10$,$$R_n \equiv 1+p+\cdots+p^9 \pmod{p^{10}},$$因为所有更高的幂都可以被整除$p^{10}$。 

让$$R=1+p+\cdots+p^9.$$然后$$\operatorname{NF}(p,q) \equiv \sum_{n=0}^{9}T_nR_n + R\sum_{n=10}^{q}T_n \pmod{p^{10}}.$$这是至关重要的简化：我们永远不需要巨大的力量$p$，仅限前十名。 

---

 # 2.Python实现```python
def solve():
    p = 61
    q = 10_000_000
    mod = p ** 10

    # Random generator seed
    S = 290797

    # R = 1 + p + p^2 + ... + p^9  (mod p^10)
    R = sum(p ** i for i in range(10)) % mod

    # Store first 10 T_n values separately
    first_terms = []

    # Sum of all T_n for n >= 10
    tail_sum = 0

    # Generate T_n values
    for n in range(q + 1):
        T = S % p

        if n < 10:
            first_terms.append(T)
        else:
            tail_sum += T

        S = (S * S) % 50515093

    # Compute contribution of first 10 terms exactly
    ans = 0

    for n in range(10):
        # R_n = 1 + p + ... + p^(n-1)
        Rn = sum(p ** i for i in range(n))
        ans += first_terms[n] * Rn

    # Contribution from all remaining terms
    ans += R * tail_sum

    ans %= mod

    return ans

print(solve())
```---
