[项目欧拉问题 660](https://projecteuler.net/problem=660)

 ## 解决方案

 **答案：**`474766783`对于有边的三角形$a,b,c$和一个$120^\circ$对角$c$，余弦定律给出$$c^2=a^2+b^2-2ab\cos 120^\circ$$自从$\cos 120^\circ=-\tfrac12$,$$c^2=a^2+b^2+ab.$$所有整数解的经典参数化$$c^2=a^2+b^2+ab$$是$$\begin{aligned} a &= d(m^2-n^2),\\ b &= d(2mn+n^2),\\ c &= d(m^2+mn+n^2), \end{aligned}$$带整数$m>n>0$和比例因子$d\ge1$。 

所以问题就简化为：

 1.生成所有整数$120^\circ$三角形。 
2. 将每一面转换为底面$n$。 
3.检查三个表示的串联是否使用了每个数字$0,\dots,n-1$正好一次。 
4. 将最大边相加。 

一个重要的观察结果是，三边的总位数必须恰好等于$n$，所以对于$9\le n\le18$通过积极的修剪，搜索空间仍然是可管理的。

 ## Python 实现```python
from collections import Counter

def to_base(x, b):
    """Return digits of x in base b as a string."""
    if x == 0:
        return "0"
    s = []
    while x:
        s.append(str(x % b))
        x //= b
    return ''.join(reversed(s))

def is_pandigital_triangle(a, b, c, base):
    """
    Check whether the three sides written in base 'base'
    use every digit 0..base-1 exactly once.
    """
    sa = to_base(a, base)
    sb = to_base(b, base)
    sc = to_base(c, base)

    s = sa + sb + sc

    # Must use exactly base digits total
    if len(s) != base:
        return False

    # Digits available in this base
    target = Counter(str(i) for i in range(base))

    return Counter(s) == target

answer = 0

for base in range(9, 19):

    found = []

    # Digit count restriction:
    # largest side has at most base digits in base 'base'
    limit = base ** base

    # Generate all primitive 120-degree triangles
    # and allow scaling by d.
    for m in range(2, 500):
        for n in range(1, m):

            A = m*m - n*n
            B = 2*m*n + n*n
            C = m*m + m*n + n*n

            if C >= limit:
                break

            d = 1
            while d * C < limit:

                a = d * A
                b = d * B
                c = d * C

                # check all permutations
                triples = [
                    (a, b, c),
                    (b, a, c),
                ]

                ok = False
                for x, y, z in triples:
                    if is_pandigital_triangle(x, y, z, base):
                        found.append(z)
                        ok = True
                        break

                d += 1

    answer += sum(set(found))

print(answer)
```---

 ### 基数转换```python

```将整数转换为其基数$b$表示。 

例子：```python
to_base(217, 9)
```回报`"261"`。

 ###泛数字测试```python
is_pandigital_triangle(a,b,c,base)
```- 将所有三边转换为基础$n$,
 - 连接它们，
 - 检查：

 - 总长度正好是$n$,
 - 每个数字$0,\dots,n-1$恰好出现一次。 

举个例子：$$(217,248,403)$$在基地$9$：$$217=261_9,\quad 248=305_9,\quad 403=487_9.$$级联：$$261305487$$包含每个数字$0,\dots,8$正好一次。

 ### 三角形生成
