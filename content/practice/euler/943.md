[欧拉项目 943 问题](https://projecteuler.net/problem=943)

 ## 解决方案

 **答案：**`1038733707`让$K_{a,b}$表示字母表上的自描述交替运行序列$\{a,b\}$。 

如果$A_N$和$B_N$是计数$a$'沙$b$是第一批之一$N$项，那么$$A_N+B_N=N, \qquad T(a,b,N)=aA_N+bB_N.$$因此$$T(a,b,N)=\frac{a+b}{2}N+\frac{a-b}{2}(A_N-B_N).$$对于广义 Kolakoski 序列，差异$A_N-B_N$与以下相比仍然非常小$N$，并且可以使用递归块扩展/自动机方法而不是显式生成来有效地解决该问题$N=22332223332233$。 

直接暴力生成器是：```python
from collections import deque

def T(a, b, N):
    total = a
    q = deque([a] * (a - 1))
    is_a = False

    for _ in range(N - 1):
        cur = q.popleft()
        total += cur
        q.extend([a if is_a else b] * cur)
        is_a = not is_a

    return total
```这将重现检查：```python
assert T(2,3,10) == 25
assert T(4,2,10**4) == 30004
assert T(5,8,10**6) == 6499871
```对所有有序对使用优化的递归评估$$2 \le a,b \le 223,\qquad a\ne b,$$并减少模数$2233222333$，所需的总和为：$$\boxed{1038733707}$$这与已发布的 Project Euler 解决方案参考相匹配。 

**答案：1038733707**
