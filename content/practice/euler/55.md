[欧拉项目问题 55](https://projecteuler.net/problem=55)

 ## 解决方案

 **答案：**`249`**Lychrel 数**（就本问题而言）是在“反转并相加”过程的 50 次迭代内不会变成回文的数字。 

我们必须计算有多少个整数$1 \le n < 10000$是该定义下的 Lychrel 数。 

---

 # 数学分析

 对于正整数$n$：

 1. 将其小数位反转：$$r(n)$$2. 形式：$$n_1 = n + r(n)$$3.如果$n_1$是一个回文，停止。 
4. 否则重复。 

我们分类$n$如果 50 次迭代内没有出现回文，则作为 Lychrel 数。 

---

 ## 示例 1：$47$

$$47 + 74 = 121$$自从$121$是一个回文，$47$**不是** Lychrel。 

---

 ## 示例 2：$349$

$$349 + 943 = 1292$$

$$1292 + 2921 = 4213$$

$$4213 + 3124 = 7337$$3次迭代后我们得到回文$7337$， 所以$349$不是利克雷尔。 

---

 # 关键观察结果

 ## 1. 检测回文

 如果一个数字的十进制表示形式等于其倒数，则该数字是回文数。 

例如：

-$121 \rightarrow$回文
 -$7337 \rightarrow$回文
 -$123 \rightarrow$非回文

 从算法上来说：```python
s == s[::-1]
```---

 ## 2. 逆加运算

 如果$$n = 1234$$然后$$r(n)=4321$$和$$1234+4321=5555$$---

 ## 3.迭代限制

 问题明确指出：

 - 下面的每个数字$10000$要么：

 - 在少于 50 次迭代内变成回文，或者
 - 被认为是 Lychrel 解决这个问题的方法。 

所以我们最多只需要测试 50 次迭代。 

---

 # 算法

 对于每个数字$n$从$1$到$9999$：

 1. 设置$x=n$2. 重复最多 50 次：

 - 计算：$$x \leftarrow x + r(x)$$- 如果$x$是一个回文：

 -$n$不是莱克雷尔
 - 停止
 3. 如果50次迭代后没有回文出现：

 - 计数$n$……

 ---

 # Python 实现```python
def reverse_number(n):
    """Return the integer obtained by reversing decimal digits of n."""
    return int(str(n)[::-1])

def is_palindrome(n):
    """Check whether n is a palindrome."""
    s = str(n)
    return s == s[::-1]

def is_lychrel(n, limit=50):
    """
    Return True if n is considered a Lychrel number.
    
    We repeatedly apply reverse-and-add up to 'limit' times.
    If a palindrome appears, return False.
    Otherwise return True.
    """
    x = n

    for _ in range(limit):
        x = x + reverse_number(x)

        if is_palindrome(x):
            return False

    return True

# Count Lychrel numbers below 10000
count = 0

for n in range(1, 10000):
    if is_lychrel(n):
        count += 1

print(count)
```---
