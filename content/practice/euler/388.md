[项目欧拉问题 388](https://projecteuler.net/problem=388)

 ## 解决方案

 **答案：**`831907372805129931`设一个格点为$P=(a,b,c)$和$0\le a,b,c\le N$，不全为零。 

两个点确定通过原点的同一条线，当且仅当其中一个点是另一个点的正整数倍。 

因此，每条不同的行都唯一对应于一个**原始**三元组：$$\gcd(a,b,c)=1.$$所以$D(N)$正是立方体中本原格点的数量$[0,N]^3\setminus\{(0,0,0)\}$。 

---

 # 1.数学分析

 定义$$F(N)=\#\{(a,b,c):0\le a,b,c\le N,\ \gcd(a,b,c)=1\}.$$然后$D(N)=F(N)-1$， 因为$(0,0,0)$是不允许的。 

我们现在使用莫比乌斯反演来计算原始三元组。 

---

 ## 计算可被整除的三元组$d$让$$T_d(N)=\#\{(a,b,c): d\mid a,\ d\mid b,\ d\mid c\}.$$的倍数为$d$在$[0,N]$是$$0,d,2d,\dots,\left\lfloor \frac Nd\right\rfloor d,$$所以有$\lfloor N/d\rfloor+1$每个坐标的选择。 因此$$T_d(N)=\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3.$$通过莫比乌斯反演，$$F(N)=\sum_{d=1}^{N}\mu(d)\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3,$$在哪里$\mu$是莫比乌斯函数。 

但起源对每一个都有贡献$T_d$，所以它的净贡献是$$\sum_{d=1}^{N}\mu(d)=M(N),$$在哪里$M(N)$是梅尔滕斯函数。 

由于不应计算起源，因此我们减去该贡献：$$D(N)=\sum_{d=1}^{N}\mu(d)\left[\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3-1\right].$$这个公式是准确的。 

---

 ## 降低复杂性

 直接一个$O(N)$求和是不可能的$N=10^{10}$。 

关键的观察是$$\left\lfloor \frac Nd\right\rfloor$$只需要大约$2\sqrt N$独特的价值观。 

具有等商的组索引：$$q=\left\lfloor \frac Nd\right\rfloor.$$如果$q$是固定的，那么所有的$$d\in [L,R],\qquad R=\left\lfloor \frac Nq\right\rfloor$$共享相同的商。 

因此$$\sum_{d=L}^{R}\mu(d) = M(R)-M(L-1).$$所以我们计算$$D(N)= \sum_{\text{blocks}} \bigl(M(R)-M(L-1)\bigr)\bigl((q+1)^3-1\bigr).$$剩下的任务是评估$M(x)$迅速地。 

---

 ## Mertens 函数的快速计算

 使用经典的递归$$M(n)=1-\sum_{l=2}^{n}(r-l+1)M\!\left(\left\lfloor\frac nl\right\rfloor\right),$$其中相等的商被分组。 

记忆使这个运行大致$O(n^{2/3})$，这足够快$10^{10}$。 

---

 # 2.Python实现```python
from functools import lru_cache

# ------------------------------------------------------------
# Linear sieve for Möbius values up to LIMIT
# ------------------------------------------------------------

def mobius_prefix(limit):
    mu = [0] * (limit + 1)
    mu[1] = 1

    primes = []
    is_composite = [False] * (limit + 1)

    for i in range(2, limit + 1):
        if not is_composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            if i * p > limit:
                break

            is_composite[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    # Prefix sums: M(n) = sum_{k<=n} mu(k)
    M = [0] * (limit + 1)

    for i in range(1, limit + 1):
        M[i] = M[i - 1] + mu[i]

    return M

LIMIT = 2_000_000
M_small = mobius_prefix(LIMIT)

# ------------------------------------------------------------
# Fast recursive Mertens function
# ------------------------------------------------------------

@lru_cache(None)
def M(n):
    if n <= LIMIT:
        return M_small[n]

    result = 1
    l = 2

    while l <= n:
        q = n // l
        r = n // q

        result -= (r - l + 1) * M(q)

        l = r + 1

    return result

# ------------------------------------------------------------
# Compute D(N)
# ------------------------------------------------------------

def D(N):
    ans = 0
    l = 1

    while l <= N:
        q = N // l
        r = N // q

        mobius_sum = M(r) - M(l - 1)

        ans += mobius_sum * ((q + 1) ** 3 - 1)

        l = r + 1

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

print(D(100))       # 850957
print(D(1_000_000)) # 831909254469114121

# Final computation
value = D(10**10)

s = str(value)

print(value)
print(s[:9] + s[-9:])
```---

 # 3. 代码演练

 ###`mobius_prefix(limit)`使用线性筛计算：

 -$\mu(n)$，莫比乌斯函数，
 - 及其前缀和$M(n)$。 

前缀和允许恒定时间检索$$\sum_{k=L}^{R}\mu(k)=M(R)-M(L-1).$$---

 ###`M(n)`递归计算大型的 Mertens 函数$n$。 

身份$$M(n)=1-\sum_{k=2}^{n} M\!\left(\left\lfloor\frac nk\right\rfloor\right)$$在商块中计算，因此递归是有效的。 

记忆化确保每个不同的参数都被计算一次。 

---

 ###`D(N)`评估$$D(N)=\sum_{d=1}^{N}\mu(d)\left[\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3-1\right]$$通过对等商进行分组。 

这减少了运行时间$O(N)$粗略地$O(\sqrt N)$块操作加上递归 Mertens 评估。
