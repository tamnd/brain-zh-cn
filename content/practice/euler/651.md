[项目欧拉问题 651](https://projecteuler.net/problem=651)

 ## 解决方案

 **答案：**`448233151`让贴纸形成一个$a\times b$矩形网格包裹在圆柱体上：

 -$a$= 沿轴的周期，
 -$b$= 圆周上的贴纸数量。 

由于该图案在两个方向上都是周期性的，因此该表面实际上是一个$a\times b$环面。 

我们必须使用**精确**来计算颜色$m$颜色，对由生成的所有几何对称性取模

 - 沿轴的平移，
 - 绕圆柱体旋转，
 - 反思。 

因此对称群是$$G \cong D_a \times D_b,$$有尺寸$$|G| = 4ab.$$问题是 **伯恩赛德引理** 的直接应用。 

---

 # 1. Burnside 引理

 对于组元素$g$， 让$c(g)$是诱导排列的循环数$ab$贴纸位置。 

固定的着色$g$每个周期必须恒定，因此$k$可用颜色有$$k^{c(g)}$$固定的颜色。 

强制使用 **exactly**$m$颜色，使用包含-排除：$$E_m(c) = \sum_{j=0}^{m} (-1)^{m-j} \binom{m}{j} j^c.$$这等于$m!\,S(c,m)$， 在哪里$S(c,m)$是第二类斯特林数。 

因此$$f(m,a,b) = \frac1{4ab} \sum_{g\in G} E_m(c(g)).$$因此整个任务简化为计算周期计数$c(g)$。 

---

 # 2. 循环结构

 二面体元素是：

 - 旋转，
 - 或反思。 

对于旋转$r$在一个长度周期上$n$：$$\gcd(n,r)$$循环发生，每个长度$n/\gcd(n,r)$。 

对于反思：

 - 如果$n$是奇数：

 - 一个固定点，
 -$(n-1)/2$换位；
 - 如果$n$是偶数：

 - 一半的反射有两个固定点，
 - 一半没有。 

对于产品动作，如果一个因素具有长度周期$p_i$另一个有长度$q_j$，那么乘积排列贡献$$\sum_{i,j}\gcd(p_i,q_j)$$循环。 

这产生了有效的除数和公式，并使计算即使对于$$(F_{39},F_{40})=(63245986,102334155).$$---

 # 3.Python实现```python
from math import gcd, isqrt, comb

MOD = 1_000_000_007

# ------------------------------------------------------------
# Euler phi
# ------------------------------------------------------------

phi_cache = {1: 1}

def phi(n):
    if n in phi_cache:
        return phi_cache[n]

    x = n
    result = n
    p = 2

    while p * p <= x:
        if x % p == 0:
            while x % p == 0:
                x //= p
            result -= result // p
        p += 1

    if x > 1:
        result -= result // x

    phi_cache[n] = result
    return result

# ------------------------------------------------------------
# Divisors
# ------------------------------------------------------------

def divisors(n):
    ds = []
    for d in range(1, isqrt(n) + 1):
        if n % d == 0:
            ds.append(d)
            if d * d != n:
                ds.append(n // d)
    return ds

# ------------------------------------------------------------
# Number of surjections onto exactly m colours
# ------------------------------------------------------------

def exact_colourings(cycles, m):
    total = 0

    for j in range(m + 1):
        total += (
            (-1) ** (m - j)
            * comb(m, j)
            * pow(j, cycles, MOD)
        )

    return total % MOD

# ------------------------------------------------------------
# Burnside count
# ------------------------------------------------------------

def f(m, a, b):

    total = 0

    # --------------------------------------------------------
    # rotation / rotation
    # --------------------------------------------------------

    for d1 in divisors(a):
        for d2 in divisors(b):

            count = phi(a // d1) * phi(b // d2)
            cycles = d1 * d2

            total += count * exact_colourings(cycles, m)

    # --------------------------------------------------------
    # rotation / reflection
    # --------------------------------------------------------

    for d1 in divisors(a):

        A = a // d1
        count = phi(A)

        if b % 2 == 1:

            cycles = d1 * (
                1 + ((b - 1) // 2) * gcd(A, 2)
            )

            total += b * count * exact_colourings(cycles, m)

        else:

            cycles_even = d1 * (b // 2 + 1)
            cycles_odd  = d1 * (b // 2)

            total += (
                (b // 2)
                * count
                * (
                    exact_colourings(cycles_even, m)
                    + exact_colourings(cycles_odd, m)
                )
            )

    # --------------------------------------------------------
    # reflection / rotation
    # --------------------------------------------------------

    for d2 in divisors(b):

        B = b // d2
        count = phi(B)

        if a % 2 == 1:

            cycles = d2 * (
                1 + ((a - 1) // 2) * gcd(B, 2)
            )

            total += a * count * exact_colourings(cycles, m)

        else:

            cycles_even = d2 * (a // 2 + 1)
            cycles_odd  = d2 * (a // 2)

            total += (
                (a // 2)
                * count
                * (
                    exact_colourings(cycles_even, m)
                    + exact_colourings(cycles_odd, m)
                )
            )

    # --------------------------------------------------------
    # reflection / reflection
    # --------------------------------------------------------

    def reflection_types(n):

        if n % 2 == 1:
            # (fixed points, transpositions), multiplicity
            return [((1, (n - 1) // 2), n)]

        return [
            ((2, (n - 2) // 2), n // 2),
            ((0, n // 2),       n // 2),
        ]

    for (f1, t1), mult1 in reflection_types(a):
        for (f2, t2), mult2 in reflection_types(b):

            cycles = (
                f1 * f2
                + f1 * t2
                + f2 * t1
                + 2 * t1 * t2
            )

            total += (
                mult1
                * mult2
                * exact_colourings(cycles, m)
            )

    total %= MOD

    return total * pow(4 * a * b, MOD - 2, MOD) % MOD

# ------------------------------------------------------------
# Fibonacci numbers
# ------------------------------------------------------------

F = [0, 1]

for _ in range(2, 41):
    F.append(F[-1] + F[-2])

# ------------------------------------------------------------
# Required sum
# ------------------------------------------------------------

ans = 0

for i in range(4, 41):
    ans += f(i, F[i - 1], F[i])

ans %= MOD

print(ans)
