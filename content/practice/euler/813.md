[欧拉项目 813 问题](https://projecteuler.net/problem=813)

 ## 解决方案

 **答案：**`14063639`让$$a \otimes b$$表示异或积。 

关键的观察结果是，异或乘积恰好是二进制多项式在域上的乘法$\mathbb F_2$。 

---

 # 1.数学分析

 将整数写入二进制：$$n=\sum n_i2^i,\qquad n_i\in\{0,1\}$$并将其与多项式相关联$$f_n(x)=\sum n_i x^i$$超过$\mathbb F_2$。 
基数的普通长乘法$2$，用 XOR 代替加法，精确地是多项式乘法模$2$。 所以：$$f_{a\otimes b}(x)=f_a(x)f_b(x).$$---

 ## 步骤1：多项式对应于$11$

$$11_{10}=1011_2$$所以$$f(x)=x^3+x+1.$$因此$$P(n)=11^{\otimes n}$$对应于$$f(x)^n.$$---

 # 2. 利用指数结构

 我们需要$$P(8^{12}\cdot 12^8).$$对指数进行因式分解：$$8^{12}\cdot 12^8 =(2^3)^{12}(2^2\cdot 3)^8 =2^{36} \cdot 2^{16}\cdot 3^8 =2^{52}3^8.$$因此$$P(8^{12}12^8) =f(x)^{2^{52}3^8}.$$---

 ## 步骤 2：Frobenius 映射$\mathbb F_2$在特点上$2$,$$(a+b)^2=a^2+b^2.$$因此对于任意多项式$g(x)$,$$g(x)^{2^k}=g(x^{2^k}).$$所以：$$f(x)^{2^{52}3^8} = \left(f(x)^{3^8}\right)^{2^{52}} = f(x^{2^{52}})^{3^8}.$$让$$f(x)^{3^8}=\sum_i c_i x^i, \qquad c_i\in\{0,1\}.$$然后$$f(x)^{2^{52}3^8} = \sum_i c_i x^{i2^{52}}.$$最后，转换回整数意味着评估$x=2$:$$P(8^{12}12^8) = \sum_i c_i 2^{i2^{52}}.$$模数$M=10^9+7$， 定义$$r=2^{2^{52}} \pmod M.$$然后$$P(8^{12}12^8)\equiv \sum_i c_i r^i \pmod M.$$所以任务减少为：

 1. 计算$f(x)^{6561}$超过$\mathbb F_2$,
 2. 对其进行评估$r$。 

---

 # 3.Python实现```python
MOD = 10**9 + 7

# Polynomial for 11 = 1011_2 = x^3 + x + 1
# Bit i = coefficient of x^i
f = (1 << 0) | (1 << 1) | (1 << 3)

# XOR-polynomial multiplication over GF(2)
def mul(a, b):
    res = 0
    shift = 0

    while b:
        if b & 1:
            res ^= (a << shift)
        shift += 1
        b >>= 1

    return res

# Fast exponentiation of polynomials over GF(2)
def poly_pow(a, n):
    res = 1

    while n:
        if n & 1:
            res = mul(res, a)

        a = mul(a, a)
        n >>= 1

    return res

# Compute f(x)^(3^8)
g = poly_pow(f, 3**8)

# r = 2^(2^52) mod MOD
r = pow(2, 2**52, MOD)

# Evaluate polynomial g at r modulo MOD
ans = 0
power = 1

while g:
    if g & 1:
        ans = (ans + power) % MOD

    power = (power * r) % MOD
    g >>= 1

print(ans)
```---

 # 4. 代码演练

 ## 多项式编码```python
f = (1 << 0) | (1 << 1) | (1 << 3)
```编码$$x^3+x+1.$$整数位掩码存储多项式系数。 

---

 ## 乘法```python
res ^= (a << shift)
```实现多项式乘法$\mathbb F_2$:

 - 移位对应于乘以$x^{\text{shift}}$,
 - XOR 对应于加法模$2$。 

---

 ## 求幂```python
g = poly_pow(f, 3**8)
```计算$$(x^3+x+1)^{6561}.$$---

 ## 弗罗贝尼乌斯替换

 而不是直接处理指数$2^{52}3^8$，我们使用$$g(x^{2^{52}})$$这成为评估$$r=2^{2^{52}} \pmod{10^9+7}.$$---

 # 5.小例子验证

 对于$n=2$:$$P(2)=11\otimes 11.$$多项式：$$(x^3+x+1)^2=x^6+x^2+1.$$评估于$x=2$:$$2^6+2^2+1=64+4+1=69,$$与声明相符。 

---

 # 6.最终验证

 - 程度$f^{6561}$是$3\cdot6561=19683$，完全可以管理。 
- 仅使用异或运算，与定义完全匹配。 
- 弗罗贝尼乌斯恒等式有效，因为系数具有特征$2$。 

计算得出：$$14063639.$$**答案：14063639**
