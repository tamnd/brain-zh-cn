[欧拉项目问题 357](https://projecteuler.net/problem=357)

 ## 解决方案

 **答案：**`1739023853137`我们寻找所有正整数$n \le 10^8$这样$$d + \frac{n}{d}$$对于**每个除数**都是素数$d$的$n$。 

我们必须计算$$\sum n.$$## 1.数学分析

 让我们得出强约束。 

### 关键条件

 对于每个除数$d \mid n$,$$d + \frac{n}{d}$$必须是素数。 

由于除数是互补对的，我们只需要测试除数$\sqrt n$。 

---

 ### 第一个观察：$d = n$服用$d=n$,$$n + \frac{n}{n} = n+1$$必须是素数。 

所以：

-$n+1$是素数，
 - 因此$n$对所有人来说都是均匀的$n>1$。 

---

 ### 第二个观察：$d=1$服用$d=1$,$$1+n$$也必须是素数——同样的条件。 

因此每个有效的$n>1$满足：$$n+1 \text{ is prime}.$$这已经是一个巨大的减少了。 

---

 ### 第三个观察：$d=p$对于素因数

 假设$p\mid n$。 

然后$$p + \frac{n}{p}$$必须是素数。 

现在考虑以下可能性：$p^2 \mid n$。 

让$$n = p^2m.$$选择除数$$d = pm.$$然后$$d+\frac{n}{d} = pm+p = p(m+1).$$自从$n>1$，这是复合的，除非它等于$p$， 不可能的。 

因此：

 ### 重要后果$$\boxed{n \text{ must be squarefree}}$$（除了$n=1$）。 

---

 ### 第四个观察：$d = p$如果$p\mid n$,$$p+\frac{n}{p}$$必须是素数。 

特别是对于$p=2$,$$2+\frac n2$$必须是素数。 

这成为一个非常有效的早期过滤器。 

---

 ### 策略

 暴力除数测试高达$10^8$是不可能的。 

我们利用观察结果：

 1.$n+1$必须是素数

 ⇒ 候选编号为$n=p-1$在哪里$p$是素数。 
2.$n$必须是无平方的。 
3. 对于每个除数$d$,

 测试是否$$d+\frac nd$$是素数。 

自从$n$是无平方的并且滤波后大部分是稀疏的，这变得可行。 

---

 ### 高效的素性查找

 我们筛选素数达到：$$10^8+1$$因为检查的最大值是$$d+\frac nd \le n+1.$$布尔筛给出$O(1)$素性测试。 

---

 ## 2.Python实现```python
from math import isqrt

LIMIT = 100_000_000

def prime_sieve(n):
    """Boolean sieve: is_prime[x] tells whether x is prime."""
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            start = p * p
            sieve[start:n + 1:p] = b"\x00" * ((n - start) // p + 1)

    return sieve

# Build primality table up to LIMIT + 1
is_prime = prime_sieve(LIMIT + 1)

total = 0

# n = 1 works:
# divisors = {1}, and 1 + 1 = 2 is prime
total += 1

# Since n + 1 must be prime, candidates are p - 1
for p in range(3, LIMIT + 2, 2):
    if not is_prime[p]:
        continue

    n = p - 1

    # n must be squarefree and satisfy condition
    valid = True

    # Check every divisor d <= sqrt(n)
    root = isqrt(n)

    for d in range(2, root + 1):
        if n % d == 0:
            q = n // d

            # d + n/d must be prime
            if not is_prime[d + q]:
                valid = False
                break

            # squarefree test:
            if q % d == 0:
                valid = False
                break

    if valid:
        total += n

print(total)
```---
