[欧拉项目 623 问题](https://projecteuler.net/problem=623)

 ## 解决方案

 **答案：**`3679796`让$T_m(n)$是$\alpha$-**精确**大小的 lambda 项的等价类$n$其自由变量在其中$m$可用的粘合剂。 

那么需要的数量就是$$\Lambda(n)=\sum_{k\le n} T_0(k).$$关键的观察是对模数进行计数$\alpha$- 等价正是 **de Bruijn 索引** 所做的：只有_绑定结构_重要，而不是实际的变量名称。 

---

 # 1.数学分析

 ## 尺寸型号

 从例子来看：

 - 可变$x$有尺寸$1$。 
- 应用$(MN)$贡献两个括号：$$|(MN)| = |M|+|N|+2.$$- 抽象$(\lambda x.M)$贡献：
 - 左括号
 -$\lambda$- 变量
 - 点
 - 右括号

 所以$$|(\lambda x.M)| = |M|+5.$$查看：$$|(\lambda x.x)| = 5+1 = 6,$$与声明相符。 

---

 ## 递归分解

 计算的术语$T_m(n)$是以下之一：

 ### 1.变量

 正好有$m$可能的自由变量。 

所以：$$T_m(1)=m.$$---

 ### 2.申请

 一个术语$(AB)$有尺寸$$|A|+|B|+2=n.$$因此：$$\sum_{i=1}^{n-3} T_m(i)\,T_m(n-2-i).$$---

 ### 3. 抽象

 一个术语$(\lambda x.M)$有尺寸$$|M|+5=n.$$在抽象内部，我们又获得了一个可用变量，因此：$$T_{m+1}(n-5).$$---

 结合一切：$$\boxed{ T_m(n)= \begin{cases} m,& n=1,\\[1ex] T_{m+1}(n-5)+ \displaystyle\sum_{i=1}^{n-3}T_m(i)T_m(n-2-i), & n\ge2. \end{cases} }$$最后，$$\boxed{ \Lambda(N)=\sum_{n=0}^{N} T_0(n). }$$---

 # 2.Python实现```python
MOD = 1_000_000_007
N = 2000

# Maximum possible abstraction depth.
# Every abstraction costs 5 symbols.
MAX_M = N // 5 + 5

# dp[m][n] = number of alpha-equivalence classes
# of exact size n with free variables among m binders
dp = [[0] * (N + 1) for _ in range(MAX_M + 2)]

# Compute from large m downward because dp[m]
# depends on dp[m+1]
for m in range(MAX_M, -1, -1):

    # Variable terms
    dp[m][1] = m

    # Larger sizes
    for n in range(2, N + 1):

        total = 0

        # Abstraction contribution
        if n >= 5:
            total += dp[m + 1][n - 5]

        # Application contribution
        # (A B) has size |A| + |B| + 2
        for left_size in range(1, n - 2):
            right_size = n - 2 - left_size
            total += dp[m][left_size] * dp[m][right_size]

        dp[m][n] = total % MOD

# Lambda(N) = cumulative count of closed terms
answer = sum(dp[0][:N + 1]) % MOD

print(answer)
```---

 # 3. 代码演练

 ## 表定义```python
dp[m][n]
```存储精确大小的项数$n$至多$m$可访问的粘合剂。 

---

 ## 变量大小写```python
dp[m][1] = m
```变量可以是以下任意一个$m$绑定变量。 

---

 ## 抽象案例```python
total += dp[m + 1][n - 5]
```一个抽象消耗 5 个符号并引入一个额外的绑定器。 

---

 ## 应用案例```python
for left_size in range(1, n - 2):
```因为application贡献了2个括号，$$|A|+|B| = n-2.$$每对贡献$$T_m(|A|)\cdot T_m(|B|).$$---

 ## 最终积累```python
answer = sum(dp[0][:N + 1]) % MOD
```封闭项正是那些最初没有可用的自由变量的项，即$m=0$。
