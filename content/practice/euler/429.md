[欧拉项目 429 问题](https://projecteuler.net/problem=429)

 ## 解决方案

 **答案：**`98792821`让$$n! = \prod_{p \le n} p^{e_p}$$在哪里$$e_p = \sum_{k\ge1}\left\lfloor \frac{n}{p^k}\right\rfloor$$由勒让德公式计算。 

**酉除数**$d$的$n!$必须满足$$\gcd(d,n!/d)=1.$$由于素因数分解$n!$对于每个素数都是唯一的$p^{e_p}$，酉除数要么取**整个因数**$p^{e_p}$或**都没有**。 仅取部分指数将使 gcd 变得不平凡。 

因此每个酉除数的形式为$$d=\prod_{p\le n} p^{\varepsilon_p e_p}, \qquad \varepsilon_p\in\{0,1\}.$$我们想要平方和：$$S(n!) = \sum_{d \text{ unitary}} d^2.$$因为选择在素数之间是独立的，所以这个因素是乘法的：$$S(n!) = \prod_{p\le n} \left(1+p^{2e_p}\right).$$所以对于$n=100\,000\,000$,$$S(100000000!) = \prod_{p\le 100000000} \left(1+p^{2e_p}\right) \pmod{1000000009}.$$我们计算：

 1. 生成所有素数$p\le 10^8$通过筛子。 
2. 对于每个素数，计算$e_p$使用勒让德公式。 
3. 乘法$$(1+p^{2e_p}) \bmod 1000000009$$进入正在运行的产品。 

Python实现：```python
from math import isqrt

MOD = 1_000_000_009
N = 100_000_000

# Sieve of Eratosthenes
is_prime = bytearray(b'\x01') * (N + 1)
is_prime[0:2] = b'\x00\x00'

for i in range(2, isqrt(N) + 1):
    if is_prime[i]:
        is_prime[i * i : N + 1 : i] = (
            b'\x00' * (((N - i * i) // i) + 1)
        )

primes = [p for p in range(2, N + 1) if is_prime[p]]

result = 1

for p in primes:
    # Legendre exponent of p in N!
    e = 0
    m = N
    while m:
        m //= p
        e += m

    result = (result * (1 + pow(p, 2 * e, MOD))) % MOD

print(result)
```小支票：

 **答案：98792821**
