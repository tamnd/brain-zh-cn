[欧拉项目问题 10](https://projecteuler.net/problem=10)

 ## 解决方案

 为了有效地解决这个问题，我们需要所有素数的总和小于$2{,}000{,}000$。 

对每个数字直接进行素性测试会太慢。 标准方法是**埃拉托色尼筛**，它将每个素数的倍数标记为合数。 

想法：

 1. 创建布尔数组`is_prime`从`0`到`1,999,999`。 
2. 最初假设所有数字$\ge 2$是素数。 
3. 对于每个素数$p$, 标记所有的倍数$p$开始于$p^2$作为非素数。 
4. 对所有剩余的素数指数求和。 

复杂度约为$O(n \log \log n)$，这对于 200 万来说足够快了。 

Python代码：```python
limit = 2_000_000

is_prime = [True] * limit
is_prime[0] = is_prime[1] = False

p = 2
while p * p < limit:
    if is_prime[p]:
        for multiple in range(p * p, limit, p):
            is_prime[multiple] = False
    p += 1

total = sum(i for i, prime in enumerate(is_prime) if prime)

print(total)
```追踪小例子的正确性：

 下面的素数$10$是：$$2,3,5,7$$他们的总和是：$$2+3+5+7=17$$与声明相符。
