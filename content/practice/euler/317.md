[项目欧拉问题 317](https://projecteuler.net/problem=317)

 ## 解决方案

 **答案：**`1856532.8455`让爆炸发生在高空$h=100$距地面 米，所有碎片均高速发射$$v_0 = 20 \text{ m/s}$$在重力作用下$$g = 9.81 \text{ m/s}^2.$$我们需要至少一个碎片在撞击地面之前到达的空间中所有点的体积。 

---

 # 1.数学分析

 使用速度分量发射的片段$(v_x,v_y,v_z)$满足$$v_x^2+v_y^2+v_z^2=v_0^2.$$因为问题是绕垂直轴旋转对称的，所以我们使用柱坐标：

 -$r=\sqrt{x^2+y^2}$-$z$垂直高度。 

让：

-$u$= 水平速度，
 -$w$= 垂直速度，

 这样$$u^2+w^2=v_0^2.$$射弹方程为$$r = ut,$$

$$z = h + wt - \frac12 gt^2.$$排除$u$使用$u=r/t$:$$\left(\frac{r}{t}\right)^2 + w^2 = v_0^2.$$还，$$w=\frac{z-h+\frac12 gt^2}{t}.$$代替：$$\frac{r^2}{t^2} + \left(\frac{z-h+\frac12 gt^2}{t}\right)^2 = v_0^2.$$乘以$t^2$：$$r^2 + \left(z-h+\frac12 gt^2\right)^2 = v_0^2 t^2.$$我们寻求，为每一个$(r,z)$，是否存在$t>0$满足这一点。 

---

 ## 可达点的包络线

 定义$$A=z-h.$$然后$$r^2 + \left(A+\frac12 gt^2\right)^2 = v_0^2 t^2.$$扩张：$$r^2 + A^2 + Ag t^2 + \frac14 g^2 t^4 = v_0^2 t^2.$$让$s=t^2$：$$\frac14 g^2 s^2 + (Ag-v_0^2)s + (A^2+r^2)=0.$$可达性需要真正的解决方案$s\ge0$。 因此判别式必须满足$$(Ag-v_0^2)^2 - g^2(A^2+r^2)\ge0.$$扩张：$$A^2g^2 - 2Agv_0^2 + v_0^4 - g^2A^2 - g^2r^2 \ge 0.$$这$A^2g^2$条款取消：$$v_0^4 - 2Agv_0^2 - g^2r^2 \ge 0.$$记起$A=z-h$：$$g^2r^2 \le v_0^4 - 2g v_0^2(z-h).$$求解$z$：$$z \le h + \frac{v_0^2}{2g} - \frac{g r^2}{2v_0^2}.$$这是一个抛物面。 

因此整个可达区域是下面的实体$$z(r)=H-\alpha r^2$$在哪里$$H=h+\frac{v_0^2}{2g}, \qquad \alpha=\frac{g}{2v_0^2}.$$该区域结束于$z=0$：$$0=H-\alpha R^2$$所以$$R^2=\frac{H}{\alpha}.$$---

 # 2.体积计算

 旋转体的体积是$$V=\int_0^R \pi r^2\,dz$$或者更直接$$V=2\pi\int_0^R r(H-\alpha r^2)\,dr.$$计算：$$V = 2\pi \left[ \frac{H r^2}{2} - \frac{\alpha r^4}{4} \right]_0^R.$$使用$R^2=H/\alpha$,$$V = 2\pi \left( \frac{H(H/\alpha)}{2} - \frac{\alpha(H/\alpha)^2}{4} \right).$$简化：$$V = 2\pi \left( \frac{H^2}{2\alpha} - \frac{H^2}{4\alpha} \right) = \frac{\pi H^2}{2\alpha}.$$自从$$\alpha=\frac{g}{2v_0^2},$$我们得到$$V = \pi H^2\frac{v_0^2}{g}.$$现在插入值：$$H = 100+\frac{20^2}{2\cdot 9.81} = 100+\frac{400}{19.62} = 120.3873598369\ldots$$因此$$V = \pi \cdot H^2 \cdot \frac{400}{9.81}.$$---

 # 3.Python实现```python
import math

# Given constants
h = 100.0
v0 = 20.0
g = 9.81

# Maximum height of the envelope paraboloid
H = h + v0**2 / (2 * g)

# Volume formula derived analytically
V = math.pi * H**2 * (v0**2 / g)

# Print rounded to 4 decimal places
print(f"{V:.4f}")
```---
