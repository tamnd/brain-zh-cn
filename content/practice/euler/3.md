[欧拉项目问题 3](https://projecteuler.net/problem=3)

 ## 解决方案

 我们想要最大的质因数$$600851475143$$标准方法是重复试除：

 - 开始除以最小的质数$2$。 
- 每当除数$d$划分$n$, 除$n$经过$d$反复。 
- 增加$d$并继续直到$d^2 > n$。 
- 剩余价值$n$那么就是最大的素因数。 

这是有效的，因为每个复合因子都有一个已经测试过的较小因子。 

Python代码：```python
n = 600851475143
factor = 2
largest = 1

while factor * factor <= n:
    while n % factor == 0:
        largest = factor
        n //= factor
    factor += 1

if n > 1:
    largest = n

print(largest)
```追踪因式分解：$$600851475143 = 71 \times 839 \times 1471 \times 6857$$所有这些都是素数，所以最大的素因数是：

 **答案：6857**
