[欧拉项目问题 326](https://projecteuler.net/problem=326)

 ## 解决方案

 **答案：**`1966666166408794329`让$$S_n=\sum_{k=1}^n k a_k.$$复发率是$$a_n=S_{n-1}\pmod n.$$我们想要$$f(N,M)=\#\{(p,q):1\le p\le q\le N,\ \sum_{i=p}^q a_i\equiv0\pmod M\}.$$标准的前缀和技巧将其转换为计数问题。 

定义$$B_n=\sum_{i=1}^n a_i,\qquad B_0=0.$$然后$$\sum_{i=p}^q a_i = B_q-B_{p-1},$$所以条件是$$B_q\equiv B_{p-1}\pmod M.$$因此如果有一个残基$r$发生$c_r$次之间$$B_0,B_1,\dots,B_N \pmod M,$$那么它就贡献了$\binom{c_r}{2}$有效对。 所以$$f(N,M)=\sum_{r=0}^{M-1}\binom{c_r}{2}.$$所以整个问题归结为理解序列$a_n$。 

---

 # 1. 推导结构$a_n$我们计算几个项：$$1,1,0,3,0,3,5,4,1,9,1,6,9,7,2,15,\dots$$一个强大的$6$- 术语模式出现。 

我们主张：$$\boxed{ \begin{aligned} a_{6m+1}&=4m+1,\\ a_{6m+2}&=3m+1,\\ a_{6m+3}&=m,\\ a_{6m+4}&=6m+3,\\ a_{6m+5}&=m,\\ a_{6m+6}&=3m+3. \end{aligned}}$$这可以通过定义递归的归纳来证明。 

---

 ## 计算前缀和$B_n$对一整块求和：$$(4m+1)+(3m+1)+m+(6m+3)+m+(3m+3)=18m+8.$$因此$$B_{6m} =\sum_{j=0}^{m-1}(18j+8) =9m^2-m.$$在一个块内：$$\boxed{ \begin{aligned} B_{6m} &= 9m^2-m,\\ B_{6m+1} &= 9m^2+3m+1,\\ B_{6m+2} &= 9m^2+6m+2,\\ B_{6m+3} &= 9m^2+7m+2,\\ B_{6m+4} &= 9m^2+13m+5,\\ B_{6m+5} &= 9m^2+14m+5. \end{aligned}}$$这些公式是准确的。 

---

 # 2. 周期模$M$减少模数$M$。 

为了$m\mapsto m+M$,$$9(m+M)^2-(m+M)\equiv 9m^2-m \pmod M,$$and similarly for all six residue classes.

 所以：$$B_{n+6M}\equiv B_n\pmod M.$$所以顺序$B_n\bmod M$有月经$6M$。 

对于这个问题：$$M=10^6,\qquad P=6M=6\cdot10^6.$$---

 # 3. 计数残基

 让$$N=qP+r.$$然后是第一个$q$完整的周期贡献相等，我们只需要一个额外的部分块。 

对于每个残基$x\in[0,M-1]$， 让$c_x$是其总频率$$B_0,B_1,\dots,B_N.$$最后：$$f(N,M)=\sum_x \frac{c_x(c_x-1)}2.$$---

 # 4.Python实现```python
from collections import defaultdict

def F(N, M):
    P = 6 * M

    # Count residues in one full period
    period_count = [0] * M

    for m in range(M):
        base = (9 * m * m - m) % M

        vals = [
            base,
            (base + 4 * m + 1) % M,
            (base + 7 * m + 2) % M,
            (base + 8 * m + 2) % M,
            (base + 14 * m + 5) % M,
            (base + 15 * m + 5) % M,
        ]

        for v in vals:
            period_count[v] += 1

    q, r = divmod(N, P)

    # Total counts
    total = [q * c for c in period_count]

    # Add the remaining prefix terms
    full_blocks = r // 6
    rem = r % 6

    for m in range(full_blocks + 1):
        base = (9 * m * m - m) % M

        vals = [
            base,
            (base + 4 * m + 1) % M,
            (base + 7 * m + 2) % M,
            (base + 8 * m + 2) % M,
            (base + 14 * m + 5) % M,
            (base + 15 * m + 5) % M,
        ]

        limit = 6 if m < full_blocks else rem + 1

        for i in range(limit):
            total[vals[i]] += 1

    # Count equal pairs
    ans = 0
    for c in total:
        ans += c * (c - 1) // 2

    return ans

print(F(10, 10))         # 4
print(F(10**4, 10**3))   # 97158
print(F(10**12, 10**6))
```---

### 步骤 2

### 步骤 4
