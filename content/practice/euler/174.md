[欧拉项目问题 174](https://projecteuler.net/problem=174)

 ## 解决方案

 **答案：**`209566`让外面的正方形有边长$a$内部正方形（“孔”）有边长$b$， 在哪里：

-$a>b$,
 - 两个正方形都居中，
 - 边框厚度是积分。 

这迫使$a$和$b$具有相同的奇偶性。 

层板中的瓷砖数量为$$t=a^2-b^2.$$我们想要计算每个$t\le 10^6$，有多少个不同的薄片产生$t$。 

如果确切地说$n$不同的层产生$t$， 然后$t$是类型$L(n)$。 

我们被要求$$\sum_{n=1}^{10} N(n),$$在哪里$N(n)$数数有多少个$t\le 10^6$是类型$L(n)$。 

---

 # 数学分析

 ## 1.重写瓦片公式

 自从$a$和$b$具有相同的奇偶性，写$$a=b+2k, \qquad k\ge1.$$然后$$t=a^2-b^2=(a-b)(a+b).$$代替$a-b=2k$:$$t=(2k)(2b+2k)=4k(b+k).$$另一种非常有用的形式来自直接扩展：$$t = 4m(m+d),$$但最简洁的计数解释是：$$t=(a-b)(a+b),$$其中两个因子都是偶数。 

定义$$u=\frac{a-b}{2}, \qquad v=\frac{a+b}{2}.$$然后$$t=4uv,$$带整数$$u\ge1,\qquad v>u.$$因此，每个层完全对应于因式分解$$\frac{t}{4}=uv$$和$u<v$。 

所以不同层的数量$t$等于因子对的数量$t/4$。 

---

 ## 2. 直接构造计数

 更具算法性的方法更简单、更快。 

固定外侧长度$a$。 

可能的内部正方形是$$b=a-2,\ a-4,\ a-6,\dots,\ge1.$$对于每对：$$t=a^2-b^2.$$我们分别数数多少次$t\le10^6$发生。 

### 限制搜索

 外部尺寸最薄的薄片$a$用途：$$a^2-(a-2)^2 = 4a-4.$$要求$$4a-4\le10^6$$所以$$a\le250001.$$生成的薄片总数是可控的（大约几百万）。 

---

 # Python 实现```python
LIMIT = 1_000_000

# ways[t] = number of distinct laminae using exactly t tiles
ways = [0] * (LIMIT + 1)

# Outer square side length
outer = 3

while True:
    # Smallest lamina for this outer size
    smallest = outer * outer - (outer - 2) * (outer - 2)

    if smallest > LIMIT:
        break

    # Try all valid inner squares
    inner = outer - 2

    while inner >= 1:
        tiles = outer * outer - inner * inner

        if tiles > LIMIT:
            break

        ways[tiles] += 1
        inner -= 2

    outer += 1

# Count t whose type is L(1) through L(10)
answer = sum(1 for t in range(LIMIT + 1) if 1 <= ways[t] <= 10)

print(answer)
```---

 # 代码演练

 ## 初始化```python
LIMIT = 1_000_000
ways = [0] * (LIMIT + 1)
```我们存储每块瓷砖的数量$t$，有多少个不同的薄片产生它。 

---

 ## 外方循环```python
outer = 3
```最小可能的外部正方形是$3\times3$，因为我们至少需要一个$1\times1$洞。 

---

 ## 停止条件```python
smallest = outer * outer - (outer - 2) * (outer - 2)
```这是最薄的边框（宽度$1$）。 

如果甚至超过了限制，则更大的外部方块将无法工作。 

---

 ## 内部方形循环```python
inner = outer - 2
```内侧和外侧必须具有相同的奇偶性，因此我们每一步减少 2。 

---

 ## 瓷砖数量```python
tiles = outer * outer - inner * inner
```恰好是边框瓷砖的数量。 

---

 ## 记录一层```python
ways[tiles] += 1
```每个有效$(outer, inner)$一对形成一个不同的叶片。 

---

 ## 最终计数```python
answer = sum(1 for t in range(LIMIT + 1) if 1 <= ways[t] <= 10)
```这算全部$t$那些是类型$L(1)$通过$L(10)$。 

---

 # 检查示例

 ## 示例：$t=8$

$$3^2-1^2=9-1=8.$$仅存在一层。 

所以$8$是类型$L(1)$。 

正确的。 

- -

＃＃ 例子：$t=32$两种表示：$$6^2-2^2 = 36-4 = 32,$$和$$5^2-1^2 = 25-1 = 24$$哎呀——不是 32。正确的第二个是$$9^2-7^2 = 81-49 = 32.$$所以正好有两个薄片$32$，使其类型$L(2)$。 

正确的。
