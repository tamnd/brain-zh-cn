[项目欧拉问题 340](https://projecteuler.net/problem=340)

 ## 解决方案

 **答案：**`291504964`让$$F(n)= \begin{cases} n-c & n>b\\[4pt] F(a+F(a+F(a+F(a+n)))) & n\le b \end{cases}$$和$$S(a,b,c)=\sum_{n=0}^{b}F(n).$$我们需要：$$S(21^7,7^{21},12^7)$$模数$10^9$。 

## 1.数学分析

 定义$$d=a-c.$$自从$a>c$，我们有$d>0$。 

为了$n>b$,$$F(n)=n-c=n-d-a+a.$$关键是要了解会发生什么$n\le b$。 

### 第 1 步：分区$n$分成块

 让$$k=\left\lfloor \frac{b-n}{a}\right\rfloor.$$这意味着$n$在于$k$从顶部开始的第 - 个块：$$b-(k+1)a < n \le b-ka.$$我们主张：$$F(n)=n+D_k$$对于依赖于块的常数$D_k$。 

---

 ### 步骤 2：基本情况 ($k=0$）

如果$b-a<n\le b$， 然后$a+n>b$， 所以：$$F(a+n)=a+n-c=n+d.$$那么每个剩余的嵌套参数都已经是$>b$，因此每个外部应用程序减去另一个$c$：$$F(n) = n+d+d+d+d = n+4(a-c).$$因此$$D_0=4a-4c.$$---

 ### 步骤 3：重复$D_k$认为$n$处于块中$k\ge1$。 然后$a+n$位于块中$k-1$，因此通过归纳法：$$F(a+n) = (a+n)+D_{k-1}.$$之后，剩下的三个外部应用程序都在$>b$制度，每个人都做出贡献$+d$。 因此：$$D_k = a+D_{k-1}+3d.$$自从$d=a-c$,$$D_k = D_{k-1}+4a-3c.$$和$$D_0=4a-4c,$$这解决了：$$D_k = (k+1)(4a-3c)-c.$$所以：$$\boxed{ F(n) = n+(k+1)(4a-3c)-c }$$在哪里$$k=\left\lfloor \frac{b-n}{a}\right\rfloor.$$---

 ### 步骤 4：求和

 让$$b=qa+r, \qquad 0\le r<a.$$然后：

 - 块$k=0,\dots,q-1$每个都包含准确的$a$价值观，
 - 块$k=q$包含$r+1$价值观。 

还，$$\sum_{n=0}^{b} n = \frac{b(b+1)}{2}.$$让$$T=4a-3c.$$自从$$D_k=(k+1)T-c,$$总偏移量是$$a\sum_{k=0}^{q-1}\big((k+1)T-c\big) + (r+1)\big((q+1)T-c\big).$$使用$$\sum_{j=1}^{q}j=\frac{q(q+1)}{2},$$我们得到$$S(a,b,c) = \frac{b(b+1)}{2} + a\left( T\frac{q(q+1)}{2} -cq \right) + (r+1)\big((q+1)T-c\big).$$---

 ## 2.Python实现```python
def crazy_sum(a, b, c):
    # Divide b into full blocks of size a
    q, r = divmod(b, a)

    # Constant increment per block
    T = 4 * a - 3 * c

    # Sum of n from 0 to b
    total = b * (b + 1) // 2

    # Contribution from full blocks
    full_blocks = a * (
        T * q * (q + 1) // 2 - c * q
    )

    # Contribution from the final partial block
    final_block = (r + 1) * (
        (q + 1) * T - c
    )

    return total + full_blocks + final_block

# Example check
print(crazy_sum(50, 2000, 40))
# 5204240

# Required problem
a = 21 ** 7
b = 7 ** 21
c = 12 ** 7

answer = crazy_sum(a, b, c) % (10 ** 9)
print(answer)
```---

 ## 3. 代码演练

 ###`divmod(b, a)`分裂$b$进入：$$b=qa+r$$所以我们知道有多少个完整的宽度块$a$存在。 

###`T = 4*a - 3*c`这是块偏移算术级数中的步长：$$D_k=(k+1)T-c.$$###`total`添加基础贡献$$\sum n=\frac{b(b+1)}{2}.$$###`full_blocks`对所有完整块的偏移量求和：$$a\sum_{k=0}^{q-1}D_k.$$###`final_block`添加剩余的部分大小块$r+1$。 

---

 对于$$(a,b,c)=(50,2000,40)$$代码返回：$$5204240$$与问题陈述完全匹配。
