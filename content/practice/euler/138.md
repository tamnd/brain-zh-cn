[欧拉计划问题 138](https://projecteuler.net/problem=138)

 ## 解决方案

 **答案：**`1118049290473932`设等腰三角形有：

 - 基地$b$,
 - 等边$L$，
- 高度$h$,

 与条件$$h=b\pm1.$$因为高平分底边，所以我们得到一个有腿的直角三角形$h$和$b/2$, 斜边$L$:$$L^2=h^2+\left(\frac b2\right)^2.$$我们寻找整数的所有整数解$b,L$。 

---

 # 1.数学分析

 套装$$b=2x,$$因为底座必须是均匀的。 然后$$L^2=h^2+x^2.$$条件$h=b\pm1$变成$$h=2x\pm1.$$代替：$$L^2 = x^2 + (2x\pm1)^2.$$展开给出$$L^2 = x^2 + 4x^2 \pm 4x +1      = 5x^2 \pm 4x +1.$$所以我们必须解决$$L^2 = 5x^2 \pm 4x +1.$$---

 ## 转换为佩尔方程

 乘以$5$:$$5L^2 = 25x^2 \pm 20x +5.$$注意$$(5x\pm2)^2 = 25x^2 \pm 20x +4.$$因此$$5L^2 = (5x\pm2)^2 +1,$$所以$$(5x\pm2)^2 - 5L^2 = -1.$$定义$$y = 5x\pm2.$$然后我们得到佩尔方程$$y^2 - 5L^2 = -1.$$这是关键的见解。 

---

 ## 解决方案的结构

 根本解决办法是$$y^2-5L^2=-1$$是$$(2,1).$$所有解都是从 的幂递归生成的$$9+4\sqrt5,$$或等效地通过递归关系。 

前几个$(y,L)$解决方案是：$$(2,1), (38,17), (682,305), (12238,5473), \dots$$抛弃琐碎$L=1$，我们准确地得到了问题中描述的三角形：

 -$L=17$,
 -$L=305$,
 - 等

 ---

 ## 简单递归

 的$L$- 值满足$$L_n = 18L_{n-1} - L_{n-2}.$$开始于$$L_1=1,\qquad L_2=17.$$通过这种递归，可以快速生成十二个非平凡的解决方案。 

---

 # 2.Python实现```python
# Project Euler 138
# Sum of the first 12 isosceles triangle side lengths L
# satisfying h = b ± 1.

def solve():
    # Recurrence for Pell-generated solutions
    # L_n = 18*L_(n-1) - L_(n-2)

    L_prev = 1
    L_curr = 17

    total = 0
    count = 0

    while count < 12:
        total += L_curr

        # Generate next solution
        L_next = 18 * L_curr - L_prev
        L_prev, L_curr = L_curr, L_next

        count += 1

    return total

print(solve())
```---
