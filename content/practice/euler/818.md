[欧拉项目 818 问题](https://projecteuler.net/problem=818)

 ## 解决方案

 **答案：**`11871909492066000`将甲板建模为仿射空间$\mathbb F_3^4$，其中每张卡都是 4 元组$\{0,1,2\}$。 

SET 恰好是满足以下条件的三个点的仿射线$$a+b+c=0 \pmod 3.$$有$1080$SET（仿射线）。 扩展$$S(C_n)^4$$轮流$F(n)$对有序 4 元组的 SET 进行计数。 如果 SET 的 4 元组具有联合大小$k$，那么它恰好包含在$$\binom{81-k}{n-k}$$不同的$n$-卡片收藏。 

因此$$F(n)=\sum_{k=3}^{12} A_k \binom{81-k}{n-k},$$在哪里$A_k$是 SET 的有序 4 元组的数量，其并集恰好包含$k$牌。 

使用有序线对的对称类$AG(4,3)$（同线、相交、平行不相交、倾斜不相交）$A_k$可以通过位集枚举有效地计算值。 计算重现给定的检查：$$F(3)=1080,\qquad F(6)=159690960.$$评估为$n=12$给出：
