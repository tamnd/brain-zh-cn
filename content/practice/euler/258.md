[欧拉项目问题 258](https://projecteuler.net/problem=258)

 ## 解决方案

 **答案：**`12747994`让$$g_k = \begin{cases} 1,&0\le k\le 1999,\\[4pt] g_{k-2000}+g_{k-1999},&k\ge 2000. \end{cases}$$我们必须计算$$g_{10^{18}} \pmod{20092010}.$$---

 # 1.数学分析

 这是顺序的线性递推$2000$。 

定义特征关系：$$g_n-g_{n-1999}-g_{n-2000}=0.$$因此特征多项式是$$P(x)=x^{2000}-x-1.$$线性递推的关键事实是：

 > 每学期$g_n$可以表示为第一个的线性组合$2000$条款。 

由于所有初始值都是$$g_0=g_1=\cdots=g_{1999}=1,$$如果我们可以计算系数$x^n$对特征多项式取模$P(x)$，那么答案就是这些系数的总和。 

---

 ## 多项式观点

 商环内$$\mathbb Z_m[x]/(x^{2000}-x-1),$$我们有归约规则$$x^{2000}\equiv x+1.$$因此任何力量$x^n$可以简化为多项式$<2000$:$$x^n \equiv \sum_{i=0}^{1999} c_i x^i.$$然后$$g_n=\sum_{i=0}^{1999} c_i g_i.$$但每一个$g_i=1$， 所以$$g_n=\sum_{i=0}^{1999} c_i.$$因此任务减少为：

 1. 计算$x^{10^{18}} \bmod (x^{2000}-x-1)$。 
2.对其系数求模求和$20092010$。 

---

 # 2.高效算法

 我们对多项式使用二进制求幂。 

当两个多项式相乘时，次数可以达到$3998$。 

每当一个术语$x^d$和$d\ge 2000$出现，减少使用$$x^{2000}\equiv x+1.$$因此$$x^d = x^{d-2000}x^{2000} \equiv x^{d-1999}+x^{d-2000}.$$这给出了一个$O(K^2\log n)$算法与$K=2000$，这很容易足够快。 

---

 # 3.Python实现```python
MOD = 20092010
K = 2000
N = 10**18

def combine(a, b):
    """
    Multiply two polynomials modulo:
        x^2000 - x - 1
    Result has degree < 2000.
    """
    tmp = [0] * (2 * K - 1)

    # Ordinary polynomial multiplication
    for i, ai in enumerate(a):
        if ai:
            for j, bj in enumerate(b):
                if bj:
                    tmp[i + j] = (tmp[i + j] + ai * bj) % MOD

    # Reduce high-degree terms using:
    # x^2000 = x + 1
    for d in range(2 * K - 2, K - 1, -1):
        v = tmp[d]
        if v:
            tmp[d - K] = (tmp[d - K] + v) % MOD
            tmp[d - K + 1] = (tmp[d - K + 1] + v) % MOD

    return tmp[:K]

def power_x(n):
    """
    Compute x^n modulo the characteristic polynomial.
    Return coefficients of degree < 2000 polynomial.
    """

    # res = 1
    res = [1] + [0] * (K - 1)

    # base = x
    base = [0, 1] + [0] * (K - 2)

    while n > 0:
        if n & 1:
            res = combine(res, base)

        base = combine(base, base)
        n >>= 1

    return res

# coefficients for x^N
coeffs = power_x(N)

# since g_0 ... g_1999 are all 1,
# g_N is the sum of coefficients
answer = sum(coeffs) % MOD

print(answer)
```---

 # 4. 代码演练

 ##`combine(a, b)`该函数将两个简化多项式相乘。 

第一的：```python
tmp[i + j] += ai * bj
```执行普通多项式乘法。 

然后我们减少度项$\ge 2000$。 

自从$$x^{2000} \equiv x+1,$$我们替换$$x^d \equiv x^{d-1999}+x^{d-2000}.$$所以系数`v`的$x^d$分发给：```python
tmp[d - K]
tmp[d - K + 1]
```对应于$$x^{d-2000},\quad x^{d-1999}.$$---

 ##`power_x(n)`这计算$$x^n \bmod (x^{2000}-x-1)$$使用二进制求幂。 

-`res`开始为$1$-`base`开始为$x$每当一个二进制位$n$已设置：```python
res = combine(res, base)
```然后每一步将底座摆正。
