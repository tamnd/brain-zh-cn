[欧拉项目 668 问题](https://projecteuler.net/problem=668)

 ## 解决方案

 **答案：**`2811077773`让$P(n)$表示最大素因数$n$（和$P(1)$未定义，但是$1$根据定义被声明为平方根平滑）。 

一个数字$n$是平方根平滑当且仅当每个质因数都严格小于$\sqrt n$。 

等价地，$$P(n)<\sqrt n$$或者$$P(n)^2<n.$$我们想要整数的个数$n\le 10^{10}$满足这一点。 

---

 # 1.数学分析

 ## 步骤 1：表征补集

 计算**不**平方根平滑的数字会更容易。 

一个数字$n>1$**不是** 平方根平滑 iff$$P(n)\ge \sqrt n.$$写$$n = pk,$$在哪里$p=P(n)$是最大的质因数。 

然后$$p \ge \sqrt n \quad\Longrightarrow\quad p^2 \ge n = pk \quad\Longrightarrow\quad p \ge k.$$所以每个非光滑数都有一个唯一的表示$$n = pk$$和：

-$p$主要的，
-$k \le p$,
 -$pk \le x$。 

相反，每个这样的对都会产生一个非平滑数，因为$p$是一个素因数并且$$p \ge k \;\Rightarrow\; p^2 \ge pk=n \;\Rightarrow\; p\ge \sqrt n.$$因此，非光滑数与对成双射$$(p,k)$$这样$$p \text{ prime},\qquad k\le p,\qquad pk\le x.$$---

 ## 第二步：计算补码

 修复$k$。 

然后$p$必须满足$$k \le p \le \frac{x}{k}.$$所以有效素数的个数是$$\pi\!\left(\frac{x}{k}\right)-\pi(k-1),$$在哪里$\pi(n)$是素数计数函数。 

还有，必然$k\le \sqrt x$， 否则$k^2>x$。 

因此非光滑整数的数量是$$N(x) = \sum_{k\le \sqrt x} \left( \pi\!\left(\frac{x}{k}\right)-\pi(k-1) \right).$$因此所需的计数是$$S(x)=x-N(x).$$所以：$$\boxed{ S(x) = x- \sum_{k\le \sqrt x} \left( \pi\!\left(\frac{x}{k}\right)-\pi(k-1) \right) }$$和$x=10^{10}$。 

---

 ## 步骤 3：检查示例$x=100$使用公式：$$N(100) = \sum_{k=1}^{10} \left( \pi(100/k)-\pi(k-1) \right) =71.$$因此$$S(100)=100-71=29,$$匹配问题陈述。

 # 2.Python实现```python
from functools import lru_cache
from math import isqrt

# ------------------------------------------------------------
# Sieve for small primes
# ------------------------------------------------------------

LIMIT = 5_000_000

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(LIMIT) + 1):
    if sieve[i]:
        sieve[i * i : LIMIT + 1 : i] = b"\x00" * (
            ((LIMIT - i * i) // i) + 1
        )

primes = [i for i, v in enumerate(sieve) if v]

# pi_small[n] = number of primes <= n
pi_small = [0] * (LIMIT + 1)

count = 0
for i in range(LIMIT + 1):
    if sieve[i]:
        count += 1
    pi_small[i] = count

# ------------------------------------------------------------
# Lehmer prime counting function
# Computes pi(n) quickly for large n
# ------------------------------------------------------------

@lru_cache(None)
def phi(x, s):
    """Count integers <= x not divisible by first s primes."""
    if s == 0:
        return x
    return phi(x, s - 1) - phi(x // primes[s - 1], s - 1)

@lru_cache(None)
def pi(n):
    """Lehmer prime counting function."""
    if n <= LIMIT:
        return pi_small[n]

    a = pi(int(n ** 0.25))
    b = pi(isqrt(n))
    c = pi(int(n ** (1 / 3)))

    # Main Lehmer formula
    result = phi(n, a) + ((b + a - 2) * (b - a + 1)) // 2

    for i in range(a + 1, b + 1):
        p = primes[i - 1]
        w = n // p

        result -= pi(w)

        if i <= c:
            bi = pi(isqrt(w))

            for j in range(i, bi + 1):
                result -= pi(w // primes[j - 1]) - (j - 1)

    return result

# ------------------------------------------------------------
# Count square-root smooth numbers
# ------------------------------------------------------------

def square_root_smooth_count(x):
    root = isqrt(x)

    non_smooth = 0

    for k in range(1, root + 1):
        non_smooth += pi(x // k) - pi(k - 1)

    return x - non_smooth

# ------------------------------------------------------------
# Compute the Project Euler answer
# ------------------------------------------------------------

x = 10_000_000_000

answer = square_root_smooth_count(x)

print(answer)
```---

 # 3. 代码演练

 ## 筛分部分

 我们首先生成所有素数$5\times10^6$使用埃拉托斯特尼筛法。```python
sieve = bytearray(...)
```存储原始性。 

我们还建造：```python
pi_small[n]
```这给出了$\pi(n)$立即为小$n$。 

---

 ##`phi(x, s)`这个函数计算数字$\le x$不能被第一个整除$s$素数。 

它满足递归：$$\phi(x,s)=\phi(x,s-1)-\phi\!\left(\left\lfloor \frac{x}{p_s}\right\rfloor,s-1\right).$$这是莱默素数计数算法的标准成分。 

---

 ##`pi(n)`这实现了 Lehmer 素数计数功能。 

它计算$\pi(n)$大致在$O(n^{2/3})$时间，足够快$10^{10}$。 

---

 ## 最终计数循环

 我们使用公式$$N(x) = \sum_{k\le \sqrt x} \left( \pi(x/k)-\pi(k-1) \right).$$实施为：```python
for k in range(1, root + 1):
    non_smooth += pi(x // k) - pi(k - 1)
```然后：```python
return x - non_smooth
```给出平方根平滑整数的数量.

 # 4.最终验证

 对于样本：$$S(100)=29,$$与陈述完全相符。 

为了$10^{10}$，计算出的值为：$$2\,811\,077\,773.$$这是有道理的：

 - 它明显小于$10^{10}$,
 - 但仍然是数十亿，因为许多整数都具有以下所有质因数$\sqrt n$。 

计算结果内部一致，与样本测试相符。
