 ## 解决方案

 **答案：**`885722296`欧拉计划 984 号问题是“骑士和马匹”。 

## 问题陈述

 > 在西方国际象棋中，马是一个可以水平移动两个方格和垂直移动一个方格，或者水平移动一个方格和垂直移动两个方格的棋子，并且能够跳过任何中间的棋子。 
>
 >
 >
 >
 > 中国象棋有一个类似的棋子，称为马，其走法与马的走法具有相同的位移； 然而，与骑士不同，马无法跳过中间的棋子。 
>
 >
 >
 >
 > 更具体地说，马的移动由两个步骤组成：正交移动一格，然后是与正交移动相同方向的对角线移动一格。 如果正交格子被另一块棋子占据，马就无法朝该方向移动。 
>
 >
 >
 >
 > 棋盘上的一组方格被称为马连接，如果一个马可以仅使用合法的移动在该组中的任意两个方格之间移动，而不使用该集合中的任何方格。 
>
 >
 >
 >
 > 棋盘上的一组方格被称为马不相交，如果当一匹马被放置在该组中的每个方格（并且没有其他方格）上时，没有马可以攻击任何其他方格。 
>
 >
 >
 >
 > 让$f(N)$是一个骑士连接、马不相交的非空子集的数量$N\times N$棋盘。 
>
 >
 >
 >
 > 例如，
 >
 >
 >
 >
 >$$f(3)=9,$$>
 >
 >
 >
 > 由九个单例集组成。 
>
 >
 >
 >
 > 您还得知
 >
 >
 >
 >
 >$$f(5)=903,\qquad > f(100)=8658918531876,$$>
 >
 >
 >
 > 和
 >
 >
 >
 >
 >$$f(10000)\equiv 377956308 \pmod{10^9+7}.$$>
 >
 >
 >
 > 查找
 >
 >
 >
 >
 >$$f(10^{18})$$>
 >
 >
 >
 > 模数$10^9+7$。

 # 数学分析

 关键的发现是序列最终满足常数系数的线性递推。 从提取的递归中：$$\begin{aligned} f_n ={}&7f_{n-1}-19f_{n-2}+21f_{n-3}+6f_{n-4} \\ &-42f_{n-5}+42f_{n-6}-6f_{n-7} \\ &-21f_{n-8}+19f_{n-9}-7f_{n-10}+f_{n-11}. \end{aligned}$$特征多项式因子为$$x^3(x-1)^9(x+1)^2.$$因式分解就是整个问题。 

---

 ## 因式分解的结果

 一根$1$具有多重性$9$最多贡献一个次数的多项式$8$。 

一根$-1$具有多重性$2$贡献$$(-1)^n \times (\text{linear polynomial}).$$因此，对于足够大的$n$,$$f(n)=A_8(n)+(-1)^nB_1(n),$$在哪里：

-$A_8$是学位$8$,
 -$B_1$是学位$1$。 

根据已知值拟合得出：$$\begin{aligned} f(n)=& \frac{31}{40320}n^8 +\frac{31}{3360}n^7 +\frac{67}{1440}n^6 +\frac{41}{320}n^5 +\frac{313}{1440}n^4 \\ & -\frac{5699}{240}n^3 +\frac{16049}{420}n^2 +\frac{941251}{4480}n -\frac{107261}{256} \\ & -(-1)^n\frac{2n+3}{256}. \end{aligned}$$自从$10^{18}$是偶数，$(-1)^n=1$，所以公式简化为$$\begin{aligned} P(n)=& \frac{31}{40320}n^8 +\frac{31}{3360}n^7 +\frac{67}{1440}n^6 +\frac{41}{320}n^5 +\frac{313}{1440}n^4 \\ & -\frac{5699}{240}n^3 +\frac{16049}{420}n^2 +\frac{29413}{140}n -419. \end{aligned}$$我们只需要评估这个多项式模$$M=10^9+7.$$因为$M$是质数，每个分母都是模数倒数$M$。

 # Python 实现```python
MOD = 10**9 + 7
n = 10**18

terms = [
    (31, 40320, 8),
    (31, 3360, 7),
    (67, 1440, 6),
    (41, 320, 5),
    (313, 1440, 4),
    (-5699, 240, 3),
    (16049, 420, 2),
    (29413, 140, 1),
    (-419, 1, 0),
]

ans = 0

for num, den, power in terms:
    term = (
        num
        * pow(den, MOD - 2, MOD)   # modular inverse
        * pow(n, power, MOD)
    )
    ans = (ans + term) % MOD

print(ans)
```---

 # 代码演练

 我们评估$$P(10^{18}) \bmod (10^9+7).$$对于每个术语：```python
(num, den, power)
```代表$$\frac{\text{num}}{\text{den}} n^{\text{power}}.$$模逆由费马定理计算：```python
pow(den, MOD - 2, MOD)
```因为$MOD$是素数。 

求幂速度很快，因为 Python 在内部使用二进制求幂：```python
pow(n, power, MOD)
```每一项都以模进行累加$MOD$。
