[项目欧拉问题 590](https://projecteuler.net/problem=590)

 ## 解决方案

 **答案：**`834171904`让$$H(n)=\#\{S\subset \mathbb Z_{>0}:\operatorname{lcm}(S)=n\}$$在哪里$S$是一个**集合**（没有重复），并且让$$L(n)=\operatorname{lcm}(1,2,\dots,n).$$我们寻求$$HL(50000)=H(L(50000)) \pmod{10^9}.$$---

 ## 1.数学分析

 ### 步骤 1：表征有效集

 如果$\operatorname{lcm}(S)=n$, 的每个元素$S$必须划分$n$。 因此，每个有效集合都是除数集合的子集$n$。 

让$D(n)$是以下集合的约数$n$，有尺寸$$\tau(n)=\#D(n).$$的每个非空子集$D(n)$有一些 lcm 划分$n$。 所以：$$2^{\tau(n)}-1 = \sum_{d\mid n} H(d).$$这是一个除数和关系，因此莫比乌斯反演给出：$$H(n) = \sum_{d\mid n} \mu(d)\,2^{\tau(n/d)}.$$自从$\mu(d)=0$除非$d$是无平方的，只有素因子的子集才重要。 

---

 ### 第 2 步：主力形式

 假设$$n=\prod_{i=1}^{r} p_i^{a_i}.$$对于无平方除数$d$，选择素数$p_i$在$d$替换因子$a_i+1$经过$a_i$里面$\tau(n/d)$。 因此$$\tau(n/d) = \prod_{p_i\nmid d}(a_i+1) \prod_{p_i\mid d}a_i.$$因此$$H(n) = \sum_{S\subseteq \{1,\dots,r\}} (-1)^{|S|} 2^{ \left( \prod_{i\notin S}(a_i+1) \prod_{i\in S}a_i \right) }.$$---

 ### 步骤 3：结构$L(50000)$根据定义，$$L(50000) = \prod_{p\le 50000} p^{\lfloor \log_p(50000)\rfloor}.$$所以指数$a_i$是：

 | 指数$a$| 计数|
 | ---| ---|
 | 15 | 15 1 |
 | 9 | 1 |
 | 6 | 1 |
 | 5 | 1 |
 | 4 | 2 |
 | 3 | 5 |
 | 2 | 37 | 37
 | 1 | 5085|

 大量的指数 1 素数是主要的计算挑战。 

---

 ### 步骤 4：模块化缩减技巧

 我们只需要对答案取模$$10^9 = 2^9\cdot 5^9.$$所有指数都是巨大的（$>9$）， 所以$$2^k\equiv 0 \pmod{2^9}.$$对于$5^9$部分，欧拉/卡迈克尔周期性给出：$$2^k \pmod{5^9}$$仅取决于$$k \bmod \lambda(5^9) = 4\cdot 5^8 = 1{,}562{,}500.$$因此我们只需要巨大的指数模$1{,}562{,}500$，使计算变得可行。

 ## 2.Python实现```python
from collections import Counter
import sympy as sp
import numpy as np

MOD = 10**9
EXP_MOD = 1_562_500  # Carmichael modulus for 5^9

def HL(n):
    # Count exponent frequencies in L(n)
    exponent_counts = Counter()

    for p in sp.primerange(1, n + 1):
        a = 0
        power = p
        while power <= n:
            a += 1
            power *= p
        exponent_counts[a] += 1

    # Use the largest multiplicity (a=1 here) as a vectorized dimension
    dominant_a = max(exponent_counts, key=lambda x: exponent_counts[x])
    dominant_count = exponent_counts.pop(dominant_a)

    # Binomial coefficients with alternating signs
    coeffs = [1]
    current = 1
    for k in range(1, dominant_count + 1):
        current = current * (dominant_count - k + 1) // k
        coeffs.append(current % MOD)

    coeffs = np.array(coeffs, dtype=np.int64)

    signs = np.array(
        [1 if k % 2 == 0 else MOD - 1
         for k in range(dominant_count + 1)],
        dtype=np.int64
    )

    coeffs = (coeffs * signs) % MOD

    # Contribution from the dominant exponent type
    dominant_factors = np.array([
        (pow(dominant_a, k, EXP_MOD) *
         pow(dominant_a + 1,
             dominant_count - k,
             EXP_MOD)) % EXP_MOD
        for k in range(dominant_count + 1)
    ], dtype=np.int64)

    # Precompute powers of 2 modulo 1e9
    power2 = np.array([
        pow(2, r, MOD)
        for r in range(EXP_MOD)
    ], dtype=np.int64)

    # Enumerate remaining exponent groups recursively
    remaining = list(exponent_counts.items())
    states = []

    def dfs(i, product_mod, coefficient):
        if i == len(remaining):
            states.append((product_mod % EXP_MOD,
                           coefficient % MOD))
            return

        a, count = remaining[i]

        comb = 1
        pow_a = 1
        pow_b = (a + 1) ** count

        for k in range(count + 1):
            sign = comb if k % 2 == 0 else -comb

            dfs(
                i + 1,
                product_mod * pow_a * pow_b,
                coefficient * sign
            )

            if k < count:
                comb = comb * (count - k) // (k + 1)
                pow_a *= a
                pow_b //= (a + 1)

    dfs(0, 1, 1)

    # Final accumulation
    answer = 0

    for base, coeff in states:
        residues = (base * dominant_factors) % EXP_MOD
        values = power2[residues]

        subtotal = int(np.dot(coeffs, values) % MOD)
        answer = (answer + coeff * subtotal) % MOD

    return answer % MOD

print(HL(4))      # 44
print(HL(50000))  # target
```---

 ## 3. 代码演练

 ### 质数指数提取

 对于每个素数$p\le n$，我们计算$$a=\lfloor \log_p(n)\rfloor$$通过反复相乘$p$。 

这构建了素功率因数分解$L(n)$。 

---

 ### 对相同的指数进行分组

 而不是全部治疗$5133$素数分开，我们按指数对它们进行分组$a$。 

对于指数$a$出现$c$时代，我们总结选择$k$包含-排除子集中的那些素数：$$\binom{c}{k}(-1)^k.$$这极大地减少了搜索空间。 

---

 ### 模指数约简

 由于仅$$2^e \pmod{10^9}$$重要的是，我们减少$e$模数$$1{,}562{,}500.$$这避免了直接处理天文数字般的大指数。 

---

 ### 小例子验证

 对于$n=4$:$$L(4)=12.$$程序返回：$$HL(4)=44,$$与问题陈述完全匹配。 

---
