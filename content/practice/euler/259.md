[欧拉项目问题 259](https://projecteuler.net/problem=259)

 ## 解决方案

 **答案：**`20101196798`让数字成为字符串$$123456789$$并假设我们递归地构建从任何连续的数字块中可以获得的每个值。 

关键的观察是：

 > 数字块上的任何有效表达式都必须在某个位置拆分为左子表达式和右子表达式，并通过一个二元运算组合起来。 

这给出了完整的递归结构。 

---

 # 1.数学分析

 我们必须使用数字$1,2,\dots,9$恰好一次并且按顺序。 

允许：

 - 连接，
 -$+$,$-$,$\times$,$/$,
 - 任意括号。 

不允许：

 - 一元减号。 

我们必须找到每个可获得的**正整数**并对它们求和。 

---

 ## 1.1 表示子问题

 定义$$F(i,j)$$是使用连续数字可获得的所有有理数的集合$$(i+1)(i+2)\cdots j$$例如：

-$F(0,1)=\{1\}$-$F(1,3)$使用数字$23$-$F(0,9)$是完整的问题。 

每个块都可以：

 1. 用作一个串联整数，
 2.或者在某个时候分裂$k$:$$[i,k) \quad\text{and}\quad [k,j)$$并通过一个二元运算组合起来。 

因此：$$F(i,j)=\{\text{concatenated integer}\} \cup \bigcup_{k=i+1}^{j-1} \left\{ a+b,\ a-b,\ a\times b,\ a/b \right\}$$为所有人$$a\in F(i,k),\quad b\in F(k,j),$$仅当$b\neq0$。 

---

 ## 1.2 为什么有理数是必要的

 中间表达式不能是整数。 

声明中的示例：$$(1/23)\times((4\times5)-6)\times(78-9)=42$$所以我们必须保持精确的有理算术。 

使用浮点会产生精度错误并错误地合并不同的值。 

因此我们使用Python的精确有理数类型：$$\texttt{Fraction}$$---

 ## 1.3 复杂性

 只有：$$\frac{9\cdot10}{2}=45$$数字间隔。 

每个间隔递归地组合较小的间隔。 

记忆化使计算完全可行。

 # 2.Python实现```python
from fractions import Fraction
from functools import lru_cache

digits = "123456789"

@lru_cache(None)
def values(i, j):
    """
    Returns the set of all rational values obtainable
    from digits[i:j].
    """

    result = set()

    # Option 1: concatenate all digits into one integer
    result.add(Fraction(int(digits[i:j]), 1))

    # Option 2: split into two parts
    for k in range(i + 1, j):

        left_values = values(i, k)
        right_values = values(k, j)

        for a in left_values:
            for b in right_values:

                result.add(a + b)
                result.add(a - b)
                result.add(a * b)

                if b != 0:
                    result.add(a / b)

    return result

# Compute all values using digits 1..9
all_values = values(0, 9)

# Keep only positive integers
reachable = {
    x.numerator
    for x in all_values
    if x.denominator == 1 and x > 0
}

answer = sum(reachable)

print(answer)
```---
