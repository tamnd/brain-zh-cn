[欧拉项目问题 280](https://projecteuler.net/problem=280)

 ## 解决方案

 **答案：**`430.088247`让状态编码：

 - 蚂蚁的当前位置$(x,y)$,
 - 是否携带种子，
 - 哪些种子留在底行，
 - 顶行中的哪些方块已经被填满。 

因为只有$5$种子，底行和顶行配置都可以由$5$位掩码。 

一个方便的标准化状态是：$$(x,y,c,S,T)$$在哪里

-$c\in\{0,1\}$表明蚂蚁是否携带种子，
 -$S$底行种子组是否仍然存在，
 -$T$是被占用的顶行方块的集合。 

这个过程是马尔可夫的。 

---

 # 1. 转换规则

 每当蚂蚁进入时：

 - 底排的方块包含一颗种子，但没有携带种子，它会立即捡起它；
 - 顶排空方块携带种子时，会立即掉落种子。 

因此，标准化状态会自动应用这些操作。 

终端状态正是具有以下内容的状态：$$S=\varnothing,\qquad T=\{0,1,2,3,4\},\qquad c=0.$$---

 # 2. 线性方程

 让$E(s)$是状态的预期剩余步数$s$。 

对于任何非终止状态：$$E(s) = 1+\frac1{d(s)} \sum_{s'} E(s'),$$在哪里$d(s)\in\{2,3,4\}$是合法相邻方格的数量。 

等价地，$$E(s)-\frac1{d(s)}\sum_{s'}E(s')=1.$$终端状态满足$$E(s)=0.$$这给出了稀疏线性系统。 

可达状态空间有大小$10270$，对于稀疏线性代数来说足够小。

 # 3.Python实现```python
from collections import deque
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# ------------------------------------------------------------
# Grid neighbors
# ------------------------------------------------------------

moves = {}

for x in range(5):
    for y in range(5):
        nbrs = []

        for dx, dy in [(1,0), (-1,0), (0,1), (0,-1)]:
            nx, ny = x + dx, y + dy

            if 0 <= nx < 5 and 0 <= ny < 5:
                nbrs.append((nx, ny))

        moves[(x, y)] = nbrs

# ------------------------------------------------------------
# Normalize a state:
#   pick up seed automatically
#   drop seed automatically
# ------------------------------------------------------------

def normalize(x, y, carry, seeds, top):

    # pick up
    if carry == 0 and y == 0 and ((seeds >> x) & 1):
        carry = 1
        seeds ^= (1 << x)

    # drop
    if carry == 1 and y == 4 and not ((top >> x) & 1):
        carry = 0
        top |= (1 << x)

    return (x, y, carry, seeds, top)

# ------------------------------------------------------------
# Initial state
# ------------------------------------------------------------

start = normalize(2, 2, 0, 31, 0)

# ------------------------------------------------------------
# Enumerate all reachable states
# ------------------------------------------------------------

q = deque([start])
visited = {start}

while q:

    s = q.popleft()

    x, y, carry, seeds, top = s

    # terminal state
    if carry == 0 and seeds == 0 and top == 31:
        continue

    for nx, ny in moves[(x, y)]:

        ns = normalize(nx, ny, carry, seeds, top)

        if ns not in visited:
            visited.add(ns)
            q.append(ns)

states = list(visited)
index = {s:i for i,s in enumerate(states)}

n = len(states)

# ------------------------------------------------------------
# Build sparse linear system
# ------------------------------------------------------------

rows = []
cols = []
vals = []

b = np.ones(n)

for s in states:

    i = index[s]

    x, y, carry, seeds, top = s

    # diagonal
    rows.append(i)
    cols.append(i)
    vals.append(1.0)

    # terminal
    if carry == 0 and seeds == 0 and top == 31:
        b[i] = 0.0
        continue

    deg = len(moves[(x, y)])

    for nx, ny in moves[(x, y)]:

        ns = normalize(nx, ny, carry, seeds, top)

        rows.append(i)
        cols.append(index[ns])
        vals.append(-1.0 / deg)

A = sp.csr_matrix((vals, (rows, cols)), shape=(n, n))

# ------------------------------------------------------------
# Solve
# ------------------------------------------------------------

solution, info = spla.bicgstab(A, b, rtol=1e-12)

answer = solution[index[start]]

print(answer)
```---

 # 4. 代码演练

 -`normalize(...)`强制执行自动接送规则。 
- BFS 仅生成可达状态。 
- 每个方程实现：$$E(s)=1+\text{average of neighbors}.$$- 矩阵是稀疏的，因为每个状态最多有$4$传出转换。 
-`bicgstab`有效解决了$10270\times10270$稀疏系统。 

计算值是：$$430.088246716666\ldots$$四舍五入为$6$小数位数：$$430.088247$$---

 # 5. 验证

 该值合理：

 - 从下到上的单次往返已经需要数十个随机游走步骤。 
- Five seeds must be transported.
 - Strong random revisitation behavior on a$5\times5$格使总预期时间为数百步。 

所以结果是$430$是完全合理的。 

**答案：430.088247**
