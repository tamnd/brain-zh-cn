[欧拉项目问题 125](https://projecteuler.net/problem=125)

 ## 解决方案

 **答案：**`2906969179`## 1.数学分析

 我们想要所有的数字$N < 10^8$这样：

 1.$N$是一个以 10 为基数的回文。 
2.$N$可以写成**连续正整数的平方**之和：$$N = a^2 + (a+1)^2 + \cdots + b^2$$和$a \ge 1$和$b>a$（至少两个术语，因为问题排除了琐碎的问题$1=0^2+1^2$）。 

目标是计算所有这些数字的总和。 

### 关键观察：有效的连续平方和

 一种幼稚的方法会重复重新计算总和：$$a^2 + (a+1)^2 + \cdots + b^2$$相反，定义前缀和：$$S(n)=1^2+2^2+\cdots+n^2$$然后：$$a^2+(a+1)^2+\cdots+b^2 = S(b)-S(a-1)$$这将每个连续平方和变成$O(1)$预处理后的操作。 

我们还可以使用封闭形式：$$S(n)=\frac{n(n+1)(2n+1)}{6}$$但存储前缀和更简单、更高效。 

### 限制搜索

 由于极限是$10^8$,$$1^2+2^2+\cdots+n^2 \approx \frac{n^3}{3}$$所以：$$\frac{n^3}{3}\lesssim 10^8 \quad\Rightarrow\quad n\approx 670$$因此我们只需要大约平方$\sqrt{10^8}=10^4$，但实际上，由于限制，循环会更早退出。 

### 避免重复

 回文可以通过多种方式表示为连续平方和。 该问题要求的是**所有数字**的总和，而不是表示形式。 

所以我们将有效的回文存储在`set`。 

### 回文测试

 数字是回文当且仅当：$$\text{str}(n)=\text{reverse(str}(n))$$对于搜索大小而言，这已经足够快了。

 ## 2.Python实现```python
LIMIT = 10**8

# Build prefix sums of squares:
# prefix[n] = 1^2 + 2^2 + ... + n^2
prefix = [0]
n = 1

while True:
    next_sum = prefix[-1] + n * n

    # Stop when even the cumulative sum exceeds the limit
    # (future sums only get larger)
    if next_sum >= LIMIT:
        prefix.append(next_sum)
        break

    prefix.append(next_sum)
    n += 1

# Store unique palindromes
palindromes = set()

# Try every consecutive range of at least two squares
for start in range(len(prefix)):
    for end in range(start + 2, len(prefix)):

        # Sum of squares from (start+1)^2 to end^2
        total = prefix[end] - prefix[start]

        # Stop early if we exceed the limit
        if total >= LIMIT:
            break

        # Check palindrome
        s = str(total)
        if s == s[::-1]:
            palindromes.add(total)

# Final answer
answer = sum(palindromes)
print(answer)
```---

 ## 3. 代码演练

 ### 构建前缀和```python
prefix = [0]
```我们定义：$$\text{prefix}[k] = 1^2+2^2+\cdots+k^2$$所以：```python
prefix[end] - prefix[start]
```给出总和：$$(start+1)^2+\cdots+end^2$$在恒定的时间内。 

---

 ### 枚举连续平方范围```python
for start in range(len(prefix)):
    for end in range(start + 2, len(prefix)):
```

`start + 2`确保**至少包含两个方块**。 

对于每对：```python
total = prefix[end] - prefix[start]
```如果：```python
total >= LIMIT
```我们停止内循环，因为增加`end`只会增加总和。 

---

 ### 回文检查```python
s = str(total)
if s == s[::-1]:
```这会检查十进制表示形式向前和向后读取是否相同。 

我们将它添加到一个集合中：```python
palindromes.add(total)
```以避免重复计算。
