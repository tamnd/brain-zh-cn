[项目欧拉问题 303](https://projecteuler.net/problem=303)

 ## 解决方案

 **答案：**`1111981904675169`让$$f(n)=\text{the smallest positive multiple of }n$$其十进制扩展仅使用数字$0,1,2$。 

我们必须计算$$\sum_{n=1}^{10000}\frac{f(n)}{n}.$$---

 # 数学分析

 关键的观察结果是，这从根本上来说是一个**最短路径/余数上的 BFS** 问题。 

---

 ## 1. 重新表述条件

 假设一个数字$x$仅使用数字$0,1,2$。 

我们想要：$$x \equiv 0 \pmod n.$$我们不是直接构造大整数，而是取模$n$。 

如果我们现在有一个有余数的数字$r$，然后附加一个数字$d\in\{0,1,2\}$产生新的余数$$r'=(10r+d)\bmod n.$$因此，每个余数都是图中的一个节点：

 - 顶点：$0,1,\dots,n-1$,
 - 边缘：$$r \to (10r+d)\bmod n,\qquad d\in\{0,1,2\}.$$我们寻求**最小的十进制数**（按字典顺序/长度顺序）达到余数$0$。 

---

 ## 2. 为什么BFS给出最小数

 广度优先搜索通过以下方式探索状态：

 1. 最短长度优先，
 2.相同长度内，数字顺序。 

如果我们按顺序排列数字$$0,1,2,$$从开始之后$1$和$2$，那么我们第一次达到余数$0$我们正好有最小的有效数字。 

这是有效的，因为十进制比较相当于：

 1. 数字较少，
 2. 等长数字中按字典顺序排列的较小。 

---

 ## 3. 重构数字

 在 BFS 期间我们存储：

 - 先前的余数，
 - 附加的数字。 

那么当余数$0$达到后，我们回溯重建十进制字符串。 

最后：$$\frac{f(n)}{n}$$是一个整数，所以我们直接计算并求和。 

---

 # Python 实现```python
from collections import deque

def quotient(n):
    """
    Returns f(n) / n, where f(n) is the smallest positive
    multiple of n using only digits 0,1,2.
    """

    # Special case
    if n == 1:
        return 1

    # parent[r] = previous remainder used to reach r
    # digit[r]  = digit appended to reach r
    parent = [-2] * n
    digit = [''] * n

    q = deque()

    # Starting numbers: 1 and 2
    for d in [1, 2]:
        r = d % n

        if parent[r] == -2:
            parent[r] = -1
            digit[r] = str(d)
            q.append(r)

    # BFS over remainders
    while q:
        r = q.popleft()

        # Found divisible number
        if r == 0:
            break

        # Append digits 0,1,2
        for d in [0, 1, 2]:
            nr = (10 * r + d) % n

            if parent[nr] == -2:
                parent[nr] = r
                digit[nr] = str(d)
                q.append(nr)

    # Reconstruct the minimal number
    chars = []
    cur = 0

    while cur != -1:
        chars.append(digit[cur])
        cur = parent[cur]

    s = ''.join(reversed(chars))

    # Return f(n)/n
    return int(s) // n

# Compute the required sum
total = sum(quotient(n) for n in range(1, 10001))

print(total)
```---

 # 代码演练

 ## 初始化```python
parent = [-2] * n
digit = [''] * n
```这些数组存储 BFS 树。 

-`parent[r]`告诉我们之前的余数，
 -`digit[r]`告诉我们附加了哪个数字。 

一个值`-2`意思是“未访问过”。 

---

 ## 起始状态```python
for d in [1, 2]:
```数字不能以以下开头`0`，所以第一位数字必须是`1`或者`2`。 

它们的余数被插入到队列中。 

---

 ## BFS 转换```python
nr = (10 * r + d) % n
```附加一个十进制数字就可以以这种方式更新余数。 

---

 ## 为什么这是有效的

 对于每个$n$:

 - 只有$n$可能的余数，
 - 每个余数被访问一次，
 - 每次访问尝试 3 位数字。 

所以复杂度大约是：$$O(n)$$每个值$n$。 

为了$n\le 10000$，这运行得很快。
