[项目欧拉问题 94](https://projecteuler.net/problem=94)

 ## 解决方案

 **答案：**`518408346`设几乎等边三角形有边：

 -$(a,a,a+1)$， 或者
-$(a,a,a-1)$，

在哪里$a$是一个整数。 我们想要：

 1. 整数边长，
 2.整数区域，
 3. 周长$\le 10^9$。 

关键是将面积条件转化为佩尔方程。 

---

 # 1.数学分析

 对于边相等的等腰三角形$a$和基地$b$，高度为$$h=\sqrt{a^2-\left(\frac b2\right)^2}.$$面积为$$A=\frac12 bh.$$我们需要$A$是一个整数。 

自从$b=a\pm1$， 写：$$A=\frac b2\sqrt{a^2-\frac{b^2}{4}} =\frac b4\sqrt{4a^2-b^2}.$$因此我们要求$$4a^2-b^2$$成为一个完美的正方形。 

让$$b=a\pm1.$$然后$$4a^2-(a\pm1)^2 =3a^2\mp2a-1.$$所以我们需要$$3a^2\mp2a-1 = k^2.$$---

 ## 情况 1：$(a,a,a+1)$我们得到$$k^2=3a^2-2a-1.$$乘以 3：$$3k^2 = 9a^2-6a-3.$$添加 1：$$3k^2+1 = (3a-1)^2.$$因此$$(3a-1)^2-3k^2=1.$$让$$x=3a-1,\qquad y=k.$$然后$$x^2-3y^2=1.$$这就是佩尔方程。 

还：$$a=\frac{x+1}{3}.$$我们需要$x\equiv2\pmod3$。 

周长是$$P=3a+1=x+2.$$---

 ## 情况2：$(a,a,a-1)$相似地，$$k^2=3a^2+2a-1.$$乘以 3 加 1：$$(3a+1)^2-3k^2=1.$$让$$x=3a+1.$$再次：$$x^2-3y^2=1.$$现在$$a=\frac{x-1}{3},$$和周长：$$P=3a-1=x-2.$$---

 ## 佩尔方程结构

 我们必须列举解决方案$x^2-3y^2=1$根本解决办法是$$(2,1),$$所有的解决方案都来自$$x_n+y_n\sqrt3=(2+\sqrt3)^n.$$我们只保留那些产生有效三角形的并且$$P\le10^9.$$Pell 解的递推式为：$$x_{n+1}=2x_n+3y_n,$$

$$y_{n+1}=x_n+2y_n.$$测试前几个：

 |$a$| 三角形| 周长|
 | ---| ---| ---|
 | 5 | 5-5-6 | 5-5-6 16 | 16
 | 17 | 17 2016 年 17 月 17 日 | 50 | 50
 | 65 | 65 65-65-66 | 65-65-66 196 | 196
 | 241 | 241 241-241-240 | 241-241-240 722 | 722

 这些与已知示例相匹配并继续交替。 

我们将所有有效周长相加$10^9$。

 # 2.Python实现```python
LIMIT = 1_000_000_000

total = 0

# Fundamental Pell solution
x, y = 2, 1

while True:
    added = False

    # Case: (a, a, a+1)
    if (x + 1) % 3 == 0:
        a = (x + 1) // 3
        p = 3 * a + 1

        # Check triangle validity
        if p <= LIMIT and 2 * a > a + 1:
            total += p
            added = True

    # Case: (a, a, a-1)
    if (x - 1) % 3 == 0:
        a = (x - 1) // 3
        p = 3 * a - 1

        # Check triangle validity
        if p <= LIMIT and a > 1:
            total += p
            added = True

    # Generate next Pell solution
    x, y = 2 * x + 3 * y, x + 2 * y

    # Stop once both possible perimeters exceed limit
    if x - 2 > LIMIT and x + 2 > LIMIT:
        break

print(total)
```---

 ### 测试两种三角形

 对于每个佩尔解决方案：```python
if (x + 1) % 3 == 0:
```这对应于$$x=3a-1$$对于三角形$(a,a,a+1)$。 

我们恢复：$$a=\frac{x+1}{3}$$和周长$$P=3a+1.$$相似地：```python
if (x - 1) % 3 == 0:
```把手$$x=3a+1$$对于三角形$(a,a,a-1)$。

 ### 佩尔复发```python
x, y = 2 * x + 3 * y, x + 2 * y
```这会生成所有解决方案$$x^2-3y^2=1.$$该序列快速呈指数增长，因此只需要几十次迭代。

 # 4.最终验证

 周长大致呈指数增长（佩尔增长），因此只有有限的多个周长低于$10^9$。 最终的总金额约为数十亿，考虑到界限，这是合理的。
