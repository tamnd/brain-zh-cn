[欧拉项目 629 问题](https://projecteuler.net/problem=629)

 ## 解决方案

 **答案：**`626616617`设单堆大小的 Sprague-Grundy 值$n$是$G_k(n)$为游戏参数$k$。 

对于由桩组成的位置$a_1,\dots,a_m$，SG值为$$G_k(a_1)\oplus G_k(a_2)\oplus\cdots\oplus G_k(a_m),$$所以一个位置正在丢失当且仅当这个异或是$0$。 

因此，任务是：

 1. 计算$G_k(n)$为所有人$n\le 200$,
 2. 计算分区数$200$谁的异或是$0$,
 3. 将其转化为获胜次数。 

---

 # 1. 计算 SG 值

 对于单堆尺寸$n$，一次移动包括将其分成$$n=b_1+\cdots+b_p,\qquad 2\le p\le k,$$与所有$b_i\ge1$。 

因此$$G_k(n)=\operatorname{mex}\Bigl\{ G_k(b_1)\oplus\cdots\oplus G_k(b_p) \Bigr\}.$$我们递归地计算这些$1$向上。 

- -

＃＃ 案件$k=2$只允许二进制分割。 

SG 值变为$$0,1,0,1,0,1,\dots$$IE。$$G_2(n)= (n-1)\bmod 2.$$- -

＃＃ 案件$k\ge4$出现一个关键现象：$$G_k(n)=n-1 \qquad (k\ge4).$$事实上，一旦 4 路分割可用，每个值$0,1,\dots,n-2$变得可达，所以 mex 是$n-1$。 

因此所有$k\ge4$是相同的。 

所以我们只需要：

 -$k=2$,
 -$k=3$,
 - 一名代表$k=4$为所有人$k\ge4$。 

因此$$g(200)=f(200,2)+f(200,3)+197\,f(200,4).$$---

 # 2. 统计丢失的分区

 让$sg[a]$表示一堆尺寸的SG值$a$。 

我们计算分区$N=200$谁的异或是$0$。 

动态规划：$$dp[s][x]$$= 总分区数$s$谁的异或是$x$。 

添加零件尺寸时$a$确切地$m$次数：

 - 贡献总额：$m a$,
 - 对异或的贡献：

 -$0$如果$m$甚至，
-$sg[a]$如果$m$奇怪的。 

这给出了标准的分区式DP。 

如果$L_k$是亏损仓位的数量，那么$$f(200,k)=p(200)-L_k,$$在哪里$p(200)$是分区号。

 # 3.Python实现```python
from functools import lru_cache

N = 200
MOD = 10**9 + 7

# ------------------------------------------------------------
# Partition numbers p(n)
# ------------------------------------------------------------

p = [0] * (N + 1)
p[0] = 1

for a in range(1, N + 1):
    for s in range(a, N + 1):
        p[s] += p[s - a]

P200 = p[200]

# ------------------------------------------------------------
# Compute SG values for fixed k
# ------------------------------------------------------------

def compute_sg(k, N):
    sg = [0] * (N + 1)

    for n in range(1, N + 1):

        reachable = set()

        # Generate all splits into p parts
        for parts in range(2, min(k, n) + 1):

            arr = [0] * parts

            def gen(rem, idx, mx, xr):
                if idx == parts - 1:
                    if 1 <= rem <= mx:
                        reachable.add(xr ^ sg[rem])
                    return

                upper = min(mx, rem - (parts - idx - 1))

                for v in range(upper, 0, -1):
                    gen(rem - v, idx + 1, v, xr ^ sg[v])

            gen(n, 0, n - 1, 0)

        g = 0
        while g in reachable:
            g += 1

        sg[n] = g

    return sg

# k = 2 and k = 3 explicitly
sg2 = compute_sg(2, N)
sg3 = compute_sg(3, N)

# For all k >= 4:
# G_k(n) = n - 1
sg4 = [i - 1 for i in range(N + 1)]

# ------------------------------------------------------------
# Count losing partitions using xor DP
# ------------------------------------------------------------

def losing_count(sg):

    MAXX = 512

    dp = [[0] * MAXX for _ in range(N + 1)]
    dp[0][0] = 1

    for a in range(1, N + 1):

        ndp = [[0] * MAXX for _ in range(N + 1)]

        for s in range(N + 1):
            for x, val in enumerate(dp[s]):

                if val == 0:
                    continue

                # choose multiplicity m of part size a
                for m in range((N - s) // a + 1):

                    nx = x
                    if m % 2 == 1:
                        nx ^= sg[a]

                    ndp[s + m * a][nx] += val

        dp = ndp

    return dp[N][0]

L2 = losing_count(sg2)
L3 = losing_count(sg3)
L4 = losing_count(sg4)

f2 = P200 - L2
f3 = P200 - L3
f4 = P200 - L4

answer = (f2 + f3 + 197 * f4) % MOD

print(answer)
```---

 # 4. 代码演练

 ### 分区编号```python
p[s] += p[s-a]
```这就是经典的分区DP计算$p(n)$。 

---

 ### SG 计算

 对于每个$n$:

 - 生成每一个合法的分割，
 - 异或子堆的 SG 值，
 - 采取墨西哥。 

递归`gen(...)`枚举非递增分区，因此每个拆分都计算一次。 

---

 ### 丢失位置 DP

 对于每个桩尺寸$a$:

 - 选择多重性$m$，
- 添加$m a$至总和，
 - 异或`sg[a]`当且仅当$m$很奇怪。 

在最后：```python
dp[200][0]
```是亏损仓位的数量。
