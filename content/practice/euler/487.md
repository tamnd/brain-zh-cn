[项目欧拉问题 487](https://projecteuler.net/problem=487)

 ## 解决方案

 **答案：**`106650212746`让$$f_k(n)=\sum_{i=1}^n i^k, \qquad S_k(n)=\sum_{i=1}^n f_k(i).$$我们需要$$\sum_{p} \left(S_{10000}(10^{12}) \bmod p\right),$$在哪里$p$遍历所有素数$$2\cdot 10^9 < p < 2\cdot 10^9+2000.$$这样的素数有 100 个。 

---

 # 1.数学分析

 ## 第 1 步：重写$S_k(n)$展开定义：$$S_k(n)=\sum_{i=1}^n \sum_{j=1}^i j^k.$$交换求和顺序：$$S_k(n)=\sum_{j=1}^n (n-j+1)j^k.$$因此$$S_k(n) = (n+1)\sum_{j=1}^n j^k-\sum_{j=1}^n j^{k+1}.$$所以：$$S_k(n)=(n+1)f_k(n)-f_{k+1}(n).$$这立即表明$S_k(n)$是一个多项式$n$学位的$k+2$。 

为了$k=10000$，度数为$10002$。 

---

 ## 步骤 2：以素数为模的多项式插值

 对于固定素数$p$， 定义$$P(n)=S_{10000}(n)\pmod p.$$自从$P(n)$是一个次数多项式$10002$，知道它的值$$0,1,2,\dots,10002$$完全模数确定它$p$。 

因为这里的每个素数都满足$$p > 2\cdot 10^9 \gg 10002,$$拉格朗日插值中的所有阶乘分母都是可逆模数$p$。 

因此我们可以评估$P(10^{12})$模数$p$对连续点使用标准拉格朗日插值。 

---

 ## Step 3: Build the interpolation table

 我们依次计算：$$f(i)=f(i-1)+i^{10000},$$进而$$S(i)=S(i-1)+f(i).$$店铺$$y_i=S(i)\pmod p$$为了$0\le i\le10002$。 

Then evaluate the polynomial at$x=10^{12}\bmod p$。 

每个素数的复杂度：

 -$10002$模幂，
 -$O(10002)$插值。 

只要有 100 个素数，这很容易实现。 

---

 # 2.Python实现```python
from sympy import primerange

K = 10000
N = 10**12
D = K + 2   # degree of S_k(n)

# ------------------------------------------------------------
# Lagrange interpolation on points x = 0,1,2,...,D
# y[i] = polynomial value at i
# Evaluates polynomial at x modulo mod.
# ------------------------------------------------------------
def lagrange(y, x, mod):
    n = len(y) - 1

    # If x is already one of the known points
    if x <= n:
        return y[x] % mod

    # factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % mod

    # inverse factorials
    ifact = [1] * (n + 1)
    ifact[n] = pow(fact[n], mod - 2, mod)

    for i in range(n, 0, -1):
        ifact[i - 1] = ifact[i] * i % mod

    # prefix products:
    # pre[i] = (x)(x-1)...(x-(i-1))
    pre = [1] * (n + 2)
    for i in range(n + 1):
        pre[i + 1] = pre[i] * (x - i) % mod

    # suffix products:
    # suf[i] = (x-i)(x-(i+1))...(x-n)
    suf = [1] * (n + 2)
    for i in range(n, -1, -1):
        suf[i] = suf[i + 1] * (x - i) % mod

    ans = 0

    for i, yi in enumerate(y):
        # numerator product excluding (x-i)
        num = pre[i] * suf[i + 1] % mod

        # denominator inverse
        den = ifact[i] * ifact[n - i] % mod

        # sign from (-1)^(n-i)
        if (n - i) & 1:
            den = mod - den

        ans = (ans + yi * num % mod * den) % mod

    return ans

def compute():
    total = 0

    # primes in (2e9, 2e9+2000)
    primes = list(primerange(2_000_000_000, 2_000_002_000))

    for p in primes:

        # y[i] = S_K(i) mod p
        y = [0] * (D + 1)

        fk = 0
        sk = 0

        for i in range(1, D + 1):
            fk = (fk + pow(i, K, p)) % p
            sk = (sk + fk) % p
            y[i] = sk

        value = lagrange(y, N % p, p)

        total += value

    return total

print(compute())
```---

 # 3. 代码演练

 ## 素数生成```python
primes = list(primerange(2_000_000_000, 2_000_002_000))
```生成所需区间内的所有素数。 

正好有 100 个。 

---

 ## 构建多项式值```python
fk = (fk + pow(i, K, p)) % p
```维持$$f_K(i)=\sum_{j=1}^i j^K \pmod p.$$然后```python
sk = (sk + fk) % p
```维持$$S_K(i)=\sum_{t=1}^i f_K(t)\pmod p.$$这些值被存储用于插值。 

---

 ## 拉格朗日插值

 因为多项式的次数是$10002$，值在$$0,1,\dots,10002$$唯一地确定它。 

插值公式为$$P(x)=\sum_{i=0}^{n} y_i \prod_{j\ne i} \frac{x-j}{i-j}.$$使用阶乘和前缀/后缀乘积可将计算时间缩短为线性时间。

 # 4. 验证

 问题陈述给出：$$S_4(100)=35375333830.$$直接的暴力计算准确地证实了这一点。 

该插值方法也在许多小型设备上进行了测试$(k,n,p)$对抗暴力破解的案例完美匹配。 

最终结果是积极且合理的：

 - 每个残基是$<2\cdot10^9$,
 - 有 100 个素数，
 - 因此总数应大致低于$2\cdot10^{11}$,

 与计算值相匹配。
