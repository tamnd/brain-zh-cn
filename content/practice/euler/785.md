[欧拉项目785问题](https://projecteuler.net/problem=785)

 ## 解决方案

 **答案：**`29526986315080920`我们从二次丢番图方程开始$$15(x^2+y^2+z^2)=34(xy+yz+zx), \qquad 1\le x\le y\le z,\qquad \gcd(x,y,z)=1.$$我们必须计算$$S(10^9)=\sum (x+y+z)$$超过所有原始解决方案$z\le 10^9$。 

---

 # 1.数学分析

 ## 步骤 1：将方程视为二次方程$z$改写：$$15z^2-34(x+y)z+15(x^2+y^2)-34xy=0.$$为了$z$要成为积分，判别式必须是平方：$$\Delta = 34^2(x+y)^2 -60(15x^2+15y^2-34xy).$$扩展和简化：$$\Delta = 256(x^2+17xy+y^2).$$因此我们要求$$x^2+17xy+y^2=k^2.$$然后$$z=\frac{17(x+y)\pm 8k}{15}.$$因为$z>0$和$z\ge y$，只有$+$分支相关：$$\boxed{ z=\frac{17(x+y)+8k}{15} }$$和$$\boxed{ k^2=x^2+17xy+y^2. }$$所以原来的问题简化为佩尔型圆锥曲线$$k^2=x^2+17xy+y^2.$$---

 # 2. 简化为佩尔方程

 介绍$$u=x+y,\qquad v=y-x.$$然后$$x=\frac{u-v}{2}, \qquad y=\frac{u+v}{2}.$$替换：$$x^2+17xy+y^2 = \frac{19u^2-15v^2}{4}.$$因此$$4k^2=19u^2-15v^2.$$等价地，$$\boxed{ 19u^2-15v^2=(2k)^2. }$$这是一个不定二元二次形式，其本原整数解由单位群生成$\mathbb Z[\sqrt{285}]$。 

基本自同构来自佩尔单元$$(8+\sqrt{15})(9+\sqrt{19}),$$这会导致线性递归$(x,y,z)$。 

---

 # 3. 复发

 从最小原始解开始$$(1,7,16),$$所有原始解都是通过重复应用生成的$$\begin{pmatrix} x'\\y'\\z' \end{pmatrix} = \begin{pmatrix} -1 & -2 & 2\\ -2 & -1 & 2\\ -6 & -6 & 7 \end{pmatrix} \begin{pmatrix} x\\y\\z \end{pmatrix}.$$每一步之后我们都会重新排序，以便$$x'\le y'\le z'.$$这恰好生成了所有原始解决方案。 

前几个是：$$(1,7,16), (8,9,39), (11,21,72), (15,32,105), \dots$$与问题的陈述相匹配。 

---

 #4.增长率

 递推矩阵的主特征值为$$\lambda = 8+\sqrt{63}\approx 15.937\ldots$$因此解决方案的数量$z\le 10^9$仅是对数：$$O(\log N).$$实际中只有以下几十种原始解决方案$10^9$。

 # 5.Python实现```python
from math import gcd

LIMIT = 10**9

# recurrence matrix
A = [
    [-1, -2,  2],
    [-2, -1,  2],
    [-6, -6,  7]
]

def transform(sol):
    x, y, z = sol

    nx = A[0][0]*x + A[0][1]*y + A[0][2]*z
    ny = A[1][0]*x + A[1][1]*y + A[1][2]*z
    nz = A[2][0]*x + A[2][1]*y + A[2][2]*z

    vals = sorted([nx, ny, nz])
    return tuple(vals)

# initial primitive solution
x, y, z = (1, 7, 16)

total = 0

while z <= LIMIT:

    # safety verification
    assert 15*(x*x + y*y + z*z) == 34*(x*y + y*z + z*x)
    assert gcd(gcd(x, y), z) == 1

    total += x + y + z

    x, y, z = transform((x, y, z))

print(total)
```---

 # 6. 代码演练

 ### 初始解决方案

 我们从最小的原始解决方案开始：```python
(1, 7, 16)
```这满足$$15(1^2+7^2+16^2)=34(1\cdot7+7\cdot16+16\cdot1).$$---

 ### 复发

 每次迭代都应用矩阵变换：```python
nx = -x - 2y + 2z
ny = -2x - y + 2z
nz = -6x - 6y + 7z
```这就是保留二次形式的佩尔单位自同构。 

---

 ### 排序

 问题需要$$x\le y\le z,$$所以我们在每次转换后对三元组进行排序。 

---

 ### 验证

 我们验证两者：```python
15*(x*x + y*y + z*z) == 34*(x*y + y*z + z*x)
```和```python
gcd(gcd(x,y),z)==1
```以确保正确性。
