[项目欧拉问题 350](https://projecteuler.net/problem=350)

 ## 解决方案

 **答案：**`84664213`让$$f(G,L,N)=\#\{(a_1,\dots,a_N)\in \mathbb N^N:\gcd(a_i)\ge G,\ \operatorname{lcm}(a_i)\le L\}.$$我们必须计算$$f(10^6,10^{12},10^{18}) \pmod{101^4}.$$模数为$$101^4=104060401.$$---

 # 1.数学分析

 ## 步骤 1：通过 gcd 标准化

 让$$g=\gcd(a_1,\dots,a_N).$$写$$a_i=g b_i.$$然后：

-$\gcd(b_1,\dots,b_N)=1$,
 -$\operatorname{lcm}(a_i)=g\operatorname{lcm}(b_i)$。 

定义$$d=\operatorname{lcm}(b_i).$$那么每个有效列表都唯一对应于：

 - 一个整数$g\ge G$,
 - 一个整数$d\ge 1$,
 - 一个列表$(b_i)$和$$\gcd(b_i)=1,\qquad \operatorname{lcm}(b_i)=d,$$- 和约束$$gd\le L.$$因此对于固定的$d$, 允许的数量$g$是$$\left\lfloor \frac{L}{d}\right\rfloor-G+1,$$假如$d\le L/G$。 

所以$$f(G,L,N) = \sum_{d\le L/G} h_N(d)\left(\left\lfloor\frac{L}{d}\right\rfloor-G+1\right),$$在哪里$h_N(d)$是长度的数量-$N$列出：$$\gcd=1,\qquad \operatorname{lcm}=d.$$所以整个问题归结为计算$h_N(d)$。 

---

 # 第 2 步：计算$h_N(d)$因素$$d=\prod p^{e_p}.$$因为 gcd/lcm 条件将质数分开，所以我们只需要研究一个质数幂。 

假设对于素数$p$, 中的指数$N$条目是$$x_1,\dots,x_N\in\{0,1,\dots,e\}.$$拥有：

 - lcm 指数$=e$: 至少一个$x_i=e$,
 - GCD 指数$=0$: 至少一个$x_i=0$。 

因此，我们用以下方法计算指数元组：$$\max x_i=e,\qquad \min x_i=0.$$元组总数$[0,e]$:$$(e+1)^N.$$减去不带零的元组：$$e^N.$$减去没有的元组$e$:$$e^N.$$添加回元组，两者都没有$0$也不$e$:$$(e-1)^N.$$因此指数的贡献$e$是$$A_e=(e+1)^N-2e^N+(e-1)^N.$$由于不同的素数是独立的：$$h_N(d)=\prod_{p^e\parallel d} A_e.$$这是乘法。 

---

 # 第三步：最终求和

 让$$M=\left\lfloor \frac{L}{G}\right\rfloor.$$然后$$f(G,L,N) = \sum_{d=1}^{M} \left( \prod_{p^e\parallel d} \big((e+1)^N-2e^N+(e-1)^N\big) \right) \left( \left\lfloor \frac{L}{d}\right\rfloor-G+1 \right).$$对于这个问题：$$G=10^6,\quad L=10^{12},\quad N=10^{18},$$所以$$M=10^6.$$数字中出现的最大指数$\le10^6$只是$19$， 自从$$2^{19}=524288,\qquad 2^{20}>10^6.$$因此我们预先计算$A_e$为了$e=0,\dots,19$模数$101^4$，然后乘法筛选直至$10^6$。 

复杂性：

 - 筛子：$O(M\log\log M)$，
- 评估：$O(M)$,

 这是很容易实现的。 

---

 # 2.Python实现```python
MOD = 101**4

G = 10**6
L = 10**12
N = 10**18

M = L // G   # = 10^6

# ------------------------------------------------------------
# Precompute:
# A[e] = (e+1)^N - 2*e^N + (e-1)^N  (mod MOD)
# ------------------------------------------------------------

MAX_E = 20

A = [0] * (MAX_E + 1)

for e in range(MAX_E + 1):
    A[e] = (
        pow(e + 1, N, MOD)
        - 2 * pow(e, N, MOD)
        + pow(e - 1, N, MOD)
    ) % MOD

# ------------------------------------------------------------
# Smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(M + 1))

for i in range(2, int(M**0.5) + 1):
    if spf[i] == i:  # i is prime
        for j in range(i * i, M + 1, i):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Compute h[d] multiplicatively
#
# h[d] = product over p^e || d of A[e]
# ------------------------------------------------------------

h = [0] * (M + 1)
h[1] = 1

for n in range(2, M + 1):

    p = spf[n]

    e = 0
    t = n

    while t % p == 0:
        t //= p
        e += 1

    h[n] = (h[t] * A[e]) % MOD

# ------------------------------------------------------------
# Final summation
# ------------------------------------------------------------

answer = 0

for d in range(1, M + 1):

    weight = (L // d) - G + 1

    answer = (answer + h[d] * weight) % MOD

print(answer)
```---

 # 3. 代码演练

 ## 预计算$A_e$

```python
A[e] = (e+1)^N - 2e^N + (e-1)^N
```这正是指数元组的包含-排除计数，其最小值为$0$最大值是$e$。 

我们计算所有幂的模$101^4$。 

---

 ## 最小素因子筛

 的`spf`数组存储每个数字的最小质因数$10^6$。 

这让我们可以非常快速地因式分解每个数字。 

- -

＃＃ 建筑$h[n]$如果$$n = p^e \cdot t$$和$p\nmid t$，然后乘法给出$$h(n)=h(t)\cdot A_e.$$因此每个值都是在恒定的摊余时间内计算的。 

---

 ## 最终总和

 对于每个$d$:```python
weight = floor(L/d) - G + 1
```计算有效的 gcd 选择$g$。 

我们积累$$h(d)\times \text{weight}.$$---
