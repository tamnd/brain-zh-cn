[项目欧拉问题 211](https://projecteuler.net/problem=211)

 ## 解决方案

 **答案：**`1922364685`我们寻找所有整数$0<n<64\,000\,000$这样$$\sigma_2(n)=\sum_{d\mid n} d^2$$是一个完全平方数，然后将所有这些相加$n$。 

---

 # 数学分析

 ## 1. 的乘法性$\sigma_2$对于任意正整数$n$质因数分解$$n=\prod p_i^{a_i},$$除数平方和函数是乘法函数：$$\sigma_2(n)=\prod \left(1+p_i^2+p_i^4+\cdots+p_i^{2a_i}\right).$$这是因为每个除数$n$是独立于主要权力而形成的。 

对于原功率：$$\sigma_2(p^a)=1+p^2+p^4+\cdots+p^{2a} =\frac{p^{2(a+1)}-1}{p^2-1}.$$所以如果我们可以计算$\sigma_2(n)$为所有人有效$n<64\cdot10^6$，我们简单地测试结果是否是完全平方数。 

---

 ## 2. 高效的筛分计算

 每个数字的直接因式分解$64$在 Python 中百万会太慢。 

相反，我们使用除数筛。 

观察：$$\sigma_2(n)=\sum_{d\mid n} d^2.$$所以我们可以初始化一个数组：$$S[n]=0$$对于每个除数$d$， 添加$d^2$到所有倍数$d$。 

伪结构：```python
for d in range(1, LIMIT):
    d2 = d*d
    for multiple in range(d, LIMIT, d):
        S[multiple] += d2
```这类似于埃拉托斯特尼筛法，运行时间大约为$$N\log N$$时间。 

为了$N=64\,000\,000$，这很大，但在优化实现中是可行的（特别是 PyPy / 低级语言）。 

---

 ## 3. 完全平方检验

 对于每个$n$，计算后$\sigma_2(n)$，我们测试它是否是一个正方形。 

使用整数平方根：$$r = \lfloor \sqrt{\sigma_2(n)} \rfloor$$并检查：$$r^2 = \sigma_2(n).$$在Python中：```python
r = isqrt(value)
if r*r == value:
    ...
```这`math.isqrt`函数是精确的并且避免了浮点错误。 

---

 # Python 实现```python
from math import isqrt

LIMIT = 64_000_000

# sigma2[n] will contain σ₂(n)
sigma2 = [0] * LIMIT

# Divisor sieve:
# add d² to every multiple of d
for d in range(1, LIMIT):
    d2 = d * d
    for multiple in range(d, LIMIT, d):
        sigma2[multiple] += d2

# Sum all n for which σ₂(n) is a perfect square
answer = 0

for n in range(1, LIMIT):
    s = sigma2[n]
    r = isqrt(s)
    if r * r == s:
        answer += n

print(answer)
```---

 # 小例子验证

 对于$n=10$：

 除数是：$$1,2,5,10$$和$$\sigma_2(10)=1^2+2^2+5^2+10^2 =1+4+25+100 =130.$$自从$130$不是正方形，10不算。 

为了$n=1$：$$\sigma_2(1)=1,$$这是一个完全平方数，因此包含 1。 

筛子可以正确计算这些。
