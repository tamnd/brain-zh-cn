[欧拉项目问题 315](https://projecteuler.net/problem=315)

 ## 解决方案

 **答案：**`13625242`让每个十进制数字由 7 段位掩码表示。 

一个数字的数字根链$n$是$$n \to s(n) \to s(s(n)) \to \cdots$$在哪里$s(n)$是小数位的总和$n$，直到达到一位数。 

例如：$$137 \to 11 \to 2$$关键的观察结果是，两个时钟的不同之处仅在于它们在连续显示之间的转换方式。

 # 1.数学分析

 ## 七段表示

 我们将每个数字编码为 7 位掩码。 

使用段编号$$\begin{matrix}  &0& \\ 1&&2\\  &3& \\ 4&&5\\  &6& \end{matrix}$$这些面具是：

 | 数字| 面膜| 分段点亮 |
 | ---| ---| ---|
 | 0 | 0x77 | 0x77 6 |
 | 1 | 0x24 | 0x24 2 |
 | 2 | 0x5D | 0x5D 5 |
 | 3 | 0x6D | 0x6D 5 |
 | 4 | 0x2E | 0x2E 4 |
 | 5 | 0x6B | 0x6B 5 |
 | 6 | 0x7B | 0x7B 6 |
 | 7 | 0x27 | 0x27 4 |
 | 8 | 0x7F | 0x7F 7 |
 | 9 | 0x6F| 6 |

 点亮的段数就是 popcount（设置位数）。 

---

 # 山姆的时钟

 山姆总是：

 1. 打开整个号码，
 2.稍后关闭整个号码。 

因此如果显示的数字$x$用途$L(x)$点亮片段，Sam 花费$$2L(x)$$该显示器上的转换。 

因此对于数字根链$$x_0,x_1,\dots,x_k$$山姆使用$$S = 2\sum_{i=0}^k L(x_i)$$---

 # 麦克斯的时钟

 Max 仅更改连续显示之间不同的段。 

如果$M(a)$和$M(b)$是两个显示器的位掩码，那么所需的转换数量是$$\operatorname{popcount}(M(a)\oplus M(b))$$因为 XOR 准确地标记了改变状态的段。 

因此 Max 的总数为：

 - 打开第一个号码，
 - 连续数字之间的异或转换，
 - 关闭最终号码。 

所以：$$T = L(x_0) + \sum_{i=0}^{k-1} \operatorname{popcount}(M(x_i)\oplus M(x_{i+1})) + L(x_k)$$---

 # 素数范围

 我们必须对所有素数进行评估$$10^7 \le p < 2\cdot 10^7$$埃拉托色尼筛很容易就足够快。

 # 2.Python实现```python
from math import isqrt

# Seven-segment bitmasks
SEG = {
    0: 0x77,
    1: 0x24,
    2: 0x5D,
    3: 0x6D,
    4: 0x2E,
    5: 0x6B,
    6: 0x7B,
    7: 0x27,
    8: 0x7F,
    9: 0x6F,
}

def digit_sum(n):
    """Sum of decimal digits."""
    s = 0
    while n:
        s += n % 10
        n //= 10
    return s

def segments_of_number(n):
    """
    Pack the seven-segment masks of all digits into one integer.
    Each digit gets 8 bits.
    """
    result = 0
    shift = 0

    while n > 0:
        result |= SEG[n % 10] << shift
        n //= 10
        shift += 8

    return result

def sam_cost(n):
    """Transitions used by Sam."""
    segs = segments_of_number(n)
    cost = 2 * segs.bit_count()

    if n > 9:
        cost += sam_cost(digit_sum(n))

    return cost

def max_cost(n, previous=0):
    """Transitions used by Max."""
    segs = segments_of_number(n)

    # Only changed segments toggle
    cost = (segs ^ previous).bit_count()

    if n > 9:
        cost += max_cost(digit_sum(n), segs)
    else:
        # Turn final display off
        cost += segs.bit_count()

    return cost

def sieve(limit):
    """Return list of primes <= limit."""
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(limit) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            for k in range(start, limit + 1, step):
                is_prime[k] = False

    return is_prime

A = 10_000_000
B = 20_000_000

prime = sieve(B)

answer = 0

for p in range(A, B + 1):
    if prime[p]:
        answer += sam_cost(p) - max_cost(p)

print(answer)
```---

 # 3. 代码演练

 ##`segments_of_number`每个数字贡献一个 7 位掩码。 

例如：$$137$$变成$$M(7)\ |\ (M(3)\ll 8)\ |\ (M(1)\ll 16)$$这让我们可以通过一次异或来比较整个显示。 

---

 ##`sam_cost`对于每个显示的值：```python
2 * segs.bit_count()
```计数打开和关闭所有段。 

然后我们递归数字和。 

为了$137$：

 -$137$：$2(2+5+4)=22$-$11$：$2(2+2)=8$-$2$：$2(5)=10$全部的：$$40$$---

 ##`max_cost`显示之间的转换计数为：```python
(segs ^ previous).bit_count()
```因为 XOR 准确地检测到更改的段。 

为了$137$：

- 空的$\to 137$: 11
 -$137 \to 11$: 7
 -$11 \to 2$: 7
 -$2 \to$空：5

 总计：$$30$$匹配问题陈述。
