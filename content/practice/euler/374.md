[欧拉项目问题 374](https://projecteuler.net/problem=374)

 ## 解决方案

 **答案：**`334420941`让$$F(n)=f(n)\cdot m(n)$$在哪里$f(n)$是从以下分区中可获得的最大乘积$n$分解为不同的正整数，并且$m(n)$是此类最佳分区中的部分数量。 

关键的观察结果是最佳分区始终“几乎连续”。 

如果$$T_k=\frac{k(k+1)}2$$和$$n=T_k+r,\qquad 0\le r\le k,$$那么：

 - 对于$r=0$:$$n=1+2+\cdots+k$$最优划分为$$2+3+\cdots+(k-1)+(k+1)$$（产品通过更换而增加$1$和$k$和$k+1$）。 

因此$$f(n)=\frac{(k+1)!}{2},\qquad m(n)=k-1.$$所以$$F(n)=\frac{(k-1)(k+1)!}{2}.$$- 为了$1\le r\le k$:

 开始于$1,2,\dots,k$， 消除$k-r$，并添加$k+1$。 

因此$$f(n)=\frac{(k+1)!}{k-r}, \qquad m(n)=k,$$与特殊情况$r=k$给予$f(n)=(k+1)!$。 

这会产生一个可以计算的总和$O(\sqrt N)$。

 ## Python 代码```
import math
from array import array

MOD = 982451653
N = 10**14

# Largest k with T_k <= N
kmax = (math.isqrt(1 + 8 * N) - 1) // 2
r = N - kmax * (kmax + 1) // 2

# Modular inverses up to kmax
inv = array('I', [0]) * (kmax + 1)
inv[1] = 1

for i in range(2, kmax + 1):
    inv[i] = (MOD - (MOD // i) * inv[MOD % i] % MOD) % MOD

inv2 = (MOD + 1) // 2

ans = 0

# H = sum_{j=1}^{k-1} 1/j mod MOD
H = 0

# A = (k+1)! mod MOD
A = 2  # for k = 1

# Complete blocks
for k in range(1, kmax):

    # contribution for n = T_k
    # plus contributions for T_k + 1 ... T_k + k
    block = A * (((k - 1) * inv2 + k * (1 + H)) % MOD)

    ans = (ans + block) % MOD

    H = (H + inv[k]) % MOD
    A = (A * (k + 2)) % MOD

# Final partial block
k = kmax

# n = T_k
ans = (ans + A * ((k - 1) * inv2)) % MOD

# n = T_k + 1 ... T_k + r
for j in range(k - r, k):
    ans = (ans + k * A * inv[j]) % MOD

ans %= MOD

print(ans)
```---

 ## 演练

 ### 1.三角分解

 每个整数$n$可以唯一地写为$$n=T_k+r,\qquad 0\le r\le k.$$这决定了最佳的分区结构。 

---

 ### 2.模逆

 我们需要很多价值观$1/j \pmod{MOD}$。 

使用递归$$\text{inv}[i] = MOD-\left\lfloor \frac{MOD}{i}\right\rfloor \cdot \text{inv}[MOD\bmod i] \pmod{MOD},$$所有倒数都是在线性时间内计算的。 

---

 ### 3.阶乘

 变量$$A=(k+1)! \pmod{MOD}$$每次迭代都会增量更新。 

---

 ### 4. 谐波和

 我们维持$$H=\sum_{j=1}^{k-1}\frac1j \pmod{MOD}.$$这允许计算每个块的贡献$O(1)$。 

---
