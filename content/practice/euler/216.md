[项目欧拉问题 216](https://projecteuler.net/problem=216)

 ## 解决方案

 **答案：**`5437849`我们必须计算以下形式的素数$$t(n)=2n^2-1,\qquad 1<n\le 50\,000\,000.$$问题表明对于$n\le 10\,000$， 确切地$2202$值是素数。 我们需要计数到$5\times 10^7$。 

---

 # 数学分析

 我们寻求数量$n$这样$$2n^2-1$$是素数。 

对所有人进行直接素性测试$50$除非我们利用代数结构，否则百万值太慢了。 

---

 ## 1.同余结构

 假设有一个素数$p$划分$2n^2-1$。 然后$$2n^2 \equiv 1 \pmod p$$这意味着$$n^2 \equiv \frac12 \pmod p.$$等价地，$$(2n)^2 \equiv 2 \pmod p.$$因此$2$必须是二次余数模$p$。 由二次互易，$$\left(\frac{2}{p}\right)=1 \iff p\equiv 1,7 \pmod 8.$$因此每个奇数素因数$2n^2-1$满足$$p\equiv 1 \text{ or } 7 \pmod 8.$$对于每个这样的素数$p$, 一致性$$2n^2\equiv 1 \pmod p$$正好有两个模解$p$。 

这意味着我们可以像素筛一样筛选所有复合值。 

---

 ## 2. 筛选策略

 定义$$f(n)=2n^2-1.$$最初假设每个$f(n)$是素数。 

对于每一个素数$p\equiv1,7\pmod8$:

 1. 解决$$2n^2\equiv1\pmod p.$$2.设两个根为$r_1,r_2$。 
3. 每个$$n\equiv r_1,r_2\pmod p$$给出$p\mid f(n)$。 

我们标记所有此类$n$。 

然而，如果$f(n)=p$就其本身而言，我们不能_将其标记为复合的。 

只有当$$2n^2-1=p.$$所以在筛选过程中我们只标记$$2n^2-1>p.$$这与在$p^2$。 

---

 ## 3. 计算根

 我们需要的解决方案$$2n^2\equiv1\pmod p.$$乘以 的倒数$2$:$$n^2\equiv 2^{-1}\pmod p.$$等价地，$$(2n)^2\equiv2\pmod p.$$因此如果$s^2\equiv2\pmod p$， 然后$$n\equiv s\cdot 2^{-1}\pmod p.$$所以我们只需要模平方根$2$模数$p$，可通过托内利-香克斯获得。 

---

 ## 4. 复杂性

 我们过筛$N=50\,000\,000$指数。 

素数上的谐波密度给出了大约的总功$$N\sum_{p}\frac{2}{p} \sim 2N\log\log N,$$这在优化代码中是可行的。 

这是该欧拉问题的标准公认解决方法。 

---

 # Python 实现```python
from array import array
from math import isqrt

LIMIT = 50_000_000

# ------------------------------------------------------------
# Ordinary prime sieve up to sqrt(2)*LIMIT
# Any composite t(n)=2n^2-1 has a prime divisor <= sqrt(t(n))
# ------------------------------------------------------------

P = isqrt(2 * LIMIT * LIMIT - 1) + 1

is_prime = bytearray(b"\x01") * (P + 1)
is_prime[0] = is_prime[1] = 0

for i in range(2, isqrt(P) + 1):
    if is_prime[i]:
        step = i
        start = i * i
        is_prime[start:P + 1:step] = b"\x00" * ((P - start) // step + 1)

primes = [p for p in range(2, P + 1) if is_prime[p]]

# ------------------------------------------------------------
# Tonelli-Shanks modular square root
# Finds x such that x^2 = n (mod p)
# ------------------------------------------------------------

def tonelli(n, p):
    assert pow(n, (p - 1) // 2, p) == 1

    if p % 4 == 3:
        return pow(n, (p + 1) // 4, p)

    # write p-1 = q * 2^s with q odd
    q = p - 1
    s = 0
    while q % 2 == 0:
        s += 1
        q //= 2

    # find quadratic nonresidue z
    z = 2
    while pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    c = pow(z, q, p)
    x = pow(n, (q + 1) // 2, p)
    t = pow(n, q, p)
    m = s

    while t != 1:
        i = 1
        temp = (t * t) % p
        while temp != 1:
            temp = (temp * temp) % p
            i += 1

        b = pow(c, 1 << (m - i - 1), p)

        x = (x * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return x

# ------------------------------------------------------------
# Candidate array:
# 1 means "possibly prime"
# ------------------------------------------------------------

cand = bytearray(b"\x01") * (LIMIT + 1)
cand[0] = cand[1] = 0

# ------------------------------------------------------------
# Sieve using prime divisors
# ------------------------------------------------------------

for p in primes:
    if p == 2:
        continue

    # 2 must be quadratic residue mod p
    if p % 8 not in (1, 7):
        continue

    # sqrt(2) mod p
    s = tonelli(2, p)

    inv2 = (p + 1) // 2

    r1 = (s * inv2) % p
    r2 = (-r1) % p

    for r in (r1, r2):
        if r == 0:
            start = p
        else:
            start = r

        # ensure 2*n^2 - 1 > p
        while 2 * start * start - 1 <= p:
            start += p

        for n in range(start, LIMIT + 1, p):
            cand[n] = 0

# ------------------------------------------------------------
# Count survivors
# ------------------------------------------------------------

answer = sum(cand)

print(answer)
```---

 ## 素数生成

 我们生成所有素数直到$$\sqrt{2N^2-1}.$$如果$2n^2-1$是合数，它的质因数不大于该界限。

 ## 托内利-香克斯`tonelli(n,p)`计算素数模的平方根：$$x^2\equiv n\pmod p.$$我们使用它$n=2$。

 ## 根结构

 如果$$s^2\equiv2\pmod p,$$然后$$n\equiv s\cdot2^{-1}\pmod p$$解决$$2n^2\equiv1\pmod p.$$第二个根是$-r_1$。

 ## 标记复合材料

 对于每个残留类别：```python
for n in range(start, LIMIT + 1, p):
    cand[n] = 0
```标记每个$n$这样$p\mid (2n^2-1)$。 

循环```python
while 2 * start * start - 1 <= p:
    start += p
```防止删除素值$2n^2-1=p$。
