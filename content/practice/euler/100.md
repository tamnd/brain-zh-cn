[项目欧拉问题 100](https://projecteuler.net/problem=100)

 ## 解决方案

 **答案：**`756872327473`我们寻求条件的整数解$$P(\text{BB})=\frac12$$其中一个盒子包含$b$蓝色光盘和$r$红色圆盘，总计$$n=b+r.$$抽出两个蓝色圆盘且不放回的概率为$$\frac{b}{n}\cdot\frac{b-1}{n-1}=\frac12.$$所以我们必须解决$$\frac{b(b-1)}{n(n-1)}=\frac12.$$等价地，$$2b(b-1)=n(n-1).$$我们被要求提供第一个解决方案$$n>10^{12}.$$---

 # 步骤 1 — 变换方程

 开始于$$2b(b-1)=n(n-1).$$扩张：$$2b^2-2b=n^2-n.$$乘以$4$：$$8b^2-8b=4n^2-4n.$$现在完成正方形：$$8b^2-8b+2=4n^2-4n+1.$$因此$$2(2b-1)^2=(2n-1)^2+1.$$重新排列：$$(2n-1)^2-2(2b-1)^2=-1.$$定义$$x=2n-1,\qquad y=2b-1.$$然后我们得到佩尔方程$$x^2-2y^2=-1.$$---

 # 步骤 2 — 佩尔方程递推

 负佩尔方程$$x^2-2y^2=-1$$递归生成无限多个解。 

前几个是：$$(1,1),\ (7,5),\ (41,29),\ (239,169),\dots$$这些对应于：$$n=\frac{x+1}{2},\qquad b=\frac{y+1}{2}.$$例如：

-$x=239,\ y=169$给出$$n=120,\qquad b=85,$$与问题陈述相匹配。 

解的标准递归是$$x_{k+1}=3x_k+4y_k,$$

$$y_{k+1}=2x_k+3y_k.$$转换回$(n,b)$，我们得到：$$n_{k+1}=3n_k+4b_k-3,$$

$$b_{k+1}=2n_k+3b_k-2.$$从已知解开始$$(n,b)=(21,15),$$我们反复生成更大的解决方案，直到$n>10^{12}$。

 # 第 3 步 — Python 实现```python
# Project Euler Problem 100

LIMIT = 10**12

# Initial known solution:
# total discs = 21
# blue discs  = 15
n = 21
b = 15

# Generate larger solutions using the Pell recurrence
while n <= LIMIT:
    n, b = (
        3 * n + 4 * b - 3,
        2 * n + 3 * b - 2
    )

print(b)
```---

 # 步骤 5 — 检查小案例

 开始于$(n,b)=(21,15)$：

 下一次递归给出：$$n=120,\qquad b=85.$$查看：$$\frac{85}{120}\cdot\frac{84}{119} = \frac{7140}{14280} = \frac12.$$正确的。 

继续递归最终得到：$$n=1\,070\,379\,110\,497,$$

$$b=756\,872\,327\,473.$$的确，$$n > 10^{12}.$$---
