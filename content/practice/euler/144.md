[欧拉项目问题 144](https://projecteuler.net/problem=144)

 ## 解决方案

 **答案：**`354`我们将激光束建模为在椭圆内反射的一系列直线段$$4x^2+y^2=100.$$我们被要求计算光束在从顶部的小开口射出之前撞击_内部_表面的次数：$$-0.01 \le x \le 0.01,\qquad y>0.$$光束从外部开始$(0,10.1)$首先到达椭圆$$(1.4,-9.6).$$---

 # 数学分析

 ## 1. 反射几何

 对于椭圆$$4x^2+y^2=100,$$隐式微分给出切线斜率：$$8x+2y\frac{dy}{dx}=0$$所以$$\frac{dy}{dx}=-\frac{4x}{y}.$$因此在某一点$(x,y)$：

 - 切向量可以视为$$T=(1,-4x/y),$$- 法向量垂直于此。 

一种更简洁的方法是使用椭圆的梯度：$$F(x,y)=4x^2+y^2.$$然后$$\nabla F=(8x,2y)$$是椭圆的法线。 

所以在撞击点$P=(x,y)$，法向量是$$N=(4x,y).$$---

 ## 2.矢量反射公式

 假设传入方向向量为$v$。 

法线反射$N$是：$$v_{\text{out}} = v - 2\frac{v\cdot N}{N\cdot N}N.$$这完全避免了三角学并且在数值上是稳定的。 

---

 ## 3. 寻找下一个路口

 假设光束离开点$P=(x_0,y_0)$有方向$v=(d_x,d_y)$。 

参数线是$$(x,y)=(x_0,y_0)+t(d_x,d_y).$$代入椭圆方程：$$4(x_0+t d_x)^2+(y_0+t d_y)^2=100.$$因为$P$已经位于椭圆上，一个根是$t=0$。 

第二个根给出了下一个撞击点。 

扩展：$$4(x_0^2+2x_0d_xt+t^2d_x^2) +y_0^2+2y_0d_yt+t^2d_y^2 =100.$$使用$4x_0^2+y_0^2=100$,$$t(8x_0d_x+2y_0d_y) +t^2(4d_x^2+d_y^2)=0.$$因此非零根是$$t = -\frac{8x_0d_x+2y_0d_y} {4d_x^2+d_y^2}.$$然后$$P_{\text{next}}=P+t\,v.$$---

 # Python 实现```python
import math

# Starting point outside the ellipse
x_prev, y_prev = 0.0, 10.1

# First impact point
x, y = 1.4, -9.6

# Count reflections on the internal surface
count = 0

while True:

    # Check whether beam exits through the hole
    if abs(x) <= 0.01 and y > 0:
        break

    # Incoming direction vector
    vx = x - x_prev
    vy = y - y_prev

    # Normal vector to ellipse at (x, y)
    nx = 4 * x
    ny = y

    # Reflect v across the normal
    dot = vx * nx + vy * ny
    norm_sq = nx * nx + ny * ny

    rx = vx - 2 * dot / norm_sq * nx
    ry = vy - 2 * dot / norm_sq * ny

    # Find next intersection with ellipse
    t = -(8 * x * rx + 2 * y * ry) / (4 * rx * rx + ry * ry)

    x_next = x + t * rx
    y_next = y + t * ry

    # Advance
    x_prev, y_prev = x, y
    x, y = x_next, y_next

    count += 1

print(count)
```---

 ## 退出条件```python

```光束只能通过顶部附近的小开口逸出。

 ## 传入方向```python

vy = y - y_prev
```这是从前一个点到当前点的方向。 

---

 ## 表面法线```python
nx = 4 * x
ny = y
```因为椭圆是$$4x^2+y^2=100,$$梯度$(8x,2y)$是正常的； 缩放比例$1/2$给出$(4x,y)$。 

---

 ## 反思步骤```python
dot = vx * nx + vy * ny
norm_sq = nx * nx + ny * ny

rx = vx - 2 * dot / norm_sq * nx
ry = vy - 2 * dot / norm_sq * ny
```这实现了矢量反射公式。 

---

 ## 下一个路口```python
t = -(8 * x * rx + 2 * y * ry) / (4 * rx * rx + ry * ry)
```这将计算与椭圆的非零交集参数。 

然后：```python
x_next = x + t * rx
y_next = y + t * ry
```给出下一个弹跳点。
