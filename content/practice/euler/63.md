[欧拉项目问题 63](https://projecteuler.net/problem=63)

 ## 解决方案

 **答案：**`49`我们寻找同时存在的所有正整数：

 - 一个$n$- 位数，以及
 - 一个$n$的力量。 
也就是说，数字的形式$$k^n$$这样$k^n$正好有$n$数字。 

---

 # 数学分析

 正整数$x$正好有$n$数字当且仅当$$10^{n-1} \le x < 10^n.$$代替$x = k^n$:$$10^{n-1} \le k^n < 10^n.$$取以 10 为底的对数：$$n-1 \le n\log_{10} k < n.$$正确的不等式始终成立$k<10$，因为那时$\log_{10} k < 1$。 

左不等式是重要的一个：$$n-1 \le n\log_{10} k.$$重新排列：$$1 - \frac1n \le \log_{10} k.$$等价地，$$n(1-\log_{10} k)\le 1.$$所以对于固定底座$k$，允许的指数满足$$n \le \frac{1}{1-\log_{10} k}.$$---

 ## 哪些碱基是可能的？ 

如果$k \ge 10$， 然后$k^n$有超过$n$数字，所以不可能。 

如果$k=1$， 然后$1^n=1$，只有 1 位数字，所以只有$n=1$作品。 

因此我们只需要$$k = 1,2,\dots,9.$$对于每个$k\in\{1,\dots,9\}$, 统计有多少个正整数$n$满足$$10^{n-1}\le k^n.$$使用导出的不等式：$$n \le \frac{1}{1-\log_{10} k}.$$因此有效数量$n$给定值$k$是$$\left\lfloor \frac{1}{1-\log_{10} k} \right\rfloor.$$现在计算：

 |$k$| 计数 |
 | --- | --- |
 | 1 | 1 |
 | 2 | 1 |
 | 3 | 1 |
 | 4 | 2 |
 | 5 | 3 |
 | 6 | 4 |
 | 7 | 6 |
 | 8 | 10 | 10
 | 9 | 21 | 21

 全部的：$$1+1+1+2+3+4+6+10+21 = 49.$$---

 # Python 实现```python
import math

count = 0

# Bases only need to go from 1 to 9
for k in range(1, 10):

    # Maximum n satisfying:
    # n <= 1 / (1 - log10(k))
    max_n = int(1 / (1 - math.log10(k)))

    count += max_n

print(count)
```---

---```python
max_n = int(1 / (1 - math.log10(k)))
```由推导可知：$$n \le \frac{1}{1-\log_{10} k}.$$取整数部分即可得出有效指数的数量。 

示例：

 -$k=7$:$$\frac1{1-\log_{10}7}\approx 6.45$$因此有 6 种有效权力：$7^1,\dots,7^6$。 

的确：

-$7^5 = 16807$有5位数字，
 -$7^6 = 117649$有 6 位数字，
 -$7^7$有 6 位数字，所以就到此为止。 

---```python
count += max_n
```添加该基地的贡献。 

---```python
print(count)
```输出最终总计。

 # 举例验证

 问题给出：$$7^5 = 16807$$这是 5 位数的五次方。 

还：$$8^9 = 134217728$$这是一个9位的9次方。 

两者都包含在上述不等式中。 

最终总分$49$是合理的，因为只有基地$1$–$9$可以工作，并且计数在基地附近快速增长$9$。 

---

 **答案：49**
