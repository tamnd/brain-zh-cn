[欧拉项目问题 286](https://projecteuler.net/problem=286)

 ## 解决方案

 **答案：**`52.6494571953`让$$p_x = 1 - \frac{x}{q}$$是芭芭拉从远处得分的概率$x$， 在哪里$x=1,2,\dots,50$。 

我们被告知，在 50 次投篮中得到**恰好 20 分**的概率正好是$2\%$:$$\Pr(\text{exactly 20 successes}) = 0.02.$$我们必须确定$q>50$。 

---

 # 数学分析

 对于每个镜头$x$:

 - 成功概率：$$p_x = 1-\frac{x}{q}$$- 错过概率：$$1-p_x = \frac{x}{q}.$$镜头是独立的，但每次镜头的概率不同，因此这不是标准二项式分布。 

因此我们使用动态规划。 

---

 ## DP 配方

 定义$$dp[k][s]$$作为考虑第一个之后的概率$k$投篮，芭芭拉准确得分$s$点。 

初始条件：$$dp[0][0]=1$$因为在任何射击之前，0 次成功的概率为 1。 

用于射击$k$:

 - 有概率$p_k$，分数增加 1，
 - 有概率$1-p_k$，它保持不变。 

所以，$$dp[k][s] = dp[k-1][s-1]\cdot p_k + dp[k-1][s]\cdot (1-p_k).$$处理完所有 50 个镜头后：$$P(q)=dp[50][20].$$我们必须解决$$P(q)=0.02.$$---

 # 单调性

 作为$q$增加：$$p_x = 1-\frac{x}{q}$$每次射击都会增加。 

因此，预期成功次数会增加，这意味着获得 20 次成功的概率最终会降低（因为平均值会超过 20）。 

数字上：

 -$P(52)\approx 0.0240$-$P(55)\approx 0.0101$因此解在 52 和 55 之间。 

因此我们可以使用二分查找。 

---

 # Python 实现```python
from math import *

def probability(q):
    # dp[s] = probability of exactly s successes so far
    dp = [0.0] * 21
    dp[0] = 1.0

    # shots from x = 1..50
    for x in range(1, 51):
        p = 1.0 - x / q

        new_dp = [0.0] * 21

        # zero successes case
        new_dp[0] = dp[0] * (1 - p)

        for s in range(1, 21):
            # make shot x
            make = dp[s - 1] * p

            # miss shot x
            miss = dp[s] * (1 - p)

            new_dp[s] = make + miss

        dp = new_dp

    return dp[20]

# Binary search for q
lo = 50.0
hi = 60.0

for _ in range(100):
    mid = (lo + hi) / 2

    if probability(mid) > 0.02:
        lo = mid
    else:
        hi = mid

q = (lo + hi) / 2

print("{:.10f}".format(q))
```---

 # 代码演练

 ###`probability(q)`计算正好 20 次成功的概率。 

我们一次只存储一行 DP：```python
dp[s]
```表示准确的概率`s`处理一些镜头后成功。 

---

 ### 过渡

 对于每个镜头：```python
make = dp[s - 1] * p
miss = dp[s] * (1 - p)
```这些对应于：

 - 达到`s`通过进行当前的拍摄，
 - 达到`s`错过当前镜头。 

---

 ### 二分查找

 我们寻找独特的$q$满意的$$P(q)=0.02.$$如果：```python
probability(mid) > 0.02
```然后$q$太小，所以我们将下限向上移动。 

经过100次迭代后，该值的准确度远超$10^{-10}$。 

---

 # 最终验证

 计算值是：$$q \approx 52.6494571953$$查看：

-$q>50$✔
 -$P(q)\approx 0.02$✔
 - 附近的值：

 -$q=52\Rightarrow P>0.02$-$q=55\Rightarrow P<0.02$所以解是一致的。
