[欧拉计划问题 131](https://projecteuler.net/problem=131)

 ## 解决方案

 **答案：**`173`我们寻找素数$p$使得存在一个正整数$n$和$$n^3+n^2p$$是一个完美的立方体。 

我们被告知，对于$p=19$,$$8^3+8^2\cdot 19=12^3.$$我们必须数一下有多少个这样的素数$p<10^6$。 

---

 # 步骤 1 — 代数分析

 我们想要整数$n,m>0$满意的$$n^3+n^2p=m^3.$$对左侧进行因式分解：$$n^2(n+p)=m^3.$$所以$$m^3=n^2(n+p).$$现在我们分析这个方程的结构。 

---

 ## 按键替换

 让$$m = nk$$对于一些理性的$k$。 替换：$$n^3k^3=n^2(n+p).$$取消$n^2$：$$nk^3=n+p.$$因此$$p=n(k^3-1).$$自从$p$是质数，这是极其严格的。 

因素：$$k^3-1=(k-1)(k^2+k+1).$$因此$$p=n(k-1)(k^2+k+1).$$因为$p$是素数并且$n\ge1$，除一个之外的所有因子都必须等于$1$。 

所以必然：$$n=k-1=1.$$但使用互质性来推导更清晰。 

---

 # 步骤 2 — 标准推导

 写$$m^3-n^3=n^2p.$$分解立方体的差异：$$(m-n)(m^2+mn+n^2)=n^2p.$$现在让$$m-n=d.$$然后$m=n+d$。 代入第二个因子：$$m^2+mn+n^2 =(n+d)^2+n(n+d)+n^2.$$扩展：$$=3n^2+3nd+d^2.$$所以$$d(3n^2+3nd+d^2)=n^2p.$$一个关键的观察：$$\gcd(d,n)=1.$$事实上，如果一个数整除两者$d=m-n$和$n$，它划分$m$也因此将两边分开$$m^3-n^3=n^2p,$$强迫矛盾，除非gcd是$1$。 

自从$d\mid n^2p$和$\gcd(d,n)=1$，我们必须有$$d\mid p.$$因为$p$是素数并且$d>0$,$$d=1 \quad \text{or} \quad d=p.$$如果$d=p$， 然后$$p(3n^2+3np+p^2)=n^2p,$$这意味着$$3n^2+3np+p^2=n^2,$$不可能的。 

因此$$d=1.$$所以$$m=n+1.$$替补后卫：$$(n+1)^3-n^3=n^2p.$$扩张：$$3n^2+3n+1=n^2p.$$但直接从原始方程中进行预期的重新排列会更容易：$$n^3+n^2p=(n+1)^3.$$因此$$n^2p=(n+1)^3-n^3.$$计算差异：$$(n+1)^3-n^3=3n^2+3n+1.$$所以$$p=\frac{3n^2+3n+1}{n^2}.$$这通常看起来不是完整的，所以我们需要一个更清晰的参数化。 

---

 # 步骤 3 — 正确的参数化

 让$$m=n+k.$$然后$$m^3-n^3 =3n^2k+3nk^2+k^3.$$因为这等于$n^2p$,$$n^2p = k(3n^2+3nk+k^2).$$再次$\gcd(n,k)=1$， 所以$k\mid p$。 自从$p$是素数，$$k=p.$$然后$$n^2 = 3n^2+3np+p^2,$$不可能，除非我们有$$k=1.$$因此$$m=n+1.$$现在仔细替换：$$(n+1)^3=n^3+n^2p.$$扩张：$$n^3+3n^2+3n+1=n^3+n^2p.$$因此$$p=\frac{3n^2+3n+1}{n^2}.$$这看起来又是错误的，因为$p=19$与$n=8$。 让我们检查一下：$$\frac{3(64)+24+1}{64}=\frac{217}{64}.$$所以我们的假设$m=n+1$是假的。 

让我们干净地重新开始吧。 

---

 # 步骤 4 — 优雅的因式分解

 来自$$n^3+n^2p=m^3,$$除以$n^3$：$$1+\frac{p}{n}=\left(\frac{m}{n}\right)^3.$$让$$\frac{m}{n}=\frac{a}{b}$$用最低的术语来说。 然后$$1+\frac{p}{n}=\frac{a^3}{b^3}.$$重新排列：$$\frac{p}{n}=\frac{a^3-b^3}{b^3}.$$因此$$pb^3=n(a^3-b^3).$$自从$a,b$是互质的，$$a^3-b^3=(a-b)(a^2+ab+b^2).$$为了$p$成为素数，唯一的可能是$$a-b=1.$$放$$a=b+1.$$然后$$a^3-b^3 =(b+1)^3-b^3 =3b^2+3b+1.$$所以$$p=3b^2+3b+1.$$这是关键结果。 

确实，与$b=2$：$$p=3(4)+6+1=19.$$这个例子给出了$$n=b^3=8,\qquad m=a^3=27 \Rightarrow m=12,$$完美匹配，因为$$8^3+8^2\cdot19=12^3.$$所以问题就简化为：

 > 计算以下形式的素数
 >
 >
 >
 >
 >$$p=3b^2+3b+1$$>
 >
 >
 >
 > 低于 100 万。 

---

 # 步骤 5 — 绑定$b$我们需要$$3b^2+3b+1<10^6.$$近似：$$3b^2<10^6 \Rightarrow b<577.35.$$所以我们只测试$b=1,\dots,576$。 

---

 # Python 实现```python
from math import isqrt

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    
    limit = isqrt(n)
    d = 3
    
    while d <= limit:
        if n % d == 0:
            return False
        d += 2
    
    return True

count = 0
values = []

b = 1

while True:
    p = 3*b*b + 3*b + 1
    
    if p >= 1_000_000:
        break
    
    if is_prime(p):
        count += 1
        values.append(p)
    
    b += 1

print(count)
```---
