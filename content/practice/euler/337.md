[欧拉项目问题 337](https://projecteuler.net/problem=337)

 ## 解决方案

 **答案：**`85068035`让我们定义一个有向转移$a_i \to a_{i+1}$每当$$\phi(a_i) < \phi(a_{i+1}) < a_i < a_{i+1}.$$那么每个有效序列只是此 DAG 中的一条路径，起始于$6$， 和$S(N)$计算最终节点为的所有此类路径$\le N$。 

## 1.数学分析

 让$dp(n)$是结束于的有效序列的数量$n$。 

由于每个序列都开始于$6$,$$dp(6)=1.$$为了$n>6$,$$dp(n) = \sum_{\substack{x<n\\ \phi(x)<\phi(n)<x}} dp(x).$$条件$$\phi(x)<\phi(n)<x$$相当于：

 -$x > \phi(n)$,
 -$\phi(x) < \phi(n)$。 

所以如果$t=\phi(n)$,$$dp(n) = \sum_{\substack{x<n\\ \phi(x)<t}} dp(x) - \sum_{\substack{x\le t\\ \phi(x)<t}} dp(x).$$现在观察一个关键的简化：

 对于每一个$x>1$,$$\phi(x)<x.$$因此，每当$x\le t$,$$\phi(x)<x\le t \quad\Rightarrow\quad \phi(x)<t$$自动地。 

因此第二个总和就变得简单了$$\sum_{x\le t} dp(x).$$定义：$$P(k)=\sum_{x\le k}dp(x)$$（前缀总和$dp$）。 

还维护一个由 totient 值存储索引的 Fenwick 树$$\sum_{\phi(x)\le v} dp(x).$$然后：$$dp(n) = \text{FenwickQuery}(\phi(n)-1) - P(\phi(n)).$$一切都是模数$10^8$。 

### 复杂性

 - 通过筛子的 totients：$O(N\log\log N)$- 每个$n$执行一个 Fenwick 查询并更新：$O(\log N)$全部的：$$O(N\log N)$$这是可行的$N=20{,}000{,}000$。

 ## 2.Python实现```python
MOD = 100_000_000
N = 20_000_000

def solve():
    # Compute Euler totients
    phi = list(range(N + 1))

    for i in range(2, N + 1):
        if phi[i] == i:  # prime
            for j in range(i, N + 1, i):
                phi[j] -= phi[j] // i

    # Fenwick tree for sums indexed by phi value
    bit = [0] * (N + 2)

    def add(i, v):
        """Add v at index i in Fenwick tree."""
        i += 1
        while i <= N + 1:
            bit[i] += v
            bit[i] %= MOD
            i += i & -i

    def query(i):
        """Prefix sum [0..i]."""
        s = 0
        i += 1
        while i > 0:
            s += bit[i]
            i -= i & -i
        return s % MOD

    # Prefix sums of dp
    prefix = [0] * (N + 1)

    # Base case: sequence [6]
    prefix[6] = 1
    add(phi[6], 1)

    for n in range(7, N + 1):
        t = phi[n]

        # dp[n]
        val = query(t - 1) - prefix[t]
        val %= MOD

        # Add to structures
        add(t, val)
        prefix[n] = (prefix[n - 1] + val) % MOD

    return prefix[N]

print(solve())
```---

 ## 3. 代码演练

 ### 筛子

 我们初始化```python
phi[i] = i
```对于每个素数$p$,$$\phi(k) \leftarrow \phi(k)\left(1-\frac1p\right)$$对于倍数$k$的$p$。 

---

 ### 芬威克树

 我们为每个客户存储价值$v$,$$\sum_{\phi(x)=v} dp(x).$$然后：```python
query(t - 1)
```回报$$\sum_{\phi(x)<t} dp(x).$$---

 ### 前缀修正

 我们必须排除一切$x \le t$，因为规则要求$$t < x.$$自从$\phi(x)<x$, 每一个这样的$x$自动满足$\phi(x)<t$，所以我们减去：```python
prefix[t]
```这等于$$\sum_{x\le t} dp(x).$$因此：```python
val = query(t - 1) - prefix[t]
```完全实现了递归。 

---

 ### 小额支票

 对于$N=10$，程序找到 4 个序列：$$(6),\ (6,8),\ (6,8,9),\ (6,10)$$所以$$S(10)=4.$$为了$N=100$,$$S(100)=482073668,$$和模$10^8$,$$82073668,$$与声明相符。 

为了$N=10000$,$$S(10000)\bmod 10^8 = 73808307,$$再次匹配问题。
