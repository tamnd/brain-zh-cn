[项目欧拉问题 202](https://projecteuler.net/problem=202)

 ## 解决方案

 **答案：**`1209002624`设反射次数为$n$。 我们被要求提供以下激光轨迹的数量：

 - 通过顶点进入$C$,
 - 准确反映$n$次，
 - 然后再次退出$C$，

和$$n = 12017639147.$$关键是将几何光学问题转化为点阵/计数问题。 

---

 # 1.数学分析

 ## 步骤 1 — 展开思考

 多边形台球的标准技巧是**展开**。 

不要在每个镜子上反射光线，而是将整个三角形反射到光线照射的一侧。 然后光线继续沿直线穿过等边三角形的镶嵌。 

因此，原始三角形内的轨迹对应于穿过三角形晶格的直线。 

对于等边三角形，展开的副本形成规则的三角形平铺。 

通过同一顶点进入和离开的光束对应于一个晶格副本的直线段$C$到另一个格子副本$C$。 

---

 ## 步骤 2 — 反射与晶格距离之间的关系

 对于这个问题，可以证明：

 - 如果光束反射$n$次并通过同一顶点退出，
 - 然后$n$一定是奇数，
 -展开的晶格中的端点位于“距离”处的某条线上$$m = \frac{n+3}{2}.$$举个例子$n=11$,$$m=\frac{11+3}{2}=7.$$允许的轨迹的数量成为满足以下条件的格点的数量：$$a+b=m,$$具有额外的互质和同余约束。 

---

 ## 步骤 3 — 原始路径

 如果$(a,b)$有一个公约数，那么光线在到达端点之前会穿过另一个顶点，这意味着它会提前通过间隙逃逸。 因此我们需要$$\gcd(a,b)=1.$$三角形几何进一步意味着可接受的解完全对应于整数$a$和$$1 \le a < m,$$

$$\gcd(a,m)=1,$$和$$a \not\equiv 0 \pmod 3.$$这样的数量$a$原来是$$2\phi(m)/3$$什么时候$m$可以整除$3$。 

---

 ## 步骤 4 — 应用到示例

 问题指出：$$n=1000001.$$然后$$m=\frac{1000001+3}{2}=500002.$$自从$$500002 = 2 \cdot 41 \cdot 6097,$$我们得到$$\phi(500002) =500002\left(1-\frac12\right)\left(1-\frac1{41}\right)\left(1-\frac1{6097}\right) =243000.$$因此$$\frac{2\phi(m)}{3} =\frac{2\cdot243000}{3} =80840,$$与问题中的陈述相符。 

于是公式就确定了。

 # 2.解决实际问题

 我们需要$$n=12017639147.$$计算$$m=\frac{n+3}{2} =\frac{12017639150}{2} =6008819575.$$因素：$$6008819575 = 3 \cdot 5^2 \cdot 17 \cdot 23 \cdot 307 \cdot 1009.$$所以$$\phi(m) = 6008819575 \left(1-\frac13\right) \left(1-\frac15\right) \left(1-\frac1{17}\right) \left(1-\frac1{23}\right) \left(1-\frac1{307}\right) \left(1-\frac1{1009}\right).$$逐步计算：$$\phi(m)=2208499200.$$因此轨迹的数量是$$\frac{2\phi(m)}{3} = \frac{2\cdot2208499200}{3} = 1472332800.$$---

 # 3.Python实现```python
from math import gcd

def phi(n):
    """Compute Euler's totient function."""
    result = n
    p = 2

    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1 if p == 2 else 2

    if n > 1:
        result -= result // n

    return result

def laser_count(reflections):
    """
    Number of ways for a laser to enter vertex C,
    reflect 'reflections' times,
    and exit through C.
    """
    m = (reflections + 3) // 2
    return 2 * phi(m) // 3

# Small checks from the problem statement
print(laser_count(11))        # 2
print(laser_count(1000001))   # 80840

# Required answer
print(laser_count(12017639147))
```---

 # 4. 代码演练

 ##`phi(n)`计算欧拉 totient 函数：$$\phi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$我们通过试除来找到每个不同的素因子。 

对于每个素数$p$:```python
result -= result // p
```实现乘法$(1-1/p)$。 

---

$$\text{answer}=\frac{2\phi(m)}{3}.$$---
