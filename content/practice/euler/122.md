[欧拉计划问题 122](https://projecteuler.net/problem=122)

 ## 解决方案

 **答案：**`1582`让$m(k)$表示计算所需的最小乘法次数$n^k$从$n$。 

这是经典的**最小加法链**问题。 

**附加链**$k$是一个序列$$1=a_0<a_1<\cdots<a_r=k$$使得每一项都满足$$a_i=a_j+a_\ell \qquad (j,\ell<i).$$每一步对应一次乘法：$$n^{a_j}\cdot n^{a_\ell}=n^{a_i}.$$因此：

 - 链条长度$r$等于乘法次数，
 - 和$m(k)$是结束于的最短加法链的长度$k$。 

例如，对于$15$：$$1,2,3,6,12,15$$有长度$5$, 给予$$m(15)=5.$$---

 # 数学分析

 我们必须计算$$\sum_{k=1}^{200} m(k).$$对所有链条的暴力破解是巨大的，但是$200$足够小以进行仔细修剪的深度优先搜索。 

---

 ## 1. 加法链

 假设我们现在知道权力$$n^{a_0},n^{a_1},\dots,n^{a_r}.$$一次乘法结合了两个已知的指数：$$n^{a_i}n^{a_j}=n^{a_i+a_j}.$$因此，每个新指数都是之前两个指数的总和。 

因此最小乘法计数$m(k)$等于最短加成链长度$k$。 

---

 ## 2. 下限

 如果一条链子有长度$r$，之后最大可能的指数$r$步骤是通过每次加倍获得的：$$1,2,4,8,\dots,2^r.$$因此：$$k\le 2^r \quad\Rightarrow\quad r\ge \lceil \log_2 k\rceil.$$这给出了强有力的修剪规则。 

---

 ## 3.深度优先搜索策略

 我们递归地构建链。 

在任何阶段我们都有：$$[1,a_1,a_2,\dots,a_t].$$从最大指数开始$a_t$，新的候选人是：$$a_t+a_i \qquad (0\le i\le t).$$为什么这就足够了？ 

最优链定理表明，总是存在一条最优链，其中每个新项都使用前一项（“布劳尔链”）。 为了$k\le 200$，此搜索对于 Euler 122 来说是充分且标准的。 

我们在保持最已知长度的同时进行深度优先搜索。 

---

 ## 4.迭代深化

 对于每个目标$k$，我们搜索长度的链：$$0,1,2,\dots$$直到成功。 

因为搜索深度很小（最大$m(k)$为了$k\le200$只是$9$），这是非常快的。 

---

 # Python 实现```python
from math import log2, ceil

LIMIT = 200

# best[k] = minimal addition-chain length found for k
best = [float('inf')] * (LIMIT + 1)
best[1] = 0

def dfs(chain, depth_limit):
    """
    Depth-first generation of addition chains.

    chain[-1] is the current largest exponent.
    len(chain)-1 is the number of multiplications used.
    """

    current = chain[-1]
    depth = len(chain) - 1

    # Update best result for current exponent
    if depth < best[current]:
        best[current] = depth

    # No more depth available
    if depth == depth_limit:
        return

    # Lower-bound pruning:
    # even if we double every remaining step,
    # can we improve anything?
    max_possible = current << (depth_limit - depth)

    # Generate next exponents in descending order
    # (larger jumps first tends to succeed earlier)
    used = set()

    for i in range(len(chain) - 1, -1, -1):
        nxt = current + chain[i]

        if nxt > LIMIT:
            continue

        if nxt in used:
            continue
        used.add(nxt)

        # If we already know an equal/better chain, skip
        if depth + 1 >= best[nxt]:
            continue

        # Append and recurse
        chain.append(nxt)
        dfs(chain, depth_limit)
        chain.pop()

# Iterative deepening
# Upper bound is safely 11 for n <= 200
for limit in range(1, 12):
    dfs([1], limit)

answer = sum(best[1:])

print(answer)
```---
