 ## 解决方案

 **答案：**`254.54470757`## 问题陈述

 欧拉项目问题 978 的标题是 **“随机游走偏度”**。 声明是：

 > 在这个问题中，我们考虑整数上的随机游走$\mathbb{Z}$，其中我们当时的位置$t$表示为$X_t$。 
>
 >
 >
 >
 > 时间$0$我们从位置开始$0$。 那是，$X_0=0$。 
>
 > 时间$1$我们跳到位置$1$。 那是，$X_1=1$。 
>
 > 此后，在某个时间$t=2,3,\dots$我们的规模有了很大的跳跃$|X_{t-2}|$正向或负向的概率$1/2$各方面。 如果$X_{t-2}=0$我们按时呆在原地$t$。 
>
 >
 >
 >
 > 在$t=5$我们找到了自己的位置$X_5$具有以下分布：
 >
 >
 >
 >
 >$$X_5=\begin{cases} > -1 & \text{with probability }3/8\\ > 1 & \text{with probability }3/8\\ > 3 & \text{with probability }1/8\\ > 5 & \text{with probability }1/8 > \end{cases}$$>
 >
 >
 >
 > 标准差$\sigma$随机变量的$X$与平均值$\mu$定义为
 >
 >
 >
 >
 >$$\sigma=\sqrt{\mathbb{E}[X^2]-\mu^2}$$>
 >
 >
 >
 > 此外，偏度$X$定义为
 >
 >
 >
 >
 >$$\text{Skew}(X)=\mathbb{E}\!\left[\left(\frac{X-\mu}{\sigma}\right)^3\right]$$>
 >
 >
 >
 > 对于$X_5$，这意味着$1$和标准差$2$，我们发现
 >
 >
 >
 >
 >$$\text{Skew}(X_5)=0.75.$$>
 >
 >
 >
 > 还给你
 >
 >
 >
 >
 >$$\text{Skew}(X_{10})\approx2.50997097.$$>
 >
 >
 >
 > 查找$\text{Skew}(X_{50})$。 将您的答案四舍五入到小数点后八位数字。

 # 数学分析

 定义独立随机符号$\varepsilon_t\in\{-1,+1\}$为了$t\ge2$，每个都有概率$1/2$。 

过程是$$X_t = X_{t-1} + \varepsilon_t |X_{t-2}|.$$我们需要偏度：$$\text{Skew}(X_n) = \frac{\mathbb E[(X_n-\mu)^3]}{\sigma^3}.$$所以我们需要：

 - 平均值$\mu_n=\mathbb E[X_n]$,
 - 方差，
 - 第三个中心时刻。 

---

 ## 步骤 1：平均值

 以过去为条件，$$\mathbb E[\varepsilon_t]=0,$$因此$$\mathbb E[X_t] = \mathbb E[X_{t-1}] + \mathbb E[\varepsilon_t |X_{t-2}|] = \mathbb E[X_{t-1}].$$自从$X_1=1$,$$\boxed{\mathbb E[X_t]=1 \quad \forall t\ge1.}$$所以平均值总是$1$。 

---

 # 第二步：第二时刻

 让$$a_t=\mathbb E[X_t^2].$$扩张：$$X_t^2 = X_{t-1}^2 + X_{t-2}^2 + 2\varepsilon_t X_{t-1}|X_{t-2}|.$$取期望可以消除交叉项：$$a_t=a_{t-1}+a_{t-2}.$$初始值：$$a_0=0,\qquad a_1=1.$$因此$a_t$正是斐波那契数列：$$\boxed{a_t=F_t}.$$所以$$\operatorname{Var}(X_t)=F_t-1.$$为了$t=50$,$$F_{50}=12586269025.$$因此$$\sigma^2 = 12586269024.$$---

 # 第三步：第三时刻

 让$$b_t=\mathbb E[X_t^3].$$扩张：$$(X_{t-1}+\varepsilon_t|X_{t-2}|)^3.$$的奇次幂$\varepsilon_t$消失在期待中，给予$$b_t = b_{t-1} + 3\mathbb E[X_{t-1}X_{t-2}^2].$$现在定义$$c_t=\mathbb E[X_tX_{t-1}^2].$$使用$$X_t=X_{t-1}+\varepsilon_t|X_{t-2}|,$$我们得到$$c_t = \mathbb E[X_{t-1}^3] + \mathbb E[\varepsilon_t|X_{t-2}|X_{t-1}^2].$$第二项又消失了，所以$$c_t=b_{t-1}.$$所以$$\boxed{b_t=b_{t-1}+3b_{t-2}}.$$初始条件：$$b_0=0,\qquad b_1=1.$$向前计算给出：$$b_{50}=359426118413557441.$$---

 # 第四步：第三中心矩

 由于平均值是$1$,$$\mu_3 = \mathbb E[(X_{50}-1)^3].$$使用$$\mathbb E[(X-1)^3] = \mathbb E[X^3]-3\mathbb E[X^2]+3\mathbb E[X]-1,$$和$\mathbb E[X]=1$,$$\mu_3 = b_{50}-3F_{50}+2.$$替代值：$$\mu_3 = 359426118413557441 - 3(12586269025) + 2 = 359426080654750368.$$---

 # 步骤 5：偏度$$\text{Skew}(X_{50}) = \frac{359426080654750368}{(12586269024)^{3/2}}.$$从数字上看，$$\boxed{ \text{Skew}(X_{50}) \approx 254.54470756901193 }$$四舍五入到八位数字：$$\boxed{254.54470757}$$---

 # Python 实现```python
from math import sqrt

N = 50

# Second moments: a[n] = E[X_n^2]
a = [0] * (N + 1)
a[0] = 0
a[1] = 1

for n in range(2, N + 1):
    a[n] = a[n - 1] + a[n - 2]

# Third moments: b[n] = E[X_n^3]
b = [0] * (N + 1)
b[0] = 0
b[1] = 1

for n in range(2, N + 1):
    b[n] = b[n - 1] + 3 * b[n - 2]

mean = 1
variance = a[N] - 1
sigma = sqrt(variance)

third_central = b[N] - 3 * a[N] + 2

skewness = third_central / (sigma ** 3)

print(f"{skewness:.8f}")
```---

 # 代码演练

 -`a[n]`商店$\mathbb E[X_n^2]$。 
- 复发$$a_n=a_{n-1}+a_{n-2}$$generates Fibonacci numbers.
 -`b[n]`商店$\mathbb E[X_n^3]$。 
- 复发$$b_n=b_{n-1}+3b_{n-2}$$来自立方展开式。 
- 方差是$$\sigma^2=a_n-1.$$- 第三个中心矩是$$b_n-3a_n+2.$$- 最后：$$\text{Skew}=\mu_3/\sigma^3.$$该代码还重现了提供的检查值：$$\text{Skew}(X_{10})\approx2.50997097.$$所以推导是一致的。
