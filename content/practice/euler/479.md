[欧拉项目 479 问题](https://projecteuler.net/problem=479)

 ## 解决方案

 **答案：**`191541795`让$$\frac1x=\left(\frac{k}{x}\right)^2(k+x^2)-kx.$$我们被告知$a_k,b_k,c_k$是这个方程的三个根，我们定义$$S(n)=\sum_{p=1}^n\sum_{k=1}^n (a_k+b_k)^p(b_k+c_k)^p(c_k+a_k)^p.$$我们必须计算$S(10^6)\bmod 1\,000\,000\,007$。 

---

 # 步骤 1：将方程转换为多项式

 开始于$$\frac1x=\frac{k^2}{x^2}(k+x^2)-kx,$$扩张：$$\frac1x=\frac{k^3}{x^2}+k^2-kx.$$乘以通过$x^2$：$$x=k^3+k^2x^2-kx^3.$$重新排列：$$kx^3-k^2x^2+x-k^3=0.$$因此$a_k,b_k,c_k$是的根$$kx^3-k^2x^2+x-k^3=0.$$除以$k$：$$x^3-kx^2+\frac1k x-k^2=0.$$所以对于莫尼克立方$$x^3-s_1x^2+s_2x-s_3,$$维埃塔给予$$s_1=a+b+c=k,$$

$$s_2=ab+ac+bc=\frac1k,$$

$$s_3=abc=k^2.$$---

 # 第二步：简化表达式

 我们需要$$(a+b)(b+c)(c+a).$$标准对称恒等式是$$(a+b)(b+c)(c+a) =(a+b+c)(ab+ac+bc)-abc.$$所以$$(a+b)(b+c)(c+a) =s_1s_2-s_3.$$代入 Vieta 值：$$=k\cdot \frac1k-k^2 =1-k^2.$$因此$$(a_k+b_k)^p(b_k+c_k)^p(c_k+a_k)^p =(1-k^2)^p.$$所以$$S(n)=\sum_{k=1}^n\sum_{p=1}^n(1-k^2)^p.$$---

 # 第三步：评估几何级数

 对于固定$k$,$$\sum_{p=1}^n r^p =\frac{r(r^n-1)}{r-1}, \quad r=1-k^2.$$因此$$S(n)=\sum_{k=1}^n \frac{(1-k^2)\big((1-k^2)^n-1\big)}{-k^2}.$$我们只需要这个模$$M=1\,000\,000\,007.$$自从$M$是素数，除以$k^2$是模逆的乘法。 

复杂度是$O(n\log M)$，很容易足够快$n=10^6$。 

---

 # 第四步：Python实现```python
MOD = 1_000_000_007
n = 10**6

ans = 0

for k in range(1, n + 1):
    r = (1 - k * k) % MOD

    # Sum_{p=1}^n r^p
    # = r * (r^n - 1) / (r - 1)

    numerator = r * (pow(r, n, MOD) - 1)
    denominator = (r - 1) % MOD

    geom = numerator * pow(denominator, MOD - 2, MOD)
    ans = (ans + geom) % MOD

print(ans % MOD)
```---
