 **答案：**`248155780267521`我们寻求以下形式的数字$$n = s(n)^k$$在哪里$s(n)$是小数位的总和$n$,$k \ge 2$， 和$n$至少有两位数。 

顺序$a_n$由所有这些逐渐排序的数字组成。 

我们得到：

 -$512 = 8^3$, 带数字和$5+1+2=8$-$614656 = 28^4$, 带数字和$6+1+4+6+5+6=28$并要求找到$a_{30}$。

 # 数学分析

 假设一个数字$N$满足条件。 

让$$s = s(N)$$为其数字和。 然后$$N = s^k$$对于某个整数$k \ge 2$。 

因此，每个有效数字都是一个完美的幂，其基数等于其自身的数字和。 

蛮力的想法是：

 1.尝试多种基础$s$。 
2. 产生力量$s^k$。 
3. 检查数字和是否$s^k$等于$s$。 

这是有效的，因为：

 - 数字总和增长缓慢，
 - 力量迅速增长，
 - 只有极少数数字满足条件。 

---

 ## 限制搜索

 如果$N$有$d$数字，那么$$s(N) \le 9d.$$但$N = s^k$，所以对于固定的$s$，力量最终变得巨大。 

根据经验，搜索最多几百个基数和最多 15-20 个指数就足以捕获前 30 个术语。

 # Python 实现```python
def digit_sum(n):
    """Return the sum of decimal digits of n."""
    return sum(int(c) for c in str(n))

values = set()

# Try possible digit sums (bases)
for s in range(2, 200):

    # Generate powers s^k
    power = s * s  # start with k = 2

    for k in range(2, 20):

        # Check the defining property
        if digit_sum(power) == s:
            # Must contain at least two digits
            if power >= 10:
                values.add(power)

        power *= s

# Sort the sequence
sequence = sorted(values)

# Display first several terms
for i, v in enumerate(sequence[:30], start=1):
    print(i, v)

print("a_30 =", sequence[29])
```---
