[项目欧拉问题 281](https://projecteuler.net/problem=281)

 ## 解决方案

 **答案：**`1485776387445623`让$N = mn$。 

我们必须计算循环排列$N$披萨片使用$m$配料，每一个都完全一致$n$次。 

旋转被识别，反射是清晰的。 

我们定义：

 f(m,n)=\text{# 循环排列 } mn \text{ 切片，每个切片使用 } m \text{ 配料 } n \text{ 次}。 

我们寻求$$\sum_{f(m,n)\le 10^{15}} f(m,n).$$---

 # 1.数学分析

 这是 **伯恩赛德引理** 在循环旋转上的经典应用。 

设循环群$C_{mn}$轮流执行安排。 

---

 ## 步骤 1：伯恩赛德引理

 伯恩赛德给出：$$f(m,n)=\frac1{mn}\sum_{r=0}^{mn-1} \mathrm{Fix}(r),$$在哪里$\mathrm{Fix}(r)$是旋转不变的排列数量$r$切片。 

---

 ## 步骤 2：轮换的结构

 对于旋转$r$， 让$$g=\gcd(r,mn).$$然后旋转分解$mn$职位分为：

 -$g$周期，
 - 每个长度$$L=\frac{mn}{g}.$$为了保持固定的排列，循环中的每个位置都必须具有相同的配料。 

因此每个配料都很重要$n$必须能被周期长度整除$L$:$$L \mid n.$$所以只有除数$L$的$n$贡献。 

---

 ## 步骤 3：计算固定安排

 假设$L\mid n$，并定义$$d=\frac{n}{L}.$$然后每个配料正好占据$d$循环。 

由于有$$g=\frac{mn}{L}=md$$循环总数，将循环分配给浇头的方法数量是$$\frac{(md)!}{(d!)^m}.$$---

 ## 步骤 4：多少次旋转有周期长度$L$？ 

旋转有周期长度$L$恰好在什么时候$$\frac{mn}{\gcd(r,mn)}=L.$$这种旋转的次数就是欧拉的 totient：$$\varphi(L).$$因此伯恩赛德变成$$f(m,n) = \frac1{mn} \sum_{L\mid n} \varphi(L)\, \frac{(mn/L)!}{((n/L)!)^m}.$$替代$d=n/L$:$f(m,n)=\frac{1}{mn}\sum_{d\mid n}\varphi\!\left(\frac{n}{d}\right)\frac{(md)!}{(d!)^m}$这就是我们计算的公式。 

---

 # 2. 限制搜索

 价值增长得非常快。 

为了$n=1$,$$f(m,1)=(m-1)!.$$自从$$18! / 18 = 17! = 355687428096000 \le 10^{15},$$但$$19! / 19 = 18! > 10^{15},$$我们只需要$m\le 18$。 

类似地，对于每个固定的$m$,$f(m,n)$快速增长$n$，因此只有极小的有限对集合幸存下来。 

事实上只有 74 个有效对$(m,n)$。 

---

 # 3.Python实现```python
from math import factorial
from sympy import divisors, totient

LIMIT = 10**15

def f(m, n):
    """
    Compute:
        f(m,n) = number of circular arrangements
    using Burnside's lemma.
    """
    total = 0

    for d in divisors(n):
        total += (
            totient(n // d)
            * factorial(m * d)
            // (factorial(d) ** m)
        )

    return total // (m * n)

answer = 0

m = 2

while True:

    # Minimal value for this m occurs at n = 1
    if f(m, 1) > LIMIT:
        break

    n = 1

    while True:
        value = f(m, n)

        if value > LIMIT:
            break

        answer += value
        n += 1

    m += 1

print(answer)
```---
