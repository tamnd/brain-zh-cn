 ## 解决方案

 **答案：**`73162890`关键的观察结果是，每次成功的登录尝试都会对秘密密码的数字给出**部分排序约束**。 

如果登录尝试是`319`， 然后：

-`3`出现在之前`1`-`1`出现在之前`9`- 所以`3`也出现在之前`9`所以整个问题就变成了：

 > 找到满足所有优先级约束的数字的**最短序列**。 

这正是有向图上的**拓扑排序**问题。

 # 步骤 2 — 构建有向图

 收集所有优先关系。 

从所有条目中，我们获得如下约束：

 -$7 \to 3$-$7 \to 1$-$3 \to 1$-$1 \to 9$-$6 \to 8$-$8 \to 0$- 等

 涉及的数字有：$$\{0,1,2,3,6,7,8,9\}$$注意数字`4`和`5`永远不会出现，因此它们不能属于最短的有效密码。

 # 步骤 3 — 拓扑排序

 我们现在反复选择一个数字，没有未遇到的前辈。 

顺序的出现是独一无二的：

 1.`7`必须是第一位的。 
2.然后`3`。 
3. 然后`1`。 
4.然后`6`。 
5. 然后`2`。 
6.然后`8`。 
7. 然后`9`。 
8.最后`0`。 

因此最短的密码是：$$73162890$$---

 # Python 实现```python
from collections import defaultdict, deque

# Login attempts from the problem file
attempts = [
    "319","680","180","690","129","620","762","689","762","318",
    "368","710","720","710","629","168","160","689","716","731",
    "736","729","316","729","729","710","769","290","719","680",
    "318","389","162","289","162","718","729","319","790","680",
    "890","362","319","760","316","729","380","319","728","716"
]

# Directed graph
graph = defaultdict(set)

# In-degree count for topological sort
indegree = defaultdict(int)

# All digits appearing in the file
digits = set()

# Build precedence graph
for attempt in attempts:
    a, b, c = attempt
    digits.update([a, b, c])

    # Add edge a -> b
    if b not in graph[a]:
        graph[a].add(b)
        indegree[b] += 1

    # Add edge b -> c
    if c not in graph[b]:
        graph[b].add(c)
        indegree[c] += 1

# Ensure every digit exists in indegree dictionary
for d in digits:
    indegree[d] += 0

# Queue all nodes with indegree 0
queue = deque(sorted([d for d in digits if indegree[d] == 0]))

# Topological ordering
result = []

while queue:
    node = queue.popleft()
    result.append(node)

    for nxt in sorted(graph[node]):
        indegree[nxt] -= 1
        if indegree[nxt] == 0:
            queue.append(nxt)

# Construct passcode
passcode = "".join(result)

print(passcode)
```---

 # 代码演练

 ## 构建图表```python
graph = defaultdict(set)
indegree = defaultdict(int)
```-`graph[a]`存储后面必须出现的所有数字`a`。 
-`indegree[x]`计算有多少先决条件数字`x`有。 

---

 ## 处理每次登录尝试```python
a, b, c = attempt
```对于像这样的字符串`"319"`:

 -`a = '3'`-`b = '1'`-`c = '9'`我们添加边：```python
a -> b
b -> c
```这对所需的排序进行编码。 

---

 ## 拓扑排序

 数字与`indegree = 0`没有剩余的先决条件。```python
queue = deque(sorted([...]))
```我们反复强调：

 1.删除一个有效数字，
 2.将其附加到答案中，
 3.减少从属数字的度数。 

这构造了满足所有约束的有效最短排序。
