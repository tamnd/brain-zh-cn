[欧拉计划问题 58](https://projecteuler.net/problem=58)

 ## 解决方案

 **答案：**`26241`这个问题的关键是理解对角线上的数字如何随着螺旋的增长而演变。 

对于边长为螺旋线$n$（在哪里$n$是奇数），外层恰好贡献了四个新的角数。 

例如：

 - 边长$1$： 只是$1$- 边长$3$: 角是$3,5,7,9$- 边长$5$: 角是$13,17,21,25$- 边长$7$: 角是$31,37,43,49$我们需要跟踪有多少个对角线数字是质数，并确定比率何时首次低于$10\%$。 

---

 # 数学分析

 ## 1. 角数公式

 考虑一个边长为奇数的方形螺旋$n$。 

图层中最大的数字始终是右下角：$$n^2$$相邻角点之间的步长为：$$n-1$$所以四个角是：$$\begin{aligned} c_1 &= n^2 \\ c_2 &= n^2-(n-1) \\ c_3 &= n^2-2(n-1) \\ c_4 &= n^2-3(n-1) \end{aligned}$$示例$n=7$:$$49,\ 43,\ 37,\ 31$$与图表相符。 

---

 ## 2. 对角线条目数

 每个新层都会添加 4 个对角线数字。 

对于边长$n$:$$\text{total diagonal numbers} = 2n-1$$查看：

-$n=1$:$1$-$n=3$:$5$-$n=5$:$9$-$n=7$:$13$正确的。 

---

 ## 3.质数比

 在每一层：

 1. 生成 4 个角数。 
2. 测试每个元素的素数。 
3.更新：$$\text{ratio} = \frac{\text{prime diagonal count}} {\text{total diagonal count}}$$我们寻求第一$n$这样：$$\frac{\text{primes}}{2n-1} < 0.10$$---

 # Python 实现```python
import math

def is_prime(n):
    """Return True if n is prime, else False."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = int(math.isqrt(n))
    d = 3

    while d <= limit:
        if n % d == 0:
            return False
        d += 2

    return True

prime_count = 0
diagonal_count = 1   # starts with center value 1
side_length = 1

while True:
    side_length += 2

    square = side_length * side_length
    step = side_length - 1

    # The four corner values
    corners = [
        square,
        square - step,
        square - 2 * step,
        square - 3 * step
    ]

    # Count primes among the corners
    for c in corners:
        if is_prime(c):
            prime_count += 1

    diagonal_count += 4

    # Check ratio
    if prime_count / diagonal_count < 0.10:
        print(side_length)
        break
```---

 # 举例验证

 对于边长$7$:

 对角线数为：$$1,3,5,7,9,13,17,21,25,31,37,43,49$$质数：$$3,5,7,13,17,31,37,43$$那是：$$8 \text{ primes out of } 13$$匹配问题陈述。

 # 最终验证

 随着层数的增加，该比率逐渐减小，因为角值中的合数变得越来越常见。 

已知的欧拉计划结果出现在中等大的奇数边长处，因此我们预计该值是数万而不是很小。 

运行该算法给出：$$26241$$根据螺旋边长的要求，这是奇数。
