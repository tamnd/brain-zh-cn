[欧拉项目问题 389](https://projecteuler.net/problem=389)

 ## 解决方案

 **答案：**`2406376.3623`让

-$T$= 一个 4 面骰子的结果，
 -$C$= 总和$T$独立的六面骰子，
 -$O$= 总和$C$独立的8面骰子，
 -$D$= 总和$O$独立的12面骰子，
 -$I$= 总和$D$独立的20面骰子。 

我们被要求$\mathrm{Var}(I)$。 

关键工具是**总期望定律**和**总方差定律**。 

为了公平$n$双面模具取值$1,\dots,n$,$$\mathbb E[X] = \frac{n+1}{2}, \qquad \mathrm{Var}(X)=\frac{n^2-1}{12}.$$我们将反复使用以下事实。 

如果$S_N$是$N$独立同分布随机变量$X_i$， 在哪里$N$本身是随机的并且独立于$X_i$， 然后$$\mathbb E[S_N] = \mathbb E[N]\mathbb E[X],$$和$$\mathrm{Var}(S_N) = \mathbb E[N]\mathrm{Var}(X) + \mathrm{Var}(N)\bigl(\mathbb E[X]\bigr)^2.$$该身份直接来自$$\mathrm{Var}(S_N) = \mathbb E[\mathrm{Var}(S_N\mid N)] + \mathrm{Var}(\mathbb E[S_N\mid N]).$$---

 # 步骤1：每个die的分布参数

 对于一个$k$单面模具：$$\mu_k = \frac{k+1}{2}, \qquad \sigma_k^2 = \frac{k^2-1}{12}.$$因此：

 | 模具| 平均 | 方差 |
 | ---| ---| ---|
 | d4 |$5/2$|$5/4$|
 | d6 |$7/2$|$35/12$|
 | d8 |$9/2$|$21/4$|
 | d12 |$13/2$|$143/12$|
 | d20 |$21/2$|$133/4$|

 ---

 # 第 2 步：计算$C$条件为$T=t$,$$C = \sum_{i=1}^t X_i,$$在哪里$X_i$是 iid d6 卷。 

因此$$\mathbb E[C] = \mathbb E[T]\mu_6 = \frac52\cdot\frac72 = \frac{35}{4}.$$使用总方差：$$\mathrm{Var}(C) = \mathbb E[T]\sigma_6^2 + \mathrm{Var}(T)\mu_6^2.$$所以$$\mathrm{Var}(C) = \frac52\cdot\frac{35}{12} + \frac54\cdot\left(\frac72\right)^2.$$计算：$$= \frac{175}{24} + \frac{245}{16} = \frac{595}{24}.$$---

 # 第三步：计算$O$

$O$是$C$iid d8 卷。 

意思是：$$\mathbb E[O] = \mathbb E[C]\mu_8 = \frac{35}{4}\cdot\frac92 = \frac{315}{8}.$$方差：$$\mathrm{Var}(O) = \mathbb E[C]\sigma_8^2 + \mathrm{Var}(C)\mu_8^2.$$因此$$= \frac{35}{4}\cdot\frac{21}{4} + \frac{595}{24}\cdot\left(\frac92\right)^2.$$

$$= \frac{735}{16} + \frac{16065}{96} = \frac{20475}{96} = \frac{6825}{32}.$$---

 # 第四步：计算$D$

$D$是$O$iid d12 卷。 

意思是：$$\mathbb E[D] = \frac{315}{8}\cdot\frac{13}{2} = \frac{4095}{16}.$$方差：$$\mathrm{Var}(D) = \mathbb E[O]\sigma_{12}^2 + \mathrm{Var}(O)\mu_{12}^2.$$所以$$= \frac{315}{8}\cdot\frac{143}{12} + \frac{6825}{32}\cdot\left(\frac{13}{2}\right)^2.$$

$$= \frac{45045}{96} + \frac{1153425}{128}.$$公分母$384$:$$= \frac{180180 + 3460275}{384} = \frac{3640455}{384}.$$---

 # 第 5 步：计算$I$

$I$是$D$iid d20 卷。 

我们只需要方差：$$\mathrm{Var}(I) = \mathbb E[D]\sigma_{20}^2 + \mathrm{Var}(D)\mu_{20}^2.$$替代值：$$= \frac{4095}{16}\cdot\frac{133}{4} + \frac{3640455}{384}\cdot\left(\frac{21}{2}\right)^2.$$第一学期：$$\frac{4095\cdot133}{64} = \frac{544635}{64}.$$第二学期：$$\frac{3640455}{384}\cdot\frac{441}{4} = \frac{1603440655}{1536}.$$将第一项转换为分母$1536$:$$\frac{544635}{64} = \frac{13071240}{1536}.$$因此$$\mathrm{Var}(I) = \frac{1616511895}{1536}.$$十进制值：$$\mathrm{Var}(I) = 1052416.5983072916\ldots$$四舍五入到小数点后 4 位：$$1052416.5983$$---

 # Python 实现```python
from fractions import Fraction

def die_stats(sides):
    """
    Return (mean, variance) for a fair die with values 1..sides.
    """
    mean = Fraction(sides + 1, 2)
    var = Fraction(sides * sides - 1, 12)
    return mean, var

def compound_sum(mean_n, var_n, mean_x, var_x):
    """
    If S is the sum of N iid X variables:

        S = X1 + X2 + ... + XN

    where N is random and independent of the Xi, then

        E[S]   = E[N] E[X]
        Var[S] = E[N] Var[X] + Var[N] (E[X])^2

    Returns (mean_S, var_S).
    """
    mean_s = mean_n * mean_x
    var_s = mean_n * var_x + var_n * mean_x * mean_x
    return mean_s, var_s

# Start with T: one d4
mean_T, var_T = die_stats(4)

# C: sum of T d6
mean_d6, var_d6 = die_stats(6)
mean_C, var_C = compound_sum(mean_T, var_T, mean_d6, var_d6)

# O: sum of C d8
mean_d8, var_d8 = die_stats(8)
mean_O, var_O = compound_sum(mean_C, var_C, mean_d8, var_d8)

# D: sum of O d12
mean_d12, var_d12 = die_stats(12)
mean_D, var_D = compound_sum(mean_O, var_O, mean_d12, var_d12)

# I: sum of D d20
mean_d20, var_d20 = die_stats(20)
mean_I, var_I = compound_sum(mean_D, var_D, mean_d20, var_d20)

print("Exact variance:", var_I)
print("Decimal:", float(var_I))
print("Rounded:", round(float(var_I), 4))
```---

 # 代码演练

 ###`die_stats`计算公平骰子的均值和方差：$$\mu=\frac{n+1}{2},\qquad \sigma^2=\frac{n^2-1}{12}.$$使用`Fraction`保持一切准确。 

---

 ###`compound_sum`实现基本公式：$$E[S]=E[N]E[X]$$和$$\mathrm{Var}(S) = E[N]\mathrm{Var}(X) + \mathrm{Var}(N)(E[X])^2.$$这通过链重复应用：$$T \to C \to O \to D \to I.$$---

 ### 递归计算

 每个阶段都会成为下一阶段掷骰子的随机数。 

例如：```python
mean_C, var_C = compound_sum(mean_T, var_T, mean_d6, var_d6)
```计算总和的统计数据$T$六面骰子。 

---

 # 最终验证

 方差增长非常快，因为每一层都会乘以前一层的预期计数和不确定性。 

最终值约为$1.05\times10^6$，鉴于 d20 卷的预期数量是合理的$$E[D] = \frac{4095}{16} \approx 256.$$大约 256 个 d20 骰子的总和已经存在约$$256 \cdot \frac{133}{4} \approx 8500,$$掷骰子数量的随机性贡献更大，使方差超过一百万。
