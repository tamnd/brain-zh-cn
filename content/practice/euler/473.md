[欧拉项目 473 问题](https://projecteuler.net/problem=473)

 ## 解决方案

 **答案：**`35856681704365`让$$\varphi=\frac{1+\sqrt5}{2},\qquad \varphi^2=\varphi+1.$$每个正整数都有一个唯一的有限表示，使用$\varphi$没有使用连续的指数。 

对于回文数字表示，数字字符串必须满足$$d_i=d_{-i-1}.$$因此，每个回文值的形式都是$$N=\sum_{i\ge0} d_i\left(\varphi^i+\varphi^{-i-1}\right).$$定义$$T_i=\varphi^i+\varphi^{-i-1}.$$使用标准身份$$\varphi^n=\frac{L_n+F_n\sqrt5}{2},$$（在哪里$F_n$和$L_n$是斐波那契数和卢卡斯数），我们发现：

 -$T_1=2$已经是一个整数，
 - 为$k\ge1$,$$T_{2k}=\frac{a_k+b_k\sqrt5}{2},\qquad T_{2k+3}=\frac{c_k-b_k\sqrt5}{2},$$所以无理数部分**仅**在成对中抵消$$T_{2k}+T_{2k+3}.$$这些整数块是$$14,36,94,246,644,\dots$$并满足递推式$$B_n=3B_{n-1}-B_{n-2},$$和$B_1=14,\ B_2=36$。 

由于原始表示禁止连续指数，因此这些块不能相邻； 事实上，所选块必须至少被两个未使用的块分隔开。 

因此，每个回文数字整数都可以从以下公式获得：

 - 可选择添加隔离值$2$,
 - 加上任意不冲突块的总和$B_n$。 

小案例（$\le1000$）给出$$1,2,14,36,38,94,96,246,248,260,644,646,658,680,682$$其总和确实是$$4345.$$---

 ## Python 实现```python
LIMIT = 10**10

# Generate the integer blocks:
# 14, 36, 94, 246, ...
blocks = [14, 36]
while True:
    nxt = 3 * blocks[-1] - blocks[-2]
    if nxt > LIMIT:
        break
    blocks.append(nxt)

# Generate all valid sums of blocks.
# If block i is used, then i+1 and i+2 are forbidden.
base_sums = set()

def dfs(start, total):
    base_sums.add(total)

    for i in range(start, len(blocks)):
        dfs(i + 3, total + blocks[i])

dfs(0, 0)

# Build the final set of palindromic phigital integers.
vals = set(base_sums)

# Optional isolated value 2.
# It conflicts only with the first block (14),
# so we only combine it with sums generated from blocks[1:].
with_two = set()

def dfs_two(start, total):
    with_two.add(total)

    for i in range(start, len(blocks)):
        dfs_two(i + 3, total + blocks[i])

dfs_two(1, 2)

vals |= with_two

# The special one-digit palindrome "1"
vals.add(1)

answer = sum(v for v in vals if v <= LIMIT)

print(answer)
```---

 ## 代码演练

 ### 1.生成区块序列```python
blocks = [14, 36]
while True:
    nxt = 3 * blocks[-1] - blocks[-2]
```这会产生整数取消块$$14,36,94,246,\dots$$这正是回文数字整数允许的构建块。 

---

 ### 2.递归生成```python
dfs(i + 3, total + blocks[i])
```选择区块`i`禁止区块`i+1`和`i+2`，所以下一个允许的索引是`i+3`。 

这恰好编码了“无连续指数”规则。 

---

 ### 3.可选的隔离值$2$价值$2$对应于独立术语$T_1$。 

它仅与第一个块冲突$14$，所以我们分别生成这些组合。 

---

 ### 4.示例验证

 对于数字$\le 1000$，生成的集合是：$$1,2,14,36,38,94,96,246,248,260,644,646,658,680,682$$其总和是$$4345,$$与问题陈述完全匹配。

 搜索空间很小，因为块序列的增长大致如下$\varphi^2\approx2.618$，所以下面只需要几十个块$10^{10}$。
