 ## 解决方案

 **答案：**`1587000`一个数字是：

 - **增加**如果从左到右读取时其数字从不减少。 

- 例子：$134468$- 如果从左到右读取时其数字从未增加，则**递减**。 

- 例子：$66420$- **有弹性**如果它既不增加也不减少。 

- 例子：$155349$我们被要求找到**最小的整数$n$** 对于哪个

 \frac{\text{# 高达 } n}{n} = 99\% 的弹性数字

 也就是说，$$\frac{B(n)}{n} = \frac{99}{100}$$在哪里$B(n)$计算有弹性的数字$\le n$。 

---

 # 数学分析

 关键的观察结果是，对于比例恰好达到的第一个数字，没有简单的封闭式公式$99\%$。 然而，检查一个数字是否有弹性的成本非常低，因此直接模拟是有效的。 

我们逐步进行：

 - 维护：

 - 当前号码$n$- 弹力数字的计数$b$对于每个$n$：

 1. 判断是否$n$正在增加。 
2. 判断是否$n$正在减少。 
3. If neither, increment$b$。 
4. 检查是否：$$\frac{b}{n} = \frac{99}{100}$$为了避免浮点不准确，请直接比较整数：$$100b = 99n$$---

 # 检测有弹性的数字

 假设数字是：$$d_1,d_2,\dots,d_k$$我们扫描相邻对。 

- 如果某对满足$d_i < d_{i+1}$，数量呈递增趋势。 
- 如果某对满足$d_i > d_{i+1}$，数量呈递减趋势。 

然后：

 - 只增加步数→增加数量
 - 只减少步数→减少数量
 - 两种类型都存在→有弹性

 示例：$155349$数字：$$1 \to 5 \quad (\uparrow)$$

$$5 \to 5 \quad (=)$$

$$5 \to 3 \quad (\downarrow)$$增加和减少都会发生，所以有弹性。

 # Python 实现```python
def is_bouncy(n):
    """
    Return True if n is bouncy, otherwise False.
    """
    digits = str(n)

    increasing = False
    decreasing = False

    # Compare adjacent digits
    for i in range(len(digits) - 1):
        if digits[i] < digits[i + 1]:
            increasing = True
        elif digits[i] > digits[i + 1]:
            decreasing = True

        # If both directions appear, number is bouncy
        if increasing and decreasing:
            return True

    return False

def solve():
    bouncy_count = 0
    n = 1

    while True:
        if is_bouncy(n):
            bouncy_count += 1

        # Check for exactly 99%
        if bouncy_count * 100 == n * 99:
            return n

        n += 1

answer = solve()
print(answer)
```---
