[欧拉项目问题 430](https://projecteuler.net/problem=430)

 ## 解决方案

 **答案：**`5000624921.38`让$X_i$是磁盘的指标随机变量$i$之后是白色的$M$轮流。 

然后$$E(N,M)=\sum_{i=1}^N \mathbb E[X_i].$$所以我们只需要单个圆盘在之后为白色的概率$M$随机翻转。 

---

 # 1. 磁盘的概率$i$一举翻转

 移动选择有序整数$A,B\in\{1,\dots,N\}$uniformly.

 磁盘$i$被翻转当且仅当$i$位于之间$A$和$B$， IE。$$(A\le i\le B)\quad\text{or}\quad(B\le i\le A).$$仅当两个端点都严格位于左侧时，才**不**翻转$i$，或两者都严格正确$i$。 

不翻转的有序对的数量$i$:$$(i-1)^2 + (N-i)^2.$$因此$$p_i =1-\frac{(i-1)^2+(N-i)^2}{N^2}.$$简化后，$$p_i=\frac{2i(N-i+1)-1}{N^2}.$$---

 # 2.白/黑奇偶校验

 每次翻转都会切换颜色。 

如果有概率翻转一个圆盘$p_i$每回合独立，然后之后$M$轮流：$$P(\text{white}) = \frac{1+(1-2p_i)^M}{2}.$$定义$$q_i = 1-2p_i.$$然后$$E(N,M) = \sum_{i=1}^N \frac{1+q_i^M}{2} = \frac N2+\frac12\sum_{i=1}^N q_i^M.$$使用公式$p_i$,$$q_i = 1-\frac{4i(N-i+1)-2}{N^2}.$$---

 # 3. 数值策略$N=10^{10}, M=4000$直接求和即可$10^{10}$条款是不可能的。 

但对于大多数人来说$i$,$$|q_i|<1$$和$q_i^{4000}$是天文数字般的微小。 

只有靠近两端的磁盘贡献明显。 

由于对称性，$$q_i=q_{N+1-i}.$$因此，我们只在一条边附近求和，直到项变得可以忽略不计。 

---

 # 4.Python实现```python
from math import log, exp

N = 10**10
M = 4000

def q(i):
    return 1 - (4 * i * (N - i + 1) - 2) / (N * N)

# Sum only where contributions matter
# (beyond this, terms are effectively zero)
LIMIT = 50_000_000

s = 0.0

for i in range(1, LIMIT + 1):
    term = exp(M * log(q(i)))
    s += 2.0 * term   # symmetry

# Expected value
E = N / 2.0 + s / 2.0

print(round(E, 2))
```---

 # 5. 代码演练

 ###`q(i)`计算$$q_i = 1-2p_i.$$### 主循环

 计算$$2\sum_{i=1}^{LIMIT} q_i^M,$$使用左右边缘之间的对称性。 

### 为什么截断有效

 对于中等$i$,$$q_i^M \approx e^{-4Mi/N}.$$和$M=4000$和$N=10^{10}$，术语呈指数衰减，并且在几千万之后在数字上变得无关紧要。 

---

 # 6.小例子验证

 对于$N=3, M=1$:$$E(3,1)=\frac{10}{9},$$匹配问题陈述。 

为了$N=3, M=2$:$$E(3,2)=\frac53,$$也正确。 

为了$N=10, M=4$:$$E(10,4)\approx 5.157,$$再次符合声明。
