[欧拉项目问题 124](https://projecteuler.net/problem=124)

 ## 解决方案

 **答案：**`21417`我们需要计算$E(10000)$当整数$1 \le n \le 100000$排序依据：

 1. 增加$\operatorname{rad}(n)$,
 2. 通过增加来打破联系$n$。 

根式被定义为不同质因数的乘积$n$。 

例如：

-$504 = 2^3 \cdot 3^2 \cdot 7$，
- 所以$$\operatorname{rad}(504)=2\cdot3\cdot7=42.$$---

 # 数学分析

 直接定义提出了两个任务：

 1. 计算$\operatorname{rad}(n)$为所有人有效$n \le 100000$,
 2. 对对进行排序$(\operatorname{rad}(n), n)$。 

对每个数字进行简单的分解是可行的，但我们可以使用类似筛子的方法做得更好。 

## 关键观察

 如果$p$是素数，那么每个的倍数$p$有$p$作为一个独特的素因数。 

所以我们可以初始化：$$\operatorname{rad}(n)=1$$为所有人$n$，然后对于每个素数$p$：

 - 乘以$\operatorname{rad}(k)$经过$p$对于每一个倍数$k$的$p$。 

这类似于埃拉托斯特尼筛法。 

---

 ## 示例

 从以下开始：$$\operatorname{rad}(1)=\operatorname{rad}(2)=\cdots=1.$$工艺底漆$2$：

 - 将 2 的所有倍数乘以 2。 

现在：$$\operatorname{rad}(2)=2,\quad \operatorname{rad}(4)=2,\quad \operatorname{rad}(6)=2,\dots$$工艺底漆$3$：

 - 将 3 的所有倍数乘以 3。 

然后：$$\operatorname{rad}(6)=2\cdot3=6,$$

$$\operatorname{rad}(9)=3.$$等等。 

复杂性本质上是：$$O(n \log\log n),$$这对于$100000$。 

---

 # Python 实现```python
LIMIT = 100000

# rad[n] will store rad(n)
rad = [1] * (LIMIT + 1)

# Sieve to compute radicals
for p in range(2, LIMIT + 1):
    # If rad[p] is still 1, then p is prime
    if rad[p] == 1:
        # Multiply p into every multiple of p
        for multiple in range(p, LIMIT + 1, p):
            rad[multiple] *= p

# Build list of (rad(n), n)
values = [(rad[n], n) for n in range(1, LIMIT + 1)]

# Sort by rad(n), then by n automatically
values.sort()

# E(10000) is the 10000th element (1-indexed)
answer = values[9999][1]

print(answer)
```---

 # 代码演练

 ## 步骤1：初始化部首```python
rad = [1] * (LIMIT + 1)
```我们从每个等于 1 的根式开始，因为当我们发现不同的质因数时，我们将乘以它们。 

---

 ## 步骤 2：检测素数```python
if rad[p] == 1:
```最初只有素数在达到时保留值 1：

 - 合数已经乘以较小的质因数，
 - 质数没有。 

因此，这充当素性测试。 

---

 ## 步骤 3：将质数乘以所有倍数```python
for multiple in range(p, LIMIT + 1, p):
    rad[multiple] *= p
```每个素数对每个倍数只贡献一次，这正是根式的定义。 

示例：

 - 当$p=2$,$12$乘以 2，
 - 当$p=3$,$12$乘以 3，
 - 重复幂不会发生进一步的乘法。 

因此：$$\operatorname{rad}(12)=2\cdot3=6.$$---

 ## 步骤 4：构建可排序对```python
values = [(rad[n], n) for n in range(1, LIMIT + 1)]
```Python 元组排序是按字典顺序排序的，因此：```python
values.sort()
```首先排序$\operatorname{rad}(n)$，然后由$n$。 

正是问题所需要的。 

---

 ## 步骤5：提取第10000个元素

 因为Python使用从0开始的索引：```python
values[9999]
```是第 10000 个条目。 

第二个组成部分是$n$。 

---

 # 小例子验证

 对于$1 \le n \le 10$，代码产生：$$(1,1), (2,2), (2,4), (2,8), (3,3), (3,9), (5,5), (6,6), (7,7), (10,10)$$因此：

-$E(4)=8$,
 -$E(6)=9$,

 匹配问题陈述。 

所以方法是正确的。

 # 最终验证

 结果应该：

 - 介于$1$和$100000$,
 - 对应于相对较小的根式排序，
 - 筛分计算是精确且确定的。 

运行该算法给出：$$E(10000)=21417.$$**答案：21417**
