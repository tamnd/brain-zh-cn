 ## 问题

 在光滑的水平金属丝环上，有两颗质量珠$m_1$和$m_2$可以无摩擦地滑动。 最初，珠子通过线连接，压缩弹簧位于珠子之间。 线被烧断。 当珠子开始移动后，将弹簧移除。 珠子将在圆环上的哪一点发生第十一次碰撞？ 珠子完美地弹性碰撞。 

## 设置和假设

 两颗质量珠$m_1$和$m_2$在圆周固定的刚性圆线上无摩擦地移动$L$。 它们沿环的位置由弧坐标描述$x_1(t)$和$x_2(t)$测量模数$L$。 压缩弹簧最初放置在珠子之间，同时螺纹保持结构固定，以便在释放之前不会发生运动。 

在最初的时刻，线程被烧毁。 然后弹簧施加内力并沿着环的切线向珠子提供相反的脉冲。 经过短暂的相互作用时间后，弹簧被完全移除，并且没有进一步的外力或内力作用。 随后，珠子沿着环自由移动，并在相遇时发生完美的弹性碰撞。 

未知的是圆环上珠子第十一次碰撞的几何位置。 

该系统在固定在环上的惯性系中进行分析。 假设环是完全刚性的，并且沿着圆周的运动严格是一维的。 

## 物理原理

 碰撞之间的运动是沿环的匀速直线运动，因此每个珠子满足$x_i(t) = x_i(0) + v_i t \quad \text{mod } L.$在碰撞过程中，应用线性动量和动能守恒。 对于一维完美弹性碰撞，$v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1 + \frac{2m_2}{m_1 + m_2}v_2,$

$v_2' = \frac{2m_1}{m_1 + m_2}v_1 + \frac{m_2 - m_1}{m_1 + m_2}v_2.$一维弹性碰撞的标准简化相当于一个模型，其中粒子彼此穿过而不相互作用，同时保持其速度。 然后，碰撞事件被解释为圆上轨迹的交叉。 

质心坐标$X_{\mathrm{cm}} = \frac{m_1 x_1 + m_2 x_2}{m_1 + m_2}$均匀运动，因为系统上的净外力为零。 因此$\frac{d^2 X_{\mathrm{cm}}}{dt^2} = 0.$## 推导

 弹簧力是内部的，仅在释放后的短时间内起作用。 由于没有外力作用，释放后的总动量守恒，并且对于所有后续运动保持恒定。 初始构型的对称性意味着弹簧沿环的切线方向产生相等且相反的冲量，因此两个珠子的总动量为零。 这产生$m_1 v_1 + m_2 v_2 = 0,$因此$v_2 = -\frac{m_1}{m_2} v_1.$质心速度为$V_{\mathrm{cm}} = \frac{m_1 v_1 + m_2 v_2}{m_1 + m_2} = 0,$所以质心保持固定在环上的一点$X_{\mathrm{cm}}$完全由初始位置决定：$X_{\mathrm{cm}} = \frac{m_1 x_1(0) + m_2 x_2(0)}{m_1 + m_2}.$弹簧取下后，珠子自由移动并弹性碰撞。 用粒子相互穿过的等效图像代替弹性碰撞表明，每个珠子在圆周上以恒定速度继续匀速运动。 碰撞恰好发生在$x_1(t) \equiv x_2(t) \pmod{L}.$在穿过表示中，两个粒子都穿过圆，而质心保持固定。 在碰撞瞬间，环上两个轨迹共享的唯一点是质心。 每次相遇时，珠子的位置都与质心坐标重合，因为围绕固定中心的运动对称性迫使相遇点在弹性散射期间的速度交换下保持不变。 

因此每次碰撞都发生在相同的几何位置$X_{\mathrm{cm}}$。 由于碰撞点与碰撞次数无关，因此第十一次碰撞与第一次碰撞发生在同一点。 

## 结果

 第 11 次碰撞的碰撞点与环上的质心位置重合，$X_{\mathrm{cm}} = \frac{m_1 x_1(0) + m_2 x_2(0)}{m_1 + m_2} \quad \text{mod } L.$如果没有指定初始坐标，则不可能进行额外的数字替换。 因此最终的答案是$\boxed{X_{\mathrm{cm}} \text{ on the ring, defined by } \frac{m_1 x_1(0) + m_2 x_2(0)}{m_1 + m_2} \ (\mathrm{mod}\ L)}.$## 健全性检查

 尺寸一致性成立是因为$X_{\mathrm{cm}}$是弧长的线性组合$x_1$和$x_2$，所以它有长度单位。 

在极限内$m_1 \gg m_2$，质心接近$x_1(0)$，这意味着较重的珠子主导碰撞位置，与系统的惯性一致。 

在极限内$m_1 = m_2$，质心减小到初始弧分离的中点，与等质量的对称性一致。 

任何不正确的处理很可能是由于假设连续的弹性碰撞使交汇点沿着环移动，这将违反质心不变性以及弹性碰撞与一维自由通道之间的等价性。
