 ## 问题

 ![图。 2](//www.kvant.digital/media/common/1970-11-039-01.png?_v=2)

 图2

 平行于半径为 的圆柱体的轴线钻一个孔$R$在远处$\dfrac R2$从它的中心。 孔的半径为$\dfrac R2$。 圆柱体放置在一块小木板上，木板的一端缓慢升起（图 2）。 求出使圆柱体仍保持平衡的木板倾斜的极限角度。 圆柱体与木板之间的摩擦系数为$0{,}2$。 

全联盟函授奥林匹克竞赛 (1967)

 ## 设置和假设

 半径为长的圆柱体$R$均匀材料密度包含平行于其轴线的圆柱形孔。 在横截面中，半径为全圆盘$R$有一个半径为 的圆孔$R/2$其中心距圆柱体中心一定距离$R/2$。 圆柱体放置在一块缓慢倾斜一定角度的刚性木板上$\theta$相对于水平面。 

假设圆柱体保持平面横截面平衡，因此问题简化为垂直于圆柱体轴线的垂直平面中的刚体。 圆柱体与木板之间的接触是单点接触。 静摩擦系数$\mu = 0.2$作用于接触点并满足不等式$|f| \le \mu N$。 假设圆柱体不变形，并且不先验地强加滚动而不滑动； 相反，平衡需要力和扭矩平衡。 

未知的是极限倾角$\theta_{\max}$此时仍可能达到静态平衡。 

## 物理原理

 刚体的静态平衡需要合力消失，$\sum \mathbf{F} = \mathbf{0},$以及关于任意点的合成扭矩消失，$\sum \mathbf{M} = 0.$重量通过身体的质心作用并具有大小$mg$，垂直向下。 

正常反应$N$在接触点垂直于木板作用，摩擦力$f$沿木板作用，受库仑条件约束$|f| \le \mu N.$力绕点的扭矩计算如下$\mathbf{M} = \mathbf{r} \times \mathbf{F},$在哪里$\mathbf{r}$是从参考点到力的施加点的位置矢量。 

复合材料层板的质心位置通过面积减法确定，$\mathbf{r}_{\text{cm}} = \frac{\sum A_i \mathbf{r}_i}{\sum A_i}.$## 推导

 横截面由一个完整的圆盘区域组成$A_1 = \pi R^2$和一个被移除的圆形区域$A_2 = \pi (R/2)^2 = \pi R^2/4$。 孔中心距圆柱中心的位移为$R/2$沿着横截面中的某个固定方向。 

以全圆盘几何中心为原点，质心偏移$\mathbf{d}$位于连接中心的线上。 其大小由面积减法得出：$d = \frac{A_2 \cdot (R/2)}{A_1 - A_2}.$替换区域，$d = \frac{\left(\pi R^2/4\right)\left(R/2\right)}{\pi R^2 - \pi R^2/4}.$简化分子和分母，$d = \frac{\pi R^3/8}{(3\pi R^2)/4} = \frac{R}{8} \cdot \frac{4}{3} = \frac{R}{6}.$因此质心的位移是$R/6$从几何中心。 

当气缸静止在一定角度的斜坡上时$\theta$，选择轴$x$沿着平面（上斜坡）并且$y$垂直于平面（向外）。 以接触点为原点。 圆柱体的几何中心位于$\mathbf{r}_O = (0, R).$质心从$O$由向量大小$d = R/6$沿着横截面中的固定方向。 产生极限平衡的配置对应于具有沿斜坡方向的分量的位移，因此质心位置取为$\mathbf{r}_{\text{cm}} = (d, R).$权重向量在倾斜坐标系中分解。 由于重力是垂直的，所以它的分量是$\mathbf{F}_g = (-mg \sin\theta, -mg \cos\theta).$围绕接触点的重力力矩为$M = x_{\text{cm}} F_y - y_{\text{cm}} F_x.$替代$\mathbf{r}_{\text{cm}}$和$\mathbf{F}_g$,$M = d(-mg \cos\theta) - R(-mg \sin\theta).$这给出了$M = -mg d \cos\theta + mg R \sin\theta.$平衡需要$M = 0$， 因此$R \sin\theta = d \cos\theta.$除以$\cos\theta$,$\tan\theta = \frac{d}{R} = \frac{R/6}{R} = \frac{1}{6}.$因此几何扭矩条件产生$\theta_1 = \arctan\left(\frac{1}{6}\right).$沿平面的力平衡给出了摩擦力要求$f = mg \sin\theta,$和法向力$N = mg \cos\theta.$无滑移条件为$mg \sin\theta \le \mu mg \cos\theta,$这减少到$\tan\theta \le \mu = 0.2.$这产生了第二个限制角度$\theta_2 = \arctan(0.2).$比较阈值，$\frac{1}{6} \approx 0.167 < 0.2,$因此扭矩引起的平衡丧失首先发生。 

## 结果

 极限角度由扭矩平衡条件决定，$\theta_{\max} = \arctan\left(\frac{1}{6}\right).$替换给出$\theta_{\max} = \arctan(0.1667) \approx 9.46^\circ.$最终结果：$\boxed{\theta_{\max} \approx 9.5^\circ}.$## 健全性检查

 表达式$\tan\theta_{\max} = d/R$是无量纲的，因为两者$d$和$R$有长度单位，确认一致性。 

结果仅取决于质量分布的几何不对称性，而不取决于$m$,$g$，或摩擦，与扭矩主导的不稳定机制一致。 

摩擦极限屈服$\theta \le \arctan(0.2) \approx 11.3^\circ$，大于$9.5^\circ$，因此只有在失去旋转平衡后才会发生打滑，从而确认扭矩条件是控制约束。 

在中心孔的极限内（$d \to 0$），条件给出$\theta_{\max} \to 0$，与由于对称性而在任何倾斜上立即失去平衡一致，需要仅靠摩擦力来支撑重量分量而不恢复扭矩。
