 ## 问题

 一块方形横截面的木块漂浮在水面上。 图 1 所示的两个平衡位置中哪一个是稳定的？ 制作该块的材料的密度等于水密度的一半。 

![](//www.kvant.digital/media/common/1970-06-027-01.png?_v=2)

 ## 设置和假设

 侧面横截面恒定为正方形的棱柱木块$a$和长度$L$浮在密度水的表面$\rho_w$。 块的密度为$\rho = \rho_w/2$。 块体是均匀的，所以它的重心$G$与其几何中心重合。 

考虑两个平衡方向。 在第一种情况下，方形横截面的一个面是水平的。 在第二个中，正方形横截面旋转了$45^\circ$这样对角线是垂直的，并且身体以“菱形”方向漂浮。 

流体不可压缩并且处于静止状态。 忽略表面张力和粘度。 基于稳心准则，使用静水稳定性理论确定平衡的小角度扰动的稳定性。 

## 物理原理

 阿基米德原理给出的浮力为$F_b = \rho_w g V$， 在哪里$V$是淹没体积。 

平衡要求重量和浮力相等，$mg = \rho_w g V$。 

对于围绕平衡的小旋转，稳定性由稳心高度决定$GM$，通过定义$GM = BM - BG,$在哪里$B$是平衡时的浮力中心，$M$是元中心。 

稳心半径满足$BM = \frac{I}{V},$在哪里$I$是水线横截面绕倾斜轴的面积二阶矩，并且$V$是位移体积。 

稳定性要求$GM > 0$，不稳定性对应于$GM < 0$。 

## 推导

 木块的重量为$mg = \rho g a^2 L$。 浮力平衡产量$\rho g a^2 L = \rho_w g V,$所以淹没体积是$V = \frac{\rho}{\rho_w} a^2 L = \frac{1}{2} a^2 L.$### 第一个平衡：面水平

 淹没深度为$a/2$，所以浮力中心位于水下长方体的质心$a/2$。 重心位于高处$a/2$从立方体的底部开始，而浮力中心位于高度$a/4$。 因此$BG = \frac{a}{2} - \frac{a}{4} = \frac{a}{4}.$水线面是一个矩形面积$a \times L$。 其绕纵向倾斜轴的面积二阶矩为$I = \frac{L a^3}{12}.$稳心半径为$BM = \frac{I}{V} = \frac{\frac{L a^3}{12}}{\frac{1}{2} a^2 L} = \frac{a}{6}.$因此$GM = BM - BG = \frac{a}{6} - \frac{a}{4} = -\frac{a}{12}.$负值表明该平衡不稳定。 

### 第二个平衡：正方形旋转$45^\circ$在这个方向上，横截面变成菱形。 水线穿过中心，将正方形分成两个全等的三角形。 浸入水中的体积相当于横截面的一个三角形的一半。 

钻石的高度是$a/\sqrt{2}$，所以淹没三角形的高度是$h = \frac{a}{\sqrt{2}}.$三角形的质心位于一定距离处$h/3$从它的底部开始，所以浮力中心位于中心下方$BG = \frac{h}{3} = \frac{a}{3\sqrt{2}}.$水线面交点是一个长方形$L$宽度等于正方形的水平对角线，$b = a\sqrt{2}.$因此面积的二阶矩为$I = \frac{L b^3}{12} = \frac{L (a\sqrt{2})^3}{12} = \frac{L \cdot 2\sqrt{2} a^3}{12} = \frac{L \sqrt{2} a^3}{6}.$位移量仍为$V = \frac{1}{2} a^2 L.$因此$BM = \frac{I}{V} = \frac{\frac{L \sqrt{2} a^3}{6}}{\frac{1}{2} a^2 L} = \frac{\sqrt{2} a}{3}.$稳心高度变为$GM = BM - BG = \frac{\sqrt{2} a}{3} - \frac{a}{3\sqrt{2}} = \frac{a}{3\sqrt{2}}.$## 结果

 对于面水平平衡，$GM = -\frac{a}{12},$所以这个位置是不稳定的。 

对于$45^\circ$旋转平衡，$GM = \frac{a}{3\sqrt{2}}.$替换给出正值，所以这个位置是稳定的。$\boxed{\text{Stable equilibrium: rotated } 45^\circ \text{ (diamond position)}}$## 健全性检查

 在这两种情况下，稳心高度都具有长度尺寸，与$GM = BM - BG$。 

在面水平情况下，浮力中心位于质心下方，但稳心半径太小而无法补偿，从而产生负值$GM$和不稳定性，这与物理预期一致，即如果浮心偏移不足，宽阔的扁平浮子很容易翻倒。 

在旋转的情况下，两个贡献都与$a$，和正系数$\frac{1}{3\sqrt{2}}$确保任何非零大小的稳定性。 结果与有效水线惯性矩越高的结构越稳定的一般原理是一致的。
