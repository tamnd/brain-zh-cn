 ## 问题

 平行板电容器的极板被充电至电位$+\phi$和$-\phi$相对于地面。 由极板形成的电容器的电容为$C$，每个极板形成的电容器相对于地的电容为$-C_1$。 如果其中一块接地，板之间的电场强度会因什么因素而变化？ 

L·G·阿斯拉马佐夫

 ## 设置和假设

 两块导电板形成一个具有互电容的平行板电容器$C$。 每个板还具有一个对地电容，建模为$C_1$，以便当板接地时系统可以与地交换电荷。 最初，板相对于地的电位为$V_1 = +\phi$和$V_2 = -\phi$， 在哪里$\phi$以伏特为单位测量。 板间电场均匀且与电势差有关$E = (V_1 - V_2)/d$， 在哪里$d$是极板分离。 

假定这些板在接地之前与外部电路隔离，因此在任何中间重新配置期间，它们的总电荷都被保留，直到建立接地连接。 边缘效应被忽略，电容器被视为完全由线性电容关系描述的集总静电系统。 

## 物理原理

 由线性电容连接的导体系统中每个导体上的电荷由电势差贡献的叠加给出：$$Q_i = \sum_j C_{ij}(V_i - V_j),$$其中对地自电容包含在与以下成比例的项中$V_i$。 

电荷守恒适用于任何与地隔离的导体。 当导体接地时，其电势根据定义固定为$V=0$，而电荷可能会因流入或流出地面而发生变化。 

平行板之间的电场与电势差成正比：$$E = \frac{\Delta V}{d}.$$## 推导

 对于两板系统，板上的电荷$1$在使用互电容和接地电容写入接地之前：$$Q_1 = C(V_1 - V_2) + C_1 V_1.$$代入初始势$V_1 = \phi$和$V_2 = -\phi$给出$$Q_1 = C(\phi - (-\phi)) + C_1 \phi = 2C\phi + C_1 \phi.$$后板$2$接地，其电位变为$V_2' = 0$。 盘子$1$保持隔离，因此其电荷守恒：$$Q_1' = Q_1.$$板的新电荷-电势关系$1$变成$$Q_1' = C(V_1' - 0) + C_1 V_1' = (C + C_1)V_1'.$$使初始费用和最终费用收益相等$$(C + C_1)V_1' = (2C + C_1)\phi,$$所以$$V_1' = \frac{2C + C_1}{C + C_1}\,\phi.$$极板间的初始电场为$$E_0 = \frac{V_1 - V_2}{d} = \frac{2\phi}{d}.$$接地板后$2$，场变成$$E = \frac{V_1' - 0}{d} = \frac{V_1'}{d} = \frac{2C + C_1}{C + C_1}\,\frac{\phi}{d}.$$因此最终场与初始场的比率为$$\frac{E}{E_0} = \frac{\frac{2C + C_1}{C + C_1}\,\frac{\phi}{d}}{\frac{2\phi}{d}} = \frac{2C + C_1}{2(C + C_1)}.$$＃＃ 结果$$\boxed{\frac{E}{E_0} = \frac{2C + C_1}{2(C + C_1)}}$$替换尺寸，两者$C$和$C_1$以法拉为单位测量，因此该比率是无量纲的：$$\frac{E}{E_0} = \frac{2C + C_1}{2(C + C_1)} \quad (1).$$## 健全性检查

 在极限内$C_1 \to 0$，极板没有对地电容，表达式简化为$$\frac{E}{E_0} = \frac{2C}{2C} = 1,$$因此，当不可能与地面进行电荷交换时，将一块板接地不会改变磁场。 

在相反的极限$C_1 \gg C$，表达式变为$$\frac{E}{E_0} \to \frac{C_1}{2C_1} = \frac{1}{2},$$这对应于对地的强耦合，在接地后更强烈地抑制隔离板的电势。 

尺寸一致性遵循，因为比率中的每一项都是电容，并且所得的量是无量纲的，与场比一致。 最敏感的步骤是保护$Q_1$，因为任何关于哪个板被隔离的错误假设都会改变关系$V_1'$并线性传播到最终结果。
