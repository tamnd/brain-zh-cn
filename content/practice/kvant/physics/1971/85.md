 ## 问题

 F85。 是否可以用理想气体进行封闭过程（循环），使 A 点和 B 点（图 1）位于同一等温线上？ 

温度$T_1$和$T_2$对应于图中绘制的等温线，以及体积$V_1$（或者$V_3$），给出。 

图 1：a 上显示一条经过 A 点和 B 点的闭合曲线$p$–$V$图表。 理想气体与温度的两条等温线$T_1$和$T_2$也显示了，并且值$V_1$和$V_3$标记在音量轴上。 

## 设置和假设

 平衡状态下的理想气体由状态描述$(p,V)$和$p>0$,$V>0$和状态方程$pV=\nu RT$。 温度由下式唯一确定$T(p,V)=\frac{pV}{\nu R}$。 

该图并不代表完整$(p,V)$-平面，但由两条等温线界定的受限制的物理相关域$T_1$和$T_2$和垂直线$V=V_1$和$V=V_3$。 这定义了一个可接受的区域$$\mathcal{D}=\{(p,V)\mid V_1\le V\le V_3,\; \nu RT_1 \le pV \le \nu RT_2\}.$$积分$A(p_A,V_A)$和$B(p_B,V_B)$位于同一条等温线上，因此$p_A V_A = p_B V_B = \nu R T_*.$由于这两个点都显示在图中，因此它们属于$\mathcal{D}$，这意味着$$T_1 \le T_* \le T_2, \quad V_1 \le V_A,V_B \le V_3.$$因此，准静态过程必须完全在内部构建$\mathcal{D}$，不仅仅是抽象的$(p,V)$状态空间。 

允许的基本过程仍然是等压和等容变换，前提是整个轨迹保持在$\mathcal{D}$。 

## 物理原理

 理想气体的准静态过程是平衡流形中的连续曲线，其中每个点的状态满足$pV=\nu RT$。 图中的可实现性需要额外的约束：轨迹必须保持在域内$\mathcal{D}$由等温线确定$T_1,T_2$和体积界限$V_1,V_3$。 

等量异位片段$p=p_0$身体上是可以进入的$\mathcal{D}$只要相应的温度满足$$T_1 \le \frac{p_0 V}{\nu R} \le T_2,$$这相当于$$\frac{\nu R T_1}{p_0} \le V \le \frac{\nu R T_2}{p_0}.$$等容片段$V=V_0$仅当$$T_1 \le \frac{pV_0}{\nu R} \le T_2,$$这给出了$$\frac{\nu R T_1}{V_0} \le p \le \frac{\nu R T_2}{V_0}.$$这些不平等确保中间状态保留在图中所示的区域内。 

## 推导

 来自$A(p_A,V_A)$，考虑同量异位变换$p=p_A$朝向体积$V_B$。 沿着这条路，$$T(V)=\frac{p_A V}{\nu R}.$$在端点处，$$T(V_A)=T_*, \quad T(V_B)=T_*,$$所以两个端点都在允许的区间内$[T_1,T_2]$。 自从$T(V)$是一个仿射函数$V$，它获得了之间的所有中间值$T(V_A)$和$T(V_B)$，因此对于所有$V$之间$V_A$和$V_B$,$$T_1 \le T(V) \le T_2.$$体积也满足$V_1 \le V \le V_3$通过构建$A$和$B$图中。 这确保了整个同量异位片段$A \to C$仍留在$\mathcal{D}$， 在哪里$C=(p_A,V_B)$。 

从$C$到$B(p_B,V_B)$，该过程是等容的$V=V_B$。 沿着这个路段，$$T(p)=\frac{pV_B}{\nu R}.$$在端点处，$$T(p_A)=T_*, \quad T(p_B)=T_*,$$自从$T(p)$线性取决于$p$，所有中间压力满足$$T_1 \le T(p) \le T_2.$$因为$p$之间变化$p_A$和$p_B$尽管$V_B$固定为$V_1 \le V_B \le V_3$，整个等容段仍保留在内部$\mathcal{D}$。 这完成了一条物理上可接受的路径$A$到$B$。 

同样的验证也适用于反向构造。 从$B$到$(p_B,V_A)$同量异位片段留在$\mathcal{D}$因为温度在公共端点值之间线性变化$T_*$并保持在$[T_1,T_2]$，并且体积保留在内部$[V_1,V_3]$。 随后的等容步骤$(p_B,V_A)$回到$A$也留在里面$\mathcal{D}$出于同样的线性原因。 

这两条允许路径的串联产生了一个完全包含在$\mathcal{D}$。 

## 结果

 闭式准静态循环通过$A$和$B$存在是因为这两个状态都位于由$T_1,T_2,V_1,V_3$，并且因为连接它们的等量线段和等容线段保留了通过线性变化定义该域的不等式$T$沿着每个段。 

所以，$$\boxed{\text{Yes, such a closed cycle is possible.}}$$## 健全性检查

 每个段满足$pV=\nu RT$在每个中间点，确保平衡。 从图中得出的容许条件，表示为不等式$T$和$V$，仍然满足，因为在等压和等容过程中温度随单个控制变量线性变化。 这保证了所构造循环的任何部分都不会离开等温线所界定的区域$T_1$和$T_2$和音量限制$V_1$和$V_3$。 

施工仅取决于$A$和$B$在允许的域内，而不是基于等温线和体积约束所编码的边界形状的附加几何假设。
