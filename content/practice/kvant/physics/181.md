 ## 问题

 _该问题被错误地发表在期刊的第 183 号下。_


 卫星以近乎圆形的轨道绕地球高速运行$v$。 轨道变化是由于卫星受到微粒摩擦力的作用$F = A \cdot v^\alpha$， 在哪里$A$和$\alpha$是常数。 寻找$\alpha$，如果已知卫星轨道半径变化非常缓慢。 

## 设置和假设

 质量卫星$m$绕地球运动$M$在半径为近圆形的轨道上$r$以轨道速度$v$。 引力参数为$\mu = GM$有单位$\mathrm{m^3,s^{-2}}$。 由于与微粒碰撞而产生的阻力与速度相反，并且具有大小$F = A v^\alpha$， 在哪里$A$是一个有单位的常数$\mathrm{kg,m^{1-\alpha},s^{\alpha-2}}$和$\alpha$是无量纲的。 

假设轨道在每一时刻都保持圆形，而半径随时间缓慢变化，因此在每一时刻都满足圆周运动的条件，并且超出重力和离心平衡的径向加速度可忽略不计。 阻力被视为纯切向力，因此它不会直接修改径向力平衡。 地球自转、辐射压力和介质不均匀性等影响被忽略。 

未知数就是指数$\alpha$。 

## 物理原理

 切线方向的牛顿第二定律给出了通过非保守力的作用轨道能量的演化，因此$\frac{dE}{dt} = \mathbf{F}\cdot \mathbf{v}.$对于圆形开普勒轨道，速度和半径满足向心加速度和重力加速度的平衡，$\frac{v^2}{r} = \frac{\mu}{r^2},$以便$v^2 = \frac{\mu}{r}.$圆形轨道的总机械能和角动量为$E = -\frac{\mu m}{2r}, \qquad L = m v r.$阻力的扭矩决定了角动量损失，$\frac{dL}{dt} = -F r.$缓慢变化的圆形轨道的一致性要求从轨道关系获得的时间导数$E(r)$和$L(r)$与从耗散力定律获得的结果一致。 

## 推导

 圆形轨道条件给出了速度作为半径的函数，$v = \sqrt{\frac{\mu}{r}}.$轨道能量表示为$r$是$E(r) = -\frac{\mu m}{2r},$所以它的导数是$\frac{dE}{dr} = \frac{\mu m}{2r^2}.$角动量为$L(r) = m v r = m r \sqrt{\frac{\mu}{r}} = m \sqrt{\mu r},$和分化产量$\frac{dL}{dr} = \frac{m}{2}\sqrt{\frac{\mu}{r}} = \frac{L}{2r}.$耗散力大小为$F = A v^\alpha$，因此做功时的能量损失率为$\frac{dE}{dt} = -Fv = -A v^{\alpha+1}.$替代$v = (\mu/r)^{1/2}$给出$\frac{dE}{dt} = -A \left(\frac{\mu}{r}\right)^{\frac{\alpha+1}{2}} = -A \mu^{\frac{\alpha+1}{2}} r^{-\frac{\alpha+1}{2}}.$扭矩方程给出$\frac{dL}{dt} = -F r = -A v^\alpha r.$替代$v$产量$\frac{dL}{dt} = -A \left(\frac{\mu}{r}\right)^{\frac{\alpha}{2}} r = -A \mu^{\frac{\alpha}{2}} r^{1-\frac{\alpha}{2}}.$使用$L(r)$，轨道几何角动量的时间导数为$\frac{dL}{dt} = \frac{dL}{dr}\frac{dr}{dt} = \frac{L}{2r}\frac{dr}{dt}.$将其与扭矩表达式等同得出$\frac{L}{2r}\frac{dr}{dt} = -A \mu^{\frac{\alpha}{2}} r^{1-\frac{\alpha}{2}}.$替代$L = m\sqrt{\mu r}$导致$\frac{m\sqrt{\mu r}}{2r}\frac{dr}{dt} = -A \mu^{\frac{\alpha}{2}} r^{1-\frac{\alpha}{2}}.$解决$\frac{dr}{dt}$给出$\frac{dr}{dt} = -\frac{2A}{m}\mu^{\frac{\alpha-1}{2}} r^{\frac{3-\alpha}{2}}.$能量关系给出$\frac{dE}{dt} = \frac{dE}{dr}\frac{dr}{dt} = \frac{\mu m}{2r^2}\frac{dr}{dt}.$替代$\frac{dr}{dt}$产量$\frac{dE}{dt} = \frac{\mu m}{2r^2}\left(-\frac{2A}{m}\mu^{\frac{\alpha-1}{2}} r^{\frac{3-\alpha}{2}}\right).$取消后$m$和$2$，这变成了$\frac{dE}{dt} = -A \mu^{\frac{\alpha+1}{2}} r^{-\frac{\alpha+1}{2}}.$该表达式与从力获得的直接功公式完全相同，$\frac{dE}{dt} = -A \mu^{\frac{\alpha+1}{2}} r^{-\frac{\alpha+1}{2}}.$因此，圆形轨道演化对于任何指数都是动态一致的$\alpha$，以及值$\alpha$必须通过产生阻力的物理机制来固定。 

对于在地球框架中静止的微粒稀介质中移动的卫星，动量传递率与入射粒子通量成正比，其比例为$v$，而每次碰撞的动量变化也按比例缩放$v$。 由此产生的阻力为$F \propto v^2$, 给予$\alpha = 2$。 

＃＃ 结果$\alpha = 2.$替换不需要数值参数，因为$\alpha$是无量纲的。$$\boxed{\alpha = 2}$$## 健全性检查

 尺寸一致性要求$A v^\alpha$拥有力量单位$\mathrm{N} = \mathrm{kg,m,s^{-2}}$，它固定了单位$A$作为$\mathrm{kg,m^{1-\alpha},s^{\alpha-2}}$, 一致为$\alpha=2$。 

为了$\alpha=2$，阻力变成速度的二次方，与通过稀释气体或粒子介质的高速运动的标准状态相匹配，其中动量通量与$v^2$。 

推导的演化定律$\frac{dr}{dt} \propto r^{(3-\alpha)/2}$变成$\frac{dr}{dt} \propto r^{1/2}$为了$\alpha=2$，产生逐渐向内的螺旋，与轨道半径缓慢变化的假设一致。 

任何符号错误都很容易进入扭矩关系中$\frac{dL}{dt} = -Fr$，因为反转切向力的方向会反转推断的衰减$L$和$r$同时保持能量平衡形式不变。
