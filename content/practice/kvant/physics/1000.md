 ## 设置和假设

 边长为立方体$a$承载稳定电流$I$沿着由其边缘形成的闭合轮廓。 立方体中心需要磁感应强度$O$。 

在第一种配置中（图 2），电流沿着形成立方体的一个正方形面的四个边缘流动。 处的磁感应强度$O$该轮廓产生的大小$B_0$。 

在第二种配置中（图 3），电流沿着立方体的六个边缘流动，形成闭合轮廓，该轮廓与在立方体的一个顶点相交的三个相互相邻的面的边界重合。 

磁场在真空中评估，电流分布被视为承载稳定电流的细线。 来自不同线段的磁场的叠加是有效的。 忽略几何形状以外的边缘效应。 

## 物理原理

 稳定电流分布的磁场由细线元件的毕奥-萨伐尔定律给出，$$d\mathbf{B} = \frac{\mu_0 I}{4\pi} \frac{d\mathbf{l} \times \mathbf{r}}{r^3}.$$总磁场是所有线段贡献的矢量和。 

对于形成表面边界的一组线轮廓，可以使用毕奥-萨伐尔定律的线性将轮廓分解为更简单的闭环来获得点处的场。 

对称性意味着对于方形环路，其对称轴上的一点处的磁场沿着垂直于该环路的轴方向。 

## 推导

 让立方体的中心位于原点，边缘与坐标轴对齐。 首先考虑承载电流的立方体的单个正方形面$I$沿着它的四个边缘。 例如，该环位于一个平面上$z = a/2$。 

立方体中心位于通过其中心垂直于该面的轴上，该环产生的磁场沿着该面的法线方向。 其大小为$B_0$。 

根据立方对称性，相同的结果适用于立方体的任何面：形成任何面的方形环在中心产生一定大小的磁场$B_0$沿着该面的向外法线方向。 

图3中的六边轮廓可以表示为在立方体的一个顶点相交的三个相互垂直的正方形面的边界。 可以选择这三个面作为垂直于$x$-,$y$-， 和$z$- 共享一个公共角的轴。 

这三个面的联合的边界与六边轮廓完全重合，电流沿边缘的方向一致。 

该轮廓产生的中心磁场等于三个单独面环产生的磁场的矢量和，因为当表面分解为定向边界时，共享边缘的贡献会抵消。 

每个面环都会产生一个幅度场$B_0$位于中心，沿其向外法线方向。 选择与轮廓一致的方向给出了三个相互垂直的贡献，$$\mathbf{B}_x = B_0 \hat{\mathbf{x}}, \quad \mathbf{B}_y = B_0 \hat{\mathbf{y}}, \quad \mathbf{B}_z = B_0 \hat{\mathbf{z}}.$$中心的总磁感应强度为$$\mathbf{B} = \mathbf{B}_x + \mathbf{B}_y + \mathbf{B}_z = B_0(\hat{\mathbf{x}} + \hat{\mathbf{y}} + \hat{\mathbf{z}}).$$它的大小由单位向量的正交性得出，$$B = B_0 \sqrt{1 + 1 + 1} = \sqrt{3}\,B_0.$$方向是沿着立方体通过中心的空间对角线，对应于向量$\hat{\mathbf{x}} + \hat{\mathbf{y}} + \hat{\mathbf{z}}$，即朝向轮廓方向中使用的三个面的公共顶点。 

## 结果

 六边轮廓的立方体中心处的磁感应强度为$$\mathbf{B} = B_0(\hat{\mathbf{x}} + \hat{\mathbf{y}} + \hat{\mathbf{z}}).$$其大小为$$B = \sqrt{3}\,B_0.$$不需要额外的数字替换，因为结果是根据给定的参考字段表示的$B_0$。 

## 健全性检查

 每个面循环贡献都有特斯拉单位，所以$\mathbf{B}$保留特斯拉单位，以及因子$\sqrt{3}$是无量纲的。 

结果与电流成线性比例$I$因为每个面的贡献与$I$，符合毕奥-萨伐尔定律。 

如果三个面的贡献是两两相反的，对称性就会产生抵消，$B=0$，但几何形状选择三个正交而不是相反的贡献，因此不会发生取消。 

用已知配置替换一个面环即可恢复$B=B_0$，与参考字段的定义一致。
