 ## 问题

 有两个焦距相同的镜头系统。 透镜的光轴重合（图 1）。 第一个系统由会聚透镜组成； 在第二种情况下，会聚透镜与发散透镜交替。 如果透镜之间的距离远小于焦距，请找出每个系统中的光线轨迹。 

图1

 ## 设置和假设

 两个无限序列的薄透镜沿公共光轴放置$z$。 相邻透镜之间的距离为$d$， 和$d \ll f$， 在哪里$f$是每个透镜的焦距的大小。 

在第一个系统中，所有透镜都是会聚的，每个透镜都有焦距$f>0$。 在第二个系统中，会聚透镜和发散透镜交替出现，焦距$+f$和$-f$分别，而间距保持不变。 

射线由其高度来描述$y(z)$光轴上方及其小角度$\theta(z)$相对于轴，有$\theta \approx \frac{dy}{dz}$。 假定为近轴光学，因此所有角度都很小并且角度的高阶项被忽略。 每个透镜都被视为薄透镜，产生斜率的瞬时变化，而透镜之间的传播是随距离的自由空间传播$d$。 

目标是确定光线轨迹的形式$y(z)$在两个周期系统中的极限$d \ll f$。 

## 物理原理

 近轴区域中的薄透镜作用由以下关系描述$\theta^{+} = \theta^{-} - \frac{y}{f}$。 

自由空间远距离传播$d$受$y \to y + d\theta$，而传播过程中角度保持不变。 

射线斜率与轨迹之间的近轴关系为$\theta = \frac{dy}{dz}$。 

在具有周期的快速重复光学元件的限制下$d$，通过将差异扩展为关于以下项的导数，可以用连续微分方程代替离散映射$z$。 

## 推导

 首先考虑由透镜组成的单个细胞，然后考虑远距离传播$d$。 让$(y_n,\theta_n)$表示紧邻之前的射线参数$n$第一个镜头。 经过镜头后，角度变为$\theta_n - \frac{y_n}{f}$当高度保持不变时$y_n$。 传播到下一个透镜后，$$y_{n+1} = y_n + d\left(\theta_n - \frac{y_n}{f}\right),$$

$$\theta_{n+1} = \theta_n - \frac{y_n}{f}.$$引入连续坐标$z = nd$，有限差分写为$$\frac{y_{n+1} - y_n}{d} = \theta_n - \frac{y_n}{f}, \qquad \frac{\theta_{n+1} - \theta_n}{d} = -\frac{y_n}{fd}.$$在连续极限下，这变成了$$\frac{dy}{dz} = \theta - \frac{y}{f},$$

$$\frac{d\theta}{dz} = -\frac{y}{fd}.$$消除$\theta$通过对第一个方程求微分$z$给出$$\frac{d^2 y}{dz^2} = \frac{d\theta}{dz} - \frac{1}{f}\frac{dy}{dz}.$$将表达式替换为$\frac{d\theta}{dz}$产量$$\frac{d^2 y}{dz^2} = -\frac{y}{fd} - \frac{1}{f}\frac{dy}{dz}.$$因此第一个系统的射线方程是$$\frac{d^2 y}{dz^2} + \frac{1}{f}\frac{dy}{dz} + \frac{1}{fd}y = 0.$$因为$d \ll f$, 系数$\frac{1}{fd}$支配$\frac{1}{f^2}$尺度变化，产生快速恢复的横向力。 特征方程$$\lambda^2 + \frac{1}{f}\lambda + \frac{1}{fd} = 0$$具有复共轭根，阶次虚部较大$\sqrt{\frac{1}{fd}}$，因此横向坐标以弱指数阻尼振荡。 因此，轨迹是一个具有缓慢变化包络线的快速振荡函数。 

对于第二个系统，镜头在$+f$和$-f$。 在由两个等距离间隔的透镜组成的一个周期内，经过会聚透镜和发散透镜后的净角度变化为$$\Delta \theta = -\frac{y}{f} + \frac{y}{f} = 0$$领先顺序$y$，因为光线高度仅根据阶数变化$d\theta$，与$f$。 

因此，在整个周期内，角度的累积变化具有更高的顺序$d/f$，因此前导连续极限满足$$\frac{d^2 y}{dz^2} = 0.$$因此轨迹是线性的$z$，对应于仅进行微弱阶次修正的直线传播$d/f$。 

## 结果

 对于第一个相同会聚透镜系统，光线轨迹满足$$\frac{d^2 y}{dz^2} + \frac{1}{f}\frac{dy}{dz} + \frac{1}{fd}y = 0,$$因此$$y(z) = e^{-\frac{z}{2f}}\left(A\cos\left(\sqrt{\frac{1}{fd} - \frac{1}{4f^2}}\,z\right) + B\sin\left(\sqrt{\frac{1}{fd} - \frac{1}{4f^2}}\,z\right)\right),$$与常数$A,B$由初始条件设定。 

对于具有交替的第二个系统$+f$和$-f$透镜的主阶轨迹是$$\frac{d^2 y}{dz^2} = 0,$$所以$$y(z) = Az + B.$$## 健全性检查

 尺寸一致性自始至终保持$[f]=[d]=\mathrm{m}$意味着$\frac{1}{fd}$有单位$\mathrm{m^{-2}}$, 匹配$d^2y/dz^2$。 阻尼项$\frac{1}{f}\frac{dy}{dz}$有单位$\mathrm{m^{-2}}$以及。 

在极限内$d \to \infty$（非常稀疏的透镜），聚焦项消失，方程减少到自由传播，这与透镜影响的减小一致。 

在极限内$d \to 0$在固定的$f$, 聚焦项$\frac{1}{fd}$成为主导，产生越来越快的横向振荡，与强聚焦能力的连续介质一致。 

对于交替透镜，透镜光焦度的精确抵消发生在最低阶，因此直线传播正如每个周期净光功率为零的系统所预期的那样。
