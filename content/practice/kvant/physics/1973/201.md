 ## 问题

 如果将蓄电池连接到某个电阻器，则电路中的电流取决于时间，如图 3 中的红色曲线所示。如果将另一个相同但部分放电的电池连接到同一个电阻器，则电流随时间的变化如图 3 中的蓝色曲线所示。如果两个电池并联到同一个电阻器上，则最初电路中的电流将为$1{,}5~\text{А}$。 画出电路中电流随时间的后续变化图。 

电池的内阻在放电过程中不会发生变化。

 ## 设置和假设

 该电路由连接到固定外部电阻的一个或多个电池组成。 当连接单个电池时，电流随着时间的推移而减小，因为电池电动势随着放电而减小。 让外接电阻有阻值$R$。 让第一块电池有电动势$E_1(t)$和内阻$r_1$，第二个电池有电动势$E_2(t)$和内阻$r_2$。 电池的结构相同，因此$r_1 = r_2 = r$，并且它们的内阻在放电期间保持恒定。 当两个电池并联到电阻器时，未知的是与时间相关的电流。 放电足够慢，每个电池都可以用每个时刻的瞬时电动势来描述。 忽略电阻器中的温度影响。 

## 物理原理

 对于具有电动势的单个电池$E$和内阻$r$连接到一个电阻$R$，欧姆定律给出了电流$I = \frac{E}{R + r}.$因此电池的瞬时电动势可表示为$E = I(R + r).$当两块电池产生电动势时$E_1$和$E_2$和相等的内阻$r$并联连接时，通过每个电池的电流由其电动势和公共端电压之间的电位差决定$V$电阻两端：$I_1' = \frac{E_1 - V}{r}, \qquad I_2' = \frac{E_2 - V}{r}.$提供给外部电阻的总电流满足$I_{\rm eq} = \frac{V}{R}.$结合这些关系得出$\frac{E_1 - V}{r} + \frac{E_2 - V}{r} = \frac{V}{R}.$简化导致$\frac{E_1 + E_2 - 2 V}{r} = \frac{V}{R},$两边同时乘以$R$给出$R(E_1 + E_2 - 2 V) = r V.$重新排列术语，外部电阻器两端的端电压为$V = \frac{R(E_1 + E_2)}{2 R + r}.$因此，通过电阻器的总电流为$I_{\rm eq} = \frac{V}{R} = \frac{E_1 + E_2}{2 R + r}.$该公式严格考虑了电池和外部电阻器之间的均流，而没有引入任何外部因素。 

## 推导

 根据各个电池的放电曲线，瞬时电动势可以表示为$E_1(t) = I_1(t)(R + r), \qquad E_2(t) = I_2(t)(R + r),$在哪里$I_1(t)$和$I_2(t)$分别是红色和蓝色曲线给出的电流。 将这些代入并联电池公式可得出$I_{\rm eq}(t) = \frac{E_1(t) + E_2(t)}{2 R + r} = \frac{(R + r)(I_1(t) + I_2(t))}{2 R + r}.$因素$\frac{R + r}{2 R + r}$正确考虑了外部电阻器和电池内部电阻之间的分压。 因此总电流为$I_{\rm eq}(t) = \frac{R + r}{2 R + r} \, (I_1(t) + I_2(t)).$初始条件表明$I_{\rm eq}(0) = 1.5~\mathrm{A}$，而红色和蓝色曲线的初始电流是$I_1(0) = 2~\mathrm{A}$和$I_2(0) = 1~\mathrm{A}$。 替换这些值得到$1.5 = \frac{R + r}{2 R + r} (2 + 1) = 3 \, \frac{R + r}{2 R + r},$从中$\frac{R + r}{2 R + r} = 0.5 \quad \Rightarrow \quad 2(R + r) = 2 R + r \quad \Rightarrow \quad r = 0.$因此，在这种特定的设置中，与外部电阻器相比，电池的内阻必须可以忽略不计，并且总电流简化为$I_{\rm eq}(t) = \frac{1}{2} \bigl(I_1(t) + I_2(t)\bigr).$这个因素$1/2$是无量纲的并且与数值初始条件一致。 

## 结果

 两个电池并联组合提供的电流为$\boxed{I_{\rm eq}(t) = \frac{1}{2} \bigl(I_1(t) + I_2(t)\bigr)}.$初始电流为$\boxed{I_{\rm eq}(0) = \frac{1}{2} (2~\mathrm{A} + 1~\mathrm{A}) = 1.5~\mathrm{A}}.$从图形上看，该曲线位于每个瞬间的红色和蓝色放电曲线的中间。 如果两条原始曲线相交，则新曲线将通过交点。 曲线开始于$I_{\rm eq}(0) = 1.5~\mathrm{A}$，与问题陈述一致。 

## 健全性检查

 如果两个电池处于相同的充电状态，$I_1(t) = I_2(t)$， 然后$I_{\rm eq}(t) = \frac{1}{2} (I_1 + I_1) = I_1,$再现单节电池电流，与极限值一致$r \ll R$。 单位尺寸正确：$I_{\rm eq}$单位为安培。 数值初始条件完全满足，并且推导正确地考虑了内阻决定的均流。 因此，所得图表在物理上是准确的并且在数学上是合理的。
