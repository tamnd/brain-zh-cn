 在什么$C_1$图 3 所示电容器系统的电容等于：

 1.$C$;
 2.$kC$（$k \ne 1$）；
 3.$C_1$？ 

B·B·布霍夫采夫

 ## 设置和假设

 理想电容器系统的连接如图 3 所示，其中包含参数电容器$C_1$和电容相同的电容器$C$。 任务是确定 的值$C_1$使得等效电容$C_{\text{eq}}$整个网络的总和等于$C$, 等于$kC$为了$k \ne 1$，并且等于$C_1$。 

所有电容器均假设为理想电容器，无漏电、无寄生电感、无介电损耗。 连接被视为完美导体，因此所有通过电线连接的节点都是等电位的。 该系统在静态状态下进行分析，其中电容通过以下方式定义$Q = C_{\text{eq}}U$。 

## 物理原理

 电容的定义关系是$Q = CU$， 在哪里$Q$是存储在导体上的电荷，$U$是电容器两端的电位差。 

对于电容器网络，使用以下关系。 对于并联电容器，电容加起来为$C_{\parallel} = \sum_i C_i$。 对于串联电容器，倒数相加为$\frac{1}{C_{\text{series}}} = \sum_i \frac{1}{C_i}$。 更一般地，等效电容是通过在浮动节点处强制电荷守恒以及在由理想导体连接的节点处电势差相等来获得的。 

对于对称网络，可以识别等电位节点，从而将电路减少为串联和并联块的组合。 

## 推导

 图3中的电路关于穿过的中心垂直轴呈镜面对称$C_1$。 因此，当在外部端子之间施加电势差时，左侧和右侧的两个相同的分支携带相同的电荷。 这种对称性意味着左右分支的相应中点处于相等的电势，因此没有电荷流过对称轴。 该网络减少为两个并联的相同子电路，每个子电路包含一个减少的串联组合$C$和$C_1$。 

每个支路由一个电容器组成$C_1$与两个相同电容器形成的有效电容串联$C$同时，给予$2C$。 该系列组合$C_1$和$2C$产生支路电容$$C_{\text{branch}} = \frac{C_1 \cdot 2C}{C_1 + 2C}.$$由于两个支路相同且并联连接，因此总电容为$$C_{\text{eq}} = 2C_{\text{branch}} = \frac{2C_1 \cdot 2C}{C_1 + 2C} = \frac{4CC_1}{C_1 + 2C}.$$对于情况 1，条件$C_{\text{eq}} = C$给出$$\frac{4CC_1}{C_1 + 2C} = C.$$除以$C$产量$$\frac{4C_1}{C_1 + 2C} = 1,$$所以$$4C_1 = C_1 + 2C,$$

$$3C_1 = 2C,$$

$$C_1 = \frac{2}{3}C.$$对于情况 2，条件$C_{\text{eq}} = kC$给出$$\frac{4CC_1}{C_1 + 2C} = kC.$$除以$C$产量$$\frac{4C_1}{C_1 + 2C} = k,$$所以$$4C_1 = k(C_1 + 2C),$$

$$4C_1 = kC_1 + 2kC,$$

$$(4 - k)C_1 = 2kC,$$

$$C_1 = \frac{2k}{4 - k}C.$$对于情况 3，条件$C_{\text{eq}} = C_1$给出$$\frac{4CC_1}{C_1 + 2C} = C_1.$$两边同时乘以$C_1 + 2C$产量$$4CC_1 = C_1^2 + 2CC_1.$$重新排列，$$0 = C_1^2 - 2CC_1,$$

$$C_1(C_1 - 2C) = 0.$$不平凡的解决方案是$$C_1 = 2C.$$## 结果

 对于$C_{\text{eq}} = C$,$$C_1 = \frac{2}{3}C.$$为了$C_{\text{eq}} = kC$和$k \ne 1$,$$C_1 = \frac{2k}{4 - k}C.$$为了$C_{\text{eq}} = C_1$,$$C_1 = 2C.$$## 健全性检查

 这些表达式具有正确的维度一致性，因为所有结果都与$C$， 所以$C_1$单位为法拉。 

为了$k \to 1$，第二个表达式给出$C_1 \to \frac{2}{3}C$，匹配第一种情况。 

为了$k \to 4$，公式$C_1 = \frac{2k}{4-k}C$发散，这对应于网络接近等效电容无法达到的配置$4C$对于任意有限的$C_1$在此拓扑内。 

为了$C_1 = 2C$，代入$C_{\text{eq}} = \frac{4CC_1}{C_1 + 2C}$产量$C_{\text{eq}} = 2C$，验证案例3的自洽性。
