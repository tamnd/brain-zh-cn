 ## 问题

 F471。 隔热腔通过相同的小开口连接到两个含有气态氦的空间（图 4）。 这些体积中氦气的压力保持恒定并且等于$p$，并且温度保持等于$T$在其中一卷中和$2T$在另一个。 求腔内的稳态压力和温度。 

图 4：两个装有加压氦气的大型容器$p$和温度$T$和$2T$分别通过小开口连接到公共隔热腔。 

## 设置和假设

 该系统由一个与连接的容器相比体积可以忽略不计的隔热腔组成，通过相同的小开口与两个大量的气态氦相连。 两个大体积中的压力保持恒定并且等于$p$，同时温度保持恒定在$T$在第一卷中和$2T$在第二个。 未知量是稳态压力$p_c$和温度$T_c$腔内。 氦气可以建模为具有摩尔质量的理想气体$M$和理想气体常数$R$。 开口足够小，流动是溢流式的，而不是流体动力式的。 热交换仅通过颗粒交换发生； 否则空腔是绝热的。 腔内的碰撞足以维持麦克斯韦速度分布。 忽略重力效应和粘度，并且该过程是稳定的，因此所有时间导数都消失。 

## 物理原理

 该解决方案依赖于以下原则。 首先，在喷射条件下颗粒通过小开口的传输速率由动力学理论给出：单位时间内离开压力气体的颗粒数量$p$和温度$T$通过区域的开口$A$正比于$n \bar{v}/4$， 在哪里$n$是数密度并且$\bar{v} = \sqrt{8RT/(\pi M)}$是平均分子速度。 其次，当从两个储存器进入空腔的净颗粒通量消失时，空腔达到稳定状态； 这种条件确保了颗粒数量以及腔体内的压力恒定。 第三，在腔内粒子之间瞬时平衡的假设下，从每个储存器进入的粒子携带的能量决定了稳态下的腔温度。 对于单原子理想气体，每个粒子的平均动能是$(3/2) k_B T$， 在哪里$k_B$是玻尔兹曼常数； 进入空腔的相应能量通量与粒子通量和平均动能的乘积成正比。 

## 推导

 让$n_c$和$T_c$表示腔内的数密度和温度，以及压力$p_c = n_c R T_c$。 温度下第一个储库的粒子通量$T_1 = T$正比于$n_1 \bar{v}_1$， 和$n_1 = p/(R T_1)$和$\bar{v}_1 = \sqrt{8 R T_1 / (\pi M)}$。 因此，从储层 1 进入腔体的通量为$\Phi_1 \propto n_1 \sqrt{T_1} = \frac{p}{R T} \sqrt{T} = \frac{p}{R} T^{-1/2}.$类似地，来自水库 2 的通量$T_2 = 2T$是$\Phi_2 \propto n_2 \sqrt{T_2} = \frac{p}{R T_2} \sqrt{T_2} = \frac{p}{R (2T)} \sqrt{2T} = \frac{p}{R} (2T)^{-1/2} = \frac{p}{R} \frac{1}{\sqrt{2T}}.$让$\Phi_c$表示从腔体返回到每个储存器的粒子通量，其与$n_c \sqrt{T_c} = (p_c / R T_c) \sqrt{T_c} = p_c / (R \sqrt{T_c})$。 稳态要求从每个储存器到空腔的粒子净通量消失：$\Phi_1 + \Phi_2 = 2 \Phi_c.$替换表达式得到$\frac{p}{R} T^{-1/2} + \frac{p}{R} (2T)^{-1/2} = 2 \cdot \frac{p_c}{R \sqrt{T_c}}.$通过因式分解进行简化$p/R$给出$T^{-1/2} + (2T)^{-1/2} = 2 \frac{p_c}{p} \frac{1}{\sqrt{T_c}}.$进入腔体的能量通量由每个粒子的平均动能决定。 来自储层 1 的每个粒子的平均能量为$(3/2) k_B T$，因此能量通量与$\Phi_1 T_1$。 类似地，从储层 2 来看，它与$\Phi_2 T_2$。 稳态下腔体温度满足$\Phi_1 T_1 + \Phi_2 T_2 = 2 \Phi_c T_c.$替换通量产量$T^{-1/2} \cdot T + (2T)^{-1/2} \cdot 2T = 2 \cdot \frac{p_c}{p} \frac{1}{\sqrt{T_c}} \cdot T_c.$简化左侧给出$T^{1/2} + 2T / \sqrt{2T} = T^{1/2} + \sqrt{2} T^{1/2} = (1 + \sqrt{2}) T^{1/2}.$右侧是$2 \frac{p_c}{p} \sqrt{T_c}.$因此能量平衡方程变为$(1 + \sqrt{2}) T^{1/2} = 2 \frac{p_c}{p} \sqrt{T_c}.$与粒子平衡方程的比较$T^{-1/2} + (2T)^{-1/2} = 2 \frac{p_c}{p} \frac{1}{\sqrt{T_c}},$观察到$(2T)^{-1/2} = 1/(\sqrt{2} \sqrt{T})$，因此左侧变为$T^{-1/2} + \frac{1}{\sqrt{2}} T^{-1/2} = \left(1 + \frac{1}{\sqrt{2}}\right) T^{-1/2} = \frac{2 + \sqrt{2}}{2} T^{-1/2}.$因此粒子平衡方程为$\frac{2 + \sqrt{2}}{2} T^{-1/2} = 2 \frac{p_c}{p} \frac{1}{\sqrt{T_c}}.$将能量方程除以粒子方程消除$p_c/p$:$\frac{(1 + \sqrt{2}) T^{1/2}}{(2 + \sqrt{2}) T^{-1/2} / 2} = \frac{\sqrt{T_c}}{1 / \sqrt{T_c}} = T_c.$左侧简化如下：$\frac{(1 + \sqrt{2}) T^{1/2}}{(2 + \sqrt{2}) T^{-1/2} / 2} = \frac{2(1 + \sqrt{2}) T^{1/2}}{(2 + \sqrt{2}) T^{-1/2}} = \frac{2(1 + \sqrt{2})}{2 + \sqrt{2}} T.$因此稳态腔温度为$T_c = \frac{2(1 + \sqrt{2})}{2 + \sqrt{2}} T.$型腔压力可根据颗粒平衡方程得出：$2 \frac{p_c}{p} \frac{1}{\sqrt{T_c}} = \frac{2 + \sqrt{2}}{2} T^{-1/2},$所以$p_c = \frac{2 + \sqrt{2}}{4} \sqrt{T_c / T} \, p.$替代$T_c$产量$p_c = \frac{2 + \sqrt{2}}{4} \sqrt{\frac{2(1 + \sqrt{2})}{2 + \sqrt{2}}} \, p = \frac{\sqrt{2(1 + \sqrt{2})} }{4} p.$## 结果

 腔内的稳态温度为$T_c = \frac{2(1 + \sqrt{2})}{2 + \sqrt{2}} T \approx 1.31 \, T,$稳态压力为$p_c = \frac{\sqrt{2(1 + \sqrt{2})}}{4} \, p \approx 0.537 \, p.$## 健全性检查

 尺寸为$T_c$和$p_c$分别与温度和压力一致。 在两个储层温度相等的极限下，$T_1 = T_2 = T$，公式减少为$T_c = T$和$p_c = p$，与物理预期一致。 腔体温度介于$T$和$2T$，并且压力低于储层压力，因为流入腔体的流出物降低了稳态密度； 这两个结果在物理上都是合理的。 的平方根的步骤$T$出现在通量表达式中的对符号或单位错误最敏感，因为不正确的指数会通过能量平衡和粒子平衡传播。
