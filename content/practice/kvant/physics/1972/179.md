 ## 问题

 _在期刊中，它被错误地发表在编号 181 下。_

 潜艇在垂直下降时会发出持续时间较短的声纳脉冲$\tau_0$向着海底。 由潜艇上的水声学家测量的反射信号的持续时间为$\tau$。 潜艇的下降速度是多少？ 

水中的声速为$V$。 海底是水平的。 

## 设置和假设

 潜艇匀速垂直向下运动$u$在静止的水中，声音以速度传播$V$。 潜艇发射持续时间短的声纳脉冲$\tau_0$，传播到水平海底、反射并返回潜艇。 接收到的回声有持续时间$\tau$在潜艇上测量的。 

未知的是下降速度$u$有单位$\mathrm{m/s}$。 已知数量是$\tau_0$和$\tau$以秒为单位，并且$V$在$\mathrm{m/s}$。 

水被视为均匀的固定介质。 海床是完全刚性和静止的，在不改变频率的情况下产生镜面反射。 运动与波传播严格共线。 速度$u$假设在每个脉冲的发射和接收期间保持恒定。 声音的耗散衰减和色散被忽略。 

## 物理原理

 相对于静止介质的移动源坐标系中的声音传播会产生由源运动决定的波长变化。 对于以速度向传播方向移动的源$u$，连续的波前从逐渐靠近的位置发射，介质中的波长为$$\lambda = (V - u)\tau_0.$$静止边界处的反射保留了频率，因此保留了介质中波前之间的时间间隔。 

对于快速移动的观察者$u$朝向波长的入射波$\lambda$，观测到的频率根据经典多普勒关系增加$$f_{\text{obs}} = \frac{V + u}{\lambda}.$$观察到的周期是观察到的频率的倒数，$$\tau = \frac{1}{f_{\text{obs}}}.$$## 推导

 潜艇发射具有固有周期的脉冲$\tau_0$。 在发射过程中，潜艇向海底移动，因此每个连续脉冲都是从距离反射器较近的位置发射的。 在水框架中，连续波前之间的空间间隔等于声音在一个发射周期内传播的距离减去声源在同一时间内移动的距离，从而给出波长$$\lambda = V\tau_0 - u\tau_0 = (V - u)\tau_0.$$在海底反射后，波向上向潜艇传播，频率没有变化，因此波长相同$\lambda$表征水框架中的返回波。 

在接收过程中，潜艇向下朝着传入的向上传播的波前移动。 及时$\Delta t$，波前按距离接近潜艇$V\Delta t$当潜艇相对于波浪向上移动额外的有效接近速度时$u\Delta t$。 波前与潜艇相遇的相对速率对应于有效传播速度$V + u$，给出观察到的频率$$f = \frac{V + u}{\lambda}.$$将表达式替换为$\lambda$,$$f = \frac{V + u}{(V - u)\tau_0}.$$所接收脉冲的测量持续时间是频率的倒数，$$\tau = \frac{1}{f} = \tau_0 \frac{V - u}{V + u}.$$解决这个关系$u$首先将两边都乘以$V + u$,$$\tau (V + u) = \tau_0 (V - u).$$扩大条款，$$\tau V + \tau u = \tau_0 V - \tau_0 u.$$收集包含以下内容的术语$u$一方面是常数项，另一方面是常数项，$$\tau u + \tau_0 u = \tau_0 V - \tau V.$$保理$u$,$$u(\tau + \tau_0) = V(\tau_0 - \tau).$$除以$\tau + \tau_0$,$$u = V \frac{\tau_0 - \tau}{\tau_0 + \tau}.$$## 结果

 潜艇的下降速度为$$u = V \frac{\tau_0 - \tau}{\tau_0 + \tau}.$$用单位代替数量，$$u = V \frac{\tau_0 - \tau}{\tau_0 + \tau} = \left(\mathrm{m/s}\right)\frac{\mathrm{s} - \mathrm{s}}{\mathrm{s} + \mathrm{s}} = \mathrm{m/s}.$$最终的盒装结果是$$\boxed{u = V \frac{\tau_0 - \tau}{\tau_0 + \tau}}.$$## 健全性检查

 当$u = 0$，表达式给出$\tau = \tau_0$，这与没有运动相匹配，因为没有发生多普勒变形。 

作为$u \to V$, 中的分子$\tau = \tau_0 \frac{V - u}{V + u}$趋于零，而分母保持有限，产生$\tau \to 0$，与当潜艇接近水中声速时返回脉冲的极端压缩一致。 

尺寸一致性成立，因为分数$\frac{\tau_0 - \tau}{\tau_0 + \tau}$是无量纲的，离开$u$单位为$V$，即$\mathrm{m/s}$。 

对符号错误最敏感的步骤出现在波长形成中$\lambda = (V - u)\tau_0$以及观察者因素$V + u$，其中反转任一相对运动方向都会反转多普勒比并错误地预测脉冲展宽而不是压缩。
