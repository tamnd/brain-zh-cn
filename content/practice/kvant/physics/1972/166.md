 ## 问题

 在水平定向的气缸中，固定活塞的一侧有 1 摩尔的理想气体。 气缸的另一部分是真空的。 位于活塞和气缸壁之间的弹簧最初未变形（图 2）。 气缸与周围环境绝热。 释放活塞，建立平衡后，气体所占据的体积加倍。 气体的温度和压力如何变化？ 气缸、活塞和弹簧的热容量可以忽略不计。

 ## 设置和假设

 水平圆柱体包含$n=1$理想气体的摩尔数。 可移动的活塞将气体与真空分开。 弹簧位于活塞和气缸右壁之间。 最初，弹簧未变形且活塞固定。 气体的初始状态用压力来描述$p_1$， 体积$V_1$和温度$T_1$。 释放活塞后，气体膨胀并达到平衡，占据一定体积$V_2 = 2V_1$。 最终压力和温度表示为$p_2$和$T_2$。 气缸是隔热的，活塞、弹簧和气缸的热容可以忽略不计，因此总能量仅包含在气体和弹簧中。 气体遵循理想气体方程$pV = nRT$。 活塞是无摩擦的，系统最终达到静态平衡。 

## 物理原理

 该系统是热隔离的，因此$Q=0$。 气体热力学第一定律如下：$\Delta U = Q - W,$在哪里$\Delta U$是内能的变化，$W$是气体对活塞所做的功。 和$Q=0$，这简化为$\Delta U = - W.$对于理想气体，内能为$U = n C_V T$，所以内能的变化为$\Delta U = n C_V (T_2 - T_1).$弹簧具有弹性势能$E_s = \frac{1}{2} k x^2,$在哪里$x$是弹簧变形。 在最终平衡状态下，弹簧施加的力平衡活塞上的气体压力：$p_2 S = k x,$在哪里$S$是活塞面积。 活塞位移对应于气体的体积变化：$x = \frac{V_2 - V_1}{S} = \frac{V_1}{S}.$因此，平衡时的弹簧能量为$E_s = \frac{1}{2} k x^2 = \frac{1}{2} k \left(\frac{V_1}{S}\right)^2.$替代$k = \frac{p_2 S}{x} = \frac{p_2 S^2}{V_1}$产量$E_s = \frac{1}{2} \frac{p_2 S^2}{V_1} \frac{V_1^2}{S^2} = \frac{1}{2} p_2 V_1.$这证实了气体所做的功完全存储在弹簧中：$W = E_s = \frac{1}{2} p_2 V_1.$理想气体定律适用于初始状态和最终状态：$p_1 V_1 = n R T_1, \qquad p_2 V_2 = n R T_2.$## 推导

 系统的总能量是守恒的。 最初，能量只是气体的内能：$E_i = U_1 = n C_V T_1.$最后，能量在气体和弹簧之间分配：$E_f = U_2 + E_s = n C_V T_2 + \frac{1}{2} p_2 V_1.$使初始能量和最终能量相等可得出$n C_V T_1 = n C_V T_2 + \frac{1}{2} p_2 V_1.$最终状态的理想气体定律规定$p_2 V_2 = n R T_2$。 和$V_2 = 2 V_1$，由此可知$p_2 \cdot 2 V_1 = n R T_2 \quad \Rightarrow \quad p_2 V_1 = \frac{1}{2} n R T_2.$将该表达式代入能量守恒方程可得$n C_V T_1 = n C_V T_2 + \frac{1}{2} \cdot \frac{1}{2} n R T_2 = n C_V T_2 + \frac{1}{4} n R T_2.$两边除以$n$得出温度之间的关系：$C_V T_1 = \left(C_V + \frac{R}{4}\right) T_2.$求解最终温度给出$T_2 = \frac{C_V}{C_V + \frac{R}{4}} T_1.$这清楚地表明最终温度取决于气体热容量并且不具有普遍性； 它低于$T_1$因为一部分内能储存在弹簧中。 

相应的压力比根据理想气体定律得出：$\frac{p_2}{p_1} = \frac{n R T_2 / V_2}{n R T_1 / V_1} = \frac{T_2}{T_1} \cdot \frac{V_1}{V_2} = \frac{T_2}{T_1} \cdot \frac{1}{2}.$因此，压力相对于初始压力降低了一个因子$\frac{1}{2} \cdot \frac{C_V}{C_V + R/4}$。 

对于单原子理想气体$C_V = \frac{3}{2} R$，温度和压力比为$\frac{T_2}{T_1} = \frac{3/2}{3/2 + 1/4} = \frac{6}{7}, \qquad \frac{p_2}{p_1} = \frac{1}{2} \cdot \frac{6}{7} = \frac{3}{7}.$对于双原子理想气体$C_V = \frac{5}{2} R$，比率为$\frac{T_2}{T_1} = \frac{5/2}{5/2 + 1/4} = \frac{10}{11}, \qquad \frac{p_2}{p_1} = \frac{1}{2} \cdot \frac{10}{11} = \frac{5}{11}.$这些结果证实，由于功从气体转移到弹簧，最终温度和压力降低，并且由能量守恒定律和理想气体定律正确确定。 

## 结果

 最终温度为$T_2 = \frac{C_V}{C_V + \frac{R}{4}} T_1,$最终压力为$p_2 = \frac{1}{2} \frac{C_V}{C_V + \frac{R}{4}} p_1.$对于特定气体，这些减少到$\text{monatomic: } T_2 = \frac{6}{7} T_1, \quad p_2 = \frac{3}{7} p_1,$

$\text{diatomic: } T_2 = \frac{10}{11} T_1, \quad p_2 = \frac{5}{11} p_1.$由于能量储存在弹簧中，气体温度降低，并且压力由于膨胀和温度降低而降低。 

## 健全性检查

 尺寸一致，比例一致$T_2 / T_1$和$p_2 / p_1$是无量纲的。 定性行为在物理上是合理的：气体膨胀成更大的体积，对弹簧做功，从而降低其内部能量，从而降低其温度。 最终压力低于初始压力，与体积增加和温度下降一致。 对于任意理想气体，能量守恒是明确满足的，如通过将单原子和双原子气体的热容代入方程中所证明的那样。 三角功论证正确地解释了膨胀过程中的非恒定压力。
