 ## 问题

 _这个问题被错误地发表在期刊的第 164 号下。_

 求某一过程中理想气体的热容，其中气体温度

 1. 与其体积的平方成正比；
 2. 与体积成反比。 

I.Sh. 斯洛博代茨基

 ## 设置和假设

 理想气体含有$n$摩尔经历准静态热力学过程，其中温度$T$被规定为体积的函数$V$。 该过程的热容量定义为$$C = \frac{\delta Q}{dT},$$在哪里$\delta Q$是在给定过程中无限小的状态变化期间提供给气体的无限小的热量。 

假设气体是理想的，因此其内能仅取决于温度，由下式给出$$U = n C_V T,$$在哪里$C_V$是定体积下的摩尔热容。 该过程假设为准静态，因此状态方程$$PV = nRT$$在每个中间状态下都成立。 不会发生相变或化学反应。 

考虑两种情况。 在第一种情况下，温度与体积的平方成正比，$$T = a V^2,$$在哪里$a$是一个正常数。 在第二种情况下，温度与体积成反比，$$T = \frac{a}{V}.$$未知的是热容$C$每种情况下的流程。 

## 物理原理

 准静态过程的热力学第一定律是$$\delta Q = dU + P\,dV.$$对于理想气体，内能差为$$dU = n C_V dT.$$状态方程为$$P = \frac{nRT}{V}.$$过程中的热容量定义为$$C = \frac{\delta Q}{dT}.$$## 推导

 将第一定律和表达式代入$dU$代入热容的定义可得$$C = \frac{dU + P\,dV}{dT} = nC_V + P\frac{dV}{dT}.$$使用压力的理想气体定律，$$C = nC_V + \frac{nRT}{V}\frac{dV}{dT}.$$### 案例 1：$T = aV^2$分化产量$$\frac{dT}{dV} = 2aV,$$所以$$\frac{dV}{dT} = \frac{1}{2aV}.$$表达$a$通过$T$和$V$从$T = aV^2$给出$a = \frac{T}{V^2}$， 因此$$\frac{dV}{dT} = \frac{V}{2T}.$$代入热容表达式，$$C = nC_V + \frac{nRT}{V}\cdot \frac{V}{2T}.$$取消$T$和$V$导致$$C = nC_V + \frac{nR}{2}.$$### 案例 2：$T = \frac{a}{V}$分化产量$$\frac{dT}{dV} = -\frac{a}{V^2}.$$使用$T = \frac{a}{V}$给出$a = TV$， 所以$$\frac{dT}{dV} = -\frac{T}{V},$$因此$$\frac{dV}{dT} = -\frac{V}{T}.$$代入热容表达式，$$C = nC_V + \frac{nRT}{V}\cdot\left(-\frac{V}{T}\right).$$取消$T$和$V$产量$$C = nC_V - nR.$$## 结果

 对于过程$T \propto V^2$,$$C = n\left(C_V + \frac{R}{2}\right).$$对于过程$T \propto \frac{1}{V}$,$$C = n(C_V - R).$$对于一摩尔气体（$n = 1$），摩尔热容为$$C_1 = C_V + \frac{R}{2}, \qquad C_2 = C_V - R.$$对于单原子理想气体，其中$C_V = \frac{3R}{2}$,$$C_1 = 2R = 16.6\ \mathrm{J\,mol^{-1}K^{-1}}, \qquad C_2 = \frac{R}{2} = 4.16\ \mathrm{J\,mol^{-1}K^{-1}}.$$## 健全性检查

 表达式$C = nC_V + nR T/V \cdot dV/dT$有单位为$\mathrm{J,K^{-1}}$因为$C_V$有单位$\mathrm{J,mol^{-1}K^{-1}}$乘以$n$，第二项减少为$nR$乘以无量纲因子，确保一致性。 

在这两种情况下，修正为$nC_V$正比于$nR$，唯一可用的气体参数组合，其带有独立于状态变量的热容量单位，从而确认维度闭合。 

对于第一个过程，术语$+nR/2$相对于恒定体积值，热容增加，因为温度升高伴随着膨胀，需要额外的热量输入来抵抗外部压力。 对于第二个过程，术语$-nR$降低了热容量，因为系统在加热时会收缩，因此部分供应的能量会作为对周围环境所做的功而被回收，从而减少了单位温度升高所需的净热量。
