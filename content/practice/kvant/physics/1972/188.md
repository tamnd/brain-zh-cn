 ## 问题

 有电源的冰箱$W$，经过一段时间$\tau$，转身$n$升水，最初有温度$t^{\circ}~\text{C}$，变成冰。 在此期间向房间释放了多少热量？ 

## 设置和假设

 冰箱运行一段时间$\tau$在消耗电力的同时$W$。 在此期间它会冻结$n$初始温度下的水升数$t^\circ\text{C}$。 任务是确定在此过程中释放到房间的总热量。 

水被视为不可压缩的密度$1,\text{kg}/\text{L}$，所以它的质量是$m = n,\text{kg}$。 初始温度$t$满足$t \ge 0^\circ\text{C}$，水的最终状态是冰$0^\circ\text{C}$。 水的比热容表示为$c$，冰的熔化潜热表示为$\lambda$。 除了与冰箱和水相关的热损失之外，忽略其他热损失。 假定最终被冰箱冷凝器拒绝的所有能量都进入房间。 

## 物理原理

 冷却液态水所需的热量$t$到$0^\circ\text{C}$由下式给出$Q_1 = mc t.$液态水在相变过程中释放的热量$0^\circ\text{C}$冰在$0^\circ\text{C}$是$Q_2 = m\lambda.$循环运行的冰箱的热力学第一定律指出，传递到热库（房间）的热量等于从冷库提取的热量与提供的机械功之和：$Q_{\text{room}} = Q_{\text{removed}} + A,$在哪里$A$是随时间变化的电功输入$\tau$，由下式给出$A = W\tau.$## 推导

 从水中带走的总热量由两部分组成。 首先是冷却水$t^\circ\text{C}$到$0^\circ\text{C}$，这产生$Q_1 = mc t$。 第二个是把水结冰$0^\circ\text{C}$，这产生$Q_2 = m\lambda$。 因此，提取的总热量为$Q_{\text{removed}} = mc t + m\lambda.$将其代入冰箱的能量平衡中，可得出释放到房间中的热量：$Q_{\text{room}} = mc t + m\lambda + W\tau.$将质量替换为$m = n$（和$n$以升为单位解释为千克）给出$Q_{\text{room}} = n c t + n\lambda + W\tau.$## 结果

 释放到房间的总热量为$Q_{\text{room}} = n(ct + \lambda) + W\tau.$明确替换单位，

 Q_{\text{房间}} = n\,(\text{kg}) \cdot \left(c\,\frac{\text{J}}{\text{kg}\cdot^\circ\text{C}} \cdot t\,^\circ\text{C} + \lambda\,\frac{\text{J}}{\text{kg}}\right) + W\,\text{W} \cdot \tau\,\text{s}。 

因此，$\boxed{Q_{\text{room}} = n(ct + \lambda) + W\tau \;\text{J}}.$## 健全性检查

 每个携带能量单位的项都具有量纲一致性：$ct$有单位$\text{J}/\text{kg}$,$\lambda$有单位$\text{J}/\text{kg}$，并乘以$n$以千克为单位产生焦耳； 期限$W\tau$还有单位$\text{J}$自从$\text{W} = \text{J}/\text{s}$。 

在极限情况下$W \to 0$，结果减少为冷却和冷冻水所释放的纯热力学热量，$n(ct + \lambda)$。 如果$t \to 0$，只剩下潜热，给出$n\lambda + W\tau$。 对于较长的操作时间$\tau$, 贡献$W\tau$占主导地位，这与冰箱不断地将提取的热量和输入的功倒入房间一致。
