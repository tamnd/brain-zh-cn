 ## 问题

 面积薄的金属板$s$覆盖有一层具有密度的液体电介质$\rho$和介电常数$\varepsilon$，使得该层的厚度远小于板的线性尺寸。 如果板带电荷，液体会发生什么$+Q$？ 

V·D·克里夫琴科夫

 ## 设置和假设

 一块薄的水平金属板$s$带有电荷$+Q$，所以自由表面电荷密度为$\sigma = \dfrac{Q}{s}$在$\mathrm{C,m^{-2}}$。 该板被密度液体电介质覆盖$\rho$在$\mathrm{kg,m^{-3}}$和相对介电常数$\varepsilon$。 液体形成一层厚度$h$它比板的特征线性尺寸小得多，因此忽略边缘效应，并且所有场都被视为局部一维且垂直于表面。 

液体上方的区域是空气，用介电常数视为真空$\varepsilon_0$。 系统被认为处于静电平衡状态。 假设液体不可压缩、不导电，并且能够在没有粘性约束的情况下移动，从而可以建立机械平衡曲线。 重力随着加速度向下作用$g$。 

未知的是液体构型的变化，特别是平衡厚度$h$带电板上介电层的形状以及液体在电场影响下的运动方向。 

## 物理原理

 物质中电位移场的高斯定律采用以下形式$\nabla \cdot \mathbf{D} = \rho_{\mathrm{free}},$边界条件为$\mathbf{D}$具有等于​​自由表面电荷密度的不连续性。 

线性各向同性电介质的本构关系为$\mathbf{D} = \varepsilon_0 \varepsilon \mathbf{E}$液体内部和$\mathbf{D} = \varepsilon_0 \mathbf{E}$在空气中。 

静电能量密度表示为$\mathbf{D}$是$u = \frac{1}{2}\mathbf{E}\cdot\mathbf{D} = \frac{D^2}{2\varepsilon_0 \varepsilon}$在电介质和$u = \frac{D^2}{2\varepsilon_0}$在空气中。 

场对电介质的机械效应是通过静电能相对于电介质占据的体积的变化而获得的。 由此产生的有效压力为$p = -\frac{\partial U}{\partial V},$按固定免费费用进行评估。 

液体中的静水力平衡要求$p_{\mathrm{electric}} = \rho g h.$## 推导

 带电板固定周围空间中位移场的法向分量。 由于板是携带总电荷的导体$Q$，自由表面电荷密度均匀且等于$\sigma = Q/s$。 高斯定律应用于横跨导体表面的药盒给出$D_n = \sigma.$因此，在介电层内部，电场的大小为$E_{\mathrm{d}} = \frac{D}{\varepsilon_0 \varepsilon} = \frac{\sigma}{\varepsilon_0 \varepsilon},$在液体上方的空气中$E_{\mathrm{a}} = \frac{D}{\varepsilon_0} = \frac{\sigma}{\varepsilon_0}.$电介质中的静电能量密度为$u_{\mathrm{d}} = \frac{D^2}{2\varepsilon_0 \varepsilon},$在空气中它是$u_{\mathrm{a}} = \frac{D^2}{2\varepsilon_0}.$用相同体积的电介质代替空气层，能量密度会改变$\Delta u = u_{\mathrm{d}} - u_{\mathrm{a}} = \frac{D^2}{2\varepsilon_0}\left(\frac{1}{\varepsilon} - 1\right).$这种能量的减少对应于将电介质拉入更强场的区域的机械压力。 作用在液体表面上的有效压力的大小由单位体积的能量变化（符号相反）得出，$p = -\Delta u = \frac{D^2}{2\varepsilon_0}\left(1 - \frac{1}{\varepsilon}\right).$替代$D = \sigma$给出$p = \frac{\sigma^2}{2\varepsilon_0}\left(1 - \frac{1}{\varepsilon}\right).$和$\sigma = Q/s$，这变成了$p = \frac{Q^2}{2\varepsilon_0 s^2}\left(1 - \frac{1}{\varepsilon}\right).$液体沿着板上升，直到电压与升高的柱的静水压力平衡，$\rho g h = \frac{Q^2}{2\varepsilon_0 s^2}\left(1 - \frac{1}{\varepsilon}\right).$解决$h$给出$h = \frac{Q^2}{2\varepsilon_0 \rho g s^2}\left(1 - \frac{1}{\varepsilon}\right).$## 结果

 电介质液体被吸引到带电板上并在其上扩散，形成较厚的层，其平衡厚度为$h = \frac{Q^2}{2\varepsilon_0 \rho g s^2}\left(1 - \frac{1}{\varepsilon}\right).$所有数量均采用 SI 单位：$Q$在$\mathrm{C}$,$s$在$\mathrm{m^2}$,$\varepsilon_0$在$\mathrm{F,m^{-1}}$,$\rho$在$\mathrm{kg,m^{-3}}$,$g$在$\mathrm{m,s^{-2}}$。 由此产生的$h$是在$\mathrm{m}$。 

## 健全性检查

 尺寸一致性如下：$\sigma^2/\varepsilon_0$有单位$\mathrm{C^2,m^{-4}} / \mathrm{F,m^{-1}} = \mathrm{N,m^{-2}}$，这是压力，除以$\rho g$产生以米为单位的长度。 

在极限内$\varepsilon \to 1$，压力消失并且$h \to 0$，对应于相对于空气的任何介电偏好的消失。 在极限内$\varepsilon \to \infty$，压力接近$\sigma^2/(2\varepsilon_0)$，给出完美电介质所期望的最大吸引力。 

该表达式显示随电荷的二次增长$Q$，与场平方的静电压力缩放一致，因为$E \sim \sigma$。 推导中最敏感的失败点在于将位移场视为均匀且等于$\sigma$; 任何忽略电介质-空气界面处的边界条件都会错误地修改该因子$\left(1 - \frac{1}{\varepsilon}\right)$并改变预测压力。
