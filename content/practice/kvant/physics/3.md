 ## 问题

 用两根相同的钢丝制成了两个弹簧。 其中一个线圈的直径等于$d$，以及其他的$2d$。 第一个弹簧在负载的作用下，拉伸了其长度的十分之一。 在相同负载的作用下，第二个弹簧将拉伸其长度的几分之一？ 

## 设置和假设

 两个螺旋弹簧由总钢丝长度相等的相同钢丝段制成$L_w$且线径相同。 弹簧仅在线圈直径上有所不同：第一个弹簧具有线圈直径$D_1 = d$，第二个有$D_2 = 2d$。 

两种弹簧都被假设为理想的：线材遵循胡克定律，变形是纯弹性的，线圈以均匀的节距紧密缠绕，并且忽略末端效应。 钢的剪切模量为$G$，并且两个弹簧的情况相同。 施加的载荷是力$F$沿弹簧轴线作用。 

第一个弹簧伸长一小部分$\varepsilon_1 = \frac{\Delta L_1}{L_1} = \frac{1}{10}$。 目标是确定$\varepsilon_2 = \frac{\Delta L_2}{L_2}$对于第二个弹簧在相同的力下$F$。 

## 物理原理

 对于由线材制成的密卷螺旋弹簧，轴向刚度由线材的扭转变形决定。 弹簧常数为$k = \frac{G r^4}{8 n D^3},$在哪里$r$是导线半径，$n$是匝数，并且$D$是线圈直径。 

轴向伸长满足胡克定律$\Delta L = \frac{F}{k}.$总导线长度与几何形状相关：$L_w = n \pi D,$所以匝数为$n = \frac{L_w}{\pi D}$。 

当节距固定时，宏观弹簧长度与圈数成比例，因此$L \propto n.$## 推导

 替代$n = \frac{L_w}{\pi D}$代入刚度公式可得$k = \frac{G r^4}{8 D^3} \cdot \frac{\pi D}{L_w} = \frac{G r^4 \pi}{8 L_w} \cdot \frac{1}{D^2}.$除$D$两个弹簧相同，所以$k \propto \frac{1}{D^2}.$为了第二个春天$D_2 = 2d$,$\frac{k_2}{k_1} = \frac{D_1^2}{D_2^2} = \frac{d^2}{(2d)^2} = \frac{1}{4},$因此$k_2 = \frac{k_1}{4}.$在同样的力量下$F$，扩展满足$\Delta L_1 = \frac{F}{k_1}, \quad \Delta L_2 = \frac{F}{k_2} = \frac{F}{k_1/4} = 4 \Delta L_1.$第一个弹簧的相对伸长量为$\frac{\Delta L_1}{L_1} = \frac{1}{10},$所以$\Delta L_1 = \frac{L_1}{10}.$因此，$\Delta L_2 = 4 \cdot \frac{L_1}{10} = \frac{2L_1}{5}.$第二个弹簧的长度与圈数成比例。 自从$n \propto \frac{1}{D}$, 加倍$D$一半$n$，因此第二个弹簧长度是$L_2 = \frac{L_1}{2}.$因此第二个弹簧的相对伸长量为$\frac{\Delta L_2}{L_2} = \frac{\frac{2L_1}{5}}{\frac{L_1}{2}} = \frac{2}{5} \cdot 2 = \frac{4}{5}.$＃＃ 结果$\varepsilon_2 = \frac{\Delta L_2}{L_2} = \frac{4}{5} = 0.80.$第二个春天延伸了$0.80$， IE。$80%$相同载荷下的长度。 

## 健全性检查

 依赖性$k \propto D^{-2}$与螺旋弹簧中的扭转能量存储一致，因为增加线圈直径会增加扭矩的杠杆臂并强烈降低刚度。 直径加倍会使刚度降低四倍，与导出的比例相匹配。 

延伸增加四倍与恒力下刚度降低一致。 相对伸长率的额外系数二是由匝数减半以及弹簧长度减半引起的。 

尺寸一致性自始至终保持不变$k$有单位为$\mathrm{N/m}$所有几何比例因子都是无量纲的。 最终结果是一个纯分数，符合相对变形的要求。
