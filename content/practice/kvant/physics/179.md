 ## 问题

 _它被错误地发表在期刊上，问题编号为 181._


 一艘垂直下降的潜艇向海底发射短声纳脉冲，持续时间$\tau_0$。 水声操作员在潜艇上测量的反射信号的持续时间为$\tau$。 潜艇的下降速度是多少？ 

水中的声速为$V$。 海底是水平的。 

## 设置和假设

 潜艇在均匀、静止的流体中垂直向下运动，声音以恒定速度传播$V$相对于水。 海床是一个固定的、完美反射的水平表面。 潜艇发射持续时间短的声纳脉冲$\tau_0$在潜艇框架中测量。 反射脉冲返回到船上的同一接收器，其测量的持续时间为$\tau$。 

未知的是恒定的下降速度$u$潜艇的方向向下。 

分析假设潜艇在脉冲发射和接收过程中进行直线匀速运动，在海底瞬时反射，并且声音的吸收和散射可以忽略不计。 假设脉冲持续时间足够短$u$在整个发射和接收过程中保持恒定。 

## 物理原理

 声脉冲在水中高速传播$V$相对于介质，独立于源和接收器的运动。 

信号的传播时间由水系中的路径长度与波速之比决定$V$。 

潜艇在传播过程中的运动会改变有效的发射和接收几何形状，因此总延迟是通过将在同一水惯性系中计算的发射时间、向下传播时间和向上传播时间相加来获得的。 

接收到的脉冲的持续时间是发射脉冲的前沿和后沿的到达时间之差。 

## 推导

 设向下方向为正。 发射时$t$，潜艇处于深度$x(t)$，到海底的距离为$d(t)$。 由于潜艇匀速下降$u$，距离减小为$$d(t) = d_0 - ut.$$在某个时间发出的脉冲的前沿$t$一段时间后到达海底$t_1$由声音传播距离的条件决定$d(t)$高速$V$：$$V t_1 = d(t),$$所以$$t_1 = \frac{d(t)}{V}.$$在反射时刻，潜艇在时间范围内进一步向下移动$t_1$，因此潜艇与海底之间的距离变为$$d_{\mathrm{ref}}(t) = d(t) - u t_1 = d(t)\left(1 - \frac{u}{V}\right).$$反射脉冲向上传播到继续向下移动的接收器。 向上运动的声音与向下运动的潜艇之间的相对接近速度为$V+u$，所以返回时间$t_2$满足$$(V+u)t_2 = d_{\mathrm{ref}}(t),$$这给出了$$t_2 = \frac{d(t)\left(1 - \frac{u}{V}\right)}{V+u}.$$发射时间对应的反射信号到达时间$t$是$$T(t) = t + t_1 + t_2 = t + \frac{d(t)}{V} + \frac{d(t)\left(1 - \frac{u}{V}\right)}{V+u}.$$自从$d(t)=d_0-ut$是线性的$t$，函数$T(t)$也是线性的$t$，因此接收脉冲的持续时间是通过将发射的持续时间乘以系数获得的$dT/dt$。 

区分、使用$d'(t)=-u$，产量$$\frac{dT}{dt} = 1 - \frac{u}{V} - \frac{u\left(1 - \frac{u}{V}\right)}{V+u}.$$接收到的持续时间满足$$\tau = \tau_0 \frac{dT}{dt}.$$介绍一下比例$$r = \frac{\tau}{\tau_0}.$$然后$$r = 1 - \frac{u}{V} - \frac{u\left(1 - \frac{u}{V}\right)}{V+u}.$$乘以$V(V+u)$消除分母：$$rV(V+u) = V(V+u) - u(V+u) - uV + u^2.$$两边展开并化简可得$$rV(V+u) = V(V-u).$$除以$V$导致$$r(V+u) = V - u.$$解决$u$,$$rV + ru = V - u,$$

$$u(r+1) = V(1-r),$$所以$$u = V\frac{1-r}{1+r}.$$正在恢复$r=\tau/\tau_0$,$$u = V\frac{\tau_0 - \tau}{\tau_0 + \tau}.$$## 结果

 潜艇的下降速度为$$u = V\frac{\tau_0 - \tau}{\tau_0 + \tau}.$$将给定数量替换为一致的单位，$$\boxed{u = V\frac{\tau_0 - \tau}{\tau_0 + \tau}\ \text{m/s}}.$$## 健全性检查

 该表达式在量纲上是一致的，因为它是无量纲比率乘以声速$V$，给出速度单位。 

在极限情况下$u=0$，潜艇是静止的，所以$\tau=\tau_0$，公式给出$u=0$根据需要。 

如果$u$增加，接收到的脉冲缩短，所以$\tau<\tau_0$，使分子为正且屈服$u>0$，与向下运动一致。 

如果$u$方法$V$，由于反射信号很快被下降的接收器赶上，接收持续时间趋于零，公式给出$\tau \to 0$和$u \to V$，匹配相对于移动潜艇的声音传播的物理极限。 

最敏感的步骤是将往返传播时间转换为单因子$dT/dt$，因为在向下或向上腿期间运动中的任何符号错误都会错误地改变最终的分数依赖关系$u/V$。
