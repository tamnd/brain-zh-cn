 ## 问题

 一根导电棒由两根细导线水平悬挂在垂直磁场中，产生感应$E = 1~\text{Тл}$（见图4）。 杆的长度为$l = 0{,}2~\text{м}$，其质量为$m = 10~\text{г}$，电线的长度是$l_1 = 0{,}1~\text{м}$。 电容的电容器$C = 100~\text{мкФ}$，充电至电压$U = 100~\text{В}$，连接到连接电线的点。 

1. 假设放电发生在很短的时间内，确定电容器放电后系统偏离平衡位置的最大角度。 
2、确定电容值$C_1$电容器在放电时系统将偏转一定角度$\alpha = 3^\circ$，如果当电容器充电到与电容相同的电压时$C_0 = 10~\text{мкФ}$放电时，偏转角为$\alpha_0 = 2^\circ$。

 ## 设置和假设

 一定长度的刚性导电棒$l = 0.2,\text{m}$由两条长度相同的灯线水平悬挂$l_1 = 0.1,\text{m}$。 将系统放置在具有感应的均匀垂直磁场中$B = 1,\text{T}$。 电容的电容器$C = 100,\mu\text{F}$，初始充电至电压$U = 100,\text{V}$，连接到电线的悬挂点，以便在放电期间电流脉冲流过杆。 

杆的质量为$m = 10,\text{g} = 0.01,\text{kg}$。 假设放电时间与机械振荡周期相比可以忽略不计，因此磁力充当脉冲。 

放电后的运动被视为刚体在重力场中的平面运动，电线表现为无质量约束，定义了具有有效长度的钟摆运动$l_1$。 在脉冲后的机械演化中，空气阻力和电阻效应被忽略。 

## 物理原理

 在均匀磁场中作用在载流导体上的磁力冲量由下式确定$\mathbf{F} = I\,\mathbf{l} \times \mathbf{B}.$脉冲的时间积分为$\mathbf{J} = \int \mathbf{F}\,dt = B l \int I\,dt,$在哪里$\int I,dt$等于总电荷$Q$放电期间穿过杆。 

对于电容器来说，$Q = CU.$冲量后的机械能在转折点立即转换为重力势能，$\frac{1}{2}mv^2 = mg h,$其中长度为摆的垂直上升$l_1$是$h = l_1(1 - \cos\alpha).$## 推导

 放电期间转移的总电荷为$Q = CU.$传递到杆的磁脉冲为$J = B l Q = B l C U.$该冲量等于杆的动量，$mv = B l C U,$所以初始速度是$v = \frac{B l C U}{m}.$放电后立即的动能为$\frac{1}{2}mv^2 = \frac{1}{2}m\left(\frac{B l C U}{m}\right)^2 = \frac{B^2 l^2 C^2 U^2}{2m}.$最大偏转角时$\alpha$，能量守恒给出$\frac{B^2 l^2 C^2 U^2}{2m} = mg l_1(1 - \cos\alpha).$解决角度依赖性，$1 - \cos\alpha = \frac{B^2 l^2 C^2 U^2}{2m^2 g l_1}.$###第一部分

 代入数值：$Q = CU = 100 \cdot 10^{-6}\,\text{F} \cdot 100\,\text{V} = 1.0 \times 10^{-2}\,\text{C}.$冲动：$J = B l Q = 1\,\text{T} \cdot 0.2\,\text{m} \cdot 1.0 \times 10^{-2}\,\text{C} = 2.0 \times 10^{-3}\,\text{N·s}.$速度：$v = \frac{J}{m} = \frac{2.0 \times 10^{-3}\,\text{N·s}}{1.0 \times 10^{-2}\,\text{kg}} = 0.2\,\text{m/s}.$活力：$\frac{1}{2}mv^2 = \frac{1}{2}\cdot 1.0\times 10^{-2}\,\text{kg}\cdot (0.2\,\text{m/s})^2 = 2.0 \times 10^{-4}\,\text{J}.$势能标度：$mgl_1 = 1.0\times 10^{-2}\,\text{kg}\cdot 9.8\,\text{m/s}^2 \cdot 0.1\,\text{m} = 9.8\times 10^{-3}\,\text{J}.$因此$1 - \cos\alpha = \frac{2.0\times 10^{-4}}{9.8\times 10^{-3}} = 2.04\times 10^{-2}.$所以$\cos\alpha = 0.9796,$这给出了$\alpha \approx 11.5^\circ.$### 第二部分

 上面推导的关系表明$1 - \cos\alpha \propto C^2.$因此对于两种情况，$\frac{1 - \cos\alpha}{1 - \cos\alpha_0} = \left(\frac{C_1}{C_0}\right)^2.$使用$\alpha_0 = 2^\circ$,$\alpha = 3^\circ$,$C_0 = 10,\mu\text{F}$：$\cos 2^\circ = 0.9993908,\quad 1 - \cos 2^\circ = 6.092\times 10^{-4},$

$\cos 3^\circ = 0.9986295,\quad 1 - \cos 3^\circ = 1.3705\times 10^{-3}.$比率：$\frac{1 - \cos 3^\circ}{1 - \cos 2^\circ} = \frac{1.3705\times 10^{-3}}{6.092\times 10^{-4}} = 2.25.$所以，$\frac{C_1}{C_0} = \sqrt{2.25} = 1.5,$所以$C_1 = 1.5 \cdot 10\,\mu\text{F} = 15\,\mu\text{F}.$## 结果

 第一部分：$\alpha = \arccos\!\left(1 - \frac{B^2 l^2 C^2 U^2}{2m^2 g l_1}\right) \approx 11.5^\circ.$第二部分：$C_1 = C_0 \sqrt{\frac{1 - \cos 3^\circ}{1 - \cos 2^\circ}} = 15\,\mu\text{F}.$最终答案：$\boxed{\alpha \approx 11.5^\circ}, \qquad \boxed{C_1 \approx 15\,\mu\text{F}}.$## 健全性检查

 脉冲缩放为$B l C U$, 给定单位$\text{T}\cdot\text{m}\cdot\text{C} = \text{N·s}$，与动量传递一致。 导出的角度取决于无量纲比$v^2/(g l_1)$，确保尺寸一致性。 

第一个结果给出了一个适中的角度，与小但不可忽略的电能转换一致$CU^2/2 = 0.5,\text{J}$转化为机械能$2\times 10^{-4},\text{J}$，表明通过脉冲机制转换的机械效率较低。 

第二部分 比例$1 - \cos\alpha \propto C^2$预测角度适度增加$2^\circ$到$3^\circ$需要将电容增加接近一个因子$1.5$，与计算值一致。
