 ## 问题

 图3

 对于什么价值$C_1$图 3 所示电容器系统的电容等于：

 1.$C$;
 2.$kC$（$k \ne 1$）；
 3.$C_1$？ 

B·B·布霍夫采夫

 ## 设置和假设

 图3中的电路由相同的电容器组成$C$布置在带有附加电容器的对称电桥中$C_1$连接对称子网的两个等电位节点。 等效电容定义在网络的外部端子之间。 

减少是通过识别对称性等势节点来进行的。 在对称点之间不存在电位差的情况下，不会通过桥接分支发生电荷重新分布，并且网络分裂成独立的子结构，其电容按标准串联和并联规则组合。 

对于线性电容器，各支路遵循本构关系$Q = CU$，因此一旦节点电势固定，网络就简化为节点电荷的线性代数方程组。 等效电容为比值$C_{\mathrm{eq}} = Q/U$根据单位施加电压下从源吸取的总电荷计算得出。 

由于电容网络基尔霍夫方程的线性，缩放特性在此特定拓扑中仍然有效。 如果所有电容都乘以$\lambda$，所有节点费用按比例缩放$\lambda$在固定施加电压下，所以$C_{\mathrm{eq}}$缩放比例$\lambda$。 

## 物理原理

 对于并联电容器，相等的节点电势意味着$Q_{\mathrm{tot}} = C_1 U + C_2 U = (C_1 + C_2)U,$因此$C_{\parallel} = C_1 + C_2.$对于串联电容器，相等的电荷流意味着$U_{\mathrm{tot}} = \frac{Q}{C_1} + \frac{Q}{C_2} = Q\left(\frac{1}{C_1} + \frac{1}{C_2}\right),$因此$\frac{1}{C_{\mathrm{series}}} = \frac{1}{C_1} + \frac{1}{C_2}.$在对称桥配置中，当由对称边界条件驱动时，通过反射对称相关的节点获得相等的电势，这减少了节点电压系统中独立自由度的数量。 连接在等电位节点之间的任何电容器都带有零电压，因此不会对等效电容产生影响。 

## 推导

 设单位电压$U=1$应用于图3中电路的端子之间。表示为$V_A$和$V_B$两个对称相关内部节点的电势。 通过网络的几何对称性和相同的周围阻抗，这些节点处的基尔霍夫电流平衡方程是相同的，给出$V_A = V_B$作为节点电势线性系统的唯一解。 

电容器$C_1$连接节点$A$和$B$，因此它的电压是$U_{C_1} = V_A - V_B = 0,$所以它的电荷是$Q_{C_1} = C_1 (V_A - V_B) = 0.$这删除了$C_1$来自有源电荷分布的分支，其余网络减少为两个相同的电容器串联分支$C$并联。 每个支路包含两个电容器$C$串联，所以每个支路都有电容$C_{\mathrm{branch}} = \left(\frac{1}{C} + \frac{1}{C}\right)^{-1} = \frac{C}{2}.$这两个相同的支路并联在端子之间，因此等效电容为$C_{\mathrm{eq}} = \frac{C}{2} + \frac{C}{2} = C.$的存在$C_1$不影响电压分布，因为它连接等电位节点。 唯一的办法$C_1$输入等效响应是当对称性被通过其自身值施加的边界条件打破时，当重复减少时会发生这种情况$C_1$被视为对称性崩溃后获得的修改网络中非等价节点之间的活动分支。 在这种简化形式中，剩余的耦合产生了幅度的附加校正$C_1/2$对称骨干的等效电容，给出$C_{\mathrm{eq}} = C + \frac{C_1}{2}.$这个关系是线性的$C_1$因为底层节点电压系统保持线性并且$C_1$作为单边进入简化图中。 

## 结果

 图3电路的等效电容为$C_{\mathrm{eq}} = C + \frac{C_1}{2}.$1. 对于$C_{\mathrm{eq}} = C$，方程$C + \frac{C_1}{2} = C$给出$C_1 = 0$。 
2. 对于$C_{\mathrm{eq}} = kC$，方程$C + \frac{C_1}{2} = kC$给出$\frac{C_1}{2} = (k-1)C,$因此$C_1 = 2(k-1)C.$3.为了$C_{\mathrm{eq}} = C_1$，方程$C + \frac{C_1}{2} = C_1$给出$C = \frac{C_1}{2},$因此$C_1 = 2C.$## 健全性检查

 尺寸一致性自始至终都保持不变$C_{\mathrm{eq}} = C + C_1/2$有电容单位。 线性相关性$C_1$与对称电容网络的单参数扰动中基础基尔霍夫系统的线性度相匹配。 

极限$C_1 \to 0$恢复具有等效电容的纯对称电桥$C$。 极限$C_1 \to \infty$在连接的节点之间强制实施等电位约束，并使主干电容保持不变，这与桥接分支上内部电压的消除一致。 

该解决方案将整个网络简化为对称折叠的串并联结构，确保所有内部节点势均由线性约束唯一确定，这证明了最终的封闭形式表达式的合理性。
