 ## 问题

 在远处$2F$从会聚透镜$\text{Л}_1$与焦距$F$，找到一个发光物体。 屏幕上物体清晰图像的照度等于$E_0$。 屏幕和镜头之间$\text{Л}_1$, 发散透镜$\text{Л}_2$与焦距$-2F$被放置。 为了获得物体的清晰图像，屏幕必须移动等于$F$。 确定第二种情况下物体图像的照度。 

V·E·贝洛努奇金

 ## 设置和假设

 将发光物体放置在薄会聚透镜的光轴上$\text{Л}_1$与焦距$F$。 距镜头的物距为$s_1 = 2F$。 在初始配置中，屏幕上形成清晰的图像，该图像的照度为$E_0$。 

薄的发散透镜$\text{Л}_2$与焦距$f_2 = -2F$被插入之间$\text{Л}_1$和屏幕。 插入第二个镜头后，屏幕沿光轴位移一段距离$F$从而形成新的清晰图像。 任务是确定照度$E$第二种配置中的图像。 

所有透镜都假设为薄且理想的，近轴近似有效，忽略吸收和反射引起的能量损失，并且将物体视为具有固定表面亮度的朗伯发射器，以便仅通过几何成像和放大倍数确定图像照度。 

## 物理原理

 对于薄透镜，成像关系由下式给出$$\frac{1}{F} = \frac{1}{s} + \frac{1}{s'}.$$薄透镜的横向放大率为$$m = -\frac{s'}{s}.$$对于理想的无损光学系统，总光通量守恒，像平面的照度与横向放大倍率的平方成反比，$$E \propto \frac{1}{|m|^2}.$$对于串联的薄透镜系统，总放大倍数是各个放大倍数的乘积，$$m = m_1 m_2.$$## 推导

 在初始配置中只有镜头$\text{Л}_1$行为。 和$s_1 = 2F$，透镜方程给出$$\frac{1}{F} = \frac{1}{2F} + \frac{1}{s_1'}.$$因此$$\frac{1}{s_1'} = \frac{1}{F} - \frac{1}{2F} = \frac{1}{2F},$$所以像距是$s_1' = 2F$。 

第一透镜的放大倍数为$$m_1 = -\frac{s_1'}{s_1} = -\frac{2F}{2F} = -1.$$初始图像的绝对值具有单位放大倍数，因此参考照度为$E_0$。 

插入发散透镜后$\text{Л}_2$，最终的清晰图像在移动的屏幕上形成$F$相对于原始位置。 原始图像平面位于$2F$从$\text{Л}_1$，因此最终图像位置为$3F$从$\text{Л}_1$。 

设位置为$\text{Л}_2$保持一定距离$x$从$\text{Л}_1$。 产生的中间图像$\text{Л}_1$在$2F$充当虚拟对象$\text{Л}_2$。 物距为$\text{Л}_2$是$s_2 = 2F - x$，像距为$s_2' = 3F - x$。 透镜方程为$\text{Л}_2$是$$\frac{1}{-2F} = \frac{1}{2F - x} + \frac{1}{3F - x}.$$引入无量纲变量$a = x/F$，这变成了$$-\frac{1}{2} = \frac{1}{2-a} + \frac{1}{3-a}.$$结合右边，$$\frac{1}{2-a} + \frac{1}{3-a} = \frac{(3-a)+(2-a)}{(2-a)(3-a)} = \frac{5-2a}{(2-a)(3-a)}.$$因此$$-\frac{1}{2}(2-a)(3-a) = 5-2a.$$扩大，$$(2-a)(3-a) = 6 - 5a + a^2,$$所以$$-\frac{1}{2}(a^2 - 5a + 6) = 5 - 2a.$$乘以$2$给出$$-(a^2 - 5a + 6) = 10 - 4a,$$这导致$$-a^2 + 9a - 16 = 0.$$乘以$-1$,$$a^2 - 9a + 16 = 0.$$物理上允许的根位于$0$和$3$是$$a = \frac{9 - \sqrt{17}}{2}.$$第二透镜的放大倍数为$$m_2 = -\frac{s_2'}{s_2} = -\frac{3F - x}{2F - x}.$$总放大倍数为$$m = m_1 m_2 = (-1)\left(-\frac{3F - x}{2F - x}\right) = \frac{3F - x}{2F - x}.$$替代$x = aF$给出$$|m| = \frac{3 - a}{2 - a}.$$利用照度和放大倍率之间的关系，$$E = E_0 \frac{1}{|m|^2} = E_0 \left(\frac{2-a}{3-a}\right)^2.$$替代$a = \frac{9 - \sqrt{17}}{2}$,$$2 - a = \frac{\sqrt{17} - 5}{2}, \qquad 3 - a = \frac{\sqrt{17} - 3}{2}.$$所以，$$E = E_0 \left(\frac{\sqrt{17} - 5}{\sqrt{17} - 3}\right)^2.$$从数字上看，$$\sqrt{17} \approx 4.123,$$所以$$E \approx E_0 \left(\frac{-0.877}{1.123}\right)^2 \approx 0.61\,E_0.$$＃＃ 结果$$\boxed{E = E_0 \left(\frac{\sqrt{17} - 5}{\sqrt{17} - 3}\right)^2 \approx 0.61\,E_0}$$## 健全性检查

 表达式为$E$仅取决于以 为单位测量的距离的无量纲比率$F$，确保尺寸一致性。 由于两个镜头的焦距相当，因此放大倍率接近一致，这与照度的适度变化是一致的。 

结果$E < E_0$事实上，第二透镜系统将有效横向放大倍数提高到1以上，从而将相同的光通量分布在更大的图像区域上。 最敏感的步骤是确定正确的物理根$x$，因为二次方程允许两个数学解，并且选择镜头和屏幕之间的间隔之外的根将对应于第二镜头相对于形成的图像的非物理放置。
