 ## 问题

 F315。 连接到主电源的螺旋线被电流加热。 螺旋的一半被冷却（例如，用水）。 这将如何影响这半螺旋释放的热量？ 另一半呢？ 通过整个螺旋？ 假设电源电压恒定。 

## 设置和假设

 螺旋线连接到具有电压的理想恒压电源$V$。 螺旋由沿着同一导体串联连接的两个相等的半部分组成，因此在任何时刻都有相同的电流流过两个半部分。 最初，每一半具有相同的电阻$R$在均匀的温度下。 

螺旋的一半被冷却，导致其温度发生变化，从而导致其电阻发生变化。 另一半不直接冷却，仅通过电流变化和可能的自加热而受到影响。 

让冷却的一半标记为 1，另一半标记为 2。冷却后，冷却的一半的电阻变为$R_1 = R(1-\varepsilon)$， 在哪里$\varepsilon$是一个无量纲参数$0<\varepsilon<1$。 另一半的电阻为$R_2 = R$，假设由于重新分布而导致的温度变化在电响应的主阶分析中是次要的。 

假设电流是稳定的，因此忽略热瞬变和电瞬变。 电压源是理想的，因此忽略电源的内阻。 电阻温度系数除了其被编码的影响外并没有明确需要$\varepsilon$。 

感兴趣的量是焦耳热功率$P_1$和$P_2$每半场释放的能量和总能量$P_{\text{tot}}$。 

## 物理原理

 电阻器的欧姆定律$R_{\Sigma}$在恒定施加电压下$V$给出当前$$I = \frac{V}{R_{\Sigma}}.$$对于串联电阻，总电阻为$$R_{\Sigma} = R_1 + R_2.$$电阻器中的焦耳热由下式给出$$P = I^2 R,$$分别应用于承载相同电流的每个段。 

电源提供的总电力为$$P_{\text{tot}} = VI = \frac{V^2}{R_{\Sigma}}.$$## 推导

 冷却前，两半都有电阻$R$，所以总电阻为$$R_{\Sigma 0} = 2R,$$目前是$$I_0 = \frac{V}{2R}.$$每一半的初始功率为$$P_0 = I_0^2 R = \left(\frac{V}{2R}\right)^2 R = \frac{V^2}{4R}.$$冷却后，电阻变为$R_1 = R(1-\varepsilon)$和$R_2 = R$。 总电阻变为$$R_{\Sigma} = R(1-\varepsilon) + R = R(2-\varepsilon).$$新的电流为$$I = \frac{V}{R(2-\varepsilon)}.$$冷却一半释放的功率为$$P_1 = I^2 R_1 = \frac{V^2}{R^2(2-\varepsilon)^2}\,R(1-\varepsilon) = \frac{V^2}{R}\,\frac{1-\varepsilon}{(2-\varepsilon)^2}.$$另一半的功率为$$P_2 = I^2 R_2 = \frac{V^2}{R^2(2-\varepsilon)^2}\,R = \frac{V^2}{R}\,\frac{1}{(2-\varepsilon)^2}.$$总功率为$$P_{\text{tot}} = P_1 + P_2 = \frac{V^2}{R}\,\frac{2-\varepsilon}{(2-\varepsilon)^2} = \frac{V^2}{R(2-\varepsilon)}.$$## 结果

 每一半的初始功率为$$P_0 = \frac{V^2}{4R}.$$冷却一半后，这样$R_1 = R(1-\varepsilon)$尽管$R_2 = R$，权力是$$P_1 = \frac{V^2}{R}\,\frac{1-\varepsilon}{(2-\varepsilon)^2}, \quad P_2 = \frac{V^2}{R}\,\frac{1}{(2-\varepsilon)^2}, \quad P_{\text{tot}} = \frac{V^2}{R(2-\varepsilon)}.$$相对于初始状态，对于小$\varepsilon$一个获得$$P_1 < P_0, \quad P_2 > P_0, \quad P_{\text{tot}} > \frac{V^2}{2R}.$$因此，冷却的一半比以前释放更少的热量，另一半比以前释放更多的热量，螺旋释放的总热量增加。 

## 健全性检查

 尺寸一致性如下：$V^2/R$，其中有单位$\mathrm{W}$自从$\mathrm{V}^2/\Omega = \mathrm{W}$。 每个表达式为$P_1$,$P_2$， 和$P_{\text{tot}}$包含相同的前因子$V^2/R$乘以无量纲函数$\varepsilon$，确保单位正确。 

在极限内$\varepsilon \to 0$，两半变得相同，表达式简化为$$P_1 = P_2 = \frac{V^2}{4R}, \quad P_{\text{tot}} = \frac{V^2}{2R},$$匹配初始均匀温度状态。 

对于小正数$\varepsilon$，扩展$P_2$给出与电流增加成比例的增加，因为该因子$(2-\varepsilon)^{-2}$增长速度超过了电阻变化本身所能补偿的速度。 为了$P_1$，电阻的减少与电流的增加相竞争，并且与$I$使净变化在领先顺序中为负值$\varepsilon$。 

最敏感的点是温度变化和电阻分布之间的耦合：假设$R_2$不变将主要电反馈与冷却部分隔离，而高阶热反馈校正仅影响中的高阶项$\varepsilon$而不改变定性结果。
