 ## 问题

 位于同一高度的两个水平半平面$h$一个在另一个之上，平滑地过渡到彼此，如图 2 所示。在上半平面上，以一定角度$\alpha$向下降方向，一个小块以速度移动$v$。 它如何在下半平面上移动？ Assume that the block does not bounce, i.e. it moves while remaining in contact with the surface of the slope. 忽略摩擦力。

 ## 设置和假设

 一小块质量$m$在由平滑空间过渡连接的两个水平半平面组成的刚性表面上无摩擦地移动。 上半平面位于高度$h$位于下半平面上方。 运动在均匀重力和加速度下发生$g$，垂直向下。 

在上平面上的一点处，块具有速度$v$它的速度形成一个角度$\alpha$下降方向，定义为表面过渡的水平轴。 垂直于该方向的运动分量完全位于水平面内。 

表面光滑，因此反作用力始终垂直于表面，不做功。 块在整个运动过程中保持与表面的连续接触。 忽略空气阻力。 在固定在地球上的惯性参考系中分析运动。 

未知数是下水平半平面上的块的运动速度和方向。 

## 物理原理

 机械能守恒，因为唯一做功的力是重力，这是保守的，并且法向反作用力始终垂直于瞬时位移。 

功能定理的应用形式为$\frac{mv^2}{2} + mgy = \text{const}.$在没有外力分量作用的方向上，相应的速度分量保持恒定。 特别是，如果表面沿水平方向具有平移对称性，则相应的速度分量保持不变。 

下平面上的最终运动是匀速直线运动，因为该表面是水平的并且无摩擦，因此没有切向力作用在那里。 

## 推导

 选择水平坐标系$x$轴沿着表面过渡的下降方向定向，并且$y$在水平面内垂直于它的轴。 初始速度分量是$v_x = v\cos\alpha, \qquad v_y = v\sin\alpha.$表面仅在$x$和垂直的$z$方向，所以它在沿着方向的平移下是不变的$y$。 来自表面的反作用力位于与表面垂直的平面内，因此没有可以改变速度的净分量$y$方向。 运动方程为$y$方向减少为$\frac{dv_y}{dt} = 0,$所以$v_y = v\sin\alpha$整个动议。 

重力仅通过垂直高度的变化来做功$h$到$0$。 动能的增益等于重力势能的损失，$\frac{m v_f^2}{2} = \frac{m v^2}{2} + mgh,$这给出了最终的速度大小$v_f^2 = v^2 + 2gh.$同时，最终速度可以分解为下平面上的分量：$v_f^2 = v_{x,f}^2 + v_{y,f}^2.$自从$v_{y,f} = v\sin\alpha$，沿下降方向的水平分量由能量平衡得出，$v_{x,f}^2 = v_f^2 - v_{y,f}^2 = (v^2 + 2gh) - v^2\sin^2\alpha,$这简化为$v_{x,f}^2 = v^2\cos^2\alpha + 2gh.$取与下降方向运动一致的正根，$v_{x,f} = \sqrt{v^2\cos^2\alpha + 2gh}.$下平面的运动方向由角度决定$\beta$速度与下降方向的关系，定义为$\tan\beta = \frac{v_{y,f}}{v_{x,f}} = \frac{v\sin\alpha}{\sqrt{v^2\cos^2\alpha + 2gh}}.$## 结果

 下半平面上的速度为$v_f = \sqrt{v^2 + 2gh}.$方向由下式给出$\tan\beta = \frac{v\sin\alpha}{\sqrt{v^2\cos^2\alpha + 2gh}}.$如果需要组件形式，$v_{x,f} = \sqrt{v^2\cos^2\alpha + 2gh}, \qquad v_{y,f} = v\sin\alpha.$将物理量代入最终的带单位表达式：$v_f = \sqrt{v^2 + 2gh}\ \text{m/s}.$## 健全性检查

 尺寸一致性遵循，因为这两项都在平方根内$v_f^2$有单位为$\text{m}^2/\text{s}^2$， 自从$gh$有单位$\text{m}^2/\text{s}^2$。 表达式为$v_{x,f}^2$还结合了$v^2\cos^2\alpha$和$2gh$，单位一致。 

在极限内$h \to 0$，速度降低为$v_f \to v$，且方向满足$\tan\beta \to \tan\alpha$，在单个水平面上保留初始运动。 在极限内$\alpha \to 0$，运动完全沿着下降方向，给出$v_f^2 = v^2 + 2gh$没有横向分量，与重力引起的高度下降下的一维加速度一致。 

最敏感的步骤是利用沿横向水平方向的对称性分离速度分量； 在该方向引入任何虚拟的力分量都会错误地改变$v_y$并破坏角度关系。
