 ## 问题

 在水平面上有两根相同的薄壁管，每根质量$m$。 它们的轴平行，半径等于$R$。 最初，其中一根管子处于静止状态，另一根管子滚动，不会滑向第一根管子，直到发生碰撞。 管子的平移速度为$v_0$。 管的平移速度和角速度如何随时间变化（画图）？ 管子与水平面之间的滑动摩擦系数为$k$; 碰撞过程中管子之间的摩擦力可以忽略不计，并且碰撞是完全弹性的。 

第三届全联盟物理奥林匹克竞赛（1969）

 ## 设置和假设

 两个质量相同的薄壁圆柱管$m$和半径$R$在水平粗糙平面上移动。 每根管子与平面之间的动摩擦系数为$k$，法向力等于$mg$，因此最大摩擦力大小为$kmg$。 每根管子都有转动惯量$I = mR^2$绕其对称轴。 

初始时刻管1以平移速度向右移动$v_0$滚动时无滑移，故其角速度满足$\omega_0 = -\frac{v_0}{R}$当逆时针方向取为正值时。 管 2 处于静止状态。 

管子之间的碰撞是中心的，沿着水平方向的中心线发生，是完全弹性的，并且管子之间不产生切向冲量和摩擦力矩。 与摩擦演化的时间尺度相比，碰撞持续时间可以忽略不计，因此速度仅在碰撞时刻瞬时变化。 

未知数是平移速度$v_1(t), v_2(t)$和角速度$\omega_1(t), \omega_2(t)$作为时间的函数，以及它们的定性时间图。 

## 物理原理

 牛顿第二平移定律给出$m a = F_{\text{ext}}$， 在哪里$F_{\text{ext}}$是滑动时的动摩擦力。 

牛顿绕质心旋转的第二定律给出$I \alpha = \tau$， 在哪里$\tau$是作用在接触点处的摩擦力的扭矩。 

对于动摩擦，其大小为$F_f = kmg$，方向与接触点相对于地面的速度相反。 

对于一维相同质量的完美弹性碰撞，平移速度会交换，而角速度保持不变，因为冲击力通过中心线作用，并且不会产生围绕每个管中心的扭矩。 

无滑移滚动条件为$v + \omega R = 0$，碰撞后可能会暂时受到侵犯，导致滑动和动摩擦。 

## 推导

 碰撞前，管 1 滚动且不打滑。 静摩擦力调整以强制执行$v_1 + \omega_1 R = 0$，并且不做功，因此平移运动是均匀的。 因此$v_1(t) = v_0, \qquad \omega_1(t) = -\frac{v_0}{R},$当管 2 保持静止时，$v_2(t) = 0, \qquad \omega_2(t) = 0.$让碰撞适时发生$t = t_c$。 对于相同的质量和完全弹性的中心碰撞，$v_1(t_c^+) = 0, \qquad v_2(t_c^+) = v_0,$当角速度保持不变时，$\omega_1(t_c^+) = -\frac{v_0}{R}, \qquad \omega_2(t_c^+) = 0.$碰撞后，管 1 的平移速度为零，但旋转速度不为零，因此接触点相对于地面以一定速度移动$v_{\text{rel},1} = \omega_1 R = -v_0$，表示滑倒。 摩擦力向右作用，大小为$kmg$。 因此对于管 1，$m \frac{dv_1}{dt} = kmg,$给予$v_1(t) = kgt.$由于底部的摩擦产生逆时针旋转，绕中心的扭矩为正，$I \frac{d\omega_1}{dt} = kmgR,$所以与$I = mR^2$,$\frac{d\omega_1}{dt} = \frac{kg}{R},$因此$\omega_1(t) = -\frac{v_0}{R} + \frac{kg}{R}t.$对于碰撞后的管 2，底部点以速度向右移动$v_0$，因此摩擦力作用于左侧，其大小为$kmg$。 因此，$m \frac{dv_2}{dt} = -kmg,$这产生$v_2(t) = v_0 - kgt.$力矩为负值，$I \frac{d\omega_2}{dt} = -kmgR,$所以$\omega_2(t) = -\frac{kg}{R}t.$对于管 1，接触点的滑移速度为$u_1(t) = v_1(t) + \omega_1(t)R = kgt - v_0 + kgt = 2kgt - v_0,$其改变符号为$t_1 = \frac{v_0}{2kg}.$对于管 2，滑移速度为$u_2(t) = v_2(t) + \omega_2(t)R = v_0 - kgt - kgt = v_0 - 2kgt,$这也会改变符号$t_2 = \frac{v_0}{2kg}.$在$t = t_1 = t_2$，两个管子的摩擦方向都相反。 在此时刻之后，相同的方程以相反的摩擦符号成立，导致对称减速和旋转调整，但关键的定性行为仍然是两个管都经历了分段线性演化$v(t)$和$\omega(t)$单个开关时间由下式确定$v_0/(2kg)$。 

## 结果

 碰撞前$t < t_c$,$v_1(t) = v_0, \qquad \omega_1(t) = -\frac{v_0}{R}, \qquad v_2(t) = 0, \qquad \omega_2(t) = 0.$碰撞时$t = t_c$,$v_1(t_c^+) = 0, \qquad \omega_1(t_c^+) = -\frac{v_0}{R}, \qquad v_2(t_c^+) = v_0, \qquad \omega_2(t_c^+) = 0.$为了$t_c < t < t_c + \frac{v_0}{2kg}$,$v_1(t) = kg(t - t_c), \qquad \omega_1(t) = -\frac{v_0}{R} + \frac{kg}{R}(t - t_c),$

$v_2(t) = v_0 - kg(t - t_c), \qquad \omega_2(t) = -\frac{kg}{R}(t - t_c).$摩擦反转的关键切换时间为$\Delta t = \frac{v_0}{2kg}.$## 健全性检查

 尺寸一致性自始至终保持$kg$有加速度单位，所以$kg,t$有速度单位和$\frac{kg}{R}$有角加速度单位。 

对于具有弹性中心碰撞的相同质量，碰撞在平移过程中守恒动量和动能，与速度交换一致。 

摩擦引起的加速度大小$kg$与质量无关，匹配水平面上的动摩擦行为。 

角加速度标尺$\frac{kg}{R}$正确地与半径成反比，因此较大的管在相同的摩擦力下旋转得更慢。 

滑移速度$u(t)$随时间线性演化并在有限时间内改变符号，从而识别摩擦方向反转的时刻； 扭矩方向上的任何符号错误都会消除该根或错误地移动它，使其成为推导中最敏感的步骤。
