 ## 问题

 有电源的冰箱$W$随着时间的推移$\tau$转身$n$升水，初始温度$t^{\circ}~\text{C}$，变成冰。 在此期间向房间释放了多少热量？ 

## 设置和假设

 该系统由一台在一定时间间隔内运行的冰箱组成$\tau$，消耗电力$W$，以及容器中初始温度下的大量水$t^\circ\text{C}$完全转化为冰。 

水量为$n$升。 水的密度被视为$1,\text{kg/L}$，所以质量是$m = n,\text{kg}$。 

物质的最终状态是冰$0^\circ\text{C}$。 冰箱与周围环境的热交换只能通过冰箱的冷凝器进入室内。 除冰箱引起的热损失外，忽略不计。 水的比热容是$c = 4.2 \times 10^3,\text{J/(kg·K)}$，水的熔化潜热为$L = 3.34 \times 10^5,\text{J/kg}$。 

所需量为总热量$Q_{\text{room}}$在此过程中释放到房间。 

## 物理原理

 冰箱在时间间隔内的热力学第一定律$\tau$给出传递到房间的热量之间的关系$Q_{\text{room}}$，从冷体中提取的热量$Q_{\text{cold}}$，以及工作输入$A$：$Q_{\text{room}} = Q_{\text{cold}} + A.$提供给冰箱的电力功是$A = W\tau.$从水中带走的热量由两个部分组成。 冷却水从$t$到$0^\circ\text{C}$需要$Q_1 = mc\Delta T,$并将水冻结在$0^\circ\text{C}$需要$Q_2 = mL.$因此从水中提取的总热量为$Q_{\text{cold}} = mc t + mL.$## 推导

 The mass of water is expressed through volume as$m = n,\text{kg}$。 

根据温度变化计算冷却过程中带走的热量$\Delta T = t,\text{K}$，因为开尔文增量和摄氏增量相同。 这给出了$Q_1 = n c t.$凝固过程中带走的热量为$Q_2 = n L.$从水中提取的总热量变为$Q_{\text{cold}} = n(ct + L).$随着时间的推移供应给冰箱的电能$\tau$是$A = W\tau.$将这些表达式代入冰箱的能量平衡中，得出$Q_{\text{room}} = n(ct + L) + W\tau.$## 结果

 释放到房间的热量为$Q_{\text{room}} = n(ct + L) + W\tau.$代入数值，$Q_{\text{room}} = n\left(4.2 \times 10^3\,t + 3.34 \times 10^5\right)\,\text{J} + W\tau.$和$n$在$\text{kg}$（或升），$t$在$\text{K}$（或者$^\circ\text{C}$),$W$以瓦为单位，以及$\tau$几秒钟后，结果是$\boxed{Q_{\text{room}} = n\left(4.2 \times 10^3 t + 3.34 \times 10^5\right) + W\tau \;\text{J}}.$## 健全性检查

 维度一致性由每项作为能量得出：$nct$有单位$\text{kg}\cdot\text{J/(kg·K)}\cdot\text{K} = \text{J}$,$nL$有单位$\text{kg}\cdot\text{J/kg} = \text{J}$， 和$W\tau$有单位$\text{W}\cdot\text{s} = \text{J}$。 

在极限内$W \to 0$，释放到房间的热量等于从水中带走的热量，对应于没有电力输入的理想冰箱。 在极限内$t \to 0$，只有潜热起作用，将表达减少到$Q_{\text{room}} = nL + W\tau$，与冷冻已冷却的水一致。 

在热力学平衡中最容易出现符号误差，其中从冷库中除去的热量和输入的功都对传递到房间的热量产生积极的影响； 颠倒任何一项都会违反冰箱循环的能量守恒定律。
