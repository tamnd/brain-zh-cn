 ## 问题

 如果理想气体经历这个过程$ABC$（图1），供给一定量的热量$Q$。 在此过程中向气体提供了多少热量$ADC$？

 ## 设置和假设

 理想气体在相同的初始状态之间经历两个不同的准静态过程$A$和最终状态$C$。 初始状态是$A(V_1,p_1)$最终状态是$C(V_2,p_2)$。 两条路径是$ABC$和$ADC$在一个$pV$图形，形成一个矩形。 

从图中可以看出，各州分别是$A(V_1,p_1), \quad B(V_2,p_1), \quad D(V_1,p_2), \quad C(V_2,p_2),$和$V_2 = 2V_1$和$p_2 = 2p_1$。 

该气体是具有恒定热容的理想气体。 内能仅取决于温度。 热容不需要明确，因为热量的差异将通过状态函数消除。 

沿途提供的热量$ABC$给出为$Q$。 任务是确定沿$ADC$。 

## 物理原理

 热力学第一定律写为$Q = \Delta U + W,$在哪里$Q$是提供给气体的热量，$\Delta U$是内能的变化，并且$W$是气体所做的功。 

对于理想气体，内能仅取决于温度，因此$\Delta U$仅取决于初始状态和最终状态，与路径无关。 

沿准静态过程进行的工作$pV$图表是$W = \int p \, dV.$沿着等容过程，$dV = 0$， 所以$W = 0$。 沿着等压过程，$W = p \Delta V$。 

对于单原子理想气体，$U = \frac{3}{2}nRT = \frac{3}{2}pV,$所以状态之间的内能变化$A$和$C$是$\Delta U = \frac{3}{2}(p_C V_C - p_A V_A).$## 推导

 沿着小路$ABC$, 段$AB$在压力下是等压的$p_1$音量从$V_1$到$V_2$。 工作是$W_{AB} = p_1(V_2 - V_1).$该段$BC$是等容的，因此$W_{BC} = 0.$总工作量$ABC$是$W_{ABC} = p_1(V_2 - V_1).$沿途提供的热量$ABC$给出为$Q = \Delta U + p_1(V_2 - V_1).$沿着小路$ADC$, 段$AD$是等容的，所以$W_{AD} = 0.$该段$DC$在压力下是等压的$p_2$， 所以$W_{DC} = p_2(V_2 - V_1).$总工作量$ADC$是$W_{ADC} = p_2(V_2 - V_1).$沿途提供的热量$ADC$是$Q_{ADC} = \Delta U + p_2(V_2 - V_1).$减去表达式$Q$和$Q_{ADC}$消除$\Delta U$：$Q_{ADC} - Q = (p_2 - p_1)(V_2 - V_1).$替代$V_2 = 2V_1$和$p_2 = 2p_1$给出$V_2 - V_1 = V_1,$

$p_2 - p_1 = p_1.$因此，$Q_{ADC} - Q = p_1 V_1,$所以$Q_{ADC} = Q + p_1 V_1.$表达$p_1 V_1$按照$Q$，我们使用表达式$Q$就状态变量而言。 首先计算$\Delta U$：$\Delta U = \frac{3}{2}(p_2V_2 - p_1V_1).$和$p_2 = 2p_1$和$V_2 = 2V_1$,$p_2V_2 = 4p_1V_1,$所以$\Delta U = \frac{3}{2}(4p_1V_1 - p_1V_1) = \frac{3}{2}\cdot 3p_1V_1 = \frac{9}{2}p_1V_1.$然后$Q = \frac{9}{2}p_1V_1 + p_1V_1 = \frac{11}{2}p_1V_1.$解决$p_1V_1$给出$p_1V_1 = \frac{2}{11}Q.$代入$Q_{ADC}$产量$Q_{ADC} = Q + \frac{2}{11}Q = \frac{13}{11}Q.$＃＃ 结果$Q_{ADC} = \frac{13}{11}Q.$替换给定值$Q$（以焦耳为单位），$Q_{ADC} = \frac{13}{11}Q \;\text{J}.$## 健全性检查

 该表达式仅取决于压力和体积的比率，这与两个过程连接相同端点的事实一致，因此$\Delta U$取消差异。 结果是量纲一致的，因为它是无量纲因子相乘$Q$。 

如果$p_2 \to p_1$，矩形垂直折叠并且两条路径在工作中重合，给出$Q_{ADC} \to Q$，与公式一致，因为$\frac{13}{11} \to 1$与此限制无关，因为假设的几何形状$p_2=2p_1$对于推导至关重要。 

符号错误最容易出现在工作术语中，因为反转$V_2 - V_1$或者交换高压和低压分支会改变校正项$p_1V_1$这决定了最终的比例。
