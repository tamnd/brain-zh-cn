 ## 问题

 发光点位于主光轴上一定距离处$d=40~\text{см}$来自具有焦距的发散透镜$F=10~\text{см}$。 该点移动了一段距离$h=5~\text{см}$在垂直于主光轴的平面中。 镜头应向什么方向移动多少距离，以使发光点的图像返回到其原始位置？ 

列宁格勒市物理奥林匹克竞赛（1979 年）

 ## 设置和假设

 具有焦距的薄型发散透镜$F = -10~\text{cm}$在空间中是固定的，并且发光点源最初位于主光轴上一定距离处$d = 40~\text{cm}$从镜头。 透镜形成的图像位于由高斯成像确定的轴上的某个点。 

然后光源垂直于光轴移动一段距离$h = 5~\text{cm}$在垂直于轴线的平面内。 随后透镜垂直于轴平移未知距离$x$，同时保持与自身平行。 所需条件是位移源的图像返回到与未变形配置相对应的原始图像位置。 

假定透镜很薄、无像差并且服从近轴光学。 所有位移都足够小，可以应用线性射线光学，并且横向位移在一阶近似内处理。 

## 物理原理

 高斯透镜公式将镜头测量到的物距和像距联系起来，$$\frac{1}{F} = \frac{1}{v} + \frac{1}{u}.$$对于近轴光线，横向放大率由下式给出$$m = \frac{y'}{y} = \frac{v}{u},$$在哪里$y$和$y'$是在镜头参考系中测量的物体和图像的横向坐标。 

透镜的刚性横向位移$x$改变镜头框架中物体和图像的坐标，同时保持主轴方向在空间中固定。 叠加适用于小的横向位移，因此物体位移和镜头平移的贡献在图像坐标中线性相加。 

## 推导

 由透镜公式求得图像的初始轴向位置。 和$F = -10~\text{cm}$和$u = 40~\text{cm}$,$$\frac{1}{-10~\text{cm}} = \frac{1}{v} + \frac{1}{40~\text{cm}}.$$这给出了$$-0.1~\text{cm}^{-1} = \frac{1}{v} + 0.025~\text{cm}^{-1},$$所以$$\frac{1}{v} = -0.125~\text{cm}^{-1},$$因此$$v = -8~\text{cm}.$$因此横向放大倍数为$$m = \frac{v}{u} = \frac{-8~\text{cm}}{40~\text{cm}} = -0.2.$$当物体横向移动$h$，镜头最初未移动，因此图像相对于轴的位移为$$y'_{(h)} = m h = (-0.2)(5~\text{cm}) = -1~\text{cm}.$$现在镜头横向平移$x$。 在镜头框架中，物体获得额外的表观位移$-x$，因此镜头平移会导致图像偏移$m(-x)$在镜头框内。 返回实验室框架增加了刚性平移$x$，给出净贡献$$y'_{(x)} = x + m(-x) = x(1 - m).$$通过独立横向位移的线性叠加，总图像位移为$$y' = m h + x(1 - m).$$像回到原来的轴向位置的条件是$y' = 0$， 因此$$m h + x(1 - m) = 0.$$解决$x$给出$$x = -\frac{m h}{1 - m}.$$替代$m = -0.2$和$h = 5~\text{cm}$,$$x = -\frac{(-0.2)(5~\text{cm})}{1 - (-0.2)}.$$这产生$$x = \frac{1~\text{cm}}{1.2} = 0.833~\text{cm}.$$## 结果

 The required lens displacement is$$x = 0.833~\text{cm} \approx 8.3~\text{mm}.$$透镜必须沿与光源横向位移相同的方向移动。 

## 健全性检查

 表达式$x = -\frac{m h}{1 - m}$具有长度尺寸，因为$m$是无量纲的并且$h$带有长度单位，确保尺寸一致性。 

对于发散透镜来说，$m$为负，因此位移物体的图像与物体位移相反地移动，与$y'_{(h)} = -1~\text{cm}$为了$h = 5~\text{cm}$。 The required lens motion is smaller than the object displacement because the factor$1 - m = 1.2$降低镜头平移对图像位置的有效性。 

在极限情况下$m \to 0$，对应于非常弱的成像系统，公式给出$x \to 0$，因为图像对物体位移不敏感。 在相反的极限$m \to 1$，对应于单位放大倍数，分母趋于零，表明仅靠镜头平移无法补偿物体位移，与刚性图像传输的几何形状一致。
