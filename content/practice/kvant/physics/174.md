 ## 问题

 _它被错误地发表在编号为 164 的期刊上。_


 求理想气体在一定过程中的热容，其中气体的温度

 1. 与其体积的平方成正比；
 2. 与体积成反比。 

I.Sh. 斯洛博杰茨基

 ## 设置和假设

 理想气体含有$n$摩尔经历准静态过程，其中压力、体积和温度始终由状态方程明确定义和关联$pV=nRT$。 任务是确定过程中的热容量，定义为$$C=\frac{\delta Q}{dT},$$对于温度之间的两个不同的函数依赖性$T$和体积$V$。 定体积摩尔热容$C_V$和气体常数$R$被视为常量。 假设该过程是可逆的，因此热力学微分是适用的。 

## 物理原理

 准静态过程的热力学第一定律写为$$\delta Q = dU + p\,dV.$$对于理想气体，内能仅取决于温度并满足$$dU = n C_V dT.$$状态方程为$$p = \frac{nRT}{V}.$$过程中的热容量定义为$$C = \frac{\delta Q}{dT}.$$## 推导

 将第一定律与内能表达式相结合，得出$$\delta Q = nC_V dT + p\,dV.$$除以$dT$产量$$C = nC_V + p\frac{dV}{dT}.$$代入理想气体压力，$$C = nC_V + \frac{nRT}{V}\frac{dV}{dT}.$$### 案例 1：$T \propto V^2$让$$T = kV^2,$$在哪里$k$是一个常数。 微分给出$$\frac{dT}{dV} = 2kV.$$表达$k$通过$T$， 自从$k = T/V^2$，产量$$\frac{dT}{dV} = 2\frac{T}{V}.$$因此，$$\frac{dV}{dT} = \frac{V}{2T}.$$代入热容表达式可得$$C = nC_V + \frac{nRT}{V}\cdot \frac{V}{2T}.$$取消$V$和$T$导致$$C = nC_V + \frac{nR}{2}.$$### 案例 2：$T \propto \frac{1}{V}$让$$T = \frac{k}{V}.$$分化产量$$\frac{dT}{dV} = -\frac{k}{V^2}.$$使用$k = TV$，导数变为$$\frac{dT}{dV} = -\frac{T}{V}.$$因此，$$\frac{dV}{dT} = -\frac{V}{T}.$$代入一般表达式可得$$C = nC_V + \frac{nRT}{V}\left(-\frac{V}{T}\right).$$取消$V$和$T$产量$$C = nC_V - nR.$$## 结果

 对于过程$T \propto V^2$,$$C_1 = nC_V + \frac{nR}{2} = n\left(C_V + \frac{R}{2}\right).$$对于过程$T \propto \frac{1}{V}$,$$C_2 = nC_V - nR = n\left(C_V - R\right).$$如果用每摩尔来表示，$$\boxed{C_1 = C_V + \frac{R}{2}}, \qquad \boxed{C_2 = C_V - R}.$$## 健全性检查

 尺寸一致性自始至终保持$C_V$和$R$两者的单位都是$\mathrm{J,mol^{-1},K^{-1}}$，使得每一项都在$C$同质。 

在第一种情况下，额外捐款$\frac{R}{2}$为正，对应于膨胀所做的功，增加了单位温度变化所需的热量。 

在第二种情况下，术语$-R$降低了热容，并且该过程可以产生负的每摩尔总热容，如果$C_V < R$，这与压缩伴随加热的过程是一致的，以至于必须提取热量来升高温度。 

最敏感的步骤是转换$dT/dV$进入$dV/dT$，其中符号错误会反转第二种情况下膨胀与压缩贡献的物理解释。
