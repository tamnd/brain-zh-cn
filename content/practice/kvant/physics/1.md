 ## 问题

 ![](//www.kvant.digital/media/1970-01-053-02.png?_v=1)

 三个充满水的连通容器，其中心距离相等$a$彼此分开，被相同材料制成的相同厚度的活塞覆盖（图3）。 相同的垂直活塞杆连接到活塞，活塞铰接到杆上$AB$。 如果杆和活塞杆的质量与活塞和重物的质量相比可以忽略不计，则可以在杆上的什么位置连接重物，以便在平衡时使杆保持水平？ 血管的直径如图所示。 

## 设置和假设

 三个相同的连通容器含有一定密度的水$\rho$在均匀引力场中$g$。 自由表面向大气开放，因此深度处的静水压力$h$表面以下是$p = p_0 + \rho g h$。 每个容器都由厚度相同的垂直活塞封闭$t$由密度均匀的材料制成$\rho_m$，具有圆形横截面积$S_i$为$i$第-个活塞，$i = 1,2,3$。 活塞通过相同的无质量刚性杆连接到单个刚性水平杆$AB$，与活塞和附加重量相比，其质量可以忽略不计$W$。 

三个容器的中心位于一个平面上并且两两相隔相同的距离$a$，所以它们的水平投影形成一个等边三角形。 活塞杆与杆的连接点$AB$是固定的并且具有已知的位置向量$\mathbf{r}_1, \mathbf{r}_2, \mathbf{r}_3$从选定的原点沿杆测量$AB$。 重量级$W$附着在坐标未知的点上$x$沿着同一个杆。 杆保持静态平衡并保持水平，这意味着在通过活塞和重量传递的所有垂直力下达到旋转平衡。 

所有杆均假定为无质量，因此只有活塞重量和外部重量会对扭矩产生影响。 忽略铰链中的摩擦力，所有运动约束都强制执行纯粹的垂直力传递。 

## 物理原理

 连接液体中的流体静力平衡在所有容器的相同深度处建立相等的压力，因此在相同的参考水平测量时，每个容器中活塞底部的压力是相同的。 

流体对活塞施加的力$i$由活塞区域上积分的压力给出，在均匀压力下，该压力减小为$F_i = p S_i.$活塞处于垂直机械平衡状态，因此每个活塞都会将此力无损失地传递到连杆。 

杆的静态旋转平衡要求杆上任意点的总扭矩消失，$\sum \tau = 0,$其中垂直力的扭矩$F$应用于坐标$x$相对于参考点是$F x$当所有力平行时为标量形式。 

因此，平衡条件是向上的活塞力产生的扭矩与向下的重量产生的扭矩之间的平衡$W$。 

## 推导

 所有三个容器中活塞水平处的静水压力是相同的，因为容器是连通的并且自由表面处于相同的大气压力。 将活塞水平处的公共压力表示为$p$，每个活塞传递到杆的力是$F_i = p S_i.$作用在杆上的总向上力是活塞力的总和，$F_{\text{tot}} = p(S_1 + S_2 + S_3).$对于杆绕原点的旋转平衡$AB$，所有垂直力的力矩总和必须消失。 在用于定义坐标的同一参考点处选择原点$x_i$，扭矩平衡条件为$p S_1 x_1 + p S_2 x_2 + p S_3 x_3 = W x,$在哪里$x$是附加重量的坐标。 

共同的压力因子从关系中抵消，$S_1 x_1 + S_2 x_2 + S_3 x_3 = \frac{W}{p} x.$求解配重产量的附着位置$x = \frac{p}{W}\left(S_1 x_1 + S_2 x_2 + S_3 x_3\right).$为了消除压力$p$，使用处于平衡状态的杆的垂直力平衡。 杆没有质量，因此总的向上活塞力等于重量，$W = p(S_1 + S_2 + S_3).$将此关系代入表达式$x$给出$x = \frac{S_1 x_1 + S_2 x_2 + S_3 x_3}{S_1 + S_2 + S_3}.$该结果表明，所需的附着点是沿杆的三个活塞动作的力中心，完全由活塞面积及其几何位置决定。 

## 结果

 必须附加重物的点的坐标是$x = \frac{S_1 x_1 + S_2 x_2 + S_3 x_3}{S_1 + S_2 + S_3}.$如果活塞的直径是$d_1, d_2, d_3$， 然后$S_i = \frac{\pi d_i^2}{4}$，结果就变成了$x = \frac{d_1^2 x_1 + d_2^2 x_2 + d_3^2 x_3}{d_1^2 + d_2^2 + d_3^2}.$所有长度均以米为单位测量，因此最终答案的单位为米，$\boxed{x \; \text{[m]}}.$## 健全性检查

 表达式为$x$是位置的加权平均值，因此它必须位于$x_1, x_2, x_3$，这符合合力作用在由活塞附着点跨越的杆段内的要求。 

尺寸一致性如下，因为每一项$S_i x_i$有单位$\text{m}^2 \cdot \text{m} = \text{m}^3$，并除以$S_1 + S_2 + S_3$返回米，确保坐标具有正确的长度尺寸。 

例如，在一个活塞面积占主导地位的极限情况下$S_1 \gg S_2, S_3$，结果减少为$x \to x_1$，这意味着重量必须直接附加在主要活塞力之上，这与由单个大贡献控制的扭矩平衡一致。 

扭矩平衡方程中很可能会出现符号误差，因为反转活塞力或重量的方向会错误地将加权平均值移到物理上有意义的连接点间隔之外。
