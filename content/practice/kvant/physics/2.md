 ## 问题

 在水平面上有两个有质量的球$m_1$和$m_2$，通过具有刚度的弹簧连接$c$。 飞机是无摩擦的。 球发生位移，压缩弹簧，然后同时释放。 确定球的振动周期。 

## 设置和假设

 两点质量$m_1$和$m_2$，单位为千克，位于水平无摩擦平面上，由具有刚度的轻弹簧连接$c$测量于$\mathrm{N,m^{-1}}$。 弹簧的自然长度表示为$\ell_0$以米为单位。 运动被限制在沿着质量连接线的一维。 

弹簧被压缩后，系统从静止状态释放，因此两个质量的初始速度均为零。 假设弹簧是理想的，在所有变形下都遵循胡克定律，并且与$m_1$和$m_2$。 系统上没有外部水平力作用，因此质心均匀移动。 

未知量是每个质量围绕平衡配置的振荡周期。 

## 物理原理

 牛顿第二定律适用于以下形式的每个质量$m_1 \ddot{x}_1 = F_1, \qquad m_2 \ddot{x}_2 = F_2,$在哪里$x_1(t)$和$x_2(t)$是群众的坐标。 

弹簧力遵循胡克定律，$F = -c(\Delta \ell),$在哪里$\Delta \ell = (x_2 - x_1 - \ell_0)$是与自然长度的偏差。 

质心坐标定义为$X = \frac{m_1 x_1 + m_2 x_2}{m_1 + m_2},$并且在没有外力的情况下满足$\ddot{X} = 0$。 

使用减少质量公式来描述相对运动，$\mu = \frac{m_1 m_2}{m_1 + m_2},$它将二体相互作用转化为等效的一体振荡问题。 

## 推导

 两个质量的运动方程为$m_1 \ddot{x}_1 = c(x_2 - x_1 - \ell_0),$

$m_2 \ddot{x}_2 = -c(x_2 - x_1 - \ell_0).$从第二个方程中减去第一个方程就消除了质心运动。 引入相对坐标$y = x_2 - x_1 - \ell_0,$它的二阶导数是$\ddot{y} = \ddot{x}_2 - \ddot{x}_1.$使用运动方程，$\ddot{y} = -\frac{c}{m_2}(x_2 - x_1 - \ell_0) - \frac{c}{m_1}(x_2 - x_1 - \ell_0),$这变成$\ddot{y} = -c\left(\frac{1}{m_1} + \frac{1}{m_2}\right)y.$使用减少的质量重写系数，$\frac{1}{\mu} = \frac{1}{m_1} + \frac{1}{m_2},$所以运动方程采用标准调和形式$\ddot{y} + \frac{c}{\mu} y = 0.$角频率为$\omega = \sqrt{\frac{c}{\mu}} = \sqrt{c\left(\frac{1}{m_1} + \frac{1}{m_2}\right)}.$振荡周期为$T = \frac{2\pi}{\omega} = 2\pi \sqrt{\frac{\mu}{c}}.$两个质量都以相同的角频率执行谐振运动，因为每个坐标都是质量中心运动（均匀）和相对振荡（谐振）的线性组合。 

## 结果

 减少的质量是$\mu = \frac{m_1 m_2}{m_1 + m_2} \ \mathrm{kg}.$每个质量的振荡周期为$T = 2\pi \sqrt{\frac{m_1 m_2}{(m_1 + m_2)c}} \ \mathrm{s}.$因此，$\boxed{T_1 = T_2 = 2\pi \sqrt{\frac{m_1 m_2}{(m_1 + m_2)c}} \ \mathrm{s}}.$## 健全性检查

 该表达式具有时间维度，因为$c$有单位$\mathrm{N,m^{-1}} = \mathrm{kg,s^{-2}}$， 所以$\mu/c$有单位$\mathrm{s^2}$它的平方根有单位$\mathrm{s}$。 

在极限内$m_1 \gg m_2$，减少的质量变为$\mu \approx m_2$，周期缩短为$T \approx 2\pi \sqrt{m_2/c}$，对应于较轻的质量相对于较重的质量提供的有效固定支撑振荡。 

在对称情况下$m_1 = m_2 = m$，减少的质量变为$\mu = m/2$, 给予$T = 2\pi \sqrt{m/(2c)}$，由于两个质量共享惯性，该周期比单质量弹簧周期短。 

在形成相对坐标方程时，很可能会出现符号错误，其中两个质量的恢复力必须以相反的符号输入； 这会错误地改变有效弹簧项的符号并破坏振荡解。
