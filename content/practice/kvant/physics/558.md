 ## 问题

 F558。 一个小重球通过一个开口进入一个相同质量的光滑球体，并经过一定距离$R/2$从球体中心（$R$是球体的半径）。 球进入后，开口自动关闭。 假设球和球体之间的碰撞是完全弹性的，请在球体最初静止的参考系中找到球和球体中心的轨迹。 确定这些轨迹的参数并在其上标记发生碰撞的点。 

## 设置和假设

 一个小而重的质量球$m$进入半径为 的空心光滑球壳$R$和质量$m$。 壳最初在惯性参考系中静止。 球通过一个孔进入，该孔随后关闭，因此球保留在壳内。 

球的初速度表示为$\mathbf v_0$，幅度$v_0$。 传入轨迹经过一段距离$$b=\frac{R}{2}$$从壳的中心。 

外壳非常光滑，球与内表面之间的每一次碰撞都具有完美的弹性。 外部力量被忽略。 重力被忽略。 外壳是坚硬的。 

未知数是球的轨迹和壳在最初静止的框架中的中心轨迹，以及所有碰撞点的位置。 

由于群众是平等的，$$M=m.$$## 物理原理

 该系统仅由球和壳体组成。 由于系统没有受到外力作用，$$\mathbf P=\text{const},$$在哪里$\mathbf P$是总动量。 

碰撞期间，力沿着球面的法线作用。 法线穿过球体的中心。 

对于完美弹性碰撞，碰撞体的相对速度会反转其法向分量，同时保持其大小。 由于碰撞是中心的并且质量相等，因此相对速度的法向分量在物体之间交换。 

可以方便地描述质心坐标系的运动。 在该框架中，质心均匀移动，相对运动相当于点质点在固定球腔中的运动，且具有来自壁的镜面反射。 

对于球形反射器，入射角等于反射角。 

## 推导

 最初，壳处于静止状态，球具有速度$\mathbf v_0$。 质心速度为$$\mathbf V_{\rm cm} = \frac{m\mathbf v_0+m\cdot0}{2m} = \frac{\mathbf v_0}{2}.$$球相对于质心的速度为$$\mathbf u = \mathbf v_0-\mathbf V_{\rm cm} = \frac{\mathbf v_0}{2}.$$壳中心在质心坐标系中以速度移动$$-\frac{\mathbf v_0}{2}.$$考虑球相对于壳中心的相对运动。 相对速度为$$\mathbf v_{\rm rel} = \mathbf v_0.$$因此，在第一次碰撞之前，相对轨迹是球体的直弦，其碰撞参数为$$b=\frac R2.$$连续反射之间的弦长为$$\ell = 2\sqrt{R^2-b^2} = 2\sqrt{R^2-\frac{R^2}{4}} = \sqrt3\,R.$$让$\alpha$是绘制到碰撞点的半径与入射光线之间的角度。 然后$$\sin\alpha = \frac bR = \frac12,$$因此$$\alpha=30^\circ.$$弦与切平面之间的角度为$$90^\circ-\alpha=60^\circ.$$反射后，光线与法线形成相同的角度。 由于球体是完全对称的，因此反射弦具有相同的距离$b$从中心。 

设第一个碰撞点为$A$。 反射光线到达第二个碰撞点$B$。 连续碰撞点之间的圆心角是从具有距离的弦的几何形状获得的$R/2$从中心：$$\cos\frac{\Delta\varphi}{2} = \frac bR = \frac12.$$所以$$\frac{\Delta\varphi}{2}=60^\circ, \qquad \Delta\varphi=120^\circ.$$因此，每个碰撞点都是通过前一个碰撞点的旋转获得的$120^\circ$绕垂直于运动平面的轴。 

经过这样三个步骤后，$$3\Delta\varphi = 360^\circ,$$所以第四次碰撞与第一次碰撞重合：$$A\to B\to C\to A\to\cdots$$碰撞点形成一个内切于运动平面内大圆的等边三角形。 

连续碰撞之间的时间为$$\tau = \frac{\ell}{v_{\rm rel}} = \frac{\sqrt3\,R}{v_0}.$$在质心坐标系中，相对轨迹是连接该等边三角形顶点的周期性折线。 

现在回到实验室框架，壳最初处于静止状态。 

质心作匀速运动$$\mathbf V_{\rm cm} = \frac{\mathbf v_0}{2}.$$在质心坐标系中，壳中心沿直线作速度运动$-\mathbf v_0/2$。 改造回实验室框架，$$\mathbf r_{\rm shell}(t) = \mathbf V_{\rm cm}t - \frac{\mathbf v_0}{2}t = 0.$$因此，壳的中心始终保持固定在其原始位置。 

为了球，$$\mathbf r_{\rm ball}(t) = \mathbf r_{\rm shell}(t) + \mathbf r_{\rm rel}(t) = \mathbf r_{\rm rel}(t),$$因为壳中心是静止的。 

因此，球沿着上述相同的周期性折线轨迹移动：连续的直线段是长度的弦$\sqrt3,R$，反射发生在三个顶点$A$,$B$， 和$C$的内接等边三角形。 

## 结果

 质心速度为$$V_{\rm cm}=\frac{v_0}{2}.$$球体内部的相对轨迹是在壁上镜面反射的直弦。 自从$$b=\frac R2,$$连续碰撞点之间的距离是$$\ell=\sqrt3\,R.$$连续碰撞点之间的圆心角为$$\Delta\varphi=120^\circ.$$因此，碰撞点是运动圆内接的等边三角形的三个顶点。 碰撞的顺序是$$A\rightarrow B\rightarrow C\rightarrow A\rightarrow\cdots.$$碰撞之间的时间是$$\tau=\frac{\sqrt3\,R}{v_0}.$$壳中心在给定参考系中保持静止：$$\boxed{\mathbf r_{\rm shell}(t)=\text{const}}.$$球沿着内接等边三角形的边周期性地移动，并在其三个顶点处依次反射：$$\boxed{\Delta\varphi=120^\circ,\qquad \ell=\sqrt3\,R,\qquad \tau=\frac{\sqrt3\,R}{v_0}}.$$## 健全性检查

 尺寸一致。 弦长$\ell$有长度单位和碰撞间隔$\tau=\ell/v_0$有时间单位。 

如果冲击参数接近零，弦将变成直径，并且粒子将沿着穿过中心的单直线振荡。 目前的结果有所不同，因为$b=R/2$产生一个非平凡的多边形轨道。 

关系$$\cos\frac{\Delta\varphi}{2}=\frac bR$$给出$\Delta\varphi=120^\circ$什么时候$b=R/2$，并且三个这样的角度恰好填充$360^\circ$。 这证实了三次反射后的周期性。 

最容易出错的步骤是确定碰撞点之间的提前角。 使用$\sin(\Delta\varphi/2)=b/R$而不是正确的关系$\cos(\Delta\varphi/2)=b/R$会导致不正确的多边形和不正确的碰撞序列。
