 ## 问题

 有两个焦距相等的镜头系统。 透镜的光轴重合（图 1）。 第一个系统由会聚透镜组成； 在第二个系统中，会聚透镜与发散透镜交替。 如果透镜之间的距离远小于焦距，请找出每个系统中光线的轨迹。

 ## 设置和假设

 考虑两个一维近轴光学系统，均由具有相同焦距大小的薄透镜组成$f$以米为单位测量。 所有透镜的光轴重合，以小角度近轴近似描述光线传播$\theta$相对于轴线和横向位移$x$从它。 

在第一个系统中，所有透镜都以焦距会聚$f>0$，相隔一段距离$d$令人满意$d \ll f$。 在第二个系统中，具有焦距的会聚透镜$+f$与不同焦距的发散透镜交替使用$-f$，再次分开相同的距离$d \ll f$。 

每个透镜都被视为无限薄，因此折射会在透镜平面上瞬间发生。 透镜之间的自由空间传播被视为匀速直线运动。 仅一阶项$d/f$被保留，与近轴和弱单元限制一致。 

未知的是射线轨迹的函数形式$x(z)$沿光轴坐标$z$对于两个系统。 

## 物理原理

 自由空间中的近轴射线传播遵循线性关系$$\frac{dx}{dz} = \theta,$$在哪里$\theta$是光线角度。 

焦距较薄的镜头$f$产生斜率的瞬时变化，由下式给出$$\Delta \theta = -\frac{x}{f},$$与符号约定$f>0$对应于会聚透镜并且$f<0$到发散透镜。 

经过一个小的传播步骤$d$，每单位长度的角度变化可以在连续极限中写为$$\frac{d\theta}{dz} = \lim_{d \to 0} \frac{\Delta \theta}{d}.$$结合这些关系可得出射线轨迹的二阶微分方程，$$\frac{d^2 x}{dz^2} = \frac{d\theta}{dz}.$$## 推导

 在第一个系统中，每个长度间隔$d$包含一个会聚透镜。 在这样的时间间隔内，斜率变化为$$\Delta \theta = -\frac{x}{f}.$$按时期划分$d$给出沿轴的角度有效变化率，$$\frac{d\theta}{dz} = -\frac{x}{f d}.$$使用$\frac{dx}{dz}=\theta$，关于微分$z$产量$$\frac{d^2 x}{dz^2} = -\frac{x}{f d}.$$该方程具有线性谐振子的形式，其中角空间频率平方$\omega^2 = \frac{1}{f d}$。 

在第二个系统中，每个周期由一个会聚透镜和一个发散透镜组成，每个透镜间隔一定距离$d$具有相同的阶数并且都在近轴状态下运行。 会聚透镜产生$$\Delta \theta_1 = -\frac{x}{f},$$当发散透镜产生$$\Delta \theta_2 = -\frac{x}{-f} = +\frac{x}{f}.$$一对完整的角度总变化为$$\Delta \theta_{\text{pair}} = -\frac{x}{f} + \frac{x}{f} = 0.$$每单位长度的净角度变化在相同的连续体近似中消失，$$\frac{d\theta}{dz} = 0,$$所以轨迹方程变为$$\frac{d^2 x}{dz^2} = 0.$$## 结果

 对于第一个系统，射线轨迹满足$$\frac{d^2 x}{dz^2} + \frac{1}{f d} x = 0,$$与一般解决方案$$x(z) = A \cos\!\left(\frac{z}{\sqrt{f d}}\right) + B \sin\!\left(\frac{z}{\sqrt{f d}}\right).$$这里$f$和$d$以米为单位测量，所以$\sqrt{f d}$单位为米，三角函数的参数是无量纲的。 

对于第二个系统，轨迹满足$$\frac{d^2 x}{dz^2} = 0,$$与一般解决方案$$x(z) = A z + B,$$在哪里$A$是一个无量纲角度并且$B$单位为米。 

## 健全性检查

 第一个系统的方程包含因子$\frac{1}{f d}$有单位$\mathrm{m^{-2}}$，与二阶导数一致$\frac{d^2 x}{dz^2}$其中也有单位$\mathrm{m^{-1}}$每导数$z$, 给予$\mathrm{m^{-2}}$全面的。 

在极限内$d \to \infty$有固定的$f$, 聚焦强度$\frac{1}{f d}$趋于零，将第一个系统减少为直线传播，与具有可忽略累积效应的孤立透镜一致。 

在第二个系统中，镜头光焦度的抵消依赖于相等的幅度$|f|$; 任何不匹配都会引入与以下比例成比例的剩余项$\frac{1}{f_1} + \frac{1}{f_2}$，这将恢复弱聚焦。 对符号错误最敏感的步骤是发散透镜关系$\Delta \theta = -x/f$， 在哪里$f<0$必须在执行代数取消之前插入。
