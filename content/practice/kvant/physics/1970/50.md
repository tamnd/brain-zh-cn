 ## 问题

 F50。 在光滑的水平桌子上放置两个相同质量的立方体$m$，通过刚度弹簧连接$k$和长度$l_0$处于未拉伸状态。 恒定的力$F$大小和方向均恒定的 突然开始作用于左侧立方体（图 1）。 找到最小和最大距离

 图1.光滑水平桌面上的两个相同的立方体通过弹簧连接； 水平力$F$指向右侧的方向应用于左侧的立方体。 

## 设置和假设

 该系统由两个相同的立方体组成，每个立方体的质量$m$，放置在光滑的水平桌子上。 它们通过理想的刚度弹簧连接$k$和自然长度$l_0$。 恒定的水平力$F$在某个时间开始作用于左边的立方体$t=0$，指向右侧。 感兴趣的数量是立方体之间的间隔作为时间的函数，特别是其最小值和最大值。 

假设桌子是无摩擦的，弹簧在所有变形下都遵循胡克定律，并且运动是纯粹水平的，因此垂直力不会影响动力学。 附在桌子上的参考系是惯性的，并且空气阻力被忽略。 

## 物理原理

 牛顿第二定律分别适用于每个立方体。 左边的立方体满足$m x_1'' = F - k(x_1 - x_2 - l_0),$而右边的立方体满足$m x_2'' = k(x_1 - x_2 - l_0).$弹簧的相对变形被引入为$\xi = x_1 - x_2 - l_0.$两个方程相减得出$m(x_1'' - x_2'') = F - 2k\xi,$这导致运动方程$\xi'' + \frac{2k}{m}\xi = \frac{F}{m}.$这是具有角频率的受迫谐振子$\omega = \sqrt{\frac{2k}{m}}.$通用解决方案的形式为$\xi(t) = \frac{F}{2k} + A\cos(\omega t) + B\sin(\omega t).$质心运动满足$X_{\mathrm{cm}} = \frac{x_1 + x_2}{2}, \quad X_{\mathrm{cm}}'' = \frac{F}{2m},$但该坐标不影响分离的相对极值，该极值完全由下式确定$\xi(t)$。 

## 推导

 初始配置对应于两个立方体都处于静止状态的未拉伸弹簧。 因此初始条件是$\xi(0) = 0, \quad \xi'(0) = 0.$将通解代入条件$t=0$给出$0 = \frac{F}{2k} + A,$这决定了$A = -\frac{F}{2k}.$差异化$\xi(t)$产量$\xi'(t) = -A\omega \sin(\omega t) + B\omega \cos(\omega t).$正在申请$\xi'(0)=0$给出$0 = B\omega,$所以$B = 0.$相对变形变为$\xi(t) = \frac{F}{2k} - \frac{F}{2k}\cos(\omega t) = \frac{F}{2k}\bigl(1 - \cos(\omega t)\bigr).$自从$\cos(\omega t)$之间变化$-1$和$1$, 因子$1 - \cos(\omega t)$之间变化$0$和$2$。 所以$0 \le \xi(t) \le \frac{F}{k}.$立方体之间的间距为$L(t) = l_0 + \xi(t).$因此，最小分离发生在$\xi=0$, 给予$L_{\min} = l_0,$最大分离发生在$\xi = \frac{F}{k}$, 给予$L_{\max} = l_0 + \frac{F}{k}.$
