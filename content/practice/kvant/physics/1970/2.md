 ## 问题

 在水平面上有两个质量球$m_1$和$m_2$，通过具有刚度的弹簧相互连接$c$。 飞机很平稳。 球发生位移，压缩弹簧，然后同时释放。 确定球的振动周期。 

## 设置和假设

 两个质量球$m_1$和$m_2$放置在光滑的水平面上并通过刚度弹簧连接$c$。 弹簧最初被压缩，然后两个球同时释放。 

所需的数量是每个球的振荡运动的周期。 

给定数量为：$$m_1 \; (\mathrm{kg}), \qquad m_2 \; (\mathrm{kg}), \qquad c \; (\mathrm{N/m}).$$采用以下理想化。 飞机非常光滑，因此没有摩擦。 弹簧是理想的、无质量的，并且遵守胡克定律。 振动足够小，弹簧力与变形成正比。 不存在外部水平力，因此质心以恒定速度移动。 在固定于平面的惯性参考系中考虑运动。 

由于球同时从静止状态释放，因此总水平动量最初为零并保持为零。 因此，质心保持静止。 

## 物理原理

 该解决方案基于牛顿第二定律和胡克定律。 

如果弹簧被拉伸或压缩一定量$x$相对于其自然长度，弹簧力大小为$$F = cx.$$对于每个质量，牛顿第二定律给出$$m a = F.$$由于唯一的水平力是弹簧力，因此两个质量块上的内力大小相等且方向相反。 

通过相对坐标可以方便的描述运动$$r = x_2 - x_1,$$在哪里$x_1$和$x_2$是沿线加入他们的群众的坐标。 

具有角频率的简谐振动$\omega$满足$$\ddot q + \omega^2 q = 0,$$其周期为$$T = \frac{2\pi}{\omega}.$$## 推导

 让$l_0$是弹簧的自然长度。 弹簧的变形量为$$\xi = r - l_0.$$什么时候$\xi>0$弹簧被拉伸，当$\xi<0$它被压缩了。 

弹簧作用在质量上$m_1$力量$$F_1 = c\xi,$$面向大众$m_2$。 论质量$m_2$力是$$F_2 = -c\xi.$$牛顿第二定律给出$$m_1\ddot x_1 = c\xi,$$

$$m_2\ddot x_2 = -c\xi.$$从第二个方程中减去第一个方程得到$$\ddot r = \ddot x_2-\ddot x_1 = -\frac{c}{m_2}\xi-\frac{c}{m_1}\xi.$$自从$\xi=r-l_0$,$$\ddot r = -c\left(\frac1{m_1}+\frac1{m_2}\right)(r-l_0).$$引入相对位移$$q=r-l_0,$$我们得到$$\ddot q + c\left(\frac1{m_1}+\frac1{m_2}\right)q = 0.$$这就是简谐振动方程。 与它比较$$\ddot q+\omega^2 q=0,$$给出$$\omega^2 = c\left(\frac1{m_1}+\frac1{m_2}\right).$$因此$$\omega = \sqrt{c\left(\frac1{m_1}+\frac1{m_2}\right)}.$$相对振荡的周期为$$T = \frac{2\pi}{\omega} = \frac{2\pi} {\sqrt{c\left(\frac1{m_1}+\frac1{m_2}\right)}}.$$分子和分母乘以$\sqrt{m_1m_2}$给出等价形式$$T = 2\pi \sqrt{\frac{m_1m_2}{c(m_1+m_2)}}.$$由于质心静止，两个球都以相同的周期进行简谐振动。 

## 结果

 两个球的振动具有角频率$$\boxed{ \omega = \sqrt{c\left(\frac1{m_1}+\frac1{m_2}\right)} }.$$他们的共同时期是$$\boxed{ T = \frac{2\pi} {\sqrt{c\left(\frac1{m_1}+\frac1{m_2}\right)}} = 2\pi \sqrt{\frac{m_1m_2}{c(m_1+m_2)}}. }$$没有数值$m_1$,$m_2$， 和$c$声明中已提供，因此不能进行数字替换。 答案仍然是象征性的。 

## 健全性检查

 数量$$\frac{m_1m_2}{m_1+m_2}$$有公斤单位。 除以$c$给出$$\frac{\mathrm{kg}}{\mathrm{N/m}} = \frac{\mathrm{kg}}{\mathrm{kg/s^2}} = \mathrm{s^2},$$所以平方根的单位是秒，这是周期的正确单位。 

例如，如果一个质量变得非常大$m_2\to\infty$， 然后$$\frac{m_1m_2}{m_1+m_2} \to m_1,$$和$$T \to 2\pi\sqrt{\frac{m_1}{c}}.$$这正是单个质量的周期$m_1$连接到弹簧，弹簧的另一端被有效固定。 

如果质量相等，$$m_1=m_2=m,$$然后$$T = 2\pi\sqrt{\frac{m}{2c}}.$$由于两个质量对称移动，因此有效惯性减小。 

最容易出错的步骤是相对坐标方程的推导。 两个牛顿方程相减时的符号错误会产生$$\ddot q-\omega^2 q=0,$$它描述的是指数增长而不是振荡运动，并且会导致非物理结果。
