 ## 问题

 F68。 容纳气体的容器壁的温度为$T$。 气体的温度为$T_1$。 在这种情况下，壁上的气体压力更大：当壁比气体冷时（$T < T_1$）或当它们变暖时（$T > T_1$）？ 

## 设置和假设

 物理系统由一个刚性容器组成，其中含有理想气体，其整体温度为$T_1$，同时墙壁保持在一定温度$T$。 未知的是当气体和壁具有不同温度时施加在壁上的压力。 分子的数量和体积是固定的。 除碰撞期间外，分子间相互作用均被忽略。 

对于静止状态，单位时间内每单位面积撞击壁的分子数必须等于离开壁的分子数。 接近壁面的分子具有气体温度的速度分布特征$T_1$，而离开壁面的分子已被壁面热化，具有温度分布特性$T$。 壁压力由这些碰撞中传递的法向动量决定。 

## 物理原理

 墙上的压力等于传递到该墙上的法向动量通量。 对于具有分布函数的气体$f(\mathbf v)$，朝向平面壁的动量通量为$$m\!\int_{v_x>0} v_x^2 f(\mathbf v)\,d^3v .$$对于各向同性麦克斯韦温度分布$\Theta$和数量密度$n$,$$m\!\int_{v_x>0} v_x^2 f(\mathbf v)\,d^3v = \frac12\,nk_B\Theta,$$因为各向同性给出$$m\langle v_x^2\rangle = k_B\Theta,$$一半的分子有$v_x>0$。 因此，仅一个速度半球所携带的动量通量恰好是平衡压力的一半：$$\Pi(\Theta)=\frac12\,nk_B\Theta.$$这是直接的动力学理论结果，而不是假设。 

## 推导

 让$\Pi_{\rm in}$表示入射分子携带到壁上的法向动量通量。 由于事件分布在温度下是麦克斯韦分布$T_1$,$$\Pi_{\rm in} = m\!\int_{v_x>0} v_x^2 f_{T_1}(\mathbf v)\,d^3v = \frac12\,nk_B T_1.$$让$\Pi_{\rm out}$表示由从壁重新发射的分子从壁带走的法向动量通量。 由于这些分子被热化至一定温度$T$,$$\Pi_{\rm out} = m\!\int_{v_x<0} v_x^2 f_T(\mathbf v)\,d^3v = \frac12\,nk_B T\,n_w,$$在哪里$n_w$是表征发射麦克斯韦分布的数密度。 

数量$n_w$一般不等于$n$。 由管壁处无气体积聚的条件决定。 传入粒子通量必须等于传出粒子通量。 

对于麦克斯韦分布，$$\Phi(\Theta,n) = \int_{v_x>0} v_x f(\mathbf v)\,d^3v = n\sqrt{\frac{k_B\Theta}{2\pi m}}.$$使传入和传出粒子通量相等可得出$$n\sqrt{T_1} = n_w\sqrt{T},$$因此$$n_w = n\sqrt{\frac{T_1}{T}}.$$代入输出动量通量，$$\Pi_{\rm out} = \frac12\,nk_B\sqrt{T_1T}.$$施加在壁上的压力等于施加到壁上的动量加上与发射分子带走的动量相关的反应：$$P = \Pi_{\rm in}+\Pi_{\rm out}.$$所以$$P = \frac12\,nk_B T_1 + \frac12\,nk_B\sqrt{T_1T} = \frac12\,nk_B\!\left(T_1+\sqrt{T_1T}\right).$$该表达式以非对称方式取决于进入气体的温度和壁的温度。 算术平均公式并非由动力学理论得出。 

然而，最初的问题是当壁比气体冷或比气体热时哪个压力更大。 令两个温度为固定数，其中$T_1>T$。 在一项实验中，气体具有温度$T_1$壁温为$T$：$$P_1 = \frac12\,nk_B\!\left(T_1+\sqrt{T_1T}\right).$$交换温度后，气体具有温度$T$壁温为$T_1$：$$P_2 = \frac12\,nk_B\!\left(T+\sqrt{T_1T}\right).$$他们的区别是$$P_1-P_2 = \frac12\,nk_B(T_1-T).$$自从$T_1>T$,$$P_1>P_2.$$因此，当气体比壁更热时的压力比当气体比壁更冷时的压力更大。 

## 结果

 与理想气体接触的壁上的压力，该理想气体的进入分子具有温度$T_1$其重新发射的分子被热化至一定温度$T$是$$P = \frac12\,nk_B\!\left(T_1+\sqrt{T_1T}\right).$$如果数值$T_1$和$T$互换后，压力变为$$P' = \frac12\,nk_B\!\left(T+\sqrt{T_1T}\right).$$为了$T_1>T$,$$P>P'.$$因此，当壁比气体冷时，壁上的气体压力比当壁比气体热时更大。 

## 健全性检查

 当$T=T_1$，公式给出$$P = \frac12\,nk_B(T+T) = nk_BT,$$这是平衡理想气体的结果。 

尺寸正确是因为$nk_B\Theta$具有压力的维度。 

用于固定壁温$T$，压力随温度增加$T_1$进入的气体。 这与物理预期一致，即较热的入射分子向壁面携带较大的法向动量。 两个实验的比较也得出了预期的顺序：$$\frac12\,nk_B\!\left(T_1+\sqrt{T_1T}\right) > \frac12\,nk_B\!\left(T+\sqrt{T_1T}\right) \qquad (T_1>T).$$结论是根据显式动量通量计算以及壁处的粒子通量平衡得出的。
