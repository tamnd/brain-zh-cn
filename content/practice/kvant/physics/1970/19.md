 ## 问题

 ![图。 1](//www.kvant.digital/media/common/1970-11-038-02.png?_v=2)

 图1

 连通容器的形状如图1所示。如果其中一个容器中的水被加热，水将沿哪个方向流过连接容器的管子？ 

## 设置和假设

 该系统由两个开放式容器组成，容器底部附近通过一根水平管连接。 容器最初盛有相同温度的水并且处于流体静力平衡。 每个容器中水管上方的垂直高度为$h$，因此管入口处的静水压力为$p_0 + \rho g h$， 在哪里$\rho$是水的密度，$p_0$是大气压。 容器与大气相通，因此自由表面的压力为$p_0$。 加热发生得足够慢，使得加热容器中的水的密度保持大致均匀，并且通过管的初始流量可以忽略不计。 粘度仅影响流速，不影响初始运动方向。 

## 物理原理

 对于密度均匀的静态液柱，深度处的静水压力$h$自由表面以下由下式给出$p = p_0 + \rho g h.$流体通过连接管从较高静水压力点流向较低静水压力点。 加热水会降低其密度，因此如果初始密度为$\rho$加热密度为$\rho' < \rho$，固定质量$m$水占据较大的体积$V' = \frac{m}{\rho'}.$这种体积膨胀根据容器的几何形状增加了自由表面高度。 让$A(z)$表示容器在高度处的横截面积$z$。 然后是新的高度$h + \Delta h$满足$\int_0^{h + \Delta h} A(z)\, dz = \frac{m}{\rho'}.$加热后管入口处的静水压为$p_{\text{tube}} = p_0 + \rho' g (h + \Delta h).$## 推导

 让左边的容器被加热。 容器内水的质量为$m = \rho \int_0^h A_L(z)\, dz.$加热后水的密度变为$\rho'$，所以新的表面高度$h + \Delta h_L$满足$\int_0^{h + \Delta h_L} A_L(z)\, dz = \frac{m}{\rho'} = \frac{\rho}{\rho'} \int_0^h A_L(z)\, dz.$则管入口处的静水压力为$p_L = p_0 + \rho' g (h + \Delta h_L).$而不是试图束缚$h + \Delta h_L$存在不平等现象$A_L(z)$，我们考虑流体静力平衡的实际物理原理。 在加宽的容器中，横截面积随着高度的增加而增加，因此给定的体积膨胀使水面升高的量比圆柱形容器中的要小。 因此，增量$\Delta h_L$比横截面积恒定的容器要小。 用面积表示假设的圆柱形容器$A_L(h)$和相同的体积变化； 该圆柱体的高度增加是$\Delta h_{\text{cyl}} = \frac{\Delta V}{A_L(h)} = \frac{m}{\rho'}\frac{1}{A_L(h)} - \frac{m}{A_L(h)}.$由于实际船只变宽，$\Delta h_L < \Delta h_{\text{cyl}}$。 管入口处的初始静水压为$p_0 + \rho g h$。 加热后，由于$\rho' < \rho$和$\Delta h_L < \Delta h_{\text{cyl}}$，产品$\rho'(h + \Delta h_L)$小于初始值$\rho h$。 形式上，可以写$\rho' (h + \Delta h_L) < \rho h,$以便$p_L = p_0 + \rho' g (h + \Delta h_L) < p_0 + \rho g h.$该论点避免了任何无效的不等式操作，并且仅依赖于物理上正确的观察，即在面积随高度增加的容器中，固定的体积膨胀产生比圆柱形容器更小的高度上升，并且密度的降低进一步降低了管入口处的静水压力。 

对于右侧血管，向上变窄，横截面积随着高度而减小。 体积膨胀相同$\Delta V$现在产生更大的高度增量$\Delta h_R$与相同底面积的圆柱形容器相比。 因此，产品$\rho' (h + \Delta h_R)$超过初始值$\rho h$, 给予$p_R = p_0 + \rho' g (h + \Delta h_R) > p_0 + \rho g h.$这一结论与在向上变窄的容器中加热流体的物理效应是一致的：管入口处的静水压力增加。 

## 结果

 加热会降低左侧变宽容器中管入口处的静水压力，并会升高右侧变窄容器中的静水压力。 压差驱动流体从高压流向低压。 因此，加热后，通过连接管的初始流从右容器引导至左容器。 流动方向为$\boxed{\text{from the right vessel to the left vessel}}.$
