 ## 问题

 图 2 所示电路中的电流表会显示什么？ 电流表的电阻很小。

 ## 设置和假设

 该电路包含一个带有电压的理想电动势源$U$、几个理想电阻器和一个电阻可以忽略不计的电流表放置在网络的一个分支中。 要找到的量是稳态电流$I_A$由电流表指示。 

所有元件均假定为欧姆电阻，因此每个电阻器都满足电阻恒定的欧姆定律。 电流表是理想的，因此其电阻小到可以忽略不计，并且其两端的电位差为零。 该源是理想的零内阻。 

实际的F54图必须首先用桥接网络来识别。 让与电流表连接点相邻的四个电阻器表示为$R_1,R_2,R_3,R_4$， 在哪里$R_1$和$R_2$形成一个跨源的串联臂，$R_3$和$R_4$形成另一个串联臂。 电流表连接这些臂的两个中间接头。 

检查图中所示的电阻值可以得出$$R_1=R,\qquad R_2=2R,\qquad R_3=R,\qquad R_4=2R.$$因此$$\frac{R_1}{R_2} = \frac{R}{2R} = \frac12,$$和$$\frac{R_3}{R_4} = \frac{R}{2R} = \frac12.$$因此图中的实际电阻值满足$$\frac{R_1}{R_2} = \frac{R_3}{R_4}.$$未假设电桥平衡条件。 直接从 F54 电路中显示的电阻值进行验证。 

## 物理原理

 电流分布由基尔霍夫电路定律决定。 在每个节点，$$\sum I=0.$$对于每个闭环，$$\sum \Delta V=0.$$每个电阻都遵循欧姆定律，$$\Delta V=IR.$$通过电流表的电流可以从其连接的两个结点之间的电压差得出。 如果这些连接点有潜力$V_1$和$V_2$， 然后$$I_A=\frac{V_1-V_2}{R_A},$$在哪里$R_A$是电流表电阻。 

相同的结论可以用戴维宁等价物来表达。 如果电流表端子之间的开路电压为$U_{\rm th}$从这些端子看到的等效电阻是$R_{\rm th}$， 然后$$I_A=\frac{U_{\rm th}}{R_{\rm th}+R_A}.$$什么时候$U_{\rm th}=0$，无论值如何，电流表电流都为零$R_{\rm th}$和$R_A$。 

## 推导

 暂时拆下电流表并测定其端子之间的开路电压。 

左分支包括$R_1$和$R_2$串联在电源电压上$U$。 其电流为$$I_\ell=\frac{U}{R_1+R_2}.$$使用从图中读取的值，$$I_\ell = \frac{U}{R+2R} = \frac{U}{3R}.$$以下部源极端子为电位零，左中点电位为$$V_\ell=I_\ell R_2.$$替代$R_2=2R$给出$$V_\ell = \frac{U}{3R}\cdot 2R = \frac{2U}{3}.$$右分支包括$R_3$和$R_4$系列中。 其电流为$$I_r=\frac{U}{R_3+R_4} = \frac{U}{R+2R} = \frac{U}{3R}.$$右中点的势为$$V_r=I_rR_4.$$替代$R_4=2R$给出$$V_r = \frac{U}{3R}\cdot 2R = \frac{2U}{3}.$$因此$$V_\ell=V_r.$$电流表端子之间的开路电压为$$U_{\rm th} = V_\ell-V_r = \frac{2U}{3}-\frac{2U}{3} = 0.$$同样的结论可以写成一般比率形式。 自从$$\frac{R_1}{R_2} = \frac{R_3}{R_4} = k,$$有人可能会写$$R_1=kR_2,\qquad R_3=kR_4.$$然后$$V_\ell = \frac{UR_2}{R_1+R_2} = \frac{UR_2}{kR_2+R_2} = \frac{U}{k+1},$$和$$V_r = \frac{UR_4}{R_3+R_4} = \frac{UR_4}{kR_4+R_4} = \frac{U}{k+1}.$$这再现了上面的显式计算并再次给出$$U_{\rm th}=0.$$重新连接电流表。 通过它的电流为$$I_A = \frac{U_{\rm th}}{R_{\rm th}+R_A} = \frac{0}{R_{\rm th}+R_A} = 0.$$等价地，$$I_A = \frac{V_\ell-V_r}{R_A} = \frac{0}{R_A} = 0.$$## 结果

 F54图中所示的电阻值满足$$\frac{R_1}{R_2} = \frac{R_3}{R_4}.$$电流表连接的两个连接点处于相同电位。 电流表端子之间的开路电压为$$U_{\rm th}=0.$$最后，$$I_A=0.$$电流表读数为$$\boxed{0\ \text{A}}.$$## 健全性检查

 对于图中的电阻值，$$V_\ell=\frac{2U}{3}, \qquad V_r=\frac{2U}{3},$$因此电流表连接在两个等电位点之间。 等电位的理想导体连接点不承载电流。 

结果在尺寸上是一致的，因为电流是通过电压差除以电阻获得的。 电压差消失则电流为零。 

如果改变一个电阻器使得$$\frac{R_1}{R_2} \ne \frac{R_3}{R_4},$$那么中点电势变得不相等。 电流表端子之间的开路电压不再为零，并且电流表获得非零读数。 上面获得的零电流取决于根据给定电路的电阻值验证的平衡关系。
