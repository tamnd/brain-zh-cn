 ## 问题

 F64。 使用木球和装满水的高容器进行了四个实验。 在第一个实验中，球在容器中漂浮时进行称重（图2a）； 在第二个实验中，将球绑在容器底部并称重（图2b）； 在第三个实验中，用一根细杆将球固定在水下（图2c）； 最后，在第四个实验中，称重过程中球上升到表面（图2d）。 在哪种情况下，用球平衡容器的重量的质量会更大？ 

图2：

 (a) 球漂浮在容器中的水面上。 

(b) 球完全浸入水中并绑在容器底部。 

(c) 将球完全浸入水中并用细杆从上方固定。 

(d) 称重时球上升到水面。 

## 设置和假设

 该系统由一个容器、容器中的水和一个木球组成。 容器放置在天平的一个盘上。 另一个盘承载一个重物，调整其质量直至达到平衡。 

让$m_b$是木球的质量，$V$它的体积，$\rho_w$水的密度，$g$重力加速度，$W_b = m_b g$球的重量，以及$F_A = \rho_w g V$球完全浸入水中时的浮力。 

因为球是木制的，$\rho_b < \rho_w$，因此$F_A > W_b$。 

要比较的量是容器以及与其机械连接的所有物体施加在天平上的力。 平衡重的质量与该力成正比。 

水被视为不可压缩的。 忽略表面张力、粘度以及螺纹和杆的质量。 假设平衡是理想的。 

## 物理原理

 该分析依赖于牛顿第三定律和阿基米德原理。 阿基米德原理指出，浸入液体中的物体受到的向上浮力等于排开液体的重量：$F_A = \rho_w g V_{\rm disp}.$牛顿第三定律断言，如果流体施加向上的力$F_A$在球上，球施加相等的向下的力$F_A$在流体上。 对于静止的系统，每个物体上的所有垂直力的总和为零。 对于由容器、水和球组成的系统，内力相互抵消，因此天平支撑与其机械连接的所有物体的总重量。 

## 推导

 在实验（a）中，球漂浮。 球的平衡要求$F_A = W_b.$球压在水面上的向下的力等于$F_A$，与自身重量一致$W_b$。 因此，由于球而施加在容器上的附加载荷恰好是$W_b$，并且余额支持$W_{\rm vessel + water} + W_b.$在实验（b）中，球完全浸没并绑在底部。 作用在球上的力满足$F_A = W_b + T,$在哪里$T$是球上向下的线的张力。 求解张力屈服$T = F_A - W_b.$球施加向下的力$F_A$在水面上。 同时，线施加向上的力$T$在船上。 传递到船舶的净附加载荷为$F_A - T = F_A - (F_A - W_b) = W_b.$因此平衡再次支持$W_{\rm vessel + water} + W_b.$在实验（c）中，球被一根细杆从上方保持浸没。 球满足$F_A = W_b + F_r,$在哪里$F_r$是杆施加的向下的力。 解决$F_r$给出$F_r = F_A - W_b.$球用力压在水面上$F_A$，杆位于容器外部。 因此，来自杆的向下的力不会传递至容器。 容器接收来自水的充分反应，$F_A$，所以天平上的附加载荷为$F_A$。 因为$F_A > W_b$，天平读数超过情况 (a) 和 (b) 的读数$F_A - W_b$。 

在实验（d）中，球在没有外部约束的情况下在水中上升。 传递到容器的瞬时力等于通过水作用的球的重量和流体对球向上加速度的反作用力的总和。 球上的垂直力满足$m_b a = F_A - W_b - F_{\rm contact},$在哪里$a$是球的向上加速度，$F_{\rm contact}$是球通过水施加在容器上的向下的力。 自从$F_{\rm contact} = F_A - m_b a$，任意时刻传递到船只的向下力为$F_{\rm vessel} = W_{\rm vessel} + W_{\rm water} + F_{\rm contact} = W_{\rm vessel + water} + F_A - m_b a.$因为$a > 0$,$F_A - m_b a < F_A$。 因此，实验（d）中的天平瞬时读数小于实验（c）中的天平瞬时读数。 精确值在运动过程中会波动，但在任何时候都不会超过情况 (c) 中的最大读数，这是当外部杆保持球上的全部浮力时获得的。 因此，尽管实验（d）中的平衡读数可能会在运动开始时暂时超过静态情况（a）和（b）的平衡读数，如果$a$很小，它不能超过完全约束的静态情况（c）。 

## 结果

 对于四个实验，作用在天平上的力满足$N_c = W_{\rm vessel + water} + F_A,$

$N_a = N_b = W_{\rm vessel + water} + W_b,$

$N_d \leq W_{\rm vessel + water} + F_A.$自从$F_A > W_b$，静态读数的顺序是$N_c > N_a = N_b.$虽然情况(d)中的动态读数取决于球的瞬时加速度，但它不能超过情况(c)中的最大静态值。 因此，当球被外部杆浸没时，天平上的最大质量出现在实验 (c) 中：$\boxed{\text{The greatest balancing mass is required in case (c).}}$## 健全性检查

 所有表达式的维度都是一致的；$F_A$和$W_b$力是以牛顿为单位测量的，因此存在以下差异：$F_A - W_b$是有意义的。 如果球的密度与水相同，$F_A = W_b$，并且实验（c）中的杆不会提供额外的力，使得所有静态读数相同，与直觉一致。 对于极轻的球来说，$W_b \ll F_A$，并且实验（c）中的船只几乎承受全部浮力，这证明了为什么该读数是最大的。 

由于从向下的浮力中明确减去了来自线的向上力，因此避免了实验（b）中先前常见的符号错误。 实验(d)的修正处理用基于瞬时力传递的分析代替了无效的质心论证，保证了结论的严谨性。
