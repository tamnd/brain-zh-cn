 ## 问题

 在 20 米以内的距离拍摄老虎是很危险的。 光圈直径为 1 毫米的暗箱多大尺寸才能使老虎在照片中呈现条纹？ 老虎皮毛上的条纹之间的距离是20厘米。 

A·L·斯塔先科

 ## 设置和假设

 暗箱被建模为一个长方形盒子$L$具有直径较小的圆孔$d = 1,\text{mm} = 1\times 10^{-3},\text{m}$。 一只老虎位于远处$R = 20,\text{m}$从光圈。 老虎的皮毛上有明暗相间的条纹，具有空间周期$S = 20,\text{cm} = 2\times 10^{-1},\text{m}$。 

图像形成在位于相机暗箱后壁的屏幕上，距离$L$从光圈。 使用几何光学，将光视为射线。 有限孔径产生几何模糊，但衍射效应被忽略，因为没有提供波长并且孔径与光学波长相比是宏观的。 

未知的是最大暗箱长度$L_{\max}$条纹图案在图像中保持可解析。 

## 物理原理

 针孔投影产生物体尺寸和图像尺寸之间的线性放大关系，$$m = \frac{L}{R}.$$图像中相邻条纹的间隔由投影间距给出$$\Delta x_{\text{img}} = m S.$$有限孔径会在屏幕上产生几何模糊点，其直径由孔径和屏幕之间的相似三角形决定，$$b = \frac{d}{R} L.$$分辨率要求模糊直径小于相邻条纹的图像间隔，$$b < \Delta x_{\text{img}}.$$## 推导

 相邻条纹之间的图像分离来自线性缩放，$$\Delta x_{\text{img}} = \frac{L}{R} S.$$有限孔径引起的模糊大小是通过考虑从孔径的相对边缘进入的光线来获得的。 这些光线形成一个随屏幕距离线性扩展的圆锥体，给出$$b = \frac{d}{R} L.$$解决条纹问题的条件是$$\frac{d}{R} L < \frac{L}{R} S.$$两侧包含相同的几何因子$\frac{L}{R}$，这取消了，$$d < S.$$不等式不依赖于$L$，因此分辨率仅取决于孔径直径与条纹间距的比率。 

## 结果

 解析条件简化为$$d < S.$$代入数值，$$1\times 10^{-3}\,\text{m} < 2\times 10^{-1}\,\text{m}.$$满足这个不等式，并且不限制相机长度$L$。 所以，$$L_{\max} = \infty.$$盒装结果：$$\boxed{L_{\max} = \infty}$$## 健全性检查

 尺寸一致性成立，因为两者$d$和$S$带有长度单位并出现在直接比较中。 

取消$L$物理上一致，因为几何模糊和几何放大倍率都与针孔模型中的相机长度呈线性关系，从而保留了相对对比度。 

主要规模比较是$d/S = 10^{-3}/(2\times 10^{-1}) = 5\times 10^{-3}$，它远低于统一，证实孔径足够小，可以在任何有限的投影距离下保持条纹对比度。
