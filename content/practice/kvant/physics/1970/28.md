 ## 问题

 两个平行板之间的距离小于其尺寸。 几个薄的导热良好的隔板（屏幕）放置在板之间。 如果出现以下情况，这将如何影响板之间的导热率：

 1. 填充板之间空间的气体分子的平均自由程，即两次碰撞之间气体分子行进的距离，与屏幕之间的距离相比较小；
 2. 气体分子的平均自由程与板之间的距离相比大吗？ 

## 设置和假设

 两个面积较大的平行板$A$相隔一段距离$L$， 和$L$比板尺寸小得多，因此边缘效应可以忽略不计。 板之间的空间充满均匀压力的气体$p$和温度场仅在垂直于板的方向上变化。 

一套$N$薄隔板（筛网）平行于板插入。 假设每个屏幕在机械上都很薄，并且由于其非常高的导热性而在内部处于完美的热平衡，因此每个屏幕都具有明确的均匀温度。 与气体相比，屏幕不会储存大量热量，并且不会在其内部引入额外的热阻。 气体充满$N+1$相邻表面之间的间隙。 

感兴趣的量是两个板之间的有效热导，或等效的热通量密度$q$对于给定的温差$\Delta T = T_1 - T_2$板之间。 

考虑气体的两种状态：

 首先，流体动力学状态，其中平均自由程$\lambda$满足$\lambda \ll d$， 在哪里$d$是相邻屏幕之间的特征间距。 

其次，自由分子状态$\lambda \gg L$。 

## 物理原理

 在流体动力学状态下，气体遵循傅里叶热传导定律$q = -\kappa \frac{dT}{dx},$在哪里$\kappa$是气体的热导率。 

一层厚度的热阻$\ell$和面积$A$是$R = \frac{\ell}{\kappa A}.$当各层串联时，热阻会增加，$R_{\text{tot}} = \sum_i R_i.$在自由分子状态下，距离小于平均自由程的两个表面之间的传热由弹道输运决定。 不同温度下两个等温面之间的热通量$T_a$和$T_b$有形式$q = G (T_a - T_b),$在哪里$G$取决于气体性质和压力，但与分离距离无关，只要大量气体中的碰撞可以忽略不计。 每个间隙对应的热阻为$R_0 = \frac{1}{G}.$对于由热平衡屏分隔的一系列弹道间隙，每个间隙的电阻串联相加。 

## 推导

 ### 制度 1：$\lambda \ll d$在这种情况下，相邻表面之间的每个子层中的气体局部处于平衡状态并且传热是扩散的。 相邻表面之间的每个间隙都表现为平面平行的厚度层$d_i$。 

设板间总距离为$L$。 和$N$屏幕，空间被划分为$N+1$层。 筛网间距均匀，每层都有厚度$d_i = \frac{L}{N+1}.$一层的热阻为$R_i = \frac{d_i}{\kappa A} = \frac{L}{(N+1)\kappa A}.$总电阻是所有层的总电阻，$R_{\text{tot}} = (N+1)\frac{L}{(N+1)\kappa A} = \frac{L}{\kappa A}.$因此有效热导率为$K_{\text{eff}} = \frac{1}{R_{\text{tot}}} = \frac{\kappa A}{L}.$屏幕的存在不会改变该状态下的有效导热率。 

### 制度2：$\lambda \gg L$在这种情况下，气体分子在与边界的碰撞之间进行弹道运动。 相邻表面之间的每个间隙都充当独立的弹道传热元件。 

对于一个间隙，热通量为$q = G (T_a - T_b),$所以一个间隙的热阻是$R_0 = \frac{1}{G}.$和$N$屏幕，有$N+1$差距。 每个屏幕都处于内部热平衡，因此它强制执行明确的中间温度。 系统变成了一系列$N+1$弹道导体。 

总电阻为$R_{\text{tot}} = (N+1)R_0.$有效电导为$K_{\text{eff}} = \frac{1}{(N+1)R_0} = \frac{G}{N+1}.$因此，热导率与段数成比例降低。 

## 结果

 对于$\lambda \ll d$:$K_{\text{eff}} = \frac{\kappa A}{L}.$替换不会引入额外的参数，因为结果与没有屏幕的情况相同。 气体的导热系数保持不变$\kappa$有效电导为$\boxed{K_{\text{eff}} = \frac{\kappa A}{L} \ \text{W/K}}.$为了$\lambda \gg L$:$K_{\text{eff}} = \frac{G}{N+1}.$相对于单间隙电导表示$G$,$\boxed{K_{\text{eff}} = \frac{G}{N+1} \ \text{W/K}}.$## 健全性检查

 在扩散区域中，总热阻仅取决于层厚度的总和。 取消$(N+1)$确认尺寸一致性，因为$\kappa A / L$有单位$\mathrm{W/K}$。 

在弹道状态中，每个屏幕引入了新的热化边界，增加了温度不连续性的数量。 电阻的线性增长$N+1$符合串联电导的规则。 

假设细分扩散介质会改变总电阻，就会产生潜在的错误； 这会错误地留下一个因素$N+1$在分母中。 另一个常见的错误是将弹道传输视为依赖于距离，这会错误地引入$L$进入$G$。
