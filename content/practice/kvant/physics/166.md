 ## 问题

 在水平定向的气缸中，固定活塞的一侧有 1 摩尔的理想气体。 气缸的另一部分是真空的。 位于活塞和气缸壁之间的弹簧处于未变形状态（图 2）。 气缸与周围环境绝热。 释放活塞，建立平衡后，气体所占据的体积加倍。 气体的温度和压力如何变化？ 气缸、活塞和弹簧的热容量可以忽略不计。

 ## 设置和假设

 水平气缸包含一个无摩擦活塞，其质量对于能量计算可以忽略不计。 在活塞的左侧有$n=1$摩尔理想气体。 右侧是真空，因此没有外部压力作用在该侧。 弹簧将活塞连接到右侧的固定缸壁； 最初弹簧未变形。 

该系统是隔热的，因此不会与环境进行热量交换。 活塞从静止状态释放并达到最终的静态平衡。 气体膨胀直到体积增加一倍，所以$V_2 = 2V_1$。 活塞位移为$x$，气体截面积为$A$， 所以$x = (V_2 - V_1)/A = V_1/A$。 

该气体是理想的，其内能仅取决于温度：$U = n C_V T$。 忽略活塞、气缸和弹簧的热容量，因此气体所做的所有功都存储在气体内能和弹簧弹性能中。 

未知数是最终温度$T_2$和压力$P_2$的气体。 

## 物理原理

 气体热力学第一定律如下：$ \Delta U = Q - W$， 和$Q=0$由于绝缘，所以$\Delta U = -W$。 

理想气体的内能满足$\Delta U = n C_V (T_2 - T_1)$。 

由于系统处于静止状态，因此气体所做的功在最终状态下完全存储在弹簧中。 弹簧势能为$E_s = \tfrac{1}{2} k x^2$， 所以$W = \tfrac{1}{2} k x^2$。 

最终状态下的机械平衡给出了活塞上的力平衡：$P_2 A = kx$， 因此$P_2 = kx/A$。 

理想气体定律在每个平衡状态下都成立：$P V = n R T$。 

## 推导

 活塞位移由体积变化确定，$x = \frac{V_2 - V_1}{A} = \frac{V_1}{A}.$最终状态下的弹簧能量变为$E_s = \frac{1}{2} k x^2 = \frac{1}{2} k \frac{V_1^2}{A^2}.$气体所做的热力学功等于该能量，$W = \frac{1}{2} k \frac{V_1^2}{A^2}.$第一定律给出$n C_V (T_2 - T_1) = -\frac{1}{2} k \frac{V_1^2}{A^2}.$由力平衡可知，$P_2 = \frac{kx}{A} = \frac{k V_1}{A^2}.$这通过表达消除了机械常数$k/A^2$按照$P_2$,$\frac{k}{A^2} = \frac{P_2}{V_1}.$代入能量关系式，$n C_V (T_2 - T_1) = -\frac{1}{2} \frac{P_2}{V_1} V_1^2 = -\frac{1}{2} P_2 V_1.$最终状态下的理想气体定律为$V_2 = 2V_1$给出$P_2 (2V_1) = n R T_2,$所以$P_2 V_1 = \frac{n R T_2}{2}.$将其代入能量方程得出$n C_V (T_2 - T_1) = -\frac{1}{2} \cdot \frac{n R T_2}{2} = -\frac{n R T_2}{4}.$除以$n$,$C_V (T_2 - T_1) = -\frac{R}{4} T_2.$重新排列术语，$C_V T_2 - C_V T_1 = -\frac{R}{4} T_2,$

$T_2 \left(C_V + \frac{R}{4}\right) = C_V T_1.$因此，$T_2 = \frac{C_V}{C_V + \frac{R}{4}} T_1.$压力遵循理想气体定律。 最初，$P_1 V_1 = n R T_1,$所以$P_1 = RT_1/V_1$。 在最终状态下，$P_2 V_1 = \frac{n R T_2}{2},$这给出了$P_2 = \frac{R T_2}{2V_1}.$取比例，$\frac{P_2}{P_1} = \frac{T_2}{2T_1},$所以$P_2 = \frac{T_2}{2T_1} P_1.$## 结果

 最终温度为$T_2 = \frac{C_V}{C_V + \frac{R}{4}} T_1.$对于一摩尔气体，用$n=1$隐含地在$C_V$（摩尔热容），$\boxed{T_2 = \frac{C_V}{C_V + \frac{R}{4}}\, T_1}.$最终压力为$P_2 = \frac{T_2}{2T_1} P_1,$所以$\boxed{P_2 = \frac{C_V}{2\left(C_V + \frac{R}{4}\right)}\, P_1}.$## 健全性检查

 组合$C_V + R/4$有单位为$R$，所以表达式为$T_2$每摩尔能量的比率在尺寸上是一致的。 压力表达式正确地减少为$P_2 \propto P_1$，确保初始状态的正确缩放。 

如果弹簧无限刚度，$C_V \ll R$相比之下会迫使$T_2 \ll T_1$，对应于由于弹簧中储存的功而产生的强烈冷却。 如果没有弹簧，模型就会破裂，因为最终体积不受限制，这表明弹簧对于平衡至关重要。 替换$P_2 V_1 = nRT_2/2$是缺失因子 2 将错误传播到最终温度和压力的步骤。
