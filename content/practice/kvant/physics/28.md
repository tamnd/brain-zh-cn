 ## 问题

 两个平行板之间的距离小于其尺寸。 几个薄的、导热良好的隔板（屏幕）放置在板之间。 如果出现以下情况，这将如何影响板之间的导热率：

 1. 填充板之间空间的气体分子的平均自由程，即两次碰撞之间气体分子行进的距离，与屏幕之间的距离相比较小；
 2. 气体分子的平均自由程与板之间的距离相比大吗？ 

## 设置和假设

 两个面积较大的平行板$S$被距离隔开$L$， 和$L$远小于横向尺寸，因此边缘效应可以忽略不计。 板保持在一定温度$T_1$和$T_2$，温差小$|T_1 - T_2| \ll T$以便线性传输理论适用。 

板之间存在稀薄气体。$N$薄隔板（筛网）平行于板插入。 每个屏幕都被假设为完美的热导体，因此其表面的温度是均匀的，并且等于与两侧气体进行能量交换所施加的局部平衡温度。 假设屏幕不会在平面上的不同位置之间直接交换热量，并且除了细分体积之外不会阻碍分子运动。 

气体的特征是分子平均自由程$\lambda$。 考虑两种制度：$\lambda \ll d$， 在哪里$d$是相邻屏幕之间的间距，并且$\lambda \gg L$。 

目的是确定板之间的有效导热率如何取决于两种情况下屏幕的存在。 

## 物理原理

 连续介质区的傅立叶热传导定律为$q = -\kappa \frac{dT}{dx},$在哪里$q$是热流密度，$\kappa$是气体的热导率。 

在扩散状态下，串联层的热阻根据以下公式增加$R = \frac{L}{\kappa S}.$在自由分子（克努森）状态下，两个表面之间的传热由壁碰撞之间​​的分子传输控制。 不同温度下两个平行表面之间的热通量$T_a$和$T_b$采取以下形式$q = h_K (T_a - T_b),$在哪里$h_K$是努森传热系数，与分离距离无关$\lambda \gg L$，并由表面的分子通量和能量交换决定。 

当存在中间等温面时，串联的热阻仍然会增加在自由分子状态中，因为每个间隙通过相邻边界之间的分子飞行独立地交换能量。 

## 推导

 完全分离$L$除以$N$屏幕进入$N+1$相同的气体层，每个厚度$d = \frac{L}{N+1}.$### 制度 1：$\lambda \ll d$在这种情况下，分子碰撞在每层内的壁到壁传输中占主导地位，因此傅里叶定律局部适用于每个气体段。 每个段都表现为具有导电性的均质导体$\kappa$。 

一层的热阻为$R_1 = \frac{d}{\kappa S} = \frac{L}{(N+1)\kappa S}.$由于层串联，总电阻为$R_{\text{tot}} = (N+1) R_1 = (N+1)\frac{L}{(N+1)\kappa S} = \frac{L}{\kappa S}.$屏幕不会产生额外的电阻，因为它们的温度在每个表面上都是连续的，并且假设它们完美导电，仅强制局部平衡而不会增加热降。 

有效电导率满足$R_{\text{tot}} = \frac{L}{\kappa_{\text{eff}} S},$因此$\kappa_{\text{eff}} = \kappa.$### 制度2：$\lambda \gg L$在这种情况下，热量通过在表面之间弹道运动的分子来传递。 相邻边界之间的每个气体区域表现为具有热通量的努森层$q = h_K (T_i - T_{i+1}).$对于一个间隙，$R_K = \frac{1}{h_K S}.$和$N+1$系列中的间隙，$R_{\text{tot}} = \frac{N+1}{h_K S}.$板之间的总热通量为$q = \frac{T_1 - T_2}{R_{\text{tot}} S} = \frac{h_K}{N+1}(T_1 - T_2).$定义随距离变化的有效电导率$L$通过$q = \kappa_{\text{eff}} \frac{T_1 - T_2}{L},$给出$\kappa_{\text{eff}} = \frac{L h_K}{N+1}.$对于没有屏幕的情况，$\kappa_0 = L h_K.$所以，$\kappa_{\text{eff}} = \frac{\kappa_0}{N+1}.$## 结果

 对于$\lambda \ll d$,$\boxed{\kappa_{\text{eff}} = \kappa}.$为了$\lambda \gg L$,$\kappa_0 = L h_K,\qquad \kappa_{\text{eff}} = \frac{\kappa_0}{N+1} = \frac{L h_K}{N+1}.$## 健全性检查

 尺寸一致性如下：$\kappa$有单位$\mathrm{W,m^{-1},K^{-1}}$， 尽管$L h_K$还有单位$\mathrm{W,m^{-1},K^{-1}}$因为$h_K$有单位$\mathrm{W,m^{-2},K^{-1}}$。 

在扩散极限内，取消$(N+1)$反映出将同质傅立叶导体细分为相同的段不会改变总电阻，因为电阻随长度线性变化。 

在自由分子极限下，每个附加屏幕都会引入额外的独立热化边界，从而使总热阻线性增加，与$N+1$，因此电导率与间隙数量成反比降低。 

每面积电导之间的转换最容易出现符号或单位错误$h_K$和体电导率乘以$L$，因为一个涉及单位面积通量，另一个涉及有限距离内的体积传输。
