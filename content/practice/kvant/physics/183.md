 ## 问题

 在光滑水平桌上滑动的测力计被恒定的力拉动$F=4~\text{Н}$。 如果测力计的弹簧质量等于其外壳的质量，并且测力计在水平位置进行校准，测力计的读数是多少？ 

G·L·科特金

 ## 设置和假设

 测功机由质量外壳组成$m_c$和一个质量弹簧$m_s$在里面。 该装置由恒定的外力沿着光滑的水平台面拉动$F=4~\text{N}$。 桌子是无摩擦的，因此水平外力仅通过拉力作用。 

该系统作为刚体加速，但大弹簧中的内应力是不均匀的。 测功机在水平静态配置中进行校准，这意味着当$F$准静态应用且弹簧质量无关，读数等于弹簧张力。 

假设外壳是刚性的，弹簧是均匀的，具有恒定的线性质量密度，并且力施加在弹簧的一端。 测力计的读数通过传递到弹簧套管端部的张力来确定。 

给定条件是$m_s=m_c$。 

## 物理原理

 整个装置运动的牛顿第二定律给出$F = (m_c + m_s)a.$对于延伸的大弹簧，加速期间张力沿其长度并不是恒定的。 在非惯性系中做加速度运动$a$，质量的每个小元素都会受到有效的体积力$-\mathrm{d}m,a$，产生张力的空间梯度。 

对于质量均匀的弹簧$m_s$，两端张力之差等于弹簧上的总惯性力，$T_{\text{pull}} - T_{\text{case}} = m_s a.$壳体受弹簧力作用，故其运动方程为$T_{\text{case}} = m_c a.$## 推导

 壳体与弹簧一端连接，外力作用$F$应用于另一端。 拉侧弹簧端传递外力，因此$T_{\text{pull}} = F.$穿过弹簧，张力降等于弹簧质量的总惯性力，$T_{\text{pull}} - T_{\text{case}} = m_s a.$替代$T_{\text{pull}}=F$给出$F - T_{\text{case}} = m_s a.$外壳通过弹簧力加速，因此$T_{\text{case}} = m_c a.$将其代入之前的关系式，得到$F - m_c a = m_s a,$所以$F = (m_c + m_s)a,$因此$a = \frac{F}{m_c + m_s}.$测功机读数等于传递到外壳的力，因此$T_{\text{case}} = m_c a = m_c \frac{F}{m_c + m_s}.$使用$m_s=m_c$,$T_{\text{case}} = m_c \frac{F}{2m_c} = \frac{F}{2}.$## 结果

 测功机读数为$T = \frac{F}{2}.$替代$F=4~\text{N}$给出$T = \frac{4~\text{N}}{2} = 2~\text{N}.$最终的答案是$\boxed{2~\text{N}}.$## 健全性检查

 表达式$T = m_c F/(m_c+m_s)$具有力的量纲，因为它是质量比和力的乘积，确保尺寸一致性。 

在极限内$m_s \to 0$，结果减少为$T \to F$，与理想的无质量弹簧测功机的行为相匹配。 在相反的极限$m_s \gg m_c$，读数趋于零，这与加速弹簧质量的大部分力一致，而不是传递到外壳。 

加速度$a=F/(m_c+m_s)$与系统的总惯性一致，任何误差很可能是由于错误地假设大弹簧中的均匀张力而引起的，这会错误地给出$T=F$而不是$T=F/2$对于同等质量。
