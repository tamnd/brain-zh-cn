 ## 问题

 证明三个连续整数的平方和不能是自然数的立方。 

于。 I. 爱奥宁

 ## 探索

 考虑三个连续整数$n-1$,$n$,$n+1$并计算它们的平方和。 明确地说，$$(n-1)^2 + n^2 + (n+1)^2 = n^2 - 2n + 1 + n^2 + n^2 + 2n + 1 = 3n^2 + 2.$$问题问这个和能否等于完美立方，即是否存在$n \in \mathbb{Z}$和$m \in \mathbb{N}$这样$$3n^2 + 2 = m^3.$$测试小值$n$产量$n = 0: 2$,$n = 1: 5$,$n = 2: 14$,$n = 3: 29$,$n = 4: 50$,$n = 5: 77$，它们都不是立方体。 消极的$n$产生相同的值。 一个模式表明$3n^2 + 2$很少与完美的立方体对齐。 

模分析可能会揭示矛盾。 对于立方体取模$3$我们有$m^3 \equiv 0,1,2 \pmod{3}$;$3n^2 + 2 \equiv 2 \pmod{3}$。 这允许$m^3 \equiv 2 \pmod{3}$，所以取模$3$仅靠这一点是不够的。 检查模数$9$,$3n^2 + 2 \equiv 2,5,8 \pmod{9}$根据$n \bmod 3$。 立方模$9$是$0,1,8$。 仅有的$n \equiv 2 \pmod 3$给出$3n^2+2 \equiv 8 \pmod 9$，匹配立方体同余，因此同余测试缩小了可能性，但并没有消除所有情况。 

关键的困难是证明丢番图方程$3n^2 + 2 = m^3$没有整数解。 小值表示无解； 同余的可能性较小，但需要仔细对待。 

## 问题理解

 该问题要求证明三个连续整数的平方和不能是自然数的立方。 这是 B 类问题：断言不存在主张的纯粹证明。 核心难点在于证明丢番图方程$3n^2 + 2 = m^3$不承认整数解。 猜想是没有整数$n, m$满足这个方程。 直观的原因是$3n^2 + 2$二次方增长，而立方体比二次方增长得更快，并且它们对小整数取模的余数模式对于所有的都不兼容$n$。 

## 证明架构

 引理 1：将三个连续整数的平方和表示为$3n^2 + 2$。 这是从扩展而来的$(n-1)^2 + n^2 + (n+1)^2$并简化。 

引理 2：对于整数$n, m$, 丢番图方程$3n^2 + 2 = m^3$没有模解$9$。 这个想法是计算$3n^2 + 2 \bmod 9$为了$n \equiv 0,1,2 \pmod 3$并与可能的立方余数进行比较$9$。 

最难的方向：严格证明即使同余允许有一个潜在的残基，也不存在解； 关键点是检查所有小情况并确保同余论证是无懈可击的。 

## 解决方案

 考虑三个连续整数$n-1$,$n$,$n+1$。 它们的平方和为$$(n-1)^2 + n^2 + (n+1)^2 = n^2 - 2n + 1 + n^2 + n^2 + 2n + 1 = 3n^2 + 2.$$假设存在整数$n$和$m \in \mathbb{N}$这样$$3n^2 + 2 = m^3.$$我们检查这个方程的模$9$。 任意整数$n$满足$n \equiv 0,1,2 \pmod 3$。 

如果$n \equiv 0 \pmod 3$， 然后$n = 3k$和$3n^2 + 2 = 3(9k^2) + 2 = 27k^2 + 2 \equiv 2 \pmod 9$。 

如果$n \equiv 1 \pmod 3$， 然后$n = 3k+1$和$n^2 = 9k^2 + 6k + 1$， 所以$3n^2 + 2 = 27k^2 + 18k + 5 \equiv 5 \pmod 9$。 

如果$n \equiv 2 \pmod 3$， 然后$n = 3k+2$和$n^2 = 9k^2 + 12k + 4$， 所以$3n^2 + 2 = 27k^2 + 36k + 14 \equiv 5 \pmod 9$。 

所以$3n^2 + 2 \equiv 2$如果$n \equiv 0 \pmod 3$， 和$\equiv 5$如果$n \equiv 1,2 \pmod 3$。 

立方体取模$9$是$0^3 \equiv 0$,$1^3 \equiv 1$,$2^3 \equiv 8$,$3^3 \equiv 0$,$4^3 \equiv 1$,$5^3 \equiv 8$,$6^3 \equiv 0$,$7^3 \equiv 1$,$8^3 \equiv 8 \pmod 9$，所以任何立方体$m^3 \equiv 0,1,8 \pmod 9$。 

比较模余数$9$,$3n^2 + 2 \equiv 2 \text{ or } 5$， 然而$m^3 \equiv 0,1,8$。 因此，不存在$n$和$m$满意的$3n^2 + 2 = m^3$。 

因此，三个连续整数的平方和不可能是自然数的立方。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的一步是计算$3n^2 + 2 \pmod 9$对于所有残留类别$n \bmod 3$。 显式替换确认：$n \equiv 0$给出$2$,$n \equiv 1$给出$5$,$n \equiv 2$给出$5$。 立方体的余数取模$9$通过平方和乘法检查：$0^3,3^3,6^3 \equiv 0$,$1^3,4^3,7^3 \equiv 1$,$2^3,5^3,8^3 \equiv 8$。 这些集合与${2,5}$，确认不存在解。 

## 替代方法

 另一种方法是治疗$3n^2 + 2 = m^3$作为椭圆曲线方程并调用莫德尔定理，指出整数解是有限的。 直接小试$|n|$很快就没有显示任何解决方案。 使用基本同余模的主要方法$9$对于 Kvant 读者来说更受欢迎，因为它避免了先进的机器，并且只用基本的数论提供了完全独立的论证。
