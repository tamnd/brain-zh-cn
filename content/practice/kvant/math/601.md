 ## 问题

 证明在任意三角形中$ABC$，边的中点$BC$位于连接三角形高交点的线段上$ABC$到该三角形外接圆上与顶点直径相对的点$A$，并平分该段。 

G. Groshev，十年级学生

 ## 探索

 让$H$是三角形的重心$ABC$， 让$M$是 的中点$BC$，并让$D$是外接圆上直径相对的点$A$。 

声明称$M$位于线段上$HD$还有那个$HM=MD$。 因此$M$应该是中点$HD$。 

坐标计算看起来很有希望。 放置外心$O$在原点。 自从$D$是截然相反的$A$，我们有$\overrightarrow{OD}=-\overrightarrow{OA}$。 

对于以原点为圆心的内切三角形，正交中心的标准向量描述为$$\overrightarrow{OH} = \overrightarrow{OA} +\overrightarrow{OB} +\overrightarrow{OC}.$$如果这是正确的，那么$$\frac{\overrightarrow{OH}+\overrightarrow{OD}}2 = \frac{ (\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}) -\overrightarrow{OA} }2 = \frac{\overrightarrow{OB}+\overrightarrow{OC}}2.$$但右边正是 的中点的位置向量$BC$。 因此$M$将是中点$HD$。 

唯一需要证明的点是重心公式。 为了验证它，让$$\mathbf h=\mathbf a+\mathbf b+\mathbf c,$$在哪里$\mathbf a,\mathbf b,\mathbf c$是位置向量$A,B,C$在以原点为圆心的圆上。 自从$$|\mathbf a|=|\mathbf b|=|\mathbf c|,$$我们得到$$(\mathbf h-\mathbf a)\cdot(\mathbf b-\mathbf c) = (\mathbf b+\mathbf c)\cdot(\mathbf b-\mathbf c) = |\mathbf b|^2-|\mathbf c|^2 = 0.$$因此$AH\perp BC$。 相同的计算循环进行，证明$\mathbf h$是正交中心。 

这给出了一个简短而严格的证明。 

## 问题理解

 让$H$是三角形三个高的交点$ABC$，并让$D$是外接圆上的点$ABC$这样$AD$是直径。 如果$M$是边的中点$BC$，我们必须证明$M$位于线段上$HD$是它的中点。 

这是一个B 类问题，纯粹的证明。 

核心困难是将重心、边的中点以及外接圆上与顶点直径相对的点联系起来。 通过用相对于外心的向量表示所有这些点来获得自然连接。 

## 证明架构

 让$O$是三角形的外心$ABC$，并让$\mathbf a,\mathbf b,\mathbf c$是位置向量$A,B,C$关于$O$。 

引理 1. 重心$H$有位置向量$\mathbf h=\mathbf a+\mathbf b+\mathbf c$。 

草图。 表明向量$\mathbf h-\mathbf a=\mathbf b+\mathbf c$垂直于$\mathbf b-\mathbf c$， 因此$AH\perp BC$; 其他两个高度也类似。 

引理 2. 如果$D$是截然相反的$A$在外接圆上，则其位置向量为$-\mathbf a$。 

草图。 外心是直径的中点$AD$。 

引理 3. 线段的中点$HD$有位置向量$(\mathbf h-\mathbf a)/2=(\mathbf b+\mathbf c)/2$。 

草图。 代入引理 1 和 2 中的表达式。 

引理 4. 边的中点$BC$有位置向量$(\mathbf b+\mathbf c)/2$。 

草图。 这是标准的中点公式。 

最微妙的一点是引理 1，因为整个论证取决于正交中心的正确向量描述。 

## 解决方案

 让$O$是三角形的外心$ABC$。 表示为$$\mathbf a=\overrightarrow{OA},\qquad \mathbf b=\overrightarrow{OB},\qquad \mathbf c=\overrightarrow{OC}$$顶点相对于的位置向量$O$。 

自从$A$,$B$， 和$C$位于以$O$，我们有$$|\mathbf a|=|\mathbf b|=|\mathbf c|.$$我们首先确定重心的位置向量。 

定义一个点$H$经过$$\overrightarrow{OH} = \mathbf h = \mathbf a+\mathbf b+\mathbf c.$$然后$$\overrightarrow{AH} = \mathbf h-\mathbf a = \mathbf b+\mathbf c.$$还，$$\overrightarrow{BC} = \mathbf c-\mathbf b.$$因此$$(\mathbf h-\mathbf a)\cdot(\mathbf c-\mathbf b) = (\mathbf b+\mathbf c)\cdot(\mathbf c-\mathbf b).$$扩大，$$(\mathbf b+\mathbf c)\cdot(\mathbf c-\mathbf b) = |\mathbf c|^2-|\mathbf b|^2 = 0.$$所以$AH\perp BC$。 

通过循环排列$A,B,C$我们类似地得到$$BH\perp AC, \qquad CH\perp AB.$$因此$H$位于三角形的所有三个高上$ABC$， 所以$H$是正交中心。 

现在让$D$是外接圆上直径相对的点$A$。 自从$O$是直径的中点$AD$,$$\overrightarrow{OD} = -\mathbf a.$$让$N$是线段的中点$HD$。 其位置向量为$$\overrightarrow{ON} = \frac{\overrightarrow{OH}+\overrightarrow{OD}}2 = \frac{\mathbf h-\mathbf a}{2}.$$替代$\mathbf h=\mathbf a+\mathbf b+\mathbf c$给出$$\overrightarrow{ON} = \frac{\mathbf b+\mathbf c}{2}.$$如果$M$是边的中点$BC$， 然后$$\overrightarrow{OM} = \frac{\mathbf b+\mathbf c}{2}.$$所以$$\overrightarrow{ON} = \overrightarrow{OM},$$这意味着$N=M$。 

因此$M$是线段的中点$HD$。 尤其，$M$位于段连接上$H$和$D$并将该部分一分为二。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是身份$$\overrightarrow{OH} = \mathbf a+\mathbf b+\mathbf c.$$要独立验证它，请计算$$(\mathbf b+\mathbf c)\cdot(\mathbf b-\mathbf c) = |\mathbf b|^2-|\mathbf c|^2.$$因为$B$和$C$位于以$O$，两个长度的平方相等，因此点积消失。 因此向量来自$A$到具有位置向量的点$\mathbf a+\mathbf b+\mathbf c$垂直于$BC$。 循环重复相同的计算证明该点位于所有三个高度上。 

第二个微妙的步骤是确定截然相反的点$A$。 自从$O$是圆的中心和直径的中点$AD$,$$\frac{\mathbf a+\overrightarrow{OD}}2=0.$$求解给出$$\overrightarrow{OD}=-\mathbf a.$$这里的任何符号错误都会改变中点计算并破坏结论。 

最后一步是中点计算：$$\frac{\overrightarrow{OH}+\overrightarrow{OD}}2 = \frac{(\mathbf a+\mathbf b+\mathbf c)-\mathbf a}{2} = \frac{\mathbf b+\mathbf c}{2}.$$这正是中点公式$BC$。 这两个中点向量相等证明了$HD$和中点$BC$是同一点。 

## 替代方法

 引入外心即可得到综合证明$O$。 自从$D$是截然相反的$A$, 点$O$是的中点$AD$。 正交中心的经典性质表明$$\overrightarrow{OH} = \overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC}.$$从这个关系可以得出$$\overrightarrow{MH} = \frac{\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}-(\overrightarrow{OB}+\overrightarrow{OC})}{2} = \frac{\overrightarrow{OA}}2,$$尽管$$\overrightarrow{MD} = \frac{-\overrightarrow{OA}-(\overrightarrow{OB}+\overrightarrow{OC})}{2} + \frac{\overrightarrow{OB}+\overrightarrow{OC}}{2} = -\frac{\overrightarrow{OA}}2.$$因此$\overrightarrow{MH}=-\overrightarrow{MD}$，这意味着$M$是的中点$HD$。 

主解决方案中提出的向量证明是更可取的，因为它从单个计算中得出结论并使中点关系完全透明。
