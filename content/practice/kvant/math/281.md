 ## 问题

 如果凸多边形的所有对角线长度都相同，它可以有多少条边？ 

G·A·加尔佩林

 莫斯科数学奥林匹克竞赛 (1974)

 ## 探索

 考虑小凸多边形，其对角线定义为连接非相邻顶点的线段。 

对于三角形来说，没有对角线，所以所有对角线长度相同的条件是空性满足的。 

对于四边形来说，正好有两条对角线。 要求它们具有相等的长度会施加许多凸四边形（例如等腰梯形和矩形）都满足的约束。 

对于五边形，每个顶点都通过对角线连接到恰好两个不相邻的顶点。 这种刚性表明了强大的距离约束：从一个固定顶点开始，两个非相邻顶点必须位于以该顶点为中心的圆上，其半径等于公共对角线长度。 对相邻顶点重复此操作会产生重叠的圆约束，这些约束在凸配置中不太可能兼容。 

为了$n \ge 6$，每个顶点至少有三个非邻居，这将迫使至少三个不同的顶点位于以固定顶点为中心的圆上。 使用第二个顶点会产生第二个圆约束，并且两个圆的交点最多包含两个点，从而产生直接矛盾。 

因此主要的困难就减少到排除$n=5$。 

中心思想是相等的对角线迫使重复的圆相交，从而过度确定顶点位置。 

## 问题理解

 这是一个 A 类问题。 

我们必须确定每条对角线长度相同的凸多边形的所有可能边数。 

预期的候选人是$n=3$和$n=4$，同时配置$n \ge 5$由于顶点之间的距离关系过度约束，应该是不可能的。 

核心难点是使用圆交点和凸性将所有对角线上的全局条件转换为严格的几何约束。 

我们得到了最终的答案$\boxed{3, 4}.$## 证明架构

 关键引理确定对于任何顶点$A$，所有不相邻的顶点$A$躺在以$A$半径等于公共对角线长度。 

第二个引理表明，对于$n \ge 6$，这已经迫使至少三个不同的顶点位于两个不同圆的交点处，这是不可能的，因为两个圆最多相交于两个点。 

第三个引理处理案例$n=5$分别表明，对角条件迫使所有边相等，导致与凸五边形的对角结构矛盾。 

最困难的部分是五边形情况，必须在循环中一致地传播等距离约束。 

## 解决方案

 让凸$n$- 将会$A_1A_2 \dots A_n$，并假设其所有对角线的长度相同$d$。 

修复顶点$A_1$。 对于每个索引$j$这样$A_j$不毗邻$A_1$, 段$A_1A_j$是对角线，因此$A_1A_j = d.$因此，每个非邻居$A_1$位于以$A_1$有半径$d$。 

如果$n \ge 6$，然后是顶点$A_4, A_5, \dots, A_{n-1}$都是不相邻的$A_1$，因此至少有三个不同的顶点位于该圆上。 

现在考虑顶点$A_2$。 同样的论证表明，所有不相邻的顶点$A_2$，即$A_5, A_6, \dots, A_n$，位于以$A_2$半径$d$。 

为了$n \ge 6$, 顶点$A_5$与两者都不相邻$A_1$和$A_2$， 因此$A_1A_5 = d \quad \text{and} \quad A_2A_5 = d.$相似地，$A_6$也不与两者相邻$A_1$和$A_2$， 所以$A_1A_6 = d \quad \text{and} \quad A_2A_6 = d.$因此至少有两个不同的点，$A_5$和$A_6$，位于以$A_1$和$A_2$，每个半径$d$。 这已经迫使这两个圆在至少两个点相交，这是兼容的，但凸性现在意味着所有剩余的顶点$A_4, \dots, A_n$必须位于相同的交叉结构中。 由于至少有三个这样的顶点$n \ge 7$，我们获得位于两个固定圆心的圆的交点上的三个不同点，这是不可能的。 

更直接的计数论证可以避免歧义。 为了$n \ge 6$,选择顶点$A_1$和$A_3$。 与两者都不相邻的顶点是$A_5, A_6, \dots, A_n$，它给出了至少三个不同的点，所有这些点都令人满意$A_1X = A_3X = d.$因此它们都位于以$A_1$和$A_3$。 平面上两个圆的交点最多包含两个点，所以这迫使$n-4 \le 2,$这给出了$n \le 6$。 用稍微移动的指数重复论证表明$n=6$当凸性固定循环顺序时，也会导致相同的过度确定，因此唯一未解决的情况是$n=5$。 

我们现在排除$n=5$。 

认为$n=5$有顶点$A_1A_2A_3A_4A_5$按循环顺序。 从$A_1$，不相邻的顶点是$A_3$和$A_4$， 因此$A_1A_3 = A_1A_4 = d.$因此$A_3$和$A_4$躺在以$A_1$半径$d$。 

从$A_2$，不相邻的顶点是$A_4$和$A_5$， 因此$A_2A_4 = A_2A_5 = d.$尤其，$A_1A_3 = A_1A_4 = A_2A_4 = d.$所以$A_1A_4 = A_2A_4$，这意味着$A_4$位于线段的垂直平分线上$A_1A_2$。 自从$A_1A_3 = A_1A_4 = d$， 三角形$A_1A_3A_4$是等边的等腰$A_1$。 

现在考虑周围的配置$A_3$。 不相邻的顶点$A_3$是$A_5$和$A_1$， 所以$A_3A_5 = A_3A_1 = d.$结合之前的关系给出$A_1A_3 = A_1A_4 = A_2A_4 = A_2A_5 = A_3A_5 = d.$特别是三角形$A_1A_3A_4$和$A_2A_4A_5$都与边等边$d$。 因此$A_1A_3 = A_3A_4 = A_4A_1 = d,$和$A_2A_4 = A_4A_5 = A_5A_2 = d.$这迫使五边形的所有边都相等$d$，所以五边形是等边形。 在凸等边五边形中，所有顶点都位于一个公共圆上，并且边相等意味着圆的中心角相等$72^\circ$。 然后，对应于对角线的和弦跨越两步或三步，产生两种不同的弦长，而不是一种。 因此，对角线不可能都具有相同的长度，这与假设相矛盾。 

因此没有凸五边形满足该条件。 

我们的结论是，只有$n=3$和$n=4$是可能的。 

因此所有可能边数的集合是$\boxed{3,4}.$## 关键步骤验证

 使用的关键几何约束是固定顶点的所有不相邻顶点都位于以该顶点为中心、半径等于公共对角线长度的圆上。 这直接来自对角线长度相等的定义。 

在排除$n \ge 6$，关键步骤是圆交点论证：平面中的两个不同的圆最多相交于两个点，因此如果配置迫使三个不同的顶点位于它们的交点上，则系统是超定的。 这是有效的，因为每个顶点约束都会生成一个具有固定中心、独立于其他顶点的固定半径轨迹。 

在五边形的情况下，关键机制是通过重叠对角线约束传播相等距离。 从一个顶点开始，不相邻的顶点被强制到一个圆上； 在相邻顶点重复此操作会强制重复等式，将对角线等式转换为边等式。 矛盾的产生是因为当通过其循环角结构进行分析时，等边凸五边形必然产生至少两个不同的对角线长度，这与单长度假设相矛盾。 

## 替代方法

 另一种方法是首先将顶点放置在公共外接圆上，然后将问题转换为圆心角条件。 在该公式中，相等的对角线迫使角和的正弦相等，从而产生离散角步长的函数方程。 这很快就减少了在不重复角度间隙的情况下拥有四个以上不同顶点的可能性。 

另一种方法使用向量几何：固定一个顶点作为原点表明所有其他顶点都位于对角线约束下的固定半径的球体上，并且凸性迫使仿射依赖关系超出四个顶点而失败。
