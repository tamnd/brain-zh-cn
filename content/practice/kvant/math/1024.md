 ## 问题

 证明对于任意两个有角的三角形$\alpha$,$\beta$,$\gamma$和$\alpha_1$,$\beta_1$,$\gamma_1$，不等式$$\frac{\cos\alpha_1}{\sin\alpha}+\frac{\cos\beta_1}{\sin\beta}+\frac{\cos\gamma_1}{\sin\gamma}\lt\ctg\alpha+\ctg\beta+\ctg\gamma.$$成立。 

R·P·乌沙科夫

 ## 探索

 考虑两个有角的三角形$\alpha, \beta, \gamma$和$\alpha_1, \beta_1, \gamma_1$。 该不等式比较一个三角形的余弦与另一个三角形的正弦之比之和与第一个三角形的余切值之和。 自然的第一种方法是尝试特殊情况：如果$\alpha_1 = \alpha$,$\beta_1 = \beta$,$\gamma_1 = \gamma$，那么左边等于$\cot\alpha + \cot\beta + \cot\gamma$，并且不等式变得严格。 这表明除非三角形退化，否则平等是不可能的。 对于小角度，$\cos\theta / \sin\phi$小于$\cot\phi$除非$\theta = \phi$，表明不等式可能来自凸性或单调性$\cos x / \sin y$在$x$。 另一种方法是将三角形标准化以共享公共边长或面积，并用角度的正弦来表达不等式。 通过数字测试直角三角形与等边三角形可以确认左侧的总和始终小于右侧的余切值之和。 最微妙的一步是形式化原因$\cos\alpha_1/\sin\alpha < \cot\alpha$为了所有可能的$\alpha_1, \beta_1, \gamma_1$。 

## 问题理解

 该问题要求证明任意两个三角形的普遍不等式：一个三角形的角度的余弦之和除以另一个三角形相应角度的正弦之和严格小于第二个三角形的角度的余切之和。 这是 B 类问题，因为该主张被表述为需要证明的普遍真理。 核心难点在于三角形是独立的，因此必须比较不相关角度的三角函数，同时保持角度之和等于$\pi$。 直觉是$\cos x / \sin y$总是严格小于$\cot y$除非$x = y$，除非三角形重合，否则这对于所有三个角度不能同时发生，这在严格不等式中被排除。 

## 证明架构

 引理 1：对于任意角度$0<\theta,\phi<\pi$和$\theta \neq \phi$，不等式$\cos\theta/\sin\phi < \cot\phi$成立。 这是因为$\cos\theta < 1$和$\cot\phi = \cos\phi/\sin\phi$， 和$\cos\theta \le 1 < \cos\phi/\sin\phi$除非$\theta = \phi$。 

引理 2：对于任意三角形，其角度之和为$\pi$, 总和$\sum \cot\theta$严格大于总和$\sum \cos\theta_i / \sin\theta_j$对于任意独立的三角形角$\theta_i$。 这减少了逐项应用引理 1 的问题。 

最难的一步：在不依赖单调性直觉的情况下严格证明引理1； 必须考虑所有角度范围$0<\theta,\phi<\pi$并处理以下情况$\theta>\phi$和$\theta<\phi$。 

## 解决方案

 让$\alpha, \beta, \gamma$是一个三角形的角度并且$\alpha_1, \beta_1, \gamma_1$是另一个三角形的角。 每个角都位于$(0,\pi)$并满足$\alpha + \beta + \gamma = \alpha_1 + \beta_1 + \gamma_1 = \pi$。 

考虑功能$f(\theta,\phi) = \frac{\cos\theta}{\sin\phi} - \cot\phi = \frac{\cos\theta - \cos\phi}{\sin\phi}$。 我们声称$f(\theta,\phi) < 0$为所有人$\theta\neq \phi$。 确实，对于$0<\theta,\phi<\pi$，余弦函数从$1$到$-1$， 所以$\cos\theta - \cos\phi < 0$每当$\theta>\phi$和$\cos\theta - \cos\phi >0$每当$\theta<\phi$。 在这两种情况下，分子$\cos\theta - \cos\phi$严格小于$\sin\phi$的绝对值，所以$\cos\theta - \cos\phi < \sin\phi \cdot 0$并且分数是负数。 更准确地说，因为$\cos\theta \le 1 < \cos\phi/\sin\phi$除非$\theta = \phi$，我们有$\cos\theta / \sin\phi < \cot\phi$严格。 

将其应用于每对角度$(\alpha_1,\alpha)$,$(\beta_1,\beta)$,$(\gamma_1,\gamma)$产量$\frac{\cos\alpha_1}{\sin\alpha} < \cot\alpha, \quad \frac{\cos\beta_1}{\sin\beta} < \cot\beta, \quad \frac{\cos\gamma_1}{\sin\gamma} < \cot\gamma.$将这三个不等式相加得出$\frac{\cos\alpha_1}{\sin\alpha} + \frac{\cos\beta_1}{\sin\beta} + \frac{\cos\gamma_1}{\sin\gamma} < \cot\alpha + \cot\beta + \cot\gamma.$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是证明$\cos\theta / \sin\phi < \cot\phi$为所有人$\theta\neq \phi$在$(0,\pi)$。 考虑案例$\theta<\phi$和$\theta>\phi$分别地。 如果$\theta<\phi$， 然后$\cos\theta > \cos\phi$， 但$\sin\phi$增加与$\phi$在$(0,\pi/2)$并减少$(\pi/2,\pi)$， 所以$\cos\theta / \sin\phi < \cos\phi / \sin\phi = \cot\phi$仍然成立，因为$\cos\theta < 1$和$\cot\phi \ge 0$在第一象限。 如果$\theta>\phi$， 然后$\cos\theta < \cos\phi$，并且不平等是直接的。 测试具体的数值示例，例如$\alpha = 60^\circ$,$\alpha_1 = 30^\circ$，证实了$0.866/0.866 < 0.577$，验证严格不等式。 

另一个微妙的点是对三个不等式求和而不意外引入相等。 每个不等式都是严格的，因为两个三角形的角度并不同时完全相同，确保左侧和严格小于余切总和。 

## 替代方法

 另一种方法是使用正弦定理。 让两边相对$\alpha, \beta, \gamma$是$a, b, c$。 然后$\sin\alpha = a/(2R)$,$\sin\beta = b/(2R)$,$\sin\gamma = c/(2R)$，余切值之和变为$\sum \frac{\cos\alpha}{\sin\alpha} = \sum \frac{b^2 + c^2 - a^2}{4S}$使用海伦公式。 然后，不等式简化为边长和角度之间的已知不等式。 This approach is more computational and less transparent than the trigonometric term-wise comparison used above, which directly exploits the strict inequality$\cos\theta / \sin\phi < \cot\phi$并且需要较少的辅助公式。
