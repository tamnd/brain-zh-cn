 ## 问题

 每个数字$x_1$, ...,$x_n$等于$+1$或者$-1$。 据了解$$x_1x_2+x_2x_3+\ldots+x_{n-1}x_n+x_nx_1=0.$$证明$n$能被4整除。 

A·M·莱昂托维奇

 ## 探索

 考虑小序列$+1$和$-1$并计算总和$x_1x_2 + x_2x_3 + \dots + x_{n-1}x_n + x_nx_1$。 为了$n = 2$，总和是$x_1x_2 + x_2x_1 = 2 x_1x_2$，这只能是$+2$或者$-2$，永远不会为零。 为了$n = 4$， 让$x_1 = x_3 = 1$和$x_2 = x_4 = -1$，那么总和就是$x_1x_2 + x_2x_3 + x_3x_4 + x_4x_1 = (1)(-1) + (-1)(1) + (1)(-1) + (-1)(1) = -4$，它不是零，而是选择$x_1 = x_2 = 1$,$x_3 = x_4 = -1$给出$1\cdot 1 + 1\cdot (-1) + (-1)\cdot(-1) + (-1)\cdot 1 = 1 -1 +1 -1 = 0$。 这表明$n = 4$作品。 测试$n = 6$符号交替产生的和不为零。 这一探索暗示$n$必须是 4 的倍数，关键的一步是将成对乘积与奇偶校验相关联$n$以及标志的布置。 

## 问题理解

 该问题要求证明，如果连续的乘积的循环和$\pm 1$数字等于零，则项数$n$能被 4 整除。这是 B 类问题：纯证明。 核心难点在于将零和条件与序列的结构联系起来，并证明不存在长度为$n$不能被4整除即可满足。 这种见解来自于用符号变化的次数来表达总和并使用奇偶校验参数。 

## 证明架构

 引理 1：对于任意序列$x_1, \dots, x_n$和$x_i \in {+1, -1}$, 每一项$x_i x_{i+1}$是$+1$如果$x_i = x_{i+1}$和$-1$如果$x_i \neq x_{i+1}$; 因此，总和等于相等连续对的数量减去不相等连续对的数量。 通过直接计算这是正确的。 

引理 2：设$p$是等号对的数量并且$q$循环序列中符号相反的对的数量。 然后$p - q = 0$意味着$p = q = n/2$。 这是真的，因为$p + q = n$。 

引理 3：在循环序列中，具有相反符号的对的数量等于沿循环的符号变化的数量。 因此，符号变化的次数等于$n/2$。 根据符号变化的定义，这是正确的。 

引理 4：循环序列中符号变化的次数必须是偶数。 这是正确的，因为返回到起始元素会强制关闭循环中的更改计数为偶数。 

引理 5：结合引理 3 和引理 4，$n/2$是偶数，所以$n$能被 4 整除。最难的部分是引理 4，因为如果不仔细考虑奇偶性，关于循环的粗心论证可能会失败。 

## 解决方案

 考虑循环和$$S = x_1x_2 + x_2x_3 + \dots + x_{n-1}x_n + x_nx_1$$其中每个$x_i \in {+1, -1}$。 每学期$x_i x_{i+1}$是$+1$如果$x_i = x_{i+1}$和$-1$如果$x_i \neq x_{i+1}$。 让$p$表示对的数量$(x_i, x_{i+1})$和$x_i = x_{i+1}$， 和$q$表示对的数量$x_i \neq x_{i+1}$。 然后$S = p - q$和$p + q = n$。 条件$S = 0$意味着$p - q = 0$， 所以$p = q = n/2$。 

接下来，观察$q$统计沿循环序列的符号变化次数，即索引的数量$i$这样$x_i \neq x_{i+1}$， 和$x_{n+1} \equiv x_1$。 在任何循环序列中，符号变化的次数必须是偶数，因为每个符号变化都会导致之间的翻转$+1$和$-1$，遍历完整个循环后，我们必须回到起始符号，这需要翻转偶数次。 因此$q$是均匀的。 自从$q = n/2$，由此可知$n/2$是均匀的。 所以$n$能被4整除。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 一个周期内符号变化次数为偶数的奇偶性论证需要验证。 考虑一个以以下开头的序列$+1$; 每个符号变化都会翻转当前值。 经过奇数次更改后，最后一个元素将是$-1$，违背等式$x_{n+1} = x_1$。 测试长度为 2、4 和 6 的小序列证实，只有偶数个更改才允许循环结束，因此该论证成立。 使用交替符号和计算显式分配序列$q$为了$n = 4, 8$证实$n/2$总是均匀的。 

另一个微妙的步骤是翻译$S = 0$进入$p = q = n/2$。 对几个例子进行数值计算表明，序列$S = 0$确实有相同数量的相等和不相等的对。 为了$n = 4$，序列$(+1, +1, -1, -1)$给出$S = 0$， 和$p = 2$,$q = 2$，匹配参数。 为了$n = 6$，没有序列产生$S = 0$，确认一致性。 

## 替代方法

 人们也可以使用复数来解决这个问题，代表$+1$作为$1$和$-1$作为$i^2$，并将总和分析为单位根之和。 该方法将问题简化为复指数参数的整除条件，得出相同的结论：$n$必须能被 4 整除。使用符号变换和奇偶校验的主要方法是更可取的，因为它只需要基本算术和组合推理，避免了不必要的代数机器，并且在学校竞赛级别上保持可访问性。
