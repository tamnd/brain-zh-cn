 ## 问题

 证明多项式$p(x)$具有整数系数，对于三个不同的整数值取值 1$x$，不能有任何整数根。 

## 探索

 考虑一个多项式$p(x)$具有取值的整数系数$1$在三个不同的整数处，比如说$a$,$b$， 和$c$。 表示$p(a) = p(b) = p(c) = 1$。 一种自然的方法是检查移位多项式$q(x) = p(x) - 1$，然后消失于$x = a, b, c$。 所以，$q(x)$有三个不同的整数根，因此它可以被整除$(x-a)(x-b)(x-c)$具有整数系数。 认为$p(x)$也有一个整数根$r$。 然后$q(r) = p(r)-1 = -1$。 这迫使$(r-a)(r-b)(r-c) = -1$以整数表示。 下一步是分析三个整数的乘积是否等于$-1$而不是其中之一$a$,$b$， 或者$c$。 测试小整数示例，如果$(r-a)(r-b)(r-c) = -1$，那么其中两个因素必须是$\pm 1$第三个$\mp 1$。 自从$a$,$b$,$c$是不同的，没有排列$\pm 1$差异可以同时明显。 因此，方程没有整数解。 关键困难在于证明没有整数解$r$可以在不假设琐碎的小数量情况的情况下存在； 需要对整数进行仔细的组合论证。 

## 问题理解

 该问题要求证明多项式$p(x)$具有整数系数，其值为$1$对于三个不同的整数，本身不能在任何整数处消失。 这是一个 B 类问题，因为它需要通用命题的证明。 核心困难在于表明$p(r) = 0$不可能发生，即使$p(a) = p(b) = p(c) = 1$，这需要精确分析整数整除性以及三个不同整数的乘积。 洞察力是通过$1$给出一个可被三个具有整数系数的不同线性因子整除的多项式，并且整数根将迫使它们的乘积等于$-1$，这是不可能的。 

## 证明架构

 引理 1：如果$p(x)$具有整数系数，则对于任意整数$r$,$a$,$b$,$c$, 数量$(r-a)(r-b)(r-c)$划分$p(r)-p(a)$以整数表示。 草图：利用以下事实：$p(x) - p(a)$可以整除$x-a$与整数商并递归应用它。 

引理 2：对于不同的整数$a$,$b$,$c$，不存在整数$r$这样$(r-a)(r-b)(r-c) = \pm 1$。 草图：考虑差异的绝对值； 三个不同的整数不能具有三个成对差，其乘积为$\pm 1$。 

主要主张：无整数$r$满足$p(r) = 0$。 草图：让$q(x) = p(x)-1$并使用引理 1 和 2 来证明$q(r) = -1$没有整数解。 

最难的一步是引理 2，因为它需要对整数进行仔细的组合推理，粗心的论证可能会错过像这样的小例子$0$,$1$,$-1$。 

## 解决方案

 让$a$,$b$,$c$是三个不同的整数，使得$p(a) = p(b) = p(c) = 1$。 定义多项式$q(x) = p(x) - 1.$然后$q(x)$具有整数系数并且满足$q(a) = q(b) = q(c) = 0.$因此$q(x)$可被这些根对应的线性因子的乘积整除：$q(x) = (x-a)(x-b)(x-c) \cdot s(x),$在哪里$s(x)$是具有整数系数的多项式。 

为了矛盾起见，假设$p(x)$有一个整数根$r$。 然后$p(r) = 0$， 所以$q(r) = p(r)-1 = -1$。 代入因式分解可得$(r-a)(r-b)(r-c) \cdot s(r) = -1.$自从$r$,$a$,$b$,$c$是整数，$s(r)$也是一个整数。 所以$(r-a)(r-b)(r-c)$必须是除数$-1$以整数表示。 的唯一整数约数$-1$是$1$和$-1$。 因此$(r-a)(r-b)(r-c) = \pm 1.$考虑三个不同的整数$r-a$,$r-b$,$r-c$。 如果他们的产品是$1$，那么数字必须是排列$(1, 1, 1)$,$(-1, -1, 1)$，或类似的组合给出$1$。 所有可能性都要求至少有两个差值相等，但是$a$,$b$,$c$是不同的，所以$r-a$,$r-b$,$r-c$是不同的。 同样，如果他们的产品是$-1$，绝对值仍必须至少包含一次重复才能满足整数乘法。 因此，没有整数$r$存在使得$(r-a)(r-b)(r-c) = \pm 1$。 

这个矛盾表明，没有整数$r$可以满足$p(r) = 0$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 在引理 2 中，三个不同整数不能相乘的断言$\pm 1$通过枚举小整数的所有可能性来验证：绝对值必须是$1$，给出其中的三个数字${-1, 1}$，但任何三个不同的整数不能全部位于该集合中。 该参数也适用于更大的整数，因为任何绝对值大于的整数$1$将使产品超过$1$以绝对值表示。 另一个微妙的步骤是因式分解$q(x) = (x-a)(x-b)(x-c)s(x)$具有整数系数。 这是有道理的，因为$q(x)$在三个不同的整数处消失并且具有整数系数，因此商$s(x)$还通过整数多项式的除法算法获得整数系数。 

## 替代方法

 另一种方法是考虑以整数为模的多项式。 例如，减少模数$p$对于素数$p$允许人们分析同余：如果$p(r) = 0$， 然后$p(r) \equiv 0 \pmod{r-a}$,$r-b$,$r-c$，在模运算中产生矛盾。 此方法看起来较短，但需要熟悉模素数的整除性质。 主要方法更可取，因为它仅依赖于基本整数算术和基本因子定理，使其完全适合高中读者。
