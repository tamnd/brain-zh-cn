 ## 问题

 从 30 个全等的矩形中，构造出与原始矩形相似的矩形。 这个长方形的边长之比是多少？ 

P·潘科夫

 ## 探索

 让原来的矩形有边长$a$和$b$，并令它们的比率为$r = \frac{a}{b} > 0$。 大矩形与小矩形相似，所以它的边长成正比$a$和$b$，因此可以写成$ka$和$kb$对于某些人来说$k>0$。 

由于大矩形是由$30$小矩形的全等副本，其面积为$30ab$。 另一方面，它的面积也$k^2 ab$， 所以$k^2 = 30$和$k = \sqrt{30}$。 

因此大矩形必须有边长$\sqrt{30}a$和$\sqrt{30}b$。 因此，平铺划分了$\sqrt{30}a \times \sqrt{30}b$矩形成$30$的副本$a \times b$，可能旋转。 

关键的结构限制是每个小矩形贡献一个$a$-段或$b$- 根据大矩形的方向沿大矩形的每条边进行分段。 这迫使之间存在线性关系$a$和$b$来自计算每个方向放置了多少个矩形。 

尝试小型配置建议拆分$30$矩形分为沿相同方向对齐的矩形和旋转的矩形。 主要困难是确保大矩形的两侧边长与相同的混合物一致。 

主要怀疑是方向之间的任何不平衡都会破坏相似性，除非$a=b$。 

## 问题理解

 这是一个 A 类问题：确定原始矩形边长的所有可能比率，使得$30$全等副本平铺一个与它们相似的矩形。 

我们被要求提供所有可能的值$r=\frac{a}{b}$。 相似性的几何约束与平铺相结合，对边长如何沿着大矩形的边界分解施加了强大的算术限制。 预期只有方形情况才能满足一致性条件。 

## 证明架构

 让$a,b>0$是小矩形的边长，$r=\frac{a}{b}$。 

让$n$是未旋转放置的矩形的数量，$30-n$数字旋转。 

第一个引理建立了大矩形边长的表达式：$n,a,b$。 

第二个引理强制大矩形和小矩形之间的相似性，产生一个方程$r$和$n$。 

第三引理求解所得方程并检查所有可接受的情况$n\in{0,1,\dots,30}$。 

最微妙的步骤是验证边界分解强制线性求和而不是更复杂的排列，并确保两个相似方向都得到处理。 

## 解决方案

 让小矩形有边$a$和$b$，并定义$r=\frac{a}{b}>0$。 大矩形由以下部分组成$30$这些矩形的全等副本。 

每个小矩形的边都放置在$a$平行于大矩形的固定边或旋转以使该边$b$与该方向平行。 让$n$表示第一方向上的矩形数量，$30-n$旋转方向上的数字。 

沿着大矩形的一侧，矩形的贡献是相加的。 在第一方向，投影贡献长度$a$朝一个方向并且$b$在垂直方向。 在旋转方向上，这些贡献被交换。 因此边长$X$和$Y$大矩形的满足$$X = na + (30-n)b, \quad Y = nb + (30-n)a.$$由于大矩形与小矩形相似，因此其边长比等于$r$或者$\frac{1}{r}$。 因此$$\frac{X}{Y} = r \quad \text{or} \quad \frac{X}{Y} = \frac{1}{r}.$$首先考虑$$\frac{na + (30-n)b}{nb + (30-n)a} = \frac{a}{b}.$$分子和分母除以$b$产量$$\frac{nr + (30-n)}{n + (30-n)r} = r.$$叉乘给出$$nr + 30 - n = rn + r(30-n)r = rn + r^2(30-n).$$减法$rn$从双方的产量$$30 - n = r^2(30-n).$$如果$n \neq 30$,除以$30-n$给出$r^2=1$， 因此$r=1$自从$r>0$。 

如果$n=30$，所有矩形均未旋转。 然后$X=30a$和$Y=30b$， 所以$\frac{X}{Y}=\frac{a}{b}=r$。 然而相似性需要比例因子$k$同时满足$X=ka$,$Y=kb$, 给予$k=30$。 那么大矩形的面积就是$900ab$，与它必须等于的事实相矛盾$30ab$。 因此$n=30$是不可能的。 

现在考虑$$\frac{nr + (30-n)}{n + (30-n)r} = \frac{1}{r}.$$交叉相乘给出$$r(nr + 30 - n) = n + (30-n)r.$$扩大，$$nr^2 + r(30-n) = n + r(30-n).$$减法$r(30-n)$从双方的产量$$nr^2 = n.$$如果$n\neq 0$，除以$n$给出$r^2=1$， 因此$r=1$。 

如果$n=0$，所有矩形都被旋转，并且像以前一样出现相同的面积矛盾，因为缩放因子将再次为$30$而不是$\sqrt{30}$。 

因此，在所有可接受的情况下，唯一可能的比率是$r=1$。 

因此原来的长方形一定是正方形，边长之比等于$$\boxed{1}.$$## 关键步骤验证

 表达式为$X$和$Y$将边界分解为按方向分类的矩形的不相交贡献直接得出； 不会发生重叠或缺失的线段，因为平铺将边界划分为每个矩形的完整边长线段。 

在第一个方程中，取消导致$30-n = r^2(30-n)$不会因为特殊情况而放弃解决方案$n=30$单独检查后发现与面积限制不符。 

在第二个方程中，取消$r(30-n)$是有效的，因为两侧都包含来自旋转矩形的相同线性贡献，并且剩余方程干净地简化为$nr^2=n$，有边界情况$n=0$被同一区域不匹配排除。 

可能性$r=-1$被边长的正数排除。 

## 替代方法

 另一种方法使用点阵模型：将每个矩形解释为向量分解中的向量贡献$\sqrt{30}\times \sqrt{30}$缩放网格。 然后表明，整数平铺的一致性迫使边长相等，从而将问题简化为对长宽比的丢番图约束。 这种方法更具几何性，但最终在方向计数上简化为相同的线性系统，而当前的论点更直接并且避免了坐标嵌入。
