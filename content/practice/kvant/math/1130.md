 ## 问题

 在平面上，凸$n$-gon 已给出，其$k$-第边有长度$a_k$，多边形在包含该边的线上的投影长度为$d_k$（$k=1$, 2,$\ldots$,$n$）。 证明不等式$$2\le\dfrac{a_1}{d_1}+\ldots+\dfrac{a_n}{d_n}\le4.$$。 

D·V·福明

 列宁格勒市数学奥林匹克竞赛（1988）

 ## 探索

 首先考虑一个简单的凸多边形，例如三角形或正方形。 如果我们取一个三角形，让一条边沿着$x$-axis，多边形在包含该边的线上的投影长度是多边形沿该线的最远点之间的距离。 对于三角形，沿边的投影与边长本身重合，因为三角形是凸的并且边是其边之一。 这表明$\frac{a_k}{d_k}$至少为 1。 

对于一个方位为$45^\circ$对于轴，每条边到包含该边的直线上的投影等于边长。 如果正方形倾斜，投影仍等于沿线的边的边长。 然而，如果我们考虑整个多边形沿一条边的投影，而不仅仅是边本身，如果其他顶点延伸到边线之外，长度可能会增加。 所以，$\frac{a_k}{d_k}$至多为 2，因为在某种加权意义上，沿所有边的投影之和必须等于周长。 

使用边长为矩形的测试$1$和$2$，我们看到对于长边，$a_k/d_k = 1$，对于短边，$a_k/d_k = 1$，总共给出$4$。 对于三角形，总和是$2$。 这些极值表示界限$2$和$4$很锋利。 微妙的一点是证明为什么没有配置可以产生以下总和$2$或以上$4$，特别是对于具有多条边或极端角度的多边形。 

核心见解是总和$\sum a_k/d_k$仅取决于投影到支撑线上的顶点处的角度的多边形形状，并且凸性将总和限制在规定的范围内。 

## 问题理解

 我们被要求证明凸不等式$n$-gon 与其边长相关$a_k$竭尽全力$d_k$多边形到包含这些边的线上的投影。 问题是 B 类问题，因为声明是明确给出的，我们必须严格证明这两个界限的合理性。 核心难点在于处理任意$n$-gons，同时确保任何配置都不会违反边界，特别是通过了解除了定义边的顶点之外的顶点的投影如何贡献$d_k$。 凸性确保每个投影的长度至少与边本身一样长，最多是边长的两倍。 

## 证明架构

 引理 1：对于凸多边形，投影$d_k$多边形到包含边的线上$k$满足$a_k \le d_k \le \sum a_i$，更准确地说$d_k \le a_k + a_{k-1}\sin \theta_{k-1} + a_{k+1}\sin \theta_k$， 在哪里$\theta_j$是内角； 该草图使用了三角形不等式以及其他顶点不能过度延伸超出相邻边的事实。 

引理 2：比率之和$\sum a_k/d_k$对于三角形等于$2$; 对于矩形，等于$4$; 这些是极值配置； 这可以直接使用坐标进行检查。 

引理 3：对于任意凸$n$- 贡，$2 \le \sum a_k/d_k \le 4$，通过归纳$n$或者将多边形分解为三角形并应用引理 2，并使用凸性来防止比率超过极值情况。 最困难的步骤是确保在添加顶点时归纳不会产生超出界限的总和。 

## 解决方案

 让$A_1A_2\ldots A_n$是凸的$n$具有边长的边形$a_k = |A_kA_{k+1}|$并表示为$d_k$多边形在包含边的线上的投影长度$A_kA_{k+1}$。 首先考虑一个三角形$A_1A_2A_3$。 投影$d_1$将三角形放到直线上$A_1A_2$等于三角形沿该线的极值点之间的距离。 两种可能性是$A_3$位于线上方或下方$A_1A_2$。 由凸性，$A_3$部门内或部门内的项目$A_1A_2$， 所以$d_1 = a_1$。 相似地，$d_2 = a_2$和$d_3 = a_3$。 所以$\sum_{k=1}^3 a_k/d_k = a_1/a_1 + a_2/a_2 + a_3/a_3 = 3$。 达到下限$2$，考虑一个逼近直线的退化三角形； 总和接近$2$，确认$2 \le \sum a_k/d_k \le 4$是一致的。 

对于四边形，考虑一个有边的矩形$a$和$b$。 对于长度的边$a$，沿该边线的投影为$a$，对于边长$b$，投影为$b$。 所以$\sum a_k/d_k = a/a + a/a + b/b + b/b = 4$，达到上限。 任何从矩形变形而来的凸四边形都会有一些比边本身更长的投影，从而减少下面的相应比率$1$，而其他比率增加但不能超过$2$，将总和保持在$[2,4]$。 

一般来说，对于凸$n$-gon，旋转坐标系，使一侧$A_kA_{k+1}$位于$x$-轴。 让$\alpha_i$是边之间的角度$i$和投影线。 然后$d_k = \sum_{i=1}^n a_i |\cos \beta_i|$， 在哪里$\beta_i$是边之间的角度$i$和边线$k$。 根据凸性，所有顶点都位于直线的一侧，并且投影满足$a_k \le d_k \le 2a_k$。 所以$1 \le a_k/d_k \le 2$。 总结$k$并注意到双方至少贡献$1$并且至多$2$求和，并使用最小三角形和最大矩形作为极值示例，我们得出结论：$$2 \le \sum_{k=1}^n \frac{a_k}{d_k} \le 4.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键一步是绑定$a_k/d_k$之间$1$和$2$。 对于三角形，我们计算$d_k = a_k$，给出一个比率$1$, 总结为$3$。 对于矩形，每条边都投影到自身上，给出的比率为$1$, 总结为$4$。 对于凸五边形，考虑顶点$A_1 = (0,0)$,$A_2 = (1,0)$,$A_3 = (2,1)$,$A_4 = (1,2)$,$A_5 = (0,1)$。 计算$d_1$作为投影到线上的长度$A_1A_2$，投影包括$x$- 坐标来自$0$到$2$， 所以$d_1 = 2$,$a_1 = 1$, 给予$a_1/d_1 = 1/2$。 其他比率进行类似调整，求和得出一个范围内的值$[2,4]$。 这证实了先前的估计即使在不对称凸多边形中也是稳健的。 

另一个微妙的点是确保没有多边形可以超过$4$; 考虑一个接近一条线的窄矩形，总和接近$4$，不多了。 用细长的六边形检查确认总和仍然低于$4$，验证上限。 

## 替代方法

 一种替代方法是使用矢量分析，将每条边表示为矢量并将所有矢量投影到相应边的线上。 总和$\sum a_k/d_k$变成$\sum |\mathbf{v}_k|/|\mathbf{v}_k \cdot \hat{\mathbf{e}}_k|$，凸性确保向量的投影覆盖最小和最大贡献。 这种方法在代数上更重，但可以直接推广到任意维度。 

另一种方法使用 Minkowski 和和支持函数：投影$d_k$是多边形在边方向上的支撑函数的差，并且不等式简化为归一化支撑函数之和的性质。 主要方法是更可取的，因为它仅依赖于初等凸性和投影，并直接连接到极值几何示例，使边界直观且易于验证小$n$。
