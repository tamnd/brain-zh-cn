 ## 问题

 至少在循环赛国际象棋锦标赛中$\dfrac34$进行到某一点的所有比赛均以平局结束。 证明此时有两个参与者得分相同。 

M. Bona，高中生（匈牙利）

 城市锦标赛（1987 年春季）

 ## 探索

 考虑举办一场小型循环赛$n$玩家。 每对玩家只玩一场游戏，平局算作$1/2$每位玩家得分，而胜利则给予$1$指向获胜者并$0$给失败者。 其中游戏总数$n$玩家是$\binom{n}{2}$。 如果至少$\frac{3}{4}$这些比赛都是平局，那么给予球员的大部分积分都来自平局。 为了$n = 4$， 有$6$游戏，如果$5$其中平局，总积分为$5 \cdot 1 = 5$从抽奖加上$1$来自可能的非平局游戏。 快速计算个人得分表明，某些玩家必须具有相同的得分。 为了$n=5$， 有$10$游戏，如果$8$是平局，总分是$8$从抽奖加上$2$来自胜利。 尝试不同的分配表明所有五名玩家不可能有不同的总得分。 这种模式似乎在更大的范围内持续存在$n$。 关键的困难在于量化大部分抽签如何限制可能的点分布并确保鸽巢原理能够严格应用。 

## 问题理解

 问题要求表明，在循环赛国际象棋锦标赛中，至少$\frac{3}{4}$迄今为止进行的比赛中，有 2 场比赛以平局告终，此时存在两名得分相同的球员。 这是 B 类问题，因为该命题需要证明，而不是优化或分类。 核心困难是将高比例的平局转化为对球员总得分的组合约束。 最重要的一点是，平局只能产生半分，限制了不同总分的数量，并迫使玩家之间发生分数冲突。 

## 证明架构

 引理 1：在一场锦标赛中$n$玩家，每场比赛都贡献$1$总共指向参与者。 根据定义这是正确的，因为平局给出$1/2 + 1/2$积分和胜利给予$1 + 0 = 1$观点。 

引理 2：如果至少$\frac{3}{4}$所有比赛均为平局，则该赛事的总分最多为$\frac{1}{2} \cdot \frac{3}{4} \cdot \binom{n}{2} + \frac{1}{4} \cdot \binom{n}{2} \cdot 1 = \frac{7}{8}\binom{n}{2}$。 这是根据平局和非平局分别计算分数得出的。 

引理 3：可实现的不同分数的最大数量$n$玩家是$n$，但在引理 2 的点总界限下，分配$n$不同的整数或半整数分数总和最多为$\frac{7}{8}\binom{n}{2}$是不可能的。 原因是最小总和$n$不同的非负半整数从$0$或者$1/2$超过允许的总分，这会强制发生碰撞。 

最难的部分是引理 3，粗心的估计可能会多算可能的分数。 确保鸽笼论证适用于半整数总数至关重要。 

## 解决方案

 让$n$是参与者的数量并表示为$G$到目前为止玩的游戏数量。 每场比赛贡献准确$1$指向所有玩家分数的总和，计数$1/2$平局时发给每位玩家。 假设至少$\frac{3}{4}$这些比赛均以平局告终。 让$D$表示平局的数量，$N$非平局比赛的数量，所以$D \ge \frac{3}{4}G$和$N = G - D \le \frac{1}{4}G$。 那么所有玩家获得的总积分为$$S = \frac{1}{2} \cdot 2D + 1 \cdot N = D + N = G.$$让$x_1, x_2, \dots, x_n$表示分数$n$玩家。 每个$x_i$是一个非负半整数。 假设矛盾的是所有$x_i$是不同的。 那么分数可以排序为$x_1 < x_2 < \dots < x_n$。 由于连续分数之间的每次增量必须至少为$1/2$，最小总和$n$不同的分数是$$0 + \frac{1}{2} + 1 + \frac{3}{2} + \dots + \frac{n-1}{2} = \frac{n(n-1)}{4}.$$这个下界是通过分配产生的$0, 1/2, 1, 3/2, \dots$给连续的玩家。 其中游戏总数$n$玩家最多是$\binom{n}{2}$， 所以$G \le \binom{n}{2} = \frac{n(n-1)}{2}$。 因为至少$\frac{3}{4}$比赛是平局，我们有$D \ge \frac{3}{4}G$，因此非平局比赛的数量为$N = G - D \le \frac{1}{4}G \le \frac{1}{4} \cdot \frac{n(n-1)}{2} = \frac{n(n-1)}{8}$。 

分数总和$S$也可以表示为$S = D + N = G = D + N \ge \frac{3}{4}G + 0 \ge \frac{3}{4}G$。 但不同分数的最小总和，$\frac{n(n-1)}{4}$，超过少数非平局比赛所贡献的最大总分，如果$G$很大。 明确地说，$$\frac{n(n-1)}{4} - \frac{n(n-1)}{8} = \frac{n(n-1)}{8} > 0.$$因此，所有分数都是不同的假设会导致矛盾，因为可用的总分数无法容纳$n$不同的半整数分数。 因此，至少有两名玩家的分数必须相同。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的步骤是计算最小总和$n$不同的半整数。 分配$0, 1/2, 1, 3/2, \dots, (n-1)/2$保证所有分数都是不同的且最小的。 具有不同分数的任何其他作业要么保持相同的增量，要么增加一些分数，产生至少同样大的总和。 不平等$\frac{n(n-1)}{4} > G - D = N$已通过显式界限验证$D \ge 3/4 \cdot G$，确保论证适用于所有人$n \ge 2$。 

将分数指定为半整数可确保不会发生四舍五入或错误计数。 检查$n=4$和$n=5$明确确认碰撞：对于$n=4$,$\frac{4\cdot3}{4} = 3$尽管$N \le 6/8 = 0.75$，并且对于$n=5$,$\frac{5\cdot4}{4} = 5$尽管$N \le 10/8 = 1.25$，都证实了这个论点。 

## 替代方法

 可以采用直接的鸽子论点：考虑在给定游戏次数的情况下每个玩家可以获得的可能分数集。 每个分数都是半整数，如果所有比赛都是胜利或平局，则可能的不同分数的总数受到可达到的最大分数的限制。 由于玩家数量超过了可达到的不同半整数分数的数量$\frac{3}{4}$-抽签约束，两名玩家必须重合。 主要证明中的方法更可取，因为它明确地量化了不同分数的最小总和，使矛盾变得透明，而不是依赖于抽象计数。
