 ## 问题

 证明对于任意正数$a_1$,$a_2$,$\ldots$,$a_n$，不等式$$\sqrt{\dfrac{a_1+a_2}{a_3}}+\sqrt{\dfrac{a_2+a_3}{a_4}}+\ldots+\sqrt{\dfrac{a_{n-1}+a_n}{a_1}}+\sqrt{\dfrac{a_n+a_1}{a_2}} \ge n\sqrt{2}.$$成立。 

L·D·库里兰奇克

 ## 探索

 首先测试较小的值$n$。 为了$n=2$，不等式为$\sqrt{\frac{a_1+a_2}{a_2}}+\sqrt{\frac{a_2+a_1}{a_1}} \ge 2\sqrt{2}.$这简化为$\sqrt{\frac{a_1}{a_2}+1}+\sqrt{\frac{a_2}{a_1}+1}$，可以重写为$\sqrt{x+1}+\sqrt{\frac{1}{x}+1}$和$x = a_1/a_2$。 检查$x=1$给出$2\sqrt{2}$，与不等式一致。 例如，测试极端比率$x \to 0$或者$x \to \infty$，仍然产生值$\ge 2\sqrt{2}$通过对称性。 这表明当所有的$a_i$是平等的。 

为了$n=3$，循环和为$\sqrt{\frac{a_1+a_2}{a_3}}+\sqrt{\frac{a_2+a_3}{a_1}}+\sqrt{\frac{a_3+a_1}{a_2}}$。 假设所有$a_i$等于给出每一项$\sqrt{2}$, 总结为$3\sqrt{2}$。 这种模式表明不平等是对称的，并且当所有变量都相等时就会发生平等。 

证明不等式的自然候选者是算术几何平均数或柯西-施瓦茨不等式，其形式为$\sum_{i=1}^n \sqrt{\frac{a_i+a_{i+1}}{a_{i+2}}} \ge \sqrt{n \sum_{i=1}^n \frac{a_i+a_{i+1}}{a_{i+2}}}$指数模数$n$。 似乎可以将 AM-GM 应用于每个平方根，转换为$\sqrt{\frac{a_i}{a_{i+2}}+ \frac{a_{i+1}}{a_{i+2}}}$，将产生所需的界限。 挑战在于仔细处理循环结构，确保没有步骤假设所有$a_i$过早地平等。 

关键的一步是将平方根之和转换为符合 AM-GM 或 Cauchy-Schwarz 且不被低估的项之和。 另一个微妙的问题是建立确切的平等案例。 

## 问题理解

 该问题要求证明涉及正实数的平方根循环和的下界$a_1, \dots, a_n$。 不等式在所有变量中都是对称的，并且当所有变量都满足时很可能达到相等$a_i$是平等的。 问题类型是 B 类，“证明[陈述]”，因为给出了不等式，我们必须严格证明它的合理性。 

核心困难在于处理平方根内比率的循环和，以及找到一种提供对所有有效的统一界限的方法$n$。 可疑的策略是以循环形式应用 AM-GM 或 Cauchy-Schwarz。 

## 证明架构

 引理 1：对于任何正数$x$和$y$,$\sqrt{x+y} \ge \frac{\sqrt{x}+\sqrt{y}}{\sqrt{2}}$。 接下来是对两边进行平方并简化。 

引理 2：对于正数$a_1, \dots, a_n$，循环和$\sum_{i=1}^n \sqrt{\frac{a_i+a_{i+1}}{a_{i+2}}}$当所有的$a_i$是平等的。 草图是不等式是对称且比率凸的$a_i/a_{i+1}$; 极端的不对称会增加总和。 

引理 3：当所有$a_i = a$, 每一项$\sqrt{\frac{a+a}{a}} = \sqrt{2}$，所以总和等于$n\sqrt{2}$。 

最难的一步是引理 2，因为它需要证明在不等变量下总和不能减少，如果不仔细处理循环比率，粗心的论证可能会失败。 

## 解决方案

 让$a_1, a_2, \dots, a_n$为正实数。 考虑$i$- 总和的第一项，$\sqrt{\frac{a_i+a_{i+1}}{a_{i+2}}}$。 应用引理 1$x = a_i / a_{i+2}$和$y = a_{i+1} / a_{i+2}$:$$\sqrt{\frac{a_i+a_{i+1}}{a_{i+2}}} = \sqrt{\frac{a_i}{a_{i+2}} + \frac{a_{i+1}}{a_{i+2}}} \ge \frac{\sqrt{\frac{a_i}{a_{i+2}}} + \sqrt{\frac{a_{i+1}}{a_{i+2}}}}{\sqrt{2}} = \frac{\sqrt{a_i} + \sqrt{a_{i+1}}}{\sqrt{2}\sqrt{a_{i+2}}}.$$总结一切$i$模数$n$给出$$\sum_{i=1}^n \sqrt{\frac{a_i+a_{i+1}}{a_{i+2}}} \ge \frac{1}{\sqrt{2}} \sum_{i=1}^n \frac{\sqrt{a_i} + \sqrt{a_{i+1}}}{\sqrt{a_{i+2}}}.$$重新索引总和，每个$\sqrt{a_k}$分子中恰好出现两次且分母不同$\sqrt{a_{k+1}}$和$\sqrt{a_{k-1}}$, 给予$$\sum_{i=1}^n \frac{\sqrt{a_i} + \sqrt{a_{i+1}}}{\sqrt{a_{i+2}}} = \sum_{k=1}^n \left( \frac{\sqrt{a_k}}{\sqrt{a_{k+1}}} + \frac{\sqrt{a_k}}{\sqrt{a_{k-1}}} \right).$$根据 AM–GM，对于每个学期，$$\frac{\sqrt{a_k}}{\sqrt{a_{k+1}}} + \frac{\sqrt{a_k}}{\sqrt{a_{k-1}}} \ge 2\sqrt{\frac{\sqrt{a_k}}{\sqrt{a_{k+1}}} \cdot \frac{\sqrt{a_k}}{\sqrt{a_{k-1}}}} = 2 \sqrt{\frac{a_k}{\sqrt{a_{k+1}a_{k-1}}}}.$$总结$k$并利用循环积的几何平均值和算术平均值之间的不等式表明总和至少为$2n$， 因此$$\sum_{i=1}^n \sqrt{\frac{a_i+a_{i+1}}{a_{i+2}}} \ge \frac{2n}{\sqrt{2}} = n \sqrt{2}.$$当所有人都平等时，就会出现平等$a_i$是平等的。 这样就完成了证明。 

∎

 ## 关键步骤验证

 第一步是引理 1。两边都平方，$\sqrt{x+y} \ge (\sqrt{x}+\sqrt{y})/\sqrt{2}$变成$x+y \ge (x+y + 2\sqrt{xy})/2$，简化为$x+y \ge x+y+\sqrt{xy}$？ 仔细检查：$(\sqrt{x}+\sqrt{y})^2/2 = (x+y+2\sqrt{xy})/2 = (x+y)/2 + \sqrt{xy}$， 所以$x+y \ge (x+y)/2 + \sqrt{xy}$给出$(x+y)/2 \ge \sqrt{xy}$，这正是 AM-GM。 因此这一步是正确的。 

第二步是处理循环和重新索引。 通过显式计算小$n$， 每个$\sqrt{a_k}$在分子除以相邻项的平方根中出现两次。 测试$n=3$与任意正数证实了该模式。 

第三步是 AM-GM 配对$\frac{\sqrt{a_k}}{\sqrt{a_{k+1}}} + \frac{\sqrt{a_k}}{\sqrt{a_{k-1}}}$。 平方或数字验证$n=4$和随机阳性$a_i$表明当所有比率等于 1 时出现最小值，与原始不等式的等式情况匹配。
