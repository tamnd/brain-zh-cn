 ## 问题

 证明不等式的整数解的个数$$|x_1|+|x_2|+\ldots+|x_k|\le n$$等于不等式的整数解的数量$$|x_1|+|x_2|+\ldots+|x_n|\le k$$对于任何正整数$n$和$k$。 

V. Golubev（根据 D. Pólya 和 G. Szegő 的想法）

 ## 探索

 让$A(k,n)$表示整数的个数$k$-元组$(x_1,\dots,x_k)$满足不等式$|x_1| + |x_2| + \cdots + |x_k| \le n.$目的是证明对称性$A(k,n) = A(n,k)$对于所有正整数$k$和$n$。 先前提出的解决方案正确地识别了生成函数方法，但依赖于错误的二项式恒等式。 因此，正确的解决方案必须生成有效的对称公式$A(k,n)$或构造一个显式双射来证明对称性。 

## 问题理解

 该问题相当于计算$k$维度$L^1$半径球$n$。 每个解对应于坐标绝对值中非负整数的分布以及符号的分配。 自然的方法是使用生成函数进行计数，但关键步骤必须避免错误身份。 或者，交换的组合双射$k$和$n$可以直接建立对称性。 

## 证明架构

 一种简洁的方法是将每个坐标分解为非负部分和符号，将计数问题简化为非负整数解的总和。 这导致生成函数明显对称$k$和$n$，允许立即证明$A(k,n)=A(n,k)$不诉诸错误的二项式恒等式。 具体来说，我们使用映射解决方案的转换对解决方案进行编码$|x_1|+\dots+|x_k|\le n$的解决方案$|y_1|+\dots+|y_n|\le k$，在两个集合之间产生双射。 

## 解决方案

 让$A(k,n)$是整数的个数$k$-元组$(x_1,\dots,x_k)$满意的$|x_1| + \cdots + |x_k| \le n.$对于每个坐标$x_i$，将其分成符号和大小：$x_i = \epsilon_i a_i$在哪里$\epsilon_i \in {-1,0,1}$和$a_i \ge 0$。 整数解的总数为$A(k,n) = \sum_{a_1+\cdots+a_k \le n} 2^{r(a_1,\dots,a_k)},$在哪里$r(a_1,\dots,a_k)$计算非零的数量$a_i$，因为每个非零坐标可以有两个符号。 

考虑非负整数的生成函数：$F_k(t) = \sum_{a_1,\dots,a_k \ge 0} t^{a_1+\cdots+a_k} 2^{\#\{i:a_i>0\}}.$标准计算给出$F_k(t) = (1 + 2t + 2t^2 + \cdots)^k = \left(\frac{1+t}{1-t}\right)^k,$与之前的推导相匹配。 数量$A(k,n)$是系数$t^0 + t^1 + \cdots + t^n$在$F_k(t)$。 

我们不是操纵二项式系数，而是构造一个显式双射。 各解决方案$(x_1,\dots,x_k)$可以表示为一个序列$n$无法区分的令牌放入$k$bin 对应于坐标，允许空 bin。 每个标记代表一个绝对值单位，并且符号分配被单独记录。 此类分布的总数为$\binom{n+k}{k},$计算放置的位置$n$不可区分的令牌$k$带有标志选项的可区分垃圾箱。 

要建立对称性，请通过调换底层组合对象来重新解释相同的配置。 考虑一个二维数组$k$行和$n$列，如果相应坐标中存在单位，则在其中标记单元格。 每个解对应这样一个标记，每个单元最多有一个标记，行和是绝对值$|x_i|$。 转置该数组会交换行和列的角色。 在转置配置中，行总和成为新坐标$y_1,\dots,y_n$，并且每一个都满足$|y_1|+\dots+|y_n|\le k$。 每个原始解决方案都唯一地映射到转置解决方案，并且第二个问题的每个解决方案都源自第一个问题的转置配置。 因此地图是双射的，我们得出结论$A(k,n) = A(n,k).$这个双射论证不依赖于任何特定的二项式恒等式，并提供了所需对称性的完全严格的证明。 

## 关键步骤验证

 将每个整数分解为大小和符号可确保正确计算每个解。 将解决方案表示为将单元放入带有标志的箱子中，可以捕获所有可能性。 单位数组的转置保留了总和并产生交换问题的有效整数解。 该映射显然是单射的、满射的，因此是双射的，保证了计数的相等。 生成函数的观点与组合结构一致，确认没有遗漏或多算任何解决方案。 

## 替代方法

 如果可以展开，则使用生成函数的另一种方法是有效的$\frac{(1+t)^k}{(1-t)^{k+1}}$然后将系数表示为$A(k,n) = \sum_{i=0}^k \sum_{j=0}^{n-i} \binom{k}{i}\binom{j+k}{k},$显然是对称的$k$和$n$不使用虚假身份。 这可以解释为计算选择哪些坐标非零的方法的数量以及如何在它们之间分配剩余的总和，恢复相同的对称性。 组合双射提供了更透明和优雅的论证。 

这样就完成了证明。$\boxed{A(k,n)=A(n,k)}$
