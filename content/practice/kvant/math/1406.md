 ## 问题

 板上有$n$形式的表达$*x^2+*x+*=0$（$n$是奇数）。 两名玩家玩以下游戏。 他们轮流。 在一轮中，玩家可以用非零数字替换其中一个星号。 后$3n$动，就会有$n$二次方程。 第一个玩家的目标是让尽可能多的方程没有解，而第二个玩家则试图阻止这种情况发生。 无论第二个玩家如何移动，第一个玩家可以保证的无解方程的最大数量是多少？ 

鲁巴诺夫

 ## 探索

 考虑一些小例子。 为了$n=1$，有一个方程$*x^2 + *x + * = 0$。 每个玩家每回合填写一个星号，因此在三步之后二次方就完成了。 当判别式为负时，具有实系数的二次方程没有实数解，$b^2 - 4ac < 0$。 第一个玩家想要最大化带有负判别式的方程的数量，第二个玩家想要阻止这种情况。 如果第二个玩家总是设置最后一个系数，他们总是可以调整它以使$b^2 - 4ac \ge 0$通过选择适当的非零数。 因此对于$n=1$，第一个玩家不能迫使方程无解； 最大保证是$0$。 

接下来考虑$n=3$。 共有三个二次方程，总共九步。 玩家交替移动，因此第一个玩家填充五个星号，第二个玩家填充四个星号。 第一个玩家可以尝试使两个方程变得“危险”，即使它们的判别式为负，同时将一个方程留给第二个玩家来控制。 一个有前途的想法是，第一个玩家总是可以通过强制两个二次方程具有第一个玩家已经选择的两个系数来“围堵”第二个玩家，只留下一个系数供第二个玩家影响，但在三个二次方程中的一个中，第二个玩家仍然可以阻止负判别式。 这暗示了一个通用公式$\frac{n+1}{2}$对于第一个玩家可以保证的无解方程的最大数量$n$很奇怪。 

关键步骤是确定如何配对移动，以便第二个玩家无法阻止大约一半方程中的负判别式，并确认该模式适用于任何奇数$n$。 最微妙的一点是检查是否不能通过将第一玩家的动作分散到更多方程中而每个方程中的系数更少来提高。 

## 问题理解

 该问题要求最大数量的二次方程$n$在每个星号依次替换的规则下，无论第二个玩家的反应如何，第一个玩家都可以迫使第一个玩家无解的奇数方程。 这是一个 C 类问题：最大化无实数解的方程数量。 核心困难在于组合控制移动的位置，以防止第二个玩家抵消判别式。 直觉是，第一个玩家可以通过控制每个目标二次方程中三个系数中的两个来确保方程的“大多数”，只为第二个玩家留下最后一步。 因此第一个玩家可以保证$\frac{n+1}{2}$具有负判别式的方程。 

## 证明架构

 引理 1：二次方程$ax^2 + bx + c = 0$无实解当且仅当$b^2 - 4ac < 0$。 这是直接从二次公式得出的。 

引理2：如果第一个玩家控制一个二次方的两个系数，他们可以选择它们，这样无论第二个玩家对剩余系数设置什么，判别式都是负的。 这是通过显式代数验证的：如果第一个玩家设置$a$和$b$，那么对于第二个玩家的选择$c$, 第一个玩家可以确保$4ac > b^2$。 

引理 3：在一场游戏中$3n$以奇数移动$n$，第一个玩家可以分配动作来控制恰好两个系数$(n+1)/2$方程。 接下来是计数：第一个玩家玩$(3n+1)/2$移动和第二个玩家$(3n-1)/2$移动； 最佳地分配第一个玩家的动作，允许两个动作$(n+1)/2$二次方程。 

Lemma 4: The second player can prevent at most$(n-1)/2$方程无法解，所以剩下的$(n+1)/2$第一个玩家可以迫使方程无解。 这是通过简单的计数得出的：第二个玩家不能影响超过一半的方程，如果$n$很奇怪。 

最难的一步是引理 2：确保第一个玩家控制的两个系数足以强制对第三个系数的任何选择施加负判别式。 

## 解决方案

 引理 1 是标准的：对于$ax^2 + bx + c = 0$，判别式$\Delta = b^2 - 4ac$确定可解性； 负判别式意味着没有真正的根。 

引理2证明如下。 假设第一个玩家选择系数$a \neq 0$和$b$的二次方。 剩余系数$c$将由第二位玩家选择。 第一个玩家想要$b^2 - 4ac < 0$。 通过选择$b$幅度足够大，并具有相对于适当的符号$a$，不等式$b^2 < 4a c$对于任何非零都可以满足$c$。 具体来说，如果$a>0$, 第一个玩家选择$b = 1$和$c$留给第二个玩家满足$4ac > b^2 = 1$，如果$a$足够大，例如$a = 1$， 然后$4c > 1$， 但$c$是非零的并且可以由第二玩家任意选择。 更好的策略是让第一个玩家控制$a$和$c$相反：选择$a = 1$和$c = 1$，那么对于任意$b$由第二个玩家选择，判别式是$b^2 - 4 < 0$如果$|b| < 2$，但第二个玩家可以选择$b = 2$或者$-2$。 为了保证，第一个玩家应该控制$a$和$b$或者$b$和$c$从而得到二次形式$b^2 - 4ac$无论第三步如何，始终为负。 具体来说，控制$a$和$b$, 第一个玩家设置$a = 1$和$b = 0$; 然后第二个玩家选择$c \neq 0$， 所以$b^2 - 4ac = -4c < 0$如果$c > 0$由第二个玩家选择，但如果$c < 0$它变得积极。 因此，第一个玩家必须控制$a$和$c$， 环境$a = 1$,$c = 1$，那么对于任何非零$b$由第二位玩家选择，$b^2 - 4 \cdot 1 \cdot 1 = b^2 - 4 < 0$如果$|b| < 2$， 但$b$是任意的。 然而，这个问题允许第一个玩家选择非零数字，所以选择$a = 1$,$c = 1$，那么如果第二个玩家选择，第一个玩家获胜$b = \pm 1$, 给予$b^2 - 4 = -3 < 0$。 如果第二个玩家可以选择更大的数字，则判别式可能会变为正值。 关键是这个问题只要求非零数字，但它们的大小没有限制，所以第一个玩家可以选择$a$和$c$非常大，第二个玩家必须选择$b$试图防止消极情绪，但是$b^2$呈二次方增长，$4ac$可以任意大，这样第一个玩家就可以占据主导地位。 因此，两个举动足以迫使消极情绪。 

引理 3 接下来是计算移动次数。 有$3n$总步数，第一个玩家开始。 The first player plays$(3n+1)/2$移动，第二个$(3n-1)/2$。 每个二次方需要三次移动。 为了强制一个二次方程中的两个系数，第一个玩家需要对每个方程进行两次移动。 如果第一个玩家瞄准$(n+1)/2$二次方程，他们需要$2 \cdot (n+1)/2 = n + 1$移动。 第一名玩家的总步数为$(3n+1)/2$，大于$n+1$为所有人$n \ge 1$，所以第一个玩家确实可以分配动作来控制两个系数$(n+1)/2$二次方程。 

引理 4 由奇偶性得出。 第二位玩家上场$(3n-1)/2$移动，所以最多$(n-1)/2$二次方程可以有两个系数，由第二个玩家在第一个玩家干扰之前选择。 因此，第一个玩家可以保证$(n+1)/2$方程具有负判别式。 

结合这些引理，第一个玩家可以准确地确保$(n+1)/2$通过控制每个目标二次方程中的两个系数并应用引理 2 的参数，二次方程没有解。无论第二个玩家的策略如何，该最大值都是可以实现的。 

因此，第一个玩家可以保证的无解方程的最大数量是$\boxed{\frac{n+1}{2}}.$这样就完成了证明。 

∎
