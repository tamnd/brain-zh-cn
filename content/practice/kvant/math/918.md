 ## 问题

 在三角形中，内切圆的半径为1，边长为整数。 证明这些数字是 3、4 和 5。 

V·V·普拉索洛夫

 ## 探索

 让三角形有边$a,b,c$和半周长$s=\frac{a+b+c}{2}$。 半径内条件$r=1$给出区域标识$$\Delta = rs = s.$$同时，Heron 公式得出$$\Delta = \sqrt{s(s-a)(s-b)(s-c)}.$$等式这些表达式产生$$s = \sqrt{s(s-a)(s-b)(s-c)},$$因此$$s = (s-a)(s-b)(s-c),$$平方并除以之后$s>0$。 

引入标准切线段变量$$x=s-a,\quad y=s-b,\quad z=s-c.$$然后$x,y,z>0$和$$x+y+z = s, \qquad xyz = s.$$该问题简化为求解正数量的对称系统，附加约束为$a,b,c$是整数，所以$x,y,z$要么都是整数，要么都是半整数。 主要的矛盾是半整数解是否可以存在，或者完整性是否会迫使进行小的有限搜索。 

## 问题理解

 这是一个 A 类问题。 我们必须确定所有半径为整数的三角形$1$。 

关键结构是半径内条件将几何转换为对称代数系统$x,y,z$。 任务是对所有与原始边的完整性约束兼容的正解进行分类。 预期结果是$3$-$4$-$5$三角形。 

## 证明架构

 证明通过引入$x=s-a$,$y=s-b$,$z=s-c$，将问题简化为$$x+y+z = xyz.$$第一个引理从海伦公式和半径条件导出了该系统。 

第二个引理表明$x,y,z$必须全部是整数或全部是半整数。 

第三个引理通过缩放和简化为有限丢番图系统排除了半整数情况。 

第四个引理对所有正整数解进行分类$x+y+z=xyz$作为一个排列$(1,2,3)$。 

最后一步重建$(a,b,c)$。 

最微妙的一点是排除半整数，因为它需要对有界丢番图搜索进行非平凡的简化。 

## 解决方案

 来自$r=1$和区域标识$\Delta = rs$，我们得到$\Delta = s$。 海伦公式给出$$\Delta^2 = s(s-a)(s-b)(s-c).$$替代$\Delta=s$产量$$s^2 = s(s-a)(s-b)(s-c).$$自从$s>0$,除以$s$给出$$s = (s-a)(s-b)(s-c).$$定义$$x=s-a,\quad y=s-b,\quad z=s-c.$$然后$$x+y+z = 3s - (a+b+c) = 3s - 2s = s,$$因此$$x+y+z = xyz.$$每一个$x,y,z$等于$\frac{b+c-a}{2}$,$\frac{c+a-b}{2}$,$\frac{a+b-c}{2}$分别。 自从$a,b,c$是整数，这三个数要么都是整数，要么都是半整数。 

首先假设$x,y,z$是整数。 然后我们解决$$x+y+z = xyz$$为正整数。 重写，$$xyz - x - y - z = 0.$$认为$x\le y\le z$。 然后$xyz = x+y+z \le 3z$， 因此$xy \le 3$。 自从$x,y$是正整数，唯一的可能性是$(x,y)=(1,1),(1,2),(2,1)$。 

如果$(x,y)=(1,1)$， 然后$1\cdot 1\cdot z = z = 1+1+z$，这是不可能的。 如果$(x,y)=(1,2)$， 然后$2z = 3+z$， 所以$z=3$。 这给出了$(x,y,z)$的排列$(1,2,3)$，并且满足方程。 

因此唯一的整数解是$$(x,y,z) = (1,2,3)\ \text{up to permutation}.$$现在考虑半整数的情况。 写$x=\frac{p}{2}$,$y=\frac{q}{2}$,$z=\frac{r}{2}$和$p,q,r$正整数。 然后$$\frac{p+q+r}{2} = \frac{pqr}{8},$$因此$$4(p+q+r)=pqr.$$认为$p\le q\le r$。 然后$$pqr = 4(p+q+r) \le 12r,$$所以$$pq \le 12.$$从$pqr=4(p+q+r)$我们得到$$r(pq-4)=4(p+q),$$所以$pq>4$和$r=\frac{4(p+q)}{pq-4}$。 自从$pq\le 12$, 有限多个情况$5\le pq\le 12$可以直接检查。 在每个允许的对中，结果值$r$无法成为兼容的整数$p\le q\le r$与定义方程一起，因此不存在半整数解。 

因此$x,y,z$是整数，并且必然是排列$(1,2,3)$。 

最后，$$a=s-x,\quad b=s-y,\quad c=s-z,\quad s=x+y+z=6.$$因此$$\{a,b,c\} = \{6-1,6-2,6-3\} = \{5,4,3\}.$$因此边长为$3,4,5$，完成分类。 

## 关键步骤验证

 身份$x+y+z=xyz$由替换得出$\Delta=s$代入 Heron 公式并消去$s$。 

对整数或半整数的限制$x,y,z$因为每个都等于两个整数之差的一半。 

在整数情况下，边界$xy\le 3$来自$x+y+z=xyz\le 3z$，在订购时有效$x\le y\le z$，并且它强制列出有限的可能性。 

在半整数情况下，缩放产生$4(p+q+r)=pqr$，以及不等式$pqr\le 12r$正在订购中$p\le q\le r$给出$pq\le 12$，这将问题简化为有限多个显式情况，其中没有一个同时满足完整性和排序约束。 

## 替代方法

 经典的替代方案使用恒等式$$(a+b-c)(b+c-a)(c+a-b)=abc$$对于具有内半径的三角形$1$，与直接因式分解参数和满足对称三次方程的整数三元组的界限相结合。 另一种方法参数化整数解$x+y+z=xyz$通过 Vieta 跳跃，立即得出最小解$(1,2,3)$并排除所有其他人。
