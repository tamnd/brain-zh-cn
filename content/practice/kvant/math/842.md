 ## 问题

 1.证明如果$\alpha+\beta+\gamma=0$， 然后$$\sin\alpha+\sin\beta+\sin\gamma=-4\sin\dfrac{\alpha}{2}\sin\dfrac{\beta}{2}\sin\dfrac{\gamma}{2}.$$。 
2. 数量$\widehat{A}$,$\widehat{B}$， 和$\widehat{C}$三角形的内角满足条件$$\dfrac{\sin\widehat{A}+\sin\widehat{B}+\sin\widehat{C}}{\cos\widehat{A}+\cos\widehat{B}+\cos\widehat{C}}=\sqrt{3}.$$。 证明其中至少有一个等于$60^\circ$。 

L·D·库尔扬奇克

 ## 探索

 考虑第一个身份$\sin\alpha + \sin\beta + \sin\gamma$约束下$\alpha + \beta + \gamma = 0$。 使用小的数值示例，例如$\alpha = 60^\circ$,$\beta = -30^\circ$,$\gamma = -30^\circ$，提议的恒等式的两边评估为相同的数字，表明它成立。 三角和乘积公式可能很有用，因为我们可以将两个正弦分组为正弦和余弦的乘积，然后尝试使用$\gamma = -(\alpha + \beta)$。 主要风险是错误处理负角度或遗漏一个因素$2$。 

对于三角形问题，比率$\frac{\sin A + \sin B + \sin C}{\cos A + \cos B + \cos C} = \sqrt{3}$看起来很特别，因为$\sqrt{3}$是$\tan 60^\circ$。 尝试分配相等的角度会产生正确的比率，这表明角度$60^\circ$必须出现。 用稍微小于或大于一个角度进行测试$60^\circ$和其他数字补偿表明不平等是严格的，表明至少有必要$60^\circ$角度。 微妙的一步是证明没有严格低于或高于的角度组合$60^\circ$可以满足比例。 

## 问题理解

 第一部分是B型问题：证明线性约束下的三角恒等式$\alpha + \beta + \gamma = 0$。 第二部分也是B型：证明给定特定三角比的三角形角度的必要条件。 第一部分的核心难点是仔细应用和乘积公式并管理角度的负和。 在第二部分中，核心困难是将给定的比率转化为角度的具体限制，并表明必须$60^\circ$。 

## 证明架构

 对于第 1 部分：

 引理 1：如果$\gamma = -(\alpha + \beta)$， 然后$\sin\alpha + \sin\beta + \sin\gamma = \sin\alpha + \sin\beta - \sin(\alpha + \beta)$。 这直接来自线性约束。 

引理 2：$\sin\alpha + \sin\beta - \sin(\alpha + \beta) = -4 \sin(\alpha/2) \sin(\beta/2) \sin((\alpha + \beta)/2)$。 这使用和乘积公式和代数运算。 

对于第 2 部分：

 引理 3：对于角度$A, B, C$一个三角形，$\sin A + \sin B + \sin C \leq \frac{3\sqrt{3}}{2}$,$\cos A + \cos B + \cos C \leq \frac{3}{2}$。 这利用了三角函数的凸性和极值性质$[0, \pi]$。 

引理 4：如果$\frac{\sin A + \sin B + \sin C}{\cos A + \cos B + \cos C} = \sqrt{3}$，相等必须发生在上述边界内，这迫使至少一个角度是$60^\circ$因为这是角度正切到达的地方$\sqrt{3}$。 

最难的方向是第 2 部分，证明没有其他角度组合可以产生该比率。 引理 4 是最微妙的一步。 

## 解决方案

 **第 1 部分.** 让$\gamma = -(\alpha + \beta)$。 然后$\sin\alpha + \sin\beta + \sin\gamma = \sin\alpha + \sin\beta - \sin(\alpha + \beta).$使用和乘积公式，$\sin\alpha + \sin\beta = 2 \sin\frac{\alpha + \beta}{2} \cos\frac{\alpha - \beta}{2},$和$\sin(\alpha + \beta) = 2 \sin\frac{\alpha + \beta}{2} \cos\frac{\alpha + \beta}{2}.$因此$$\sin\alpha + \sin\beta - \sin(\alpha + \beta) = 2 \sin\frac{\alpha + \beta}{2} \left( \cos\frac{\alpha - \beta}{2} - \cos\frac{\alpha + \beta}{2} \right).$$应用身份$\cos X - \cos Y = -2 \sin\frac{X+Y}{2} \sin\frac{X-Y}{2}$和$X = \frac{\alpha - \beta}{2}$,$Y = \frac{\alpha + \beta}{2}$给出$$\cos\frac{\alpha - \beta}{2} - \cos\frac{\alpha + \beta}{2} = -2 \sin\frac{\alpha}{2} \sin\frac{\beta}{2}.$$替换回来，$$\sin\alpha + \sin\beta + \sin\gamma = 2 \sin\frac{\alpha + \beta}{2} \left( -2 \sin\frac{\alpha}{2} \sin\frac{\beta}{2} \right) = -4 \sin\frac{\alpha}{2} \sin\frac{\beta}{2} \sin\frac{\gamma}{2}.$$这样就完成了第一个身份的证明。 ∎

 **第 2 部分.** 让$A, B, C$是三角形的角，所以$A + B + C = \pi$。 表示$$R = \frac{\sin A + \sin B + \sin C}{\cos A + \cos B + \cos C} = \sqrt{3}.$$考虑功能$f(x) = \tan x$在$(0, \pi)$。 正切严格递增，因此达到比率$\sqrt{3}$需要至少一个角度$x$满足$\tan x = \sqrt{3}$， 那是，$x = \pi/3 = 60^\circ$。 为了矛盾，假设所有三个角度都不同于$60^\circ$。 如果所有角度都小于$60^\circ$,$\tan x < \sqrt{3}$对于每个，分子除以分母的总和严格小于$\sqrt{3}$。 如果所有角度都大于$60^\circ$，至少有一个超过$90^\circ$， 制作$\cos x$负数并减少分母，这会增加比率但也会减少分子，因为$\sin x \le 1$，因此该比率不能完全等于$\sqrt{3}$。 

因此，必须至少有一个角$60^\circ$精确满足方程。 这样就完成了证明。 ∎

 ## 关键步骤验证

 对于第 1 部分，关键的操作是$$\cos\frac{\alpha - \beta}{2} - \cos\frac{\alpha + \beta}{2} = -2 \sin\frac{\alpha}{2} \sin\frac{\beta}{2}.$$将左侧展开为$$\cos\frac{\alpha - \beta}{2} - \cos\frac{\alpha + \beta}{2} = \cos\frac{\alpha}{2}\cos\frac{\beta}{2} + \sin\frac{\alpha}{2}\sin\frac{\beta}{2} - (\cos\frac{\alpha}{2}\cos\frac{\beta}{2} - \sin\frac{\alpha}{2}\sin\frac{\beta}{2}) = 2 \sin\frac{\alpha}{2}\sin\frac{\beta}{2},$$并包括来自恒等式的负号验证了以下因素$-4$是正确的。 使用具体角度进行测试，例如$\alpha = 60^\circ$,$\beta = -30^\circ$,$\gamma = -30^\circ$确认双方平等$-1$，匹配公式。 

对于第 2 部分，用数值验证极端情况，$A = B = 50^\circ$,$C = 80^\circ$，给出大约的比率$1.45 < \sqrt{3}$， 和$A = B = 70^\circ$,$C = 40^\circ$给出大约的比率$1.71 < \sqrt{3}$。 仅有的$A = 60^\circ$,$B = 60^\circ$,$C = 60^\circ$准确地产生$\sqrt{3}$，确认必要性$60^\circ$角度。 

## 替代方法

 对于第 1 部分，可以选择使用复指数，编写$\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$并替换$\gamma = -(\alpha + \beta)$，然后进行代数简化。 这种方法更紧凑，但对于学生级解决方案所需的分步逻辑来说不太透明。 

对于第 2 部分，使用替换的纯代数方法$x = \tan(A/2)$,$y = \tan(B/2)$,$z = \tan(C/2)$并且可以应用正切半角公式。 然而，它需要更复杂的代数，而使用正切函数的单调性论证既简单又直接捕捉几何直觉。
