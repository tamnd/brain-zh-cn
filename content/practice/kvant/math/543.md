 ## 问题

 让$$\rho(x,y)=\dfrac{|x-y|}{\sqrt{1+x^2}\sqrt{1+\smash{y}\vphantom{x}^2}}.$$证明对于任意实数$a$,$b$,$c$不平等$$\rho(a,c)\le\rho(a,b)+\rho(b,c).$$成立。 

安杰伊·帕什凯维奇（华沙）

 ## 探索

 表达式$$\rho(x,y)=\frac{|x-y|}{\sqrt{1+x^2}\sqrt{1+y^2}}$$类似于三角替换后的欧几里得距离。 如果我们把$$x=\tan \alpha,\qquad y=\tan \beta,$$然后$$x-y=\frac{\sin(\alpha-\beta)}{\cos\alpha\cos\beta},$$和$$\sqrt{1+x^2}=\sec\alpha,\qquad \sqrt{1+y^2}=\sec\beta.$$因此$$\rho(x,y)=|\sin(\alpha-\beta)|.$$那么问题就变成了$$|\sin(\alpha-\gamma)| \le |\sin(\alpha-\beta)|+|\sin(\beta-\gamma)|.$$这看起来更接近三角不等式。 数量$|\sin(u-v)|$是点之间的欧几里德距离$(\cos u,\sin u)$和$(\cos v,\sin v)$在单位圆上，除以$2$， 因为$$(\cos u-\cos v)^2+(\sin u-\sin v)^2 =4\sin^2\frac{u-v}{2}.$$这给出了弦长$2|\sin\frac{u-v}{2}|$， 不是$|\sin(u-v)|$，因此这条路线不会立即产生所需的表达式。 

更好的观察是$$|\sin(\alpha-\beta)| = |\sin\alpha\cos\beta-\cos\alpha\sin\beta|.$$这是单位向量行列式的绝对值$$u_\alpha=(\cos\alpha,\sin\alpha),\qquad u_\beta=(\cos\beta,\sin\beta).$$对于向量$u,v,w$在飞机上，$$\det(u,w)=\det(u,v)+\det(v,w).$$取绝对值得出$$|\det(u,w)| \le |\det(u,v)|+|\det(v,w)|.$$这正是切线替换后所需的不等式。 

最有可能隐藏错误的步骤是从实数开始$a,b,c$到角度。 必须选择角度$\tan\alpha=a$,$\tan\beta=b$,$\tan\gamma=c$，并仔细验证$\rho(x,y)=|\sin(\alpha-\beta)|$没有符号错误。 

## 问题理解

 我们必须证明这个函数$$\rho(x,y)=\frac{|x-y|}{\sqrt{1+x^2}\sqrt{1+y^2}}$$满足三角不等式$$\rho(a,c)\le \rho(a,b)+\rho(b,c)$$对于所有实数$a,b,c$。 

这是一个B 类问题。 陈述已经给出，任务是证明它。 

核心难点在于认识其几何意义$\rho$。 替换后$x=\tan\theta$，表达式变为两个单位向量的行列式的绝对值。 然后，三角不等式由行列式的线性得出。 

## 证明架构

 引理 1. 对于任何实数$x,y$， 如果$\alpha,\beta\in(-\pi/2,\pi/2)$满足$x=\tan\alpha$和$y=\tan\beta$， 然后$$\rho(x,y)=|\sin(\alpha-\beta)|.$$这是从正切减法公式得出的$\sqrt{1+\tan^2 t}=\sec t$。 

引理 2. 如果$u_\theta=(\cos\theta,\sin\theta)$， 然后$$\det(u_\alpha,u_\beta)=\sin(\beta-\alpha).$$这是直接计算。 

引理 3. 对于任何平面向量$u,v,w$,$$\det(u,w)=\det(u,v)+\det(v,w).$$这是由行列式的双线性和反对称性得出的。 

引理 4. 对于任何平面向量$u,v,w$,$$|\det(u,w)| \le |\det(u,v)|+|\det(v,w)|.$$将普通三角不等式应用于引理 3。 

最难的一点是引理 1，因为整个归约取决于确切的身份$\rho(x,y)=|\sin(\alpha-\beta)|$。 

## 解决方案

 选择角度$$\alpha,\beta,\gamma\in\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$$这样$$a=\tan\alpha,\qquad b=\tan\beta,\qquad c=\tan\gamma .$$我们首先表达$\rho$从这些角度来看。 使用$$\tan\alpha-\tan\beta = \frac{\sin(\alpha-\beta)}{\cos\alpha\cos\beta},$$和$$\sqrt{1+\tan^2\alpha}=\sec\alpha=\frac1{\cos\alpha},$$我们得到$$\rho(a,b) = \frac{\left|\dfrac{\sin(\alpha-\beta)} {\cos\alpha\cos\beta}\right|} {\sec\alpha\,\sec\beta} = |\sin(\alpha-\beta)|.$$相似地，$$\rho(b,c)=|\sin(\beta-\gamma)|, \qquad \rho(a,c)=|\sin(\alpha-\gamma)|.$$现在让$$u_\theta=(\cos\theta,\sin\theta).$$直接计算给出$$\det(u_\alpha,u_\beta) = \cos\alpha\sin\beta-\sin\alpha\cos\beta = \sin(\beta-\alpha).$$因此$$\rho(a,b)=|\det(u_\alpha,u_\beta)|.$$类似的公式也适用于其他对。 

利用行列式的双线性，$$\det(u_\alpha,u_\gamma) = \det(u_\alpha,u_\beta) + \det(u_\beta,u_\gamma).$$取绝对值并应用普通三角不等式，$$|\det(u_\alpha,u_\gamma)| \le |\det(u_\alpha,u_\beta)| + |\det(u_\beta,u_\gamma)|.$$将每个行列式替换为相应的行列式$\rho$-价值收益率$$\rho(a,c) \le \rho(a,b)+\rho(b,c).$$这样就完成了证明。 

∎

 ## 关键步骤验证

 身份$$\rho(a,b)=|\sin(\alpha-\beta)|$$必须仔细检查。 开始于$$a=\tan\alpha,\qquad b=\tan\beta,$$我们有$$a-b = \frac{\sin(\alpha-\beta)}{\cos\alpha\cos\beta}.$$自从$\alpha,\beta\in(-\pi/2,\pi/2)$，两个余弦均为正，并且$$\sqrt{1+a^2}\sqrt{1+b^2} = \frac1{\cos\alpha\cos\beta}.$$相乘正好给出$$\rho(a,b)=|\sin(\alpha-\beta)|.$$决定因素身份也值得独立检查：$$\det(u_\alpha,u_\gamma) = \det(u_\alpha,u_\beta) + \det(u_\beta,u_\gamma).$$写作$u_\gamma=u_\beta+(u_\gamma-u_\beta)$,$$\det(u_\alpha,u_\gamma) = \det(u_\alpha,u_\beta) + \det(u_\alpha,u_\gamma-u_\beta).$$自从$$\det(u_\alpha,u_\gamma-u_\beta) = \det(u_\alpha,u_\gamma)-\det(u_\alpha,u_\beta),$$身份简化为$$\det(u_\alpha,u_\gamma) = \det(u_\alpha,u_\beta)+\det(u_\beta,u_\gamma),$$这相当于$$\det(u_\alpha-u_\beta,u_\gamma-u_\beta)=0.$$展开证实了等式。 

一个常见的错误是识别$|\sin(\alpha-\beta)|$单位圆上两点之间的距离。 实际弦长为$$2\left|\sin\frac{\alpha-\beta}{2}\right|,$$因此这种解释不会直接产生所需的三角不等式。 

## 替代方法

 替换后$a=\tan\alpha$,$b=\tan\beta$,$c=\tan\gamma$，问题就变成了$$|\sin(\alpha-\gamma)| \le |\sin(\alpha-\beta)|+|\sin(\beta-\gamma)|.$$然后可以写$$\sin(\alpha-\gamma) = \sin(\alpha-\beta)\cos(\beta-\gamma) + \cos(\alpha-\beta)\sin(\beta-\gamma)$$并应用三角不等式：$$|\sin(\alpha-\gamma)| \le |\sin(\alpha-\beta)|\,|\cos(\beta-\gamma)| + |\cos(\alpha-\beta)|\,|\sin(\beta-\gamma)|.$$由于两个余弦因子最多具有绝对值$1$,$$|\sin(\alpha-\gamma)| \le |\sin(\alpha-\beta)| + |\sin(\beta-\gamma)|.$$这个证明比较短。 行列式方法更可取，因为它揭示了背后的几何结构$\rho$：切线参数化后，$\rho$变为由两个单位向量跨越的平行四边形的定向面积的绝对值。 三角不等式就成为线性的直接结果。
