 ## 问题

 三个数字$x$,$y$,$z$满足条件$x+y+z=0$,$xyz=2$。 找出最大值$\dfrac{x^2}{y}+\dfrac{y^2}{z}+\dfrac{z^2}{x}$。 

S. 多伊切夫、R. 科扎列夫

 ## 探索

 我们被要求最大化表达$S = \frac{x^2}{y} + \frac{y^2}{z} + \frac{z^2}{x}$在约束条件下$x+y+z=0$和$xyz=2$。 第一步是考虑对称性。 这些约束表明了类似于 Viète 的有根三次方公式的关系$x$,$y$,$z$。 将第一个约束重写为$z = -x-y$允许将表达式写成两个变量：$S = \frac{x^2}{y} + \frac{y^2}{-(x+y)} + \frac{(-x-y)^2}{x}.$简化导致$S = \frac{x^2}{y} - \frac{y^2}{x+y} + \frac{(x+y)^2}{x} = \frac{x^2}{y} + \frac{(x+y)^2}{x} - \frac{y^2}{x+y}.$测试小整数似乎是不可能的，因为$xyz = 2$不是整数立方体，因此理性的例子更有希望。 我们可以尝试对称模式：也许$x = y \neq z$或者$x = -y$等设置$x=y$给出$z=-2x$和$x^2 y = x^2 x = x^3$;$xyz= x^2(-2x) = -2x^3=2$, 给予$x^3=-1$， 所以$x=-1$,$y=-1$,$z=2$。 替代产品$S = \frac{(-1)^2}{-1} + \frac{(-1)^2}{2} + \frac{2^2}{-1} = -1 + \frac{1}{2} - 4 = -\frac{9}{2}.$这是负面的。 也许$x = -y$给出$z=0$，不可能，因为$xyz=0\neq 2$。 另一种自然的猜测是尝试两个相等的正数和一个负数，例如，$x=y=a$,$z=-2a$; 我们得到$xyz=-2a^3$，等于 2 如果$a=-1$，如上所述。 另一种对称性$x=z$给出$y=-2x$， 然后$xyz=-2x^3=2$，同上。 因此最大值可能为正，表明当所有三个数字不同时就会出现极值。 

我们还可以尝试拉格朗日乘数方法。 考虑$S$作为一个函数$x$,$y$,$z$有限制$x+y+z=0$和$xyz=2$。 这导致了三个变量的三个有理方程组。 一个更对称的想法是尝试替换$z=-x-y$并定义$S$按照$x$和$y$仅有的：$S(x,y) = \frac{x^2}{y} + \frac{y^2}{-x-y} + \frac{(x+y)^2}{x}.$这仍然是有理数的，但可以简化为$S(x,y) = \frac{x^3 - y^3 + (x+y)^3}{xy(x+y)} = \frac{x^3 + 3x^2y + 3xy^2 + y^3 - y^3 + (x+y)^3?}{xy(x+y)},$这需要仔细的代数。 测试对称模式，例如$x=2$,$y=-1$,$z=-1$给出$xyz=2$和$x+y+z=0$。 然后$S = 4/(-1) + 1/(-1) + 1/2 = -4 -1 + 1/2 = -9/2$和以前一样。 

尝试$x=1$,$y=-2$,$z=1$,$xyz= -2\neq 2$;$x=2$,$y=1$,$z=-3$,$xyz=-6\neq 2$。 更有希望的模式是$x=y$,$z$负小数。 然后$x^2 z = 2 \implies z = 2/x^2$,$x+y+z = 2x + 2/x^2=0 \implies x^3 = -1$，给出前面的例子。 

因此，先前的负解是唯一具有重复数字的解。 也许最大值出现在数字不同并且数字很小时$S$大的。 例如，让$x>0$,$y>0$,$z<0$， 然后$\frac{z^2}{x} >0$,$\frac{y^2}{z}<0$,$\frac{x^2}{y}>0$。 然后$S$可以是正数，也许还很大。 

最大值的合理候选者是$y=z$,$x$消极的。 让$y=z=t>0$,$x= -2t$， 然后$xyz = -2 t^3 = 2$,$t^3 = -1$,$t=-1$,$x=2$。 然后$S = x^2 / y + y^2 / z + z^2 / x = 4/(-1) +1/1 +1/2 = -4 +1 +0.5=-2.5$，仍为负数。 

测试有理分数，$x= -1$,$y=2$,$z=-1$, 总和$0$， 产品$2$,$S = 1/2 + 4/(-1) +1/(-1) = 0.5 -4 -1=-4.5$。 仍然是负面的。 也许最大值是正数，并且在一个数字接近零时出现。 让$x\to 0^+$,$y\to +\infty$,$z\to -y$,$xyz \to -0 \cdot y \cdot (-y) =0$，无法匹配 2。因此最大值是有限的，并且当两个数字相等时可能会出现。 

尝试$x= -1$,$y = ?$,$z = ?$,$x+y+z=0$,$xyz=2$,$y+z=1$,$yz=-2$给出二次$t^2 - t -2=0$,$t=(1\pm \sqrt{1+8})/2 = (1\pm 3)/2$， 所以$t=2$或者$-1$。 然后三倍$(-1,2,-1)$或者$(-1,-1,2)$, 之前所有的,$S=-4.5$或-4.5。 对称性给出相同的负数。 因此，可以通过其他模式实现最大值。
