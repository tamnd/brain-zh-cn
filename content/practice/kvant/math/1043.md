 ## 问题

 是否可以将所有整数的集合分为三个子集，以便对于任何整数$n$,$n$,$n-50$,$n+1987$属于三个不同的子集？ 

S.V.科尼亚金

 莫斯科第 50 届城市数学奥林匹克竞赛，1987 年

 ## 重新制定

 的一个分区$\mathbb{Z}$分成三个子集由函数编码$f:\mathbb{Z}\to\mathbb{Z}_3$。 条件是对于每个整数$n$, 数字$n$,$n-50$,$n+1987$位于三个不同的子集中意味着三元组$f(n),\ f(n-50),\ f(n+1987)$由三个不同的元素组成$\mathbb{Z}_3$。 自从$\mathbb{Z}_3={0,1,2}$，这相当于每个三元组是排列的陈述${0,1,2}$。 

因此，对于每一个$n$,

 f(n)+f(n-50)+f(n+1987)=0 \quad \text{in } \mathbb{Z}_3。 \标签{1}

 ## 约束的算子表述

 在函数上定义移位运算符$\mathbb{Z}\to\mathbb{Z}_3$经过$(Tf)(n)=f(n-50), \qquad (Sf)(n)=f(n+1987).$等式（1）成为操作符恒等式

 (I+T+S)f=0。 \标签{2}

 因为两者$T$和$S$正在轮班$\mathbb{Z}$，他们上下班。 

方程(2)可以改写为

 Sf = -f - Tf。 \标签{3}

 ## 通勤轮班的一致性约束

 申请$T^{50}$(3) 的两侧。 由于轮班通勤，$T^{50}Sf = ST^{50}f.$使用（3），$T^{50}Sf = -T^{50}f - T^{100}f,$和$ST^{50}f = -T^{50}f - ST^{50}Tf = -T^{50}f - T^{1987}f - T^{2037}f.$使两个表达式相等给出$-T^{50}f - T^{100}f = -T^{50}f - T^{1987}f - T^{2037}f,$因此

 T^{100}f = T^{1987}f + T^{2037}f。 \标签{4}

 向后移动$100$产量

 f = T^{1887}f + T^{1937}f。 \标签{5}

 方程（5）是一个全局线性约束$f$。 

## 原方程的二次传播

 将 (1) 平移$1937$：

 f(n+1937)+f(n+1887)+f(n+3924)=0。 \标签{6}

 减去 (5) 评估于$n$来自（6）。 条款$f(n+1887)$取消、给予

 f(n+3924)=0 \quad \text{对于所有 } n \text{使得取消有效}。 \标签{7}

 由于涉及的移位是双射$\mathbb{Z}$，方程（7）意味着$f(n)=0 \quad \text{for all } n.$因此$f$同样为零$\mathbb{Z}_3$。 

## 最终矛盾

 如果$f(n)=0$对于所有整数$n$，那么对于每个$n$三重$f(n),\ f(n-50),\ f(n+1987)$是$(0,0,0)$因此不能由三个不同的元素组成$\mathbb{Z}_3$。 

这与分区的定义条件相矛盾。 

## 结论

 无功能$f:\mathbb{Z}\to\mathbb{Z}_3$满足身份$f(n),\ f(n-50),\ f(n+1987)\ \text{are pairwise distinct for all } n,$因此不可能将整数划分为具有所需属性的三个子集。
