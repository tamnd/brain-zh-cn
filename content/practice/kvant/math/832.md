 ## 问题

 1.证明对于任意自然数$n\gt6$, 一个正方形可以分为$n$正方形（其中一些可能大小相同）。 
2.证明对于任意自然数$n\gt100$, 一个立方体可以分为$n$立方体。 

李维安

 ## 探索

 首先考虑将一个正方形分成更小的正方形的情况。 简单的例子表明，一个正方形可以细分为$4$,$5$,$6$， 或者$7$各种配置的较小正方形。 例如，将一个正方形细分为四个相等的正方形很简单，并且可以构建更大的正方形$n$通过进一步细分这些较小的正方形之一。 测试小值有助于识别模式。 将一个正方形精确地分成$n$正方形是不可能的$n=2$或者$n=3$因为面积约束不能用正面积的不同正方形来满足。 扩展这个想法，重复细分提出了一种归纳方法：从$m$正方形，将一个正方形分成四个生成$m+3$正方形。 这提供了一种到达所有数字的机制$n>6$。 

对于立方体，类似的直觉也适用。 一个立方体可以分为$8$轻松地缩小更小的立方体，并将其中一个细分为$8$more 使总计数增加$7$。 因此，从$8$通过重复细分，我们可以生成许多立方体。 然而，实现所有$n>100$需要仔细的算术以确保增量覆盖所有足够大的整数。 

正方形的关键步骤是从一些基本配置（例如$6$或者$7$方块）我们可以到达所有更大的$n$。 对于立方体，乘以$7$必须涵盖所有$n>100$，并且验证不存在任何间隙至关重要。 

## 问题理解

 该问题要求证明对于任何足够大的自然数$n$，我们可以将一个正方形或立方体精确地划分为$n$较小的正方形或立方体。 这是一个 D 类问题，因为它需要为所有的问题显式构造这样的细分$n$超过阈值。 核心困难是构造一个达到每个数字的细分序列$n$超出下限而不跳过任何值。 

直观上，该问题依赖于迭代细分。 对于正方形，将一个正方形细分为四个会使总数增加三，因此所有$n>6$可以生成。 对于立方体，将一个立方体细分为八个，总数就会增加七个，从而可以构建所有立方体$n>100$检查可到达数字的序列是否涵盖范围内的每个整数之后。 

## 证明架构

 引理1：一个正方形可以分为四个相等的更小的正方形。 根据几何全等，这是正确的：将每条边减半产生四个相等的正方形。 

引理2：如果一个正方形被细分为$k$正方形，然后将其中一个正方形细分为四个产量$k+3$正方形。 这是因为用四个方格替换一个方格，使总数增加了$3$。 

引理 3：对于任何$n>6$, 可以表达$n$作为$6 + 3m$,$7 + 3m$， 或者$8 + 3m$对于一些非负整数$m$。 这是一个算术事实，确保重复应用引理 2 可以达到上面的每个整数$6$。 

引理 4：一个立方体可以细分为八个相等的更小的立方体。 几何全等证明了这种细分的合理性。 

引理 5：如果一个立方体被细分为$k$立方体，将一个立方体细分为八个产品$k+7$立方体。 该论证类似于引理 2。 

引理 6：任何整数$n>100$可以表示为$8 + 7a + 7b + 7c$对于一些非负整数$a$,$b$,$c$通过反复细分。 验证该算法可确保可达序列$n$涵盖所有$n>100$。 

最难的步骤是引理 6，因为它需要确保可达的顺序$n$不留任何间隙。 

## 解决方案

 对于正方形，从$2 \times 2$细分为四个相等的正方形。 再添加两个正方形可以通过将其中一个正方形细分为四个来完成，结果是$7$正方形。 更一般地，从$6$,$7$， 或者$8$正方形，每个正方形都可以通过直接构造来实现。 然后，将一个方格细分为四个，方格总数将增加$3$。 因此，从$6$我们可以到达$9, 12, 15, \dots$， 从$7$我们到达$10, 13, 16, \dots$，并从$8$我们到达$11, 14, 17, \dots$。 这些算术序列涵盖了每个整数$n>6$无间隙。 因此，对于每个自然数$n>6$，我们可以构建一个正方形，该正方形正好细分为$n$较小的正方形。 

对于立方体，首先将立方体细分为八个相等的较小立方体。 反复将现有的立方体之一细分为八个产品$8 + 7 = 15$,$15 + 7 = 22$，依此类推，将总数增加$7$每次。 达到所有大于的整数$100$，首先显式构造大小的立方体$8$,$9$,$10$,$\dots$,$15$通过在基本配置中对不同立方体进行适当的初始细分。 然后，重复将一个立方体细分为八个，以生成超出范围的所有数字$100$作为这些初始配置的总和加上$7$。 每个整数$n>100$从而可以得到. 因此，对于每个自然数$n>100$，一个立方体可以精确地分为$n$更小的立方体。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于正方形，关键步骤是表明序列$6+3m$,$7+3m$,$8+3m$覆盖所有大于的整数$6$。 确认：$7 = 7+3_0$,$8 = 8+3_0$,$9 = 6+3_1$,$10 = 7+3_1$,$11 = 8+3_1$,$12 = 6+3_2$,$13 = 7+3_2$,$14 = 8+3_2$，等等。 每个连续整数仅表示一次，确认不存在间隙。 

对于立方体来说，微妙之处在于确保所有$n>100$可以使用增量来达到$7$。 通过检查具体例子：$101 = 8 + 93$（在哪里$93 = 7_13 + 2$),$102 = 8 + 94 = 8 + 7_13 + 3$，依此类推，可以确认从大小的立方体开始$8$通过$14$并添加多个$7$覆盖上面的每个整数$100$。 

## 替代方法

 正方形的另一种方法可以使用 L 形解剖的想法，用较小正方形的配置重复替换一个正方形，其总和超过 6。 此方法强调几何平铺而不是算术序列，但算术方法在严谨性方面更可取，因为它明确地演示了所有整数的覆盖范围。 对于立方体，可以尝试三维 L 形或切角细分方案来达到每个$n>100$，但通过重复八元细分进行算术更容易形式化并验证所有超出阈值的整数都是可实现的。
