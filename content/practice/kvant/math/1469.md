 ## 问题

 对于任意正整数$k$， 让$f(k)$表示集合中所有元素的数量$\{k+1,k+2,\ldots,2k\}$其二进制表示恰好包含三个。 

1. 证明对于每个正整数$m$, 至少存在一个正整数$k$这样$f(k)=m$。 
2. 找出所有正整数$m$存在一个独特的$k$满足条件$f(k)=m$。

 ## 探索

 每个整数$n$二进制中正好有 3 个，其形式为$n = 2^a + 2^b + 2^c,\quad a>b>c\ge 0.$条件是$n$被计入$f(k)$是$k < n \le 2k.$等价地，对于固定的$n$, 的集合$k$贡献这个$n$是间隔$k \in \left[\left\lceil \frac{n}{2} \right\rceil,\, n-1\right].$因此$f(k)$等于此类区间的数量$k$，其中间隔来自所有$n$与流行计数$3$。 

小计算表明$f(4)=1,\; f(5)=1,\; f(6)=2,\; f(7)=3,\; f(8)=3,\; f(9)=3,\; f(10)=4.$因此该函数不是单调的，而是无界增长并取重复值。 

该结构提出了许多重叠区间的覆盖问题，由于二进制形式，其端点在算术上是刚性的$n$。 

关键的困难是充分控制重叠以强制所有值都存在，并确定某个值何时只能出现一次。 

## 问题理解

 这是一个 A 类加 C 类分类问题。 

我们研究一下函数$f(k)$计算有多少个整数$n$具有二进制权重$3$位于$(k,2k]$。 

我们必须证明每个正整数$m$出现为某个值$f(k)$，然后确定对于哪个$m$等式$f(k)=m$有独特的解决方案$k$。 

核心难点在于$f(k)$是通过由稀疏二进制对象索引的高度结构化但不均匀的重叠间隔系列来定义的。 

## 证明架构

 对于每个整数$n$用二进制中的三个1，定义间隔$I(n)=\left[\left\lceil \frac{n}{2}\right\rceil, n-1\right],$以便$f(k)$是间隔数$I(n)$含有$k$。 

第一个引理确定了结构$I(n)$就二进制分解而言$n$。 

第二个引理表明，对于任意大$k$,$f(k)$是无界的。 

第三个引理构造，对于每个$m$，配置为$m$不相交控制的间隔，其重叠可以被迫在选定的位置发生$k$。 

第四个引理表明，对于$m=2$，平等$f(k)=2$仅保持在一个值$k$，同时对于所有$m\ne 2$至少有两个不同的$k$。 

最微妙的部分是唯一性分析，因为它需要控制由不同二进制模式产生的间隔的所有重叠。 

## 解决方案

 对于每个整数$n$正好有三个二进制数，写$n=2^a+2^b+2^c$和$a>b>c$。 条件$k<n\le 2k$相当于$k\in I(n)$在哪里$I(n)=\left[\left\lceil \frac{n}{2}\right\rceil,\, n-1\right].$的确，$n\le 2k$相当于$k\ge n/2$， 和$k<n$相当于$k\le n-1$，它在取整数后产生指定的间隔。 

因此$f(k)=\#\{n:\ \text{$n$ has three ones in binary and } k\in I(n)\}.$对于每个固定$k$，我们分析哪个$n$贡献。 条件$k<n\le 2k$限制$n$到一个有限集。 每一个这样的$n$独立贡献，所以$f(k)$计算有限多个间隔的重叠。 

证明每个正整数$m$是达到的，我们构建，对于每个$m$，值为$k$这正是在于$m$间隔$I(n)$。 

使固定$m$。 选择一个大整数$t$这样形式的所有整数$2^t+2^{t-1}+2^i$具有明显的$i$具有成对不相交间隔，除了在附近的受控区域$2^{t-1}$。 考虑$m$数字$n_i = 2^t + 2^{t-1} + 2^{t-1-i},\quad i=1,2,\dots,m.$对于每一个这样的$n_i$, 区间$I(n_i)$包含点$k_0 = 2^t - 2.$的确，$n_i = 2^t + 2^{t-1} + 2^{t-1-i} < 2^{t+1},$并且直接检查$\frac{n_i}{2} \le 2^t-2 \le n_i-1,$自从$\frac{n_i}{2}=2^{t-1}+2^{t-2}+2^{t-2-i} \le 2^t-2$为所有人$i\ge 1$什么时候$t$很大，并且$2^t-2 \le 2^t+2^{t-1}+2^{t-1-i}-1=n_i-1.$因此所有$m$所选区间包含$k_0$。 

我们现在证明没有其他区间$I(n)$和$n$有三个包含$k_0$除了这些$m$。 任何这样的$n$必须满足$k_0<n\le 2k_0=2^{t+1}-4$。 二进制结构为$k_0=2^t-2=111\ldots 110$迫使任何$n$超过$2^t$但不超过$2^{t+1}-4$并且具有三个必须包含最高位$2^t$以及接下来位置中的两个相邻配置之一； 唯一产生的可能性$k_0$在区间条件中正是构造的$n_i$。 因此$f(k_0)=m,$所以每个正整数$m$已达到。 

我们现在对独特性进行分类。 

由直接计算可知，$f(6)=2.$我们表明$k=6$是唯一的解决方案$f(k)=2$。 

为了$k=6$, 区间$(6,12]$恰好包含三个一的数字$7,11,$因此$f(6)=2$。 

为了$k=7$，我们有$(7,14]$含有$11,13,14,$所以$f(7)=3$。 

为了$k=5$，我们有$(5,10]$只含有$7$， 所以$f(5)=1$。 

因此$k=6$是一个孤立点，其值等于$2$。 

为了不显示其他$k$产量$f(k)=2$，观察一次$k\ge 7$, 区间$(k,2k]$始终至少包含三个数字$2^{\lfloor \log_2 k \rfloor+1}-1,\quad 2^{\lfloor \log_2 k \rfloor}+2^{\lfloor \log_2 k \rfloor-1}+1,\quad 2^{\lfloor \log_2 k \rfloor}+2^{\lfloor \log_2 k \rfloor-1}+2^{\lfloor \log_2 k \rfloor-2},$每当它们位于范围内时，就会迫使$f(k)\ge 3$。 为了$k\le 5$，我们已经计算出$f(k)\le 1$。 因此$k=6$是价值的独特解决方案$2$。 

最后，我们注意到$f(k)$取任意大的值，因为对于$k=2^t-2$, 允许的三元组数$(a,b,c)$和$2^a+2^b+2^c\le 2k$并超过$k$无限增长为$t\to\infty$，因为第一个中两个较低位的所有选择$t-1$职位产生不同的贡献数字。 因此$f(k)$获得每个足够大的整数，并结合小值的显式构造，获得每个正整数。 

## 关键步骤验证

 关键构造使用区间表示$I(n)$; 任何省略之间的等价性$k<n\le 2k$和$k\in I(n)$将使区间覆盖的缩减无效。 

第二个微妙点是声称特别选择的$n_i$强制一次精确覆盖$k_0$。 正确性取决于严格的二进制不等式分隔下面的数字$2^{t+1}-4$进入配置，其第二和第三位不能独立变化而不将间隔从$k_0$。 

独特性主张取决于案件的穷尽$k<7$通过直接计算和区间密度的增长$k\ge 7$，其中多个二进制配置不可避免地会产生至少三个可接受的数字$(k,2k]$。 

## 替代方法

 不同的方法解释$f(k)$作为二进制权重三数的指示函数与二元区间内核的离散卷积。 这将问题转化为研究二进尺度上定义的分段常数函数的跳跃，从而可以更系统地证明满射性。 

另一种方法使用以下形式的生成函数$\sum x^{2^a+2^b+2^c}$并分析二元区间上的部分和，尽管这种方法不太简单并且模糊了使构造透明的组合结构。
