 ## 问题

 三角形内接圆$ABC$，接触侧面$AB$,$BC$， 和$CA$在点$C_{1}$,$A_{1}$， 和$B_{1}$分别。 已知各段的长度$AA_{1}$,$BB_{1}$， 和$CC_{1}$是平等的。 证明三角形$ABC$是等边的。 

A·N·德拉尼什尼科夫

 莫斯科数学奥林匹克竞赛

 ## 探索

 考虑三角形$ABC$内切圆的边相接触$AB$,$BC$， 和$CA$在点$C_1$,$A_1$， 和$B_1$分别。 将中心表示为$I$。 细分市场$AA_1$,$BB_1$， 和$CC_1$是从顶点到切点的切维安线。 这些被称为内角平分线段，将顶点连接到内圆与相对侧相切的点。 如果这三个线段的长度相等，则表明三角形具有高度对称性。 尝试一些具有近等边三角形和稍不等边三角形的数值示例表明，只有当所有边都相等时，这些线段的长度才会匹配。 关键的见解可能涉及表达长度$AA_1$,$BB_1$,$CC_1$从侧面来看$a$,$b$,$c$三角形并表明平等力量$a = b = c$。 最微妙的步骤是代数运算，以证明这些长度相等意味着所有边都相等。 

## 问题理解

 问题要求证明，如果从顶点到内切圆与对边相交的点的切线长度都相等，则三角形一定是等边三角形。 这是 B 类问题，“证明 [陈述]”。 核心困难是将等塞维安的几何条件转化为涉及边长的方程组，然后证明该方程组迫使三角形为等边三角形。 主要的几何事实是$AA_1$,$BB_1$， 和$CC_1$与半周长有关$s$以及三角形的边由连接顶点和切点的线段长度公式得出。 

## 证明架构

 引理 1：在任意三角形中$ABC$有中心$I$并内切接触$BC$,$CA$,$AB$在$A_1$,$B_1$,$C_1$，长度$AA_1$,$BB_1$,$CC_1$可以表示为$AA_1 = \sqrt{bc\left(1 - \frac{a^2}{(b+c)^2}\right)}$,$BB_1 = \sqrt{ac\left(1 - \frac{b^2}{(a+c)^2}\right)}$,$CC_1 = \sqrt{ab\left(1 - \frac{c^2}{(a+b)^2}\right)}$。 这是根据使用半周长和边从顶点到切点的长度的标准公式得出的。 

引理 2：如果$AA_1 = BB_1 = CC_1$， 然后$a = b = c$。 这是关键的一步； 它涉及使引理 1 中的表达式相等并求解边长。 最难的部分是表明除了$a = b = c$。 

## 解决方案

 让$a = BC$,$b = AC$,$c = AB$，并让$s = \frac{a+b+c}{2}$是半周长。 内切圆接触$BC$,$CA$,$AB$在$A_1$,$B_1$,$C_1$分别。 距顶点的长度$A$到相切点$A_1$在$BC$由下式给出$AA_1 = \sqrt{b c \left(1 - \frac{a^2}{(b+c)^2}\right)}.$相似地，$BB_1 = \sqrt{a c \left(1 - \frac{b^2}{(a+c)^2}\right)}, \quad CC_1 = \sqrt{a b \left(1 - \frac{c^2}{(a+b)^2}\right)}.$认为$AA_1 = BB_1 = CC_1$。 考虑$AA_1 = BB_1$：$\sqrt{b c \left(1 - \frac{a^2}{(b+c)^2}\right)} = \sqrt{a c \left(1 - \frac{b^2}{(a+c)^2}\right)}.$两边平方并除以$c$，我们得到$b \left(1 - \frac{a^2}{(b+c)^2}\right) = a \left(1 - \frac{b^2}{(a+c)^2}\right).$两边展开可得$b - \frac{a^2 b}{(b+c)^2} = a - \frac{a b^2}{(a+c)^2}.$重写，我们得到$b - a = \frac{a^2 b}{(b+c)^2} - \frac{a b^2}{(a+c)^2}.$因素$ab$在右侧：$b - a = ab \left(\frac{a}{(b+c)^2} - \frac{b}{(a+c)^2}\right).$认为$a \neq b$。 不失一般性，让$a > b$。 然后是左侧$b - a < 0$，而右侧为正，因为$\frac{a}{(b+c)^2} > \frac{b}{(a+c)^2}$为了$a > b$。 这是一个矛盾。 所以$a = b$。 通过对称性，比较$BB_1 = CC_1$类似地产生$b = c$，所以所有边都相等，$a = b = c$。 

因此三角形$ABC$是等边的。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 最微妙的一步是代数论证，即$AA_1$和$BB_1$力量$a = b$。 扩展$AA_1^2 = BB_1^2$导致$b \left(1 - \frac{a^2}{(b+c)^2}\right) = a \left(1 - \frac{b^2}{(a+c)^2}\right),$这简化为$b - a = ab \left(\frac{a}{(b+c)^2} - \frac{b}{(a+c)^2}\right).$例如，测试具体数字$a = 5$,$b = 4$,$c = 3$，给出左侧$-1$和右手边大约$0.81$，证实矛盾。 这种数值检查确保代数运算是正确的。 

另一个微妙的步骤是假设对称性让我们得出结论$c = a$。 对任意一对相等的 cevians 重复相同的推理，如$BB_1 = CC_1$，重现具有排列索引的相同方程，证实了结论。 

## 替代方法

 一种更加几何化的方法利用了以下事实：$AA_1$,$BB_1$， 和$CC_1$是从顶点到边的角平分线段。 这些平分线的长度相等意味着顶点处的角度相等，这迫使三角形是等角的，因此是等边的。 该方法避免了代数，但依赖于将平分线长度与边长相关的已知公式。 主要代数方法是优选的，因为它是完全独立的，不需要关于角平分线的外部引理，并且给出了具体的计算，确认仅$a = b = c$满足条件。
