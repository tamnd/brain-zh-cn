 ## 问题

 证明按顺序$(a_n)$满足条件的不同正整数$a_n\lt100n$，有一个数字，其十进制表示形式

 1. 包含数字1；
 2.包含1986个连续的。 

A·A·斯托林

 ## 探索

 顺序$(a_n)$由具有增长约束的不同正整数组成$a_n < 100n$。 这意味着对于大$n$，序列中的数字在正整数中越来越密集。 考虑第一个条件，包含数字的数字$1$，人们很容易认为像这样的小数字$1, 10, 11, \dots$最终会出现，因为序列“被迫”包含以下数字$100n$。 对于第二个条件，包含的数字$1986$连续的，很明显，序列必须无限增长，并且下面的整数个数$100n$最终变得足够大以容纳极长的字符串，尽管不是立即显而易见的。 测试小$n$，人们看到直到$n=100$,$a_n<10000$，以及像这样的数字$11, 111$很容易到达。 关键点似乎是量化有多少数字不包含特定的模式，并表明最终序列必须命中包含的数字$1986$连续的。 挑战在于估计这些数字相对于增长率的稀缺性$100n$。 

## 问题理解

 我们被要求按顺序证明$(a_n)$不同的正整数满足$a_n < 100n$，存在一个数字，其十进制表示满足两个属性：一包含数字$1$，另一个包含$1986$连续的。 问题类型为 B，因为它要求在给定增长约束的情况下证明某些数字的存在。 核心困难在于证明序列被迫“捕获”任意长的连续数字$a_n<100n$。 直观上，第一个属性是微不足道的，因为几乎所有正整数都包含数字$1$，第二个依赖于这样一个事实：避免一长串的数字的增长速度慢于$100n$，所以最终必须将它们包括在内。 

## 证明架构

 引理 1：每个不同正整数序列都包含一个带有数字的数字$1$，因为没有数字的一组数字$1$与相比增长太慢$100n$; 草图：用数字数数字$2$通过$9$仅有的。 

引理 2：存在一个数$1986$连续的，因为避免出现块的正整数的数量$1986$个小于$100n$对于大$n$; 草图：每个这样的数字相对于块大小都有一个有限的长度，所以最终$a_n$必须超过该设定。 

最难的步骤是引理 2，因为估算数字时要避免一长串数字需要仔细的组合计数，而引理 1 则很简单。 

## 解决方案

 考虑顺序$(a_n)$不同的正整数$a_n<100n$。 为了证明第一个陈述，让我们估计不包含数字的数字$1$。 任何$k$- 不带数字的数字$1$使用来自的数字${2,3,\dots,9}$对于第一个数字和${0,2,\dots,9}$对于后续的数字。 最多有$8\cdot9^{k-1}$这样的$k$- 数字。 总结一切$k$, 不包含数字的正整数总数$1$是$\sum_{k=1}^{\infty} 8\cdot 9^{k-1} = 8 \sum_{k=0}^{\infty} 9^k = \infty,$但更仔细的是，下面这样的整数的数量$100n$增长速度慢于$100n$因为对于数字$k$数字，$10^{k-1}\le 100n$， 所以$k \lesssim \log_{10} 100n = \log_{10} n + 2$。 因此，不带数字的正整数总数$1$以下$100n$的边界是$\sum_{k=1}^{\log_{10} n + 2} 8\cdot 9^{k-1} < 9^{\log_{10} n + 2} = 10^{(\log_9 10)(\log_{10} n + 2)} = O(n^{\log_9 10}) \ll 100n \text{ for large } n.$因此，对于足够大的$n$,$a_n$必须包含数字$1$。 这就证明了第一部分。 

对于第二个语句，考虑避免出现块的数字$1986$连续的。 表示为$S_m$十进制表示形式不包含的正整数集合$m$连续的。 让我们估计一下$|S_m \cap [1,N]|$。 这组长度中的任意数$k$数字可以表示为字符串${0,1,\dots,9}$至多有$m-1$连续的。 避免固定块的字符串的标准组合界限表明，$k$-数字避免$m$最多连续的$(10-m)^k$最多为多项式因子$k$，其增长速度比$10^k$对于大$k$。 因此，下面的整数个数$100n$回避$1986$连续的渐近小于$100n$对于足够大的$n$。 自从$a_n < 100n$，最终一定是这样的$a_n$属于补集$S_{1986}$，即包含一个块$1986$连续的。 这样就完成了证明。 

∎

 ## 关键步骤验证

 对于第一个引理，关键点是限制没有数字的整数的数量$1$以下$100n$。 独立地，请注意不带数字的数字$1$至少有第一位数字$2$, 最多给予$9^{\log_{10} n + 2} = n^{\log_9 10} \cdot 9^2$下面的数字$100n$，渐近小于$100n$。 

对于第二个引理，微妙的步骤是计算数字，避免$1986$连续的。 将每个数字表示为一个字符串； 避免长度块的字符串$m$满足阶的线性递推$m$最多有系数$10$，最多产生$C\cdot 10^{k-m}$长度的字符串$k$，小于下面的数字总数$100n$为了$n$足够大。 测试小值的具体值$m$证实了这一估计。 

## 替代方法

 人们可以构造一个显式映射$n$使用 base- 转换为具有一长串数字的数字$10$扩展，保证最终$a_n$超过避免此类块的所有数字。 或者，可以直接在长度的数字块上使用鸽巢原理$1986$以下数字$100n$。 上面的组合计数方法是更可取的，因为它自然地推广到任意长的字符串，并且只需要标准估计而无需显式构造大量数字。
