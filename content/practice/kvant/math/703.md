 ## 问题

 求解方程组$$\left\{\begin{array}{l} 3\left(x+\dfrac{1}{x}\right)=4\left(y+\dfrac{1}{y}\right)=5\left(z+\dfrac{1}{z}\right),\\ xy+yz+zx=1. \end{array}\right.$$A·费奥多罗夫

 ## 探索

 第一个方程链接了以下形式的三个表达式$t + \frac{1}{t}$乘以常数 3、4 和 5。 表示$u = x + \frac{1}{x}$,$v = y + \frac{1}{y}$,$w = z + \frac{1}{z}$，系统简化为$3u = 4v = 5w$。 这表明了比率$\frac{u}{v} = \frac{4}{3}$,$\frac{u}{w} = \frac{5}{3}$等各方程$t + \frac{1}{t} = \text{constant}$可以重写为二次$t$，给每个变量两个根。 

第二个方程，$xy + yz + zx = 1$，对称于$x, y, z$。 一种自然的方法是表达$x, y, z$通过$u, v, w$，然后在两两乘积之间施加线性关系。 小整数或简单分数$x, y, z$给定整数常数 3, 4, 5，可以产生有理乘积和。解集很可能是有限的，并且可能涉及像这样的倒数$1$或者$-1$。 

一个看似合理的关键见解是$x, y, z$必须满足$x + 1/x = 4/3 y + 1/y = 5/3 z + 1/z$; the ratios of the constants might suggest a proportionality among the variables themselves, possibly$x : y : z = 1 : 1 : 1$或者$x : y : z = 1 : 2 : 3$，但是两两乘积和$xy + yz + zx = 1$限制了这些猜测。 最微妙的步骤是确保在求解每个二次方程时不会丢失解$x, y, z$。 

## 问题理解

 问题要求找到所有实数三元组$(x, y, z)$两者都满足$3(x + \frac{1}{x}) = 4(y + \frac{1}{y}) = 5(z + \frac{1}{z})$和$xy + yz + zx = 1$。 这是一个 A 类问题：一个分类问题，需要验证任何声称的解决方案有效，并证明不存在其他解决方案。 

核心难点在于处理第一个方程，该方程连接三个非线性表达式，同时满足乘积的对称二次约束。 答案可能由一小组有限的有理数或简单代数数组成，这些数是通过求解二次形式得出的$t + 1/t = \text{constant}$并执行$xy + yz + zx = 1$。 

启发式地，人们期望解决方案涉及这样的数字：$x = y = z$或具有较小整数比的数字，因为倒数项之和必须成有理比例。 

## 证明架构

 引理 1：如果$3(x + 1/x) = 4(y + 1/y) = 5(z + 1/z)$， 然后$x + 1/x$,$y + 1/y$， 和$z + 1/z$为正且成比例。 草图：表示共同值$k = 3(x + 1/x) = 4(y + 1/y) = 5(z + 1/z)$; 然后$x + 1/x = k/3$,$y + 1/y = k/4$,$z + 1/z = k/5$。 

引理 2：对于每个正数$k$，方程$t + 1/t = k/c$至多有两个实数解，一个大于 1，一个在 0 和 1 之间。草图：函数$f(t) = t + 1/t$严格递减$(0,1]$并严格增加$[1, \infty)$，达到最小值$t = 1$，所以每个$k/c \ge 2$产生两个正解。 

引理 3：方程$xy + yz + zx = 1$限制符号和大致尺寸$x, y, z$。 示意图：如果所有变量都为正，则每个二次解必须产生两两乘积之和为 1 的数字。负解导致乘积之和小于零，这是不可能的。 

引理 4：唯一的解三元组出现在$x, y, z$都是积极的。 草图：检查符号模式表明任何负分量违反了乘积和相等。 

引理 5：使用显式求解$x = k/3 - 1/x$,$y = k/4 - 1/y$,$z = k/5 - 1/z$，然后代入$xy + yz + zx = 1$并解决$k$产生有限多个候选者。 草图：将每个变量表示为其二次方的正根，并将乘积和减少为四次方$k$，然后找到与所有正性约束兼容的唯一解。 

最难的步骤是引理 5，因为它需要显式计算和验证负根不存在其他解。 

## 解决方案

 让$k$表示第一个方程中的公共值，因此$k = 3(x + 1/x) = 4(y + 1/y) = 5(z + 1/z)$。 然后$x + 1/x = k/3$,$y + 1/y = k/4$， 和$z + 1/z = k/5$。 每个方程$t + 1/t = m$是二次方：$t^2 - m t + 1 = 0$。 所以，$x$满足$x^2 - (k/3)x + 1 = 0$,$y^2 - (k/4)y + 1 = 0$,$z^2 - (k/5)z + 1 = 0$。 

对于每个二次方，判别式是$\Delta_x = (k/3)^2 - 4$,$\Delta_y = (k/4)^2 - 4$,$\Delta_z = (k/5)^2 - 4$。 对于真正的解决方案，每个判别式必须是非负的。 因此$k/3 \ge 2 \implies k \ge 6$,$k/4 \ge 2 \implies k \ge 8$,$k/5 \ge 2 \implies k \ge 10$。 仅当满足所有三个不等式时$k \ge 10$。
