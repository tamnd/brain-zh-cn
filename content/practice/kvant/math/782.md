 ## 问题

 证明如果两个自然数之和等于$30\,030$，那么他们的乘积不能被整除$30\,030$。 

S.V.福明

 ## 探索

 让$a+b=30030$和$a,b\in \mathbb{N}$。 假设矛盾的是$30030 \mid ab$。 由于在整数线性组合下保留了数字的整除性，因此考虑$$(a+b)^2 - 4ab = a^2 + 2ab + b^2 - 4ab = a^2 - 2ab + b^2 = (a-b)^2.$$因为$30030 \mid (a+b)$和$30030 \mid ab$，由此可知$30030 \mid (a-b)^2$。 

数量$30030 = 2\cdot 3\cdot 5\cdot 7\cdot 11\cdot 13$是无平方的，所以平方的整除力迫使底数整除，因此$30030 \mid (a-b)$。 

现在两者$a+b$和$a-b$是的倍数$30030$，这强烈限制了$a$和$b$。 写作$a$和$b$就总和和差而言，表明它们以$15015$，导致结构非常刚性。 检查与自然数的兼容性将确定是否存在任何有效的对，以及假设的整除性是否实际上可以发生。 

## 问题理解

 这是一个B 类问题。 

我们必须证明，每当两个自然数之和等于$30030$，它们的乘积不能被整除$30030$。 

关键的难点在于条件$30030 \mid ab$与固定总和约束相互作用，对差值施加强整除条件$a-b$，最终过度约束这对$(a,b)$。 

## 证明架构

 证明使用身份$(a-b)^2 = (a+b)^2 - 4ab$。 

首先，我们证明如果$30030 \mid a+b$和$30030 \mid ab$， 然后$30030 \mid (a-b)^2$。 

其次，我们用它$30030$是无平方的，所以$30030 \mid x^2$意味着$30030 \mid x$。 

第三，我们推论$30030 \mid (a-b)$。 

第四，我们参数化$a$和$b$通过和与差并分析完整性和正性约束。 

最微妙的一点是从可分性的转变$(a-b)^2$的整除性$(a-b)$使用无平方结构$30030$。 

## 解决方案

 让$a,b\in\mathbb{N}$满足$a+b=30030$。 假设$30030 \mid ab$。 

考虑身份$$(a-b)^2 = (a+b)^2 - 4ab.$$自从$30030 \mid (a+b)$，由此可知$30030 \mid (a+b)^2$。 自从$30030 \mid ab$，由此可知$30030 \mid 4ab$。 所以$30030$除以它们的差异，因此$$30030 \mid (a-b)^2.$$数量$$30030 = 2\cdot 3\cdot 5\cdot 7\cdot 11\cdot 13$$是不同素数的乘积。 让$p$是这些素数中的任何一个。 从$30030 \mid (a-b)^2$由此可见$p \mid (a-b)^2$， 因此$p \mid (a-b)$。 因为这对于每个素因数都成立$30030$，由此可知$$30030 \mid (a-b).$$因此存在一个整数$k$这样$a-b = 30030k$。 解决系统$$a+b=30030,\quad a-b=30030k$$给出$$a = 15015(1+k),\quad b = 15015(1-k).$$自从$a,b$是自然数，两个表达式都必须是正整数。 表达式为$b$意味着$1-k>0$， 因此$k\le 0$。 

如果$k=0$， 然后$a=b=15015$， 和$$ab = 15015^2.$$自从$30030 = 2\cdot 15015$，整除性$15015^2$经过$30030$需要除以$2$，这是不可能的，因为$15015^2$很奇怪。 因此$30030 \nmid ab$在这种情况下。 

如果$k<0$， 写$k=-m$和$m\in\mathbb{N}$。 然后$$b = 15015(1+m),$$但条件$b>0$适合所有人$m\ge 1$， 尽管$$a = 15015(1-m).$$为了$m\ge 1$，这给出了$a\le 0$，与假设相矛盾$a$是一个自然数。 不可能出现这种情况。 

因此没有一对自然数的和$30030$可以满足$30030 \mid ab$。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 转型的步骤$30030 \mid a+b$和$30030 \mid ab$进入$30030 \mid (a-b)^2$使用直接代数恒等式，右侧的两项都是$30030$，所以它们的区别也是如此。 

过渡从$30030 \mid (a-b)^2$到$30030 \mid (a-b)$依赖于素因数分解$30030$。 对于任意素数$p$划分$30030$，条件$p \mid (a-b)^2$力量$p \mid (a-b)$， 自从$p$是素数。 将其应用于所有六个不同的素数可以得到它们的乘积的整除性。 

通过直接代入线性系统来检查参数化步骤，确保在表达时不会出现算术不一致$a$和$b$。 

## 替代方法

 一种替代方法直接对每个素因数取模$30030$。 假设$30030 \mid ab$和$a+b=30030$, 可以减少模数$p$对于每个$p\in{2,3,5,7,11,13}$并表明$a\equiv 0$或者$b\equiv 0 \pmod p$同时对所有素数施加不相容的约束。 

另一种方法通过设置使用对称性$a=15015+x$,$b=15015-x$并分析状况$30030 \mid (15015^2-x^2)$，这会导致相同的限制$30030 \mid x^2$因此$x$可除以$30030$，通过符号约束崩溃为相同的矛盾。
