 ## 问题

 呈三角形$ABC$，角平分线$BL$和$AK$被绘制。 事实证明$KL$是三角形的角平分线$AKC$。 找到角度$BAC$。 

S·I·托卡列夫

 城镇锦标赛（1997 年春季）

 ## 探索

 让$BL$是内角平分线$B$会议$AC$在$L$， 和$AK$是内角平分线$A$会议$BC$在$K$。 条件表明在三角形中$AKC$, 段$KL$是内角平分线$\angle AKC$， 所以$L$位于$AC$和$KL$按比例将相对边除以相邻边。 

这引入了三个角平分线约束：一个在三角形中$ABC$在$A$，一处$B$，第三个三角形$AKC$链接$K$和$L$。 该结构建议通过边长来表达段比并增强它们之间的兼容性。 

让$AB=c$,$BC=a$,$CA=b$。 未知的关键是$\angle BAC = A$。 决定性的一步是表达$AK/KC$通过平分线在$A$并将其与$AL/LC = AB/BC$由平分线产生$B$。 这将几何条件转换为三角方程$A$。 

最微妙的一点是保证三角形的平分线条件$AKC$正确地转换为一个比率$AC$并与三角形一致匹配$ABC$边长。 

## 问题理解

 这是一个 A 类问题：确定所有可能的值$\angle BAC$。 

呈三角形$ABC$，两个标准角平分线定义点$K$在$BC$和$L$在$AC$。 附加条件规定$KL$是三角形的角平分线$AKC$在顶点$K$。 

任务是将这种几何并发条件转换为边比的代数约束，这迫使$\angle BAC$。 推导必须证明构形的必要性和存在性。 

## 证明架构

 一、表达$AL/LC$使用三角形的角平分线定理$ABC$, 给予$AL/LC = AB/BC$。 

接下来，表达条件$KL$一分为二$\angle AKC$呈三角形$AKC$，产生$AL/LC = AK/KC$。 

然后计算$AK$和$KC$按照$a,b,c$使用角平分线定理$A$呈三角形$ABC$，得到$KC = \frac{ab}{b+c}$和$AK = \frac{2bc\cos(\frac{A}{2})}{b+c}$。 

使两个表达式相等$AL/LC$产生一个三角方程$A$独自的。 为了确保完整性，我们还必须验证三角形$\angle A = 120^\circ$实际上满足所有平分线条件。 

## 解决方案

 让$AB=c$,$BC=a$,$CA=b$，并让$\angle BAC = A$。 

自从$BL$是内角平分线$\angle B$呈三角形$ABC$，角平分线定理给出$\frac{AL}{LC} = \frac{AB}{BC} = \frac{c}{a}.$现在考虑三角形$AKC$。 条件表明$KL$是内角平分线$\angle AKC$，因此根据三角形的角平分线定理$AKC$,$\frac{AL}{LC} = \frac{AK}{KC}.$将两个等式组合起来$\frac{AL}{LC}$产量$\frac{AK}{KC} = \frac{c}{a}.$我们现在计算$AK$和$KC$。 

自从$AK$是内角平分线$\angle A$呈三角形$ABC$，角平分线定理给出$\frac{BK}{KC} = \frac{AB}{AC} = \frac{c}{b},$所以$KC = \frac{ab}{b+c}.$角平分线的标准长度公式为$A$给出$AK = \frac{2bc\cos\left(\frac{A}{2}\right)}{b+c}.$所以，$\frac{AK}{KC} = \frac{\frac{2bc\cos\left(\frac{A}{2}\right)}{b+c}}{\frac{ab}{b+c}} = \frac{2c\cos\left(\frac{A}{2}\right)}{a}.$将此等同于$\frac{c}{a}$产量$\frac{2c\cos\left(\frac{A}{2}\right)}{a} = \frac{c}{a}.$自从$a>0$和$c>0$，我们取消得到$2\cos\left(\frac{A}{2}\right) = 1,$所以$\cos\left(\frac{A}{2}\right) = \frac{1}{2}.$因此$\frac{A}{2} = 60^\circ,$这给出了$A = 120^\circ.$为了验证存在性，我们检查一个三角形$\angle A = 120^\circ$可以满足所有平分关系。 根据余弦定律，$a^2 = b^2 + c^2 - 2bc\cos A = b^2 + c^2 + bc,$所以$a = \sqrt{b^2 + bc + c^2}.$平分线长度则满足$KC = \frac{ab}{b+c} = \frac{b \sqrt{b^2 + bc + c^2}}{b+c}, \qquad AK = \frac{2bc\cos(60^\circ)}{b+c} = \frac{bc}{b+c}.$然后$\frac{AK}{KC} = \frac{bc/(b+c)}{b\sqrt{b^2 + bc + c^2}/(b+c)} = \frac{c}{\sqrt{b^2 + bc + c^2}} = \frac{c}{a},$与之前的比例一致。 相似地，$\frac{AL}{LC} = \frac{c}{a}$和以前一样，所以$KL$确实一分为二$\angle AKC$。 这确认配置存在并满足所有条件。 

因此，满足给定构型的唯一角度是$\boxed{120^\circ}.$## 关键步骤验证

 鉴定$\frac{AL}{LC} = \frac{AK}{KC}$直接从应用三角形的角平分线定理得出$AKC$到$KL$， 自从$L$位于$AC$和$K$是平分角的顶点。 

的计算$KC$依赖于三角形的标准角平分线定理$ABC$, 给予$BK:KC = AB:AC$。 

公式为$AK$与将平分线投影到对边得到的平分线长度关系一致。 替换产生的比率仅取决于$A$，并验证相反情况表明该配置存在$A = 120^\circ$。 

## 替代方法

 还可以使用三线坐标或重心坐标来解决该问题，其中条件$KL$是角平分线，转换为坐标之间的线性关系$K$和$L$，导致边比齐次方程减少为三角约束$\angle A$。 

另一种方法使用定向角和 Ceva 型关系，应用两次，一次在$ABC$一旦进入$AKC$，消除没有明确长度公式的段比率。 三角平分线长度法较短，因为它将条件立即简化为单个方程$\angle A$并允许直接验证存在。
