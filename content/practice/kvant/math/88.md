 ## 问题

 系数必须满足什么条件$a$,$b$,$c$方程的$x^3+ax^2+bx+c=0$满足其三个根构成算术级数？ 

M·F·别兹博罗德尼科夫

 ## 探索

 考虑三次多项式$x^3+ax^2+bx+c=0$并假设它的根形成一个算术级数。 将根表示为$r-d$,$r$， 和$r+d$， 在哪里$r$是中根并且$d$是共同的区别。 标准 Vieta 公式给出$r_1+r_2+r_3=-a$,$r_1r_2+r_1r_3+r_2r_3=b$,$r_1r_2r_3=-c$。 替代$r_1=r-d$,$r_2=r$,$r_3=r+d$，我们发现$r_1+r_2+r_3 = 3r$， 所以$r=-a/3$。 然后$r_1r_2+r_1r_3+r_2r_3 = (r-d)r + (r-d)(r+d) + r(r+d) = 3r^2 - d^2$。 因此$b=3r^2-d^2$。 根的乘积为$r_1r_2r_3 = (r-d)r(r+d) = r(r^2-d^2)$， 所以$-c=r^3 - r d^2$。 候选条件是$a^2-3b=9d^2$。 这抓住了本质，但要验证的关键点是根的顺序或可能的简并性（例如$d=0$）引入隐藏案例。 测试小数值示例，例如根$-1,0,1$和$1,2,3$确认模式：$b=-3d^2$什么时候$a=0$和$r=0$，并且一般来说$b=3r^2 - d^2$,$c=-r(r^2-d^2)$。 

最有可能隐藏错误的步骤是表达$b$和$c$按照$a$单独而不失一般性，并确保$d$正确表达以将其从最终条件中消除。 

## 问题理解

 该问题要求系数的充分必要条件$a$,$b$,$c$三次多项式的$x^3+ax^2+bx+c=0$使得它的三个根形成一个算术级数。 这是一个 A 类问题，因为它需要精确表征所有系数三元组$(a,b,c)$满足属性。 核心难点是消除辅助变量$d$（级数的共同差异）获得纯粹的关系$a$,$b$， 和$c$。 直观地说，算术级数的对称性表明$b$和$c$必须满足涉及的关系$a$， 具体来说$a^2 - 3b$和$c$呈立方体状组合。 

## 证明架构

 引理1：如果三个数构成等差数列，则中间的数等于这三个数的平均值。 这是从算术级数的定义得出的。 

引理 2：将立方根表示为$r-d$,$r$,$r+d$, Vieta 的公式给出$a=-3r$,$b=3r^2-d^2$,$c=-r(r^2-d^2)$。 直接计算证实了这一点。 

引理 3：消除$r$从这些方程得出一个单一条件$a$,$b$,$c$。 替换$r=-a/3$进入$b$和$c$产生$b = a^2/3 - d^2$和$c = a(a^2/27 - d^2/3)$。 然后求解$d^2$按照$a$和$b$给出$d^2 = a^2/3 - b$，代入$c$给出$c = (2a^3 - 9ab)/27$。 这是一个微妙的步骤，因为它涉及代数消除$d$。 

最难的一步：推导最终关系$c$按照$a$和$b$不会丢失或引入虚假的解决方案。 最有可能失败的引理是引理 3。 

## 解决方案

 假设三次多项式的根$x^3+ax^2+bx+c=0$形成算术级数。 将根表示为$r-d$,$r$， 和$r+d$， 在哪里$r$是中根并且$d$是共同的区别。 根据 Vieta 公式，根之和满足$$(r-d) + r + (r+d) = 3r = -a,$$因此$r=-a/3$。 两两乘积之和为$$(r-d)r + (r-d)(r+d) + r(r+d) = r^2 - rd + r^2 - d^2 + r^2 + rd = 3r^2 - d^2 = b.$$根的乘积为$$(r-d) r (r+d) = r(r^2 - d^2) = -c.$$替代$r=-a/3$进入$b$产量$$b = 3(-a/3)^2 - d^2 = a^2/3 - d^2,$$所以$$d^2 = a^2/3 - b.$$同样，替换$r=-a/3$进入$c$给出$$-c = (-a/3)((-a/3)^2 - d^2) = (-a/3)(a^2/9 - d^2) = -a(a^2 - 9 d^2)/27,$$因此$$c = a(a^2 - 9 d^2)/27.$$替代$d^2 = a^2/3 - b$进入这个表达式产生$$c = \frac{a}{27}\left(a^2 - 9\left(\frac{a^2}{3} - b\right)\right) = \frac{a}{27}\left(a^2 - 3a^2 + 9b\right) = \frac{a(9b - 2a^2)}{27} = \frac{9ab - 2a^3}{27}.$$因此系数的充分必要条件$a$,$b$,$c$三次方有算术级数的根是$$\boxed{27c = 9ab - 2a^3}.$$这样就完成了证明。 ∎

 ## 关键步骤验证

 为了验证推导$d^2 = a^2/3 - b$，考虑对称根$-1,0,1$， 在哪里$a=0$,$b=-1$,$c=0$。 然后$d=1$，而且确实$d^2=1 = 0 - (-1) = 1$，验证公式。 对于最终的关系$27c = 9ab - 2a^3$， 代替$a=0$,$b=-1$， 然后$27c = 0 - 0 = 0$，匹配$c=0$如示例所示。 第二次检查根$1,2,3$给出$a=-6$,$b=11$,$c=-6$， 和$9ab - 2a^3 = 9(-6)(11) - 2(-6)^3 = -594 - (-432) = -162$， 所以$27c=-162$; 的确$c=-6$，验证公式。 这些检查确认正确性并消除代数滑移$d$。 

## 替代方法

 另一种方法是将三次方视为$x^3+ax^2+bx+c=(x-r+d)(x-r)(x-r-d)$并直接展开可得$a$,$b$,$c$按照$r$和$d$，然后消除$r$和$d$通过结果计算。 这会产生相同的条件，但需要更繁重的代数运算和结果的使用。 通过 Vieta 公式的方法因其清晰性、最小代数和直接替换而更可取，减少了遗漏特殊情况或引入虚假解决方案的机会。
