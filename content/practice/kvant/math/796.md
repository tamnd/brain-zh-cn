 ## 问题

 点$P$位于广场内部$ABCD$这样$|AP|:|BP|:|CP|=1:2:3$。 寻找$\widehat{APB}$。 

L·D·库兰奇克

 ## 探索

 考虑一个正方形$ABCD$有一点$P$在里面。 按顺序标记顶点，并尝试放置$P$这样$|AP| : |BP| : |CP| = 1:2:3$。 引入坐标：令$A=(0,0)$,$B=(1,0)$,$C=(1,1)$,$D=(0,1)$。 然后$P=(x,y)$，有距离$|AP|=\sqrt{x^2+y^2}, \quad |BP|=\sqrt{(x-1)^2+y^2}, \quad |CP|=\sqrt{(x-1)^2+(y-1)^2}.$比率条件变为$\sqrt{x^2+y^2} : \sqrt{(x-1)^2+y^2} : \sqrt{(x-1)^2+(y-1)^2} = 1:2:3$。 平方消除根式，得到两个方程。 尝试对称性简化，假设$P$沿着连接相对顶点的线或沿着对角线。 主要挑战是求解由此产生的非线性系统。 一个可能的关键步骤是确定$P$满足所有三个距离的精确比例。 所需角度$\widehat{APB}$尽管坐标很复杂，但可能会显示一个简单的值。 

## 问题理解

 我们被要求找到角度的测量值$\widehat{APB}$给定一个点$P$位于与三个顶点具有指定距离比率的正方形内。 这是 B 类问题，因为角度由距离比决定，不需要分类或极值化。 核心难点在于将比率条件转化为可解的几何或代数系统并提取角度。 直觉表明这些比率$1:2:3$对应于沿连接线的特定位置$A$和$C$，产生一个简单的角度$\widehat{APB}$, 可能$\mathbf{60^\circ}$或者$\mathbf{120^\circ}$。 

## 证明架构

 引理 1：坐标$P$令人满意$|AP| : |BP| : |CP| = 1:2:3$躺在线上$y=x$。 这是根据平方比和距离比的对称性得出的。 

引理2：在线$y=x$，距离方程减少到一个二次方$x$，在正方形内有唯一解。 

引理 3：与$P$确定、计算$\cos \widehat{APB}$使用向量的点积公式$\overrightarrow{AP}$和$\overrightarrow{BP}$。 最困难的步骤是验证比率条件是否产生可解的二次方程$x$在$(0,1)$。 

## 解决方案

 将正方形放在坐标平面上$A=(0,0)$,$B=(1,0)$,$C=(1,1)$,$D=(0,1)$。 让$P=(x,y)$广场内。 距离比条件读取$|AP| : |BP| : |CP| = \sqrt{x^2+y^2} : \sqrt{(x-1)^2+y^2} : \sqrt{(x-1)^2+(y-1)^2} = 1:2:3.$计算距离的平方并引入公因数$k^2$以便$|AP|^2=k^2$,$|BP|^2=4k^2$,$|CP|^2=9k^2$。 然后$x^2 + y^2 = k^2, \quad (x-1)^2 + y^2 = 4k^2, \quad (x-1)^2 + (y-1)^2 = 9k^2.$从第二个方程中减去第一个方程：$(x-1)^2 + y^2 - (x^2+y^2) = 4k^2 - k^2 \implies x^2 - 2x + 1 + y^2 - x^2 - y^2 = 3k^2 \implies -2x+1 = 3k^2 \implies k^2 = \frac{1-2x}{3}.$从第三个中减去第二个：$(x-1)^2 + (y-1)^2 - [(x-1)^2 + y^2] = 9k^2 - 4k^2 \implies y^2 - 2y + 1 - y^2 = 5k^2 \implies -2y + 1 = 5k^2 \implies k^2 = \frac{1-2y}{5}.$使两个表达式相等$k^2$:$\frac{1-2x}{3} = \frac{1-2y}{5} \implies 5(1-2x)=3(1-2y) \implies 5-10x = 3 - 6y \implies 2 -10x = -6y \implies y = \frac{5x-1}{3}.$为确保$P$是在广场里面，$0< x <1$,$0< y <1$。 然后$0< \frac{5x-1}{3}<1 \implies 0<5x-1<3 \implies 1/5 < x < 4/5$。 

现在$k^2 = (1-2x)/3$。 还$y = (5x-1)/3$， 所以$|AP|^2 = x^2 + y^2 = x^2 + \left(\frac{5x-1}{3}\right)^2 = k^2 = \frac{1-2x}{3}$。 两边同时乘以 9：$9x^2 + (5x-1)^2 = 3(1-2x) \implies 9x^2 + 25x^2 -10x +1 = 3-6x \implies 34x^2 -4x -2 = 0 \implies 17x^2 -2x -1 =0.$求解二次方程：$x = \frac{2 \pm \sqrt{4 + 68}}{34} = \frac{2 \pm \sqrt{72}}{34} = \frac{2 \pm 6\sqrt{2}}{34} = \frac{1 \pm 3\sqrt{2}}{17}$。 仅有的$0< x<1$给出$x = \frac{1+3\sqrt{2}}{17}$。 然后$y = \frac{5x-1}{3} = \frac{5(1+3\sqrt{2})/17 -1}{3} = \frac{(5+15\sqrt{2})/17 -1}{3} = \frac{(5+15\sqrt{2}-17)/17}{3} = \frac{-12+15\sqrt{2}}{51} = \frac{5\sqrt{2}-4}{17}$。 

因此$P=(\frac{1+3\sqrt{2}}{17}, \frac{5\sqrt{2}-4}{17})$。 计算向量：$\overrightarrow{AP} = (x,y)$,$\overrightarrow{BP} = (x-1,y)$。 然后$\cos \widehat{APB} = \frac{\overrightarrow{AP}\cdot \overrightarrow{BP}}{|AP||BP|} = \frac{x(x-1)+y^2}{|AP||BP|}.$计算分子：$x(x-1)+y^2 = x^2 - x + y^2 = (x^2+y^2)-x = k^2 - x = \frac{1-2x}{3}-x = \frac{1-2x-3x}{3} = \frac{1-5x}{3}$。 替代$x = \frac{1+3\sqrt{2}}{17}$给出$1-5x = 1 - 5(1+3\sqrt{2})/17 = 1 - (5+15\sqrt{2})/17 = (17-5-15\sqrt{2})/17 = (12-15\sqrt{2})/17$。 那么分子=$(12-15\sqrt{2})/51$。 分母：$|AP| = k = \sqrt{(1-2x)/3}$,$|BP| = 2k = 2\sqrt{(1-2x)/3}$。 然后$|AP||BP| = 2 (1-2x)/3 = 2(1-2x)/3 = 2(1-2(1+3\sqrt{2})/17)/3 = 2(1-2/17-6\sqrt{2}/17)/3 = 2(15-6\sqrt{2})/51 = (30-12\sqrt{2})/51$。 然后$\cos \widehat{APB} = \frac{12-15\sqrt{2}}{30-12\sqrt{2}} = \frac{12-15\sqrt{2}}{30-12\sqrt{2}}$。 分子因数 3，分母因数 6
