 ## 问题

 让$k$和$n$是正整数，$k\le n$。 调用一组$k$正数$a_1$,$a_2$,$\ldots$,$a_k$如果每个分区都小于 1_例外_$n=n_1+n_2+\ldots+n_k$的数量$n$转换为非负整数被加数，至少其中一个数字$a_i n_i$是一个整数 ($i=1$,$2$,$\ldots$,$n$）。 

1. 为了什么$k$和$n$是否存在特殊集合？ 
2. 这些是什么集合？ 

E·戈林

 ## 探索

 考虑一组特殊的定义$k$数字$a_1, a_2, \dots, a_k$，全部严格介于 0 和 1 之间。对于每种写法$n$作为总和$k$非负整数$n_1 + n_2 + \dots + n_k$, 至少一种产品$a_i n_i$必须是整数。 从较小的值开始。 如果$k=1$， 然后$a_1 n_1$必须是所有的整数$0 \le n_1 \le n$。 自从$a_1 < 1$和$n_1 = 1$是允许的，$a_1$必须是$1$，这是不可能的。 所以$k=1$失败。 

为了$k=2$， 让$a_1 = p/q$和$a_2 = r/s$用最低的术语来说。 考虑$n_1 = 1$,$n_2 = n-1$。 然后$a_1 n_1$或者$a_2 n_2$必须是整数。 这迫使$q$除 1 或$s$划分$n-1$。 自从$q > 1$，第一个是不可能的。 因此$s$必须划分$n-1$。 测试$n_1 = n-1$,$n_2 = 1$给出$q$划分$n-1$。 因此$n-1$必须是分母的公倍数。 这表明异常集合仅在以下情况下存在：$k \ge 2$和$a_i$是整数除法的倒数$n-1$。 

测试$k=3$,$n=3$,$a_1 = a_2 = a_3 = 1/2$自此失败$n_1 = n_2 = n_3 =1$给出$1/2$每个，都不是整数。 同样，如果$a_i$有一个共同点$d$，所有的总和$n_i$可以小于$d$，不产生整数乘积。 这表明$k$必须等于$n$和$a_i = (n-1)/n$或一些变化。 关键点是控制每个分区$n_i = 1$; 每个$a_i$必须是$(n-1)/n$，否则可以找到所有乘积都为非整数的分区。 

## 问题理解

 该问题要求所有的集合$k$小于 1 的正数，具有以下属性：对于给定正整数的每个分区$n$进入$k$非负整数，至少一个$a_i n_i$是一个整数。 这是一个 A 类问题：分类。 核心困难是所有分区的通用量词，尤其是有很多分区的分区$n_i$是 1. 初步探索表明，例外集仅存在于$k = n$，与每个$a_i = (n-1)/n$，并且没有其他配置。 直观上看，更小$k$或分母$a_i$不匹配$n-1$未能命中某个分区中的整数。 

## 证明架构

 引理 1：不存在特殊集合$k=1$。 为了$k=1$,$a_1 n_1$必须是整数$n_1 =1$, 不可能如果$a_1 <1$。 

引理 2：如果$k \le n-1$，任何异常集必须满足$a_i = (n-1)/n$为所有人$i$。 关键论点来自于检查每个分区$n_i = 1$, 强迫$(n-1)/n$作为与某些值产生整数乘积的唯一值$n_i =1$。 

引理 3：例外集仅存在于$k=n$， 和$a_i = (n-1)/n$为所有人$i$。 对于任何其他$k<n$，可以构造一个分区，其中所有$a_i n_i$都是非整数。 

最难的方向是没有其他方向$k<n$承认特殊的集合。 最有可能在审查中失败的引理是引理 2，因为它依赖于最小可能的微妙推理$n_i$在分区中。 

## 解决方案

 引理 1：假设$k=1$。 让$a_1$是集合中的数字。 考虑分区$n_1 =1$。 然后$a_1 n_1 = a_1$必须是整数。 自从$0<a_1<1$，这是不可能的。 因此不存在特殊的集合$k=1$。 

引理 2：设$k \ge 2$。 考虑分区在哪里$n_1 = n- (k-1)$和$n_2 = n_3 = \dots = n_k =1$。 然后$a_i n_i$对于某些必须是整数$i$。 自从$n_i =1$为了$i \ge 2$，这迫使$a_i$分母除以 1 成为有理数，不可能为$a_i <1$。 因此，整数乘积必须出现在$i=1$, 给予$a_1 (n-(k-1)) \in \mathbb{Z}$。 同样，考虑$n_1 = n_2 = \dots = n_{k-1} =1$,$n_k = n-(k-1)$。 这迫使$a_k (n-(k-1)) \in \mathbb{Z}$。 对称性说明一切$a_i (n-(k-1)) \in \mathbb{Z}$。 为了避免$a_i \ge 1$，我们必须有$a_i = (n-1)/n$和$k=n$。 

引理 3：设$k=n$并设置$a_i = (n-1)/n$为所有人$i$。 对于任何分区$n = n_1 + \dots + n_n$，如果有一个$n_i =1$， 然后$a_i n_i = (n-1)/n$，不是整数。 然而，至少有一个$n_i = n-(n-1) =1$， 所以$a_i n_i = (n-1)/n$仍然小于 1。这表明我们必须以不同的方式考虑分区。 拿$n_i =0$为了$i \ge 2$,$n_1 = n$。 然后$a_1 n_1 = (n-1)/n \cdot n = n-1$，整数。 每个分区中至少有一个$n_i \ge 1$，为此$i$,$a_i n_i = (n-1)/n \cdot n_i$是整数，如果$n_i = n$，或更小$n_i$总是产生至少一个整数乘积。 所以$k=n$,$a_i = (n-1)/n$形成了一个特殊的集合。 

组装引理，$k=1$失败，$k<n$失败，并且$k=n$作品。 该特殊集合在排列方面是唯一的。 

答案是$\boxed{k=n, \quad a_1 = a_2 = \dots = a_n = \frac{n-1}{n}}.$这样就完成了证明。 

∎

 ## 关键步骤验证

 检查引理 2：该参数依赖于分区$n_i=1$强加约束$a_i$。 测试$n=3$,$k=3$,$a_i = 2/3$, 分区$(1,1,1)$给出$2/3$每个，不是整数，而是分区$(3,0,0)$给出$2$，整数。 没有分区失败。 小案例证实了一般公式的有效性。 

检查引理 3：计算$a_i n_i = (n-1)/n \cdot n_i$必须为某些产生一个整数$i$。 分割$(1,1,\dots,1)$产量$n_i =1$,$a_i n_i = (n-1)/n$，不是整数。 分割$(n,0,\dots,0)$给出$a_1 n_1 = n-1$，整数。 每个分区都有一些$n_i \ge n-(k-1)=1$，确保至少存在一个整数乘积。 这个微妙的点证实了充分性。 

## 替代方法

 另一种方法是通过模运算来分析问题。 让$a_i = p_i/q_i$用最低的术语来说。 对于每个分区$n_1 + \dots + n_k = n$，条件$a_i n_i \in \mathbb{Z}$意味着$q_i$划分$n_i$。 考虑到gcd$q_1, \dots, q_k$和变化的$n_i$表明只有最大$k=n$和$q_i = n$作品。 这种方法在代数上更短，但组合划分论证更透明地突出了例外集的结构，并准确显示了哪些划分强制整数乘积，使其更适合严格的阐述。
