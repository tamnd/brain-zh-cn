 ## 问题

 让$a_1$,$a_2$,$\ldots$,$a_n$是非负数。 哪个数字更大：$$\sqrt[\scriptstyle1988]{a_1^{1988}+a_2^{1988}+\ldots+a_n^{1988}}\quad\text{или}\quad \sqrt[\scriptstyle1989]{a_1^{1989}+a_2^{1989}+\ldots+a_n^{1989}}~?$$A·I·谢霍斯基

 ## 探索

 让$$X=\left(a_1^{1988}+a_2^{1988}+\cdots+a_n^{1988}\right)^{1/1988}, \qquad Y=\left(a_1^{1989}+a_2^{1989}+\cdots+a_n^{1989}\right)^{1/1989}.$$问题问是否$X$或者$Y$更大。 

首先测试简单的情况。 

如果$n=1$， 然后$$X=Y=a_1.$$如果$a_1=a_2=1$， 然后$$X=2^{1/1988},\qquad Y=2^{1/1989},$$自从$1/1988>1/1989$,$$X>Y.$$如果$a_1=2$,$a_2=0$， 然后$$X=Y=2.$$这些例子表明$X\ge Y$，当至多为 1 时相等$a_i$是非零的。 

表达式为$\ell_p$向量的范数$(a_1,\dots,a_n)$为了$p=1988$和$p=1989$。 一个标准事实是，对于非负向量，$\ell_p$规范减少$p$增加。 由于这正是要证明的命题，因此必须直接证明它是正确的。 

一个方便的路线是设置$$S=\sum_{i=1}^n a_i^{1988}.$$如果$S=0$，那么所有$a_i=0$和$X=Y=0$。 

认为$S>0$并定义$$b_i=\frac{a_i^{1988}}{S}.$$然后$b_i\ge0$和$\sum b_i=1$。 我们得到$$\sum a_i^{1989} = S\sum b_i a_i.$$自从$b_i$形式权重总和为$1$,$$\sum b_i a_i\le \max_i a_i.$$还，$$a_i^{1988}\le S,$$因此$$a_i\le S^{1/1988}.$$所以$$\sum a_i^{1989}\le S^{1+1/1988}=S^{1989/1988}.$$服用$1989$th 根给出$$Y\le S^{1/1988}=X.$$关键点是证明$$\sum a_i^{1989}\le \left(\sum a_i^{1988}\right)^{1989/1988}.$$上面的加权平均论证似乎准确地证实了这一点。 

## 问题理解

 我们被要求比较两个数字$$\left(\sum_{i=1}^n a_i^{1988}\right)^{1/1988} \quad\text{and}\quad \left(\sum_{i=1}^n a_i^{1989}\right)^{1/1989},$$哪里都$a_i$是非负的。 

这是一个 C 类问题，因为我们必须确定哪个数量更大。 

核心难点是证明不等式$$\left(\sum a_i^{1988}\right)^{1/1988} \ge \left(\sum a_i^{1989}\right)^{1/1989}$$对于任意非负数。 

答案是第一个数字总是至少与第二个数字一样大。 直观上，提高指数会在较大的坐标上施加更大的权重，而相应的根并不能完全补偿这种影响。 

## 证明架构

 让$$S=\sum_{i=1}^n a_i^{1988}.$$如果$S=0$，两个量都是$0$。 

认为$S>0$并定义$$b_i=\frac{a_i^{1988}}{S}.$$然后$b_i\ge0$和$\sum b_i=1$。 

引理 1. 对于每一个$i$,$$a_i\le S^{1/1988}.$$这是从$a_i^{1988}\le S$。 

引理 2. 一个有$$\sum_{i=1}^n a_i^{1989} = S\sum_{i=1}^n b_i a_i.$$这是通过替换获得的$a_i^{1988}=Sb_i$。 

引理 3. 由于$b_i$是非负的并且总和为$1$,$$\sum b_i a_i\le \max_i a_i.$$加权平均值不能超过最大条目。 

结合引理 1、2 和 3 得出$$\sum a_i^{1989} \le S^{1989/1988}.$$服用$1989$th 根给出了所需的比较。 

最有可能在审查下失败的步骤是从引理 2 到边界的过渡$\sum a_i^{1989}$，因为它同时使用加权平均属性和估计值$\max a_i\le S^{1/1988}$。 

## 解决方案

 表示$$X=\left(a_1^{1988}+a_2^{1988}+\cdots+a_n^{1988}\right)^{1/1988},$$和$$Y=\left(a_1^{1989}+a_2^{1989}+\cdots+a_n^{1989}\right)^{1/1989}.$$我们将证明$X\ge Y$。 

让$$S=\sum_{i=1}^n a_i^{1988}.$$如果$S=0$，那么每一个$a_i=0$， 因此$X=Y=0$。 

现在假设$S>0$。 定义$$b_i=\frac{a_i^{1988}}{S}.$$然后$$b_i\ge0, \qquad \sum_{i=1}^n b_i=1.$$自从$a_i^{1988}\le S$对于每一个$i$,$$a_i\le S^{1/1988}.$$所以$$\max_i a_i\le S^{1/1988}.$$下一个，$$\sum_{i=1}^n a_i^{1989} = \sum_{i=1}^n a_i\cdot a_i^{1988} = S\sum_{i=1}^n b_i a_i.$$因为数字$b_i$是非负的，它们的总和是$1$, 数量$\sum b_i a_i$是数字的加权平均值$a_i$。 因此$$\sum_{i=1}^n b_i a_i\le \max_i a_i.$$将此与之前的估计相结合得出$$\sum_{i=1}^n a_i^{1989} \le S\cdot S^{1/1988} = S^{1+1/1988} = S^{1989/1988}.$$采取$1989$两边的根，$$Y = \left(\sum_{i=1}^n a_i^{1989}\right)^{1/1989} \le \left(S^{1989/1988}\right)^{1/1989} = S^{1/1988} = X.$$因此$$\left(a_1^{1988}+a_2^{1988}+\cdots+a_n^{1988}\right)^{1/1988} \ge \left(a_1^{1989}+a_2^{1989}+\cdots+a_n^{1989}\right)^{1/1989}.$$当至多有一个数字时，相等成立$a_i$是非零的。 

因此较大的数是$$\boxed{\left(a_1^{1988}+a_2^{1988}+\cdots+a_n^{1988}\right)^{1/1988}}.$$## 关键步骤验证

 第一个微妙的步骤是估计$$a_i\le S^{1/1988}.$$自从$$S=\sum_{k=1}^n a_k^{1988},$$每个被加数都满足$$a_i^{1988}\le S.$$所有数量都是非负数，因此取$1988$根产量$$a_i\le S^{1/1988}.$$第二个微妙的步骤是$$\sum b_i a_i\le \max_i a_i.$$让$M=\max_i a_i$。 自从$a_i\le M$对于每一个$i$,$$\sum b_i a_i \le \sum b_i M = M\sum b_i = M.$$第三个微妙的步骤是过渡$$\sum a_i^{1989} = S\sum b_i a_i.$$使用定义$b_i=a_i^{1988}/S$,$$S\sum b_i a_i = S\sum \frac{a_i^{1988}}{S}a_i = \sum a_i^{1989},$$这是一个精确的恒等式，而不仅仅是一个不平等。 

## 替代方法

 标准论证使用霍尔德不等式。 让$$p=\frac{1989}{1988},\qquad q=1989.$$将 Hölder 应用于序列$a_i^{1988}$和$1$给出$$\sum a_i^{1988} \le \left(\sum a_i^{1989}\right)^{1988/1989} n^{1/1989}.$$重新排列后得到单调性$\ell_p$规范。 这种方法证明了一个更普遍的定理，但它引入了比问题所需更强大的机制。 

另一种方法使用詹森不等式。 环境$$b_i=\frac{a_i^{1988}}{\sum a_k^{1988}},$$函数的凸性$x^{1989/1988}$产量$$\sum b_i^{1989/1988}\le 1.$$将这个不等式重写为$a_i$，一到达$$\sum a_i^{1989} \le \left(\sum a_i^{1988}\right)^{1989/1988}.$$主要证明中使用的加权平均论证较短，并且仅依赖于非负数的基本属性。
