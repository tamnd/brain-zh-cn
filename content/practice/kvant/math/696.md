 ## 问题

 是否可以填写$10 \times 10$- 具有 100 个不同自然数的单元格表，以便对于任何$k \times k$-单元格正方形（$2 \le k \le 10$）

 1. 总和，
 2、产品$k$对角线上的数字相等吗？ 

A·巴林斯基

 ## 探索

 考虑小问题$k \times k$正方形。 对于一个$2 \times 2$正方形，两条对角线各包含两个数字。 如果对角线之和必须相等，那么对于数字$a, b, c, d$排列为$$\begin{pmatrix} a & b \\ c & d \end{pmatrix},$$条件$a + d = b + c$必须持有。 同时，对角线的乘积必须满足$a d = b c$。 这两个条件意味着对数量的严格限制。 使用方程，我们可以求解$d$按照$a, b, c$从总和相等：$d = b + c - a$。 代入乘积等式得出$a(b + c - a) = b c$，这简化为$ab + ac - a^2 = bc$， 然后$-a^2 + a(b + c) - bc = 0$，其中因子为$(a - b)(a - c) = 0$。 因此$a = b$或者$a = c$，强制重复。 已经在$2 \times 2$在这种情况下，不同的数字是不可能的。 

将这一观察扩展到更大范围$k$， 每个$2 \times 2$内的子方格$10 \times 10$表需要重复的数字。 由于该表必须填充不同的自然数，因此这是不可能的。 关键的难点是是否有约束条件$k > 2$可以以某种方式避免重复，但是$2 \times 2$子方块已经造成了不可避免的碰撞。 

## 问题理解

 问题是问是否可以填写$10 \times 10$具有不同自然数的表，这样对于每个$k \times k$与$2 \le k \le 10$，沿两条对角线的数字的和与积相等。 这是一个 B 类问题，因为它需要证明或反驳这种配置的存在。 核心困难是理解不同数字的同时和和乘积相等是否可以共存。 初步计算$2 \times 2$方块表示立即存在障碍，暗示不存在解决方案。 

## 证明架构

 引理 1：对于任何$2 \times 2$对角线和和对角线乘积相等的自然数的平方，至少有两个数必须重合。 这是通过求解四个变量的两个方程组得出的，得出$(a - b)(a - c) = 0$。 

引理 2：任意$k \times k$正方形包含一个$2 \times 2$子广场。 这是显而易见的，因为在$k \times k$平方产生一个$2 \times 2$子广场。 

引理 3：因此，$10 \times 10$表必须包含重复的数字。 这是引理 1 和 2 的直接结果，因为每个$2 \times 2$子方需要重复，与独特性要求相矛盾。 

最难的一步是引理 1，其中明确的代数论证必须表明相等的和与积强制重复。 

## 解决方案

 考虑一个$2 \times 2$自然数的平方$$\begin{pmatrix} a & b \\ c & d \end{pmatrix}.$$对角线之和相等的条件给出$$a + d = b + c,$$对角线乘积相等的条件给出$$a d = b c.$$从总和相等，解出$d$：$$d = b + c - a.$$代入乘积等式：$$a(b + c - a) = b c.$$展开并重新排列：$$a b + a c - a^2 = b c \implies -a^2 + a(b + c) - b c = 0.$$这因素为$$(a - b)(a - c) = 0,$$所以$a = b$或者$a = c$。 无论哪种情况，正方形都包含重复的数字。 这证明了引理1。 

接下来，任意$k \times k$与$k \ge 2$包含一个$2 \times 2$子广场。 该子正方形必须满足相同的对角线和和乘积条件，因此根据引理 1，它包含重复的数字。 将此应用到$10 \times 10$table shows that the table must have repeated numbers.

 Since the problem requires all 100 numbers to be distinct, this is impossible. Hence, no such table exists.

 这样就完成了证明。 

∎

 ## 关键步骤验证

 The derivation in Lemma 1 was verified by explicitly solving the system for$d$并代入乘积方程。 保理$-a^2 + a(b + c) - bc$作为$(a - b)(a - c)$通过扩展检查：$(a - b)(a - c) = a^2 - a c - a b + b c = -a^2 + a(b + c) - b c$两边相乘后$-1$，确认正确性。 引理1对所有的应用$2 \times 2$较大的子正方形$k \times k$通过考虑任意对的连续行和列来确认正方形，保证覆盖每个$2 \times 2$子集。 

## 替代方法

 人们可以尝试使用奇偶校验或模算术进行组合论证，以素数为模分配假设的数字，并显示对角线和或乘积必须发生冲突。 另一种方法是尝试对小表进行显式构造，并观察随着大小增加的故障模式。 所提出的代数方法是优选的，因为它以最简单的方式提供了直接且完全的阻塞。$2 \times 2$案例，立即扩展到完整$10 \times 10$桌子。
