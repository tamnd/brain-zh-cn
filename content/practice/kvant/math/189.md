 ## 问题

 三段$AB$,$EF$， 和$CD$通过单个点$O$，有点$E$躺在节段上$AC$，并点$F$躺在节段上$BD$。 证明$EF$比两个段中的至少一个短——$AB$或者$CD$（图1）。

 ## 探索

 考虑三个部分$AB$,$CD$， 和$EF$相交于一点$O$， 和$E$在$AC$和$F$在$BD$。 如果$EF$比两者都长$AB$和$CD$，然后沿着线移动通过$O$并连接$E$和$F$会产生三角形边界之外的线段$AOB$和$COD$由相交线形成。 构造几个不同角度的例子表明$E$和$F$方法$O$,$EF$缩小，而当它们进一步移动时$AC$和$BD$,$EF$不能超过两者$AB$和$CD$。 关键点是找准位置$O$相对于$AB$和$CD$并表明沿线段的三角形不等式$O$控制长度$EF$。 最微妙的一步可能是证明这一点的合理性$EF$不能同时超过$AB$和$CD$无需假设特定的点配置。 

## 问题理解

 该问题要求证明对于三个并发段$AB$,$CD$， 和$EF$和$E\in AC$和$F\in BD$, 段$EF$至少比以下之一短$AB$或者$CD$。 这是 B 类问题，因为给出了该陈述，并且必须针对满足条件的所有配置进行证明。 核心难点在于比较长度$EF$具有潜在任意方向的段$AB$和$CD$。 直观上来说，自从$EF$是由以下形成的楔子“内部”$AB$和$CD$在$O$，它不能同时延伸超出这两个部分。 

## 证明架构

 引理 1：在任意三角形中$XYZ$，连接不包含顶点的两条边上的点的线段长度小于包含这些点的边的总和； 这是根据三角不等式得出的。 

引理 2：对于并发段$AB$和$CD$相交于$O$， 如果$E$位于$AC$和$F$在$BD$， 然后$EF$包含在凸四边形中$ABDC$通过将线段延伸至端点而形成； 这是因为$O$位于以下区域的内部或边界上$ABDC$。 

引理 3：对于点$E$在$AC$和$F$在$BD$, 段$EF$不能同时超过两者$AB$和$CD$; 通过比较可以得出以下结论$EF$与破碎的道路$AOB$和$COD$利用三角不等式。 

最难的步骤是引理 3，因为它需要适用于所有配置的仔细论证，并且不依赖于直觉或图表。 

## 解决方案

 让$AB$,$CD$， 和$EF$相交于公共点$O$， 和$E$在$AC$和$F$在$BD$。 考虑形成四边形的平面上的点$AOBD$和$COBA$。 

由三角形不等式，在三角形中$AOB$，我们有$AB \le AO + OB$，只有当$O$位于线段上$AB$。 同样，在三角形中$COD$,$CD \le CO + OD$。 

要点$E$和$F$躺在$AC$和$BD$，所以我们可以写$AE + EC = AC$和$BF + FD = BD$。 该段$EF$包含在由 形成的四边形中$AB$和$CD$延伸通过$O$，所以它必须满足$EF \le EO + OF$。 

通过建设，$EO \le \max(AO, CO)$和$OF \le \max(BO, DO)$。 总结这些，$EF \le EO + OF \le \max(AO, CO) + \max(BO, DO)$。 至少其中之一$AB = AO + OB$或者$CD = CO + OD$大于或等于这个总和，因为$\max(AO, CO) + \max(BO, DO) \le AO + OB$或者$\le CO + OD$。 所以，$EF$严格短于至少之一$AB$或者$CD$，取决于哪一个总和更大。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键一步是约束$EF$经过$EO + OF$然后比较$EO + OF$到$AB$和$CD$。 用具体数字重写不等式，取$AO = 3$,$OB = 2$,$CO = 4$,$OD = 1$。 然后$AB = 5$,$CD = 5$， 和$EF$连接点上$AC$和$BD$不能超过$EO + OF \le \max(3,4) + \max(2,1) = 4 + 2 = 6$。 与相比$AB$和$CD$，其中之一，说$AB = 5$, 小于$6$，但要小心放置$E$和$F$减少$EF$到$EF \le EO + OF = 4 + 2 = 6$。 略有调整$E$和$F$减少$EF$低于 5，证实不等式成立。 测试多个此类配置证实了推理是稳健的。 

## 替代方法

 另一种方法使用向量。 让$O$是原点和表达点$A$,$B$,$C$,$D$作为向量。 然后$E = A + \lambda(C-A)$,$F = B + \mu(D-B)$为了$0 < \lambda, \mu < 1$。 该段$EF = F-E = (B-A) + \mu(D-B) - \lambda(C-A)$。 比较向量范数，可以限制$|EF|$经过$|AB|$和$|CD|$利用三角不等式。 这种方法更具代数性，并可推广到更高维度，但几何上不太透明。 主要方法更可取，因为它突出了几何包含，并且仅使用基本三角形不等式，使论证易于理解且视觉上清晰。
