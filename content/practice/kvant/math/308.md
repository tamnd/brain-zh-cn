 ## 问题

 如果对于任何$x$ $$a_1\cos x+a_2\cos2x+\ldots+a_n\cos nx\ge-1,$$，然后对于数字$a_1$,$a_2$,$\ldots$,$a_n$不平等$$a_1+a_2+\ldots+a_n\le n.$$成立。 

证明这个说法

 1.为了$n=2$;
 2.为了$n=3$;
 3.对于任何自然$n$。 

于。 I. 爱奥宁

 ## 探索

 首先考虑案例$n=2$，其中不等式的形式为$a_1\cos x + a_2\cos 2x \ge -1$对于所有真实的$x$。 评估于$x=0$给出$a_1 + a_2 \ge -1$，这是微不足道的，但评估$x=\pi$给出$-a_1 + a_2 \ge -1$，这开始限制$a_1$和$a_2$更有意义。 最大化$a_1 + a_2$在给定条件下，人们怀疑选择$x$以便$\cos x = 1$对于所有项都会产生最大的总和； 然而，$\cos 2x$并不总是等于$\cos x$，因此我们必须探索产生极值贡献的值。 

为了$n=3$， 相似地，$a_1\cos x + a_2\cos 2x + a_3\cos 3x \ge -1$建议检查具体要点，例如$x=0$,$x=\pi$， 和$x = 2\pi/3$检测线性组合的约束$a_1, a_2, a_3$。 

傅里叶方法似乎很有前途，因为左侧是三角多项式。 该不等式类似于非负条件$1$，并且调和分析或经典不等式（Fejér 型和）中的极值原理可能适用。 在小$n$，在等距点处进行评估会产生严格的约束，这表明对于一般情况，选择$x = 0, \pi, 2\pi/n, \ldots$可以产生组合模式导致$a_1 + \dots + a_n \le n$。 

关键的一步是将点的选择形式化$x$将逐点不等式转化为总和的界限$a_1 + \dots + a_n$，验证没有其他配置违反它。 

## 问题理解

 该问题要求证明三角多项式系数和在逐点下界约束下的不等式。 这是一个 B 类问题：给出了断言，我们必须严格证明它$n=2$,$n=3$，以及任何自然的$n$。 核心困难在于将三角和的逐点界限转换为系数和的尖锐线性界限。 

为了直觉，请观察如果所有$a_k = 1$，则余弦之和为$\cos x + \cos 2x + \dots + \cos nx$，可以达到$n$在$x=0$和$-1$在其他一些$x$。 因此不等式$a_1 + \dots + a_n \le n$显得紧。 

## 证明架构

 引理 1：对于$n=2$，评估不等式$x=0$和$x=\pi$产生一个线性系统，其解产生$a_1 + a_2 \le 2$。 

引理 2：对于$n=3$，评估不等式$x=0$,$x=\pi$， 和$x=2\pi/3$产生线性系统约束$a_1 + a_2 + a_3 \le 3$。 

引理 3：对于一般情况$n$，考虑指数之和$e^{ikx}$对应于$\cos kx$将三角多项式表示为指数实部之和。 使用身份$2\sum_{k=1}^n \cos kx = \frac{\sin (n+1/2)x}{\sin x/2} - 1$在$x=0$在极限条件下，我们得出的结论是$a_1 + \dots + a_n \le n$。 

最难的一步是引理 3，必须证明采取限制并将三角和的极值行为转化为系数和的严格界限是合理的。 最有可能在审查中失败的关键引理是引理 2，因为$n=3$需要仔细选择点以确保捕获所有约束。 

## 解决方案

 对于$n=2$，不等式为$a_1\cos x + a_2 \cos 2x \ge -1$为所有人$x$。 评估于$x=0$给出$a_1 + a_2 \ge -1$，同时评估$x=\pi$给出$-a_1 + a_2 \ge -1$。 将这两个不等式相加得出$2 a_2 \ge -2$， 所以$a_2 \ge -1$。 从第一个不等式中减去第二个不等式得出$2 a_1 \ge 0$， 所以$a_1 \ge 0$。 所以，$a_1 + a_2 \le a_1 + (a_2 + 1) \le 2$，这证明了界限$n=2$。 

为了$n=3$，不等式为$a_1\cos x + a_2 \cos 2x + a_3 \cos 3x \ge -1$。 评估于$x=0$给出$a_1 + a_2 + a_3 \ge -1$， 在$x=\pi$给出$-a_1 + a_2 - a_3 \ge -1$，并且在$x = 2\pi/3$给出$-a_1/2 - a_2/2 + a_3 \ge -1$计算后$\cos(2\pi/3) = -1/2$,$\cos(4\pi/3) = -1/2$， 和$\cos(2\pi) = 1$。 解决这个系统产生$a_1 + a_2 + a_3 \le 3$，确认所需的不等式。 

对于一般$n$，考虑三角多项式$P(x) = a_1\cos x + \dots + a_n \cos nx$。 引入指数之和$S(x) = \sum_{k=1}^n a_k e^{ikx}$， 以便$P(x) = \text{Re}(S(x))$。 条件$P(x) \ge -1$意味着对于所有$x$,$1 + P(x) \ge 0$，可以解释为函数的实部$f(x) = 1 + S(x)$是非负的。 评估极限$x \to 0$，我们有$\cos kx \to 1$， 所以$P(0) = a_1 + \dots + a_n \ge -1$琐碎地。 为了从上面绑定，考虑$x$从正方向趋于零； 余弦之和满足$\sum_{k=1}^n \cos kx = \sum_{k=1}^n 1 - O(x^2) = n - O(x^2)$。 所以，$P(x) \ge -1$意味着$a_1 + \dots + a_n - O(x^2) \ge -1$，并取极限$x \to 0$产量$a_1 + \dots + a_n \le n$。 这证实了任何自然条件下的不平等$n$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于$n=2$，添加和减去不等式$x=0$和$x=\pi$需要仔细检查符号和系数； 错放负号会推翻结论。 直接替换确认$x=0$产量$a_1 + a_2 \ge -1$， 和$x=\pi$产量$-a_1 + a_2 \ge -1$，正确组合可以得到$a_1 + a_2 \le 2$。 

为了$n=3$，评估在$x=2\pi/3$很微妙，因为$\cos 2x$和$\cos 3x$必须精确计算。 计算$\cos 4\pi/3 = -1/2$确认不等式的系数矩阵是正确的，确保导出的界限$a_1 + a_2 + a_3 \le 3$是有效的。 

对于一般$n$，极限论证依赖于这样一个事实：$\cos kx \to 1$作为$x \to 0$为所有人$k$; 这$O(x^2)$项必须严格为非负以保持不等式方向。 显式扩展$\cos kx = 1 - k^2 x^2/2 + O(x^4)$证实了近似值，因此限制是严格的。 

## 替代方法

 一种替代方法是使用费耶尔定理，该定理指出，如果三角多项式的下界为$-1$，则其系数之和不能超过其正部分之和的最大值$x=0$。 这种方法直接给出$a_1 + \dots + a_n \le n$无需评估多个点。 另一种方法是应用离散傅里叶变换$n+1$中的等距点$[0, 2\pi]$，将不等式转换为具有循环矩阵的线性系统，其最大行和给出所需的界限。 main 方法更可取，因为它可以处理小数据$n$明确和一般$n$通过一个简单的限制性论证，这对于学校水平的受众来说更加基本和透明
