 ## 问题

 单个病毒进入由以下组成的菌落$n$细菌。 在第一分钟内，它消灭了一个细菌，然后分裂成两种新的病毒，同时剩余的每个细菌也分裂成两种新的细菌。 在下一分钟内，两种新形成的病毒消灭了两种细菌，然后两种病毒和所有剩余的细菌再次分裂，依此类推。 这个殖民地会永远存在，还是最终会消亡？ 

R·M·科夫通

 ## 探索

 考虑较小的初始菌落大小以了解动态。 如果$n=1$，单一病毒在第一分钟杀死唯一的细菌。 此后，没有细菌可以分裂，因此病毒数量不受控制地翻倍，但没有进一步的影响。 如果$n=2$，第一个病毒杀死一个细菌，留下一个，加倍到两个。 病毒也加倍至两倍。 下一分钟，两种病毒消灭了两种细菌，恰好是总数，不留任何细菌； 然后两个人口都会翻倍。 为了$n=3$，第一个病毒杀死一个细菌，留下两个，加倍到四个。 病毒倍增至两倍。 下一分钟，两种病毒杀死了两种细菌，留下了两种细菌，又增加了一倍，达到了四种。 病毒数量增加了一倍至四种。 继续下去，病毒种群的增长速度比细菌更快，因此细菌最终会被淹没。 测试这些小案例表明，无论初始数量如何$n$，病毒数量最终超过细菌数量，导致菌落灭绝。 关键的见解是，杀死相当于其当前大小的细菌后，病毒数量会增加一倍，而细菌在减少后会增加一倍，因此病毒最终会超过它们。 

## 问题理解

 该问题描述了一个涉及单个病毒的离散时间动力系统$n$细菌，在特定的相互作用规则下，两个种群每分钟都会翻倍。 问题是细菌群体是无限期地生存还是最终灭绝。 这是一个 B 类问题，“证明 [陈述]”。 核心难点在于比较两个不同偏移量的指数过程：病毒杀死细菌后翻倍，细菌失去部分个体后翻倍。 关键是确定是否存在一个有限时间，当病毒数量等于或超过剩余细菌时，这将导致灭绝。 

## 证明架构

 证明将按以下步骤进行。 一、定义序列$V_k$和$B_k$代表病毒和细菌在开始时的数量$k$第 - 分钟。 其次，推导递推关系：$V_0 = 1$,$B_0 = n$,$V_{k+1} = 2 V_k$,$B_{k+1} = 2(B_k - V_k)$，并证明这些公式正确地模拟了该过程。 第三，为所有人建立$k$,$B_k$保持非负数直到第一个$k$这样$V_k \ge B_k$，这对应于细菌的灭绝。 四、显示比例$B_k / V_k$最终跌破$1$为所有人$n \ge 1$，这意味着病毒数量超过了细菌数量。 最困难的一步是严格证明$B_k / V_k$减少到以下$1$，这就是粗心估计可能失败的地方。 这需要精确地处理重复性，而不是直观的增长比较。 

## 解决方案

 让$V_k$表示开头的病毒数量$k$第-分钟和$B_k$初始细菌数$k$第 - 分钟。 最初，$V_0 = 1$和$B_0 = n$。 根据这个问题，每一分钟都分两个阶段进行：病毒消灭相同数量的细菌，然后两个细菌数量都翻倍。 病毒作用后，细菌数量$B_k - V_k$，只要是非负的$B_k \ge V_k$。 然后两个群体都翻倍，所以递推关系是$V_{k+1} = 2 V_k,$

$B_{k+1} = 2(B_k - V_k).$我们通过归纳来验证这些重现$k$。 为了$k=0$，第一分钟，$V_1 = 2 \cdot 1 = 2$和$B_1 = 2(n - 1)$，与问题陈述相匹配。 假设该关系对于某些情况成立$k \ge 0$。 在$(k+1)$第-分钟，当前病毒数量$V_{k+1}$杀死$V_{k+1}$细菌，留下$B_{k+1} - V_{k+1} = 2(B_k - V_k) - 2 V_k = 2(B_k - 2 V_k)$，这与迭代公式一致。 通过归纳，关系式是正确的。 

定义比率$r_k = B_k / V_k$。 然后$r_0 = n, \quad r_{k+1} = \frac{B_{k+1}}{V_{k+1}} = \frac{2(B_k - V_k)}{2 V_k} = \frac{B_k}{V_k} - 1 = r_k - 1.$因此，$r_k$减少$1$在每一步。 这个序列是算术序列：$r_k = n - k$。 因此，存在有限$k_0 = n$这样$r_{k_0} = 0$， 意义$B_{k_0} = 0$。 因此，细菌数量在之后变为零$n$分钟后，病毒就可以自由加倍，无需竞争。 由于这发生在每个初始$n \ge 1$，群体不可能无限期地生存。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 递推式的推导$B_{k+1} = 2(B_k - V_k)$它很微妙，因为它结合了两个独立的过程：病毒破坏和细菌倍增。 要验证，请考虑$n=3$。 然后$B_0 = 3$,$V_0 = 1$， 所以$B_1 = 2(3 - 1) = 4$，这与明确的逐步模拟相匹配：病毒杀死一个，留下两个，加倍到四个。 比率的计算$r_{k+1} = r_k - 1$是精确的，因为将递归除以$V_{k+1} = 2 V_k$产量$r_{k+1} = (2(B_k - V_k))/(2 V_k) = B_k / V_k - 1$。 测试小$n$证实$r_k$准确地达到零$n$步骤，验证灭绝论。 

## 替代方法

 另一种方法是编写$B_k$和$V_k$明确地作为函数$n$和$k$:$V_k = 2^k$和$B_k = 2^k (n - k)$。 这使得灭绝变得明显，因为$B_n = 2^n (n - n) = 0$。 虽然这个直接公式很有效，但它的推导依赖于识别比率的算术减少$B_k / V_k$。 使用该比率的主要方法强调两个种群的指数增长率之间的比较，并强调灭绝的潜在机制，使论证更加透明并可推广到相关过程。
