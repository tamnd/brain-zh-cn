 ## 问题

 求表达式的最小值$(x+y)(x+z)$， 鉴于$x$,$y$,$z$是正数并且$xyz(x+y+z)=1$。 

奥列格·赫里斯坚科，十年级学生

 ## 探索

 我们被要求尽量减少$(x+y)(x+z)$约束下$xyz(x+y+z)=1$， 和$x$,$y$,$z$积极的。 自然的第一步是考虑对称性：约束是对称的$x$,$y$,$z$，而表达式$(x+y)(x+z)$是对称的$y$和$z$但不完全对称。 这表明极值可能出现在$y=z$，将问题简化为两个变量。 

我们可以测试近似满足约束的小整数类值。 认为$y=z$。 那么约束就变成了$x y^2 (x + 2y) = 1$。 表达式简化为$(x+y)(x+y) = (x+y)^2$，表明当两个变量相等时可能会达到最小值。 

尝试$x=y=z$给出$x^3(3x) = 3x^4 = 1$， 所以$x = 3^{-1/4} \approx 0.7598$。 然后$(x+y)(x+z) = (2x)^2 = 4 \cdot 3^{-1/2} = 4/\sqrt{3} \approx 2.309$。 

尝试$y=z=1$并解决$x \cdot 1 \cdot 1 \cdot (x+2) = x(x+2) = 1$给出$x^2 + 2x -1=0$， 所以$x = \sqrt{2} -1 \approx 0.4142$, 给予$(x+y)(x+z) = (x+1)^2 \approx 1.414^2 = 2$。 这小于$2.309$，表明最小值出现在$y=z=1$和$x=\sqrt{2}-1$。 

因此，探索表明，当两个变量相等并且第三个变量进行调整以满足约束时，就会出现极值。 

## 问题理解

 该问题要求在对称乘法线性约束下三个正变量的正函数的最小值。 这是 C 类：“找到最小值”。 核心难点是平衡乘法约束$xyz(x+y+z)=1$反对表达$(x+y)(x+z)$，当$x$很小并且$y$,$z$是温和的，但约束迫使人们进行权衡。 探索表明两个变量相等会导致最小配置。 预期的最小值似乎是$2$，达到时$y=z=1$和$x=\sqrt{2}-1$。 

## 证明架构

 引理 1：至少$(x+y)(x+z)$在给定的约束条件下，变量$y$和$z$必须相等。 草图：使用拉格朗日乘子的对称性以及表达式对称的事实$y$和$z$。 

引理 2：与$y=z$，约束减少为$x y^2 (x+2y) =1$，表达式简化为$(x+y)^2$。 草图：直接替换。 

引理 3：函数$f(x) = (x+y)^2$和$y$固定正数，在约束下$x y^2 (x+2y) = 1$，达到最小值时$y=1$和$x=\sqrt{2}-1$。 草图：显式求解所得二次方程。 

主要要求： 的最小值$(x+y)(x+z)$是$2$，达到$(x,y,z) = (\sqrt{2}-1, 1,1)$及其排列。 最难的一步：论证$y=z$并排除具有所有不同变量的配置。 

## 解决方案

 考虑功能$F(x,y,z)=(x+y)(x+z)$受约束$G(x,y,z) = xyz(x+y+z) -1=0$， 和$x,y,z>0$。 我们应用拉格朗日乘子法。 让$\lambda$是一个乘数，使得$$\nabla F = \lambda \nabla G.$$计算偏导数：$$\frac{\partial F}{\partial x} = (x+y) + (x+z) = 2x + y + z, \quad \frac{\partial F}{\partial y} = x+z, \quad \frac{\partial F}{\partial z} = x+y,$$

$$\frac{\partial G}{\partial x} = yz (2x + y + z), \quad \frac{\partial G}{\partial y} = xz (x + 2y + z), \quad \frac{\partial G}{\partial z} = xy (x + y + 2z).$$环境$\frac{\partial F}{\partial y} = \lambda \frac{\partial G}{\partial y}$和$\frac{\partial F}{\partial z} = \lambda \frac{\partial G}{\partial z}$给出$$x+z = \lambda x z (x+2y+z), \quad x+y = \lambda x y (x+y+2z).$$除以这些方程：$$\frac{x+z}{x+y} = \frac{x z (x+2y+z)}{x y (x+y+2z)} = \frac{z (x+2y+z)}{y (x+2z+ y)} = \frac{z (x+2y+z)}{y (x+y+2z)}.$$左侧是$ \frac{x+z}{x+y}$。 平等需要$y=z$或其他一些关系减少到$y=z$。 因此，至少我们可以假设$y=z$通过对称性。 

代替$y=z$并表示$y=z=t>0$。 约束变为$x t^2 (x+2 t) = 1$，表达式简化为$$F(x,t,t) = (x+t)^2.$$我们解决$x t^2 (x+2t) =1$为了$x$按照$t$。 这给出了二次方程$x^2 t^2 + 2 x t^3 -1=0$或同等地$x^2 + 2 t x -1/t^2=0$。 正根是$$x = -t + \sqrt{t^2 + 1/t^2}.$$那么 $F(x,t,t) = (x+t)^2 = (\sqrt{t^2 + 1/t^2})^2 = t^2 + 1/t^2。 

因此，问题减少到最小化$f(t) = t^2 + 1/t^2$超过$t>0$。 计算导数：

 f'(t) = 2t - 2/t^3 = 2(t - 1/t^3),

 设置$f'(t)=0$产量$t - 1/t^3 =0$， 所以$t^4=1$， 因此$t=1$（自从$t>0$）。 然后$x = -1 + \sqrt{1 +1} = \sqrt{2} -1$。 替换给出

 F_{\min} = (x+t)^2 = (\sqrt{2}-1 +1)^2 = (\sqrt{2})^2 = 2。 

因此，最小值为$(x+y)(x+z)$在给定约束下是$2$，达到时$y=z=1$和$x=\sqrt{2}-1$，或通过对称性，其任何排列。 极值配置满足原始约束：$xyz(x+y+z) = (\sqrt{2}-1)\cdot1\cdot1\cdot (\sqrt{2}-1 +1+1) = (\sqrt{2}-1) \cdot (\sqrt{2}+1) = 1$。 这样就完成了证明。 ∎ ## 关键步骤验证 拉格朗日乘子步骤要求$y=z$; 这通过除以导数方程得到证实。 另一种验证是假设$x\le y\le z$并认为$(x+y)(x+z)$正在增加$y$对于固定的$x$和$z$, 强迫$y=z$至少。 求解二次方程$x^2 +2 t x -1/t^2 =0$采取积极的根源是至关重要的； 使用负根会违反正性。 确认$x+t = \sqrt{2}$为了$t=1$准确地产生$F_{\min} =2$，与原始约束的直接检查一致。 最小化$t^2 + 1/t^2$超过$t>0$给出$t=1$，通过导数和评估附近的值进行验证，例如，$t=0.9$给出$0.81 +1.524 \approx 2.334>2$,$t=1.1$给出$1.21 +0.826 \approx 2.036>2$，确认全局最小值。 ## 替代方法 另一种方法是引入替换$x = a$,$y=z = b$立即将问题减少为两个变量并最小化$(a+b)^2$在下面$ab^2(a+2b)=1$。 这导致与拉格朗日相同的二次方程和解
