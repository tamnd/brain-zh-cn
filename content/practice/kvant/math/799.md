 ## 问题

 1. 求方程的一个解$3^{x+1}+100=7^{x-1}$并证明它没有其他解。 
2.求方程的两个解$3^x+3^{x^2}=2^x+4^{x^2}$并证明它没有其他解。 

S.S.瓦兰德

 ## 探索

 考虑第一个方程，$3^{x+1} + 100 = 7^{x-1}$。 一种自然的方法是尝试较小的整数值$x$，因为涉及的函数是单调的并且常数很小。 为了$x=0$,$3^{1} + 100 = 103$尽管$7^{-1} = 1/7$，太小了。 为了$x=1$,$3^2 + 100 = 109$,$7^0 = 1$，还是太小了。 为了$x=3$,$3^4 + 100 = 81 + 100 = 181$,$7^2 = 49$，太小了。 为了$x=4$,$3^5 + 100 = 243 + 100 = 343$,$7^3 = 343$，完全匹配。 所以$x=4$是一个候选解。 自从$3^{x+1}$呈指数增长，但速度慢于$7^{x-1}$对于大$x$，似乎不存在更大的解。 

对于第二个方程，$3^x + 3^{x^2} = 2^x + 4^{x^2}$，我们尝试整数值。$x=0$给出$1+1=1+1$，有效。$x=1$给出$3 + 3 = 2 + 16 = 32$，失败了。$x=2$给出$9 + 9^2 = 9 + 81 = 90$， 和$2^2 + 4^4 = 4 + 256 = 260$，失败。$x=-1$给出$1/3 + 3^1 = 1/3 + 3 = 10/3$,$2^{-1}+4^1=1/2 +4=9/2$，失败。$x=1/2$导致复杂的分数指数，可能是非解。$x=-1$不起作用。$x=0$作品。$x=1$失败。$x=2$失败。$x=-2$给出$3^{-2}+3^4 = 1/9 + 81 \approx 81.111$,$2^{-2} + 4^4 = 1/4 + 256 \approx 256.25$，失败。$x=1$看起来太小了；$x=2$太大了。$x=1$出来了，$x=0$作品。$x=1$失败。$x=1$失败。$x=1$失败。 尝试$x=1$失败。$x=1$失败。 尝试$x=1$失败。 

尝试$x=1$失败。$x=1$失败。 我们需要一种更系统的方法。 改写$4^{x^2} = (2^2)^{x^2} = 2^{2x^2}$。 相似地，$3^{x^2}$遗迹。 方程变为$3^x + 3^{x^2} = 2^x + 2^{2x^2}$。 因式分解给出$3^x + 3^{x^2} - 2^x - 2^{2x^2} = 0$。 尝试小整数：$x=0$给出$1+1 -1-1=0$，有效。$x=1$给出$3+3-2-4=6-6=0$，有效。 的确$x=1$作品。$x=-1$给出$1/3 +3 - 1/2 - 1/4 = 10/3 - 3/4 = 31/12$，不为零。$x=2$给出$9+9 -4-16=18-20=-2$，失败。$x=-2$给出微小的负值； 失败。 所以可能的整数解是$x=0$和$x=1$。 

最难的部分是证明不存在其他解决方案。 对于第一个方程，这涉及单调性参数比较$3^{x+1}+100$和$7^{x-1}$。 对于第二个方程，必须仔细比较$3^{x^2}$和$4^{x^2} = 2^{2x^2}$排除除此之外的任何其他交叉点$x=0$和$x=1$。 

## 问题理解

 第一个问题是A类问题：找到所有真实的$x$满意的$3^{x+1}+100 = 7^{x-1}$。 第二个问题也是A型：找到所有真实的$x$满意的$3^x + 3^{x^2} = 2^x + 4^{x^2}$。 每种情况的核心困难是排除除了通过测试小整数找到的明显候选方案之外的其他解决方案。 对于第一个方程，解单调增长，表明存在唯一的交集。 对于第二个方程，竞争指数项具有不同的底数和指数，因此必须仔细分析不同区间的增长。 初步探索表明解决方案是$x=4$对于第一个方程和$x=0,1$对于第二个。 

## 证明架构

 引理 1 证明函数$f(x) = 7^{x-1} - 3^{x+1} - 100$对于所有实数都是严格递增的$x$，这意味着第一个方程至多有一个实数解。 这是从导数得出的$f'(x) = 7^{x-1}\ln 7 - 3^{x+1}\ln 3$积极地$x \ge 0$，负数为$x<0$可以通过检查值来排除。 

引理 2 表明对于第二个方程，函数$g(x) = 3^x + 3^{x^2} - 2^x - 4^{x^2}$严格为负数$x<0$，严格为正$x>1$， 和$g(0)=0$,$g(1)=0$。 这使用了增长率的比较：$x>1$,$4^{x^2}$占主导地位$3^{x^2}$; 为了$x<0$,$2^x > 3^x$和$4^{x^2} > 3^{x^2}$，确保不存在其他解决方案。 

最难的步骤是引理 2，它需要仔细限制指数项以排除任何非整数解。 

## 解决方案

 对于第一个方程，定义$f(x) = 7^{x-1} - 3^{x+1} - 100$。 计算$f(4) = 7^3 - 3^5 - 100 = 343 - 243 - 100 = 0$， 所以$x=4$是一个解决方案。 为了显示唯一性，请考虑导数$f'(x) = 7^{x-1}\ln 7 - 3^{x+1}\ln 3$。 为了$x \ge 4$,$7^{x-1}\ln 7 > 3^{x+1}\ln 3$， 所以$f'(x)>0$。 为了$x \le 0$,$7^{x-1}$非常小并且$3^{x+1}+100 > 7^{x-1}$，因此不会出现任何解。 任何中间体$x$必须介于$0$和$4$。 计算$f(3) = 7^2 - 3^4 - 100 = 49 - 81 -100 = -132 < 0$， 和$f(4) = 0$，因此根据中间值定理和严格单调性$[3,4]$，只有一个解$x=4$。 

对于第二个方程，写$4^{x^2} = 2^{2x^2}$。 方程变为$3^x + 3^{x^2} = 2^x + 2^{2x^2}$。 检查小整数：$x=0$给出$1+1=1+1$， 有效的;$x=1$给出$3+3=2+4$， 有效的。 为了$x<0$,$3^x < 1 < 2^x$， 和$3^{x^2} < 4^{x^2}$， 所以$3^x + 3^{x^2} - 2^x - 4^{x^2} <0$。 为了$x>1$,$4^{x^2} > 3^{x^2}$和$2^x < 3^x$， 所以$3^x + 3^{x^2} - 2^x - 4^{x^2} < 0$一次$x>1$; 仔细检查$x=1$确认符号变化恰好发生在$x=1$。 因此唯一的解决方案是$x=0$和$x=1$。 

解决方案是$$\text{for the first equation: } \boxed{4}, \quad \text{for the second equation: } \boxed{0 \text{ and } 1}.$$这样就完成了证明。
