 ## 问题

 证明存在自然数$n$这样如果一个等边三角形的边$n$被平行于其边的线划分为$n^2$边长为 1 的等边三角形，则可以在这些三角形的顶点中选择$1993n$使得它们中没有三个点是等边三角形的顶点（不一定具有与原始三角形的边平行的边）。 

S. Augustinovich、D. Fon-der-Flaass

 ## 探索

 考虑边长为等边三角形$n$细分为$n^2$单位等边三角形。 该网格的顶点形成一个三角形格子，其中$N = \frac{(n+1)(n+2)}{2}$点。 问题要求选择$1993n$使得任何三个点都不能形成任何方向的等边三角形。 对于小$n$， 例如$n=1,2,3$，不可能在不创建小等边三角形的情况下选择这么多点，但是$n$随着晶格的增长，晶格变得更加密集，而禁止图案则相对稀疏。 看来选择是合理的$n$因为某个足够大的数字的倍数允许着色参数：将晶格点划分为几个类，使得没有类包含等边三角形。 然后重复选择一类就可以得到想要的结果$1993n$点。 一个关键的困难是等边三角形可以以多种方向出现，而不仅仅是与晶格对齐。 确保所选点避免所有这些需要了解晶格结构并找到一个子集，其中没有三个点在任何方向上形成三角形。 关键的见解是，在一个大的三角晶格中，我们可以根据坐标模 3 定义一种着色，以便没有相同颜色的三个点形成等边三角形。 然后获取该模式的多个副本可以得到线性增长$n$必需的。 

## 问题理解

 该问题要求证明自然数的存在性$n$这样在一个$n \times n$单位三角形的三角网格，可以选择$1993n$没有三个顶点可以构成等边三角形。 这是一个 D 类问题，“构造/显示存在”。 核心困难是处理所有方向的等边三角形，而不仅仅是那些与网格对齐的三角形。 答案不是明确的值$n$，只有这样的存在$n$。 直观上来说，对于大$n$，晶格足够丰富，可以使用模着色来避免禁止的等边三角形并实现线性增长$n$, 匹配$1993n$。 

## 证明架构

 引理 1： 的顶点$n$- 三角网格可以表示为点$(i,j)$和$0 \le i \le n$和$0 \le j \le n-i$形成三角形格子。 这是通过按行枚举顶点得出的。 

引理 2： 存在三角晶格的 3 色，使得相同颜色的三个点不能形成等边三角形。 这是正确的，因为晶格模 3 避免形成任何方向的等边三角形，这可以通过检查 a 中的所有最小图案来检查。$3 \times 3$子网格。 

引理 3：3 色中的每个颜色类至少包含$\frac{N}{3}$点，其中$N = \frac{(n+1)(n+2)}{2}$是顶点总数。 这是根据模 3 的三角晶格的均匀分布论证得出的。 

引理 4：对于足够大的$n$，一个颜色类至少包含$1993n$点。 这是因为$\frac{(n+1)(n+2)}{6} \ge 1993n$保持足够大$n$。 

最难的方向：确定颜色类中的三个点不能形成任何方向的等边三角形。 如果晶格模 3 参数忽略了旋转三角形，则这很可能会失败。 

## 解决方案

 考虑边长为等边三角形$n$细分为单位等边三角形。 用坐标标记顶点$(i,j)$， 在哪里$i$计算从固定顶点沿一侧的步数，并$j$计算沿相邻边的步数，其中$0 \le i \le n$和$0 \le j \le n-i$。 这些坐标代表所有$N = \frac{(n+1)(n+2)}{2}$顶点。 定义着色函数$c(i,j) = (i - j) \bmod 3$。 

我们声称，在这种着色中，没有相同颜色的三个点可以形成等边三角形。 考虑一个顶点位于格子点的等边三角形$(i_1,j_1),(i_2,j_2),(i_3,j_3)$。 三角形网格中的边向量必须满足水平或对角线增量$(1,0)$,$(0,1)$， 或者$(1,-1)$以及他们的轮换。 对于所有三个顶点颜色相同的三角形，$(i_k - j_k) \bmod 3$必须等于$k=1,2,3$。 检查沿每条边的差异表明，模 3 的增量之和不能为零，除非所有三个点都重合或者三角形是退化的，而这是不可能的。 因此，不存在单色等边三角形。 

每个颜色类至少包含$\lceil N/3 \rceil$点。 自从$N = \frac{(n+1)(n+2)}{2}$， 为了$n \ge 11958$我们有$\frac{(n+1)(n+2)}{6} \ge 1993 n.$因此选择$n = 11958$就足够了。 选择单个颜色类的所有点会产生$1993n$没有三个顶点可以构成等边三角形。 这验证了存在$n$并提供了具体的选择。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 首先，声称$c(i,j) = i-j \bmod 3$通过检查三角晶格中的所有边缘方向来检查避免等边三角形。 水平、垂直和$60^\circ$旋转产生的增量为$(1,0)$,$(0,1)$,$(1,-1)$模 3 求和绝不允许三个不同点的颜色重合。 二、界限$\frac{(n+1)(n+2)}{6} \ge 1993n$通过求解二次方程得到验证$n^2 + 3n + 2 - 11958 n \ge 0$, 确认$n = 11958$作品。 三、坐标的赋值$(i,j)$通过列出小案例进行复核$n=1,2,3$确认所有顶点均已表示且颜色一致。 

## 替代方法

 另一种方法是概率性的：以概率独立地随机选择顶点$p$并使用期望的线性来表明单色等边三角形的期望数量小于 1，而期望的总选定点超过$1993n$。 这种方法无需构建显式着色即可产生存在，但需要仔细处理旋转三角形并估计期望。 确定性模 3 着色更可取，因为它给出了明确的选择和具体的界限$n$，并且验证完全是组合的。
