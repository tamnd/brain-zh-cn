 ## 问题

 等腰三角形的顶点坐标是整数。 证明它的底数的平方是偶数。 

V·V·普罗伊兹沃洛夫

 ## 探索

 考虑等腰三角形的小例子，其顶点具有整数坐标。 最简单的此类三角形是与轴对齐的直角三角形。 例如，点$(0,0)$,$(2,0)$,$(1,1)$与底边形成等腰三角形$(0,0)-(2,0)$长度$2$， 和$2^2 = 4$是均匀的。 另一个例子是$(0,0)$,$(4,0)$,$(2,3)$; 底数的平方是$16$，也甚至。 对于小整数，尝试找到基数平方为奇数的反例失败，这表明奇偶校验约束正在发挥作用。 

检查坐标的奇偶性，注意如果两个基端点都是偶数或都是奇数$x$和$y$，距离的平方是偶数。 如果一为偶数，一为奇数，则坐标的平方差为奇数。 关键的困难在于证明对于具有整数顶点的等腰三角形，坐标奇偶性不能产生奇数的平方底。 

另一个角度是向量分析。 让$\mathbf{AB}$是基向量并且$\mathbf{AC}$和$\mathbf{BC}$相等的边。 平方距离涉及整数的平方和。 问题归结为如果两个平方距离相等，则剩余的平方距离一定是偶数。 挑战在于严格地形式化这一平等论点。 

## 问题理解

 问题要求证明，在任意顶点坐标均为整数的等腰三角形中，底边长度的平方是偶数。 这是 B 类问题，因为该陈述是通用的并且需要证明。 核心难点是当三角形具有整数坐标时控制平方距离的奇偶性。 从小例子和奇偶性考虑中得出的见解表明，底数的平方长度必然可以除以$2$。 

## 证明架构

 引理 1：在任何具有整数坐标的等腰三角形中，底边中点的坐标要么都是整数，要么都是半整数。 草图：中点公式$(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$直接显示这一点。 

引理 2：与底边相对的顶点必须与底边端点等距。 草图：根据等腰三角形的定义，到底端点的距离平方相等； 将这些距离展开为整数平方和。 

引理3：如果一条线段连接两个整数坐标点，并且与两个端点等距的点位于垂直平分线上，则该线段长度的平方是偶数。 草图：以代数方式表达坐标； 奇偶校验参数表明坐标差的平方和必须是偶数。 

最难的一步是引理 3，因为不小心的奇偶校验处理可能会导致错误的结论。 主要论点结合了前两个引理来应用奇偶校验约束。 

## 解决方案

 让$A=(x_1,y_1)$,$B=(x_2,y_2)$， 和$C=(x_3,y_3)$是具有整数坐标的等腰三角形的顶点。 认为$AB$是基础。 然后$AC=BC$，这意味着$$(x_3-x_1)^2 + (y_3-y_1)^2 = (x_3-x_2)^2 + (y_3-y_2)^2.$$两边展开，我们得到$$x_3^2 - 2x_3 x_1 + x_1^2 + y_3^2 - 2y_3 y_1 + y_1^2 = x_3^2 - 2x_3 x_2 + x_2^2 + y_3^2 - 2y_3 y_2 + y_2^2.$$减法$x_3^2 + y_3^2$从双方来看，我们得到$$-2 x_3 x_1 + x_1^2 - 2 y_3 y_1 + y_1^2 = -2 x_3 x_2 + x_2^2 - 2 y_3 y_2 + y_2^2.$$重写，我们有$$2 x_3 (x_2 - x_1) + 2 y_3 (y_2 - y_1) = x_2^2 - x_1^2 + y_2^2 - y_1^2.$$两边因式分解：$$2 x_3 (x_2 - x_1) + 2 y_3 (y_2 - y_1) = (x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1).$$两边除以$1$（还没有因子 2）。 现在观察左侧可被整除$2$， 自从$2 x_3 (x_2 - x_1) + 2 y_3 (y_2 - y_1)$显然是均匀的。 因此，右侧也必须是偶数：$$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1) \equiv 0 \pmod{2}.$$现在，$(x_2 - x_1)^2 + (y_2 - y_1)^2 = (x_2 - x_1)(x_2 - x_1) + (y_2 - y_1)(y_2 - y_1)$模同余$2$到上面的总和，因为对于任何整数$a,b$,$a^2 \equiv a \cdot a \equiv a \cdot a \pmod{2}$。 更准确地说，请注意$(x_2 - x_1)^2 + (y_2 - y_1)^2 = (x_2 - x_1)(x_2 - x_1) + (y_2 - y_1)(y_2 - y_1)$，这是一个整数同余模$2$到$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1)$因为$(x_2 - x_1)(x_2 + x_1) - (x_2 - x_1)^2 = (x_2 - x_1)(x_1 + x_2 - x_2 + x_1) = 2(x_2 - x_1)x_1$可以整除$2$，并且类似地对于$y$学期。 

因此，底边长度的平方$AB$,$$AB^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2,$$是均匀的。 这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是验证奇偶校验同余：$$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1) \equiv (x_2 - x_1)^2 + (y_2 - y_1)^2 \pmod{2}.$$独立重新推导：$(x_2 - x_1)(x_2 + x_1) - (x_2 - x_1)^2 = (x_2 - x_1)(2 x_1)$，可除以$2$。 同样对于$y$。 因此左侧甚至意味着$AB^2$是均匀的。 用具体例子进行测试，$(0,0),(1,0),(0,1)$未能形成等腰；$(0,0),(2,0),(1,1)$产量$AB^2 = 4$，这是均匀的，确认一致性。 

## 替代方法

 使用底边中点的矢量方法简化了论证。 让$M$是 的中点$AB$; 然后是第三个顶点$C$位于垂直于$AB$通过$M$。 自从$M$具有两个整数或两个半整数的坐标，距离的平方$A$到$B$必须能整除$2$维护整数坐标$C$。 这种方法强调几何，但简化为相同的宇称论证。 出于严格性，代数展开式是首选，因为它显式地处理所有整数可能性，而不需要关于坐标对齐的假设。
