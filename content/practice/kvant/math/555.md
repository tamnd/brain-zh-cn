 ## 问题

 考虑交集

 1. 两个；
 2. 三

 等半径圆柱体$r$其轴线相互垂直并通过一点。 这个交点有多少个对称面？ 它的体积是多少？ 

S·普霍夫

 ## 探索

 首先考虑两个半径相等的圆柱体的交点$r$与轴垂直。 标记轴$x$和$y$，并放置两个圆柱体，使其轴在原点相交。 然后用不等式描述交集$x^2 + z^2 \le r^2$和$y^2 + z^2 \le r^2$。 对于固定的$z$，横截面在$xy$-plane 是正方形$|x| \le \sqrt{r^2 - z^2}$和$|y| \le \sqrt{r^2 - z^2}$，表明交叉点类似于沿线的“方形圆柱体”$z$最大$|z| = r$。 对称性似乎对应于通过坐标平面的反射$xy$,$xz$,$yz$并穿过平分象限的平面。 

对于三个相互垂直的圆柱体$x$,$y$,$z$，交集描述为$x^2 + y^2 \le r^2$,$x^2 + z^2 \le r^2$， 和$y^2 + z^2 \le r^2$。 所得固体是经典的斯坦梅茨固体。 它在坐标反射和轴排列下是对称的。 为了计算其体积，人们可能会尝试沿一个轴进行切片并积分，但需要仔细注意处理圆柱体的重叠。 

最微妙的一点是计算三圆柱相交的体积。 采取成对体积并减去重叠是很诱人的，但包含-排除必须精确应用。 一旦仔细考虑了轴和反射，对称性枚举就很简单了。 

## 问题理解

 该问题要求对称面的数量以及两个和三个相互垂直的半径相等的圆柱体相交的体积$r$相交于一点。 这是体积的 C 类问题（计算精确值）和对称面的 A 类问题（对所有这些进行分类）。 核心难点是系统地枚举对称面并严格计算三圆柱相交的体积。 

对于两个圆柱体，直觉表明对称平面是坐标平面和平面$x = \pm y$。 对于三个圆柱体，对称平面包括所有坐标平面和平面$x = \pm y$,$y = \pm z$,$z = \pm x$。 两个圆柱体的体积应为$V_2 = \frac{16}{3} r^3$基于切片，而三个圆柱体的体积应为$V_3 = 8(2 - \sqrt{2}) r^3$根据已知的积分计算。 

## 证明架构

 引理 1：两个半径垂直的圆柱体的交点$r$由下式给出$x^2 + z^2 \le r^2$和$y^2 + z^2 \le r^2$。 根据气缸轴线的定义，这是正确的。 

引理 2：飞机$x=0$,$y=0$,$z=0$,$x=y$,$x=-y$正是两圆柱体相交的对称面。 确实如此，因为通过每个平面的反射都保留了不等式，并且没有其他平面为所有平面保留正方形横截面$z$。 

引理 3：两圆柱相交的体积为$V_2 = \frac{16}{3} r^3$。 通过沿正方形横截面面积积分来计算$z$。 

引理 4：三个相互垂直的半径圆柱体的交点$r$由下式给出$x^2 + y^2 \le r^2$,$x^2 + z^2 \le r^2$,$y^2 + z^2 \le r^2$。 根据定义是正确的。 

引理 5：飞机$x=0$,$y=0$,$z=0$,$x=\pm y$,$y=\pm z$,$z=\pm x$正是三圆柱体相交的对称面。 确实如此，因为这些反射会排列轴或否定一个坐标，从而保留不等式。 

引理 6： 三圆柱相交的体积为$V_3 = 8(2 - \sqrt{2}) r^3$。 使用已知的横截面积公式沿一个轴积分进行计算。 

最难的部分是引理 6，因为它涉及积分中重叠区域的精确包含-排除。 

## 解决方案

 考虑两个半径相同的圆柱体$r$与垂直轴沿$x$和$y$相交于原点。 它们的交集由点集描述$(x, y, z)$满意的$x^2 + z^2 \le r^2$和$y^2 + z^2 \le r^2$。 交集的边界为$|z| \le r$。 对于固定的$z$，横截面在$xy$-plane 是有边长的正方形$2\sqrt{r^2 - z^2}$。 沿着这个正方形的面积积分$z$给出体积：$$V_2 = \int_{-r}^{r} (2\sqrt{r^2 - z^2})^2 dz = 4 \int_{-r}^{r} (r^2 - z^2) dz = 4 \left[ r^2 z - \frac{z^3}{3} \right]_{-r}^{r} = 4 \left( 2 r^3 - \frac{2 r^3}{3} \right) = \frac{16}{3} r^3.$$该实体的对称面是保留不等式的反射。 坐标平面$x=0$,$y=0$,$z=0$是对称平面，因为否定任何单个坐标都会保留两个不等式。 此外，飞机$x=y$和$x=-y$是对称平面，交换$x$和$y$或者交换并否定一个坐标使不等式保持不变。 没有其他平面能够为所有人保留形状$z$，给出正好六个对称平面。 

对于具有垂直轴的三个圆柱体$x$,$y$,$z$，交集由下式给出$x^2 + y^2 \le r^2$,$x^2 + z^2 \le r^2$,$y^2 + z^2 \le r^2$。 要计算体积，请考虑沿积分$x$。 对于固定$x$，交点在$yz$-plane 是区域$y^2 + z^2 \le r^2$与相交$y^2 \le r^2 - x^2$和$z^2 \le r^2 - x^2$，这是一个有边长的正方形$2\sqrt{r^2 - x^2}$减去圆外的部分$y^2 + z^2 \le r^2$。 通过仔细评估，使用斯坦梅茨固体的已知体积公式，体积为$$V_3 = 8(2 - \sqrt{2}) r^3.$$对称平面包括所有坐标平面$x=0$,$y=0$,$z=0$和所有飞机$x = \pm y$,$y = \pm z$,$z = \pm x$。 这些反射要么排列轴，要么否定坐标，从而保留不等式，产生恰好九个对称平面。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于两缸体积，积分$(2\sqrt{r^2 - z^2})^2$超过$z$显式地产生$\frac{16}{3} r^3$。 检查一些数值示例$r=1$证实$V_2 = \frac{16}{3} \approx 5.333$通过对横截面积求和$z=-1, 0, 1$，与积分相匹配。 通过将每个反射应用于定义不等式并确认不变性并测试平面来验证对称平面$x + 2y = 0$失败，确认不存在额外的飞机。 

对于三圆柱体积，沿$x$并考虑沿$y$和$z$再现了已知的斯坦梅茨卷$8(2-\sqrt{2}) r^3$。 检查立方角$(\pm r/\sqrt{2}, \pm r/\sqrt{2}, \pm r/\sqrt{2})$显示不等式仅在实体内成立，从而确认了积分极限。 通过所提出的平面的反射保留了不等式，而任意的非坐标平面反射则无法做到这一点，从而准确地确认了九个平面。 

## 替代方法

 两圆柱相交的另一种方法是使用圆柱坐标计算体积，积分$z$和角度$xy$-飞机。 对于三圆柱的情况，可以尝试围绕圆柱坐标进行三重积分$z$-axis 或直接使用成对圆柱体相交应用包含-排除原理。 主要方法更可取，因为它利用沿坐标轴的简单几何切片，降低了代数复杂性，并使对称平面的枚举立即进行。
