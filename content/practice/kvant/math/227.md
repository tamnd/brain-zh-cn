 ## 问题

 在平行四边形的每一边上选择一个点。 以这些点为顶点的四边形的面积等于平行四边形面积的一半。 证明四边形的至少一条对角线与平行四边形的一条边平行。 

E.V.萨利宁

 ## 探索

 让平行四边形通过仿射变换映射到单位正方形，因为仿射映射保留了平行度、面积比以及位于线段上的点的条件。 在这种标准化下，平行四边形变成带有顶点的正方形$A(0,0)$,$B(1,0)$,$C(1,1)$,$D(0,1)$。 

设边上选定的点为$E(a,0)\in AB$,$F(1,b)\in BC$,$G(c,1)\in CD$,$H(0,d)\in DA$和$a,b,c,d\in[0,1]$。 

四边形是$EFGH$。 对角线与边平行的条件简化为简单的坐标约束：仅当对角线是水平或垂直时，对角线才与正方形的边平行。 该段$EG$有垂直位移$1$，所以它永远不可能是水平的； 因此，当它垂直时，它恰好平行于一条边，这迫使$a=c$。 相似地，$FH$恰好与一条边平行时$b=d$。 

因此问题简化为证明$a=c$或者$b=d$从地区条件来看。 

关键一步是表达面积$EFGH$按照$a,b,c,d$并分析由此产生的代数约束。 

## 问题理解

 这是一个B 类问题。 必须证明，如果在平行四边形的边上选择四个点，所得四边形的面积等于平行四边形的一半，则其对角线之一与平行四边形的一条边平行。 

仿射归一化后，任务变成单位正方形中的坐标几何语句。 基本的困难是将面积条件转化为代数恒等式，迫使相反参数相等。 

## 证明架构

 首先，使用仿射变换将平行四边形映射到单位正方形，保留所有相关属性。 

其次，将四个边界点的坐标引入为$E(a,0)$,$F(1,b)$,$G(c,1)$,$H(0,d)$。 

三、四边形的面积$EFGH$使用鞋带公式计算，产生一个表达式$a,b,c,d$。 

四、该面积等于的条件$1/2$被转换成一个方程，涉及$(a-c)(b-d)$。 

第五，对该方程进行分析，表明它迫使$a=c$或者$b=d$。 

最微妙的步骤是面积条件的代数约简以及使用参数有界性排除第二个代数情况。 

## 解决方案

 仿射变换将平行四边形缩小为单位正方形，而不改变平行度或面积比。 因此，考虑具有顶点的正方形就足够了$A(0,0)$,$B(1,0)$,$C(1,1)$,$D(0,1)$。 

让$E(a,0)\in AB$,$F(1,b)\in BC$,$G(c,1)\in CD$,$H(0,d)\in DA$， 在哪里$a,b,c,d\in[0,1]$。 

的对角线$EFGH$平行于正方形的一条边当且仅当它是水平或垂直的。 向量$EG=(c-a,1)$永远不会水平，因此当它垂直时，它恰好与一条边平行，这相当于$c-a=0$， 因此$a=c$。 向量$FH=(-1,d-b)$永远不会垂直，因此当它是水平的时，它恰好与一条边平行，这相当于$d-b=0$， 因此$b=d$。 仍有待证明$a=c$或者$b=d$。 

面积为$EFGH$由鞋带公式按循环顺序计算$E,F,G,H$：$$S_1 = a b + 1 + c d,$$

$$S_2 = 0\cdot 1 + b c + 1\cdot 0 + d a = bc + ad.$$因此面积为$$[EFGH] = \frac12 |S_1 - S_2| = \frac12 |1 + ab + cd - bc - ad|.$$条件$[EFGH]=\frac12$意味着$$|1 + ab + cd - bc - ad| = 1.$$让$$T = 1 + ab + cd - bc - ad.$$然后$|T|=1$，所以要么$T=1$或者$T=-1$。 

如果$T=1$， 然后$$ab + cd - bc - ad = 0.$$分组项给出$$a(b-d) + c(d-b) = (a-c)(b-d) = 0,$$所以$a=c$或者$b=d$。 

如果$T=-1$， 然后$$1 + ab + cd - bc - ad = -1,$$所以$$ab + cd - bc - ad = -2.$$左边等于$(a-c)(b-d)$， 因此$$(a-c)(b-d) = -2.$$自从$a,c,b,d\in[0,1]$，每个因素都在于$[-1,1]$，所以他们的产品在于$[-1,1]$，矛盾$(a-c)(b-d)=-2$。 因此，这种情况是不可能的。 

所以$a=c$或者$b=d$，这意味着$EG$或者$FH$平行于正方形的一条边，因此也平行于原始平行四边形的一条边。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 仿射约简保留了该条件，因为仿射图保留了共线性、并行性和面积比，因此面积的相等性被保留到一个常数因子，当与总面积的一半进行比较时，该常数因子被取消。 

在鞋带计算中，每个顶点恰好贡献以下形式的一个乘积$x_i y_{i+1}$以及其中一种形式$y_i x_{i+1}$按循环顺序，所有零项均来自位于轴上的边界坐标，仅记录四个非零贡献。 

身份$ab + cd - bc - ad = (a-c)(b-d)$接下来是直接展开式，而第二种情况的矛盾仅在于以下事实：$a-c$和$b-d$每个都躺在$[-1,1]$，所以他们的乘积不能等于$-2$。 

## 替代方法

 综合方法通过将区域条件解释为通过将四边形投影到平行于平行四边形各边的方向而获得的定向子区域之间的线性依赖关系来避免坐标。 这通过有符号面积分解隐式地导致相同的代数约束。 坐标方法更可取，因为它将条件简化为单个显式方程，其因式分解立即强制所需的简并性。
