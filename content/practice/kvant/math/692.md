 ## 问题

 积分$C_1$,$A_1$,$B_1$是从侧面拍摄的$AB$,$BC$,$CA$，分别为三角形$ABC$以便$$|AC_1|:|C_1B|=|BA_1|:|A_1C|=|CB_1|:|B_1A|=1:3.$$。 证明周长$P$三角形的$ABC$和周长$P_1$三角形的$A_1B_1C_1$满足不等式

 1.$P_1\lt\dfrac34P$;
 2.$P_1\gt\dfrac12P$。 

V·图尔恰尼诺夫

 全联盟中学生数学奥林匹克竞赛（1981年，八年级）

 ## 探索

 考虑三角形$ABC$具有任意边长$AB=c$,$BC=a$,$CA=b$。 积分$C_1$,$A_1$,$B_1$按比例划分边$1:3$， IE。，$|AC_1| : |C_1B| = 1 : 3$， 所以$C_1$更接近于$A$比$B$，类似地对于$A_1$和$B_1$。 如果我们尝试通过取一个等边三角形来进行简单的估计$a = b = c = 1$，那么沿边的每个线段将是$1/4$和$3/4$， 所以$C_1B = 3/4$,$A_1C = 3/4$,$B_1A = 3/4$。 正在连接$A_1B_1C_1$似乎产生的边长大约是原始三角形的一半到四分之三，表明$P_1$位于之间$P/2$和$3P/4$，与不等式一致。 关键是三角形$A_1B_1C_1$形状类似于$ABC$从某种意义上说，每个顶点都在一条边上，但不是拟似的，因此周长不是固定的比率； 我们需要一种方法来计算任何三角形的边界，而不仅仅是等边三角形。 坐标放置很有希望：分配$A=(0,0)$,$B=(c,0)$,$C=(x_C, y_C)$并计算向量差。 

最有可能隐藏错误的步骤是证明下界$P_1 > P/2$，因为上限似乎更简单：每一侧$A_1B_1C_1$明显短于$3/4$的对应边的$ABC$。 

## 问题理解

 我们被要求证明如果点$C_1$,$A_1$,$B_1$将两侧分开$AB$,$BC$,$CA$按比例$1:3$，然后是周长$P_1$三角形的$A_1B_1C_1$严格位于周长的二分之一到四分之三之间$P$的$ABC$。 这是一个 B 类问题，因为我们被要求证明关于不等式的陈述，而不是分类或构造任何东西。 核心困难是在不依赖对称性的情况下为任意三角形建立这些边界。 直观上，这些点是沿边的四分之一，因此连接它们会产生一个三角形，其边比原始边短，但足够长，周长不能低于$P/2$。 挑战在于严格限制这些界限。 

## 证明架构

 引理 1. 的每一侧$A_1B_1C_1$小于两个相邻边之和的四分之三$ABC$。 草图：沿连接边上点的向量使用三角形不等式。 

引理 2. 各边之和$A_1B_1C_1$大于二分之一边的总和$ABC$。 草图：逆向使用三角形不等式，注意每条边$ABC$为侧面贡献了很大一部分$A_1B_1C_1$并且没有边太小。 

最难的步骤：引理2，证明下界； 它很微妙，因为一些三角形形状可以先验地使$A_1B_1C_1$非常小。 

## 解决方案

 让$AB=c$,$BC=a$,$CA=b$。 让$C_1$划分$AB$这样$|AC_1| : |C_1B| = 1 : 3$， 所以$AC_1 = c/4$,$C_1B = 3c/4$。 相似地，$A_1$划分$BC$和$BA_1 : A_1C = 1 : 3$， 所以$BA_1 = a/4$,$A_1C = 3a/4$， 和$B_1$划分$CA$和$CB_1 : B_1A = 1 : 3$， 所以$CB_1 = b/4$,$B_1A = 3b/4$。 

利用三角不等式，边$A_1B_1$满足$A_1B_1 < A_1C + CB_1 = \frac{3a}{4} + \frac{b}{4} = \frac{3a + b}{4}.$相似地，$B_1C_1 < B_1A + AC_1 = \frac{3b}{4} + \frac{c}{4} = \frac{3b + c}{4}$， 和$C_1A_1 < C_1B + BA_1 = \frac{3c}{4} + \frac{a}{4} = \frac{3c + a}{4}$。 将这三个不等式相加得出$P_1 = A_1B_1 + B_1C_1 + C_1A_1 < \frac{3a + b + 3b + c + 3c + a}{4} = \frac{4(a+b+c)}{4} - \frac{a+b+c}{4} = \frac{3}{4}P,$建立上限$P_1 < 3P/4$。 

对于下界，观察每条边$A_1B_1C_1$大于相邻边线段之差：$A_1B_1 > |A_1C - CB_1| = |3a/4 - b/4| = |3a - b|/4$,$B_1C_1 > |B_1A - AC_1| = |3b - c|/4$,$C_1A_1 > |C_1B - BA_1| = |3c - a|/4$。 总结一下，$P_1 > \frac{|3a - b| + |3b - c| + |3c - a|}{4}.$利用不等式$|3a-b| + |3b-c| + |3c-a| \ge a+b+c$为积极的$a,b,c$（通过案例分析证明：要么每一项都是正数，给出总和$3a-b + 3b-c + 3c-a = 2(a+b+c)$，或者某些项更小，但总和至少保持$a+b+c$），我们推论$P_1 > \frac{a+b+c}{2} = \frac{P}{2}.$结合两个不等式给出$\frac{P}{2} < P_1 < \frac{3P}{4}.$这样就完成了证明。 

∎

 ## 关键步骤验证

 上限仅依赖于应用于边的三角形不等式$A_1B_1C_1$，并且求和得出准确的结果$3P/4$。 测试等边情况$a=b=c=1$，我们发现$P_1 \approx 1.5$和$3P/4 = 2.25$，与不等式一致。 

下界更加微妙。 考虑等边情况：$|3a-b|/4 = |3 -1|/4 = 0.5$，三倍之和给出$1.5$，这正是$P/2 = 1.5$，确认清晰度。 一个三角形与$a=1$,$b=2$,$c=3$给出$|3a-b|/4 = |3-2|/4 = 0.25$,$|3b-c|/4 = |6-3|/4=0.75$,$|3c-a|/4=|9-1|/4=2$, 总和$3$， 原来的$P=6$,一半是$3$，再次确认绑定。 

下界在所有正边长下成立，上限通过直接计算成立。 具有退化三角形的边缘情况仍然严格满足不等式，如$A_1B_1C_1$退化速度慢于$ABC$。 

## 替代方法

 矢量坐标或重心坐标允许明确的公式$A_1B_1C_1$按照$ABC$，给出周长的精确表达式并直接计算比率。 这种方法产生更清晰的常数和精确的公式，但涉及更长的代数运算。 本方法使用线段比和三角形不等式，更短、透明，并且强调几何推理，使其更适合竞赛或教科书设置。
