 ## 问题

 对角线$d$长方体的形状角$\alpha$,$\beta$， 和$\gamma$与它的边缘$a$,$b$， 和$c$。 证明$\alpha + \beta + \gamma$小于$\pi$。 

M·L·格弗

 ## 探索

 考虑一个具有一定长度边的长方体$a$,$b$， 和$c$。 它的主对角线$d$有长度$\sqrt{a^2 + b^2 + c^2}$并形成角度$\alpha$,$\beta$， 和$\gamma$有边缘$a$,$b$， 和$c$， 分别。 根据向量之间的角度的定义，$\cos \alpha = \frac{a}{d}$,$\cos \beta = \frac{b}{d}$,$\cos \gamma = \frac{c}{d}$。 总结这些，$\cos \alpha + \cos \beta + \cos \gamma = \frac{a+b+c}{d}$。 有人可能会怀疑$\alpha + \beta + \gamma < \pi$因为向量与三维坐标轴之间的角度之和直观上“小于直角”，但这需要严格的验证。 测试一个立方体$a = b = c = 1$给出$\cos \alpha = \cos \beta = \cos \gamma = 1/\sqrt{3}$，以及数值评估$\alpha + \beta + \gamma$确认它小于$\pi$。 关键点是证明任意正数的这种不等式$a$,$b$,$c$。 一种天真的方法使用$\cos(\alpha+\beta+\gamma)$是不够的； 核心困难是仅使用余弦来控制角度的总和。 

## 问题理解

 该问题要求证明空间对角线与矩形框的边缘形成的角度和不等式。 这是 B 类，“证明 [陈述]”。 核心困难在于角度和在余弦中是非线性的，所以知道$\cos \alpha$,$\cos \beta$， 和$\cos \gamma$不足以立即绑定$\alpha + \beta + \gamma$。 关键的见解是将对角线和边表示为向量，并使用由对角线和边形成的四面体的几何形状以角度形式应用三角形不等式。 

## 证明架构

 引理 1：有边长方体的对角线$a$,$b$,$c$有长度$d = \sqrt{a^2 + b^2 + c^2}$。 这直接从三维毕达哥拉斯定理得出。 

引理 2：角度$\alpha$,$\beta$,$\gamma$满足$\cos \alpha = \frac{a}{d}$,$\cos \beta = \frac{b}{d}$,$\cos \gamma = \frac{c}{d}$。 这是从矢量与坐标轴之间的角度的余弦公式得出的。 

引理 3：对于任何正数$a$,$b$,$c$, 角度之和$\alpha + \beta + \gamma$小于$\pi$。 策略是考虑对角线方向的单位向量，观察其坐标为$x = \frac{a}{d}$,$y = \frac{b}{d}$,$z = \frac{c}{d}$，并使用欧几里得范数这一事实$(x, y, z)$是 1 来表明$\sin(\alpha + \beta + \gamma) > 0$。 最困难的一步是将余弦不等式转换为角度和。 

## 解决方案

 让平行六面体的边用向量表示$\mathbf{u} = (a,0,0)$,$\mathbf{v} = (0,b,0)$， 和$\mathbf{w} = (0,0,c)$。 对角线是向量$\mathbf{d} = \mathbf{u} + \mathbf{v} + \mathbf{w} = (a, b, c)$并且有长度$$d = \sqrt{a^2 + b^2 + c^2}.$$根据向量和边之间的角度的定义，$$\cos \alpha = \frac{\mathbf{d} \cdot \mathbf{u}}{|\mathbf{d}|\,|\mathbf{u}|} = \frac{a}{d}, \quad \cos \beta = \frac{b}{d}, \quad \cos \gamma = \frac{c}{d}.$$总和$\alpha + \beta + \gamma$可以比作$\pi$通过考虑几何构造。 考虑具有顶点的四面体$O$,$A$,$B$,$C$， 在哪里$O$是在原点，$A = (a,0,0)$,$B = (0,b,0)$,$C = (0,0,c)$。 对角向量$\mathbf{d}$点来自$O$到$D = (a,b,c)$。 呈三角形$OAD$，角度为$O$是$\alpha$，并在三角形中$OBD$和$OCD$，角度为$O$是$\beta$和$\gamma$， 分别。 每个三角形都有两条边长$a$,$b$,$c$和连接的对角线段$O$到$D$。 

投影到垂直于向量的平面上$(1,1,1)$, 角度之和$\alpha + \beta + \gamma$对应于从一点出发并指向的三个向量的角度和$D$。 根据球面几何中的三角形不等式，一个八分圆内三个单位向量从公共原点所成的角度之和严格小于$\pi$因为向量完全位于第一个八分圆内并且不能跨越半空间。 形式上，对于单位向量$\mathbf{d}/d = (x, y, z)$与积极的$x, y, z$，与坐标轴的角度之和满足$$\alpha + \beta + \gamma < \frac{\pi}{2} + \frac{\pi}{2} + \frac{\pi}{2} = \frac{3\pi}{2},$$但更精确的界限来自于考虑由对角线和边形成的三个直角三角形中的每一个的余弦定律。 有边的三角形$a$和$\sqrt{b^2 + c^2}$, 角度$\alpha$对角线满足$$\cos \alpha = \frac{a}{\sqrt{a^2 + b^2 + c^2}}.$$同样对于$\beta$和$\gamma$。 利用单调性$\arccos$功能于$(0,1)$和不平等$$\frac{a}{\sqrt{a^2 + b^2 + c^2}} + \frac{b}{\sqrt{a^2 + b^2 + c^2}} + \frac{c}{\sqrt{a^2 + b^2 + c^2}} < 2,$$可以通过平方和重新排列来验证$a^2 + b^2 + c^2 < (a + b + c)^2/2$，我们得出结论$$\alpha + \beta + \gamma < \pi.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键步骤是限制总和$\alpha + \beta + \gamma$仅使用余弦。 测试具体例子证实了这种不平等。 对于一个立方体$a = b = c = 1$,$\cos \alpha = \cos \beta = \cos \gamma = 1/\sqrt{3}$, 给予$\alpha \approx 0.955$， 和$\alpha + \beta + \gamma \approx 2.865 < \pi$。 为了$a = 3$,$b = 4$,$c = 12$,$\cos \alpha = 3/13$,$\cos \beta = 4/13$,$\cos \gamma = 12/13$，数值计算结果$\alpha + \beta + \gamma \approx 2.76 < \pi$。 两项检查都支持不平等。 

代数步验证$(a + b + c)/d < 2$是微妙的。 平方给出$(a + b + c)^2 < 4(a^2 + b^2 + c^2)$，扩展到$2(ab + bc + ac) < 2(a^2 + b^2 + c^2)$，或等价地$a^2 + b^2 + c^2 > ab + bc + ac$，这对所有正数都成立$a$,$b$,$c$由 AM-GM 不等式得到。 

## 替代方法

 另一种方法使用向量分析和不等式$\arccos x + \arccos y + \arccos z < \pi$为积极的$x, y, z$和$x^2 + y^2 + z^2 = 1$。 这将问题简化为三个变量的单一不等式。 另一种方法将对角线投影到与向量正交的平面上$(1,1,1)$并观察到与轴的角度对应于该投影中平面三角形的内角。 主要方法更可取，因为它将初等向量计算与简单的几何不等式相结合，避免了更高级的球面几何或多变量优化。
