 ## 问题

 将印迹放在一张纸上。 对于印迹的每个点，确定到印迹边界的最小距离和到印迹边界的最大距离（该图显示了该点到边界的最大和最小距离$K$）。 在所有最小的距离中，选择了最大的距离——$r_0$，并且在最大的距离中，选择了最小的距离 -$R_0$。 如果是的话，印迹的形状是什么$r_0=R_0$？

 ## 探索

 考虑任意紧凑的平面印迹。 为了一点$P$在印迹中，让$r(P)$表示距离的最小距离$P$到边界，并且$R(P)$最大距离$P$到边界。 然后$r_0 = \max_P r(P)$和$R_0 = \min_P R(P)$。 如果$r_0 = R_0$, 每一点$P$达到$r_0$以及获得的每一点$R_0$必须满足$r(P) = R(P)$。 一个小的不对称形状，如椭圆形或矩形，似乎违反了这个等式，因为靠近中心的点有$r(P) < R(P)$，并且角点附近的点有$r(P) = 0 < R(P)$。 为了平等$r_0 = R_0$要成立，似乎从“中心”到边界的距离在所有方向上都必须相同，这表明是一个圆。 为了测试，取一个半径为圆的圆$r$：那么中心的每个点都有距离$r$到边界，最小和最大，所以$r_0 = R_0 = r$。 任何与圆度的偏差似乎都会产生这样的点：$r(P) < R(P)$或者最大距离超过最小距离，矛盾$r_0 = R_0$。 微妙的一点是验证没有其他凸形或非凸形可以满足这个等式。 非凸形状往往会创建点$r(P) < R(P)$附近的凹痕，证实了这个圆是唯一的怀疑。 

## 问题理解

 该问题要求确定平面印迹的形状，条件是印迹内任何点到其边界的最大最小距离等于印迹内任何点到边界的最小最大距离。 这是一个 A 类问题，需要对满足条件的所有形状进行分类。 核心难点在于证明唯一性：只有圆满足$r_0 = R_0$。 直观上，等式意味着存在一个点，其到边界上每个点的距离在所有方向上都是恒定的，这是圆所特有的性质。 答案是一个圆圈。 

## 证明架构

 引理 1. 对于任何紧凑印迹，$r_0 \le R_0$。 这是因为对于任何点$P$,$r(P) \le R(P)$，所以他们的极值满足$r_0 = \max r(P) \le \min R(P) = R_0$。 

引理 2. 如果$r_0 = R_0$，存在一个点$C$在印迹中这样的距离$C$边界上的每个点都恰好是$r_0$。 这个想法是$r_0$在某个时刻达到，并且平等$r_0 = R_0$强制从该点到的最大距离与$r_0$。 

引理 3. 包含点的平面紧集$C$使得边界的所有点都处于一定距离$r_0$从$C$是一个半径为圆的圆$r_0$以$C$。 这是从圆的定义得出的：距固定中心等距的点的集合。 

最难的方向是引理 2：表明$r_0 = R_0$强制存在一个与整个边界等距的点。 粗心的论证可能会毫无根据地假设凸性或对称性。 因此，最微妙的引理是引理 2。 

## 解决方案

 引理 1.设$r(P)$是距离的最小距离$P$到边界和$R(P)$最大距离。 然后$r(P) \le R(P)$为所有人$P$在印迹中，因为边界上最近的点不能比最远的点更远。 取最大值和最小值，$\max_P r(P) \le \min_P R(P)$， 因此$r_0 \le R_0$。 

引理 2. 假设$r_0 = R_0 = \rho$。 让$C$是一个点$r(P)$达到最大$r_0$。 然后$r(C) = \rho$。 自从$R_0 = \rho$， 为了$C$最大距离$R(C)$必须满足$R(C) \ge r_0 = \rho$。 另一方面，$R(C) \ge r(C) = \rho$， 和$R_0 = \min_P R(P) = \rho$， 所以$R(C) = \rho$。 因此，最小和最大距离$C$与边界重合，$r(C) = R(C) = \rho$。 因此，边界的每一点都恰好位于距离$\rho$从$C$。 

引理 3. 让$B$是印迹的边界。 如果每一个点$B$是在距离$\rho$从一个固定点$C$， 然后$B$是距离上所有点的集合$\rho$从$C$，即半径的圆$\rho$以$C$。 因此，印迹正是由该圆包围的圆盘。 

由引理 1，$r_0 \le R_0$，因此只有在引理 2 的特殊配置中才可能相等。根据引理 2，相等意味着存在一个点$C$与所有边界点等距。 然后引理 3 确定印迹是圆形。$\boxed{\text{The blot is a circle.}}$## 关键步骤验证

 在引理 2 中，考虑一点$C$达到$r_0$。 认为$R(C) > r_0$。 然后是所有点的最小值$P$的$R(P)$将严格小于$R(C)$, 给予$R_0 < R(C)$。 但我们有$R_0 = r_0 = \rho = r(C)$。 这个矛盾证实了$R(C) = r(C)$。 

在引理 3 中，所有点都处于一定距离的非凸边界的可能性$\rho$从$C$被排除，因为任何边界点比$\rho$违反了距离相等。 这证实了边界必须是距离恰好相等的点的集合$\rho$，形成一个圆圈。 

## 替代方法

 变分方法考虑使印迹的边界变形并观察对印迹的影响$r_0$和$R_0$。 增加一个方向的距离会增加$R_0$或减少$r_0$，所以任何不对称都会导致$r_0 < R_0$。 这立即将圆选为唯一满足的对称配置$r_0 = R_0$。 该方法较短，但需要对连续变形进行推理，所选择的方法通过仅依赖显式距离和极值点来避免这种情况。 另一种方法是通过凸性：假设印迹是凸的，$r_0$是内半径并且$R_0$是外接半径，内半径和外接半径相等仅适用于圆。 主要证明是更可取的，因为它不需要凸性并且适用于所有紧平面集。
