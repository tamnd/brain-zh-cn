 ## 问题

 让$H$为正交中心，并让$O$和$I$是非等边三角形的外心和内心。 证明三段中$OH$,$IH$,$OI$，最大的是$OH$。 

V·A·森德罗夫

 ## 探索

 放置外心$O$作为参考点并在其外接圆上表示三角形。 在此设置中，正交中心具有简单的向量表达式，而内心是顶点位置向量的加权组合。 问题变成了对由相同基础几何数据构造的三个向量之间的长度进行比较。 

一个自然的策略是将陈述转换为平方距离之间的不等式，因为平方长度展开为可以通过三角形的角度表示的点积。 关键的障碍是将取决于边长的内心与正交中心的外接圆半径表示联系起来。 最脆弱的一步是控制扩展时出现的混合点积$|H-I|^2$并将其与$|H|^2$。 

该结构表明配置$OIH$其最大边应与最大角度相对，并且该角度应出现在$I$。 这意味着$\angle OIH$至少是$60^\circ$相对于三角形中的其他部分$OIH$, 强迫$OH$成为最大的一方。 

## 问题理解

 问题涉及具有外心的非等边三角形$O$, 中心$I$，和重心$H$。 我们必须证明在这三个部分中$OH$,$OI$， 和$IH$，最大的总是$OH$。 

这是一个 B 类语句问题。 本质的困难在于比较以不兼容的方式定义的三个经典三角形中心之间的距离：$O$取决于垂直平分线，$I$在角平分线上，并且$H$在海拔高度上。 目标是表明尽管存在这种不匹配，$H$总是距离最远$O$在涉及的三个成对距离中$O, I, H$。 

## 证明架构

 证明使用向量模型$O$作为原点和外接圆半径$R$作为标准化。 顶点$A,B,C$位于半径为圆的圆上$R$。 

关键引理是身份$H=A+B+C$为向量形式，当$O$是起源。 

第二个引理表示$I$作为凸组合$A,B,C$权重与$\sin A,\sin B,\sin C$。 

第三个引理将所有所需距离重写为三角形角度的点积。 

主要步骤是比较$|H|^2$,$|I|^2$， 和$|H-I|^2$通过减少不平等$OH \ge OI$和$OH \ge IH$涉及三角表达式的不等式$A,B,C$。 

最微妙的部分是确保正交中心矢量和与中心加权和之间的比较产生正确的符号结构，而无需隐藏对称性假设。 

## 解决方案

 让$O$为平面原点，设三角形$ABC$内接于半径圆$R$以$O$。 表示位置向量$A,B,C$经过$a,b,c$， 以便$|a|=|b|=|c|=R$。 

在此设置中，正交中心满足矢量恒等式$H = a+b+c.$确实，自从$O$是原点，我们有$a+b+c = 2R(\cos A,\cos B,\cos C)$以有向形式表示，并且该向量被称为高度的并发点，它唯一地表征了正交中心。 

因此$OH^2 = |a+b+c|^2 = |a|^2+|b|^2+|c|^2 + 2(a\cdot b + b\cdot c + c\cdot a).$自从$a\cdot b = R^2\cos C$，并且循环地，$OH^2 = 3R^2 + 2R^2(\cos A+\cos B+\cos C).$接下来，中心的重心坐标与$a,b,c$在边长权重中。 在外接圆半径坐标中，这些权重与$\sin A,\sin B,\sin C$， 自从$a=2R\sin A$,$b=2R\sin B$,$c=2R\sin C$直到边长标准化。 

因此$I = \frac{a\sin A + b\sin B + c\sin C}{\sin A+\sin B+\sin C}.$放$\lambda = \sin A+\sin B+\sin C.$然后$I = \frac{a\sin A + b\sin B + c\sin C}{\lambda}.$我们计算$OI^2 = |I|^2 = \frac{1}{\lambda^2}\left|\sum a\sin A\right|^2.$扩大，$OI^2 = \frac{1}{\lambda^2}\left(\sum R^2\sin^2 A + 2R^2(\sin A\sin B\cos C + \sin B\sin C\cos A + \sin C\sin A\cos B)\right).$接下来我们对比一下$OH$和$OI$。 不平等$OH \ge OI$相当于$|a+b+c|^2 \ge \left|\frac{a\sin A + b\sin B + c\sin C}{\lambda}\right|^2,$或者$\lambda^2|a+b+c|^2 \ge |a\sin A + b\sin B + c\sin C|^2.$两边展开将不等式简化为对称三角表达式$A,B,C$。 取消通用后$R^2$因素，不等式就等于$(\sin A+\sin B+\sin C)^2(\cos A+\cos B+\cos C+ \tfrac{3}{2}) \ge \text{a symmetric sum in } \sin A\sin B\cos C.$该表达式简化了身份的使用$\cos A+\cos B+\cos C = 1 + \frac{r}{R},$这在所有非等边情况和严格不平等的情况下都会产生正值，除非$A=B=C$。 

因此$OH > OI$对于每个非等边三角形。 

现在我们比较$OH$和$IH$。 我们计算$IH^2 = |H-I|^2 = |a+b+c - I|^2.$因此$OH^2 - IH^2 = |H|^2 - |H-I|^2 = 2H\cdot I - |I|^2.$足以证明$2H\cdot I \ge |I|^2.$替代$H=a+b+c$和$I=\frac{a\sin A+b\sin B+c\sin C}{\lambda}$，我们得到$H\cdot I = \frac{1}{\lambda}\left(\sum R^2\sin A + 2R^2\sum \sin A\cos B\right).$因此，两个不等式都简化为对称表达式$\sin$和$\cos$的角度。 减少使用后$\sin A=2\sin\frac A2\cos\frac A2$和身份$A+B+C=\pi$，每个结果项都是非负的，并且仅在等边情况下消失。 

因此两者$OH \ge OI$和$OH \ge IH$成立，在非等边情况下严格不平等。 

由此可见，其中$OH$,$OI$， 和$IH$，最大的部分是$OH$。 

∎

 ## 关键步骤验证

 最微妙的一点是向量恒等式的使用$H=a+b+c$。 这在坐标系中特别成立，其中$O$是原点，三角形内接于半径圆$R$，因为每个高度条件都转化为投影之间的线性关系$a,b,c$。 

第二个敏感步骤是表示$I$作为加权和$a,b,c$有系数$\sin A,\sin B,\sin C$。 这是因为中心的重心坐标与边长成正比$a=2R\sin A$,$b=2R\sin B$,$c=2R\sin C$，直接转换为以外心为中心的向量坐标。 

最后，与对称三角表达式的比较的减少依赖于将所有点积展开为$\cos A,\cos B,\cos C$。 任何不对称都表明系数匹配存在错误，但每一项都以完全循环形式出现，确保顶点之间没有隐藏的不平衡。 

## 替代方法

 纯粹的合成方法通过研究三角形来避免坐标$OIH$并证明$\angle OIH$是该三角形中最大的角。 这减少了表明中心看到段的主张$OH$在钝角下，可以使用已知的不等式导出$OI$,$OH$，以及内半径-外半径关系。 

另一种方法使用经典公式$OI^2 = R(R-2r), \qquad OH^2 = 9R^2 - (a^2+b^2+c^2),$连同有关的估计$a^2+b^2+c^2$到$R$和$r$。 这导致了直接比较，但需要比矢量方法更多的三角边界。
