 ## 问题

 让$A$,$B$,$C$是平行六面体与其顶点相邻的顶点$P$，并让$Q$是与 相对的顶点$P$。 证明

 1. 到点的距离$A$,$B$,$C$到线$PQ$可以作为某个三角形的边长；
 2. 面积$S$这个三角形的体积$V$平行六面体的形状和长度$d$其对角线的$PQ$由方程相关$V = 2dS$。 

I.F.沙里金

 ## 探索

 考虑一个有顶点的平行六面体$P$在原点，沿向量的边$\vec{a}$,$\vec{b}$,$\vec{c}$通向相邻顶点$A = P + \vec{a}$,$B = P + \vec{b}$,$C = P + \vec{c}$。 相反的顶点是$Q = P + \vec{a} + \vec{b} + \vec{c}$。 线路$PQ$有方向$\vec{a} + \vec{b} + \vec{c}$。 距离$A$到$PQ$由空间中点到线的距离的标准公式给出：$d_A = \frac{| \vec{AP} \times \vec{PQ} |}{| \vec{PQ} |}$。 类似的公式适用于$B$和$C$。 这些叉积减少为$\vec{a} \times (\vec{a} + \vec{b} + \vec{c})$,$\vec{b} \times (\vec{a} + \vec{b} + \vec{c})$， 和$\vec{c} \times (\vec{a} + \vec{b} + \vec{c})$。 扩展产生如下表达式$\vec{a} \times \vec{b} + \vec{a} \times \vec{c}$。 这些都是垂直于$PQ$。 由于平行六面体几何形状和由同一平面中的三个向量形成的三角形，三角形不等式似乎可以得到满足$PQ$。 

对于第二部分，体积为$V = |\vec{a} \cdot (\vec{b} \times \vec{c})|$和长度$PQ$是$d = |\vec{a} + \vec{b} + \vec{c}|$。 所形成的三角形的面积为$d_A, d_B, d_C$可以使用正交于平面的向量叉积来表示$PQ$。 使用向量三重积的直接计算表明了一个因子$2$出现，暗示$V = 2dS$。 

关键点是表明$d_A$,$d_B$,$d_C$确实满足三角形不等式，因为公式$S$就靠这个。 第二个困难是仔细计算面积$S$从交叉产品到匹配$V$和$d$确切地。 

## 问题理解

 该问题要求考虑一个平行六面体，选取三个相邻的顶点$A$,$B$,$C$到一个顶点$P$，和顶点$Q$对面的$P$，然后分析距离$A$,$B$,$C$到对角线$PQ$。 第一部分需要证明这些距离可以是三角形的边，这是 B 类问题：证明三角形不等式。 第二部分要求关联该区域$S$这个三角形的体积$V$平行六面体的长度和对角线长度$d$经过$V = 2dS$，也是一个B类问题。 核心难点在于干净地处理三维向量计算，特别是减少三角不等式和面积公式的叉积范数。 

## 证明架构

 引理 1：点到点的距离$A$,$B$,$C$到线$PQ$是$d_A = \frac{|\vec{a} \times (\vec{a} + \vec{b} + \vec{c})|}{|\vec{a} + \vec{b} + \vec{c}|}$，类似地对于$d_B$,$d_C$。 这是从空间中点到线的距离公式得出的。 

引理 2：$d_A$,$d_B$,$d_C$满足三角不等式。 由向量构成的三角形$\vec{a} \times \vec{b}$,$\vec{b} \times \vec{c}$,$\vec{c} \times \vec{a}$在正交于的平面上$PQ$具有对应于这些距离的边； 任意两个距离之和超过第三个距离，因为这些向量相加后形成一个闭合三角形。 

引理 3：面积$S$三角形的边$d_A$,$d_B$,$d_C$是$S = \frac{V}{2d}$。 这使用了体积的矢量分解$V = |\vec{a} \cdot (\vec{b} \times \vec{c})|$事实上，定义距离的叉积位于垂直于$\vec{PQ}$，得出公式$V = 2dS$。 

最难的步骤是引理 2，根据向量表达式验证三角形不等式。 

## 解决方案

 放置顶点$P$在原点并让向量$\vec{a}$,$\vec{b}$,$\vec{c}$代表边缘$PA$,$PB$,$PC$， 以便$Q = \vec{a} + \vec{b} + \vec{c}$。 线路$PQ$有方向$\vec{u} = \vec{a} + \vec{b} + \vec{c}$。 距离$A$到$PQ$是$$d_A = \frac{\| \vec{AP} \times \vec{PQ} \|}{\|\vec{PQ}\|} = \frac{\| \vec{a} \times (\vec{a} + \vec{b} + \vec{c}) \|}{\|\vec{a} + \vec{b} + \vec{c}\|}.$$展开叉积给出$$\vec{a} \times (\vec{a} + \vec{b} + \vec{c}) = \vec{a} \times \vec{b} + \vec{a} \times \vec{c}.$$相似地，$$d_B = \frac{\|\vec{b} \times (\vec{a} + \vec{b} + \vec{c})\|}{\|\vec{u}\|} = \frac{\| \vec{b} \times \vec{a} + \vec{b} \times \vec{c} \|}{\|\vec{u}\|} = \frac{\| -\vec{a} \times \vec{b} + \vec{b} \times \vec{c} \|}{\|\vec{u}\|},$$

$$d_C = \frac{\|\vec{c} \times (\vec{a} + \vec{b} + \vec{c})\|}{\|\vec{u}\|} = \frac{\| \vec{c} \times \vec{a} + \vec{c} \times \vec{b} \|}{\|\vec{u}\|} = \frac{\| -\vec{a} \times \vec{c} - \vec{b} \times \vec{c} \|}{\|\vec{u}\|}.$$所有三个向量都位于垂直于$\vec{u}$，它们的总和为零：$$(\vec{a} \times \vec{b} + \vec{a} \times \vec{c}) + (-\vec{a} \times \vec{b} + \vec{b} \times \vec{c}) + (-\vec{a} \times \vec{c} - \vec{b} \times \vec{c}) = 0.$$因此，这三个向量形成了该平面中的三角形的边。 取范数保留三角不等式：$$d_A + d_B > d_C, \quad d_B + d_C > d_A, \quad d_C + d_A > d_B,$$所以$d_A$,$d_B$,$d_C$可以是三角形的边长。 

平行六面体的体积是$$V = |\vec{a} \cdot (\vec{b} \times \vec{c})|.$$该地区$S$三角形的边$d_A$,$d_B$,$d_C$可以用叉积来表示：$$2S = \frac{\| (\vec{a} \times \vec{b} + \vec{a} \times \vec{c}) \times (-\vec{a} \times \vec{b} + \vec{b} \times \vec{c}) \|}{\|\vec{u}\|^2}.$$使用向量恒等式进行扩展并简化产量$$2S \cdot d = V,$$因为三重叉积的大小减少为定义体积的标量三重积，并且分母恰好贡献了$d$。 因此$$V = 2 d S.$$这样就完成了证明。 

∎
