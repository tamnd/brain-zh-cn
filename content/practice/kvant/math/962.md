 ## 问题

 证明对于无多项式$P(x)$对于整数系数是否可以存在不同的整数$x_1$,$x_2$,$\ldots$,$x_n$（$n\ge3$) 其中等式$P(x_1)=x_2$,$P(x_2)=x_3$,$ \ldots$,$P(x_{n-1})=x_n$,$P(x_n)=x_1$抓住。 

杜米特鲁·拉杜（罗马尼亚）

 ## 探索

 让$P(x)\in\mathbb{Z}[x]$并假设存在不同的整数$x_1,\dots,x_n$和$n\ge 3$这样$$P(x_i)=x_{i+1}\quad (i=1,\dots,n-1),\qquad P(x_n)=x_1.$$这意味着$P$permutes a finite set of integers cyclically.

 主要障碍是整数多项式满足强整除性：$$a-b \mid P(a)-P(b)\quad \text{for all } a,b\in\mathbb{Z}.$$沿循环应用这一点会产生连续差异之间的整除关系$$d_i = x_{i+1}-x_i,$$迫使刚性结构$d_i$。 如果这些差异都具有相同的大小，则围绕至少一个周期的唯一可能的符号模式$3$与伸缩总和变得不兼容$\sum d_i=0$。 

可整除性和循环可加性之间的相互作用是至少应该消除所有长度循环的机制$3$。 

## 问题理解

 这是一个 B 类问题：证明不存在这样的多项式和环。 

困难在于从整数多项式中提取算术刚性而不诉诸解析增长或单调性。 决定性的结构是多项式差值除以输入差值，这迫使假定循环中的连续间隙循环地相互划分。 这会将所有间隙折叠到相同的大小，之后循环条件至少对于长度变得不可能$3$。 

## 证明架构

 证明采用以下步骤。 

首先，建立对于任何整数系数多项式$P$和整数$a,b$， 区别$P(a)-P(b)$可以整除$a-b$。 

其次，将其应用于循环的连续元素以推断出$x_{i+1}-x_i$划分$x_{i+2}-x_{i+1}$为所有人$i$，指数循环解释。 

第三，推导所有绝对差异$|x_{i+1}-x_i|$是平等的。 

四、证明长度为的循环序列$n\ge 3$所有具有相同非零幅度的步骤都无法返回到其起点。 

最微妙的一点是循环周围相互可分性的全局后果，这迫使所有步长相等。 

## 解决方案

 让$P(x)\in\mathbb{Z}[x]$。 对于任意整数$a,b$, 身份$$P(a)-P(b)=(a-b)Q(a,b)$$对于某些多项式成立$Q(x,y)\in\mathbb{Z}[x,y]$。 接下来是写$$x^k-y^k=(x-y)(x^{k-1}+x^{k-2}y+\cdots+y^{k-1})$$对于每个单项式并线性延伸到$P$。 最后，$$a-b \mid P(a)-P(b).$$假设存在不同的整数$x_1,\dots,x_n$和$n\ge 3$这样$$P(x_i)=x_{i+1}\quad (i=1,\dots,n-1),\qquad P(x_n)=x_1.$$定义$$d_i=x_{i+1}-x_i \quad (i=1,\dots,n),$$其中指数是循环获取的，所以$x_{n+1}=x_1$和$d_n=x_1-x_n$。 

将可分性应用于$x_i$和$x_{i+1}$给出$$x_i-x_{i+1}\mid P(x_i)-P(x_{i+1}).$$代入循环关系可得$$x_i-x_{i+1}\mid x_{i+1}-x_{i+2},$$因此$$d_i \mid d_{i+1}$$为所有人$i$（循环）。 

迭代这些整除性得到$$d_1 \mid d_2 \mid \cdots \mid d_n \mid d_1.$$所以$|d_1|\le |d_2|\le \cdots \le |d_n|\le |d_1|$， 所以$$|d_1|=|d_2|=\cdots=|d_n|=k$$对于某个整数$k\ge 1$。 自从$x_i$是不同的，$k\ne 0$。 

各可分关系$d_i\mid d_{i+1}$与...一起$|d_i|=|d_{i+1}|$意味着$d_{i+1}=\pm d_i$。 因此每一个$d_i$等于$k$或者$-k$。 

总结整个周期的所有差异得出$$\sum_{i=1}^n d_i = (x_2-x_1)+\cdots+(x_1-x_n)=0.$$因此总和为$n$每个数字都等于$k$或者$-k$必须为零。 这迫使数量$+k$项数等于$-k$项，因此$n$必须是均匀的。 

如果$n\ge 3$，唯一的可能是$n\ge 4$或者$n=3$。 为了$n=3$, 三个数中不能选择符号$\pm k$产生零和。 为了$n\ge 4$，相等数量的$+k$和$-k$意味着在完成所有步骤之前，循环中的部分和必须返回零，这与所有部分和对应于不同的整数相矛盾$x_i$严格循环，完成前不重复。 

这个矛盾表明，不存在这样的周期长度$n\ge 3$可以存在。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 可分割性主张取决于身份$x^m-y^m=(x-y)\sum_{j=0}^{m-1}x^{m-1-j}y^j$，它具有整数系数，因此线性组合保留完整性，确保$P(a)-P(b)$总是的倍数$a-b$。 

步骤$d_i\mid d_{i+1}$直接替换为$a=x_i$,$b=x_{i+1}$进入这个整除性并使用循环关系重写$P(x_i)-P(x_{i+1})$作为$x_{i+1}-x_{i+2}$。 

绝对值相等是由整除性循环链得出的，因为一个非零整数除以另一个具有相同绝对值的整数会强制等于符号。 

最后，通过观察任何部分抵消模式来验证以相等步骤的非平凡循环返回零的不可能性$\pm k$强制重复之前的总和$n$使用步骤，与循环仅在之后才返回其起点的假设相矛盾$n$步骤。 

## 替代方法

 一种替代论点使用模算术，通过考虑余数模素数的诱导排列，并表明循环结构将强制对足够多的素数进行不兼容的同余约束。 

另一种方法使用增长：如果$\deg P\ge 2$，大整数的迭代逃离任何有界区域，与周期性相矛盾； 然后直接对线性情况进行分类，并证明至少不允许有长度的循环$3$。
