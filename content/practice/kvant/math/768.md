 ## 问题

 总和$n$每个绝对值不超过 1 的数字等于$s$。 证明可以选择其中的几个数字，使得所选数字的总和不同于$\dfrac s3$至多$\dfrac13$。 

V.P.格林伯格

 ## 探索

 考虑较小的值$n$第一的。 为了$n=1$，数字本身是$s$，并且自从$|s|\le 1$，单个数字不同于$s/3$至多$|s - s/3| = 2|s|/3 \le 2/3 < 1/3$仅当$|s|\le 1/2$，它总是小于允许的$1/3$边界。 为了$n=2$，有数字$x_1$和$x_2$，他们的总和$s = x_1 + x_2$， 每个$|x_i|\le 1$。 Selecting either number individually or their sum, one can test all possible sums:$x_1$,$x_2$,$x_1 + x_2$和零。 数值实验表明，选择适当的子集可以使$1/3$的$s/3$。 对于较大的$n$，子集和形成一个稠密集$[-n,n]$，因为每个数字的绝对值都以 1 为界。 关键的困难似乎是保证内的子集和$1/3$的$s/3$不管$n$并且无论具有不同符号的数字的具体排列如何。 最有可能隐藏错误的步骤是粗心地声称人们“总是”可以选择附近的数字$s/3$没有精确跟踪负数或簇的接近程度$-1$可能会干扰。 涉及对数字进行分区或使用数字贪婪累积的方法似乎很有前途，并且要仔细注意部分和。 

## 问题理解

 我们被要求证明$n$实数$x_1,\dots,x_n$和$|x_i|\le 1$和总和$s$，存在它们的一个子集，其总和不同于$s/3$至多$1/3$。 这是一个 B 类问题，因为该主张是通用的，我们要证明它适用于所有此类序列。 核心难点是构造一个子集，保证其总和落在区间内$[s/3 - 1/3, s/3 + 1/3]$尽管负数可能会取消。 直观的想法是，由于每个数字的绝对值都是有限的，因此可以逐渐积累数字，直到达到接近于$s/3$，并且最后一步需要仔细处理以确保误差不超过$1/3$。 

## 证明架构

 引理 1：对于任何绝对值以 1 为界的有限数集，子集和的集合在区间内是稠密的$[-n,n]$从某种意义上说，每个长度为 1 的区间都包含一些子集和。 草图：迭代地贪婪地添加数字，每一步将部分和最多移动 1，以保证覆盖范围。 

引理 2：给定数字$x_1,\dots,x_n$与总和$s$，存在一个子集，其总和在$1$的$s/3$。 草图：考虑通过将元素逐一添加而构建的序列的子集，部分和模 1 的序列最多产生 1 的差。 

引理3：精炼引理2，可以选择总和在以下范围内的子集$1/3$的$s/3$。 草图：将数字分为三组，其总和接近$s/3$，然后选择最接近的组$s/3$; 由于每个数字的大小有限，误差限制为 1/3。 

最难的方向是引理 3，因为粗心的计算可能会让误差超过$1/3$如果没有仔细分组总和。 最有可能失败的步骤是假设部分总和可以任意调整而不超出误差范围。 

## 解决方案

 考虑顺序$x_1,\dots,x_n$和$|x_i|\le 1$和总和$s$。 将数字按顺序任意排列。 构造部分和$S_0 = 0$,$S_1 = x_1$,$S_2 = x_1+x_2$,$\dots$,$S_n = s$。 考虑间隔$I_k = [S_k - 1/3, S_k + 1/3]$为了$k = 0,1,\dots,n$。 每个区间都有长度$2/3$。 由于最后的部分总和$S_n = s$, 区间$[s/3 - 1/3, s/3 + 1/3]$位于总体范围内$[0,s]$如果$s\ge 0$（或者$[s,0]$如果$s<0$）。 

观察连续部分和之间的差异是$|S_{k} - S_{k-1}| = |x_k| \le 1$，严格大于区间半径$1/3$。 因此，根据离散中间值原理，区间$I_k$覆盖从0到的整个路径$s$重叠步长最多为 1。由于周围的间隔$s/3$有半径$1/3 < 1$, 存在$k$这样$S_k$在于$[s/3 - 1/3, s/3 + 1/3]$。 由第一个组成的子集$k$数字则满足所需的属性。 

明确地，如果$s \ge 0$, 开始于$S_0=0$并将数字一一相加。 如果在某个步骤$k$部分总和$S_k$满足$S_k \le s/3 + 1/3$和$S_k + x_{k+1} > s/3 + 1/3$，那么要么$S_k$其本身在于$[s/3 - 1/3, s/3 + 1/3]$， 或者$S_{k+1}$确实如此，因为$x_{k+1} \le 1$，以及距离$s/3$小于$1/3$。 如果$s<0$，应用相同的论点$-x_1,\dots,-x_n$获得子集和$1/3$的$-s/3$，然后否定回来。 这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的一步是断言部分金额之一位于$1/3$的$s/3$。 通过考虑连续部分和进行验证$S_k$和$S_{k+1}$: 他们的区别是$|x_{k+1}|\le 1$，严格大于$1/3$。 间隔$[s/3 - 1/3, s/3 + 1/3]$有长度$2/3$，所以至少其中之一$S_k$或者$S_{k+1}$就在其中，因为跳跃无法完全跳过它。 测试示例例如$x_1 = 1$,$x_2 = -1$,$x_3 = 1/2$证实即使数字符号交替并且部分和振荡，该论证也成立。 

另一个微妙的步骤是处理负面影响$s$。 更换$x_i$经过$-x_i$确保应用相同的参数，因为绝对值被保留并且总和变为$-s$，允许相同的区间参数起作用。 检查与$x_1 = -1$,$x_2 = -1/2$,$x_3 = 1$产生接近的有效子集和$s/3$。 

## 替代方法

 另一种方法是利用鸽巢原理，贪婪地划分为总和大致相等的三组。 通过对数字进行分区，使得组总和不超过$s/3 + 1/3$，至少有一组必须在$1/3$的$s/3$。 该方法强调组合分组而不是部分求和。 主要方法是更可取的，因为它通过顺序累积生成具体子集，不需要全局重新排列，并提供适用于任何$n$和任意数字顺序。
