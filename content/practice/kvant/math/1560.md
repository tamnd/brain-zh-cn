 ## 问题

 在某个国家，一个人只有比邻居的80%（或更多）高才可以进入警卫室。 为了证明自己有权进入警卫，该人自己指定了一个号码$R$（一个半径），之后他的“邻居”被认为是所有居住距离小于$R$来自他。 在同一个国家，只有当一个人的身高比他的邻居的80%（或更多）矮时，才可以免服兵役。 “邻居”的定义是类似的：这个人自己指定一个数字$r$（半径）等，其中$R$和$r$不必重合。 是否会出现至少 90% 的人口有资格加入警卫队，同时至少 90% 的人口可以免服兵役？ （值$R$和$r$必须选择使得相应的“邻居集”非空。）

 N·N·康斯坦丁诺夫

 第 59 届莫斯科数学奥林匹克竞赛，1996 年，城镇锦标赛（1996 年春季）

 ### 建设

 将总体视为有限集合$N$个人沿圆圈排列。 将圆划分为一系列交替的块，表示为$L_1, H_1, L_2, H_2, \dots, L_m, H_m$，使得每个块包含大量明确指定数量的个体。 为了确定性，让每个$L$-块和每个$H$-block 完全包含$K$个人，与$K$可除以$10$。 为个人分配高度，以便所有成员$L$-block 比任何的所有成员都短$H$-堵塞。 在每个块内，沿着圆的遍历对个体的高度进行排序，将高度分配为算术级数，以确保对于块内连续个体的任何子集，相对顺序保持严格递增。 选择块的总数，以便至少$90%$的人口位于街区内部，最多留下$10%$在块之间的边界处。 标记每个块内的个人$1$到$K$按照他们的身高顺序。 

### 内部行为$L$-块

 修复个人$x$在一个的内部$L$- 阻止位置$i$, 满足$4 \le i \le K-3$，以避免边界效应。 定义一个小半径$R$使得邻域$x$恰好包含$5$左边的连续邻居和$5$右边连续的邻居，总共有$s = 10$邻居。 左邻居和右邻居由沿圆的邻接组合确定。 由于块中的高度沿着遍历严格增加，如果$x$被定位为$k$- 其中最高的个体$11$人（包括$x$），邻居的数量小于$x$正是$k-1$，并且邻居的数量高于$x$是$s-(k-1)$。 选择$x$成为$9$该组中最高的确保$8$的$10$邻居较短，屈服$80%$邻居的个数短于$x$。 这样就满足了进入守卫的条件。 半径的选择$R$由所包含的相邻个体的数量组合定义，确保邻域非空并且包含规定的离散邻居集。 

对于更大的半径$r$，定义邻域$x$包括整个$L$-块包含$x$连同完整的相邻$H$-两侧都有块。 让每一个$H$-块包含$K$个人。 邻域总大小为$s' = K + 2K = 3K$邻居，其中$2K$属于$H$- 块并且比$x$。 邻居的比例高于$x$正是$2K/3K = 2/3$，略低于$80%$。 要纠正此问题，请增加每个中的人数$H$-阻止到$5K$，使得总邻域大小变为$s' = K + 2\cdot5K = 11K$，其中$10K$比$x$。 分数是$10K/11K = 10/11 > 0.8$，满足豁免条件。 半径$r$被组合定义为包括这些块并且保证非空。 

### 内部行为$H$-块

 修复个人$y$在一个的内部$H$- 阻止位置$j$,$6 \le j \le 5K-5$，以避免边界效应。 对于小半径$R$，选择一个由以下组成的邻域$5$两侧的连续邻居$y$在块内，给出$s = 10$邻居。 选择$y$成为$3$-rd 其中最高$11$个人，因此$8$的$10$邻居比别人高$y$，确保$80%$的邻居都比较高。 这满足了兵役的豁免条件。 邻域是非空的并且是组合定义的，避免了连续近似。 

对于更大的半径$r$，包括整个$H$-块包含$y$和完整的相邻$L$-两侧都有块。 每个$L$-块包含$K$个人。 邻域总大小为$s' = 5K + 2\cdot K = 7K$，其中$2K$短于$y$。 邻居的比例小于$y$是$2K/7K = 2/7 < 0.8$。 增加每个的大小$L$-阻止到$4K$以便$s' = 5K + 2\cdot4K = 13K$，并且邻居的数量小于$y$是$8K$。 那么分数是$8K/13K \approx 0.615$，仍低于$0.8$。 为了达到$80%$阈值，放大每个$L$-阻止到$10K$， 所以$s' = 5K + 2\cdot10K = 25K$较短邻居的数量是$20K$，产生$20K/25K = 0.8$。 现在已经满足豁免条件了。 半径$r$被组合定义为包括这些块并且非空。 

### 确保90%的要求

 仅限距离内的个人$5$来自任何块边界的个体可能无法满足这两个条件之一，因为他们的邻域不能完全包含在所需块或相邻块中。 每个块至少包含$5K$个人，并且只有第一个和最后一个$5$位置被排除，因此每个块的边界个体的比例最多为$10/5K = 2/K$。 选择$K \ge 50$确保边界个体的比例最多为$4%$。 由于这些区块覆盖了全部人口，至少$96%$的个体位于内部位置并同时满足两个条件以及适当定义的半径$R$和$r$。 这超出了要求$90%$临界点。 

### 结论

 通过将人口划分为仔细指定大小的离散交替块，并在每个块内分配严格增加的高度，同时确保$L$-块高度小于$H$-块高度，可以为每个内部个体定义一个小半径$R$和更大的半径$r$组合起来，使得至少$80%$的邻居分别满足守卫和豁免条件。 显式计算相对于块大小的边界个体的数量保证至少$90%$人口的数量同时满足这两个属性。 因此，存在实现所需场景的人口的有限离散配置和相应的邻域半径。
