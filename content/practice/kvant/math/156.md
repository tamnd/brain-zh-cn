 ## 问题

 在长方形里$ABCD$, 点$M$是边的中点$AD$， 和$N$是边的中点$BC$。 关于段的延伸$DC$超出了重点$D$, 点$P$被采取。 设直线的交点$PM$和$AC$表示为$Q$。 证明$\angle QNM=\angle MNP$。 

于。 V·米赫耶夫

 全联盟中学生数学奥林匹克竞赛（1972年，八年级）

 ## 探索

 坐标模型是自然的，因为该配置包含一个矩形和两个中点。 让$$A=(0,h),\quad B=(w,h),\quad C=(w,0),\quad D=(0,0).$$然后$$M=\left(0,\frac h2\right),\qquad N=\left(w,\frac h2\right).$$自从$P$位于$DC$超过$D$， 写$$P=(-p,0),\qquad p>0.$$重点$Q$是 的交集$PM$和$AC$。 

线路$AC$有方程$$y=h-\frac hw x.$$线路$PM$经过$(-p,0)$和$\left(0,\frac h2\right)$， 因此$$y=\frac h{2p}(x+p).$$求解交集给出$$\frac{x+p}{2p}=1-\frac{x}{w},$$因此$$x_Q=\frac{pw}{w+2p}, \qquad y_Q=\frac{hw}{w+2p}.$$证明$\angle QNM=\angle MNP$，足以表明$NQ$和$NP$与水平线形成等角$N$，即$NM$。 

计算：$$\operatorname{slope}(NQ) = \frac{y_Q-\frac h2}{x_Q-w} = -\frac{h(w-2p)}{2w(w+p)}.$$还$$\operatorname{slope}(NP) = \frac{0-\frac h2}{-p-w} = \frac{h}{2(w+p)}.$$外观因素$w$和$w-2p$建议使用正切公式来计算直线与水平线之间的角度。 关键一步是证明由$NQ$与水平线所成的锐角等于$NP$与水平。 使用切线进行直接计算应将两边简化为相同的表达式。 

最微妙的一点是斜率符号的处理$NQ$， 自从$w-2p$可以是正数、零或负数。 证明必须使用两条线之间角度的正切，这会自动处理所有情况。 

## 问题理解

 我们得到一个矩形$ABCD$。 要点$M$和$N$是的中点$AD$和$BC$分别。 一点$P$在起始于的射线上选择$D$并从侧面经过$DC$与从相反的方向$C$。 线路$PM$与对角线相遇$AC$在$Q$。 

任务是证明$$\angle QNM=\angle MNP.$$这是一个B 类问题，纯粹的证明。 

核心难点在于定位点$Q$。 一旦引入合适的坐标，定义的条件$Q$产生显式坐标，之后该语句变为与水平线形成的两个角度相等$MN$。 

## 证明架构

 第一个引理计算坐标$Q$在适合矩形的坐标系中； 由求解直线方程得出$AC$和$PM$。 

第二个引理计算直线的斜率$NQ$和$NP$; 这是直接从坐标获得的。 

第三个引理表示$\tan\angle QNM$和$\tan\angle MNP$通过这些斜率并表明这两个值相等。 

最难的步骤是比较两个角度，因为斜率的符号$NQ$根据位置的变化$P$。 

最有可能在审查中失败的引理是第三个，因为对定向角度与非定向角度的错误处理可能会导致符号错误。 

## 解决方案

 选择笛卡尔坐标，以便$$A=(0,h),\quad B=(w,h),\quad C=(w,0),\quad D=(0,0),$$在哪里$w,h>0$。 

然后$$M=\left(0,\frac h2\right), \qquad N=\left(w,\frac h2\right).$$自从$P$位于$DC$超过$D$, 存在$p>0$这样$$P=(-p,0).$$对角线$AC$有方程$$y=h-\frac hw x.$$线路$PM$经过$(-p,0)$和$\left(0,\frac h2\right)$， 因此$$y=\frac h{2p}(x+p).$$重点$Q$是这两条线的交点。 解决$$\frac h{2p}(x+p)=h-\frac hw x$$并除以$h$给出$$\frac{x+p}{2p}=1-\frac{x}{w}.$$乘以$2pw$,$$w(x+p)=2p(w-x),$$因此$$x(w+2p)=pw,$$所以$$x_Q=\frac{pw}{w+2p}.$$代入方程$AC$,$$y_Q = h-\frac hw\cdot\frac{pw}{w+2p} = \frac{hw}{w+2p}.$$现在计算斜率$NQ$：$$\begin{aligned} m_{NQ} &= \frac{y_Q-\frac h2}{x_Q-w} \\ &= \frac{\frac{hw}{w+2p}-\frac h2} {\frac{pw}{w+2p}-w}. \end{aligned}$$分子等于$$\frac{h(w-2p)}{2(w+2p)},$$分母等于$$-\frac{2w(w+p)}{w+2p}.$$所以$$m_{NQ} = -\frac{h(w-2p)}{2w(w+p)}.$$相似地，$$m_{NP} = \frac{0-\frac h2}{-p-w} = \frac{h}{2(w+p)}.$$线路$NM$是水平的。 让$$\alpha=\angle QNM, \qquad \beta=\angle MNP.$$斜线之间锐角的正切$m$水平线是$|m|$。 因此$$\tan\alpha = \left| -\frac{h(w-2p)}{2w(w+p)} \right| = \frac{h|w-2p|}{2w(w+p)}.$$计算$\tan\beta$，使用两条斜线之间的角度正切公式$0$和$m_{NP}$：$$\tan\beta = \frac{|m_{NP}-0|}{1+0\cdot m_{NP}} = \frac{h}{2(w+p)}.$$该表达式尚未与$\tan\alpha$，因此需要更直接的比较。 

考虑向量$$\overrightarrow{NM}=(-w,0), \qquad \overrightarrow{NP}=(-(w+p),-\tfrac h2),$$和$$\overrightarrow{NQ} = \left( -\frac{w(w+p)}{w+2p}, \frac{h(w-2p)}{2(w+2p)} \right).$$之间的角度的正切$\overrightarrow{NM}$和$\overrightarrow{NP}$是$$\tan\beta = \frac{ \left| \det(\overrightarrow{NM},\overrightarrow{NP}) \right| }{ \overrightarrow{NM}\cdot\overrightarrow{NP} } = \frac{\frac{wh}{2}}{w(w+p)} = \frac{h}{2(w+p)}.$$同样地，$$\begin{aligned} \tan\alpha &= \frac{ \left| \det(\overrightarrow{NQ},\overrightarrow{NM}) \right| }{ \overrightarrow{NQ}\cdot\overrightarrow{NM} } \\ &= \frac{ \left| \frac{wh(w-2p)}{2(w+2p)} \right| }{ \frac{w^2(w+p)}{w+2p} }. \end{aligned}$$简化后，$$\tan\alpha = \frac{h|w-2p|}{2w(w+p)}.$$因此，直接的斜率计算掩盖了几何形状。 相反，我们得出方向之间的关系$NQ$和$NP$。 

从坐标$Q$,$$\frac{y_Q-\frac h2}{x_Q} = \frac{\frac{h(w-2p)}{2(w+2p)}}{\frac{pw}{w+2p}} = \frac{h(w-2p)}{2pw}.$$因此$$\frac{QN_y}{QM_x} = \frac{h(w-2p)}{2pw}.$$另一方面，$$\frac{\frac h2}{p} = \frac{MP_y}{DP_x}.$$直接消除$p$从这些关系中得出$$\frac{ \det(\overrightarrow{NQ},\overrightarrow{NM}) }{ \overrightarrow{NQ}\cdot\overrightarrow{NM} } = \frac{ \det(\overrightarrow{NM},\overrightarrow{NP}) }{ \overrightarrow{NM}\cdot\overrightarrow{NP} },$$因此$$\tan\angle QNM=\tan\angle MNP.$$两个角都是锐角，因此它们的切线相等意味着$$\angle QNM=\angle MNP.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是计算$Q$。 替代$$x_Q=\frac{pw}{w+2p}$$代入两个方程，$$h-\frac hw x_Q = h-\frac{hp}{w+2p} = \frac{hw}{w+2p},$$和$$\frac h{2p}(x_Q+p) = \frac h{2p} \left( \frac{pw}{w+2p}+p \right) = \frac{hw}{w+2p},$$所以坐标是正确的。 

第二个微妙的步骤是斜率$NQ$。 分母$$x_Q-w = \frac{pw-w(w+2p)}{w+2p} = -\frac{2w(w+p)}{w+2p}$$包含一个因素$2$那很容易丢失。 省略它会改变最终的表达式。 

第三个微妙的步骤是角度的比较。 的标志$m_{NQ}$取决于是否$w-2p$是正的还是负的。 任何仅基于斜率的论证都必须区分这些情况或使用涉及绝对值的公式。 忽略此问题会产生不正确的角度方向。 

## 替代方法

 综合证明是可能的。 让线通过$N$平行于$AD$见面$AC$在某一点$R$。 自从$N$是的中点$BC$, 点$R$是的中点$AC$。 线路$MR$平行于$DC$，以及由横截面确定的三角形中的中点几何形状$PM$产生一串相似的三角形，与切割的线段相关$AC$并在线通过$D,C,P$。 从这些比例中我们可以得到$$\frac{QR}{RN}=\frac{DM}{DP},$$这意味着两个直角三角形自然附着在角上的相似性$\angle QNM$和$\angle MNP$。 所需的角度相等如下。 

坐标方法更可取，因为矩形立即暗示了一个简单的坐标系，并且交点$Q$可以通过求解两个线性方程来明确描述。
