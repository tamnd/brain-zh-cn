 ## 问题

 让$x_1$,$x_2$,$\ldots$,$x_n$是实数，使得$x_1^2+x_2^2+\ldots+x_n^2=1$。 证明绝对值之和$2^n$数字$$\pm x_1 \pm x_2 \pm \ldots \pm x_n$$（带有所有可能的符号组合“$+$“ 和 ”$-$”）不超过$2^n$。 

I. Kasakovskikh

 ## 探索

 考虑较小的值$n$第一的。 为了$n=1$，数字是$\pm x_1$，它们的绝对值之和是$|x_1| + |-x_1| = 2|x_1| \le 2$， 自从$x_1^2=1$意味着$|x_1|\le 1$。 为了$n=2$，数字是$\pm x_1 \pm x_2$，给出四个数字：$x_1+x_2$,$x_1-x_2$,$-x_1+x_2$,$-x_1-x_2$。 它们的绝对值之和为$|x_1+x_2| + |x_1-x_2| + |-x_1+x_2| + |-x_1-x_2| = 2(|x_1+x_2| + |x_1-x_2|)$。 

测试极端情况，如果$x_1^2+x_2^2=1$，最大值出现在$x_1$和$x_2$都是$1$或两者兼而有之$-1$; 但绝对值之和是$2(|1+1| + |1-1|) = 4$，等于$2^2$。 随机较小的数字，例如$x_1=x_2=1/2$，产生较小的总和。 

对于一般$n$, 总和$2^n$绝对值的符号组合应受以下限制$2^n$。 最简单的猜想是，当每个$x_i$是$\pm 1$，适当缩放以满足$x_1^2+\dots+x_n^2=1$，即所有$x_i$等于$1/\sqrt{n}$。 测试$n=2$,$x_1=x_2=1/\sqrt{2}$给出总和$2(|1/\sqrt{2}+1/\sqrt{2}| + |1/\sqrt{2}-1/\sqrt{2}|) = 2( \sqrt{2}+0) = 2\sqrt{2} < 4$。 这支持了猜想。 

可能的关键见解是利用对称性和递归公式：如果$S_n$表示绝对值之和$n$数，那么$$S_n(x_1,\dots,x_n) = \sum_{\epsilon_1,\dots,\epsilon_n = \pm 1} |\epsilon_1 x_1 + \dots + \epsilon_n x_n| = \sum_{\epsilon_n = \pm 1} \sum_{\epsilon_1,\dots,\epsilon_{n-1}} |\epsilon_1 x_1 + \dots + \epsilon_{n-1} x_{n-1} + \epsilon_n x_n|.$$这减少到$S_n = \sum_{\epsilon} (|A + x_n| + |A - x_n|)$， 在哪里$A$范围超过总和$n-1$变量。 不平等$|A+x_n| + |A-x_n| \le 2\max(|A|,|x_n|)$是有希望的，但更尖锐的界限是$|A+x_n| + |A-x_n| \le 2(|A|+|x_n|)$; 递归地，$2^n$因素出现。 验证基本情况$n=1$很简单，并且递归保留了界限。 

微妙的步骤是确保递归不等式不会过度计数，并且最坏情况的配置确实给出了界限$2^n$。 

## 问题理解

 该问题要求证明一个不等式：对于实数$x_1,\dots,x_n$平方和等于 1，所有绝对值之和$2^n$与任意的线性组合$\pm$标志最多是$2^n$。 这是 B 类问题，因为该语句已修复并且不需要分类或极值。 核心难点在于处理指数数量的项并利用约束$x_1^2+\dots+x_n^2=1$高效。 基本的几何直觉是数字$x_1,\dots,x_n$位于单位球面上$\mathbb{R}^n$，并且超立方体所有顶点的绝对值加权之和不能超过$2^n$。 

## 证明架构

 引理 1：对于任何实数$A$和$B$,$|A+B| + |A-B| \le 2(|A|+|B|)$; 这是根据考虑所有四个符号组合得出的$A$和$B$并利用三角不等式。 

引理 2：如果$S_{n-1}$表示绝对值之和$n-1$数字，然后相加$x_n$产量$S_n = \sum_{\epsilon_1,\dots,\epsilon_{n-1}} (| \epsilon_1 x_1 + \dots + \epsilon_{n-1} x_{n-1} + x_n| + |\epsilon_1 x_1 + \dots + \epsilon_{n-1} x_{n-1} - x_n|)$，其边界为$2 S_{n-1}$; 该引理源自逐项应用的引理 1。 

引理 3：$S_1 \le 2$; 这是立即发生的，因为$|x_1| \le 1$。 

主要论点：应用归纳法$n$使用引理 1-3。 最难的步骤是引理 2，其中不小心应用不等式可能会产生超出的松散界限$2^n$; 仔细的逐项处理可确保准确的系数。
