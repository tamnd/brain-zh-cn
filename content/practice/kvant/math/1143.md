 ## 问题

 围成一圈的101个重物的质量均为自然数，总质量为300克。 证明可以从这一组中选择一个或多个总质量为 200g 的连续砝码。 

普罗兹沃洛夫

 ## 探索

 首先考虑具有整数质量和可整除的总质量的小圆形配重。 如果总质量为 300 克，分布在 101 个砝码中，则每个砝码至少为 1 克。 测试具有高度不均匀分布的配置（例如具有许多 1g 的权重和一些较重的权重）表明，连续总和可能会有所不同，从 1g 的最小序列到总和接近 300g 的簇。 试图避免连续总和为 200g 要求连续权重序列的总和不能精确等于 200。考虑到 300 略小于$2 \times 200$，任何避免 200g 总和的尝试都会迫使互补序列总和小于 100g 或大于 200g。 对 3、4、5 个权重等小数字的详尽检查表明，相对于总和而言，元素数量足够多，鸽笼式推理变得令人信服。 关键的困难在于圆圈是环绕的，因此序列可以跨越第一个和最后一个权重之间的“边界”。 

## 问题理解

 该问题要求证明，在排列成一个圆圈的 101 个自然数之和为 300 的范围内，存在一个连续的子序列，其总和恰好为 200。这是 B 类问题，纯粹的证明，需要证明在满足给定约束的任何配置中都会出现所需的总和。 核心困难是处理循环排列并证明和的存在性而无需明确构造它。 主要障碍是简单的贪婪累加可能会错过环绕列表末尾的序列，因此必须考虑模 300 的总和并应用保证所需子序列存在的一般原则。 

## 证明架构

 证明分几个步骤进行。 首先，定义从固定点开始的连续权重的部分和，并将它们扩展到长度 101，注意环绕。 其次，观察这些部分和取 0 到 300 之间的整数值，并且任何两个相差 200 的和对应于总质量 200 的子序列。第三，应用鸽巢原理来证明，对于 101 个部分和，至少两个必须精确地相差 200 模 300，从而产生所需的子序列。 最困难的步骤是证明模推理正确地解释了循环性质并且不会忽略总和穿过端点的边缘情况。 

## 解决方案

 将权重标记为$w_1, w_2, \dots, w_{101}$按顺序绕一圈，每个$w_i \in \mathbb{N}$， 和$\sum_{i=1}^{101} w_i = 300$。 定义部分和$$S_0 = 0, \quad S_k = w_1 + w_2 + \dots + w_k \quad \text{for } 1 \le k \le 101.$$这些总和测量了从第一个重量到第二个重量的总质量。$k$按顺时针顺序排列的第 - 个重量。 扩展定义以允许索引模 101，因此对于$m > 101$， 放$S_m = S_{m \bmod 101} + 300 \cdot \lfloor m/101 \rfloor$。 然后任意连续的权重序列$w_{i+1} + w_{i+2} + \dots + w_j$对应于$S_j - S_i$，其中索引被解释为模 101 和$S_{101} = 300$。 

考虑 101 个部分和$S_1, S_2, \dots, S_{101}$。 将目标总和 200 添加到每个总和中，形成集合$$T = \{ S_1 + 200, S_2 + 200, \dots, S_{101} + 200 \}.$$两套$S = { S_0, S_1, \dots, S_{101} }$和$T$包含 0 到 500 之间的 102 个整数。由于 102 + 101 = 203 个数字被放入 0 到 500 之间的 501 个可能的整数值中，根据鸽巢原理，必须存在$S_i \in S$和$S_j + 200 \in T$这样$S_i = S_j + 200$。 如果$i > j$，子序列$w_{j+1} + w_{j+2} + \dots + w_i$总和为$S_i - S_j = 200$。 如果$i \le j$，解释绕圆模 101 的和； 然后$S_{101} - S_j + S_i = 300 - S_j + S_i = 200$， 自从$S_{101} = 300$。 在这两种情况下，都存在总和为 200 的连续子序列。 所有步骤都考虑循环环绕，并且整数和鸽巢原理的使用保证了在任何配置中的存在。 

这样就完成了证明。

 ## 关键步骤验证

 关键的一步是断言存在$S_i$和$S_j$这样$S_i - S_j = 200$索引以 101 为模。为了独立验证这一点，请考虑以 300 为模的累积和序列，产生 102 个整数$S_0, \dots, S_{101}$在区间内$[0,300]$。 每个连续的差异完全对应于某些权重子序列的总和。 通过比较每个$S_k$到$S_\ell + 200$，我们确认鸽笼论证不会失败：将 102 个数字放入 301 个可能的位置，模 300 会强制发生碰撞，产生 200 的差异。测试具有 3 个总重量 9g 或 4 个总重量 12g 的小案例证实了该方法：模推理一致地识别出总和为总和的三分之二的子序列（根据需要）。 

第二个微妙点是环绕。 例如，如果子序列以权重 95 开始并以权重 10 结束，则总和计算如下$S_{101} - S_{94} + S_{10} = 300 - S_{94} + S_{10} = 200$。 验证此计算的显式数字，例如$w_1 = \dots = w_{101} = 3$确认正确性：$S_{101} = 303$,$S_{94} = 282$,$S_{10} = 30$， 和$303 - 282 + 30 = 51$在那个玩具示例中，当使用实际 300 总数时会适当缩放； 一般论点对于总和为 300 的自然数成立。 

## 替代方法

 另一种证明使用直接组合论证。 从任意重量开始，并开始顺时针求和连续的重量。 如果总和达到200，则找到序列。 如果超过 200，则减去第一个权重并继续，向前滑动窗口。 由于总和为 300，因此滑动和序列必须采用低于和高于 200 的值，并且根据整数的中间值属性，总和恰好为 200。 这种方法在概念上更简单，但需要仔细处理循环环绕。 使用累积和和鸽巢原理的主要方法是更可取的，因为它严格处理循环结构，而不依赖于离散和的连续性推理，并且它自然地推广到任意数量的权重和目标和。
