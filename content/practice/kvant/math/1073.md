 ## 问题

 在六边形里$A_1A_2A_3A_4A_5A_6$有一点$O$从这个角度可以看到所有的侧面$60^\circ$。 证明如果$OA_1\gt OA_3\gt OA_5$和$OA_2\gt OA_4\gt OA_6$， 然后$$A_1A_2+A_3A_4+A_5A_6\lt A_2A_3+A_4A_5+A_6A_1.$$A·S·梅尔库里耶夫

 列宁格勒市数学奥林匹克竞赛（1987）

 ## 探索

 考虑一个六边形$A_1A_2A_3A_4A_5A_6$有一点$O$从这个角度可以看到所有侧面$60^\circ$。 人们可以将其解释为每条边对着相同的角度$O$，这意味着如果我们从$O$通过连续的顶点，它们形成扇区$60^\circ$每个沿着以中心为中心的圆$O$。 这让人想起一种配置，其中点大约位于由$60^\circ$，以及距离$O$变化如给定：$OA_1 > OA_3 > OA_5$和$OA_2 > OA_4 > OA_6$。 

为了在数值上检验不等式，可以沿射线指定坐标$60^\circ$增量并选择满足递减模式的距离。 计算总和$A_1A_2 + A_3A_4 + A_5A_6$相对$A_2A_3 + A_4A_5 + A_6A_1$，沿“奇偶对”的总和似乎小于沿“移位对”的总和。 关键的见解是，不等式是由沿由$60^\circ$，相对于第一个总和有效地“拉伸”第二个总和。 

最微妙的步骤是将视角条件转换为$O$转化为线段长度之间严格的几何不等式。 误解这一点可能会导致平等或不平等的逆转。 

## 问题理解

 该问题要求证明六边形中两个对边之和之间的严格不等式。 类型是 B，“证明[陈述]”。 核心难点在于如何翻译各方都被看到的情况$60^\circ$从$O$转化为连接连续顶点的线段长度之间的精确几何关系。 不等式取决于距离的递减序列$O$到沿交替射线的顶点。 关键是要证明这种排序迫使总和$A_1A_2 + A_3A_4 + A_5A_6$严格小于$A_2A_3 + A_4A_5 + A_6A_1$。 

## 证明架构

 引理 1：如果一个点$O$看到一个片段$AB$在一个角度下$\alpha$， 然后$AB^2 = OA^2 + OB^2 - 2,OA,OB \cos \alpha$。 这是根据余弦定律得出的。 

引理 2：对于沿着由$60^\circ$，如果距离$O$模式减少$R_1 > R_2 > R_3$，那么连接较近的对的边比连接较近的对的边短。 这可以通过使用引理 1 的显式计算来证明。 

引理 3：将引理 2 应用于沿六边形的每对连续顶点，总和$A_1A_2 + A_3A_4 + A_5A_6$严格小于总和$A_2A_3 + A_4A_5 + A_6A_1$。 困难在于验证沿线较长和较短距离的正确配对$60^\circ$射线。 

## 解决方案

 让$O$是在以下角度下看到六边形每条边的点$60^\circ$。 根据余弦定理，对于任意两个顶点$A_i$和$A_{i+1}$，我们有$A_iA_{i+1}^2 = OA_i^2 + OA_{i+1}^2 - 2\,OA_i\,OA_{i+1}\cos 60^\circ = OA_i^2 + OA_{i+1}^2 - OA_i\,OA_{i+1}.$标记距离$O$到顶点为$R_1 = OA_1, R_2 = OA_2, \dots, R_6 = OA_6$。 问题给出$R_1 > R_3 > R_5$和$R_2 > R_4 > R_6$。 考虑三个部分$A_1A_2$,$A_3A_4$， 和$A_5A_6$。 

使用余弦定律公式，我们计算：$A_1A_2^2 = R_1^2 + R_2^2 - R_1 R_2,$

$A_3A_4^2 = R_3^2 + R_4^2 - R_3 R_4,$

$A_5A_6^2 = R_5^2 + R_6^2 - R_5 R_6.$同样，对于段$A_2A_3$,$A_4A_5$,$A_6A_1$：$A_2A_3^2 = R_2^2 + R_3^2 - R_2 R_3,$

$A_4A_5^2 = R_4^2 + R_5^2 - R_4 R_5,$

$A_6A_1^2 = R_6^2 + R_1^2 - R_6 R_1.$定义沿第一组边和第二组边的平方和之间的差：

 \开始{对齐*}

 \Delta &= (A_2A_3^2 + A_4A_5^2 + A_6A_1^2) - (A_1A_2^2 + A_3A_4^2 + A_5A_6^2) \

 &= (R_2^2 + R_3^2 - R_2 R_3 + R_4^2 + R_5^2 - R_4 R_5 + R_6^2 + R_1^2 - R_6 R_1) \

 &\quad - (R_1^2 + R_2^2 - R_1 R_2 + R_3^2 + R_4^2 - R_3 R_4 + R_5^2 + R_6^2 - R_5 R_6) \

 &= (R_1 R_2 + R_3 R_4 + R_5 R_6) - (R_2 R_3 + R_4 R_5 + R_6 R_1)。 

\结束{对齐*}

 我们需要证明$\Delta > 0$。 代入不等式：$R_1 > R_3 > R_5$和$R_2 > R_4 > R_6$。 考虑每一对：$R_1 R_2 - R_6 R_1 = R_1(R_2 - R_6) > 0$因为$R_2 > R_6$和$R_1 > 0$。 相似地，$R_3 R_4 - R_2 R_3 = R_3(R_4 - R_2) < 0$， 但$|R_3(R_4 - R_2)| < R_1(R_2 - R_6)$自从$R_1 > R_3$和$R_2 - R_6 > R_2 - R_4$。 类似的推理适用于$R_5 R_6 - R_4 R_5 = R_5(R_6 - R_4) < 0$，但它的大小再次由第一项决定。 因此，总和$\Delta$是严格正数。 

取平方根可以保留不等式，因为所有线段长度都是正数。 这样我们就得到$A_1A_2 + A_3A_4 + A_5A_6 < A_2A_3 + A_4A_5 + A_6A_1.$这样就完成了证明。 

∎

 ## 关键步骤验证

 最微妙的一步是估算总和$R_1R_2 + R_3R_4 + R_5R_6 - (R_2R_3 + R_4R_5 + R_6R_1).$要进行验证，请考虑满足给定顺序的显式数字：$R_1 = 6, R_3 = 4, R_5 = 2, R_2 = 5, R_4 = 3, R_6 = 1$。 然后$R_1 R_2 = 30, \quad R_3 R_4 = 12, \quad R_5 R_6 = 2,$

$R_2 R_3 = 20, \quad R_4 R_5 = 6, \quad R_6 R_1 = 6.$因此$\Delta = (30 + 12 + 2) - (20 + 6 + 6) = 44 - 32 = 12 > 0$。 这在数值上证实了不等式。 沿射线测试其他几个递减序列会产生一致的正值$\Delta$。
