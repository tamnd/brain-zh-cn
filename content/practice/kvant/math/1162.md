 ## 问题

 找出所有整数解$(x, y)$方程的$$x^{3}-13xy+y^{3}=13.$$D·V·福明

 ## 探索

 考虑丢番图方程$x^3 - 13xy + y^3 = 13.$由于系数是小整数，因此很自然地尝试使用小整数值$x$和$y$。 如果$|x|$或者$|y|$很大时，三次项占主导地位，因此解应该位于小整数之间。 尝试$x$和$y$之间$-3$和$3$看起来很合理。 例如，如果$x = y$，方程变为$2x^3 - 13x^2 = 13$，它没有整数解，因为$2x^3 - 13x^2 - 13 = 0$根据有理根定理，没有整数根。 

另一种方法是将方程重写为$x^3 + y^3 - 13xy = 13$，并回忆起身份$x^3 + y^3 = (x+y)^3 - 3xy(x+y)$。 代入，方程变为$(x+y)^3 - 3xy(x+y) - 13xy = 13.$这简化为$(x+y)^3 - xy(3(x+y)+13) = 13.$这建议定义$s = x+y$和$p = xy$，得出方程$s^3 - p(3s+13) = 13,$所以$p = \frac{s^3 - 13}{3s+13}$。 自从$p$必须是整数，$3s + 13$必须划分$s^3 - 13$。 测试小整数$s$是可行的。 

关键点是找到所有整数对$(s, p)$这样$p = \frac{s^3 - 13}{3s+13}$是整数然后求解$x+y = s$,$xy = p$对于整数$x$和$y$。 

## 问题理解

 该问题要求所有整数解$(x,y)$具有混合项的三次丢番图方程。 这是一个 A 类问题：我们必须对所有解决方案进行分类并证明不存在其他解决方案。 核心难点在于处理混合术语$-13xy$，这会阻止变量的直接因式分解或简单限制。 其见解是使用以下的和与积来简化方程$x$和$y$，允许可分性约束来识别所有可能的解决方案。 直观上，由于三次增长和右侧适度，解预计是小整数。 

## 证明架构

 引理 1：如果$(x, y)$是一个整数解，那么$x+y = s$和$xy = p$满足$p = \frac{s^3 - 13}{3s+13} \in \mathbb{Z}$。 这是从身份得出的$x^3 + y^3 = (x+y)^3 - 3xy(x+y)$。 

引理 2：所有整数$s$这样$3s+13$划分$s^3-13$包含在集合中${-4, -1, 0, 1, 3, 4}$。 这是通过小尺寸的直接整除测试来验证的$|s|$和大边界$|s|$利用不等式$|s^3-13| < |3s+13| |s^2|$为了$|s|\ge5$。 

引理 3：对于每个候选人$s$, 二次方$t^2 - st + p = 0$具有整数解当且仅当判别式$s^2 - 4p$是一个完美的正方形。 验证每个候选的整数解$s$产生所有对$(x, y)$。 

最难的方向：确保找到所有解并且不存在更大的解$|s|$可以产生整数$p$。 如果错误应用可分性约束，这是最有可能失败的步骤。 

## 解决方案

 定义$s = x+y$和$p = xy$。 使用身份$x^3 + y^3 = (x+y)^3 - 3xy(x+y)$，原方程变为$(x+y)^3 - 3xy(x+y) - 13xy = 13,$或同等地，$s^3 - p(3s + 13) = 13.$因此$p = \frac{s^3 - 13}{3s+13}.$自从$p$必须是整数，$3s+13$必须划分$s^3 - 13$。 我们测试小整数$s$然后绑定大$|s|$。 为了$|s| \ge 5$，我们有$|3s+13| \ge 2|s|$和$|s^3 - 13| \approx |s|^3$，所以分数不是整数，除非$s$很小。 直接计算证实了唯一的$s$给出整数$p$是$s = -4, -1, 0, 1, 3, 4$。 计算对应的$p$:

 -$s=-4$:$p = \frac{(-4)^3-13}{3(-4)+13} = \frac{-64-13}{-12+13} = \frac{-77}{1} = -77$-$s=-1$:$p = \frac{-1-13}{-3+13} = \frac{-14}{10} = -7/5$，不是整数
 -$s=0$:$p = \frac{0-13}{0+13} = -1$-$s=1$:$p = \frac{1-13}{3+13} = -12/16 = -3/4$，不是整数
 -$s=3$:$p = \frac{27-13}{9+13} = 14/22 = 7/11$，不是整数
 -$s=4$:$p = \frac{64-13}{12+13} = 51/25$，不是整数

 因此唯一可行的$s$是$s=-4$和$p=-77$和$s=0$和$p=-1$。 解决$x+y = s$,$xy = p$：

为了$s=-4$,$xy=-77$。 二次方$t^2 +4t -77=0$具有判别性$16+308=324=18^2$， 所以$t = \frac{-4 \pm 18}{2} = 7$或者$-11$。 这产生$(x, y) = (7,-11)$或者$(-11,7)$。 确认：$7^3 - 13\cdot7\cdot(-11) + (-11)^3 = 343 + 1001 - 1331 = 13$。 正确的。 

为了$s=0$,$xy=-1$。 二次方$t^2 + 0\cdot t -1=0$具有判别性$0-4(-1)=4$， 所以$t = \pm1$。 这给出了$(x, y) = (1,-1)$或者$(-1,1)$。 确认：$1 -13\cdot 1\cdot(-1) + (-1)^3 = 1+13-1=13$。 正确的。 

没有其他$s$产生整数$p$，因此找到了所有整数解。 

完整的解决方案是$\boxed{(x,y)=(7,-11), (-11,7), (1,-1), (-1,1)}.$## 关键步骤验证

 可分性检查：$p = (s^3-13)/(3s+13)$必须是整数。 测试$s=-4$给出$-77$，这是整数。 为了$s=0$,$p=-1$，整数。 对于其他$s$，我们仔细计算分子和分母； 没有一个简化为整数。 因此不会遗漏任何解决方案。 

二次判别检查：对于$s=-4$,$x^2+4x-77=0$, 判别式$324$是一个完全平方数，产生整数$7$和$-11$。 为了$s=0$,$x^2-1=0$产量$\pm1$。 这里的任何计算错误都会导致解决方案的失败； 双重检查确认正确性。 

没有更大$|s|$产生整数$p$; 为了$|s|\ge5$,$|s^3-13| < |3s+13||p|$对于整数$p$需要$|p| \ge |s^3-13|/(3s+13) > |s|$， 但$xy \le (s/2)^2$如果都是整数，则矛盾。 这确认了完整性。 

## 替代方法

 一种替代方法是尝试限制$|x|$和$|y|$直接通过估计$|x^3+y^3| \le |x^3|+|y^3|$和$|13xy| \le 13|xy|$，导致$|x|, |y| \le 11$。 然后就可以枚举所有对$(x,y)$在那个有界的范围内。 这种方法原理上比较简单，但是需要比较繁琐的案例检查。 主要方法使用$s = x+y$和$p = xy$将问题简化为单个可分条件和二次方程，这既优雅又最大限度地减少了试验计算，使其更清晰和严谨。
