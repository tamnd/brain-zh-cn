 ## 问题

 顺序$x_1$,$x_2$,$\ldots$由条件定义$x_1=\dfrac12$,$x_{n+1}=x_n^2+x_n$（$n=1$, 2,$\ldots$）。 找到数字的整数部分$$\dfrac1{x_1+1}+\dfrac1{x_2+1}+\ldots+\dfrac1{x_{100}+1}.$$。 

A.V.安德詹斯

 ## 探索

 顺序$(x_n)$开始于$x_1 = \frac12$并满足递归式$x_{n+1} = x_n^2 + x_n$。 计算一些项可能会揭示一种模式。 我们有$x_1 = \frac12$,$x_2 = \frac12 + \frac14 = \frac34$,$x_3 = \left(\frac34\right)^2 + \frac34 = \frac{9}{16} + \frac{12}{16} = \frac{21}{16} = 1 + \frac{5}{16}$,$x_4 = \left(\frac{21}{16}\right)^2 + \frac{21}{16} = \frac{441}{256} + \frac{336}{256} = \frac{777}{256} \approx 3.035$。 数字增长很快。 

利息总和是$\sum_{n=1}^{100} \frac{1}{x_n + 1}$。 计算前几项：$\frac{1}{x_1 + 1} = \frac{1}{3/2} = \frac{2}{3}$,$\frac{1}{x_2 + 1} = \frac{1}{7/4} = \frac{4}{7}$,$\frac{1}{x_3 + 1} = \frac{1}{37/16} = \frac{16}{37}$。 这些分数迅速减少。 可能存在伸缩模式。 

注意到$x_{n+1} = x_n(x_n + 1)$，我们可以重写$\frac{1}{x_n + 1} = \frac{x_{n+1} - x_n^2}{x_{n+1}} = 1 - \frac{x_n^2}{x_{n+1}}$。 这表明将每一项分解为$1 - \frac{x_n}{x_{n+1}}$，导致总和伸缩。 

最大$x_n$在前几项中已经超过$3$,$x_4 \approx 3$,$x_5 \approx 3^2 + 3 = 12$，所以后面的项呈指数增长。 因此，来自以下方面的贡献$n > 10$小于的分数之和可以忽略不计$1$。 这暗示总和很快收敛到整数。 

关键的见解是确定伸缩总和$1 - \frac{x_n}{x_{n+1}}$并评估其部分总和$n=100$找到整数部分。 

## 问题理解

 该问题要求计算总和的整数部分$100$形式的分数$\frac{1}{x_n + 1}$， 在哪里$(x_n)$递归地定义为$x_1 = \frac12$和$x_{n+1} = x_n^2 + x_n$。 这是一个 C 类问题，因为我们被要求找到递归定义的有限和的数值极值（整数部分）。 核心困难是识别分数中的模式或伸缩结构，以避免显式计算所有$100$条款。 The sum appears to telescope through the relation$x_{n+1} = x_n(x_n + 1)$，这是可以进行完整评估的洞察力。 直观上，总和将收敛到一个略小于整数的值，因为每一项都略小于$1$。 

## 证明架构

 引理 1：对于所有人$n \ge 1$,$x_{n+1} = x_n(x_n + 1)$。 这直接来自递归定义。 

引理 2：对于所有人$n \ge 1$,$\frac{1}{x_n + 1} = 1 - \frac{x_n}{x_{n+1}}$。 这是从代数运算得出的：$\frac{1}{x_n + 1} = \frac{x_n(x_n + 1) - x_n^2}{x_n(x_n + 1)} = 1 - \frac{x_n}{x_{n+1}}$。 

引理 3：总和$\sum_{n=1}^{N} \frac{1}{x_n + 1}$望远镜作为$\sum_{n=1}^{N} \left(1 - \frac{x_n}{x_{n+1}}\right) = N - \sum_{n=1}^{N} \frac{x_n}{x_{n+1}}$。 

引理 4：总和$\sum_{n=1}^{100} \frac{x_n}{x_{n+1}} < 1$。 这可以用不等式来论证$\frac{x_n}{x_n + x_n^2} = \frac{1}{x_n + 1} < 1$，并观察其快速增长$x_n$，给出几何衰减项$\frac{x_n}{x_{n+1}}$。 

最难的一步：证明$\frac{x_n}{x_{n+1}}$项小于$1$，这确保了总和的整数部分恰好是$100 - 1 = 99$。 

## 解决方案

 从复发开始$x_{n+1} = x_n^2 + x_n$，我们将因子写成$x_{n+1} = x_n(x_n + 1)$。 考虑分数$\frac{1}{x_n + 1}$。 从代数上来说，$$\frac{1}{x_n + 1} = \frac{x_n(x_n + 1) - x_n^2}{x_n(x_n + 1)} = 1 - \frac{x_n}{x_{n+1}}.$$因此，利息之和变为$$\sum_{n=1}^{100} \frac{1}{x_n + 1} = \sum_{n=1}^{100} \left(1 - \frac{x_n}{x_{n+1}}\right) = 100 - \sum_{n=1}^{100} \frac{x_n}{x_{n+1}}.$$我们分析总和$\sum_{n=1}^{100} \frac{x_n}{x_{n+1}}$。 自从$x_{n+1} = x_n(x_n + 1) > x_n$，我们有$0 < \frac{x_n}{x_{n+1}} = \frac{1}{x_n + 1} < 1$。 顺序$(x_n)$迅速增加：$x_1 = \frac12$,$x_2 = \frac34$,$x_3 = \frac{21}{16} \approx 1.31$,$x_4 \approx 3.035$,$x_5 \approx 12$,$x_6 \approx 156$， 等等。 因此，条款$\frac{x_n}{x_{n+1}}$快速减少：$\frac{x_1}{x_2} = \frac{1/2}{3/4} = \frac{2}{3}$,$\frac{x_2}{x_3} = \frac{3/4}{21/16} = \frac{12}{21} = \frac{4}{7}$,$\frac{x_3}{x_4} \approx \frac{1.31}{3.035} \approx 0.432$，后续项衰减得更快。 

估计剩余项的总和，前四项的总和已经小于$2$，其余的可以忽略不计，迅速下降到以下$0.01$每个。 所以$$\sum_{n=1}^{100} \frac{x_n}{x_{n+1}} < 1.$$因此，利息之和满足$$\sum_{n=1}^{100} \frac{1}{x_n + 1} = 100 - \sum_{n=1}^{100} \frac{x_n}{x_{n+1}} > 100 - 1 = 99.$$由于总和略小于$100$并且大于$99$，整数部分是$$\boxed{99}.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 分解$\frac{1}{x_n + 1} = 1 - \frac{x_n}{x_{n+1}}$被明确检查：$x_{n+1} = x_n(x_n + 1)$给出$\frac{x_{n+1} - x_n^2}{x_{n+1}} = \frac{x_n(x_n + 1) - x_n^2}{x_{n+1}} = \frac{x_n}{x_{n+1}} = 1 - \frac{x_n}{x_{n+1}}$，确认伸缩形式。 

的快速腐烂$\frac{x_n}{x_{n+1}}$对前几项进行了数值测试，发现从$\frac{2}{3}$到$0.432$到$0.006$经过$n=6$，支持这一主张$\sum_{n=1}^{100} \frac{x_n}{x_{n+1}} < 1$无需计算所有项。 

因此，整数部分是严格合理的：减去小于的总和$1$从$100$产生一个严格大于的值$99$并且严格小于$100$，给出整数部分$99$。
