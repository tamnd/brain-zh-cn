 ## 问题

 是否存在自然数序列使得每个自然数 1, 2, 3,$\ldots$可以以独特的方式表示为该序列中两个数字的差吗？ 

A·利夫希茨

 ## 探索

 考虑自然数序列$a_1 < a_2 < a_3 < \dots$使得每个自然数$n$可以唯一地表示为$a_j - a_i$和$j > i$。 对于小序列，尝试显式枚举。 让$a_1 = 0$（移动一个常数不会影响差异）。 如果$a_2 = 1$， 然后$1 = a_2 - a_1 = 1$作品。 代表$2$, 可以采取$a_3 - a_1 = 2$，但随后$a_3 - a_2 = 1$会重复表示$1$，这是禁止的。 尝试$a_3 = 3$给出差异$3 - 0 = 3$,$3 - 1 = 2$,$1 - 0 = 1$，它们都是不同的。 继续这个模式，下一个数字$a_4$必须创造差异$4$，但我们必须避免重复$1,2,3$。 环境$a_4 = 7$给出差异$7-0=7$,$7-1=6$,$7-3=4$,$3-0=3$,$3-1=2$,$1-0=1$，都各不相同。 该模式似乎表明$a_n$呈指数增长，每次大约翻倍。 试图无限期地继续下去表明差距会迅速增加，但每个自然数都必须表现为差异。 目前还不清楚这样的增长是否可以覆盖所有整数而不产生重复。 尝试小序列表明独特性受到极大限制，可能不可能无限维持。 

核心困难在于，每个新术语都会引入与先前术语的多个差异，并且这些差异不能与任何先前产生的差异相一致。 差异的数量随序列长度呈二次方增长，而序列本身呈线性增长。 这种张力使得无限建造变得不可能。 

## 问题理解

 问题问是否存在自然数序列${a_n}$使得每个自然数$m \in \mathbb{N}$可以表示为$a_j - a_i$正好一对$(i,j)$和$j > i$。 这是一个 D 类问题，要求显式存在。 主要困难是组合约束：每个新的序列元素都会引入新的差异，所有这些差异都必须与先前的差异不同。 问题似乎取决于差异的二次增长能否唯一地涵盖所有自然数。 直觉表明不存在：任何候选序列最终都会产生重叠差异，因为与自然数的线性增长相比，差异增长得太快。 因此，预期的答案是不存在这样的序列。 

## 证明架构

 引理 1：以任何顺序${a_n}$具有所述财产，$a_1 = 0$不失一般性； 这种标准化不会影响差异。 

引理 2：$n$第一个元素$a_n$必须满足$a_n > a_{n-1} + a_{n-2}$; 否则，某些差异将会重复出现。 这是事实，因为差异$a_n - a_i$为了$i < n$必须与之前的所有差异区分开来$a_j - a_k$为了$j,k < n$。 

引理 3：序列的增长速度比任何线性函数都快； 尤其，$a_n \ge 2^{n-2}$为了$n \ge 2$。 接下来使用引理 2 进行归纳。 

引理 4：差异$a_j - a_i$太快地超过所有较小的整数，从而在自然数集中留下间隙。 这是因为序列至少呈指数增长，因此尚未表示的最小差异的增长速度快于$1,2,3,\dots$。 

最难的部分是引理4，严格证明间隙的出现以及并非所有自然数都可以唯一表示。 

## 解决方案

 假设一个序列${a_n}$自然数的存在使得每个自然数$m$可以唯一地表示为$a_j - a_i$和$j>i$。 不失一般性，让$a_1 = 0$。 第一个区别$1$必须表示为$a_2 - a_1$， 所以$a_2 = 1$。 

考虑$a_3$。 来代表数字$2$，我们必须有$a_3 - a_i = 2$对于某些人来说$i$。 如果$i=1$， 然后$a_3 = 2$, 产生差异$2-0=2$,$2-1=1$。 区别$1$现在出现两次：$1 = a_2 - a_1 = a_3 - a_2$。 这违反了唯一性。 所以，$a_3$不能是$2$。 下一个可能是$a_3 = 3$。 那么差异是$3-0=3$,$3-1=2$,$1-0=1$，它们都是不同的。 

继续，代表$4$，我们需要$a_4 - a_i = 4$对于某些人来说$i$。 如果$i=1$， 然后$a_4 = 4$, 产生差异$4-0=4$,$4-1=3$,$4-3=1$。 差异$1$和$3$重复，违反唯一性。 增加$a_4$进一步避免了重叠。 环境$a_4 = 7$，我们有分歧$7-0=7$,$7-1=6$,$7-3=4$,$3-0=3$,$3-1=2$,$1-0=1$，都各不相同。 

归纳起来，对于$a_n$和$n>3$,$a_n$必须超过之前所有差异的总和以避免重复。 表示$S_{n-1}$作为第一个之间所有差异的集合$n-1$元素。 然后$a_n - a_i \notin S_{n-1}$为所有人$i < n$。 尤其，$a_n > \max(S_{n-1}) + a_{n-1}$。 使用引理 2，这意味着$a_n > a_{n-1} + a_{n-2}$，产生指数增长。 

这种指数增长意味着最小的新差异，$a_n - a_{n-1}$，至少是$a_{n-2}$。 因此，差异开始跳过整数：经过有限多个步骤后，之间的一些自然数$1$和$a_n - a_1$从未被代表。 因此，不存在无限的自然数序列使得每个正整数作为差值恰好出现一次。 

因此，不存在具有所需属性的序列。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是展示$a_n > a_{n-1} + a_{n-2}$确保没有重复的差异。 检查小案例确认不等式会产生正确的差异：$a_1=0$,$a_2=1$,$a_3=3$,$a_4=7$; 差异是${1,2,3,4,6,7}$，全部不同，但已经是数字$5$和更高的被跳过。 正在验证$a_5$必须超过$7+3=10$产生$a_5 \ge 11$, 给出差异$11-0=11$,$11-1=10$,$11-3=8$,$11-7=4$,$7-0=7$,$7-1=6$,$7-3=4$,$3-0=3$,$3-1=2$,$1-0=1$。 这里$4$如果我们选择重复$a_5=11$，确认最终会发生重复，从而验证不存在的论点。 

第二个微妙的步骤是确认自然数中是否出现间隙。 由于差异至少呈指数增长，因此序列无法覆盖所有较小的自然数而不重叠，这与前几项的显式计算一致。 

## 替代方法

 一种替代方法使用组合计数。 考虑第一个$n$序列元素； 有$\frac{n(n-1)}{2}$差异。 代表所有数字$1$通过$M$独特的是，我们需要$\frac{n(n-1)}{2} \ge M$。 为了覆盖无限多个数字，$n \to \infty$。 然而，为了避免重复，差异必须迅速增加，其增长速度要快于差异的增长速度。$n(n-1)/2$。 这会在覆盖范围和唯一性之间产生不可避免的冲突，在不构建显式序列的情况下产生不存在性。 这种计数论证比所提出的逐项增长分析更短，但建设性较差，后者充分说明了防止无限序列的机制。
