 ## 问题

 在黑板上，$n$数字被写入。 可以删除其中任意两个，例如$a$和$b$，而是写一个数字$\dfrac{a+b}4$。 重复这个操作$n-1$次，结果，棋盘上只剩下一个数字。 证明如果最初董事会有$n$，那么经过所有操作后，棋盘上剩余的数量至少为$\dfrac1n$。 

B·贝尔洛夫

 全联盟数学奥林匹克竞赛（XXV，1991）

 ## 探索

 考虑较小的值$n$获得洞察力。 如果$n=2$，我们从数字开始$1$和$1$。 擦除它们并写入$\dfrac{1+1}{4} = \dfrac12$树叶$\dfrac12$，等于$1/2$，并且确实满足要求$1/2 \ge 1/2$。 为了$n=3$, 开始于$1,1,1$。 选择任意两个数字$1$和$1$给出$\dfrac{1+1}{4} = \dfrac12$，留下数字$\dfrac12$和$1$。 然后最后一步产生$\dfrac{\frac12 + 1}{4} = \dfrac{3/2}{4} = \dfrac{3}{8}$，大于$1/3$。 为了$n=4$, 数字$1,1,1,1$可以通过多种方式进行配对。 选择前两个给出$\dfrac12$，后两个给出另一个$\dfrac12$，离开$\dfrac12, \dfrac12$。 结合这些给出$\dfrac{1/2+1/2}{4} = 1/4$，等于$1/4$。 这些例子表明，当初始数字成对对称地组合时，会出现最小的最终数字，从而在每个步骤中产生尽可能小的分数。 

操作$\dfrac{a+b}{4}$将两个数字的总和减少一个因子$1/4$他们的总和。 直接跟踪总和可能会产生误导，因为总和不是线性保留的。 一种更有前途的方法是考虑所有初始数字的加权和，其系数由每个数字对最终结果的贡献次数确定。 

另一个角度是为每个数字分配一个“权重”，代表其对最终数字的贡献。 每个操作都会将综合贡献减少一个因子$1/4$，这表明最终数字是初始数字与总权重的凸组合$4^{-(n-1)}$在每条路径上。 小情况表明最小值至少为$1/n$，并且当$n$是一个幂$2$，允许完美的成对合并。 

可能微妙的一点是严格证明对于任何选择序列，最终的数字至少是$1/n$，而不仅仅是在对称或二次幂的情况下。 

## 问题理解

 该问题要求证明经过一系列操作后最终数字的下界$n-1$操作于$n$最初的。 每个操作需要两个数字$a$和$b$并将它们替换为$(a+b)/4$。 问题类型为 B 类：我们被要求证明有关最终结果的陈述。 核心困难在于操作顺序是任意的，我们需要一个适用于所有选择的界限。 

直观上，最终的数字不能太小，因为每次操作都会将所选数字的总和减少一个因子$1/4$，但初始数字都是相等的，因此没有任何选择可以极大地偏向一个数字而不是其他数字。 预期的答案是所有序列的最小数是$1/n$，这似乎与小例子一致。 

## 证明架构

 引理 1：在每次操作中，替换$a$和$b$和$(a+b)/4$将所有数字的总和减少一个因子，但最终数字可以表示为初始数字的凸组合，其非负系数总和为$1$。 该证明使用了对操作数量的归纳并跟踪贡献。 

引理 2：对于从以下位置开始的任何操作序列$n$，最终数中每个初始数的系数最多为$1$。 这是从递归结构得出的：每次合并将两个数字的总和除以$4$，因此每个原始值都沿着乘法路径贡献$1/4$，从不超过$1$。 

引理 3：当贡献分布尽可能不均匀时，最终数字就会最小。 通过对称性，当合并序列为一个数字产生最大可能数量的“嵌套”时，就实现了最小数量，这对应于合并二叉树的结构。 最小的最终数字等于$1/n$。 证明使用了一个极值论证：$1/4$任何路径上的因素总和不能小于$1/n$。 

最难的部分是引理 3，因为它需要对贡献进行仔细的组合计算，并严格论证没有序列可以产生小于$1/n$。 

## 解决方案

 将初始数字表示为$x_1 = x_2 = \dots = x_n = 1$。 每个操作替换两个数字$a$和$b$和$(a+b)/4$。 让$y$是之后的最终数字$n-1$运营。 考虑代表$y$作为初始数字的线性组合：$$y = c_1 x_1 + c_2 x_2 + \dots + c_n x_n,$$其中系数$c_i$是非负的并且取决于操作顺序。 最初，每个$x_i$有系数$1$。 什么时候$x_i$和$x_j$合并起来，新的系数为$(c_i + c_j)/4$。 

我们通过归纳法证明$n$任何此类线性组合中的最小可能最终系数至少为$1/n$。 为了$n=1$，最终的数字是$1$，等于$1/1$，满足要求。 假设该声明适用于所有人$k<n$。 考虑$n$数字和第一个操作合并$a$和$b$。 让$A$和$B$是最终贡献的两组初始数字的大小$a$和$b$， 所以$A+B = n$。 根据归纳假设，可得 中各初始数的系数$a$至少是$1/A$，并在$b$至少$1/B$。 然后任意初始数在新数中的系数$(a+b)/4$至少是$$\frac{1/A + 0}{4} \quad \text{or} \quad \frac{0 + 1/B}{4}.$$我们的目标是最小化一条路径上的最大系数。 当合并组的大小尽可能相等时，会出现最小的最终系数。 在这种情况下，让$A = \lfloor n/2 \rfloor$和$B = \lceil n/2 \rceil$， 所以$$\frac{1}{4} \left(\frac{1}{A} + \frac{1}{B}\right) \ge \frac{1}{n}.$$事实上，对于整数$A,B \ge 1$和$A+B=n$，我们有$$\frac{1}{4} \left(\frac{1}{A} + \frac{1}{B}\right) = \frac{1}{4} \cdot \frac{A+B}{AB} = \frac{n}{4 AB}.$$产品$AB$最大时$A$和$B$尽可能相等，所以$AB \le \frac{n^2}{4}$， 因此$$\frac{n}{4 AB} \ge \frac{n}{4 \cdot n^2 /4} = \frac{1}{n}.$$没有任何操作序列可以产生更小的系数，因为任何其他合并都会产生更小的系数$AB$因此更大$\frac{n}{4AB}$。 所以，$y \ge 1/n$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是估计$$\frac{1}{4} \left(\frac{1}{A} + \frac{1}{B}\right) \ge \frac{1}{n}.$$我们检查一些小例子。 为了$n=4$,$A=B=2$, 给予$1/4 (1/2 + 1/2) = 1/4$, 匹配$1/n = 1/4$。 为了$n=3$,$A=1$,$B=2$, 给予$1/4(1 + 1/2) = 3/8 > 1/3$。 为了$n=5$,$A=2$,$B=3$, 给予$1/4(1/2 + 1/3) = 5/24 > 1/5$。 这些计算证实了该论点适用于小$n$并建议一般情况下边界成立。 粗心的论证可能失败的唯一方法是假设$AB$等于$n^2/4$完全适合所有人$n$，但不等式考虑了整数舍入，使其变得严格。 

将最终数字分解为初始数字的线性组合是另一个微妙的步骤。 重新推导为$n=3$与合并$(1,1) \to 1/2$， 然后$(1/2,1) \to 3/8$，确认每个初始数至少有系数$1/3$。 

## 替代方法

 另一种方法考虑总和$S$黑板上的数字。 每个操作替换$a$和$b$经过$(a+b)/4$，将总和减少$3/4(a+b)$。 直接追踪$S$很混乱，但是系数调和平均值的不等式会导致相同的结果$1/n$边界。 另一种方法将该过程建模为带有标记的叶子的有根二叉树
