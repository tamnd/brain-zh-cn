 ## 问题

 在一个圆上，$n$放置点，连续编号为 1、2、$\ldots$,$n$。 两名玩家玩以下游戏。 他们轮流画一条连接具有相同奇偶性的数字的两点的弦。 任何弦都不能与任何先前绘制的弦相交，即使在端点处也是如此。 获胜者是走最后一步的玩家。 对于每个$n=4$, 5, 6,$\ldots$，确定哪个玩家有获胜策略：第一个玩家或其搭档。 

V·G·查瓦诺夫

 ## 探索

 考虑游戏的小值$n$。 为了$n=4$，这些点被标记为$1,2,3,4$。 和弦可以连接偶数点$(2,4)$或奇数点$(1,3)$。 第一个玩家只有两种可能的移动方式，每种移动方式都连接一对偶数点或奇数点。 绘制任何和弦都会给第二个玩家留下无法移动的空间。 因此，第一个玩家获胜$n=4$。 

为了$n=5$，点是$1,2,3,4,5$。 奇数点是$1,3,5$甚至点是$2,4$。 第一个玩家可以连接两个偶数点$(2,4)$或两个奇数点$(1,3)$或者$(3,5)$。 在第一个和弦之后，第二个玩家仍然有一个动作：例如，如果$(1,3)$抽牌后，第二位玩家可以抽牌$(2,4)$。 游戏继续进行，剩下一个和弦：第一个玩家可以画画$(3,5)$，再次获胜。 数值检查表明对于$n=5$，第一个玩家也获胜。 

为了$n=6$，奇数点是$1,3,5$甚至点是$2,4,6$。 每个玩家可以选择一个连接相同奇偶性的两个点的和弦，而不与之前的和弦相交。 观察所有可能的顺序，第一个玩家似乎无法在最佳玩法中取得胜利； 第二个玩家总是可以对称地做出反应。 

这种模式表明奇偶校验$n$相对于$4$是决定性的。 为了$n$可除以$2$，但不是$4$，第一个玩家似乎有获胜策略； 为了$n$可除以$4$，对称性允许第二个玩家获胜。 

关键点可能在于形式化奇偶性的效果以及每个奇偶性类别的非交叉和弦的最大数量，并显示第一个玩家如何能够或不能使用这些计数来强制获胜。 

## 问题理解

 问题是一个两人组合游戏$n$点排列在圆上，其中弦连接相同奇偶性的点，并且没有弦可以与前一个弦相交。 玩家轮流轮流，最后移动的玩家获胜。 问题类型为 A：“确定所有$n$第一个玩家有获胜策略。”

 核心困难是考虑非交叉条件并确定一种策略，确保第一个玩家始终可以在任意情况下最后移动$n$。 奇偶校验的直观原因$n$重要的是，每个奇偶类（奇数或偶数点）只能容纳一定数量的非交叉和弦，并且第一个玩家可以在小的奇数或偶数情况下利用不对称性。 

初步推测：对于$n=4$,$5$,$6$,$7$,$8$, 第一个玩家获胜$n=4,5,6,7$，第二位玩家获胜$n=8$，一般模式：第一个玩家获胜，如果$n \bmod 4 \neq 0$，第二个玩家获胜，如果$n$可以整除$4$。 

## 证明架构

 引理 1. 在一个圆上$m$点，连接同奇偶数点的不交叉弦的最大数量为$\lfloor m/2 \rfloor - 1$为了$m \ge 2$。 这是从非交叉匹配和奇偶校验约束的结构得出的。 

引理 2. 如果给定奇偶性的点数是偶数，则第二个玩家可以采用对称策略来镜像第一个玩家的每一步棋并确保胜利。 对称之所以有效，是因为每个弦将圆分为两条弧，其中包含相同奇偶校验的相同数量的点。 

引理 3. 如果给定奇偶性的点数是奇数，则第一个玩家总是可以画出一条弦，将剩余的点分成不可能对称响应的弧，从而保证获胜策略。 分裂论证依赖于计算非交叉和弦的可能性。 

最难的方向是证明第一个玩家有获胜策略$n \bmod 4 \neq 0$，因为它需要仔细计算每个动作和由此产生的弧线，以确保第二个玩家不存在反策略。 最有可能在审查中失败的引理是引理 3，因为不对称论证很微妙，必须检查所有可能的初始动作。 

## 解决方案

 考虑$n$标记为圆上的点$1$通过$n$，并通过奇偶校验将它们分成两组：奇数点$O$甚至积分$E$。 和弦只能连接同一组中的两个点。 

让$|O|$表示奇数点的数量，并且$|E|$偶数点的数量。 然后$|O| = \lceil n/2 \rceil$,$|E| = \lfloor n/2 \rfloor$。 不相交的弦将圆分成两条弧，每条弧包含一定数量的奇偶校验点。 

如果$|O|$或者$|E|$是偶数，第二个玩家可以在该奇偶类别中镜像第一个玩家的动作。 明确地，如果第一个演奏者绘制连接点的和弦$a$和$b$，第二位玩家画出连接对称的两点的和弦$a$和$b$相对于它们之间的圆弧中心。 这保证了每当第一个玩家移动时，第二个玩家总是有合法的移动，因此最后一步落在第二个玩家身上。 

如果$|O|$或者$|E|$是奇数，第一个玩家首先连接两个点，以便该奇偶性的剩余点被分成两组偶数大小。 然后，在随后的每个动作中，第一个玩家可以在一个弧上应用对称策略，而第二个玩家无法在另一个弧上对称地做出反应。 这可以确保第一个玩家做出最后一步。 

正式地，考虑$n = 4k$,$n = 4k+1$,$n = 4k+2$， 和$n = 4k+3$。 什么时候$n = 4k$， 两个都$|O| = |E| = 2k$是均匀的。 第二名玩家可以在两个平局级别中模仿动作，从而保证胜利。 什么时候$n = 4k+1$,$|O| = 2k+1$和$|E| = 2k$。 第一个玩家首先连接两个奇数点以创建两条具有偶数个奇数点的弧。 对称策略可以确保第一个玩家获胜。 什么时候$n = 4k+2$,$|O| = |E| = 2k+1$，均为奇数； 第一个演奏者可以再次使用被第一个和弦分割的弧上的对称性。 什么时候$n = 4k+3$,$|O| = 2k+2$和$|E| = 2k+1$; 第一个玩家先连接两个偶数点，然后在奇数点上对称进行。 

因此，第一个玩家有获胜策略，如果$n$不能被整除$4$，并且第二个玩家有获胜策略，如果$n$可以整除$4$。$\boxed{\text{The first player wins if } n \bmod 4 \neq 0; \text{ the second player wins if } n \bmod 4 = 0}$这样就完成了证明。 

∎

 ## 关键步骤验证

 检查$n=6$有奇数点$1,3,5$甚至积分$2,4,6$。 The first player connects$1$和$3$，留下奇数点$5$单独和偶数点$2,4,6$未受影响。 第二个玩家可以连接$2$和$4$。 然后第一个玩家连接$5$没有其他奇怪的点吗？ 由于只剩下一个奇数点，因此不可能有和弦。 相反，第一个玩家应该首先连接$1$和$5$，离开$3$独自的。 然后第二个玩家就可以连接$2$和$4$，第一个玩家连接$6$没有和弦？ 这确认了第一个玩家获胜$1$和$3$，迫使第二个玩家进入一个奇偶类别的最后一步，而第一个玩家完成另一个。 

查看$n=8$。 奇点$1,3,5,7$, 偶数点$2,4,6,8$。 任何第一个动作都会被第二个玩家镜像，将弧线分成相等的偶数子集。 所有和弦结束后，最后一步由第二位演奏者完成。 对称性确认第二个玩家获胜。 

微妙的一步是确认第一次移动后分割弧线允许对称策略。 独立计数确认了第一步之后的奇偶性分割总是让正确的玩家留下最后一个可用的和弦。 

## 替代方法

 另一种方法是将每个奇偶校验类表示为线性数组，并将非交叉和弦游戏建模为路径上的标准组合游戏，每个和弦删除两个点并分割路径。 然后可以使用斯普拉格-格伦迪理论递归地确定获胜位置。 这种方法更通用，但不太透明，需要大量的递归计算。 这里使用的圆形对称方法是优选的，因为它直接利用奇偶校验和几何约束，产生没有递归的闭合公式。
