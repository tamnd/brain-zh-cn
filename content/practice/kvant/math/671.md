 ## 问题

 在循环四边形中，一条对角线平分另一条对角线。 证明第一条对角线长度的平方等于四边形所有边长度平方和的一半。 

R·马佐夫

 ## 探索

 设循环四边形为$ABCD$有对角线$AC$和$BD$。 认为$AC$一分为二$BD$在点$E$， 所以$BE = ED$。 给侧面贴上标签$AB = a$,$BC = b$,$CD = c$， 和$DA = d$，和对角线$AC = p$,$BD = q$。 其主张是$p^2 = \frac{a^2 + b^2 + c^2 + d^2}{2}$。 

考虑将四边形放置在坐标系中以简化计算。 环境$E$在原点和$AC$沿着$x$-axis 很有前途，因为二分条件产生对称坐标$B$和$D$，即$B = (x_B, y)$和$D = (x_D, -y)$。 然后$BD = q = 2y$和$E$在中点给出$x_B = x_D$，符合对称性。 

尝试使用矩形或正方形作为特殊情况来验证该公式。 对于有边的正方形$s$，对角线相等$s\sqrt{2}$， 和$AC$一分为二$BD$。 然后$p^2 = 2s^2$， 尽管$(a^2 + b^2 + c^2 + d^2)/2 = 4s^2/2 = 2s^2$， 持续的。 底角相等的等腰梯形给出了另一个看似合理的检验。 

中心思想是，循环四边形中一条对角线的平分引入了对称性，允许在共享平分对角线的三角形中应用余弦定律，以半对角线长度和另一条对角线的长度表示边长。 在消除余弦项后，这将证明简化为代数恒等式。 

关键是处理一般的循环情况，而不依赖直角（如正方形）并正确计算$p^2$就所有四个方面而言。 

## 问题理解

 该问题要求证明在循环四边形中$ABCD$，如果对角线$AC$平分对角线$BD$， 然后$AC^2$等于四个边的平方和的一半。 这是 B 类问题：需要直接证明，不需要分类或极值构造。 核心难点是用对角线来表达边长$AC$和二分性质，然后在不假设任何特殊角度的情况下严格证明恒等式。 该公式的对称性表明与平面中的向量或坐标表示或应用于三角形的余弦定律有关$ABC$和$ADC$。 

## 证明架构

 引理 1. 放置$E$，中点$BD$，在原点并对齐$AC$沿着$x$-axis 引入坐标$A=(-p/2,0)$,$C=(p/2,0)$,$B=(u,v)$,$D=(-u,-v)$。 这捕获了二分条件并保留了循环性。 草图：中点和平移简化了距离。 

引理 2. 循环条件意味着点$A,B,C,D$位于一个圆上，给出之间的二次关系$u$,$v$， 和$p$。 草图：所有点距圆心等距，或使用标准距离公式。 

引理 3. 用以下形式表示边长$p$,$u$,$v$产量$AB^2 = (u + p/2)^2 + v^2$,$BC^2 = (u - p/2)^2 + v^2$,$CD^2 = (u + p/2)^2 + v^2$,$DA^2 = (u - p/2)^2 + v^2$。 简述：求和时代数展开式简化。 

引理 4. 将边的平方相加并除以二产生$p^2 + 2(u^2 + v^2)$。 草图：对称项适当取消，留下$p^2$如果周期性确保$u^2 + v^2 = 0$，这是从放置在圆上得出的。 

最难的部分是引理 4，验证代数简化是否正确地同时处理循环条件和二分。 

## 解决方案

 让$ABCD$是一个有对角线的循环四边形$AC$平分$BD$在$E$。 分配坐标$A = (-p/2,0)$和$C = (p/2,0)$沿着$x$- 轴，有$E = (0,0)$。 自从$E$是的中点$BD$， 写$B = (u,v)$和$D = (-u,-v)$。 坐标满足构造平分。 

这些坐标中的边长是通过距离公式计算的。 我们有$$AB^2 = \left(-\frac{p}{2} - u\right)^2 + (0 - v)^2 = \left(u + \frac{p}{2}\right)^2 + v^2,$$

$$BC^2 = \left(u - \frac{p}{2}\right)^2 + v^2,$$

$$CD^2 = \left(-u - \frac{p}{2}\right)^2 + (-v - 0)^2 = \left(u + \frac{p}{2}\right)^2 + v^2,$$

$$DA^2 = \left(-u + \frac{p}{2}\right)^2 + (-v - 0)^2 = \left(u - \frac{p}{2}\right)^2 + v^2.$$将所有四个边的平方相加得出

 \开始{对齐*}

 AB^2 + BC^2 + CD^2 + DA^2 &= \left(u + \frac{p}{2}\right)^2 + v^2 + \left(u - \frac{p}{2}\right)^2 + v^2 \

 &\quad + \left(u + \frac{p}{2}\right)^2 + v^2 + \left(u - \frac{p}{2}\right)^2 + v^2 \

 &= 2\left[(u + \frac{p}{2})^2 + (u - \frac{p}{2})^2\right] + 4v^2。 

\结束{对齐*}

 扩展$(u \pm p/2)^2 = u^2 \pm pu + p^2/4$并总结：

 \开始{对齐*}

 (u + \frac{p}{2})^2 + (u - \frac{p}{2})^2 &= u^2 + pu + \frac{p^2}{4} + u^2 - pu + \frac{p^2}{4} = 2u^2 + \frac{p^2}{2}。 

\结束{对齐*}

 因此，$$AB^2 + BC^2 + CD^2 + DA^2 = 2(2u^2 + \frac{p^2}{2}) + 4v^2 = 4u^2 + p^2 + 4v^2 = p^2 + 4(u^2 + v^2).$$自从$B$和$D$躺在圆圈上通过$A$和$C$，原点$E$和点$A$,$C$满足圆方程。 让圆有圆心$(0,k)$和半径$R$。 然后$A$和$C$满足$(-p/2)^2 + k^2 = (p/2)^2 + k^2 = R^2$, 给予$k^2 + p^2/4 = R^2$。 为了$B=(u,v)$和$D=(-u,-v)$躺在同一个圆上，$(u)^2 + (v - k)^2 = R^2$和$(-u)^2 + (-v - k)^2 = u^2 + (v + k)^2 = R^2$。 等同$u^2 + (v - k)^2 = u^2 + (v + k)^2$给出$v - k)^2 = (v + k)^2$， 或者$v^2 - 2vk + k^2 = v^2 + 2vk + k^2$， 所以$-4vk = 0$。 自从$k \neq 0$一般来说，这会产生$v = 0$。 

和$v = 0$，我们有$u^2 + v^2 = u^2$，但前面的方程$u^2 + (v - k)^2 = R^2 = k^2 + p^2/4$减少到$u^2 + k^2 = k^2 + p^2/4$, 给予$u^2 = p^2/4$。 因此$u^2 + v^2 = p^2/4 + 0 = p^2/4$。 代回平方和，$AB^2 + BC^2 + CD^2 + DA^2 = p^2 + 4(u^2 + v^2) = p^2 + 4(p^2/4) = 2p^2$。 因此$$p^2 = \frac{AB^2 + BC^2 + CD^2 + DA^2}{2}.$$这样就完成了证明。 

∎
