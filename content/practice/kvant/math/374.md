 ## 问题

 M374。 让$a, b$和$c$为正数，$a > c$和$b > c$。 证明不等式$\sqrt{c(a-c)} + \sqrt{c(b-c)} \le \sqrt{ab}$。 

## 探索

 该表达式包含两个均包含因子的平方根$c$，建议进行因式分解$\sqrt{c}$。 写作$\sqrt{c(a-c)} + \sqrt{c(b-c)} = \sqrt{c}\bigl(\sqrt{a-c} + \sqrt{b-c}\bigr)$将问题简化为比较两个平方根之和$\sqrt{ab/c}$将右侧平方后。 

平方是可行的，因为所有数量都是正数。 平方后，形式的混合项$\sqrt{(a-c)(b-c)}$出现，这表明在引入后完成一个正方形$x = \sqrt{(a-c)(b-c)}$。 该结构可能会塌陷成一个完美的正方形。 

## 问题理解

 这是 B 类问题：证明不等式$\sqrt{c(a-c)} + \sqrt{c(b-c)} \le \sqrt{ab},$为积极的$a,b,c$和$a>c$和$b>c$。 

关键的难点是在对不等式进行平方后处理两个平方根之间的相互作用，并确保所得的代数表达式可以简化为非负形式。 

## 证明架构

 证明从分解开始$\sqrt{c}$从左侧。 

主要引理是，两边平方后，不等式等于$(a-c)(b-c) + c^2 \ge 2c\sqrt{(a-c)(b-c)}.$第二个引理是替换$x = \sqrt{(a-c)(b-c)}$，将不等式转化为完全平方数：$x^2 - 2cx + c^2 \ge 0.$最困难的步骤是验证平方后的代数重排不会引入无关的不对称性并在正性约束下保持等价性。 

## 解决方案

 自从$a>c$和$b>c$，平方根下的所有表达式都是正数。 给定的不等式等价于$\sqrt{c}\bigl(\sqrt{a-c} + \sqrt{b-c}\bigr) \le \sqrt{ab}.$两边均平方得到$c\bigl(\sqrt{a-c} + \sqrt{b-c}\bigr)^2 \le ab.$扩大正方形给出$c\bigl((a-c) + (b-c) + 2\sqrt{(a-c)(b-c)}\bigr) \le ab.$分发$c$导致$c(a+b-2c) + 2c\sqrt{(a-c)(b-c)} \le ab.$重新排列术语给出$ab - c(a+b-2c) \ge 2c\sqrt{(a-c)(b-c)}.$左边简化为$ab - ca - cb + 2c^2 = (a-c)(b-c) + c^2.$因此不等式变为$(a-c)(b-c) + c^2 \ge 2c\sqrt{(a-c)(b-c)}.$让$x = \sqrt{(a-c)(b-c)}$。 然后$x>0$不等式变为$x^2 + c^2 \ge 2cx.$这相当于$(x-c)^2 \ge 0,$这适用于所有真实的$x$和$c$。 因此原来的不等式成立。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 第一个微妙的步骤是消除不平等。 两边都是非负的，因为$c>0$和$a>c$,$b>c$确保每个平方根都是定义的并且为正数，因此平方可以保持等价性。 

第二步是代数恒等式$ab - ca - cb + 2c^2 = (a-c)(b-c) + c^2,$接下来是直接扩展$(a-c)(b-c)$和系数的比较。 

第三步是化简为完全平方数。 替代$x=\sqrt{(a-c)(b-c)}$产量$x^2 + c^2 - 2cx = (x-c)^2,$这是通过展开平方并精确匹配项而获得的。 

## 替代方法

 另一种方法使用替换$a = c + x^2$和$b = c + y^2$，将不等式转化为$c(x+y) \le \sqrt{(c+x^2)(c+y^2)}.$再次平方导致对称不等式$x$和$y$减少到$(x-y)^2 \ge 0$取消后。 该方法更早地揭示了对称性，但比直接平方完成论证引入了更多的代数替换步骤。
