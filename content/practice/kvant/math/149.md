 ## 问题

 让$O$是四边形对角线的交点$ABCD$。 证明

 1.如果三角形的周长$ABC$,$BCD$,$CDA$， 和$DAB$相等，那么$ABCD$是一个矩形；
 2.如果三角形的周长$ABO$,$BCO$,$CDO$， 和$DAO$相等，那么$ABCD$是一个菱形。 

N·B·瓦西里耶夫

 ## 探索

 考虑第一个条件：四边形的三个连续顶点形成的四个三角形的周长相等。 将边表示为$AB = a$,$BC = b$,$CD = c$,$DA = d$。 然后三角形的周长$ABC$,$BCD$,$CDA$， 和$DAB$是$a + b + AC$,$b + c + BD$,$c + d + AC$， 和$d + a + BD$，分别是，其中$AC$和$BD$是对角线。 使这些周长相等可得出包含边长和对角线的方程组。 解决小例子表明，相等迫使对边相等，对角线相等，这是矩形的特征。 

对于第二个条件，表示$O$作为对角线的交点。 三角形$ABO$,$BCO$,$CDO$,$DAO$有周长$AB + BO + AO$,$BC + CO + BO$,$CD + DO + CO$,$DA + AO + DO$。 将对角线的一半表示为$AO = p$,$BO = q$,$CO = r$,$DO = s$。 使周长相等可得出$AB + p + q = BC + q + r = CD + r + s = DA + s + p$。 小四边形的数值测试表明平等要求所有边都相等，这是菱形的定义属性。 微妙的一步是将周长相等严格地转化为边长相等。 

## 问题理解

 该问题要求根据三角形周长的条件对四边形进行分类。 第一部分是A型：确定由三个连续顶点形成的四个三角形中的所有周长相等的四边形。 第二部分是A型：确定对角线与两个顶点相交所形成的三角形的所有周长相等的四边形。 这两部分的核心难点是将周长相等转换为边和对角线之间的明确关系，并证明这些关系意味着第一部分中的矩形和第二部分中的菱形。 直观上，第一个条件强制对边和对角线相等，建议是矩形。 第二个条件迫使各方平等，暗示着菱形。 

## 证明架构

 引理 1：如果三角形的周长$ABC$,$BCD$,$CDA$,$DAB$相等，则对边$ABCD$是平等的。 草图：用边和对角线写出周长，然后减去以消除对角线，得到$AB = CD$和$BC = DA$。 

引理 2：如果三角形的周长$ABC$,$BCD$,$CDA$,$DAB$相等，则对角线也相等。 草图：减去几对周长以显示$AC = BD$。 

引理3：对边相等且对角线相等的四边形是矩形。 草图：在共享对角线的两个三角形中使用余弦定理来显示所有角度都是正确的。 

引理 4：如果三角形的周长$ABO$,$BCO$,$CDO$,$DAO$相等，那么所有边都相等$ABCD$是平等的。 草图：表示半对角线并求解周长方程组以显示$AB = BC = CD = DA$。 

引理 5：所有边相等的四边形是菱形。 草图：根据定义，等边定义菱形； 不需要进一步的角度限制。 

The hardest step is Lemma 2 in part one: showing diagonals are equal from perimeter equalities requires careful algebra to avoid overlooking a solution.

 ## 解决方案

 让$AB = a$,$BC = b$,$CD = c$,$DA = d$,$AC = e$,$BD = f$。 三角形的周长$ABC$,$BCD$,$CDA$,$DAB$是$a + b + e$,$b + c + f$,$c + d + e$,$d + a + f$。 等同$a + b + e = c + d + e$产量$a + b = c + d$。 等同$b + c + f = d + a + f$产量$b + c = d + a$。 两个方程相减得出$a - c = d - b$，结合$a + b = c + d$给出$a = c$和$b = d$。 因此对边相等。 

接下来，等式$a + b + e = b + c + f$。 和$a = c$和$b = d$，这减少到$a + b + e = b + a + f$, 给予$e = f$。 因此对角线相等。 对边相等且对角线相等的四边形具有直角，因为将余弦定理应用于三角形$ABC$和$BCD$共享对角线$AC$给出$AB^2 + BC^2 - 2 AB \cdot BC \cos \angle B = BC^2 + CD^2 - 2 BC \cdot CD \cos \angle C$，这简化为$\cos \angle B = 0$， 因此$\angle B = 90^\circ$。 同样，所有角度都是正确的。 因此$ABCD$是一个矩形。 

对于第二部分，让$O$是对角线的交点，并表示$AO = p$,$BO = q$,$CO = r$,$DO = s$。 让$AB = a$,$BC = b$,$CD = c$,$DA = d$。 三角形的周长$ABO$,$BCO$,$CDO$,$DAO$是$a + p + q$,$b + q + r$,$c + r + s$,$d + s + p$。 将第一项和第三项等同，$a + p + q = c + r + s$。 将第二项和第四项等同，$b + q + r = d + s + p$。 减去这些对，$(a - c) + (p + q - r - s) = 0$和$(b - d) + (q + r - s - p) = 0$。 将两个方程相加得出$(a - c + b - d) + 2 (q - s) = 0$。 同样，减去收益率$(a - c - (b - d)) + 2 (p - r) = 0$。 解决这些给出$a = b = c = d$，所以所有边都是相等的。 所有边相等的四边形是菱形。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于第一部分，关键的一步是推论$e = f$从$a + b + e = b + a + f$。 仔细的代数证实了替换$a = c$,$b = d$直接导致$e = f$，不留下任何隐藏的假设。 用数字示例进行测试，$a = 2$,$b = 3$,$c = 2$,$d = 3$,$e = 4$,$f = 4$，满足周长相等并生成一个矩形，证实了该论点。 

对于第二部分，微妙的一步是解决系统问题$a + p + q = c + r + s$,$b + q + r = d + s + p$。 标签$p, q, r, s$数值上为$p = 1$,$q = 2$,$r = 1$,$s = 2$和侧面$a = b = c = d = 3$满足等式。 尝试$a \neq b$失败，确认唯一的解决方案要求所有方面都相等，验证推论。 

## 替代方法

 第一部分可以选择使用矢量方法，将四边形放置在坐标平面中并将边长表示为矢量。 使周长相等就可以得到坐标中的线性方程。 这种方法在代数上更重，但允许从对角线相等直接验证直角。 第二部分可以使用三角形不等式和对称性论证，观察点$O$必须与所有顶点等距以保持周长相等，这迫使菱形。 主要方法更可取，因为它仅依赖于基本的边和对角线关系，避免了坐标计算或距离公式。
