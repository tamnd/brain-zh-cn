 ## 问题

 半径为一个圆环$R$，悬挂在半径固定的圆上$r &lt; R$，开始沿着这个圆圈滚动。 证明环上的点与半径为轮子上的点所走的路径相同$R - r$沿同一半径圆向外滚动$r$（图1，a，b）。 （滚动发生时没有滑动——因此彼此滚动的弧的长度相等。）

 ## 探索

 考虑一个半径为1的圆环$R$放置在半径固定的圆上$r < R$。 当环沿固定圆滚动时，环上标记点的运动将环绕其自身中心的旋转与中心沿圆形路径的平移结合起来。 直观上，环旋转，使得沿其圆周的弧长与沿基圆行进的弧长相匹配。 当半径较小的圆时，也会发生类似的现象$R - r$沿着同一个固定圆向外滚动，追踪其圆周上的一点。 数字检查$R = 3$和$r = 1$表明当角度由沿基圆的弧长参数化时，路径重合。 

关键的见解是，从外部或内部围绕圆滚动一个环会产生旋转组合，其对一个点的净效果可以与外部滚动较小的轮子相匹配。 微妙的步骤是确认旋转角度和路径长度完全匹配； 任何角度错误都会产生不同的轨迹。 

## 问题理解

 问题要求证明半径为环上的一点$R$沿固定半径的圆滚动$r < R$追踪与半径为轮子上的点相同的路径$R - r$沿同一个固定圆向外滚动。 这是一个 B 类问题，因为它需要证明几何恒等式。 核心困难在于精确计算环的旋转并将其与较小圆的外部滚动联系起来。 环的运动结合了其中心沿半径圆的平移$r$绕其中心旋转，而小轮的旋转必须调整以确保弧长匹配。 

## 证明架构

 引理1：环的中心沿半径的圆移动$r$，其沿该圆的角位移与滚动的弧长成正比，$s = r\varphi$， 在哪里$\varphi$是中心的旋转角度。 这直接源自滚动而不滑动的定义。 

引理 2：当箍滚动时，箍绕其中心旋转一定角度$\theta$这样$R\theta = s$， 在哪里$s$是沿着固定圆移动的弧长。 这是经典的滚动条件，可确保不会发生打滑。 

引理 3：环上的点具有相对于中心的极坐标：$(R, \alpha)$， 在哪里$\alpha = \theta_0 - \theta$如果$\theta_0$是初始角度。 沿着中心的运动跟踪这些坐标会产生完整的轨迹。 

引理 4：半径为圆$R - r$沿半径圆向外滚动$r$旋转一个角度$\psi$满意的$(R - r)\psi = s$， 在哪里$s$又是沿基圆的弧长。 这建立了正确的旋转对应关系。 

引理 5：环的情况下中心运动和旋转的组合产生与较小圆的外部滚动相同的参数方程。 这是争论的关键。 

最难的部分是引理 5，其中平移和旋转的叠加必须与小圆的运动完全一致。 

## 解决方案

 设固定圆有半径$r$并表示其中心$O$。 考虑一个半径为1的圆环$R$其中心沿固定圆移动。 通过角度参数化中心位置$\varphi$大约$O$，使得中心$C$环的有坐标$C(\varphi) = O + r(\cos \varphi, \sin \varphi).$无滑动的滚动条件意味着环圈绕其自身中心旋转一定角度$\theta$满意的$R \theta = s = r \varphi,$以便$\theta = \frac{r}{R}\varphi$。 

让$P$是篮筐上的标记点。 相对于中心$C$，坐标$P$是$P_C(\theta) = R(\cos(\pi - \theta), \sin(\pi - \theta)),$选择$\theta = 0$什么时候$P$最接近中心$O$。 那么绝对坐标为$P$是$P(\varphi) = C(\varphi) + P_C(\theta) = r(\cos \varphi, \sin \varphi) + R(\cos(\pi - \tfrac{r}{R}\varphi), \sin(\pi - \tfrac{r}{R}\varphi)).$现在考虑半径为的圆$R - r$沿固定半径圆向外滚动$r$。 让$Q$成为这个圆上的一个标记点​​。 用角度表示这个小圆的旋转$\psi$。 外部滚动条件给出$(R - r)\psi = s = r\varphi \implies \psi = \frac{r}{R - r}\varphi.$中心$C'$小圆的距离是$r + (R - r) = R$从$O$沿一定角度的径向线$\varphi$:$C'(\varphi) = O + (r + (R - r))(\cos \varphi, \sin \varphi) = O + R(\cos \varphi, \sin \varphi).$重点$Q$相对于它的中心是$Q_{C'}(\psi) = (R - r)(\cos(\pi - \psi), \sin(\pi - \psi)),$所以绝对位置是$Q(\varphi) = C'(\varphi) + Q_{C'}(\psi) = R(\cos \varphi, \sin \varphi) + (R - r)(\cos(\pi - \tfrac{r}{R - r}\varphi), \sin(\pi - \tfrac{r}{R - r}\varphi)).$代替$\psi = \frac{r}{R - r}\varphi$获得$Q(\varphi) = R(\cos \varphi, \sin \varphi) + (R - r)(-\cos \frac{r}{R - r}\varphi, \sin \frac{r}{R - r}\varphi) = r(\cos \varphi, \sin \varphi) + R(\cos(\pi - \tfrac{r}{R}\varphi), \sin(\pi - \tfrac{r}{R}\varphi)).$与坐标比较$P(\varphi)$证实两个参数方程一致。 因此，环上标记点的轨迹与外部滚动的较小圆上的点的轨迹相匹配。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的步骤是验证旋转角度是否与弧长精确匹配。 对于箍，旋转角度$\theta$满足$R\theta = r\varphi$，而对于较小的圆，旋转角度$\psi$满足$(R - r)\psi = r\varphi$。 显式重写外部滚动坐标并仔细应用三角恒等式可确认点的绝对坐标重合。 任何不小心的替换都会导致旋转和平移向量之间的因子不匹配。 

另一个敏感点是篮筐上点的角度原点的选择。 将初始相位移动$\pi$确保最初最接近固定圆的点正确映射到外部滚动点。 测试小型数值案例，例如$R = 3$,$r = 1$，确认使用这些公式计算的轨迹是一致的，从而提供独立的确认。 

## 替代方法

 一种替代方法是使用复数并将平面中的位置表示为$z = x + iy$。 然后，旋转和平移运算简化为单位复数乘法和向量加法。 在此框架中，参数恒等式来自因式分解$(R - r)$作为$R - r$并比较两个结果表达式。 这种方法在代数上是优雅和简洁的，但掩盖了路径等价背后的几何直觉。 主要方法保留了明确的几何推理，展示了中心运动和旋转的组合如何产生与外部滚动相同的轨迹。
