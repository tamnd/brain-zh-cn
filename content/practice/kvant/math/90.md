 ## 问题

 证明如果$x_1 \lt x_2 \lt x_3 \lt \ldots$是自然数，那么$$\frac{\sqrt{x_2-x_1}}{x_2} + \frac{\sqrt{x_3-x_2}}{x_3}+ \ldots + \frac{\sqrt{x_n-x_{n-1}}}{x_n} \lt 1+\frac{1}{2}+\frac{1}{3}+\ldots+\frac{1}{n^2-1}+\frac{1}{n^2}.$$G·I·纳坦森

 ## 探索

 让$$d_k=x_k-x_{k-1}\qquad (k\ge 2).$$然后$$x_k=d_2+d_3+\cdots+d_k+x_1.$$被加数是$$\frac{\sqrt{d_k}}{x_k}.$$自从$x_k\ge d_k$，粗略估计$$\frac{\sqrt{d_k}}{x_k}\le \frac1{\sqrt{d_k}}$$太弱了，因为右侧不需要以所需的方式求和。 

分母$x_k$包含所有先前的增量。 自从$$x_k=x_{k-1}+d_k,$$比较是很自然的事$\sqrt{d_k}/x_k$差异涉及$x_{k-1}$和$x_k$。 计算，$$\frac1{\sqrt{x_{k-1}}}-\frac1{\sqrt{x_k}} = \frac{x_k-x_{k-1}} {\sqrt{x_{k-1}}\sqrt{x_k}\,(\sqrt{x_k}+\sqrt{x_{k-1}})} = \frac{d_k} {\sqrt{x_{k-1}}\sqrt{x_k}\,(\sqrt{x_k}+\sqrt{x_{k-1}})}.$$这不会立即占主导地位$\sqrt{d_k}/x_k$。 

一个更有希望的比较是$$2(\sqrt{x_k}-\sqrt{x_{k-1}}) = \frac{2d_k}{\sqrt{x_k}+\sqrt{x_{k-1}}}.$$自从$x_k\ge d_k$,$$\frac{\sqrt{d_k}}{x_k} \le \frac{2d_k}{x_k(\sqrt{x_k}+\sqrt{x_{k-1}})} = 2\frac{\sqrt{x_k}-\sqrt{x_{k-1}}}{x_k}.$$使用$x_k\ge k$然后会给$$\frac{\sqrt{d_k}}{x_k} \le \frac{2(\sqrt{x_k}-\sqrt{x_{k-1}})}{k}.$$求和建议采用阿贝尔求和。 写作$$a_k=\sqrt{x_k},$$我们得到$$\sum_{k=2}^n \frac{a_k-a_{k-1}}{k}.$$按零件标识的标准离散积分给出$$\sum_{k=2}^n \frac{a_k-a_{k-1}}{k} = \frac{a_n}{n} -\frac{a_1}{2} +\sum_{k=2}^{n-1}a_k\!\left(\frac1k-\frac1{k+1}\right).$$自从$x_k\ge k$，我们有$a_k\ge\sqrt{k}$，这是错误的方向。 我们需要一个上限。 因为序列是严格递增且自然的，$$x_k\ge x_1+k-1\ge k,$$再次只有一个下限。 

因此该路线无法产生所需的谐波类型上估计。 

右边等于$$\sum_{m=1}^{n^2}\frac1m.$$这表明每个被加数应受调和项块的限制。 自从$x_k\ge k$，我们有$$x_k-x_{k-1}=d_k\ge1.$$一个自然的猜测是$$\frac{\sqrt{d_k}}{x_k} \le \sum_{m=x_{k-1}+1}^{x_k}\frac1m.$$的确，$$\sum_{m=x_{k-1}+1}^{x_k}\frac1m > \frac{d_k}{x_k}.$$因而足以证明$$\frac{\sqrt{d_k}}{x_k}\le \frac{d_k}{x_k},$$这成立是因为$d_k\ge1$意味着$\sqrt{d_k}\le d_k$。 

总结$k$产量$$\sum_{k=2}^n\frac{\sqrt{d_k}}{x_k} < \sum_{m=x_1+1}^{x_n}\frac1m.$$现在$x_n\ge n$， 因此$$\sum_{m=x_1+1}^{x_n}\frac1m \le \sum_{m=1}^{x_n}\frac1m.$$这还不够，因为$x_n$可能超过$n^2$。 目标是固定总和$n^2$。 

关键的观察是$$x_n=x_1+\sum_{k=2}^n d_k.$$对于固定$n$，最大可能值$$\sum \frac{\sqrt{d_k}}{x_k}$$应该在增量尽可能小时发生，因为较大的增量会放大分母。 让我们尝试直接估计。 自从$x_k\ge k$,$$\frac{\sqrt{d_k}}{x_k} \le \frac{\sqrt{d_k}}{k}.$$应用柯西，$$\sum_{k=2}^n \frac{\sqrt{d_k}}{k} \le \left(\sum_{k=2}^n d_k\right)^{1/2} \left(\sum_{k=2}^n \frac1{k^2}\right)^{1/2},$$这不会导致所需的谐波界限。 

另一个想法是$$\frac{\sqrt{d_k}}{x_k} \le \frac1{\sqrt{x_k}} \le \frac1{\sqrt{k}}.$$总和$1/\sqrt{k}$比谐波大得多。 

块解释可以变得更加尖锐。 自从$d_k\ge1$,$$\sqrt{d_k} \le 1+\frac12+\cdots+\frac1{d_k}.$$事实上，谐波和超过$\int_1^{d_k+1}\frac{dt}{t}>\frac12\log d_k$，数字检查显示更多。 需要更强的基本不等式。 测试：

 对于$d=1,2,3,4$,$$H_d=(1,1.5,1.833\ldots,2.083\ldots),$$全部超过$\sqrt d$。 

如果$$\sqrt d\le H_d,$$然后$$\frac{\sqrt{d_k}}{x_k} \le \sum_{j=0}^{d_k-1}\frac1{x_k} < \sum_{m=x_{k-1}+1}^{x_k}\frac1m.$$求和给出$$\sum_{k=2}^n\frac{\sqrt{d_k}}{x_k} < \sum_{m=x_1+1}^{x_n}\frac1m.$$结束时，只需表明$x_n\le n^2$。 一般来说，这是错误的。 

因此比较必须至少分配$\sqrt{d_k}$调和项$k$th 被加数。 自从$x_k\ge k$, 区间$$[(k-1)^2+1,\;k^2]$$包含$2k-1$调和项，以及$$\sum_{m=(k-1)^2+1}^{k^2}\frac1m > \frac{2k-1}{k^2} = \frac2k-\frac1{k^2}.$$这样就足以证明$$\frac{\sqrt{d_k}}{x_k} < \frac2k-\frac1{k^2}.$$使用$x_k\ge d_k+k-1$,$$\frac{\sqrt{d_k}}{x_k} \le \frac{\sqrt d}{d+k-1}.$$对于固定$k$, 最大化$$f(d)=\frac{\sqrt d}{d+k-1}.$$差异化，$$f'(d)=\frac{k-1-d}{2\sqrt d\,(d+k-1)^2}.$$因此最大值出现在$d=k-1$, 给予$$f(d)\le \frac{\sqrt{k-1}}{2(k-1)} =\frac1{2\sqrt{k-1}}.$$与相比$$\frac2k-\frac1{k^2},$$后者对所有人来说都更大$k\ge2$。 例如，$$\frac2k-\frac1{k^2} =\frac{2k-1}{k^2},$$和$$\frac{2k-1}{k^2}>\frac1{2\sqrt{k-1}}$$减少到$$4(2k-1)^2(k-1)>k^4,$$这适用于$k\ge2$。 这似乎是正确的道路。 

然后总结一下$k$准确给出谐波块$n^2$。 

微妙之处在于证明不等式$$\frac{\sqrt d}{d+k-1} < \frac{2k-1}{k^2}.$$## 问题理解

 我们必须证明对于每个严格递增的自然数序列$$x_1<x_2<\cdots<x_n,$$总和$$\sum_{k=2}^n\frac{\sqrt{x_k-x_{k-1}}}{x_k}$$小于谐波和$$\sum_{m=1}^{n^2}\frac1m.$$这是一个B 类问题。 该陈述已给出并且必须得到证明。 

核心困难是获得每个被加数的界限，该界限仅取决于其索引$k$，而不是序列的特定值。 一旦找到这样的界限，右侧建议将调和和划分为多个块$$((k-1)^2+1,\ldots,k^2).$$## 证明架构

 对于每个$k\ge2$， 写$d=x_k-x_{k-1}$; 然后$x_k\ge d+k-1$因为之前的$k-1$项是不同的正整数。 

对于固定$k$，函数$$f(d)=\frac{\sqrt d}{d+k-1}$$达到最大值$d=k-1$; 微分给出最大值的位置。 

最后，$$\frac{\sqrt{x_k-x_{k-1}}}{x_k} \le \frac1{2\sqrt{k-1}}.$$调和项块来自$(k-1)^2+1$到$k^2$有长度$2k-1$， 所以$$\sum_{m=(k-1)^2+1}^{k^2}\frac1m > \frac{2k-1}{k^2}.$$不平等$$\frac1{2\sqrt{k-1}} < \frac{2k-1}{k^2}$$对于每一个都成立$k\ge2$。 

组合前两个估计值会产生相应谐波块对每个被加数的按块支配。 总结$k$证明定理。 

最有可能在审查中失败的引理是比较$$\frac1{2\sqrt{k-1}} < \frac{2k-1}{k^2},$$必须仔细检查。 

## 解决方案

 套装$$d_k=x_k-x_{k-1}\qquad (k=2,\ldots,n).$$自从$x_1,\ldots,x_k$是$k$不同的正整数，$$x_k\ge d_k+k-1.$$的确，$$x_{k-1}\ge k-1,$$因此$$x_k=x_{k-1}+d_k\ge d_k+k-1.$$所以$$\frac{\sqrt{d_k}}{x_k} \le \frac{\sqrt{d_k}}{d_k+k-1}.$$使固定$k$并考虑$$f(d)=\frac{\sqrt d}{d+k-1}, \qquad d>0.$$计算给出$$f'(d) = \frac{k-1-d} {2\sqrt d\,(d+k-1)^2}.$$因此$f'(d)>0$为了$d<k-1$和$f'(d)<0$为了$d>k-1$。 因此$f$达到最大值$d=k-1$， 和$$f(d)\le f(k-1) = \frac{\sqrt{k-1}}{2(k-1)} = \frac1{2\sqrt{k-1}}.$$最后，$$\frac{\sqrt{d_k}}{x_k} \le \frac1{2\sqrt{k-1}}.$$接下来，考虑谐波块$$B_k= \sum_{m=(k-1)^2+1}^{k^2}\frac1m .$$该块包含$$k^2-(k-1)^2=2k-1$$项，并且每个分母至多是$k^2$。 因此$$B_k > \frac{2k-1}{k^2}.$$我们声称$$\frac1{2\sqrt{k-1}} < \frac{2k-1}{k^2} \qquad (k\ge2).$$由于两边都是正数，平方是合法的。 该主张相当于$$4(2k-1)^2(k-1)>k^4.$$扩大，$$4(2k-1)^2(k-1)-k^4 = 15k^4-32k^3+20k^2-4k.$$保理，$$15k^4-32k^3+20k^2-4k = k(k-2)(15k^2-2k+2)+8k.$$为了$k\ge2$右侧第一项是非负数，第二项等于$8k>0$。 因此$$4(2k-1)^2(k-1)-k^4>0,$$这证明了这一说法。 

结合不等式，$$\frac{\sqrt{d_k}}{x_k} < \frac{2k-1}{k^2} < B_k.$$总结$k=2,\ldots,n$产量$$\sum_{k=2}^n \frac{\sqrt{x_k-x_{k-1}}}{x_k} < \sum_{k=2}^n \sum_{m=(k-1)^2+1}^{k^2}\frac1m.$$右边的块是不相交的，并且一起形成整数区间$2$到$n^2$。 所以$$\sum_{k=2}^n \sum_{m=(k-1)^2+1}^{k^2}\frac1m = \sum_{m=2}^{n^2}\frac1m < \sum_{m=1}^{n^2}\frac1m.$$因此$$\frac{\sqrt{x_2-x_1}}{x_2} +\frac{\sqrt{x_3-x_2}}{x_3} +\cdots+ \frac{\sqrt{x_n-x_{n-1}}}{x_n} < 1+\frac12+\frac13+\cdots+\frac1{n^2}.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是估计$$x_k\ge d_k+k-1.$$由于序列由$k-1$之前不同的正整数$x_k$，最小可能值$x_{k-1}$是$k-1$。 代入$$x_k=x_{k-1}+d_k$$给出所需的不等式。 更换$k-1$经过$k$将是不正确的，并且序列已经失败$1,2,\ldots,k$。 

第二个微妙的步骤是最大化$$\frac{\sqrt d}{d+k-1}.$$导数等于$$\frac{k-1-d} {2\sqrt d\,(d+k-1)^2}.$$其符号从正变为负$d=k-1$，因此该点是全局最大值。 仅检查附近的整数值$d$无法证明这一估计的合理性。 

第三步是证明$$\frac1{2\sqrt{k-1}} < \frac{2k-1}{k^2}.$$检查小值，$$k=2:\quad \frac12<\frac34,$$

$$k=3:\quad \frac1{2\sqrt2}<\frac59.$$对于一般$k$，多项式计算准确地显示出正性。 如果没有这种验证，对于某些大型的块比较可能会失败$k$。 

## 替代方法

 获得后$$\frac{\sqrt{d_k}}{x_k} \le \frac{\sqrt{d_k}}{d_k+k-1},$$我们可以通过应用算术几何平均不等式来避免微分：$$d_k+k-1\ge 2\sqrt{d_k(k-1)}.$$这给出了$$\frac{\sqrt{d_k}}{d_k+k-1} \le \frac1{2\sqrt{k-1}}.$$证明的其余部分完全按照上面的调和块进行。 

这个变体更短并且更基本。 主要证明是通过单变量函数的最大化提出的，因为它准确地识别了最坏情况发生的位置，即$d_k=k-1$，并使估计的结构完全透明。
