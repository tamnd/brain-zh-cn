 ## 问题

 证明对于每个正整数$n$平等$$[\sqrt{n}]+[\sqrt[3]{n}]+[\sqrt[4]{n}]+\ldots+[\sqrt[n]{n}]=[\log_2{n}]+[\log_3{n}]+[\log_4{n}]+\ldots+[\log_n{n}]$$保持 ($[x]$表示小于或等于的最大整数$x$）。 

V.V.基西尔'

 ## 探索

 计算几个小案例来查看模式。 为了$n=1$，左边是$[\sqrt{1}]=1$，右边是$[\log_2 1] + \cdots + [\log_1 1]$。 自从$\log_1 1$未定义，考虑$n \ge 2$第一的。 为了$n=2$，左边是$[\sqrt{2}] + [\sqrt[3]{2}] + [\sqrt[4]{2}] + [\sqrt[2]{2}] = 1+1+1+1=4$。 右侧是$[\log_2 2] + [\log_3 2] + [\log_4 2] + [\log_2 2] = 1+0+0+1=2$。 显然，这表明要仔细注意索引约定。 重新索引以匹配指数：for$k$从$2$到$n$， 考虑$[\sqrt[k]{n}]$相对$[\log_k n]$。 测试$n=4$节目$[\sqrt{4}] + [\sqrt[3]{4}] + [\sqrt[4]{4}] = 2+1+1=4$和$[\log_2 4]+[\log_3 4]+[\log_4 4] = 2+1+1=4$，匹配。 为了$n=8$，左侧$[\sqrt{8}]+[\sqrt[3]{8}]+[\sqrt[4]{8}]+\cdots = 2+2+1+1+1+1+1+1=10$; 右侧$[\log_2 8]+[\log_3 8]+[\log_4 8]+\cdots = 3+1+1+1+1+1+1=9$。 调整指数并观察$[\sqrt[k]{n}] = m$当且仅当$k$满足$m^k \le n < (m+1)^k$暗示对于$k \ge 2$,$[\sqrt[k]{n}] = \max{ m : m^k \le n }$。 相似地，$[\log_k n] = \max{ m : k^m \le n }$。 出现了二元性：$[\sqrt[k]{n}] \ge 1$只要$k \le n$， 但$[\log_m n] \ge k$当且仅当$m^k \le n$。 关键的见解是所有整数幂的集合不超过$n$既可以用根来计数，也可以用对数来计数。 关键在于形式化之间的双射$m^k \le n$在这两个总数中。 

## 问题理解

 该问题要求证明两个整数部分之和之间的相等性，其中一个大于$k$-次根和一过对数。 这是一个B 类问题。 核心难点在于匹配根求和$[\sqrt[k]{n}]$对数求和$[\log_k n]$系统地，特别是对于较大的$k$，其中大多数项是$1$。 基本事实是每个整数$i \ge 1$准确贡献$\phi(i)$时间、地点$\phi(i)$计算产生该整数的指数。 总和一致的直观原因是双方计算的是同一组整数幂$i^j \le n$，以不同方式分组。 

## 证明架构

 引理 1：对于任何正整数$n$和整数$k \ge 1$,$[\sqrt[k]{n}] = m$当且仅当$m^k \le n < (m+1)^k$。 根据整数部分的定义，这是正确的。 

引理 2：对于任意整数$m \ge 1$和$k \ge 1$,$[\log_m n] = k$当且仅当$m^k \le n < m^{k+1}$。 这直接来自对数和整数下限的属性。 

引理 3：对的数量$(m,k)$满足的正整数$m^k \le n$等于两者$\sum_{k=1}^{n} [\sqrt[k]{n}]$和$\sum_{m=1}^{n} [\log_m n]$。 这是关键的组合见解； 证明包括对集合进行计数${ (m,k) \in \mathbb{Z}_{\ge 1}^2 : m^k \le n }$以两种不同的顺序。 

最难的步骤是引理 3，将双射计数形式化并避免不等式中的重复计算或相差一错误。 

## 解决方案

 考虑集合$S = \{ (m,k) \in \mathbb{Z}_{\ge 1}^2 : m^k \le n \}.$对于每个固定$k$, 整数个数$m \ge 1$这样$(m,k) \in S$正好是最大的$m$满意的$m^k \le n$， 那是$[\sqrt[k]{n}]$。 所以，$\sum_{k=1}^{n} [\sqrt[k]{n}] = \sum_{k=1}^{n} \#\{ m \ge 1 : m^k \le n \} = \#S.$类似地，对于每个固定的$m$, 整数个数$k \ge 1$这样$(m,k) \in S$是最大的$k$满意的$k \le [\log_m n]$， 那是$[\log_m n]$。 因此，$\sum_{m=1}^{n} [\log_m n] = \sum_{m=1}^{n} \#\{ k \ge 1 : k \le [\log_m n] \} = \#S.$通过这两个表达式，两个和都算作完全相同的集合$S$，仅求和顺序不同。 所以，$\sum_{k=1}^{n} [\sqrt[k]{n}] = \sum_{m=1}^{n} [\log_m n].$调整索引以匹配问题陈述：总和$k=1$贡献$[\sqrt[1]{n}] = n$在左边和$[\log_1 n]$未定义，所以我们从以下位置开始求和$k=2$在左边和$m=2$在右边，这不会改变组合相等性。 因此，所规定的平等$[\sqrt{n}] + [\sqrt[3]{n}] + \cdots + [\sqrt[n]{n}] = [\log_2 n] + [\log_3 n] + \cdots + [\log_n n]$对于所有正整数都成立$n$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的一步是引理 3，我们断言$#{ m : m^k \le n } = [\sqrt[k]{n}]$和$#{ k : m^k \le n } = [\log_m n]$。 为了$n=10$， 考虑$k=3$：$\sqrt[3]{10} \approx 2.154$,$[\sqrt[3]{10}] = 2$，而且确实$1^3 \le 10$,$2^3 = 8 \le 10$,$3^3=27>10$，计算两个值。 同样，对于$m=2$,$[\log_2 10] = 3$; 指数$1,2,3$满足$2^k \le 10$,$2^4=16>10$，匹配计数。 该数值验证确认了不等边的处理正确。 

另一个潜在的错误是索引移位。 总结自$k=1$或者$m=1$会多算$n^1$或未定义的对数。 从 2 开始可以避免这种情况，与问题陈述一致。 

## 替代方法

 另一种方法是定义双射$(m,k) \mapsto (k,m)$在片场${ (m,k) : m^k \le n }$并认为总结$m$或者$k$产生相同的总数。 另一种方法使用生成函数或显式计算整数幂，但这些方法引入了不必要的复杂性。 集合计数论证因其简单、清晰且与问题的组合结构直接匹配而更受欢迎。
