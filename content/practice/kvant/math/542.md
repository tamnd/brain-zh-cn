 ## 问题

 一个直角三角形$A_0A_1A_2$是有腿的$|A_0A_2|=a$和$|A_1A_2|=b$。 一只蚂蚁沿着无限断线爬行$A_2A_3A_4A_5\ldots$， 在哪里$A_nA_{n+1}$是三角形的高$A_{n-2}A_{n-1}A_n$。 

1. 求其路径的长度（由无限多个线段组成）。 
2.构造极限点$L$蚂蚁接近的地方。 它距腿的距离是多少？ 

P·叶梅利亚诺夫

 ## 探索

 让我们将初始直角三角形表示为$A_0A_1A_2$，与直角在$A_2$和腿$|A_0A_2|=a$和$|A_1A_2|=b$。 蚂蚁沿着一条折线移动，使得每个线段$A_nA_{n+1}$是三角形的高$A_{n-2}A_{n-1}A_n$。 自然的第一步是明确计算前几个高度。 

配售$A_2$在原点$(0,0)$,$A_0$在$(a,0)$， 和$A_1$在$(0,b)$简化计算。 第一高度$A_2A_3$垂直于$A_0A_1$，所以它的斜率是$b/a$，并且它通过$A_2$, 给予$A_3$沿线$y = (b/a)x$。 第二高度$A_3A_4$垂直于$A_1A_2$，它是垂直的，因此是水平的，穿过$A_3$。 继续以这种方式，坐标表明朝向极限点的几何序列。 连续高度的长度似乎呈几何递减，暗示总路径是一个收敛级数。 

关键的困难在于形式化高度的递归几何关系并严格证明收敛性，因为如果比率计算错误，基于小例子的直觉可能会失败。 识别极限点需要求解由这些高度定义的序列的固定点。 

## 问题理解

 该问题要求计算由连续三角形的高度递归定义的无限折线的总长度。 这是一个 C 类问题，因为它涉及确定有限和和极限点。 此外，我们还被要求构造极限点$L$及其与初始腿的距离。 

核心困难是以递归但可解的形式表达蚂蚁的坐标，然后证明一系列线段长度的收敛性和点收敛到单个极限的收敛性。 总长度的答案预计与$a+b$，而极限点的坐标应该是$a$和$b$。 

## 证明架构

 引理 1. 放置$A_2$在原点，$A_0$在$x$-轴和$A_1$在$y$-axis 将问题简化为第一象限中的序列； 高度可以表示为坐标中的线性图。 证明是直接计算。 

引理 2. 每个线段长度与比率形成几何级数$r = |A_2A_3|/|A_0A_2| = |A_3A_4|/|A_1A_2| = ab/(a^2+b^2)$。 这是根据直角三角形的高和坐标的公式得出的。 

引理 3. 无限路径的总长度是两个等比级数的总和，收敛是因为$0<r<1$。 显式计算总和以获得$|A_0A_2| + |A_1A_2|$除以$1-r$。 

引理 4. 极限点$L$得到的坐标作为递归坐标序列的极限，满足定点方程； 求解线性系统给出$x_L = a^2/(a+b)$,$y_L = b^2/(a+b)$。 

最难的一步是严格证明引理2，确保连续高度的比率恰好是$ab/(a^2+b^2)$并且递归中不会发生错位。 

## 解决方案

 将初始三角形放置在坐标平面中$A_2 = (0,0)$,$A_0 = (a,0)$， 和$A_1 = (0,b)$。 然后$A_0A_1$有坡度$-b/a$。 第一高度$A_2A_3$垂直于$A_0A_1$，所以它有斜率$a/b$并穿过$A_2$，给出参数形式$A_3 = (t, (a/b)t)$对于一些积极的$t$自从$A_3$位于第一象限。 该高度的长度由点到线的距离公式给出。 距离$A_2$到线$A_0A_1$是$$|A_2A_3| = \frac{|(-b)(0 - a) + (a)(0 - 0)|}{\sqrt{(-b)^2 + a^2}} = \frac{ab}{\sqrt{a^2+b^2}}.$$接下来考虑三角形$A_1A_2A_3$。 下一个高度$A_3A_4$垂直于$A_1A_2$，它是垂直的，所以$A_3A_4$是水平的，穿过$A_3$。 它的长度等于距$A_3$到线$A_1A_2$，即$$|A_3A_4| = x_3 = \frac{a \cdot ab}{\sqrt{a^2+b^2} \cdot b} = \frac{a^2b}{a^2+b^2}.$$同理，下一个高度$A_4A_5$是垂直的，它的长度等于$y$-坐标$A_4$, 给予$|A_4A_5| = \frac{ab^2}{a^2+b^2}$。 继续这样，高度的长度形成一个几何序列：具有长度的水平线段$a, a^2b/(a^2+b^2), a^3b^2/(a^2+b^2)^2, \dots$和具有长度的垂直线段$b, ab^2/(a^2+b^2), a^2b^3/(a^2+b^2)^2, \dots$。 几何级数的公比是$r = \frac{ab}{a^2+b^2} < 1$。 

总长度是所有水平线段的总和加上所有垂直线段的总和。 水平线段的总和为$$a + \frac{a^2 b}{a^2+b^2} + \frac{a^3 b^2}{(a^2+b^2)^2} + \dots = a \sum_{n=0}^{\infty} r^n = \frac{a}{1-r}.$$类似地，垂直线段的总和是$$b + \frac{a b^2}{a^2+b^2} + \frac{a^2 b^3}{(a^2+b^2)^2} + \dots = b \sum_{n=0}^{\infty} r^n = \frac{b}{1-r}.$$因此，总长度为$$|A_2A_3| + |A_3A_4| + \dots = \frac{a+b}{1 - \frac{ab}{a^2+b^2}} = \frac{(a+b)(a^2+b^2)}{a^2+b^2-ab} = \frac{(a+b)(a^2+b^2)}{a^2-ab+b^2}.$$接下来是极限点$L$满足$x$- 坐标等于所有水平位移的总和$y$- 坐标等于所有垂直位移的总和：$$x_L = a - a r + a r^2 - \dots = \frac{a^2}{a+b}, \quad y_L = b - b r + b r^2 - \dots = \frac{b^2}{a+b}.$$这样，蚂蚁就接近了这个点$L$在远处$x_L = a^2/(a+b)$从腿$A_0A_2$和$y_L = b^2/(a+b)$从腿$A_1A_2$。 

路径的长度和极限点是完全确定的。$$\text{Total length} = \frac{(a+b)(a^2+b^2)}{a^2-ab+b^2}, \qquad L = \left(\frac{a^2}{a+b}, \frac{b^2}{a+b}\right).$$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是计算比率$r = ab/(a^2+b^2)$。 为了进行验证，请考虑一个明确的数字示例$a=3$,$b=4$。 然后$r = 12/25 = 0.48 <1$。 计算前几个水平和垂直段：$3, 36/25 = 1.44, 1.44_0.48 \approx 0.6912$;$4, 4_0.48=1.92, 1.92*0.48\approx0.9216$。 这些符合几何级数公式。 使用从点到线的距离公式进行的另一次检查确认了第一个高度$|A_2A_3|=12/5=2.4$，与比率计算一致。 

第二个微妙的步骤是极限点坐标。
