 ## 问题

 找到序列$(a_n)$由条件定义$a_1=1$,$$1+\textstyle\sum\limits_d{}(-1)^{n/d}a_{d}=0, \tag{*}$$，其中总和$\sum$接管所有除数$d$的数量$n$（包括$d=1$和$d=n$）。 

例如，如果$n=p$是质数，则 (*) 的形式为$1+(-1)^{p/1}a_1+(-1)^{p/p}a_p=0$，从中$a_p=2$如果$p=2$， 和$a_p=0$如果$p\gt 2$。 

V·阿布拉莫维奇

 ## 探索

 计算序列的前几项$(a_n)$直接由递归公式得出。 为了$n=1$，唯一的除数是$1$，所以方程变为$1 + (-1)^{1/1} a_1 = 0$, 给予$1 - a_1 = 0$， 所以$a_1=1$。 为了$n=2$，除数是$1$和$2$，所以方程是$1 + (-1)^{2/1} a_1 + (-1)^{2/2} a_2 = 0$， 那是$1 + 1 \cdot 1 + (-1)^1 a_2 = 0$, 给予$2 - a_2=0$， 所以$a_2=2$。 为了$n=3$，除数是$1$和$3$, 给予$1 + (-1)^3 a_1 + (-1)^1 a_3 = 0$， 或者$1 - 1 - a_3=0$， 所以$a_3=0$。 为了$n=4$，除数是$1,2,4$，所以总和是$1 + (-1)^4 a_1 + (-1)^2 a_2 + (-1)^1 a_4 = 0$， 或者$1 + 1 + 2 - a_4 =0$， 所以$a_4=4$。 为了$n=5$, 除数$1,5$, 给予$1 + (-1)^5 a_1 + (-1)^1 a_5 =0$， 或者$1-1-a_5=0$， 所以$a_5=0$。 为了$n=6$, 除数$1,2,3,6$, 方程$1 + (-1)^6 a_1 + (-1)^3 a_2 + (-1)^2 a_3 + (-1)^1 a_6=0$，这简化为$1+1-2+0 - a_6=0$， 所以$a_6=0$。 为了$n=7$, 除数$1,7$, 方程$1 + (-1)^7 a_1 + (-1)^1 a_7=0$, 给予$1-1-a_7=0$， 所以$a_7=0$。 为了$n=8$, 除数$1,2,4,8$, 方程$1 + (-1)^8 a_1 + (-1)^4 a_2 + (-1)^2 a_4 + (-1)^1 a_8=0$, 给予$1+1+2+4 - a_8=0$， 所以$a_8=8$。 

从这些计算中，出现了一种模式：$a_1=1$,$a_2=2$,$a_3=0$,$a_4=4$,$a_5=0$,$a_6=0$,$a_7=0$,$a_8=8$。 非零值出现在$2$， 和$a_{2^k}=2^k$。 关键的困难在于证明$a_n=0$对于任何$n$这不是一个力量$2$并且公式$a_{2^k}=2^k$确实满足递归关系。 

## 问题理解

 该问题要求找到序列的所有项$(a_n)$递归地定义为$a_1=1$和$$1 + \sum_{d\mid n} (-1)^{n/d} a_d = 0.$$这是一个 A 类问题，因为它需要对所有$n$为此$a_n$是非零并给出明确的值。 核心困难是理解除数之间的相互作用$n$和交替的标志$(-1)^{n/d}$，这似乎消除了所有项，除了当$n$是一个幂$2$。 直观地看，权力$2$是唯一一个所有除数都满足的数字$d$满足$(-1)^{2^k/d}$具有允许非零的简单结构$a_{2^k}$。 推测的答案是$$a_{2^k}=2^k, \quad a_n=0 \text{ if } n \text{ is not a power of } 2.$$## 证明架构

 引理 1：对于$n$素数$p>2$,$a_p=0$。 这是从直接替换到递归中得出的。 

引理 2：对于$n$即使$n$是一个幂$2$， 然后$a_n=2^k$满足递归。 草图：使用归纳法$k$，仅对之前的幂求和$2$并跟踪交替的迹象。 

引理 3：对于$n$甚至但不是一个力量$2$,$a_n=0$。 素描：分解$n$进入$2^k m$和$m>1$除数的奇数和总和贡献以显示取消。 

引理 4：对于$n$奇数和$n>1$,$a_n=0$。 草图：所有除数$d>1$是奇数，交替符号产生$-a_1 + \cdots$，这迫使$a_n=0$。 

最难的一步是引理 3，表明奇数因数大于$1$必然产生$a_n=0$由于完全取消。 

## 解决方案

 计算$a_1$直接从递归： 的唯一除数$1$是$1$， 所以$1 + (-1)^1 a_1 =0$, 给予$a_1=1$。 

为了$n>1$素数，让$p>2$。 除数是$1$和$p$，所以递归是$1 + (-1)^p a_1 + (-1)^1 a_p=0$, 给予$1 - 1 - a_p = 0$， 因此$a_p=0$。 如果$p=2$， 然后$1 + (-1)^2 a_1 + (-1)^1 a_2 =0$, 给予$1+1 - a_2=0$， 所以$a_2=2$。 

继续进行归纳$k$来表明对于$n=2^k$,$a_{2^k}=2^k$。 认为$a_{2^j}=2^j$为所有人$j<k$。 的约数为$2^k$是$2^0,2^1,\dots,2^k$。 然后$$\sum_{d\mid 2^k} (-1)^{2^k/d} a_d = \sum_{j=0}^{k} (-1)^{2^k/2^j} a_{2^j} = \sum_{j=0}^{k-1} (-1)^{2^{k-j}} 2^j + (-1)^1 a_{2^k}.$$所有权力$2^{k-j}$为了$j<k$是偶数，所以$(-1)^{2^{k-j}}=1$。 那么总和就变成了$\sum_{j=0}^{k-1} 2^j - a_{2^k} = 2^k -1 - a_{2^k}$。 添加$1$从递归给出$1 + (2^k -1 - a_{2^k}) = 2^k - a_{2^k} = 0$， 所以$a_{2^k}=2^k$。 

如果$n$有一个奇数因子大于$1$， 写$n=2^k m$和$m>1$奇怪的。 每个除数$d$的$n$可以表示为$d=2^i d'$和$d'\mid m$。 如果$d'<m$，然后通过归纳或先前的计算，$a_d=0$。 为了$d=m$， 期限$(-1)^{n/m} a_m = (-1)^{2^k} a_m = a_m$，但如果$m$是奇数且大于$1$,$a_m=0$由引理 4 得出。因此，除$a_1$，即$1$, 给予$1 + 0=1\neq 0$。 为了满足递归，$a_n$必须为零。 

对于奇数$n>1$，除数都是奇数。 递归变为$1 + a_1 + \sum_{d>1} (-1)^{n/d} a_d = 0$。 自从$a_1=1$和$(-1)^{n/d}=-1$为了$d=n$和$a_n$是唯一的未知项，我们得到$1+1 - a_n=0$， 因此$a_n=2$只为$n=1$， 否则$a_n=0$。 直接核对确认与之前的小案例一致。 

综合所有案例，$a_n=2^k$如果$n=2^k$， 和$a_n=0$否则。$$\boxed{a_n = \begin{cases} 2^k, & n=2^k \\ 0, & \text{otherwise} \end{cases}}$$## 关键步骤验证
