 ## 问题

 二次三项式$f(x) = ax^{2} + bx + c$使得方程$f(x) = x$没有真正的根源。 证明方程$f(f(x)) = x$也没有真正的根源。 

于。 I. 爱奥宁

 全联盟中学生数学奥林匹克竞赛（七年级，十年级）

 ## 探索

 让$f(x)=ax^{2}+bx+c$并假设方程$f(x)=x$没有真正的根源。 这相当于二次$g(x)=f(x)-x=ax^{2}+(b-1)x+c$没有真正的零，因此具有恒定的符号$\mathbb{R}$。 自从$g$是连续且不为零的$g(x)>0$为所有人$x$或者$g(x)<0$为所有人$x$。 

等式$f(f(x))=x$可以使用重写$g$作为$f(f(x)) - x = \bigl(f(f(x)) - f(x)\bigr) + \bigl(f(x)-x\bigr) = g(f(x)) + g(x).$关键是$g(x)$为所有实数保留一个固定的符号，所以两者$g(x)$和$g(f(x))$inherit that same sign. 因此它们的总和不会消失。 

这表明组合不能引入符号变化，因此不会出现不动点或 2 周期。 

唯一的微妙之处是确保替换$f(x)$进入$g$正确保留符号参数而不假设单调性$f$。 

## 问题理解

 这是一个B 类问题。 必须证明，如果二次$f(x)$没有实数不动点，则第二个迭代方程$f(f(x))=x$也没有真正的解决方案。 

核心难点是条件只涉及$f(x)-x$，而结论涉及一个组合$f(f(x))$，原则上可以创建与固定点无关的新的实际解决方案$f$。 

正确的期望是$f(x)-x$是全局固定的，并且这种刚性通过组合传播，因此$f(f(x))-x$无法消失。 

## 证明架构

 首先证明二次方程$g(x)=f(x)-x$持续登录$\mathbb{R}$。 

二、重写$f(f(x))-x$作为$g(f(x))+g(x)$。 

第三，表明$g(f(x))$也有相同的常数符号$g(x)$对于所有真实的$x$。 

第四，得出结论$f(f(x))-x$处处严格为正或处处严格为负，因此没有实零。 

最微妙的一步是分解$f(f(x))-x=g(f(x))+g(x)$以及两个被加数共享一个独立于固定符号的理由$x$。 

## 解决方案

 让$f(x)=ax^{2}+bx+c$并定义$g(x)=f(x)-x=ax^{2}+(b-1)x+c.$假设方程$f(x)=x$没有实根意味着二次方程$g(x)=0$没有真正的解决方案。 自从$g$是一个连续的二次多项式并且永远不会消失$\mathbb{R}$，因此它具有持续登录$\mathbb{R}$，意思是$g(x)>0 \quad \text{for all } x\in\mathbb{R},$或者$g(x)<0 \quad \text{for all } x\in\mathbb{R}.$考虑表达式$f(f(x))-x$。 使用$g(x)=f(x)-x$，我们重写$f(f(x)) - x = f(f(x)) - f(x) + f(x) - x = g(f(x)) + g(x).$自从$g(t)$每个实数都有恒定的符号$t$，值$g(f(x))$每个实数也有相同的符号$x$， 因为$f(x)$对于每个实数都是实数$x$因此位于以下域中$g$有固定标志。 

如果$g(x)>0$对于所有真实的$x$，那么两者$g(f(x))>0$和$g(x)>0$对于所有真实的$x$， 因此$f(f(x)) - x = g(f(x)) + g(x) > 0 \quad \text{for all } x\in\mathbb{R}.$如果$g(x)<0$对于所有真实的$x$，那么两者$g(f(x))<0$和$g(x)<0$对于所有真实的$x$， 因此$f(f(x)) - x = g(f(x)) + g(x) < 0 \quad \text{for all } x\in\mathbb{R}.$在这两种情况下，表达式$f(f(x)) - x$永远不会消失$\mathbb{R}$，所以方程$f(f(x))=x$没有真正的解决方案。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 中心分解$f(f(x)) - x = g(f(x)) + g(x)$直接从加法和减法得出$f(x)$，并且没有使用额外的假设。 

关键的属性是$g(x)$没有真正的零意味着到处都是严格的积极性或严格的消极性。 这是根据多项式的连续性得出的：如果$g$改变符号，中间值定理将迫使实数根。 

第二个微妙点是$g(f(x))$保留相同的符号。 这是成立的，因为符号条件在 的余域中是全局的$f$， 和$f(x)\in\mathbb{R}$对于所有真实的$x$，因此替换不会引入新值，其中$g$可能会有不同的行为。 

## 替代方法

 一种替代方法使用动态系统语言：因为$f(x)-x$具有常数符号，每次迭代$f$相对于直线严格沿一个方向移动所有实点$y=x$，防止任何有限周期的周期点。 然后将这种单调位移形式化以排除$f^{2}(x)=x$。 

另一种方法是分析抛物线​​的几何形状$y=f(x)$相对于线$y=x$，表明它完全位于上方或下方，然后通过几何不等式研究迭代的交集，尽管这需要比上面使用的直接符号分解更仔细的控制。
