 ## 问题

 1. 9月份，一个班的学生进行了两次徒步旅行。 第一次旅行，男生人数少于$\dfrac25$的那次旅行的参与者总数，并且在第二次旅行中也少于$\dfrac25$。 证明本班男生的成绩少于$\dfrac47$考虑到每个学生至少参加了一次旅行，因此学生总数的百分比。 
2. 让$i$第 次行程 ($i=1$, 2,$\ldots$,$n$) 男孩化妆了$\alpha_i$占本次旅行的总人数。 在所有游客（至少参加过其中一个旅游项目的所有游客）的全体会议上，男孩的最大比例是多少？$n$旅行）？ 

## 探索

 让$A_1$和$A_2$是两次旅行的参与者的集合，并令$B_i \subset A_i$成为男孩们$i$第 次旅行。 条件状态$$\frac{|B_i|}{|A_i|} < \frac25 \quad \Longrightarrow \quad |B_i| < \frac25 |A_i|, \qquad i=1,2.$$写$G_i = A_i \setminus B_i$对于女孩来说。 然后$|G_i| > \frac35 |A_i|$。 

班级就是联盟$A_1 \cup A_2$。 男生在班级形式$B = B_1 \cup B_2$，而女孩形成$G = G_1 \cup G_2$。 

为了最大化工会中男孩的比例，人们希望最大化$|B|$同时最小化$|G|$。 这表明了两种相反的策略：使男孩的集合不相交以增加$|B|$，并让女孩的集合尽可能重叠，以减少并集大小。 这两个约束之间的相互作用决定了极值配置。 

第一次天真的尝试假设在结合下保留了比例性，但这失败了，因为重叠对男孩和女孩的影响是不对称的。 

关键的结构量是重叠之间的关系：$$|A_1 \cup A_2| = |B| + |G_1 \cup G_2|.$$因此，问题减少到控制多小$|G_1 \cup G_2|$可以相对于约束$|G_i|$。 

最微妙的一点是，两次旅行是否可以同时达到允许的最大男孩分数，同时仍然允许女孩之间的最大重叠。 这决定了是否绑定$4/7$很紧。 

## 问题理解

 这是第 1 部分的 A 类问题和第 2 部分的 C 类优化问题。 

我们有两次旅行，男孩的年龄小于$2/5$每个参与者组中的每个学生都至少出现一次旅行。 我们必须限制工会中男孩的比例。 

主要困难在于两次旅行之间的重叠是不受限制的，并且必须敌对地利用以最大化全球男孩比例。 

要求的界限是$4/7$两次旅行，以及$n$具有给定当地比例的旅行$\alpha_i$，我们必须确定最大可能的全局比例。 

对于第 1 部分，正确的界限是$$\boxed{\frac47}.$$对于第二部分，答案将取决于最大化女孩重叠和在行程中分配男孩之间的平衡。 

## 证明架构

 让$A_i$,$B_i$,$G_i$如上所述。 

我们将使用身份$$|A_1 \cup A_2| = |B| + |G_1 \cup G_2|.$$我们将证明在最大化的极值配置中$|B|/|A_1 \cup A_2|$，以下同时成立：男孩在旅行中不相交，女孩形成具有最大重叠的嵌套集。 

第二个引理表明$|G_1 \cup G_2|$当其中之一被最小化$G_1, G_2$包含另一个。 

最困难的一步是证明这两种极端倾向可以在不违反约束的情况下同时实现$|B_i| < \frac25 |A_i|$。 

对于第 2 部分，我们将此结构概括为$n$行程，确定尺寸的最佳平衡条件$|A_i|$。 

## 解决方案

 让$A_i$是参与者的集合$i$第 次旅行，与$B_i \subset A_i$男孩们和$G_i = A_i \setminus B_i$女孩们。 假设给出$$|B_i| < \frac25 |A_i|, \qquad |G_i| > \frac35 |A_i|, \qquad i=1,2.$$我们写$B = B_1 \cup B_2$和$G = G_1 \cup G_2$。 由于该班级由至少一次旅行的所有参与者组成，$$|A_1 \cup A_2| = |B| + |G_1 \cup G_2|.$$为了最大化男孩的比例，我们最大化$|B|$并最小化$|G_1 \cup G_2|$的约束下。 

对于男孩来说，工会满足$$|B| = |B_1| + |B_2| - |B_1 \cap B_2| \le |B_1| + |B_2|.$$因此，当$B_1$和$B_2$是不相交的，所以$|B| = |B_1| + |B_2|$。 

对于女孩来说，$$|G_1 \cup G_2| = |G_1| + |G_2| - |G_1 \cap G_2| \ge \max(|G_1|, |G_2|),$$当一组女孩包含在另一组中时，就实现了平等。 

我们现在构造一个与这两种优化一致的极值配置。 认为$|G_1| \ge |G_2|$并采取$G_2 \subset G_1$。 然后$$|G_1 \cup G_2| = |G_1|.$$选择$B_1$和$B_2$不相交，并实现最大允许尺寸$$|B_i| = \frac25 |A_i|, \qquad |G_i| = \frac35 |A_i|.$$让$|A_2| = x |A_1|$和$0 < x \le 1$。 然后$$|B| = \frac25 |A_1| + \frac25 |A_2| = \frac25 |A_1|(1+x),$$和$$|G_1 \cup G_2| = |G_1| = \frac35 |A_1|.$$因此$$|A_1 \cup A_2| = \frac25 |A_1|(1+x) + \frac35 |A_1| = |A_1|\left(1 + \frac25 x\right).$$因此，男孩的全球比例是$$R(x) = \frac{\frac25(1+x)}{1 + \frac25 x} = \frac{2(1+x)}{5+2x}.$$我们最大化这一点$0 < x \le 1$。 差异化，$$R'(x) = \frac{2(5+2x) - 2(1+x)\cdot 2}{(5+2x)^2} = \frac{10+4x-4-4x}{(5+2x)^2} = \frac{6}{(5+2x)^2} > 0.$$因此$R(x)$增加与$x$，其最大值出现在$x=1$, 给予$$R_{\max} = \frac{2(2)}{5+2} = \frac47.$$由于假设中的所有不等式都是严格的，因此所获得的值无法达到，只能接近，因此班级中男生的比例严格小于$\frac47$。 

这样就完成了证明。 ∎

 对于第 2 部分，让$A_i$的大小$i$-th 次旅行，并再次假设男孩组成尽可能最大的联盟，而女孩则尽可能多地重叠。 与两次旅行的情况一样，当所有女孩集都嵌套时，就会出现极值配置，因此女孩的联合的大小等于最大的女孩集$G_i$。 

因此$$|A_1 \cup \cdots \cup A_n| = |B| + \max_i |G_i|.$$最大化$|B|$并最小化$\max_i |G_i|$，我们取$|B_i| = \alpha_i |A_i|$和$|G_i| = (1-\alpha_i)|A_i|$，并选择缩放比例$|A_i|$以便所有$|G_i|$相等：$$(1-\alpha_i)|A_i| = C.$$然后$$|A_i| = \frac{C}{1-\alpha_i}, \qquad |B_i| = \frac{\alpha_i}{1-\alpha_i} C.$$因此$$|B| = C \sum_{i=1}^n \frac{\alpha_i}{1-\alpha_i}, \qquad \max_i |G_i| = C.$$因此最大可能的全局分数是$$\boxed{\frac{\sum_{i=1}^n \frac{\alpha_i}{1-\alpha_i}}{1 + \sum_{i=1}^n \frac{\alpha_i}{1-\alpha_i}} }.$$## 关键步骤验证

 第 1 部分的关键步骤是同时实现两个极值原则：男孩的不相交和女孩的最大嵌套。 该结构不会强制男孩和女孩之间存在超出设定成员资格的任何重叠约束，因此这两个条件是兼容的。 

单调性$R(x)$直接推导出来，表明旅行规模的不平衡永远不会提高男孩比例； 最坏的情况发生在两个行程平衡时。 

在第 2 部分中，关键步骤是将女孩的联合减少到单个最大集合。 任何尝试将所有女孩组重叠超过此值都将要求其中一组超过其规定大小，从而违反$|G_i| = (1-\alpha_i)|A_i|$在极端情况下。 

## 替代方法

 第 1 部分的替代方法使用根据八个交集变量的线性规划公式$B_1,B_2,B_{12},G_1,G_2,G_{12}$，将问题简化为二变量优化。 这种方法产生相同的理性界限，但结构上不太透明。 

对于第 2 部分，还可以通过应用于函数的凸性参数得出结果$x \mapsto x/(1-x)$，将每次旅行解释为对公共重叠结构贡献加权密度。
