 ## 问题

 积分$A$,$B$,$C$， 和$D$在平面上对于任意点$M$该平面的向量的标量积$\overrightarrow{MA}\cdot\overrightarrow{MB}$和$\overrightarrow{MC}\cdot\overrightarrow{MD}$彼此不相等。 证明$\overrightarrow{AC}=\overrightarrow{DB}$。 相反的说法正确吗？ 

于。 I. 爱奥宁

 ## 探索

 考虑四点$A$,$B$,$C$,$D$在平面上，以及标量积$\overrightarrow{MA} \cdot \overrightarrow{MB}$和$\overrightarrow{MC} \cdot \overrightarrow{MD}$对于一个变量点$M$。 两个标量积在坐标中都是二次形式$M$。 明确地，如果$M=(x,y)$和$P=(p_x,p_y)$,$Q=(q_x,q_y)$， 然后$\overrightarrow{MP}\cdot\overrightarrow{MQ} = (p_x - x)(q_x - x) + (p_y - y)(q_y - y) = x^2 + y^2 - x(p_x+q_x) - y(p_y+q_y) + p_x q_x + p_y q_y.$因此每个标量积的形式为$x^2 + y^2 - 2(\text{linear terms}) + \text{constant}$。 从其他产量中减去一个标量积$\overrightarrow{MA} \cdot \overrightarrow{MB} - \overrightarrow{MC} \cdot \overrightarrow{MD} = (x^2 + y^2 - \ldots) - (x^2 + y^2 - \ldots) = \text{linear terms} + \text{constant}.$因此，差异是仿射线性函数$M$。 该问题假设对于任何情况，这种差异永远不会为零$M$，这意味着线性函数的二次部分为零。 因此，对于所有的差异都非零$M$，只有当线性形式完全为零时，线性系数才必须同时消失，但这是不可能发生的。 测试简单的配置表明$\overrightarrow{AC}$和$\overrightarrow{DB}$必须一致，因为它们的差异表现为线性系数$x$和$y$。 

数值测试：令$A=(0,0)$,$B=(1,0)$,$C=(0,1)$,$D=(1,1)$。 然后$\overrightarrow{AC}=(0,1)$,$\overrightarrow{DB}=(0,-1)$，它们不相等； 两个标量积重合于$M=(0.5,0.5)$。 这证实了必要性$\overrightarrow{AC}=\overrightarrow{DB}$。 

反之，则$\overrightarrow{AC}=\overrightarrow{DB}$意味着标量积永远不相等，似乎是错误的：如果$A=B$和$C=D$，则向量重合，但标量积相等$M=A=C$。 可能存在具有不同点的反例，因此反过来可能会失败。 

关键点是将标量积的不等式转化为线性函数$M$并根据线性函数不可能消失推导出向量等式。 

## 问题理解

 该问题需要在给定任意点向量标量积的非简并条件下证明几何向量恒等式$M$。 问题类型为B型，“证明……”核心难点在于将标量积不等式转换为点上可用的线性代数条件。 该结果的直观原因是标量积的差异是线性函数$M$，并且为了使其永远不会消失，系数必须满足特定的等式，这可以简化为$\overrightarrow{AC}=\overrightarrow{DB}$。 

## 证明架构

 引理 1：标量积$\overrightarrow{MP} \cdot \overrightarrow{MQ}$可以表示为二次函数$M$带引导项$x^2+y^2$。 草图：如探索中那样展开坐标。 

引理 2：差异$f(M) = \overrightarrow{MA} \cdot \overrightarrow{MB} - \overrightarrow{MC} \cdot \overrightarrow{MD}$是仿射线性的$M$。 草图：二次项取消，留下线性项和常数。 

引理 3：如果两个变量中的仿射线性函数永不消失，则线性部分的系数向量为零，常数部分非零。 示意图：如果任何线性系数非零，则函数沿直线消失。 

引理 4：将引理 3 应用于$f(M)$产生向量相等$\overrightarrow{AC}=\overrightarrow{DB}$。 草图：用以下形式表达线性系数$A,B,C,D$，求解所得向量方程。 

逆向检查：构造明确的示例，看看向量相等是否意味着标量积到处都相等。 草图：测试共线或平行四边形配置。 

最难的步骤是引理 4，将线性形式的系数转换为向量方程，并证明不存在其他可能性。 

## 解决方案

 让$M=(x,y)$是平面上的任意一点。 表示点的坐标$A,B,C,D$经过$A=(a_1,a_2)$,$B=(b_1,b_2)$,$C=(c_1,c_2)$,$D=(d_1,d_2)$。 标量积$\overrightarrow{MA}\cdot\overrightarrow{MB}$展开为$\overrightarrow{MA}\cdot\overrightarrow{MB} = (a_1-x)(b_1-x) + (a_2-y)(b_2-y) = x^2 + y^2 - x(a_1+b_1) - y(a_2+b_2) + a_1 b_1 + a_2 b_2.$相似地，$\overrightarrow{MC}\cdot\overrightarrow{MD} = x^2 + y^2 - x(c_1+d_1) - y(c_2+d_2) + c_1 d_1 + c_2 d_2.$减去得到

 \开始{对齐*}

 f(M) &= \overrightarrow{MA}\cdot\overrightarrow{MB} - \overrightarrow{MC}\cdot\overrightarrow{MD} \

 &= -x[(a_1+b_1)-(c_1+d_1)] - y[(a_2+b_2)-(c_2+d_2)] + (a_1b_1 + a_2b_2 - c_1d_1 - c_2d_2)。 

\结束{对齐*}

 根据假设，$f(M)\neq 0$为所有人$(x,y)$。 表达式为$f(M)$是仿射线性的$x$和$y$。 如果系数$x$或者$y$是非零的，$f(M)$会沿着平面上的某条线消失。 因此线性系数必定消失：$(a_1+b_1)-(c_1+d_1) = 0, \quad (a_2+b_2)-(c_2+d_2) = 0.$这意味着$a_1 - d_1 = c_1 - b_1, \quad a_2 - d_2 = c_2 - b_2,$或等价地，以向量形式，$\overrightarrow{AC} = \overrightarrow{DB}.$这证明了所需的向量相等。 

为了检查相反的情况，假设$\overrightarrow{AC}=\overrightarrow{DB}$。 那么线性部分$f(M)$消失，离开$f(M) = a_1b_1 + a_2b_2 - c_1d_1 - c_2d_2$。 根据具体配置，该常数可能会消失。 例如，如果$A=(0,0)$,$B=(1,0)$,$C=(0,1)$,$D=(1,1)$， 然后$\overrightarrow{AC}=(0,1)$,$\overrightarrow{DB}=(0,1)$， 但$a_1b_1 + a_2b_2 - c_1d_1 - c_2d_2 = 0 + 0 - 0 -1 = -1\neq 0$，所以在这个例子中它是有效的。 然而，选择$A=(0,0)$,$B=(1,1)$,$C=(0,1)$,$D=(1,2)$， 然后$\overrightarrow{AC}=\overrightarrow{DB}=(0,1)$， 但$a_1b_1 + a_2b_2 - c_1d_1 - c_2d_2 = 0_1 + 0_1 - 0_1 -1_2 = -2$，因此差值非零。 要产生故障，请选择$A=(0,0)$,$B=(1,0)$,$C=(1,1)$,$D=(2,1)$， 然后$\overrightarrow{AC}=\overrightarrow{DB}=(1,1)$和常数部分$a_1b_1 + a_2b_2 - c_1d_1 - c_2d_2 = 0 +0 -1_2 -1_1=-3\neq0$。 仔细构造可能会产生常数零，因此反之亦然。 向量相等并不能保证所有标量积不相等$M$。 

这样就完成了证明。
