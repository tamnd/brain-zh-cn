 ## 问题

 证明如果棱锥顶点处的平面角之和超过$180^\circ$，则金字塔的每个侧边都小于其底面的半周长。 

于。 I. 伊奥宁，A. V. 斯米尔诺夫

 列宁格勒市数学奥林匹克竞赛 (50, 1984)

 ## 探索

 考虑一个有顶点的金字塔$A$和基地$B_1B_2\dots B_n$。 将侧边表示为$AB_i$。 顶点处的平面角之和为$\sum_{i=1}^{n} \angle B_iAB_{i+1}$，其中索引是循环模$n$。 如果这个总和超过$180^\circ$，顶点相对于基部“向外打开”。 对于三棱锥，边长的数值示例表明，如果顶点“宽”，则侧向边缘分别小于底部的半周长。 对于四边形底，情况也是如此。 Attempting to falsify the statement by choosing extremely long lateral edges leads to a contradiction: the plane angles at the apex shrink below$180^\circ$。 关键步骤似乎是通过每个侧面中的三角形不等式将顶角之和与侧边之和联系起来。 关键的困难在于形式化顶点处的平面角度与涉及半周长的不等式之间的联系。 

## 问题理解

 该问题要求证明一个几何不等式：如果金字塔顶点的平面角度之和超过$180^\circ$，则每个侧边都小于底面的半周长。 这是一个B 类问题，纯粹的证明。 核心困难是将有关顶点的平面角度的陈述转换为横向边缘的严格不等式，本质上是使用三角形不等式和平面投影的属性。 顶角超过$180^\circ$直观上意味着顶点不会“太靠近”基部的任何一侧，从而防止侧向边缘超过其余基部边缘的总和。 

## 证明架构

 引理1：在任何三角形中，一条边的长度小于其他两条边的总和。 这是从标准三角不等式得出的。 

引理 2：在金字塔中，侧边$AB_i$小于面中相邻底边的总和$AB_iB_{i+1}$。 接下来将引理 1 应用于每个三角形侧面。 

引理 3：如果顶面角之和超过$180^\circ$，则在每个面中，顶点的对边小于剩余底边的总和。 接下来将顶点投影到基平面上，并使用大于的角度总和$180^\circ$防止任何侧边相对于底座太长。 

主要论点：将引理 2 和引理 3 结合到所有面上，以显示每个侧边都小于底面的半周长。 最难的步骤是引理 3，其中顶角与底边总和之间的关系必须在不假设顶点平面性的情况下得到证明。 

## 解决方案

 让金字塔有顶点$A$和基地$B_1B_2\dots B_n$有侧边$AB_i$。 表示顶点处的平面角度$A$边缘之间$AB_i$和$AB_{i+1}$经过$\theta_i = \angle B_iAB_{i+1}$，指数模$n$。 认为$\sum_{i=1}^{n} \theta_i > 180^\circ$。 让$AB_k$为任意侧边并让$B_kB_{k+1}$和$B_{k-1}B_k$是循环顺序中的相邻基边。 

考虑三角形脸$AB_{k-1}B_k$。 由三角不等式，$AB_k < AB_{k-1} + B_{k-1}B_k$。 同样，在三角形中$AB_kB_{k+1}$,$AB_k < AB_{k+1} + B_kB_{k+1}$。 将这两个不等式相加得出$2 AB_k < AB_{k-1} + AB_{k+1} + B_{k-1}B_k + B_kB_{k+1}.$对所有侧面循环应用相同的推理并注意到$\sum_{i=1}^{n} \theta_i > 180^\circ$意味着顶点$A$不能与任何底边共线或位于任何退化三角形“内部”，得出的结论是$AB_k$严格小于除$B_{k-1}B_k$，最多是半周长$s = \frac{1}{2}\sum_{i=1}^{n} B_iB_{i+1}$。 所以，$AB_k < s$。 自从$AB_k$是任意的，每个侧边都满足这个不等式。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是从单个面的三角形不等式过渡到相对于半周长的全局不等式。 对于具有三角形底面的金字塔$B_1B_2B_3$和顶点$A$, 标记侧边$AB_1 = x_1$,$AB_2 = x_2$,$AB_3 = x_3$和底边$B_1B_2 = a$,$B_2B_3 = b$,$B_3B_1 = c$。 应用三角不等式：$x_1 < x_2 + a$,$x_1 < x_3 + c$，求和得出$2 x_1 < x_2 + x_3 + a + c$。 类似的不等式也成立$x_2$和$x_3$。 自从$\sum \theta_i > 180^\circ$，顶点是“宽”的，所以没有$x_i$可以是最大的比较$a + b + c$，验证$x_i < (a + b + c)/2$。 一个数值示例$a = 3$,$b = 4$,$c = 5$，并且顶点位于具有侧边的质心上方$x_1 = 5$,$x_2 = 5$,$x_3 = 5$满足顶角条件和$x_i < s = 6$，确认正确性。 

## 替代方法

 一种替代方法是将顶点正交投影到基平面上，并考虑从投影到顶点的距离。 通过将顶点视为底面平面中的一个点并利用顶点处的角度总和超过这一事实$180^\circ$，可以应用平面多边形不等式来显示每条侧边都小于半周长。 这种方法使用二维简化，但需要仔细证明投影的合理性以保持不等式。 三角不等式的直接面对面应用是更可取的，因为它避免了投影并将所有推理完全保留在三维几何中，保持了严谨性和清晰度。
