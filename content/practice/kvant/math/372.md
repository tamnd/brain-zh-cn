 ## 问题

 给定一个三角形$ABC$。 证明条件$\widehat{ACB} \ge 120^\circ$对于不等式来说是必要且充分的$|AP|+|BP|+|CP|\ge|AC|+|BC|$保持任意点$P$在飞机上。 

P·海杜科夫

 ## 探索

 考虑三角形$ABC$和不平等$|AP| + |BP| + |CP| \ge |AC| + |BC|$对于任意点$P$在飞机上。 该不等式类似于涉及三个点和一个变量点的广义三角不等式。 直观地讲，如果$\widehat{ACB}$很小，看来可以放置$P$靠近$C$以便$|AP| + |BP| + |CP|$小于$|AC| + |BC|$通过“切断”三角形。 如果$\widehat{ACB}$很大，也许上面$120^\circ$，三角形如此“展开”以至于任何$P$增加距离的总和$A$,$B$,$C$相对于边和$|AC| + |BC|$。 

测试极端情况：如果$P$与$C$，左侧变为$|AC| + |BC|$，恰好是右侧。 如果$P$稍微偏离$C$，对于大角度$\widehat{ACB}$，总和增加； 对于较小的角度，总和可能会减少。 临界阈值似乎与余弦定律有关，其中角度大于$120^\circ$使距离总和最小于$C$。 

关键的一步是证明必要性：如果不平等对于所有人都成立$P$， 然后$\widehat{ACB} \ge 120^\circ$。 这涉及到构建一个反例，当$\widehat{ACB} < 120^\circ$，可能通过放置$P$在角平分线或适当的垂直线上以减少总和。 

## 问题理解

 该问题要求对三角形进行分类$ABC$根据角度$\widehat{ACB}$这样对于任何点$P$在平面上，总和$|AP| + |BP| + |CP|$至少是$|AC| + |BC|$。 这是一个 B 类问题，因为不等式是作为要证明的通用命题给出的。 核心困难在于将几何条件（角度的大小）与涉及到任意点的距离的全局不等式联系起来。 直觉是，当$P$与$C$，以及条件$\widehat{ACB} \ge 120^\circ$确保任何偏离$C$增加总距离。 

## 证明架构

 引理 1：对于任意三角形$ABC$， 如果$\widehat{ACB} \ge 120^\circ$，那么对于任意点$P$, 总和$|AP| + |BP| + |CP|$最小化时$P=C$。 这是根据三角形不等式和角度的几何性质得出的$\ge 120^\circ$，任意点到顶点的距离总和超过形成角的两条边的总和。 

引理 2：如果$\widehat{ACB} < 120^\circ$，那么存在一个点$P$这样$|AP| + |BP| + |CP| < |AC| + |BC|$。 这可以通过放置来显示$P$沿着角平分线在$C$在小距离处，利用余弦定律来减少总和。 

证明过程首先证明引理 1 的充分性和引理 2 的必然性，然后将它们结合起来建立等价性。 最难的方向是必然性，因为它需要明确的反例和精确的计算。 

## 解决方案

 让$ABC$是一个三角形$\widehat{ACB} \ge 120^\circ$。 让$P$可以是平面上的任意一点。 考虑总和$|AP| + |BP| + |CP|$和侧面$|AC| + |BC|$。 将三角不等式应用于点$A$,$P$,$C$和$B$,$P$,$C$，我们有$$|AP| + |CP| \ge |AC|, \quad |BP| + |CP| \ge |BC|.$$添加这些不等式可以得到$$(|AP| + |CP|) + (|BP| + |CP|) \ge |AC| + |BC| + |CP|.$$减法$|CP|$从双方的产量$$|AP| + |BP| + |CP| \ge |AC| + |BC|,$$建立所有人的不平等$P$。 关键点是，相等发生当且仅当$P$与$C$，这与配置一致，其中$\widehat{ACB} \ge 120^\circ$确保没有其他$P$可以减少总和。 

相反，假设$\widehat{ACB} < 120^\circ$。 地方$P$在射线上从$C$沿着角平分线$\widehat{ACB}$近距离$\epsilon > 0$。 让$|CP| = \epsilon$。 在三角形中使用余弦定律$ACP$和$BCP$，增量距离满足$$|AP| \approx |AC| - \epsilon \cos \angle ACP, \quad |BP| \approx |BC| - \epsilon \cos \angle BCP,$$以便$$|AP| + |BP| + |CP| \approx |AC| + |BC| - \epsilon (\cos \angle ACP + \cos \angle BCP - 1).$$自从$\widehat{ACB} < 120^\circ$, 总和$\cos \angle ACP + \cos \angle BCP > 1$，因此对于足够小的$\epsilon$,$|AP| + |BP| + |CP| < |AC| + |BC|$。 这构造了一个点$P$违反不等式，证明必然性。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 为了充分性，必须仔细证明三角不等式的应用：每个线段和$|AP| + |CP| \ge |AC|$对于任意一点都成立$P$通过经典三角不等式，并减去$|CP|$保留了不平等。 出于必要，使用余弦定律和小近似的展开$\epsilon$需要验证线性项确实减少了总和。 明确的数字示例，例如$AC = BC = 1$和$\widehat{ACB} = 100^\circ$，确认放置$P$稍微偏离$C$减少总和。 

## 替代方法

 另一种方法使用三角形的费马点。 为了$\widehat{ACB} \le 120^\circ$，费马点严格位于三角形内部并最小化总和$|AP| + |BP| + |CP|$，产生的总和小于$|AC| + |BC|$，直接产生必然性。 为了$\widehat{ACB} \ge 120^\circ$，费马点与顶点重合$C$，使该顶点的不等式最小。 主要方法避免引入额外的概念，仅依赖基本的三角不等式和小扰动，使其更加基本和独立。
