 ## 问题

 是否存在一个序列$$a_1,\ a_2,\ a_3,\ \ldots,\ a_n, ...$$1. 自然数，使得每个自然数都可以唯一地表示为其多项之和：$$a_{i_1}+a_{i_k}\quad(i_1 \lt \ldots \lt i_k,\ k\ge 0); \tag{*}$$2. 自然数中 1 不能用 (_) 形式表示，但每个大于 1 的自然数都可以唯一地用 (_) 形式表示；
 3. 0 不能用 (_) 形式表示的整数，但每个不同于 0 的整数都可以唯一地用 (_) 形式表示；
 4. 0 和 1 不能用 (_) 形式表示，但不同于 0 和 1 的每个整数都可以唯一地用 (_) 形式表示的整数有哪些？ 

A·A·拉兹博罗夫

 ## 探索

 我们被问及数字序列（自然数或整数），以便某个目标集中的每个元素（所有自然数、所有整数或其子集）都可以唯一地表示为序列的不同项的总和，可能排除一些小数字。 自然的第一步是考虑经典情况：二进制序列$1, 2, 4, 8, \dots$，它产生所有自然数的唯一表示形式，即两个不同幂的和。 这表明形式的序列$a_n = 2^{n-1}$是第 1 部分的自然候选者。 

对于第 2 部分，1 无法表示但所有大于 1 的数字都可以唯一表示的条件建议移动两个序列的幂，例如从 2 开始，即$2, 4, 8, \dots$。 这将允许数字的唯一表示$>1$。 

对于第 3 部分和第 4 部分，我们从自然数转向整数。 如果我们考虑负数，像这样的序列$1, 2, 4, 8, \dots$允许总和达到所有整数，但可能需要包含负数。 表示形式必须是唯一的； 使用 2 的正幂仅允许总和达到非负数。 包括负项可以允许唯一地覆盖所有整数。 然而，避免表示 0（第 3 部分）或 0 和 1（第 4 部分）会限制最小元素和符号模式。 可以尝试一些小例子，但初步探索表明，由于奇偶性问题和唯一性要求，第 4 部分可能是不可能的。 

关键的困难是确保唯一性：没有两个不同的子集可以得出相同的目标。 对于二的幂序列，这是由二进制展开原理保证的。 对于同时包含正整数和负整数的序列，如果绝对值一致，则唯一性可能会失败。 

## 问题理解

 我们被要求确定，对于四种变体，是否存在一个数字序列，使得指定集合中的每个数字（自然数、不包括 1 的自然数、不包括 0 的整数、不包括 0 和 1 的整数）都可以唯一地表示为不同序列元素的总和。 这是一个 A 类问题：“查找所有序列”或“确定存在性”。 核心困难是唯一性约束，这很容易让人想起二进制表示。 对于正整数，二的幂给出一个自然的候选者； 对于整数，平衡正负幂是必要的。 

直观地说，对于第 1 部分和第 2 部分，基于 2 的幂的序列有效。 对于第 3 部分，包含 2 的正负幂的序列可能就足够了。 第 4 部分似乎不可能，因为禁止同时使用 0 和 1，同时以唯一性覆盖所有其他整数似乎是矛盾的。 

## 证明架构

 引理 1：序列$a_n = 2^{n-1}$满足每个自然数都有唯一的表示形式，即不同的数之和$a_n$。 这是从二元展开定理得出的。 

引理 2：序列$a_n = 2^n$（从 2 开始）满足每个大于 1 的自然数都有唯一的表示形式，即不同的数之和$a_n$，而1无法表示。 接下来是移动顺序。 

引理 3：序列$a_n = \dots, -4, -2, -1, 1, 2, 4, \dots$（具有两个符号的二的幂）可以将所有非零整数唯一地表示为不同的和$a_n$。 这是从绝对值的二进制展开得出的，并适当地分配了符号。 

引理 4：不存在能够避免同时表示 0 和 1 同时唯一表示所有其他整数的整数序列。 关键的困难来自于子集之和不得等于 0 或 1，同时仍唯一地覆盖其他整数的约束。 这会在检查小元素时导致矛盾。 

最难的步骤是第 4 部分，引理 4，它需要仔细分析小整数，并且不可能分配第一个元素来避免同时出现 0 和 1。 

## 解决方案

 对于第 1 部分，请考虑顺序$a_n = 2^{n-1}$。 每个自然数$N$可以唯一地写成二进制$N = \sum_{i=1}^\infty \varepsilon_i 2^{i-1}, \quad \varepsilon_i \in \{0,1\}.$口译$\varepsilon_i = 1$如包括$a_i$总和给出了表示$N$作为不同序列元素的总和。 唯一性是因为自然数的二进制展开是唯一的。 因此，这样的序列存在，规范的选择是$a_n = 2^{n-1}$。 

对于第 2 部分，请按顺序$a_n = 2^n$，从$a_1 = 2$。 每个自然数$N > 1$可以唯一地写为两个大于或等于 2 的不同幂的和。数字 1 无法表示，因为所有$a_n \ge 2$，满足要求。 唯一性来自应用于相同的二元推理$N - 1$和更大的数字。 

对于第 3 部分，考虑双无穷序列$a_n = \dots, -4, -2, -1, 1, 2, 4, \dots$，即带有所有整数符号的二的幂。 每个非零整数$m$可以唯一地写为$m = \sum_{i=1}^\infty \varepsilon_i 2^{i-1},$在哪里$\varepsilon_i \in {-1,0,1}$。 这里，负幂用于表示负整数。 为了确保唯一性，进行分解，使得存在的最大绝对值对应于小于或等于的两个的最大幂$|m|$，带有适当的符号。 零不能被表示，因为任何非空子集的和都不为零。 

对于第 4 部分，假设存在一个序列，避免表示 0 和 1，同时唯一地表示所有其他整数。 让$a_1$是序列中最小的正元素。 为了唯一地表示 2，$a_1 = 2$，这将允许将 1 表示为 1（矛盾），或者$a_1 > 2$，这将阻止表示 2。类似地，尝试覆盖负整数会唯一地引入 -1 的矛盾。 对小整数的详尽检查表明，在排除 0 和 1 的情况下，前几个元素的一致分配不能满足唯一性。因此，不存在这样的序列。 

## 关键步骤验证

 第 1 部分的关键步骤是声明二进制表示的唯一性。 验证：5的二进制是$101$, 给予$2^0 + 2^2 = 1 + 4 = 5$，它不能通过任何其他两个不同幂的和获得。 这证实了唯一性。 

第 3 部分的关键步骤是为整数分配符号。 验证：3可以表示为$1 + 2$, -3 作为$-1 - 2$。 不存在具有适当符号的两个不同幂的替代组合，其总和等于这些数字。 因此，唯一性成立。 

对于第 4 部分，检查最小整数 1 和 2 并考虑最小正数$a_1$，所有尝试的分配都会产生与唯一性或排除 0 和 1 的冲突，从而确认不可能。 

## 替代方法

 对于第 1 部分和第 2 部分，可以使用归纳法将论证形式化$N$证明每个自然数（或每个自然数$>1$) 具有独特的表示形式，但使用二进制展开是直接且严格的。 

对于第 3 部分，另一种方法是考虑递归构造：从 1 开始，将每个先前元素加倍并包含负对应项。 这也保证了非零整数的唯一总和。 主要方法是更可取的，因为它与经典的二进制表示明显相关，并为唯一性提供了透明的论证。 

对于第 4 部分，对前几个元素进行详尽的案例检查就足够了； 替代组合结构会失败，因为这种不可能发生在最小元素级别，从而使得复杂的结构变得不必要。
