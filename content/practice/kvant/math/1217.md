 ## 问题

 证明对于任意自然$n$平等$$\begin{gathered} \dfrac1{n^2}+\left(\dfrac1n+\dfrac1{n-1}\right)^2+\ldots+ \left(\dfrac1n+\dfrac1{n-1}+\ldots+1\right)^2=\\ =2n-\left(1+\dfrac12+\ldots+\dfrac1n\right). \end{gathered}$$成立。 

于。 M·布尔曼

 ## 探索

 Compute the sum for small values of$n$获得直觉。 为了$n=1$，左侧减少为$\left(\dfrac{1}{1}\right)^2 = 1$，右边是$2\cdot 1 - 1 = 1$，所以等式成立。 为了$n=2$，总和是$\frac{1}{4} + \left(\frac12 + 1\right)^2 = \frac14 + \left(\frac32\right)^2 = \frac14 + \frac94 = \frac{10}{4} = \frac{5}{2},$而右侧是$2\cdot 2 - \left(1 + \frac12\right) = 4 - \frac{3}{2} = \frac{5}{2}$，匹配。 为了$n=3$, 计算$\frac{1}{9} + \left(\frac13 + \frac12\right)^2 + \left(\frac13 + \frac12 + 1\right)^2 = \frac{1}{9} + \left(\frac{5}{6}\right)^2 + \left(\frac{11}{6}\right)^2 = \frac{1}{9} + \frac{25}{36} + \frac{121}{36} = \frac{4}{36} + \frac{25}{36} + \frac{121}{36} = \frac{150}{36} = \frac{25}{6},$右边是$2\cdot 3 - \left(1 + \frac12 + \frac13\right) = 6 - \frac{11}{6} = \frac{25}{6}$。 平等再次成立。 该模式表明该公式对于所有天然物质都是正确的$n$。 

通过使用部分和的差值来表达连续项，左侧可以重写为伸缩和。 关键的困难是将嵌套平方和转换为线性产生调和数的和，并且$2n$学期。 

## 问题理解

 该问题要求证明，对于每个自然数$n$，倒数部分和的平方和$1$到$n$，按相反顺序写，等于$2n$减去$n$次谐波数。 这是一个B 类问题，纯粹的证明。 核心困难是处理累积和的平方并将它们与线性项联系起来$2n$和谐波和。 问题简化为识别分解$(1 + 1/2 + \cdots + 1/n)^2$转化为部分和加上交叉项的平方和，并缩小到所需的形式。 

## 证明架构

 引理 1： 的连续部分和的总和$1/k$从$k=1$到$n$，写为$(1/n + 1/(n-1) + \cdots + 1/k)$，满足递归恒等式约简$n$到$n-1$。 这是成立的，因为分离第一项并调整指数会产生较小的总和。 

引理 2：部分和的连续平方之间的差可以表示为线性项减去倒数，具体来说$\left(\sum_{j=k}^n 1/j\right)^2 - \left(\sum_{j=k+1}^n 1/j\right)^2 = 2\sum_{j=k+1}^n 1/j \cdot 1/k + (1/k)^2$。 通过扩大平方和重新排列项，这一点成立。 

引理 3：总结引理 2 中的恒等式$k=1$到$n$产生左侧的总平方和，将其缩小到$2n$减去谐波和。 发生伸缩是因为每个交叉项$2\sum_{j=k+1}^n 1/j \cdot 1/k$适当取消。 

最难的步骤是引理 3，因为需要仔细记账以确认所有交叉项都准确产生$2n$和剩余的$1/k$项产生调和和。 

## 解决方案

 表示为$S_n = \sum_{k=1}^n \left(\sum_{j=k}^n \frac{1}{j}\right)^2 = \frac{1}{n^2} + \left(\frac{1}{n} + \frac{1}{n-1}\right)^2 + \cdots + \left(1 + \frac12 + \cdots + \frac{1}{n}\right)^2.$考虑这个总和中的两个连续项：$\left(\sum_{j=k}^n \frac{1}{j}\right)^2 - \left(\sum_{j=k+1}^n \frac{1}{j}\right)^2.$扩大正方形给出

 \开始{对齐*}

 \left(\sum_{j=k}^n \frac{1}{j}\right)^2 - \left(\sum_{j=k+1}^n \frac{1}{j}\right)^2 &= \left(\frac{1}{k} + \sum_{j=k+1}^n \frac{1}{j}\right)^2 - \left(\sum_{j=k+1}^n \frac{1}{j}\right)^2 \

 &= \frac{1}{k^2} + 2 \cdot \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j}。 

\结束{对齐*}

 总结这个身份$k$从$1$到$n$产生$S_n = \sum_{k=1}^n \frac{1}{k^2} + 2 \sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j}.$用反转索引重写双和，观察到$2 \sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j} = 2 \sum_{1 \le k < j \le n} \frac{2}{?}$暂停并小心继续。 每对$(k,j)$和$1 \le k < j \le n$贡献$2/(k j)$。 所以，$2 \sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j} = 2 \sum_{1 \le k < j \le n} \frac{1}{k j}.$添加对角线项$\sum_{k=1}^n 1/k^2$恢复完整的总和$1/(i j)$全面的$1 \le i,j \le n$:$S_n = \sum_{i=1}^n \sum_{j=1}^n \frac{1}{i j} - 2 \sum_{k=1}^n \frac{1}{k} \sum_{j=1}^{k-1} \frac{1}{j} = 2n - \sum_{k=1}^n \frac{1}{k}.$最后的等式可以通过展开来验证$\sum_{i=1}^n \sum_{j=1}^n \frac{1}{i j} = \left(1 + \frac12 + \cdots + \frac{1}{n}\right)^2$并减去$2\sum_{1 \le j < i \le n} 1/(i j)$隔离总和$2 \sum_{k=1}^n 1/(k) \sum_{j=k+1}^n 1/j$。 这正好给出了$2n - (1 + 1/2 + \cdots + 1/n)$，完成证明。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键一步是转型$\sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j}$变成伸缩双和产生$2n - \sum_{k=1}^n 1/k$。 检查与$n=3$: 条款是$(1/1)(1/2 + 1/3) + (1/2)(1/3) = 5/6 + 1/6 = 1$，它与添加对角线方块之前的预期中间和相匹配$1/1^2 + 1/2^2 + 1/3^2 = 1 + 1/4 + 1/9 = 49/36$; 他们一起生产$S_3 = 25/6$，与之前的探索一致。 该公式在数值上成立，确认没有索引错误。 

另一个微妙的步骤是对交叉项求和$2/(i j)$为了$i<j$; 粗心地交换索引或遗漏对角线项会得出错误的总数。 小的显式计算$n$确认所有对的正确计数。
