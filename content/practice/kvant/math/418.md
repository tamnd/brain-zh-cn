 ## 问题

 证明对于任意自然数$n$下列不等式成立：$$n{\left(\!\sqrt[\scriptstyle n~]{n+1}-1\right)}\le 1+\dfrac12+\dfrac13+\ldots+\dfrac1n\le 1+n{\left(1-\dfrac1{\!\sqrt[\scriptstyle n~]n}\right)}.$$## 探索

 对于较小的值$n$,$$n=1:\qquad 1(\sqrt[1]{2}-1)=1,\qquad H_1=1,\qquad 1+1\left(1-\frac1{\sqrt[1]{1}}\right)=1.$$为了$n=2$,$$2(\sqrt3-1)\approx1.464,\qquad H_2=\frac32,\qquad 1+2\left(1-\frac1{\sqrt2}\right)\approx1.586.$$不平等现象依然存在。 

表达式涉及$n$th 根建议取对数。 如果$$a=\sqrt[n]{n+1},$$然后$$n(a-1)\le H_n \iff a\le 1+\frac{H_n}{n}.$$自从$$a^n=n+1,$$就足以证明$$\left(1+\frac{H_n}{n}\right)^n\ge n+1.$$调和和自然地出现在乘积中$$\prod_{k=1}^n\left(1+\frac1k\right)=n+1.$$比较各个因素$1+\frac1k$与普通数量$1+\frac{H_n}{n}$表明算术平均数-几何平均数不等式。 

对于上限，重写给出$$H_n-1\le n\left(1-\frac1{\sqrt[n]{n}}\right).$$等价地，$$\frac{n+1-H_n}{n}\ge \frac1{\sqrt[n]{n}}.$$数量$n+1-H_n$等于$$\sum_{k=1}^n\left(1-\frac1k\right) =\sum_{k=1}^n\frac{k-1}{k}.$$再次建议使用AM-GM。 数字的乘积$\frac{k-1}{k}$为了$k\ge2$是$$\frac12\cdot\frac23\cdots\frac{n-1}{n}=\frac1n,$$与外观相匹配$\sqrt[n]{n}$。 

微妙的一点是第二个不等式，因为必须应用 AM-GM 来$n$数字，其中之一是$0$，并验证所得的几何平均值确实是$n^{-1/n}$。 

## 问题理解

 我们必须证明对于每个自然数$n$，调和和$$H_n=1+\frac12+\frac13+\cdots+\frac1n$$位于通过以下方式表示的两个量之间$n$根源：$$n\bigl(\sqrt[n]{n+1}-1\bigr) \le H_n \le 1+n\left(1-\frac1{\sqrt[n]{n}}\right).$$这是一个B 类问题。 该陈述已经给出并且必须被证明。 

核心难点在于将谐波和与乘积联系起来$$\prod_{k=1}^n\left(1+\frac1k\right)=n+1 \quad\text{and}\quad \prod_{k=1}^n\left(1-\frac1k\right)=0,$$或者更准确地说$$\prod_{k=2}^n\left(1-\frac1k\right)=\frac1n,$$然后以适当的形式使用算术平均-几何平均不等式。 

## 证明架构

 引理 1. 应用于数字的算术平均-几何平均不等式$1+\frac1k$给出$$1+\frac{H_n}{n}\ge\sqrt[n]{n+1}.$$这些数字的乘积望远镜$n+1$。 

Lemma 2. The arithmetic mean-geometric mean inequality applied to the numbers$1-\frac1k$为了$k=1,\dots,n$给出$$\frac{n-H_n+1}{n}\ge \frac1{\sqrt[n]{n}}.$$他们的算术平均值等于$\frac{n-H_n+1}{n}$他们的产品是$0\cdot\frac1n=0$，但第一项必须通过写出完整集合的几何平均值来仔细处理。 

更方便的版本是将 AM-GM 应用于数字$$0,\frac12,\frac23,\dots,\frac{n-1}{n},$$谁的产品是$0$，然后分离零项并计算剩余的几何平均值。 

最困难的部分是获得具有正确常数的上限。 最有可能失败的步骤是计算与数字相关的几何平均值$\frac{k-1}{k}$。 

## 解决方案

 让$$H_n=1+\frac12+\frac13+\cdots+\frac1n.$$我们首先证明左不等式。 

考虑$n$正数$$1+\frac11,\quad 1+\frac12,\quad \dots,\quad 1+\frac1n.$$他们的算术平均值是$$\frac1n\sum_{k=1}^n\left(1+\frac1k\right) = 1+\frac{H_n}{n}.$$他们的产品是$$\prod_{k=1}^n\left(1+\frac1k\right) = \prod_{k=1}^n\frac{k+1}{k} = n+1.$$由算术平均数-几何平均数不等式，$$1+\frac{H_n}{n} \ge \sqrt[n]{\,n+1\,}.$$因此$$H_n \ge n\bigl(\sqrt[n]{n+1}-1\bigr),$$这是所需的下限。 

现在我们证明正确的不等式。 

考虑$n$数字$$0,\ \frac12,\ \frac23,\ \dots,\ \frac{n-1}{n}.$$他们的算术平均值等于$$\frac1n\left( 0+\frac12+\frac23+\cdots+\frac{n-1}{n} \right).$$自从$$\frac{k-1}{k}=1-\frac1k,$$我们有$$\sum_{k=1}^n\frac{k-1}{k} = \sum_{k=1}^n\left(1-\frac1k\right) = n-H_n.$$因此算术平均值为$$\frac{n-H_n}{n}.$$将 AM-GM 应用于$n-1$正数$$\frac12,\frac23,\dots,\frac{n-1}{n}.$$他们的产品是$$\frac12\cdot\frac23\cdots\frac{n-1}{n} = \frac1n.$$因此$$\frac1{n-1} \sum_{k=2}^n\frac{k-1}{k} \ge \left(\frac1n\right)^{1/(n-1)}.$$使用$$\sum_{k=2}^n\frac{k-1}{k}=n-H_n,$$我们得到$$n-H_n \ge (n-1)n^{-1/(n-1)}.$$仍然需要将右侧与$n^{1-1/n}-1$。 

放$$t=n^{1/n}\ge1.$$然后$$(n-1)n^{-1/(n-1)} = (n-1)t^{-\,n/(n-1)}.$$我们声称$$(n-1)n^{-1/(n-1)} \ge n^{1-1/n}-1 = \frac{n}{t}-1.$$乘以正数$t^{,n/(n-1)}$给出等价的不等式$$n-1 \ge \left(\frac{n}{t}-1\right)t^{\,n/(n-1)}.$$自从$t^n=n$,$$\left(\frac{n}{t}-1\right)t^{\,n/(n-1)} = t^{\,n/(n-1)-1}(t^n-t) = t^{1/(n-1)}(n-t).$$因而足以证明$$n-1\ge t^{1/(n-1)}(n-t).$$因为$t\ge1$和$t^{1/(n-1)}\le t$，右边不超过$$t(n-t).$$因此足以表明$$n-1\ge t(n-t).$$后者相当于$$t^2-nt+n-1\ge0,$$和$$t^2-nt+n-1=(t-1)(t-(n-1)).$$自从$t=n^{1/n}$满足$$1\le t\le2\le n-1 \qquad (n\ge3),$$产品是非负的。 为了$n=1$和$n=2$，直接检查所需的不等式。 

最后，$$n-H_n\ge n^{1-1/n}-1.$$重新排列，$$H_n \le n+1-n^{1-1/n} = 1+n\left(1-\frac1{\sqrt[n]{n}}\right).$$这是所需的上限。 

两个不等式均得证。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于下界，关键的计算是$$\prod_{k=1}^n\left(1+\frac1k\right) = \frac21\cdot\frac32\cdots\frac{n+1}{n} = n+1.$$每个中间因素都相互抵消。 AM-GM 然后产生$$1+\frac{H_n}{n}\ge (n+1)^{1/n},$$这正好等于所需的不等式。 

对于上限，重要的恒等式是$$\prod_{k=2}^n\frac{k-1}{k} = \frac12\cdot\frac23\cdots\frac{n-1}{n} = \frac1n.$$粗心的计算可能会产生$\frac1{n-1}$而不是$\frac1n$; 伸缩只剩下分子$1$和分母$n$。 

另一个微妙的点是比较$$(n-1)n^{-1/(n-1)} \ge n^{1-1/n}-1.$$介绍完后$t=n^{1/n}$，差异减少为$$(t-1)(t-(n-1)).$$自从$1\le t\le n-1$为了$n\ge3$，这个量是非负的。 缺少因式分解会完全掩盖该符号。 

## 替代方法

 较短的路线使用对数的凹度。 从$$\log(1+x)\le x$$为了$x>-1$,$$\log(n+1) = \sum_{k=1}^n\log\!\left(1+\frac1k\right) \le H_n.$$结合这与$$e^x\ge1+x$$给出$$n+1=e^{\log(n+1)} \le e^{H_n} \le \left(1+\frac{H_n}{n}\right)^n,$$得出下界。 

对于上限，可以类似地使用$$-\log(1-x)\ge x \qquad (0<x<1)$$关于数字$x=\frac1k$,$k\ge2$，得到$$H_n-1 \le -\log\!\left(\frac1n\right) = \log n.$$自从$$\log n\le n\left(1-\frac1{\sqrt[n]{n}}\right),$$所需的估计如下。 AM-GM 方法更可取，因为这两个界限都源于相同的想法和伸缩产品$n+1$和$1/n$自然地出现。
