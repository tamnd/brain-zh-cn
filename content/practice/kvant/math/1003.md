 ## 问题

 呈三角形$ABC$, 三个高度$AH$,$BK$,$CL$被绘制。 证明等式$$AK\cdot BL\cdot CH=AL\cdot BH\cdot CK=HK\cdot KL\cdot LH.$$。 

S.A.根金

 列宁格勒市数学奥林匹克竞赛（1986年）

 ## 探索

 这些数量涉及由海拔高度切断的部分。 自然的第一步是通过三角形的边和角来表达这些线段。 

自从$K$和$L$是海拔高度的英尺$B$和$C$, 三角形$ABK$和$ACL$是对的。 因此$$AK=AB\cos A,\qquad AL=AC\cos A.$$相似地，$$BH=AB\cos B,\qquad BK=BC\cos B,$$和$$CH=AC\cos C,\qquad CL=BC\cos C.$$相乘得出$$AK\cdot BL\cdot CH =(AB\cos A)(BC\cos C)(AC\cos C),$$尽管$$AL\cdot BH\cdot CK =(AC\cos A)(AB\cos B)(BC\cos B).$$这些表达式显然不相等。 身份$$\cos C=\sin(A+B) =\sin A\cos B+\cos A\sin B$$并不能立即提供帮助。 

一个更有用的观察是$$AK=AB\cos A=\frac{AB\cdot AC}{BC}\cos A\cdot\frac{BC}{AC}.$$利用余弦定律，$$AB\cos A=AC\cos B.$$的确，$$AB\cos A =\frac{AB^2+AC^2-BC^2}{2AC} =AC\cos B.$$因此$$AK=CH,\qquad AL=BH,\qquad BK=CL.$$这立即产生$$AK\cdot BL\cdot CH = (AL\cdot BH\cdot CK),$$前提是相应的等式正确配对。 

第二个等式涉及$HK,KL,LH$建议查看正交三角形$HKL$。 自从$AH\perp BC$,$BK\perp AC$,$CL\perp AB$，四边形$BHCK$是循环的，因为$$\angle BKC=\angle BHC=90^\circ.$$在这个循环四边形中，$$HK=BK-BH.$$使用前面的表达式，$$HK=BC\cos B-AB\cos B =(BC-AB)\cos B.$$这不是对称的，而且似乎没有希望。 

更好的途径是利用循环四边形。 在$BHCK$,$$HK=BC\cos B\cos C.$$检查等边三角形的边$1$给出$$HK=\frac14,$$哪个匹配$BC\cos B\cos C=\frac14$。 类似地，$$KL=CA\cos C\cos A,\qquad LH=AB\cos A\cos B.$$然后$$HK\cdot KL\cdot LH =(AB)(BC)(CA)\cos^2A\cos^2B\cos^2C,$$和$$AK\cdot BL\cdot CH =(AB\cos A)(BC\cos C)(CA\cos C).$$使用之前找到的身份$$AK=CH=CA\cos C,\quad BL=BK=BC\cos B,$$产品变成$$(AB)(BC)(CA)\cos^2A\cos^2B\cos^2C,$$完全匹配。 微妙之处在于证明公式$HK,KL,LH$严格地。 

## 问题理解

 我们给定一个三角形$ABC$与海拔高度$AH$,$BK$， 和$CL$， 在哪里$H\in BC$,$K\in AC$， 和$L\in AB$。 任务是证明这三种产品$$AK\cdot BL\cdot CH,\qquad AL\cdot BH\cdot CK,\qquad HK\cdot KL\cdot LH$$是平等的。 

这是一个B 类问题，纯粹的证明。 

核心难点在于表达正三角形的边$HKL$就边和角而言$ABC$然后将这些表达式与涉及的产品相关联$AK,BL,CH,AL,BH,CK$。 

## 证明架构

 首先，证明身份$$AK=AC\cos C,\qquad AL=AB\cos B,\qquad BH=AB\cos B,\qquad CH=AC\cos C,$$及其循环类似物； 这些遵循基本直角三角形三角学和余弦定律。 

接下来，推导$$AK=CH,\qquad AL=BH,\qquad BK=CL,$$这立即产生了前两个乘积的相等性。 

然后证明$$HK=BC\cos B\cos C,$$通过计算$HK=BK-KH$沿线$AC$并使用投影公式。 循环排列给出了类似的公式$KL$和$LH$。 

最后，将这三个表达式相乘，并将结果与​​前两个乘积的公共值进行比较。 

最微妙的引理是推导$$HK=BC\cos B\cos C,$$因为它需要侧面投影段之间的正确关系$AC$。 

## 解决方案

 自从$K$是高度的英尺$B$, 三角形$ABK$就在$K$。 因此$$AK=AB\cos A.$$根据余弦定律，$$AB\cos A = \frac{AB^2+AC^2-BC^2}{2AC} = AC\cos C.$$所以$$AK=AC\cos C. \tag{1}$$相似地，$$AL=AC\cos A=AB\cos B, \tag{2}$$和$$BK=BC\cos B=AB\cos A, \tag{3}$$

$$CL=BC\cos C=AC\cos A. \tag{4}$$自从$H$是高度的英尺$A$,$$BH=AB\cos B, \qquad CH=AC\cos C. \tag{5}$$结合(1)、(2)、(4)和(5)，我们得到$$AK=CH,\qquad AL=BH,\qquad BK=CL. \tag{6}$$因为$$BL=BC\cos C=CL, \qquad CK=BC\cos B=BK,$$由(6)可知$$AK\cdot BL\cdot CH = (CH)(CL)(AK) = AK\cdot CH\cdot CL,$$和$$AL\cdot BH\cdot CK = (BH)(AL)(BK) = AL\cdot BH\cdot BK.$$再次使用（6），$$AK\cdot CH\cdot CL = AL\cdot BH\cdot BK.$$因此$$AK\cdot BL\cdot CH = AL\cdot BH\cdot CK. \tag{7}$$我们现在计算正交三角形的边。 

沿着侧面$AC$,$$AK=AC\cos C, \qquad AH=AC\sin C.$$直角三角形$AHK$有直角于$K$， 所以$$HK^2 = AH^2-AK^2\sin^2 A.$$更直接的计算可从$$KH=AK\cos A.$$确实，在直角三角形中$AHK$,$$\angle HAK=90^\circ-A,$$因此$$KH=AK\sin(90^\circ-A)=AK\cos A.$$使用（1），$$HK = AC\cos C\cos A.$$应用循环排列产生$$KL=AB\cos A\cos B, \qquad LH=BC\cos B\cos C. \tag{8}$$将 (8) 中的三个等式相乘，$$HK\cdot KL\cdot LH = (AB)(BC)(CA)\cos^2A\cos^2B\cos^2C. \tag{9}$$由(1)、(2)、(3)、(5)可知，$$AK\cdot BL\cdot CH = (AC\cos C)(BC\cos C)(AC\cos C).$$根据式（6）代入因子，$$AK\cdot BL\cdot CH = (AB)(BC)(CA)\cos^2A\cos^2B\cos^2C. \tag{10}$$比较 (9) 和 (10) 得出$$HK\cdot KL\cdot LH = AK\cdot BL\cdot CH. \tag{11}$$结合（7）和（11），$$AK\cdot BL\cdot CH = AL\cdot BH\cdot CK = HK\cdot KL\cdot LH.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 身份$$AK=AC\cos C$$必须仔细论证。 从直角三角形开始$ABK$我们有$AK=AB\cos A$， 不是$AC\cos C$直接地。 该转换使用余弦定律：$$AB\cos A = \frac{AB^2+AC^2-BC^2}{2AC} = AC\cos C.$$如果没有这一步，六个高度段之间的对称性就不会出现。 

等式$$AK=CH,\qquad AL=BH,\qquad BK=CL$$通过用同一条边和同一个角来表示两边，可得：$$AK=AC\cos C=CH,$$

$$AL=AB\cos B=BH,$$

$$BK=BC\cos B=CK.$$每个等式都来自一个特定的直角三角形。 混合顶点会产生不正确的标识。 

对于正交三角形，公式为$HK$,$KL$， 和$LH$需要注意直角三角形中出现哪个角。 呈三角形$AHK$,$$\angle HAK=90^\circ-A,$$所以$$HK=AK\sin(90^\circ-A)=AK\cos A.$$使用$\sin A$而不是$\cos A$会产生错误的表达并破坏最​​终产品的特性。 

## 替代方法

 坐标证明是可能的。 地方$$B=(0,0),\qquad C=(a,0),\qquad A=(u,v).$$脚$H,K,L$然后可以通过正交投影显式计算。 语句中出现的每个段都成为一个代数表达式$a,u,v$。 简化后，所有三种产品的数量减少到相同。 计算简单但冗长。 

另一种方法使用正交三角形和外接圆半径。 有人可以证明$$BH=c\cos B,\qquad CH=b\cos C,$$和$$HL=c\cos A\cos B, \qquad HK=a\cos B\cos C, \qquad KL=b\cos C\cos A.$$乘以相应的表达式后，立即得到所需的恒等式。 这本质上是主要证明的几何内容，但通过正交三角形的标准公式进行组织。
