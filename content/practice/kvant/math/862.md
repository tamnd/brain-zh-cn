 ## 问题

 1. 在给定的等边三角形内，指出所有点的集合$M$使得距离$M$它的边本身就是某个三角形的边长。 
2. 在给定的正四面体内，指出所有点的集合$M$使得距离$M$四面体各面的边长用作某些四边形的边长。 

E.A.亚西诺维̆ĭ

 ## 探索

 首先考虑等边三角形的情况。 设三角形有边长$a$并将其边表示为$AB$,$BC$， 和$CA$。 为了一点$M$里面，让$d_1$,$d_2$,$d_3$是距离$M$到$AB$,$BC$， 和$CA$， 分别。 这些距离都是正数并且满足$d_1 + d_2 + d_3 = h$， 在哪里$h$是三角形的高。 为了使这些距离形成三角形，它们必须满足三角形不等式$d_1 < d_2 + d_3$,$d_2 < d_3 + d_1$,$d_3 < d_1 + d_2$。 注意到$d_1 + d_2 + d_3 = h$，不平等减少到$d_i < h/2$对于每个$i$。 这表明轨迹是三角形内到边的距离都小于的点的集合$h/2$，它似乎是适当缩放的内侧三角形的内部。 

对于四面体，设其边长为$a$，并让$M$有距离$d_1, d_2, d_3, d_4$到脸上。 从任何内部点到面的距离之和（按面面积加权）等于四面体体积； 对于正四面体，这可以减少为$d_1 + d_2 + d_3 + d_4 = H$，距任意顶点的高度。 为了$d_1, d_2, d_3, d_4$要形成四边形，它们必须满足$d_i < d_j + d_k + d_l$为所有人$i$，这又相当于$d_i < H/2$。 这表明内点满足$d_i < H/2$为所有人$i$，四面体缩放比例为$1/2$从质心。 关键的一步是证明这个半高度限制既是必要的也是充分的。 

## 问题理解

 该问题要求以几何方式描述正则单纯形（三角形或四面体）内的点集，以便到边（或面）本身的距离可以排列为三角形（或四边形）的边。 这两部分都是分类问题，所以这是 A 类问题。核心困难是将距离的三角形或四边形不等式转换为单纯形内的简单几何条件。 对于三角形，答案是中心小三角形的内部，该三角形的边界是与各边平行的线，距各边高度距离的一半。 对于四面体，它是围绕质心的较小四面体的内部，其到面的距离小于高度的一半。 

## 证明架构

 1.引理1：在等边三角形中，任意内点到三边的距离之和等于高$h$。 这是根据面积公式得出的$[\triangle ABC] = \frac{1}{2} a h$并将面积分解为三个子三角形面积之和$[\triangle MBC] + [\triangle MCA] + [\triangle MAB]$。 
2. 引理 2：正数$d_1, d_2, d_3$当且仅当每条边都小于另外两条边之和时，形成三角形的边。 应用引理 1，三角形不等式简化为$d_i < h/2$。 
3. 引理 3：等边三角形内到边的距离小于的点的轨迹$h/2$是按比例缩放的内侧三角形的内部$1/2$，以与远处平行的线为界$h/2$。 
4.引理4：在正四面体中，任意内点到四个面的距离之和等于四面体的高度$H$。 这是从类似于引理 1 的体积分解得出的。 
5. 引理 5：正数$d_1, d_2, d_3, d_4$构成四边形当且仅当每个都小于其他三个之和。 使用引理 4，这可以简化为$d_i < H/2$。 
6. 引理 6：正四面体内到面的距离小于的点的轨迹$H/2$是围绕质心的较小四面体的内部，其面与原始面在一定距离处平行$H/2$。 

最难的方向是证明必然性：超过一半的高度违反了不等式。 如果忽略精确边界，引理 2 和引理 5 是最容易出错的步骤。 

## 解决方案

 考虑边长为等边三角形$a$和海拔高度$h = \frac{\sqrt{3}}{2} a$。 让$M$为三角形内的任意一点，并表示$d_1$,$d_2$,$d_3$距离$M$到两侧$AB$,$BC$， 和$CA$， 分别。 每个子三角形$MBC$,$MCA$,$MAB$有面积$\frac{1}{2} a d_i$。 求和，面积为$\triangle ABC$是$$[\triangle ABC] = [\triangle MBC] + [\triangle MCA] + [\triangle MAB] = \frac{1}{2} a (d_1 + d_2 + d_3).$$与相比$[\triangle ABC] = \frac{1}{2} a h$产量$$d_1 + d_2 + d_3 = h.$$为了$d_1, d_2, d_3$要形成三角形，三角形不等式需要$d_1 < d_2 + d_3$,$d_2 < d_3 + d_1$,$d_3 < d_1 + d_2$。 替代$d_1 + d_2 + d_3 = h$给出$d_1 < h - d_1$， 因此$d_1 < h/2$。 相似地，$d_2 < h/2$和$d_3 < h/2$。 相反，如果$d_1, d_2, d_3 < h/2$，他们的总和是$h$，并且每个都小于其他两个的总和。 因此，该条件是充分必要的。 几何上，三角形内的点集满足$d_i < h/2$是三角形的内部，以与远处平行的线为界$h/2$从每一面。 

考虑边长的正四面体$a$和海拔高度$H = \frac{\sqrt{6}}{3} a$。 让$M$是一个内点，并让$d_1, d_2, d_3, d_4$是它到面的距离。 将四面体分解为四个带有顶点的较小四面体$M$以原始四面体的每个面为底，它们的体积为$\frac{1}{3} \cdot (\text{area of face}) \cdot d_i$。 对所有面求和即可得出四面体的体积$$V = \frac{1}{3} S H = \sum_{i=1}^{4} \frac{1}{3} S d_i,$$在哪里$S$是脸部的面积。 除以$\frac{1}{3} S$产量$d_1 + d_2 + d_3 + d_4 = H$。 四边形不等式要求$d_i < d_j + d_k + d_l$为所有人$i$，这意味着$d_i < H - d_i$， 或者$d_i < H/2$。 相反，如果$d_i < H/2$为所有人$i$，满足不等式。 满足此条件的点集是与原始四面体相似的四面体的内部，其面与原始面平行，并且每个面都具有一定距离$H/2$从它。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 三角形情况的关键步骤是确认$d_1 + d_2 + d_3 = h$对于任何内点都成立。 沿着中线和随机内部点构建多个点，使用面积分解的直接计算确认了精确相等。 对于四面体，将体积分解为具有共享顶点的四个四面体$M$求和得到$d_1 + d_2 + d_3 + d_4 = H$，明确验证质心点和沿边缘的点。 减少不平等现象$d_i < d_j + d_k + d_l$到$d_i < H/2$通过检查进行数字验证$d_1 = H/2 + \epsilon$违反了不平等。
