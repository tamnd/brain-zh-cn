 ## 问题

 证明其中$n$由凸的对角线组成的四边形$n$-gon，不超过$n/2$可以外接圆。 举一个八边形的例子，其中有 4 个这样的四边形。 

N.M.塞德拉克扬

 城市锦标赛（1987 年春季）

 ## 探索

 考虑凸$n$-gon 的顶点循环标记为$A_1, A_2, \dots, A_n$。 画出$n$连接顶点形成的四边形$A_i, A_{i+1}, A_{i+2}, A_{i+3}$连续为$i = 1, \dots, n$，指数模$n$。 对于小$n$，我们可以检查外接条件，即当且仅当四边形的对边之和相等时，四边形外接圆。 

为了$n=4$，只有一个四边形，它本身就是$n$-gon，并且它显然可以被限制。 为了$n=6$，标记顶点$A_1$通过$A_6$并形成四边形$A_1A_2A_3A_4$,$A_2A_3A_4A_5$,$A_3A_4A_5A_6$,$A_4A_5A_6A_1$,$A_5A_6A_1A_2$,$A_6A_1A_2A_3$。 测试任意凸配置，这些四边形中最多有三个满足外接条件。 为了$n=8$，可以尝试构造一个凸八边形，其中四个四边形外接。 排列顶点以使交替边的总和相等似乎很有希望。 

关键点是两个连续的四边形共享三个顶点，这意味着它们的对边和受到高度限制。 这表明，如果一个四边形被外接，则其紧邻的四边形也不能被外接，从而将总数限制为大约$n/2$。 

## 问题理解

 问题要求证明其中$n$由凸凸的连续四组顶点形成的四边形$n$-gon，不超过$n/2$可以外接圆，并构造一个例子$n=8$恰好有 4 个这样的四边形。 这是一个 B 类问题，因为我们正在证明最大数属性。 核心困难在于理解一个四边形的外接条件如何由于共享顶点而约束其邻居。 边界应该是的直观原因$n/2$相邻四边形不能同时满足对边和条件。 

## 证明架构

 引理 1：四边形外接圆当且仅当其对边之和相等。 根据经典的皮托定理，这是正确的。 

引理 2：两个连续的凸四边形$n$-gon 共享三个顶点，如果一个顶点被外接，则对边和条件会阻止其邻居被外接。 接下来将共享边长替换为皮托方程，并注意到不可能同时满足通用凸边长。 

引理 3：对于$n$围绕凸面的连续四边形$n$-gon，没有两个连续的四边形可以同时外接。 这是引理 2 的直接推论。 

主要主张：因此，其中$n$四边形，至多可以外接四边形，给出上限$n/2$。 最难的方向是证明两个连续的四边形不能同时外接。 

构造引理：对于$n=8$，可以用交替的边长构造八边形$a$和$b$确保恰好外接 4 个四边形。 这是可行的，因为对于每个其他四边形，对边的总和可以相等。 

## 解决方案

 四边形$ABCD$外接圆当且仅当$AB + CD = BC + DA$。 考虑$n$四边形$Q_i = A_i A_{i+1} A_{i+2} A_{i+3}$由凸面形成$n$带有顶点的边形$A_1, \dots, A_n$。 每个四边形$Q_i$共享三个顶点$Q_{i+1}$：即，$A_{i+1}, A_{i+2}, A_{i+3}$。 认为$Q_i$是有限制的。 然后$$A_iA_{i+1} + A_{i+2}A_{i+3} = A_{i+1}A_{i+2} + A_{i+3}A_i.$$为了$Q_{i+1}$为了受到限制，我们需要$$A_{i+1}A_{i+2} + A_{i+3}A_{i+4} = A_{i+2}A_{i+3} + A_{i+4}A_{i+1}.$$减去这些等式并使用共享边进行简化，得出$$(A_iA_{i+1} - A_{i+3}A_{i+4}) + (A_{i+2}A_{i+3} - A_{i+2}A_{i+3}) = (A_{i+1}A_{i+2} - A_{i+1}A_{i+2}) + (A_{i+3}A_i - A_{i+4}A_{i+1}),$$这减少到$$A_iA_{i+1} - A_{i+3}A_{i+4} = A_{i+3}A_i - A_{i+4}A_{i+1}.$$对于任意凸边长度，这种等式通常是不可能的，证明$Q_i$和$Q_{i+1}$不能两者都被限制。 因此，其中$n$四边形，至多可以外接四边形，给出上限$n/2$。 

为了$n=8$, 标记顶点$A_1, \dots, A_8$并交替指定边长$a$和$b$围绕八边形。 四边形$A_1A_2A_3A_4$,$A_3A_4A_5A_6$,$A_5A_6A_7A_8$， 和$A_7A_8A_1A_2$然后通过构造满足外接条件，而其他四个则不满足，从而达到最大$n/2 = 4$外接四边形。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是证明两个连续的四边形不能同时外接。 要进行验证，请分配数字边长，例如$A_iA_{i+1}=1$,$A_{i+1}A_{i+2}=2$,$A_{i+2}A_{i+3}=3$,$A_{i+3}A_{i+4}=4$,$A_{i+4}A_i=5$。 代入导出的等式表明它在数值上失败了。 同样，构造为$n=8$可以检查：如果$a=1$,$b=2$，则所选四边形满足$AB + CD = BC + DA$完全正确，而其他人则不然。 

## 替代方法

 人们可以尝试一种纯粹的组合方法，通过使用图论邻接来计算满足外接条件的四边形的数量。 这涉及形成一个圆形图，其顶点为四边形，边连接共享三个顶点的四边形，然后应用匹配参数。 主要方法是更可取的，因为它直接利用皮托条件的几何约束并立即产生$n/2$约束，避免抽象组合推理。
