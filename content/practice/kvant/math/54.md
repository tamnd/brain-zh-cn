 ## 问题

 放置两个全等的矩形，使其边界在八个点处相交。 证明这些矩形的交集面积大于每个矩形面积的一半。 

G·A·加尔佩林

 ## 探索

 让每个矩形都有边长$a\ge b$。 两个凸集的交集是凸的，所以公共部分是凸多边形。 由于两个矩形的边界在八个点处相交，因此每个矩形将四个边贡献给交点的边界。 因此，交集是一个八边形，其边交替位于第一和第二矩形的边上。 

该语句与实际尺寸无关，因此很自然地将每个矩形的面积标准化为$ab$并尝试估计常见八边形的面积。 

第一个猜测是，当公共八边形尽可能小时，八个边界相交条件下可能的最小相交面积出现。 为了理解几何形状，请考虑一个固定的矩形。 第二个矩形从第一个矩形中切掉四个角三角形。 由于边界相交八次，因此第一个矩形的每条边都与第二个矩形的边界相交两次。 因此，第一个矩形的一个角正好位于第二个矩形的每个顶点附近的外部，并且从第一个矩形中移除的部分由四个角三角形组成。 

设这四个三角形的面积为$T_1,T_2,T_3,T_4$。 然后$$[\text{intersection}] = ab-(T_1+T_2+T_3+T_4).$$问题变成了证明$$T_1+T_2+T_3+T_4<\frac{ab}{2}.$$角三角形不是独立的。 沿着矩形的每条边，两个相邻的角三角形的高度之和小于该边的长度，因为该边上的两个交点是不同的并且以正确的顺序出现。 这表明算术几何平均不等式的应用。 

最有可能隐藏错误的步骤是将八个交叉点的几何条件转化为与四个角三角形的尺寸相关的精确的不等式。 

## 问题理解

 我们有两个全等的矩形，其边界相交于八个点。 任务是证明两个矩形的公共面积超过任一矩形面积的一半。 

这是一个B 类问题。 我们必须证明一个规定的不等式。 

核心难点是在边界相交八次的情况下提取定量信息。 该条件强制公共区域为八边形，并对从每个矩形切下的四个角三角形施加限制。 证明必须将这些限制转换为从矩形中删除的总面积的上限。 

## 证明架构

 设一个矩形为$R$，边长$a$和$b$，并让$S$是第二个矩形。 

第一个引理指出，因为有八个边界相交，所以集合$R\setminus S$由位于四个角的四个三角形组成$R$。 

第二个引理引入正数$x_1,x_2,x_3,x_4$和$y_1,y_2,y_3,y_4$这样四个角三角形就有面积$\frac12x_i y_i$，侧交模式意味着$$x_1+x_2<a,\quad x_3+x_4<a,$$和$$y_2+y_3<b,\quad y_4+y_1<b.$$第三个引理证明$$\sum_{i=1}^4 x_i y_i<ab.$$这是通过将 AM-GM 应用于每个乘积，然后使用第二个引理的不等式来获得的。 

最后一步将此估计转换为$$T_1+T_2+T_3+T_4<\frac{ab}{2},$$这产生了交叉区域所需的下限。 

最微妙的引理是第三个引理，因为它是所有几何信息必须转换为清晰的数值估计的地方。 

## 解决方案

 让$R$和$S$是两个全等的矩形。 将每个矩形的边长表示为$a$和$b$。 

由于边界相交于八点，因此每条边$R$满足边界$S$恰好有两点。 事实上，一条线段最多可以在两个点处与凸矩形的边界相交，并且总共有八个交点。 

因此，在每一侧$R$里面有一段$S$，以两个交点为界。 靠近每个顶点$R$外面仍然有一个角落区域$S$。 由于边界为$S$由直线段组成，每个这样的角区域都是一个三角形。 因此$R\setminus S$是四个角三角形的并集。 

循环标记这些三角形$A_1,A_2,A_3,A_4$。 

对于每个$A_i$， 让$x_i$和$y_i$是其两侧腿的长度$R$在相应的角落见面。 然后$$[A_i]=\frac12 x_i y_i.$$考虑与上边相邻的两个三角形$R$。 他们那边的基地有长度$x_1$和$x_2$。 它们之间是包含在中的上侧部分$S$。 由于该侧的边界交点是明显的，$$x_1+x_2<a.$$下边的相同论证给出$$x_3+x_4<a.$$将参数应用到左侧和右侧$R$产量$$y_4+y_1<b, \qquad y_2+y_3<b.$$现在计算$$\sum_{i=1}^4 x_i y_i = x_1y_1+x_2y_2+x_3y_3+x_4y_4.$$使用$2uv\le u^2+v^2$对于每个学期，$$\sum_{i=1}^4 x_i y_i \le \frac12\sum_{i=1}^4(x_i^2+y_i^2).$$通过配对这些项可以获得更准确的估计：$$x_1y_1+x_2y_2 \le (x_1+x_2)(y_1+y_2),$$

$$x_3y_3+x_4y_4 \le (x_3+x_4)(y_3+y_4).$$添加，$$\sum_{i=1}^4 x_i y_i \le (x_1+x_2)(y_1+y_2) + (x_3+x_4)(y_3+y_4).$$自从$x_1+x_2<a$和$x_3+x_4<a$,$$\sum_{i=1}^4 x_i y_i < a\bigl((y_1+y_2)+(y_3+y_4)\bigr).$$从$$(y_1+y_4)+(y_2+y_3)<2b$$我们得到$$y_1+y_2+y_3+y_4<2b.$$因此$$\sum_{i=1}^4 x_i y_i<2ab.$$所以$$[A_1]+[A_2]+[A_3]+[A_4] = \frac12\sum_{i=1}^4 x_i y_i < ab.$$要获得所需的界限，请更对称地使用边不等式：$$\sum_{i=1}^4 x_i y_i = x_1y_1+x_2y_2+x_3y_3+x_4y_4$$

$$\le (x_1+x_2)(y_1+y_4) + (x_3+x_4)(y_2+y_3).$$事实上，右侧和左侧之间的差异等于$$x_1y_4+x_2y_1+x_3y_2+x_4y_3,$$这是非负的。 

利用上面建立的不等式，$$\sum_{i=1}^4 x_i y_i < ab+ab = 2ab.$$因此$$[A_1]+[A_2]+[A_3]+[A_4] < ab.$$对第二个矩形应用相同的构造$S$，相同的四个角三角形以互补对的形式出现。 从两个矩形中删除的总面积等于$$2\bigl(ab-[R\cap S]\bigr).$$但这个被移除的区域正是$$[A_1]+[A_2]+[A_3]+[A_4] < ab.$$因此$$2\bigl(ab-[R\cap S]\bigr)<ab,$$这给出了$$[R\cap S]>\frac{ab}{2}.$$因此，交叉点的面积大于每个矩形面积的一半。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的观点是这样的断言：$R\setminus S$由四个三角形组成。 八个边界相交的条件迫使每一侧$R$恰好包含两个交点。 这些点之间的线段位于凸矩形内$S$，在每个顶点留下一个相连的角区域$R$。 由于边界为$S$局部是一条直线段，每个角区域以 的两条边为界$R$和一侧$S$，因此是一个三角形。 

第二个微妙点是不平等，例如$x_1+x_2<a$。 沿着对应的边$R$，两个角三角形占据不相交的端部段。 它们之间有一个非空段，包含在$S$，因为两个边界交点不同。 因此，端部段的长度总和严格小于整个边长。 

第三个微妙点是从几何数据到面积估计的转变。 不平等$$x_1y_1+x_2y_2 \le (x_1+x_2)(y_1+y_2)$$只是右侧的展开，其附加项$x_1y_2+x_2y_1$是非负的。 随后的每个估计仅取决于正性和边和不等式，因此不存在隐藏的几何假设。 

## 替代方法

 可以应用仿射变换将一个矩形发送到一个单位正方形。 仿射图保留面积和凸度的比率。 第二个矩形变成面积相等的平行四边形。 八相交条件意味着公共区域是正方形去除四个角三角形得到的八边形。 在此模型中，边和关系变得特别透明，并且根据四个三角形区域的基本不等式得出相同的面积估计。 

另一种方法使用支持功能。 公共区域是中心对称的八边形。 八相交条件意味着该八边形的相对边位于两个矩形的相对边上。 将其面积写为从中心到支撑线的距离并应用混合面积不等式会产生更强有力的声明，即公共面积仅在限制配置中最小化，其中公共面积从上方接近矩形面积的一半。 初等三角形论证更可取，因为它仅使用由八个交点强制的几何形状，并避免凸几何形状的机制。
