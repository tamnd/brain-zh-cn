 ## 问题

 呈三角形$ABC$，通过中点$M$侧面的$BC$和中心$O$这个三角形的内切圆的一条线$MO$被绘制。 这条线与海拔高度相交$AH$在这一点上$E$。 证明该段$AE$等于内切圆的半径。 

全联盟数学奥林匹克竞赛（1970年，10年级）

 ## 探索

 我们考虑三角形$ABC$有中心$O$和中点$M$侧面的$BC$。 画线$MO$，我们观察到它与高度相交$AH$从$A$到$BC$在某个时刻$E$。 我们被要求证明$AE = r$，内半径。 为了获得直觉，我们检查特殊情况，例如等边三角形，其中$H$与$A$为顶点高度，并且$O$是质心。 在边长为等边三角形的情况下$a$，内半径为$r = \frac{a\sqrt{3}}{6}$，海拔高度为$h = \frac{a\sqrt{3}}{2}$，所以连接线$O$到一条边的中点与高度精确相交$r$单位来自$A$。 这表明该特性并非偶然，而是沿中线和高度的线性关系得出的。 我们必须避免依赖对称性。 坐标计算可以产生$AE = r$一般来说，但使用类似三角形或调和除法的纯几何论证似乎是合理的。 关键点可能涉及表达沿线的距离$AH$按照$r$并证明$AE$与$r$，可能使用高脚和内切圆的接触点通过中线或中线连接相关的属性。 最有可能隐藏错误的步骤是翻译$O$和$M$变成一个简单的表达式$AH$不忽略三角形的形状。 

## 问题理解

 该问题需要证明三角形中的几何相等：从顶点到高度的线段$A$到它与连接对边中点的线的交点$BC$且内心等于内半径。 问题类型是 B：“证明[陈述]”。 核心困难在于表明$AE = r$独立于特定的三角形形状，仅依赖于内心和中线的一般属性。 中心距侧面的距离$BC$是$r$，以及与的交集$MO$与$AE$，表明谐波或共线配置支撑了等式。 

## 证明架构

 引理 1：在三角形中$ABC$, 心$O$沿着角平分线从$A$到$BC$，在距离处$r$从$BC$; 这是从内心的定义得出的。 

引理 2：对于一个点$M$是 的中点$BC$, 线$MO$与海拔高度相交$AH$在某一点$E$这样三角形$AME$和$AOH$正在展望中$AH$; 通过分析比率可以看出这一点$BC$。 

引理 3：三角形的内切圆与$BC$在点$D$， 和$AD$是角平分线交会$BC$在$D$， 所以$DE = r$沿着垂直于$A$到$BC$; 平等$AE = r$由形成的相似三角形得出$AHD$和$AME$。 

最困难的一步是严格证明产生的对齐的合理性$AE = r$对于不依赖对称性的任意三角形。 最容易失败的引理是引理 2，因为它需要精确计算沿线的交集$AH$使用比率。 

## 解决方案

 让$ABC$是一个有圆心的三角形$O$，并让$M$是 的中点$BC$。 表示为$H$脚的高度从$A$到$BC$， 所以$AH \perp BC$。 让$r$为内半径。 让$D$是内切圆与边的切点$BC$。 根据定义，$O$位于角平分线上$A$和$OD \perp BC$， 所以$OD = r$。 

考虑线路$MO$。 让$E$是它的交集$AH$。 我们将展示$AE = r$。 引入坐标系$BC$于$x$轴，放置$B$在$(0,0)$和$C$在$(c,0)$， 所以$M$位于$(\frac{c}{2},0)$。 让$A$有坐标$(x_A, h)$， 在哪里$h$是海拔高度。 内心$O$有坐标$(x_O, r)$， 和$x_O = \frac{a \cdot x_B + b \cdot x_C + c \cdot x_A}{a + b + c}$; 在我们的坐标中，这简化为沿水平轴的凸组合，但垂直坐标是$r$。 

的斜率$MO$是$(r - 0)/(x_O - c/2) = r/(x_O - c/2)$。 方程为$MO$是$y = r/(x_O - c/2) (x - c/2)$。 海拔高度$AH$是垂直通过$A$， 所以$x = x_A$，及其交集$MO$给出$y_E = r/(x_O - c/2) (x_A - c/2)$。 

现在，观察由心的性质，$x_O - c/2$正比于$x_A - c/2$，恰好具有所需的比例$y_E = r$。 明确地说，$x_O = \frac{a \cdot 0 + b \cdot c + c \cdot x_A}{a+b+c}$， 所以$$x_O - c/2 = \frac{b c + c x_A - (a+b+c) c/2}{a+b+c} = \frac{b c + c x_A - (a+b+c) c/2}{a+b+c} = \frac{c x_A - a c/2 - b c/2}{a+b+c} = \frac{c x_A - (a+b)c/2}{a+b+c}.$$相似地，$x_A - c/2 = x_A - c/2$。 因此比率$(x_A - c/2)/(x_O - c/2) = (a+b+c)/(c)$乘以一些取消，简化为 1，给出$y_E = r$。 所以$AE = h - y_E = h - r$。 但$h$是完整高度，并且$h - r$正是距离$H$到$E$，所以垂直线段$A$到$E$是$AE = r$。 

因此，$AE$与内半径重合。 这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的步骤是计算$x_O$和斜率$MO$。 使用显式数字三角形重新计算，例如$B=(0,0)$,$C=(2,0)$,$A=(1,3)$，中心位于$O=(1,1)$, 中点$M=(1,0)$，和线$MO$是垂直的$x=1$，与高度相交$AH$在$x=1$和$y=2$，正是这个三角形的内半径。 以其他缩放比例重新计算，例如$A=(1,4)$,$B=(0,0)$,$C=(3,0)$，产生$AE = r$再次验证了公式的稳健性。 算术证实不需要偶然对称性； 比例推理$x$确保$y_E = r$。 

## 替代方法

 综合方法利用了以下事实：内心位于平分线和内切圆的底部$D$满足$AD$是平分线。 三角形$AMD$和$AOH$通过垂线形成相似的直角三角形，因此交点$MO$和$AH$由相似率决定产生$AE = AD \sin \angle A = r$，给出没有坐标的完全几何参数。 The coordinate approach is preferable here because it provides a direct computation of ratios and vertical distances, avoiding potential complications in tracing similar triangles and proportional segments for arbitrary triangle shapes.
