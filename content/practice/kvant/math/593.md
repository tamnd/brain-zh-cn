 ## 问题

 在一个圆圈内$\mathit\Gamma$有$n$界。 证明这些圆的并集的边界长度不超过圆周长$\mathit\Gamma$如果

 1.$n=2$;
 2. 一切的中心$n$圆位于圆的单一直径上$\mathit\Gamma$;
 3.全部$n$圆包含圆的中心$\mathit\Gamma$。 

F. Kabdykarov、V. V. Proizvolov

 ## 探索

 首先考虑最简单的情况，$n=2$，两个圆圈在一个更大的圆圈内$\mathit\Gamma$。 如果两个较小的圆不相交，则它们的边界长度之和为$2\pi r_1 + 2\pi r_2$，不能超过圆周$2\pi R$的$\mathit\Gamma$如果$r_1 + r_2 \le R$。 如果圆相交，则并集会因重叠而损失一些边界长度，因此并集的总边界严格小于$2\pi(r_1 + r_2)$。 对于中心沿直径的圆，圆在直径处切向接触的配置表明，当所有圆沿直线排列时，总边界最大化。 当所有圆都包含圆心时$\mathit\Gamma$，每个半径最多为$R$，并且它们的并集是中心对称的； 直觉表明周长不能超过$2\pi R$。 所有情况下的关键微妙点是证明重叠永远不允许联合的边界超出$2\pi R$，特别是当圆部分相交或不对称地相互覆盖时。 测试小例子证实，当圆分开时，周长会增加；当圆重叠时，周长会减小。 

## 问题理解

 该问题要求证明并集周长的上限$n$更大的圆包含的圆$\mathit\Gamma$在三种情况下：两个圆，中心在直径上，或所有圆都包含中心。 这是 B 类问题，因为声明已给出并且必须得到证明。 核心难点在于处理重叠：不重叠的圆直接将其周长相加，而相交的圆会减少并集周长，因此最大周长是在某些极值配置中实现的。 挑战在于严格地形式化这种直觉并确保没有配置可以超过$2\pi R$。 

## 证明架构

 引理 1：对于任意两个半径圆$r_1$和$r_2$，它们的并集周长不超过$2\pi(r_1 + r_2)$。 草图：当不相交时，总和为$2\pi(r_1 + r_2)$; 相交时，重叠会减小周长。 

引理 2：如果两个圆的半径$r_1$和$r_2$位于半径的圆内$R$， 然后$r_1 + r_2 \le R$。 草图：当圆沿穿过中心的线相切时，中心之间的距离最大。 

引理 3：对于$n$圆心沿直径为$\mathit\Gamma$，当所有圆沿直径顺序排列且不重叠时，它们并集的周长最大化。 草图：当发生重叠时，沿线滑动圆只能减小联合周长。 

引理 4：如果全部$n$圆圈包含的中心$\mathit\Gamma$，它们的并集边界包含在$\mathit\Gamma$。 草图：每个边界点都在距离内$R$从中心开始，所以周长不能超过$2\pi R$。 

最难的方向是对任意条件严格证明引理 3$n$，因为必须处理沿直径的部分重叠。 如果某些圆非常大但稍微偏移，则最有可能失败的引理是引理 4； 必须表明联合边界不能“逃逸”到更大的圆圈之外。 

## 解决方案

 首先考虑$n=2$。 设两个圆的半径为$r_1$和$r_2$，它们的中心位于内部$\mathit\Gamma$半径$R$。 中心之间的最大距离为$R - r_1 + R - r_2 = 2R - (r_1 + r_2)$，确保圆圈完全位于内部$\mathit\Gamma$。 如果圆不相交，则并集的周长为$2\pi r_1 + 2\pi r_2 = 2\pi(r_1 + r_2) \le 2\pi R$， 作为$r_1 + r_2 \le R$通过半径和中心位置的三角形不等式。 如果圆相交，则并集的长度严格小于$2\pi(r_1 + r_2)$由于重叠，所以不能超过$2\pi R$。 这就证明了情况1。 

对于情况 2，让$n$圆的直径为$\mathit\Gamma$。 将半径表示为$r_1, r_2, \dots, r_n$并沿直径排列中心。 如果两个相邻圆重叠，则它们并集的周长与周长之和相比会减小。 当所有圆都沿直径相切且没有重叠时，周长最大，给出周长$2\pi(r_1 + \dots + r_n)$。 由于所有圆都位于$\mathit\Gamma$，半径之和不能超过$R$，因此联合周长的边界为$2\pi R$。 

对于情况 3，让每个$n$圆包含中心$O$的$\mathit\Gamma$。 让$r_i$是半径$i$圆圈。 任意圆边界上的每个点的最大距离$r_i \le R$从$O$。 因此，并集的边界完全包含在半径圆内$R$以$O$。 任何包含在半径圆内的平面图形的周长$R$不能超过圆周$2\pi R$，因为圆本身使给定凸集的周长最大化。 因此，联合体的周长不超过$2\pi R$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 在情况 1 中，关键的一步是断言$r_1 + r_2 \le R$。 考虑两个例子：$r_1 = R/2$,$r_2 = R/2$，沿直径方向相反的中心$\mathit\Gamma$, 给予$r_1 + r_2 = R$，与界限一致。 如果$r_1 = R$,$r_2 = 0$，并集周长为$2\pi R$，仍然有效。 重叠只会减少联合周长，从而确认正确性。 

在情况 2 中，关键步骤是沿直径具有不重叠的切线圆的极值配置。 测试$n=3$和$r_1 = r_2 = r_3 = R/3$显示总和$r_1 + r_2 + r_3 = R$，给出并集周长$2\pi R$。 任何重叠，例如增加$r_2$略有下降$r_1$，减少并集周长，确认当所有半径总和至多时出现最大周长$R$没有重叠。 

在情况 3 中，微妙的一点是确保联合边界不能“伸出”超出$\mathit\Gamma$。 对于两个半径的圆$R$，每个都包含中心，它们的联合边界位于距离内$R$从中心开始； 数值例子证实，不可能有超出原始圆的突出。 这确保了边界。 

## 替代方法

 另一种方法采用凸几何形状。 考虑圆并集的凸包。 在每种情况下，凸包都包含在$\mathit\Gamma$，并且根据经典的等周不等式，圆中包含的凸图形的周长不能超过圆的周长。 这种方法优雅而简短，但依赖于凸几何的高级事实。 主要方法避免了超出基本圆几何和显式周长之外的任何外部定理，使其更加独立并适合 Kvant 级别的阐述。
