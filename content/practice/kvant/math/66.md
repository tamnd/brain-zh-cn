 ## 问题

 下面是一些例子，其中平方和$k$连续的自然数等于下一个自然数的平方和$k-1$自然数：$$\begin{gathered} 3^2+4^2=5^2,\\ 36^2+37^2+38^2+39^2+40^2=41^2+42^2+43^2+44^2,\\ 55^2+56^2+57^2+58^2+59^2+60^2=61^2+62^2+63^2+64^2+65^2. \end{gathered}$$找到一个涵盖所有此类情况的通用公式。 

A·I·米洛瓦诺夫

 ## 探索

 考虑给出的例子：$3^2 + 4^2 = 5^2$,$36^2 + 37^2 + 38^2 + 39^2 + 40^2 = 41^2 + 42^2 + 43^2 + 44^2$， 和$55^2 + 56^2 + 57^2 + 58^2 + 59^2 + 60^2 = 61^2 + 62^2 + 63^2 + 64^2 + 65^2$。 在每种情况下，平方和为$k$连续整数等于的平方和$k-1$紧随其后的连续整数。 将左侧总和的第一个数字表示为$n$和项数$k$。 然后右边的总和开始于$n+k$。 将正确总和中的项数表示为$k-1$。 方程变为$$n^2 + (n+1)^2 + \dots + (n+k-1)^2 = (n+k)^2 + (n+k+1)^2 + \dots + (n+2k-2)^2.$$使用连续整数平方和的公式扩展每个和，简化为二次$n$和$k$。 测试小值表明之间存在线性关系$n$和$k$，但更大的例子表明通解涉及寻找丢番图方程的整数解。 挑战在于表达$n$和$k$用一个简单的公式捕获所有解决方案。 

## 问题理解

 该问题要求找到所有连续自然数的序列，使得$k$连续的数字等于下一个数字的平方和$k-1$数字。 这是一个 A 类问题：“查找所有 X”。 核心困难是将平方和条件转化为可解的丢番图方程，并确定产生所有解的通用公式。 直观上，序列的第一个数字大致与$k$，但必须确定确切的整数关系。 

## 证明架构

 引理 1： 的平方和$m$开始于的连续整数$a$由下式给出$$\sum_{i=0}^{m-1} (a+i)^2 = m a^2 + m(m-1)a + \frac{m(m-1)(2m-1)}{6}.$$引理 2：使平方和相等$k$开始于的数字$n$的平方和$k-1$开始于的数字$n+k$产生一个二次方$n$，可以显式求解整数解。 

引理 3：整数的通解$n$和$k$是$$n = \frac{k(2k-1)}{2}, \quad \text{with } k \ge 2.$$最难的部分是证明该公式产生所有解并且不存在其他整数解，特别是因为二次丢番图方程可能具有隐藏的无关根。 

## 解决方案

 让$n$是左侧总和中的第一个数字并且$k$术语的数量。 的平方和$k$开始于的连续整数$n$是$$\sum_{i=0}^{k-1} (n+i)^2 = k n^2 + n k(k-1) + \frac{k(k-1)(2k-1)}{6}.$$下一个的平方和$k-1$起始于的整数$n+k$是$$\sum_{i=0}^{k-2} (n+k+i)^2 = (k-1)(n+k)^2 + (n+k)(k-1)(k-2) + \frac{(k-1)(k-2)(2k-3)}{6}.$$使两个总和相等得出$$k n^2 + k(k-1)n + \frac{k(k-1)(2k-1)}{6} = (k-1)(n+k)^2 + (k-1)(k-2)(n+k) + \frac{(k-1)(k-2)(2k-3)}{6}.$$展开右侧：$$(k-1)(n+k)^2 = (k-1)(n^2 + 2kn + k^2) = (k-1)n^2 + 2k(k-1)n + k^2(k-1),$$

$$(k-1)(k-2)(n+k) = (k-1)(k-2)n + (k-1)(k-2)k = (k-1)(k-2)n + k(k-1)(k-2),$$

$$\frac{(k-1)(k-2)(2k-3)}{6} \text{ remains.}$$总结这些术语：$$(k-1)n^2 + [2k(k-1) + (k-1)(k-2)] n + k^2(k-1) + k(k-1)(k-2) + \frac{(k-1)(k-2)(2k-3)}{6}.$$简化系数：$$n^2 + 3k - 2?? \text{Better to compute carefully: } 2k(k-1)+(k-1)(k-2)=2k^2-2k + k^2-3k +2 = 3k^2 -5k +2.$$同样，常量：$k^2(k-1)+k(k-1)(k-2)+\frac{(k-1)(k-2)(2k-3)}{6}$。 

逐步计算：

 1.$k^2(k-1) = k^3 - k^2$。 
2.$k(k-1)(k-2) = k(k^2 -3k +2) = k^3 -3k^2 + 2k$。 
3.$\frac{(k-1)(k-2)(2k-3)}{6} = \frac{(2k^3 -7k^2 +11k -6)}{6} = \frac{1}{3} k^3 - \frac{7}{6} k^2 + \frac{11}{6} k -1$。 

总和常数：$(k^3 - k^2) + (k^3 -3k^2 +2k) + (\frac{1}{3} k^3 - \frac{7}{6} k^2 + \frac{11}{6} k -1) = \frac{7}{3} k^3 - \frac{25}{6} k^2 + \frac{23}{6} k -1$。 

左侧常数：$\frac{k(k-1)(2k-1)}{6} = \frac{2k^3 -3k^2 + k}{6} = \frac{1}{3} k^3 - \frac{1}{2} k^2 + \frac{1}{6} k$。 

系数$n^2$:$k - (k-1) =1$。 系数$n$:$k(k-1) - (3k^2 -5k +2) = k^2 - k - (3k^2 -5k +2) = -2k^2 +4k -2 = -2(k-1)^2$。 

常数：$\frac{1}{3} k^3 - \frac{1}{2} k^2 + \frac{1}{6} k - (\frac{7}{3} k^3 - \frac{25}{6} k^2 + \frac{23}{6} k -1) = -2 k^3 + 3 k^2 -3k +1 = -(2k-1)(k-1)^2$。 

因此，二次方程简化为$$n^2 - 2(k-1)^2 n - (2k-1)(k-1)^2 =0.$$使用二次公式求解：$$n = \frac{2(k-1)^2 \pm \sqrt{4(k-1)^4 + 4(2k-1)(k-1)^2}}{2} = (k-1)^2 \pm (k-1)\sqrt{(k-1)^2 + 2k -1}.$$化简平方根：$(k-1)^2 + 2k -1 = k^2$。 

因此，$\sqrt{k^2} = k$， 所以$$n = (k-1)^2 \pm k(k-1) = (k-1)^2 + k(k-1) = (k-1)(k-1+k) = (k-1)(2k-1),$$或者$n = (k-1)^2 - k(k-1) = (k-1)(k-1 - k) = -(k-1)$，它是负数并且不是自然数。
