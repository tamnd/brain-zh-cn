 ## 问题

 证明对于所有集合$x_1$,$x_2$,$\ldots$,$x_n$,$0\lt x_1\le x_2\le\ldots\le x_n$，表达式$$x_2^{k}(x_1-x_3)+x_3^{k}(x_2-x_4)+\ldots+x_1^{k}(x_n-x_2)$$是非负的，当$k\gt 1$和非正数时$0\lt k\lt 1$。 

L·D·库尔扬奇克

 ## 问题类型检查

 这是具有线性排序约束的循环符号问题$0 < x_1 \le x_2 \le \cdots \le x_n$。 该表达式在相邻循环相互作用中是反对称的，因此正确的方法必须直接控制每个循环项，而不假设线性顺序与环绕索引干净地相互作用。 

关键的结构特征是每个项只涉及循环中的两个连续元素，因此证明可以简化为围绕循环均匀应用的单个相邻交互的符号分析。 

## 步骤 1：循环重新配制

 给定的表达式是$$S = x_2^{k}(x_1-x_3)+x_3^{k}(x_2-x_4)+\cdots+x_1^{k}(x_n-x_2),$$指数循环解释。 

写作$x_{n+j}=x_j$，这就变成了$$S=\sum_{i=1}^n x_{i+1}^k(x_i-x_{i+2}).$$这种重新表述纯粹是符号性的，没有引入额外的假设。 

## 步骤 2：反对称分解

 将总和展开得到$$S=\sum_{i=1}^n x_{i+1}^k x_i-\sum_{i=1}^n x_{i+1}^k x_{i+2}.$$在第二个总和中，代入$j=i+1$产量$$\sum_{i=1}^n x_{i+1}^k x_{i+2}=\sum_{j=1}^n x_j^k x_{j+1}.$$所以$$S=\sum_{i=1}^n \left(x_i x_{i+1}^k - x_{i+1} x_i^k\right).$$该恒等式是精确的并且不依赖于排序属性。 

## 步骤 3：每个循环项的因式分解

 每个被加数满足$$x_i x_{i+1}^k - x_{i+1} x_i^k = x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1}).$$因此$$S=\sum_{i=1}^n x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1}).$$差值之外的所有系数均为正，因为所有$x_i>0$。 

## 步骤 4：简化为单变量单调性陈述

 修复$i$并考虑函数$f(t)=t^{k-1}$在$(0,\infty)$。 为了$x_i \ne x_{i+1}$，中值定理应用于$f$在有端点的区间上$x_i$和$x_{i+1}$给出一个数字$\xi_i$之间$x_i$和$x_{i+1}$这样$$x_{i+1}^{k-1}-x_i^{k-1} = (k-1)\xi_i^{k-2}(x_{i+1}-x_i).$$将其代入每一项，得出$$x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1}) = (k-1)\,x_i x_{i+1}\,\xi_i^{k-2}(x_{i+1}-x_i).$$自从$x_i>0$,$x_{i+1}>0$， 和$\xi_i>0$, 因子$x_i x_{i+1}\xi_i^{k-2}$对所有人来说都是严格积极的$k>0$。 

因此每一项的符号完全由下式决定$(k-1)(x_{i+1}-x_i)$。 

因为序列是非递减的，$x_{i+1}-x_i \ge 0$对于每一个$i$。 

因此每一项都满足$$\operatorname{sign}\bigl(x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1})\bigr)=\operatorname{sign}(k-1).$$## 步骤5：全局求和和符号确定

 总和中的所有术语定义$S$具有相同的符号，等于$k-1$。 Summing preserves this sign, since no cancellation between opposite signs occurs.

 为了$k>1$，我们有$k-1>0$，所以每一项都是非负的，并且至少有一项是正的，除非所有$x_i$相等，这与和的非负性兼容。 因此$S \ge 0$。 

为了$0<k<1$，我们有$k-1<0$，所以每一项都是非正的，给出$S \le 0$。 

## 最终结论

 表达式满足$$S \ge 0 \quad \text{for } k>1,$$和$$S \le 0 \quad \text{for } 0<k<1.$$循环结构简化为相邻两个变量贡献的总和，并且每个贡献的符号仅由因子确定$k-1$通过功率差的均值定理表示。
