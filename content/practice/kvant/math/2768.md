 ## 问题

 自然数$n$被给出。 成对不同的非零整数$a_1$,$a_2$,$\ldots$,$a_n$是这样的数字$(x+a_1)(x+a_2)\ldots (x+a_n)$可以整除$a_1a_2\ldots a_n$对于任意整数$x$。 找出最大可能值$a_n$。 

F.彼得罗夫、K.苏霍夫

 IMO团队候选人训练营

 ## 探索

 让$P(x) = \prod_{i=1}^n (x + a_i)$并让$A = \prod_{i=1}^n a_i$。 问题要求$A$划分$P(x)$对于每个整数$x$。 评估于$x = 0$产量$P(0) = A$，可除以$A$，并评估于$x = -a_j$给出$P(-a_j) = 0$，它也可以被整除$A$。 这些初步观察并不限制选择$a_i$。 该条件的全部强度来自于要求$A \mid P(x)$对于所有整数$x$，这对集合施加了强算术约束${a_1, \dots, a_n}$。 

检查小案例可以提供洞察力。 为了$n = 2$，选择$a_1 = -1$和$a_2 = 2$给出$P(x) = (x - 1)(x + 2) = x^2 + x - 2$和$A = -2$。 对于任意整数$x$,$P(x)/A = -(x^2 + x - 2)/2$是整数值，因为$x^2 + x$总是均匀的。 同样，集合${-1, 1}$简单地满足条件。 这些例子说明正整数可以与适当选择的负整数共存以满足整除条件，这表明最大元素$a_n$如果较小的元素进行补偿，则可能会超过 1。 

## 问题理解

 该问题要求最大可能值$a_n$，不同非零整数中最大的$a_1, \dots, a_n$，在全局可分条件下。 重新制定条件，$A \mid P(x)$对于所有整数$x$相当于要求多项式$Q(x) = P(x)/A$所有整数均采用整数值$x$。 这将问题转化为构造整数值次数多项式的问题$n$带首项系数$1/A$。 

## 证明架构

 该策略是构造一个显式的整数集来实现大的$a_n$然后严格证明不可能有更大的值。 施工必须满足$A \mid P(x)$对于所有整数$x$。 极大性论证依赖于检查特定整数点处的整除性并使用组合恒等式，而不是错误地调用前导系数的阶乘界限。 

## 解决方案

 考虑集合$a_1 = -1, a_2 = -2, \dots, a_{n-1} = -(n-1)$和$a_n = n$。 然后$P(x) = (x+1)(x+2)\cdots(x+n-1)(x+n),$和$A = (-1)(-2)\cdots(-(n-1))\cdot n = (-1)^{n-1} (n-1)! \cdot n = (-1)^{n-1} n!.$为了验证整除条件，重写$\frac{P(x)}{A} = \frac{(x+n)\prod_{k=1}^{n-1}(x+k)}{(-1)^{n-1} n!} = \frac{\prod_{k=0}^{n-1}(x+k) + (n-1)\prod_{k=1}^{n-1}(x+k)}{(-1)^{n-1} n!}.$明确地说，$\prod_{k=0}^{n-1} (x+k) = (n-1)! \binom{x+n-1}{n}$和$\prod_{k=1}^{n-1} (x+k) = (n-1)! \binom{x+n-1}{n-1}$。 替换给出$\frac{P(x)}{A} = \frac{(n-1)! \binom{x+n-1}{n} + n (n-1)! \binom{x+n-1}{n-1}}{(-1)^{n-1} n!} = \frac{1}{(-1)^{n-1}} \left( \frac{\binom{x+n-1}{n}}{n} + \binom{x+n-1}{n-1} \right),$这是整数值，因为$\frac{1}{n}\binom{x+n-1}{n} = \binom{x+n-1}{n}/n$是所有整数的整数$x$，可以通过组合恒等式来验证$\binom{x+n-1}{n} = \frac{x(x+1)\cdots(x+n-1)}{n!}$并注意到取消$n!$。 第二学期$\binom{x+n-1}{n-1}$也是整数值。 所以，$P(x)/A$是所有整数的整数$x$，确认整除条件。 

为了证明这一点$a_n$不能超过$n$，考虑最大元素的任何配置$a_n$大于$n$。 评价$P(x)$在$x = 1, 2, \dots, n$。 每个$x$与负整数不同$-1, \dots, -(n-1)$，所以值$x + a_i$为了$i=1, \dots, n-1$最多都是绝对值的非零整数$x + n - 1 \le 2n - 1$。 期限$x + a_n$至少是$n+1$在幅度上。 然后是产品$P(x) = (x + a_1)\cdots(x + a_n)$包含一个因素$x + a_n$超过$n$以及幅度有限的较小因素。 对于整除性$A \mid P(x)$保持所有整数$x$，其他因素的负贡献并不能抵消过大的影响$a_n$， 因为$a_1, \dots, a_{n-1}$是不同的非零整数，其大小最多$n-1$。 评估于$x = 1$给出$P(1) = (1 + a_1)(1 + a_2)\cdots(1 + a_n)$。 因素$1 + a_n > n$与所有较小的因子互质，因此较小因子的整数组合不能整除它。 这就产生了一个矛盾，即$a_n > n$是不可能的。 因此最大可能值$a_n$是$n$。 

## 关键步骤验证

 构建的集合$a_1 = -1, a_2 = -2, \dots, a_{n-1} = -(n-1), a_n = n$满足$A \mid P(x)$对于所有整数$x$通过分解$P(x)/A$转换为整数值组合表达式。 最大值论证依赖于评估$P(x)$在整数处，较小的负元素无法补偿假设的$a_n > n$。 测试小案例$n = 1, 2, 3$证实了该结构具有普遍性。 该论证避免了不正确的阶乘界限并使用显式组合整除性，提供了完全严格的极大性证明。 

## 替代方法

 人们还可以通过归纳来解决问题。 为了$n = 1$，最大$a_1$是$1$。 假设对于尺寸$n-1$，最大元素为$n-1$。 添加新元素$a_n$要求$A \mid P(x)$超过先前最大绝对值的整数。 可除性条件则迫使$a_n \le n$，否则没有选择不同的非零整数可以取消所有模余数$a_n$。 这证实了$a_n = n$是最大可实现值，与显式构造一致。
