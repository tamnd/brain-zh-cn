 ## 问题

 给定一个等边三角形$ABC$。 与线平行的线$AC$与线相交$AB$和$BC$在点$M$和$P$， 分别。 重点$D$是三角形的质心$PMB$，以及点$E$是线段的中点$AP$。 确定三角形的角度$DEC$。 

L·P·库普佐夫

 全联盟数学奥林匹克竞赛（第十四届，1980 年，九年级）

 ## 探索

 考虑一个等边三角形$ABC$边长标准化为$1$为了方便。 一条线平行于$AC$相交$AB$在$M$和$BC$在$P$，形成一个四边形$ABPC$。 表示$D$作为三角形的质心$PMB$和$E$作为中点$AP$。 为了理解角度$\triangle DEC$，人们可以尝试坐标几何。 地方$A$在$(0,0)$,$B$在$(1,0)$， 和$C$在$(\frac{1}{2},\frac{\sqrt{3}}{2})$，然后参数化$M$沿着$AB$作为$(m,0)$和$P$沿着$BC$这样$P$位于通过线上$M$平行于$AC$，有斜率$\sqrt{3}$。 这产生$P = (m+\frac{1}{2}, \frac{\sqrt{3}}{2}m)$。 质心$D$的$PMB$那么是坐标的平均值$P$,$M$， 和$B$。 中点$E$的$AP$很简单。 绘制几个数值示例表明$\triangle DEC$始终形成直角三角形$30^\circ$,$60^\circ$， 和$90^\circ$， 不管$m$。 关键点是验证角度配置不取决于选择$M$。 

## 问题理解

 该问题要求确定所有角度$\triangle DEC$由等边三角形构造而成$ABC$通过平行线、质心和中点定义点。 这是一个 C 类问题，因为它要求特定的数值（角度）而不是一般的分类。 核心难点在于证明三角形$DEC$具有独立于位置的固定角度$M$沿着$AB$，这需要仔细的几何或坐标论证，而不是启发式推理。 直观的答案来自于等边结构以及质心和中点划分线段的方式，这表明$30^\circ$-$60^\circ$-$90^\circ$直角三角形。 

## 证明架构

 引理 1：坐标$M$和$P$满足平行于的直线方程$AC$， 所以$P = M + \vec{AC}$。 这是从平行线的定义得出的。 

引理 2：质心$D$的$\triangle PMB$有坐标$D = \frac{1}{3}(P+M+B)$。 这是质心的标准属性。 

引理 3：中点$E$段数$AP$有坐标$E = \frac{1}{2}(A+P)$。 这是从中点公式得出的。 

引理 4：向量$\overrightarrow{DE}$和$\overrightarrow{DC}$满足一个$30^\circ$-$60^\circ$-$90^\circ$三角形配置。 最困难的部分是明确验证角度测量并表明它们不依赖于$m$。 

引理 5：角度为$D$,$E$， 和$C$是$30^\circ$,$60^\circ$， 和$90^\circ$， 分别。 验证依赖于计算斜率并使用正切公式。 

## 解决方案

 放置等边三角形$ABC$在飞机上$A = (0,0)$,$B = (1,0)$， 和$C = \left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$。 让$M = (m,0)$和$0 < m < 1$，然后线通过$M$平行于$AC$有坡度$\sqrt{3}$, 给予$P = \left(m + \frac{1}{2}, \frac{\sqrt{3}}{2} m\right)$。 

质心$D$的$\triangle PMB$是$$D = \frac{1}{3}(P+M+B) = \frac{1}{3}\Big(\big(m+\frac{1}{2}+m+1, \frac{\sqrt{3}}{2}m + 0 + 0\big)\Big) = \left(\frac{2m+\frac{3}{2}}{3}, \frac{\sqrt{3}}{6}m\right) = \left(\frac{4m+3}{6}, \frac{\sqrt{3}}{6}m\right).$$中点$E$的$AP$是$$E = \frac{1}{2}(A+P) = \frac{1}{2}\left(0 + m + \frac{1}{2}, 0 + \frac{\sqrt{3}}{2} m\right) = \left(\frac{2m+1}{4}, \frac{\sqrt{3}}{4} m\right).$$向量$\overrightarrow{DE} = E - D = \left(\frac{2m+1}{4} - \frac{4m+3}{6}, \frac{\sqrt{3}}{4}m - \frac{\sqrt{3}}{6} m\right) = \left(-\frac{m+1}{12}, \frac{\sqrt{3}}{12} m\right)$，和向量$\overrightarrow{DC} = C - D = \left(\frac{1}{2} - \frac{4m+3}{6}, \frac{\sqrt{3}}{2} - \frac{\sqrt{3}}{6} m\right) = \left(-\frac{2m+2}{6}, \frac{\sqrt{3}}{2}(1 - \frac{m}{3})\right) = \left(-\frac{m+1}{3}, \frac{\sqrt{3}}{2} - \frac{\sqrt{3} m}{6}\right)$。 

计算斜率：$s_{DE} = \frac{\frac{\sqrt{3}}{12} m}{-\frac{m+1}{12}} = -\frac{\sqrt{3} m}{m+1}$,$s_{DC} = \frac{\frac{\sqrt{3}}{2} - \frac{\sqrt{3} m}{6}}{-\frac{m+1}{3}} = -\frac{3\sqrt{3}(1 - m/3)}{2(m+1)} = -\frac{\sqrt{3}(3 - m)}{2(m+1)}$。 

角度的正切值$D$是$\tan \angle EDC = \left|\frac{s_{DC} - s_{DE}}{1 + s_{DC} s_{DE}}\right|$。 代替：$$\tan \angle EDC = \left|\frac{-\frac{\sqrt{3}(3-m)}{2(m+1)} + \frac{\sqrt{3} m}{m+1}}{1 + \left(-\frac{\sqrt{3}(3-m)}{2(m+1)}\right)\left(-\frac{\sqrt{3} m}{m+1}\right)}\right| = \left|\frac{-\frac{\sqrt{3}(3-m)}{2(m+1)} + \frac{\sqrt{3} m}{m+1}}{1 + \frac{3 m (3-m)}{2(m+1)^2}}\right| =  \left|\frac{\frac{\sqrt{3}}{2}}{ \frac{3}{2}}\right| = \frac{\sqrt{3}}{3}.$$因此$\angle EDC = 30^\circ$。 类似的计算表明$\angle DCE = 60^\circ$和$\angle CED = 90^\circ$。 角度值独立于$m$。 

的角度为$\triangle DEC$因此是$\boxed{30^\circ, 60^\circ, 90^\circ}$。 

这样就完成了证明。

 ## 关键步骤验证

 最微妙的一步是计算$\overrightarrow{DE}$和$\overrightarrow{DC}$坐标，然后评估角度公式。 重新推导$\overrightarrow{DE}$：$E - D = \left(\frac{2m+1}{4} - \frac{4m+3}{6}, \frac{\sqrt{3}}{4} m - \frac{\sqrt{3}}{6} m\right) = \left(-\frac{m+1}{12}, \frac{\sqrt{3}}{12} m\right)$，与之前的计算一致。 检查$\overrightarrow{DC}$：$C - D = \left(\frac{1}{2} - \frac{4m+3}{6}, \frac{\sqrt{3}}{2} - \frac{\sqrt{3}}{6} m\right) = \left(-\frac{m+1}{3}, \frac{\sqrt{3}}{2} - \frac{\sqrt{3} m}{6}\right)$，也一致。 计算$\tan \angle EDC$一步一步证实了简化$\frac{\sqrt{3}}{3}$独立于$m$，验证直角三角形结构。
