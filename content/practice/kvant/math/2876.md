 ## 问题

 让$f_{a,b}(x)=[ax+b]$。 对于哪些实数对$a\gt0$和$b$是否存在真实的$c\gt0$和$d$这样对于所有自然的$n$平等$f_{c,d}\big(f_{a,b}(n)\big)=n$持有？ 

I·多罗费耶夫

 南方数学锦标赛（XX）

 ## 探索

 我们研究形式的功能$f_{a,b}(n)=\lfloor an+b\rfloor$和$a>0$作用于$\mathbb{N}$。 

条件$$f_{c,d}(f_{a,b}(n))=n \quad \text{for all } n\in\mathbb{N}$$意味着$f_{a,b}$是单射的$\mathbb{N}$和$f_{c,d}$它的逆是$\mathbb{N}$。 因此$f_{a,b}$必须是双射$\mathbb{N}\to\mathbb{N}$。 

因此，问题简化为对排列的仿射楼层图进行分类$\mathbb{N}$并且其逆也是相同的形式。 

主要的张力在于增长和离散之间。 如果$a>1$，价值增长太快并留下缺口。 如果$0<a<1$，值重复并破坏单射性。 唯一可行的候选人是$a=1$， 在哪里$f(n)=\lfloor n+b\rfloor$，其行为类似于转变。 微妙之处在于非整数移位是否仍然可以是变相的双射，或者除零之外的整数移位是否可以与相同形式的逆相兼容。 

决定性的一步是证明双射性同时迫使单射性和满射性，消除所有重要的转变。 

## 问题理解

 这是一个 A 类问题。 我们必须确定所有对$(a,b)$对于其中存在$c>0$和$d$这样$$\lfloor c\lfloor an+b\rfloor + d\rfloor = n \quad \text{for all } n\in\mathbb{N}.$$组成条件力$f_{a,b}$是一个双射$\mathbb{N}$也具有仿射地板类型的逆。 关键的困难是当底线性映射可以无间隙或重复地排列所有自然数时进行分类。 

预期的结论是，只有恒等映射才能经受住这些刚性约束。 

## 证明架构

 第一个引理断言存在$c,d$意味着$f_{a,b}$是双射的$\mathbb{N}$，因为它具有由另一个函数给出的两侧逆。 

第二个引理证明如果$f_{a,b}(n)=\lfloor an+b\rfloor$是单射的$\mathbb{N}$， 然后$a\le 1$， 自从$a>1$强制严格扩张并创造间隙，同时$a<1$强制重复。 

第三个引理表明，如果$a=1$， 然后$f(n)=\lfloor n+b\rfloor$仅当$b=0$，因为任何非零位移都会破坏满射性$\mathbb{N}$。 

最困难的一步是排除异国取消的情况$a\ne 1$但地板可能会人为地恢复双射性。 

## 解决方案

 假设存在$c>0$和$d\in\mathbb{R}$这样对于所有$n\in\mathbb{N}$,$$\lfloor c\lfloor an+b\rfloor + d\rfloor = n.$$表示$f(n)=\lfloor an+b\rfloor$和$g(x)=\lfloor cx+d\rfloor$。 那么条件是$g(f(n))=n$为所有人$n\in\mathbb{N}$。 

### 步骤 1：双射性$f$在$\mathbb{N}$对于每一个$n$，值$n$在于形象$g$仅限于$f(\mathbb{N})$。 自从$g$是在所有整数上定义的函数，其恒等式$g(f(n))=n$意味着$f(n_1)=f(n_2)$会产生$$n_1=g(f(n_1))=g(f(n_2))=n_2,$$所以$f$是单射的$\mathbb{N}$。 

对于满射性，对于每一个$n$存在$m=f(n)$这样$g(m)=n$。 因此每一个$n$是在图像中$g\circ f$，并且自从$g$是在整数上定义的，这迫使$f(\mathbb{N})$只包含一个原像$g$对于每个$n$， 所以$f$必须映射$\mathbb{N}$到一个无限子集上$g$是单射的并且涵盖了所有$\mathbb{N}$。 尤其，$f$是之间的双射$\mathbb{N}$和$f(\mathbb{N})$， 和$g$限制为其倒数。 因此$f$是一个双射$\mathbb{N}\to\mathbb{N}$。 

因此$f$是一个排列$\mathbb{N}$。 

### 第 2 步：排除$a>1$如果$a>1$， 然后$$f(n+1)-f(n)\ge \lfloor a(n+1)+b\rfloor - (a n + b -1)$$至少意味着渐近增长$a$，所以增量至少是$1$经常并最终严格大于$1$无限频繁。 更直接地说，对于任意$n$,$$f(n+1)\ge a(n+1)+b-1 = an+b + (a-1).$$自从$a-1>0$，对于所有足够大的$n$,$$f(n+1)\ge f(n)+1,$$事实上，严格增长是有间隙的。 因此，该图像省略了无限多个整数，与排列的满射性相矛盾$\mathbb{N}$。 因此$a\le 1$。 

### 第 3 步：排除$0<a<1$如果$0<a<1$，那么对于所有$n$,$$an+b \le a(n+1)+b < an+b+1.$$因此$\lfloor an+b\rfloor$要么是常数，要么是在任意长的时间间隔内重复值，所以$f(n)=f(n+1)$对于无穷多个$n$，矛盾的单射性。 因此$a\ge 1$。 

从第 2 步和第 3 步，我们得出结论$a=1$。 

### 第 4 步：确定$b$现在$f(n)=\lfloor n+b\rfloor$。 写$b=k+\varepsilon$和$k\in\mathbb{Z}$和$\varepsilon\in[0,1)$。 

然后$$f(n)=\lfloor n+k+\varepsilon\rfloor = n+k.$$如果$k\ne 0$， 然后$f(\mathbb{N})=\mathbb{N}+k$，缺少第一个$k$正整数，当$k>0$或 包含非正整数时$k<0$，所以它不是一个排列$\mathbb{N}$。 自从$f$必须是双射$\mathbb{N}$，我们得到$k=0$， 因此$b=0$。 

因此$f(n)=n$。 

### 第 5 步：存在$c,d$如果$f(n)=n$，然后选择$c=1$和$d=0$给出$$\lfloor c\lfloor n\rfloor + d\rfloor = n,$$所以条件满足。 

因此唯一可接受的对是$(a,b)=(1,0)$。$$\boxed{(a,b)=(1,0)}$$## 关键步骤验证

 排除$a>1$依赖于增长估计$f(n+1)\ge f(n)+1$最终，这会导致图像中出现无限的间隙； 任何这样的差距都与排列的满射性相矛盾$\mathbb{N}$。 

排除$0<a<1$取决于不平等$an+b< a(n+1)+b<an+b+1$，它保证两个连续整数无限频繁地共享相同的下限值，这与单射性相矛盾。 

减少量从$b=k+\varepsilon$到$f(n)=n+k$利用这样一个事实：当应用于整数时，添加小数部分不会影响下限。 

## 替代方法

 人们可以通过密度来争论：渐近密度${\lfloor an+b\rfloor}$等于$1/a$。 由于排列$\mathbb{N}$必须有密度$1$，这迫使$a=1$，之后整数移位分析产生$b=0$。 另一种方法使用 Beatty 序列理论来表明任何非平凡的缩放都会产生互补分区而不是排列，再次将身份隔离为唯一的可能性。
