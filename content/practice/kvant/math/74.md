 ## 问题

 多项式$p$具有以下性质： 对于某些数$a$,$$p(x)=p(a-x).$$证明$p(x)$可以表示为多项式$$\left(x-\frac{a}{2}\right)^2.$$。 

例如，如果$p(x)=x^5+(1-x)^5$，那么显然$p(x)=p(1-x)$并且，很容易验证，$$p(x)=5y^2+\frac{5}{2}y+\frac{1}{16},$$在哪里$$y=\left(x-\frac{1}{2}\right)^2.$$。 

## 探索

 考虑使用小次多项式来检测模式。 对于零度，常数函数$p(x)=c$微不足道地满足$p(x)=p(a-x)$并且已经是一个函数$(x-a/2)^2$。 对于一级，写$p(x)=\alpha x + \beta$。 然后$p(a-x)=\alpha(a-x)+\beta = -\alpha x + \alpha a + \beta$。 平等$p(x)=p(a-x)$意味着$\alpha = -\alpha$， 因此$\alpha=0$。 因此只有常数线性多项式满足条件，这与猜想一致。 

对于二阶，让$p(x)=\gamma x^2 + \delta x + \epsilon$。 然后$p(a-x)=\gamma(a-x)^2 + \delta(a-x)+\epsilon = \gamma x^2 - 2\gamma a x + \gamma a^2 + \delta a - \delta x + \epsilon = \gamma x^2 + (-2\gamma a - \delta)x + (\gamma a^2 + \delta a + \epsilon)$。 与 平等$p(x)$意味着$-2\gamma a - \delta = \delta$， 所以$\delta=-\gamma a$，则常数项为$\gamma a^2 - \gamma a^2 + \epsilon = \epsilon$，这是一致的。 重写$x^2 - a x$按照$y=(x-a/2)^2$给出$x^2 - a x = (x-a/2)^2 - a^2/4$，确认二次可以用以下形式表示$y=(x-a/2)^2$。 

关键的一步似乎是变量的改变$y=x-a/2$，将多项式集中在$x=a/2$并暴露对称性。 挑战在于严格证明_每个度_多项式满足$p(x)=p(a-x)$可以写成$(x-a/2)^2$，不仅仅是低度。 

## 问题理解

 该问题要求证明如果多项式$p$满足$p(x)=p(a-x)$对于某些人来说$a$，那么它是单变量的多项式$y=(x-a/2)^2$。 这是一个B 类问题，纯粹的证明。 核心难点是对称条件的转换$p(x)=p(a-x)$转化为关于多项式的结构陈述。 直观上，多项式关于直线对称$x=a/2$，任何关于点对称的函数都可以表示为到该点的距离的平方的函数。 

## 证明架构

 引理 1：如果$p(x)$是一个满足的多项式$p(x)=p(a-x)$，那么所有奇次幂$x-a/2$展开后消失。 这是因为变量的变化$y=x-a/2$将对称条件变换为$p(a/2+y)=p(a/2-y)$，强制所有奇数次幂的系数$y$为零。 

引理 2：只有偶次方的多项式$y$可以表示为多项式$y^2$。 这直接来自多项式的定义：$p(y)=\sum_{k=0}^n c_{2k} y^{2k}$意味着$p(y)=\sum_{k=0}^n c_{2k} (y^2)^k$。 

最难的一步是引理 1，粗心的代数可能会错过展开式中的一项。 验证任意程度的奇次幂消失需要仔细的系数比较。 

## 解决方案

 让$y = x - a/2$。 然后$x = a/2 + y$，以及对称条件$p(x) = p(a-x)$变成$p(a/2 + y) = p(a/2 - y)$。 扩张$p(a/2 + y)$作为多项式$y$：$$p(a/2 + y) = c_0 + c_1 y + c_2 y^2 + \dots + c_n y^n.$$然后$$p(a/2 - y) = c_0 - c_1 y + c_2 y^2 - c_3 y^3 + \dots + (-1)^n c_n y^n.$$平等$p(a/2+y)=p(a/2-y)$要求系数$y, y^3, y^5, \dots$消失。 明确地，比较术语给出$c_1 = -c_1$,$c_3=-c_3$， …， 因此$c_{2k+1}=0$为所有人$k$。 所以$$p(a/2 + y) = c_0 + c_2 y^2 + c_4 y^4 + \dots + c_{2m} y^{2m}.$$替补后卫$y = x - a/2$，得到$$p(x) = c_0 + c_2 (x-a/2)^2 + c_4 (x-a/2)^4 + \dots + c_{2m} (x-a/2)^{2m}.$$这表达了$p$作为多项式$(x-a/2)^2$，根据需要。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键步骤是验证所有奇数系数都消失。 考虑$p(x) = x^5 + (1-x)^5$和$a=1$。 代替$y = x - 1/2$， 然后$p(1/2 + y) = (1/2+y)^5 + (1/2-y)^5$。 使用二项式定理展开这两项：$(1/2+y)^5 = (1/2)^5 + 5 (1/2)^4 y + 10 (1/2)^3 y^2 + \dots$,$(1/2-y)^5 = (1/2)^5 - 5(1/2)^4 y + 10 (1/2)^3 y^2 - \dots$。 加法仅给出偶次幂，证实了一般推理。 检查二级示例$x^2 + (a-x)^2$产生相同的模式。 

## 替代方法

 另一种方法是利用以下事实：任何多项式都是由其在足够多的点上的值确定的。 评价$p$在$x = a/2 + t$和$x = a/2 - t$对于任意的$t$，得到函数方程$p(a/2+t) = p(a/2-t)$。 治疗$t$如变量所示$p(a/2+t)$是一个偶函数，因此是一个多项式$t^2$。 该方法在概念上更短，但隐含地依赖于偶函数表征。 主要方法是更可取的，因为它严格处理逐个系数的验证并自然地推广到任何程度。
