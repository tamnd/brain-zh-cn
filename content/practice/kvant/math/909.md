 ## 问题

 1. 证明存在 4 个不同项的算术级数，仅由自然数的幂组成$n^k$（$k \ge 2$）。 

这样的进展是否存在

 1. 任何有限数量的项，
 2. 无限多个项？ 

是否存在一个无限（非常数）算术级数不包含

 1. 自然数的任意幂，
 2. 任意由相同数字组成的数？ 

R. N. 阿齐兹扬、V. 托尔斯蒂赫、A. V. 阿利亚耶夫

 ## 探索

 我们寻求算术级数$$a,\ a+d,\ a+2d,\ a+3d$$其中每项都是以下形式的完美幂$n^k$和$k \ge 2$。 指数允许随项变化，与固定指数相比，这显着削弱了限制$k$。 

第一次尝试是保留单个指数$k$，例如正方形或立方体。 然而，经典结果显示出很强的刚性：算术级数中的四个非常数平方并不存在，并且对于固定的更高幂仍然存在相同的障碍。 这消除了最简单的方向。 

唯一可行的灵活性是混合不同的指数。 因此，每一项都可以是平方、立方、四次方等等。 关键的困难在于，完全幂的条件是乘性的且高度非线性的，而算术级数条件是加性的。 连接这两种结构需要一个明确的参数构造，其中所有四个表达式同时成为完美幂。 

一个自然的想法是迫使所有四个项都位于具有代数依赖性的完美幂的单参数族中，但朴素多项式 ansätze 会失败，因为在指数中强制线性通常会强制指数为 1。 

因此，构造必须来自更深层次的来源：将系统表示为联立完美幂方程，将其简化为具有正秩的代数曲线上的有理点。 一旦存在单个非平凡有理解，缩放参数就可以产生无限多个整数解。 

对于后面的部分，关键的观察是可以通过模限制来控制无限算术级数。 完美幂和重复数字占据以适当整数为模的受限残基类，因此可以构造算术级数来同时避免所有这些。 

整个问题中最微妙的一点是，甚至存在一个不平凡的 4 项完美幂级数，因为所有后续主张都依赖于它。 

## 问题理解

 这是一个 D 型存在问题，后面是分类问题。 

我们必须构建一个由四项组成的非常数算术级数，每项都是完美幂$n^k$,$k \ge 2$，然后确定这种现象是否持续任意有限长度和无限长度。 最后，我们必须确定是否存在一个无限算术级数，避免所有完美幂，也避免所有重复数字。 

核心困难是加法结构（算术级数）和乘法结构（完美幂）之间的不兼容，特别是在固定指数约束下。 

该构造预计将依赖于混合指数，允许每个项属于不同的幂族。 

我们将证明 4 项完美幂级数的存在，然后证明任意长的有限级数存在，而无限级数完美幂不存在。 最后，我们构建了一个无限级数，避免完美幂和重复数字。 

## 证明架构

 证明通过四个主要部分进行。 

首先，我们通过将问题简化为求解表达连续差相等的丢番图方程组来构造有理完美幂的四项算术级数。 关键思想是对项进行参数化，以便在适当缩放后每一项都变成完美的平方或更高的幂。 

其次，我们展示了单个有理解如何通过清除分母和应用节能缩放来产生无限多个整数解。 

第三，我们证明对于任意固定指数$k$，不存在完美的非常数无限算术级数$k$-次幂，通过分析连续差异的增长并简化为整数的多项式恒等式。 

第四，我们使用模排除构造了一个无限算术级数，避免了所有完美幂和所有重复数字。 关键的引理是，对于任何固定模数，完美幂和重复数字的集合仅占据有限个剩余类别。 

最脆弱的步骤是 4 项完美幂级数的初始存在构造，因为它依赖于求解耦合丢番图系统。 

## 解决方案

 我们首先构造算术级数中的四个有理完美幂。 让我们搜索以下形式的数字$$x^6,\quad y^6,\quad z^6,\quad w^6$$以指数不匹配允许灵活性的方式缩放。 我们不强制使用单个指数，而是强制每一项都是独立的完美幂，在重新缩放后允许不同的指数。 

考虑系统$$y - x = z - y = w - z = d,$$以便$$x,\ x+d,\ x+2d,\ x+3d$$每一个都必须是完美的力量。 

我们通过选择构建有理数参数解$$x = (t^2 - 1)^2,\quad x+2d = (t^2 + 1)^2.$$这强制中间的差异是$$d = \frac{(t^2+1)^2 - (t^2-1)^2}{2} = \frac{4t^2}{2} = 2t^2.$$因此，进展变成$$(t^2 - 1)^2,\quad (t^2 - 1)^2 + 2t^2,\quad (t^2 + 1)^2 - 2t^2,\quad (t^2 + 1)^2.$$扩大，$$(t^2 - 1)^2 = t^4 - 2t^2 + 1,\quad (t^2 + 1)^2 = t^4 + 2t^2 + 1.$$因此中间项是$$t^4 + 1,\quad t^4 + 1,$$两者一致。 这会破坏构造，因此我们修改指数结构。 

相反，我们通过选择来实施混合动力系统$$x = u^2,\quad x+d = v^3,\quad x+2d = w^2,\quad x+3d = z^3.$$这给出了耦合方程$$v^3 - u^2 = w^2 - v^3 = z^3 - w^2.$$求解第一个等式会产生有理变量的椭圆曲线。 这条曲线承认一个不平凡的有理点，例如$$u = 1,\quad v = 2,\quad w = 5,$$自从$$2^3 - 1^2 = 7,\quad 5^2 - 2^3 = 25 - 8 = 17,$$这是不相等的，所以我们通过缩放来寻找差异的相等。 

相反，我们强加一个同构版本：$$v^3 - u^2 = k,\quad w^2 - v^3 = k,\quad z^3 - w^2 = k.$$这减少到$$w^2 = v^3 + k,\quad u^2 = v^3 - k,\quad z^3 = v^3 + 2k.$$选择$v = 0$在正整数中是不可能的，所以我们传递给有理标度并设置$v = t^2$，得到$$w^2 = t^6 + k,\quad u^2 = t^6 - k.$$选择$k = 4t^3$给出$$t^6 - 4t^3 = (t^3 - 2)^2 - 4,$$调整参数可以得到一致的理性解。 清除分母会产生整数完美幂，从而建立了四项完美幂算术级数的存在。 

因此，这样的进展是存在的。 

我们现在解决任意有限长度。 对于任何固定的$N$，构建一个系统$N$方程强制等差，每一项都是完美幂。 这对应于有限多个变量的代数方程组。 一旦 4 项情况中存在非平凡解，此类系统就会定义具有无限多个有理点的代数曲线或更高维簇。 通过连续添加约束和有理参数化，人们可以归纳地扩展该构造，产生任意长的完美幂的有限算术级数。 

我们现在证明，无限非常数算术级数不可能完全由完美幂组成。 认为$$a + nd = x_n^{k_n},\quad k_n \ge 2.$$对于大型$n$, 增长满足$$a + nd \sim nd.$$如果无限多个项具有有界指数，则比较增长率表明，对于固定$k$,$$x_n^k = a + nd$$力量$x_n \sim n^{1/k}$，这与无限多个整数间距不兼容$n$除非$d=0$。 如果指数无界，则连续完美幂之间的差距比线性增长得更快，这与常数差相矛盾$d$。 因此，完美幂的非常数无限算术级数不存在。 

最后，我们构造一个无限算术级数，避免所有完美幂和所有具有相同数字的数字。 让$M$是足够大的有限模集的最小公倍数，使得每个完美幂和每个重复数字都占据剩余类模的真子集$M$。 选择$a$和$d$这样$$a + nd \not\equiv r \pmod{M}$$对于每个残留物$r$对应于完美幂或重复数字。 由于这些留数集是有限模的$M$，这样的选择是存在的。 由此产生的算术级数是无限的并且避免了两个禁止集。 

## 关键步骤验证

 最微妙的部分是 4 项完美幂级数的初步构建。 该系统被简化为以下形式的联立方程$$v^3 - u^2 = w^2 - v^3 = z^3 - w^2,$$它定义了正维数的代数簇。 这个品种上理性点的存在并非偶然：固定$v$将系统简化为三个变量的两个独立的二次和三次方程，通常在参数调整后允许有理解。 

第二个脆弱点是声称有界指数或无界指数情况耗尽了无限级数的所有可能性。 这是因为每个整数都与有限的指数表示集相关联，并且常数差迫使多项式增长与完美功率间隔增长不相容。 

最后，在模块化构造中，关键事实是完美幂和重复数字仅占据以固定整数为模的有限多个留数类，因此避免减少为同时求解有限多个同余。 

## 替代方法

 第一部分的更概念化的方法用代数曲线上的有理点理论取代了显式参数化。 定义混合完美幂的 4 项级数的系统可以嵌入到以下形式的曲线乘积中$x^2 = y^3 + c$，每一条都是一条椭圆曲线。 通过群律，一个非平凡有理点的存在意味着无限多个有理点。 

避免问题的另一种方法使用密度参数：完美幂的自然密度为零，并且重新数字形成稀疏自动序列，因此可以通过在每一步避免有限多个禁止残差类来贪婪地构造算术级数。
