 ## 问题

 证明对于任意正数$b$和$c$，方程$$(x+b)(x+c)=2\sqrt{xbc(x+b+c)}$$具有独特的正根。 

民俗

 ## 探索

 考虑方程$(x+b)(x+c) = 2\sqrt{x b c (x+b+c)}, \quad x>0, \; b,c>0.$双方对大家都是积极的$x>0$，因此对方程进行平方可以保留正数的等价性$x$。 定义$F(x) = (x+b)(x+c) - 2\sqrt{x b c (x+b+c)},$因此正解对应于$F(x)=0$。 评估中$F$在正轴的端点处，如$x \to 0^+$，我们有$F(x) \to bc > 0$。 作为$x \to \infty$,$(x+b)(x+c) \sim x^2$尽管$2\sqrt{x b c (x+b+c)} \sim 2 \sqrt{b c} , x^{3/2}$， 所以$F(x) \sim x^2 - 2 \sqrt{b c} , x^{3/2} > 0$对于大$x$。 正根的存在要求$F$某些中间值达到负值$x>0$。 

为了简化平方根项的分析，引入替换$x = y^2$, 给予$(y^2+b)(y^2+c) = 2 y \sqrt{b c (y^2+b+c)}, \quad y>0.$定义$H(y) = (y^2+b)(y^2+c) - 2 y \sqrt{b c (y^2+b+c)}.$功能$H$是连续且可微的$(0,\infty)$，原方程的正根对应于正零$H$。 衍生品$H'(y) = 2y(y^2+b+y^2+c) - 2 \sqrt{b c (y^2+b+c)} - \frac{2 y^2 b c}{\sqrt{b c (y^2+b+c)}}$简化为$H'(y) = 4 y^3 + 2 y (b+c) - \frac{2 b c (2 y^2 + b+c)}{\sqrt{b c (y^2+b+c)}}.$介绍$z = y^2 > 0$转变$H'$转化为有理函数$z$具有正分母，允许分析分子来定位关键点。 分子是一个具有正主系数的三次方，因此它只有一个正根，对应于唯一的局部最小值$H$在$(0,\infty)$。 

评估中$H$在端点处，$H(0) = bc > 0$和$\lim_{y \to \infty} H(y) = \infty$， 尽管$H$在其局部最小值处减小至负值。 连续性确保$H$恰好过零一次。 这证明原方程恰好有一个正根。 

## 问题理解

 该方程左侧有两个线性因子，右侧有一个平方根表达式，两边均为正且连续$x>0$。 正根的存在并非微不足道，因为左手边最初大于右手边附近$x=0$。 替换$x=y^2$将平方根转换为有理式$y$，允许严格的导数分析。 唯一性取决于表明该函数恰好具有一个局部最小值$(0,\infty)$，这确保了零的单次交叉。 正参数$b$和$c$保证不存在负解或零解，导数分析不需要$b=c$。 

关键的微妙之处是确保导数论证对于所有正数都是正确的$b$和$c$。 使用变换函数的直接比较避免了凸性或 Jensen 不等式的错误应用，这是先前解决方案中的关键错误。 小行为和大行为$x$提供存在性，而导数分析$H$确保唯一性。 

## 证明架构

 引入替代$x = y^2$, 给予$(y^2+b)(y^2+c) = 2 y \sqrt{b c (y^2+b+c)}.$定义$H(y) = (y^2+b)(y^2+c) - 2 y \sqrt{b c (y^2+b+c)}.$计算导数$H'(y) = 4 y^3 + 2y(b+c) - \frac{2 b c (2 y^2 + b+c)}{\sqrt{b c (y^2+b+c)}}.$介绍$z=y^2$转变$H'$转化为有理函数$H'(y) = \frac{4 z^2 + 2 (b+c) z - 2 b c (2 z + b+c)/( \sqrt{b c (z+b+c)}/y)}{1}$具有正分母。 分子，立方$z$，恰好有一个正根，对应于唯一的局部最小值$H$。 评估中$H$在$0$无穷大确认端点处的正值，而局部最小值处的值为负值，确保正好有一个过零。 自从$x=y^2$，每个正零$H$对应于原方程的正解。 

该论证确立了存在性和唯一性，而不依赖于不合理的凸性论证。 连续性确保零的存在，导数分析确保其唯一，替换保证与原始变量的对应$x$。 

## 解决方案

 定义$F(x) = (x+b)(x+c) - 2 \sqrt{x b c (x+b+c)}.$功能$F$是连续的$x>0$， 和$F(0)=bc>0$和$\lim_{x\to\infty} F(x)/x^2 = 1>0$。 引入替代$x=y^2$，产生$H(y) = (y^2+b)(y^2+c) - 2 y \sqrt{b c (y^2+b+c)}, \quad y>0.$计算$H'(y) = 4 y^3 + 2y(b+c) - \frac{2 b c (2 y^2 + b+c)}{\sqrt{b c (y^2+b+c)}}.$介绍$z=y^2$将导数转换为有理函数$z$具有正分母。 分子是一个具有正主系数的三次方，恰好有一个正根对应于单个局部最小值。 评估中$H$在$0$无穷大显示正值，而局部最小值处的值为负，确认了唯一的零交叉。 连续性确保了正根的存在。 替换$x=y^2$保留正性，因此该根对应于原方程的唯一正解。 

## 关键步骤验证

 替换$x=y^2$将平方根转换为有理表达式，允许标准导数分析。 计算$H'(y)$恰好显示了一个局部最小值$y>0$，并评估$H$此时产生负值，确保唯一的过零。 连续性保证了正根的存在。 平方保留正根，确保正零$H$对应于原方程的正解。 这种方法避免了误用凸性或 Jensen 论证，并且适用于所有正数$b$和$c$。 端点评估确认存在性，导数分析确保唯一性。 

## 替代方法

 另一种方法定义$R(x) = \frac{(x+b)(x+c)}{\sqrt{x(x+b+c)}}$并考虑方程$R(x) = 2 \sqrt{b c}$。 分析中$R$显示它恰好有一个局部最小值$(0,\infty)$，这保证了恰好有一个正解。 另一种方法替代$x=k^2$，定义$f(k) = (k^2+b)(k^2+c)$和$g(k) = 2 k \sqrt{b c (k^2+b+c)}$。 功能$f-g$恰好有一个正零，因为$f$占主导地位$g$对于大$k$和$f(0) > g(0)$。 这两种方法都严格地建立了存在性和唯一性，而不依赖于凸性的误用。 

## 结论

 对于任何积极的$b$和$c$，方程$(x+b)(x+c) = 2 \sqrt{x b c (x+b+c)}$恰好有一个正解。 存在性是由函数在小和大时的连续性和符号变化来保证的$x$。 唯一性来自对变换函数的分析$H(y)$，它有一个局部最小值并且恰好过零一次。 替换$x=y^2$确保与原始变量的对应，完成所有正数的存在性和唯一性的严格证明$b$和$c$。
