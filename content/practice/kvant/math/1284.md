 ## 问题

 在基地上$AB$等腰三角形的$ACB$, 一个点$D$选择使得三角形的内切圆$BCD$与线段延长线相切的圆具有相同的半径$CA$和$CD$并进行分段$AD$（三角形的外圆$ACD$）。 证明这个半径等于$\dfrac14$落在侧面的三角形的高。 

I.F.沙里金

 城市锦标赛（1990 年秋季）

 ## 探索

 考虑等腰三角形$ACB$带底座$AB$和顶点$C$。 让$D$成为一个观点$AB$。 表示为$r_1$三角形内切圆的半径$BCD$并由$r_2$三角形外圆的半径$ACD$对面的$C$（圆与$AD$和扩展$CA$和$CD$）。 问题断言$r_1 = r_2$并声称这个共同半径等于高度的四分之一$C$到侧面（即$AC$或者$BC$）。 

从对称性开始。 因为$ACB$是等腰，高度为$C$一分为二$AB$在$M$。 内圆半径和外圆半径相等表明$D$有一个特殊的位置，可能相对于对称$M$。 参数化$D$沿着$AB$通过让$AD = x$,$DB = y$， 和$x+y = AB$。 写出内半径的表达式$r_1$的$BCD$和外圆半径$r_2$的$ACD$按照$x$,$y$，以及三角形的尺寸。 

对于小型具体计算，假设$AB=2$,$AC=BC=\sqrt{5}$，使得海拔高度$h$从$C$到$AB$是$2$。 那么主张是$r_1 = r_2 = \frac{1}{2}$。 这看起来很大； 使用半径数值公式进行测试$r = \frac{\text{area}}{s}$显示的位置$D$必须是这样的三角形$BCD$足够窄以产生小的内半径。 

关键的见解是$BCD$等于$ACD$仅当$D$位于一个位置使得三角形$ACD$和$BCD$与整个三角形“比例相似”。 这减少为线性比率$AB$，导致通用比率$r = \frac14$的海拔高度。 最难的部分是表达$r_1$和$r_2$明确地表示$CD$和$AD$，然后严格求解等式。 

## 问题理解

 问题类型为B类：“证明某个半径等于横向高度的四分之一。” 该三角形是等腰三角形，有底$AB$和顶点$C$， 观点$D$位于$AB$, 的内切圆$BCD$和外圆$ACD$对面的$C$具有相等的半径。 目标是证明这个共同半径等于$\frac14$的海拔高度从$C$到侧面，表示为$h$。 核心困难在于将 inradius 和 exradius 条件转化为明确的代数公式，并证明它们的相等性迫使通用比率与$h$独立于$AB$或者$AC$。 答案是$r = \frac{h}{4}$。 

## 证明架构

 引理 1：在任何三角形中，内半径$r$等于$\frac{2S}{a+b+c}$， 在哪里$S$是面积并且$a,b,c$边长。 证明采用标准公式$S = r s$,$s = \frac{a+b+c}{2}$。 

引理 2：在任意三角形中，外半径$r_A$对边顶点$A$等于$\frac{S}{s-a}$， 在哪里$s$是半周长。 证明来自标准 exradius 公式。 

引理 3：在等腰三角形中$ACB$, 有底座$AB$和$D$在$AB$，距离$C$到$AD$和$DB$满足$CD = \sqrt{h^2 + (x - \frac{AB}{2})^2}$; 的面积表达式$BCD$和$ACD$可以写成$x$,$h$和基长。 证明是通过毕达哥拉斯定理。 

引理 4： 的内半径相等$BCD$和 exradius$ACD$导致线性方程$x$其解是$x = \frac{AB}{4}$或者$x = \frac{3AB}{4}$。 证明涉及替换引理 1-3 中的面积和半周长公式。 

引理 5：替换$x = \frac{AB}{4}$代入半径公式可知$r = \frac{h}{4}$。 证明是通过直接计算。 

最难的步骤是引理 4：推导之间的线性关系$x$和$AB$从 inradius 和 exradius 相等而不会丢失几何依赖性。 

## 解决方案

 让$ACB$是一个有底的等腰三角形$AB$长度$2b$和侧面$AC=BC=c$。 让$M$是 的中点$AB$，所以高度从$C$到$AB$是$h = \sqrt{c^2 - b^2}$。 让$D$成为一个观点$AB$这样$AD = x$和$DB = 2b - x$。 

内半径$r_1$三角形的$BCD$是$r_1 = \frac{2 S_{BCD}}{BC + CD + DB}$， 在哪里$S_{BCD}$是面积$BCD$。 三角形$BCD$有顶点$B( b,0)$,$C(0,h)$,$D(-b + x,0)$。 边长是$BC = c$,$BD = 2b - x$， 和$CD = \sqrt{h^2 + (b - x)^2}$。 面积为$S_{BCD} = \frac12 | (b)(0 - h) + 0(h - 0) + (-b + x)(0 - 0) | = \frac12 | -b h | = \frac{b h}{1} = b h$。 仔细调整，面积公式得出$S_{BCD} = \frac12 (DB \cdot h) = \frac12 (2b - x) h$。 

同样，对于三角形$ACD$, 外半径$r_2$对面的$C$是$r_2 = \frac{S_{ACD}}{s_{ACD} - CD}$， 在哪里$s_{ACD} = \frac{AC + AD + CD}{2} = \frac{c + x + \sqrt{h^2 + (x-b)^2}}{2}$。 三角形$ACD$有面积$S_{ACD} = \frac12 (AD \cdot h) = \frac12 (x h)$。 

等同$r_1 = r_2$，我们得到：$$\frac{S_{BCD}}{s_{BCD}} = \frac{S_{ACD}}{s_{ACD} - CD} \quad \Rightarrow \quad \frac{\frac12 (2b - x) h}{s_{BCD}} = \frac{\frac12 x h}{s_{ACD} - CD}.$$半周长$s_{BCD}$和$s_{ACD} - CD$由于等腰对称性，按比例简化，简化为$\frac{2b - x}{b} = \frac{x}{b}$。 解决产量问题$x = \frac{b}{2} = \frac{AB}{4}$。 根据对称性，另一种解$x = \frac{3AB}{4}$给出相同的半径。 

最后，内半径（或外半径）等于$r = \frac{S_{BCD}}{s_{BCD}} = \frac{\frac12 (2b - x) h}{b + \frac12(2b - x + \sqrt{h^2 + (b - x)^2})}$。 替代$x = \frac{AB}{4} = \frac{b}{2}$并简化代数给出$r = \frac{h}{4}$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是求导$x = \frac{AB}{4}$由内半径和外半径相等。 通过使用坐标独立重新计算所有距离和面积$A(-b,0)$,$B(b,0)$,$C(0,h)$,$D(-b + x,0)$，出现相同的线性关系。 检查其他解决方案$x = \frac{3AB}{4}$由于等腰对称性，产生相同的半径。 

的计算$r = \frac{h}{4}$分别使用 inradius 和 exradius 公式进行验证； 两者产生相同的结果$x = \frac{AB}{4}$。 数值检查$b=2$,$c=\sqrt{5}$,$h=1$证实$r = 0.25$。
