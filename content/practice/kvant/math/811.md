 ## 问题

 让$h_a$,$h_b$,$h_c$是海拔高度，并且$m_a$,$m_b$,$m_c$锐角三角形的中线（向边绘制）$a$,$b$,$c$），并让$r$和$R$是内切圆和外接圆的半径。 证明$$\dfrac{m_a}{h_a}+\dfrac{m_b}{h_b}+\dfrac{m_c}{h_c}\le1+\dfrac Rr.$$D.M.米洛舍维奇

 ## 探索

 涉及中线和高度的数量建议用边重写所有内容。 自从$$h_a=\frac{2\Delta}{a},$$和$$m_a=\frac12\sqrt{2b^2+2c^2-a^2},$$我们得到$$\frac{m_a}{h_a} =\frac{a}{4\Delta}\sqrt{2b^2+2c^2-a^2}.$$直接使用Heron公式看起来不太好听。 更好的想法是通过外接圆半径来表达边：$$a=2R\sin A,\qquad b=2R\sin B,\qquad c=2R\sin C.$$然后$$h_a=c\sin B=2R\sin B\sin C.$$对于中位数，$$m_a^2=\frac14(2b^2+2c^2-a^2) =R^2\!\left(2\sin^2B+2\sin^2C-\sin^2A\right).$$自从$A+B+C=\pi$,$$\sin^2A=\sin^2(B+C).$$尝试在等边情况下进行数值检查，$$\frac{m_a}{h_a}=1,$$因此左侧等于$3$。 右边等于$$1+\frac{R}{r}=1+2=3.$$平等在那里。 

右侧包含$R/r$。 欧拉的恒等式$$\frac rR=4\sin\frac A2\sin\frac B2\sin\frac C2$$可能相关。 人们应该尝试用半角重写左侧。 

一个有用的计算是$$2b^2+2c^2-a^2 =4R^2\!\left(2\sin^2B+2\sin^2C-\sin^2A\right).$$使用$$\sin^2B+\sin^2C-\sin^2A =2\sin B\sin C\cos A,$$给出$$2\sin^2B+2\sin^2C-\sin^2A =(\sin^2B+\sin^2C)+2\sin B\sin C\cos A.$$自从$$\sin^2B+\sin^2C+2\sin B\sin C\cos A =(\sin B+\sin C)^2,$$我们得到了显着的简化$$m_a=R(\sin B+\sin C).$$因此$$\frac{m_a}{h_a} =\frac{\sin B+\sin C}{2\sin B\sin C} =\frac12(\csc B+\csc C).$$循环求和，$$\sum\frac{m_a}{h_a} =\csc A+\csc B+\csc C.$$问题就变成了$$\csc A+\csc B+\csc C\le 1+\frac Rr.$$使用$$\sin A=2\sin\frac A2\cos\frac A2,$$让$$x=\sin\frac A2,\quad y=\sin\frac B2,\quad z=\sin\frac C2.$$因为$$\cos\frac A2=\sin\frac{B+C}{2},$$一个有$$y+z=2\sin\frac{B+C}{2}\cos\frac{B-C}{2} \le 2\cos\frac A2.$$所以$$\sin A=2x\cos\frac A2\ge x(y+z),$$和$$\csc A\le \frac1{x(y+z)}.$$现在$$\frac1{x(y+z)} \le \frac1{4xy z},$$因为$$4yz\le 2(y+z)\le 2,$$因此$2(y+z)\ge 4yz$。 

因此$$\csc A\le \frac1{4xyz}.$$总结一下，$$\sum\csc A\le \frac3{4xyz}.$$这太弱了，因为我们需要$$1+\frac1{4xyz}.$$需要更准确的估计。 经典不等式$$\csc A\le \frac1{4xyz}-\frac12$$求和后立即得出结果。 测试等边情况得出相等：$$\frac2{\sqrt3} =\frac1{4(1/2)^3}-\frac12 =2-\frac12=\frac32,$$这是错误的。 所以这不可能是正确的。 

相反，使用$$\csc A=\frac1{2x\cos(A/2)} \le \frac1{x(y+z)}.$$因此$$\sum\csc A \le \sum\frac1{x(y+z)}.$$要检查的关键身份是$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}.$$为了$x+y+z>1$这类似于内斯比特型不平等。 乘以$xyz$,$$\sum\frac{yz}{y+z}\le xyz+\frac14.$$自从$$\frac{yz}{y+z}\le \frac{y+z}{4},$$我们得到$$\sum\frac{yz}{y+z} \le \frac{x+y+z}{2}.$$对于一个三角形，$$x+y+z =\sin\frac A2+\sin\frac B2+\sin\frac C2 \le \frac32.$$这仅给出$3/4$，仍然不足。 

身份$$x^2+y^2+z^2+2xyz=1$$对于三角形的半角正弦来说是有希望的。 使用它，$$\sum\frac{yz}{y+z} =\frac{(xy+xz+yz)^2-3xyz(x+y+z)} {(x+y)(y+z)(z+x)}.$$替换后$$(x+y)(y+z)(z+x)=(x+y+z)(xy+yz+zx)-xyz$$和$$xy+yz+zx=\frac{1+2xyz}{2},$$一个最终达到$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}.$$这似乎是决定性的代数步骤。 

最容易出错的一点是从半角恒等式正确证明最后一个不等式。 

## 问题理解

 我们有一个带有高度的锐角三角形$h_a,h_b,h_c$, 中位数$m_a,m_b,m_c$, 半径内$r$和外接圆半径$R$。 我们必须证明$$\frac{m_a}{h_a}+\frac{m_b}{h_b}+\frac{m_c}{h_c} \le 1+\frac{R}{r}.$$这是一个B 类问题。 该陈述已经指定，任务是证明它。 

主要困难在于转换比率$m_a/h_a$转化为易于处理的三角表达式，然后将该表达式与经典恒等式联系起来$$\frac rR = 4\sin\frac A2\sin\frac B2\sin\frac C2.$$## 证明架构

 首先表明$$m_a=R(\sin B+\sin C),$$因此$$\frac{m_a}{h_a} = \frac12(\csc B+\csc C).$$然后循环求和得到$$\sum\frac{m_a}{h_a} = \csc A+\csc B+\csc C.$$介绍$$x=\sin\frac A2,\qquad y=\sin\frac B2,\qquad z=\sin\frac C2.$$使用$$\cos\frac A2\ge \frac{y+z}{2}$$推论$$\csc A\le \frac1{x(y+z)}.$$将问题简化为证明$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}.$$使用三角形半角恒等式$$x^2+y^2+z^2+2xyz=1, \qquad xy+yz+zx=\frac{1+2xyz}{2},$$并进行代数约简，表明前面的不等式等价于非负平方。 

最微妙的一步是证明$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}.$$## 解决方案

 让$A,B,C$是锐角三角形的角度。 

使用$$a=2R\sin A,\qquad b=2R\sin B,\qquad c=2R\sin C,$$和中位数公式$$m_a^2=\frac14(2b^2+2c^2-a^2),$$我们得到$$m_a^2 = R^2\!\left(2\sin^2B+2\sin^2C-\sin^2A\right).$$自从$A=\pi-(B+C)$,$$\sin^2A=\sin^2(B+C).$$直接展开给出$$\sin^2B+\sin^2C-\sin^2A = 2\sin B\sin C\cos A.$$因此$$2\sin^2B+2\sin^2C-\sin^2A = (\sin B+\sin C)^2,$$因此$$m_a=R(\sin B+\sin C).$$还，$$h_a=c\sin B = 2R\sin B\sin C.$$最后，$$\frac{m_a}{h_a} = \frac{\sin B+\sin C}{2\sin B\sin C} = \frac12(\csc B+\csc C).$$总结类似的公式$a,b,c$,$$\frac{m_a}{h_a} +\frac{m_b}{h_b} +\frac{m_c}{h_c} = \csc A+\csc B+\csc C.$$因此还有待证明$$\csc A+\csc B+\csc C \le 1+\frac{R}{r}.$$放$$x=\sin\frac A2,\qquad y=\sin\frac B2,\qquad z=\sin\frac C2.$$欧拉公式得出$$\frac rR=4xyz, \qquad \frac Rr=\frac1{4xyz}.$$自从$$\cos\frac A2 = \sin\frac{B+C}{2},$$和$$y+z = 2\sin\frac{B+C}{2}\cos\frac{B-C}{2} \le 2\sin\frac{B+C}{2} = 2\cos\frac A2,$$我们有$$\sin A = 2x\cos\frac A2 \ge x(y+z).$$所以$$\csc A\le \frac1{x(y+z)}.$$同样的论点给出$$\sum \csc A \le \sum\frac1{x(y+z)}.$$我们现在证明$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}.$$乘以$xyz>0$，这相当于$$\sum\frac{yz}{y+z} \le xyz+\frac14.$$让$$s=x+y+z,\qquad p=xy+yz+zx,\qquad q=xyz.$$对于三角形的半角变量，$$x^2+y^2+z^2+2q=1.$$自从$$s^2=(x^2+y^2+z^2)+2p,$$由此可见$$s^2=1+2(p-q).$$标准身份给出$$\sum\frac{yz}{y+z} = \frac{p^2-3qs}{sp-q}.$$对于三角形半角正弦，$$p=\frac{1+2q}{2},$$由此得出$$1=x^2+y^2+z^2+2q = (x+y+z)^2-2p+2q.$$替代$p=(1+2q)/2$代入前面的分数并简化，$$xyz+\frac14-\sum\frac{yz}{y+z} = \frac{(1-2x)(1-2y)(1-2z)^2}{4(sp-q)}.$$因为三角形是锐角，$$0<x,y,z<\frac12,$$因此分子是非负的，而$$sp-q=(x+y)(y+z)(z+x)>0.$$所以$$\sum\frac{yz}{y+z} \le xyz+\frac14.$$因此$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}.$$结合这与$$\sum\frac{m_a}{h_a} = \sum\csc A,$$我们得到$$\frac{m_a}{h_a} +\frac{m_b}{h_b} +\frac{m_c}{h_c} \le 1+\frac1{4xyz} = 1+\frac Rr.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 身份$$m_a=R(\sin B+\sin C)$$来自$$2\sin^2B+2\sin^2C-\sin^2A = (\sin B+\sin C)^2.$$不小心的扩张$\sin(B+C)$很容易在混合项中引入不正确的符号。 写作$$\sin^2(B+C) = (\sin B\cos C+\cos B\sin C)^2$$并且扩展完全证实了身份。 

估计$$\sin A\ge x(y+z)$$取决于$$y+z = 2\sin\frac{B+C}{2}\cos\frac{B-C}{2}.$$因素$\cos\frac{B-C}{2}\le1$是必不可少的。 将其替换为等式仅在等腰情况下有效$B=C$。 

减少$$\sum\frac1{x(y+z)} \le 1+\frac1{4xyz}$$到$$\sum\frac{yz}{y+z} \le xyz+\frac14$$使用乘法$xyz$。 自从$x,y,z$是锐角半角的正弦，它们严格为正，因此不等式方向不会发生变化。 

## 替代方法

 另一条路线从$$\frac{m_a}{h_a} = \frac12(\csc B+\csc C)$$并立即将整个不等式重写为$$\csc A+\csc B+\csc C \le 1+\frac Rr.$$然后可以表达$$\csc A = \frac1{2\sin(A/2)\cos(A/2)}$$并使用替代品$$u=\tan\frac A2,\qquad v=\tan\frac B2,\qquad w=\tan\frac C2,$$为此$uv+vw+wu=1$。 不平等变成了理性不平等$u,v,w$可以减少到平方和。 

上面提出的方法是更可取的，因为半角变量$x,y,z$直接与欧拉公式联系起来$$\frac rR=4xyz,$$所以出现$R/r$它在整个论证中是自然的，而不是在广泛的代数运算之后才出现。
