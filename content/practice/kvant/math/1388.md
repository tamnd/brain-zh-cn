 ## 问题

 给定不同的二次三项式$f(x)$和$g(x)$，首项系数都等于 1。 据了解$f(1)+f(10)+f(100)=g(1)+g(10)+g(100)$。 为了哪个$x$是否平等$f(x)=g(x)$抓住？ 

A·佩林

 圣彼得堡城市数学奥林匹克竞赛

 ## 探索

 让$f(x)=x^2+bx+c$和$g(x)=x^2+px+q$，因为两个二次方程都有主系数$1$。 给定条件是$f(1)+f(10)+f(100)=g(1)+g(10)+g(100).$显式计算，$f(1)+f(10)+f(100) = (1+b+c) + (100+10b+c) + (10000+100b+c) = 10101 + 111b + 3c,$和类似地$g(1)+g(10)+g(100) = 10101 + 111p + 3q.$因此条件减少为$111b + 3c = 111p + 3q \implies 37(b-p) = q-c.$区别$h(x)=f(x)-g(x)=(b-p)x+(c-q)$是线性多项式，因为二次项相互抵消。 我们被要求找到$x$为此$f(x)=g(x)$， IE。，$h(x)=0$。 

所以$x=\frac{q-c}{p-b}$，并使用之前的关系$q-c = 37(b-p) = -37(p-b)$，我们得到$x=\frac{-37(p-b)}{p-b}=-37$。 这表明唯一的解决方案是$x=-37$。 

关键点是确认符号：$b\neq p$自从$f\neq g$，所以除以$p-b$是允许的。 这也意味着线性方程确实有唯一解。 

尝试用小数字验证这一点$x=-37$作品。 

## 问题理解

 我们有两个不同的一元二次方程$f(x)$和$g(x)$使得它们的值之和为$1$,$10$， 和$100$是平等的。 问题要求的是$x$在哪$f(x)=g(x)$。 这是一个 A 类问题，因为我们被要求找到所有$x$满足一个条件。 核心困难是将三点和条件简化为单个线性方程，该方程可确定两个二次方程的交点。 直观上答案是单个数字，因为具有相等主系数的两个二次方程的差是线性的，因此它们只能在一点相交。 根据初步计算，$x$是$-37$。 

## 证明架构

 引理 1：任意两个不同的一元二次方程$f(x)$和$g(x)$有$f(x)-g(x)$作为线性多项式。 这是正确的，因为二次项抵消了。 

引理 2：如果$f(1)+f(10)+f(100)=g(1)+g(10)+g(100)$， 然后$37(b-p)=q-c$对于线性系数$b,p$和常数$c,q$的$f$和$g$。 这是直接扩展和简化的结果。 

引理 3：解决方案$f(x)=g(x)$是$x=\frac{q-c}{p-b}$，这是线性且唯一的，因为$b\neq p$。 

主要主张使用引理 2 和 3 来显式计算唯一的交点。 引理 2 是最微妙的，因为算术错误会产生错误的分数，从而产生错误的分数$x$。 

## 解决方案

 让$f(x)=x^2+bx+c$和$g(x)=x^2+px+q$。 然后$f(1)+f(10)+f(100)=(1+b+c)+(100+10b+c)+(10000+100b+c)=10101+111b+3c,$和$g(1)+g(10)+g(100)=10101+111p+3q.$使这些总和相等，得出$10101+111b+3c = 10101+111p+3q \implies 111b+3c = 111p+3q \implies 37(b-p) = q-c.$区别$h(x)=f(x)-g(x)=(b-p)x+(c-q)$是一个线性多项式。 自从$f\neq g$,$b\neq p$，所以方程$h(x)=0$有独特的解决方案$x = \frac{q-c}{p-b}.$替代$q-c = 37(b-p)$给出$x = \frac{37(b-p)}{p-b} = \frac{37(b-p)}{- (b-p)} = -37.$因此$f(x)=g(x)$成立当且仅当$x=-37$。$\boxed{-37}$## 关键步骤验证

 的扩展$f(1)+f(10)+f(100)$和$g(1)+g(10)+g(100)$逐项验证：$1^2+b+c = 1+b+c$,$10^2+10b+c = 100+10b+c$,$100^2+100b+c = 10000+100b+c$。 求和给出$10101+111b+3c$。 替代$q-c = 37(b-p)$进入$x=(q-c)/(p-b)$需要仔细注意标志； 反转减法会产生$+37$而不是$-37$。 考虑到$b-p$相对$p-b$证实$-37$是正确的。 测试小整数示例，例如$b=1,p=2$，确认解决方案仍然存在$x=-37$。 

## 替代方法

 人们可以尝试一种使用三个方程组的方法$f(1)=y_1$,$f(10)=y_2$,$f(100)=y_3$并直接求解$x$在哪里$f(x)=g(x)$。 这种方法涉及更多代数，并且不会自然地简化为单一线性关系。 这里使用的方法利用了前导系数的对称性和差异的线性性，以最少的算术和最大的透明度产生直接计算。
