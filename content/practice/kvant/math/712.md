 ## 问题

 证明任何正数都可以表示为九个数字的和，其十进制表示形式仅包含数字 0 和 7。 

E·图尔克维奇

 ## 探索

 我们试图将任意正实数表示为九个数字的和，其十进制扩展仅使用数字$0$和$7$。 该约束是纯数字式的，但十进制加法中的进位阻止了直接的独立数字分解。 将每个十进制数字分成九部分的天真的想法失败了，因为进位无限传播。 

更稳健的观点是在控制进位的同时从左到右逐位构建九个被加数。 由于每个被加数中的每个数字都是$0$或者$7$，任意固定位置上的数字之和为${0,7,14,\dots,63}$。 这个范围足够宽，可以吸收目标数字和有界进位，表明受控的贪婪结构。 

关键的困难是确保在每一步都可以选择与所需的十进制数字和传入的进位兼容的数字和，同时保持下一个进位统一有界，以便过程永远不会中断。 

## 问题理解

 这是一个 D 类问题（存在性证明的构造）。 

我们必须证明，每个正实数都可以表示为九个数字的和，其十进制表示仅由数字组成$0$和$7$。 

同样，我们必须仅使用$0$和$7$其逐项总和等于给定数字。 核心难点是基地的管理$10$同时尊重受限制的数字集。 

该结构必须确保在每个小数位上，可以选择九个数字的总数字贡献来匹配所需的数字并将受控进位传播到下一个位置。 

## 证明架构

 我们从左到右逐位构造这九个数字。 

首先，我们修复给定正数的小数展开式。 

其次，我们构建九个数字序列，每个数字可以是$0$或者$7$，以及描述传递到下一个小数位的溢出量的进位序列。 

第三，我们证明一个引理，保证对于有界范围内的任何传入进位和任何目标数字，都存在九个数字的选择${0,7}$其和产生有效的下一个进位，同时匹配所需的数字约束。 

最难的部分是存在引理，确保具有有界进位的局部数字方程的可解性。 这依赖于模块化参数和范围检查。 

一旦这个局部步骤得到保证，全局构造就通过小数点归纳来进行。 

## 解决方案

 让$x>0$被给予。 修复小数扩展$$x = \sum_{k=m}^{\infty} d_k 10^k,$$其中每个$d_k \in {0,1,\dots,9}$并且只有有限多个$d_k$和$k\ge 0$均非零。 

我们构造九个数字$x_1,\dots,x_9$，每个都有小数位${0,7}$，使得$$x = x_1 + \cdots + x_9.$$我们写每个$x_i$作为$$x_i = \sum_{k=m}^{\infty} a_{i,k} 10^k,$$其中每个$a_{i,k} \in {0,7}$。 

我们构造数字$a_{i,k}$通过增加$k$，从最低位置开始，同时保持进位$c_k \in \mathbb{Z}_{\ge 0}$这样$$\sum_{i=1}^9 a_{i,k} + c_k = d_k + 10c_{k+1}.$$我们将归纳确保$c_k \le 6$为所有人$k$。 

假设对于某个位置$k$携带$c_k \in {0,1,\dots,6}$被给出。 我们必须选择数字$a_{1,k},\dots,a_{9,k} \in {0,7}$和一个携带$c_{k+1} \in {0,1,\dots,6}$满意的$$S_k + c_k = d_k + 10c_{k+1},$$在哪里$S_k = \sum_{i=1}^9 a_{i,k}$。 

由于每个$a_{i,k}$是$0$或者$7$, 总和$S_k$必须属于集合$$\{0,7,14,\dots,63\}.$$因此我们必须找到整数$t \in {0,1,\dots,9}$和$c_{k+1} \in {0,\dots,6}$这样$$S_k = 7t, \quad 0 \le 7t \le 63,$$和$$7t + c_k = d_k + 10c_{k+1}.$$等价地，$$7t = d_k - c_k + 10c_{k+1}.$$我们选择$c_{k+1}$这样右边就可以被整除$7$。 工作模数$7$，我们使用$10 \equiv 3 \pmod 7$， 因此$$d_k - c_k + 10c_{k+1} \equiv d_k - c_k + 3c_{k+1} \pmod 7.$$作为$c_{k+1}$贯穿$0,1,\dots,6$，值$3c_{k+1} \pmod 7$遍历所有残基类模$7$因为$\gcd(3,7)=1$。 因此存在一个选择$c_{k+1} \in {0,\dots,6}$这样$$d_k - c_k + 10c_{k+1} \equiv 0 \pmod 7.$$对于此选择，定义$$S_k = d_k - c_k + 10c_{k+1}.$$我们现在验证一下$S_k$在于${0,7,14,\dots,63}$。 自从$0 \le d_k \le 9$和$0 \le c_k \le 6$和$0 \le c_{k+1} \le 6$，我们得到$$-6 \le d_k - c_k \le 9,$$因此$$-6 \le S_k - 10c_{k+1} \le 9.$$因此$$10c_{k+1} - 6 \le S_k \le 10c_{k+1} + 9.$$为了$c_{k+1} \in {0,\dots,6}$这个区间总是相交的${0,7,14,\dots,63}$，并且由于残差条件固定$S_k$模数$7$，只有一个以下形式的候选者$7t$在每个残基类别中，因此我们可以选择位于$[0,63]$。 这会产生一个有效的$t \in {0,\dots,9}$因此在位置上的有效数字分配$k$。 

然后我们定义数字$a_{i,k}$通过准确选择$t$九个指数中$i$为此$a_{i,k}=7$和其余的$0$。 

这样就完成了归纳步骤。 

由于进位仍然受$6$，对所有数字进行构造。 结果九个数字$x_1,\dots,x_9$满足正确进位的数字恒等式，因此它们的总和等于$x$。 

每个$x_i$仅使用数字$0$和$7$通过建设。 

这样就完成了所需表示的构建。 

∎

 ## 关键步骤验证

 中心点是可解性$$7t + c_k = d_k + 10c_{k+1}$$和$t \in {0,\dots,9}$和$c_{k+1} \in {0,\dots,6}$。 

定影$c_k$和$d_k$，我们各不相同$c_{k+1}$。 模数$7$表达式变为$d_k - c_k + 3c_{k+1}$。 由于乘以$3$对残基类进行模置换$7$，存在唯一的$c_{k+1}$产生整除性$7$。 

一旦强制执行整除性，结果值$S_k$位于由有界确定的短区间内$d_k,c_k,c_{k+1}$。 可能的倍数$7$在允许的范围内始终包含至少一个所需残留类别的代表，以确保与$t \in {0,\dots,9}$。 

潜在的脆弱点是残差约束和边界之间的相互作用$0 \le S_k \le 63$。 该结构避免了失败，因为允许的范围$S_k$跨度超过$7$连续整数，保证与唯一倍数的交集$7$在所选的残基类别中。 

## 替代方法

 一种不同的方法使用康托型数字集中的表示法，用缩放参数代替逐位构造${0,7}$。 一个表明，该集合在加法下足够厚，九倍和填充所有正实数，使用除以下的自相似性$10$并分解为不相交的数字块。 该方法避免了显式进位跟踪，但需要关于受限数字集的加性基的更全局的结构论证。
