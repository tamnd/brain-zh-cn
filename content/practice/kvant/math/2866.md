 ## 问题

 数字 1、2、3、$\ldots$，127 人被分为两组。 这些组中数字的乘积之和是否可以恰好以以下形式结尾：

 1. 10个零；
 2. 30个零？ 

K·苏霍夫

 南俄罗斯数学奥林匹克“阿萨拉”（IV）

 ## 探索

 问题询问整数是否来自$1$通过$127$可以分为两组，使得每组中的数字的乘积之和以正好十个零或正好三十个零结尾。 自然数的尾随零的数量由以下指数的最小值决定$2$和$5$在其素因数分解中，因为每个因子$10$贡献一个尾随零。 其中的整数来自$1$到$127$, 的权力$2$比权力更丰富$5$，因此实现给定数量的尾随零的可行性主要受因素分布的限制$5$两组之间。 因此，问题简化为构造十个尾随零的分区，并通过分析证明三十个尾随零的不可能性$5$-adic 和$2$-激进的估值。 

## 问题理解

 设两组为$A$和$B$, 与产品$P_A$和$P_B$。 表示$v_5(P_A) = a$和$v_5(P_B) = b$， 在哪里$v_5(x)$表示指数$5$在质因数分解中$x$。 由于所有数字的乘积等于$127!$，由此可知$a + b = v_5(127!)$。 总和$S = P_A + P_B$满足$v_5(S) \ge \min(a, b)$和$v_5(S) = \min(a, b)$如果被加数不以较小的幂为模抵消$5$。 尾随零的数量$S$由下式给出$\min(v_2(S), v_5(S))$，因此要精确地获得十个尾随零，只需找到一个分区，其中较小的$5$-adic估值$P_A$和$P_B$等于十，相应的$2$-adic 估值至少为 10。 

## 证明架构

 总计$5$-adic 估值$127!$首先使用勒让德公式计算。 一旦因素总数$5$已知，分析是否可以对数字进行划分，使得其中较小的一个$v_5(P_A)$和$v_5(P_B)$等于十。 为了确保恰好有十个尾随零，必须严格验证总和$S = P_A + P_B$有$5$-adic 估值正好十和$2$-adic估值至少十。 对于三十个尾随零，总和必须为$v_5(S) \ge 30$，但因子总数$5$限制了可达到的最大值$5$-任意金额的adic估值，提供严格的不可能论证。 

## 解决方案

 的$5$-adic 估值$127!$使用勒让德公式计算：$v_5(127!) = \left\lfloor \frac{127}{5} \right\rfloor + \left\lfloor \frac{127}{25} \right\rfloor + \left\lfloor \frac{127}{125} \right\rfloor = 25 + 5 + 1 = 31.$因子总数$5$在$127!$是$31$。 设两组为$A$和$B$, 与产品$P_A$和$P_B$，并让$v_5(P_A) = a$,$v_5(P_B) = b$。 然后$a + b = 31$，对于任何分区，总和$S = P_A + P_B$满足$v_5(S) \ge \min(a,b)$，如果两个被加数不以较小的幂为模抵消，则相等$5$。 

要构造一个以十个零结尾的和，请考虑子集$A = \{5, 10, 15, 20, 25, 50, 75, 2, 4, 8, 16\}.$这$5$-adic 的贡献是$v_5(5) = 1$,$v_5(10) = 1$,$v_5(15) = 1$,$v_5(20) = 1$,$v_5(25) = 2$,$v_5(50) = 2$， 和$v_5(75) = 2$, 总结为$v_5(P_A) = 10$。 这$2$-adic 的贡献是$v_2(2) = 1$,$v_2(4) = 2$,$v_2(8) = 3$,$v_2(16) = 4$,$v_2(10) = 1$,$v_2(20) = 2$,$v_2(50) = 1$, 总结为$v_2(P_A) = 14$。 互补组$B$包含剩余的数字$1,3,6,7,\dots,127\setminus A$，及其产品$P_B$包含其余因素$5$，总计$v_5(P_B) = 31 - 10 = 21$，以及大量的因素$2$，肯定超过$14$。 

让$P_A = 5^{10} u$和$P_B = 5^{21} v$， 在哪里$u$和$v$是不能被整除的整数$5$。 然后$S = P_A + P_B = 5^{10} u + 5^{21} v = 5^{10} (u + 5^{11} v).$自从$u$不能被整除$5$，内项满足$u + 5^{11} v \not\equiv 0 \pmod 5$， 所以$v_5(S) = 10$。 对于$2$-adic估值，$v_2(P_A) = 14 \ge 10$， 和$v_2(P_B)$肯定大于$10$， 所以$v_2(S) \ge \min(v_2(P_A), v_2(P_B)) \ge 10.$因此总和$S = P_A + P_B$正好有$v_{10}(S) = \min(v_2(S), v_5(S)) = 10$尾随零。 这严格证实了所选分区产生的总和恰好以十个零结尾。 

对于三十个尾随零，最大可能的$5$-adic 估值总和为$\min(a,b) \le 15$， 自从$a + b = 31$。 拥有$v_5(S) \ge 30$， 两个都$a$和$b$至少需要$30$，这是不可能的。 这$2$-adic 估值充足，但尾随零的数量受到$5$-adic估值。 因此，不划分${1, 2, \dots, 127}$可以产生以三十个零结尾的和。 

## 关键步骤验证

 计算$v_5(127!) = 31$使用勒让德公式是正确的。 子集的构建$A$确保$v_5(P_A) = 10$和$v_2(P_A) = 14$，其中，连同非常大的$v_2(P_B)$，保证$v_{10}(S) = 10$。 这$5$- 总金额的adic估值是通过书面形式严格确定的$P_A = 5^{10} u$和$P_B = 5^{21} v$，注意到$u + 5^{11} v$不能被整除$5$。 三十个尾随零的不可能性论证依赖于加性约束$a + b = 31$并且是完全合理的，因为$\min(a,b) \le 15$防止总和超过 15 个因数$5$，使得三十个尾随零无法实现。 

## 替代方法

 生成函数方法可以将子集编码为多项式的系数并跟踪$5$-adic 和$2$-adic 组合估值。 每个子集对应于展开式中的一项$\prod_{k=1}^{127} (1 + x^k)$，以及指数$x$对子集乘积之和进行编码。 分析$5$-adic 和$2$-在此框架下的adic估值可以确定可行的金额。 这种方法比直接的方法复杂$p$-adic 参数与显式分区相结合，可以通过最少的计算立即证明存在性和不可能性性。
