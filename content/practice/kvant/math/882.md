 ## 问题

 三个整数之和$a$,$b$， 和$c$等于0。证明这个数$2a^4+2b^4+2c^4$是整数的平方。 

L. D. Kurlyandchik、A. S. Merkuryev、S. V. Fomin

 列宁格勒市数学奥林匹克竞赛（1984 年第 50 届）

 ## 探索

 考虑小整数三元组$(a,b,c)$满意的$a+b+c=0$。 如果$a=1$,$b=1$， 然后$c=-2$， 和$2a^4+2b^4+2c^4 = 2+2+32 = 36$，即$6^2$。 如果$a=2$,$b=-1$,$c=-1$， 然后$2a^4+2b^4+2c^4 = 2\cdot16 + 2\cdot1 + 2\cdot1 = 36$，又是一个完全平方数。 测试对称三元组，例如$(n,-n,0)$给出$2n^4 + 2n^4 + 0 = 4n^4 = (2n^2)^2$，它始终是一个正方形。 这些例子表明了一种对称模式，其中四次方的总和减少到完全平方，可能是通过代数恒等式利用$a+b+c=0$。 最有可能隐藏错误的步骤是假设这样的分解存在而不证明它，因为四次方可能表现得不规则，如果$a$,$b$,$c$have different magnitudes or signs.

 ## 问题理解

 The problem asks to show that for any integers$a$,$b$,$c$和$a+b+c=0$，表达式$2a^4+2b^4+2c^4$是一个完美的正方形。 这是 B 类问题，因为它要求证明通用属性而不是分类或优化。 核心难点在于操控$a^4+b^4+c^4$线性关系下$a+b+c=0$为了暴露一个隐藏的方块，该方块在扩展中不会立即明显。 直观上，对称性意味着用另外两个变量重写一个变量并对四次方之和进行因式分解。 

## 证明架构

 引理 1：如果$c = -(a+b)$， 然后$a^4+b^4+c^4 = a^4+b^4+(a+b)^4$。 这是由替换得出的。 

引理 2：展开式$(a+b)^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4$。 这是标准的二项式展开式。 

引理 3：合并同类项产生$a^4+b^4+(a+b)^4 = 2(a^2 + ab + b^2)^2$。 这通过显式代数计算得到验证。 

最难的方向是引理 3，因为它需要仔细的代数来识别完美的平方并确保没有遗漏任何项。 最微妙的步骤是结合三次项、二次项和交叉项来查看正方形结构。 

## 解决方案

 让$a$,$b$,$c$是整数使得$a+b+c=0$。 然后$c = -(a+b)$，兴趣表达变成$2a^4+2b^4+2c^4 = 2a^4 + 2b^4 + 2(a+b)^4.$扩展$(a+b)^4$使用二项式定理给出$(a+b)^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4.$添加$a^4$和$b^4$产量$a^4 + b^4 + (a+b)^4 = a^4 + b^4 + a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4 = 2a^4 + 2b^4 + 4a^3b + 6a^2b^2 + 4ab^3 + 2b^4.$仔细组合相似的项可以产生$a^4 + b^4 + (a+b)^4 = 2a^4 + 2b^4 + 4a^3b + 6a^2b^2 + 4ab^3 = 2(a^4 + 2a^3b + 3a^2b^2 + 2ab^3 + b^4).$观察一下$a^4 + 2a^3b + 3a^2b^2 + 2ab^3 + b^4 = (a^2 + ab + b^2)^2.$扩展$(a^2 + ab + b^2)^2$给出$(a^2 + ab + b^2)^2 = a^4 + 2a^3b + a^2b^2 + a^2b^2 + 2ab^3 + b^4 = a^4 + 2a^3b + 3a^2b^2 + 2ab^3 + b^4,$它与前面的表达式完全匹配。 所以，$2a^4 + 2b^4 + 2c^4 = 2(a^4 + b^4 + (a+b)^4) = 2\cdot 2(a^2 + ab + b^2)^2 = 4(a^2 + ab + b^2)^2 = (2(a^2 + ab + b^2))^2.$自从$a$和$b$是整数，$2(a^2 + ab + b^2)$是一个整数。 最后，$2a^4+2b^4+2c^4$是整数的平方$2(a^2+ab+b^2)$。 这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是确定$a^4 + 2a^3b + 3a^2b^2 + 2ab^3 + b^4$等于$(a^2+ab+b^2)^2$。 扩展$(a^2+ab+b^2)^2$独立地给予$a^4 + a^3b + a^2b^2 + a^2b^2 + ab^3 + b^4 + 2a^3b + 2ab^3 + a^2b^2$, 总结为$a^4 + 2a^3b + 3a^2b^2 + 2ab^3 + b^4$，确认完全匹配。 测试小整数三元组，例如$(1,1,-2)$和$(2,-1,-1)$产生与公式中相同的整数平方，确保没有算术监督。 

## 替代方法

 另一种方法重写$a^4+b^4+c^4$就对称多项式而言：$a+b+c$,$ab+bc+ca$， 和$abc$。 和$a+b+c=0$, 总和$a^4+b^4+c^4$可以表示为$2(ab+bc+ca)^2 - 8abc(a+b+c)$，减少到$2(ab+bc+ca)^2$。 虽然很优雅，但这需要熟悉牛顿恒等式，并且可能会掩盖直接的构造因式分解。 主要方法因其简单性和完美平方的明确演示而更受欢迎，熟悉二项式展开式的高中生完全可以理解。
