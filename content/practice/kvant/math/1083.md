 ## 问题

 最大的非负数$a_1$,$a_2$,$\ldots$,$a_n$是$a$。 

1.证明不等式$$\frac{a_1^2+a_2^2+\ldots+a_n^2}n\le\left(\frac{a_1+a_2+\ldots+a_n}{n}\right)^2+\frac{a^2}4$$2.什么时候实现平等？ 

L·G·卡宁

 ## 探索

 考虑较小的值$n$去理解不平等。 为了$n=2$，设数字为$a_1$和$a_2$和$a_2 \ge a_1 \ge 0$和$a_2 = a$。 不等式变为$\frac{a_1^2 + a_2^2}{2} \le \left(\frac{a_1 + a_2}{2}\right)^2 + \frac{a^2}{4}.$将右侧展开，$\left(\frac{a_1 + a_2}{2}\right)^2 + \frac{a_2^2}{4} = \frac{a_1^2 + 2a_1 a_2 + a_2^2}{4} + \frac{a_2^2}{4} = \frac{a_1^2 + 2a_1 a_2 + 2 a_2^2}{4}.$左侧是$\frac{a_1^2 + a_2^2}{2} = \frac{2a_1^2 + 2a_2^2}{4}$。 从右边减去左边得到$\frac{a_1^2 + 2 a_1 a_2 + 2 a_2^2 - 2 a_1^2 - 2 a_2^2}{4} = \frac{-a_1^2 + 2 a_1 a_2}{4} = \frac{a_1(2a_2 - a_1)}{4} \ge 0,$自从$0 \le a_1 \le a_2$。 这表明不平等是合理的。 

测试$n=3$和$0,0,a$给出$\frac{a^2}{3} \le \frac{a^2}{9} + \frac{a^2}{4} = \frac{13 a^2}{36} \approx 0.361 a^2$， 尽管$\frac{a^2}{3} \approx 0.333 a^2$，这也成立。 

平等发生于$n=2$如果$a_1 = 0$或者$a_1 = a_2$。 为了$n>2$，某些模式可能涉及所有数字$0$除了可能有一个或两个等于$a$。 

关键点是如何将不平等形式化$n$。 将其写为$\frac{1}{n} \sum_{i=1}^n a_i^2 - \left(\frac{\sum a_i}{n}\right)^2 \le \frac{a^2}{4}$建议使用类似方差的表达式，因为左侧是$\frac{1}{n} \sum a_i^2 - \bar a^2 = \frac{1}{n} \sum (a_i - \bar a)^2$，即平均平方偏差。 最大为$\sum (a_i - \bar a)^2$在下面$0 \le a_i \le a$当数字相距尽可能远时会发生：一些$0$， 一些$a$，至多有两个不同的值。 这是核心见解。 

## 问题理解

 该问题要求证明非负数的不等式$a_1, \dots, a_n$其最大值为$a$。 不等式将平方平均值除以平均值的平方$a^2/4$。 这是 B 类，因为要证明单个陈述。 核心难点在于控制数字的离散度和显示界限$\frac{a^2}{4}$就足够了。 平等情况需要识别使方差界限饱和的极值安排。 

## 证明架构

 引理 1：对于任何实数$x_1, \dots, x_n$, 身份$\frac{1}{n} \sum x_i^2 - \left(\frac{\sum x_i}{n}\right)^2 = \frac{1}{2 n^2} \sum_{i,j} (x_i - x_j)^2$成立，将差异表示为两两差异的平方平均值。 通过直接扩展也是如此。 

引理 2：在数中$[0,a]$, 总和$\sum_{i,j} (a_i - a_j)^2$当每个$a_i$等于$0$或者$a$，因为二次函数在区间的端点处达到极值。 

引理 3：对于数字$0 \le a_i \le a$只取$0$或者$a$, 总和$\sum_{i,j} (a_i - a_j)^2$是$2 k (n-k) a^2$， 在哪里$k$是的数量$a_i$等于$a$。 这是通过对不同的对进行计数来组合计算的。 最大值出现在$k = \lfloor n/2 \rfloor$或者$k = \lceil n/2 \rceil$, 最多给予$n^2 a^2 / 2$。 

主要论点：结合引理 1-3 来显示$\frac{1}{n} \sum a_i^2 - (\bar a)^2 \le a^2/4$，然后添加$\bar a^2$两边得到不等式。 等式仅发生在引理 3 中确定的极值配置中$k = n/2$如果$n$甚至或$k = (n \pm 1)/2$如果$n$奇怪的。 

## 解决方案

 对于数字$a_1, \dots, a_n$， 让$\bar a = \frac{1}{n} \sum_{i=1}^n a_i$。 然后$\frac{1}{n} \sum_{i=1}^n a_i^2 - \bar a^2 = \frac{1}{2 n^2} \sum_{i,j=1}^n (a_i - a_j)^2$通过扩展：$\sum_{i,j} (a_i - a_j)^2 = \sum_{i,j} (a_i^2 - 2 a_i a_j + a_j^2) = 2 n \sum a_i^2 - 2 (\sum a_i)^2$。 两边除以$2 n^2$给出身份。 

当每个$a_i$是$0$或者$a$，因为对于$x \in [0,a]$，函数$(x - y)^2$每个变量都是凸函数，并且紧凑区间上的凸函数在端点处达到最大值。 表示为$k$的数量$a_i$等于$a$。 然后是对数$(i,j)$和$a_i \neq a_j$是$2 k (n-k)$，并且每一对都贡献$a^2$到总和。 所以$\sum_{i,j} (a_i - a_j)^2 = 2 k (n-k) a^2.$最大为$k(n-k)$对于整数$k \in [0,n]$发生在$k = \lfloor n/2 \rfloor$或者$k = \lceil n/2 \rceil$, 给予$k(n-k) \le n^2 /4$。 因此$\frac{1}{2 n^2} \sum_{i,j} (a_i - a_j)^2 = \frac{1}{2 n^2} \cdot 2 k(n-k) a^2 = \frac{k(n-k)}{n^2} a^2 \le \frac{a^2}{4}.$添加$\bar a^2$双方都有收益$\frac{1}{n} \sum_{i=1}^n a_i^2 = \bar a^2 + \left(\frac{1}{n} \sum a_i^2 - \bar a^2\right) \le \bar a^2 + \frac{a^2}{4}.$平等恰好发生在$k = n/2$对于甚至$n$， 或者$k = (n \pm 1)/2$对于奇数$n$，并且所有数字都等于$0$或者$a$。 这样就完成了证明。 

∎
