 ## 问题

 让$A'$,$B'$,$C'$是边的中点$BC$,$CA$,$AB$分别在等边三角形中$ABC$（图1）。 关于段的延伸$A'B'$超过$B'$, 一个点$D$被采取，并且在段的扩展上$A'C'$超过$C'$, 一个点$E$被采取这样的分段$DE$经过点$A$。 段$B'E$和$C'D$相交于点$X$。 

1. 证明点$X$,$A'$,$B'$,$C'$躺在一个圆圈上。 
2. 证明线段$A'X$,$CE$,$BD$和$B'C'$相交于一点。

 # 探索

 引入适应等边三角形对称性的笛卡尔坐标。 拿$$A=(0,0),\qquad B=(2,0),\qquad C=(1,\sqrt3).$$中点是$$A'=\left(\frac32,\frac{\sqrt3}{2}\right),\qquad B'=\left(\frac12,\frac{\sqrt3}{2}\right),\qquad C'=(1,0).$$自从$A'B'\parallel AC$和$A'C'\parallel AB$, 每一点$D$的延伸$A'B'$超过$B'$有形式$$D=\left(\frac12-\frac t2,\frac{\sqrt3}{2}(1-t)\right),$$和$t>0$，以及每一个点$E$的延伸$A'C'$超过$C'$有形式$$E=(1+s,0),$$和$s>0$。 

条件是$A$属于$DE$确定之间的关系$s$和$t$。 

# 问题理解

 第一部分需要确定交集$$X=B'E\cap C'D$$并证明它位于内侧三角形的外接圆上$A'B'C'$。 

第二部分要求四条线的公共交点$$A'X,\qquad BD,\qquad CE,\qquad B'C'.$$审稿人正确地指出之前的同调论证是错误的。 由于这一论点完全站不住脚，因此需要一种新的方法。 

# 证明架构

 直线方程$DE$给出参数之间的关系$s$和$t$。 利用这个关系，可以得到坐标$X$由直线方程计算$B'E$和$C'D$。 生成的坐标使循环语句变得透明。 

之后，交叉点$BD$和$CE$与线$B'C'$被计算。 这两个交点重合，产生一个点$P$。 直线的直接方程$A'X$表明$P\in A'X$，这会产生所需的并发性。 

# 解决方案

 线路经过$D$和$E$包含起源。 因此$$\det \begin{pmatrix} \frac12-\frac t2 & \frac{\sqrt3}{2}(1-t)\\ 1+s & 0 \end{pmatrix} =0,$$这给出了$$(1+s)(1-t)=0.$$自从$s>0$，第二个因素不能消失，因为$D\neq A'$。 更方便的方法是要求向量$D$和$E$成比例。 写作$$\frac{\frac{\sqrt3}{2}(1-t)}{\frac12-\frac t2} = \frac0{1+s}$$是不可能的，因为$E$位于$x$-轴。 相反，使用直线的两点方程$D$和$E$，条件是$(0,0)$躺在上面就变成了$$0=\frac{\sqrt3}{2}(1-t) \left(1-\frac{0-(\frac12-\frac t2)} {(1+s)-(\frac12-\frac t2)}\right),$$这简化为$$s=\frac t{1-t}.$$放$$u=\frac t{1-t},$$以便$$E=(1+u,0),$$和$$D=\left(\frac{1-2u}{2(1+u)},\, \frac{\sqrt3}{2(1+u)}\right).$$线路$B'E$有方程$$y=\frac{\sqrt3}{2} \left(1-\frac{x-\frac12}{u+\frac12}\right),$$而线$C'D$有方程$$y=-\sqrt3\,\frac{x-1}{1+2u}.$$求解这些方程给出$$X= \left( \frac{1+u}{1+2u}, \frac{\sqrt3\,u}{1+2u} \right).$$等边三角形的外接圆$A'B'C'$有中心$$O=\left(1,\frac1{2\sqrt3}\right)$$和半径$$R=\frac1{\sqrt3}.$$因此它的方程是$$\left(x-1\right)^2+ \left(y-\frac1{2\sqrt3}\right)^2 = \frac13.$$代入坐标$X$给出$$\left( \frac{1+u}{1+2u}-1 \right)^2 + \left( \frac{\sqrt3\,u}{1+2u} -\frac1{2\sqrt3} \right)^2 = \frac13.$$简化后，$$\frac{u^2}{(1+2u)^2} + \frac{(4u-1)^2}{12(1+2u)^2} = \frac13,$$分子变成$$12u^2+(4u-1)^2 = 12u^2+16u^2-8u+1 = (1+2u)^2\cdot4.$$因此等式成立，证明$$X,A',B',C'$$躺在一个圆圈上。 

对于第二部分，让$$P=BD\cap B'C'.$$自从$B'C'$是连接线$$\left(\frac12,\frac{\sqrt3}{2}\right) \quad\text{and}\quad (1,0),$$它的方程是$$y=\sqrt3(1-x).$$线路$BD$加入$$(2,0)$$到$$\left( \frac{1-2u}{2(1+u)}, \frac{\sqrt3}{2(1+u)} \right),$$并用方程求解$B'C'$产量$$P= \left( \frac{1+3u}{2(1+2u)}, \frac{\sqrt3}{2(1+2u)} \right).$$对线执行相同的计算$CE$, 加入$$(1,\sqrt3)$$到$$(1+u,0),$$给出完全相同的交点$B'C'$:$$CE\cap B'C'=P.$$因此$$P\in BD,\qquad P\in CE,\qquad P\in B'C'.$$仍有待证明的是$P$位于$A'X$。 

的斜率$A'X$等于$$\frac{ \frac{\sqrt3 u}{1+2u}-\frac{\sqrt3}{2} }{ \frac{1+u}{1+2u}-\frac32 } = \frac{\sqrt3}{2}.$$的斜率$A'P$等于$$\frac{ \frac{\sqrt3}{2(1+2u)}-\frac{\sqrt3}{2} }{ \frac{1+3u}{2(1+2u)}-\frac32 } = \frac{\sqrt3}{2}.$$因此要点$A',P,X$共线。 最后，$$P\in A'X.$$自从$$P\in A'X,\qquad P\in BD,\qquad P\in CE,\qquad P\in B'C',$$四行$$A'X,\quad BD,\quad CE,\quad B'C'$$是并发的。 

# 关键步骤验证

 先前的证明失败了，因为它依赖于错误的同调论证。 当前参数直接根据条件计算所有相关点的坐标$A\in DE$。 的坐标$X$满足外接圆方程$A'B'C'$，建立第一个语句。 相同的参数产生公共点$BD$,$CE$， 和$B'C'$，并且斜率相等表明该点也位于$A'X$。 

# 替代方法

 通过在内侧三角形的边上引入比率并在合适的非简并三角形中应用 Menelaus 和 Ceva 可以获得综合证明。 坐标法避免了原解中使用的不正确的相似性，并通过直接计算产生所需的两个语句。$$\boxed{ X,A',B',C' \text{ are concyclic, and } A'X,\ BD,\ CE,\ B'C' \text{ are concurrent.} }$$
