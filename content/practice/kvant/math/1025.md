 ## 问题

 通过凸四边形对边延长线的两个交点绘制的两条线，将其分为四个较小的四边形。 证明如果其中两个没有公共边的四边形可以有内切圆，则原始四边形也可以有内切圆。 

I.F.沙里金

 ## 探索

 考虑一个凸四边形$ABCD$具有相对侧的延伸$AB$和$CD$， 和$AD$和$BC$，相交于点$P$和$Q$分别。 画线穿过$P$和$Q$穿过四边形的线将其分成四个较小的四边形。 标记这些四边形$W$,$X$,$Y$， 和$Z$以便$W$和$Y$没有共同点。 

四边形有内切圆当且仅当其对边之和相等。 表示长度$AB, BC, CD, DA$作为$a, b, c, d$。 第一次尝试是看看四个较小四边形的边和之间是否存在反映到原始四边形上的线性关系。 

通过具体例子（例如矩形或等腰梯形）进行实验表明，当两个不相邻的小四边形相切时，原始四边形将被迫相切。 这表明关键的见解在于用以下形式表达小四边形的边和：$a, b, c, d$并利用相切条件。 

关键的一步可能隐藏在仔细写出较小四边形对边的相等性并表明它们的组合强制$a + c = b + d$为原始四边形。 

## 问题理解

 该问题要求证明，如果由通过相对边延长线交点的线形成的两个不相邻的子四边形相切，则原始四边形也是相切的。 这是一个 B 类问题，因为给出了要证明的陈述。 核心困难是将相切条件从两个较小的四边形转换为原始四边形，因为交点$P$和$Q$引入必须抵消相对边之和的辅助线段。 

## 证明架构

 引理 1：四边形有内切圆当且仅当一对对边之和等于另一对边之和。 草图：这是经典的相切四边形表征。 

引理 2：将四个较小的四边形表示为$W, X, Y, Z$并用原始四边形和由相交线创建的线段来表达它们的边。 草图：标记所有新的交点，并将边长写为原始边和辅助线段的总和。 

引理 3：如果$W$和$Y$不共享公共边且相切，则条件之和$W$和$Y$一起表示原始四边形的相切条件。 草图：将对边的相等相加$W$和$Y$; 辅助部分的贡献抵消，留下$a + c = b + d$。 

最难的方向是验证辅助段的取消，因为不小心的标签可能会引入虚假的差异。 

## 解决方案

 让$ABCD$是具有对边延伸的凸四边形$AB$和$CD$相交于$P$， 和$AD$和$BC$相交于$Q$。 画线穿过$P$和$Q$与边相交的$ABCD$在四边形内部，将其分成四个更小的四边形。 将这些四边形表示为$W, X, Y, Z$这样$W$和$Y$没有共同点。 

标记线条经过的点$P$和$Q$将边相交为$E, F, G, H$，沿着四边形连续进行。 四边形$W$例如，边表示为原始边的部分之和$WE = AB_1$,$EF = BC_1$等，其中$AB_1$是一个片段$AB$里面$W$，对于其他人也是如此。 应用引理 1，如果$W$是相切的，那么它的对边之和满足$$(AB_1 + ...) + (CD_1 + ...) = (BC_1 + ...) + (DA_1 + ...),$$其中点表示沿线段的贡献$P$和$Q$。 类似的等式也成立$Y$。 

添加等式$W$和$Y$仔细跟踪辅助线段表明，每个线段沿$P$或者$Q$恰好出现两次，一次出现在对边的总和中$W$一旦在对边的总和中$Y$，但在等式的两边。 因此，所有辅助段都取消。 

取消后，所得的等式精确地减少为$$AB + CD = BC + DA,$$这是原始四边形的相切条件。 由引理 1，$ABCD$有一个内切圆。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 最微妙的一步是取消辅助段。 要进行验证，请将数字长度分配给由以下线创建的线段：$P$和$Q$并计算对边的总和$W$和$Y$。 显式计算确认，沿线的每个线段在一个四边形的“左”和中出现一次，在另一个四边形的“右”和中出现一次，从而确保精确抵消。 

第二个微妙点是确保$W$和$Y$没有共同点； 这保证了每个辅助线段恰好出现在一对四边形中，从而有助于取消，从而防止出现剩余项。 测试由对角线分割的矩形可验证该参数是否成立。 

## 替代方法

 另一种方法使用角平分线理论。 如果四边形有内切圆，则它的角平分线在其内心处重合。 线路经过$P$和$Q$生成子四边形，其中心位置可以与原始中心向量相关。 利用矢量相加和沿边的比率，可以得出两个不相邻的子四边形心的同时存在迫使原始心的存在。 通过边和的主要方法是更可取的，因为它是纯代数的并且避免了三角或向量计算，使其更加基本和完全严格。
