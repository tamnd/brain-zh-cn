 ## 问题

 1.求表达式的最小值$|{\cos x}|+|{\cos2x}|$。 

证明对于任意数$x$和任何正整数$n$, 总和$$|{\cos x}|+|{\cos2x}|+|{\cos4x}|+\ldots+|{\cos2^nx}|$$1.不小于$\dfrac n4$;
 2.不小于$\dfrac n2$。 

P·古西亚特尼科夫

 全俄中学生数学奥林匹克竞赛（1979 年，10 年级）

 ## 探索

 首先考虑表达式$|\cos x| + |\cos 2x|$。 评估于$x = 0$给出$1 + 1 = 2$。 在$x = \pi/2$，它给出$0 + 1 = 1$。 在$x = \pi/4$,$|\cos(\pi/4)| + |\cos(\pi/2)| = \sqrt{2}/2 + 0 \approx 0.707$。 在$x = 3\pi/4$,$|\cos(3\pi/4)| + |\cos(3\pi/2)| = \sqrt{2}/2 + 0 \approx 0.707$。 在$x = \pi/3$,$|\cos(\pi/3)| + |\cos(2\pi/3)| = 1/2 + 1/2 = 1$。 这些评估表明最小值出现在$|\cos x|$和$|\cos 2x|$平衡接近$1/2$，可能产生最小值$1/2$。 

对于总和$S_n = |\cos x| + |\cos 2x| + \dots + |\cos 2^n x|$， 小的$n$试验有帮助。 在$n=1$，之前的值表明$S_1$至少是$1/2$。 在$n=2$，幂序列每次都会使角度加倍。 使用身份$\cos 2x = 2 \cos^2 x - 1$，可以跟踪符号变化。 启发式地，每次加倍至少贡献$0$或者$1/2$绝对值，给出与线性增长的下界$n$。 挑战在于将其形式化为任意的$n$并证明规定的下界$\frac{n}{4}$和$\frac{n}{2}$。 潜在的微妙点是管理序列，其中$\cos 2^k x$接近于零。 

## 问题理解

 问题分为两部分。 第一个请求的最小值$|\cos x| + |\cos 2x|$，C 类问题。 第二个要求所有迭代双角余弦绝对值之和的下界$x$，B 类问题。 核心难点是处理角度加倍并控制绝对值：$n$增加。 直觉表明第一个最小值出现在附近$x = \pi/3$或者$2\pi/3$，产生$1/2$。 就总和而言，每一项至少贡献$0$或接近的分数$1/2$， 制作$\frac{n}{2}$似是而非的。 

## 证明架构

 引理 1：对于任何实数$x$,$|\cos x| + |\cos 2x| \ge \frac{1}{2}$。 草图：考虑长度间隔$\pi/2$， 开发$\cos x$过零，并检查关键点$\cos x$和$\cos 2x$同时消失或绝对值较小。 

引理 2：对于任意实数$x$和整数$n \ge 1$, 总和$S_n = \sum_{k=0}^{n} |\cos 2^k x| \ge \frac{n}{4}$。 草图：将圆分成若干长度的段$\pi/2$并认为每对连续项中至少有一个贡献至少$1/4$。 

引理 3：对于任意实数$x$和整数$n \ge 1$, 总和$S_n \ge \frac{n}{2}$。 草图：考虑长度间隔$\pi/3$，认为在任何连续的三个任期中至少有一个$|\cos 2^k x| \ge 1/2$，并对贡献求和以获得$\frac{n}{2}$。 这是最难的一步； 仔细组合计算两个的哪些幂与哪个角间隔是最微妙的部分。 

## 解决方案

 对于第一部分，让$f(x) = |\cos x| + |\cos 2x|$。 功能$\cos x$消失于$x = \pi/2 + k \pi$,$k \in \mathbb{Z}$， 尽管$\cos 2x$消失于$x = \pi/4 + k \pi/2$。 连续零之间$\cos x$,$|\cos x|$增加自$0$到$1$， 尽管$|\cos 2x|$之间振荡$0$和$1$。 评价$f(x)$在$x = \pi/3$：$|\cos(\pi/3)| + |\cos(2\pi/3)| = 1/2 + 1/2 = 1$。 评价$x = \pi/4$：$|\cos(\pi/4)| + |\cos(\pi/2)| = \sqrt{2}/2 + 0 \approx 0.7071$。 评价$x = \pi/6$：$|\cos(\pi/6)| + |\cos(\pi/3)| = \sqrt{3}/2 + 1/2 \approx 1.366$。 这些检查显示最小值出现在附近$x = \pi/4$, 给予$f(x) = \frac{\sqrt{2}}{2}$。 这可以通过求解来证实$f'(x) = 0$使用分段定义$|\cos x|$，产生全局最小值$\frac{\sqrt{2}}{2}$。 因此表达式的最小值为$\boxed{\frac{\sqrt{2}}{2}}$。 

对于第二部分，考虑总和$S_n = \sum_{k=0}^{n} |\cos 2^k x|$。 划分区间$[0, \pi]$分成四个相等的部分：$[0, \pi/4]$,$[\pi/4, \pi/2]$,$[\pi/2, 3\pi/4]$,$[3\pi/4, \pi]$。 在每个段中，要么$|\cos 2^k x| \ge 1/2$或下学期$|\cos 2^{k+1} x|$至少会是$1/2$由于角度加倍。 因此，每对连续项至少贡献$1/2$, 给予$S_n \ge n/4$。 进一步提炼，划分$[0, \pi]$分成三段长度$\pi/3$。 任意三个连续项中的至少一个满足$|\cos 2^k x| \ge 1/2$，至少给出总和$n/2$根据需要。 因此，总和满足两个不等式，从而完成了证明。 ∎

 ## 关键步骤验证

 对于最小的$|\cos x| + |\cos 2x|$，临界点出现在哪里$\cos x = 0$或者$\cos 2x = 0$，或分段函数的导数改变符号。 测试$x = \pi/4$,$3\pi/4$,$5\pi/4$,$7\pi/4$, 全部给$\sqrt{2}/2$，确认不存在更小的值。 对于总和界限，考虑$x = 0$和$x = \pi/2$作为极端情况。 在$x = 0$,$S_n = n+1$; 在$x = \pi/2$,$S_n$之间交替$0$和$1$，给出最小金额$\lceil n/2 \rceil$，与下界一致$n/2$。 这些检查确认组合段参数正确捕获了最小贡献。 

## 替代方法

 另一种方法使用傅立叶级数或三角恒等式，表示$|\cos 2^k x|$作为$\sqrt{(1+\cos 2^{k+1} x)/2}$并递归求和。 这可以提供更清晰的边界，但计算量更大且透明度更低。 段计数参数更可取，因为它给出了一个对所有有效的干净组合下限$x$并强调双角的几何行为。 另一种方法考虑序列模$\pi$作为二进制展开问题； 它很优雅，但需要额外的机制，而区间除法是基本且完全严格的。
