 ## 问题

 证明如果$abc=4Rrr_c$， 在哪里$a$,$b$,$c$是三角形的边，并且$R$,$r$,$r_c$是外接圆、内圆和其中一个外圆的半径，则三角形是直角。 （外圆接触侧面$c$以及另外两侧的延伸。）

 B. Tureshbaev，11 年级学生

 ## 探索

 我们有一个有边的三角形$a$,$b$,$c$和关系$abc = 4R r r_c,$在哪里$R$是外接圆半径，$r$是内半径，并且$r_c$是外半径的对边$c$。 目标是证明这个条件意味着三角形是直角的。 标准公式用三角形的半周长来表达这些半径$s = \frac{a+b+c}{2}$和面积$\Delta$作为$R = \frac{abc}{4\Delta}, \qquad r = \frac{\Delta}{s}, \qquad r_c = \frac{\Delta}{s-c}.$将它们代入给定的关系将产生一个仅涉及的恒等式$s$,$\Delta$和边长。 使用海伦公式$\Delta = \sqrt{s(s-a)(s-b)(s-c)}$然后将允许简化纯粹双方之间的关系$a$,$b$,$c$，这可以证明强制$c^2 = a^2 + b^2$。 

## 问题理解

 问题是要证明边长和半径的特定乘积表征直角三角形。 自然的方法是使用已知公式消除半径，并将给定条件简化为边之间的代数方程。 核心步骤是正确操纵所得的恒等式并证明它与毕达哥拉斯定理等效。 

## 证明架构

 证明通过将标准公式替换为$R$,$r$， 和$r_c$代入给定条件，得到方程$\Delta$和$s$。 然后应用 Heron 公式来替换$\Delta$具有边长和半周长的表达式。 这产生了立方恒等式$s$，可以系统地简化以揭示$c^2 = a^2 + b^2$。 连接步骤中的关键是仔细的代数$(s-a)(s-b)$和$s(s-c)$到毕达哥拉斯条件。 

## 解决方案

 让$\Delta$表示三角形的面积，$s = \frac{a+b+c}{2}$半周长。 外接圆半径、内半径和外半径对边的标准公式$c$是$R = \frac{abc}{4\Delta}, \qquad r = \frac{\Delta}{s}, \qquad r_c = \frac{\Delta}{s-c}.$将这些代入给定条件，得到$4R r r_c = 4 \cdot \frac{abc}{4\Delta} \cdot \frac{\Delta}{s} \cdot \frac{\Delta}{s-c} = \frac{abc \, \Delta}{s(s-c)}.$将此等同于$abc$给出$abc = \frac{abc \, \Delta}{s(s-c)} \implies \Delta = s(s-c),$除以$abc$是合理的，因为三角形是非退化的并且$abc > 0$。 

应用海伦公式，我们有$\Delta = \sqrt{s(s-a)(s-b)(s-c)}.$将其等同于$\Delta = s(s-c)$给出$\sqrt{s(s-a)(s-b)(s-c)} = s(s-c) \implies (s-a)(s-b) = s(s-c).$用边来表达每一项$a$,$b$,$c$:$s = \frac{a+b+c}{2}, \quad s-a = \frac{b+c-a}{2}, \quad s-b = \frac{a+c-b}{2}, \quad s-c = \frac{a+b-c}{2}.$将这些代入$(s-a)(s-b) = s(s-c)$给出$\frac{b+c-a}{2} \cdot \frac{a+c-b}{2} = \frac{a+b+c}{2} \cdot \frac{a+b-c}{2}.$两边同时乘以 4 得到等价方程$(b+c-a)(a+c-b) = (a+b+c)(a+b-c).$仔细展开两边，左边变成$$\begin{aligned} (b+c-a)(a+c-b) &= (b)(a) + (b)(c-b) + (c-a)(a+c-b) \\ &= ab + bc - b^2 + ac + c^2 - bc - a^2 - ac + ab \\ &= 2ab - a^2 - b^2 + c^2 \\ &= c^2 - (a-b)^2 + 2ab. \end{aligned}$$更系统地拓展$(b+c-a)(a+c-b)$:$$(b+c-a)(a+c-b) = b a + b c - b^2 + c a + c^2 - c b - a^2 - a c + a b = 2ab - a^2 - b^2 + c^2,$$这简化为$c^2 - (a-b)^2 + 2ab = a^2 + b^2 + 2ab - (a^2 + b^2 - c^2) = 2ab + c^2 - a^2 - b^2.$右侧展开为$(a+b+c)(a+b-c) = (a+b)^2 - c^2 = a^2 + 2ab + b^2 - c^2.$使两个展开式相等可得$2ab + c^2 - a^2 - b^2 = a^2 + 2ab + b^2 - c^2 \implies 2c^2 = 2(a^2 + b^2) \implies c^2 = a^2 + b^2.$因此三角形满足毕达哥拉斯定理。 根据毕达哥拉斯定理的逆命题，角度的对边$c$是直角，三角形也是直角。$\boxed{\text{The triangle is right-angled.}}$## 关键步骤验证

 标准公式的替代$R$,$r$， 和$r_c$是有效的。 的推导$\Delta = s(s-c)$直接从给定条件得出。 应用Heron公式来代替$\Delta$是合理的，并且代数从$(s-a)(s-b) = s(s-c)$到$c^2 = a^2 + b^2$系统地进行，没有遗漏任何因素。 每一步都仅依赖于标准三角形恒等式和非简并假设，使论证完整。 

## 替代方法

 可以直接表达$r$和$r_c$按照$a$,$b$,$c$和$R$不调用半周长。 使用$r = \frac{2\Delta}{a+b+c}$和$r_c = \frac{2\Delta}{-a-b+c+2c}$最终将条件降低为二次$c^2$，这会得出相同的结论$c^2 = a^2 + b^2$。 通过半周长和海伦公式的方法更加优雅，因为它自然地将计算减少到单一恒等式和因子。
