 ## 问题

 在平面上，给出 12 个点，它们是四个正方形的顶点$A_1B_1A_2C_1$,$A_2C_2A_3B_2$,$A_3B_3A_4C_3$， 和$A_4C_4A_1B_4$（每个正方形的顶点按顺时针顺序列出）。 证明$B_1B_2B_3B_4$和$C_1C_2C_3C_4$是全等的平行四边形，其中一个是通过旋转从另一个获得的$90^\circ$（这些平行四边形可能是退化的：在这种情况下，每个平行四边形的四个顶点位于一条直线上）。 

L·P·库普佐夫

 ## 探索

 该问题涉及四个正方形排列在一个具有共享顶点的平面上，形成一条链：第一个正方形的第二个顶点与第二个正方形的顶点重合，依此类推，最后回到第一个正方形。 将正方形表示为$A_1B_1A_2C_1$,$A_2C_2A_3B_2$,$A_3B_3A_4C_3$， 和$A_4C_4A_1B_4$，人们注意到$B_i$和$C_i$点形成两个独立的四边形。 主张这些四边形是全等的平行四边形，并且其中一个是$90^\circ$对方的旋转。 

最初的方法是将坐标分配给$A_1$,$A_2$,$A_3$,$A_4$以简单的配置（例如，在晶格上）并计算$B_i$和$C_i$明确地。 Early trials suggest that$B_1B_2B_3B_4$和$C_1C_2C_3C_4$形成边相等且角度相关的全等四边形$90^\circ$。 关键的步骤似乎是将“平方”旋转转换为向量加法，然后表达$B_i$和$C_i$作为向量的旋转版本$A_iA_{i+1}$。 

最微妙的一点是正确处理循环周围的索引，因为每个方块与其邻居共享一个顶点。 不小心贴错标签很容易得出关于全等或旋转的错误结论。 

## 问题理解

 问题是 B 类，“证明”几何构型具有某种属性。 给定四个循环连接的正方形，并要求我们证明由$B_i$点并由$C_i$点是全等的平行四边形，一个点通过另一个点获得$90^\circ$旋转。 核心困难是将正方形的组合排列转化为正方形之间的向量关系$B_i$和$C_i$点并严格证明全等，而不依赖图表。 直观上，正方形强制向量进行刚性旋转，因此$B_i$和$C_i$四边形继承了旋转对称性。 

## 证明架构

 引理 1：在任意正方形中$PQRS$顺时针列出，从第一个顶点到第二个顶点的矢量，旋转$90^\circ$顺时针方向，等于从第一个顶点到第四个顶点的向量。 这遵循标准正方形几何形状，并且可以通过坐标或旋转公式进行验证。 

引理 2：每个$B_i$可以表示为$B_i = A_i + \mathbf{v}_i$， 在哪里$\mathbf{v}_i$通过旋转得到$A_iA_{i+1}$经过$90^\circ$顺时针。 同样，每个$C_i = A_i + \mathbf{w}_i$， 和$\mathbf{w}_i$相同的向量旋转$90^\circ$逆时针。 这直接从应用于每个方块的引理 1 得出。 

引理 3：围绕循环的连续旋转向量的总和消失：$\mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 + \mathbf{v}_4 = 0$类似地对于$\mathbf{w}_i$。 这是由四边形的闭合得出的$A_1A_2A_3A_4$在飞机上。 

引理 4：四边形$B_1B_2B_3B_4$和$C_1C_2C_3C_4$是平行四边形。 的各边向量$B_1B_2B_3B_4$等于两个连续旋转向量的总和$\mathbf{v}_i$，引理 3 暗示对边相等。 

引理 5：$B_1B_2B_3B_4$和$C_1C_2C_3C_4$是一致的，并且一个是$90^\circ$对方的旋转。 这是因为$\mathbf{w}_i$通过旋转得到$\mathbf{v}_i$经过$90^\circ$，并且在旋转下保留和的同余性。 

最难的引理是引理 5，因为它需要仔细跟踪围绕闭合方块链旋转的累积效应。 

## 解决方案

 让$A_1$,$A_2$,$A_3$,$A_4$是给定的四个正方形的共享顶点。 考虑第一个正方形$A_1B_1A_2C_1$。 向量来自$A_1$到$A_2$被旋转$90^\circ$顺时针屈服$A_1B_1$，并旋转$90^\circ$逆时针屈服$A_1C_1$。 表示$\mathbf{v}_1 = \overrightarrow{A_1B_1}$和$\mathbf{w}_1 = \overrightarrow{A_1C_1}$。 根据正方形的性质，$\mathbf{w}_1$通过旋转得到$\mathbf{v}_1$经过$90^\circ$。 

将相同的推理应用于第二个正方形$A_2C_2A_3B_2$，向量$\overrightarrow{A_2A_3}$旋转的$90^\circ$顺时针产量$\overrightarrow{A_2B_2}$，逆时针旋转得到$\overrightarrow{A_2C_2}$。 同样定义$\mathbf{v}_2 = \overrightarrow{A_2B_2}$和$\mathbf{w}_2 = \overrightarrow{A_2C_2}$。 第三个和第四个方格的产量$\mathbf{v}_3, \mathbf{v}_4$和$\mathbf{w}_3, \mathbf{w}_4$以同样的方式。 

四边形$B_1B_2B_3B_4$有边向量$\overrightarrow{B_1B_2} = \overrightarrow{A_1B_1} + \overrightarrow{B_1B_2} - \overrightarrow{A_1B_1} = \mathbf{v}_1 + \mathbf{v}_2,$

$\overrightarrow{B_2B_3} = \mathbf{v}_2 + \mathbf{v}_3,$

$\overrightarrow{B_3B_4} = \mathbf{v}_3 + \mathbf{v}_4,$

$\overrightarrow{B_4B_1} = \mathbf{v}_4 + \mathbf{v}_1.$将所有四个边向量相加得出$\overrightarrow{B_1B_2} + \overrightarrow{B_2B_3} + \overrightarrow{B_3B_4} + \overrightarrow{B_4B_1} = 2(\mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 + \mathbf{v}_4).$四边形$A_1A_2A_3A_4$是关闭的，所以$\overrightarrow{A_1A_2} + \overrightarrow{A_2A_3} + \overrightarrow{A_3A_4} + \overrightarrow{A_4A_1} = 0$。 每个$\mathbf{v}_i$是一个$90^\circ$的旋转$\overrightarrow{A_iA_{i+1}}$，因此旋转后的总和也会消失：$\mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 + \mathbf{v}_4 = 0.$因此，边向量的总和$B_1B_2B_3B_4$为零，确认关闭。 此外，对边相等：$\overrightarrow{B_1B_2} = \mathbf{v}_1 + \mathbf{v}_2 = \overrightarrow{B_3B_4}, \quad \overrightarrow{B_2B_3} = \mathbf{v}_2 + \mathbf{v}_3 = \overrightarrow{B_4B_1},$所以$B_1B_2B_3B_4$是一个平行四边形。 同样的推理也适用于$C_1C_2C_3C_4$， 使用$\mathbf{w}_i$而不是$\mathbf{v}_i$。 

每个$\mathbf{w}_i$是从获得$\mathbf{v}_i$由一个$90^\circ$旋转，所以整个四边形$C_1C_2C_3C_4$是从获得$B_1B_2B_3B_4$通过旋转$90^\circ$。 由于旋转保持距离，因此平行四边形全等。 退化的情况$A_1A_2A_3A_4$是共线的简并平行四边形。 

这样就完成了证明。
