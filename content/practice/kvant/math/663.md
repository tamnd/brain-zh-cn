 ## 问题

 找出所有质数$p$其中的数字$2^p+p^2$也是素数。 

S·麦祖斯

 ## 探索

 考虑小素数来理解表达式的行为$2^p + p^2$。 为了$p = 2$，我们有$2^2 + 2^2 = 4 + 4 = 8$，这不是素数。 为了$p = 3$,$2^3 + 3^2 = 8 + 9 = 17$，这是素数。 为了$p = 5$,$2^5 + 5^2 = 32 + 25 = 57$，可除以$3$并且不是素数。 为了$p = 7$,$2^7 + 7^2 = 128 + 49 = 177$，可除以$3$并且不是素数。 为了$p = 11$,$2^{11} + 11^2 = 2048 + 121 = 2169$，可除以$3$并且不是素数。 这种模式表明对于奇素数$p > 3$, 总和$2^p + p^2$可能总是可以被整除$3$，这会阻止它成为素数。 最有可能隐藏错误的步骤是严格确认所有大于的奇素数的整除性声明$3$。 

## 问题理解

 该问题要求所有素数$p$这样$2^p + p^2$也是素数。 这是一个 A 类问题，因为我们被要求找到满足给定条件的所有数字，并且解决方案必须对所有可能性进行分类。 核心难点在于处理所有奇素数$p > 3$并证明他们都不能$2^p + p^2$主要的。 通过探索，直观的答案似乎是$p = 3$，因为较小的素数会失败，而较大的素数似乎受到模考虑的限制，特别是模$3$。 

## 证明架构

 引理 1：如果$p = 2$， 然后$2^p + p^2$不是素数。 通过直接计算得出：$2^2 + 2^2 = 8$。 

引理 2：如果$p = 3$， 然后$2^p + p^2$是素数。 直接计算给出$2^3 + 3^2 = 17$，这是素数。 

引理 3：如果$p$是一个奇素数大于$3$， 然后$2^p + p^2$可以整除$3$。 这依赖于一致性$2^p \equiv 2 \pmod 3$和$p^2 \equiv 1 \pmod 3$, 给予$2^p + p^2 \equiv 0 \pmod 3$。 这是最难的引理，因为模运算的粗心应用可能会因小而失败$p$。 

## 解决方案

 引理1通过计算得到验证$2^2 + 2^2 = 8$，这不是素数。 

引理2通过计算得到验证$2^3 + 3^2 = 8 + 9 = 17$，这是素数。 

对于引理 3，让$p$是大于的奇素数$3$。 然后$p$是一致的$1$或者$2$模数$3$。 计算$2^p$模数$3$。 自从$2^1 \equiv 2 \pmod 3$和$2^2 \equiv 1 \pmod 3$, 的权力$2$模数$3$周期循环$2$。 因此，如果$p \equiv 1 \pmod 2$， 然后$2^p \equiv 2 \pmod 3$。 下一个，$p^2 \equiv 1 \pmod 3$因为$p \equiv 1$或者$2 \pmod 3$。 添加这些，$2^p + p^2 \equiv 2 + 1 \equiv 0 \pmod 3$。 自从$2^p + p^2 > 3$，它不可能是素数。 

唯一剩下的候选人是$p = 3$，这已经得到验证。 

因此，完整的素数列表$p$这样$2^p + p^2$是质数是$\boxed{3}.$## 关键步骤验证

 关键的一步是奇素数的模论证$p > 3$。 验证与$p = 5$:$2^5 = 32 \equiv 2 \pmod 3$,$5^2 = 25 \equiv 1 \pmod 3$, 总和$32 + 25 = 57 \equiv 0 \pmod 3$。 为了$p = 7$:$2^7 = 128 \equiv 2 \pmod 3$,$7^2 = 49 \equiv 1 \pmod 3$, 总和$128 + 49 = 177 \equiv 0 \pmod 3$。 这些例子证实了引理的有效性。 周期长度为$2$模数$3$被正确应用。 

## 替代方法

 另一种方法是分别考虑奇偶校验和小素数。 注意到对于$p$甚至，$p = 2$给出一个复合和，对于奇数$p > 3$,$2^p + p^2$总是可以整除$3$，立即排除所有较大的素数。 这种方法在严格性上是等效的，但在写作上更短。 所选择的方法是更可取的，因为它明确地标识了负责所有排除的模块约束，使论证透明且通用。
