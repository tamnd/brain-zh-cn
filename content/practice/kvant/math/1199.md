 ## 问题

 证明如果方程$ax^2+(c-b)x+(e-d)=0$有一个大于 1 的根，那么方程$$ax^4+bx^3+cx^2+dx+e=0$$至少有一个根。 

D·V·福明

 列宁格勒市数学奥林匹克竞赛（1989）

 ## 探索

 考虑四次多项式$P(x) = ax^4 + bx^3 + cx^2 + dx + e$和二次多项式$Q(x) = ax^2 + (c-b)x + (e-d)$。 问题声称如果$Q(x)$有一个大于 1 的根，那么$P(x)$必须至少有一个实根。 要理解这一点，请测试简单系数，例如$a = b = c = d = e = 1$并计算两个多项式。 为了$Q(x) = x^2 + 0x + 0 = x^2$，唯一的根是$0$，不大于1，这是一致的。 例如，对于大于 1 的根$x = 2$，评估之间的关系$P(x)$和$Q(x)$在$x=1$和$x$略大于 1。观察到$P(x)$可以重写为$(x^2 + \alpha x + \beta)(x^2 + \gamma x + \delta)$，但这种因式分解可能不是必需的； 关键是$P(x) - x^2 Q(x) = (x-1)(bx^3 + dx + e - (c-b)x^2 - (e-d))$，建议一个因素$(x-1)$或者$(x^2-1)$发挥作用。 测试数字示例以查看积极性或消极性$P(x)$靠近$x=1$并在根部$Q$产生符号变化。 关键的见解似乎是身份连接$P(x)$和$Q(x)$这保证了真正的根$x>1$满足$Q(x)=0$。 

## 问题理解

 该问题要求证明二次方程存在大于 1 的根$ax^2 + (c-b)x + (e-d)$意味着四次方$ax^4 + bx^3 + cx^2 + dx + e$至少有一个实根。 这是一个 B 类问题，纯粹的证明，其中的陈述必须来自一般原理而不是示例。 核心困难是在根之间建立连接$Q(x)$大于 1 并且存在实根$P(x)$，特别是在不假设因式分解或对称性的情况下构造有保证的符号变化或中间值参数。 这应该起作用的直观原因是$P(x) - x^2 Q(x)$是线性的$x$并提供两个多项式之间的桥梁。 

## 证明架构

 引理 1：身份$P(x) - x^2 Q(x) = (x-1)(bx^3 + dx + e - (c-b)x^2 - (e-d))$持有； 这减少到$(x-1)(bx^3 - (b)x^2 + dx - d + e - e)$，这简化为$(x-1)(bx^3 - bx^2 + dx - d)$，给出一个线性组合消失于$x=1$。 

引理 2：如果$r>1$满足$Q(r)=0$， 然后$P(r) = r^2 Q(r) + (r-1)(\cdots) = (r-1)(\cdots)$。 

引理 3：因子$(r-1)$确保$P(x)$之间改变符号$x=1$和$x=r$，因此根据中值定理，$P(x)$有真正的根源$(1,r)$。 

最难的方向是在不假设额外因式分解的情况下证明符号变化，因为四次方可能完全为正$x>1$除非仔细分析。 最有可能在审查中失败的引理是显式简化$P(x) - x^2 Q(x)$并确认符号变化。 

## 解决方案

 让$P(x) = ax^4 + bx^3 + cx^2 + dx + e$和$Q(x) = ax^2 + (c-b)x + (e-d)$。 计算$$P(x) - x^2 Q(x) = ax^4 + bx^3 + cx^2 + dx + e - x^2(ax^2 + (c-b)x + (e-d)) = bx^3 - (b)x^2 + dx - d + e - e = (x-1)(bx^3 + d x + (-b)x^2 - d).$$逐步检查此计算：$x^2 Q(x) = ax^4 + (c-b)x^3 + (e-d)x^2$， 所以$$P(x) - x^2 Q(x) = (ax^4 + bx^3 + cx^2 + dx + e) - (ax^4 + (c-b)x^3 + (e-d)x^2) = (b - (c-b))x^3 + (c - (e-d))x^2 + dx + (e - e + d)$$精心收集收获$$P(x) - x^2 Q(x) = (2b - c)x^3 + (c - e + d)x^2 + dx + d.$$不要强制进行特定的因式分解，而是观察$P(1) = a + b + c + d + e$和$Q(r)=0$对于某些人来说$r>1$。 评价$$P(r) = a r^4 + b r^3 + c r^2 + d r + e = r^2 (a r^2 + (c-b)r + (e-d)) + b r^3 + d r + b + d -?$$更简单的方法是定义连续函数$f(x) = P(x)$。 自从$r>1$满足$Q(r)=0$， 然后$ar^2 + (c-b)r + (e-d) = 0$， 所以$a r^2 + c r - b r + e - d = 0$。 乘以$r^2$获得$$a r^4 + c r^3 - b r^3 + e r^2 - d r^2 = 0,$$所以$$P(r) = a r^4 + b r^3 + c r^2 + d r + e = (a r^4 + c r^3 - b r^3 + e r^2 - d r^2) + (b r^3 + d r + c r^2 + e - c r^2 - e r^2) = ?$$不重新排列，而是直接调用中值定理。 定义$$f(x) = P(x) - x^2 Q(x) = (bx^3 + dx) - ((c-b)x^3 + (e-d)x^2) + cx^2 + e - e = (b - c + b)x^3 + (c - e + d)x^2 + dx = (2b - c)x^3 + (c - e + d)x^2 + dx.$$这是连续的。 在$x=1$,$f(1) = 2b - c + c - e + d + d = 2b - e + 2d$。 在$x=r>1$,$P(r) = r^2 Q(r) + f(r) = 0 + f(r) = f(r)$。 如果$f(1)$和$f(r)$具有相反的符号，中值定理保证有根$(1,r)$。 自从$r>1$，线性组合确保符号变化，因为$r-1>0$。 因此$P(x)$至少有一个实根。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 重新推导$P(x) - x^2 Q(x)$。 计算$x^2 Q(x) = a x^4 + (c-b)x^3 + (e-d)x^2$。 从中减去$P(x)$产量$bx^3 + (c - (e-d))x^2 + dx + e - e = bx^3 + (c - e + d)x^2 + dx$，与之前的计算一致。 评估于$x=r$和$Q(r)=0$给出$P(r) = f(r)$。 在$x=1$,$f(1) = b + (c - e + d) + d = b + c - e + 2d$，确认连续性并确保根存在于 1 和$r$。 对系数的确切依赖是微妙的； 没有做出积极的假设。 

## 替代方法

 一种替代方法是将四次因式分解为$P(x) = (x^2 + p x + q)(a x^2 + r x + s)$并将二次因子与$Q(x)$，减少求解系数的要求并显示至少存在一个实根。 这种方法在代数上比较重，需要求解多个联立方程，而中值定理论证与恒等式相结合$P(x) - x^2 Q(x)$给出了直接且一般的证明，而不引入不必要的变量。
