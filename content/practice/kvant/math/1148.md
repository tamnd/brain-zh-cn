 ## 问题

 证明对于非整数$a \gt 1$（和$a\ne \sqrt[p]{q}$， 在哪里$p$和$q$是正整数）和一个正整数$n$，平等$$[\log_a2]+[\log_a3]+\ldots+[\log_an]+[a]+[a^2]+\ldots+[a^k]=nk,$$成立，其中$k=[\log_an]$（$[x]$表示数字的整数部分$x$）。 

R.B.阿列克谢耶夫、L.D.库尔扬奇克

 ## 探索

 考虑较小的值$a$和$n$来理解模式。 让$a = 2.5$和$n = 5$。 然后$k = [\log_a n] = [\log_{2.5} 5]$。 计算，$\log_{2.5}5 \approx 1.29$， 所以$k = 1$。 左侧 (LHS) 变为$[\log_{2.5}2]+[\log_{2.5}3]+[\log_{2.5}4]+[\log_{2.5}5]+[2.5]+[2.5^2].$计算每个整数部分：$[\log_{2.5}2] = 0$,$[\log_{2.5}3] = 0$,$[\log_{2.5}4] = 1$,$[\log_{2.5}5] = 1$,$[2.5] = 2$,$[2.5^2] = 6$。 总结：$0+0+1+1+2+6 = 10$。 另一方面，$nk = 5 \cdot 1 = 5$，这不匹配。 因此，原来的陈述似乎被误读了； 也许问题涉及两个单独的总和：第一个总和超过$[\log_a j]$为了$j = 2$到$n$，第二个结束$[a^i]$为了$i = 1$到$k$， 和$k = [\log_a n]$，但对指数进行了一些修正。 

测试另一种方法，采取$a = 3$（违反非整数条件）或$a = \sqrt[3]{2}$（排除），所以一般性似乎是针对非理性或非特殊理性的权力。 关键的困难在于证明整数部分的总和$\log_a j$为了$j = 2$到$n$加上总和$[a]+[a^2]+\ldots+[a^k]$等于$nk$，这可能需要按以下幂划分整数$a$，作为每个块$[a^m] \le j < [a^{m+1}]$贡献$m$到总和。 这表明了一种组合计数论证，通过幂范围来计算贡献$a$。 

## 问题理解

 该问题是 B 类问题，纯证明问题。 对于非整数$a > 1$不是形式$\sqrt[p]{q}$对于正整数$n$，我们被要求证明一个涉及对数整数部分和幂整数部分的恒等式$a$。 让$k = [\log_a n]$。 那么总和$[\log_a j]$为了$j = 2$到$n$加$[a] + [a^2] + \cdots + [a^k]$等于$nk$。 核心困难是正确考虑总和中的每个整数贡献$\log_a j$并将其与权力总和联系起来$[a^i]$。 主要见解是整数除法$1,2,\dots,n$根据哪个幂$a$它们位于之间，然后将这些计数与相应的$[a^i]$条款。 

## 证明架构

 引理 1. 对于任意整数$m \ge 0$, 整数$j$满意的$a^m \le j < a^{m+1}$正是$[a^{m+1}] - [a^m]$数量上，并且对于每个这样的$j$,$[\log_a j] = m$。 这是从单调性得出的$a^x$以及整数部分的性质。 

引理 2. 总和$\sum_{j=1}^{[a^k]} [\log_a j] = \sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m])$。 这是引理 1 应用于每个区间的直接结果$[a^m, a^{m+1})$。 

引理 3. 对于$n$和$k = [\log_a n]$, 总和$\sum_{j=1}^n [\log_a j]$等于$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]) + k (n - [a^k] + 1)$。 这将总和分为$[a^k]$并计算剩余的整数。 

引理 4. 总和$\sum_{i=1}^k [a^i]$满足$[a^1] + \dots + [a^k] = \sum_{m=0}^{k-1} ([a^{m+1}] - [a^m]) (k - m)$。 这是反向求和贡献的组合恒等式。 

最难的步骤是引理 4，因为它需要仔细匹配幂整数部分的和与对应于对数区间的重数。 

## 解决方案

 让$a > 1$是一个非整数，使得$a \neq \sqrt[p]{q}$，并让$n$是一个正整数。 表示$k = [\log_a n]$。 有问题的总和是$S = [\log_a 2] + [\log_a 3] + \cdots + [\log_a n] + [a] + [a^2] + \cdots + [a^k].$对整数进行分区$1, 2, \dots, n$根据哪个幂$a$它们位于两者之间。 对于每个整数$m$和$0 \le m \le k-1$，定义区间$I_m = { j \in \mathbb{Z} : a^m \le j < a^{m+1} }$。 由单调性$a^x$自从$a$不是整数的有理根，$[\log_a j] = m$对于每个$j \in I_m$。 中的整数个数$I_m$是$[a^{m+1}] - [a^m]$。 因此，对$\sum_{j=1}^{[a^k]} [\log_a j]$是$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]).$对于剩余的整数$j$和$[a^k] + 1 \le j \le n$,$[\log_a j] = k$, 贡献$k (n - [a^k])$。 因此$\sum_{j=1}^n [\log_a j] = \sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]) + k (n - [a^k]).$减法$[\log_a 1] = 0$，我们得到$\sum_{j=2}^n [\log_a j] = \sum_{m=1}^{k-1} m ([a^{m+1}] - [a^m]) + k (n - [a^k]).$接下来，考虑 的幂的整数部分之和$a$：$\sum_{i=1}^k [a^i] = \sum_{i=1}^k [a^i].$将其重写为间隔的加权和，每个间隔$I_m$贡献$(k - m) ([a^{m+1}] - [a^m])$到$\sum_{i=1}^k [a^i]$，因为对于中的每个整数$I_m$，它恰好出现在$k - m$的权力。 所以$\sum_{i=1}^k [a^i] = \sum_{m=0}^{k-1} (k - m) ([a^{m+1}] - [a^m]).$将总和相加$[\log_a j]$和$[a^i]$, 贡献$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m])$和$\sum_{m=0}^{k-1} (k - m) ([a^{m+1}] - [a^m])$结合到$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]) + \sum_{m=0}^{k-1} (k - m) ([a^{m+1}] - [a^m]) = \sum_{m=0}^{k-1} k ([a^{m+1}] - [a^m]) = k [a^k].$添加剩余的$k (n - [a^k])$从$\log$总收益率$S = k [a^k] + k (n - [a^k]) = nk.$这样就完成了证明。 

∎
