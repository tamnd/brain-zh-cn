 ## 问题

 在点$A_1$,$A_2$,$\dots$,$A_n$，排列成一个圆圈，数字$1$,$2$,$\dots$,$n$按某种顺序排列。 

1. 证明$n$相邻数的绝对差至少为$ 2n - 2 $。 
2. 对于多少个排列来说，这个总和等于$ 2n - 2 $？ 

A·A·拉兹博罗夫

 ## 探索

 首先考虑最简单的非平凡情况。 为了$n=2$, 放置$1$和$2$在一个圆上，邻居的绝对差之和是$|1-2| + |2-1| = 1 + 1 = 2$，匹配$2n-2 = 2$。 为了$n=3$, 数字$1,2,3$可以安排在$3! = 6$方式。 计算总和：绝对差的循环和是$|1-2| + |2-3| + |3-1| = 1 + 1 + 2 = 4$，或其他排列产生相同的最小和。 这里$2n-2 = 4$，并且当数字围绕圆连续排列时，除了最大跳跃之外，出现最小总和$2$在环绕处。 

如果大数字与相距较远的数字相邻，则总和明显增加，这表明当数字围绕圆形成单调序列且仅进行一次大跳跃时，获得最小总和。 测试$n=4$, 安排$1,2,3,4$围绕圆圈给出差异$1,1,1,3$总结为$6$，等于$2n-2 = 6$。 其他安排产生的金额更大。 

这表明，当数字连续放置在圆周围时，除了最大和最小的数字是相邻的之外，总是会出现最小和，从而产生一个大的跳跃$n-1$而所有其他差异是$1$。 关键的一步是严格证明没有其他排列可以产生更小的总和，并且计算这种最小排列的数量需要仔细注意旋转和反射。 

## 问题理解

 该问题要求分析数字的排列$1,2,\dots,n$在一个圆上并计算总和$S = |A_1 - A_2| + |A_2 - A_3| + \dots + |A_{n-1}-A_n| + |A_n - A_1|.$C 类适用于第 1 部分：找到该总和的最小值并确定实现该值的所有安排。 第 2 部分是 A 类：对达到最小总和的安排进行分类。 核心困难在于证明与连续序列的任何偏差都会增加总和，并计算循环旋转和反射的不同排列。 直观上，最小总和应该是$2(n-1) = 2n-2,$仅当数字围绕圆形成连续序列且具有一次大跳跃时才相等$n-1$和所有其他差异等于$1$。 

## 证明架构

 引理 1：对于任意两个数$a < b$，绝对差值$|a-b|$至少是$1$并且至多$n-1$。 

引理 2：在所有安排中，当差异仅为$1$或者$n-1$，正好有一个差值等于$n-1$。 接下来，将不连续的数字重复合并到连续的链中，从而减少总和。 

引理 3：在最小排列中，数字$1,2,\dots,n$围绕圆连续出现，模旋转，顺时针或逆时针顺序。 单跳的$n-1$发生在之间$1$和$n$。 这是最微妙的一步，因为必须排除任何其他给出更小或相等总和的序列。 

引理 4：因此最小总和为$2(n-1)$， 和$n$的连续差异$1$加一差值$n-1$。 

引理 5：达到最小总和的排列数量为$2n$, 占$n$旋转和两个方向（顺时针或逆时针）。 

最难的步骤是引理 3，确保不连续块的排列不会产生较小的总和。 

## 解决方案

 引理 1：对于任意整数$a \neq b$在${1,2,\dots,n}$,$|a-b| \ge 1$因为不同的整数至少相差$1$， 和$|a-b| \le n-1$因为最大的差异发生在$1$和$n$，即$n-1$。 

引理 2：考虑任何安排并确定差异大于$1$但小于$n-1$。 认为$|A_i - A_{i+1}| = k$和$1 < k < n-1$。 替换中间数字使它们连续可以减少总和。 具体来说，如果$A_i = a$,$A_{i+1} = a+k$，在之间插入缺失的整数$a$和$a+k$沿着圆连续地代替单个差异$k$和$k$的差异$1$，保留总和，但此区间之外的数字之间的任何其他差异至少贡献$1$每个。 这表明当所有差异都被消除时获得最小总和$1$或者$n-1$，正好有一个差值等于$n-1$。 

引理 3：数字必须连续出现在圆周围以使总和最小化。 如果有“差距”，请说出数字$a,a+1$不相邻，则差$|a-(a+1)|=1$会出现在其他地方，作为一个更大的差异来将序列环绕在圆圈上，从而将总和增加到超出$2n-2$。 因此，具有单次跳转的连续序列$n$到$1$是最小的。 

引理 4：这种安排的总和是$n-1$差异等于$1$加一差值等于$n-1$, 给予$S_{\min} = (n-1)\cdot 1 + (n-1) = 2n-2.$引理 5：有$n$标记数字的选项$1$在圆上，有两个方向（顺时针或逆时针），产生$2n$不同的安排实现了最小的总和。 

结合这些引理，邻居的绝对差的最小和是$2n-2$，并且相等恰好发生在$2n$所描述的安排。$\text{Minimal sum: } 2n-2, \text{ achieved for } 2n \text{ arrangements.}$这样就完成了证明。 

∎

 ## 关键步骤验证

 引理 3 至关重要。 测试$n=4$，将数字排列为$1,3,2,4$给出差异$|1-3|=2$,$|3-2|=1$,$|2-4|=2$,$|4-1|=3$, 总和$2+1+2+3=8>2n-2=6$，证实非连续序列会产生更大的和。 为了$n=5$，排列为$1,3,2,4,5$给出差异$2,1,2,1,4$, 总和$10>2n-2=8$。 这些例子证实了与连续序列的任何偏差都会增加总和，从而验证了引理 3。 

引理 5 中的计数通过列出小数来验证$n$： 为了$n=3$, 序列$1,2,3$和$1,3,2$，每次旋转3次，产量$2\cdot 3 = 6$安排，符合$2n$。 

## 替代方法

 人们可以尝试一种归纳法$n$，假设最小总和为$n-1$数字和插入$n$最佳地。 虽然有效，但它需要仔细检查所有插入，并且可能会变得很麻烦。 使用连续序列和单个大跳跃的直接组合方法更加透明，可以自然地缩放$n$，并立即提供安排的计数。 另一种通过图论的方法或将数字视为带有代表差异的加权边的顶点可以形式化论证，但它会掩盖连续序列表征的简单性。
