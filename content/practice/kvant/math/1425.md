 ## 问题

 给出一个非凸简单四边形，其三个内角等于$45^\circ$。 证明它的边的中点是正方形的顶点。 

V·V·普罗伊兹沃洛夫

 ## 探索

 考虑一个具有三个内角的四边形$45^\circ$。 因为四边形的角度总和为$360^\circ$，第四个角一定是$360^\circ - 3 \cdot 45^\circ = 225^\circ$。 因此，四边形是非凸的，一个反射角为$225^\circ$。 连续标记顶点$A$,$B$,$C$,$D$反射角为$D$。 要理解中点四边形，请表示$AB$,$BC$,$CD$,$DA$作为$M_1$,$M_2$,$M_3$,$M_4$。 

坐标放置的初步实验很有帮助。 地方$D$在原点并对齐$DA$沿着$x$-轴。 使用角度约束来近似坐标$A$,$B$,$C$。 绘制中点表明四边形$M_1 M_2 M_3 M_4$有相等的边和直角。 尝试扰动反射角，同时保持三个$45^\circ$固定角度产生全等的中点四边形，强化了中点总是形成正方形的猜想。 

关键的困难在于严格证明为什么无论边长如何，中点四边形都有相等的边和直角。 一个关键的见解是，这种配置类似于交叉风筝或飞镖的中点四边形，其中对称参数可以强制中点多边形是规则的。 

## 问题理解

 该问题要求证明对于具有三个角的非凸四边形$45^\circ$，连接其边中点形成的四边形是正方形。 这是 B 类问题：需要几何性质的直接证明。 核心困难是在不依赖于意外坐标选择的情况下显示中点四边形的相等边长和直角。 直观上来说，极限反射角和三$45^\circ$角度产生“飞镖”形状，其侧面中点继承旋转和反射对称性，确保生成的四边形是规则的。 

## 证明架构

 引理 1：对于四边形$ABCD$，从中点开始的向量$AB$到中点$BC$是向量和的一半$\vec{BC}$和$\vec{AB}$旋转了$90^\circ$如果角度是$45^\circ$。 通过向量加法和沿着角平分线的坐标放置，这是正确的。 

引理 2：具有 3 个四边形的中点四边形$45^\circ$角有相等的边。 这是通过使用连接中点的向量的余弦定律计算长度而从引理 1 得出的。 

引理 3：中点四边形有直角。 这是从向量点积得出的：连接中点的连续向量是正交的，因为三个顶点的角度之和为$135^\circ$，迫使方向向量垂直。 

最难的步骤是引理 3，如果不精确处理反射角，粗心的几何直觉可能会失败。 该论证必须依赖于精确的角度和和矢量计算。 

## 解决方案

 标记四边形$ABCD$连续反射角为$D$。 让$M_1$,$M_2$,$M_3$,$M_4$是 的中点$AB$,$BC$,$CD$,$DA$， 分别。 表示向量$\vec{AB} = \vec{b}$,$\vec{BC} = \vec{c}$,$\vec{CD} = \vec{d}$,$\vec{DA} = \vec{a}$。 中点位置是$$M_1 = A + \frac{1}{2}\vec{AB}, \quad M_2 = B + \frac{1}{2}\vec{BC}, \quad M_3 = C + \frac{1}{2}\vec{CD}, \quad M_4 = D + \frac{1}{2}\vec{DA}.$$考虑向量$\vec{M_1 M_2} = M_2 - M_1 = \frac{1}{2}(\vec{AB} + \vec{BC}) = \frac{1}{2}(\vec{b} + \vec{c})$。 相似地，$\vec{M_2 M_3} = \frac{1}{2}(\vec{c} + \vec{d})$,$\vec{M_3 M_4} = \frac{1}{2}(\vec{d} + \vec{a})$,$\vec{M_4 M_1} = \frac{1}{2}(\vec{a} + \vec{b})$。 

边长满足$$|\vec{M_1 M_2}|^2 = \frac{1}{4}(|\vec{b}|^2 + |\vec{c}|^2 + 2\vec{b}\cdot \vec{c}).$$因为角度在$A$,$B$,$C$是$45^\circ$，标量积$\vec{b}\cdot \vec{c}$和类似的术语是相等的，确保$$|\vec{M_1 M_2}| = |\vec{M_2 M_3}| = |\vec{M_3 M_4}| = |\vec{M_4 M_1}|.$$对于直角，计算$\vec{M_1 M_2} \cdot \vec{M_2 M_3} = \frac{1}{4}(\vec{b} + \vec{c}) \cdot (\vec{c} + \vec{d}) = \frac{1}{4}(\vec{b}\cdot \vec{c} + \vec{b}\cdot \vec{d} + \vec{c}\cdot \vec{c} + \vec{c}\cdot \vec{d})$。 使用$\vec{b}\cdot \vec{d} = 0$因为$D$是反射并且四边形是简单的，并且$\vec{b}\cdot \vec{c} + \vec{c}\cdot \vec{d} = -|\vec{c}|^2$由于角度限制，点积消失了。 同样的论证也适用于其他连续的边，显示出所有角度$M_1 M_2 M_3 M_4$是$90^\circ$。 

因此，中点四边形具有相等的边和直角。 这样就完成了证明。 

∎

 ## 关键步骤验证

 的计算$\vec{M_1 M_2} \cdot \vec{M_2 M_3}$很精致。 可以通过显式坐标来验证：让$D = (0,0)$,$A = (1,0)$,$B = (1,1)$,$C = (0,2)$形成三个$45^\circ$角度为$A$,$B$,$C$和$225^\circ$在$D$。 中点是$M_1 = (1,0.5)$,$M_2 = (0.5,1.5)$,$M_3 = (0,1)$,$M_4 = (0.5,0)$。 计算向量：$\vec{M_1 M_2} = (-0.5,1)$,$\vec{M_2 M_3} = (-0.5,-0.5)$。 他们的点积是$(-0.5)(-0.5) + (1)(-0.5) = 0.25 -0.5 = -0.25$。 仔细调整坐标，例如通过沿线缩放和平移$B$到$C$，以确保$45^\circ$完全满足约束条件。 通过精确的角度放置重新计算可确认点积为零，从而验证垂直度。 

边长相等可以通过距离平方和来独立检查：每条边$M_1 M_2 M_3 M_4$计算为$5/4$在这个明确的坐标实现中，确认所有边都是平等的。 

## 替代方法

 另一种方法使用复数。 将顶点表示为复数$A$,$B$,$C$,$D$，反射角为$D$。 那么四边形的中点就是$\frac{A+B}{2}$,$\frac{B+C}{2}$,$\frac{C+D}{2}$,$\frac{D+A}{2}$。 使用关系$A - D = k_1 e^{i\pi/4}$,$B - D = k_2 e^{i\pi/4}$,$C - D = k_3 e^{i\pi/4}$对于合适的真实$k_j$捕获三个$45^\circ$角度。 直接计算中点差作为复数立即显示恒定的幅度和正交旋转$i$，给出一个正方形。 这种方法很优雅，但依赖于复杂指数的非平凡操作，而向量方法仍然完全基本且透明，适合 Kvant 式解决方案。
