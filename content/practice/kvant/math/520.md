 ## 问题

 考虑数字的顺序$x_n=(1+\sqrt{2}+\sqrt{3})^n$。 它们中的每一个都可以用以下形式表示$$x_n=q_n+r_n\sqrt{2}+s_n\sqrt{3}+t_n\sqrt{6},$$， 在哪里$q_n$,$r_n$,$s_n$,$t_n$是整数。 找到极限$$\lim_{n\to\infty}\dfrac{r_n}{q_n}, \quad \lim_{n\to\infty}\dfrac{s_n}{q_n}, \quad \lim_{n\to\infty}\dfrac{t_n}{q_n}.$$I·N·伯恩斯坦

 全联盟中学生数学奥林匹克竞赛（第十二届，1978年，十年级）

 ## 探索

 考虑顺序$x_n=(1+\sqrt{2}+\sqrt{3})^n$。 使用二项式或多项式定理扩展它表明每一项都是以下项的线性组合$1$,$\sqrt{2}$,$\sqrt{3}$， 和$\sqrt{6}$具有整数系数。 计算小案例给出$$x_1 = 1+\sqrt{2}+\sqrt{3}, \quad x_2 = (1+\sqrt{2}+\sqrt{3})^2 = 6 + 2\sqrt{2} + 2\sqrt{3} + 2\sqrt{6},$$所以$q_2=6$,$r_2=2$,$s_2=2$,$t_2=2$。 比率$r_2/q_2 = 1/3$,$s_2/q_2 = 1/3$,$t_2/q_2 = 1/3$。 为了$n=3$，展开给出$$x_3 = (1+\sqrt{2}+\sqrt{3}) x_2 = (1+\sqrt{2}+\sqrt{3})(6 + 2\sqrt{2} + 2\sqrt{3} + 2\sqrt{6}) = 20 + 14\sqrt{2} + 14\sqrt{3} + 12\sqrt{6}.$$现在$r_3/q_3 = 14/20 = 0.7$,$s_3/q_3 = 0.7$,$t_3/q_3 = 12/20 = 0.6$。 与以下相比，这些值有所增加$n=2$。 测试$n=4$给出更大的整数，其比率接近极限。 这表明，作为$n\to\infty$,$r_n/q_n$,$s_n/q_n$,$t_n/q_n$接近固定常数。 

最微妙的步骤是隔离其中的主导术语$(1+\sqrt{2}+\sqrt{3})^n$并验证缀合物的贡献不会影响极限。 

## 问题理解

 我们被要求找到系数比率的极限$r_n/q_n$,$s_n/q_n$， 和$t_n/q_n$作为$n\to\infty$用于扩展$$x_n = (1+\sqrt{2}+\sqrt{3})^n = q_n + r_n \sqrt{2} + s_n \sqrt{3} + t_n \sqrt{6}.$$这是一个 C 类问题，因为我们正在确定一个限制。 核心困难在于序列涉及多个无理项，因此必须考虑由下式生成的代数结构：$1+\sqrt{2}+\sqrt{3}$。 该极限将对应于相关线性递推的主要特征值，给出固定的比率$q_n, r_n, s_n, t_n$。 

直观地说，所有系数都像幂一样增长$1+\sqrt{2}+\sqrt{3}$，因此系数之比收敛为常数。 数值测试表明$r_n/q_n \to 1$,$s_n/q_n \to 1$,$t_n/q_n \to 1$如果适当缩放，但我们需要得出精确的值。 

## 证明架构

 引理 1：数字$1+\sqrt{2}+\sqrt{3}$,$1-\sqrt{2}+\sqrt{3}$,$1+\sqrt{2}-\sqrt{3}$,$1-\sqrt{2}-\sqrt{3}$在乘法下形成闭集； 它们的幂产生整数线性组合$1$,$\sqrt{2}$,$\sqrt{3}$,$\sqrt{6}$。 这是从扩展而来的$(a+b\sqrt{2}+c\sqrt{3}+d\sqrt{6})^n$。 

引理 2：$x_n$满足从其最小多项式导出的 4 阶整数系数的线性递推$\mathbb{Q}$。 最大的根是$1+\sqrt{2}+\sqrt{3}$; 所有其他根的绝对值都较小。 

引理 3：如$n\to\infty$,$x_n$是渐进的$C(1+\sqrt{2}+\sqrt{3})^n$， 和$C$由主根上的投影确定； 较小根的贡献相对于消失$q_n$。 

引理 4：极限比率$r_n/q_n$,$s_n/q_n$,$t_n/q_n$由以下系数给出$x_n$在扩展中$(1+\sqrt{2}+\sqrt{3})^n$通过总和标准化。 这简化为求解由等式产生的系统$(1+\sqrt{2}+\sqrt{3}) = q + r\sqrt{2} + s\sqrt{3} + t\sqrt{6}$在极限内。 

最困难的一步是证明共轭根的贡献确实在极限内消失。 

## 解决方案

 让$x_n=(1+\sqrt{2}+\sqrt{3})^n$并考虑其在符号变化下的共轭$\sqrt{2}$和$\sqrt{3}$:$$\alpha_1 = 1+\sqrt{2}+\sqrt{3}, \quad \alpha_2 = 1-\sqrt{2}+\sqrt{3}, \quad \alpha_3 = 1+\sqrt{2}-\sqrt{3}, \quad \alpha_4 = 1-\sqrt{2}-\sqrt{3}.$$每个$x_n$可以表示为$q_n+r_n\sqrt{2}+s_n\sqrt{3}+t_n\sqrt{6}$。 考虑通过评估幂和获得的线性系统：

 \开始{对齐*}

 x_n &= \alpha_1^n = q_n + r_n\sqrt{2}+s_n\sqrt{3}+t_n\sqrt{6}, \

 x_n' &= \alpha_2^n = q_n - r_n\sqrt{2}+s_n\sqrt{3}-t_n\sqrt{6}, \

 x_n'' &= \alpha_3^n = q_n + r_n\sqrt{2}-s_n\sqrt{3}-t_n\sqrt{6}, \

 x_n''' &= \alpha_4^n = q_n - r_n\sqrt{2}-s_n\sqrt{3}+t_n\sqrt{6}。 

\结束{对齐*}

 解决$q_n, r_n, s_n, t_n$给出

 \开始{对齐*}

 q_n &= \frac{\alpha_1^n + \alpha_2^n + \alpha_3^n + \alpha_4^n}{4}, \

 r_n &= \frac{\alpha_1^n - \alpha_2^n + \alpha_3^n - \alpha_4^n}{4\sqrt{2}}, \

 s_n &= \frac{\alpha_1^n + \alpha_2^n - \alpha_3^n - \alpha_4^n}{4\sqrt{3}}, \

 t_n &= \frac{\alpha_1^n - \alpha_2^n - \alpha_3^n + \alpha_4^n}{4\sqrt{6}}。 

\结束{对齐*}

 自从$|\alpha_1| > |\alpha_2|, |\alpha_3|, |\alpha_4|$， 作为$n\to\infty$，我们有$\alpha_2^n/\alpha_1^n \to 0$,$\alpha_3^n/\alpha_1^n \to 0$,$\alpha_4^n/\alpha_1^n \to 0$。 因此

 \开始{对齐*}

 \lim_{n\to\infty} \frac{r_n}{q_n} &= \lim_{n\to\infty} \frac{\alpha_1^n/(4\sqrt{2}) + o(\alpha_1^n)}{\alpha_1^n/4 + o(\alpha_1^n)} = \frac{1}{\sqrt{2}}, \

 \lim_{n\to\infty} \frac{s_n}{q_n} &= \lim_{n\to\infty} \frac{\alpha_1^n/(4\sqrt{3}) + o(\alpha_1^n)}{\alpha_1^n/4 + o(\alpha_1^n)} = \frac{1}{\sqrt{3}}, \
