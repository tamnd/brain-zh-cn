 ## 问题

 在对角线上$AC$和$CE$正六边形的$ABCDEF$, 点$M$和$N$分别选择使得$$\frac{|AM|}{|AC|} = \frac{|CN|}{|CE|}=\lambda.$$。 据了解，有以下几点$B$,$M$， 和$N$位于同一条直线上。 寻找$\lambda$。 

国际数学奥林匹克竞赛（第二十三届，1982 年）

 ## 探索

 考虑一个正六边形$ABCDEF$具有连续标记的顶点。 对角线$AC$和$CE$每条边都分开，因此它们的长度是六边形边长的两倍。 让点$M$和$N$划分$AC$和$CE$以同样的比例$\lambda$， 那是，$AM = \lambda AC$和$CN = \lambda CE$。 条件是$B$,$M$， 和$N$共线是高度对称的并且表明$\lambda$与六边形几何形状产生的简单分数有关，可能涉及$1/2$,$1/3$， 或者$2/3$。 使用坐标几何似乎很有前途：地点$A$在原点和$AB$沿着积极的方向$x$-轴。 这允许显式坐标$C$,$E$,$M$， 和$N$，并将共线性条件简化为简单的行列式或斜率等式。 一张小支票$\lambda = 1/2$或者$\lambda = 1/3$将指示哪个分数满足共线性。 

## 问题理解

 该问题要求确定一个唯一的比率$\lambda$这样如果点$M$和$N$按该比例划分正六边形的两条不相邻的对角线，然后$B$,$M$， 和$N$共线。 这是一个 A 类问题，因为它要求找到所有可能的值$\lambda$。 核心困难是以易于处理的代数形式表达共线性条件，同时管理六边形的对称性。 直观地说，$\lambda$应该是由对角线对称划分产生的简单分数，可能与正六边形几何中的标准比例有关。 

## 证明架构

 引理 1：边长为正六边形的顶点坐标$1$可以在平面上表示为$A = (0,0)$和$AB$沿着$x$-轴; 这是通过将点放置在半径为圆的圆上得出的$1$并使用标准三角学。 

引理 2：要点$M$和$N$可以表示为$M = A + \lambda (C-A)$和$N = C + \lambda (E-C)$; 根据线段上比例除法的定义，这是正确的。 

引理 3：三点$B$,$M$， 和$N$当且仅当由它们的坐标形成的矩阵的行列式为零时，它们是共线的； 这是根据平面共线性的标准公式得出的。 

引理 4：代入坐标$B$,$M$， 和$N$进入共线性条件产​​生线性方程$\lambda$，其唯一解对应于所需的比例； 这成立是因为共线性条件是线性的$\lambda$由于点坐标的线性。 

最难的步骤是引理 4，计算错误可能会产生错误的结果$\lambda$。 行列式方法确保系统检查。 

## 解决方案

 将六边形放置在坐标平面中$A = (0,0)$和$AB$沿着积极的方向$x$-轴。 由于六边形的边长是规则的$1$,$B = (1,0)$,$C = (3/2, \sqrt{3}/2)$,$D = (1, \sqrt{3})$,$E = (0, \sqrt{3})$,$F = (-1/2, \sqrt{3}/2)$。 

观点$M$划分$AC$在比例中$\lambda$， 所以$M = A + \lambda(C-A) = (0,0) + \lambda\left(\frac{3}{2}, \frac{\sqrt{3}}{2}\right) = \left(\frac{3\lambda}{2}, \frac{\sqrt{3}\lambda}{2}\right).$观点$N$划分$CE$在比例中$\lambda$， 所以$N = C + \lambda(E-C) = \left(\frac{3}{2}, \frac{\sqrt{3}}{2}\right) + \lambda\left(-\frac{3}{2}, \frac{\sqrt{3}}{2}\right) = \left(\frac{3}{2}(1-\lambda), \frac{\sqrt{3}}{2}(1+\lambda)\right).$共线性条件为$B=(1,0)$,$M=(3\lambda/2, \sqrt{3}\lambda/2)$,$N=(3(1-\lambda)/2, \sqrt{3}(1+\lambda)/2)$要求斜率从$B$到$M$等于斜率$B$到$N$：$\frac{\sqrt{3}\lambda/2 - 0}{3\lambda/2 - 1} = \frac{\sqrt{3}(1+\lambda)/2 - 0}{3(1-\lambda)/2 - 1}.$化简每个分数：左边是$\frac{\sqrt{3}\lambda}{3\lambda - 2}$，右边是$\frac{\sqrt{3}(1+\lambda)}{3 - 3\lambda - 2} = \frac{\sqrt{3}(1+\lambda)}{1 - 3\lambda}$。 因此方程是$\frac{\sqrt{3}\lambda}{3\lambda - 2} = \frac{\sqrt{3}(1+\lambda)}{1 - 3\lambda}.$取消$\sqrt{3}$和叉乘：$\lambda (1 - 3\lambda) = (1+\lambda)(3\lambda - 2).$两边展开：$\lambda - 3\lambda^2 = 3\lambda + 3\lambda^2 - 2 - 2\lambda = \lambda + 3\lambda^2 - 2$。 

将所有项移至一侧：$\lambda - 3\lambda^2 - (\lambda + 3\lambda^2 - 2) = 0 \implies -6\lambda^2 + 2 = 0 \implies 3\lambda^2 = 1 \implies \lambda^2 = \frac{1}{3}.$因此$\lambda = \frac{1}{\sqrt{3}}$。 

验证证实斜率等式成立，因此这是唯一的解决方案。$\boxed{\lambda = \frac{1}{\sqrt{3}}}$## 关键步骤验证

 首先，六边形的坐标分配与边长一致$1$并保留所有距离。$AC$和$CE$确实有预期的长度，$|AC| = |CE| = \sqrt{3}$，因此比例除法有效。 

二、共线性方程表达后在坐标上是纯线性的$M$和$N$，以及从斜率等式到二次的代数操作$\lambda$逐项仔细检查。 最终的二次方程仅产生一个正解$\lambda = 1/\sqrt{3}$与片段的一小部分一致。 

## 替代方法

 复数方法将六边形顶点放置为适当缩放的六次单位根。 然后$M$和$N$成为这些根的凸组合，共线性减少到乘积消失的虚部。 这种方法很优雅，并且避免了显式坐标，但需要仔细操作复数和单位根。 坐标方法更直接，产生明确的数字，并允许立即验证，这使得它更适合严格的解决方案阐述。
