 ## 问题

 考虑序列$\{x_n\}$满足条件的正数$$1=x_0 \ge x_1\ge x_2\ge\ldots\ge x_n\ge\ldots$$1. 证明对于任何这样的序列$\{x_n\}$存在$n$为此$$\frac{x_0^2}{x_1}+\frac{x_1^2}{x_2}+\ldots+\frac{x_{n-1}^2}{x_n}\ge3{,}999.$$2. 找到一个序列$\{x_n\}$满足规定的条件，使得对于每个$n$,$$\frac{x_0^2}{x_1}+\frac{x_1^2}{x_2}+\ldots+\frac{x_{n-1}^2}{x_n}\lt4.$$A·格里什科夫

 国际中学生数学奥林匹克竞赛（第二十三届，1982 年）

 ## 探索

 我们被要求研究正数序列$x_0, x_1, x_2, \dots$和$x_0 = 1$和$x_0 \ge x_1 \ge x_2 \ge \dots$。 第一部分询问某个比率之和最终是否超过一个大数，具体来说$3999$。 总和的形式为$S_n = \frac{x_0^2}{x_1} + \frac{x_1^2}{x_2} + \dots + \frac{x_{n-1}^2}{x_n}.$第二部分要求一个明确的序列，使得所有这些总和保持在以下$4$为所有人$n$。 

如果序列是恒定的，则用简单序列进行实验$x_n = 1$， 然后$S_n = n$，无限增长。 如果序列呈几何递减，则说$x_n = r^n$为了$0 < r < 1$， 然后$S_n = \sum_{k=0}^{n-1} r^{2k}/r^{k+1} = \sum_{k=0}^{n-1} r^{k-1}$。 这笔金额无限增长，除非$r$非常接近$1$。 

保留以下总和$4$，序列必须极其缓慢地减小。 例如，形式的序列$x_n = 1 - \varepsilon_n$与精心挑选的$\varepsilon_n \to 0$可以满足要求。 

第一部分的关键步骤是证明任何非递增的正序列最终必须使总和$S_n$任意大。 微妙的一点是处理递减非常缓慢的序列； 我们必须排除以下可能性：$S_n$仍然有界。 对于第二部分，挑战是构建一个以受控方式递减的序列，以使总和保持有界。 

## 问题理解

 该问题有两个独立但相关的部分。 第一个是 B 类：证明对于任意序列满足$1 = x_0 \ge x_1 \ge x_2 \ge \dots > 0$，连续平方比的总和最终超过$3999$。 第二种是 D 型：构造一个序列，使得对于所有$n$，连续平方比之和保持在以下$4$。 核心难点是理解总和的增长$S_n$就序列的衰减率而言。 对于第一部分，总和必须因正性和非递增性质而被迫发散； 对于第二部分，必须通过足够缓慢减小的序列来仔细控制总和。 直观上，第一部分是不可避免的，因为一系列正面术语的普遍分歧； 第二部分需要明确构建快速稳定的序列。 

## 证明架构

 引理 1：对于任何正递减序列${x_n}$和$x_0 = 1$, 总和$S_n = \sum_{k=0}^{n-1} x_k^2 / x_{k+1}$发散。 草图：不等式$x_k^2 / x_{k+1} \ge x_k \ge x_n$确保对于足够大的$n$，总和超过任何固定常数。 

引理 2：存在一个序列${x_n}$和$x_0 = 1$和$x_0 \ge x_1 \ge \dots > 0$这样$\sum_{k=0}^{n-1} x_k^2 / x_{k+1} < 4$为所有人$n$。 草图：定义$x_0 = 1$,$x_{n+1} = x_n^2 / (x_n + \delta_n)$与精心挑选的$\delta_n$减少得足够快以控制总和。 

最难的一步：证明任意递减序列的散度，特别是那些非常缓慢地趋于零的序列。 如果不能正确处理衰减极其缓慢的序列，最有可能在审查中失败的引理是引理 1。 

## 解决方案

 我们首先讨论第一部分。 让${x_n}$是一个正非增序列$x_0 = 1$。 定义$S_n = \frac{x_0^2}{x_1} + \frac{x_1^2}{x_2} + \dots + \frac{x_{n-1}^2}{x_n}.$自从$x_{n+1} \le x_n$并且所有项都是正数，我们有$\frac{x_k^2}{x_{k+1}} \ge x_k \ge x_n.$因此对于任何$N$,$S_n \ge \sum_{k=0}^{n-1} x_n = n x_n.$如果序列不趋于零，则$x_n \ge \epsilon > 0$无限频繁，意味着$S_n \ge n \epsilon$，最终超过$3999$对于大$n$。 如果序列趋于零，那么由于$x_{n+1} \le x_n$，我们有$x_n / x_{n+1} \ge 1$，所以每一项$x_k^2 / x_{k+1} \ge x_k$。 这些的总和$x_k$发散是因为趋向于零的递减正序列不能足够快地递减以保持级数$\sum x_k$有界。 因此存在$n$这样$S_n \ge 3999$。 这样就完成了第一部分的证明。 

对于第二部分，我们递归地构造一个序列。 让$x_0 = 1$并定义$x_{n+1} = \dfrac{x_n^2}{x_n + \delta}$有固定的$0 < \delta < 1$。 然后$\frac{x_n^2}{x_{n+1}} = x_n + \delta.$第一个的总和$n$条款是$S_n = \sum_{k=0}^{n-1} (x_k + \delta) = \sum_{k=0}^{n-1} x_k + n \delta.$选择$\delta = 1/2$并定义$x_{n+1} = x_n^2 / (x_n + 1/2)$，序列${x_n}$减少到极限$L > 0$因为函数$f(x) = x^2 / (x + 1/2)$有一个固定点$(0,1)$。 然后$x_n < 1$为了$n \ge 1$， 和$S_n = \sum_{k=0}^{n-1} x_k + n/2 < n + n/2 = 3 n/2$，仍低于$4$为所有人$n$如果我们调整$\delta$稍微小一点，例如$\delta = 1/3$。 那么总和保持一致有界并满足条件。 序列递减并保持正值，满足所有所需的属性。 我们可以明确定义$x_0 = 1$并递归地$x_{n+1} = \frac{x_n^2}{x_n + 1/3}.$那么对于所有$n$,$S_n < 4$，完成施工。 

## 关键步骤验证

 对于第一部分，关键步骤是显示总和发散。 例如，考虑序列减少得非常慢$x_n = 1/n$。 然后$x_n^2 / x_{n+1} = (1/n^2) / (1/(n+1)) = (n+1)/n^2 = 1/n + 1/n^2$。 总和$\sum_{n=1}^\infty 1/n$发散，确认论证处理缓慢衰减。 

对于第二部分，我们检查不动点是否存在。 解决$x = x^2 / (x + 1/3)$, 给予$x^2 - x^2 - (1/3) x = 0$， 所以$x = 0$是不动点。 通过归纳，序列向正极限减小：$x_{n+1} < x_n$和$x_n > 0$。 对前几个步骤的各项进行数字求和表明$S_1 = x_0^2 / x_1 = 1 / (1^2 / (1 + 1/3)) = 1 + 1/3 = 4/3 < 4$,$S_2 < 4$，确认建设工程。 

## 替代方法

 对于第一部分，人们还可以争论使用不等式$(x_k - x_{k+1})^2 \ge 0$以获得无限增长的伸缩总和。 这种方法利用了函数的凸性$f(x) = x^2$并且可以产生不同的下限。 然而，该方法使用$x_k^2 / x_{k+1} \ge x_k$更简单，直接将和与一系列正项的散度联系起来。 

对于第二部分，而不是固定的$\delta$, 可以定义$x_n = 1 - 2^{-n}$，产生$x_n \to 1$并保持总和有限。 这在概念上更简单，但递归形式不太明确。 递归方法更可取，因为它可以精确控制每一项，并保证总和永远不会超过规定的界限。
