 ## 问题

 在三角形的边上$ABC$, 正方形$ABMN$,$BCKL$,$ACPQ$是向外建造的。 分段上$NQ$和$PK$, 正方形$NQZT$和$PKXY$被建造。 求正方形面积之差$NQZT$和$PKXY$，考虑到正方形面积的差异$ABMN$和$BCKL$是已知的。 

A·格尔科

 莫斯科第 59 届数学奥林匹克竞赛，1996 年，城市锦标赛（1996 年春季）

 ## 探索

 考虑一个三角形$ABC$带有向外的方块$ABMN$,$BCKL$， 和$ACPQ$建造在其两侧。 分段上$NQ$和$PK$, 正方形$NQZT$和$PKXY$被建造。 该问题要求根据已知的第一代正方形面积差来求出第二代正方形的面积差$ABMN$和$BCKL$。 表示复平面中的点提供了一个方便的框架，因为旋转$90^\circ$对应于乘以$i$。 将顶点的复坐标表示为$A$,$B$， 和$C$。 在线段上构建向外的正方形如下：如果在线段上构建正方形$UV$，向量来自$U$到相邻的正方形顶点不$UV$是$i(V-U)$逆时针旋转。 表示为$M$,$N$,$K$,$L$,$P$,$Q$第一代正方形的顶点与三角形边相对，因此$M = B + i(B-A), \quad N = A + i(B-A), \quad K = C + i(C-B), \quad L = B + i(C-B), \quad P = C + i(C-A), \quad Q = A + i(C-A).$第二代广场建造于$NQ$和$PK$。 沿着这些线段的向量是$\overrightarrow{NQ} = Q - N = A + i(C-A) - (A + i(B-A)) = i(C-B),$

$\overrightarrow{PK} = K - P = C + i(C-B) - (C + i(C-A)) = i(A-B).$该任务简化为计算长度的平方$|NQ|^2$和$|PK|^2$以某种方式将它们与原始三角形边相关联，然后与相应正方形的面积相关联。 

## 问题理解

 建设产量$|NQ| = |C-B|$和$|PK| = |B-A|$一旦矢量差异被简化。 第二代正方形的面积等于这些长度的正方形，而第一代正方形的面积等于它们所构建的三角形边的正方形。 明确地说，$[ABMN] = |AB|^2$和$[BCKL] = |BC|^2$。 因此，计算第二代平方面积的差异需要仔细评估平方大小$\overrightarrow{NQ}$和$\overrightarrow{PK}$。 

直接向量计算避免了任何关于“众所周知的身份”的假设，并明确地考虑了方向和旋转。 表达$NQ$作为$i(C-B)$给出$|NQ|^2 = |C-B|^2 = |BC|^2$，并表达$PK$作为$i(A-B)$给出$|PK|^2 = |A-B|^2 = |AB|^2$。 因此第二代正方形的面积差为$[NQZT] - [PKXY] = |NQ|^2 - |PK|^2 = |BC|^2 - |AB|^2 = -(|AB|^2 - |BC|^2).$该负号反映了基于第二代方块的标记的减法顺序。 调整减法以匹配问题的约定给出$[PKXY] - [NQZT] = |AB|^2 - |BC|^2 = [ABMN] - [BCKL].$最终的表达式仅取决于第一代正方形的面积差，并且与第一代正方形的向外方向无关，因为所有向量一致地旋转$90^\circ$在复平面上。 

## 证明架构

 该问题简化为计算正方形顶点之间的向量差并评估平方大小。 让$\overrightarrow{AB} = B-A$,$\overrightarrow{BC} = C-B$， 和$\overrightarrow{AC} = C-A$。 向外的正方形产生垂直于边的向量：对于线段$UV$，垂直向量$U$是$i(V-U)$。 建设中$NQ$和$PK$由于第一代正方形顶点的差异产生$\overrightarrow{NQ} = Q - N = (A + i(C-A)) - (A + i(B-A)) = i(C-B),$

$\overrightarrow{PK} = K - P = (C + i(C-B)) - (C + i(C-A)) = i(A-B).$长度的平方是$|NQ|^2 = |i(C-B)|^2 = |C-B|^2 = |BC|^2, \quad |PK|^2 = |i(A-B)|^2 = |A-B|^2 = |AB|^2.$因此第二代正方形的面积差为$[NQZT] - [PKXY] = |NQ|^2 - |PK|^2 = |BC|^2 - |AB|^2.$为了满足用以下形式表达这种差异的问题要求$[ABMN] - [BCKL]$，有人写道$[PKXY] - [NQZT] = |AB|^2 - |BC|^2 = [ABMN] - [BCKL].$所有步骤均通过直接向量计算来证明，并且不依赖于未经证明的身份。 第一代正方形的向外方向影响矢量的方向，但不影响平方大小，因此最终的面积差与方向无关。 不需要对三角形的形状做出任何假设。 

## 解决方案

 构造三角形$ABC$和向外的正方形$ABMN$,$BCKL$， 和$ACPQ$。 在线段上定义第二代正方形$NQ$和$PK$。 分配复杂坐标$A$,$B$,$C$并构造第一代正方形顶点为$M = B + i(B-A)$,$N = A + i(B-A)$,$K = C + i(C-B)$,$L = B + i(C-B)$,$P = C + i(C-A)$,$Q = A + i(C-A)$。 沿着连接第一代正方形顶点的线段计算向量：$\overrightarrow{NQ} = Q - N = i(C-B), \quad \overrightarrow{PK} = K - P = i(A-B).$第二代正方形的面积是这些向量的长度平方：$[NQZT] = |NQ|^2 = |BC|^2, \quad [PKXY] = |PK|^2 = |AB|^2.$第二代正方形的面积之差用第一代正方形的面积表示为$[PKXY] - [NQZT] = |AB|^2 - |BC|^2 = [ABMN] - [BCKL].$这个等式对于任何三角形都成立$ABC$一致地构建向外的平方，并且通过向量减法和平方幅度的评估来明确地证明计算的合理性。 第一代正方形的方向符号不影响结果，并且不需要关于三角形的假设。
