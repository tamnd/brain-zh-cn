 ## 问题

 六段闭合折线的顶点位于圆上。 这样一条折线最多可以有多少个自交点？ 

N·B·瓦西里耶夫

 莫斯科 LIX 数学奥林匹克竞赛，1996 年，城镇锦标赛（1996 年春季）

 ## 探索

 六段闭合折线是一个六边形循环，其六个顶点位于一个圆上。 顶点不必按循环顺序取； 边是连接循环的连续顶点的弦。 

任何自交点都是两个不相邻线段的交点。 相邻线段共享一个顶点，并且不能在线段内部产生自相交。 

有六个边。 每条边都与另外两条边相邻，因此对于固定边有$6-3=3$与它不相邻的边。 因此，无序的不相邻边对的数量等于$$\frac{6\cdot 3}{2}=9.$$由于圆的两条弦最多在一个内点相交，因此自交总数不能超过$9$。 问题是是否所有$9$可以同时达到。 

要测试这一点，请按循环顺序标记圆上的六个点$$1,2,3,4,5,6.$$考虑闭合虚线$$1\to 4\to 2\to 5\to 3\to 6\to 1.$$它的边缘是$$14,\ 42,\ 25,\ 53,\ 36,\ 61.$$检查几对表明每对不相邻的边在圆上都有交替的端点，因此相交。 例如，$14$遇见$25$,$53$， 和$36$;$42$遇见$53$和$61$; 等等。 如果这对于所有九个不相邻对都成立，则上限$9$已实现。 

最有可能隐藏错误的步骤是验证所有九个不相邻对确实相交。 需要一个系统的标准而不是检查。 

## 问题理解

 我们在一个圆上有六个点，将它们循环连接起来，形成一条有六段的闭合折线。 顶点连接的顺序可能与其循环顺序不同。 我们必须确定所得闭合折线的最大可能自交点数量。 

这是一个C 类问题。 我们必须找到尽可能多的自交点，构造一条达到它的折线，并证明不可能有更多的自交点。 

核心困难在于表明通过计算不相邻边对而得出的明显上限实际上是可以实现的。 

答案应该是$9$，因为正好有九对不相邻的边，并且合适的高度交叉的循环排序似乎使每对这样的边相交。 

## 证明架构

 首先，证明自交只能由一对不相邻边产生，并且每对不相邻边最多贡献一个交点。 

其次，统计六条边的闭合折线中不相邻边对的数量并获得上界$9$。 

第三，构造圆上六个顶点的特定循环顺序，即$1\to4\to2\to5\to3\to6\to1$。 

第四，使用圆的弦相交的标准：当两条弦的端点围绕圆交替时，它们在内部恰好相交。 

第五，验证构造中的每对不相邻边都有交替的端点，因此相交。 

最难的部分是完整验证构造中所有九个不相邻对是否相交。 

## 解决方案

 让闭合虚线的六个边表示为$$e_1,e_2,\dots,e_6,$$指数取模$6$。 

自交点只能出现在不相邻的两条边上。 相邻边在折线的公共顶点处相交，并且不会在线段内部产生自相交。 

圆的任意两条弦最多有一个内部交点。 因此，每对不相邻的边最多贡献一个自交。 

对于固定边缘$e_i$，相邻的边是$e_{i-1}$和$e_{i+1}$。 除了这些还有$e_i$本身，还剩下$$6-3=3$$不相邻的边$e_i$。 

因此，无序的不相邻边对的数量等于$$\frac{6\cdot 3}{2}=9.$$因此任意六段闭合折线的自交点最多为$9$。 

仍有待证明的是$9$实际上是可以达到的。 

在圆上选择六个点并按循环顺序标记它们$$1,2,3,4,5,6.$$考虑闭合虚线$$1\to4\to2\to5\to3\to6\to1.$$它的边缘是$$14,\quad 42,\quad 25,\quad 53,\quad 36,\quad 61.$$我们使用标准事实：圆的两条弦在其内部相交当且仅当它们的端点在圆上交替。 

不相邻的边对是：$$(14,25),\ (14,53),\ (14,36),$$

$$(42,53),\ (42,36),\ (42,61),$$

$$(25,36),\ (25,61),$$

$$(53,61).$$对于每一对，四个端点围绕圆交替：$$1,2,4,5 \quad\text{for } (14,25),$$

$$1,3,4,5 \quad\text{for } (14,53),$$

$$1,3,4,6 \quad\text{for } (14,36),$$

$$2,3,4,5 \quad\text{for } (42,53),$$

$$2,3,4,6 \quad\text{for } (42,36),$$

$$1,2,4,6 \quad\text{for } (42,61),$$

$$2,3,5,6 \quad\text{for } (25,36),$$

$$1,2,5,6 \quad\text{for } (25,61),$$

$$1,3,5,6 \quad\text{for } (53,61).$$在每种情况下，第一个弦的一个端点位于第二个弦的端点之间，另一个端点位于该间隔之外，因此端点交替。 因此，每对不相邻的边都会相交。 

正好有九对不相邻的边，每对都贡献一个自交点。 因此这条断线有$9$自交点。 

因为没有一条断线可以有超过$9$，最大可能的自交点数量是$$\boxed{9}.$$平等适用于折线$$1\to4\to2\to5\to3\to6\to1.$$## 关键步骤验证

 上限依赖于正确计算不相邻对的数量。 六个边中的每一个都恰好有三个不相邻的伙伴。 计算有序对给出$6\cdot3=18$。 每个无序对都被计算两次，所以正确的数字是$18/2=9$。 不正确的减法，例如$6-2$会产生不可能的价值$12$。 

必须对照所有不相邻的对（而不仅仅是样本）来检查该结构。 这样的对正好有九对。 从每个边缘系统地列出它们可以避免遗漏一个。 每个列出的对都有四个不同的端点，并且上面显示的循环顺序交替，因此每对都相交。 

粗心的论证可能会假设只要两条边不相邻，它们就会相交。 一般来说，这是错误的。 排序的特殊属性$$1\to4\to2\to5\to3\to6\to1$$是每个不相邻的对在圆上都有交替的端点。 该证明明确验证了所有九对的这一条件。 

## 替代方法

 人们可以观察一种结构模式，而不是单独检查九对。 构造中使用的顶点的循环顺序是通过对每三个顶点取模来获得的$6$：$$1,4,2,5,3,6.$$每条边连接由圆上两个中间顶点分隔的顶点。 对于该循环中的任何两个不相邻的边，四个端点必然围绕圆交错。 弦相交准则意味着每个不相邻的对都相交。 尽管需要仔细证明交错属性，但这提供了更短的验证。 

另一种方法使用图论。 圆上的六个顶点确定了完整图中这些顶点上的哈密顿循环。 交叉的数量等于交叉的不相邻边对的数量。 由于这样的对只有九对，$9$是绝对上限。 具体的哈密顿循环$1-4-2-5-3-6-1$实现每个符合条件的对的交叉，给出最大值。
