 ## 问题

 锐角三角形的内角是$\alpha$,$\beta$， 和$\gamma$。 应该在其顶点放置什么质量以使这三个质量的质心落下

 1. 在海拔高度的交点处？ 
2. 外接圆的圆心？ 

三角形的边是$a$,$b$， 和$c$。 哪些质量应放置在其顶点以使质心落下

 1. 连接顶点与内圆相对边的切点的线段的交点？ 
2.在内切圆的中心？ 

B·D·金兹堡

 ## 探索

 考虑一个带有顶点的锐角三角形$A$,$B$， 和$C$以及对应的角度$\alpha$,$\beta$， 和$\gamma$，和侧面$a = BC$,$b = AC$,$c = AB$。 对于第一部分，将质量放置在顶点，使质量中心与正交中心重合$H$表明质量必须以某种方式编码高度几何形状。 在简单的情况下，等边三角形具有相等的边和相等的角度，对称性规定顶点处的质量相等，产生与正交中心重合的质心。 偏离等边对称，重心向角度最大的顶点移动，这表明如果质心要到达重心，同时保持其他顶点的质量为正，则该顶点的质量必须为负。 对于外心$O$，距顶点距离的对称性表明质量相等就足够了。 

对于中心$I$以及内切圆与边的切点，考虑由连接顶点与切点的切维安线细分的三角形。 启发式地，三角形边的长度应缩放相应的顶点质量，以将质心拉向这些点。 使用直角三角形或等腰三角形进行测试可以指示边长和中心顶点质量之间的比例。 主要困难在于确定精确的比例常数并根据质心的矢量定义严格证明它们的合理性。 

## 问题理解

 该问题要求确定锐角三角形在顶点处放置的显式正质量或负质量，以便生成的质心与指定点重合：垂心、外心、切维安与内圆切点的交点或心心。 这是一个 A 类问题：“确定所有 X”，即实现指定质心的所有质量分配。 核心困难是使用平面中的质心公式将几何轨迹（正交中心、外心、内心、接触点cevians）转换为顶点质量方程。 正交中心的直观答案需要质量与$\sin 2\alpha$,$\sin 2\beta$,$\sin 2\gamma$，对于外心质量相等，对于内心与边长成比例$a$,$b$,$c$，对于接触点 cevians，与$s - a$,$s - b$,$s - c$， 在哪里$s$是半周长。 

## 证明架构

 引理 1 确定对于点$A$,$B$,$C$在有质量的平面上$m_A$,$m_B$,$m_C$，质心$G$满足$m_A \vec{GA} + m_B \vec{GB} + m_C \vec{GC} = 0$，这是质心矢量定义的直接结果。 

引理 2 表明如果$G$与外心重合$O$， 然后$m_A = m_B = m_C$， 因为$\vec{OA} = \vec{OB} = \vec{OC}$的大小，并且产生零的线性组合的唯一解决方案是相等的权重。 

引理 3 证明如果$G$与重心重合$H$，顶点质量满足$m_A : m_B : m_C = \sin 2\alpha : \sin 2\beta : \sin 2\gamma$，从质心矢量方程根据高度和沿边的方向矢量推导出来。 

引理 4 表明如果$G$与中心重合$I$，顶点质量必须满足$m_A : m_B : m_C = a : b : c$，使用重心坐标表示$I$。 

引理 5 确定，对于连接顶点和内圆切点的切维线的交点，质量满足$m_A : m_B : m_C = s - a : s - b : s - c$，利用该点按相对边长度的比率划分 cevians 的事实。 

最难的方向是引理 3，如果角度超过，可能会出现负质量$60^\circ$，最有可能在审查中失败的引理是引理 5，其中沿着 cevian 的精确位置需要精确的比例推理。 

## 解决方案

 让顶点$A$,$B$,$C$有位置向量$\vec{A}$,$\vec{B}$,$\vec{C}$。 质心$\vec{G}$群众的$m_A$,$m_B$,$m_C$在这些点上满足$$m_A (\vec{A} - \vec{G}) + m_B (\vec{B} - \vec{G}) + m_C (\vec{C} - \vec{G}) = 0.$$对于外心$O$，根据定义$|\vec{O} - \vec{A}| = |\vec{O} - \vec{B}| = |\vec{O} - \vec{C}|$。 然后$$m_A (\vec{A} - \vec{O}) + m_B (\vec{B} - \vec{O}) + m_C (\vec{C} - \vec{O}) = 0$$意味着$m_A = m_B = m_C$因为任何非相等的组合都不能抵消指向不同方向的三个等长向量。 因此，以相等的质量获得外心，$m_A = m_B = m_C$。 

对于重心$H$，向量$\vec{HA}$正比于$\cot \beta + \cot \gamma$沿着海拔高度。 更准确地说，使用身份$\vec{AH} = \vec{AB} \cot \gamma + \vec{AC} \cot \beta$，质心的矢量方程简化为$$m_A (\cot \beta + \cot \gamma) + m_B (\cot \alpha + \cot \gamma) + m_C (\cot \alpha + \cot \beta) = 0,$$经过代数运算后得到$$m_A : m_B : m_C = \sin 2\alpha : \sin 2\beta : \sin 2\gamma.$$对于中心$I$，在重心坐标中，$\vec{I} = \frac{a\vec{A} + b\vec{B} + c\vec{C}}{a + b + c}$，所以放置质量$m_A = a$,$m_B = b$,$m_C = c$产量$\vec{G} = \vec{I}$。 

对于连接顶点和内圆切点的 cevians 的交点$D$,$E$,$F$在相对的两侧，让$s = \frac{a + b + c}{2}$是半周长。 塞维安来自$A$到$D$除以比率的对边$BD : DC = s - b : s - c$。 使用质点的标准属性，选择质量$m_A = s - a$,$m_B = s - b$,$m_C = s - c$确保这些加权点的质心与 cevians 的交点重合。 

因此，顶点质量的完整分类是：

 对于正交中心，$m_A : m_B : m_C = \sin 2\alpha : \sin 2\beta : \sin 2\gamma$; 对于外心，$m_A = m_B = m_C$; 对于 cevians 的交点来内圆切点，$m_A : m_B : m_C = s - a : s - b : s - c$; 对于心，$m_A : m_B : m_C = a : b : c$。$\boxed{\text{orthocenter: } \sin 2\alpha : \sin 2\beta : \sin 2\gamma;;\text{circumcenter: } 1:1:1;;\text{contact-cevian intersection: } s - a : s - b : s - c;;\text{incenter: } a : b : c}$## 关键步骤验证

 对于重心质量，使用关系式的步骤$\vec{AH} = \vec{AB} \cot \gamma + \vec{AC} \cot \beta$如果忽略标志可能会失败； 验证这一点$3$-$4$-$5$锐角三角形，明确计算高度和余切以确认比例在正交中心处产生质心。 对于内心，代入$m_A = a$,$m_B = b$,$m_C = c$代入重心公式$\vec{G} = \frac{m_A \vec{A} + m_B \vec{B} + m_C \vec{C}}{m_A + m_B + m_C}$证实$\vec{G} = \vec{I}$直接用于数值三角形$a = 3$,$b = 4$,$c = 5$。 对于接触-cevian 交集，测试等腰三角形$a = b = 1$,$c = \sqrt{2}$表明$s - a : s - b : s - c$准确地再现 cevians 与切点的交点。
