 ## 问题

 数字$a$,$b$,$c$位于区间内$\left(0;\dfrac\pi2\right)$并满足等式：$$\begin{align*} \cos a&=a,\\ \sin\cos b&=b,\\ \cos\sin c&=c. \end{align*}$$。 按升序排列这些数字。 

南黑森州

 全联盟学校数学奥林匹克竞赛（1982 年，十年级）

 ## 探索

 问题给出了三个数字$a$,$b$,$c$在区间内$(0, \frac{\pi}{2})$令人满意$$\cos a = a, \quad \sin(\cos b) = b, \quad \cos(\sin c) = c,$$并询问它们的升序。 每个方程定义一个唯一的数字，因为所涉及的函数是严格单调的$(0, \frac{\pi}{2})$。 对于小$x$,$\cos x \approx 1 - x^2/2$,$\sin x \approx x$， 和$\sin(\cos x)$和$\cos(\sin x)$也在附近$1$对于小$x$。 这表明$a$小于$b$和$c$因为$\cos a = a$力量$a < 1$， 尽管$\sin(\cos b) = b$和$\cos(\sin c) = c$涉及接近单调函数的组合$1$。 

数值估计可以提供帮助。 功能$f(x) = \cos x - x$减少自$\cos 0 - 0 = 1$到$\cos(\pi/2) - \pi/2 = -\pi/2$， 所以$a \in (0,1)$。 相似地，$\sin(\cos x) - x$开始于$\sin 1 \approx 0.8415$在$x=0$并减少，表明$b$接近于$0.7$， 和$\cos(\sin x) - x$开始于$1$并减少，表明$c$接近于$0.8$。 这暗示了排序$a < b < c$。 

微妙之处在于确认每个函数的单调性，保证唯一性并严格比较$a$,$b$,$c$而不仅仅依赖于近似值。 

## 问题理解

 该问题要求比较由非线性方程确定的三个数字，并将它们按升序排列。 这是一个 A 类问题：“查找所有 X”，其中$X$是相对顺序$a$,$b$,$c$。 核心困难在于比较由严格单调函数隐式定义的数字。 初步直觉，得到粗略数值估计的支持，表明$a < b < c$， 因为$\cos x$比其他组合函数下降得更快，并且$x$表现为越来越大的函数的固定点。 

## 证明架构

 引理 1：方程$\cos x = x$有一个独特的解决方案$(0, \frac{\pi}{2})$，表示为$a$。 草图：$f(x) = \cos x - x$严格递减$(0, \pi/2)$，将符号从正变为负。 

引理 2：方程$\sin(\cos x) = x$有一个独特的解决方案$(0, \frac{\pi}{2})$，表示为$b$。 草图：$f(x) = \sin(\cos x) - x$严格从$f(0) = \sin 1 > 0$到$f(\pi/2) = \sin 0 - \pi/2 < 0$。 

引理 3：方程$\cos(\sin x) = x$有一个独特的解决方案$(0, \frac{\pi}{2})$，表示为$c$。 草图：$f(x) = \cos(\sin x) - x$严格从$f(0) = \cos 0 = 1$到$f(\pi/2) = \cos 1 - \pi/2 < 0$。 

引理 4：比较$a$和$b$： 展示$a < b$使用$\cos x - x$和$\sin(\cos x) - x$。 草图：比较函数值$a$和$b$。 

引理 5：比较$b$和$c$： 展示$b < c$使用$\sin(\cos x)$相对$\cos(\sin x)$。 草图：估计或分析导数以确保单调交叉。 

最难的就是确定方向$b < c$严格地没有数值近似。 

## 解决方案

 考虑功能$f(x) = \cos x - x$在$(0, \frac{\pi}{2})$。 其衍生品$f'(x) = -\sin x - 1 < 0$， 所以$f$是严格递减的。 在$x=0$,$f(0) = 1 > 0$，并且在$x = \pi/2$,$f(\pi/2) = 0 - \pi/2 < 0$。 由中间值定理，存在唯一的$a \in (0, \pi/2)$这样$\cos a = a$。 

接下来，定义$g(x) = \sin(\cos x) - x$在$(0, \pi/2)$。 其衍生品$g'(x) = -\cos(\cos x)\sin x - 1 < 0$， 所以$g$是严格递减的。 在$x=0$,$g(0) = \sin 1 > 0$，并且在$x = \pi/2$,$g(\pi/2) = \sin 0 - \pi/2 = -\pi/2 < 0$。 由中间值定理，存在唯一的$b \in (0, \pi/2)$这样$\sin(\cos b) = b$。 

同样，定义$h(x) = \cos(\sin x) - x$在$(0, \pi/2)$。 其衍生品$h'(x) = -\sin(\sin x)\cos x - 1 < 0$， 所以$h$是严格递减的。 在$x=0$,$h(0) = 1 > 0$，并且在$x = \pi/2$,$h(\pi/2) = \cos 1 - \pi/2 < 0$。 因此存在一种独特的$c \in (0, \pi/2)$这样$\cos(\sin c) = c$。 

比较$a$和$b$， 考虑$f(x) - g(x) = \cos x - \sin(\cos x)$。 让$\phi(x) = \cos x - \sin(\cos x)$。 其衍生品$\phi'(x) = -\sin x + \cos(\cos x)\sin x = \sin x(\cos(\cos x) - 1) \le 0$， 所以$\phi$正在减少。 评价$\phi(0) = 1 - \sin 1 > 0$和$\phi(\pi/2) = 0 - \sin 0 = 0$。 自从$\phi$从正值减小到零，因此$\phi(a) > 0$， 所以$\cos a - \sin(\cos a) > 0$。 但$\cos a = a$， 所以$a - \sin(\cos a) = a - b > 0$，意味着$a < b$。 

比较$b$和$c$， 考虑$\psi(x) = \cos(\sin x) - \sin(\cos x)$。 其衍生品$\psi'(x) = -\sin(\sin x)\cos x - \cos(\cos x)\sin x < 0$， 所以$\psi$是严格递减的。 在$x=0$,$\psi(0) = 1 - \sin 1 > 0$，并且在$x = \pi/2$,$\psi(\pi/2) = \cos 1 - 0 > 0$。 然而，$b$和$c$是解决方案$x = \sin(\cos x)$和$x = \cos(\sin x)$。 评价$\psi$在$b$:$\psi(b) = \cos(\sin b) - b$。 自从$b < 1$,$\sin b < b$， 所以$\cos(\sin b) > \cos b > \sin(\cos b) = b$，意味着$\psi(b) > 0$， 因此$b < c$。 

因此，数字满足$a < b < c$。 

数字的升序是$$\boxed{a < b < c}.$$## 关键步骤验证

 关键的一步是比较$b$和$c$。 要验证，请注意$b$满足$b = \sin(\cos b) < \cos(\sin b)$因为$\sin(\cos b) < \cos(\sin b)$为了$b \in (0, \pi/2)$。 这是从不等式得出的$\cos y > \sin y$为了$y \in (0, \pi/4)$和$b \in (0,1)$，通过直接评估确认：$\cos(\sin b) - b = \cos(\sin b) - \sin(\cos b) > 0$， 所以$b < c$。 

另一个微妙的步骤是验证解决方案的唯一性。 各功能$f$,$g$,$h$严格递减$(0, \pi/2)$并将符号从正变为负，保证区间中正好有一个零。 这排除了多重交集或等式失败的情况。
