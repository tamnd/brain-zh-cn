 ## 问题

 是否存在多项式$P(x)$具有负系数，而其任何幂的所有系数$P^n(x)$,$n\gt1$是积极的吗？ 

O·克雷扎诺夫斯基

 莫斯科数学奥林匹克竞赛（LVII，1994 年）

 ## 探索

 考虑具有负系数的多项式，例如$P(x) = -x + 2$或者$P(x) = x^2 - x + 1$。 快速计算低幂表明负系数传播：$P(x) = -x + 2$，正方形是$P^2(x) = (-x + 2)^2 = x^2 - 4x + 4$，仍具有负系数。 尝试通过添加更大的正项来进行补偿，例如$P(x) = x^2 + 3x - 1$，正方形是$P^2(x) = x^4 + 6x^3 + 7x^2 - 6x + 1$，保留负系数。 测试$P(x) = -1 + x + x^2$给出$P^2(x) = 1 - 2x + 3x^2 + 2x^3 + x^4$，再次存在负面术语。 

小程度的例子表明，单个负系数$P(x)$导致至少一个负系数$P^2(x)$。 直觉是，乘法将负贡献分布在各项中，并且初始负性不能被其他项的正系数完全吸收。 这表明该问题可能是不可能的，并且一般论证必须表明，对于任何至少具有一个负系数的多项式，某些幂将始终保留负系数。 

关键的困难是在任意次数和任意系数组合下证明这一点，特别是当负系数与正系数相比量级较小时。 任何粗心的求和都可能忽略会产生完全正幂的抵消，因此每一步都必须仔细追踪哪些项对幂中的每个系数有贡献。 

## 问题理解

 问题问是否存在多项式$P(x)$至少有一个负系数，使得对于所有整数$n > 1$，每个系数$P^n(x)$是积极的。 这是一个 D 类问题：“构造/显示存在”，或者如果不存在则证明不可能性。 核心困难在于，负贡献在权力扩张中会倍增并结合起来，可能会留下负系数。 探索强烈表明不存在这样的多项式，因为负系数$P(x)$不可避免地会在更高的幂中产生负系数。 直观上，乘法会分散负面影响，并且在没有微调系数的情况下无法通过其他正项完全抵消，这对所有人来说都是不可能的$n>1$。 

## 证明架构

 引理 1：如果$P(x)$具有负系数，则其具有负系数的最低次数项在任何正幂之后其次数贡献严格为正。 草图：跟踪负项在每个项式的最低次单项式中的贡献$P^n(x)$。 

引理 2：任何具有负系数的多项式都会产生某个幂的负系数$P^n(x)$,$n > 1$。 草图：考虑负系数出现的最小和最大度数； 它们与展开式中的其他项的卷积最终总是产生负系数。 

主要主张：没有多项式$P(x)$存在负系数，使得$P^n(x)$具有所有正系数$n > 1$。 草图：应用引理 2； 中的任何否定词$P$不可能在所有力量中消失。 

最难的一步：引理 2，显示负系数不可避免地会保留一些幂。 

## 解决方案

 假设矛盾存在一个多项式$P(x)$至少有一个负系数，并且对于所有$n>1$,$P^n(x)$只有正系数。 写$P(x) = a_0 + a_1 x + \dots + a_m x^m$带整数$m \ge 0$，并让$k$是最小的索引，使得$a_k < 0$。 然后$a_0, \dots, a_{k-1} \ge 0$， 和$a_k < 0$。 

考虑$P^2(x) = P(x) \cdot P(x)$。 系数为$x^k$在$P^2(x)$是$$\sum_{i=0}^k a_i a_{k-i}.$$所有条款均以$i < k$有$a_i \ge 0$和$a_{k-i} \ge 0$除非$k-i = k$，仅发生在$i=0$给予$a_0 a_k \le 0$。 期限$i = k$贡献$a_k a_0 < 0$，以及术语$0 < i < k$是非负的。 因此总和是$a_0 a_k + (\text{nonnegative terms}) \le a_0 a_k < 0$。 因此，系数$x^k$在$P^2(x)$是负数，与所有系数的假设相矛盾$P^2(x)$是积极的。 

这个论点同样适用于任何$n > 1$： 中具有负系数的最低次项$P(x)$传播到$P^n(x)$，产生负系数。 因此，任何具有负系数的多项式都不可能具有所有幂的所有正系数$n > 1$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的步骤是确定系数$x^k$在$P^2(x)$。 显式计算：让$P(x) = a_0 + \dots + a_m x^m$和$k$最小使得$a_k < 0$。 然后$x^k$在$P^2(x)$来自$a_i a_{k-i}$,$i = 0, \dots, k$。 自从$a_0, \dots, a_{k-1} \ge 0$， 仅有的$a_0 a_k$和$a_k a_0$是负面的。 所有其他贡献都是非负的。 将这些相加得到负和。 测试小例子，例如$P(x) = 2 - x + x^2$，给出$P^2(x) = 4 - 4x + 5x^2 - 2x^3 + x^4$，其中$x$系数为负，证实了推理。 

## 替代方法

 另一种方法是考虑生成函数方法，将系数视为与幂展开的乘积相对应的多组索引的总和。 负系数为$P(x)$在包含它的每个多重集中产生一个负项，确保一些负系数保留下来。 为了清晰和最小的技术开销，直接的最小度论证更可取，避免组合爆炸并使证明完全基本。
