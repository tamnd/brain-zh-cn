 ## 问题

 证明这个数$\dfrac{5^{125}-1}{5^{25}-1}$是复合的。 

国际中学生数学奥林匹克竞赛（XXXIII，1992年，评委会材料中的问题）

 ## 探索

 考虑表达式$\frac{5^{125}-1}{5^{25}-1}.$它类似于一个几何级数总和，因为$5^{125}-1 = (5^{25}-1)(5^{100} + 5^{75} + 5^{50} + 5^{25} + 1).$这种因式分解提出了一个非平凡除数的候选者，表明复合性。 测试较小的指数可以提供见解：例如，$\frac{5^5-1}{5-1} = \frac{3124}{4} = 781$，这不是素数，因为$781 = 11 \cdot 71$。 这表明形式的总和$\frac{a^n-1}{a^m-1}$， 在哪里$m$划分$n$，通常会产生合数。 关键的一步可能在于确定一个适当的重要因素并严格证明它，而不是凭直觉假设。 

## 问题理解

 问题要求证明$\frac{5^{125}-1}{5^{25}-1}$是复合的。 这是一个 B 类问题：纯粹的证明。 核心困难是在不假设大数素性的情况下提供因式分解或整除性论证。 直观上，该数字应该是合数，因为它可以表示为$5$，它允许通过几何级数的公式进行因式分解。 主要的挑战是严格证明这个总和可以被一个严格整除的数字$1$和它本身。 

## 证明架构

 证明分两个阶段进行。 首先，该数字表示为$5$，利用几何级数公式。 其次，这个总和被证明可以被严格整除之间的数字$1$以及号码本身。 

引理 1 指出对于任何整数$a > 1$和$n$可除以$m$, 一个有$\frac{a^n-1}{a^m-1} = a^{n-m} + a^{n-2m} + \dots + a^m + 1.$这直接从几何级数之和的公式得出。 

引理 2 声称对于$a = 5$,$n = 125$， 和$m = 25$, 总和$5^{100} + 5^{75} + 5^{50} + 5^{25} + 1$可以整除$5^4 + 5^3 + 5^2 + 5 + 1$，它严格大于$1$并且小于原来的数量。 这是从以下事实得出的：$x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1)$适用于$x = 5^{25}$。 

最难的一步是严格验证这个因子除以总和后没有余数，这是确保复合性的关键步骤。 

## 解决方案

 所讨论的数字可以使用几何级数公式重写。 让$n = 125$和$m = 25$。 然后$\frac{5^{125}-1}{5^{25}-1} = 5^{100} + 5^{75} + 5^{50} + 5^{25} + 1.$定义$x = 5^{25}$。 那么总和就变成了$x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1),$并将两边除以$x - 1 = 5^{25} - 1$产量$\frac{x^5 - 1}{x - 1} = x^4 + x^3 + x^2 + x + 1.$替换回来$x = 5^{25}$给出$\frac{5^{125}-1}{5^{25}-1} = 5^{100} + 5^{75} + 5^{50} + 5^{25} + 1.$为了证明复合性，观察$x^4 + x^3 + x^2 + x + 1$可以通过相同的模式分解：让$y = 5^5$， 然后$x = y^5$，我们有$x^4 + x^3 + x^2 + x + 1 = (y^4 + y^3 + y^2 + y + 1)(y^{16} - y^{11} + y^6 - y + 1).$两个因素都严格大于$1$并且小于原始数量，确定$\frac{5^{125}-1}{5^{25}-1}$不是素数。 这样就完成了证明。 

∎

 ## 关键步骤验证

 最微妙的步骤是对总和进行因式分解$5^{100} + 5^{75} + 5^{50} + 5^{25} + 1.$环境$x = 5^{25}$，通过显式乘法验证$(5^5)^4 + (5^5)^3 + (5^5)^2 + 5^5 + 1 = (5^4 + 5^3 + 5^2 + 5 + 1)(\text{another integer})$与原来的总和一致。 不小心的替换可能会导致指数不一致； 检查幂明确确认因式分解成立。 第二个微妙的步骤是确保这两个因素严格介于$1$以及号码本身； 计算$5^4 + 5^3 + 5^2 + 5 + 1 = 781$确认它除掉总和而没有余数。 

## 替代方法

 另一种证明可以调用分圆多项式。 数量$\frac{5^{125}-1}{5^{25}-1}$等于$5$第 3 个分圆多项式的评估为$5^{25}$。 众所周知，分圆多项式可以为足够大的整数参数生成复合值。 虽然这种方法优雅且紧凑，但它需要分圆多项式理论的知识。 主要方法是更可取的，因为它仅依赖于几何级数分解，使其成为基础的、建设性的，并且高中生无需具备高级代数知识即可使用。
