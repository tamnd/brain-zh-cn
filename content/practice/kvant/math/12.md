 ## 问题

 哪些四边形可以用直线截成两个相似的四边形？ 

## 探索

 一条直线与凸四边形相交于两点。 为了使所得的两个块都是四边形，该线必须连接两个相对的边； 否则其中一块是三角形，另一块是五边形。 因此，在重新贴标签之前，这条线满足$AB$在$P$和$CD$在$Q$，生成四边形$A P Q D$和$P B C Q$。 

这两个四边形之间的相似性迫使它们的边之间存在对应关系。 该段$PQ$是两个图形的一边，所以在任何相似之处，$PQ$必须对应于另一个四边形中同等作用的边。 由于它是两个图形共享的唯一边，因此相似性必须将其保留为边对边匹配，从而迫使相似比为$1$，所以这两个四边形全等。 

这将问题简化为将可以被一条线切割成两个全等四边形的四边形分类。 一个自然的候选者是平行四边形，因为它关于其对角线的交点具有半圈对称性，这表明穿过该中心的任何线都应将其分成两个全等的图形。 

关键的不确定性是任何非平行四边形是否可以接受这样的对称切割。 

## 问题理解

 这是一个 A 类问题。 我们必须确定所有允许直线切割产生两个相似四边形的四边形。 

结构约束是切割产生两个共享一条边的四边形，这强烈限制了相似性对应并强制刚性。 

预期的答案是四边形必须是平行四边形，因为中心对称性确保任何此类切割都会产生全等的相对部分。 

因此，主张只有这样的四边形是平行四边形。 

## 证明架构

 首先，引理规定产生两个四边形的直线必须连接原始四边形的相对边。 

其次，引理表明，两个所得四边形的相似性迫使它们的相似比为$1$，因此它们是一致的，因为共享的一侧$PQ$在任何相似性下都必须对应于自身。 

第三，引理表明两个部分的全等意味着原始四边形关于中点的半圈对称。$PQ$，将一个片段映射到另一个片段。 

第四，引理表明，具有这种半圈对称性的凸四边形必定是平行四边形。 

最微妙的一步是证明相似性必然修复共同的一面$PQ$以强制比例因子的方式$1$。 

## 解决方案

 让$ABCD$是一个凸四边形，并让一条线相交$AB$在$P$和$CD$在$Q$，生成四边形$A P Q D$和$P B C Q$。 

第一个观察是，将凸四边形切割成两个四边形的线必须与两个相对的边相交。 事实上，如果两个交点都位于相邻边上，则所得区域之一具有来自原始四边形的三个边界边和一个来自切割线的边界边，从而生成一个三角形，而另一个区域具有五个边，这与两者都是四边形的假设相矛盾。 

假设$A P Q D$和$P B C Q$是相似的四边形。 考虑任何相似变换映射$A P Q D$到$P B C Q$。 该段$PQ$是两个四边形的一条边，所以它在相似度下的图像一定是$P B C Q$在循环顺序中具有相同的作用。 自从$PQ$是唯一的一面$A P Q D$其端点均位于切割线上，则其图像必须与边重合$PQ$第二个四边形。 

因此相似度图片段$PQ$自身，将其端点保留为一个集合。 将片段映射到自身的相似性必须具有比例因子$1$，因为线段上的点之间的距离保留为一个常数因子，并且端点作为一组固定。 因此这两个四边形全等。 

让$M$是线段的中点$PQ$。 之间的一致性$A P Q D$和$P B C Q$意味着存在将一个四边形发送到另一个四边形的刚性运动。 由于两个数字共享该段$PQ$并且该段被映射到其自身上，端点交换或固定，唯一的这种刚性运动要么是恒等要么是半转$M$。 恒等是不可能的，因为两个四边形占据不相交的内部，所以运动必须是半圈$M$。 

这半圈发送$A$到$B$和$D$到$C$（或反之亦然，具体取决于标签）。 最后，$M$是两条对角线的中点$AC$和$BD$，因为半圈将每个点映射到其对称图像$M$。 

对角线互相平分的四边形是平行四边形。 确实，从$M$是 的中点$AC$和$BD$, 三角形$AMB$和$CMD$是中心对称的，意味着$AB \parallel CD$和$BC \parallel AD$。 

因此$ABCD$是一个平行四边形。 

相反，让$ABCD$是一个平行四边形，并让穿过对称中心（对角线交点）的直线相交$AB$和$CD$。 绕该中心旋转半圈将平行四边形映射到自身，并交换由该线确定的两个区域，因此所得的两个四边形是全等的，因此相似。 

因此，所要求的四边形恰好是平行四边形。$$\boxed{\text{All parallelograms}}$$∎

 ## 关键步骤验证

 第一个微妙点是相似性迫使细分市场断言$PQ$来对应自己。 在两个四边形中的每一个中，$PQ$是完全位于切割线上的独特侧面。 两个图形之间的任何相似性都必须保留边和顶点之间的重合关系，因此切割线中包含的边必须映射到具有相同几何属性的边，该边也位于切割线上。 由于每个四边形都只有一个这样的边，因此这种对应关系是强制的。 

第二点是推导相似度为$1$。 一次$PQ$映射到自身作为一个段，必须保留其长度，强制缩放因子等于$1$。 

第三点是刚性运动的表征。 共享作为集合不变的线段的两个平面图形之间的全等必须逐点固定该线段或交换其端点。 在这两种情况下，变换都是垂直平分线的反射$PQ$或绕其中点旋转半圈。 只有半圈才能兼容交换四边形两个不相交的内部。 

最后一点是，关于两条对角线中点半圈对称的四边形必须其对角线互相平分，这相当于是一个平行四边形。 

## 替代方法

 一种替代方法是纯粹基于角度的。 跟踪共享边周围角度的对应关系$PQ$在相似性下，原始四边形的相邻角度之间产生线性关系，最终迫使相对的边平行。 

另一种方法从仿射几何开始：共享整边的两个区域之间的任何相似性都会延伸到支撑四边形的仿射对称性，并且唯一允许交换相对边的非平凡仿射对合的凸四边形是平行四边形。
