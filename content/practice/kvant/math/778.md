 ## 问题

 给定一个等腰三角形$A_1A_2A_3$。 让$a_i$是其与顶点相对的边$A_i$（$i=1$, 2, 3),$M_i$;$a_i$是边的中点$a_i$,$T_i$该边与三角形内切圆的切点，以及$S_i$对称于的点$T_i$相对于角平分线$A_i$三角形的。 证明线$M_1S_1$,$M_2S_2$， 和$M_3S_3$同意。 

国际中学生数学奥林匹克竞赛（第二十三届，1982 年）

 ## 探索

 设三角形为等腰三角形$A_2A_3=a_1$作为基础和$A_1A_2=A_1A_3$。 由于该命题在两条相等的边上对称，因此自然期望重合点位于三角形的对称轴上。 

要了解要点$S_i$，将边长写为$$a_2=a_3=b,\qquad a_1=c.$$让$$s=\frac{2b+c}{2}=b+\frac c2$$是半周长。 

对于接触点$T_1$在基地上$A_2A_3$，标准相切关系给出$$A_2T_1=A_3T_1=s-b=\frac c2,$$因此$T_1$是底面的中点。 由于平分线为$A_1$也是三角形的对称轴，反射叶子$T_1$固定的。 因此$$S_1=T_1=M_1,$$和线$M_1S_1$退化到对称轴。 

那么问题就变成了：证明$M_2S_2$和$M_3S_3$在该轴上相遇。 

坐标计算似乎很有前途。 放$$A_2=(-d,0),\qquad A_3=(d,0),\qquad A_1=(0,h),$$以便$$b=\sqrt{d^2+h^2},\qquad c=2d.$$联络点$T_2$位于$A_1A_3$。 自从$$A_1T_2=s-c=b-d,\qquad A_3T_2=s-b=d,$$分频比为$A_1A_3$是$$A_1T_2:A_3T_2=(b-d):d.$$这产生$$T_2=\left(\frac{d(b-d)}b,\frac{hd}b\right).$$的平分线$A_2$方向等于沿方向的单位向量之和$A_2A_3$和$A_2A_1$，即$$\left(1+\frac db,\frac hb\right).$$反思$T_2$在这个平分线上给出了一个明确的点。 结果坐标出人意料地简化为$$S_2=\left(\frac{d(2d-b)}b,\frac{hd}b\right).$$这$y$-坐标不变，这表明隐藏的几何原因。 

现在$$M_2=\left(\frac d2,\frac h2\right).$$线路经过$M_2$和$S_2$与对称轴相交$x=0$在某个点上$y$- 坐标结果是$$\frac h2\cdot\frac{b}{\,2b-3d\,}.$$根据对称性，$M_3S_3$在同一点与同一轴相交。 因此这三行是一致的。 

潜在危险的步骤是反射计算。 必须认真执行并严格简化。 

## 问题理解

 给定一个等腰三角形$A_1A_2A_3$。 对于每一方来说，$M_i$是它的中点，$T_i$是内切圆与该边相切的点，并且$S_i$是的反映$T_i$穿过角平分线$A_i$。 

任务是证明这三行$$M_1S_1,\qquad M_2S_2,\qquad M_3S_3$$是并发的。 

这是一个B 类问题。 该声明是一个几何并发声明。 

核心困难是获得反射点的可用描述$S_2$和$S_3$。 一旦知道它们的位置，对称性就强烈表明公共点位于等腰三角形的轴上。 

## 证明架构

 引理 1. 在等腰三角形中，接触点$T_1$底座上与中点重合$M_1$基地的； 因此$S_1=M_1$。 

草图。 切线长度从$A_2$和$A_3$是相等的，所以$T_1$是底面的中点。 对称轴上的反射修复了这一点。 

引理 2. 在坐标中$$A_2=(-d,0),\quad A_3=(d,0),\quad A_1=(0,h),$$重点$T_2$有坐标$$\left(\frac{d(b-d)}b,\frac{hd}b\right), \qquad b=\sqrt{d^2+h^2}.$$草图。 使用侧面的标准切线长度$A_1A_3$。 

引理 3. 的反思$T_2$在平分线$\angle A_2$给出$$S_2=\left(\frac{d(2d-b)}b,\frac{hd}b\right).$$草图。 使用平分线的单位方向向量计算反射。 

引理 4. 直线$M_2S_2$与对称轴相交$x=0$在这一点上$$P=\left(0,\frac h2\cdot\frac b{2b-3d}\right).$$草图。 写出直线方程$M_2$和$S_2$。 

引理 5. 根据对称性，直线$M_3S_3$经过同一个点$P$。 

草图。 对称轴的反射交换索引$2$和$3$。 

最微妙的引理是引理 3，因为反射计算中的错误将使并发计算无效。 

## 解决方案

 选择坐标$$A_2=(-d,0),\qquad A_3=(d,0),\qquad A_1=(0,h),$$和$d>0$和$h>0$。 那么这个三角形是等腰三角形，并且$$b=A_1A_2=A_1A_3=\sqrt{d^2+h^2}.$$对称轴是线$x=0$。 

让$T_1$是内切圆与底面的接触点$A_2A_3$。 自从$$A_1A_2=A_1A_3,$$切线长度从$A_2$和$A_3$是平等的。 因此$$A_2T_1=A_3T_1,$$所以$T_1$是的中点$A_2A_3$。 所以$$T_1=M_1=(0,0).$$的平分线$\angle A_1$是对称轴$x=0$，这修复了$T_1$。 最后$$S_1=T_1=M_1.$$因此$M_1S_1$是对称轴。 

接下来我们确定$S_2$。 

侧面$A_1A_3$有长度$b$，而底座有长度$2d$。 让$$s=\frac{2b+2d}{2}=b+d.$$对于切点$T_2$在$A_1A_3$,$$A_1T_2=s-2d=b-d, \qquad A_3T_2=s-b=d.$$因此$T_2$划分$A_1A_3$在比例中$$A_1T_2:A_3T_2=(b-d):d.$$使用截面公式，$$T_2 = \frac{dA_1+(b-d)A_3}{b} = \left(\frac{d(b-d)}b,\frac{hd}b\right).$$让$u$是平分线的单位方向向量$\angle A_2$。 沿着边的两个单位向量从$A_2$是$$(1,0), \qquad \left(\frac db,\frac hb\right),$$所以$$u= \frac{\left(1+\frac db,\frac hb\right)} {\sqrt{\left(1+\frac db\right)^2+\left(\frac hb\right)^2}} = \left(\sqrt{\frac{b+d}{2b}},\sqrt{\frac{b-d}{2b}}\right).$$写$$w=T_2-A_2 = \left(\frac{d(2b-d)}b,\frac{hd}b\right).$$通过线的反射$A_2$具有单位方向向量$u$发送$w$到$$w'=2(u\cdot w)u-w.$$直接计算得出$$u\cdot w = \frac{d}{b} \left( (2b-d)\sqrt{\frac{b+d}{2b}} + h\sqrt{\frac{b-d}{2b}} \right).$$自从$$h^2=b^2-d^2=(b+d)(b-d),$$我们有$$h\sqrt{\frac{b-d}{2b}} =(b-d)\sqrt{\frac{b+d}{2b}}.$$所以$$u\cdot w = d\sqrt{\frac{b+d}{2b}}.$$因此$$2(u\cdot w)u = \left( \frac{d(b+d)}b, \frac{hd}b \right).$$减法$w$,$$w' = \left( \frac{d(b+d)}b-\frac{d(2b-d)}b, \frac{hd}b-\frac{hd}b \right) = \left( \frac{d(2d-b)}b, 0 \right).$$添加坐标$A_2=(-d,0)$,$$S_2 = A_2+w' = \left( \frac{d(2d-b)}b, \frac{hd}b \right).$$边的中点$A_1A_3$是$$M_2=\left(\frac d2,\frac h2\right).$$的斜率$M_2S_2$等于$$m= \frac{\frac{hd}b-\frac h2} {\frac{d(2d-b)}b-\frac d2} = \frac{h(2d-b)} {d(4d-3b)}.$$其方程为$$y-\frac h2 = m\left(x-\frac d2\right).$$环境$x=0$产生与对称轴的交点：$$y = \frac h2-\frac d2\,m = \frac h2 \left( 1-\frac{2d-b}{4d-3b} \right) = \frac h2\cdot\frac b{2b-3d}.$$因此$$P= \left( 0, \frac h2\cdot\frac b{2b-3d} \right)$$位于$M_2S_2$。 

对称轴的反射$x=0$交换顶点$A_2$和$A_3$，因此它交换了对$(M_2,S_2)$和$(M_3,S_3)$。 线路$M_3S_3$因此是$M_2S_2$。 

自从$P$位于对称轴上，它被该反射固定。 最后$P$也位于$M_3S_3$。 

重点$P$位于$M_1S_1$因为$M_1S_1$是对称轴本身。 因此$$P\in M_1S_1\cap M_2S_2\cap M_3S_3.$$这三条线是并行的。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是确定$T_2$。 边上的切线长度$A_1A_3$是$$A_1T_2=s-a_1=(b+d)-2d=b-d,$$和$$A_3T_2=s-a_3=(b+d)-b=d.$$他们的总和是$b$，长度$A_1A_3$，因此截面公式中使用的比率是正确的。 

第二个微妙的步骤是简化$$u\cdot w=d\sqrt{\frac{b+d}{2b}}.$$开始于$$h^2=(b+d)(b-d),$$一个获得$$h\sqrt{\frac{b-d}{2b}} = \sqrt{\frac{(b+d)(b-d)^2}{2b}} = (b-d)\sqrt{\frac{b+d}{2b}},$$这证明了取消的合理性，从而使反射计算变得易于管理。 

第三个微妙的步骤是对称性论证。 轴上的反射$x=0$发送$A_2$到$A_3$，保留内切圆，发送$T_2$到$T_3$，并发送平分线$\angle A_2$到平分线$\angle A_3$。 因此它发送$S_2$到$S_3$和$M_2$到$M_3$。 因此该线的图像$M_2S_2$正是这条线$M_3S_3$。 由于对称轴上的每一点都是固定的，因此对称轴上的任意一点$M_2S_2$位于该轴上也必须位于$M_3S_3$。 

## 替代方法

 通过引入对称轴并通过等角度条件表达反射接触点，可以采用综合方法。 可以直接证明 cevians$M_2S_2$和$M_3S_3$是对称的，然后使用沿边的比率和合适的辅助三角形中的 Menelaus 类型计算来识别它们在轴上的公共点。 该论证避免了坐标，但需要几个重要的比率变换。 

另一种方法使用重心坐标。 内切圆的接触点具有简单的重心描述，并且可以用代数方式表达穿过角平分线的反射。 计算线的重心方程后$M_iS_i$，并发性由行列式计算得出。 上面提出的坐标方法是优选的，因为等腰对称性将问题简化为寻找与对称轴的单个交点，并且每个计算仍然是基本的。
