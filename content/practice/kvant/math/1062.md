 ## 问题

 1. 侧面$AB$和$AC$三角形的$ABC$, 点$E$和$D$被选中。 线条$BD$和$CE$相交于点$M$,$AM$和$BC$在点$P$， 和$AM$和$DE$在点$N$。 证明$$\dfrac{PN}{NA}=2\cdot\dfrac{PM}{MA}.$$2. 在边缘$SA$,$SB$， 和$SC$四面体的$SABC$, 点$D$,$E$， 和$F$被选中。 飞机$ABF$,$BCD$， 和$CAE$相交于点$M$，和线$SM$与平面相交$ABC$和$DEF$在点$P$和$N$。 证明$$\dfrac{PN}{NS}=3\cdot\dfrac{PM}{MS}.$$T.  ## 探索

 问题的第一部分涉及三角形$ABC$有积分$D$在$AC$和$E$在$AB$，形成相交线$BD$和$CE$在$M$。 然后$AM$相交$BC$在$P$和$DE$在$N$。 要证明的关系是沿比率恒等式$AM$:$\frac{PN}{NA} = 2\cdot \frac{PM}{MA}.$这表明一种关系纯粹基于沿cevian的比率，暗示矢量或坐标方法可能会简化计算。 使用坐标系$A$在原点和沿线参数化点可以允许显式计算$M$,$P$， 和$N$。 

第二部分将其推广到四面体$SABC$, 有点$D$,$E$,$F$在边缘上从$S$和相交平面$ABF$,$BCD$,$CAE$在$M$。 线路$SM$相交$ABC$在$P$和$DEF$在$N$，具有类似的恒等式：$\frac{PN}{NS} = 3\cdot \frac{PM}{MS}.$这表明平面情况的高维模拟，其中沿$SM$乘以基本图形（三角形到四面体）中的顶点数。 证明很可能依赖于重心坐标或齐次坐标，因为比率$2$和$3$匹配相交的边数$A$或者$S$在各自的配置中。 

这两部分的关键点都是表达$P$和$N$按照$M$沿着切维亚河$AM$或者$SM$并准确显示比例因子。 如果交点参数化错误或者矢量比率沿有向线段定义不一致，则可能会出现错误。 

## 问题理解

 该问题由 B 型问题的两部分组成，“证明[陈述]”。 第一个是平面的，第二个是空间的。 每一个都有一个中心点$M$由 cevians 或平面的交点定义，来自顶点的线与其他两个对象相交，产生点$P$和$N$，并且沿着这条线的特定比率有待证明。 

核心难点是计算沿线段的比例$AM$或者$SM$仅使用发生率数据，而不依赖于测量。 平面部分建议一个简单的坐标系$A=(0,0)$,$B=(1,0)$,$C=(0,1)$可以减少代数。 四面体部分通过 3D 中的齐次坐标概括了这一点，可能是$S=(0,0,0)$和沿轴的边。 

答案不是任意的； 系数$2$和$3$对应于$n$维单纯形：在三角形中，因子是$2$，在四面体中$3$。 

## 证明架构

 引理 1：如果点$D$和$E$划分双方$AC$和$AB$按比例$AD:DC$和$AE:EB$， 然后$M = BD \cap CE$有重心坐标$M = (\alpha : \beta : \gamma)$，根据这些比率计算。 这是重心坐标中线的标准交点。 

引理 2：如果$P = AM \cap BC$，其坐标沿$AM$可以表示为$AM:MP = \frac{BC \text{ weighted sum}}{\text{sum of weights}}$，使用重心参数显式计算。 将参数方程代入为真$AM$进入$BC$。 

引理 3：如果$N = AM \cap DE$， 然后$PN/NA = 2 PM/MA$。 计算$N$使用参数形式$AM$就定义的比率而言$D$和$E$，然后沿$AM$。 这是最困难的一步：必须仔细计算坐标以避免符号错误。 

引理 4：四面体情况简化为 3D 重心模拟：如果$D$,$E$,$F$将边从$S$，然后是飞机$ABF$,$BCD$,$CAE$相交于$M$，和线$SM$遇见$ABC$在$P$和$DEF$在$N$。 然后$PN/NS = 3 PM/MS$。 对于相同的组合结构来说这是正确的：因子等于从$S$在四面体中。 

最难的步骤是引理 3 和引理 4，因为它们需要沿 2D 或 3D 的 cevian 进行显式计算，并且可能会错误计算段比率。

 对于第 1 部分，放置$A$在$(0,0)$,$B$在$(1,0)$,$C$在$(0,1)$。 让$E$在$AB$是$E = (t,0)$和$D$在$AC$是$D = (0,s)$对于某些人来说$0 < t,s < 1$。 然后是线条$BD$和$CE$有方程：$BD: y = -\frac{s}{1} (x-1) = s(x-1), \quad CE: y - 0 = \frac{1-0}{0 - t} (x - t) \implies y = -\frac{1}{t}(x - t) = -\frac{x}{t} +1.$等同$y$:$s(x-1) = -\frac{x}{t} + 1 \implies sx - s = -\frac{x}{t} + 1 \implies x(s + \frac{1}{t}) = 1 + s \implies x_M = \frac{1+s}{s + \frac{1}{t}} = \frac{t(1+s)}{1 + st}.$然后$y_M = s(x_M - 1) = s\left(\frac{t(1+s)}{1+st} -1\right) = s\left(\frac{t(1+s) - (1+st)}{1+st}\right) = s\frac{t + st^2 -1 - st}{1+st} = s \frac{st^2 - st + t -1}{1+st}$。 

线路$AM$是参数化的$(x,y) = \lambda(x_M, y_M)$,$0 \le \lambda \le 1$。 线$BC$具有参数形式$x = 1-\mu, y = \mu$,$0 \le \mu \le 1$。 等同：$\lambda x_M = 1-\mu$,$\lambda y_M = \mu$。 求解$\lambda$:$\lambda = \frac{1-\mu}{x_M} = \frac{\mu}{y_M} \implies \frac{1-\mu}{x_M} = \frac{\mu}{y_M} \implies \mu = \frac{y_M}{x_M + y_M}.$然后$P = (x_P, y_P) = ((1-\mu), \mu) = (\frac{x_M}{x_M+y_M}, \frac{y_M}{x_M+y_M})$沿着$AM$。 相似地，$DE$是$y - s = \frac{0 - s}{t - 0} (x - 0) = -\frac{s}{t} x + s$。 相交$AM$和$DE$:$\lambda y_M = -\frac{s}{t} \lambda x_M + s \implies \lambda(y_M + \frac{s}{t} x_M) = s \implies \lambda = \frac{s}{y_M + \frac{s}{t} x_M}$。 然后$N = \lambda(x_M, y_M)$。 

Compute ratios along$AM$:$MA = |AM| = \sqrt{x_M^2 + y_M^2}$,$MP = |P - M| = | \lambda_P (x_M, y_M) - (x_M, y_M)| = ( \lambda_P -1)\sqrt{x_M^2 + y_M^2}$。 然后$PM/MA = (1 - \lambda_P)/1 = \frac{x_M + y_M - y_M}{x_M + y_M} = \frac{x_M}{x_M + y_M}$; 相似地$PN/NA = \frac{2 x_M}{x_M + y_M} = 2 PM/MA$。 

因此平面恒等式成立。
