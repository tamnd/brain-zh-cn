 ## 问题

 1. 证明 的平方和$k$连续的自然数不能是完全平方数，如果$k$等于 3、5、7 或 9。 
2. 找出平方和为完全平方数的 11 个连续自然数。 

E·G·戈特曼

 ## 探索

 考虑平方和$k$开始于的连续自然数$n$，表示为$S_k(n) = n^2 + (n+1)^2 + \dots + (n+k-1)^2 = \sum_{i=0}^{k-1} (n+i)^2.$扩大这个产量$S_k(n) = k n^2 + k(k-1) n + \frac{k(k-1)(2k-1)}{6}.$该公式允许研究小$k$。 为了$k=3$，总和是$3n^2 + 6n + 5$，这永远不是自然的完美平方$n$因为它的模 3 的值不是 2 就是 0，不能是模 3 的平方。类似的模小整数分析，特别是模 3 和模 4，可以帮助排除$k=5,7,9$。 为了$k=11$，测试小整数或尝试将数字对称地集中在平均值周围可能会产生完全平方的总和。 关键的困难是证明小奇数的完美平方不存在$k$; naive trial fails, so modular arithmetic provides the essential constraint.

 ## 问题理解

 第一部分需要证明$k=3,5,7,9$，平方和$k$连续的自然数本身永远不是完美的平方。 这是一个 B 类问题，纯粹是不可能的证明。 第二部分要求提供 11 个连续自然数的明确示例，其平方和形成完全平方数，这是一个 D 类问题，需要构造。 

第一部分的核心难点在于证明对于奇数$k$，平方和，表示为二次多项式$n$，永远不会达到完美的平方。 对于第二部分，挑战是找到平方和简化为平方的数字，可能是通过对称地居中数字并利用对称序列的和来实现的。 

## 证明架构

 引理 1：对于奇数$k$，平方和$k$连续的自然数可以表示为二次$n$具有整数系数。 多项式形式由以下展开得出$(n+i)^2$和算术级数求和。 

引理 2：对于$k=3$，模 3 算术表明总和永远不是完美的平方。 模 3 求和产生与模 3 二次余数不兼容的余数。 

引理 3：对于$k=5$, 模 5 算术不包括完全平方数。 模 5 求和得出的余数不在模 5 的二次余数集合中。 

引理 4：对于$k=7$和$k=9$，模 7 和模 3 算术的类似论证表明不可能。 对小素数取模的二次留数足以排除解。 

引理 5：要找到平方和为完全平方数的 11 个连续数字，请将序列对称地居中$n$，用以下形式表示总和$n$，并求解所得二次方程的整数$n$使得总和是一个完全平方数。 整数解的验证完成了构造。 

最难的部分是引理 4，其中对同余的粗心处理可能会遗漏某些残基或忽略周期性。 

## 解决方案

 让$S_k(n) = \sum_{i=0}^{k-1} (n+i)^2$。 展开给出$S_k(n) = k n^2 + k(k-1) n + \frac{k(k-1)(2k-1)}{6}.$为了$k=3$,$S_3(n) = 3 n^2 + 6 n + 5.$考虑$S_3(n)$模 3。每个完全平方都等于 0 或 1 模 3。总和减少模 3：$S_3(n) \equiv 3n^2 + 6n + 5 \equiv 0 + 0 + 2 \equiv 2 \pmod{3}.$由于 2 不是模 3 的二次余数，$S_3(n)$永远不是一个完美的正方形。 

为了$k=5$,$S_5(n) = 5 n^2 + 20 n + 55.$减少模 5 给出$S_5(n) \equiv 5 n^2 + 20 n + 55 \equiv 0 + 0 + 0 \equiv 0 \pmod{5}.$因此任何完全平方解都必须能被 5 整除。让$S_5(n) = 5 m^2$。 代入，我们得到$5 n^2 + 20 n + 55 = 5 m^2 \implies n^2 + 4 n + 11 = m^2.$然后$n^2 + 4 n + 11 - m^2 = 0 \implies n^2 + 4 n + (11 - m^2) = 0.$该二次方程的判别式为$n$必须是完全平方数：$\Delta = 16 - 4(11 - m^2) = 16 - 44 + 4 m^2 = 4 m^2 - 28 = 4(m^2 - 7).$这个判别式必须是完全平方数，所以$4(m^2 - 7) = k^2$对于某个整数$k$，意味着$k$甚至，$k = 2 t$， 和$m^2 - 7 = t^2$， 因此$m^2 - t^2 = 7 \implies (m-t)(m+t) = 7.$7 的整数因子对是$(1,7)$和$(7,1)$以及他们的负面影响。 解决$m-t=1$,$m+t=7$给出$m=4$,$t=3$;$m-t=7$,$m+t=1$给出$m=4$,$t=-3$;$m-t=-1$,$m+t=-7$给出$m=-4$,$t=3$;$m-t=-7$,$m+t=-1$给出$m=-4$,$t=-3$。 每个案例给出$n = (-4 \pm \sqrt{\Delta})/2 = (-4 \pm 2 t)/2 = -2 \pm t$，产生$n = 1$或者$-5$,$n=-5$或者$1$等。只有积极的$n$很重要，所以$n=1$。 然后$S_5(1) = 1^2 + 2^2 + 3^2 + 4^2 + 5^2 = 55$，不是一个完美的正方形。 不存在解决方案。
