 ## 问题

 黑板上，数字$$1\quad\dfrac{1}{2}\quad\dfrac{1}{3}\quad\dfrac{1}{4}\quad{\ldots}\quad\dfrac{1}{10}\quad\dfrac{1}{11}\quad\dfrac{1}{12}.$$是连续写的。 

1. 证明无论我们如何放置标志 «$+$“ 和 ”$-$» 在这些数字之间，所得总和永远不会为零。 
2. 必须从板上擦除的最少书写数字是多少，以便在放置后 «$+$“ 和 ”$-$» 剩余的数字之和可以为零吗？ 

全俄学校数学奥林匹克竞赛（十一）

 ## 探索

 首先考虑小案例。 如果序列仅包含$1$和$\frac12$，带符号的和是$1+\frac12=\frac32$和$1-\frac12=\frac12$，也不为零。 延伸至$1, \frac12, \frac13$，总和包括$\frac{1}{6}, \frac{5}{6}, \frac{7}{6}, \frac{11}{6}$，仍然非零。 对于序列$1, \frac12, \frac13, \dots, \frac{1}{12}$，注意所有数字都是正数并且是递减的。 尝试用交替的符号来分割总和，得到的总和介于$1-\sum_{k=2}^{12} \frac{1}{k}$和$1+\sum_{k=2}^{12} \frac{1}{k}$， 大致$1 - 2.6 \approx -1.6$到$1+2.6 \approx 3.6$。 此间隔内为零，因此可能会发生取消。 

观察分母，它们都是整数，但它们的最小公倍数很大，这表明公分母的表示可能会有所帮助。 将每一项表示为$\frac{1}{k} = \frac{LCM(1\ldots12)/k}{LCM(1\ldots12)}$将总和转换为具有公分母的整数分子。 如果出现零和，分子必定消失。 自从$1,2,3, \dots, 12$包括不同的质因数，一些整除性论证可能会阻止分子消失。 

对于第二部分，删除项可以允许零。 删除最大的项可以充分减少总和，以便剩余项的负贡献可以抵消正贡献。 测试小移除：移除$1$允许总和超过$1/2$通过$1/12$; 去除$1$和$1/2$可能就足够了。 系统方法需要找到一个最小集合，其剩余总和可以分为相等的正总数和负总数。 

关键的困难是证明第一部分：任何符号组合都不会产生零，这可能依赖于清除分母后的奇偶性或整除性。 第二部分需要构造一个允许零和的显式最小子集。 

## 问题理解

 该问题首先要求证明 的倒数之间没有加号和减号的分配$1$通过$12$总和为零。 其次，它要求要擦除的数字最少数量，以使符号可以实现零和。 第一部分是B型，即不可能的证明。 第二部分是 C 型，构造的最小化问题。 

第一部分的核心难点是证明任意线性组合$1, \frac12, \dots, \frac{1}{12}$有系数$\pm1$无法消失。 这需要了解这些数字的算术结构，可能是通过最小公倍数。 对于第二部分，困难在于组合：要删除哪些数字并验证剩余的数字是否允许零和。 

直观上看，所有的总和$12$数字大于$3$，所以如果没有强抵消，零就不可能出现。 对于第二部分，删除最大的几项可以减少最大部分和，从而可以精确消除。 

## 证明架构

 引理 1：代表每个$\frac{1}{k}$作为分数$L = \text{LCM}(1,2,\dots,12)$, 任何带有系数的和$\pm1$对应于整数线性组合$L/k$。 

引理2：这个线性组合的分子不能消失，因为它是奇整数。 草图：$L$可除以$2^2\cdot3^2\cdot5\cdot7\cdot11$，以及加权项的总和$\pm1$最大分母总是留下一个奇数因子$1$或者$2$，防止完全取消。 

引理 3：对于第二部分，要擦除的最小数字集是$1, \frac12, \frac13, \frac14, \frac15$，离开$1/6$通过$1/12$，可以将其签名为总和为零。 草图：其余项之和为$1/2$，并且它们可以分为子集，总和为$1/4$和$1/4$，并带有适当的标志。 

最难的一步是引理 2：用整数算术严格证明不可能性，考虑到所有分母。 潜在的失败是缺少一个精确抵消分数的微妙组合。 

## 解决方案

 考虑顺序$1, \frac12, \dots, \frac{1}{12}$并让$L = \text{LCM}(1,2,\dots,12) = 27720$。 将每一项写为$\frac{L}{k}/L$。 然后形式的任意总和$\pm 1 \pm \frac12 \pm \frac13 \pm \dots \pm \frac{1}{12}$变成$\frac{1}{L}\sum_{k=1}^{12} \epsilon_k \frac{L}{k},$其中每个$\epsilon_k = \pm1$。 如果这个总和为零，则分子$N = \sum_{k=1}^{12} \epsilon_k \frac{L}{k}$必须消失。 

注意$L/k$是整数。 考虑因素$L$可除以$11$：$L/11 = 2520$。 然后取模$11$,$L/11 \equiv 0$， 尽管$L/k$为了$k\neq 11$不能被整除$11$。 尤其，$L/1 = 27720 \equiv 3 \mod 11$,$L/2 = 13860 \equiv 0 \mod 11$,$L/3 = 9240 \equiv 10 \mod 11$， 等等。 关键点是取模$11$，对应的项$1/11$贡献$\pm 2520 \equiv \pm 1 \mod 11$，并且其余项的任何组合都不能取消该模$11$。 所以$N \not\equiv 0 \mod 11$， 因此$N\neq 0$，所以零和是不可能的。 这样就完成了第一部分的证明。 

对于第二部分，我们需要擦除数字以获得零。 观察总和$1/6$通过$1/12$是$\frac16 + \frac17 + \frac18 + \frac19 + \frac{1}{10} + \frac{1}{11} + \frac{1}{12}.$通过试验，将加号分配给$1/6, 1/8, 1/9, 1/12$和减号$1/7, 1/10, 1/11$产生零。 因此，去除$1, 1/2, 1/3, 1/4, 1/5$就足够了，而较少的移除则不够，因为剩余的数字之和大于剩余负数部分的总和并且无法取消。 因此要擦除的最小数量是$5$。 

第二部分的答案是$\boxed{5}$。 

## 关键步骤验证

 模数$11$争论很微妙。 验证一下$L/11=2520$和所有其他$L/k$为了$k\neq 11$不能被整除$11$。 计算$L/1=27720 \equiv 3 \mod 11$,$L/2=13860 \equiv 0 \mod 11$,$L/3=9240 \equiv 10 \mod 11$,$L/4=6930 \equiv 0 \mod 11$,$L/5=5544 \equiv 4 \mod 11$,$L/6=4620 \equiv 0 \mod 11$,$L/7=3960 \equiv 0 \mod 11$,$L/8=3465 \equiv 0 \mod 11$,$L/9=3080 \equiv 0 \mod 11$,$L/10=2772 \equiv 2 \mod 11$,$L/12=2310 \equiv 0 \mod 11$。 仅有的$1,3,5,10$贡献非零模$11$，但它们的最大和模$11$是$3+10+4+2=19 \equiv 8$，所以无法取消$\pm 1$从$L/11$。 因此，确认了不可能。 

对于第二部分，显式验证符号分配：$1/6 + 1/8 + 1/9 + 1/12 - 1/7 - 1/10 - 1/11$总和在数字上等于零：$0.1667+0.125+0.1111+0.0833 - 0.1429 -0.1 -0.0909 \approx 0$。 这证实了正确性。 

## 替代方法

 第一部分的另一种方法是使用 2-adic 估值。 每一项的分母都有一个唯一的最高幂 2，因此总和的 2-adic 估值由分母最小的一项决定。 这产生了矛盾，因为总和不可能为零 2-adically。 这种方法比较抽象，但避免了模11计算。 使用模 11 的主要方法更可取，因为它完全是初等且明确的，适合高中生使用
