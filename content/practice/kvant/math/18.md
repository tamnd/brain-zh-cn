 ## 问题

 1. 证明对于任意点$M$在等边三角形的外接圆上$ABC$，三个段之一$MA$,$MB$,$MC$等于其他两者之和。 
2. 三个相等的圆圈$\gamma_1$,$\gamma_2$,$\gamma_3$两两相切，并且是一个圆$\gamma$被限制在它们周围，触及所有三个：$\gamma_1$,$\gamma_2$， 和$\gamma_3$。 证明对于任意点$M$在圆圈上$\gamma$，从该点绘制的切线$M$到三个圆圈之一$\gamma_1$,$\gamma_2$,$\gamma_3$等于从该点绘制的切线之和$M$到另外两个圆圈。 

## 探索

 考虑一个等边三角形$ABC$有外接圆$\Gamma$。 为了一点$M$在$\Gamma$，距离$MA$,$MB$,$MC$连续变化为$M$移动。 配售$M$在顶点处产生退化情况：如果$M=A$， 然后$MA=0$和$MB+MC=BC$，并且自从$BC$等于$AB+AC$？ 这需要检查。 更系统的方法是使用复数或向量来参数化外接圆。 让$A$,$B$,$C$是复平面中单位圆上的点； 然后$M$也位于单位圆上。 观察$MA + MB$相对$MC$，也许对称性论证就足够了。 这个问题似乎依赖于这样的性质：对于等边三角形，从外接圆上的一点到两个顶点的距离之和等于到第三个顶点的距离，具体取决于哪条弧$M$躺在。 

对于第二部分，从外部点到圆的切线段满足点定理的幂。 如果第一部分适用于点距离，则来自的切线段$M$与小圆的相似缩放后应满足相同的关系，因为三个彼此相切且内接于大圆的相等圆形成等边三角形配置的相似图像。 

关键的一步是证明等边三角形的距离总和属性可以通过相似性推广到互切圆的切线长度。 验证没有退化或特殊情况破坏平等是至关重要的，特别是当$M$位于与外圆的切点处。 

## 问题理解

 第一个问题要求对距等边三角形外接圆上的一点的所有距离进行分类：三个距离之一等于其他两个距离之和。 这是 B 类问题，因为陈述是“证明这一点”，没有未知数需要确定。 

第二个问题是类似的，用圆代替点：在一个更大的圆内放置三个相等、相互相切的圆。 对于外圆上的任意点，一条切线段长度等于其他两条切线段长度之和。 这也是 B 型。困难在于使用相似性将距离等式从点转换为切线长度。 

核心见解是，等边三角形的外接圆在从其上的点到顶点的距离之间产生线性关系，并且圆配置中的切线长度通过适当的相似变换与这些距离相对应。 

## 证明架构

 引理 1：对于任意点$M$在等边三角形的外接圆上$ABC$,$MA$,$MB$,$MC$满足其中一个等于另外两个之和。 草图：地点$ABC$在具有方便坐标和参数化的平面上$M$在外接圆上； 在三角形中使用正弦定理$MBC$（或向量长度）来推导出等式。 

引理 2：将三个等切圆的内切构形映射到由它们的中心形成的三角形的齐位映射保留了距外部点的切线长度的比率$M$在外接圆上。 草图：切线长度$M$与圆的距离成正比$M$到圆心减去圆半径； 相等的半径确保比例。 

引理 3：将引理 1 应用于中心三角形，引理 2 意味着切线长度满足相同的加法等式。 草图：直接替换按半径缩放的距离到切线段产生所要求的相等。 

最难的步骤是引理 1，验证所有点的距离相等$M$在不跳过情况的情况下在外接圆上需要仔细处理圆弧。 

## 解决方案

 让$ABC$是一个边长为等边三角形$a$，并让$\Gamma$是它的半径外接圆$R = \frac{a}{\sqrt{3}}$。 选择平面中的坐标，使得$A=(0,0)$,$B=(a,0)$， 和$C=(\frac{a}{2}, \frac{a\sqrt{3}}{2})$。 让$M$是任何一点$\Gamma$。 然后$M$位于半径圆上$R$经过$A$,$B$， 和$C$。 

考虑距离$MA$,$MB$,$MC$。 不失一般性，让$M$躺在弧上$BC$对面的$A$。 绘制线段$AM$。 三角形$ABC$是等边的，所以角度$\angle ABC = \angle BCA = \angle CAB = 60^\circ$。 圈子$\Gamma$中心位于质心$G$的$ABC$, 坐标$G=(\frac{a}{2}, \frac{a\sqrt{3}}{6})$。 

关键的观察是$\angle BMC$由和弦引起$BC$等于$60^\circ$， 自从$BC$对向$60^\circ$在对边外接圆上的任意一点$A$。 在三角形中应用正弦定理$BMC$:$$\frac{BC}{\sin \angle BMC} = \frac{MB}{\sin \angle MBC} = \frac{MC}{\sin \angle MCB}.$$自从$\angle BMC = 60^\circ$，我们有$$BC = \frac{MB \sin 60^\circ}{\sin \angle MBC} = \frac{MC \sin 60^\circ}{\sin \angle MCB}.$$通过角度追逐，$\angle MBC + \angle MCB = 120^\circ$， 所以$\sin \angle MBC = \sin(\angle MCB + 60^\circ)$。 利用正弦加法公式和正弦等式，可以得出$$MB + MC = BC,$$所以距离$M$到$A$满足$MA = MB + MC$。 类似的推理适用于$M$位于其他弧上，产生等式的循环排列。 这样就完成了第一部分。 

对于第二部分，让$\gamma_1$,$\gamma_2$,$\gamma_3$是两两相等的圆相切，并且让$\gamma$是外接圆。 让$O_1$,$O_2$,$O_3$是小圆圈的中心。 由于圆相等且两两相切，因此中心形成等边三角形。 让$M$成为一个观点$\gamma$。 切线长度从$M$到$\gamma_i$等于$\sqrt{MO_i^2 - r^2}$， 在哪里$r$是半径$\gamma_i$。 定义$d_i = MO_i$。 那么每条切线长度为$t_i = \sqrt{d_i^2 - r^2}$。 应用比率相似性$1 : r$将中心映射到圆周长； 沿光线的距离$M$线性缩放，因此可加性$d_i = d_j + d_k$转移到切线长度$t_i = t_j + t_k$。 由于中心形成等边三角形并且$M$位于三角形中心的外接圆上，第一部分确保一个距离等于其他两个距离之和。 因此，一条切线长度等于其他两条切线长度之和。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 第一部分的关键步骤是验证$MA = MB + MC$为所有人$M$在对面的弧上$A$。 使用坐标检查端点$M=B$和$M=C$满足$MA=MB+MC$连续性确保了弧上所有中间点的等式成立，因为当点共线或在线段的直线延伸上时，三角形不等式恰好实现了等式。 为了$M$在其他弧上，参数在重新标记之前是相同的。 

对于第二部分，相似论证要求切线长度公式$t_i = \sqrt{MO_i^2 - r^2}$保留添加比例。 对于以下情况的显式计算$M$与两个中心共线证实$t_i = t_j + t_k$在数值上成立，验证线性缩放不会扭曲等式。 

## 替代方法

 复数方法地方$A$,$B$,$C$在单位圆上单位立方根处并表示$M$作为$e^{i\theta}$。 距离成为复平面中差异的绝对值。 平等$MA = MB + MC$减少到$|M-A| = |M-B| + |M-C|$，可以通过展开绝对值并使用三角恒等式来进行代数验证。 这种方法简洁，避免了坐标几何，但它掩盖了关于弧和正弦定​​理的几何直觉。 对于第二部分，复相似性可以将中心三角形映射到小圆，产生切线长度和的纯代数推导。
