 ## 问题

 让$a_n$表示最接近的整数$\sqrt{n}$。 求总和$$\dfrac1{a_1}+\dfrac1{a_2}+\dfrac1{a_3}+\ldots+\dfrac1{a_{1980}}.$$G·A·古列维奇

 全联盟中学生数学奥林匹克竞赛（第十二届，1978 年，8-9 年级）

 ## 探索

 考虑前几个值$a_n$。 为了$n = 1$,$\sqrt{1} = 1$， 所以$a_1 = 1$。 为了$n = 2$,$\sqrt{2} \approx 1.414$，四舍五入到最接近的整数给出$a_2 = 1$。 为了$n = 3$,$\sqrt{3} \approx 1.732$， 所以$a_3 = 2$。 为了$n = 4$,$\sqrt{4} = 2$, 给予$a_4 = 2$。 为了$n = 5$,$\sqrt{5} \approx 2.236$， 所以$a_5 = 2$。 为了$n = 6$,$\sqrt{6} \approx 2.449$,$a_6 = 2$。 为了$n = 7$,$\sqrt{7} \approx 2.646$,$a_7 = 3$。 为了$n = 8$,$\sqrt{8} \approx 2.828$,$a_8 = 3$。 为了$n = 9$,$\sqrt{9} = 3$,$a_9 = 3$。 继续这样下去，每个整数$k$显示为$a_n$连续多次$n$前$a_n$跳转到$k+1$。 这表明可以根据值对总和进行分组$a_n$，计算每个整数出现的次数，这可能与平方有关$k^2$和$(k+1)^2$。 

关键点是确定到底有多少个整数$n$对应于给定的$a_n = k$，特别是在边界附近$\sqrt{n}$是两个整数之间的中间值。 这些舍入阈值中可能会出现错误。 

## 问题理解

 该问题要求最接近的整数的倒数之和$\sqrt{n}$为了$n$从$1$到$1980$。 这是一个 C 类问题，因为它要求有限和的精确值。 核心难点在于正确计算每个整数值对应有多少项$a_n$。 直观地说，$a_n = k$对于整数$n$在区间内$[(k - \tfrac12)^2, (k + \tfrac12)^2)$，除非必须对小量进行调整$k$在哪里$k - \tfrac12 < 1$。 这个间隔长度决定了每个倒数的次数$1/k$出现。 

## 证明架构

 引理 1：对于每个整数$k \ge 1$,$a_n = k$当且仅当$n$满足$k - \frac12 \le \sqrt{n} < k + \frac12$， 那是，$n \in [(k - \frac12)^2, (k + \frac12)^2)$。 这直接来自最接近整数舍入的定义。 

引理 2：整数的数量$n$满意的$a_n = k$是$2k$为了$k \ge 2$和$1$为了$k=1$。 这是通过计算区间内的整数计数获得的$[(k - \frac12)^2, (k + \frac12)^2)$。 

引理 3：确定最大整数$m$这样$(m + \tfrac12)^2 \le 1980$识别最后一个完整的术语块$a_n = m$。 这涉及显式计算并确保所有$n \le 1980$被覆盖。 

引理 4：对每个块的贡献求和$1/k$乘以它发生的次数。 对于最后一个部分块，仅包含以下项$n \le 1980$。 

最难的步骤是引理 2，因为误算间隔长度或舍入规则将给出不正确的总和。 引理 3 还需要仔细算术以避免差一错误。 

## 解决方案

 考虑定义$a_n$作为最接近的整数$\sqrt{n}$。 然后$a_n = k$当且仅当$$k - \frac12 \le \sqrt{n} < k + \frac12.$$两边平方得到$$(k - \frac12)^2 \le n < (k + \frac12)^2.$$为了$k = 1$,$(1 - \frac12)^2 = \frac14$， 但$n \ge 1$，所以第一个区间是$n \in [1, \frac{9}{4})$， 那是，$n = 1, 2$。 检查这些，$a_1 = 1$,$a_2 = 1$。 因此，$1$出现两次，但我们必须精确：$n=1,2$对应于$a_n = 1$因为$\sqrt{2} \approx 1.414 < 1.5$。 

为了$k \ge 2$，区间长度为$(k + \frac12)^2 - (k - \frac12)^2 = (k^2 + k + \frac14) - (k^2 - k + \frac14) = 2k$。 因此，对于每个$k \ge 2$，正好有$2k$连续整数$n$这样$a_n = k$。 

让$m$是最大的整数，使得$(m + \frac12)^2 \le 1980$。 计算$(m + \frac12)^2 = 1980$大约。 自从$44^2 = 1936$和$45^2 = 2025$,$(44 + \frac12)^2 = 44.5^2 = 1980.25 > 1980$， 所以$m = 44$。 所以，$a_n = k$为了$k = 1, 2, \dots, 43$每个都准确地出现$2k$次，以及$a_n = 44$为了$n$从$(43.5)^2 = 1892.25$最多$1980$。 最后一个块中的整数数量是$1980 - 1892 = 88$。 

因此总和是$$\sum_{k=1}^{43} 2k \cdot \frac{1}{k} + 88 \cdot \frac{1}{44} = \sum_{k=1}^{43} 2 + 2 = 86 + 2 = 88.$$明确地说，$\sum_{k=1}^{43} 2 = 86$，最后的贡献是$88/44 = 2$，总共给出$88$。 

因此总和是$$\boxed{88}.$$## 关键步骤验证

 区间长度公式$(k + \frac12)^2 - (k - \frac12)^2 = 2k$明确地重新计算为$k = 2,3,4$并验证：对于$k=2$,$(2.5)^2 - (1.5)^2 = 6.25 - 2.25 = 4 = 2 \cdot 2$， 为了$k=3$,$(3.5)^2 - (2.5)^2 = 12.25 - 6.25 = 6 = 2 \cdot 3$。 最大$m$被重新计算：$(44.5)^2 = 1980.25 > 1980$,$(43.5)^2 = 1892.25 < 1980$, 确认$m = 44$。 最后一个块的长度$1980 - 1892 = 88$进行了双重检查。 每一步都会重现总和$88$准确地说，确认算术和舍入边界是正确的。 

## 替代方法

 另一种方法是使用积分来近似求和，解释$1/a_n \approx 1/\sqrt{n}$并总结$n$来估计价值。 这将提供近似答案，但无法产生精确的整数$88$因为舍入效应会累积，最后的部分区间需要精确计数。 主要方法更可取，因为它提供了精确的术语枚举并严格考虑了舍入规则。
