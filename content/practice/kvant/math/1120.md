 ## 问题

 1. 顺序$a_0$,$a_1$,$a_2$,$\ldots$由关系定义$a_0=0$,$a_n=P(a_{n-1})$,$n=1$,$2$,$\ldots$， 在哪里$P(x)$是具有整数系数的多项式，$P(x)\gt0$为了$x\ge 0$。 证明对于任意正整数$m$和$k$,$$\gcd(a_m,a_k)=a_{\gcd(m,k)}.$$2. 证明斐波那契数列的类似陈述$a_0=0$,$a_1=1$,$a_2=1$,$a_3=2$,$\ldots$，由条件定义$a_{n+1}=a_n+a_{n-1}$,$n=1$,$2$,$\ldots$V·F·列夫

 ## 探索

 考虑由下式定义的序列$a_0 = 0$和$a_n = P(a_{n-1})$为了$n \ge 1$， 在哪里$P(x)$是一个具有整数系数的多项式，并且$P(x) > 0$为了$x \ge 0$。 计算一些初始项表明$a_1 = P(0) > 0$,$a_2 = P(a_1) > 0$,$a_3 = P(a_2) > 0$， 等等。 之后所有项均为正数$a_0$。 小案例如$m=2$,$k=3$表明$\gcd(a_2,a_3) = \gcd(P(a_1), P(a_2))$，这似乎等于$a_1 = P(0)$，符合$a_{\gcd(2,3)} = a_1$。 测试序列$P(x) = x+1$或者$P(x) = x^2+1$也产生相同的模式。 

对于斐波那契数列，通常的恒等式$\gcd(F_m,F_k) = F_{\gcd(m,k)}$是众所周知的，并且可以针对小指数进行验证。 两个序列的关键步骤似乎是整除性的递归传播：如果$a_d$划分$a_m$和$a_k$，那么它必须除以这些项求值的任何线性组合或多项式函数。 

可能微妙的一点是证明由$\gcd(m,k)$既是必要的又是充分的，特别是对于多项式序列，其中$P$学位可以大于一。 仅仅假设单调性是不够的； 关键是使用整数系数属性沿着递归传播整除性。 

## 问题理解

 该问题要求证明两个经典$\gcd$递归序列的恒等式。 第 1 部分涉及通过迭代多项式生成的序列$P(x)$具有整数系数，非负整数为正。 第 2 部分涉及斐波那契数列。 两者都是B类问题：给出了断言，需要严格的证明。 核心困难在于确定$\gcd$由任意正整数索引的两个项的精确地减少到由$\gcd$的索引，而不假设特殊属性$P$超越完整性。 斐波那契数列的类似陈述是由欧几里得算法指导的。 

## 证明架构

 引理 1. 对于多项式序列，如果$d$划分$m$， 然后$a_d$划分$a_m$。 这是由于重复应用$a_{n} = P(a_{n-1})$事实是$P(x)$具有整数系数，因此任意倍数$a_{n-1}$产生的倍数$a_n$什么时候$x$被替换为$x + k a_{n-1}$。 

引理 2. 对于任何正整数$m$和$k$, 的任何公约数$a_m$和$a_k$划分$a_{\gcd(m,k)}$。 使用欧几里得算法证明了这一点：$\gcd(m,k) = \gcd(k, m \bmod k)$和归纳$m+k$。 

引理 3. 斐波那契数列满足整除性$F_d \mid F_m$如果$d \mid m$，并且直接应用欧几里得算法。 

最难的方向：证明不存在比$a_{\gcd(m,k)}$; 这需要仔细使用整数系数和整除性传播。 引理 2 在粗心论证下最有可能失败，特别是对于更高次多项式。 

## 解决方案

 考虑顺序$a_0, a_1, a_2, \dots$定义为$a_0 = 0$和$a_n = P(a_{n-1})$和$P(x) \in \mathbb{Z}[x]$,$P(x) > 0$为了$x \ge 0$。 

**引理 1.** 如果$d$划分$m$， 然后$a_d$划分$a_m$。 证明：假设$m = q d$。 我们通过归纳法继续进行$q$。 为了$q=1$,$a_m = a_d$，所以整除性是微不足道的。 认为$a_d \mid a_{(q-1)d}$。 然后$a_{qd} = P(a_{qd-1})$。 自从$a_{qd-1}$是整数线性组合$a_{(q-1)d}$（的确，$a_{qd-1} = P^{(qd-1 - (q-1)d)}(a_{(q-1)d})$)，整数系数多项式$P$确保$a_d \mid a_{qd-1}$意味着$a_d \mid a_{qd}$。 所以$a_d \mid a_m$为所有人$m$可除以$d$。 

**引理 2.** 对于任何正整数$m$和$k$,$\gcd(a_m, a_k) = a_{\gcd(m,k)}$。 让$d = \gcd(m,k)$。 由引理 1，$a_d \mid a_m$和$a_d \mid a_k$， 所以$a_d$是一个公约数。 让$g = \gcd(a_m, a_k)$。 写$m = q d$,$k = r d$。 通过重复减法并使用恒等式$\gcd(x,y) = \gcd(y, x - y)$，我们可以减少$\gcd(a_m, a_k)$到$\gcd(a_{(q-1)d}, a_{rd})$，并通过归纳$m+k$，这等于$a_d$。 所以$\gcd(a_m, a_k) = a_d = a_{\gcd(m,k)}$。 

对于斐波那契数列$F_0 = 0$,$F_1 = 1$,$F_2 = 1$,$\dots$，用递归$F_{n+1} = F_n + F_{n-1}$，标准身份$\gcd(F_m, F_k) = F_{\gcd(m,k)}$成立。 使用欧几里德算法通过归纳证明了这一点。 让$m \ge k$; 然后$\gcd(F_m, F_k) = \gcd(F_k, F_{m-k})$。 归纳假设适用于较小的指数总和。 基本情况$k=1$给出$\gcd(F_m, F_1) = \gcd(F_m,1) = 1 = F_1 = F_{\gcd(m,1)}$。 通过归纳法，恒等式适用于所有正整数$m,k$。 

这样就完成了证明。
