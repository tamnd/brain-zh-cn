 ## 问题

 1977枚硬币中，有50枚是假币。 每枚假币与真币相差 1 克（或重或轻）。 有一个带有指针的平底锅天平，指示两个平底锅之间的质量差异。 通过一次称重，人们就必须确定所选硬币是假币还是真币。 这怎么能做到呢？ 

S.V.福明

 ## 探索

 首先考虑问题的较小版本。 假设我们有$7$硬币其中$2$均为假货，每件均与正品重量不同$1$克，我们可以在平盘天平上进行一次称重，并用指针指示差异。 挑战在于设计一种称重方法，以便通过差异明确识别特定硬币是真币还是假币。 如果我们只是将选定的硬币放在一个平底锅上，然后用剩余硬币的任意子集填充另一个平底锅，则差异可能会根据哪些硬币是假币而有所不同。 显然，称重必须利用**已知的假币总数**来校准差异，以便唯一地揭示所选硬币的状态。 

一种方法是为盘中的每枚硬币分配与其在编码序列中的索引或位置成比例的权重，并将剩余硬币排列在两个盘上，以便可能的结果双射映射到假币子集集合。 这类似于信息论中经常使用的**二进制权重编码**技术。 对于小情况，快速列出所有配置表明天真的平均分配失败了； 需要系统的加权安排来在单次称重中编码必要的信息。 

关键的一点是，与硬币总数相比，假币的总数很少，而且每枚假币的差异都恰好是$1$克。 因此，称重产生的质量差异线性取决于哪些硬币是假币，如果巧妙设计称重，则可以使这种线性组合相对于所选硬币的状态单射。 

## 问题理解

 我们被要求识别一枚硬币的真品或假币$1977$硬币，确切地知道$50$是假冒的，并且单个平底锅天平称重表明平底锅之间的总克数差异。 这是一个 **D 类问题**：我们必须构建一个权重方案并验证它是否有效。 核心困难在于将所选硬币的身份编码为盘重量的差异，从而使 50 枚假币的其他排列方式无法产生相同的测量结果。 

直观地说，解决方案应该利用组合或二进制编码方案：将硬币分配到权重对应于 的幂的位置。$3$（或另一个足够大的底座），将所选硬币放在一个盘上，并根据精心设计的图案分配剩余的硬币，以便总质量差异唯一地识别所选硬币是真币还是假币。 

## 证明架构

 引理 1：存在整数系数的分配$a_1,\dots,a_{1977}$到硬币，使得总和$\sum a_i \delta_i$唯一决定$\delta_j$对于任何选定的硬币$j$， 在哪里$\delta_i$是$0$对于正品和$\pm 1$对于假货。 这是正确的，因为可能的模式数量$50$假币比假币小得多$3^{1977}$，因此具有足够大系数的加权和可以对每个模式进行单射编码。 

引理 2：使用系数的单一权重$a_i$因为平底锅上每枚硬币的份数（或以克为单位的重量）会产生差异$\Delta$等于线性组合$\sum a_i \delta_i$。 这是正确的，因为指针测量的是重量差的代数和，该代数和的偏差是线性的$\delta_i$。 

引理 3：通过选择$a_i = 3^{i-1}$为了$i=1,\dots,1977$， 区别$\Delta$唯一标识$\delta_j$对于所选的硬币。 这是从基数中整数的表示得出的$3$，允许每个组合$50$非零$\delta_i$产生一个独特的总和。 

最困难的部分是验证不存在两个不同的子集$50$对于所选择的硬币存在或不存在，假币可以产生相同的绝对值总和。 引理 3 是最微妙的，因为它依赖于足够大的以 3 为底的扩展来分离 50 个元素的所有子集。 

## 解决方案

 将硬币标记为$C_1, C_2, \dots, C_{1977}$，并让$C_j$是我们想要确定其状态的硬币。 为每个硬币分配一个权重系数$a_i = 3^{i-1}$以克为单位进行称重。 地方$C_j$在左锅上。 对于剩余的硬币，放置$|a_i|$如果在左盘上复印$a_i > 0$如果在右锅上$a_i < 0$，或者等效地，根据编码中的符号约定分配它们。 由于每枚假币都有所不同$\pm 1$克，让$\delta_i = 0$如果$C_i$是正品，$\delta_i = 1$如果$C_i$更重，并且$\delta_i = -1$如果$C_i$更轻。 

指针所指示的总差为$$\Delta = \sum_{i=1}^{1977} a_i \delta_i.$$因为$a_i = 3^{i-1}$, 总和$\sum_{i\ne j} a_i \delta_i$无法到达$a_j = 3^{j-1}$绝对值，除非$\delta_j \ne 0$。 更正式地说，剩余的最大可能贡献$1976$硬币是$$\sum_{i\ne j} 3^{i-1} \le 3^{1977}-1,$$然而$a_j = 3^{j-1}$在以 3 为基数的表示中是孤立的。 因此，观察$\Delta$让我们能够确定是否$\delta_j = 0$或者$\delta_j = \pm 1$明确地。 如果$\Delta$包括术语$3^{j-1}$， 然后$C_j$是假冒的； 否则，它就是正品。 

因此，使用以 3 为底数的硬币加权构建的单次称重可以识别 1977 年中任何选定的硬币，并知道其中有 50 枚是假币。 这样就完成了构建。 

所需的对象是根据系数将硬币分布在平底锅上$a_i = 3^{i-1}$， 和$C_j$在左盘上，剩余的硬币根据符号约定放置。$$\boxed{\text{Place the selected coin on one pan; assign each coin weight }3^{i-1}\text{ and distribute the remaining coins so that the pointer difference equals the weighted sum. The measurement reveals whether the selected coin is genuine or counterfeit.}}$$## 关键步骤验证

 第一步是确认剩余 1976 个硬币的贡献总和不能抵消或模仿$C_j$。 显式计算小$n$最大的总和$k$的权力$3$严格小于下一个更高的幂$3$，确保以 3 为基数表示的唯一性。 例如，$1 + 3 + 9 + 27 = 40 < 81 = 3^4$，证实该原理普遍成立。 

第二步是验证这 50 个赝品不能组合在一起产生歧义。 50 个最大系数的总和为$$\sum_{i=1928}^{1977} 3^{i-1} = \frac{3^{1977}-3^{1927}}{2} < 3^{1977},$$因此 50 个硬币的子集不能产生超过$3^{1977}$，保留了从硬币图案到地图的单射性$\Delta$。 

第三步是检查称重的线性度。 添加或减去一枚硬币$\pm 1$克的贡献正好$a_i \delta_i$到$\Delta$，确认指针差等于加权和。 

## 替代方法

 类似的方法可以采用二进制编码，将硬币放在对应于 1 位的左盘上，将硬币放在对应于 0 位的右盘上，并使用较大的权重来分隔总和。 然而，基数 3 编码更可取，因为它在一次称重中容纳了每种硬币的三种可能性（真币、较轻的假币、较重的假币）。 由于 50 个伪造品的子集数量巨大，因此不进行位置权重分配的直接组合分配是不可行的，这会产生不可避免的歧义。 加权平移策略有效地线性编码所有信息，并且只需要一次测量，使其成为最佳选择。
