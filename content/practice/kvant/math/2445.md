 ## 问题

 让$P=A_1A_2\ldots A_k$是平面上的凸多边形。 顶点$A_1$,$A_1$,$\ldots$,$A_k$具有整数坐标并位于单个圆上。 表示为$S$多边形的面积$P$。 奇自然数$n$使得多边形所有边的长度的平方$P$是可被整除的整数$n$。 证明$2S$是一个能被整除的整数$n$。 

A·盖富林

 国际数学奥林匹克竞赛（第57届）

 ## 探索

 让$A_{k+1} = A_1$，并让$q = p^t$是任意质数幂除以奇数$n$。 足以证明$q \mid 2S$对于每一个这样的主要力量。 顶点位于具有整数方程的圆上$a(x^2 + y^2) + bx + cy + d = 0,$选择原语使得$\gcd(a,b,c,d) = 1$。 对于一个顶点$A_i = (x_i, y_i)$定义边缘向量$e_i = A_{i+1} - A_i = (u_i, v_i)$。 减去计算的圆方程$A_i$和$A_{i+1}$给出$a\bigl((x_i + u_i)^2 + (y_i + v_i)^2 - x_i^2 - y_i^2\bigr) + b u_i + c v_i = 0,$这简化为$2a(x_i u_i + y_i v_i) + a(u_i^2 + v_i^2) + b u_i + c v_i = 0.$自从$q \mid \lVert e_i \rVert^2 = u_i^2 + v_i^2$对于每一方，我们都有$2a(x_i u_i + y_i v_i) + b u_i + c v_i \equiv 0 \pmod q.$总结一切$i = 1, \dots, k$产量$\sum_{i=1}^k \bigl(2a(x_i u_i + y_i v_i) + b u_i + c v_i\bigr) \equiv 0 \pmod q.$条款涉及$b$和$c$在伸缩总和下消失，因为$\sum_{i=1}^k u_i = \sum_{i=1}^k v_i = 0$，离开$2a \sum_{i=1}^k (x_i u_i + y_i v_i) \equiv 0 \pmod q.$众所周知的公式$x_i u_i + y_i v_i = \det(A_i, e_i)$给出$2a \sum_{i=1}^k \det(A_i, e_i) = 4aS,$在哪里$S$是多边形的面积。 所以$4aS \equiv 0 \pmod q.$现在证明根据残差类别进行划分$p$模数$4$。 

## 方法

 案例$p \equiv 3 \pmod 4$由估值参数处理。 条件$q \mid \lVert e_i \rVert^2$强制每个边缘向量的两个坐标都可以被整除$p^{\lceil t/2 \rceil}$，然后鞋带公式得出$q \mid 2S$。 为了$p \equiv 1 \pmod 4$，多边形的循环性至关重要。 定义向量$B_i = 2a A_i + (b, c).$然后$B_i \cdot e_i \equiv 0 \pmod q$因为$2a A_i \cdot e_i + b u_i + c v_i \equiv 0 \pmod q$，还有$e_i \cdot e_i \equiv 0 \pmod q$。 关键引理如下。 如果$u \in (\mathbb{Z}/q\mathbb{Z})^2$满足$u \cdot u \equiv 0$和$v \cdot u \equiv 0$， 然后$v$是标量倍数$u$模数$q$。 这是通过提升解模来证明的$p$使用亨塞尔引理，因为$-1$是平方模$p$和$q = p^t$。 将此引理应用到$B_i$和$e_i$给出了$B_i \equiv \lambda_i e_i \pmod q$对于一些标量$\lambda_i \in \mathbb{Z}/q\mathbb{Z}$。 综合各方面，$\sum_{i=1}^k B_i \cdot e_i \equiv \sum_{i=1}^k \lambda_i \lVert e_i \rVert^2 \equiv 0 \pmod q$，这意味着$4aS \equiv 0 \pmod q$和以前一样。 因为$q$是奇数并且$p \nmid a$, 整数$4a$是可逆模数$q$， 所以$q \mid 2S$。 

## 解决方案

 修复主电源$q = p^t \mid n$。 我们首先证明$p \nmid a$。 认为$p \mid a$。 约简圆方程模$p$产量$b x + c y + d \equiv 0 \pmod p$因为$a \equiv 0 \pmod p$并且该方程是原始的。 因此所有顶点都位于一条模线上$p$。 对于每一个边向量$e_i = (u_i, v_i)$,$q \mid u_i^2 + v_i^2$意味着$u_i \equiv v_i \equiv 0 \pmod p$如果$p \equiv 3 \pmod 4$， 和$e_i$平行于$(1, \omega)$或者$(1, -\omega)$模数$p$如果$p \equiv 1 \pmod 4$， 在哪里$\omega^2 \equiv -1 \pmod p$。 在这两种情况下，所有顶点的模全等$p$到一个点，与圆方程的原始性相矛盾。 所以$p \nmid a$。 

### 案例 1：$p \equiv 3 \pmod 4$让$e_i = (u_i, v_i)$。 条件$q \mid u_i^2 + v_i^2$力量$v_p(u_i^2 + v_i^2) \ge t$。 因为$-1$是非平方模数$p$，至少其中之一$u_i$,$v_i$必须能整除$p^{\lceil t/2 \rceil}$， 所以$v_p(u_i) \ge \lceil t/2 \rceil$和$v_p(v_i) \ge \lceil t/2 \rceil$。 平移多边形使得$A_1 = (0,0)$，每个顶点都是边向量的和，因此每个顶点的每个坐标都可以整除$p^{\lceil t/2 \rceil}$。 根据鞋带公式，每一项$x_i y_{i+1} - x_{i+1} y_i$可以整除$p^t$，因此$q \mid 2S$。 

### 案例 2：$p \equiv 1 \pmod 4$选择$\omega \in \mathbb{Z}/q\mathbb{Z}$和$\omega^2 \equiv -1 \pmod q$，通过 Hensel 从解模中提升获得$p$。 让$B_i = 2a A_i + (b, c)$， 然后$B_i \cdot e_i \equiv 0 \pmod q$和$e_i \cdot e_i \equiv 0 \pmod q$。 引理断言如果$u \cdot u \equiv 0$和$v \cdot u \equiv 0$模数$q$， 然后$v \equiv \lambda u \pmod q$对于某些人来说$\lambda$。 为了证明这一点，写$u = (u_1, u_2)$和$u_1$可逆模数$p$; 等式$u_1^2 + u_2^2 \equiv 0 \pmod q$意味着$u_2/u_1 \equiv \pm \omega \pmod q$。 那么任意$v$正交于$u$满足$v_1 u_1 + v_2 u_2 \equiv 0$， 因此$v_2/v_1 \equiv -u_1/u_2 \equiv \pm \omega$， 所以$v \equiv \lambda u \pmod q$。 将此引理应用到$B_i$给出$B_i \equiv \lambda_i e_i \pmod q$对于某些人来说$\lambda_i$。 综合各方面，$\sum_{i=1}^k B_i \cdot e_i \equiv \sum_{i=1}^k \lambda_i \lVert e_i \rVert^2 \equiv 0 \pmod q$， 因此$4aS \equiv 0 \pmod q$。 自从$q$是奇数并且$p \nmid a$，我们得出结论$q \mid 2S$。 

### 结合素数幂

 对于每一个原功率$q \mid n$，我们已经证明了$q \mid 2S$。 的素数幂因数$n$是两两互质，所以$n \mid 2S$。 这建立了所需的整除性。
