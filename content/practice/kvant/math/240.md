 ## 问题

 给定一个$x$，值$x^8$可以在三个算术运算中找到：$x^2=x\cdot x$,$x^4=x^2\cdot x^2$,$x^8=x^4\cdot x^4$， 尽管$x^{15}$需要五个操作：前三个相同，后面是$x^8\cdot x^8=x^{16}$和$x^{16}:x=x^{15}$。 表明

 1.$x^{1000}$可以通过 12 次运算（乘法和除法）得到；
 2.对于任何自然$n$，值$x^n$最多可以找到$\dfrac32\log_2 n+1$运营。 

E·G·贝拉加

 ## 探索

 这些例子表明除法应该与重复平方一起使用。 如果$n$接近 2 的幂，计算附近的幂可能更经济$x^{2^k}$然后除以适当选择的幂。 

对于一般问题，令$T(n)$表示计算所需的操作数$x^n$。 目标估计有系数$\frac32$，比普通二值法得到的系数要小很多。 需要不同的递归构造。 

关键思想是将指数减少大约一个因子$2$一步之遥。 如果$n$是偶数，那么$x^n=(x^{n/2})^2$，计算后花费一次操作$x^{n/2}$。 如果$n$是奇数，写任一$$n=2m+1 \qquad\text{or}\qquad n=2m-1.$$计算后$x^m$，平方给出$x^{2m}$，并进一步乘法或除以$x$给出$x^{2m\pm1}$。 因此，可以使用两个附加运算从大约一半的指数获得奇数指数。 

这导致了系数的递归$\frac32$自然地出现。 

## 问题理解

 我们必须展示计算$x^{1000}$最多使用$12$算术运算，然后证明每个指数$n$最多可以使用$$\frac32\log_2 n+1$$运营。 

该问题仅要求上限，而不要求最优算法。 

## 证明架构

 定义$T(n)$作为计算所需的最少操作数$x^n$从$x$。 

第一部分由显式构造处理。 

对于第二部分，我们通过归纳法证明$$T(n)\le \frac32\log_2 n \qquad (n\ge 2).$$归纳法使用关系式$$T(2m)\le T(m)+1,$$和$$T(2m\pm1)\le T(m)+2.$$归纳步骤将指数减小到大约一半。 得出的估计值强于声明中要求的界限。 

## 解决方案

 对于第(1)部分，依次计算$$x^2,\ x^4,\ x^8,\ x^{16},\ x^{32},\ x^{64},\ x^{128},\ x^{256},\ x^{512},\ x^{1024}.$$这需要$10$乘法。 

利用现有的权力，$$x^{24}=x^{16}\cdot x^8,$$这需要再进行一次乘法。 

最后，$$x^{1000}=\frac{x^{1024}}{x^{24}},$$这需要一个部门。 

操作总数为$$10+1+1=12.$$对于第 (2) 部分，令$T(n)$是计算所需的最少操作数$x^n$。 

我们通过归纳法证明$n\ge2$那$$T(n)\le \frac32\log_2 n.$$为了$n=2$,$$T(2)=1=\log_2 2<\frac32\log_2 2,$$所以这个主张成立。 

假设它适用于所有小于的正整数$n$。 

首先假设$n=2m$是均匀的。 计算$x^m$然后将其平方。 因此$$T(n)\le T(m)+1.$$由归纳假设，$$T(n)\le \frac32\log_2 m+1       =\frac32(\log_2 n-1)+1       =\frac32\log_2 n-\frac12       <\frac32\log_2 n.$$现在假设$n$很奇怪。 

如果$n=2m+1$, 计算$x^m$, 平方得到$x^{2m}$，并乘以$x$。 因此$$T(n)\le T(m)+2.$$如果$n=2m-1$, 计算$x^m$, 平方得到$x^{2m}$，并除以$x$。 就这样又$$T(n)\le T(m)+2.$$无论哪种情况，$$m=\frac{n\pm1}{2}.$$自从$m<n$和$m\le\frac{n+1}{2}$，归纳假设给出$$T(n)\le \frac32\log_2 m+2.$$对于奇数$n\ge3$,$$m\le\frac{n+1}{2}\le\frac{2n}{3},$$因为$n\ge3$。 所以$$T(n)    \le \frac32\log_2\!\left(\frac{2n}{3}\right)+2    = \frac32\log_2 n      +\frac32\log_2\!\left(\frac23\right)+2.$$自从$$\log_2\!\left(\frac23\right) = 1-\log_2 3,$$我们得到$$\frac32\log_2\!\left(\frac23\right)+2 = \frac72-\frac32\log_2 3.$$因为$\log_2 3>1.5$,$$\frac72-\frac32\log_2 3<1.25<\frac32.$$因此$$T(n)<\frac32\log_2 n+\frac32.$$通过分离两种奇怪的情况可以获得更清晰的计算。 

如果$n=2m+1$， 然后$m=\frac{n-1}{2}$， 所以$$T(n)\le \frac32\log_2\!\left(\frac{n-1}{2}\right)+2       <\frac32\log_2 n-\frac32+2       =\frac32\log_2 n+\frac12.$$如果$n=2m-1$， 然后$m=\frac{n+1}{2}$。 为了$n\ge7$,$$m=\frac{n+1}{2}\le\frac{4n}{7},$$因此$$T(n)  \le \frac32\log_2\!\left(\frac{4n}{7}\right)+2  = \frac32\log_2 n    +3-\frac32\log_2 7  < \frac32\log_2 n,$$自从$\log_2 7>2$。 

剩余的奇数值$n=3$和$n=5$满足$$T(3)=2<\frac32\log_2 3, \qquad T(5)=3<\frac32\log_2 5.$$因此在所有情况下$$T(n)\le \frac32\log_2 n \qquad (n\ge2).$$自从$$\frac32\log_2 n \le \frac32\log_2 n+1,$$每个自然数指数$n$可以计算不超过$$\frac32\log_2 n+1$$运营。 

这证明了这两个断言。 ∎

 ## 关键步骤验证

 建设为$x^{1000}$准确地使用$12$运营。 

偶数指数的归纳步骤在减少指数后添加了一项操作$n$到$n/2$。 

奇数指数的归纳步骤在将指数减少到任一之后添加两个运算$(n-1)/2$或者$(n+1)/2$。 

归纳估计产生更强的界限$$T(n)\le \frac32\log_2 n \qquad (n\ge2),$$这立即暗示了问题中所述的界限。
