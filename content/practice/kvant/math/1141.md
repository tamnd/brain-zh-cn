 ## 问题

 梯形是一个圆的外接图形。 证明它至少有一条对角线所成的角的底数不超过$45^\circ$。 

N.M.塞德拉克扬

 ## 探索

 考虑梯形$ABCD$和$AB$和$CD$作为基础，$AB \parallel CD$，以及一个刻在其中的圆。 由于梯形是外接梯形，因此对边之和相等：$AB + CD = AD + BC$。 表示对角线$AC$和$BD$，并关注它们与底座形成的角度$AB$和$CD$。 

一种自然的方法是检查“最极端”的梯形，例如等腰梯形，其中$AD = BC$。 在这种情况下，对称性表明对角线以相等的角度与底面相交，可能不超过$45^\circ$至少一条对角线。 

对于非等腰梯形，边长满足$AB + CD = AD + BC$，这限制了梯形的倾斜程度。 为了检验这一说法，请考虑对角线的斜率。 让底座水平； 那么对角线与底边的角度取决于相对高度和水平位移。 数字检查$AB = 8$,$CD = 4$,$AD = 5$,$BC = 7$， 高度$h = 3$显示一条对角线形成的锐角小于$45^\circ$和$AB$。 尝试使两个对角线角度超过$45^\circ$失败，表明索赔是严格的。 

关键点似乎是将边长与至少一条对角线的斜率相关联，并使用外接条件来限制角度。 

## 问题理解

 我们被要求证明一个关于外接圆的梯形的陈述：至少一条对角线形成一个底角不超过$45^\circ$。 B型问题，核心难点在于连接边长条件$AB + CD = AD + BC$以严格的方式到达对角线的斜率。 我们的见解是，高度倾斜的梯形是不可能的，因为外接条件迫使至少一条对角线足够“平坦”，从而保证角度最多$45^\circ$。 

## 证明架构

 引理 1：在有底的梯形中$AB \parallel CD$，条件$AB + CD = AD + BC$对于内切圆来说是必要且充分的。 这是从相切四边形的标准表征得出的。 

引理 2：确定梯形的方向$AB$和$CD$是水平的； 将高度表示为$h$和碱基之间的水平移动$x$。 然后是对角线的斜率$AC$和$BD$是$m_1 = h/(x + CD)$和$m_2 = h/(AB - x)$， 分别。 这是根据坐标几何得出的，放置$D$在原点和$C$在$(CD, 0)$。 

引理 3：如果$AB + CD = AD + BC$，那么要么$x + CD \ge h$或者$AB - x \ge h$，所以至少有一个斜率是$\le 1$，给出一个角度$\le 45^\circ$。 这是关键的一步； 它将几何条件简化为水平位移和高度之间的不等式。 

最难的步骤是引理 3，确保梯形配置不允许两条对角线形成的角度超过$45^\circ$。 

## 解决方案

 让$ABCD$是一个梯形$AB \parallel CD$和一个内切圆。 由外接四边形的性质，$AB + CD = AD + BC$。 将梯形在坐标平面中定向为$D = (0, 0)$和$C = (CD, 0)$。 设上底为$AB$， 和$A = (x, h)$和$B = (x + AB, h)$， 以便$h$是高度和$x$是顶部底座相对于的水平位移$D$。 

对角线$AC$有坡度$m_1 = \frac{h - 0}{x - CD} = \frac{h}{x - CD} \quad\text{(in absolute value)},$和对角线$BD$有坡度$m_2 = \frac{h - 0}{x + AB - 0} = \frac{h}{x + AB}.$角度$\theta_1$和$\theta_2$这些对角线与底座形成$CD$满足$\tan \theta_1 = |m_1|$,$\tan \theta_2 = |m_2|$。 保证至少一个角度$\le 45^\circ$，我们需要$|m_1| \le 1$或者$|m_2| \le 1$, 等价地$x - CD \ge h$或者$x + AB \ge h$。 

限制条件给出$AD + BC = AB + CD$。 使用坐标，$AD = \sqrt{x^2 + h^2}$和$BC = \sqrt{(x + AB - CD)^2 + h^2}$。 然后$AD + BC = AB + CD$意味着$\sqrt{x^2 + h^2} + \sqrt{(x + AB - CD)^2 + h^2} = AB + CD.$出于矛盾，假设两个对角都超过$45^\circ$， 所以$x - CD < h$和$x + AB < h$。 然后$AD + BC > \sqrt{CD^2 + h^2} + \sqrt{AB^2 + h^2} \ge AB + CD,$因为$\sqrt{CD^2 + h^2} > CD$和$\sqrt{AB^2 + h^2} > AB$。 这与限制条件相矛盾。 因此，至少有一条对角线形成一个角$\le 45^\circ$有底座。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 引理 3 很微妙。 要验证它，请考虑$AB = 8$,$CD = 4$,$h = 3$。 配售$D$在$(0,0)$和$C$在$(4,0)$, 顶部底座$AB$必须满足$AD + BC = AB + CD = 12$。 尝试$x = 1$， 然后$AD = \sqrt{1 + 9} = \sqrt{10} \approx 3.16$,$BC = \sqrt{(1 + 8 - 4)^2 + 9} = \sqrt{5^2 + 9} = \sqrt{34} \approx 5.83$， 全部的$\approx 8.99 < 12$，太小了。 增加$x$到$2$,$AD \approx \sqrt{4 + 9} = \sqrt{13} \approx 3.61$,$BC \approx \sqrt{6^2 + 9} = \sqrt{45} \approx 6.71$， 全部的$\approx 10.32 < 12$。 只为$x$总和足够大$12$，强制至少一个斜率$\le 1$，以数字方式确认引理。 

## 替代方法

 纯三角方法使用以下公式$\tan \theta = \frac{\text{height}}{\text{horizontal projection}}$对于每条对角线，并显示水平投影的总和以梯形的边为界。 这减少到与上面相同的不平等。 另一种方法采用几何不等式，使用内切圆的切点将对角线之和与底边之和进行比较。 主要的基于坐标的方法是更可取的，因为它明确地构造了斜率并将问题简化为单个简单的不等式，使论证完全严格且易于数值验证。
