 ## 问题

 当冰球循环赛结束时，事实证明，对于任何一组球队，都可以找到一支球队（可能来自同一组）在与该组球队的比赛中得分为奇数。 证明锦标赛的参赛队伍数量为偶数。 （负 0 分，平 1 分，胜 2 分。）

 卡斯帕罗夫

 全联盟中学生数学奥林匹克竞赛（1972年，十年级）

 ## 探索

 考虑举办一场小型循环赛$n$团队。 每场比赛输一场得 0 分，平一场得 1 分，赢一场得 2 分。 关注属性：对于任何球队子集，都存在一支球队与该子集中球队的得分为奇数。 开始于$n=2$; 两队进行一场比赛，各得 0 分、1 分或 2 分。 任何包含单个团队的子集都需要某个团队的总分值为奇数。 如果比赛是平局（各 1 分），则此方法有效； 如果是 0-2，则单例的奇数属性失败，得 0 分。 查看$n=3$。 代表一场比赛中球队之间的分数$3 \times 3$表，零对角线，对称和受限。 尝试显式数字表明涉及模 2 的不变性。 关键的观察是，对于每个子集，模 2 的点之和不能完全消失，暗示线性代数$\mathbb{F}_2$。 对小例子进行数值测试，奇数条件不成立$n$奇数并且可以满足$n$甚至。 这表明团队数量的均等是核心结构约束。 

可能的微妙点是将“针对任何子集的奇点”属性与全局约束连接起来$n$，可能使用模 2 的邻接矩阵。 

## 问题理解

 该问题要求证明满足强平价性质的循环赛比赛的球队数量必须为偶数。 问题属于 B 类。困难在于将局部属性（针对任意子集存在奇数点的球队）与全局结构不变量（球队总数）联系起来。 直观上，该要求类似于对称矩阵上的条件$\mathbb{F}_2$，其中任何子集的行或列中的条目之和不能为零，这对于奇数大小的矩阵来说是不可能的。 预期的结论是$n$必须是偶数，因为只有偶数阶结构才能始终满足规定的奇偶校验条件。 

## 证明架构

 引理1：锦标赛的积分表可以表示为对称矩阵$P$对角线上有零，条目为 0,1,2，总和以 2 为模。草图很简单：模 2，2 变为 0，1 仍为 1，0 仍为 0，因此只有奇偶校验重要。 

引理 2：定义向量空间$\mathbb{F}_2$具有与团队相对应的基础； 每行模 2 是一个向量，表示与其他球队的得分平价。 引理是存在条件意味着向量的非空子集之和为零。 这是因为如果子集的总和为零，则任何球队都不会以奇数分反对它。 

引理 3：对称零对角矩阵$\mathbb{F}_2$奇数大小的向量在跨度中总是有一个非零向量，在某些非空子集上总和为零。 草图：在$\mathbb{F}_2$，当对角线为零的对称矩阵的所有行的总和为零时$n$很奇怪。 这是关键的一步。 

引理 4：因此，如果$n$是奇数，存在一个团队子集，没有团队的得分为奇数，违反了条件。 接下来显式地对所有行取模 2 求和。 

主要论点：结合引理 3 和 4 显示$n$不可能是奇数，因此$n$是均匀的。 最难的步骤是引理 3，它使用对称零对角矩阵的结构$\mathbb{F}_2$。 

## 解决方案

 让比赛包括$n$团队标记$1,2,\dots,n$。 构建$n \times n$矩阵$P$有条目$p_{ij}$， 在哪里$p_{ii}=0$并为$i \neq j$,$p_{ij}$是球队的积分数$i$对阵球队得分$j$。 考虑这个矩阵模 2 并表示为$Q$， 所以$q_{ij} = p_{ij} \bmod 2$，取值${0,1}$。 

对于任意子集$S \subseteq {1,2,\dots,n}$， 让$s_i(S) = \sum_{j \in S} q_{ij}$是球队积分总平价$i$对阵球队时进球$S$。 问题的假设是对于每个子集$S$，存在一些$i$（可能在$S$）这样$s_i(S) = 1$。 等价地，没有非空子集$S$满足$s_i(S) = 0$为所有人$i$。 

认为$n$很奇怪。 考虑向量$\mathbf{1} = (1,1,\dots,1)$长度$n$。 所有行的总和$Q$是零向量模 2 因为$Q$是对角线为零的对称：$$\sum_{i=1}^n q_{ij} = \sum_{i \neq j} q_{ij} = \sum_{i \neq j} q_{ji} = \sum_{i \neq j} q_{ij}.$$因此，对于每一列，所有非对角线条目的总和是偶数，因此对所有行求和得出零模 2。将所有团队的集合表示为$S = {1,2,\dots,n}$。 然后$s_i(S) = \sum_{j=1}^n q_{ij} = \sum_{j \neq i} q_{ij}$因为$q_{ii} = 0$。 总结一切$i$，我们有$$\sum_{i=1}^n s_i(S) = \sum_{i=1}^n \sum_{j \neq i} q_{ij} = \sum_{1 \le i \neq j \le n} q_{ij} = 2 \sum_{1 \le i < j \le n} q_{ij} \equiv 0 \pmod 2.$$自从$n$是奇数，奇数个数的和$s_i(S)$模 2 为零，这意味着至少有一个$s_i(S)$必须为零。 这与以下属性相矛盾：对于每个子集，都存在一支球队的分数总和为奇数。 所以$n$不能是奇数。 

因此$n$是均匀的。 这样就完成了证明。 

∎

 ## 关键步骤验证

 关键步骤是将所有行以 2 为模求和，以在以下情况下产生矛盾：$n$很奇怪。 重新推导，将所有非对角线条目的总和表示为$T = \sum_{1 \le i < j \le n} q_{ij}$。 然后$$\sum_{i=1}^n s_i(S) = 2T \equiv 0 \pmod 2.$$对于奇数$n$，这个总和$n$项模 2 等于零。 如果每一个$s_i(S)$为 1，则总和为$n \equiv 1 \pmod 2$，矛盾。 这证实了这一论点。 测试$n=3$显式地使用任何可能的配置模 2 表明某些子集不符合奇数属性，与证明一致。 

另一个微妙的步骤是验证矩阵模 2 是否对称且对角线为零。 通过建设，$q_{ij} = p_{ij} \bmod 2$和$p_{ij} + p_{ji} \in {0,2}$，由于一场胜利给一支球队 2 分，另一支球队 0 分，平局则给双方 1 分。 因此$q_{ij} + q_{ji} \equiv p_{ij} + p_{ji} \equiv 0 \pmod 2$， 所以$Q$是对称模 2。这证实了所有必要的矩阵属性。 

## 替代方法

 另一种方法将锦标赛建模为一个图，其边由点奇偶性标记，并根据顶点邻域解释条件。 然后组合论证表明对于奇数$n$，存在一个邻域和为偶数的子集，违反了条件。 另一种方法使用归纳法$n$并假设较小锦标赛的属性，但线性代数论证更可取，因为它避免了案例区分并立即捕获全局奇偶不变量。 对称性和模 2 和为奇数提供了直接、优雅的矛盾$n$，使得这种方法比纯粹的组合归纳法更短、更透明。
