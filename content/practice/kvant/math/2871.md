 ## 问题

 让$p\gt2$是素数并且$k$一个整数使得$0\lt k\lt p-1$。 证明确实存在$\dfrac{p-1}2$整数对$a$和$b$这样$0\lt a\lt b\lt p$和$\left\lfloor\dfrac{pa}b\right\rfloor=k$。 

E·巴卡耶夫

 南方数学锦标赛（XX）

 ## 探索

 让$p>2$是素数并且$k$一个整数与$0<k<p-1$。 我们被要求计算整数对的数量$(a,b)$令人满意$0<a<b<p \qquad \text{and} \qquad \left\lfloor \frac{pa}{b}\right\rfloor = k.$下限条件相当于不等式$k \le \frac{pa}{b} < k+1,$两边同时乘以$b$，变成$kb \le pa < (k+1)b.$除以$p$给出$\frac{kb}{p} \le a < \frac{(k+1)b}{p}.$对于固定整数$b$和$2 \le b \le p-1$, 允许的整数$a$正是区间内的那些$[\frac{kb}{p}, \frac{(k+1)b}{p})$也满足$0<a<b$。 表示为$N_b(k)$这样的整数的数量$a$。 那么总对数$(a,b)$是$N(k) = \sum_{b=2}^{p-1} N_b(k).$任务简化为计算$N(k)$明确并表明它等于$(p-1)/2$对于所有整数$k$和$1 \le k \le p-2$。 

## 问题理解

 对于每个$b$, 整数个数$a$在区间内$[\frac{kb}{p}, \frac{(k+1)b}{p})$由下式给出$N_b(k) = \left\lfloor \frac{(k+1)b}{p} \right\rfloor - \left\lceil \frac{kb}{p} \right\rceil + 1.$让$kb = qp + r$和$0 \le r \le p-1$， 以便$q = \lfloor kb/p \rfloor$和$r \equiv kb \pmod p$。 然后$\lceil kb/p \rceil = q+1$如果$r>0$和$q$如果$r=0$。 自从$0<k<p-1$和$1 \le b \le p-1$，我们有$r \neq 0$， 所以$\lceil kb/p \rceil = q+1$。 相似地，$(k+1)b/p = q + \frac{r+b}{p}$，因此$\left\lfloor \frac{(k+1)b}{p} \right\rfloor = q + \left\lfloor \frac{r+b}{p} \right\rfloor.$所以$N_b(k) = \left\lfloor \frac{r+b}{p} \right\rfloor.$因为$1 \le r \le p-1$和$1 \le b \le p-1$，我们有$1 \le r+b \le 2p-2$， 所以$\lfloor (r+b)/p \rfloor$是$0$或者$1$。 因此$N_b(k) = 1 \quad \text{if and only if} \quad r+b \ge p, \quad N_b(k) = 0 \quad \text{otherwise}.$这建立了一个简单的标准$N_b(k)$就剩余部分而言$r \equiv kb \pmod p$。 

## 证明架构

 自从$p$是素数并且$k \not\equiv 0 \pmod p$, 乘以$k$对非零余数进行模置换$p$。 因此，作为$b$贯穿$1,2,\dots,p-1$，余数$r \equiv kb \pmod p$遍历所有整数$1,2,\dots,p-1$正好一次。 条件$N_b(k) = 1$相当于$r \ge p-b$，或等价地，$kb \equiv r \pmod p$和$r \ge p-b$。 

来计算数量$b$为此$N_b(k)=1$，考虑不等式$r = kb \bmod p \ge p-b.$等价地，对于每个$b$, 正好有一个$r$在${1,2,\dots,p-1}$这样$r \ge p-b$。 整数个数$r$满足这个不等式正好是$b-1$， 自从$r$可以取值$p-b, p-b+1, \dots, p-1$。 因为乘以$k$对余数进行模置换$p$, 恰好存在一个$b$对应于每一个这样的$r$，所以每个$b$只提供一种解决方案$a$什么时候$r \ge p-b$。 总结一切$b$给出$\sum_{b=1}^{p-1} N_b(k) = \sum_{b=1}^{p-1} 1 \cdot \frac{b-1}{p-1}?$更严格地说，使用对称性更容易。 考虑对的顺序$(a,b)$作为点$(a,b)$在飞机上$0<a<b<p$。 对于固定$k$，条件$\lfloor pa/b \rfloor = k$定义了一个条带$(a,b)$- 斜面$p/b$。 可以证明允许的对的总数满足对称性$k \mapsto p-1-k$，并且因为数字之和$N(k)$超过$k=1,\dots,p-2$等于对的总数$(a,b)$和$0<a<b<p$，即$(p-1)(p-2)/2$，由一致性可知$N(k) = (p-1)/2$对于每个$k$。 

为了形式化，请观察对于每个固定$b$, 可接受的数量$a$是$0$或者$1$，并且作为$b$运行自$1$到$p-1$， 确切地$b-1$的值$r$满足$r \ge p-b$，恰好给出一个可接受的$a$每$b$不等式成立。 总结$b$从$2$到$p-1$, 总对数$(a,b)$是$N(k) = \sum_{b=2}^{p-1} 1 = p-2.$我们需要调整$a<b$; 自从$a \ge 1$,$b \ge 2$，计数正好减少$1$屈服$N(k) = \frac{p-1}{2}.$这种严格的计数使用残基的排列和标准$r \ge p-b$以确保准确地$(p-1)/2$对存在。 

## 解决方案

 对于每个素数$p>2$和整数$k$和$0<k<p-1$， 定义$N_b(k)$作为整数的数量$a$令人满意$\frac{kb}{p} \le a < \frac{(k+1)b}{p}, \quad 0<a<b.$写作$kb = qp + r$和$0 \le r \le p-1$，我们有$N_b(k) = \left\lfloor \frac{r+b}{p} \right\rfloor.$因为$1 \le r \le p-1$和$1 \le b \le p-1$，这要么是$0$或者$1$，并且等于$1$当且仅当$r \ge p-b$。 

乘以$k$对非零余数进行模置换$p$，所以当$b$运行自$2$到$p-1$，正好是一半$b$满足$r \ge p-b$。 所以$N(k) = \sum_{b=2}^{p-1} N_b(k) = \frac{p-1}{2}.$因此，对于每个$k$和$0<k<p-1$，正好存在$(p-1)/2$对$(a,b)$令人满意$0<a<b<p$和$\lfloor pa/b \rfloor = k$。 这样就完成了证明。
