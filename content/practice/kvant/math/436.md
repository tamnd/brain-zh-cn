 ## 问题

 给定 20 个数字$a_1$,$a_2$,$\ldots$,$a_{10}$,$b_1$,$b_2$,$\ldots$,$b_{10}$。 证明 100 个数字的集合（不一定不同）$a_1+b_1$,$a_1+b_2$,$\ldots$,$a_{10}+b_{10}$可以分为10个子集，每个子​​集包含10个数字，使得每个子集中的数字之和相同。 

S.T.贝尔科莱科

 ## 探索

 我们被要求将两组十个数字的所有成对和划分为十组，每组十个，每个组的总数相同。 自然的第一个实验是尝试非常小的集合，看看是否出现任何简单的模式。 认为$a_1, \dots, a_{10}$都是平等的并且$b_1, \dots, b_{10}$也都是平等的。 Then every sum is the same, and any grouping trivially works. 如果$a_i$和$b_j$各有特色，可以尝试一下$a_i = i$和$b_j = j$; 那么$100$总和是$i+j$为了$1 \le i,j \le 10$。 将它们排列在一个$10 \times 10$行索引为的表$a_i$和列$b_j$，总和$i$-第 行是$\sum_{j=1}^{10} (i+j)$，随着增加$i$，以及总和$j$第-列是$\sum_{i=1}^{10} (i+j)$，随着增加$j$。 然而，如果我们对对角线取模$10$，总和似乎稳定下来。 这表明组合设计，例如从每个元素中取出一个元素$a_i$和每个$b_j$以循环模式，可以产生相等的总和。 

关键的困难是找到一个分区，其中每个子集恰好包含来自每个“行”和每个“列”的一个元素$10 \times 10$总和数组。 这类似于构造一个拉丁方并沿对角线求和。 

## 问题理解

 该问题要求证明分区的存在性$100$太阳队$a_i + b_j$进入$10$的子集$10$每个数字都具有相同的总和。 这是一个 D 类问题，一个存在性陈述。 核心困难在于确保每个子集的总和相同，而不管子集的具体值是多少$a_i$和$b_j$。 直觉是将总和排列在$10 \times 10$表并沿对角线取模选择元素$10$平衡每个人的贡献$a_i$和每个$b_j$跨所有子集。 

## 证明架构

 引理 1：令总和$a_i + b_j$被安排在一个$10 \times 10$带行的矩阵$i$和列$j$。 每行总和等于$10 a_i + \sum_{j=1}^{10} b_j$，每列总和等于$10 b_j + \sum_{i=1}^{10} a_i$。 接下来是对每行和每列中的总和进行因式分解。 

引理 2：定义子集$S_k = { a_i + b_{(i+k-1 \bmod 10)+1} : i = 1, \dots, 10 }$为了$k=0,\dots,9$。 每个子集只包含每一行和每一列中的一个元素。 这成立是因为地图$i \mapsto (i+k-1 \bmod 10)+1$是一个双射${1,\dots,10}$对于每个$k$。 

引理 3：每个子集中元素的总和$S_k$独立于$k$。 这成立是因为每个子集包含每个$a_i$正好一次且每次$b_j$恰好一次，所以总和是$\sum_{i=1}^{10} a_i + \sum_{j=1}^{10} b_j$。 

最困难的步骤是验证子集是否不相交并覆盖所有子集$100$求和而不重复。 

## 解决方案

 安排$100$数字$a_i + b_j$在一个$10 \times 10$矩阵$M$哪里的$(i,j)$第 - 个条目是$a_i + b_j$。 构造$10$子集$S_0, S_1, \dots, S_9$如下：对于每个$k = 0, 1, \dots, 9$， 让$$S_k = \{ a_i + b_{(i+k-1 \bmod 10)+1} : i = 1, \dots, 10 \}.$$每个子集$S_k$只包含每一行和每一列中的一个元素，因为该函数$i \mapsto (i+k-1 \bmod 10)+1$排列${1,2,\dots,10}$。 因此，子集是不相交的，并且一起包含所有$100$数字。 

中元素的总和$S_k$是$$\sum_{i=1}^{10} \left(a_i + b_{(i+k-1 \bmod 10)+1}\right) = \sum_{i=1}^{10} a_i + \sum_{i=1}^{10} b_i,$$因为每个$b_j$在总和中只出现一次。 该总和独立于$k$。 因此$100$数字可以分为$10$的子集$10$每个数字，都具有相同的总和。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 第一步是确认映射$i \mapsto (i+k-1 \bmod 10)+1$确实是每个的双射$k$。 如果两个不同的$i_1$和$i_2$映射到同一列，我们会有$(i_1+k-1 \bmod 10) = (i_2+k-1 \bmod 10)$，这意味着$i_1 \equiv i_2 \pmod{10}$，矛盾$1 \le i_1, i_2 \le 10$。 第二步是确保每个$b_j$在每个子集和中只出现一次。 由于地图是一个排列${1,\dots,10}$，每个列索引只出现一次。 没有元素被计算两次，并且所有元素在某个子集中只出现一次。 

## 替代方法

 人们可以通过考虑完整的二分图，使用图论术语来解决这个问题$K_{10,10}$边缘加权为$a_i + b_j$。 然后任务将边缘划分为$10$完美匹配，总重量相同。 这种观点概括为任意的$n \times n$矩阵。 主要方法是更可取的，因为它使用简单的算术显式构造所需的子集，避免抽象并直接证明相等的和。
