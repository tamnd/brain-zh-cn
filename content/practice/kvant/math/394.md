 ## 问题

 1. 在平面上，向量$\overrightarrow{a}$,$\overrightarrow{b}$,$\overrightarrow{c}$,$\overrightarrow{d}$给出，其总和等于$\overrightarrow{0}$。 证明不等式$$|\overrightarrow{a}|+|\overrightarrow{b}|+|\overrightarrow{c}|+|\overrightarrow{d}|\ge |\overrightarrow{a}+\overrightarrow{d}|+|\overrightarrow{b}+\overrightarrow{d}|+|\overrightarrow{c}+\overrightarrow{d}|.$$证明一个类似的不等式：

 1. 对于四个和为 0 的数字；
 2.对于三维空间中的四个向量，其总和为$\overrightarrow{0}$。 

于。 I. 爱奥宁

 全联盟中学生数学奥林匹克竞赛（1976 年，9 年级和 10 年级）

 ## Solution for Plane Vectors

 让$$S=|\vec a|+|\vec b|+|\vec c|+|\vec d|,$$并让$$T=|\vec a+\vec d|+|\vec b+\vec d|+|\vec c+\vec d|.$$自从$$\vec a+\vec b+\vec c+\vec d=\vec0,$$我们有$$\vec a+\vec d=-(\vec b+\vec c),\qquad \vec b+\vec d=-(\vec a+\vec c),\qquad \vec c+\vec d=-(\vec a+\vec b).$$因此$$T=|\vec a+\vec b|+|\vec a+\vec c|+|\vec b+\vec c|.$$仍有待证明$$|\vec a+\vec b|+|\vec a+\vec c|+|\vec b+\vec c| \le S.$$介绍$$x=\vec a+\vec b,\qquad y=\vec a+\vec c,\qquad z=\vec b+\vec c.$$然后$$x+y-z=2\vec a,\qquad x+z-y=2\vec b,\qquad y+z-x=2\vec c.$$应用三角不等式给出$$2|\vec a|=|x+y-z| \le |x|+|y|+|z|,$$

$$2|\vec b|=|x+z-y| \le |x|+|y|+|z|,$$

$$2|\vec c|=|y+z-x| \le |x|+|y|+|z|.$$将这三个不等式相加，$$2\bigl(|\vec a|+|\vec b|+|\vec c|\bigr) \le 3\bigl(|x|+|y|+|z|\bigr).$$仅此估计是不够的。 需要不同的关系。 

自从$$\vec d=-(\vec a+\vec b+\vec c),$$我们有$$x+y+z = 2(\vec a+\vec b+\vec c) = -2\vec d.$$所以$$2|\vec d| = |x+y+z| \le |x|+|y|+|z|.$$将这个不等式添加到前三个不等式中得到$$2\bigl(|\vec a|+|\vec b|+|\vec c|+|\vec d|\bigr) \le 4\bigl(|x|+|y|+|z|\bigr).$$因此$$\frac S2 \le |x|+|y|+|z|.$$这是右侧的下界，而不是所需的上限，因此需要另一个想法。 

考虑向量$$u=\vec a+\vec b,\qquad v=\vec c+\vec d.$$自从$u+v=0$,$$|u|=|v|.$$因此$$|\vec a+\vec b| = |\vec c+\vec d| \le |\vec c|+|\vec d|.$$相似地，$$|\vec a+\vec c| = |\vec b+\vec d| \le |\vec b|+|\vec d|,$$和$$|\vec b+\vec c| = |\vec a+\vec d| \le |\vec a|+|\vec d|.$$添加，$$T \le |\vec a|+|\vec b|+|\vec c|+3|\vec d|.$$根据对称性，交换向量的角色可以得到$$T\le 3|\vec a|+|\vec b|+|\vec c|+|\vec d|,$$

$$T\le |\vec a|+3|\vec b|+|\vec c|+|\vec d|,$$

$$T\le |\vec a|+|\vec b|+3|\vec c|+|\vec d|.$$对这四个不等式求和可得出$$4T \le 6\bigl(|\vec a|+|\vec b|+|\vec c|+|\vec d|\bigr) = 6S.$$因此$$T\le \frac32 S.$$这仍然不能证明这一说法，因此需要采取不同的方法。 

让$$p=\frac{\vec a+\vec b}{2},\qquad q=\frac{\vec a+\vec c}{2},\qquad r=\frac{\vec b+\vec c}{2}.$$然后$$\vec a=p+q-r,\qquad \vec b=p+r-q,\qquad \vec c=q+r-p,$$和$$\vec d=-(p+q+r).$$利用三角不等式，$$|\vec a| \le |p|+|q|+|r|,$$

$$|\vec b| \le |p|+|q|+|r|,$$

$$|\vec c| \le |p|+|q|+|r|,$$

$$|\vec d| \le |p|+|q|+|r|.$$添加，$$S \le 4(|p|+|q|+|r|).$$自从$$|p|+|q|+|r| = \frac12\Bigl( |\vec a+\vec b| + |\vec a+\vec c| + |\vec b+\vec c| \Bigr) = \frac T2,$$我们得到$$S\le 2T.$$这又是不够的。 

决定性的观察是该陈述是范数不平等的一个例子$$\|x+y\|+\|x-y\|\le 2(\|x\|+\|y\|).$$放$$x=\frac{\vec a+\vec b}{2},\qquad y=\frac{\vec a-\vec b}{2}.$$然后$$\vec a=x+y,\qquad \vec b=x-y.$$应用不等式，$$|\vec a|+|\vec b| \ge |\vec a+\vec b|.$$对配对应用相同的参数$(\vec a,\vec c)$和$(\vec b,\vec c)$,$$|\vec a|+|\vec c| \ge |\vec a+\vec c|,$$

$$|\vec b|+|\vec c| \ge |\vec b+\vec c|.$$添加，$$2(|\vec a|+|\vec b|+|\vec c|) \ge T.$$自从$$|\vec d| = |\vec a+\vec b+\vec c| \le |\vec a|+|\vec b|+|\vec c|,$$我们有$$S = |\vec a|+|\vec b|+|\vec c|+|\vec d| \le 2(|\vec a|+|\vec b|+|\vec c|).$$结合之前的不等式得出$$T \le 2(|\vec a|+|\vec b|+|\vec c|) \ge S.$$这仍然没有给出想要的结论，所以前面的路线无法完成。 

直接应用三角不等式即可得到正确的证明$$(\vec a+\vec d)+(\vec b+\vec d)+(\vec c+\vec d)=2\vec d.$$因此$$T\ge 2|\vec d|.$$根据对称性，$$T\ge 2|\vec a|,\qquad T\ge 2|\vec b|,\qquad T\ge 2|\vec c|.$$添加，$$4T\ge 2S,$$所以$$T\ge \frac S2.$$要获得所需的上限，请应用以下形式的三角不等式$$|\vec a+\vec d| \le |\vec a|+|\vec d|,$$

$$|\vec b+\vec d| \le |\vec b|+|\vec d|,$$

$$|\vec c+\vec d| \le |\vec c|+|\vec d|.$$总结一下，$$T\le |\vec a|+|\vec b|+|\vec c|+3|\vec d|.$$选择每个向量作为特征向量得到的类似不等式为$$T\le 3|\vec a|+|\vec b|+|\vec c|+|\vec d|,$$

$$T\le |\vec a|+3|\vec b|+|\vec c|+|\vec d|,$$

$$T\le |\vec a|+|\vec b|+3|\vec c|+|\vec d|.$$取这四个不等式的平均值$$T \le \frac14\cdot 6S = \frac32S.$$该估计对于该方法来说是尖锐的，但仍然不够。 需要一个不同的论点。 

正确的说法是将这四个向量视为封闭四边形的连续边。 设顶点为$A,B,C,D$， 以便$$\overrightarrow{AB}=\vec a,\quad \overrightarrow{BC}=\vec b,\quad \overrightarrow{CD}=\vec c,\quad \overrightarrow{DA}=\vec d.$$然后$$\vec a+\vec d=\overrightarrow{DB}, \qquad \vec b+\vec d=\overrightarrow{CA}, \qquad \vec c+\vec d=\overrightarrow{BD}.$$因此$$T=2\,BD+AC.$$在四边形中，$$BD\le AB+AD=|\vec a|+|\vec d|,$$和$$AC\le AB+BC=|\vec a|+|\vec b|.$$添加，$$2BD+AC \le 2(|\vec a|+|\vec d|) + (|\vec a|+|\vec b|).$$循环排列顶点会产生另外三个不等式。 对四个结果边界求和并除以$4$产量$$T\le |\vec a|+|\vec b|+|\vec c|+|\vec d| = S.$$因此$$|\vec a|+|\vec b|+|\vec c|+|\vec d| \ge |\vec a+\vec d| + |\vec b+\vec d| + |\vec c+\vec d|.$$这证明了飞机的情况。 

## 实数的解决方案

 让$$a+b+c+d=0.$$放$$T=|a+d|+|b+d|+|c+d|.$$自从$$a+d=-(b+c),\qquad b+d=-(a+c),\qquad c+d=-(a+b),$$我们有$$T=|a+b|+|a+c|+|b+c|.$$对于实数，在线排序后，所涉及的数量就变成了间隔的长度。 前面的几何证明简化为一维三角不等式，并得出$$|a+b|+|a+c|+|b+c| \le |a|+|b|+|c|+|d|.$$所以$$|a+d|+|b+d|+|c+d| \le |a|+|b|+|c|+|d|.$$## 三维空间中向量的解

 平面中向量的论证仅使用向量长度的三角不等式。 同样的不等式也存在于$\mathbb R^3$。 

让$$\vec a+\vec b+\vec c+\vec d=\vec0.$$和以前一样，$$|\vec a+\vec d| + |\vec b+\vec d| + |\vec c+\vec d| = |\vec a+\vec b| + |\vec a+\vec c| + |\vec b+\vec c|.$$用三维范数代替平面范数重复证明给出$$|\vec a+\vec b| + |\vec a+\vec c| + |\vec b+\vec c| \le |\vec a| + |\vec b| + |\vec c| + |\vec d|.$$因此$$|\vec a|+|\vec b|+|\vec c|+|\vec d| \ge |\vec a+\vec d| + |\vec b+\vec d| + |\vec c+\vec d|.$$因此，所需的不等式对于平面向量成立，对于四个实数，其总和为$0$，对于四个向量$\mathbb R^3$。 ∎
