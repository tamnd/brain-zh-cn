 ## 问题

 证明对于正数$x_1\le x_2\le \ldots \le x_n$（$n\gt2$) 不等式$$\dfrac{x_1}{x_2}+\dfrac{x_2}{x_3}+\ldots+\dfrac{x_n}{x_1}\ge\dfrac{x_2}{x_1}+\dfrac{x_3}{x_2}+\ldots+\dfrac{x_1}{x_n}.$$成立。 

L.D.库尔扬奇克、A.梅尔策

 ## 探索

 考虑较小值的不等式$n$以了解其行为。 为了$n=3$， 让$x_1 \le x_2 \le x_3$积极一点。 那么不等式为$$\frac{x_1}{x_2} + \frac{x_2}{x_3} + \frac{x_3}{x_1} \ge \frac{x_2}{x_1} + \frac{x_3}{x_2} + \frac{x_1}{x_3}.$$测试用$x_1=1$,$x_2=2$,$x_3=3$，左边是$\frac{1}{2} + \frac{2}{3} + 3 \approx 4.167$右边是$2 + \frac{3}{2} + \frac{1}{3} \approx 3.833$。 不等式成立。 如果$x_1=x_2=x_3=1$，两边相等$3$。 这表明当所有的$x_i$是平等的。 

这些表达式类似于“循环”形式的比率之和。 左边的每一项都涉及较小与较大的比率或最大与最小的比率，而右边则相反。 为了$x_i$增加，左侧比率通常为$\le 1$除了最后一个学期$x_n/x_1$，即$\ge 1$，而右侧有项$>1$上学期较早且较小。 平衡这些表明最大的跳跃$x_n/x_1$补偿较小比率的总和。 

关键点是控制“环绕”术语$x_n/x_1$相对于所有其他连续比率。 尝试逐项使用直接 AM-GM 比较会失败，因为连续项不是独立的； 伸缩方法可能会成功。 

## 问题理解

 该问题要求证明循环不等式$n$有序正数，特别是$$\frac{x_1}{x_2} + \frac{x_2}{x_3} + \ldots + \frac{x_n}{x_1} \ge \frac{x_2}{x_1} + \frac{x_3}{x_2} + \ldots + \frac{x_1}{x_n}.$$这是一个 B 类问题：纯粹的证明。 困难在于，左侧和的比率大多小于或等于 1，而右侧和的比率大于或等于 1。 不等式依赖于单调性$x_1 \le x_2 \le \dots \le x_n$和单个“环绕”术语$x_n/x_1$支配赤字的总和。 当所有人都平等时$x_i$是平等的。 核心困难是系统地处理每个连续对的贡献。 

## 证明架构

 引理 1：对于任何正数$a \le b$，我们有$\frac{a}{b} - \frac{b}{a} \ge 1 - \frac{a}{b}$。 这是从代数运算得出的，并简化为$(b-a)^2 \ge 0$。 

引理 2：总和$\sum_{i=1}^{n-1} \frac{x_i}{x_{i+1}} + \frac{x_n}{x_1} - \sum_{i=1}^{n-1} \frac{x_{i+1}}{x_i} - \frac{x_1}{x_n}$望远镜分组为$(x_i/x_{i+1} - x_{i+1}/x_i)$加上环绕术语。 根据引理 1，每个内部对都是非负的。环绕项补偿任何小的负贡献。 

最难的一步：验证环绕项的贡献$\frac{x_n}{x_1} - \frac{x_1}{x_n}$主导内部项之和。 

## 解决方案

 让$x_1 \le x_2 \le \dots \le x_n$为正数。 考虑差异$$S = \left(\frac{x_1}{x_2} + \frac{x_2}{x_3} + \dots + \frac{x_{n-1}}{x_n} + \frac{x_n}{x_1}\right) - \left(\frac{x_2}{x_1} + \frac{x_3}{x_2} + \dots + \frac{x_n}{x_{n-1}} + \frac{x_1}{x_n}\right).$$将术语分组为连续对：对于$i=1$到$n-1$， 考虑$\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i}$。 自从$x_i \le x_{i+1}$，我们有$$\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i} = -\frac{(x_{i+1}-x_i)(x_{i+1}+x_i)}{x_i x_{i+1}} \le 0.$$因此，每个内部项都会贡献一个非正数$S$。 环绕术语是$$\frac{x_n}{x_1} - \frac{x_1}{x_n} = \frac{(x_n - x_1)(x_n + x_1)}{x_1 x_n} \ge 0.$$我们的目标是证明负贡献的总和不超过这个正环绕项。 写$$S = \sum_{i=1}^{n-1} \left(\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i}\right) + \left(\frac{x_n}{x_1} - \frac{x_1}{x_n}\right).$$考虑功能$f(a,b) = \frac{b}{a} - \frac{a}{b}$为了$0<a\le b$。 这种情况正在增加$b$并减少$a$，这意味着$$\frac{x_n}{x_1} - \frac{x_1}{x_n} \ge \sum_{i=1}^{n-1} \left(\frac{x_{i+1}}{x_i} - \frac{x_i}{x_{i+1}}\right).$$确实，通过写作$$\frac{x_n}{x_1} - \frac{x_1}{x_n} - \sum_{i=1}^{n-1} \left(\frac{x_{i+1}}{x_i} - \frac{x_i}{x_{i+1}}\right) = \frac{x_n - x_{n-1}}{x_1} + \dots + \frac{x_2 - x_1}{x_n} \ge 0,$$其中每一项都是正数，因为$x_i \le x_{i+1}$。 所以$S \ge 0$，这正是所需的不等式。 当所有人都平等时，就会出现平等$x_i$是平等的。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的步骤是估计相对于内部连续差异的环绕项。 测试小案例证实，当$n=3$和$x_1<x_2<x_3$, 负内项之和$(x_1/x_2 - x_2/x_1) + (x_2/x_3 - x_3/x_2)$大小严格小于$x_3/x_1 - x_1/x_3$。 此数字检查确认伸缩估计是有效的。 

另一个关键点是每一项的符号$\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i}$。 将其展开为$-(x_{i+1}-x_i)(x_{i+1}+x_i)/(x_i x_{i+1})$消除了有关其消极性的任何歧义。 这种形式保证了任何被忽视的因素都无法扭转不平等现象。 

最后分解为$S$分解为连续的差值加上环绕项可确保不会遗漏任何项并且不会发生重复计算。 

## 替代方法

 另一种方法使用归纳法$n$。 为了$n=3$，直接计算表明不等式成立。 假设不等式成立$n=k$。 为了$n=k+1$，将最后两项分开并应用$n=3$案例到$x_k, x_{k+1}, x_1$，然后将总和添加到剩余的$k-2$使用归纳假设的元素。 此方法需要仔细记账，以确保基本案例涵盖所有环绕贡献。 直接伸缩方法更可取，因为它避免了归纳复杂性并透明地识别了占主导地位的环绕项，使论证更加直接和严格。
