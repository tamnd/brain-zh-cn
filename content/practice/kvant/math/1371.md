 ## 问题

 在以圆心为中心的圆上$O$, 点$A$和$B$位于。 观点$P$位于较小的弧上$AB$, 点$Q$和$R$与点对称$P$相对于线条$OA$和$OB$分别是，和$P'$是线段的交点$AR$和$BQ$。 证明几点$P$和$P'$相对于线对称$AB$。 

V.V.普罗兹沃洛夫、B.库库什金

 1992 年共和数学奥林匹克竞赛

 ## 探索

 放置点$A$和$B$在一个圆上并选取一个点$P$在较小的弧上$AB$。 构造$Q$对称于$P$相对于线$OB$和$R$对称于$P$相对于线$OA$。 绘制线段$AR$和$BQ$并标记它们的交点$P'$。 尝试一些具体的位置$P$表明$P'$似乎是反映$P$过线$AB$。 与单位圆坐标实验$A=(1,0)$,$B=(-1,0)$， 和$O=(0,0)$建议坐标为$P'$满足$x_{P'} = x_P$和$y_{P'} = -y_P$如果$AB$是$x$-轴，表示对称性$AB$。 关键的一步似乎是表达$Q$和$R$以一种方便的形式并表明$AR$和$BQ$位于的反射线上$P$超过$AB$。 穿过线的对称性$O$暗示旋转或反射方法。 

## 问题理解

 我们被要求证明一个圆的几何对称性，并通过其中心的直线进行反射。 积分$Q$和$R$被定义为反射$P$过线$OB$和$OA$， 和$P'$是 的交集$AR$和$BQ$。 问题类型是 B 类，“证明 [陈述]”。 The core difficulty is showing that the intersection of these two segments, constructed via reflections over lines through$O$，正是$P$在和弦之上$AB$。 基本的见解是反射和交叉尊重线性对称性和中心性$O$允许使用线对称参数而不是混乱的坐标。 

## 证明架构

 引理 1：点在通过圆心的直线上的反射等价于保留圆的线性变换。 这是正确的，因为穿过中心的线定义了直径，并且穿过它的反射是沿着直径的中心对称。 

引理 2：线$AR$和$BQ$相交于一点$P'$谁的反思$AB$与$P$。 这是因为反思$OA$和$OB$保持线之间的角度$O$，以及从反射点到直线的交点$A$和$B$与反射对齐$P$穿过$AB$。 

最难的步骤是引理 2，其中必须仔细应用坐标或向量几何，以确认交集确实产生了所需的对称性，无一例外。 

## 解决方案

 将圆放置在坐标平面中$O$在原点。 让$A=(1,0)$和$B=(-1,0)$以便$AB$位于$x$-轴。 认为$P$有坐标$P=(\cos \theta, \sin \theta)$和$0<\theta<\pi$确保它位于较小的弧上$AB$。 的反映$P$过线$OA$（这$x$-轴通过$A$) 通过在线反射得到$x=1$。 垂直线上的反射公式$x=a$给出$R = (2a - x_P, y_P) = (2 - \cos \theta, \sin \theta)$。 同样，反射$P$过线$OB$（线$x=-1$）给出$Q = (-2 - \cos \theta, \sin \theta)$。 

线路$AR$经过$A=(1,0)$和$R=(2-\cos \theta, \sin \theta)$。 其斜率是$m_{AR} = \frac{\sin \theta - 0}{(2 - \cos \theta) - 1} = \frac{\sin \theta}{1 - \cos \theta +1} = \frac{\sin \theta}{1 - \cos \theta + 1}.$仔细计算一下：$(2-\cos \theta) - 1 = 1 - \cos \theta$。 所以$m_{AR} = \frac{\sin \theta}{1 - \cos \theta}$。 直线方程为$y = \frac{\sin \theta}{1 - \cos \theta} (x - 1)$。 

线路$BQ$经过$B=(-1,0)$和$Q=(-2 - \cos \theta, \sin \theta)$。 其斜率是$m_{BQ} = \frac{\sin \theta - 0}{(-2 - \cos \theta) - (-1)} = \frac{\sin \theta}{-1 - \cos \theta} = -\frac{\sin \theta}{1 + \cos \theta}$。 其方程为$y = -\frac{\sin \theta}{1 + \cos \theta} (x + 1)$。 

十字路口$P'=(x',y')$满足$\frac{\sin \theta}{1 - \cos \theta} (x' - 1) = -\frac{\sin \theta}{1 + \cos \theta} (x' + 1).$两边除以$\sin \theta \neq 0$:$\frac{x' - 1}{1 - \cos \theta} = -\frac{x' + 1}{1 + \cos \theta}.$叉乘：$(x' - 1)(1 + \cos \theta) = -(x' + 1)(1 - \cos \theta).$扩张：$x' (1 + \cos \theta) - (1 + \cos \theta) = -x'(1 - \cos \theta) - (1 - \cos \theta).$全部带上$x'$一侧为项，另一侧为常数：$x'(1 + \cos \theta + 1 - \cos \theta) = (1 + \cos \theta - 1 + \cos \theta) = 2\cos \theta.$所以$2 x' = 2 \cos \theta \implies x' = \cos \theta = x_P$。 

现在$y' = \frac{\sin \theta}{1 - \cos \theta} (x' - 1) = \frac{\sin \theta}{1 - \cos \theta} (\cos \theta - 1) = -\sin \theta = -y_P$。 

因此$P' = (x_P, -y_P)$，这正是$P$横跨$x$-轴，与线重合$AB$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是求解交集方程$x'$。 不小心扩展可能会错过登录$-(x' + 1)(1 - \cos \theta)$，导致错误的$x'$价值。 从头开始重新计算证实$x'(1 + \cos \theta + 1 - \cos \theta) = 2 x'$和解决方案$x' = \cos \theta$。 斜率计算为$AR$和$BQ$通过显式替换坐标并检查分子和分母差异来验证。 最后，$y'$计算被独立地重新计算以确保$y' = -y_P$。 

## 替代方法

 纯合成方法利用了这样一个事实：穿过中心的线的反射保留了以下角度：$O$并将圆映射到其自身上。 通过构造四边形$ARPB$和$BQPA$，人们可以认为交集$P'$必须依赖于反射$P$超过$AB$使用循环特性和角度追踪。 使用坐标的主要方法是更可取的，因为它避免了角度追踪中的细微错误并保证了明确的验证$x'$和$y'$毫无歧义。
