 ## 问题

 证明对于任意正数序列$a_n$，数字平方根的整数部分$$b_n=(a_1+a_2+\ldots+a_n)\left(\dfrac{1}{a_1}+\dfrac{1}{a_2}+\ldots+\dfrac{1}{a_n}\right)$$都是不同的。 

L·D·库里兰奇克

 ## 探索

 考虑正数序列$a_1, a_2, \dots$。 定义$b_n = (a_1 + \dots + a_n)\left(\frac{1}{a_1} + \dots + \frac{1}{a_n}\right).$计算小案例以了解其行为。 为了$n=1$,$b_1 = a_1 \cdot \frac{1}{a_1} = 1$。 为了$n=2$， 如果$a_1 = 1$,$a_2 = 1$， 然后$b_2 = (1+1)(1 + 1) = 4$。 如果$a_1 = 1$,$a_2 = 2$， 然后$b_2 = (1+2)(1 + 1/2) = 3 \cdot 1.5 = 4.5$, 整数部分$4$。 为了$n=3$， 选择$a_1 = a_2 = a_3 = 1$， 然后$b_3 = 3 \cdot 3 = 9$。 选择$a_1 = 1$,$a_2 = 2$,$a_3 = 3$，我们有$b_3 = 6 \cdot (1 + 1/2 + 1/3) = 6 \cdot \frac{11}{6} = 11$, 整数部分$11$。 

整数部分变大并且显得不同。 数量$b_n$类似于离散柯西-施瓦茨不等式：$(a_1 + \dots + a_n)(1/a_1 + \dots + 1/a_n) \ge n^2$, 只有当所有$a_i$是平等的。 这表明$b_n$增长并且无法返回到之前的整数。 

主要困难是证明不存在两个数$b_m$和$b_n$共享相同的整数部分$m \neq n$，无论选择正值$a_i$。 

## 问题理解

 该问题要求证明对于任何正数序列$a_n$, 整数部分$\lfloor \sqrt{b_n} \rfloor$序列的$b_n = (a_1 + \dots + a_n)\left(\frac{1}{a_1} + \dots + \frac{1}{a_n}\right)$都是不同的。 这是 B 类问题：我们被要求在不进行分类或优化的情况下证明一个命题。 

核心困难在于证明该序列相对于其前一个序列增长得足够快，使得平方根的整数部分增加，并且没有整数重复。 关键的见解是不平等$b_{n+1} > b_n$，但我们还必须证明一个更强的不等式，以保证整数部分永远不会重合。 柯西-施瓦茨不等式提供了下界$b_n \ge n^2$，这可能有助于分离整数部分。 

## 证明架构

 引理 1：对于任何正数序列$a_1, \dots, a_n$,$b_n \ge n^2,$平等当且仅当所有$a_i$是平等的。 这是根据柯西-施瓦茨不等式应用于$(\sqrt{a_1}, \dots, \sqrt{a_n})$和$(1/\sqrt{a_1}, \dots, 1/\sqrt{a_n})$。 

引理 2：对于任意正数$a_{n+1}$,$b_{n+1} > b_n.$这是从考虑增量得出的$(a_1 + \dots + a_n + a_{n+1})(1/a_1 + \dots + 1/a_n + 1/a_{n+1}) - (a_1 + \dots + a_n)(1/a_1 + \dots + 1/a_n)$并利用积极性$a_{n+1}$和凸状结构。 

引理 3：如果$b_{n+1} > b_n$， 然后$\lfloor \sqrt{b_{n+1}} \rfloor \ge \lfloor \sqrt{b_n} \rfloor$。 从底函数的单调性来看，这是微不足道的。 

引理 4（关键引理）：增量$b_{n+1} - b_n < 2\sqrt{b_n} + 1$是不可能的。 同样，平方根的整数部分不能保持不变，因为连续方格之间的距离至少为$2\lfloor \sqrt{b_n} \rfloor + 1$，这确保了不同的整数部分。 这需要仔细分析$b_n$。 

最难的步骤是引理 4，因为它涉及证明增长足以防止任意正序列的重复整数部分。 

## 解决方案

 我们首先建立引理 1。作者：Cauchy–Schwarz，$(a_1 + \dots + a_n)\left(\frac{1}{a_1} + \dots + \frac{1}{a_n}\right) \ge \left(\sqrt{a_1 \cdot \frac{1}{a_1}} + \dots + \sqrt{a_n \cdot \frac{1}{a_n}}\right)^2 = n^2,$只有当$\sqrt{a_i} / (1/\sqrt{a_i})$对所有人来说都是恒定的$i$， IE。，$a_1 = \dots = a_n$。 所以$b_n \ge n^2$。 

为了证明引理 2，写$$b_{n+1} - b_n = (a_1 + \dots + a_n + a_{n+1})\left(\sum_{i=1}^{n} \frac{1}{a_i} + \frac{1}{a_{n+1}}\right) - (a_1 + \dots + a_n)\sum_{i=1}^{n} \frac{1}{a_i}.$$展开，我们得到$$b_{n+1} - b_n = a_{n+1}\sum_{i=1}^{n} \frac{1}{a_i} + (a_1 + \dots + a_n)\frac{1}{a_{n+1}} + a_{n+1}\frac{1}{a_{n+1}} = a_{n+1}\sum_{i=1}^{n} \frac{1}{a_i} + \frac{a_1 + \dots + a_n}{a_{n+1}} + 1.$$自从$a_i > 0$，每一项都是正数，因此$b_{n+1} - b_n > 0$，证明引理 2。 

引理 3 由下取函数的单调性以及以下事实得出：$b_{n+1} > b_n$意味着$\sqrt{b_{n+1}} > \sqrt{b_n}$， 因此$\lfloor \sqrt{b_{n+1}} \rfloor \ge \lfloor \sqrt{b_n} \rfloor$。 

为了证明引理 4，通过反证假设$\lfloor \sqrt{b_{n+1}} \rfloor = \lfloor \sqrt{b_n} \rfloor = k$对于某个整数$k$。 然后$k^2 \le b_n < (k+1)^2$和$k^2 \le b_{n+1} < (k+1)^2$，这意味着$b_{n+1} - b_n < (k+1)^2 - k^2 = 2k + 1$。 

不过从之前的拓展来看，$$b_{n+1} - b_n = a_{n+1}\sum_{i=1}^{n} \frac{1}{a_i} + \frac{a_1 + \dots + a_n}{a_{n+1}} + 1 \ge 2 \sqrt{(a_1 + \dots + a_n)\sum_{i=1}^{n} \frac{1}{a_i}} + 1 = 2 \sqrt{b_n} + 1,$$通过应用于两个正数的算术几何平均不等式$a_{n+1}\sum_{i=1}^{n} 1/a_i$和$(a_1 + \dots + a_n)/a_{n+1}$。 自从$b_n \ge n^2 \ge 1$，由此可知$2\sqrt{b_n} + 1 > 2k + 1$，矛盾。 因此整数部分必须增加。 

结果，整数部分$\lfloor \sqrt{b_n} \rfloor$严格增加$n$并因此是不同的。 

这样就完成了证明。 

∎
