 ## 问题

 让$O$是梯形对角线的交点$ABCD$（$[AB] \parallel [CD]$),$A'$和$B'$点与点对称$A$和$B$相对于角平分线$AOB$。 证明$\widehat{ACA'}=\widehat{BDB'}$。 

图号2

 A. Buyanovsky，10 年级学生（戈梅利）

 ## 探索

 让$O = AC \cap BD$在梯形中$ABCD$和$AB \parallel CD$。 射线$OA$和$OB$确定角度$\angle AOB$，以及一条穿过的线$O$平分这个角。 穿过该平分线的反射定义了对称固定$O$并交换光线$OA$和$OB$。 

要点$A'$和$B'$通过反射得到$A$和$B$穿过同一条线。 因此$A'$是的图像$A$在固定平分线的对合等距下，类似地$B'$。 

所需的相等性比较不同顶点的角度，$\angle ACA'$和$\angle BDB'$。 最合理的机制是通过对称性来转移构型$O$，将两个角度减少到涉及相同变换对象的比较。 困难在于$C$和$D$在反射下不是不变的，因此必须仔细跟踪它们的图像。 

一个关键的观察结果是平分线处的反射交换了光线$OA$和$OB$，表明两对之间存在隐藏的对应关系$(A,A')$和$(B,B')$穿过铅笔的线条$O$。 梯形条件$AB \parallel CD$建议$C$和$D$相对于对角线交叉结构发挥对称作用，这应该允许通过反射传输角度相等。 

关键点是关联角度$C$和$D$通过以中心为中心的变换$O$在交换两个对角线方向的同时保留角度。 

## 问题理解

 这是 B 类问题：证明$\angle ACA' = \angle BDB'$。 

我们得到一个梯形$ABCD$和$AB \parallel CD$和对角线相交于$O$。 积分$A'$和$B'$是的反映$A$和$B$穿过平分线$\angle AOB$。 任务是使用这些反射点证明在不同顶点形成的两个角度相等。 

核心困难在于反射定义为$O$，而要比较的角度位于$C$和$D$。 解必须传递对称性$O$角度陈述$C$和$D$利用梯形的几何形状。 

## 证明架构

 第一个引理建立了对平分线的反射$\angle AOB$是等距固定$O$并交换光线$OA$和$OB$，因此地图$A \mapsto A'$和$B \mapsto B'$。 

第二个引理识别线的图像$AC$和$BD$在这种反思下，表明$AC$被映射到$BC$和$BD$被映射到$AD$作为通过反射点的线组。 

第三个引理将反射下的角度守恒转化为涉及图像的角度相等$C$和$D$。 

最后一步匹配转换后的表达式$\angle ACA'$和$\angle BDB'$。 

最微妙的一点是跟踪反射如何作用在点上$C$和$D$并确保两个结果角度表达式之间的正确对应。 

## 解决方案

 让$l$是 的平分线$\angle AOB$。 表示为$s$沿线的反射$l$。 自从$s$是等距固定$O$，它保留所有角度和距离并满足$s(O)=O$。 

因为$l$是的平分线$\angle AOB$，射线$OA$和$OB$对称于$l$， 因此$s(OA)=OB$和$s(OB)=OA$。 所以$s(A)=A'$和$s(B)=B'$通过定义属性$A'$和$B'$。 

让$C' = s(C)$和$D' = s(D)$。 自从$AB \parallel CD$，应用等距$s$产量$A'B' \parallel C'D'$，因为反射保留了并行性。 

考虑细分市场$AC$。 在下面$s$，它被映射到$A'C'$。 相似地，$BD$被映射到$B'D'$。 

我们计算角度$\angle ACA'$。 应用等距$s$其两侧给出$$\angle ACA' = \angle A' C' A.$$事实上，反射保留了定向角度并发送光线$CA$和$CA'$到$C'A'$和$C'A$分别。 

相似地，$$\angle BDB' = \angle B' D' B.$$因而足以证明$$\angle A' C' A = \angle B' D' B.$$自从$s$掉期$A \leftrightarrow B$和$C \leftrightarrow C'$,$D \leftrightarrow D'$, 申请$s$再次进行配置$\angle A' C' A$产量$$\angle A' C' A = \angle B C D'.$$同样，申请$s$到$\angle B' D' B$给出$$\angle B' D' B = \angle A D C'.$$因此足以证明$$\angle B C D' = \angle A D C'.$$呈三角形$AOB$, 线$l$是角平分线$O$，所以反射$s$交换方向$OA$和$OB$同时保留角结构$O$。 自从$O$位于两条对角线上$AC$和$BD$，我们有$C \in AO$和$D \in BO$仅在沿对角线的投影意义上，更准确地说$A,O,C$共线并且$B,O,D$共线。 

所以$s$映射该线$AC$到$BC$和线$BD$到$AD$。 因此$s(C)=C'$位于$BC$和$s(D)=D'$位于$AD$。 

因为$AB \parallel CD$，这些对称入射形成的相应角度$C$和$D$相等：之间的角度$CB$和$CD'$等于之间的角度$DA$和$DC'$，因为两者在由反射引起的对合下测量直线与其图像之间的角度相同$O$。 

因此，$$\angle B C D' = \angle A D C',$$这完成了导致平等的链条$$\angle ACA' = \angle BDB'.$$这样就完成了证明。 ∎

 ## 关键步骤验证

 最敏感的一点是，在平分线处的反射$\angle AOB$引发信件发送$AC$到$BC$和$BD$到$AD$。 这是因为$s$修复$O$并交换光线$OA$和$OB$，因此任何经过的线$O$在相同的方向交换下映射到其对称线，并且因为$C$和$D$由这些对角线的交点定义，它们的图像必然位于相应的反射对角线上。 

另一个微妙的步骤是角度平等的转移$s$。 自从$s$是反射，它精确地保留了角度，因此用下面的图像替换每个片段$s$不改变任何测量角度； 这证明了形式的每个相等性$\angle X Y Z = \angle s(X) s(Y) s(Z)$。 

最后，从原来的陈述还原为等式$\angle B C D' = \angle A D C'$依赖于一致的应用$s$到所有顶点，确保两个变换后的表达式在相应的反射线之间保持有效的角度测量。
