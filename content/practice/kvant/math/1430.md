 ## 问题

 单调递增的整数序列$\{a_n\}$具有以下性质：对于任意一对互质数$p$和$q$，平等$a_{pq}=a_p a_q$持有； 此外，据悉$a_1=1$,$a_2=2$。 

1.证明$a_3=3$。 
2.证明$a_n=n$对于任意自然数$n$。 

（如果两个数字没有公约数，则称为互质。）

 V·A·森德罗夫

 ## 探索

 顺序${a_n}$是单调且整数值的。 乘法性质$a_{pq} = a_p a_q$对于共素$p$和$q$暗示与标准身份的联系$n \mapsto n$，因为自然数满足相同的乘法性质。 测试小数字，$a_1=1$和$a_2=2$给出$a_2 = 2$,$a_4 = a_2^2 = 4$,$a_6 = a_2 a_3$，这立即表明知道$a_3$至关重要。 如果$a_3$大于3，$a_6$会超过 6，与单调性相矛盾； 如果$a_3 < 3$， 然后$a_3 = 2$，但随后$a_6 = a_2 a_3 = 4$，小于 6，再次与单调性相冲突，因为$a_5$必须介于$a_4 = 4$和$a_6 = 4$，这是不可能的。 这表明$a_3=3$。 扩展到更大的数字，人们可以尝试归纳使用素因数分解和乘法性质。 主要的挑战是严格证明除了$a_n = n$与单调性和乘性性质兼容。 

## 问题理解

 该问题要求确定确切的顺序${a_n}$满足两个约束：互质指数的单调性和乘性，其中$a_1=1$和$a_2=2$。 这是一个 A 类问题，因为它要求对满足给定条件的所有序列（在本例中为单个序列）进行分类。 核心困难在于证明乘法性质与单调性相结合迫使序列与上的恒等函数一致$\mathbb{N}$。 直观上，素数的任何偏差都会通过乘法性质传播到合数，这会违反单调性。 

## 证明架构

 引理 1：$a_3=3$。 接下来测试整数可能性$a_3$并检查$a_6 = a_2 a_3$关于单调性约束。 

引理 2：$a_p = p$对于所有素数$p$。 使用引理 1 和单调性，可以证明如果有任何素数$p$被分配的值不同于$p$，在序列中出现矛盾的倍数$p$。 

引理 3：$a_n = n$对于所有自然数$n$。 使用素因数分解$n = \prod p_i^{\alpha_i}$和乘法，可表示为$a_n$作为$\prod a_{p_i}^{\alpha_i}$。 应用引理 2，计算结果为$n$。 

最难的步骤是引理 2，因为它需要仔细处理所有素数及其倍数，以确保单调性不允许出现偏差。 

## 解决方案

 我们首先确定$a_3$。 由于序列是递增的，$a_3 > a_2 = 2$。 认为$a_3 \ge 4$。 然后$a_6 = a_2 a_3 \ge 2 \cdot 4 = 8$， 但$a_6 \le 6$由于单调性（因为$a_4 = a_2^2 = 4$和$a_5 \ge a_4 = 4$,$a_6 \le a_5$不能超过6），产生矛盾。 如果$a_3 = 2$， 然后$a_3 = a_2$，违反了严格的单调性。 所以$a_3=3$。 

接下来，我们证明$a_p = p$对于所有素数$p$。 让$p$是任何大于 3 的素数。假设矛盾的是$a_p \ne p$。 自从$a_p$是一个大于的整数$a_{p-1} \ge p-1$，只有两种可能：$a_p \ge p+1$或者$a_p \le p-1$。 如果$a_p \ge p+1$， 考虑$a_{2p} = a_2 a_p = 2 a_p \ge 2(p+1) = 2p+2$，但单调性要求$a_{2p} \le 2p$，矛盾。 如果$a_p \le p-1$， 然后$a_{3p} = a_3 a_p = 3 a_p \le 3(p-1) = 3p-3$，但单调性要求$a_{3p} \ge 3p$，又矛盾了。 所以$a_p = p$对于所有素数$p$。 

最后，对于任意自然数$n$，写出它的素因数分解$n = \prod_{i=1}^k p_i^{\alpha_i}$。 通过重复应用互质因子的乘法性质，我们得到$a_n = \prod_{i=1}^k a_{p_i}^{\alpha_i} = \prod_{i=1}^k p_i^{\alpha_i} = n.$这证实了$a_n = n$对于每个自然数$n$。$\boxed{a_n = n \text{ for all } n \in \mathbb{N}}$## 关键步骤验证

 决定的关键一步$a_3$涉及检查两种可能性$a_3=2$和$a_3 \ge 4$并观察其后果$a_6 = a_2 a_3$。 重新计算$a_6$和$a_3=2$给出$a_6 = 2 \cdot 2 = 4$，这意味着$a_5 \le 4$，自相矛盾的单调性$a_4 = 4$, 确认$a_3$不可能 2. 测试$a_3 \ge 4$产量$a_6 \ge 8$，相对的矛盾单调性$a_4=4$和$a_5 \ge a_4$, 确认$a_3=3$是唯一的可能。 

对于主要步骤，请考虑$p=5$。 如果$a_5=6$， 然后$a_{10} = a_2 a_5 = 12$， 但$10 < 12$，矛盾的单调性。 如果$a_5=4$， 然后$a_{15} = a_3 a_5 = 12$， 但$a_{15} \ge 15$，又矛盾了。 类似的推理适用于所有较大的素数，从而验证了引理。 

## 替代方法

 另一种方法是使用完全归纳法$n$。 认为$a_k = k$为所有人$k < n$。 如果$n$是素数，考虑$a_n = a_n a_1 = a_n$，以及来自相邻项力的单调性约束$a_n = n$。 如果$n$是复合的，写成$n = pq$与共质$p,q < n$，乘法给出$a_n = a_p a_q = pq = n$。 这种归纳方法更加机械，但不太透明，因为主要步骤仍然需要仔细的单调性分析。 主要方法阐明了素数在强化身份方面的关键作用$a_n=n$直接地。
