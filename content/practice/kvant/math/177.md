 ## 问题

 找到方程的所有解$$\sqrt[\scriptstyle n~]{x^n-a^n}+\sqrt[\scriptstyle n~]{2a^n-x^n}=a,$$， 在哪里$a$是给定的实数，并且$n$是大于一的自然数。 

T·特米罗夫

 ## 探索

 考虑方程$$\sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n} = a,$$和$a \in \mathbb{R}$和$n > 1$一个自然数。 该结构表明周围对称$x = a$， 自从$x^n - a^n$和$2a^n - x^n$总和为$a^n$。 从小测试开始$n$来检测模式。 为了$n = 2$，方程变为$\sqrt{x^2 - a^2} + \sqrt{2a^2 - x^2} = a$，只有在以下情况下才有意义$x^2 - a^2 \ge 0$和$2a^2 - x^2 \ge 0$，意味着$x \in [a, a\sqrt{2}]$。 计算$\sqrt{x^2 - a^2} + \sqrt{2a^2 - x^2}$作为一个函数$x$超过这个间隔。 在$x = a$，总和等于$\sqrt{0} + \sqrt{a^2} = a$。 在$x = a\sqrt{2}$，总和等于$\sqrt{a^2} + \sqrt{0} = a$。 导数表明单调性； 因此，该方程可能恰好有两个解$n = 2$。 为了$n > 2$， 测试$x = a$。 然后$\sqrt[n]{a^n - a^n} + \sqrt[n]{2a^n - a^n} = 0 + \sqrt[n]{a^n} = a$，满足方程。 边界$x = 2^{1/n} a$给出$\sqrt[n]{(2^{1/n}a)^n - a^n} + \sqrt[n]{2a^n - (2^{1/n}a)^n} = \sqrt[n]{(2 - 1)a^n} + \sqrt[n]{2a^n - 2a^n} = a + 0 = a$，这是有效的。 负解可以通过替换来测试$x = -a$; 然后$\sqrt[n]{(-a)^n - a^n} + \sqrt[n]{2a^n - (-a)^n} = \sqrt[n]{(-1)^n a^n - a^n} + \sqrt[n]{2a^n - (-1)^n a^n}$。 对于甚至$n$，第一项是$\sqrt[n]{a^n - a^n} = 0$，第二个是$\sqrt[n]{2a^n - a^n} = a$，产生一个解决方案$x = -a$。 对于奇数$n$，第一项是$\sqrt[n]{-a^n - a^n} = \sqrt[n]{-2 a^n} = -2^{1/n} a$，第二项$\sqrt[n]{2a^n - (-a)^n} = \sqrt[n]{2a^n + a^n} = 3^{1/n} a$，所以总和是$(-2^{1/n} + 3^{1/n}) a$，这可能等于$a$仅当$2^{1/n} + 1 = 3^{1/n}$，这是错误的。 因此，负解仅存在于偶数$n$。 该初步分析表明了潜在的解决方案$x = a$,$x = 2^{1/n}a$，并且可能$x = -a$什么时候$n$是均匀的。 

关键是要证明没有其他$x$可以满足方程。 因为函数$f(x) = \sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n}$正在增加$[a, 2^{1/n}a]$并且对称，这些候选点之外的任何其他解决方案都必须违反单调性或域限制。 主要的微妙之处是这样的$n$奇数与偶数并确保不存在解$(−\infty, a)$或者$(2^{1/n} a, \infty)$。 

## 问题理解

 该问题要求确定所有实数$x$满足总和$n$带参数的三次根方程$a \in \mathbb{R}$和$n \in \mathbb{N}$,$n > 1$。 这是一个 A 类问题，因为它需要确定完整的解决方案集并证明不存在其他解决方案。 核心难点是分析两个数之和$n$-th 根，仅在有限的区间内定义，并确保不会由于非线性或奇偶性而出现意外的解$n$。 初步探索表明解决方案是$x = a$,$x = 2^{1/n} a$， 和$x = -a$如果$n$是偶数，基于域限制和对称性。 

## 证明架构

 引理 1 指出$x^n - a^n \ge 0$和$2a^n - x^n \ge 0$是真实必要的$n$-th 根存在，意味着$x \in [a, 2^{1/n} a]$为了$a \ge 0$; 相似地，$x \in [2^{1/n} a, a]$如果$a \le 0$。 引理 2 断言该函数$f(x) = \sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n}$严格递增于$[a, 2^{1/n} a]$为了$n$甚至和$n$奇怪，除了可能在$x = a$或者$x = 2^{1/n}a$，保证在这个区间内最多有两个解。 引理 3 检查候选点$x = a$,$x = 2^{1/n} a$， 和$x = -a$（如果$n$是偶数）并且表明每个都满足方程。 最难的方向是证明不存在其他解决方案，特别是对于$n$奇怪的是，导数分析需要小心。 最有可能在审查下失败的引理是引理 2，特别是确保一般区间内的严格单调性$n$。
