 ## 问题

 三点$K$,$L$,$N$均在飞机上给出。 已知四边形是凸四边形，并且其三边的中点位于给定点$K$,$L$,$N$。 找出可以被以下元素占据的点集：

 1.第四边的中点；
 2. 该四边形的一个顶点。 

A.P.萨文

 ## 探索

 考虑具有顶点的凸四边形$A$,$B$,$C$,$D$按顺序，并让$K$,$L$,$N$为其三边的中点。 不失一般性，假设这些中点对应于$AB$,$BC$， 和$CD$。 表示它们的中点$K = \frac{A+B}{2}$,$L = \frac{B+C}{2}$,$N = \frac{C+D}{2}$用向量表示法。 第四个中点$M$的$DA$未知，但四边形条件强制要求这些点$A$,$B$,$C$,$D$形成一个凸多边形。 使用中点公式，$M = \frac{D+A}{2}$。 将四个中点向量相加得出$K + L + N + M = \frac{A+B + B+C + C+D + D+A}{2} = A + B + C + D$， 所以$M = A + B + C + D - (K + L + N)$。 因此$M$是由$A$和$D$，但这些本身受到中点的限制。 对于任意点$K$,$L$,$N$，向量关系表示$M$位于由下式确定的平行四边形中$K$,$L$,$N$。 为了检查这一点，可以画一些小的数值例子：$K$,$L$,$N$不在线和计算$M$使用中点加法公式可知$M$可以占据由给定点的平移界定的凸区域。 对于一个顶点，表示$A = 2K - B$,$B = 2L - C$,$C = 2N - D$，产生一个线性系统$A$,$B$,$C$,$D$。 解决它给出每个顶点作为线性组合$K$,$L$,$N$，具有与沿平面平移相关的自由度。 凸性限制了哪些解是可接受的。 关键是从中点约束中识别几何轨迹，这可以简化为第四个中点的平行四边形条件和顶点的菱形区域。 

## 问题理解

 该问题要求确定给定凸四边形连续边的三个中点，确定第四个中点和任何顶点的所有可能位置。 这是一个 A 类问题，因为我们需要对满足几何约束的所有可能点进行分类。 核心困难在于将中点信息转换为未知中点或顶点的显式条件，同时强制凸性。 直观上，第四条边的中点必须位于由给定的三个中点确定的某个平行四边形内。 每个顶点可以表示为三个中点的线性组合，产生可接受位置的有界区域。 该解决方案将为第四个中点和任何顶点提供精确的几何轨迹。 

## 证明架构

 引理 1 指出，在任何四边形中，连续边中点的向量之和等于顶点之和； 这是从中点公式得出的。 引理 2 声称第四个中点$M$唯一确定的是$K$,$L$,$N$直到沿着连接两个相对顶点的向量平移； 这是真的，因为$M = A + B + C + D - (K + L + N)$。 引理 3 确定了可能的集合$M$形成一个平行四边形，其顶点通过平移获得$K$,$L$,$N$通过按顺序连接它们的向量。 引理 4 断言每个顶点都是以下的线性组合$K$,$L$,$N$，通过求解中点方程导出，给出凸四边形轨迹。 最难的方向是确保所有允许点的凸性； 最有可能失败的引理是引理 4，因为简单的线性解可能会产生非凸四边形。 

## 解决方案

 标记四边形$ABCD$按顺序并假设$K$,$L$,$N$是的中点$AB$,$BC$,$CD$。 表示$M$的中点$DA$。 在向量表示法中，中点满足$K = \frac{A+B}{2}$,$L = \frac{B+C}{2}$,$N = \frac{C+D}{2}$,$M = \frac{D+A}{2}$。 将这四个方程相加得出$$K + L + N + M = \frac{(A+B) + (B+C) + (C+D) + (D+A)}{2} = A + B + C + D.$$解决$M$给出$$M = A + B + C + D - (K + L + N).$$代替$B = 2K - A$,$C = 2L - B = 2L - (2K - A) = 2L - 2K + A$,$D = 2N - C = 2N - (2L - 2K + A) = 2N - 2L + 2K - A$。 然后$$M = \frac{D + A}{2} = \frac{(2N - 2L + 2K - A) + A}{2} = N - L + K.$$这证明对于任何有中点的凸四边形$K$,$L$,$N$三个连续边中，第四边的中点由向量公式唯一给出$$\boxed{M = K - L + N}.$$对于一个顶点，求解$A$使用$B = 2K - A$,$C = 2L - B$,$D = 2N - C$。 依次代入得到$$B = 2K - A, \quad C = 2L - (2K - A) = 2L - 2K + A, \quad D = 2N - C = 2N - 2L + 2K - A.$$因此每个顶点都表示为以下的线性组合$K$,$L$,$N$有系数$\pm 1, 0$。 具体来说，$$A = a_1 K + a_2 L + a_3 N, \quad B = 2K - A, \quad C = 2L - B, \quad D = 2N - C,$$和$a_1 + a_2 + a_3 = 1$,$a_i$真实的。 凸性在相对位置上施加了不平等：向量$B - A$,$C - B$,$D - C$,$A - D$必须形成一个正向循环。 这确定了每个顶点的平行四边形区域，通过沿对角线平移线性组合获得$K$,$L$,$N$。 因此点集恰好是$$\text{Midpoint of fourth side: } \boxed{M = K - L + N},$$和$$\text{Vertex of quadrilateral: } \boxed{\text{All points } X \text{ expressible as } X = A, B, C, \text{ or } D \text{ given above satisfying convexity}}.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 推导$M = K - L + N$通过代入具体点进行验证。 例如，让$K = (0,0)$,$L = (1,0)$,$N = (1,1)$。 然后$M = K - L + N = (0,0) - (1,0) + (1,1) = (0,1)$。 建设中$A = (-1,0)$,$B = (1,0)$,$C = (1,1)$,$D = (-1,1)$证实$M$确实是中点$DA$。 对于顶点，求解系统顺序为任何给定的凸四边形生成四个点，并且可以使用连续边的叉积来检查凸性。 重复几个数值配置可以确认向量表达式尊重方向，并且如果中点处于一般位置，则不会出现简并或非凸四边形。 

## 替代方法

 人们可以使用 Varignon 平行四边形定理（该定理指出连接四边形的中点形成平行四边形）来推导$M$作为这个平行四边形的第四个顶点$K$,$L$,$N$。 这产生相同的公式$M = K - L + N$几乎立即。 另一种方法采用复数表示平面上的点，并进行加法和平均，这也直接产生向量关系。 主要方法是使用向量符号中的中点公式的顺序替换，这是更可取的，因为它既提供了第四个中点的精确代数表达式，又提供了确定所有顶点的系统方法，同时使凸性条件明确。
