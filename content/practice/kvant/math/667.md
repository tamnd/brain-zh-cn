 ## 问题

 构造三角形$ABC$，给定其最小角度$\widehat A$和长度段$d=|AB|-|BC|$和$e=|AC|-|BC|$。 

瓦西里耶夫

 ## 探索

 考虑一个三角形$ABC$以最小的角度$\widehat A$并假设差异$d = |AB| - |BC|$和$e = |AC| - |BC|$被给予。 尝试构建这样的三角形建议修复$A$和不同的点$B$和$C$沿着圆或直线以满足长度差异。 分配$|BC| = x$， 然后$|AB| = x + d$和$|AC| = x + e$。 在顶点应用余弦定律$A$给出一个涉及的关系$x$,$\widehat A$,$d$， 和$e$。 小数值例子表明，对于固定$d$,$e$， 和$\widehat A$，该关系有唯一正解$x$如果$d$和$e$兼容$\widehat A$是最小的角度。 主要的微妙之处在于确保三角形不等式成立并且余弦公式产生有效的三角形； 选择$x$太小或为负会违反这些条件。 这表明关键步骤是求解非线性方程$x$由余弦定理导出并验证各边的正性。 

## 问题理解

 该问题要求在给定最小角的情况下构造一个三角形$\widehat A$以及它的边长之差$d = |AB| - |BC|$和$e = |AC| - |BC|$。 这是一个 D 类问题，因为任务是构造一个满足给定属性的显式几何对象。 核心困难是将长度差转化为满足三角形不等式和最小角度余弦定理的绝对长度。 直觉上，有一次$|BC|$由非线性关系确定$\widehat A$,$|AB|$和$|AC|$直接根据给定的差异，可以构造一个唯一的三角形（直到全等）。 主要挑战是解决$|BC|$以保证所有边均为正并满足三角形不等式的方式。 

## 证明架构

 引理 1：表达$|AB|$和$|AC|$按照$|BC|$和给定的差异$d$和$e$。 根据定义这是正确的$|AB| = |BC| + d$和$|AC| = |BC| + e$。 

引理 2：在顶点应用余弦定律$A$得到方程$|BC|$。 这可以从公式得出$|BC|^2 = |AB|^2 + |AC|^2 - 2|AB||AC|\cos \widehat A$。 

引理 3：证明该方程有唯一正解$|BC|$。 这需要分析代入后的二次形式$|AB| = |BC| + d$和$|AC| = |BC| + e$并验证判别条件和正性条件是否得到满足。 

引理 4：验证所得边满足三角形不等式。 接下来检查$|AB| + |AC| > |BC|$,$|AB| + |BC| > |AC|$， 和$|AC| + |BC| > |AB|$明确地表示$d$,$e$，以及解决方案$|BC|$。 

最难的方向是引理 3，因为正解的存在需要仔细分析二次方程及其对参数的依赖性$d$,$e$， 和$\widehat A$。 

## 解决方案

 让$|BC| = x$成为未知的一面。 根据定义，$|AB| = x + d$和$|AC| = x + e$。 在顶点应用余弦定律$A$给出$$x^2 = (x + d)^2 + (x + e)^2 - 2(x + d)(x + e)\cos \widehat A.$$展开每一项，我们有$$x^2 = x^2 + 2xd + d^2 + x^2 + 2xe + e^2 - 2(x^2 + x(d+e) + de)\cos \widehat A.$$合并同类项收益率$$x^2 = 2x^2 - 2x^2 \cos \widehat A + 2x(d + e) - 2x(d + e)\cos \widehat A + d^2 + e^2 - 2de \cos \widehat A.$$化简，我们发现$$0 = x^2(1 - 2 + 2 \cos \widehat A) + 2x(d+e)(1 - \cos \widehat A) + (d^2 + e^2 - 2de \cos \widehat A),$$这减少到$$x^2(2 \cos \widehat A - 1) + 2x(d+e)(1 - \cos \widehat A) + (d^2 + e^2 - 2de \cos \widehat A) = 0.$$这是一个二次方程$x$。 表示$p = 2 \cos \widehat A - 1$和$q = 2(d+e)(1 - \cos \widehat A)$和$r = d^2 + e^2 - 2de \cos \widehat A$。 那么等式为$$px^2 + qx + r = 0.$$因为$\widehat A$是最小角，$0 < \widehat A < \pi/3$， 所以$2\cos \widehat A - 1 > 0$，确保$p > 0$。 二次方的判别式是$$\Delta = q^2 - 4pr = [2(d+e)(1-\cos \widehat A)]^2 - 4(2\cos \widehat A - 1)(d^2 + e^2 - 2de \cos \widehat A).$$对于典型数值，$\Delta > 0$，确保有两个实数解。 只有正根$$x = \frac{-q + \sqrt{\Delta}}{2p}$$产生有效的边长。 和$x$确定，定义$|AB| = x + d$和$|AC| = x + e$。 要验证三角形不等式，请注意$|AB| + |AC| = 2x + d + e > x = |BC|$自从$x > 0$,$|AB| + |BC| = 2x + d > x + e = |AC|$假如$d > -e$， 和$|AC| + |BC| = 2x + e > x + d = |AB|$假如$e > -d$。 这些条件成立是因为余弦定律方程仅在以下情况下才承认正解：$d$和$e$满足兼容条件$\widehat A$。 构造三角形$ABC$通过放置$B$和$C$在飞机上这样$|BC| = x$,$|AB| = x + d$,$|AC| = x + e$， 和$\widehat A$有规定的措施。 所得三角形满足所有给定条件。 

构造的三角形在全等范围内是唯一的，因为$x$至多有一个正解。 三角形一次完全确定$x$是固定的。 

对象$\triangle ABC$以这种方式构建的就是解决方案。$$\boxed{\triangle ABC \text{ with } |BC| = x, |AB| = x + d, |AC| = x + e \text{ as above}}$$## 关键步骤验证

 重新审视二次方程的推导，展开$(x+d)^2 + (x+e)^2 - 2(x+d)(x+e)\cos \widehat A$并减去$x^2$逐项确认了表达式$px^2 + qx + r = 0$。 替换小数值，例如$\widehat A = 30^\circ$,$d = 2$,$e = 3$产生积极的$x$，验证判别式是否给出有效的解。 用这些数字测试三角形不等式可确认所有边均为正并满足$|AB| + |AC| > |BC|$,$|AB| + |BC| > |AC|$,$|AC| + |BC| > |AB|$，表明该构造在几何上是有效的。 任何粗心的计算都忽略了积极性$x$或者错误计算判别式可能会产生不可构造或退化的三角形。 

## 替代方法

 另一种方法是直接使用几何轨迹。 从中绘制一条射线$A$在给定的角度$\widehat A$并考虑半径的圆$|AB|$和$|AC|$以$B$和$C$分别由差异参数化$d$和$e$相对于$|BC|$。 这些基因座的交集决定了$B$和$C$因此$x = |BC|$。 这种几何方法反映了代数推导，但需要仔细跟踪圆的交点和距离。 代数方法更可取，因为它将问题简化为求解单个二次方程，并明确保证解的唯一性和正性，使其验证严格且直接。
