 ## 问题

 求方程自然数的所有解$$n^x+n^y=n^z.$$R. Egoryan，九年级学生

 ## 探索

 考虑方程$n^x + n^y = n^z$在自然数中。 首先，观察对称性$x$和$y$，让我们可以不失一般性地假设$x \le y$。 测试较小的值$n$。 为了$n=2$，有人看到$2^1 + 2^1 = 2^2$, 给予$(x, y, z) = (1,1,2)$。 尝试$x=1$,$y=2$给出$2^1 + 2^2 = 2 + 4 = 6$，不是 2 的幂。对于$x=y$,$n^x + n^x = 2n^x = n^z$; 然后$2 = n^{z-x}$， 所以$n$必须除以 2。对于$n>2$,$2$不能是一个力量$n$， 所以$x=y$导致无解，如果$n>2$。 什么时候$x < y$， 因素$n^x$要得到$n^x(1 + n^{y-x}) = n^z$， 所以$1 + n^{y-x} = n^{z-x}$。 为了$n=2$,$1 + 2^k = 2^m$仅适用于小整数； 查看$k=1$,$1+2=3$，不是 2 的幂；$k=2$,$1+4=5$等，建议$x=y$是唯一的可能性$n>1$。 为了$n=1$，方程变为$1 + 1 = 1$， 不可能的。 可能的解决方案包括$x=y$和$z=x+1$。 最容易出错的步骤是不显示其他组合$x<y$产生解决方案，特别是当$n=2$。 

## 问题理解

 我们被要求找到所有自然数$(n, x, y, z)$满意的$n^x + n^y = n^z$。 这是一个 A 类问题，因为我们必须确定所有解决方案。 核心难点在于处理以下情况：$x<y$相对$x=y$，确保小型解决方案不被忽视$n$。 直观的答案是$x=y$和$z = x+1$, 给予$(n, x, y, z)$形式的$(n, k, k, k+1)$和$n=2$，还有$(1, x, y, z)$是不可能的。 为了$n>2$，只有对称情况才可以工作，给出$(2, k, k, k+1)$。 

## 证明架构

 引理 1：如果$n=1$，方程无自然数解。 确实如此，因为$1^x + 1^y = 2 \ne 1^z = 1$。 

引理 2：不失一般性，假设$x \le y$通过对称性。 很简单，因为加法是可交换的。 

引理 3：如果$x < y$， 然后$n^x(1 + n^{y-x}) = n^z$， 所以$1 + n^{y-x} = n^{z-x}$， 和$n^{z-x} - n^{y-x} = 1$。 该方程无解$n>1$,$y-x \ge 1$,$z-x \ge 1$。 考虑到这一点是正确的$n^{z-x} - n^{y-x} = n^{y-x}(n^{z-y}-1) = 1$力量$n^{y-x}=1$， 不可能的。 

引理 4：如果$x=y$， 然后$2 n^x = n^z$，意味着$2 = n^{z-x}$。 仅有的$n=2$工作、给予$z=x+1$。 

引理 5：检查小值$n$明确地。 为了$n=2$,$(x, y, z) = (k, k, k+1)$作品; 为了$n>2$，引理 3 不会产生任何解。 

最难的部分：为所有人严格证明引理 3$n>1$和$x<y$。 微妙的一点是因式分解并显示没有其他整数解$n^{z-x}-n^{y-x}=1$。 

## 解决方案

 假设$n$是一个自然数并且$(x, y, z)$是满足的自然数$n^x + n^y = n^z$。 根据对称性，取$x \le y$。 

首先，考虑$n=1$。 然后$1^x + 1^y = 1 + 1 = 2$， 尽管$1^z = 1$，所以这个方程是不可能成立的。 所以，$n \ge 2$。 

如果$x = y$，则方程变为$n^x + n^x = 2 n^x = n^z$， 所以$2 = n^{z-x}$。 自然数中唯一的解发生在$n=2$，产生$2 = 2^{z-x}$， 所以$z-x=1$, 给予$z=x+1$。 因此，对于$x=y$我们得到解决方案$(n, x, y, z) = (2, k, k, k+1)$对于任何自然的$k$。 

如果$x < y$， 因素$n^x$从左侧开始：$$n^x + n^y = n^x (1 + n^{y-x}) = n^z.$$两边除以$n^x$要得到$$1 + n^{y-x} = n^{z-x}.$$让$a = y-x \ge 1$和$b = z-x \ge 1$。 然后$$1 + n^a = n^b \implies n^b - n^a = 1 \implies n^a(n^{b-a}-1) = 1.$$自从$n \ge 2$和$a \ge 1$,$n^a \ge 2$， 所以$n^a(n^{b-a}-1) \ge 2 \cdot 1 = 2$，不能等于$1$。 因此，不存在解决方案$x<y$。 

所有案件都已穷尽。 唯一的自然数解出现在$x=y$和$n=2$, 给予$z=x+1$。 因此，完整的解决方案是$$(n, x, y, z) = (2, k, k, k+1), \quad k \in \mathbb{N}.$$

$\boxed{(n, x, y, z) = (2, k, k, k+1), ; k \in \mathbb{N}}$## 关键步骤验证

 在因式分解步骤中$x<y$，论证$n^a(n^{b-a}-1) = 1$依赖于最小值$n^a \ge 2$。 为了$n=2$,$a=1$,$b-a \ge 1$，一得到$2(2^{b-1}-1) \ge 2$， 绝不$1$。 如果粗心的论证忽略了最小性，人们可能会错误地认为$2^1(2^{0}-1)=0$作为解决方案； 显式检查可以防止这种情况发生。 

步骤$x=y$屈服$2 n^x = n^z$需要确定$2 = n^{z-x}$力量$n=2$自从$n>2$产生超过 2 的幂。 测试$n=3$给出$3^{z-x} = 2$， 不可能的; 这验证了没有其他$n$作品。 

显式测试小$k$为了$n=2$，例如，$x=y=1$，产量$2^1 + 2^1 = 4 = 2^2$，确认模式$(k,k,k+1)$是正确的。 

## 替代方法

 另一种方法是假设$x \le y$并设置$y = x + d$,$z = x + e$， 和$d, e \ge 0$。 然后$n^x(1 + n^d) = n^{x+e} \implies 1 + n^d = n^e$。 从这里开始考虑$n^e - n^d = 1$将问题简化为 Catalan 方程$n^e - n^d = 1$，其自然数的唯一解是$(n,d,e) = (2,1,2)$。 这立即产生了解决方案$(2,k,k,k+1)$。 主要方法更可取，因为它不假设您了解加泰罗尼亚定理，仅依赖初等因式分解和极小值论证，因此九年级水平即可使用。
