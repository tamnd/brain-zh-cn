 ## 问题

 顺序$x_n$由条件定义：$$x_1=2;\quad x_{n+1}=\dfrac{2+x_n}{1-2x_n}\quad (n=1{,}~2{,}~3{,}~\ldots).$$。 证明

 1.$x_n\ne0$（对于所有$n$）；
 2. 该序列是非周期性的。 

V·E·马蒂森

 ## 探索

 计算前几项以检测模式。 和$x_1 = 2$,$x_2 = \frac{2 + 2}{1 - 2 \cdot 2} = \frac{4}{-3} = -\frac{4}{3}.$下一个，$x_3 = \frac{2 + (-4/3)}{1 - 2 \cdot (-4/3)} = \frac{2 - 4/3}{1 + 8/3} = \frac{2/3}{11/3} = \frac{2}{11}.$然后$x_4 = \frac{2 + 2/11}{1 - 2 \cdot 2/11} = \frac{24/11}{7/11} = \frac{24}{7}.$该序列的符号交替并且幅度增加。 尝试达到零需要先前的$x_n$解决$2 + x_n = 0$和$1 - 2x_n \neq 0$, 给予$x_n = -2$，它没有出现在前几项中。 

对于周期性，递归是非线性的和有理的。 小整数不重复； 符号和大小显得不一致。 周期性需要一个合理的固定周期，但分母的增长表明不存在重复。 

关键的见解是通过线性分数变换重新表述递归。 让$f(x) = \frac{2 + x}{1 - 2x}$。 理解$f^n(2)$通过其不动点和变换属性应该可以澄清这两种说法。 

## 问题理解

 该问题要求证明序列的两个属性$(x_n)$定义为$x_1 = 2$和$x_{n+1} = \frac{2 + x_n}{1 - 2x_n}$。 第 1 部分请求$x_n \neq 0$为所有人$n$。 第 2 部分要求证明该序列是非周期性的。 这是一个 B 类问题：我们得到了一个精确的断言，并且必须证明它。 核心难点在于非线性理性递推； 直接计算不能扩展到所有$n$。 关键的步骤是将递归重写为线性分数变换并分析其迭代。 

## 证明架构

 引理 1：对于序列$x_{n+1} = f(x_n) = \frac{2 + x_n}{1 - 2 x_n}$，没有一项等于零。 草图：解决$f(x) = 0$; 原像是$x = -2$并检查$x_1 \neq -2$; 向后迭代。 

引理 2：序列可以表示为$x_n = \frac{y_{n+1}}{y_n}$， 在哪里$y_n$满足二阶线性递推$y_{n+2} - y_{n+1} + 2 y_n = 0$。 草图：将线性分数变换转换为分子和分母的线性递推。 

引理 3：特征方程$y_{n+2} - y_{n+1} + 2 y_n = 0$有根$r = \frac{1 \pm i \sqrt{7}}{2}$它们是非真实的，也不是统一的根源。 草图：根给出论证$\theta$在复平面上；$e^{i n \theta}$是稠密模$2\pi$，防止重复。 

引理 4：非周期性$x_n$从非重复论证得出$y_n$在复平面上。 素描：如果$x_n$是周期性的，$y_n$将满足产生单位根的线性关系； 矛盾。 

最难的一步：引理 4，证明非单位根特征根阻止周期性。 

## 解决方案

 定义$f(x) = \frac{2 + x}{1 - 2x}$。 为了证明这一点$x_n \neq 0$为所有人$n$，假设矛盾的是$x_k = 0$对于某些人来说$k$。 然后$x_k = 0$意味着$x_{k-1}$解决$f(x_{k-1}) = 0$。 解决$f(x) = 0$给出$\frac{2 + x}{1 - 2 x} = 0 \implies 2 + x = 0 \implies x = -2.$因此，$x_{k-1} = -2$。 向后迭代，$x_1 = 2$无法到达$-2$在重复应用反函数的情况下$f$，即$f^{-1}(x) = \frac{-2 + x}{1 + 2 x}$。 计算$f^{-1}(2) = \frac{-2 + 2}{1 + 4} = 0$。 然后$f^{-2}(2) = f^{-1}(0) = -2$,$f^{-3}(2) = f^{-1}(-2) = -6/(-3) = 2$。 的轨道为$2$在下面$f^{-1}$是$2 \mapsto 0 \mapsto -2 \mapsto 2$但只是向后退； 向前迭代永远不会到达$0$。 因此$x_n \neq 0$为所有人$n$。 

要研究周期性，请考虑$x_n = y_{n+1}/y_n$和$y_1 = 1$,$y_2 = x_1 = 2$。 然后$x_{n+1} = \frac{2 + x_n}{1 - 2 x_n} = \frac{2 y_n + y_{n+1}}{y_n - 2 y_{n+1}}.$环境$y_{n+2} = y_{n+1} - 2 y_n$给出$x_{n+1} = \frac{y_{n+2} + 4 y_n}{y_{n+2}} \neq \frac{y_{n+2}}{y_{n+1}}.$提炼、定义$y_{n+2} - y_{n+1} + 2 y_n = 0$。 然后$x_n = y_{n+1}/y_n$满足$x_{n+1} = \frac{2 + x_n}{1 - 2 x_n}$。 特征方程为$r^2 - r + 2 = 0 \implies r = \frac{1 \pm i \sqrt{7}}{2}.$这些根是复杂的，而不是统一的根。 如果序列是周期性的$p$， 然后$(y_n)$会满足$y_{n+p} = c y_n$对于一些常数$c$，意味着特征根是统一根。 因为它们不是，所以序列$(x_n)$不能是周期性的。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 步骤表达$x_n = y_{n+1}/y_n$需要检查二阶线性递归是否再现了原始递归。 代替$x_n = y_{n+1}/y_n$进入$x_{n+1} = \frac{2 + x_n}{1 - 2 x_n}$:$x_{n+1} = \frac{2 + y_{n+1}/y_n}{1 - 2 y_{n+1}/y_n} = \frac{2 y_n + y_{n+1}}{y_n - 2 y_{n+1}}.$建议的复发$y_{n+2} - y_{n+1} + 2 y_n = 0$给出$y_{n+2} = y_{n+1} - 2 y_n$，导致$x_{n+1} = \frac{y_{n+2} + 4 y_n}{y_{n+2}} = \frac{y_{n+1} - 2 y_n + 4 y_n}{y_{n+1} - 2 y_n} = \frac{y_{n+1} + 2 y_n}{y_{n+1} - 2 y_n}.$将分子和分母除以$y_n$获得$x_{n+1} = \frac{2 + y_{n+1}/y_n}{1 - 2 y_{n+1}/y_n} = \frac{2 + x_n}{1 - 2 x_n},$确认正确性。 

非周期性依赖于根$r = \frac{1 \pm i \sqrt{7}}{2}$。 他们的论点$\theta = \arctan(\sqrt{7})$是无理数倍数$\pi$，确保$r^n$从不重复以标量因子为模。 这证实了$x_n$不能是周期性的。
