 ## 问题

 黑板上写着几个连续的自然数（多个）。 会不会所有偶数写出的数字之和等于自然数的平方，并且所有奇数写出的数字之和也等于自然数的平方？ 

A·库兹涅佐夫

 欧拉奥林匹克竞赛（第十七届，地区赛段）

 ## 探索

 让$a, a+1, \dots, a+n-1$是$n>1$连续的自然数。 让$S_e$表示该块中偶数的总和$S_o$奇数的总和。 目标是确定两者是否有可能$S_e$和$S_o$是完美的正方形。 

序列的结构取决于奇偶校验$n$。 什么时候$n=2m$，双方出现的次数相同。 什么时候$n=2m+1$，一个奇偶校验比另一个奇偶校验恰好多出现一次。 在这两种情况下，偶数项和奇数项的和都可以使用算术级数公式显式表示，这将问题简化为这些表达式的丢番图条件。 

## 问题理解

 该问题要求存在一个长度大于 1 的连续整数块，使得分别限制为偶数和奇数项的部分和都是完全平方数。 该结构迫使两个和紧密相关，因此策略是以封闭形式表达它们并分析整除性和平方条件。 

## 证明架构

 证据分为案例$n=2m$和$n=2m+1$。 在每种情况下，都有明确的公式$S_e$和$S_o$是衍生出来的。 所得方程被转换为涉及平方和整除性的约束。 然后使用整数的因式分解属性和互质参数将每种情况减少到不可能。 

## 解决方案

 ### 长度均匀$n=2m$认为$a$是偶数； 相反的奇偶校验情况是对称的。 偶数是$a, a+2, \dots, a+2(m-1)$奇数是$a+1, a+3, \dots, a+2m-1$。 他们的总和是$S_e = m(a+m-1), \quad S_o = m(a+m).$认为$S_e = s^2$和$S_o = t^2$。 然后$t^2 - s^2 = m.$因此$(t-s)(t+s)=m.$从$S_e = m(a+m-1)$我们得到$m \mid s^2$，所以每个素数除法$m$必须出现在$s$至少有其指数的一半。 写$m = u v^2,$在哪里$u$是无平方的并且$v \in \mathbb{N}$。 整除性$m \mid s^2$意味着$u \mid s$， 所以$s = u k$。 替换给出$s^2 = u^2 k^2 = m(a+m-1) = u v^2 (a+m-1).$取消$u$产量$u k^2 = v^2 (a+m-1).$自从$u$是无平方的，$u \mid v^2 (a+m-1)$力量$u \mid (a+m-1)$。 写$a+m-1 = u t^2$。 然后$u k^2 = v^2 u t^2,$所以$k = v t$因此$s = u v t.$代入$S_e = s^2$给出$u v^2 (a+m-1) = u^2 v^2 t^2,$因此$a+m-1 = u t^2$和$a = u t^2 - m + 1.$现在计算$S_o$:$S_o = m(a+m) = u v^2 (u t^2 + 1).$自从$S_o$是一个完全平方并且$v^2$已经是平方因子了，我们要求$u(u t^2 + 1) \text{ to be a perfect square}.$数字$u$和$u t^2 + 1$是互质的，因为它们的区别是$1$。 因此每一个都必须是一个完美的正方形。 因为$u$是无平方的，这个力$u=1$， 所以$m=v^2$是一个完美的正方形。 

然后$S_o = v^2(t^2+1).$为了使它成为一个正方形，$t^2+1$一定是完全平方数，所以存在$x$这样$x^2 - t^2 = 1.$这意味着$(x-t)(x+t)=1$，它在自然数中没有解。 于是就有了这样的案例$n=2m$是不可能的。 

### 奇数长度$n=2m+1$让$x = a+m$。 然后$S_e = (m+1)x, \quad S_o = mx.$假设两者都是完全平方数：$mx = t^2, \quad (m+1)x = s^2.$写$m = u v^2$， 在哪里$u$是无平方的。 从$mx=t^2$我们得到$u v^2 x = t^2,$所以$u \mid t^2$， 因此$u \mid t$。 写$t = u k$。 替换给出$u v^2 x = u^2 k^2,$所以$x = \frac{u k^2}{v^2}.$因此$v^2 \mid u k^2$。 自从$u$是无平方的，$v \mid k$， 所以$k = v c$和$x = u c^2.$现在代入$(m+1)x = s^2$:$(m+1) u c^2 = s^2.$因为$\gcd(u, m+1)=1$, 的每个素因数$u$必须出现在$s$， 所以$u \mid s$，并写作$s = u d$给出$(m+1)c^2 = u d^2.$自从$c^2$是一个正方形，这意味着$u \mid c^2$， 因此$u=1$因为$u$是无平方的。 所以$m$是一个完美的正方形。 

然后$mx=t^2$变成$m x = c^2$， 和$m=v^2$， 所以$v^2 x = c^2,$因此$x$是一个正方形，$x = r^2$， 和$c = v r$。 

代入$(m+1)x = s^2$给出$(v^2+1) r^2 = s^2,$所以$v^2+1$一定是一个完美的正方形。 这意味着$p^2 - v^2 = 1$， 因此$(p-v)(p+v)=1,$这在自然数中是不可能的。 

如此情况$n=2m+1$也是不可能的。 

## 结论

 两种可能的长度奇偶情况$n>1$导致矛盾。 因此，不存在一个以上连续自然数的块，其偶数之和与奇数之和均为完全平方。
