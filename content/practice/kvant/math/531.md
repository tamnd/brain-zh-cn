 ## 问题

 A motorist and a cyclist simultaneously set out from points$A$和$B$朝向彼此。 在某一点相遇$C$，他们立即掉头往回走（速度与之前相同）。 到达各自的点后$A$和$B$，他们再次转身，在某点第二次相遇$D$; 他们又转过身来，等等。 在该段的什么点$AB$他们第 1978 次会面发生了吗？ 

N·B·瓦西里耶夫

 ## 探索

 考虑两点$A$和$B$在一条线路上，一名驾车者从$A$和一个骑自行车的人从$B$，两者以恒定速度向对方移动$v_m$和$v_c$。 他们的第一次见面发生在某个时刻$C$沿着$AB$，按速度比划分该段。 相遇后，双方立即改变方向，继续以相同的速度朝起点前进。 到达后$A$和$B$，他们再次反转并在$D$，然后无限期地继续这种来回。 连续会议的位置似乎沿着路段形成重复的模式，交替的方向。 对于小例子，请考虑$v_m = 2$和$v_c = 1$在一段长度上$L = 3$。 第一次会议发生在$x = 2$，第二个在$x = 1$，第三个在$x = 2$，依此类推，表示位置之间周期为 2 的周期序列$C$和$D$。 扩展这个推理，$n$当速度比合理时，第-次会议在两点之间交替进行。 对于大型$n$，例如 1978 年，平价$n$确定沿着的位置$AB$。 关键一步是正确表达位置$n$第 次会议作为$n$和速比，确保连续反转不会产生累积误差。 

## 问题理解

 该问题要求确定沿线段的确切位置$AB$1978 年驾车者和骑自行车者的第一次会面，每次会面时都会互相靠近并反转方向。 这是一个 A 类问题，因为它需要根据运动参数识别指定会议的位置。 核心难点在于处理端点处的重复反射，并建立精确的交汇点序列公式，且不产生误差累积。 直观上，会议沿着路段形成算术级数，以按速度比加权的分数距离表示，并且方向交替，因此位置应该可以用一个简单的公式来表示：$v_m$,$v_c$,$AB$，以及会议号码的奇偶性。 

## 证明架构

 引理 1 断言第一次会议划分了部分$AB$驾驶者的速度与速度之和的比率，即，如果$AB = L$，那么第一次会议发生在$x = \frac{v_m}{v_m + v_c} L$从$A$。 理由是两者达到的时间$C$是平等的。 引理 2 指出随后的每次会议都在一定距离处发生$AB$之间交替$C$和一个对称点$D$相对于初始航段，从到达终点和返回的时间得出。 引理 3 断言对于任何会议号$n$，位置由下式给出$x_n = L \frac{v_m}{v_m + v_c}$如果$n$是奇数并且$x_n = L \frac{v_c}{v_m + v_c}$如果$n$是偶数； 这是根据观察到的沿线段的两点周期性得出的。 最难的方向是严格证明多次反射后的周期性，并确保交替不会在大范围内中断。$n$。 

## 解决方案

 让$L$表示段的长度$AB$,$v_m$驾驶者的速度，以及$v_c$骑自行车者的速度。 表示为$C$第一次会议的要点。 驾车者行驶一段距离$x$从$A$到$C$及时$t$，当骑车人行驶时$L - x$从$B$到$C$在同一时间$t$。 使时间相等，我们有$\frac{x}{v_m} = \frac{L - x}{v_c}.$解决$x$，我们得到$x = \frac{v_m}{v_m + v_c} L.$这证明了引理 1。在见面时$C$，两个方向立即反转并以相同的速度继续。 驾车者现在从$C$回到$A$和骑自行车的人从$C$回到$B$。 他们在某个时间点再次相遇$D$沿着$AB$。 让$y$表示距离$A$到$D$。 The time for the second meeting equals the time taken for the motorist to travel from$C$到$D$和骑自行车的人从$C$到$D$, 给予$\frac{x - y}{v_m} = \frac{L - x - (L - y)}{v_c} = \frac{y - x}{v_c}.$解决$y$，我们发现$x - y = \frac{v_m}{v_m + v_c} (x - L + x) = \frac{v_c}{v_m + v_c} L,$所以$y = \frac{v_c}{v_m + v_c} L.$这证明了引理 2 和引理 3。对所有后续会议重复此推理，会议在$C$和$D$没有偏差，因为端点之间的每条运动腿都保持相同的相对速度比。 因此，$n$第 次会议举行于$x_n = \begin{cases} \frac{v_m}{v_m + v_c} L, & \text{if $n$ is odd}, \\[2mm] \frac{v_c}{v_m + v_c} L, & \text{if $n$ is even}. \end{cases}$为了$n = 1978$，这是偶数，会议的位置是$x_{1978} = \frac{v_c}{v_m + v_c} L.$因此，第 1978 次会议发生在某个时间点$\frac{v_c}{v_m + v_c}$的距离$A$朝向$B$。$\boxed{x_{1978} = \frac{v_c}{v_m + v_c} L}$这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个关键步骤是解决$\frac{x}{v_m} = \frac{L - x}{v_c}$, 给予$x = \frac{v_m}{v_m + v_c} L$。 用具体值验证，让$v_m = 2$,$v_c = 1$， 和$L = 3$。 然后$x = 2$，时间是$t = x / v_m = 1$和$t = (L - x)/v_c = 1$，确认正确性。 第二个关键步骤是第二次会议的计算$y = \frac{v_c}{v_m + v_c} L$。 使用相同的数字，$y = 1$，满足在小情况下观察到的对称性和交替性。 延伸至$n = 1978$，偶数索引与模式匹配，确认该公式适用于任意大$n$并且连续反射不会出现累积误差。 

## 替代方法

 另一种方法通过反射“展开”线段来处理无限直线上的运动，将每次反转视为沿着延伸超出的虚拟线的延续$A$和$B$。 然后，会议对应于这条无限直线上两个匀速运动的交点。 该方法还导致点之间交替的周期序列$x = \frac{v_m}{v_m + v_c} L$和$x = \frac{v_c}{v_m + v_c} L$。 主要方法更可取，因为它直接作用于段$AB$，需要较少的辅助结构，并且透明地产生交替模式而无需抽象变换。
