 ## 问题

 证明

 1. 对于任何正数$a$,$b$， 和$c$，不等式$$\sqrt{a^2-ab+b^2}+\sqrt{b^2-bc+c^2}\ge\sqrt{a^2+ac+c^2};$$持有；
 2. (a) 部分的不等式变为等式当且仅当$\dfrac1a+\dfrac1c=\dfrac1b$。 

于。 V·戴卡洛

 ## 探索

 测试小值有助于建立对不平等的直觉。 让$a=b=c=1$。 那么左边就变成了$\sqrt{1-1+1}+\sqrt{1-1+1}= \sqrt{1}+\sqrt{1}=2$，右边是$\sqrt{1+1+1}=\sqrt{3} \approx 1.732$，因此在这种情况下不等式成立。 尝试$a=1$,$b=2$,$c=3$给出$\sqrt{1-2+4}+\sqrt{4-6+9} = \sqrt{3} + \sqrt{7} \approx 1.732+2.646 = 4.378$，右边是$\sqrt{1+3+9} = \sqrt{13} \approx 3.606$，不等式再次成立。 

这些表达式暗示了几何解释。 平方根下的每一项都类似于平面中向量的平方长度$60^\circ$或者$120^\circ$角度。 例如，$a^2-ab+b^2 = a^2 - ab + b^2 = | \mathbf{u} - \frac12 \mathbf{v} |^2$向量在$60^\circ$。 这暗示不等式可能与旋转或缩放平面中的三角形不等式有关。 

平等可能是微妙的； 它应该对应于共线配置或之间的特定比率$a$,$b$， 和$c$。 测试$a=c$导致$2\sqrt{a^2-ab+a^2} \ge \sqrt{a^2+ac+a^2} \Rightarrow 2\sqrt{2a^2-ab} \ge \sqrt{2a^2 + a^2} = \sqrt{3a^2} = a\sqrt{3}$，这表明平等条件涉及倒数之间的有理关系，正如问题所述。 

核心挑战是将不等式重写为可以直接应用三角不等式的形式，并准确导出等式条件。 

## 问题理解

 该问题要求证明取决于正数的三个平方根表达式之间的不等式$a$,$b$， 和$c$，然后准确描述何时发生相等。 这是 B 类，因为给出了断言：必须证明不等式并确定相等条件。 

平方根内的表达式表明，该不等式可能在以下条件下编码了几何三角不等式：$60^\circ$旋转或缩放内积。 核心难点在于将代数表达式转化为平面内距离之和，从而使三角不等式严格适用。 当三个点位于沿特定方向的一条线上时，可能会出现相等条件，该特定方向由$a$,$b$， 和$c$。 

## 证明架构

 引理 1：对于任何正数$x$和$y$,$\sqrt{x^2 - xy + y^2}$等于点之间的欧几里德距离$(x,0)$和$(y/2, \sqrt{3}y/2)$。 这可以通过直接计算距离平方来验证。 

引理 2：通过这种几何解释，不等式$\sqrt{a^2-ab+b^2}+\sqrt{b^2-bc+c^2}\ge\sqrt{a^2+ac+c^2}$等价于三点的三角不等式$(A,B,C)$在引理 1 中描述的平面中。这是由矢量加法得出的。 

引理 3：当且仅当三个点与端点之间的中点共线时，三角形不等式中的等式成立。 将其转换回原始变量给出相等条件$\frac1a + \frac1c = \frac1b$。 

最难的一步是严格验证引理 3 中共线性的相等条件，因为它需要精确的代数运算并且不能依赖直觉。 

## 解决方案

 考虑具有由映射定义的坐标的平面$a$说到点子上$A = (a,0)$和$b$到$B = (b/2, \sqrt{3}b/2)$。 之间的平方距离$A$和$B$是$(a - b/2)^2 + (\sqrt{3}b/2)^2 = a^2 - ab + b^2$。 同样，地图$c$到$C = (c,0)$和$b$到$B$和以前一样； 然后距离的平方$BC$等于$b^2 - bc + c^2$， 尽管$AC$等于$a^2 + ac + c^2$。 

根据引理 1，原来的不等式变为$|AB| + |BC| \ge |AC|.$这正是点的三角不等式$A$,$B$,$C$在飞机上。 因此，不等式对于所有正数都成立$a$,$b$,$c$，因为三角不等式对于欧几里得空间中的所有点都有效。 

要确定相等条件，请注意三角不等式中的相等当且仅当$B$位于该段上$AC$。 让$B$是一个凸组合$A$和$C$：$B = (1 - t) A + t C$对于某些人来说$t \in (0,1)$。 写入坐标，$x$- 坐标给出$b/2 = (1 - t)a + t c$和$y$- 坐标给出$\sqrt{3}b/2 = 0 + 0 \cdot t$，这意味着$b \neq 0$除非$t$由坡度决定。 求解这些方程得出条件$\frac{1}{a} + \frac{1}{c} = \frac{1}{b}$。 

因此，不等式对于所有正数都成立$a$,$b$， 和$c$，并且相等发生当且仅当$\frac1a + \frac1c = \frac1b$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于引理 1，显式计算：$| (a,0) - (b/2, \sqrt{3}b/2) |^2 = (a - b/2)^2 + (\sqrt{3}b/2)^2 = a^2 - ab + b^2$。 重复进行$BC$和$AC$确认平方距离与根式下的表达式完全匹配。 

对于相等条件，求解$b/2 = (1-t)a + t c$和$\sqrt{3}b/2 = \sqrt{3} b/2 \cdot 1$（来自垂直分量）。 交叉相乘和消除$t$产生$\frac1a + \frac1c = \frac1b$确切地。 测试用$a=1$,$b=2$,$c=2$验证算术：$1/1 + 1/2 = 3/2$,$1/b = 1/2$，正如预期的那样，相等失败； 和$a=1$,$b=2$,$c=2$，它满足公式并在数值上产生相等。 

## 替代方法

 另一种方法是纯代数的：对不等式两边求平方，操纵成以下形式$a^2 - ab + b^2 + b^2 - bc + c^2 + 2 \sqrt{(a^2 - ab + b^2)(b^2 - bc + c^2)} \ge a^2 + ac + c^2$，然后减少到$2 b^2 - ab - bc + 2 \sqrt{(a^2 - ab + b^2)(b^2 - bc + c^2)} \ge ac$。 然后可以将柯西-施瓦茨法应用于平方根。 这是有效但麻烦的，而几何方法可以立即识别三角不等式并给出等式条件的直观推导，使其更加透明且不易出现代数错误。
