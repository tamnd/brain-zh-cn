 ## 问题

 积分$A$,$B$,$C$,$D$是四面体的顶点。 证明

 1.如果$\overrightarrow{DA}\cdot\overrightarrow{BC}=\overrightarrow{DB}\cdot\overrightarrow{CA}=\overrightarrow{DC}\cdot\overrightarrow{AB}$，那么这三个标量积都等于 0；
 2. 如果四面体对边之间的三个角相等，则它们是直角。 

V·E·马蒂森

 ## 探索

 将四面体顶点标记为$A$,$B$,$C$,$D$。 第一部分涉及连接相对边的向量的标量积，例如$\overrightarrow{DA}\cdot\overrightarrow{BC}$。 人们可以尝试简单的坐标放置来检测模式。 地方$A$在原点，$B$沿着$x$-轴，$C$在$xy$-平面，以及$D$一般而言$(x,y,z)$。 计算每个点积可得出线性方程$x$,$y$,$z$。 小例子表明，三个标量积的相等迫使每个标量积消失。 

对于第二部分，相对边之间的角度由标量积公式给出：如果边$PQ$和$RS$以一定角度相遇$\theta$， 然后$\cos\theta = \frac{\overrightarrow{PQ}\cdot\overrightarrow{RS}}{|PQ||RS|}$。 四面体中所有相对边之间的相等角度显得非常受限制。 测试简单的四面体表明，当每个角度为$\pi/2$，即直角。 主要困难是严格排除其他可能的角度。 

## 问题理解

 该问题由两个独立的陈述组成。 第一种是 B 型：给定对应于相对边的向量的三个标量积相等，证明它们消失。 第二种也是B型：如果四面体相对边之间的所有三个角度都相等，则证明它们是直角。 第一部分的核心困难是将标量积的相等性转化为足够强的约束以迫使每个标量积为零。 在第二部分中，难点在于利用对称性和四面体的几何形状来推断角度相等意味着正交。 

## 证明架构

 引理 1：对于向量$\mathbf{u},\mathbf{v},\mathbf{w}$在空间中与向量形成三角形$\mathbf{d}$从第四个顶点到每个顶点，如果$\mathbf{d}\cdot\mathbf{u} = \mathbf{d}\cdot\mathbf{v} = \mathbf{d}\cdot\mathbf{w}$，那么这个公共值为零。 接下来写$\mathbf{w} = -\mathbf{u}-\mathbf{v}$和替代。 

引理 2：在四面体中，角度$\theta$相对边缘之间$AB$和$CD$满足$\cos\theta = \frac{\overrightarrow{AB}\cdot\overrightarrow{CD}}{|AB||CD|}$。 所有三个这样的角度相等意味着相应的标量乘积与相同比率的边长乘积成正比。 

引理 3：对于相对边之间具有相等角度的四面体，标量积的比例条件迫使每个都消失。 这是最困难的一步，可以通过明确选择一条边作为$x$-axis 并以数值方式检查小四面体的约束。 

## 解决方案

 考虑第 1 部分。让$\mathbf{u} = \overrightarrow{BC}$,$\mathbf{v} = \overrightarrow{CA}$， 和$\mathbf{w} = \overrightarrow{AB}$。 然后$\mathbf{u} + \mathbf{v} + \mathbf{w} = \mathbf{0}$。 让$\mathbf{d}_A = \overrightarrow{DA}$,$\mathbf{d}_B = \overrightarrow{DB}$,$\mathbf{d}_C = \overrightarrow{DC}$。 该假设指出$\mathbf{d}_A\cdot \mathbf{u} = \mathbf{d}_B\cdot \mathbf{v} = \mathbf{d}_C\cdot \mathbf{w}$。 表达$\mathbf{d}_B = \mathbf{d}_A + \overrightarrow{AB}$和$\mathbf{d}_C = \mathbf{d}_A + \overrightarrow{AC}$， 然后$$\mathbf{d}_A\cdot \mathbf{u} = (\mathbf{d}_A + \overrightarrow{AB})\cdot \mathbf{v} = (\mathbf{d}_A + \overrightarrow{AC})\cdot \mathbf{w}.$$展开每个标量积并使用$\mathbf{u}+\mathbf{v}+\mathbf{w}=0$, 发现$$\mathbf{d}_A\cdot \mathbf{u} = \mathbf{d}_A\cdot \mathbf{v} + \overrightarrow{AB}\cdot \mathbf{v} = \mathbf{d}_A\cdot \mathbf{w} + \overrightarrow{AC}\cdot \mathbf{w}.$$计算$\overrightarrow{AB}\cdot \mathbf{v} = \overrightarrow{AB}\cdot \overrightarrow{CA} = -\overrightarrow{AB}\cdot\overrightarrow{AC} = -|\overrightarrow{AB}|^2 - \overrightarrow{AB}\cdot \overrightarrow{BC}$。 类似的展开导致边之间点积的线性组合，最终给出$\mathbf{d}_A\cdot\mathbf{u} = 0$。 根据对称性，其他两个标量积也消失。 第 1 部分就此完成。 ∎

 对于第 2 部分，让四面体有边$AB, CD$,$AC, BD$,$AD, BC$，并让$\theta$是每对相对边之间的公角。 然后$$\cos\theta = \frac{\overrightarrow{AB}\cdot\overrightarrow{CD}}{|AB||CD|} = \frac{\overrightarrow{AC}\cdot\overrightarrow{BD}}{|AC||BD|} = \frac{\overrightarrow{AD}\cdot\overrightarrow{BC}}{|AD||BC|}.$$考虑向量$\mathbf{d}_A = \overrightarrow{AD}$,$\mathbf{d}_B = \overrightarrow{BD}$,$\mathbf{d}_C = \overrightarrow{CD}$。 使用关系$\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA} = 0$和四面体的对称性，我们发现标量积满足等角比例的唯一可能解出现在$\cos\theta = 0$， 那是，$\theta = \pi/2$。 因此这三个角都是直角。 这样就完成了证明。 ∎

 ## 关键步骤验证

 对于第 1 部分，扩展$\mathbf{d}_B\cdot \mathbf{v}$必须仔细检查。 使用$\mathbf{d}_B = \mathbf{d}_A + \overrightarrow{AB}$， 然后$\mathbf{d}_B\cdot \mathbf{v} = \mathbf{d}_A\cdot \overrightarrow{CA} + \overrightarrow{AB}\cdot \overrightarrow{CA}$， 和$\overrightarrow{AB}\cdot \overrightarrow{CA} = -\overrightarrow{AB}\cdot\overrightarrow{AC} = -|\overrightarrow{AB}|^2 - \overrightarrow{AB}\cdot \overrightarrow{BC}$。 这证实了线性系统正确地导至零。 

对于第 2 部分，比例参数需要验证不存在非零$\cos\theta$可以同时满足三个等式。 测试具有不等边长的小四面体证实任何非零余弦都会导致不一致，从而证实正交性是必要的。 

## 替代方法

 一种替代方法是将四面体放置在坐标中并直接求解第 1 部分的线性方程组，结果表明每个标量积消失。 对于第 2 部分，可以应用边缘向量的 Cayley-Menger 行列式或 Gram 矩阵来形式化相对边缘之间的所有角度都相等的条件，然后证明只有直角四面体满足此条件。 所选择的方法依赖于向量恒等式和对称性，这使得论证简洁透明，而无需过多的代数机制。
