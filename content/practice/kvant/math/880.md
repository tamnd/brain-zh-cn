 ## 问题

 在序列 1, 0, 1, 0, 1, 0 中，$\ldots$，从第七项开始的每一项都等于前面六项之和的最后一位数字。 证明在这个序列中，六个数字 0, 1, 0, 1, 0, 1 永远不会连续出现。 

A·S·梅尔库里耶夫

 列宁格勒市数学奥林匹克竞赛 (50, 1984)

 ## 探索

 该序列开始为$1, 0, 1, 0, 1, 0$随后的每一项被定义为前六项之和的最后一位数字。 明确计算一些项有助于识别模式。 第七项是$1+0+1+0+1+0=3$， 所以$a_7=3$。 第八项是$0,1,0,1,0,3$, 给予$5$，以及第九项总和$1,0,1,0,3,5$到$10$, 最后一位数字$0$。 第十项总和$0,1,0,3,5,0=9$, 最后一位数字$9$。 这些早期术语表明该序列并不是立即周期性的$6$，但初始交替模式$1,0,1,0,1,0$很快就发散了。 

为了证伪以下猜想$0,1,0,1,0,1$可能会出现，我们可以尝试在序列中的任何位置对齐该块，并查看递归是否允许。 前面六个术语的最后一位数字是敏感的； 位置上有三个零$2,4,6$六项块的总和可能会阻止交替的继续$0,1,0,1,0,1$图案。 尝试小的数字序列表明，引入该块会导致最后一位数字无法一致地再现该模式的总和，这表明这是不可能的。 关键点是理解六项中最后一位数字和的进位效应。 

## 问题理解

 我们被要求证明，在由前六项之和的最后一位递归定义的序列中，六项块$0,1,0,1,0,1$永远不会出现。 这是一个 B 类问题：一个纯粹的证明，其中的陈述被断言并且必须严格建立。 核心难点是处理模算术模$10$六个连续项的总和并证明递归不能适应这种交替模式。 直观上，序列的增长和数字求和规则与交替块相冲突，但这必须被形式化。 

## 证明架构

 引理 1：如果一个块$b_1,\dots,b_6$出现在序列中的下一项$b_7$唯一确定为它们总和的最后一位数字。 这直接来自序列定义。 

引理 2：形成模式的任何六个连续数字的总和$0,1,0,1,0,1$是$0+1+0+1+0+1=3$，所以下一项必须是$3$。 

引理 3：放置$0,1,0,1,0,1$在序列中的任何位置，块之后的下一项将是$3$，但是递归确定的以下项无法重现移动的初始块，从而使该块不可重现。 

引理 4：因为递归仅取决于最后六项，并且$3$不同于$0$（块的第一项），序列不可能包含$0,1,0,1,0,1$连续地。 最微妙的步骤是引理 3，验证递归不能允许块以任何对齐方式继续。 

## 解决方案

 考虑顺序$a_1=1, a_2=0, a_3=1, a_4=0, a_5=1, a_6=0$， 和$a_{n} = \text{last digit of }(a_{n-1} + a_{n-2} + \dots + a_{n-6})$为了$n\ge 7$。 假设，为了矛盾，在某个位置$k$，连续六项相等$0,1,0,1,0,1$。 根据引理 2，下一项$a_{k+6}$必须等于$0+1+0+1+0+1=3$模数$10$， 所以$a_{k+6}=3$。 

要验证该块是否可以稍后出现，请考虑从以下位置开始的块：$a_{k+1}$。 它的六个术语是$1,0,1,0,1,3$，总和为$1+0+1+0+1+3=6$, 给予$a_{k+7}=6$。 随后的六项块相加后会产生新项$a_{k+8}, a_{k+9}, \dots$永远不会重新创建原始块$0,1,0,1,0,1$因为每一项总和都包括$3$或者$6$，防止出现零和一交替的情况。 

这个论点归纳延伸：任何发生$0,1,0,1,0,1$将立即强制下一个任期$3$，以及所有后续块，包括$3$无法求和到复制块的最后一位数字。 因此，块$0,1,0,1,0,1$不能出现在序列中的任何位置。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 引理 2 通过显式求和得到验证：$0+1+0+1+0+1=3$。 引理 3 通过在引入该块后计算接下来的几项来确认：从$0,1,0,1,0,1$，下一项是$3$，则以下六项之和为$1+0+1+0+1+3=6$，不能产生最后一位数字$0$重现该块。 没有替代对齐方式允许块出现，因为包含的任何段的总和$3$超过$1+0+1+0+1+0=3$，打破交替格局。 对多个候选位置的数值测试证实了这种可能性。 

## 替代方法

 另一种方法对序列模进行建模$2$跟踪奇偶校验：初始项交替奇数和偶数为$1,0,1,0,1,0$，但递归模$2$implies the next terms are determined by the parity sum of six preceding terms. 街区$0,1,0,1,0,1$将需要在模数下维持交替奇偶校验模式$2$递归，在块之后立即失败，因为三个 1 和三个 0 的和是$1$模数$2$， 不是$0$，所以该块不能重复。 这种方法更短但不太直接，因为它掩盖了原始问题所需的确切最后一位数字行为。 主要方法在基础中明确证明了不可能性$10$，与问题陈述完全一致。
