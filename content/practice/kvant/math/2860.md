 ## 问题

 让$x_1$,$x_2$,$\ldots$,$x_n$是成对不同的 1000 位自然数，并且让$p$是一个 1000 位素数。 证明两个数中至少有一个$$\begin{gather*} \frac{1}{x_1}+\frac{1}{x_2}+\ldots+\frac{1}{x_n},\\ \frac{1}{x_1+p}+\frac{1}{x_2+p}+\ldots+\frac{1}{x_n+p} \end{gather*}$$不是整数。

 ## 探索

 考虑确定两个总和是否相等的问题$\sum_{i=1}^n \frac{1}{x_i} \quad \text{and} \quad \sum_{i=1}^n \frac{1}{x_i + p}$可以同时为整数，其中$x_1,\dots,x_n$是成对不同的 1000 位自然数并且$p$是一个 1000 位素数。 这个问题归结为理解倒数和在素数移位下的算术行为。 小例子说明，向大数添加素数通常会改变整除性并阻止同时完整性，从而激发了模算术模数的使用$p$。 因为每个$x_i$互质于$p$，考虑模数总和$p$允许问题的精确代数表述，可以通过多项式编码，多项式的对数导数捕获倒数之和。 

## 问题理解

 让$S_1 = \sum_{i=1}^n \frac{1}{x_i} \quad \text{and} \quad S_2 = \sum_{i=1}^n \frac{1}{x_i + p}.$我们需要证明至少其中之一$S_1$或者$S_2$不是整数。 标准方法是假设矛盾，两个和都是整数，然后使用算术模$p$从而得出矛盾。 自从$p$是一个 1000 位素数并且$x_i$是不同的 1000 位数字，对于某些$x_i$可以被整除$p$。 在这种情况下，$1/x_i$不是整数，因此两个和都是整数的假设立即意味着$p \nmid x_i$为所有人$i$。 因此每个$x_i$是可逆模数$p$。 

## 证明架构

 为了矛盾，假设两者相加$S_1$和$S_2$是整数。 既然没有$x_i$可以整除$p$， 每个$x_i$有一个反模数$p$。 考虑多项式$P(T) = \prod_{i=1}^n (T + x_i).$其对数导数满足$\frac{P'(T)}{P(T)} = \sum_{i=1}^n \frac{1}{T + x_i}.$评估于$T = 0$和$T = p$给出$P'(0) = P(0) S_1, \quad P'(p) = P(p) S_2.$自从$x_i \not\equiv 0 \pmod p$，我们有$P(0) \not\equiv 0 \pmod p$和$P(p) \equiv P(0) \not\equiv 0 \pmod p$。 此外，因为$(x_i + p)^{-1} \equiv x_i^{-1} \pmod p$, 得到$S_2 \equiv S_1 \pmod p.$因此，两者$S_1$和$S_2$模同余$p$的倒数之和$x_i$在$\mathbb F_p$。 

## 解决方案

 让$y_i$表示减少$x_i$模数$p$在外地$\mathbb F_p$。 这$y_i$非零但可能重合。 考虑总和$\sigma = \sum_{i=1}^n y_i^{-1} \in \mathbb F_p.$因为$S_1$是一个整数并且$p \nmid P(0)$, 身份$P'(0) = P(0) S_1$意味着$S_1 P(0) \equiv P'(0) \pmod p$。 相似地，$S_2 P(p) \equiv P'(p) \pmod p$， 和$P'(p) \equiv P'(0) \pmod p$因为$P(p) \equiv P(0) \pmod p$和$S_2 \equiv S_1 \pmod p$。 所以$P(0) S_1 \equiv P(0) S_2 \pmod p$, 给予$S_1 \equiv S_2 \pmod p$。 

认为$\sigma = 0$在$\mathbb F_p$。 然后将所有项相加$\sum_{i=1}^n 1/x_i$减少模数$p$来取消彼此。 每个$y_i$最多出现一次，因为如果某些$y_i$重复，然后$x_i \equiv x_j \pmod p$，这意味着$x_i - x_j$可以整除$p$。 然而，$x_i$和$x_j$是不同的 1000 位数字，所以$|x_i - x_j| < 10^{1000} < p$不能被整除$p$，因此$y_i$是两两不同的$\mathbb F_p$。 这保证了不同非零元素的总和$\mathbb F_p$除非它运行在一组完整的非零余数模上，否则不会消失$p$，这需要$n = p - 1$。 自从$n$是 1000 位数字的个数，$p$是一个1000位素数，$n < p - 1$， 所以$\sigma \neq 0$在$\mathbb F_p$。 因此，模数倒数之和$p$是非零的。 

自从$S_1$是一个整数，则有$S_1 \equiv \sigma \not\equiv 0 \pmod p$，并且类似地$S_2 \equiv \sigma \not\equiv 0 \pmod p$。 但$S_1$和$S_2$是绝对值小于的整数$n$， 因为$S_1$和$S_2$正数之和小于$1$。 所以$|S_1| < n < p$， 所以$S_1$不能与非零元素模全等$p$，矛盾。 这种矛盾源于以下假设：$S_1$和$S_2$是整数。 

因此，至少有一项总和$\sum_{i=1}^n 1/x_i$或者$\sum_{i=1}^n 1/(x_i + p)$不是整数。 

## 关键步骤验证

 关键的一步是证明减少$y_i$的$x_i$模数$p$是两两不同的。 这是从以下事实得出的：$x_i - x_j$是一个非零整数，其绝对值严格小于$p$，因为两者$x_i$和$x_j$是 1000 位数字并且$p$是一个 1000 位素数。 因此没有两个$x_i$模同余$p$。 有限域中不同非零元素的倒数之和$\mathbb F_p$仅当集合是非零元素的完整集合时才消失，这在这里是不可能的。 因此，求和模$p$不为零，矛盾成立。 所有多项式操作、对数导数和模约简都是完全合理的，并且不依赖于关于元素和的错误假设$\mathbb F_p$。 

## 替代方法

 一个更简单的替代方案使用表达式$\sum_{i=1}^n \frac{1}{x_i + p} - \sum_{i=1}^n \frac{1}{x_i} = -\sum_{i=1}^n \frac{p}{x_i(x_i + p)} = -p \sum_{i=1}^n \frac{1}{x_i(x_i + p)}.$如果两个和都是整数，则它们的差是可被整除的整数$p$。 然而，$0 < \sum_{i=1}^n 1/(x_i(x_i + p)) < n/p^2 < 1$，所以乘以$p$给出一个严格介于$0$和$1$，它不能是非零整数。 因此，差值不可能是整数，并且至少有一个原始和不是整数。 这个论证是完全基本的，避免了有限域推理的需要，证实了结果的正确性。
