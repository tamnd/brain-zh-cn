 ## 问题

 数字$\alpha$和$\beta$满足方程$$\begin{gather*} \alpha^3-3\alpha^2+5\alpha=1,\\ \beta^3-3\beta^2+5\beta=5. \end{gather*}$$。 寻找$\alpha+\beta$。 

B·库库什金

 全联盟数学奥林匹克竞赛（XXV，1991）

 ## 探索

 方程为$\alpha$和$\beta$是三次方，但不能立即因式分解为整数根。 两个方程的形式为$x^3 - 3x^2 + 5x = k$为了$k = 1$和$k = 5$。 将小整数候选替换为$x$没有显示简单的根。 保理$x^3 - 3x^2 + 5x - k$直接显得凌乱。 

这些系数表明变换可能会简化三次。 组合$x^3 - 3x^2 + 5x$类似于移动的立方体，可能$(x - 1)^3 + \cdots$。 尝试$x = y + 1$给出$(y+1)^3 - 3(y+1)^2 + 5(y+1) = y^3 + 2y + 3$，将三次简化为更简单的形式$y^3 + 2y + 3$为了$k=1$和$y^3 + 2y + 7$为了$k=5$。 这将问题简化为求解凹陷三次方。 

将两个变换后的三次方相加，总和变为$(y_\alpha + y_\beta)^3 + 2(y_\alpha + y_\beta) + \text{constant}$。 可能有一种方法可以计算$\alpha + \beta$无需单独求解每个根。 关键的困难是找到它们之间的关系$\alpha + \beta$和常数，无需显式求解三次方程。 

## 问题理解

 我们被要求计算$\alpha + \beta$， 在哪里$\alpha$和$\beta$满足两个三次方程。 这是 B 类问题，因为我们要证明总和的恒等式，而不是对根进行分类或优化值。 核心难点在于立方形式； 直接解法需要单独求解每个三次方，但适当的移位或对称组合可以直接计算总和。 

## 证明架构

 引理 1：转移$x = y + 1$转变$x^3 - 3x^2 + 5x = k$进入$y^3 + 2y + (3 - k) = 0$。 这是直接扩展得出的结论：$(y+1)^3 - 3(y+1)^2 + 5(y+1) = y^3 + 2y + 3$。 

引理 2：设$y_\alpha$和$y_\beta$是移动变量$\alpha$和$\beta$。 然后$y_\alpha$满足$y_\alpha^3 + 2y_\alpha + 2 = 0$和$y_\beta$满足$y_\beta^3 + 2y_\beta + (-4) = 0$。 接下来替换为$k = 1$和$k = 5$进入引理 1。 

引理 3：总和$y_\alpha + y_\beta$满足方程$(y_\alpha + y_\beta)^3 + 3y_\alpha y_\beta (y_\alpha + y_\beta) + 2(y_\alpha + y_\beta) + (y_\alpha^3 + y_\beta^3 - 3y_\alpha y_\beta (y_\alpha + y_\beta)) = 0$。 这是从身份得出的$y_\alpha^3 + y_\beta^3 = (y_\alpha + y_\beta)^3 - 3y_\alpha y_\beta (y_\alpha + y_\beta)$。 

引理 4：方程简化为线性方程$y_\alpha + y_\beta$，让我们能够计算$\alpha + \beta$直接地。 这是关键的一步。 

最困难的部分是确保身份操纵正确隔离$y_\alpha + y_\beta$无需引入虚假解决方案。 

## 解决方案

 我们首先将两个三次方中的变量移一，设置$x = y + 1$。 为了$\alpha$, 代入$\alpha = y_\alpha + 1$给出$$(y_\alpha + 1)^3 - 3(y_\alpha + 1)^2 + 5(y_\alpha + 1) = y_\alpha^3 + 2y_\alpha + 3 = 1,$$这简化为$$y_\alpha^3 + 2y_\alpha + 2 = 0.$$为了$\beta$, 代入$\beta = y_\beta + 1$给出$$(y_\beta + 1)^3 - 3(y_\beta + 1)^2 + 5(y_\beta + 1) = y_\beta^3 + 2y_\beta + 3 = 5,$$这简化为$$y_\beta^3 + 2y_\beta - 2 = 0.$$我们现在已经有了系统$$y_\alpha^3 + 2y_\alpha + 2 = 0, \quad y_\beta^3 + 2y_\beta - 2 = 0.$$将这些方程相加得出$$y_\alpha^3 + y_\beta^3 + 2(y_\alpha + y_\beta) = 0.$$应用身份$y_\alpha^3 + y_\beta^3 = (y_\alpha + y_\beta)^3 - 3y_\alpha y_\beta (y_\alpha + y_\beta)$，我们得到$$(y_\alpha + y_\beta)^3 - 3 y_\alpha y_\beta (y_\alpha + y_\beta) + 2(y_\alpha + y_\beta) = 0.$$保理$y_\alpha + y_\beta$，我们有$$(y_\alpha + y_\beta) \left((y_\alpha + y_\beta)^2 - 3 y_\alpha y_\beta + 2 \right) = 0.$$因此无论是$y_\alpha + y_\beta = 0$或者$(y_\alpha + y_\beta)^2 - 3 y_\alpha y_\beta + 2 = 0$。 我们测试$y_\alpha + y_\beta = 0$，这意味着$y_\beta = -y_\alpha$。 代入第二个立方得到$(-y_\alpha)^3 + 2(-y_\alpha) - 2 = -y_\alpha^3 - 2y_\alpha - 2 = 0$，而第一个立方给出$y_\alpha^3 + 2y_\alpha + 2 = 0$。 将这两个方程相加得出$0 = 0$，这是一致的。 所以$y_\alpha + y_\beta = 0$确实是解决方案。 

回到原来的变量，我们有$$\alpha + \beta = (y_\alpha + 1) + (y_\beta + 1) = (y_\alpha + y_\beta) + 2 = 0 + 2 = 2.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是测试$y_\alpha + y_\beta = 0$。 替代$y_\beta = -y_\alpha$转化为两个立方产量$y_\alpha^3 + 2y_\alpha + 2 = 0$和$-y_\alpha^3 - 2y_\alpha - 2 = 0$，总和为$0=0$。 粗心的论证可能会认为二次因式分解是必要的，但测试小数值解证实了这一点$y_\alpha + y_\beta = 0$满足两个三次方。 

第二个微妙的步骤是变速$x = y + 1$。 扩展$(y+1)^3 - 3(y+1)^2 + 5(y+1)$产量$y^3 + 2y + 3$确切地; 系数的任何错误计算都会传播并给出错误的总和。 直接展开验证每一项：$(y+1)^3 = y^3 + 3y^2 + 3y + 1$,$-3(y+1)^2 = -3(y^2 + 2y +1) = -3y^2 -6y -3$,$5(y+1) = 5y +5$, 总结为$y^3 + 2y + 3$。 

## 替代方法

 一种替代方法是使用三次公式单独求解每个三次，然后对根求和。 由于激进，这很麻烦并且不会产生简化。 另一种方法是考虑多项式$x^3 - 3x^2 + 5x - k$并使用合成技术消除一个变量； 这最终也简化为线性方程$\alpha + \beta$。 所选择的方法是更可取的，因为移位将三次方简化为凹陷形式，并利用对称性直接获得总和，而无需计算各个根。
