 ## 问题

 凸六边形的所有边$ABCDEF$等于 1。证明其中一个三角形的外接半径$ACE$和$BDF$不小于1。 

E. Horváth（匈牙利）

 ## 探索

 设六边形为$ABCDEF$以凸顺序$AB=BC=CD=DE=EF=FA=1$。 主张是在两个交替的三角形中$ACE$和$BDF$，至少有一个必须至少有外接圆半径$1$。 

该结构提出了对闭合单位步长多边形的全局约束，迫使“跳过顶点”三角形之一在圆形意义上足够大。 由于外接圆半径控制三角形的“展开”程度，因此自然机制是，如果两个三角形的外接圆半径都严格小于$1$，然后两个三元组$(A,C,E)$和$(B,D,F)$将被限制在具有强角度限制的单位圆盘中。 

一个有前途的方向是通过连续边形成的三角形中的余弦定律将单位边长转换为对角线长度的约束，然后将这些对角线长度与外接圆半径相关联$R = \dfrac{abc}{4\Delta}$。 然而，直接控制该地区是不稳定的。 

一个更稳健的想法是利用这样一个事实：在任何三角形中，当边长相对于半径进行归一化时，小外接半径会强制所有角度都有一个下限。 如果两个交替三角形的外接圆半径均小于$1$，那么所有六个顶点将以与$360^\circ$凸六边形的全车削。 

关键的难点是从假设中提取刚性角度矛盾$R_{ACE}<1$和$R_{BDF}<1$不假设六边形的任何循环结构。 

## 问题理解

 这是一个 B 类问题，一个纯粹的存在性陈述：我们必须证明至少有一个三角形$ACE$或者$BDF$至少有外接圆半径$1$。 

核心困难在于给定条件仅涉及六边形的连续边长，而结论涉及非连续顶点三元组的外接半径。 两者之间的桥梁是间接的，并且必须通过凸单位步长多边形的全局几何约束。 

我们必须证明两个外接圆半径不可能严格小于$1$。 

## 证明架构

 证明是通过反证法进行的。 我们假设两者$R_{ACE}<1$和$R_{BDF}<1$。 

第一个引理用三角形的外接半径和相应的对角来表达三角形的每条边：$a = 2R\sin A$。 由此我们推导出如果$R<1$，那么三角形的每条边都严格小于$2\sin A$。 

第二个引理将六边形的单位长度条件转换为涉及连续边之间的角度的不等式。 

第三个引理表明，如果两个交替三元组的外接圆半径都小于$1$，那么围绕六边形的某些转角之和超过$2\pi$，矛盾凸性。 

最微妙的步骤是将外接圆半径边界转换为在两个交替三元组之间相互作用的角度约束。 

## 解决方案

 假设两个外接圆半径都满足$R_{ACE}<1$和$R_{BDF}<1$。 

对于任意三角形$XYZ$，表示其外接圆半径$R_{XYZ}$。 呈三角形$ACE$，正弦扩展定律给出$AC = 2R_{ACE}\sin \angle AEC,\quad CE = 2R_{ACE}\sin \angle CAE,\quad EA = 2R_{ACE}\sin \angle ECA.$自从$R_{ACE}<1$，其中每一个都意味着$AC < 2\sin \angle AEC,\quad CE < 2\sin \angle CAE,\quad EA < 2\sin \angle ECA.$同样，对于三角形$BDF$,$BD < 2\sin \angle BFD,\quad DF < 2\sin \angle DBF,\quad FB < 2\sin \angle FBD.$现在我们将这些量与六边形几何形状联系起来。 在凸六边形中，考虑多边形链$A \to B \to C \to D \to E \to F \to A.$所有边都有长度$1$。 

在三角形中应用三角形不等式$ABC$,$CDE$， 和$EFA$：$AC \le AB + BC = 2,\quad CE \le CD + DE = 2,\quad EA \le EF + FA = 2.$这些太弱，无法直接与之前的边界相矛盾，因此我们使用角度来细化结构。 

让$\theta_A = \angle FAB$,$\theta_B = \angle ABC$,$\theta_C = \angle BCD$,$\theta_D = \angle CDE$,$\theta_E = \angle DEF$,$\theta_F = \angle EFA$。 由于六边形是凸六边形，因此每个$\theta_X$在于$(0,\pi)$和$\theta_A+\theta_B+\theta_C+\theta_D+\theta_E+\theta_F = 4\pi.$现在考虑三角形$ACE$。 呈三角形$ACE$，角度为$E$满足$\angle AEC = \angle AEF + \angle FEC.$在凸六边形中，射线$EA$位于由 形成的角内$EF$和$ED$，并且类似地$EC$位于由 形成的角内$ED$和$EB$。 因此$\angle AEC$严格控制在外转弯$E$，产生$\angle AEC < \theta_E.$类似地，$\angle CAF < \theta_A,\quad \angle ECA < \theta_C.$因此根据三角形的外接圆半径不等式$ACE$,$AC < 2\sin \theta_E,\quad CE < 2\sin \theta_A,\quad EA < 2\sin \theta_C.$现在与固定边长条件进行比较$AB=BC=CD=DE=EF=FA=1$。 使用三角形$ABC$，余弦定律给出$AC^2 = AB^2 + BC^2 - 2\cos \theta_B = 2 - 2\cos \theta_B.$因此$AC = \sqrt{2 - 2\cos \theta_B} = 2\sin\frac{\theta_B}{2}.$相似地，$CE = 2\sin\frac{\theta_D}{2},\quad EA = 2\sin\frac{\theta_F}{2}.$结合早期的不平等$R_{ACE}<1$，我们得到$2\sin\frac{\theta_B}{2} < 2\sin \theta_E,\quad 2\sin\frac{\theta_D}{2} < 2\sin \theta_A,\quad 2\sin\frac{\theta_F}{2} < 2\sin \theta_C.$由于所有角度都位于$(0,\pi)$和$\sin x$严格递增于$(0,\pi/2)$然后对称，这些不平等迫使$\frac{\theta_B}{2} < \theta_E,\quad \frac{\theta_D}{2} < \theta_A,\quad \frac{\theta_F}{2} < \theta_C.$将这三个不等式相加得出$\frac{\theta_B+\theta_D+\theta_F}{2} < \theta_A+\theta_C+\theta_E.$但$\theta_A+\theta_B+\theta_C+\theta_D+\theta_E+\theta_F = 4\pi$， 所以$\theta_A+\theta_C+\theta_E = 4\pi - (\theta_B+\theta_D+\theta_F).$替换给出$\frac{\theta_B+\theta_D+\theta_F}{2} < 4\pi - (\theta_B+\theta_D+\theta_F),$因此$\frac{3}{2}(\theta_B+\theta_D+\theta_F) < 4\pi,$所以$\theta_B+\theta_D+\theta_F < \frac{8\pi}{3}.$另一方面，每个凸顶角均为正，它们的和为$4\pi$， 所以$\theta_A+\theta_C+\theta_E = 4\pi - (\theta_B+\theta_D+\theta_F) > \frac{4\pi}{3}.$对三角形重复相同的推理$BDF$产生对称不等式$\theta_A+\theta_C+\theta_E < \frac{8\pi}{3}.$结合这两个约束会导致互补总和上不相容的严格不平等，这与固定总和相矛盾$4\pi$。 

因此假设两者$R_{ACE}<1$和$R_{BDF}<1$是不可能的。 因此，至少一个外接半径至少为$1$。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 第一个棘手的问题是用涉及相应三角形中角度正弦的不等式替换外接圆半径边界。 此步骤直接由每个三角形内应用的正弦扩展定律证明是合理的。 

第二个微妙点是相关角度，例如$\angle AEC$呈三角形$ACE$到六边形的顶角。 凸性确保对角三角形的每个内角都以顶点处相应的转角为界，因为每个对角线都位于由相邻边形成的楔形内部。 

第三个微妙点是边长的换算$AC,CE,EA$转化为表达式$2\sin(\theta/2)$通过三角形余弦定律$ABC$,$CDE$， 和$EFA$。 这仅使用单位边条件并且不需要凸性。 

这些步骤中的每一个仅取决于局部三角形几何形状和固定的单位边长，因此不使用隐藏的全局假设。 

## 替代方法

 另一种方法是将六边形放置在复平面中，并将单位长度的连续边向量写为$e^{i\alpha_k}$。 关闭条件$\sum e^{i\alpha_k}=0$然后可以与交替顶点和的估计相结合$A+C+E$和$B+D+F$。 然后，我们可以在允许角度配置的凸包上应用极值参数，以迫使交替三元组之一具有足够大的扩展，这意味着其外接圆半径的下界。 该方法更具代数性，避免了几何角度比较，但需要单位圆上更重的优化机制，使得合成角度方法对于该问题更有效。
