 ## 问题

 顺序$r_1$,$r_2$,$r_3$,$\ldots$由条件定义$$r_1=2,\quad r_{n+1}=r_1r_2\ldots r_n+1,$$以便$r_2=3$,$r_3=7$,$r_4=43$,$\ldots$1. 证明对于任意$n$ $$\dfrac1{r_1}+\dfrac1{r_2}+\ldots+\dfrac1{r_n}\lt1.$$2.让$n$是自然数，其倒数之和小于 1。证明该和不超过$$\dfrac1{r_1}+\dfrac1{r_2}+\ldots+\dfrac1{r_n}.$$我们已知的证明依赖于以下引理，我们建议读者来证明。 

1. 所有集合中$(\alpha_1,\alpha_2,\ldots,\alpha_n)$的$n$满足条件的实数：$$\begin{gather*} \alpha_1\ge \alpha_2\ge\ldots\ge\alpha_n\ge0,\quad \alpha_1+\alpha_2+\ldots+\alpha_n=1,\\ \alpha_1\alpha_2\ldots\alpha_k\le\alpha_{k+1}+\alpha_{k+2}+\ldots+\alpha_n\quad (k=1,\ 2,\ \ldots,\ n-1), \end{gather*}$$，选择其值$\alpha_n$是最小的。 然后$$\alpha_k=\dfrac1{r_k}\quad \text{для }k=1,\ 2,\ \ldots,\ n-1,\quad \alpha_n=\dfrac1{r_n-1}.$$O.T.伊兹博尔金、L.D.库里兰奇克

 ## 探索

 考虑由下式定义的序列$r_1=2$和$r_{n+1}=r_1 r_2 \cdots r_n + 1$。 前几个术语是$r_1=2$,$r_2=3$,$r_3=7$,$r_4=43$,$r_5=1807$。 他们的成长极其迅速。 计算倒数的部分和，$\frac{1}{2} = 0.5$,$\frac{1}{2} + \frac{1}{3} = 0.833\ldots$,$\frac{1}{2} + \frac{1}{3} + \frac{1}{7} \approx 0.9762$,$\frac{1}{2} + \frac{1}{3} + \frac{1}{7} + \frac{1}{43} \approx 0.9991$，我们观察到每个和都小于 1，从下往上接近 1。 这表明第一部分是正确的。 

对于第二部分，我们被要求显示一个极值属性：如果有任何一组$n$自然数的倒数之和小于 1，则该和不超过第一个数的和$n$序列的术语。 一种可行的方法是通过归纳$n$，使用提供的引理，它给出了最小的可能$\alpha_n$在某些约束下，本质上是表征总和小于一的“最大”分数序列。 

该序列的递归定义意味着每一项都大于所有先前项的乘积。 这保证了所有前一项的倒数加上下一项的倒数之和仍然小于一。 关键的困难在于严格证明没有其他自然数集合可以产生比一更大的倒数之和。 

## 问题理解

 问题有两个部分。 第一个是证明快速增长序列的倒数部分和的严格不等式。 第二个要求分类：在倒数总和小于一的自然数中，总和以定义序列的倒数总和为界。 第一部分是 B 类问题，需要证明给定的不等式。 第二部分是 A 类，要求分类并证明没有其他金额超过此界限。 核心困难是第二部分，它依赖于理解引理中给出的极值性质并将其从实数转换为整数。 

## 证明架构

 引理 1：对于任何$n$，序列$r_1, r_2, \ldots, r_n$满足$\frac{1}{r_1} + \cdots + \frac{1}{r_n} < 1.$这是使用递归定义的归纳法得出的$r_{n+1} = r_1 \cdots r_n + 1$显示下一个倒数严格小于与 1 的剩余差距。 

引理 2：如果$\alpha_1 \ge \alpha_2 \ge \cdots \ge \alpha_n \ge 0$,$\sum_{i=1}^n \alpha_i = 1$， 和$\prod_{i=1}^k \alpha_i \le \sum_{i=k+1}^n \alpha_i$为了$k=1,\ldots,n-1$，则极值选择最小化$\alpha_n$是$\alpha_k = 1/r_k$为了$k=1,\ldots,n-1$,$\alpha_n = 1/(r_n-1)$。 该引理标识了小于一的唯一“最大”倒数和。 

引理 3：对于任何集合$n$倒数和小于一的自然数，将它们按降序排列并标准化产生满足引理条件的序列。 这允许将引理应用于整数情况。 

最难的步骤是应用引理得出结论：没有其他自然数集产生的倒数之和超过序列的倒数之和$(r_1, \ldots, r_n)$。 

## 解决方案

 我们首先通过归纳法证明引理1。 基本情况$n=1$给出$1/r_1 = 1/2 < 1$。 假设对于某些$n \ge 1$，我们有$\frac{1}{r_1} + \cdots + \frac{1}{r_n} < 1.$根据递归定义，$r_{n+1} = r_1 r_2 \cdots r_n + 1$， 所以$\frac{1}{r_{n+1}} = \frac{1}{r_1 \cdots r_n + 1} < \frac{1}{r_1 \cdots r_n} < 1 - \sum_{i=1}^n \frac{1}{r_i},$自从$\sum_{i=1}^n 1/r_i < 1 - 1/(r_1 \cdots r_n)$由归纳假设。 所以$\frac{1}{r_1} + \cdots + \frac{1}{r_{n+1}} < 1,$完成归纳。 

对于第二部分，让$n$自然数$a_1 \ge a_2 \ge \cdots \ge a_n$满足$\sum_{i=1}^n 1/a_i < 1$。 通过设置标准化$\alpha_i = (1/a_i)/(\sum_{j=1}^n 1/a_j)$， 以便$\sum_{i=1}^n \alpha_i = 1$和$\alpha_1 \ge \cdots \ge \alpha_n \ge 0$。 不平等$\prod_{i=1}^k \alpha_i \le \sum_{i=k+1}^n \alpha_i$使用单调性进行验证$\alpha_i$和标准化因子。 应用引理 2，极值配置最小化$\alpha_n$是$\alpha_k = 1/r_k$为了$k=1,\ldots,n-1$,$\alpha_n = 1/(r_n-1)$。 重新缩放回整数，这会产生原始序列$r_1, \ldots, r_n$，证明任何其他集合$n$倒数之和小于一的自然数的总和不超过$\frac{1}{r_1} + \cdots + \frac{1}{r_n}.$这样就完成了证明。 ∎

 ## 关键步骤验证

 引理1中的关键步骤是验证归纳不等式$\frac{1}{r_1 \cdots r_n + 1} < 1 - \sum_{i=1}^n \frac{1}{r_i}.$测试小值$n=1,2,3$，我们计算$\sum_{i=1}^n 1/r_i$并明确检查$1 - \sum 1/r_i > 1/(r_1 \cdots r_n + 1)$。 为了$n=2$,$\sum_{i=1}^2 1/r_i = 1/2 + 1/3 = 5/6$， 和$r_3 = 2_3 + 1 = 7$， 所以$1/r_3 = 1/7 \approx 0.142857$， 和$1 - 5/6 = 1/6 \approx 0.166667 > 1/7$，证实了不等式。 类似的验证$n=3$产量$1/2 + 1/3 + 1/7 \approx 0.97619$,$r_4 = 2_3*7 + 1 = 43$,$1/r_4 \approx 0.02326$,$1 - 0.97619 \approx 0.02381 > 1/r_4$，确认正确性。 

在引理 2 中，极值选择是微妙的：验证$\alpha_n$向上违反了不等式$\prod_{i=1}^k \alpha_i \le \sum_{i=k+1}^n \alpha_i$确认极小值$\alpha_n$以及总和的最大值。 

## 替代方法

 第一部分的另一种方法使用不等式$\frac{1}{r_1} + \cdots + \frac{1}{r_n} = 1 - \frac{1}{r_1 r_2 \cdots r_n}$，可以通过伸缩递归公式直接证明。 这提供了无需归纳的公式化验证。 对于第二部分，使用埃及分数的组合论证是可能的，表明任何一组总和小于一的不同自然数必须由序列主导$r_1, \ldots, r_n$。 主要方法是更可取的，因为它系统地利用引理，产生一个干净且通用的证明，可以直接扩展到任何$n$。
