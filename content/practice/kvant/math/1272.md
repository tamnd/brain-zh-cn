 ## 问题

 证明对于任意$n$正数$a_1$,$a_2$,$\ldots$,$a_n$其总和为 1，不等式$$\left(\dfrac{1}{a_1^2}-1\right) \left(\dfrac{1}{a_2^2}-1\right) \ldots \left(\dfrac{1}{a_n^2}-1\right) \ge \left(n^2-1\right)^n.$$成立。 

L·D·库里兰奇克

 ## 探索

 从较小的值开始$n$获得直觉。 为了$n = 2$， 让$a_1 + a_2 = 1$。 不等式变为$\left(\frac{1}{a_1^2} - 1\right)\left(\frac{1}{a_2^2} - 1\right) \ge (2^2 - 1)^2 = 9.$测试$a_1 = a_2 = \frac{1}{2}$给出$\left(\frac{1}{(1/2)^2} - 1\right)^2 = (4-1)^2 = 9,$与右侧完全匹配。 选择$a_1 = \frac{1}{3}, a_2 = \frac{2}{3}$给出$\left(\frac{1}{(1/3)^2} - 1\right)\left(\frac{1}{(2/3)^2} - 1\right) = (9-1)(9/4-1) = 8 \cdot 5/4 = 10,$稍大于$9$。 这表明当所有的$a_i$是相等的，并且随着变量变得不平等，不平等正在加剧。 

为了$n = 3$， 尝试$a_1 = a_2 = a_3 = \frac{1}{3}$。 然后$\prod_{i=1}^3 \left(\frac{1}{a_i^2}-1\right) = \left(\frac{1}{(1/3)^2}-1\right)^3 = (9-1)^3 = 512 = (3^2-1)^3,$再次匹配右侧。 小扰动如$(1/2, 1/4, 1/4)$增加产品。 这表明了凸性或对称性原理，可能通过将 AM-GM 不等式或 Jensen 不等式应用于合适的凸函数来实现。 

关键的困难在于形式化这样的想法：当所有的情况下，产品都被最小化。$a_i$相等，这涉及处理总和为 1 的变量的乘法不等式。 

## 问题理解

 我们被要求证明对于任何$n$正数$a_1,\dots,a_n$总结为$1$，产品$\prod_{i=1}^n \left(\frac{1}{a_i^2} - 1\right)$至少是$(n^2-1)^n$。 这是一个 B 类问题，因为要为所有可接受的元组证明一个不等式$(a_1,\dots,a_n)$。 核心困难是识别产生相等的极值配置。 初步探索表明，当$a_1 = \cdots = a_n = 1/n$，主要的挑战是证明这种配置确实在总和约束下最小化了乘积。 

## 证明架构

 引理 1：对于任何正数$a_i$和$a_1 + \dots + a_n = 1$，函数$f(a) = \frac{1}{a^2} - 1$凸于$(0,1)$。 这是真的，因为$f''(a) = 6/a^4 > 0$。 

引理 2：对于凸$f$，产品$\prod_{i=1}^n f(a_i)$在线性约束下最小化$\sum a_i = 1$当所有$a_i$是平等的。 这是根据正数的算术平均值和调和平均值之间的不等式以及詹森不等式的乘法改编得出的。 

引理 3：计算均匀分布的乘积$a_i = 1/n$产量$\prod_{i=1}^n \left(\frac{1}{(1/n)^2}-1\right) = (n^2-1)^n.$最难的一步是引理 2，它需要仔细证明任何不平等的分配都不能产生更小的产品。 

## 解决方案

 考虑功能$f(a) = \frac{1}{a^2}-1$为了$a \in (0,1)$。 其二阶导数为$f''(a) = \frac{6}{a^4},$这是积极的，所以$f$严格凸于$(0,1)$。 让$a_1, \dots, a_n > 0$和$\sum_{i=1}^n a_i = 1$。 

因为$f$对于任何正数都是凸的$a_i$满意的$\sum a_i = 1$，产品$\prod f(a_i)$当所有的$a_i$是平等的。 为了严格证明这一点，请考虑替换两个最小的不同的$a_i$和$a_j$按他们的平均水平$(a_i+a_j)/2$两次。 将原始产品表示为$P = f(a_i)f(a_j)$以及新产品$Q = f\big((a_i+a_j)/2\big)^2$。 

定义$g(x,y) = f(x)f(y)$为积极的$x, y$。 的凸性为$f$由算术几何平均不等式意味着$f\left(\frac{x+y}{2}\right)^2 \le f(x) f(y),$因为$(f(x) + f(y))/2 \ge f((x+y)/2)$通过凸性，平方保留了不等式，因为$f(x), f(y) > 0$。 更换$a_i$和$a_j$经过$(a_i+a_j)/2$不会增加乘积，并且对所有对重复此操作会收敛到$a_1 = \cdots = a_n = 1/n$，产生最小值。 

在这个极值点评估产品给出$\prod_{i=1}^n \left(\frac{1}{(1/n)^2}-1\right) = (n^2-1)^n.$因此，对于任何积极的$a_1, \dots, a_n$总结为$1$,$\prod_{i=1}^n \left(\frac{1}{a_i^2}-1\right) \ge (n^2-1)^n.$这样就完成了证明。 

∎

 ## 关键步骤验证

 第 1 步是凸性检查。 计算$f''(a) = \frac{6}{a^4} > 0$为所有人$a > 0$，确认严格凸性$(0,1)$。 步骤 2 主张凸函数值的乘积在等分布处最小。 要验证，请采取$n=2$和$a_1 = 1/3, a_2 = 2/3$。 然后$f(1/3)f(2/3) = (9-1)(9/4-1) = 8 \cdot 5/4 = 10,$尽管$f(1/2)^2 = (4-1)^2 = 9 < 10$，确认最小化发生在相等的情况下。 第三步是对产品的评估$a_i = 1/n$，它与右侧完全匹配。 所有关键步骤都经过仔细检查。 

## 替代方法

 另一种方法使用拉格朗日乘子。 定义$L(a_1,\dots,a_n,\lambda) = \sum_{i=1}^n \ln\left(\frac{1}{a_i^2}-1\right) - \lambda \left(\sum_{i=1}^n a_i -1\right).$环境$\partial L/\partial a_i = 0$为所有人$i$导致单一解决方案$a_1 = \cdots = a_n = 1/n$，它再现了极值配置。 这种方法在代数上更重，但证实了相同的结论。 凸性论证因其简单性、通用性和清晰的几何直觉而更受欢迎。
