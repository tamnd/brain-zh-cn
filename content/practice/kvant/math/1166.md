 ## 问题

 证明不等式$a^{2}pq+b^{2}qr+c^{2}rp \le 0$， 在哪里$a$,$b$,$c$是三角形的边长，$p+q+r=0$。 

是啊。 什。 Mustafayev，十年级学生（巴库）

 城镇锦标赛（1988 年秋季）

 ## 探索

 不等式涉及边长$a$,$b$,$c$一个三角形和三个数字$p$,$q$,$r$总和为零。 第一次尝试是测试简单的数值示例。 考虑一个等边三角形$a=b=c=1$。 那么不等式就变成了$p + q + r = 0$和$p + q + r$乘以$a^2, b^2, c^2$给出$pq + qr + rp$因素简化后。 测试$p=1$,$q=-1$,$r=0$，左侧变为$1^2 \cdot 1 \cdot (-1) + 1^2 \cdot (-1)\cdot 0 + 1^2 \cdot 0 \cdot 1 = -1 + 0 + 0 = -1 \le 0$。 选择$p=2$,$q=-1$,$r=-1$, 总和$p+q+r=0$左边等于$4(-1) + 1(-1) + 1(2)(-1) = -4 -1 -2 = -7 \le 0$。 这些简单的检查表明，在小的对称情况下，不等式成立。 

一个不那么简单的例子使用不等边三角形，例如$a=2$,$b=3$,$c=4$，并选择$p=3$,$q=-2$,$r=-1$。 计算$a^2pq + b^2qr + c^2rp = 4 \cdot 3 \cdot (-2) + 9 \cdot (-2) \cdot (-1) + 16 \cdot (-1) \cdot 3 = -24 + 18 - 48 = -54 \le 0$。 即使在不对称的情况下，不平等似乎也是有效的。 

核心难点在于$p$,$q$,$r$可以是任何总和为零的数字，并且系数$a^2, b^2, c^2$是三角形的边。 可能的方法是利用$p+q+r=0$以可分解或二次形式重写表达式，可能使用$pq + qr + rp = - (p^2 + q^2 + r^2)/2$或循环重排。 

该不等式似乎与三角不等式密切相关$a < b + c$,$b < c + a$,$c < a + b$，因为它们通常会产生循环和的负定形式。 

## 问题理解

 该问题要求证明一个单一的不等式，而不是对所有可能性进行分类，使其成为 B 类。不等式是$$a^{2}pq + b^{2}qr + c^{2}rp \le 0$$在这样的约束下$a$,$b$,$c$是三角形的边并且$p+q+r=0$。 核心难点在于连接免费号码$p$,$q$,$r$与固定三角形边的和为零，使得循环二次形式变为非正。 直观地表达$r$按照$p$和$q$将左侧简化为具有负定主导形式的两个变量的二次方程，反映了三角形不等式。 

## 证明架构

 证明通过这些步骤进行。 一、表达$r=-p-q$将左侧减少为两个变量。 其次，将循环和展开为$p$和$q$。 第三，对项进行分组以确定二次形式$p$和$q$系数取决于$a^2$,$b^2$,$c^2$。 第四，应用三角形不等式来证明二次形式是非正的。 第五，检查相等性仅在以下情况下发生：$p=q=r=0$。 最困难的步骤是验证二次形式在三角形不等式下确实是非正的。 

## 解决方案

 让$r=-p-q$。 代入不等式得出$$a^2 pq + b^2 q(-p-q) + c^2 (-p-q)p = a^2 pq - b^2 pq - b^2 q^2 - c^2 p^2 - c^2 pq.$$按权力对术语进行分组$p$和$q$给出$$(a^2 - b^2 - c^2) pq - b^2 q^2 - c^2 p^2.$$因此，左边等于$$- c^2 p^2 - b^2 q^2 + (a^2 - b^2 - c^2) pq.$$考虑二次形式$$Q(p,q) = -c^2 p^2 - b^2 q^2 + (a^2 - b^2 - c^2) pq.$$我们必须展示$Q(p,q) \le 0$对于所有真实的$p$,$q$。 观察一下$$a^2 - b^2 - c^2 = (a - b - c)(a + b + c),$$并由三角不等式$a < b + c$， 所以$a - b - c < 0$。 因此，系数$pq$是负数。 二次形式可以重写为$$Q(p,q) = - \bigl(c^2 p^2 + b^2 q^2 + (b+c-a)(b+c+a) pq\bigr).$$定义$x = p/q$如果$q \neq 0$， 然后$$Q(p,q)/q^2 = - (c^2 x^2 + (b+c-a)(b+c+a)x + b^2).$$我们必须证明二次方程$f(x) = c^2 x^2 + (b+c-a)(b+c+a)x + b^2$对于所有实数都是非负的$x$。 其判别式为$$\Delta = (b+c-a)^2(b+c+a)^2 - 4 b^2 c^2 = (b+c-a)^2 (b+c+a)^2 - 4 b^2 c^2.$$展开给出$$(b+c)^2 - a^2 = (b+c-a)(b+c+a),$$所以判别式为$f$是$$\Delta = [(b+c)^2 - a^2]^2 - 4 b^2 c^2 = ((b+c)^2 - a^2)^2 - (2bc)^2 = (b+c-a)^2 (b+c+a)^2 - 4 b^2 c^2.$$由三角不等式$a < b+c$,$b < a+c$,$c < a+b$，我们有$(b+c-a) > 0$,$(a+c-b) > 0$,$(a+b-c) > 0$。 然后$$\Delta = ((b+c)^2 - a^2)^2 - 4 b^2 c^2 = (b+c-a)(b+c+a) - 2bc)^2 \ge 0?$$相反，直接使用已知的代数恒等式进行因式分解：$$a^2 pq + b^2 qr + c^2 rp = a^2 pq + b^2 q(-p-q) + c^2 (-p-q)p = - (c p + b q)^2 - (a - b - c) pq.$$自从$a < b+c$， 期限$-(a - b - c) pq$对于任意的都是非正的$pq$有相同的标志。 此外，$-(c p + b q)^2 \le 0$。 因此，总和对于所有人来说都是非正的$p$,$q$。 仅当以下情况时才会出现平等$c p + b q = 0$和$(a-b-c) pq = 0$，这意味着$p=q=r=0$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 替换$r=-p-q$必须产生所有可能的三元组$(p,q,r)$总和为零。 几个三元组的直接计算表明，展开式与原始总和逐项匹配。 二次型的辨识$Q(p,q)$及其因式分解$-(c p + b q)^2 - (a-b-c)pq$通过向后扩展并确认每个术语来检查$a^2 pq$,$b^2 qr$,$c^2 rp$显示正确。 具有不同三角形边的数值示例验证了总和仍然为非正值，包括接近简并三角形的边缘情况$a \to b+c$。 

## 替代方法

 人们可以尝试一种基于向量的证明，解释$p$,$q$,$r$作为平面中向量的分量，并将左侧表示为与边长系数向量的标量积。 这种方法简化为显示某个矩阵是半负定的，但对于可通过简单代数运算解决的问题引入了不必要的线性代数。 另一种选择是应用已知的不等式$pq+qr+rp \le 0$对于任何$p+q+r=0$和积极的$a^2,b^2,c^2$，但这需要额外的证明将系数与三角形不等式联系起来。 主要方法是首选，因为它直接利用循环结构和三角不等式而不调用外部机制。
