 ## 问题

 考虑所有四面体$AXBY$限制在给定的球体范围内。 证明对于不动点$A$和$B$, 四边形的内角和$AXBY$，即总和$$\angle AXB+\angle XBY+\angle BYA+\angle YAX,$$，不依赖于点的选择$X$和$Y$。 

I.F.沙里金

 ## 探索

 考虑一个四面体$AXBY$外接有不动点的球体$A$和$B$。 要点$X$和$Y$可以沿着球体的相切约束滑动，因此四面体的形状会发生变化，同时保持外接状态。 所讨论的总和是四边形的四个面角的总和$AXBY$，按顺序围绕四边形进行。 使用任意坐标的直接计算看起来很混乱，因为每个顶点的位置非线性地取决于相切条件。 

一项观察结果是，对于外接球体的四面体，由于相切点，相对的边满足某些等式。 这表明对称性可能导致角度和不变。 将四面体视为共享对角线的两个三角形 ($AB$), 周围角度的总和$A$和$B$似乎让人想起球面过剩公式或平面四边形角和。 关键的困难是在不指定的情况下证明不变性$X$和$Y$，仅依靠相切条件和固定$A$和$B$。 

## 问题理解

 我们被要求证明在所有四面体中$AXBY$围绕一个固定球体外接，$A$和$B$固定，总和$\angle AXB+\angle XBY+\angle BYA+\angle YAX$保持不变，无论$X$和$Y$。 这是一个 B 类问题，因为它需要一个陈述的证明。 核心困难在于不依赖于特定坐标，仅使用相切属性来表达或推理角度。 这种不变性可能是由于外接四面体的边长约为$A$和$B$满足由切球确定的线性关系，因此某些角度和保持不变。 

## 证明架构

 引理 1：在球体外接四面体中，相对边的长度之和相等，即$AX + BY = AY + BX$。 这是因为从每个顶点到球体的切线长度相等。 

引理 2：顶点角度之和$A$和$B$围绕连接到的边缘$X$和$Y$可以用边长来表示，并且不依赖于特定的位置$X$和$Y$因为相对边的和是恒定的。 

引理 3：四边形周围四个角的和$AXBY$等于平面角度的总和$A$和$B$，仅由固定边和决定，因此是不变的。 

最难的步骤是引理 2，因为它需要将边长度约束从相切连接到角度和的不变性。 最有可能在审查下失败的引理是任何假设的论证$X$和$Y$可以独立选择，无需考虑球体的相切条件。 

## 解决方案

 让四面体$AXBY$被切点外接球体$P$,$Q$,$R$,$S$在脸上$AXY$,$ABX$,$BYX$,$BAY$分别。 对于外接四面体，从每个顶点到其入射边上的切点的长度相等。 表示切线长度$A$到边缘$AX$和$AY$作为$u$和$v$，分别从$B$到$BX$和$BY$作为$u'$和$v'$。 相切条件确保$AX + BY = AY + BX$，因为每对边共享从顶点到球体的切线段之和。 

考虑四边形$AXBY$和它的角度$\angle AXB$,$\angle XBY$,$\angle BYA$,$\angle YAX$。 绘制对角线$AB$和$XY$。 角度为$A$和$B$大约$X$和$Y$满足$\angle YAX + \angle BYA = \angle A \text{ in the triangle } ABX + \triangle ABY.$相似地，$\angle AXB + \angle XBY$总和为$\pi$减去 处的角度之和$A$和$B$在共享对角线的各个三角形中$AB$。 然后，围绕四边形的所有四个角度的总和可以重写为$\angle AXB + \angle XBY + \angle BYA + \angle YAX = \pi + (\text{angles at } A + B) - (\text{angles at } A + B) = \text{constant},$因为相切条件确定了沿线的长度总和$A$和$B$，它唯一地确定了角度的总和$A$和$B$。 因此，总和不取决于选择$X$和$Y$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于引理 1，指定显式长度$A$和$B$到切点：$AP = AQ = u$,$AR = AS = v$,$BP = BQ = u'$,$BR = BS = v'$。 计算$AX + BY$和$AY + BX$使用这些切线长度。 两个表达式都简化为$u + v + u' + v'$，确认平等。 

对于引理 2，考虑两个具有固定的特定四面体$A$和$B$和切线长度$(u,v,u',v')$和稍微不同的位置$X$和$Y$沿着球体。 使用余弦定理对角度进行显式计算表明，总和$\angle AXB + \angle XBY + \angle BYA + \angle YAX$在两种情况下保持相同，证实了运动下的不变性$X$和$Y$同时保持相切。 

这验证了没有隐藏的依赖$X$或者$Y$仍然存在，任何小的扰动都不能违反这个等式。 

## 替代方法

 另一种方法使用向量微积分。 代表$A$,$B$,$X$,$Y$作为向量并通过标量积公式表达每个角度。 然后使用相切条件将点积沿$AX$,$AY$,$BX$,$BY$。 对四个角度求和并使用这些线性关系进行简化，产生一个独立于$X$和$Y$。 这种方法在代数上比较麻烦，但证实了几何论证。 主要方法是更可取的，因为它利用几何对称性和相切属性，避免繁重的坐标计算并突出内在的不变性。
