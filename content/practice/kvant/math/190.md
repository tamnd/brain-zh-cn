 ## 问题

 飞机上有两条线$a$和$b$被给予。 在点$A_1$，位于线上$a$距线的距离小于 1$b$，一只跳蚤坐了下来。 然后跳蚤依次跳到点$B_1$,$A_2$,$B_2$,$A_3$,$B_3$,$\ldots$，遵循以下规则（图 2）：

 1. 积分$A_1$,$A_2$,$A_3$,$\ldots$躺在线上$a$, 点$B_1$,$B_2$,$B_3$,$\ldots$躺在b线上；
 2.$A_1B_1 = B_1A_2 = A_2B_2 = B_2A_3 = A_3B_3 = \ldots = 1$;
 3. 点$A_n$不符合$A_{n+1}$，除了以下情况：$A_nB_n \perp a$（同样，$B_n$与$B_{n+1}$仅当$B_nA_{n+1} \perp b$）。 （很容易看出，条件（1）—（3）唯一确定了跳跃的顺序，从$B_1A_2$.)

 证明如果线之间的角度$a$和$b$以有理数度数来测量，则跳蚤的路径将是周期性的； 也就是说，在某个时刻它会回到起点$A_1$然后依次经过相同的点$B_2$,$A_2$,$B_3$,$\ldots$就像在路径的开始处一样。 如果角度是无理数度数，则跳蚤不会落在任何点上超过两次。

 ## 探索

 运动完全由两条线和当前点决定。 描述它的一种自然方式不是通过点本身，而是通过将一条线上的当前点连接到另一条线上的下一个点的定向线段。 

让$\alpha$是从$a$到$b$。 假设从跳转$a$到$b$由单位向量表示角度$\theta$带线$a$。 由于端点位于$b$，下一次跳转必须从该端点开始并且具有相同的长度$1$。 排除立即回溯的条件是指，除垂直情况外，下一次跳跃是通过反映直线上的前一个单位向量来获得的$b$。 然后通过line反射得到下面的跳转$a$， 等等。 

因此，跳跃方向的序列是由两条线中的交替反射产生的。 反射的组成$a$和$b$是一个旋转$2\alpha$。 因此，每跳跃两次后，方向就会旋转$2\alpha$。 

这建议引入方向角$\theta_n$跳跃的$A_nB_n$。 然后$$\theta_{n+1}=\theta_n+2\alpha \pmod{2\pi}.$$然后应该可以从这些方向恢复访问点的几何形状。 

最微妙的一点是，通过简单的方式表明实际位置是由这些方向控制的。 让$u_n$是有符号的坐标$A_n$在线的$a$。 跳跃的投影$A_nB_n$到$a$等于$\cos\theta_n$。 下一次跳跃的投影$B_nA_{n+1}$到$a$是一样的，因为它是第一次跳转的反射$b$。 因此$$u_{n+1}-u_n=2\cos\theta_n.$$使用$\theta_n=\theta_1+2(n-1)\alpha$，该动议$a$变成三角步行。 

如果$\alpha/\pi$是有理数，方向仅取有限多个值，因此是周期性的。 一个周期增量的总和为$$2\sum \cos(\theta_1+2k\alpha),$$对于单位根的完整循环，这个总和是$0$。 因此，关于这一点$a$一整个周期后返回到其初始位置，形成闭合轨道。 

如果$\alpha/\pi$是无理数，所有方向均不同模$2\pi$。 那么增量就不会以周期性的方式重复。 假设某个点$a$被拜访了 3 次。 两对访问之间的差异将给出一个不平凡的消失三角和$$\sum_{k=r}^{s-1} e^{i(\theta_1+2k\alpha)} = \sum_{k=t}^{u-1} e^{i(\theta_1+2k\alpha)}.$$消去后，得到有限关系$$\sum_{j=m}^{n} e^{2ij\alpha}=0.$$但这是一个几何级数，只有当$e^{2i\alpha}$是统一的根源，与非理性相反$\alpha/\pi$。 因此没有意义$a$可以参观两次以上。 同样的论点也适用于$b$。 

“两次”的出现是通过这样的事实来解释的：来自一侧的跳跃可以到达一个点一次，来自另一侧的跳跃也可以到达一个点一次。 

## 问题理解

 我们有两条线$a$和$b$和一个点$A_1\in a$谁的距离$b$小于$1$。 跳蚤交替落在$a$和$b$，进行长度跳跃$1$。 在每一步中，它都会选择唯一的延续，该延续不会立即回溯先前的跳跃，除非在端点保持固定的垂直情况下。 

我们必须证明两个断言。 

首先，如果角度$\alpha$之间$a$和$b$是有理数度数，那么整个轨迹是周期性的：经过有限多次跳跃后，跳蚤返回到$A_1$然后重复相同的序列。 

其次，如果$\alpha$是无理数度数，则轨迹上的任何点都不会被访问超过两次。 

这是一个B 类问题。 核心困难是将几何规则转换为跳跃方向的代数描述，然后将重复位置与几何级数的有限和相关联。 

## 证明架构

 让$\alpha$是之间的角度$a$和$b$。 

引理 1. 连续的跳跃向量是通过交替反射获得的$b$和$a$; 这直接来自排除立即回溯的规则。 

引理 2. 如果$\theta_n$是方向角$A_nB_n$， 然后$\theta_{n+1}\equiv\theta_n+2\alpha\pmod{2\pi}$; 反射的组成$a$和$b$是一个旋转$2\alpha$。 

引理 3. 如果$u_n$是有符号的坐标$A_n$在线的$a$， 然后$$u_{n+1}-u_n=2\cos\theta_n.$$沿位移$a$是两个连续单位跳跃的投影之和。 

引理 4. 如果$\alpha/\pi$是有理数，则方向序列具有有限周期$q$， 和$$\sum_{k=0}^{q-1}\cos(\theta_1+2k\alpha)=0.$$这是单位根的完全几何和的实部。 

引理 5. 因此$u_{q+1}=u_1$和$\theta_{q+1}=\theta_1$，因此整个状态重复并且轨迹是周期性的。 

引理 6. 如果$\alpha/\pi$是无理数，那么对于任意整数$m\le n$,$$\sum_{k=m}^{n}e^{2ik\alpha}\ne0.$$有限的几何级数只有当$e^{2i\alpha}$是统一之根。 

引理 7. 在非理性假设下，没有任何意义$a$被访问两次以上； 否则，两个不同的间隔将具有相等的位移，从而产生禁止的几何和消失。 同样的论点也适用于$b$。 

最难的部分是引理 7，必须将重复的位置转化为精确的代数关系，并证明它迫使一个不平凡的几何和消失。 

## 解决方案

 选择平面的方向。 让$\alpha\in(0,\pi)$是与线的角度$a$到线$b$。 

对于每个$n\ge1$， 让$v_n$是指向的单位向量$A_n$到$B_n$。 跳跃从$B_n$到$A_{n+1}$也有长度$1$。 自从$A_{n+1}$位于$a$, 段$B_nA_{n+1}$是的反映$A_nB_n$在行中$b$。 排除立即回溯的条件精确地选择反射段。 

让$R_a$和$R_b$表示反射$a$和$b$。 然后$$B_nA_{n+1}=R_b(v_n),$$和类似地$$A_{n+1}B_{n+1}=R_aR_b(v_n).$$因此$$v_{n+1}=R_aR_b(v_n).$$以一定角度相交的两条线的反射合成$\alpha$是旋转角度$2\alpha$。 所以$$v_{n+1} = \operatorname{Rot}_{2\alpha}(v_n).$$如果$\theta_n$表示方向角$v_n$， 然后$$\theta_{n+1}\equiv\theta_n+2\alpha \pmod{2\pi},$$因此$$\theta_n\equiv\theta_1+2(n-1)\alpha \pmod{2\pi}.$$让$u_n$是有符号的坐标$A_n$在线的$a$。 位移自$A_n$到$A_{n+1}$等于向量之和$A_nB_n$和$B_nA_{n+1}$。 他们的预测$a$都是$\cos\theta_n$，因为反射在$b$不改变平行的分量$a$的对称对。 因此$$u_{n+1}-u_n=2\cos\theta_n.$$使用公式$\theta_n$,$$u_{n+1}-u_n = 2\cos(\theta_1+2(n-1)\alpha).$$首先假设$\alpha$是有理数度数。 然后$$\frac{\alpha}{\pi}=\frac pq$$对于一些互质整数$p,q>0$。 自从$$e^{2iq\alpha}=e^{2ip\pi}=1,$$序列$\theta_n$有月经$q$:$$\theta_{n+q}\equiv\theta_n\pmod{2\pi}.$$考虑一段时间内的位移：$$u_{q+1}-u_1 = 2\sum_{k=0}^{q-1}\cos(\theta_1+2k\alpha).$$将余弦和写为几何级数的实部，$$\sum_{k=0}^{q-1}e^{i(\theta_1+2k\alpha)} = e^{i\theta_1} \sum_{k=0}^{q-1}(e^{2i\alpha})^k.$$自从$e^{2iq\alpha}=1$和$e^{2i\alpha}\ne1$除非两条线重合，$$\sum_{k=0}^{q-1}(e^{2i\alpha})^k = \frac{1-e^{2iq\alpha}}{1-e^{2i\alpha}} = 0.$$所以$$u_{q+1}=u_1.$$时$q+1$跳蚤又在同一点$A_1$并且传出跳跃的方向与当时相同$1$， 因为$\theta_{q+1}=\theta_1$。 进化规则是确定性的，因此随后的每一次跳跃都会重复之前的跳跃。 因此该路径是周期性的。 

现在假设$\alpha$是一个无理数的度数。 然后$\alpha/\pi$是无理数，因此$$e^{2i\alpha}$$不是统一之根。 

让$$S(m,n)=\sum_{k=m}^{n}e^{2ik\alpha}.$$为了$m\le n$,$$S(m,n) = e^{2im\alpha} \frac{1-e^{2i(n-m+1)\alpha}}      {1-e^{2i\alpha}}.$$自从$e^{2i\alpha}$不是单位根，分子永远不会消失。 因此$$S(m,n)\ne0 \qquad(m\le n).$$假设某个点$a$至少被访问过 3 次。 那么存在索引$$r<s<t$$和$$A_r=A_s=A_t.$$由位移公式可知，$$0=u_s-u_r = 2\sum_{k=r}^{s-1} \cos(\theta_1+2(k-1)\alpha),$$和类似地$$0=u_t-u_s = 2\sum_{k=s}^{t-1} \cos(\theta_1+2(k-1)\alpha).$$乘以$e^{i\theta_1}$结合实部和虚部，这些关系意味着$$\sum_{k=r}^{s-1} e^{i(\theta_1+2(k-1)\alpha)} =0,$$第二个间隔也是如此。 因式分解后$e^{i\theta_1}$，每个都成为连续幂的总和$e^{2i\alpha}$。 这与不消失性相矛盾$S(m,n)$。 

因此没有线点$a$点之间可以出现3次$A_n$。 

相同的参数，坐标在线$b$，表明没有线点$b$点之间可以出现3次$B_n$。 

由于每个访问点都属于$a$或到$b$，轨迹上的任何点都不会被访问超过两次。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是从几何规则到旋转的过渡$2\alpha$。 反思于$b$改变跳跃$A_nB_n$进入跳跃$B_nA_{n+1}$。 反思于$a$然后转变$B_nA_{n+1}$进入$A_{n+1}B_{n+1}$。 组成$R_aR_b$正是两次反射的标准组合，因此旋转了线之间角度的两倍。 通过旋转来替换它$\alpha$会破坏有理角的周期性陈述。 

第二个微妙的步骤是证明一个完整周期的净位移为零。 之后重复指示$q$步骤因为$e^{2iq\alpha}=1$。 仅仅重复指示并不意味着返回起点。 必须计算$$\sum_{k=0}^{q-1}e^{i(\theta_1+2k\alpha)} = e^{i\theta_1}\sum_{k=0}^{q-1}(e^{2i\alpha})^k$$并使用精确的几何级数公式。 这笔钱的消失就是产生的结果$u_{q+1}=u_1$。 

第三个微妙的步骤是排除三次访问，当$\alpha/\pi$是不合理的。 粗心的论证可能会说，非理性旋转意味着密集的方向，因此没有重复。 仅密度并不能排除重复位置。 必要的事实更加有力：两个非平凡位移的任何相等都会产生连续幂的消失有限和$e^{2i\alpha}$。 这样的总和等于$$e^{2im\alpha} \frac{1-e^{2iN\alpha}}{1-e^{2i\alpha}},$$并且只有当$e^{2iN\alpha}=1$，这是不可能的，当$\alpha/\pi$是不合理的。 

## 替代方法

 更几何的证明用单位圆上的点来标识每个跳跃方向。 两条线的交替反射产生该点在旋转下的轨道$2\alpha$。 线上的连续位置$a$通过对相应的投影和弦求和获得。 的合理性$\alpha/\pi$使轨道成为正多边形，其边向量之和为零，从而具有周期性。 无理数使轨道无限并阻止任何非平凡的多边形和闭合。 

另一种方法从一开始就使用复数。 将每个跳跃方向表示为$z_n=e^{i(\theta_1+2(n-1)\alpha)}$。 着陆点的坐标变为以下部分的和$z_n+\overline{z_n}$。 有理角对应于单位根，完整的周期总和为零。 无理角对应于非单位根的幂，并且每个所需的不重复陈述都简化为有限几何级数的不消失。 主要证明遵循这个想法，同时保持跳跃的几何意义可见。
