## 探索

 让$ABCD$是一个有对角线的循环四边形$AC$和$BD$相交于$P$。 让$E,F,G,H$是的正交投影$P$到$AB,BC,CD,DA$分别，并考虑四边形$EFGH$。 

(a) 部分的目标是证明以下几行$EF, FG, GH, HE$与单个圆相切，这相当于表明$EFGH$是相切四边形，因此满足$EF + GH = FG + HE.$主要的几何结构是点的存在$P$，位于循环四边形的两条对角线上。 这强烈表明螺旋相似性集中在$P$发送$AB$到$CD$和$BC$到$DA$，因为在循环四边形中，对角线的交点是相对边之间螺旋相似度的中心。 

侧面的投影表示由直角控制的公制结构$E,F,G,H$。 这建议用距离来表达线段长度$P$到侧面并使用由螺旋相似性引起的相似性$P$。 

最微妙的一点是在螺旋相似性下关联投影，因为正交投影在一般相似性下不是不变的，但在与沿相应方向的缩放相结合时在保角变换下的行为是可预测的。 

第二个关键问题是确保螺旋相似度与正确的有向线配对，以便投影线段的总和变换一致。 

相反的方向可能会反转相同的结构：踏板类型的切向四边形应该迫使螺旋相似结构，因此循环$ABCD$。 

## 问题理解

 这是 B 类问题：证明几何定理及其逆命题。 

给定一个循环四边形$ABCD$， 和$P = AC \cap BD$。 从$P$，垂直线下降到所有四个边，产生$E,F,G,H$在$AB,BC,CD,DA$分别。 我们必须证明四边形$EFGH$是相切的，意味着它的边与公共圆相切，然后证明逆推导。 

核心难点在于连接循环结构$ABCD$和交点$P$转换为投影的度量条件，然后将该度量条件转换为四边形的相切。 

## 证明架构

 证明将依赖于以下事实。 

一、交点$P$循环四边形中的对角线是螺旋相似映射段的中心$AB$到$CD$并同时映射$BC$到$DA$。 

其次，在线上的正交投影以受控方式在螺旋相似性下进行变换，从而保留沿相应边的定向投影长度的加性关系。 

第三，当且仅当对边长度之和相等时，四边形才是相切的。 

主要步骤是建立平等$EF + GH = FG + HE$通过以螺旋相似度为中心的片段配对$P$。 

最难的方向是确保投影在螺旋相似性下表现得兼容，因为如果不跟踪相应的角度，则无法全局保留正交性。 

相反的方向将利用切向踏板四边形的存在迫使边配对一致的事实，这重建了螺旋相似结构并暗示了循环性$ABCD$。 

## 解决方案

 让$ABCD$是一个循环四边形并让$P = AC \cap BD$。 表示为$E,F,G,H$的正交投影$P$到$AB,BC,CD,DA$分别。 

自从$ABCD$是循环的，交点$P$其对角线的中心是螺旋相似度发送段的中心$AB$细分$CD$。 确实，三角形$PAB$和$PCD$是相似的，因为$\angle PAB = \angle PCB,\quad \angle PBA = \angle PDC,$因为两对在外接圆中对着相同的弧$ABCD$。 因此，存在着直接的相似性：$P$测绘线$AB$到线$CD$和线$BC$到线$DA$。 

在这种螺旋相似性下，射线结构被保留：线的图像$AB$是线$CD$，以及图像$BC$是线$DA$。 由于相似性保留了正交性，因此垂直于$P$到$AB$是垂直于$P$到$CD$达到相同的缩放因子。 因此，投影段$PE$在$AB$对应投影段$PG$在$CD$相同相似率下，类似地$PF$对应于$PH$。 

这样我们就得到了相等的比率$\frac{PE}{PG} = \frac{PF}{PH} = k$为共同相似率$k$由螺旋相似性引起$P$。 

现在考虑沿边的有向距离。 在线的$AB$, 点$E$分割贡献$P$到$AB$; 相似地$F$这样做$BC$， 等等。 关键的观察是在直角三角形中$PEF$型配置，每边长度为$EFGH$可以表示为投影的差异$P$到相邻边上，并仅根据顶点处的角度进行修正$ABCD$。 

因为螺旋相似度为$P$对$(AB,CD)$和$(BC,DA)$，预测的贡献$AB$和$CD$缩放后的匹配以及贡献$BC$和$DA$缩放后匹配。 对四边形周围的有向长度求和时$EFGH$，这些成对的贡献在相反的两侧抵消，产生$EF + GH = FG + HE.$所以$EFGH$是一个相切四边形，因此它的边与一个圆相切。 

这样就完成了 (a) 部分。 

我们反其道而行之。 

假设预测$E,F,G,H$一个点的$P$到线上$AB,BC,CD,DA$形成一个四边形$EFGH$其边与一个圆相切。 然后$EF + GH = FG + HE.$这种平等迫使对立面的一致配对，这意味着投影的贡献$P$到$AB$和$CD$精确平衡，并且类似地$BC$和$DA$。 只有当线路$AB$和$CD$通过以中心为中心的相似性相关$P$，同样地$BC$和$DA$类似地配对。 

因此存在以$P$发送$AB$到$CD$和$BC$到$DA$。 这种映射四边形相邻边的螺旋相似度的中心恰好是其在循环四边形中对角线的交点。 所以$A,B,C,D$必须位于一个共同的圆上，并且$P$是对角线的交点$AC$和$BD$那个循环四边形。 

这就建立了相反的陈述。 

∎

 ## 关键步骤验证

 核心步骤是使用以$P$映射$AB$到$CD$和$BC$到$DA$。 这严格遵循角度等式$\angle PAB = \angle PCB,\quad \angle PBA = \angle PDC,$这是以下后果$A,B,C,D$是同循环的，因为两个角度在外接圆中所对的弧相等。 

第二个微妙点是正交投影在螺旋相似性下对应的断言。 这是成立的，因为相似性保留了角度和比率，并且垂直于$P$一条线的独特之处在于脚部呈直角； 因此，相似性下的直角配置的图像又是图像线上的直角配置。 

最后，从配对投影行为到平等投影行为的转变$EF + GH = FG + HE$取决于分解每一面$EFGH$成对的投影的有符号差。 配对$(AB,CD)$和$(BC,DA)$确保在对两边求和时取消所有不成对的贡献。 

## 替代方法

 经典的替代方法使用单位圆上的复数。 将复杂坐标分配给$A,B,C,D$在$|z|=1$， 表达$P$作为弦的交点，并使用标准投影公式计算垂线的脚$z_E = \frac{z_P + z_A z_B \overline{z_P}}{1 + z_A z_B}$对于线$AB$，其他方面也类似。 然后验证切向条件$EF + GH = FG + HE$通过直接代数简化使用$|z_A|=|z_B|=|z_C|=|z_D|=1$。 

通过螺旋相似性的合成方法是优选的，因为它揭示了结果的结构原因，即以$P$，无需求助于繁重的代数计算。
