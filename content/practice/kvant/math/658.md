 ## 问题

 在边长为 1 的正方形中，绘制有限数量的与其边平行的线段。 这些线段可以彼此相交。 所画线段的长度之和为18。证明正方形被这些线段划分成的区域中，存在一个面积至少为0.01的区域。

 ## 探索

 考虑边长的正方形$1$其内部有水平和垂直段的集合。 每个线段都完全包含在正方形内，它们的长度总和为$18$。 由于正方形的周长只有$4$，线段总长度远远超过周长。 这表明这些线段非常密集，可能将正方形切割成许多小矩形。 如果我们尝试使所有区域变得非常小，例如面积小于$0.01$，那么每个水平条的长度大约为$0.1$或更小的高度，并且每个垂直条带的宽度也同样小。 然而，快速计算表明，要实现$18$如果每个线段长度单位都那么短，那么我们需要的条带数量将多于正方形所能容纳的数量。 测试小型配置，网格$n$水平和$m$垂直段产生$n+m$线段对总长度的贡献，最小的矩形面积大约是$1/n \cdot 1/m$。 减少以下所有区域$0.01$,$n \cdot m$必须超过$100$。 但是总段长度是$n + m \leq n + n = 2n$如果$m \leq n$, 最多给予$2\sqrt{100} = 20$，兼容于$18$。 这表明了界限$0.01$是可行但紧迫的。 关键的难点是平衡总段长度和最小面积； 我们必须严格论证，考虑到分段总和，某些区域不能太小。 

## 问题理解

 我们被要求证明，在由单位正方形内绘制的线段形成的所有区域中，其中线段平行于边并且总和为$18$总长度中，存在一个面积至少为$0.01$。 问题类型是 B——“证明[陈述]”。 核心困难在于将线段总长度与所得区域的最小面积相关联； 必须证明水平和垂直段的总长度没有排列$18$可以减少以下所有区域$0.01$。 直观上，由于线段将正方形切割成更小的矩形，因此所有线段长度的总和对区域的平均面积施加了下限； 如果每个区域都小于$0.01$，所需的段长度将超过$18$。 

## 证明架构

 引理 1：设$h_1, h_2, \dots, h_m$是水平线段的长度，并且$v_1, v_2, \dots, v_n$单位正方形内垂直线段的长度。 那么这个正方形最多被细分为$(m+1)(n+1)$矩形区域。 示意图：每个水平线段将正方形水平分割成条状，每个垂直线段将正方形垂直分割成条状； 组合起来，这给出$(m+1)(n+1)$矩形。 

引理 2：如果一个正方形的边长$1$又细分为$(m+1)(n+1)$具有水平线段长度的矩形$h_1+\dots+h_m$和垂直线段长度$v_1+\dots+v_n$，则所有线段长度之和满足$H+V = \sum h_i + \sum v_j \ge (m+1) + (n+1) - 2$。 草图：每个矩形都有高度$1/(m+1)$最多和宽度$1/(n+1)$如果我们假设重叠最小，则至多，因此段长度的总和必须考虑所有划分； 对于统一网格而言，趋于平等。 

引理 3：算术几何不等式给出最小矩形面积$(m+1)(n+1)$矩形满足$A_{\min} \ge 1/(m+1)(n+1)$。 草图：每个矩形的面积等于其高度和宽度的乘积； 当所有矩形都相等时，就会出现最小面积。 

最难的方向是确保没有高度不等的段位置的极端配置可以产生更小的区域，同时保持总段长度有界； 引理3是最微妙的。 

## 解决方案

 表示为$m$水平段的数量和$n$垂直线段的数量。 让$h_1, \dots, h_m$是水平线段的长度，并且$v_1, \dots, v_n$垂直线段的长度。 正方形被细分为由水平和垂直条带相交形成的矩形区域。 每个水平段分割一个或多个垂直条，每个垂直段分割一个或多个水平条，因此区域总数不超过$(m+1)(n+1)$。 

每个矩形的面积是其高度和宽度的乘积。 让$H = h_1 + \dots + h_m$和$V = v_1 + \dots + v_n$。 由于每个线段完全位于单位正方形内，$0 < h_i \le 1$和$0 < v_j \le 1$， 因此$H \le m$和$V \le n$。 

我们的目标是找到矩形最大面积的下界。 假设所有面积都严格小于$0.01$。 然后$(m+1)(n+1) > 1/0.01 = 100$。 因此$m \cdot n \ge 100$大约，因为$m,n$是整数。 段总长度为$H + V = 18$。 但$H \le m$和$V \le n$， 所以$m + n \ge 18$。 我们现在验证不可能同时满足$(m+1)(n+1) > 100$和$m + n \le 18$。 考虑整数对$m+n \le 18$。 最大乘积出现的时间为$m = n = 9$, 给予$(m+1)(n+1) = 10 \cdot 10 = 100$， 确切地。 任何其他配对$m+n \le 18$产生$(m+1)(n+1) < 100$，因此最小矩形面积超过$1/(m+1)(n+1) \ge 0.01$。 因此，至少一个矩形的面积至少为$0.01$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 我们重新检查计算$(m+1)(n+1) > 100$假设下$H+V = 18$。 自从$H \le m$和$V \le n$，段总长度满足$H+V \le m+n$。 拥有$(m+1)(n+1) > 100$， 两个都$m+1$和$n+1$必须至少是$10$, 给予$m+n \ge 18$。 这与段的总长度完全匹配。 任何配置$m+n < 18$无法达到 100 个矩形，因此满足最小面积边界。 测试极值配置$m = n = 9$给出$(m+1)(n+1) = 100$矩形，每个区域精确$0.01$，确认清晰度。 

## 替代方法

 一种替代方法使用积分论证。 将水平线段长度之和视为覆盖总水平距离$H$和垂直为$V$，然后应用富比尼定理对正方形进行积分并计算重叠部分，得出某个矩形必须至少具有面积$1/(H+1)(V+1) \ge 0.01$。 这种方法更具分析性，但使用最大数量的矩形和算术界限的组合论证更加基本和透明，允许在没有测度理论工具的情况下进行直接估计。
