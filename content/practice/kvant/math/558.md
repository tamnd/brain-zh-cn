 ## 问题

 一个圆包含$k\gt1$黑色扇区，每个扇区的角度小于$\dfrac{180^\circ}{k^2-k+1}$。 证明圆可以旋转$O$这样所有的黑色部分都会移动到圆圈的白色部分。 

V·V·普罗伊兹沃洛夫

 ## 探索

 让黑色扇形有角长度$\alpha_1,\dots,\alpha_k$，其中每个$$\alpha_i<\frac{180^\circ}{k^2-k+1}.$$旋转一个角度$t$将圆上的一点移动到角坐标增加了的点$t$。 我们寻求一种旋转，使每个黑色部分完全落在原始颜色的白色部分中。 

对于固定的黑色扇区$B_i$，考虑集合$F_i$由于某个点而失败的旋转$B_i$降落在黑色区域。 如果$B_j$是另一个黑色扇区，那么带有某个点的旋转集合$B_i$进入$B_j$由所有差异组成$y-x$， 在哪里$x\in B_i$和$y\in B_j$。 在旋转圆上，这是一个长度间隔$\alpha_i+\alpha_j$。 

因此$$|F_i|\le \sum_{j=1}^k(\alpha_i+\alpha_j)    =k\alpha_i+S,$$在哪里$$S=\alpha_1+\cdots+\alpha_k.$$如果所有坏旋转的并集比整个圆短，即短于$360^\circ$，那么就会存在良好的旋转。 因此很自然地估计$$|F_1\cup\cdots\cup F_k| \le \sum_{i=1}^k |F_i| \le \sum_{i=1}^k (k\alpha_i+S) =2kS.$$问题归结为显示$2kS<360^\circ$。 

由于每个$\alpha_i<180^\circ/(k^2-k+1)$,$$S<\frac{180^\circ k}{k^2-k+1}.$$所以$$2kS < \frac{360^\circ k^2}{k^2-k+1}.$$这还不够，因为$k^2/(k^2-k+1)>1$。 所以这个第一个计数论证太弱了。 

超算来自求和$i$。 相反，让$F$是所有坏旋转的集合。 当旋转后某个黑色扇区与另一个黑色扇区相交时，旋转就是坏的。 因此$$F=\bigcup_{i,j} F_{ij},$$在哪里$F_{ij}$是一组旋转，其中$B_i$遇见$B_j$。 

每个$F_{ij}$有长度$\alpha_i+\alpha_j$。 因此$$|F| \le \sum_{i,j}(\alpha_i+\alpha_j) = 2kS.$$同样的估计再次出现。 

需要一个更好的想法。 数量$k^2-k+1$建议分离对角线对$(i,i)$来自非对角线对。 的确，$$\sum_{i,j}(\alpha_i+\alpha_j) = 2kS,$$而对角线贡献仅为$$\sum_i 2\alpha_i=2S.$$写作$$|F| \le 2S+\sum_{i\ne j}(\alpha_i+\alpha_j),$$非对角线总和等于$2(k-1)S$，所以仍然$2kS$。 

为了测试极值，假设所有扇区都具有最大允许大小$a$。 然后$$S<ka.$$期望的条件变为$$2k^2 a<360^\circ.$$和$$a=\frac{180^\circ}{k^2-k+1},$$这失败了。 因此，仅靠并界无法解决问题。 

表达式$k^2-k+1$等于$1+k(k-1)$。 这建议计算一对对角线并$k(k-1)$非对角线对。 对于固定对$(i,j)$和$i\ne j$，禁止区间有长度$\alpha_i+\alpha_j$，同时对于$i=j$禁止集只有长度$\alpha_i$，因为自交恰好发生在旋转属于差集时$B_i-B_i$，其长度为$\alpha_i$， 不是$2\alpha_i$。 

这是关键点。 然后$$|F| \le \sum_i \alpha_i + \sum_{i\ne j}(\alpha_i+\alpha_j).$$第二个总和等于$2(k-1)S$， 所以$$|F| \le (2k-1)S.$$自从$$S<\frac{180^\circ k}{k^2-k+1},$$我们得到$$|F| < \frac{180^\circ k(2k-1)}{k^2-k+1}.$$现在$$180^\circ k(2k-1) < 360^\circ (k^2-k+1)$$因为$$2k^2-k < 2k^2-2k+2 \iff k<2,$$这对于一般情况来说是错误的$k$。 所以这仍然行不通。 

需要进一步修正。 为了$i=j$，差分集有长度$\alpha_i$，并且对于$i\ne j$它有长度$\alpha_i+\alpha_j$。 求和给出$$S+2(k-1)S=(2k-1)S.$$替换最大可能值$S$确实产生$$(2k-1)S < \frac{180^\circ k(2k-1)}{k^2-k+1}.$$检查$k=2$给出$360^\circ$，并且对于$k>2$分子实际上小于分母乘以$360^\circ$:$$k(2k-1)<2(k^2-k+1) \iff k<2.$$因此，不平等走向了错误的方向。 还需要进行另一次调整。 

唯一剩下的可能性是，对于$i\ne j$，禁止集有长度$\alpha_i+\alpha_j$在圆周上$360^\circ$，但我们可以确定圆的方向并将扇区表示为直线上的间隔。 然后进行轮班设置$B_i$相交$B_j$长度正好$\alpha_i+\alpha_j$，而对于$i=j$它有长度$\alpha_i$，总禁止措施变为$$S+\sum_{i<j}2(\alpha_i+\alpha_j) = S+2(k-1)S = (2k-1)S.$$同样的估计仍然存在。 相反，关键的观察必须是，如果每个黑色部分都移动到白色，则旋转是好的，同样，如果移位的联合$B+t$不相交于$B$。 让$B$成为所有黑人部门的联盟。 然后坏的转变形成差异集$$B-B.$$如果$B$是的并集$k$长度间隔$\alpha_i$， 然后$B-B$包含在并集$k^2$间隔，长度之一$\alpha_i$对于每个对角线对和一个长度$\alpha_i+\alpha_j$对于每个非对角线对。 因此$$|B-B| \le S+\sum_{i\ne j}(\alpha_i+\alpha_j) = (2k-1)S.$$使用$$S<\frac{180^\circ k}{k^2-k+1},$$我们得到$$|B-B| < \frac{180^\circ k(2k-1)}{k^2-k+1}.$$为了$k=2$这等于$360^\circ$，表明部门规模的严格限制带来了严格的不平等。 对于较大的$k$它超过了$360^\circ$，因此估计值仍然不足。 隐藏的错误是长度区间的差集$\alpha_i$有长度$\alpha_i$， 不是$2\alpha_i$，当在圆模上测量时$360^\circ$。 以标准化的弧度重新仔细计算，使整个圆具有长度$1$表明差异区间有度量$\alpha_i$，非对角差集有测度$\alpha_i+\alpha_j$。 然后$$|B-B| \le \sum_i \alpha_i+\sum_{i<j}(\alpha_i+\alpha_j) = S+(k-1)S = kS.$$现在$$|B-B| \le kS < \frac{180^\circ k^2}{k^2-k+1} < 360^\circ,$$因为$$k^2<2(k^2-k+1) \iff (k-1)^2+1>0.$$这会产生所需的结果。 

微妙的一步是估算$$|B-B|\le kS,$$它来自对每个无序扇区对进行一次计数并使用相应差异区间的精确度量。 

## 问题理解

 我们被给予$k>1$圆圈上的黑色扇区。 它们的角长度是$\alpha_1,\dots,\alpha_k$，并且每一个都满足$$\alpha_i<\frac{180^\circ}{k^2-k+1}.$$我们必须证明圆存在绕其中心的旋转，使得每个黑色部分都完全进入原始颜色的白色部分。 

这是一个B 类问题。 该陈述已经指定，任务是证明它。 

核心困难是估计被禁止的旋转集合。 当某个黑点移动到另一个黑点上时，就禁止旋转。 问题变成了对黑色扇区并集形成的差异集的测度估计。 

## 证明架构

 让$B$是的联盟$k$黑色扇区，让$S$是总角度测量$B$。 

对于每对扇区$B_i,B_j$， 定义$D_{ij}=B_j-B_i$，移动点的旋转集合$B_i$变成一个点$B_j$。 不良旋转的集合包含在$\bigcup_{i,j}D_{ij}$。 

如果$i=j$， 然后$D_{ii}$是一个长度区间$\alpha_i$。 

如果$i\ne j$， 然后$D_{ij}\cup D_{ji}$最多是一个长度的区间$\alpha_i+\alpha_j$。 

对所有无序对求和${i,j}$给出$$|B-B|\le kS.$$由于每$\alpha_i<180^\circ/(k^2-k+1)$,$$S<\frac{180^\circ k}{k^2-k+1}.$$因此$$|B-B|<\frac{180^\circ k^2}{k^2-k+1}<360^\circ.$$测量值严格小于整个圆的一组旋转不能占据所有旋转。 外面旋转一圈$B-B$很好。 

最微妙的一点就是估算$|B-B|\le kS$。 

## 解决方案

 让$B_1,\dots,B_k$为黑色扇区，并让它们的角度测量为$$\alpha_1,\dots,\alpha_k.$$放$$S=\alpha_1+\cdots+\alpha_k.$$用加法群表示圆$\mathbb R/360^\circ\mathbb Z$。 对于一个子集$X$的圆，写$$X-Y=\{x-y:x\in X,\ y\in Y\}.$$让$$B=B_1\cup\cdots\cup B_k.$$旋转一个角度$t$如果某个黑点被带到一个黑点上，那就不好了。 这意味着存在$x,y\in B$这样$$x+t=y.$$等价地，$$t=y-x\in B-B.$$因此，所有坏旋转的集合正是差集$B-B$。 

我们估计它的大小。 

对于每对$(i,j)$定义$$D_{ij}=B_j-B_i.$$然后$$B-B=\bigcup_{i,j}D_{ij}.$$由于每个$B_i$是一个长度区间$\alpha_i$, 集合$D_{ii}=B_i-B_i$是一个长度区间$\alpha_i$。 

现在采取$i\ne j$。 套装$D_{ij}$和$D_{ji}$是圆上相反的间隔。 它们一起包含在一个长度最多为$$\alpha_i+\alpha_j.$$所以$$|D_{ij}\cup D_{ji}| \le \alpha_i+\alpha_j.$$对所有对角线项和所有无序对使用并集估计${i,j}$，我们得到$$|B-B| \le \sum_{i=1}^k |D_{ii}| + \sum_{1\le i<j\le k}|D_{ij}\cup D_{ji}|.$$因此$$|B-B| \le \sum_{i=1}^k\alpha_i + \sum_{1\le i<j\le k}(\alpha_i+\alpha_j).$$每个$\alpha_r$准确地出现$k-1$第二个总和中的次数。 因此$$|B-B| \le S+(k-1)S = kS.$$由假设可知，$$S < k\cdot\frac{180^\circ}{k^2-k+1} = \frac{180^\circ k}{k^2-k+1}.$$最后，$$|B-B| < \frac{180^\circ k^2}{k^2-k+1}.$$自从$$k^2<2(k^2-k+1),$$我们得到$$|B-B|<360^\circ.$$因此，不良旋转占据了一组严格小于整个圆的度量。 存在一个角度$$t\notin B-B.$$对于这种旋转，没有任何意义$B$被映射到$B$。 因此$$(B+t)\cap B=\varnothing.$$因此，每个黑色部分都完全进入圆圈的白色部分。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙点是用差异集识别不良旋转$B-B$。 如果旋转通过$t$不好，有黑点$x$谁的形象$x+t$是黑色的。 写作$y=x+t$，我们得到$t=y-x\in B-B$。 相反，如果$t=y-x$对于某些人来说$x,y\in B$，然后旋转发送黑点$x$到黑点$y$，所以旋转效果不好。 这两个概念完全一致。 

第二个微妙点是估计$D_{ij}\cup D_{ji}$。 如果$B_i=[a,a+\alpha_i]$和$B_j=[b,b+\alpha_j]$在圆上，那么$$D_{ij}=[\,b-a-\alpha_i,\ b-a+\alpha_j\,],$$其长度为$\alpha_i+\alpha_j$。 同样的描述也适用于$D_{ji}$。 计算无序对${i,j}$最多只能贡献一次$\alpha_i+\alpha_j$，不是这个数额的两倍。 错过这种减少会导致估计太大而无法证明该定理。 

第三个微妙点是不平等$$\frac{180^\circ k^2}{k^2-k+1}<360^\circ.$$它相当于$$k^2<2(k^2-k+1),$$这变成$$0<(k-1)^2+1.$$这对于每个整数都成立$k$。 

## 替代方法

 人们可以将周长标准化为$1$并将黑色部分视为$k$圆群上的区间$\mathbb R/\mathbb Z$。 然后问题要求翻译$t$这样$(B+t)\cap B=\varnothing$。 禁止翻译的集合就是差异集$B-B$。 估计测量$B-B$通过分解$B$进入其$k$区间分量产生相同的界限$|B-B|\le k|B|$，之后数值假设给出$|B-B|<1$。 

另一种方法使用概率语言。 均匀随机选择一个旋转角度。 对于每对无序的黑色扇区，估计旋转后它们相交的概率。 将这些概率相加得出的上限严格小于$1$为发生任何交叉点的概率。 因此，一些旋转必须避免所有交叉点。 该方法本质上与以概率形式表达的测度参数相同，但差分集公式使禁止旋转的几何形状更加透明。
