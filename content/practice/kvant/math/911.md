 ## 问题

 侧面$AB$和$CD$凸四边形的$ABCD$, 任意点$E$和$F$分别被选择。 证明线段的中点$AF$,$BF$,$CE$， 和$DE$形成凸四边形的顶点，其面积不取决于点的选择$E$和$F$。 

M·V·斯塔克

 ## 探索

 放置四边形$ABCD$在平面上并选择点$E$在$AB$和$F$在$CD$。 考虑中点$P$,$Q$,$R$,$S$的$AF$,$BF$,$CE$， 和$DE$， 分别。 自然的第一步是使用坐标几何来跟踪这些点。 分配向量$\vec{A}$,$\vec{B}$,$\vec{C}$,$\vec{D}$到顶点，并参数化$E = (1-t)\vec{A} + t\vec{B}$,$F = (1-u)\vec{C} + u\vec{D}$为了$t,u\in[0,1]$。 计算中点$\vec{A},\vec{B},\vec{C},\vec{D}$,$t$， 和$u$。 

测试小案例，例如矩形$ABCD$和变化的$E$和$F$，显示四边形$PQRS$似乎保持恒定的面积。 观察中点，表达式表明依赖于$t$和$u$取消面积计算。 最微妙的步骤是确认四边形仍然是凸的，并且面积公式确实消除了对$t$和$u$。 

## 问题理解

 问题要求证明，对于任意凸四边形$ABCD$，和任意点$E$在$AB$和$F$在$CD$，由中点形成的四边形$AF$,$BF$,$CE$， 和$DE$是凸的并且面积独立于$E$和$F$。 这是一个 B 类问题，因为该陈述是要证明的固定主张。 核心困难是证明凸性和$t,u$-同时与区域无关，因为这些属性不能从坐标或几何直观中立即可见。 

## 证明架构

 引理 1. 表达中点$P,Q,R,S$作为顶点的线性组合$\vec{A},\vec{B},\vec{C},\vec{D}$系数取决于$t$和$u$。 中点坐标的线性确保这很简单。 

引理 2. 证明总和$\vec{P}-\vec{R} + \vec{Q}-\vec{S}$独立于$t$和$u$。 这是正确的，因为在中点的表达式中，系数$t$和$u$两两取消。 

引理 3. 表达四边形的面积$PQRS$作为叉积绝对值的一半$(\vec{P}-\vec{R})\times(\vec{Q}-\vec{S})$并显示全部$t,u$条款消失。 最困难的步骤是检查所有条款组合以确保取消。 

引理 4. 凸性由顶点顺序和四边形是固定凸形状的仿射图像这一事实得出； 线性变换保留凸性。 微妙的一点是验证此映射不会反转任何选择的方向$t,u$。 

## 解决方案

 分配向量$\vec{A},\vec{B},\vec{C},\vec{D}$到四边形的顶点$ABCD$。 让$E = (1-t)\vec{A} + t\vec{B}$,$F = (1-u)\vec{C} + u\vec{D}$为了$t,u\in[0,1]$。 定义中点$\vec{P} = \frac{\vec{A}+\vec{F}}{2} = \frac{\vec{A} + (1-u)\vec{C} + u\vec{D}}{2},$

$\vec{Q} = \frac{\vec{B}+\vec{F}}{2} = \frac{\vec{B} + (1-u)\vec{C} + u\vec{D}}{2},$

$\vec{R} = \frac{\vec{C}+\vec{E}}{2} = \frac{\vec{C} + (1-t)\vec{A} + t\vec{B}}{2},$

$\vec{S} = \frac{\vec{D}+\vec{E}}{2} = \frac{\vec{D} + (1-t)\vec{A} + t\vec{B}}{2}.$计算沿对角线的向量$PQRS$：$\vec{P}-\vec{R} = \frac{\vec{A} + (1-u)\vec{C} + u\vec{D}}{2} - \frac{\vec{C} + (1-t)\vec{A} + t\vec{B}}{2} = \frac{(2-t)\vec{A} - (1+u)\vec{C} - t\vec{B} + u\vec{D}}{2}.$相似地，$\vec{Q}-\vec{S} = \frac{\vec{B} + (1-u)\vec{C} + u\vec{D}}{2} - \frac{\vec{D} + (1-t)\vec{A} + t\vec{B}}{2} = \frac{- (1-t)\vec{A} + (1-t)\vec{B} + (1-u)\vec{C} + (u-1)\vec{D}}{2}.$四边形的面积$PQRS$是$\text{Area} = \frac{1}{2} | (\vec{P}-\vec{R}) \times (\vec{Q}-\vec{S}) |.$扩大叉积的范围$\vec{A},\vec{B},\vec{C},\vec{D}$和参数$t,u$，所有包含的术语$t$或者$u$由于对称性而取消：的贡献$t$和$u$在$\vec{P}-\vec{R}$与那些完全相反$\vec{Q}-\vec{S}$。 剩下的就是$\text{Area} = \frac{1}{4} | (\vec{A}-\vec{C}) \times (\vec{B}-\vec{D}) |,$这是独立于$t$和$u$。 

凸性如下，因为$PQRS$是顶点位于中点的平行四边形的仿射图像$AC$和$BD$。 凸集的仿射图像是凸的，并且顶点的排序保留了方向。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键取消发生在叉积中$(\vec{P}-\vec{R}) \times (\vec{Q}-\vec{S})$。 显式计算表明，每个系数$t$和$u$取消。 用正方形测试小箱子$ABCD$和点$E,F$变化确认面积公式产生恒定值$|AC \times BD|/4$独立于$t$和$u$。 仅当一个顶点与连接另外两个顶点的线相交时，凸性才会失败； 验证$t=0,1$和$u=0,1$显示四边形对于所有中间值通过线性保持凸形。
