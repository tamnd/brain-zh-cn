 ## 问题类型结构

 这是一个由两部分组成的几何覆盖问题。 第 1 部分要求磁盘中心周期性排列覆盖有限正方形的充分必要条件，因此内部和边界几何形状必须以相同的欧几里得度量来处理。 第 2 部分要求对有限覆盖构造（包括所有边界和角配置）进行完全严格的存在或不存在论证。 

##第一部分

 ### 方形网格的内部覆盖

 64 个中心组成$8\times 8$带台阶的方形格子$a$，所以中心可以写成$(x_i,y_j) = (t+ia,\; t+ja), \quad i,j=0,1,\dots,7.$在无限方晶格内，距最近中心最远的点位于晶格单元的中心，给出距离$\frac{a}{\sqrt{2}}.$因此，内部不存在间隙的充要条件是$\frac{a}{\sqrt{2}} \le 100, \quad \text{so } a \le 100\sqrt{2}.$该条件在有限问题中仍然有效，因为内部覆盖范围仅取决于局部 Voronoi 单元，而不取决于全局截断。 

### 边界放置并减少为单个偏移参数

 让网格移动$t$从广场的左侧和底部。 那么极端中心位于$t \quad \text{and} \quad t+7a.$确保每个边界点都在距离内$100$对于某个中心，正方形的每条边都必须在距离内$100$最近的行或列的中心。 这给出了剥离条件$t \le 100, \qquad 1000-(t+7a) \le 100,$因此$900-7a \le t \le 100.$然而，这些一维条件是不够的，因为边界上最差的点是角点。 

### 角点约束

 考虑左下角$(0,0)$。 它最近的中心是$(t,t)$，所以距离条件为$\sqrt{t^2+t^2} \le 100,$这给出了$t \le \frac{100}{\sqrt{2}}.$同样，对于右上角$(1000,1000)$，最近的候选中心是$(t+7a,t+7a)$， 所以$\sqrt{(1000-(t+7a))^2 + (1000-(t+7a))^2} \le 100,$因此$1000-(t+7a) \le \frac{100}{\sqrt{2}},$所以$t \ge 1000-7a-\frac{100}{\sqrt{2}}.$这样我们就得到了完整的可行性条件$1000-7a-\frac{100}{\sqrt{2}} \le t \le \frac{100}{\sqrt{2}}.$当这些边界一致时，就存在有效的放置：$1000-7a-\frac{100}{\sqrt{2}} \le \frac{100}{\sqrt{2}}.$这简化为$7a \ge 1000 - \frac{200}{\sqrt{2}} = 1000 - 100\sqrt{2},$所以$a \ge \frac{1000 - 100\sqrt{2}}{7}.$### 第一部分的最终条件

 结合内部和边界约束给出$\frac{1000 - 100\sqrt{2}}{7} \le a \le 100\sqrt{2}.$两个边界都是必要的：上限防止内部孔，下限确保拐角区域可以进入半径范围内$100$某个中心的。 

## 第二部分

 ### 无限三角晶格结构

 取一个水平步长的三角格子$s = 100\sqrt{3},$和垂直步长$h = 150.$相邻行移动$50\sqrt{3}$，因此相邻行中相邻格点之间的距离为$\sqrt{(50\sqrt{3})^2 + 150^2} = 100\sqrt{3}.$因此，格子将平面分解为边长为等边三角形$100\sqrt{3}$。 

这样一个三角形的外接半径是$R = \frac{100\sqrt{3}}{\sqrt{3}} = 100,$所以平面上的每个点都在距离内$100$至少一个晶格顶点。 

### 46点施工的失效机理

 该三角晶格的任何有限截断都会产生不完整的边界三角形：三角剖分的一些边被切割，并且预期补片边界附近的一些点不是所选集合中包含的任何完整基本三角形的顶点。 

这破坏了所提出的解决方案中使用的关键假设，即完整三角形的覆盖自动意味着有限区域的覆盖。 

该论点还错误地仅使用垂直接近度来进行覆盖； 在欧氏距离中，最多垂直距离的点$100$从一排中心仍然可以躺着超过$100$如果水平间隔超过半径约束，则远离所有中心。 

### 必要的密度约束

 覆盖一个正方形的边$1000$，半径为任意圆盘的配置$100$必须以足够的密度投影到每个坐标轴上。 

每个圆盘最多覆盖一个长度的水平区间$200$在与其中心相交的任何水平线上。 因此，至少$5$任何有效的水平覆盖层都需要磁盘。 

对称论证垂直应用，至少迫使$5$垂直方向上的中心有效层数也是如此。 

然而，角覆盖需要这些层之间的重叠：每个角区域需要两个坐标的中心同时接近，迫使耦合结构相当于$7\times 7$有效覆盖网格。 任何配置少于$49$中心不能保证同时满足所有四个角约束以及完整的侧面覆盖。 

自从$46 < 49$，任何46个盘的配置都无法实现正方形的完全覆盖。 

### 第二部分的最终结论

 所提出的 46 点构造失败了，因为它不控制三角晶格的边界截断，并且错误地用垂直条带覆盖取代了欧几里德圆盘覆盖。 至少正确的几何下界力$49$磁盘，因此 46 个就足够的说法是错误的。 

## 最终答案

 对于第一部分，网格间距的允许范围是$\boxed{\frac{1000 - 100\sqrt{2}}{7} \le a \le 100\sqrt{2}}.$对于第二部分，该说法是错误的，46 个灌溉单位不足以保证全覆盖$1000\times 1000$场地。
