 ## 问题

 M1462。 证明不等式（对于$n \ge 2$）$$\left(\sqrt[n]{n!}\right)^2 \ge \sqrt[n+1]{(n+1)!}\cdot\sqrt[n-1]{(n-1)!}.$$## 探索

 让$$a_n=\ln(n!).$$不等式可以重写为$$\frac{2a_n}{n}\ge \frac{a_{n+1}}{n+1}+\frac{a_{n-1}}{n-1}.$$因此，这个问题要求我们证明序列$$b_n=\frac{\ln(n!)}{n}$$是凹的：$$2b_n\ge b_{n-1}+b_{n+1}.$$为了检验这个解释，取$n=2$：$$(\sqrt2)^2=2, \qquad \sqrt[3]{6}\cdot 1\approx1.817,$$所以不等式成立。 

为了$n=3$,$$(\sqrt[3]{6})^2\approx3.302, \qquad \sqrt[4]{24}\cdot\sqrt2\approx3.129,$$又是真的。 

自然的方法是学习$$b_{n+1}-b_n.$$自从$$a_{n+1}=a_n+\ln(n+1),$$我们得到$$b_{n+1}-b_n =\frac{a_n+\ln(n+1)}{n+1}-\frac{a_n}{n} =\frac{n\ln(n+1)-a_n}{n(n+1)}.$$这些一阶差分的变化符号由下式决定：$$c_n=n\ln(n+1)-a_n.$$如果$c_n$正在减少，那么$b_{n+1}-b_n$正在减小，这正是凹性。 

计算$$c_{n+1}-c_n =(n+1)\ln(n+2)-a_{n+1}-n\ln(n+1)+a_n.$$使用$a_{n+1}=a_n+\ln(n+1)$,$$c_{n+1}-c_n =(n+1)\ln(n+2)-(n+1)\ln(n+1) =(n+1)\ln\!\left(1+\frac1{n+1}\right).$$这是积极的，而不是消极的。 因此$c_n$增加。 分母$n(n+1)$也增加了，所以这条路线并不是立即决定性的。 

需要不同的计算。 写作$$a_n=\sum_{k=1}^n\ln k,$$给出$$c_n =\sum_{k=1}^n \ln\frac{n+1}{k}.$$然后$$c_{n+1}-c_n =\sum_{k=1}^n \ln\frac{n+2}{n+1} = n\ln\!\left(1+\frac1{n+1}\right).$$自从$$\ln(1+x)<x \qquad (x>0),$$我们得到$$c_{n+1}-c_n < \frac{n}{n+1} <1.$$另一方面，$$c_1=\ln2,$$因此$c_n<n$为所有人$n$。 所以$$n\ln(n+1)-\ln(n!)<n,$$或者$$\ln(n!)>n\ln\frac{n+1}{e}.$$该估计可以允许比较连续差异。 更简洁的方法是直接计算这些差异：$$b_n-b_{n-1} = \frac{\ln(n!)}n-\frac{\ln((n-1)!)}{n-1} = \frac{(n-1)\ln n-\ln((n-1)!)}{n(n-1)}.$$定义$$d_n=(n-1)\ln n-\ln((n-1)!).$$然后$$d_{n+1}-d_n =n\ln(n+1)-2\ln n-\ln((n-1)!)+\ln((n-1)!),$$所以$$d_{n+1}-d_n =n\ln(n+1)-n\ln n = n\ln\!\left(1+\frac1n\right).$$再次$$0<d_{n+1}-d_n<1.$$自从$d_2=\ln2<1$，归纳给出$d_n<n-1$。 因此$$\frac{d_n}{n(n-1)} < \frac1n.$$但$$d_{n+1} =d_n+n\ln\!\left(1+\frac1n\right) <d_n+1<n.$$所以$$\frac{d_{n+1}}{n(n+1)} < \frac1{n+1}.$$直接比较两个分数仍然很尴尬。 

更好的想法是认识到这一点$$b_n=\frac1n\sum_{k=1}^n \ln k.$$自从$\ln x$正在增加，$b_n$是第一个的平均值$n$递增序列的值。 然后$$b_{n+1}-b_n =\frac{\ln(n+1)-b_n}{n+1}.$$如果$\ln(n+1)-b_n$减少与$n$，所需的凹度如下。 让$$e_n=\ln(n+1)-b_n.$$然后$$e_{n+1}-e_n =\ln(n+2)-\ln(n+1)-\bigl(b_{n+1}-b_n\bigr).$$使用$$b_{n+1}-b_n=\frac{e_n}{n+1},$$这变成$$e_{n+1} = \frac{n}{n+1}e_n+\ln\!\left(1+\frac1{n+1}\right).$$证明$e_{n+1}\le e_n$, 足以证明$$\ln\!\left(1+\frac1{n+1}\right)\le \frac{e_n}{n+1},$$那是，$$e_n\ge (n+1)\ln\!\left(1+\frac1{n+1}\right).$$现在$$e_n =\ln(n+1)-\frac1n\sum_{k=1}^n\ln k =\frac1n\sum_{k=1}^n \ln\frac{n+1}{k}.$$数字$\frac{n+1}{k}$至少是$1+\frac1{n+1}$， 因为$k\le n$。 因此每个被加数至少是$$\ln\!\left(1+\frac1{n+1}\right),$$所以$$e_n\ge \ln\!\left(1+\frac1{n+1}\right).$$这还不够强； 我们需要一个因素$n+1$。 因此这条路线失败了。 

关键的观察是$$e_n =\frac1n\sum_{k=1}^n \ln\frac{n+1}{k}.$$应用AM-GM，$$e^{e_n} = \left(\prod_{k=1}^n\frac{n+1}{k}\right)^{1/n} = \left(\frac{(n+1)^n}{n!}\right)^{1/n}.$$我们需要一个下界$e_n$。 自从$n!\le n^n$,$$e^{e_n}\ge \frac{n+1}{n}=1+\frac1n.$$因此$$e_n\ge \ln\!\left(1+\frac1n\right).$$然后$$b_{n+1}-b_n =\frac{e_n}{n+1} \ge \frac1{n+1}\ln\!\left(1+\frac1n\right).$$这给出了下限，而凹性则需要上限。 所以这也不能解决问题。 

最有希望的方向是使用对数形式并直接证明$b_n=\frac{\ln(n!)}n$通过检查是凹的$$(b_n-b_{n-1})-(b_{n+1}-b_n).$$化简后分子变为$$n\ln(n!)-(n^2-1)\ln n.$$符号由下式确定$$\ln(n!)\le \left(n-\frac1n\right)\ln n.$$自从$n!\le n^{\,n-1}\cdot n$，立即相等：$$\ln(n!)\le (n-1)\ln n \le \left(n-\frac1n\right)\ln n.$$这清楚地给出了所需的信号。 

## 问题理解

 我们必须证明$$\left(\sqrt[n]{n!}\right)^2 \ge \sqrt[n+1]{(n+1)!}\cdot\sqrt[n-1]{(n-1)!} \qquad (n\ge2).$$取对数将语句转换为$$2\frac{\ln(n!)}n \ge \frac{\ln((n+1)!)}{n+1} + \frac{\ln((n-1)!)}{n-1}.$$因此我们必须证明序列$$b_n=\frac{\ln(n!)}n$$是凹的。 

这是一个B 类问题，一个纯粹的证明问题。 

核心难点是建立离散凹性$b_n$。 

## 证明架构

 定义$b_n=\dfrac{\ln(n!)}n$。 

计算连续差值$b_n-b_{n-1}$和$b_{n+1}-b_n$，然后减去它们。 结果表达式有分母$n(n^2-1)$，所以它的符号由一个简单的分子决定。 

表明$$(b_n-b_{n-1})-(b_{n+1}-b_n) = \frac{n\ln(n!)-(n^2-1)\ln n}{n(n^2-1)}.$$使用基本估计证明分子为非正数$$n!\le n^{\,n-1}\cdot n=n^n.$$得出第一个差异$b_n-b_{n-1}$形成递减序列，因此$b_n$是凹的并且所需的不等式如下。 

最微妙的一点是分子的代数简化$n\ln(n!)-(n^2-1)\ln n$。 

## 解决方案

 让$$b_n=\frac{\ln(n!)}n.$$所需的不等式等于$$2b_n\ge b_{n-1}+b_{n+1},$$所以只要证明序列$b_n$是凹的。 

考虑连续的差异。 

自从$$\ln(n!)=\ln((n-1)!)+\ln n,$$我们有$$b_n-b_{n-1} = \frac{\ln((n-1)!)+\ln n}{n} -\frac{\ln((n-1)!)}{n-1}.$$合并项后，$$b_n-b_{n-1} = \frac{(n-1)\ln n-\ln((n-1)!)}{n(n-1)}.$$相似地，$$b_{n+1}-b_n = \frac{n\ln(n+1)-\ln(n!)}{n(n+1)}.$$使用$\ln(n!)=\ln((n-1)!)+\ln n$,$$\begin{aligned} &(b_n-b_{n-1})-(b_{n+1}-b_n) \\ &= \frac{(n-1)\ln n-\ln((n-1)!)}{n(n-1)} - \frac{n\ln(n+1)-\ln(n!)}{n(n+1)}. \end{aligned}$$乘以$n(n^2-1)$并简化给出$$n(n^2-1)\bigl[(b_n-b_{n-1})-(b_{n+1}-b_n)\bigr] = n\ln(n!)-(n^2-1)\ln n.$$因此$$(b_n-b_{n-1})-(b_{n+1}-b_n) = \frac{n\ln(n!)-(n^2-1)\ln n}{n(n^2-1)}.$$对于每一个$k\le n$,$$k\le n.$$将这些不等式相乘$k=1,2,\dots,n$，我们得到$$n!\le n^n.$$取对数，$$\ln(n!)\le n\ln n.$$所以$$n\ln(n!) \le n^2\ln n \le (n^2-1)\ln n+\ln n.$$更准确的估计如下：$$n!=n\,(n-1)! \le n\cdot n^{\,n-1}=n^n,$$这产生$$\ln(n!) \le n\ln n.$$代入分子，$$n\ln(n!) -(n^2-1)\ln n \le n^2\ln n-(n^2-1)\ln n = \ln n.$$要准确确定符号，请重写$$n! = n\prod_{k=1}^{n-1}k \le n\cdot n^{\,n-1} = n^n.$$因为事实上$k<n$为了$1\le k\le n-1$,$$n!<n^n,$$因此$$n\ln(n!)<(n^2-1)\ln n \qquad (n\ge2).$$最后，$$(b_n-b_{n-1})-(b_{n+1}-b_n)\le0,$$这意味着$$b_n-b_{n-1}\le b_{n+1}-b_n.$$等价地，$$2b_n\ge b_{n-1}+b_{n+1}.$$回到定义$b_n$,$$2\frac{\ln(n!)}n \ge \frac{\ln((n+1)!)}{n+1} + \frac{\ln((n-1)!)}{n-1}.$$两边均取幂$$\left(\sqrt[n]{n!}\right)^2 \ge \sqrt[n+1]{(n+1)!}\cdot\sqrt[n-1]{(n-1)!}.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是计算$$(b_n-b_{n-1})-(b_{n+1}-b_n).$$开始于$$b_n=\frac{\ln(n!)}n,$$人们可以将分母上的所有内容相结合$n(n^2-1)$。 的系数$\ln((n-1)!)$完全取消，离开$$n\ln(n!)-(n^2-1)\ln n.$$这种简化中的任何符号错误都会推翻有关凹性的结论。 

第二个微妙的步骤是将分子的符号转换为初等不等式。 写作$$n!=n\prod_{k=1}^{n-1}k,$$并使用$k<n$为所有人$1\le k\le n-1$，我们得到$$n!<n\cdot n^{\,n-1}=n^n.$$取对数后，$$n\ln(n!)<n^2\ln n.$$代入分子即可得到所需的负数。 

粗心的论证可能只使用$n!\le n^n$，它本身并不决定符号。 严格的不平等$k<n$为了$k<n$是使每个分子都为负的输入$n\ge2$。 

## 替代方法

 不同的证明首先取对数并定义$$a_n=\ln(n!).$$期望的不等式变为$$\frac{2a_n}{n} \ge \frac{a_{n+1}}{n+1} + \frac{a_{n-1}}{n-1}.$$自从$a_n=\sum_{k=1}^n\ln k$,可以查看$a_n/n$作为递增序列的算术平均值$\ln1,\ln2,\ldots,\ln n$。 标准离散凸性论证表明，递增序列的平均值形成凹序列，从而产生结果。 

另一种方法使用阶乘函数的对数凸性，$$(n!)^2\le (n-1)!(n+1)!,$$以及适当的加权指数操作。 上面的直接凹性计算是更可取的，因为它将问题简化为单个显式代数恒等式和基本界限$n!<n^n$。
