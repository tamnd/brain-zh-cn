 ## 问题

 在尺寸表中$m \times n$，写入实数，每个单元格中一个数字。 在每一列中，$k$最大的数字（$k\le m$) 带有下划线； 在每一行中，$l$最大的数字（$l\le n$) 带有下划线。 证明至少$kl$数字加下划线两次。 首先考虑案例

 1.$k=l=2$;
 2.$k=l=3$。 

S.V.科尼亚金

 ## 探索

 让$A=(a_{ij})$成为一个$m\times n$矩阵。 每行$i$贡献一套$R_i\subset{1,\dots,n}$尺寸的$l$，由列组成，其中$a_{ij}$是其中$l$行中最大的$i$。 每栏$j$贡献一套$C_j\subset{1,\dots,m}$尺寸的$k$，由行组成，其中$a_{ij}$是其中$k$列中最大的$j$。 

一个细胞$(i,j)$恰好在以下时间点被划线两次$j\in R_i$和$i\in C_j$。 因此，我们必须估计两个固定大小集合族的交集结构的大小。 

唯一可见的刚性信息是尺寸的均匀性$|R_i|=l$和$|C_j|=k$。 极端直觉表明，当所有情况都发生时，最坏的情况应该发生$R_i$一致并且所有$C_j$重合，因为这样对齐就最大程度地集中，准确地产生$kl$双下划线的单元格。 任何“传播”选择的尝试都会通过鸽笼式压缩强制产生额外的重叠。 

对于小案例，$k=l=2$建议必须出现四个双重选择； 为了$k=l=3$， 九。 在这两种情况下，任何行都会贡献两个标记的列，任何列都会贡献两个标记的行，因此该结构的行为就像两个常规二分图，其交集必须很大。 

关键问题是防止行选择和列选择“倾斜”以避免重叠的配置。 最脆弱的步骤是证明任何与完美对齐的偏差都会增加而不是减少交集。 

## 问题理解

 这是一个 A 类问题：根据行和列极值选择规则确定矩阵中双下划线条目的保证最小数量。 

我们必须证明至少$kl$条目同时在$l$他们这一排中最大的$k$他们专栏中最大的。 核心困难是控制垂直方向上应用的两个独立贪婪选择之间的相互作用。 

预期的答案是$\boxed{kl}.$直觉是行约束强制执行$lm$总行选择，强制列约束$kn$总的列选择，并且最佳的“非重叠”将需要这些选择的完美对齐，从而准确地产生$k\times l$强制交叉的核心。 

## 证明架构

 证明引入了指标变量$x_{ij}$用于双重选择。 

第一个引理指出问题简化为有界$\sum_{i,j} x_{ij}$在每行都有精确的约束下$l$行选择和每列都有$k$列选择。 

第二个引理执行压缩参数：如果两行或两列“未对齐”，交换它们的选定集不会减少双重选择的数量，并最终导致所有行选择集相同且所有列选择集相同的配置。 

第三个引理明确地评估这个极值配置并准确地产生$kl$双重选择。 

最微妙的部分是压缩步骤，因为它需要表明本地交换不能减少交集计数。 

## 解决方案

 让$R_i\subset{1,\dots,n}$是对应于的列的集合$l$行中最大的元素$i$， 所以$|R_i|=l$。 让$C_j\subset{1,\dots,m}$是对应于的行集$k$列中最大的元素$j$， 所以$|C_j|=k$。 

定义

 \begin{情况} 1, & j\in R_i \text{ 和 } i\in C_j,\\ 0, & \text{否则}。 \结束{案例}$$The number of doubly underlined entries is$$X=\sum_{i=1}^m\sum_{j=1}^n x_{ij}。$$Fix the family $(R_i)$. For each column $j$, the contribution of column $j$ is $|\{i\in C_j: j\in R_i\}|$. Thus$$X=\sum_{j=1}^n |C_j\cap S_j|,$$where $S_j=\{i: j\in R_i\}$. We now perform a compression argument on the family $(R_i)$ while keeping $|R_i|=l$ fixed for all $i$. Suppose there exist rows $i_1,i_2$ and columns $j_1,j_2$ such that $j_1\in R_{i_1}$, $j_2\notin R_{i_1}$ and $j_2\in R_{i_2}$, $j_1\notin R_{i_2}$. Replace $R_{i_1}$ by $(R_{i_1}\setminus\{j_1\})\cup\{j_2\}$ and $R_{i_2}$ by $(R_{i_2}\setminus\{j_2\})\cup\{j_1\}$. For every column $j\notin\{j_1,j_2\}$, the sets $S_j$ are unchanged. For $j_1$ and $j_2$, membership in $S_j$ is swapped between $i_1$ and $i_2$. The column sets $C_j$ are unaffected, hence the only possible change in $X$ comes from columns $j_1$ and $j_2$. In each of these two columns, the number of selected rows $|C_j|=k$ is fixed. The contribution of column $j$ depends only on how many of its $k$ rows lie in $S_j$. Since swapping preserves the total number of incidences of $i_1$ and $i_2$ across $j_1,j_2$, the sum of contributions from these two columns does not decrease. Hence $X$ does not decrease under such swaps. Iterating this operation finitely many times yields a stable configuration in which all sets $R_i$ are identical; otherwise another swap is possible. Thus there exists a set $R\subset\{1,\dots,n\}$ with $|R|=l$ such that $R_i=R$ for all $i$. In this configuration, for each column $j\in R$, we have $S_j=\{1,\dots,m\}$, and for $j\notin R$, we have $S_j=\varnothing$. Hence$$X=\sum_{j\in R} |C_j|。$$Since each $C_j$ has size $k$, we obtain$$X=\sum_{j\in R} k = lk。$$This configuration is attainable, so the minimum possible value of $X$ is $kl$. Therefore at least $kl$ entries are doubly underlined, as required. Hence the number of doubly underlined entries is at least $kl$, completing the proof.$$\boxed{kl}$$## 关键步骤的验证 关键点是交换两个行选择集中的两个条目的效果。 唯一受影响的列正是交换的列，并且在每个此类列中，列选择大小保持固定为$k$，因此只有这些列中选定的行数才重要。 交换保留了两个相关行跨两个相关列的出现总数，因此这些列中每一列的贡献以补偿方式发生变化，从而防止总交集计数减少。 这确保了压缩过程是单调的。 第二个微妙点是过程的终止：每次交换严格减少无序的自然度量，例如具有不同选择模式的行对的数量，保证最终收敛到相同的行选择集。 ## 替代方法另一种方法将情况编码为两种$0$–$1$矩阵，一个标记行向上$l$条目和其他标记按列顶部-$k$条目，并应用双随机平均参数来表明最小重叠发生在两个矩阵都具有一阶结构的极值点。 这直接导致相同的极值配置，其中所有行和列都对齐，从而产生$kl$。
