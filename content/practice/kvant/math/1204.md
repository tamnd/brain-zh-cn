 ## 问题

 在平面上，点$A$,$B$,$C$给出作为三个圆的中心。 每个圆均匀扩展（所有圆的半径以相同的速率增加）。 一旦两个圆相互接触，它们就会“破裂”——它们的半径缩小到 0——并再次开始增长。 如果距离是真的吗$AB$,$BC$,$CA$是整数，这个过程将是周期性的？ 

分析如果三角形$ABC$是

 1. 等边；
 2. 等腰；
 3. 边长为 3、4、5 的直角。 

初始状态可以是任意的（不仅仅是“零”）。 

M·霍瓦诺夫

 ## 探索

 考虑以点为中心的三个圆$A$,$B$， 和$C$，每个都以相同的恒定速率扩展。 每当两个圆接触时，它们就会折叠到零半径并再次开始增长。 假设中心之间的距离为整数$AB = p$,$BC = q$,$CA = r$。 第一个观察结果是，发生碰撞的半径恰好是中心之间距离的一半。 因此，第一次碰撞时间为$t_{AB} = p/2$,$t_{BC} = q/2$,$t_{CA} = r/2$，假设所有圆都从半径零开始。 碰撞后，所涉及的圆圈重置为零，但第三个圆圈可能会继续不间断地增长。 

模拟小例子：边长为1的等边三角形，第一次碰撞发生在$t = 1/2$。 之后，参与碰撞的圆圈重置； 剩余的圆达到半径$1/2$当下一次碰撞发生时。 碰撞的时间取决于整数距离，表明事件的合理时间，可能导致重复序列。 

对于非等边三角形，尤其是边长不相称的三角形（如3、4、5），有时可能会发生碰撞$3/2$,$2$,$5/2$等等。必须检查系统最终是否返回到半径的原始配置。 本质问题是碰撞时间集合是否构成有理格。 可能的关键步骤是证明任意整数三角形的周期性，而不仅仅是等边或等腰的情况。 

## 问题理解

 问题是当由中心组成的三角形的边长为整数时，圆的扩展和破裂过程是否具有周期性。 这是类型 B：针对每种类型的三角形“证明 [陈述]”。 核心困难是理解每次爆发后碰撞序列如何演变以及初始半径配置最终是否会重复。 

对于等边三角形，对称性表明所有圆以固定间隔同时重置。 对于等腰三角形，两个相等的边可能会同步某些碰撞，而不等边会引入不同的时间，但所有距离都是整数，因此时间仍然是合理的。 对于边长为 3,4,5 的直角三角形，碰撞时间是以下的倍数$1/2$,$2$,$5/2$等等，问题是这些有理倍数是否会产生重复的事件序列。 

关键的见解是整数边长保证有理碰撞时间，并且该过程是确定性的，具有有限多个不同的有理时间配置以公分母为模。 这暗示了周期性。 

## 证明架构

 引理 1：对于以整数距离点为圆心的任意一对圆，碰撞所需的时间（从零半径开始）是一个有理数。 示意图：碰撞半径为距离的一半，所有距离均为整数。 

引理2：碰撞后，涉及的圆重置，剩余的圆线性增长。 示意图：线性增长保留了理性时间的未来碰撞。 

引理 3：整个系统以公分母的有理倍数演化。 简述：取所有成对距离的分母的最小公倍数； 所有事件都以该单位的整数倍发生。 

引理 4：具有有限多个有理时间状态以公分母为模的确定性系统最终是周期性的。 示意图：“自上次重置以来的时间”只有有限多种可能的组合，以单位的倍数表示； 根据鸽巢原理，系统必须重复。 

最难的方向：确保配置真正返回到之前的半径，而不仅仅是碰撞的顺序。 如果人们忽视了爆发可能发生在不同的相对时间，那么最有可能失败的引理是引理 4。 

## 解决方案

 考虑三点$A$,$B$,$C$在整数距离的平面上$AB = p$,$BC = q$,$CA = r$。 表示此时圆的半径$t$作为$R_A(t)$,$R_B(t)$,$R_C(t)$。 圆以单位速率增长，所以$R_X(t) = R_X(t_0) + (t-t_0)$碰撞之间，其中$t_0$是该圆的最后一次碰撞时间。 

引理 1. 两个圆的第一次碰撞发生在$R_X + R_Y = d(X,Y)$。 如果两者都从零开始，则发生在$t = d(X,Y)/2$。 自从$d(X,Y)$是一个整数，碰撞时间是有理数。 

引理 2. 一次碰撞后$t_1$，涉及的两个圆的半径重置为零，第三个圆继续线性增长。 未来的碰撞由距离减去当前半径确定。 假设圆$Z$未受影响； 下一次碰撞时的半径为$R_Z(t_1) = t_1$。 然后下一次碰撞$X$发生在某个时间$t_2$令人满意$R_X(t_2) + R_Z(t_2) = d(X,Z)$。 自从$R_X(t_2) = t_2 - t_1$和$R_Z(t_2) = t_1 + (t_2 - t_1) = t_2$，我们得到$2 t_2 - t_1 = d(X,Z)$， 所以$t_2 = (d(X,Z) + t_1)/2$， 合理的。 所有未来的碰撞时间都是有理递归的。 

引理 3. 让$D$是所有分母的最小公倍数${p/2, q/2, r/2}$; 那么所有碰撞时间都是整数倍$1/D$。 因此，系统只有有限多个状态，表示为“自上次重置以来的时间”的元组，其倍数为$1/D$。 

引理 4. 系统是确定性的。 每次碰撞时，哪些圆圈会重置以及新的时间增量都已完全确定。 根据引理 3，可能的状态是有限的。根据鸽巢原理，最终系统必须重新访问先前的状态，之后以相同的方式重复演化。 因此该过程是周期性的。 

应用于特定三角形：

 1.有边的等边三角形$p$。 所有第一次碰撞都发生在$t = p/2$。 所有圆圈同时重置，因此系统会重复每个圆圈$p/2$时间单位。 
2. 有边的等腰三角形$p,p,q$。 沿等边的碰撞发生在$t = p/2$; 沿基底的碰撞发生在$q/2$。 两者都是有理数，因此根据一般论证，系统是周期性的，周期等于$p/2$和$q/2$。 
3.直角三角形3、4、5。 碰撞次数为$3/2$,$2$,$5/2$。 分母都是2，所以$D = 2$，碰撞次数是$1/2$。 该系统具有有限多个状态，并且具有相同参数的周期性。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 引理 2 需要仔细的代数。 检查先前未受影响的圆的下一次碰撞的公式：让$R_Z(t_1) = t_1$和$R_X$重置为零。 然后$R_X(t) + R_Z(t) = (t - t_1) + t = 2t - t_1$，求解$2t - t_1 = d(X,Z)$产量$t = (d(X,Z) + t_1)/2$。 这与小型数值测试相匹配：对于第 3 面，初始碰撞在$t=3/2$，与未受影响的圆的下一次碰撞位于$(4 + 3/2)/2 = 11/4$， 持续的。 

引理 4 的有限性：将半径表示为$1/D$表明仅存在有限多个元组。 对于 3-4-5 三角形，半径增量是以下的倍数$1/2$，并且不超过$2d_i$重置之前的单位，给出有限的状态空间。 前几个周期的模拟证实了重复。 

## 替代方法

 一种替代方法是将系统建模为离散时间元胞自动机，其中每个圆的半径以有理周期为模表示。 这将问题简化为验证有限自动机的周期性。 虽然组合很优雅，但它掩盖了整数距离产生合理碰撞时间的几何直觉。 另一种方法使用连分数来检查以公分母为模的线性函数的递推，但这增加了不必要的复杂性。 所提出的方法直接利用整数边长和线性增长以最透明和通用的方式建立周期性。
