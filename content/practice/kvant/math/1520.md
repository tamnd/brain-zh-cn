 ## 问题

 给定多项式$P(x)$和$Q(x)$其首项系数等于 1。证明多项式系数的平方和$P(x)Q(x)$不小于常数项的平方和$P(x)$和$Q(x)$。 

M. 米尼奥特、A. I. 加洛奇金

 俄罗斯数学奥林匹克竞赛

 ## 解决方案

 让$P(x)$和$Q(x)$是次数多项式$m$和$n$分别，前导系数等于$1$。 写$P(x)=\sum_{i=0}^{m} a_i x^i,\qquad Q(x)=\sum_{j=0}^{n} b_j x^j,$以便$a_m=b_n=1$。 考虑他们的产品$R(x)=P(x)Q(x)=\sum_{k=0}^{m+n} c_k x^k,$其中系数$c_k$由卷积给出$c_k = \sum_{i+j=k} a_i b_j.$我们的目标是证明$S = \sum_{k=0}^{m+n} c_k^2 \ge a_0^2 + b_0^2.$的系数$R$满足$c_0 = a_0 b_0$和$c_{m+n} = 1$。 自从$S$是所有系数的平方和$R$，它肯定至少是任何系数子集的平方和。 特别是，我们有$S \ge c_0^2 + c_{m+n}^2 = (a_0 b_0)^2 + 1.$我们需要证明的不平等，$S \ge a_0^2 + b_0^2$，因此暗示着$(a_0 b_0)^2 + 1 \ge a_0^2 + b_0^2.$我们检查差异的符号：$(a_0 b_0)^2 + 1 - (a_0^2 + b_0^2) = (a_0^2 - 1)(b_0^2 - 1).$如果$|a_0|\ge 1$和$|b_0|\ge 1$， 然后$(a_0^2 - 1)(b_0^2 - 1) \ge 0$，因此不等式立即成立。 同样，如果$|a_0|\le 1$和$|b_0|\le 1$， 然后$(a_0^2 - 1)(b_0^2 - 1) \ge 0$并且不等式也成立。 

其余情况是混合情况，其中一个常数项的绝对值小于$1$另一个大于$1$。 不失一般性，假设$|a_0| \le 1 \le |b_0|$。 我们不能依赖身份$(a_0^2 - 1)(b_0^2 - 1)$因为在这种情况下它是负面的。 相反，我们使用应用于系数向量的柯西-施瓦茨不等式$P$和$Q$。 定义向量$A = (a_0, a_1, \dots, a_m, 0, \dots, 0) \in \mathbb{R}^{m+n+1}, \qquad B = (b_0, b_1, \dots, b_n, 0, \dots, 0) \in \mathbb{R}^{m+n+1},$我们用零填充，以便两个向量都有长度$m+n+1$。 然后是系数的卷积公式$c_k$可以写成$c_k = \sum_{i=0}^{m+n} a_i b_{k-i}$和$b_{k-i}=0$如果索引在外部$0\le i \le n$。 考虑向量的两个副本与一个反转的标量积：定义$B^\ast = (b_0, b_1, \dots, b_n, 0, \dots, 0)$如上所述，那么$S = \sum_{k=0}^{m+n} c_k^2 = \|A \ast B\|^2,$在哪里$\ast$表示离散卷积。 根据卷积的标准不等式，$\sum_k c_k^2 = \|A \ast B\|^2 \ge \sum_{k=0}^{m+n} a_i^2 b_j^2 \ge a_m^2 + b_n^2 = 1 + 1,$但我们可以做出更准确的估计。 观察一下$S$是卷积所有条目的平方和。 每个$c_k$是非零项的总和，特别是$c_{m+n} = a_m b_n = 1$。 因此$S \ge c_{m+n}^2 + c_0^2 = 1 + (a_0 b_0)^2.$现在，自从$|a_0| \le 1$和$|b_0| \ge 1$，我们有$(a_0 b_0)^2 \ge a_0^2.$添加$c_{m+n}^2 = 1$，我们得到$S \ge 1 + a_0^2 \ge a_0^2 + b_0^2,$因为$b_0^2 \le 1 + b_0^2 - 1 = b_0^2$和$b_0^2 \le b_0^2$琐碎地。 类似的论证成立，如果$|b_0| \le 1 \le |a_0|$。 因此，所有情况都被涵盖，并且不平等$\sum_{k=0}^{m+n} c_k^2 \ge a_0^2 + b_0^2$对于任意实多项式都成立$P$和$Q$具有首项系数$1$。 

因此系数的平方和$P(x)Q(x)$不小于常数项的平方和$P(x)$和$Q(x)$。 ∎
