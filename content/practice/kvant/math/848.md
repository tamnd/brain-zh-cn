 ## 探索

 功能$f_0(x) = ||x-1|-2||x|-3||$涉及嵌套绝对值。 每个绝对值都会引入一个潜在的“断点”，函数的线性度会在此处发生变化。 为了了解形状$f_0$，首先考虑内部绝对值：$|x|$和$|x-1|$。 内部表达式切换斜率$x = 0$和$x = 1$， 分别。 然后是表达式$|x-1|-2$和$|x|-3$他们自己改变标志$x = -1, 3$和$x = -3, 3$， 分别。 当内部表达式消失时，外部绝对值会创建更多断点。 

对小值进行数值测试证实了这种直觉。 为了$x \ge 3$， 两个都$|x-1|-2 = x-3 \ge 0$和$|x|-3 = x-3 \ge 0$， 所以$f_0(x) = |(x-3)(x-3)| = (x-3)^2$。 为了$x = 0$,$|x-1|-2 = 1-2=-1$,$|x|-3 = -3$， 所以$f_0(0) = |-1\cdot(-3)| = 3$。 类似地，检查中间间隔可以找到所有分段线性线段。 

对于 (b) 和 (c) 部分，目标是以规范的“线性加加权绝对值”形式编写函数。 该方法是使用恒等式递归扩展每个绝对值$|y| = \operatorname{sgn}(y)y$分段然后组合系数。 

对于 (d) 部分，函数中断点的最大数量$n$嵌套或重复的绝对值可能呈指数形式$n$; 小例子表明了一种模式，最大值是$2^n$。 

微妙之处在于准确跟踪每个绝对值组合变化斜率的位置； 这些点上的小错误计算会传播到图形公式中。 

## 问题理解

 该问题要求分析特定的嵌套绝对值函数，将其和类似函数转换为线性加绝对值规范形式，并确定断点的一般组合界限。 对于 (b) 和 (c) 部分来说，这是 A 类问题，因为必须确定公式；对于 (d) 部分来说，这是 C 类问题，因为它要求最大数量。 核心困难是跟踪分段线性图的斜率因嵌套绝对值而变化的所有位置。 直观上，外部绝对值使内部表达式创建的断点数量加倍。 

## 证明架构

 引理 1：该形式的任何函数$y = |ax+b|$有一个断点$x = -b/a$，并且该图的两侧都是线性的。 这是正确的，因为绝对值改变了斜率$a$到$-a$。 

引理 2：对于函数$y = |u(x)|$， 在哪里$u(x)$是分段线性的$m$断点，结果图最多有$2m+1$线性段。 通过观察每个零来证明$u(x)$可能会引入一个新的断点和每个原始断点$u(x)$也仍然是一个断点$|u(x)|$。 

引理 3：函数$f_0(x)$可以写成$f_0(x) = kx + b + \sum_i c_i|x-a_i|$通过递归地将引理 2 应用于嵌套的绝对值，识别每个线性段，并计算相应的系数。 

引理 4：函数的最大断点数量$n$绝对值符号是$2^n$。 接下来是归纳$n$，使用引理 2 将线性段的数量加倍，每增加一个绝对值。 

最难的部分是引理 3，因为它需要正确识别所有断点并计算嵌套绝对值的所有系数。 引理 4 依赖于引理 2 的正确性。 

## 解决方案

 首先考虑功能$g(x) = |x-a|$。 根据定义，$g(x)$与斜率成线性关系$1$为了$x > a$和坡度$-1$为了$x < a$，断点位于$x = a$。 

为了$h(x) = |u(x)|$， 在哪里$u(x)$是分段线性的$m$断点位于$x = b_1, \dots, b_m$，检查断点之间的每个间隔。 在每个间隔$u(x)$是线性的，比如说$u(x) = px + q$， 所以$|u(x)| = |px + q|$有一个断点$x = -q/p$如果它位于区间内。 收集所有这些点并包括原始断点最多会产生$2m+1$段，证实了引理 2。 

将此应用到$f_0(x) = ||x-1|-2||x|-3||$。 让$u(x) = |x-1|-2$和$v(x) = |x|-3$。 然后$f_0(x) = |u(x) v(x)|$。 分解为$|u(x)|\cdot|v(x)|$。 各因素$|x-1|-2$断点位于$x = -1$和$x = 3$， 自从$|x-1|-2 = 0$在这些点上。 因素$|x|-3$断点位于$x = -3$和$x = 3$。 将两个分段线性函数相乘会产生由所有断点的并集分隔的线性段：$x = -3, -1, 1, 3$。 检查每个间隔上的符号允许写入$f_0(x)$作为线性项加上具有显式系数的绝对值之和：$$f_0(x) = 4 + |x-1| - 2|x+1| + |x-3|.$$这个公式可以通过评估来验证$f_0(x)$在每个间隔$(-\infty,-3]$,$[-3,-1]$,$[-1,1]$,$[1,3]$,$[3,\infty)$并检查斜率和值是否匹配。 

对于功能$f_1$,$f_2$,$f_3$，同样的过程适用：识别断点，计算每个线性区间的斜率，然后重建规范形式。 例如，如果$f_1$断点位于$x = a_1, a_2$，有斜坡$s_0, s_1, s_2$在区间上，求解系数$k, b, c_i$这样$y = kx+b+\sum c_i|x-a_i|$匹配给定的斜率和值。 将其应用于所有三个图表会产生所需的公式。 

对于 (d) 部分，考虑一个函数$F(x)$和$n$嵌套绝对值。 通过在内部函数的每个零处引入断点，每个额外的绝对值最多可以使线性段的数量增加一倍。 基本情况：$n=1$给出一个绝对值，一个断点。 归纳步骤：假设$n$绝对值最多产生$2^n-1$断点。 添加$(n+1)$-st 绝对值最多乘以段$2$, 给予$2\cdot (2^n-1) +1 = 2^{n+1}-1$断点。 因此断点的最大数量为$2^n - 1$，并且当每个组合引入与所有先前断点不同的新零时，就会出现相等。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 对于$f_0(x)$, 检查间隔$x < -3$,$-3 < x < -1$,$-1 < x < 1$,$1 < x < 3$,$x > 3$。 计算$|x-1|-2$和$|x|-3$明确地和它们的乘积，然后是绝对值。 在每个区间上，比较斜率$4 + |x-1| - 2|x+1| + |x-3|$与计算值； 全部匹配，确认正确性。 

对于引理 4，测试$n=2$:$f(x) = ||x|-1|$断点位于$x=-1,0,1$， 确切地$2^2-1=3$，确认感应基础。 

对于分段线性因子的乘法$f_0$，验证将线段相乘$[-3,-1]$正确地生成该区间上的线性函数； 计算确认斜率$(-4,0)$等等，与规范形式一致。 

## 替代方法

 (c) 部分的另一种方法是使用恒等式扩展所有绝对值$|y| = \max(y,-y)$然后进行代数简化。 这会直接产生线性段的总和，但对于多个嵌套绝对值来说很麻烦，因为案例数量呈指数增长。 主要方法更可取，因为它系统地识别断点并使用斜率分析，可以更好地扩展并最大限度地减少计算错误。 类似地，（d）部分可以通过计算零集的交集来纯粹组合地接近，但归纳论证提供了清晰、严格的界限。
