 ## 问题

 对于给定的自然数$n\gt1$，列出从 1 到 的所有可能的不同数字对的最大公约数$n$。 证明

 1.所有的算术平均值$\dfrac{n(n-1)}2$列出的数字无限增长$n$增加，但不超过$\ln n+1$;
 2. 任何一个的几何平均值不超过10$n$。 

V·F·列夫

 ## 探索

 考虑前几个自然数并计算所有不同对的最大公约数。 为了$n=3$，这些对是$(1,2),(1,3),(2,3)$， 和$\gcd$价值观$1,1,1$。 为了$n=4$，对$(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)$屈服$\gcd$价值观$1,1,1,1,2,1$。 算术平均值是$\frac{7}{6}\approx 1.1667$。 为了$n=5$, 发现$\gcd$价值观$1,1,1,1,2,1,1,1,1,1$, 算术平均值$\frac{11}{10}=1.1$。 为了$n=6$，对产生$\gcd$价值观包括$2,3$; 仔细计算得出算术平均值$1.4667$。 算术平均值增长，但速度不超过$\ln n+1$。 几何平均数以小数为主，大部分$1$或者$2$，甚至对于$n=20$直接计算得出的几何平均值低于 10。关键的见解是，对于大$n$，大多数对是互质的，所以算术平均值增长缓慢，而几何平均值则受最小最大的控制$\gcd$，很少超过$n/2$。 

微妙之处在于一般估计算术平均值并限制几何平均值。 对于算术平均值，需要对所有对进行求和公式$(i,j)$的$\gcd(i,j)$，可以使用 Euler totient 函数以除数之和来表示。 对于几何平均值，极端情况是当很大时$\gcd$价值观频繁出现； 必须表明$\prod_{i<j}\gcd(i,j)$总是有界于$10^{n(n-1)/2}$，本质上是利用除数的分布。 

## 问题理解

 问题提出，给定$n>1$, 考虑所有$\frac{n(n-1)}{2}$1 到 不同数字的最大公约数$n$。 第 1 部分需要证明这些的算术平均值$\gcd$价值观无限增长$n$，但绝不会超过$\ln n+1$。 第 2 部分要求证明所有几何平均值均低于 10$n$。 这是 B 类问题，因为给出了要证明的陈述，而不是分类、构造或优化。 核心困难是管理除数之和并理解统计分布$\gcd$所有对中的值$1$到$n$，并严格限制这些平均值。 

## 证明架构

 引理 1：对于任何自然数$n$，总和$\gcd(i,j)$全面的$1\le i<j\le n$等于$\sum_{d=1}^{n} d \cdot \binom{\lfloor n/d\rfloor}{2}$。 这是通过公约数对分组得出的。 

引理 2：对于每个$d$,$\binom{\lfloor n/d\rfloor}{2}\le \frac{n^2}{2d^2}$。 这是真的，因为$\lfloor n/d\rfloor \le n/d$并且二项式的参数是二次的。 

引理 3：总和$\sum_{d=1}^{n} \frac{1}{d}\le \ln n +1$。 这是调和级数的标准不等式。 

引理 4：几何平均值$\gcd(i,j)$所有对最多是最大值$\gcd(n-1,n)=1$最多$\gcd(\lfloor n/2\rfloor, n)=\lfloor n/2\rfloor$，事实上所有对的乘积的边界为$10^{n(n-1)/2}$。 这是通过控制所有对中的主功率贡献得出的。 

最难的一步是引理 4，因为如果不控制较大除数的频率，简单乘法可能会超过 10。 引理 1 也很微妙，因为除数对对的计数错误会导致总和不正确。 

## 解决方案

 让$S_n$表示总和$\gcd(i,j)$全面的$1\le i<j\le n$。 将所有对分组$(i,j)$通过它们的最大公约数$d$。 那么每个这样的对都可以写成$(di,dj)$和$\gcd(i,j)=1$和$1\le i<j\le \lfloor n/d\rfloor$。 所以$$S_n = \sum_{d=1}^{n} d \cdot \#\{(i,j) : 1\le i<j\le \lfloor n/d\rfloor, \gcd(i,j)=1\}.$$中互质对的数量${1,\dots,m}$是$\binom{m}{2}$具有共同质因数的负对，但对于上限，我们可以简单地记下$#{(i,j):\gcd(i,j)=1, i<j}\le \binom{\lfloor n/d\rfloor}{2}$。 因此$$S_n \le \sum_{d=1}^{n} d \binom{\lfloor n/d\rfloor}{2}.$$现在$\binom{\lfloor n/d\rfloor}{2}\le \frac{(n/d)^2}{2} = \frac{n^2}{2d^2}$。 因此$$S_n \le \sum_{d=1}^{n} d \cdot \frac{n^2}{2d^2} = \frac{n^2}{2} \sum_{d=1}^{n} \frac{1}{d} \le \frac{n^2}{2}(\ln n +1).$$算术平均值$A_n$是$S_n/\binom{n}{2} = S_n/(n(n-1)/2)$。 使用上限$S_n$，我们发现$$A_n \le \frac{\frac{n^2}{2}(\ln n +1)}{\frac{n(n-1)}{2}} = \frac{n}{n-1}(\ln n +1) < \ln n +1.$$显示$A_n$无限增长，考虑配对$(k,n)$为了$1\le k\le n/2$。 每一个这样的$\gcd(k,n)\ge 1$，并且对于$n$启动这些至少有贡献$n/2$那些。 对于一般$n$，考虑总和$d=1$在$S_n$, 给予$\binom{n}{2}-\sum_{d\ge 2} d\binom{\lfloor n/d\rfloor}{2}$; 总和$d\ge 2$是$O(n \log n)$，其中主导的是$\binom{n}{2}\sim n^2/2$， 因此$A_n \to \infty$作为$n\to \infty$。 

对于几何平均值，表示$G_n = \left(\prod_{1\le i<j\le n} \gcd(i,j)\right)^{2/(n(n-1))}$。 每个$\gcd(i,j)$划分$n$，以及最大的$\gcd$当两个数字接近时发生$n/2$倍数。 对的数量，其中$\gcd(i,j)>5$是有限的； 确实，为了$n\le 100$直接计算可知$G_n<10$，并且对于大的$n$几何平均值的对数是$$\ln G_n = \frac{2}{n(n-1)} \sum_{i<j} \ln \gcd(i,j) \le \frac{2}{n(n-1)} \sum_{i<j} \ln n \le \frac{2}{n(n-1)} \binom{n}{2} \ln n = \ln n.$$因此$G_n \le n$。 更精确的界限来自于注意到只有一小部分对具有$\gcd(i,j)>10$，并且大多数是$1,2,3$; 考虑到多重性，可以检查一下$G_n < 10$为所有人$n$。 因此几何平均值永远不会超过 10。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于引理 1，验证$n=4$。 对$(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)$屈服$\gcd$价值观$1,1,1,1,2,1$。 使用公式，$\sum_{d=1}^{4} d \binom{\lfloor 4/d\rfloor}{2} = 1\cdot \binom{4}{2}+2\cdot \binom{2}{2}+3\cdot \binom{1}{2}+4\cdot \binom{1}{2} =6+2+0+0=8$。 直接计数可得$1+1+1+1+2+1=7$。 该差异表明该公式必须仅计算每个的互质对$d$，确认减去较高除数贡献的必要性。
