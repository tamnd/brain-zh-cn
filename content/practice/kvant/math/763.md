 ## 问题

 给定一个平行四边形$ABCD$那不是菱形。 线对称于$AB$相对于对角线$AC$相交于点$Q$线对称于$DC$相对于对角线$DB$（图2）。 找出比例$|QA|:|QD|$如果比率$|AC|:|BD|=k$是已知的。

 ## 探索

 让$$s=\overrightarrow{AC},\qquad t=\overrightarrow{DB}.$$平行四边形的对角线互相平分，所以如果$$a=\overrightarrow{AB},\qquad d=\overrightarrow{AD},$$然后$$s=a+d,\qquad t=a-d.$$因此$$a=\frac{s+t}{2},\qquad d=\frac{s-t}{2}.$$线对称于$AB$关于$AC$经过$A$并具有通过反射向量获得的方向$a$在跨越的线上$s$。 线对称于$DC$关于$DB$经过$D$并具有通过反射向量获得的方向$DC=a$在跨越的线上$t$。 

非菱形假设是必要的。 自从$$|s|^2-|t|^2 = |a+d|^2-|a-d|^2 = 4\,a\cdot d,$$条件$s\perp t$给出$$0=s\cdot t=(a+d)\cdot(a-d)=|a|^2-|d|^2.$$因此$|a|=|d|$，所以平行四边形的所有边都相等并且平行四边形是菱形。 问题排除了这种情况。 最后，$$s\cdot t\neq0.$$取消时将使用此事实$s\cdot t$之后。 

## 问题理解

 平行四边形$ABCD$被给出。 边线$AB$沿着对角线反射$AC$，和边线$DC$沿着对角线反射$DB$。 他们的图像相交于一点$Q$。 

比率$$\frac{|AC|}{|BD|}=k$$是已知的。 目标是确定$$\frac{|QA|}{|QD|}.$$自然的框架是具有对角向量的向量几何$s=\overrightarrow{AC}$和$t=\overrightarrow{DB}$。 

## 证明架构

 通过对角线表达平行四边形的边。 使用标准反射公式计算两条反射线的方向。 写出交点$Q$在两条线上采用参数形式并求解参数。 将这些参数与距离相关联$QA$和$QD$利用反射保持长度这一事实。 最后消除所有对角度的依赖，只保留对角线长度的比率。 

## 解决方案

 让$$a=\frac{s+t}{2},\qquad d=\frac{s-t}{2},$$并让$$s=\overrightarrow{AC},\qquad t=\overrightarrow{DB}.$$对于非零向量$u$，在跨越的线上的反射$u$由下式给出$$R_u(v)=2\frac{u\cdot v}{u\cdot u}\,u-v.$$让$r_1$是图像的方向向量$AB$反思中$AC$。 然后$$r_1=R_s(a).$$自从$$s\cdot a = s\cdot\frac{s+t}{2} = \frac{|s|^2+s\cdot t}{2},$$我们得到$$r_1 = 2\frac{s\cdot a}{|s|^2}s-a = \left(\frac{|s|^2+s\cdot t}{|s|^2}\right)s-\frac{s+t}{2} = \left(\frac12+\frac{s\cdot t}{|s|^2}\right)s-\frac12\,t.$$介绍$$m=\frac{s\cdot t}{|s|^2}.$$然后$$r_1=\left(\frac12+m\right)s-\frac12\,t.$$侧面$DC$平行于$AB$并具有相同的方向向量$a$。 让$r_2$是图像的方向向量$DC$反思中$DB$。 然后$$r_2=R_t(a).$$自从$$t\cdot a = t\cdot\frac{s+t}{2} = \frac{s\cdot t+|t|^2}{2},$$我们得到$$r_2 = 2\frac{t\cdot a}{|t|^2}t-a = \left(\frac{s\cdot t+|t|^2}{|t|^2}\right)t-\frac{s+t}{2} = -\frac12\,s+\left(\frac12+\frac{s\cdot t}{|t|^2}\right)t.$$放$$n=\frac{s\cdot t}{|t|^2}.$$然后$$r_2=-\frac12\,s+\left(\frac12+n\right)t.$$第一条反射线穿过$A$，第二个通过$D$。 写$$Q=A+\lambda r_1=D+\mu r_2.$$自从$$\overrightarrow{AD}=d=\frac{s-t}{2},$$我们有$$\lambda r_1=\frac{s-t}{2}+\mu r_2.$$因为$s$和$t$不是平行的，它们构成了基础。 比较系数$s$和$t$给出$$\lambda\left(\frac12+m\right)=\frac12-\frac{\mu}{2},$$和$$-\frac{\lambda}{2} = -\frac12+\mu\left(\frac12+n\right).$$乘以$2$,$$\lambda(1+2m)=1-\mu,$$

$$-\lambda=-1+\mu(1+2n).$$第二个方程给出$$\lambda=1-\mu(1+2n).$$代入第一个，$$(1-\mu(1+2n))(1+2m)=1-\mu.$$扩大，$$1+2m-\mu(1+2n)(1+2m)=1-\mu.$$因此$$2m=\mu\bigl((1+2n)(1+2m)-1\bigr).$$自从$$(1+2n)(1+2m)-1 = 1+2m+2n+4mn-1 = 2(m+n+2mn),$$我们得到$$\mu=\frac{m}{2mn+m+n}.$$然后$$\lambda = 1-\frac{m(1+2n)}{2mn+m+n} = \frac{2mn+m+n-m-2mn}{2mn+m+n} = \frac{n}{2mn+m+n}.$$所以$$\frac{\lambda}{\mu} = \frac{n}{m}.$$自从$s\cdot t\neq0$,$$m=\frac{s\cdot t}{|s|^2}\neq0, \qquad n=\frac{s\cdot t}{|t|^2}\neq0.$$而且，$$\frac{n}{m} = \frac{\dfrac{s\cdot t}{|t|^2}} {\dfrac{s\cdot t}{|s|^2}} = \frac{|s|^2}{|t|^2} >0.$$因此$\lambda/\mu>0$， 所以$\lambda$和$\mu$有相同的标志。 最后，$$\frac{|\lambda|}{|\mu|} = \frac{\lambda}{\mu}.$$反射保留长度。 两个都$r_1$和$r_2$是同一个向量的反射$a$， 因此$$|r_1|=|a|, \qquad |r_2|=|a|,$$因此$$|r_1|=|r_2|.$$自从$$Q=A+\lambda r_1, \qquad Q=D+\mu r_2,$$我们有$$|QA|=|\lambda|\,|r_1|, \qquad |QD|=|\mu|\,|r_2|.$$因此$$\frac{|QA|}{|QD|} = \frac{|\lambda|\,|r_1|} {|\mu|\,|r_2|} = \frac{|\lambda|}{|\mu|} = \frac{\lambda}{\mu} = \frac{n}{m}.$$使用$s\cdot t\neq0$, 因子$s\cdot t$可能被取消：$$\frac{n}{m} = \frac{\dfrac{s\cdot t}{|t|^2}} {\dfrac{s\cdot t}{|s|^2}} = \frac{|s|^2}{|t|^2}.$$所以$$\frac{|QA|}{|QD|} = \frac{|s|^2}{|t|^2} = \frac{|AC|^2}{|BD|^2}.$$自从$$\frac{|AC|}{|BD|}=k,$$由此可见$$\frac{|QA|}{|QD|}=k^2.$$因此$$\boxed{|QA|:|QD|=k^2:1}.$$## 关键步骤验证

 菱形担保的排除$s\cdot t\neq0$。 确实，如果$s\cdot t=0$，则对角线垂直。 对于平行四边形，$$0=(a+d)\cdot(a-d)=|a|^2-|d|^2,$$所以$|a|=|d|$，这意味着所有边都相等，平行四边形是菱形。 由于该问题假设平行四边形不是菱形，因此必须有$s\cdot t\neq0$。 

这种不消失证明了取消的合理性$$\frac{\dfrac{s\cdot t}{|t|^2}} {\dfrac{s\cdot t}{|s|^2}} = \frac{|s|^2}{|t|^2}.$$同样的事实意味着$m$和$n$都是非零并且具有相同的符号，因为两者都是通过除以相同的非零数获得的$s\cdot t$由正量。 因此$$\frac{\lambda}{\mu} = \frac{n}{m} = \frac{|s|^2}{|t|^2} >0,$$这表明$\lambda$和$\mu$具有相同的符号并允许替换$$\frac{|\lambda|}{|\mu|} = \frac{\lambda}{\mu}.$$向量$s$和$t$线性无关，因为非简并平行四边形的对角线不同且不平行。 这证明了比较基础中的系数是合理的${s,t}$。 

## 替代方法

 坐标方法将对角线放置在方便的坐标轴上。 为反射线写出显式方程并求解它们的交点再次导致$$\frac{|QA|}{|QD|} = \frac{|AC|^2}{|BD|^2} = k^2.$$矢量方法隔离了对对角线长度的依赖性并直接产生比率。
