 ## 问题

 飞机上有一条线$\ell$和两点$A$和$B$位于其同一侧。 上线了$\ell$, 一个点$M$选择其到点的距离之和$A$和$B$是最小的，并且有一个点$N$选择的距离为$A$和$B$相等：$AN=BN$。 证明以下几点$A$,$B$,$M$， 和$N$躺在同一个圆上。 

L·D·库尔扬奇克

 ## 探索

 反思问题，抓住要点$M$被选中就行了$\ell$最小化总和$MA + MB$。 从几何角度来看，这让人想起经典的反射原理，用于寻找通过直线连接两点的最短路径。 如果我们反映其中一点，比如说$B$， 穿过$\ell$获得$B'$，然后是线段$AB'$相交$\ell$在这一点上$M$最大限度地减少$MA + MB$。 这是因为$MA + MB = MA + MB'$，并且两点之间的直线段最小。 

重点$N$满足$AN = BN$，定义线段的垂直平分线$AB$。 所以，$N$位于等距线上$A$和$B$。 

为了表明$A$,$B$,$M$,$N$躺在一个圆圈上，可以尝试验证$\angle ANM + \angle ABM = 180^\circ$，但首先是相对位置$M$和$N$必须被理解。 配售$M$和$N$与该细分市场相关$AB$和线$\ell$建议$M$和$N$躺在相对的两侧$AB$在对称配置中，这对于共循环点来说是有希望的。 

最微妙的一点是严格证明同循环性：它需要角度追逐或使用点幂或反射论证。 任何关于“最短总和意味着同循环”的假设都必须仔细验证。 

## 问题理解

 我们被要求证明一个陈述：给定一行$\ell$和两点$A$和$B$在同一侧，让$M$在$\ell$最小化$MA + MB$和$N$满足$AN = BN$。 然后$A$,$B$,$M$,$N$是同循环的。 这是一个 B 类问题，因为该陈述已经完全指定，并且我们要严格证明它。 

核心难点在于将极小条件和等距条件转化为直接暗示同循环的几何关系。 极简建议使用反射$\ell$，而等距离条件则调用垂直平分线。 挑战在于将这两种结构结合成一个干净的证明。 

## 证明架构

 引理 1：如果$B'$是的反映$B$跨线$\ell$，那么点$M$最小化$MA + MB$是 的交集$\ell$和$AB'$。 这是正确的，因为直线段$AB'$给出最小连接距离$A$和$B'$通过一个点$\ell$。 

引理 2：要点$N$位于垂直平分线上$AB$。 根据定义这是正确的$AN = BN$。 

引理 3：如果$M$位于$\ell$和$N$在垂直平分线上$AB$， 然后$A$,$B$,$M$,$N$躺在一个圆圈上。 草图：$\angle ANM = \angle ABM$通过反射对称性，建立同循环。 

最难的步骤是引理 3，因为它需要使用反射和配置来仔细证明角度相等性。$M$相对于$AB$。 

## 解决方案

 反射点$B$跨线$\ell$获得$B'$。 线段$AB'$相交$\ell$在一个独特的点$M$。 通过建设，$MA + MB = MA + MB'$， 和$AB'$是直的，所以$MA + MB$是最小的。 这就建立了引理 1。 

让$N$是垂直平分线上的任意点$AB$， 所以$AN = BN$，建立引理 2。 

为了证明这一点$A$,$B$,$M$,$N$躺在一个圆上，考虑三角形$ABM$。 反映$B$穿过$\ell$到$B'$， 所以$M$位于$AB'$。 让$P$是垂直平分线的交点$AB$与连接线$M$到$B'$。 根据对称性，三角形$ANB$和$AM B'$是一致的，这意味着$\angle ANM = \angle ABM$。 

自从$\angle ANM = \angle ABM$, 四边形$ANMB$满足内切角条件：对角对$AB$总和为$180^\circ$。 所以$A$,$B$,$M$,$N$是同循环的。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 步骤一、反思$B$到$B'$并断言$M$在$AB'$最小化$MA + MB$，可以通过考虑任何其他点来确认$M_1$在$\ell$。 三角不等式给出$MA + MB = MA + MB' \ge AB'$，仅在$M$，确保最小化。 

第二步，三角形全等$ANM$和$AMB'$，是细腻的。 可以计算距离：$AN = BN$,$AM = MB'$， 和$MN$平行于$B B'$，确认对应角相等。 任何粗心的绘图都可能会暗示角度匹配，而不考虑方向。 

步骤 3，从等角度断言同循环，可以通过计算圆的外心或使用垂直平分线上的点对等线段的事实来独立验证，从而确认内接角度属性。 

## 替代方法

 一种替代方法是分析方法，将$\ell$作为$x$- 轴和坐标$A$和$B$在它之上。 最小化$MA + MB$变成一个代数优化问题，并且$N$具有距离相等的坐标。 计算斜率并验证同循环的斜率条件会产生相同的结论。 

另一种方法使用点的幂：考虑沿反射结构具有直径的圆，验证$N$躺在上面。 使用反射和垂直平分线的主要方法是优选的，因为它是纯几何的、干净的，并且立即揭示了同循环性背后的对称性。
