 ## 问题$n$数字（$n\gt1$) 被称为关闭，如果它们中的每一个都小于这些数字的总和除以$n-1$。 让$a$,$b$,$c$,$\ldots$是$n$接近数字，并让$S$是他们的总和。 证明

 1. 全部为阳性；
 2. 总是$a+b\gt c$;
 3. 总是$a+b\ge\dfrac S{n-1}$。 

R·施莱弗

 城市锦标赛

 ## 探索

 考虑“接近”数字的定义。 为了$n$数字$a_1, a_2, \dots, a_n$, 各满足$a_i < \frac{a_1 + a_2 + \dots + a_n}{n-1} = \frac{S}{n-1}.$为了$n = 2$，不等式减少为$a < b/(2-1) = b$和$b < a$，这是不可能的。 于是，本案$n = 2$被排除在外。 为了$n = 3$，设数字为$a, b, c$。 不平等变成了$a < \frac{b+c}{2}$,$b < \frac{a+c}{2}$,$c < \frac{a+b}{2}$。 小数值例子表明所有数字都是正数并且满足$a+b > c$。 例如，与$a=1, b=2, c=2$，我们计算$S = 5$， 然后$S/(n-1) = 5/2 = 2.5$，而且确实$1<2.5$,$2<2.5$,$2<2.5$。 此外，$a+b = 3 > c = 2$,$a+b = 3 > S/(n-1) = 2.5$。 这证实了这一模式。 主要挑战是严格证明任意性的正性和不等式$n$，特别是确保不平等$a+b \ge S/(n-1)$对于任何数字对都成立。 

最有可能隐藏错误的步骤是证明正性，因为不等式是严格的，但仅相对于$n-1$数字。 

## 问题理解

 我们被要求证明三项陈述$n>1$数字$a_1, \dots, a_n$称为“接近”，由不等式定义$a_i < S/(n-1)$对于每个$i$， 在哪里$S = a_1+\dots+a_n$。 问题属于B型，即纯证明，因为要证明的陈述是明确给出的。 核心难点是处理好各个之间的依赖关系$a_i$基于所有数字的总和并确保严格的不平等会导致正数和总不平等。 

## 证明架构

 引理 1：每个接近的数都是正数。 示意图：假设一个数是非正数； 将不等式相加会导致矛盾。 

引理 2：对于任意三个数字$a, b, c$其中$n$数字，$a+b>c$。 草图：将接近度的定义应用到$c$并重新排列。 

引理 3：对于任意两个数$a, b$,$a+b \ge S/(n-1)$。 草图：除$a$和$b$束缚$S$按照$a+b$。 

最难的方向是引理 1，因为天真的否定性假设可以表面上满足一个不等式。 引理 3 是最微妙的，因为它涉及到$n$变量和相等性是不明显的。 

## 解决方案

 让$a_1, a_2, \dots, a_n$是接近的数字并且$S = a_1 + a_2 + \dots + a_n$。 

**引理 1.** 每$a_i > 0$。 

认为$a_1 \le 0$。 那么紧密度的定义给出$a_1 < S/(n-1)$。 如果$a_1 \le 0$， 然后$S = a_1 + a_2 + \dots + a_n \le a_2 + \dots + a_n$。 因此$\frac{S}{n-1} \le \frac{a_2 + \dots + a_n}{n-1}.$另一方面，对于每个$i = 2, \dots, n$,$a_i < S/(n-1) \le (a_2+\dots+a_n)/(n-1)$。 总结这些$n-1$不平等收益$a_2 + \dots + a_n < \frac{n-1}{n-1} (a_2 + \dots + a_n) = a_2 + \dots + a_n,$这是不可能的。 所以$a_1 > 0$。 根据对称性，所有$a_i > 0$。 

**引理 2.** 对于任何$a, b, c$,$a+b>c$。 

考虑$c$作为数字之一。 凭着亲近感，$c < S/(n-1)$。 然后$c < \frac{a+b + \sum_{\text{others}}}{n-1} = \frac{a+b + (S - a - b - c)}{n-1} = \frac{S - c}{n-1}.$两边同时乘以$n-1$给出$(n-1)c < S - c = (a+b) + \sum_{\text{others}}$。 减去其他数字的总和（根据引理 1 均为正数）得出$a+b > c$。 

**引理 3.** 对于任何$a, b$,$a+b \ge S/(n-1)$。 

将所有数字的不等式相加，除了$a$和$b$:$\sum_{i\ne a,b} a_i < \sum_{i\ne a,b} \frac{S}{n-1} = (n-2) \frac{S}{n-1}.$所有数字的总和，除了$a$和$b$是$S - a - b$。 因此$S - a - b < (n-2) S/(n-1)$。 重新排列给出$a+b > S - (n-2) S/(n-1) = S/(n-1)$。 

每个引理都被证明； 将它们组合起来可以得出所需的结论。 这样就完成了证明。 

∎

 ## 关键步骤验证

 在引理 1 中，关键步骤是求和$a_2 + \dots + a_n < (a_2 + \dots + a_n)$，这是不可能的。 用小数字进行测试，例如$a_1 = 0$,$a_2 = a_3 = 1$准确地证实了矛盾的出现。 

在引理 3 中，重新排列$S - a - b < (n-2) S/(n-1) \implies a+b > S/(n-1)$成立，因为$(n-1)(a+b) > S$是等价的； 小数字检查，例如$n=3$,$a=1$,$b=2$,$c=2$,$S=5$，验证不等式。 

引理 2 通过显式减去其他数字的总和来验证，确保每一项的正数不会翻转不等式。 

## 替代方法

 人们可以尝试归纳$n$。 为了$n=3$，不等式简化为标准三角不等式； 假设这些陈述成立$n-1$数字，可以添加$n$th 数并检查总和不等式是否传播。 这比较麻烦，需要仔细跟踪所有总和，而使用总和的直接方法$S$不平等的重新安排立即证实了所有主张。 另一种选择是将几何可视化作为单纯形$\mathbb{R}^n$，但这增加了抽象，但没有简化算术论证。
