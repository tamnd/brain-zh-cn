 ## 问题

 给定一个正方形$ABCD$。 积分$P$和$Q$分别侧卧$AB$和$BC$， 和$BP = BQ$。 让$H$是从点垂下的垂线的底部$B$细分$PC$。 证明角度$DHQ$是一个直角。 

N·B·瓦西里耶夫

 全联盟中学生数学奥林匹克竞赛（1974年，十年级）

 ## 探索

 直接合成方法需要跟踪垂直线的底部$B$到线$PC$，这表明坐标表示或向量投影可能会将配置简化为代数恒等式。 条件$BP = BQ$表示两条腿之间的对称性$AB$和$BC$，建议$P$和$Q$可以通过沿垂直轴的单个变量进行参数化。 

选择正方形与坐标轴对齐的笛卡尔模型可将几何条件转换为单个参数$t$描述两者$P$和$Q$。 脚$H$然后获得原点到通过两个明确已知点的直线的正交投影，该投影在计算下是稳定的。 最终条件$\angle DHQ = 90^\circ$转换为向量之间的点积$HD$和$HQ$等于零。 

主要风险在于投影点的代数简化以及确保计算消除错误不会隐藏重要的几何依赖性。 一旦正确表达了投影，正交条件就简化为一个变量的多项式恒等式。 

## 问题理解

 图形是一个正方形$ABCD$和$P$在$AB$和$Q$在$BC$，选择使得$BP = BQ$。 从$B$，垂直线段下降$PC$，在$H$。 任务是证明$\angle DHQ$是一个直角。 

这是 B 类问题，需要证明几何正交性陈述。 

约束条件$BP = BQ$强制平衡放置$P$和$Q$在两个垂直的侧面，表明隐藏的旋转或反射对称性以$B$。 结论声称该段$HD$垂直于$HQ$， 虽然$D$位于对角线对面$B$和$Q$位于相邻侧，因此该结构在明显的轴上不是立即对称的。 

## 证明架构

 引入一个坐标系将正方形放置在平面上，以便$B$是在原点，$A$和$C$位于坐标轴上，并且$D$相应地确定。 参数化$P$和$Q$使用单个参数$t$由条件强加的$BP = BQ$。 

计算直线方程$PC$并确定$H$作为原点到这条线上的正交投影，通过最小化到一般点的平方距离$PC$。 这产生了一个明确的公式$H$。 

表达载体$HD$和$HQ$坐标并计算它们的标量积。 证明这个标量积同样消失$t$，建立正交性。 

最微妙的一点是投影参数的正确计算以及所得坐标的简化$H$，因为任何代数错误都会破坏导致最终恒等式的取消。 

## 解决方案

 放置正方形，使得$B = (0,0)$,$A = (0,1)$,$C = (1,0)$， 和$D = (1,1)$。 让$P$躺在$AB$， 所以$P = (0,t)$对于某些人来说$t \in [0,1]$。 让$Q$躺在$BC$， 所以$Q = (t,0)$由于条件$BP = BQ$意味着两个距离$B$等于$t$。 

线路$PC$经过$P = (0,t)$和$C = (1,0)$，因此它可以参数化为$$X(s) = (s,\, t - st), \quad s \in \mathbb{R}.$$重点$H$是从原点到这条线的垂直线的脚，所以它最小化$$|X(s)|^2 = s^2 + (t - st)^2.$$扩大，$$|X(s)|^2 = s^2 + t^2 - 2st^2 + s^2 t^2 = s^2(1+t^2) - 2st^2 + t^2.$$相对于微分$s$并将导数设置为零收益率$$2s(1+t^2) - 2t^2 = 0,$$所以$$s = \frac{t^2}{1+t^2}.$$替换这个值给出坐标$H$:$$H = \left(\frac{t^2}{1+t^2},\, t - \frac{t^3}{1+t^2}\right) = \left(\frac{t^2}{1+t^2},\, \frac{t}{1+t^2}\right).$$向量$HD$和$HQ$计算如下。 为了$D = (1,1)$,$$HD = \left(1 - \frac{t^2}{1+t^2},\, 1 - \frac{t}{1+t^2}\right) = \left(\frac{1}{1+t^2},\, \frac{1+t^2 - t}{1+t^2}\right).$$为了$Q = (t,0)$,$$HQ = \left(t - \frac{t^2}{1+t^2},\, -\frac{t}{1+t^2}\right) = \left(\frac{t + t^3 - t^2}{1+t^2},\, -\frac{t}{1+t^2}\right).$$标量积满足$$HD \cdot HQ = \frac{1}{(1+t^2)^2}\Bigl[(t + t^3 - t^2) - t(1+t^2 - t)\Bigr].$$展开括号内的表达式，$$t + t^3 - t^2 - t - t^3 + t^2 = 0.$$因此$HD \cdot HQ = 0$，这意味着$HD \perp HQ$， 所以$\angle DHQ = 90^\circ$。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 的计算$H$依赖于最小化从原点到参数化点的平方距离$PC$。 由此产生的线性方程$s$有唯一解，因为系数$1+t^2$严格为正，确保投影明确且唯一。 

第二个坐标的简化$H$使用身份$$t - \frac{t^3}{1+t^2} = \frac{t(1+t^2) - t^3}{1+t^2} = \frac{t}{1+t^2},$$这证实了不存在对更高权力的隐藏依赖$t$遗迹。 

在标量积计算中，中的每一项$t$,$t^2$， 和$t^3$完全抵消了来自的贡献$HD$和$HQ$，并且取消不依赖于任何不等式或近似，仅依赖于代数重排。 

## 替代方法

 可以使用轮换来构建综合方法$90^\circ$关于$B$, 发送$A$到$C$和$P$到$Q$。 在此变换下，该行$PC$映射到自身，并且垂直于$B$到$PC$被保留。 然后该配置表现出对称性交换$D$与一个点对齐$H$和$Q$编码直角条件。 

坐标方法更直接，因为它将几何投影转换为单个显式最小化问题，并将最终语句简化为代数恒等式，从而避免了以几何方式管理旋转不变量的需要。
