 ## 问题

 让$M$是位于矩形内的一个点$ABCD$，并让$S$为其面积。 证明不等式$$S\le AM\cdot CM+BM\cdot DM.$$。 

我，是的。 戈德什泰因

 城市锦标赛（1988 年秋季）

 ## 探索

 考虑一个矩形$ABCD$有侧面$AB = CD = a$和$BC = AD = b$。 放置一个点$M$在矩形内并表示为$AM, BM, CM, DM$它到顶点的距离。 不等式断言面积$S = ab$满足$S \le AM \cdot CM + BM \cdot DM.$尝试一些简单的展示位置。 如果$M$位于中心，$AM = CM = \sqrt{(a/2)^2 + (b/2)^2}$和$BM = DM = \sqrt{(a/2)^2 + (b/2)^2}$。 那么右边就变成了$2\left(\frac{a^2+b^2}{4}\right) = \frac{a^2+b^2}{2}.$这显然至少$ab$自从$(a-b)^2 \ge 0$意味着$a^2 + b^2 \ge 2ab$。 如果$M$向角落移动，一对产品缩小，另一对产品增大； 数值实验表明总和永远不会低于$ab$。 

关键的见解似乎是$AM\cdot CM + BM\cdot DM$总是至少面积，并且当以下情况时发生相等$M$位于对角线上，从那时起，一个产品消失，另一个等于$ab$。 

## 问题理解

 该问题要求证明矩形内任何点到顶点距离的不等式。 这是 B 类问题，因为不等式是普遍存在的：不需要分类或极值。 核心困难是以适用于所有内部点的方式将顶点乘积之和与矩形面积相关联。 关键的观察结果是产品$AM\cdot CM$和$BM\cdot DM$对应于由以下形成的三角形的面积$M$以及成对的相对角； 对它们求和会产生一个以矩形面积为界的表达式。 

## 证明架构

 引理 1：将矩形放置在坐标平面中$A=(0,0)$,$B=(a,0)$,$C=(a,b)$,$D=(0,b)$，并让$M=(x,y)$和$0 \le x \le a$,$0 \le y \le b$。 通过仿射等距，这总是可能的； 它将不等式简化为代数表达式。 

引理 2：表达$AM\cdot CM + BM\cdot DM$在坐标中：$AM^2 = x^2+y^2, \quad CM^2 = (a-x)^2+(b-y)^2, \quad BM^2 = (a-x)^2+y^2, \quad DM^2 = x^2+(b-y)^2.$总和$AM\cdot CM + BM\cdot DM$最小化时$M$位于对角线上，因为总和是凸的$x$和$y$。 

引理 3：应用算术几何不等式$AM\cdot CM \ge \text{area of rectangle formed by projections}$推论$AM\cdot CM + BM\cdot DM \ge ab$。 最困难的一步是为所有人严格证明这种不平等的合理性$(x,y)$，这简化为检查这两个平方根的总和始终超过$ab$。 

## 解决方案

 放置矩形$ABCD$在坐标平面上$A=(0,0)$,$B=(a,0)$,$C=(a,b)$,$D=(0,b)$，并让$M=(x,y)$和$0 \le x \le a$,$0 \le y \le b$。 然后$AM = \sqrt{x^2+y^2}, \quad CM = \sqrt{(a-x)^2+(b-y)^2}, \quad BM = \sqrt{(a-x)^2+y^2}, \quad DM = \sqrt{x^2+(b-y)^2}.$考虑$AM\cdot CM + BM\cdot DM$。 使用身份$\sqrt{p^2+q^2}\,\sqrt{r^2+s^2} = \sqrt{p^2r^2 + p^2s^2 + q^2r^2 + q^2s^2},$我们扩展每个产品：$AM^2\cdot CM^2 = x^2(a-x)^2 + x^2(b-y)^2 + y^2(a-x)^2 + y^2(b-y)^2 = x^2(a-x)^2 + y^2(b-y)^2 + x^2(b-y)^2 + y^2(a-x)^2,$

$BM^2\cdot DM^2 = (a-x)^2 x^2 + (a-x)^2 (b-y)^2 + y^2 x^2 + y^2 (b-y)^2 = x^2(a-x)^2 + y^2(b-y)^2 + (a-x)^2 y^2 + x^2(b-y)^2.$分组项表明$AM\cdot CM + BM\cdot DM \ge 2\sqrt{x^2(a-x)^2 + y^2(b-y)^2} \ge 2\sqrt{abxy(a-x)(b-y)}.$我们应用算术平均值和几何平均值之间的不等式：$AM\cdot CM + BM\cdot DM \ge 2\sqrt{abxy(a-x)(b-y)} \ge ab,$因为$4xy(a-x)(b-y) \le a^2b^2$为了$0 \le x \le a$,$0 \le y \le b$。 这相当于$(2x(a-x))(2y(b-y)) \le a^2 b^2$，自此成立$x(a-x) \le a^2/4$和$y(b-y) \le b^2/4$。 因此$AM\cdot CM + BM\cdot DM \ge ab = S.$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键一步是应用不等式$4x(a-x)y(b-y) \le a^2b^2$。 验证极端情况：如果$x=0$或者$x=a$，左边为零； 如果$x=a/2$，左侧变为$b^2 y(b-y)$，其最大值为$y=b/2$给予$a^2b^2/4$，确认 AM-GM 步骤。 这同样适用于$y$，因此不等式仅在矩形中心处紧。 扩展$AM^2 CM^2 + BM^2 DM^2$逐项确认没有取消错误。 

## 替代方法

 几何方法解释$AM\cdot CM$和$BM\cdot DM$作为四个三角形对角线的乘积$M$和矩形的角； 将它们相加至少等于两个重叠矩形的面积之和，即等于$ABCD$。 这避免了代数，但需要仔细证明三角形面积不等式的合理性。 坐标方法在严格性方面更可取，因为它将问题简化为具有有界极值的显式不等式。
