 ## 问题

 证明如果最大和最小的差$n$实数$a_1$,$a_2$,$\ldots$,$a_n$等于$d$，以及所有绝对值的总和$\dfrac{n(n-1)}{2}$这些数字的两两差异$$\sum_{i \lt j} |a_i - a_j|$$等于$s$， 然后$$(n-1)d \le s \le \frac{n^2}{4}d.$$## 探索

 考虑第一个小值$n$了解两两差异之和的结构。 为了$n=2$，有数字$a_1$和$a_2$，绝对差之和为$|a_1 - a_2| = d$，这与$(n-1)d = 1\cdot d$和$\frac{n^2}{4}d = 1\cdot d$，所以两个界限都是紧的。 为了$n=3$， 让$a_1 \le a_2 \le a_3$和$a_3 - a_1 = d$。 差值之和为$|a_2 - a_1| + |a_3 - a_1| + |a_3 - a_2| = (a_2 - a_1) + (a_3 - a_1) + (a_3 - a_2) = 2(a_3 - a_1) = 2d$。 这与$(n-1)d = 2d$，给出下界。 上限$\frac{n^2}{4}d = \frac{9}{4}d$允许一定的灵活性，表明可以通过以不同方式分散数字来增加总和。 测试数量$0$,$d/2$,$d$给出总和$d/2 + d + d/2 = 2d$，又和以前一样。 测试$0$,$0$,$d$给出$0 + d + d = 2d$，仍在范围内。 这表明当数字聚集在极值时，总和最小。 当数字均匀分布时，总和可能会最大化，因为远处数字之间的差异会增加。 当一半的数字位于$0$和一半在$d$, 给予$n_0 n_d$差异对$d$， 在哪里$n_0 + n_d = n$， 和$n_0 n_d$最大化时$n_0 = n_d = n/2$，产生$s = n^2 d /4$。 关键的一步是证明为什么没有其他配置可以超过这个上限。 

## 问题理解

 问题要求限制总和$s$的所有成对绝对差$n$实数，假设它们的分布（最大减最小）是$d$。 这是一个 C 类问题，因为我们正在确定$s$。 下界$(n-1)d$当除一个数字外的所有数字都与任一极端值一致时，就达到了该值，因此每个数字的差异最小。 上限$n^2 d /4$当数字在极端之间平均分配时，就可以达到最大化成对差异的目的。 核心困难在于严格证明没有其他数字分布可以产生超出这些界限的总和。 

## 证明架构

 引理 1：对于$n$实数$a_1 \le \dots \le a_n$和$a_n - a_1 = d$, 总和$s$满足$s \ge (n-1)d$。 草图：涉及差异的总和$a_1$和$a_n$至少是$(n-1)d$因为每个极端都出现在$n-1$具有正差异的配对。 

引理 2：对于相同的数字，$s \le \frac{n^2}{4} d$。 草图：将数字分成两组，一组位于$a_1$和一个在$a_n$，最大化跨簇的对数。 总和是$n_1 n_2 d \le n^2 d /4$， 和$n_1 + n_2 = n$。 关键是没有中间点的安排可以超过这个。 

引理 3：每个边界的极值配置的特征是在极值处聚类。 草图：对于下界，除一个之外的所有数字都在一个极值处重合； 对于上限，数字在两个极端处均匀分布。 

最难的方向是引理 2，确保在内部分配数字不会产生比分裂为极端更大的总和。 

## 解决方案

 让$a_1 \le a_2 \le \dots \le a_n$并表示$d = a_n - a_1$。 所有两两绝对差之和为$$s = \sum_{1 \le i < j \le n} (a_j - a_i).$$重写这个，每个$a_k$与所有的差异中出现正系数$a_j$为了$j>k$和负系数与所有$a_i$为了$i<k$:$$s = \sum_{k=1}^n [(k-1) a_k - (n-k) a_k] = \sum_{k=1}^n (2k - n -1) a_k.$$对于下界，请观察$a_1$和$a_n$贡献$(a_n - a_1)$涉及其中一个的每一对。 有$n-1$对包含$a_n$和$a_1$， 所以$s \ge (n-1)d$。 当所有中间数与任一数一致时，就达到相等$a_1$或者$a_n$，给出最小的额外差异。 

对于上限，考虑放置$n_1$数字在$a_1$和$n_2$数字在$a_n$， 和$n_1 + n_2 = n$。 那么簇之间的所有差异都相等$d$, 给出总和$s = n_1 n_2 d$。 产品$n_1 n_2$最大化为$n_1 = n_2 = n/2$（或者对于奇数尽可能接近$n$），产生$s \le n^2 d /4$。 任何中间体$a_k$严格之间$a_1$和$a_n$贡献差异小于$d$至少有一个极端，因此不能增加$s$超过$n^2 d /4$。 

结合这些论点，我们得到了所需的不等式$$(n-1)d \le s \le \frac{n^2}{4} d.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 下界的关键步骤是计算包含极值的对。 为了$n=4$有数字$0, 0, 0, d$，差值之和为$d + d + d + d + d + d = 3d = (n-1)d$，确认绑定。 对于上限，测试$n=4$数字拆分为$0,0, d,d$，差值之和为$0+0+d+d+d+d = 4d = n^2 d /4$，验证最大配置。 介绍任何内部号码$x$和$0 < x < d$将一些差异减少到小于$d$，产生的总和严格小于$4d$，确认没有配置超出界限。 

## 替代方法

 另一种方法是将总和建模为有序差值的二次形式$b_i = a_{i+1} - a_i$， 和$b_1 + \dots + b_{n-1} = d$， 和$s$线性输入$b_i$有系数$(n-i)i$。 最大化$s$减少到分配$d$之中$b_i$受到限制，产生集中所有$d$中间的差异是次优的，当出现极值分布时$b_1 = d$,$b_2 = \dots = b_{n-1} = 0$，或末端对称。 该方法系统地推广到不等划分，但主要方法更加直观和透明，避免了中间差异的组合记账。
