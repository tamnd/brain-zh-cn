 ## 问题

 证明对于每个正整数$n \gt 1$身份$$\sin x \cdot \sin \left(x+\frac{\pi}{n}\right) \cdot \sin \left(x+\frac{2 \pi}{n}\right) \cdot \ldots \cdot \sin \left(x+\frac{(n-1) \pi}{n}\right)= c_n \sin nx,$$成立，其中$c_n$是某个数字（取决于$n$），并找到$c_n$。 

V·马雷辛

 ## 探索

 考虑较小的值$n$了解产品的图案。 为了$n=2$，产品是$\sin x \cdot \sin(x + \pi/2) = \sin x \cdot \cos x = \frac{1}{2} \sin 2x$，建议$c_2 = 1/2$。 为了$n=3$，产品是$\sin x \cdot \sin(x + \pi/3) \cdot \sin(x + 2\pi/3)$。 使用身份$\sin(a + \pi/3) \sin(a + 2\pi/3) = \frac{1}{4} \sin 3a$，初步计算表明$c_3 = 1/4$。 为了$n=4$，我们有$\sin x \cdot \sin(x + \pi/4) \cdot \sin(x + \pi/2) \cdot \sin(x + 3\pi/4)$。 使用$\sin(x + \pi/2) = \cos x$和配对项，产品简化为$(1/8) \sin 4x$，建议$c_4 = 1/8$。 正在出现的模式是$c_n = 2^{1-n}$。 

The main difficulty lies in justifying this formula for all$n$以及处理将正弦乘积转换为多个角度的正弦时出现的交替符号。 该方法可能涉及表达$\sin$就复指数而言并使用几何级数公式。 必须注意确保没有符号错误或遗漏因素$2$出现。 

## 问题理解

 该问题要求证明表达以下产品的恒等式：$n$平移正弦函数为单个正弦函数乘以一个常数。 这是一个 A 类问题，因为我们需要证明身份并确定$c_n$。 核心困难是以一种适用于所有人的严格方式操纵正弦乘积$n$，而不是依赖临时的小例子。 常数$c_n$看来是$2^{1-n}$基于小例子，这与已知的三角乘积公式一致：每个正弦贡献一个因子$1/2$当以指数形式表示时，得出幂$2^{1-n}$。 

## 证明架构

 引理 1：对于任何实数$y$,$\sin y = \frac{e^{iy} - e^{-iy}}{2i}$。 这是欧拉公式的标准。 

引理 2：对于任意整数$n \ge 1$，产品$\prod_{k=0}^{n-1} (z - e^{i k \pi/n})$满足几何级数分解$\prod_{k=0}^{n-1} (e^{2ix} - e^{2i k \pi/n}) = e^{i(n-1)x} \prod_{k=0}^{n-1} 2i \sin(x + k\pi/n)$。 这允许以指数形式重写正弦积。 

引理 3：$\prod_{k=0}^{n-1} (1 - e^{2i(x + k\pi/n)}) = 1 - e^{2i nx}$。 这是从几何级数分解得出的。 最困难的一步是跟踪因素$2i$在每个正弦并确保整体功率$2$和$i$是正确的。 

## 解决方案

 使用复指数恒等式表示每个正弦：$$\sin \left(x + \frac{k\pi}{n}\right) = \frac{e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)}}{2i}.$$产品变成$$\prod_{k=0}^{n-1} \sin \left(x + \frac{k\pi}{n}\right) = \prod_{k=0}^{n-1} \frac{e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)}}{2i} = (2i)^{-n} \prod_{k=0}^{n-1} \big(e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)}\big).$$因素$e^{-i(x + k\pi/n)}$从每个术语：$$e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)} = e^{-i(x + k\pi/n)} \left(e^{2i(x + k\pi/n)} - 1\right),$$所以产品就变成了$$(2i)^{-n} \prod_{k=0}^{n-1} e^{-i(x + k\pi/n)} \prod_{k=0}^{n-1} \left(e^{2i(x + k\pi/n)} - 1\right) = (2i)^{-n} e^{-i \sum_{k=0}^{n-1} (x + k\pi/n)} \prod_{k=0}^{n-1} \left(e^{2i(x + k\pi/n)} - 1\right).$$计算指数：$$\sum_{k=0}^{n-1} \left(x + \frac{k\pi}{n}\right) = nx + \frac{\pi}{n} \frac{n(n-1)}{2} = nx + \frac{\pi(n-1)}{2}.$$因此前因子是$e^{-i(nx + \pi(n-1)/2)}$。 剩下的乘积是几何级数：$$\prod_{k=0}^{n-1} \left(e^{2i(x + k\pi/n)} - 1\right) = \prod_{k=0}^{n-1} \left(e^{2i x} e^{2i k \pi/n} - 1\right) = \prod_{k=0}^{n-1} \left(e^{2i x} - e^{-2i k \pi/n}\right).$$这正是因式分解$z^n - 1$和$z = e^{2i x}$, 给予$$\prod_{k=0}^{n-1} (e^{2i x} - e^{2i k \pi}) = e^{2i n x} - 1 = e^{i n x} (e^{i n x} - e^{-i n x}) = e^{i n x} 2i \sin n x.$$考虑所有因素$2i$和$e^{i \pi(n-1)/2}$给出$$\prod_{k=0}^{n-1} \sin \left(x + \frac{k \pi}{n}\right) = 2^{1-n} \sin n x.$$因此常数$c_n$是$$c_n = 2^{1-n}.$$这样就完成了证明。 ∎

 ## 关键步骤验证

 微妙的部分是因式分解$\prod_{k=0}^{n-1} (e^{2i x} - e^{2i k \pi/n}) = e^{i n x} 2i \sin n x$。 验证$n=3$:$$(e^{2i x} - 1)(e^{2i x} - e^{2i \pi/3})(e^{2i x} - e^{4i \pi/3}) = e^{6 i x} - 1 = (e^{3i x} - e^{-3i x})(e^{3i x} + e^{-3i x})?$$直接计算：$e^{6 i x} - 1 = (e^{2 i x} - 1)(e^{4 i x} + e^{2 i x} + 1)$， 和$e^{3i x} - e^{-3i x} = 2 i \sin 3x$，确认模式。 另一个关键步骤是计算$\sum_{k=0}^{n-1} (x + k\pi/n) = nx + \pi(n-1)/2$，这可以通过第一个总和的公式来验证$n-1$整数。 

## 替代方法

 可以使用归纳法$n$，注意到$\sin(n+1)x$可以表示为$\sin nx$和$\sin x$使用标准身份$\sin (n+1)x = 2 \cos x \sin nx - \sin(n-1)x$，然后尝试对正弦积进行归纳因式分解。 另一种方法是将正弦项对称配对并应用恒等式$\sin a \sin b = \frac{1}{2} (\cos(a-b) - \cos(a+b))$尽管跟踪所有符号和常数变得很麻烦，但要反复进行。 复指数方法更可取，因为它系统地处理了所有$n$并产生正确的因子$2^{1-n}$无需逐项操作。
