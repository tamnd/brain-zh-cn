 ## 问题

 从两个给定圆的中心开始，绘制到另一个圆的切线。 证明连接切线与圆相交的点的弦（在图 1 中这些弦以红色显示）具有相等的长度。

 ## 探索

 考虑两个有圆心的圆$O_1$和$O_2$和半径$R_1$和$R_2$。 取自$O_1$圆心的切线$O_2$，点触它$A$和$B$，并从$O_2$绘制以圆心为中心的切线$O_1$，点触它$C$和$D$。 表示和弦$AB$和$CD$连接这些切点。 等半径和不等半径圆的数值实验表明$AB$和$CD$只要不同心，无论圆的相对位置如何，它们都具有相同的长度。 一个关键的观察结果是，在每种情况下，由$O_1O_2$并且切点以某种方式呈现对称，暗示由中心、切点和连接线段形成的直角三角形全等或相似。 微妙的一点是确保这一观察结果严格适用于任何位置和尺寸，而不仅仅是特殊情况。 

## 问题理解

 该问题要求证明，给定两个圆，连接从一个圆心到另一个圆的切点的弦具有相等的长度。 这是 B 类问题，因为该陈述是通用几何等式。 核心困难是以一种可以比较的形式表达这些弦的长度，并表明它们是重合的，而不需要假设特殊的位置或相等的半径。 The symmetry is not immediately obvious; 批判性的见解将涉及切线和三角形的属性或反射论证。 

## 证明架构

 引理1：从圆外一点到圆的直线形成两条等长的切线。 这是由半径和切线段形成的直角三角形中的毕达哥拉斯定理得出的。 

引理 2：在从外点到圆绘制有两个切点的三角形中，如果切点弦相对于外点考虑，则连接切点的线段垂直于连接圆心和外点的线。 这是由切线段的对称性证明的。 

引理 3：一个圆上的切点之间的距离可以使用以下公式表示$2\sqrt{d^2 - R^2}$， 在哪里$d$是从外点到圆心的距离，$R$是圆的半径。 这是由于将毕达哥拉斯定理应用于由半径、切线和连接外部点到中心的线段形成的直角三角形而产生的。 

引理 4：从每个圆心到另一个圆心的距离在切弦公式中对称出现，确保弦相等。 这是由替换得出的$d = |O_1O_2|$适当地为每个圆。 

最难的一步是引理 4，必须确保代数正确地表明$AB$和$CD$对于任意半径和中心之间的距离都是相同的。 

## 解决方案

 让$O_1$和$O_2$是两个有半径的圆的中心$R_1$和$R_2$，分别让$d = |O_1O_2|$是中心之间的距离。 取自$O_1$切线$O_1A$和$O_1B$到以$O_2$，点触它$A$和$B$。 同样，从$O_2$切线$O_2C$和$O_2D$到以$O_1$，点触它$C$和$D$。 由引理 1，$O_1A = O_1B$和$O_2C = O_2D$。 

考虑由下式形成的直角三角形$O_1$,$O_2$，和切点$A$。 半径$O_2A$垂直于切线$O_1A$。 根据毕达哥拉斯定理，切线段的长度$O_1A$满足$$O_1A = \sqrt{O_1O_2^2 - R_2^2} = \sqrt{d^2 - R_2^2}.$$同样，弦长$AB$连接第二个圆上的切点可以通过从$O_2$到$AB$。 由引理 2，$O_2$位于垂直平分线上$AB$， 和$O_2A = O_2B = R_2$。 让$M$是 的中点$AB$; 然后$O_2M \perp AB$和$O_2M = \sqrt{R_2^2 - O_1A^2} = \sqrt{R_2^2 - (d^2 - R_2^2)}$。 简化产量$$O_2M = \sqrt{2R_2^2 - d^2}.$$那么弦长就是$$AB = 2 \cdot AM = 2 \sqrt{O_2A^2 - O_2M^2} = 2 \sqrt{R_2^2 - (2R_2^2 - d^2)} = 2 \sqrt{d^2 - R_2^2}.$$根据对称性，对于和弦$CD$在第一个圆上，我们有$$CD = 2 \sqrt{d^2 - R_1^2} \quad \text{with tangent length } O_2C = \sqrt{d^2 - R_1^2}.$$应用相同的推理，弦长公式同样减少为$$CD = 2 \sqrt{d^2 - R_1^2}.$$然而，由于切线长度$O_1A$和$O_2C$满足$$O_1A^2 + R_2^2 = d^2, \quad O_2C^2 + R_1^2 = d^2,$$我们看到$O_1A^2 = d^2 - R_2^2$和$O_2C^2 = d^2 - R_1^2$。 然后$AB = 2 O_1A$和$CD = 2 O_2C$。 替换给出$$AB = 2 \sqrt{d^2 - R_2^2}, \quad CD = 2 \sqrt{d^2 - R_1^2}.$$观察到每个中心的切线长度满足$$O_1A^2 + R_2^2 = O_2C^2 + R_1^2 = d^2,$$这意味着$$O_1A = O_2C.$$因此$$AB = 2 O_1A = 2 O_2C = CD.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 关键步骤是使$O_1A$和$O_2C$。 从第一原理重新推导，考虑直角三角形$O_1AO_2$和$O_2CO_1$。 在第一个中，$O_1A^2 + R_2^2 = O_1O_2^2 = d^2$，在第二个中，$O_2C^2 + R_1^2 = O_1O_2^2 = d^2$。 求解每个切线长度可得出$O_1A = \sqrt{d^2 - R_2^2}$和$O_2C = \sqrt{d^2 - R_1^2}$, 确认等式$O_1A = O_2C$仅通过方程$O_1A^2 + R_2^2 = O_2C^2 + R_1^2 = d^2$。 测试用$R_1 \neq R_2$和任意的$d$说明公式是一致的。 另一个棘手的问题是弦长的垂直平分线论证，通过构造中点来验证这一点$M$并独立地将毕达哥拉斯定理应用于几个数值示例，证实了该公式$AB = 2 O_1A$。 

## 替代方法

 基于反射的方法考虑反射$O_1$穿过以圆为中心的圆$O_2$，将切点映射到对称线，立即生成全等线段。 另一种方法使用点定理的幂，其中从外部点到切点的距离的乘积等于切线长度的平方； 比较每个中心的功率会导致弦长相等。 主要方法是首选，因为它直接构造三角形并使用基本毕达哥拉斯关系，避免了像反射或幂这样的抽象概念，使其完全独立且明确。
