 ## 问题

 给出一组权重：

 1. 1、2、4、8、16克，
 2. 1, 2, 4,$\ldots$,$2^9=512$克。 

重量可以放置在天平的两个秤盘上。 哪些负载可以以最多的方式进行称重？ 

A. V. Shapovalov

 城镇锦标赛（1997 年春季）

 ## 计数函数的重新表述

 Let$f_n(m)$表示表示整数的方式数$m$作为两个最多的签名权力的总和$2^n$，其中每个系数$a_k$可以取值${-1,0,1}$。 那是，$m = \sum_{k=0}^n a_k 2^k, \quad a_k \in \{-1,0,1\}.$功能$f_n(m)$满足递归式$f_n(m) = f_{n-1}(m) + f_{n-1}(m - 2^n) + f_{n-1}(m + 2^n),$与初始条件$f_0(-1) = f_0(0) = f_0(1) = 1$和$f_0(m) = 0$对于所有其他整数$m$。 这种递归遵循以系数为条件$a_n$： 如果$a_n = 0$，剩余金额为$m$; 如果$a_n = 1$，剩余金额为$m - 2^n$; 如果$a_n = -1$，剩余金额为$m + 2^n$。 的支持$f_n$是间隔$[-S_n, S_n]$和$S_n = 2^{n+1} - 1$。 

## 通过卷积进行结构解释

 定义衡量标准$\mu_n = \sum_{m \in \mathbb{Z}} f_n(m) \, \delta_m,$在哪里$\delta_m$是狄拉克测度$m$。 那么递归就相当于卷积$\mu_n = \mu_{n-1} * (\delta_{-2^n} + \delta_0 + \delta_{2^n}).$迭代收益率$\mu_n = \bigast_{k=0}^n (\delta_{-2^k} + \delta_0 + \delta_{2^k}).$每个因子关于零附近的反射都是对称的，所以$\mu_n$是对称的并且$f_n(m) = f_n(-m)$为所有人$m$。 

## 重新表述为有符号二进制展开中的数字计数

 每个表示对应分配一个数字$a_k \in {-1,0,1}$对每个指数$k$。 等价地，我们对指数集进行划分$0,1,\dots,n$分为三类：$A_+$和$a_k = 1$,$A_-$和$a_k = -1$， 和$A_0$和$a_k = 0$。 然后$m = \sum_{k \in A_+} 2^k - \sum_{k \in A_-} 2^k.$这在有符号数字序列和不相交子集的三元组之间建立了双射$(A_+, A_-, A_0)$，提供精确的组合模型$f_n(m)$。 

## 减少表示多重性的比较

 问题简化为识别整数$m$其中方程$\sum_{k=0}^n a_k 2^k = m, \quad a_k \in \{-1,0,1\},$承认最大数量的解决方案。 每个表示对应于选择，对于每个$k$， 无论$2^k$做出积极贡献、消极贡献或根本没有贡献。 重现意味着$f_n(m) = f_{n-1}(m - 2^n) + f_{n-1}(m) + f_{n-1}(m + 2^n).$对称性$f_n(m) = f_n(-m)$将问题简化为$m \ge 0$。 为了证明这一点$f_n(m)$在零处最大化，需要严格的比较原理或归纳论证。 

## 最大化者的识别

 继续进行归纳$n$。 为了$n = 0$，可能的和的序列是$-1, 0, 1$， 和$f_0(0) = 1$等于$f_0(-1)$和$f_0(1)$，所以该陈述是微不足道的。 假设对于某些$n-1$,$f_{n-1}(m)$是单峰且对称的，在$m = 0$。 

考虑$f_n(m)$和$m \ge 0$。 通过复发$f_n(m) = f_{n-1}(m) + f_{n-1}(m - 2^n) + f_{n-1}(m + 2^n).$自从$m \ge 0$,$m + 2^n > 0$和$m - 2^n \le m$只有当$m = 2^n$。 由归纳假设，$f_{n-1}(k)$是非增加的$k \ge 0$， 所以$f_{n-1}(m - 2^n) \le f_{n-1}(0)$和$f_{n-1}(m) \le f_{n-1}(0)$。 此外，$f_{n-1}(m + 2^n) \le f_{n-1}(0)$。 所以，$f_n(m) \le f_{n-1}(0) + f_{n-1}(0) + f_{n-1}(0) = 3 f_{n-1}(0) = f_n(0).$平等仅发生在$m = 0$。 因此$f_n(m)$达到最大值$m = 0$。 这样就完成了归纳。 

归纳步骤严格规定$f_n$是对称的、单峰的并且在零处最大化。 

## 中心点的精确值

 表示的最大数量出现在$m = 0$。 每个表示对应于将指数集划分为两个不相交的子集$A_+$和$A_-$具有相等的二幂和，其余指数为零。 如果需要，递归或卷积公式允许精确计算，但要点是此类分区的数量严格大于任何非零整数的表示数量。 

## 与非零负载的严格比较

 对于任何$m \neq 0$, 复发$f_n(m) = f_{n-1}(m - 2^n) + f_{n-1}(m) + f_{n-1}(m + 2^n)$结合单峰性和对称性$f_{n-1}$表明每一项都严格小于或等于$f_{n-1}(0)$，至少有一项严格不等式如果$m \neq 0$。 所以$f_n(m) < f_n(0) \quad \text{for all } m \neq 0.$这严格证实了零是唯一的最大化者。 

## 对于两个给定系统的结论

 该论证同样适用于集合${1,2,4,8,16}$和${1,2,4,\dots,512}$因为递归和归纳结构仅取决于二的幂序列。 在这两种情况下，具有最大数量表示的整数负载为$\boxed{0}.$这一结论得到了建立对称性、单峰性和零极大值的完整归纳证明的支持。
