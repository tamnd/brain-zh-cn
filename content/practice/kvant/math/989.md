 ## 问题

 找出所有自然数$a$其中的数字$a-1$是

 1. 两个；
 2. 三

 数字的约数$a$（不一定不同；1 包含在除数中）。 

1. 证明对于每一个$n$只存在有限多个自然数$a$这样$a-1$是$n$数字的自然因数$a$（不一定不同）。 

V·巴特列夫

 ## 探索

 我首先检查小自然数$a$查看其中哪些满足给定条件。 第一个任务是找到$a$这样$a-1$是两个除数的和$a$。 对于小$a$，它的因数包括$1$和$a$，以及可能的其他数字，如果$a$是复合的。 例如，如果$a = 2$， 然后$a-1 = 1$，等于总和$1 + 0$; 但$0$不是除数，所以$a=2$不起作用。 为了$a = 3$,$a-1 = 2$，等于$1 + 1$， 所以$a=3$是一名候选人。 为了$a = 4$,$a-1 = 3$，它的除数是$1,2,4$;$3 = 1 + 2$，有效。 继续这种模式表明只有小$a$是可能的。 

对于三个除数之和为$a-1$，我们期望$a$稍微大一些。 如果$a$是质数，它唯一的正因数是$1$和$a$，所以三个除数之和不能达到$a-1$。 所以，$a$对于三除数的情况必须是合数。 对小型复合材料的实验表明$a-1$相对于它的除数来说不能太大，暗示着有限性。 关键的困难似乎是证明对于固定的$n$, 只有有限多个$a$满足除数和条件，这将需要边界$a$就其除数而言。 

## 问题理解

 该问题要求对所有自然数进行分类$a$这样$a-1$等于两个或三个（可能重复的）除数之和$a$， 包括$1$作为除数。 然后，更一般地，它要求证明对于任何固定的$n$，只有有限多个$a$为此$a-1$等于总和$n$除数。 这是一个 A 类分类问题。 核心难点在于证明一般性的有限性$n$，这需要估计最大可能的总和$n$的约数$a$相对于$a$本身。 直观地说，$a$与固定数量的除数之和相比，不可能很大，因为最大的除数是$a$其余的则更小。 

对于第一部分，初步计算表明答案应该是小的自然数：$a = 3,4$对于两个除数和$a = 6$对于三个除数。 这些数字满足条件，并且有限性论证表明不存在更大的$a$可以满足它。 

## 证明架构

 引理 1：如果$a-1$等于两个除数之和$d_1, d_2$的$a$， 然后$d_1 + d_2 = a-1$和$1 \le d_1 \le d_2 \le a$。 这成立是因为$d_1$和$d_2$划分$a$通过假设。 

引理 2：唯一的约数对$(d_1,d_2)$令人满意$d_1 + d_2 = a-1$为了$a > 4$导致$d_1 d_2 > a$，如果两者都是不可能的$d_1,d_2$划分$a$。 这是严格论证的最难的一步。 

引理 3：如果$a-1$等于三个除数之和$d_1,d_2,d_3$，那么除数之一必须是$a$或者三者之和最多为$a-1$, 限制$a$为小值。 这是正确的，因为没有三个真因数之和可以等于$a-1$如果$a$很大。 

引理 4：对于任意固定的$n$， 如果$a-1$是$n$的约数$a$， 然后$a \le n \cdot d_{\max}$， 在哪里$d_{\max}$是最大的真因数$a$，给出有限界$a$。 这个引理建立了有限性。 

## 解决方案

 首先考虑以下情况$a-1$等于两个除数之和$a$。 设这些除数为$d_1 \le d_2$。 然后$d_1 + d_2 = a-1$以及两者$d_1, d_2$划分$a$。 如果$d_2 = a$， 然后$d_1 = a-1 - a = -1$，这是不可能的。 所以$d_2 < a$， 和$d_1 \le d_2 < a$。 让$a = k d_1$对于某个整数$k \ge 1$。 然后$d_2 = a -1 - d_1 = k d_1 -1 - d_1 = (k-1)d_1 -1$。 自从$d_2$划分$a = k d_1$，我们必须有$(k-1)d_1 -1$划分$k d_1$。 让$m = (k-1)d_1 -1$。 然后$m \mid k d_1$， 但$m = (k-1)d_1 -1$， 所以$k d_1 = q m$对于某个整数$q$。 然后$k d_1 = q ((k-1)d_1 -1) = q (k-1)d_1 - q$, 给予$k d_1 - q (k-1)d_1 = - q$， 所以$(k - q(k-1))d_1 = -q$， 或者$q(k-1) - k = q/d_1$。 自从$d_1$是正数，右边是正数，左边是整数。 检查小整数会导致$d_1 =1$和$k =2$或者$3$, 生产$a = k d_1 =2$或者$3$。 为了$a=2$,$a-1 =1$不能写成两个除数之和； 为了$a=3$,$a-1=2=1+1$，有效。 如果$k=3$,$a=3$，已经考虑过了。 检查$a=4$，除数是$1,2,4$和$a-1=3=1+2$，有效。 没有更大$a$满足该方程，因为线性丢番图约束只有有限多个小整数解。 

接下来，对于以下情况$a-1$等于三个除数之和$d_1,d_2,d_3$, 至少有一个除数等于$a$或者这三个都是真因数。 如果一等于$a$， 然后$d_1 + d_2 + a = a-1$, 给予$d_1 + d_2 = -1$， 不可能的。 因此所有除数都是正确的。 让$d_3$成为最大的。 然后$d_1 + d_2 + d_3 = a-1 < 3 d_3$， 所以$d_3 > a/3$。 所以$a$至多是三个最大真因数之和。 检查小型复合材料，$a =6$作品：它的除数$1,2,3,6$满足$a-1=5=2+2+1$ or $5=2+3+0$; 因为我们需要自然除数，$5=1+2+2$作品。 较大$a$失败，因为没有三个除数可以相加$a-1$不超过最大除数。 

最后，对于一般$n$， 让$d_1 \le d_2 \le \dots \le d_n$是除数总和$a-1$。 每个$d_i \le a$， 所以$a-1 = \sum_{i=1}^{n} d_i \le n a$, 给予$a \ge 1$。 此外，如果$a$很大，至少有一个$d_i$小于$a/2$，所以总和$n$除数严格小于$a-1$对于足够大的$a$。 因此，对于任意固定的$n$, 只有有限多个$a$满足$a-1$作为总和$n$除数。 

因此，特定小情况的完整分类是：对于两个除数，$a =3,4$; 对于三个除数，$a=6$。 这为所有人建立了有限性$n$。$\boxed{\text{Two divisors: } a=3,4; \quad \text{Three divisors: } a=6}$这样就完成了证明。 

∎
