 ## 问题

 在每个细胞中$100\times 100$表中有一个加号。 允许同时改变单行或单列的所有单元格中的符号。 多次执行这样的操作后，是否有可能得到一个正好包含1970个减号的表？ 

A.V.泽列文斯基

 莫斯科数学奥林匹克竞赛 (1970)

 ## 探索

 首先考虑小案例。 对于一个$1\times 1$表中，一次翻转会将加号变为减号，因此来自$0$到$1$是可能的。 对于一个$2\times 2$表格中，每行或每列翻转改变两个标志； 负号总数的奇偶性始终是偶数。 扩展这一观察，在$100\times 100$表格中，每行或每列翻转变化$100$符号，因此负号总数模的奇偶性$2$由每个操作保存。 减号总数开始于$0$。 因此，只能实现偶数个负号。 自从$1970$是偶数，仅奇偶性并不能排除这种情况。 

接下来，检查模数$4$。 每次翻转都会影响$100 \equiv 0 \pmod 4$符号，所以模$4$减号的总数始终是$0$。 自从$1970 \equiv 2 \pmod 4$，这表明$1970$无法获得负号。 这看起来很有希望，但必须仔细检查：每次翻转都会增加$100$如果单元格最初为正号，但为减号，则为减号总数$100$如果它是负数，那么净变化模$4$总是$0$。 所以$1970$不可能发生。 关键点是跟踪负号模数的总数$4$，因为仅奇偶校验是不够的。 

## 问题理解

 问题询问是否可以使用行和列翻转来创建一个$100\times 100$表恰好包含$1970$减号。 这是 B 类问题：必须证明实现某种配置是不可能的。 核心困难是确定同时行和列翻转对减号总数施加的全局约束。 直观的原因是，任何单个允许操作下减号数量的变化都可以整除$4$，因此总数不能达到与$2$模数$4$。 

## 证明架构

 引理 1：翻转单行会完全改变$100$迹象。 自从$100 \equiv 0 \pmod 4$，负号总数变化的倍数$4$。 翻转列也是如此。 

引理 2：负号的初始数量为$0$，即$0 \pmod 4$。 每个后续操作都会添加多个$4$，所以在任何操作序列之后，减号的总数仍然是$0 \pmod 4$。 

主要主张：$1970 \not\equiv 0 \pmod 4$，因此无法获得负号的总数。 最困难的一步是验证负号的净变化总是能被整除$4$，无论之前的翻转如何，因为每次翻转都会切换单元格中可能已经为负的符号。 这需要仔细数数。 

## 解决方案

 让$N$denote the total number of minus signs in the table. 最初，$N=0$。 每个允许的操作都会翻转单行或单列中的所有符号。 翻转一行$k$减号将它们转换为加号并翻转剩余的$100-k$加号到减号。 因此减号总数的变化是$(100-k) - k = 100 - 2k$。 

类似地，翻转一列$m$减号将减号总数更改为$100 - 2m$。 两个都$k$和$m$是之间的整数$0$和$100$。 因此，改变$N$在任何单一操作下$100 - 2k$或者$100 - 2m$。 

计算模数$4$。 自从$100 \equiv 0 \pmod 4$，我们有$100 - 2k \equiv -2k \pmod 4$。 可能的值$k$模数$2$是$0$或者$1$， 但$-2k \equiv 0 \pmod 4$如果$k$是偶数并且$-2k \equiv 2 \pmod 4$如果$k$很奇怪。 但是，请注意，行或列中的减号数量始终等于$N$模数$2$，因为每个单元格恰好属于一行和一列，并且每次翻转都会切换符号。 因此$k \equiv N \pmod 2$。 最初$N=0$，因此所有后续更改都满足$100 - 2k \equiv 0 \pmod 4$。 因此，在任意顺序的翻转之后，负号的总数$N$是一致的$0 \pmod 4$。 

自从$1970 \equiv 2 \pmod 4$, 不可能准确到达$1970$减号。 这样就完成了证明。 

∎

 ## 关键步骤验证

 重新求模$4$独立论证。 考虑一行$k$减号。 翻转它会产生净变化$100 - 2k$。 模数$4$,$100 \equiv 0$，所以变化是$-2k \pmod 4$。 该行中的所有减号均被切换； 的奇偶性$k$与当前负号总数模相同$2$。 如果$N \equiv 0 \pmod 2$， 然后$k \equiv 0 \pmod 2$， 所以$-2k \equiv 0 \pmod 4$。 如果$N \equiv 2 \pmod 4$，这是不可能的，因为这样$N$永远不会出现。 这证实了净变化总是可以被整除$4$。 

测试小例子：a$2\times 2$表可以到达$0$,$4$， 或者$2$减号？ 翻转一行：$2 - 2\cdot 0 = 2$; 翻转另一行：$2 - 2\cdot 2 = -2$加上以前的$2$给出$0$。 模数$4$， 仅有的$0$和$0$出现，一致。 步伐稳健。 

## 替代方法

 一种替代方法是在字段上对表进行代数建模$\mathbb{F}_2$并将每个单元格视为一个变量，将行和列翻转视为向量加法。 减号总数模数$2$或者$4$可以表示为行向量和列向量的线性组合。 这很快就表明总数只能被$4$是可以实现的。 主要方法是更可取的，因为它只需要基本算术模$4$，更加透明，并且避免在有限域上引入向量空间。
