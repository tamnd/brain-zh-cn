 ## 问题

 证明对于每个正整数$n$,$$\dfrac12+\dfrac1{3\sqrt{2}}+\dfrac1{4\sqrt{3}}+\ldots+\dfrac1{(n+1)\sqrt{n}}\lt2.$$S.I.麦祖斯

 ## 探索

 总和是$$S_n=\frac12+\frac1{3\sqrt2}+\frac1{4\sqrt3}+\cdots+\frac1{(n+1)\sqrt n} =\sum_{k=1}^{n}\frac1{(k+1)\sqrt k}.$$一个自然的想法是将每个项与涉及的伸缩差异进行比较$\sqrt{k}$。 

为了$k=1,2,3$,$$\frac1{(k+1)\sqrt k} = \frac12,\ \frac1{3\sqrt2},\ \frac1{4\sqrt3},$$尽管$$\frac2{\sqrt k+\sqrt{k+1}} = \frac2{1+\sqrt2},\ \frac2{\sqrt2+\sqrt3},\ \frac2{\sqrt3+2}.$$从数字上看，$$\frac12<\frac2{1+\sqrt2},\qquad \frac1{3\sqrt2}<\frac2{\sqrt2+\sqrt3},\qquad \frac1{4\sqrt3}<\frac2{\sqrt3+2}.$$自从$$\frac2{\sqrt k+\sqrt{k+1}} =\sqrt{k+1}-\sqrt k,$$这种比较将产生一个伸缩总和。 

关键是要证明$$\frac1{(k+1)\sqrt k} < \sqrt{k+1}-\sqrt k = \frac1{\sqrt{k+1}+\sqrt k} \cdot 2.$$清除分母后，就变成了$$\sqrt{k+1}+\sqrt k<2(k+1)\sqrt k,$$这是立即的，因为$\sqrt{k+1}<\sqrt k+1$，因此左侧小于$2\sqrt k+1$，而右侧等于$2k\sqrt k+2\sqrt k$并超过$2\sqrt k+1$对于每个正整数$k$。 

由此产生的伸缩总和给出$$S_n<2(\sqrt{n+1}-1).$$对于大型企业来说，仅此一点是不够的$n$。 需要进行更清晰的比较。 

尝试代替$$\frac1{(k+1)\sqrt k} < \frac2{\sqrt k}-\frac2{\sqrt{k+1}} = \frac{2(\sqrt{k+1}-\sqrt k)}{\sqrt k\,\sqrt{k+1}},$$化简后我们得到$$\frac1{k+1} < \frac{2}{\sqrt{k+1}(\sqrt{k+1}+\sqrt k)}.$$乘以正数，$$\sqrt{k+1}+\sqrt k<2\sqrt{k+1},$$这是真的，因为$\sqrt k<\sqrt{k+1}$。 

这给出了完美的伸缩估计：$$S_n < 2\sum_{k=1}^{n}\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}\!}\right) = 2\left(1-\frac1{\sqrt{n+1}}\right) <2.$$微妙的一步是导致伸缩表达式的术语不等式。 

## 问题理解

 我们必须证明对于每个正整数$n$,$$\sum_{k=1}^{n}\frac1{(k+1)\sqrt k}<2.$$这是一个B 类问题，纯粹的证明。 

核心困难是为产生伸缩级数的通用术语找到合适的上限。 一旦获得这样的界限，总和就会分解为一个明显小于的简单表达式$2$。 

## 证明架构

 证明使用一个引理。 

引理。 对于每个正整数$k$,$$\frac1{(k+1)\sqrt k} < 2\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right).$$草图。 将右侧重写为$$\frac{2(\sqrt{k+1}-\sqrt k)}{\sqrt k\,\sqrt{k+1}} = \frac{2}{\sqrt{k+1}(\sqrt{k+1}+\sqrt k)},$$并比较分母。 

总结引理后$k=1$到$n$，右侧望远镜，产生$$S_n < 2\left(1-\frac1{\sqrt{n+1}}\right) <2.$$引理是最有可能在审查中失败的步骤，因为整个论证取决于获得准确正确的伸缩界限。 

## 解决方案

 让$$S_n=\sum_{k=1}^{n}\frac1{(k+1)\sqrt k}.$$对于每个正整数$k$,$$2\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right) = \frac{2(\sqrt{k+1}-\sqrt k)}{\sqrt k\,\sqrt{k+1}}.$$使用$$\sqrt{k+1}-\sqrt k = \frac1{\sqrt{k+1}+\sqrt k},$$我们得到$$2\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right) = \frac{2}{\sqrt{k+1}\,(\sqrt{k+1}+\sqrt k)}.$$因此$$2\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right) - \frac1{(k+1)\sqrt k} = \frac{2}{\sqrt{k+1}(\sqrt{k+1}+\sqrt k)} - \frac1{(k+1)\sqrt k}.$$由于所有数量都是正数，因此比较分母就足够了。 不平等$$\sqrt k<\sqrt{k+1}$$意味着$$\sqrt{k+1}+\sqrt k<2\sqrt{k+1}.$$乘以$\sqrt{k+1}$给出$$\sqrt{k+1}\,(\sqrt{k+1}+\sqrt k) < 2(k+1).$$乘以$\sqrt k$产量$$\sqrt{k+1}\,(\sqrt{k+1}+\sqrt k)\sqrt k < 2(k+1)\sqrt k.$$取倒数，$$\frac{2}{\sqrt{k+1}(\sqrt{k+1}+\sqrt k)} > \frac1{(k+1)\sqrt k}.$$所以$$\frac1{(k+1)\sqrt k} < 2\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right).$$将这个不等式求和为$k=1,2,\dots,n$给出$$S_n < 2\sum_{k=1}^{n} \left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right).$$右侧望远镜系列：$$\sum_{k=1}^{n} \left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right) = 1-\frac1{\sqrt{n+1}}.$$最后，$$S_n < 2\left(1-\frac1{\sqrt{n+1}}\right) <2.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 第一个微妙的步骤是身份$$\sqrt{k+1}-\sqrt k = \frac1{\sqrt{k+1}+\sqrt k}.$$右边乘以$\sqrt{k+1}+\sqrt k$给出$1$， 尽管$$(\sqrt{k+1}-\sqrt k)(\sqrt{k+1}+\sqrt k) = (k+1)-k = 1,$$所以身份是准确的。 

第二个微妙的步骤是分母的比较。 开始于$$\sqrt k<\sqrt{k+1},$$我们得到$$\sqrt{k+1}+\sqrt k<2\sqrt{k+1}.$$乘以正数$\sqrt{k+1}\sqrt k$保持不平等和收益率$$\sqrt{k+1}(\sqrt{k+1}+\sqrt k)\sqrt k < 2(k+1)\sqrt k.$$由于两边都是正数，因此互作用会逆转不等式，从而精确地产生所需的逐项估计。 

一个常见的错误是望远镜$$\sqrt{k+1}-\sqrt k$$而不是$$\frac1{\sqrt k}-\frac1{\sqrt{k+1}}.$$前者导致上限增长如下$\sqrt n$，这不足以证明均匀边界$2$。 

## 替代方法

 一个密切相关的证明开始于$$\frac1{(k+1)\sqrt k} < \frac1{k\sqrt k} = \frac1{k^{3/2}}.$$然后证明$$\frac1{k^{3/2}} < 2\left(\frac1{\sqrt k}-\frac1{\sqrt{k+1}}\right),$$这是从主解决方案中使用的相同计算得出的。 再次求和得出$$S_n < 2\left(1-\frac1{\sqrt{n+1}}\right) <2.$$主要方法是更可取的，因为它直接将原始项与伸缩差异进行比较，避免了中间估计并使伸缩结构的来源透明。
