 ## 问题

 1.方程有多少个解$$[x]-1977\{x\}=1978?$$有？ （这里$[x]$是整数部分$x$， 和$\{x\}=x-[x]$.)
 2. 证明对于任意$p\ne 0$和$q$等式$$[x]+p\{x\}=q$$有$[|p|]$或者$[|p|]-1$解决方案。 

唷。 萨塔罗夫

 ## 探索

 写$x=n+t$和$n=[x]\in\mathbb{Z}$和$t={x}\in[0,1)$。 等式$$[x]-1977\{x\}=1978$$变成$$n-1977t=1978.$$对于固定整数$n$，这决定了唯一的实数$t=\frac{n-1978}{1977}$，限制条件是$0\le t<1$。 因此我们必须计算整数$n$这样$$0 \le \frac{n-1978}{1977} < 1.$$这给出了一个有限区间$n$，所以解的数量是有限的。 

对于第二个方程，$$[x]+p\{x\}=q,$$写作$x=n+t$给出$$n+pt=q,$$所以$t=\frac{q-n}{p}$。 条件$t\in[0,1)$转化为不平等$n$取决于 的符号$p$。 因此，问题简化为计算长度区间内的整数$|p|$。 唯一的微妙之处在于是否包含端点，这可能会将计数改变 1。 

要点是整数的个数$n$满足严格或半开区间的长度$|p|$是$[|p|]$或者$[|p|]-1$，取决于端点与整数的对齐方式。 

## 问题理解

 A型：确定第一个方程的解的个数，并证明第二个方程的可能解的个数。 

核心思想是分解$x=[x]+{x}$，将问题转化为整数计数问题$n=[x]$使得线性约束$n$产生有效的小数部分$[0,1)$。 

对于第一个方程，计数应该是单个固定数字。 对于第二个方程，数字取决于间隔的长度$|p|$与整数晶格对齐，产生$[|p|]$或者$[|p|]-1$解决方案。 

## 证明架构

 首先证明对于任意实数$x$存在独特的$n\in\mathbb{Z}$和$t\in[0,1)$这样$x=n+t$。 

其次，将每个方程转换为线性条件$n$并表达$t$按照$n$。 

三、推导充要条件$t\in[0,1)$作为限制不平等$n$到半开区间。 

第四，对于第一个方程，显式计算间隔$n$并计算整数。 

第五，对于第二个方程表明，允许的集合$n$是一个长度区间$|p|$并计算这样一个区间内的整数个数，证明它只能是$[|p|]$或者$[|p|]-1$。 

最微妙的一点是计算整数时半开区间的端点行为。 

## 解决方案

 让$x=n+t$， 在哪里$n=[x]\in\mathbb{Z}$和$t={x}\in[0,1)$。 这种表示是唯一的并且满足$x=n+t$,$0\le t<1$。 

### 1. 方程$[x]-1977{x}=1978$替代$x=n+t$给出$$n-1977t=1978,$$所以$$t=\frac{n-1978}{1977}.$$条件$t\in[0,1)$相当于$$0 \le \frac{n-1978}{1977} < 1.$$自从$1977>0$，这相当于$$0 \le n-1978 < 1977,$$因此$$1978 \le n < 1978+1977=3955.$$因此$n$范围大于整数$$n=1978,1979,\dots,3954.$$这样的整数的个数是$$3954-1978+1=1977.$$每一个这样的$n$恰好产生一个$t$在$[0,1)$，因此恰好有一个$x$。 因此方程正好有$1977$解决方案。 

### 2. 方程$[x]+p{x}=q$,$p\ne 0$再次写$x=n+t$， 所以$$n+pt=q, \quad t=\frac{q-n}{p}.$$我们强加$0\le t<1$。 

＃＃＃＃ 案件$p>0$然后$$0 \le \frac{q-n}{p} < 1$$相当于$$0 \le q-n < p.$$这给出了$$q-p < n \le q.$$因此$n$是半开区间内的整数$(q-p,,q]$。 

这个区间的长度是$p$。 其中整数的个数是$[p]$或者$[p]-1$，取决于是否$q-p$是一个整数。 

确实，写$p=m+\alpha$和$m=[p]$和$0\le\alpha<1$。 间隔$(q-m-\alpha,,q]$总是至少包含$m$整数$q-m+1,\dots,q$什么时候$\alpha>0$，可能还有一个整数$q-m$取决于是否$q-m-\alpha<q-m$允许包含$q-m$作为区间内的整数。 This yields either$m$或者$m+1$整数，即$[p]$或者$[p]-1$取决于端点对齐。 

为了准确起见，中的整数$(q-p,q]$正是那些整数$n$满意的$n\le q$和$n>q-p$。 最小整数$\le q$是$\lfloor q\rfloor$，和截止值$q-p$可能会也可能不会排除$\lfloor q-p\rfloor+1$。 因此计数是$\lfloor p\rfloor$或者$\lfloor p\rfloor-1$。 

＃＃＃＃ 案件$p<0$写$p=-|p|$。 然后$$n-|p|t=q, \quad t=\frac{n-q}{|p|}.$$条件$0\le t<1$变成$$0 \le \frac{n-q}{|p|} < 1,$$所以$$0 \le n-q < |p|,$$因此$$q \le n < q+|p|.$$因此$n$范围为半开区间内的整数$[q,,q+|p|)$。 

该区间内的整数个数又是$[|p|]$或者$[|p|-1]$，取决于是否$q+|p|$是否是整数边界对齐。 

在这两种情况下，允许值$n$形成一个长度区间$|p|$，以及长度为半开区间中包含的整数个数$|p|$是$[|p|]$或者$[|p|]-1$。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 第一个微妙点是减少$x=n+t$和$t\in[0,1)$。 这是有道理的，因为对于任何真实的$x$，定义$n=[x]$和$t=x-n$力量$0\le t<1$并且具有唯一性，因为两次分解会给出整数差$( -1,1 )$，因此为零。 

第二个微妙点是除以时的不等式变换$p$。 为了$p>0$不平等保留了方向，而对于$p<0$它们相反，在每种情况下产生正确的区间端点。 

第三个要点是在长度为半开的区间内计算整数$L$。 该数字仅取决于左端点与整数的对齐方式； 将间隔移动非整数量会改变是否包含端点整数，从而恰好产生两个相差一的可能计数。 

## 替代方法

 几何方法解释$n+pt=q$作为线的交点$n+pt=q$在$(n,t)$带条的平面$t\in[0,1)$，因此解对应于平移宽度条中的整数格点$1$与线段相交。 Counting becomes a lattice intersection problem with a segment of length$|p|$，导致相同的端点敏感整数计数。 

另一种方法将方程重写为$x-{x}(1977+p)=1978-q$并研究每个单位间隔上的诱导分段线性函数，计算固定水平的交叉点。 这再次简化为整数的间隔计数，但不如上面使用的分解那么直接。
