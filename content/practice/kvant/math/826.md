 ## 问题

 黑板上写着三个数字。 然后其中一个被删除并替换为另外两个数字之和减一。 重复几次这个操作，结果得到数字17、1967、1983。 原来的数字可能是

 1. 2, 2, 2;
 2. 3, 3, 3？ 

A.A.贝尔津什

 全联盟学校数学奥林匹克竞赛（1983 年，八年级）

 ## 探索

 板上描述的操作将一个数字替换为其他两个数字之和减一。 将任意阶段的三个数字表示为$a$,$b$,$c$。 更换$a$给出新的三元组$(b+c-1, b, c)$。 同样，替换$b$或者$c$产生类似的三元组。 观察总和$S = a + b + c$，如果我们替换$a$，新的总和是$(b+c-1) + b + c = 2b + 2c - 1 = 2S - 2a - 1$。 总和在原始数字中呈线性变化，这表明模 2 的守恒量可能会提供信息。 

尝试小例子，从$(2,2,2)$，重复操作可以得到快速增长的总和。 为了$(2,2,2)$, 总和$S=6$，每次操作都会产生$2_6 - 2_2 -1 = 12 -4 -1 =7$和？ 实际上，总和变化为$S_{\text{new}} = a+b+c + (b+c-1 - a) = S + (b+c-1 - a) = S + (S - a - a -1) = 2S - 2a -1$，证实了之前的观察。 尝试具体步骤，总和不断演变：从总和 6 开始，替换 2：$S_{\text{new}} = 2_6 -2_2 -1 = 12-4-1=7$。 这很奇怪，迭代将继续产生整数。 最终，我们能到达1967年、1983年17日吗？ 他们的总和是$17 + 1967 + 1983 = 3967$。 检查模模式：从 6 开始，和奇偶校验为偶数，下一个和 7 为奇数。 模 2，序列交替。 最后的和 3967 是奇数。 从 6（偶数）开始，经过奇数步后，最终的总和为奇数。 所以单靠奇偶校验并不禁止$(2,2,2)$。 

为了$(3,3,3)$，初始总和为 9，奇数。 替换一个数字：$2_9 - 2_3 -1 = 18 -6 -1=11$，总和为奇数。 最终总和为3967奇数，奇偶校验一致。 因此，仅进行奇偶校验测试是不够的。 另一个不变量是$S - 1$模 2？ 或者也许模 3？ 检查模 3：开始$(2,2,2)$, 总和$6 \equiv 0 \pmod 3$。 操作：新总和$2S -2a -1 = 2*6 -4-1=7 \equiv 1 \pmod 3$。 接下来的替换更改进一步总结。 最终，我们必须达到3967$\equiv 1 \pmod 3$，这似乎是可能的。 更好的是寻找不变的线性组合：定义$f(a,b,c) = a+b+c -3$。 然后更换$a$,$a_{\text{new}} = b+c-1$，新三元组的总和：$(b+c-1) + b + c = 2b + 2c -1 = 2(b+c) -1$。 表达$S-3$并追踪其演变。 观察小例子，需要一种更系统的方法：也许从最终数字开始向后推算，反转操作。 

操作$x \mapsto y + z -1$是可逆的：知道任意阶段的三个数字，擦除的数字可以恢复为$x = y + z -1 - x_{\text{new}}$？ 更好：之前替换的数字是$x_{\text{prev}} = y + z -1 - x_{\text{new}}$？ 是的，重新排列，如果$x_{\text{new}} = y + z -1$， 然后$x_{\text{old}} = y + z -1$？ 等等，向后看，假设最后的三元组是$(17,1967,1983)$。 选择一个数字进行反转：$x_{\text{prev}} = y + z -1 - x_{\text{current}}$？ 测试小情况：如果数字是$(2,2,3)$，替换 3 给出新数字$2+2-1=3$，有效。 所以向后看，之前的数字是$y+z - x_{\text{current}} -1$？ 是的，一致。 因此，逆向工作是可行的。 

## 问题理解

 问题问是否可以从一致三元组开始$(2,2,2)$或者$(3,3,3)$并且，在多次迭代操作后，将一个数字替换为其他两个数字之和减一，得到数字$17$,$1967$,$1983$。 这是一个 A 类问题，“确定所有 X”，因为我们必须验证每个提议的起始三元组是否可以导致最终配置。 核心困难是确定一个不变量或一种方法来排除或确认操作序列可以将提议的初始三元组连接到给定的最终数字。 可能的决定性方法是使用逆运算从最终数字开始向后计算，并检查起始三元组是否可达。 直觉上，像 1967 年和 1983 年这样的大数字不太可能从$(2,2,2)$经过少量操作后。 

## 证明架构

 引理 1. 三个数之和在以下运算下演化$S_{\text{new}} = 2(S - a) -1$， 在哪里$S$是当前三元组的总和，$a$是被替换的号码。 这是使用运算定义的直接计算。 

引理 2. 该运算是可逆的，因为给定一个三元组$(x,y,z)$从之前的三元组获得$(x',y,z)$通过替换$x'$, 之前的值$x'$满足$x' = y + z -1 - x$。 接下来是运算公式的代数重新排列。 

引理 3. 如果替换的数字与总和具有相同的奇偶校验，则总和的奇偶校验随每个操作而交替。 这是通过考虑三元组的所有奇偶组合和运算公式来验证的。 

引理 4. 从一致三元组开始$(2,2,2)$，任何操作序列可实现的最大数字都严格小于 1967。这是通过迭代限制最大数字的增长来显示的，观察每个操作增加的数字小于其他两个操作的最大值的两倍。 

引理 5. 从$(3,3,3)$，操作顺序无法达到最后的三元组$(17,1967,1983)$因为数字之间的差异相对于起始值太大。 这通过证明总和和奇偶校验约束不能在任意数量的操作中产生如此不同的数字来证明。 

最难的一步是引理 4，它需要对数字的增长进行仔细的限制； 如果增量小于预期，指数增长的天真假设可能会失败。 

## 解决方案

 设最后的三元组为$(17,1967,1983)$。 将数字一般表示为$(x,y,z)$总和为$S = x+y+z$。 替换一个数字，例如$x$， 经过$y+z-1$给出新的总和$S_{\text{new}} = (y+z-1) + y + z = 2(y+z)-1 = 2(S-x)-1$，建立引理1。 

为了向后工作，假设最后一个操作替换了数字$x$。 然后是之前的值$x_{\text{prev}}$满足$x_{\text{prev}} = y+z-1 - x$，通过求解验证$x_{\text{new}} = y+z-1$为了$x_{\text{old}}$，建立引理 2。 

考虑起始三元组$(2,2,2)$。 总和是$6$，并且每个操作替换一个数字$a$和$b+c-1 = (S-a)-1$，所以新的总和$S_{\text{new}} = S - a + (S-a-1) = 2(S-a) -1$。 总和增加的幅度小于前一个总和减一的两倍，但从 6 开始，一次操作后可达到的最大数字是$b+c-1 = 2+2-1=3$，小于最终数字的最大值。 任何后续操作都将数字替换为其他两个减一的总和，并且最大数字的增长速度比前一个三元组的最大数字的线性增长慢。 更准确地说，如果$M$是三元组中最大的数字，替换它最多会产生$2M-1$， 尽管$1967$超过从以下位置开始重复加倍所获得的任何数字$2$，即使经过十次操作。 具体来说，在第一次操作之后，三元组变成$(3,2,2)$,$(2,3,2)$， 或者$(2,2,3)$，每个都有总和$7$，以及最大的数$3$。 下一次操作将最大数增加到最多$2_3-1=5$，那么至多$2_5-1=9$， 然后$17$， 然后$31$， 然后$61$， 然后$121$， 然后$241$， 然后$481$， 然后$961$， 然后$1921$， 然后$3841$。 观察这些界限，可以达到$1967$原则。 我们必须检查平等。 开始于$(2,2,2)$，所有数字都是偶数，第一个操作：替换$2$2 美元以上
