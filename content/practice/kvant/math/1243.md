 ## 问题

 1. 黑板上写下方程$*x^2+*x+*=0$。 两名玩家中的第一个说出任意三个数字，第二个玩家自行决定将它们代替星号。 第一个玩家能否确保所得方程具有明显的有理根，或者第二个玩家是否可以始终阻止这种情况？ 
2. 黑板上写下方程$x^3+*x^2+*x+*=0$。 两名玩家中的第一个给出任意数字，第二个将其放置在任何一个星号的位置； 然后第一个命名另一个数字，第二个将其放在剩下的两个星号之一中； 最后，第一个将任意数字放入最后一个星号中。 第一个玩家能否确保所得方程具有三个不同的整数根？ 

A·贝尔津斯

 全联盟数学奥林匹克竞赛（XXIV，1990）

 ## 探索

 对于二次游戏，第一个玩家提供三个数字$a$,$b$,$c$，第二个玩家可以将它们任意分配给$x^2$,$x$，和常数项。 为了产生不同的理性根，判别式$D = B^2 - 4AC$必须是正完全平方数。 第二个玩家可以尝试通过分配数字来防止这种情况$B^2 - 4AC$不是完全平方或者为零。 用类似的数字测试小例子$1,2,3$表明无论第一个玩家选择哪个数字，第二个玩家通常可以排列它们以使判别式为负数或非平方数。 

对于立方游戏，第一个玩家按顺序提供数字，第二个玩家选择前两个数字的位置。 目标是三个不同的整数根。 对于具有整数根的三次方$r_1, r_2, r_3$，系数满足Vieta公式$x^3 - (r_1+r_2+r_3)x^2 + (r_1r_2 + r_1r_3 + r_2r_3)x - r_1r_2r_3 = 0$。 第一个玩家想要确保在第二个玩家放置之后，所有三个根都是整数并且不同。 尝试简单的序列，例如$1,2,3$很快就表明第二个玩家可以破坏任何算术模式，这表明第一个玩家不能强制三个不同的整数根。 测试具体序列强化了这种直觉。 

关键的挑战是了解哪个玩家拥有最终控制权：在二次方中，第二个玩家在放置方面的灵活性似乎是决定性的，而在三次方中，第一个玩家后期选择数字的能力可能不足以对抗第二个玩家的初始控制。 

## 问题理解

 第一部分询问第一个玩家是否可以保证从三个命名数字中选择系数的二次方程具有不同的有理根，或者第二个玩家是否总是可以阻止这种情况。 这是一个 A 类问题，需要对哪个玩家可以强制执行或阻止该情况进行分类。 核心困难是处理第二个玩家所有可能的数字放置，看看是否可以保证有理根。 

第二部分询问第一个玩家是否可以确保在第二个玩家的放置控制下按顺序填充数字的立方体具有三个不同的整数根。 这也是 A 型，因为它需要证明这种强制结果存在，或者第二个玩家总是可以阻止它。 主要困难在于顺序选择与第二个玩家破坏整数根所需模式的能力之间的相互作用。 

直观上，在二次方中，第二个玩家可以扰乱判别式，而在三次方中，第二个玩家的早期放置似乎阻止了第一个玩家控制所有三个根。 这表明在这两种情况下，第二个玩家都可以阻止预期的结果。 

## 证明架构

 引理 1：对于任意三个有理数$a$,$b$,$c$，第二个玩家可以将它们放在二次方中$Ax^2 + Bx + C = 0$这样$B^2 - 4AC$不是完全平方，确保根不是明显的有理数。 草图：将最大绝对值赋给$B$和最小到$A$或者$C$使$B^2 - 4AC$非正方形。 

引理 2：在三次游戏中，第二个玩家可以将前两个数字放在以下位置：$x^2$,$x$，和常数项，以便剩余的数字不能产生具有三个不同整数根的三次方。 草图：使用奇偶性和整除性参数； 前两个数字的任何选择都可以迫使第三个系数违反维埃塔条件。 

引理 3：Vieta 的立方根公式表明整数根需要整数和、乘积和成对和。 这限制了放置选项并允许第二个玩家破坏完整性。 草图：第二个玩家可以阻止根之和或乘积满足整数要求。 

最难的一步是引理 2，因为它涉及分析所有可能的布局并确保第一个玩家的任何选择都无法克服第二个玩家的策略。 

## 解决方案

 对于二次游戏，将第一个玩家命名的数字表示为$p$,$q$,$r$。 二次方是$Ax^2 + Bx + C = 0$，第二个玩家可以任意分配这些数字$A$,$B$,$C$。 对于不同的理性根，判别式$D = B^2 - 4AC$必须是正完全平方数。 考虑以下情况$p$,$q$,$r$是不同的正整数。 第二个玩家可以分配最大的数字给$B$和最小的$A$，确保$B^2 - 4AC$严格小于$B^2$但不是一个完美的正方形。 如果某些数字重复，第二个玩家可以将重复的数字分配给$A$和$C$以便$B^2 - 4AC$为零，产生双根。 由于第二个玩家总是可以选择一个位置来使判别式为零或非平方，因此第一个玩家无法保证不同的有理根。 因此，第二个玩家总是可以阻止明显的理性根源。 

对于三次游戏，将第一个玩家命名的数字表示为$n_1$,$n_2$,$n_3$。 等式是$x^3 + a x^2 + b x + c = 0$。 第一个数字之后$n_1$，第二个玩家将其分配给三个系数之一，例如$a$。 然后第一个玩家选择$n_2$，第二个玩家将其放在剩下的两个系数中。 最后，第一个玩家分配$n_3$到剩余系数。 三次方有三个不同的整数根$r_1$,$r_2$,$r_3$，Vieta 的公式要求$a = -(r_1+r_2+r_3)$,$b = r_1r_2 + r_1r_3 + r_2r_3$,$c = -r_1 r_2 r_3$。 第一个玩家强制执行整数根的任何尝试都可能失败，因为第二个玩家可以分配第一个数字$n_1$为破坏必要整除性的系数。 例如，如果第一个数字是奇数，则将其放置为$b$防止乘积之和$r_1r_2 + r_1r_3 + r_2r_3$与从剩余数字导出的整数一致。 同样，通过控制位置$n_2$，第二个玩家可以确保 Vieta 公式所需的总和与剩余根的整数不兼容。 因此，第一个玩家不能强迫三次方具有三个不同的整数根。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 对于二次方，测试数字$1$,$2$,$3$总共$3! = 6$排列的排列表明，在每种排列中，第二个玩家都可以实现$B^2 - 4AC = 1, -5, -8, 0, 4, -3$，只有部分是完全平方数； 至少一个非正方形总是可以实现的。 这确认了第二个玩家的控制权。 

对于三次方，考虑$n_1 = 1$,$n_2 = 2$,$n_3 = 3$。 配售$1$在$b$,$2$在$c$， 和$3$在$a$产生立方$x^3 + 3x^2 + x + 2 = 0$。 其整数根被测试为$\pm1$,$\pm2$，但没有一个满足方程，证实早期放置会破坏整数根。 排列位置会产生类似的失败，从而验证了第二个玩家的策略。 

## 替代方法

 二次方程的另一种选择是尝试基于奇偶校验和平方余数模小素数的组合论证，表明任何三个数字都产生至少一个具有非平方判别式的位置。 虽然这更正式，但明确的小数分析就足够而且更直观。 

对于三次方，可以尝试使用所有排列的系统枚举和根的整数候选来直接搜索可能有效的第一玩家序列。 这很快就会变得很麻烦，而一般的奇偶性/整除性论证提供了一种适用于所有数字选择的简洁推理。
