 ## 问题

 ## 问题理解

 爱丽丝从二维网格的原点开始，可以在四个基本方向上移动。 她有固定的动作顺序，可以无限地重复。 红皇后位于固定坐标`(a, b)`，我们被要求确定爱丽丝最终是否会到达该位置。 输入提供多个测试用例，每个测试用例指定移动序列的长度、目标坐标和移动字符串。 

网格坐标很小（`1 ≤ n, a, b ≤ 10`），并且序列长度也很小。 这使我们能够直接模拟爱丽丝的运动，而不必担心性能。 关键的挑战是爱丽丝永远重复她的移动序列，因此该路径可以被认为是周期性的。 我们需要考虑她在重复循环中将占据的所有位置，而不仅仅是序列的一次遍历。 

不明显的边缘情况包括循环移动或以可能超出目标的方式移动的序列。 例如，如果 Alice 的序列是`NESW`红皇后在`(1,1)`，第一个周期让她度过了难关`(0,1) → (1,1) → (1,0) → (0,0)`，达到第二步的目标。 仅在完成序列后进行检查的简单方法可能会错过这一点。 

## 方法

 蛮力方法将无限期地模拟爱丽丝的移动，直到她到达目标或我们检测到重复位置。 在最坏的情况下，这可能需要无限长的时间，但考虑到限制，我们实际上可以限制步骤数。 由于目标的最大坐标为 10，并且移动序列长度最多为 10，因此 Alice 在一个周期内向任意方向移动距离原点的距离不能超过 10 个单位。 重复该序列多次覆盖由以下定义的边界框内的所有可到达位置`[-10,10] × [-10,10]`。 一旦我们模拟了所有这些位置，爱丽丝要么已经达到目标，要么永远无法达到目标。 

一种更数学化的方法是计算序列的一个完整周期的总位移，并确定目标坐标是否可以表示为该位移加上周期的某个前缀的非负整数组合。 由于最大坐标很小，这减少了对所有前缀的迭代，检查目标位移和前缀位移之间的差异是否是全周期位移的倍数。 

考虑到这些限制，第一种方法更简单并且完全可以接受。

 ## 算法演练

 1. 对于每个测试用例，读取序列长度`n`，目标坐标`(a, b)`，以及移动字符串`s`。 
2. 初始化Alice当前位置为`(0,0)`字典映射移动到坐标变化：`'N' → (0,1)`,`'E' → (1,0)`,`'S' → (0,-1)`,`'W' → (-1,0)`。 
3. 通过对每个移动的变化求和来计算一个完整序列后的总位移`s`。 
4. 迭代序列每个前缀所到达的位置。 对于每个前缀，计算到达所需的剩余位移`(a,b)`完成一些完整周期后。 
5. 检查剩余位移是否为x、y 方向全周期位移的整数倍。 只有非负倍数才有效，因为 Alice 只能循环前进。 
6. 如果任何前缀存在这样的组合，则输出“YES”。 否则，输出“NO”。 

**为什么有效**：Alice 可以到达的每个位置都是前缀位移加上全周期位移的非负倍数之和。 通过检查所有前缀并验证目标减去前缀是否是循环位移的非负倍数，我们覆盖了 Alice 可以占据的所有位置。 

## Python 解决方案```
import sys
input = sys.stdin.readline

def can_meet(a, b, s):
    n = len(s)
    dx = {'N': 0, 'E': 1, 'S': 0, 'W': -1}
    dy = {'N': 1, 'E': 0, 'S': -1, 'W': 0}

    # prefix positions
    px = [0]
    py = [0]
    for move in s:
        px.append(px[-1] + dx[move])
        py.append(py[-1] + dy[move])

    total_dx = px[-1]
    total_dy = py[-1]

    for i in range(n + 1):
        rem_x = a - px[i]
        rem_y = b - py[i]

        # check if the remaining displacement can be reached via full cycles
        if total_dx == 0 and total_dy == 0:
            if rem_x == 0 and rem_y == 0:
                return True
        elif total_dx == 0:
            if rem_x == 0 and rem_y % total_dy == 0 and rem_y // total_dy >= 0:
                return True
        elif total_dy == 0:
            if rem_y == 0 and rem_x % total_dx == 0 and rem_x // total_dx >= 0:
                return True
        else:
            if rem_x % total_dx == 0 and rem_y % total_dy == 0:
                kx = rem_x // total_dx
                ky = rem_y // total_dy
                if kx == ky and kx >= 0:
                    return True
    return False

def main():
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        s = input().strip()
        print("YES" if can_meet(a, b, s) else "NO")

if __name__ == "__main__":
    main()
```**解释**：该解决方案将所有可到达的位置计算为前缀位移和全序列位移的倍数之和。 它处理零位移情况，避免负倍数，并检查两个轴是否相等。

 ## 探索

 爱丽丝在整数格上移动，起始于$(0,0)$，她的运动是周期性的，由一串$n$无限重复的动作。 红皇后固定在$(a,b)$和$1\le a,b\le 10$，因此可达点集包含在一个序列的一组有限前缀位置的整数平移的并集中。 小例子表明对于像这样的序列$NE$，爱丽丝可以到达$(2,2)$重复循环两次后。 每个周期产生零净位移的序列，例如$NEWS$，只允许 Alice 到达前缀位置内的目标。 关键的一步是检查从某个前缀到目标的向量是否是全周期位移向量的非负倍数。 当一个坐标中的位移为零时，会出现边缘情况。 

## 问题理解

 这是 B 类问题：我们必须证明有关可达性的陈述。 对于每个测试用例，我们都会得到一个有界移动序列和一个目标点$(a,b)$。 我们要确定爱丽丝最终是否会占据$(a,b)$在某个时候。 核心困难在于该序列无限重复，产生无限路径。 我们必须考虑前缀位置与循环总位移之间的相互作用，特别是当循环位移的一个或两个分量为零时。 

## 证明架构

 引理1.Alice能够到达的每个位置都可以表示为前缀位移与循环位移向量的非负整数倍之和。 这是从线性得出的：重复序列的效果$k$时代补充$k$乘以序列到每个前缀的总位移。 

引理 2. 如果坐标中每个周期的总位移为零，则只能到达与该坐标中的前缀匹配的位置。 这是因为零位移乘以任何整数都会使坐标保持不变。 

引理 3. 如果两个坐标中的总位移均不为零，则两个坐标中到目标的剩余位移必须是相等的倍数。 否则，目标不能位于通过重复序列生成的位置线上。 

引理 4. 彻底检查所有前缀可以保证如果存在解决方案，就会找到该解决方案，因为任何可达点必须对应于某个前缀加上整个循环的倍数。 

最难的方向是引理3：当两个位移都不为零时验证倍数相等，并确保倍数非负。 

## 解决方案

 让$(\Delta_x,\Delta_y)$表示一个完整循环后的总位移。 让$(p_x,p_y)$表示第一个之后到达的位置$i$序列的移动。 考虑向量$(a - p_x, b - p_y)$从这个前缀到目标。 如果$\Delta_x=0$和$\Delta_y=0$， 然后$(a,b)=(p_x,p_y)$必须坚持才能达到目标，否则不可能。 如果恰好有一个组成部分$\Delta$为零，对应的分量$(a-p_x,b-p_y)$也必须为零，并且另一个分量必须是非零位移的非负倍数。 如果两个组件$\Delta$非零，那么$(a-p_x)$和$(b-p_y)$必须是整数倍$\Delta_x$和$\Delta_y$分别，并且倍数必须相等且非负。 检查所有前缀$i=0,\dots,n$由引理 4 就足够了。 

形式上，对于每个前缀$i$, 计算$(p_x,p_y)$作为第一个的总和$i$移动向量。 计算剩余位移$(r_x,r_y)=(a-p_x,b-p_y)$。 如果$(\Delta_x,\Delta_y)=(0,0)$， 然后$(r_x,r_y)=(0,0)$意味着可达性。 如果$\Delta_x=0$和$\Delta_y\ne 0$， 然后$r_x=0$和$r_y/\Delta_y\ge 0$整数。 对称地如果$\Delta_y=0$和$\Delta_x\ne 0$。 如果$\Delta_x\ne 0$和$\Delta_y\ne 0$， 然后$r_x/\Delta_x = r_y/\Delta_y = k\ge 0$整数。 如果存在这样的前缀，则输出YES，否则输出NO。 这样就完成了证明。 ∎

 ## 关键步骤验证

 考虑顺序$s=NE$， 目标$(2,2)$。 前缀位置：$(0,0),(0,1),(1,1)$。 每个周期的总位移：$(1,1)$。 对于前缀$(1,1)$, 剩余位移$(1,1)$等于一倍$(1,1)$，非负整数，所以可达。 考虑$s=NNE$， 目标$(2,2)$。 总排量$(1,2)$。 前缀$(0,0)$给出剩余的$(2,2)$,$2/1\ne 2/2$，没有匹配； 前缀$(0,1)$给出$(2,1)$,$2/1\ne 1/2$，没有匹配； 前缀$(0,2)$给出$(2,0)$,$2/1\ne 0/2$，没有匹配。 没有前缀有效，无法访问。 这些迹线证实了比率条件的正确性。 

## 替代方法

 人们可以模拟爱丽丝在有界网格中所有位置上的运动，标记访问过的坐标。 这种方法是可行的，因为$1\le a,b\le 10$和$n\le 10$，但很难扩展到更大的网格。 上面使用的向量分解方法是优选的，因为它推广到任意坐标和序列，避免不必要的迭代，并直接识别可达性的充分必要条件。
