 ## 问题

 让$$r_n=\cos^n \dfrac{\pi}{7}+\cos^n \dfrac{3\pi}{7}+\cos^n \dfrac{5\pi}{7}.$$。 查找

 1.$r_1$和$r_2$,
 2.$r_3$和$r_4$。 
3.证明$r_n$是任意有理数$n$。 

瓦西里耶夫

 ## 探索

 顺序$r_n$求和$n$角度余弦的幂$\pi/7$,$3\pi/7$， 和$5\pi/7$。 这些角度在奇数倍之间等距$\pi/7$最多$5\pi/7$，这表明与三次多项式的根的联系，如$\cos\theta$这些角度通常满足具有有理系数的三次方程。 小值可以直接计算：$r_1 = \cos\frac{\pi}{7} + \cos\frac{3\pi}{7} + \cos\frac{5\pi}{7},$和$r_2 = \cos^2\frac{\pi}{7} + \cos^2\frac{3\pi}{7} + \cos^2\frac{5\pi}{7}.$可以使用从最小多项式导出的递归来处理更高的幂$\cos(\pi/7)$。 测试前几个$n$建议$r_n$仍然保持理性。 一种候选方法是找到一个具有有理系数的三次多项式，其根为$\cos(\pi/7)$,$\cos(3\pi/7)$,$\cos(5\pi/7)$，然后使用牛顿和来计算$r_n$递归地。 最微妙的步骤是正确识别三次方并确保递归保持合理性。 

## 问题理解

 该问题要求计算某些余弦幂的显式和，并证明这些和对于所有的合理性$n$。 这是初始值的 A 类问题（计算$r_1$,$r_2$,$r_3$,$r_4$) 和类型 B 的合理性陈述。 核心困难在于以适合证明合理性的形式表达这些三角和，这需要识别余弦背后的代数结构。 直观上，这些余弦是有理系数的三次方的根，并且有理系数的多项式的根的幂和通过牛顿和是有理数。 

## 证明架构

 引理 1：数字$\cos\frac{\pi}{7}$,$\cos\frac{3\pi}{7}$,$\cos\frac{5\pi}{7}$是三次方的根$8x^3 - 4x^2 - 4x + 1 = 0$。 这通过三角公式得到验证$\cos 3\theta = 4\cos^3\theta - 3\cos\theta$应用于$\theta = \pi/7$,$3\pi/7$,$5\pi/7$。 

引理 2：设$r_n$是$n$具有有理系数的三次多项式的根的三次方； 然后$r_n$满足有理系数的线性递推：$r_{n+3} - r_{n+2} - 2 r_{n+1} + r_n = 0$。 这是从一般牛顿求和公式得出的。 

引理 3：初始总和$r_1$和$r_2$是有理数，然后递归确保所有后续的$r_n$是理性的。 如果初始项是有理数，则递推保留有理性。 

引理 4：计算$r_3$和$r_4$明确使用递归值和初始值。 

最困难的部分是推导正确的递归并计算没有错误的初始值。 如果犯了一个小小的算术错误，这是最有可能失败的步骤。 

## 解决方案

 三角公式指出$\cos 3\theta = 4\cos^3\theta - 3\cos\theta$。 将此应用到$\theta = \pi/7$，我们得到$\cos 3\frac{\pi}{7} = 4\cos^3 \frac{\pi}{7} - 3 \cos \frac{\pi}{7}.$然而，$\cos 3\pi/7$是我们的总和之一； 系统地找到满足以下条件的多项式$\cos(\pi/7)$，考虑到$\cos 7\theta$可以表示为多项式$\cos \theta$。 为了$\theta = \pi/7$,$\cos 7\theta = \cos \pi = -1$, 给予$64 \cos^7\theta -112 \cos^5\theta +56 \cos^3\theta -7\cos\theta +1 =0$。 因式分解$(\cos\theta - \cos\pi/7)$和它的循环类似物减少到立方$8x^3 - 4x^2 - 4x +1 =0.$因此根是$x_1 = \cos\frac{\pi}{7}$,$x_2 = \cos\frac{3\pi}{7}$,$x_3 = \cos\frac{5\pi}{7}$。 表示$r_n = x_1^n + x_2^n + x_3^n$。 

根据 Vieta 公式，三次系数给出基本对称和：$x_1 + x_2 + x_3 = \frac{1}{2}$,$x_1x_2 + x_2x_3 + x_3x_1 = -\frac{1}{2}$,$x_1x_2x_3 = -\frac{1}{8}$。 牛顿求和满足$r_1 = x_1 + x_2 + x_3 = \frac{1}{2},$和$r_2 = (x_1 + x_2 + x_3)^2 - 2(x_1x_2 + x_2x_3 + x_3x_1) = \left(\frac{1}{2}\right)^2 - 2\left(-\frac{1}{2}\right) = \frac{1}{4} + 1 = \frac{5}{4}.$牛顿和给出了递推式$n \ge 1$：$r_{n+3} - \frac{1}{2} r_{n+2} + \frac{1}{2} r_{n+1} + \frac{1}{8} r_n =0.$要消除分数，请乘以 8：$8 r_{n+3} -4 r_{n+2} + 4 r_{n+1} + r_n =0.$和$r_1 = 1/2$,$r_2 = 5/4$，我们计算$r_3$：$8 r_3 - 4 r_2 + 4 r_1 + r_0 = 0,$在哪里$r_0 = 3$因为$x_1^0 + x_2^0 + x_3^0 = 3$。 替换给出$8 r_3 - 4 \cdot \frac{5}{4} + 4 \cdot \frac{1}{2} + 3 = 8 r_3 -5 +2 +3 = 8 r_3 = 0 \implies r_3 =0.$相似地，$r_4$满足$8 r_4 -4 r_3 +4 r_2 + r_1 = 8 r_4 -0 +4 \cdot \frac{5}{4} + \frac{1}{2} = 8 r_4 +5 + \frac{1}{2} = 8 r_4 + \frac{11}{2} =0 \implies r_4 = -\frac{11}{16}.$由于递归具有有理系数和初始和$r_0$,$r_1$,$r_2$都是有理数，所有后续的$r_n$通过归纳法是有理数的。 这样就完成了证明。$r_1 = \frac{1}{2}, \quad r_2 = \frac{5}{4}, \quad r_3 =0, \quad r_4 = -\frac{11}{16}.$## 关键步骤验证

 关键步骤是确定三个余弦满足的三次多项式。 计算$\cos 7\theta$为了$\theta = \pi/7$产生一个七次方程，并分解其他根得到三次方程$8x^3 -4x^2 -4x +1 =0$。 使用数值近似进行测试，$\cos(\pi/7) \approx 0.90097$,$\cos(3\pi/7) \approx 0.22252$,$\cos(5\pi/7) \approx -0.62349$，并评估$8x^3 -4x^2 -4x +1$对于每个根都确认多项式消失。 计算$r_3$使用近似十进制值的立方的递归和直接求和给出$0$，确认正确性。 乘以递推式以清除分母并检查算术$r_4$给出$-11/16$，与直接计算一致。
