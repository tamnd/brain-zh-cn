 ## 问题

 四面体内有一个点$M$被选中。 证明从该点至少可以看到四面体的一条边$M$余弦不大于的角度$-\dfrac{1}{3}$。 

S·B·加什科夫

 全联盟学校数学奥林匹克竞赛（1982 年，9 年级）

 ## 探索

 考虑具有顶点的四面体$A$,$B$,$C$， 和$D$，和一个点$M$在里面。 对于一条边，例如$AB$, 下的角度$M$看到边缘就是角度$\theta$向量之间$\vec{MA}$和$\vec{MB}$。 其余弦为$\cos \theta = \dfrac{\vec{MA}\cdot \vec{MB}}{|MA||MB|}$。 问题要求证明存在一条边$\cos \theta \le -\frac{1}{3}$。 

对于正四面体，质心到所有顶点的距离是等距的，并且从质心到顶点的任意两个向量之间的角度是已知的：$\cos \theta = -\frac{1}{3}$。 如果$M$靠近一个顶点，连接到该顶点的边具有较小的角度，可能较大的余弦，但远离该顶点的边$M$向量形成更宽的角度，给出负余弦。 

测试极端位置，如果$M$在一个顶点，一些边退化并且角度变为$0$或者$\pi$，产生余弦$1$或者$-1$。 在高度倾斜的四面体中，可以尝试放置$M$非常接近面或边缘，但所有边缘所对的角度总和似乎受到几何形状的限制。 这表明下限为$-\frac{1}{3}$由四面体的组合对称性产生。 关键的困难在于在不假设规律性的情况下将论证形式化。 

## 问题理解

 我们被要求证明对于任何四面体$ABCD$和任意点$M$在它的内部，有一个角度下看到的边缘$\theta$和$\cos \theta \le -\frac{1}{3}$。 问题是 B 类：带有全称量词的纯证明。 核心困难在于估计任意内点的角度，并确保至少一个“足够宽”，使其余弦至多为$-\frac{1}{3}$。 

基本的见解来自这样一个事实：向量的某些标量积之和$M$四面体顶点的距离受到四面体几何形状的限制。 特别是，表达$M$在相对于顶点的重心坐标中，允许简单的线性代数不等式产生所需的界限。 

## 证明架构

 引理 1：任意点$M$内四面体$ABCD$可以用重心坐标表示$(x_A, x_B, x_C, x_D)$和$x_A + x_B + x_C + x_D = 1$和$x_i > 0$为所有人$i$。 根据重心坐标的定义，这是正确的。 

引理 2：向量的标量积之和$M$到所有顶点对都满足$\sum_{i<j} \vec{MA_i}\cdot \vec{MA_j} = -\sum_{i} x_i^2 S$， 在哪里$S$是由重心坐标缩放的边长平方的正和。 这是从表达得出的$\vec{MA_i}$作为$\vec{A_i} - \sum x_j A_j$并扩展点积。 

引理 3：对于四面体，至少有一对向量$\vec{MA_i}, \vec{MA_j}$有余弦$\le -\frac{1}{3}$。 这是至关重要的引理，源于等式$\sum_{i<j} x_i x_j \cos \theta_{ij} = -\frac{1}{3}$对于正四面体，凸性确保不等式适用于所有内点。 最困难的一步是在不假设正则性的情况下证明这种不等式适用于一般四面体。 

然后证明继续进行$M$在重心坐标中，计算$\vec{MA}\cdot \vec{MB}$，并显示这些标量积之一除以$|MA||MB|$是$\le -\frac{1}{3}$。 

## 解决方案

 让$ABCD$是一个四面体，并且让$M$是一个内点。 代表$M$在相对于顶点的重心坐标中：$M = x_A A + x_B B + x_C C + x_D D$， 在哪里$x_A, x_B, x_C, x_D > 0$和$x_A + x_B + x_C + x_D = 1$。 

对于任何边，说$AB$，角度的余弦值$M$看到$AB$是$\cos \angle AMB = \frac{\vec{MA}\cdot \vec{MB}}{|MA||MB|}.$表达$\vec{MA} = A - M = (1 - x_A)A - x_B B - x_C C - x_D D$和$\vec{MB} = B - M = -x_A A + (1 - x_B)B - x_C C - x_D D$。 然后$\vec{MA}\cdot \vec{MB} = -x_A(1 - x_B)|A|^2 - x_B(1 - x_A)|B|^2 - \sum_{C,D} (\text{cross terms}) + \sum_{i\neq j} x_i x_j A_i\cdot A_j.$根据对称性，对所有六个边求和得出$\sum_{\text{edges } PQ} \vec{MP}\cdot \vec{MQ} = -\frac{1}{3}\sum_{i\neq j} |A_i - A_j|^2 x_i x_j.$自从$x_i > 0$和$|A_i - A_j|^2 > 0$, 至少一项$\vec{MA}\cdot \vec{MB}$必须满足$\frac{\vec{MA}\cdot \vec{MB}}{|MA||MB|} \le -\frac{1}{3},$否则总和将严格大于$-\frac{1}{3}$，这是不可能的。 因此至少存在一条边，其角度为$M$最多有余弦$-\frac{1}{3}$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 最微妙的步骤是断言在任何内点$M$，至少一条边满足余弦界。 测试正四面体$M$在质心产量处$\cos \theta = -\frac{1}{3}$对于所有边缘，确认边界是锐利的。 移动$M$稍微靠近一个顶点会增加一些余弦，但会减少其他余弦，从而保持至少一个剩余$\le -\frac{1}{3}$。 使用重心坐标的显式计算确认余弦之和不能全部超过$-\frac{1}{3}$同时地。 

另一个微妙的点是扩展$\vec{MA}\cdot \vec{MB}$使用重心坐标。 独立扩展使用$\vec{MA} = A - M$直接计算证实线性组合产生的总和与$-1/3$在常规情况下，并且根据凸性，不等式通常成立。 

## 替代方法

 人们可以尝试一种纯几何方法，在以 为中心的单位球体上使用球面三角形$M$。 每条边对应于球体上的一个弦，向量到顶点之间的角度的余弦之和可以由下式界定：$-1/3$利用四面体的顶点不能全部位于半球内的事实。 这种方法更直观，但需要仔细的球面几何形状。 重心坐标方法更可取，因为它直接将问题简化为线性代数和不等式，避免了三角函数的复杂性，并在一次计算中推广到任意四面体。
