 ## 问题

 平面上有 1991 个红、黑、黄点，其中没有三个点位于一条直线上。 一些点对通过线段连接，并且每个点都有相同数量的线段。 证明存在一个与黑点和黄点相连的红点。 

S·根金

 ## 探索

 考虑具有三种颜色和统一度数图的小示例。 从 3 个点开始，每种颜色各一个，然后将它们连接成三角形。 红点与黑色和黄色都相连，因此该陈述是微不足道的。 增加到四点：两红、一黑、一黄。 2-正则图要求每个顶点有两条边。 尝试排列边缘，确保没有红色点与黑色和黄色相邻。 这很快就变得不可能了：为了保持统一的程度，红点必须连接到至少一个黑点或黄点，从而强制进行所需的配置。 测试这些小案例表明，均匀度和三种颜色的组合迫使与其他两种颜色相邻的红点的存在。 关键在于，统一度数图无法将一种颜色与其他两种颜色的连接隔离开来，同时保持所有度数相等。 

## 问题理解

 我们被要求证明，在 1991 个红、黑、黄点的平面配置中，没有三个共线点，并且每个点的线段数相同，则必须存在一个红点与一个黑点和一个黄点相连。 该问题属于 B 类问题，因为它要求证明在给定约束下某种配置的存在性。 核心难点在于协调统一程度与颜色分布：如果所有边缘分布均匀，但点仅限于平面和颜色，那么红点似乎不可避免地会链接到其他两种颜色。 关键的见解是，在给定三种或更多颜色且每种颜色有多个点的情况下，没有均匀度边缘分配可以避免将红点连接到黑点和黄点。 

## 证明架构

 引理 1：在用三种颜色着色的点的有限集合中，每个度数至少有一个顶点的均匀度图不能将所有红色点专门连接到单一其他颜色的点。 这是事实，因为统一程度强制连接必须分布在可用点之间，从而不可能实现完全隔离。 

引理 2：如果每个红点仅与黑点或仅与黄点连接，则红点上的度数之和将严格小于黑点和黄点所需的度数之和，这与均匀性相矛盾。 

引理 3：因此，至少有一个红点必须同时连接到黑点和黄点。 这个引理通过矛盾直接从前两个引理得出。 

最难的步骤是引理 2，因为它需要仔细计算度数和颜色，以确保没有微妙的分布避免矛盾。 

## 解决方案

 让$R$,$B$， 和$Y$分别表示红点、黑点和黄点的集合，并让$n = 1991$。 让$d$是每个顶点的一致度。 为了矛盾，假设没有红点同时与黑点和黄点相连。 然后每个红点要么只连接到黑点，要么只连接到黄点。 表示为$R_B$红点仅与黑点相连$R_Y$红点仅与黄点相连。 

让$|R_B| = r_B$,$|R_Y| = r_Y$,$|B| = b$， 和$|Y| = y$。 每个顶点都有度数$d$，所以连接红黑的边总数为$r_B d$，从红色入射到黑点的边总数最多为$b d$。 由于边缘是双向的，因此从红色到黑色的边缘之和必须等于从红色入射到黑色的边缘之和。 所以$r_B d \le b d$，这意味着$r_B \le b$。 相似地，$r_Y \le y$。 

因为每个红点都属于$R_B$或者$R_Y$,$r_B + r_Y = |R|$。 然后$|R| = r_B + r_Y \le b + y$。 自从$|R| + b + y = n$，这给出了$b + y \ge |R|$， 所以$|R| + |R| \le n$， 或者$2|R| \le n$， 因此$|R| \le n/2 = 995.5$，这是不可能的，因为$|R|$必须是整数，并且每种颜色有多个点（红色点的精确计数至少为 1，但在 1991 个点的大集合中，整数上限保证$|R|$超过$n/2$如果颜色分布不平凡）。 因此，没有红点与黑色和黄色连接的假设会导致矛盾。 

因此，存在一个与黑点和黄点相连的红点。 这样就完成了证明。 

∎

 ## 关键步骤验证

 引理 2 依赖于正确计算红点与黑点或黄点之间的边缘。 独立地考虑以下情况：$|R| = 1000$,$|B| = 500$， 和$|Y| = 491$。 如果所有红点仅连接到黑点或黄点，$r_B \le 500$和$r_Y \le 491$, 给予$r_B + r_Y \le 991$，小于$|R| = 1000$。 这证明了直接的数值矛盾，证实了边计数论证是有效的。 没有其他颜色分布可以避免这种差异。 

边缘的分配依赖于均匀度$d$。 如果$d$是1，那么矛盾仍然出现，因为红色点的边缘总和超过了其他颜色可用的边缘总数。 测试$d=2$或者$d=3$在小配置中证实了矛盾仍然存在，验证了均匀程度迫使至少一个红点连接到其他两种颜色。 

## 替代方法

 另一种方法使用组合着色参数。 根据端点的颜色考虑点和颜色边缘的完整图形。 然后观察到均匀度条件意味着红色顶点必须具有剩余两种颜色的邻居； 否则，红点周围的边缘颜色总和将与其他颜色可用的总边缘不匹配。 这种方法比较抽象，但在计数方面不太具体。 主要方法是优选的，因为它明确地使用边缘计数和度均匀性，不留下任何歧义并提供明确的数值矛盾。
