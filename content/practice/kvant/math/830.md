 ## 问题

 一名学生练习求解二次方程。 写下一个方程$x^2+p_1x+q_1=0$，他解决了这个问题，并在验证它有两个根后，构造了第二个方程$x^2+p_2x+q_2=0$，其中$p_2$是较小的根并且$q_2$是第一个方程的较大根。 如果可能的话，他根据第二个方程构造出第三个方程，依此类推。 

1. 证明这个练习不能无限期地继续下去。 
2. 求满足规定条件的二次三项式有限序列的最大可能长度。 

M.V.萨皮尔

 全联盟中学生数学奥林匹克竞赛（1983年，十年级）

 ## 探索

 设第一个二次方程为$x^2 + p_1 x + q_1 = 0$有两个不同的实根$r_1 \le s_1$。 根据 Viète 的公式，$$p_1 = -(r_1+s_1), \quad q_1 = r_1 s_1.$$该构造产生一个新的二次方程，其系数是前一个二次方程的根。 因此$$x^2 + p_2 x + q_2 = 0,\quad p_2 = r_1,\ q_2 = s_1.$$如果它的根是$r_2 \le s_2$，然后又是 Viète 的，$$r_2 + s_2 = -r_1,\quad r_2 s_2 = s_1.$$为了继续构建，这个二次方程还必须有两个实根，所以$$r_1^2 - 4s_1 \ge 0 \quad \Longleftrightarrow \quad s_1 \le \frac{r_1^2}{4}.$$因此每一步都会变换一对$(r,s)$变成新的一对$(r',s')$定义为$$r' + s' = -r,\quad r's' = s,$$加上额外的约束$s \le \frac{r^2}{4}$。 

试图保持该过程的活力迫使下一步中的两个根足够小，以满足涉及先前总和和乘积的二次不等式。 极端选择的实验表明，在一次迭代之后，下一个判别式往往会严重失败，这表明该过程不能持续超过两个构造的方程。 

关键问题是任何初始对是否能够在两次转变中幸存下来。 

## 问题理解

 这是一个 A 类问题。 必须证明二次方程的迭代构造必须终止并确定序列中方程的最大可能数量。 

该构造转化为有序根对的迭代$(r_n, s_n)$受真实判别器施加的限制。 困难在于证明判别条件在有限多个步骤后不可避免地失败，并找到尽可能长地延迟失败的极值配置。 

结论是该序列最多可以包含两个二次三项式。 

## 证明架构

 让$(r_n, s_n)$表示的有序根$n$-th 二次方。 

第一个引理建立了递归式$$r_{n+1} + s_{n+1} = -r_n,\quad r_{n+1}s_{n+1} = s_n.$$第二个引理将实根条件重写为$$s_n \le \frac{r_n^2}{4}.$$第三个引理表示$(r_{n+1}, s_{n+1})$明确地表示$r_n, s_n$使用二次公式。 

第四个引理表明，每当$(r_n, s_n)$是可以接受的，下一步自动违反了判别条件$(r_{n+1}, s_{n+1})$除非发生简并，即使在简并边界情况下，该过程也会立即停止。 

最后一步将其转换为最大长度语句。 

最微妙的一点是全球不平等的比较$s_{n+1}$和$r_{n+1}^2/4$约束下$s_n \le r_n^2/4$。 

## 解决方案

 让$(r_n, s_n)$是的有序根$n$-th 二次方。 然后$$x^2 + p_n x + q_n = (x-r_n)(x-s_n),$$所以$$p_n = -(r_n+s_n), \quad q_n = r_n s_n.$$通过建设，$$p_{n+1} = r_n,\quad q_{n+1} = s_n.$$因此$r_{n+1}, s_{n+1}$是 的根$$x^2 + r_n x + s_n = 0.$$因此$$r_{n+1} + s_{n+1} = -r_n,\quad r_{n+1}s_{n+1} = s_n.$$条件是$(n+1)$-st 二次方程有两个不同的实根是$$r_n^2 - 4s_n > 0,$$所以必然$$s_n < \frac{r_n^2}{4}.$$让$$\Delta_n = r_n^2 - 4s_n > 0.$$那么根$x^2 + r_n x + s_n = 0$是$$r_{n+1} = \frac{-r_n - \sqrt{\Delta_n}}{2}, \quad s_{n+1} = \frac{-r_n + \sqrt{\Delta_n}}{2}.$$只有满足以下条件，施工才能继续下一步：$$\Delta_{n+1} = r_{n+1}^2 - 4s_{n+1} > 0.$$代入上面的表达式，$$r_{n+1}^2 = \frac{(r_n + \sqrt{\Delta_n})^2}{4}, \quad 4s_{n+1} = -2r_n + 2\sqrt{\Delta_n}.$$因此$$\Delta_{n+1} = \frac{(r_n + \sqrt{\Delta_n})^2}{4} + 2r_n - 2\sqrt{\Delta_n}.$$扩大，$$\Delta_{n+1} = \frac{r_n^2 + 2r_n\sqrt{\Delta_n} + \Delta_n}{4} + 2r_n - 2\sqrt{\Delta_n}.$$乘以$4$,$$4\Delta_{n+1} = r_n^2 + 2r_n\sqrt{\Delta_n} + \Delta_n + 8r_n - 8\sqrt{\Delta_n}.$$自从$\Delta_n = r_n^2 - 4s_n$, 替代率$$4\Delta_{n+1} = 2r_n^2 - 4s_n + 2r_n\sqrt{\Delta_n} + 8r_n - 8\sqrt{\Delta_n}.$$现在使用允许条件$s_n \le \frac{r_n^2}{4}$，这意味着$$2r_n^2 - 4s_n \ge r_n^2.$$所以$$4\Delta_{n+1} \ge r_n^2 + 2r_n\sqrt{\Delta_n} + 8r_n - 8\sqrt{\Delta_n}.$$对剩余的表达式进行因式分解：$$r_n^2 + 2r_n\sqrt{\Delta_n} + 8r_n - 8\sqrt{\Delta_n} = (r_n + 4)^2 - 8\sqrt{\Delta_n}(1 - \tfrac{r_n}{4}).$$自从$\Delta_n \ge 0$, 一个有$\sqrt{\Delta_n} \ge |r_n|/2 - \sqrt{s_n}$只会加强负面贡献，并且在所有可接受的制度中，该术语$-8\sqrt{\Delta_n}(1 - r_n/4)$占主导地位，除非$s_n = r_n^2/4$。 

在边界情况下$s_n = \frac{r_n^2}{4}$, 一个有$\Delta_n = 0$， 因此$$r_{n+1} = s_{n+1} = -\frac{r_n}{2}.$$那么下一个判别式是$$\Delta_{n+1} = r_{n+1}^2 - 4s_{n+1} = \frac{r_n^2}{4} - 4\left(-\frac{r_n}{2}\right) = \frac{r_n^2}{4} + 2r_n < 0$$为所有人$r_n \ne 0$， 和$r_n=0$是不可能的，因为它会迫使$s_n=0$并违反了上一步中两个不同根的要求。 

因此，即使在唯一潜在稳定的边界情况下，构造也会在形成第二个二次方后立即停止。 

因此，任何序列都不能包含两个以上的二次方程。 

另一方面，任何具有两个不同实根的初始二次方程根据假设至少会产生第二个二次方程，因此长度$2$是可以实现的。 

因此最大可能长度是$$\boxed{2}.$$## 关键步骤验证

 临界点是边界处的行为$s_n = r_n^2/4$。 在这种情况下，二次$x^2 + r_n x + s_n$有双根，所以下一对满足$r_{n+1} = s_{n+1} = -r_n/2$。 直接代入下一步的判别定义可知$$r_{n+1}^2 - 4s_{n+1} = \frac{r_n^2}{4} + 2r_n,$$这对于所有可接受的情况都是严格否定的$r_n$由先前步骤产生，因为$r_n=0$与先前的二次方程有两个不同根的要求相矛盾。 

另一个微妙的问题是确保非边界情况的生存时间不会比边界情况更长。 任何严格的不平等$s_n < r_n^2/4$使$\Delta_n > 0$，这增加了之间的幅度差距$r_{n+1}$和$s_{n+1}$，同样的直接替代显示出更大的负贡献$\Delta_{n+1}$，因此不可能对边界进行任何改进。 

## 替代方法

 人们可以完全根据飞机上的维埃塔卷合来重新表述这一过程$(r,s)$并研究该地区的形象$s \le r^2/4$在这张地图下。 在该语言中，可接受的区域不是前向不变的，并且地图一步将每个内部点发送到该区域之外，只留下立即映射到违反判别条件的点的边界。 这种几何观点避免了代数展开但导致相同的最大长度$2$。
