 ## 问题

 证明实数轴上的任意区间都可以分为几个黑白子区间，使得积分之和

 1. 任何二次多项式，
 2. 任何次数不超过的多项式$n$白色和黑色子区间上的值相等。 

G·V·康达科夫

 ## 探索

 对于固定间隔$[a,b]$，对于给定族中的每个多项式，白色和黑色子区间上的积分和相等的条件可以重写为有符号积分的消失。 If we assign a function$\varepsilon(x)\in{+1,-1}$在每个子区间上都是恒定的，并且在子区间之间交替，那么要求变为$\int_a^b p(x)\,\varepsilon(x)\,dx = 0$对于所有多项式$p(x)$在规定的班级里。 

因此问题简化为构造一个阶跃函数$\varepsilon$具有有限多个符号变化，使得有限多个矩条件成立。 对于次数最多的多项式$n$，这会产生$n+1$线性约束：$\int_a^b x^k \varepsilon(x)\,dx = 0,\quad k=0,1,\dots,n.$涉及二次多项式的要求一次是多余的$n\ge 2$， 自从$1,x,x^2$已经包括在内。 如果$n<2$，二次条件增强了系统，但没有改变其性质：我们仍然强制执行有限多个力矩约束。 

关键问题是能否选择有限多个割点，使得$\pm1$阶跃函数同时消除了所有这些时刻。 这是一个有限维平衡问题，建议有一个具有足够自由度的配置空间，即割点。 

一种自然的方法是将结构解释为划分为$m$具有交替颜色的子区间，产生$m-1$参数。 每个时刻条件在这些参数中都是连续的。 保证此类平衡问题可解的经典机制是类似于高维中的中间值原理的拓扑论证，或者等效于连续项链分裂原理。 

关键步骤是将约束的数量与可用切割参数的数量相匹配，并确保矩图的连续性。 

## 问题理解

 这是一个 D 类问题：存在分区（构造）。 

必须证明任何区间都可以分为有限多个黑白子区间，因此对于每个次数最多的多项式$n$（特别是每个二次多项式），黑色和白色部分的积分相等。 

等价地，如果$B$和$W$表示黑白子区间的并集，然后对于每个这样的多项式$p$,$\int_B p(x)\,dx = \int_W p(x)\,dx.$核心困难在于，这必须同时适用于无限多个多项式，但足以在有限的基础上强制执行它$1,x,\dots,x^n$，将问题转换为割点处的有限非线性方程组。 

预期的答案是这样的分区总是存在，并且它可以用有限多个子区间构造，仅取决于$n+1$矩条件。 

## 证明架构

 证明引入了矩向量$M_k = \int_a^b x^k \varepsilon(x)\,dx,$为了$k=0,1,\dots,n$， 在哪里$\varepsilon$是一个$\pm1$通过划分为具有交替颜色的子区间来确定的阶跃函数。 

第一个引理用所有的消失来表达黑白积分的相等性$M_k$。 

第二个引理表明，考虑次数达到多项式就足够了$n$通过线性度。 

第三个引理从割点单纯形构造一个连续映射$\mathbb{R}^{n+1}$由这些矩向量给出。 

第四个引理是一个拓扑存在陈述，断言可以使用多维中间值原理（两种颜色的项链分裂定理）来选择切割点，以便该连续映射到达原点。 

最难的部分是最后一个引理，因为它是唯一一个不将存在简化为代数运算而是简化为全局连续性论证的地方。 

## 解决方案

 让$[a,b]$是给定的间隔。 划分为有限多个单色子区间确定一个函数$\varepsilon:[a,b]\to{-1,1}$在每个子区间上都是恒定的，取值$+1$在白色碎片上和$-1$在黑色棋子上，仅在子区间的端点处改变符号。 

对于任意多项式$p$，白色子区间上的总积分等于黑色子区间上的总积分的条件等价于$\int_a^b p(x)\,\varepsilon(x)\,dx = 0,$因为白色棋子上的积分有正向贡献，黑色棋子上的积分有负向贡献。 

因此构建就足够了$\varepsilon$这样$\int_a^b x^k \varepsilon(x)\,dx = 0,\quad k=0,1,\dots,n,$因为每个次数最多的多项式$n$是这些单项式的线性组合。 

修复一个整数$m=n+1$。 选择$m$点$a=t_0 \le t_1 \le \cdots \le t_m=b,$并定义$\varepsilon$在每个间隔上保持不变$[t_{i-1},t_i]$，符号交替，从$\varepsilon=+1$在$[t_0,t_1]$。 然后$\varepsilon$完全由$(t_1,\dots,t_{m-1})$。 

对于每个$k=0,1,\dots,n$， 定义$F_k(t_1,\dots,t_{m-1})=\int_a^b x^k \varepsilon(x)\,dx.$每个$F_k$变量是连续的$(t_1,\dots,t_{m-1})$因为它是端点连续变化的区间内连续函数积分的有限和。 

定义地图$F=(F_0,\dots,F_n):\Delta \to \mathbb{R}^{n+1},$在哪里$\Delta$是闭单纯形$a\le t_1\le \cdots \le t_{m-1}\le b$。 

我们现在评估$F$在边界上$\Delta$。 如果两个连续参数重合，比如$t_i=t_{i+1}$，则一个子区间消失，两个连续的符号取消，因此配置减少为有效区间较少的一个。 在这种退化中，相应的矩向量位于相同结构的低维面的图像中，并且符号结构确保相反面的对映行为，从交换所有符号变化的意义上来说$F$到$-F$。 

关键的拓扑事实是，没有连续的映射$(n)$维单纯形边界变为$\mathbb{R}^{n+1}\setminus{0}$可以满足这种对映对称性，而无需在内部强制为零。 因此存在$(t_1,\dots,t_{m-1})$这样$F_0=\cdots=F_n=0.$对于这样的划分点选择，对应的阶跃函数$\varepsilon$满足$\int_a^b x^k \varepsilon(x)\,dx = 0 \quad \text{for all } k\le n,$因此对于每个多项式$p$最多学位$n$,$\int_a^b p(x)\,\varepsilon(x)\,dx=0.$这意味着$p$白色和黑色子区间相等，因为$\int_W p(x)\,dx - \int_B p(x)\,dx = \int_a^b p(x)\,\varepsilon(x)\,dx = 0.$二次多项式的条件包含在这些约束中，因此会自动满足。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 从白人和黑人积分相等到恒等式的还原$\int_a^b p(x)\varepsilon(x),dx=0$直接将积分分割在不相交的子区间上并将相反的符号分配给两种颜色。 

声称检查单项式就足够了$1,x,\dots,x^n$是合理的，因为任何多项式$p(x)=\sum_{k=0}^n c_k x^k$满足$\int_a^b p(x)\varepsilon(x)\,dx = \sum_{k=0}^n c_k \int_a^b x^k \varepsilon(x)\,dx,$因此，所有单项式积分的消失意味着所有此类积分的消失$p$。 

微妙的一步是零的存在$F$。 如果不存在这样的零，那么$F$将定义从单纯形（分区的参数空间）到$\mathbb{R}^{n+1}$。 合并相邻区间下的对映抵消迫使相反的边界行为对应于反转所有符号，这与在整个单纯形上扩展这样的对称非零映射的不可能性相矛盾。 当试图在与反转着色相对应的相对面上维持非零力矩向量时，就会精确地发生故障，因为连续性会强制符号反转，而不允许连续变形避免零。 

## 替代方法

 另一种路线使用两个小偷的项链分裂定理。 一解读措施$\mu_k(A)=\int_A x^k dx$为了$k=0,1,\dots,n$作为$n+1$连续有限测量$[a,b]$。 该定理断言存在一个分区$[a,b]$最多进入$n+1$切割，使得所得间隔可以交替分配给两个部分，以便每个小节在两个部分之间平均分配。 这恰好产生了所需的着色条件。 

这种方法更可取，因为它用已知的组合几何定理代替了单纯形上的拓扑论证，该定理的假设直接匹配多项式矩结构。
