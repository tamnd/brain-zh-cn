 ## 问题

 大约五个整数$a$,$b$,$c$,$d$,$e$，已知总和$a+b+c+d+e$和$a^2+b^2+c^2+d^2+e^2$能被奇数整除$p$。 证明这个数$$a^5+b^5+c^5+d^5+e^5-5abcde$$也可除以$p$。 

S.V.福明

 列宁格勒市数学奥林匹克竞赛 (50, 1984)

 ## 探索

 工作在残渣场进行$\mathbb{F}_p$， 在哪里$p$是奇怪的，所以$2$是可逆的。 假设表明前两个幂和满足$$p_1 := a+b+c+d+e \equiv 0 \pmod p, \qquad p_2 := a^2+b^2+c^2+d^2+e^2 \equiv 0 \pmod p.$$要证明的表达式可被整除$p$是$$p_5 - 5s_5,$$在哪里$p_k = a^k+b^k+c^k+d^k+e^k$和$s_5 = abcde$。 

连接幂和与初等对称多项式的自然机制是牛顿恒等式。 关键的期望是一旦$p_1$和$p_2$消失，所有较低的对称障碍物在递归中消失$p_5$，只留下关系$p_5 = 5s_5$。 

微妙的一点是确保在以下情况下不会使用非法划分：$p=3$或者$p=5$，因此恒等式必须以其积分形式使用。 

## 问题理解

 这是一个 B 类问题：证明一个特定的对称表达式可以被整除$p$在前两个幂和的条件下。 

核心困难是连接幂和和初等对称多项式，而不假设小整数模的可逆性$p$以一种可能会失败的方式$p=3$或者$p=5$。 正确的结构由整数形式的牛顿恒等式提供。 

## 证明架构

 该证明使用牛顿恒等式与幂和相关$p_k$和初等对称多项式$s_k$对于五个变量。 

第一个引理成立$s_1 \equiv 0$和$s_2 \equiv 0$从给定的假设。 

第二个引理计算牛顿恒等式$k=5$以一种隔离的形式$p_5 - 5s_5$。 

最难的一点是确保所有中间项模数消失$p$不除以不可逆整数。 

## 解决方案

 让$a,b,c,d,e$被考虑在环中$\mathbb{Z}/p\mathbb{Z}$。 表示为$$p_k = a^k+b^k+c^k+d^k+e^k$$功率总和和$s_k$基本对称多项式$a,b,c,d,e$， 和$s_5 = abcde$。 

整数形式的牛顿恒等式表明对于每个$k \ge 1$,$$k s_k = \sum_{i=1}^{k} (-1)^{i-1} s_{k-i} p_i,$$在哪里$s_0 = 1$。 

从案例来看$k=1$，我们得到$$1 \cdot s_1 = p_1,$$因此$s_1 \equiv 0 \pmod p$。 

为了$k=2$，身份变为$$2 s_2 = s_1 p_1 - p_2.$$自从$s_1 \equiv 0$和$p_1 \equiv 0$，由此可知$2 s_2 \equiv -p_2 \equiv 0 \pmod p$。 因为$p$是奇数，$2$是可逆模数$p$， 因此$s_2 \equiv 0 \pmod p$。 

我们现在将身份应用于$k=5$：$$5 s_5 = s_4 p_1 - s_3 p_2 + s_2 p_3 - s_1 p_4 + p_5.$$每一项都进行模检查$p$。 假设给出$p_1 \equiv 0$和$p_2 \equiv 0$。 先前建立的关系给出$s_1 \equiv 0$和$s_2 \equiv 0$。 因此，除了$p_5$模数消失$p$，身份简化为$$5 s_5 \equiv p_5 \pmod p.$$重写，$$p_5 - 5abcde \equiv 0 \pmod p.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 最微妙的一点是使用牛顿恒等式而不除以潜在的不可逆整数。 身份为$k=2$以以下形式使用$2s_2 = s_1p_1 - p_2$，它仍然有效$\mathbb{Z}$并且只需要除以$2$减模后$p$，有理由自$p$很奇怪。 

为了$k=5$，恒等式直接以其整数形式应用。 每个术语包含$p_1$或者$p_2$立即消失在$\mathbb{Z}/p\mathbb{Z}$，以及剩余的身份$5s_5 = p_5$独立于可逆性成立$3$或者$4$，因为没有执行它们的除法。 

如果尝试导出中间表达式，例如$s_3 = p_3/3$或者$s_4 = -p_4/4$; 这些划分是不必要的，并且在最后的论证中完全避免了。 

## 替代方法

 另一种方法使用特征多项式$$(t-a)(t-b)(t-c)(t-d)(t-e) = t^5 - s_1 t^4 + s_2 t^3 - s_3 t^2 + s_4 t - s_5$$并通过商代数中的迹将幂和与系数联系起来$\mathbb{F}_p[x]/(f(x))$。 通过考虑乘法算子的迹，我们可以得出相同的结论，但这引入了额外的代数结构，而没有简化牛顿恒等式提供的核心抵消机制。
