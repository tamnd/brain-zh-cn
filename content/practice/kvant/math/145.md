 ## 问题$A$承诺付款$B$平均为$\sqrt{2}$每天卢布。 他们一致认为，关于$n$第天$A$将收到一个整数$a_n$卢布（$a_n$等于 1 或 2)，选择该值以便在第一个期间收到的总金额$n$天 （$a_1+a_2+\ldots+a_n$) 尽可能接近该数字$n\sqrt{2}$。 

例如，$a_1=1$,$a_2=2$,$a_3=1$,$a_4=2$,$a_5=1$。 证明序列$a_1$,$a_2$,$a_3$,$\ldots$是非周期性的。 

A.K.托尔皮戈

 ## 探索

 考虑通过取最接近累积目标的整数定义的序列的前几项$n\sqrt{2}$。 为了$n=1$,$1$更接近于$\sqrt{2} \approx 1.414$比$2$， 所以$a_1=1$。 为了$n=2$，累计付款金额应近似$2\sqrt{2} \approx 2.828$。 如果$a_2=1$，总和是$2$，距离较远$2.828$比$3$如果$a_2=2$， 所以$a_2=2$。 继续下去，得到$a_3=1$,$a_4=2$,$a_5=1$,$a_6=2$,$a_7=2$， 等等。 该序列呈现出一种模式，最初在$1$和$2$，但有时会连续两次$2$出现。 没有出现固定长度的重复块，表明非周期性。 

为了形式化这一观察，请注意序列可以用倍数的小数部分来描述$\sqrt{2}$。 让$S_n = a_1 + \dots + a_n$，并定义误差$E_n = S_n - n\sqrt{2}$。 然后$|E_n|$每一步都最小化，并且增量$a_{n+1}$由是否确定$E_n$小于$1/2$或大于$1/2$以绝对值表示。 小型数值实验表明该序列不会陷入重复模式，这暗示了$\sqrt{2}$至关重要。 

关键的一步可能在于表明没有有限的整数块可以无限重复，这需要证明如果$a_1, \dots, a_p$重复，然后$p\sqrt{2}$将是某个整数的整数倍，与以下的无理性相矛盾$\sqrt{2}$。 

## 问题理解

 该问题要求证明付款顺序$a_n \in {1,2}$，选择使累积总和最接近$n\sqrt{2}$，不能是周期性的。 这是一个 B 类问题，因为给出了一个陈述并且必须证明。 核心难点在于连接$a_n$就近似而言$n\sqrt{2}$不可能出现重复块。 直观地说，如果序列是周期性的$p$，那么一段时间内的平均付款必须等于$\sqrt{2}$，这是不可能的，因为$\sqrt{2}$是不合理的。 这表明周期性不可能发生。 

## 证明架构

 引理 1：对于所有人$n$,$a_n$等于$1$或者$2$并满足$|S_n - n\sqrt{2}| \le 1/2$， 在哪里$S_n = a_1 + \dots + a_n$。 这直接遵循选择规则$a_n$最接近$n\sqrt{2} - S_{n-1}$。 

引理 2：如果整数序列$a_1, \dots, a_p$周期性地重复生成$a_n$为所有人$n$，那么平均值$a_1, \dots, a_p$等于$\sqrt{2}$。 这是成立的，因为每个时期的平均值必须与每期所需的平均增长一致，以使总和保持接近$n\sqrt{2}$。 

引理 3：任何有限整数序列的平均值不能等于$\sqrt{2}$， 作为$\sqrt{2}$是不合理的。 这是从无理数的定义中直接得出的。 

最困难的一步是严格证明周期性会迫使一个时期的平均值等于$\sqrt{2}$，因为序列近似$n\sqrt{2}$在最小误差意义上，小的波动不能与精确的周期性相一致。 

## 解决方案

 让$S_n = a_1 + a_2 + \dots + a_n$表示序列的累积和。 通过建设，$a_n$被选择使得$|S_n - n\sqrt{2}|$被最小化，并且$a_n \in {1,2}$。 因此，对于所有$n$，错误$E_n = S_n - n\sqrt{2}$满足$|E_n| \le 1/2$。 

为了矛盾起见，假设序列$(a_n)$是周期性的$p$， 所以$a_{n+p} = a_n$为所有人$n$。 那么累计和满足$S_{n+p} = S_n + S_p$， 在哪里$S_p = a_1 + \dots + a_p$。 另一方面，目标总和满足$(n+p)\sqrt{2} = n\sqrt{2} + p\sqrt{2}$。 一段时间后的误差为$$E_{n+p} = S_{n+p} - (n+p)\sqrt{2} = S_n + S_p - n\sqrt{2} - p\sqrt{2} = E_n + (S_p - p\sqrt{2}).$$由于最小错误规则确保$|E_{n+p}| \le 1/2$和$|E_n| \le 1/2$，增量$S_p - p\sqrt{2}$必须满足$|S_p - p\sqrt{2}| \le 1$，更准确地说，$S_p - p\sqrt{2} = 0$，因为否则误差将随着每个周期线性增长。 所以$$\frac{S_p}{p} = \sqrt{2}.$$然而，$S_p$是一个整数并且$p$是一个正整数，所以$S_p/p$是有理数，而$\sqrt{2}$是不合理的。 这是一个矛盾。 因此没有这样的时期$p$存在，并且序列$(a_n)$是非周期性的。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是断言周期性意味着$(S_p/p) = \sqrt{2}$。 为了验证，考虑之后的累积和$k$周期是$S_{kp} = kS_p$。 之后的目标总和$k$周期是$kp\sqrt{2}$。 最小误差条件要求$|S_{kp} - kp\sqrt{2}| \le 1/2$，这对于大$k$只有当$S_p - p\sqrt{2} = 0$。 任何小的非零差异都会导致$|k(S_p - p\sqrt{2})| > 1/2$对于足够大的$k$，违反了最小错误规则。 对小周期进行数值测试证实，即使很小的整数差异也会累积，从而验证了该论点。 

另一个微妙的点是确保$a_n$永远保留$1$或者$2$。 规则定义$a_n$保证这一点是因为$n\sqrt{2} - S_{n-1}$严格位于$0.414$和$1.586$，因此四舍五入到最接近的整数会产生$1$或者$2$，确认初始项的内部一致性并归纳推广。 

## 替代方法

 另一种方法是将序列视为小数部分的符号编码${n\sqrt{2}}$。 定义$b_n = \lfloor n\sqrt{2} \rfloor - \lfloor (n-1)\sqrt{2} \rfloor$，等于$1$或者$2$取决于小数部分是否$(n-1)\sqrt{2}$超过$1 - {\sqrt{2}}$。 这标识了$(a_n)$正如著名的斯特米安斜率序列$\sqrt{2} - 1$，这是一个标准的非周期序列。 虽然很优雅，但这种方法依赖于 Sturmian 序列和符号动力学的先验知识，而主要方法直接从定义中证明非周期性$a_n$以及不合理性$\sqrt{2}$，使其完全独立。
