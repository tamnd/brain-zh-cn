 ## 问题

 桌子$m\times n$充满了$mn$使得在每一行和每一列中这些数字形成算术级数。 位于表角的四个数字的总和等于$s$。 表中所有数字的总和是多少？ 

## 探索

 首先考虑小桌子。 对于一个$2\times 2$表格中的条目在行和列中形成算术级数，将条目标记为$a$,$a+d$,$a+e$,$a+d+e$， 在哪里$d$是行差并且$e$列差异。 角点的总和是$a + (a+d) + (a+e) + (a+d+e) = 4a + 2d + 2e = s$。 所有四个条目的总和与此计算一致，这表明总和与$s$。 延伸到一个$3\times 3$具有行差异的表$d_1$,$d_2$和列差异$e_1$,$e_2$，将条目明确写为$a_{ij} = a + (j-1)d + (i-1)e$。 对所有条目求和得出角条目以及行差和列差的倍数的组合。 尝试具体的数值示例，例如$a=1$,$d=2$,$e=3$，确认所有条目的总和成正比的模式$mn$乘以四个角的平均值。 这表明表的总和线性取决于$m$,$n$，以及角点的总和。 微妙的一步是确保针对小情况导出的公式可以推广到任意情况$m$和$n$并且算术级数的约束被完全纳入。 

## 问题理解

 该问题要求计算一个数组中所有条目的总和$m\times n$表，其中每行和每列都形成一个算术级数，假设四个角项的总和为$s$。 这是一个 C 类问题，因为它要求确定一个值，特别是所有表条目的总和。 核心困难是同时考虑行和列算术级数所施加的约束，并确保所有条目之和的表达式可以纯粹用以下形式表示：$m$,$n$，以及角点的总和，而不依赖于沿行和列的个体差异。 直观上，每个条目可以写为左上角与行差和列差的倍数的线性组合，因此所有条目的总和应因子为$mn$乘以四个角的平均值。 

## 证明架构

 引理 1 指出任何$m\times n$具有每行和每列中形成算术级数的条目的表可以表示为$a_{ij} = a + (j-1)d + (i-1)e$对于某些数字$a$,$d$,$e$。 这是正确的，因为指定左上角以及行和列差异确定了每个条目的唯一性。 引理 2 断言所有条目的总和可以通过求和来计算$i$和$j$式中$a_{ij} = a + (j-1)d + (i-1)e$。 这减少到线性依赖于的总和$a$,$d$， 和$e$。 引理 3 声称四个角的总和等于$s = a + a + (n-1)d + a + (m-1)e + a + (m-1)e + (n-1)d = 4a + 2(m-1)e + 2(n-1)d$，它提供了之间的线性关系$a$,$d$,$e$， 和$s$。 关键的一步是将总和表示为$s$,$m$， 和$n$独自一人，消除$a$,$d$， 和$e$。 

## 解决方案

 为条目添加标签$m\times n$表格依据$a_{ij}$和$1\le i\le m$和$1\le j\le n$。 因为每一行和每一列都是一个等差级数，表示$a_{11} = a$作为左上角的条目，$d$作为沿行的公差，并且$e$作为沿列的公差。 那么每个条目都可以写成$a_{ij} = a + (j-1)d + (i-1)e.$所有条目的总和是$\sum_{i=1}^{m}\sum_{j=1}^{n} a_{ij} = \sum_{i=1}^{m}\sum_{j=1}^{n} \left(a + (j-1)d + (i-1)e\right) = \sum_{i=1}^{m}\sum_{j=1}^{n} a + \sum_{i=1}^{m}\sum_{j=1}^{n} (j-1)d + \sum_{i=1}^{m}\sum_{j=1}^{n} (i-1)e.$计算每一项。 第一项是$mn a$。 第二项是$\sum_{i=1}^{m}\sum_{j=1}^{n} (j-1)d = \sum_{i=1}^{m} d\sum_{j=1}^{n} (j-1) = m d \frac{n(n-1)}{2}.$同样，第三项是$\sum_{i=1}^{m}\sum_{j=1}^{n} (i-1)e = \sum_{j=1}^{n} e\sum_{i=1}^{m} (i-1) = n e \frac{m(m-1)}{2}.$因此总和是$S = mn a + m d \frac{n(n-1)}{2} + n e \frac{m(m-1)}{2} = mn a + \frac{mn(n-1)}{2} d + \frac{mn(m-1)}{2} e.$因素$mn$获得$S = mn\left(a + \frac{n-1}{2} d + \frac{m-1}{2} e\right).$接下来是四个角$a_{11} = a$,$a_{1n} = a + (n-1)d$,$a_{m1} = a + (m-1)e$,$a_{mn} = a + (n-1)d + (m-1)e$。 他们的总和是$s = a + (a + (n-1)d) + (a + (m-1)e) + (a + (n-1)d + (m-1)e) = 4a + 2(n-1)d + 2(m-1)e.$两边除以$4$获得$\frac{s}{4} = a + \frac{n-1}{2} d + \frac{m-1}{2} e.$与之前的公式相比$S$，我们发现$S = mn \cdot \frac{s}{4}.$因此表中所有数字的总和为$\boxed{\frac{mn s}{4}}.$这样就完成了证明。 

## 关键步骤验证

 为了验证计算，考虑一个$2\times 3$表与$a = 1$,$d = 2$,$e = 3$。 那么表项是$\begin{matrix} 1 & 3 & 5 \\ 4 & 6 & 8 \end{matrix}.$角点的总和是$1 + 5 + 4 + 8 = 18$。 所有条目的总和是$1 + 3 + 5 + 4 + 6 + 8 = 27$，这与$mn s /4 = 2\cdot 3\cdot 18 /4 = 27$。 检查一个$3\times 3$表与$a=0$,$d=1$,$e=2$，角点是$0,2,4,6$与总和$12$，总和为$0+1+2+2+3+4+4+5+6=27$,再次匹配$mn s/4 = 3\cdot 3\cdot 12/4 = 27$。 这些独立的计算证实了因式分解和代数是正确的，并且在一般推导中没有遗漏任何项。 

## 替代方法

 另一种方法是考虑算术级数的线性，并认为所有条目的总和是行数和列数乘以第一行和最后一行的平均值的乘积。 同样，对第一列和最后一列求平均值会产生相同的结果。 直接对四个角求平均给出相同的线性组合。 这种方法使用对称参数并避免显式求和公式，但在用代数表达每个步骤时不太严格。 主要方法是更可取的，因为它为每个条目给出了明确的公式，确认每个系数的正确性，并处理任意$m$和$n$系统地。
