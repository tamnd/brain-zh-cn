 ## 问题

 让总和$1+\dfrac12+\dfrac13+\ldots+\dfrac1n$表示为$h_n$。 证明（对于每个自然数$n$) 不等式$$\dfrac1{h_1^2}+\dfrac1{2h_2^2}+\dfrac1{3h_3^2}+\ldots+\dfrac1{nh_n^2}\lt 2.$$。 

L·D·库兰奇克

 ## 探索

 让$$S_n=\sum_{k=1}^{n}\frac1{k h_k^2}.$$需要证明的不等式是$S_n<2$对于每一个$n$。 

首先计算几个项：$$h_1=1,\qquad h_2=\frac32,\qquad h_3=\frac{11}{6}.$$因此$$S_1=1,$$

$$S_2=1+\frac1{2(3/2)^2}=1+\frac29=\frac{11}{9},$$

$$S_3=\frac{11}{9}+\frac1{3(11/6)^2} =\frac{11}{9}+\frac{12}{121}\approx1.322.$$总和增长缓慢，因此伸缩估计是合理的。 

自从$$h_k-h_{k-1}=\frac1k,$$被加数可以重写为$$\frac1{k h_k^2} =\frac{h_k-h_{k-1}}{h_k^2}.$$一个自然的比较是$$\frac{h_k-h_{k-1}}{h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k},$$因为右手边有望远镜。 检查：$$\frac1{h_{k-1}}-\frac1{h_k} = \frac{h_k-h_{k-1}}{h_{k-1}h_k}.$$因此我们需要$$\frac1{h_k^2} \le \frac1{h_{k-1}h_k},$$这是真的，因为$h_k\ge h_{k-1}$。 

求和会给出$$S_n \le \sum_{k=1}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right),$$但$h_0$没有定义。 第一项必须分开。 

为了$k\ge2$,$$\frac1{k h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k}.$$然后$$S_n = 1+\sum_{k=2}^{n}\frac1{k h_k^2} \le 1+\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = 1+\left(1-\frac1{h_n}\right) = 2-\frac1{h_n}.$$自从$h_n>1$对于每一个$n\ge2$，这产生$S_n<2$。 为了$n=1$,$S_1=1<2$。 

唯一可能微妙的步骤是与伸缩差异的比较。 

## 问题理解

 我们必须证明对于每个自然数$n$,$$\sum_{k=1}^{n}\frac1{k h_k^2}<2,$$在哪里$$h_k=1+\frac12+\cdots+\frac1k$$是$k$次谐波数。 

这是一个B 类问题，纯粹的证明。 

核心难点是识别与因子相关的伸缩量$1/k=h_k-h_{k-1}$。 一旦将被加数与谐波数倒数的伸缩差进行比较，就会得出不等式。 

## 证明架构

 第一个主张是对于每一个$k\ge2$,$$\frac1{k h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k}.$$这是从$h_k-h_{k-1}=1/k$和不平等$h_{k-1}\le h_k$。 

第二个主张是将这些不平等相加$k=2$到$n$生产伸缩系列，$$\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = 1-\frac1{h_n}.$$This is the standard telescoping cancellation.

 最后一步是分离原始总和的第一项，应用之前的估计，并获得$$S_n\le 2-\frac1{h_n}<2.$$最有可能在审查中失败的引理是第一个比较不等式，因为它包含整个重要的估计。 

## 解决方案

 定义$$S_n=\sum_{k=1}^{n}\frac1{k h_k^2}.$$对于每一个$k\ge2$,$$h_k-h_{k-1}=\frac1k.$$因此$$\frac1{k h_k^2} = \frac{h_k-h_{k-1}}{h_k^2}.$$自从$h_{k-1}\le h_k$，我们有$$h_{k-1}h_k\le h_k^2,$$因此$$\frac1{h_k^2} \le \frac1{h_{k-1}h_k}.$$乘以正数$h_k-h_{k-1}$给出$$\frac{h_k-h_{k-1}}{h_k^2} \le \frac{h_k-h_{k-1}}{h_{k-1}h_k}.$$使用$h_k-h_{k-1}=1/k$,$$\frac1{k h_k^2} \le \frac{h_k-h_{k-1}}{h_{k-1}h_k} = \frac1{h_{k-1}}-\frac1{h_k}.$$将这个不等式求和为$k=2,3,\ldots,n$，我们得到$$\sum_{k=2}^{n}\frac1{k h_k^2} \le \sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right).$$右侧望远镜：$$\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = \frac1{h_1}-\frac1{h_n} = 1-\frac1{h_n}.$$最后，$$S_n = \frac1{h_1^2} + \sum_{k=2}^{n}\frac1{k h_k^2} \le 1+\left(1-\frac1{h_n}\right) = 2-\frac1{h_n}.$$如果$n=1$， 然后$S_1=1<2$。 

如果$n\ge2$， 然后$h_n>1$， 所以$$2-\frac1{h_n}<2.$$因此在所有情况下$$\sum_{k=1}^{n}\frac1{k h_k^2}<2.$$这样就完成了证明。 

∎

 ## 关键步骤验证

 临界估计是$$\frac1{k h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k}.$$从右手边开始，$$\frac1{h_{k-1}}-\frac1{h_k} = \frac{h_k-h_{k-1}}{h_{k-1}h_k} = \frac1{k\,h_{k-1}h_k}.$$因此估计相当于$$\frac1{h_k^2} \le \frac1{h_{k-1}h_k},$$这正是以下的结果$h_{k-1}\le h_k$。 没有使用隐藏假设。 

伸缩步骤为$$\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = \left(\frac1{h_1}-\frac1{h_2}\right) +\left(\frac1{h_2}-\frac1{h_3}\right) +\cdots +\left(\frac1{h_{n-1}}-\frac1{h_n}\right).$$每个中期任期都会取消，留下$$\frac1{h_1}-\frac1{h_n}.$$一个常见的错误是从以下位置开始求和：$k=1$，这会引入未定义的数量$h_0$。 分离第一项可以完全避免这个问题。 

最后的严格不等式需要检查$$2-\frac1{h_n}<2.$$为了$n\ge2$,$$h_n=1+\frac12+\cdots+\frac1n>1,$$所以$1/h_n>0$。 为了$n=1$，原总和等于$1$。 因此每个值$n$被覆盖。 

## 替代方法

 人们可以将被加数重写为$$\frac1{k h_k^2} = \frac{h_k-h_{k-1}}{h_k^2}$$并与积分进行比较$$\int_{h_{k-1}}^{h_k}\frac{dx}{x^2}.$$自从$x\le h_k$整个间隔$[h_{k-1},h_k]$,$$\int_{h_{k-1}}^{h_k}\frac{dx}{x^2} \ge \frac{h_k-h_{k-1}}{h_k^2} = \frac1{k h_k^2}.$$总结$k\ge2$给出$$\sum_{k=2}^{n}\frac1{k h_k^2} \le \int_{1}^{h_n}\frac{dx}{x^2} = 1-\frac1{h_n},$$同样的结论如下。 

伸缩证明是更可取的，因为它完全停留在初等代数范围内，并且直接展示了差异主导被加数的数量。
