 ## 问题

 证明直角三角形的斜边除以其内切圆的切点所得的线段长度的乘积等于三角形的面积。 

## 探索

 考虑一个直角三角形$ABC$与直角在$C$。 将斜边表示为$AB$让内切圆接触$AB$在点$D$。 表示段$AD = p$和$DB = q$， 以便$AB = p + q$。 其主张是$p \cdot q$等于三角形的面积$ABC$。 指定边长$AC = b$,$BC = a$,$AB = c$，并让$s = \frac{a+b+c}{2}$是半周长。 从中心点和切点的标准公式，我们知道$AD = s - a$和$DB = s - b$。 然后$p \cdot q = (s - a)(s - b)$。 直角三角形的面积是$\frac{1}{2}ab$，所以任务减少为显示$(s - a)(s - b) = \frac{1}{2}ab$在此背景下。 尝试小的数字示例，例如$a = 3$,$b = 4$,$c = 5$，产量$s = 6$,$p = s - a = 3$,$q = s - b = 2$,$p \cdot q = 6$， 和$\frac{1}{2}ab = 6$。 等式成立。 核心观点似乎是在表达$p$和$q$按照$a$,$b$， 和$c$使用半周长然后简化。 

## 问题理解

 该题要求证明，对于直角三角形，斜边除以内圆切点所得的线段的乘积等于三角形的面积。 这是一个 B 类问题：纯粹的证明。 主要困难在于用三角形的边严格表达斜边上的线段，并确认它们的乘积等于面积而不跳过任何代数论证。 它起作用的直观原因是内切圆的切点满足$AD = s - a$和$DB = s - b$，得出与面积公式相匹配的对称公式。 

## 证明架构

 引理 1：在任何三角形中，内圆将每条边分成等于半周长减去对边的线段，具体来说$AD = s - a$和$DB = s - b$。 这是从内切圆与边的相切公式得出的。 

引理 2：在有腿的直角三角形中$a$,$b$和斜边$c$，半周长是$s = \frac{a + b + c}{2}$， 所以$s - a = \frac{b + c - a}{2}$和$s - b = \frac{a + c - b}{2}$。 这是简单的算术。 

引理 3：在直角三角形中，$c = \sqrt{a^2 + b^2}$，因此$(s - a)(s - b) = \frac{1}{2}ab$。 证明需要扩展$(s - a)(s - b)$仔细代数并简化以匹配面积公式$\frac{1}{2}ab$。 

最难的一步是引理 3，因为粗心的展开可能会忽略直角三角形关系并给出不同的值。 

## 解决方案

 让$ABC$是一个直角三角形，其直角为$C$, 腿$AC = b$,$BC = a$和斜边$AB = c$。 将中心表示为$I$让内切圆接触$AB$在$D$。 半周长是$s = \frac{a + b + c}{2}$。 根据内切圆的标准性质，$AD = s - a$和$DB = s - b$。 然后$(s - a)(s - b) = \left(\frac{a + b + c}{2} - a\right)\left(\frac{a + b + c}{2} - b\right) = \left(\frac{b + c - a}{2}\right)\left(\frac{a + c - b}{2}\right).$自从$c^2 = a^2 + b^2$，我们有$c = \sqrt{a^2 + b^2}$，因此$b + c - a = b - a + \sqrt{a^2 + b^2}, \quad a + c - b = a - b + \sqrt{a^2 + b^2}.$所以$(s - a)(s - b) = \frac{(b - a + \sqrt{a^2 + b^2})(a - b + \sqrt{a^2 + b^2})}{4} = \frac{(\sqrt{a^2 + b^2})^2 - (a - b)^2}{4}.$展开分子得到$a^2 + b^2 - (a^2 - 2ab + b^2) = 2ab,$以便$(s - a)(s - b) = \frac{2ab}{4} = \frac{ab}{2}.$三角形的面积$ABC$是$\frac{1}{2}ab$，这与$(s - a)(s - b)$。 这样就完成了证明。 

∎

 ## 关键步骤验证

 关键代数是展开式$(\sqrt{a^2 + b^2})^2 - (a - b)^2 = a^2 + b^2 - (a^2 - 2ab + b^2) = 2ab$。 用数字示例进行测试证实了正确性：对于$a = 3$,$b = 4$,$c = 5$，我们有$(s - a)(s - b) = 3 \cdot 2 = 6$和$\frac{1}{2}ab = 6$。 表达式$(s - a)(s - b)$对符号错误敏感$a - b$，所以仔细地写成$(\sqrt{a^2 + b^2} - (a - b))(\sqrt{a^2 + b^2} + (a - b))$确保正确分解。 

## 替代方法

 几何方法将直角三角形视为由两个共享内心的较小直角三角形组成，并通过相似性沿斜边构造线段。 其一表明，线段的乘积等于高度和投影的几何平均性质的面积。 代数方法更可取，因为它给出了一个明确的通用公式，无需引入额外的结构或比率，使其完全严格且可立即验证任意直角三角形。
