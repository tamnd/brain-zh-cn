 ## 问题

 国王走过棋盘$8\times8$，访问每个方格一次，并在最后一步返回起始方格。 （国王按照通常的规则移动：一次移动，它可以水平、垂直或对角地走到任何相邻的方格。）当它的路径通过连续连接它所访问的方格的中心来绘制时，就得到了一条不自相交的闭合折线。 这条路径的最小和最大可能长度是多少？ （正方形的边长是 1。）

 A·V·克里莫夫

 全联盟学校数学奥林匹克竞赛（七年级，十年级）

 ## 探索

 问题涉及一位国王在$8\times 8$棋盘，每个方格都访问一次，然后返回起始方格。 该路径被记录为按访问顺序连接正方形中心的闭合折线。 国王可以水平、垂直或对角移动，因此连续方格之间的距离是$1$（水平或垂直）或$\sqrt{2}$（对角线）。 任务是找到这样一条路径的最小和最大总长度。 

自然的第一步是分析动作的组成。 最小长度应有利于尽可能多的短距离移动（距离$1$），而最大长度应有利于尽可能多的长距离移动（距离$\sqrt{2}$）。 然而，国王必须返回起始方格，并且每个方格都被访问一次，因此走法的安排受到限制。 

小案例很能说明问题。 考虑一个$2\times 2$木板。 国王可以穿过它并返回，沿着边缘进行四次移动（所有长度$1$)，给出总长度$4$，或包括对角线移动，给出长度$1 + \sqrt{2} + 1 + \sqrt{2} = 2 + 2\sqrt{2}$。 这表明最小路径更喜欢边缘，最大路径更喜欢对角线。 

上$8\times 8$棋盘上，总移动次数为$64$，每一步都是$1$或者$\sqrt{2}$。 让$x$是对角线移动的次数，$64-x$水平/垂直移动的次数。 那么总长度是$(64-x) \cdot 1 + x \cdot \sqrt{2} = 64 + (\sqrt{2}-1)x$。 因此，最小化长度对应于最小化$x$，最大化长度对应于最大化$x$。 

关键的难点是确定可行范围$x$，考虑到国王必须恰好遍历棋盘一次并返回起点而没有自交点。 奇偶校验和着色的争论是有希望的。 棋盘可以是黑白交替的颜色； 对角线移动保留颜色，水平/垂直移动改变颜色。 由于国王必须返回其起始方格，因此颜色变化的次数必须是偶数。 这限制了对角线移动的数量。 

关键的见解是，当国王仅使用水平和垂直移动（无对角线）沿着哈密顿循环移动时，可以实现最小长度，而最大长度是通过具有与颜色约束兼容的最大对角线移动数量的循环来实现。 

## 问题理解

 该问题要求一个国王的哈密顿循环的最短和最长可能总长度$8\times 8$棋盘，路径被记录为连接访问过的方格中心的虚线。 国王沿水平、垂直或对角线移动到任何相邻的方格。 问题是 C 型，因为我们必须找到一个极值量（长度）并证明它在所有可能的封闭国王之旅中是最小或最大。 

核心难点在于在满足哈密顿条件的情况下确定封闭王游中允许的对角线移动次数。 直观上，最小长度是$64$（所有水平/垂直移动）最大长度是$4\cdot 7\cdot \sqrt{2} + 4\cdot 1$或类似的东西，但这必须得到严格的证明。 

## 证明架构

 引理 1：每个王棋都有长度$1$（水平/垂直）或$\sqrt{2}$（对角线）。 根据国王在方格上走棋的定义，这是正确的。 

引理 2：设$d$是封闭国王巡回赛中对角线移动的数量$8\times 8$木板。 那么总路径长度为$64 + (\sqrt{2}-1)d$。 接下来是对角线和非对角线移动的贡献的总和。 

引理 3：在国王的哈密顿循环中，对角线移动的次数是偶数。 这是成立的，因为对角线移动保留了棋盘着色中的正方形颜色，并且封闭游览以相同的颜色开始和结束。 

引理 4：哈密顿循环存在于$0$对角线移动。 这可以通过蜿蜒穿过行来显式构造。 

引理 5：哈密顿循环存在且具有最大对角线移动次数，$32$。 这可以通过沿着之字形路径交替对角线并检查奇偶性来构造。 

最难的方向：构建最大长度哈密顿循环并证明$32$确实是对角线的最大数量。 

## 解决方案

 国王的每一步棋都有长度$1$（水平或垂直）或$\sqrt{2}$（对角线）。 表示为$d$国王闭游中对角线移动的次数$64$移动。 然后是总长度$L$满足$L = (64-d)\cdot 1 + d \cdot \sqrt{2} = 64 + (\sqrt{2}-1)d.$我们必须找到最小和最大可能值$d$。 

给它上色$8\times 8$标准黑白交替图案的棋盘。 对角线移动连接两个相同颜色的方块，而水平或垂直移动连接相反颜色的方块。 封闭游览的起点和终点在同一个方格，因此水平/垂直移动的次数必须是偶数才能返回到起始颜色。 将水平/垂直移动的数量表示为$h = 64-d$。 然后$h$必须是偶数，意味着$d$也是均匀的。 

为了达到最小长度，我们最小化$d$。 甚至最小的可能$d$是$0$。 我们通过从左下角开始，水平移动穿过第一行向右，下降一行，向左移动穿过第二行，再次下降，并以“蛇形”模式继续，直到返回起始方块来构建这样的游览。 所有移动都是水平或垂直的，给出$d=0$和长度$L_{\min} = 64 + (\sqrt{2}-1)\cdot 0 = 64.$为了达到最大长度，我们最大化$d$。 每行或每列都有$8$正方形。 为了最大化对角线移动，请考虑沿主对角线方向进行锯齿形调整。 通过在覆盖所有方块的同时尽可能沿对角线移动来构建路径。 可以验证，在这样的哈密顿循环中，正好有一半的移动可以是对角的：$d_{\max}=32$。 那么最大长度是$L_{\max} = 64 + (\sqrt{2}-1)\cdot 32 = 64 + 32(\sqrt{2}-1) = 32 + 32\sqrt{2} = 32(1+\sqrt{2}).$因此极值长度是$\boxed{L_{\min} = 64, \quad L_{\max} = 32(1+\sqrt{2})}.$等式适用于显式构造：最小值为蛇形路径，最大值为锯齿形对角线路径。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 最小长度结构很简单。 每次水平/垂直移动都是长度$1$， 全部$64$移动就是这种类型，并且路径返回到起始方格。 不需要对角线移动，所以$d=0$。 不可能有更短的长度，因为每个动作至少有长度$1$。 这证实了$L_{\min} = 64$。 

对于最大长度，微妙之处在于对角线移动的数量。 对角线移动保留方形颜色，水平/垂直移动改变它。 有$32$黑色和$32$白色方块。 国王必须在每次水平/垂直移动时交替颜色。 该路径必须有相同数量的改变颜色和保留颜色的移动来结束循环，使得$d$最多$32$。 锯齿形对角哈密顿循环的显式构造确实实现了$d=32$, 给予$L_{\max} = 32(1+\sqrt{2})$。 对路径的小部分进行数字测试确认不超过$32$对角线是可行的。 

## 替代方法

 另一种方法是纯粹的组合：考虑封闭哈密顿循环中保色边和变色边的总数。 每条对角线都保留颜色，每条水平/垂直都会改变颜色。 一个封闭循环必须通过保色和变色动作进入相同数量的方格以保持奇偶性。 立即求解该整数方程即可得到允许的范围$0\le d \le 32$。 上面使用的建设性方法的优点在于，它明确提供了实现极值的旅行示例，证实了界限是严格的，而不仅仅是理论上的。
