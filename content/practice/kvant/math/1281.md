 ## 问题

 证明如果两个正数的乘积大于它们的和，则它们的和大于 4。 

N·B·瓦西里耶夫

 城镇锦标赛（1990 年秋季）

 ## 探索

 考虑两个正数$x$和$y$这样$xy > x + y$。 尝试小整数对表明，对于小于或等于的数字，不等式失败$2$。 例如，$x = y = 1$给出$xy = 1$和$x + y = 2$， 所以$1 \not> 2$。$x = y = 2$给出$xy = 4$和$x + y = 4$， 所以$4 \not> 4$。$x = y = 3$给出$xy = 9$和$x + y = 6$， 所以$9 > 6$，有效。 这表明如果$xy > x + y$，那么两者$x$和$y$严格大于$2$。 测试稍微不对称的情况，例如$x = 1.5$和$y = 3$，产量$xy = 4.5$和$x + y = 4.5$，这是相等的，所以仍然不是严格意义上的更大。 这一探索表明临界边界已接近$2$，总和必须超过$4$。 

核心观点是不平等$xy > x + y$相当于$(x - 1)(y - 1) > 1$，这将问题转化为更简单的形式，其中下界为$x + y$变得透明。 最微妙的一步是证明这一点$(x - 1)(y - 1) > 1$确实意味着$x + y > 4$对于所有积极的$x$和$y$。 

## 问题理解

 我们被要求证明一个通用的命题：如果两个正数的乘积超过它们的和，那么它们的和超过$4$。 这是一个B 类问题。 困难在于改变不平等$xy > x + y$转换为允许直接推理总和的形式$x + y$。 关键的观察是减去$x + y$从两侧并添加$1$给出一个因式分解，产生下界$x + y$。 这个问题表面上很基本，但需要精确操纵不平等并仔细处理积极性。 

## 证明架构

 引理 1：对于任何正数$x$和$y$，不等式$xy > x + y$相当于$(x - 1)(y - 1) > 1$。 接下来通过扩展$(x - 1)(y - 1)$并重新排列术语。 

引理 2：如果$x - 1 > 0$和$y - 1 > 0$， 和$(x - 1)(y - 1) > 1$， 然后$x + y = (x - 1) + (y - 1) + 2 > 4$。 这是从 AM-GM 应用于$(x - 1)$和$(y - 1)$，但也可以直接验证，因为总和超过乘积平方根的两倍，大于$2$。 

最困难的一步是确保双方$x - 1$和$y - 1$是正数，即$x > 1$和$y > 1$，必须从初始不等式证明其合理性$xy > x + y$。 这需要考虑一个变量是的情况$\le 1$而展示这些是不可能的。 

## 解决方案

 让$x$和$y$是满足正数$xy > x + y$。 首先考虑以下可能性：$x \le 1$或者$y \le 1$。 不失一般性，假设$x \le 1$。 然后$xy \le y$， 自从$x \le 1$， 和$x + y \ge y + 0 = y$。 所以$xy \le y \le x + y$，矛盾$xy > x + y$。 这一矛盾表明，双方$x$和$y$必须严格大于$1$， 所以$x - 1 > 0$和$y - 1 > 0$。 

将不等式重写为$xy - x - y > 0$并添加$1$双方得到$(x - 1)(y - 1) = xy - x - y + 1 > 1.$自从$x - 1 > 0$和$y - 1 > 0$，我们可以考虑它们的总和：$x + y = (x - 1) + (y - 1) + 2.$不平等$(x - 1)(y - 1) > 1$意味着$(x - 1) + (y - 1) > 2$因为对于任意两个正数$a$和$b$， 如果$ab > 1$， 然后$a + b > 2$，根据应用于的 AM-GM 不等式得出$a$和$b$:$\frac{a + b}{2} \ge \sqrt{ab} > 1 \implies a + b > 2.$替代$a = x - 1$和$b = y - 1$，我们得到$(x - 1) + (y - 1) > 2 \implies x + y = (x - 1) + (y - 1) + 2 > 4.$这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的第一步正在显现$x > 1$和$y > 1$。 测试$x = 1$或者$y = 1$产生平等$xy = x + y$，所以不会出现反例。 如果$x < 1$和$y > 1$， 然后$xy < y < x + y$，证实了不可能。 测试$x, y \in (0,1)$给出$xy < x + y$，也是不可能的。 因此扣除$x, y > 1$是严谨的。 

第二个微妙的步骤是应用 AM-GM$(x - 1)$和$(y - 1)$。 认为$(x - 1)(y - 1) = 1 + \epsilon$和$\epsilon > 0$。 然后$\sqrt{(x - 1)(y - 1)} = \sqrt{1 + \epsilon} > 1$， 所以$(x - 1) + (y - 1) \ge 2\sqrt{(x - 1)(y - 1)} > 2$, 确认$x + y > 4$。 直接替换数字示例，例如$x = 2.5$,$y = 2$，给出$xy = 5 > 4.5 = x + y$和$x + y = 4.5 > 4$，与不等式一致。 

## 替代方法

 一种替代方法是修复$x + y = s$并治疗$xy$作为$p$。 那么不等式$p > s$可以重写为$p - s > 0$，并使用$p \le \frac{s^2}{4}$通过AM-GM，我们得到$s^2/4 - s > 0 \implies s(s - 4) > 0$，这直接给出$s > 4$自从$s > 0$。 这种方法在代数上是紧凑的，但需要回忆两个具有固定和的正数的最大乘积。 主要方法是更可取的，因为它仅使用基本不等式而不引入额外参数，并给出清晰的逐步推理，适合竞赛式解决方案。
