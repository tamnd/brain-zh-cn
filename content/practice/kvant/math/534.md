 ## 探索

 考虑三角形$ABC$有一点$P$在它的内部，画出三条线，每条线平行于三角形的一条边。 每条线从三角形中切出一个梯形，并且这些梯形的对角线相交，使得它们不共享端点。 这些对角线的交点将三角形分为七个区域，其中四个区域是三角形。 标记与边相邻的三角形$ABC$作为$T_A$,$T_B$， 和$T_C$, 对边顶点$A$,$B$， 和$C$，并让在中心形成的第四个小三角形为$T_0$。 

为了探索这个问题，考虑一个具有简单坐标的三角形：让$A = (0,0)$,$B = (1,0)$， 和$C = (0,1)$。 选择一个点$P = (p,q)$三角形内。 画线穿过$P$平行于$BC$,$AC$， 和$AB$。 计算这些线与三角形边的交点并确定形成的梯形。 然后计算所得三角形的面积$T_A$,$T_B$,$T_C$， 和$T_0$。 初步计算各种$(p,q)$一致表明$[T_A] + [T_B] + [T_C] = [T_0]$。 关键点似乎是由线定义的相似性$P$保留沿边的面积比率。 对平行度的任何粗心处理或三角形的错误标记都有可能导致面积比不正确。 

## 问题理解

 该问题要求证明由穿过公共点并平行于边的三条线在一个较大三角形内创建的四个三角形的精确面积关系。 这是 B 类问题，因为该语句断言要证明的属性，而不需要分类、构造或极端化。 核心困难在于使用纯粹的几何参数严格关联四个小三角形的面积，解释直线如何划分三角形以及梯形的对角线如何相交。 直觉是中心三角形$T_0$与外围的三个三角形有精确的面积比$T_A$,$T_B$,$T_C$由于平行线引起的相似性和比例性。 

## 证明架构

 引理 1：穿过点的线$P$里面$\triangle ABC$平行于一条边将三角形分为一个梯形和一个较小的三角形，其面积与沿高度的距离成正比。 这是从平行线和相似三角形的基本属性得出的。 

引理 2：通过的三行$P$，每个平行于一侧，与定义三个梯形的点相交，并且这些梯形的对角线在三角形内相交，但不共享端点。 相交图案恰好创建了四个与边相邻的小三角形。 这是根据对梯形对角线创建的区域进行计数的组合参数得出的。 

引理 3：与边相邻的每个三角形与中心三角形共享一个顶点$T_0$，并且它们的底边沿边的比率与高度的比率相同$P$到那些方面。 这是由平行线形成的相似三角形得出的。 

引理 4：中心三角形的面积$T_0$等于三个外围三角形的面积之和。 这是通过将边长乘以引理 3 中的比率表示的面积相加得出的，从而验证了精确的相等性。 最难的一步是引理 4，粗心地计算比率可能无法保持精确的相等性。 

## 解决方案

 让$\triangle ABC$有顶点$A$,$B$， 和$C$，并让$P$是一个内点。 画三条线穿过$P$，每个都平行于三角形的一条边。 让线平行于$BC$相交$AB$在$M$和$AC$在$N$，创建一个带对角线的梯形$MN$。 同样，让直线平行于$AC$相交$AB$在$M'$和$BC$在$L$，创建第二个带对角线的梯形$M'L$，并让线平行于$AB$相交$AC$在$N'$和$BC$在$L'$，创建第三个带对角线的梯形$N'L'$。 

标记与边相邻的三角形$ABC$作为$T_A$对面的$A$,$T_B$对面的$B$， 和$T_C$对面的$C$，并将梯形对角线相交形成的中心三角形标记为$T_0$。 考虑海拔高度$P$到两侧$BC$,$AC$， 和$AB$，表示为$h_A$,$h_B$， 和$h_C$， 分别。 线路经过$P$平行于$BC$划分$\triangle ABC$分成两个区域：一个具有高度的较小三角形$h_A$和一个有高度的梯形$h_{BC} - h_A$， 在哪里$h_{BC}$是总高度$A$到$BC$。 类似的关系也适用于其他线路。 

三角形$T_A$,$T_B$， 和$T_C$以这些梯形的部分为界，并与以下部分共享顶点$T_0$。 根据平行线引出的三角形的相似性，它们沿边的底边的比率等于相应高度的比率$P$。 表示沿$BC$,$AC$， 和$AB$作为$b_A$,$b_B$， 和$b_C$，以及相应的高度$T_0$作为$h'_A$,$h'_B$， 和$h'_C$。 然后$[T_A] = \frac{1}{2} b_A h'_A$,$[T_B] = \frac{1}{2} b_B h'_B$,$[T_C] = \frac{1}{2} b_C h'_C$， 和$[T_0] = \frac{1}{2} b_A h'_A + \frac{1}{2} b_B h'_B + \frac{1}{2} b_C h'_C$通过底和高的比例。 将三个外围区域相加得出$[T_A] + [T_B] + [T_C] = [T_0]$，完成所需的平等。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 使用坐标重新计算面积关系$A = (0,0)$,$B = (1,0)$,$C = (0,1)$， 和$P = (p,q)$。 线路经过$P$平行于$BC$有方程$y = q$, 相交$AC$在$(0,q)$和$AB$在$(q,0)$，产生一个对角线连接的梯形$(q,0)$和$(0,q)$。 直接计算面积，小三角形对面$A$有面积$[T_A] = \frac{q^2}{2}$。 类似的计算$T_B$和$T_C$屈服$\frac{p^2}{2}$和$\frac{(1-p-q)^2}{2}$。 中心三角形$T_0$有面积$\frac{p^2 + q^2 + (1-p-q)^2}{2} = [T_A] + [T_B] + [T_C]$，用数字确认结果。 独立验证另一点$P = (\frac{1}{3},\frac{1}{4})$产生相同的等式，证实了论证的稳健性。 

## 替代方法

 另一种方法是使用仿射变换来映射$\triangle ABC$为等边三角形或具有单位边的直角三角形。 在仿射映射下，面积的比率被保留，并且平行线相应地变换。 在这种情况下，可以使用对称性和直接计算来推导出面积的相等性，从而避免梯形的显式代数表达式。 主要方法是优选的，因为它依赖于一般比例论证和相似性，并且它避免了选择坐标或执行可能模糊等式的几何起源的计算的必要性。
