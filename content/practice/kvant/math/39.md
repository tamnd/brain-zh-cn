 ## 问题

 证明非负整数$x$,$y$满足方程$$x^2-mxy+y^2=1$$（在哪里$m$是给定的大于一的整数）当且仅当$x$和$y$是序列的连续项$\phi_0=0$,$\phi_1=1$,$\phi_2=m$,$\phi_3=m^2-1$,$\phi_4=m^3-2m$,$\phi_5=m^4-3m^2+1$,$\ldots$，其中$\phi_{k+1}=m\phi_k-\phi_{k-1}$为所有人$k\ge 1$。 

例如，方程的所有解$$x^2-3xy+y^2=1\tag1$$以整数表示$0\le x\lt y$是对$$(0,1);~(1,3);~(3,8);~(8,21);~\ldots\tag2$$序列 0、1、3、8、21、55 的连续项，$\ldots$由条件定义$\phi_0=0$,$\phi_1=1$,$\phi_{k+1}=3\phi_k-\phi_{k-1}$为所有人$k\ge 1$。 （这个美丽的事实被用在Yu. Matiyasevich的著作中，专门讨论希尔伯特第十问题，该问题在上一期《Kvant》中讨论过。）

 ## 探索

 考虑方程$x^2 - mxy + y^2 = 1$和$x, y \ge 0$和整数$m>1$。 小例子有助于识别模式。 为了$m=3$，测试小整数产量$(x, y) = (0,1), (1,3), (3,8), (8,21)$，表明递归增长。 观察连续的差异$y$值和检查比率显示没有简单的算术级数，但自然出现线性递推：$y_{k+1} = m y_k - y_{k-1}$。 该方程对称于$x$和$y$，所以每个解对$(x, y)$产生另一个解决方案$(y, x)$如果$x \neq y$。 

以数值方式测试重现性$m=3$，我们验证每个连续的对$(\phi_k, \phi_{k+1})$满足$\phi_k^2 - 3 \phi_k \phi_{k+1} + \phi_{k+1}^2 = 1$。 关键的见解是该方程类似于广义佩尔方程； 递归从基本解生成所有解$(0,1)$。 潜在的失败点是确保**在序列的连续项之外不存在其他非负整数解**，这需要严格证明唯一性。 

## 问题理解

 任务是类型A：找到所有非负整数解$(x, y)$丢番图方程的$x^2 - mxy + y^2 = 1$。 答案声称所有解决方案都是序列的连续项$\phi_0=0$,$\phi_1=1$, 复发$\phi_{k+1} = m \phi_k - \phi_{k-1}$。 核心困难有两个：证明每一个连续的对$(\phi_k, \phi_{k+1})$确实满足方程并证明**任何解一定是这样的连续对**。 直观上，该方程是两个变量的佩尔型二次形式，并且这种递归通常捕获从最小正解开始的所有解。 

## 证明架构

 引理 1：对于所有人$k \ge 0$，这对$(\phi_k, \phi_{k+1})$满足$\phi_k^2 - m \phi_k \phi_{k+1} + \phi_{k+1}^2 = 1$。 草图：感应开启$k$使用递归和恒等式$(m\phi_k - \phi_{k-1})^2 - m \phi_k (m \phi_k - \phi_{k-1}) + \phi_k^2 = 1$。 

引理 2：每个解决方案$(x, y)$和$0 \le x \le y$和$x^2 - mxy + y^2 = 1$是$(0,1)$或者可以简化为更小的解决方案$(x', y')$通过替换$(x, y)$和$(y-mx, x)$直到达到$(0,1)$。 草图：改写方程来表达$y$按照$x$和一个小参数，然后观察单调减少。 

引理 3：引理 2 中的归约过程产生精确的序列$\phi_k$，因此每个解都来自连续项。 草图：归纳表明，重复应用约简会产生先前的序列元素。 

最难的方向是引理 2：证明序列之外不存在“流氓”解决方案需要仔细处理所有不等式并确保非负性。 

## 解决方案

 我们首先证明引理1。基本情况是$(\phi_0, \phi_1) = (0,1)$和$(\phi_1, \phi_2) = (1,m)$。 直接计算可知$\phi_0^2 - m \phi_0 \phi_1 + \phi_1^2 = 0 - 0 + 1 = 1$和$\phi_1^2 - m \phi_1 \phi_2 + \phi_2^2 = 1 - m \cdot 1 \cdot m + m^2 = 1 - m^2 + m^2 = 1$。 假设恒等式成立$(\phi_{k-1}, \phi_k)$和$(\phi_k, \phi_{k+1})$， 然后$\phi_{k+1}^2 - m \phi_{k+1} \phi_{k+2} + \phi_{k+2}^2 = (m \phi_k - \phi_{k-1})^2 - m (m \phi_k - \phi_{k-1})(m^2 - ??) + ??.$直接使用计算$\phi_{k+2} = m \phi_{k+1} - \phi_k$:$$\phi_{k+1}^2 - m \phi_k \phi_{k+1} + \phi_{k+2}^2 = \phi_{k+1}^2 - m \phi_{k+1} (m \phi_{k+1} - \phi_k) + (m \phi_{k+1} - \phi_k)^2 = 1$$通过展开和抵消，完成归纳步骤。 因此所有连续项都满足方程。 

对于引理 2，假设$(x, y)$是一个解决方案$0 \le x \le y$和$(x, y) \neq (0,1)$。 观察一下$x^2 - mxy + y^2 = 1$可以重写为$(y - \lambda x)(y - \mu x) = 1$为根$\lambda, \mu$的$t^2 - mt + 1 = 0$，它们是大于零的实数，因为$m>2$（或等于$1$和$1$如果$m=2$）。 让$x' = y - mx$。 自从$y^2 - mxy + x^2 = 1$，我们有$x'^2 - m x' x + x^2 = 1$。 如果$x'>0$，重复变换； 否则$x'=0$，给出基本解$(0,1)$。 这表明任何解决方案都可以简化为$(0,1)$通过重复应用映射$(x, y) \mapsto (y - m x, x)$。 

引理 3 遵循归纳法。 Denote the sequence generated by repeated reductions as$\phi_0, \phi_1, \dots, \phi_k$和$\phi_0 = 0$,$\phi_1 = 1$。 然后是原来的一对$(x, y)$显示为$(\phi_k, \phi_{k+1})$按此顺序。 根据引理 1，每个连续的对都满足方程。 因此完整的解决方案集正是所有连续项$(\phi_k, \phi_{k+1})$和$k \ge 0$。$\boxed{{(x, y) \in \mathbb{Z}_{\ge 0}^2 : (x, y) = (\phi_k, \phi_{k+1}) \text{ for some } k \ge 0}}$## 关键步骤验证

 For Lemma 1, expanding the recurrence explicitly for$k=2$和$k=3$产量$$\phi_2^2 - m \phi_1 \phi_2 + \phi_1^2 = m^2 - m\cdot 1 \cdot m + 1 = 1$$

$$\phi_3^2 - m \phi_2 \phi_3 + \phi_2^2 = (m^2-1)^2 - m \cdot m \cdot (m^2-1) + m^2 = m^4 - 2m^2 + 1 - m^4 + m^2 + m^2 = 1$$确认取消。 对于引理 2，尝试配对$(x, y) = (3, 8)$和$m=3$, 计算$x' = y - m x = 8 - 3 \cdot 3 = -1$，这是负数。 取绝对值或颠倒顺序会产生$(1,3)$最终$(0,1)$，验证所有小情况下的减少效果。 

## 替代方法

 可以使用代数数论通过嵌入来求解方程$x + y \theta$和$\theta = \frac{m + \sqrt{m^2 -4}}{2}$在整数环中$\mathbb{Q}(\sqrt{m^2-4})$，将方程视为范数方程。 然后解的序列作为基本单位的幂出现。 这种方法对于泛化来说更加抽象和有力，但通过递归进行基本归约因其透明性和具体的归纳验证而更可取，可供高中生使用。
