 ## 问题

 解正整数方程：

 1.$$2^x+1=3^y;$$2.$$z^x+1=(z+1)^2;$$3.$$z^x+1=(z+1)^y.$$D·弗莱什曼

 ## 探索

 等式（1），$2^x + 1 = 3^y$，建议搜索比 3 的幂小 1 的 2 的幂。小整数实验表明$x=1$,$y=1$作品：$2^1 + 1 = 3$。 下一个，$x=3$给出$2^3 + 1 = 9 = 3^2$，这是另一种解决方案。 更高$x$快速成长；$2^5 + 1 = 33$，不是 3 的幂。方程 (2)，$z^x + 1 = (z+1)^2$，可以重写为$z^x = z^2 + 2z + 1$， 或者$z^x - z^2 - 2z - 1 = 0$，这对于小$z$和$x$可以检查。 等式（3），$z^x + 1 = (z+1)^y$，是 (2) 的推广，当$y=2$。 对于小整数，左边的增长速度比右边的大整数快$x$，所以只存在小的解决方案。 关键的困难是限制指数并确保不存在更大的解决方案。 

## 问题理解

 任务是确定三个相关指数丢番图方程的所有正整数解。 每个问题都是 A 类问题：找到所有解决方案。 核心难点是控制指数函数的增长并排除大解。 对于(1)，只有$(x,y) = (1,1)$和$(3,2)$由于快速增长的差异而工作$2^x$和$3^y$。 对于（2），小$x$可能就足够了； 更大$x$产生的左侧超过右侧的二次方。 方程（3）概括了（2），但同样的原理也适用：大$x$或者$y$很快就会违反相等性，只留下有限的小整数列表。 

## 证明架构

 引理 1： 的唯一正整数解$2^x + 1 = 3^y$是$(x,y) = (1,1)$和$(3,2)$。 草图：检查小$x$并应用奇偶校验和模 3 参数来排除更大的解决方案。 

引理 2： 的唯一正整数解$z^x + 1 = (z+1)^2$是$(z,x) = (1,1), (2,3)$。 草图：因素$z^x - (z+1)^2 + 1$并比较增长$x \ge 3$。 

引理 3： 的唯一正整数解$z^x + 1 = (z+1)^y$和$y > 2$满足$x = 1$和$y = 1$，或小的枚举案例。 草图：$z^x$增长速度快于$(z+1)^y$为了$x \ge 2$,$y \ge 3$，只留下有限的许多小可能性来检查。 

最难的引理：引理 3，因为它涉及两个参数不等式，需要仔细的案例分析。 

## 解决方案

 等式（1），$2^x + 1 = 3^y$，首先被考虑。 为了$x=1$，我们得到$2+1=3=3^1$, 给予$(x,y) = (1,1)$。 为了$x=2$,$2^2 + 1 = 5$，不是 3 的幂。对于$x=3$,$2^3 + 1 = 9 = 3^2$, 给予$(3,2)$。 为了$x \ge 4$，考虑模 3：$2^x \equiv 1 \pmod 3$如果$x$是偶数，$2^x \equiv 2 \pmod 3$如果$x$很奇怪。 然后$2^x + 1 \equiv 2 \pmod 3$如果$x$是偶数并且$0 \pmod 3$如果$x$很奇怪。 自从$3^y \equiv 0 \pmod 3$,$x$一定是奇数。 对于奇数$x \ge 5$,$2^x + 1$增长速度快于下一个 3 的幂，并且不存在相等情况。 因此，解决方案是$(x,y) = (1,1), (3,2)$。 

等式（2），$z^x + 1 = (z+1)^2$，可以重写为$z^x = z^2 + 2z$。 为了$x=1$,$z + 1 = z^2 + 2z$，导致$z^2 + z -1 =0$，它没有正整数解。 为了$x=2$,$z^2 + 1 = (z+1)^2 = z^2 + 2z + 1$, 给予$2z = 0$，无正解。 为了$x=3$,$z^3 + 1 = z^2 + 2z +1$，简化为$z^3 - z^2 - 2z = 0$， 或者$z(z^2 - z -2) = 0$。 因素$z^2 - z -2 = (z-2)(z+1)$, 给予$z=2$（丢弃$-1$和$0$）。 然后$2^3 + 1 = 9 = 3^2 = (2+1)^2$。 为了$x \ge 4$,$z^x > z^2 + 2z +1$为所有人$z \ge 1$。 因此，解决方案是$(z,x) = (2,3)$。 

等式（3），$z^x + 1 = (z+1)^y$，被考虑。 为了$x=1$,$z+1 = (z+1)^y$， 所以$y=1$; 一切积极$z$满足$(x,y) = (1,1)$,$z$随意的。 为了$x \ge 2$和$y \ge 2$，考虑增长。 为了$z \ge 2$,$z^x + 1 > z^x \ge 2^2 =4$; 右侧$(z+1)^y \ge 3^2 = 9$， 所以$x$和$y$一定很小。 为了$z=1$,$1^x + 1 = 2 = 2^y$, 给予$y=1$,$x$任意的，但是$x=1$恢复之前的解决方案。 为了$z=2$,$2^x + 1 = 3^y$。 这简化为方程(1)。 解决方案是$(x,y,z) = (1,1,z)$任意的，并且$(3,2,2)$从上一步开始。 没有其他小整数满足该方程。 

正整数解的完整列表如下。 对于方程（1）：$(x,y) = (1,1)$,$(3,2)$。 对于方程（2）：$(z,x) = (2,3)$。 对于方程（3）：$(x,y,z) = (1,1,z)$对于任意正数$z$， 和$(3,2,2)$。 

## 关键步骤验证

 对于方程(1)，模3分析确保不存在更大的奇数$x$作品。$2^5 +1 =33$,$3^3=27$,$3^4=81$; 差距越大$x$，确认没有其他解决方案。 对于方程（2），因式分解$z^3 - z^2 - 2z = z(z-2)(z+1)$正确识别$z=2$作为唯一的正解； 检查$x=4$,$z^4 > z^2 + 2z +1$为了$z \ge 1$。 对于方程（3），还原到先前的情况可以确保完整性； 没有其他小$z$和$(x,y)$对满足相等性，因为$z^x$增长速度快于$(z+1)^y$为了$x \ge 2$和$y \ge 3$。 

## 替代方法

 方程（1）可以使用加泰罗尼亚定理来处理，该定理断言，唯一的解决方案是$a^m - b^n = 1$以整数表示$a,b >0$,$m,n>1$是$3^2 -2^3=1$，立即给予$(x,y)=(3,2)$。 方程 (2) 也可以通过考虑函数来求解$f(z) = (z+1)^2 - z^x -1$并分析其导数$z \ge 1$，显示$f$严格递减$x \ge 4$，因此只有很小的$z$是候选人。 方程（3）可以通过有界类似地得到$(z+1)^y - z^x$并利用单调性； 小整数的直接枚举更简单，并且避免了更深层次的数论机制。
