 ## 问题

 求总和$$\frac{1}{2!}+\frac{2}{3!}+\ldots+\frac{n-1}{n!}$$（产品$1\cdot2\cdot\ldots\cdot k$表示为$k!$）。 

V·V·普罗伊兹沃洛夫

 ## 探索

 计算该序列的前几项以检测模式。 为了$n=2$，总和是$\frac{1}{2!} = \frac{1}{2}$。 为了$n=3$，总和是$\frac{1}{2!} + \frac{2}{3!} = \frac{1}{2} + \frac{2}{6} = \frac{1}{2} + \frac{1}{3} = \frac{5}{6}$。 为了$n=4$，总和是$\frac{1}{2!} + \frac{2}{3!} + \frac{3}{4!} = \frac{1}{2} + \frac{1}{3} + \frac{1}{8} = \frac{12}{24} + \frac{8}{24} + \frac{3}{24} = \frac{23}{24}$。 为了$n=5$，总和是$\frac{1}{2!} + \frac{2}{3!} + \frac{3}{4!} + \frac{4}{5!} = \frac{1}{2} + \frac{1}{3} + \frac{1}{8} + \frac{1}{30} = \frac{23}{24} + \frac{1}{30} = \frac{115/120 + 4/120} = \frac{119}{120}$。 

总和接近 1 作为$n$增加。 每一项都可以重写为$\frac{k}{k!} = \frac{1}{(k-1)!} - \frac{1}{k!}$，建议采用伸缩结构。 关键点是验证这种分解是否正确以及伸缩对于所有情况都严格有效$k$。 

## 问题理解

 我们被要求求总和$S_n = \frac{1}{2!} + \frac{2}{3!} + \cdots + \frac{n-1}{n!}.$这是一个 A 类问题，因为它要求求封闭形式的总和。 核心困难是确定每个术语的正确操作以揭示伸缩模式。 初步探索表明$\frac{k}{k!} = \frac{1}{(k-1)!} - \frac{1}{k!},$它产生一个伸缩总和，可以整齐地折叠成一个简单的表达式。 直观上，总和应该是$S_n = 1 - \frac{1}{n!},$因为差异模式只留下第一项和最后一项。 

## 证明架构

 引理 1：对于每个整数$k \ge 2$，平等$\frac{k}{k!} = \frac{1}{(k-1)!} - \frac{1}{k!}$成立。 这是真的，因为$\frac{1}{(k-1)!} - \frac{1}{k!} = \frac{k}{k \cdot (k-1)!} - \frac{1}{k!} = \frac{k-1}{k!}$并且需要我们仔细核实。 最困难的步骤是确认分解没有错误。 

引理 2：总和$\sum_{k=2}^n \left(\frac{1}{(k-1)!} - \frac{1}{k!}\right)$望远镜到$1 - \frac{1}{n!}$。 这是正确的，因为所有中间项都在连续的差分序列中抵消。 

主要权利要求：总和$S_n$等于$1 - \frac{1}{n!}$，通过结合引理 1 和 2。主要风险是未能正确处理伸缩中的第一项或最后一项。 

## 解决方案

 我们首先证明引理1。对于任何整数$k \ge 2$，我们计算：$\frac{1}{(k-1)!} - \frac{1}{k!} = \frac{k}{k \cdot (k-1)!} - \frac{1}{k!} = \frac{k - 1}{k!}.$仔细地进行乘法和化简，$\frac{k}{k!} = \frac{k}{k \cdot (k-1)!} = \frac{1}{(k-1)!},$所以$\frac{1}{(k-1)!} - \frac{1}{k!} = \frac{1}{(k-1)!} - \frac{1}{k \cdot (k-1)!} = \frac{k-1}{k \cdot (k-1)!} = \frac{k-1}{k!}.$这证实了分解是正确的$k \ge 2$。 

将引理 1 应用于每一项$S_n$，我们得到$S_n = \sum_{k=2}^n \frac{k-1}{k!} = \sum_{k=2}^n \left(\frac{1}{(k-1)!} - \frac{1}{k!}\right).$重新索引总和的第一部分，让$j = k-1$， 然后$\sum_{k=2}^n \frac{1}{(k-1)!} = \sum_{j=1}^{n-1} \frac{1}{j!}$。 所以，$S_n = \sum_{j=1}^{n-1} \frac{1}{j!} - \sum_{k=2}^n \frac{1}{k!}.$结合这两个和，我们注意到除了第一个和的第一项之外，所有项都被取消，$\frac{1}{1!} = 1$，以及第二个总和的最后一项，$-\frac{1}{n!}$。 因此，$S_n = 1 - \frac{1}{n!}.$这样就完成了证明。 ∎

 ## 关键步骤验证

 仔细重新检查引理 1。 为了$k=2$,$\frac{2}{2!} = 1$和$\frac{1}{1!} - \frac{1}{2!} = 1 - \frac{1}{2} = \frac{1}{2}$。 有一个误判。 重新计算：$\frac{1}{(k-1)!} - \frac{1}{k!} = \frac{1}{1!} - \frac{1}{2!} = 1 - \frac{1}{2} = \frac{1}{2},$哪个匹配$\frac{k-1}{k!} = \frac{1}{2!} = \frac{1}{2}$。 因此公式应该是$\frac{k-1}{k!} = \frac{1}{(k-1)!} - \frac{1}{k!}$。 这是正确的分解。 

重新检查伸缩总和$n=4$:$\frac{1}{2!} + \frac{2}{3!} + \frac{3}{4!} = \frac{1}{2} + \frac{1}{3} + \frac{1}{8} = \frac{23}{24}$。 使用公式$1 - \frac{1}{4!} = 1 - \frac{1}{24} = \frac{23}{24}$。 已验证。 

## 替代方法

 另一种方法是注意$\frac{k-1}{k!} = \frac{1}{(k-1)!} - \frac{1}{k!}$并直接写$S_n = \sum_{k=2}^n \frac{1}{(k-1)!} - \sum_{k=2}^n \frac{1}{k!} = \sum_{j=1}^{n-1} \frac{1}{j!} - \sum_{k=2}^n \frac{1}{k!} = 1 - \frac{1}{n!}$无需引入伸缩术语。 主要方法是更可取的，因为它清楚地解释了为什么中间项消失并突出了伸缩结构，使底层图案透明。
