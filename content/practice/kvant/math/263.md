 ## 问题

 两个数字$p$和$q$给出大于 1 的值。 侧面$BC$和$DC$矩形的$ABCD$, 点$P$和$Q$被选择以便$|BC| = p \cdot |BP|$和$|DC| = q \cdot |DQ|$。 各边长之比为多少$AB$和$AD$将角度$PAQ$实现其最大价值？ 在特定情况下这个最大价值是多少$p = 2$,$q = \dfrac{3}{2}$（图2）？

 ## 探索

 让矩形有坐标$$A=(0,0),\quad B=(a,0),\quad D=(0,b),\quad C=(a,b),$$在哪里$a=|AB|$和$b=|AD|$。 

自从$$|BC|=b=p\cdot |BP|,$$我们有$$|BP|=\frac b p,$$因此$$P=\left(a,\frac b p\right).$$相似地，$$|DC|=a=q\cdot |DQ|,$$所以$$|DQ|=\frac a q,$$因此$$Q=\left(\frac a q,b\right).$$要最大化的角度是向量之间的角度$$\overrightarrow{AP}=\left(a,\frac b p\right),\qquad \overrightarrow{AQ}=\left(\frac a q,b\right).$$介绍$$r=\frac ab>0.$$问题简化为最大化$\angle PAQ$作为一个函数$r$。 

角度的余弦是$$\cos\theta = \frac{\left(a,\frac b p\right)\cdot\left(\frac a q,b\right)} {\sqrt{a^2+\frac{b^2}{p^2}}\, \sqrt{\frac{a^2}{q^2}+b^2}}.$$将分子和分母除以$b^2$,$$\cos\theta = \frac{\frac{r^2}{q}+\frac1p} {\sqrt{r^2+\frac1{p^2}}\, \sqrt{\frac{r^2}{q^2}+1}}.$$自从$0<\theta<\pi/2$, 最大化$\theta$相当于最小化$\cos\theta$。 

该表达式建议使用柯西不等式。 的确，$$\frac{r^2}{q}+\frac1p = \left(r,\frac1p\right)\cdot \left(\frac r q,1\right).$$分母是这两个向量的长度的乘积。 因此$\cos\theta$正好是之间角度的余弦$$u=\left(r,\frac1p\right),\qquad v=\left(\frac r q,1\right).$$从而最大限度地减少$\cos\theta$意味着最大化之间的角度$u$和$v$。 

这些向量的斜率是$$m_u=\frac1{pr},\qquad m_v=\frac q r.$$它们的夹角等于$$\arctan\frac q r-\arctan\frac1{pr}.$$现在问题变成了一变量微积分。 差异化，$$\frac{d\theta}{dr} = -\frac q{r^2+q^2} + \frac p{p^2r^2+1}.$$将其设置为等于$0$,$$\frac p{p^2r^2+1} = \frac q{r^2+q^2}.$$这产生$$p(r^2+q^2)=q(p^2r^2+1),$$因此$$(p-p^2q)r^2=q-pq^2.$$保理，$$p(1-pq)r^2=q(1-pq).$$自从$p,q>1$,$pq\neq1$， 所以$$pr^2=q, \qquad r^2=\frac q p.$$这是一个自然的候选人。 检查导数表明它在那里从正变为负，因此角度最大。 

替代$r=\sqrt{q/p}$,$$\theta_{\max} = \arctan\sqrt{pq} - \arctan\frac1{\sqrt{pq}}.$$由于这两个论点是互逆且正向的，$$\theta_{\max} = 2\arctan\sqrt{pq}-\frac\pi2.$$为了$p=2$,$q=\frac32$,$$pq=3,$$所以$$\theta_{\max} = 2\arctan\sqrt3-\frac\pi2 = 2\cdot\frac\pi3-\frac\pi2 = \frac\pi6.$$## 问题理解

 长方形$ABCD$有边长$a=|AB|$和$b=|AD|$。 观点$P$位于$BC$以便$BP=\frac1p\,BC$，并点$Q$位于$DC$以便$DQ=\frac1q\,DC$。 比率$a:b$可能会有所不同。 

我们必须确定哪个比率$a:b$角度$\angle PAQ$尽可能大，然后计算最大角度$p=2$和$q=\frac32$。 

这是一个C 类问题。 需要优化的量是角度$\angle PAQ$。 

核心难点是用一种依赖于边比的形式来表达角度$a/b$可以分析。 决定性的观察是角度可以写成两个反正切函数的差。 

预期的答案是$$\frac{|AB|}{|AD|}=\sqrt{\frac q p},$$因为在这个比率下，导数中出现的两项完全平衡。 最大角度为$$2\arctan\sqrt{pq}-\frac{\pi}{2}.$$## 证明架构

 让$a=|AB|$,$b=|AD|$， 和$r=a/b$。 

第一个主张是$$P=\left(a,\frac b p\right),\qquad Q=\left(\frac a q,b\right)$$在合适的坐标系中； 这直接来自于定义条件$P$和$Q$。 

第二个主张是$$\angle PAQ = \arctan\frac q r-\arctan\frac1{pr};$$这是从解释得出的$\angle PAQ$作为两个向量之间的角度并计算它们的方向。 

第三个主张是$$\frac{d}{dr}\angle PAQ = -\frac q{r^2+q^2} +\frac p{p^2r^2+1};$$这是通过区分第二项权利要求的表达而获得的。 

第四个主张是唯一临界点满足$$r^2=\frac q p;$$这是通过求解通过将导数设置为零而获得的方程得出的。 

第五项主张是导数为正$$r<\sqrt{\frac q p}$$和负数$$r>\sqrt{\frac q p},$$所以临界点产生全局最大值。 

最困难的一步是证明临界点确实给出了全局最大值。 最有可能在审查中失败的引理是导数的符号分析。 

## 解决方案

 将矩形放置在坐标平面中，使得$$A=(0,0),\quad B=(a,0),\quad D=(0,b),\quad C=(a,b),$$在哪里$$a=|AB|,\qquad b=|AD|.$$自从$$|BC|=b=p\,|BP|,$$我们得到$$|BP|=\frac b p.$$因为$P$位于$BC$,$$P=\left(a,\frac b p\right).$$相似地，$$|DC|=a=q\,|DQ|,$$因此$$|DQ|=\frac a q,$$因此$$Q=\left(\frac a q,b\right).$$让$$r=\frac ab.$$向量$$\overrightarrow{AP} = \left(a,\frac b p\right), \qquad \overrightarrow{AQ} = \left(\frac a q,b\right)$$有斜坡$$\frac{b/p}{a}=\frac1{pr}, \qquad \frac{b}{a/q}=\frac q r.$$自从$p,q>1$，不等式$$\frac q r>\frac1{pr}$$对于每一个都成立$r>0$。 因此两个向量之间的角度等于它们的方向角之差：$$\theta=\angle PAQ = \arctan\frac q r-\arctan\frac1{pr}.$$区分于$r$:$$\theta'(r) = -\frac q{r^2+q^2} +\frac p{p^2r^2+1}.$$临界点满足$$-\frac q{r^2+q^2} +\frac p{p^2r^2+1}=0,$$或者$$p(r^2+q^2)=q(p^2r^2+1).$$重新整理后，$$p(1-pq)r^2=q(1-pq).$$因为$p,q>1$，我们有$pq>1$， 所以$1-pq\neq0$。 因此$$pr^2=q,$$那是，$$r^2=\frac q p.$$要确定导数的符号，请写$$\theta'(r) = \frac{p(r^2+q^2)-q(p^2r^2+1)} {(r^2+q^2)(p^2r^2+1)}.$$分母为正。 分子等于$$p(1-pq)r^2+q(pq-1) = (pq-1)(q-pr^2).$$自从$pq-1>0$,$$\operatorname{sgn}\theta'(r) = \operatorname{sgn}(q-pr^2).$$所以$$\theta'(r)>0 \quad\text{for}\quad r<\sqrt{\frac q p},$$和$$\theta'(r)<0 \quad\text{for}\quad r>\sqrt{\frac q p}.$$功能$\theta(r)$增加到$$r=\sqrt{\frac q p}$$并随后减少。 因此，当$$\frac{|AB|}{|AD|} = \sqrt{\frac q p}.$$在此值下，$$\frac q r=\sqrt{pq}, \qquad \frac1{pr}=\frac1{\sqrt{pq}}.$$因此$$\theta_{\max} = \arctan\sqrt{pq} - \arctan\frac1{\sqrt{pq}}.$$对于积极的$x$,$$\arctan x+\arctan\frac1x=\frac\pi2.$$将此应用与$x=\sqrt{pq}$,$$\theta_{\max} = 2\arctan\sqrt{pq}-\frac\pi2.$$为了$$p=2,\qquad q=\frac32,$$我们有$$pq=3,$$所以$$\theta_{\max} = 2\arctan\sqrt3-\frac\pi2 = 2\cdot\frac\pi3-\frac\pi2 = \frac\pi6.$$因此$$\boxed{\frac{|AB|}{|AD|}=\sqrt{\frac q p}}$$和$$\boxed{\max\angle PAQ = 2\arctan\sqrt{pq}-\frac\pi2}.$$在具体情况下$p=2$,$q=\frac32$,$$\boxed{\max\angle PAQ=\frac\pi6},$$与平等时$$\boxed{\frac{|AB|}{|AD|}=\sqrt{\frac34}=\frac{\sqrt3}{2}}.$$## 关键步骤验证

 第一个微妙的步骤是公式$$\theta = \arctan\frac q r-\arctan\frac1{pr}.$$方向角为$\overrightarrow{AP}$是$\arctan\!\left(\frac1{pr}\right)$，而方向角$\overrightarrow{AQ}$是$\arctan\!\left(\frac q r\right)$。 自从$q>1$，第二个斜率大于第一个：$$\frac q r-\frac1{pr} = \frac{pq-1}{pr}>0.$$因此，光线之间的角度恰好是这些方向角的差。 忘记验证这种不等式可能会产生错误的符号。 

第二个微妙的步骤是求解临界点方程。 从$$p(r^2+q^2)=q(p^2r^2+1)$$一个获得$$p(1-pq)r^2=q(1-pq).$$因素$1-pq$仅在检查其非零后才能取消。 自从$p,q>1$,$pq>1$，所以取消是合法的并且产生$$r^2=\frac q p.$$第三个微妙的步骤是证明极大性。 将导数重写为$$\theta'(r) = \frac{(pq-1)(q-pr^2)} {(r^2+q^2)(p^2r^2+1)}$$表明它的符号仅由$q-pr^2$。 这在临界点之前给出了正号，在临界点之后给出了负号，从而建立了全局最大值而不仅仅是驻点。 

## 替代方法

 纯粹的几何方法从恒等式开始$$\tan\angle PAQ = \frac{\tan\alpha-\tan\beta} {1+\tan\alpha\tan\beta},$$在哪里$$\alpha=\arctan\frac q r,\qquad \beta=\arctan\frac1{pr}.$$替换给出$$\tan\angle PAQ = \frac{pq-1}{pqr+r^{-1}}.$$自从$pq-1$是常数，最大化角度相当于最大化其切线，因此最小化$$pqr+\frac1r.$$算术几何平均不等式得出$$pqr+\frac1r \ge 2\sqrt{pq},$$恰好当$$pqr=\frac1r,$$那是，$$r^2=\frac q p.$$该方法避免了微分，通过单一不等式达到最优。 坐标和微积分方法是优选的，因为它还直接产生最大角度的值并使单调性完全透明。
