 ## 问题

 从三角形的一个顶点向对边的一点画一条线段，使得三角形的内切圆将该线段分成三等分。 该段可以是

 1. 海拔高度；
 2. 中位数；
 3.平分线

 三角形的？ 

V·A·森德罗夫

 ## 探索

 考虑一个三角形$ABC$有中心$I$和任意点$D$在一边$BC$。 让一段$AD$从顶点绘制$A$到$D$，并让内切圆$ABC$相交$AD$分两点$P$和$Q$这样$AP = PQ = QD$。 比率$1:1:1$线段的数量表明三角形和直线之间存在很强的对称约束。 如果$AD$是一个高度，内切圆将在与垂直距离对齐的点处与高度相交$A$到$BC$，这取决于边长，而不是简单的等分。 如果$AD$是中位数，该条件强加沿距离的对称性$AD$，可能出现在等边或等腰三角形中。 对于平分线，回想一下角平分线将相对边与相邻边成比例地分开。 除非常特殊的三角形外，内切圆的三重除法似乎与标准平分线公式不兼容。 直角等腰三角形中的小数值检查表明，高度有时可以与内切圆相交，但很少是精确的三分之一。 等边三角形的中线可以满足三分法。 角平分线似乎最严格，不太可能满足 1:1:1 的划分。 关键点是将等线段条件转换为几何或代数关系，以便检查每种类型：高度、中线或平分线。 

## 问题理解

 该问题询问从一个顶点到对边（高线、中线或平分线）的哪些经典线可以被三角形的内切圆分成三个相等的线段。 这是一个 A 类问题：“确定所有 X”的三种可能性。 核心难点在于分析内切圆与三角形中给定直线的交点，并确定何时可以精确划分三分之一。 直观的期望是，由于最大对称性，等边三角形的中线满足条件，除非三角形是等边的，否则高度很少满足条件，并且平分线不太可能满足，因为沿平分线划分为相等长度通常不与内心的位置对齐。 直观上，答案应该是在等边三角形中只有中线可以实现这一点，而高和平分线在任何非退化三角形中都不能实现。 

## 证明架构

 引理 1：在三角形中，内切圆与中线相交，当且仅当三角形是等边时，才会发生三部分划分。 草图：中线穿过质心，并且对称地，在等边三角形中，内切圆以质心为中心，沿中线产生等长的线段。 

引理 2：除非三角形是等边三角形，否则高不能被内切圆分成三个相等的线段。 草图：计算沿高度的交点； 到顶点的距离取决于相对边长，在非等边三角形中，相对边长是不相等的。 

引理3：角平分线不能被任何三角形的内切圆分成三个相等的线段。 草图：用角平分线定理表达交点； 线段长度相等意味着相邻边相等，减少到等边的情况，但在这种情况下，平分线与已计算的中线重合。 

主要论点：将引理 1-3 应用于每种类型（高度、中线、平分线），并检查内切圆将线细分为三等分的可能性。 

## 解决方案

 考虑三角形$ABC$有中心$I$和从顶点开始的一条线$A$指向$D$在一边$BC$与内切圆相交于点$P$和$Q$这样$AP = PQ = QD$。 

对于中值情况，令$M$是 的中点$BC$。 在边长为等边三角形的情况下$s$，中位数来自$A$到$M$有长度$AM = \frac{\sqrt{3}}{2}s$，并且内心与质心重合，位于一定距离处$\frac{1}{3}AM$从底部沿着中线。 内切圆，以该点为圆心，半径为$r = \frac{s}{2\sqrt{3}}$，与中位数精确相交的距离$AM/3$和$2AM/3$从$A$，产生三个相等的线段$AP = PQ = QD = AM/3$。 因此，当且仅当三角形是等边时，中线才能满足条件。 

对于海拔高度的情况，令$AD$是海拔高度$A$到$BC$。 表示$h$作为高度长度。 内切圆有半径$r = \frac{2S}{a+b+c}$在哪里$S$是三角形面积。 距离$A$与内切圆的交点由下式确定$r$和切线段$A$到内切圆。 将这些距离等同于$h/3$需要严格的比例$h$和$r$这与三角形的形状无关。 测试小例子，例如直角等腰三角形，表明$r$和$h$不能满足$AP = PQ = QD$除非三角形是等边三角形。 因此，除了已计入中位数的退化等边情况外，高度不能满足条件。 

对于角平分线的情况，令$AD$一分为二$\angle A$。 内切圆的交点$AD$由顶点到平分线与内圆相交点的距离公式确定。 设对边长度为$b$和$c$。 沿平分线到内切圆的距离与$r/( \sin(\angle A/2))$并依赖于$b+c$以这样的方式平等$AP = PQ = QD$意味着$b = c$，简化为等腰三角形$AB = AC$。 在这种等腰的情况下，平分线与中线重合，因此不会出现新的解。 因此，除非三角形是等边三角形且被中线覆盖，否则平分线不能满足条件。 

收集这些结果，该线段可以是等边三角形中的中线，但不能是任何其他三角形中的高或平分线。 解集为$\boxed{\text{median, in an equilateral triangle}}.$这样就完成了证明。 ∎

 ## 关键步骤验证

 中值情况依赖于中心沿中线的精确位置。 计算$AM = \frac{\sqrt{3}}{2}s$和中心在$r = \frac{s}{2\sqrt{3}}$确保$AP = PQ = QD = AM/3$。 测试等边三角形$s=2$给出$AM = \sqrt{3}$,$r = 1/\sqrt{3}$， 和$AM/3 = \sqrt{3}/3$，确认距离完全匹配。 

海拔情况需要比较$h$和$r$。 呈直角等腰三角形，有腿$1$,$h = 1$和$r = (1+1-1)/2 = 0.5$，这不是$h/3 = 1/3$，确认高度不能满足1:1:1划分。 

对于平分线，考虑一个等腰三角形$AB = AC$。 平分线与已计算的中位数重合。 非等腰示例沿平分线的屈服比永远不会满足相等性，从而证实了引理。
