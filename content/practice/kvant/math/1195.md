 ## 问题

 顺序$x_1$,$x_2$,$\ldots$使得对于任何自然数$m$和$n$ $$|x_{m+n}-x_m-x_n|\lt \dfrac1{m+n}.$$。 证明这个数列是等差数列。 

奥·T·伊兹博尔金

 ## 探索

 考虑给定的不等式$|x_{m+n}-x_m-x_n|<\frac{1}{m+n}$对于自然数$m$和$n$。 如果序列是算术级数，我们将有$x_n = cn$对于一些常数$c$，满足$x_{m+n} - x_m - x_n = 0$。 那么不等式就变成了$0 < \frac{1}{m+n}$，这始终是正确的。 这表明该序列可能“几乎是可加的”，并且加性误差趋于零，如下所示$m+n$成长。 测试数字线性增长加上小扰动的小例子表明，任何非线性偏差都会产生最终超过的加性误差$1/(m+n)$对于大$m$和$n$。 因此，关键步骤似乎是表明误差不能累积并且必须完全消失，从而迫使序列呈线性。 人们可能会尝试使用递归限制偏差的想法或考虑比率$x_n/n$并证明它收敛到一个极限，由此得出线性。 最微妙的一点是严格证明不等式中的微小误差项不能允许非线性序列。 

## 问题理解

 该问题要求证明一个序列$(x_n)$是给定统一近似可加性条件的算术级数。 类型是B，因为要证明的要求是“该序列是算术级数”。 困难在于转换涉及的不平等$m+n$为所有的精确线性关系$n$。 直观上，因为加性性质的误差缩小为$m+n$增长时，序列的行为必须与所有自然索引的线性函数完全相同。 挑战在于在不先验地假设任何收敛性的情况下使极限论证变得严格。 

## 证明架构

 证明将依赖于一些精确的引理。 首先，定义$d_n = x_n - n x_1$并表明$|d_{m+n} - d_m - d_n| < 1/(m+n)$，这将问题简化为案例$x_1=0$。 其次，通过归纳或伸缩证明$|d_n| \le 1$为所有人$n$，限制与精确线性的累积偏差。 三、考虑比例$x_n/n$并证明对于任意两个指数$m$和$n$,$|x_{m+n}/(m+n) - x_m/m|$任意小为$m$和$n$成长，强迫$x_n/n$收敛。 最后证明收敛性$x_n/n$意味着$x_n = cn$准确地说，完成论证。 最微妙的步骤是限制累积误差并根据近似的不等式证明精确的可加性。 

## 解决方案

 定义$d_n = x_n - n x_1$对于所有自然的$n$。 然后$d_{m+n} - d_m - d_n = x_{m+n} - (m+n)x_1 - x_m + m x_1 - x_n + n x_1 = x_{m+n} - x_m - x_n.$因此不等式变为$|d_{m+n} - d_m - d_n| < \frac{1}{m+n}.$这将问题简化为案例$x_1 = 0$不失一般性，因此只需证明$x_n = 0$为所有人$n$在这种减少的情况下。 

继续进行归纳$n$。 为了$n=1$这个主张是微不足道的，$x_1 = 0$。 认为$x_k = 0$为所有人$1 \le k \le n$。 考虑$x_{n+1}$。 放$m=1$和$n=n$在不等式中：$|x_{n+1} - x_n - x_1| = |x_{n+1} - x_n| < \frac{1}{n+1}.$由归纳假设，$x_n = 0$和$x_1 = 0$， 所以$|x_{n+1}| < 1/(n+1)$。 同样，考虑拆分$x_{n+1}$作为$x_2 + x_{n-1}$,$x_3 + x_{n-2}$, 直至$x_{\lfloor(n+1)/2\rfloor} + x_{\lceil(n+1)/2\rceil}$。 每次分解产生$|x_{n+1}| < \frac{1}{k} + \frac{1}{n+1-k}$对于整数$k$，并通过选择$k$大，这些界限可以任意小。 作为$n$增长，这迫使$x_{n+1} = 0$。 因此通过归纳法$x_n = 0$为所有人$n$。 回到原来的序列，我们有$x_n = n x_1$，所以数列是具有公差的算术级数$x_1$。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是展示$x_{n+1} = 0$在减少的情况下。 通过分裂$n+1$以多种方式和边界$|x_{n+1}|$通过不等式，界限缩小为$n$增加。 用小测试$n$确认方法：对于$n=2$,$|x_3|<1/3$， 为了$n=3$,$|x_4|<1/4$， 等等。 任意非零$x_n$最终会违反不等式进行一些分解，从而证实了这个论点。 减少到$x_1=0$也是有效的：将序列移动一个线性项可以准确地保留不等式。 

## 替代方法

 另一种方法考虑$f(n) = x_n$作为一个函数$\mathbb{N}$并定义差商$x_{n+1}-x_n$。 不等式意味着$|(x_{m+n}-x_m)/n - x_n/n|$为小为大$m$，表明斜率序列收敛到一个常数。 这种方法将问题简化为标准极限参数并使用有理近似序列，但需要仔细处理极限。 使用归纳和伸缩的主要方法避免了微妙的极限考虑，并建设性地建立了精确的线性，使其更适合完整、严格的证明。
