 ## 问题

 给出了无限的数字序列。 证明对于任意自然数$n$，与 10 互质，可以在序列中找到一组连续的数字，使得这些数字形成的数字可以整除$n$。 

V·A·乌夫纳洛夫斯基

 ## 探索

 设无限序列的数字为$a_1,a_2,a_3,\dots$，其中每个$a_i \in {0,1,\dots,9}$。 位置上的连续数字块$i$到$j$代表数字$$N_{i,j} = a_i 10^{j-i} + a_{i+1} 10^{j-i-1} + \cdots + a_j.$$目标是证明对于每个自然数$n$和$\gcd(n,10)=1$, 存在$i \le j$这样$N_{i,j} \equiv 0 \pmod n$。 

直接尝试使用普通前缀和会失败，因为块表达式不是前缀的简单差异； 的权力$10$取决于块的长度。 关键的障碍是，除非我们补偿移位，否则串联不会以固定模数相加。 

自从$\gcd(n,10)=1$，残基类别$10$模数$n$是可逆的，这表明引入 的幂的模逆$10$。 这个想法是通过删除数字的位置权重来标准化每个前缀数字。 

定义前缀号码$$B_k = a_1 10^{k-1} + a_2 10^{k-2} + \cdots + a_k.$$然后是一个块$N_{i,j}$可以用以下方式表示$B_j$和$B_{i-1}$，但缩放因子涉及$10^{j-i+1}$。 的可逆性$10$模数$n$建议乘以$10^{-k}$模数$n$可能会将其转换为伸缩结构。 

关键的一步是找到将数字连接转换为简单差异的残基序列。 

## 问题理解

 这是一个 A 类问题：我们必须证明对于每个自然数$n$互质与$10$，每个无限数字序列都包含一个连续的块，其数值可被整除$n$。 

核心困难在于，由于位置权重，块所表示的数字在数字上不是线性的。 关键思想应该利用以下事实：$10$是可逆模数$n$，使我们能够标准化数字位置的移位，以便串联与模减法兼容。 

我们的目标是构造一个仅取有限多个值的残差序列，以便两个相等的值产生一个零残差块。 

预期结果是$$\boxed{\text{every such sequence contains a block divisible by } n}.$$## 证明架构

 定义前缀值$B_k = \sum_{i=1}^k a_i 10^{k-i}$。 

定义标准化残基$C_k \equiv B_k \cdot 10^{-k} \pmod n$， 在哪里$10^{-1}$存在模数$n$因为$\gcd(n,10)=1$。 

证明$C_j - C_{i-1} \equiv 0 \pmod n$当且仅当块$a_i \dots a_j$形成一个可被整除的数字$n$。 

将鸽巢原理应用于序列$C_0,C_1,\dots$在$\mathbb{Z}/n\mathbb{Z}$获得指数$i<j$具有相同的残留量。 

最难的点是验证块可分性和归一化前缀残基的相等性之间的等价性。 

## 解决方案

 让$a_1,a_2,a_3,\dots$是给定的无限数字序列。 对于每个$k \ge 1$,定义前缀号码$$B_k = \sum_{t=1}^k a_t 10^{k-t},$$并设置$B_0=0$。 

自从$\gcd(n,10)=1$，存在一个整数$u$这样$10u \equiv 1 \pmod n$。 对于每个整数$k \ge 0$， 定义$10^{-k}$作为$u^k \pmod n$。 

定义$$C_k \equiv B_k \cdot 10^{-k} \pmod n.$$修复索引$0 \le i \le j$。 我们表达$B_j$按照$B_{i-1}$:$$B_j = B_{i-1} \cdot 10^{j-i+1} + \sum_{t=i}^j a_t 10^{j-t}.$$两边同时乘以$10^{-j}$在$\mathbb{Z}/n\mathbb{Z}$给出$$B_j 10^{-j} \equiv B_{i-1} 10^{-(i-1)} + \sum_{t=i}^j a_t 10^{-t}.$$因此$$C_j \equiv C_{i-1} + \sum_{t=i}^j a_t 10^{-t} \pmod n.$$最后一个同余乘以$10^j$产量$$C_j 10^j - C_{i-1} 10^j \equiv \sum_{t=i}^j a_t 10^{j-t} \pmod n.$$右边就是数字$N_{i,j}$。 所以$$N_{i,j} \equiv 0 \pmod n \quad \Longleftrightarrow \quad C_j 10^j \equiv C_{i-1} 10^j \pmod n.$$自从$10^j$是可逆模数$n$，这相当于$$C_j \equiv C_{i-1} \pmod n.$$这样就形成了一个块$a_i \dots a_j$产生的倍数$n$恰好当其中两个值$C_0,C_1,C_2,\dots$重合。 

残留物$C_k$位于一组尺寸中$n$，而无限序列$(C_k)_{k \ge 0}$包含无限多个项。 根据鸽巢原理，存在指数$0 \le i < j$这样$C_i \equiv C_j \pmod n$。 对应的块$a_{i+1}\dots a_j$满足$N_{i+1,j} \equiv 0 \pmod n$。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 最微妙的一点是块可分性和归一化残基相等性之间的等价性。 构建依赖于身份$$B_j = B_{i-1} 10^{j-i+1} + \sum_{t=i}^j a_t 10^{j-t},$$接下来直接在位置分割前缀和$i-1$和因式分解的权力$10$。 

第二个微妙点是权力划分的合法性$10$模数$n$。 这是有效的，因为$\gcd(10,n)=1$， 所以$10$在残差环中是可逆的，因此所有幂$10^k$也是可逆的。 

最后，鸽笼论证仅取决于残差类模的有限性$n$，不在数字的任何结构上，确保重复$C_k$是不可避免的。 

## 替代方法

 一种替代方法避免显式标准化，而是考虑对$(B_k,10^k)$作为有限模块的元素$\mathbb{Z}/n\mathbb{Z}$，然后在由数字串联引起的半直接结构中应用线性相关参数。 该方法将块编码为仿射动作中的差异。 

另一种方法使用自动机理论：前缀残差集在数字输入下形成有限确定性自动机，任何无限输入单词都会引发一个循环，该循环对应于产生可分割块的零权重循环。 上面的归一化方法更直接，并且避免了模逆和鸽巢原理之外的形式机制。
