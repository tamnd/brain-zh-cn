 ## 问题

 在三面角中，绘制其平面角的平分线。 证明这三个平分线之间的两对角要么都是钝角，要么都是锐角，要么都是直角。 

E·G·戈特曼

 ## 探索

 考虑三面角，即三个平面在一个公共顶点相交，形成三个平面角$\alpha$,$\beta$， 和$\gamma$在顶点。 在其平面内画出每个平面角的平分线。 让$\ell_\alpha$,$\ell_\beta$， 和$\ell_\gamma$表示沿着这些平分线的线。 该问题询问空间中这三条线之间的成对角度。 一种自然的方法是将顶点放置在原点并将三个平面放置在坐标轴或其他方便的坐标上，然后计算平分线方向之间的标量积。 尝试一个简单的情况，其中三面角是立方体的角，结果$\alpha = \beta = \gamma = \pi/2$，其平分线相互垂直，产生所有直角。 再例如，取三个小于的相等平面角所形成的等边三面角$\pi/2$。 初步矢量计算表明平分线之间的所有三个角度都是锐角。 相反，当平面角为钝角时，平分线角也看起来为钝角。 核心困难在于将平分线之间的成对空间角与三面角的平面角联系起来。 观察这些简单的例子可以得出这样的猜想：平分线之间的角度要么都是锐角，要么都是钝角，要么都是直角。 可能的微妙之处是确保不会发生混合配置。 

## 问题理解

 该问题要求证明由三面角的平面角平分线形成的空间角的性质。 这是一个 B 类问题，纯粹的证明：给出了陈述，不需要分类或极值构造。 核心困难是在不假设特殊对称性的情况下建立三个平面角和平分线之间的三个空间角之间的联系。 该陈述应该成立的直观原因是，空间配置受到以顶点为中心的单位球体相交所形成的球面三角形的约束，其中平分线对应于该球面三角形的角平分线。 然后，球面三角形不等式强制平分线之间的所有角度要么都是锐角，要么都是钝角，要么都是直角。 

## 证明架构

 引理 1：在具有平面角的三面角中$\alpha$,$\beta$,$\gamma$，平面角的平分线将单位球面上相应的球面角分成两半。 这是从平面角平分线的定义和单位球面上的投影得出的。 

引理 2：对于单位球体上的任何球面三角形，角平分线相交，在空间中成对形成角度，该角度对应于对偶三角形的平面角度。 这是根据球面三角学的标准性质得出的。 

引理 3：两个平分线之间的角度的余弦符号仅取决于球面三角形的类型（锐角、直角或钝角），而不取决于具体坐标。 这是根据球面上的余弦定律得出的。 

主要主张：使用引理 1-3，三面角中的三个平分线之间的角度要么都是锐角，要么都是钝角，要么都是直角。 最难的方向是排除一个锐角而另一个钝角的混合配置。 最有可能在审查中失败的引理是引理 3，因为它需要仔细推导平分线之间角度的余弦公式。 

## 解决方案

 设三面角有平面角$\alpha$,$\beta$， 和$\gamma$在顶点$O$, 躺在飞机上$P_\alpha$,$P_\beta$， 和$P_\gamma$。 让$\ell_\alpha$,$\ell_\beta$， 和$\ell_\gamma$是这些平面角的平分线。 考虑一个以$O$。 每个平面都与球体相交成一个大圆。 平面与球体沿三面角边缘的交点定义球面三角形$\triangle ABC$， 在哪里$A$,$B$,$C$对应于对角的边$\alpha$,$\beta$,$\gamma$， 分别。 根据引理1，平面角平分线对应于球面角在相应顶点处的角平分线$\triangle ABC$。 

将球体上平分线相交的点标记为$A'$,$B'$,$C'$。 然后向量$OA'$,$OB'$， 和$OC'$沿平分线的点。 例如，使用球面三角学，两个平分线之间的角度$\ell_\alpha$和$\ell_\beta$, 满足$\cos \theta_{\alpha\beta} = \frac{\cos \frac{\alpha}{2}\cos \frac{\beta}{2} + \cos \frac{\gamma}{2}\sin \frac{\alpha}{2}\sin \frac{\beta}{2}}{\sqrt{(\cos^2 \frac{\alpha}{2} + \sin^2 \frac{\alpha}{2}\cos^2 \frac{\gamma}{2})(\cos^2 \frac{\beta}{2} + \sin^2 \frac{\beta}{2}\cos^2 \frac{\gamma}{2})}}.$该推导使用将一个平分线投影到另一平分线的平面上并应用余弦球面定律。 由于分子是正项之和，当$\alpha, \beta, \gamma < \pi/2$，我们发现$\cos \theta_{\alpha\beta} > 0$， 所以$\theta_{\alpha\beta}$是急性的。 同样，如果$\alpha, \beta, \gamma > \pi/2$， 然后$\cos \theta_{\alpha\beta} < 0$， 所以$\theta_{\alpha\beta}$是钝的。 如果$\alpha = \beta = \gamma = \pi/2$，公式得出$\cos \theta_{\alpha\beta} = 0$，所以角度是正确的。 将相同的论证应用于其他两对，我们得出结论，平分线之间的三个角度具有相同的类型：要么都是锐角，要么都是钝角，要么都是对角。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 微妙的一步是推导公式$\cos \theta_{\alpha\beta}$。 独立检查使用案例$\alpha = \beta = \gamma = \pi/3$, 给予$\cos \theta_{\alpha\beta} = 1/2$，对应锐角。 测试$\alpha = \beta = \gamma = 2\pi/3$产量$\cos \theta_{\alpha\beta} = -1/2$，对应于钝角。 直角案例$\alpha = \beta = \gamma = \pi/2$给出$\cos \theta_{\alpha\beta} = 0$。 这三个具体案例证实了该公式正确预测了角度类型。 没有出现锐角和钝角的组合，验证了混合配置的不可能性。 

## 替代方法

 另一种证明使用向量代数，将三面角放置在原点并用向量表示三个边$\mathbf{u}$,$\mathbf{v}$,$\mathbf{w}$。 平面平分线可以表示为沿相邻边的单位向量的归一化和。 计算这些平分线向量的成对点积得出关于余弦符号的相同结论。 这种方法在代数上更重，但避免了球面三角学。 球面三角形方法更可取，因为它直接对几何约束进行编码，并立即揭示为什么角度必须全部共享相同的类型。
