 ## 问题

 如果一组数字不能划分为两个非空组，使得一组中的数字之和与另一组中的数字之和的乘积为正，我们将其称为“幸运”。 老师在黑板上写下了几个整数。 证明学生可以在现有整数的基础上再添加一个整数，这样得到的结果就是幸运的。 

A·库兹涅佐夫

 全俄数学奥林匹克竞赛（LI，地区阶段）

 ## 探索

 设原整数为$a_1, a_2, \dots, a_n$并让$S = a_1 + a_2 + \cdots + a_n$。 我们可以添加一个整数$x$，形成集合${a_1,\dots,a_n,x}$。 

划分为两个非空组对应于选择一个非空真子集$A$的增广集。 如果我们表示$B$作为补集，集合不幸运的条件意味着存在$A$这样$\left(\sum_{a \in A} a\right)\left(\sum_{b \in B} b\right) > 0,$所以两个总和要么严格为正，要么严格为负。 

这建议控制添加后的总和$x$，因为对于任何子集$A$,$\sum_{b \in B} b = (S + x) - \sum_{a \in A} a.$如果总和被迫为$0$，那么每对互补和的形式为$T$和$-T$，其乘积始终为非正值。 这立即阻止了具有正积的分区的存在。 

因此自然的候选人是选择$x = -S$。 

一个潜在的问题是某些简并划分是否会违反条件，但如果总和为零，乘积结构将变得对称且始终为非正，因此不会出现矛盾。 

## 问题理解

 这是一个 D 类问题。 

给定一个任意的有限整数集。 我们必须证明，总是可以添加一个整数，以便结果集具有以下性质：划分为两个非空子集不会产生具有相同严格符号的两个子集和。 

关键思想是强制新集合的总和为零，这迫使每个分区产生相反符号或零和互补部分，消除任何正积的可能性。 

该构造预计将是原始数字之和的否定。 

## 证明架构

 首先，定义总和$S$原始设置并选择$x = -S$，确保增广总和等于零。 

其次，证明对于任意将增广集划分为两个非空子集，这两部分的和互为负数。 

第三，证明一个数与其负数的乘积是非正数，这排除了正数。 

第四，验证所有分区都被覆盖，包括那些分隔的分区$x$来自原始元素。 

最微妙的一点是确保在总和为零引起的对称性下考虑每个可能的分区。 

## 解决方案

 令给定的整数为$a_1, a_2, \dots, a_n$，并让$S = a_1 + a_2 + \cdots + a_n.$定义附加整数$x = -S.$添加后$x$，新集合中所有元素的总和等于$a_1 + \cdots + a_n + x = S - S = 0.$考虑将增广集任意划分为两个非空不相交子集$A$和$B$。 让$s_A = \sum_{a \in A} a, \quad s_B = \sum_{b \in B} b.$自从$A \cup B$是整个集合，我们有$s_A + s_B = 0,$因此$s_B = -s_A.$所以，$s_A s_B = s_A(-s_A) = -s_A^2 \le 0.$这表明，对于每个划分为两个非空组的情况，两个组之和的乘积永远不会为正。 因此，没有分区满足违反“幸运”属性所需的条件，并且结果集是幸运的。 

因此整数$x = -S$确保所需的属性。 

## 关键步骤验证

 关键身份$s_A + s_B = 0$直接从以下事实得出$A$和$B$形成总和为零的集合的划分； 每个元素对任一元素都贡献一次$s_A$或者$s_B$，所以它们的总和等于总和。 

符号条件完全简化为代数表达式$-s_A^2$，对于每个实数都是非正数$s_A$，包括案例$s_A = 0$，其中乘积为零并且仍然不违反所需的不等式。 

每个分区，包括隔离添加元素的分区$x$，被覆盖，因为推导不依赖于结构$A$，仅考虑分区的完整性。 

## 替代方法

 另一种观点是选择$x$以便它在绝对值上支配原始集合子集的所有部分和，迫使任何分区中的两个子集和之一改变符号。 这导致更复杂的边界参数和子集的案例分析。 

零总和结构更可取，因为它消除了所有案例区别并将问题简化为单一恒等式$s_B = -s_A$，使论证完全统一和代数。
