 ## 问题

 平面上有两点$A$和$B$被给予。 让$C$是一个等距的点$A$和$B$。 构建点序列$C_1=C$,$C_2$,$C_3$,$\ldots$,$C_n$,$C_{n+1}$,$\ldots$在哪里$C_{n+1}$是三角形的外心$AC_nB$。 对于点的哪个位置$C$1. 重点是$C_n$落在线段的中点$AB$（在这种情况下，$C_{n+1}$并且序列的后续成员未定义）？ 
2. 重点是$C_n$与$C$？ 

N. Chernov，十年级学生（克里沃罗格）

 ## 探索

 让点$A$和$B$固定在平面上，并让$C$位于线段的垂直平分线上$AB$，因为它必须满足$|AC| = |BC|$。 该序列是递归定义的：$C_1 = C$和$C_{n+1}$是三角形的外心$AC_nB$。 第一个问题询问的是$C$这样在某个步骤$n$,$C_n$恰好落在中点$M$的$AB$。 第二个问题询问序列变得静止的位置，$C_n = C$。 

考虑简单的几何配置。 配售$C$远离$AB$沿着垂直平分线似乎将外心“拉”近$AB$，表明收缩到$M$。 如果$C$位于垂直于$AB$在$M$， 然后$C_2$位于两者之间$C$和$M$。 这暗示该序列实际上是沿着这条垂直线的一维迭代。 关键的困难是以易于处理的形式描述迭代并确定其固定点和有限时间命中$M$。 

探索坐标模型可能会有所帮助。 地方$A=(-1,0)$,$B=(1,0)$， 然后$M=(0,0)$。 任何$C$等距于$A$和$B$有坐标$(0,h)$。 计算$C_2$，三角形的外心$A C_1 B$。 外心位于垂直平分线的交点处。 的垂直平分线$AB$是$x=0$， 所以$C_2$必须有$x=0$。 类似地，垂直平分线$A C_1$经过$((0 + -1)/2, (h + 0)/2) = (-0.5, h/2)$有坡度$-1/m$, 给予$C_2 = (0, h/2)$。 这表明每一步将距离减半$M$， 所以$C_n = (0, h/2^{,n-1})$。 这立即给出了两个问题的清晰模式：序列命中$M$在有限步中如果$h = 0$最初（然后$C_1 = M$），否则它接近$M$渐进地。 

## 问题理解

 该问题需要对位置进行分类$C$沿着垂直平分线$AB$关于递归外心序列。 这是A型：我们必须找到所有$C$满足有限时间命中或平稳性。 核心困难在于形式化几何递归并将其转化为可计算的序列。 直观上，垂直平分线将问题简化为一维收缩，使中点成为有限时间终止的唯一候选点和平稳性的唯一固定点。 

推测的答案是：对于第一个问题，$C = M$; 对于第二个，同样的$C = M$，因为任何其他点都严格指向$M$但永远不会在有限的步骤中达到它。 

## 证明架构

 引理 1. 如果$A=(-1,0)$,$B=(1,0)$,任意一点$C$等距于$A$和$B$有坐标$(0,h)$。 草图：这由等式得出$|AC| = |BC|$。 

引理 2. 如果$C_n = (0,h_n)$， 然后$C_{n+1} = (0,h_{n+1})$和$h_{n+1} = h_n/2$。 草图：三角形的外心$A C_n B$位于$x=0$是 的中点$C_n M$沿着垂直线。 

引理 3. 序列$h_n$收敛于$0$并点击$0$仅当在有限步中$h_1 = 0$。 素描：几何系列$h_n = h/2^{,n-1}$意味着$h_n \to 0$渐近除非$h=0$。 

最难的一步：证明沿着垂直平分线的迭代确实每次都会使距离减半。 验证必须仔细计算垂直平分线及其交点。 

## 解决方案

 地点$A=(-1,0)$和$B=(1,0)$; 那么中点是$M=(0,0)$。 任意一点$C$等距于$A$和$B$位于垂直平分线上$AB$，这是线$x=0$， 所以$C=(0,h)$对于一些实数$h$。 考虑顺序$C_1 = C$,$C_{n+1}$作为三角形的外心$A C_n B$。 

三角形的外心位于其各边垂直平分线的交点处。 的垂直平分线$AB$是$x=0$。 的垂直平分线$A C_n$经过 的 中点$A C_n$，即$(-1/2, h_n/2)$，并且有斜率$1$， 自从$A C_n$是垂直距离$h_n$和水平距离$1$，给出垂线的斜率$1$。 该垂直平分线的方程为$y - h_n/2 = 1(x + 1/2)$，所以在$x=0$，它给出$y = h_n/2 + 1/2$。 修正：仔细重新计算斜率。$A C_n$有坐标$A=(-1,0)$,$C_n=(0,h_n)$。 其斜率是$m = (h_n - 0)/(0 - (-1)) = h_n / 1 = h_n$。 垂直斜率为$-1/m = -1/h_n$。 中点是$(-1/2, h_n/2)$。 垂直平分线方程为$y - h_n/2 = -1/h_n (x + 1/2)$。 在$x=0$,$y = h_n/2 - 1/(2h_n)$。 等等，检查单位。 

更好：用代数的方式处理。 三角形的外心$(-1,0)$,$(1,0)$,$(0,h)$位于$(0, h/2)$：确实，垂直平分线$AB$是$x=0$。 的垂直平分线$A C$经过中点$(-0.5,h/2)$, 坡度$-1/h$， 线：$y - h/2 = -1/h (x + 0.5)$。 在$x=0$,$y - h/2 = -1/(2h)$？ 这在维度上是不一致的。 使用矢量方法。 

更好的方法：有底三角形$AB$水平和顶点$C=(0,h)$。 外心$O$有$x=0$通过对称性。 让$y = k$。 距离$O=(0,k)$到$A=(-1,0)$等于距离$C=(0,h)$。 计算：$(0+1)^2 + (k-0)^2 = (0-0)^2 + (k - h)^2$， 所以$1 + k^2 = (k - h)^2 = k^2 - 2 h k + h^2$， 因此$1 + k^2 = k^2 - 2 h k + h^2$， 所以$1 = -2 h k + h^2$， 所以$2 h k = h^2 -1$， 所以$k = (h^2 -1)/(2h)$。 

查看：$k = (h^2 -1)/(2h)$。 这给出了精确的迭代$h_{n+1} = (h_n^2 -1)/(2 h_n)$。 

中点有限时间命中$M=(0,0)$需要$h_n = 0$对于某些人来说$n$。 那么递归公式给出$0 = (h_{n-1}^2 -1)/(2 h_{n-1})$， 所以$h_{n-1}^2 -1 =0$， 所以$h_{n-1} = \pm 1$。 因此$C = (0,1)$或者$(0,-1)$导致$C_2 = M$。 

平稳性$C_{n+1} = C_n$需要$h = (h^2 -1)/(2h)$，求解$2h^2 = h^2 -1$， 所以$h^2 = -1$，不可能超过实数。 因此不存在非平凡不动点； 序列永远不会变得平稳，除非渐近于$M$。 

因此，对于第一部分，$C = (0,1)$或者$C=(0,-1)$产生$C_2 = M$并在那里终止。 对于第二部分，没有产生真正的点$C_n = C$为所有人$n$。
