 ## 问题

 1. 证明总和$$C_n^0-C_{n-1}^1\cdot\dfrac14+C_{n-2}^2\cdot\dfrac1{4^2}-\ldots+(-1)^i C_{n-i}^i\cdot\frac1{4^i}+\ldots$$ $\Big($对所有整数求和$i$,$0\le i\le\dfrac n2\Big)$等于$\dfrac{n+1}{2^n}$。 
2.证明如果$p$和$q$是不同的数字并且$p+q=1$，然后求和$$C_n^0-C_{n-1}^1pq+C_{n-2}^2p^2q^2-\ldots+(-1)^i C_{n-i}^i p^iq^i+\ldots,$$类似于前一个等于$\dfrac{p^{n+1}-q^{n+1}}{p-q}$对于任意的$n$。 

这里$C_n^k$是二项式系数，即$C_n^0=1$和$C_n^k=\dfrac{n(n-1)\ldots(n-k+1)}{1\cdot2\cdot\ldots\cdot k}$。 （数字$C_n^k$[“Kvant”今年第 2 期](//www.kvant.digital/issues/1973/2/vaguten-chisla_cnk_mnogochlenyi_posledovatelnosti-6d842221/) 中进行了讨论。）

 D·A·弗里德金

 ## 探索

 我们首先检查第一个和的小值$n$。 为了$n=1$，总和减少为$C_1^0 = 1$，并且所要求的公式给出$(1+1)/2^1 = 1$，匹配。 为了$n=2$，总和是$C_2^0 - C_1^1 \cdot \frac{1}{4} = 1 - \frac{1}{4} = \frac{3}{4}$，而公式给出$(2+1)/2^2 = 3/4$，确认同意。 为了$n=3$，总和是$C_3^0 - C_2^1 \cdot \frac{1}{4} + C_1^2 \cdot \frac{1}{16} = 1 - 2\cdot \frac{1}{4} + 0 = 1 - \frac{1}{2} = \frac{1}{2}$, 匹配$(3+1)/2^3 = 4/8 = 1/2$。 该模式表明公式是正确的，但这些检查本身并不能证明。 

交替的符号和因素$(1/4)^i$表示与展开式中的二项式系数的联系，例如$(1 - x)^n$，但指数发生了偏移，给出$C_{n-i}^i$。 总和类似于两个序列的卷积，这表明采用生成函数方法。 第二个总和通过替换概括了这一点$1/4$和$pq$并考虑到$p+q=1$，暗示一个更通用的公式，当$p=q=1/2$。 关键的一步是确定生成函数或递归函数$C_{n-i}^i$。 

## 问题理解

 第一个问题是要证明$$\sum_{i=0}^{\lfloor n/2\rfloor} (-1)^i C_{n-i}^i \frac{1}{4^i} = \frac{n+1}{2^n}.$$第二个问题是证明具有不同特征的广义版本$p$和$q$总结为$1$:$$\sum_{i=0}^{\lfloor n/2\rfloor} (-1)^i C_{n-i}^i (pq)^i = \frac{p^{n+1}-q^{n+1}}{p-q}.$$这两个问题都是 B 类问题。核心困难是将和识别为合适的生成函数展开式中的系数或递归关系的解。 关键的见解是$C_{n-i}^i$对避免相邻元素的子集进行计数，或者可以通过递归进行编码。 

## 证明架构

 引理 1 建立了一个递归式$S_n = \sum_{i=0}^{\lfloor n/2\rfloor} (-1)^i C_{n-i}^i x^i$作为$S_n = S_{n-1} - x S_{n-2}$。 接下来将总和分解为以下各项：$i=0$和$i>0$并重新索引。 

引理 2 解决了递归问题$S_n = S_{n-1} - x S_{n-2}$和$S_0=1$,$S_1=1$, 给予$S_n = \frac{\alpha^{n+1}-\beta^{n+1}}{\alpha-\beta}$， 在哪里$\alpha$和$\beta$是 的根$r^2 - r + x = 0$。 这是具有常数系数的二阶线性递推的标准。 

引理 3 应用引理 2$x=1/4$, 计算根$\alpha=1/2$,$\beta=1/2$，适当取极限，得到$S_n = (n+1)/2^n$。 

引理 4 应用引理 2$x=pq$和$\alpha=p$,$\beta=q$， 使用$p+q=1$，产生$S_n = (p^{n+1}-q^{n+1})/(p-q)$。 

最困难的一步是严格推导引理 1 并确保总和限制$i\le n/2$在复发中得到正确处理。 

## 解决方案

 定义$S_n(x) = \sum_{i=0}^{\lfloor n/2\rfloor} (-1)^i C_{n-i}^i x^i$。 目标是找到一个封闭的形式。 我们首先建立一个递归。 

为了$i\ge 1$，我们有$C_{n-i}^i = C_{n-1-(i-1)}^{i-1} + C_{n-2-(i-1)}^{i-1}$由帕斯卡恒等式应用于顶部索引。 乘以$(-1)^i x^i$并求和$i=1$到$\lfloor n/2\rfloor$，我们得到$$\sum_{i=1}^{\lfloor n/2\rfloor} (-1)^i C_{n-i}^i x^i = -x \sum_{i=0}^{\lfloor (n-2)/2\rfloor} (-1)^i C_{n-2-i}^i x^i + \sum_{i=0}^{\lfloor (n-1)/2\rfloor} (-1)^i C_{n-1-i}^i x^i - C_{n-1}^0 x^0.$$包括$i=0$学期$C_n^0 = 1$，这简化为$$S_n(x) = S_{n-1}(x) - x S_{n-2}(x).$$基本情况是$S_0(x) = 1$和$S_1(x) = 1$。 这证实了引理 1。 

该递推式的特征方程为$r^2 - r + x = 0$。 让$\alpha$和$\beta$是它的根源：$$\alpha = \frac{1 + \sqrt{1 - 4x}}{2}, \qquad \beta = \frac{1 - \sqrt{1 - 4x}}{2}.$$那么一般的解决办法就是$$S_n(x) = \frac{\alpha^{n+1} - \beta^{n+1}}{\alpha - \beta},$$满足初始条件$S_0 = (\alpha - \beta)/(\alpha - \beta) = 1$和$S_1 = (\alpha^2 - \beta^2)/(\alpha - \beta) = \alpha + \beta = 1$，证实引理 2。 

对于第一个总和，取$x = 1/4$。 然后$\alpha = \beta = 1/2$。 公式通过极限减少$$\frac{\alpha^{n+1} - \beta^{n+1}}{\alpha - \beta} \to (n+1) \alpha^n = \frac{n+1}{2^n},$$建立第一部分。 

对于第二个总和，取$x = pq$， 和$p+q = 1$。 然后$\alpha = p$,$\beta = q$, 给予$$S_n(pq) = \frac{p^{n+1} - q^{n+1}}{p - q},$$根据需要。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是递推式的推导$S_n = S_{n-1} - x S_{n-2}$。 要独立检查它，请考虑小$n$:$n=2$,$S_2 = C_2^0 - C_1^1 x = 1 - x$， 尽管$S_1 - x S_0 = 1 - x \cdot 1 = 1 - x$，匹配。 为了$n=3$,$S_3 = 1 - 2x + 0 = 1 - 2x$， 和$S_2 - x S_1 = (1 - x) - x\cdot 1 = 1 - 2x$，再次确认。 极限为$\alpha \to \beta$通过计算验证$(1/2)^{n+1} - (1/2)^{n+1} = 0$形式化并应用导数技巧：$(\alpha^{n+1}-\beta^{n+1})/(\alpha-\beta) \to (n+1) \alpha^n$，这给出了正确的因子。 

## 替代方法

 人们可以通过解释来尝试组合论证$C_{n-i}^i$作为计数选择的方式$i$一行中不相交的相邻位置对$n$对象并分配权重$(-1/4)^i$。 总结一切$i$导致同样的复发。 另一种方法使用生成函数：定义$F(t) = \sum_{n\ge0} S_n t^n$，这导致了一个有理函数$F(t) = 1/(1-t+xt^2)$; 将分母展开为部分分数即可恢复封闭形式。 递归方法更可取，因为它直接处理有限和并且自然地扩展到$p,q$概括。
