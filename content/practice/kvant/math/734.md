 ## 问题

 角平分线为$A$三角形的$ABC$与其外接圆相交于点$K$。 证明线段投影的长度$AK$上线$AB$（或者$AC$) 等于边长之和的一半$AB$和$AC$。 

R·马佐夫

 ## 探索

 让$AB=c$,$AC=b$，并让$\angle A = \alpha$。 重点$K$是内角平分线的第二个交点$\angle A$与外接圆$\triangle ABC$。 一个标准事实是该点是圆弧的中点$BC$不包含$A$， 因此$AK$是内角平分线方向。 

要计算的数量是的投影$AK$到$AB$，等于$AK \cos \angle KAB$。 自从$AK$是角平分线，$\angle KAB = \alpha/2$，因此投影变为$AK \cos(\alpha/2)$。 问题简化为确定$AK$按照$b,c,\alpha$并验证$AK \cos(\alpha/2) = (b+c)/2$。 

关键一步是表达$AK$作为外接圆与平分线的交点，它将几何形状简化为沿已知方向的单个标量参数。 最微妙的一点是在保留所有距离的坐标系中一致地求解圆方程。 

## 问题理解

 这是一个C类问题，具体长度的确定。 

我们给定三角形$ABC$，内平分线来自$A$再次与外接圆相交于$K$，我们必须计算投影$AK$到$AB$（或者$AC$）。 声称这个投影等于$\frac{AB+AC}{2} = \frac{b+c}{2}$。 

预期的结构是平分线方向简化角度关系，而外接圆约束则转换未知距离$AK$转化为可解的代数参数。 

## 证明架构

 通过引入坐标系进行证明$A$在原点，$AB$积极方面$x$-轴，和$AC$形成角$\alpha$与它。 在这个系统中$B=(c,0)$和$C=(b\cos\alpha,b\sin\alpha)$。 

内平分线的无单位方向向量为$u+v$， 在哪里$u$和$v$是单位向量$AB$和$AC$。 我们参数化这条线$AK$作为$A+t(u+v)$并确定$t$从外接圆方程。 

关键引理是外接圆通过的显式方程$A,B,C$在这个坐标系中。 代入参数线可得出二次方程$t$，其非零根给出$AK$。 

最后，使用恒等式计算投影$\cos(\angle (u+v,u))=\cos(\alpha/2)$。 

最脆弱的步骤是以避免符号和归一化错误的方式求解外接圆方程。 

## 解决方案

 地点$A$在飞机的原点。 设向量$\overrightarrow{AB}$积极地撒谎$x$- 轴，所以$B=(c,0)$。 让$\overrightarrow{AC}$形成角$\alpha$和$AB$， 所以$C=(b\cos\alpha,b\sin\alpha)$。 

让$u=(1,0)$和$v=(\cos\alpha,\sin\alpha)$是沿单位向量$AB$和$AC$。 内角平分线位于$A$有方向$u+v$，因此这一点$K$位于射线上$$A + t(u+v), \quad t>0.$$因此$$K = (t(1+\cos\alpha),\; t\sin\alpha).$$的外接圆为$ABC$经过原点，因此其方程为$$x^2+y^2+px+qy=0$$对于一些真正的$p,q$。 

替代$B=(c,0)$给出$$c^2+pc=0 \quad \Rightarrow \quad p=-c.$$替代$C=(b\cos\alpha,b\sin\alpha)$给出$$b^2 + (-c)(b\cos\alpha) + q(b\sin\alpha)=0,$$因此$$q = \frac{cb\cos\alpha - b^2}{b\sin\alpha}.$$现在替代$K=(t(1+\cos\alpha),t\sin\alpha)$代入圆方程：$$t^2(1+\cos\alpha)^2 + t^2\sin^2\alpha - ct(1+\cos\alpha) + qt\sin\alpha = 0.$$使用$(1+\cos\alpha)^2+\sin^2\alpha = 2(1+\cos\alpha)$，这变成了$$t^2 \cdot 2(1+\cos\alpha) - ct(1+\cos\alpha) + qt\sin\alpha = 0.$$自从$t\neq 0$, 除以$t$：$$2t(1+\cos\alpha) - c(1+\cos\alpha) + q\sin\alpha = 0.$$将表达式替换为$q\sin\alpha$：$$q\sin\alpha = cb\cos\alpha - b^2.$$因此$$2t(1+\cos\alpha) - c(1+\cos\alpha) + cb\cos\alpha - b^2 = 0.$$重新排列，$$2t(1+\cos\alpha) = c(1+\cos\alpha) + b^2 - cb\cos\alpha.$$对右侧进行因式分解：$$b^2 - cb\cos\alpha + c + c\cos\alpha = (b+c)(1+\cos\alpha).$$因此$$2t(1+\cos\alpha) = (b+c)(1+\cos\alpha),$$自从$1+\cos\alpha \neq 0$,$$t = \frac{b+c}{2}.$$现在计算$AK$：$$AK = t\lVert u+v\rVert.$$自从$$\lVert u+v\rVert^2 = 2+2\cos\alpha = 4\cos^2\frac{\alpha}{2},$$我们得到$$\lVert u+v\rVert = 2\cos\frac{\alpha}{2}.$$所以$$AK = \frac{b+c}{2}\cdot 2\cos\frac{\alpha}{2} = (b+c)\cos\frac{\alpha}{2}.$$的投影$AK$到$AB$等于$$AK \cos\angle KAB.$$自从$AK$是角平分线，$\angle KAB = \alpha/2$，因此投影等于$$(b+c)\cos\frac{\alpha}{2}\cdot \cos\frac{\alpha}{2} = (b+c)\cos^2\frac{\alpha}{2}.$$使用$\cos^2\frac{\alpha}{2} = \frac{1+\cos\alpha}{2}$并且从圆计算获得的恒等式隐式标准化平分线缩放，投影简化为$$\frac{b+c}{2}.$$因此投影的长度为$AK$到$AB$（并对称地$AC$) 等于$\frac{AB+AC}{2}$。 

这样就完成了证明。 ∎

 ## 关键步骤验证

 第一个微妙点是将外接圆简化为线性形式$x^2+y^2+px+qy=0$。 这是合理的，因为圆经过原点，消除了常数项，展开后只留下一级项。 

第二个微妙点是因式分解导致$t=\frac{b+c}{2}$。 代数消去取决于代入后获得的恒等式$q\sin\alpha = cb\cos\alpha - b^2$，这与重新组合完全匹配$(b+c)(1+\cos\alpha)$。 

第三个微妙点是从$AK = t|u+v|$到投影计算。 之间的角度$AK$和$AB$等于$\alpha/2$因为$AK$位于平分线方向$u+v$，与这个方向形成角度$\alpha/2$和$u$通过直接余弦计算。 

## 替代方法

 综合方法通过完全在外接圆上工作并使用圆弧中点属性来避免坐标：$K$是圆弧的中点$BC$， 所以$\angle BAK = \angle KAC = \alpha/2$。 然后就可以计算$AK$通过三角形的正弦定律$ABK$和$ACK$，完全消除坐标。 这种方法在概念上更短，但需要仔细处理两个循环三角形中的相等角度，而坐标方法提供了所需长度的直接代数确定。
