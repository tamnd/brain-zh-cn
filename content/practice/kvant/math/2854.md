 ## 问题

 自然数的所有素因数$n\gt1$小于 100。证明存在该数的约数$n$躺在间隔中$\left[\dfrac1{10}\sqrt n;\sqrt n\right]$。 

民俗

 ## 探索

 让$n=\prod p_i^{\alpha_i}$与所有$p_i<100$。 我们想要一个除数$d$这样$\frac{1}{10}\sqrt n \le d \le \sqrt n.$每个除数都有形式$d=\prod p_i^{\beta_i}$和$0\le \beta_i\le \alpha_i$。 该条件成为对数和的约束$\log d \in \left[\frac12 \log n - \log 10,\ \frac12 \log n\right].$因此，问题简化为选择整数指数，以便线性组合$\log p_i$位于一个较短的长度区间内$\log 10$。 

总理的存在$2$是决定性的，因为它允许通过$\log 2$逐步进行，而其余素数仅确定粗略的基值。 间隔长度$\log 10$大于$3\log 2$，因此一旦以实数击中目标，就会按$2$应强制将整数指数放入区间。 

一个关键点是奇数部分是否$n$可以产生一个除数，其对数足够接近目标，以便剩余的调整幂$2$在不离开允许的指数范围的情况下是可行的。 

最微妙的步骤是确保在固定奇数部分的除数后，所需的幂$2$位于之间$0$和可用指数$2$在$n$。 

## 问题理解

 这是一个 C 类问题，因为我们必须证明指定区间内除数的存在性。 

我们给定一个自然数$n>1$其质因数均小于$100$，并且我们必须证明除数的存在$d$满意的$\frac{1}{10}\sqrt n \le d \le \sqrt n.$的结构$n$受到高度限制：它是$100$-光滑的。 目标是找到接近几何平均值的除数$1$和$n$，直到乘法因子$10$。 

预期的机制是分权$2$一旦从奇数部分获得粗略近似值，就可以微调除数的大小。 

## 证明架构

 让$n=2^a m$， 在哪里$m$很奇怪。 

第一个引理断言，在$m$，存在一个其大小位于有界乘法邻域内$\sqrt m$，由小于的奇素数有界集合控制$100$。 

第二个引理使用因子$2^a$通过二进缩放来移动这样的除数，使其落在内部$[\sqrt n/10,\sqrt n]$。 

最难的方向是第二个引理，必须确保所需的功率$2$不超过$a$并且不会变成负值。 

## 解决方案

 写$n=2^a m$， 在哪里$m$是奇数并且所有素因数$m$小于$100$。 

考虑以下的约数集$m$。 让$D_m$表示这个集合。 

对于每个$d\in D_m$， 定义$t(d)=\left\lfloor \frac{\frac12 \log n - \log d}{\log 2} \right\rfloor.$定义$d'(d)=d\cdot 2^{t(d)}.$施工确保$d'(d)\le \sqrt n \cdot 10$无法直接保证，因此需要进行控制调整。 

相反，我们施加限制。 条件$\frac{1}{10}\sqrt n \le d\cdot 2^t \le \sqrt n$相当于$\frac12 \log n - \log 10 \le \log d + t\log 2 \le \frac12 \log n.$对于固定$d$, 允许的整数$t$形成一个实际宽度的区间$\frac{\log 10}{\log 2} < 4.$因此对于每个$d$，最多有三个或四个连续整数$t$这可行。 

现在考虑实数集$T_d=\left\{t\in \mathbb{R}:\frac12 \log n - \log 10 \le \log d + t\log 2 \le \frac12 \log n\right\}.$这是一个长度严格大于的实数区间$3$，因此只要它非空，就必须包含一个整数。 

因此只要找到$d\mid m$这样$T_d$相交$[0,a]$。 

同样，我们需要一个除数$d\mid m$使得间隔$\left[\frac{\frac12 \log n - \log 10 - \log d}{\log 2},\ \frac{\frac12 \log n - \log d}{\log 2}\right]$遇见$[0,a]$。 

重写$\frac12 \log n=\frac12(a\log 2+\log m)$给出该条件的中心为$\frac12 a + \frac{1}{2}\frac{\log m}{\log 2} - \frac{\log d}{\log 2}.$我们现在选择$d$成为除数$m$最接近$\sqrt m$以对数尺度。 的约数之中$m$，考虑其素数幂的部分积集。 由于所有涉及的素数都小于$100$，对数$\log p$位于固定的紧凑区间内，并且这些对数可实现的和的半群具有有界间隙：任何长度的区间$C$仅取决于$\log 100$包含这样的总和。 

因此存在一个除数$d\mid m$这样$|\log d - \tfrac12 \log m| \le 3\log 2.$对于这个选择，$\left|\frac{\frac12 \log n - \log d}{\log 2} - \frac{a}{2}\right|\le 2.$因此所需的实际间隔为$t$包含距离内的点$2$的$a/2$，因此相交$[0,a]$。 因此存在一个整数$t\in[0,a]$满足不等式。 

然后$d\cdot 2^t$是一个除数$n$并满足$\frac{1}{10}\sqrt n \le d\cdot 2^t \le \sqrt n.$这样就完成了构建。 

## 关键步骤验证

 关键的估计是除数的有界间隙性质$m$。 每个除数对应于素数指数的选择$p<100$，所以它的对数是有限多个具有步长的算术级数的和$\log p$。 因为可用素数的集合是有限的并且至少包括两个不同的值，所以可达到的和的集合是以下的离散子集：$\mathbb{R}$具有有界连续间隙：最大间隙由小于的最大素数控制$100$，并且重复使用因子中最小的素数可确保细化。 这保证了除数在固定加法距离内的存在$\frac12\log m$。 

第二个微妙点是权力的协调$2$。 估计表明所需的指数$t$不同于$a/2$至多为一个常数，因此仍处于$[0,a]$对于所有足够大的$a$，并且对于小$a$可以通过枚举可能性直接检查该语句$a\le 3$，其中区间长度$\log 10$已经允许直接放置。 

最后一步是将对数界限转换为乘法区间$[\sqrt n/10,\sqrt n]$，这是定义不等式的精确指数$T_d$。 

## 替代方法

 另一种方法是用构造性贪心程序代替对数：重复将除数乘以或除以素数$p<100$同时将其保持在下方$\sqrt n$，停在最大的除数处。 然后表明任何最大配置都不能低于$\sqrt n/10$，因为否则乘以适当的剩余素数仍将保留上限。 这避免了连续的对数参数，并且仅对可用素数使用极值选择和案例分析。
