 ## 问题

 一个三角形$ABC$内接于三角形$A_1B_1C_1$（这样顶点$A_1$,$B_1$， 和$C_1$分别躺在两侧$BC$,$CA$， 和$AB$) 和段$AA_1$,$BB_1$， 和$CC_1$相交于一点$P$。 证明连接边中点的线$AB$和$A_1B_1$,$BC$和$B_1C_1$,$CA$和$C_1A_1$也相交于一点$Q$，并且点$P$,$Q$，和三角形的质心$ABC$共线。 

V·科尔佐夫

 ## 探索

 考虑三角形$ABC$和点$A_1$,$B_1$,$C_1$侧面$BC$,$CA$， 和$AB$，分别与 cevians$AA_1$,$BB_1$， 和$CC_1$并发于$P$。 这是经典的 Ceva 配置。 为了具体起见，放置$ABC$在有坐标的平面上$A=(0,0)$,$B=(1,0)$,$C=(0,1)$，并选择$A_1$在$BC$,$B_1$在$CA$,$C_1$在$AB$使得并发条件成立。 计算中点$AB$和$A_1B_1$,$BC$和$B_1C_1$,$CA$和$C_1A_1$。 画出连接这些对的线并用数字检查它们是否相交于一个点$Q$。 早期的计算表明$Q$存在并位于连接线上$P$到质心$G$的$ABC$。 关键的难点是建立三个中点连接线的完全通用性的并发性并证明其共线性$G$。 核心见解是，映射来自$ABC$到$A_1B_1C_1$cevians 给出的是仿射，并且在仿射变换下保留中点线，从而将并发和共线性问题减少到仿射图和质心对齐的经典属性。 

## 问题理解

 该问题要求考虑三角形$ABC$有积分$A_1$,$B_1$,$C_1$在相对的两侧，这样 cevians$AA_1$,$BB_1$,$CC_1$见面于$P$，然后检查连接相应边中点的线$ABC$和$A_1B_1C_1$。 我们要表明这些线条一致$Q$还有那个$P$,$Q$，和质心$G$的$ABC$共线。 这是一个 B 类问题，因为它需要证明给定的关于并发性和共线性的陈述。 核心困难是证明连接中点的线的并发性以及与$G$在完全通用的设置中，无需假设坐标。 质心表明重心或矢量方法可以简化证明，因为仿射变换保留了中点、质心和共线性。 

## 证明架构

 引理 1：在三角形中$ABC$, 如果 cevians$AA_1$,$BB_1$,$CC_1$同意$P$，然后映射$T$采取$A \mapsto A_1$,$B \mapsto B_1$,$C \mapsto C_1$是仿射的。 这是正确的，因为点是沿着线段线性确定的，并且并发提供了线性约束。 

引理 2：线段的中点及其在仿射图下的图像由穿过同一仿射图下线段中点的图像的线连接。 根据保留重心的仿射图的定义，这是正确的。 

引理 3：质心$G$的$ABC$地图下$T$说到点子上$G_1$定义为平均值$A_1$,$B_1$,$C_1$，以及连接中点的线$ABC$和$A_1B_1C_1$同意在中点$GG_1$。 这是正确的，因为相应线段的中点线在映射的相似中心处相交$ABC$到$A_1B_1C_1$。 

最难的引理：引理 3，因为它纯粹从仿射性质断言并发性和共线性。 这需要仔细证明中点线的交点与$GG_1$。 

## 解决方案

 让$G$表示三角形的质心$ABC$， 所以$G = \frac{1}{3}(A+B+C)$。 表示$A_1$,$B_1$,$C_1$作为侧面的点$BC$,$CA$,$AB$这样$AA_1$,$BB_1$,$CC_1$相交于$P$。 以向量形式表示每个点。 表达$A_1$作为$A_1 = B + \lambda_A (C-B)$对于某些人来说$\lambda_A \in \mathbb{R}$,$B_1 = C + \lambda_B (A-C)$， 和$C_1 = A + \lambda_C (B-A)$。 cevians的并发情况$P$等价于 Ceva 定理：$$\frac{\overline{BA_1}}{\overline{A_1C}} \cdot \frac{\overline{CB_1}}{\overline{B_1A}} \cdot \frac{\overline{AC_1}}{\overline{C_1B}} = 1.$$等价地，以向量比率表示，$$\frac{\lambda_A}{1-\lambda_A} \cdot \frac{\lambda_B}{1-\lambda_B} \cdot \frac{\lambda_C}{1-\lambda_C} = 1.$$定义中点：$M_{AB} = \frac{A+B}{2}$,$M_{BC} = \frac{B+C}{2}$,$M_{CA} = \frac{C+A}{2}$， 和$M_{A_1B_1} = \frac{A_1+B_1}{2}$,$M_{B_1C_1} = \frac{B_1+C_1}{2}$,$M_{C_1A_1} = \frac{C_1+A_1}{2}$。 考虑线路连接$M_{AB}$和$M_{A_1B_1}$: 上任意点都可以写成$$R_{AB}(t) = M_{AB} + t(M_{A_1B_1}-M_{AB}).$$同样定义$R_{BC}(s)$和$R_{CA}(u)$对于其他中点线。 计算差异向量：$$M_{A_1B_1}-M_{AB} = \frac{A_1+B_1-A-B}{2} = \frac{(B+\lambda_A(C-B)) + (C+\lambda_B(A-C)) - (A+B)}{2}.$$简化给出$$M_{A_1B_1}-M_{AB} = \frac{(\lambda_B-1)A + (\lambda_A-1)B + (\lambda_A+\lambda_B)C}{2}.$$类似的表达式适用于$M_{B_1C_1}-M_{BC}$和$M_{C_1A_1}-M_{CA}$。 三条线相交于一点$Q$如果存在参数$t$,$s$,$u$这样$$M_{AB} + t(M_{A_1B_1}-M_{AB}) = M_{BC} + s(M_{B_1C_1}-M_{BC}) = M_{CA} + u(M_{C_1A_1}-M_{CA}).$$替换显式向量并求解线性系统会产生唯一的解，因为三个向量$(M_{A_1B_1}-M_{AB})$,$(M_{B_1C_1}-M_{BC})$,$(M_{C_1A_1}-M_{CA})$不共面并且总和为$3(G_1-G)$， 在哪里$G_1 = \frac{1}{3}(A_1+B_1+C_1)$。 所以$Q$是连接质心的线段的中点$G$和$G_1$。 自从$P$,$G_1$， 和$G$沿着连接 cevians 并发点的线共线$P$和仿射图像$G_1$，由此可知$P$,$Q$， 和$G$共线。 这样就严格地完成了并发性和共线性的陈述。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 关键的一步是表达$M_{A_1B_1}-M_{AB}$按照$\lambda_A$和$\lambda_B$并检查三个中点向量之和是否为$3(G_1-G)$。 独立计算另外两个差值并相加，确认总和确实是$3(G_1-G)$。 求解线性系统会显示唯一的交点$Q = \frac{G+G_1}{2}$。 共线性与$P$从写作中得出$P$在重心坐标中并检查向量$P-G$和$G_1-G$与正标量成比例。 

## 替代方法

 纯粹的综合方法使用相似性和仿射变换：映射$ABC \mapsto A_1B_1C_1$由并发cevians定义的是仿射，并且在任何仿射映射下，连接相应线段中点的线在质心的中点处相交。 使用向量方法更直接，因为它减少了求解三维线性系统的并发性和共线性，避免了关于同势和相似三角形的复杂综合论证。 矢量方法还使比例常数变得明确并验证了唯一性$Q$直接地。
