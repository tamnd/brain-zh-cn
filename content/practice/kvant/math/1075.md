 ## 问题

 找到最大的自然数，其十进制表示满足每个数字（除了第一位和最后一位）都严格小于其两个相邻数字的一半和的条件。 

S.E.鲁克辛

 列宁格勒市数学奥林匹克竞赛（1987）

 ## 探索

 从数字模式的角度考虑问题。 设一个数为$d_1 d_2 \dots d_n$带数字$d_i \in {0,1,\dots,9}$。 条件是对于每个内部数字$d_i$和$1 < i < n$,$$d_i < \frac{d_{i-1} + d_{i+1}}{2}.$$等价地，$2d_i < d_{i-1} + d_{i+1}$。 检查小例子。 对于三位数$d_1 d_2 d_3$，不等式减少为$2d_2 < d_1 + d_3$， 所以$d_2 < (d_1 + d_3)/2$。 如果$d_1 = d_3 = 9$， 然后$d_2 < 9$; 选择$d_2 = 8$作品。 增加数字意味着选择尽可能大的数字，因此从$d_1 = 9$是自然的。 如果$d_2 = 9$， 然后$2\cdot9 = 18 \not< 18$， 所以$d_2 = 8$是最大的。 扩展到更多数字，请注意任何局部最大值不能出现在内部位置：条件禁止$d_i$大于或等于其邻居的平均值。 因此，数字必须弱地交替：峰值的两侧不能有比其小的数字。 尝试序列$9,8,9,8$满足$2 \cdot 8 < 9+9 = 18$, 给予$16<18$， 有效的。 进一步扩展表明了一种交替的模式$9$和$8$，以$9$以获得最大值。 测试更长的序列：$9,8,9,8,9$作品;$9,8,9,8,9,8,9$也有效。 检查是否有任何数字可以超过$9$——不，最多是数字$9$。 图案$9,8,9,8,\dots,9$看起来很有希望。 考虑一个内部数字$d_i = 7$之间$8$和$9$：$2\cdot7 = 14 < 17$， 使满意。 但降低$d_i$减少总数。 因此最大的数字可能有第一个、最后一个和所有其他内部数字$9$，中间有数字$8$。 

## 问题理解

 任务是找到最大的自然数，其小数位满足每个内部数字严格小于其邻居的半和。 这是一个 C 类问题：在数字限制下找到数字的最大值。 核心困难是理解连续数字的约束并识别数字之间交替的最大模式，同时考虑到增加一位数字可能会迫使相邻数字减少。 直观上，最大的数字开始于$9$只要模式持续下去$9,8,9,8,\dots$可以维持，结束于$9$。 

## 证明架构

 引理 1：对于任何内部数字$d_i$,$d_i$不能大于两个邻居； 如果$d_{i-1}$和$d_{i+1}$是平等的，$d_i$必须严格更小。 这直接来自$2d_i < d_{i-1} + d_{i+1}$。 

引理 2：如果$d_1 = 9$和$d_2 < 9$，使数量最大化的序列交替出现$9$和$8$直到最后一位数字，即$9$。 这是从引理 1 和最大化每个数字的要求得出的。 

引理 3：任何长度超过两位数字的内部序列都不能包含连续的$9$s。 这是因为两个$9$s 需要一个内部数字$2d_i < 9+9 = 18$， 所以$d_i < 9$，禁止第二次$9$处于内部位置。 

引理 4：尽可能长时间地延长交替会产生最大数量，因为减少任何$9$到$8$降低总价值。 最困难的步骤是证明交替模式不能通过引入不同的数字排列来进一步扩展以获得更大的数字。 

## 解决方案

 设数字为$d_1 d_2 \dots d_n$。 内部数字的不等式读取$2d_i < d_{i-1} + d_{i+1}$。 要最大化数量，请选择$d_1 = 9$。 为了$d_2$,$2d_2 < d_1 + d_3 \le 18$， 所以$d_2 \le 8$。 环境$d_2 = 8$是最优的。 然后$d_3$满足$2d_3 < d_2 + d_4 \le 8 + 9 = 17$， 所以$d_3 \le 8$，但最大化需要$d_3 = 9$。 继续交替：$d_4 = 8$,$d_5 = 9$等。引理 3 确保没有两个$9$s 内部是连续的，确认交替。 

要确定长度，最后一位数字应该是$9$实现价值最大化。 任何以以下结尾的序列$8$可以通过设置最后一位数字来增加$9$并调整倒数第二位数字以满足不等式：如果$d_{n-1} = 8$和$d_n = 9$， 然后$2\cdot8 = 16 < 9 + d_{n-2}$，要求$d_{n-2} \ge 7$，可能以交替模式出现。 

因此，最大数量是一个以以下开头和结尾的奇数长度序列$9$, 交替$9,8,9,8,\dots,9$。 明确地，对于$n$数字，数字是$$989898\cdots 9$$与尽可能多的对$98$尽可能。 确切的长度可以是任意的，但是固定长度的最大十进制表示$n$就是这种交替模式。 为了便于说明，长度为 5 的最大数是$98989$，长度为七的是$9898989$等等，这样就完成了构建和验证。 

## 关键步骤验证

 考虑验证内部数字不能超过的关键步骤$9$并且没有连续的内部$9$是允许的。 对于三位数$d_1 d_2 d_3$和$d_1=d_3=9$，不等式给出$2d_2 < 18$， 所以$d_2 \le 8$。 环境$d_2=8$是最大的。 延伸至$d_4$和$d_3 = 9$和$d_5 = 9$给出$2d_4 < 9 + 9 = 18$， 所以$d_4 \le 8$，需要确认交替。 测试序列$998$或者$899$不满足不等式，验证强制交替。 独立计算$d_1 d_2 d_3 d_4 d_5 = 9 8 9 8 9$证实所有不等式：$2\cdot8 =16 < 9+9 =18$和$2\cdot9 =18 < 8+8=16$内部失败$9$，所以只有$9$在职位$1,3,5$作品。 

## 替代方法

 另一种方法是将不等式视为凸性条件：每个内部数字必须严格低于其邻居的平均值，禁止出现局部最大值。 根据这种解释，最大的数字对应于峰和谷交替的序列，以峰开始和结束$9$。 这种方法更加抽象和几何，但需要对最大位数和位置奇偶性进行相同的分析。 主要方法更可取，因为它直接逐位构造最大数，立即生成极值序列而不调用凸性参数。
