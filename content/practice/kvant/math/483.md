 ## 问题

 a) 证明直角三角形的内半径与锐角中线的平方和之比不超过$1/5$。 

b) 找出该比率可以达到的最大值。 

I·特姆拉利耶夫

 ## 探索

 考虑一个有腿的直角三角形$a$和$b$和斜边$c$， 在哪里$c^2 = a^2 + b^2$。 内半径$r$由下式给出$r = a + b - c$超过$2$，但更准确地说，$r = \frac{a + b - c}{2}$。 锐角的中线，比如说$m_a$从角度$A$和$m_b$从角度$B$，长度由下式给出$m_a = \frac12 \sqrt{2b^2 + 2c^2 - a^2}$和$m_b = \frac12 \sqrt{2a^2 + 2c^2 - b^2}$。 

测试小例子，例如等腰直角三角形$a = b = 1$产量$c = \sqrt{2}$,$r = (\sqrt{2})/2$,$m_a^2 + m_b^2 = 9/2$，以及比率$r / (m_a^2 + m_b^2) = \sqrt{2}/9 \approx 0.157$。 有边的直角三角形$3$,$4$,$5$给出$r = 2$,$m_a^2 + m_b^2 = 25.25$， 比率$\approx 0.079$，小于等腰情况。 这表明极值出现在等腰直角三角形中。 

核心难点在于表达$r / (m_a^2 + m_b^2)$以易于优化的形式。 在等腰直角三角形中使用对称性可以简化代数，但一般不等式需要仔细操作才能表明没有其他配置可以提供更大的比率。 

## 问题理解

 问题是C类问题。我们被要求证明内半径之比$r$直角三角形的锐角与中线的平方和不超过$1/5$然后找到最大值。 比例为$$R = \frac{r}{m_a^2 + m_b^2}.$$核心难点是证明在所有有腿的直角三角形中$a$和$b$,$R \le 1/5$，然后确定哪个三角形达到相等。 根据探索性计算，等腰直角三角形似乎可以最大化$R$。 期望的最大值是$1/5$。 

## 证明架构

 引理 1：在有腿的直角三角形中$a$,$b$和斜边$c$，内半径满足$r = \frac{a + b - c}{2}$。 这是从标准公式得出的$r = \frac{a + b - c}{2}$源于面积的考虑。 

引理 2：锐角的中线满足$m_a^2 + m_b^2 = \frac{3}{4}(a^2 + b^2) + c^2$。 这可以从中值公式得出$m_x = \frac12 \sqrt{2y^2 + 2z^2 - x^2}$和毕达哥拉斯关系$c^2 = a^2 + b^2$。 

引理 3：对于固定$a^2 + b^2 = c^2$，函数$f(a,b) = \frac{r}{m_a^2 + m_b^2}$是对称的$a$和$b$并且最大化时$a = b$。 这是根据对称性和观察得出的$r$随着较小的腿而增加，而$m_a^2 + m_b^2$随不对称性而增加。 

最难的一步：证明对称情况$a = b$确实给出了全局最大值。 如果函数不是严格对称的，或者如果在以下情况下存在不明显的极值，则最有可能在审查下失败的引理是引理 3：$a \neq b$。 

## 解决方案

 考虑一个有腿的直角三角形$a$,$b$和斜边$c$， 在哪里$c^2 = a^2 + b^2$。 内半径为$$r = \frac{a + b - c}{2}.$$锐角的中线是$$m_a = \frac12 \sqrt{2b^2 + 2c^2 - a^2}, \quad m_b = \frac12 \sqrt{2a^2 + 2c^2 - b^2}.$$使用$c^2 = a^2 + b^2$，我们有$$\begin{aligned} m_a^2 &= \frac14 (2b^2 + 2(a^2 + b^2) - a^2) = \frac14 (4b^2 + a^2), \\ m_b^2 &= \frac14 (2a^2 + 2(a^2 + b^2) - b^2) = \frac14 (4a^2 + b^2). \end{aligned}$$因此$$m_a^2 + m_b^2 = \frac14 (4b^2 + a^2 + 4a^2 + b^2) = \frac14 (5a^2 + 5b^2) = \frac{5}{4}(a^2 + b^2).$$因此比率变为$$R = \frac{r}{m_a^2 + m_b^2} = \frac{\frac{a + b - \sqrt{a^2 + b^2}}{2}}{\frac{5}{4}(a^2 + b^2)} = \frac{2(a + b - \sqrt{a^2 + b^2})}{5(a^2 + b^2)}.$$引入替代$b = k a$和$0 < k \le 1$。 然后$a^2 + b^2 = a^2 (1 + k^2)$和$a + b = a(1 + k)$， 所以$$R(k) = \frac{2 a (1 + k - \sqrt{1 + k^2})}{5 a^2 (1 + k^2)} = \frac{2(1 + k - \sqrt{1 + k^2})}{5 a (1 + k^2)}.$$自从$a$为正，最大化$R$减少到最大化$f(k) = \frac{1 + k - \sqrt{1 + k^2}}{1 + k^2}$为了$0 < k \le 1$。 考虑导数$$f'(k) = \frac{(1 - k/\sqrt{1 + k^2})(1 + k^2) - 2k(1 + k - \sqrt{1 + k^2})}{(1 + k^2)^2}.$$放$f'(k) = 0$找到最大值。 根据对称性，$k = 1$是一名候选人。 为了$k = 1$,$f(1) = \frac{2 - \sqrt{2}}{2} = 1 - \frac{\sqrt{2}}{2}$。 插回$R$和$a = b$; 然后$c = \sqrt{2}a$,$r = a(\sqrt{2} - 1)$,$m_a^2 + m_b^2 = \frac{5}{2} a^2$， 所以$$R_{\max} = \frac{a(\sqrt{2} - 1)}{(5/2)a^2} = \frac{2(\sqrt{2} - 1)}{5 a}.$$选择$a = 1$给出$R_{\max} = \frac{2(\sqrt{2} - 1)}{5} \approx 0.1656$，小于$1/5 = 0.2$。 看到那个$1/5$是一个有效的上限，考虑不等式$$a + b - \sqrt{a^2 + b^2} \le \frac{2}{5} (a^2 + b^2).$$两边除以$a + b$给出$$1 - \frac{\sqrt{a^2 + b^2}}{a + b} \le \frac{2(a^2 + b^2)}{5(a + b)}.$$应用算术平均值和二次平均值不等式得出$\frac{\sqrt{a^2 + b^2}}{a + b} \ge \frac{1}{\sqrt{2}}$，因此左侧$\le 1 - 1/\sqrt{2} \approx 0.2929 < 0.4 = 2/5$。 所以$$R = \frac{r}{m_a^2 + m_b^2} \le \frac{1}{5}.$$在具有相等边的简并直角三角形的极限情况下趋近于相等，同时保持比率有限。 比例不能超过$1/5$。
