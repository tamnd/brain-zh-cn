 ## 问题

 给出一棵树（即没有循环的连通图）。 最初，它的每个顶点都包含一个芯片。 在移动时，选择一条边，并交换该边两端的两个筹码。 证明如果一个人（以某种顺序）为每个边执行一次移动，那么结果，筹码将相对于其初始位置在一个周期内移动（即，筹码可以编号为 1、2、...、$n$这样芯片 1 最终位于芯片 2 的初始位置，芯片 2 位于芯片 3 的初始位置，..., 芯片$n$在芯片 1) 的初始位置。 图 1 显示了一个示例$n=5$。

 ## 探索

 考虑一棵树$n$顶点，每个顶点最初包含一个芯片。 移动包括选择一条边并交换其端点处的筹码。 如果树的边以任意顺序仅使用一次，则芯片上的操作定义了顶点的排列。 目标是证明这个排列总是单一的$n$-cycle，意味着芯片相对于其初始位置循环移位。 

一种自然的方法是表示每条边${x,y}$作为转置$(x,y)$在对称群中$S_n$。 对于任意边序列$e_1, e_2, \dots, e_{n-1}$， 让$t_i$表示对应于的转置$e_i$。 那么筹码的排列结果是$\pi = t_{n-1} t_{n-2} \cdots t_1.$这将问题简化为表明与树相对应的边转置的任何乘积，无论以任何顺序，都是一个单一的$n$-循环。 

该策略是对顶点数量使用归纳法。 对于归纳步​​骤，移除叶顶点，将归纳假设应用于较小的树，然后将叶边缘的影响合并到现有循环中。 关键的代数事实是，通过置换共轭转置可以正确地将新顶点插入到循环中。 

## 问题理解

 让$T$是一棵有顶点集的树$V$和边缘集$E$。 标记顶点$1, 2, \dots, n$并关联每条边${x,y} \in E$随着转置$(x,y)$在$S_n$。 如果边缘按某种顺序使用$e_1, e_2, \dots, e_{n-1}$，得到的排列是$\pi = t_{n-1} t_{n-2} \cdots t_1,$在哪里$t_i$对应于$e_i$。 问题是要证明$\pi$是一个$n$-循环用于边缘的任何排序。 

## 证明架构

 证明通过顶点数归纳进行$n$。 基本情况$n=2$是立即的。 为了$n>2$，选择一个叶顶点$v$与独特的邻居$u$并考虑边缘$e_k = {u,v}$按给定的顺序。 去除$v$和$e_k$产生一棵树$T'$在$n-1$顶点。 产品中的每一次换位$\pi$要么涉及$v$恰好一次或仅作用于$T'$。 表示为$A$之后转置的乘积$e_k$并由$B$之前的产品$e_k$， 以便$\pi = A (u,v) B$。 自从$A$和$B$仅涉及以下顶点$T'$，他们修复$v$。 

定义$\sigma = BA$，这是所有边的乘积$T'$按某种顺序。 由归纳假设，$\sigma$是一个$(n-1)$-循环开启$T'$。 然后的目标是表明插入$v$通过转置$(u,v)$产生一个单一的$n$-循环。 正确的结合是$A(u\,v)A^{-1} = (A(u)\,v).$环境$w = A(u)$确保新顶点正确插入到循环中$T'$。 

## 解决方案

 让树的边缘以某种固定的顺序使用$e_1, e_2, \dots, e_{n-1}$。 关联每条边$e_i = {x,y}$随着转置$t_i = (x,y)$，因此得到的排列是$\pi = t_{n-1} t_{n-2} \cdots t_1.$我们通过归纳法证明$n$那$\pi$是一个$n$-循环。 

为了$n=2$，树由连接两个顶点的单边组成。 相应的转置交换这两个顶点，产生一个$2$-cycle，建立基本情况。 

假设该陈述对于所有树都成立$n-1$顶点。 让$T$成为一棵树$n$顶点。 选择一片叶子$v$与独特的邻居$u$并让$e_k = {u,v}$表示该边在序列中的位置。 编写产品用于$\pi$并分离出对应的因子$e_k$给出$\pi = A (u\,v) B,$在哪里$A = t_{n-1} \cdots t_{k+1}, \quad B = t_{k-1} \cdots t_1.$每一次换位$A$和$B$仅涉及以下顶点$T' = T \setminus {v}$从而修复$v$。 

定义$\sigma = BA.$的因素$\sigma$正是对应于边缘的转置$T'$，按照删除后从原始序列继承的顺序$e_k$。 由归纳假设，$\sigma$是一个$(n-1)$-循环开启$T'$。 

共轭$(u,v)$经过$A$给出$A (u\,v) A^{-1} = (A(u)\,v).$放$w = A(u)$，属于$T'$。 然后$\pi = A (u\,v) B = (A (u\,v) A^{-1}) (AB) = (w\,v) (AB).$而且，$AB$和$BA = \sigma$是共轭的，所以$AB$也是一个$(n-1)$-循环开启$T'$。 将此循环表示为$\rho = (w, a_2, a_3, \dots, a_{n-1}).$然后$(w\,v)\rho = (w, a_2, a_3, \dots, a_{n-1}, v).$的确，$w \mapsto a_2$,$a_2 \mapsto a_3$,$\dots$,$a_{n-1} \mapsto v$， 和$v \mapsto w$。 因此$(w,v)\rho$是一个包含所有$n$顶点。 所以$\pi$是一个$n$-循环。 这样就完成了归纳。 

## 关键步骤验证

 归纳不要求叶边缘出现在序列中的任何特殊位置。 无论顺序如何，隔离与叶相对应的转置都是有效的。 归纳假设适用于$T'$具有继承的顺序，可以是任意的。 共轭公式$A(u,v)A^{-1} = (A(u),v)$正确识别图像$u$在下面$A$，确保新的顶点$v$已正确插入$(n-1)$-周期$T'$。 这保证了最终的排列$\pi$是一个$n$-循环。 将循环乘以转置的群论推理是基本且完全合理的。 

## 替代方法

 可以用芯片轨迹来表述等效的论点。 移除一片叶子会使树减少到$T'$，其芯片形成$(n-1)$-循环。 沿着叶子边缘的交换将叶子的碎片插入到现有的循环中，产生一个$n$-循环。 这种基于轨迹的论证反映了排列论证，但需要动态跟踪芯片位置。 上面提出的代数证明分离了叶转置并将归纳法直接应用于排列，产生了简洁而严格的解决方案。 ∎
