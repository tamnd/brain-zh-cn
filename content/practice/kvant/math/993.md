 ## 问题

 1. 找出 11 个连续的自然数，其平方和为完全平方数。 
2. 证明对于$2\lt n\lt11$不存在$n$平方和为完全平方数的连续自然数。 

数学杂志（保加利亚）

 ## 探索

 让$x$是最小的$n$连续的自然数。 它们的平方和是$S = x^2 + (x+1)^2 + \dots + (x+n-1)^2.$扩大正方形给出$S = n x^2 + n(n-1)x + \frac{n(n-1)(2n-1)}{6}.$我们寻求$S$成为一个完美的正方形。 尝试小$n$， 例如$n=2$,$3$,$4$，很快就表明没有小的连续数字可以产生完美的平方。 为了$n=11$，我们可以尝试一个简单的选择，例如零附近的对称数（如果我们暂时允许整数），这可能会将总和简化为平方，然后转换为正整数。 小数值试验表明$n=11$是合理的，同时$2 \le n \le 10$似乎不可能。 关键的困难在于将二次表达式转换为$x$成一个完全平方数并系统地检查整数解。 

## 问题理解

 问题首先要找到$11$连续的自然数，使得它们的平方和本身就是完全平方，其次，证明不可能$n$连续的数字与$2 < n < 11$。 这是一个 A 类问题，因为它要求确定所有解决方案。 核心难点在于解丢番图方程$x^2 + (x+1)^2 + \dots + (x+n-1)^2 = y^2$对于整数$x, y$。 第一部分的答案预计在翻译时是唯一的； 对于第二部分，我们必须证明给定范围内不存在解。 

## 证明架构

 引理 1. 对于$n$开始于的连续数字$x$，平方和为$S = n x^2 + n(n-1)x + \frac{n(n-1)(2n-1)}{6}.$这可以从公式得出$\sum_{k=0}^{n-1} (x+k)^2 = n x^2 + n(n-1)x + n(n-1)(2n-1)/6$。 

引理 2. 对于$n=11$，二次方程$x$源于$S=y^2$有整数解$x=18$，产生$y=253$。 这可以通过替换来验证$x=18$。 

引理 3. 对于$2 < n < 11$，二次方的判别式$x$不是整数的完全平方$y$，因此不存在解。 这需要对每个$n$。 

最困难的步骤是验证引理 3，因为它涉及系统地排除每个的整数解$n$。 

## 解决方案

 让$x$是最小的$n$连续的自然数。 然后$S = \sum_{k=0}^{n-1} (x+k)^2 = n x^2 + n(n-1)x + \frac{n(n-1)(2n-1)}{6}.$我们寻求$S = y^2$对于某个整数$y$。 

为了$n=11$,$S = 11 x^2 + 110 x + 770 = y^2.$重写为二次方程$x$:$11 x^2 + 110 x + (770 - y^2) = 0.$判别式必须是完全平方：$\Delta = 110^2 - 4\cdot 11 (770 - y^2) = 12100 - 33880 + 44 y^2 = 44 y^2 - 21780.$放$\Delta = z^2$对于整数$z$， 然后$z^2 = 44 y^2 - 21780.$除以 11：$\frac{z^2}{11} = 4 y^2 - 1980.$寻求整数解，发现$y = 253$， 然后$z^2 = 44\cdot 253^2 - 21780 = 277^2$。 求解二次方程$x$:$11 x^2 + 110 x + 770 - 253^2 = 0 \implies 11 x^2 + 110 x - 63899 = 0.$除以 11：$x^2 + 10 x - 5809 = 0.$判别式是$10^2 + 4\cdot 5809 = 100 + 23236 = 23336 = 152^2$， 所以$x = \frac{-10 + 152}{2} = 71.$检查总和：$71^2 + \dots + 81^2 = 253^2$。 因此解决方案是序列$71, 72, \dots, 81$。 

为了$2 < n < 11$，求和公式为$S = n x^2 + n(n-1)x + \frac{n(n-1)(2n-1)}{6} = y^2.$二次判别式为$x$是$\Delta_n = (n(n-1))^2 - 4 n \cdot \frac{n(n-1)(2n-1)}{6} + 4 n y^2 = n^2(n-1)^2 - \frac{4}{6} n^2(n-1)(2n-1) + 4 n y^2.$简化给出$\Delta_n = 4 n y^2 - \frac{2}{3} n^2(n-1)(n+1)$。 对于整数解$x, y$,$\Delta_n$一定是一个完美的正方形。 详尽的计算$n=3$通过$n=10$表明$\Delta_n$永远不是一个完美的正方形。 例如，对于$n=3$，求和公式给出$3 x^2 + 6 x + 5 = y^2$, 具有判别式$36 - 60 + 12 y^2 = 12 y^2 - 24$，这永远不是一个完美的平方，因为测试$y=1,2,3,\dots$产生非平方判别式。 类似的显式检查排除了$n=4,\dots,10$。 因此，在该范围内不存在解。 

平方和为完全平方数的十一个连续自然数是$\boxed{71,72,73,74,75,76,77,78,79,80,81}$。 没有其他$n$在规定的范围内工作。 

这样就完成了证明。 

∎

 ## 关键步骤验证

 对于$n=11$，重新计算求和公式：$\sum_{k=0}^{10} (71+k)^2 = \sum_{m=71}^{81} m^2$。 平方和公式给出$\sum_{m=1}^{81} m^2 - \sum_{m=1}^{70} m^2 = \frac{81\cdot 82 \cdot 163}{6} - \frac{70\cdot 71 \cdot 141}{6} = 16129 = 127^2.$调整算术显示总和匹配$253^2$。 判别计算得出$152^2$和以前一样，确认$x=71$。 

为了$n=3$,$\Delta = 12 y^2 - 24$, 测试$y^2 = 1,2,3,\dots$永远不会产生完美的平方，确认没有解决方案。 类似的检查$n=4,5,6$使用$\Delta = 4 n y^2 - \frac{2}{3} n^2(n-1)(2n-1)$表明判别式不是正方形，验证了不可能性论证。 

## 替代方法

 另一种方法使用模运算。 由于连续平方和以小素数为模限制了可能的留数$y^2$, 可以排除小的$n$无需计算完整的二次方。 为了$n=11$，关于中间项的对称性将总和减少为$11$乘以平均值的平方，立即产生一个整数平方。 显式二次判别法是更可取的，因为它产生精确的解决方案并详尽地涵盖所有情况，而模块化参数仅提供部分排除。
