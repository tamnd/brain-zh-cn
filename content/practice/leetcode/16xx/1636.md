[LeetCode 问题 1636](https://leetcode.com/problems/sort-array-by-increasing-Frequency/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们根据每个值的频率对整数数组重新排序。 具体来说，频率较低的元素应该出现在频率较高的元素之前。 如果两个元素具有相同的频率，则**较大**的元素应该首先出现。 换句话说，排序是**主要通过增加频率**和**次要通过减少数值**。 

输入是一个数组`nums`包含范围内的整数`[-100, 100]`长度在 1 到 100 之间。输出是一个包含相同元素但根据上述规则排序的新数组。 

重要的边缘情况包括所有元素相同的数组（所有元素的频率相同）、存在负数的数组、具有单个元素的数组以及具有相同频率的多个元素的数组。 约束很小，因此即使是简单的排序解决方案也是可行的。 

## 方法

 强力方法需要手动计算每个元素的频率，为每个频率创建多个数组，然后以正确的顺序连接它们。 这可行，但涉及额外的簿记和不必要的复杂性。 

最佳解决方案的关键见解是使用**哈希映射**来计算每个元素的频率，然后在原始数组上使用**自定义排序**。 排序可以直接套用规则：按频率升序排序，按数值降序进行平局排序。 这是简单、高效的，并且利用内置的排序功能来实现清晰度和正确性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 手动计算频率，按频率分组，然后对组进行排序 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 使用哈希图进行频率计数，然后使用自定义比较器对数组进行排序 |

 ## 算法演练

 1. 初始化哈希图`freq`将每个数字的频率存储在`nums`。 循环通过`nums`并增加每个数字的计数。 这使我们能够知道每个数字出现了多少次。 
2. 排序`nums`使用自定义密钥。 关键是一个元组`(frequency, -value)`， 在哪里`frequency`是从获得`freq`。 负号确保当频率相等时较大的数字先出现。 
3. 返回排序后的数组。 

工作原理：首先根据频率比较每个元素，然后根据其值进行比较。 Python 和 Go 的排序是稳定的，这意味着具有相同键的元素会保留相对顺序，从而确保平局打破正常工作。 这保证了输出遵循两个排序条件。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def frequencySort(self, nums: List[int]) -> List[int]:
        freq = Counter(nums)
        return sorted(nums, key=lambda x: (freq[x], -x))
```Python 实现使用`Counter`有效地计算频率。 这`sorted`函数接受一个`key`函数，它提供了一个元组`(frequency, -value)`对于每个元素。 这可以一步处理主要和次要排序条件。 结果作为新的排序列表返回。 

## 解决方案```go
import "sort"

func frequencySort(nums []int) []int {
    freq := make(map[int]int)
    for _, num := range nums {
        freq[num]++
    }
    sort.Slice(nums, func(i, j int) bool {
        if freq[nums[i]] == freq[nums[j]] {
            return nums[i] > nums[j]
        }
        return freq[nums[i]] < freq[nums[j]]
    })
    return nums
}
```在 Go 中，我们使用映射来计算频率并`sort.Slice`对切​​片进行就地排序。 比较器功能首先检查频率； 如果频率相等，则首先返回值较大的元素。 该解决方案自然地处理空切片，因为 for 循环和`sort.Slice`在空输入上安全操作。

 ## 边缘情况

 一种边缘情况是**单元素数组**。 由于只有一个元素，因此频率和决胜逻辑不会更改数组，并且该函数必须正确返回它。 

第二种边缘情况是**所有元素都相同**。 频率排序将检测相等的频率，但由于所有值都相同，因此平局决断逻辑不会影响输出。 这确保了函数能够优雅地处理同构数组。 

第三种边缘情况涉及**负数和频率关系**。 使用时，负数会颠倒平局决胜逻辑中的顺序`-x`在 Python 中或`nums[i] > nums[j]`在围棋中。 当频率相等时，该实现正确地将较大的负数（更接近零）排序在较小的负数之前。
