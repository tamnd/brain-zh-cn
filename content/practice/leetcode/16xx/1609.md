 ## 问题理解

 该问题要求我们确定给定的二叉树是否满足**偶奇树**属性。 换句话说，我们需要根据树的级别验证两个主要条件：

 1. 对于**偶数索引级别**（0、2、4、...），所有节点值必须是**奇数**并且从左到右**严格递增**。 
2. 对于**奇数索引级别**（1、3、5、...），所有节点值必须是**偶数**并且从左到右**严格递减**。 

输入是`root`二叉树的结构，其中每个节点都有一个整数值。 输出是一个布尔值：`true`如果树满足条件，`false`否则。 

约束表明树可以非常大，最多可达`10^5`节点，值范围为`1`到`10^6`。 这表明任何解决方案都必须**节点数量呈线性**才能有效运行。 

重要的边缘情况包括：

 - 只有根节点的树。 对于级别 0，它必须具有奇数值。 
- 具有单个节点的级别，可以轻松满足增加/减少条件。 
- 连续节点违反严格递增或递减顺序的级别。 
- 节点奇偶校验不正确的级别（奇数级别上的奇数或偶数级别上的偶数）。 

该问题保证了一棵非空树，所以我们不需要处理`None`作为输入根。 

## 方法

 暴力方法很简单：逐层遍历树（使用 BFS）并检查每个级别的所有值是否满足奇偶校验条件和严格排序。 对于每个节点，我们需要将其值与同一级别上的所有其他节点进行比较。 虽然正确，但这种幼稚的方法效率低下，因为它可能涉及每个级别的重复比较。 

最佳方法利用**使用队列的级别顺序遍历。 在每个级别，我们按顺序检查每个节点：

 - 确保节点奇偶校验与级别匹配（偶数索引为奇数，奇数索引为偶数）。 
- 确保与同一级别的前一个节点相比，值严格增加或减少。 

这种方法非常高效，因为它只访问每个节点一次，并且只维护一个与当前级别宽度成比例的小队列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 将每个节点与级别中的所有节点进行比较，对于宽级别而言效率较低。 |
 | 最佳| O(n) | O(w) | 带队列的 BFS，其中 w 是任意级别的最大节点数。 一次性检查奇偶性和排序。 |

 ## 算法演练

 1. 以根节点初始化队列。 该队列将帮助执行**层序遍历** (BFS)。 
2. 设置变量`level`为 0 以跟踪当前级别索引。 
3. 当队列不为空时，按如下方式处理每一级：

 a. 记录当前层的节点数（`level_size`）。 

b. 初始化一个变量`prev_value`用于订购支票。 将其设置为`-inf`对于均匀水平和`+inf`对于奇数级别。 

c. 对于当前级别的每个节点：

 岛 检查奇偶性：如果电平是偶数，则值必须是奇数； 如果级别为奇数，则值必须为偶数。 如果没有，则返回`false`。 

二. 检查顺序：对于偶数级别，值必须大于`prev_value`; 对于奇数级别，值必须小于`prev_value`。 如果没有，则返回`false`。 

三. 更新`prev_value`为当前节点的值。 

四. 将节点的左子节点和右子节点放入队列（如果存在）。 
4. 增量`level`处理完当前级别的所有节点后。 
5. 如果所有级别都通过检查，则返回`true`。 

**为什么有效：**

 这种基于 BFS 的算法可确保按从左到右的顺序检查每个级别。 通过维护`prev_value`，我们保证严格订购。 通过检查每个级别的奇偶校验，我们强制执行奇偶属性。 由于 BFS 只访问每个节点一次，因此该算法可以有效地覆盖整个树。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def isEvenOddTree(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        
        queue = deque([root])
        level = 0
        
        while queue:
            level_size = len(queue)
            prev_value = float('-inf') if level % 2 == 0 else float('inf')
            
            for _ in range(level_size):
                node = queue.popleft()
                val = node.val
                
                # Check parity
                if level % 2 == 0 and val % 2 == 0:
                    return False
                if level % 2 == 1 and val % 2 == 1:
                    return False
                
                # Check order
                if level % 2 == 0 and val <= prev_value:
                    return False
                if level % 2 == 1 and val >= prev_value:
                    return False
                
                prev_value = val
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            level += 1
        
        return True
```该代码反映了该算法：我们使用队列执行 BFS，检查每个级别的奇偶校验和严格排序，并将子级传播到下一个级别的队列中。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isEvenOddTree(root *TreeNode) bool {
    if root == nil {
        return true
    }
    
    queue := []*TreeNode{root}
    level := 0
    
    for len(queue) > 0 {
        levelSize := len(queue)
        var prevVal int
        if level % 2 == 0 {
            prevVal = -1
        } else {
            prevVal = 1000001
        }
        
        nextQueue := []*TreeNode{}
        
        for i := 0; i < levelSize; i++ {
            node := queue[i]
            val := node.Val
            
            if level % 2 == 0 && val % 2 == 0 {
                return false
            }
            if level % 2 == 1 && val % 2 == 1 {
                return false
            }
            
            if level % 2 == 0 && val <= prevVal {
                return false
            }
            if level % 2 == 1 && val >= prevVal {
                return false
            }
            
            prevVal = val
            
            if node.Left != nil {
                nextQueue = append(nextQueue, node.Left)
            }
            if node.Right != nil {
                nextQueue = append(nextQueue, node.Right)
            }
        }
        
        queue = nextQueue
        level++
    }
    
    return true
}
```Go 特定注释：`nil`被用来代替`None`。 我们维护一个单独的切片`nextQueue`以避免迭代时切片的问题。`prevVal`使用节点值的约束进行初始化。
