[LeetCode 1643 题](https://leetcode.com/problems/kth-smallest-instructions/)

 **难度：** 🔴难
 **主题：** 数组、数学、动态规划、组合学

 ## 解决方案

 ## 问题理解

 这个问题要求我们从左上角开始为Bob生成一条特定的路径`(0, 0)`到目的地`(row, column)`在网格上。 鲍勃只能**向右**移动（`'H'`) 或 **向下** (`'V'`）。 任何遵循这些方向并到达目的地的移动序列都是有效的指令。 挑战是找到**字典顺序上最小的序列**。 这里的词典顺序与字典顺序相同，意思是`'H'`出现在之前`'V'`。 

输入是`destination`大批`[row, column]`和一个整数`k`。 输出是一个长度的字符串`row + column`恰好由`row` `'V'`移动和`column` `'H'`表示按字典顺序排列的第 k 个序列的移动。 

约束确保网格很小（`1 <= row, column <= 15`），使组合方法可行，并且`k`始终有效（`1 <= k <= nCr(row + column, row)`），这意味着不需要检查边界`k`。 边缘情况包括最小的网格`1x1`，只有一行或一列的网格，以及`k`等于`1`或最大序列数。 

主要挑战是生成所有序列并对它们进行排序不够高效。 相反，我们可以利用组合学**跳过序列的整个分支**并直接构建第 k 条路径。 

## 方法

 暴力方法使用回溯生成所有有效序列，将它们存储在列表中，对列表进行排序，然后返回第 k 个序列。 虽然正确，但这种方法对于大型网格来说太慢，因为序列的数量按组合方式增长`nCr(row + column, row)`。 对于一个`15x15`网格，有`155117520`序列，这是不可能生成的。 

最佳方法使用**组合学来指导第 k 个序列的构造**。 在每一步中，我们决定是否放置`'H'`或者`'V'`通过计算有多少个序列以`'H'`使用二项式系数。 如果`k`小于或等于以`'H'`，我们选择`'H'`; 否则，我们选择`'V'`并调整`k`通过减去跳过的序列。 这种方法在相对于路径长度的线性时间内构造答案，而不生成所有序列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(nCr(行+列, 行) * (行+列)) | O(nCr(行+列, 行) * (行+列)) | 生成所有序列并对它们进行排序 |
 | 最佳 | O(行 + 列) | O(1) | O(1) | 使用组合直接构造序列 |

 ## 算法演练

 1. 计算水平移动的总数（`H_count = column`）和垂直移动（`V_count = row`）。 路径的总长度是`H_count + V_count`。 
2.初始化一个空字符串`result`来构建序列。 
3. 当还有剩余步数时 (`H_count + V_count > 0`）：

 a. 如果有水平向左移动，计算以`'H'`使用公式`comb(H_count + V_count - 1, V_count)`。 

b. 比较`k`与这个数字。 如果`k`小于或等于，追加`'H'`到`result`并减少`H_count`。 

c. 否则，附加`'V'`到`result`, 递减`V_count`，并减去以`'H'`从`k`。 
4. 重复直到所有动作都用完。 返回构造的字符串。 

为什么有效：算法在每一步都会考虑字典顺序。 使用组合计数可以跳过以`'H'`什么时候`k`大于此计数，确保构造的序列恰好是字典顺序中的第 k 个。 

## Python 解决方案```python
from math import comb
from typing import List

class Solution:
    def kthSmallestPath(self, destination: List[int], k: int) -> str:
        row, column = destination
        result = []
        H_count, V_count = column, row
        
        while H_count > 0 or V_count > 0:
            if H_count > 0:
                # Number of sequences starting with 'H'
                count_H_first = comb(H_count + V_count - 1, V_count)
                if k <= count_H_first:
                    result.append('H')
                    H_count -= 1
                else:
                    result.append('V')
                    V_count -= 1
                    k -= count_H_first
            else:
                result.append('V')
                V_count -= 1
        return ''.join(result)
```该代码首先解压目标坐标。 它初始化水平和垂直移动的计数器，并迭代地选择下一步移动。 在每一步中，它都会计算有多少个序列以`'H'`。 如果`k`都在这个范围内，`'H'`被选中。 否则，`'V'`被选择，并且`k`通过删除跳过的序列来更新。 这一直持续到路径完全构建完成。 

## 解决方案```go
package main

import "math/big"

func comb(n, k int) int {
    result := big.NewInt(1)
    for i := 0; i < k; i++ {
        result.Mul(result, big.NewInt(int64(n-i)))
        result.Div(result, big.NewInt(int64(i+1)))
    }
    return int(result.Int64())
}

func kthSmallestPath(destination []int, k int) string {
    row, column := destination[0], destination[1]
    H_count, V_count := column, row
    result := make([]byte, 0, H_count+V_count)
    
    for H_count > 0 || V_count > 0 {
        if H_count > 0 {
            count_H_first := comb(H_count+V_count-1, V_count)
            if k <= count_H_first {
                result = append(result, 'H')
                H_count--
            } else {
                result = append(result, 'V')
                V_count--
                k -= count_H_first
            }
        } else {
            result = append(result, 'V')
            V_count--
        }
    }
    return string(result)
}
```在 Go 中，解决方案反映了 Python 方法。`big.Int`用于安全地计算组合数以避免整数溢出，尽管对于给定的约束，这并不是绝对必要的。 切片用于有效地构建结果。
