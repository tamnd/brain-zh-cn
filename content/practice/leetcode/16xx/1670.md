 **难度：** 🟡 中等
 **主题：** 数组、链表、设计、队列、双向链表、数据流

 ## 解决方案

 ## 问题理解

 问题是要求我们设计一个专门的队列，不仅允许在前面和后面插入和删除，还可以在队列的中间插入和删除。 我们需要维护队列，以便我们可以有效地访问和修改这三个位置的元素。 中间操作有点棘手，因为当队列有偶数个元素时，“中间”被定义为**两个中间位置中的最前面**。 

输入由一系列操作组成（`pushFront`,`pushMiddle`,`pushBack`,`popFront`,`popMiddle`,`popBack`）以及用于推送操作的整数值。 预期输出是 pop 操作的结果，返回`-1`如果队列为空。 约束表示最大操作数为 1000，值介于 1 和$10^9$。 这是一个适中的大小，允许线性时间操作，但为了清晰度和效率，优选最佳解决方案。 

重要的边缘情况包括队列为空时推入或弹出，确定中间元素时处理偶数与奇数长度队列，以及确保元素推到中间时的正确排序。 

## 方法

 暴力方法是将队列维护为简单的 Python 列表（或 Go 切片），并在指定索引处执行插入或删除。 为了`pushFront`或者`popFront`，我们将使用索引 0，对于`pushBack`或者`popBack`，我们将使用最后一个索引，对于中间操作，我们根据当前长度计算中间索引。 这工作正常，但是中间的列表插入和删除需要 O(n) 时间，如果队列变大，效率就会很低。 

最佳解决方案的关键是使用**两个平衡双端队列**来表示队列的前半部分和后半部分。 通过保持前半部和后半部的大小大致相等，我们可以在前部、中部和后部实现 O(1) 的压入和弹出操作。 每当出现不平衡（大小差异大于 1）时，我们就会重新平衡两半。 该方法使用**双端队列（deque）**数据结构，允许从两端高效插入和删除。

 | --- | --- | --- | --- |

 ## 算法演练

 1.初始化两个双端队列：`front`和`back`。 这`front`deque 将存储前半部分元素，并且`back`将存储后半部分。 
2. 对于`pushFront(val)`， 插入`val`在左端`front`然后重新平衡。 
3.为了`pushBack(val)`, 附加`val`在右端`back`然后重新平衡。 
4. 对于`pushMiddle(val)`， 如果`front`的元素多于`back`，移动最后一个元素`front`的左边`back`。 然后追加`val`到右端`front`。 
5. 对于`popFront()`，删除并返回最左边的元素`front`。 如果`front`为空，从中删除`back`。 然后重新平衡。 
6. 对于`popBack()`，删除并返回最右边的元素`back`。 如果`back`为空，从中删除`front`。 然后重新平衡。 
7. 对于`popMiddle()`， 如果`front`具有相同数量或多一个元素`back`, 从右侧删除`front`。 否则，从左侧删除`back`。 然后重新平衡。 
8.重新平衡确保之间的大小差异`front`和`back`通过根据需要将元素从一个双端队列移动到另一个双端队列，最多为 1。 

**为什么有效：** 通过将队列分成两半并保持大小不变​​，我们可以有效地访问中间元素，该元素始终位于队列的末尾`front`如果总大小是奇数或平衡的。 所有操作都会操作双端队列的任一端，这在 Python 中为 O(1)。 

## Python 解决方案```python
from collections import deque

class FrontMiddleBackQueue:

    def __init__(self):
        self.front = deque()
        self.back = deque()
        
    def _rebalance(self):
        while len(self.front) > len(self.back) + 1:
            self.back.appendleft(self.front.pop())
        while len(self.front) < len(self.back):
            self.front.append(self.back.popleft())

    def pushFront(self, val: int) -> None:
        self.front.appendleft(val)
        self._rebalance()

    def pushMiddle(self, val: int) -> None:
        if len(self.front) > len(self.back):
            self.back.appendleft(self.front.pop())
        self.front.append(val)

    def pushBack(self, val: int) -> None:
        self.back.append(val)
        self._rebalance()

    def popFront(self) -> int:
        if not self.front and not self.back:
            return -1
        if self.front:
            val = self.front.popleft()
        else:
            val = self.back.popleft()
        self._rebalance()
        return val

    def popMiddle(self) -> int:
        if not self.front and not self.back:
            return -1
        if len(self.front) >= len(self.back):
            val = self.front.pop()
        else:
            val = self.back.popleft()
        self._rebalance()
        return val

    def popBack(self) -> int:
        if not self.front and not self.back:
            return -1
        if self.back:
            val = self.back.pop()
        else:
            val = self.front.pop()
        self._rebalance()
        return val
```**实现说明：**`front`和`back`双端队列逻辑上分割队列。 这`_rebalance`方法确保`front`永远不会有超过一个元素`back`而且永远不会少。 推入和弹出操作始终操纵这些双端队列的末端，从而允许恒定时间操作。 

## 解决方案```go
package main

type FrontMiddleBackQueue struct {
    front []int
    back  []int
}

func Constructor() FrontMiddleBackQueue {
    return FrontMiddleBackQueue{
        front: []int{},
        back:  []int{},
    }
}

func (this *FrontMiddleBackQueue) rebalance() {
    for len(this.front) > len(this.back)+1 {
        this.back = append([]int{this.front[len(this.front)-1]}, this.back...)
        this.front = this.front[:len(this.front)-1]
    }
    for len(this.front) < len(this.back) {
        this.front = append(this.front, this.back[0])
        this.back = this.back[1:]
    }
}

func (this *FrontMiddleBackQueue) PushFront(val int) {
    this.front = append([]int{val}, this.front...)
    this.rebalance()
}

func (this *FrontMiddleBackQueue) PushMiddle(val int) {
    if len(this.front) > len(this.back) {
        this.back = append([]int{this.front[len(this.front)-1]}, this.back...)
        this.front = this.front[:len(this.front)-1]
    }
    this.front = append(this.front, val)
}

func (this *FrontMiddleBackQueue) PushBack(val int) {
    this.back = append(this.back, val)
    this.rebalance()
}

func (this *FrontMiddleBackQueue) PopFront() int {
    if len(this.front) == 0 && len(this.back) == 0 {
        return -1
    }
    var val int
    if len(this.front) > 0 {
        val = this.front[0]
        this.front = this.front[1:]
    } else {
        val = this.back[0]
        this.back = this.back[1:]
    }
    this.rebalance()
    return val
}

func (this *FrontMiddleBackQueue) PopMiddle() int {
    if len(this.front) == 0 && len(this.back) == 0 {
        return -1
    }
    var val int
    if len(this.front) >= len(this.back) {
        val = this.front[len(this.front)-1]
        this.front = this.front[:len(this.front)-1]
    } else {
        val = this.back[0]
        this.back = this.back[1:]
    }
    this.rebalance()
    return val
}

func (this *FrontMiddleBackQueue) PopBack() int {
    if len(this.front) == 0 && len(this.back) == 0 {
        return -1
    }
    var val int
    if len(this.back) > 0 {
        val = this.back[len(this.back)-1]
        this.back = this.back[:len(this.back)-1]
    } else {
        val = this.front[len(this.front)-1]
        this.front = this.front[:len(this.front)-1]
    }
    this.rebalance()
    return val
}
```**Go 特定注释：** 由于 Go 切片没有高效的`popFront`，我们小心地使用切片操作。 我们在前面加上`append([]int{val}, slice...)`并切片以去除。 该逻辑在其他方面反映了基于 Python 双端队列的方法。
