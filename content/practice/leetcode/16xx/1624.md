[LeetCode 问题 1624](https://leetcode.com/problems/largest-substring- Between-two-equal-characters/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定字符串中**两个相同字符**之间的最长子字符串的长度`s`。 子字符串不包含两个相同的字符本身。 如果没有字符至少出现两次，我们必须返回`-1`。 

换句话说，我们正在字符串中寻找成对的相同字符，并严格测量它们之间**的字符数。 然后我们返回找到的最大长度。 该字符串仅包含小写英文字母，长度范围为 1 到 300，因此我们正在处理适合简单的基于哈希的方法的小规模输入。 

重要的边缘情况包括具有所有唯一字符的字符串、最长子字符串为空的字符串（例如`"aa"`)，以及具有多个重复字符的字符串。 

## 方法

 ### 蛮力

 暴力方法将检查字符串中的**每对可能的字符**，看看它们是否相等并计算它们之间的子字符串长度。 这涉及嵌套循环：外部循环选择第一个字符，内部循环检查所有后续字符是否匹配。 每当找到匹配项时，我们都会计算子字符串长度并记录最大值。 

虽然这保证了正确性，但效率很低。 带有长度的字符串`n`，该方法需要检查`O(n^2)`对，鉴于约束允许更好的解决方案，因此无需执行嵌套循环。 

### 最佳方法

 关键的观察是，对于任何字符，**只有第一次和最后一次出现才重要**来计算相同字符之间的最大子串长度。 如果某个字符出现多次，则两次出现之间的最长子字符串由该字符的**第一个和最后一个索引**确定。 

使用哈希映射（或字典）来存储每个字符的**第一次出现索引**，我们可以迭代字符串一次。 当我们遇到以前见过的字符时，我们计算从它第一次出现到当前索引的子字符串长度，减一以排除字符本身。 我们维持结果的运行最大值。 

这种方法利用了所有字符都是小写英文字母的特性，最多给出 26 个唯一字符，并且通过比较索引而不是枚举所有对来找到最大子字符串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 检查所有字符对 |
 | 最佳| O(n) | O(26) ≈ O(1) | O(26) ≈ O(1) | 使用哈希映射来跟踪首次出现 |

 ## 算法演练

 1.初始化一个空字典`first_occurrence`存储每个字符出现的第一个索引。 初始化`max_length`到`-1`处理没有重复字符的情况。 
2. 使用索引迭代字符串`i`和性格`c`。 
3.如果`c`不在`first_occurrence`， 店铺`i`作为它的第一次出现。 
4. 如果`c`已经在`first_occurrence`，计算第一次出现和之间的子字符串的长度`i`作为`i - first_occurrence[c] - 1`。 
5. 更新`max_length`如果此长度大于当前最大值。 
6. 遍历字符串后，返回`max_length`。 

**为什么起作用：** 该算法保证我们考虑每个字符的最长可能子字符串，因为当前索引的第一次出现覆盖了相同字符之间的最大间隙。 跟踪第一次出现可以确保我们不会重新计算不必要的对，从而将复杂性从二次降低到线性。 

## Python 解决方案```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first_occurrence = {}
        max_length = -1

        for i, c in enumerate(s):
            if c not in first_occurrence:
                first_occurrence[c] = i
            else:
                current_length = i - first_occurrence[c] - 1
                if current_length > max_length:
                    max_length = current_length

        return max_length
```实现完全遵循算法。 字典存储字符的第一个索引。 对于字符的每个后续出现，都会计算子字符串长度并更新最大值。 最后，我们返回`max_length`，即`-1`如果没有发现重复。 

## 解决方案```go
func maxLengthBetweenEqualCharacters(s string) int {
    firstOccurrence := make(map[rune]int)
    maxLength := -1

    for i, c := range s {
        if _, exists := firstOccurrence[c]; !exists {
            firstOccurrence[c] = i
        } else {
            currentLength := i - firstOccurrence[c] - 1
            if currentLength > maxLength {
                maxLength = currentLength
            }
        }
    }

    return maxLength
}
```在 Go 中，我们使用`map[rune]int`对于第一次出现的情况。 其逻辑与 Python 非常相似。 符文用于处理字符，尽管所有输入都是小写字母。 该映射提供 O(1) 访问，其余代码是简单的算术和比较。 

## 工作示例

 **示例1：`s = "aa"`**

 | 步骤| 我| c | 首次出现 | 当前长度| 最大长度|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | '一个' | {'a':0} | - | -1 |
 | 2 | 1 | '一个' | {'a':0} | 1-0-1=0 | 1-0-1=0 0 |

 返回`0`。 

**示例2：`s = "abca"`**

 | 步骤| 我| c | 首次出现 | 当前长度| 最大长度|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | '一个' | {'a':0} | - | -1 |
 | 2 | 1 | 'b' | {'a':0, 'b':1} | - | -1 |
 | 3 | 2 | 'c' | {'a':0, 'b':1, 'c':2} | - | -1 |
 | 4 | 3 | '一个' | {'a':0, 'b':1, 'c':2} | 3-0-1=2 | 3-0-1=2 2 |

 返回`2`。 

**示例3：`s = "cbzxy"`**

 所有角色都独一无二，`max_length`遗迹`-1`。 返回`-1`。

 ## 边缘情况

 第一个边缘情况是只有一个字符的字符串。 正确的输出是`-1`因为没有重复的字符。 这可能会导致尝试越界索引的幼稚方法。 

第二个边缘情况是两个相邻的相同字符，例如`"aa"`。 子串长度为零。 实现正确计算`i - first_index - 1 = 0`没有错误。 

第三种边缘情况是同一字符的多次重复，其中最长的子字符串由第一次和最后一次出现确定，而不是中间的出现。 例如，在`"abacabadabacaba"`, 字符`'a'`重复多次。 使用首次出现的字典可确保我们进行计算`last_index - first_index - 1`为最大间隙。 

这种方法可以有效、正确地处理所有边缘情况。
