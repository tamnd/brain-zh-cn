[LeetCode 问题 1646](https://leetcode.com/problems/get-maximum-in- generated-array/)

 **难度：** 🟢简单
 **主题：** 数组、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们生成一个名为的数组`nums`使用一组特定的规则，然后返回该数组中出现的最大值。 

数组有长度`n + 1`，这意味着其有效指数范围为`0`到`n`。 生成规则定义了如何根据先前计算的元素来计算每个元素。 

规则是：

 -`nums[0] = 0`-`nums[1] = 1`- 对于偶数指数：

 -`nums[2 * i] = nums[i]`- 对于奇数索引：

 -`nums[2 * i + 1] = nums[i] + nums[i + 1]`重要的细节是每个新值仅取决于之前已经生成的值。 这意味着我们可以从左到右递增地构建数组。 

输入是单个整数`n`，输出是出现在生成数组中任意位置的最大整数。 

限制非常小：

 -`0 <= n <= 100`自从`n`至多是`100`，即使相对低效的解决方案仍然可以快速运行。 然而，问题主要是测试我们是否正确模拟生成过程。 

有几个重要的边缘情况：

 -`n = 0`，该数组仅包含`[0]`-`n = 1`，数组是`[0, 1]`- 一些生成规则永远不会执行的小值
 - 奇数和偶数索引必须以不同方式处理
 - 访问`nums[i + 1]`必须始终保持有效

 该问题保证规则在条件满足时始终产生有效的索引。 

## 方法

 ### 蛮力方法

 最直接的解决方案是按照问题陈述逐字逐句生成每个元素。 

我们创建一个大小的数组`n + 1`，初始化已知的基本情况，然后迭代索引并应用生成规则。 

每一步：

 - 如果当前索引是偶数，则复制该值`nums[index // 2]`- 如果当前索引为奇数，则计算两个较早值的总和

 构造完整个数组后，我们再次扫描数组以找到最大值。 

这种方法是正确的，因为它完全反映了问题陈述中给出的定义。 

尽管约束很小，但这种方法仍然执行不必要的工作，因为它需要第二遍来计算最大值。 

### 最佳方法

 关键的观察是，在生成数组时，我们已经只看到每个值一次。 

我们可以在构造过程中保持运行最大值，而不是生成完整的数组然后稍后扫描它。 

每当计算新值时：

 - 将其与当前最大值进行比较
 - 如果需要更新最大值

 这避免了额外的遍历并保持逻辑干净和高效。 

因为每个值仅取决于先前计算的值，所以动态规划自然适用于此。 每个状态都是由较小的已知状态构建而成。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 生成数组，然后再次扫描最大 |
 | 最佳 | O(n) | O(n) | 生成数组同时跟踪最大值 |

 ## 算法演练

 1. 首先处理最小的边缘情况。 

如果`n == 0`，该数组仅包含`[0]`，所以答案是立即`0`。 
2. 创建数组`nums`尺寸的`n + 1`。 

该数组将存储所有生成的值。 我们需要它，因为未来的值取决于之前的条目。 
3. 初始化基本案例。 

放：

-`nums[0] = 0`-`nums[1] = 1`还将当前最大值初始化为`1`， 自从`nums[1]`是目前已知的最大值。 
4. 从索引迭代`2`通过`n`。 

每个索引必须根据它是偶数还是奇数来计算。 
5. 处理偶数索引。 

如果`i`是偶数：```
nums[i] = nums[i // 2]
```这直接遵循生成规则。 
6. 处理奇数索引。 

如果`i`是奇数：```
nums[i] = nums[i // 2] + nums[i // 2 + 1]
```整数除法为我们提供了正确的父索引。 
7. 更新运行最大值。 

计算后`nums[i]`，将其与当前最大值进行比较。 

如果新值较大，则更新最大值。 
8. 循环结束后返回最大值。 

### 为什么它有效

 该算法之所以有效，是因为数组中的每个值都是完全根据问题陈述中提供的规则生成的。 

迭代时`i`，所有较小的索引都已计算完毕，因此任何所需的依赖关系都已存在。 由于我们按升序处理索引，因此每次计算都是有效的。 

在生成过程中跟踪最大值可确保在循环结束时，我们只看到每个值一次，因此存储的最大值必须是数组中的最大值。 

## Python 解决方案```python
class Solution:
    def getMaximumGenerated(self, n: int) -> int:
        if n == 0:
            return 0

        nums = [0] * (n + 1)
        nums[0] = 0
        nums[1] = 1

        maximum = 1

        for i in range(2, n + 1):
            if i % 2 == 0:
                nums[i] = nums[i // 2]
            else:
                nums[i] = nums[i // 2] + nums[i // 2 + 1]

            maximum = max(maximum, nums[i])

        return maximum
```实现首先处理特殊情况，其中`n`是`0`。 如果没有此检查，则尝试分配`nums[1]`会导致索引错误，因为数组长度仅为`1`。 

接下来，解决方案分配一个长度的数组`n + 1`并初始化两个所需的基值。 

循环从索引处开始`2`因为指数`0`和`1`是已知的。 

循环内部：

 - 甚至索引也会复制以前的值
 - 奇数索引计算两个较早值的总和

 生成每个值后，算法立即更新运行最大值。 这避免了稍后需要再次遍历。 

最后，该函数返回遇到的最大值。 

## 解决方案```go
func getMaximumGenerated(n int) int {
    if n == 0 {
        return 0
    }

    nums := make([]int, n+1)
    nums[0] = 0
    nums[1] = 1

    maximum := 1

    for i := 2; i <= n; i++ {
        if i%2 == 0 {
            nums[i] = nums[i/2]
        } else {
            nums[i] = nums[i/2] + nums[i/2+1]
        }

        if nums[i] > maximum {
            maximum = nums[i]
        }
    }

    return maximum
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

使用创建切片`make([]int, n+1)`，它会自动将所有条目初始化为零。 

Go 不提供内置的`max`函数用于整数，因此使用简单的比较来更新最大值。 

Go 中的整数除法的行为完全符合此问题的需要，因此像这样的表达式`i/2`正确产生楼层划分。 

由于约束非常小，因此不必担心整数溢出。

 ## 边缘情况

 ### 边缘情况 1：`n = 0`这是最重要的特殊情况，因为数组仅包含一个元素：```
[0]
```如果没有显式处理这种情况，实现将尝试分配`nums[1] = 1`，这会导致越界错误。 该解决方案通过立即返回来避免这种情况`0`什么时候`n == 0`。 

### 边缘情况 2：小数组

 当`n`是`1`,`2`， 或者`3`，仅执行少数生成规则。 

这些小情况是差一错误的常见来源，特别是当循环从索引处开始时`2`。 该实现可以正确处理它们，因为循环范围在以下情况下自然会跳过无效迭代：`n`太小了。 

### 边缘情况 3：奇数索引计算

 奇数索引需要访问两者：```
nums[i // 2]
nums[i // 2 + 1]
```一个常见的错误是使用不正确的父索引或意外访问超出范围的值。 

该问题保证对于每个有效的奇数索引，两个所需的父索引都已经存在。 由于算法按升序处理索引，因此那些较早的值在需要之前就已经被计算出来了。
