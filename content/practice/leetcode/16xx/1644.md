[LeetCode 问题 1644](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree-ii/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到两个给定节点的**最低共同祖先（LCA）**，`p`和`q`，在二叉树中，条件是**任一节点可能不存在于树中**。 换句话说，给定一个具有唯一值和两个目标节点的二叉树，我们必须确定作为两个目标节点的祖先的最深节点`p`和`q`。 如果其中之一`p`或者`q`树中不存在，我们返回`null`。 

输入由二叉树的根节点和两个节点组成`p`和`q`。 树中的每个节点都有一个唯一的整数值。 预期输出是对 LCA 的 **TreeNode** 的引用，或者`null`如果任一节点丢失。 

该问题保证了`p != q`并且树中的节点数最多可达 10^4。 这表明 O(n) 遍历是可以接受的，但为了提高效率，应避免重复遍历。 

重要的边缘情况包括：

 1. 树中不存在节点之一。 幼稚的 LCA 算法会错误地返回节点。 
2. LCA本身就是节点之一。 根据定义，节点可以是其自身的后代。 
3. 树是倾斜的（所有节点都在一侧），这测试了递归深度和正确性。 

## 方法

 **暴力方法**首先需要使用单独的遍历来检查两个节点是否都存在于树中。 确认存在后，可以使用标准 LCA 算法递归搜索`p`和`q`在左子树和右子树中。 虽然正确，但这需要多次遍历树，因此对于大型树来说效率低下。 

**最佳方法**将存在检查和 LCA 搜索结合到单个递归遍历中。 我们定义一个递归函数，返回是否`p`或者`q`存在于子树和 LCA 中（如果存在）。 在每个节点，我们递归地检查左子节点和右子节点，然后确定当前节点是否是 LCA。 这确保我们只遍历树一次并正确处理节点丢失的情况。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 两次遍历：一次用于存在性检查，一次用于 LCA |
 | 最佳 | O(n) | O(h) | 单次DFS，其中h为树高； 仅当两个节点都存在时才返回 LCA |

 ## 算法演练

 1.定义递归函数`dfs(node)`遍历树。 对于每个节点，它将返回一个元组`(found_p, found_q, lca)`。 
2. 如果当前节点是`None`， 返回`(False, False, None)`因为两个目标都不存在于空子树中。 
3、递归遍历左孩子和右孩子，得到`(left_p, left_q, left_lca)`和`(right_p, right_q, right_lca)`。 
4. 确定是否`p`和`q`存在于当前子树中：`found_p = left_p or right_p or node == p`,`found_q = left_q or right_q or node == q`。 
5. 确定 LCA：

 - 如果`left_lca`不是`None`，向上传播。 
- 如果`right_lca`不是`None`，向上传播。 
- 如果`p`和`q`在不同的子树中找到（一棵在左，一棵在右）或者当前节点是`p`或者`q`并且另一个节点存在于子节点中，则当前节点是LCA。 
6. 返回`(found_p, found_q, lca)`对于当前节点。 
7. 在根处，检查两者是否`p`和`q`被发现。 如果是，则返回`lca`; 否则，返回`None`。 

**为什么起作用**：该算法确保我们仅在两个目标都存在于子树中时才将节点视为 LCA。 通过向上传播有关找到的节点和候选 LCA 的信息，可以识别正确的最低节点，并妥善处理丢失的节点。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        def dfs(node: 'TreeNode') -> tuple[bool, bool, 'TreeNode']:
            if not node:
                return False, False, None
            
            left_p, left_q, left_lca = dfs(node.left)
            right_p, right_q, right_lca = dfs(node.right)
            
            found_p = left_p or right_p or node == p
            found_q = left_q or right_q or node == q
            
            # If LCA already found in left or right, propagate it
            if left_lca:
                return found_p, found_q, left_lca
            if right_lca:
                return found_p, found_q, right_lca
            
            # If current node is LCA
            if (node == p or node == q) and (left_p or left_q or right_p or right_q):
                return found_p, found_q, node
            if left_p or left_q and right_p or right_q:
                return found_p, found_q, node
            
            return found_p, found_q, None
        
        found_p, found_q, lca = dfs(root)
        return lca if found_p and found_q else None
```该代码实现了所描述的 DFS 遍历。 每次递归调用都会判断是否`p`或者`q`存在于子树中，如果找到则返回 LCA。 这确保了如果两个目标都存在，我们只返回一个节点。 最后的返回检查标志以避免在一个节点丢失时返回 LCA。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    var dfs func(node *TreeNode) (bool, bool, *TreeNode)
    dfs = func(node *TreeNode) (bool, bool, *TreeNode) {
        if node == nil {
            return false, false, nil
        }
        
        leftP, leftQ, leftLCA := dfs(node.Left)
        rightP, rightQ, rightLCA := dfs(node.Right)
        
        foundP := leftP || rightP || node == p
        foundQ := leftQ || rightQ || node == q
        
        if leftLCA != nil {
            return foundP, foundQ, leftLCA
        }
        if rightLCA != nil {
            return foundP, foundQ, rightLCA
        }
        
        if (node == p || node == q) && (leftP || leftQ || rightP || rightQ) {
            return foundP, foundQ, node
        }
        if (leftP || leftQ) && (rightP || rightQ) {
            return foundP, foundQ, node
        }
        
        return foundP, foundQ, nil
    }
    
    foundP, foundQ, lca := dfs(root)
    if foundP && foundQ {
        return lca
    }
    return nil
}
```Go 实现反映了 Python 逻辑。 我们不返回元组，而是返回多个值`(bool, bool, *TreeNode)`。 Go 中的 Nil 处理取代了 Python`None`，并且使用指针相等进行比较很简单。 

## 工作示例

 **示例 1：root = [3,5,1,6,2,0,8,null,null,7,4]，p = 5，q = 1**

 1. 在节点 3 上启动 DFS。 
2. 向左递归到节点5：左子树包含5，右子树包含4和7； LCA 候选者为 5。 
3. 向右递归到节点1：节点1匹配q； 返回（假、真、零）。 
4. 在节点 3 处合并左右结果：左子树有 p，右子树有 q → LCA 为 3。 
5. 两个节点都找到，返回3。 

**示例 2：root = [3,5,1,6,2,0,8,null,null,7,4]，p = 5，q = 4**

 1. 节点 3 处的 DFS。 
2. DFS 左到节点 5：左子树有 6，右子树有 2 → DFS 右到 2，左有 7，右有 4。节点 4 匹配 q。 
3. 合并结果：节点 5 右子树中有 p 本身和 q → LCA 为 5。 
4.返回5。 

**示例 3：root = [3,5,1,6,2,0,8,null,null,7,4]，p = 5，q = 10**

 1. DFS 到达所有节点，找到 p = 5，但从未找到 q = 10。 
2.最终检查失败`found_q`， 返回`None`。
