[LeetCode 第 1615 题](https://leetcode.com/problems/maximal-network-rank/)

 **难度：** 🟡 中等
 **主题：** 图论

 ## 解决方案

 ## 问题理解

 该问题要求我们计算由双向道路连接的一组城市的**最大网络排名**。 每个城市都可以被视为图中的一个节点，每条道路都可以被视为一条无向边。 一对城市的**网络排名**是连接到任一城市的道路总数，共享道路仅计算一次。 目标是检查所有可能的城市对，并确定哪对实现最大的组合连通性。 

输入由一个整数组成`n`代表标记为的城市数量`0`到`n-1`，和一个列表`roads`其中每个元素`[a, b]`代表城市之间的直接联系`a`和`b`。 输出是一个表示**最大网络排名**的整数。 

约束告诉我们`n`至多是`100`并且最多可以有`n*(n-1)/2`道路，意味着完全连接的图是可能的。 输入保证没有重复的道路，也没有自环，这简化了边缘计数的处理。 

要考虑的边缘情况包括没有道路的城市、完全互联的城市以及两个城市共享直接道路的城市对与不共享直接道路的城市对。 

## 方法

 **暴力方法**涉及计算每对城市的网络排名。 我们可以迭代所有对`(i, j)`并统计直接连接到的道路`i`和`j`，如果它们共用一条直接道路，请确保减去一。 虽然这是正确的，但它涉及检查每对道路的每条道路，给出的时间复杂度为`O(n^2 * m)`在哪里`m`是道路的数量。 这对于小型来说是可行的`n`但效率低下时`n`接近100。 

**最佳方法**利用两个观察结果。 首先，我们只需要每个城市的**度**（与其相连的道路数量）。 其次，我们需要知道哪些城市是直接相连的，以处理“共享减一”的规则。 使用邻接矩阵（或每个城市的一组）允许我们通过迭代所有对并计算来计算最大网络等级`degree[i] + degree[j] - (1 if i and j are connected else 0)`。 这将复杂性降低到`O(n^2)`用于成对计算和`O(m)`用于预处理，这对于给定的约束是有效的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * m) | O(n^2 * m) | O(1) | O(1) | 检查每对城市并通过扫描道路列表来计算连接 |
 | 最佳 | O(n^2 + m) | O(n^2 + m) | O(n^2 或 n*m) | 预先计算度数和邻接信息，然后迭代所有对 |

 ## 算法演练

 1.初始化一个数组`degree`尺寸的`n`跟踪连接到每个城市的道路数量。 
2. 初始化一个`n x n`邻接矩阵`connected`或用于跟踪两个城市是否直接连接的集合列表。 
3. 迭代每条路`[a, b]`在`roads`。 增量`degree[a]`和`degree[b]`。 标记`connected[a][b]`和`connected[b][a]`作为`True`。 
4. 初始化`max_rank`至 0。 
5. 迭代所有城市对`(i, j)`在哪里`i < j`。 计算`rank = degree[i] + degree[j] - (1 if connected[i][j] else 0)`。 更新`max_rank`如果`rank`更高。 
6. 返回`max_rank`。 

**为什么有效**：该算法保证了正确性，因为它计算每个城市的准确度数，仅计算一次共享道路，并评估每对城市。 通过迭代所有对，它确保不会错过任何可能的最大网络排名。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximalNetworkRank(self, n: int, roads: List[List[int]]) -> int:
        degree = [0] * n
        connected = [[False] * n for _ in range(n)]
        
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1
            connected[a][b] = True
            connected[b][a] = True
        
        max_rank = 0
        for i in range(n):
            for j in range(i + 1, n):
                rank = degree[i] + degree[j] - (1 if connected[i][j] else 0)
                max_rank = max(max_rank, rank)
        
        return max_rank
```Python 实现使用一个列表来存储每个城市的度数，并使用一个 2D 列表来标记连接。 通过迭代每条道路一次，可以有效地计算度数和连接。 然后，迭代所有对可确保我们找到最大网络排名。 

## 解决方案```go
func maximalNetworkRank(n int, roads [][]int) int {
    degree := make([]int, n)
    connected := make([][]bool, n)
    for i := 0; i < n; i++ {
        connected[i] = make([]bool, n)
    }

    for _, road := range roads {
        a, b := road[0], road[1]
        degree[a]++
        degree[b]++
        connected[a][b] = true
        connected[b][a] = true
    }

    maxRank := 0
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            rank := degree[i] + degree[j]
            if connected[i][j] {
                rank--
            }
            if rank > maxRank {
                maxRank = rank
            }
        }
    }
    
    return maxRank
}
```Go 实现镜像 Python，但使用邻接矩阵切片并显式处理索引。 Go 不需要切片的类型提示，并且为每行显式初始化布尔切片。

 ## 边缘情况

 第一个边缘情况是**没有道路**的图**，其中最大网络等级应为 0，因为没有城市有任何连接。 该算法自然地处理这个问题，因为所有度数都为零。 

第二个边缘情况是一个**所有城市相互连接的图**，一个完全连接的图。 这里，最大网络等级等于`2*(n-1) - 1`因为任何一对都共用一条路。 邻接矩阵确保我们对共享边减去 1，从而给出正确的结果。
