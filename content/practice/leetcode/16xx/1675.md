[LeetCode 问题 1675](https://leetcode.com/problems/minimize-deviation-in-array/)

 **难度：** 🔴难
 **主题：** 数组、贪婪、堆（优先级队列）、有序集

 ## 解决方案

 ## 问题理解

 该问题要求我们最小化正整数数组中的偏差。 偏差定义为数组中最大元素和最小元素之间的差。 我们可以使用两个操作来修改数组：如果一个元素是偶数，我们可以将其除以 2，如果一个元素是奇数，我们可以将它乘以 2。这两个操作都可以对任何元素应用任意次。 

输入`nums`是一个正整数数组，输出应该是一个整数，表示执行一系列允许的操作后可能出现的最小偏差。 这些约束表明数组可以很大，最多可以有 50,000 个元素，元素本身最多可以有 10^9。 这意味着由于指数增长，任何探索所有可能的操作序列的简单暴力方法都将是不可行的。 

要考虑的边缘情况包括所有元素都已相等的数组、所有元素均为奇数或偶数的数组以及混合有非常小和非常大数字的数组。 该问题保证至少有两个元素且全部为正整数，因此我们不需要处理空数组或零/负数。 

## 方法

 暴力方法将尝试探索每个元素上的每个操作序列，以跟踪最小可能的偏差。 虽然理论上是正确的，但这种方法太慢，因为可能的序列数量随着数组大小和元素值呈指数增长。 鉴于限制，这是不可行的。 

最佳解决方案的关键在于偏差是由当前的最大和最小元素决定的。 由于偶数只能减少，奇数只能增加，因此我们应该首先通过使每个元素为偶数来规范化数组。 这确保了每个元素只能减少。 使用最大堆，我们重复减少最大元素（如果是偶数）并跟踪堆中的最小元素。 通过这样做，我们迭代地减少最大值，同时保持当前最小值，更新每一步的偏差。 当最大值为奇数（无法进一步减小）时，该过程停止，确保实现尽可能最小的偏差。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 探索所有操作顺序； 对于大 n | 来说不切实际
 | 最佳 | O(n log n) | O(n log n) | O(n) | 将所有数字归一化为偶数，使用 max-heap 迭代最小化偏差 |

 ## 算法演练

 1. 遍历数组`nums`。 对于每个元素，如果它是奇数，则将其乘以 2。这确保所有元素都是偶数，这使得我们只能从此时开始减少元素。 
2. 初始化最大堆。 在 Python 中，使用带有负值的最小堆，因为标准库仅提供最小堆。 
3. 在初始转换期间跟踪数组中的最小元素，因为这设置了计算偏差的基线。 
4. 当堆不为空时，从堆中提取最大元素（Python 中的值取负）。 将当前偏差计算为该最大值与跟踪的最小值之间的差值，如果较小则更新结果。 
5. 如果最大元素是偶数，则将其除以 2，必要时更新最小值，然后将其推回堆中。 这模拟了最大值的减少，同时可能减少总体偏差。 
6. 如果最大元素是奇数，则中断循环，因为它无法再减少。 
7. 返回跟踪的最小偏差。 

为什么它有效：该算法确保我们始终减少当前最大元素，同时跟踪当前最小值。 由于每个元素在最初就已经被制作出来，所以所有元素只能减少，而这种对最大值的贪婪减少保证了我们探索所有可能导致最小值的偏差。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        max_heap = []
        minimum = float('inf')
        
        for num in nums:
            if num % 2 == 1:
                num *= 2
            heapq.heappush(max_heap, -num)
            minimum = min(minimum, num)
        
        min_deviation = float('inf')
        
        while True:
            maximum = -heapq.heappop(max_heap)
            min_deviation = min(min_deviation, maximum - minimum)
            
            if maximum % 2 == 0:
                maximum //= 2
                minimum = min(minimum, maximum)
                heapq.heappush(max_heap, -maximum)
            else:
                break
        
        return min_deviation
```实现首先对数组进行标准化，以确保所有元素都是偶数。 然后每个元素被推入最大堆（作为负数）。 全程跟踪最小元素以计算每一步的偏差。 循环继续减小最大值，直到变为奇数。 该算法正确返回最小偏差。 

## 解决方案```go
package main

import (
	"container/heap"
	"math"
)

type MaxHeap []int

func (h MaxHeap) Len() int            { return len(h) }
func (h MaxHeap) Less(i, j int) bool  { return h[i] > h[j] }
func (h MaxHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x any)         { *h = append(*h, x.(int)) }
func (h *MaxHeap) Pop() any {
	n := len(*h)
	x := (*h)[n-1]
	*h = (*h)[:n-1]
	return x
}

func minimumDeviation(nums []int) int {
	h := &MaxHeap{}
	heap.Init(h)
	minimum := math.MaxInt32

	for _, num := range nums {
		if num%2 == 1 {
			num *= 2
		}
		heap.Push(h, num)
		if num < minimum {
			minimum = num
		}
	}

	minDeviation := math.MaxInt32

	for {
		maximum := heap.Pop(h).(int)
		if maximum-minimum < minDeviation {
			minDeviation = maximum - minimum
		}

		if maximum%2 == 0 {
			maximum /= 2
			if maximum < minimum {
				minimum = maximum
			}
			heap.Push(h, maximum)
		} else {
			break
		}
	}

	return minDeviation
}
```在 Go 中，我们定义了一个自定义 MaxHeap 类型来使用最大堆的堆包。 否则，逻辑反映了 Python 实现：标准化数字、推送到堆、跟踪最小值、迭代减少最大值并返回最小偏差。

 最小偏差 = 1。 

示例2：`nums = [4,1,5,20,3]`正常化：`[4,2,10,20,6]`通过迭代减少最大值进行处理：最终最小偏差 = 3。 

示例3：`nums = [2,10,8]`正常化：`[2,10,8]`（都是偶数）

 减少最大10→5→5奇数→停止

 跟踪偏差 → 3。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n log n) | O(n log n) | 每个元素最多可以减半log(max_num)次； 每次堆操作的成本为 O(log n) |
 | 空间| O(n) | 最大堆存储所有 n 个元素 |

 原因是每个元素只能减半 log2(max(nums)) 次，并且堆操作主导了运行时间。 空间是线性的，因为我们将所有元素存储在堆中。
