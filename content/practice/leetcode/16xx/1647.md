[LeetCode 问题 1647](https://leetcode.com/problems/minimum-deletions-to-make-character-frequencies-unique/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们使一个字符串**好**，这意味着字符串中没有两个不同的字符具有相同的频率。 输入是一个字符串`s`由小写英文字母组成，输出是获得良好字符串所需的最少字符删除数。 字符的**频率**就是它在字符串中出现的次数。 

约束表明`s`最长可达长度`10^5`，因此具有二次时间复杂度的解会太慢。 输入可以包括所有字符都相同、所有字符唯一或多个字符共享相同频率的字符串。 该问题明确允许删除字符，直到字符串良好为止，包括可能删除字符的所有实例，并且频率为零不会与其他字符冲突。 可能会导致幼稚实现失败的边缘情况包括具有许多重复字符形成大频率簇的字符串或所有字符的频率均为 1 的字符串。 

## 方法

 **暴力方法**将涉及重复检查所有字符频率对，并在发现重复项时递减频率，然后重复直到所有频率都是唯一的。 这种方法是正确的，因为它通过迭代删除来确保唯一性，但效率较低，如果许多字符共享相同的频率，在最坏的情况下可能需要 O(n^2) 次操作。 

**最佳方法的关键见解**是我们只关心频率集。 如果多个字符共享相同的频率，我们可以贪婪地降低其中一个字符的频率，直到它变得唯一。 通过按降序对频率进行排序，我们可以迭代地调整它们，同时跟踪最大允许频率以避免重复。 这是有效的，因为我们从不增加频率，并且我们总是贪婪地从最大到最小解决冲突，从而最大限度地减少删除。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(26) | 反复扫描并减少冲突频率 |
 | 最佳 | O(n + k log k) | O(n + k log k) | O(26) | 统计频率、排序、贪婪地减少重复项； k <= 26 个字母 |

 ## 算法演练

 1. 使用哈希图或大小为 26 的固定大小数组来统计字符串中每个字符的出现频率。 
2. 将所有非零频率存储在列表中。 
3. 按降序对频率列表进行排序，以便我们首先处理较高的频率，这使我们能够进行最少的删除。 
4. 初始化变量`deletions`为 0 以跟踪删除总数。 
5. 设置变量`max_allowed`到排序列表中的第一个频率。 这表示下一个字符可以保持唯一性的最大频率。 
6. 从第二个元素开始迭代排序后的频率：

 1. 如果当前频率大于等于`max_allowed`，将其减少到`max(0, max_allowed - 1)`并将差值添加到`deletions`。 
2. 更新`max_allowed`到下一次迭代的新频率。 
7. 返回总计`deletions`。 

**为什么起作用：** 通过按降序处理频率并始终限制下一个频率小于前一个频率，我们保持了不存在两个频率相同的不变性，同时最大限度地减少了删除。 频率无法增加，因此贪婪地减少重复项可确保最小的总删除量。 

## Python 解决方案```python
class Solution:
    def minDeletions(self, s: str) -> int:
        from collections import Counter

        freq_counter = Counter(s)
        frequencies = sorted(freq_counter.values(), reverse=True)
        deletions = 0
        max_allowed = frequencies[0]

        for freq in frequencies:
            if freq > max_allowed:
                deletions += freq - max_allowed
                freq = max_allowed
            max_allowed = max(0, freq - 1)

        return deletions
```该实现首先使用以下方法计算字符频率`Counter`，按降序对它们进行排序，然后使用所描述的贪婪方法迭代调整它们。 这`max_allowed`确保每个频率严格小于前一个频率，并且`max(0, ...)`确保我们永远不会出现负频率。 

## 解决方案```go
import "sort"

func minDeletions(s string) int {
    freq := make([]int, 26)
    for _, ch := range s {
        freq[ch-'a']++
    }

    freqs := []int{}
    for _, f := range freq {
        if f > 0 {
            freqs = append(freqs, f)
        }
    }

    sort.Sort(sort.Reverse(sort.IntSlice(freqs)))

    deletions := 0
    maxAllowed := freqs[0]

    for _, f := range freqs {
        if f > maxAllowed {
            deletions += f - maxAllowed
            f = maxAllowed
        }
        if maxAllowed > 0 {
            maxAllowed = f - 1
        }
    }

    return deletions
}
```Go 版本使用固定大小的数组来计算字符频率，并使用切片来保存非零频率。 排序和贪心归约遵循与Python相同的逻辑。 Go 需要仔细处理切片和整数索引，但逻辑反映了 Python 方法。 

## 工作示例

 **示例1：**`s = "aab"`频率：`[2,1]`→ 已排序`[2,1]`→ 最大允许数 = 2

 - 'a': 频率 2 ≤ 2 → 确定
 - 'b'：频率 1 < 2 → 确定

 删除 = 0

 **示例2：**`s = "aaabbbcc"`频率：`[3,3,2]`→ 已排序`[3,3,2]`→ 最大允许数 = 3

 - 前 3 → 确定
 - 第二个 3 → 减少到 2 → 删除 += 1, max_allowed = 1
 - 第三个 2 → 减少到 1 → 删除 += 1, max_allowed = 0

 删除总数 = 2

 **示例3：**`s = "ceabaacb"`频率：`[3,2,2,1]`→ 已排序`[3,2,2,1]`→ 最大允许数 = 3

 - 3 → 确定
 - 2 → 好的，max_allowed = 1
 - 2→减少到1→删除+=1，max_allowed = 0
 - 1→减少到0→删除+=1

 删除总数 = 2

 ## 边缘情况

 **情况1：单个字符串**

 字符串像`"a"`只有一个字符，频率为 1。不需要删除，算法可以正确处理这一问题，因为`max_allowed`从 1 开始，不存在其他频率。 

**情况2：所有出现频率为1的字符**

 像这样的字符串`"abcdef"`有频率`[1,1,1,1,1,1]`。 该算法将每个后续频率减少到严格小于前一个，最终删除字符以达到唯一性。 第一个频率保持为 1，下一个频率变为 0，这是允许的，因为频率 0 被忽略。 

**情况 3：大型重复簇**

 具有许多重复字符的字符串，例如`"aaaabbbbcccc"`有频率`[4,4,4]`。 算法排序`[4,4,4]`并贪婪地将它们减少到`[4,3,2]`对于最小删除，正确计算删除为`1 + 2 = 3`。 这确保了最少的删除，同时保持唯一性。
