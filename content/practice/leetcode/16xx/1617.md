[LeetCode 问题 1617](https://leetcode.com/problems/count-subtrees-with-max-distance- Between-cities/)

 **难度：** 🔴难
 **主题：** 动态规划、位操作、树、枚举、位掩码

 ## 解决方案

 ## 问题理解

 输入描述了一个无向树`n`城市。 由于图是一棵树，因此有`n - 1`edges and there is a unique simple path between every pair of cities.

 这个问题要求我们检查每一个可能连接的城市子集。 A subset is considered a valid subtree if all cities inside the subset remain connected using only nodes from the subset itself. In graph terms, we are looking for all connected induced subgraphs of the tree.

 For every valid subtree, we compute its diameter. 直径是该子树内任意两个城市之间的最大距离，其中距离表示两个城市之间最短路径上的边数。 

The task is to count how many connected subtrees have diameter`1`, 有多少个直径`2`，依此类推，直到`n - 1`。 

返回的数组有长度`n - 1`， 在哪里：

-`answer[0]`存储具有直径的连接子树的数量`1`-`answer[1]`存储具有直径的连接子树的数量`2`- ...
 -`answer[n - 2]`存储具有直径的连接子树的数量`n - 1`约束条件极其重要：

 -`2 <= n <= 15`一棵只有 15 个节点的树非常小。 这立即表明位掩码枚举是可行的。 由于最多有`2^15 = 32768`子集，我们实际上可以迭代节点的每个子集。 

挑战不在于子集的数量，而在于有效地确定：

 1、子集是否形成连通子树
 2. 该子树的直径是多少

 一些边缘情况很重要：

 - 只有一个节点的子集是相连的，但它的直径为`0`，问题仅要求直径`1`到`n - 1`，因此单节点子集不应对答案有贡献。 
- 某些子集已断开连接，必须被忽略。 
- 树的形状可以非常不同，例如星形、链形或平衡树，因此该算法必须适用于所有拓扑。 
- 由于图已经是一棵树，因此每个连接的子集都会自动形成一个有效的子树。 

## 方法

 ### 蛮力方法

 最直接的解决方案是枚举每个节点子集并测试它是否形成连通子树。 

对于每个子集：

 1. 提取所有包含的节点。 
2.检查归纳图是否使用DFS或BFS连接。 
3. 如果已连接，则计算子集中每对节点之间的最大距离。 
4. 增加与直径对应的答案桶。 

为了计算距离，我们可以从子集中的每个节点运行 BFS。 

这种方法是正确的，因为它显式地评估每个可能的子树并直接测量其直径。 然而，它执行了大量的重复工作。 

如果我们为每个子集重复重新计算距离，复杂度就会变得不必要的高。 

### 关键见解

 约束条件`n <= 15`允许完整的子集枚举，但我们应该优化每个子集的工作。 

重要的观察是该图是一棵树，这意味着：

 - 一个连通子集`k`节点必须准确包含`k - 1`内部边缘。 
- 使用两次 BFS 或 DFS 遍历可以有效地找到树的直径。 

因此我们可以：

 1. 使用位掩码枚举所有子集。 
2. 检查与 DFS 的连接。 
3. 使用经典的两遍 DFS 技术计算直径。 

二次直径法的工作原理如下：

 - 从子树中的任意节点开始。 
- 找到最远的节点`A`。 
- 开始于`A`并找到最远的节点`B`。 
- 距离`A`到`B`是子树直径。 

这避免了显式检查每一对。

 ## 算法演练

 ### 第 1 步：构建邻接表

 将边列表转换为邻接列表表示。 

这允许对树进行高效的 DFS 遍历。 

### 步骤 2：枚举所有子集

 使用位掩码`1`到`(1 << n) - 1`。 

每个比特代表一个节点是否包含在当前子集中。 

例如，与`n = 4`:

 -`0101`表示节点`{1, 3}`-`1110`表示节点`{2, 3, 4}`我们跳过只有一个节点的子集，因为它们的直径是`0`。 

### 第三步：找到起始节点

 对于当前子集，找到其位被设置的任何节点。 

该节点成为 DFS 的起点。 

### 步骤 4：检查连接性

 执行DFS，同时仅遍历子集中包含的节点。 

跟踪有多少个节点被访问。 

如果访问节点的数量小于子集大小，则该子集将断开连接并应被忽略。 

### 步骤 5：找到直径的一个端点

 从起始节点运行 DFS。 

跟踪最远的可到达节点及其距离。 

这会产生子树直径的一个端点。 

### 步骤 6：计算直径

 再次运行 DFS，这次从步骤 5 中找到的最远节点开始。 

在此遍历过程中达到的最大距离就是直径。 

### 第 7 步：更新答案

 如果直径大于`0`，增量：```
answer[diameter - 1]
```因为结果数组是零索引的。 

### 步骤 8：继续，直到处理完所有子集

 检查每个子集后，返回答案数组。 

### 为什么它有效

 每个可能的节点子集都会被检查一次。 子集仅在连接时才对答案做出贡献，这保证了它在原始树中形成有效的子树。 

两遍 DFS 方法可以正确计算树的直径，因为直径的一个端点始终是距离任意起始节点最远的节点。 从该端点再次运行 DFS 会产生真正的最大距离。 

由于每个连接的子树都只计算一次并分配给其正确的直径桶，因此该算法是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def countSubgraphsForEachDiameter(self, n: int, edges: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(n)]

        for u, v in edges:
            u -= 1
            v -= 1
            graph[u].append(v)
            graph[v].append(u)

        answer = [0] * (n - 1)

        def dfs(node: int, mask: int, visited: List[bool], distance: int):
            visited[node] = True

            farthest_node = node
            max_distance = distance
            count = 1

            for neighbor in graph[node]:
                if ((mask >> neighbor) & 1) and not visited[neighbor]:
                    next_node, next_distance, next_count = dfs(
                        neighbor,
                        mask,
                        visited,
                        distance + 1
                    )

                    count += next_count

                    if next_distance > max_distance:
                        max_distance = next_distance
                        farthest_node = next_node

            return farthest_node, max_distance, count

        for mask in range(1, 1 << n):
            if mask & (mask - 1) == 0:
                continue

            start = 0
            while ((mask >> start) & 1) == 0:
                start += 1

            visited = [False] * n

            farthest_node, _, visited_count = dfs(
                start,
                mask,
                visited,
                0
            )

            subset_size = mask.bit_count()

            if visited_count != subset_size:
                continue

            visited = [False] * n

            _, diameter, _ = dfs(
                farthest_node,
                mask,
                visited,
                0
            )

            answer[diameter - 1] += 1

        return answer
```实现首先将边列表转换为邻接列表。 由于输入节点是一索引的，而 Python 列表是零索引的，因此每个节点值都会减一。 

核心辅助函数是`dfs`。 它同时执行三项任务：

 1.只遍历当前子集中的节点
 2. 统计有多少个节点被访问
 3. 追踪最远可达节点及其距离

 递归返回三个值：

 - 找到最远的节点
 - 到该节点的距离
 - 访问的节点数

 外循环迭代每个位掩码子集。 

单节点子集将被立即跳过，因为它们对答案没有贡献。 

第一个 DFS 检查连通性并找到直径的一个候选端点。 如果访问计数不等于子集中的节点数，则子集断开连接。 

第二次DFS从之前找到的最远节点开始。 在此遍历中发现的最大距离是直径。 

最后，相应的答案桶递增。 

## 解决方案```go
package main

func countSubgraphsForEachDiameter(n int, edges [][]int) []int {
	graph := make([][]int, n)

	for _, edge := range edges {
		u := edge[0] - 1
		v := edge[1] - 1

		graph[u] = append(graph[u], v)
		graph[v] = append(graph[v], u)
	}

	answer := make([]int, n-1)

	var dfs func(int, int, []bool, int) (int, int, int)

	dfs = func(node int, mask int, visited []bool, distance int) (int, int, int) {
		visited[node] = true

		farthestNode := node
		maxDistance := distance
		count := 1

		for _, neighbor := range graph[node] {
			if ((mask>>neighbor)&1) == 1 && !visited[neighbor] {
				nextNode, nextDistance, nextCount := dfs(
					neighbor,
					mask,
					visited,
					distance+1,
				)

				count += nextCount

				if nextDistance > maxDistance {
					maxDistance = nextDistance
					farthestNode = nextNode
				}
			}
		}

		return farthestNode, maxDistance, count
	}

	for mask := 1; mask < (1 << n); mask++ {
		if mask&(mask-1) == 0 {
			continue
		}

		start := 0

		for ((mask >> start) & 1) == 0 {
			start++
		}

		visited := make([]bool, n)

		farthestNode, _, visitedCount := dfs(
			start,
			mask,
			visited,
			0,
		)

		subsetSize := 0

		for temp := mask; temp > 0; temp >>= 1 {
			subsetSize += temp & 1
		}

		if visitedCount != subsetSize {
			continue
		}

		visited = make([]bool, n)

		_, diameter, _ := dfs(
			farthestNode,
			mask,
			visited,
			0,
		)

		answer[diameter-1]++
	}

	return answer
}
```Go 实现遵循与 Python 解决方案相同的结构。 

一个显着的区别是 Go 不提供内置的`bit_count()`以与 Python 相同的便捷方式处理整数函数。 因此，子集大小是通过计算设置位来手动计算的。 

切片用于邻接列表和访问跟踪。 由于 Go 通过类似引用的行为传递切片，因此 DFS 函数可以修改共享的切片`visited`直接切片。 

整数溢出不是问题，因为由于约束，涉及的最大值非常小`n <= 15`。

这是足够有效的，因为`n <= 15`，所以子集的最大数量只有32768。

 ## 边缘情况

 一个非常重要的边缘情况是单节点子集。 从技术上讲，单个节点形成一棵连通子树，但其直径为`0`。 由于该问题仅要求直径`1`到`n - 1`，这些子集不得对结果有贡献。 该实现通过跳过仅包含一组位的掩码来处理此问题。 

另一个重要的边缘情况是断开的子集。 例如，在一个链中`1-2-3`，子集`{1,3}`无效，因为节点`2`丢失，因此其余节点已断开连接。 幼稚的实现可能会意外地将其视为有效的子树。 DFS 连接检查通过确保访问节点的数量与子集大小匹配来防止这种情况发生。 

星形树也很棘手。 在以节点为中心的星形中`1`，任何包含两个叶节点的子集还必须包含中心节点才能保持连接。 该实现自然会强制执行此操作，因为 DFS 遍历无法到达没有中心的叶子之间。 

最后，长链树强调直径计算。 在路径图中，直径可以变得与`n - 1`。 无论树的形状如何，两遍 DFS 方法都能正确识别最长路径的端点。
