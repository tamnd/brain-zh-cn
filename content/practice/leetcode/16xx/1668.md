[LeetCode 第 1668 题](https://leetcode.com/problems/maximum-repeating-substring/)

 **难度：** 🟢简单
 **主题：** 字符串、动态规划、字符串匹配

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定给定的字符串出现了多少次`word`可以连续重复，同时仍然作为另一个字符串中的子字符串出现，称为`sequence`。 

更正式地说，如果满足以下条件，则字符串被视为 **k 重复**：`word`串联的`k`时间出现在里面的某个地方`sequence`作为连续的子字符串。 我们的目标是找到**最大可能的值`k`**。 

例如，如果：```
sequence = "ababc"
word = "ab"
```然后：

-`"ab"`出现在`"ababc"`→`k = 1`-`"abab"`出现在`"ababc"`→`k = 2`-`"ababab"`没有出现→`k = 3`无效

 因此，答案是`2`。 

输入由两个字符串组成：

 -`sequence`，我们搜索的较大字符串
 -`word`，我们要测试的重复单元

 预期输出是一个整数，表示连续重复的最大次数`word`作为子串存在`sequence`。 

限制相对较小：

 -`sequence.length <= 100`-`word.length <= 100`这些限制立即表明我们可以承受一些低效的操作，例如重复的子字符串检查，而不必担心性能。 由于总输入大小很小，即使具有二次或三次行为的算法仍然可以轻松通过。 

然而，仍然有一些重要的边缘情况需要考虑。 

一种棘手的情况发生在`word`没有出现在`sequence`根本不。 在这种情况下，答案必须是`0`。 

另一个重要的情况是当`word`只出现一次，但重复版本则不会。 例如：```
sequence = "ababc"
word = "ba"
```这里，`"ba"`存在，但是`"baba"`没有，所以答案是`1`。 

我们还应该考虑重叠的模式。 例如：```
sequence = "aaaaa"
word = "aa"
```重复的子串`"aaaa"`出现，意义`k = 2`有效，即使事件在概念上重叠。 

该问题保证两个字符串都只包含小写英文字母且非空，因此我们不需要处理空字符串或无效输入。 

## 方法

 ### 蛮力方法

 解决这个问题的一个直接方法是尝试每个可能的值`k`并检查是否`word * k`作为子串存在`sequence`。 

我们可以从`k = 1`并反复串联`word`对自己。 对于每次重复，我们测试结果字符串是否出现在内部`sequence`。 

最终，发生以下两件事之一：

 1、重复的字符串不再是子串。 
2. 重复的字符串变得长于`sequence`，使得进一步的检查毫无意义。 

最大的成功`k`是我们的答案。 

这种方法是正确的，因为它按升序明确检查每个可能的候选者。 由于我们仅在重复失败时停止，因此最终的有效计数必须是最大的。 

然而，重复重建字符串和扫描子字符串可能会变得低效。 尽管约束足够小，该解决方案可以轻松运行，但我们可以更仔细地进行推理并更好地构建流程。 

### 最佳方法

 关键的观察是最大可能的重复计数自然是有限的。 

如果`word`有长度`m`和`sequence`有长度`n`， 然后：```
maximum possible k = n // m
```任何更大的东西都会超过总长度`sequence`，使其无法拟合。 

而不是盲目增加`k`，我们可以迭代所有可行的重复次数并检查重复的字符串是否存在于`sequence`。 

由于 Python 和 Go 中的子字符串搜索非常高效并且约束很小，因此这成为一个干净实用的解决方案。 

我们反复构建：```
word
word * 2
word * 3
...
```并跟踪最大有效重复次数。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复构建字符串并增量检查子字符串 |
 | 最佳 | O(n²) | O(n) | 将检查限制为可行的重复计数并停止不必要的工作 |

 自从`n ≤ 100`，这两种方法都足够快。 最佳版本更干净、结构更好。 

## 算法演练

 ### 最优算法

 1. 计算最大可能的重复次数。 

由于重复复制`word`必须适合里面`sequence`，最大重复次数不能超过：```
len(sequence) // len(word)
```这给了我们一个上限并避免了不必要的检查。 
2. 初始化一个变量来跟踪答案。 

我们维持`max_repeating = 0`因此，每当我们找到有效的重复子字符串时，我们就可以更新它。 
3. 迭代所有可能的重复计数。 

对于每个值`k`从`1`对于最大可能的重复计数，构造：```
repeated_word = word * k
```4. 检查重复的字符串是否是以下字符串的子串`sequence`。 

如果：```
repeated_word in sequence
```然后`k`有效，所以更新`max_repeating`。 
5. 返回最大有效重复次数。 

测试所有可行值后`k`，返回存储的最大值。 

### 为什么它有效

 该算法之所以有效，是因为它按升序系统地检查每个有效候选重复计数。 既然一切可能`k`之间`1`并测试了理论最大值，不能错过任何有效答案。 该算法仅记录成功的重复，确保最终结果是最大的有效结果`k`。 

## Python 解决方案```python
class Solution:
    def maxRepeating(self, sequence: str, word: str) -> int:
        max_possible = len(sequence) // len(word)
        max_repeating = 0

        for k in range(1, max_possible + 1):
            repeated_word = word * k

            if repeated_word in sequence:
                max_repeating = k

        return max_repeating
```实现首先计算最大可能的重复次数。 由于重复的子串不能长于`sequence`，我们使用整数除法来建立上限。 

然后我们初始化`max_repeating`到`0`，它可以正确处理以下情况`word`从未出现在`sequence`。 

这`for`循环遍历每个可行的重复计数。 对于每个`k`，我们使用以下方法构建重复模式：```python
word * k
```Python 字符串乘法使这变得简洁而高效。 

然后我们检查生成的字符串是否出现在里面`sequence`使用Python内置的子字符串操作：```python
repeated_word in sequence
```如果子字符串存在，我们更新答案。 

最后，在检查每个候选重复计数后，我们返回最大的有效值。 

## 解决方案```go
func maxRepeating(sequence string, word string) int {
    maxPossible := len(sequence) / len(word)
    maxRepeating := 0

    for k := 1; k <= maxPossible; k++ {
        repeatedWord := ""

        for i := 0; i < k; i++ {
            repeatedWord += word
        }

        if contains(sequence, repeatedWord) {
            maxRepeating = k
        }
    }

    return maxRepeating
}

func contains(sequence string, target string) bool {
    return strings.Contains(sequence, target)
}
```Go 实现遵循与 Python 版本相同的整体逻辑。 

与 Python 不同，Go 不支持字符串乘法，例如：```go
word * k
```所以我们使用循环手动构造重复的字符串。 

子字符串检查是通过以下方式处理的：```go
strings.Contains(sequence, repeatedWord)
```这需要导入`strings`包裹。 

Go 字符串是不可变的，就像 Python 字符串一样，但考虑到微小的输入限制，重复连接在这里是完全可以接受的。 

带有导入的完全 LeetCode 可提交版本如下所示：```go

 ## 边缘情况

 一种重要的边缘情况发生在以下情况：`word`没有出现在`sequence`根本不。 幼稚的实现可能会意外返回`1`如果它假设至少存在一个重复。 我们的实现通过初始化避免了这个问题`max_repeating = 0`仅当找到有效的子字符串时才更新它。 

另一个边缘情况是当`word`与自身重叠。 例如：```
sequence = "aaaaa"
word = "aa"
```尽管出现的次数在概念上重叠，但重复的子串`"aaaa"`仍然连续存在于序列中，这意味着`k = 2`是有效的。 由于我们直接检查重复的连接字符串，因此自然可以处理重叠行为，无需特殊逻辑。 

第三个重要的情况发生在`word`长于`sequence`。 在这种情况下，任何重复都是不可能的。 因为我们计算：```
len(sequence) // len(word)
```最大可能的重复次数变为`0`，意味着循环永远不会运行并且函数正确返回`0`。 

最后，单字符字符串值得关注，因为它们可以产生相对于输入大小而言非常大的重复计数。 例如：```
sequence = "zzzzzz"
word = "z"
```我们的实现正确检查每个可行的重复级别并返回`6`，证明该逻辑即使在极端的重复密度下也能发挥作用。
