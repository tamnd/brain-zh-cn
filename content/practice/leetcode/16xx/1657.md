[LeetCode 问题 1657](https://leetcode.com/problems/define-if-two-strings-are-close/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、排序、计数

 ## 解决方案

 ## 问题理解

 问题询问两个字符串是否`word1`和`word2`，根据两个允许的操作是“关闭”的。 操作1允许交换字符串中的任意两个现有字符，这意味着字符的相对顺序是灵活的。 操作 2 允许将一个字符的所有出现转换为另一个现有字符，反之亦然，只要字符串中存在这两个字符，它就可以有效地让您重新分配字符之间的频率。 

输入由两个仅包含小写英文字母的字符串组成，长度最多为`10^5`。 预期输出是一个布尔值：`true`如果可以使用任意数量的这些操作将字符串相互转换，并且`false`否则。 

这些约束意味着我们无法模拟所有可能的操作序列，因为这对于长字符串来说太慢了。 重要的边缘情况包括不同长度的字符串、字符集不匹配的字符串或字符以不同频率存在且即使在交换后也无法匹配的字符串。 

主要见解是，由于操作 1，字符的顺序并不重要，因此只有**字符集**及其**频率分布**重要。 操作 2 允许我们排列字符之间的频率，因此频率计数本身只需要作为多重集进行匹配。 

## 方法

 暴力方法会尝试模拟所有可能的操作序列，迭代地交换字符和转换频率以检查字符串是否可以变得相同。 这在理论上是正确的，但对于高达以下的输入长度来说是不切实际的`10^5`因为可能的操作数量随字符串长度呈阶乘增长。 

最佳方法依赖于两个关键观察结果：首先，字符串必须具有相同的唯一字符集； 其次，排序后的字符频率计数必须匹配。 对频率进行排序说明了操作 2 允许在字符之间重新分配频率的事实。 这将问题简化为简单的设置和频率比较，这是高效的。

 ## 算法演练

 1. **检查长度**：如果`word1`和`word2`有不同的长度，返回`false`。 这是因为这两个操作都无法更改字符总数。 
2. **统计字符频率**：为每个字符串构建频率图。 这让我们可以跟踪每个字符出现的次数。 
3. **比较字符集**：从每个字符串中提取唯一字符集。 如果这些集合不同，则返回`false`因为我们无法使用允许的操作引入新字符。 
4. **比较频率分布**：对每个字符串的频率值进行排序并进行比较。 如果匹配，则可以使用操作 2 将字符串相互转换； 否则，返回`false`。 

**为什么有效**：操作 1 允许任意重新排序字符，操作 2 允许对现有字符之间的频率进行任意排列。 因此，如果两个字符串具有相同的字符集和相同的频率多重集，则它们是接近的。 这保证了任何操作序列都可以将一个字符串转换为另一个字符串。 

## Python 解决方案```python
from collections import Counter

class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        if len(word1) != len(word2):
            return False
        
        freq1 = Counter(word1)
        freq2 = Counter(word2)
        
        if set(freq1.keys()) != set(freq2.keys()):
            return False
        
        return sorted(freq1.values()) == sorted(freq2.values())
```Python 实现首先检查字符串的长度是否相同。 然后它使用`Counter`来计算字符出现的次数。 字符集的比较使用`set(freq1.keys())`以确保存在相同的字符。 最后，比较排序的频率列表以验证频率分布是否匹配，从而允许进行任何交换或转换。 

## 解决方案```go
import "sort"

func closeStrings(word1 string, word2 string) bool {
    if len(word1) != len(word2) {
        return false
    }
    
    freq1 := make(map[rune]int)
    freq2 := make(map[rune]int)
    
    for _, ch := range word1 {
        freq1[ch]++
    }
    for _, ch := range word2 {
        freq2[ch]++
    }
    
    if len(freq1) != len(freq2) {
        return false
    }
    
    keys1 := make([]rune, 0, len(freq1))
    keys2 := make([]rune, 0, len(freq2))
    
    for k := range freq1 {
        keys1 = append(keys1, k)
    }
    for k := range freq2 {
        keys2 = append(keys2, k)
    }
    
    keySet1 := make(map[rune]struct{})
    keySet2 := make(map[rune]struct{})
    
    for _, k := range keys1 {
        keySet1[k] = struct{}{}
    }
    for _, k := range keys2 {
        keySet2[k] = struct{}{}
    }
    
    for k := range keySet1 {
        if _, ok := keySet2[k]; !ok {
            return false
        }
    }
    
    values1 := make([]int, 0, len(freq1))
    values2 := make([]int, 0, len(freq2))
    
    for _, v := range freq1 {
        values1 = append(values1, v)
    }
    for _, v := range freq2 {
        values2 = append(values2, v)
    }
    
    sort.Ints(values1)
    sort.Ints(values2)
    
    for i := range values1 {
        if values1[i] != values2[i] {
            return false
        }
    }
    
    return true
}
```在 Go 中，实现使用映射来计算字符频率。 键集是使用空结构来构造的，以比较字符集。 频率被逐个元素地提取、排序和比较。 由于缺乏内置的 Counter 和 set 操作，Go 版本更加冗长。
