[LeetCode 第 1692 题](https://leetcode.com/problems/count-ways-to-distribute-candies/)

 **难度：** 🔴难
 **主题：** 动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算分配方式的数量`n`**不同**糖果变成`k`袋子，每个袋子至少有一颗糖果。 这些糖果是独一无二的，并贴有来自`1`到`n`，袋子内糖果的顺序或袋子本身的顺序并不重要。 如果两个分布中至少一个袋子中的糖果组不同，则认为两个分布不同。 

输入由两个整数组成，`n`和`k`。 输出是一个整数，表示有效分布的模数$10^9 + 7$。 限制因素$1 \le k \le n \le 1000$表明解决方案必须高效，可能需要动态编程或组合数学而不是强力枚举，因为枚举所有分区呈指数增长。 

需要注意的要点包括：所有糖果必须分发，每个袋子必须至少装有一颗糖果，并且顺序无关紧要。 边缘情况包括：`n == k`，每个袋子必须恰好得到一颗糖果，并且`k == 1`，所有糖果都装在一个袋子里。 

## 方法

 暴力方法会尝试生成所有分区`n`元素进入`k`非空子集。 这在理论上是正确的，但在计算上是不可行的，因为方式的数量快速增长（与**第二类斯特林数**相关）。 枚举所有可能的分布在时间复杂度上是指数级的，因此对于`n`最多 1000 个。 

最佳解决方案的关键见解是认识到这个问题相当于计算**第二类斯特林数**，它计算划分方法的数量`n`不同的项目进入`k`非空子集。 斯特林数的递归公式为：$$S(n, k) = k \cdot S(n-1, k) + S(n-1, k-1)$$推理是：当添加`n`-th 糖果，它可以进入现有的糖果之一`k`袋子（因此`k * S(n-1, k)`）或开始一个新包（因此`S(n-1, k-1)`）。 使用动态规划，我们可以计算所有`S(n, k)`有效地计算值并返回模数结果$10^9 + 7$。

 ## 算法演练

 1.初始化2D DP表`dp`尺寸的`(n+1) x (k+1)`在哪里`dp[i][j]`代表分配方式的数量`i`糖果进入`j`包。 
2. 设置基本情况`dp[0][0] = 1`，这意味着有一种方法可以将零糖果分配到零袋子中。 
3. 对于每个糖果数量`i`从 1 到`n`:

 - 对于每个行李数量`j`从 1 到`k`:

 - 计算`dp[i][j]`使用递归关系`dp[i][j] = (j * dp[i-1][j] + dp[i-1][j-1]) % MOD`。 

-`j * dp[i-1][j]`说明将新糖果放入现有糖果之一`j`包。 
-`dp[i-1][j-1]`说明将新糖果放入新袋子中的情况。 
4. 返回`dp[n][k]`作为最终答案模数$10^9 + 7$。 

工作原理：递归确保所有分区都只计算一次，并且模运算可防止整数溢出。 基本情况和递归结构涵盖了所有可能的分布，同时满足每个袋子至少包含一颗糖果的约束。 

## Python 解决方案```python
class Solution:
    def waysToDistribute(self, n: int, k: int) -> int:
        MOD = 10**9 + 7
        dp = [[0] * (k+1) for _ in range(n+1)]
        dp[0][0] = 1

        for i in range(1, n+1):
            for j in range(1, k+1):
                dp[i][j] = (j * dp[i-1][j] + dp[i-1][j-1]) % MOD

        return dp[n][k]
```该实现使用二维数组`dp`存储中间结果。 我们迭代每个可能数量的糖果和袋子，应用斯特林数递归来填充表格。 使用模可以确保大数下的正确性。 

## 解决方案```go
func waysToDistribute(n int, k int) int {
    const MOD = 1000000007
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, k+1)
    }
    dp[0][0] = 1

    for i := 1; i <= n; i++ {
        for j := 1; j <= k; j++ {
            dp[i][j] = (j*dp[i-1][j] + dp[i-1][j-1]) % MOD
        }
    }

    return dp[n][k]
}
```Go 实现反映了 Python 逻辑。 我们初始化一片切片来表示 DP 表，迭代糖果和袋子，并应用递归。 仔细处理整数乘法和加法模$10^9 + 7$以防止溢出。

 ## 边缘情况

 **边缘情况 1：n == k**

 当糖果数量等于袋子数量时，每个袋子必须恰好收到一颗糖果。 DP 递归正确地处理了这个问题，因为`dp[i][i]`建立自`dp[i-1][i-1]`，确保所有糖果都放入单独的袋子中。 

**边缘情况 2：k == 1**

 所有糖果都装在一个袋子里。 递归之所以有效，是因为`dp[i][1]`乘以`1 * dp[i-1][1]`，有效地仅计算一个分布。
