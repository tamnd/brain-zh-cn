[LeetCode 问题 1674](https://leetcode.com/problems/minimum-moves-to-make-array-complementary/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、前缀和

 ## 解决方案

 ## 问题理解

 该问题需要我们变换一个数组`nums`长度均匀的`n`进入**互补数组**。 如果对于每个索引，数组是互补的`i`，总和`nums[i] + nums[n - 1 - i]`是相同的常数值。 中的每个元素`nums`可以更改为范围内的任意整数`[1, limit]`在一次移动中，我们想要确定实现此属性的**最小移动次数**。 

简单来说，我们从数组的两端对称地配对元素，并尝试使用尽可能少的替换使所有对的总和达到相同的数字。 关键的观察结果是每个元素都可以在`[1, limit]`并且我们只需要考虑对的总和，而不是孤立的单个元素。 

约束条件告诉我们`n`可以达到`10^5`和`limit`可以达到`10^5`，这排除了迭代所有可能的总和或简单地修改元素的解决方案。 边缘情况包括已经互补的数组、需要最大更改的数组以及其中的数组`limit`相对于元素非常小或非常大。 

重要保证：数组长度`n`是均匀的，并且所有`nums[i]`在之内`[1, limit]`。 

## 方法

 ### 蛮力

 天真的方法会考虑每一个可能的目标总和`S`从`2`到`2 * limit`并且，对于每个，计算使每对总和等于所需的移动次数`S`。 对于每对`(a, b) = (nums[i], nums[n-1-i])`，我们根据是否需要零次移动、一次移动或两次移动来确定`a + b == S`或者如果改变一个或两个元素可以实现`S`。 虽然正确，但这种方法需要`O(n * limit)`最坏情况下的时间对于`n`最多`10^5`和`limit`最多`10^5`。 

### 最佳方法

 关键的见解是对于一对`(a, b)`，所需的移动次数取决于**一步可实现的总和范围**。 具体来说，一步操作可以使总和介于`1 + min(a, b)`和`limit + max(a, b)`。 超出这个范围，需要两次移动。 通过使用**前缀和差数组**，我们可以有效地计算所有可能的和的最小移动`2`到`2 * limit`无需单独检查每对的每个总和。 

洞察的步骤：

 1. 对于每对`(a, b)`，识别：

 - 需要 **2 步** 的最低金额（`2`）
 - 需要**1次移动**的总和范围（`1 + min(a, b)`到`limit + max(a, b)`）
 - 需要**0步**的总和（`a + b`）
 2.使用差异数组`delta`在哪里`delta[s]`表示所需移动总和的变化`s`。 最初添加+2步，在边界处减去或加1来编码范围，然后计算前缀和以有效地获得所有总和的步数。 

这种方法将复杂性降低到线性`n`加上线性输入`limit`，在给定约束的情况下这是可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 极限) | O(1) | O(1) | 检查每对的所有可能的总和 |
 | 最佳 | O(n + 极限) | O(极限) | 使用前缀和/差数组有效地计算移动 |

 ## 算法演练

 1.初始化一个差异数组`delta`长度`2 * limit + 2`存储每次总和的移动变化。 
2. 迭代每一对`(a, b) = (nums[i], nums[n-1-i])`。 
3. 对于每一对，最初假设所有总和都需要 **2 次移动**。 
4. 更新`delta`考虑 **1 次移动** 或 **0 次移动** 可能的总和范围：

 - 增量为`2`经过`2`（两步总和的开始）
 - 递减于`1 + min(a, b)`减 1（1 步总和的开始）
 - 递减于`a + b`减 1（0 步总和）
 - 增量为`a + b + 1`减 1（0 步总和结束）
 - 增量为`limit + max(a, b) + 1`减 1（1 步总和结束）
 5. 计算前缀和`delta`获得每笔金额的**实际所需的移动**。 
6. 返回所有总和中的**最小值**。 

为什么有效：差异数组对每个总和需要多少步进行编码。 前缀和将差异数组转换为实际的移动，使我们能够有效地计算所有总和的最小移动，而无需显式检查每对的每个移动。 

## Python 解决方案```python
from typing import List

class Solution:
    def minMoves(self, nums: List[int], limit: int) -> int:
        n = len(nums)
        delta = [0] * (2 * limit + 2)
        
        for i in range(n // 2):
            a, b = nums[i], nums[n - 1 - i]
            low = 1 + min(a, b)
            high = limit + max(a, b)
            sum_ab = a + b
            
            delta[2] += 2
            delta[low] -= 1
            delta[sum_ab] -= 1
            delta[sum_ab + 1] += 1
            delta[high + 1] += 1
        
        moves = float('inf')
        current = 0
        for s in range(2, 2 * limit + 1):
            current += delta[s]
            moves = min(moves, current)
        
        return moves
```Python 实现直接遵循该算法。 差异数组对动作进行编码，并且单遍计算前缀和以有效地确定最小动作。 

## 解决方案```go
func minMoves(nums []int, limit int) int {
    n := len(nums)
    delta := make([]int, 2*limit+2)
    
    for i := 0; i < n/2; i++ {
        a, b := nums[i], nums[n-1-i]
        low := 1 + min(a, b)
        high := limit + max(a, b)
        sumAB := a + b
        
        delta[2] += 2
        delta[low] -= 1
        delta[sumAB] -= 1
        delta[sumAB+1] += 1
        delta[high+1] += 1
    }
    
    moves := int(1e9)
    current := 0
    for s := 2; s <= 2*limit; s++ {
        current += delta[s]
        if current < moves {
            moves = current
        }
    }
    return moves
}

func min(a, b int) int {
    if a < b { return a }
    return b
}

func max(a, b int) int {
    if a > b { return a }
    return b
}
```Go 解决方案镜像了 Python 版本，使用切片和整数函数`min`和`max`。 它避免了显式类型转换，因为所有值都在 int 范围内。 

## 工作示例

 ### 示例 1：`nums = [1,2,4,3], limit = 4`对：`(1,3)`和`(2,4)`一对`(1,3)`：

 - 总和= 4，低= 2，高= 7
 - 增量更新：增量[2] +=2、增量[2]-=1、增量[4]-=1、增量[5]+=1、增量[8]+=1

 一对`(2,4)`：

 - 总和 = 6，低位 = 3，高位 = 8
 - 增量更新相应

 总和 2..8 上的前缀总和给出移动：最小值 = 1

 ### 示例 2：`nums = [1,2,2,1], limit = 2`对：`(1,1)`和`(2,2)`- 所有超出可实现范围的金额都需要移动
 - 前缀和计算显示最小值 = 2

 ### 示例 3：`nums = [1,2,1,2], limit = 2`对：`(1,2)`和`(2,1)`- 已经互补（总和 = 3）
 - 前缀总和显示最小移动 = 0
