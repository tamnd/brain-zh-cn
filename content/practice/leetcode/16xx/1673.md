 ## 解决方案

## 问题理解

 该问题要求我们找到给定整数数组中最具**竞争力**的子序列`nums`尺寸的`k`。 通过从数组中删除零个或多个元素而不改变剩余元素的相对顺序来形成子序列。 一个子序列`a`被认为比子序列更具竞争力`b`如果第一个不同的元素具有相同的长度`a`小于`b`。 

例如，给定`nums = [3,5,2,6]`和`k = 2`，长度为 2 的子序列是`[3,5]`,`[3,2]`,`[3,6]`,`[5,2]`,`[5,6]`,`[2,6]`。 其中，`[2,6]`在第一个不同索引处按字典顺序最小，因此它是最具竞争力的。 

输入约束对于理解规模很重要：`nums`最多可以有 100,000 个元素，每个元素可以大到`10^9`， 和`k`范围可以从 1 到长度`nums`。 这排除了任何显式生成所有子序列的强力解决方案，因为长度的子序列数`k`是组合性的，对于大输入来说是不可行的。 

要考虑的边缘情况包括已按升序或降序排序的数组、具有重复元素的数组以及`k`等于 1 或等于 的长度`nums`。 如果这些情况没有正确处理剩余元素或基于堆栈的删除，则可能会导致简单的实现失败。 

## 方法

 **暴力方法**将涉及生成所有可能的长度子序列`k`从`nums`并对它们进行比较以找到最具竞争力的一个。 这保证了正确性，因为它会检查每个可能的候选者。 然而，生成所有长度的子序列`k`需要组合运算（`C(n,k)`），这对于`n = 10^5`。 

**最佳方法**依赖于使用**单调堆栈**的贪婪策略。 关键的观察是，为了使子序列具有竞争力，我们希望尽早使用较小的元素，同时确保我们仍然可以形成长度的子序列`k`与其余元素。 我们可以迭代`nums`并维护一个代表目前为止最具竞争力的子序列的堆栈。 在每一步中，如果当前数量小于栈顶，并且有足够的剩余元素来完成一个长度`k`接下来，我们弹出堆栈，为较小的数字腾出空间。 这保证了我们始终保持字典顺序上最小的子序列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(C(n,k) * k) | O(C(n,k) * k) | O(k) | 生成长度为 k 的所有子序列并选择最小值。 对于 n=10^5 | 太慢
 | 最佳 | O(n) | O(k) | 使用单调堆栈贪婪地维护最具竞争力的子序列 |

 ## 算法演练

 1. 初始化一个空栈来表示正在构建的子序列。 
2. 迭代每个元素`num`在`nums`。 
3. 当栈不为空时，栈顶元素大于`num`，其余元素加上堆栈长度足以形成长度为的子序列`k`，弹出栈顶。 这可以确保在可能的情况下较小的数字取代较大的数字。 
4. 如果堆栈少于`k`元素、推`num`到堆栈上。 否则，跳过`num`因为包含它会超出所需的长度。 
5、处理完所有元素后，栈中包含长度最有竞争力的子序列`k`。 

**为什么起作用：** 堆栈不变式确保在每个索引处，我们在最早的位置维护尽可能小的数字，同时仍然保证有足够的剩余元素来完成长度的子序列`k`。 这会产生字典顺序最小的序列，因为在允许的情况下，我们会贪婪地删除较大的元素以支持较小的元素。 

## Python 解决方案```python
from typing import List

class Solution:
    def mostCompetitive(self, nums: List[int], k: int) -> List[int]:
        stack = []
        n = len(nums)
        
        for i, num in enumerate(nums):
            # Pop elements from stack if current num is smaller and enough elements remain
            while stack and stack[-1] > num and len(stack) - 1 + (n - i) >= k:
                stack.pop()
            if len(stack) < k:
                stack.append(num)
        return stack
```**说明：** 我们维护一个堆栈作为我们的子序列。 while 循环确保我们在顶部删除较大的元素（如果我们可以安全地用较小的元素替换它们）`num`同时仍然能够达到长度`k`。 最后的检查防止堆栈超出大小`k`。 这直接遵循算法演练。 

## 解决方案```go
func mostCompetitive(nums []int, k int) []int {
    stack := make([]int, 0, k)
    n := len(nums)

    for i, num := range nums {
        for len(stack) > 0 && stack[len(stack)-1] > num && len(stack)-1+(n-i) >= k {
            stack = stack[:len(stack)-1]
        }
        if len(stack) < k {
            stack = append(stack, num)
        }
    }
    return stack
}
```**Go 特定说明：** 我们预先分配具有容量的堆栈切片`k`以避免重复分配。 切片调整大小通过`append`自动处理添加元素。 逻辑与Python版本相同，并且边界检查通过切片操作安全地处理。
