[LeetCode 问题 1694](https://leetcode.com/problems/reformat-phone-number/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题需要以特定的结构化方式重新格式化电话号码字符串。 输入是一个字符串`number`包含数字、空格和破折号。 我们的任务是首先删除所有非数字字符，然后将数字分成长度为 3 的块，并对最后几位数字进行特殊处理：如果正好剩下 4 位数字，则将它们分成两个 2 的块； 如果还剩 3 位数字，则为 3 的单块； 如果剩余 2 位数字，则为 2 的单个块。最终输出应该是一个字符串，其中块由破折号分隔，不允许长度为 1 的块。 

约束条件指定`number`长度介于 2 到 100 之间，仅包含数字、空格或破折号，并且至少有两位数字。 这确保了我们始终有足够的数字来形成有效的块，并且性能不是标准解决方案的主要关注点。 重要的边缘情况包括已格式化的字符串、具有连续非数字字符的字符串以及末尾仅保留 2、3 或 4 位数字的字符串。 

## 方法

 一种暴力方法涉及逐个字符地迭代字符串，构造一个干净的数字字符串，然后尝试各种可能的方法将其分割成块，直到找到有效的字符串。 虽然这会产生正确的结果，但对于较大的输入来说，它不必要地复杂且效率低下。 

最佳解决方案的关键是首先**删除所有非数字字符**以获得干净的数字序列。 然后，重复取 3 位数字的块，直到剩余的数字为 4 或更少。 这保证了我们有效地处理 2、3 或 4 位数字的特殊情况，并确保不会产生长度为 1 的块。 这种方法在时间上是线性的并且易于实施。

 ## 算法演练

 1. **清理输入**：迭代输入字符串`number`并仅将数字附加到新字符串或列表中。 这会删除空格和破折号。 
2. **初始化块的存储**：创建一个空列表来保存数字块。 
3. **形成3位数字块**：当剩余数字长度大于4时，将前3位数字作为一个块，将其追加到块列表中，并将其从剩余数字中删除。 
4. **处理最后2到4位数字**：经过上述步骤后，正好剩下2、3或4位数字：

 - 如果还剩下 4 位数字，则分成两块，每块 2 位数字。 
- 如果还剩下 3 位数字，则组成一组 3 位数字。 
- 如果还剩下 2 位数字，则形成一组 2 位数字。 
5. **连接块**：使用破折号`-`字符连接所有块并返回结果字符串。 

**为什么有效：** 通过重复获取 3 位数字的块，我们确保最终数字始终为 2、3 或 4。对这些最后数字的特殊处理保证不会出现长度为 1 的块，并且最终的破折号分隔的连接会生成格式正确的数字。 

## Python 解决方案```python
class Solution:
    def reformatNumber(self, number: str) -> str:
        digits = [ch for ch in number if ch.isdigit()]
        blocks = []
        
        while len(digits) > 4:
            blocks.append(''.join(digits[:3]))
            digits = digits[3:]
        
        if len(digits) == 4:
            blocks.append(''.join(digits[:2]))
            blocks.append(''.join(digits[2:]))
        else:
            blocks.append(''.join(digits))
        
        return '-'.join(blocks)
```此实现首先通过过滤掉非数字字符来构造数字列表。 然后它形成 3 位数字的块，直到剩余的数字少于 5 位。 剩余的数字根据规则进行处理，最后的块用破折号连接起来以生成格式化的电话号码。 

## 解决方案```go
func reformatNumber(number string) string {
    digits := []byte{}
    for i := 0; i < len(number); i++ {
        if number[i] >= '0' && number[i] <= '9' {
            digits = append(digits, number[i])
        }
    }

    blocks := []string{}
    for len(digits) > 4 {
        blocks = append(blocks, string(digits[:3]))
        digits = digits[3:]
    }

    if len(digits) == 4 {
        blocks = append(blocks, string(digits[:2]))
        blocks = append(blocks, string(digits[2:]))
    } else {
        blocks = append(blocks, string(digits))
    }

    result := ""
    for i, block := range blocks {
        if i > 0 {
            result += "-"
        }
        result += block
    }
    return result
}
```在 Go 中，我们使用字节片来存储数字。 切片可以方便地删除已处理的数字并转换为字符串。 主要逻辑与Python相同：处理3个块，处理最后2-4位数字，并用破折号连接块。

 ## 边缘情况

 第一个边缘情况是只有 2 位数字的电话号码，例如`"12"`。 总是尝试形成 3 位数字块的简单实现可能会错误地生成长度为 1 的块。我们的解决方案通过在剩余 ≤ 4 个数字时直接添加剩余数字来处理此问题。 

第二个边缘情况恰好涉及 4 个剩余数字，例如`"1234"`。 该算法将它们分成两个 2 位数字块，确保不会出现单位数字块，从而符合规则。 

第三种边缘情况是混合有空格和破折号的输入，例如`"1-2 3-4 5"`。 过滤掉非数字字符可确保分隔符不会干扰块形成。 无论原始格式如何，这都保证了一致的行为。
