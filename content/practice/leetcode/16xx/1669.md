[LeetCode 问题 1669](https://leetcode.com/problems/merge-in- Between-linked-lists/)

 **难度：** 🟡 中等
 **主题：** 链接列表

 ## 解决方案

 ## 问题理解

 该问题要求我们以非常具体的方式合并两个单链表。 我们被给予`list1`和`list2`，有尺寸`n`和`m`分别连同两个索引`a`和`b`。 任务是删除节点`list1`从索引开始`a`直至索引`b`（包括）并插入整个`list2`在他们的地方。 结果列表应保留之前的所有节点`a`从`list1`，包括来自的所有节点`list2`，然后继续使用来自的节点`list1`后`b`。 

简单来说，`list2`替换连续的段`list1`由指数定义`[a, b]`。 该问题保证有效索引和非空列表，因此我们不需要处理空`list1`或者`list2`。 索引从 0 开始，并且`1 <= a <= b < list1.length - 1`确保删除的段不在列表的最末端，这简化了指针操作。 

需要考虑的重要边缘情况包括在开始或结束时合并`list1`，有`list2`长度为 1，并且连续节点被删除`list1`直接相邻的`a`和`b`。 该问题确保列表长度达到 10,000，因此需要高效的线性时间算法。 

## 方法

 蛮力方法将遍历`list1`和`list2`，将它们转换为数组或切片，在数组级别执行删除和插入，然后重建一个新的链表。 这是可行的，但需要 O(n + m) 额外空间，并且是不必要的，因为链表允许直接指针操作。 

最佳方法利用了可以通过调整指针来拼接链表的事实。 我们穿越`list1`找到之前的节点`a`（`prev_a`) 和紧随其后的节点`b`（`after_b`）。 然后我们连接`prev_a.next`到 的 头`list2`并连接尾部`list2`到`after_b`。 这种方法以相对于长度的线性时间运行`list1`和`list2`，使用 O(1) 额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n + m) | O(n + m) | 将列表转换为数组、操作数组、重建列表 |
 | 最佳 | O(n + m) | O(1) | O(1) | 遍历指针，直接拼接列表，最少的额外内存 |

 ## 算法演练

 1.初始化两个指针：`prev_a`没有和`current`到`list1`。 遍历`list1`直到达到`a`第 个节点，更新`prev_a`指向之前的节点`a`。 这确定了拼接开始的位置。 
2.继续遍历`list1`从节点`a`直到到达节点`b`。 保留指针`after_b`到下面的节点`b`。 这标识了已删除段的末尾。 
3. 遍历`list2`找到它的尾节点。 这是连接末端所必需的`list2`到剩余部分`list1`。 
4. 连接`prev_a.next`到 的 头`list2`。 这将连接替换段。 
5.连接尾部`list2`到`after_b`。 这将重新连接其余部分`list1`删除节点后。 
6. 返回`list1`作为修改后的链表的头。 

为什么它有效：该算法之所以有效，是因为它保持了之前所有节点的不变性`a`以及之后`b`保持不变，而节点之间`a`和`b`被替换为`list2`。 指针操作确保没有节点丢失，遍历确保所有指针都正确更新。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeInBetween(self, list1: ListNode, a: int, b: int, list2: ListNode) -> ListNode:
        prev_a = None
        current = list1
        index = 0
        
        # Step 1: Find node before 'a' (prev_a)
        while index < a:
            prev_a = current
            current = current.next
            index += 1
        
        # Step 2: Find node after 'b' (after_b)
        after_b = current
        while index <= b:
            after_b = after_b.next
            index += 1
        
        # Step 3: Find tail of list2
        tail_list2 = list2
        while tail_list2.next:
            tail_list2 = tail_list2.next
        
        # Step 4: Connect prev_a to head of list2
        prev_a.next = list2
        
        # Step 5: Connect tail of list2 to after_b
        tail_list2.next = after_b
        
        return list1
```该实现首先定位要删除的线段周围的节点，然后遍历`list2`直至其结束。 键指针连接很简单：`prev_a.next`附件`list2`，以及尾部`list2`连接回`after_b`。 其余的`list1`保持不变。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func mergeInBetween(list1 *ListNode, a int, b int, list2 *ListNode) *ListNode {
    var prevA *ListNode
    current := list1
    index := 0

    // Step 1: Find node before 'a' (prevA)
    for index < a {
        prevA = current
        current = current.Next
        index++
    }

    // Step 2: Find node after 'b' (afterB)
    afterB := current
    for index <= b {
        afterB = afterB.Next
        index++
    }

    // Step 3: Find tail of list2
    tailList2 := list2
    for tailList2.Next != nil {
        tailList2 = tailList2.Next
    }

    // Step 4: Connect prevA to head of list2
    prevA.Next = list2

    // Step 5: Connect tail of list2 to afterB
    tailList2.Next = afterB

    return list1
}
```在 Go 中，处理`nil`指针至关重要，但其他方面的逻辑与 Python 类似。 直接更新指针，无需额外的数据结构，保持 O(1) 空间复杂度。
