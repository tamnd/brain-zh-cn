[LeetCode 问题 1641](https://leetcode.com/problems/count-sorted-vowel-strings/)

 **难度：** 🟡 中等
 **主题：** 数学、动态规划、组合学

 ## 解决方案

 ## 问题理解

 该问题要求我们计算长度为多少的字符串`n`仅由元音组成`a`,`e`,`i`,`o`,`u`这样每个字符串都是**按字典顺序排序的**。 按字典顺序排序意味着字符串中的字符不会随着从左向右移动而减少。 例如，`ae`是有效的，因为`a`出现在之前`e`， 但`ea`无效，因为`e`之后`a`。 

输入是单个整数`n`，表示字符串的长度。 输出是一个整数，表示该长度的有效字符串总数。 

约束条件，`1 <= n <= 50`，告诉我们`n`足够小，可以使用组合或动态编程方法，但太大，无法天真地生成所有字符串。 

重要的边缘情况包括`n = 1`，这是微不足道的，因为每个元音形成一个有效的字符串，并且大`n`价值观像`n = 50`，这需要一个避免指数枚举的解决方案。 

## 方法

 ### 蛮力

 暴力方法是生成所有可能的长度字符串`n`使用 5 个元音，然后过滤掉那些未按字典顺序排序的元音。 这将涉及 5^n 种可能性，这对于`n`小至 15 或 20。虽然正确，但效率极低。 

### 最佳

 关键的见解是，对于按字典顺序排序的字符串，元音的顺序不会减少。 这使我们能够将问题视为**组合问题**，其中我们计算允许重复的元音组合。 

从数学上讲，这种长度的字符串的数量`n`使用 5 个元音相当于组合公式：$$C(n + k - 1, k - 1)$$在哪里`k = 5`是元音的数量。 这个公式来自组合“星条”定理，计算分配方式的数量`n`5 个不同类别（元音）中的相同项目（字符串中的位置），同时保持顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(5^n) | O(5^n) | O(5^n) | O(5^n) | 生成所有字符串并过滤 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 使用组合公式 C(n+4,4) |

 ## 算法演练

 1. 认识到问题归结为选择`n`允许 5 个元音重复的项目，同时保持顺序。 
2. 认识到这相当于在其中选择 4 个分配器的组合问题`n + 4`职位。 
3. 计算二项式系数`C(n + 4, 4)`使用公式：$$C(n+4, 4) = \frac{(n+4)(n+3)(n+2)(n+1)}{24}$$1. 返回该值作为结果。 

**为什么有效**：每个有效字符串都可以通过每个元音出现的次数来唯一表示，并且元音的顺序本质上是通过计算组合来维护的。 这确保我们对所有字符串精确计数一次。 

## Python 解决方案```python
class Solution:
    def countVowelStrings(self, n: int) -> int:
        # Using combinatorial formula C(n+4, 4)
        return (n + 4) * (n + 3) * (n + 2) * (n + 1) // 24
```此实现计算从以下位置开始的四个连续整数的乘积`n+1`除以 24（4 的阶乘）即可得到二项式系数 C(n+4,4)。 它直接来自上面的组合推理。 

## 解决方案```go
func countVowelStrings(n int) int {
    return (n + 4) * (n + 3) * (n + 2) * (n + 1) / 24
}
```在 Go 中，整数除法在这里是安全的，因为所有中间乘积都可以被 24 整除，并且结果符合`int`对于给定的约束。 不需要额外的库。 

## 工作示例

 **示例1**：`n = 1`C(1+4,4) = C(5,4) = 5

 **示例2**：`n = 2`C(2+4,4) = C(6,4) = 15

 **示例3**：`n = 33`C(33+4,4) = C(37,4) = 66045

 ## 边缘情况

 **单长度字符串**：当`n=1`，答案就是元音的数量，即 5。公式正确处理了这一点。 

**最大长度字符串**：当`n=50`，组合数很大，但适合 Python 和 Go 中的标准整数。 使用整数除法可确保不会发生舍入错误。 

**重复字符**：像这样的字符串`aaaa`或者`eeeee`是有效的，并且组合方法会自动对它们进行计数，因为它允许重复选择相同的元音。 这避免了在代码中进行任何特殊处理的需要。
