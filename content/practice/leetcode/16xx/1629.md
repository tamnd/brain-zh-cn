[LeetCode 1629 题](https://leetcode.com/problems/slowest-key/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 此问题要求我们确定在测试序列期间按下键盘上的哪个键的**持续时间**最长。 我们得到两条信息：`releaseTimes`指示每个键何时被释放，以及一个字符串`keysPressed`代表按顺序按下的键。 第一个键被认为是在时间 0 按下的，并且当前一个键被释放时，后续的每个键都被准确地按下。 

按键的**持续时间**计算为其释放时间与前一个按键的释放时间之间的差值，第一个按键除外，其持续时间等于其释放时间。 如果多个按键具有相同的最大持续时间，我们必须返回 **按字典顺序最长的按键**。 

约束告诉我们输入长度`n`较小（最多1000），释放次数严格递增，并且仅使用小写英文字母作为键。 这保证了除了具有相同持续时间的多个按键之外，时间上没有联系，并且数组始终有效。 重要的边缘情况包括第一个键是最慢的，以及需要字典序比较的持续时间之间的联系。 

## 方法

 暴力方法将迭代每个按键，计算其持续时间，并将最大持续时间与按键一起存储。 这可以正确工作并且有效`n = 1000`，但我们必须使用字典比较仔细处理关系。 没有更快的渐近解决方案，因为我们必须至少检查每个键一次，因此单遍迭代是最佳的。 

关键的观察是我们可以实时跟踪最大持续时间。 在迭代按键时，我们将当前按键的持续时间与迄今为止找到的最大值进行比较。 如果持续时间更长，我们更新最大值和相应的键。 如果持续时间等于最大值，则仅当它按字典顺序更大时我们才更新密钥。 这在具有恒定额外空间的单遍中给出了 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 计算所有键的持续时间并跟踪列表中的最大值，然后选择按字典顺序打破平局的最大值 |
 | 最佳| O(n) | O(1) | O(1) | 单遍跟踪最大持续时间和字典顺序最大的键 |

 ## 算法演练

 1. 初始化`maxDuration`作为第一次按键的持续时间（`releaseTimes[0]`） 和`resultKey`作为`keysPressed[0]`。 
2. 迭代从索引 1 到 n-1 的其余按键。 
3. 对于索引处的每个键`i`，计算其持续时间为`releaseTimes[i] - releaseTimes[i-1]`。 
4. 如果这个持续时间大于`maxDuration`， 更新`maxDuration`并设置`resultKey`到当前键。 
5. 如果持续时间等于`maxDuration`， 更新`resultKey`仅当当前键按字典顺序大于当前键时`resultKey`。 
6. 处理完所有按键后，返回`resultKey`。 

**为什么有效**：该算法在每次迭代后都保持不变，`resultKey`是迄今为止所看到的持续时间最长的键，或者是那些持续时间最长的键中按字典顺序排列最长的键。 这确保了单次传递的正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def slowestKey(self, releaseTimes: List[int], keysPressed: str) -> str:
        maxDuration = releaseTimes[0]
        resultKey = keysPressed[0]
        
        for i in range(1, len(keysPressed)):
            duration = releaseTimes[i] - releaseTimes[i - 1]
            if duration > maxDuration or (duration == maxDuration and keysPressed[i] > resultKey):
                maxDuration = duration
                resultKey = keysPressed[i]
                
        return resultKey
```Python 实现直接遵循算法演练。 我们使用第一个键初始化最大持续时间和结果键，然后迭代其余键。 对于每个键，我们计算其相对于前一个键的持续时间。 如果持续时间超过当前最大值，我们将更新两者`maxDuration`和`resultKey`。 如果持续时间达到最大值，我们会进行字典顺序比较来决定是否更新`resultKey`。 

## 解决方案```go
func slowestKey(releaseTimes []int, keysPressed string) byte {
    maxDuration := releaseTimes[0]
    resultKey := keysPressed[0]
    
    for i := 1; i < len(keysPressed); i++ {
        duration := releaseTimes[i] - releaseTimes[i-1]
        if duration > maxDuration || (duration == maxDuration && keysPressed[i] > resultKey) {
            maxDuration = duration
            resultKey = keysPressed[i]
        }
    }
    
    return resultKey
}
```Go 解决方案反映了 Python 方法。 我们使用第一个键初始化最大持续时间和结果键，迭代这些键，并相应地更新。 Go 将字符串索引处理为字节，这与使用`>`操作员。

 ## 边缘情况

 一个重要的边缘情况是**第一个键最慢**。 由于其持续时间的计算方式不同（`releaseTimes[0]`），一个总是使用的幼稚实现`releaseTimes[i] - releaseTimes[i-1]`对于所有键可能会错误计算第一个持续时间。 此实现正确初始化`maxDuration`和`releaseTimes[0]`。 

另一个边缘情况是**持续时间的关系**。 多个键可能具有相同的持续时间，该问题需要返回字典顺序最大的键。 这是通过简单的比较来处理的`keysPressed[i] > resultKey`每当持续时间等于`maxDuration`。 

第三种边缘情况是**所有键都相同**。 如果按下的每个键都相同，则持续时间最长的键自然就是该键，但算法仍必须正确计算持续时间，而不是依赖于键的唯一性。 这是通过迭代和比较无缝处理的。
