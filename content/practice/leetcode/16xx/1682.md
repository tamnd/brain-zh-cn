[LeetCode 问题 1682](https://leetcode.com/problems/longest-palindromic-subsequence-ii/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 问题是要求我们找到给定字符串中最长的良好回文子序列的长度**`s`。 **好的回文子序列**是满足几个条件的字符串：它必须是`s`，它必须向前和向后读取相同，它必须具有**偶数长度**，并且除了中间两个字符之外不能包含两个连续的相等字符。 

输入`s`是一串小写英文字母，长度最大为 250，它足够小，可以考虑使用动态规划解决方案`O(n^3)`实践中的时间复杂度，尽管理想情况下我们希望`O(n^2)`如果可能的话。 输出是一个整数，表示最长的好回文子序列的长度。 

重要的边缘情况包括所有字符都相同的字符串、只有一个字符的字符串、不存在良好回文子序列的字符串以及最佳子序列嵌套在字符串深处而不是末尾的字符串。 该问题保证至少有一个字符，因此不需要处理空字符串输入。 

## 方法

 **暴力方法**是生成所有可能的子序列`s`，检查每个字符是否为回文、偶数长度以及不重复的相邻字符。 这种方法是正确的，因为它详尽地考虑了所有可能性，但它是不切实际的：生成子序列具有指数时间复杂度，特别是`O(2^n)`对于一个长度的字符串`n`，这对于`n`最多 250 个。 

**最佳方法**是使用动态规划。 我们定义`dp[i][j]`作为子串中最长的好回文子序列的长度`s[i:j+1]`。 我们迭代子字符串长度并填充`dp[i][j]`基于是否`s[i]`等于`s[j]`以及选择它们是否保持“无连续重复”属性。 我们的见解是，我们可以通过检查这些条件并跟踪最大有效长度，从较小的回文中构建较大的回文。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 生成所有子序列并检查条件 |
 | 最佳 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 通过检查连续重复项对子字符串索引进行 DP |

 ## 算法演练

 1.初始化一个2D DP数组`dp`尺寸的`n x n`用零填充，其中`n`是字符串的长度。 
2. 迭代所有子串`s`按长度`len_sub`从 2 到`n`。 
3. 对于从索引开始的每个子字符串`i`并以索引结束`j = i + len_sub - 1`，检查是否`s[i] == s[j]`。 
4. 如果字符相等，则查看子串内部`s[i+1:j]`求最长的有效子序列并确保添加`s[i]`和`s[j]`不违反“不能连续重复”的规则。 
5. 否则，取两者之间的最大值`dp[i+1][j]`和`dp[i][j-1]`。 
6. 记录在此过程中找到的最大偶数长度。 
7.返回存储在的最大长度`dp[0][n-1]`迭代所有子字符串后。 

**为什么它有效：** 这有效是因为每个`dp[i][j]`正确表示最长有效子序列`s[i:j+1]`通过考虑端点的所有可能选择。 通过从较小的子字符串构建到较大的子字符串，我们保证在使用之前解决所有依赖关系。 

## Python 解决方案```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        
        for i in range(n):
            dp[i][i] = 0  # single character cannot be even-length good palindrome

        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    if length == 2:
                        dp[i][j] = 2
                    elif s[i] != s[i + 1] and s[j] != s[j - 1]:
                        dp[i][j] = dp[i + 1][j - 1] + 2
                    else:
                        dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        
        return max(max(row) for row in dp)
```此实现初始化 DP 表，迭代地填充它，同时检查良好回文子序列的规则，并返回找到的最大长度。 单字符子串被初始化为零，因为它们不能形成偶数长度的回文。 

## 解决方案```go
func longestPalindromeSubseq(s string) int {
    n := len(s)
    dp := make([][]int, n)
    for i := 0; i < n; i++ {
        dp[i] = make([]int, n)
    }

    for length := 2; length <= n; length++ {
        for i := 0; i <= n - length; i++ {
            j := i + length - 1
            if s[i] == s[j] {
                if length == 2 {
                    dp[i][j] = 2
                } else if s[i] != s[i+1] && s[j] != s[j-1] {
                    dp[i][j] = dp[i+1][j-1] + 2
                } else {
                    dp[i][j] = max(dp[i+1][j], dp[i][j-1])
                }
            } else {
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])
            }
        }
    }

    maxLen := 0
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            if dp[i][j] > maxLen {
                maxLen = dp[i][j]
            }
        }
    }
    return maxLen
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```在 Go 中，实现使用切片的切片来创建 DP 表。 其逻辑与 Python 相似，通过仔细的索引检查来防止超出范围的错误。 辅助函数`max`用于简化比较。
