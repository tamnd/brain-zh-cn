[LeetCode 问题 1637](https://leetcode.com/problems/widest-vertical-area- Between-two-points-containing-no-points/)

 **难度：** 🟢简单
 **主题：** 数组、排序

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个 2D 平面上的点列表，其中每个点表示为`[x, y]`。 我们需要找到最宽的垂直区域，其中严格不包含任何点。 

垂直区域由两条垂直线定义。 由于该区域沿 y 轴无限延伸，因此只有 x 坐标重要。 y 值与确定垂直间隙的宽度完全无关。 

垂直区域的宽度就是两个 x 坐标之间的水平距离。 我们希望最大可能的宽度使得这两个 x 值之间严格不存在点。 

一个重要的细节是允许恰好位于边界上的点。 这意味着如果两个点有 x 坐标`x1`和`x2`，那么只要没有其他点的 x 值严格位于它们之间，它们之间的垂直区域就有效`x1`和`x2`。 

例如，考虑以下 x 值：```
1, 3, 5, 9
```差距是：

 - 1 和 3 之间 → 宽度 2
 - 3 和 5 之间 → 宽度 2
 - 5 和 9 之间 → 宽度 4

 答案是`4`。 

约束条件很重要：

 -`2 <= n <= 10^5`-`0 <= xi, yi <= 10^9`由于点数量最多可达 100,000 个，因此低效的二次解法速度会太慢。 我们需要一个接近的算法`O(n log n)`或更好。 

有几个重要的边缘情况：

 - 多个点可以共享相同的 x 坐标。 
- 排序后，最宽的间隙可能出现在开头或结尾。 
- 大坐标值需要小心处理，但标准整数类型就足够了。 
- y 坐标根本不影响答案。 

该问题保证至少有两个点，因此总会有至少一个垂直间隙可供评估。 

## 方法

 ### 蛮力方法

 一种简单的方法是比较每对点，并检查是否存在另一个点，其 x 坐标严格位于它们之间。 

对于每对`(xi, xj)`：

 1. 计算宽度`abs(xi - xj)`。 
2. 扫描所有其他点。 
3. 验证是否有任何点严格位于区间内。 

如果区间内不存在点，则宽度就是候选答案。 

这种方法是正确的，因为它明确地检查每个可能的垂直区域。 然而，它太慢了。 

有`O(n^2)`对，对于每一对，我们可以扫描所有`n`点，导致`O(n^3)`时间复杂度。 

即使是稍微优化的版本（在没有内部验证的情况下检查所有对）对于`n = 10^5`。 

### 关键见解

 关键的观察结果是只有排序后的 x 坐标才重要。 

假设我们对所有 x 值进行排序：```
x1 <= x2 <= x3 <= ... <= xn
```最宽的有效垂直区域必须位于按排序顺序的两个连续 x 值之间。 

为什么？ 

因为如果它们之间还有另一个 x 坐标，那么该区域将包含一个点并且不会是空的。 

因此，排序后，我们只需要计算：```
x[i] - x[i - 1]
```对于每一个相邻的对。 

最大相邻差就是答案。 

排序将问题从几何问题转化为简单的数组间隙问题。

 ## 算法演练

 1. 从输入点中提取所有 x 坐标。 

y 坐标无关紧要，因为垂直区域向上和向下无限延伸。 只有水平距离很重要。 
2. 按升序对 x 坐标进行排序。 

排序将所有点按顺序沿 x 轴排列，从而可以轻松识别连续的间隙。 
3. 初始化一个变量来存储目前找到的最大宽度。 

开始于`0`因为宽度是非负的。 
4. 从索引开始迭代已排序的 x 值`1`。 

对于每个位置：

 - 计算间隙：```
current_gap = x[i] - x[i - 1]
```- 如果此间隙较大，则更新最大宽度。 
5. 返回处理完所有相邻对后的最大宽度。 

### 为什么它有效

 排序后，任何有效的空白垂直区域必须位于两个连续的 x 坐标之间。 如果两个 x 值不连续，则它们之间至少存在一个其他点，这意味着该区域不为空。 

因此，排序数组中最大的相邻差恰好代表不包含点的最宽垂直区域。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxWidthOfVerticalArea(self, points: List[List[int]]) -> int:
        x_coordinates = sorted(point[0] for point in points)

        max_width = 0

        for i in range(1, len(x_coordinates)):
            current_width = x_coordinates[i] - x_coordinates[i - 1]
            max_width = max(max_width, current_width)

        return max_width
```实现首先使用生成器表达式提取所有 x 坐标。 由于只有 x 值很重要，因此我们完全忽略 y 值。 

然后，x 坐标按升序排序。 一旦排序，每个相邻的对代表这些位置之间的最小可能间隔。 

循环从索引处开始`1`因为每个间隙都是根据前一个元素计算的。 

对于每个相邻对，该算法计算宽度并更新迄今为止找到的最大值。 

最后返回最大宽度。 

实现很简洁，因为关键见解极大地简化了问题。 

## 解决方案```go
package main

import "sort"

func maxWidthOfVerticalArea(points [][]int) int {
	xCoordinates := make([]int, len(points))

	for i, point := range points {
		xCoordinates[i] = point[0]
	}

	sort.Ints(xCoordinates)

	maxWidth := 0

	for i := 1; i < len(xCoordinates); i++ {
		currentWidth := xCoordinates[i] - xCoordinates[i-1]

		if currentWidth > maxWidth {
			maxWidth = currentWidth
		}
	}

	return maxWidth
}
```Go 解决方案遵循与 Python 实现相同的逻辑。 

分配一个切片来存储所有 x 坐标。 内置的`sort.Ints()`函数按升序对切片进行排序。 

然后该算法扫描相邻元素并跟踪最大差异。 

去的`int`type 可以安全地处理此问题中的坐标范围，因为最大差异最多为`10^9`。

 ## 边缘情况

 ### 具有相同 x 坐标的多个点

 错误的常见来源是假设所有 x 值都是唯一的。 如果多个点共享相同的 x 坐标，则它们之间的间隙为零。 

例如：```
[[1,1], [1,5], [1,10]]
```排序后，所有相邻的差异都是`0`，所以答案是`0`。 

该实现自然地处理了这个问题，因为相邻的减法正确地产生零。 

### 只有两点

 最小的可能输入恰好包含两个点。 

例如：```
[[1,1], [10,10]]
```只有一个可能的垂直间隙，其宽度`9`。 

该实现正确地处理了这个问题，因为循环只运行一次。 

### 非常大的坐标值

 坐标可以大到`10^9`。 

例如：```
[[0,0], [1000000000,1]]
```答案是`1000000000`。 

该算法仅执行减法和排序，这两者在 Python 和 Go 中的标准整数限制内都是安全的。
