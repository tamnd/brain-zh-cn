[LeetCode 问题 1623](https://leetcode.com/problems/all-valid-triplets-that-can-represent-a-country/)

 **难度：** 🟢简单
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们生成来自三所学校代表一个国家的所有有效三元组学生：`SchoolA`,`SchoolB`， 和`SchoolC`。 每个三联体由每所学校的一名学生组成，并且只有当所有三名学生都具有不同的姓名和不同的 ID 时，三联体才有效。 

输入由三个数据库表组成，每个表代表一所学校。 每张桌子都有独特的`student_id`价值观和独特的`student_name`该学校的价值观。 学校之间的学生不存在重叠，因此算法在形成三元组时必须检查姓名和 ID 冲突。 输出是任意顺序的有效三元组列表，其中每个三元组包含从以下位置选择的学生的姓名`SchoolA`,`SchoolB`， 和`SchoolC`。 

主要限制因素包括：

 - 学生在学校内是独一无二的。 
- 有效的三元组需要成对不同的名称和 ID。 
- 桌子的大小可能不同，因此解决方案应正确处理空桌子或只有一名学生的桌子。 

重要的边缘情况：

 - 一所或多所没有学生的学校不应培养三胞胎。 
- 学校间重复的姓名或身份证可能会取消许多三胞胎的资格。 
- 如果每所学校只有一名学生，则应正确处理最少的输入（如果它们不同）。 

## 方法

 ### 蛮力

 暴力解决方案考虑了每所学校一名学生的每一种组合。 对于每个组合，它会检查所有三个名称和所有三个 ID 是否不同。 如果是，则将三元组添加到结果中。 

这种方法是正确的，因为它明确地测试了所有可能的三元组。 但其时间复杂度为$O(n \cdot m \cdot k)$在哪里`n`,`m`， 和`k`的尺寸为`SchoolA`,`SchoolB`， 和`SchoolC`， 分别。 如果每所学校有数百名学生，这种方法可能会生成数百万个组合，这可能效率低下。 

### 最佳方法

 由于我们必须检查学校之间姓名和 ID 的成对唯一性，因此没有捷径可以完全避免测试组合。 蛮力组合方法对于正确性而言实际上是最佳的，但我们可以通过在生成三元组之前过滤掉一所学校中与另一所学校的所有学生发生冲突的学生来进行稍微优化。 这减少了不必要的检查，但并没有从根本上改变复杂性。 

关键的见解是，由于表通常并不庞大，因此生成所有组合并按独特性进行过滤既简单又有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m * k) | O(n * m * k) | O(n * m * k) | O(n * m * k) | 明确检查所有三元组，过滤无效的三元组。 |
 | 优化过滤 | O(n * m * k) | O(n * m * k) | O(n * m * k) | O(n * m * k) | 对有冲突的学生进行轻微的预过滤，仍然检查所有三元组。 |

 ## 算法演练

 1. 检索所有学生`SchoolA`,`SchoolB`， 和`SchoolC`。 
2. 初始化一个空的结果表来存储有效的三元组。 
3. 迭代每个学生`SchoolA`作为`a`。 
4. 对于每个`a`，迭代每个学生`SchoolB`作为`b`。 
5. 跳过组合，其中`a.student_id == b.student_id`或者`a.student_name == b.student_name`。 
6. 对于每个有效`(a, b)`配对，迭代每个学生`SchoolC`作为`c`。 
7. 跳过组合`c`与任一冲突`a`或者`b`在`student_id`或者`student_name`。 
8. 如果所有三个学生的 ID 和姓名均不同，则添加`(a.student_name, b.student_name, c.student_name)`到结果。 
9. 返回结果表。 

**为什么有效**：该算法显式检查所有组合并强制执行对名称和 ID 的约束。 因为它测试每个可能的三元组，所以它保证不会遗漏任何有效的三元组，也不包含无效的三元组。 

## Python 解决方案```python
# LeetCode uses SQL-style database problems, but we can simulate using Python
from typing import List, Dict

def all_valid_triplets(schoolA: List[Dict], schoolB: List[Dict], schoolC: List[Dict]) -> List[Dict]:
    result = []
    for a in schoolA:
        for b in schoolB:
            if a['student_id'] == b['student_id'] or a['student_name'] == b['student_name']:
                continue
            for c in schoolC:
                if (c['student_id'] in {a['student_id'], b['student_id']} or
                    c['student_name'] in {a['student_name'], b['student_name']}):
                    continue
                result.append({
                    'member_A': a['student_name'],
                    'member_B': b['student_name'],
                    'member_C': c['student_name']
                })
    return result
```The implementation iterates over all combinations of students from the three schools. 它使用简单`if`检查以强制成对的唯一性。 使用集合进行检查`c`反对`(a, b)`确保正确性和可读性。 

## 解决方案```go
package main

type Student struct {
    StudentID   int
    StudentName string
}

type Triplet struct {
    MemberA string
    MemberB string
    MemberC string
}

func AllValidTriplets(schoolA, schoolB, schoolC []Student) []Triplet {
    var result []Triplet
    for _, a := range schoolA {
        for _, b := range schoolB {
            if a.StudentID == b.StudentID || a.StudentName == b.StudentName {
                continue
            }
            for _, c := range schoolC {
                if c.StudentID == a.StudentID || c.StudentID == b.StudentID ||
                   c.StudentName == a.StudentName || c.StudentName == b.StudentName {
                    continue
                }
                result = append(result, Triplet{MemberA: a.StudentName, MemberB: b.StudentName, MemberC: c.StudentName})
            }
        }
    }
    return result
}
```Go 实现反映了 Python 逻辑。 它使用切片作为输入表和一个简单的`append`用于积累结果。 Go 的强类型确保我们无需转换即可显式处理 ID 和名称。
