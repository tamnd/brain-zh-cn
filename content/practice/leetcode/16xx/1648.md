## 问题理解

 问题要求我们出售`orders`以**最大化获得的总价值**的方式从不同颜色的球的库存中选择球的数量。 每个球的价值都会根据剩余的颜色数量而递减。 例如，如果某种颜色有 5 个球，则第一个售出的球价值 5，接下来的价值 4，依此类推，直到该颜色的最后一个球价值 1。 

输入由一个数组组成`inventory`在哪里`inventory[i]`代表颜色球的数量`i`，和一个整数`orders`代表顾客想要多少个球。 产出是精确销售的最大总价值`orders`球，模数`10^9 + 7`。 

约束告诉我们输入可以很大：最多`10^5`颜色和球数最多`10^9`。 一次迭代一个球的天真的方法太慢了，因为`orders`也可能达到`10^9`。 

关键的边缘情况包括销售的球少于总库存、所有球的价值相同或数量非常大而存在整数溢出的风险。 问题保证`orders`永远有效，所以我们的销量永远不会超过我们的数量。 

## 方法

 **蛮力法**：天真的方法是反复出售当前价值最高的球。 您可以使用最大堆来始终选择最大的可用球，减少其计数并累加值。 虽然这给出了正确的答案，但对于约束来说太慢了，因为每个订单操作都可能需要`O(log n)`与堆，导致`O(orders * log n)`时间，这是不可行的`orders`可以是`10^9`。 

**最佳方法**：一个关键的观察结果是，问题可以简化为**以相同价值的块出售球**。 我们可以按降序对库存进行排序，然后确定在每个“价值级别”可以有效销售多少个球。 我们不是逐一出售，而是计算出售整个价值范围的总利润`high`到`low`使用算术级数和公式：$$\text{sum} = \frac{(high + low + 1) * (high - low)}{2} * \text{count\_of\_colors}$$这种方法是**贪婪**，总是首先删除具有最高值的球，并允许我们在恒定时间内计算块的总和。 排序使得这个`O(n log n)`为了`n`颜色。

 ## 算法演练

 1. **按降序对库存进行排序**，以便首先处理具有最多球的颜色。 这确保了价值最高的球首先被出售。 
2. **在排序后的数组末尾添加一个零**作为哨兵，以简化处理最后一个值块时的计算。 
3. **迭代清单**。 每一步计算差异`diff = current_value - next_value`。 这代表了我们当前这组球可以出售的价值级别数量。 
4. **计算我们可以从这个区块中出售多少个球**：`count = diff * number_of_colors_at_this_level`。 
5.如果`orders >= count`，使用等差数列求和公式出售该区块中的所有球并递减`orders`经过`count`。 
6. 如果`orders < count`，我们不能出售整个区块。 计算我们可以单独出售和处理多少个**完整价值级别**。 
7. **使用模数`10^9 + 7`** 所有累计金额以避免溢出。 
8. 继续直到`orders`达到零。 

**为什么有效**：贪婪不变量是首先出售价值最高的球可以实现利润最大化。 通过批量销售而不是单独销售，我们确保了效率，同时保持了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxProfit(self, inventory: List[int], orders: int) -> int:
        MOD = 10**9 + 7
        inventory.sort(reverse=True)
        inventory.append(0)  # sentinel
        profit = 0
        n = 1  # number of colors at current value
        
        for i in range(len(inventory) - 1):
            if inventory[i] > inventory[i + 1]:
                diff = inventory[i] - inventory[i + 1]
                total = diff * n
                if orders >= total:
                    # Sell full levels
                    profit += n * (inventory[i] + inventory[i + 1] + 1) * diff // 2
                    orders -= total
                else:
                    # Sell partial levels
                    full, remainder = divmod(orders, n)
                    profit += n * (2 * inventory[i] - full + 1) * full // 2
                    profit += remainder * (inventory[i] - full)
                    return profit % MOD
            n += 1
        
        return profit % MOD
```**说明**：为了简单起见，我们对库存进行降序排序并附加零。 我们跟踪有多少颜色共享当前最高值（`n`）。 对于每个块差，如果我们可以出售所有球，我们使用算术求和公式。 如果没有，我们计算有多少个完整价值水平和剩余球要出售并返回模数`10^9 + 7`。 

## 解决方案```go
package main

import "sort"

func maxProfit(inventory []int, orders int) int {
    const MOD = int(1e9 + 7)
    sort.Sort(sort.Reverse(sort.IntSlice(inventory)))
    inventory = append(inventory, 0)
    profit := 0
    n := 1 // number of colors at current level

    for i := 0; i < len(inventory)-1; i++ {
        if inventory[i] > inventory[i+1] {
            diff := inventory[i] - inventory[i+1]
            total := diff * n
            if orders >= total {
                profit += n * (inventory[i] + inventory[i+1] + 1) * diff / 2
                orders -= total
            } else {
                full := orders / n
                remainder := orders % n
                profit += n * (2*inventory[i] - full + 1) * full / 2
                profit += remainder * (inventory[i] - full)
                return profit % MOD
            }
        }
        n++
    }

    return profit % MOD
}
```**Go 特定注释**：Go 需要显式排序`sort.IntSlice`并谨慎使用整数除法。 切片与附加哨兵一起使用，类似于 Python。 

## 工作示例

 **示例1**：`inventory = [2,5], orders = 4`排序：`[5,2,0]`步骤一：`diff = 5-2=3`,`n=1`,`total=3`。 订单=4 ≥ 3 → 卖出全部3个球：利润+= (5+3+1)*3/2 = 5+4+3=12，订单=1

 步骤2：`diff = 2-0=2`,`n=2`，总计=4。 订单=1 < 4 → 卖出 0 个满级，余数=1 → 利润 += 余数*(current_value)=1*2=2

 利润总额=12+2=14

 **示例2**：`inventory = [3,5], orders = 6`排序：`[5,3,0]`步骤一：`diff=5-3=2`,`n=1`，总计=2。 订单=6 ≥2 → 利润+= (5+4)*2/2=9, 订单=4

 步骤2：`diff=3-0=3`,`n=2`，总计=6。 订单=4 < 6 → 满=4/2=2，剩余=0 → 利润 += 2*(3+2)/2_2=2_(5)*2/2=10

 利润总额=9+10=19
