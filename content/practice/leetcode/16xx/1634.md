[LeetCode 问题 1634](https://leetcode.com/problems/add-two-polynomials-represented-as-linked-lists/)

 **难度：** 🟡 中等
 **主题：** 链表、数学、两个指针

 ## 解决方案

 ## 问题理解

 这个问题要求我们添加两个表示为单链表的多项式。 链表中的每个节点代表多项式的一项，带有系数和幂。 链表严格按照幂降序排序，系数为零的项不会出现。 例如，多项式`2x^2 + 4x + 3`将表示为`[[2,2],[4,1],[3,0]]`。 

输入是两个这样的链表的头，`poly1`和`poly2`，我们将生成一个新的链表，表示这些多项式的和，也按幂降序排列，省略系数为零的项。 

约束告诉我们，每个多项式最多可以有 10,000 项，系数的大小可以非常大（最多 10^9），并且幂也可以非常大（最多 10^9）。 然而，这些列表的功效严格递减，并且没有系数最初为零。 

边缘情况包括完全不相交的幂、相互抵消产生零系数的项以及空多项式。 该问题保证输入列表是排序的，这对于有效的解决方案至关重要。 

## 方法

 蛮力方法是遍历每个多项式并将每个项插入到由幂键控的字典中。 然后，将具有相同幂的项的系数相加，并按降序重建一个新的链表。 这是可行的，但需要在最后对幂进行排序，从而给出 O(n log n) 时间复杂度和字典的额外空间。 

最佳方法利用了输入列表已按幂降序排序的事实。 使用双指针技术，我们可以同时遍历两个列表，比较每一步的幂。 如果幂相等，我们将系数相加。 如果其中一个幂更大，我们会将该项附加到结果中。 这自然地保留了降序并避免了额外的排序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 使用字典对项求和，然后对幂进行排序 |
 | 最佳 | O(n + m) | O(1) | O(1) | 无需额外排序的两指针遍历 |

 ## 算法演练

 1. 初始化一个虚拟节点作为结果链表的头。 使用指针`current`在我们构建结果列表时跟踪结果列表的末尾。 
2.初始化两个指针，`p1`和`p2`, 到`poly1`和`poly2`。 
3. 虽然两者`p1`和`p2`不为空：

 - 比较权力`p1.power`和`p2.power`。 
- 如果`p1.power > p2.power`, 附加`p1`到结果并移动`p1`向前。 
- 如果`p1.power < p2.power`, 附加`p2`到结果并移动`p2`向前。 
- 如果`p1.power == p2.power`，对系数求和。 如果总和不为零，则使用求和系数和相同幂创建一个新节点，然后将其附加到结果中。 两者都移动`p1`和`p2`向前。 
4. 循环结束后，追加以下剩余节点`p1`或者`p2`到结果。 
5. 返回`dummy.next`作为新多项式的头。 

**为什么有效：**

 两指针技术保证我们按照幂的降序处理所有项。 具有相同幂的项被合并，并且零系数的项被省略。 结果保持排序，无需额外排序。 

## Python 解决方案```python
# Definition for polynomial singly-linked list.
# class PolyNode:
#     def __init__(self, x=0, y=0, next=None):
#         self.coefficient = x
#         self.power = y
#         self.next = next

class Solution:
    def addPoly(self, poly1: 'PolyNode', poly2: 'PolyNode') -> 'PolyNode':
        dummy = PolyNode()
        current = dummy
        p1, p2 = poly1, poly2

        while p1 and p2:
            if p1.power > p2.power:
                current.next = PolyNode(p1.coefficient, p1.power)
                p1 = p1.next
            elif p1.power < p2.power:
                current.next = PolyNode(p2.coefficient, p2.power)
                p2 = p2.next
            else:
                summed_coeff = p1.coefficient + p2.coefficient
                if summed_coeff != 0:
                    current.next = PolyNode(summed_coeff, p1.power)
                p1 = p1.next
                p2 = p2.next
            if current.next:
                current = current.next

        while p1:
            current.next = PolyNode(p1.coefficient, p1.power)
            current = current.next
            p1 = p1.next

        while p2:
            current.next = PolyNode(p2.coefficient, p2.power)
            current = current.next
            p2 = p2.next

        return dummy.next
```该实现反映了该算法。 我们使用虚拟节点来简化附加操作。 这`while`循环比较权力来决定附加哪个节点。 当幂匹配时，我们对系数求和，并且仅在非零时附加。 其余节点随后附加。 

## 解决方案```go
type PolyNode struct {
    Coefficient int
    Power       int
    Next        *PolyNode
}

func addPoly(poly1 *PolyNode, poly2 *PolyNode) *PolyNode {
    dummy := &PolyNode{}
    current := dummy
    p1, p2 := poly1, poly2

    for p1 != nil && p2 != nil {
        if p1.Power > p2.Power {
            current.Next = &PolyNode{Coefficient: p1.Coefficient, Power: p1.Power}
            p1 = p1.Next
        } else if p1.Power < p2.Power {
            current.Next = &PolyNode{Coefficient: p2.Coefficient, Power: p2.Power}
            p2 = p2.Next
        } else {
            sum := p1.Coefficient + p2.Coefficient
            if sum != 0 {
                current.Next = &PolyNode{Coefficient: sum, Power: p1.Power}
            }
            p1 = p1.Next
            p2 = p2.Next
        }
        if current.Next != nil {
            current = current.Next
        }
    }

    for p1 != nil {
        current.Next = &PolyNode{Coefficient: p1.Coefficient, Power: p1.Power}
        current = current.Next
        p1 = p1.Next
    }

    for p2 != nil {
        current.Next = &PolyNode{Coefficient: p2.Coefficient, Power: p2.Power}
        current = current.Next
        p2 = p2.Next
    }

    return dummy.Next
}
```在 Go 中，主要区别在于使用`nil`而不是`None`和显式结构初始化。 逻辑和流程与 Python 相同。 

## 工作示例

 ### 示例 1

 输入：`poly1 = [[1,1]]`,`poly2 = [[1,0]]`初始指针：`p1=1x^1`,`p2=1x^0`比较权力：`1 > 0`, 附加`1x^1`进步`p1`→ 无

 追加剩余的`p2=1x^0`输出：`[[1,1],[1,0]]`### 示例 2

 输入：`poly1 = [[2,2],[4,1],[3,0]]`,`poly2 = [[3,2],[-4,1],[-1,0]]`逐步：

 | p1 | p2| 行动| 结果列表 |
 | --- | --- | --- | --- |
 | 2x^2 | 2x^2 3x^2 | 3x^2 总和=5 | 5x^2 | 5x^2
 | 4x^1 | 4x^1 -4x^1 | -4x^1 总和=0 | 跳过|
 | 3x^0 | 3x^0 -1x^0 | -1x^0 总和=2 | 2x^0 | 2x^0

 输出：`[[5,2],[2,0]]`### 示例 3

 输入：`poly1 = [[1,2]]`,`poly2 = [[-1,2]]`幂 2 的总和：`1 + (-1) = 0`→ 跳过

 没有剩余节点

 输出：`[]`## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + m) | 每个列表都被遍历一次，其中n和m是poly1和poly2 | 的长度。 
| 空间| O(1) | O(1) | 仅使用指针和结果列表； 我们不使用与输入成正比的额外空间 |

 鉴于我们必须检查每个术语一次，复杂性是最佳的。
