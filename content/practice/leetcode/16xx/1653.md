[LeetCode 问题 1653](https://leetcode.com/problems/minimum-deletions-to-make-string-balanced/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划、堆栈

 ## 解决方案

 ## 问题理解

 问题要求我们制作一个仅包含字符的字符串`'a'`和`'b'`**平衡**通过删除最小数量的字符。 如果没有出现以下情况，则认为字符串是**平衡的**`'b'`出现在`'a'`在字符串中。 换句话说，所有`'a'`字符必须出现在任何字符之前`'b'`字符，或者等效地，字符串可以被分割成前缀`'a'`s 后跟后缀`'b'`s，中间可能有删除。 

输入是一个字符串`s`长度可达100,000。 输出是一个整数，表示实现平衡状态所需的最小删除量。 约束告诉我们，解决方案必须高效（可能是线性时间），因为二次或更高的方法会太慢。 

重要的边缘情况包括已经平衡的字符串、完全由以下组成的字符串`'a'`或`'b'`s 和交替的字符串`'a'`沙`'b'`可能需要删除全文。 

## 方法

 蛮力方法是考虑每个可能的删除子集，以实现所有的字符串`'a'`s 后面跟着所有`'b'`s。 这涉及到检查所有组合，对于长度高达 100,000 的字符串来说，这在计算上是不可行的，因为它具有指数复杂度。 

最佳解决方案的关键观察是我们可以线性处理字符串，同时跟踪两个计数器：`'b'`到目前为止遇到的 s 以及所需的最小删除次数。 在每个位置，我们有两个选择：要么删除当前的`'a'`如果它发生在之后`'b'`s，或计算当前`'b'`作为应该保留的序列的一部分。 通过迭代字符串并相应地更新最小删除，我们可以在线性时间内解决这个问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 检查所有可能的删除子集以找到最小删除 |
 | 最佳 | O(n) | O(1) | O(1) | 线性扫描跟踪`'b'`动态计数和最小删除|

 ## 算法演练

 1. 初始化两个计数器：`b_count = 0`跟踪`'b'`遇到并且`deletions = 0`存储当前所需的最少删除内容。 
2. 遍历字符串中的每个字符`s`。 
3. 如果当前字符是`'b'`, 增量`b_count`因为它可能是有效后缀的一部分`'b'`s。 
4. 如果当前字符是`'a'`，我们有两个选择：删除这个`'a'`（增量`deletions`通过 1) 或考虑删除一些`'b'`到目前为止我们看到保持平衡。 更新`deletions`为最小值`deletions + 1`和`b_count`。 
5. 继续迭代直到字符串末尾。 
6. 返回`deletions`作为使字符串平衡所需的最小删除次数。 

为什么它有效：该算法在每一步都保持不变，`deletions`表示到目前为止处理的前缀达到平衡所需的最小删除量。 它正确地处理了删除之间的权衡`'a'`或`'b'`s 在每个冲突点。 

## Python 解决方案```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        b_count = 0
        deletions = 0
        
        for char in s:
            if char == 'b':
                b_count += 1
            elif char == 'a':
                deletions = min(deletions + 1, b_count)
        
        return deletions
```这个 Python 实现完全遵循该算法。 我们维持`b_count`追踪数量`'b'`s 可能是平衡后缀的一部分。 对于每个`'a'`遇到了，我们决定是否删除这个更便宜`'a'`或删除所有以前的`'b'`来保持平衡。 这`min`操作确保我们在每一步总是有最少的删除。 

## 解决方案```go
func minimumDeletions(s string) int {
    bCount := 0
    deletions := 0

    for i := 0; i < len(s); i++ {
        if s[i] == 'b' {
            bCount++
        } else if s[i] == 'a' {
            if deletions+1 < bCount {
                deletions++
            } else {
                deletions = bCount
            }
        }
    }

    return deletions
}
```在 Go 中，逻辑是相同的。 我们使用整数计数器`bCount`和`deletions`。 该循环使用索引迭代字符串。 这`if`语句确保我们选择删除当前项之间的最小值`'a'`或删除所有前面的`'b'`s 实现前缀平衡。
