[LeetCode 问题 1681](https://leetcode.com/problems/minimum-incompatibility/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、动态规划、位操作、位掩码

 ## 解决方案

 ## 问题理解

 问题是要求我们对整数数组进行分区`nums`准确地进入`k`大小相等的子集，使得子集不包含重复元素。 子集的**不兼容性**定义为其最大值和最小值之间的差异。 我们的目标是在最佳分区后找到所有子集中这些不兼容性的最小可能总和，或者返回`-1`如果不存在有效分区。 

输入`nums`表示一个整数数组，其中每个元素都在 1 和`nums.length`。 整数`k`确定我们需要形成的子集的数量以及约束`nums.length % k == 0`确保每个子集具有相同的大小`n = nums.length / k`。 

主要限制和影响是：

 -`1 <= nums.length <= 16`意味着数组足够小，可以考虑对子集进行位掩码或动态编程。 
-`nums[i] <= nums.length`允许我们有效地使用频率计数或基于集合的检查。 
- 子集不能有重复的元素； 因此，如果任何元素出现超过`k`有时，有效的分配是不可能的。 

重要的边缘情况包括：

 - 重复项超过的数组`k`发生的事件，必须返回`-1`。 
- 所有元素都相同的数组，这也可能导致不可能的分布。 
- 最小尺寸的数组，例如，`nums.length == k`，其中每个子集将恰好包含一个元素，从而使不兼容性和为零。 

## 方法

 蛮力方法将涉及生成所有可能的分区`nums`进入`k`子集并计算每个有效分区的不兼容性总和。 这保证是正确的，但效率非常低，因为分区的数量随着`nums.length`。 和`nums.length`最多 16 个，这在计算上是不可行的。 

更好的解决方案的关键洞察是利用**位掩码动态编程**。 DP 中的每个状态代表我们已经使用的元素的子集，编码为位掩码。 我们迭代所有组合`subset_size = n/k`元素，预先计算有效子集的不兼容性，如果子集可以添加到当前掩码而不重复元素，则更新 DP 状态。 这将问题从阶乘复杂性降低到可以使用以下方法管理的程度`2^n`状态与有效的子集枚举相结合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((nums.length!) / (subset_size!)^k) | O((nums.length!) / (subset_size!)^k) | O(nums.length) | O(nums.length) | 生成所有分区，过滤无效分区，求和不兼容项 |
 | 位掩码 DP | O(3^n) | O(3^n) | O(2^n) | O(2^n) | 将 DP 与子集掩码结合使用，预先计算有效子集及其不兼容性 |

 ## 算法演练

 1. 计算每个子集的大小：`subset_size = len(nums) // k`。 
2. 检查是否有元素出现超过`k`次。 如果是，则返回`-1`立即，因为不存在有效的分区。 
3. 预先计算所有有效的大小子集`subset_size`没有重复项。 对于每个有效子集，计算其不兼容性（最大值 - 最小值）并将其存储在由表示该子集的位掩码键入的字典中。 
4. Initialize a DP array of size`2^n`和`inf`， 在哪里`dp[mask]`表示由以下元素表示的元素子集的不兼容性的最小总和`mask`。 放`dp[0] = 0`。 
5. Iterate over each DP mask. 对于每个掩码，尝试添加一个不与已使用的元素重叠的有效子集（使用按位 AND 进行检查）。 使用不兼容性之和更新新掩码的 DP 值。 
6. 处理完所有掩码后，包含所有元素的掩码处的 DP 值（`(1 << n) - 1`) 给出最小总和。 如果还是这样的话`inf`， 返回`-1`。 

**为什么有效：** DP 保证每个状态只考虑不重叠的有效子集。 通过迭代所有可能的子集并增量更新 DP，我们探索所有可行的分区，同时避免子集中的重复。 因此，最低金额是有保证的。 

## Python 解决方案```python
from typing import List
from itertools import combinations

class Solution:
    def minimumIncompatibility(self, nums: List[int], k: int) -> int:
        from collections import Counter
        n = len(nums)
        subset_size = n // k
        
        # Early check for impossible cases
        if any(v > k for v in Counter(nums).values()):
            return -1
        
        # Map each valid subset (bitmask) to its incompatibility
        nums_index = list(range(n))
        valid_subsets = {}
        for combo in combinations(nums_index, subset_size):
            elements = [nums[i] for i in combo]
            if len(set(elements)) == subset_size:  # ensure no duplicates
                mask = sum(1 << i for i in combo)
                valid_subsets[mask] = max(elements) - min(elements)
        
        # Initialize DP
        INF = float('inf')
        dp = [INF] * (1 << n)
        dp[0] = 0
        
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            for submask, incompat in valid_subsets.items():
                if mask & submask == 0:
                    dp[mask | submask] = min(dp[mask | submask], dp[mask] + incompat)
        
        return dp[(1 << n) - 1] if dp[(1 << n) - 1] != INF else -1
```**说明：** 我们首先使用元素频率检查不可能分布。 接下来，使用组合预先计算所需大小的所有有效子集，确保没有重复。 然后，我们使用位掩码 DP 探索这些子集的所有组合而不重叠，从而增量更新最小不兼容总和。 最终的 DP 状态表示使用所有元素。 

## 解决方案```go
package main

import (
	"math"
)

func minimumIncompatibility(nums []int, k int) int {
	n := len(nums)
	subsetSize := n / k

	// Early check for impossible cases
	counts := make([]int, n+1)
	for _, v := range nums {
		counts[v]++
		if counts[v] > k {
			return -1
		}
	}

	// Precompute all valid subsets of size subsetSize
	validSubsets := map[int]int{}
	for mask := 0; mask < (1 << n); mask++ {
		if bitCount(mask) == subsetSize {
			seen := map[int]bool{}
			minVal, maxVal := math.MaxInt32, math.MinInt32
			valid := true
			for i := 0; i < n; i++ {
				if mask&(1<<i) != 0 {
					if seen[nums[i]] {
						valid = false
						break
					}
					seen[nums[i]] = true
					if nums[i] < minVal {
						minVal = nums[i]
					}
					if nums[i] > maxVal {
						maxVal = nums[i]
					}
				}
			}
			if valid {
				validSubsets[mask] = maxVal - minVal
			}
		}
	}

	// DP
	INF := math.MaxInt32
	dp := make([]int, 1<<n)
	for i := range dp {
		dp[i] = INF
	}
	dp[0] = 0

	for mask := 0; mask < (1 << n); mask++ {
		if dp[mask] == INF {
			continue
		}
		for submask, incompat := range validSubsets {
			if mask&submask == 0 {
				newMask := mask | submask
				if dp[newMask] > dp[mask]+incompat {
					dp[newMask] = dp[mask] + incompat
				}
			}
		}
	}

	if dp[(1<<n)-1] == INF {
		return -1
	}
	return dp[(1<<n)-1]
}

func bitCount(x int) int {
	count := 0
	for x > 0 {
		count += x & 1
		x >>= 1
	}
	return count
}
```**Go 特定说明：** Go 需要手动进行位计数以验证子集大小。 我们使用`map[int]int`和`map[int]bool`用于频率和重复检查，以及用于 DP 的切片。`math.MaxInt32`用来表示无穷大。 

## 工作示例

 **示例1：**`nums = [1,2,1,4], k = 2`- 子集大小 = 2
 - 有效子集：`[1,2]`,`[1,4]`,`[2,4]`- DP迭代：

 - 从掩码 0 开始，dp[0] = 0
 - 添加`[1,2]`→ 掩码 = 0b0011，dp[0b0011] = 1
 - 添加`[1,4]`→ 掩码 = 0b0101，dp[0b0101] = 3
 - 合并不重叠的子集 → dp[0b1111] = 4
 - 返回 4
