## 问题理解

 该问题提出了一个具有微妙缺陷的二叉树：**恰好有一个无效节点**，其右子节点错误地指向**相同深度**但**位于其右侧的另一个节点**。 我们的任务是**删除无效节点及其子树**，同时保留树的其余部分。 

输入是二叉树的根。 在测试设置中，节点`fromNode`其右指针错误地指向`toNode`在同一深度。 我们的函数**没有收到`fromNode`或者`toNode`直接地**; 它必须通过树遍历来推断无效节点。 

约束条件很重要：

 - 所有节点值都是唯一的，这允许我们使用所见值的哈希图来跟踪节点。 
- 树可能很大，最多有 10,000 个节点，因此重复检查所有节点对的低效解决方案会太慢。 
- 该问题准确保证**一个无效节点**； 我们不需要处理多个错误。 
-`fromNode.right`在原始树中为空，因此无效的右指针是唯一的结构异常。 

需要注意的边缘情况包括无效节点为根的树、最后一级的无效节点或除了缺陷之外仅剩下子节点的树。 如果我们不仔细跟踪所看到的节点，这些可能会导致天真的遍历失败。 

## 方法

 **暴力方法：** 我们可以遍历每个节点，并且对于每个节点，扫描相同深度的所有节点以查看其右指针是否指向另一个节点。 一旦我们找到一个直接指向相同深度的另一个节点的节点，我们就删除它及其子树。 这是可行的，因为它直接检查无效指针，但效率很低：对于每个节点，扫描同一级别需要 O(n) 时间。 在最坏的情况下，这会变成 **O(n²)** 时间，这对于 n = 10⁴ 来说是不可接受的。 

**最佳方法：** 关键的观察结果是 BFS 层序遍历自然会暴露相同深度的节点。 如果我们逐层遍历树，我们可以维护一组**该层已经见过的节点**。 对于每个节点，如果其右子节点指向该集合中已有的节点，则该节点是无效节点。 然后我们可以通过将相应的父指针设置为空来删除它。 这种方法保证 **O(n)** 时间，因为每个节点都被访问一次，并且检查集合中的成员资格是 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 检查每个节点的相同深度的所有节点 |
 | 最优（带有哈希集的 BFS）| O(n) | O(n) | BFS 保证级别顺序并允许使用哈希集进行检测 |

 ## 算法演练

 1. **初始化一个队列**，以根节点进行BFS遍历。 
2. **在队列不为空的情况下**，逐级处理节点：

 1. 创建一个`set`被称为`seen`记录当前级别的所有节点。 
2. 对于当前级别的每个节点：

 1. 如果该节点有右子节点且`node.right`是在`seen`，这是**无效节点**。 
2. 通过将其父指针设置为空来删除无效节点。 
3. 否则，将该节点添加到`seen`。 
3. 将当前节点的子节点添加到队列中以处理下一级。 
3. 继续直到BFS遍历结束。 
4. 返回根节点，该节点现在指向更正后的树。 

**工作原理：** BFS 逐级处理节点，因此任何直接指向同一级别已存在节点的节点必定是无效节点。 不变的是`seen`包含当前深度左侧的所有节点，因此检查右指针`seen`可靠地检测到缺陷。 立即删除该节点可确保不会遍历其子节点，这符合问题要求。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque

class Solution:
    def correctBinaryTree(self, root: TreeNode) -> TreeNode:
        if not root:
            return None
        
        queue = deque([root])
        parent_map = {root: None}  # Keep track of parents to remove invalid node
        
        while queue:
            level_size = len(queue)
            seen = set()
            for _ in range(level_size):
                node = queue.popleft()
                
                # Check if the right child points to a node already seen
                if node.right and node.right in seen:
                    parent = parent_map[node]
                    if parent:
                        if parent.left == node:
                            parent.left = None
                        else:
                            parent.right = None
                    else:
                        root = None  # Edge case: root itself is invalid
                    return root  # Only one invalid node exists
                
                seen.add(node)
                
                if node.left:
                    queue.append(node.left)
                    parent_map[node.left] = node
                if node.right:
                    queue.append(node.right)
                    parent_map[node.right] = node
                    
        return root
```**说明：** 我们使用队列执行 BFS。`seen`跟踪当前级别的节点。`parent_map`允许我们通过更新父节点的指针来删除无效节点。 一旦检测到无效节点，我们就将其删除并返回纠正后的树。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func correctBinaryTree(root *TreeNode) *TreeNode {
    if root == nil {
        return nil
    }

    type pair struct {
        node   *TreeNode
        parent *TreeNode
    }

    queue := []pair{{root, nil}}

    for len(queue) > 0 {
        levelSize := len(queue)
        seen := make(map[*TreeNode]bool)

        for i := 0; i < levelSize; i++ {
            p := queue[0]
            queue = queue[1:]
            node := p.node
            parent := p.parent

            if node.Right != nil && seen[node.Right] {
                if parent != nil {
                    if parent.Left == node {
                        parent.Left = nil
                    } else {
                        parent.Right = nil
                    }
                } else {
                    root = nil
                }
                return root
            }

            seen[node] = true

            if node.Left != nil {
                queue = append(queue, pair{node.Left, node})
            }
            if node.Right != nil {
                queue = append(queue, pair{node.Right, node})
            }
        }
    }
    return root
}
```**说明：** Go 实现镜像 Python。 我们使用一个`pair`结构体来跟踪节点及其父节点。 一张地图`seen`检测到无效的右指针。 通过检查节点是否是其父节点的左子节点或右子节点，删除节点很简单。 

## 工作示例

 **示例1：** root = [1,2,3]，fromNode = 2，toNode = 3

 层序遍历：

 | 水平| 节点| 看过集| 行动|
 | --- | --- | --- | --- |
 | 0 | 1 | {} | 添加 1 到已看到的位置，将子项加入队列 [2,3] |
 | 1 | 2 | {} | 添加 2 到已看到的位置，左/右入队（无/3） |
 | 1 | 3 | {2} | 右指针没问题，加 3 即可看到 |

 检测无效：节点2右指向3，其中`seen`→ 删除节点 2

 **输出：** [1,null,3]

 **示例 2：** root = [8,3,1,7,null,9,4,2,null,null,null,5,6], fromNode = 7, toNode = 4

 层序遍历和已见集检测到7的右边指向已见的4→删除节点7及其子树2

 **输出：** [8,3,1,null,null,9,4,null,null,5,6]
