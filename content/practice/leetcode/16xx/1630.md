[LeetCode 1630 题](https://leetcode.com/problems/arithmetic-subarrays/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定数组的子数组是否可以重新排列以形成算术序列。 **算术序列**是连续元素之间的差异恒定的序列。 输入由一个数组组成`nums`整数和两个数组`l`和`r`表示多个子数组的开始和结束索引。 对于每个查询，我们将检查子数组的元素是否`nums[l[i]:r[i]+1]`可以重新排序为算术。 

预期输出是一个布尔值列表，每个查询一个，指示每个子数组是否可以形成算术序列。 约束表明数组长度相对较小（`n <= 500`），这使我们可以考虑直接对每个子数组进行排序，作为可行解决方案的一部分。 负数是可能的，因此解决方案必须处理一般整数值，而不仅仅是正数。 

重要的边缘情况包括仅具有两个元素的子数组（始终算术）、具有重复元素的子数组（可以形成差值为零的算术序列）以及具有不规则间隙（无法形成恒定差值）的子数组。 

## 方法

 ### 蛮力

 暴力方法很简单：对于每个查询，提取子数组，对其进行排序，然后检查连续元素之间的差异。 如果所有差异都相等，则将其标记为`true`; 否则，将其标记为`false`。 这是正确的，因为排序将子数组置于可以一致比较连续差异的唯一顺序，并且算术序列的属性仅取决于这些差异。 然而，单独对每个子数组进行排序的时间复杂度为`O(k log k)`每个查询，导致`O(m * k log k)`总体而言，对于最大约束，这可能会变得低效。 

### 最佳方法

 优化的关键观察是，我们可以通过使用子数组的最小值和最大值计算**预期差异**来避免排序。 如果一个子数组的长度`k`是算术，差`d`必须满足`d = (max - min) / (k - 1)`所有元素都应该适合这个均匀分布的序列。 通过检查每个元素是否与预期的差异对齐且不重复，我们可以确定子数组是否可以形成算术序列。 这避免了`O(k log k)`排序步骤，用线性扫描代替`O(k)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * k log k) | O(m * k log k) | O(k) | 对每个子数组进行排序并检查差异 |
 | 最佳| O(m * k) | O(k) | 使用 min、max 和集合来检查算术属性而不进行排序 |

 ## 算法演练

 1.初始化一个空的结果列表`answer`。 
2. 迭代每个查询`(l[i], r[i])`。 
3. 提取子数组`sub = nums[l[i]:r[i]+1]`。 
4. 计算`min_val`和`max_val`的子数组。 
5. 计算预期差异`d = (max_val - min_val) / (length - 1)`。 如果这不是整数，则子数组无法形成算术序列。 
6. 使用集合来跟踪所看到的元素。 对于每个元素`x`在子数组中，检查是否`(x - min_val) % d == 0`。 如果没有，请标记`false`。 如果在预期位置出现重复，则标记`false`。 
7. 如果所有元素都符合预期位置且没有冲突，则标记`true`。 
8. 将布尔结果附加到`answer`。 
9. 返回`answer`。 

工作原理：通过导出最小值和最大值的差值并检查位置，我们保证只有每个元素都与预期均匀间隔序列中的一个槽匹配时，该序列才能是算术序列。 这可以保持正确性而无需排序。 

## Python 解决方案```python
from typing import List

class Solution:
    def checkArithmeticSubarrays(self, nums: List[int], l: List[int], r: List[int]) -> List[bool]:
        answer = []
        for start, end in zip(l, r):
            sub = nums[start:end+1]
            length = end - start + 1
            min_val, max_val = min(sub), max(sub)
            if length == 2:
                answer.append(True)
                continue
            if (max_val - min_val) % (length - 1) != 0:
                answer.append(False)
                continue
            d = (max_val - min_val) // (length - 1)
            seen = set()
            valid = True
            for x in sub:
                if (x - min_val) % d != 0 or x in seen:
                    valid = False
                    break
                seen.add(x)
            answer.append(valid)
        return answer
```该代码首先处理长度为 2 的普通子数组，这些子数组始终是算术数组。 对于较长的子数组，它计算预期的差异`d`并使用集合来检查所有元素是否可以正确放置在算术序列中且没有重复。 如果任何检查失败，子数组就无法形成算术序列。 

## 解决方案```go
func checkArithmeticSubarrays(nums []int, l []int, r []int) []bool {
    answer := make([]bool, len(l))
    for i := 0; i < len(l); i++ {
        start, end := l[i], r[i]
        sub := nums[start : end+1]
        length := end - start + 1
        if length == 2 {
            answer[i] = true
            continue
        }
        minVal, maxVal := sub[0], sub[0]
        for _, v := range sub {
            if v < minVal {
                minVal = v
            }
            if v > maxVal {
                maxVal = v
            }
        }
        if (maxVal - minVal) % (length - 1) != 0 {
            answer[i] = false
            continue
        }
        d := (maxVal - minVal) / (length - 1)
        seen := make(map[int]bool)
        valid := true
        for _, v := range sub {
            if (v - minVal) % d != 0 || seen[v] {
                valid = false
                break
            }
            seen[v] = true
        }
        answer[i] = valid
    }
    return answer
}
```在 Go 中，我们明确地处理切片和映射。 与 Python 的主要区别在于使用`map[int]bool`而不是子数组的集合和切片语法。 边缘情况的处理方式相同。
