 ## 解决方案

 ## 问题理解

 该问题要求我们确定两个二叉表达式树是否等价，其中等价定义为表示相同算术表达式的树，对加法的顺序取模，因为加法是可交换的。 每个树节点包含一个`'+'`运算符（对于内部节点）或变量（对于叶节点）。 输入由此类二元表达式树的两个根节点组成。 预期输出是一个布尔值，`true`如果树是等价的并且`false`否则。 

约束指定每棵树的节点数为奇数，最多 4999 个节点，并且保证每个节点都是有效的二叉表达式树。 节点上的较小上限允许递归或基于 DFS 的解决方案。 重要的边缘情况包括具有单个节点（单个变量）的树、所有添加都以不同方式嵌套的树以及包含重复变量的树。 

## 方法

 简单或暴力的方法是尝试评估加法运算的所有可能的排列，这是不可行的，因为排列的数量随着操作数的数量呈阶乘增长。 这种方法原则上是正确的，但对于较大的树来说效率极低。 

更好的解决方案的关键观察是加法是可交换的和结合的。 这允许我们将每个表达式树表示为其叶变量的多重集（或计数器）。 通过递归地展平树并计算每个变量的出现次数，我们可以有效地比较两棵树。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成加法顺序的所有排列； 对于 n > 10 不可行 |
 | 最佳| O(n) | O(n) | 使用 DFS 将树展平为变量的多重集并进行比较 |

 ## 算法演练

 1. 定义递归辅助函数`flatten(node)`返回一个`Counter`子树中变量的个数`node`。 
2.如果`node`是`None`，返回一个空的`Counter`。 
3.如果`node.val`是一个变量（不是`'+'`），返回一个`Counter`包含计数为 1 的变量。 
4. 如果`node.val`是`'+'`,递归调用`flatten`在`node.left`和`node.right`，然后将两者合并`Counter`对象通过加法。 
5.使用助手将两者压平`root1`和`root2`一分为二`Counter`对象。 
6.比较两者`Counter`平等的对象。 返回`true`如果相等，`false`否则。 

**为什么有效：** 展平函数有效地计算每个子树的变量多重集。 由于加法是可交换和结合的，因此变量的和在不同的树形状下是不变的。 比较这些多重集可确保等效性，而无需考虑树结构。 

## Python 解决方案```python
from collections import Counter

# Definition for a binary tree node.
# class Node(object):
#     def __init__(self, val=" ", left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def checkEquivalence(self, root1: 'Node', root2: 'Node') -> bool:
        def flatten(node: 'Node') -> Counter:
            if not node:
                return Counter()
            if node.val != '+':
                return Counter([node.val])
            left_count = flatten(node.left)
            right_count = flatten(node.right)
            return left_count + right_count
        
        return flatten(root1) == flatten(root2)
```**实现说明：**`flatten`辅助函数按 DFS 顺序遍历树。 叶节点产生一个单元素计数器。 内部节点有`'+'`合并他们孩子的计数。 计数器的相等比较正确地捕获了加法的交换等价性。 

## 解决方案```go
package main

import "reflect"

// Definition for a binary tree node.
type Node struct {
    Val   string
    Left  *Node
    Right *Node
}

type Solution struct{}

func (s *Solution) CheckEquivalence(root1 *Node, root2 *Node) bool {
    var flatten func(node *Node) map[string]int
    flatten = func(node *Node) map[string]int {
        if node == nil {
            return map[string]int{}
        }
        if node.Val != "+" {
            return map[string]int{node.Val: 1}
        }
        leftMap := flatten(node.Left)
        rightMap := flatten(node.Right)
        for k, v := range rightMap {
            leftMap[k] += v
        }
        return leftMap
    }

    leftCount := flatten(root1)
    rightCount := flatten(root2)
    return reflect.DeepEqual(leftCount, rightCount)
}
```**Go 特定注释：** 我们使用`map[string]int`而不是`Counter`。 合并映射需要迭代键并递增计数。 相等性检查使用`reflect.DeepEqual`因为 Go 映射不支持直接相等比较。

 ## 边缘情况

 一个重要的边缘情况是两棵树都由单个叶节点组成。 假设每个节点有两个子节点的简单实现可能会失败。 我们的 flatten 函数通过返回叶节点的计数器来自然地处理这个问题。 

第二种边缘情况是变量出现多次。 计数器正确地累积出现次数，这确保了重复变量的准确比较。 

第三种边缘情况是不平衡树，例如`a+(b+(c+(d+e)))`与`((a+b)+c)+(d+e)`。 扁平化将这些变量转换为单个多组变量，确保无论树形状如何都能检测到等效性。 

这种方法可以正确缩放所有有效输入，保留加法的交换和关联属性，并无缝处理重复变量。
