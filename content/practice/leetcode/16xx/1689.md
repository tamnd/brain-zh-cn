 ## 解决方案

 ## 问题理解

 该问题要求我们确定求和为表示为字符串的给定十进制数所需的**正十进制数的最小数量**。 

**十进制数** 是一个数字，其数字仅包含`0`和`1`，并且它不能包含前导零。 例如：

-`101`有效，因为每个数字都是`0`或者`1`-`1100`有效
 -`112`无效，因为它包含`2`-`3001`无效，因为它包含`3`我们得到一个字符串`n`表示正十进制整数。 目标是返回总和等于的最小数量的十进制数`n`。 

为了更好地理解问题，请考虑输入`"32"`。 

我们想要构造这个数字`32`通过将十进制数相加。 一种有效的分解是：```
10
11
11
--
32
```这使用了 3 个十进制数，结果是最小可能的答案。 

关键细节是我们没有被要求构造实际的十进制数。 我们只需要计算**最小计数**。 

### 了解限制

 限制条件是：

 -`1 <= n.length <= 10^5`-`n`仅包含数字
 -`n`没有前导零
 -`n`代表一个正整数

 这里最重要的观察是长度限制。 自从`n`最多可包含`100,000`数字，将其转换为整数甚至可能不适合标准数字类型。 更重要的是，任何执行昂贵的重复操作或模拟的解决方案都可能太慢。 

我们需要一个在**线性时间**或接近线性时间运行的解决方案。 

### 重要的边缘案例

 多个输入可能会导致幼稚的实现失败。 

如果该数字仅包含`1`s，例如`"1111"`，答案很简单`1`，因为数字本身已经是十进制了。 

如果数字包含大数字，例如`9`， 例如`"27346209830709182346"`，答案必须至少是`9`，因为没有任何一个十进制数可以贡献超过`1`到任意数字位置。 

个位数输入也很重要。 为了`"7"`，答案是`7`，因为我们需要七个`1`s 堆叠在一起以创建数字`7`。 

该问题保证输入是有效的、正的，并且不包含前导零，因此我们不需要处理格式错误的输入。 

## 方法

 ### 蛮力方法

 蛮力方法会尝试重复构造十进制数并将它们从`n`直到剩余值变为零。 

例如，给定`"82734"`，我们可以通过放置来重复创建一个十进制数`1`s 位于数字非零的位置：```
82734
11111
-----
71623
11111
-----
60512
...
```我们继续减法，直到所有数字都变为零。 

这种方法最终会产生正确的结果，因为每次减法最多将每个非零数字减少`1`，最终数字变为零。 

然而，它的效率很低。 在最坏的情况下，比如`"999999999"`，我们需要执行最多`9`字符串的完整遍历。 尽管`9`在技​​术上是恒定的，模拟减法过程是不必要的工作并且使逻辑更加复杂。 

通过认识问题的数学属性，我们可以做得更好。 

### 关键见解

 关键的观察是**答案只是字符串中的最大数字**。 

为什么？ 

每个十进制数最多可以贡献`1`到任意数字位置。 假设其中一位数字`n`是`8`。 

这意味着所有十进制数的总和必须贡献总计`8`在那个位置。 由于每个十进制数最多贡献`1`，我们需要**至少8个数字**。 

现在考虑是否`8`数量总是足够的。 

是的。 我们可以想象堆叠十进制数，以便每个数字位置恰好接收所需的数量`1`s。 

例如：```
82734
```最大的数字是`8`。 

我们可以构造 8 个十进制数：

 - 第一个数字为八`1`是
 - 第二位数字为 2`1`是
 - 第三位数字为七`1`s
 - 等等

 由于每个数字都可以独立满足，因此最大数字决定了：

 1. 最低数量要求
 2. 足够的数字来构造总和

 因此，问题就简化为寻找**字符串中最大的数字**。

 ## 算法演练

 ### 最优算法

 1. 初始化一个变量来跟踪迄今为止看到的最大数字。 
2.遍历字符串中的每个字符`n`。 
3. 将当前字符转换为其数值。 
4. 将当前数字与运行最大值进行比较。 如果数字较大，则更新最大值。 
5. 由于数字的范围仅从`0`到`9`，如果我们遇到`9`，我们可以立即返回`9`，因为不可能有更大的答案。 
6. 扫描整个字符串后，返回找到的最大数字。 

### 为什么它有效

 正确性来自于一个简单的不变量。 

对于任何数字位置，每个十进制数最多贡献`1`。 因此，如果一个数字等于`d`，我们至少需要`d`产生该数字的数字。 

同时，`maxDigit`数量总是足够的，因为我们可以分配`1`s 跨越数字位置以完全匹配每个所需的数字计数。 

因此，十进制数的最小个数等于`n`。 

## Python 解决方案```python
class Solution:
    def minPartitions(self, n: str) -> int:
        max_digit = 0

        for digit_char in n:
            digit = int(digit_char)
            max_digit = max(max_digit, digit)

            if max_digit == 9:
                return 9

        return max_digit
```### 实现说明

 该实现维护一个名为的变量`max_digit`，它存储迄今为止遇到的最大数字。 

我们遍历字符串中的每个字符`n`。 由于输入是字符串，每个数字都以字符形式到达，因此我们使用以下命令将其转换为整数`int()`。 

转换后，我们将其与当前最大值进行比较并进行相应更新。 

其中包括一个优化：如果我们遇到`9`，我们立即返回`9`。 由于数字范围仅从`0`到`9`，不存在更大的答案。 

最后，如果没有`9`找到后，我们返回遍历过程中看到的最大数字。 

该实现直接遵循前面讨论的数学见解。 

## 解决方案```go
func minPartitions(n string) int {
    maxDigit := 0

    for _, char := range n {
        digit := int(char - '0')

        if digit > maxDigit {
            maxDigit = digit
        }

        if maxDigit == 9 {
            return 9
        }
    }

    return maxDigit
}
```### Go 特定的实现差异

 Go 解决方案与 Python 版本非常相似，但有一些实现细节值得注意。 

在 Go 中，迭代字符串会生成 Unicode 符文值。 由于输入仅由数字组成，因此减去`'0'`转换一个字符，如`'7'`化为整数`7`。 

与 Python 不同，Go 没有内置的`max()`函数用于整数，因此我们执行手动比较。 

不用担心整数溢出，因为数字被限制在范围内`0`通过`9`。

 ## 边缘情况

 ### 输入仅包含`0`和`1`数字

 像这样的输入`"10101"`已经可以使用单个十进制数来表示。 简单的实现可能会使分解过程变得过于复杂，但我们的解决方案只是找到最大数字，即`1`，并正确返回`1`。 

### 个位数输入

 对于输入，例如`"7"`，只有一位数字需要检查。 由于十进制数最多可以贡献`1`在数字位置，我们正好需要`7`数字。 该实现自然会处理这个问题，因为最大数字成为答案。 

### 存在`9`如果输入包含`9`， 例如`"27346209830709182346"`，答案一定是`9`，因为没有数字可以超过`9`。 这种情况很重要，因为它允许提前退出优化。 执行立即返回`9`看到它后，避免在很长的字符串上进行不必要的工作。 

### 非常大的输入

 输入长度可达`100,000`人物。 任何重复模拟减法或构建中间表示的方法都可能变得低效。 我们的实现仅对字符串执行一次传递，并使用恒定的额外内存，即使在最大输入大小下也能保持高效。
