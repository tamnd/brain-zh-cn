[LeetCode 问题 1638](https://leetcode.com/problems/count-substrings-that-differ-by-one-character/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、动态规划、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们计算有多少对子串，一对取自`s`和一个取自`t`，仅相差一个字符。 

子字符串是连续的，因此对于像这样的字符串`"abcde"`，有效子串包括`"a"`,`"bc"`,`"abcd"`， 和`"cde"`。 

我们不允许有零个差异或超过一个差异。 两个子字符串必须：

 1.长度相同
 2. 仅有一个位置不同

 例如：

 -`"abc"`和`"adc"`恰好有一个字符不同，第二个字符不同
 -`"abc"`和`"abc"`相差零个字符，因此它们无效
 -`"abc"`和`"axy"`相差两个字符，因此无效

 任务是计算每个有效对的数量。 

限制很小：

 -`1 <= s.length, t.length <= 100`由于两个字符串的长度最多为 100，因此`O(n^3)`甚至`O(n^4)`解决方案可能仍然可行。 然而，我们仍然应该寻找一种更清洁、更有效的方法。 

一些边缘情况很重要：

 - 单字符串
 - 具有所有相同字符的字符串
 - 没有匹配区域的字符串
 - 许多重叠子串分别贡献的情况
 - 子字符串的第一个或最后一个字符不同的情况

 该问题保证所有字符都是小写英文字母，因此字符比较很简单。 

## 方法

 ### 蛮力方法

 蛮力的想法是生成每个子串`s`和每个子串`t`，然后比较所有具有相同长度的对。 

对于每对：

 1. 逐个比较字符
 2. 计算有多少个位置不同
 3. 如果差值恰好等于 1，则增加答案

 这是有效的，因为它显式地检查每个可能的有效子字符串对。 

然而，复杂性变得昂贵。 

如果`n = len(s)`和`m = len(t)`：

- 有`O(n^2)`中的子串`s`- 有`O(m^2)`中的子串`t`- 比较两个子字符串可能需要`O(min(n, m))`总体复杂度约为`O(n^3 * m^3)`在最坏的情况下，即使输入大小适中，速度也会过慢。 

### 最佳方法

 关键的见解是，我们可以处理每对索引，而不是显式地生成子字符串`(i, j)`作为潜在的错配位置。 

认为：

-`s[i] != t[j]`然后这个不同的字符可以作为单个所需的不匹配。 

现在我们只需要确定：

 - 有多少个相等的字符向左延伸
 - 有多少个相等的字符向右延伸

 如果：

 -`left`= 紧邻左侧的匹配字符数
 -`right`= 紧邻右侧的匹配字符数

 然后：

 - 我们可以选择任何前缀长度`0`到`left`- 我们可以选择任何后缀长度`0`到`right`所以由不匹配贡献的有效子串对的数量`(i, j)`是：$$(left + 1) \times (right + 1)$$这是有效的，因为每个构造的子串对都包含一个不匹配，即`(i, j)`。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3 × m3) | O(1) | O(1) | 显式枚举所有子字符串对 |
 | 最佳 | O(n² × 平方米) | O(1) | O(1) | 将每个不匹配视为唯一的不同位置 |

 ## 算法演练

 ### 最优算法

 1. 初始化`answer = 0`。 
2. 迭代每个索引`i`在字符串中`s`。 
3. 迭代每个索引`j`在字符串中`t`。 
4. 如果`s[i] == t[j]`，跳过这一对，因为我们只需要一个不同的字符。 
5.如果`s[i] != t[j]`， 对待`(i, j)`作为独特的错配位置。 
6. 向左展开：

 - 开始于`i - 1`和`j - 1`- 计算有多少个连续字符匹配
 - 将此计数存储在`left`7. 向右展开：

 - 开始于`i + 1`和`j + 1`- 计算有多少个连续字符匹配
 - 将此计数存储在`right`8. 必须始终包括不匹配位置本身。 

- 我们可以向左延伸`0`通过`left`人物
 - 我们可以直接延长`0`通过`right`人物
 9. 添加：$$(left + 1) \times (right + 1)$$到答案。 
10. 继续，直到处理完所有索引对。 
11.返回最终答案。 

### 为什么它有效

 每个有效的子串对都有一个不同的位置。 我们的算法直接枚举不同的位置。 

对于每个不匹配`(i, j)`：

 -`left + 1`表示在保持相等的同时向左扩展的所有有效方法
 -`right + 1`代表了在保持平等的同时扩大权利的所有有效方式

 将它们相乘计算出唯一不匹配发生在的每个子串对`(i, j)`。 

没有遗漏有效对，也没有无效对被计算两次。 

## Python 解决方案```python
class Solution:
    def countSubstrings(self, s: str, t: str) -> int:
        n = len(s)
        m = len(t)

        answer = 0

        for i in range(n):
            for j in range(m):
                if s[i] == t[j]:
                    continue

                left = 0
                a = i - 1
                b = j - 1

                while a >= 0 and b >= 0 and s[a] == t[b]:
                    left += 1
                    a -= 1
                    b -= 1

                right = 0
                a = i + 1
                b = j + 1

                while a < n and b < m and s[a] == t[b]:
                    right += 1
                    a += 1
                    b += 1

                answer += (left + 1) * (right + 1)

        return answer
```实现直接遵循算法。 

外部两个循环枚举每对位置`(i, j)`。 

每当字符不同时，我们都会将该位置视为单个不匹配。 然后我们在两个方向上向外扩展以计算匹配区域。 

左扩展决定了在不匹配之前可以安全地包含多少个字符。 正确的扩展决定了在不匹配之后可以安全地包含多少个字符。 

最后，将左侧选择和右侧选择的数量相乘，得出以该不匹配为中心的有效子串对的总数。 

该算法仅使用恒定的额外空间，因为所有计算都是使用整数计数器和索引变量执行的。 

## 解决方案```go
func countSubstrings(s string, t string) int {
	n := len(s)
	m := len(t)

	answer := 0

	for i := 0; i < n; i++ {
		for j := 0; j < m; j++ {

			if s[i] == t[j] {
				continue
			}

			left := 0
			a, b := i-1, j-1

			for a >= 0 && b >= 0 && s[a] == t[b] {
				left++
				a--
				b--
			}

			right := 0
			a, b = i+1, j+1

			for a < n && b < m && s[a] == t[b] {
				right++
				a++
				b++
			}

			answer += (left + 1) * (right + 1)
		}
	}

	return answer
}
```Go 实现密切反映了 Python 逻辑。 

由于 Go 中的字符串是 ASCII 字符的字节切片，因此直接索引`s[i]`和`t[j]`工作正常，因为输入仅包含小写英文字母。 

不需要额外的内存分配，并且整数溢出也不是问题，因为对于给定的约束，最大答案完全在 Go 的整数范围内。

 ## 边缘情况

 ### 完全相同的字符串

 如果`s`和`t`相同，很容易意外地计算出零差异的子串。 

例如：```
s = "aaa"
t = "aaa"
```每个子字符串对都完美匹配，但问题需要恰好有一个不同的字符。 

该实现正确地处理了这个问题，因为它仅在以下情况下开始扩展：`s[i] != t[j]`。 

### 单字符串

 最小的输入可能会出现相差一的错误。 

例子：```
s = "a"
t = "b"
```不可能进行左或右扩展，但不匹配本身形成一个有效的子串对。 

公式：$$(left + 1)(right + 1)$$正确地变为：$$1 \times 1 = 1$$### 字符串边界不匹配

 不匹配可能发生在子字符串的开头或结尾。 

例子：```
s = "abc"
t = "xbc"
```不同的字符出现在第一个位置。 

该实现可以安全地处理这个问题，因为当索引变为负数时，左扩展立即停止，而右扩展正常继续。 

### 多个重叠的有效子字符串

 某些输入包含许多重叠的有效子字符串。 

例子：```
s = "abab"
t = "baba"
```不同的子串对可能共享相同的失配位置，但具有不同的长度。 

乘法：$$(left + 1)(right + 1)$$正确地独立计算每个不同的扩展组合。
