 # LeetCode 352 - 作为不相交间隔的数据流

 ## 问题理解

 这个问题要求我们处理非负整数流并持续维护迄今为止看到的所有数字的紧凑表示。 

我们不想单独存储每个单独的数字，而是希望将连续的数字分组为不相交的区间。 一个区间`[start, end]`表示每个整数`start`通过`end`，包含在内。 

例如，如果流包含：```
1, 2, 3, 7
```那么汇总的区间为：```
[[1, 3], [7, 7]]
```因为`1, 2, 3`形成一个连续的块，同时`7`孤立无援。 

该类必须支持两种操作：

 1.`addNum(value)`将数字添加到数据流中。 
2.`getIntervals()`返回按起始值排序的所有不相交间隔。 

重要的细节是数字可能以任意顺序到达。 添加数字可能会产生几种不同的情况：

 - 它可能已经存在
 - 它可能会创建一个新的孤立区间
 - 它可能会延长现有的间隔
 - 它可以将两个间隔合并在一起

 例如：```
Current intervals: [[1, 1], [3, 3]]
Add 2
Result: [[1, 3]]
```这里，`2`弥合两个音程之间的差距并将它们合并。 

限制相对较小：

 -`0 <= value <= 10^4`- 至多`3 * 10^4`业务总计
 - 至多`10^2`打电话给`getIntervals`这些限制表明精心设计的有序结构就足够了。 我们不需要极其先进的平衡结构，但我们确实需要高效的区间合并。 

一些边缘情况很重要：

 - 添加重复值不应改变任何内容
 - 添加与现有间隔相邻的值必须正确合并
 - 添加连接两个间隔的值必须将它们合并为一个
 - 在现有范围的开头或结尾添加值必须正确更新边界
 - 返回的间隔必须始终保持排序且不重叠

 ## 方法

 ### 蛮力方法

 一个简单的解决方案是将每个数字单独存储在一个集合中。 

每当`getIntervals()`称为：

 1. 提取所有数字
 2. 对它们进行排序
 3. 浏览排序列表
 4. 将连续数字合并为区间

 这是有效的，因为连续的数字在线性扫描期间自然形成间隔。 

例如：```
Numbers: {1, 2, 3, 6, 7}
Sorted: [1, 2, 3, 6, 7]
Intervals: [[1, 3], [6, 7]]
```该方法易于实施并且始终正确。 然而，当流变大时，重复排序和重建间隔就会变得低效。 

如果有很多`getIntervals()`调用时，我们反复重做之前已经计算过的工作。 

### 最佳方法

 关键的观察结果是，当插入新数字时，间隔仅在本地发生变化。 

添加时`value`，只有相邻的间隔很重要：

 - 结束于的间隔`value - 1`- 间隔开始于`value + 1`其他一切保持不变。 

因此，我们可以随着数字的到来逐步维护间隔，而不是每次都从头开始重建间隔。 

我们按排序顺序存储间隔并在插入期间立即合并它们。 

这为我们提供了高效的更新并使得`getIntervals()`微不足道，因为间隔始终保持有效形式。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 |`addNum: O(1)`,`getIntervals: O(n log n)`|`O(n)`| 每次从排序数字重建间隔 |
 | 最佳|`addNum: O(k)`,`getIntervals: O(k)`|`O(k)`| 增量维护合并间隔 |

 这里，`k`是不相交间隔的数量。 

## 算法演练

 我们维护一个间隔排序列表。 

每个区间表示为：```
[start, end]
```该列表始终是：

 - 排序依据`start`- 不重叠
 - 完全合并

 ### 第1步：找到插入位置

 插入新值时，我们会扫描间隔，直到找到该值所属的位置。 

我们跳过所有末尾严格小于的区间`value - 1`。 

这些间隔与新数字完全无关。 

### 步骤 2：处理重叠或重复

 如果该值已经位于某个区间内，我们什么都不做。 

例子：```
Intervals: [[1, 5]]
Add 3
```自从`3`已经属于`[1, 5]`，无需更新。 

### 步骤 3：合并相邻区间

 如果该值触及相邻区间，我们将它们合并。 

有几种可能：

 #### 延长左间隔```
[[1, 3]]
Add 4
```变成：```
[[1, 4]]
```#### 延长右区间```
[[5, 7]]
Add 4
```变成：```
[[4, 7]]
```#### 连接两个音程```
[[1, 2], [4, 5]]
Add 3
```变成：```
[[1, 5]]
```这是最重要的一个案例。 

### 步骤 4：插入孤立区间

 如果无法合并，则插入一个新间隔：```
[[1, 2], [6, 7]]
Add 4
```变成：```
[[1, 2], [4, 4], [6, 7]]
```### 步骤 5：返回间隔

 因为间隔是增量维持的，`getIntervals()`只是返回存储的间隔。 

### 为什么它有效

 该算法保持了区间始终排序、不相交和完全合并的不变性。 

每次插入仅检查相邻的间隔，因为在插入一个值后只有相邻的范围可能会发生变化。 通过在发生邻接时立即合并间隔，我们保证之后没有两个间隔保持可合并。 

因此，间隔列表始终表示插入数字的精确集合。 

## Python 解决方案```python
from typing import List

class SummaryRanges:

    def __init__(self):
        self.intervals = []

    def addNum(self, value: int) -> None:
        new_interval = [value, value]
        result = []
        inserted = False

        for start, end in self.intervals:

            # Current interval is completely before new interval
            if end + 1 < new_interval[0]:
                result.append([start, end])

            # Current interval is completely after new interval
            elif new_interval[1] + 1 < start:
                if not inserted:
                    result.append(new_interval)
                    inserted = True

                result.append([start, end])

            # Intervals overlap or touch, merge them
            else:
                new_interval[0] = min(new_interval[0], start)
                new_interval[1] = max(new_interval[1], end)

        if not inserted:
            result.append(new_interval)

        self.intervals = result

    def getIntervals(self) -> List[List[int]]:
        return self.intervals
```该实现始终维护一个排序的间隔列表。 

里面`addNum`，我们创建一个临时间隔`[value, value]`。 当我们扫描现有的区间时，我们将每个区间分为三类之一。 

如果当前间隔完全位于新间隔之前，我们只需将其复制到结果中即可。 

如果当前间隔完全位于新间隔之后，则如果尚未插入新间隔，我们首先插入新间隔。 

否则，间隔会重叠或接触，因此我们通过更新边界来合并它们`new_interval`。 

在扫描结束时，如果从未插入新间隔，我们会将其附加。 

由于合并发生在插入期间，因此间隔列表始终保持有效。 

这`getIntervals()`方法很简单，因为所有维护工作都已逐步完成。 

## 解决方案```go
type SummaryRanges struct {
	intervals [][]int
}

func Constructor() SummaryRanges {
	return SummaryRanges{
		intervals: [][]int{},
	}
}

func (this *SummaryRanges) AddNum(value int) {
	newInterval := []int{value, value}
	result := [][]int{}
	inserted := false

	for _, interval := range this.intervals {
		start := interval[0]
		end := interval[1]

		// Current interval is completely before new interval
		if end+1 < newInterval[0] {
			result = append(result, []int{start, end})

		// Current interval is completely after new interval
		} else if newInterval[1]+1 < start {
			if !inserted {
				result = append(result, newInterval)
				inserted = true
			}

			result = append(result, []int{start, end})

		// Overlapping or adjacent intervals
		} else {
			if start < newInterval[0] {
				newInterval[0] = start
			}

			if end > newInterval[1] {
				newInterval[1] = end
			}
		}
	}

	if !inserted {
		result = append(result, newInterval)
	}

	this.intervals = result
}

func (this *SummaryRanges) GetIntervals() [][]int {
	return this.intervals
}

/**
 * Your SummaryRanges object will be instantiated and called as such:
 * obj := Constructor();
 * obj.AddNum(value);
 * param_2 := obj.GetIntervals();
 */
```Go 的实现与 Python 的逻辑非常相似。 

一个重要的区别是切片处理。 在 Go 中，间隔存储为`[][]int`，并且我们在将间隔附加到结果中时显式创建新切片。 

Go also distinguishes between nil slices and empty slices, but both work correctly here because LeetCode accepts either representation for empty results.

 整数溢出不是问题，因为值的边界是`10^4`。

 ## 边缘情况

 ### 重复值

 一个微妙的问题是多次插入相同的值。 

例如：```
Add 5
Add 5
```有缺陷的实现可能会错误地创建重复的间隔或分割范围。 

该解决方案可以自然地处理重复项，因为重叠的间隔被合并。 如果该值已存在于某个区间内，则合并操作会使该区间保持不变。 

### 连接两个区间

 最重要的边缘情况是当单个值连接两个先前独立的区间时。 

例子：```
[[1,2], [4,5]]
Add 3
```正确的结果是：```
[[1,5]]
```幼稚的实现通常只与一侧合并，而忘记第二次合并。 

此实现避免了该问题，因为它在合并后继续扫描。 不断成长的`new_interval`可以在单次通过期间吸收多个间隔。 

### 在开头或结尾插入

 添加小于所有间隔或大于所有间隔的值可能会暴露插入顺序错误。 

示例：```
[[5,7]]
Add 1
```或者```
[[1,3]]
Add 10
```该算法可以正确处理这两种情况，因为只有在找到适当的位置时才会插入间隔。 如果扫描期间从未发生插入，则将间隔附加在末尾。 

### 空数据流

 呼唤`getIntervals()`在任何插入之前应该返回一个空列表。 

一些实现意外返回`None`或未初始化的结构。 

该解决方案初始化`self.intervals`从一开始就是一个空列表，因此该方法正确返回：```
[]
```
