 ## 解决方案

 ## 问题理解

 这个问题要求我们设计一个自定义的数据结构，称为`RandomizedSet`支持三种操作：

 1. 将一个值插入集合中。 
2. 从集合中删除一个值。 
3. 从集合中返回一个随机元素。 

关键要求是所有三个操作必须平均运行`O(1)`时间复杂度。 

该行为与正常的数学集非常相似：

 - 不允许有重复的值。 
- 插入现有值应该返回`false`。 
- 删除缺失值应该返回`false`。 

额外的挑战是`getRandom()`手术。 当前存储在集合中的每个元素必须具有相同的被选择概率。 这意味着实现不能偏向于较早或较晚插入的值。 

LeetCode 中的输入表示为一系列方法调用和参数。 输出是每个方法调用的返回值。 在内部，我们只需要正确实现该类即可。 

约束条件很重要：

 - 最多`2 * 10^5`可以进行操作。 
- 值的范围可以是`-2^31`到`2^31 - 1`。 

由于操作数量很大，任何比恒定时间慢的操作都可能变得过于昂贵。 例如，一个`O(n)`在最坏的情况下，每个操作中的删除可能会导致二次行为。 

有几种边缘情况我们必须小心处理：

 - 插入重复值。 
- 删除不存在的值。 
- 删除最后剩余的元素。 
- 从中间删除一个元素，同时保留有效的随机访问。 
- 确保`getRandom()`始终在所有当前元素中进行统一选择。 

该问题保证了`getRandom()`仅当集合包含至少一个元素时才调用，因此我们不需要为该方法处理空结构。 

## 方法

 ### 蛮力方法

 一个简单的实现将仅使用一个列表。 

对于插入，我们将扫描列表以检查该值是否已存在。 如果没有，我们将其附加。 

对于删除，我们将扫描列表以查找目标值，然后将其删除。 

为了`getRandom()`，我们可以生成一个随机索引并返回相应的元素。 

这种方法是正确的，因为列表准确地存储了所有当前元素，并且随机索引自然地为每个元素提供了相等的概率。 

然而，插入和删除都需要对列表进行线性搜索。 由于列表最多可以包含`O(n)`元素，这些操作变成`O(n)`。 

高达`200,000`操作，这太慢了。 

### 最佳方法

 关键的观察是我们同时需要两个属性：

 1. 快速的成员资格检查和索引查找。 
2. 通过索引快速随机访问。 

哈希图给出`O(1)`按值平均查找、插入和删除。 

动态数组给出`O(1)`按索引随机访问。 

最佳解决方案结合了两者：

 - 使用数组来存储实际值。 
- 使用哈希映射来存储数组中每个值的索引。 

具有挑战性的部分是删除。 

从数组中间删除任意元素通常是`O(n)`因为元素必须左移。 

为了避免移位，我们使用交换技巧：

 - 将要删除的元素与最后一个元素交换。 
- 更新哈希图中移动元素的索引。 
- 从数组中弹出最后一个元素。 

这使删除保持在`O(1)`平均时间。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 插入：O(n)，删除：O(n)，随机：O(1) | O(n) | 仅使用列表，需要线性扫描 |
 | 最佳 | 插入：O(1)，删除：O(1)，随机：平均 O(1) | O(n) | 将数组和哈希图与交换删除技巧结合起来 |

 ## 算法演练

 1. 初始化两个数据结构。 

创建：

 - 动态数组`values`它存储当前集合中的所有元素。 
- 哈希图`index_map`将每个值映射到其内部索引`values`。 

数组提供恒定时间随机访问，哈希图提供恒定时间存在检查和索引查找。 
2. 处理插入。 

插入值时：

 - 首先检查该值是否已经存在于`index_map`。 
- 如果存在，则返回`false`。 
- 否则：

 - 将值附加到`values`。 
- 将其索引存储在`index_map`。 
- 返回`true`。 

追加到动态数组是分摊的`O(1)`。 
3. 手柄拆卸。 

删除值时：

 - 首先检查该值是否存在于`index_map`。 
- 如果不存在，则返回`false`。 

否则：

 - 检索要删除的值的索引。 
- 检索数组中的最后一个元素。 
- 将最后一个元素移动到已删除元素的位置。 
- 更新移动元素的索引`index_map`。 
- 使用删除最后一个数组元素`pop`。 
- 删除删除的值`index_map`。 
- 返回`true`。 

这避免了昂贵的移位操作。 
4. 处理随机检索。 

返回随机元素：

 - 生成一个随机索引`0`和`len(values) - 1`。 
- 返回`values[random_index]`。 

由于每个元素恰好占据一个数组位置，因此每个元素具有相等的概率。 

### 为什么它有效

 核心不变量是存储在集合中的每个值在数组中只出现一次，并且哈希映射始终存储该值在数组中的正确索引。 

插入通过附加新值并记录其索引来保留此不变量。 

删除通过用最后一个元素替换删除的元素并更新移动元素的存储索引来保留不变式。 

由于数组保持紧凑且没有间隙，因此随机索引会统一选择每个存储的元素。 

## Python 解决方案```python
import random
from typing import Dict, List

class RandomizedSet:

    def __init__(self):
        self.values: List[int] = []
        self.index_map: Dict[int, int] = {}

    def insert(self, val: int) -> bool:
        if val in self.index_map:
            return False

        self.values.append(val)
        self.index_map[val] = len(self.values) - 1

        return True

    def remove(self, val: int) -> bool:
        if val not in self.index_map:
            return False

        remove_index = self.index_map[val]
        last_value = self.values[-1]

        self.values[remove_index] = last_value
        self.index_map[last_value] = remove_index

        self.values.pop()
        del self.index_map[val]

        return True

    def getRandom(self) -> int:
        return random.choice(self.values)

# Your RandomizedSet object will be instantiated and called as such:
# obj = RandomizedSet()
# param_1 = obj.insert(val)
# param_2 = obj.remove(val)
# param_3 = obj.getRandom()
```该实现使用两个实例变量：

 -`values`，存储所有当前元素的列表。 
-`index_map`，将值映射到列表中索引的字典。 

这`insert`方法首先检查该值是否已经存在。 如果是，则插入失败。 否则，该值将附加到列表中，并将其索引存储在字典中。 

这`remove`方法使用交换删除优化。 它不是直接从列表中间删除，而是用最后一个元素替换目标元素。 这可以避免移动元素并保持恒定时间性能。 

这`getRandom`方法用途`random.choice`，它从列表中选择一个均匀随机的元素。 

由于数组始终包含活动集元素，因此每个值都有相同的返回概率。 

## 解决方案```go
package main

import (
	"math/rand"
)

type RandomizedSet struct {
	values   []int
	indexMap map[int]int
}

func Constructor() RandomizedSet {
	return RandomizedSet{
		values:   []int{},
		indexMap: make(map[int]int),
	}
}

func (this *RandomizedSet) Insert(val int) bool {
	if _, exists := this.indexMap[val]; exists {
		return false
	}

	this.values = append(this.values, val)
	this.indexMap[val] = len(this.values) - 1

	return true
}

func (this *RandomizedSet) Remove(val int) bool {
	removeIndex, exists := this.indexMap[val]
	if !exists {
		return false
	}

	lastValue := this.values[len(this.values)-1]

	this.values[removeIndex] = lastValue
	this.indexMap[lastValue] = removeIndex

	this.values = this.values[:len(this.values)-1]
	delete(this.indexMap, val)

	return true
}

func (this *RandomizedSet) GetRandom() int {
	randomIndex := rand.Intn(len(this.values))
	return this.values[randomIndex]
}

/**
 * Your RandomizedSet object will be instantiated and called as such:
 * obj := Constructor();
 * param_1 := obj.Insert(val);
 * param_2 := obj.Remove(val);
 * param_3 := obj.GetRandom();
 */
```Go 实现遵循与 Python 版本相同的算法结构。 

主要区别在于 Go 显式使用切片和映射：

 -`[]int`存储元素。 
-`map[int]int`存储索引。 

删除使用切片截断：```go
this.values = this.values[:len(this.values)-1]
```而不是 Python 的`pop()`。 

随机选择使用`rand.Intn`，它生成一个范围内的随机整数`[0, n)`。 

Go 没有内置的动态类型，因此所有数据结构都是强类型的。

 ## 边缘情况

 ### 删除不存在的元素

 一个常见的错误是尝试删除当前未存储的值。 如果不首先检查，实现可能会引发错误或损坏内部状态。 

此实现通过首先检查来避免该问题：```
if val not in self.index_map:
    return False
```该方法立即退出，不做任何修改。 

### 删除最后一个元素

 当目标元素已经是数组中的最后一个元素时，交换操作实际上将元素与自身交换。 

例如：```
values = [1, 2, 3]
remove(3)
```该代码仍然可以正常工作，因为将最后一个元素分配回其自己的位置是无害的。 之后的后续`pop`，结构仍然有效。 

### 删除后重用值

 当删除某个值然后再次插入时，会出现另一个微妙的问题。 

如果在删除过程中未正确清理哈希映射，则实现可能会错误地认为该值仍然存在。 

此实现显式地从映射中删除该值：```
del self.index_map[val]
```因此，将来插入相同的值可以正常工作。 

### 交换后保持正确的索引

 该解决方案最容易出错的部分是在移动最后一个元素后更新索引。 

如果移动元素的索引未更新，则将来的删除或查找将引用过时的位置。 

此实现在交换后立即修复索引：```
self.index_map[last_value] = remove_index
```这保证了哈希映射始终与实际的数组布局匹配。
