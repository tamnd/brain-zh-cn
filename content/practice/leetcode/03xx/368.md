[LeetCode 第 368 题](https://leetcode.com/problems/largest-divisible-subset/)

 **难度：** 🟡 中等
 **主题：** 数组、数学、动态规划、排序

 ## 解决方案

 ## 问题理解

 该问题为我们提供了一组不同的正整数，并要求我们找到每对数字满足整除关系的最大子集。 对于任意两个元素`a`和`b`在子集中，要么`a % b == 0`或者`b % a == 0`必须持有。 

换句话说，所选子集中的每对值必须在可整除性下兼容。 该子集不需要保留输入数组的原始顺序，如果存在多个有效的最大子集，则返回其中任何一个都是可以接受的。 

输入包括：

 - 一个数组`nums`- 所有数字均为正数
 - 所有号码都是唯一的
 - 数组长度可以大到`1000`- 个体值可以大到`2 * 10^9`的约束条件为`nums.length`尤为重要。 尺寸为`1000`足够大以至于指数暴力子集生成变得不可行。 由于有`2^n`可能的子集，天真的穷举搜索将慢得难以置信。 

唯一性保证简化了问题，因为我们永远不需要担心重复值会创建不明确的链或重复的可分性检查。 

尽早识别一些边缘情况很重要：

 - 单元素数组始终有效，因为一个数字通常满足条件。 
- 没有两个数字可以相除的数组应该返回任何单个元素。 
- 包含长整除链的数组，例如`[1,2,4,8,16]`应该返回完整的数组。 
- 大型素数重数组可能仅产生非常小的有效子集。 
- 由于所有数字都是正数，整除行为仍然简单，并避免涉及零或负值的问题。 

## 方法

 ### 蛮力方法

 暴力解决方案将生成数组的每个可能的子集，并检查该子集是否满足整除条件。 

对于每个子集，我们将比较每对元素。 如果每一对都满足一个除另一个的规则，则该子集有效。 然后我们将跟踪找到的最大有效子集。 

这种方法是正确的，因为它显式地检查所有可能的子集，保证最终会发现最佳答案。 

然而，运行时间非常昂贵。 大小的数组`n`有`2^n`子集。 对于每个子集，检查所有对可能需要`O(n^2)`工作。 和`n = 1000`，这种做法是完全不可行的。 

### 最佳解决方案的关键见解

 关键的观察是整除性在排序后表现出传递性。 

如果我们按升序对数字进行排序，则对于有效的可整除子集：

 - 较小的数字出现在较大的数字之前
 - 如果`a`划分`b`和`b`划分`c`， 然后`a`也分`c`这将问题转化为与最长递增子序列问题非常相似的问题。 

排序后，我们可以定义：

 -`dp[i]`= 以索引结束的最大可整子集的长度`i`-`parent[i]`= 链中的前一个索引，用于重建

 对于每个数字`nums[i]`，我们查看之前的所有数字`nums[j]`在哪里`j < i`。 如果`nums[i] % nums[j] == 0`， 然后`nums[i]`可以扩展结束于的子集`j`。 

这种动态规划方法有效地构建了在每个位置结束的最佳链。

 ## 算法演练

 1. 将输入数组按升序排序。 

排序至关重要，因为整除链会自然地从较小的数字增长到较大的数字。 排序后，如果`nums[i]`可以整除`nums[j]`为了`j < i`， 然后`nums[i]`可以延长结束于的链`j`。 
2. 创建一个`dp`大批。`dp[i]`存储以索引结尾的最大可整子集的长度`i`。 

最初，每个元素都可以形成仅包含其自身的子集，因此所有值都以`1`。 
3. 创建一个`parent`大批。`parent[i]`存储结束于的可分割链中的前一个索引`i`。 

这允许在动态编程阶段完成后重建最终子集。 
4. 跟踪迄今为止找到的最佳子集。 

维持：

-`max_length`，找到的最大子集的大小
 -`max_index`，该子集的结束索引
 5. 迭代每个位置`i`。 

对于每一个`i`，检查所有较早的位置`j`在哪里`0 <= j < i`。 
6. 检查整除性。 

如果`nums[i] % nums[j] == 0`， 然后`nums[i]`可以扩展结束于的子集`j`。 
7.更新动态规划状态。 

如果将链条延长至`j`产生比当前最佳结束更长的子集`i`， 更新：```
dp[i] = dp[j] + 1
parent[i] = j
```8. 更新全局最大值。 

如果`dp[i]`超过`max_length`，存储新的最佳长度和结束索引。 
9.重构答案。 

开始于`max_index`，反复遵循`parent`向后链接直到到达`-1`。 
10. 反转重建的列表。 

由于重建是通过链向后进行的，因此在返回结果之前反转结果。 

### 为什么它有效

 排序后，每个有效的可整子集都可以视为一条链，其中每个元素都可以划分下一个元素。 动态规划递归保证`dp[i]`始终存储结束于的最大有效链`nums[i]`。 

因为每一个可能的前任`j < i`经过检查，该算法绝不会错过有效的扩展名。 父指针保留用于构造最佳解决方案的精确链，从而允许在最后进行正确的重建。 

## Python 解决方案```python
from typing import List

class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        if not nums:
            return []

        nums.sort()
        n = len(nums)

        dp = [1] * n
        parent = [-1] * n

        max_length = 1
        max_index = 0

        for i in range(n):
            for j in range(i):
                if nums[i] % nums[j] == 0:
                    if dp[j] + 1 > dp[i]:
                        dp[i] = dp[j] + 1
                        parent[i] = j

            if dp[i] > max_length:
                max_length = dp[i]
                max_index = i

        result = []

        while max_index != -1:
            result.append(nums[max_index])
            max_index = parent[max_index]

        result.reverse()
        return result
```该实现首先对数组进行排序，以便可以从左到右构建可分链。 

这`dp`数组跟踪以每个索引结尾的最佳可整子集的长度。 最初，每个值都是`1`因为每个数都可以单独构成一个子集。 

这`parent`数组记录了哪个较早的数字为每个位置产生了最佳链。 这是必要的，因为动态规划仅存储长度，而不存储实际的子集。 

嵌套循环检查每个当前位置的所有早期值。 每当找到可整除的前驱时，算法都会检查扩展该链是否可以改善当前的最佳结果。 

动态规划阶段完成后，算法通过向后遍历来重构答案`parent`数组从`max_index`。 

最后，由于重建是从最大元素到最小元素进行的，所以重建链被反转。 

## 解决方案```go
package main

import (
	"sort"
)

func largestDivisibleSubset(nums []int) []int {
	if len(nums) == 0 {
		return []int{}
	}

	sort.Ints(nums)

	n := len(nums)

	dp := make([]int, n)
	parent := make([]int, n)

	for i := 0; i < n; i++ {
		dp[i] = 1
		parent[i] = -1
	}

	maxLength := 1
	maxIndex := 0

	for i := 0; i < n; i++ {
		for j := 0; j < i; j++ {
			if nums[i]%nums[j] == 0 {
				if dp[j]+1 > dp[i] {
					dp[i] = dp[j] + 1
					parent[i] = j
				}
			}
		}

		if dp[i] > maxLength {
			maxLength = dp[i]
			maxIndex = i
		}
	}

	result := []int{}

	for maxIndex != -1 {
		result = append(result, nums[maxIndex])
		maxIndex = parent[maxIndex]
	}

	for left, right := 0, len(result)-1; left < right; left, right = left+1, right-1 {
		result[left], result[right] = result[right], result[left]
	}

	return result
}
```Go 实现遵循与 Python 版本相同的逻辑。 主要差异与语言语法和切片处理有关。 

Go 需要显式初始化数组并使用`sort.Ints(nums)`用于排序。 结果重建使用手动切片反转，因为Go没有提供内置的切片反转函数。 

整数溢出不是问题，因为整除性检查仅对问题约束内的值使用模运算。

 ## 边缘情况

 ### 单元素输入

 仅包含一个数字的数组始终有效，因为没有需要检查的冲突对。 有缺陷的实现可能会错误地假设可分割关系至少需要两个元素。 

此实现可以自然地处理这种情况，因为每个元素都以`dp[i] = 1`，这意味着每个数字本身形成一个有效的子集。 

### 不可整除的对

 考虑像这样的输入`[2,3,5,7]`。 这些价值观都不会相互分割。 

如果幼稚的链构建算法在扩展子集之前没有仔细验证可分性，则可能会意外返回无效组合。 

该解决方案检查`nums[i] % nums[j] == 0`在每次转换之前，确保只构建有效的链。 结果成为任何单元素子集。 

### 多个最佳答案

 一些输入有几个同样大的有效子集。 例如：```
[1,2,3,6]
```两个都`[1,2,6]`和`[1,3,6]`是有效的答案。 

不正确的实现可能会假设答案是唯一的，并意外地覆盖有效的重建数据。 

此实现仅返回它发现的第一个最大链。 由于该问题明确允许返回任何有效的最大子集，因此这种行为是正确的。 

### 未排序的输入

 输入数组可能以任意顺序出现，例如`[8,1,4,2]`。 

如果不进行排序，整除链将难以一致地构建，因为较大的整除值可能会出现在较小的基值之前。 

排序保证了处理时`nums[i]`，所有可能的前驱都已经出现在数组的较早位置。 这就是动态规划转换有效且高效的原因。
