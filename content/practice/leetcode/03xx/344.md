[LeetCode 第 344 题](https://leetcode.com/problems/reverse-string/)

 **难度：** 🟢简单
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们反转表示为字符数组的字符串。 我们必须直接修改原始数组，而不是返回一个新的反转字符串。 这个要求很重要，因为问题明确指出该解决方案必须就地工作并且仅使用`O(1)`额外的内存。 

输入是一个数组`s`，其中每个元素都是一个字符。 例如：```
["h","e","l","l","o"]
```代表字符串`"hello"`。 

反转后，数组应变为：```
["o","l","l","e","h"]
```该函数不返回任何内容，因为输入数组本身已被修改。 

这些约束告诉我们有关该问题的一些有用的信息：

 - 数组长度可以大到`10^5`，这意味着算法必须高效。 
- 每个元素都是可打印的 ASCII 字符，因此我们无需担心 Unicode 编码问题或多字节字符。 
- 由于输入可能非常大，因此重复创建数组的副本效率很低。 

最重要的要求是就地约束`O(1)`额外的内存。 这立即排除了创建另一个大小数组的解决方案`n`。 

一些边缘情况值得尽早识别：

 - 单字符数组，例如`["a"]`应保持不变。 
- 具有偶数个字符的数组和具有奇数个字符的数组在中间的行为略有不同。 
- 重复的字符，例如`["a","a","a"]`还是应该正确处理。 
- 算法必须避免在交换值之前覆盖值。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是创建一个新数组，以相反的顺序存储字符。 我们可以从末尾到开头迭代原始数组，并将每个字符附加到一个新数组中。 

例如：```
Original: ["h","e","l","l","o"]
New:      ["o","l","l","e","h"]
```构造反转数组后，我们可以将值复制回原始数组。 

这种方法是正确的，因为位置上的每个字符`i`被移动到位置`n - 1 - i`，这正是反转字符串的定义。 

然而，这个解决方案使用了一个额外的数组`n`，这违反了问题要求`O(1)`额外的内存。 尽管时间复杂度仍然是线性的，但额外的空间使其不是最优的。 

### 最佳方法

 关键的观察是反转字符串只需要交换字符对。 

第一个字符应与最后一个字符交换，第二个字符应与倒数第二个字符交换，依此类推。 这自然建议使用两个指针：

 - 一个指针从数组的开头开始。 
- 另一个指针从数组末尾开始。 

每一步：

 - 交换两个指针处的字符。 
- 将左指针向右移动一步。 
- 将右指针向左移动一步。 

该过程一直持续到指针相遇或交叉为止。 

由于交换直接发生在原始数组内部，因此不需要额外的数组。 这满足了就地要求并且仅使用恒定的额外内存。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 创建单独的反向副本 |
 | 最佳| O(n) | O(1) | O(1) | 使用两个指针并就地交换 |

 ## 算法演练

 1. 初始化两个指针。 

放`left`到数组开头的索引处`0`。 放`right`到最后一个索引，即`len(s) - 1`。 

这些指针代表接下来应该交换的字符对。 
2. 比较指针位置。 

继续处理同时`left < right`。 

一旦指针相遇或交叉，所有必要的交换就已经完成。 
3.交换角色。 

交换值于`s[left]`和`s[right]`。 

这会将正确的字符同时放置在数组的两端。 
4. 将两个指针向内移动。 

增量`left`经过`1`并减少`right`经过`1`。 

这会将指针移向中心，以便交换下一对指针。 
5. 重复直至完成。 

继续交换并向内移动，直到处理完所有对。 

### 为什么它有效

 该算法保持当前指针范围之外的所有字符都已处于正确的反转位置的不变性。 

在每次迭代时：

 - 左侧的角色移动到右侧的正确镜像位置。 
- 右侧的角色移动到左侧的正确镜像位置。 

由于每个位置都只处理一次，并且交换是对称执行的，因此当指针相遇时整个数组就会反转。 

## Python 解决方案```python
from typing import List

class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        
        left = 0
        right = len(s) - 1

        while left < right:
            s[left], s[right] = s[right], s[left]

            left += 1
            right -= 1
```实现首先创建两个指针，`left`和`right`，分别指向数组的开头和结尾。 

这`while`只要指针没有交叉，循环就会继续。 在循环内部，Python 元组解包用于交换单个语句中的两个字符：```python
s[left], s[right] = s[right], s[left]
```交换后，指针向内移动。 这个过程一直持续到整个数组都被反转为止。 

该方案直接修改数组，满足就地要求。 不会创建与输入大小成比例的附加数据结构。 

## 解决方案```go
func reverseString(s []byte) {
	left := 0
	right := len(s) - 1

	for left < right {
		s[left], s[right] = s[right], s[left]

		left++
		right--
	}
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

特定于语言的一个小差异是输入类型是`[]byte`而不是`[]string`。 在 Go 中，为了提高效率，字符串通常被作为字节切片进行操作。 

Go 还支持交换期间同时分配：```go
s[left], s[right] = s[right], s[left]
```这避免了需要临时变量。 

不需要对空或 nil 切片进行特殊处理，因为约束保证输入中至少有一个字符。

 该算法从两端向中心处理数组。 每次迭代执行恒定量的工作，迭代次数大约为`n / 2`。 由于 Big O 表示法中忽略常量，因此总时间复杂度为`O(n)`。 

该解决方案仅使用两个整数变量作为指针，并且不分配与输入大小成比例的额外内存，因此空间复杂度为`O(1)`。

 ## 边缘情况

 单字符数组是最小的有效输入。 这种情况很重要，因为两个指针立即从同一位置开始。 有缺陷的实现可能会意外地执行不必要的操作或错误地移动指针。 在这个实现中，条件`left < right`防止发生任何交换，因此数组按预期保持不变。 

具有奇数个字符的数组是另一个重要的情况。 在此类输入中，有一个中间字符在反转后应保持在相同位置。 例如：```
["a","b","c","b","a"]
```该算法自然地处理这个问题，因为当指针相遇时循环停止。 中间的字符永远不会交换，这是正确的行为。 

包含重复字符的数组有时会隐藏索引错误，因为交换相同的值不会产生可见的更改。 例如：```
["x","x","x"]
```即使输出看起来与输入相同，算法仍然正确处理索引并正确终止。 

偶数长度数组也很重要，因为指针交叉时不会落在同一索引上。 这测试停止条件是否正确。 使用`left < right`确保每个所需的对都恰好交换一次，而不会撤消之前的交换。
