[LeetCode 第 391 题](https://leetcode.com/problems/perfect-rectangle/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、数学、几何、扫描线

 ## 解决方案

 ## 问题理解

 该问题询问一组较小的轴对齐矩形是否完美地形成一个较大的矩形，没有间隙，也没有重叠。 

每个矩形表示为：```
[xi, yi, ai, bi]
```在哪里：

-`(xi, yi)`是左下角
 -`(ai, bi)`是右上角

 由于矩形是轴对齐的，因此它们的边平行于 x 轴和 y 轴。 

任务是确定所有矩形是否一起创建一个精确的矩形区域。 这意味着：

 1. 最终边界矩形内的每个点都必须被覆盖。 
2. 任何一个点都不能被重复覆盖一次。 
3. 不得有任何孔洞或缺失区域。 
4. 所有矩形的并集本身必须是矩形。 

输入大小可以大到`2 * 10^4`矩形，因此任何试图检查单个单位单元或模拟网格上的几何形状的解决方案都是不可行的。 坐标也可以大到`10^5`在数量级上，这意味着坐标压缩或强力光栅化仍然太昂贵。 

重要的边缘情况包括：

 - 部分重叠的矩形
 - 留下微小间隙的矩形
 - 仅在边缘或角落接触的矩形
 - Duplicate rectangles
 - 单个矩形，应该返回`true`- Complex arrangements where area matches but geometry is still invalid

A naive implementation might only compare total area, but equal area alone is not enough. Two overlapping rectangles can still produce the correct total area if another region is missing. Similarly, checking only boundary coordinates is insufficient because internal overlaps or holes may still exist.

 The challenge is detecting both overlaps and gaps efficiently.

 ## 方法

 ### 蛮力方法

 A brute-force idea is to model the entire 2D plane covered by the rectangles and mark every unit square that gets covered.

 对于每个矩形：

 1. Iterate through all integer coordinate cells it covers.
 2. 在哈希集或网格中标记这些单元格。 
3. If a cell is visited twice, an overlap exists.
 4. After processing all rectangles, verify that the covered cells form one perfect rectangle.

 This approach works conceptually because it directly checks every covered region.

 However, it is far too slow and memory intensive. 坐标可以大到`10^5`，这意味着几何面积可能是巨大的。 即使是一个矩形也可以跨越数十亿个晶胞。 

因此，暴力破解并不实用。 

### 关键见解

 完美的矩形封面有两个关键属性：

 1. 所有小矩形的总面积必须等于最终外接矩形的面积。 
2. 每个内角出现偶数次，而四个外角恰好出现一次。 

第二个观察结果是最佳解决方案的核心。 

考虑一下当矩形完美地组合在一起时会发生什么：

 - 共享边缘导致内角抵消。 
- 只有最终大矩形的四个角保持不匹配。 

我们可以使用哈希集来跟踪角点：

 - 如果某个角出现一次，请添加它。 
- 如果再次出现，请将其删除。 

处理完所有矩形后：

 - 应该保留四个角。 
- 这些角必须是边界矩形的角。 
- 该区域必须完全匹配。 

如果任一条件失败，矩形就不能形成完美的覆盖物。

 ## 算法演练

 ### 最优角集算法

 1. 初始化边界矩形的变量。 

Track:

 - minimum x
 - minimum y
 - maximum x
 - maximum y

 这些值定义了应包含所有内容的外部矩形。 
2. 初始化总面积变量。 

处理每个矩形时，计算：$\text{area} = (a_i - x_i)(b_i - y_i)$将其添加到运行总计中。 
3. 创建角点的哈希集。 

每个矩形贡献四个角：

 -`(xi, yi)`-`(xi, bi)`-`(ai, yi)`-`(ai, bi)`4. 切换集合中的每个角。 

对于每个角落：

 - 如果该角不在该组中，请将其插入。 
- 如果角已经存在，请将其移除。 

这是可行的，因为内角在矩形之间共享，并且应该出现偶数次。 
5. 更新边界矩形。 

对于每个矩形：

 -`min_x = min(min_x, xi)`-`min_y = min(min_y, yi)`-`max_x = max(max_x, ai)`-`max_y = max(max_y, bi)`6. 处理完所有矩形后，验证是否保留了四个角。 

其余的角必须是：

 -`(min_x, min_y)`-`(min_x, max_y)`-`(max_x, min_y)`-`(max_x, max_y)`7. 计算边界矩形的面积。$\text{bounding area} = (\text{max}_x - \text{min}_x)(\text{max}_y - \text{min}_y)$8. 比较面积。 

如果所有小矩形的总面积与外接矩形面积不同，则返回`false`。 
9. 如果所有检查都通过，则返回`true`。 

### 为什么它有效

 该算法依赖于两个不变量。 

首先，完美的覆盖物不能有多余或缺失的区域，因此总面积必须恰好等于边界矩形面积。 

其次，每个内角在矩形之间共享，因此出现偶数次。 切换角会删除这些内部点。 仅保留四个外角。 

如果存在任何重叠或间隙，则至少会破坏以下属性之一：

 - 重叠扭曲区域或角奇偶校验
 - 间隙会扭曲区域或留下额外的不匹配的角落

 这些检查一起足以保证正确性。 

## Python 解决方案```python
from typing import List, Set, Tuple

class Solution:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        min_x = float("inf")
        min_y = float("inf")
        max_x = float("-inf")
        max_y = float("-inf")

        total_area = 0
        corners: Set[Tuple[int, int]] = set()

        for x1, y1, x2, y2 in rectangles:
            # Update bounding rectangle
            min_x = min(min_x, x1)
            min_y = min(min_y, y1)
            max_x = max(max_x, x2)
            max_y = max(max_y, y2)

            # Add rectangle area
            total_area += (x2 - x1) * (y2 - y1)

            # Rectangle corners
            rectangle_corners = [
                (x1, y1),
                (x1, y2),
                (x2, y1),
                (x2, y2),
            ]

            # Toggle corners in the set
            for corner in rectangle_corners:
                if corner in corners:
                    corners.remove(corner)
                else:
                    corners.add(corner)

        expected_corners = {
            (min_x, min_y),
            (min_x, max_y),
            (max_x, min_y),
            (max_x, max_y),
        }

        # Corner validation
        if corners != expected_corners:
            return False

        # Area validation
        bounding_area = (max_x - min_x) * (max_y - min_y)

        return total_area == bounding_area
```该实现紧密遵循前面描述的算法。 

第一部分初始化边界矩形坐标和总累积面积。 

这`corners`set is the key data structure. 每次出现一个角时，它都会在集合中切换。 内角最终会消失，因为它们出现的次数为偶数。 

对于每个矩形：

 - the bounding box is updated
 - the rectangle area is added
 - the four corners are processed

 处理完所有矩形后，代码将构造最终矩形的四个预期角。 

如果剩余的角集与这四个点不同，则矩形不能形成完美的覆盖物。 

最后，将总累积面积与边界矩形面积进行比较。 If both conditions hold, the answer is`True`。 

## 解决方案```go
package main

func isRectangleCover(rectangles [][]int) bool {
	minX, minY := int(1e9), int(1e9)
	maxX, maxY := -int(1e9), -int(1e9)

	totalArea := 0

	corners := make(map[[2]int]bool)

	for _, rect := range rectangles {
		x1, y1, x2, y2 := rect[0], rect[1], rect[2], rect[3]

		// Update bounding rectangle
		if x1 < minX {
			minX = x1
		}
		if y1 < minY {
			minY = y1
		}
		if x2 > maxX {
			maxX = x2
		}
		if y2 > maxY {
			maxY = y2
		}

		// Add area
		totalArea += (x2 - x1) * (y2 - y1)

		rectCorners := [][2]int{
			{x1, y1},
			{x1, y2},
			{x2, y1},
			{x2, y2},
		}

		// Toggle corners
		for _, corner := range rectCorners {
			if corners[corner] {
				delete(corners, corner)
			} else {
				corners[corner] = true
			}
		}
	}

	expectedCorners := map[[2]int]bool{
		{minX, minY}: true,
		{minX, maxY}: true,
		{maxX, minY}: true,
		{maxX, maxY}: true,
	}

	if len(corners) != 4 {
		return false
	}

	for corner := range expectedCorners {
		if !corners[corner] {
			return false
		}
	}

	boundingArea := (maxX - minX) * (maxY - minY)

	return totalArea == boundingArea
}
```Go 实现几乎完全反映了 Python 逻辑。 

主要区别在于 Go 没有内置的元组类型，因此固定大小的数组`[2]int`用于表示角坐标。 

角切换行为是通过`map[[2]int]bool`。 

Go 整数足以解决这个问题，因为最大可能区域仍然​​在 32 位有符号整数范围内，尽管使用`int64`为了额外的安全性也是可以接受的。

from typing import List

class Solution:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        min_x = float("inf")
        min_y = float("inf")
        max_x = float("-inf")
        max_y = float("-inf")

        total_area = 0
        corners = set()

        for x1, y1, x2, y2 in rectangles:
            min_x = min(min_x, x1)
            min_y = min(min_y, y1)
            max_x = max(max_x, x2)
            max_y = max(max_y, y2)

            total_area += (x2 - x1) * (y2 - y1)

            for corner in [
                (x1, y1),
                (x1, y2),
                (x2, y1),
                (x2, y2),
            ]:
                if corner in corners:
                    corners.remove(corner)
                else:
                    corners.add(corner)

        expected = {
            (min_x, min_y),
            (min_x, max_y),
            (max_x, min_y),
            (max_x, max_y),
        }

        if corners != expected:
            return False

        return total_area == (max_x - min_x) * (max_y - min_y)

 ## 边缘情况

 ### 具有匹配外边界的重叠矩形

 当矩形内部重叠但仍产生相同的外部边界矩形时，就会出现一种棘手的情况。 仅检查角坐标的简单实现可能会错误地接受此类情况。 

区域检查可以防止此错误。 重叠区域在总面积中进行多次计数，使得累加面积大于外接矩形面积。 

### 矩形内隐藏的间隙

 另一个微妙的情况是，外部边界看起来正确，但结构内部某处有一个洞。 

如果重叠补偿了其他地方缺失的区域，则纯区域检查有时可能会失败。 角奇偶校验会捕获这些无效的内部结构，因为集合中仍保留额外的不匹配角。 

### 共享边缘和内角

 当矩形完全对齐时，相邻矩形之间共享许多角。 有缺陷的实现可能会意外地错误地计算共享角。 

切换机制可以优雅地处理这种情况。 每个内角都会出现偶数次并自动取消。 最后仅保留四个真正的外角。
