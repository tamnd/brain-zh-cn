[LeetCode 第 335 题](https://leetcode.com/problems/self-crossing/)

 **难度：** 🔴难
 **主题：** 数组、数学、几何

 ## 解决方案

 ## 问题理解

 该问题描述了在二维网格上追踪的路径。 我们从原点开始`(0, 0)`并根据中的值移动`distance`大批。 移动方向始终按以下重复顺序逆时针旋转：

 - 北
 - 西
 - 南
 - 东

 然后该模式再次重复。 

例如，如果`distance = [2,1,1,2]`，运动顺序为：

 - 向北移动2个单位
 - 向西移动1个单位
 - 向南移动1个单位
 - 向东移动2个单位

 任务是确定路径是否在任意点与自身相交。 当新绘制的线段与任何先前的线段重叠或相交时，就会发生自交叉。 

重要的细节是运动总是发生在轴对齐的方向上，这显着简化了几何形状。 每个部分都是垂直的或水平的。 

限制条件很大：

 -`distance.length`可以达到`10^5`- 每个距离值也可以达到`10^5`这些约束立即排除了每对线段之间昂贵的几何相交检查。 一个`O(n^2)`解决方案对于`10^5`动作。 

另一个重要的观察结果是运动模式是高度结构化的。 由于方向以固定的逆时针顺序旋转，因此只有少数附近的线段可能与当前线段相交。 

一些边缘情况尤其重要：

 - 非常短的数组不能自交叉
 - 重叠的线段算作交叉
 - 精确接触端点也算交叉
 - 螺旋状向内运动模式经常产生交叉点
 - 等长的移动可以创建天真的逻辑会忽略的特殊重叠情况

 正确的解决方案必须仔细处理所有这些情况。 

## 方法

 ### 蛮力方法

 最直接的解决方案是显式构造每个线段，并根据所有先前的非相邻线段检查新创建的线段。 

对于每个动作：

 1. 计算线段端点。 
2. 将新段与所有早期段进行比较。 
3. 如果存在交集，则返回`true`。 

这种方法是正确的，因为每个可能的交叉都是使用标准线段相交逻辑显式检查的。 

然而，这变得极其昂贵。 如果有`n`段，比较的总数约为：$$1 + 2 + 3 + \dots + (n-1) = O(n^2)$$和`n = 10^5`，这是不可行的。 

### 最佳观察

 关键的见解是，由于运动方向以固定的逆时针模式旋转，因此一个线段只能与一小部分先前的线段相交。 

随着路径的发展，只有三种几何交叉模式是可能的：

 1. 当前线提前 3 步与线交叉。 
2. 当前行与前 4 步的行重叠。 
3. 当前线提前 5 步与线交叉。 

这些模式完全覆盖了这个运动系统中所有可能的自我交叉。 

这意味着我们永远不需要存储所有线段的坐标或执行一般的几何相交检查。 我们只需要涉及最近距离的恒定时间比较。 

因此，该解决方案变成了对阵列的单个线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 显式构造并比较所有段 |
 | 最佳 | O(n) | O(1) | O(1) | 使用螺旋运动特有的几何交叉图案 |

 ## 算法演练

 ### 几何案例

 最佳解决方案检查三个特定的交叉配置。 

### 情况 1：当前线提前 3 步穿过线

 这是最简单的交叉模式。 

假设我们正在处理段`i`。 

当前线段与线段交叉`i-3`如果：$$distance[i] \ge distance[i-2]$$和$$distance[i-1] \le distance[i-3]$$这对应于向内折叠并与自身相交的路径。 

### 情况 2：当前线与线提前 4 步重叠

 当路径形成循环并且最新的段直接落在较早的段的顶部时，就会发生这种情况。 

状况：$$distance[i-1] = distance[i-3]$$和$$distance[i] + distance[i-4] \ge distance[i-2]$$### 情况 3：当前线提前 5 步穿过线

 这是最复杂的内螺旋情况。 

状况：$$distance[i-2] \ge distance[i-4]$$

$$distance[i] + distance[i-4] \ge distance[i-2]$$

$$distance[i-1] \le distance[i-3]$$

$$distance[i-1] + distance[i-5] \ge distance[i-3]$$这捕捉到了紧密的螺旋交叉场景。 

### 逐步算法

 1. 从索引开始迭代数组`3`，因为至少需要四个线段才能创建交叉点。 
2. 对于每个索引`i`，首先检查段的简单交叉情况`i-3`。 
3. 然后检查段的重叠情况`i-4`， 如果`i >= 4`。 
4. 然后对照线段检查螺旋交叉情况`i-5`， 如果`i >= 5`。 
5. 如果满足任何条件，立即返回`true`。 
6. 如果循环结束时没有检测到交叉，则返回`false`。 

### 为什么它有效

 运动方向有固定的和循环的。 由于这种结构，新添加的线段不能与任意远距离线段相交。 任何有效的自交叉必须发生在上述三个局部几何配置之一内。 

这三种情况穷尽了逆时针螺旋路径与其自身相交的所有可能方式。 由于每个新段都会根据所有有效的交叉模式进行检查，因此算法可以保证检测到每个自交叉。 

## Python 解决方案```python
from typing import List

class Solution:
    def isSelfCrossing(self, distance: List[int]) -> bool:
        n = len(distance)

        for i in range(3, n):

            # Case 1:
            # Current line crosses the line 3 steps ahead
            if (
                distance[i] >= distance[i - 2]
                and distance[i - 1] <= distance[i - 3]
            ):
                return True

            # Case 2:
            # Current line overlaps the line 4 steps ahead
            if i >= 4:
                if (
                    distance[i - 1] == distance[i - 3]
                    and distance[i] + distance[i - 4] >= distance[i - 2]
                ):
                    return True

            # Case 3:
            # Current line crosses the line 5 steps ahead
            if i >= 5:
                if (
                    distance[i - 2] >= distance[i - 4]
                    and distance[i] + distance[i - 4] >= distance[i - 2]
                    and distance[i - 1] <= distance[i - 3]
                    and distance[i - 1] + distance[i - 5] >= distance[i - 3]
                ):
                    return True

        return False
```该实现直接反映了前面讨论的三种几何交叉情况。 

循环从索引处开始`3`因为在可以穿越之前至少需要四个路段。 

第一个条件检查当前线段是否与前三个移动的线段相交。 这是最常见的自交叉配置，可捕获简单的向内折叠。 

第二个条件处理重叠情况。 等长的相对边可能会导致路径直接落在前一段上，而不是仅仅穿过它。 

第三个条件捕获更紧密的向内螺旋，其中最新的线段与较早移动的五段线段相交。 

每次检查仅使用附近的索引，这使每次迭代的时间和空间使用保持恒定。 

一旦检测到交叉，该函数立即返回`True`。 如果处理完所有段后没有发生交叉，则函数返回`False`。 

## 解决方案```go
func isSelfCrossing(distance []int) bool {
	n := len(distance)

	for i := 3; i < n; i++ {

		// Case 1:
		// Current line crosses the line 3 steps earlier
		if distance[i] >= distance[i-2] &&
			distance[i-1] <= distance[i-3] {
			return true
		}

		// Case 2:
		// Current line overlaps the line 4 steps earlier
		if i >= 4 {
			if distance[i-1] == distance[i-3] &&
				distance[i]+distance[i-4] >= distance[i-2] {
				return true
			}
		}

		// Case 3:
		// Current line crosses the line 5 steps earlier
		if i >= 5 {
			if distance[i-2] >= distance[i-4] &&
				distance[i]+distance[i-4] >= distance[i-2] &&
				distance[i-1] <= distance[i-3] &&
				distance[i-1]+distance[i-5] >= distance[i-3] {
				return true
			}
		}
	}

	return false
}
```Go 实现几乎与 Python 版本相同，因为该算法仅依赖于索引算术和比较。 

Go 切片天然支持高效的索引访问，因此不需要额外的数据结构。 

整数溢出在这里不是问题，因为涉及的最大值最多为：$$10^5 + 10^5 = 2 \times 10^5$$很容易适合 Go 的内部`int`类型。 

与 Python 不同，Go 不需要为此解决方案显式类型提示或导入。

 ## 边缘情况

 ### 非常小的数组

 少于四次运动的阵列不可能自交叉，因为至少需要四个线段才能形成交叉点。 幼稚的实现可能会意外访问负索引或错误地报告交叉。 

该实现通过在索引处开始循环来避免这种情况`3`。 

### 重叠片段

 交叉不仅仅意味着垂直交叉。 直接落在较早段之上的段也很重要。 

例如：```
[1,1,2,1,1]
```创建重叠情况而不是标准交叉。 

这就是第二个几何条件存在的原因。 如果没有它，就会错过重叠的案例。 

### 紧密的向内螺旋

 有些向内的螺旋线经过几圈才相交，不满足简单相交条件。 

例如：```
[1,1,1,2,1]
```需要更高级的 Case 3 逻辑。 

仅与段进行比较的幼稚实现`i-3`会错误返回`false`。 第三个条件确保正确检测到这些更深的螺旋交叉点。 

### 端点接触

 准确地触摸拐角或端点仍然算作自交叉。 

这就是为什么该实现使用`>=`和`<=`比较而不是严格的不平等。 相等边界正确地将端点接触识别为交叉点。
