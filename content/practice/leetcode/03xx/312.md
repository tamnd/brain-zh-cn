 # LeetCode 312，爆裂气球

 ## 问题理解

 问题给了我们一个数组`nums`，其中每个元素代表一个包含数字的气球。 当我们在指数处爆破气球时`i`，我们获得的硬币等于：$\text{coins} = nums[i-1] \times nums[i] \times nums[i+1]$重要的细节是，当气球被移除时，气球的邻居会动态变化。 气球破裂后就会消失，剩下的气球会变得相邻。 

如果气球没有左或右邻居，因为它位于边界，我们将丢失的邻居视为具有值`1`。 

目标是通过选择爆破所有气球的最佳顺序来确定我们可以收集的最大硬币数量。 

输入包括：

 - 整数数组`nums`-`nums[i]`是画在气球上的值`i`-`n`可以大到`300`输出是一个整数，表示可实现的最大硬币数。 

约束条件是暴力破解不起作用的关键指标：

 - 最多可以有`300`气球
 - 突发顺序的每个排列都可能不同
 -`300!`可能的订单是天文数字

 这立即表明我们需要一个动态规划解决方案。 

一些边缘情况很重要：

 - 长度数组`1`- 包含零的数组
 - 所有数字都相同的数组
 - 早期爆破小气球可以在以后实现更大乘法的情况
 - 边界气球，因为它们使用有价值的虚拟邻居`1`天真的贪婪方法很容易失败，因为局部选择会影响未来的邻居关系。 

## 方法

 ### 蛮力方法

 暴力解决方案会尝试所有可能的气球爆裂顺序。 

在每一步中，我们选择一个要破裂的气球，计算从其当前邻居获得的硬币，将其移除，并递归地解决较小的问题。 由于每个递归级别都可以在剩余的气球中进行选择，因此可能性的总数呈阶乘增长。 

这种方法是正确的，因为它详尽地探索了所有有效的突发序列并返回最大总数。 

然而，它太慢了。 和`n = 300`，阶乘复杂度在任何实际时间限制内都不可能计算。 

### 最佳解决方案的关键见解

 主要的困难来自于气球的破裂会改变邻里关系。 

关键的见解不是考虑哪个气球首先破裂，而是考虑子阵列内哪个气球最后破裂。 

假设我们正在解决索引之间气球的子问题`left`和`right`。 

如果气球`k`是该间隔内最后一次气球爆炸：

 - 里面的所有其他气球`(left, right)`已经被删除了
 ——那一刻，气球`k`仅与`left`和`right`- 因此，获得的币是固定的并且易于计算

 这将困难的动态问题转化为区间动态规划问题。 

为了简化边界处理，我们添加了具有值的虚拟气球`1`在两端。 

如果变换后的数组是：```
[1] + nums + [1]
```那么递归就变成：$dp[left][right] = \max_{left < k < right} \left(dp[left][k] + dp[k][right] + nums[left] \times nums[k] \times nums[right]\right)$这是有效的，因为：

 -`dp[left][k]`代表着打破之间的一切`left`和`k`-`dp[k][right]`代表着打破之间的一切`k`和`right`-`k`是间隔中的最后一个突发

 该问题成为经典的区间DP。

 ## 算法演练

 1. 创建一个带有虚拟边界气球的新阵列。 

我们前置和附加`1`到原始数组：```
balloons = [1] + nums + [1]
```这消除了对边缘气球的特殊处理，因为每个气球现在总是有有效的邻居。 
2. 创建二维DP表。 

让：```
dp[left][right]
```代表严格在之间爆破所有气球可获得的最大硬币`left`和`right`。 

区间是开区间，意思是`left`和`right`他们自己并没有在这个子问题中崩溃。 
3. 迭代间隔长度。 

我们先解决较小的区间，然后再解决较大的区间，因为较大的区间依赖于较小的区间。 

对于每个间隔`(left, right)`：

 - 尝试所有可能的气球`k`他们之间
 - 假设`k`是该时间间隔内最后一次气球爆炸
 4. 计算获得的硬币，如果`k`是最后一个。 

由于区间内的所有气球除了`k`已经消失了：```
balloons[left] * balloons[k] * balloons[right]
```是爆裂赚到的金币吗`k`。 
5. 添加子问题的结果。 

总计变为：```
dp[left][k] + dp[k][right] + current_coins
```因为左右区间独立一次`k`被固定为最终的气球。 
6. 存储最大结果。 

我们采取尽可能最好的选择`k`：```
dp[left][right] = max(...)
```7.返回答案。 

最终的答案是：```
dp[0][n - 1]
```在哪里`n`是填充数组的大小。 

### 为什么它有效

 核心不变量是当我们选择气球时`k`当最后一个气球在间隔中破裂时`(left, right)`，它的邻居保证恰好是`left`和`right`。 这使得硬币变得具有确定性。 

因为每个有效的爆裂序列在每个间隔中都恰好有最后一个气球，所以递归探索了所有可能性而不重复。 DP 表确保每个区间都求解一次，从而提供正确性和效率。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        balloons = [1] + nums + [1]
        n = len(balloons)

        dp = [[0] * n for _ in range(n)]

        for length in range(2, n):
            for left in range(n - length):
                right = left + length

                for k in range(left + 1, right):
                    coins = (
                        dp[left][k]
                        + dp[k][right]
                        + balloons[left] * balloons[k] * balloons[right]
                    )

                    dp[left][right] = max(dp[left][right], coins)

        return dp[0][n - 1]
```实施首先添加具有价值的虚拟气球`1`到数组的两端。 这简化了边界条件，因为每个气球总是有邻居。 

这`dp`表存储区间的解决方案。 最初，所有值都是`0`因为空的间隔不会产生硬币。 

外循环从小到大迭代间隔大小。 这种排序至关重要，因为较大的间隔取决于已解决的较小子问题。 

对于每个间隔`(left, right)`，算法尝试每一个可能的气球`k`当最后一个气球在那段时间破裂时。 

递归结合了：

 - 左子区间的最优结果
 - 右侧子区间的最优结果
 - 爆裂获得的金币`k`最后

 最后，`dp[0][n - 1]`包含整个数组的最佳可能答案。 

## 解决方案```go
func maxCoins(nums []int) int {
	balloons := make([]int, 0, len(nums)+2)
	balloons = append(balloons, 1)

	for _, num := range nums {
		balloons = append(balloons, num)
	}

	balloons = append(balloons, 1)

	n := len(balloons)

	dp := make([][]int, n)
	for i := range dp {
		dp[i] = make([]int, n)
	}

	for length := 2; length < n; length++ {
		for left := 0; left < n-length; left++ {
			right := left + length

			for k := left + 1; k < right; k++ {
				coins := dp[left][k] +
					dp[k][right] +
					balloons[left]*balloons[k]*balloons[right]

				if coins > dp[left][right] {
					dp[left][right] = coins
				}
			}
		}
	}

	return dp[0][n-1]
}
```Go 实现遵循与 Python 解决方案相同的区间动态规划策略。 

使用切片代替 Python 列表，并使用嵌套手动初始化 2D DP 表`make`来电。 

Go 整数足以解决这个问题，因为最大可能的答案符合给定约束下的标准整数限制。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n3) | 三个嵌套循环：间隔长度、左边界和最后的气球选择 |
 | 空间| O(n²) | DP 表存储所有间隔的结果 |

 DP表包含`O(n²)`状态因为每对`(left, right)`定义一个区间。 

对于每个间隔，我们迭代每个可能的最后一个气球`k`，添加另一个因素`O(n)`。 

因此，总时间复杂度变为`O(n³)`。 

和`n <= 300`，这种复杂性是可以接受的。

 ## 边缘情况

 ### 单气球

 当输入仅包含一个气球时，算法必须正确地将其邻居视为具有值的虚拟气球`1`。 

例如：```
nums = [5]
```结果应该是：```
1 × 5 × 1 = 5
```如果没有边界填充，实现通常会产生索引错误或不正确的邻居计算。 填充数组技术自然地处理了这个问题。 

### 包含零的气球

 零值气球可以极大地改变最佳破裂顺序。 

例如：```
nums = [0, 1, 5]
```太晚突破零可能会消除更大产品的机会。 贪婪的方法在这里很容易失败。 

间隔 DP 解决方案探索每个间隔的每个可能的最后一个气球，确保正确处理零值。 

### 非常小的间隔

 内部只有一个气球的区间是 DP 表的基本构建块。 

对于间隔`(left, right)`在哪里：```
right = left + 2
```恰好有一个气球可能最后破裂。 

不正确的间隔迭代顺序可能会使所需的子问题无法计算。 通过按长度递增的顺序处理间隔，该实现保证了所有依赖关系在需要之前就已得到解决。
