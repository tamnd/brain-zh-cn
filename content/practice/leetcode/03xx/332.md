[LeetCode 第 332 题](https://leetcode.com/problems/reconstruct-itinerary/)

 **难度：** 🔴难
 **主题：** 数组、字符串、深度优先搜索、图论、排序、堆（优先级队列）、欧拉电路

 ## 解决方案

 ## 问题理解

 问题是要求我们根据机票列表重建航班行程。 每张机票都是单程航班，以一对机场代码表示`[from, to]`。 旅行者总是从`"JFK"`，并且行程必须使用**所有门票恰好一次**。 如果存在多个有效行程，则应返回具有**最小字典顺序**的行程。 

输入是机票列表，其中每个机场代码都是由三个大写字母组成的字符串。 最多可有 300 张门票。 这是一个中等大小的输入，因此票数呈指数级增长的算法将不会表现良好。 

输出是一个字符串列表，以重建的旅行顺序表示机场。 例如，如果`["JFK", "ATL", "SFO"]`返回，表示从 JFK 飞往 ATL，然后从 ATL 飞往 SFO 的航班。 

重要的约束和保证是：

 - 每张门票只能使用一次。 
- 所有门票至少有一个有效行程。 
- 机场代码是长度为 3 的唯一字符串。 
- 可能有多个有效行程，因此必须考虑词汇顺序。 

潜在的边缘情况包括来自同一机场的多个目的地的机票、断开的路径（尽管问题保证了连通性）以及形成循环的机票。 

## 方法

 **暴力方法**是生成从以下位置开始的所有可能的票证排列：`"JFK"`，检查哪些序列仅使用所有票证一次，然后选择字典顺序最小的一个。 虽然这种方法是正确的，但它本质上是**组合**：`n`门票，有`n!`可能的序列。 这对于`n = 300`。 

**最佳方法**依赖于这样的观察：该问题相当于在有向图中寻找**欧拉路径**。 每个机场都是一个节点，每张机票都是一条有向边。 由于行程必须仅使用一次所有门票，因此我们需要仅遍历图中的所有边一次。 为了确保词汇顺序，我们可以将每个机场的出发目的地存储在**优先级队列或排序列表**中。 使用带有回溯的**深度优先搜索（DFS）**，我们可以递归地构造路径`"JFK"`同时始终首先访问最小的词汇目的地。 这保证了生成的路径具有最小的词法顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 生成所有排列，过滤有效行程，按字典顺序选择最小的 |
 | 最佳 | O(E 日志 E) | O(V + E) | 具有词汇顺序优先级队列的 DFS； 欧拉路径确保所有边都被访问 |

 ## 算法演练

 1. **图构建：** 构建一个图，其中键是出发机场，值是目的地机场的最小堆（优先级队列）。 这使我们始终能够有效地选择词汇顺序最小的下一个机场。 
2. **DFS遍历：** 从以下位置开始DFS`"JFK"`。 在每个机场，虽然优先级队列中还有剩余目的地，但首先递归地访问最小的词汇目的地。 
3. **后序路径构建：** 仅在探索机场的所有出站边缘后才将机场附加到行程中。 这会以相反的顺序构造路径，因为我们在访问所有更深的节点后追加。 
4. **反转结果：** 由于行程是后序构建的，因此对收集到的列表进行反转即可得到正确的行程。 

**为什么有效：** 该算法之所以有效，是因为我们对有向图中的欧拉路径有效地执行了 **Hierholzer 算法**。 使用优先级队列可确保每个决策点的词汇顺序。 由于所有票证（边）仅使用一次，因此生成的路径包含每张票证，满足所有约束。 

## Python 解决方案```python
from typing import List
from collections import defaultdict
import heapq

class Solution:
    def findItinerary(self, tickets: List[List[str]]) -> List[str]:
        graph = defaultdict(list)
        for frm, to in tickets:
            heapq.heappush(graph[frm], to)
        
        result = []
        
        def dfs(airport: str):
            heap = graph[airport]
            while heap:
                next_airport = heapq.heappop(heap)
                dfs(next_airport)
            result.append(airport)
        
        dfs("JFK")
        return result[::-1]
```**实施说明：**

 我们首先使用最小堆字典创建一个图来维护词汇顺序。 DFS 探索每个机场，总是选择最小的可用目的地。 我们在探索所有出港航班（订单后）后添加机场，确保所有机票都仅使用一次。 最后，我们反转结果以获得正确的行程顺序。 

## 解决方案```go
package main

import (
	"container/heap"
	"sort"
)

func findItinerary(tickets [][]string) []string {
	graph := make(map[string]*StringHeap)
	for _, t := range tickets {
		if _, ok := graph[t[0]]; !ok {
			graph[t[0]] = &StringHeap{}
		}
		heap.Push(graph[t[0]], t[1])
	}
	result := []string{}
	var dfs func(string)
	dfs = func(airport string) {
		h, exists := graph[airport]
		for exists && h.Len() > 0 {
			next := heap.Pop(h).(string)
			dfs(next)
		}
		result = append(result, airport)
	}
	dfs("JFK")
	// reverse the result
	for i, j := 0, len(result)-1; i < j; i, j = i+1, j-1 {
		result[i], result[j] = result[j], result[i]
	}
	return result
}

// Implement min-heap for strings
type StringHeap []string

func (h StringHeap) Len() int           { return len(h) }
func (h StringHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h StringHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *StringHeap) Push(x any) {
	*h = append(*h, x.(string))
}

func (h *StringHeap) Pop() any {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[0 : n-1]
	return x
}
```**Go 特定注释：** 我们为字符串实现了自定义最小堆，因为标准`container/heap`需要一个接口。 DFS逻辑与Python相同，并且反转步骤是手动完成的。 

## 工作示例

 **示例1：**

 门票：`[["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]]`堆化后的图：```
JFK -> ["MUC"]
MUC -> ["LHR"]
LHR -> ["SFO"]
SFO -> ["SJC"]
```DFS遍历：

 1. 从 JFK 出发，弹出 MUC → DFS(MUC)
 2. 在MUC，弹出LHR → DFS(LHR)
 3. 在 LHR 处，弹出 SFO → DFS(SFO)
 4. 在SFO，弹出SJC → DFS(SJC)
 5. 在SJC，没有传出→追加SJC
 6. 回溯：附加 SFO、LHR、MUC、JFK

 结果（反转）：`["JFK","MUC","LHR","SFO","SJC"]`**示例2：**

 门票：`[["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]]`堆化后的图：```
JFK -> ["ATL", "SFO"]
ATL -> ["JFK", "SFO"]
SFO -> ["ATL"]
```DFS遍历：

 1. 从 JFK 出发，弹出 ATL → DFS(ATL)
 2. 在 ATL，弹出 JFK → DFS(JFK)
 3. 在 JFK，弹出 SFO → DFS(SFO)
 4. 在SFO，弹出ATL → DFS(ATL)
 5. 在 ATL，弹出 SFO → DFS(SFO)
 6. 在 SFO，无传出 → 追加 SFO
 7.回溯：追加ATL、ATL、SFO、JFK、JFK

 结果（反转）：`["JFK","ATL","JFK","SFO","ATL","SFO"]`## 复杂度分析
