 # LeetCode 342 - 四的幂

 ## 问题理解

 这个问题要求我们判断给定的整数是否`n`是四的精确幂。 换句话说，我们需要检查是否存在某个整数`x`这样：```
n = 4^x
```四的幂的例子有：```
1  = 4^0
4  = 4^1
16 = 4^2
64 = 4^3
```输入由单个整数组成`n`，预期输出是一个布尔值：

 - 返回`true`如果`n`是四的幂。 
- 返回`false`否则。 

约束允许的值来自：```
-2^31 <= n <= 2^31 - 1
```这意味着输入可以是负数、零或正数。 由于四的幂始终是正整数，因此任何非正数都会立即满足条件。 

一个重要的细节是后续问题：

 > 你能在没有循环/递归的情况下解决它吗？ 

此暗示强烈表明预期的最佳解决方案使用数学或位操作属性，而不是重复除以四。 

一些边缘情况很重要：

 -`n <= 0`- 四的幂必须是正数。 
- 价值观如`0`,`-4`， 或者`-16`应该返回`false`。 
-`n = 1`- 自从`1 = 4^0`，答案应该是`true`。 
- 不是四的幂的二的幂

 - 例如：```
8  = 2^3
32 = 2^5
```- 这些仅包含一组位，但它们不是四的幂。 
- 接近整数限制的大值

 - 解决方案应保持高效并避免溢出问题。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是重复将数字除以`4`虽然它仍然可以被整除`4`。 

其逻辑工作原理如下：

 1.如果`n <= 0`， 返回`false`。 
2. 虽然`n % 4 == 0`, 除`n`经过`4`。 
3、最后：

 - 如果`n == 1`，它是四的幂。 
- 否则，就不是了。 

这种方法是正确的，因为四的每一次方都可以化简为`1`通过重复除以`4`。 

例如：```
16 -> 4 -> 1
64 -> 16 -> 4 -> 1
```如果在任何一点这个数字都不能被整除`4`，那么它不可能是四的幂。 

尽管这个解决方案对于给定的约束已经是有效的，但后续要求一个没有循环或递归的解决方案。 

### 最佳位操作方法

 关键的见解是每一个四的幂都有两个特殊属性：

 1.它也是2的幂。 
2. 其单个设置位仅出现在奇数位置。 

回想一下二进制表示：```
1   = 0001
4   = 0100
16  = 00010000
64  = 01000000
```请注意：

 - 每个值都只有一个`1`少量。 
- 该位总是出现在以下位置：```
0, 2, 4, 6, ...
```要检查一个数字是否是 2 的幂，我们使用：```
n & (n - 1) == 0
```这是可行的，因为 2 的幂恰好包含一个设置位。 

然而，四的幂只是二的幂的子集。 例如：```
8  = 1000
32 = 100000
```这些是二的幂但不是四的幂。 

为了区分它们，我们使用十六进制掩码：```
0x55555555
```其二进制形式为：```
01010101010101010101010101010101
```该掩码仅保留有效的四次方位置中的位。 

所以最终的条件是：

 1.`n > 0`2.`n & (n - 1) == 0`3.`n & 0x55555555 != 0`如果一切为真，那么`n`是四的幂。

 ## 算法演练

 1.首先检查是否`n`是积极的。 

四的幂必须大于零。 如果`n <= 0`，立即返回`false`。 
2. 检查是否`n`是二的幂。 

使用表达式：```
n & (n - 1)
```2 的幂恰好有一个设置位。 减法`1`翻转所有低位，因此 AND 运算仅在 2 的幂时变为零。 

示例：```
16 = 10000
15 = 01111
AND = 00000
```但：```
12 = 01100
11 = 01011
AND = 01000
```3. 验证设置位是否处于有效的四次方位置。 

使用面膜：```
0x55555555
```这款面膜含有`1`s 仅在对应于四的幂的位置。 

履行：```
n & 0x55555555
```如果结果非零，则该位位于正确的位置。 
4. 返回合并结果。 

仅当满足所有条件时，该数字才是四的幂。 

### 为什么它有效

 该算法依赖于两个数学属性：

 - 每个四的幂也是二的幂，这意味着它恰好包含一组位。 
- 四的幂的单个设置位总是出现在偶数索引的二进制位置中。 

第一个条件消除具有多个设置位的数字，第二个条件消除不是四的幂的二的幂。 它们共同唯一地确定了四的幂。 

## Python 解决方案```python
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        return (
            n > 0 and
            (n & (n - 1)) == 0 and
            (n & 0x55555555) != 0
        )
```该实现由组合成单个返回语句的三个逻辑检查组成。 

第一个条件确保该数字为正数。 这会立即删除无效输入，例如零和负数。 

第二个条件检查该数字是否是 2 的幂。 表达式：```python
(n & (n - 1)) == 0
```是一种经典的位操作技巧，它之所以有效，是因为 2 的幂恰好包含一个设置位。 

第三个条件使用mask`0x55555555`验证设置位是否出现在有效的四次幂位置。 如果没有这一步，值如`8`或者`32`会错误地通过。 

所有检查都是恒定时间操作，使得该解决方案极其高效。 

## 解决方案```go
func isPowerOfFour(n int) bool {
	return n > 0 &&
		(n&(n-1)) == 0 &&
		(n&0x55555555) != 0
}
```Go 实现与 Python 版本几乎相同，因为两种语言都直接支持按位运算。 

一个小区别是 Go 使用显式整数运算符，没有自动布尔链接语法差异。 逻辑本身保持不变。 

常数`0x55555555`在标准 LeetCode 环境中安全地适合 Go 的整数范围。

 ## 边缘情况

 一种重要的边缘情况是输入为零或负时。 四的幂是严格正的，因为四的每次幂都会产生正结果。 仅检查整除性或位模式的简单实现可能会意外地错误处理负值。 该实现通过立即要求来防止这种情况发生`n > 0`。 

另一个重要案例是`n = 1`。 许多实现忘记了这一点`1`是四的有效幂，因为：```
1 = 4^0
```位操作方法可以正确处理这种情况，因为`1`恰好包含一个设置位，并且该位位于有效的四次方位置。 

第三种关键边缘情况涉及 2 的幂但不是 4 的幂的数字，例如`8`或者`32`。 这些值通过了经典的二次幂检查：```
n & (n - 1) == 0
```如果没有额外的掩码检查，他们会错误地返回`true`。 面具`0x55555555`确保单个设置位仅出现在允许的位置，从而正确拒绝这些值。
