[LeetCode 第 387 题](https://leetcode.com/problems/first-unique-character-in-a-string/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、队列、计数

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅由小写英文字母组成。 我们必须找到在整个字符串中只出现一次的第一个字符的索引。 如果每个字符出现多次，我们返回`-1`。 

关键细节是我们正在根据字符串中的位置而不是字母顺序来查找第一个非重复字符。 例如，在`"loveleetcode"`, 字符`'v'`只出现一次并且早于其他唯一字符出现，所以答案是索引`2`。 

输入大小可以大到`10^5`，这意味着我们需要一个有效的解决方案。 重复扫描字符串中的每个字符的简单解决方案可能会变得太慢，因为在最坏的情况下可能需要二次时间。 

由于该字符串仅包含小写英文字母，因此最多有 26 个不同的字符。 这个约束使我们能够非常有效地使用计数结构。 

立即识别几个边缘情况非常重要。 字符串可能只包含重复的字符，例如`"aabb"`，在这种情况下答案是`-1`。 一个字符串可能只包含一个字符，例如`"z"`，应该返回`0`。 另一个重要的情况是当第一个唯一字符出现在字符串末尾附近时，这意味着我们不能在计数过程中提前停止。 

## 方法

 ### 蛮力方法

 一种简单的解决方案是逐一检查每个字符并计算它在字符串中出现的次数。 

对于每个索引`i`，我们再次扫描整个字符串并计算出现次数`s[i]`。 如果计数正好是`1`，然后我们立即返回`i`因为我们是从左到右扫描的。 

这种方法是正确的，因为每个字符都被彻底检查，并且第一个字符出现频率`1`被返回。 然而，它的效率很低，因为对于每个字符，我们可能会再次扫描整个字符串。 

如果字符串长度为`n`，那么对于每一个`n`我们可能会表演另一个角色`O(n)`扫描。 这会产生`O(n^2)`时间复杂度，对于`n = 10^5`。 

### 最佳方法

 关键的观察结果是该问题完全取决于字符频率。 我们可以对所有字符频率进行一次计数并将其存储在哈希映射或频率数组中，而不是重复重新计数字符。 

计算频率后，我们从左到右第二次遍历字符串。 第一个出现频率为的字符`1`就是答案。 

这可以有效地工作，因为计数频率允许在第二遍期间对每个字符进行恒定时间查找。 

由于小写英文字母限制为 26 个字符，因此我们可以使用哈希映射或固定大小的数组。 固定大小的数组效率稍高，因为数组索引比哈希映射查找更快。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 重新计算每个字符的出现次数 |
 | 最佳| O(n) | O(1) | O(1) | 使用两次通过的频率计数 |

 ## 算法演练

 1. 创建一个大小为 26 且用零初始化的频率数组。 每个位置代表一个小写英文字母`'a'`到`'z'`。 
2. 遍历一次字符串并统计每个字符的出现次数。 对于一个角色`c`，使用计算其索引`ord(c) - ord('a')`在 Python 中或`c - 'a'`在围棋中。 增加相应的频率。 
3. 从左到右第二次遍历字符串。 这保留了字符的原始顺序。 
4. 对于每个字符，检查其在数组中的出现频率。 如果频率恰好是`1`，立即返回当前索引，因为这是第一个非重复字符。 
5. 如果遍历结束没有找到唯一字符，则返回`-1`。 

选择频率数组是因为问题只保证小写英文字母。 这提供了恒定大小的存储和非常快速的查找。 

### 为什么它有效

 该算法之所以有效，是因为第一遍计算了字符串中每个字符的准确出现次数。 在第二遍期间，字符按其原始顺序进行检查。 因此，频率等于的第一个字符`1`必须是字符串中的第一个非重复字符。 

## Python 解决方案```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        frequency = [0] * 26

        # Count character frequencies
        for char in s:
            index = ord(char) - ord('a')
            frequency[index] += 1

        # Find the first unique character
        for i, char in enumerate(s):
            index = ord(char) - ord('a')

            if frequency[index] == 1:
                return i

        return -1
```该实现遵循前面描述的精确的两遍策略。 

第一个循环构建频率数组。 每个字符都映射到一个整数索引`0`和`25`。 例如，`'a'`映射到`0`,`'b'`映射到`1`， 等等。 

第二个循环按原始顺序扫描字符串。 一旦出现出现频率的字符`1`找到后，立即返回其索引。 

如果不存在这样的字符，函数返回`-1`循环完成后。 

使用固定大小的数组而不是字典可以使实现高效且简单，因为问题只保证小写英文字母。 

## 解决方案```go
func firstUniqChar(s string) int {
    frequency := make([]int, 26)

    // Count character frequencies
    for _, char := range s {
        index := char - 'a'
        frequency[index]++
    }

    // Find the first unique character
    for i, char := range s {
        index := char - 'a'

        if frequency[index] == 1 {
            return i
        }
    }

    return -1
}
```Go 解决方案与 Python 版本几乎相同。 长度为 26 的切片存储字符频率。 

Go 特有的一个细节是迭代字符串`range`产生 Unicode 符文。 由于问题保证小写英文字母，因此符文处理在这里是完全安全的。 

该解决方案不需要担心整数溢出，因为频率最多为`10^5`，它很容易适合 Go 的整数类型。

 ## 边缘情况

 一个重要的边缘情况是每个字符都重复的字符串，例如`"aabbcc"`。 粗心的实现可能会错误地返回最后检查的索引或无法处理唯一字符的缺失。 该实现正确完成了第二次遍历并返回`-1`。 

另一种重要的边缘情况是仅包含一个字符的字符串，例如`"x"`。 由于该角色只出现一次，因此答案应该是`0`。 频率计数方法自然可以处理这个问题，因为单个字符接收频率`1`。 

当第一个唯一字符出现在字符串中很晚的时候，就会出现第三种重要的边缘情况，例如`"aabbccd"`。 某些实现可能会在遇到重复字符后错误地过早停止。 该解决方案继续扫描，直到找到第一个频率等于`1`，确保返回正确的索引。 

最后一种边缘情况涉及所有字符都是唯一的字符串，例如`"abcdef"`。 该算法必须返回第一个索引，即`0`。 由于第二遍按顺序检查字符，因此第一个字符立即满足唯一性条件。
