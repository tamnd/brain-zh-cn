 **难度：** 🟢简单
 **主题：** 数组、哈希表、两个指针、二分查找、排序

 ## 解决方案

 ## 问题理解

 该问题给了我们两个整数数组，`nums1`和`nums2`，并要求我们返回它们的交集。 交集由两个数组中出现的所有值组成。 但是，结果必须仅包含唯一元素，即使数字在任一数组中出现多次也是如此。 

例如，如果`nums1 = [1,2,2,1]`和`nums2 = [2,2]`, 数量`2`出现在两个数组中，所以答案是`[2]`。 虽然`2`出现多次，它应该只在结果中出现一次。 

输入数组可以包含重复值，但重复值与最终输出无关，因为需要唯一性。 输出的顺序并不重要，这使我们可以灵活地构建结果。 

约束相对较小，两个数组最多都有 1000 个元素。 这意味着即使更慢的方法在技术上也可以通过，但问题旨在测试哈希表、排序或两个指针的有效使用。 

认识一些边缘情况很重要：

 - 数组可能包含许多重复项，因此我们必须避免返回重复的值。 
- 一个数组可能包含从未出现在另一数组中的元素。 
- 交集可能仅包含单个值。 
- 数组可能已经是唯一的，或者它们可能包含所有相同的值。 
- 由于值被限制在范围内`[0, 1000]`，不用担心整数溢出或极大的数字。 

关键要求是唯一性，这意味着我们需要一种可靠的方法来跟踪我们是否已经为答案添加了价值。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是比较中的每个元素`nums1`中的每个元素`nums2`。 

对于每个数字`nums1`，我们扫描`nums2`查看该值是否存在。 如果存在，我们会将其添加到结果中（如果尚未添加）。 

这种方法之所以有效，是因为每个可能的对都会被检查，保证最终会找到任何公共元素。 然而，嵌套迭代使得算法效率低下。 

如果`n`的长度是`nums1`和`m`的长度是`nums2`，那么这种方法需要`O(n * m)`时间。 虽然约束足够小，可以通过，但对于较大的输入，它会变得不必要的缓慢。 

### 最佳方法

 关键的观察是我们只需要快速的成员资格检查。 

哈希集提供平均值`O(1)`查找时间。 通过将一个数组的所有元素存储在一个集合中，我们可以快速确定另一个数组中是否存在某个元素。 

算法变为：

 1. 将一个数组转换为一个集合。 
2. 迭代第二个数组。 
3. 如果集合中存在值，则将其添加到结果集中。 
4. 将结果集转换为列表。 

使用集合会自动删除重复项，这完全符合问题要求。 

这将时间复杂度降低到相对于输入数组大小的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(k) | 比较每对元素，对于大输入效率低下 |
 | 最佳| O(n + m) | O(n + k) | 使用哈希集进行快速查找和自动唯一性 |

 这里，`k`表示交集中唯一元素的数量。 

## 算法演练

 1. 创建一个集合`nums1`。 

A set allows constant average time membership checking. This means we can quickly determine whether a value from`nums2`存在于`nums1`。 
2. 创建一个空结果集。 

由于该问题需要唯一的交集值，因此集合是存储答案的理想结构。 即使我们多次遇到相同的值，它也只会在结果集中出现一次。 
3. 迭代中的每个数字`nums2`。 

For every value, check whether it exists in the set created from`nums1`。 
4. 如果该值存在于第一个集合中，则将其添加到结果集中。 

这确认了该值出现在两个数组中。 
5. 将结果集转换为列表并返回。 

该问题需要一个类似数组的结构作为输出，因此我们在返回之前将集合转换回列表。 

### 为什么它有效

 该算法之所以有效，是因为当且仅当一个值出现在两个数组中时，该值才属于交集。 第一组记录来自的所有唯一值`nums1`。 迭代期间`nums2`，每次查找都会检查当前值是否也存在于`nums1`。 

使用结果集可以自动保证唯一性。 因此，每个返回值在两个数组中都只出现一次，满足问题要求。 

## Python 解决方案```python
from typing import List

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums1_set = set(nums1)
        intersection_set = set()

        for num in nums2:
            if num in nums1_set:
                intersection_set.add(num)

        return list(intersection_set)
```实现从转换开始`nums1`进入一个名为`nums1_set`。 此预处理步骤可实现快速成员资格检查。 

接下来，代码初始化`intersection_set`，它存储唯一的交集值。 

循环遍历中的每个值`nums2`。 对于每个数字，条件`if num in nums1_set`检查第一个数组中是否存在该值。 如果是，则将该值添加到`intersection_set`。 

最后，集合被转换为列表，因为 LeetCode 需要列表返回类型。 

该实现直接反映了算法演练，并利用 Python 内置的集合运算来实现简洁高效的代码。 

## 解决方案```go
func intersection(nums1 []int, nums2 []int) []int {
    nums1Set := make(map[int]bool)
    resultSet := make(map[int]bool)

    for _, num := range nums1 {
        nums1Set[num] = true
    }

    for _, num := range nums2 {
        if nums1Set[num] {
            resultSet[num] = true
        }
    }

    result := []int{}

    for num := range resultSet {
        result = append(result, num)
    }

    return result
}
```Go 没有内置的集合类型，因此映射通常用于模拟集合。 在这个解决方案中，`map[int]bool`用于跟踪会员资格。 

第一个映射存储来自的所有值`nums1`，而第二张地图唯一存储交集值。 

与 Python 不同，Go 在构造最终结果时需要显式创建切片并附加。 否则，整体逻辑保持不变。 

不用担心整数溢出，因为约束很小并且 Go 的`int`type 可以轻松处理输入范围。

 ## 边缘情况

 当两个数组都包含许多相同值的重复项时，就会出现一种重要的边缘情况。 幼稚的实现可能会意外地将相同的数字多次添加到结果中。 使用集合作为结果会自动防止此问题，因为集合仅存储唯一元素。 

当数组没有公共元素时，会发生另一种边缘情况。 在这种情况下，算法应返回一个空列表。 由于仅当第一个集合中存在成员资格时才会添加值，因此结果集保持为空并干净地转换为空列表。 

第三种重要情况是一个数组完全包含在另一个数组中。 例如，`nums1 = [1,2,3,4]`和`nums2 = [2,3]`。 该算法正确识别了两者`2`和`3`作为公共元素，因为较小数组中的每个值都会根据集合独立检查。 

最后一种边缘情况涉及长度为一的数组。 小输入通常会因一个错误或不正确的初始化而暴露。 该实现可以正确处理这些，因为逻辑不依赖于数组大小，每个元素都通过相同的集合查找机制统一处理。
