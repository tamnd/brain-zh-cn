 **主题：** 链表、数学

 ## 解决方案

 ## 问题理解

 该问题要求我们对表示为单链表的非负整数加一。 列表中的每个节点都包含一个数字，列表的头部对应于最高有效的数字。 本质上，链表`[1,2,3]`代表整数`123`，并且添加一个应该将其转换为`[1,2,4]`，代表`124`。 

输入保证是一个有效的非负整数，没有前导零，除了数字为零的特殊情况（`[0]`）。 节点数量在 1 到 100 之间，这意味着该解决方案必须有效地处理中等大小的列表。 每个节点的值都在 0 到 9 之间。 

重要的边缘情况包括以一个或多个结尾的链表`9`s（例如，`[1,2,9]`或者`[9,9,9]`），这将需要保留前面的数字，可能会增加列表的长度。 该问题保证了有效的输入，因此我们不需要处理空列表或负数。 

由于最高有效数字位于头部，因此该任务稍微复杂一些，这意味着我们不能像在没有反向或基于堆栈的方法的数组中那样简单地从前面遍历和添加。 

## 方法

 一种强力方法是将链表转换为整数，加一，然后重建链表。 这是可行的，因为整数表示允许简单的算术，并且保证了正确性。 但是，对于非常大的列表（接近 100 位），转换为整数可能会超出某些语言中的标准整数类型，并且重复的字符串操作可能效率低下。 

最佳方法利用了这样一个事实：带进位的加法从最低有效数字传播到最高有效数字。 由于列表是单链的，因此从最低有效位到最高有效位进行处理的最简单方法是反转链表，在传播进位的同时执行加法，然后将列表反转回来。 另一种无需逆向的替代方法是递归方法，其中递归堆栈模拟反向遍历列表。 

关键的见解是，我们只需要在加一时跟踪进位，一旦进位为零，我们就可以提前终止。 对于所有数字都是的情况`9`，我们可能需要创建一个具有值的新头节点`1`并为其余部分添加零。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将列表转换为整数或字符串，加一，重建列表。 简单但不优雅； 在某些语言中可能会导致整数溢出。 |
 | 最佳| O(n) | O(1) | O(1) | 反转列表，带进位加一，反转返回。 句柄可以有效地进行传播，无需额外的整数转换。 |

 ## 算法演练

 1. 反转链表，使最低有效数字位于头部。 这允许我们以加法和进位的自然顺序遍历列表。 
2. 用值初始化进位变量`1`因为我们要在数字上加一。 
3.逐个节点遍历反向链表。 对于每个节点，将进位添加到节点的值中。 将节点的值更新为`sum % 10`并将进位设置为`sum // 10`。 这可以处理总和超过 9 并且需要传播到下一个数字的情况。 
4. 如果遍历完所有节点后，进位仍然是`1`，创建一个具有值的新节点`1`并将其附加到列表中。 这可以处理类似的情况`[9,9,9]`。 
5. 再次反转列表以恢复原始顺序，因此最高有效数字回到头部。 

为什么有效：通过反转列表，我们将问题转换为标准的最低有效位加法问题，其中进位传播非常简单。 该算法保证每个数字都正确更新，额外的节点保证数字个数增加时的正确性。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def plusOne(self, head: ListNode) -> ListNode:
        # Helper function to reverse a linked list
        def reverse(node: ListNode) -> ListNode:
            prev = None
            current = node
            while current:
                next_node = current.next
                current.next = prev
                prev = current
                current = next_node
            return prev
        
        head = reverse(head)
        current = head
        carry = 1
        
        while current:
            total = current.val + carry
            current.val = total % 10
            carry = total // 10
            if carry == 0:
                break
            if current.next is None and carry:
                current.next = ListNode(carry)
                carry = 0
            current = current.next
        
        head = reverse(head)
        return head
```这个Python解决方案首先反转链表以首先处理最低有效数字。 while 循环处理加法和进位传播。 如果到达链表末尾后仍有进位，则追加一个新节点。 最后，再次反转列表，恢复原来的顺序。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func plusOne(head *ListNode) *ListNode {
    // Helper function to reverse a linked list
    var reverse func(node *ListNode) *ListNode
    reverse = func(node *ListNode) *ListNode {
        var prev *ListNode
        current := node
        for current != nil {
            next := current.Next
            current.Next = prev
            prev = current
            current = next
        }
        return prev
    }

    head = reverse(head)
    current := head
    carry := 1

    for current != nil {
        total := current.Val + carry
        current.Val = total % 10
        carry = total / 10
        if carry == 0 {
            break
        }
        if current.Next == nil && carry > 0 {
            current.Next = &ListNode{Val: carry}
            carry = 0
        }
        current = current.Next
    }

    head = reverse(head)
    return head
}
```在 Go 中，逻辑几乎相同。 Go 需要显式处理指针和`nil`检查。 与 Python 不同，我们使用整数除法`/`和模数`%`运算符并创建新节点`&ListNode{Val: carry}`当需要时。 

## 工作示例

 **示例1：`[1,2,3]`**

撤销：`[3,2,1]`初始进位 = 1

 | 节点值 | 添加进位| 新瓦尔| 携带|
 | --- | --- | --- | --- |
 | 3 | 3+1 | 4 | 0 |

 不能再带了，停下来。 反向返回：`[1,2,4]`。 

**示例2：`[0]`**

撤销：`[0]`初始进位 = 1

 | 节点值 | 添加进位| 新瓦尔| 携带|
 | --- | --- | --- | --- |
 | 0 | 0+1 | 1 | 0 |

 不能再带了，停下来。 反向返回：`[1]`。 

**示例3：`[9,9,9]`**

撤销：`[9,9,9]`→`[9,9,9]`初始进位 = 1

 | 节点值 | 添加进位| 新瓦尔| 携带|
 | --- | --- | --- | --- |
 | 9 | 9+1 | 0 | 1 |
 | 9 | 9+1 | 0 | 1 |
 | 9 | 9+1 | 0 | 1 |

 列表末尾，创建具有值的新节点`1`。 反向返回：`[1,0,0,0]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 反转列表两次并遍历一次进行加法与节点数呈线性关系。 |
 | 空间| O(1) | O(1) | 我们只使用恒定数量的变量（上一个、当前、进位）并就地修改列表。 |

 该算法避免了除了偶尔用于进位传播的新节点之外的额外内存分配。 每个节点都会被访问恒定的次数，从而提供线性运行时间。

# test cases
def list_to_nodes(lst):
    dummy = ListNode(0)
    current = dummy
    for val in lst:
        current.next = ListNode(val)
        current = current.next
    return dummy.next

def nodes_to_list(node):
    result = []
    while node:
        result.append(node.val)
        node = node.next
    return result

sol = Solution()
