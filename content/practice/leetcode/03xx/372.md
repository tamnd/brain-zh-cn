[LeetCode 第 372 题](https://leetcode.com/problems/super-pow/)

 **难度：** 🟡 中等
 **主题：** 数学、分而治之

 ## 解决方案

 ## 问题理解

 该问题要求我们计算：$a^b \bmod 1337$复杂的是指数`b`非常大。 它不是以普通整数的形式给出，而是以数字数组的形式提供。 例如，如果：```
b = [1, 0, 2, 4]
```那么指数实际上代表数字：```
1024
```目标是有效地计算模幂结果，而无需显式构造巨大的整数。 

模数固定为`1337`，相对较小。 这很重要，因为模运算允许我们保持中间数有界并避免溢出或巨大的计算。 

一个幼稚的实现可能会尝试重建指数，然后计算：```
a^b
```直接地。 然而，指数可能包含多达 2000 位数字，这意味着它可能是天文数字。 即使将该整数存储在标准数字类型中也是不可能的。 

这些约束揭示了几个重要的观察结果：

 -`a`可以大到`2^31 - 1`，因此没有模约简的重复乘法在许多语言中都会溢出。 
-`b.length <= 2000`，这意味着指数可以包含数千位小数。 
- 由于模数仅为`1337`，模幂技术变得非常有效。 
- 指数数字保证没有前导零，因此数组始终表示有效的正整数。 

一些边缘情况很重要：

 -`a = 1`，因为 1 的任何幂仍然是 1。 
- 非常大的指数，直接构造数字是不可能的。 
- 包含零的数字，例如`[1,0]`，它代表 10 个操作而不是单独的操作。 
- 大值`a`，这需要尽早且经常进行模块化缩减。 

## 方法

 ### 蛮力方法

 蛮力的想法很简单。 首先，重构digit数组表示的整数`b`。 然后计算：```
(a^b) % 1337
```使用重复乘法或标准幂函数。 

这种方法是正确的，因为它直接评估问题的数学定义。 

然而，它立即变得不切实际，因为指数最多可以有 2000 位数字。 2000 位数字远远大于内置整数类型可以有效存储的数字。 即使具有任意精度整数的语言也很难直接计算如此巨大的指数。 

此外，重复乘法将需要不可能数量的运算。 

### 最佳方法

 关键的见解是模运算允许指数分解。 

假设指数数字是从左到右处理的。 如果我们已经计算过：```
a^x mod 1337
```我们添加另一个数字`d`，新的指数变为：```
10x + d
```使用指数规则：$a^{10x+d} = (a^x)^{10} \cdot a^d$取模`1337`自始至终给出：$a^{10x+d} \bmod 1337 = \left((a^x)^{10} \bmod 1337\right) \cdot \left(a^d \bmod 1337\right) \bmod 1337$这意味着我们永远不需要完整的指数。 我们在一位一位处理数字的同时，只维护当前的模结果。 

高效的模幂运算，通常称为二进制幂运算或快速幂，可以让我们在对数时间内计算幂。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 指数/不可行| 超大| 尝试构建和使用完整指数 |
 | 最佳| O(n log 10) | O(n log 10) | O(1) | O(1) | 使用模运算增量处理指数数字 |

 这里，`n`是数字的个数`b`。 

## 算法演练

 1. 初始化模数为`1337`。 

由于每次计算都是模数执行的`1337`，我们存储这个常量一次并在整个算法中重复使用它。 
2. 减少`a`模数`1337`。 

这可以防止不必要的大中间值，因为：$(a \bmod m)^k \bmod m = a^k \bmod m$3. 将运行答案初始化为`1`。 

这代表了以下值：```
a^0 mod 1337
```在处理任何指数数字之前。 
4. 处理每个数字`b`从左到右。 

假设当前答案代表：```
a^x mod 1337
```下一个数字是`d`。 

新的指数变为：```
10x + d
```5. 将当前答案提高到 10 次方模`1337`。 

这对应于：```
(a^x)^10
```我们使用快速模幂来有效地计算这一点。 
6. 计算`a^d mod 1337`。 

自从`d`之间只有一位小数`0`和`9`，这个计算量很小。 
7. 将两个模块化组件相乘。 

这会产生：```
a^(10x+d) mod 1337
```这将成为更新后的运行答案。 
8. 继续，直到处理完所有数字。 

在最后一位数字之后，运行答案等于：```
a^b mod 1337
```### 为什么它有效

 该算法依赖于处理第一个之后的不变量`i`的数字`b`，变量`result`等于：```
a^(value represented by first i digits) mod 1337
```每个新数字都会变换指数`x`进入`10x + d`。 使用指数定律和模运算，我们可以正确更新结果，而无需显式构造巨大的指数。 

## Python 解决方案```python
from typing import List

class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        MOD = 1337

        def mod_pow(base: int, exponent: int) -> int:
            result = 1
            base %= MOD

            while exponent > 0:
                if exponent % 2 == 1:
                    result = (result * base) % MOD

                base = (base * base) % MOD
                exponent //= 2

            return result

        result = 1
        a %= MOD

        for digit in b:
            result = (
                mod_pow(result, 10) * mod_pow(a, digit)
            ) % MOD

        return result
```实现从辅助函数开始`mod_pow`，它使用二进制幂执行快速模幂。 不是重复地乘以基数，而是每次迭代时指数减半，从而将复杂性从线性降低到对数。 

里面`mod_pow`，每当当前指数位为奇数时，当前基数都会影响最终答案。 每一步之后都会对底数进行平方，因为二进制幂运算将幂分解为 2 的幂。 

main函数初始化`result`到`1`，代表一个空指数。 的价值`a`立即减少模数`1337`使所有未来的计算保持较小。 

对于指数数组中的每个数字，算法使用数学恒等式更新当前结果：$a^{10x+d} = (a^x)^{10} \cdot a^d$表达式：```python
mod_pow(result, 10)
```处理前一个指数乘以 10，同时：```python
mod_pow(a, digit)
```添加新的数字贡献。 

处理完所有数字后返回最终结果。 

## 解决方案```go
func superPow(a int, b []int) int {
	const MOD = 1337

	modPow := func(base int, exponent int) int {
		result := 1
		base %= MOD

		for exponent > 0 {
			if exponent%2 == 1 {
				result = (result * base) % MOD
			}

			base = (base * base) % MOD
			exponent /= 2
		}

		return result
	}

	result := 1
	a %= MOD

	for _, digit := range b {
		result = (modPow(result, 10) * modPow(a, digit)) % MOD
	}

	return result
}
```Go 实现密切反映了 Python 逻辑。 由于 Go 不像 Python 那样方便地支持嵌套命名函数，因此 helper 被实现为分配给的内联闭包`modPow`。 

Go 整数在这里就足够了，因为所有中间值仍然受到模数的限制`1337`。 每次乘法后，模运算可防止溢出增长。 

使用 Go 处理指数数字`range`切片上的语法。

 ## 边缘情况

 当指数为零时会出现一种重要的边缘情况，例如`b = [0]`。 数学上：$a^0 = 1$有缺陷的实现可能会处理不当，因为没有乘法步骤对结果有贡献。 在这个解决方案中，`result`开始于`1`，所以处理数字`0`自然地保留了正确的值。 

另一个关键情况是当`a`可以整除`1337`。 例如：```
a = 1337
```模块化缩减后：```
a % 1337 = 0
```因此任何正指数都应该产生`0`。 由于实施立即减少`a`模数`1337`，这种行为会自动出现。 

第三个重要的边缘情况是具有数千位数字的极大指数。 在许多语言中，显式构造指数会溢出内存或整数限制。 该实现通过增量处理数字并使用指数分解更新模块化结果来完全避免这种情况。 

最后，非常大的基值接近`2^31 - 1`如果中间值增长不受控制，可能会导致溢出。 重复的模运算确保每次乘法都保持有界，从而保持计算的安全和高效。
