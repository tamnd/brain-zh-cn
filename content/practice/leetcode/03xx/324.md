 **难度：** 🟡 中等
 **主题：** 数组、分而治之、贪心、排序、快速选择

 ## 解决方案

 ## 问题理解

 该问题要求我们重新排列一个数组，使其遵循严格的交替模式：

 -`nums[0] < nums[1]`-`nums[1] > nums[2]`-`nums[2] < nums[3]`- 等等。 

这种模式称为摆动序列，因为值反复上升和下降。 

输入是一个整数数组`nums`，并且我们必须就地修改它。 该问题保证至少一种有效的排列总是存在。 

一个关键细节是不平等是严格的。 在以下任一位置中不允许使用相同的相邻值`<`或者`>`是必须的。 这使得仔细处理重复项尤为重要。 

约束允许数组最多`5 * 10^4`元素，这意味着`O(n^2)`解决方案可能会超时。 我们需要一些接近线性或`O(n log n)`。 

后续要求`O(n)`时间解与`O(1)`额外的空间。 这强烈暗示使用：

 - 快速选择以找到线性时间的中位数
 - 仔细的就地分区
 - 一个特殊的索引技巧可以正确放置大值和小值

 几种边缘情况可能会导致幼稚实现中的错误：

 - 具有许多重复值的数组，例如`[1,1,1,2,2,2]`- 中位数出现多次的数组
 - 非常小的阵列
 - 已经摆动排序的数组
 - 直接相邻交换无法维持严格不平等的数组

 保证有效答案始终存在稍微简化了问题，因为我们永远不需要检测不可能的情况。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是：

 1. 对数组进行排序。 
2.将其分成两半。 
3. 将较小的一半和较大的一半交错。 

例如：

 - 排序：`[1,1,1,4,5,6]`- 小一半：`[1,1,1]`- 较大的一半：`[4,5,6]`然后交替放置值：

 - 即使指数也得到较小的值
 - 奇数索引获得更大的值

 为了避免重复的结果相邻，我们从每一半的末尾而不是从头开始填充。 

这是有效的，因为：

 - 奇数位置必须包含相对较大的值
 - 即使头寸也必须包含相对较小的值
 - 反转两半会将重复项分开

 这种做法是正确的，而且更容易实现，但是排序成本`O(n log n)`如果我们构建临时数组，通常需要额外的空间。 

### 最佳方法

 最优解达到：

 -`O(n)`平均时间
 -`O(1)`额外的空间

 关键的见解是最终的摆动模式从根本上是由中位数决定的。 

如果我们知道中位数：

 - 大于中位数的值应进入奇数位置
 - 小于中位数的值应进入偶数位置
 - 等于中位数的值填充剩余的点

 这类似于荷兰国旗划分问题。 

然而，直接对数组进行分区是不够的，因为物理索引与摆动要求不符。 因此，我们使用虚拟索引技巧。 

虚拟索引映射：```
mapped_index = (1 + 2 * i) % (n | 1)
```重新排序遍历，以便：

 - 奇数位置先被填补
 - 甚至职位也会在之后填补

 这保证了较大的元素自然地落在摆动峰值位置。

 ## 算法演练

 ### 最优算法

 1. 使用 Quickselect 查找数组的中位数。 

中位数充当小值和大值之间的分界线。 大于中位数的元素应占用奇数索引，而较小的元素应占用偶数索引。 
2. 定义虚拟索引映射。 

而不是访问索引`i`直接，我们使用：```
virtual(i) = (1 + 2 * i) % (n | 1)
```该映射按以下顺序访问索引：```
1, 3, 5, 0, 2, 4
```对于偶数长度数组。 

这种排序确保较大的元素首先放入奇数索引中。 
3. 围绕中线进行三向分区。 

我们维护三个区域：

 - 左侧区域包含大于中位数的值
 - 中间区域包含等于中位数的值
 - 右侧区域包含小于中位数的值

 这在本质上与荷兰国旗算法相同。 
4.使用三个指针：

 -`left`跟踪下一个大值应该去哪里
 -`i`扫描数组
 -`right`跟踪下一个小值应该去哪里
 5. 扫描时：

 - 如果当前值大于中位数：

 - 将其交换到左侧区域
 - 移动两者`left`和`i`- 如果当前值小于中位数：

 - 将其交换到正确的区域
 - 移动`right`- 不前进`i`但由于换入的值仍需要处理
 - 如果当前值等于中位数：

 - 只需前进`i`6. 由于所有访问都使用虚拟索引，因此大值自动移至奇数位置，小值自动移至偶数位置。 

### 为什么它有效

 摆动条件要求奇数索引处有峰值，偶数索引处有谷值。 

虚拟索引方案保证首先处理奇数索引。 分区时：

 - 大于中位数的值移向虚拟订单的前面
 - 小于中位数的值向后移动

 结果：

 - 奇数位置接收大值
 - 即使头寸也收到较小的值

 等于中位数的值可以安全地占据剩余位置，而不会违反摆动结构。 

严格的不等式之所以成立，是因为所有较大的值都通过构造与较小的值分开。 

## Python 解决方案```python
from typing import List
import random

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """

        n = len(nums)

        def kth_smallest(k: int) -> int:
            left, right = 0, n - 1

            while True:
                pivot_index = random.randint(left, right)
                pivot = nums[pivot_index]

                # Three-way partition
                nums[pivot_index], nums[right] = nums[right], nums[pivot_index]

                store_index = left

                for i in range(left, right):
                    if nums[i] < pivot:
                        nums[store_index], nums[i] = nums[i], nums[store_index]
                        store_index += 1

                nums[store_index], nums[right] = nums[right], nums[store_index]

                if store_index == k:
                    return nums[store_index]
                elif store_index < k:
                    left = store_index + 1
                else:
                    right = store_index - 1

        median = kth_smallest(n // 2)

        def virtual_index(i: int) -> int:
            return (1 + 2 * i) % (n | 1)

        left = 0
        i = 0
        right = n - 1

        while i <= right:
            mapped_i = virtual_index(i)

            if nums[mapped_i] > median:
                mapped_left = virtual_index(left)

                nums[mapped_left], nums[mapped_i] = (
                    nums[mapped_i],
                    nums[mapped_left],
                )

                left += 1
                i += 1

            elif nums[mapped_i] < median:
                mapped_right = virtual_index(right)

                nums[mapped_right], nums[mapped_i] = (
                    nums[mapped_i],
                    nums[mapped_right],
                )

                right -= 1

            else:
                i += 1
```实现首先使用 Quickselect 查找中位数。 Quickselect 不是对数组进行完全排序，而是重复对数组进行分区，直到确定中间位置。 

找到中值后，解定义了虚拟索引函数。 这种映射是问题的核心技巧，因为它将标准的三向分区转换为摆动感知的重新排列。 

然后该算法执行荷兰国旗分区：

 - 大于中位数的值向左移动
 - 小于中位数的值向右移动
 - 中值保持在中间

 重要的细节是所有读取和写入都使用虚拟索引而不是物理索引。 这保证了最终的摆动顺序。 

该解决方案就地修改数组并仅使用恒定的额外内存。 

## 解决方案```go
package main

import (
	"math/rand"
)

func wiggleSort(nums []int) {
	n := len(nums)

	kthSmallest := func(k int) int {
		left, right := 0, n-1

		for {
			pivotIndex := left + rand.Intn(right-left+1)
			pivot := nums[pivotIndex]

			nums[pivotIndex], nums[right] = nums[right], nums[pivotIndex]

			storeIndex := left

			for i := left; i < right; i++ {
				if nums[i] < pivot {
					nums[storeIndex], nums[i] = nums[i], nums[storeIndex]
					storeIndex++
				}
			}

			nums[storeIndex], nums[right] = nums[right], nums[storeIndex]

			if storeIndex == k {
				return nums[storeIndex]
			} else if storeIndex < k {
				left = storeIndex + 1
			} else {
				right = storeIndex - 1
			}
		}
	}

	median := kthSmallest(n / 2)

	virtualIndex := func(i int) int {
		return (1 + 2*i) % (n | 1)
	}

	left, i, right := 0, 0, n-1

	for i <= right {
		mappedI := virtualIndex(i)

		if nums[mappedI] > median {
			mappedLeft := virtualIndex(left)

			nums[mappedLeft], nums[mappedI] =
				nums[mappedI], nums[mappedLeft]

			left++
			i++

		} else if nums[mappedI] < median {
			mappedRight := virtualIndex(right)

			nums[mappedRight], nums[mappedI] =
				nums[mappedI], nums[mappedRight]

			right--

		} else {
			i++
		}
	}
}
```Go 的实现与 Python 解决方案非常相似。 Go 切片是可变引用，因此修改会自动就地发生。 

一个小的实现细节是随机主元生成。 Go 使用`rand.Intn()`在快速选择期间选择枢轴索引。 

虚拟索引逻辑和三向分区与Python版本保持相同。

 ## 边缘情况

 ### 具有许多重复值的数组

 输入如`[1,1,1,2,2,2]`很难，因为相等的元素很容易相邻，从而违反严格的不平等。 

简单的相邻交换解决方案在这里经常会失败。 虚拟索引策略通过在数组中分离相等的中值，同时将较大的值强制到奇数位置来避免这种情况。 

### 中位数经常出现的数组

 案例如`[1,2,2,2,3,3]`特别棘手，因为中位数在数组中占主导地位。 

三路分区正确分组：

 - 较大的值
 - 中值
 - 较小的值

 不影响摆动结构。 中值自然会安全地填充剩余的槽位。 

### 非常小的数组

 小数组，例如`[1,2]`或者`[2,1]`可能会暴露索引错误或相差一错误。 

该实现自然地处理这些，因为：

 - 快速选择仍然可以正常工作
 - 虚拟索引仍然有效
 - 分区循环在适当的时候立即终止

 ### 逆序数组

 按降序排列的数组可能看起来与摆动排列相去甚远。 

然而，由于该算法仅依赖于与中位数的相对比较，因此初始顺序并不重要。 分区过程将阵列完全重新组织成所需的交替结构。
