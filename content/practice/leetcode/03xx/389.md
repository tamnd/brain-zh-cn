[LeetCode 第 389 题](https://leetcode.com/problems/find-the-difference/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、位操作、排序

 ## 解决方案

 ## 问题理解

 这个问题给了我们两个字符串，`s`和`t`。 字符串`t`是通过获取所有字符来创建的`s`，将它们打乱为不同的顺序，然后在字符串中的某处插入一个附加字符。 

我们的任务是识别并返回那个额外的字符。 

换句话说，剧中的每一个角色`s`出现在`t`相同的次数，除了一个额外的字母在`t`。 我们必须确定那是哪个角色。 

例如：

 - 如果`s = "abcd"`和`t = "abcde"`，唯一的额外字符是`'e'`。 
- 如果`s = ""`和`t = "y"`， 然后`t`仅包含添加的字符，所以答案是`'y'`。 

限制相对较小：

 -`0 <= s.length <= 1000`-`t.length == s.length + 1`- 两个字符串仅包含小写英文字母。 

这些限制告诉我们一些重要的事情：

 - 输入大小足够小，即使效率较低的方法也可以工作。 
- 由于仅使用小写英文字母，因此最多有 26 个不同的字符。 
- 该问题保证恰好有一个额外的字符`t`。 
- 我们永远不需要处理无效输入或多个添加的字符。 

重要的边缘情况包括：

 - 一个空的`s`， 在哪里`t`仅包含一个字符。 
- 重复的字符，例如`s = "aabb"`和`t = "ababb"`。 
- 额外的字符与已存在的现有字符相同`s`。 
- 出现在开头、中间或结尾的额外字符`t`，尽管洗牌意味着位置并不重要。 

仅直接检查位置的简单实现将会失败，因为字符被打乱了。 该解决方案必须比较字符频率或使用独立于排序的属性。 

## 方法

 ### 蛮力方法

 解决这个问题的一个直接方法是计算每个字符在两个字符串中出现的次数。 

我们可以：

 1. 统计每个字符出现的频率`s`。 
2. 统计每个字符出现的频率`t`。 
3. 逐个字符比较计数。 
4. 返回其中计数较大的字符`t`。 

这是可行的，因为该问题保证恰好存在一个附加字符。 

一种可能的暴力实现是：

 - 对于每个角色`t`，使用重复扫描计算它在两个字符串中出现的次数。 
- 第一个计数不同的字符就是答案。 

然而，重复扫描字符串中的每个字符效率很低。 如果我们使用重复计数操作来检查频率，时间复杂度可能会变成二次。 

### 最佳方法

 最优解使用按位异或运算。 

关键的观察是：

 - 一个数与它本身的异或是`0`。 
- 与一个数字进行异或`0`是数字本身。 
- XOR 是可交换和结合的，因此顺序并不重要。 

如果我们将所有字符异或在一起`s`以及来自的所有字符`t`，每个匹配的字符都会抵消，只留下多余的字符。 

例如：```
a ^ b ^ c ^ d ^ a ^ b ^ c ^ d ^ e
```所有匹配对消失：```
0 ^ 0 ^ 0 ^ 0 ^ e = e
```这为我们提供了一个非常优雅且高效的解决方案，并具有恒定的额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 通过扫描字符串重复计数字符 |
 | 最佳| O(n) | O(1) | O(1) | 使用 XOR 取消属性来隔离额外的字符 |

 ## 算法演练

 ### 最优异或算法

 1. 初始化一个名为`xor_result`到`0`。 

该变量将存储两个字符串中所有字符的累积异或。 
2. 迭代中的每个字符`s`。 

使用以下命令将每个字符转换为其 ASCII 整数值`ord()`在Python中，然后将其异或为`xor_result`。 
3. 迭代中的每个字符`t`。 

再次将每个字符转换为其 ASCII 值，并将其异或为`xor_result`。 
4. 每个匹配的字符来自`s`和`t`取消。 

由于对相同值进行异或两次会产生`0`，所有共享字符都会消失，无论顺序如何。 
5. 唯一剩余的价值`xor_result`是额外字符的 ASCII 值。 
6. 使用以下命令将最终整数转换回字符`chr()`并归还它。 

### 为什么它有效

 正确性依赖于 XOR 的取消属性：```
x ^ x = 0
```因为每个角色都来自`s`出现在`t`，每个匹配对在 XOR 累加期间相互抵消。 XOR 与顺序无关，因此洗牌并不重要。 唯一没有匹配对的字符是添加的字符，在所有取消操作后仍保留该字符。 

## Python 解决方案```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        xor_result = 0

        for char in s:
            xor_result ^= ord(char)

        for char in t:
            xor_result ^= ord(char)

        return chr(xor_result)
```实现从初始化开始`xor_result`为零。 这充当运行中的异或累加器。 

第一个循环处理中的每个字符`s`。 每个字符都使用以下方法转换为其 ASCII 整数表示形式`ord()`，然后异或到累加器中。 

第二个循环对中的每个字符执行相同的操作`t`。 

由于匹配的字符在每个字符串中出现一次，因此它们会相互抵消。 两个循环完成后，累加器仅包含额外字符的 ASCII 值。 

最后，`chr()`将该整数转换回字符，该字符作为答案返回。 

## 解决方案```go
func findTheDifference(s string, t string) byte {
    var xorResult byte = 0

    for i := 0; i < len(s); i++ {
        xorResult ^= s[i]
    }

    for i := 0; i < len(t); i++ {
        xorResult ^= t[i]
    }

    return xorResult
}
```Go 实现遵循与 Python 版本相同的 XOR 策略。 

由于 Go 字符串内部是 ASCII 字符的字节切片，因此我们可以直接对字节进行异或，而无需通过诸如`ord()`或者`chr()`。 

结果存储在`byte`变量，因为问题只包含小写英文字母，它们自然适合单个字节。 

空字符串会自动处理，因为迭代空字符串只执行零次迭代。

 ## 边缘情况

 ### 空原始字符串

 当`s`是空的，`t`恰好包含一个字符。 设计不当的解决方案可能会假设两个字符串都包含匹配的字符，并且在空输入时失败。 

XOR 解决方案可以自然地处理这个问题。 由于没有处理任何字符`s`，累加器保持不变`0`直到单个字符从`t`被异或进去。该字符直接成为最终答案。 

### 重复字符

 案例如下：```
s = "aabb"
t = "ababb"
```可能会导致仅检查存在而不是频率的实现中的错误。 

XOR 解决方案可以正常工作，因为每个匹配出现都会独立取消。 只剩下不匹配的事件了。 

### 额外字符已存在于`s`一个常见的错误是假设添加的字符必须是新的。 

例如：```
s = "abc"
t = "abcc"
```额外的字符是`'c'`， 虽然`'c'`已经存在于`s`。 

XOR 方法可以正确处理这个问题，因为三个`'c'`值减少到一个无与伦比的`'c'`两两抵消后。 

### 打乱顺序

 自从`t`被打乱后，字符不会出现在相应的位置。 

对于以下输入，简单的逐位置比较将失败：```
s = "abcd"
t = "dacbe"
```XOR 运算与顺序无关，因为 XOR 是可交换且可结合的。 无论字符排列如何，这都保证了正确性。
