[LeetCode 第 361 题](https://leetcode.com/problems/bomb-enemy/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 问题提出了一个`m x n`矩阵称为`grid`其中每个元素都是代表墙的字符`'W'`，一个敌人`'E'`，或一个空单元格`'0'`。 任务是确定在空牢房中放置一枚炸弹可以消灭的最大敌人数量。 炸弹会影响同一行和同一列的所有敌人，但其效果会被墙壁阻挡。 

输入是大小高达 500x500 的 2D 矩阵，这意味着检查每行和每列中的每个单元格的强力解决方案可能会导致计算成本高昂。 输出是一个整数，表示通过最佳放置炸弹可以杀死的最大敌人数量。 

重要的边缘情况包括没有空单元格的网格、没有敌人的网格、完全充满墙壁的网格以及可能会影响性能的非常长的行或列。 该问题保证有效输入和非空网格，因此我们不需要处理空或格式错误的输入。 

## 方法

 ### 蛮力

 一种简单的方法是遍历每个空单元格并计算同一行和同一列中的敌人数量，直到遇到墙壁。 这确保了正确性，因为它会检查每个可能的炸弹放置位置。 然而，对于大小的网格`m x n`，每张支票需要扫描最多`m + n`单元格，在最坏的情况下导致时间复杂度为 O(m^2 * n + m * n^2)。 对于 500x500 这样的大网格来说这太慢了。 

### 最佳方法

 关键的见解是，除非遇到墙壁，否则行或列中的敌人数量不会改变。 我们可以预先计算墙之间的行和列段中的敌人数量，并将这些计数重复用于这些段中的所有空单元格。 通过将这些计数存储在临时变量中并仅在新段开始时更新它们，我们可以避免重复扫描并将时间复杂度降低到 O(m * n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m^2 * n + m * n^2) | O(m^2 * n + m * n^2) | O(1) | O(1) | 通过扫描整行和整列来检查每个空单元格 |
 | 最佳| O(m * n) | O(1) | O(1) | 重复使用行和列计数，仅在墙壁上更新 |

 ## 算法演练

 1. 初始化变量`max_enemies`储存最多可杀死的敌人。 初始化`row_hits`计算当前行段和数组中的敌人数量`col_hits`尺寸的`n`计算每个列段中的敌人数量。 
2. 迭代网格中的每个单元格。 对于每一行，重置`row_hits`当在墙后或行的开头开始新的行段时。 对于每一列，更新`col_hits[j]`仅在柱段的起点或墙后。 
3.如果当前单元格是敌人`'E'`, 增量`row_hits`和`col_hits[j]`。 这些计数表示如果将炸弹放置在该部分的空单元格中，将会杀死的敌人总数。 
4. 如果当前单元格为空`'0'`，计算总击杀数为`row_hits + col_hits[j]`并更新`max_enemies`如果这大于当前最大值。 
5. 对整个网格继续此过程。 遍历完所有单元格后，`max_enemies`将包含答案。 

**为什么有效：** 该算法保证了正确性，因为它准确地计算了由墙壁隔开的每行和每列段中的敌人数量。 通过仅更新分段边界处的计数，可以避免重复扫描并确保根据正确数量的敌人评估每个空单元格。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxKilledEnemies(self, grid: List[List[str]]) -> int:
        if not grid or not grid[0]:
            return 0

        m, n = len(grid), len(grid[0])
        max_enemies = 0
        col_hits = [0] * n

        for i in range(m):
            row_hits = 0
            for j in range(n):
                if j == 0 or grid[i][j-1] == 'W':
                    row_hits = 0
                    k = j
                    while k < n and grid[i][k] != 'W':
                        if grid[i][k] == 'E':
                            row_hits += 1
                        k += 1
                if i == 0 or grid[i-1][j] == 'W':
                    col_hits[j] = 0
                    k = i
                    while k < m and grid[k][j] != 'W':
                        if grid[k][j] == 'E':
                            col_hits[j] += 1
                        k += 1
                if grid[i][j] == '0':
                    max_enemies = max(max_enemies, row_hits + col_hits[j])
        return max_enemies
```实现使用`row_hits`跟踪当前行段中的敌人并`col_hits`追踪纵队敌人。 对于每个空单元格，它通过将这些计数相加来计算杀死的敌人总数。 仅当新段在墙后开始时才会重新计算计数，这可确保最佳性能。 

## 解决方案```go
func maxKilledEnemies(grid [][]byte) int {
    if len(grid) == 0 || len(grid[0]) == 0 {
        return 0
    }
    m, n := len(grid), len(grid[0])
    maxEnemies := 0
    colHits := make([]int, n)

    for i := 0; i < m; i++ {
        rowHits := 0
        for j := 0; j < n; j++ {
            if j == 0 || grid[i][j-1] == 'W' {
                rowHits = 0
                for k := j; k < n && grid[i][k] != 'W'; k++ {
                    if grid[i][k] == 'E' {
                        rowHits++
                    }
                }
            }
            if i == 0 || grid[i-1][j] == 'W' {
                colHits[j] = 0
                for k := i; k < m && grid[k][j] != 'W'; k++ {
                    if grid[k][j] == 'E' {
                        colHits[j]++
                    }
                }
            }
            if grid[i][j] == '0' {
                if rowHits+colHits[j] > maxEnemies {
                    maxEnemies = rowHits + colHits[j]
                }
            }
        }
    }
    return maxEnemies
}
```在 Go 中，切片用于`colHits`，逻辑反映了Python版本。 边缘情况通过初始检查空网格来处理。 Go 不需要类型提示，但方法在其他方面是相同的。 

## 工作示例

 **示例1**

 输入：```
grid = [["0","E","0","0"],["E","0","W","E"],["0","E","0","0"]]
```逐步评估：

 | 我| j | 行点击数 | col_hits[j]| 最大敌人数 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 1 | 1 | 2 |
 | 0 | 1 | 1 | 1 | 2 |
 | 0 | 2 | 1 | 1 | 3 |
 | 1 | 1 | 1 | 2 | 3 |

 最终输出：3

 **示例2**

 输入：```
grid = [["W","W","W"],["0","0","0"],["E","E","E"]]
```评价：

 第 1 行中只有空单元格。每个单元格下方墙前最多有 1 个敌人，因此 max_enemies = 1。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 每个单元格都会被访问一次，并且每行/列段的敌人计数最多更新两次 |
 | 空间| O(n) | 仅使用单个 row_hits 整数和大小为 n 的 col_hits 数组 |

 这种方法有效地减少了不必要的重复扫描，使其适用于大型 500x500 网格。
