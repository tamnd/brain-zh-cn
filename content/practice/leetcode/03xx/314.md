[LeetCode 第 314 题](https://leetcode.com/problems/binary-tree-vertical-order-traversal/)

 **难度：** 🟡 中等
 **主题：** 哈希表、树、深度优先搜索、广度优先搜索、排序、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们按二叉树的垂直列对节点进行分组，并从左到右返回这些组。 

树中的每个节点都属于一个概念坐标系：

 - 根从列开始`0`- 移动到左子节点会减少列索引`1`- 移动到右子节点会增加列索引`1`输出应包含属于分组在一起的同一列的所有节点。 列本身必须从最左列到最右列出现。 

在单个列中，节点必须从上到下出现。 这个要求很重要，因为它决定了我们应该使用的遍历策略。 此外，如果两个节点共享同一行和同一列，则它们必须从左到右出现。 

输入是二叉树的根节点。 该树最多可以包含`100`节点数相对较小，但排序要求足够严格，不小心遍历仍然会产生错误的结果。 

例如，考虑这棵树：```
        3
       / \
      9   20
         /  \
        15   7
```列分配是：```
Column -1: 9
Column  0: 3, 15
Column  1: 20
Column  2: 7
```所以结果就变成了：```
[[9], [3,15], [20], [7]]
```一个重要的细节是平局打破规则。 如果两个节点共享相同的行和列，则从左到右第一个遇到的节点必须首先出现在输出中。 此要求强烈建议使用广度优先搜索而不是简单的深度优先搜索。 

一些边缘情况很重要：

 - 空树应该返回空列表
 - 只有一个节点的树应该返回单列
 - 多个节点可能落入同一列
 - 同一行和同一列的节点必须保持从左到右的顺序
 - 高度倾斜的树可以创建许多负或正的列索引

 该问题保证输入是有效的二叉树，并且节点值在一个小的整数范围内。 

## 方法

 ### 蛮力方法

 暴力解决方案首先分配坐标`(row, column)`使用诸如 DFS 之类的遍历到每个节点。 收集完所有节点后，我们可以通过以下方式对它们进行全局排序：

 1. 专栏
 2. 行
 3.从左到右的访问顺序

 最后，我们将按列对节点进行分组。 

这是有效的，因为排序显式地强制执行所需的排序规则。 然而，该方法引入了不必要的开销。 我们必须为每个节点存储额外的元数据，并对所有收集的条目执行排序操作。 

虽然约束大小只有`100`，该方法不太优雅，并且不能自然地模拟遍历顺序要求。 

### 最佳解决方案的关键见解

 关键的观察是，广度优先搜索自然地逐级处理节点，这已经保证了从上到下的排序。 

更好的是，当 BFS 在每个级别内从左到右处理节点时，它会自动保留共享相同行和列的节点所需的平局规则。 

这意味着我们不需要显式存储行索引或执行复杂的排序。 我们只需要：

 - 用于BFS遍历的队列
 - 从列索引到节点值的哈希映射
 - 跟踪遇到的最小和最大列索引

 当我们遍历时：

 - 左孩子获得列`col - 1`- 右孩子获得列`col + 1`因为 BFS 已经保证了正确的访问顺序，所以直接将值附加到每个列列表中会产生正确的结果。

 ## 算法演练

 1. 首先处理空树的情况。 

如果根是`None`，没有要处理的节点，因此立即返回一个空列表。 
2. 初始化广度优先搜索的队列。 

每个队列条目存储：

 - 当前节点
 - 其列索引

 根从列开始`0`。 
3. 创建一个哈希映射，将列索引映射到节点值列表。 

这使我们能够在遍历树时有效地将节点附加到其垂直组中。 
4. 跟踪遇到的最小和最大列索引。 

由于列索引可以变为负数或正数，因此我们稍后需要这些边界来按顺序从左到右输出列。 
5. 进行BFS遍历。 

反复从队列中删除节点：

 - 将节点值追加到其列的列表中
 - 更新最小和最大列索引
 - 添加带有列的左子项`col - 1`- 添加带有列的右子项`col + 1`6. 构建最终答案。 

从最小列索引迭代到最大列索引，并从哈希映射中收集相应的列表。 
7. 返回完成的垂直顺序遍历。 

### 为什么它有效

 该算法之所以有效，是因为 BFS 逐级处理节点，从而保证了从上到下的排序。 在同一级别内，节点是从左到右访问的，因为左子节点在右子节点之前排队。 因此，共享相同行和列的节点会自动按所需顺序出现。 在遍历过程中按列对节点进行分组直接构造了正确的垂直排​​序。 

## Python 解决方案```python
from collections import defaultdict, deque
from typing import List, Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def verticalOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        column_table = defaultdict(list)
        queue = deque([(root, 0)])

        min_column = 0
        max_column = 0

        while queue:
            node, column = queue.popleft()

            column_table[column].append(node.val)

            min_column = min(min_column, column)
            max_column = max(max_column, column)

            if node.left:
                queue.append((node.left, column - 1))

            if node.right:
                queue.append((node.right, column + 1))

        result = []

        for column in range(min_column, max_column + 1):
            result.append(column_table[column])

        return result
```该实现从空树情况的早期返回开始。 

一个`defaultdict(list)`用于存储属于每个垂直列的节点。 这避免了在附加值之前手动检查存在性。 

队列存储对`(node, column)`以便每个节点都知道其当前的垂直位置。 

BFS遍历时：

 - 当前节点值被追加到其列列表中
 - 更新了列边界
 - 子级被插入队列并调整列索引

 最后，该算法从最小的列索引迭代到最大的列索引，确保输出列从左到右出现。 

该实现依赖 BFS 排序来满足以下两个要求：

 - 从上到下的顺序
 - 从左到右打破平局

 不需要显式排序。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func verticalOrder(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }

    type Pair struct {
        node   *TreeNode
        column int
    }

    columnTable := make(map[int][]int)
    queue := []Pair{{root, 0}}

    minColumn := 0
    maxColumn := 0

    for len(queue) > 0 {
        current := queue[0]
        queue = queue[1:]

        node := current.node
        column := current.column

        columnTable[column] = append(columnTable[column], node.Val)

        if column < minColumn {
            minColumn = column
        }

        if column > maxColumn {
            maxColumn = column
        }

        if node.Left != nil {
            queue = append(queue, Pair{node.Left, column - 1})
        }

        if node.Right != nil {
            queue = append(queue, Pair{node.Right, column + 1})
        }
    }

    result := [][]int{}

    for column := minColumn; column <= maxColumn; column++ {
        result = append(result, columnTable[column])
    }

    return result
}
```Go 实现遵循与 Python 版本相同的逻辑，但使用 Go 特定的数据结构。 

定制`Pair`struct 存储节点指针及其列索引。 队列是使用切片实现的，其中元素从前面删除。 

哈希映射使用`map[int][]int`将列索引与节点值相关联。 

与 Python 不同，Go 需要明确的`nil`检查和手动队列管理。 否则，整体算法保持不变。

辅助空间来自两种结构：

 - 用于BFS的队列

class Solution:
    def verticalOrder(self, root: Optional[TreeNode]):
        from collections import defaultdict, deque

        if not root:
            return []

        column_table = defaultdict(list)
        queue = deque([(root, 0)])

        min_column = 0
        max_column = 0

 ## 边缘情况

 ### 空树

 空树是最常见的故障点之一。 如果实现假设根始终存在，则访问子指针或节点值将引发错误。 该解决方案立即处理此问题：```
if not root:
    return []
```这保证了尽可能最小的输入的安全执行。 

### 共享相同行和列的节点

 这是问题中最棘手的逻辑边缘情况。 考虑：```
      1
     / \
    2   3
     \ /
      4 5
```两个都`4`和`5`占据同一行和同一列。 正确的顺序是`[4, 5]`因为`4`从左到右首先出现。 

DFS 实现可能会意外地产生`[5, 4]`取决于遍历顺序。 BFS 避免了这个问题，因为节点是逐级处理的，并且子节点先左后右排队。 

### 高度倾斜的树

 仅向左或向右延伸的树会创建连续减少或增加的列索引。 

例如：```
    1
   /
  2
 /
3
```列变成`0`,`-1`， 和`-2`。 

如果实现未正确跟踪最小和最大列索引，则最终输出排序可能不正确或不完整。 该解决方案在遍历期间显式维护两个边界，确保所有列都以正确的从左到右的顺序返回。
