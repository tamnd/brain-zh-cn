 **难度：** 🟡 中等
 **主题：** 数学、动态规划、回溯

 ## 解决方案

 ## 问题理解

 该问题要求我们计算范围内有多少个整数`0 <= x < 10^n`不包含重复的数字。 

例如，当`n = 2`，有效范围为：```
0 <= x < 100
```这意味着我们考虑来自`0`到`99`。 在这些数字中，我们只统计那些数字都是唯一的。 像这样的数字`11`,`22`， 和`99`由于重复数字而被排除。 

短语“唯一数字”是指在同一数字中没有数字出现超过一次。 前导零不被视为数字的实际数字。 例如：

-`7`有效
 -`10`有效
 -`98`有效
 -`11`无效
 -`100`无效，因为`0`重复

 输入`n`代表我们可以使用的最大位数。 输出是范围内具有唯一数字的数字总数`[0, 10^n)`。 

限制条件是：```
0 <= n <= 8
```这很重要，因为它告诉我们最大数字长度仅为 8。由于十进制数字的范围仅从`0`到`9`，总共只有 10 个可能的唯一数字。 这强烈建议采用组合计数方法而不是强力枚举。 

一些边缘情况很重要：

 -`n = 0`- 范围变为`0 <= x < 1`- 只有号码`0`存在，所以答案是`1`-`n > 10`- 此处不相关，因为约束限制`n <= 8`- 尽管如此，从概念上讲，长度超过 10 位的数字不能具有所有唯一的十进制数字
 - 带有前导零的数字

 - 我们没有明确表示前导零
 - 例如，`0012`只是`12`单独检查每个数字的简单实现适用于小型`n`，但随着范围呈指数级增长，它会变得低效。 

## 方法

 ### 蛮力方法

 蛮力方法迭代范围内的每个数字：```
0 to 10^n - 1
```对于每个数字，我们检查其数字并确定是否有任何数字出现多次。 

一种简单的方法是：

 1. 将数字转换为字符串
 2. 将每个数字插入一组
 3. 将集合大小与字符串长度进行比较

 如果两个长度匹配，则所有数字都是唯一的。 

这种方法是正确的，因为它显式检查每个有效候选者并直接验证唯一性条件。 

然而，它变得低效，因为整数的数量呈指数增长`n`。 

例如：

-`n = 8`- 范围大小=`10^8 = 100,000,000`对于如此小的组合问题，检查一亿个数字的成本是不必要的。 

### 最佳方法

 关键的见解是我们不需要自己生成数字。 相反，我们可以计算每个数字长度存在多少个有效数字。 

假设我们要计算有效的 2 位数字：

 - 第一个数字：

 - 不能是`0`- 有 9 个选择（`1-9`）
 - 第二位数字：

 - 不能重复第一个数字
 - 剩余 9 个选择

 总计：```
9 * 9 = 81
```对于 3 位数字：

 - 第一个数字：9 个选择
 - 第二位数字：9 个选择
 - 第三位数字：8 个选择

 总计：```
9 * 9 * 8 = 648
```这成为一个排列计数问题。 

然后我们将所有长度的计数相加`1`到`n`，加上特殊情况`0`。 

这种方法完全避免了枚举，并且以相对于约束边界的恒定时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(10^n * n) | O(10^n * n) | O(n) | 单独检查每个数字 |
 | 最佳| O(n) | O(1) | O(1) | 使用组合计数 |

 ## 算法演练

 ### 最优计数算法

 1.处理特殊情况`n == 0`。 

如果`n = 0`，唯一有效的数字是`0`，所以我们立即返回`1`。 
2. Initialize the answer for single digit numbers.

 All one digit numbers are valid because no digit can repeat within a single digit number.

 这些都是：```
0, 1, 2, ..., 9
```所以我们从以下开始：```
total = 10
```3. 开始数更多位数的数字。 

对于 2 位数字：

 - 第一位数字不能为零
 - 剩余数字不能与前面的数字重复

 我们使用：```
current_count
```存储当前数字长度存在多少个有效数字。 
4. 增量计算计数。 

对于数字长度`k`:

 - 第一个数字有 9 个选择
 - 第二个数字还有 9 个剩余选择
 - 第三位数字还有 8 个剩余选择
 - 第四位数字还有 7 个剩余选择
 - 等等

 我们反复乘以剩余的可用数字。 
5. 将每个数字长度贡献添加到总数中。 

在计算出特定数字长度的所有有效数字后，我们将它们添加到运行答案中。 
6. 继续直到达到数字长度`n`。 

由于只有 10 个唯一数字，乘法自然会随着数字长度的增加而减少。 

### 为什么它有效

 该算法之所以有效，是因为每个具有唯一数字的有效数字都可以根据其数字长度进行唯一分类。 

对于每个长度：

 - 第一位数字不能为零
 - 每个后续数字必须与之前选择的所有数字不同

 乘法原理正确地计算了所有可能的有效排列，没有重复或遗漏。 将所有长度上的这些计数相加即可得出所需范围内唯一数字的总数。 

## Python 解决方案```python
class Solution:
    def countNumbersWithUniqueDigits(self, n: int) -> int:
        if n == 0:
            return 1

        total = 10
        current_count = 9
        available_digits = 9

        for digit_length in range(2, n + 1):
            current_count *= available_digits
            total += current_count
            available_digits -= 1

        return total
```实现从处理边缘情况开始`n == 0`。 

然后我们初始化：

 -`total = 10`- 代表所有有效的一位数字
 -`current_count = 9`- 表示多位数字第一位有效选择的个数
 -`available_digits = 9`- 选择第一个数字后，还剩下 9 个未使用的数字

 循环内部：```python
current_count *= available_digits
```扩展下一个数字位置的计数。 

例如：

 - 2 位数字：

 -`9 * 9`- 3 位数字：

 -`9 * 9 * 8`- 4 位数字：

 -`9 * 9 * 8 * 7`每次迭代将新计算的计数添加到`total`。 

循环继续，直到我们处理完所有数字长度为止`n`。 

## 解决方案```go
func countNumbersWithUniqueDigits(n int) int {
    if n == 0 {
        return 1
    }

    total := 10
    currentCount := 9
    availableDigits := 9

    for digitLength := 2; digitLength <= n; digitLength++ {
        currentCount *= availableDigits
        total += currentCount
        availableDigits--
    }

    return total
}
```Go 实现遵循与 Python 解决方案相同的组合逻辑。 

一些特定于 Go 的细节值得注意：

 - 整数算术很简单，因为在问题约束内结果仍然很小。 
- 不需要额外的数据结构。 
- 为了清晰和一致性，变量命名反映了 Python 版本。

 ## 边缘情况

 ### 边缘情况 1：`n = 0`这种情况很容易处理不当，因为许多实现都假设至少存在一位数字。 

然而，问题将范围定义为：```
0 <= x < 10^0
```自从`10^0 = 1`，只有数字`0`包括在内。 

该实现通过以下方式显式处理此问题：```
if n == 0:
    return 1
```### 边缘情况 2：最大约束`n = 8`在这种规模下，暴力解决方案变得效率极低，因为它需要检查：```
100,000,000
```分别编号。 

组合解决方案完全避免了枚举，并且仅使用几次乘法来计算结果，即使在最大输入大小下也能保持高效。 

### 边缘情况 3：数字用完

 总共只有 10 位小数。 

随着数字长度的增加，可用的未使用数字的数量会减少：```
9, 8, 7, ...
```该算法使用以下方法正确跟踪剩余的选择：```
available_digits -= 1
```这保证了我们永远不会计算具有重复数字的无效数字。
