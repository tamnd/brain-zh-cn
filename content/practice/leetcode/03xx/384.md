 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个支持对整数数组进行两种操作的数据结构：

 1. 将阵列重置回其原始顺序。 
2. 返回数组的随机打乱版本。 

重要的要求是数组的每个可能的排列必须具有相同的可能性。 这意味着洗牌操作不会引入统计偏差。 如果数组包含`n`元素，有`n!`可能的排列，并且每一种排列都必须以概率出现`1 / n!`。 

构造函数接收初始数组并将其存储在内部。 这`reset()`方法必须恢复并返回与创建对象时完全相同的原始配置。 这`shuffle()`方法必须返回数组的随机排列版本。 

限制相对较小：

 -`1 <= nums.length <= 50`- 所有元素都是独一无二的
 - 至多`10^4`总来电次数`reset`和`shuffle`尽管数组大小很小，但问题根本在于随机化的正确性而不是原始性能。 一个幼稚的实现可能看起来在视觉上有效，但仍然产生有偏差的排列。 

由于所有元素都是唯一的，因此我们无需担心重复值会产生无法区分的排列。 这简化了概率分析。 

一些边缘情况很重要：

 - 长度数组`1`，其中改组应始终返回相同的数组。 
- 多次连续调用`shuffle()`，必须保持独立和公正。 
- 致电`reset()`洗牌后，必须恢复准确的原始顺序。 
- 避免存储的原始数组的意外突变。 

## 方法

 ### 蛮力方法

 一种强力方法是生成数组的所有可能的排列，将它们存储在列表中，然后在任何时候随机选择一个排列`shuffle()`被称为。 

这种方法是正确的，因为每个排列都是显式生成的，因此从列表中统一选择可以保证所有结果的概率相等。 

然而，排列的数量呈阶乘增长。 长度的数组`n`有`n!`排列。 尽管限制很小，但阶乘增长很快就变得不切实际。 例如：

-`5! = 120`-`10! = 3,628,800`-`50!`是一个天文数字

 内存使用和预处理时间都变得完全不可行。 

### 最佳方法

 最佳解决方案使用 Fisher-Yates Shuffle 算法，也称为 Knuth Shuffle。 

关键的见解是，我们可以逐步构建均匀随机的排列，而不是生成每个排列。 

在数组中的每个位置，我们随机选择剩余未使用的元素之一并将其放置在那里。 通过确保每个剩余元素在每一步都有相同的被选择概率，所有最终排列的可能性都相同。 

Fisher-Yates 算法就地工作并以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 显式生成每个排列 |
 | 最佳| O(n) | O(n) | 使用具有均匀随机性的 Fisher-Yates 洗牌 |

 ## 算法演练

 ### 费舍尔-耶茨洗牌

 1. 在初始化期间存储原始数组的副本。 

我们需要原始配置，以便`reset()`可以稍后恢复。 副本是必要的，因为洗牌后的数组将被就地修改。 
2. 在`reset()`，返回原始数组的新副本。 

直接返回原始引用是危险的，因为外部代码可能会修改它。 返回副本可以防止意外突变。 
3. 在`shuffle()`，创建原始数组的工作副本。 

我们不想永久改变存储的原始配置。 
4. 从左到右迭代数组。 

假设我们当前处于索引处`i`。 
5. 随机选择一个索引`j`之间`i`和`n - 1`。 

该范围代表尚未固定到最终位置的所有元素。 
6. 交换索引处的元素`i`和`j`。 

这会将一个随机选择的剩余元素放置到位`i`。 
7. 继续，直到处理完所有位置。 

在最后一次迭代之后，数组被完全洗牌。 

### 为什么它有效

 正确性来自于每个位置在所有剩余未使用元素中统一选择的事实。 

对于大小的数组`n`:

 - 第一个位置有`n`同样可能的选择。 
- 第二个位置有`n - 1`同样可能的选择。 
- 第三个位置有`n - 2`同样可能的选择。 

继续这个过程会产生：$n \times (n-1) \times (n-2) \times \cdots \times 1 = n!$可能的结果，并且每个排列都是以相同的概率生成的。 

## Python 解决方案```python
from typing import List
import random

class Solution:

    def __init__(self, nums: List[int]):
        self.original = nums[:]

    def reset(self) -> List[int]:
        return self.original[:]

    def shuffle(self) -> List[int]:
        shuffled = self.original[:]
        n = len(shuffled)

        for i in range(n):
            j = random.randint(i, n - 1)
            shuffled[i], shuffled[j] = shuffled[j], shuffled[i]

        return shuffled

# Your Solution object will be instantiated and called as such:
# obj = Solution(nums)
# param_1 = obj.reset()
# param_2 = obj.shuffle()
```构造函数将输入数组的副本存储在`self.original`。 使用切片会创建一个单独的列表，因此以后的修改不会影响存储的版本。 

这`reset()`方法只是返回原始数组的新副本。 返回副本而不是内部引用可以防止调用者改变内部状态。 

这`shuffle()`方法创建另一个名为`shuffled`。 这是我们要修改的数组。 

循环处理每个索引`i`。 对于每个位置，我们随机选择一个索引`j`从范围`[i, n - 1]`。 交换这些值可以保证每个剩余元素都有相同的占据位置的概率`i`。 

该算法就地修改数组并在线性时间内完成。 

## 解决方案```go
package main

import (
	"math/rand"
)

type Solution struct {
	original []int
}

func Constructor(nums []int) Solution {
	originalCopy := make([]int, len(nums))
	copy(originalCopy, nums)

	return Solution{
		original: originalCopy,
	}
}

func (this *Solution) Reset() []int {
	resetCopy := make([]int, len(this.original))
	copy(resetCopy, this.original)

	return resetCopy
}

func (this *Solution) Shuffle() []int {
	shuffled := make([]int, len(this.original))
	copy(shuffled, this.original)

	n := len(shuffled)

	for i := 0; i < n; i++ {
		j := rand.Intn(n-i) + i
		shuffled[i], shuffled[j] = shuffled[j], shuffled[i]
	}

	return shuffled
}

/**
 * Your Solution object will be instantiated and called as such:
 * obj := Constructor(nums);
 * param_1 := obj.Reset();
 * param_2 := obj.Shuffle();
 */
```Go 实现遵循与 Python 版本相同的逻辑，但切片需要仔细复制，因为切片引用共享的底层数组。 

这`copy()`每当我们需要一个独立的切片时，就会使用该函数。 如果不进行复制，洗牌过程中的突变会改变存储的原始数组。 

随机索引生成与 Python 略有不同。`rand.Intn(k)`生成一个值`[0, k)`，所以我们将其移动`i`获得范围`[i, n - 1]`。 

整数溢出不是问题，因为约束非常小。

 ## 边缘情况

 ### 单元素数组

 仅包含一个元素的数组恰好具有一种可能的排列。 幼稚的实现可能仍然会尝试不必要的交换或随机操作。 Fisher-Yates 算法自然地处理了这个问题，因为循环要么通过自交换运行一次，要么不执行任何有意义的更改。 

### 返回数组的外部突变

 返回对内部数组的直接引用时，会出现一个微妙的错误。 如果调用者修改返回的数组，则对象的内部状态可能会被损坏。 此实现通过始终使用 Python 中的切片返回副本来避免该问题`copy()`在围棋中。 

### 多个连续的随机调用

 一些不正确的实现会重复对已经打乱的数组进行打乱。 虽然这看起来可以接受，但它使正确性推理变得复杂，并且如果实施不当，可能会意外地引入偏差。 该解决方案始终从洗牌前的原始存储配置开始，确保每个洗牌调用独立产生均匀的随机排列。
