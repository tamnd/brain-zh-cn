[LeetCode 第 366 题](https://leetcode.com/problems/find-leaves-of-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们重复删除二叉树中的所有叶节点，并记录每轮删除的值。 

叶节点是没有左或右子节点的节点。 在每次迭代期间，我们收集每个当前叶节点，从概念上将它们从树中删除，并继续该过程直到树变空。 

输入是二叉树的根节点。 输出是一个列表列表，其中每个内部列表包含在一轮叶子删除期间删除的值。 

例如，考虑这棵树：```
        1
       / \
      2   3
     / \
    4   5
```第一轮，节点`4`,`5`， 和`3`是叶子，所以我们收集它们：```
[4,5,3]
```删除它们后，树变成：```
    1
   /
  2
```现在`2`是一片叶子：```
[2]
```最后，`1`成为唯一剩下的叶子：```
[1]
```所以结果是：```
[[4,5,3],[2],[1]]
```限制比较小，最多100个节点。 即使效率较低的方法也可以通过，但目标是设计一个干净且可扩展的解决方案。 由于问题涉及到反复识别和移除叶子，因此我们应该仔细考虑是否可以避免多次对树进行物理修改。 

一些边缘情况很重要：

 - 一棵只有一个节点的树。 该节点立即成为叶子。 
- 一棵完全倾斜的树，每一轮删除仅删除一个节点。 
- 子树深度不均匀的树，叶子出现在不同的级别。 
- 许多叶子同时存在的树。 

该问题保证输入是一棵有效的二叉树并且至少包含一个节点。 

## 方法

 ### 蛮力方法

 最直接的解决方案是完全按照描述模拟该过程。 

每轮期间：

 1. 遍历整棵树。 
2. 识别当前所有叶子。 
3. 存储它们的值。 
4. 将他们从父母身边带走。 
5. 重复此操作，直到树为空。 

这种方法是正确的，因为它从字面上遵循问题陈述。 每次迭代都会准确删除当前离开的节点。 

然而，这种方法效率较低，因为树可能会被遍历很多次。 在最坏的情况下，例如完全倾斜的树，每轮仅删除一个节点。 如果有`n`节点，我们可以执行`n`完全遍历，导致二次时间复杂度。 

### 最佳方法

 关键的见解是我们实际上不需要物理删除节点。 

相反，我们可以观察到节点被删除的轮次完全取决于该节点距离树底部的高度。 

- 叶子节点首先被删除，因此它们属于级别`0`。 
- 之后他们的父母变成叶子，所以他们属于水平`1`。 
- 更高的祖先属于逐渐更高的层次。 

这意味着问题可以转化为：

 > 按距底部的高度对节点进行分组。 

我们可以使用后序深度优先搜索来计算这个高度。 

对于每个节点：

 - 计算左子树的高度。 
- 计算右子树的高度。 
- 节点的高度为：```
max(leftHeight, rightHeight) + 1
```在同一轮中删除具有相同高度的节点。 

这避免了重复遍历并在一次 DFS 遍历中计算所有内容。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 反复遍历并修改树 |
 | 最佳| O(n) | O(n) | 单DFS按删除轮次对节点进行分组|

 ## 算法演练

 ### 基于高度的最优 DFS 算法

 1. 从根开始后序 DFS 遍历。 

后序遍历很重要，因为我们必须在处理当前节点之前处理子节点。 节点的删除轮次取决于其子节点消失的时间。 
2. 定义空节点的高度为`-1`。 

这自然简化了叶子计算。 如果两个孩子都为空：```
height = max(-1, -1) + 1 = 0
```所以叶子节点自动获取高度`0`。 
3. 递归计算左子树的高度。 

这告诉我们在左子树完全消失之前需要多少轮。 
4. 递归计算右子树的高度。 

同样，这决定了右子树的存活时间。 
5. 计算当前节点的高度。```
currentHeight = max(leftHeight, rightHeight) + 1
```只有当两棵子树都消失后，该节点才能成为叶子，因此它取决于更深的子树。 
6. 使用高度作为结果数组的索引。 

如果这个高度以前没有出现过，则创建一个新的内部列表。 

然后将当前节点的值附加到：```
result[currentHeight]
```7. 将计算出的高度返回给父调用。 

这允许祖先节点确定它们自己的移除轮次。 
8. DFS完成后，返回结果。 

结果中的每个索引对应于一轮叶子去除。 

### 为什么它有效

 该算法之所以有效，是因为节点在其下方的所有节点都已被删除后才成为叶子。 因此，节点的移除轮数等于从树底部测量的节点高度。 后序遍历保证子节点的高度在父节点的高度之前计算，因此每个节点都被放入正确的移除组中。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def findLeaves(self, root: Optional[TreeNode]) -> List[List[int]]:
        result = []

        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return -1

            left_height = dfs(node.left)
            right_height = dfs(node.right)

            current_height = max(left_height, right_height) + 1

            if current_height == len(result):
                result.append([])

            result[current_height].append(node.val)

            return current_height

        dfs(root)
        return result
```该解决方案使用嵌套的 DFS 辅助函数，该函数返回从树底部测量的每个节点的高度。 

基本情况返回`-1`对于空节点。 这允许叶节点自然地计算高度`0`。 

递归首先处理左子树和右子树。 这是后序遍历，这是必要的，因为节点的删除轮次取决于其子节点。 

计算完两个子树的高度后，使用以下方法确定当前节点的高度：```python
max(left_height, right_height) + 1
```每当出现新的高度级别时，结果列表就会动态扩展。 每个节点值都被附加到与其删除轮对应的列表中。 

最后，DFS 从根开始，并返回完整构造的结果。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func findLeaves(root *TreeNode) [][]int {
    result := [][]int{}

    var dfs func(node *TreeNode) int

    dfs = func(node *TreeNode) int {
        if node == nil {
            return -1
        }

        leftHeight := dfs(node.Left)
        rightHeight := dfs(node.Right)

        currentHeight := max(leftHeight, rightHeight) + 1

        if currentHeight == len(result) {
            result = append(result, []int{})
        }

        result[currentHeight] = append(result[currentHeight], node.Val)

        return currentHeight
    }

    dfs(root)

    return result
}

func max(a int, b int) int {
    if a > b {
        return a
    }
    return b
}
```Go 实现遵循与 Python 版本相同的逻辑。 主要区别在于 Go 需要显式的切片管理和辅助函数。 

结果表示为整数切片的切片：```go
[][]int
```DFS 助手是作为递归闭包实现的。 由于 Go 没有提供内置的`max`整数函数，包含一个小辅助函数。 

Nil 指针直接使用以下方法处理：```go
if node == nil
```这对应于 Python 检查`None`。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(n) | 结果存储加递归栈|

 DFS 恰好遍历每个节点一次，并且每次访问仅执行常量工作。 因此，总运行时间与节点数量呈线性关系。 

空间复杂度有两个来源：

 - 递归栈，可以达到`O(h)`在哪里`h`是树的高度。 
- 结果结构，存储所有节点值。 

在倾斜树的最坏情况下，递归深度变为`O(n)`。

 ## 边缘情况

 单节点树是最小的有效输入，并且很容易在高度计算中暴露出差一错误。 如果基本情况实施不正确，根可能会被放入错误的组中。 此实现可以正确处理它，因为 null 子级返回`-1`，导致单个节点计算高度`0`。 

完全倾斜的树的行为与链表类似。 在这种情况下，每一轮只删除一个节点。 简单的实现可能会重复遍历整个树，从而导致性能下降。 基于 DFS 高度的解决方案仍然只对每个节点处理一次，因此运行时间保持线性。 

子树深度不均匀的树是错误的另一个常见来源。 仅当两个子树都消失后，节点才应变为可移动。 该算法通过使用以下方式正确处理此问题：```
max(leftHeight, rightHeight) + 1
```这保证了节点在确定其删除轮次之前等待更深的子树。 

当多个叶子同时存在于树中的不同位置时，会出现另一种微妙的边缘情况。 无论遍历顺序如何，该实现都会正确地将具有相同高度的所有节点分组在一起，这与每轮内的顺序无关紧要的问题陈述相匹配。
