[LeetCode 问题 302](https://leetcode.com/problems/smallest-rectangle-enending-black-pixels/)

 **难度：** 🔴难
 **主题：** 数组、二分搜索、深度优先搜索、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个二进制矩阵，其中每个单元格包含`'0'`或者`'1'`。 一个`'1'`代表一个黑色像素，而`'0'`代表一个白色像素。 所有黑色像素都属于一个连通分量，这意味着仅使用水平或垂直移动就可以从每个其他黑色像素到达每个黑色像素。 

我们还得到了坐标`(x, y)`一个黑色像素。 我们的任务是计算包含图像中每个黑色像素的最小轴对齐矩形的面积。 

轴对齐的矩形意味着矩形的边必须与矩阵的行和列保持平行。 因此，我们只需要确定四个边界：

 - 最上面的行包含黑色像素
 - 最底行包含黑色像素
 - 最左边的列包含黑色像素
 - 最右边的列包含黑色像素

 一旦知道这些边界，矩形区域就是：$$(\text{bottom} - \text{top} + 1) \times (\text{right} - \text{left} + 1)$$重要的约束是算法必须在小于`O(mn)`时间、地点`m`是行数并且`n`是列数。 直接对矩阵进行全面扫描会访问每个单元，这会花费`O(mn)`，所以我们需要更高效的东西。 

关键的观察结果是所有黑色像素形成一个连通分量。 这意味着包含黑色像素的行形成连续的间隔，并且包含黑色像素的列也形成连续的间隔。 这种单调结构使我们能够使用二分搜索来有效地定位矩形边界。 

一些边缘情况很重要：

 - 图像可能仅包含一个黑色像素。 
- 黑色区域可能跨越整个矩阵。 
- 黑色分量可以占据单行或单列。 
- 提供的`(x, y)`可能已经位于矩形边界之一上。 
- 矩阵维度可以小至`1 x 1`。 

该问题保证：

 -`(x, y)`始终是黑色像素。 
- 恰好有一个相连的黑色区域。 
- 矩阵维度最多为`100 x 100`。 

这些保证大大简化了解决方案。 

## 方法

 ### 蛮力方法

 最简单的解决方案是扫描矩阵中的每个单元格。 每当我们遇到黑色像素时，我们都会更新四个变量：

 - 最小行索引
 - 最大行索引
 - 最小列索引
 - 最大列索引

 最后，我们根据这些边界计算矩形面积。 

这种方法是正确的，因为它直接检查每个黑色像素并记录极值坐标。 然而，它总是访问所有`m * n`细胞，即使黑色区域很小。 

由于该问题明确要求比`O(mn)`复杂性，这种方法还不够。 

### 最佳方法，行和列的二分搜索

 重要的见解是黑色像素形成一个连通区域。 正因为如此：

 - 包含黑色像素的所有行连续出现。 
- 所有包含黑色像素的列连续出现。 

假设我们定义一个辅助函数：

 -`rowHasBlack(row)`返回一行是否包含至少一个黑色像素。 
-`colHasBlack(col)`返回一列是否至少包含一个黑色像素。 

那么这些行在概念上看起来像这样：```
False False False True True True False False
```同样的属性也适用于列。 

这种单调模式允许二分搜索定位：

 - 第一行包含黑色像素
 - 黑色区域之后的第一行
 - 第一列包含黑色像素
 - 黑色区域之后的第一列

 每个二分查找检查整行或整列。 

这将运行时间减少到：$$O(m \log n + n \log m)$$这绝对比`O(mn)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(百万) | O(1) | O(1) | 扫描每个细胞并追踪边界 |
 | 最佳 | O(m log n + n log m) | O(m log n + n log m) | O(1) | O(1) | 使用单调结构进行二分搜索行和列 |

 ## 算法演练

 ### 第 1 步：确定矩阵维度

 首先，存储行数和列数：```
rows = len(image)
cols = len(image[0])
```我们在二分搜索过程中反复需要这些维度。 

### 步骤 2：为行创建辅助函数

 我们定义一个函数来检查一行是否包含至少一个黑色像素。```python
def row_has_black(row):
    return '1' in image[row]
```该函数扫描一行`O(n)`时间。 

结果表现单调：

 - 黑色区域返回之前的行`False`- 区域内的行返回`True`- 区域返回后的行`False`### 步骤 3：为列创建辅助函数

 我们还为列定义了一个函数：```python
def col_has_black(col):
    for row in range(rows):
        if image[row][col] == '1':
            return True
    return False
```这会扫描其中的一列`O(m)`时间。 

同样，结果形成单调结构。 

### 步骤 4：二分搜索顶部边界

 我们搜索行来自`0`到`x`。 

我们希望第一行包含黑色像素。 

如果中间行包含黑色像素，则顶部边界仍可能位于其上方，因此我们向左移动。 

否则，我们向右移动。 

### 步骤 5：二分搜索底部边界

 我们搜索行来自`x + 1`到`rows`。 

这次我们寻找不包含黑色像素的第一行。 

实际的底部边界是该位置之前的一行。 

### 步骤 6：二分搜索左边界

 我们搜索列`0`到`y`。 

我们希望第一列包含黑色像素。 

### 步骤 7：二分查找正确的边界

 我们搜索列`y + 1`到`cols`。 

我们寻找没有黑色像素的第一列。 

实际的右边界是该位置之前的一列。 

### 步骤 8：计算矩形面积

 一旦知道了所有边界：```
height = bottom - top
width = right - left
```该区域变为：```
height * width
```### 为什么它有效

 该算法依赖于这样一个事实：所有黑色像素都属于一个连通分量。 因此，包含黑色像素的行必须形成一个连续的间隔。 对于列也是如此。 

只要搜索空间可以分为两个单调区域，二分搜索就会起作用。 在这里，行从以下位置转换：```
no black pixels -> black pixels -> no black pixels
```同样的属性也适用于列。 因此，二分查找正确地识别了矩形边界。 

## Python 解决方案```python
from typing import List

class Solution:
    def minArea(self, image: List[List[str]], x: int, y: int) -> int:
        rows = len(image)
        cols = len(image[0])

        def row_has_black(row: int) -> bool:
            return '1' in image[row]

        def col_has_black(col: int) -> bool:
            for row in range(rows):
                if image[row][col] == '1':
                    return True
            return False

        # Find top boundary
        left = 0
        right = x

        while left < right:
            mid = (left + right) // 2

            if row_has_black(mid):
                right = mid
            else:
                left = mid + 1

        top = left

        # Find bottom boundary
        left = x + 1
        right = rows

        while left < right:
            mid = (left + right) // 2

            if row_has_black(mid):
                left = mid + 1
            else:
                right = mid

        bottom = left

        # Find left boundary
        left = 0
        right = y

        while left < right:
            mid = (left + right) // 2

            if col_has_black(mid):
                right = mid
            else:
                left = mid + 1

        left_boundary = left

        # Find right boundary
        left = y + 1
        right = cols

        while left < right:
            mid = (left + right) // 2

            if col_has_black(mid):
                left = mid + 1
            else:
                right = mid

        right_boundary = left

        return (bottom - top) * (right_boundary - left_boundary)
```实现首先存储矩阵维度。 然后定义两个辅助函数。 一个检查行是否包含任何黑色像素，另一个检查列是否包含任何黑色像素。 

第一个二分搜索找到包含黑色像素的最上面的行。 由于给定的坐标`(x, y)`保证是黑色的，我们知道顶部边界位于行之间的某个位置`0`和行`x`。 

第二次二分查找找到黑色区域之后的第一行。 这给了我们唯一的下限。 

对列重复相同的策略。 

最后，使用独占边界计算矩形尺寸：```python
height = bottom - top
width = right_boundary - left_boundary
```将它们相乘得出最终面积。 

## 解决方案```go
func minArea(image [][]byte, x int, y int) int {
	rows := len(image)
	cols := len(image[0])

	rowHasBlack := func(row int) bool {
		for col := 0; col < cols; col++ {
			if image[row][col] == '1' {
				return true
			}
		}
		return false
	}

	colHasBlack := func(col int) bool {
		for row := 0; row < rows; row++ {
			if image[row][col] == '1' {
				return true
			}
		}
		return false
	}

	// Find top boundary
	left, right := 0, x

	for left < right {
		mid := (left + right) / 2

		if rowHasBlack(mid) {
			right = mid
		} else {
			left = mid + 1
		}
	}

	top := left

	// Find bottom boundary
	left, right = x+1, rows

	for left < right {
		mid := (left + right) / 2

		if rowHasBlack(mid) {
			left = mid + 1
		} else {
			right = mid
		}
	}

	bottom := left

	// Find left boundary
	left, right = 0, y

	for left < right {
		mid := (left + right) / 2

		if colHasBlack(mid) {
			right = mid
		} else {
			left = mid + 1
		}
	}

	leftBoundary := left

	// Find right boundary
	left, right = y+1, cols

	for left < right {
		mid := (left + right) / 2

		if colHasBlack(mid) {
			left = mid + 1
		} else {
			right = mid
		}
	}

	rightBoundary := left

	return (bottom - top) * (rightBoundary - leftBoundary)
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 主要区别在于 Go 使用`[][]byte`而不是`List[List[str]]`。 

辅助函数作为闭包实现。 由于Go不支持Python的方便`'1' in row`语法，必须手动扫描每一行。 

不需要对整数溢出进行特殊处理，因为矩阵维度最多为`100 x 100`，因此最大可能面积仅为`10,000`。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m log n + n log m) | O(m log n + n log m) | 每个二分搜索重复检查行或列 |

 每行检查扫描`n`列，二分查找执行`O(log m)`行搜索。 因此，行搜索成本`O(n log m)`。 

同样，每列检查扫描`m`行，二分查找执行`O(log n)`栏目搜索。 因此，列搜索成本`O(m log n)`。 

将它们加在一起得到：$$O(m \log n + n \log m)$$该算法使用恒定的额外内存，因为它只存储一些索引和辅助函数。

 ## 边缘情况

 ### 单个黑色像素

 最小的可能输入是一个仅包含一个黑色像素的矩阵。 这种情况在计算矩形尺寸时可能会出现相差一的错误。 

例如：```
[["1"]]
```该实现可以正确处理此问题，因为二分搜索返回独占边界：```
top = 0
bottom = 1
left = 0
right = 1
```结果面积变为`1`。 

### 黑色区域占据整个矩阵

 如果每个单元格都是黑色的，则矩形应覆盖整个矩阵。 

有错误的实现可能会错误地提前停止二分搜索或无法包含最后一行或最后一列。 

该算法可以正确处理这个问题，因为：

 - 底部边界搜索查找没有黑色像素的第一行。 
- 右边界搜索查找没有黑色像素的第一列。 

当不存在这样的行或列时，搜索自然终止于`rows`和`cols`。 

### 矩形宽度或高度等于一

 连接的黑色区域可以形成细线。 

示例：```
Vertical:
0 1 0
0 1 0
0 1 0
```

```
Horizontal:
1 1 1
```这些情况是差一错误的常见来源，因为一维等于`1`。 

该实现始终使用独占边界：```
height = bottom - top
width = right - left
```这确保了矩形的宽度`1`或身高`1`计算正确。
