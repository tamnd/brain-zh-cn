[LeetCode 第 336 题](https://leetcode.com/problems/palindrome-pairs/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、字符串、Trie、哈希函数

 ## 解决方案

 ## 问题理解

 该问题为我们提供了一个名为的唯一字符串列表`words`。 我们必须找到每对有序索引`(i, j)`这样：

 -`i != j`- 连接`words[i] + words[j]`形成一个回文

 回文是向前和向后读相同的字符串。 

重要的细节是这些对是有序的。 如果`(0, 1)`形成一个回文，`(1, 0)`可能也可能不形成一个，并且两者必须分开考虑。 

例如：```
words = ["bat", "tab"]
```-`"bat" + "tab" = "battab"`这是一个回文
 -`"tab" + "bat" = "tabbat"`这也是一个回文

 所以两者`[0,1]`和`[1,0]`属于答案。 

限制条件很大：

 - 最多`5000`话
 - 每个单词的长度可达`300`检查每一对的强力解决方案需要：```
O(n^2 * k)
```在哪里：

-`n`是单词数
 -`k`是平均字长

 与`5000`话说，这变得太慢了。 

该问题明确要求算法的运行时间与所有单词的总长度成正比，这强烈表明我们需要基于哈希或基于特里树的优化。 

有几个重要的边缘情况：

 - 空字符串
 - 单字词
 - 已经是回文的单词
 - 反向单词匹配
 - 仅单词的一部分参与回文结构的情况

 唯一性保证简化了实现，因为我们永远不会将重复的单词映射到不同的索引。 

## 方法

 ### 蛮力方法

 最直接的解决方案是检查每个有序对`(i, j)`在哪里`i != j`。 

对于每对：

 1. 连接`words[i] + words[j]`2. 检查结果是否为回文

 回文检查需要`O(k)`时间、地点`k`是组合字符串的长度。 

由于有`O(n^2)`对，总复杂度变为：```
O(n^2 * k)
```这种方法是正确的，因为它明确地检查每个可能的对。 然而，对于`n = 5000`。 

### 最佳方法

 关键的见解是回文结构可以分解为前缀和后缀。 

假设我们将一个单词分成：```
word = prefix + suffix
```如果：

-`prefix`是一个回文
 - 反转（`suffix`) 存在于数组的其他位置

 那么：```
reverse(suffix) + word
```形成一个回文。 

同样，如果：

 -`suffix`是一个回文
 - 反转（`prefix`) 存在

 那么：```
word + reverse(prefix)
```形成一个回文。 

这使我们能够避免直接比较每一对。 

我们将所有单词存储在哈希图中：```
word -> index
```然后，对于每个单词，我们尝试每个可能的分割位置并执行恒定时间反向查找。 

这极大地减少了搜索空间。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² × k) | O(n² × k) | O(1) | O(1) | 直接检查每对 |
 | 最佳 | O(n × k²) | O(n × k²) | O(n × k) | O(n × k) | 使用哈希图和回文分解 |

 这里：

-`n`= 字数
 -`k`= 最大字长

 虽然`O(n × k²)`字长不是严格线性的，它被接受是因为`k <= 300`，使解决方案变得实用。 

## 算法演练

 1. 创建从每个单词到其索引的哈希映射。 

这允许恒定时间查找来确定数组中其他位置是否存在反向子字符串。 
2. 初始化一个空的结果列表。 

这将存储所有有效的回文对。 
3. 对于数组中的每个单词，迭代每个可能的分割位置。 

如果这个词是：```
word = prefix + suffix
```然后我们考虑以下的每一个分割：```
""
to
word
```4. 检查前缀是否为回文。 

如果是，那么我们只需要后缀的反转就可以出现在其他地方。 

例子：```
word = "lls"

split:
prefix = "ll"
suffix = "s"

prefix is palindrome
reverse(suffix) = "s"
```然后：```
"s" + "lls" = "slls"
```这是一个回文。 
5. 检查后缀是否为回文。 

如果是，则可以附加前缀的相反内容。 

例子：```
word = "sssll"

split:
prefix = "sss"
suffix = "ll"

suffix is palindrome
reverse(prefix) = "sss"
```然后：```
"llsss"
```有助于形成有效的对。 
6. 避免将单词与自身配对。 

即使存在相反的情况，指数也必须不同。 
7. 继续，直到处理完所有单词和所有分割位置。 
8. 返回收集到的对。 

### 为什么它有效

 每个回文对必须围绕其中心具有对称结构。 通过将每个单词拆分为前缀和后缀，我们可以准确识别缺失的镜像部分可以由另一个单词提供的情况。 

该算法是完整的，因为每个可能的回文串联都可以通过这些有效的前缀/后缀分解之一来表示。 

## Python 解决方案```python
from typing import List

class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        def is_palindrome(s: str) -> bool:
            return s == s[::-1]

        word_to_index = {
            word: i
            for i, word in enumerate(words)
        }

        result = []

        for index, word in enumerate(words):
            length = len(word)

            for split in range(length + 1):
                prefix = word[:split]
                suffix = word[split:]

                # Case 1:
                # reverse(suffix) + word
                if is_palindrome(prefix):
                    reversed_suffix = suffix[::-1]

                    if (
                        reversed_suffix in word_to_index and
                        word_to_index[reversed_suffix] != index
                    ):
                        result.append([
                            word_to_index[reversed_suffix],
                            index
                        ])

                # Case 2:
                # word + reverse(prefix)
                #
                # split != length prevents duplicates
                if split != length and is_palindrome(suffix):
                    reversed_prefix = prefix[::-1]

                    if (
                        reversed_prefix in word_to_index and
                        word_to_index[reversed_prefix] != index
                    ):
                        result.append([
                            index,
                            word_to_index[reversed_prefix]
                        ])

        return result
```实现首先定义一个辅助函数`is_palindrome`，它检查字符串向前和向后读取是否相同。 

接下来我们构建`word_to_index`，存储每个单词及其索引的哈希图。 这提供了反向字符串的恒定时间查找。 

外循环单独处理每个单词。 对于每个单词，我们都会检查每个可能的分割位置`0`通过`len(word)`。 

在每次分割时：

 -`prefix = word[:split]`-`suffix = word[split:]`然后该算法评估两种情况。 

第一种情况检查前缀是否是回文。 如果是，那么我们搜索后缀的反向。 如果存在这样的单词，则将其放在当前单词之前形成回文对。 

第二种情况检查后缀是否是回文。 如果是，则可以将前缀的相反内容附加在当前单词之后。 

条件：```python
split != length
```防止在后缀为空时添加重复对。 

最后，返回累积的对列表。 

## 解决方案```go
package main

func palindromePairs(words []string) [][]int {
	isPalindrome := func(s string) bool {
		left := 0
		right := len(s) - 1

		for left < right {
			if s[left] != s[right] {
				return false
			}

			left++
			right--
		}

		return true
	}

	reverseString := func(s string) string {
		bytes := []byte(s)

		left := 0
		right := len(bytes) - 1

		for left < right {
			bytes[left], bytes[right] = bytes[right], bytes[left]
			left++
			right--
		}

		return string(bytes)
	}

	wordToIndex := make(map[string]int)

	for i, word := range words {
		wordToIndex[word] = i
	}

	result := [][]int{}

	for index, word := range words {
		length := len(word)

		for split := 0; split <= length; split++ {
			prefix := word[:split]
			suffix := word[split:]

			// Case 1
			if isPalindrome(prefix) {
				reversedSuffix := reverseString(suffix)

				if otherIndex, exists := wordToIndex[reversedSuffix]; exists && otherIndex != index {
					result = append(result, []int{otherIndex, index})
				}
			}

			// Case 2
			if split != length && isPalindrome(suffix) {
				reversedPrefix := reverseString(prefix)

				if otherIndex, exists := wordToIndex[reversedPrefix]; exists && otherIndex != index {
					result = append(result, []int{index, otherIndex})
				}
			}
		}
	}

	return result
}
```Go 实现遵循与 Python 版本相同的逻辑，但存在一些特定于语言的差异。 

回文检查是使用两个指针手动实现的，因为 Go 不像 Python 那样提供内置的切片反转。 

字符串反转是通过将字符串转换为字节片并就地交换字符来处理的。 

Go 切片是数组的轻量级视图，因此子字符串提取可以使用：```go
word[:split]
```和```go
word[split:]
```是高效的。 

结果存储为整数切片的切片：```go
[][]int
```这与 LeetCode 的预期返回类型相匹配。

 ## 边缘情况

 ### 空字符串

 空字符串很棘手，因为将它与任何回文串连接仍然会产生回文串。 

例如：```
"" + "aba" = "aba"
"aba" + "" = "aba"
```幼稚的实现可能会忘记处理这个特殊的结构。 当前的算法通过前缀和后缀分割自然地处理它。 

### 自匹配

 当反转子字符串时，反转的字符串可能等于当前单词本身。 

例如：```
word = "aba"
reverse(word) = "aba"
```问题需要`i != j`, so self-pairs are invalid. 实现明确检查：```
word_to_index[reversed_word] != index
```以防止错误匹配。 

### 重复对生成

 当后缀为空时，两个回文条件都可以产生相同的对。 

如果不仔细处理，可能会出现重复的答案。 

条件：```
split != length
```当后缀为空时，防止第二种情况运行，从而彻底消除重复生成。
