[LeetCode 第 333 题](https://leetcode.com/problems/largest-bst-subtree/)

 **难度：** 🟡 中等
 **主题：** 动态规划、树、深度优先搜索、二叉搜索树、二叉树

 ## 解决方案

 ## 问题理解

 该问题给了我们任意二叉树的根，并要求我们找到最大子树的大小，该子树也是有效的二叉搜索树，缩写为 BST。 

子树是任何节点及其所有后代。 这意味着我们不能选择性地忽视孩子。 如果我们选择一个节点作为子树的根，我们必须包含它下面的每个后代。 

二叉搜索树遵循两个重要规则：

 1. 左子树中的每个值必须严格小于当前节点的值。 
2. 右子树中的每个值必须严格大于当前节点的值。 

输入中提供的树不保证是 BST。 树的某些部分可能满足 BST 属性，而其他部分则不满足。 我们的目标是识别形成有效 BST 的最大连通子树，并返回该子树中的节点数。 

输入是标准二叉树根指针。 输出是一个整数，表示所有 BST 子树中的最大节点数。 

约束条件很重要：

 - 该树最多可以包含`10^4`节点。 
- 节点值范围为`-10^4`到`10^4`。 

一棵拥有一万个节点的树足够大，以至于重复的完全遍历变得昂贵。 一个`O(n^2)`在最坏的情况下，解决方案可能会超时，尤其是对于倾斜的树。 这强烈表明预期的解决方案应该只处理每个节点一次，从而导致`O(n)`方法。 

一些边缘情况很重要：

 - 应该返回一棵空树`0`。 
- 单个节点始终是大小有效的 BST`1`。 
- 没有父子关系满足 BST 规则的树仍然包含有效的单节点 BST。 
- 重复值很重要，因为 BST 规则要求严格更小和严格更大的值。 相等的值会使 BST 条件无效。 
- 高度倾斜的树可能会暴露递归验证方法的低效率。 

## 方法

 ### 蛮力方法

 最直接的解决方案是将每个节点视为可能的子树根，并检查该子树是否形成有效的 BST。 

对于每个节点：

 1. 验证以该节点为根的子树是否是 BST。 
2. 如果是，则计算该子树中的节点数。 
3. 跟踪找到的最大子树大小。 

为了正确验证 BST，我们必须确保每个节点都满足从其祖先继承的有效值范围。 这需要具有下限和上限的 DFS 遍历。 

问题是我们多次重复遍历相同的节点。 例如，当检查以某个节点为根的子树时，我们会遍历它的后代。 然后，当检查子子树时，我们再次遍历许多相同的后代。 

在最坏的情况下，特别是对于倾斜的树，这会导致`O(n^2)`时间复杂度。 

### 最佳方法

 关键的见解是 BST 有效性可以自下而上确定。 

要使节点成为有效 BST 的根：

 - 它的左子树必须已经是 BST。 
- 它的右子树必须已经是 BST。 
- 左子树中的最大值必须小于当前节点。 
- 右子树中的最小值必须大于当前节点。 

这表明后序遍历，因为我们在处理父级之前需要来自子级的信息。 

对于每个子树，我们计算四条信息：

 - 子树是否是 BST。 
- 子树的大小（如果是 BST）。 
- 子树内的最小值。 
- 子树内的最大值。 

使用此信息，每个父节点可以在恒定时间内确定其整个子树是否形成 BST。 

由于每个节点只处理一次，因此解决方案运行在`O(n)`时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(h) | 重复验证重叠子树 |
 | 最佳 | O(n) | O(h) | 使用子树元数据进行单后序遍历 |

 这里，`h`代表树的高度。 

## 算法演练

 ### 最优自下而上 DFS

 1. 对树进行后序遍历。 

我们首先处理左子树，然后处理右子树，最后处理当前节点。 此顺序是必要的，因为当前节点取决于两个子节点的信息。 
2. 定义每个子树返回的信息。 

对于每个节点，DFS 函数返回：

 - 子树是否是有效的 BST。 
- 子树的大小（如果是 BST）。 
- 子树中的最小值。 
- 子树中的最大值。 

此信息足以让家长验证 BST 条件。 
3. 处理空节点的基本情况。 

空子树被视为有效的 BST。 

我们返回：

 -`is_bst = True`-`size = 0`-`min_value = +infinity`-`max_value = -infinity`这些极值使得比较对于叶节点自然有效。 
4. 递归处理左右孩子。 

每个递归调用都会为我们提供有关子子树的完整信息。 
5. 检查当前节点是否形成BST。 

仅当满足以下条件时，当前子树才是 BST：

 - 左子树是 BST。 
- 右子树是 BST。 
-`left_max < node.val < right_min`这些条件保证了整个子树的 BST 正确性。 
6. 计算当前子树信息。 

如果子树有效：

 - 尺寸变为`left_size + right_size + 1`- 最小值变为`min(left_min, node.val)`- 最大值变为`max(right_max, node.val)`我们还使用新的子树大小更新全局答案。 
7. 处理无效的BST案例。 

如果子树不是 BST：

 - 将其标记为无效。 
- 确切的最小值和最大值不再重要，因为祖先不能使用此子树作为 BST 的一部分。 
8. 继续向上，直到处理完根部。 

遍历期间跟踪的全局最大大小是最终答案。 

### 为什么它有效

 该算法保持了很强的不变量：

 对于每个节点，DFS 函数都会正确报告以该节点为根的子树是否为 BST，以及其大小和值边界。 

因为每个父节点都会从其子节点接收经过充分验证的信息，因此它可以正确确定将它们与当前节点组合是否仍然满足 BST 属性。 由于遍历过程是自下而上地处理节点，因此每个子树只被评估一次，并且所有 BST 条件都会被正确检查。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional, Tuple

class Solution:
    def largestBSTSubtree(self, root: Optional[TreeNode]) -> int:
        largest_size = 0

        def dfs(node: Optional[TreeNode]) -> Tuple[bool, int, int, int]:
            nonlocal largest_size

            if not node:
                return True, 0, float("inf"), float("-inf")

            left_is_bst, left_size, left_min, left_max = dfs(node.left)
            right_is_bst, right_size, right_min, right_max = dfs(node.right)

            if (
                left_is_bst
                and right_is_bst
                and left_max < node.val < right_min
            ):
                current_size = left_size + right_size + 1
                largest_size = max(largest_size, current_size)

                current_min = min(left_min, node.val)
                current_max = max(right_max, node.val)

                return True, current_size, current_min, current_max

            return False, 0, 0, 0

        dfs(root)
        return largest_size
```该实现使用嵌套的 DFS 函数来递归处理子树。 

DFS 函数返回四个值，描述以当前节点为根的子树。 这些值允许父节点确定将两个子节点与当前节点组合是否仍然形成有效的 BST。 

基本情况通过将空节点视为大小为零的有效 BST 来处理空节点。 使用正无穷大和负无穷大作为最小值和最大值可以简化叶节点的比较。 

递归处理完两个子节点后，算法检查 BST 条件：

 - 左子树必须有效。 
- 右子树必须有效。 
- 左子树中的最大值必须小于当前节点。 
- 右子树中的最小值必须大于当前节点。 

如果所有条件成立，则子树有效，我们计算其大小和边界值。 否则，子树被标记为无效。 

变量`largest_size`跟踪树中任何地方发现的最大的 BST。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

import "math"

type Info struct {
	isBST bool
	size  int
	minV  int
	maxV  int
}

func largestBSTSubtree(root *TreeNode) int {
	largest := 0

	var dfs func(node *TreeNode) Info

	dfs = func(node *TreeNode) Info {
		if node == nil {
			return Info{
				isBST: true,
				size:  0,
				minV:  math.MaxInt,
				maxV:  math.MinInt,
			}
		}

		left := dfs(node.Left)
		right := dfs(node.Right)

		if left.isBST &&
			right.isBST &&
			left.maxV < node.Val &&
			node.Val < right.minV {

			currentSize := left.size + right.size + 1

			if currentSize > largest {
				largest = currentSize
			}

			currentMin := min(left.minV, node.Val)
			currentMax := max(right.maxV, node.Val)

			return Info{
				isBST: true,
				size:  currentSize,
				minV:  currentMin,
				maxV:  currentMax,
			}
		}

		return Info{
			isBST: false,
			size:  0,
			minV:  0,
			maxV:  0,
		}
	}

	dfs(root)

	return largest
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}
```Go 实现遵循与 Python 版本相同的逻辑，但使用名为`Info`打包子树元数据。 

Go 没有元组，因此结构存储：

 - BST有效性
 - 子树大小
 - 最小值
 - 最大值

 递归使用`nil`检查而不是 Python 的真实性检查。 

实现使用`math.MaxInt`和`math.MinInt`作为空子树的哨兵值。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点只被处理一次 |
 | 空间| O(h) | 递归调用栈使用树高|

 该算法访问每个节点一次，并在每次访问时执行恒定的工作，从而给出线性时间复杂度。 

辅助空间来自递归深度。 在平衡树中，高度为`O(log n)`。 在最坏的情况下，例如完全倾斜的树，高度变为`O(n)`。

 ## 边缘情况

 ### 空树

 空树是一种特殊情况，因为根本没有节点。 幼稚的实现可能会意外返回`1`或由于空指针访问而失败。 该实现通过 DFS 基本情况自然地处理这个问题，其中空节点返回大小为有效的 BST`0`。 因此，最终答案仍然是`0`。 

### 重复值

 该问题中的 BST 定义需要严格的不等式。 这意味着两侧不允许有相同的值。 一个常见的错误是使用`<=`或者`>=`比较，错误地允许重复。 实现明确检查：```
left_max < node.val < right_min
```这保证了重复项使子树无效。 

### 子树内部的深度违规

 有时，直接子代看起来有效，但更深的后代违反了 BST 排序。 例如：```
    10
   /
  5
   \
   12
```节点`12`违反了 BST 性质，因为它属于`10`，不是左边。 

天真的亲子比较会忽略这个问题。 该算法通过向上传播子树最小值和最大值来避免此错误。 这确保每个节点验证整个子树范围，而不仅仅是直接子节点。 

### 高度倾斜的树

 行为类似于链表的树可以创建最坏情况的递归深度。 该算法仍然正确，因为每个节点都被处理一次。 时间复杂度保持线性，尽管递归深度变为`O(n)`在最坏的情况下。
