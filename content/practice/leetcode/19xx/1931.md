[LeetCode 1931 题](https://leetcode.com/problems/painting-a-grid-with- Three- different-colors/)

 **难度：** 🔴难
 **主题：** 动态规划

 ## 解决方案

 ## 问题理解

 问题是要求我们计算绘制一个物体的方法的数量`m x n`网格使用三种颜色：红色、绿色和蓝色，并具有**任何两个相邻单元格不能具有相同颜色**的约束。 相邻小区包括垂直相邻小区和水平相邻小区。 输入`m`和`n`分别定义网格的行数和列数，输出为有效着色总数取模`10^9 + 7`以避免溢出。 

关键限制是`1 <= m <= 5`和`1 <= n <= 1000`。 小上限为`m`表明逐行计算是可行的，但上界较大`n`表明任何直接迭代所有可能网格的方法都会太慢。 重要的边缘情况包括非常小的网格（例如`1x1`或者`1x2`）和最大尺寸（`5x1000`）。 该问题保证所有输入都是正整数并且网格是完全可绘制的。 

## 方法

 一种强力方法会尝试枚举网格的所有可能的颜色，检查每一种颜色是否满足邻接约束。 对于一个`m x n`网格，有`3^(m*n)`总着色。 该方法保证了正确性，但不可行`m=5, n=1000`因为组合的数量呈指数增长。 

最佳方法使用**带有状态压缩的动态编程**。 自从`m`很小，我们可以将每一行表示为一个序列`m`颜色。 首先，我们生成所有有效的行模式，其中同一行中没有两个相邻单元格具有相同的颜色。 然后，我们使用 DP 来计算这些行图案如何堆叠在一起，强制没有两个垂直相邻的单元具有相同的颜色。 这降低了指数复杂度`3^(m*n)`到`3^m * n`对于 DP 转换，考虑到约束条件，这是很容易处理的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(3^(m*n)) | O(3^(m*n)) | O(3^(m*n)) | O(3^(m*n)) | 枚举所有可能的网格，检查邻接约束 |
 | 最佳| O(n * 3^m * 3^m) | O(3^m) | O(3^m) | 生成有效的行模式并使用 DP 来计算堆叠可能性 |

 ## 算法演练

 1. **生成所有有效的行模式**：每一行`m`细胞可以被涂上`3^m`方式。 过滤这些以仅保留行中没有两个相邻单元格共享相同颜色的模式。 
2. **预先计算行邻接兼容性**：对于每对有效的行模式，检查它们是否可以堆叠，即一行中的所有单元格是否与另一行中的相应单元格不同。 
3. **初始化DP**：使用字典或数组`dp`其中键/索引是有效的行模式，值是使用该模式填充网格直至当前列的方式数。 
4. **逐列迭代**：对于每一列，使用前一列的 DP 和邻接兼容性表更新下一列的 DP。 
5. **对所有最终 DP 值求和**：处理所有列后，最后 DP 字典中的值的总和给出有效着色的总数。 

**为什么有效**：该算法之所以有效，是因为它保留了以下不变式：`dp[pattern]`始终存储当前列的网格着色方式的数量，其中顶行为`pattern`。 通过迭代组合兼容的行，我们可以正确计算所有有效的网格配置，而不会违反邻接约束。 

## Python 解决方案```python
class Solution:
    MOD = 10**9 + 7
    
    def colorTheGrid(self, m: int, n: int) -> int:
        from itertools import product
        
        # Generate all valid row patterns
        colors = [0, 1, 2]  # Represent red, green, blue
        valid_rows = []
        for row in product(colors, repeat=m):
            if all(row[i] != row[i+1] for i in range(m-1)):
                valid_rows.append(row)
        
        # Precompute compatibility between rows
        compatible = {row: [] for row in valid_rows}
        for row1 in valid_rows:
            for row2 in valid_rows:
                if all(row1[i] != row2[i] for i in range(m)):
                    compatible[row1].append(row2)
        
        # Initialize DP
        dp = {row: 1 for row in valid_rows}
        
        # Iterate over columns
        for _ in range(1, n):
            new_dp = {row: 0 for row in valid_rows}
            for row in valid_rows:
                for prev in compatible[row]:
                    new_dp[row] = (new_dp[row] + dp[prev]) % self.MOD
            dp = new_dp
        
        return sum(dp.values()) % self.MOD
```Python 解决方案首先生成所有有效的行模式并预先计算哪些行可以位于彼此之上。 DP字典存储了到达每行配置的方式数量，我们逐列更新它。 模数确保我们有效地处理大量数字。 

## 解决方案```go
package main

func colorTheGrid(m int, n int) int {
    const MOD = 1_000_000_007
    
    // Generate all valid rows using recursion
    var validRows [][]int
    var gen func([]int)
    gen = func(row []int) {
        if len(row) == m {
            validRows = append(validRows, append([]int(nil), row...))
            return
        }
        for c := 0; c < 3; c++ {
            if len(row) == 0 || row[len(row)-1] != c {
                gen(append(row, c))
            }
        }
    }
    gen([]int{})
    
    // Precompute compatibility
    compatible := make(map[int][]int)
    for i, r1 := range validRows {
        for j, r2 := range validRows {
            ok := true
            for k := 0; k < m; k++ {
                if r1[k] == r2[k] {
                    ok = false
                    break
                }
            }
            if ok {
                compatible[i] = append(compatible[i], j)
            }
        }
    }
    
    dp := make([]int, len(validRows))
    for i := range dp {
        dp[i] = 1
    }
    
    for col := 1; col < n; col++ {
        newDp := make([]int, len(validRows))
        for i := range validRows {
            for _, prev := range compatible[i] {
                newDp[i] = (newDp[i] + dp[prev]) % MOD
            }
        }
        dp = newDp
    }
    
    result := 0
    for _, val := range dp {
        result = (result + val) % MOD
    }
    return result
}
```Go 解决方案镜像了 Python 版本，但使用切片和映射而不是字典和元组。 它使用递归来生成有效的行模式和存储兼容性关系的映射。 切片复制确保独立的行存储。 

## 工作示例

 **示例1：`m = 1, n = 1`**

 所有单细胞着色均有效。`dp`开始于`{0:1, 1:1, 2:1}`，并且自从`n=1`，总和是`3`。 

**示例2：`m = 1, n = 2`**

 有效行：`[0],[1],[2]`。 兼容性允许任何行跟随不同的行。 对于第二列，每行后面可以跟另外两行，给出`3*2=6`。 

**示例3：`m = 5, n = 5`**

 该算法生成所有有效的 5 单元格行（共有 66 个），计算兼容性，然后对列迭代 5 次。 DP 准确地计算有效着色的数量，从而得到`580986`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * 3^m * 3^m) | 生成所有有效行`3^m`，检查所有对的兼容性`3^m * 3^m`，然后迭代`n`专栏 |
 | 空间| O(3^m + 3^m * 3^m) | 存储有效行和兼容性映射，以及大小的 DP 数组`3^m`|

 复杂度是可行的，因为`m <= 5`， 制作`3^m = 243`最多。
