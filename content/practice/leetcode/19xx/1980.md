 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、回溯

 ## 解决方案

 ## 问题理解

 问题是要求我们找到长度为的二进制字符串`n`给定列表中不存在`nums`唯一的二进制字符串，其中每个字符串`nums`也有长度`n`。 更简单地说，我们给出`n`由 0 和 1 组成的字符串，我们需要生成列表中尚不存在的另一个相同长度的字符串。 字符串的顺序并不重要，多个有效答案也是可以接受的。 

输入`nums`保证有`n`唯一的二进制字符串，因此正好有`n`长度的字符串`n`已经在集合中了。 所有可能长度的二进制字符串的数量`n`是`2^n`。 自从`n`最多可以为 16，可能的字符串总数最多为 65536，这个值足够小，可以在需要时考虑完全枚举。 然而，这些约束也允许我们使用巧妙的观察而不是暴力枚举来设计最佳解决方案。 

重要的边缘情况包括：`n = 1`（尽可能小的字符串），`n = 16`（性能测试的最大长度），以及情况`nums`包含覆盖极端序列的字符串（例如`"000...0"`或者`"111...1"`）。 该问题保证了输入字符串的唯一性，因此我们不需要处理重复项。 

## 方法

 蛮力方法很简单。 一个人可以生成所有`2^n`可能的二进制字符串长度`n`并根据中的一组字符串检查每个`nums`。 一旦我们发现集合中不存在的字符串，我们就将其返回。 这保证了正确性，因为所有可能的字符串都被考虑在内，但它的效率很低，因为生成了所有`2^n`字符串呈指数增长`n`并且当`n`很大。 

最佳方法利用了**对角化技术**的概念，其灵感来自于康托尔的对角论证。 对于长度字符串的列表`n`，考虑第 i 个字符串的第 i 个字符。 如果我们翻转该字符（0 到 1 或 1 到 0），则生成的字符串不能存在于原始列表中，因为它至少在一个位置与每个字符串不同。 这种方法保证了唯一性并且以线性时间运行`n`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 2^n) | O(n * 2^n) | O(n * 2^n) | O(n * 2^n) | 生成所有可能的字符串并检查成员资格 |
 | 最佳| O(n) | O(1) | O(1) | 使用对角化构造保证唯一的字符串 |

 ## 算法演练

 1. 初始化一个空结果字符串，用于存储新的二进制字符串。 
2. 使用索引迭代字符串列表`i`从 0 到`n-1`。 
3. 对于索引处的每个字符串`i`, 取位置处的字符`i`。 
4、翻转字符：如果是`'0'`, 附加`'1'`到结果； 如果是的话`'1'`, 附加`'0'`。 
5. 对所有人继续此过程`n`人物。 
6. 循环结束后，返回结果字符串。 

**为什么有效**：对角化可确保生成的字符串与所有 i 的第 i 个位置处的第 i 个字符串不同。 因此，它无法匹配原始列表中的任何字符串。 这保证了字符串是唯一的。 

## Python 解决方案```python
from typing import List

class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        n = len(nums)
        result = []
        for i in range(n):
            # Flip the i-th character of the i-th string
            result.append('1' if nums[i][i] == '0' else '0')
        return ''.join(result)
```在这个实现中，我们首先确定长度`n`输入列表的。 然后我们迭代每个字符串，翻转对角字符以构建一个新字符串。 这`join`函数将字符列表转换为最终字符串。 这直接实现了对角化算法。 

## 解决方案```go
func findDifferentBinaryString(nums []string) string {
    n := len(nums)
    result := make([]byte, n)
    for i := 0; i < n; i++ {
        if nums[i][i] == '0' {
            result[i] = '1'
        } else {
            result[i] = '0'
        }
    }
    return string(result)
}
```在 Go 中，我们使用字节切片来构建结果字符串。 对角化方法是相同的，翻转第 i 个字符串的第 i 个字符。 最后，我们在返回之前将字节切片转换为字符串。

## 复杂度分析

 对角化方法是最优的，因为它保证了唯一性，同时避免了生成所有可能字符串的指数成本。

 ## 边缘情况

 **情况 1：n = 1**

 当`n`为1时，字符串中只有一个字符。 翻转它可以确保独特性。 这种情况可能会破坏假设多个字符的简单实现。 

**情况 2：nums 中全零或全一**

 如果`nums`包含`"000"`或者`"111"`，天真的方法可能会意外生成相同的字符串。 对角化保证至少一位被翻转，避免冲突。 

**情况 3：最大 n (n = 16)**

 即使输入最大，该算法也能高效运行，因为它只翻转每个字符串一个字符。 这确保了 O(n) 时间，而不是尝试枚举 2^16 个字符串。 

这种方法可以可靠地处理所有边缘情况。
