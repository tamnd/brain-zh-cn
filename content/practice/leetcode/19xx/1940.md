[LeetCode 1940 题](https://leetcode.com/problems/longest-common-subsequence- Between-sorted-arrays/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们在多个已排序的整数数组中找到**最长公共子序列**（LCS）。 简单来说，我们得到一个数组列表，其中每个数组都按严格递增的顺序排序，并且我们需要识别所有数组中出现的数字序列**以相同的相对顺序**并且尽可能长。 结果也应该作为数组返回。 

输入`arrays`是整数数组的列表。 每个`arrays[i]`严格递增排序，这意味着单个数组中不存在重复项。 预期输出是一个包含最长序列的数组，该序列是中每个数组的子序列`arrays`。 如果不存在公共元素，则输出为空数组。 

主要限制因素有助于指导我们的解决方案：

 - 最多有 100 个数组，每个数组最多有 100 个元素。 
- 每个整数都在范围内`[1, 100]`。 
- 每个数组都是严格递增的。 

这些约束表明输入大小适中并且受小整数限制。 严格递增的属性暗示**我们可以有效地跟踪公共元素，而不必担心单个数组中的重复项**。 

重要的边缘情况包括：

 - 没有公共元素的数组，应该返回一个空列表。 
- 阵列中的一个阵列比其他阵列短得多，可能会限制 LCS 长度。 
- 所有数组都是相同的，应该返回数组本身。 

## 方法

 ### 蛮力

 一种简单的方法会考虑生成第一个数组的**所有可能的子序列**，然后对照所有其他数组检查每个子序列，看看它是否显示为子序列。 虽然原则上是正确的，但由于子序列的数量呈指数增长，因此速度非常慢。 对于长度的数组`n`， 有`2^n`可能的子序列。 对于多个阵列，这很快在计算上变得不可行。 

### 最佳方法

 关键的见解来自于约束：所有数字都在 1 到 100 之间，并且数组严格按递增排序。 这允许我们**计算所有数组中的出现次数**，而不是显式检查每个子序列。 如果我们迭代数组并跟踪所有数组中出现的数字，**按排序顺序的公共元素**会自动形成有效的子序列。 

为了实现这一点，我们可以：

 1. 创建哈希映射或计数器来跟踪包含每个数字的数组数量。 
2. 迭代每个数组并更新计数器，确保每个数组只对每个数字计数一次。 
3. 处理完所有数组后，提取所有数组中出现的数字，保留它们从第一个数组开始的顺序。 

这种方法保证了最长的子序列，因为数组是排序的，所以所有数组中的数字的交集自然保持相对顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * k) | O(2^n * k) | O(n) | 生成第一个数组的所有子序列并检查 k 个数组中的每个子序列 |
 | 最佳| O(k * 米) | O(100) | 使用哈希映射计算公共元素并提取所有数组中出现的数字 |

 这里，`k`是数组的数量并且`m`是任何数组的最大长度。 空间复杂度很小，因为数字的范围是 1 到 100。 

## 算法演练

 1.初始化一个字典`count`存储每个数字出现的数组数量。 
2. 迭代每个数组。 对于每个数组，创建其元素的临时集以避免计算同一数组中的重复项。 
3. 更新`count`对于临时集中的每个数字。 
4.初始化一个空列表`result`存储最长公共子序列。 
5. 迭代第一个数组。 对于每个数字，检查是否`count[number]`等于数组的总数。 如果是这样，请将其附加到`result`。 
6. 返回`result`。 

**为什么有效**：该算法之所以有效，是因为我们只包含每个数组中出现的数字，并且迭代第一个数组可确保保留元素的相对顺序。 由于数组严格递增，因此第一个数组中的顺序反映了正确的子序列顺序。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def longestCommonSubsequence(self, arrays: List[List[int]]) -> List[int]:
        count = defaultdict(int)
        total_arrays = len(arrays)
        
        for arr in arrays:
            seen = set()
            for num in arr:
                if num not in seen:
                    count[num] += 1
                    seen.add(num)
        
        result = []
        for num in arrays[0]:
            if count[num] == total_arrays:
                result.append(num)
        
        return result
```**说明**：

 该代码初始化一个`count`字典来记录每个数字出现的数组数量。对于每个数组，有一个`seen`set 确保同一数组中的重复项不会增加计数。 计数完毕后，我们迭代第一个数组以保持正确的顺序，将所有数组中出现的数字添加到`result`。 

## 解决方案```go
func longestCommonSubsequence(arrays [][]int) []int {
    count := make(map[int]int)
    totalArrays := len(arrays)
    
    for _, arr := range arrays {
        seen := make(map[int]bool)
        for _, num := range arr {
            if !seen[num] {
                count[num]++
                seen[num] = true
            }
        }
    }
    
    result := []int{}
    for _, num := range arrays[0] {
        if count[num] == totalArrays {
            result = append(result, num)
        }
    }
    
    return result
}
```**Go Notes**：我们使用`map[int]int`用于计算出现次数和`map[int]bool`跟踪当前数组中已经看到的数字。 切片`result`按照第一个数组的顺序收集数字，确保子序列顺序正确。
