[LeetCode 1912 题](https://leetcode.com/problems/design-movie-rental-system/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、设计、堆（优先级队列）、有序集

 ## 解决方案

 ## 问题理解

 该问题需要为多个商店设计一个电影租赁系统，其中每个商店最多携带每部电影一份副本。 我们被要求实现一个类，该类可以有效地支持搜索可用电影、租借、归还它们以及报告当前租借的最便宜的电影。 

The input consists of the number of shops`n`和一个清单`entries`它指定哪个商店有哪部电影以及价格是多少。 预期输出取决于操作：

 -`search(movie)`：返回**最便宜的 5 家商店**，并提供可用的副本`movie`，首先按价格排序，然后按商店编号排序。 
-`rent(shop, movie)`：将电影标记为在特定商店租借的。 此操作保证有效（电影可用）。 
-`drop(shop, movie)`：返回之前租借的电影。 这也保证有效。 
-`report()`：返回**最便宜的 5 部租借电影**，按价格排序，然后是商店编号，然后是电影 ID。 

这些约束表明商店的数量可能很大（`3 * 10^5`）并且操作次数最多可达`10^5`。 这排除了对每个操作进行任何简单的 O(n) 搜索。 为了满足时间限制，必须有效使用有序集、哈希图和优先级队列等数据结构。 

重要的边缘情况包括：

 - 多个商店的电影价格相同（需要按商店 ID 排序）
 - 连续租用和丢弃操作影响可用性
 - 少于 5 个结果`search`或者`report`（应返回所有可用条目）
 - 租借的电影可能包含来自不同商店的相同电影 ID 的重复项

 ## 方法

 暴力方法会将所有条目存储在一个简单的列表或哈希映射中，并且对于每个操作，迭代所有条目以查找相关电影。 为了`search`，我们会过滤未租借的电影并对其进行排序； 为了`report`，我们会过滤租借的电影并对它们进行排序。 虽然正确，但由于每个操作中的 O(n log n) 排序和 O(n) 过滤，这太慢了。 

最佳方法利用有序数据结构。 我们可以使用：

 - 将每部电影映射到**排序集**的字典`(price, shop)`对未租用的副本，允许 O(log n) 插入、删除和 top-k 检索。 
- 全球**排序**的租借电影`(price, shop, movie)`高效生成最便宜的 5 部租借电影的报告。 

这允许`search`,`rent`,`drop`， 和`report`每次插入/删除的复杂度为 O(log n)，获取 top-k 元素的复杂度为 O(k)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每次操作 O(n log n) | O(n) | 针对每个查询对所有电影进行过滤和排序 |
 | 最佳| 每次插入/删除 O(log n)，每次查询 O(k) | O(n) | 使用有序集进行高效的 top-k 检索 |

 ## 算法演练

 1. **初始化**：创建一个字典映射每个`movie`到一组已排序的`(price, shop)`代表未租用的副本。 另外，为租借的电影创建一个全局排序集`(price, shop, movie)`。 
2. **搜索（电影）**：查找给定电影的未租借副本的排序集。 从排序集中取出前 5 个元素并返回相应的商店。 
3. **租赁（商店、电影）**：删除`(price, shop)`从电影的未租借集中添加`(price, shop, movie)`到租来的那套。 
4. **Drop(商店、电影)**：删除`(price, shop, movie)`从租用的套件中添加`(price, shop)`回到未租用的电影布景。 
5. **Report()**：从租用集中取出前5个元素并返回一个列表`[shop, movie]`对。 

**为什么有效**：维护的不变量是未租用的集合始终包含可用的副本，而租用的集合始终包含租用的副本。 排序确保我们可以有效地获取最便宜的 top-k 元素`search`和`report`。 

## Python 解决方案```python
from typing import List
from sortedcontainers import SortedList

class MovieRentingSystem:

    def __init__(self, n: int, entries: List[List[int]]):
        self.movie_to_unrented = {}
        self.rented = SortedList()
        self.price_map = {}
        
        for shop, movie, price in entries:
            if movie not in self.movie_to_unrented:
                self.movie_to_unrented[movie] = SortedList()
            self.movie_to_unrented[movie].add((price, shop))
            self.price_map[(shop, movie)] = price

    def search(self, movie: int) -> List[int]:
        if movie not in self.movie_to_unrented:
            return []
        unrented_list = self.movie_to_unrented[movie]
        return [shop for price, shop in unrented_list[:5]]

    def rent(self, shop: int, movie: int) -> None:
        price = self.price_map[(shop, movie)]
        self.movie_to_unrented[movie].remove((price, shop))
        self.rented.add((price, shop, movie))

    def drop(self, shop: int, movie: int) -> None:
        price = self.price_map[(shop, movie)]
        self.rented.remove((price, shop, movie))
        self.movie_to_unrented[movie].add((price, shop))

    def report(self) -> List[List[int]]:
        return [[shop, movie] for price, shop, movie in self.rented[:5]]
```**实施演练**：

 初始化有效地存储未租用和租用的数据。`search`由于排序列表保持顺序，因此在 O(k) 时间内获取前 5 个元素。`rent`和`drop`修改两个集合的时间复杂度为 O(log n)，因为`SortedList`运营。`report`直接从排序列表中检索最便宜的 5 部租借电影。 使用`price_map`确保恒定时间的价格查找。 

## 解决方案```go
package main

import (
    "sort"
)

type Entry struct {
    price int
    shop  int
    movie int
}

type MovieRentingSystem struct {
    movieToUnrented map[int][]Entry
    rented          []Entry
    priceMap        map[[2]int]int
}

func Constructor(n int, entries [][]int) MovieRentingSystem {
    m := make(map[int][]Entry)
    pMap := make(map[[2]int]int)
    for _, e := range entries {
        shop, movie, price := e[0], e[1], e[2]
        m[movie] = append(m[movie], Entry{price, shop, movie})
        pMap[[2]int{shop, movie}] = price
    }
    for _, list := range m {
        sort.Slice(list, func(i, j int) bool {
            if list[i].price != list[j].price {
                return list[i].price < list[j].price
            }
            return list[i].shop < list[j].shop
        })
    }
    return MovieRentingSystem{m, []Entry{}, pMap}
}

func (this *MovieRentingSystem) Search(movie int) []int {
    res := []int{}
    list := this.movieToUnrented[movie]
    for i := 0; i < len(list) && i < 5; i++ {
        res = append(res, list[i].shop)
    }
    return res
}

func removeEntry(entries []Entry, target Entry) []Entry {
    for i, e := range entries {
        if e.shop == target.shop && e.movie == target.movie {
            return append(entries[:i], entries[i+1:]...)
        }
    }
    return entries
}

func insertEntry(entries []Entry, e Entry) []Entry {
    entries = append(entries, e)
    sort.Slice(entries, func(i, j int) bool {
        if entries[i].price != entries[j].price {
            return entries[i].price < entries[j].price
        }
        if entries[i].shop != entries[j].shop {
            return entries[i].shop < entries[j].shop
        }
        return entries[i].movie < entries[j].movie
    })
    return entries
}

func (this *MovieRentingSystem) Rent(shop int, movie int) {
    price := this.priceMap[[2]int{shop, movie}]
    e := Entry{price, shop, movie}
    this.movieToUnrented[movie] = removeEntry(this.movieToUnrented[movie], e)
    this.rented = insertEntry(this.rented, e)
}

func (this *MovieRentingSystem) Drop(shop int, movie int) {
    price := this.priceMap[[2]int{shop, movie}]
    e := Entry{price, shop, movie}
    this.rented = removeEntry(this.rented, e)
    this.movieToUnrented[movie] = insertEntry(this.movieToUnrented[movie], Entry{price, shop, movie})
}

func (this *MovieRentingSystem) Report() [][]int {
    res := [][]int{}
    for i := 0; i < len(this.rented) && i < 5; i++ {
        res = append(res, []int{this.rented[i].shop, this.rented[i].movie})
    }
    return res
}
```**Go 实现说明**：在 Go 中，我们使用切片和排序操作来模拟有序集。`removeEntry`和`insertEntry`处理更新
