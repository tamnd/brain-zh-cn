[LeetCode 1984 题](https://leetcode.com/problems/minimum-difference- Between-highest-and-lowest-of-k-scores/)

 **难度：** 🟢简单
 **主题：** 数组、滑动窗口、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们在精确选择**时找到最高分和最低分之间可能的最小差异`k`来自一系列学生分数的分数**。 输入是一个 **0 索引的整数数组`nums`** 其中每个元素代表学生的分数，并且是一个整数`k`这是要选择的分数数量。 预期输出是一个整数，表示最高分和最低分之间可实现的**最小差异**`k`选定的分数。 

约束表明`nums`最多可以有 1000 个元素，每个分数最多可以达到 100,000。 这排除了尝试检查每种组合的暴力方法`k`由于组合数量呈指数增长，因此得分。 我们也知道`k`至少为 1，因此总会有一个有效的子集。 重要的边缘情况包括`k = 1`（差异始终为 0）以及已排序或包含重复数字的数组。 

这里的关键见解是，问题从根本上讲是如何最大限度地减少病毒的传播`k`数组排序时的连续分数，这使得我们可以在排序后将其转化为**滑动窗口问题**。 

## 方法

 ### 蛮力

 暴力方法将生成所有可能的大小子集`k`从`nums`，计算每个子集的最大值和最小值之间的差值，并返回找到的最小差值。 虽然正确，但该方法效率极低，因为子集的数量是组合的，特别是$C(n, k)$，这对于`n = 1000`。 

### 最佳方法

 最佳方法是利用排序。 一旦数组排序完毕，任意一组`k`连续元素将始终包含该段的最小差异。 通过滑动一个长度的窗口`k`在排序后的数组上并计算窗口的第一个和最后一个元素之间的差异，我们可以有效地找到最小差异。 排序可确保每个窗口的最大和最小元素位于末尾，从而无需为每个组合重复计算最大值和最小值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n 选择 k * k) | O(k) | 生成大小为 k 的所有子集并计算它们的差异 |
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 对数组进行排序并使用滑动窗口找出最小差异 |

 ## 算法演练

 1. **对数组进行排序`nums`** 按升序排列。 排序可确保彼此接近的元素差异最小，这是找到最小可能范围的关键`k`分数。 
2. **初始化一个变量`min_diff`** 为一个大数，例如无穷大。 这将记录遇到的最小差异。 
3. **使用大小的滑动窗口**进行迭代`k`从数组的开头到结尾。 对于从索引开始的每个窗口`i`，计算窗口的最后一个元素和第一个元素之间的差异：`nums[i + k - 1] - nums[i]`。 
4. **更新`min_diff`** 如果当前窗口的差异小于先前记录的最小值。 
5. **返回`min_diff`** 循环结束后。 

**为什么它有效：** 排序确保对于任何长度的窗口`k`，最大差异出现在第一个和最后一个元素之间。 滑动所有可能的窗口可以保证我们检查每个可能的子集`k`连续得分。 因此，找到的最小差异是所有可能子集的全局最小值。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        if k == 1:
            return 0
        
        nums.sort()
        min_diff = float('inf')
        
        for i in range(len(nums) - k + 1):
            diff = nums[i + k - 1] - nums[i]
            min_diff = min(min_diff, diff)
        
        return min_diff
```在此 Python 实现中，我们首先处理边缘情况`k = 1`直接地。 排序确保了之间的最小差异`k`分数总是在连续的子数组中找到。 循环迭代所有可能的长度窗口`k`，计算差异并更新最小值。 使用`float('inf')`确保我们从一个大于任何可能差异的值开始。 

## 解决方案```go
import "sort"

func minimumDifference(nums []int, k int) int {
    if k == 1 {
        return 0
    }
    
    sort.Ints(nums)
    minDiff := int(^uint(0) >> 1) // initialize to max int
    
    for i := 0; i <= len(nums) - k; i++ {
        diff := nums[i+k-1] - nums[i]
        if diff < minDiff {
            minDiff = diff
        }
    }
    
    return minDiff
}
```在 Go 中，我们处理`k = 1`相似地。 我们使用`sort.Ints`对数组进行排序，并且`int(^uint(0) >> 1)`初始化最大整数值。 滑动窗口逻辑与Python相同，迭代每个连续的`k`-长度窗口并更新最小差异。

 ## 边缘情况

 1. **单元素（`k=1`)**：差值始终为 0。我们的实现通过提前返回直接处理此问题。 
2. **所有元素相同**：任何子集也将具有 0 的差异。排序和滑动窗口逻辑仍然可以正常工作，因为差异计算产生 0。 
3. **`k`等于数组长度**：唯一有效的子集是整个数组。 排序确保我们正确计算最大和最小元素之间的差异。 我们的滑动窗口循环也可以自然地处理这种情况`len(nums) - k + 1 = 1`迭代。 

这种方法和实现可以稳健地处理所有可能的输入，同时保持高效。
