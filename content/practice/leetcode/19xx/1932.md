 **难度：** 🔴难
 **主题：** 数组、哈希表、树、深度优先搜索、二叉搜索树、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们采用多个非常小的二叉搜索树（BST），每个树最多有三个节点，并尝试将它们合并为一个有效的 BST。 每棵树由其在数组中的根节点表示`trees`。 唯一允许的操作是，如果叶子的值与第二棵树的根匹配，则将一棵树附加到另一棵树的叶子上。 合并后，我们从列表中删除附加的树。 

输入是一个数组`n`根节点，其中`1 <= n <= 5 * 10^4`，每棵树有 1 到 3 个节点。 没有两个根值是相同的。 如果可能的话，输出是完全合并的 BST 的根，或者`null`如果无法形成有效的 BST。 

重要的一点包括，树中的每个节点可能只有子节点，但没有孙子节点，因此所有树都非常小。 叶子被定义为没有子节点的节点。 BST 性质要求所有左后代严格小于该节点，所有右后代严格大于该节点。 

要考虑的边缘情况包括由于没有叶子与另一个根匹配而无法合并的树、合并但违反 BST 属性的树以及可能简单地成为另一棵树的叶子的单节点树。 

## 方法

 ### 蛮力

 暴力方法将尝试所有可能的合并序列。 对于每棵树中的每个叶子，我们将检查它是否与另一棵树的根匹配，并递归地执行合并，直到所有树都被合并或没有有效操作剩余。 虽然这保证了正确性，但在计算上是不可行的，因为合并序列的数量随着树的数量呈阶乘增长。 这对于`n`最多 50,000 个。 

### 最佳方法

 最佳解决方案的关键见解是使用**哈希图**来快速查找可以根据叶子值合并哪些树。 我们不是尝试所有序列，而是跟踪哪些树是叶子，哪些是根。 然后，我们尝试合并根是另一棵树的叶子的任何树。 合并后，我们在 DFS 遍历期间使用 **范围检查** 确保生成的树仍然满足 BST 属性。 

通过预先计算根到树的映射以及叶到父关系，我们可以在相对于节点总数的线性时间内合并树。 我们还检查是否存在确切的**一个候选根**，它不是任何其他树中的叶子； 如果存在有效的 BST，这必定是最终的根。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 尝试所有合并序列； 对于大 n | 不可行
 | 最佳| O(n) | O(n) | 使用哈希图来跟踪根和叶； 在线性时间内合并 |

 ## 算法演练

 1. **收集根和叶信息**：迭代所有树。 将每个根值映射到其树，并跟踪所有叶值及其父树。 计算每片叶子包含多少棵树。 
2. **识别候选最终根**：只有不作为任何叶子出现的根值才能成为最终根。 如果不存在这样的候选人，则返回`null`。 
3. **递归合并**：从候选根开始，递归地尝试合并根与当前树的叶子匹配的任何子树。 对于每次合并，从根映射中删除合并的树。 
4. **BST验证**：合并时，为每个节点维护一个有效的值范围。 使用 DFS 检查所有节点是否遵循 BST 属性。 如有违规，请退回`null`。 
5. **最终检查**：合并后，确保所有树都已被消耗。 如果有任何树仍未合并，则返回`null`。 否则，返回完全合并的根。 

**为什么有效**：每次合并仅在叶子与根匹配时发生，确保我们永远不会丢失树节点。 BST 验证保证合并树是有效的。 通过选择任何树中不是叶子的唯一根，我们确保出现一棵最终树。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import List, Optional

class Solution:
    def canMerge(self, trees: List[TreeNode]) -> Optional[TreeNode]:
        if not trees:
            return None

        root_map = {tree.val: tree for tree in trees}
        leaves = set()
        count_leaves = {}

        # Collect all leaves and count occurrences
        for tree in trees:
            for child in (tree.left, tree.right):
                if child:
                    leaves.add(child.val)
                    count_leaves[child.val] = count_leaves.get(child.val, 0) + 1

        # Candidate root is a root that is not a leaf
        candidate_roots = [val for val in root_map if val not in leaves]
        if len(candidate_roots) != 1:
            return None
        root_val = candidate_roots[0]
        root = root_map[root_val]

        def merge(node: TreeNode, lower: int, upper: int) -> bool:
            if not node:
                return True
            if not (lower < node.val < upper):
                return False
            if node.val in root_map and node != root:
                sub = root_map.pop(node.val)
                node.left = sub.left
                node.right = sub.right
            return merge(node.left, lower, node.val) and merge(node.right, node.val, upper)

        if not merge(root, float('-inf'), float('inf')):
            return None
        return root if len(root_map) == 1 else None
```**说明**：我们构建哈希映射以通过根值快速访问树并计算叶子的出现次数。 我们选择不属于任何人的叶子的根。 递归`merge`当叶子与根匹配时，函数会附加子树，并使用范围检查验证 BST 属性。 最后，我们确保所有树都已合并。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func canMerge(trees []*TreeNode) *TreeNode {
    rootMap := make(map[int]*TreeNode)
    leaves := make(map[int]int)

    for _, tree := range trees {
        rootMap[tree.Val] = tree
        if tree.Left != nil {
            leaves[tree.Left.Val]++
        }
        if tree.Right != nil {
            leaves[tree.Right.Val]++
        }
    }

    var candidateRoot *TreeNode
    for val, tree := range rootMap {
        if _, exists := leaves[val]; !exists {
            if candidateRoot != nil {
                return nil
            }
            candidateRoot = tree
        }
    }

    if candidateRoot == nil {
        return nil
    }

    var merge func(node *TreeNode, low, high int) bool
    merge = func(node *TreeNode, low, high int) bool {
        if node == nil {
            return true
        }
        if node.Val <= low || node.Val >= high {
            return false
        }
        if sub, exists := rootMap[node.Val]; exists && node != candidateRoot {
            node.Left = sub.Left
            node.Right = sub.Right
            delete(rootMap, node.Val)
        }
        return merge(node.Left, low, node.Val) && merge(node.Right, node.Val, high)
    }

    if !merge(candidateRoot, -1, 50001) {
        return nil
    }

    if len(rootMap) != 1 {
        return nil
    }
    return candidateRoot
}
```**说明**：Go 需要显式的 nil 检查并使用映射而不是 Python 字典。 合并逻辑镜像 Python，确保 BST 的范围验证，并仅当叶子与根匹配时才合并子树。

 | 测量 | 复杂性 | 说明|
