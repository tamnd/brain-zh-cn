 ## 问题理解

 该问题要求我们计算二维空间中一组点的**最小外接圆**，其中每个点代表一棵树。 我们得到了一个树木列表作为坐标`trees[i] = [xi, yi]`。 我们的目标是找到一个圆（由圆心定义）`(x, y)`和半径`r`）使得**所有树都位于圆的内部或之上**，并且圆的半径是**最小**。 结果应返回为`[x, y, r]`，并在其中回答`1e-5`的正确答案是可以接受的。 

约束表明树的数量`n`最大可达 3000 并且坐标在该范围内`[0, 3000]`。 这意味着任何具有**超二次时间复杂度**的解决方案（例如`O(n^3)`）可能太慢，所以我们应该寻求一种更有效的方法。 

边缘情况包括：

 - 只有一棵树：圆心是树本身，半径`0`。 
- 两棵树：圆由连接它们的线段定义，半径为距离的一半。 
- 直线上的树木：圆的中心是连接两棵最远树木的线段的中点。 

理解这些有助于避免天真的错误，例如假设总是由三个点定义圆。 

## 方法

 **暴力方法**将涉及检查由一个、两个或三个点定义的所有可能的圆，并验证所有其他点是否位于内部。 对于每个组合：

 - 对于一点，半径为零。 
- 对于两点，圆是以中点为圆心，距离的一半为半径。 
- 对于三个点，计算穿过所有三个点的圆。 

这种方法在最坏的情况下是**O(n^4)**，这对于`n = 3000`。 

**最佳方法**使用 **Welzl 算法**，这是一种随机算法，可以有效地找到 **最小外接圆**。 它递归地选取点并维护一组边界点（`R`) 定义圆。 最多三个点可以定义最小圆的边界。 Welzl 的算法预期时间复杂度为 **O(n)**，并且在实践中效果良好。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 检查 1-3 个点的所有组合来定义圆 |
 | 最佳（Welzl）| O(n) 预期 | O(n) | 随机递归来维护边界点，对于大 n | 非常有效

 ## 算法演练

 1. **随机打乱点**：随机顺序确保 Welzl 算法的预期线性时间。 
2. **定义递归函数**`minCircle(points, R)`：

 -`points`是剩下的要考虑的点。 
-`R`是边界点的集合（最多 3 个）。 
3. **基本案例**：

 - 如果`points`为空或`R`包含 3 个点，返回通过 中的点的最小圆`R`。 
4. **选择一个点`p`从`points`**：

 - 递归计算最小圆，无需`p`。 
- 如果`p`在这个圆的内部，它已经被包含在内，返回这个圆。 
- 否则，`p`必须在边界上； 将其添加到`R`并递归。 
5. **辅助函数**：

 - 使用几何公式从 1、2 或 3 个点计算圆。 
- 使用距离的平方检查点是否位于圆内。 
6. 返回找到的最小圆。 

**为什么有效**：该算法确保每个点要么位于圆内，要么位于边界上。 通过保持最多三个边界点，我们保证了最小性，因为三个点唯一地定义了一个圆。 

## Python 解决方案```python
from typing import List
import random
import math

class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[float]:
        def dist(a, b):
            return math.hypot(a[0]-b[0], a[1]-b[1])

        def is_inside(circle, p):
            c, r = circle
            return dist(c, p) <= r + 1e-10

        def circle_from(points):
            if not points:
                return ((0,0), 0)
            if len(points) == 1:
                return (points[0], 0)
            if len(points) == 2:
                a, b = points
                center = ((a[0]+b[0])/2, (a[1]+b[1])/2)
                radius = dist(a,b)/2
                return (center, radius)
            # Three points
            A, B, C = points
            # Circumcircle formula
            D = 2*(A[0]*(B[1]-C[1]) + B[0]*(C[1]-A[1]) + C[0]*(A[1]-B[1]))
            if D == 0:
                # Collinear, return max distance circle
                max_dist = 0
                center = (0,0)
                for i in range(3):
                    for j in range(i+1,3):
                        d = dist(points[i], points[j])/2
                        if d > max_dist:
                            max_dist = d
                            center = ((points[i][0]+points[j][0])/2, (points[i][1]+points[j][1])/2)
                return (center, max_dist)
            Ux = ((A[0]**2 + A[1]**2)*(B[1]-C[1]) + (B[0]**2 + B[1]**2)*(C[1]-A[1]) + (C[0]**2 + C[1]**2)*(A[1]-B[1])) / D
            Uy = ((A[0]**2 + A[1]**2)*(C[0]-B[0]) + (B[0]**2 + B[1]**2)*(A[0]-C[0]) + (C[0]**2 + C[1]**2)*(B[0]-A[0])) / D
            center = (Ux, Uy)
            radius = dist(center, A)
            return (center, radius)

        def welzl(P, R):
            if not P or len(R) == 3:
                return circle_from(R)
            p = P.pop()
            circle = welzl(P, R)
            if is_inside(circle, p):
                P.append(p)
                return circle
            R.append(p)
            c = welzl(P, R)
            R.pop()
            P.append(p)
            return c

        points = trees[:]
        random.shuffle(points)
        center, radius = welzl(points, [])
        return [center[0], center[1], radius]
```**实现说明**：

 我们定义辅助函数来计算距离、检查包含性并计算 1-3 个点的圆。 这`welzl`函数实现随机递归，维护点的边界`R`。 洗牌可确保预期的线性时间。 该函数返回包围所有点的最小圆。
