[LeetCode 1936 题](https://leetcode.com/problems/add-minimum-number-of-rungs/)

 **难度：** 🟡 中等
 **主题：** 数组、贪心

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个由严格递增数组表示的梯子，称为`rungs`。 数组中的每个值代表地板上方梯级的高度。 你开始站在高处的地板上`0`，您的目标是到达最后一级。 

限制是，只有当当前位置与下一个梯级之间的垂直距离最多为`dist`。 如果间隙大于`dist`，则梯子当前不可攀爬。 为了解决这个问题，您可以在任何尚未占用的正整数高度处插入额外的梯级。 

任务是计算所需额外梯级的最小数量，以便从一个梯级到下一个梯级的每次爬升不超过`dist`。 

输入包括：

 -`rungs`，一个严格递增的整数数组
 -`dist`, 允许的最大爬升距离

 输出是一个整数，表示所需新梯级的最小数量。 

约束条件很重要：

 -`rungs.length`可以大到`10^5`- 高度可以大到`10^9`这些限制立即告诉我们，任何二次或大量模拟的解决方案都会太慢。 我们需要一种能够一次性有效处理梯子的算法。 

该问题还保证`rungs`严格递增，这简化了处理，因为我们永远不需要处理重复或排序。 

一些边缘情况很重要：

 - 第一个梯级可能已经可以从地板到达
 - 第一个梯级可能需要插入多个梯级
 - 大间隙可能需要插入许多梯级
 -`dist`或许`1`，迫使每个高度差恰好为一
 - 梯子可能已经有效并且不需要插入

 在计算间隙内需要多少个梯级时，幼稚的实现很容易犯差一的错误。 

## 方法

 ### 蛮力方法

 一种直接的方法是模拟一步一步爬梯子。 

对于当前位置和下一个梯级之间的每个间隙：

 - 如果差距最多为`dist`, 直接移动到下一个梯级
 - 否则，重复插入新的梯级`dist`比当前位置高的单位，直到可以到达下一个原始梯级

 这种方法是正确的，因为每个插入的梯级都可以最大化爬升距离，同时保持梯子有效。 然而，它可能会针对较大的间隙执行多次重复操作。 

例如，如果间隙是`1,000,000,000`和`dist = 1`，我们将模拟近十亿次插入。 这太慢了。 

### 最优贪心法

 关键的观察是我们不需要显式模拟每个插入的梯级。 

假设两个可到达位置之间的差距为：```
gap = next_rung - current_position
```如果`gap <= dist`，不需要新的梯级。 

否则，我们必须将间隙分成更小的段，其长度最多为`dist`。 

对于尺寸的间隙`gap`，插入的最小梯级数为：```
(gap - 1) // dist
```为什么这个公式有效？ 

如果间隙可以被整除`dist`，我们需要比商少一个插入的梯级，因为最终的跳转直接落在目标梯级上。 

示例：

 -`gap = 6`,`dist = 2`- 我们需要跳跃：`2, 2, 2`- 插入梯级：`2`- 公式：`(6 - 1) // 2 = 2`-`gap = 5`,`dist = 2`- 我们需要跳跃：`2, 2, 1`- 插入梯级：`2`- 公式：`(5 - 1) // 2 = 2`这让我们能够在恒定的时间内处理每个间隙。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O（插入的总梯级）| O(1) | O(1) | 单独模拟每个插入的梯级 |
 | 最佳| O(n) | O(1) | O(1) | 以数学方式计算所需的插入 |

 ## 算法演练

 1. 初始化一个名为`previous_height`到`0`因为我们是从地板上开始的。 
2. 初始化一个名为`added_rungs`到`0`。 这将跟踪插入的梯级总数。 
3. 迭代每个梯级高度`rungs`大批。 
4. 对于每个梯级，计算当前梯级与上一个可到达位置之间的间隙：```
gap = rung - previous_height
```5. 如果`gap <= dist`，当前梯级可直接到达。 不需要额外的工作。 
6. 如果`gap > dist`，计算需要多少额外的梯级：```
needed = (gap - 1) // dist
```该公式给出了确保每次跳跃最多所需的插入梯级的最小数量`dist`。 
7. 添加`needed`到`added_rungs`。 
8. 更新`previous_height`到当前的梯级高度，因为我们现在可以站在这个梯级上。 
9. 继续，直到处理完所有梯级。 
10. 返回`added_rungs`。 

### 为什么它有效

 贪婪策略之所以有效，是因为每个间隙都是独立的。 为了最小化插入的梯级，我们总是希望每次跳跃尽可能大，同时保持在`dist`。 

对于尺寸的间隙`gap`，将其分成最大允许长度的段可以最大限度地减少插入梯级的数量。 公式`(gap - 1) // dist`准确计算需要多少个中间点。 

由于我们以最佳且独立的方式处理每个间隙，因此插入的梯级总数全局最小。 

## Python 解决方案```python
from typing import List

class Solution:
    def addRungs(self, rungs: List[int], dist: int) -> int:
        added_rungs = 0
        previous_height = 0

        for rung in rungs:
            gap = rung - previous_height

            if gap > dist:
                added_rungs += (gap - 1) // dist

            previous_height = rung

        return added_rungs
```实现直接遵循算法。 

变量`previous_height`跟踪最后可到达的位置。 最初，这是高度的地板`0`。 

对于每个梯级，我们计算当前梯级和前一个位置之间的间隙。 如果间隙超过`dist`，我们使用整数除法计算需要多少个附加梯级。 

表达式`(gap - 1) // dist`是解决方案的关键部分。 它避免了差一错误，并正确处理间隙可以被整除的情况`dist`。 

该算法一次性处理数组，并且仅使用恒定的额外内存。 

## 解决方案```go
func addRungs(rungs []int, dist int) int {
    addedRungs := 0
    previousHeight := 0

    for _, rung := range rungs {
        gap := rung - previousHeight

        if gap > dist {
            addedRungs += (gap - 1) / dist
        }

        previousHeight = rung
    }

    return addedRungs
}
```Go 实现与 Python 版本几乎相同。 

Go 整数除法会自动截断为零，这正是我们想要的公式`(gap - 1) / dist`。 

对于空切片不需要特殊处理，因为约束保证至少有一个梯级。 

最大可能的答案安全地适合 Go 的范围`int`标准 LeetCode 环境下的类型。

 ## 边缘情况

 当第一个梯级本身无法从地板上到达时，就会出现一个重要的边缘情况。 由于攀登是从高处开始的`0`，第一个间隙可能已经违反了`dist`限制。 粗心的实现可能只会比较相邻的梯级，而完全忘记楼层。 该解决方案通过初始化避免了该问题`previous_height`到`0`。 

另一个重要的边缘情况是当间隙可以被整除时`dist`。 例如，如果间隙是`6`和`dist`是`2`，我们只需要插入两个梯级，而不是三个。 不正确的公式如`gap // dist`会多算的。 使用`(gap - 1) // dist`正确处理精确整除的情况。 

大间隙是错误的另一个常见来源。 约束条件高达`10^9`，显式模拟插入的梯级将非常慢。 该实现在恒定时间内以数学方式计算所需的插入，使其能够有效地处理巨大的间隙。 

当根本不需要插入时，就会出现最终的边缘情况。 每个间隙可能已经满足距离约束。 该算法自然会处理这个问题，因为它只会在以下情况下添加到答案中：`gap > dist`。
