[LeetCode 1970 题](https://leetcode.com/problems/last-day-where-you-can-still-cross/)

 **难度：** 🔴难
 **主题：** 数组、二分搜索、深度优先搜索、广度优先搜索、并查找、矩阵

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到**最后一天**我们可以从顶行穿过网格到底行，只在陆地上行走。 网格最初都是陆地（`0`），每天，特定的细胞都会被水淹没（`1`）根据`cells`大批。 每个条目`cells[i] = [ri, ci]`告诉我们那天`i + 1`（从 1 开始），行中的单元格`ri`和列`ci`变成水。 

输入包括`row`和`col`定义网格大小，以及`cells`随着时间的推移，该列表将淹没每个单元格。 输出是最后一天（从 1 开始），仍然可以仅使用陆地单元并沿四个方向（上、下、左、右）移动从**任何顶行单元**到**任何底行单元**。 

约束表明矩阵总共最多可以有 2 * 10^4 个单元格**，并且所有`cells`价值观是独一无二的。 这意味着任何通过完整遍历线性检查每天的幼稚方法都是低效的。 该问题保证每个单元格都被淹没一次，因此我们不需要处理重复的淹没事件。 

重要的边缘情况包括非常窄的网格（如 2xN）、首先在单列或行中发生泛洪的网格，或者最后一个从上到下的路径在序列后期被阻塞的情况。 

## 方法

 ### 蛮力

 暴力方法将日复一日地模拟洪水。 每天，我们将相应的单元格标记为水，然后从顶行开始搜索，看看是否存在到达底行的路径。 该搜索可以是 BFS 或 DFS。 我们将继续下去，直到没有路径存在为止，并在有路径可能的最后一天返回。 

虽然正确，但这种方法太慢，因为在大小的网格上执行 BFS/DFS`row * col`可能每天（最多`row * col`天）将导致 **O((row * col)^2)** 时间复杂度，这对于大型网格来说是不可行的。 

### 最佳方法

 关键的观察结果是，该问题是**单调的**：一旦某天某条路径被阻塞，随后的所有日子也将被阻塞。 这允许我们在天数上使用**二分搜索**，结合 BFS 或 DFS 来检查给定日期的连接性。 

我们可以定义一个辅助函数`canCross(day)`在淹没当天的所有单元格后构建网格，然后检查是否存在从上到下的路径。 在日期范围 [1, len(cells)] 上进行二分搜索使我们能够有效地找到最后一天。 

Union-Find 是用于连接检查的 BFS 的另一种替代方案，但对于此问题，BFS/DFS 更易于实现和理解。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((行 * 列)^2) | O(行 * 列) | 洪水一天天，BFS/DFS检查路径|
 | 二分查找+BFS | O(行 * 列 * log(行 * 列)) | O(行 * 列) | 使用 BFS 进行数天的二分搜索来检查路径 |

 ## 算法演练

 1. **二分查找设置**：初始化`left = 1`和`right = row * col`。 我们将寻找可以穿越的最后一天。 
2. **洪水网格功能**：对于给定的一天`d`，创建一个网格，其中第一个`d`细胞来自`cells`是水，其余的是土地。 
3. **路径检查功能**：从顶行的所有陆地单元开始使用BFS或DFS。 仅遍历陆地单元。 如果到达底行中的任何单元格，则返回 True。 
4. **二分查找迭代**：虽然`left <= right`, 计算`mid = (left + right) // 2`。 使用`canCross(mid)`检查当天是否可以穿越。 
5. **更新搜索范围**：如果`canCross(mid)`为真，移动`left`到`mid + 1`（我们可以稍后尝试）。 如果为 False，则移动`right`到`mid - 1`（不可能穿越，请尝试早点）。 
6. **返回结果**：二分查找完成后，`right`将是可以穿越的最后一天。 

**为什么有效**：不变的是，所有日子<=最后可能的日子都可以穿越，而>最后一天的日子不可能穿越。 二分查找可以有效地找到转变点。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def latestDayToCross(self, row: int, col: int, cells: List[List[int]]) -> int:
        def canCross(day: int) -> bool:
            grid = [[0] * col for _ in range(row)]
            for i in range(day):
                r, c = cells[i]
                grid[r-1][c-1] = 1
            
            queue = deque()
            for c in range(col):
                if grid[0][c] == 0:
                    queue.append((0, c))
                    grid[0][c] = 1  # mark visited

            directions = [(0,1),(1,0),(0,-1),(-1,0)]
            while queue:
                r, c = queue.popleft()
                if r == row - 1:
                    return True
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < row and 0 <= nc < col and grid[nr][nc] == 0:
                        grid[nr][nc] = 1
                        queue.append((nr, nc))
            return False

        left, right = 1, row * col
        last_day = 0
        while left <= right:
            mid = (left + right) // 2
            if canCross(mid):
                last_day = mid
                left = mid + 1
            else:
                right = mid - 1
        return last_day
```**解释**：我们首先定义`canCross(day)`模拟之后的网格`day`从顶行开始进行泛洪并执行 BFS。 在 BFS 期间，访问过的陆地单元被标记为水以避免再次访问。 然后，二分搜索可以有效地找到路径存在的最后一天。 

## 解决方案```go
package main

func latestDayToCross(row int, col int, cells [][]int) int {
    canCross := func(day int) bool {
        grid := make([][]int, row)
        for i := range grid {
            grid[i] = make([]int, col)
        }
        for i := 0; i < day; i++ {
            r, c := cells[i][0]-1, cells[i][1]-1
            grid[r][c] = 1
        }

        type point struct{ r, c int }
        queue := []point{}
        for c := 0; c < col; c++ {
            if grid[0][c] == 0 {
                queue = append(queue, point{0, c})
                grid[0][c] = 1
            }
        }

        directions := []point{{0,1},{1,0},{0,-1},{-1,0}}
        for len(queue) > 0 {
            p := queue[0]
            queue = queue[1:]
            if p.r == row-1 {
                return true
            }
            for _, d := range directions {
                nr, nc := p.r + d.r, p.c + d.c
                if nr >= 0 && nr < row && nc >= 0 && nc < col && grid[nr][nc] == 0 {
                    grid[nr][nc] = 1
                    queue = append(queue, point{nr, nc})
                }
            }
        }
        return false
    }

    left, right := 1, row * col
    lastDay := 0
    for left <= right {
        mid := (left + right) / 2
        if canCross(mid) {
            lastDay = mid
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    return lastDay
}
```**Go 特定说明**：我们使用切片来表示网格，并使用基于切片的队列进行 BFS。 这`point`struct 帮助管理坐标。 该逻辑反映了 Python 实现，为网格仔细处理基于 0 的索引。
