[LeetCode 1979 题](https://leetcode.com/problems/find-greatest-common-divisor-of-array/)

 **难度：** 🟢简单
 **主题：** 数组、数学、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们计算从输入数组派生的两个特定值的最大公约数 (GCD)`nums`：数组中最小的元素和数组中最大的元素。 

换句话说，我们不是计算所有元素的 GCD，也不是寻找数组中的成对关系。 我们首先将数组简化为两个关键代表：最小值和最大值，然后计算这两个整数的 GCD。 

输入是一个整数数组`nums`长度在 2 到 1000 之间，每个元素在 1 到 1000 之间。输出是表示 GCD 的单个整数`min(nums)`和`max(nums)`。 

这些约束很小，这表明 O(n) 扫描足以提取最小值和最大值。 数字本身也很小（以 1000 为界），这保证了任何标准 GCD 计算都是高效的。 

边缘情况包括所有元素都相同的数组、最小值和最大值互质的数组以及仅包含两个元素的数组。 一个特别重要的情况是当`min(nums) == max(nums)`，在这种情况下，答案就是该数字本身，因为`gcd(x, x) = x`。 

## 方法

 暴力方法将计算最小值和最大值，然后通过检查从两个数字中较小的一个到 1 的所有可能除数来确定它们的 GCD。对于每个候选除数，我们检查它是否能整除这两个数字。 遇到的第一个有效除数就是答案。 虽然正确，但与使用欧几里得算法相比效率较低。 

关键的见解是该问题将整个数组减少为两个数字。 一旦我们有了最小值和最大值，计算它们的 GCD 就是一个经典的数论问题，最好使用欧几里得算法来解决，该算法重复应用模归约，直到达到零。 

这将问题从可能检查许多除数减少到对数时间算术过程。

 | ---| ---| ---| ---|

 ## 算法演练

 1.初始化两个变量`min_val`和`max_val`。 最初使用数组的第一个元素设置两者。 这确保了我们有一个有效的起始比较点。 
2. 迭代数组一次。 对于每个数字，更新`min_val`如果当前数字较小，则更新`max_val`如果当前数字更大。 此步骤确保我们在 O(n) 时间内提取数组所需的两个代表。 
3. 扫描完成后，我们现在有了数组中的最小值和最大值。 这些是最终计算所需的唯一值。 
4. 计算 GCD`min_val`和`max_val`使用欧几里得算法。 欧几里得算法的工作原理是重复替换`(a, b)`和`(b, a % b)`直到`b`变为零。 
5. 什么时候`b`变为零，`a`得到最大公约数，这就是最终的结果。 

### 为什么它有效

 正确性来自于问题本身的定义：答案仅取决于数组中的最小和最大元素。 欧几里德算法保证重复模约简保持 GCD 不变量，这意味着`gcd(a, b) = gcd(b, a % b)`直至终止。 

## Python 解决方案```python
from typing import List

class Solution:
    def findGCD(self, nums: List[int]) -> int:
        min_val = float('inf')
        max_val = float('-inf')
        
        for num in nums:
            if num < min_val:
                min_val = num
            if num > max_val:
                max_val = num
        
        def gcd(a: int, b: int) -> int:
            while b != 0:
                a, b = b, a % b
            return a
        
        return gcd(min_val, max_val)
```该实现首先扫描数组一次以计算最小值和最大值。 然后它定义了一个实现欧几里得算法的内部辅助函数。 最后，它返回两个计算极值的 GCD。 

## 解决方案```go
func findGCD(nums []int) int {
    minVal := nums[0]
    maxVal := nums[0]
    
    for _, num := range nums {
        if num < minVal {
            minVal = num
        }
        if num > maxVal {
            maxVal = num
        }
    }
    
    gcd := func(a, b int) int {
        for b != 0 {
            a, b = b, a%b
        }
        return a
    }
    
    return gcd(minVal, maxVal)
}
```在 Go 中，为了简单起见，我们对 gcd 函数使用闭包。 切片迭代是使用完成的`range`，整数运算的行为与 Python 中相同，因为约束很小并且避免了溢出问题。 

## 工作示例

 ### 示例 1：nums = [2,5,6,9,10]

 第一遍寻找极值：

 | 步骤| 编号 | 最小值 | 最大值 |

 | 初始化| - | 2 | 2 |
 | 1 | 2 | 2 | 2 |
 | 2 | 5 | 2 | 5 |
 | 3 | 6 | 2 | 6 |
 | 4 | 9 | 2 | 9 |
 | 5 | 10 | 10 2 | 10 | 10

 现在计算 gcd(2, 10)：

 - (2, 10) → (10, 2)
 - (10, 2) → (2, 0)
 - 结果 = 2

 ### 示例 2：nums = [7,5,6,8,3]

 最小/最大提取：

 | 2 | 5 | 5 | 7 |

 计算 gcd(3, 8)：

 - (3, 8) → (8, 3)
 - (8, 3) → (3, 2)
 - (3, 2) → (2, 1)
 - (2, 1) → (1, 0)
 - 结果 = 1

 最小/最大提取：

 由于值相等，因此直接计算 gcd(3, 3) = 3。

 ## 边缘情况

 一种重要的边缘情况是数组中的所有元素都相同。 在这种情况下，最小值和最大值都是相同的值，并且 GCD 应该就是该值。 该实现自然地处理了这个问题，因为欧几里德算法返回`a`什么时候`a == b`。 

另一个边缘情况是最小值为 1 时。由于 1 整除每个整数，因此 1 和任何数字的 GCD 始终为 1。这确保算法在这种情况下快速收敛，无需任何特殊处理。 

当最小值和最大值是互质值（例如 3 和 8）时，会出现第三种边缘情况。在这种情况下，欧几里得算法将减少该对直到达到 1，从而正确识别不存在更大的公约数。
