[LeetCode 1952 题](https://leetcode.com/problems/ Three-divisors/)

 **难度：** 🟢简单
 **主题：** 数学、枚举、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的整数是否`n`有**正好三个正因数**。 换句话说，我们要检查是否正好存在三个不同的整数`d`这样`n % d == 0`和`d > 0`。 例如，数字4有约数1、2和4，满足条件，而2只有约数1和2，则不满足条件。 

输入是单个整数`n`受限于`1 <= n <= 10^4`，所以相对较小。 输出是一个布尔值：`true`如果`n`恰好有三个约数，`false`否则。 

关键见解包括认识到恰好具有三个正因数的数字必须具有以下形式`p^2`， 在哪里`p`是一个素数。 这是因为除数`p^2`是`1`,`p`， 和`p^2`。 如果`n`不是完全平方或者它的平方根不是素数，那么`n`不能正好有三个约数。 

重要的边缘情况包括`n = 1`，只有一个除数，以及合数的完美平方，例如`n = 9`（`3^2`） 或者`n = 16`（`4^2`）。 只有素数的完全平方才能满足条件。 

## 方法

 暴力方法会枚举从 1 到`n`并计算有多少次除法`n`均匀。 如果计数正好达到 3，我们返回 true； 否则，我们返回 false。 虽然这种方法简单且正确，但对于较大的值来说效率较低。`n`因为它检查每个整数的整除性`n`。 

最佳解决方案的关键在于，任何恰好具有三个约数的数字都必须是素数的平方。 因此，解决方案减少为两个检查：首先，是否`n`是一个完全平方数，第二，它的平方根是否是质数。 这要快得多，因为我们只需要计算整数平方根并执行素性检查。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 检查从 1 到 n 的每个整数的整除性并计算除数 |
 | 最佳 | O(√n) | O(√n) | O(1) | O(1) | 检查 n 是否为完全平方并验证平方根是否为质数 |

 ## 算法演练

 1. 计算整数平方根`n`使用内置平方根函数或整数求幂。 这给了我们一个候选人`sqrt_n`这样`sqrt_n * sqrt_n == n`如果`n`是一个完美的正方形。 
2.如果`n`不是一个完美的平方（即`sqrt_n * sqrt_n != n`）， 返回`false`立即，因为恰好具有三个约数的数字必定是完全平方数。 
3.如果`n`是一个完全平方数，我们现在需要检查是否`sqrt_n`是素数。 如果一个数大于 1 并且只能被 1 和它本身整除，那么这个数就是素数。 
4. 要有效地检查素数，请从 2 迭代到 的平方根`sqrt_n`。 如果任意数能整除`sqrt_n`，它不是素数，我们返回`false`。 
5. 如果循环中没有找到约数，`sqrt_n`是素数，因此`n`正好有三个约数。 返回`true`。 

为什么它有效：关键的不变量是唯一具有三个正因数的数字是素数的完美平方。 这是因为除数`p^2`仅限于`1`,`p`， 和`p^2`。 任何其他结构产生的除数要么少于或多于三个。 

## Python 解决方案```python
import math

class Solution:
    def isThree(self, n: int) -> bool:
        sqrt_n = int(math.isqrt(n))
        if sqrt_n * sqrt_n != n:
            return False
        
        if sqrt_n < 2:
            return False
        
        for i in range(2, int(math.isqrt(sqrt_n)) + 1):
            if sqrt_n % i == 0:
                return False
        
        return True
```该代码首先计算整数平方根`n`检查完美正方形状态。 如果`n`不是完全平方数，函数立即返回`false`。 接下来，它确保平方根大于 1，因为 1 不是质数。 然后，它迭代到平方根`sqrt_n`检查可分性。 如果发现任何因素，`sqrt_n`不是素数，所以`n`不能正好有三个约数。 如果没有找到因素，函数返回`true`。 

## 解决方案```go
import "math"

func isThree(n int) bool {
    sqrtN := int(math.Sqrt(float64(n)))
    if sqrtN*sqrtN != n {
        return false
    }
    
    if sqrtN < 2 {
        return false
    }
    
    for i := 2; i*i <= sqrtN; i++ {
        if sqrtN % i == 0 {
            return false
        }
    }
    
    return true
}
```在围棋中，`math.Sqrt`返回一个 float64，因此我们将其转换为整数。 整数平方根检查确保`n`是一个完美的正方形。 该循环通过测试除数到整数平方根来检查素数`sqrtN`。 否则，逻辑会反映 Python 解决方案。 

## 工作示例

 ### 示例 1：`n = 2`1. 计算`sqrt_n = int(sqrt(2)) = 1`。 
2. 检查`sqrt_n * sqrt_n == n`：`1*1 != 2`，所以返回`false`。 

### 示例 2：`n = 4`1. 计算`sqrt_n = int(sqrt(4)) = 2`。 
2. 检查`sqrt_n * sqrt_n == n`：`2*2 == 4`， 继续。 
3. 检查是否`sqrt_n`是素数。`2`是素数，所以返回`true`。

 ## 边缘情况

 第一个重要的边缘情况是`n = 1`。 由于 1 只有一个除数，任何计算除数的简单方法都可能错误地假设它有三个除数。 该实现显式处理`n = 1`通过检查平方根和素数条件。 

第二个边缘情况是非素数的完全平方，例如`n = 16`(4^2)。 如果我们不验证平方根是否为素数，则对完美平方的简单检查将错误地返回 true。 我们的算法通过对平方根执行素数检查来处理这个问题。 

第三种边缘情况是接近上限的大素数平方，例如`n = 10_000`。 我们需要确保整数平方根计算和素性检查是高效的。 该算法仅迭代到 √(sqrt(n))，即使对于最大输入，该值也很小，因此对于性能问题具有鲁棒性。
