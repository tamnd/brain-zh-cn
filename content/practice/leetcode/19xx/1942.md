[LeetCode 1942 题](https://leetcode.com/problems/the-number-of-the-smallest-unoccupied-chair/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 这个问题描述了这样一个场景：一群朋友参加一个聚会，有无数张椅子标记为`0`向上。 每个朋友都有特定的到达和离开时间。 当朋友到来时，他们必须占据**数量最少的空闲椅子**。 当他们离开时，那把椅子立即变得空闲，可以由同时到达的另一位朋友占据。 

输入`times`是一个二维数组，其中`times[i] = [arrivali, leavingi]`给出朋友的到达和离开时间`i`。`targetFriend`确定我们想要追踪哪个朋友以找到他们占据的椅子。 预期输出是一个整数，表示分配给该朋友的椅子编号。 

约束告诉我们最多可以有`10^4`朋友们，到达时间不同。 这确保了按到达时间排序是安全的，并且没有需要显式处理的同时到达，从而简化了调度。 但是，最长离开时间可达`10^5`，这意味着我们需要一种有效的方法来跟踪椅子的占用情况，而无需迭代每个可能的椅子。 重要的边缘情况包括朋友在同一时刻到达而另一个人离开，以及到达和离开时间范围非常大或极小。 

## 方法

 ### 蛮力

 暴力解决方案将模拟从最早到达到最晚离开的每个时间步。 对于每个朋友的到来，我们都会迭代从以下位置开始的所有椅子`0`找到第一个无人居住的地方。 当朋友离开时，我们将他们的椅子标记为空闲。 这种方法是正确的，但效率低下，因为迭代每个朋友的所有椅子对于`n = 10^4`。 

### 最佳

 更好的解决方案的关键是维护**两个优先级队列**。 一个最小堆跟踪**可用椅子编号**，其他轨道**按离开时间排序的占用椅子**。 按到达时间对朋友进行排序可确保我们按时间顺序处理事件。 当朋友到来时，我们首先为已经离开的朋友腾出椅子。 然后我们将最小的可用椅子分配给新朋友。 这避免了迭代所有主席编号，确保在对数时间内有效分配和解除分配。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 遍历所有椅子，为每位朋友找到最小的免费椅子 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 使用最小堆进行有效的椅子分配和释放 |

 ## 算法演练

 1. **按到达时间对好友进行排序**，以按时间顺序处理事件。 每个好友记录都包含其原始索引以进行跟踪`targetFriend`。 
2. **初始化两个最小堆**：一个用于空闲椅子，最初为空，另一个用于已占用椅子，存储元组`(leaving time, chair number)`。 
3. **跟踪使用的最大椅子数量**。 每当朋友无法重复使用空闲椅子时，请分配下一个最大的椅子编号。 
4. **按到达顺序遍历每个朋友**：

 a. 当最早被占用的椅子的离开时间小于或等于当前朋友的到达时间时，将其从占用堆中弹出，并将其椅子编号压入空闲椅子堆中。 

b. 如果有空闲椅子，则从空闲堆中弹出最小的椅子编号并将其分配给朋友。 否则，分配下一个最大主席编号。 

c. 推`(leaving time, chair number)`这个朋友到占用的堆上。 

d. 如果这位朋友是`targetFriend`，立即返回主席编号。 
5. 算法停止时`targetFriend`被分配了一把椅子。 

**为什么起作用**：该算法保持不变，即空闲椅子堆始终包含当前到达之前可用的所有椅子。 这可确保始终分配编号最小的可用椅子，从而正确模拟聚会的座位规则。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def smallestChair(self, times: List[List[int]], targetFriend: int) -> int:
        # Annotate each friend with their index
        friends = [(arr, leave, i) for i, (arr, leave) in enumerate(times)]
        friends.sort(key=lambda x: x[0])  # Sort by arrival time

        free_chairs = []  # min-heap of available chair numbers
        occupied_chairs = []  # min-heap of (leaving time, chair number)
        next_chair = 0  # Next unassigned chair number

        for arr, leave, idx in friends:
            # Free chairs from friends who have already left
            while occupied_chairs and occupied_chairs[0][0] <= arr:
                _, chair_num = heapq.heappop(occupied_chairs)
                heapq.heappush(free_chairs, chair_num)

            # Assign chair
            if free_chairs:
                chair_num = heapq.heappop(free_chairs)
            else:
                chair_num = next_chair
                next_chair += 1

            # Track occupied chair
            heapq.heappush(occupied_chairs, (leave, chair_num))

            # Return if target friend
            if idx == targetFriend:
                return chair_num
```**说明**：首先，好友按照到达时间排序。 对于每个朋友，都会检查占用的椅子堆中是否有任何离开的朋友，从而释放他们的椅子。 从空闲椅子堆中选择最小的可用椅子，或者如果没有空闲椅子，则分配下一个新椅子。 主席分配被推送到占用的堆上以供将来的发布跟踪。 立刻`targetFriend`收到一把椅子，解决方案将其返回。 

## 解决方案```go
package main

import (
	"container/heap"
	"sort"
)

type Friend struct {
	arrival, leaving, index int
}

type IntHeap []int

func (h IntHeap) Len() int            { return len(h) }
func (h IntHeap) Less(i, j int) bool  { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() interface{} {
	n := len(*h)
	x := (*h)[n-1]
	*h = (*h)[:n-1]
	return x
}

type OccupiedHeap [][2]int // [leaving, chair]

func (h OccupiedHeap) Len() int           { return len(h) }
func (h OccupiedHeap) Less(i, j int) bool { return h[i][0] < h[j][0] }
func (h OccupiedHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *OccupiedHeap) Push(x interface{}) {
	*h = append(*h, x.([2]int))
}
func (h *OccupiedHeap) Pop() interface{} {
	n := len(*h)
	x := (*h)[n-1]
	*h = (*h)[:n-1]
	return x
}

func smallestChair(times [][]int, targetFriend int) int {
	n := len(times)
	friends := make([]Friend, n)
	for i := 0; i < n; i++ {
		friends[i] = Friend{times[i][0], times[i][1], i}
	}
	sort.Slice(friends, func(i, j int) bool { return friends[i].arrival < friends[j].arrival })

	freeChairs := &IntHeap{}
	heap.Init(freeChairs)
	occupiedChairs := &OccupiedHeap{}
	heap.Init(occupiedChairs)
	nextChair := 0

	for _, f := range friends {
		// Free chairs
		for occupiedChairs.Len() > 0 && (*occupiedChairs)[0][0] <= f.arrival {
			leavingChair := heap.Pop(occupiedChairs).([2]int)[1]
			heap.Push(freeChairs, leavingChair)
		}

		// Assign chair
		var chair int
		if freeChairs.Len() > 0 {
			chair = heap.Pop(freeChairs).(int)
		} else {
			chair = nextChair
			nextChair++
		}

		heap.Push(occupiedChairs, [2]int{f.leaving, chair})

		if f.index == targetFriend {
			return chair
		}
	}
	return -1
}
```**说明**：Go 版本使用切片和自定义堆来镜像 Python 逻辑。`IntHeap`和`OccupiedHeap`实现最小堆接口。 椅子分配自`freeChairs`或者`nextChair`，并且释放的椅子被推回到空闲堆上。 Go 特定的处理可确保类型安全和接口合规性。
