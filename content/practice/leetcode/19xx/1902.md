[LeetCode 问题 1902](https://leetcode.com/problems/depth-of-bst-given-insertion-order/)

 **难度：** 🟡 中等
 **主题：** 数组、树、二叉搜索树、二叉树、有序集

 ## 解决方案

 ## 问题理解

 问题给了我们一个数组`order`表示将值插入二叉搜索树（通常缩写为 BST）的确切顺序。 该数组是以下整数的排列`1`到`n`，这意味着每个值都只出现一次并且没有重复项。 

在所有插入完成后，我们被要求确定生成的 BST 的深度。 

二叉搜索树遵循两个重要规则：

 - 左子树中的每个节点必须包含比当前节点小的值。 
- 右子树中的每个节点必须包含比当前节点更大的值。 

向 BST 的插入是通过从根开始并根据新值是小于还是大于当前节点重复向左或向右移动来执行的。 

树的深度定义为从根到任意叶节点的最长路径上的节点数。 仅包含一个节点的树具有深度`1`。 

例如，如果插入顺序是：```
[2,1,4,3]
```最好的变成：```
    2
   / \
  1   4
     /
    3
```最长的路径是：```
2 -> 4 -> 3
```其中包含`3`节点，所以答案是`3`。 

约束条件很重要：

 -`n`可以大到`100000`- 在最坏的情况下，简单的 BST 构建可能会变得极其缓慢
 - 因此我们需要一个接近于`O(n log n)`输入保证：

 - 所有值都是唯一的
 - 值范围为`1`到`n`- 该顺序是有效的排列

 这些保证简化了实现，因为我们永远不需要处理重复项。 

重要的边缘情况包括完全递增序列、完全递减序列和平衡插入模式。 增加或减少订单会创建高度倾斜的树，并可能暴露低效的实现。 

## 方法

 ### 蛮力方法

 最直接的解决方案是实际构建二叉搜索树。 

对于每一个值`order`：

 1. 从根源开始。 
2. 将当前值与节点值进行比较。 
3. 根据比较向左或向右移动。 
4. 继续，直到找到空的子位置。 
5. 将新节点插入其中。 
6. 跟踪插入过程中达到的深度。 

这会产生正确的答案，因为它完全模拟了 BST 插入。 

然而，这种方法可能会变得极其缓慢。 

考虑：```
[1,2,3,4,5,...]
```BST 变成一个链表：```
1
 \
  2
   \
    3
     \
      4
```每次插入几乎遍历整棵树。 

总复杂度变为：```
1 + 2 + 3 + ... + n = O(n²)
```和`n = 100000`，这太慢了。 

### 最佳方法

 关键的见解是我们不需要显式地构建树。 

将新值插入 BST 时，其父值必须是：

 - 最接近的较小插入值
 - 最接近的较大插入值

 在这两个候选者中，较晚插入的者将成为父级。 

我们可以按插入顺序处理值，同时维护：

 - 一组已排序的插入值
 - 每个插入值的深度

 对于每个新值：

 1. 按排序顺序查找其前一个。 
2. 按排序顺序查找其后继者。 
3、新的节点深度为：```
max(depth(predecessor), depth(successor)) + 1
```这是可行的，因为插入路径总是在更深的有效邻居下方结束。 

为了有效地找到前驱和后继，我们使用带有二分搜索的排序结构。

 ## 算法演练

 1. 初始化一个包含第一个插入值的排序列表，因为第一个元素始终成为根。 
2. 将根的深度存储为`1`在哈希图中。 哈希图允许恒定时间检索先前计算的深度。 
3. 将答案初始化为`1`，因为根本身就给出了深度`1`。 
4. 对于每个后续值`order`，使用二分查找来查找将其插入到排序列表中的位置。 
5. 紧邻该位置左侧的值是前驱值，它是最接近的较小插入值。 
6. 紧邻该位置右侧的值是后继值，它是最接近的较大插入值。 
7. 检索前驱和后继的深度（如果存在）。 
8. 新的节点深度变为：```
max(left_depth, right_depth) + 1
```这是可行的，因为插入路径必须终止于较深的相邻节点下方。 

1. 将计算出的深度存储在哈希图中。 
2. 将值插入到排序列表中，以便将来的插入可以将其定位为邻居。 
3.更新全局最大深度。 
4. 处理完所有值后，返回找到的最大深度。 

### 为什么它有效

 对于每个插入的值，BST 插入路径由已插入的值唯一确定。 新节点必须成为其最近的较小祖先或最近的较大祖先的子节点。 在这两个候选节点中，更深的节点决定了实际的插入位置。 因此，采用最大邻居深度​​并加一可以正确计算新节点的深度。 

## Python 解决方案```python
from bisect import bisect_left
from typing import List

class Solution:
    def maxDepthBST(self, order: List[int]) -> int:
        sorted_values = [order[0]]
        depth = {order[0]: 1}

        max_depth = 1

        for value in order[1:]:
            index = bisect_left(sorted_values, value)

            left_depth = 0
            right_depth = 0

            if index > 0:
                predecessor = sorted_values[index - 1]
                left_depth = depth[predecessor]

            if index < len(sorted_values):
                successor = sorted_values[index]
                right_depth = depth[successor]

            current_depth = max(left_depth, right_depth) + 1

            depth[value] = current_depth
            max_depth = max(max_depth, current_depth)

            sorted_values.insert(index, value)

        return max_depth
```实现首先初始化根节点。 由于第一个插入的值总是成为根，因此它的深度立即可知为`1`。 

这`sorted_values`list 按排序顺序存储所有插入的元素。 该结构允许通过二分查找`bisect_left`，它可以有效地找到前任和后继候选人。 

这`depth`字典将每个插入的值映射到其计算的深度。 一旦节点深度已知，它就永远不会改变。 

对于每个新值，我们在排序列表中找到其插入位置。 左边的邻居是前任，右边的邻居是后继。 

节点深度计算如下：```python
max(predecessor_depth, successor_depth) + 1
```最后，我们将值插入到排序列表中并更新全局最大深度。 

## 解决方案```go
package main

import "sort"

func maxDepthBST(order []int) int {
	sortedValues := []int{order[0]}
	depth := map[int]int{
		order[0]: 1,
	}

	maxDepth := 1

	for i := 1; i < len(order); i++ {
		value := order[i]

		index := sort.SearchInts(sortedValues, value)

		leftDepth := 0
		rightDepth := 0

		if index > 0 {
			predecessor := sortedValues[index-1]
			leftDepth = depth[predecessor]
		}

		if index < len(sortedValues) {
			successor := sortedValues[index]
			rightDepth = depth[successor]
		}

		currentDepth := max(leftDepth, rightDepth) + 1

		depth[value] = currentDepth

		if currentDepth > maxDepth {
			maxDepth = currentDepth
		}

		sortedValues = append(sortedValues, 0)
		copy(sortedValues[index+1:], sortedValues[index:])
		sortedValues[index] = value
	}

	return maxDepth
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

主要区别在于 Go 不提供像 Python 那样的内置有序列表插入实用程序`insert`。 我们使用手动扩展切片和移位元素`copy`。 

这`sort.SearchInts`函数执行二分查找以有效地定位插入位置。 

由于所有值都适合标准整数范围，因此不需担心溢出。

 ## 边缘情况

 ### 全面增加投入

 输入例如：```
[1,2,3,4,5]
```创建一个 BST，其中每个节点都成为前一个节点的右子节点。 这是最坏的 BST 形状，产生的最大深度等于`n`。 

简单的实现通常会变得二次，因为每次插入都会遍历整个树。 我们的实现使用前驱关系正确计算深度，而无需显式遍历树。 

### 完全减少输入

 输入例如：```
[5,4,3,2,1]
```创建一棵完全左偏的树。 

这种情况与递增顺序的情况对称，并且可能会暴露前驱或后继处理假设一侧始终存在的错误。 我们的实现在访问邻居之前安全地检查边界。 

### 单元素输入

 当数组只包含一个值时：```
[3]
```BST 仅包含根节点。 

一个常见的错误是返回深度`0`而不是`1`。 我们的实现将根深度正确初始化为`1`，确保立即返回正确答案。
