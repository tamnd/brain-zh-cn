[LeetCode 1999 题](https://leetcode.com/problems/smallest-greater-multiple-made-of-two-digits/)

 **难度：** 🟡 中等
 **主题：** 数学、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们找到满足三个特定条件的最小整数。 给定一个整数`k`和两位数`digit1`和`digit2`，我们需要一个严格**大于的整数`k`**，是**倍数`k`**，并且**仅包含两个给定的数字**。 该整数还必须符合 32 位有符号整数范围，否则我们返回`-1`。 

输入代表：

 -`k`：我们感兴趣的倍数的基数，保证在 1 到 1000 之间。 
-`digit1`和`digit2`：目标号码中唯一允许的数字，范围为0到9。它们可以相同。 

输出是一个整数：满足三个约束的最小数字，或者`-1`如果它不存在。 

需要注意的关键约束包括相对较小的最大值`k`(1000)，意味着任何倍数都是可以管理的，并且结果数字可能需要任意大，但仍在 32 位有符号整数范围内。 边缘情况包括：

 - 两位数字均为零，这通常不会产生有效数字。 
- 一位数字为零，不能出现在最高位。 
- 非常小`k`具有大数字，可以快速产生非常大的数字。 

## 方法

 ### 蛮力

 蛮力方法将涉及生成多个`k`一一开始`k + 1`。 对于每个倍数，我们将检查每个数字是否属于该集合`{digit1, digit2}`。 这种方法保证了正确性，因为它系统地测试了每个可能的候选者。 然而，它的效率很低，因为`k`可以快速增长，并且检查的数量可能会很大，特别是当有效数字有很多位时。 

### 最佳方法

 最佳方法是对数字本身使用**广度优先搜索 (BFS)**，而不是迭代多个`k`。 这个想法是仅使用允许的数字按升序生成数字，并通过以下方式检查整除性：`k`。 这种方法工作效率很高，因为 BFS 保证遇到的第一个有效数字是最小的。 

关键的见解是：

 - 使用增量构建数字`digit1`和`digit2`。 
- 使用 BFS 来确保我们按升序检查数字。 
- 跟踪余数模数`k`以避免探索不必要的路径，因为`(number * 10 + digit) % k`给出新数字的余数。 

这使我们能够修剪大量的可能性，并只关注有效的候选者。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(L * k) | O(1) | O(1) | 检查 k 的每个倍数，直到结果，可能非常大的数字 |
 | 最优（BFS）| O(k * 2^D) | O(k * 2^D) | O(k) | 使用 BFS 逐位生成数字，按模剪枝 |

 ## 算法演练

 1. 检查两位数是否为零。 如果是，立即返回-1。 
2. 使用非零起始数字初始化队列。 我们避免使用前导零。 
3. 维护一组已访问的余数模`k`以防止重新访问相同的剩余部分，这将导致重复探索。 
4. 执行BFS：

 1. 从队列中弹出一个号码。 
2. 计算模余数`k`。 
3. 如果余数为零且数字大于`k`，退货。 
4. 追加两者`digit1`和`digit2`对于当前数字（作为字符串），跳过附加前导零。 
5. 仅当新数字对余数取模时才将其推入队列`k`尚未被访问过。 
5. 如果 BFS 完成后没有找到数字，则返回 -1。 

**为什么有效：** BFS 保证数字按升序生成。 使用模数`k`确保我们有效地跟踪潜在的倍数。 一旦我们找到余数为零的有效数字，它就保证是满足所有条件的最小可能数字。 

## Python 解决方案```python
from collections import deque

class Solution:
    def findInteger(self, k: int, digit1: int, digit2: int) -> int:
        if digit1 == 0 and digit2 == 0:
            return -1
        
        digits = sorted({digit1, digit2})
        queue = deque()
        visited = set()
        
        for d in digits:
            if d != 0:
                queue.append(str(d))
                visited.add(d % k)
        
        while queue:
            num_str = queue.popleft()
            num = int(num_str)
            rem = num % k
            
            if rem == 0 and num > k:
                if num > 2_147_483_647:
                    return -1
                return num
            
            for d in digits:
                new_num_str = num_str + str(d)
                new_rem = (rem * 10 + d) % k
                if new_rem not in visited:
                    visited.add(new_rem)
                    queue.append(new_num_str)
        
        return -1
```该代码使用有效的起始数字初始化 BFS，跟踪余数模`k`修剪重复的路径，并附加允许的数字以形成新的数字。 一旦有效倍数大于，它就会停止`k`被发现。 

## 解决方案```go
package main

import (
	"fmt"
	"strconv"
)

func findInteger(k int, digit1 int, digit2 int) int {
	if digit1 == 0 && digit2 == 0 {
		return -1
	}
	digitsMap := map[int]bool{digit1: true, digit2: true}
	digits := []int{}
	for d := range digitsMap {
		digits = append(digits, d)
	}
	queue := []string{}
	visited := map[int]bool{}
	for _, d := range digits {
		if d != 0 {
			queue = append(queue, strconv.Itoa(d))
			visited[d%k] = true
		}
	}
	for len(queue) > 0 {
		numStr := queue[0]
		queue = queue[1:]
		num, _ := strconv.Atoi(numStr)
		rem := num % k
		if rem == 0 && num > k {
			if num > 2147483647 {
				return -1
			}
			return num
		}
		for _, d := range digits {
			newNumStr := numStr + strconv.Itoa(d)
			newRem := (rem*10 + d) % k
			if !visited[newRem] {
				visited[newRem] = true
				queue = append(queue, newNumStr)
			}
		}
	}
	return -1
}
```Go 解决方案镜像了 Python 版本，使用切片作为队列，并使用映射来访问剩余部分。 整数和字符串之间的转换是使用显式完成的`strconv`。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(k * 2^D) | O(k * 2^D) | BFS 使用两位数生成数字，模 k 确保仅探索唯一的余数 |
 | 空间| O(k) | 存储已访问的余数和队列字符串，以 k | 为界

 BFS 方法利用了鸽巢原理：任意数的余数模`k`只能采取`k`可能的值，这确保算法不会探索无限的路径。
