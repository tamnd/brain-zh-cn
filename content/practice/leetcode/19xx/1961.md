[LeetCode 1961 题](https://leetcode.com/problems/check-if-string-is-a-prefix-of-array/)

 **难度：** 🟢简单
 **主题：** 数组、两个指针、字符串

 ## 解决方案

 ## 问题理解

 问题是要求我们判断给定的字符串是否`s`可以通过连接第一个来形成`k`数组的元素`words`， 在哪里`k`是某个小于或等于长度的正整数`words`。 换句话说，`s`当所有字符串按顺序连接时，必须与数组的前缀完全匹配。 

输入由一个字符串组成`s`和一个字符串列表`words`。 预期输出是一个布尔值：`true`如果`s`可以通过连接前缀来形成`words`和`false`否则。 约束表明`words`相对较小（最多 100 个元素），并且其中的每个字符串都很短（最多 20 个字符），而`s`可以更长（最多 1000 个字符）。 因此，效率很重要，但我们不需要像高级字符串匹配算法那样极端的优化。 

重要的边缘情况包括`s`比第一个元素短`words`， 什么时候`s`等于一个单词`words`， 什么时候`s`正是所有单词的串联`words`，以及当`words`包含部分匹配的元素`s`但不能形成完整的前缀。 

## 方法

 暴力方法会将每个前缀连接起来`words`增量并检查结果字符串是否匹配`s`。 这是有效的，因为它直接模拟前缀字符串的定义。 然而，这可能效率低下，特别是当连接的前缀增长大于`s`，因为可能会发生不必要的串联。 

最佳解决方案的关键在于我们不需要立即构建整个连接字符串。 相反，我们可以迭代`words`同时跟踪我们的位置`s`。 对于每个单词，我们检查它是否与相应的子字符串匹配`s`。 如果在任何时候某个单词不匹配，我们可以立即返回`false`。 这避免了不必要的串联并允许提前终止。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n * m) | 连接前缀并与`s`直接地。`n`= 的长度`words`,`m`= 的长度`s`。 |
 | 最佳| O(米) | O(1) | O(1) | 迭代`words`并匹配子串`s`无需创建新字符串。 |

 ## 算法演练

 1. 初始化变量`pos`到 0 来跟踪我们在字符串中的当前位置`s`。 
2. 遍历每个单词`words`。 
3. 对于每个单词，检查其子串是否为`s`开始于`pos`并且长度等于单词匹配单词。 
4. 如果不匹配，则返回`false`立即地。 
5. 如果匹配，则递增`pos`由当前单词的长度决定。 
6. 每次增量后，检查是否`pos`等于长度`s`。 如果是，我们就匹配了完整的字符串`s`使用前缀`words`并可以返回`true`。 
7. 如果循环完成但没有返回，`s`比连接的前缀长`words`，所以返回`false`。 

**为什么有效**：该算法保持了以下不变式：`s[:pos]`等于处理的前几个单词的串联。 如果任何单词无法匹配其相应的子串`s`，我们可以立即得出结论`s`不是前缀字符串。 这确保了正确性，同时避免了不必要的串联。 

## Python 解决方案```python
from typing import List

class Solution:
    def isPrefixString(self, s: str, words: List[str]) -> bool:
        pos = 0
        for word in words:
            if pos + len(word) > len(s) or s[pos:pos + len(word)] != word:
                return False
            pos += len(word)
            if pos == len(s):
                return True
        return False
```该代码初始化一个`pos`跟踪进度的指针`s`。 对于其中的每个单词`words`，它检查子串是否`s`开始于`pos`匹配这个词。 如果没有，则返回`false`。 添加单词长度后`pos`，它检查是否`pos`已经结束了`s`，在这种情况下前缀匹配成功。 如果循环结束但没有匹配`s`完全，它返回`false`。 

## 解决方案```go
func isPrefixString(s string, words []string) bool {
    pos := 0
    for _, word := range words {
        if pos+len(word) > len(s) || s[pos:pos+len(word)] != word {
            return false
        }
        pos += len(word)
        if pos == len(s) {
            return true
        }
    }
    return false
}
```Go 解决方案反映了 Python 逻辑。 它使用`pos`跟踪当前索引`s`。 主要区别在于 Go 的切片语法`s[pos:pos+len(word)]`用于子字符串提取和显式使用`len()`对于长度。 除了整数跟踪之外，不会分配额外的内存。

 ## 边缘情况

 一个重要的边缘情况是当`s`比第一个单词短`words`。 尝试在没有边界检查的情况下连接或切片的简单实现可能会崩溃或产生不正确的结果。 我们的实现明确检查`pos + len(word) > len(s)`在比较之前。 

另一个边缘情况是当`s`正是所有单词的串联`words`。 该算法处理这个问题是因为`pos`将递增以匹配`len(s)`关于最后一个词，并且`True`将正确返回。 

第三种边缘情况是当`words`包含部分匹配的元素`s`但无法完全构建它。 例如，`s = "abcde"`和`words = ["ab", "cd", "f"]`。 该算法正确识别“f”处的不匹配并返回`False`立即，防止错误匹配。
