[LeetCode 1906 题](https://leetcode.com/problems/minimum-absolute-difference-queries/)

 **难度：** 🟡 中等
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组的子数组中的**最小绝对差**`nums`用于多个查询。 每个查询指定一个带有索引的子数组`[li, ri]`，我们需要找到该子数组中任意两个**不同**元素之间的最小差异。 如果子数组中的所有元素都相同，则最小绝对差为`-1`。 

输入由一个数组组成`nums`值介于`1`和`100`，以及一个查询列表，其中每个查询都是一对索引`[li, ri]`。 约束表明`nums`可以达到`10^5`元素很长，最多可以有`2 * 10^4`查询。 直接检查每个查询中的每一对的简单方法会太慢，因为它可能需要最多$O(n^2)$每个查询的操作数，这对于大输入来说是不可行的。 

重要的边缘情况包括所有元素都相同的子数组（必​​须返回`-1`）、大小为 2 的子数组（仅计算一个差异）以及跨越整个数组的查询。 

## 方法

 **暴力方法**很简单：对于每个查询，提取子数组，对其进行排序，并通过迭代连续元素来计算最小差异。 排序可确保连续元素之间的差异足以找到最小值，因为排序时相邻数字之间必须出现最小绝对差异。 这工作正常，但是对每个查询的每个子数组进行排序会导致时间复杂度为$O(q \cdot m \log m)$， 在哪里$m$是子数组的长度，对于大输入大小来说太慢。 

**最佳方法**利用了以下约束：`1 <= nums[i] <= 100`。 因为值很小，我们可以使用**前缀频率数组**来快速知道哪些数字出现在任何子数组中。 我们构建一个二维前缀和数组`prefix[i][num]`在哪里`prefix[i][num]`表示有多少次`num`从索引中出现`0`到`i`。 然后进行查询`[li, ri]`，我们可以有效地确定子数组中存在哪些数字，按顺序迭代现有数字，并计算最小差异​​。 这将每次查询的时间减少到$O(100) = O(1)$并使算法可行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(q * m log m) | O(q * m log m) | O(米) | 对每个查询的每个子数组进行排序，对于大型 n 或多个查询来说太慢 |
 | 最佳| O(n * 100 + q * 100) | O(n * 100) | 使用前缀频率数组有效检查数字 |

 ## 算法演练

 1.初始化一个2D前缀数组`prefix`尺寸的`(n+1) x 101`充满零。`prefix[i][num]`将计算出现次数`num`直至索引`i-1`在`nums`。 
2. Populate the prefix array by iterating over`nums`。 对于每个索引`i`, 副本计数自`prefix[i]`到`prefix[i+1]`，并增加计数`nums[i]`。 
3. 对于每个查询`[li, ri]`，通过计算确定子数组中存在哪些数字`prefix[ri+1][num] - prefix[li][num]`。 如果差值大于0，则该数字存在于子数组中。 
4. 迭代数字`1`通过`100`并跟踪之前看到的数字。 计算连续数字之间的差异并更新找到的最小差异。 
5. 如果子数组中存在的不同数字少于 2 个，则返回`-1`。 否则，返回计算出的最小差异。 

**为什么有效**：前缀频率数组保证我们可以在 O(1) 时间内确定子数组中是否存在任何数字。 由于数字范围限制为 1-100，因此迭代所有可能的数字速度很快。 通过检查连续的数字，我们确保找到尽可能小的绝对差异。 

## Python 解决方案```python
from typing import List

class Solution:
    def minDifference(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)
        # Step 1: Build prefix frequency array
        prefix = [[0] * 101 for _ in range(n + 1)]
        for i in range(n):
            for num in range(1, 101):
                prefix[i + 1][num] = prefix[i][num]
            prefix[i + 1][nums[i]] += 1
        
        res = []
        for li, ri in queries:
            # Step 2: Find numbers present in subarray
            present = [num for num in range(1, 101) if prefix[ri + 1][num] - prefix[li][num] > 0]
            
            if len(present) < 2:
                res.append(-1)
            else:
                min_diff = float('inf')
                for i in range(1, len(present)):
                    min_diff = min(min_diff, present[i] - present[i - 1])
                res.append(min_diff)
        return res
```**解释**：我们首先构造前缀频率数组，以有效地确定任何子数组中存在哪些数字。 对于每个查询，我们构建子数组中出现的数字列表，然后计算连续数字之间的最小差异。 如果少于 2 个不同的数字，我们返回`-1`。 

## 解决方案```go
func minDifference(nums []int, queries [][]int) []int {
    n := len(nums)
    prefix := make([][101]int, n+1)
    
    for i := 0; i < n; i++ {
        for num := 1; num <= 100; num++ {
            prefix[i+1][num] = prefix[i][num]
        }
        prefix[i+1][nums[i]]++
    }
    
    res := make([]int, len(queries))
    for q, query := range queries {
        li, ri := query[0], query[1]
        present := make([]int, 0)
        for num := 1; num <= 100; num++ {
            if prefix[ri+1][num]-prefix[li][num] > 0 {
                present = append(present, num)
            }
        }
        
        if len(present) < 2 {
            res[q] = -1
        } else {
            minDiff := 101
            for i := 1; i < len(present); i++ {
                diff := present[i] - present[i-1]
                if diff < minDiff {
                    minDiff = diff
                }
            }
            res[q] = minDiff
        }
    }
    return res
}
```**Go 特定注释**：与 Python 的主要区别是使用固定大小的数组`[101]int`对于前缀和，以及切片操作`present`数字。 Go 需要仔细初始化数组以避免 nil 切片，这是在这里处理的。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * 100 + q * 100) | 构建前缀数组需要 O(n * 100)，每个查询最多检查 100 个数字 |
 | 空间| O(n * 100) | 存储前缀频率数组 |

 该算法是有效的，因为`nums[i]`以 100 为界，因此迭代所有可能的值实际上是每个查询的恒定时间。
