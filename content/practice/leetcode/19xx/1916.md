 ## 解决方案

 ## 问题理解

 该问题要求我们计算在蚁群中顺序构建所有房间的有效方法的数量，给定一个**依赖树**，它规定哪些房间必须先于其他房间构建。 每个房间`i`有前任`prevRoom[i]`必须在之前构建`i`。 房间`0`总是最先构建的。 输入是一个整数列表，`prevRoom`，其中每个元素要么指向父房间，要么是`-1`为根。 输出是一个整数，表示构建所有房间的有效序列的数量`10^9 + 7`。 

约束告诉我们`n`可以大到`10^5`，因此生成所有排列的强力解决方案是不可行的。 我们还知道输入形成了一个以房间为根的有效**树**`0`，这保证了没有循环且所有房间均可到达。 边缘情况包括房间链（线性依赖）、具有高分支因子的树以及最小输入，其中`n = 2`。 

关键的挑战是，如果多个房间共享同一个父房间，通常可以按不同的顺序构建，这是树结构上的组合计数问题。 

## 方法

 ### 蛮力

 暴力方法将尝试生成遵守依赖性约束的所有可能的序列。 这可以通过递归探索其父级已构建的所有房间来完成。 虽然这种方法原则上是正确的，但它**慢**，因为序列的数量随着房间的数量呈阶乘增长，使得无法处理`n = 10^5`。 

### 最佳方法

 关键的见解是，问题可以简化为计算有根树中**交错子树**的方法数量。 对于每个节点，我们可以递归地计算构建其子树的方式数量，然后乘以代表排列其子树的方式数量的**多项式系数**。 这需要：

 1. 构建树的邻接表表示。 
2.使用DFS计算子树大小和每个子树的有效构建序列的数量。 
3. 应用组合学：如果一个节点有`k`具有子树大小的子项`[s1, s2, ..., sk]`，交织它们的方式数量是`(s1 + s2 + ... + sk)! / (s1! * s2! * ... * sk!)`。 

我们预先计算阶乘模`10^9 + 7`使计算更加高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 递归生成所有序列； 对于大 n | 不可行
 | 最佳| O(n log n) | O(n log n) | O(n) | DFS + 使用预先计算阶乘的组合； 有效处理大n |

 ## 算法演练

 1. **预计算阶乘和倒数**：我们计算`fact[i]`=`i! % MOD`和`inv[i]`= 模逆`fact[i]`使用费马小定理，允许 O(1) 计算二项式系数模`10^9 + 7`。 
2. **构建树**：转换`prevRoom`进入邻接表`tree`其中每个节点存储其子节点的列表。 这将使我们能够有效地遍历树。 
3. **DFS函数**：定义一个递归DFS函数，返回`(ways, size)`对于以节点为根的子树`u`：

 -`size`是子树中的节点总数。 
-`ways`是该子树的有效构建序列的数量。 
4. **递归步骤**：

 - 初始化`total_ways = 1`和`total_size = 0`。 
- 对于每个孩子`v`的`u`，递归计算`(child_ways, child_size)`。 
- 乘法`total_ways`经过`child_ways`。 
- 乘以多项系数`C(total_size + child_size, child_size)`使用预先计算的阶乘。 
- 增量`total_size`经过`child_size`。 
5. **返回结果**：从根开始DFS后`0`， 返回`ways`作为最终答案。 

**为什么起作用**：每个节点使用**其子路径的乘积**和**交织因子**来计算构建其子树的有效序列的数量。 由于树没有循环，因此该递归正确地计算了所有可能的序列，而不会过度计数。 

## Python 解决方案```python
from typing import List

MOD = 10**9 + 7

class Solution:

    def waysToBuildRooms(self, prevRoom: List[int]) -> int:
        n = len(prevRoom)
        
        # Precompute factorials and modular inverses
        fact = [1] * (n + 1)
        inv = [1] * (n + 1)
        for i in range(2, n + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n - 1, 0, -1):
            inv[i] = inv[i + 1] * (i + 1) % MOD
        
        # Build tree
        tree = [[] for _ in range(n)]
        for child, parent in enumerate(prevRoom):
            if parent != -1:
                tree[parent].append(child)
        
        # DFS to count ways
        def dfs(node: int) -> (int, int):
            total_ways, total_size = 1, 0
            for child in tree[node]:
                child_ways, child_size = dfs(child)
                total_ways = total_ways * child_ways % MOD
                total_ways = total_ways * fact[total_size + child_size] % MOD
                total_ways = total_ways * inv[total_size] % MOD
                total_ways = total_ways * inv[child_size] % MOD
                total_size += child_size
            return total_ways, total_size + 1
        
        result, _ = dfs(0)
        return result
```该实现完全遵循这些步骤。 阶乘和模逆允许快速计算二项式系数。 DFS 累积子树的大小和方式，并使用多项系数将它们组合起来。 

## 解决方案```go
package main

func waysToBuildRooms(prevRoom []int) int {
    const MOD int = 1e9 + 7
    n := len(prevRoom)
    
    // Precompute factorials and inverses
    fact := make([]int, n+1)
    inv := make([]int, n+1)
    fact[0] = 1
    for i := 1; i <= n; i++ {
        fact[i] = fact[i-1] * i % MOD
    }
    inv[n] = modPow(fact[n], MOD-2, MOD)
    for i := n - 1; i >= 0; i-- {
        inv[i] = inv[i+1] * (i+1) % MOD
    }
    
    // Build tree
    tree := make([][]int, n)
    for i := 0; i < n; i++ {
        if prevRoom[i] != -1 {
            tree[prevRoom[i]] = append(tree[prevRoom[i]], i)
        }
    }
    
    var dfs func(int) (int, int)
    dfs = func(node int) (int, int) {
        totalWays, totalSize := 1, 0
        for _, child := range tree[node] {
            childWays, childSize := dfs(child)
            totalWays = totalWays * childWays % MOD
            totalWays = totalWays * fact[totalSize+childSize] % MOD
            totalWays = totalWays * inv[totalSize] % MOD
            totalWays = totalWays * inv[childSize] % MOD
            totalSize += childSize
        }
        return totalWays, totalSize + 1
    }
    
    result, _ := dfs(0)
    return result
}

func modPow(a, b, mod int) int {
    res := 1
    for b > 0 {
        if b%2 == 1 {
            res = res * a % mod
        }
        a = a * a % mod
        b /= 2
    }
    return res
}
```Go 实现类似，但使用`modPow`for modular inverse calculation. 其余部分遵循相同的 DFS 和组合逻辑。 Go 切片可以有效地处理动态子列表。
