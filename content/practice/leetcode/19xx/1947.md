[LeetCode 1947 题](https://leetcode.com/problems/maximum-compatibility-score-sum/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、回溯、位操作、位掩码

 ## 解决方案

 ## 问题理解

 问题是要求我们将学生与导师进行最佳配对，以使他们的兼容性分数总和最大化。 每个学生、每个导师都给出了答案`n`是/否问题代表`0`沙`1`s。 学生-导师对的兼容性分数是匹配答案的计数。 例如，如果一个学生回答`[1, 0, 1]`导师回答`[0, 0, 1]`，得分为`2`因为两个答案匹配。 

输入由两个组成`m x n`矩阵：`students`和`mentors`。 每行`students`代表一个学生的答案，每一行`mentors`代表一位导师的答案。 输出是一个整数，表示通过将每个学生分配给一位导师可实现的最大兼容性分数总和，反之亦然。 

限制很小：`1 <= m, n <= 8`。 这使我们能够考虑涉及检查学生导师作业的所有排列的解决方案，因为`8! = 40320`计算上是可行的。 我们还知道每个答案都是二进制的，这允许进行位操作来加速分数计算。 

重要的边缘情况包括：所有学生和导师都有相同的答案（最高分），所有答案完全相反（零分），以及最小的情况`m = 1`和`n = 1`。 

## 方法

 蛮力方法是生成导师索引的所有排列并将每个排列分配给学生。 对于每项作业，我们通过将每对学生-导师的分数相加来计算总兼容性分数。 这保证了正确性，因为它详尽地检查了每个可能的分配。 但其时间复杂度为`O(m! * m * n)`由于`m!`排列并计算每个学生-导师对的兼容性，这对于较大的学生-导师对来说效率低下`m`。 

最佳解决方案的关键见解是使用**回溯和修剪**。 我们不是立即生成所有排列，而是递归地将学生分配给导师，并将导师标记为已分配。 对于每个部分作业，我们都会跟踪累积分数。 如果一个分支无法超过当前的最大分数（例如，如果所有剩余的可能匹配都无法提高分数），我们会修剪该分支。 这样在保证最优解的同时减少了冗余计算。 位掩码还可用于有效跟踪分配了哪些导师。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m! * m * n) | O(米) | 生成导师作业的所有排列并计算分数 |
 | 使用位掩码回溯 | O(m * 2^m * n) | O(2^m) | O(2^m) | 使用带有位掩码的递归来跟踪指定的指导者并修剪次优路径 |

 ## 算法演练

 1. 预先计算二维数组中所有学生-导师对的兼容性分数`score[i][j]`， 在哪里`i`是学生指数，`j`是导师指数。 这允许在回溯期间进行恒定时间查找。 
2. 定义递归函数`dfs(student_index, mask)`尝试将当前学生分配给任何未分配的导师。`mask`是一个位掩码，其中`j`-第 位是`1`如果导师`j`被分配。 
3.如果`student_index`等于`m`， 返回`0`因为所有的学生都被分配了。 
4. 对于每位导师`j`从`0`到`m-1`，检查是否`mask & (1 << j)`是`0`（导师`j`未分配）。 如果是，则递归调用`dfs(student_index + 1, mask | (1 << j))`并添加`score[student_index][j]`到结果。 
5. 跟踪当前学生所有递归调用的最大总和。 
6. 返回分配所有学生获得的最大总和。 

**为什么有效：** 回溯探索所有有效的学生导师作业，同时使用位掩码修剪无效状态。 预计算分数允许对每项作业进行恒定时间评估。 由于考虑了所有排列，该算法保证找到最大兼容性和。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxCompatibilitySum(self, students: List[List[int]], mentors: List[List[int]]) -> int:
        m, n = len(students), len(students[0])
        
        # Precompute compatibility scores
        score = [[0] * m for _ in range(m)]
        for i in range(m):
            for j in range(m):
                score[i][j] = sum(students[i][k] == mentors[j][k] for k in range(n))
        
        memo = {}
        
        def dfs(student_index: int, mask: int) -> int:
            if student_index == m:
                return 0
            if (student_index, mask) in memo:
                return memo[(student_index, mask)]
            
            max_sum = 0
            for j in range(m):
                if not mask & (1 << j):
                    current_sum = score[student_index][j] + dfs(student_index + 1, mask | (1 << j))
                    max_sum = max(max_sum, current_sum)
            memo[(student_index, mask)] = max_sum
            return max_sum
        
        return dfs(0, 0)
```Python 实现首先预先计算兼容性分数`score[i][j]`。 这`dfs`函数使用递归和位掩码来有效跟踪分配了哪些导师。 记忆化确保重复的子问题不会被重新计算，从而将有效时间复杂度从指数降低到`O(m * 2^m)`。 

## 解决方案```go
func maxCompatibilitySum(students [][]int, mentors [][]int) int {
    m, n := len(students), len(students[0])
    
    // Precompute compatibility scores
    score := make([][]int, m)
    for i := 0; i < m; i++ {
        score[i] = make([]int, m)
        for j := 0; j < m; j++ {
            count := 0
            for k := 0; k < n; k++ {
                if students[i][k] == mentors[j][k] {
                    count++
                }
            }
            score[i][j] = count
        }
    }
    
    memo := make(map[[2]int]int)
    
    var dfs func(int, int) int
    dfs = func(studentIndex int, mask int) int {
        if studentIndex == m {
            return 0
        }
        key := [2]int{studentIndex, mask}
        if val, ok := memo[key]; ok {
            return val
        }
        maxSum := 0
        for j := 0; j < m; j++ {
            if mask&(1<<j) == 0 {
                currentSum := score[studentIndex][j] + dfs(studentIndex+1, mask|(1<<j))
                if currentSum > maxSum {
                    maxSum = currentSum
                }
            }
        }
        memo[key] = maxSum
        return maxSum
    }
    
    return dfs(0, 0)
}
```在 Go 中，方法几乎相同。 主要区别在于 Go 的类型系统，使用切片而不是列表，并使用`[2]int`数组作为记忆键而不是元组。 整数位运算的工作方式与 Python 中相同。 

## 工作示例

 **示例1**`students = [[1,1,0],[1,0,1],[0,0,1]]`

`mentors = [[1,0,0],[0,0,1],[1,1,0]]`兼容性分数：

 | 学生\导师| 0 | 1 | 2 |
 | --- | --- | --- | --- |
 | 0 | 2 | 1 | 3 |
 | 1 | 2 | 2 | 1 |
 | 2 | 0 | 3 | 1 |

 回溯赋值步骤：

 1.从学生0开始：分配导师2→分数3
 2.学生1：分配导师0→分数2
 3.学生2：分配导师1→得分3

 总计 = 3 + 2 + 3 = 8

 **示例2**

 所有学生`[0,0]`，所有导师`[1,1]`。 每项分数均为 0。任何作业的总分均为 0。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * 2^m * n) | 每个学生最多有`2^m`掩码状态； 对于每个，我们检查`m`使用预计算在 O(1) 中指导并计算分数 |
 | 空间| O(2^m + m^2) | O(2^m + m^2) |`2^m`用于记忆和`m^2`用于预先计算的分数表|

 记忆回溯将暴力排列的阶乘复杂度降低到指数级，但由于较小的值而易于管理`m`。
