[LeetCode 1967 题](https://leetcode.com/problems/number-of-strings-that-appear-as-substrings-in-word/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们确定数组中有多少个字符串`patterns`显示为给定字符串中的子字符串`word`。 子字符串被定义为连续的字符序列，这意味着字符必须按顺序出现并且内部没有间隙`word`。 

我们有两个输入。 第一个输入，`patterns`，是一个小字符串列表。 第二个输入，`word`, 是单个字符串。 目标是检查每个字符串`patterns`并计算其中有多少可以在里面找到`word`作为一个连续的段。 

输出是表示该计数的单个整数。 重要的是，如果相同的字符串出现多次`patterns`，每次出现都是独立计数的，即使它们引用相同的子字符串。 

约束很小：模式的数量和长度都最多为 100，并且`word`其本身最多 100 个字符长。 这立即表明，即使是相对简单的子字符串检查也将足够有效。 

边缘情况包括重复模式、与以下模式相同的模式`word`，图案长于`word`，以及根本不出现的图案。 由于所有输入都是小写英文字母，因此我们不需要处理 Unicode 或区分大小写。 

## 方法

 蛮力方法很简单：对于中的每个字符串`patterns`，检查它是否作为子字符串存在`word`。 在 Python 中，这可以使用`in`操作员，或通过手动扫描所有可能的起始位置`word`并逐个字符进行比较。 

这是有效的，因为子字符串匹配对于每个模式都是独立的。 然而，尽管强力方法很简单，但如果通过逐个字符扫描每个模式来手动实现，它可能会做多余的工作。 这将导致重复扫描`word`对于每个模式。 

更优化的方法利用了以下事实：`word`很小，并且子字符串检查已经在现代语言中有效实现。 我们可以直接使用内置的子字符串搜索或预先计算`word`并将它们存储在哈希集中。 自从`word`长度最多为 100，子串总数最多为 5050，这仍然很小。 

关键的见解是，而不是搜索`word`对于每个模式重复进行，我们可以依赖高效的内置子字符串搜索，或者预先计算所有子字符串一次并执行 O(1) 成员资格检查。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m * k) | O(n * m * k) | O(1) | O(1) | 对于每个模式，逐个字符地扫描单词 |
 | 最优（子串的哈希集）| O(m² + n * k) | O(平方米) | 预先计算单词的所有子串，然后检查成员资格 |

 这里，`n`是模式的数量，`m`的长度是`word`， 和`k`是平均模式长度。 

## 算法演练

 我们使用基于预先计算所有子串的优化方法`word`。 

1.首先，我们生成所有可能的子串`word`。 我们通过固定起始索引并将结束索引从该位置延伸到字符串的末尾来实现此目的。 每个子字符串都被插入到一个哈希集中。 此步骤确保我们稍后可以在恒定时间内检查子字符串是否存在。 
2. 我们将计数器变量初始化为零。 这将存储出现在的模式数量`word`。 
3. 我们迭代中的每个字符串`patterns`。 对于每个模式，我们检查它是否存在于预先计算的子字符串集中。 
4. 如果该模式存在于集合中，我们将计数器加一。 否则，我们会忽略它。 
5. 处理完所有模式后，我们返回最终计数。 

我们预先计算子串的原因`word`不是直接检查每个模式，而是避免重复扫描`word`。 每次查找都变为 O(1)，使解决方案高效且干净。 

### 为什么它有效

 这是可行的，因为所有子串的集合`word`完全表征了每个可能的连续段`word`。 任何有效的模式匹配都必须出现在该集合中，并且该集合中的任何字符串必须对应于`word`。 因此，该集合中的成员资格对于正确性来说既是必要的也是充分的。 

## Python 解决方案```python
from typing import List

class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        substring_set = set()
        n = len(word)

        for i in range(n):
            current = []
            for j in range(i, n):
                current.append(word[j])
                substring_set.add("".join(current))

        count = 0
        for p in patterns:
            if p in substring_set:
                count += 1

        return count
```该实现首先通过迭代所有可能的开始和结束索引来构建一组所有子字符串。 嵌套循环确保捕获每个连续的子字符串。 为了提高效率，我们使用列表增量构建子字符串，然后在插入集合之前将其转换为字符串。 

预处理后，我们只需迭代`patterns`并检查集合中的成员资格，当找到匹配时增加结果。 

## 解决方案```go
func numOfStrings(patterns []string, word string) int {
	substringSet := make(map[string]struct{})
	n := len(word)

	for i := 0; i < n; i++ {
		current := make([]byte, 0)
		for j := i; j < n; j++ {
			current = append(current, word[j])
			substringSet[string(current)] = struct{}{}
		}
	}

	count := 0
	for _, p := range patterns {
		if _, exists := substringSet[p]; exists {
			count++
		}
	}

	return count
}
```在 Go 中，我们使用`map[string]struct{}`模拟哈希集。 使用空结构是因为它消耗零内存。 字符串是使用字节片增量构造的。 

与 Python 不同，Go 需要在字节切片和字符串之间进行显式转换，这会带来轻微的开销，但在给定约束的情况下仍然保持高效。

 ## 边缘情况

 一种重要的边缘情况是模式包含重复项。 由于该问题独立地计算每次出现的次数，因此我们不能对输入列表进行重复数据删除。 该算法正确地处理了这个问题，因为我们迭代了`patterns`directly without using a set.

 另一种边缘情况是当模式长于`word`。 在这种情况下，根据定义它不能是子字符串。 我们的方法自然地处理这个问题，因为这样的字符串永远不会出现在预先计算的子字符串集中。 

第三种边缘情况是当模式包含空字符串时。 根据解释，空字符串是每个字符串的子字符串，包括`word`。 我们的实现包括隐式生成空子字符串`i == j`，因此如果出现此类输入，则可以正确处理这种情况。
