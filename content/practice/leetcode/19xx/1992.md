 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出一个二元矩阵，称为`land`。 每个单元格包含：

 -`0`, 代表林地
 -`1`, 代表农田

 农田单元被组织成矩形组。 每个组都保证形成一个完全由`1`s。 此外，不同的群体在四个基本方向上永远不会相互接触，这意味着一个群体的农田单元没有直接位于另一群体农田的上方、下方、左侧或右侧。 

我们的目标是识别每个农田矩形并以以下格式返回其坐标：```
[r1, c1, r2, c2]
```在哪里：

-`(r1, c1)`是矩形的左上角
 -`(r2, c2)`是矩形的右下角

 答案可以按任何顺序返回。 

矩阵维度满足：

 -`1 <= m, n <= 300`这意味着矩阵最多可以包含`90,000`细胞。 对整个矩阵的二次或三次算法可能会变得太慢，因此我们应该寻求一种仅访问每个单元少量次数的解决方案。 

有几个重要的观察和保证：

 - 每个农田组都是矩形的
 - 不同的组永远不会重叠
 - 不同组在四个方向上不相邻
 - 单个农田单元本身可以形成一个有效的矩形

 这些保证大大简化了问题，因为一旦我们发现农田组的左上角，我们就可以安全地向右和向下扩展以确定矩形边界。 

一些很容易导致错误的边缘情况包括：

 - 根本没有农田的矩阵
 - 整个网格是一个大农田矩形的矩阵
 - 单细胞农田群
 - 多个分离的农田矩形
 - 薄矩形，例如单行或单列

 正确的实现必须干净地处理所有这些情况。 
该问题给出了一个表示一块土地的二进制矩阵，其中`1`表示农田和`0`表示森林。 耕地不是任意的； 它被组织成不相交的矩形组。 每组都是一个最大的矩形，完全由`1`s，并且即使通过四向邻接，也没有两个组相互接触。 

任务是识别每个这样的矩形并以以下格式返回其左上角和右下角坐标`[r1, c1, r2, c2]`。 输出顺序并不重要。 

关键限制是矩阵可以大到 300 x 300，并且每个单元格可以是`0`或者`1`。 重要的是，组保证是矩形且不相邻，这显着简化了检测。 

边缘情况包括完全空的网格、没有农田的网格、具有一个大矩形的网格以及每个农田单元被隔离的网格（每个网格形成一个 1x1 矩形）。 如果多次冗余地处理同一区域，则从每个单元重复扫描或扩展而不有效地标记访问过的节点的简单方法将太慢。 

## 方法

 ### 蛮力方法

 一种简单的方法是检查每个农田单元，并尝试使用深度优先搜索或广度优先搜索来发现整个连接的组件。 

对于每个未访问过的`1`细胞：

 1. 开始一次DFS或BFS遍历
 2. 访问所有相连的农田单元
 3. 轨迹：

 - 最小行数
 - 最小列
 - 最大行数
 - 最大列
 4. 标记所有访问过的单元格
 5. 存储生成的矩形

 这是可行的，因为每个农田组都是相连的且呈矩形。 通过探索组件，我们可以确定其边界。 

然而，该解决方案执行额外的遍历开销并且需要辅助访问结构或就地标记。 虽然约束仍然可以接受，但它做了超出必要的工作，因为问题保证了组是矩形。 

### 最佳方法的关键见解

 最重要的观察结果是，每个农田组都是一个矩形，并且各组之间是分开的。 

这意味着农田组可以通过其左上角来唯一标识。 

一个细胞`(r, c)`是农田组的左上角，如果：

 -`land[r][c] == 1`- 上面没有农田
 - 左边没有农田

 换句话说：```
(r == 0 OR land[r-1][c] == 0)
AND
(c == 0 OR land[r][c-1] == 0)
```一旦我们找到这样的左上角，我们就可以：

 1.向下展开找到最后一行
 2.向右展开找到最后一列

 因为保证该组是矩形，所以这两个边界完全确定了矩形。 

这让我们可以通过矩阵的单次传递来解决问题，无需 DFS、BFS 或额外的内存。

 ## 算法演练

 ### 第 1 步：迭代每个单元格

 我们逐行、逐列扫描矩阵。 

For every cell`(row, col)`，我们检查它是否包含农田：```
land[row][col] == 1
```只有农田单元格才是开始矩形的候选单元格。 

### 步骤 2：确定单元格是否为左上角

 一个农田单元恰好属于一个矩形。 

我们只想处理每个矩形一次，因此我们只检测每组的左上角。 

如果满足以下条件，则单元格位于左上角：

 1.这是农田
 2. 上方无农田
 3. 左边没有农田

 条件是：```
(row == 0 or land[row - 1][col] == 0)
and
(col == 0 or land[row][col - 1] == 0)
```如果顶部或左侧邻居是农田，则该单元属于已发现的矩形内的某个位置。 

### 步骤 3：向下扩展

 一旦我们发现了左上角，我们就可以确定矩形垂直延伸的距离。 

开始于`row`，继续向下移动，同时单元格仍为农田：```
while bottom + 1 < rows and land[bottom + 1][col] == 1:
    bottom += 1
```这给了我们底部边界。 

### 步骤 4：向右展开

 接下来，确定矩形水平延伸的距离。 

开始于`col`，在单元格仍为农田时继续向右移动：```
while right + 1 < cols and land[row][right + 1] == 1:
    right += 1
```这给了我们正确的边界。 

### 步骤 5：存储矩形

 现在我们知道：

 - 顶行 =`row`- 左栏 =`col`- 底行 =`bottom`- 右栏 =`right`我们附加：```
[row, col, bottom, right]
```到结果列表。 

### 第 6 步：继续扫描

 我们继续扫描矩阵，直到所有单元格都已处理完毕。 

因为每个矩形都只有一个左上角，所以每一组都只添加一次。 

### 为什么它有效

 该算法依赖于保证每个农田组都是一个完美的矩形并且不同组之间是分开的。 

每个矩形只有一个单元格，其上方或左侧（即其左上角）没有农田。 通过仅检测这些单元格，我们处理每个矩形一次并避免重复。 

一旦知道左上角，向下和向右扩展就可以正确识别矩形边界，因为每个农田组都是完全矩形的。 

因此，每个农田组都以正确的坐标被发现一次。 
蛮力方法会迭代矩阵中的每个单元格。 当一个`1`遇到时，它将尝试向下和向右扩展，通过检查所有可能的边界来找到矩形的完整范围。 识别出一个矩形后，它仍然需要将其所有单元格标记为已访问或重复重新扫描网格以避免重复。 

虽然这在概念上可行，但效率很低，因为在冗余扩展或扫描期间可能会多次检查每个单元。 如果没有适当的标记，重叠工作就会变得昂贵。 即使进行标记，从多个单元重复进行边界扫描也会降低性能。 

### 最佳方法洞察

 关键的观察是每个农田组都是一个完美的矩形，并且组之间不接触。 这意味着每个矩形都有一个唯一的左上角，该左上角不与上方或左侧相邻。 因此，每当我们发现一个`1`尚未访问过的部分，它一定是新矩形的左上角。 

从该起点开始，我们只需向右扩展即可找到列边界，向下扩展即可找到行边界。 一旦我们确定了右下角，我们就可以将整个矩形标记为在一次遍历中访问过。 

这确保了每个单元格只被处理一次。 

### 复杂性比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 最坏情况下的 O(m²n²) | O(1) 或 O(mn) | 重复边界扫描和冗余探索 |
 | 最佳 DFS 扩展 | O(百万) | O(1) 额外（不包括递归堆栈）| 每个单元格访问一次，矩形从左上角展开 |

 ## 算法演练

 最优算法如下：

 1. 迭代每个单元格`(r, c)`在矩阵中。 这确保我们检查农田组的每个潜在起点。 我们这样做是因为任何未访问过的`1`必须属于一个新的矩形。 
2.当我们遇到有值的单元格时`0`，我们跳过它，因为它代表森林并且无关紧要。 
3.当我们遇到有值的单元格时`1`，我们将其视为新矩形的左上角。 这是有效的，因为该问题保证没有两个矩形相邻，因此矩形的内部单元不会被误认为起点。 
4. 从这个起点开始，我们计算完整的矩形边界。 我们首先扩展列索引`c2`只要我们看到就向右`1`s 在同一行。 This finds the horizontal boundary of the rectangle.
 5.接下来，我们扩展行索引`r2`向下。 对于每一行，我们确保所有列`c1`到`c2`仍然`1`。 当这个条件不成立时我们就停止。 这给了我们垂直边界。 
6.一次`(r2, c2)`确定后，我们记录下矩形`[r1, c1, r2, c2]`。 
7. 然后，我们将此矩形内的所有单元格标记为已访问（例如，将它们设置为`0`）以避免重新处理。 
8. 继续扫描矩阵，直到处理完所有单元格。 

### 为什么它有效

 正确性依赖于以下不变量：每个农田组都是连续的矩形，并且矩形是不相交且不相邻的。 因此，第一个未访问的`1`迭代期间遇到的必须是以前未见过的矩形的左上角。 从它在两个维度上进行扩展可以正确地重建完整的群体，而不会产生歧义。 

## Python 解决方案```python
from typing import List

class Solution:
    def findFarmland(self, land: List[List[int]]) -> List[List[int]]:
        rows = len(land)
        cols = len(land[0])

        result = []

        for row in range(rows):
            for col in range(cols):

                # Check whether this cell is the top-left corner
                # of a farmland group.
                if (
                    land[row][col] == 1
                    and (row == 0 or land[row - 1][col] == 0)
                    and (col == 0 or land[row][col - 1] == 0)
                ):

                    bottom = row
                    right = col

                    # Expand downward
                    while (
                        bottom + 1 < rows
                        and land[bottom + 1][col] == 1
                    ):
                        bottom += 1

                    # Expand rightward
                    while (
                        right + 1 < cols
                        and land[row][right + 1] == 1
                    ):
                        right += 1

                    result.append([row, col, bottom, right])
        if not land or not land[0]:
            return []

        m, n = len(land), len(land[0])
        result = []

        for r in range(m):
            for c in range(n):
                if land[r][c] == 0:
                    continue

                r1, c1 = r, c

                c2 = c1
                while c2 + 1 < n and land[r1][c2 + 1] == 1:
                    c2 += 1

                r2 = r1
                valid = True
                while r2 + 1 < m and valid:
                    for j in range(c1, c2 + 1):
                        if land[r2 + 1][j] == 0:
                            valid = False
                            break
                    if valid:
                        r2 += 1

                for i in range(r1, r2 + 1):
                    for j in range(c1, c2 + 1):
                        land[i][j] = 0

                result.append([r1, c1, r2, c2])

        return result
```实现首先确定矩阵维度并初始化结果列表。 

嵌套循环扫描矩阵中的每个单元格。 对于每个农田单元格，代码检查它是否符合农田矩形的左上角条件。 这可以防止重复处理。 

一旦找到左上角，代码就会向下扩展以确定矩形高度，并向右扩展以确定矩形宽度。 

由于该问题保证了矩形农田群，因此这两次扩展完全确定了矩形边界。 

最后，矩形坐标被附加到结果列表中，并在全扫描完成后返回。 
### Python代码解释

 该算法线性扫描网格。 当它发现一个`1`，它水平扩展以找到正确的边界，然后通过验证每行是否保持矩形属性来垂直扩展以找到底部边界。 一旦矩形被识别，它的所有单元格都被标记为`0`以避免再次访问。 这确保了每个农田组只被处理一次。 

## 解决方案```go
func findFarmland(land [][]int) [][]int {
	rows := len(land)
	cols := len(land[0])

	result := [][]int{}

	for row := 0; row < rows; row++ {
		for col := 0; col < cols; col++ {

			// Check whether this cell is the top-left corner
			// of a farmland group.
			if land[row][col] == 1 &&
				(row == 0 || land[row-1][col] == 0) &&
				(col == 0 || land[row][col-1] == 0) {

				bottom := row
				right := col

				// Expand downward
				for bottom+1 < rows &&
					land[bottom+1][col] == 1 {
					bottom++
				}

				// Expand rightward
				for right+1 < cols &&
					land[row][right+1] == 1 {
					right++
				}

				result = append(result, []int{
					row,
					col,
					bottom,
					right,
				})
			}
		}
	}

	return result
}

## Edge Cases

### Empty Farmland Matrix

A matrix may contain only `0`s, meaning no farmland exists anywhere.

This case can cause issues if the implementation assumes every scan eventually finds a rectangle. The algorithm handles this naturally because no cell satisfies the farmland condition, so the result list remains empty.

### Single Cell Farmland

A farmland group may consist of only one cell.

This is important because downward and rightward expansion loops should stop immediately without going out of bounds. The implementation correctly leaves both `bottom` and `right` equal to the starting coordinates.

### Thin Rectangles

A farmland group may occupy only one row or one column.

For example:

```[1,1,1,1]```

or

```[
 [1],
 [1],
 [1]
 ]```

These cases can expose bugs in algorithms that incorrectly assume both dimensions expand simultaneously. The implementation handles them correctly because vertical and horizontal expansion are computed independently.

### Multiple Nearby Groups

Several farmland groups may exist close to each other diagonally.

Although groups cannot touch in four directions, diagonal placement is allowed. A careless implementation might accidentally merge them.

Because this solution only expands through direct farmland continuity and identifies rectangles using top left corners, diagonal groups remain separate and are processed independently.
| Time | O(mn) | Each cell is visited and marked at most once as part of a rectangle scan |
| Space | O(1) extra | No auxiliary structures besides output; grid modified in place |

The algorithm is linear in the number of cells because each cell is consumed exactly once when its rectangle is processed.

 ## 边缘情况

 一个重要的边缘情况是网格不包含`1`根本没有。 在这种情况下，算法永远不会进入矩形扩展逻辑，结果仍然为空。 早期跳过条件确保不会发生无效访问。 

另一个边缘情况是网格，其中每个`1`是孤立的。 每个这样的细胞变成一个`1x1`长方形。 该算法自然地处理了这个问题，因为在所有方向上的扩展都会立即失败，从而正确地生成单单元矩形。 

第三种边缘情况是一个大的单个矩形填充整个网格。 该算法正确地从第一个单元扩展到整个边界，并将所有内容标记为已访问，确保没有重复处理并产生完全相同的结果。
