[LeetCode 1938 题](https://leetcode.com/problems/maximum-genic-difference-query/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、位操作、深度优先搜索、Trie

 ## 解决方案

 ## 问题理解

 该问题提出了一个有根树，其中每个节点都由一个整数唯一标识`0`到`n-1`。 这个整数也代表节点的**遗传值**。 树结构由下式给出`parents`数组，其中`parents[i]`表示节点的父节点`i`， 和`-1`表示根节点。 

对于每个查询`[nodei, vali]`，任务是确定之间的**最大遗传差异**`vali`以及路径上的任何节点值`nodei`到根。 遗传差异使用**按位异或运算**定义。 换句话说，对于每个查询，您遍历从给定节点到根的路径并找到该节点`pi`最大化`vali XOR pi`。 

输出是一个数组，其中每个条目对应于每个查询的最大遗传差异。 约束表明问题涉及**大树**（`up to 10^5`节点）和大量的查询（`up to 3*10^4`）。 因此，检查每个查询的每个路径的简单方法会太慢。 

重要的边缘情况包括高度倾斜的树（所有节点都在一行中）、根节点处的查询以及`vali`存在`0`或最大允许值。 

## 方法

 **暴力方法**涉及，对于每个查询，从查询节点向上走到根，计算`vali XOR pi`对于每个节点`pi`在路径上，并返回最大值。 这是正确的，但效率很低，因为如果树倾斜，在最坏的情况下每个查询可能需要 O(n)，导致总时间复杂度为 O(n * q)，这对于输入大小来说是不可接受的。 

**最佳方法**使用专门用于 XOR 查询的 **Trie 数据结构**。 关键的见解是 Trie 可以存储数字的二进制表示，并且通过贪婪地导航 Trie，我们可以找到与 O(log C) 中的给定值进行 XOR 最大化的数字，其中 C 是数字的最大值。 为了使这项工作高效，我们使用 **DFS** 遍历树，并在进入/退出每个节点时动态添加/删除 Trie 中的节点值，从而有效地将 Trie 限制为仅包含当前节点的祖先。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * q) | O(n) | 每个查询的行走路径； 对于大输入来说太慢|
 | 最优（Trie + DFS）| O((n + q) * log C) | O((n + q) * log C) | O(n * log C) | O(n * log C) | 使用 Trie 沿路径高效计算最大异或 |

 ## 算法演练

 1. **从以下位置构建树**`parents`大批。 创建一个表示每个节点的子节点的邻接列表。 将根识别为节点`parent == -1`。 
2. **按节点分组查询**。 为了高效处理，将每个节点映射到访问 DFS 中该节点时需要回答的查询列表。 
3. **实现具有插入、删除和最大异或查询操作的二进制 Trie**。 每个 Trie 节点都会跟踪通过它的数字计数，以便在 DFS 回溯期间进行动态删除。 
4. **树的DFS遍历**。 从根开始：

 - 将当前节点的值插入到 Trie 中。 
- 通过查询 Trie 以获得最大异或来处理与此节点关联的所有查询`vali`。 
- 对所有儿童重复。 
- 在返回父节点之前从 Trie 中删除当前节点的值，以保持 Trie 只包含当前节点的祖先的不变量。 
5. **按照查询顺序收集结果**。 

**为什么有效：** Trie 总是包含从当前节点到根的路径上的节点值。 每个节点的查询都在此上下文中得到答复，确保维持路径约束。 Trie 中的贪心异或遍历保证了每次查询的最大异或。 

## Python 解决方案```python
from typing import List, Dict

class TrieNode:
    def __init__(self):
        self.children = {}
        self.count = 0

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, num: int):
        node = self.root
        for i in reversed(range(18)):  # numbers <= 2*10^5 fit in 18 bits
            bit = (num >> i) & 1
            if bit not in node.children:
                node.children[bit] = TrieNode()
            node = node.children[bit]
            node.count += 1
    
    def remove(self, num: int):
        node = self.root
        for i in reversed(range(18)):
            bit = (num >> i) & 1
            child = node.children[bit]
            child.count -= 1
            if child.count == 0:
                del node.children[bit]
                return
            node = child
    
    def max_xor(self, num: int) -> int:
        node = self.root
        xor_val = 0
        for i in reversed(range(18)):
            bit = (num >> i) & 1
            toggled_bit = 1 - bit
            if toggled_bit in node.children:
                xor_val |= (1 << i)
                node = node.children[toggled_bit]
            else:
                node = node.children.get(bit)
        return xor_val

class Solution:
    def maxGeneticDifference(self, parents: List[int], queries: List[List[int]]) -> List[int]:
        n = len(parents)
        tree = [[] for _ in range(n)]
        root = -1
        for i, p in enumerate(parents):
            if p == -1:
                root = i
            else:
                tree[p].append(i)
        
        node_to_queries: Dict[int, List[tuple]] = {}
        for idx, (node, val) in enumerate(queries):
            node_to_queries.setdefault(node, []).append((idx, val))
        
        ans = [0] * len(queries)
        trie = Trie()
        
        def dfs(node: int):
            trie.insert(node)
            for idx, val in node_to_queries.get(node, []):
                ans[idx] = trie.max_xor(val)
            for child in tree[node]:
                dfs(child)
            trie.remove(node)
        
        dfs(root)
        return ans
```该实现定义了一个包含动态插入和删除计数的 Trie。 DFS 确保只有相关节点位于 Trie 中，并且可以通过以下方式有效地回答查询`max_xor`。 

## 解决方案```go
package main

type TrieNode struct {
	children [2]*TrieNode
	count    int
}

type Trie struct {
	root *TrieNode
}

func NewTrie() *Trie {
	return &Trie{root: &TrieNode{}}
}

func (t *Trie) Insert(num int) {
	node := t.root
	for i := 17; i >= 0; i-- {
		bit := (num >> i) & 1
		if node.children[bit] == nil {
			node.children[bit] = &TrieNode{}
		}
		node = node.children[bit]
		node.count++
	}
}

func (t *Trie) Remove(num int) {
	node := t.root
	for i := 17; i >= 0; i-- {
		bit := (num >> i) & 1
		child := node.children[bit]
		child.count--
		if child.count == 0 {
			node.children[bit] = nil
			return
		}
		node = child
	}
}

func (t *Trie) MaxXOR(num int) int {
	node := t.root
	xorVal := 0
	for i := 17; i >= 0; i-- {
		bit := (num >> i) & 1
		toggled := 1 - bit
		if node.children[toggled] != nil {
			xorVal |= 1 << i
			node = node.children[toggled]
		} else {
			node = node.children[bit]
		}
	}
	return xorVal
}

func maxGeneticDifference(parents []int, queries [][]int) []int {
	n := len(parents)
	tree := make([][]int, n)
	root := -1
	for i, p := range parents {
		if p == -1 {
			root = i
		} else {
			tree[p] = append(tree[p], i)
		}
	}

	nodeToQueries := make(map[int][][2]int)
	for idx, q := range queries {
		nodeToQueries[q[0]] = append(nodeToQueries[q[0]], [2]int{idx, q[1]})
	}

	ans := make([]int, len(queries))
	trie := NewTrie()

	var dfs func(int)
	dfs = func(node int) {
		trie.Insert(node)
		for _, q := range nodeToQueries[node] {
			ans[q[0]] = trie.MaxXOR(q[1])
		}
		for _, child := range tree[node] {
			dfs(child)
		}
		trie.Remove(node)
	}

	dfs(root)
	return ans
}
```Go 解决方案镜像了 Python 版本。 Go 需要 Trie 中子元素的固定大小数组和显式切片初始化。 递归以相同的方式处理动态 Trie 插入和删除。
