[LeetCode 1982 题](https://leetcode.com/problems/find-array-given-subset-sums/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、排序、计数

 ## 解决方案

 ## 问题理解

 问题给了我们一个整数`n`和一个数组`sums`长度`2^n`，其中包含长度未知的数组的每个可能的子集和`n`。 我们的任务是重建任意一个有效的数组`ans`尺寸的`n`这样所有子集和的多重集`ans`完全匹配给定的`sums`。 

换句话说，我们得到了隐藏数组的完整“子集和谱”，并且我们必须对原始元素进行逆向工程。 未知数组中的每个元素在形成子集总和时要么包含要么排除，因此恰好有`2^n`子集总和。 

约束很小，有`n ≤ 15`，意味着输入大小最多为 32,768 个子集和。 这强烈表明`O(2^n log 2^n)`或类似的解决方案是可行的，但指数`n`除此之外的算法太慢了。 

关键边缘条件包括存在重复项（多个相同的子集和）、原始数组中的零元素、负数和多个有效答案。 该问题保证至少一个有效的重构始终存在。 

一个主要的微妙之处是子集和包含重复项，因此我们必须对待`sums`作为多重集，而不是集合。 

## 方法

 蛮力的想法是尝试所有可能的长度数组`n`其中每个元素都是从合理的范围内选择的（例如以输入总和范围为界）。 对于每个候选数组，我们将生成所有子集总和并与给定的进行比较`sums`。 这是不可行的，因为搜索空间巨大，在约束范围内实际上是无限的。 

关键的见解是子集和具有递归结构。 如果我们选择一个元素`x`从未知数组中，则子集和可以分为两组：没有`x`，以及那些有`x`额外。 这形成了一种配对结构，允许我们使用多集匹配一次剥离一个元素。 

我们利用配对子集和之间的最小差异对应于原始数组元素之一的事实，并且我们可以通过排序和贪婪配对来迭代重建。

 ## 算法演练

 最佳解决方案依赖于每次重复提取一个原始元素，方法是将子集和分为与是否包含该元素相对应的两组。 

我们按如下方式进行：

 1.首先，排序`sums`大批。 排序至关重要，因为它使我们能够一致地识别最小绝对差结构并正确配对和。 
2. 中的最小元素`sums`对应于空子集或负值组合的总和。 我们不假设它为零，因此我们通过使用差异进行标准化。 
3.我们考虑一个候选元素`x`作为最小的两个不同子集和之间的差。 在实践中，我们尝试两者`x`和`-x`因为真正的元素可能是正的，也可能是负的。 
4. 一旦我们确定了候选人`x`，我们尝试将和的多重集分成对`(s, s + x)`使得两个元素都存在于多重集中。 这代表因包含而不同的子集`x`。 
5. 我们使用哈希映射（或多集计数器）来有效地跟踪剩余的总和，因为我们必须重复删除匹配的对。 
6. 如果所选的配对成功`x`，我们接受它作为原始数组的一个元素，并在大小减半的缩减多重集上递归。 
7.我们重复这个过程，直到我们提取了所有`n`元素。 

哈希映射的选择至关重要，因为我们需要对多重集执行 O(1) 平均时间的成员资格和删除操作。 

### 为什么它有效

 该算法之所以有效，是因为每个元素`x`原始数组中在子集和上产生完美的配对结构：每个子集没有`x`唯一对应于一个子集`x`额外。 这保证了有效的重建总是形成一致的分区，并且贪婪地提取一个有效的`x`在不损失正确性的情况下减小问题的大小。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, n: int, sums: List[int]) -> List[int]:
        sums.sort()
        
        def dfs(multiset: Counter, length: int) -> List[int]:
            if length == 0:
                return []
            
            arr = sorted(multiset.elements())
            base = arr[0]
            
            for i in range(1, len(arr)):
                x = arr[i] - base
                
                for sign in (x, -x):
                    counter = Counter(multiset)
                    result = []
                    valid = True
                    
                    for v in sorted(counter):
                        while counter[v] > 0:
                            counter[v] -= 1
                            if counter[v + sign] <= 0:
                                valid = False
                                break
                            counter[v + sign] -= 1
                            result.append(sign)
                        if not valid:
                            break
                    
                    if valid:
                        return result + dfs(counter, length - 1)
            
            return []
        
        counter = Counter(sums)
        return dfs(counter, n)
```该实现对子集和的多重集使用递归策略。 我们使用以下方式表示多重集`Counter`用于有效的频率跟踪。 在每个递归级别，我们尝试通过尝试候选和之间的差异来找到有效的原始元素。 一旦找到有效的配对，我们就删除配对元素并递归解决简化的问题。 

## 解决方案```go
package main

import (
	"sort"
)

func recoverArray(n int, sums []int) []int {
	sort.Ints(sums)

	counter := make(map[int]int)
	for _, v := range sums {
		counter[v]++
	}

	var helper func(map[int]int, int) []int

	helper = func(mp map[int]int, k int) []int {
		if k == 0 {
			return []int{}
		}

		keys := make([]int, 0, len(mp))
		for key := range mp {
			keys = append(keys, key)
		}
		sort.Ints(keys)

		base := keys[0]

		for i := 1; i < len(keys); i++ {
			diff := keys[i] - base

			for _, sign := range []int{diff, -diff} {
				tmp := make(map[int]int)
				for k, v := range mp {
					tmp[k] = v
				}

				res := []int{}
				valid := true

				for _, v := range keys {
					for tmp[v] > 0 {
						tmp[v]--
						if tmp[v+sign] <= 0 {
							valid = false
							break
						}
						tmp[v+sign]--
						res = append(res, sign)
					}
					if !valid {
						break
					}
				}

				if valid {
					return append(res, helper(tmp, k-1)...)
				}
			}
		}

		return []int{}
	}

	return helper(counter, n)
}
```在 Go 中，我们使用从整数到频率的映射显式模拟多重集。 与 Python 不同`Counter`，Go在分支时需要手动复制，这使得实现更加冗长。 在尝试候选分割时要小心地深度复制映射，以避免递归分支之间的突变。

```第一个基地是`-3`。 尝试配对差异：

 - 候选 x = 1（从 -2 - (-3)）

 我们尝试配对：```
-3 + 1 = -2
-2 + 1 = -1
...
```有效配对成功，产生元素`1`。 

剩余金额对应于：```
[-3,-2,-1,0,0,1,2,3] → reduced after removing contributions of 1

[1,2,-3]

 ## 边缘情况

 一种重要的边缘情况是原始数组中的所有元素均为零。 在这种情况下，所有子集和都相同，并且算法必须正确推断重复的零元素，而无需尝试无效的对差异。 

当负数占主导地位时，会出现另一种边缘情况，将最小子集和移离零。 该算法不得假设输入中存在零，而是依赖于总和之间的相对差异。 

第三种边缘情况涉及重复的子集和，这种情况很常见，因为多个子集产生相同的和。 实现必须将输入视为多重集，仔细递减频率而不是直接删除值，确保配对逻辑的正确性。
