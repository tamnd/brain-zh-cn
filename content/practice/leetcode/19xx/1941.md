[LeetCode 1941 题](https://leetcode.com/problems/check-if-all-characters-have-equal-number-of-occurrences/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们判断给定的字符串是否`s`是**好**，意味着**字符串中出现的所有字符出现的次数相同**。 换句话说，如果计算每个不同字符的频率，那么这些频率应该相同，字符串才被认为是好的。 

输入是长度在1到1000之间的字符串，仅由小写英文字母组成。 输出是一个布尔值：`true`如果琴弦完好并且`false`否则。 

Key observations include that a string of length 1 is trivially good since there is only one character, and a string with all identical characters is also good. Edge cases that could trip a naive solution include strings with only one unique character, strings where one character differs in frequency by 1, or strings with all characters appearing exactly once. 这些约束告诉我们输入大小足够小，可以进行线性扫描和基于哈希的计数，而不会出现效率问题。 

## 方法

 A **brute-force approach** would iterate through every unique character, count its occurrences by scanning the entire string each time, and then compare all counts. 虽然这会产生正确的结果，但需要`O(n * k)`时间、地点`n`是字符串长度，`k`是不同字符的数量。 给定`n`到 1000 时，这种方法是可行的，但效率不必要地低。 

**最佳方法**利用哈希映射（Python 中的字典，Go 中的映射）来计算单次传递中每个字符的出现次数。 收集所有计数后，我们只需检查所有频率值是否相等。 这将时间复杂度降低到`O(n)`并将空间复杂度保持在`O(k)`， 在哪里`k`最多 26 个，因为我们只有小写英文字母。 关键的见解是我们可以使用单个数据结构有效地总结所有字符频率，然后以简单的方式检查相等性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(1) | O(1) | 通过重复扫描分别计算每个字符 |
 | 最佳| O(n) | O(k) | 使用哈希图进行单次频率计数并检查相等性 |

 ## 算法演练

 1. 初始化一个空的哈希映射（Python 中的字典，Go 中的映射）来存储字符串中每个字符的频率。 
2. 迭代字符串中的每个字符，增加其在哈希映射中的计数。 这可确保记录每个字符的总出现次数。 
3. 从哈希映射中提取值（频率）集。 使用一组可以让我们立即检测所有频率是否相同。 
4.如果集合的长度为1，则表示所有字符出现频率相同，所以返回`true`。 否则，返回`false`。 

**为什么有效：** 该算法之所以有效，是因为它对单次遍历中的所有出现次数进行计数，确保准确的频率计数，然后验证这些频率之间的相等性。 使用一组来存储频率可以保证检测到计数之间的任何差异。 

## Python 解决方案```python
class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        # Step 1: Count occurrences of each character
        freq = {}
        for char in s:
            if char in freq:
                freq[char] += 1
            else:
                freq[char] = 1
        
        # Step 2: Check if all frequencies are the same
        return len(set(freq.values())) == 1
```该实现创建一个字典来存储计数。 每个字符如果出现则增加其计数，否则初始化为 1。 计数后，我们将频率值转换为一组。 如果所有计数相等，则该集合的长度将为 1。这与上述算法步骤直接对齐。 

## 解决方案```go
func areOccurrencesEqual(s string) bool {
    freq := make(map[rune]int)
    
    // Count occurrences of each character
    for _, char := range s {
        freq[char]++
    }
    
    // Check if all frequencies are the same
    var count int
    first := true
    for _, v := range freq {
        if first {
            count = v
            first = false
        } else if v != count {
            return false
        }
    }
    return true
}
```在 Go 中，我们使用来自`rune`到`int`来计算频率。 我们迭代地图值并将每个频率与第一个频率进行比较。 这避免了转换为集合，这在 Go 中不太惯用。 该方法保证了与 Python 相同的正确性。

 ## 边缘情况

 **单个字符串：**类似的字符串`"a"`非常好，因为只有一个字符，因此所有字符的出现频率都相同，均为 1。算法正确返回`true`因为频率集的长度为 1。 

**所有字符相同：** 对于像这样的字符串`"zzzz"`，所有字符都相同。 频率词典只有一个具有正确计数的键。 算法正确检测单频并返回`true`。 

**一个字符不同：** 类似的字符串`"aaabbbcccdddde"`包括一个频率与其他字符不同的字符。 这测试算法是否正确识别差异。 频率集将有多个值，并且算法正确返回`false`。 

由于计算频率和检查相等性的通用性，这种方法可以稳健地处理所有这些边缘情况，无需额外的特殊处理。
