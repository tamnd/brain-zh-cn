[LeetCode 1918 题](https://leetcode.com/problems/kth-smallest-subarray-sum/)

 **难度：** 🟡 中等
 **主题：** 数组、二分搜索、滑动窗口

 ## 解决方案

 ## 问题理解

 问题要求我们找到`kth`给定整数数组的所有可能的**非空连续子数组**中的最小总和`nums`。 每个子数组都是通过从以下位置获取连续的元素序列而形成的`nums`, and its sum is the sum of the elements in that subarray. 输入由数组组成`nums`和一个整数`k`，并且输出应该是表示的单个整数`kth`当所有子数组和按从小到大排序时，最小子数组和。 

例如，在`nums = [2,1,3]`，子数组是`[2]`,`[1]`,`[3]`,`[2,1]`,`[1,3]`， 和`[2,1,3]`, 给出总和`[2,1,3,3,4,6]`。 第四小的总和是`3`。 

约束提供了对问题规模的重要见解。 该数组最多可达`2 * 10^4`元素长，元素本身最多可达`5 * 10^4`。 可能的子数组的数量是`n*(n+1)/2`，最大可能达到大约 2 亿`n`。 这排除了任何显式生成所有子数组和的解决方案。 约束条件还保证`k`是有效的，即`1 <= k <= n*(n+1)/2`。 

重要的边缘情况包括长度为 1 的数组、具有重复值的数组、`k = 1`（最小总和），以及`k = n*(n+1)/2`（最大金额）。 由于时间和内存的限制，生成所有总和的简单解决方案将会失败。 

## 方法

 **暴力方法**涉及生成每个子数组并计算其总和，然后对总和列表进行排序并返回`kth`最小的。 虽然这在概念上简单且正确，但对于大型数组来说在计算上是不可行的，因为子数组的数量呈二次方增长，并且对它们进行排序会增加进一步的开销。 

最佳解决方案的**关键观察**是子数组和是元素的连续和，并且所有单独的和都是正的，因为`nums[i] >= 1`。 这允许结合**滑动窗口/计数技术**使用**可能的总和值**的二分搜索来确定有多少子数组总和小于或等于候选总和。 这种方法避免显式存储所有子数组和。 

我们可以定义一个辅助函数，给定目标总和`mid`, 计算总和小于或等于的子数组的数量`mid`使用两指针技术。 然后，在总和范围内使用二分搜索`[min(nums), sum(nums)]`，我们找到至少有的最小总和`k`小于或等于它的子数组。

 ## 算法演练

 1. **初始化搜索范围**：设置`left`到最小元素`nums`（最小可能的子数组和）和`right`所有元素的总和（最大可能的子数组总和）。 
2. **二分查找循环**：While`left < right`, 计算`mid = (left + right) // 2`。 
3. **计数子数组<= mid**：使用两指针滑动窗口。 开始于`start = 0`和`curr_sum = 0`。 迭代`end`的所有元素`nums`，添加`nums[end]`到`curr_sum`。 尽管`curr_sum > mid`, 减去`nums[start]`并增加`start`。 在每一步中，结束于的子数组的数量`end`且 ≤`mid`是`end - start + 1`。 累积这个计数。 
4. **调整二分查找范围**：如果计数小于`k`，我们需要更大的金额，所以设置`left = mid + 1`。 否则，设置`right = mid`。 
5. **返回结果**：当`left == right`，它代表`kth`最小子数组和。 

**为什么有效**：该算法利用子数组和与二分搜索之间的单调关系。 计算子数组 ≤`mid`确保二分查找正确地识别出最小和，其中至少`k`子数组存在于其下方。 

## Python 解决方案```python
from typing import List

class Solution:
    def kthSmallestSubarraySum(self, nums: List[int], k: int) -> int:
        def count_subarrays_le(target: int) -> int:
            count = 0
            curr_sum = 0
            start = 0
            for end, val in enumerate(nums):
                curr_sum += val
                while curr_sum > target:
                    curr_sum -= nums[start]
                    start += 1
                count += end - start + 1
            return count

        left, right = min(nums), sum(nums)
        while left < right:
            mid = (left + right) // 2
            if count_subarrays_le(mid) < k:
                left = mid + 1
            else:
                right = mid
        return left
```**实施说明**：`count_subarrays_le`helper 使用滑动窗口来有效地计算总和 ≤ 的子数组`target`。 应用二分查找来查找计数至少为的最小总和`k`。 这确保我们有效地找到`kth`无需枚举所有子数组的最小总和。 

## 解决方案```go
func kthSmallestSubarraySum(nums []int, k int) int {
    countSubarraysLE := func(target int) int {
        count, currSum, start := 0, 0, 0
        for end, val := range nums {
            currSum += val
            for currSum > target {
                currSum -= nums[start]
                start++
            }
            count += end - start + 1
        }
        return count
    }

    left, right := nums[0], 0
    for _, val := range nums {
        if val < left {
            left = val
        }
        right += val
    }

    for left < right {
        mid := (left + right) / 2
        if countSubarraysLE(mid) < k {
            left = mid + 1
        } else {
            right = mid
        }
    }
    return left
}
```**Go 注释**：Go 版本密切反映了 Python 实现。 辅助函数是一个内联函数。 注意整数除法和累加。 Go 切片自然地处理空数组或单例数组。
