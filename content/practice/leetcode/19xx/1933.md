[LeetCode 1933 题](https://leetcode.com/problems/check-if-string-is-decomposable-into-value-equal-substrings/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的字符串是否`s`，仅由数字组成`'0'`通过`'9'`，可以分割成连续的 **值相等** 子字符串，使得 **恰好一个子字符串的长度为 2** 并且所有剩余子字符串的长度为 3。值相等的子字符串是一系列相同的字符，例如`"111"`或者`"22"`。 

输入是单个字符串`s`长度在 1 到 1000 之间。输出是一个布尔值：`true`如果`s`可以根据规则分解，`false`否则。 

限制条件下的主要观察结果：

 - 每个字符都属于某个子字符串。 
- 子串的长度只能为 2 或 3，并且只有一个子串的长度可以为 2。 
- 字符串很短（≤ 1000 个字符），因此线性或近线性算法是可行的。 

边缘情况包括以下字符串：

 - 长度小于 2（不可能形成长度为 2 或 3 的子串）。 
- 具有所有相同的字符，但长度不符合分解规则。 
- 具有无法满足“恰好一个长度-2”约束的混合长度值相等段。 

## 方法

 **暴力方法**会尝试一切可能的方法将字符串拆分为长度为 2 或 3 的值相等的子字符串。对于每个相同字符的片段，我们可以尝试以所有组合形式形成长度为 2 和 3 的子字符串，同时确保恰好存在一个长度为 2 的子字符串。 虽然正确，但该方法的时间复杂度呈指数级，因为每个段都可以分支为多个组合。 

**最佳方法**依赖于这样的见解：对于相同字符的每个连续段，可以贪婪地决定分解为长度 2 和长度 3 子串：

 - 如果段长度可被 3 整除，则我们取长度为 3 的所有子串。 
- 如果一个段长度模 3 等于 2，我们可以取一个长度为 2 的子串，其余的长度为 3。 
- 如果段长度模3等于1，则不可能按照规则分解。 

我们还跟踪是否已经使用了 length-2 子字符串，因为该规则总共允许 **恰好一个** length-2 子字符串。 如果有任何段无法分解，我们立即返回`false`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试将所有值相等的段拆分为长度 2 和 3，即指数分支。 |
 | 最佳| O(n) | O(1) | O(1) | 贪婪地处理连续段，跟踪单个长度为 2 的子字符串的使用情况。 |

 ## 算法演练

 1. 初始化变量`used_length2`到`False`跟踪是否使用了唯一的长度为 2 的子字符串。 
2. 迭代字符串以识别相同字符的连续段。 
3. 对于每个线段，计算其长度`seg_len`。 
4.如果`seg_len % 3 == 0`，该段可以完全分割成长度为 3 的子串。 
5. 如果`seg_len % 3 == 2`，检查是否`used_length2`已经是`True`。 如果是，则返回`false`。 否则，标记`used_length2 = True`。 
6. 如果`seg_len % 3 == 1`，该段无法分解为有效的子字符串，因此返回`false`。 
7.处理完所有段后，返回`True`如果所有段都已分解并且恰好使用了一个长度为 2 的子串。 

**为什么有效：** 相同字符的每个片段都是独立的。 模 3 逻辑保证当且仅当段长度可以分为长度 3 和正好一个长度为 2 的子串时，存在有效的分解。 追踪`used_length2`确保“恰好一个”约束。 

## Python 解决方案```python
class Solution:
    def isDecomposable(self, s: str) -> bool:
        n = len(s)
        i = 0
        used_length2 = False
        
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            seg_len = j - i
            
            if seg_len % 3 == 0:
                pass  # all length-3 substrings
            elif seg_len % 3 == 2:
                if used_length2:
                    return False
                used_length2 = True
            else:  # seg_len % 3 == 1
                return False
            
            i = j
        
        return True
```**实现演练：** 我们用指针迭代字符串`i`。 对于每个重复字符段，我们计算段长度。 使用模 3，我们决定该段是否可以分解。 我们跟踪使用单个长度为 2 的子字符串来强制执行问题的约束。 如果有任何段不符合规则，我们立即返回`False`。 

## 解决方案```go

    i := 0
    usedLength2 := false

    for i < n {
        j := i
        for j < n && s[j] == s[i] {
            j++
        }
        segLen := j - i

        if segLen % 3 == 0 {
            // all length-3 substrings
        } else if segLen % 3 == 2 {
            if usedLength2 {
                return false
            }
            usedLength2 = true
        } else {
            return false
        }
        i = j
    }

}
