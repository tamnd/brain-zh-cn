[LeetCode 问题 1901](https://leetcode.com/problems/find-a-peak-element-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、二分搜索、矩阵

 ## 解决方案

 ## 问题理解

 该问题需要在 2D 矩阵中找到 **峰值元素**。 峰值元素定义为**严格大于**其顶部、底部、左侧和右侧的相邻元素的元素。 保证矩阵中没有两个相邻元素相等，这简化了比较。 输入是一个二维列表`mat`尺寸的`m x n`值在 1 到 10^5 之间。 该矩阵在概念上被周长包围`-1`，确保边界元素仍然可以是峰值而无需额外检查。 

预期输出是坐标`[i, j]`**任何峰元素**。 该问题需要一个具有 **O(m log n)** 或 **O(n log m)** 时间复杂度的算法，这排除了对所有元素的暴力扫描（`O(m*n)`），特别是因为`m`和`n`最大可达 500。 

重要的边缘情况包括单行或单列矩阵、边界上有峰值的矩阵以及具有多个可能峰值的矩阵。 

## 方法

 **暴力方法**将迭代矩阵中的每个元素并检查它是否大于其四个邻居。 这保证了正确的解决方案，但需要 O(m*n) 时间，这对于问题约束来说太慢了。 

**最佳方法**利用沿行或列的二分搜索策略。 关键的观察是，如果您在中间列中找到全局最大值并且它不是峰值，那么峰值必须存在于包含大于该最大值的邻居的矩阵的一半中。 这使我们能够在每次迭代中**将搜索空间减少一半**，实现 O(m log n) 或 O(n log m) 时间，具体取决于我们是按列搜索还是按行搜索。 为了保持一致性，我们将描述基于列的二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m*n) | O(1) | O(1) | 检查所有元素的峰值属性 |
 | 最佳| O(m*log n) | O(m*log n) | O(1) | O(1) | 对列进行二分搜索，检查每列的最大行数 |

 ## 算法演练

 1.初始化两个指针`left = 0`和`right = n-1`代表列边界。 
2. 虽然`left <= right`,计算中间列`mid = (left + right) // 2`。 
3.查找列中最大元素的**行索引**`mid`。 该元素是峰的候选元素。 
4. 将此最大元素与它的左、右相邻元素（如果存在）进行比较。 

一个。 如果该元素比两个邻居都大，则它是一个峰值。 返回`[row_index, mid]`。 

b. 如果左邻居更大，则将搜索移至左半部分`right = mid - 1`。 

c. 如果右邻居更大，则将搜索移至右半部分`left = mid + 1`。 
5. 重复步骤 2-4，直至找到峰值。 二分查找确保循环收敛。 

**为什么有效：** 每次迭代要么找到一个峰值，要么移动到包含比候选值更大的邻居的一半。 由于矩阵是有界的并且没有两个相邻单元是相等的，这保证了搜索总是会导致峰值。 

## Python 解决方案```python
from typing import List

class Solution:
    def findPeakGrid(self, mat: List[List[int]]) -> List[int]:
        m, n = len(mat), len(mat[0])
        left, right = 0, n - 1

        while left <= right:
            mid = (left + right) // 2
            # Find the row with the maximum element in the middle column
            max_row = max(range(m), key=lambda r: mat[r][mid])
            # Check neighbors
            left_val = mat[max_row][mid - 1] if mid - 1 >= 0 else -1
            right_val = mat[max_row][mid + 1] if mid + 1 < n else -1
            if mat[max_row][mid] > left_val and mat[max_row][mid] > right_val:
                return [max_row, mid]
            elif left_val > mat[max_row][mid]:
                right = mid - 1
            else:
                left = mid + 1
```Python 代码对列使用二分搜索。 这`max()`函数与`key`lambda 标识具有列最大值的行。 相邻比较确定候选是否是峰值或者搜索是否应该向左或向右继续。 这确保了 O(m*log n) 时间复杂度。 

## 解决方案```go
func findPeakGrid(mat [][]int) []int {
    m, n := len(mat), len(mat[0])
    left, right := 0, n - 1

    for left <= right {
        mid := (left + right) / 2
        maxRow := 0
        for i := 1; i < m; i++ {
            if mat[i][mid] > mat[maxRow][mid] {
                maxRow = i
            }
        }
        leftVal, rightVal := -1, -1
        if mid-1 >= 0 {
            leftVal = mat[maxRow][mid-1]
        }
        if mid+1 < n {
            rightVal = mat[maxRow][mid+1]
        }
        if mat[maxRow][mid] > leftVal && mat[maxRow][mid] > rightVal {
            return []int{maxRow, mid}
        } else if leftVal > mat[maxRow][mid] {
            right = mid - 1
        } else {
            left = mid + 1
        }
    }
    return nil
}
```Go 实现镜像 Python，但显式处理数组索引。 我们预先定义`leftVal`和`rightVal`作为`-1`对于越界列。 整数除法确保正确`mid`计算。 

## 工作示例

 **示例1：**`mat = [[1,4],[3,2]]`步骤一：`left=0, right=1, mid=0`。 第 0 列最大值为`3`在第 1 行。比较邻居：左=-1，右=2。 由于 3 > -1 但 3 > 2 为假，因此向右移动`left=1`。 

步骤2：`mid=1`。 第 1 列最大值为`4`在第 0 行。邻居：左=1，右=-1。 4 > 1 且 4 > -1，所以`[0,1]`被返回。 

**示例2：**`mat = [[10,20,15],[21,30,14],[7,16,32]]`步骤一：`left=0, right=2, mid=1`。 第 1 列最大值为`30`在第 1 行。邻居：左=21，右=14。 30 > 21 且 30 > 14，所以`[1,1]`立即返回。

 ## 边缘情况

 **单元素矩阵：** 矩阵 [[1]] 只有一个元素，这通常是一个峰值。 该算法正确地识别了这一点，因为邻居检查默认为`-1`对于越界索引。 

**单行或单列：** 单行或单列可能在边界处具有峰值。 二分搜索处理这个问题，因为它检查左邻居和右邻居的列，并将丢失的邻居视为`-1`。 

**多个可能的峰：** 基质可能有多个峰。 该算法保证找到**任何峰值**，不一定是第一个。 这与问题要求一致，并且即使存在多个有效答案也能确保正确性。
