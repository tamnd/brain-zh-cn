[LeetCode 1997 题](https://leetcode.com/problems/first-day-where-you-have-been-in-all-the-rooms/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题描述了一个场景，您访问一系列`n`房间，从房间开始`0`当天`0`。 后续访问的顺序由规则决定，该规则取决于您访问当前房间的次数。 具体来说，如果您对某个房间的访问次数为**奇数**，您将移动到由`nextVisit`数组，它总是指向一个编号小于或等于当前房间的房间。 如果访问次数为**偶数**，您将移至下一个房间`(i + 1) mod n`。 

输入是单个数组`nextVisit`长度`n`，其中每个元素`nextVisit[i]`指定离开房间时前往的房间`i`奇数次访问后。 预期输出是**第一天**，当您至少访问过所有房间一次时，取模`10^9 + 7`。 

约束表明`n`可以达到`10^5`，对于每天的简单模拟来说太大了，因为由于重复访问编号较低的房间，天数可能会呈二次方增长或更糟。 边缘情况包括最小数组大小、重复跳回`0`，以及房间指向自身的序列。 

## 方法

 **暴力方式**模拟每一天，跟踪每个房间的访问次数，并根据规则更新当前房间。 虽然它在概念上简单且正确，但速度非常慢，因为反复重新访问编号较低的房间可能会导致 O(n^2) 或更糟糕的操作。 

**最佳方法**利用**动态编程**。 让`dp[i]`表示您在前往编号更高的房间之前最后一次访问房间 i** 的第一天。 我们可以从问题规则中推导出一个递归式：

 - 你总是从 0 号房间开始：`dp[0] = 0`。 
- 房间用`i > 0`，考虑到要第一次到达它，您必须完成之前房间的所有访问。 到达房间的天数`i`可以递归地表达：```
dp[i] = (2 * dp[i-1] - dp[nextVisit[i-1]] + 2) % MOD
```这个公式来自于对每个房间的观察`i-1`被访问**奇数次**（将您送回`nextVisit[i-1]`）和**偶数次**（让您前进到`i`）。 通过使用先前计算的`dp`值，我们避免单独模拟每一天。 

这将复杂性从潜在的 O(n^2) 降低到 O(n)，使其可行`n`最多`10^5`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) 或更糟 | O(n) | 模拟每一天，跟踪访问量，大n太慢|
 | 最佳 | O(n) | O(n) | 使用动态规划有效计算首次访问天数 |

 ## 算法演练

 1. 初始化一个`dp`长度数组`n`在哪里`dp[i]`商店参观完房间的第一天`i`。 
2. 设置`dp[0] = 0`因为第一次访问房间 0 发生在第 0 天。 
3. 定义`MOD = 10**9 + 7`处理大量数据。 
4. 遍历房间`i = 1`到`n-1`：

 1. 计算`dp[i]`使用递归式：`dp[i] = (2 * dp[i-1] - dp[nextVisit[i-1]] + 2) % MOD`。 
2. 术语`2 * dp[i-1]`说明在房间里来回的情况`i-1`访问。 
3. 减法`dp[nextVisit[i-1]]`删除第一次重新访问之前多算的天数。 
4. 加 2 以包括奇偶转换所需的两次移动。 
5. 返回`dp[n-1] % MOD`作为您参观完所有房间的那一天。 

**为什么它有效**：不变的是`dp[i]`正确计算完全处理直至房间的所有访问的最少天数`i`。 每一步都仔细考虑了重新审视规则，而不是单独模拟每一天。 

## Python 解决方案```python
from typing import List

class Solution:
    def firstDayBeenInAllRooms(self, nextVisit: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nextVisit)
        dp = [0] * n
        dp[0] = 0  # Day 0 we visit room 0
        
        for i in range(1, n):
            dp[i] = (2 * dp[i - 1] - dp[nextVisit[i - 1]] + 2) % MOD
        
        return dp[n - 1]
```Python 实现遵循动态规划递归。 数组`dp`用零初始化，然后按顺序填充。 模运算可确保数字保持在大范围内`n`。 

## 解决方案```go
func firstDayBeenInAllRooms(nextVisit []int) int {
    const MOD int = 1e9 + 7
    n := len(nextVisit)
    dp := make([]int, n)
    dp[0] = 0
    
    for i := 1; i < n; i++ {
        dp[i] = (2*dp[i-1] - dp[nextVisit[i-1]] + 2) % MOD
        if dp[i] < 0 {
            dp[i] += MOD
        }
    }
    
    return dp[n-1]
}
```在 Go 中，我们明确处理减法在取模之前可能产生负数的情况。 为了灵活性，使用切片初始化而不是数组。 

## 工作示例

 **示例1：**`nextVisit = [0,0]`| 日 | 房间| 访问次数 | 下一个房间 |
 | --- | --- | --- | --- |
 | 0 | 0 | 1 | 下一次访问[0] = 0 |
 | 1 | 0 | 2 | (0 + 1) % 2 = 1 |
 | 2 | 1 | 1 | 完成 |`dp`价值观：`dp[0] = 0`,`dp[1] = 2`。 返回`2`。 

**示例2：**`nextVisit = [0,0,2]`

`dp`计算：

 -`dp[0] = 0`-`dp[1] = 2*0 - dp[0] + 2 = 2`-`dp[2] = 2*2 - dp[0] + 2 = 6`返回`6`。 

**示例3：**`nextVisit = [0,1,2,0]`

`dp`计算：

 -`dp[0] = 0`-`dp[1] = 2*0 - dp[0] + 2 = 2`-`dp[2] = 2*2 - dp[1] + 2 = 4`-`dp[3] = 2*4 - dp[2] + 2 = 6`返回`6`。

 ## 边缘情况

 **边缘情况 1：最小`n = 2`**

什么时候`n=2`，第一次重新访问是立即的，测试模算术是否正确处理小数。 实施集`dp[0] = 0`并计算`dp[1] = 2`，这是正确的。 

**边缘情况 2：重复访问 0 号房间**
