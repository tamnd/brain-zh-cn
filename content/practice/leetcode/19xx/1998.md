 ## 解决方案

 ## 问题理解

 问题询问是否可以对整数数组进行排序`nums`使用非常特定类型的交换转换为非递减顺序。 您可以交换任意两个元素`nums[i]`和`nums[j]`当且仅当它们的最大公约数 (GCD) 大于 1 时。输入是范围从 2 到 100,000 的整数数组，长度最大为 30,000。 预期输出是一个布尔值，`true`如果可以使用任意数量的此类交换对数组进行排序，或者`false`否则。 

关键的一点是，操作不是任意的； 它受到数论性质的限制。 这意味着两个元素只有共享一个共同的质因数，才能通过交换链进行交互。 因此，排序是否可能取决于数字之间通过共享质因数的连通性。 

要考虑的边缘情况包括已经排序的数组、某些元素是质数且不能与其他元素交互的数组，以及所有元素都是公因子的倍数的数组。 

## 方法

 一种简单的暴力方法会尝试模拟所有有效的交换。 这将涉及计算所有可能对的 GCD，并在允许的情况下交换元素，重复直到无法进行更多交换。 虽然这在逻辑上是正确的，但对于输入约束来说太慢了，因为潜在交换的数量是 O(n²)，并且每对的 GCD 计算也可能成本高昂。 

最佳方法利用数论和并查找（不相交集并，DSU）。 观察结果是，元素只能移动到同一连接组件中其他元素的位置，其中连接性是通过共享至少一个素因子来定义的。 使用筛子有效地分解数字，我们可以将共享素因子的所有数字合并到同一个分量中。 构建这些组件后，如果对于每个索引，排序值和原始值属于同一连接组件，则可以进行排序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² * log(max(nums))) | O(n² * log(max(nums))) | O(n) | 通过检查所有对的 GCD 来模拟交换，这对于大型数组来说是不可行的 |
 | 最佳 | O(n log(max(nums)) + n α(n)) | O(n log(max(nums)) + n α(n)) | O(n + 最大值(nums)) | 使用并查找和素因数分解来有效地对可交换元素进行分组 |

 ## 算法演练

 1. **初始化并查**：为所有数字创建并查（DSU）结构，直到最大值`nums`。 每个数字最初都是其自己的父数字。 
2. **因式分解筛法**：使用埃拉托斯特尼筛法或类似的因式分解技术来查找直到`max(nums)`。 对于每个数字，将其与其素数因子结合起来，以链接所有共享相同素数的数字。 
3. **联合连接数**：迭代`nums`大批。 对于每个数字，找到它的质因数并将该数字与每个质数结合起来。 这构建了可以交换同一组件中的数字的组件。 
4. **检查排序可行性**：创建排序的副本`nums`。 对于每个索引`i`，检查是否`nums[i]`和`sorted_nums[i]`属于同一个组件。 如果任何元素不与其排序位置共享组件，则返回`false`。 
5. **返回True**：如果所有元素都可以通过连通分量交换到其排序位置，则返回`true`。 

**为什么有效**：这种方法保证了正确性，因为并查找组件通过有效的 GCD 交换精确捕获哪些元素可以到达哪些位置。 任何需要移动到已排序位置的元素必须与该位置位于同一连接组件中； 否则，任何有效的交换序列都无法正确放置它。 

## Python 解决方案```python
from math import isqrt
from typing import List

class Solution:
    def gcdSort(self, nums: List[int]) -> bool:
        max_val = max(nums)
        parent = list(range(max_val + 1))
        
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int):
            parent[find(x)] = find(y)
        
        # Factorization and union with primes
        for num in nums:
            n = num
            for p in range(2, isqrt(num) + 1):
                if n % p == 0:
                    union(num, p)
                    while n % p == 0:
                        n //= p
            if n > 1:
                union(num, n)
        
        sorted_nums = sorted(nums)
        for a, b in zip(nums, sorted_nums):
            if find(a) != find(b):
                return False
        return True
```**说明**：我们首先初始化并查找结构`parent`代表每个组件的领导者。 这`find`函数应用路径压缩以提高效率。 这`union`函数合并两个组件。 对于每个数字，我们将其分解并与其素数因子结合，确保所有共享素数的数字都是相连的。 最后，我们通过比较组件领导者来检查每个数字是否可以到达其排序位置。 

## 解决方案```go
func gcdSort(nums []int) bool {
    maxVal := 0
    for _, num := range nums {
        if num > maxVal {
            maxVal = num
        }
    }

    parent := make([]int, maxVal+1)
    for i := range parent {
        parent[i] = i
    }

    var find func(int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }

    union := func(x, y int) {
        parent[find(x)] = find(y)
    }

    for _, num := range nums {
        n := num
        for p := 2; p*p <= n; p++ {
            if n%p == 0 {
                union(num, p)
                for n%p == 0 {
                    n /= p
                }
            }
        }
        if n > 1 {
            union(num, n)
        }
    }

    sortedNums := append([]int(nil), nums...)
    sort.Ints(sortedNums)

    for i := range nums {
        if find(nums[i]) != find(sortedNums[i]) {
            return false
        }
    }
    return true
}
```**Go 特定注释**：Go 版本显式处理切片并使用闭包`find`来实现路径压缩。 质因数分解使用与 Python 相同的方法。 排序用途`sort.Ints`在复制的切片上以避免修改原始切片。 

## 工作示例

 **示例1**：`nums = [7, 21, 3]`- 因式分解 7 → {7}、21 → {3,7}、3 → {3}。 
- 联盟：7 ↔ 7, 21 ↔ 3,21 ↔ 7, 3 ↔ 3
 - 连接的组件：{3,21}、{7,21}
 - 排序后的数字 = [3,7,21]
 - 检查索引 0: 7 → 3, 7 和 3 是否连接？ 是的
 - 检查索引 1：21 → 7，已连接？ 是的
 - 检查索引 2：3 → 21，已连接？ 是的
 - 返回`True`**示例2**：`nums = [5,2,6,2]`- 因式分解 5 → {5}、2 → {2}、6 → {2,3}、2 → {2}
 - 联合组件：{2,6}、{3,6}、{5}
 - 排序后的数字 = [2,2,5,6]
 - 检查索引 2：6 → 5，6 和 5 连接了吗？ 否
