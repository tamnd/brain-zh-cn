[LeetCode 1977 题](https://leetcode.com/problems/number-of-ways-to-separate-numbers/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划、后缀数组

 ## 解决方案

 ## 问题理解

 该问题要求我们确定一串数字的排列方式，`num`，可以分成一系列**非递减**且**无前导零**的正整数序列。 本质上，每个有效分区代表一个数字序列，这些数字可能在删除逗号之前就已经写下了。 输出是此类序列的总计数，模数$10^9 + 7$，因为序列的数量可能非常大。 

输入`num`为一串数字，长度最大为3500个字符。 这很重要，因为它排除了枚举所有可能分区的任何简单解决方案，因为分区数量随着字符串长度呈指数增长。 边缘情况包括开头为零的字符串、单位数字字符串以及所有数字都相同的序列。 

约束条件告诉我们：

 - 数字不能以a开头`'0'`。 
- 数字必须是**正数**。 
- 序列必须是非递减的。 
- 字符串可能很长，最多 3500 个字符，因此需要有效的算法，可能是 O(n²) 或更好。 

可能导致简单方法失败的关键边缘情况包括：

 - 字符串开头`'0'`喜欢`"094"`。 
- 个位数，尤其是`"0"`。 
- 重复数字的字符串需要仔细比较以保持不递减的属性。 

## 方法

 ### 蛮力

 暴力方法会尝试字符串的**所有可能的分区**。 对于每个位置，我们决定是否在那里分割字符串，递归地检查结果数字是否非递减并且没有前导零。 尽管这会产生正确的答案，但效率极低，因为分区数量随着字符串长度呈指数增长。 具体来说，一个长度为`n`最多可以有$2^{n-1}$分区，这是不可行的`n`最多 3500。 

### 最佳方法

 关键的见解是使用**动态规划**。 我们定义`dp[i]`作为分割子串的有效方法的数量`num[0:i]`。 计算`dp[i]`，我们考虑以索引结尾的每个可能的最后一个数字`i-1`，并且我们使用**字符串比较**来确保不递减的属性。 

由于字符串比较的成本很高，因此我们可以预处理字符串所有后缀的**最长公共前缀（LCP）**。 LCP 数组允许我们有效地检查最后一个数字是否至少与前一个数字一样大，而无需将子字符串转换为整数，从而防止溢出并优化比较。 

这将复杂度从指数降低到 **O(n²)**，这对于`n ≤ 3500`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归尝试所有分区，检查每个数字的有效性 |
 | 最佳| O(n²) | O(n²) | 通过 LCP 数组进行字符串比较的动态编程 |

 ## 算法演练

 1.初始化一个DP数组`dp`长度`n+1`， 在哪里`dp[i]`表示子串的有效序列数`num[0:i]`。 放`dp[0] = 1`作为空字符串的基本情况。 
2. 预先计算所有后缀对的**最长公共前缀 (LCP)**。 LCP 有助于快速确定一个子字符串按字典顺序是否小于、等于或大于另一个子字符串。 
3. 从左到右迭代字符串。 对于每个索引`i`,尝试每一个可能的起始索引`j`对于序列中的最后一个数字，使得`num[j:i]`不开始于`'0'`。 
4. 对于每个候选的最后一个数字，使用 LCP 数组将其与前一个数字进行比较。 如果前一个数字小于或等于最后一个数字，则添加`dp[j]`到`dp[i]`。 
5. 应用模数$10^9 + 7$每次添加时防止溢出。 
6. 遍历字符串后，返回`dp[n]`，整个字符串的有效分区数。 

**为什么有效：**

 DP 不变量是`dp[i]`计算所有以以下结尾的有效分区`i`。 通过迭代所有可能的最后一个数字并确保它们相对于前一个数字不减少，我们保证所有计数的序列都是有效的。 LCP 数组确保字符串比较的效率。 

## Python 解决方案```python
class Solution:
    def numberOfCombinations(self, num: str) -> int:
        MOD = 10**9 + 7
        n = len(num)
        if num[0] == '0':
            return 0
        
        # Precompute LCP array
        lcp = [[0]*(n+1) for _ in range(n+1)]
        for i in range(n-1, -1, -1):
            for j in range(n-1, -1, -1):
                if num[i] == num[j]:
                    lcp[i][j] = lcp[i+1][j+1] + 1
        
        dp = [0] * (n+1)
        dp[0] = 1
        
        for i in range(1, n+1):
            for j in range(i):
                if num[j] == '0':
                    continue
                length = i - j
                prev_start = j - length
                if prev_start >= 0:
                    common = lcp[prev_start][j]
                    if common < length and num[prev_start + common] > num[j + common]:
                        continue
                dp[i] = (dp[i] + dp[j]) % MOD
        
        return dp[n]
```**说明：**

 我们首先检查前导零，这会使任何序列无效。 然后我们反向构建 LCP 数组，以允许快速比较任意两个子字符串。`dp`初始化为`dp[0] = 1`。 对于每个结束索引`i`，我们考虑所有有效的起始索引`j`对于最后一个数字。 如果号码不以`'0'`并且满足与前一个数的不减性质，我们添加`dp[j]`到`dp[i]`。 最终的答案是`dp[n]`。 

## 解决方案```go
func numberOfCombinations(num string) int {
    const MOD int = 1e9 + 7
    n := len(num)
    if num[0] == '0' {
        return 0
    }
    
    lcp := make([][]int, n+1)
    for i := range lcp {
        lcp[i] = make([]int, n+1)
    }
    
    for i := n-1; i >= 0; i-- {
        for j := n-1; j >= 0; j-- {
            if num[i] == num[j] {
                lcp[i][j] = lcp[i+1][j+1] + 1
            }
        }
    }
    
    dp := make([]int, n+1)
    dp[0] = 1
    
    for i := 1; i <= n; i++ {
        for j := 0; j < i; j++ {
            if num[j] == '0' {
                continue
            }
            length := i - j
            prevStart := j - length
            if prevStart >= 0 {
                common := lcp[prevStart][j]
                if common < length && num[prevStart+common] > num[j+common] {
                    continue
                }
            }
            dp[i] = (dp[i] + dp[j]) % MOD
        }
    }
    
    return dp[n]
}
```**Go 特定注释：**

 使用切片而不是数组。 我们显式初始化 2D`lcp`片。 通过在每次加法时使用模来避免整数溢出。 索引和比较遵循与 Python 相同的逻辑。 

## 工作示例

 **示例 1：num = "327"**

 逐步执行 DP：

 | 我| j | 数字[j:i] | dp[i] | dp[i] |
 | ---| ---| ---| ---|
 | 1 | 0 | “3”| 1 |
 | 2 | 0 | “32”| 1 |
 | 2 | 1 | “2”| 0 |
 | 3 | 0 | “327”| 1 |
 | 3 | 1 | “27”| 1 |
 | 3 | 2 | “7”| 0 |

 结果：`dp[3] = 2`。 

**示例2：num =“094”**

 前导零会使所有序列无效。`dp[3] = 0`。 

**示例 3：num = "0"**

 单个零无效。`dp[1] = 0`。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n²) | 我们在 O(n²) 中计算 LCP，在 O(n²) 中计算 DP 更新 |
