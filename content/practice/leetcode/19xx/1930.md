[LeetCode 1930 题](https://leetcode.com/problems/unique-length-3-palindromic-subsequences/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、位操作、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定字符串中**长度为 3** 的唯一回文子序列`s`。 回文字符串向前和向后读取相同的内容，在这种情况下，我们只关心恰好三个字符的字符串。 子序列是通过从原始字符串中删除零个或多个字符而不改变剩余字符的相对顺序而形成的。 

例如，在字符串中`"aabca"`,`"aba"`是一个有效的子序列，因为我们可以取第一个`'a'`，跳过第二个`'a'`， 拿`'b'`，然后取最后一个`'a'`。 结果应该只计算**唯一序列**，因此如果`"aba"`发生，则算作 1。 

输入`s`长度最大为105，仅由小写英文字母组成。 这个长度表明简单的三循环暴力方法可能太慢，特别是因为迭代三个字符的所有组合将是 O(n3)。 边缘情况包括没有回文的字符串、具有重复字符的字符串以及第一个和最后一个字符相同但中间没有足够的字符来形成长度为 3 的回文的字符串。 

## 方法

 **暴力方法**是生成所有可能的长度为3的子序列，检查每个子序列是否是回文，然后将其添加到集合中以确保唯一性。 这种方法工作正常，但需要 O(n3) 时间，因为三个字符的可能组合有 O(n3) 种。 对于 n 达到 105，这是不可行的。 

**最佳方法**依赖于观察到任何长度为 3 的回文都具有以下形式`a_b_a`， 在哪里`a`是第一个和最后一个字符并且`b`是它们之间的任意字符。 因此，对于每个角色`a`在`'a'`到`'z'`，我们可以在字符串中找到它的**第一次和最后一次出现**。 然后，这些位置之间的每个唯一字符形成以下形式的有效回文`a_b_a`。 使用一组来计算唯一的中间字符可确保我们只计算每个回文一次。 这将问题减少到 O(n * 26) 时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n3) | 生成所有长度为 3 的子序列并过滤回文 |
 | 最佳| O(n * 26) ≈ O(n) | O(26) ≈ O(1) | O(26) ≈ O(1) | 对于每个字符，计算第一次出现和最后一次出现之间的唯一字符 |

 ## 算法演练

 1. 将结果计数器初始化为 0。 
2. 对于每个角色`a`从`'a'`到`'z'`：

 1. 找到**第一个索引**`a`在字符串中。 
2. 找到**最后一个索引**`a`在字符串中。 
3. 如果第一个索引大于或等于最后一个索引，则跳过该字符，因为它无法形成长度为 3 的回文。 
4. 否则，收集第一个索引和最后一个索引之间的所有唯一字符。 
5. 该区间中唯一字符的数量就是该形式的回文数`a_b_a`为了这`a`。 将此计数添加到结果中。 
3. 返回结果。 

**为什么有效：** 这种方法保证了正确性，因为每个长度为 3 的回文在第一个和最后一个位置必须具有相同的字符。 通过计算之间所有不同的字符，我们捕获所有唯一的长度为 3 的回文。 该集合确保忽略重复项，满足唯一性要求。 

## Python 解决方案```python
class Solution:
    def countPalindromicSubsequence(self, s: str) -> int:
        result = 0
        for ch in map(chr, range(ord('a'), ord('z') + 1)):
            first = s.find(ch)
            last = s.rfind(ch)
            if first == -1 or first == last:
                continue
            middle_chars = set(s[first + 1:last])
            result += len(middle_chars)
        return result
```**解释：** 我们迭代每个小写字母。`s.find(ch)`和`s.rfind(ch)`有效地找到该字母的第一次和最后一次出现。 如果字母没有出现两次，则无法形成长度为 3 的回文。 然后，我们使用集合收集第一个和最后一个位置之间的所有唯一字符并对其进行计数。 对这些计数求和就得到了唯一回文子序列的总数。 

## 解决方案```go
func countPalindromicSubsequence(s string) int {
    result := 0
    for ch := 'a'; ch <= 'z'; ch++ {
        first := -1
        last := -1
        for i, c := range s {
            if c == ch {
                if first == -1 {
                    first = i
                }
                last = i
            }
        }
        if first == -1 || first == last {
            continue
        }
        middleChars := make(map[rune]struct{})
        for i := first + 1; i < last; i++ {
            middleChars[rune(s[i])] = struct{}{}
        }
        result += len(middleChars)
    }
    return result
}
```**说明：** Go 需要使用具有空结构值的映射来显式管理集合。 我们手动扫描第一个和最后一个位置，然后填充地图以查找唯一的中间字符。 其他一切都与 Python 方法类似。

 ## 边缘情况

 **单字符重复字符串：**`"aaa"`仅形成一个回文`"aaa"`。 算法正确地计算了中间字符，在本例中为空，但是`first != last`允许计算长度为 3 的回文。 

**没有重复字符的字符串：**`"abc"`不能形成任何长度为 3 的回文。 该算法正确地跳过出现次数少于两次的字符。 

**最大长度的字符串：** 对于`s`长度为 10⁵ 时，该算法仍然高效，因为它只扫描每个字母一次，最多处理 26 个集合，每个集合最多 26 个元素。 这可确保线性性能并防止超时。
