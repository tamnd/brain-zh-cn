 **难度：** 🟢简单
 **主题：** 深度优先搜索、广度优先搜索、并查找、图论

 ## 解决方案

 ## 问题理解

 该问题要求我们确定无向图中两个节点之间是否存在路径。 该图定义为`n`顶点标记为`0`到`n - 1`以及边列表，其中每条边连接两个不同的顶点。 关键点是图是**双向的**，没有重复的边，也没有自环。 输入`source`和`destination`是顶点索引，输出应该是一个布尔值，指示是否存在将源连接到目标的边序列。 

约束告诉我们该图可能非常大：最多 200,000 个顶点和 200,000 个边。 这意味着任何在顶点和边的数量上具有超过线性或接近线性时间复杂度的方法都可能太慢。 该图也可能是断开连接的，因此仅检查单个顶点的邻居是不够的。 重要的边缘情况包括`source`等于`destination`，当图有孤立的顶点时，或者当`edges`是空的。 

## 方法

 强力方法是使用深度优先搜索 (DFS) 或广度优先搜索 (BFS) 对图执行完整搜索。 从`source`顶点，我们将递归或迭代地探索每个邻居，标记访问过的顶点以避免循环，直到我们到达`destination`或耗尽所有可到达的节点。 虽然正确，但这种方法的时间复杂度为 O(V + E)，这是可以接受的，但简单的递归 DFS 可能会达到 Python 对于非常大的图的递归限制，从而使迭代方法更安全。 

更复杂的方法是使用 **Union-Find**（不相交集并集）数据结构。 见解是，如果两个节点属于同一连接组件，则它们是连接的。 我们可以迭代所有边，合并节点，最后检查是否`source`和`destination`共享同一个根。 这种方法在实践中也是 O(V + E)，但具有迭代操作更简单且没有递归深度错误风险的优点。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | DFS/BFS| O(V + E) | O(V) | 探索可达节点； 迭代DFS或BFS避免递归限制|
 | 联查| O(E * α(V)) | O(V) | 联合查找与路径压缩和按等级联合有效地对连接的组件进行分组

 ## 算法演练

 我们将使用 BFS 方法作为 Python 和 Go 中清晰度和鲁棒性的最佳解决方案。 

1. **构建邻接列表**：迭代边列表，将每条边添加到两个顶点的邻居列表中。 这允许 O(1) 访问邻居进行探索。 
2. **初始化BFS**：创建一个队列，初始化为`source`顶点和访问集来跟踪访问过的节点。 
3. **迭代BFS循环**：当队列不为空时，将前端节点出队。 如果这个节点是`destination`， 返回`true`。 
4. **探索邻居**：对于当前节点的每个邻居，如果没有被访问过，则将其标记为已访问并入队。 
5. **返回结果**：如果队列清空而没有找到目的地，则返回`false`。 

**为什么有效**：BFS 按距离递增顺序探索从源可到达的所有顶点。 如果目的地可达，BFS就会遇到； 否则，所有可到达的顶点都将被耗尽。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        if source == destination:
            return True

        # Build adjacency list
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        # BFS initialization
        visited = [False] * n
        queue = deque([source])
        visited[source] = True

        # BFS loop
        while queue:
            node = queue.popleft()
            if node == destination:
                return True
            for neighbor in graph[node]:
                if not visited[neighbor]:
                    visited[neighbor] = True
                    queue.append(neighbor)

        return False
```该实现首先处理源等于目标的边缘情况。 邻接列表允许高效的邻居查找。 BFS 确保所有可达节点都被访问一次，并且访问的数组可以防止循环。 

## 解决方案```go
package main

func validPath(n int, edges [][]int, source int, destination int) bool {
    if source == destination {
        return true
    }

    // Build adjacency list
    graph := make([][]int, n)
    for _, edge := range edges {
        u, v := edge[0], edge[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }

    // BFS initialization
    visited := make([]bool, n)
    queue := []int{source}
    visited[source] = true

    // BFS loop
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        if node == destination {
            return true
        }
        for _, neighbor := range graph[node] {
            if !visited[neighbor] {
                visited[neighbor] = true
                queue = append(queue, neighbor)
            }
        }
    }

    return false
}
```Go 实现镜像 Python，使用切片作为邻接列表和队列。 BFS 中不存在递归深度问题。

 ## 边缘情况

 第一个边缘情况是当`source`等于`destination`。 一个天真的 BFS 可能仍然会不必要地排队和探索邻居，但我们的实现通过返回来立即处理这个问题`True`。 

第二个边缘情况是空边缘列表。 该图可能由孤立的顶点组成，BFS 应该正确识别不存在路径，除非`source`等于`destination`。 

第三种边缘情况是靠近上限的大型稀疏图`n = 2 * 10^5`。 由于 Python 递归限制，递归 DFS 会失败，但带有队列的 BFS 可以避免堆栈溢出并有效处理最大输入大小。 我们使用邻接列表和访问数组确保性能随顶点和边的数量线性扩展。
