[LeetCode 1983 题](https://leetcode.com/problems/widest-pair-of-indices-with-equal-range-sum/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们在两个二进制数组中找到**最宽的子数组**（连续段）`nums1`和`nums2`这样两个数组的该段中的元素总和**相等**。 形式上，我们需要找到索引`(i, j)`和`i <= j`这样：```
sum(nums1[i..j]) == sum(nums2[i..j])
```并最大化距离`j - i + 1`。 

输入由两个等长的二进制数组组成。 输出是最宽的有效子数组的长度。 如果不存在有效的子数组，我们返回`0`。 

约束表明数组长度`n`可以达到`10^5`。 因此，任何具有**二次时间复杂度**的解决方案都会太慢，我们需要一个更接近线性时间的解决方案。 

重要的边缘情况包括没有匹配和的数组、长度为 1 的数组以及最宽子数组跨越整个数组的数组。 

## 方法

 ### 蛮力

 暴力方法迭代所有可能的子数组`(i, j)`并计算总和`nums1`和`nums2`对于每个部分。 如果总和匹配，我们将更新最大距离。 虽然这种方法是正确的，但它太慢了，因为大约有`O(n^2)`子数组，并且天真地计算每个总和是`O(n)`。 甚至使用前缀和来计算子数组和`O(1)`仍然会导致`O(n^2)`总时间，这是不可行的`n = 10^5`。 

### 最佳方法

 关键的观察是对于子数组`(i, j)`使两个数组中的总和相等：```
sum(nums1[i..j]) == sum(nums2[i..j])
```这相当于说：```
prefix1[j] - prefix1[i-1] == prefix2[j] - prefix2[i-1]
```或者```
(prefix1[j] - prefix2[j]) == (prefix1[i-1] - prefix2[i-1])
```如果我们定义`diff[k] = prefix1[k] - prefix2[k]`并让`diff[-1] = 0`，那么我们需要`diff[j] == diff[i-1]`。 这将问题简化为**查找差异数组中两个相等值之间的最大距离**，这可以使用哈希映射来存储每个差异的第一次出现来有效地完成。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 使用前缀和计算所有子数组和 |
 | 最佳| O(n) | O(n) | 使用前缀差异和哈希图来跟踪首次出现 |

 ## 算法演练

 1. 初始化哈希图`first_occurrence`存储每个差异的第一个索引`diff`发生。 初始化它`{0: -1}`处理从索引 0 开始的子数组。 
2. 初始化变量`max_width`为 0 以存储找到的最大距离。 
3. 初始化`diff = 0`跟踪运行差异`prefix1 - prefix2`。 
4. 迭代每个索引`i`从`0`到`n-1`。 

1.更新运行差异：`diff += nums1[i] - nums2[i]`。 
2.如果`diff`以前曾见过`first_occurrence`，计算从第一次出现到`i`并更新`max_width`如果它更大。 
3.如果`diff`没见过，将当前索引存储在`first_occurrence`。 
5.迭代结束后，返回`max_width`。 

**为什么它有效：** 通过跟踪每个差异的第一次出现，相同差异的任何未来出现都意味着数组之间的总和相等的子数组。 仅存储第一次出现可确保我们最大化距离。 

## Python 解决方案```python
from typing import List

class Solution:
    def widestPairOfIndices(self, nums1: List[int], nums2: List[int]) -> int:
        first_occurrence = {0: -1}
        diff = 0
        max_width = 0
        
        for i in range(len(nums1)):
            diff += nums1[i] - nums2[i]
            if diff in first_occurrence:
                max_width = max(max_width, i - first_occurrence[diff])
            else:
                first_occurrence[diff] = i
        
        return max_width
```**解释：** 我们维持运行差异`diff`之间的前缀和`nums1`和`nums2`。 哈希图`first_occurrence`存储出现特定差异的最早索引。 每当我们再次遇到相同的差异时，第一次出现和当前索引之间的子数组在两个数组中的总和相等。 更新中`max_width`确保我们捕获最宽的子数组。 

## 解决方案```go
func widestPairOfIndices(nums1 []int, nums2 []int) int {
    firstOccurrence := map[int]int{0: -1}
    diff := 0
    maxWidth := 0
    
    for i := 0; i < len(nums1); i++ {
        diff += nums1[i] - nums2[i]
        if firstIndex, exists := firstOccurrence[diff]; exists {
            if i - firstIndex > maxWidth {
                maxWidth = i - firstIndex
            }
        } else {
            firstOccurrence[diff] = i
        }
    }
    
    return maxWidth
}
```**Go 特定说明：** Go 需要明确的地图存在检查。 我们初始化地图`{0: -1}`处理从索引 0 开始的子数组。无需担心整数溢出，因为差异受数组长度限制。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单次遍历数组，每次操作都是 O(1) |
 | 空间| O(n) | 哈希映射最多可以存储n个不同的差异|

 复杂度是线性的，因为我们只扫描数组一次，并且每个差异在哈希映射中只存储一次。
