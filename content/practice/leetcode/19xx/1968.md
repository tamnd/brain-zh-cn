[LeetCode 1968 题](https://leetcode.com/problems/array-with-elements-not-equal-to-average-of-neighbors/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们重新排列一个**不同的整数数组**，以便没有元素等于**其邻居的平均值**。 输入是一个零索引数组`nums`长度至少为 3，并且所有元素都保证是不同的。 输出应该是**任何有效的重新排列**`nums`满足具有左邻居和右邻居的所有元素的条件，即索引`1`到`len(nums) - 2`。 

约束告诉我们，数组可以相对较大（最多 10^5 个元素），并且元素值是最多 10^5 的非负整数。 由于这个大小，任何涉及尝试**所有排列**的算法都会太慢。 

关键边缘情况包括已按升序或降序排序的数组，或相邻差异最小的数组。 该问题保证了不同的元素，因此我们不必处理重复项，这简化了我们的任务。 

基本要求是对于任何元素`nums[i]`，它一定不等于`(nums[i-1] + nums[i+1]) / 2`。 直观上，当一个元素位于其邻居“之间”时，就会发生这种情况。 因此，巧妙的重新排序可以避免这种情况，从而解决这个问题。 

## 方法

 暴力方法将尝试数组的**所有排列**并检查每个排列的条件。 虽然这保证最终会找到一个解决方案（如果存在），但它在计算上是不可行的。 为了`n`元素，有`n!`排列，这远远超出了合理范围`n = 10^5`。 

最佳方法的关键见解基于**排序和交错极端**。 如果我们对数组进行排序，然后通过交替较小的一半和较大的一半来重新排列元素，我们可以确保没有中间元素是其邻居的平均值。 本质上，通过分散较小和较大的数字，较小和较大的邻居将数字“夹在中间”可以防止它成为它们的平均值。 

这种技术是一种基于排序的**贪婪方法**，它保证了所需的属性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 检查数组的所有排列是否满足条件 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对数组进行排序并交错较小和较大的两半以避免平均冲突 |

 ## 算法演练

 1. 首先按升序**对数组进行排序**。 排序提供了从最小到最大元素的可预测结构。 
2. 将排序后的数组分成两半。 为了简单起见，考虑`left`作为较小的一半和`right`作为较大的一半。 
3. 创建一个新的结果数组和**替代元素**`left`和`right`。 首先从以下位置获取一个元素`left`，然后从`right`，然后继续。 
4. 如果数组长度为奇数，则较大的一半将多出一个元素。 将其放在交错序列的末尾。 
5. 返回交错数组作为重新排列的结果。 

**为什么有效：** 排序保证每个元素都是有序的。 通过交错小值和大值，每个有邻居的元素都会有一个较小的和一个较大的邻居。 从数学上讲，一个数字不可能完全等于一个较小数字和一个较大数字的平均值，除非它以精确的算术方式重复或对称，而由于不同的元素，这是不可能的。 这确保了所有中间元素都满足不变量。 

## Python 解决方案```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        left = nums[:n//2]
        right = nums[n//2:]
        
        result = []
        i = 0
        j = 0
        while i < len(left) or j < len(right):
            if j < len(right):
                result.append(right[j])
                j += 1
            if i < len(left):
                result.append(left[i])
                i += 1
        return result
```该解决方案首先对数组进行排序以施加顺序。 这`left`和`right`然后将两半交织到结果中。 我们首先从较大的一半中取出元素，以确保序列不会意外地将较小的数字放置在两个较大的数字之间，这可能形成平均值。 这保证了算法的正确性。 

## 解决方案```go
import "sort"

func rearrangeArray(nums []int) []int {
    sort.Ints(nums)
    n := len(nums)
    left := nums[:n/2]
    right := nums[n/2:]
    
    result := make([]int, 0, n)
    i, j := 0, 0
    for i < len(left) || j < len(right) {
        if j < len(right) {
            result = append(result, right[j])
            j++
        }
        if i < len(left) {
            result = append(result, left[i])
            i++
        }
    }
    return result
}
```在 Go 中，我们小心地处理切片。`make([]int, 0, n)`预先分配结果数组以避免重复调整大小。 排序是使用就地完成的`sort.Ints`。 交错逻辑反映了 Python 方法。 

## 工作示例

 **示例1：`nums = [1,2,3,4,5]`**

 1. 排序：`[1,2,3,4,5]`2. 分割：`left = [1,2]`,`right = [3,4,5]`3. 交错：`result = [3,1,4,2,5]`4. 验证：

 - i=1: (3+4)/2 = 3.5 != 1
 - i=2: (1+2)/2 = 1.5 != 4
 - i=3: (4+5)/2 = 4.5 != 2

 **示例2：`nums = [6,2,0,9,7]`**

 1. 排序：`[0,2,6,7,9]`2. 分割：`left = [0,2]`,`right = [6,7,9]`3. 交错：`result = [6,0,7,2,9]`4. 验证：

 - i=1: (6+7)/2 = 6.5 != 0
 - i=2: (0+2)/2 = 1 != 7
 - i=3: (7+9)/2 = 8 != 2

 两个例子都满足条件。

 ## 边缘情况

 **最小长度数组：** 长度为 3 的数组是可能的最小数组。 交错逻辑仍然有效，因为左半部分将有一个元素，右半部分将有两个元素，从而产生一个有效的序列。 

**具有连续整数的排序数组：** 如果进行简单交换，可能会意外生成等于平均值​​的元素。 排序和交替两半可以通过极端间距来防止这种情况发生。 

**奇数长度数组：** 左半部分的元素比右半部分少。 从一开始就从右侧放置额外的元素可确保每个中间元素仍然具有一个较小和一个较大的邻居，从而保持正确性。
