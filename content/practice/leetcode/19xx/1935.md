[LeetCode 1935 题](https://leetcode.com/problems/maximum-number-of-words-you-can-type/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 问题是要求我们确定在有故障的键盘上可以完整键入给定字符串中的多少个单词。 键盘上有一些损坏的字母键无法使用。 输入由一个字符串组成`text`包含由空格分隔的单词和一个字符串`brokenLetters`包含损坏的不同字母。 输出是一个整数，表示不包含任何损坏字母并因此完全可输入的单词数。 

关键的限制是`text`最长可达 10,000 个字符，`brokenLetters`最多包含 26 个字符（全部不同的小写字母），并且`text`仅包含由单个空格分隔的小写字母，没有前导或尾随空格。 这意味着该解决方案必须有效地检查每个单词与损坏的字母，而无需过多的重复计算。 

边缘情况包括：`brokenLetters`为空（所有单词都可输入），当每个单词至少包含一个损坏的字母时（输出为 0），并且当`text`由一个长单词组成。 该问题保证单词之间恰好有一个空格分隔并且字母是小写的，从而简化了解析和比较。 

## 方法

 蛮力方法会迭代中的每个单词`text`并检查每个字符与所有损坏的字母。 对于每个单词，如果有任何字符被破坏，则跳过该单词； 否则，则被计算在内。 这可以正常工作，但如果`text`非常长，因为检查每个字符的字符串中的成员资格是 O(k)，导致总体 O(n*k)，其中 n 是`text`k 是长度`brokenLetters`。 

最佳方法使用集合来存储`brokenLetters`用于 O(1) 成员资格检查。 然后我们分手了`text`分成单词，并针对每个单词检查其任何字符是否在损坏的集合中。 如果没有损坏，我们就增加计数。 与字符串或列表相比，使用集合可以大大减少查找时间，从而使解决方案高效且简单。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(1) | O(1) | 检查每个单词的每个字符与损坏的字母串的关系 |
 | 最佳| O(n + k) | O(k) | 将损坏的字母转换为 O(1) 查找的集合，检查每个单词一次 |

 ## 算法演练

 1. 转换字符串`brokenLetters`进入一个名为`broken_set`。 这允许在 O(1) 时间内对任何字母进行常量成员资格检查。 
2. 分割字符串`text`使用空格字符作为分隔符分成单个单词。 这会产生一个单词列表。 
3. 初始化一个计数器变量`count`为零。 这将存储可以完整键入的单词数。 
4. 迭代单词列表中的每个单词。 对于每个单词：

 a. 检查该单词中是否存在任何字母`broken_set`。 

b. 如果集合中存在某个字母，则跳过该单词； 否则，增加`count`一个。 
5. 迭代完所有单词后，返回值`count`。 

工作原理：该算法保证了正确性，因为它使用有效的集合查找来明确检查每个单词的每个字母与所有损坏的字母。 通过仅在单词没有损坏的字母时递增计数器，返回的计数准确地表示所有可键入的单词。 

## Python 解决方案```python
class Solution:
    def canBeTypedWords(self, text: str, brokenLetters: str) -> int:
        broken_set = set(brokenLetters)
        count = 0
        
        for word in text.split():
            if all(char not in broken_set for char in word):
                count += 1
        
        return count
```实现首先转换`brokenLetters`进入一个集合以进行快速成员资格检查。 这`text`被分成单词使用`split()`。 对于每个单词，生成器表达式会检查其中不存在字符`broken_set`。 如果这个词通过了这个检查，`count`是递增的。 最后，`count`被返回。 

## 解决方案```go
func canBeTypedWords(text string, brokenLetters string) int {
    brokenSet := make(map[rune]bool)
    for _, ch := range brokenLetters {
        brokenSet[ch] = true
    }

    words := strings.Fields(text)
    count := 0

    for _, word := range words {
        canType := true
        for _, ch := range word {
            if brokenSet[ch] {
                canType = false
                break
            }
        }
        if canType {
            count++
        }
    }

    return count
}
```在围棋中，`brokenLetters`转换为 O(1) 查找的映射。`strings.Fields`用于安全地将文本拆分为单词。 一个布尔值`canType`跟踪是否可以键入当前单词。 该单词通过符文进行迭代，以正确处理所有字母。 如果任何字母被破坏，则该单词将被跳过。

 ## 边缘情况

 一个重要的边缘情况是当`brokenLetters`是空的。 这可能会导致假设集合非空的简单实现失败。 我们的解决方案可以正确处理这个问题，因为该集合只是空的，并且所有`char not in broken_set`检查会通过。 

另一种极端情况是每个单词至少包含一个损坏的字母。 如果不小心处理，循环可能会意外地计算出阻塞的单词。 我们的实现确保只有在没有字母出现的情况下才计算单词`broken_set`。 

第三种边缘情况是当`text`由一个很长的单词组成。 一些按空格分割或迭代效率低下的解决方案可能会出现性能问题。 我们的算法可以正确处理它，因为它在一次传递中处理字符，并且不依赖于不必要的单词嵌套循环。
