[LeetCode 1973 题](https://leetcode.com/problems/count-nodes-equal-to-sum-of-descendants/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们分析一棵二叉树并计算有多少个节点满足特定属性：该节点的值等于其所有后代的总和。 节点的**后代**是位于以该节点为根的子树中的任何节点（不包括该节点本身）。 例如，如果一个节点有两个子节点，则后代的总和包括两个子节点及其所有各自的子树。 如果一个节点没有子节点，则其后代的总和被视为 0。 

输入是二叉树的根。 每个节点都包含一个整数值，我们需要遍历整棵树来找到满足该属性的节点。 输出是一个表示此类节点数量的整数。 

约束告诉我们这棵树可以相当大，最多可达$10^5$节点，所有节点值都是 0 到 之间的非负整数$10^5$。 由于树可能很大，任何在嵌套循环中重复访问节点的解决方案都可能太慢。 边缘情况包括只有一个节点的树、所有节点的值都为零的树或深度较大但值较小的树，因为这些可能会暴露整数溢出或递归深度问题。 

## 方法

 ### 蛮力方法

 一种简单的方法是单独计算每个节点的后代总和。 对于每个节点，我们将递归地遍历其子树，对所有后代节点值求和，并将总和与节点的值进行比较。 这种方法工作正常，因为它显式计算每个节点的属性，但效率低下。 每个子树和计算最多可以遍历$O(n)$节点，如果我们对每个节点重复此操作，最坏情况的时间复杂度将变为$O(n^2)$，这对于$n = 10^5$。 

### 最佳方法

 高效解决方案的关键见解是我们可以使用**后序深度优先遍历**来计算子树和。 在后序遍历中，我们处理左子树，然后处理右子树，然后处理节点本身。 这使我们能够在一次传递中计算每个节点的后代总和：节点后代的总和是左子树和右子树的总和。 如果我们将这个总和包含在节点本身中，它就成为子树的总和，然后子树可以有效地向上传播。 使用这种方法，每个节点都被访问一次，给出$O(n)$时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(h) | 分别对每个节点的后代进行递归求和； h 是树的高度。 |
 | 最佳| O(n) | O(h) | 后序 DFS 在单次遍历中计算子树和。 |

 ## 算法演练

 1. 初始化一个计数器变量来跟踪其值等于后代总和的节点。 
2. 定义一个递归辅助函数，该函数将节点作为输入并返回以该节点为根的子树的总和。 
3. 在辅助函数中，如果节点是`None`，返回 0，因为空子树没有任何贡献。 
4. 递归计算左子树和右子树的和。 
5. 计算后代的总和作为左子树和右子树总和的总和。 
6. 将节点的值与后代的总和进行比较。 如果它们相等，则增加计数器。 
7. 返回以该节点为根的子树的总和，即后代的总和加上该节点自身的值。 
8. 从根节点开始递归。 
9. 递归结束后，返回计数器作为最终结果。 

**为什么有效：** 通过执行后序遍历，我们确保对于任何给定的节点，在检查该节点之前已经计算出其左子树和右子树的和。 这保证了我们正确计算所有节点的后代总和，并且仅计算一次，避免冗余计算。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def equalToDescendants(self, root: Optional[TreeNode]) -> int:
        count = 0
        
        def dfs(node: Optional[TreeNode]) -> int:
            nonlocal count
            if not node:
                return 0
            left_sum = dfs(node.left)
            right_sum = dfs(node.right)
            descendants_sum = left_sum + right_sum
            if node.val == descendants_sum:
                count += 1
            return descendants_sum + node.val
        
        dfs(root)
        return count
```该实现定义了一个`dfs`返回以每个节点为根的子树的总和的辅助函数。 这`count`每当节点的值与其后代的总和相匹配时，变量就会更新。 后序遍历确保在检查节点之前计算左子树和右子树之和，完全遵循算法演练。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func equalToDescendants(root *TreeNode) int {
    count := 0
    
    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil {
            return 0
        }
        leftSum := dfs(node.Left)
        rightSum := dfs(node.Right)
        descendantsSum := leftSum + rightSum
        if node.Val == descendantsSum {
            count++
        }
        return descendantsSum + node.Val
    }
    
    dfs(root)
    return count
}
```在围棋中，`nil`被用来代替`None`。 闭包用于将计数器维护在外部范围内。 该逻辑完全反映了 Python 解决方案。 

## 工作示例

 ### 示例 1：`[10,3,4,2,1]`1. 计算节点 3 的左子树和： left=2, right=1, sum=3 → node.val = sum → count = 1
 2. 计算节点 4 的右子树和：left=0, right=0, sum=0 → node.val ≠ sum → count = 1
 3.计算根10：左sum=6，右sum=4，sum=10→node.val = sum→count = 2

 最终输出 = 2

 ### 示例 2：`[2,3,null,2,null]`1. 节点2（左子节点）：左sum=2，右sum=0，node.val=3 ≠ 2 → count=0
 2. 节点2（根）：左sum=5，右sum=0，node.val=2 ≠ 5 → count=0

 最终输出 = 0

 ### 示例 3：`[0]`1.节点0：左sum=0，右sum=0→node.val=sum→count=1

 最终输出 = 1

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 具有单个节点的树是一种重要的边缘情况，因为后代的总和为 0，并且如果其值为 0，则应该对节点进行计数。实现会自然地处理此问题，因为 DFS 函数对于空子节点返回 0。 

全零值的树测试算法是否正确计算每个节点。 由于后代总和将始终与节点值匹配，因此每个节点都应递增计数。 该实现正确地递归地对左子节点和右子节点求和，包括零。 

高度不平衡的树，例如链表形状的树，测试递归深度。 如果树非常深，Python 可能会达到递归限制，而 Go 可以有效地处理递归。 该算法仍然可以正确运行，因为 DFS 可以正确计算沿单个路径的后代总和。
