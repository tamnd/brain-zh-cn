 # LeetCode 1960 - 两个回文子串长度的最大乘积

 ## 问题理解

 该问题要求我们找到两个**不重叠的奇数长度回文子串**，其长度乘积尽可能大。 

我们得到一个字符串`s`长度可达`10^5`。 我们必须选择两个回文子串：

 - 第一个占用索引`[i, j]`- 第二个占用索引`[k, l]`- 它们不能相交，所以`j < k`- 两个回文长度必须是奇数

 我们的目标是最大化：$$(j - i + 1) \times (l - k + 1)$$关键的观察是两个回文只需要由某个分割点分开。 如果我们知道：

 - 每个前缀中完全包含的最长奇回文。 
- 每个后缀中完全包含的最长奇数回文。 

然后可以独立评估每个分割位置。 

约束是问题中最重要的部分。 自从：$$n \le 10^5$$任何比大约更糟糕的解决方案`O(n log n)`可能太慢了。 枚举所有回文或所有子串对是不可能的，因为有`O(n²)`子串和`O(n⁴)`子串对。 

重要的边缘情况包括：

 - 每个字符都相同的字符串，产生极大的重叠回文。 
- 没有回文长度超过 length 的字符串`1`。 
- 最佳答案使用较短回文的情况，因为较大的回文会阻塞更好的第二个回文。 
- 接近约束限制的非常长的字符串，需要线性或近线性算法。 
## 问题理解

 该问题要求我们在给定字符串中找到两个**非重叠的回文子串**，其**奇数长度**`s`使得**它们的长度的乘积最大化**。 本质上，我们的任务是识别字符串两个不同部分中最大的“奇数长度回文”，并计算它们长度的最大乘积。 

输入为一串小写英文字母，长度为`10^5`。 输出是表示最大乘积的单个整数。 关键限制是回文长度必须是奇数且不相交，这排除了尝试所有子字符串的任何幼稚方法，因为子字符串的数量与字符串长度成二次方。 

边缘情况包括所有字符都相同的字符串、没有任何长度超过 1 的回文串的字符串以及最小长度 (2) 的字符串。 约束保证至少有两个字符，因此我们总是有最小的机会形成两个长度为 1 的回文。 

## 方法

 ### 蛮力

 直接方法将枚举字符串中的每个奇数长度回文，然后检查每对回文并在它们不重叠时计算乘积。 

这是正确的，因为每个有效的解决方案都经过显式检查。 不幸的是，可能有`O(n²)`字符串中的回文子串，例如`"aaaaaa..."`。 比较所有对需要`O(n⁴)`最坏情况下的时间。 

即使是更仔细的实现，首先枚举所有回文，然后检查对，对于`n = 10^5`。 

### 关键见解

 关键的观察是，最终答案是由某个分割位置决定的。 

假设我们在索引之间分割字符串`i`和`i+1`。 

然后：

 - 左侧回文必须完全位于内部`[0, i]`。 
- 正确的回文必须完全位于内部`[i+1, n-1]`。 

如果我们知道：

 -`left[i]`= 完全包含在前缀中的最长奇回文`[0, i]`-`right[i]`= 完全包含在后缀中的最长奇回文`[i, n-1]`那么答案就变成：$$\max_i \left(left[i] \times right[i+1]\right)$$剩下的挑战是有效地计算这些数组。 

这就是 **Manacher 算法** 发挥作用的地方。 它计算每个中心在线性时间内的最大奇数回文半径。 

根据这些半径，我们可以确定哪些回文长度在每个位置结束以及哪些回文长度从每个位置开始。 使用优先级队列的扫描，我们可以计算每个索引处可用的最长回文`O(n log n)`时间。

 ## 算法演练

 ### 1. 使用 Manacher 算法计算奇回文半径

 对于每个职位`i`，计算：$$d[i]$$在哪里`d[i]`是以 为中心的最大奇数回文的半径`i`。 

回文长度为：$$2d[i]-1$$Manacher 计算所有半径`O(n)`时间。 

### 2.记录回文间隔

 对于每个中心`i`：

 - 左边界：$$L=i-d[i]+1$$- 右边界：$$R=i+d[i]-1$$- 长度：$$len=2d[i]-1$$这个最大的回文数隐含地包含以同一位置为中心的所有较小的奇数回文数。 

### 3. 计算在每个位置结束的最长回文

 对于以`c`有半径`r`：$$R=c+r-1$$每个回文都以位置结束`x ≤ R`贡献：$$2(x-c)+1$$线性增长为`x`向右移动。 

扫描线处理其回文当前覆盖位置的中心`x`。 

最大堆存储：$$2x + (-2c + 1)$$允许有效地获得在每个位置结束的最佳回文。 

将结果存储在：```
endBest[x]
```### 4. 转换为每个前缀中包含的最佳回文

 如果回文在位置结束`x`，那么它包含在后面的每个前缀中。 

所以：```
left[i] = max(left[i-1], endBest[i])
```现在`left[i]`表示完全在前缀内的最长回文`[0, i]`。 

### 5. 从每个位置开始计算最长回文

 从右到左应用对称过程。 

店铺：```
startBest[i]
```这是最长的回文，正好从`i`。 

### 6. 转换为每个后缀包含的最佳回文

 如果回文从位置开始`i`，它属于之前开始的每个后缀`i`。 

计算：```
right[i] = max(right[i+1], startBest[i])
```现在`right[i]`是后缀中完全包含的最长回文`[i, n-1]`。 

### 7. 评估每个分割

 对于每一次分割`i`和`i+1`：```
left[i] * right[i+1]
```取最大值。 

### 为什么它有效

 Manacher 算法保证每个奇数回文都由某个中心半径表示。 扫描线计算得出在每个位置结束或开始的最大回文长度，而无需显式枚举所有回文。 然后，前缀和后缀最大值确保对于每个分割位置，我们都知道最好的回文完全位于左侧和完全位于右侧。 由于每对有效的非重叠回文都必须通过某种分割来分隔，因此检查所有分割可以保证找到最大的乘积。 
蛮力方法将迭代所有可能的子串对`(s[i:j+1], s[k:l+1])`，检查它们是否是奇数长度回文，确保它们不重叠，并计算它们长度的乘积。 这种方法是正确的，但不可行，因为对于长度为`n`，子串的数量为`O(n^2)`，检查子串是否是回文是`O(n)`。 这导致总时间复杂度大约为`O(n^4)`。 

### 最佳方法

 关键的观察是我们只需要**奇数长度回文**，这允许我们使用**Manacher算法**来找到以每个字符为中心的最大奇数长度回文`O(n)`时间。 一旦我们有了以每个索引为中心的最长回文，我们就可以预先计算两个数组：

 1.`left[i]`：在索引处或之前结束的最长奇数长度回文的长度`i`。 
2.`right[i]`：从索引处或之后开始的最长奇数长度回文的长度`i`。 

然后，对于字符串中每个可能的分割点，最大乘积为`left[i] * right[i+1]`。 这将问题减少到初始回文计算后的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 检查所有子串对 |
 | 最佳| O(n) | O(n) | 使用 Manacher 算法和前缀/后缀最大数组 |

 ## 算法演练

 1.使用**Manacher算法**进行计算`odd_pal_len[i]`对于每个中心`i`，它表示以`i`。 
2. 初始化数组`left_max`和`right_max`尺寸的`n`。`left_max[i]`将保存在或之前结束的最长奇数长度回文的长度`i`。`right_max[i]`将保存从 或之后开始的最长奇数长度回文的长度`i`。 
3. 迭代字符串进行填充`left_max`。 对于每个以`i`有半径`r`，更新该回文覆盖的所有索引的最大长度。 
4.同样，向后迭代填充`right_max`。 
5. 通过迭代所有分割点来计算最大乘积`i`从`0`到`n-2`并计算`left_max[i] * right_max[i+1]`。 
6. 返回最大乘积。 

**为什么有效：** Manacher 算法保证我们知道线性时间内以每个索引为中心的最大回文。 使用前缀和后缀最大数组可确保对于任何分割，我们都可以有效地计算两个不相交回文的最大乘积。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)

        # Manacher for odd palindromes
        d = [0] * n
        l = 0
        r = -1

        for i in range(n):
            k = 1 if i > r else min(d[l + r - i], r - i + 1)

            while (
                i - k >= 0
                and i + k < n
                and s[i - k] == s[i + k]
            ):
                k += 1

            d[i] = k

            if i + k - 1 > r:
                l = i - k + 1
                r = i + k - 1

        # longest palindrome ending at each position
        add_end = [[] for _ in range(n)]
        remove_end = [[] for _ in range(n + 1)]

        for c, rad in enumerate(d):
            start = c
            end = c + rad - 1

            add_end[start].append(c)

            if end + 1 < len(remove_end):
                remove_end[end + 1].append(c)

        heap = []
        removed = {}

        end_best = [1] * n

        for pos in range(n):
            for c in add_end[pos]:
                value = -2 * c + 1
                heapq.heappush(heap, (-value, c))

            for c in remove_end[pos]:
                removed[c] = removed.get(c, 0) + 1

            while heap:
                _, c = heap[0]
                if removed.get(c, 0):
                    removed[c] -= 1
                    heapq.heappop(heap)
                else:
                    break

            if heap:
                value = -heap[0][0]
                end_best[pos] = 2 * pos + value

        left = [0] * n
        left[0] = end_best[0]

        for i in range(1, n):
            left[i] = max(left[i - 1], end_best[i])

        # longest palindrome starting at each position
        add_start = [[] for _ in range(n)]
        remove_start = [[] for _ in range(n + 1)]

        for c, rad in enumerate(d):
            start = c - rad + 1
            end = c

            add_start[end].append(c)

            if start - 1 >= 0:
                remove_start[start - 1].append(c)

        heap = []
        removed = {}

        start_best = [1] * n

        for pos in range(n - 1, -1, -1):
            for c in add_start[pos]:
                value = 2 * c + 1
                heapq.heappush(heap, (-value, c))

            for c in remove_start[pos]:
                removed[c] = removed.get(c, 0) + 1

            while heap:
                _, c = heap[0]
                if removed.get(c, 0):
                    removed[c] -= 1
                    heapq.heappop(heap)
                else:
                    break

            if heap:
                value = -heap[0][0]
                start_best[pos] = value - 2 * pos

        right = [0] * n
        right[-1] = start_best[-1]

        for i in range(n - 2, -1, -1):
            right[i] = max(right[i + 1], start_best[i])

        answer = 0

        for i in range(n - 1):
            answer = max(answer, left[i] * right[i + 1])

        return answer
```### 实现说明

 第一部分实现 Manacher 算法并计算每个中心周围的最大奇数回文半径。 这提供了线性时间内的所有回文信息。 

下一次扫描计算`end_best`。 每个回文都贡献一个线性函数，描述在每个可到达位置结束的最大回文。 堆维护当前活动的中心，允许有效地检索最大值。 

前缀最大传递将这些精确的结束长度转换为`left[i]`，每个前缀中完全包含的最佳回文。 

然后从右到左镜像该过程来计算`start_best`，后跟后缀最大传递以产生`right[i]`。 

最后，评估每个分割位置。 左侧有贡献`left[i]`, 右侧贡献`right[i+1]`，并返回最大的乘积。

| --- | --- |

| Position | right |
| --- | --- |

func maxProduct(s string) int64 {
    n := len(s)
    oddLen := make([]int, n)
    center, right := 0, 0

    for i := 0; i < n; i++ {
        mirror := 2*center - i
        if i < right {
            if oddLen[mirror] < right-i {
                oddLen[i] = oddLen[mirror]
            } else {
                oddLen[i] = right - i
            }
        }
        a, b := i-oddLen[i]-1, i+oddLen[i]+1
        for a >= 0 && b < n && s[a] == s[b] {
            oddLen[i]++
            a--
            b++
        }
        if i+oddLen[i] > right {
            center, right = i, i+oddLen[i]
        }
    }

    leftMax := make([]int, n)
    rightMax := make([]int, n)

    for i := 0; i < n; i++ {
        length := 2*oddLen[i] + 1
        start := i - oddLen[i]
        end := i + oddLen[i]
        if leftMax[end] < length {
            leftMax[end] = length
        }
        if rightMax[start] < length {
            rightMax[start] = length
        }
    }

    for i := 1; i < n; i++ {
        if leftMax[i] < leftMax[i-1] {
            leftMax[i] = leftMax[i-1]
        }
    }
    for i := n - 2; i >= 0; i-- {
        if rightMax[i] < rightMax[i+1] {
            rightMax[i] = rightMax[i+1]
        }
    }

    var maxProd int64
    for i := 0; i < n-1; i++ {
        prod := int64(leftMax[i] * rightMax[i+1])
        if prod > maxProd {
            maxProd = prod
        }
    }
    return maxProd
}

 ## 边缘情况

 ### 所有字符都不同

 考虑：```
"abcdef"
```每个奇回文都有长度`1`。 有缺陷的实现可能会假设较长的回文总是存在，或者当仅存在琐碎的回文时会失败。 该解决方案用回文长度初始化每个位置`1`，保证有效答案`1`。 

### 大型重叠回文

 考虑：```
"aaaaaaa"
```许多大回文相互重叠。 最佳答案不一定是通过选择两个最大的回文来获得，因为它们可能相交。 通过独立评估每个拆分位置，实现会自动强制执行不重叠的要求。 

### 回文触及边界

 考虑：```
"abac"
```回文`"aba"`从索引开始`0`。 错误处理间隔边界的算法通常会丢失触及字符串开头或结尾的回文。 Manacher 半径计算显式跟踪左右限制，因此可以正确处理边界回文。 

### 整个字符串是回文

 考虑：```
"racecar"
```最大的回文几乎跨越整个字符串。 但是，它不能与另一个不重叠的回文配对。 前缀/后缀分解确保只有完全包含在拆分相对侧的回文才会相乘，从而防止无效重叠。
