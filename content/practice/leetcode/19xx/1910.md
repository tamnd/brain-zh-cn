[LeetCode 1910 题](https://leetcode.com/problems/remove-all-occurrences-of-a-substring/)

 **难度：** 🟡 中等
 **主题：** 字符串、堆栈、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们重复删除出现的子字符串`part`从字符串`s`。 重要的细节是，在每个操作中，我们必须删除**最左边**出现的`part`。 我们将继续执行移除操作，直到`part`不再出现在里面的任何地方`s`。 

简单来说，我们扫描字符串，一次删除一个匹配的子字符串，并继续这样做，直到字符串不再包含目标模式。 

例如，如果：```
s = "daabcbaabcbc"
part = "abc"
```第一个`"abc"`出现在索引处`2`，因此删除它会产生：```
"dabaabcbc"
```删除后，可能会出现新的字符，因为之前分开的字符现在可以变得相邻。 这是问题中的关键挑战。 

输入由两个小写英文字符串组成：

 -`s`, 原始字符串
 -`part`，我们重复删除的子字符串

 输出是所有删除完成后的最终字符串。 

限制条件是：```
1 <= s.length <= 1000
1 <= part.length <= 1000
```这些限制相对较小，这意味着即使是效率较低的解决方案也可能通过。 然而，该问题旨在奖励更清洁、更高效的模拟方法。 

一些边缘情况很重要：

 - 删除一个事件可能会跨越边界创建另一个事件。 
-`part`可能与自身重叠。 
- 整个字符串可能会消失。 
-`part`可能永远不会出现。 
-`part`可以是长度`1`，这意味着必须删除每个匹配的字符。 

如果重复扫描和重建字符串，简单的实现很容易变得低效。 

## 方法

 ### 蛮力方法

 最直接的解决办法就是反复搜索最左边出现的`part`里面`s`。 

在每次迭代时：

 1. 查找索引`part`在`s`2. 如果不存在任何情况，则停止
 3. 否则，删除该子字符串
 4. 重复

 在Python中，这可以使用以下方式实现`find()`和字符串切片。 

这种方法是正确的，因为它完全遵循问题陈述中描述的规则。 每次迭代都会删除最左边的出现点，直到没有出现为止。 

然而，重复搜索和重建字符串可能会变得昂贵。 每次搜索可能需要`O(n)`时间，每次删除都会创建一个新的大小的字符串`O(n)`。 在最坏的情况下，我们可能会进行多次删除。 

### 基于堆栈的最佳方法

 关键的观察是我们只需要检查字符串的最近构建的部分是否以`part`。 

我们不是重复地重新扫描整个字符串，而是一个接一个地处理字符，并使用类似堆栈的结构逐步构建答案。 

对于每个角色：

 1.将其追加到当前结果中
 2、检查当前结果末尾是否匹配`part`3. 如果有，请立即删除这些字符

 这是有效的，因为先前删除创建的任何新出现都必须出现在添加新字符的边界附近。 

通过持续维护有效的部分结果，我们可以避免重复的全字符串重新扫描。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 反复搜索并重建字符串 |
 | 最佳| O(n × m) | O(n) | 使用堆栈并仅检查最近的字符 |

 这里：

-`n = len(s)`-`m = len(part)`因为约束只是`1000`，堆栈解决方案很容易足够快。 

## 算法演练

 ### 最佳基于堆栈的算法

 1. 创建一个空的堆栈结构。 

我们使用堆栈来存储当前处理的字符串的字符。 这允许高效的追加和删除操作。 
2. 遍历每个字符`s`。 

我们从左到右处理输入，因为问题总是首先删除最左边的出现。 
3. 将当前字符追加到堆栈中。 

这模拟了增量构建结果字符串。 
4.追加后检查栈尾是否匹配`part`。 

由于只有新添加的字符才能创建新的出现，因此我们只需将当前堆栈的后缀与`part`。 
5.如果后缀匹配`part`，删除最后一个`len(part)`人物。 

这模拟子字符串出现后立即将其删除。 
6. 继续处理，直到处理完所有字符。 
7. 将剩余的堆栈字符加入到最终的字符串中并返回。 

### 为什么它有效

 该算法保持一个不变量：

 > 处理完每个字符后，堆栈将包含删除所有出现的正确字符串`part`来自已处理的前缀。 

每当有新的情况发生时`part`出现时，它必须以当前字符结束，因为较早出现的字符已被删除。 通过立即删除匹配的后缀，堆栈始终保持有效。 

这保证了最终的堆栈正是所需的答案。 

## Python 解决方案```python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        stack = []
        part_length = len(part)

        for char in s:
            stack.append(char)

            if len(stack) >= part_length:
                if "".join(stack[-part_length:]) == part:
                    del stack[-part_length:]

        return "".join(stack)
```该实现使用列表作为堆栈，因为Python列表支持高效的从末尾追加和删除。 

我们首先存储长度`part`以避免重复重新计算。 

对于每一个角色`s`，我们将其附加到堆栈中。 添加后，我们检查最近的字符是否构成子字符串`part`。 

表达式：```python
stack[-part_length:]
```提取当前堆栈的后缀。 如果匹配的话`part`，我们立即使用以下方法删除这些字符：```python
del stack[-part_length:]
```最后，我们将所有剩余的字符连接到最终的字符串中。 

该实现直接遵循前面描述的算法并有效地维护了部分处理的结果。 

## 解决方案```go
func removeOccurrences(s string, part string) string {
    stack := make([]byte, 0)
    partLen := len(part)

    for i := 0; i < len(s); i++ {
        stack = append(stack, s[i])

        if len(stack) >= partLen {
            match := true

            for j := 0; j < partLen; j++ {
                if stack[len(stack)-partLen+j] != part[j] {
                    match = false
                    break
                }
            }

            if match {
                stack = stack[:len(stack)-partLen]
            }
        }
    }

    return string(stack)
}
```Go 实现使用`[]byte`切片作为堆栈，因为 Go 中的字符串是不可变的。 

附加字符的效率很高`append`，并使用切片截断来删除后缀：```go
stack = stack[:len(stack)-partLen]
```与 Python 不同，Go 不方便地提供直接的字符串切片比较，因此我们在循环中手动比较字符。 

由于问题仅包含小写英文字母，因此使用字节是完全安全且高效的。

 ## 边缘情况

 当删除子字符串在删除部分的边界上创建一个新的出现时，就会出现一种重要的边缘情况。 例如：```
s = "abababa"
part = "aba"
```删除第一个后`"aba"`，其余字符变得相邻并形成另一个出现。 没有正确继续检查的幼稚实现可能会错过这一点。 堆栈方法自然地处理这个问题，因为每个新形成的后缀都会立即检查。 

另一个棘手的情况是当`part`仅包含一个字符。 例如：```
s = "banana"
part = "a"
```每个事件都必须单独删除。 某些实现错误地假设子字符串长度大于一。 堆栈方法仍然可以正常工作，因为后缀检查长度`1`是有效的。 

第三个重要的边缘情况是重叠模式，例如：```
s = "aaaaa"
part = "aa"
```事件严重重叠。 如果未按照从左到右的顺序仔细处理删除，则可能会出现不正确的结果。 堆栈解决方案会在最左边的出现项形成后立即将其正确删除，从而保留问题陈述定义的预期行为。
