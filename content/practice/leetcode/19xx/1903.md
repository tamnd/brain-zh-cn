[LeetCode 问题 1903](https://leetcode.com/problems/largest-odd-number-in-string/)

 **难度：** 🟢简单
 **主题：** 数学、字符串、贪心

 ## 解决方案

 ## 问题理解

 该问题要求我们从给定的字符串中找到最大值的奇整数子串`num`代表一个大整数。 这里，**子字符串**是任意连续的字符序列`num`。 我们必须将子字符串本身作为字符串返回，如果不存在奇数则返回空字符串`num`。 

例如，如果`num = "35427"`，整个字符串本身已经是奇数了，因为它的最后一位数字`7`很奇怪。 为了`num = "4206"`，所有数字都不是奇数，因此不存在奇数，结果为空字符串。 

输入约束很重要。 长度为`num`最多可达 100,000 位数字，因此任何显式检查所有可能子字符串的算法都会太慢。 每个子串最多可达`n`数字，子串的数量是 O(n²)，这是不可行的。 

边缘情况包括全部为偶数数字的字符串、具有单个奇数数字的字符串、开头或结尾为奇数的字符串以及达到最大长度的非常大的字符串。 

## 方法

 **暴力方法**是生成所有可能的子字符串，检查每个子字符串是否代表奇数，并跟踪最大的子字符串。 这工作正常，因为我们检查每个候选者，但它太慢：对于长度的字符串`n`，有 O(n²) 个子串，每个子串比较的时间复杂度为 O(n)，时间复杂度为 O(n³)。 这对于`n`最多 10⁵。 

**最佳方法**利用了这样的观察：当且仅当一个数字的最后一位数字是奇数时，该数字才是奇数。 从中找到最大的奇数子串`num`，我们可以简单地从右侧截断数字，直到最后一位数字变为奇数。 这是可行的，因为删除尾随数字只会减少数字的值，而我们想要最大可能的子字符串。 本质上，答案是最长的前缀`num`以奇数结尾。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 生成所有子字符串并检查是否为奇数 |
 | 最佳| O(n) | O(1) | O(1) | 从尾开始扫描找到最后一个奇数，返回前缀 |

 ## 算法演练

 1.从字符串的最后一个字符开始`num`。 目标是找到最右边的奇数位。 
2. 向后迭代`num`。 对于每个字符，检查它是否是奇数（`'1'`,`'3'`,`'5'`,`'7'`,`'9'`）。 
3. 一旦遇到奇数位，就记录它的索引。 该索引表示最大奇数子串的末尾。 
4. 返回从开头开始的子字符串`num`直至并包括该索引。 如果没有找到奇数位，则返回空字符串。 
5. 由于我们只从末尾扫描一次，因此该算法运行时间为 O(n)，并使用 O(1) 额外空间。 

**为什么有效：** 最大的奇数必须以该数字的最后一个奇数位结束，因为任何偶数位的后缀都不能增加该值。 截断尾随偶数位可确保我们在满足奇数条件的同时获得最大值。 

## Python 解决方案```python
class Solution:
    def largestOddNumber(self, num: str) -> str:
        # Scan from the end to find the last odd digit
        for i in range(len(num) - 1, -1, -1):
            if num[i] in '13579':
                return num[:i+1]  # Return prefix including this odd digit
        return ""  # No odd digit found
```实现完全遵循算法。 我们向后迭代`num`，检查每个字符是否奇怪。 一旦找到，我们就返回从开始到该位置的子字符串。 如果不存在奇数位，则该函数返回空字符串。 

## 解决方案```go
func largestOddNumber(num string) string {
    for i := len(num) - 1; i >= 0; i-- {
        if num[i] == '1' || num[i] == '3' || num[i] == '5' || num[i] == '7' || num[i] == '9' {
            return num[:i+1]
        }
    }
    return ""
}
```在 Go 中，我们使用类似的方法。 该循环从字符串末尾迭代到开头，根据奇数位组检查每个字节。 子串切片`num[:i+1]`产生最大的奇数。 不用担心整数溢出，因为我们操作的是字符串，而不是数字类型。

 ## 边缘情况

 **所有数字都是偶数：** 对于像这样的输入`"4206"`或者`"222222"`，没有奇数，因此该函数通过扫描所有数字而没有找到奇数来正确返回空字符串。 

**单字符字符串：** 必须正确处理长度为1的字符串。`"7"`回报`"7"`,`"8"`回报`""`。 在没有特殊情况的情况下，实现自然会处理这个问题，因为循环仍然可以正确迭代。 

**大输入字符串：** 由于输入高达 10⁵ 位，效率至关重要。 线性扫描可确保快速完成求解，即使字符串包含 100,000 个字符（无论是全偶数还是以奇数结尾）。 该算法避免了子字符串生成和数字转换，这可能是昂贵的。
