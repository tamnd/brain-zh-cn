[LeetCode 第 1283 题](https://leetcode.com/problems/find-the-smallest-divisor-given-a-threshold/)

 **难度：** 🟡 中等
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定数组的最小正整数除数`nums`这样当数组的每个元素除以该除数时，这些除法的上限之和不超过给定的`threshold`。 换句话说，对于每个`num`在`nums`，我们计算`ceil(num / divisor)`，对这些结果求和，并确保总和小于或等于`threshold`。 我们的目标是尽量减少`divisor`。 

输入由整数数组组成`nums`和一个整数`threshold`。 中的每个元素`nums`介于`1`和`10^6`，和长度`nums`可以达到`5 * 10^4`。 阈值至少与数组长度一样大，并且可以高达`10^6`。 这意味着尝试每个可能的除数的简单方法可能会太慢，特别是因为除数的范围可能是`1`到`max(nums)`。 

边缘情况包括等于长度的阈值`nums`（强制除数非常大以将所有除法减少到 1）和具有所有相同元素的数组。 该问题保证总有解决方案，因此我们不需要处理没有有效除数的情况。 

## 方法

 蛮力方法是尝试从 1 到 1 的所有可能的除数`max(nums)`。 对于每个除数，我们计算除法的上限之和。 总和小于或等于的第一个除数`threshold`是我们的答案。 虽然正确，但这种方法对于大输入来说太慢了，因为它可能需要`O(max(nums) * n)`运营。 

最佳方法利用**二分搜索**。 关键的见解是，上限除法的总和是除数的单调递减函数：随着除数的增加，总和减少。 这使我们能够使用 1 和 1 之间的二分搜索有效地搜索最小除数`max(nums)`。 在每一步中，我们计算中间除数的总和并相应地调整我们的搜索范围。

 | 蛮力 | O(n * 最大(nums)) | O(1) | O(1) | 检查从 1 到 max(nums) | 的每个除数

 ## 算法演练

 1. 确定搜索范围。 最小可能的除数是 1，最大的除数是`max(nums)`。 
2. 定义一个辅助函数来计算给定除数的上限除法总和。 对于每个元素`num`在`nums`, 计算`ceil(num / divisor)`，可以实现为`(num + divisor - 1) // divisor`以避免浮点运算。 
3. 执行二分查找：

 1. 计算中点`mid`当前范围。 
2. 使用辅助函数计算上限除法的总和。 
3. 如果总和超过`threshold`，这意味着除数太小。 将新的下限设置为`mid + 1`。 
4. 如果总和在`threshold`，这意味着除数可能有效，但可能存在更小的有效除数。 将新的上限设置为`mid - 1`并记录`mid`作为候选答案。 
4. 继续直到搜索范围收敛。 
5. 返回找到的最小除数。 

**为什么起作用：** sum 函数的单调性确保一旦除数产生阈值内的和，所有较大的除数也将满足阈值。 二分查找保证我们有效地找到最小的除数。 

## Python 解决方案```python
from typing import List

class Solution:
    def smallestDivisor(self, nums: List[int], threshold: int) -> int:
        def compute_sum(divisor: int) -> int:
            return sum((num + divisor - 1) // divisor for num in nums)

        left, right = 1, max(nums)
        result = right

        while left <= right:
            mid = (left + right) // 2
            if compute_sum(mid) <= threshold:
                result = mid
                right = mid - 1
            else:
                left = mid + 1

        return result
```辅助函数`compute_sum`使用整数算术有效地计算上限除法和。 二分查找根据当前是否存在来调整搜索范围`mid`满足阈值。 变量`result`跟踪找到的最小有效除数。 

## 解决方案```go
func smallestDivisor(nums []int, threshold int) int {
    computeSum := func(divisor int) int {
        sum := 0
        for _, num := range nums {
            sum += (num + divisor - 1) / divisor
        }
        return sum
    }

    left, right := 1, 0
    for _, num := range nums {
        if num > right {
            right = num
        }
    }
    result := right

    for left <= right {
        mid := (left + right) / 2
        if computeSum(mid) <= threshold {
            result = mid
            right = mid - 1
        } else {
            left = mid + 1
        }
    }

    return result
}
```在 Go 中，我们定义了一个闭包`computeSum`计算上限除法和。 我们还处理计算`max(nums)`手动。 二分搜索逻辑反映了 Python 版本，确保行为差异最小。

 | 4 | 1+1+2+3=7 | 7 > 6 | 7 > 6
 | 5 | 1+1+1+2=5 | 5 <= 6 | 5 <= 6 |

 | 44 | 44 1+1+1+1+1=5 |
 | 43 | 43 2+1+1+1+1=6 |

 满足阈值的最小除数是`44`。

 ## 边缘情况

 1. **单元素数组**：当`nums`仅包含一个元素，最小除数为 1 或元素本身，具体取决于`threshold`。 该实现通过二分搜索自然地处理它。 
2. **阈值等于数组长度**：如果`threshold == len(nums)`，每次除法的结果必须是上限后的 1，迫使除数至少为`max(nums)`。 二分查找可以有效地找到这一点。 
3. **大数**：包含元素最多的数组`10^6`需要仔细的整数运算以避免浮点错误。 使用`(num + divisor - 1) // divisor`确保使用整数进行准确的上限除法。 

该解决方案通过利用二分搜索求和函数的单调性，有效处理所有边缘情况并保证正确性。
