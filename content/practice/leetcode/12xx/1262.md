[LeetCode 第 1262 题](https://leetcode.com/problems/greatest-sum-divisible-by- Three/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、贪心、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们找到整数数组中元素的最大和`nums`使得总和可以被三整除。 换句话说，我们可以从数组中选择任何数字子集，我们的目标是在模 3 的和等于 0 的条件下最大化该子集的和。`nums`元素范围从 1 到 10,000 个，最多可达 40,000 个元素，因此任何尝试所有子集的强力方法在计算上都是不可行的。 

这些约束意味着，由于指数复杂性，检查每个子集的简单解决方案并不实用。 该问题保证所有元素都是正整数，因此总和始终为非负数。 要考虑的边缘情况包括任何数字组合都不能被三整除的数组、具有单个元素的数组以及所有元素都可以被三整除的数组。 

## 方法

 蛮力方法将涉及生成所有可能的子集`nums`，计算每个子集的总和，并检查它是否可以被三整除。 虽然这保证了正确的答案，但时间复杂度为 O(2^n)，这对于输入约束（最多 40,000 个元素）来说太慢了。 

更优化解决方案的关键观察基于模运算。 任何模 3 的数字都可以是 0、1 或 2。为了最大化可被 3 整除的和，我们可以在迭代数组时保持余数为 0、1 和 2 的最大和。 对于每个数字，我们考虑将其添加到每个余数的现有总和中，并更新每个余数的最大可能总和。 这种方法利用动态编程并确保我们只存储三个变量，从而为我们提供了线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成所有子集，对它们求和，然后选择可被 3 整除的最大子集 |
 | 最佳 | O(n) | O(1) | O(1) | 使用具有三个变量的动态规划来跟踪模 3 的最大和 |

 ## 算法演练

 1.初始化一个数组`dp`尺寸 3 的`dp[0] = 0`和`dp[1] = dp[2] = -inf`。 该数组将存储余数 0、1 和 2 的最大和。 
2. 迭代每个数字`num`在`nums`。 
3. 对于每个号码，创建当前号码的临时副本`dp`数组称为`new_dp`。 
4. 对于每个余数`r`在 {0, 1, 2} 中，计算潜在的新总和`dp[r] + num`。 
5. 确定该新和模 3 的余数。 
6. 更新`new_dp[new_remainder]`是其当前值与新值之和的最大值。 
7. 处理完所有余数后，设置`dp = new_dp`。 
8. 迭代完所有数字后，`dp[0]`将包含可被三整除的最大总和。 

**为什么有效：** 这是有效的，因为在每一步中，我们都会考虑将当前数字添加到先前计算的每个余数的总和中的所有可能性。 通过仅保留每个余数的最大和，我们确保最优性并避免冗余计算。 模 3 运算保证我们正确跟踪可被 3 整除的和。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxSumDivThree(self, nums: List[int]) -> int:
        dp = [0, float('-inf'), float('-inf')]
        for num in nums:
            new_dp = dp[:]
            for r in range(3):
                new_sum = dp[r] + num
                new_dp[new_sum % 3] = max(new_dp[new_sum % 3], new_sum)
            dp = new_dp
        return dp[0]
```Python 实现初始化一个`dp`数组来跟踪每个余数模 3 的最大和。对于中的每个数字`nums`，它计算潜在的新总和并更新每个余数的最大值。 在最后，`dp[0]`包含可被 3 整除的最大总和。使用`float('-inf')`确保我们正确处理最初无法形成某些余数的和。 

## 解决方案```go
func maxSumDivThree(nums []int) int {
    dp := [3]int{0, -1 << 60, -1 << 60}
    for _, num := range nums {
        newDp := dp
        for r := 0; r < 3; r++ {
            newSum := dp[r] + num
            if newSum > newDp[newSum%3] {
                newDp[newSum%3] = newSum
            }
        }
        dp = newDp
    }
    return dp[0]
}
```在 Go 中，我们使用大小为 3 的数组来跟踪每个余数的最大和。 负无穷大表示为`-1 << 60`安全地处理大额负数。 该逻辑反映了 Python 的方法，但使用了 Go 特定的语法和切片处理。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个数字都被处理一次，我们更新三个余数 |
 | 空间| O(1) | O(1) | 无论输入大小如何，仅存储三个值 |

 线性时间复杂度的产生是因为我们迭代数组一次并对每个元素执行恒定的工作。 空间复杂度是恒定的，因为我们只跟踪三个最大和。

 ## 边缘情况

 一种重要的边缘情况是数组只有一个元素。 如果该元素能被 3 整除，则结果是该元素本身； 否则，它为零。 当所有元素具有相同的模 3 余数时，会出现另一种边缘情况。该算法利用动态编程更新，正确组合或跳过元素以形成可被 3 整除的和。 第三种边缘情况涉及数量接近 10,000 的大型数组。 该算法可以有效地处理这个问题，因为它只维护三个总和，并避免构建任何大型子集或存储所有可能的总和。
