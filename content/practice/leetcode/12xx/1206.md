 ## 解决方案

 ## 问题理解

 这个问题要求我们从头开始实现一个 **Skiplist**，这是一种允许高效搜索、插入和删除操作的概率数据结构。 跳过列表由多个级别的排序链表组成，其中每个较高级别充当“快速通道”以跳过较低级别中的多个元素。 最底层包含按排序顺序排列的所有元素，而较高级别包含越来越稀疏的元素子集。 

输入由对方法的调用组成`Skiplist`类，例如`add`,`search`， 和`erase`。 每个操作都可以修改数据结构或返回指示值是否存在的布尔值。 预期输出是操作结果的序列，例如`True`或者`False`用于搜索和擦除。 

约束表明操作次数最多可达`5 * 10^4`，并且值的范围介于`0`和`2 * 10^4`。 这排除了每个操作的简单线性搜索或插入，因为每个操作的 O(n) 对于上限来说太慢了。 此外，允许重复，因此跳跃列表必须支持同一数字多次出现。 

重要的边缘情况包括插入重复值、删除列表中不存在的数字、搜索当前范围之外的数字以及处理空的跳跃列表。 

## 方法

 **暴力方法**是使用标准的排序链表。 要添加数字，我们从头部开始遍历以找到正确的位置。 如果元素不存在，搜索或擦除还需要遍历整个列表。 虽然这种方法是正确的，但每次操作都需要 O(n) 时间，考虑到限制，这太慢了。 

**最佳方法**使用具有多个级别的跳表结构。 每个节点都包含不同级别的前向指针数组。 较高级别允许跳过较低级别中的多个节点。 关键的见解是，通过随机选择节点级别（例如，概率为 0.5），预期级别数为 O(log n)。 这允许搜索、插入和删除在预期的 O(log n) 时间内运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 标准排序链表，线性遍历 |
 | 最佳 | O(log n) | O(n) | 具有随机级别分配、预期对数时间的跳表 |

 ## 算法演练

 1. **节点结构**：每个节点包含一个值和一个前向指针数组，节点占据的每一层都有一个前向指针。 头节点具有最大级别数。 
2. **随机级别生成**：对于插入，我们使用几何分布生成随机级别，其中每个级别被添加的概率为 0.5。 这确保了平均对数高度。 
3. **查找操作**：从头节点最顶层开始查找。 当下一个节点的值小于目标时继续前进。 下降一层并重复，直到到达底部。 如果节点的值与目标匹配，则返回 True； 否则，返回 False。 
4. **添加操作**：类似于搜索的遍历，同时保持一个`update`数组，存储插入点之前每一层的最后一个节点。 为新节点生成随机级别，更新前向指针，并在所有适当的级别插入新节点。 
5. **擦除操作**：类似遍历`add`来填补`update`大批。 如果目标节点存在，则更新前向指针以跳过它。 如有必要，调整当前最大级别。 

**为什么有效**：跳跃列表在每个级别都保持排序顺序。 这`update`array 确保前向指针在插入或删除期间始终正确更新。 随机级别确保操作平均运行时间为 O(log n)。 

## Python 解决方案```python
import random

class Node:
    def __init__(self, val: int, level: int):
        self.val = val
        self.forward = [None] * (level + 1)

class Skiplist:

    MAX_LEVEL = 16
    P = 0.5

    def __init__(self):
        self.head = Node(-1, self.MAX_LEVEL)
        self.level = 0

    def random_level(self) -> int:
        lvl = 0
        while random.random() < self.P and lvl < self.MAX_LEVEL:
            lvl += 1
        return lvl

    def search(self, target: int) -> bool:
        current = self.head
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].val < target:
                current = current.forward[i]
        current = current.forward[0]
        return current is not None and current.val == target

    def add(self, num: int) -> None:
        update = [None] * (self.MAX_LEVEL + 1)
        current = self.head
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].val < num:
                current = current.forward[i]
            update[i] = current
        lvl = self.random_level()
        if lvl > self.level:
            for i in range(self.level + 1, lvl + 1):
                update[i] = self.head
            self.level = lvl
        new_node = Node(num, lvl)
        for i in range(lvl + 1):
            new_node.forward[i] = update[i].forward[i]
            update[i].forward[i] = new_node

    def erase(self, num: int) -> bool:
        update = [None] * (self.MAX_LEVEL + 1)
        current = self.head
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].val < num:
                current = current.forward[i]
            update[i] = current
        current = current.forward[0]
        if current is None or current.val != num:
            return False
        for i in range(self.level + 1):
            if update[i].forward[i] != current:
                continue
            update[i].forward[i] = current.forward[i]
        while self.level > 0 and self.head.forward[self.level] is None:
            self.level -= 1
        return True
```**解释**：`Node`类存储值和前向指针。 这`Skiplist`管理头节点、当前级别和最大级别。`random_level`决定新节点应占据多少层。`search`从上到下遍历。`add`在每一层更新前向指针时插入。`erase`删除节点同时保持跳表结构。 

## 解决方案```go
package main

import (
    "math/rand"
    "time"
)

type Node struct {
    val     int
    forward []*Node
}

type Skiplist struct {
    head  *Node
    level int
}

const MAX_LEVEL = 16
const P = 0.5

func Constructor() Skiplist {
    rand.Seed(time.Now().UnixNano())
    head := &Node{-1, make([]*Node, MAX_LEVEL+1)}
    return Skiplist{head: head, level: 0}
}

func randomLevel() int {
    lvl := 0
    for rand.Float64() < P && lvl < MAX_LEVEL {
        lvl++
    }
    return lvl
}

func (this *Skiplist) Search(target int) bool {
    current := this.head
    for i := this.level; i >= 0; i-- {
        for current.forward[i] != nil && current.forward[i].val < target {
            current = current.forward[i]
        }
    }
    current = current.forward[0]
    return current != nil && current.val == target
}

func (this *Skiplist) Add(num int) {
    update := make([]*Node, MAX_LEVEL+1)
    current := this.head
    for i := this.level; i >= 0; i-- {
        for current.forward[i] != nil && current.forward[i].val < num {
            current = current.forward[i]
        }
        update[i] = current
    }
    lvl := randomLevel()
    if lvl > this.level {
        for i := this.level + 1; i <= lvl; i++ {
            update[i] = this.head
        }
        this.level = lvl
    }
    newNode := &Node{num, make([]*Node, lvl+1)}
    for i := 0; i <= lvl; i++ {
        newNode.forward[i] = update[i].forward[i]
        update[i].forward[i] = newNode
    }
}

func (this *Skiplist) Erase(num int) bool {
    update := make([]*Node, MAX_LEVEL+1)
    current := this.head
    for i := this.level; i >= 0; i-- {
        for current.forward[i] != nil && current.forward[i].val < num {
            current = current.forward[i]
        }
        update[i] = current
    }
    current = current.forward[0]
    if current == nil || current.val != num {
        return false
    }
    for i := 0; i <= this.level; i++ {
        if update[i].forward[i] != current {
            continue
        }
        update[i].forward[i] = current.forward[i]
    }
    for this.level > 0 && this.head.forward[this.level] == nil {
        this.level--
    }
    return true
}
```**关于 Go 的注释**：Go 使用切片而不是数组作为前向指针。 Nil 指针代表每个指针的结束
