[LeetCode 第 1246 题](https://leetcode.com/problems/palindrome-removal/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们从整数数组中删除所有元素`arr`在**最小移动次数**中，其中移动包括删除连续的**回文子数组**。 回文子数组向前和向后读取相同的内容。 删除子数组后，左侧和右侧的元素会移动以填充间隙。 

输入是一个整数数组，其中`1 <= arr.length <= 100`每个元素都在 1 到 20 之间。这个约束表明，尝试所有可能的删除序列的强力解决方案会太慢，因为潜在子数组的数量呈二次方增长，而序列的数量呈指数增长。 

预期输出是一个整数，即完全删除数组的最小移动次数。 重要的边缘情况包括长度为 1 的数组、所有元素都相同的数组（完全回文）以及没有两个相邻元素相等的数组（强制删除单个元素）。 

## 方法

 **暴力方法**将尝试所有可能的回文删除序列。 在每一步中，它都会尝试删除所有可能的回文子数组，递归计算结果数组的最小移动次数。 虽然这保证了正确的答案，但其时间复杂度是指数级的，这对于`arr.length = 100`。 

**最佳方法**依赖于动态规划。 定义`dp[i][j]`作为删除子数组的最小移动次数`arr[i:j+1]`。 关键的见解是，如果`arr[i] == arr[j]`，我们可以考虑在删除中间子数组后将两者一起删除`arr[i+1:j]`。 否则，我们会在某些时候分开`k`之间`i`和`j`，递归删除左右段。 通过存储子数组的结果，我们可以避免重新计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归尝试每个回文删除序列 |
 | 最佳 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 具有拆分和合并回文的子数组上的 DP |

 ## 算法演练

 1. 初始化一个2D数组`dp`尺寸的`n x n`在哪里`n = len(arr)`。 每个条目`dp[i][j]`表示要移除的最小移动次数`arr[i:j+1]`。 将所有值初始化为一个大数。 
2. 设置基本情况：`dp[i][i] = 1`因为单个元素可以一步移除。 
3. 迭代子数组长度从 2 到`n`。 
4. 对于每个子数组`arr[i:j+1]`，首先假设最后一个元素被单独删除，即`dp[i][j] = dp[i][j-1] + 1`。 
5.然后，迭代所有位置`k`从`i`到`j-1`。 如果`arr[k] == arr[j]`，考虑删除`arr[k+1:j]`首先并合并`arr[k]`和`arr[j]`。 更新`dp[i][j] = min(dp[i][j], dp[i][k-1] + dp[k+1][j-1])`。 处理`k=i`小心谨慎，避免越界。 
6. 填写表格后，`dp[0][n-1]`包含删除整个数组的最少移动次数。 

**为什么有效：** DP 确保对于每个子数组，我们都考虑通过拆分或合并匹配端来删除回文的所有方法。 通过从较小的子数组构建到较大的子数组，可以解决所有依赖关系，从而保证正确的最小值。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumMoves(self, arr: List[int]) -> int:
        n = len(arr)
        dp = [[0] * n for _ in range(n)]
        
        for i in range(n-1, -1, -1):
            dp[i][i] = 1
            for j in range(i+1, n):
                dp[i][j] = dp[i][j-1] + 1
                for k in range(i, j):
                    if arr[k] == arr[j]:
                        if k == i:
                            dp[i][j] = min(dp[i][j], dp[k+1][j-1] if k+1 <= j-1 else 0)
                        else:
                            dp[i][j] = min(dp[i][j], dp[i][k-1] + (dp[k+1][j-1] if k+1 <= j-1 else 0))
        return dp[0][n-1]
```**实现演练：**我们首先初始化`dp[i][i]`对于单元素子数组为 1。 对于较大的子数组，我们首先假设最后一个元素被单独删除。 然后我们迭代所有可能的位置`k`匹配最后一个元素，尝试有效地合并回文。 仔细处理边缘情况可确保不会出现索引错误。 

## 解决方案```go
func minimumMoves(arr []int) int {
    n := len(arr)
    dp := make([][]int, n)
    for i := 0; i < n; i++ {
        dp[i] = make([]int, n)
    }

    for i := n-1; i >= 0; i-- {
        dp[i][i] = 1
        for j := i + 1; j < n; j++ {
            dp[i][j] = dp[i][j-1] + 1
            for k := i; k < j; k++ {
                if arr[k] == arr[j] {
                    var middle int
                    if k+1 <= j-1 {
                        middle = dp[k+1][j-1]
                    } else {
                        middle = 0
                    }
                    if k == i {
                        if middle < dp[i][j] {
                            dp[i][j] = middle
                        }
                    } else {
                        if dp[i][k-1]+middle < dp[i][j] {
                            dp[i][j] = dp[i][k-1] + middle
                        }
                    }
                }
            }
        }
    }
    return dp[0][n-1]
}
```**Go 特定说明：** 我们使用切片来实现 2D DP 数组。 计算时仔细检查索引范围`middle`。 考虑到问题的限制，不必担心整数溢出。 

## 工作示例

 **示例1：**`arr = [1,2]`| 我| j | dp[i][j] | dp[i][j] |
 | ---| ---| ---|
 | 0 | 0 | 1 |
 | 1 | 1 | 1 |
 | 0 | 1 | dp[0][0] + 1 = 2 |

 输出：2

 **示例2：**`arr = [1,3,4,1,5]`| 我| j | dp[i][j] 计算 |
 | ---| ---| ---|
 | 0 | 0 | 1 |
 | 1 | 1 | 1 |
 | 2 | 2 | 1 |
 | 3 | 3 | 1 |
 | 4 | 4 | 1 |
 | 0 | 1 | dp[0][0] + 1 = 2 |
 | 1 | 3 | dp[1][2] + 1 = 2，然后合并arr[1]和arr[3]： dp[2][2]=1 -> dp[1][3]=1+1=2 |
 | 0 | 4 | 分别删除最后一个：dp[0][3]+1=3，合并arr[0]和arr[3]：dp[1][2]+0=2 -> min=3 |

 输出：3

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^3) | O(n^3) | 三重循环：子数组长度、起始索引和潜在的分割位置 |

 当 n ≤ 100 时，O(n^3) 时间是可以接受的，因为 1,000,000 次操作是可行的。
