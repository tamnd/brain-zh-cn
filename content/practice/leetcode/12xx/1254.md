 ## 问题理解

 该问题提供了一个表示陆地和水域地图的二维网格。 细胞具有`0`代表土地，单元格`1`代表水。 _岛屿_是水平或垂直（不是对角线）连接的任何连续的陆地区域。 _封闭岛_是指四个侧面（包括网格边缘）完全被水包围的岛屿。 

任务是计算给定网格中存在多少个封闭岛屿。 输入网格可以大到 100 x 100，这意味着简单的算法必须足够高效才能处理多达 10,000 个单元格。 该问题保证每个单元格要么是`0`或者`1`，所以我们不需要处理无效的单元格值。 

重要的边缘情况包括岛屿接触网格边缘的网格（它们无法闭合）、完全充满水的网格（无岛屿）以及可能形成也可能不形成闭合岛屿的单细胞网格。 

## 方法

 蛮力方法是迭代每个陆地单元（`0`）并执行深度优先搜索（DFS）或广度优先搜索（BFS）来探索整个连接的岛屿。 在探索时，我们跟踪岛屿的任何部分是否接触网格边界。 如果是，我们将其标记为未关闭； 否则，我们就计算它。 这种方法有效，但可能会不必要地重复遍历相同的单元格，如果不仔细实施，它可能会为访问的单元格使用额外的空间。 

最佳方法利用了任何接触边界的岛屿都不能关闭的观察结果。 我们首先淹没所有连接到边界的陆地单元，将它们标记为已访问或用水忽略它们。 在这个预处理步骤之后，我们迭代剩余的陆地单元。 这些单元中的每个 DFS/BFS 都保证是一个封闭岛。 这减少了不必要的检查并简化了逻辑。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m*n) | O(m*n) | 探索每一个陆地单元； 跟踪访问过的单元格； 在 DFS/BFS 期间检查边界 |
 | 最佳 | O(m*n) | O(m*n) | 洪水前填埋的边境连接土地； 其余岛屿全部关闭|

 ## 算法演练

 1. 迭代网格的所有边框单元格（顶行、底行、最左列、最右列）。 对于每个陆地单元（`0`），执行 DFS 将所有连接的土地标记为已访问或转换为水域（`1`）。 这确保了以后不会计算任何与边界相连的岛屿。 
2. 初始化计数器`closed_islands = 0`。 
3. 迭代网格的所有单元格。 对于每个未访问过的陆地单元（`0`），执行 DFS 将所有连接的土地标记为已访问并递增`closed_islands`反一。 
4. 返回`closed_islands`作为封闭岛屿的总数。 

为什么它有效：保持不变的是所有接触网格边缘的岛屿在计数之前都被删除。 因此，任何剩余的陆地岛屿都被水完全包围，符合闭岛定义。 DFS 确保在每一步中访问所有连接的陆地单元，从而保证没有岛屿被多次计数。 

## Python 解决方案```python
from typing import List

class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        
        def dfs(r: int, c: int):
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 1:
                return
            grid[r][c] = 1
            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)
        
        # Flood-fill border-connected lands
        for r in range(rows):
            dfs(r, 0)
            dfs(r, cols - 1)
        for c in range(cols):
            dfs(0, c)
            dfs(rows - 1, c)
        
        closed_islands = 0
        for r in range(1, rows - 1):
            for c in range(1, cols - 1):
                if grid[r][c] == 0:
                    dfs(r, c)
                    closed_islands += 1
        return closed_islands
```解释：`dfs`函数将所有连接的陆地单元标记为水以避免重新计数。 首先，所有与边境相连的陆地单元都被移除，确保只保留潜在的封闭岛屿。 然后，嵌套循环搜索剩余的陆地单元，并将每个孤立的 DFS 算作一个封闭的岛屿。 

## 解决方案```go
func closedIsland(grid [][]int) int {
    rows, cols := len(grid), len(grid[0])

    var dfs func(r, c int)
    dfs = func(r, c int) {
        if r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == 1 {
            return
        }
        grid[r][c] = 1
        dfs(r+1, c)
        dfs(r-1, c)
        dfs(r, c+1)
        dfs(r, c-1)
    }

    // Flood-fill border-connected lands
    for r := 0; r < rows; r++ {
        dfs(r, 0)
        dfs(r, cols-1)
    }
    for c := 0; c < cols; c++ {
        dfs(0, c)
        dfs(rows-1, c)
    }

    closedIslands := 0
    for r := 1; r < rows-1; r++ {
        for c := 1; c < cols-1; c++ {
            if grid[r][c] == 0 {
                dfs(r, c)
                closedIslands++
            }
        }
    }
    return closedIslands
}
```说明：Go 处理切片和 DFS 的方式与 Python 类似。 该函数使用递归来标记访问过的陆地单元。 Go 不需要内部函数的类型提示，索引和循环逻辑与 Python 方法保持一致。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m*n) | 在 DFS 泛洪填充和计数期间，每个单元最多被访问一次。 |
