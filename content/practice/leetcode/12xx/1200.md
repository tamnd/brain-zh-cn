[LeetCode 第 1200 题](https://leetcode.com/problems/minimum-absolute-difference/)

 **难度：** 🟢简单
 **主题：** 数组、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们找到数组中绝对差最小的所有数字对。 换句话说，给定一个不同整数的列表，我们想要识别每一对`[a, b]`使得差异`b - a`在数组中所有可能的对中最小化，并且我们总是首先列出较小的数字。 

输入`arr`是长度至少为 2 且最多 100,000 个元素的不同整数数组，每个元素的范围为 -1,000,000 到 1,000,000。 输出应该是列表的列表，其中每个内部列表都是一对`[a, b]`按值排序`a`，然后由`b`如果需要的话。 

需要注意的要点是数组具有**不同的元素**，因此我们不需要担心重复。 对输出对进行排序并正确处理负数非常重要。 边缘情况可能包括具有负数的数组、已排序的数组或仅具有两个元素（这是最小有效大小）的数组。 

## 方法

 蛮力方法将涉及比较所有可能的数字对以计算它们的绝对差。 这保证了正确性，因为我们评估每一对，但效率很低，因为它需要`O(n^2)`操作，这对于`n`最多 100,000。 

最佳方法依赖于一个关键观察：排序数组中的最小绝对差总是出现在**连续元素**之间。 这是因为任何非连续元素之间的差异至少与它们之间的连续元素之间的差异一样大。 因此，通过首先对数组进行排序，然后扫描连续的对，我们可以有效地找到最小差异。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 比较每一对找出最小差异 |
 | 最佳 | O(n log n) | O(n log n) | O(1) 或 O(n) | 对数组进行排序并检查连续差异 |

 ## 算法演练

 1. **对数组进行排序**：排序确保连续元素之间的差异尽可能小。 排序需要`O(n log n)`时间。 
2. **初始化跟踪变量**：创建变量`min_diff`设置为一个非常大的值和一个空列表`result`来存储对。 
3. **迭代连续元素**：使用索引循环遍历数组`i`从 0 到`len(arr) - 2`。 对于每对`(arr[i], arr[i+1])`，计算差值`diff = arr[i+1] - arr[i]`。 
4. **更新最小值和结果列表**：如果`diff`小于`min_diff`， 更新`min_diff`到`diff`并重置`result`仅包含这一对。 如果`diff`等于`min_diff`，将这对附加到`result`。 
5. **返回结果**：循环结束后，`result`包含具有最小绝对差值的所有对。 

**为什么有效**：排序可确保连续数字之间的差异最小。 通过仅比较连续元素，我们避免了冗余计算，同时仍然保证找到所有最小差异对。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumAbsDifference(self, arr: List[int]) -> List[List[int]]:
        arr.sort()
        min_diff = float('inf')
        result = []
        
        for i in range(len(arr) - 1):
            diff = arr[i+1] - arr[i]
            if diff < min_diff:
                min_diff = diff
                result = [[arr[i], arr[i+1]]]
            elif diff == min_diff:
                result.append([arr[i], arr[i+1]])
        
        return result
```该代码首先对数组进行排序，以确保连续元素给出尽可能小的差异。 然后它迭代连续的对，更新`min_diff`和`result`根据需要。 使用列表来存储对可确保我们可以自然地按升序返回它们。 

## 解决方案```go
import "sort"

func minimumAbsDifference(arr []int) [][]int {
    sort.Ints(arr)
    minDiff := int(1e7)
    result := [][]int{}
    
    for i := 0; i < len(arr)-1; i++ {
        diff := arr[i+1] - arr[i]
        if diff < minDiff {
            minDiff = diff
            result = [][]int{{arr[i], arr[i+1]}}
        } else if diff == minDiff {
            result = append(result, []int{arr[i], arr[i+1]})
        }
    }
    
    return result
}
```在 Go 中，我们使用`sort.Ints`对数组进行排序。 我们初始化`minDiff`具有大量以安全地容纳最大可能的差异。 添加切片类似于 Python 列表。 自然处理负数或最小数组长度等边缘情况。 

## 工作示例

 **示例1：**`arr = [4,2,1,3]`排序后：`[1,2,3,4]`

`min_diff = inf`最初。 

| 我| 到达[我] | arr[i+1] | 差异| 最小差异 | 结果 |
 | ---| ---| ---| ---| ---| ---|
 | 0 | 1 | 2 | 1 | 1 | [[1,2]] |
 | 1 | 2 | 3 | 1 | 1 | [[1,2],[2,3]] |
 | 2 | 3 | 4 | 1 | 1 | [[1,2],[2,3],[3,4]] |

 **示例2：**`arr = [1,3,6,10,15]`排序后：`[1,3,6,10,15]`

`min_diff = 2`发生在之间`1`和`3`。 只有一对匹配。 

**示例3：**`arr = [3,8,-10,23,19,-4,-14,27]`排序后：`[-14,-10,-4,3,8,19,23,27]`具有最小差异的配对`4`是`[-14,-10]`,`[19,23]`,`[23,27]`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log n) | O(n log n) | 排序占主导地位，迭代连续对的时间复杂度为 O(n) |
 | 空间| O(n) | 用于存储结果对； Python 中的排序是就地排序，但可以使用 O(n) 辅助 |

 对数组进行排序是主要成本。 跟踪最小差异并构建输出列表与对的数量呈线性关系，在最坏的情况下可以接近`n`。

 ## 边缘情况

 1. **最小数组长度**：只有两个元素，正好有一对，这就是最小的差异。 该算法正确返回这一对。 
2. **负数**：包含负值的数组仍必须正确计算差异。 通过排序，可以自然地处理负数，并且连续的差异仍然有效。 
3. **大数字和极端差异**：当值接近±10^6时，差异计算在某些语言中可能会溢出。 在 Python 中，整数可以处理任意大小。 在 Go 中，我们确保`minDiff`被初始化为足够大的数字以安全地存储差异而不会溢出。
