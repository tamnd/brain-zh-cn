 ## 解决方案

 ## 问题理解

 该问题要求我们找到**树的直径**，它被定义为**任意两个节点之间的**最长路径**中的边数。 我们得到一棵表示为边列表的无向树。 每条边连接两个节点，标记为`0`到`n - 1`。 输入数组`edges`有`n - 1`元素，与树的属性对齐`n`节点总是有精确的`n - 1`边缘。 

预期输出是一个整数，表示树中任意两个节点之间的最长路径（以边为单位）。 重要的是，路径不一定要经过根，因为树不一定有根。 

约束告诉我们树可以相当大，最多 10,000 个节点，因此复杂度为 O(n²) 的算法可能太慢。 中的每个节点对`edges`是唯一的，并且没有循环，保证输入始终是有效的树。 

重要的边缘情况包括单节点树，其直径应为`0`因为没有边缘或线性链，其中直径为`n - 1`边缘。 

## 方法

 ### 蛮力

 暴力方法需要计算从每个节点开始的最长路径。 这可以通过从每个节点执行 BFS 或 DFS，跟踪到所有其他节点的最长距离来完成。 虽然这种方法有效，但效率低下，因为`n`节点上，每个 DFS 或 BFS 需要 O(n) 时间，导致总复杂度为 O(n²)。 为了`n`最多 10⁴，这太慢了。 

### 最佳方法

 关键的观察结果是，**树的直径可以通过执行两次 BFS/DFS 遍历来找到**。 首先，选择任意节点并执行 DFS 或 BFS 来查找距该节点最远的节点，例如`u`。 然后再执行一次DFS或BFS，从`u`找到距离最远的节点`u`， 说`v`。 之间的距离`u`和`v`是树的**直径**。 这是有效的，因为在树中，距任何起点最远的节点始终是直径路径的端点。 

这种方法将时间和空间的复杂度降低到 O(n)，因为我们最多遍历每个节点两次并使用邻接表来存储边。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | BFS/DFS从每个节点寻找最长路径|
 | 最佳 | O(n) | O(n) | 使用邻接表表示的两次 DFS/BFS 遍历 |

 ## 算法演练

 1. 将边列表转换为邻接列表来表示树。 这允许有效地遍历邻居。 
2.选择任意一个起始节点，例如node`0`。 
3. 从起始节点开始进行DFS（或BFS），找到离它最远的节点。 跟踪距离和节点本身。 
4. 一旦找到最远的节点（称其为`u`), 执行另一个 DFS/BFS 从`u`找到距离最远的节点`u`。 到该节点的距离就是直径。 
5. 返回步骤 4 中找到的距离。 

**为什么有效：** 在任何树中，距任意节点最远的节点都保证是最长路径的端点。 通过找到距此端点最远的节点，我们确保测量树中的最大路径长度。 这样就保证了正确性。 

## Python 解决方案```python
from typing import List, Tuple
from collections import defaultdict, deque

class Solution:
    def treeDiameter(self, edges: List[List[int]]) -> int:
        if not edges:
            return 0

        # Build adjacency list
        tree = defaultdict(list)
        for u, v in edges:
            tree[u].append(v)
            tree[v].append(u)

        # Helper function for BFS
        def bfs(start: int) -> Tuple[int, int]:
            visited = set()
            queue = deque([(start, 0)])
            farthest_node, max_dist = start, 0

            while queue:
                node, dist = queue.popleft()
                if dist > max_dist:
                    farthest_node, max_dist = node, dist
                visited.add(node)
                for neighbor in tree[node]:
                    if neighbor not in visited:
                        queue.append((neighbor, dist + 1))
                        visited.add(neighbor)
            return farthest_node, max_dist

        # First BFS to find one endpoint of the diameter
        u, _ = bfs(0)
        # Second BFS to find the actual diameter
        _, diameter = bfs(u)
        return diameter
```Python 实现首先构建邻接列表以进行高效的邻居查找。 这`bfs`函数查找距给定起点最远的节点和距离。 第一个 BFS 识别直径的一个端点，第二个 BFS 从该端点计算树中的最长路径。 

## 解决方案```go
package main

func treeDiameter(edges [][]int) int {
    if len(edges) == 0 {
        return 0
    }

    // Build adjacency list
    n := len(edges) + 1
    tree := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        tree[u] = append(tree[u], v)
        tree[v] = append(tree[v], u)
    }

    // BFS helper
    bfs := func(start int) (int, int) {
        visited := make([]bool, n)
        queue := []struct {
            node, dist int
        }{{start, 0}}
        visited[start] = true
        farthestNode, maxDist := start, 0

        for len(queue) > 0 {
            curr := queue[0]
            queue = queue[1:]
            if curr.dist > maxDist {
                farthestNode, maxDist = curr.node, curr.dist
            }
            for _, neighbor := range tree[curr.node] {
                if !visited[neighbor] {
                    visited[neighbor] = true
                    queue = append(queue, struct {
                        node, dist int
                    }{neighbor, curr.dist + 1})
                }
            }
        }
        return farthestNode, maxDist
    }

    u, _ := bfs(0)
    _, diameter := bfs(u)
    return diameter
}
```在 Go 中，邻接表被表示为切片的切片。 BFS 使用切片作为队列，`visited`布尔切片。 除了语法差异外，算法逻辑与 Python 版本相同。 

## 工作示例

 **示例 1：** 边 = [[0,1],[0,2]]

 1.构建邻接表：{0:[1,2],1:[0],2:[0]}
 2.从0开始BFS找到最远节点1（距离1）
 3. BFS从1找到最远的节点2（距离2）
 4.返回2

 **示例 2：** 边 = [[0,1],[1,2],[2,3],[1,4],[4,5]]

 1.邻接表：{0:[1],1:[0,2,4],2:[1,3],3:[2],4:[1,5],5:[4]}
 2.从0开始BFS找到最远节点3（距离3）
 3. BFS从3找到最远的节点5（距离4）
 4.返回4

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 两次BFS遍历，每次访问每个节点一次 |
 | 空间| O(n) | 邻接表+BFS队列+访问集|

 时间复杂度是线性的，因为每个节点和边最多被访问两次。 空间复杂度主要由 BFS 中使用的邻接表和辅助结构决定。
