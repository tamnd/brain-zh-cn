[LeetCode 问题 1253](https://leetcode.com/problems/reconstruct-a-2-row-binary-matrix/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们重建一个恰好有两行的二进制矩阵，并且`n`给定三个约束的列：上行中元素的总和（`upper`)，下排元素之和 (`lower`)，以及每列中元素的总和 (`colsum`）。 矩阵中的每个元素是`0`或者`1`。 这`colsum[i]`代表总数`1`s 在第 i 列。 如果`colsum[i]`是`2`，两行都必须有一个`1`在该栏中； 如果是的话`1`，上排或下排有一个`1`; 如果是的话`0`，两行都有`0`。 

输入约束表明列数可能非常大，最多可达`10^5`，这排除了尝试每种组合的天真的方法。 此外，`upper`和`lower`受列数限制，因此任何重建不得超过这些总和。 该问题保证了`colsum`值只是`0`,`1`， 或者`2`，简化决策逻辑。 

关键边缘情况包括以下场景：`upper`或者`lower`无法容纳所需数量`1`s，当`colsum`包含多个`2`s 超过行总和，并且当`colsum`长度最小 (1) 或最大 (`10^5`）。 

## 方法

 暴力方法将尝试生成所有可能的组合`0`和`1`满足每个列的展示位置`colsum[i]`，然后检查结果行的总和是否为`upper`和`lower`。 该方法原则上是正确的，但计算上不可行，因为`n`列，最多有`2^n`列的组合，其中`colsum[i] == 1`。 

最佳方法依赖于贪婪策略和对列的观察`colsum[i] == 2`是固定的：两行都必须有`1`那里。 列与`colsum[i] == 1`可以分配给上行或下行，优先考虑具有剩余总容量的行。 通过按顺序迭代列并分配`1`s 贪婪地递减`upper`和`lower`，我们可以有效地重建矩阵或检测到这是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试列的所有放置组合`colsum[i] == 1`|
 | 最佳 | O(n) | O(n) | 贪婪分配`1`基于`colsum[i]`值和剩余`upper`和`lower`总和|

 ## 算法演练

 1.初始化两个列表`upper_row`和`lower_row`长度为零`n`来表示两行。 
2. 迭代`colsum`来自索引`0`到`n-1`。 
3.如果`colsum[i] == 2`， 分配`1`对双方`upper_row[i]`和`lower_row[i]`。 两者都减少`upper`和`lower`经过`1`。 如果其中之一`upper`或者`lower`becomes negative, return an empty matrix as it is impossible.
 4.如果`colsum[i] == 1`， 分配`1`到仍有剩余总容量的行（上或下）。 如果出现以下情况，请先选择上行`upper > 0`。 减少相应的行总和。 如果两者都`upper`和`lower`当 a 时为零`1`需要时，返回一个空矩阵。 
5.如果`colsum[i] == 0`，同时保留`upper_row[i]`和`lower_row[i]`作为`0`。 
6. 处理完所有列后，如果`upper`或者`lower`不为零，则返回一个空矩阵，因为行总和与给定的约束不匹配。 
7. 返回`[upper_row, lower_row]`。 

为什么它有效：不变的是处理每一列后，剩余的`upper`和`lower`计数反映了数量`1`我们还需要放置。 列与`2`必须是`1`在两行和两列中`1`贪婪地按剩余容量排成一排。 这确保了在遵守总和要求的同时不违反任何约束。 

## Python 解决方案```python
from typing import List

class Solution:
    def reconstructMatrix(self, upper: int, lower: int, colsum: List[int]) -> List[List[int]]:
        n = len(colsum)
        upper_row = [0] * n
        lower_row = [0] * n
        
        for i in range(n):
            if colsum[i] == 2:
                if upper <= 0 or lower <= 0:
                    return []
                upper_row[i] = 1
                lower_row[i] = 1
                upper -= 1
                lower -= 1
            elif colsum[i] == 1:
                if upper > 0:
                    upper_row[i] = 1
                    upper -= 1
                elif lower > 0:
                    lower_row[i] = 1
                    lower -= 1
                else:
                    return []
        if upper != 0 or lower != 0:
            return []
        return [upper_row, lower_row]
```在此实现中，我们用零初始化两行并迭代`colsum`。 我们处理固定情况`colsum[i] == 2`首先，减少总和。 为了`colsum[i] == 1`, 网络分配`1`到任何仍能容纳它的行。 如果最后的总和不匹配或者不可能放置，我们返回一个空列表。 

## 解决方案```go
func reconstructMatrix(upper int, lower int, colsum []int) [][]int {
    n := len(colsum)
    upperRow := make([]int, n)
    lowerRow := make([]int, n)
    
    for i := 0; i < n; i++ {
        if colsum[i] == 2 {
            if upper <= 0 || lower <= 0 {
                return [][]int{}
            }
            upperRow[i] = 1
            lowerRow[i] = 1
            upper--
            lower--
        } else if colsum[i] == 1 {
            if upper > 0 {
                upperRow[i] = 1
                upper--
            } else if lower > 0 {
                lowerRow[i] = 1
                lower--
            } else {
                return [][]int{}
            }
        }
    }
    if upper != 0 || lower != 0 {
        return [][]int{}
    }
    return [][]int{upperRow, lowerRow}
}
```在 Go 中，我们使用切片来表示行，并小心处理 nil 与空切片返回。 逻辑类似于 Python，具有显式递减和可行性检查。 

## 工作示例

 **示例1：**`upper = 2, lower = 1, colsum = [1,1,1]`| 我| 列总[i] | 上行 | 下排| 上 | 降低|
 | --- | --- | --- | --- | --- | --- |
 | 0 | 1 | 1 | 0 | 1 | 1 |
 | 1 | 1 | 1 | 0 | 0 | 1 |
 | 2 | 1 | 0 | 1 | 0 | 0 |

 输出：`[[1,1,0],[0,0,1]]`**示例2：**`upper = 2, lower = 3, colsum = [2,2,1,1]`第一栏`colsum[0] == 2`需要递减`upper`和`lower`by 1. 第二列之后`colsum[1] == 2`,`upper`变为0，`lower`变为 1. 对于`colsum[2] == 1`，上位为0，下位赋值1。 为了`colsum[3] == 1`，上限为0，下限为0，不可能。 输出：`[]`。 

**示例3：**`upper = 5, lower = 5, colsum = [2,1,2,0,1,0,1,2,0,1]`根据剩余的上限和下限进行贪婪分配会产生输出矩阵：`[[1,1,1,0,1,0,0,1,0,0],[1,0,1,0,0,0,1,1,0,1]]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单次通过`colsum`每列持续工作 |
 | 空间| O(n) | 额外两行长度`n`已存储|

 贪心算法确保我们只迭代一次，并且矩阵输出本身需要 O(n) 空间。
