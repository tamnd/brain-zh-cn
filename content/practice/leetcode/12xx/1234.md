[LeetCode 问题 1234](https://leetcode.com/problems/replace-the-substring-for-balanced-string/)

 **难度：** 🟡 中等
 **主题：** 字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们平衡由四种字符组成的字符串：`'Q'`,`'W'`,`'E'`， 和`'R'`。 当每个字符完全出现时，字符串**平衡**`n / 4`时间、地点`n`是字符串的长度。 输入是一个字符串`s`长度`n`（保证是4的倍数），输出是可以替换以达到平衡的连续子串的最小长度。 可以使用任何相同长度的字符进行替换，这意味着子字符串可以是完全任意的，只要生成的字符串变得平衡即可。 

限制条件`4 <= n <= 10^5`表明我们需要一个最坏的线性或线性算数的解，因为强力二次解会太慢。 边缘情况包括已经平衡的字符串、一个字符占主导地位的字符串或多个字符超过其目标计数的字符串。 由于所有字符都来自一个小的固定集，因此使用哈希映射或固定大小的数组可以有效地计算出现次数。 

## 方法

 **蛮力方法：**人们可以考虑所有可能的子串`s`并模拟用平衡剩余字符串的字符替换每个子字符串。 对于每个子字符串，我们将计算该子字符串之外每个字符的出现次数，并检查替换子字符串是否可以平衡字符串。 虽然这在原则上是可行的，但它需要`O(n^3)`时间：`O(n^2)`对于所有子串和`O(n)`计算每个子字符串的剩余字符。 为了`n = 10^5`，这是不可行的。 

**最佳方法：** 关键的见解是我们只需要替换多余的字符。 如果某个字符出现超过`n / 4`有时，必须通过替换包含它们的子字符串来减少它的额外出现。 我们可以使用**滑动窗口**来找到包含所有多余字符的最小子字符串。 窗口外所有字符的个数最多为`n / 4`。 我们滑动窗口，同时维护其中的字符计数，并且对于每个窗口，我们检查外部的剩余字符是否在目标内。 满足这个条件的最小窗口给出了解决方案。 这是线性时间`O(n)`因为每个指针最多移动`n`步骤，并且检查计数是常数时间，因为只有四个字符。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 检查所有子串并模拟替换； 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 包含所有多余字符的滑动窗口； 使用固定大小的哈希映射 |

 ## 算法演练

 1. **统计出现次数：** 统计出现的频率`'Q'`,`'W'`,`'E'`,`'R'`在字符串中`s`。 计算允许的频率`target = n / 4`。 
2. **识别多余字符：** 对于每个字符，如果其计数超过`target`，记录超出的金额； 如果不超过`target`，将其超出部分视为零。 
3. **初始化滑动窗口：** 使用两个指针`left`和`right`开始于`0`。`left`将标记窗口的开始，并且`right`将扩展以包含字符。 
4. **展开窗口：** 移动`right`通过字符串，减少窗口中包含的字符的多余计数。 
5. **缩小窗口：** 一旦所有多余计数为零或负数（意味着所有多余字符都在窗口内），移动`left`在保持这种情况的同时，尽可能地缩小窗口。 
6. **更新最小值：** 跟踪找到的覆盖所有多余字符的最小窗口长度。 
7. **返回结果：** 找到的最小窗口的长度就是可以替换以平衡字符串的最小子串长度。 

**为什么有效：** 通过保持窗口外的不变量，没有字符超过其允许的频率，我们确保用任意字符串替换窗口将使整个字符串平衡。 滑动窗口保证了最小性，因为一旦满足条件，我们总是尝试从左侧缩小它。 

## Python 解决方案```python
class Solution:
    def balancedString(self, s: str) -> int:
        from collections import Counter

        n = len(s)
        target = n // 4
        count = Counter(s)
        
        excess = {c: max(0, count[c] - target) for c in 'QWER'}
        if all(v == 0 for v in excess.values()):
            return 0

        min_len = n
        left = 0
        for right, char in enumerate(s):
            if char in excess:
                excess[char] -= 1
            while left <= right and all(v <= 0 for v in excess.values()):
                min_len = min(min_len, right - left + 1)
                if s[left] in excess:
                    excess[s[left]] += 1
                left += 1

        return min_len
```**解释：** 我们首先计算字符频率并确定超出的数量。 如果所有超出部分都为零，则字符串已经平衡。 否则，我们扩展一个窗口`right`同时减少多余的计数。 一旦满足所有超额计数为零或负数的条件，我们就会尝试缩小窗口`left`，更新找到的最小长度。 最后，我们返回最小窗口长度。 

## 解决方案```go
func balancedString(s string) int {
    n := len(s)
    target := n / 4
    count := map[byte]int{'Q': 0, 'W': 0, 'E': 0, 'R': 0}
    for i := 0; i < n; i++ {
        count[s[i]]++
    }

    excess := map[byte]int{}
    allZero := true
    for _, c := range []byte{'Q', 'W', 'E', 'R'} {
        if count[c] > target {
            excess[c] = count[c] - target
            allZero = false
        } else {
            excess[c] = 0
        }
    }
    if allZero {
        return 0
    }

    minLen := n
    left := 0
    for right := 0; right < n; right++ {
        if _, ok := excess[s[right]]; ok {
            excess[s[right]]--
        }
        for left <= right && excess['Q'] <= 0 && excess['W'] <= 0 && excess['E'] <= 0 && excess['R'] <= 0 {
            if right-left+1 < minLen {
                minLen = right - left + 1
            }
            if _, ok := excess[s[left]]; ok {
                excess[s[left]]++
            }
            left++
        }
    }

    return minLen
}
```**Go 特定说明：** 我们使用字节映射进行计数，在窗口扩展和收缩时仔细管理减法和加法。 条件`excess[...] <= 0`展开所有四个字符，因为 Go 不允许直接`all()`功能。 否则，逻辑会反映 Python 实现。 

## 工作示例

 **示例 1：s =“QWER”**

 | 步骤| 左| 对| 多余| 最小长度 |
 | ---| ---| ---| ---| ---|
 | 初始化| 0 | 0 | {Q:0,W:0,E:0,R:0} | 4 |
 | 检查 | - | - | 全部为零| 0 |

 输出：0

 **示例2：s =“QQWE”**

 | 步骤| 左| 对| 多余| 最小长度 |

 | 初始化| 0 | 0 | {Q:1,W:0,E:0,R:0} | 4 |
 | 右=0(Q) | 0 | 0 | {Q:0,W:0,E:0,R:0} | 1 |
 | 向左收缩 | 1 | 0 | {Q:1,W:0,E:0,R:0} | 1 |

 输出：1

 | 步骤| 左| 对| 多余| 最小长度 |

 | 右=0(Q) | 0 | 0 | {Q:1,W:0,E:0,R:0} | 4 |
 | 右=1(Q) | 0 | 1 | {Q:0,W:0,E:0,R:0} | 2 |
 | 向左收缩 | 1 | 1 | {Q:1,W:0,E:0,R:0} | 2 |

 输出：2

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个指针最多移动 n 步，每步计数和检查超出的部分是 O(1) |
 | 空间| O(1) | O(1) | 四个角色的固定大小地图； 恒定的额外空间|

 滑动窗口确保线性遍历，并且由于仅跟踪四个字符计数，因此空间不会随着输入大小而增长。
