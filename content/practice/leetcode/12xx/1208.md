[LeetCode 第 1208 题](https://leetcode.com/problems/get-equal-substrings-within-budget/)

 **难度：** 🟡 中等
 **主题：** 字符串、二分查找、滑动窗口、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们确定最长的连续子串`s`可以转化为对应的子串`t`在不超出给定预算的情况下，`maxCost`。 对于子字符串中的每个字符，转换成本是子字符串中字符的 ASCII 值之间的绝对差`s`和`t`在同一位置。 

换句话说，我们想要最大化子串的长度`s`这样字符转换成本的总和就可以匹配`t`不超过`maxCost`。 

输入是两个长度相等的字符串和一个表示最大允许成本的整数。 输出是一个整数，即成本约束下的最大子串长度。 

约束条件的主要观察结果是：

 1. 字符串最多可达`10^5`字符长，因此任何简单的 O(n²) 解决方案都会太慢。 
2.`maxCost`可以为零，这需要处理不允许更改的情况。 
3. 两个字符串均仅由小写英文字母组成，这简化了 ASCII 计算。 

重要的边缘情况包括：

 -`maxCost`= 0（无法执行任何字符更改）
 - 所有字符都相同或不同的字符串
 - 单字符字符串（最小长度）

 ## 方法

 ### 蛮力

 蛮力方法将迭代所有可能的子串`s`，计算更改每个子字符串以匹配的成本`t`，并跟踪其中的最大长度`maxCost`。 这是有效的，因为它详尽地考虑了每个候选子串。 

然而，这种方法太慢了。 对于长度的字符串`n`，有 O(n²) 个可能的子串。 计算每个子串的成本最多可能需要 O(n) 时间，导致总时间复杂度为 O(n³)，这对于`n = 10^5`。 

### 最佳方法

 最佳方法使用**滑动窗口**技术。 关键的见解是问题需要一个连续的子字符串，因此我们可以维护一个窗口`[left, right]`超过`s`。 我们通过移动来扩大窗口`right`转发并计算包含新字符的增量成本。 如果总成本超过`maxCost`，我们从左边缩小窗口，直到总成本在预算之内。 这确保了我们始终保持有效的窗口，并且可以有效地跟踪最大窗口长度。 

这是可行的，因为成本函数是相加的，并且字符的变换是独立的，因此扩展和收缩窗口可以保证我们不会错过任何有效的子字符串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(1) | O(1) | 检查所有子串并计算成本 |
 | 滑动窗| O(n) | O(1) | O(1) | 维护运行成本并动态调整窗口 |

 ## 算法演练

 1.初始化两个指针，`left`和`right`，都为 0。同时初始化`totalCost`到 0 和`maxLen`至 0。 
2. 迭代`right`从 0 到`n-1`（字符串末尾）。 对于每个角色，计算改变的成本`s[right]`到`t[right]`并将其添加到`totalCost`。 
3.如果`totalCost`超过`maxCost`， 移动`left`向前并减去成本`s[left] -> t[left]`从`totalCost`。 重复直到`totalCost`≤`maxCost`。 
4. 更新`maxLen`作为电流的最大值`maxLen`和当前窗口大小`right - left + 1`。 
5. 继续直到`right`到达字符串末尾。 
6. 返回`maxLen`。 

**为什么有效**：滑动窗口保证每个结束索引`right`，我们通过动态调整找到以此处结尾的最长有效子串`left`。 由于成本是相加的并且子串是连续的，因此缩小和扩展窗口永远不会错过有效的候选者。 

## Python 解决方案```python
class Solution:
    def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
        left = 0
        totalCost = 0
        maxLen = 0
        
        for right in range(len(s)):
            totalCost += abs(ord(s[right]) - ord(t[right]))
            
            while totalCost > maxCost:
                totalCost -= abs(ord(s[left]) - ord(t[left]))
                left += 1
            
            maxLen = max(maxLen, right - left + 1)
        
        return maxLen
```**解释**：我们迭代`s`使用`right`。 对于每个角色，我们添加将其转换为相应角色的成本`t`特点。 如果总成本超过`maxCost`，我们移动`left`降低总成本，直至其符合预算。`maxLen`跟踪最长的有效窗口。 

## 解决方案```go
func equalSubstring(s string, t string, maxCost int) int {
    left, totalCost, maxLen := 0, 0, 0
    
    for right := 0; right < len(s); right++ {
        totalCost += abs(int(s[right]) - int(t[right]))
        
        for totalCost > maxCost {
            totalCost -= abs(int(s[left]) - int(t[left]))
            left++
        }
        
        if right - left + 1 > maxLen {
            maxLen = right - left + 1
        }
    }
    
    return maxLen
}

func abs(a int) int {
    if a < 0 {
        return -a
    }
    return a
}
```**说明**：Go 版本镜像了 Python 解决方案。 主要区别是 ASCII 值的显式整数转换和定义助手`abs`功能。 使用切片索引代替字符串迭代器。
