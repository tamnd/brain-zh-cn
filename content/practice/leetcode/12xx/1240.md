[LeetCode 1240 题](https://leetcode.com/problems/tiling-a-rectangle-with-the-fewest-squares/)

 **难度：** 🔴难
 **主题：** 回溯

 ## 解决方案

 ## 问题理解

 问题是要求我们完全覆盖一个大小的矩形`n x m`具有整数边长的正方形数量最少。 矩形可以与任何大小的正方形平铺，只要每个正方形完全适合矩形并且没有重叠即可。 输入由两个整数组成，`n`和`m`，分别表示矩形的高度和宽度。 预期输出是一个整数，表示完全平铺矩形所需的最小正方形数。 

约束条件，`1 <= n, m <= 13`，表明矩形相对较小，这表明回溯方法是可行的，因为搜索空间有限，但需要仔细修剪以避免指数时间爆炸。 边缘情况包括已经是正方形的矩形（答案为 1）、较薄的矩形（例如 1xN）或以下矩形：`n`和`m`与那些相对素数的因子共享公共因子，这会影响可能的平铺配置。 

该问题保证了`n`和`m`是正整数，因此不需要处理零或负维度。 然而，具有素数尺寸的小矩形可能特别棘手，因为它们通常需要混合较小的正方形，从而增加了搜索复杂性。 

## 方法

 暴力方法将递归地尝试在每个可用的空单元格处放置所有可能的正方形。 对于每个空位置，我们可以尝试使用大小从 1 到适合剩余空间的最大正方形的正方形。 此方法保证了正确性，因为它会探索每个配置，但速度非常慢。 递归调用的数量与矩形的面积一起增长，对于 13x13 的矩形，它在计算上变得不可行。 

最佳方法的关键见解是使用回溯和修剪和启发式方法。 通过始终将最大可能的正方形放置在最左上角的空单元中并跟踪当前放置的正方形数量，我们可以修剪超出当前最佳解决方案的任何递归路径。 此外，记忆某些矩形状态或使用 2D 板表示来跟踪填充的单元格使我们能够有效地探索有效的平铺。 小的约束使得通过修剪执行递归深度优先搜索变得可行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n*m)) | O(2^(n*m)) | O(n*m) | 尝试每个方形放置而不修剪 |
 | 最佳| O(k^(n*m)) 带剪枝 | O(n*m) | 具有最大优先启发式和剪枝的 DFS/回溯 |

 ## 算法演练

 1. 初始化表示矩形的二维数组或列表，将所有单元格标记为空。 
2. 定义一个递归函数，尝试从左上角的空单元格开始放置正方形。 
3. 在每个递归步骤中，按行优先顺序查找第一个空单元格。 
4. 确定从该单元格开始可以容纳的最大正方形大小，而不会重叠填充的单元格或超出矩形边界。 
5. 从最大的正方形尺寸迭代到 1，放置一个正方形并将相应的单元格标记为已填充。 
6. 使用更新的矩形状态和所使用的正方形的增量计数进行递归。 
7. 通过移除放置的方块并取消标记其单元格来回溯。 
8. 跟踪所有递归路径上的最小方块数。 
9. 返回探索所有有效平铺后的最小方块数。 

为什么有效：该算法保证了正确性，因为它探索了每个有效的配置，但有效地修剪了无法改进迄今为止找到的最佳解决方案的路径。 通过始终首先尝试最大的正方形，它通常可以更快地达到最佳解决方案，并避免不必要地探索较小的、次优的正方形。 

## Python 解决方案```python
class Solution:
    def tilingRectangle(self, n: int, m: int) -> int:
        if n > m:
            n, m = m, n

        min_squares = n * m
        board = [[0] * m for _ in range(n)]

        def can_place(x, y, size):
            if x + size > n or y + size > m:
                return False
            for i in range(x, x + size):
                for j in range(y, y + size):
                    if board[i][j]:
                        return False
            return True

        def place_square(x, y, size, value):
            for i in range(x, x + size):
                for j in range(y, y + size):
                    board[i][j] = value

        def dfs(count):
            nonlocal min_squares
            if count >= min_squares:
                return

            for i in range(n):
                for j in range(m):
                    if board[i][j] == 0:
                        max_size = min(n - i, m - j)
                        for size in range(max_size, 0, -1):
                            if can_place(i, j, size):
                                place_square(i, j, size, 1)
                                dfs(count + 1)
                                place_square(i, j, size, 0)
                        return
            min_squares = min(min_squares, count)

        dfs(0)
        return min_squares
```实施首先确保`n <= m`以减少对称性。 这`can_place`函数检查给定大小的正方形是否适合某个位置。`place_square`将单元格标记为已填充或空。 递归`dfs`函数探索所有位置，修剪当前计数超过迄今为止找到的最佳计数的路径。 该算法总是首先尝试最大的平方以进行有效的修剪。 

## 解决方案```go
func tilingRectangle(n int, m int) int {
    if n > m {
        n, m = m, n
    }

    board := make([][]int, n)
    for i := 0; i < n; i++ {
        board[i] = make([]int, m)
    }

    minSquares := n * m

    var canPlace func(x, y, size int) bool
    canPlace = func(x, y, size int) bool {
        if x+size > n || y+size > m {
            return false
        }
        for i := x; i < x+size; i++ {
            for j := y; j < y+size; j++ {
                if board[i][j] == 1 {
                    return false
                }
            }
        }
        return true
    }

    var placeSquare func(x, y, size, val int)
    placeSquare = func(x, y, size, val int) {
        for i := x; i < x+size; i++ {
            for j := y; j < y+size; j++ {
                board[i][j] = val
            }
        }
    }

    var dfs func(count int)
    dfs = func(count int) {
        if count >= minSquares {
            return
        }
        for i := 0; i < n; i++ {
            for j := 0; j < m; j++ {
                if board[i][j] == 0 {
                    maxSize := min(n-i, m-j)
                    for size := maxSize; size >= 1; size-- {
                        if canPlace(i, j, size) {
                            placeSquare(i, j, size, 1)
                            dfs(count + 1)
                            placeSquare(i, j, size, 0)
                        }
                    }
                    return
                }
            }
        }
        if count < minSquares {
            minSquares = count
        }
    }

    dfs(0)
    return minSquares
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```在 Go 中，使用切片而不是列表，以及类似的函数`min`被明确定义。 零值不是问题，因为我们初始化了一个完全分配的板。 递归函数使用闭包来捕获`board`和`minSquares`。 

## 工作示例

 ### 示例 1：n = 2，m = 3

 1. 棋盘被初始化为 2x3 网格。 
2. 左上角单元格为空，最大正方形尺寸为 2（垂直和水平都适合）。 
3. 在左上角放置 2x2 正方形，标记覆盖的单元格。 
4. 递归，下一个空单元格位于 (0,2) 处，放置 1x1 正方形。 
5. 在 (1,2) 处的下一个空单元格中放置 1x1 正方形。 
6. 棋盘完全覆盖，总方格 = 3。 

### 示例 2：n = 5，m = 8

 1. 左上角最大的正方形是 5x5。 
2. 剩下的矩形是5x3。 
3. 将 3x3 正方形放入剩余的矩形中。 
4. 剩余的矩形为 2x3，继续根据需要放置正方形 2x2 和 1x1。 
5. 使用 5 个正方形找到最佳平铺。 

### 示例 3：n = 11，m = 13

 1. 左上角最大的正方形为 11x11。 
2. 剩余的 11x2 矩形由 2x2 和 1x1 正方形平铺。 
3. 最优解需要6个方格。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(k^(n*m)) 带剪枝 | DFS 探索配置，剪枝显着减少路径数量，k 是平均分支因子 |
 | 空间| O(n*m) | board 数组存储矩形当前的填充状态 |

 由于限制很小，带有剪枝的回溯是可行的。 这`n*m <= 169`与启发式方法相结合，使详尽的搜索变得易于管理。
