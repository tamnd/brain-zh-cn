 # LeetCode 1260 - 平移二维网格

 ## 问题理解

 这个问题要求我们模拟二维矩阵上的重复移位操作。 我们被赋予了一个`m x n`网格和一个整数`k`，表示必须应用移位操作的次数。 

单个移位操作将每个元素按行优先顺序向前移动一位。 这意味着：

 - 每个元素向右移动一列。 
- 一行的最后一个元素换行到下一行的开头。 
- 右下角的元素一直回绕到左上角的位置。 

如果我们将矩阵视为一个连续的线性数组，则该操作相当于将数组向右旋转一位。 

例如，网格：```
1 2 3
4 5 6
7 8 9
```可以看作：```
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```一班后：```
[9, 1, 2, 3, 4, 5, 6, 7, 8]
```它映射回：```
9 1 2
3 4 5
6 7 8
```输入包括：

 -`grid`, 一个二维整数矩阵
 -`k`, 移位操作的次数

 输出应该是应用所有移位后的变换矩阵。 

限制相对较小：

 -`m, n <= 50`- 细胞总数 <= 2500
 -`k <= 100`这些限制意味着即使效率较低的解决方案也可能通过，但该问题旨在测试对矩阵索引和模拟的理解。 

一些边缘情况很重要：

 -`k = 0`，意味着没有发生转变
 -`k`等于单元格总数，意味着矩阵返回到原始状态
 - 单行矩阵
 - 单列矩阵
 - A`1 x 1`矩阵，移位不会改变任何内容
 - 大号`k`值，除非使用模算术进行优化，否则重复模拟会变得浪费

 ## 方法

 ### 蛮力方法

 最直接的解决办法就是精确模拟移位操作`k`次。 

对于每个班次：

 1. 保存右下角的值。 
2. 将每个元素移动到新位置。 
3. 将保存的值放入`grid[0][0]`。 

这种方法很简单，并且准确地反映了问题陈述。 由于每个班次都会接触到每个细胞，因此一个班次的成本`O(m * n)`时间。 重复这个`k`次给出：```
O(k * m * n)
```这在限制范围内有效，因为`k <= 100`，但它执行了不必要的重复工作。 

### 最佳方法

 关键的观察结果是网格的行为就像一个圆形一维阵列。 

毕竟，我们可以直接计算每个元素所属的位置，而不是一次执行一个移位`k`轮班。 

对于具有以下内容的网格：```
total = m * n
```每个元素都有一个线性索引：```
index = row * n + col
```右移后`k`职位：```
new_index = (index + k) % total
```然后我们将新的线性索引转换回二维坐标：```
new_row = new_index // n
new_col = new_index % n
```这使我们能够在一次传递中将每个元素直接放置到其最终位置。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k * m * n) | O(1) | O(1) | 单独模拟每个班次 |
 | 最佳 | O(m * n) | O(m * n) | 使用索引映射直接计算最终位置 |

 ## 算法演练

 ### 最优算法

 1. 确定矩阵维度。 

让：```
m = number of rows
n = number of columns
```元素总数为：```
total = m * n
```2. 使用模数减少不必要的旋转。 

移动网格`total`位置将其恢复到原始状态。 所以：```
k = k % total
```这避免了多余的工作。 
3. 创建结果矩阵。 

我们分配一个新的`m x n`将存储移位值的矩阵。 
4. 遍历原网格中的每个元素。 

对于每个位置`(row, col)`:

 - 将其转换为一维索引：```
current_index = row * n + col
```- 计算移动后的新位置：```
new_index = (current_index + k) % total
```5. 将新的 1D 索引转换回 2D 坐标。```
new_row = new_index // n
new_col = new_index % n
```6. 将值放入结果矩阵中。```
result[new_row][new_col] = grid[row][col]
```7. 继续，直到处理完所有元素。 
8. 返回结果矩阵。 

### 为什么它有效

 该算法之所以有效，是因为矩阵中的每个位置都唯一对应于行优先顺序的线性索引。 移位操作完全相当于将该线性序列向右旋转。 通过使用模运算直接计算每个元素的目标索引，我们保证每个值都移动到正确的最终位置，没有重叠或遗漏。 

## Python 解决方案```python
from typing import List

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        rows = len(grid)
        cols = len(grid[0])

        total_cells = rows * cols
        k %= total_cells

        result = [[0] * cols for _ in range(rows)]

        for row in range(rows):
            for col in range(cols):
                current_index = row * cols + col
                new_index = (current_index + k) % total_cells

                new_row = new_index // cols
                new_col = new_index % cols

                result[new_row][new_col] = grid[row][col]

        return result
```实现首先确定矩阵维度和单元总数。 模运算减少了不必要的旋转，因为按矩阵大小移位会产生原始配置。 

分配一个新的结果矩阵，以便可以将值直接放入其最终位置，而无需覆盖现有值。 

嵌套循环只对每个单元格迭代一次。 每个`(row, col)`使用行优先排序将坐标转换为线性索引。 新的移动位置通过模运算计算出来，然后转换回 2D 坐标。 

最后，将该值放入正确的目标单元格并返回完整的矩阵。 

## 解决方案```go
func shiftGrid(grid [][]int, k int) [][]int {
    rows := len(grid)
    cols := len(grid[0])

    totalCells := rows * cols
    k %= totalCells

    result := make([][]int, rows)

    for i := 0; i < rows; i++ {
        result[i] = make([]int, cols)
    }

    for row := 0; row < rows; row++ {
        for col := 0; col < cols; col++ {
            currentIndex := row*cols + col
            newIndex := (currentIndex + k) % totalCells

            newRow := newIndex / cols
            newCol := newIndex % cols

            result[newRow][newCol] = grid[row][col]
        }
    }

    return result
}
```Go 解决方案遵循与 Python 版本完全相同的逻辑。 主要区别是使用 2D 切片的显式分配`make`。 

Go 整数除法会自动截断为零，这正是我们将线性索引转换回行索引所需的。 

由于约束很小，因此不必担心整数溢出。

 ## 边缘情况

 ### 移位计数等于零

 当`k = 0`，矩阵应保持不变。 有缺陷的实现可能仍会尝试不必要的移动或意外覆盖值。 此实现可以自然地处理这种情况，因为：```
new_index = current_index
```所以每个元素都直接映射回其原始位置。 

### 班次计数大于单元总数

 如果`k`超过细胞数量，重复的转变开始在先前看到的状态之间循环。 如果没有模数约简，实现可能会浪费时间执行冗余操作。 

例如：```
total cells = 4
k = 100
```相当于：```
k = 100 % 4 = 0
```该实施通过减少不必要的工作来避免`k`立即地。 

### 单行或单列矩阵

 这些特殊的矩阵形状通常会暴露索引错误。 

对于单行：```
[[1,2,3,4]]
```该操作变成普通的圆形阵列旋转。 

对于单列：```
[[1],[2],[3]]
```元素垂直包裹。 

由于该算法使用统一的线性索引系统，因此两种情况都会自动工作，无需单独处理。 

### 单细胞矩阵

 一个`1 x 1`矩阵永远不会改变，无论`k`。 某些实现可能会意外除以零或错误处理微小矩阵中的包装逻辑。 

这里：```
total_cells = 1
k % 1 = 0
```唯一的元素简单地映射回其自身。
