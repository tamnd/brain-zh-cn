[LeetCode 问题 1225](https://leetcode.com/problems/report-contigious-dates/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们分析一个在固定时间内每天运行一项任务的系统，从`2019-01-01`到`2019-12-31`。 每一天，任务要么成功，要么失败。 我们有两张表：`Failed`和`Succeeded`，每个分别包含任务失败或成功的日期。 每个表中的日期都是唯一的。 

目标是生成系统状态相同的连续天的**连续间隔**的报告（`failed`或者`succeeded`）。 每个区间应由其表示`start_date`,`end_date`，以及`period_state`。 间隔必须正确合并：如果连续多天具有相同的状态，它们应显示为一行。 

要点：

 - 范围严格限于 2019 年。任何超出此范围的日期都必须被忽略。 
- 每天都有一个结果（失败或成功）。 
- 表中可能包含 2019 年以外的日期，必须将其过滤掉。 
- 我们需要识别相同结果的**连续序列**，并将它们报告为单个间隔。 

重要的边缘情况：

 1. 任一表中都没有记录的一天：根据问题陈述，每个任务要么在`Failed`或者`Succeeded`表，所以没有缺失的日子。 
2. 在边界处开始或结束的区间`2019-01-01`或者`2019-12-31`。 
3. 单日间隔。 

## 方法

 ### 蛮力

 一个天真的解决方案将生成每个日期`2019-01-01`到`2019-12-31`并对照每个日期检查`Failed`和`Succeeded`表。 对于每个日期，我们将分配一个状态，然后迭代序列以将具有相同状态的连续天合并到间隔中。 

虽然这种方法是正确的，但它有两个主要问题。 首先，如果在带有子查询的 SQL 中简单地实现，单独生成和检查每个日期可能效率很低。 其次，在 SQL 中手动合并连续日期需要相关子查询或过程逻辑，这既麻烦又缓慢。 

### 最佳方法

 关键的见解是将连续日期视为**分组序列**，其中日期和连续行号之间的差异是恒定的。 这种技术通常被称为“间隙和岛屿”问题，使我们能够有效地识别连续序列。 

最佳方法的步骤：

 1. 过滤两者`Failed`和`Succeeded`表格仅包含 2019 年的日期。 
2. 将表合并为一个包含列的表`date`和`period_state`。 
3. 为按日期排序的每一行分配行号。 
4. 通过从日期中减去行号（或使用日期算术）来计算“组标识符”。 同一州的连续日期将共享相同的标识符。 
5. 按状态和组标识符进行分组，以查找每个间隔的开始日期和结束日期。 
6. 对结果进行排序`start_date`。 

此方法避免显式迭代每个日期并有效地使用 SQL 集操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N) | O(N) | 手动生成所有日期并合并序列 |
 | 最佳| O(N) | O(N) | 使用带有行号的“间隙和岛屿”对连续日期进行分组 |

 ## 算法演练

 1. **筛选 2019 年日期**：仅选择以下行`Failed`和`Succeeded`日期介于`'2019-01-01'`和`'2019-12-31'`。 这确保了其他年份的不相关数据被忽略。 
2. **联合表**：合并`Failed`和`Succeeded`到一个有两列的表中：`date`和`period_state`。 这通过将所有日期集中在一处来简化处理。 
3. **分配行号**：使用 SQL`ROW_NUMBER()`功能结束`ORDER BY date`对于每个`period_state`。 这将使我们能够计算“组密钥”来识别连续序列。 
4. **计算组键**：从日期（转换为整数或序数格式）中减去行号以创建键。 同一状态的连续日期将具有相同的键，因为日期和行号每天都会增加 1。 
5. **聚合间隔**：分组依据`period_state`和计算出的密钥。 对于每个组，计算`MIN(date)`作为`start_date`和`MAX(date)`作为`end_date`。 
6. **对结果排序**：排序依据`start_date`产生最终报告。 

**为什么有效**：从日期中减去行号会对连续日期产生相同的差异，形成一个常量组标识符。 这保证了仅合并相同状态的连续序列，这精确地模拟了所需的间隔。 

## Python 解决方案```python
import pandas as pd

def report_contiguous_dates(failed: pd.DataFrame, succeeded: pd.DataFrame) -> pd.DataFrame:
    # Filter 2019 dates
    failed_2019 = failed[(failed['fail_date'] >= '2019-01-01') & (failed['fail_date'] <= '2019-12-31')]
    succeeded_2019 = succeeded[(succeeded['success_date'] >= '2019-01-01') & (succeeded['success_date'] <= '2019-12-31')]

    # Union tables
    failed_2019 = failed_2019.rename(columns={'fail_date': 'date'})
    failed_2019['period_state'] = 'failed'
    succeeded_2019 = succeeded_2019.rename(columns={'success_date': 'date'})
    succeeded_2019['period_state'] = 'succeeded'

    all_dates = pd.concat([failed_2019, succeeded_2019])
    all_dates = all_dates.sort_values('date').reset_index(drop=True)

    # Compute group identifier using cumulative difference
    all_dates['date'] = pd.to_datetime(all_dates['date'])
    all_dates['rn'] = all_dates.groupby('period_state').cumcount()
    all_dates['group'] = all_dates['date'] - pd.to_timedelta(all_dates['rn'], unit='D')

    # Aggregate intervals
    result = all_dates.groupby(['period_state', 'group'], as_index=False).agg(
        start_date=('date', 'min'),
        end_date=('date', 'max')
    ).sort_values('start_date')

    result['start_date'] = result['start_date'].dt.date
    result['end_date'] = result['end_date'].dt.date

    return result[['period_state', 'start_date', 'end_date']]
```**说明**：代码首先过滤 2019 年之前的日期，然后合并两个表。 排序可确保正确的排序。 每累计计数`period_state`创建一个运行索引。 从日期中减去该索引会为连续序列生成一致的组键。 最后，按此键分组聚合间隔。 

## 解决方案```go
package main

import (
    "database/sql"
    "fmt"
)

func reportContiguousDates(db *sql.DB) (*sql.Rows, error) {
    query := `
    WITH combined AS (
        SELECT fail_date AS date, 'failed' AS period_state
        FROM Failed
        WHERE fail_date BETWEEN '2019-01-01' AND '2019-12-31'
        UNION ALL
        SELECT success_date AS date, 'succeeded' AS period_state
        FROM Succeeded
        WHERE success_date BETWEEN '2019-01-01' AND '2019-12-31'
    ),
    numbered AS (
        SELECT
            date,
            period_state,
            ROW_NUMBER() OVER (PARTITION BY period_state ORDER BY date) AS rn
        FROM combined
    ),
    grouped AS (
        SELECT
            period_state,
            date - INTERVAL (rn) DAY AS grp,
            MIN(date) OVER (PARTITION BY period_state, date - INTERVAL (rn) DAY) AS start_date,
            MAX(date) OVER (PARTITION BY period_state, date - INTERVAL (rn) DAY) AS end_date
        FROM numbered
    )
    SELECT DISTINCT period_state, start_date, end_date
    FROM grouped
    ORDER BY start_date;
    `
    return db.Query(query)
}
```**说明**：Go版本使用带有CTE的SQL来处理数据库中的问题，这对于LeetCode SQL问题来说是很自然的。 逻辑反映了 Python 方法：组合表、分配行号、使用日期算术计算组键、聚合最小值和最大值以及按开始日期排序。
