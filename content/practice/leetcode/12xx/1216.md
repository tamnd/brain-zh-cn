 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们判断给定的字符串是否`s`删除后最多可以变成回文`k`人物。 回文是一个正反读都相同的字符串，`k`-palindrome 是最多可以变成回文的一个`k`删除。 

输入由一个字符串组成`s`仅包含小写英文字母和整数`k`。 输出是一个布尔值，`true`如果字符串是`k`- 回文和`false`否则。 

约束告诉我们，字符串的长度可达 1000，这个长度足够大，以至于探索所有可能删除的简单递归解决方案会太慢。`k`范围可以从 1 到字符串的长度，这意味着在某些情况下我们可能需要删除几乎所有字符。 

重要的边缘情况包括非常短的字符串（长度为 1 或 2）、已经是回文的字符串、需要精确匹配的字符串`k`删除和字符串其中`k`大于所需删除的数量。 

## 方法

 暴力方法将尝试所有可能的方法来删除最多`k`字符，然后检查结果字符串是否是回文。 这种方法之所以有效，是因为它探索了所有可能的有效转换，但在计算上是不可行的。 带有长度的字符串`n`，有许多组合的字符子集需要删除，导致指数时间复杂度。 

最佳解决方案的关键见解是认识到该问题相当于在字符串中查找**最长回文子序列 (LPS)**。 一旦我们知道了 LPS 长度，我们就可以计算出所需的最小删除量：`len(s) - LPS_length`。 如果这个数字小于或等于`k`，该字符串是一个`k`-回文。 动态规划在这里很自然，因为我们可以使用重叠子问题来构建 LPS 长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 探索所有删除子集并检查回文 |
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 使用 DP 计算最长回文子序列，然后与 k | 进行比较

 ## 算法演练

 1.定义一个2D DP数组`dp[i][j]`表示子串的最长回文子序列的长度`s[i:j+1]`。 
2. 初始化`dp[i][i] = 1`为所有人`i`，因为单个字符始终是长度为 1 的回文。 
3. 迭代子串长度`l`从 2 到`n`。 对于每个子串长度：

 a. 迭代所有可能的起始索引`i`这样`i + l - 1 < n`。 

b. 让`j = i + l - 1`是结束索引。 

c. 如果`s[i] == s[j]`， 然后`dp[i][j] = dp[i+1][j-1] + 2`，因为匹配的字符可以扩展中间的回文。 

d. 如果`s[i] != s[j]`， 然后`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`，因为我们必须删除其中一个`s[i]`或者`s[j]`最大化回文子序列。 
4. 填充DP表后，整个字符串的最长回文子序列为`dp[0][n-1]`。 
5. 计算`min_deletions = len(s) - dp[0][n-1]`。 如果`min_deletions <= k`， 返回`true`; 否则，返回`false`。 

**为什么有效：** DP 方法保证对于每个子串，我们使用最优子结构正确计算最长的回文子序列。 通过比较最小删除`k`，我们正确地确定字符串是否可以转换为回文数，最多`k`删除。 

## Python 解决方案```python
class Solution:
    def isValidPalindrome(self, s: str, k: int) -> bool:
        n = len(s)
        dp = [[0] * n for _ in range(n)]

        for i in range(n):
            dp[i][i] = 1

        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        return n - dp[0][n - 1] <= k
```该实现首先初始化 DP 表并设置单字符子字符串的基本情况。 然后，它迭代增加的子字符串长度，使用递归关系填充表。 最后，它计算最小删除并与`k`。 

## 解决方案```go
func isValidPalindrome(s string, k int) bool {
    n := len(s)
    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][i] = 1
    }

    for length := 2; length <= n; length++ {
        for i := 0; i <= n-length; i++ {
            j := i + length - 1
            if s[i] == s[j] {
                if length == 2 {
                    dp[i][j] = 2
                } else {
                    dp[i][j] = dp[i+1][j-1] + 2
                }
            } else {
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])
            }
        }
    }

    return n - dp[0][n-1] <= k
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```Go 版本镜像了 Python 实现。 唯一显着的区别是切片的显式处理以及需要定义一个`max`辅助功能。 初始化和迭代遵循相同的DP逻辑。
