 **难度：** 🟡 中等
 **主题：** 数学、字符串、贪心

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定生成两个字符串所需的最小交换次数，`s1`和`s2`， 平等的。 两个字符串的长度相同并且仅包含字符`"x"`和`"y"`。 允许的交换操作受到限制：只能在两个字符串之间交换字符，而不能在同一字符串内交换字符。 

输入字符串表示在某些位置可能不同的字符序列。 输出是一个整数，表示使字符串相同所需的最小交换次数，或者`-1`如果不可能实现平等。 

约束告诉我们字符串的长度最多可达 1000，因此 O(n²) 方法可能效率较低。 重要的边缘情况包括已经相等的字符串（需要 0 次交换）、在不可能匹配的奇数个位置不同的字符串或仅在一个位置不同的字符串。 该问题保证两个字符串都非空并且只包含`"x"`和`"y"`。 

## 方法

 蛮力方法将涉及迭代之间所有可能的字符交换`s1`和`s2`直到它们匹配。 对于每个不匹配，我们将递归或迭代地尝试所有可能的交换，以达到相等。 虽然这种方法原则上是正确的，但由于可能的交换序列的阶乘数量，它的效率极低，导致 O(2^n) 或更糟糕的时间复杂度。 

最佳解决方案依赖于计算不匹配的字符对。 不匹配有两种类型：`xy`（在哪里`s1`有`x`和`s2`有`y`） 和`yx`（在哪里`s1`有`y`和`s2`有`x`）。 我们可以配对`xy`和`xy`或者`yx`和`yx`在不匹配的对中执行单个交换。 配对后任何剩余的不匹配必须恰好由一个组成`xy`和一个`yx`，可以通过两次交换来解决。 如果不匹配的总数是奇数，则不可能使字符串相等，我们返回`-1`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试字符串之间所有可能的交换 |
 | 最佳 | O(n) | O(1) | O(1) | 数数`xy`和`yx`不匹配并计算掉期 |

 ## 算法演练

 1. 初始化两个计数器：`xy`和`yx`为零。 这些将跟踪位置的数量`s1[i]`是`x`和`s2[i]`是`y`，反之亦然。 
2. 使用相同的索引迭代字符串`i`。 对于每个位置，检查是否`s1[i] != s2[i]`。 
3. 如果有不匹配的情况`s1[i]`是`x`尽管`s2[i]`是`y`，增加`xy`柜台。 如果`s1[i]`是`y`尽管`s2[i]`是`x`，增加`yx`柜台。 
4. 迭代结束后，检查是否`(xy + yx) % 2 != 0`。 如果不匹配总数为奇数，则返回`-1`，因为每次交换都会解决两个不匹配问题。 
5. 计算最小交换次数。 每对`xy`不匹配可以通过一次交换来解决（`xy // 2`）。 每对`yx`不匹配可以类似地解决（`yx // 2`）。 
6. 如果还剩一张`xy`还剩一张`yx`，需要两次交换才能解决它们。 这相当于`(xy % 2) * 2`。 
7. 返回这些交换的总和作为所需的最小交换数量。 

**为什么有效**：每次交换都能以最佳方式解决两个不匹配问题。 配对不匹配有效地减少了它们，并且模检查确保检测到不匹配的情况。 这保证了正确性而无需冗余操作。 

## Python 解决方案```python
class Solution:
    def minimumSwap(self, s1: str, s2: str) -> int:
        xy = 0
        yx = 0
        
        for a, b in zip(s1, s2):
            if a == 'x' and b == 'y':
                xy += 1
            elif a == 'y' and b == 'x':
                yx += 1
        
        if (xy + yx) % 2 != 0:
            return -1
        
        swaps = (xy // 2) + (yx // 2) + (xy % 2) * 2
        return swaps
```在此 Python 实现中，我们首先将不匹配计数为`xy`和`yx`。 模检查确保尽早发现不可能性。 最终的交换计算处理完整的不匹配对和剩余的一对不匹配的情况，产生最小数量的交换。 

## 解决方案```go
func minimumSwap(s1 string, s2 string) int {
    xy, yx := 0, 0

    for i := 0; i < len(s1); i++ {
        if s1[i] == 'x' && s2[i] == 'y' {
            xy++
        } else if s1[i] == 'y' && s2[i] == 'x' {
            yx++
        }
    }

    if (xy + yx) % 2 != 0 {
        return -1
    }

    swaps := (xy / 2) + (yx / 2)
    if xy % 2 == 1 {
        swaps += 2
    }

    return swaps
}
```在 Go 中，逻辑与 Python 非常相似。 我们明确地使用整数除法和模运算符。 Go 不需要额外的数据结构，因为计数器就足够了，并且字符串是直接索引的。
