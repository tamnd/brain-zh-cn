 **难度：** 🟢简单

 ## 解决方案

 ## 问题理解

 该问题要求我们从最初形成算术级数 (AP) 的数组中找到缺失值。 算术级数是一个序列，其中连续项之间的差是恒定的，即`arr[i + 1] - arr[i]`对于每个连续的对都是相同的。 我们得到一个数组`arr`其中**一个元素已被删除**，重要的是，丢失的元素**不是第一个或最后一个元素**。 

输入是表示不完整 AP 的整数列表，预期输出是被删除的单个整数。 约束条件表示数组至少包含 3 个元素，最多 1000 个元素，值范围为 0 到 100,000。 这些限制告诉我们，`O(n)`解决方案是可以接受的，并且整数算术将安全地适合标准整数类型。 

需要注意的边缘情况包括值递减的序列、步长大于 1 的序列，以及缺失数字出现在原始 AP 的开头或结尾附近但不在实际数组边界处的数组。 

## 方法

 **暴力方法**将涉及检查数组的最小值和最大值之间可能存在的每个可能的数字，构造一个假设的完整 AP，并将其与给定的数组进行比较以找到丢失的数字。 这是可行的，因为 AP 完全由其第一个和最后一个元素及其长度定义。 然而，它的效率很低，因为它可能需要构建和比较多达`O(n)`不必要的元素。 

**最佳方法**利用了 AP 具有恒定步长的事实`d`并且可以通过检查给定数组中的连续差异来推断丢失的数字。 由于只缺少一个数字，**正确的步骤是连续元素之间最常见的差异**。 一次`d`已知，我们可以遍历数组，找到第一个不存在差异的地方`d`。 缺失的数字只是前一个元素加上`d`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 生成完整的 AP 并比较元素 |
 | 最佳| O(n) | O(1) | O(1) | 从第一个/最后一个元素计算步骤并直接检测缺失的数字 |

 ## 算法演练

 1. 识别数组的第一个和最后一个元素以计算预期的公差`d`。 由于缺少一个元素，实际步骤是`(last - first) / len(arr)`。 
2. 从开始到倒数第二个元素迭代数组。 
3. 对于每对连续元素，计算它们的差值。 
4. 将观察到的差异与预期进行比较`d`。 
5. 当观察到的差异大于`d`，这意味着缺失的数字位于这两个元素之间。 
6.返回缺失的数字作为前一个元素加上`d`。 

**为什么有效**：在缺失一个数字的有效 AP 中，除了与缺失数字相邻的差异之外，所有差异都与公共差异匹配。 第一对差异大于`d`唯一标识丢失号码的位置。 算术计算可确保精确地重建缺失的数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def missingNumber(self, arr: List[int]) -> int:
        n = len(arr) + 1  # original array length
        d = (arr[-1] - arr[0]) // (n - 1)
        
        for i in range(len(arr) - 1):
            if arr[i + 1] - arr[i] != d:
                return arr[i] + d
        
        # fallback, should not be reached due to problem constraints
        return -1
```Python 实现首先计算正确的步骤`d`使用数组的第一个和最后一个元素。 然后它迭代连续的对`arr`定位异常差异，从而查明缺失的数字。 计算`arr[i] + d`直接重建缺失的元素。 

## 解决方案```go
func missingNumber(arr []int) int {
    n := len(arr) + 1
    d := (arr[len(arr)-1] - arr[0]) / (n - 1)
    
    for i := 0; i < len(arr)-1; i++ {
        if arr[i+1] - arr[i] != d {
            return arr[i] + d
        }
    }
    
    return -1
}
```Go 解决方案镜像了 Python 版本。 我们使用整数除法来计算步长，并且迭代是在切片索引上进行的。 Go 不需要对这里的边缘情况进行特殊处理，因为约束保证数组内至少有三个元素和一个缺失的数字。 

## 工作示例

 **示例1**：`arr = [5,7,11,13]`步骤计算：`d = (13 - 5) // 4 = 2`迭代：

 -`5 -> 7`：差异= 2，好的
 -`7 -> 11`：差异= 4，不匹配→缺失= 7 + 2 = 9

 **示例2**：`arr = [15,13,12]`步骤计算：`d = (12 - 15) // 3 = -1`迭代：

 -`15 -> 13`：差异 = -2，不匹配 → 缺失 = 15 + (-1) = 14

 ## 边缘情况

 **边缘情况 1：递减序列**

 AP 可能会减少。 如果步骤为负，则应用相同的逻辑，因为差异可以正确地与`d`。 我们的计算自然地处理负差异。 

**边缘情况 2：开始或结束时缺少数字**

 保证缺失的数字不是第一个或最后一个元素。 迭代逻辑检查每个连续的对； 缺失的元素将作为第一个异常差异被捕获。 

**边缘情况 3：非单位步长**

 AP 的步长可能大于 1。 通过使用计算步骤`(arr[-1] - arr[0]) // (n - 1)`，无论大小如何，我们都可以正确推断出公差，从而确保正确重建缺失的数字。
