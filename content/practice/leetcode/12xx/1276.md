## 问题理解

 该问题要求我们确定我们可以使用给定数量的番茄片和奶酪片制作多少个 **Jumbo** 和 **Small** 汉堡，而不留下任何剩余成分。 每个**巨型汉堡**需要`4`番茄片和`1`奶酪片，而每个**小汉堡**需要`2`番茄片和`1`奶酪片。 我们有两个整数，`tomatoSlices`和`cheeseSlices`，代表可用成分总数。 我们的任务是返回`[total_jumbo, total_small]`消耗所有成分。 如果不存在完全用完所有成分的组合，我们返回一个空列表`[]`。 

用代数术语重述，令`J`是巨型汉堡的数量，`S`是小汉堡的数量。 那么问题就简化为求解系统：```
4 * J + 2 * S = tomatoSlices
1 * J + 1 * S = cheeseSlices
```解必须满足`J >= 0`和`S >= 0`，并且两个数字都必须是整数。 

约束告诉我们`0 <= tomatoSlices, cheeseSlices <= 10^7`，它允许 O(1) 算术解决方案，但对于大输入来说，暴力迭代不可行。 

重要的边缘情况包括`tomatoSlices`或者`cheeseSlices`当成分无法匹配任何组合（例如，奇数番茄数量）并且当一种类型的汉堡占主导地位时，为零。 

## 方法

 **暴力方法：**

 一种幼稚的方法是迭代所有可能数量的巨型汉堡`J`从`0`到`tomatoSlices // 4`并且，对于每个，检查剩余的番茄片和奶酪片是否可以形成整数个小汉堡`S`。 虽然这保证了正确性，但效率很低，因为在最坏的情况下可能需要多达 250 万次迭代（对于`tomatoSlices = 10^7`），这是不必要的，因为这个问题可以用简单的代数来解决。 

**最佳方法：**

 关键的见解是将其视为线性方程组。 从奶酪方程`J + S = cheeseSlices`，我们可以表达`S = cheeseSlices - J`。 代入番茄方程：```
4 * J + 2 * (cheeseSlices - J) = tomatoSlices
4J + 2*cheeseSlices - 2J = tomatoSlices
2J + 2*cheeseSlices = tomatoSlices
2J = tomatoSlices - 2*cheeseSlices
J = (tomatoSlices - 2*cheeseSlices) / 2
```一次`J`计算得出，`S = cheeseSlices - J`。 该解决方案仅在以下情况下有效`J >= 0`,`S >= 0`，并且两者都是整数。 如果不满足这些条件，则不存在解决方案。

 ## 算法演练

 1. **检查可行性：** 首先，确保`tomatoSlices`至少是两倍`cheeseSlices`（否则我们无法满足每种奶酪的最低 2 个番茄要求）并且是均匀的。 如果`tomatoSlices`为奇数，不存在整数解。 
2. **计算 Jumbo 汉堡：** 使用导出公式`J = (tomatoSlices - 2 * cheeseSlices) // 2`。 
3. **计算小汉堡：**计算`S = cheeseSlices - J`。 
4. **验证解决方案：** 检查`J >= 0`和`S >= 0`。 如果其中一个为负数，则返回`[]`。 
5. **返回结果：** 返回`[J, S]`。 

**为什么有效：**

 该算法之所以有效，是因为它直接解决了描述问题的线性系统。 系统只有一个有效的整数解（如果存在）。 代数推导确保我们检查不浪费成分的充分必要条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def numOfBurgers(self, tomatoSlices: int, cheeseSlices: int) -> List[int]:
        if tomatoSlices % 2 != 0 or tomatoSlices < 2 * cheeseSlices or tomatoSlices > 4 * cheeseSlices:
            return []
        
        jumbo = (tomatoSlices - 2 * cheeseSlices) // 2
        small = cheeseSlices - jumbo
        
        if jumbo < 0 or small < 0:
            return []
        
        return [jumbo, small]
```**说明：**

 解决方案首先检查不可能的情况：奇数`tomatoSlices`每个汉堡不能平均分配 2 到 4 个，并且`tomatoSlices`外部`[2 * cheeseSlices, 4 * cheeseSlices]`不能形成有效的组合。 然后，它计算`jumbo`使用导出公式并导出`small`因此。 最终检查确保非负性。 

## 解决方案```go
func numOfBurgers(tomatoSlices int, cheeseSlices int) []int {
    if tomatoSlices%2 != 0 || tomatoSlices < 2*cheeseSlices || tomatoSlices > 4*cheeseSlices {
        return []int{}
    }

    jumbo := (tomatoSlices - 2*cheeseSlices) / 2
    small := cheeseSlices - jumbo

    if jumbo < 0 || small < 0 {
        return []int{}
    }

    return []int{jumbo, small}
}
```**Go 特定注释：**

 Go 使用切片来返回结果。 检查奇数使用模`%`。 由于 Go 不会像 Python 那样抛出越界切片异常，因此当解决方案无效时，我们可以安全地返回一个空切片。 整数除法自动将结果取整，与 Python 的相匹配`//`行为。
