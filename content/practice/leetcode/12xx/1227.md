 **难度：** 🟡 中等

 ## 解决方案

 ## 问题理解

 这个问题涉及到一个场景`n`乘客和`n`飞机上的座位。 每位乘客都有指定座位，但第一位乘客丢失了车票并随机选座。 随后的每位乘客将选择自己的座位（如果空位）或随机选择一个可用座位（如果座位已被占用）。 该问题要求最后一个或`nth`，乘客最终坐在自己指定的座位上。 

输入`n`表示乘客（和座位）总数，范围为 1 到 100,000。 输出应该是 0 到 1 之间的浮点数，表示该概率`nth`乘客有自己的座位。 

这些限制表明，对于大型企业来说，用蛮力模拟来检查每种可能的座位安排是不可行的。`n`因为排列的数量呈阶乘增长。 重要的边缘情况包括`n = 1`，其中概率一般为 1，并且`n = 2`，其中随机性对第一位乘客发挥作用。 该问题保证了`n >= 1`，所以我们不需要处理零或负乘客。 

## 方法

 蛮力方法将递归地或使用动态编程来模拟所有可能的座位安排，跟踪哪些座位被占用并计算座位被占用的情况。`nth`乘客最终坐在自己的座位上。 虽然这是正确的，但时间复杂度是阶乘，这对于`n`最多 100,000。 

关键的见解是这个问题有一个令人惊讶的简单模式。 对于任何`n > 1`，概率`nth`乘客获得座位的比例始终为 0.5。 这是因为只有两个事件会影响最后一个座位：要么第一位乘客坐在最后一个座位上`nth`直接入座（概率`1/n`），或者最终，流离失所的乘客链离开最后一个座位`nth`乘客。 递归推理或归纳表明，对于所有情况，该值都稳定为 0.5`n >= 2`。 为了`n = 1`，概率为 1。 

这种见解允许无需模拟或递归即可实现 O(1) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | Simulates all seat arrangements recursively; 对于大的来说不可行`n`|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 使用观察结果：n = 1 时概率为 1，n >= 2 时概率为 0.5 |

 ## 算法演练

 1. 检查是否`n`等于 1。如果是，则返回 1.0，因为唯一的乘客必须坐在自己的座位上。 
2. 对于所有人`n >= 2`，返回 0.5。 这是基于这样的不变量：第一位乘客恰好为最后一个座位引入了两种可能的结果：要么被第一位乘客占用，要么留给后一个乘客。`nth`经过一系列流离失所后的乘客。 
3. 以浮点数形式返回概率。 

**为什么起作用：** 第一个乘客创建了一个场景，其中最后一个座位可以由第一个乘客立即选择，也可以保留到最后一个乘客登机。 递归推理表明，每个中间乘客要么保留可用座位，要么随机重新分配可用座位，通过对称性，使`nth`乘客获得自己的座位正好是所有人的 0.5`n >= 2`。 

## Python 解决方案```python
class Solution:
    def nthPersonGetsNthSeat(self, n: int) -> float:
        if n == 1:
            return 1.0
        return 0.5
```此实现检查是否`n`为 1，并以概率 1 处理该简单情况。对于所有其他情况，它返回 0.5，捕获由第一位乘客的随机选择建立的概率模式。 不需要循环或递归，因此非常高效。 

## 解决方案```go
func nthPersonGetsNthSeat(n int) float64 {
    if n == 1 {
        return 1.0
    }
    return 0.5
}
```Go 实现反映了 Python 逻辑。 没有特殊的数据结构，所有情况都通过简单的条件处理。 该函数返回一个 float64 以满足问题的要求。 

## 工作示例

 **示例1：**`n = 1`由于只有一名乘客和一个座位，他们必须坐在自己的座位上。 输出为1.0。

 **示例2：**`n = 2`第一个乘客随机选择一个座位。 存在两种可能性：他们坐在座位 1（概率 0.5）或座位 2（概率 0.5）。 仅在第一种情况下，第二位乘客才能获得座位。 输出为0.5。 

| 步骤| 客运| 行动| 笔记|
 | ---| ---| ---| ---|
 | 1 | 1 | 占据座位 1 或 2 | 随机|

 | 结果 | - | - | 概率 = 0.5 |

 **示例3：**`n = 3`第一个乘客可以选择座位 1（好）、座位 2（取代 2）或座位 3（对 3 来说不好）。 对于第三名乘客，递归概率分析仍然得出 0.5。

 ## 边缘情况

 **单人乘客：** 何时`n = 1`，概率为 1。不处理此问题的简单实现可能会错误地返回 0.5。 

**两名乘客：** 当`n = 2`，第一位乘客引入的随机性直接影响第二位乘客。 确保正确计算该概率对于正确性至关重要。 

**大n：** 对于`n`最多 100,000 个，暴力或递归解决方案会太慢并且超出内存限制。 最佳解决方案完全避免了迭代，从而可以安全地应对极端的输入大小，而不会出现溢出或性能问题。
