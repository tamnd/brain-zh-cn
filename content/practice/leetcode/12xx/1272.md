[LeetCode 第 1272 题](https://leetcode.com/problems/remove-interval/)

 **难度：** 🟡 中等
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 该问题要求我们删除给定的区间`toBeRemoved`来自不重叠的排序间隔列表`intervals`。 每个区间表示为`[a, b)`并包括所有数字`x`这样`a <= x < b`。 删除间隔意味着我们需要调整或分割与重叠的任何现有间隔`toBeRemoved`，生成一个新的间隔列表，其中排除所有数字`toBeRemoved`。 

输入`intervals`保证按开始时间排序且不重叠。 这确保了每个区间都可以独立考虑与`toBeRemoved`。 输出还应该排序且不重叠，与输入表示一致。 

重要的边缘情况包括完全之前或之后的间隔`toBeRemoved`，完全包含在其中的区间`toBeRemoved`，以及在开始或结束时部分重叠的间隔。 限制条件`1 <= intervals.length <= 10^4`和`-10^9 <= ai < bi <= 10^9`表明一个`O(n)`解决方案是可以接受的，但是任何明显慢得多的解决方案都可能表现不佳。 

## 方法

 蛮力方法将涉及生成每个间隔表示的所有数字，删除落入其中的任何数字`toBeRemoved`，然后重建区间。 虽然正确，但效率很低，因为当间隔很大时，它需要处理潜在的数十亿个数字。 

最佳方法利用了间隔已排序且不相交的事实。 对于每个间隔`[start, end)`:

 1.如果之前完全说谎`toBeRemoved`，它未受影响。 
2.如果之后完全躺着`toBeRemoved`，它未受影响。 
3. 如果与`toBeRemoved`，它可能需要分成两个间​​隔：一个在之前`toBeRemoved`以及之后的一张`toBeRemoved`。 

这可以在一次通过中完成`intervals`在`O(n)`时间，无需创建中间的数字列表。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(M)| O(M)| 生成区间内的所有数字并删除区间内的数字`toBeRemoved`，其中 M 是所有间隔的长度之和。 对于大范围来说太慢。 |
 | 最佳 | O(n) | O(n) | 单遍，仅分割重叠间隔。 高效且简单。 |

 ## 算法演练

 1.初始化一个空列表`result`存储删除后的间隔。 
2. 迭代每个区间`[start, end)`在`intervals`。 
3.如果`end <= toBeRemoved[0]`或者`start >= toBeRemoved[1]`, 追加`[start, end)`到`result`因为它不重叠。 
4.如果`start < toBeRemoved[0]`和`end > toBeRemoved[0]`, 追加`[start, toBeRemoved[0]]`到`result`。 这处理重叠的左侧部分。 
5.如果`start < toBeRemoved[1]`和`end > toBeRemoved[1]`, 追加`[toBeRemoved[1], end]`到`result`。 这处理重叠的右侧部分。 
6. 继续迭代，直到处理完所有区间。 
7. 返回`result`。 

**为什么有效：** 关键的不变性是间隔是不相交的且已排序，因此每个间隔都可以独立考虑。 通过将重叠间隔分成最多两部分并保持非重叠间隔不变，我们保证输出保持排序和不相交，并排除`toBeRemoved`。 

## Python 解决方案```python
from typing import List

class Solution:
    def removeInterval(self, intervals: List[List[int]], toBeRemoved: List[int]) -> List[List[int]]:
        result = []
        remove_start, remove_end = toBeRemoved
        
        for start, end in intervals:
            if end <= remove_start or start >= remove_end:
                result.append([start, end])
            else:
                if start < remove_start:
                    result.append([start, remove_start])
                if end > remove_end:
                    result.append([remove_end, end])
                    
        return result
```**解释：** 我们迭代每个间隔。 如果它完全位于外面`toBeRemoved`，我们将其添加不变。 如果重叠，我们检查左侧和右侧部分是否在外面`toBeRemoved`并分别附加它们。 这确保了没有数字`toBeRemoved`保留在输出中。 

## 解决方案```go
func removeInterval(intervals [][]int, toBeRemoved []int) [][]int {
    result := [][]int{}
    removeStart, removeEnd := toBeRemoved[0], toBeRemoved[1]
    
    for _, interval := range intervals {
        start, end := interval[0], interval[1]
        if end <= removeStart || start >= removeEnd {
            result = append(result, []int{start, end})
        } else {
            if start < removeStart {
                result = append(result, []int{start, removeStart})
            }
            if end > removeEnd {
                result = append(result, []int{removeEnd, end})
            }
        }
    }
    
    return result
}
```**Go 特定说明：** 我们使用切片来存储间隔，并自动附加处理动态调整大小。 Nil 切片不是问题，因为我们初始化了`result`到一个空切片。
