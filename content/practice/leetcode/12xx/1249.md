[LeetCode 问题 1249](https://leetcode.com/problems/minimum-remove-to-make-valid-parentheses/)

 **难度：** 🟡 中等
 **主题：** 字符串、堆栈

 ## 解决方案

 ## 问题理解

 问题是要求我们处理一个包含小写字母和括号的字符串，并删除最少数量的括号以使剩余的字符串有效。 有效的字符串由通常的括号规则定义：每个左括号`'('`必须有相应的右括号`')'`，并且括号必须正确嵌套。 输入字符串可能很大，最多 100,000 个字符，并且可能包含多个放错位置或多余的括号。 输出是通过删除尽可能少的括号形成的任何有效字符串； 它不需要是唯一的。 

关键的观察结果是小写字母始终有效并且不需要删除，并且可以通过仔细跟踪不匹配的括号在线性时间内解决问题。 重要的边缘情况包括完全是括号的字符串、具有所有有效括号的字符串、字母中散布着不匹配括号的字符串以及删除后变为空的字符串。 

## 方法

 暴力方法涉及通过删除各种括号组合并检查每个组合的有效性来生成所有可能的字符串。 虽然正确，但效率极低，因为组合的数量随着括号的数量呈指数增长。 

最佳方法使用堆栈来跟踪不匹配左括号的索引`'('`并分两次处理该字符串。 第一遍删除不匹配的右括号`')'`如果堆栈中没有相应的左括号，则跳过它们。 第二遍通过使用存储在堆栈中的索引来删除任何剩余的不匹配的左括号。 这确保了最少的删除次数，因为我们只删除不匹配的括号。

 ## 算法演练

 1. 初始化一个空栈来存储不匹配的索引`'('`字符和一个空集来记录要删除的括号的索引。 
2. 从左到右迭代字符串。 对于每个字符，如果是`'('`，将其索引压入堆栈。 如果是的话`')'`并且堆栈不为空，则弹出堆栈（匹配一对）。 如果是的话`')'`并且堆栈为空，标记该索引以进行删除。 
3. 完成第一遍后，堆栈中剩余的任何索引都对应于不匹配的`'('`。 也标记这些索引以进行删除。 
4. 通过迭代原始字符串并跳过索引标记为要删除的任何字符来构建结果字符串。 
5. 返回结果字符串。 

**为什么有效：** 通过维护堆栈，我们确保每个`')'`有一个匹配的`'('`在它之前，以及任何剩余的`'('`没有匹配的将被删除。 这保证了结果字符串是有效的，并且删除了最少数量的括号，因为我们从不删除匹配对。 

## Python 解决方案```python
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        stack = []
        to_remove = set()
        
        for i, char in enumerate(s):
            if char == '(':
                stack.append(i)
            elif char == ')':
                if stack:
                    stack.pop()
                else:
                    to_remove.add(i)
        
        to_remove.update(stack)
        
        result = []
        for i, char in enumerate(s):
            if i not in to_remove:
                result.append(char)
        
        return ''.join(result)
```Python实现使用堆栈来跟踪不匹配的`'('`字符和集合`to_remove`存储不匹配的索引`')'`。 第一个循环迭代字符串以查找不匹配的括号。 在第一个循环之后，堆栈中的任何剩余索引都是不匹配的`'('`，它们被添加到`to_remove`。 最后，我们再次迭代字符串以构造结果，同时跳过索引`to_remove`。 

## 解决方案```go
func minRemoveToMakeValid(s string) string {
	stack := []int{}
	toRemove := make(map[int]bool)
    
	for i, char := range s {
		if char == '(' {
			stack = append(stack, i)
		} else if char == ')' {
			if len(stack) > 0 {
				stack = stack[:len(stack)-1]
			} else {
				toRemove[i] = true
			}
		}
	}
    
	for _, idx := range stack {
		toRemove[idx] = true
	}
    
	var result []rune
	for i, char := range s {
		if !toRemove[i] {
			result = append(result, char)
		}
	}
    
	return string(result)
}
```在 Go 中，我们使用切片作为堆栈和映射`toRemove`存储不匹配括号的索引。 该方法与 Python 版本相同，但在附加字符以安全地处理 Unicode 时，Go 需要从字符串显式转换为符文切片，即使问题约束是 ASCII 字母和括号。

 ## 边缘情况

 一个重要的边缘情况是仅包含括号的字符串，例如`"))(("`。 在这种情况下，所有括号都不匹配，正确的结果是空字符串。 假设字母存在的简单实现可能会在这里失败。 

第二个边缘情况是一个字符串，其中所有括号都正确嵌套，但中间存在一些字母，例如`"(a(b)c)"`。 该算法正确地保留字母并匹配括号，因为它只删除不匹配的括号。
