[LeetCode 第 1289 题](https://leetcode.com/problems/minimum-falling-path-sum-ii/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们计算正方形中**具有非零位移**的下降路径的最小总和`n x n`矩阵。 下降路径是通过从每一行中恰好选择一个元素来形成的，并且约束条件是没有两个连续元素来自同一列。 本质上，当您向下移动行时，您选择的列必须改变。 

输入`grid`是表示矩阵的二维整数数组。 预期输出是一个整数，表示在非零移位条件下可实现的最小可能总和。 

约束表明`n`可以大到 200，元素值范围从 -99 到 99。这意味着所有可能路径的强力枚举将太慢，因为潜在路径的数量为`n^(n)`。 该问题保证每行至少有一个元素，因此我们不需要处理空矩阵。 可能导致简单方法失败的边缘情况包括具有负值的矩阵、所有元素都相同的矩阵或单行矩阵。 

## 方法

 强力方法涉及通过递归探索每行中的每个选择来生成所有可能的路径，同时避开前一行中的列。 这保证了正确性，但复杂性呈指数级增长（`O(n^n)`）因此不可行`n`最多 200 个。 

最佳解决方案的关键见解是**具有行状态压缩的动态编程**。 对于每一行，我们可以通过考虑所有其他列中前一行的最小总和来计算每列结束的最小下降路径总和。 进一步的优化是跟踪前一行的**最小和第二小值**，这使我们能够以每个单元格的 O(1) 计算当前单元格的最小值，而不是扫描所有列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^n) | O(n^n) | O(n) | 递归探索具有列约束的所有路径 |
 | 具有最小跟踪的最佳 DP | O(n^2) | O(n^2) | O(n) | 使用前一行最小值有效更新当前行 |

 ## 算法演练

 1. 初始化一维数组`dp`存储以第一行的每一列结束的最小路径和。 这只是第一行的值。 
2. 对于每个后续行，确定最小的 (`min1`）和第二小的（`min2`）值来自`dp`上一行的列索引以及`min1`。 
3. 对于每一列`j`在当前行中，将新的 DP 值更新为`grid[i][j] + (min1 if j != min1_index else min2)`。 这确保我们不会重复使用前一行中的同一列。 
4.处理完该行后，替换`dp`与新行的计算值。 
5. 迭代所有行后，结果为最终的最小值`dp`。 

**为什么它起作用：** 通过始终携带前一行的最小值和第二最小值，我们保证每个单元格从前一行中选择最小的可能总和，同时遵守非零移位约束。 这确保了每一步的最优性并导致全局最小总和。 

## Python 解决方案```python
from typing import List

class Solution:
    def minFallingPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dp = grid[0][:]  # Initialize with the first row
        
        for i in range(1, n):
            new_dp = [0] * n
            # Find the smallest and second smallest in the previous row
            min1 = min2 = float('inf')
            min1_index = -1
            for j in range(n):
                if dp[j] < min1:
                    min2 = min1
                    min1 = dp[j]
                    min1_index = j
                elif dp[j] < min2:
                    min2 = dp[j]
            
            for j in range(n):
                new_dp[j] = grid[i][j] + (min1 if j != min1_index else min2)
            
            dp = new_dp
        
        return min(dp)
```该实现首先将第一行复制到`dp`。 对于每一行，它计算前一行的最小和第二小总和。 通过将相应的网格值添加到正确的最小值来更新新行中的每个元素。 这可以避免在相邻行中重复使用同一列。 最后，它返回最后一行的最小值。 

## 解决方案```go
func minFallingPathSum(grid [][]int) int {
    n := len(grid)
    dp := make([]int, n)
    copy(dp, grid[0])
    
    for i := 1; i < n; i++ {
        newDP := make([]int, n)
        min1, min2 := int(1e9), int(1e9)
        min1Index := -1
        
        for j := 0; j < n; j++ {
            if dp[j] < min1 {
                min2 = min1
                min1 = dp[j]
                min1Index = j
            } else if dp[j] < min2 {
                min2 = dp[j]
            }
        }
        
        for j := 0; j < n; j++ {
            if j != min1Index {
                newDP[j] = grid[i][j] + min1
            } else {
                newDP[j] = grid[i][j] + min2
            }
        }
        dp = newDP
    }
    
    result := dp[0]
    for _, val := range dp {
        if val < result {
            result = val
        }
    }
    return result
}
```在 Go 中，我们使用切片而不是列表，并手动跟踪最小值的索引。 我们使用大量`1e9`作为初步比较`min1`和`min2`。 将第一行复制到`dp`确保正确的初始化。 

## 工作示例

 **示例1：**`grid = [[1,2,3],[4,5,6],[7,8,9]]`初始dp：`[1,2,3]`第 1 行处理：min1=1（索引 0），min2=2

 新的DP：`[4+2=6, 5+1=6, 6+1=7] → [6,6,7]`第2行处理：min1=6（索引0），min2=6

 新的DP：`[7+6=13, 8+6=14, 9+6=13] → [13,14,13]`最终结果：`min([13,14,13]) = 13`**示例2：**`grid = [[7]]`只有一行，结果 = 7

 ## 边缘情况

 一种重要的边缘情况是**单元素矩阵**，其中算法必须正确返回该元素而不访问越界索引。 我们的 DP 初始化自然地处理了这个问题。 

另一种边缘情况涉及**最小值出现在多个列中的行**，这可能会影响最小值和第二小值之间的选择。 跟踪索引可确保同一列永远不会重复使用，即使值重复也是如此。 

第三种边缘情况是**负数**，其中求和可能会减少总数。 该算法可以正确处理负值，因为动态规划更新不假设正值； 最小值由实际总和而不是绝对值确定。
