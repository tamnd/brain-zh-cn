 **主题：** 字符串、回溯、设计、迭代器

 ## 解决方案

 ## 问题理解

 问题要求我们设计一个类`CombinationIterator`从一串已排序的不同小写字母生成给定长度的所有组合。 迭代器必须按**字典顺序**返回这些组合，即按字母顺序排列。 

输入由两个部分组成：一个字符串`characters`，其中包含按升序排序的唯一字母和一个整数`combinationLength`，指定每个组合的大小。 预期输出为`next()`是按字典顺序排列的下一个组合，并且`hasNext()`应表明是否有更多组合可用。 

约束限制`characters`至多长度 15 并保证有效调用`next()`。 这确保了我们永远不会请求超出现有组合的组合，并且还使组合总数保持可控，因为 15 选择 7（组合的最大中点）是 6435，这在计算上是可行的。 

重要的边缘情况包括`combinationLength`等于 1（返回单个字符），`combinationLength`等于长度`characters`（返回字符串本身），以及重复调用的情况`next()`穷尽所有组合。 输入保证字符的唯一性，因此我们不需要处理重复项。 

## 方法

 暴力方法会预先生成所有可能的组合并将它们存储在列表中。 这确保了`next()`和`hasNext()`通过沿着列表移动索引来实现很简单。 然而，提前生成所有组合可能会占用大量内存，并且如果不需要所有组合，则没有必要。 

更好的解决方案的关键观察是可以**延迟**生成组合，即仅当`next()`被调用，使用索引数组来跟踪当前组合。 这使我们能够按字典顺序有效地生成下一个组合，而无需立即存储所有组合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n, k)) | O(C(n, k)) | O(C(n, k) * k) | O(C(n, k) * k) | 预先计算所有组合并迭代它们。 |
 | 最佳| 每 O(k)`next()`| O(k) | 跟踪当前组合索引并按字典顺序动态更新。 |

 ## 算法演练

 1.初始化一个数组`indices`尺寸的`combinationLength`包含第一个`combinationLength`指数`[0, 1, ..., combinationLength-1]`。 这代表字符的第一个组合。 
2. 维护旗帜`has_next`指示是否存在更多组合。 最初，它是`True`。 
3. 在`next()`方法，转换电流`indices`到相应的组合字符串中，并为下一个组合准备索引。 
4. 前进`indices`对于下一个组合，从最右边的索引开始并尝试递增它。 如果达到最大允许值（`n - (combinationLength - i)`），向左移动直到可以增加，然后按顺序重置所有后续索引。 
5. 如果没有索引可以递增，则设置`has_next`到`False`。 
6. 的`hasNext()`方法只是返回`has_next`旗帜。 

为什么它有效：不变的是`indices`始终代表有效的词典组合。 增加最右边的可能索引可确保我们按照严格的顺序生成组合，而不会跳过任何组合。 

## Python 解决方案```python
class CombinationIterator:

    def __init__(self, characters: str, combinationLength: int):
        self.characters = characters
        self.combinationLength = combinationLength
        self.indices = list(range(combinationLength))
        self.has_next = True

    def next(self) -> str:
        if not self.has_next:
            return ""
        # Generate the current combination string
        current = ''.join(self.characters[i] for i in self.indices)
        # Prepare indices for the next combination
        n = len(self.characters)
        i = self.combinationLength - 1
        while i >= 0 and self.indices[i] == n - self.combinationLength + i:
            i -= 1
        if i < 0:
            self.has_next = False
        else:
            self.indices[i] += 1
            for j in range(i + 1, self.combinationLength):
                self.indices[j] = self.indices[j - 1] + 1
        return current

    def hasNext(self) -> bool:
        return self.has_next
```Python 实现初始化索引来表示第一个组合。 每次致电`next()`生成当前组合字符串并更新`indices`到下一个有效组合。 这`has_next`flag 有效地跟踪是否还有更多组合。 

## 解决方案```go
type CombinationIterator struct {
    characters string
    combinationLength int
    indices []int
    hasNext bool
}

func Constructor(characters string, combinationLength int) CombinationIterator {
    indices := make([]int, combinationLength)
    for i := 0; i < combinationLength; i++ {
        indices[i] = i
    }
    return CombinationIterator{characters: characters, combinationLength: combinationLength, indices: indices, hasNext: true}
}

func (this *CombinationIterator) Next() string {
    if !this.hasNext {
        return ""
    }
    current := make([]byte, this.combinationLength)
    for i, idx := range this.indices {
        current[i] = this.characters[idx]
    }
    n := len(this.characters)
    i := this.combinationLength - 1
    for i >= 0 && this.indices[i] == n - this.combinationLength + i {
        i--
    }
    if i < 0 {
        this.hasNext = false
    } else {
        this.indices[i]++
        for j := i + 1; j < this.combinationLength; j++ {
            this.indices[j] = this.indices[j-1] + 1
        }
    }
    return string(current)
}

func (this *CombinationIterator) HasNext() bool {
    return this.hasNext
}
```Go 实现镜像了 Python 逻辑，主要区别在于切片处理和显式字节到字符串转换。 这`indices`切片和`hasNext`标志具有相同的作用。 

## 工作示例

 示例：`CombinationIterator("abc", 2)`| 步骤| 指数| 当前组合 | 有下一个 |
 | ---| ---| ---| ---|
 | 初始化| [0,1]| “ab”| 真实|
 | 调用 next() | [0,1] → [0,2] | “ab”| 真实|
 | 调用 next() | [0,2] → [1,2] | “交流”| 真实|
 | 调用 next() | [1,2] → 无 | “BC”| 假 |

 在每一步中，最右边的可递增索引都会被更新，并且所有后续索引都会被重置，从而按字典顺序生成所有组合。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | 每 O(k)`next()`| 更新索引并生成长度的字符串`k`。 |
 | 空间| O(k) | 只有`indices`大小数组`combinationLength`被存储。 |

 该算法不会预先计算所有组合，从而节省大量空间。 每个`next()`调用仅执行与以下比例成比例的有限数量的操作`combinationLength`。

 ## 边缘情况

 一种边缘情况是`combinationLength = 1`，其中字符串中的每个字符都是一个组合。 这可能会导致假设每个组合有多个字符的实现失败。 我们的方法可以自然地处理它，因为索引数组仍然正确地表示位置。 

另一个边缘情况是当`combinationLength`等于长度`characters`。 只有一种有效组合，并且`next()`应该立即返回字符串并设置`hasNext`为假。 最右边的索引增量逻辑无需附加条件即可处理此问题。 

第三种边缘情况是重复调用`next()`用尽所有组合后。 因为`hasNext`当不可能进一步增加时设置为 false，随后`next()`调用返回空字符串，而不是产生错误或无效组合。 这确保了重复调用时的安全行为。
