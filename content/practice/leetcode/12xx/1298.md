[LeetCode 第 1298 题](https://leetcode.com/problems/maximum-candies-you-can-get-from-boxes/)

 **难度：** 🔴难
 **主题：** 数组、广度优先搜索、图论

 ## 解决方案

 ## 问题理解

 该问题要求我们确定从一组具有不同可访问性的盒子中可以收集的最大糖果数量。 每个盒子最初可能是打开或关闭的，可能包含糖果、其他盒子的钥匙以及里面的其他盒子。 我们从一组初始盒子开始，只有当一个盒子已经打开或者我们已经从另一个盒子获得了它的钥匙时，我们才能打开它。 一旦盒子被打开，我们就可以拿走它的所有糖果，获取它的钥匙，并取回它包含的任何盒子。 

输入数组是`status`,`candies`,`keys`,`containedBoxes`， 和`initialBoxes`。 各指标`i`对应于一个盒子，及其状态、糖果数量、钥匙和所包含的盒子。 输出是一个整数，表示按照规则收集的糖果总数。 

约束表明`n`最多可以为 1000 个，每个盒子的糖果数量最多可以为 1000 个，每个盒子可以包含多个钥匙或盒子，但每个盒子最多包含一个其他盒子。 这确保了盒子之间不会出现循环，并且 BFS 或 DFS 遍历是可行的。 

重要的边缘情况包括所有盒子最初关闭而没有可用的钥匙，包含我们最初没有的盒子钥匙的盒子，或者访问取决于顺序收集钥匙的盒子链。 

## 方法

 暴力方法需要递归地尝试所有可能的打开盒子和收集钥匙的序列。 我们可以将每个动作序列建模为递归调用，尝试打开我们当前可以访问的每个盒子，收集糖果、钥匙和包含的盒子。 虽然正确，但由于序列数量呈指数增长，这种方法是不可行的`n`增长到1000。 

更优化解决方案的关键见解是将问题建模为使用 BFS 或 DFS 的图遍历。 每个盒子都可以被视为一个节点，键或包含的盒子为其他节点提供边缘。 使用队列和集合来跟踪可用盒子，我们可以迭代地打开盒子，收集糖果，并将新盒子或钥匙添加到可用集合中。 这保证了我们以高效的方式打开我们可以访问的每个盒子，而无需多余的工作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试打开盒子和收集钥匙的所有顺序。 指数增长。 |
 | 最优 BFS/DFS | O(n + m) | O(n + m) | 使用集合和队列的 BFS 遍历来有效地收集糖果和钥匙。`m`是所有盒子中钥匙/盒子的总数。 |

 ## 算法演练

 1. 初始化队列或设置`initialBoxes`我们拥有。 
2. 维护一组我们目前拥有的钥匙和一组可以打开的盒子。 
3. 初始化变量`total_candies`到 0 来累积收集的糖果。 
4. 虽然有箱子可以打开：

 1. 从集合中选择一个盒子。 
2. 如果盒子是打开的或者我们有钥匙，请打开它。 
3.将盒子里的糖果添加到`total_candies`。 
4. 将此框中的任何新密钥添加到我们的密钥集中。 
5. 将任何包含的盒子添加到我们的可用盒子集中。 
6. 将盒子标记为已打开，以防止再次访问。 
5. 重复此操作，直至无法再打开任何盒子。 
6. 返回`total_candies`。 

工作原理：BFS/DFS 遍历确保所有可通过键访问的框和包含的框都被访问一次。 不变的是，在任何时候，我们只尝试打开我们可以直接或通过收集的钥匙访问的盒子，保证不会错过收集糖果的机会。 

## Python 解决方案```python
from typing import List
from collections import deque

class Solution:
    def maxCandies(self, status: List[int], candies: List[int], keys: List[List[int]], containedBoxes: List[List[int]], initialBoxes: List[int]) -> int:
        available = set(initialBoxes)
        obtained_keys = set()
        opened = set()
        total_candies = 0
        queue = deque(initialBoxes)
        
        while queue:
            box = queue.popleft()
            if box in opened:
                continue
            if status[box] == 1 or box in obtained_keys:
                total_candies += candies[box]
                opened.add(box)
                for key in keys[box]:
                    if key not in obtained_keys:
                        obtained_keys.add(key)
                        if key in available and key not in opened:
                            queue.append(key)
                for contained in containedBoxes[box]:
                    if contained not in opened:
                        queue.append(contained)
                        available.add(contained)
            else:
                queue.append(box)
        
        return total_candies
```在这个实现中，我们维护一个用于 BFS 遍历的队列，并设置跟踪打开的盒子、可用的盒子和获取的密钥。 无法立即打开的箱子将重新排队，直到我们最终收集到必要的钥匙。 

## 解决方案```go
func maxCandies(status []int, candies []int, keys [][]int, containedBoxes [][]int, initialBoxes []int) int {
    available := make(map[int]bool)
    obtainedKeys := make(map[int]bool)
    opened := make(map[int]bool)
    queue := []int{}
    totalCandies := 0

    for _, box := range initialBoxes {
        available[box] = true
        queue = append(queue, box)
    }

    for len(queue) > 0 {
        box := queue[0]
        queue = queue[1:]
        if opened[box] {
            continue
        }
        if status[box] == 1 || obtainedKeys[box] {
            totalCandies += candies[box]
            opened[box] = true
            for _, key := range keys[box] {
                if !obtainedKeys[key] {
                    obtainedKeys[key] = true
                    if available[key] && !opened[key] {
                        queue = append(queue, key)
                    }
                }
            }
            for _, contained := range containedBoxes[box] {
                if !opened[contained] {
                    queue = append(queue, contained)
                    available[contained] = true
                }
            }
        } else {
            queue = append(queue, box)
        }
    }

    return totalCandies
}
```Go 实现反映了 Python 逻辑，包括轨迹集映射、队列切片和直接整数累加。 我们将 nil 切片自然地处理为附加到切片。

 | 测量| 复杂性 | 说明|
