 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定范围内的所有整数`[low, high]`其数字是**连续的**，这意味着每个数字都比前一个数字大一位。 例如，`123`是连续的，因为`2 = 1 + 1`和`3 = 2 + 1`， 但`135`不是连续的，因为数字不连续增加。 

输入由两个整数组成，`low`和`high`，它定义了我们需要找到这些数字的包含范围。 输出是满足此范围内的顺序属性的整数的**排序列表**。 

约束表明`low`和`high`至少两者都是`10`并且至多`10^9`。 这个上限排除了所有整数的暴力枚举，因为从`10`到`10^9`会太慢了。 我们需要一种仅生成连续数字的方法，而不检查范围内的每个整数。 

重要的边缘情况包括边界处的数字，例如`low`本身或`high`本身是有顺序的。 此外，我们需要考虑不同长度（位数）的数字，因为 2 位连续数字是有效的，但 1 位数字低于最小约束。 

## 方法

 **暴力方法**很简单：迭代中的每个整数`[low, high]`并检查其数字是否连续。 这是正确的，但效率极低，因为该范围可能包含多达十亿个数字。 检查每个数字是不必要的，因为连续数字在范围内形成非常稀疏的集合。 

**最佳方法**利用了连续数字高度结构化的事实。 所有连续的数字都可以由数字开头生成`1`通过`9`并重复附加下一个连续数字，直到超过允许的最大位数或值超过`high`。 通过以这种方式系统地生成序列，我们可以避免迭代绝大多数永远不可能连续的数字。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(高-低) | O(1) | O(1) | 迭代每个数字并检查是否连续 |
 | 最佳| O(1) 相对于范围大小 | O(1) 额外 | 系统地生成序列号； 连续数字的总数受位数（常数）限制 |

 ## 算法演练

 1. 初始化一个列表`result`来存储连续的数字。 
2. 迭代起始数字`1`到`9`。 
3. 对于每个起始数字，通过重复附加下一个连续数字来构建数字，直到数字超过`high`或者最后一位数字变成`9`。 
4. 生成数字后，检查是否在范围内`[low, high]`。 如果是，则将其添加到`result`列表。 
5. 对所有起始数字继续此过程，以生成所有连续数字。 
6.最后，排序`result`列表以确保在返回之前按升序排列。 

**为什么有效：** 该算法之所以有效，是因为每个序列号完全由其起始数字和长度决定。 通过系统地生成从每个数字开始的所有序列，我们保证产生该范围内的每个可能的序列号，而不会产生任何无效数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        result = []
        for start in range(1, 10):
            num = start
            next_digit = start
            while next_digit < 10:
                if low <= num <= high:
                    result.append(num)
                next_digit += 1
                num = num * 10 + next_digit
        return sorted(result)
```Python 实现紧密遵循该算法。 我们迭代起始数字`1`通过`9`并通过附加数字顺序构建数字。 每次追加时，我们都会检查数字是否在范围内`[low, high]`。 最后，我们对列表进行排序，因为从较小的起始数字生成的数字可能不会自动按升序排列。 

## 解决方案```go
func sequentialDigits(low int, high int) []int {
    var result []int
    for start := 1; start <= 9; start++ {
        num := start
        nextDigit := start
        for nextDigit < 10 {
            if num >= low && num <= high {
                result = append(result, num)
            }
            nextDigit++
            num = num*10 + nextDigit
        }
    }
    // Sort the slice in ascending order
    for i := 0; i < len(result)-1; i++ {
        for j := i + 1; j < len(result); j++ {
            if result[i] > result[j] {
                result[i], result[j] = result[j], result[i]
            }
        }
    }
    return result
}
```在 Go 中，我们遵循相同的逻辑。 Go 没有内置的`sorted`函数用于整数切片，因此我们使用嵌套循环进行排序。 否则，序列号的生成与 Python 方法相同。

 ## 边缘情况

 **边缘情况 1：** 范围低于 10，例如，`[1, 9]`。 由于连续数字必须至少有 2 位数字，因此该算法会正确返回空列表。 

**边缘情况 2：** 范围仅与有效数字部分重叠，例如，`[90, 100]`。 不存在序列号，但算法仍然生成序列并按范围过滤，返回空结果。 

**边缘情况 3：** 靠近上限的数字非常大，例如，`[123456789, 987654321]`。 该算法通过生成最多可能位数的序列来正确处理这些问题，并且仅包含给定范围内的有效数字。 没有整数
