[LeetCode 第 1218 题](https://leetcode.com/problems/longest-arithmetic-subsequence-of-given-difference/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求给定数组中最长算术子序列的长度`arr`使得连续元素之间的差等于指定的整数`difference`。 子序列可以跳过元素，但必须保留原始顺序。 

换句话说，对于每个元素`arr[i]`在数组中，我们想知道如果每个元素与前一个元素完全不同，则以该元素结束的序列可以有多长`difference`。 预期输出是所有此类序列中的最大长度。 

输入数组`arr`最多可以有`10^5`元素，每个元素的范围可以是`-10^4`到`10^4`， 和`difference`也在同一范围内。 这表明任何显式探索所有子序列的强力解决方案都会太慢。 要考虑的边缘情况包括所有元素都相同的数组、没有比一个元素长的有效算术子序列的数组以及负差。 

## 方法

 蛮力方法将涉及生成所有可能的子序列`arr`并检查每个数是否形成具有给定差值的算术序列。 虽然这在原则上是正确的，但效率极低，因为子序列的数量随着序列的长度呈指数增长。`arr`。 具体来说，生成大小数组的所有子序列`n`需要 O(2^n) 时间，这对于`n = 10^5`。 

最佳解决方案的关键在于我们不需要生成所有子序列。 相反，我们可以使用哈希图来跟踪以每个值结尾的最长算术子序列的长度。 如果`arr[i] - difference`存在于哈希映射中，我们可以通过包含来扩展该子序列`arr[i]`。 这种方法利用哈希表进行动态编程，实现线性时间复杂度，因为我们只处理每个元素一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成所有子序列并检查差异 |
 | 最佳 | O(n) | O(n) | 使用哈希图动态跟踪子序列长度 |

 ## 算法演练

 1.初始化一个空的哈希图`dp`在哪里`dp[value]`存储以结尾的最长算术子序列的长度`value`。 
2. 初始化变量`max_len`为零以跟踪找到的总体最长子序列。 
3. 迭代每个元素`num`在数组中`arr`。 
4. 对于每个`num`，检查是否`num - difference`存在于`dp`。 如果是这样，则意味着我们可以扩展以`num - difference`通过包括`num`。 否则，开始一个长度为 1 的新子序列。 
5. 更新`dp[num]`使用新的长度，从 1 开始或扩展前一个子序列。 
6. 更新`max_len`如果`dp[num]`大于当前`max_len`。 
7. 处理完所有元素后，`max_len`包含最长算术子序列的长度。 

工作原理：哈希映射确保对于每个数字，我们都知道以该数字结尾的有效子序列的最大长度。 通过始终从以下位置扩展序列`num - difference`如果存在，我们正在有效地动态构建最长的可能子序列。 

## Python 解决方案```python
from typing import List

class Solution:
    def longestSubsequence(self, arr: List[int], difference: int) -> int:
        dp = {}
        max_len = 0
        
        for num in arr:
            dp[num] = dp.get(num - difference, 0) + 1
            max_len = max(max_len, dp[num])
        
        return max_len
```该实现初始化一个空字典`dp`存储以每个值结尾的子序列的长度。 对于中的每个元素`arr`，它要么扩展之前结尾的子序列`num - difference`或开始一个新的。 这`max_len`变量跟踪总体最大长度，该长度在最后返回。 

## 解决方案```go
func longestSubsequence(arr []int, difference int) int {
    dp := make(map[int]int)
    maxLen := 0
    
    for _, num := range arr {
        dp[num] = dp[num-difference] + 1
        if dp[num] > maxLen {
            maxLen = dp[num]
        }
    }
    
    return maxLen
}
```在 Go 中，我们使用地图`dp`跟踪子序列的长度。 与 Python 的主要区别在于类型声明和映射默认值的处理：访问 Go 映射中缺失的键会返回值类型的零值，这对于该算法来说是完美的，因为缺失的键自然会返回 0。我们更新`maxLen`与Python类似。
