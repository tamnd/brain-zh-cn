[LeetCode 第 1274 题](https://leetcode.com/problems/number-of-ships-in-a-rectangle/)

 **难度：** 🔴难
 **主题：** 数组、分而治之、交互

 ## 解决方案

 ## 问题理解

 该问题提出了一个交互式场景，其中船舶被放置在笛卡尔平面上的整数坐标处。 你不知道它们的位置，每个坐标最多包含一艘船。 给定两个点，分别代表矩形的左下角和右上角，您需要确定该矩形内包含的船只数量。 

收集有关船舶位置信息的唯一方法是通过 API`Sea.hasShips(topRight, bottomLeft)`，它返回一个布尔值，指示给定矩形内是否至少有一艘船。 挑战在于统计使用尽可能少的呼叫的所有船舶，硬性限制为 400 次呼叫。 该问题保证任何查询的矩形中最多有 10 艘船，这允许有效的分而治之策略。 

关键的边缘情况包括查询没有船只的矩形、只有一个点的矩形（其中右上等于左下）以及船只聚集在角上的矩形。 保证`topRight != bottomLeft`通过避免初始输入中的零面积矩形，稍微简化了问题。 

## 方法

 强力方法是单独查询矩形内的每个整数点。 对于每个点`(x, y)`在这个范围内，我们可以调用`hasShips(Point(x, y), Point(x, y))`并数一下船只。 虽然正确，但效率非常低，因为矩形的面积可能高达 1001 × 1001 点，导致超过一百万次 API 调用。 这显然超出了 400 次调用的限制，因此不切实际。 

最佳方法利用**分而治之**策略。 关键的见解是，如果一个矩形包含至少一艘船，您可以将其细分为四个较小的矩形（象限）并递归检查每个矩形。 如果矩形中没有船只，您可以立即跳过它。 通过反复细分，算法放大了船舶所在的各个点。 由于最多有 10 艘船，因此递归深度和调用数量仍然在可控范围内。 该策略类似于四叉树搜索，有效地修剪空区域。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(宽 * 高) | O(1) | O(1) | 单独检查每个点； 对于大矩形不可行 |
 | 分而治之| O(S * log(W*H)) | O(log(宽*高)) | 递归地将矩形分割为象限； S = 船舶数量 |

 ## 算法演练

 1. 从定义的输入矩形开始`bottomLeft`和`topRight`。 
2. 打电话`sea.hasShips(topRight, bottomLeft)`。 如果这返回`False`，因为没有船只，所以立即返回 0。 
3. 如果矩形代表单个点（`topRight.x == bottomLeft.x`和`topRight.y == bottomLeft.y`） 和`hasShips`回报`True`，返回 1，因为只有一艘船。 
4. 否则，使用沿 x 轴和 y 轴的中点将矩形分成四个较小的矩形。 计算中点为`midX = (topRight.x + bottomLeft.x) // 2`和`midY = (topRight.y + bottomLeft.y) // 2`。 
5. 在每个象限上递归调用该函数：

 - 左下象限
 - 右下象限
 - 左上象限
 - 右上象限
 6. 将四次递归调用的结果相加，得到当前矩形内的船舶总数。 
7. 返回该总数。 

工作原理：分而治之确保每个递归调用要么检测不到船舶，要么在点级别隔离一艘船舶。 通过对所有结果求和，我们可以正确计算所有船只，而无需重复查询空区域。 递归终止是因为每次划分都会减少矩形面积，最终达到单个点。 

## Python 解决方案```python
# """
# This is Sea's API interface.
# You should not implement it, or speculate about its implementation
# """
#class Sea:
#    def hasShips(self, topRight: 'Point', bottomLeft: 'Point') -> bool:
#
#class Point:
#    def __init__(self, x: int, y: int):
#        self.x = x
#        self.y = y

class Solution:
    def countShips(self, sea: 'Sea', topRight: 'Point', bottomLeft: 'Point') -> int:
        if topRight.x < bottomLeft.x or topRight.y < bottomLeft.y:
            return 0
        
        if not sea.hasShips(topRight, bottomLeft):
            return 0
        
        if topRight.x == bottomLeft.x and topRight.y == bottomLeft.y:
            return 1
        
        midX = (topRight.x + bottomLeft.x) // 2
        midY = (topRight.y + bottomLeft.y) // 2
        
        count = 0
        count += self.countShips(sea, Point(midX, midY), bottomLeft)
        count += self.countShips(sea, Point(topRight.x, midY), Point(midX + 1, bottomLeft.y))
        count += self.countShips(sea, Point(midX, topRight.y), Point(bottomLeft.x, midY + 1))
        count += self.countShips(sea, topRight, Point(midX + 1, midY + 1))
        
        return count
```该实现首先检查矩形是否无效或为空。 如果矩形没有船只，则立即返回零。 对于大小为 1×1 的矩形，如果存在船只，则返回 1。 否则，它将矩形分为几个象限，递归地计算每个象限中的船只，并对结果求和。 

## 解决方案```go
/**
 * // This is Sea's API interface.
 * // You should not implement it, or speculate about its implementation
 * type Sea struct {
 *     func hasShips(topRight, bottomLeft []int) bool {}
 * }
 */

func countShips(sea Sea, topRight, bottomLeft []int) int {
    if topRight[0] < bottomLeft[0] || topRight[1] < bottomLeft[1] {
        return 0
    }
    if !sea.hasShips(topRight, bottomLeft) {
        return 0
    }
    if topRight[0] == bottomLeft[0] && topRight[1] == bottomLeft[1] {
        return 1
    }
    
    midX := (topRight[0] + bottomLeft[0]) / 2
    midY := (topRight[1] + bottomLeft[1]) / 2
    
    count := 0
    count += countShips(sea, []int{midX, midY}, bottomLeft)
    count += countShips(sea, []int{topRight[0], midY}, []int{midX + 1, bottomLeft[1]})
    count += countShips(sea, []int{midX, topRight[1]}, []int{bottomLeft[0], midY + 1})
    count += countShips(sea, topRight, []int{midX + 1, midY + 1})
    
    return count
}
```在 Go 中，切片用于表示点。 递归逻辑反映了 Python，特别注意象限的切片构造。 由于 Go 函数可以直接传递切片，因此不需要类。 

## 工作示例

 **示例1：**`ships = [[1,1],[2,2],[3,3],[5,5]], topRight = [4,4], bottomLeft = [0,0]`| 递归调用 | 矩形| 有船吗？ | 计数|
 | --- | --- | --- | --- |
 | 1 | [0,0]-[4,4] | 真实| 3（子调用总和）|
 | 2 | [0,0]-[2,2] | 真实| 2 |
 | 3 | [0,0]-[1,1] | 真实| 1 |
 | 4 | [2,0]-[2,1] | 假 | 0 |
 | 5 | [0,2]-[1,2] | 假 | 0 |
 | 6 | [2,2]-[2,2] | 真实| 1 |
 | 7 | [3,3]-[4,4] | 真实| 1 |

 总和 = 3 艘船。 

**示例2：**`ships = [[1,1],[2,2],[3,3]], topRight = [1000,1000], bottomLeft = [0,0]`该算法快速修剪空的大区域，仅递归地细分`hasShips`返回真。 总计数 = 3。
