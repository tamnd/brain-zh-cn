[LeetCode 第 1223 题](https://leetcode.com/problems/dice-roll-simulation/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算滚动六面骰子生成的有效序列总数`n`次，每个人都面临额外的限制`i`不能出现超过`rollMax[i]`连续多次。 这里，`rollMax`是一个 6 元素数组，对应于每个骰子面允许的最大连续出现次数（从 1 到 6）。结果应以模数形式返回`10^9 + 7`由于潜在的大量。 

换句话说，如果我们掷骰子`n`有时，我们想要计算所有长度的序列`n`约束来自哪里`rollMax`很满意。 输入`n`最大可达 5000 个，每个`rollMax[i]`最多 15。这意味着所有序列的强力枚举在计算上是不可行的，因为可能序列的数量呈指数增长（`6^n`）。 

重要的边缘情况包括以下场景：`rollMax`全部为 1（不允许立即重复的序列）或当`n`很小（如 1 或 2），几乎可以轻松解决。 约束保证`rollMax`始终有效（正整数）并且数组始终恰好有 6 个元素，因此我们不需要处理格式错误的输入。 

## 方法

 **暴力方法**将生成所有`6^n`递归或迭代地序列，并对照每个序列检查`rollMax`限制。 虽然这会产生正确的结果，但对于`n = 5000`因为时间和内存都呈指数增长。 

**动态规划方法**是关键的观察结果。 我们注意到，在任何步骤中，有效序列的数量取决于最后滚动的数字以及它连续出现的次数。 因此，我们可以定义一个DP状态`dp[i][j][k]`， 在哪里`i`是当前的滚动索引，`j`是最后滚动的模面，并且`k`是连续次数`j`已滚动。 使用此状态，我们可以通过考虑所有有效的先前状态来逐步构建解决方案。 通过仔细更新 DP 数组并使用模运算，我们可以有效地计算出总计数`n`滚动而不枚举所有序列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(6^n) | O(6^n) | O(n) | 枚举所有序列并检查有效性 |
 | 动态规划| O(n * 6 * 最大值(rollMax)) | O(n * 6 * 最大值(rollMax)) | 使用 DP over rolls、最后一个数字和连续计数来计算有效序列 |

 ## 算法演练

 1.初始化一个2D DP数组`dp[j][k]`在哪里`j`代表模具面 (0-5) 和`k`代表连续出现的`j`。`dp[j][k]`存储当前长度以face结尾的序列数`j`连续出现`k`次。 
2. 设置第一卷的基本情况：每个面`j`只能出现一次，所以`dp[j][1] = 1`为所有人`j`。 
3. 从滚动开始迭代`2`到`n`。 对于每个新卷，创建一个新的 DP 阵列`new_dp`存储更新的计数。 
4. 对于每个模具面`j`，考虑所有可能的连续计数`k`（从 1 到`rollMax[j]`）。 
5. 对于每个可能的先前模具面`i`， 如果`i == j`，我们只能扩展以结尾的序列`i`如果连续计数`k - 1`是有效的。 否则，如果`i != j`，我们可以开始一个新序列`j`通过对所有以结尾的序列求和`i`无论它们的连续计数如何。 
6. 更新`new_dp[j][k]`计算出的计数模数`10^9 + 7`。 
7. 处理完该辊的所有面后，更换`dp`和`new_dp`。 
8. 毕竟`n`滚动，总和`dp[j][k]`获取有效序列的总数。 

**为什么有效：** DP 方法保证了正确性，因为它跟踪所有必要的状态：最后滚动的面以及它连续出现的次数。 这确保了没有顺序违反`rollMax`约束和所有有效序列只计算一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        MOD = 10**9 + 7
        max_roll = max(rollMax)
        dp = [[0] * (max_roll + 1) for _ in range(6)]
        
        for j in range(6):
            dp[j][1] = 1
        
        for roll in range(1, n):
            new_dp = [[0] * (max_roll + 1) for _ in range(6)]
            for j in range(6):
                for k in range(1, rollMax[j] + 1):
                    if k == 1:
                        new_dp[j][k] = sum(dp[i][c] for i in range(6) if i != j for c in range(1, rollMax[i] + 1)) % MOD
                    else:
                        new_dp[j][k] = dp[j][k - 1]
            dp = new_dp
        
        return sum(dp[j][k] for j in range(6) for k in range(1, rollMax[j] + 1)) % MOD
```Python解决方案初始化一个具有维度的DP数组`[6][max_roll+1]`存储计数。 第一卷撒有种子`1`对于每张脸。 对于后续的滚动，将创建一个新的 DP 阵列来保存更新的计数。 通过增加同一面的连续计数或开始不同面的新计数来扩展序列。 模运算确保不会出现整数溢出。 最后，所有状态的总和得出有效序列的总数。 

## 解决方案```go
func dieSimulator(n int, rollMax []int) int {
    const MOD = 1e9 + 7
    maxRoll := 0
    for _, v := range rollMax {
        if v > maxRoll {
            maxRoll = v
        }
    }
    dp := make([][]int, 6)
    for i := 0; i < 6; i++ {
        dp[i] = make([]int, maxRoll+1)
        dp[i][1] = 1
    }

    for roll := 1; roll < n; roll++ {
        newDp := make([][]int, 6)
        for i := 0; i < 6; i++ {
            newDp[i] = make([]int, maxRoll+1)
        }
        for j := 0; j < 6; j++ {
            for k := 1; k <= rollMax[j]; k++ {
                if k == 1 {
                    sum := 0
                    for i := 0; i < 6; i++ {
                        if i == j {
                            continue
                        }
                        for c := 1; c <= rollMax[i]; c++ {
                            sum = (sum + dp[i][c]) % MOD
                        }
                    }
                    newDp[j][k] = sum
                } else {
                    newDp[j][k] = dp[j][k-1]
                }
            }
        }
        dp = newDp
    }

    result := 0
    for j := 0; j < 6; j++ {
        for k := 1; k <= rollMax[j]; k++ {
            result = (result + dp[j][k]) % MOD
        }
    }
    return result
}
```在 Go 中，切片用于 DP 数组。 初始化和更新遵循与 Python 中相同的逻辑。 Go 特定的考虑因素包括显式切片创建和模运算以防止溢出。
