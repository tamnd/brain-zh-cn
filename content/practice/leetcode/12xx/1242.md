[LeetCode 1242 题](https://leetcode.com/problems/web-crawler-multithreaded/)

 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、并发

 ## 解决方案

 ## 问题理解

 该问题要求我们实现一个从给定 URL 开始的**多线程网络爬虫**`startUrl`并访问可从其访问的所有 URL，**但仅访问共享相同主机名的 URL**。 我们给定了一个接口`HtmlParser`可以通过其返回页面上的所有 URL`getUrls(url)`方法。 目标是返回**所有发现的 URL**，而不会多次访问任何 URL。 

本质上，问题是要求我们执行**图遍历**，其中节点是 URL，如果一个页面链接到另一个页面，则存在边。 然而，与标准遍历不同，我们被限制在与起始 URL 相同的主机名下的节点 (URL)。 该挑战强调**多线程**，因为`getUrls`是阻塞操作，顺序遍历可能会超出时间限制。 

输入是单个字符串`startUrl`，输出是 URL 列表（顺序无关紧要）。 约束向我们保证最多有 1000 个 URL，每个 URL 最多 300 个字符，并且没有重复。 主机名规则是标准的，可以简化从 URL 中提取主机名的过程。 

重要的边缘情况包括链接到主机名之外的页面的 URL、没有传出链接的页面以及链接图中的循环。 

## 方法

 ### 蛮力方法

 一个简单的解决方案将执行**单线程 DFS 或 BFS**，保留访问集以避免重复。 开始于`startUrl`，我们使用递归方式获取 URL`getUrls`，按主机名过滤，然后继续。 这可以正常工作，但会太慢，因为`getUrls`正在阻塞并且每个 URL 请求都需要时间。 对于单线程，如果我们假设每个请求为 15 毫秒，那么顺序访问 1000 个 URL 的最坏情况可能会超出时间限制。 

### 最佳方法

 关键的观察是`getUrls`**I/O 限制**。 多线程允许我们并行发起多个 URL 请求，从而显着减少总抓取时间。 通过使用**线程池**或**并发任务执行**，我们可以同时启动多个爬取任务。 每个线程处理一个 URL，获取所有链接的 URL，按主机名过滤，并将所有未访问的 URL 提交到池中。 

只要我们正确同步对访问集的访问，这种方法就可以保证正确性，确保没有 URL 被抓取两次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n + e) 顺序 | O(n) | DFS/BFS单线程，因阻塞而慢`getUrls`|
 | 最佳| O(n + e) 并行 | O(n) | 使用并发访问集的多线程 BFS/DFS，挂钟时间更快 |

 ## 算法演练

 1. **提取主机名**：解析`startUrl`提取主机名。 这将用于过滤 URL。 
2. **初始化并发结构**：创建一个线程安全的`visited`设置一个队列（或任务池）来保存要爬行的 URL。 
3. **开始爬取任务**：添加`startUrl`到队列并将其标记为已访问。 
4. **并发处理**：每个工作线程从队列中获取一个URL，调用`htmlParser.getUrls(url)`，并将结果过滤为仅那些具有相同主机名且尚未访问过的 URL。 
5. **提交新 URL**：将任何新的、未访问的 URL 添加到队列中以供进一步处理。 立即将它们标记为已访问以避免重复。 
6. **等待完成**：继续直到队列为空且所有工作线程完成。 
7. **返回结果**：将访问过的集合转换为列表并返回。 

**为什么有效**：同一主机名下的每个 URL 最终都会添加到队列中并被访问一次。 多线程确保阻塞调用重叠，减少挂钟时间，同时通过访问集上的同步保持正确性。 

## Python 解决方案```python
from typing import List
from urllib.parse import urlparse
from concurrent.futures import ThreadPoolExecutor
import threading

class Solution:
    def crawl(self, startUrl: str, htmlParser: 'HtmlParser') -> List[str]:
        hostname = urlparse(startUrl).hostname
        visited = set()
        visited_lock = threading.Lock()
        
        def crawl_url(url: str):
            urls = htmlParser.getUrls(url)
            for u in urls:
                if urlparse(u).hostname == hostname:
                    with visited_lock:
                        if u not in visited:
                            visited.add(u)
                            executor.submit(crawl_url, u)
        
        with ThreadPoolExecutor(max_workers=8) as executor:
            visited.add(startUrl)
            executor.submit(crawl_url, startUrl)
            executor.shutdown(wait=True)
        
        return list(visited)
```**说明**：我们首先从中提取主机名`startUrl`。 这`visited`set 受锁保护以确保线程安全。 这`crawl_url`函数获取 URL，按主机名过滤，并将新的未访问 URL 提交回线程池。 我们从提交开始`startUrl`，等待所有线程完成，然后返回所有访问过的 URL。 

## 解决方案```go
package main

import (
	"net/url"
	"sync"
)

func crawl(startUrl string, htmlParser *HtmlParser) []string {
	parsedUrl, _ := url.Parse(startUrl)
	hostname := parsedUrl.Hostname()
	visited := make(map[string]struct{})
	var mu sync.Mutex
	var wg sync.WaitGroup

	var crawlURL func(string)
	crawlURL = func(current string) {
		defer wg.Done()
		urls := htmlParser.getUrls(current)
		for _, u := range urls {
			parsed, _ := url.Parse(u)
			if parsed.Hostname() == hostname {
				mu.Lock()
				if _, ok := visited[u]; !ok {
					visited[u] = struct{}{}
					wg.Add(1)
					go crawlURL(u)
				}
				mu.Unlock()
			}
		}
	}

	mu.Lock()
	visited[startUrl] = struct{}{}
	mu.Unlock()
	wg.Add(1)
	go crawlURL(startUrl)
	wg.Wait()

	result := make([]string, 0, len(visited))
	for u := range visited {
		result = append(result, u)
	}
	return result
}
```**说明**：与Python类似，我们使用Go例程并行抓取URL。 一个`sync.Mutex`保护`visited`地图，和一个`sync.WaitGroup`确保主线程等待，直到所有爬行 goroutine 完成。 仅当新 URL 位于同一主机名下且尚未被访问时，才会对其进行爬网。 

## 工作示例

 **示例1**：

 起始网址：`"http://news.yahoo.com/news/topics/"`主机名：`"news.yahoo.com"`1. 参观`"http://news.yahoo.com/news/topics/"`。 
2. 获取网址：`["http://news.yahoo.com", "http://news.yahoo.com/news", "http://news.google.com", "http://news.yahoo.com/us"]`3. 过滤相同主机名：`["http://news.yahoo.com", "http://news.yahoo.com/news", "http://news.yahoo.com/us"]`4. 将每个未访问的 URL 提交到线程池并重复。 
5.最终，`visited = ["http://news.yahoo.com", "http://news.yahoo.com/news", "http://news.yahoo.com/news/topics/", "http://news.yahoo.com/us"]`**示例2**：

 起始网址：`"http://news.google.com"`主机名：`"news.google.com"`1. 参观`"http://news.google.com"`2. 获取 URL：所有其他 URL 都是不同的主机名。 
3、结果：仅`["http://news.google.com"]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + e) | 每个 URL 被访问一次，每条边被处理一次。 由于并行性，挂钟时间要快得多。 |
 | 空间| O(n) | 存储访问过的 URL 和队列/任务池。 |

 尽管理论上的时间是 O(n + e)，但多线程显着减少了实际的爬行时间。
