[LeetCode 1202 题](https://leetcode.com/problems/smallest-string-with-swaps/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、深度优先搜索、广度优先搜索、并查找、排序

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`和一个名为的索引对列表`pairs`。 每对`[a, b]`意味着我们可以交换位置上的字符`a`和`b`。 

重要的细节是交换可以执行任意多次。 这完全改变了问题的性质。 我们不限于每对使用一次。 相反，如果索引`0`可以交换`1`， 和`1`可以交换`2`，然后索引`0`可以有效地与索引交换字符`2`通过一系列的交换。 

该问题要求我们返回在执行任何有效的交换序列后可以形成的字典顺序最小的字符串。 

词典顺序与词典顺序类似。 例如：

-`"abcd"`小于`"abdc"`-`"abc"`小于`"acb"`所以目标是使字符串中最早的字符尽可能小。 

限制条件很大：

 -`s.length`可以达到`10^5`-`pairs.length`也可以达到`10^5`这些限制立即告诉我们，昂贵的重复交换或详尽的搜索是不可能的。 任何比粗略更糟糕的算法`O(n log n)`可能会超时。 

一个重要的观察结果是，互换创建了相互连接的指数组。 如果两个索引通过交换对直接或间接连接，则该连接组件内的任何字符最终都可以移动到同一组件内的任何位置。 

例如：```
pairs = [[0,1],[1,2]]
```这意味着指数`0`,`1`， 和`2`都属于同一个连通分量。 因此，这些位置的字符可以在这些索引中任意重新排列。 

重要的边缘情况包括：

 - 一个空的`pairs`数组，不能交换
 - 全连接图，整个字符串可以全局排序
 - 多个断开连接的组件
 - 重复的交换对
 - 单字符字符串
 - 只包含一个索引的组件

 该问题保证所有索引都有效并且字符串仅包含小写英文字母。 

## 方法

 ### 蛮力方法

 强力解决方案将反复尝试交换并尝试改进字符串，直到找不到更好的排列。 

一种可能的暴力策略是：

 - 通过交换操作使用 BFS 或 DFS 生成所有可达字符串
 - 跟踪访问的配置
 - 返回遇到的最小字典字符串

 这种方法在技术上是正确的，因为它探索了所有可能的有效交换序列。 然而，这在计算上是不可行的。 

如果一个组件包含`k`指数，那么可能`k!`字符的排列是可以达到的。 即使对于适度的值`k`，这变得巨大。 

另一种暴力变体将贪婪地重复应用有益的交换。 然而，除非我们理解连通分量结构，否则贪婪的局部交换并不一定会导致全局最小的排列。 

因为约束条件是`10^5`，暴力探索是完全不切实际的。 

### 关键见解

 关键的见解是交换关系形成图中的连接组件。 

如果两个索引属于同一个连通分量，则它们的字符可以通过交换序列任意重新排列。 

这将问题转化为：

 1. 查找索引的所有连通分量
 2.收集属于每个组件的所有字符
 3.对字符进行升序排序
 4. 将最小的字符放入最小的索引中

 为什么这有效？ 

为了最小化字典顺序，较早的位置应接收尽可能小的字符。 由于连接组件内的所有索引都可以自由互换，因此我们应该贪婪地将最小的可用字符分配给最小的索引。 

Union-Find 也称为不相交集并集 (DSU)，是高效构建连接组件的理想选择。

 ## 算法演练

 ### 使用并查找的最优算法

 1. 初始化并查数据结构。 

每个索引最初都属于它自己的集合。 并查结构有效地合并连接的索引并确定索引属于哪个组件。 
2. 处理每个交换对。 

对于每对`[a, b]`，合并两个索引。 这构建了代表可以交换字符的所有位置的连接组件。 
3. 按组件根对索引进行分组。 

所有并集完成后，每个连接的组件都有一个代表根。 我们迭代所有索引并按根对它们进行分组。 

例如：```
Component root 0 -> [0, 2, 3]
Component root 5 -> [5, 7]
```4. 收集属于每个组件的字符。 

对于每组索引，从字符串中提取相应的字符。 

例子：```
indices = [0, 2, 3]
chars = ['d', 'a', 'b']
```5. 对索引和字符进行排序。 

索引已排序，因此我们首先填充较早的位置。 

对字符进行排序，因此首先分配最小的可用字符。 

例子：```
indices = [0, 2, 3]
chars = ['a', 'b', 'd']
```6. 重建结果字符串。 

将已排序的字符分配回已排序的索引。```
result[0] = 'a'
result[2] = 'b'
result[3] = 'd'
```7. 返回最终的字符串。 

处理完所有组件后，将结果数组连接成字符串。 

### 为什么它有效

 在连接的组件中，每个字符最终都可以移动到该组件中的任何索引。 因此，字典顺序最小的排列是通过对组件的字符进行排序并将它们按升序放入组件的索引中来获得的。 

这种贪婪的放置是最佳的，因为字典顺序比较优先考虑较早的位置，然后再考虑较晚的位置。 

## Python 解决方案```python
from collections import defaultdict
from typing import List

class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)

        parent = list(range(n))
        rank = [0] * n

        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x: int, y: int) -> None:
            root_x = find(x)
            root_y = find(y)

            if root_x == root_y:
                return

            if rank[root_x] < rank[root_y]:
                parent[root_x] = root_y
            elif rank[root_x] > rank[root_y]:
                parent[root_y] = root_x
            else:
                parent[root_y] = root_x
                rank[root_x] += 1

        # Build connected components
        for a, b in pairs:
            union(a, b)

        # Group indices by component root
        components = defaultdict(list)

        for index in range(n):
            root = find(index)
            components[root].append(index)

        result = list(s)

        # Sort characters within each component
        for indices in components.values():
            chars = sorted(s[index] for index in indices)

            indices.sort()

            for index, char in zip(indices, chars):
                result[index] = char

        return "".join(result)
```实现首先初始化并查结构。 每个索引都作为其自己的父索引启动，因为最初没有已知的连接。 

这`find`函数使用路径压缩。 这种优化使树结构变得扁平，因此将来的查找变得非常快。 

这`union`函数使用按等级并集来合并两个组件。 这可以使树保持浅层并提高性能。 

处理完所有对后，每个连接的组件都已完全建立。 

接下来，我们使用哈希映射根据索引的组件根对索引进行分组。 每个键代表一个连接的组件。 

对于每个组件：

 - 我们收集它的角色
 - 对字符进行排序
 - 对索引进行排序
 - 将最小的字符分配给最小的索引

 最后，我们将结果列表连接成一个字符串并返回它。 

## 解决方案```go
package main

import (
	"sort"
)

func smallestStringWithSwaps(s string, pairs [][]int) string {
	n := len(s)

	parent := make([]int, n)
	rank := make([]int, n)

	for i := 0; i < n; i++ {
		parent[i] = i
	}

	var find func(int) int

	find = func(x int) int {
		if parent[x] != x {
			parent[x] = find(parent[x])
		}
		return parent[x]
	}

	union := func(x, y int) {
		rootX := find(x)
		rootY := find(y)

		if rootX == rootY {
			return
		}

		if rank[rootX] < rank[rootY] {
			parent[rootX] = rootY
		} else if rank[rootX] > rank[rootY] {
			parent[rootY] = rootX
		} else {
			parent[rootY] = rootX
			rank[rootX]++
		}
	}

	// Build connected components
	for _, pair := range pairs {
		union(pair[0], pair[1])
	}

	components := make(map[int][]int)

	// Group indices by root
	for i := 0; i < n; i++ {
		root := find(i)
		components[root] = append(components[root], i)
	}

	result := []byte(s)

	// Process each component
	for _, indices := range components {
		chars := make([]byte, len(indices))

		for i, index := range indices {
			chars[i] = s[index]
		}

		sort.Ints(indices)

		sort.Slice(chars, func(i, j int) bool {
			return chars[i] < chars[j]
		})

		for i, index := range indices {
			result[index] = chars[i]
		}
	}

	return string(result)
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

一个显着的区别是 Go 字符串是不可变的，因此我们将字符串转换为`[]byte`修改字符之前的数组。 

组件图使用`map[int][]int`按根对索引进行分组。 

对字符进行排序需要`sort.Slice`因为 Go 不会使用专用的助手直接按字典顺序对字节切片进行排序。 

Go 在这里不需要对整数溢出进行特殊处理，因为所有索引都受以下限制`10^5`。

 ## 边缘情况

 ### 空交换列表

 如果`pairs`为空，无法进行交换。 幼稚的实现可能仍然会尝试不必要的处理，或者在构造组件时失败。 

当前的实现自然地处理了这个问题。 每个索引都保留在其自己的单例组件中，因此原始字符串不变地返回。 

### 全连接字符串

 如果所有索引都属于一个连通分量，则可以自由地重新排列整个字符串。 

这实际上相当于按字典顺序对整个字符串进行排序。 该算法可以正确处理这一问题，因为所有索引都映射到同一根，从而生成一个大组件。 

### 重复或冗余对

 输入可能包含重复的对或连接已连接索引的对。 

例如：```
[[0,1],[1,2],[0,2]]
```有缺陷的实现可能会低效地重复重建结构。 

Union-Find 可以安全地处理这个问题，因为尝试合并同一集合中已有的两个索引将成为无操作。 

### 尺寸一的组件

 有些索引可能永远不会出现在任何对中。 

这些索引形成单例组件，并且它们的字符不能移动。 

该算法正确地保留了这些字符，因为对单元素组件进行排序不会改变任何内容。 

### 重复字符

 字符串可能包含许多相同的字符。 

例如：```
"aaaa"
```一些不正确的实现意外地依赖于字符的唯一性。 

该解决方案不假定唯一性。 它只是对字符数组进行排序，即使有重复项也能正常工作。
