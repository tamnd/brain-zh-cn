[LeetCode 问题 1284](https://leetcode.com/problems/minimum-number-of-flips-to-convert-binary-matrix-to-zero-matrix/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、位操作、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们变换给定的二进制矩阵`mat`变成一个零矩阵，其中所有元素都是`0`。 每个操作都允许您翻转一个单元格及其四个直接相邻的单元格（上、下、左、右）。 翻转意味着改变一个`1`到`0`或一个`0`到`1`。 输入是一个`m x n`维度限制在之间的二元矩阵`1`和`3`对于两者`m`和`n`，这意味着矩阵总是很小。 输出是将矩阵转换为零矩阵所需的最小翻转次数。 如果不可能，我们就返回`-1`。 

约束条件，具体而言`1 <= m, n <= 3`，暗示对所有可能的翻转序列进行强力探索是可行的。 然而，在没有优化的情况下尝试所有可能序列的简单实现仍然需要仔细设计以避免冗余工作。 重要的边缘情况包括已经为零的矩阵（需要零翻转）、无法转换的矩阵（需要`-1`)，以及只有一行或一列的矩阵。 

## 方法

 蛮力方法涉及尝试矩阵上的每种翻转组合。 对于大小矩阵`m x n`， 有`2^(m*n)`翻转单元格的可能方法，因为每个单元格可以翻转也可以不翻转。 对于每个配置，您应用翻转并检查结果矩阵是否为零。 虽然这保证了正确性，但指数时间复杂度使得它对于较大的矩阵来说不切实际。 即使最大`m*n`是`9`,`2^9 = 512`是可以管理的，但仍然不优雅。 

最佳方法的关键见解是，矩阵的小尺寸允许我们使用**广度优先搜索（BFS）**与**位掩码**相结合。 我们可以将矩阵表示为单个整数，其中每一位代表一个单元格。 BFS逐级探索所有可能的翻转状态，保证到达零矩阵的最少步数。 我们还使用一组来跟踪访问的状态，以避免重新访问相同的配置。 位操作使翻转邻居变得高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m_n) * m_n) | O(2^(m_n) * m_n) | O(1) | O(1) | 尝试所有可能的翻转组合并检查结果 |
 | 最佳（BFS + 位掩码）| O(2^(m_n) * m_n) | O(2^(m_n) * m_n) | O(2^(m*n)) | O(2^(m*n)) | 状态空间上的 BFS 使用位掩码表示矩阵，跟踪访问的状态 |

 ## 算法演练

 1. 将矩阵转换为整数`start`，其中每一位代表一个单元格。 少量`1`意味着该单元格是`1`和位`0`意味着该单元格是`0`。 这允许快速比较和翻转。 
2. 定义辅助函数`flip(mask, r, c)`翻转单元格`(r, c)`及其邻居使用按位异或运算。 
3. 初始化一个 BFS 队列`(start, 0)`在哪里`0`是所采取的步数。 
4.使用一套`seen`跟踪访问过的口罩以避免重复工作。 
5. 当队列不为空时：

 1. 弹出一个掩码及其相应的步数。 
2. 如果掩码为零，则返回步数。 
3. 否则，对于每个单元格`(r, c)`在矩阵中，翻转后计算新的掩码，如果尚未看到，请将其排队。 
6. 如果 BFS 结束时没有找到零掩码，则返回`-1`。 

**为什么有效**：BFS 在不断增加的翻转次数中探索所有状态。 我们第一次遇到零掩码对应于所需的最小翻转次数。 位掩码确保恒定时间的翻转和比较。 跟踪访问的状态可确保我们不会无限循环。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def minFlips(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        start = 0
        for i in range(m):
            for j in range(n):
                if mat[i][j]:
                    start |= 1 << (i * n + j)
        
        def flip(mask: int, r: int, c: int) -> int:
            for dr, dc in [(0,0),(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    mask ^= 1 << (nr * n + nc)
            return mask
        
        queue = deque([(start, 0)])
        seen = {start}
        
        while queue:
            mask, steps = queue.popleft()
            if mask == 0:
                return steps
            for i in range(m):
                for j in range(n):
                    new_mask = flip(mask, i, j)
                    if new_mask not in seen:
                        seen.add(new_mask)
                        queue.append((new_mask, steps + 1))
        
        return -1
```该实现首先将矩阵转换为位掩码整数。 这`flip`函数有效地切换与单元及其邻居相对应的位。 BFS 探索所有可能的翻转，同时避免重复状态。 当达到零掩码时，算法返回最小翻转次数。 

## 解决方案```go
package main

func minFlips(mat [][]int) int {
    m, n := len(mat), len(mat[0])
    start := 0
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if mat[i][j] == 1 {
                start |= 1 << (i*n + j)
            }
        }
    }

    flip := func(mask int, r int, c int) int {
        directions := [][2]int{{0,0},{0,1},{0,-1},{1,0},{-1,0}}
        for _, d := range directions {
            nr, nc := r + d[0], c + d[1]
            if nr >= 0 && nr < m && nc >= 0 && nc < n {
                mask ^= 1 << (nr*n + nc)
            }
        }
        return mask
    }

    type pair struct {
        mask, steps int
    }
    queue := []pair{{start, 0}}
    seen := map[int]bool{start:true}

    for len(queue) > 0 {
        p := queue[0]
        queue = queue[1:]
        if p.mask == 0 {
            return p.steps
        }
        for i := 0; i < m; i++ {
            for j := 0; j < n; j++ {
                newMask := flip(p.mask, i, j)
                if !seen[newMask] {
                    seen[newMask] = true
                    queue = append(queue, pair{newMask, p.steps + 1})
                }
            }
        }
    }
    return -1
}
```Go 使用切片作为已访问状态的队列和映射。 位掩码操作和 BFS 逻辑镜像 Python 版本。 Go 不需要类型提示，我们使用切片操作来处理队列。 

## 工作示例

 **示例1：**`mat = [[0,0],[0,1]]`初始位掩码：`0001`（二进制）。 BFS步骤：

 | 步骤| 面膜| 翻转动作| 新面膜 |
 | ---| ---| ---| ---|
 | 0 | 0001| 翻转(1,0) | 0111|
 | 1 | 0111| 翻转(0,1) | 1011 | 1011
 | 2 | 1011 | 1011 翻转(1,1) | 0000 | 0000

 最少翻转次数：`3`。 

**示例2：**`mat = [[0]]`位掩码：`0`。 已经为零，所以结果是`0`。 

**示例3：**`mat = [[1,0,0],[1,0,0]]`位掩码：`100001`。 BFS 探索了所有 64 种可能的状态，没有一个达到零，所以结果是`-1`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(2^(m_n) * m_n) | O(2^(m_n) * m_n) | BFS 探索每个可能的矩阵状态，对于每个状态我们考虑 m*n 次翻转 |
 | 空间| O(2^(m*n)) | O(2^(m*n)) | 将所有访问过的状态存储在一个集合中 |

 指数因子是可以接受的，因为`m*n <= 9`。 BFS 通过逐级探索保证最少的翻转，而位掩码则确保有效的状态转换。
