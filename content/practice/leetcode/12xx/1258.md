[LeetCode 第 1258 题](https://leetcode.com/problems/synonymous-sentences/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、回溯、排序、并查

 ## 解决方案

 ## 问题理解

 这个问题要求我们根据等效单词对列表生成给定句子的所有可能的同义变体。 每个同义词对表示这两个词可以互换。 输出必须包括通过用同义词替换单词而创建的所有可能的句子，并且必须按字典顺序排序。 

输入是：

 -`synonyms`：单词对列表，其中每对`[si, ti]`表示`si`和`ti`是可以互换的。 约束保证所有对都是唯一的，并且对的数量最多为 10 个。 
-`text`：一个句子，最多包含 10 个单词，并用单个空格分隔。 每个单词可能有也可能没有同义词。 

输出是一个字符串列表，表示用同义词替换单词后的所有有效句子，按字典顺序排序。 

主要限制和观察：

 - 因为`synonyms.length <= 10`和`text`最多 10 个单词，可能的句子总数相对较少，易于回溯。 
- 同义词关系可以是传递的。 例如，如果“happy”=“joy”并且“joy”=“cheerful”，则“happy”=“cheerful”。 
- 没有同义词的单词保持不变。 
- 我们必须避免重复并按字典顺序返回句子。 

重要的边缘情况：

 - 没有同义词：句子保持不变。 
- 句子中的单词没有出现在`synonyms`。 
- 同义词对形成比两个单词更长的链。 

## 方法

 一种强力方法是检查句子中的每个单词，并直接根据提供的对生成所有可能的替换。 对于每个单词，我们可以递归地尝试每对匹配。 虽然这会产生正确的句子，但它无法考虑传递同义词，并且可能会创建需要重复数据删除的重复结果。 此外，随着同义词的增长，组合的数量可能会激增，导致不必要的重复计算。 

最佳方法利用并查（不相交集并集）数据结构对所有传递连接的同义词进行分组。 形成同义词组后，我们可以预先计算从每个单词到其完整同义词集的映射。 然后，使用回溯，我们迭代句子中的每个单词，用其组中的每个同义词替换它并生成所有可能的句子。 最后，我们按字典顺序对结果进行排序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * m) | O(2^n * m) | O(2^n * m) | O(2^n * m) | 使用对递归地替换单词； 重复项需要删除 |
 | 最佳 | O(n * 2^k * log(2^k)) | O(n * 2^k * log(2^k)) | O(n + k) | 使用并查对同义词进行分组，然后回溯； 排序结果 |

 这里，`n`是句子中的单词数，并且`k`是具有同义词的单词数量。 

## 算法演练

 1. 初始化并查数据结构。 同义词列表中的每个唯一单词都是一个节点。 
2. 对于每个同义词对`[si, ti]`，联合并查结构中的两个单词，确保所有传递连接的同义词共享相同的代表。 
3. 构建从每个同义词组的代表到该组中排序的单词列表的映射。 这允许快速查找任何单词的所有同义词。 
4. 分割输入`text`变成文字。 
5.使用回溯生成句子。 对于句子中的每个单词：

 a. 如果映射中有同义词，则迭代每个同义词，递归地生成带有该替换的句子。 

b. 如果它没有同义词，则保持不变并继续。 
6. 将所有生成的句子收集到一个列表中。 
7. 按字典顺序对列表进行排序。 
8. 返回排序后的列表。 

为什么有效：通过使用并查，我们可以正确地将所有传递连接的同义词分组。 回溯确保我们探索同义替换的每种组合，同时保留原始词序。 最后的排序保证了字典顺序的要求。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def generateSentences(self, synonyms: List[List[str]], text: str) -> List[str]:
        parent = {}
        
        def find(word: str) -> str:
            if word not in parent:
                parent[word] = word
            if parent[word] != word:
                parent[word] = find(parent[word])
            return parent[word]
        
        def union(a: str, b: str):
            pa, pb = find(a), find(b)
            if pa != pb:
                parent[pa] = pb
        
        # Build union-find structure
        for a, b in synonyms:
            union(a, b)
        
        # Build mapping from root to all synonyms
        groups = defaultdict(list)
        for word in parent:
            root = find(word)
            groups[root].append(word)
        
        for key in groups:
            groups[key].sort()
        
        words = text.split()
        res = []
        
        def backtrack(index: int, path: List[str]):
            if index == len(words):
                res.append(' '.join(path))
                return
            word = words[index]
            if word in parent:
                for syn in groups[find(word)]:
                    backtrack(index + 1, path + [syn])
            else:
                backtrack(index + 1, path + [word])
        
        backtrack(0, [])
        return sorted(res)
```Python 实现首先构建并查结构并对同义词进行分组。 然后，句子中的每个单词都会被其组中的所有同义词递归替换。 没有同义词的单词保持不变。 排序确保字典顺序。 

## 解决方案```go
package main

import (
	"sort"
	"strings"
)

func generateSentences(synonyms [][]string, text string) []string {
	parent := map[string]string{}
	
	var find func(string) string
	find = func(word string) string {
		if _, exists := parent[word]; !exists {
			parent[word] = word
		}
		if parent[word] != word {
			parent[word] = find(parent[word])
		}
		return parent[word]
	}
	
	union := func(a, b string) {
		pa, pb := find(a), find(b)
		if pa != pb {
			parent[pa] = pb
		}
	}
	
	for _, pair := range synonyms {
		union(pair[0], pair[1])
	}
	
	groups := map[string][]string{}
	for word := range parent {
		root := find(word)
		groups[root] = append(groups[root], word)
	}
	
	for key := range groups {
		sort.Strings(groups[key])
	}
	
	words := strings.Split(text, " ")
	var res []string
	
	var backtrack func(int, []string)
	backtrack = func(index int, path []string) {
		if index == len(words) {
			res = append(res, strings.Join(path, " "))
			return
		}
		word := words[index]
		if _, exists := parent[word]; exists {
			for _, syn := range groups[find(word)] {
				backtrack(index+1, append(append([]string{}, path...), syn))
			}
		} else {
			backtrack(index+1, append(path, word))
		}
	}
	
	backtrack(0, []string{})
	sort.Strings(res)
	return res
}
```Go 实现镜像 Python，但仔细管理切片以避免在递归期间修改共享状态。 地图处理 Union-Find 家长和团体。 字典排序是使用`sort.Strings`。 

## 工作示例

 示例1：```
synonyms = [["happy","joy"],["sad","sorrow"],["joy","cheerful"]]
text = "I am happy today but was sad yesterday"
```一步一步：

 1、并查组：“快乐”、“快乐”、“开朗”相连； “悲伤”和“悲伤”是相连的。 
2. 组映射：

 - 根“快乐”：[“快乐”、“快乐”、“快乐”]
 - 根“悲伤”：[“悲伤”，“悲伤”]
 3. 分句：[“我”,“是”,“快乐”,“今天”,“但是”,“曾经”,“悲伤”,“昨天”]
 4、回溯：

 - 对于“快乐”：尝试[“快乐”，“快乐”，“快乐”]
 - 对于“悲伤”：尝试[“悲伤”，“悲伤”]
 5. 组合所有可能性：3 * 2 = 6 个句子
 6.按字典顺序排序

 最终输出：```
["I am cheerful today but was sad yesterday",
 "I am cheerful today but was sorrow yesterday",
 "I am happy today but was sad yesterday",
 "I am happy today but was sorrow yesterday",
 "I am joy today but was sad yesterday",
 "I am joy today but was sorrow yesterday"]
```示例 2 的工作原理类似，但同义词较少，并且只有两个结果句子。
