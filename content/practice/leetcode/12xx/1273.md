 **难度：** 🟡 中等
 **主题：** 数组、树、深度优先搜索、广度优先搜索

 ## 解决方案

 ## 问题理解

 该问题提供了一棵以节点为根的树`0`，用两个并行数组表示：`parent`和`value`。 这`parent[i]`数组表示的父级`i-th`节点，与`-1`表示根。 这`value[i]`array 给出每个节点的整数值。 任务是删除所有节点值之和为零的子树，然后返回树中剩余节点的计数。 

例如，如果子树以某个节点为根`x`总和为零，其所有子节点和节点本身都将被删除。 该过程在树上递归地继续，因为删除子树可能会导致其父树的总和也为零。 这些约束保证树至少有一个节点并且输入表示一棵有效的树。 节点值可以是负数、零或正数。 

关键边缘情况包括在叶级别总和为零的子树、包括总和为零的根的子树以及没有节点需要删除的树。 

## 方法

 暴力方法将递归计算每个节点的每个子树的总和并删除总和为零的子树。 虽然正确，但这种方法需要重复重新计算总和，并且在最坏的情况下对于深树可能需要 O(n²) 时间。 

最佳方法利用深度优先搜索 (DFS) 遍历。 通过首先访问子树，我们可以以自下而上的方式计算每个子树的总和。 如果子树的总和为零，则可以立即将其删除。 这可确保每个节点仅被访问一次，从而给出线性 O(n) 时间解决方案。 我们维护一个树结构（使用从父级到子级的映射）来简化遍历和删除。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 为每个节点重复重新计算子树总和 |
 | 最佳 | O(n) | O(n) | DFS 计算每个子树和一次并删除零和子树 |

 ## 算法演练

 1. 使用将每个节点映射到其子节点的字典（哈希图）构建树表示。 这允许在遍历期间有效地访问节点的所有子节点。 
2. 定义一个 DFS 函数，递归计算以给定节点为根的子树的总和。 
3. 对于每个节点，使用 DFS 函数递归地对其子节点的所有值求和。 如果子树的子树总和为零，则跳过对其节点的计数（有效地删除子树）。 
4. 将当前节点的值与其子节点的总和相加，以获得当前节点的子树总和。 
5. 如果当前节点的子树之和为零，则向父节点发出信号以删除该节点。 
6. DFS 完成后，返回属于非零子树的节点总数。 

**为什么起作用：** DFS 遍历确保节点的后序处理，在评估父节点之前计算子树总和。 这保证了任何总和为零的子树都被完全考虑并删除。 每个节点只处理一次，因此算法正确且高效。 

## Python 解决方案```python
from typing import List, Dict

class Solution:
    def deleteTreeNodes(self, nodes: int, parent: List[int], value: List[int]) -> int:
        tree: Dict[int, List[int]] = {i: [] for i in range(nodes)}
        for i in range(1, nodes):
            tree[parent[i]].append(i)

        def dfs(node: int) -> int:
            subtotal = value[node]
            for child in tree[node]:
                child_sum = dfs(child)
                if child_sum == 0:
                    continue
                subtotal += child_sum
            return subtotal

        total_sum = dfs(0)

        def count_nodes(node: int) -> int:
            subtotal = value[node]
            count = 1
            for child in tree[node]:
                child_sum = dfs(child)
                if child_sum == 0:
                    continue
                count += count_nodes(child)
            if subtotal + sum(dfs(c) for c in tree[node] if dfs(c) != 0) == 0:
                return 0
            return count

        return count_nodes(0)
```**说明：** 我们首先构建邻接表`tree`来代表儿童。 这`dfs`函数计算子树总和。 这`count_nodes`函数遍历树，计算子树和非零的节点。 具有零和子树的节点将被跳过。 这直接实现了所讨论的算法。 

## 解决方案```go
func deleteTreeNodes(nodes int, parent []int, value []int) int {
    tree := make([][]int, nodes)
    for i := 1; i < nodes; i++ {
        tree[parent[i]] = append(tree[parent[i]], i)
    }

    var dfs func(int) int
    dfs = func(node int) int {
        subtotal := value[node]
        for _, child := range tree[node] {
            subtotal += dfs(child)
        }
        return subtotal
    }

    var countNodes func(int) int
    countNodes = func(node int) int {
        subtotal := value[node]
        count := 1
        for _, child := range tree[node] {
            childSum := dfs(child)
            if childSum == 0 {
                continue
            }
            count += countNodes(child)
        }
        childSumTotal := 0
        for _, child := range tree[node] {
            cs := dfs(child)
            if cs != 0 {
                childSumTotal += cs
            }
        }
        if subtotal+childSumTotal == 0 {
            return 0
        }
        return count
    }

    return countNodes(0)
}
```**说明：** Go 实现镜像 Python，使用切片而不是列表以及带有闭包的递归函数。 邻接表是使用构建的`make([][]int, nodes)`。 使用DFS计算子树和，如果子树和不为零，则对节点进行计数。 

## 工作示例

 **示例1**

 输入：`nodes = 7, parent = [-1,0,0,1,2,2,2], value = [1,-2,4,0,-2,-1,-1]`树表示：```
0(1)
├─1(-2)
│ └─3(0)
└─2(4)
  ├─4(-2)
  ├─5(-1)
  └─6(-1)
```逐步：

 1. 叶子 3 处的 DFS：sum = 0 → 删除
 2. 叶 4 处的 DFS：sum = -2 → 保留
 3. 叶子 5 处的 DFS：sum = -1 → 保留
 4. 叶子 6 处的 DFS：sum = -1 → 保留
 5. 节点2处的DFS：4 + (-2) + (-1) + (-1) = 0 → 删除
 6. 节点1处的DFS：-2→保留
 7. 根 0 处的 DFS：1 + (-2) = -1 → 保留

 剩余节点：0和1→输出`2`。 

**示例2**

 输入：`nodes = 7, parent = [-1,0,0,1,2,2,2], value = [1,-2,4,0,-2,-1,-2]`按照相同的过程，只有叶子 3 的和为零并被删除。 所有其他节点保持 → 输出`6`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | DFS 遍历时每个节点都会被访问一次。 构建树的时间复杂度为 O(n)。 |
 | 空间| O(n) | 树表示使用 O(n) 空间。 递归堆栈深度最多为 O(n)。 |

 原因是 DFS 可以有效地计算子树和并计算节点数。 每个节点恰好被访问两次：一次用于计算总和，一次用于计算剩余节点。 空间由邻接表和递归栈主导。
