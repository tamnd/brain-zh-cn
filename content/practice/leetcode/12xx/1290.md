 ## 解决方案

 ## 问题理解

 这个问题给了我们一个单链表的头，其中每个节点都包含`0`或者`1`。 这些值一起代表一个二进制数。 列表的头部存储最高有效位，这意味着二进制数字的出现顺序与我们通常从左到右书写二进制数的顺序相同。 

我们的任务是将这个二进制表示形式转换为其等效的十进制整数并返回该值。 

例如，如果链表是：```
1 -> 0 -> 1
```那么二进制数是`101₂`，等于`5`以十进制表示。 

输入不是数组或字符串，而是链表。 这意味着我们不能直接索引位置，而必须逐个节点遍历。 

限制非常小：

 - 链表保证非空。 
- 节点数量最多为`30`。 
- 每个节点值是`0`或者`1`。 

这些限制告诉我们一些重要的事情：

 - 生成的整数将安全地适合标准 32 位整数。 
- 即使效率较低的解决方案仍然会通过，因为输入大小很小。 
- 然而，目标仍然是设计一个干净且最佳的线性时间解决方案。 

有几种边缘情况值得考虑：

 - 只包含一个节点的列表，例如`[0]`或者`[1]`- 带有前导零的二进制数，例如`[0,0,1]`- 每个值所在的列表`1`- 最大长度输入30个节点

 该问题保证列表是有效的二进制输入，因此我们永远不需要处理无效数字。 

## 方法

 ### 蛮力方法

 解决该问题的一个直接方法是首先将链表中的所有位提取到数组或字符串中。 之后，我们可以从右到左处理二进制表示并使用 2 的幂计算十进制值。 

例如：```
1 -> 0 -> 1
```可能会变成：```
"101"
```然后我们会评估：```
1 × 2² + 0 × 2¹ + 1 × 2⁰ = 5
```这是可行的，因为二进制位置表示法根据其位置将每个数字定义为 2 的幂。 

尽管这种方法是正确的，但它需要额外的内存来单独存储这些位。 它还执行额外的计算能力或反转位置的工作。 

### 最佳方法

 关键的观察是，可以在遍历链表时增量构建二进制数。 

假设我们已经处理了一些位，并且当前将它们的十进制值保存在一个名为的变量中`result`。 

当我们读取下一个二进制数字时：

 - 二进制左移一位相当于乘以`2`- 然后我们添加新的位

 所以更新规则就变成了：```
result = result * 2 + current_bit
```或等效地使用位操作：```
result = (result << 1) | current_bit
```这反映了二进制数是如何自然地逐位构建的。 

例如：```
1 -> 0 -> 1
```处理步骤：```
0
0 * 2 + 1 = 1
1 * 2 + 0 = 2
2 * 2 + 1 = 5
```这种方法一次性处理列表并使用恒定的额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 单独存储位，然后计算二进制值 |
 | 最佳| O(n) | O(1) | O(1) | 在遍历期间增量构建十进制值 |

 ## 算法演练

 1. 初始化一个名为`result`到`0`。 

该变量将存储到目前为止构建的十进制值。 
2、从头节点开始遍历链表。 

由于链表表示从最高有效位到最低有效位的二进制数，因此我们按顺序处理节点。 
3. 对于每个节点，将当前结果左移一位。 

左移一位相当于当前值乘以`2`。 这为下一个二进制数字创造了空间。 
4. 添加当前节点的值。 

因为每个节点包含`0`或者`1`，附加下一个二进制数字只是添加该位。 
5. 移动到下一个节点并重复，直到遍历完成。 
6. 返回最终存储的值`result`。 

### 为什么它有效

 每一步，`result`表示到目前为止处理的所有二进制数字的十进制值。 乘以`2`将现有二进制数字左移一位，完全匹配二进制位置规则。 添加当前位会将新的二进制数字附加到数字中。 由于每个节点都是按从最高有效位到最低有效位的顺序处理的，因此最终值是正确的十进制表示形式。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

from typing import Optional

class Solution:
    def getDecimalValue(self, head: Optional[ListNode]) -> int:
        result = 0
        current = head

        while current:
            result = (result << 1) | current.val
            current = current.next

        return result
```实现从初始化开始`result`到`0`。 该变量存储遍历期间构建的十进制值。 

然后我们使用名为的指针迭代链表`current`。 

在循环内部，表达式：```python
result = (result << 1) | current.val
```执行两个操作：

 -`result << 1`将当前二进制数左移一位，相当于乘以`2`-`| current.val`追加当前的二进制数字

 因为每个节点只包含`0`或者`1`，按位或运算干净地将新位插入到最低有效位置。 

处理完当前节点后，我们前进到下一个节点，直到遍历结束。 

最后，我们返回完整的十进制值。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func getDecimalValue(head *ListNode) int {
    result := 0
    current := head

    for current != nil {
        result = (result << 1) | current.Val
        current = current.Next
    }

    return result
}
```Go 实现遵循与 Python 解决方案完全相同的逻辑。 主要的语言特定差异是 Go 使用`nil`而不是`None`用于链表终止检查。 

位操作操作在 Go 中的工作方式相同。 由于输入大小限制为 30 位，因此对于 Go 的标准整数类型来说，整数溢出不是问题。

 ## 边缘情况

 一个重要的边缘情况是仅包含单个节点的链表。 输入如`[0]`或者`[1]`可能会暴露实现错误地假设存在多个节点的错误。 所提供的解决方案自然地处理了这个问题，因为即使对于单次迭代，遍历循环也能正常工作。 

Another important case is leading zeros, such as`[0,0,1]`。 一些不正确的实现可能会意外地忽略早期位或错误处理位置值。 移位方法正确地保留了二进制结构，因为每个处理的位根据其位置对最终值做出贡献。 

第三个重要的边缘情况是 30 个节点的最大输入大小。 尽管约束很小，但这仍然测试了实现是否可以在线性时间内有效地处理列表，而不会使用不必要的内存。 由于该算法仅使用一次遍历和恒定的额外空间，因此它可以干净地扩展到允许的最大输入大小。 

最后的边缘情况是所有位都为零，例如`[0,0,0]`。 如果某些实现不正确地初始化或更新累加器，则可能会错误地生成非零值。 在这里，重复的左移和与零的 OR 运算正确地保留了值`0`整个遍历过程中。
