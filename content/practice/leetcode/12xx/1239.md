[LeetCode 问题 1239](https://leetcode.com/problems/maximum-length-of-a-concatenated-string-with-unique-characters/)

 **难度：** 🟡 中等
 **主题：** 数组、字符串、回溯、位操作

 ## 解决方案

 ## 问题理解

 该问题要求我们从输入数组中选择字符串的子序列`arr`并将它们连接在一起，使得生成的字符串仅包含唯一字符。 在所有有效的串联中，我们必须返回最大可能的长度。 

子序列意味着我们可以包含或跳过每个字符串，同时保留原始顺序。 我们不允许重新排列字符串或字符。 重要的条件是最终连接字符串中的每个字符必须恰好出现一次。 

例如，如果我们连接`"un"`和`"iq"`，我们得到`"uniq"`，其中包含字符`u`,`n`,`i`， 和`q`，都是独一无二的。 然而，串联`"ab"`和`"bc"`会产生`"abbc"`，重复该字符`b`，使其无效。 

输入尺寸相对较小：

 -`arr.length <= 16`- 每个字符串的长度最多为`26`- 仅使用小写英文字母

 这些限制强烈表明指数探索是可以接受的，因为最多有`2^16 = 65,536`子序列。 对于仔细实施的回溯或位掩码解决方案来说，这已经足够小了。 

一些边缘情况很重要：

 - 字符串内部可能已经包含重复字符，例如`"aa"`。 此类字符串永远不可能成为有效答案的一部分。 
- 多个字符串的字符可能会重叠，从而导致它们无法组合。 
- 最佳答案可能只包含一个字符串。 
- 空子序列始终有效且有长度`0`。 
- 由于只存在小写英文字母，我们可以使用 26 位整数掩码有效地表示字符集。 

## 方法

 ### 蛮力方法

 最直接的解决方案是生成每个可能的子序列`arr`。 对于每个子序列，我们连接所有选定的字符串并检查最终结果是否包含唯一字符。 

暴力破解过程的工作原理如下：

 1.生成全部`2^n`子序列。 
2. 连接选定的字符串。 
3. 检查生成的字符串是否有重复字符。 
4. 跟踪最大有效长度。 

这种方法是正确的，因为它会检查每种可能的组合，保证找到最佳答案。 

然而，重复连接字符串和检查唯一性的效率很低。 每个验证步骤可能需要重复扫描许多字符。 虽然约束足够小，暴力破解可以通过，但它会执行不必​​要的工作。 

### 关键见解

 主要的优化来自于用位掩码表示字符集。 

由于只有 26 个小写字母，因此我们可以使用 26 位整数，其中每一位代表当前串联中是否存在字符。 

例如：

 - 位`0`代表`'a'`- 少量`1`代表`'b'`- 少量`25`代表`'z'`这有两个主要好处：

 1.我们可以快速判断一个字符串内部是否包含重复字符。 
2. 我们可以使用单个按位与运算来检查两个字符串是否重叠。 

如果两个掩码没有重叠位：```
mask1 & mask2 == 0
```然后可以安全地组合字符串。 

这将重复的字符扫描转换为恒定时间的位操作，使回溯更加高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n × n × 26) | O(2^n × n × 26) | O(n × 26) | 生成每个子序列并重复验证字符串 |
 | 最佳| O(2^n) | O(2^n) | O(2^n) | O(2^n) | 使用位掩码回溯进行快速重叠检查 |

 ## 算法演练

 ### 使用位掩码进行最佳回溯

 1. 首先，预处理每个字符串`arr`到位掩码中。 

对于字符串中的每个字符，计算其相应的位位置并在掩码中设置该位。 

如果我们遇到一个已经在同一个字符串中设置的字符，那么该字符串本身就包含重复项，并且永远无法使用。 我们立即丢弃它。 
2. 将所有有效的字符串掩码存储在列表中。 

每个掩码代表该字符串使用的字符集。 
3. 开始回溯掩码列表。 

在每个位置，我们都有两种选择：

 - 跳过当前字符串
 - 如果当前字符串不与现有字符重叠，则包含当前字符串
 4. 保持`current_mask`代表当前使用的所有字符。 

检查是否可以添加新字符串：```
current_mask & next_mask == 0
```如果此条件成立，则字符串不共享字符。 

1. 添加字符串时，使用按位或组合掩码：```
new_mask = current_mask | next_mask
```1. 在每次递归调用时，使用当前掩码中设置的位数更新最大答案。 
2. 继续探索所有有效组合，直到处理完所有掩码。 

### 为什么它有效

 该算法探索字符串的每个有效子序列。 位掩码表示形式保证当前串联中不存在重复字符，因为重叠掩码永远不会组合。 

由于每个有效组合仅被考虑一次并且无效组合被立即修剪，因此该算法总是找到最大可能的长度。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxLength(self, arr: List[str]) -> int:
        valid_masks = []

        # Convert each string into a bitmask
        for word in arr:
            mask = 0
            valid = True

            for ch in word:
                bit = 1 << (ord(ch) - ord('a'))

                # Duplicate character inside the same word
                if mask & bit:
                    valid = False
                    break

                mask |= bit

            if valid:
                valid_masks.append(mask)

        self.answer = 0

        def backtrack(index: int, current_mask: int) -> None:
            self.answer = max(self.answer, current_mask.bit_count())

            for i in range(index, len(valid_masks)):
                next_mask = valid_masks[i]

                # Skip if characters overlap
                if current_mask & next_mask:
                    continue

                backtrack(i + 1, current_mask | next_mask)

        backtrack(0, 0)

        return self.answer
```实现首先将每个字符串预处理为位掩码。 在此步骤中，包含重复字符的字符串将被丢弃，因为它们永远无法形成有效的解决方案。 

这`valid_masks`list 仅存储可用的字符串。 

递归`backtrack`函数探索所有有效的子序列。 这`current_mask`参数跟踪哪些字符已被使用。 

在每次递归调用时，我们都会使用以下方法更新答案：```python
current_mask.bit_count()
```这可以有效地计算当前选择的唯一字符的数量。 

在添加新字符串之前，我们检查是否重叠：```python
if current_mask & next_mask:
```如果存在重叠，添加该字符串将违反唯一性条件，因此我们跳过它。 

否则，我们使用按位或组合掩码并继续递归。 

## 解决方案```go
func maxLength(arr []string) int {
	validMasks := []int{}

	// Convert strings into bitmasks
	for _, word := range arr {
		mask := 0
		valid := true

		for _, ch := range word {
			bit := 1 << (ch - 'a')

			// Duplicate character inside the same word
			if mask&bit != 0 {
				valid = false
				break
			}

			mask |= bit
		}

		if valid {
			validMasks = append(validMasks, mask)
		}
	}

	answer := 0

	var backtrack func(index int, currentMask int)

	backtrack = func(index int, currentMask int) {
		length := 0

		// Count set bits
		temp := currentMask
		for temp > 0 {
			length += temp & 1
			temp >>= 1
		}

		if length > answer {
			answer = length
		}

		for i := index; i < len(validMasks); i++ {
			nextMask := validMasks[i]

			// Skip overlapping masks
			if currentMask&nextMask != 0 {
				continue
			}

			backtrack(i+1, currentMask|nextMask)
		}
	}

	backtrack(0, 0)

	return answer
}
```Go 实现遵循与 Python 版本相同的总体策略。 由于 Go 没有提供内置的`bit_count()`与 Python 相同的整数方法，我们使用循环手动计算设置的位。 

切片用于存储有效掩码，递归是使用分配给的闭包实现的`backtrack`。 

无需特殊处理`nil`需要与空切片进行比较，因为在 Go 中迭代空切片自然是安全的。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(2^n) | O(2^n) | 每个有效子集都会被探索一次 |

 预处理步骤最多需要`O(n × 26)`因为每个字符串的长度最多为26。 

主导因素是子集的递归探索。 由于每个字符串都可以包含或排除，因此组合的数量受以下限制：`2^n`。 

因为`n <= 16`，这已经足够有效了。

 ## 边缘情况

 当字符串内部包含重复字符时，会出现一种重要的边缘情况，例如`"aa"`或者`"abca"`。 幼稚的实现可能仍会尝试在递归期间使用这些字符串，从而创建无效的串联。 预处理阶段通过在构建掩码时检测重复位来立即消除此类字符串。 

当每个字符串与其他字符串重叠时，会发生另一个重要情况。 例如：```
["ab", "bc", "cd"]
```在这种情况下，算法必须正确确定不可能组合所有字符串。 位掩码重叠检查可确保在继续递归之前跳过无效组合。 

第三种边缘情况涉及空子序列。 如果每个字符串都无效，例如：```
["aa", "bb"]
```正确答案是`0`，代表空连接。 由于递归从空掩码开始，并且仅使用有效组合更新答案，因此该实现自然可以正确处理这种情况。 

当最佳解决方案不是由最长的单个字符串形成时，会出现另一种微妙的边缘情况。 例如：```
["abc", "de", "fgh"]
```最好的答案是`"defgh"`与长度`5`， 不是`"abc"`与长度`3`。 回溯方法探索所有有效组合，确保局部最优选择不会错误地终止搜索。
