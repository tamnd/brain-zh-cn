 **难度：** 🟡 中等
 **主题：** 数组、两个指针、排序

 ## 解决方案

 ## 问题理解

 这个问题要求我们在给定两个人各自的空闲时间安排的情况下，找到他们之间给定持续时间的最早重叠时间段。 每个人的可用性表示为一组不重叠的时隙`[start, end]`， 在哪里`start`和`end`是表示包含时间范围的整数。 会议持续时间是一个整数`duration`。 预期输出是最早的时间段`[start, start + duration]`适合两个人的可用性，或者如果不存在这样的插槽，则为空数组。 

约束告诉我们每个人最多可以有 10,000 个时间段，并且开始和结束时间可以大到 10^9。 这意味着检查两个人的每个槽位组合的简单解决方案会太慢（最多 10^8 次比较）。 重要的是，同一个人的两个时段不会重叠，因此每个人的日程安排已经在内部保持一致。 持续时间保证至少为 1 且不超过 10^6，这确保它可以与时隙长度进行有意义的比较。 

要考虑的边缘情况包括一个人的第一个时隙完全在另一个人的最后一个时隙之后、时隙短于所需的持续时间时，以及时隙恰好在其端点处接触但在会议持续时间内没有充分重叠时。 

## 方法

 蛮力方法将迭代每对时隙`slots1`和`slots2`。 对于每一对，它将计算交集并检查它是否可以容纳`duration`。 这是可行的，因为它会检查所有可能性，但计算成本很高。 如果每个人有 10,000 个槽位，这种方法可能需要多达 1 亿次比较，这对于给定的输入大小来说太慢了。 

最佳解决方案的关键见解是，通过**按开始时间对槽进行排序**并使用**双指针技术**，我们可以有效地找到重叠的槽，而无需检查每一对。 排序后，我们从每个人的第一个槽开始，计算他们的交集。 如果交集足够长，我们立即返回。 否则，我们将指针移至较早结束的槽，因为在该端之外不可能与其他人的当前槽有任何重叠。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 检查每对插槽是否重叠 |
 | 最佳| O(n log n + m log m) | O(n log n + m log m) | O(1) | O(1) | 对两个数组进行排序并使用两个指针来查找最早的交集 |

 ## 算法演练

 1. **对两个计划进行排序**：排序`slots1`和`slots2`按他们的开始时间。 这确保我们始终首先考虑最早的可用槽位，从而保证我们找到的第一个有效交叉点是最早的。 
2. **初始化两个指针**：设置`i = 0`为了`slots1`和`j = 0`为了`slots2`。 
3. **遍历两个列表**：虽然`i < len(slots1)`和`j < len(slots2)`，执行以下步骤：
 4. **计算重叠**：对于当前槽位`slot1 = slots1[i]`和`slot2 = slots2[j]`, 计算`start_overlap = max(slot1[0], slot2[0])`和`end_overlap = min(slot1[1], slot2[1])`。 这给出了两个人都可以使用的范围。 
5. **检查持续时间要求**：如果`end_overlap - start_overlap >= duration`， 返回`[start_overlap, start_overlap + duration]`。 这是满足持续时间的最早时隙。 
6. **前进指针**：移动最先结束的槽位的指针（`if slot1[1] < slot2[1] then i += 1 else j += 1`）。 直觉是较短的时段不能与其他人较晚的时段进一步重叠。 
7. **No slot found**：如果循环结束没有返回，则返回空数组`[]`。 

**为什么有效**：排序可确保我们始终按时间顺序检查插槽。 两指针方法保证我们永远不会错过可以满足持续时间的重叠，因为我们总是前进到无法对未来交叉点做出贡献的槽位。 维持的不变量是`slots1[i]`和`slots2[j]`是最早剩余的可能重叠的候选位置。 

## Python 解决方案```python
from typing import List

class Solution:
    def minAvailableDuration(self, slots1: List[List[int]], slots2: List[List[int]], duration: int) -> List[int]:
        # Sort both people's slots by start time
        slots1.sort(key=lambda x: x[0])
        slots2.sort(key=lambda x: x[0])
        
        i, j = 0, 0
        while i < len(slots1) and j < len(slots2):
            start_overlap = max(slots1[i][0], slots2[j][0])
            end_overlap = min(slots1[i][1], slots2[j][1])
            
            if end_overlap - start_overlap >= duration:
                return [start_overlap, start_overlap + duration]
            
            # Advance the pointer of the slot that ends first
            if slots1[i][1] < slots2[j][1]:
                i += 1
            else:
                j += 1
                
        return []
```实现首先对两个计划进行排序，以便我们可以按时间顺序有效地进行扫描。 然后它遍历两个列表，计算重叠并检查持续时间。 向前移动最先结束的槽的指针可确保我们不会错过任何潜在的交叉点，同时避免不必要的比较。 

## 解决方案```go
import "sort"

func minAvailableDuration(slots1 [][]int, slots2 [][]int, duration int) []int {
    sort.Slice(slots1, func(i, j int) bool { return slots1[i][0] < slots1[j][0] })
    sort.Slice(slots2, func(i, j int) bool { return slots2[i][0] < slots2[j][0] })

    i, j := 0, 0
    for i < len(slots1) && j < len(slots2) {
        startOverlap := max(slots1[i][0], slots2[j][0])
        endOverlap := min(slots1[i][1], slots2[j][1])

        if endOverlap-startOverlap >= duration {
            return []int{startOverlap, startOverlap + duration}
        }

        if slots1[i][1] < slots2[j][1] {
            i++
        } else {
            j++
        }
    }

    return []int{}
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```在 Go 中，我们使用`sort.Slice`对两个计划进行排序并定义辅助函数`max`和`min`为了可读性。 该逻辑完全反映了 Python 解决方案。 空切片`[]int{}`未找到会议空位时返回。
