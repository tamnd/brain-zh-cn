[LeetCode 问题 2472](https://leetcode.com/problems/maximum-number-of-non-overlapping-palindrome-substrings/)

 **难度：** 🔴难
 **主题：** 两个指针、字符串、动态规划、贪心

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定字符串中**非重叠回文子串**的最大数量`s`使得每个子串的长度至少为`k`。 换句话说，我们希望将字符串分割成有效的回文块，其中没有两个选定的块重叠并且每个块足够长。 输入是一个字符串`s`由小写英文字母和正整数组成`k`。 输出是一个整数，表示此类非重叠回文子串的最大数量。 

约束告诉我们字符串长度最多可达 2000，这意味着任何时间复杂度低于 O(n²) 的解决方案都可能太慢。 要考虑的边缘情况包括长度不大于 k 的子字符串不是回文的字符串、每个字符都相同的字符串以及 k 等于字符串长度的情况。 

需要注意的要点：

 1. 子串必须是连续的。 
2. 子串不能重叠。 
3. 每个回文数必须至少有长度`k`。 

这使得问题成为**回文检测**和**间隔选择**的组合，暗示动态规划或贪婪方法。 

## 方法

 **强力方法**将涉及生成长度≥ k 的所有可能的子串，检查每个子串是否是回文，然后尝试非重叠选择的所有组合。 这种方法是正确的，但效率极低，因为存在 O(n²) 个子字符串，并且对于每个子字符串检查回文可能需要 O(n)，从而导致 O(n³) 复杂性。 此外，尝试所有不重叠子串的组合将导致子串数量呈指数增长。 

最佳解决方案的**关键观察**是我们只需要知道**哪些子串是回文**，然后使用贪心或动态规划方法来选择**不重叠间隔的最大数量**。 使用**中心扩展方法**或**DP表**预先计算回文子串使我们能够快速检查回文。 一旦我们有了这个，我们就可以从左到右迭代，并始终选择在前一个回文结束后开始的下一个有效回文。 这是有效的，因为选择最早结束的回文给出了最大化计数的最佳机会（经典的间隔调度逻辑）。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n²) | 生成所有≥k的子串，检查回文，枚举所有组合 |
 | 最佳| O(n²) | O(n²) | 使用DP预先计算回文，然后进行贪心区间选择 |

 ## 算法演练

 1. **预计算回文**：创建一个2D布尔数组`is_palindrome[i][j]`指示子串是否`s[i:j+1]`是一个回文。 使用标准DP公式：`is_palindrome[i][j] = (s[i] == s[j]) and (j-i < 3 or is_palindrome[i+1][j-1])`。 这允许 O(1) 回文查询。 
2. **初始化变量**：设置一个变量`last_end = -1`跟踪最后选定的回文的末尾并且`count = 0`累积所选回文的数量。 
3. **迭代字符串**：对于每个可能的起始索引`i`在字符串中，检查所有子字符串`s[i:j+1]`在哪里`j >= i + k - 1`。 如果子串是回文并且`i > last_end`，选择它，增加`count`，并更新`last_end = j`。 
4. **返回结果**：迭代字符串后，返回`count`作为不重叠回文的最大数量。 

**为什么有效**：通过预先计算所有回文，我们减少了重复计算。 选择最早结束的回文可确保我们为未来的回文留出尽可能多的空间，这是一种贪婪策略，已知在区间选择问题中是最优的。 

## Python 解决方案```python
class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)
        # DP table for palindrome checks
        is_palindrome = [[False] * n for _ in range(n)]
        
        for end in range(n):
            for start in range(end + 1):
                if s[start] == s[end] and (end - start < 3 or is_palindrome[start + 1][end - 1]):
                    is_palindrome[start][end] = True
        
        count = 0
        last_end = -1
        
        for start in range(n):
            for end in range(start + k - 1, n):
                if is_palindrome[start][end] and start > last_end:
                    count += 1
                    last_end = end
                    break
        
        return count
```这个实现首先填充一个DP表来知道哪些子串是回文。 然后它从左到右迭代，贪婪地选择与先前选择不重叠的第一个有效回文。 内部循环在选择后立即中断以避免重叠，从而确保最大计数。 

## 解决方案```go
func maxPalindromes(s string, k int) int {
    n := len(s)
    isPalindrome := make([][]bool, n)
    for i := range isPalindrome {
        isPalindrome[i] = make([]bool, n)
    }
    
    for end := 0; end < n; end++ {
        for start := 0; start <= end; start++ {
            if s[start] == s[end] && (end-start < 3 || isPalindrome[start+1][end-1]) {
                isPalindrome[start][end] = true
            }
        }
    }
    
    count := 0
    lastEnd := -1
    
    for start := 0; start < n; start++ {
        for end := start + k - 1; end < n; end++ {
            if isPalindrome[start][end] && start > lastEnd {
                count++
                lastEnd = end
                break
            }
        }
    }
    
    return count
}
```Go 解决方案反映了 Python 逻辑。 主要区别在于显式切片初始化和使用`make`对于 DP 表。 Go 切片可以高效地处理布尔数组，并且算法逻辑保持不变。 

## 工作示例

 **示例1：**`s = "abaccdbbd", k = 3`- 长度≥3的回文：`"aba"`在`[0:2]`,`"acc"`无效的，`"dbbd"`在`[5:8]`。 
- 迭代：

 - 开始=0，选择`"aba"`,`last_end=2`,`count=1`。 
- 开始=5，选择`"dbbd"`,`last_end=8`,`count=2`。 
- 结果：2。 

**示例2：**`s = "adbcda", k = 2`- 不存在长度≥2的回文子串。 
- 结果：0。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n²) | 填充 DP 表需要 O(n²)，贪婪选择循环在最坏情况下也是 O(n²) |
 | 空间| O(n²) | 存储所有子串的回文状态的 DP 表需要 O(n²) 空间 |
