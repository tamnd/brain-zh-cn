[LeetCode 问题 2465](https://leetcode.com/problems/number-of-distinct-averages/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、两个指针、排序

 ## 解决方案

 ## 问题理解

 该问题需要使用特定过程计算从数字序列生成的不同平均值的数量。 输入是一个整数数组`nums`长度均匀。 该过程重复从数组中删除最小和最大的数字，计算它们的平均值，并继续直到数组为空。 输出是通过此过程获得的唯一平均值的数量。 

约束告诉我们，数组相对较小（最多 100 个元素），这使得即使是简单的方法也可行，但我们仍然应该以清晰度和效率为目标。 该数组始终具有偶数个元素，确保每个最小值都有一个相应的最大值进行配对。 输入数字范围为 0 到 100，这简化了处理并允许安全使用浮点除法，而无需担心极值。 

重要的边缘情况包括所有数字都相等的数组、具有重复数字的数组以及仅包含两个元素的数组。 这些情况只能产生一个唯一的平均值或多个重复的平均值，并且实现必须正确地仅计算不同的值。 

## 方法

 蛮力方法是完全按照所描述的方式模拟该过程。 在每一步中，我们都会搜索最小值和最大值，删除它们，计算它们的平均值，并将其存储在一个集合中以计算不同的平均值。 这种方法是正确的，但不是最优的，因为在未排序的数组中重复搜索最小值和最大值效率很低，最坏情况下的时间复杂度为 O(n²)。 

优化的关键观察是我们可以首先对数组进行排序。 一旦排序，最小的数字总是在开始，最大的总是在最后。 然后，我们可以使用两个指针将两端的元素配对，计算它们的平均值，并将它们插入到集合中。 排序需要 O(n log n) 时间，两指针传递需要 O(n) 时间，从而获得整体高效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复搜索最小值和最大值，将平均值存储在集合中 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对数组排序一次，使用两个指针计算平均值 |

 ## 算法演练

 1. 对输入数组进行排序`nums`按升序排列。 排序确保最小值位于开头，最大值位于末尾。 
2.初始化两个指针：`left`在开始处 (0) 和`right`最后（len(nums) - 1）。 
3.初始化一个空集`averages`存储唯一的平均值。 
4. 虽然`left < right`:

 1. 计算平均值`nums[left]`和`nums[right]`。 
2. 将此平均值添加到集合中`averages`。 
3. 增量`left`并减少`right`向内移动。 
5. 循环结束后，返回`averages`设置为不同平均值的数量。 

为什么有效：该算法之所以有效，是因为将排序数组中的最小和最大元素配对模仿了问题描述中的删除过程。 通过使用集合，重复的平均值将被自动忽略，从而保证最终计数代表不同的平均值。 

## Python 解决方案```python
from typing import List

class Solution:
    def distinctAverages(self, nums: List[int]) -> int:
        nums.sort()
        left, right = 0, len(nums) - 1
        averages = set()
        while left < right:
            avg = (nums[left] + nums[right]) / 2
            averages.add(avg)
            left += 1
            right -= 1
        return len(averages)
```这个Python解决方案首先排序`nums`使最小和最大的元素易于访问。 它使用两个指针从两端遍历，计算平均值并将其存储在一个集合中。 使用集合可确保仅计算唯一平均值。 最后，它返回不同平均值的数量。 

## 解决方案```go
import "sort"

func distinctAverages(nums []int) int {
    sort.Ints(nums)
    left, right := 0, len(nums)-1
    averages := make(map[float64]struct{})
    for left < right {
        avg := float64(nums[left]+nums[right]) / 2
        averages[avg] = struct{}{}
        left++
        right--
    }
    return len(averages)
}
```在 Go 中，我们使用以下方法对切片进行排序`sort.Ints`。 然后，我们使用两个指针，将平均值计算为 float64，并将其存储在映射中以确保唯一性。 Go 没有原生的集合类型，因此使用具有空结构值的映射。 该逻辑反映了 Python 解决方案。

 ## 边缘情况

 一种边缘情况是所有元素都相同的数组。 在这里，每个计算出的平均值都是相同的，并且算法必须正确返回 1。排序不会影响结果，并且集合可确保忽略重复项。 

第二个边缘情况是长度为 2 的数组。算法自然地处理这个问题，因为左指针从 0 开始，右指针从 1 开始，计算单个平均值并返回 1。 

第三种边缘情况涉及数字之间差距较大的数组。 例如，`[0,50,100,200]`产生不同的平均值，如 100 和 75。排序可确保正确配对，并且该集合仅准确计算唯一值，从而正确处理潜在的浮点平均值。
