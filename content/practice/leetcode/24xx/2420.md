[LeetCode 问题 2420](https://leetcode.com/problems/find-all-good-indices/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们识别数组中所有**好的索引**`nums`基于窗口大小`k`。 一个好的索引`i`满足两个条件：`k`紧邻**之前**的元素形成**非递增**序列，并且`k`紧随其后的元素形成一个非递减序列。 输入是一个从 0 索引的整数数组，并且`k`是一个正整数，使得`1 <= k <= n/2`，保证候选索引周围的前缀和后缀窗口`i`存在。 输出是按升序排列的所有此类索引的列表。 

约束表明`n`可以大到`10^5`和`nums[i]`可以达到`10^6`。 这排除了任何检查每个窗口中每个索引的暴力解决方案`O(k)`时间，因为总工作量可能是`O(n*k)`这太慢了。 

重要的边缘情况包括元素全部相等的数组、严格递增或递减的数组、`k`等于`1`，以及没有索引满足条件的数组。 这些是幼稚实现的潜在陷阱。 

## 方法

 **暴力方法**检查每个候选索引`i`单独。 对于每个索引，我们提取`k`之前的元素`i`并验证它们不增加，并提取`k`之后的元素`i`并验证它们是非递减的。 这种方法是正确的，但效率低下，因为每次检查都会花费`O(k)`并且有`O(n)`候选索引，导致`O(n*k)`时间复杂度。 对于大型`n`和`k`，这变得不可行。 

**最佳方法**依赖于**前缀信息**。 我们可以预先计算两个数组：`nonInc`和`nonDec`。`nonInc[i]`存储以索引结尾的连续非递增序列的长度`i`， 和`nonDec[i]`存储从索引开始的连续非递减序列的长度`i`。 使用这些数组，我们可以在恒定时间内检查索引是否`i`很好：如果`nonInc[i-1] >= k`和`nonDec[i+1] >= k`，然后索引`i`是有效的。 这将复杂性降低到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*k) | O(1) | O(1) | 通过检查子数组来单独检查每个候选索引 |
 | 最佳| O(n) | O(n) | 使用前缀和后缀数组在恒定时间内检查每个索引的条件 |

 ## 算法演练

 1.初始化两个数组`nonInc`和`nonDec`尺寸的`n`所有值设置为`1`。`nonInc[i]`将存储结束于的非递增序列的长度`i`， 和`nonDec[i]`起始于的非递减序列的长度`i`。 
2.从左到右遍历数组进行填充`nonInc`。 对于每个索引`i > 0`， 如果`nums[i] <= nums[i-1]`， 放`nonInc[i] = nonInc[i-1] + 1`。 否则就保留吧`1`。 
3.从右向左遍历数组进行填充`nonDec`。 对于每个索引`i < n-1`， 如果`nums[i] <= nums[i+1]`， 放`nonDec[i] = nonDec[i+1] + 1`。 否则就保留吧`1`。 
4. 迭代所有候选索引`i`从`k`到`n-k-1`。 对于每个索引，检查是否`nonInc[i-1] >= k`和`nonDec[i+1] >= k`。 如果两个条件都成立，则添加`i`到结果列表。 
5. 返回按升序排序的结果列表。 

**为什么它有效**：`nonInc[i-1]`准确捕获在索引之前结束的非递增段的长度`i`， 和`nonDec[i+1]`捕获从索引之后开始的非递减段`i`。 通过比较这些长度`k`，我们确保满足良好索引的前缀和后缀条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def goodIndices(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        if n < 2*k + 1:
            return []

        nonInc = [1] * n
        nonDec = [1] * n

        for i in range(1, n):
            if nums[i] <= nums[i-1]:
                nonInc[i] = nonInc[i-1] + 1

        for i in range(n-2, -1, -1):
            if nums[i] <= nums[i+1]:
                nonDec[i] = nonDec[i+1] + 1

        result = []
        for i in range(k, n-k):
            if nonInc[i-1] >= k and nonDec[i+1] >= k:
                result.append(i)
        return result
```Python 实现首先处理数组太短而没有任何好的索引的边缘情况。 然后，它构造前缀和后缀数组。 最后，它使用预先计算的长度检查每个候选索引并将有效索引附加到结果中。 

## 解决方案```go
func goodIndices(nums []int, k int) []int {
    n := len(nums)
    if n < 2*k+1 {
        return []int{}
    }

    nonInc := make([]int, n)
    nonDec := make([]int, n)
    for i := range nonInc {
        nonInc[i] = 1
        nonDec[i] = 1
    }

    for i := 1; i < n; i++ {
        if nums[i] <= nums[i-1] {
            nonInc[i] = nonInc[i-1] + 1
        }
    }

    for i := n-2; i >= 0; i-- {
        if nums[i] <= nums[i+1] {
            nonDec[i] = nonDec[i+1] + 1
        }
    }

    result := []int{}
    for i := k; i < n-k; i++ {
        if nonInc[i-1] >= k && nonDec[i+1] >= k {
            result = append(result, i)
        }
    }

    return result
}
```在 Go 中，切片初始化为`make`和长度设置为`1`。 该逻辑完全反映了 Python 的实现。 我们将好的索引附加到结果切片中，然后返回结果切片。 这里不用担心整数溢出，因为问题保证了标准整数范围内的界限。
