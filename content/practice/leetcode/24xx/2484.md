[LeetCode 问题 2484](https://leetcode.com/problems/count-palindromic-subsequences/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定数字字符串内所有长度为 5 的回文子序列`s`。 回文子序列是正向和反向读取相同的序列，可以通过删除零个或多个字符而不改变剩余字符的顺序来形成子序列。 例如，给定`"103301"`，一个长度为 5 的有效回文子序列是`"10301"`。 

输入`s`是长度最大为 10,000 的数字字符串。 输出是回文子序列模 10^9 + 7 的**计数**。 

重要的限制和影响：

 -`1 <= s.length <= 10^4`意味着对所有子序列进行暴力枚举是不可行的，因为存在多个组合（长度为 5 的子序列为 O(n^5)）。 
- 只允许使用数字（`0-9`)，这是一个小字符集。 这使我们能够使用频率数组或前缀/后缀计数进行优化。 
- 需要注意的边缘情况包括长度小于 5 的字符串（答案为 0）、具有重复相同数字的字符串（可以形成多个回文）以及根本没有回文的字符串。 

## 方法

 **暴力方法**：枚举字符串中 5 个索引的所有组合，并检查所选字符是否形成回文。 这可以正确工作，但速度非常慢，因为从 n 中选择 5 个索引具有 O(n^5) 复杂度，这对于 n = 10,000 来说是不可行的。 

**最佳方法**：关键的见解是长度为 5 的回文子序列具有以下形式`a b c b a`。 这意味着第一个和最后一个字符必须相同，第二个和第四个字符必须相同，中间字符可以是任何数字。 我们可以通过使用前缀和后缀频率数组有效地计算数字对来进行优化。 

1. 预先计算左侧和右侧的单个数字和数字对的计数。 
2. 迭代所有可能的中间位置`i`对于回文。 对于每个位置，计算有多少个有效位置`a b`对存在于左侧和右侧。 
3. 将每个左边对的数量乘以右边对的数量`i`并求和得到总数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^5) | O(n^5) | O(1) | O(1) | 枚举所有 5 长度子序列并检查回文性 |
 | 最佳| O(n * 100) ≈ O(n) | O(100) | 使用每个中间位置的前缀和后缀频率数组对对进行计数 |

 ## 算法演练

 1.初始化两个2D数组`left`和`right`尺寸的`10 x 10`存储数字对的计数`(a, b)`每个位置的左侧和右侧。 
2. 初始化`freqLeft`和`freqRight`大小为 10 的数组，用于存储左侧和右侧的个位数计数。 
3. 填充`right`通过从字符串末尾迭代到开头。 对于每个角色，更新`right`使用迄今为止在右侧看到的数字的频率。 增加每个的计数`(current_digit, other_digit)`一对。 更新`freqRight`因此。 
4. 从左到右迭代。 对于每个位置`i`作为回文的中间字符，乘以对的数量`(a, b)`向左按对数`(a, b)`向右得到以`i`。 累积这个计数。 
5. 更新`freqLeft`和`left`下一次迭代的数组。 

**为什么有效**：通过预先计算有效的数量`(a, b)`与每个潜在中间字符的左侧和右侧配对，我们确保每个有效的回文`a b c b a`只计算一次。 使用前缀和后缀频率数组保证了正确性。 

## Python 解决方案```python
class Solution:
    def countPalindromes(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        if n < 5:
            return 0

        left = [[0]*10 for _ in range(10)]
        right = [[0]*10 for _ in range(10)]
        freqLeft = [0]*10
        freqRight = [0]*10

        # Fill right pair counts
        for ch in s:
            d = int(ch)
            for i in range(10):
                right[i][d] += freqRight[i]
            freqRight[d] += 1

        result = 0
        freqLeft = [0]*10

        for ch in s:
            d = int(ch)
            freqRight[d] -= 1
            for i in range(10):
                right[i][d] -= freqRight[i]

            for a in range(10):
                for b in range(10):
                    result = (result + left[a][b] * right[a][b]) % MOD

            for i in range(10):
                left[i][d] += freqLeft[i]
            freqLeft[d] += 1

        return result
```该实现将计数分为三个阶段：构建右侧对、迭代中间位置并组合左侧和右侧计数以及更新左侧对。 这确保了所有回文子序列都得到有效计数，而不会遗漏任何或重复计数。 

## 解决方案```go
func countPalindromes(s string) int {
    const MOD = 1_000_000_007
    n := len(s)
    if n < 5 {
        return 0
    }

    left := [10][10]int{}
    right := [10][10]int{}
    freqLeft := [10]int{}
    freqRight := [10]int{}

    for _, ch := range s {
        d := int(ch - '0')
        for i := 0; i < 10; i++ {
            right[i][d] += freqRight[i]
        }
        freqRight[d]++
    }

    result := 0

    for _, ch := range s {
        d := int(ch - '0')
        freqRight[d]--
        for i := 0; i < 10; i++ {
            right[i][d] -= freqRight[i]
        }

        for a := 0; a < 10; a++ {
            for b := 0; b < 10; b++ {
                result = (result + left[a][b]*right[a][b]) % MOD
            }
        }

        for i := 0; i < 10; i++ {
            left[i][d] += freqLeft[i]
        }
        freqLeft[d]++
    }

    return result
}
```Go 版本反映了 Python 逻辑。 数组的数字大小是固定的`0-9`，整数溢出自然使用模算术处理，并且类型转换对于字符数字是显式的。 

## 工作示例

 **示例1：`s = "103301"`**

 -`left`第一个字符后的对：空。 
-`right`对：对像这样的对进行计数`(1,0)`,`(0,3)`,`(3,3)`等等
 - 中间人物`3`：`left[a][b] * right[a][b]`正好计算出 2 个回文（`10301`两次）。 

**示例2：`s = "0000000"`**

 - 5 个零的每个组合形成一个回文。 
-`left`和`right`配对计数可确保对所有 21 个子序列进行计数。 

**示例3：`s = "9999900000"`**

 - 只有回文数是`99999`和`00000`。 
- 正确计数对会返回 2。
