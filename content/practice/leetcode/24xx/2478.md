[LeetCode 问题 2478](https://leetcode.com/problems/number-of-beautiful-partitions/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算分割给定字符串的方法数量`s`的数字精确地`k`非重叠子串，其中每个子串满足特定规则：它必须以素数开头（`2`,`3`,`5`,`7`)，以非质数数字 (`1`,`4`,`6`,`8`,`9`），且长度至少为`minLength`。 结果必须按模返回`10^9 + 7`因为分区的数量可能非常大。 

输入由一个字符串组成`s`的数字来自`'1'`到`'9'`, 一个整数`k`所需分区的数量，以及`minLength`，每个子字符串允许的最小长度。 约束保证`s`相对较小（`length <= 1000`），所以算法大致可达`O(n^2)`或者`O(n^2 * k)`可能是可行的，但对所有分区进行强力枚举可能太慢。 

边缘情况包括字符串太短而无法生成的情况`k`至少的子串`minLength`，或者第一个或最后一个数字不满足素数/非素数规则，这会立即使答案为零。 

## 方法

 ### 蛮力

 天真的方法会尝试一切可能的方法将字符串拆分为`k`子字符串并检查每个候选分区的素数开始、非素数结束和长度约束。 虽然这保证了正确性，但效率极低，因为分割长度字符串的方法数量`n`进入`k`子串是组合的 (`C(n-1, k-1)`），对于`n = 1000`。 

### 最佳方法

 关键的观察是，可以增量检查约束，并且问题具有最佳子结构：如果我们知道以某个索引结尾的漂亮分区的数量`j`分区，我们可以通过扩展先前的有效索引来构建更大的分区。 这提出了动态规划解决方案。 

我们定义`dp[i][j]`作为以索引结尾的漂亮分区的数量`i`的`s`恰好与`j`子串。 对于每个有效的起始索引，我们检查长度是否至少为`minLength`结束于`i`是有效的。 使用 DP 数组的前缀和使我们能够有效地计算`O(1)`每个索引。 

这将强力组合搜索减少为可管理的动态规划解决方案，时间复杂度约为`O(n * k)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(C(n-1, k-1) * n) | O(C(n-1, k-1) * n) | O(k) | 枚举所有分区并检查约束 |
 | 最佳 | O(n * k) | O(n * k) | 使用带有前缀和的动态规划来跟踪有效分区 |

 ## 算法演练

 1. 将质数数字识别为一组以进行恒定时间查找：`{'2', '3', '5', '7'}`。 
2. 立即检查第一个数字是否`s`是质数，最后一位数字是非质数。 如果不是，则返回 0，因为不可能进行有效分区。 
3.初始化DP表`dp[i][j]`在哪里`i`是结束索引`s`和`j`是分区数。 
4. 设置`dp[i][1]`对于从索引 0 开始且长度至少为 1 的所有有效单个子字符串`minLength`并满足开始/结束规则。 
5. 对于每个索引`i`从 0 到`len(s)-1`对于每个分区计数`j`从 2 到`k`，向后迭代以找到有效的先前分区端点，这些端点可以形成以`i`至少长度`minLength`。 
6. 使用前缀和对所有有效的求和`dp[prev][j-1]`有效地而不是循环。 
7. 返回以以下结尾的分区总数`len(s)-1`恰好与`k`子串取模`10^9 + 7`。 

**为什么它有效**：动态规划不变量是`dp[i][j]`正确计算所有以以下结尾的分区`i`和`j`子串。 每个转换仅考虑满足约束的有效先前子串，以确保正确性。 

## Python 解决方案```python
class Solution:
    def beautifulPartitions(self, s: str, k: int, minLength: int) -> int:
        MOD = 10**9 + 7
        n = len(s)
        primes = {'2', '3', '5', '7'}

        if s[0] not in primes or s[-1] in primes:
            return 0
        
        valid = [0] * n
        for i in range(minLength - 1, n):
            if s[i] not in primes and s[i - minLength + 1] in primes:
                valid[i] = 1

        dp = [[0] * (k + 1) for _ in range(n)]
        for i in range(minLength - 1, n):
            if valid[i]:
                dp[i][1] = 1

        for j in range(2, k + 1):
            prefix = [0] * n
            prefix[0] = dp[0][j - 1]
            for i in range(1, n):
                prefix[i] = (prefix[i - 1] + dp[i][j - 1]) % MOD

            for i in range(minLength - 1, n):
                if not valid[i]:
                    continue
                left = i - minLength
                if left < 0:
                    continue
                dp[i][j] = prefix[left]

        return sum(dp[i][k] for i in range(n)) % MOD
```**实现说明**：我们首先标记子串的所有有效端点`valid`。 DP表`dp[i][j]`计算结束于的分区数`i`和`j`部分。 前缀和`prefix`有效地累加先前 DP 值的总和以避免嵌套循环。 最后，我们将所有有效端点相加`k`分区。 

## 解决方案```go
func beautifulPartitions(s string, k int, minLength int) int {
    const MOD = 1_000_000_007
    n := len(s)
    primes := map[byte]bool{'2': true, '3': true, '5': true, '7': true}

    if !primes[s[0]] || primes[s[n-1]] {
        return 0
    }

    valid := make([]int, n)
    for i := minLength - 1; i < n; i++ {
        if !primes[s[i]] && primes[s[i-minLength+1]] {
            valid[i] = 1
        }
    }

    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, k+1)
    }

    for i := minLength - 1; i < n; i++ {
        if valid[i] == 1 {
            dp[i][1] = 1
        }
    }

    for j := 2; j <= k; j++ {
        prefix := make([]int, n)
        prefix[0] = dp[0][j-1]
        for i := 1; i < n; i++ {
            prefix[i] = (prefix[i-1] + dp[i][j-1]) % MOD
        }
        for i := minLength - 1; i < n; i++ {
            if valid[i] == 0 {
                continue
            }
            left := i - minLength
            if left < 0 {
                continue
            }
            dp[i][j] = prefix[left]
        }
    }

    ans := 0
    for i := 0; i < n; i++ {
        ans = (ans + dp[i][k]) % MOD
    }
    return ans
}
```**Go 注释**：Go 实现镜像了 Python 逻辑，具有切片和显式初始化。 Map 用于恒定时间素数查找。 整数溢出的处理方式是`% MOD`积累过程中。
