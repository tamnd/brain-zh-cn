[LeetCode 问题 2466](https://leetcode.com/problems/count-ways-to-build-good-strings/)

 **难度：** 🟡 中等
 **主题：** 动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算可以通过重复附加任一字符串来构造的“好”字符串的数量`'0'`确切地`zero`次或`'1'`确切地`one`次，从空字符串开始。 如果字符串的长度介于`low`和`high`包容性。 输出必须按模返回`10^9 + 7`因为好的字符串数量可以增长得非常多。 

简单来说，我们试图找到构建长度为 的字符串的所有操作序列`[low, high]`，其中每个操作添加固定数量的`'0'`或`'1'`s。 输入参数定义这些构建块的大小（`zero`和`one`）和可接受的字符串长度范围（`low`到`high`）。 约束条件告诉我们`low`和`high`可以达到`10^5`，因此尝试显式生成所有字符串的算法会太慢。 边缘情况包括`low == high`,`zero == one`，或者极度倾斜的长度，例如`zero = 1`和`one = low`。 

关键的挑战是**高效**地计算所有有效序列，而无需枚举每个可能的字符串。 

## 方法

 暴力方法会尝试从空字符串开始生成所有可能的字符串，然后对长度为`[low, high]`。 这种方法在理论上是正确的，因为它探索了所有组合，但由于指数增长，它是不可行的 - 序列的数量增长得非常快`high`和尺寸`zero`和`one`。 

最佳方法使用**动态规划**。 我们可以定义一个DP数组`dp[i]`作为长度良好的字符串的数量`i`。 我们初始化`dp[0] = 1`因为只有一个长度为0的字符串：空字符串。 然后对于每个`i`从`1`到`high`，我们考虑添加一个`'0'`长度块`zero`或一个`'1'`长度块`one`，并增加`dp[i]`相应地，如果结果长度不超过`i`。 最后，我们总结一下`dp[i]`为所有人`i`之间`low`和`high`获得好字符串的总数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(高/分钟(零,一))) | O（高）| 以指数方式枚举所有字符串，对于大型字符串不可行`high`|
 | 最佳| O（高）| O（高）| DP 按长度计算字符串数量，无需显式枚举 |

 ## 算法演练

 1.初始化一个DP数组`dp`尺寸的`high + 1`所有元素均为 0，除了`dp[0] = 1`来解释空字符串。 
2. 循环遍历`i`从`1`到`high`。 对于每个`i`:

 a. 如果`i >= zero`， 添加`dp[i - zero]`到`dp[i]`。 这考虑了所有可以达到长度的字符串`i`通过附加一个块`'0'`。 

b. 如果`i >= one`， 添加`dp[i - one]`到`dp[i]`。 这考虑了所有可以达到长度的字符串`i`通过附加一个块`'1'`。 

c. 应用模数`10^9 + 7`到`dp[i]`以避免溢出。 
3. 初始化结果变量`total = 0`。 循环通过`i`从`low`到`high`并添加`dp[i]`到`total`，再次应用模数。 
4. 返回`total`。 

**为什么有效：** 每个长度`i`,`dp[i]`表示恰好具有该长度的有效字符串的数量。 通过使用 DP 递归，我们可以正确计算所有块添加序列，而不会遗漏或重复计算任何序列。 总结自`low`到`high`确保我们只计算好的字符串。 

## Python 解决方案```python
class Solution:
    def countGoodStrings(self, low: int, high: int, zero: int, one: int) -> int:
        MOD = 10**9 + 7
        dp = [0] * (high + 1)
        dp[0] = 1  # base case: empty string

        for length in range(1, high + 1):
            if length >= zero:
                dp[length] += dp[length - zero]
            if length >= one:
                dp[length] += dp[length - one]
            dp[length] %= MOD

        total = sum(dp[low:high + 1]) % MOD
        return total
```在这个实现中，DP数组用于统计每个长度的字符串数量。 我们迭代自`1`到`high`并通过考虑添加来更新计数`'0'`和`'1'`块。 每一步都应用模数以避免整数溢出。 最终总和为`dp[low:high + 1]`给出好字符串的总数.

 ## 解决方案```go
func countGoodStrings(low int, high int, zero int, one int) int {
    MOD := 1000000007
    dp := make([]int, high+1)
    dp[0] = 1

    for length := 1; length <= high; length++ {
        if length >= zero {
            dp[length] = (dp[length] + dp[length-zero]) % MOD
        }
        if length >= one {
            dp[length] = (dp[length] + dp[length-one]) % MOD
        }
    }

    total := 0
    for length := low; length <= high; length++ {
        total = (total + dp[length]) % MOD
    }

    return total
}
```Go 实现遵循与 Python 相同的逻辑。 使用切片而不是数组。 每一步都执行模运算以避免溢出。 边缘情况如`low == high`自然地通过对适当的范围求和来处理。

 | 0 | 基地| 1 |

 总和来自`low`到`high`→`dp[3] = 8`。 

**示例2：**`low = 2, high = 3, zero = 1, one = 2`| 长度我| dp[i] 计算 | dp[i] | dp[i] |
 | --- | --- | --- |
 | 0 | 基地| 1 |

 和`dp[2] + dp[3] = 2 + 3 = 5`。
