[LeetCode 问题 2435](https://leetcode.com/problems/paths-in-matrix-whose-sum-is-divisible-by-k/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们从左上角开始计算二维整数矩阵中的路径数`(0, 0)`到右下角`(m - 1, n - 1)`使得沿路径的值的总和可以被给定的整数整除`k`。 每一步的移动仅限**向下**或**向右**。 

输入`grid`是表示矩阵的二维整数数组，并且`k`是 1 到 50 之间的正整数。输出是一个整数，表示有效路径的计数，模数`10^9 + 7`。 

约束表明，虽然单元总数最多可达`5 * 10^4`，每个维度单独也可以达到`5 * 10^4`。 每个单元格包含一个小于或等于 100 的非负整数。这些约束表明，枚举所有路径的强力方法在计算上是不可行的，因为路径数量会随着网格大小呈指数增长。 

重要的边缘情况包括小网格（1x1、1xN、Nx1）、全零的网格以及以下情况`k = 1`，这意味着所有路径都是有效的，因为每个总和都可以被 1 整除。 

## 方法

 ### 蛮力方法

 蛮力方法将递归地探索所有可能的路径`(0, 0)`到`(m - 1, n - 1)`，跟踪每条路径的运行总和。 每当我们到达右下角时，我们都会检查总和是否可以整除`k`并增加一个计数器（如果是）。 虽然正确，但这种方法在单元格数量上是指数级的，O(2^(m+n))，因为每个单元格分为两种可能性：向右移动或向下移动。 考虑到限制，这太慢了。 

### 最佳方法

 最佳方法利用**动态编程和模块化算术**。 我们不是跟踪每条路径上的绝对和，而是跟踪模数和`k`在每个单元格。 具体来说，我们定义一个3D DP数组`dp[i][j][r]`表示到单元格的路径数`(i, j)`与模求和`k`等于`r`。 

我们可以计算每个`dp[i][j]`使用上面单元格中的值`(i-1, j)`和左边的单元格`(i, j-1)`，相应地更新模和。 这将状态空间减少到`O(m * n * k)`考虑到限制，这是可行的，因为`k`最多为 50。 

关键的见解是`sum % k`在加法下表现良好：`(a + b) % k = ((a % k) + (b % k)) % k`。 这使我们能够有效地传播路径计数，而无需存储实际的总和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(m+n) | 递归地探索所有路径，跟踪总和 |
 | 最佳| O(m * n * k) | O(n * k) | DP 使用和模 k； 可以通过一次只存储一行来优化空间|

 ## 算法演练

 1.初始化一个大小为2D DP的数组`[n][k]`来表示当前行。 每个元素`dp[j][r]`存储到单元格的路径数`(i, j)`与模求和`k`等于`r`。 全部初始化为0。 
2.设置起始单元格`(0, 0)`这样`dp[0][grid[0][0] % k] = 1`因为有一条路径具有该模数。 
3. 迭代每一行`i`从 0 到`m-1`。 
4. 对于行中的每个单元格`(i, j)`，迭代所有可能的先前模和`r`从上面的单元格`(i-1, j)`然后离开了`(i, j-1)`如果它们存在的话。 
5. 对于之前的每一项总和`r`，计算新模数为`(r + grid[i][j]) % k`并更新当前的`dp[j][new_mod]`通过添加前一个单元格的路径数。 
6. 应用模数`10^9 + 7`在每次更新期间避免溢出。 
7. 处理完最后一行后，答案存储在`dp[n-1][0]`，到右下单元格的路径数，其总和可被整除`k`。 

**为什么有效**：每个`dp[j][r]`正确计算所有结束于的路径`(i, j)`与模求和`k`等于`r`。 模运算保留了整除性，并且组合左侧和上方的结果可确保所有路径都被精确计数一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def numberOfPaths(self, grid: List[List[int]], k: int) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])
        dp = [[0] * k for _ in range(n)]
        dp[0][grid[0][0] % k] = 1
        
        for i in range(m):
            new_dp = [[0] * k for _ in range(n)]
            for j in range(n):
                for r in range(k):
                    if i > 0:
                        new_mod = (r + grid[i][j]) % k
                        new_dp[j][new_mod] = (new_dp[j][new_mod] + dp[j][r]) % MOD
                    if j > 0:
                        new_mod = (r + grid[i][j]) % k
                        new_dp[j][new_mod] = (new_dp[j][new_mod] + new_dp[j-1][r]) % MOD
                if i == 0 and j == 0:
                    new_dp[j][grid[0][0] % k] = 1
            dp = new_dp
        return dp[n-1][0]
```**说明**：我们维护一个代表每一行的滚动 DP 数组。 对于每个单元格，我们结合顶部和左侧单元格的计数，更新模和。 使用临时`new_dp`确保我们不会过早覆盖当前行值。 最后，`dp[n-1][0]`包含有效路径的数量。 

## 解决方案```go
func numberOfPaths(grid [][]int, k int) int {
    MOD := int(1e9 + 7)
    m, n := len(grid), len(grid[0])
    dp := make([][]int, n)
    for j := 0; j < n; j++ {
        dp[j] = make([]int, k)
    }
    dp[0][grid[0][0] % k] = 1
    
    for i := 0; i < m; i++ {
        newDp := make([][]int, n)
        for j := 0; j < n; j++ {
            newDp[j] = make([]int, k)
        }
        for j := 0; j < n; j++ {
            for r := 0; r < k; r++ {
                if i > 0 {
                    newMod := (r + grid[i][j]) % k
                    newDp[j][newMod] = (newDp[j][newMod] + dp[j][r]) % MOD
                }
                if j > 0 {
                    newMod := (r + grid[i][j]) % k
                    newDp[j][newMod] = (newDp[j][newMod] + newDp[j-1][r]) % MOD
                }
            }
            if i == 0 && j == 0 {
                newDp[j][grid[0][0]%k] = 1
            }
        }
        dp = newDp
    }
    return dp[n-1][0]
}
```**Go 特定注释**：切片是动态分配的。 我们处理模运算的方式与 Python 类似。 的初始化`newDp`确保前一行的值不被覆盖。 通过在每次加法时应用模数来防止溢出。 

## 工作示例

 ### 示例 1```
grid = [[5,2,4],
        [3,0,5],
        [0,7,2]], k = 3
```- 开始于`(0,0)`与模求和`k`= 2 (`5 % 3 = 2`）。 
- 向右移动`(0,1)`模 3 求和：`(2 + 2) % 3 = 1`- 向下移动`(1,0)`模 3 求和：`(2 + 3) % 3 = 2`- 继续直到`(2,2)`。 以 0 为模的路径被计数。 
- 最终计数：2 条路径。 

DP 阵列位于`(2,2)`显示：

 | 模| 计数|
 | --- | --- |
 | 0 | 2 |
 | 1 | 0 |
 | 2 | 2 |

 答案：2
