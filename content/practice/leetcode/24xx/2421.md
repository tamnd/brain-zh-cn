[LeetCode 问题 2421](https://leetcode.com/problems/number-of-good-paths/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、树、并查集、图论、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们计算树中**好路径**的数量。 树是一个连通的无环图`n`节点和`n - 1`边缘。 每个节点都有一个由数组分配的整数值`vals`。 **好的路径**被定义为简单路径（没有重复的节点），其中第一个和最后一个节点具有相同的值，并且所有中间节点的值**小于或等于**这个最大值。 单个节点算作有效路径，因为它通常满足条件。 

输入由一个数组组成`vals`长度`n`，表示节点值，以及一个数组`edges`长度`n - 1`，表示节点之间的无向连接。 输出是一个整数，表示不同的良好路径的总数。 

约束表明节点数量可以大到`3 * 10^4`，节点值可以大到`10^5`。 因为输入保证形成一棵树，所以我们知道不存在循环，每个节点都是连接的，并且我们不需要检查断开的组件。 

重要的边缘情况包括具有单个节点的树、具有相同值的多个节点以及中间节点超过起始节点值的路径。 如果不仔细考虑中间值，这些场景可能会导致简单的实现失败。 

## 方法

 ### 蛮力

 暴力方法涉及在树中生成所有可能的简单路径。 对于每条路径，我们将检查起始节点和结束节点是否具有相同的值，以及所有中间节点是否小于或等于该值。 虽然这种方法是正确的，但在计算上是不可行的。 生成树中的所有简单路径`n`节点可能导致指数复杂性，远远超出给定的约束`n <= 3 * 10^4`。 

### 最佳方法

 最佳解决方案的关键观察是，树结构允许我们使用**并集查找（不相交集并集）数据结构**与**按节点值排序**相结合。 通过按值的递增顺序处理节点，我们确保当我们合并节点时，我们形成的所有路径都满足“所有中间节点都小于或等于”约束。 具有相同值的节点可以相互形成良好的路径。 计算具有相等值的节点的连接组件内的组合，可以为我们提供除单节点路径之外的其他良好路径的数量。 

这种方法之所以有效，是因为在树中，两个节点之间的任何路径都是唯一的。 按值处理节点可确保我们只考虑有效路径并且不违反最大值约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成所有简单路径并验证每一个； 对于大的来说不可行`n`|
 | 最佳| O(n log n) | O(n log n) | O(n) | 按值对节点进行排序，使用并查找对连接的组件进行分组，组合计算好的路径 |

 ## 算法演练

 1. **初始化数据结构**：创建并查结构以有效管理连接的组件。 使用字典将节点值映射到具有该值的节点列表。 
2. **按值对节点进行排序**：从中提取唯一值`vals`并按升序处理它们。 这确保了当我们连接节点时，我们遵守“中间节点≤起始节点”约束。 
3. **联合连接节点**：对于当前值的每个节点，迭代其邻居。 如果邻居的值小于或等于当前值，则合并两个节点。 此步骤构建作为有效良好路径的连接组件。 
4. **计算组件中的好路径**：合并后，对于每个连接的组件，计算有多少个节点具有当前值。 如果有`k`这样的节点，它们形成`k * (k - 1) / 2`额外的好路径（成对组合），加上`k`单节点路径。 
5. **求和结果**：保持良好路径数量的运行总数。 最后返回这个值。 

**为什么有效**：通过按值递增的顺序处理节点并仅联合遵守值约束的节点，组件中计数的每条好路径都是有效的。 树的路径唯一性保证不会重复计算任何路径，并且对组件内等值节点的组合进行计数可说明所有有效的多节点路径。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int):
        xr, yr = self.find(x), self.find(y)
        if xr == yr:
            return
        if self.size[xr] < self.size[yr]:
            xr, yr = yr, xr
        self.parent[yr] = xr
        self.size[xr] += self.size[yr]

class Solution:
    def numberOfGoodPaths(self, vals: List[int], edges: List[List[int]]) -> int:
        n = len(vals)
        uf = UnionFind(n)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        val_to_nodes = defaultdict(list)
        for i, val in enumerate(vals):
            val_to_nodes[val].append(i)

        result = 0
        for val in sorted(val_to_nodes):
            nodes = val_to_nodes[val]
            for node in nodes:
                for neighbor in graph[node]:
                    if vals[neighbor] <= val:
                        uf.union(node, neighbor)

            count = defaultdict(int)
            for node in nodes:
                root = uf.find(node)
                count[root] += 1

            for c in count.values():
                result += c * (c + 1) // 2

        return result
```**实现说明**：我们首先构建图邻接表。 然后我们将值映射到相应的节点。 按升序处理值仅允许在满足良好路径约束的节点之间进行联合操作。 最后，我们计算每个连接组件中节点的成对组合，以确定良好路径的总数。 

## 解决方案```go
package main

func numberOfGoodPaths(vals []int, edges [][]int) int {
    n := len(vals)
    parent := make([]int, n)
    size := make([]int, n)
    for i := 0; i < n; i++ {
        parent[i] = i
        size[i] = 1
    }

    var find func(int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }

    union := func(x, y int) {
        xr, yr := find(x), find(y)
        if xr == yr {
            return
        }
        if size[xr] < size[yr] {
            xr, yr = yr, xr
        }
        parent[yr] = xr
        size[xr] += size[yr]
    }

    graph := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }

    valToNodes := make(map[int][]int)
    for i, val := range vals {
        valToNodes[val] = append(valToNodes[val], i)
    }

    keys := make([]int, 0, len(valToNodes))
    for k := range valToNodes {
        keys = append(keys, k)
    }
    sort.Ints(keys)

    result := 0
    for _, val := range keys {
        nodes := valToNodes[val]
        for _, node := range nodes {
            for _, neighbor := range graph[node] {
                if vals[neighbor] <= val {
                    union(node, neighbor)
                }
            }
        }

        count := make(map[int]int)
        for _, node := range nodes {
            root := find(node)
            count[root]++
        }

        for _, c := range count {
            result += c * (c + 1) / 2
        }
    }

    return result
}
```**Go 实现说明**：Go 使用切片作为邻接列表，使用映射来计数组件。 Union-Find 是通过切片来实现的`parent`和`size`。 排序和映射迭代反映了 Python 的行为。 整数溢出不是问题，因为约束在范围内`int`范围。

 ### 示例 1```
vals = [1,3,2,1,3]
edges = [[0,1],[0,2],[2,3],[2,4]]
```按顺序处理值：1、2、3

 - 值1：节点`[0, 3]`。 联合连接的节点<=1。 组件：{0}、{3}。 计数：2 个单节点路径 + 0 对 = 2。 
- 值2：节点`[2]`。 联合连接节点<=2。 组件：{2}。 数量：1 条路径。 
- 值3：节点`[1,4]`。 联合邻居<=3。 1-0-2-4 连接，根数：{1:2, 4:1}。 成对计算：3
