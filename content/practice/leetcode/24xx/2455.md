[LeetCode 问题 2455](https://leetcode.com/problems/average-value-of-even-numbers-that-are-divisible-by- Three/)

 **难度：** 🟢简单
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 该问题要求我们计算数组中所有整数的**平均值**`nums`同时满足两个条件：它们必须是**偶数**并且**能被3整除。 换句话说，我们只考虑 6 的倍数，因为既能被 2 又能被 3 整除的数字也能被 6 整除。 

输入是长度范围从 1 到 1000 的正整数列表，每个整数都在 1 到 1000 之间。输出是表示所选数字的平均值的单个整数，使用下限除法**向下舍入**到最接近的整数。 如果没有符合条件的数字，我们返回 0。 

约束要点：

 - 数组相对较小（`nums.length <= 1000`），因此即使是简单的线性扫描也是高效的。 
- 所有数字都是正数，因此我们不需要处理负数或零。 
- 有可能**没有数字符合标准**，这是一个重要的边缘情况。 

潜在的边缘情况：

 - 没有数字是偶数且可被 3 整除的数组（应返回 0）。 
- **所有数字**满足条件的数组。 
- 具有满足或不满足条件的**单个元素**的数组。 

## 方法

 **暴力方法**很简单：迭代数组，检查每个数字是否为偶数且可被 3 整除，将它们相加，并计算有多少个数字满足条件。 最后，将总和除以计数，如果计数为零则返回 0。 考虑到约束条件，这非常简单且高效，因为我们只需对最多 1000 个元素进行一次传递。 

**最优性的关键观察**是，没有比单遍更有效的方法了，因为我们必须至少检查每个数字一次，以验证它是否为偶数且可被 3 整除。因此，强力方法实际上是此处的最佳解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 迭代一次，对能被 6 整除的数字求和，对它们进行计数，计算平均值 |
 | 最佳 | O(n) | O(1) | O(1) | 与暴力破解相同； 单次通过已经是最佳的 |

 ## 算法演练

 1.初始化两个变量：`total_sum`到 0 和`count`到 0。它们将分别存储能被 6 整除的数字之和以及这些数字的个数。 
2. 迭代每个数字`num`在数组中`nums`。 
3. 对于每个`num`，检查它是否能被 6 整除（即`num % 6 == 0`）。 这确保了它既是偶数又可以被 3 整除。 
4. 如果`num`满足条件，添加到`total_sum`和增量`count`1.
 5. 遍历数组后，检查是否`count`大于0。如果是，则返回整数除法`total_sum // count`。 如果没有数字符合条件，则返回 0。 

**为什么有效：** 在每一步中，我们都保持不变式：`total_sum`包含迄今为止遇到的所有能被 6 整除的数字的总和`count`包含此类数字的数量。 迭代后将总和除以计数得出平均值，由于整数除法而正确舍入。 

## Python 解决方案```python
from typing import List

class Solution:
    def averageValue(self, nums: List[int]) -> int:
        total_sum = 0
        count = 0
        for num in nums:
            if num % 6 == 0:
                total_sum += num
                count += 1
        return total_sum // count if count > 0 else 0
```**实现演练：**我们定义两个变量，`total_sum`和`count`。 我们循环遍历`nums`，检查每个数字是否能被 6 整除。如果是，我们更新总和和计数。 循环结束后，我们使用整数除法来返回下限平均值，如果没有数字满足条件，则返回 0。 这直接实现了上面讨论的算法。 

## 解决方案```go
func averageValue(nums []int) int {
    totalSum := 0
    count := 0
    for _, num := range nums {
        if num % 6 == 0 {
            totalSum += num
            count++
        }
    }
    if count == 0 {
        return 0
    }
    return totalSum / count
}
```**Go 特定注释：** 我们使用`range`迭代切片`nums`。 Go 中的整数除法会自动将结果取整，类似于 Python。 诸如空计数之类的边缘情况通过`if`查看。

 ## 边缘情况

 1. **空的限定数字：** 当数组中没有可以被 6 整除的数字时，我们必须返回 0。这是通过检查 if 来正确处理的`count`除法前为0。 
2. **单元素数组：** 单个元素能被6整除的情况和不能被6整除的情况都是边缘情况。 实现工作正常，返回元素本身或 0。 
3. **接近1000的大数字：** 输入允许最大1000的数字，并且由于我们对它们进行求和，所以我们必须确保不会发生整数溢出。 在 Python 中，整数可以增长任意大，因此这是安全的。 在 Go 中，对于 32 位或 64 位的 1000 以下数字，整数溢出不是问题`int`。 

该解决方案对于问题约束内的所有输入都是稳健的。
