 **难度：** 🟡 中等
 **主题：** 数组、二分查找、位操作、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们查找给定数组中的每个索引`nums`，**从该索引开始的最短连续子数组的长度**，其**按位或**等于**从该索引向前可获得的最大可能的按位或**。 换句话说，我们需要查看所有以`i`，计算它们的按位 OR，并找到 OR 达到可实现的最大值的最小子数组`i`到数组的末尾。 

输入是一个从 0 索引的非负整数数组。 输出是一个相同大小的数组，其中每个元素表示实现最大按位 OR 的起始索引的最小子数组长度。 

约束告诉我们`n`最大可达 100,000 个，元素可达 10 亿个。 这意味着迭代所有子数组的简单解决方案是不可行的，因为`O(n^2)`复杂。 可能导致简单方法失败的边缘情况包括具有重复数字、全零的数组，或者仅在最后一个元素实现最大 OR 的数组。 

## 方法

 暴力方法涉及迭代每个索引，计算从该索引开始的每个可能子数组的 OR，然后选择实现最大 OR 的最小长度。 虽然正确，但这种方法具有 **O(n^2)** 时间复杂度，并且对于大型数组来说太慢。 

最佳方法利用了这样一个事实：**按位 OR 运算是单调的**：一旦在累积 OR 中将某个位设置为 1，就无法通过包含更多元素来取消设置。 这使我们能够计算每个索引可实现的最大或，然后以相反的顺序确定最小子数组长度。 我们维护每个位的最新位置，以计算该位出现在 OR 中所需的最小长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 对从每个索引开始的所有子数组计算“或”|
 | 最佳| O(n * B) | O(B) | 跟踪每个位的最后一次出现，使用位位置计算最小长度（B = 位数，≤ 30）|

 ## 算法演练

 1.初始化一个数组`answer`长度`n`来存储结果。 
2. 创建数组`nextPos`大小为 30（对于 30 位，因为`nums[i] <= 10^9`) 跟踪每个位的下一次出现，初始化为`n`（超出最后一个索引）。 
3. 从右向左遍历数组（从索引处开始）`n-1`）来更新`nextPos`对于存在于中的每一位`nums[i]`。 
4. 对于每个索引`i`，通过查看确定任何位需要扩展以实现最大 OR 的最远位置`nextPos`。 最小子数组长度为`farthest - i + 1`。 
5. 更新`nextPos`反映这些位`nums[i]`现在可以在索引中看到`i`。 
6. 继续，直到处理完索引 0。 返回`answer`大批。 

**为什么有效：** 按位或是单调的。 通过跟踪设置为 1 的每个位的最后位置，我们保证包括最远位的下一个位置之前的所有元素会产生最大 OR。 由于我们从右向左遍历，因此我们始终有正确的“未来”位置可用于计算最小长度。 

## Python 解决方案```python
from typing import List

class Solution:
    def smallestSubarrays(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [0] * n
        B = 30  # maximum number of bits to consider
        nextPos = [n] * B  # next position where each bit is set
        
        for i in range(n-1, -1, -1):
            farthest = i
            for bit in range(B):
                if (nums[i] >> bit) & 1:
                    nextPos[bit] = i
                if nextPos[bit] < n:
                    farthest = max(farthest, nextPos[bit])
            answer[i] = farthest - i + 1
        
        return answer
```**说明：** 我们初始化`nextPos`跟踪每个位的最新出现。 向后迭代，我们更新`nextPos`对于当前数字中的每一位。`farthest`跟踪当前索引处或之后出现的任何所需位的最大索引。 那么子数组的长度就是`farthest - i + 1`。 这可以有效地计算最小长度子数组，从而为每个起始索引实现最大 OR 值。 

## 解决方案```go
func smallestSubarrays(nums []int) []int {
    n := len(nums)
    answer := make([]int, n)
    B := 30
    nextPos := make([]int, B)
    for i := 0; i < B; i++ {
        nextPos[i] = n
    }

    for i := n - 1; i >= 0; i-- {
        farthest := i
        for bit := 0; bit < B; bit++ {
            if (nums[i]>>bit)&1 == 1 {
                nextPos[bit] = i
            }
            if nextPos[bit] < n {
                if nextPos[bit] > farthest {
                    farthest = nextPos[bit]
                }
            }
        }
        answer[i] = farthest - i + 1
    }
    return answer
}
```**说明：** Go 实现镜像 Python。 我们使用切片`answer`和`nextPos`。 整数算术和位移位的工作原理相同。 唯一的区别是切片的显式初始化和使用条件比较`== 1`。

 ## 边缘情况

 一种重要的边缘情况是**单元素数组**。 最小子数组的长度一般为 1，最大 OR 是元素本身。 我们的实现通过初始化正确处理了这个问题`farthest = i`。 

另一个边缘情况是当**最大 OR 出现在数组的最后一个元素**时，这需要从较早索引开始的子数组一直延伸到末尾。 使用`nextPos`确保我们正确计算最远的位位置，从而计算出最小子数组长度。
