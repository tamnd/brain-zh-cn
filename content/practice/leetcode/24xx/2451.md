 # LeetCode 2451 - 奇数字符串差异

 ## 问题理解

 该问题给了我们一个字符串数组，其中每个字符串都具有相同的长度。 对于每个字符串，我们通过减去连续字符的字母位置来构造一个差异数组。 

例如，字符串`"adc"`产生：

 -`'d' - 'a' = 3`-`'c' - 'd' = -1`所以它的差分数组就变成了`[3, -1]`。 

重要的观察是几乎所有字符串都共享完全相同的差异数组。 只有一个字符串具有不同的模式，我们必须识别并返回该字符串。 

输入数组`words`包含3到100个字符串，每个字符串长度在2到20之间。由于输入大小相对较小，因此我们不需要非常高级的优化。 然而，我们仍然想要一个干净、高效的解决方案。 

预期输出是原始字符串，其差异数组与大多数不同。 

这里有一些重要的细节：

 - 差异可能是负数。 
- 字符串保证只包含小写英文字母。 
- 所有字符串都具有相同的长度，这意味着每个差异数组具有相同的大小。 
- 恰好有一个字符串是不同的，因此总有一个唯一的答案。 

一个简单的错误是直接比较字符串而不是比较它们生成的差异数组。 另一个微妙的问题是一致地表示差异数组，以便它们可以用作哈希映射内的键。 

## 方法

 ### 蛮力方法

 一种简单的解决方案是为每个字符串生成差异数组，并将每个字符串与每个其他字符串进行比较。 

对于每个字符串，我们可以计算有多少其他字符串共享相同的差异模式。 频率为 1 的那个就是答案。 

这种方法之所以有效，是因为该问题保证了一个唯一的模式。 然而，它执行许多重复的比较。 如果有`m`字符串，每个差异数组都有长度`n - 1`，然后比较所有对的成本`O(m^2 * n)`时间。 

尽管约束足够小，这仍然可以通过，但效率却不必要地低下。 

### 最佳方法

 更好的方法是使用哈希图来计算每个差异模式的出现次数。 

我们首先将每个单词转换为其差异数组。 由于列表不能直接作为 Python 中的字典键或 Go 中的映射键，因此我们将差异数组转换为不可变的表示形式，例如元组或格式化字符串。 

当我们处理单词时，我们存储：

 - 差异模式
 - 出现的次数
 - 对应的原词

 最后，频率为 1 的模式对应于奇数串。 

这避免了重复的成对比较，并且每个单词仅处理一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m² × n) | O(m × n) | 将每个差异数组与所有其他数组进行比较 |
 | 最佳| O(m × n) | O(m × n) | 使用哈希图来计算差异模式 |

 这里，`m`是单词数，`n`是每个单词的长度。 

## 算法演练

 1. 创建一个辅助函数，将单词转换为其差异数组。 

对于每对相邻的字符，减去它们的字母位置。 按顺序存储这些差异，因为序列本身定义了模式。 
2. 初始化哈希图。 

键是差异模式，值将存储该模式出现的次数。 
3.逐个处理每个单词。 

生成其差异数组并将其转换为可哈希表示。 
4. 更新该模式的频率计数。 

同时，存储与模式关联的原始单词，以便我们稍后可以返回它。 
5. 处理完所有单词后，迭代存储的模式。 

频率恰好为 1 的模式对应于奇数串。 
6. 返回关联词。 

### 为什么它有效

 该问题保证除一个字符串之外的所有字符串都共享相同的差异数组。 因此，当我们计算每个模式的出现次数时，常见模式会出现多次，而独特模式只会出现一次。 由于每个单词都被正确处理并按其差异模式分组，因此该算法始终识别奇数字符串。 

## Python 解决方案```python
from collections import defaultdict
from typing import List, Tuple

class Solution:
    def oddString(self, words: List[str]) -> str:
        def build_difference(word: str) -> Tuple[int, ...]:
            differences = []

            for index in range(len(word) - 1):
                difference = ord(word[index + 1]) - ord(word[index])
                differences.append(difference)

            return tuple(differences)

        pattern_count = defaultdict(int)
        pattern_word = {}

        for word in words:
            pattern = build_difference(word)

            pattern_count[pattern] += 1
            pattern_word[pattern] = word

        for pattern, count in pattern_count.items():
            if count == 1:
                return pattern_word[pattern]

        return ""
```该解决方案首先定义一个名为的辅助函数`build_difference`。 该函数通过减去相邻字符代码将单词转换为其差异模式。 

差异数组被转换为元组，因为元组是不可变的并且可以用作字典键。 

这`pattern_count`字典跟踪每个模式出现的次数。 这`pattern_word`字典存储与每个模式关联的原始单词。 

当我们迭代输入单词时，我们生成相应的模式并更新两个词典。 

最后，我们扫描所有模式并返回模式只出现一次的单词。 

决赛`return ""`语句在技术上是不必要的，因为问题保证了有效的答案，但它使函数在语法上保持完整。 

## 解决方案```go
package main

import (
	"strconv"
	"strings"
)

func buildDifference(word string) string {
	var builder strings.Builder

	for i := 0; i < len(word)-1; i++ {
		diff := int(word[i+1]) - int(word[i])

		builder.WriteString(strconv.Itoa(diff))
		builder.WriteString(",")
	}

	return builder.String()
}

func oddString(words []string) string {
	patternCount := make(map[string]int)
	patternWord := make(map[string]string)

	for _, word := range words {
		pattern := buildDifference(word)

		patternCount[pattern]++
		patternWord[pattern] = word
	}

	for pattern, count := range patternCount {
		if count == 1 {
			return patternWord[pattern]
		}
	}

	return ""
}
```Go 解决方案遵循与 Python 版本相同的整体逻辑。 由于 Go 切片不能用作映射键，因此差异数组将转换为格式化字符串表示形式。 

这`strings.Builder`type 用于有效构建模式字符串。 每个差异都用逗号分隔，以避免值之间出现歧义。 

Go 中的 Map 天然支持频率计数和模式查找。 

不存在整数溢出问题，因为字符差异保持在非常小的范围内`-25`到`25`。

 ## 边缘情况

 一种重要的边缘情况是字符串长度只有两个字符。 在这种情况下，每个差异数组只包含一个值。 粗心的实现可能会错误地假设存在多个差异。 当前的解决方案自然地处理了这个问题，因为循环只运行一次。 

另一个重要的情况是重复相同的单词。 例如，多个副本`"aaa"`都产生相同的差异数组`[0, 0]`。 哈希图正确聚合这些频率，确保独特的模式仍然突出。 

负差异也很重要。 像这样的字符串`"za"`产生差异`-25`。 如果实现错误地仅假设正值，则比较逻辑将失败。 由于该算法直接存储有符号整数差，因此正值和负值都可以正确处理。 

最后一个微妙的边缘情况涉及哈希键表示。 在 Go 中，连接没有分隔符的值可能会产生不明确的键。 例如，`[1, 11]`和`[11, 1]`都可以成为`"111"`。 该实现通过在构造模式字符串时在值之间插入逗号来避免这种情况。
