[LeetCode 问题 2457](https://leetcode.com/problems/minimum-addition-to-make-integer-beautiful/)

 **难度：** 🟡 中等
 **主题：** 数学、贪心

 ## 解决方案

 ## 问题理解

 该问题要求我们变换给定的整数`n`通过添加最小的非负整数变成一个**美丽的**整数`x`。 如果一个整数的数字之和小于或等于给定值，则该整数被定义为漂亮整数`target`。 输入由两个数字组成：`n`（原始号码）和`target`（允许的最大数字和）。 输出是最小的`x`这样`n + x`变得美丽。 

约束表明`n`可以大到`10^12`和`target`最多 150。这意味着任何简单的方法都可以从`n`由于潜在的输入量很大，向上是不切实际的。 重要的边缘情况包括以下场景：`n`已经很漂亮了（所以`x`应为 0),`n`有很多位数，或者位数之和略高于`target`。 问题保证了解决方案的存在，因此我们不需要处理不可能的情况。 

## 方法

 **暴力方法**是检查从以下位置开始的每个连续整数`n`并计算它的数字和，直到它变得美丽为止。 这种方法是正确的，但对于较大的值来说非常慢`n`，因为计算每个数字和并迭代可能需要长达`10^12`迭代。 

最佳解决方案的**关键见解**来自于观察当我们将数字“四舍五入”到下一个十的幂的倍数时数字总和如何变化。 通过逐步将最低有效侧的数字清零并递增高位数字，我们可以最小化添加的数字，同时确保所得整数的数字总和不超过`target`。 本质上，我们正在模拟进位操作来创建最小的漂亮数字。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * log n) | O(n * log n) | O(1) | O(1) | 增量`n`直到数字总和 <= 目标。 对于大 n 来说太慢了。 |
 | 最佳 | O(log n) | O(1) | O(1) | 将 n 位逐位向上舍入到 10^k 的下一个倍数，直到数字总和 <= 目标。 |

 ## 算法演练

 1. 计算数字之和`n`。 如果已经<=`target`，返回 0 因为`n`已经很漂亮了。 
2. 初始化`factor`到 1。这代表我们四舍五入到的当前 10 的幂。 
3. 当工作号码的各位数字之和大于时循环`target`:

 1. 计算`increment = factor - (n % factor)`。 这是将最低有效数字四舍五入为零所需的最小数字。 
2.添加`increment`到`n`。 
3. 乘法`factor`10 移动到下一个更高的数字。 
4. 一旦数字之和`n`是 <=`target`，返回增量的累积和作为最小值`x`。 

**为什么有效：** 通过逐步对数字进行四舍五入，我们可以确保删除对总和贡献过多的低位数字，同时尽可能少地增加较高位数字。 这保证了结果数是可能的最小美丽数，并且增量之和给出了最小`x`。 

## Python 解决方案```python
class Solution:
    def makeIntegerBeautiful(self, n: int, target: int) -> int:
        def digit_sum(num: int) -> int:
            total = 0
            while num > 0:
                total += num % 10
                num //= 10
            return total
        
        if digit_sum(n) <= target:
            return 0
        
        result = 0
        factor = 1
        
        while digit_sum(n) > target:
            increment = factor - (n % factor)
            n += increment
            result += increment
            factor *= 10
        
        return result
```该代码首先定义一个辅助函数来计算数字之和。 如果`n`已经很漂亮了，返回0。否则，迭代向上取整`n`到下一个十的递增幂的倍数，累加总增量，直到满足数字和条件。 

## 解决方案```go
func makeIntegerBeautiful(n int64, target int) int64 {
    digitSum := func(num int64) int {
        sum := 0
        for num > 0 {
            sum += int(num % 10)
            num /= 10
        }
        return sum
    }
    
    if digitSum(n) <= target {
        return 0
    }
    
    var result int64 = 0
    factor := int64(1)
    
    for digitSum(n) > target {
        increment := factor - (n % factor)
        n += increment
        result += increment
        factor *= 10
    }
    
    return result
}
```Go 的实现反映了 Python 的逻辑。 它定义了一个闭包`digitSum`用于计算数字总和，处理大整数`int64`，并使用与累积增量相同的舍入策略。

 ## 边缘情况

 当出现一种边缘情况时`n`已经很漂亮了。 简单的算法可能仍会尝试增量，但我们的解决方案首先检查数字总和并立即返回 0。另一种情况是当增量导致进位增加位数时，例如 999 → 1000。基于因子的舍入通过在每个数字级别计算适当的增量来正确处理此问题。 最后，附近有非常大的数字`10^12`暴力方法可能会导致性能问题，但对数迭代可以确保效率。
