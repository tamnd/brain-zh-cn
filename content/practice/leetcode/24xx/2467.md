[LeetCode 问题 2467](https://leetcode.com/problems/most-profitable-path-in-a-tree/)

 **难度：** 🟡 中等
 **主题：** 数组、树、深度优先搜索、广度优先搜索、图论

 ## 解决方案

 ## 问题理解

 问题提出了一棵有根树`n`节点编号从`0`到`n-1`，其中节点`0`是根。 每个节点都有一个门，可以花费金钱打开（负值）或给予奖励（正值）。 Alice 从根开始，Bob 从指定节点开始。 两者同时移动：爱丽丝向叶子移动以最大化她的净收益，而鲍勃向根部移动。 如果他们在一个节点相遇，则门的成本或奖励将平均分配。 一旦节点的大门被打开，任何人都无法再从中获得或失去。 

输入包括`edges`，表示树结构，`bob`，这是 Bob 的起始节点，并且`amount`，表示每个节点的货币效应。 输出是Alice通过选择到达叶子的最优路径所能获得的最大净收入。 

约束表明树可以很大（最多`10^5`节点），因此任何未经优化探索所有路径的幼稚解决方案都会太慢。 输入保证形成有效的树，并且所有`amount`值是偶数。 边缘情况包括 Bob 从根附近开始、负奖励或所有正奖励。 

## 方法

 ### 蛮力方法

 暴力方法将模拟爱丽丝的每条可能的叶路径，跟踪鲍勃通往根的路径。 对于每条路径，通过检查 Bob 是否首先访问该节点、同时访问该节点还是根本没有访问该节点来计算 Alice 的净收入。 这保证了正确性，因为它直接计算爱丽丝所有可能性的收入。 

然而，暴力解决方案效率低下，因为在最坏的情况下，树中的叶路径数量可能是指数级的。 这种方法不能扩展到`n = 10^5`节点。 

### 最佳方法

 关键的见解是将鲍勃的运动建模为从节点到他到达每个节点的**时间**的地图。 我们执行从 Bob 到根的 DFS 来记录这一点。 然后，我们从 Alice 的根开始执行 DFS，根据 Bob 到达的时间计算她在每个节点的潜在收入。 在每个节点：

 - 如果爱丽丝先于鲍勃到达，她将获得全部奖励或支付全部费用。 
- 如果爱丽丝和鲍勃同时到达，她收取或支付一半。 
- 如果鲍勃已经过去了，她就什么也得不到。 

我们将此计算传播到叶子，跟踪所有叶子路径上的最大收入。 这种方法非常高效，因为每个节点仅被访问两次（每个 DFS 一次），从而产生线性时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 探索所有叶子路径，对于大树来说效率低下 |
 | 最佳| O(n) | O(n) | 从 Bob 到根的 DFS + 从根到叶子的 DFS，树大小呈线性 |

 ## 算法演练

 1. **为树构建邻接表**`edges`大批。 这允许有效的遍历。 
2. **记录鲍勃的到达时间**。 使用从 Bob 到根的 DFS，存储 Bob 到达每个节点所需的步数（时间）。 这将用于确定与 Alice 共享门禁。 
3. **从根节点对Alice执行DFS**。 每一步：

 - 确定爱丽丝的当前时间（深度）。 
- 根据以下规则计算 Alice 在节点的净收益：

 - 如果 Alice **早于 ** Bob 到达，则添加全额金额。 
- 如果爱丽丝与鲍勃**同时**到达，则添加一半的金额。 
- 如果爱丽丝**晚于**鲍勃到达，则添加零。 
4. **对当前节点的所有子节点继续递归地进行 DFS。 
5. **在叶子节点**，更新迄今为止遇到的最大净收入。 
6. **返回探索所有叶子路径后的最大净收入**。 

**为什么有效：**

 不变的是，Alice 在任意节点的净收入仅取决于她的到达时间和 Bob 的到达时间。 通过首先计算鲍勃的时间，我们可以准确地模拟同时或顺序的门交互。 DFS 确保我们有效地评估所有叶路径。 

## Python 解决方案```python
from typing import List, Dict

class Solution:
    def mostProfitablePath(self, edges: List[List[int]], bob: int, amount: List[int]) -> int:
        from collections import defaultdict

        n = len(amount)
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # Record Bob's arrival time at each node; -1 if not on path
        bob_time = [-1] * n
        
        def dfs_bob(node: int, parent: int, time: int) -> bool:
            if node == 0:
                bob_time[node] = time
                return True
            for nei in graph[node]:
                if nei != parent and dfs_bob(nei, node, time + 1):
                    bob_time[node] = time
                    return True
            return False
        
        dfs_bob(bob, -1, 0)
        
        max_income = float('-inf')
        
        def dfs_alice(node: int, parent: int, alice_time: int, current_sum: int):
            nonlocal max_income
            # Determine Alice's gain at this node
            if bob_time[node] == -1 or alice_time < bob_time[node]:
                gain = amount[node]
            elif alice_time == bob_time[node]:
                gain = amount[node] // 2
            else:
                gain = 0
            current_sum += gain
            
            # Leaf check
            if len(graph[node]) == 1 and node != 0:
                max_income = max(max_income, current_sum)
                return
            
            for nei in graph[node]:
                if nei != parent:
                    dfs_alice(nei, node, alice_time + 1, current_sum)
        
        dfs_alice(0, -1, 0, 0)
        return max_income
```Python 解决方案首先构建邻接表并计算 Bob 到达每个节点的时间。 然后，Alice 的 DFS 根据时间规则计算净收入。 叶子节点更新最大收入。 使用`defaultdict(list)`简化了邻接管理，递归 DFS 可以有效地处理树遍历。 

## 解决方案```go
package main

func mostProfitablePath(edges [][]int, bob int, amount []int) int {
    n := len(amount)
    graph := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }
    
    bobTime := make([]int, n)
    for i := range bobTime {
        bobTime[i] = -1
    }
    
    var dfsBob func(node, parent, time int) bool
    dfsBob = func(node, parent, time int) bool {
        if node == 0 {
            bobTime[node] = time
            return true
        }
        for _, nei := range graph[node] {
            if nei != parent && dfsBob(nei, node, time+1) {
                bobTime[node] = time
                return true
            }
        }
        return false
    }
    
    dfsBob(bob, -1, 0)
    
    maxIncome := -1 << 60
    
    var dfsAlice func(node, parent, aliceTime, currentSum int)
    dfsAlice = func(node, parent, aliceTime, currentSum int) {
        var gain int
        if bobTime[node] == -1 || aliceTime < bobTime[node] {
            gain = amount[node]
        } else if aliceTime == bobTime[node] {
            gain = amount[node] / 2
        } else {
            gain = 0
        }
        currentSum += gain
        
        if len(graph[node]) == 1 && node != 0 {
            if currentSum > maxIncome {
                maxIncome = currentSum
            }
            return
        }
        
        for _, nei := range graph[node] {
            if nei != parent {
                dfsAlice(nei, node, aliceTime+1, currentSum)
            }
        }
    }
    
    dfsAlice(0, -1, 0, 0)
    return maxIncome
}
```Go 实现反映了 Python 逻辑。`graph`是相邻切片的切片，`bobTime`存储 Bob 的到达，DFS 函数被定义为闭包。 叶子检测和增益计算遵循相同的规则。 Go 特定的处理包括大的负初始化`maxIncome`。

 - 节点 4：爱丽丝独自一人，增益 6 → 当前总和 6

 最大收入 = 6。
