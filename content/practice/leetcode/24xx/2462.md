[LeetCode 问题 2462](https://leetcode.com/problems/total-cost-to-hire-k-workers/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、堆（优先级队列）、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们模拟一个招聘过程`k`列表中的工人`costs`，其中每个工人都有相关成本。 我们只能从一开始就雇用工人`candidates`工人或最后`candidates`每次招聘期间的工人。 目标是准确计算雇用后产生的总成本`k`工人，总是从允许的候选人中选择成本最低的工人。 如果多个worker的成本相同，则选择索引最小的那个。 一旦工人被雇用，他们就会被排除在考虑范围之外。 

输入由一个整数数组组成`costs`长度最多为 10^5，这意味着任何算法都必须高效，理想情况下为 O(n log n) 或更好。 整数`k`和`candidates`分别指定要雇用的工人数量和两端的池大小。 输出是一个整数，即成本的总和`k`雇用的工人。 

边缘情况包括以下情况`candidates`大于或等于数组长度的一半、所有元素都相同的数组以及最小长度的数组。 这些需要仔细处理重叠的候选池和按索引打破平局。 

## 方法

 蛮力方法是重复扫描第一个`candidates`最后`candidates`工人找到成本最低的工人，将其删除，并累积总成本。 每次选择需要 O(k * 候选) 时间复杂度，在最坏的情况下可能达到 O(k * n) 。 对于大型`n`和`k`，这是低效的。 

最佳方法使用两个最小堆（优先级队列）来维护数组两端的最小成本候选者。 我们首先推第一个`candidates`工人进入左堆和最后一个`candidates`工人进入正确的堆。 在每次招聘过程中，我们都会比较两个堆的顶部元素，选择最小的元素，然后如果还有剩余的未处理的工人，则将其替换为该侧的下一个候选人。 这确保每个招聘会话花费 O(log 候选人) 时间，并且总体复杂性为 O(k log 候选人)，考虑到限制，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k * 候选者) | O(1) | O(1) | 多次扫描允许工人|
 | 最佳 | O(k 对数候选) | O(候选者 * 2) | 使用两个堆来有效地选择成本最低的 |

 ## 算法演练

 1.初始化两个最小堆，`left_heap`和`right_heap`，存储元组`(cost, index)`对于第一个`candidates`最后`candidates`分别为工人。 如果工人总数少于`2 * candidates`，确保两个堆中的工作人员不要重叠。 
2. 跟踪左侧和右侧的下一个可用索引，`l`和`r`，从初始堆窗口之外开始。 
3. 初始化变量`total_cost`至 0。 
4. 重复`k`次数：

 1. 比较中的最小元素`left_heap`和`right_heap`。 
2. 选择成本较小的。 如果出现平局，请选择`left_heap`（确保选择最小的索引）。 
3. 将选定的成本添加到`total_cost`。 
4. 如果所选堆在当前堆窗口之外还有剩余的worker，则将下一个worker推入堆中并递增/递减`l`或者`r`因此。 
5. 返回`total_cost`。 

工作原理：该算法保持两个堆始终包含当前第一个和最后一个可用候选者的不变性。 通过始终比较每个堆中的最小元素，我们确保在每个会话中允许的候选者中选择全局最小成本。 这保证了正确性，同时保持了效率。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def totalCost(self, costs: List[int], k: int, candidates: int) -> int:
        n = len(costs)
        total_cost = 0
        
        left_heap, right_heap = [], []
        l, r = candidates, n - candidates - 1
        
        for i in range(candidates):
            heapq.heappush(left_heap, (costs[i], i))
        
        for i in range(max(candidates, n - candidates), n):
            heapq.heappush(right_heap, (costs[i], i))
        
        for _ in range(k):
            if left_heap and right_heap:
                if left_heap[0] <= right_heap[0]:
                    cost, idx = heapq.heappop(left_heap)
                    total_cost += cost
                    if l <= r:
                        heapq.heappush(left_heap, (costs[l], l))
                        l += 1
                else:
                    cost, idx = heapq.heappop(right_heap)
                    total_cost += cost
                    if l <= r:
                        heapq.heappush(right_heap, (costs[r], r))
                        r -= 1
            elif left_heap:
                cost, idx = heapq.heappop(left_heap)
                total_cost += cost
            else:
                cost, idx = heapq.heappop(right_heap)
                total_cost += cost
        
        return total_cost
```此 Python 解决方案为第一个和最后一个候选创建两个最小堆，并使用指针来维护当前候选窗口。 每次招聘会话都会弹出成本最小的工人，如果还有未处理的工人，则补充堆。 该过程重复进行`k`计算总招聘成本的时间。 

## 解决方案```go
package main

import (
	"container/heap"
)

type Worker struct {
	cost int
	index int
}

type MinHeap []Worker

func (h MinHeap) Len() int { return len(h) }
func (h MinHeap) Less(i, j int) bool {
	if h[i].cost == h[j].cost {
		return h[i].index < h[j].index
	}
	return h[i].cost < h[j].cost
}
func (h MinHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }

func (h *MinHeap) Push(x interface{}) { *h = append(*h, x.(Worker)) }
func (h *MinHeap) Pop() interface{} {
	old := *h
	n := len(old)
	item := old[n-1]
	*h = old[:n-1]
	return item
}

func totalCost(costs []int, k int, candidates int) int64 {
	n := len(costs)
	var total int64
	leftHeap := &MinHeap{}
	rightHeap := &MinHeap{}
	heap.Init(leftHeap)
	heap.Init(rightHeap)
	l, r := candidates, n - candidates - 1

	for i := 0; i < candidates && i < n; i++ {
		heap.Push(leftHeap, Worker{costs[i], i})
	}
	for i := max(candidates, n - candidates); i < n; i++ {
		heap.Push(rightHeap, Worker{costs[i], i})
	}

	for i := 0; i < k; i++ {
		if leftHeap.Len() > 0 && rightHeap.Len() > 0 {
			if (*leftHeap)[0].cost < (*rightHeap)[0].cost || ((*leftHeap)[0].cost == (*rightHeap)[0].cost && (*leftHeap)[0].index < (*rightHeap)[0].index) {
				w := heap.Pop(leftHeap).(Worker)
				total += int64(w.cost)
				if l <= r {
					heap.Push(leftHeap, Worker{costs[l], l})
					l++
				}
			} else {
				w := heap.Pop(rightHeap).(Worker)
				total += int64(w.cost)
				if l <= r {
					heap.Push(rightHeap, Worker{costs[r], r})
					r--
				}
			}
		} else if leftHeap.Len() > 0 {
			w := heap.Pop(leftHeap).(Worker)
			total += int64(w.cost)
		} else {
			w := heap.Pop(rightHeap).(Worker)
			total += int64(w.cost)
		}
	}
	return total
}

func max(a, b int) int {
	if a > b { return a }
	return b
}
```Go 解决方案镜像了 Python 逻辑，但使用了自定义`MinHeap`类型来处理带有索引平局的堆操作。 Go 特定的细节包括使用`int64`总计以避免溢出并小心处理切片索引。
