[LeetCode 问题 2413](https://leetcode.com/problems/smallest-even-multiple/)

 **难度：** 🟢简单
 **主题：** 数学、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们找到两者的倍数的最小正整数`2`和给定的正整数`n`。 换句话说，我们正在寻找 **最小公倍数 (LCM)**`2`和`n`。 输入`n`保证在之间`1`和`150`，这是一个非常小的范围。 这允许简单的算术而不用担心整数溢出。 

关键的观察是`2`非常小，任何偶数都会自动成为`2`。 如果`n`已经是偶数，两者的最小倍数`2`和`n`只是`n`。 如果`n`是奇数，乘以`2`产生可被整除的最小偶数`n`。 要考虑的边缘情况包括`n = 1`（尽可能小的输入），以及`n = 2`（已经是了）。 

## 方法

 蛮力方法是从`n`并增加`1`直到找到一个可以被两者整除的数`2`和`n`。 虽然这种方法有效，但效率很低，尤其是对于较大的数字。 考虑到限制，这并不重要，但没有必要。 

最佳方法利用对奇偶性的观察：如果`n`是偶数，返回`n`; 如果`n`为奇数，返回`2 * n`。 这是有效的，因为将奇数乘以`2`保证它可以被两者整除`n`和`2`。 不需要循环或额外的数据结构。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 增量自`n`直到找到一个能被2整除的数和n |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 检查n是否为偶数； 如果不是，则返回 2 * n |

 ## 算法演练

 1. 检查输入的号码是否正确`n`是均匀的。 这可以使用模运算符来完成：`n % 2 == 0`。 
2.如果`n`是偶数，它已经可以被整除`2`和它本身，所以返回`n`。 
3.如果`n`是奇数，相乘`n`经过`2`确保结果可以被两者整除`2`和`n`。 
4. 返回结果数。 

为什么它有效：这是有效的，因为每个偶数都可以被整除`2`。 如果`n`是奇数，`2 * n`是最小的偶数倍`n`因为乘以`2`保留整除性`n`同时保证其均匀。 该算法仅通过一次条件检查即可保证正确性。 

## Python 解决方案```python
class Solution:
    def smallestEvenMultiple(self, n: int) -> int:
        if n % 2 == 0:
            return n
        else:
            return 2 * n
```Python 实现完全遵循该算法。 模运算符检查是否`n`是均匀的。 如果是，我们返回`n`。 如果没有，我们就加倍。 这确保了约束内所有输入的最小计算和直接处理。 

## 解决方案```go
func smallestEvenMultiple(n int) int {
    if n%2 == 0 {
        return n
    }
    return 2 * n
}
```Go 实现反映了 Python 逻辑。 这`%`运算符检查奇偶校验，条件返回`n`或者`2 * n`。 对于溢出或切片没有特殊的考虑，因为输入范围很小并且 Go 整数可以处理最大乘积`2 * 150`安全。 

## 工作示例

 **示例1：**`n = 5`自从`5`是奇数，乘以`2`。 结果是`10`。 

| 步骤| n | 状况 | 结果 |
 | --- | --- | --- | --- |
 | 1 | 5 | 5 % 2 != 0 | 2 * 5 = 10 | 2 * 5 = 10 |
 | 2 | 10 | 10 返回 | 10 | 10

 **示例2：**`n = 6`自从`6`是偶数，返回`6`。 

| 步骤| n | 状况 | 结果 |
 | --- | --- | --- | --- |
 | 1 | 6 | 6 % 2 == 0 | 返回 6 |

 ## 边缘情况

 首先，`n = 1`是最小的正整数。 乘以`2`是必要的，因为`1`是奇数，确保返回值是偶数。 第二，`n = 2`已经是均匀的了。 返回`n`直接是正确的，因为它可以被两者整除`2`和它本身。 三、最大投入`n = 150`测试没有发生算术溢出。 自从`2 * 150 = 300`完全在标准整数范围内，实现可以毫无问题地处理它。 之间的所有其他奇数和偶数`1`和`150`由简单条件统一处理。
