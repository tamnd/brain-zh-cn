[LeetCode 问题 2416](https://leetcode.com/problems/sum-of-prefix-scores-of-strings/)

 **难度：** 🔴难
 **主题：** 数组、字符串、Trie、计数

 ## 解决方案

 ## 问题理解

 问题是要求我们计算字符串列表中每个字符串的特殊分数。 具体来说，对于一个字符串`term`，它的 **score** 被定义为数组中具有以下特征的字符串的数量：`term`作为前缀。 主要任务是计算列表中每个字符串的所有**非空前缀**的分数总和。 

例如，如果`words = ["abc", "ab", "bc", "b"]`，我们考虑前缀`"a"`,`"ab"`,`"abc"`为了`"abc"`，并计算列表中有多少个单词以每个前缀开头。 将这些计数相加即可得出该字符串的最终分数。 输出应该是这些和的数组，保持输入的顺序。 

输入最多包含 1000 个字符串，每个字符串的长度最多为 1000 个字符。 这些约束意味着将每个字符串的每个前缀与所有字符串进行比较的简单方法可能太慢，因为这会导致粗略的结果$O(n^2 \cdot L^2)$最坏情况下的操作，其中$L$是最大字符串长度。 该问题仅保证非空字符串和小写字母，这简化了前缀处理并允许基于 trie 的优化。 

重要的边缘情况包括单字符字符串、重复字符串以及广泛共享公共前缀的字符串，因为如果处理不当，这些可能会产生大量计数。 

## 方法

 **暴力方法**将迭代每个字符串，提取所有非空前缀，然后对于每个前缀，迭代数组中的所有字符串以计算匹配项。 这是正确的，因为它显式地计算每个前缀出现的次数，但由于重复扫描每个前缀的所有字符串，因此效率低下。 

**最佳方法**使用 **Trie（前缀树）** 来有效聚合前缀计数。 特里树中的每个节点都会跟踪有多少单词经过它。 通过将所有单词插入到特里结构中并沿路径递增计数，我们可以稍后在恒定时间内计算任何前缀相对于其长度的分数。 将一个单词的所有前缀的分数相加就变成了沿着单词字典树中的路径进行简单的遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * L) | O(n^2 * L) | O(1) | O(1) | 将每个前缀与所有单词进行比较，对于 n=L=1000 来说太慢 |
 | 最佳| O(n * L) | O(n * L) | 基于Trie的解决方案，高效计数前缀 |

 ## 算法演练

 1. **初始化 Trie**：创建一个根节点，其中子节点为空字典，计数器初始化为零。 计数器将存储通过该节点的单词数。 
2. **将所有单词插入 Trie**：对于每个单词，从根开始并迭代其字符。 对于每个字符：

 - 如果该角色不在当前节点的子节点中，则创建一个新节点。 
- 移动到该角色对应的子节点。 
- 将节点的计数器增加 1。该计数器现在表示具有该前缀的单词数。 
3. **计算每个单词的前缀和**：对于每个单词，按照其字符遍历 trie。 在每个节点，将其计数器添加到运行总和中。 该总和代表该单词的所有前缀的总分。 
4. **返回结果**：将计算出的总和收集在列表或切片中，并将其作为答案返回。 

**为什么起作用**： trie 确保所有前缀都存储在分层结构中。 每个节点的计数器准确跟踪有多少单词共享该前缀。 通过遍历 trie 中每个单词的路径，我们可以有效地对其所有前缀的计数进行求和，而无需进行冗余比较。 

## Python 解决方案```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.count = 0

class Solution:
    def sumPrefixScores(self, words: List[str]) -> List[int]:
        root = TrieNode()
        
        # Build the Trie and count prefixes
        for word in words:
            node = root
            for char in word:
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
                node.count += 1
        
        # Calculate sum of prefix scores
        result = []
        for word in words:
            node = root
            total = 0
            for char in word:
                node = node.children[char]
                total += node.count
            result.append(total)
        
        return result
```**实施演练**：我们定义一个`TrieNode`用于容纳子级和前缀计数的类。 首先，我们将所有单词插入到 trie 中，沿路径递增计数。 接下来，对于每个单词，我们遍历 trie 并对沿其路径的所有节点的计数求和，产生所需的前缀分数总和。 

## 解决方案```go
type TrieNode struct {
	children map[rune]*TrieNode
	count    int
}

func sumPrefixScores(words []string) []int {
	root := &TrieNode{children: make(map[rune]*TrieNode)}
	
	// Build Trie and count prefixes
	for _, word := range words {
		node := root
		for _, ch := range word {
			if node.children[ch] == nil {
				node.children[ch] = &TrieNode{children: make(map[rune]*TrieNode)}
			}
			node = node.children[ch]
			node.count++
		}
	}
	
	// Calculate sum of prefix scores
	result := make([]int, len(words))
	for i, word := range words {
		node := root
		total := 0
		for _, ch := range word {
			node = node.children[ch]
			total += node.count
		}
		result[i] = total
	}
	
	return result
}
```**Go 特定注释**：Go 需要显式初始化映射`TrieNode`。 在迭代字符串以正确支持 Unicode 时，我们还会显式处理符文，尽管小写英文字母足以解决此问题。 切片用于结果。 

## 工作示例

 示例：`words = ["abc","ab","bc","b"]`1. 插入“abc”→更新计数：a:1, b:1, c:1
 2. 插入“ab”→更新计数：a:2, b:2
 3. 插入“bc”→更新计数：b:3, c:2
 4. 插入“b”→更新计数：b:4

 前缀和：

 | 词| 前缀 | 计数| 总和|
 | --- | --- | --- | --- |
 | “abc”| a、ab、abc | 2, 2, 1 | 5 |
 | “ab”| 一个，一个| 2, 2 | 4 |
 | “BC”| 乙，公元前| 4, 1 | 5（匹配之前的解释应该是3，小心）|

 仔细算一下，正确的计数是：

 - a：出现在“abc”、“ab”→2
 - ab：出现在“abc”、“ab”→2
 - abc：出现在“abc”→1
 - b：出现在“b”，“bc”→2
 - bc：出现在“bc”→1

 因此求和匹配问题描述：`[5,4,3,2]`。

 ## 边缘情况

 **单字符单词**：它们本身是有效的前缀，并且可能与以相同字符开头的其他单词重叠。 实现通过遍历 trie 正确地对它们进行计数。 

**重复单词**：当单词重复时，所有前缀的计数都会增加多次。 trie 节点正确累积计数，确保重复项的总和准确。 

**非常长的单词**：长度为 1000 的单词强调时间和空间。 使用 trie 可以避免重复比较，使时间复杂度相对于字符总数保持线性而不是二次。 

该解决方案可以正确处理所有这些边缘情况，同时保持高效。
