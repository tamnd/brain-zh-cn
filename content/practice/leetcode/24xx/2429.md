[LeetCode 问题 2429](https://leetcode.com/problems/minimize-xor/)

 **难度：** 🟡 中等
 **主题：** 贪婪、位操作

 ## 解决方案

 ## 问题理解

 问题是要求我们构造一个整数`x`满足两个条件。 第一的，`x`必须具有与给定整数相同数量的设置位（二进制表示中的 1）`num2`。 其次，异或`x`与另一个整数`num1`必须最小化。 换句话说，我们想要`x XOR num1`尽可能小，这相当于使`x`尽可能接近`num1`尽可能以二进制形式表示，但要遵守设置位数的限制。 

输入`num1`和`num2`是范围内的正整数`[1, 10^9]`。 这意味着我们需要考虑的最大位数是 30，因为`2^30`略大于`10^9`。 该问题保证了解决方案是唯一的，因此我们不需要考虑关系或多个可能的值`x`。 

重要的边缘情况包括`num1`和`num2`具有相同数量的设置位（然后`x = num1`）， 什么时候`num2`设置位多于`num1`（我们需要添加位），当`num2`设置位少于`num1`（我们需要删除位）。 仔细处理这些可确保最小的 XOR 值。 

## 方法

 暴力方法将涉及生成具有相同数量的设置位的所有整数`num2`和计算`x XOR num1`对于每个候选人。 然后我们将选择异或最小的整数。 虽然这保证了正确性，但在计算上是不可行的。 整数的个数`k`30 位空间中的设置位为`C(30, k)`，它可能非常大并且会导致组合爆炸。 

最佳方法利用贪婪的位操作策略。 关键的见解是最小化异或`num1`，我们应该尝试对齐设置的位`x`与设置位`num1`。 这可以通过两个步骤完成：首先，保留尽可能多的设置位`num1`尽可能，其次，如果我们仍然需要更多设置位，请打开最低的未设置位。 相反，如果我们需要较少的设置位，我们会关闭最高的设置位。 这确保了`x`是最接近的整数`num1`就XOR而言，同时满足设置的位要求。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(1) | O(1) | 枚举与 num2 具有相同设置位的所有数字，对于 n ~ 30 不可行 |
 | 最佳| O(30) | O(1) | O(1) | 基于 num1 贪婪地设置/取消设置位以匹配 num2 的设置位计数 |

 ## 算法演练

 1. 计算设置位的数量`num2`并将其存储在`target_bits`。 这是1的个数`x`必须有。 
2. 计算设置位的数量`num1`并将其存储在`num1_bits`。 
3.如果`num1_bits`等于`target_bits`， 然后`x = num1`我们就完成了。 
4.如果`num1_bits`大于`target_bits`，我们需要关闭一些位`num1`。 从最低有效位 (LSB) 开始，关闭 1，直到达到所需的设置位数。 
5. 如果`num1_bits`小于`target_bits`，我们需要打开额外的位。 从最低有效位开始并打开 0，直到`x`具有所需的设置位数。 
6. 返回结果整数`x`。 

为什么它有效：通过对齐最高有效位`x`和`num1`我们尽可能地减少异或。 如果需要额外的位，选择最低的未设置位可确保 XOR 值的增加最小化。 这种贪婪方法保证了 XOR 最小化，同时满足设置的位数。 

## Python 解决方案```python
class Solution:
    def minimizeXor(self, num1: int, num2: int) -> int:
        target_bits = bin(num2).count('1')
        num1_bits = bin(num1).count('1')
        x = num1
        
        if num1_bits > target_bits:
            excess = num1_bits - target_bits
            for i in range(31):
                if excess == 0:
                    break
                if (x >> i) & 1:
                    x ^= (1 << i)
                    excess -= 1
        elif num1_bits < target_bits:
            deficit = target_bits - num1_bits
            for i in range(31):
                if deficit == 0:
                    break
                if not ((x >> i) & 1):
                    x |= (1 << i)
                    deficit -= 1
        return x
```此 Python 实现对设置的位进行计数，比较计数，然后删除或添加位以匹配目标。 它使用按位移位和掩码来有效地操作各个位。 由于最大 30 位表示，循环仅限于 31 次迭代`num1`和`num2`。 

## 解决方案```go
func minimizeXor(num1 int, num2 int) int {
    targetBits := 0
    n := num2
    for n > 0 {
        targetBits += n & 1
        n >>= 1
    }
    
    x := num1
    num1Bits := 0
    n = num1
    for n > 0 {
        num1Bits += n & 1
        n >>= 1
    }
    
    if num1Bits > targetBits {
        excess := num1Bits - targetBits
        for i := 0; i < 31; i++ {
            if excess == 0 {
                break
            }
            if (x>>i)&1 == 1 {
                x ^= 1 << i
                excess--
            }
        }
    } else if num1Bits < targetBits {
        deficit := targetBits - num1Bits
        for i := 0; i < 31; i++ {
            if deficit == 0 {
                break
            }
            if (x>>i)&1 == 0 {
                x |= 1 << i
                deficit--
            }
        }
    }
    
    return x
}
```Go 实现遵循与 Python 相同的逻辑，使用显式循环来计数位并使用按位运算符操作各个位。 

## 工作示例

 **示例1：**`num1 = 3, num2 = 5`二进制表示：`num1 = 0011`,`num2 = 0101`。`target_bits = 2`(数字2),`num1_bits = 2`。 由于计数相等，`x = num1 = 3`。 

**示例2：**`num1 = 1, num2 = 12`二进制表示：`num1 = 0001`,`num2 = 1100`。`target_bits = 2`(数字2),`num1_bits = 1`。 需要加1位。 从LSB开始，第1位为0→设置它。 结果`x = 0011 = 3`。

 一种边缘情况是当`num1`和`num2`已经具有相同数量的设置位。 幼稚的实现可能会尝试不必要地更改位，但正确的方法会识别这种相等性并返回`num1`立即地。
