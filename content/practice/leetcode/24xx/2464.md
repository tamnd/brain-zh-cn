 ## 解决方案

 ## 问题理解

 该问题要求我们分割一个整数数组`nums`分成连续的子数组，使得每个子数组满足**有效性条件**：子数组的第一个和最后一个元素的最大公约数 (GCD) 必须严格大于 1。`nums`必须恰好属于一个子数组。 我们的目标是找到满足此标准的**最小子数组数量**。 如果不存在有效的分割，我们返回`-1`。 

输入`nums`是一个整数列表，其中`1 <= nums.length <= 1000`并且每个元素满足`1 <= nums[i] <= 10^5`。 这些约束表明，尝试每种可能的子数组分割的直接暴力方法可能在计算上成本高昂，因为子数组的数量随数组长度呈二次方增长。 此外，元素等于`1`永远不能与任何其他数字形成有效的子数组，因为`gcd(1, x) = 1`，不大于 1。 

重要的边缘情况包括包含以下内容的数组`1`s、所有元素互质的数组、所有元素相同的数组以及长度为 1 的数组。 

## 方法

 ### 蛮力

 强力方法是尝试所有可能的方法将数组拆分为连续的子数组，并检查每个子数组的第一个和最后一个元素是否满足 GCD 条件。 我们将递归地尝试每个可能的分区并跟踪子数组的最小数量。 虽然这保证了正确性，但效率极低，因为分区数量随着数组长度呈指数增长，对于长度达到 1000 的数组来说不可行。 

### 最佳方法

 关键的见解是，只要当前子数组的第一个元素和所考虑的子数组段的最后一个元素的 GCD 大于 1，每个有效子数组都可以从左到右贪婪地扩展。这允许我们在线性时间内扫描数组，同时保持动态编程数组`dp[i]`表示以索引结尾的有效子数组的最小数量`i`。 

对于每个元素`nums[i]`，我们检查所有可能的起始位置`j <= i`对于结束于的子数组`i`。 如果`gcd(nums[j], nums[i]) > 1`，我们可以从以下形式形成一个有效的子数组`j`到`i`， 和`dp[i]`更新为`dp[j-1] + 1`（或 1，如果`j = 0`）。 扫描后，`dp[n-1]`包含整个数组的最小有效子数组数，或者`-1`如果不可能进行有效的分割。 

这种动态编程方法避免了检​​查所有分区，并利用 GCD 条件有效地修剪无效子数组。

 ## 算法演练

 1.初始化一个DP数组`dp`长度`n`和`inf`， 在哪里`dp[i]`表示以索引结尾的有效子数组的最小数量`i`。 
2. 迭代每个索引`i`从`0`到`n-1`。 
3. 对于每个`i`，迭代可能的起始索引`j`从`0`到`i`形成一个子数组`nums[j..i]`。 
4. 计算`gcd(nums[j], nums[i])`。 如果 GCD 大于 1，则子数组有效。 
5. 更新`dp[i]`和`dp[j-1] + 1`如果`j > 0`， 或者`1`如果`j == 0`。 
6.全部处理完毕后`i`， 查看`dp[n-1]`。 如果是的话`inf`， 返回`-1`因为不存在有效的分割； 否则，返回`dp[n-1]`。 

**为什么它有效：** 该算法之所以有效是因为`dp[i]`始终存储分割所需的最小子数组数`nums[0..i]`有效地。 通过考虑所有以以下结尾的有效子数组`i`并更新`dp[i]`我们贪婪地确保每个索引都得到最佳覆盖。 不变的是在处理索引之前`i`,`dp[0..i-1]`已经包含其各自前缀的最小数量的有效子数组。 

## Python 解决方案```python
from math import gcd
from typing import List

class Solution:
    def validSubarraySplit(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [float('inf')] * n
        
        for i in range(n):
            for j in range(i + 1):
                if gcd(nums[j], nums[i]) > 1:
                    if j == 0:
                        dp[i] = 1
                    else:
                        dp[i] = min(dp[i], dp[j-1] + 1)
        
        return dp[-1] if dp[-1] != float('inf') else -1
```Python 实现使用嵌套循环，其中外循环迭代结束索引`i`内部循环迭代可能的起始索引`j`。 这`gcd`函数用于验证子数组的有效性。 这`dp`数组根据上面解释的规则更新。 最后，解决方案返回有效子数组的最小数量或`-1`如果不存在。 

## 解决方案```go
package main

import "math"

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func validSubarraySplit(nums []int) int {
    n := len(nums)
    dp := make([]int, n)
    for i := range dp {
        dp[i] = math.MaxInt32
    }

    for i := 0; i < n; i++ {
        for j := 0; j <= i; j++ {
            if gcd(nums[j], nums[i]) > 1 {
                if j == 0 {
                    dp[i] = 1
                } else if dp[j-1] != math.MaxInt32 {
                    if dp[j-1]+1 < dp[i] {
                        dp[i] = dp[j-1] + 1
                    }
                }
            }
        }
    }

    if dp[n-1] == math.MaxInt32 {
        return -1
    }
    return dp[n-1]
}
```Go 实现镜像了 Python 解决方案，重点关注切片初始化和处理`math.MaxInt32`作为无穷大的表示。 这`gcd`函数是迭代实现的。 像空切片这样的边缘情况会被自然地处理，因为`len(nums)`保证至少为 1。
