[LeetCode 问题 2473](https://leetcode.com/problems/minimum-cost-to-buy-apples/)

 **难度：** 🟡 中等
 **主题：** 数组、图论、堆（优先级队列）、最短路径

 ## 解决方案

 ## 问题理解

 该问题要求我们确定从双向道路连接的城市网络中的每个城市出发恰好购买一个苹果的最低成本。 每个城市都有特定的购买苹果成本，每条道路都有一定的旅行成本。 购买苹果后，你必须返回出发城市，但回程时，路费会乘以给定的系数`k`。 

输入由城市数量组成`n`，道路列表，其中每条道路由`[ai, bi, costi]`，一个列表`appleCost`尺寸的`n`代表每个城市一个苹果的成本，以及一个乘数`k`。 输出应该是大小列表`n`其中每个条目代表从该城市开始购买一个苹果的最低总成本。 

约束表明城市数量最多可达 1000 个，道路数量最多可达 2000 个，这意味着检查从每个城市到其他城市的每条路径的简单解决方案会太慢。 没有重复的边，并且所有成本都是正整数，因此我们不必处理零成本循环。 

边缘情况包括在起始城市购买苹果是最佳的场景（例如，当`appleCost[start]`比去其他城市旅行要小）或哪里`k = 1`所以回程费用与去程费用相同。 另一种微妙的情况发生在某些城市被孤立但仍然可以通过多条道路到达时，确保 Dijkstra 算法可以优雅地处理断开的图。 

## 方法

 ### 蛮力

 蛮力方法是计算每个起始城市在每个可能的城市购买苹果的成本。 对于起始城市`i`，我们会枚举所有可能的目的地`j`，计算最短路径`j`，购买苹果，然后计算返回到的最短路径`i`乘以`k`。 所有可能的最小值`j`是起始城市的答案`i`。 这种方法需要运行最短路径算法（如 Dijkstra）`n`每个出发城市和目的地对的时间复杂度为 O(n^3)，这对于约束来说太慢了。 

### 最佳方法

 关键的观察结果是，除了乘数之外，往返城市的成本是对称的`k`回程时。 通过将问题建模为加权图，并使用每个城市的 Dijkstra 算法来计算所有其他城市的最小成本，我们可以有效地计算每个起始城市的总成本。 我们进一步优化，将苹果购买视为额外节点，成本等于`appleCost[j]`。 这使我们能够将每个城市的一次 Dijkstra 通行证中的旅行和购买成本结合起来，从而产生 O(n (m log n)) 复杂度，考虑到约束条件，这是可行的 (`m`是边数）。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 计算从每个城市到其他每个城市的所有路径 |
 | 最佳 | O(n * (m log n)) | O(n * (m log n)) | O(n + m) | 使用每个城市的 Dijkstra 算法找出最低旅行成本 |

 ## 算法演练

 1. **图构建**：使用给定道路为城市构建邻接列表。 每个城市都指向一个元组列表`(neighbor, cost)`。 
2. **迭代城市**：对于每个起始城市`i`，我们将计算购买一个苹果的最低成本。 
3. **Dijkstra初始化**：对于起始城市，初始化一个最小堆优先级队列：`(currentCost, city) = (0, start)`。 
4. **追踪最低成本**：维持`dist`存储从起始城市到每个其他城市的最短距离的数组。 
5. **进程堆**：从堆中弹出成本最小的城市，并针对每个邻居，检查穿过当前城市是否提供更短的距离。 如果是，请更新`dist[neighbor]`并将其推入堆。 
6. **计算总成本**：获得最短路径后，计算在每个城市购买一个苹果的总成本`j`作为`dist[j] + appleCost[j] + k * dist[j]`。 保持所有最小值`j`答案。 
7. **Repeat for All Cities**：对所有城市重复 Dijkstra 遍历`1..n`并存储结果。 

**为什么有效**：Dijkstra 算法保证具有正边权重的图中的最短路径。 将最短路径距离乘以`k`对于回程，我们正确地考虑了不对称成本。 添加`appleCost[j]`确保算法考虑实际的购买成本，并在所有城市中取最小值保证我们找到最优解决方案。 

## Python 解决方案```python
from heapq import heappush, heappop
from typing import List

class Solution:
    def minCost(self, n: int, roads: List[List[int]], appleCost: List[int], k: int) -> List[int]:
        graph = [[] for _ in range(n)]
        for u, v, w in roads:
            graph[u-1].append((v-1, w))
            graph[v-1].append((u-1, w))
        
        answer = [0] * n
        
        for start in range(n):
            dist = [float('inf')] * n
            dist[start] = 0
            heap = [(0, start)]
            
            while heap:
                d, node = heappop(heap)
                if d > dist[node]:
                    continue
                for nei, w in graph[node]:
                    if dist[node] + w < dist[nei]:
                        dist[nei] = dist[node] + w
                        heappush(heap, (dist[nei], nei))
            
            min_cost = float('inf')
            for j in range(n):
                total = dist[j] + appleCost[j] + k * dist[j]
                min_cost = min(min_cost, total)
            answer[start] = min_cost
        
        return answer
```Python 解决方案首先将图构造为邻接表，以实现高效遍历。 Dijkstra 算法计算从起始城市到所有其他城市的最低旅行成本。 计算出最短路径后，计算在每个城市购买苹果的总成本（包括回程成本）并存储最小值。 

## 解决方案```go
package main

import (
	"container/heap"
	"math"
)

type Item struct {
	cost int
	node int
}

type PriorityQueue []Item

func (pq PriorityQueue) Len() int { return len(pq) }
func (pq PriorityQueue) Less(i, j int) bool { return pq[i].cost < pq[j].cost }
func (pq PriorityQueue) Swap(i, j int) { pq[i], pq[j] = pq[j], pq[i] }

func (pq *PriorityQueue) Push(x any) { *pq = append(*pq, x.(Item)) }
func (pq *PriorityQueue) Pop() any {
	old := *pq
	n := len(old)
	item := old[n-1]
	*pq = old[:n-1]
	return item
}

func minCost(n int, roads [][]int, appleCost []int, k int) []int64 {
	graph := make([][][2]int, n)
	for _, r := range roads {
		u, v, w := r[0]-1, r[1]-1, r[2]
		graph[u] = append(graph[u], [2]int{v, w})
		graph[v] = append(graph[v], [2]int{u, w})
	}
	
	answer := make([]int64, n)
	for start := 0; start < n; start++ {
		dist := make([]int, n)
		for i := range dist {
			dist[i] = math.MaxInt32
		}
		dist[start] = 0
		pq := &PriorityQueue{}
		heap.Init(pq)
		heap.Push(pq, Item{0, start})
		
		for pq.Len() > 0 {
			item := heap.Pop(pq).(Item)
			d, node := item.cost, item.node
			if d > dist[node] { continue }
			for _, nei := range graph[node] {
				if dist[node] + nei[1] < dist[nei[0]] {
					dist[nei[0]] = dist[node] + nei[1]
					heap.Push(pq, Item{dist[nei[0]], nei[0]})
				}
			}
		}
		
		minCost := int64(math.MaxInt64)
		for j := 0; j < n; j++ {
			total := int64(dist[j]) + int64(appleCost[j]) + int64(k)*int64(dist[j])
			if total < minCost {
				minCost = total
			}
		}
		answer[start] = minCost
	}
	
	return answer
}
```Go 解决方案镜像了 Python 版本，使用来自`container/heap`实现 Dijkstra 算法。 我们小心翼翼地使用`int64`以避免结果溢出，因为成本和乘数可能很大。
