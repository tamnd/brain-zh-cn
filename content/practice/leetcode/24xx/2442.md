[LeetCode 问题 2442](https://leetcode.com/problems/count-number-of-distinct-integers-after-reverse-operations/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、数学、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们在对每个元素执行特定操作后计算数组中**不同整数**的数量：反转其数字并将其添加到数组中。 换句话说，对于中的每个整数`nums`，我们生成它的反向并附加它。 处理完所有原始元素后，我们计算结果数组中存在多少个唯一数字。 

输入`nums`是正整数数组，输出是表示不同数字的计数的单个整数。 约束告诉我们数组最多可以有$10^5$元素，每个整数可以大到$10^6$。 这意味着任何解决方案迭代`nums`多次或对每个数字执行昂贵的操作可能会变得低效。 边缘情况包括具有重复数字的数组、反转后变得相同的数字（例如，`10`颠倒过来就变成`1`) 和单元素数组。 

## 方法

 一种强力方法是显式创建一个包含所有原始元素及其反转形式的新数组，然后使用集合来查找不同的数字。 这是正确的，因为集合本质上会删除重复项，但它并不是最佳的，因为它会创建额外的数组，增加内存使用量并执行不必要的插入。 

最佳解决方案的关键观察是我们不需要维护完整的数组。 我们只需要跟踪**不同的数字**，这可以使用哈希集有效地完成。 对于每个数字`nums`，我们将数字本身及其反转形式插入到集合中。 这保证了我们关心的所有数字都被跟踪，而无需构建更大的数组。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) 反转 + O(n) 集合 | O(2n) | O(2n) | 使用原始数字和反转数字显式构建更大的数组 |
 | 最佳| O(n log m) | O(n log m) | O(n) | 使用一组来跟踪不同的数字，同时反转数字，其中 m 是最大位数 |

 ## 算法演练

 1. 初始化一个空的哈希集，名为`distinct_numbers`存储独特的值。 
2. 迭代每个数字`num`在输入数组中`nums`。 
3. 对于每个`num`，将其插入到`distinct_numbers`放。 这可确保计算原始数量。 
4. 反转数字`num`。 这可以通过重复提取最后一位数字并构造反转数来完成。 
5. 将反转后的数字插入`distinct_numbers`放。 
6. 处理完所有数字后，得到大小`distinct_numbers`表示最终数组中不同整数的数量。 返回此计数。 

**为什么有效：** 哈希集自动保证唯一性，我们系统地添加原始数字和反转数字。 不会遗漏任何数字，并忽略重复项，确保计数正确。 

## Python 解决方案```python
from typing import List

class Solution:
    def countDistinctIntegers(self, nums: List[int]) -> int:
        distinct_numbers = set()
        
        for num in nums:
            distinct_numbers.add(num)
            
            reversed_num = 0
            temp = num
            while temp > 0:
                reversed_num = reversed_num * 10 + temp % 10
                temp //= 10
            
            distinct_numbers.add(reversed_num)
        
        return len(distinct_numbers)
```Python 解决方案迭代输入数组中的每个数字。 对于每个数字，我们使用整数算术手动计算其反转形式。 原始数字和反转数字都会添加到一个集合中，该集合会自动处理重复项。 最后，我们返回集合中元素的数量。 

## 解决方案```go
func countDistinctIntegers(nums []int) int {
    distinctNumbers := make(map[int]struct{})

    for _, num := range nums {
        distinctNumbers[num] = struct{}{}

        reversedNum := 0
        temp := num
        for temp > 0 {
            reversedNum = reversedNum*10 + temp%10
            temp /= 10
        }

        distinctNumbers[reversedNum] = struct{}{}
    }

    return len(distinctNumbers)
}
```在 Go 中，我们使用具有空结构值的映射来模拟集合。 反转逻辑与 Python 相同，使用整数运算。 我们安全地处理切片，不需要担心 nil 切片，因为迭代空切片可以正常工作。

 | --- | --- | --- |
 | 1 | 1 | {1} |

 | 10 | 10 1 | {1, 10, 13, 31} |

 | 2 | 2 | {2} |
 | 2 | 2 | {2} |
 | 2 | 2 | {2} |

 最终计数 = 1

 ## 复杂度分析

 | 测量| 复杂性 | 说明|

 ## 边缘情况

 一种边缘情况是所有数字都相同，例如，`[2,2,2]`。 该算法可以正确处理重复项，因为该集会自动忽略重复插入。 

另一个边缘情况是以零结尾的数字，例如`10`或者`100`。 当反转时，前导零消失，例如，`10`变成`1`。 该算法通过以数字方式构造反转整数（而不是字符串）来正确处理此问题。 

第三种边缘情况是单元素数组，例如`[1]`。 该集合将正确包含数字及其反转，这与原始数字相同，导致计数为 1。这确保了算法对于最小输入大小而言是稳健的。
