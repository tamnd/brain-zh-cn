[LeetCode 问题 2402](https://leetcode.com/problems/meeting-rooms-iii/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、排序、堆（优先级队列）、模拟

 ## 解决方案

 ## 问题理解

 问题在于将会议安排在固定数量的房间中，其中每个会议都有唯一的开始时间和定义的持续时间。 我们有`n`房间编号从`0`到`n - 1`，我们得到了一个会议列表，表示为`[start, end)`间隔。 任务是根据特定规则将每个会议分配到一个房间：始终使用**编号最小的可用房间**，如果没有空闲房间则延迟会议，并且当多个会议等待时，优先考虑原始开始时间最早的会议。 分配所有会议后，我们需要确定哪个房间主持的会议最多，通过选择数量最少的房间来打破平局。 

输入保证了唯一的开始时间，因此不会有两个会议同时开始。 限制条件适中：最多 100 个房间和最多 100,000 个会议。 这排除了为每次会议扫描所有房间的简单方法，因为 O(n * m) 解决方案可能会达到 1000 万次操作，这是可接受的但效率低下。 重要的边缘情况包括所有房间都很忙且会议延迟的情况，最小的输入（`n = 1`,`meetings`有一个元素），或者当所有房间最终举办相同数量的会议时。 

## 方法

 **强力方法**是通过按时间顺序迭代每个会议、检查所有房间的可用性并将会议分配到第一个空闲房间来模拟时间线。 如果没有空闲房间，您将逐步增加时间，直到有可用房间。 虽然正确，但这种方法效率低下，因为时间线可能会延长至`5 * 10^5`我们可能需要在每个时间步检查每个房间，最坏情况的复杂度为 O(n * maxTime)，这太慢了。 

**最佳方法**使用两个优先级队列（最小堆）。 一个堆通过编号跟踪可用房间，使我们始终能够在 O(log n) 时间内获得编号最小的空闲房间。 另一个堆通过完成时间跟踪已占用的房间，因此我们可以有效地知道哪个房间接下来会空闲。 我们按照会议的开始时间对会议进行排序并按顺序进行处理。 当会议因所有房间都被占用而无法开始时，我们将其延迟到最早的房间释放时间，保留其原始持续时间。 这确保我们有效地管理房间分配和会议延误。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大时间) | O(n) | 在每个时间步检查每个房间； 大的慢`meetings`|
 | 最佳| O(m log n) | O(n) | 使用两个堆；`m`是会议次数，`n`是房间数 |

 ## 算法演练

 1. **对会议进行排序**：按照会议的原始开始时间对会议进行排序，因此我们始终首先处理最早的会议。 
2. **初始化堆**：为按房间号排序的可用房间创建一个最小堆，最初包含从 0 到`n-1`。 为按结束时间排序的已占用房间创建一个最小堆，存储元组`(endTime, roomNumber)`。 
3. **处理每个会议**：按排序顺序迭代每个会议。 
4. **空闲房间**：在分配房间之前，检查占用的堆并释放会议在当前会议开始时间之前或当时结束的所有房间。 将这些房间推回可用堆。 
5. **分配房间**：如果存在可用房间，则弹出编号最小的房间并安排会议。 如果没有空闲房间，则从占用的堆中弹出最早结束的房间，并延迟会议在该结束时间开始，同时保留其持续时间。 
6. **更新计数**：维护一个计数器数组`roomCounts`跟踪每个房间举办的会议数量。 
7. **确定结果**：所有会议安排完毕后，返回人数最多的房间号。 如果出现平局，则最小房间号自然会解决它，因为数组索引对应于房间号。 

**为什么有效**：该算法保持不变，即可用房间始终有序，并且延迟的会议尊重其原始开始时间和持续时间。 使用堆可以确保根据问题规则，房间选择和释放都是高效且正确的。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def mostBooked(self, n: int, meetings: List[List[int]]) -> int:
        # Sort meetings by start time
        meetings.sort()
        
        # Initialize available rooms heap
        available = list(range(n))
        heapq.heapify(available)
        
        # Heap to track ongoing meetings: (end_time, room_number)
        occupied = []
        
        # Count of meetings per room
        room_counts = [0] * n
        
        for start, end in meetings:
            # Free up rooms that have finished before the current meeting starts
            while occupied and occupied[0][0] <= start:
                finish_time, room = heapq.heappop(occupied)
                heapq.heappush(available, room)
            
            if available:
                room = heapq.heappop(available)
                actual_start = start
            else:
                finish_time, room = heapq.heappop(occupied)
                actual_start = finish_time  # delay meeting
            actual_end = actual_start + (end - start)
            heapq.heappush(occupied, (actual_end, room))
            room_counts[room] += 1
        
        # Return the room with the most meetings (ties broken by smallest index)
        return room_counts.index(max(room_counts))
```**说明**：我们首先对会议进行排序，以按时间顺序处理它们。 两个堆可以有效地管理房间可用性和会议结束时间。 对于每次会议，我们都会释放可用的房间，然后分配最早的空闲房间，或者在所有房间都被占用的情况下延迟会议。 计数数组跟踪会议分配以确定最常用的房间。 

## 解决方案```go
package main

import (
    "container/heap"
    "sort"
)

type Room struct {
    endTime int
    index   int
}

type MinHeap []Room

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].endTime < h[j].endTime || (h[i].endTime == h[j].endTime && h[i].index < h[j].index) }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any)        { *h = append(*h, x.(Room)) }
func (h *MinHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

func mostBooked(n int, meetings [][]int) int {
    sort.Slice(meetings, func(i, j int) bool { return meetings[i][0] < meetings[j][0] })

    available := &IntHeap{}
    heap.Init(available)
    for i := 0; i < n; i++ {
        heap.Push(available, i)
    }

    occupied := &MinHeap{}
    heap.Init(occupied)

    counts := make([]int, n)

    for _, m := range meetings {
        start, end := m[0], m[1]

        // Free rooms
        for occupied.Len() > 0 && (*occupied)[0].endTime <= start {
            room := heap.Pop(occupied).(Room)
            heap.Push(available, room.index)
        }

        var room int
        actualStart := start
        if available.Len() > 0 {
            room = heap.Pop(available).(int)
        } else {
            r := heap.Pop(occupied).(Room)
            room = r.index
            actualStart = r.endTime
        }
        actualEnd := actualStart + (end - start)
        heap.Push(occupied, Room{actualEnd, room})
        counts[room]++
    }

    maxCount, ans := 0, 0
    for i, c := range counts {
        if c > maxCount {
            maxCount = c
            ans = i
        }
    }
    return ans
}

// Helper IntHeap for available rooms
type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}
```**Go 特定说明**：Go 要求对可用房间和已占用房间进行显式堆实现。 已占用房间的 MinHeap 跟踪结束时间和房间索引以解决关系。 IntHeap 用于对可用空间进行简单的整数比较。
