[LeetCode 问题 2437](https://leetcode.com/problems/number-of-valid-clock-times/)

 **难度：** 🟢简单
 **主题：** 字符串、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们确定从部分已知的格式的数字时钟字符串可以形成的有效时间数`"hh:mm"`，其中未知数字表示为`'?'`。 每个`'?'`可以替换为任意数字`0`到`9`，但由此产生的小时 (`hh`) 必须在范围内`00`到`23`，以及分钟（`mm`) 必须在范围内`00`到`59`。 

输入始终是长度为 5 的字符串，包括冒号`':'`在索引 2 处。输出是一个整数，表示通过替换所有内容可获得的有效次数总数`'?'`人物。 

约束表明输入始终是格式正确的，因此我们不需要处理格式错误的字符串。 重要的边缘情况包括所有字符都未知的字符串（`"??:??"`），具有单个未知数字且有效替换有限的字符串（`"?5:00"`)，以及小时或分钟的两位数字未知但受最大有效值 (`23`几个小时，`59`分钟）。 

## 方法

 蛮力方法将涉及迭代每个数字的所有可能数字`'?'`并生成所有可能的时间字符串，然后检查每个字符串的有效性。 虽然这会产生正确的结果，但效率低下，尤其是在多个`'?'`字符存在。 例如，`"??:??"`需要检查 10,000 个组合，即使我们知道只有 24 * 60 = 1440 个有效时间。 

最佳解决方案的关键见解是，我们可以根据已知和未知的数字**独立地计算几小时和几分钟**的有效选择数量。 对于小时，第一个数字决定第二个数字的可能范围。 分钟内，范围始终为`00`到`59`，因此每个未知数字都可以独立计数。 将有效小时组合的数量乘以有效分钟组合的数量即可得出有效时​​间的总数。

 ## 算法演练

 1. 将字符串拆分为小时 (`hh`）和分钟（`mm`） 成分。 
2. 计算有效小时可能性的数量：

 - 如果两个小时数字都是`'?'`，有 24 种可能性（00 到 23）。 
- 如果第一个数字是`'?'`但第二个是已知的：

 - 如果第二个数字是`0`到`3`，第一个数字可以是`0`或者`1`或者`2`取决于约束条件。 具体来说，如果第二位数字≤3，则第一位数字可以是`0`,`1`， 或者`2`; 否则仅`0`或者`1`。 
- 如果第二个数字是`'?'`但第一个是已知的：

 - 如果第一个数字是`0`或者`1`，第二位数字可以是`0`到`9`。 
- 如果第一个数字是`2`，第二位数字可以是`0`到`3`。 
- 如果两者都不是`'?'`，只有 1 个有效组合。 
3. 计算有效分钟可能性的数量：

 - 如果两个分钟数字都是`'?'`，有 60 种可能性。 
- 如果第一个分钟数字是`'?'`，有 6 个可能的数字（`0`到`5`）。 
- 如果第二分钟数字是`'?'`，有 10 个可能的数字（`0`到`9`）。 
- 如果两者都是，则增加可能性`'?'`。 
4. 将有效小时可能性的数量与有效分钟可能性的数量相乘以获得最终答案。 

**为什么有效：** 每个`'?'`只能影响自己的位置，小时和分钟的约束是独立的。 通过分别计算每个组件的有效组合并将它们相乘，我们覆盖了所有有效的排列，而无需枚举它们。 

## Python 解决方案```python
class Solution:
    def countTime(self, time: str) -> int:
        hour, minute = time.split(':')
        
        # Calculate possible hours
        if hour == '??':
            hour_options = 24
        elif hour[0] == '?':
            hour_options = 2 if hour[1] > '3' else 3
        elif hour[1] == '?':
            hour_options = 10 if hour[0] in '01' else 4
        else:
            hour_options = 1
        
        # Calculate possible minutes
        if minute == '??':
            minute_options = 60
        elif minute[0] == '?':
            minute_options = 6
        elif minute[1] == '?':
            minute_options = 10
        else:
            minute_options = 1
        
        return hour_options * minute_options
```**实现说明：**我们首先将输入字符串拆分为小时和分钟。 然后，使用基于未知数字的条件逻辑，我们计算有效的小时和分钟组合的数量。 最后，我们将它们相乘以获得总有效时间。 特别注意时间限制，因为时间不能超过 23 小时。 

## 解决方案```go
func countTime(time string) int {
    hour := time[:2]
    minute := time[3:]
    
    var hourOptions int
    if hour == "??" {
        hourOptions = 24
    } else if hour[0] == '?' {
        if hour[1] > '3' {
            hourOptions = 2
        } else {
            hourOptions = 3
        }
    } else if hour[1] == '?' {
        if hour[0] == '0' || hour[0] == '1' {
            hourOptions = 10
        } else {
            hourOptions = 4
        }
    } else {
        hourOptions = 1
    }
    
    var minuteOptions int
    if minute == "??" {
        minuteOptions = 60
    } else if minute[0] == '?' {
        minuteOptions = 6
    } else if minute[1] == '?' {
        minuteOptions = 10
    } else {
        minuteOptions = 1
    }
    
    return hourOptions * minuteOptions
}
```**Go 特定注释：** Go 实现镜像了 Python 逻辑。 由于 Go 将字符串视为字节数组，因此谨慎使用字符串切片和索引。 不需要对 nil 值或溢出进行额外处理，因为所有计算都在整数范围内。 

## 工作示例

 对于`"?5:00"`, 小时有`'?'`第一个位置和第二个数字是`5`。 自从`5 > 3`，第一个数字可以是`0`或者`1`， 所以`hour_options = 2`。 分钟是固定的，所以`minute_options = 1`。 总计 = 2 * 1 = 2。 

对于`"0?:0?"`，小时第一位数字是`0`第二个是`'?'`， 所以`hour_options = 10`。 分钟第一位数字是`0`第二个是`'?'`， 所以`minute_options = 10`。 总计 = 10 * 10 = 100。 

对于`"??:??"`，所有数字未知。 小时选项 = 24，分钟选项 = 60，总计 = 24 * 60 = 1440。
