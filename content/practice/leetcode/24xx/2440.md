 **难度：** 🔴难
 **主题：** 数组、数学、树、深度优先搜索、枚举

 ## 解决方案

 ## 问题理解

 这个问题要求我们采用一个无向树，其中每个节点都有一个数值，并确定我们可以删除多少条边，以便每个结果连接的组件都具有相同的总值。 树由节点值列表表示`nums`和边列表`edges`连接节点。 Deleting an edge splits the tree into two subtrees, and the "value" of a subtree is the sum of the node values in that subtree.

 The input guarantees that the graph is a tree, so it has`n`节点和`n-1`边，并且任意两个节点之间总是存在一条路径。 这很重要，因为这意味着我们在求和时永远不用担心循环，并且每次分割都会产生独立的子树。 

输出是一个整数，表示在确保所有组件具有相同值的同时可以删除的最大边数。 边缘情况包括一棵只有一个节点的树，其中不存在可删除的边，以及一棵所有节点值都相等的树，这可以允许最大分裂。 

约束表明`n`最多可以达到 20,000，因此探索所有可能的边缘删除组合的算法太慢。 节点值很小（`1 <= nums[i] <= 50`），这可以允许对整除性进行数学观察。 

重要的观察结果包括所有节点的值的总和，`total_sum`，必须能被我们想要创建的每个组件的值整除。 如果`total_sum`不能均匀划分，不可能进行有效的划分。 

## 方法

 暴力方法会尝试考虑要删除的每个边子集，计算所得的分量总和，并检查所有总和是否相等。 虽然原则上是正确的，但这种方法是不可行的，因为子集的数量随着`n`。 

最佳方法的关键是所有节点的总和必须能被我们想要创建的组件的数量整除。 如果我们考虑每一个因素`total_sum`作为候选分量值，我们可以尝试从根开始进行 DFS 并跟踪每个子树的总和。 每当子树与候选组件值匹配时，它就会形成一个有效组件，并且我们会为父树重置其总和。 如果所有子树都可以这样划分，则可删除边的数量就是组件数量减一。 

这种方法利用树的属性和简单的算术，避免指数搜索。 DFS 确保每个节点被访问一次，使其与每个候选因子的节点数量成线性关系。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 检查所有边子集是否有效分割； n 达到 20,000 时不可行 |
 | 最佳| O(n * sqrt(S)) | O(n * sqrt(S)) | O(n) | 总和S的每个因子的DFS，每个因子的线性遍历 |

 ## 算法演练

 1. 计算所有节点值的总和，`total_sum = sum(nums)`。 
2. 找出 的所有约数`total_sum`因为每个分量的值必须均分`total_sum`。 
3. 对于每个除数`val`，尝试对树进行分区，使每个组件都有价值`val`。 
4. 实现从任意节点（根为0）开始的DFS。 对于每个节点，递归计算其子树的总和。 
5. 如果子树的和等于`val`，增加有效组件的计数器并向父级返回零（指示该子树被“切断”）。 
6. 如果子树的和超过`val`，这个候选值无效，我们停止这个因子的DFS。 
7. 经过DFS后，如果有效分量的个数等于`total_sum // val`，更新最大可删除边数，即`(number of components - 1)`。 
8. 返回所有有效除数中的最大可删除边。 

**为什么起作用**：该算法确保每个子树总和要么与候选组件值匹配，要么向上传播以进行进一步聚合。 因为图是一棵树，所以每个节点只计算一次，并且 DFS 保证我们可以识别每个有效组件。 除数的使用保证了分量总和均匀地划分总和。 

## Python 解决方案```python
from typing import List
from math import isqrt
from collections import defaultdict

class Solution:
    def componentValue(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        total_sum = sum(nums)
        
        # Build adjacency list
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # Function to find all divisors of total_sum
        def divisors(x):
            divs = set()
            for i in range(1, isqrt(x) + 1):
                if x % i == 0:
                    divs.add(i)
                    divs.add(x // i)
            return divs
        
        max_edges = 0
        
        for val in divisors(total_sum):
            target_components = total_sum // val
            found_components = 0
            
            def dfs(node, parent):
                nonlocal found_components
                subtotal = nums[node]
                for nei in graph[node]:
                    if nei == parent:
                        continue
                    child_sum = dfs(nei, node)
                    subtotal += child_sum
                if subtotal == val:
                    found_components += 1
                    return 0
                return subtotal
            
            if dfs(0, -1) == 0 and found_components == target_components:
                max_edges = max(max_edges, found_components - 1)
        
        return max_edges
```Python代码首先构造一个邻接表，以便于遍历。 它计算总和的除数，并使用 DFS 来验证树是否可以使用该分量值进行分区。 每个与目标值匹配的子树都算作一个组件，可删除边的数量为组件数量减一。 这有效地仅探索可行的组件值。 

## 解决方案```go
package main

func componentValue(nums []int, edges [][]int) int {
    n := len(nums)
    totalSum := 0
    for _, v := range nums {
        totalSum += v
    }

    graph := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }

    divisors := func(x int) []int {
        divs := []int{}
        for i := 1; i*i <= x; i++ {
            if x%i == 0 {
                divs = append(divs, i)
                if i != x/i {
                    divs = append(divs, x/i)
                }
            }
        }
        return divs
    }

    maxEdges := 0

    for _, val := range divisors(totalSum) {
        targetComponents := totalSum / val
        foundComponents := 0

        var dfs func(node, parent int) int
        dfs = func(node, parent int) int {
            subtotal := nums[node]
            for _, nei := range graph[node] {
                if nei == parent {
                    continue
                }
                subtotal += dfs(nei, node)
            }
            if subtotal == val {
                foundComponents++
                return 0
            }
            return subtotal
        }

        if dfs(0, -1) == 0 && foundComponents == targetComponents {
            if foundComponents-1 > maxEdges {
                maxEdges = foundComponents - 1
            }
        }
    }

    return maxEdges
}
```Go 的实现与 Python 非常相似。 切片用于邻接列表，递归处理子树和。 除数是显式计算的，并且要注意避免组件的重复计数。 从 DFS 返回零对应于切割子树。 

## 工作示例

 **示例 1：nums = [6,2,2,2,6]，edges = [[0,1],[1,2],[1,3],[3,4]]**

 总和 = 18。除数：1、2、3、6、9、18。 

候选值 = 6（18/3 = 3 个分量）：

 - 来自节点 0 的 DFS 返回小计 6 -> 找到组件。 
- 在考虑节点 2 和 3 后，以节点 1 为根的 DFS 子树的总和为 6 -> 找到的组件。 
- 仅节点 4 的总和就是 6 -> 找到组件。 

组件数量 = 3，可删除边 = 2。 

**示例 2：nums = [2]，edges = []**

 总和 = 2。除数 = 1,2。 只有一个节点，不能删除边。 结果 = 0。
