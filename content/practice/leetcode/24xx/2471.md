[LeetCode 问题 2471](https://leetcode.com/problems/minimum-number-of-operations-to-sort-a-binary-tree-by-level/)

 **难度：** 🟡 中等
 **主题：** 树、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们确定按严格升序逐级对二叉树的值进行排序所需的**交换操作**数量。 具体来说，在树的每个级别，我们只能交换该级别上存在的节点的值。 该树作为具有唯一整数值​​的标准二叉树给出，目标是计算**所有级别**组合的此类交换的最小数量。 

输入是`root`二叉树的结构，最多可包含 100,000 个节点，每个节点都有一个唯一的整数值。 输出是一个整数，表示所需的最少操作总数。 由于节点值是唯一的，因此我们不需要处理重复项，从而简化了排序和映射操作。 

关键边缘情况包括已经进行级别排序的树（无需操作）、仅具有一个节点的树以及需要复杂交换的多个级别的树。 该问题保证了一棵具有唯一值的有效二叉树，因此我们不必处理超出一个节点最小大小的无效或空输入。 

## 方法

 ### 蛮力

 暴力方法会迭代每个级别，重复交换节点对，直到级别排序。 这可能涉及比较所有节点对并根据需要交换它们的嵌套循环。 虽然正确，但效率非常低：对于具有`n`节点，我们最多可以有`O(n^2)`每级可进行操作，节点总数最多可达10万个。 对于大树来说，这种方法太慢了。 

### 最佳方法

 关键的见解是，通过查找将当前数组映射到其排序版本的排列中的循环数，可以有效地计算**对数组进行排序的最小交换次数**。 具体来说，对于长度的数组`n`，排序所需的交换次数为`sum(len(cycle) - 1)`排列中的所有循环。 

对于我们的问题，最佳解决方案包括以下步骤：

 1. 对树执行层序遍历 (BFS)。 
2. 对于每个级别，将节点值收集到列表中。 
3. 使用循环检测方法确定对该列表进行排序的最小交换次数。 
4. 对所有级别的交换进行求和。 

这种方法将问题简化为排序数组和计算周期，这是有效的并且可以扩展到问题约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N^2) | O(N^2) | O(N) | 反复交换，直到每个级别都排序完毕，对于大级别来说效率低下 |
 | 最佳| O(N log N) | O(N log N) | O(N) | BFS 收集级别 + 每个级别的循环检测，可扩展到 10^5 个节点 |

 ## 算法演练

 1. 初始化一个队列进行BFS遍历，并添加根节点。 
2. 初始化变量`total_swaps`跟踪操作。 
3. 当队列不为空时，处理每一级：

 1.确定本层节点数（`level_size`）。 
2. 收集列表中该级别所有节点的值。 
3. 生成从值到其在列表的排序版本中的索引的映射。 
4. 使用访问数组来跟踪已经属于循环的节点。 
5. 迭代级别列表中的节点：

 1、如果某个节点没有被访问过，则遍历它的循环。 
2. 计算周期长度并相加`cycle_length - 1`到级别交换计数。 
6. 添加关卡交换计数`total_swaps`。 
7. 将这一层节点的所有子节点放入队列中。 
4. 返回`total_swaps`。 

**为什么有效：** 每个级别都是独立处理的，并且通过计算周期来正确计算数组的最小交换次数。 由于级别是独立的并且节点值是唯一的，因此所有级别之间的交换总和给出了正确的最小总操作数。 

## Python 解决方案```python
from collections import deque
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def minimumOperations(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        total_swaps = 0
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            level_vals = []
            
            for _ in range(level_size):
                node = queue.popleft()
                level_vals.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # Compute minimum swaps to sort this level
            sorted_vals = sorted(level_vals)
            index_map = {val: i for i, val in enumerate(level_vals)}
            visited = [False] * level_size
            level_swaps = 0
            
            for i in range(level_size):
                if visited[i] or index_map[sorted_vals[i]] == i:
                    continue
                
                cycle_size = 0
                j = i
                while not visited[j]:
                    visited[j] = True
                    j = index_map[sorted_vals[j]]
                    cycle_size += 1
                level_swaps += cycle_size - 1
            
            total_swaps += level_swaps
        
        return total_swaps
```该实现首先执行 BFS 来遍历级别。 对于每个级别，它都会收集节点值并使用循环检测确定最小交换次数。 这确保了每个级别都以最少的操作进行排序。 

## 解决方案```go
package main

type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func minimumOperations(root *TreeNode) int {
    if root == nil {
        return 0
    }

    totalSwaps := 0
    queue := []*TreeNode{root}

    for len(queue) > 0 {
        levelSize := len(queue)
        levelVals := make([]int, levelSize)
        
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            levelVals[i] = node.Val
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        sortedVals := make([]int, levelSize)
        copy(sortedVals, levelVals)
        sort.Ints(sortedVals)
        
        indexMap := make(map[int]int)
        for i, val := range levelVals {
            indexMap[val] = i
        }

        visited := make([]bool, levelSize)
        levelSwaps := 0

        for i := 0; i < levelSize; i++ {
            if visited[i] || indexMap[sortedVals[i]] == i {
                continue
            }
            cycleSize := 0
            j := i
            for !visited[j] {
                visited[j] = true
                j = indexMap[sortedVals[j]]
                cycleSize++
            }
            levelSwaps += cycleSize - 1
        }

        totalSwaps += levelSwaps
    }

    return totalSwaps
}
```Go 实现密切反映了 Python 逻辑。 主要区别包括处理切片而不是列表以及使用映射而不是字典。 BFS 和周期检测逻辑保持相同。

 ### 复杂性分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N log N) | O(N log N) | BFS 遍历所有节点 O(N)，对于级别大小 k，对每个级别进行排序可以花费 O(k log k)，总节点总和为 N |
 | 空间| O(N) | BFS 的队列在最后一级最多可以存储 O(N) 个节点，再加上用于级别值的数组 |

 BFS 确保我们接触每个节点一次，并且每个级别的循环检测都是线性的。 排序在运行时中占主导地位，总体上为 O(N log N)。
