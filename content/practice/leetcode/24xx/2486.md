[LeetCode 问题 2486](https://leetcode.com/problems/append-characters-to-string-to-make-subsequence/)

 **难度：** 🟡 中等
 **主题：** 两个指针、字符串、贪婪

 ## 解决方案

 ## 问题理解

 该问题要求我们确定需要附加到字符串末尾的最少字符数`s`所以那个字符串`t`成为的子序列`s`。 子序列是按与另一个字符串中相同的顺序出现的序列，但不一定是连续的。 本质上，我们可以延长`s`通过在其末尾添加字符，我们的目标是找到要附加的最小字符数，以便每个字符`t`可以按顺序出现在扩展中`s`。 

输入由两个字符串组成`s`和`t`，都只包含小写英文字母。 输出是一个整数，表示要附加的字符数`s`。 

约束表明两者`s`和`t`可以很大，最多`10^5`字符，这意味着时间复杂度低于 O(n + m) 的任何解决方案（其中`n`和`m`的长度是`s`和`t`）不太可能足够有效。 

重要的边缘情况包括`t`已经是`s`， 什么时候`s`是空的或者很短，并且当`t`包含根本没有出现在`s`。 

## 方法

 暴力方法将尝试生成所有可能的扩展`s`通过附加字符`t`并检查是否`t`成为子序列。 这显然是不可行的，因为组合的数量随着长度的增加而呈指数增长。`t`。 

最佳方法利用了这样一个事实：我们只需要检查有多少个字符`t`已经是一个子序列`s`。 通过使用双指针技术迭代两个字符串，我们可以确定最长的前缀`t`这已经是`s`。 其余字符在`t`此前缀后面正是必须附加的字符。 该解与两个字符串的长度呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m * n) | O(2^m * n) | O(n + m) | 生成所有扩展并检查子序列，不可行 |
 | 最佳| O(n + m) | O(1) | O(1) | 寻找最长子序列前缀的两指针方法 |

 ## 算法演练

 1.初始化两个指针，`i`为了`s`和`j`为了`t`，都从 0 开始。 
2. 迭代`s`使用指针`i`。 对于每个角色`s[i]`,检查是否与当前字符匹配`t[j]`。 
3.如果`s[i] == t[j]`, 增量`j`移动到下一个字符`t`。 这跟踪有多少个字符`t`已作为子序列进行匹配。 
4. 增量`i`在每次迭代中移动`s`。 
5. 迭代之后`s`,`j`将指示字符数`t`已经匹配的`s`。 
6. 追加的最少字符数为剩余长度`t`后`j`， IE。，`len(t) - j`。 

**为什么有效：** 两指针方法确保我们检查每个字符`s`恰好一次，同时保持子序列顺序`t`。 遍历结束时，任何不匹配的部分`t`必须附加到`s`使`t`一个子序列。 

## Python 解决方案```python
class Solution:
    def appendCharacters(self, s: str, t: str) -> int:
        i, j = 0, 0
        while i < len(s) and j < len(t):
            if s[i] == t[j]:
                j += 1
            i += 1
        return len(t) - j
```代码初始化两个指针`i`和`j`遍历`s`和`t`分别。 每当找到匹配的字符时，`j`递增以跟踪匹配字符的数量`t`。 循环结束后，`len(t) - j`给出必须附加的字符数`s`使`t`一个子序列。 

## 解决方案```go
func appendCharacters(s string, t string) int {
    i, j := 0, 0
    for i < len(s) && j < len(t) {
        if s[i] == t[j] {
            j++
        }
        i++
    }
    return len(t) - j
}
```Go 实现镜像了 Python 版本。 指针`i`和`j`遍历`s`和`t`。 循环继续直到任一字符串的末尾，递增`j`每场比赛。 最后，剩余的未匹配部分`t`作为答案返回。

 ## 边缘情况

 1. **空`s`**： 如果`s`为空，解决方案必须追加整个字符串`t`。 两指针方法可以正确处理这个问题，因为循环永远不会递增`j`， 所以`len(t) - j = len(t)`。 
2. **空`t`**： 如果`t`为空，无需附加任何字符。 循环立即退出，并且`len(t) - j = 0`。 
3. **`t`已经是一个子序列`s`**： 如果`t`完全存在于`s`按顺序，算法正确地识别出`j`达到`len(t)`在迭代期间，产生`len(t) - j = 0`，因此不需要附加。 
4. **没有字符`t`在`s`**： 如果`s`不与以下角色共享任何字符`t`,`j`始终保持0，算法正确返回`len(t)`作为要附加的字符数。 这可以防止对部分匹配的错误假设。 

这种方法非常稳健，涵盖了线性时间和恒定空间约束内的所有边缘情况。
