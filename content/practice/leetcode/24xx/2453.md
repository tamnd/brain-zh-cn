[LeetCode 问题 2453](https://leetcode.com/problems/destroy-sequential-targets/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、计数

 ## 解决方案

 ## 问题理解

 该问题提出了一个场景，其中我们有一个正整数列表`nums`代表放置在数轴上的目标。 我们还有一个整数`space`表示机器的步距。 该机器可以从初始种子值开始摧毁所有目标`nums[i]`的步骤`space`。 换句话说，如果我们给机器播种`nums[i]`，它会销毁表格中的所有数字`nums[i] + c * space`在哪里`c`是任意非负整数。 

任务是确定初始种子值`nums[i]`这使我们能够摧毁**最大数量的目标**，并且在平局的情况下，返回最小的此类种子。 该问题受到潜在的大型数组的限制（`nums.length <= 10^5`）和大数（`nums[i] <= 10^9`），这意味着单独检查每个可能的目标序列的简单方法会太慢。 

重要的边缘情况包括所有数字都是唯一或非常大的数组`space`防止任何序列摧毁多个目标的值。 输入保证至少有一个数字，因此不需要空数组处理。 

## 方法

 **暴力方法**将涉及，对于每个元素`nums`，模拟销毁过程并通过检查每个其他数字与起始数字模数的一致性来计算销毁的数字数量`space`。 虽然正确，但这种方法将花费 O(n²) 时间，这对于 n 高达 100,000 的情况是不可接受的。 

**最佳方法**依赖于一个关键观察：在一个序列中被破坏的数字都具有相同的余数模`space`。 因此，我们可以按数字对数字进行分组`num % space`值并计算每组中有多少个数字。 计数最大的组代表可以摧毁最大数量目标的序列。 在这组数字中，我们选择最小的数字作为种子。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 通过检查所有数字来单独模拟每个序列 |
 | 最佳 | O(n) | O(n) | 对数字进行分组`num % space`并从最大的组中选择最小的种子 |

 ## 算法演练

 1. 初始化一个哈希映射（字典）来存储每个余数的计数`nums`除以`space`。 键是余数，值是一个列表，其中包含数字计数以及观察到的该余数的最小数字。 
2. 迭代每个数字`num`在`nums`。 计算余数`r = num % space`。 如果该余数不在映射中，则将其初始化为当前数字作为最小值并计数 1。如果存在，则增加计数并在当前数字小于存储的最小值时更新最小值。 
3. 处理完所有数字后，迭代哈希图以找到计数最大的余数。 如果出现平局，则选择存储的最小数最小的余数。 
4. 返回与该余数相对应的最小数。 

**为什么有效**：同一个模组中的所有数字都可以从该组中的任何数字开始被销毁，因为添加多个`space`保留该组中的数字。 通过跟踪计数和最小值，我们有效地找到最佳的起始种子。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def destroyTargets(self, nums: List[int], space: int) -> int:
        remainder_map = defaultdict(lambda: [0, float('inf')])
        
        for num in nums:
            r = num % space
            remainder_map[r][0] += 1
            remainder_map[r][1] = min(remainder_map[r][1], num)
        
        max_count = 0
        result = float('inf')
        
        for count, minimum in remainder_map.values():
            if count > max_count or (count == max_count and minimum < result):
                max_count = count
                result = minimum
        
        return result
```**解释**：我们使用`defaultdict`储存`[count, minimum]`对于每个余数。 当我们处理每个数字时，我们会有效地更新计数和最小数字。 最后，我们选择具有最大计数的组并返回最小种子。 

## 解决方案```go
func destroyTargets(nums []int, space int) int {
    type Pair struct {
        count int
        minNum int
    }
    
    remainderMap := make(map[int]Pair)
    
    for _, num := range nums {
        r := num % space
        if p, exists := remainderMap[r]; exists {
            p.count++
            if num < p.minNum {
                p.minNum = num
            }
            remainderMap[r] = p
        } else {
            remainderMap[r] = Pair{1, num}
        }
    }
    
    maxCount := 0
    result := int(1e9 + 1)
    
    for _, p := range remainderMap {
        if p.count > maxCount || (p.count == maxCount && p.minNum < result) {
            maxCount = p.count
            result = p.minNum
        }
    }
    
    return result
}
```**Go 特定注释**：我们定义一个结构体`Pair`保存计数和最小数量，因为 Go 没有元组类型。 我们通过重新分配结构来更新映射，因为映射值是在访问时复制的。 

## 工作示例

 **示例 1：nums = [3,7,8,1,1,5]，空格 = 2**

 | 编号 | 余数 (num % 2) | 步骤后的剩余图 |
 | --- | --- | --- |
 | 3 | 1 | {1: [1,3]} |
 | 7 | 1 | {1: [2,3]} |
 | 8 | 0 | {1: [2,3], 0: [1,8]} |
 | 1 | 1 | {1: [3,1], 0: [1,8]} |
 | 1 | 1 | {1: [4,1], 0: [1,8]} |
 | 5 | 1 | {1: [5,1], 0: [1,8]} |

 余数 1 的最大计数为 5。该组中的最小数字为 1，因此输出为 1。 

**示例 2：nums = [1,3,5,2,4,6]，空格 = 2**

 余数：

 | 余数 0 | 剩余 1 |
 | --- | --- |
 | 2,4,6 | 1,3,5 |

 两组的计数均为 3。最小数量分别为 2 和 1。 返回 1。 

**示例 3：nums = [6,2,5]，空格 = 100**

 余数：6 % 100 = 6、2 % 100 = 2、5 % 100 = 5

 所有计数均为 1。最小数量为 2，因此返回 2。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单次通过`nums`to populate the map, then linear pass over map values |
 | 空间| O(n) | Storing counts and minima for up to n distinct remainders |

 Because the number of distinct remainders is at most`space`但有界于`n`，最坏情况下空间为 O(n)。
