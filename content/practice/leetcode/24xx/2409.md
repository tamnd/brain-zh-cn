[LeetCode 问题 2409](https://leetcode.com/problems/count-days-spent-together/)

 **难度：** 🟢简单
 **主题：** 数学、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们根据爱丽丝和鲍勃各自的到达和离开日期计算他们在罗马一起度过的天数。 每个日期都表示为以下格式的字符串`"MM-DD"`。 输入由四个字符串组成：`arriveAlice`,`leaveAlice`,`arriveBob`， 和`leaveBob`。 输出应该是 Alice 和 Bob 在罗马的重叠天数的总数。 

简单来说，问题是找到单个非闰年内两个日期范围的交集。 如果范围重叠，我们计算重叠天数； 如果它们不重叠，则结果为零。 

约束确保所有日期都有效，发生在同一年，并且 Alice 和 Bob 的到达日期始终早于或等于他们的离开日期。 这保证了我们不需要处理无效范围或闰年。 重要的边缘情况包括访问不重叠、恰好在某一天接触或一次访问完全包含在另一次访问中的情况。 

## 方法

 暴力方法涉及将每个日期范围转换为每个人在场的一年中所有天数的列表，然后计算常见天数。 虽然这种方法有效，但没有必要，因为我们不需要明确地迭代每一天。 

最佳方法利用了这样一个事实：两个间隔之间的重叠可以使用最大开始日期和最小结束日期来确定。 如果计算的开始日期晚于结束日期，则不存在重叠。 否则，在一起的天数只是结束日期和开始日期之间的差值加一（因为两个端点都包含在内）。 为了简化计算，我们使用每月天数的累积总和将日期转换为一年中的日期整数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N) | O(N) | 生成两个范围内的所有日期并计算交叉点 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 将日期转换为一年中的某一天并以数学方式计算重叠 |

 ## 算法演练

 1.定义一个数组`days_in_month`表示非闰年每个月的天数。 这将是`[31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]`。 
2. 创建辅助函数`day_of_year(date: str)`转换一个`"MM-DD"`字符串到一年中相应的一天。 将字符串拆分为月和日，将所有先前月份的天数相加，然后添加当月的天数。 
3. 使用辅助函数将所有四个输入日期转换为年份整数。 
4. 通过取两个开始日期中的最大值和两个结束日期中的最小值来确定重叠范围。 
5. 如果重叠开始晚于重叠结束，则返回 0，因为不存在重叠。 
6.否则返回`overlap_end - overlap_start + 1`计算所有包含的重叠天数。 

为什么有效：通过将日期转换为一年中的某天整数，我们可以将问题简化为查找两个数值范围的交集。 不变量是任何重叠范围的起点小于或等于终点。 这样就保证了正确性。 

## Python 解决方案```python
class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:
        days_in_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        def day_of_year(date: str) -> int:
            month, day = map(int, date.split('-'))
            return sum(days_in_month[:month-1]) + day
        
        start_alice = day_of_year(arriveAlice)
        end_alice = day_of_year(leaveAlice)
        start_bob = day_of_year(arriveBob)
        end_bob = day_of_year(leaveBob)
        
        overlap_start = max(start_alice, start_bob)
        overlap_end = min(end_alice, end_bob)
        
        return max(0, overlap_end - overlap_start + 1)
```Python 代码首先将每个日期转换为其年份表示形式。 然后，它计算 Alice 和 Bob 停留之间的重叠范围。 这`max(0, ...)`确保如果没有重叠，我们正确地返回零。 

## 解决方案```go
func countDaysTogether(arriveAlice string, leaveAlice string, arriveBob string, leaveBob string) int {
    daysInMonth := []int{31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}

    dayOfYear := func(date string) int {
        var month, day int
        fmt.Sscanf(date, "%02d-%02d", &month, &day)
        dayOfYear := day
        for i := 0; i < month-1; i++ {
            dayOfYear += daysInMonth[i]
        }
        return dayOfYear
    }

    startAlice := dayOfYear(arriveAlice)
    endAlice := dayOfYear(leaveAlice)
    startBob := dayOfYear(arriveBob)
    endBob := dayOfYear(leaveBob)

    overlapStart := max(startAlice, startBob)
    overlapEnd := min(endAlice, endBob)

    if overlapStart > overlapEnd {
        return 0
    }
    return overlapEnd - overlapStart + 1
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```在围棋中，`dayOfYear`功能用途`fmt.Sscanf`解析日期字符串和辅助函数`max`和`min`计算重叠范围。 其逻辑与 Python 非常相似。 

## 工作示例

 **示例1：**`arriveAlice = "08-15"`,`leaveAlice = "08-18"`,`arriveBob = "08-16"`,`leaveBob = "08-19"`逐步：

 1. 将日期转换为年份：Alice`[227, 230]`, 鲍勃`[228, 232]`。 
2. 重叠开始 = max(227, 228) = 228，重叠结束 = min(230, 232) = 230。 
3. 在一起的天数 = 230 - 228 + 1 = 3。 

**示例2：**`arriveAlice = "10-01"`,`leaveAlice = "10-31"`,`arriveBob = "11-01"`,`leaveBob = "12-31"`1. 转换日期：Alice`[274, 304]`, 鲍勃`[305, 365]`。 
2. 重叠开始 = max(274, 305) = 305，重叠结束 = min(304, 365) = 304。 
3. 重叠开始>重叠结束，返回0。

 ## 边缘情况

 第一个重要的边缘情况是 Alice 和 Bob 的住宿时间恰好重叠一天。 这测试了范围的包容性，并确保算法正确计算单个重叠日。 第二种情况是根本没有重叠的情况； 这确保了`max(0, ...)`逻辑工作正常。 第三种边缘情况是当一个范围完全在另一个范围内时，这确保算法可以正确处理嵌套间隔并计算重叠天数的准确数量而不会遗漏任何天数。 全部
