[LeetCode 问题 2433](https://leetcode.com/problems/find-the-original-array-of-prefix-xor/)

 **难度：** 🟡 中等
 **主题：** 数组、位操作

 ## 解决方案

 ## 问题理解

 问题是要求我们对数组进行逆向工程`arr`来自其前缀 XOR 数组`pref`。 具体来说，`pref[i]`表示中所有元素的异或`arr`来自索引`0`到`i`。 我们的目标是重建`arr`仅给出`pref`。 

例如，如果`pref = [5,2,0,3,1]`，这意味着：

 -`pref[0] = arr[0]`-`pref[1] = arr[0] ^ arr[1]`-`pref[2] = arr[0] ^ arr[1] ^ arr[2]`-`pref[3] = arr[0] ^ arr[1] ^ arr[2] ^ arr[3]`-`pref[4] = arr[0] ^ arr[1] ^ arr[2] ^ arr[3] ^ arr[4]`预期输出是数组`arr`满足这些方程。 

限制因素`1 <= pref.length <= 10^5`和`0 <= pref[i] <= 10^6`告诉我们，解决方案必须在时间和空间上呈线性才能有效地处理大型数组。 重要的边缘情况包括单元素数组和元素异或为零的数组。 

该问题保证了答案是唯一的，因此我们不需要考虑多个有效的解决方案。 

## 方法

 ### 蛮力方法

 一种天真的暴力方法会尝试所有可能的序列`arr`产生给定的`pref`通过使用回溯。 在每一步中，您都会尝试选择一个数字，当与迄今为止的累积异或运算时，该数字等于下一个数字`pref[i]`。 虽然这最终会找到解决方案，但它的效率极低且不可行。`n`最多`10^5`，因为它探索指数搜索空间。 

### 最佳方法

 最佳解决方案的关键观察来自 XOR 的属性。 如果`pref[i] = arr[0] ^ arr[1] ^ ... ^ arr[i]`， 然后：

-`arr[0] = pref[0]`-`arr[1] = pref[0] ^ pref[1]`-`arr[2] = pref[1] ^ pref[2]`-`arr[i] = pref[i-1] ^ pref[i]`为了`i >= 1`这是可行的，因为 XOR 是它自己的逆：如果`x ^ y = z`， 然后`y = x ^ z`。 所以，我们可以重构`arr`通过异或连续元素的单次传递`pref`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试所有可能的序列，对于大 n | 不可行
 | 最佳| O(n) | O(n) | 使用XOR属性直接重构arr |

 ## 算法演练

 1.初始化一个空数组`arr`与相同长度`pref`。 
2. 设置第一个元素`arr`成为`pref[0]`因为`arr[0]`总是等于`pref[0]`。 
3. 迭代自`i = 1`到`n-1`:

 - 计算`arr[i]`作为`pref[i] ^ pref[i-1]`。 这有效是因为`arr[0] ^ ... ^ arr[i] ^ arr[0] ^ ... ^ arr[i-1] = arr[i]`。 
4.返回重建的`arr`。 

**为什么有效：** XOR 是可逆且关联的。 通过对连续的前缀异或进行异或，我们取消了所有先前的元素，只留下当前元素。 这确保了每个`arr[i]`计算正确。 

## Python 解决方案```python
from typing import List

class Solution:
    def findArray(self, pref: List[int]) -> List[int]:
        n = len(pref)
        arr = [0] * n
        arr[0] = pref[0]
        for i in range(1, n):
            arr[i] = pref[i] ^ pref[i - 1]
        return arr
```**实现演练：**我们首先分配`arr`并直接分配其第一个元素`pref[0]`。 然后我们循环遍历剩余的索引并对每个连续的索引进行异或`pref`对来确定中的下一个元素`arr`。 这直接实现了算法演练中描述的 XOR 属性。 

## 解决方案```go
func findArray(pref []int) []int {
    n := len(pref)
    arr := make([]int, n)
    arr[0] = pref[0]
    for i := 1; i < n; i++ {
        arr[i] = pref[i] ^ pref[i-1]
    }
    return arr
}
```**Go 实现说明：** Go 版本镜像了 Python 逻辑。 我们使用`make`初始化切片。 Go 处理整数时无需特别注意溢出，因为约束保证值适合 32 位整数。 循环逻辑与Python 相同。

 ## 边缘情况

 1. **单元素数组：** 最简单的情况`pref`长度为 1。这验证了代码处理最少的输入而没有索引错误。 该实现通过直接分配来处理这个问题`arr[0] = pref[0]`。 
2. **所有元素为零：** A`pref`全零数组可确保 XOR 计算不会引入意外的非零值。 自从`0 ^ 0 = 0`，该算法正确地重建了一个零数组。 
3. **具有最大约束的大数组：** A`pref`数组与`10^5`elements 测试性能和正确性。 使用线性 O(n) 算法可确保程序高效执行而不会超出内存限制。 该算法不依赖递归或回溯，避免了堆栈溢出。
