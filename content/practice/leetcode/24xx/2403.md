[LeetCode 问题 2403](https://leetcode.com/problems/minimum-time-to-kill-all-monsters/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、位操作、位掩码

 ## 解决方案

 ## 问题理解

 问题是要求我们计算击败数组中所有怪物所需的最少天数`power`， 在哪里`power[i]`代表着实力`i-th`怪物。 你从零法力开始，每天获得法力，初始日增益为`1`。 击败怪物后，你的法力值会重置为零，并且每日增益会增加`1`。 挑战在于安排要击败的怪物，以尽量减少总天数。 

输入是一个整数数组，长度最大为 17，值最大为 10^9。 这个小数组长度表明探索怪物子集或使用位掩码的解决方案是可行的，尽管个体值很大。 输出是一个整数，表示所需的最小天数。 

重要的边缘情况包括早期拥有非常高力量的怪物、具有相同力量的多个怪物以及只有一个怪物的阵列。 该问题保证至少有一个怪物，因此我们不需要处理空输入。 

## 方法

 ### 蛮力

 一种幼稚的方法是尝试击败怪物的命令的所有排列。 对于每个订单，我们模拟每一天，积累法力并检查是否足以击败当前的怪物。 虽然这种方法保证了正确性，但排列的数量是`n!`，这对于`n`最多 17 个。 

### 最佳方法

 关键的见解是该问题可以简化为**位掩码动态编程**问题。 每个怪物子集都可以用位掩码表示，我们可以计算击败该子集中所有怪物的最短天数。 

让`dp[mask]`是击败下列怪物所需的最短天数`mask`。 对于每个状态，我们迭代蒙版中尚未击败的怪物，模拟使用当前增益击败该怪物所需的天数，并更新新蒙版的 dp 状态。 自从`n <= 17`, 最多有`2^17 ≈ 131072`子集，这是可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 尝试怪物的所有排列； 对于 n=17 来说太慢 |
 | 最佳| O(n * 2^n) | O(n * 2^n) | O(2^n) | O(2^n) | 位掩码 DP； 有效地迭代怪物的所有子集 |

 ## 算法演练

 1.初始化一个DP数组`dp`尺寸的`2^n`无穷大，除了`dp[0] = 0`代表零个怪物被击败。 
2. 迭代所有掩码`0`到`(1 << n) - 1`。 对于每个面具：

 1. 统计已经击败的怪物数量，从而确定当前的怪物数量`gain`。 
2.对于每个怪物`i`不在面具中：

 1.计算积累足够的法力来击败怪物所需的天数`i`与电流增益使用`ceil(power[i] / gain)`。 
2. 更新`dp[new_mask]`作为其当前值的最小值和`dp[mask] + days_needed`。 
3. 返回`dp[(1 << n) - 1]`其中包含击败所有怪物的最短天数。 

**为什么有效：** DP 不变量确保对于被击败的怪物的每个子集，`dp[mask]`存储所需的最少天数。 通过迭代所有可能的状态并始终取最小值，我们保证了全局最优。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def minimumTime(self, power: List[int]) -> int:
        n = len(power)
        dp = [math.inf] * (1 << n)
        dp[0] = 0

        for mask in range(1 << n):
            defeated = bin(mask).count("1")
            gain = defeated + 1
            for i in range(n):
                if not (mask & (1 << i)):
                    days_needed = (power[i] + gain - 1) // gain  # ceil division
                    new_mask = mask | (1 << i)
                    dp[new_mask] = min(dp[new_mask], dp[mask] + days_needed)

        return dp[(1 << n) - 1]
```**说明：** 我们使用位掩码来表示被击败的怪物。 对于每个状态，我们确定当前的每日增益，计算击败任何剩余怪物所需的天数，并更新新面具的 DP。 最终的答案存储在代表所有击败的怪物的DP值中。 

## 解决方案```go
package main

import "math"

func minimumTime(power []int) int64 {
    n := len(power)
    size := 1 << n
    dp := make([]int64, size)
    for i := 1; i < size; i++ {
        dp[i] = math.MaxInt64
    }

    for mask := 0; mask < size; mask++ {
        defeated := 0
        for j := 0; j < n; j++ {
            if mask&(1<<j) != 0 {
                defeated++
            }
        }
        gain := int64(defeated + 1)
        for i := 0; i < n; i++ {
            if mask&(1<<i) == 0 {
                daysNeeded := (int64(power[i]) + gain - 1) / gain
                newMask := mask | (1 << i)
                if dp[mask]+daysNeeded < dp[newMask] {
                    dp[newMask] = dp[mask] + daysNeeded
                }
            }
        }
    }
    return dp[size-1]
}
```**Go注意事项：** Go没有内置`ceil`对于整数，所以我们使用`(a + b - 1) / b`用于天花板划分。 我们还使用`int64`以防止大幂值的整数溢出。

 ## 边缘情况

 1. **单个怪物**：有`power = [x]`，最短天数就是`ceil(x / 1)`。 This checks if the algorithm handles the smallest input correctly. The DP handles this because the only mask update occurs from`0`到`1`。 
2. **最大功率**：如果`power[i]`非常大（最多10^9），我们需要确保整数运算不会溢出。 在Python中，整数是任意精度的，而在Go中我们使用`int64`安全地处理大量数据。 
3. **所有怪物力量相同**：当所有怪物力量相同时，击败它们的顺序可能并不重要，但DP可以确保我们随着增益的增加而准确地计算天数。 此案例测试 DP 在每次失败后是否正确积累增益。
