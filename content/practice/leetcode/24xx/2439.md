[LeetCode 问题 2439](https://leetcode.com/problems/minimize-maximum-of-array/)

 **难度：** 🟡 中等
 **主题：** 数组、二分搜索、动态规划、贪心、前缀和

 ## 解决方案

 ## 问题理解

 问题给出了一个 0 索引的数组`nums`非负整数并允许特定操作：选择一个索引`i`（在哪里`1 <= i < n`）这样`nums[i] > 0`，然后减少`nums[i]`加 1 并增加`nums[i - 1]`1. 任务是执行此操作任意多次，以便**最小化数组中的最大值**。 

实际上，该操作允许在数组中向左移动“值”，这意味着可以向后扩展数组中稍后的较高值以减少峰值。 输入约束表明`n`最大可以是 100,000，值最大可以是 10^9，这排除了任何模拟每个可能操作的强力方法，因为它太慢了。 

关键的挑战是在任意多次操作后确定**最小可能的最大值**，而无需显式模拟每个操作。 重要的边缘情况包括已经不递增的数组、末尾具有非常大值的数组或所有元素都相等的数组。 

## 方法

 ### 蛮力

 蛮力方法会通过从右向左扫描、从左向右移动 1 来重复模拟允许的操作。`nums[i]`到`nums[i-1]`只要有可能，直到不可能进一步减少最大值为止。 这种方法原则上是正确的，因为它精确地模拟了问题，但速度太慢。 对于大小为 10^5 且值高达 10^9 的数组，这可能需要数十亿次操作。 

### 最佳洞察力

 关键的观察结果是，该操作本质上允许我们**平衡前缀和**。 任何操作序列之后的最大值受到前缀和的平均值的限制。 具体来说，对于第一个`i`元素中，最大值不能小于第一个元素之和的上限`i`元素除以`i + 1`。 这是因为第一个的总和`i+1`无法重新分配元素以使所有元素都小于平均值。 

因此，解决方案是计算整个数组中这些前缀平均值的最大值。 这种方法完全避免了模拟操作，并且可以在线性时间内计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大(nums)) | O(1) | O(1) | 模拟每一个有效操作； 对于大输入来说太慢|
 | 最佳| O(n) | O(1) | O(1) | 使用前缀和和上限除法来确定最小最大值 |

 ## 算法演练

 1. 初始化`prefix_sum`到 0 和`result`至 0。`prefix_sum`将累加从索引 0 到当前索引的元素之和。`result`将跟踪迄今为止看到的最大前缀平均值。 
2. 迭代每个元素`nums[i]`在数组中。 
3. 添加`nums[i]`到`prefix_sum`。 
4. 计算当前前缀的最小可能最大值：`ceil(prefix_sum / (i + 1))`。 在整数运算中，这是`(prefix_sum + i) // (i + 1)`。 
5. 更新`result`为当前的最大值`result`和这个值。 
6. 处理完所有元素后，`result`将保存整个数组的最小可能最大值。 

**为什么有效：** 任何向左移动的数字都有助于降低未来的峰值，但前缀总和确保在不违反总和的情况下，任何前缀都不会降低到其平均值以下。 通过取最大前缀平均值，我们保证所有元素都可以重新分配以不超过该值。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimizeArrayValue(self, nums: List[int]) -> int:
        prefix_sum = 0
        result = 0
        for i, num in enumerate(nums):
            prefix_sum += num
            result = max(result, (prefix_sum + i) // (i + 1))
        return result
```在此实现中，我们迭代每个数字，更新前缀和并使用整数除法计算前缀平均值的上限。 决赛`result`是可达到的最小最大值。 

## 解决方案```go
func minimizeArrayValue(nums []int) int {
    prefixSum := 0
    result := 0
    for i, num := range nums {
        prefixSum += num
        avg := (prefixSum + i) / (i + 1)
        if avg > result {
            result = avg
        }
    }
    return result
}
```在 Go 中，我们使用类似的整数运算。 唯一的区别是显式变量类型。 不需要对大数进行特殊处理，因为 Go`int`可以处理总计`10^14`安全地解决这个问题。

 ## 边缘情况

 1. **全零**：数组如`[0,0,0]`如果代码假设存在正数，则可能会被错误处理。 该解决方案可以正确处理此问题，因为前缀和保持为零且结果为零。 
2. **末尾的大值**：像这样的数组`[0,1000000000]`测试整数溢出和重新分配的正确处理。 该算法计算前缀平均值的上限并安全地返回大数而不会溢出。 
3. **递增序列**：数组如`[1,2,3,4,5]`需要向左移动值以最小化最大值。 幼稚的方法可能会错误地假设只有最后一个值很重要。 前缀总和方法确保通过考虑所有前缀的平均值来计算正确的最小最大值。
