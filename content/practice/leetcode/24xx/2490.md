[LeetCode 第 2490 题](https://leetcode.com/problems/circular-sentence/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的句子是否是**循环**。 句子被定义为由单个空格分隔的单词字符串，没有前导或尾随空格。 单词仅包含大写和小写英文字母。 循环性的关键条件是每个单词的最后一个字符必须与下一个单词的第一个字符匹配，此外，最后一个单词的最后一个字符必须与第一个单词的第一个字符匹配。 

输入是一个字符串`sentence`长度在 1 到 500 之间，输出是布尔值：`true`如果句子是循环语句，`false`否则。 这些约束确保没有空词或多余空格，因此我们不需要处理修剪或多个空格。 

重要的边缘情况包括具有单个单词的句子，其中第一个和最后一个字符必须相同，以及单词的第一个或最后一个字母不同的句子，从而破坏了循环属性。 

## 方法

 暴力方法很简单：将句子分割成单词，对于每个相邻的单词对，检查第一个单词的最后一个字符是否等于下一个单词的第一个字符。 最后，检查最后一个单词的最后一个字符是否与第一个单词的第一个字符匹配。 这种方法工作正常，但需要迭代每个单词和字符，这对于给定的约束来说足够简单，但可以稍微优化。 

最佳方法使用相同的想法，但通过直接访问每个单词的第一个和最后一个字符而不构建额外的结构来避免不必要的复杂性。 由于单词是用空格分隔的，Python 的`split()`方法就足够了，我们可以用一个简单的迭代`for`循环和直接字符串索引。 此方法非常高效，因为单词数受字符串长度限制，并且每次比较的时间复杂度为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 拆分句子并比较相邻单词； 有效，但会为单词列表使用额外的空间 |
 | 最佳 | O(n) | O(1) | O(1) | 迭代时直接比较第一个和最后一个字符； 最小的开销|

 ## 算法演练

 1. 使用空格字符将句子拆分为单词。 这给出了按顺序排列的单词列表。 
2. 从第一个单词到倒数第二个单词迭代列表。 
3. 对于索引处的每个单词`i`，将其最后一个字符与索引处下一个单词的第一个字符进行比较`i+1`。 
4. 如果有任何一对不匹配，立即返回`false`因为这句话不是循环的。 
5. 完成迭代后，将最后一个单词的最后一个字符与第一个单词的第一个字符进行比较。 
6. 如果最终比较失败，则返回`false`。 
7. 如果所有检查都通过，则返回`true`，表明该句子是循环语句。 

**为什么有效：** 通过迭代所有相邻对并确保第一个到最后一个字符属性成立，并检查从最后一个单词到第一个单词的环绕，我们确保每个连续单词转换满足循环性的不变性。 这样就保证了正确性。 

## Python 解决方案```python
class Solution:
    def isCircularSentence(self, sentence: str) -> bool:
        words = sentence.split()
        for i in range(len(words) - 1):
            if words[i][-1] != words[i + 1][0]:
                return False
        return words[-1][-1] == words[0][0]
```Python 解决方案首先将句子拆分为单词列表。 然后它遍历列表，将当前单词的最后一个字符与下一个单词的第一个字符进行比较。 如果任何比较失败，则返回`False`立即地。 检查完所有对后，它验证最后一个单词和第一个单词之间的循环条件，返回`True`如果它通过了。 

## 解决方案```go
func isCircularSentence(sentence string) bool {
    words := strings.Fields(sentence)
    for i := 0; i < len(words)-1; i++ {
        if words[i][len(words[i])-1] != words[i+1][0] {
            return false
        }
    }
    lastWord := words[len(words)-1]
    firstWord := words[0]
    return lastWord[len(lastWord)-1] == firstWord[0]
}
```在 Go 中，句子被分成单词`strings.Fields`，它处理单空格分隔。 我们迭代每个相邻的单词，使用索引比较最后一个和第一个字符。 环绕检查的执行方式类似，确保循环条件成立。 与 Python 不同，Go 使用从零开始的索引`len()`对于字符串长度，但逻辑保持不变。

 ## 边缘情况

 一个重要的边缘情况是**单字句子**，其中循环性仅取决于第一个和最后一个字符是否相同。 这是通过解决方案中的最终比较来处理的。 

第二个边缘情况是**区分大小写**，其中`'A'`和`'a'`被认为是不同的。 该解决方案通过使用直接字符比较正确地尊重了这一点。 

第三个边缘情况是**双词句子**。 幼稚的实现可能会忘记检查环绕条件，但此解决方案通过循环和最终比较自然地处理它。
