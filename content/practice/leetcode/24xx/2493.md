[LeetCode 问题 2493](https://leetcode.com/problems/divide-nodes-into-the-maximum-number-of-groups/)

 **难度：** 🔴难
 **主题：** 深度优先搜索、广度优先搜索、并查找、图论

 ## 解决方案

 ## 问题理解

 我们得到一个无向图`n`节点和边列表。 该图可能包含多个断开连接的组件。 我们的任务是将所有节点分为有序组，编号为`1`到`m`。 

关键约束基于图的边。 如果两个节点通过边连接，并且一个节点属于组`x`，那么另一个节点一定属于组`x - 1`或者`x + 1`。 换句话说，每条边必须连接组索引恰好相差 1 的节点。 

目标不仅仅是找到任何有效的分组，而是最大化组的总数。 

这个条件非常重要，因为它有效地迫使相邻节点出现在连续的层中。 这立即类似于广度优先搜索分层结构。 

该图还可以断开连接，这意味着每个连接的组件都可以独立处理。 最终答案是每个连接组件的最大有效组计数的总和。 

限制相对较小：

 -`n <= 500`-`edges.length <= 10^4`这允许我们在必要时从每个节点运行 BFS，因为`500 * (500 + 10^4)`仍然是可以管理的。 

有几个重要的边缘情况：

 - 包含奇数环的图不可能正确分组。 奇数循环不是二分的，无法满足所需的分层条件。 
- 断开连接的图需要独立处理每个组件。 
- 单个孤立节点恰好贡献一组。 
- 同一组件内的多个 BFS 起点可能会产生不同数量的层，因此我们必须找到最大可能值。 

## 方法

 ### 蛮力方法

 一个天真的想法是尝试将所有可能的节点分配到组中并验证每条边是否满足条件`|x - y| = 1`。 

这种方法在理论上是正确的，因为它探索每个有效的分组配置并选择最大组数。 然而，可能的分配数量随着节点数量呈指数增长。 即使对于中等大小的图形，这也变得完全不可行。 

另一种强力变体将尝试将每个节点作为可能的起始层，并在检查一致性的同时将相邻节点递归地分配给相邻层。 虽然稍微好一些，但在密集图中仍然会出现组合爆炸。 

核心困难在于相邻节点之间的约束创建了一个巨大的全局依赖结构。 

### 关键见解

 关键的观察结果是，所需的分组结构相当于二分图中的 BFS 级别。 

假设我们选择一个起始节点并将其分配给组`1`。 那么所有邻居都必须属于组`2`。 他们的邻居必须属于组`1`或者`3`， 等等。 

这正是 BFS 距离的表现方式。 

对于任何有效的分组：

 - 相邻节点必须恰好相差一级。 
- 因此，节点不能不一致地共享相同的奇偶校验周期。 
- 该图必须是二分图。 

如果连通分量不是二分的，则答案是立即`-1`。 

对于二分组件，最大组数等于该组件中某个节点可实现的最大 BFS 层数。 这对应于最大最短路径深度加一。 

自从`n <= 500`，我们可以从每个节点安全地运行 BFS。

 ## 算法演练

 1. 为图构建邻接表。 

由于图是无向且足够稀疏的，因此邻接表是最有效的表示形式。 每个节点存储其所有邻居。 
2. 识别连接的组件。 

该图可能是断开连接的，因此我们独立处理每个组件。 我们可以使用BFS或DFS来收集属于同一组件的所有节点。 
3. 检查每个组件是否是二分的。 

在遍历过程中，为相邻节点分配交替颜色。 如果我们找到一条连接两个颜色相同的节点的边，则该图包含一个奇数环，答案是`-1`。 

这是有效的，因为所需的分组条件本质上需要二分结构。 
4. 对于组件中的每个节点，运行 BFS。 

我们计算从起始节点到所有其他可到达节点的最短距离。 

在 BFS 期间：

 - 存储每个节点的距离。 
- 对于每一个边缘`(u, v)`，验证`|dist[u] - dist[v]| == 1`。 

如果此条件失败，则图结构无效。 
5. 计算该 BFS 产生的组数。 

BFS 级别自然对应于有效组。 

如果到达的最大距离是`d`，则组数为`d + 1`。 
6. 获取组件的最大 BFS 深度。 

不同的起始节点可能会产生不同数量的层。 我们想要最大可能的分组数。 
7. 将组件贡献添加到全局答案中。 

由于断开连接的组件不会交互，因此可以简单地对它们的最佳组计数进行求和。 

### 为什么它有效

 有效的分组将连续的级别分配给相邻节点。 BFS 分层已经保证相邻节点的距离最多相差 1。 在二部图中，边永远不会连接具有相同级别奇偶校验的节点，因此每条边必须连接相邻级别。 

从每个节点运行 BFS 可以保证我们发现每个组件内最大可能的分层深度。 由于组件是独立的，因此将它们的最大值相加即可得出最佳全局答案。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        graph = [[] for _ in range(n + 1)]

        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        color = [-1] * (n + 1)

        def get_component(start: int) -> List[int]:
            queue = deque([start])
            component = []
            color[start] = 0

            while queue:
                node = queue.popleft()
                component.append(node)

                for neighbor in graph[node]:
                    if color[neighbor] == -1:
                        color[neighbor] = color[node] ^ 1
                        queue.append(neighbor)
                    elif color[neighbor] == color[node]:
                        return []

            return component

        def bfs_depth(start: int) -> int:
            queue = deque([start])
            distance = [-1] * (n + 1)
            distance[start] = 0

            max_distance = 0

            while queue:
                node = queue.popleft()

                for neighbor in graph[node]:
                    if distance[neighbor] == -1:
                        distance[neighbor] = distance[node] + 1
                        max_distance = max(
                            max_distance,
                            distance[neighbor]
                        )
                        queue.append(neighbor)
                    elif abs(distance[neighbor] - distance[node]) != 1:
                        return -1

            return max_distance + 1

        answer = 0

        for node in range(1, n + 1):
            if color[node] != -1:
                continue

            component = get_component(node)

            if not component:
                return -1

            best = 0

            for start in component:
                depth = bfs_depth(start)

                if depth == -1:
                    return -1

                best = max(best, depth)

            answer += best

        return answer
```实现首先构建图的邻接列表表示。 

这`get_component`函数同时执行两项工作。 它收集属于同一连接组件的所有节点，并检查该组件是否是二分的。 这`color`数组存储相邻节点的交替颜色。 如果两个相邻节点接收到相同的颜色，则该图包含奇数循环，因此该函数返回一个空列表以表示失败。 

这`bfs_depth`函数计算从选定节点开始的 BFS 层数。 这`distance`数组存储距起始节点的最短路径距离。 

随着 BFS 向外扩展：

 - 未访问过的邻居接收距离`distance[node] + 1`。 
- 遇到的最大距离决定了组的数量。 
- 检查每条边以确保相邻节点恰好相差一个 BFS 级别。 

最后，外循环独立处理每个连接的组件并对最大层数求和。 

## 解决方案```go
package main

import "container/list"

func magnificentSets(n int, edges [][]int) int {
	graph := make([][]int, n+1)

	for _, edge := range edges {
		u, v := edge[0], edge[1]
		graph[u] = append(graph[u], v)
		graph[v] = append(graph[v], u)
	}

	color := make([]int, n+1)

	for i := 0; i <= n; i++ {
		color[i] = -1
	}

	getComponent := func(start int) []int {
		queue := list.New()
		queue.PushBack(start)

		component := []int{}
		color[start] = 0

		for queue.Len() > 0 {
			front := queue.Front()
			queue.Remove(front)

			node := front.Value.(int)
			component = append(component, node)

			for _, neighbor := range graph[node] {
				if color[neighbor] == -1 {
					color[neighbor] = color[node] ^ 1
					queue.PushBack(neighbor)
				} else if color[neighbor] == color[node] {
					return []int{}
				}
			}
		}

		return component
	}

	bfsDepth := func(start int) int {
		queue := list.New()
		queue.PushBack(start)

		distance := make([]int, n+1)

		for i := 0; i <= n; i++ {
			distance[i] = -1
		}

		distance[start] = 0
		maxDistance := 0

		for queue.Len() > 0 {
			front := queue.Front()
			queue.Remove(front)

			node := front.Value.(int)

			for _, neighbor := range graph[node] {
				if distance[neighbor] == -1 {
					distance[neighbor] = distance[node] + 1

					if distance[neighbor] > maxDistance {
						maxDistance = distance[neighbor]
					}

					queue.PushBack(neighbor)
				} else {
					diff := distance[neighbor] - distance[node]

					if diff < 0 {
						diff = -diff
					}

					if diff != 1 {
						return -1
					}
				}
			}
		}

		return maxDistance + 1
	}

	answer := 0

	for node := 1; node <= n; node++ {
		if color[node] != -1 {
			continue
		}

		component := getComponent(node)

		if len(component) == 0 {
			return -1
		}

		best := 0

		for _, start := range component {
			depth := bfsDepth(start)

			if depth == -1 {
				return -1
			}

			if depth > best {
				best = depth
			}
		}

		answer += best
	}

	return answer
}
```Go 的实现与 Python 解决方案非常相似。 

主要区别在于队列处理。 Go 没有像 Python 那样内置的双端队列结构`collections.deque`，所以我们使用`container/list`。 

距离和颜色数组是手动初始化的，因为 Go 切片默认为零值而不是`-1`。 

整数溢出不是问题，因为最大图形大小仅为`500`。

 ## 边缘情况

 一个重要的边缘情况是奇数循环，例如三角形。 这些图不是二分图，这意味着不可能一致地分配连续的组索引。 仅检查 BFS 深度的简单实现可能会错误地接受此类图。 二分着色步骤通过检测相同颜色的相邻节点来防止此问题。 

另一个重要的情况是断开的图。 由于组件不相互作用，因此应独立添加它们的最佳组数。 忘记这一点可能会导致计数不足或遍历逻辑不正确。 该实现在处理连接组件之前显式地提取它们。 

孤立的节点也很容易被错误处理。 没有边的节点仍然构成有效组件并贡献一组。 BFS 逻辑正确返回深度`1`因为节点到自身的最大距离是`0`。 

一个微妙的边缘情况涉及不同 BFS 起始节点产生不同数量层的图。 例如，在路径图中，从中间开始比从端点开始提供的层数更少。 该实现通过从组件中的每个节点运行 BFS 并选择最大结果来正确处理此问题。
