 ## 问题理解

 该问题要求我们找到整数数组中最长子序列的长度`nums`使得子序列严格递增并且连续元素之间的差异不超过给定整数`k`。 子序列是通过从数组中删除零个或多个元素而不对剩余元素重新排序而形成的。 

输入`nums`是一个长度最大为 100,000 的整数数组，每个元素最大可以为 100,000。 整数`k`范围也高达 100,000。 输出是一个整数，表示满足这两个约束的有效子序列的最大可能长度。 

关键挑战是输入的大小以及连续元素之间允许的最大差异的第二个约束。 考虑所有子序列的简单解决方案将太慢。 重要的边缘情况包括已经严格递增的数组，以及由于以下原因而没有两个元素可以成为同一有效子序列的一部分的数组：`k`，以及具有重复元素的数组。 

## 方法

 暴力方法将尝试生成所有可能的子序列，检查每个子序列是否严格递增并遵守`k`差，然后跟踪最大长度。 这是正确的，但由于子序列的组合数量而不可行：对于长度为 O(2^n) 的数组`n`。 

更好的解决方案利用动态编程和高效的数据结构来查询某个范围内的最大子序列长度。 具体来说，我们可以使用线段树（或二叉索引树）来跟踪以任意数字结尾的子序列的最大长度。 对于每个数字`num`在`nums`，我们查询范围内所有数字中的最大长度`[num - k, num - 1]`然后更新`num`在线段树中的位置。 这种方法将时间复杂度从指数降低到 O(n log M)，其中 M 是最大可能数`nums`。

 ## 算法演练

 1. 初始化一个线段树或二叉索引树，其大小等于中的最大值`nums`。 每个节点将存储以该数字结尾的有效子序列的最大长度。 
2. 迭代每个元素`num`在`nums`。 
3.对于当前`num`，查询线段树，找出范围内数字中的最大子序列长度`[num - k, num - 1]`。 这确保了任何扩展的子序列`num`尊重严格递增顺序和最大允许差异`k`。 
4. 结束于的子序列的长度`num`是`max_length_in_range + 1`。 
5.更新索引处的线段树`num`与新的子序列长度。 
6. 迭代时跟踪全局最大子序列长度。 
7. 处理完所有元素后返回全局最大值。 

为什么它有效：在每一步，线段树确保我们可以有效地检索最长的有效子序列`num`可以延长。 通过更新树，我们保持了树总是存储以每个数字结尾的最佳子序列长度的不变量。 这保证了正确的全局最大值。 

## Python 解决方案```python
from typing import List

class SegmentTree:
    def __init__(self, size: int):
        self.N = 1
        while self.N < size:
            self.N *= 2
        self.tree = [0] * (2 * self.N)
    
    def update(self, index: int, value: int):
        index += self.N
        self.tree[index] = max(self.tree[index], value)
        while index > 1:
            index //= 2
            self.tree[index] = max(self.tree[2 * index], self.tree[2 * index + 1])
    
    def query(self, left: int, right: int) -> int:
        left += self.N
        right += self.N
        result = 0
        while left <= right:
            if left % 2 == 1:
                result = max(result, self.tree[left])
                left += 1
            if right % 2 == 0:
                result = max(result, self.tree[right])
                right -= 1
            left //= 2
            right //= 2
        return result

class Solution:
    def lengthOfLIS(self, nums: List[int], k: int) -> int:
        max_num = max(nums)
        seg_tree = SegmentTree(max_num + 1)
        max_length = 0
        for num in nums:
            left = max(1, num - k)
            right = num - 1
            best_prev = seg_tree.query(left, right) if left <= right else 0
            curr_length = best_prev + 1
            seg_tree.update(num, curr_length)
            max_length = max(max_length, curr_length)
        return max_length
```此 Python 解决方案使用线段树来跟踪每个数字的最大子序列长度。 对于每个`num`，它查询最大值`[num - k, num - 1]`并更新树。 这`max_length`迭代更新以维持全局最大值。 

## 解决方案```go
package main

func lengthOfLIS(nums []int, k int) int {
    maxNum := 0
    for _, num := range nums {
        if num > maxNum {
            maxNum = num
        }
    }

    size := 1
    for size < maxNum+1 {
        size *= 2
    }
    tree := make([]int, 2*size)

    var query func(l, r int) int
    query = func(l, r int) int {
        res := 0
        l += size
        r += size
        for l <= r {
            if l%2 == 1 {
                if tree[l] > res {
                    res = tree[l]
                }
                l++
            }
            if r%2 == 0 {
                if tree[r] > res {
                    res = tree[r]
                }
                r--
            }
            l /= 2
            r /= 2
        }
        return res
    }

    update := func(index, value int) {
        index += size
        if value > tree[index] {
            tree[index] = value
        }
        for index > 1 {
            index /= 2
            if tree[2*index] > tree[2*index+1] {
                tree[index] = tree[2*index]
            } else {
                tree[index] = tree[2*index+1]
            }
        }
    }

    maxLength := 0
    for _, num := range nums {
        left := num - k
        if left < 1 {
            left = 1
        }
        right := num - 1
        bestPrev := 0
        if left <= right {
            bestPrev = query(left, right)
        }
        currLength := bestPrev + 1
        update(num, currLength)
        if currLength > maxLength {
            maxLength = currLength
        }
    }
    return maxLength
}
