[LeetCode 第 136 题](https://leetcode.com/problems/single-number/)

 **难度：** 🟢简单
 **主题：** 数组、位操作

 ## 解决方案

 ## 问题理解

 问题给出一个整数数组`nums`其中每个值恰好出现两次，除了一个仅出现一次的值。 任务是找到并返回那个独特的价值。 

问题的重要部分不仅仅是找到唯一的号码，而是在严格的约束下这样做。 该解决方案必须在线性时间内运行，`O(n)`，并且仅使用恒定的额外空间，`O(1)`。 

输入数组可以包含正数、负数和零。 数组长度可以大到`3 * 10^4`，这意味着低效的方法可能会变得太慢。 由于每个重复的数字恰好出现两次，因此我们可以利用数据中的强对称性。 

预期输出是一个整数，即没有重复伙伴的一个值。 

立即识别几个边缘情况很重要：

 - 数组可能只包含一个元素，在这种情况下，该元素就是答案。 
- 唯一编号可能出现在数组的开头、中间或末尾。 
- 数组可能包含负数。 
- 简单的嵌套循环方法在逻辑上可以工作，但会违反所需的时间复杂度。 
- 基于哈希图的解决方案将满足线性时间，但会违反恒定空间要求。 

该问题保证一个数字恰好出现一次，而所有其他数字恰好出现两次，因此我们永远不需要处理无效的输入配置。 

## 方法

 ### 蛮力方法

 一种简单的方法是检查每个数字并计算它在数组中出现的次数。 

对于每个元素，我们迭代整个数组并计算其频率。 如果频率为一，我们返回该数字。 

这种方法是正确的，因为它显式验证每个值的出现次数。 然而，它的效率很低，因为对于每个`n`元素，我们可以再次扫描整个数组。 

这导致时间复杂度为`O(n^2)`，随着输入变大，它会变得不必要的慢。 

另一种常见的初学者解决方案使用哈希图来计算频率。 这将运行时间提高到`O(n)`但需要`O(n)`额外的空间，违反了问题的要求。 

### 最佳方法，使用 XOR 进行位操作

 关键观察是 XOR 运算的行为。 

XOR 有几个有用的属性：

 -`a ^ a = 0`-`a ^ 0 = a`- XOR 是可交换的和结合的

 这意味着当我们将所有数字异或在一起时：

 - 每个重复的数字都会自行抵消
 - 仅保留唯一编号

 例如：```
2 ^ 2 ^ 1
= 0 ^ 1
= 1
```因为我们只维护单个运行的 XOR 值，所以该解决方案使用恒定的额外空间。 由于我们遍历数组一次，因此运行时间是线性的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 使用嵌套循环计算出现次数 |
 | 最佳| O(n) | O(1) | O(1) | 使用 XOR 取消属性 |

 ## 算法演练

 1. 初始化一个名为`result`到`0`。 

我们使用`0`因为与零进行异或会使数字保持不变。 这使其成为积累的理想起始值。 
2. 遍历数组中的每个数字。 

我们对每个元素只处理一次，这确保了线性运行时间。 
3. 将当前数字与`result`。```
result = result ^ num
```如果一个数字出现两次，则两次出现会相互抵消，因为`a ^ a = 0`。 
4. 继续，直到处理完所有号码。 

当所有重复对消除后，只有唯一的数字仍然存储在`result`。 
5. 返回`result`。 

该最终值是仅出现一次的单个数字。 

### 为什么它有效

 正确性来自于 XOR 的取消性质。 由于每个重复值恰好出现两次，因此当异或在一起时，每对都会产生零。 XOR 具有结合性和交换性，因此顺序并不重要。 当所有重复对取消后，仅保留唯一的数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        result = 0

        for num in nums:
            result ^= num

        return result
```实现从初始化开始`result`到`0`。 该变量存储迄今为止处理的所有数字的运行异或。 

循环遍历中的每个数字`nums`。 在每次迭代期间，当前值与`result`。 

如果该数字以前出现过，则两次出现的次数相互抵消。 如果该数字是唯一的，则它保留在累积的 XOR 结果中。 

遍历结束时，所有重复的数字都被消除，只剩下一个不重复的数字。 然后该方法返回该值。 

## 解决方案```go
func singleNumber(nums []int) int {
    result := 0

    for _, num := range nums {
        result ^= num
    }

    return result
}
```Go 实现遵循与 Python 版本相同的逻辑。 

这`range`循环遍历切片并检索每个数字。 异或赋值运算符`^=`高效更新运行结果。 

不需要对空输入进行特殊处理，因为该问题保证数组非空。 整数溢出不是问题，因为异或运算是在位级别进行的，没有算术增长。

 ## 边缘情况

 ### 单元素数组

 仅包含一个元素的数组是最小的有效输入。 有缺陷的实现可能会错误地假设至少存在一对重复项。 XOR 解决方案可以自然地处理这个问题，因为`0 ^ x = x`，所以直接返回单独的值。 

### 负数

 某些实现错误地假设 XOR 仅适用于正整数。 按位异或对于有符号整数也能正确工作。 该算法处理负数的方式与处理正数的方式完全相同，因此重复的负值仍然可以正确抵消。 

### 任何位置的独特价值

 唯一编号可能出现在数组的开头、中间或末尾。 顺序并不重要，因为 XOR 是可交换的和结合的。 该实现按顺序处理值，但无论排列如何，最终结果都保持正确。
