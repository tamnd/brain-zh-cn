[LeetCode 第 151 题](https://leetcode.com/problems/reverse-words-in-a-string/)

 **难度：** 🟡 中等
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 问题要求我们取一个字符串`s`包含由空格分隔的单词，并返回一个新字符串，其中单词以**相反的顺序**出现。 单词被定义为任意非空格字符序列，并且单词可以用多个空格分隔。 输出必须规范空格，以便单词之间仅存在一个空格，并且不保留前导或尾随空格。 

输入字符串可以包含大小写英文字母、数字和空格，长度最大为10000个字符。 该问题保证**至少有一个单词**，因此空输入字符串不需要处理。 重要的边缘情况包括多个连续空格、前导或尾随空格以及单个单词字符串。 

简单的解决方案可能会忽略多余的空格或无法正确反转单词。 如果字符串是可变的，后续挑战要求**就地**解决方案`O(1)`额外的空间。 

## 方法

 ### 蛮力

 一种简单的暴力方法是使用内置方法将字符串拆分为单词（例如，`split()`在 Python 中或`strings.Fields`在 Go 中），它会自动删除多余的空格。 然后，反转单词列表并用一个空格将它们连接起来。 这种方法简单且正确，但使用与单词数量成比例的额外内存，因为创建了新的列表或切片。 对于很长的字符串，这个额外的空间可能很重要。 

### 最佳方法

 如果字符串是可变的，或者至少具有最小的额外空间，则最佳方法使用**双指针技术**来就地反转单词。 关键的见解是反转整个字符串，然后单独反转每个单词以实现所需的顺序。 这是有效的，因为反转所有字符会将单词移动到相反的位置，并且反转每个单词中的字符会恢复正确的单词拼写。 需要额外的步骤来有效地删除多余的空格。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 拆分成单词、反向列表、连接 |
 | 最佳| O(n) | O(1) 额外（如果可变）| 反转整个字符串，然后反转每个单词，修剪空格 |

 ## 算法演练

 1. **修剪和标准化空格**：删除前导和尾随空格，并将单词之间的多个空格减少为单个空格。 这确保了一致的处理。 
2. **反转整个字符串**：将字符串视为字符数组，反转所有字符。 这会将单词移动到相反的位置。 
3. **单独反转每个单词**：迭代反转的字符串，通过扫描空格来识别每个单词，并反转每个单词的字符。 这将恢复每个单词的正确拼写。 
4. **用单个空格连接单词**：将所有单词反转后，最终的字符串将具有正确的逆序单词，并用单个空格分隔它们。 

**为什么有效**：反转整个字符串会将单词移动到另一端，而单独反转每个单词会将每个单词恢复到正确的顺序。 结合起来，这两个操作会颠倒单词的顺序，同时保持其内部字符完整。 

## Python 解决方案```python
class Solution:
    def reverseWords(self, s: str) -> str:
        # Step 1: Trim and normalize spaces
        words = s.strip().split()
        # Step 2: Reverse the list of words
        reversed_words = words[::-1]
        # Step 3: Join with single space
        return ' '.join(reversed_words)
```**说明**：

 首先，`strip()`删除前导和尾随空格。`split()`自动按空格分割并折叠单词之间的多个空格。 通过切片反转列表`[::-1]`改变单词的顺序。 最后，`' '.join()`使用单词之间的单个空格构造结果字符串。 

## 解决方案```go
import "strings"

func reverseWords(s string) string {
    // Step 1: Trim spaces and split by whitespace
    fields := strings.Fields(s)
    // Step 2: Reverse the slice of words
    for i, j := 0, len(fields)-1; i < j; i, j = i+1, j-1 {
        fields[i], fields[j] = fields[j], fields[i]
    }
    // Step 3: Join words with single space
    return strings.Join(fields, " ")
}
```**说明**：

 Go 没有内置的字符串反转，因此我们通过两指针交换手动反转单词切片。`strings.Fields`自动处理修剪和折叠多个空间。`strings.Join`用一个空格连接单词。 该逻辑与 Python 解决方案非常相似。 

## 工作示例

 示例：`s = "  hello world  "`1. 修剪和规范化空间 →`["hello", "world"]`2. 反转词 →`["world", "hello"]`3. 加入 →`"world hello"`例子：`s = "a good   example"`1. 修剪和标准化 →`["a", "good", "example"]`2. 反转词 →`["example", "good", "a"]`3. 加入 →`"example good a"`## 复杂度分析

 ## 边缘情况

 **单个单词**：输入如下`"single"`应该返回`"single"`。 不存在可删除或反转的空格。 

**单词之间有多个空格**：输入如下`"a   b"`必须标准化为`"b a"`。 按空格分割会自动处理这个问题。 

**前导空格和尾随空格**：输入如下`"   hello"`或者`"world   "`必须修剪以删除多余的空格。 该解决方案使用`strip()`在Python和`strings.Fields`在 Go 中，确保输出中不出现前导或尾随空格。 

**空或全空格字符串**：即使问题保证至少有一个单词，防御性实现也确保它不会失败`" "`或空字符串输入。 split 操作安全地返回一个空列表，而 join 返回一个空字符串，这与规范化输出一致。
