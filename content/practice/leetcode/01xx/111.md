[LeetCode 第 111 题](https://leetcode.com/problems/minimum-depth-of-binary-tree/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们确定二叉树的最小深度。 换句话说，给定二叉树的根，我们想要找到从根节点到最近的叶节点的最短路径。 叶节点被显式定义为没有子节点的节点，这意味着它的左指针和右指针均为空。 

输入是一个二叉树，可能为空，输出是一个表示最小深度的整数。 例如，一棵只有一个节点的树的最小深度为 1，因为根本身就是叶子。 这些约束表明树可能最多有 100,000 个节点，因此重复遍历整棵树的低效解决方案可能会太慢。 节点值在范围内`[-1000, 1000]`，但值本身不会影响深度的计算。 

重要的边缘情况包括一棵空树（最小深度应为 0）、一棵每个节点只有一个子节点的树（实际上是一个链表，其中最小深度等于节点总数）以及根有一个空子节点和一个非空子节点的树。 计算左深度和右深度而不仔细处理空子节点的简单实现可能会错误地将不存在路径的深度计为零。 

## 方法

 强力方法是使用递归深度优先搜索 (DFS)。 我们将递归地计算左子树和右子树的最小深度，并取较小的值，为当前节点加一。 这原则上可行，但有一个微妙的问题：如果其中一个子级为空，我们就不能取零和另一个深度的最小值，因为这会低估深度。 我们必须以不同的方式对待空孩子以避免这种错误。 

更优化的方法使用广度优先搜索 (BFS) 遍历。 关键的见解是 BFS 自然地逐层探索树。 一旦遇到第一个叶子节点，我们就可以立即返回它的深度，因为 BFS 保证它是最浅的叶子。 这避免了遍历整棵树并且效率更高，特别是对于不平衡的树。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力DFS | O(n) | O(h) | 递归计算每个子树的最小深度； h 是树高 |
 | 最优 BFS | O(n) | O(w) | 使用队列进行层序遍历； w 是树的最大宽度 |

 ## 算法演练

 1. 检查根是否为空。 如果是，则立即返回 0，因为树是空的。 
2. 初始化队列并将根节点及其深度添加为元组`(node, depth)`。 
3. 当队列不为空时，从队列中删除最前面的节点及其深度。 
4. 检查当前节点是否为叶子节点（左右子节点均为空）。 如果是，立即返回其深度。 这是最小深度，因为 BFS 保证我们首先遇到浅节点。 
5. 如果该节点有左子节点，则将其添加到队列中，深度加1。 
6. 如果该节点有右子节点，则将其添加到队列中，深度加1。 
7. 继续，直到队列为空。 遇到的第一片叶子给出了最小深度。 

**为什么有效：** BFS 确保节点被逐级访问。 我们遇到的第一个叶节点必须位于最小深度，因为所有较浅的节点都已经被访问过。 这保证了正确性和效率。 

## Python 解决方案```python
from collections import deque
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        queue = deque([(root, 1)])
        
        while queue:
            node, depth = queue.popleft()
            
            if not node.left and not node.right:
                return depth
            
            if node.left:
                queue.append((node.left, depth + 1))
            if node.right:
                queue.append((node.right, depth + 1))
```Python 实现首先处理空树情况。 我们使用双端队列作为队列来维护节点及其深度。 BFS 确保一旦找到叶子，我们立即返回其深度，这避免了不必要的更深节点的探索。 元组`(node, depth)`允许跟踪当前深度而无需重新计算。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func minDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }

    type NodeDepth struct {
        node  *TreeNode
        depth int
    }

    queue := []NodeDepth{{root, 1}}

    for len(queue) > 0 {
        current := queue[0]
        queue = queue[1:]

        if current.node.Left == nil && current.node.Right == nil {
            return current.depth
        }

        if current.node.Left != nil {
            queue = append(queue, NodeDepth{current.node.Left, current.depth + 1})
        }
        if current.node.Right != nil {
            queue = append(queue, NodeDepth{current.node.Right, current.depth + 1})
        }
    }

    return 0
}
```在Go中，我们使用切片来实现队列和结构体`NodeDepth`跟踪节点及其深度。 与 Python 不同，Go 需要显式处理`nil`指针，但逻辑反映了 Python 中的 BFS 方法。 追加到切片可提供具有 O(1) 摊销复杂度的队列行为。 

## 工作示例

 **示例1：`[3,9,20,null,null,15,7]`**

 | 队列状态 | 行动|
 | --- | --- |
 | [(3,1)] | 弹出 3，将 9 和 20 添加到队列 |
 | [(9,2),(20,2)] | pop 9，它是一片叶子→ return 2 |

 **示例2：`[2,null,3,null,4,null,5,null,6]`**

 | 队列状态 | 行动|
 | --- | --- |
 | [(2,1)] | 弹出 2，添加 3 |
 | [(3,2)] | 弹出 3，添加 4 |
 | [(4,3)] | 弹出 4，添加 5 |
 | [(5,4)] | 弹出 5，添加 6 |
 | [(6,5)] | pop 6，它是一片叶子→ return 5 |

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | BFS 中每个节点最多被访问一次 |
 | 空间| O(w) | 队列最多保存树的最大宽度 |

 空间复杂度取决于任何级别的最大节点数，对于平衡树，该最大节点数可能远小于 n，但对于非常宽的树，可以接近 n。

 ## 边缘情况

 一个重要的边缘情况是一棵空树。 假设根存在的简单实现可能会引发异常。 我们的解决方案明确检查`if not root`或者`if root == nil`返回 0。 

另一个边缘情况是倾斜树，其中所有节点都是左子节点或右子节点。 如果 DFS 实现仅采用左深度和右深度的最小值而不考虑一个子节点为空，则它可能会失败。 我们的 BFS 方法通过仅将非空子级添加到队列中来自然地处理这个问题。 

第三种边缘情况是根具有一个空子级和一个非空子级。 如果算法错误地将空子项视为 DFS 中的深度零，则会低估最小深度。 在 BFS 中，这是自动处理的，因为空子节点永远不会排队，并且遇到的第一个叶子给出了正确的深度。
