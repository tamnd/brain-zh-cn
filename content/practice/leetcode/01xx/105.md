[LeetCode 第 105 题](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、分而治之、树、二叉树

 ## 解决方案

 ## 问题理解

 问题是要求我们在给定两个遍历顺序的情况下重建二叉树：`preorder`和`inorder`。 在前序遍历中，节点按以下顺序访问：根、左子树、右子树。 在中序遍历中，节点按以下顺序访问：左子树、根、右子树。 

给定这两个序列，任务是重建**精确的原始树结构**并返回其根。 数组中的每个值都是唯一的，这保证了在遍历时可以唯一地标识每个节点。 这些约束表明数组最多可以有 3000 个元素，因此任何方法都必须有效地处理中等大小的输入。 

边缘情况包括最小的树（单个节点）、完全左偏或右偏的树以及空输入（尽管约束保证至少有一个节点）。 唯一性保证简化了问题，因为我们不必处理重复的值。 

## 方法

 蛮力方法是迭代`preorder`数组，将每个元素视为潜在的根，并递归地尝试数组中所有可能的分割`inorder`数组来构建左子树和右子树。 虽然这种方法在逻辑上可行，但效率很低，因为它会重复搜索根索引`inorder`数组，时间复杂度为 O(n^2)。 

最佳方法依赖于两个关键的观察结果。 首先，第一个元素`preorder`永远是根。 其次，该根在`inorder`array 将数组划分为左子树和右子树。 使用哈希映射来存储值的索引`inorder`数组允许 O(1) 查找根位置，从而提高递归构造的效率。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 搜索根索引`inorder`在每次递归中 |
 | 最佳| O(n) | O(n) | 使用哈希映射作为根索引，递归构造 |

 ## 算法演练

 1. 构造一个哈希映射`inorder`其指数值。 这允许 O(1) 访问任意根的位置`inorder`。 
2. 维护一个指针或索引`preorder`知道哪个节点是当前的根。 从 0 开始。 
3. 定义递归函数`build_subtree(left, right)`在哪里`left`和`right`是当前子树的边界`inorder`大批。 
4. 基本情况：如果`left > right`， 返回`None`因为没有要处理的节点。 
5. 取当前根值`preorder[current_index]`并增加索引。 
6. 使用该根值创建一个新的树节点。 
7. 使用索引递归构造左子树`left`到`root_index_in_inorder - 1`。 
8. 使用索引递归构造右子树`root_index_in_inorder + 1`到`right`。 
9. 在附加两个子树后返回根节点。 

**为什么有效：** 在每一步中，我们确保节点来自`preorder`被放置在由其确定的正确位置`inorder`指数。 递归保证所有节点相对于其父节点正确放置，保留原始树结构。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: list[int], inorder: list[int]) -> 'Optional[TreeNode]':
        if not preorder or not inorder:
            return None
        
        # Map each value to its index in inorder
        inorder_index_map = {value: idx for idx, value in enumerate(inorder)}
        preorder_index = 0
        
        def build_subtree(left: int, right: int) -> 'Optional[TreeNode]':
            nonlocal preorder_index
            if left > right:
                return None
            
            root_val = preorder[preorder_index]
            preorder_index += 1
            root = TreeNode(root_val)
            
            root.left = build_subtree(left, inorder_index_map[root_val] - 1)
            root.right = build_subtree(inorder_index_map[root_val] + 1, right)
            
            return root
        
        return build_subtree(0, len(inorder) - 1)
```Python 实现首先构造一个哈希映射，将值映射到中的索引`inorder`。 我们维持一个`preorder_index`知道接下来要处理哪个节点。 递归`build_subtree`函数确保对于每个根，其左子树和右子树都使用中序边界正确构建。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func buildTree(preorder []int, inorder []int) *TreeNode {
    if len(preorder) == 0 || len(inorder) == 0 {
        return nil
    }
    
    inorderIndexMap := make(map[int]int)
    for i, val := range inorder {
        inorderIndexMap[val] = i
    }
    
    preorderIndex := 0
    
    var buildSubtree func(left, right int) *TreeNode
    buildSubtree = func(left, right int) *TreeNode {
        if left > right {
            return nil
        }
        
        rootVal := preorder[preorderIndex]
        preorderIndex++
        root := &TreeNode{Val: rootVal}
        
        root.Left = buildSubtree(left, inorderIndexMap[rootVal]-1)
        root.Right = buildSubtree(inorderIndexMap[rootVal]+1, right)
        
        return root
    }
    
    return buildSubtree(0, len(inorder)-1)
}
```在 Go 中，我们类似地处理递归，但需要显式管理指向`TreeNode`。 这`preorderIndex`变量保存在闭包中`buildSubtree`。 使用 Nil 指针代替 Python 的指针`None`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点只被处理一次。 哈希映射查找的时间复杂度为 O(1)。 |
 | 空间| O(n) | 哈希映射使用 O(n)，在倾斜树中递归堆栈可以达到 O(n)。 |

 ## 边缘情况

 **单节点树：**何时`preorder`和`inorder`有一个元素，树只有一个根。 实现会处理这个问题，因为递归中的基本情况正确返回节点。 

**倾斜树：** 完全向左或向右倾斜的树可以达到等于节点数的递归深度。 该算法可以处理这个问题，并且 Python/Go 递归深度限制足以满足 n ≤ 3000。 

**空输入：** 约束保证至少有一个节点，但代码通过返回来防御性地处理空列表`None`或者`nil`。 这可以防止递归调用期间潜在的索引错误。
