[LeetCode 第 137 题](https://leetcode.com/problems/single-number-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、位操作

 ## 解决方案

 ## 问题理解

 这个问题要求我们在数组中找到一个唯一的数字，其中每个其他数字都出现**恰好三次**。 简单来说，如果你想象对数组中的所有数字进行计数，除了 1 之外的每个数字都会出现 3 次，而我们的任务是找出只出现一次的数字。 

输入是一个整数列表`nums`，尺寸限制可达`3 * 10^4`，相对较大。 数字本身可以是负数、零或正数，最大可达 32 位有符号整数范围。 输出是一个整数，即不重复 3 次的数字。 

要记住的边缘情况包括最小大小为 1 的数组（其中唯一的数字就是答案）、具有负数的数组以及唯一数字为零的数组。 该问题保证了恰好有**一个唯一的数字**，因此我们不需要处理多个单个数字或空数组。 

关键的挑战是该解决方案必须以**线性时间**运行并使用**恒定的额外空间**，这排除了使用哈希映射或排序的典型方法。 

## 方法

 **暴力方法**是使用哈希映射或字典来计算每个数字的出现次数。 一旦知道了所有计数，我们就可以迭代字典来查找出现过一次的数字。 这种方法简单且正确，但它使用了 **O(n) 额外空间**，这违反了问题的常数空间约束。 

**最佳方法**利用**位操作**。 由于数字是具有固定位数（在本例中为 32 位）的整数，因此我们可以检查所有数字中的每个位位置。 对于每个位位置，如果我们将数组中该位置的所有位相加并取模 3，则对于属于出现 3 次的数字的位，总和将为零。 剩余的总和将对应于唯一编号的位。 利用这种洞察力，我们可以重建单个数字，而无需超出几个整数变量的额外内存。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 使用哈希图统计出现次数，简单但违反常量空间约束 |
 | 最佳| O(n) | O(1) | O(1) | 使用按位运算跟踪模 3 的位数，高效重构单个数字 |

 ## 算法演练

 1.初始化两个整型变量，`ones`和`twos`, 为零。 这些变量将分别跟踪出现过一次和两次的位。 
2. 迭代每个数字`num`在数组中。 
3. 更新`twos`出现过两次的位。 这是使用完成的`twos |= ones & num`。 
4. 更新`ones`与出现过一次的位。 使用`ones ^= num`。 
5. 计算出现过 3 次的位的掩码：`common_mask = ~(ones & twos)`。 
6. 清除位`ones`和`twos`出现过三次的：`ones &= common_mask`和`twos &= common_mask`。 
7. 处理完所有数字后，`ones`将包含唯一编号的位。 返回`ones`。 

**为什么有效：**

 该算法为每个位位置维护模 3 出现的按位计数。 每当一个位出现 3 次时，它就会从两者中清除`ones`和`twos`，有效地重置该位的计数。 最后，只有与唯一编号对应的位保留在`ones`。 

## Python 解决方案```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ones, twos = 0, 0
        for num in nums:
            twos |= ones & num
            ones ^= num
            common_mask = ~(ones & twos)
            ones &= common_mask
            twos &= common_mask
        return ones
```在这个实现中，`ones`跟踪曾经见过的位，`twos`跟踪出现过两次的位，并且`common_mask`清除出现过 3 次的位。 到最后，`ones`包含唯一编号。 

## 解决方案```go
func singleNumber(nums []int) int {
    ones, twos := 0, 0
    for _, num := range nums {
        twos |= ones & num
        ones ^= num
        commonMask := ^(ones & twos)
        ones &= commonMask
        twos &= commonMask
    }
    return ones
}
```Go 实现反映了 Python 解决方案。 我们使用整数`ones`和`twos`跟踪位数，以及`commonMask`重置已出现 3 次的位。 对于 32 位整数，Go 的按位运算与 Python 的工作方式相同。

 ## 边缘情况

 **单元素数组：** 如果数组只有一个元素，那么它就是唯一的数字。 我们的实现自然地处理了这个问题，因为循环运行一次，并且`ones`最终成为该元素。 

**负数：** 位操作可以在 Python 和 Go 中正确处理负数，因为这些操作适用于二进制补码表示形式。 这确保了`ones`正确地重建负数。 

**唯一数字为零：** 零没有设置位，因此它可能看起来很棘手，但算法可以正确处理它，因为`ones`从零开始，如果除零以外的所有数字都出现三次，则将保持为零。 这可确保准确地返回零。
