[LeetCode 第 116 题](https://leetcode.com/problems/populate-next-right-pointers-in-each-node/)

 **难度：** 🟡 中等
 **主题：** 链表、树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们填充`next`**完美二叉树**中的节点指针。 完美二叉树的所有层都被完全填满； 每个内部节点都有两个子节点，并且所有叶子节点都处于相同的深度。 这`next`节点的指针应指向紧邻其右侧的同一级别的节点。 如果右侧没有节点（该节点是其级别上的最后一个），则`next`指针应该是`NULL`。 

输入是二叉树的根，其中每个节点有四个字段：`val`（整数值），`left`（指向左孩子的指针），`right`（指向右孩子的指针），以及`next`（最初`NULL`）。 输出是同一棵树，但具有`next`指针设置正确。 

约束表明树的大小最多为`2^12 - 1`节点，这对于一个足够适度的`O(n)`解决方案。 由于它是一个完美的二叉树，我们可以安全地假设每个内部节点都有两个子节点。 这简化了遍历逻辑，因为我们不必检查丢失的孩子。 

边缘情况包括**空树**（根是`NULL`）和一棵只有**一个节点**的树。 在这两种情况下，`next`指针仍然存在`NULL`。 

**后续约束**要求我们实现**恒定的额外空间**，这意味着我们不能使用队列进行级别顺序遍历，除非我们将隐式递归堆栈视为可接受的空间。 

## 方法

 暴力方法是使用队列执行层序遍历。 在每个级别，我们迭代所有节点，将每个节点链接到队列中的下一个节点。 完成一个关卡后，我们设置`next`最后一个节点的指针`NULL`。 虽然这可以正常工作并且很容易实现，但它需要`O(n)`为队列提供额外的空间，这违反了常量空间后续。 

最佳解决方案利用了**完美二叉树**的特性。 对于每个节点，其左子节点的`next`应该指向它的右孩子。 此外，该节点的右子节点`next`应该指向该节点的左子节点`next`（如果存在）。 这允许我们仅使用先前建立的链接来链接级别中的所有节点`next`没有额外空间的指针。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 使用队列进行层序遍历； 每层链接节点 |
 | 最佳| O(n) | O(1) | O(1) | 利用完美二叉树属性； 不需要额外的数据结构|

 ## 算法演练

 1. **处理基本情况：** 如果根是`NULL`， 返回`NULL`。 
2. **初始化一个遍历levels的指针：**设置`leftmost`到根。 该指针将始终指向当前级别的第一个节点。 
3. **逐级迭代：** While`leftmost.left`不是`NULL`，执行以下操作：

 1. 初始化一个`head`指向当前层内遍历节点的指针。 
2. 对于该级别中的每个节点，连接其子节点：

 1.`head.left.next = head.right`将左孩子连接到右孩子。 
2.如果`head.next`存在，`head.right.next = head.next.left`将右子树连接到下一个子树的左子树。 
3. 移动`head`到`head.next`继续链接当前级别的节点。 
4. **移动到下一个级别：** 设置`leftmost`到`leftmost.left`。 
5. **返回根。**

 **为什么它有效：** 不变的是，在每个级别开始时，所有`next`上一级的指针设置正确。 使用这个不变量，我们可以链接当前级别，而无需任何额外的数据结构。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: int = 0, left: 'Node' = None, right: 'Node' = None, next: 'Node' = None):
        self.val = val
        self.left = left
        self.right = right
        self.next = next
"""

class Solution:
    def connect(self, root: 'Optional[Node]') -> 'Optional[Node]':
        if not root:
            return None
        
        leftmost = root
        
        while leftmost.left:
            head = leftmost
            while head:
                # Connect left -> right
                head.left.next = head.right
                # Connect right -> next.left if available
                if head.next:
                    head.right.next = head.next.left
                head = head.next
            leftmost = leftmost.left
        
        return root
```该代码首先检查树是否为空。 然后它使用`leftmost`跟踪每个级别的第一个节点。 在每个级别内，`head`迭代节点并使用已建立的连接子节点`next`指针。 完成一个级别后，它会通过以下方式向下移动一个级别`leftmost.left`。 当没有更多的子节点时，循环终止。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Left *Node
 *     Right *Node
 *     Next *Node
 * }
 */

func connect(root *Node) *Node {
	if root == nil {
		return nil
	}
	
	leftmost := root
	
	for leftmost.Left != nil {
		head := leftmost
		for head != nil {
			head.Left.Next = head.Right
			if head.Next != nil {
				head.Right.Next = head.Next.Left
			}
			head = head.Next
		}
		leftmost = leftmost.Left
	}
	
	return root
}
```在 Go 中，我们处理`nil`代替`NULL`。 逻辑与Python版本相同，使用两个指针来有效地迭代级别和链接节点。

 ## 边缘情况

 第一个重要的边缘情况是**空树**，其中`root`是`NULL`。 一个幼稚的实现可能会尝试访问`root.left`并导致运行时错误。 解决方案立即返回`NULL`安全地处理这个问题。 

第二个边缘情况是**具有单个节点的树**。 由于没有孩子，大家`next`指针仍然存在`NULL`。 循环检查`leftmost.left`确保它不会尝试不必要的连接。 

第三种边缘情况是**深度完美二叉树**，其中层数接近约束所允许的最大值。 该解决方案必须正确遍历所有级别且不会出现堆栈溢出。 由于该算法使用迭代方法，因此只需使用恒定数量的指针即可有效地处理大深度。
