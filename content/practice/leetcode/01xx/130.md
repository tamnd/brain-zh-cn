[LeetCode 第 130 题](https://leetcode.com/problems/surrounded-regions/)

 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、广度优先搜索、并查找、矩阵

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个二维网格，称为`board`，其中每个单元格包含`'X'`或者`'O'`。 目标是通过捕获每个区域来修改棋盘`'O'`细胞完全被包围`'X'`。 

连接相邻的区域形成一个区域`'O'`单元格水平或垂直。 对角线连接不算数。 如果一个区域没有任何单元格接触棋盘的边界，则该区域被视为被包围。 如果该区域中有一个像元位于边缘或连接到边缘`'O'`，那么整个区域必须保持不变。 

重要的观察是，包围的区域正是`'O'`无法到达边境的地区。 任何`'O'`连接到边界`'O'`是安全的，不应翻转。 

输入是一个`m x n`两个维度最多为的矩阵`200`。 这意味着该板最多可以包含`40,000`细胞。 由于这种限制，重复扫描电路板或从每个单元启动昂贵搜索的算法可能会变得太慢。 线性遍历解，`O(m * n)`，是理想的目标。 

一些边缘情况很重要：

 - 单行或单列板不能包含包围区域，因为每个单元格都接触边界。 
- 一块板只有`'X'`单元格应保持不变。 
- 一块板只有`'O'`单元格也应保持不变，因为所有单元格都连接到边界。 
- 大的连接区域需要仔细遍历以避免重复访问单元格。 

## 方法

 ### 蛮力方法

 一个简单的想法是检查每一个`'O'`细胞独立。 对于每个未访问过的`'O'`，我们可以执行DFS或BFS来确定全连接区域。 在遍历过程中，我们跟踪该区域是否触及边界。 

如果该区域不接触边界，我们将该区域中的每个单元格翻转到`'X'`。 否则，我们将保持该区域不变。 

这种方法是正确的，因为在决定是否应该捕获每个区域之前，都会对每个区域进行彻底的探索。 然而，如果搜索重复地重新访问相同的单元格，或者如果我们不必要地从许多位置发起新的遍历，那么简单的实现可能会变得低效。 

优化不佳的暴力解决方案可能会接近`O((m * n)^2)`在最坏的情况下。 

### 最佳方法

 关键的见解是我们实际上不需要直接识别周围的区域。 相反，我们只需要识别未被包围的区域。 

任何`'O'`连接到边界的永远无法被占领。 因此：

 1.从所有边界开始`'O'`细胞。 
2. 遍历所有连通的`'O'`使用 DFS 或 BFS 的单元。 
3. 暂时标记这些安全单元格。 
4、遍历后：

 - 任何剩余的`'O'`必须被包围，所以翻转它`'X'`。 
- 将临时标记的安全单元恢复到`'O'`。 

这将问题转化为图可达性问题。 我们不会单独测试每个区域，而是只保护保证生存的区域。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m * n)^2) | O((m * n)^2) | O(m * n) | 反复探索多个细胞的区域 |
 | 最佳| O(m * n) | O(m * n) | 标记边界连接区域一次 |

 ## 算法演练

 1、首先检查板子是否为空。 如果棋盘没有行或列，则没有任何可处理的内容。 
2. 遍历所有边界单元格。 这些包括：

 - 第一行
 - 最后一排
 - 第一栏
 - 最后一栏
 3. 每当边界单元格包含`'O'`，从该单元启动 DFS 或 BFS。 遍历过程中：

 - 标记每个可到达的地方`'O'`作为临时值，例如`'T'`- 继续在四个方向探索相邻单元格：

 - 向上
 - 向下
 - 左
 - 右
 4. 标记完所有边界连接区域后，再次扫描整个板。 
5. 对于每个单元格：

 - 如果细胞仍然存在`'O'`，这意味着它从未连接到边界，因此它被包围。 将其转换为`'X'`。 
- 如果细胞是`'T'`，将其恢复到`'O'`因为它属于安全区域。 
6. 董事会现已完全更新到位。 

### 为什么它有效

 该算法依赖于一个重要的不变量：

 任意`'O'`连接到边界无法被包围。 

仅从边界开始遍历`'O'`细胞，我们准确标记必须存活的细胞。 每一个没有标记的`'O'`因此属于全封闭区域，可以安全翻转到`'X'`。 

由于每个单元最多被处理固定次数，因此该算法既正确又高效。 

## Python 解决方案```python
from typing import List

class Solution:
    def solve(self, board: List[List[str]]) -> None:
        """
        Do not return anything, modify board in-place instead.
        """
        
        if not board or not board[0]:
            return

        rows = len(board)
        cols = len(board[0])

        def dfs(r: int, c: int) -> None:
            if (
                r < 0 or r >= rows or
                c < 0 or c >= cols or
                board[r][c] != 'O'
            ):
                return

            board[r][c] = 'T'

            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)

        # Process left and right borders
        for r in range(rows):
            if board[r][0] == 'O':
                dfs(r, 0)

            if board[r][cols - 1] == 'O':
                dfs(r, cols - 1)

        # Process top and bottom borders
        for c in range(cols):
            if board[0][c] == 'O':
                dfs(0, c)

            if board[rows - 1][c] == 'O':
                dfs(rows - 1, c)

        # Final conversion
        for r in range(rows):
            for c in range(cols):
                if board[r][c] == 'O':
                    board[r][c] = 'X'
                elif board[r][c] == 'T':
                    board[r][c] = 'O'
```实现首先安全地处理空输入。 电路板的尺寸存储在`rows`和`cols`以便于访问。 

这`dfs`辅助函数执行深度优先遍历。 当出现以下情况时，它会立即停止：

 - 位置超出范围
 - 细胞不是`'O'`每当有效`'O'`找到后，暂时标记为`'T'`。 这可以防止重新访问同一单元格并将安全单元格与周围的单元格区分开来。 

然后该算法扫描所有边界单元。 每一个边界`'O'`启动 DFS 遍历来标记所有连接的安全单元。 

识别出所有安全区域后，最后一次扫描棋盘：

 - 剩余`'O'`细胞被包围并翻转到`'X'`- 暂时的`'T'`细胞恢复到`'O'`这满足了就地修改的要求，因为没有创建单独的板。 

## 解决方案```go
func solve(board [][]byte) {
    if len(board) == 0 || len(board[0]) == 0 {
        return
    }

    rows := len(board)
    cols := len(board[0])

    var dfs func(int, int)

    dfs = func(r int, c int) {
        if r < 0 || r >= rows || c < 0 || c >= cols || board[r][c] != 'O' {
            return
        }

        board[r][c] = 'T'

        dfs(r+1, c)
        dfs(r-1, c)
        dfs(r, c+1)
        dfs(r, c-1)
    }

    // Process left and right borders
    for r := 0; r < rows; r++ {
        if board[r][0] == 'O' {
            dfs(r, 0)
        }

        if board[r][cols-1] == 'O' {
            dfs(r, cols-1)
        }
    }

    // Process top and bottom borders
    for c := 0; c < cols; c++ {
        if board[0][c] == 'O' {
            dfs(0, c)
        }

        if board[rows-1][c] == 'O' {
            dfs(rows-1, c)
        }
    }

    // Final conversion
    for r := 0; r < rows; r++ {
        for c := 0; c < cols; c++ {
            if board[r][c] == 'O' {
                board[r][c] = 'X'
            } else if board[r][c] == 'T' {
                board[r][c] = 'O'
            }
        }
    }
}
```Go 解决方案遵循与 Python 实现完全相同的算法结构。 一个区别是该板使用`[][]byte`而不是单个字符的字符串。 这允许对细胞进行直接就地修改。 

Go 还要求在将闭包分配给递归函数变量之前显式声明它。 除了语法差异之外，遍历和标记逻辑保持相同。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 每个单元最多被访问固定次数 |
 | 空间| O(m * n) | 递归DFS堆栈可以增长到棋盘的大小|

 棋盘遍历本身是线性的，因为每个单元最多在状态之间转换一次。 如果棋盘包含一个巨大的连通区域，则 DFS 递归深度可能会变大`'O'`单元格，这就是为什么辅助空间复杂度也是`O(m * n)`在最坏的情况下。

 ## 边缘情况

 ### 单行或单列

 只有一行或一列的板很重要，因为每个单元格都位于边界上。 幼稚的实现可能会错误地尝试捕获内部单元，即使不存在真正的内部。 

该算法自然地处理这个问题，因为所有`'O'`细胞在边界穿越阶段被发现并标记为安全。 

### 大型互联边境地区

 一块板可能包含一个巨大的区域`'O'`细胞通过一条很长的路径间接连接到边界。 有缺陷的解决方案可能只保留边界单元本身，而不是保留整个连接的组件。 

DFS 遍历正确地传播到所有连接的`'O'`细胞，确保整个地区的生存。 

### 完全封闭的岛屿

 一个完全被包围的区域`'X'`cells 是主要的捕获情况。 这里的危险是由于不完整的遍历或不正确的邻居检查而意外保留单元格。 

由于该算法仅保留边界可到达的单元格，因此封闭区域永远不会被标记为安全。 他们仍然`'O'`在标记阶段，然后翻转到`'X'`在最终扫描期间。
