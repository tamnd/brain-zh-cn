 ## 解决方案

 ## 问题理解

 该问题要求我们旋转给定的整数数组`nums`向右`k`步骤。 换句话说，数组的每个元素都应该移动`k`位置向前，“从末端脱落”的元素环绕到数组的前面。 例如，如果`nums = [1,2,3,4,5]`和`k = 2`, 最后两个元素`[4,5]`移动到前面，导致`[4,5,1,2,3]`。 

输入`nums`是一个标准的整数列表或数组，长度在 1 到 105 之间，每个整数都在 32 位有符号整数范围内。 整数`k`可以大到 105，这意味着一次旋转数组一步的简单解决方案会太慢。 输出是相同的数组`nums`，修改**就地**，意味着如果实现最佳解决方案，则不应返回或分配新数组。 

重要的边缘情况包括`k`为零（不需要旋转），当`k`等于数组的长度（旋转结果是同一个数组），并且当数组仅包含一个元素时。 这些约束保证数组非空，但是旋转量`k`可能大于数组长度，因此需要进行模运算。 

## 方法

 强力方法一次旋转阵列一步，`k`次。 在每个步骤中，我们保存最后一个元素，将所有其他元素向右移动一个位置，并将保存的元素放置在索引 0 处。这可以正常工作，因为它完全按照描述模拟旋转。 然而，它的时间复杂度是 O(n * k)，因为移位数组需要 O(n) 次操作，并且会重复进行`k`次，这对于大型阵列或大型`k`。 

最佳方法使用**数组反转技术**。 关键的见解是旋转阵列`k`向右移动相当于将整个数组反转，然后将第一个数组反转`k`元素，最后反转剩余的`n-k`元素。 此方法可以在 O(1) 额外空间内就地工作，并且只需要 O(n) 操作。 原因是反转子数组保留了旋转段的相对顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(1) | O(1) | 一次旋转一步，对于大型设备来说效率低下`k`|
 | 最佳| O(n) | O(1) | O(1) | 采用数组反转技术，就地高效 |

 ## 算法演练

 1. 使用以下公式计算有效旋转`k = k % n`， 在哪里`n`是数组的长度。 这处理以下情况`k`大于`n`。 
2. 反转整个数组。 这会将应出现在末尾的元素移动到开头，但顺序相反。 
3.反转第一个`k`元素。 这将恢复旋​​转段的正确顺序。 
4.将剩余的反转`n-k`元素。 这将恢复剩余段的正确顺序。 
5. 数组`nums`现在已旋转`k`步骤向右到位。 

为什么有效：反转整个数组会翻转所有元素的位置。 通过反转第一个`k`元素和其余元素分开，我们恢复旋转段内的相对顺序。 这保证了数组在使用恒定的额外空间的同时正确旋转。 

## Python 解决方案```python
from typing import List

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        k %= n  # handle cases where k > n

        def reverse(start: int, end: int) -> None:
            while start < end:
                nums[start], nums[end] = nums[end], nums[start]
                start += 1
                end -= 1

        reverse(0, n - 1)      # reverse the whole array
        reverse(0, k - 1)      # reverse the first k elements
        reverse(k, n - 1)      # reverse the rest
```该实现首先计算有效`k`使用模。 辅助函数`reverse`在两个索引之间就地交换元素。 我们反转整个数组，然后反转第一个数组`k`元素来固定旋转的段，最后反转剩余元素以恢复其原始顺序。 这反映了上述算法。 

## 解决方案```go
func rotate(nums []int, k int)  {
    n := len(nums)
    k %= n // handle cases where k > n

    reverse := func(start, end int) {
        for start < end {
            nums[start], nums[end] = nums[end], nums[start]
            start++
            end--
        }
    }

    reverse(0, n-1) // reverse the whole array
    reverse(0, k-1) // reverse the first k elements
    reverse(k, n-1) // reverse the rest
}
```在 Go 中，我们使用类似的方法。 这`reverse`函数被定义为匿名函数捕获`nums`并在两个索引之间交换元素。 与 Python 的主要区别在于语法，Go 中的切片是引用，因此就地更改直接修改原始数组。

 ## 边缘情况

 一个重要的边缘情况是当`k`为零。 在这种情况下，数组应该保持不变。 模运算确保我们自然地处理这个问题而无需额外的检查。 另一个边缘情况是当`k`等于数组的长度； 模算术将其转换为零旋转。 第三种边缘情况是单元素数组，无论什么情况它都不会改变`k`。 该算法可以正确处理所有这些情况，因为反转操作对于这些情况实际上是无操作的。 另外，当`k`大于`n`, 采取`k % n`确保轮换有意义并避免不必要的操作。
