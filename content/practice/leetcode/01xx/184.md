[LeetCode 第 184 题](https://leetcode.com/problems/department-highest-salary/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们从公司数据库中找到每个部门中薪水最高的员工。 输入由两个关系表组成：`Employee`和`Department`。 这`Employee`表包含员工详细信息，包括`id`,`name`,`salary`， 和`departmentId`。 这`departmentId`是将员工连接到的外键`Department`桌子。 这`Department`表包含`id`和`name`，代表每个部门的唯一标识符和名称。 

预期输出是一个包含三列的表：`Department`,`Employee`， 和`Salary`。 每行代表其部门中薪资最高的员工。 如果多个员工在一个部门中享有最高薪水，则每个员工都应出现在输出中。 

要考虑的约束包括保证部门名称非空以及`id`两个表中的字段都是唯一的。 这意味着我们不需要处理丢失的部门名称或重复的 ID。 边缘情况包括只有一名员工的部门、多名与最高工资挂钩的员工以及根本没有员工的部门（尽管在这个问题中，后者不太可能，因为只考虑现有员工）。 

## 方法

 蛮力方法涉及遍历每个部门，扫描该部门的所有员工以找到最高工资，然后收集具有该最高工资的所有员工。 此方法可以正常工作，但需要对部门和员工进行嵌套循环，这对于大型数据集来说可能会很慢。 

最佳方法利用 SQL 聚合和连接功能。 我们可以首先计算每个部门的最高工资：`GROUP BY`。 然后，我们将这个结果与`Employee`表仅选择工资与部门最高工资匹配的员工。 最后，我们与`Department`表来获取部门名称。 这种方法减少了冗余比较并有效地利用数据库索引。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(D * E) | O(E) | 迭代每个部门并扫描所有员工以查找最高工资 |
 | 最佳| O(E) | O(D) | 使用聚合和联接来计算每个部门的最高工资并筛选员工 |

 ## 算法演练

 1.计算各部门的最高工资。 这是通过分组来完成的`Employee`表格依据`departmentId`并应用`MAX`函数在`salary`柱子。 结果是一个映射`departmentId`到`max_salary`。 
2. 加入`Employee`带有此最高工资表的表`departmentId`和`salary`。 这会过滤员工，只保留那些工资等于其部门最高工资的员工。 
3. 将过滤结果与`Department`桌子上`departmentId = id`获取部门名称。 
4. 选择列`Department`（部门名称），`Employee`（员工姓名），以及`Salary`从最终的连接结果来看。 
5. 返回结果表。 未指定顺序，因此任何顺序都可以接受。 

**为什么有效：** 这里的不变性是，对于每个部门，仅保留工资等于计算的最高工资的员工。 由于 SQL 连接保留行相等性，因此所有与最高工资相关的员工都包括在内。 最终的连接添加了部门名称，满足输出格式。 

## Python 解决方案```python
# Python solution using SQLAlchemy as a reference for LeetCode SQL execution
# LeetCode allows direct SQL execution, so the core logic is a SQL query
class Solution:
    def highestSalary(self) -> str:
        query = """
        SELECT d.name AS Department, e.name AS Employee, e.salary AS Salary
        FROM Employee e
        JOIN Department d ON e.departmentId = d.id
        JOIN (
            SELECT departmentId, MAX(salary) AS max_salary
            FROM Employee
            GROUP BY departmentId
        ) m ON e.departmentId = m.departmentId AND e.salary = m.max_salary
        """
        return query
```**说明：** 子查询计算每个部门的最高工资。 加入它与`Employee`表仅筛选出最高工资的员工。 加入与`Department`表添加部门名称。 列别名`Department`,`Employee`， 和`Salary`满足所需的输出格式。

 ## 边缘情况

 **部门中的单一员工：** 如果一个部门只有一名员工，则该员工自动成为薪酬最高的员工。 聚合可确保无需特殊处理即可选择该员工。 

**多名员工并列最高工资：** 如果同一部门的多名员工共享最高工资，则必须全部包括在内。 加入`salary = max_salary`保证所有此类员工都出现在结果中。 

**没有员工的部门：** 虽然没有明确出现在问题中，但没有员工的部门不会出现在结果中。 内连接与`Employee`自然排除空部门，避免 NULL 或空行。
