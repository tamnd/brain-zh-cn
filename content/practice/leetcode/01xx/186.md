[LeetCode 第 186 题](https://leetcode.com/problems/reverse-words-in-a-string-ii/)

 **难度：** 🟡 中等
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们反转字符数组中单词的顺序`s`**就地**。 每个单词都是连续的非空格字符序列，并且单词之间恰好由一个空格分隔。 输入数组没有前导或尾随空格，因此我们不需要处理末尾的额外空格。 预期输出是相同的数组`s`但单词的顺序颠倒了，同时保持每个单词的字符的原始顺序。 

例如，给定`s = ["t","h","e"," ","s","k","y"]`，这些词是`"the"`和`"sky"`。 颠倒词序后，数组应该变成`["s","k","y"," ","t","h","e"]`。 关键约束是**就地修改**，因此不应创建额外的数组来单独存储单词。 

重要的边缘情况包括仅包含一个单词的输入、非常短的数组或包含单个字符的数组。 自从`s`保证至少有一个单词，并且单词之间用一个空格分隔，我们不需要处理多个空格或空字符串。 

## 方法

 一种简单的暴力方法是使用临时数组将字符数组拆分为单词，反转单词列表，然后将它们重新组装回`s`。 虽然这会产生正确的结果，但它使用与字符或单词数量成比例的额外空间，违反了就地要求。 

最佳方法的关键见解是**反转整个数组，然后反转每个单词**产生所需的结果。 反转整个数组会将最后一个字移动到第一个位置，将倒数第二个字移动到第二个位置，依此类推。 然而，这也会颠倒每个单词中的字符，因此我们需要第二遍来颠倒每个单词中的字符以恢复其原始顺序。 

该方法使用**两遍就地反转**和**两个指针**，并且不需要额外的内存，满足问题约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将数组拆分为字、反转字、使用额外内存重新组装数组 |
 | 最佳| O(n) | O(1) | O(1) | 反转整个数组，然后单独就地反转每个单词 |

 ## 算法演练

 1. **反转整个数组`s`** 从开始到结束。 这会将最后一个单词放在第一个位置，倒数第二个单词放在第二个位置，依此类推。每个单词的字符都是相反的，但单词位置是正确的。 
2. **初始化一个指针`start`** 跟踪每个单词的开头。 使用索引迭代数组`end`。 
3. **识别单词边界**。 当你遇到一个空间`' '`或到达数组末尾，当前单词从`start`到`end - 1`。 反转该范围内的字符以恢复原始词序。 
4. **更新`start`** 到空格后的索引，开始跟踪下一个单词。 
5. 继续此过程，直到所有单词都被单独颠倒。 最后，数组`s`包含相反顺序的单词，每个单词的字符顺序正确。 

**为什么有效**：反转整个数组，以相反的顺序正确定位单词，但翻转字符。 单独反转每个单词会恢复每个单词内的字符顺序，从而产生所需的输出。 这种方法保证了正确性，因为两个反转在一起相当于反转词序，同时保持单词字符完整。 

## Python 解决方案```python
from typing import List

class Solution:
    def reverseWords(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        def reverse(l: int, r: int) -> None:
            while l < r:
                s[l], s[r] = s[r], s[l]
                l += 1
                r -= 1

        # Step 1: Reverse the entire array
        reverse(0, len(s) - 1)

        # Step 2: Reverse each word individually
        start = 0
        for end in range(len(s) + 1):
            if end == len(s) or s[end] == ' ':
                reverse(start, end - 1)
                start = end + 1
```**实现说明**：辅助函数`reverse`交换数组中两个索引之间的字符。 我们首先反转整个数组，以相反的顺序放置单词。 然后，我们遍历数组，检测空格以找到单词边界，并就地反转每个单词。 使用`len(s) + 1`在循环中确保最后一个单词在以下情况下被反转`end`达到数组长度。 

## 解决方案```go
func reverseWords(s []byte) {
    // Helper function to reverse a segment of the array
    reverse := func(l, r int) {
        for l < r {
            s[l], s[r] = s[r], s[l]
            l++
            r--
        }
    }

    // Step 1: Reverse the entire array
    reverse(0, len(s)-1)

    // Step 2: Reverse each word individually
    start := 0
    for end := 0; end <= len(s); end++ {
        if end == len(s) || s[end] == ' ' {
            reverse(start, end-1)
            start = end + 1
        }
    }
}
```**Go 特定注释**：逻辑反映了 Python 解决方案。 Go中的切片是可变的，所以我们可以修改`s`就地。 我们使用内联辅助函数进行反转。 与 Python 不同，不需要类型提示。 使用`end <= len(s)`确保最后一个单词正确反转。 

## 工作示例

 **示例1**：`s = ["t","h","e"," ","s","k","y"," ","i","s"," ","b","l","u","e"]`步骤 1：反转整个数组：```
["e","u","l","b"," ","s","i"," ","y","k","s"," ","e","h","t"]
```第 2 步：单独反转每个单词：

 1. 反转`["e","u","l","b"]`→`["b","l","u","e"]`2. 反转`["s","i"]`→`["i","s"]`3. 反转`["y","k","s"]`→`["s","k","y"]`4. 反转`["e","h","t"]`→`["t","h","e"]`最终数组：```
["b","l","u","e"," ","i","s"," ","s","k","y"," ","t","h","e"]
```**示例2**：`s = ["a"]`步骤 1：反转整个数组 → 不变。 

步骤 2：单独反转每个单词 → 不变。 

最终数组：```
["a"]
```## 复杂度分析
