[LeetCode 第 140 题](https://leetcode.com/problems/word-break-ii/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、字符串、动态规划、回溯、Trie、记忆化

 ## 解决方案

 ## 问题理解

 该问题要求我们对给定的字符串进行分段`s`进入所有可能的句子，其中句子中的每个单词都存在于给定的字典中`wordDict`。 本质上，我们需要找到**在字符串中插入空格的所有方法**，以便每个结果子字符串都是有效的字典单词。 输出应该是一个字符串列表，每个字符串代表一个有效的句子。 

输入`s`是一串小写英文字母。 这`wordDict`是唯一小写单词的列表，可以多次重复使用。 该问题确保输出的总长度不会超过 10^5 个字符，这暗示即使存在多种组合，总输出也是可控的。 长度为`s`最多为 20，因此我们可以进行递归或回溯，但需要小心避免冗余计算。 

重要的边缘情况包括：

 1. 根本无法分段的字符串（例如“catsandog”）。 
2. 字典中在字符串中重叠的单词（例如“catsanddog”中的“cat”和“cats”）。 
3. 空字典或空字符串（尽管约束保证至少有一个字符）。 

挑战在于**有效地找到所有组合**，避免在探索重叠子问题时重复工作。 

## 方法

 ### 蛮力

 暴力解决方案尝试在每个可能的索引处拆分字符串，并递归检查左子字符串是否是有效单词并继续处理右子字符串。 对于每个有效的分割，它递归地组合结果。 虽然正确，但这种方法会产生许多重叠的子问题，因为同一子字符串可以被评估多次。 其时间复杂度随着长度的增加呈指数级增长`s`，即使对于长度为 20 的相对较小的字符串也是不切实际的。 

### 优化方法：通过记忆进行回溯

 关键的见解是许多子问题会重复：例如，如果需要分解“sanddog”，我们可能会在不同的递归路径中多次评估它。 通过**将先前计算的结果存储在哈希映射中（记忆）**，我们可以避免重新计算。 这将复杂性从指数级降低到可管理的水平。 

此外，使用字典集允许 O(1) 查找，这在重复检查子字符串有效性时至关重要。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归地尝试所有可能的分割，字符串长度呈指数 |
 | 最佳| O(n * 2^n) | O(n * 2^n) | O(n * 2^n) | O(n * 2^n) | 记忆回溯减少重复工作； 字典集允许快速查找|

 ## 算法演练

 1. 转换`wordDict`到 O(1) 查找的集合。 
2. 定义递归辅助函数`dfs(start)`返回子字符串的所有有效句子`s[start:]`。 
3.如果`start`到达字符串末尾，返回一个包含空字符串作为基本情况的列表。 
4.检查当前是否`start`已经在备忘录字典中计算过了。 如果是，则返回缓存的结果。 
5.初始化一个空列表`sentences`存储此起始索引的结果。 
6. 循环遍历`end`从`start + 1`到`len(s) + 1`。 提取子串`word = s[start:end]`。 
7. 如果`word`字典里有，递归调用`dfs(end)`获取剩余字符串的所有句子。 
8. 对于递归中的每个句子，连接`word`和句子（如果句子不为空则用空格）并附加到`sentences`。 
9. 商店`sentences`在备忘录字典中键入`start`。 
10. 返回`sentences`。 

为什么它有效：每个递归调用都会为从 开始的子字符串构造所有有效句子`start`。 记忆化保证每个子字符串最多被处理一次。 通过将有效单词与后续子串的结果相结合，我们生成所有有效句子，不会遗漏任何句子。 

## Python 解决方案```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        word_set = set(wordDict)
        memo = {}
        
        def dfs(start: int) -> List[str]:
            if start in memo:
                return memo[start]
            
            if start == len(s):
                return [""]
            
            sentences = []
            for end in range(start + 1, len(s) + 1):
                word = s[start:end]
                if word in word_set:
                    for subsentence in dfs(end):
                        if subsentence:
                            sentences.append(word + " " + subsentence)
                        else:
                            sentences.append(word)
            
            memo[start] = sentences
            return sentences
        
        return dfs(0)
```该实现使用了递归`dfs`函数探索从每个索引开始的每个有效分段。 通过将结果存储在`memo`，重复的子串仅计算一次。 嵌套循环根据字典检查每个子字符串，并将有效单词与递归结果组合以形成完整的句子。 

## 解决方案```go
package main

func wordBreak(s string, wordDict []string) []string {
    wordSet := make(map[string]bool)
    for _, word := range wordDict {
        wordSet[word] = true
    }
    
    memo := make(map[int][]string)
    
    var dfs func(start int) []string
    dfs = func(start int) []string {
        if val, exists := memo[start]; exists {
            return val
        }
        if start == len(s) {
            return []string{""}
        }
        
        sentences := []string{}
        for end := start + 1; end <= len(s); end++ {
            word := s[start:end]
            if wordSet[word] {
                for _, subsentence := range dfs(end) {
                    if subsentence != "" {
                        sentences = append(sentences, word + " " + subsentence)
                    } else {
                        sentences = append(sentences, word)
                    }
                }
            }
        }
        memo[start] = sentences
        return sentences
    }
    
    return dfs(0)
}
```Go 的实现与 Python 版本非常相似。 一个映射用于记忆，另一个映射存储字典单词以供快速查找。 Go 可以高效地处理切片，因此我们将句子附加到切片而不是列表中。 空字符串处理可确保正确插入空格。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * 2^n) | O(n * 2^n) | 每个子串可以分支成多个有效单词。 记忆化确保每个起始索引都被处理一次。 |
 | 空间| O(n * 2^n) | O(n * 2^n) | Memo 存储每个起始索引的句子列表； 递归堆栈最多可达 n。 |

 尽管最坏情况下有效分割的数量呈指数增长，但记忆化显着减少了重新计算，从而使得`s.length <= 20`。
