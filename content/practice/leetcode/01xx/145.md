 ## 解决方案

 ## 问题理解

 该问题要求我们返回二叉树的后序遍历。 

二叉树由节点组成，其中每个节点包含：

 - 一个值
 - 指向左孩子的指针
 - 指向右孩子的指针

 在后序遍历中，我们必须按照以下顺序访问节点：

 1. 遍历左子树
 2. 遍历右子树
 3.访问当前节点

 这种排序很重要，因为节点本身只有在其两个子节点都已被处理之后才会被处理。 

例如，考虑树：```
    1
     \
      2
     /
    3
```遍历顺序变为：

 - 访问 1 的左子树，该子树为空
 - 访问以 2 为根的右子树

 - 访问以 3 为根的左子树
 - 访问 2 的右子树，该子树为空
 - 访问节点2
 - 访问节点1

 结果：```
[3, 2, 1]
```输入作为二叉树的根节点给出。 输出应该是一个包含后序序列中的节点值的列表。 

约束很小，最多 100 个节点，因此即使是递归解决方案也很容易满足大多数语言的递归深度限制。 然而，后续内容特别要求迭代解决方案，这意味着我们应该了解如何使用堆栈手动模拟递归。 

一些边缘情况很重要：

 - 树可能是空的，这意味着`root = []`- 树可能只包含一个节点
 - 树可能完全向左或向右倾斜
 - 节点可能包含负值
 - 有些孩子可能会`null`当其他人存在时

 如果过早访问当前节点，幼稚的实现很容易产生错误的排序。 后序遍历需要延迟节点处理，直到两个子树都完成之后。 

## 方法

 ### 蛮力方法，递归 DFS

 最简单的解决方案使用递归。 

在每个节点：

 1.递归遍历左子树
 2. 递归遍历右子树
 3. 将当前节点的值附加到结果中

 这很自然，因为函数调用堆栈会自动记住每个子树完成后返回的位置。 递归结构反映了后序遍历本身的定义。 

这种方法是正确的，因为每个节点只有在其左右后代都已被处理之后才会被处理。 

尽管问题约束很小，但递归使用与树高度成比例的隐式堆栈空间。 后续还明确询问我们是否可以迭代执行，这意味着我们应该了解如何用显式堆栈数据结构替换递归调用堆栈。 

### 最优方法，使用堆栈的迭代 DFS

 迭代方法使用堆栈手动模拟递归。 

一种常见的技术是：

 - 以修改后的预购顺序处理节点：

 - 根
 - 右
 - 左
 - 存储访问过的值
 - 反转最终结果

 为什么这有效？ 

正常的前序遍历是：```
Root -> Left -> Right
```如果我们改为遍历：```
Root -> Right -> Left
```然后将结果反转，我们得到：```
Left -> Right -> Root
```这正是后序遍历。 

这种方法很优雅，因为它避免了复杂的状态跟踪。 堆栈自然地处理遍历顺序，并且反转结果会产生所需的序列。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(h) | 使用调用堆栈的递归 DFS |
 | 最佳| O(n) | O(n) | 使用显式堆栈和结果反转的迭代 DFS |

 这里：

-`n`是节点数
 -`h`是树的高度

 ## 算法演练

 ### 迭代后序遍历

 1. 创建一个空结果列表。 

该列表将以修改后的预序顺序临时存储节点。 
2. 处理空树箱。 

如果根是`None`，立即返回一个空列表。 
3. 以根节点初始化堆栈。 

堆栈模拟递归DFS遍历。 
4. 当堆栈不为空时，继续处理节点。 

每次迭代处理堆栈中的一个节点。 
5. 从堆栈中弹出顶部节点。 

该节点成为当前正在处理的节点。 
6. 将当前节点的值追加到结果列表中。 

我们有意在其子节点之前处理该节点。 这会产生：```
Root -> Right -> Left
```7. 如果左子节点存在，则将其推入堆栈。 

我们先向左推，因为堆栈是后进先出的。 这确保了右子节点在左子节点之前得到处理。 
8. 将右子节点压入堆栈（如果存在）。 

由于右子节点是最后推送的，因此它首先被处理。 
9. 遍历结束后，反转结果列表。 

生成的遍历顺序为：```
Root -> Right -> Left
```反转给出：```
Left -> Right -> Root
```这是正确的后序遍历。 
10. 返回反转后的结果列表。 

### 为什么它有效

 该算法保证了正确性，因为按照临时顺序，每个节点都在其子节点之前被访问。 反转该顺序可确保每个节点都出现在其左子树和右子树之后，与后序遍历的定义完全匹配。 

堆栈确保每个节点只处理一次，并且反转将修改后的前序遍历转换为真正的后序遍历。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        result = []
        stack = [root]

        while stack:
            node = stack.pop()
            result.append(node.val)

            if node.left:
                stack.append(node.left)

            if node.right:
                stack.append(node.right)

        return result[::-1]
```实现首先处理空树的情况。 如果根是`None`，遍历结果只是一个空列表。 

堆栈是用根节点初始化的。 堆栈控制遍历顺序并取代递归函数调用。 

在循环内，我们重复从堆栈中弹出节点并将它们的值附加到结果列表中。 关键细节是子项被推送的顺序：

 - 左孩子优先
 - 右孩子第二

 由于堆栈是后进先出的，因此右子级会先于左子级处理。 

这会产生如下的遍历顺序：```python
Root -> Right -> Left
```最后将结果列表倒转得到：```python
Left -> Right -> Root
```这是所需的后序遍历。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func postorderTraversal(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }

    result := []int{}
    stack := []*TreeNode{root}

    for len(stack) > 0 {
        n := len(stack) - 1
        node := stack[n]
        stack = stack[:n]

        result = append(result, node.Val)

        if node.Left != nil {
            stack = append(stack, node.Left)
        }

        if node.Right != nil {
            stack = append(stack, node.Right)
        }
    }

    // Reverse result
    left, right := 0, len(result)-1
    for left < right {
        result[left], result[right] = result[right], result[left]
        left++
        right--
    }

    return result
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 对堆栈和结果列表都使用切片。 由于Go没有提供内置的堆栈结构，因此堆栈是使用切片追加和切片操作来实现的。 

与Python不同`[::-1]`，Go需要使用两个指针手动反转切片。 

空树情况返回一个空切片而不是`nil`，这符合 LeetCode 的预期行为。

 ## 边缘情况

 ### 空树

 一棵空树表示为`root = None`。 这是错误的常见来源，因为遍历循环可能假设根存在并尝试访问诸如`root.left`。 

实现立即处理这个问题：```
if not root:
    return []
```这保证了安全行为并返回正确的空遍历。 

### 单节点树

 A tree with only one node has no children. 某些实现错误地尝试子树遍历而不检查`None`。 

在这种情况下：

 - 该节点被添加到结果中
 - 没有孩子被推入堆栈
 - 反转单元素列表使其保持不变

 算法正确返回`[node.val]`。 

### 高度倾斜的树

 一棵树可能类似于一个链表，要么完全左偏，要么右偏。 

例如：```
1
 \
  2
   \
    3
```这些情况很重要，因为遍历顺序更容易被意外破坏。 

基于堆栈的实现可以按照修改后的前序顺序正确处理节点，并在最后反转结果，从而确保正确的后序遍历，无论树的形状如何。 

### 失踪儿童的树

 有些节点可能只有一个子节点。 

例子：```
    1
   /
  2
   \
    3
```天真的实现可能会错误地假设两个孩子都存在。 

实现明确检查：```
if node.left:
```和```
if node.right:
```在将子项推入堆栈之前，防止无效访问，同时保留正确的遍历顺序。
