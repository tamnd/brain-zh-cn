 **难度：** 🟡 中等
 **主题：** 数组、哈希表、并查

 ## 解决方案

 ## 问题理解

 该问题要求我们找到未排序数组中最长的连续整数序列的长度。 连续序列是指数字依次出现，无论它们在数组中的位置如何。 输入中的数字不需要相邻，并且数组本身未排序。 

简单来说，我们想要确定最大的整数链，其中每个数字与下一个数字的相差恰好`1`。 例如，如果数组包含`[1, 2, 3, 4]`，序列长度为`4`。 如果数字比较分散，比如`[100, 4, 200, 1, 3, 2]`，我们仍然认识到`[1, 2, 3, 4]`形成一个连续的长度序列`4`。 

输入是一个整数数组`nums`，其中可能包含重复值并且可能包含负数。 输出应该是一个整数，表示数组中找到的任何连续序列的最大长度。 

约束在这里尤为重要：

 -`0 <= nums.length <= 10^5`-`-10^9 <= nums[i] <= 10^9`该数组最多可以包含`100,000`元素，这意味着嵌套循环或基于重复排序的搜索等低效方法可能会变得太慢。 该问题明确要求`O(n)`时间解决方案，它立即排除了许多传统的排序方法`O(n log n)`复杂。 

尽早识别一些边缘情况很重要：

 应该返回一个空数组`0`因为没有序列。 

单元素数组应该返回`1`，因为任何数字本身都会形成一个连续的长度序列`1`。 

可能会出现重复值，但不应错误地增加序列长度。 例如，`[1,0,1,2]`包含重复的`1`s，但最长的序列仍然是`[0,1,2]`与长度`3`。 

必须正确处理负整数。 例如，`[-2,-1,0,1]`形成有效的连续长度序列`4`。 

数字之间的巨大差距应该不重要。 由于数组未排序，连续关系仅取决于数字邻接，而不取决于索引位置。 

## 方法

 ### 蛮力方法

 一个简单的想法是将每个数字视为潜在的起点，并重复检查下一个连续数字是否存在。 

对于每个数字`x`，我们会寻找`x + 1`， 然后`x + 2`，并继续直到序列中断。 由于数组未排序，因此每次查找都需要扫描整个数组以确定某个值是否存在。 

例如，与`[100,4,200,1,3,2]`，从`1`需要检查是否`2`存在，那么`3`， 然后`4`， 等等。 每次查找都很昂贵，因为它涉及遍历数组。 

这种方法是正确的，因为它最终会探索所有可能的序列，但效率很低。 在最坏的情况下，每次查找都会花费`O(n)`并且对于许多元素重复发生，导致`O(n²)`时间复杂度。 

### 最佳解决方案的关键见解

 主要的观察是，我们只需要在序列开始时开始计数。 

假设我们有一个序列`[1,2,3,4]`。 如果我们从每个元素开始扩展，我们就会重复不必要的工作：

 - 开始于`1`发现整个序列。 
- 开始于`2`重复大部分工作。 
- 开始于`3`再次重复。 

相反，我们应该只从没有前任的数字开始序列扩展。 

例如：

-`1`是一个有效的起点，因为`0`不存在。 
-`2`不是起点，因为`1`存在。 
-`3`不是起点，因为`2`存在。 

为了使存在性检查有效，我们将所有数字存储在哈希集中。 哈希集提供平均值`O(1)`查找时间，让我们能够快速判断一个数字是否存在。 

这给了我们一个`O(n)`算法，因为每个数字最多参与序列扩展一次。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 重复扫描数组以查找连续值 |
 | 最佳| O(n) | O(n) | 使用哈希集并且仅从序列开始扩展 |

 ## 算法演练

 ### 最优哈希集方法

 1. 创建一个包含输入数组中每个数字的哈希集。 

我们使用哈希集是因为成员资格检查，例如`x in set`取平均值`O(1)`时间。 这使我们能够有效地确定是否存在连续的数字。 
2. 初始化变量`longest_streak = 0`。 

该变量跟踪迄今为止找到的最大序列长度。 
3. 迭代哈希集中的每个数字。 

我们迭代集合而不是原始数组，以避免重复导致的冗余处理。 
4. 检查当前编号是否为序列的开头。 

一个数字`x`仅当`x - 1`不存在于集合中。 

此步骤至关重要，因为它避免了多次重新处理序列。 
5. 如果该数字是序列开始，则开始计算连续数字。 

初始化：

 -`current_number = x`-`current_streak = 1`然后反复检查是否`current_number + 1`存在于集合中。 
6. 尽可能扩展序列。 

只要下一个连续数字存在：

 - 增量`current_number`- 增量`current_streak`这一直持续到序列中断为止。 
7. 更新最大序列长度。 

比较`current_streak`和`longest_streak`并保留较大的值。 
8. 返回`longest_streak`处理完所有数字后。 

### 为什么它有效

 关键的不变量是每个连续序列恰好有一个有效的起点，即该序列中的最小数字。 通过仅从没有前身的数字扩展序列，我们保证每个序列都被恰好探索一次。 

由于扩容时每个号码最多访问一次，因此不会发生不必要的重复工作。 这确保了正确性和线性时间复杂度。 

## Python 解决方案```python
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        number_set = set(nums)
        longest_streak = 0

        for number in number_set:
            # Only start a sequence if this is the beginning
            if number - 1 not in number_set:
                current_number = number
                current_streak = 1

                while current_number + 1 in number_set:
                    current_number += 1
                    current_streak += 1

                longest_streak = max(longest_streak, current_streak)

        return longest_streak
```实现首先将输入数组转换为一个名为的集合`number_set`。 这会删除重复项并启用恒定时间的成员资格检查。 

变量`longest_streak`跟踪迄今为止看到的最佳答案。 

该循环遍历集合中的每个数字。 在尝试构建序列之前，算法会检查是否`number - 1`存在。 如果是，则当前数字不是序列的开头，因此会被跳过。 

当找到有效的起始点时，算法会初始化序列计数器并重复检查下一个连续数字。 每次成功的查找都会增加序列长度。 

完全扩展序列后，将结果与`longest_streak`。 处理结束时，返回最大序列长度。 

## 解决方案```go
func longestConsecutive(nums []int) int {
	numberSet := make(map[int]bool)

	for _, num := range nums {
		numberSet[num] = true
	}

	longestStreak := 0

	for num := range numberSet {
		// Only start if this is the beginning
		if !numberSet[num-1] {
			currentNum := num
			currentStreak := 1

			for numberSet[currentNum+1] {
				currentNum++
				currentStreak++
			}

			if currentStreak > longestStreak {
				longestStreak = currentStreak
			}
		}
	}

	return longestStreak
}
```Go 的实现与 Python 解决方案非常相似。 由于 Go 没有内置的哈希集，因此`map[int]bool`用于模拟一个。 

检查存在性时，Go 映射返回零值`false`对于丢失的键，这使得表达式如`numberSet[num-1]`方便会员测试。 

无需特殊处理`nil`或空切片。 如果`nums`为空，映射保持为空，循环永远不会执行，并且函数正确返回`0`。 

整数溢出在这里不是问题，因为问题约束安全地保持在 Go 的整数范围内。

 ## 边缘情况

 ### 空数组

 空输入数组是一种重要的边缘情况，因为没有要处理的数字。 幼稚的实现可能会意外地错误地初始化答案或假设至少存在一个元素。 在此实现中，集合为空，循环永远不会执行，并且`longest_streak`遗迹`0`，正确返回。 

### 重复值

 如果处理不当，重复可能会引入微妙的错误。 例如，`[1,0,1,2]`包含两个`1`s，但最长的序列仍然只有`[0,1,2]`。 通过将输入转换为集合，重复项将被自动删除，从而防止重复工作或序列长度膨胀。 

### 负数

 由于整数可以为负数，因此算法必须正确识别负值之间的连续关系。 例如，`[-3,-2,-1,0,1]`形成一个有效的长度序列`5`。 该实现自然有效，因为算术比较，例如`number - 1`和`number + 1`对于负值，行为相同。 

### 没有连续元素

 有些数组可能包含完全不相关的数字，例如`[10,30,20]`。 在这些情况下，每个数字都有自己的长度序列`1`。 该算法可以正确处理此问题，因为每个值都可以作为起点，但不会发生扩展。 

### 非常长的连续序列

 包含大型连续链的输入，例如`[1,2,3,...,100000]`，强调表现。 一个幼稚的解决方案会重复地重新访问相同的元素，从而导致运行时间很差。 该实现通过仅从序列开始扩展来避免冗余，保留所需的`O(n)`即使对于最大尺寸的输入也具有复杂性。
