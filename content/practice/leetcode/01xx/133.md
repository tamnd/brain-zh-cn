 # Clone Graph

 ## 问题理解

 这个问题要求我们创建一个无向连通图的深层副本。 我们获得了对图中一个节点的引用，并且我们必须返回整个图结构的完全独立的副本。 

Each graph node contains two pieces of information:

 -`val`，唯一标识节点的整数
 -`neighbors`，相邻节点的列表

 深层复制意味着克隆图必须包含全新的节点对象。 克隆的节点应保留与原始图完全相同的连接结构，但原始节点对象不能被重用。 

该图在概念上表示为邻接列表。 例如：```
[[2,4],[1,3],[2,4],[1,3]]
```means:

 - 节点 1 连接到节点 2 和 4
 - 节点 2 连接到节点 1 和 3
 - 节点 3 连接到节点 2 和 4
 - 节点 4 连接到节点 1 和 3

 重要的是图表可能包含循环。 与每个节点都有一个父节点的树不同，图可以通过不同的路径重新访问以前看到的节点。 这是问题的核心挑战。 

限制相对较小：

 - 最多100个节点
 - Node values are unique
 - No self loops
 - No duplicate edges
 - 图形已连接

 即使图很小，没有循环处理的简单递归解决方案也会失败，因为循环图可能导致无限递归。 

必须谨慎处理几个重要的边缘情况：

 - 输入节点可以是`None`，代表一个空图
 - 该图可能包含没有邻居的单个节点
 - 图表可能包含循环
 - 多个节点可能引用同一个邻居，需要一致地重用克隆节点

 The key challenge is ensuring that every original node maps to exactly one cloned node.

 ## 方法

 ### 蛮力方法

 一种简单的方法是递归地克隆每个节点及其邻居，而不跟踪哪些节点已被复制。 

该算法看起来像这样：

 1.创建当前节点的克隆
 2. 递归克隆每个邻居
 3. Attach the cloned neighbors to the cloned node

 乍一看，这似乎是合理的，因为递归自然地遵循图的边缘。 

然而，当循环存在时，这种方法会立即失效。 

考虑这个图：```
1 -- 2
```由于图是无向的：

 - 节点 1 引用节点 2
 - 节点 2 引用节点 1

 如果我们递归地克隆邻居而不记住以前克隆的节点：

 - 克隆节点 1 克隆节点 2
 - 克隆节点2再次克隆节点1
 - 克隆节点1再次克隆节点2
 - 这将永远持续下去

 即使以某种方式阻止了无限递归，该算法也会错误地创建同一逻辑节点的多个副本。 

核心问题是图不是层次结构。 可以通过不同的遍历路径重新访问节点。 

### 最佳方法

 关键的一点是每个原始节点必须恰好对应一个克隆节点。 

这自然建议使用哈希图：```
original node -> cloned node
```每当我们遇到一个节点时：

 - 如果已经被克隆，则重复使用现有的克隆
 - 否则：

 - 创建一个新的克隆
 - 立即将其存储在哈希图中
 - 递归克隆其邻居

 这解决了两个主要问题：

 - 防止循环图中的无限递归
 - 通过重用克隆节点确保结构一致性

 我们可以使用 DFS 或 BFS 遍历来实现这一点。 带有递归的 DFS 是最简洁、最自然的解决方案。

 ## 算法演练

 ### DFS + 哈希图算法

 1. 首先，处理空图情况。 

如果输入节点是`None`， 返回`None`立即，因为没有什么可以克隆。 
2. 创建哈希映射来存储从原始节点到克隆节点的映射。 

该图是算法的核心。 它保证每个原始节点都被克隆一次。 

例子：```
visited[original_node] = cloned_node
```3. 定义递归DFS 函数。 

DFS 函数接收原始节点并返回其克隆版本。 
4. 在DFS函数中，首先检查节点是否已经被克隆。 

如果该节点存在于哈希图中，则立即返回之前创建的克隆。 

这可以防止：

 - 无限递归
 - 重复节点创建
 5. 如果该节点尚未被克隆，则创建一个新的克隆节点。 

最初，克隆的节点具有：

 - 相同的值
 - 空的邻居列表
 6. 立即将克隆存储在哈希图中。 

这一步很关键。 

我们在处理邻居之前存储克隆，以便循环引用可以在递归期间安全地重用它。 
7. 遍历当前节点的所有邻居。 

对于每个邻居：

 - 使用DFS递归克隆它
 - 将克隆的邻居追加到当前克隆节点的邻居列表中
 8. 处理完所有邻居后，返回克隆节点。 
9. 从输入节点启动DFS并返回生成的克隆。 

### 为什么它有效

 该算法保持了哈希映射中每个原始节点都映射到恰好一个克隆节点的不变性。 

每当通过另一条遍历路径重新访问节点时，都会重用现有的克隆，而不是创建新的克隆。 由于每条边都是使用这些一致的克隆参考重建的，因此最终的图保留了原始图的精确结构。 

由于该算法仅访问每个节点和边一次，因此它可以正确克隆循环图，而无需无限递归。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val = 0, neighbors = None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []
"""

from typing import Optional

class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if not node:
            return None

        cloned_nodes = {}

        def dfs(current: 'Node') -> 'Node':
            if current in cloned_nodes:
                return cloned_nodes[current]

            clone = Node(current.val)
            cloned_nodes[current] = clone

            for neighbor in current.neighbors:
                clone.neighbors.append(dfs(neighbor))

            return clone

        return dfs(node)
```实现从处理空图情况开始。 如果输入节点是`None`，函数立即返回`None`。 

这`cloned_nodes`字典充当原始节点与其克隆对应节点之间的映射。 这是防止重复克隆和无限递归的机制。 

递归`dfs`函数执行实际的图遍历和克隆。 

里面的第一次操作`dfs`检查当前节点是否已被克隆。 If so, the stored clone is returned immediately.

 If the node has not been cloned yet, a new`Node`使用相同的值创建实例。 在处理邻居之前，克隆将存储在字典中。 这种排序至关重要，因为循环图可能在递归期间重新访问节点。 

然后该算法迭代当前节点的每个邻居。 每个邻居都会被递归地克隆，并将生成的克隆邻居附加到当前克隆的邻居列表中。 

最后，返回输入节点的克隆版本。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Neighbors []*Node
 * }
 */

func cloneGraph(node *Node) *Node {
    if node == nil {
        return nil
    }

    clonedNodes := make(map[*Node]*Node)

    var dfs func(*Node) *Node

    dfs = func(current *Node) *Node {
        if clone, exists := clonedNodes[current]; exists {
            return clone
        }

        clone := &Node{
            Val: current.Val,
        }

        clonedNodes[current] = clone

        for _, neighbor := range current.Neighbors {
            clone.Neighbors = append(clone.Neighbors, dfs(neighbor))
        }

        return clone
    }

    return dfs(node)
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

主要区别在于 Go 使用显式指针类型：```go
map[*Node]*Node
```该映射存储指向原始节点的指针和指向克隆节点的指针。 

Go 还需要为邻居列表显式附加切片：```go
clone.Neighbors = append(clone.Neighbors, dfs(neighbor))
```空图情况的处理使用`nil`而不是Python的`None`。 

由于节点值是小整数并且不执行算术运算，因此整数溢出不是该问题的问题。

 ## 边缘情况

 ### 空图

 输入可能是`None`，表示没有节点的图。 

这种情况很容易被忽视，因为许多图算法都假设至少存在一个节点。 尝试访问邻居`None`对象会立即导致错误。 

该实现通过以下方式安全地处理此问题：```
if not node:
    return None
```这确保了算法在任何遍历逻辑开始之前退出。 

### 循环图

 图通常包含环，尤其是无向图。 

如果不跟踪访问的节点，递归将永远重复地重新访问相同的节点，最终导致堆栈溢出或无限递归。 

哈希映射通过在创建后立即存储克隆节点来防止此问题。 每当重新访问节点时，都会重用现有的克隆，而不是再次递归克隆。 

这是问题中最重要的正确性条件。 

### 对同一节点的多个引用

 一个图可能包含通往同一节点的多条路径。 

例如：```
1 -> 2
 \  /
  3
```如果每次遇到节点时实现都会创建一个新的克隆，则克隆图将错误地包含节点 3 的重复版本。 

哈希图保证原始节点和克隆节点之间的一一对应，准确地保留图结构。
