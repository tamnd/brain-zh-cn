[LeetCode 第 107 题](https://leetcode.com/problems/binary-tree-level-order-traversal-ii/)

 **难度：** 🟡 中等
 **主题：** 树、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们遍历二叉树并逐层返回节点值，但按**自下而上的顺序**。 通常，级别顺序遍历会收集从根到叶的值。 在这里，我们需要颠倒该顺序并首先返回叶级别，然后向上移动到根。 

输入是由根节点表示的标准二叉树。 每个节点都包含一个整数值以及指向其左子节点和右子节点的指针。 输出是一个整数列表的列表，其中每个内部列表对应于树中的一个级别，从最底层开始一直向上移动到根。 

约束指定树最多可以有 2000 个节点，节点值范围从 -1000 到 1000。这表明算法理想情况下应该以相对于节点数的线性时间运行。 边缘情况包括一棵空树（`root = None`）和只有一个节点的树。 

## 方法

 暴力方法将执行标准的级别顺序遍历 (BFS)，从上到下将每个级别存储在列表中。 收集完所有级别后，我们可以在最后反转级别列表。 虽然这有效，但它使用额外的空间来存储关卡和额外的反向操作。 它是正确的，但在空间和后处理方面效率稍低。 

最佳解决方案的关键见解是，我们仍然可以执行 BFS，但在遍历时**将每个级别添加到结果列表**。 这样，底部级别自然会出现在结果列表的开头，从而无需单独的反向操作。 BFS 确保我们逐级访问节点，而前置则有效地保留了自下而上的顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 自上而下执行BFS并在最后反转列表 |
 | 最佳| O(n) | O(n) | 执行 BFS 并将每个级别添加到结果列表中 |

 ## 算法演练

 1. **处理边缘情况：** 如果`root`是`None`，立即返回一个空列表。 这可以防止对空树进行不必要的处理。 
2. **初始化BFS结构：** 使用队列来促进BFS。 首先将根节点放入队列。 创建一个空结果列表以按自下而上的顺序存储级别。 
3. **处理每一层：** 当队列不为空时，判断当前层的节点数（`level_size`）。 创建一个临时列表来存储该级别的值。 
4. **遍历当前级别的节点：** 对于该级别中的每个节点，将其出队，将其值添加到临时列表中，并将其非空左子节点和右子节点入队。 
5. **前置级别：** 当前级别的所有节点都处理完毕后，将临时列表插入到结果列表的**开始**处。 这确保了自下而上的排序，而不会在最后反转。 
6. **返回结果：** 队列为空后，处理完所有级别，结果列表包含从下到上的级别。 

**为什么起作用：** BFS保证节点从上到下逐级被访问。 通过将每个级别添加到结果中，最后的级别（叶子）自然会首先出现，满足自下而上的要求。 每个节点只访问一次，确保正确性和效率。 

## Python 解决方案```python
from typing import List, Optional
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            level = []
            for _ in range(level_size):
                node = queue.popleft()
                level.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            result.insert(0, level)  # Prepend the current level
        
        return result
```Python 实现使用`deque`用于高效的队列操作。 每个级别的节点都收集在一个临时列表中，然后插入到结果列表的开头以保持自下而上的顺序。 像空树这样的边缘情况是预先处理的。 

## 解决方案```go
package main

/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func levelOrderBottom(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }
    
    result := [][]int{}
    queue := []*TreeNode{root}
    
    for len(queue) > 0 {
        levelSize := len(queue)
        level := []int{}
        
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            level = append(level, node.Val)
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        
        // Prepend level
        result = append([][]int{level}, result...)
    }
    
    return result
}
```在Go中，切片用于模拟队列，并且在前面添加切片是通过串联完成的。`nil`检查取代Python的`None`检查，切片动态增长以存储每个级别。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 在 BFS 中每个节点只被访问一次 |
 | 空间| O(n) | 队列最后一层最多可以存储n/2个节点，结果列表存储所有节点 |

 复杂度是线性的，因为每个节点都被处理一次，并且所有级别都存储在内存中。

 ## 边缘情况

 **空树：** 如果根是`None`，队列永远不会用节点初始化。 该算法立即返回一个空列表，防止空引用错误。 

**单节点树：** 仅存在一个节点。 BFS 循环运行一次，添加一个包含单个元素的列表并在其前面添加。 结果是正确的，表明该算法可以处理最少的输入。 

**高度不平衡的树：**向左或向右倾斜的树可能会破坏简单的索引方法。 我们的 BFS 方法使用队列，它自然地通过跳过来处理丢失的子进程`None`/`nil`节点，确保正确的自下而上排序，无需额外检查。
