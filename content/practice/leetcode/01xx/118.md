 ## 解决方案

 ## 问题理解

 问题是要求我们生成第一个`numRows`**帕斯卡三角形**，它是数字的三角形排列，其中每个数字都是其正上方两个数字的总和。 第一行始终是`[1]`，第二行`[1, 1]`，后续行是通过将前一行中的相邻数字对相加而构建的，其中`1`在每行的两端。 

输入`numRows`是一个 1 到 30 之间的整数，它指定我们必须生成多少行帕斯卡三角形。 输出是一个二维列表或切片，其中每个内部列表代表三角形的一行。 

重要的边缘情况包括最小输入`numRows = 1`（应该返回`[[1]]`) 和小行，其中总和不需要复杂的计算。 约束足够小，简单的迭代解决方案将有效地工作，但求和中间元素的正确性至关重要。 

## 方法

 强力方法涉及通过递归地求和其上方的元素来计算三角形的每个元素。 虽然正确，但递归会增加不必要的开销，并且对于较大的情况可能效率低下`numRows`。 每次调用都会重复重新计算总和，从而导致冗余计算。 

最佳方法依赖于我们可以从前一行迭代地构建每一行的观察。 每行开始和结束于`1`，每个内部元素是前一行中其上方两个元素的总和。 这消除了递归或重新计算的需要，并确保了 O(numRows^2) 解决方案，因为每个元素只计算一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力（递归）| O(2^n) | O(2^n) | O(n) | 递归地对每个元素的值求和； 大型企业效率低下`numRows`|
 | 最优（迭代）| O(行数^2) | O(行数^2) | 使用前一行逐行构建三角形； 简单高效|

 ## 算法演练

 1.初始化一个空列表`triangle`保存帕斯卡三角形的所有行。 
2. 循环`i`从 0 到`numRows - 1`生成每一行。 
3. 对于每一行，从长度列表开始`i + 1`充满了1s。 第一个和最后一个元素始终为 1。 
4. 对于每个位置`j`从 1 到`i - 1`， 放`row[j] = triangle[i-1][j-1] + triangle[i-1][j]`。 这就是上面两个数字的总和。 
5. 将完成的行附加到`triangle`。 
6.循环结束后，返回`triangle`。 

**为什么有效**：每一行仅使用前一行构建。 由于第一行是`[1]`每行的第一个和最后一个元素是`1`，三角形正确生长。 这保留了所有行的帕斯卡三角形属性。 

## Python 解决方案```python
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        triangle = []
        for i in range(numRows):
            row = [1] * (i + 1)
            for j in range(1, i):
                row[j] = triangle[i - 1][j - 1] + triangle[i - 1][j]
            triangle.append(row)
        return triangle
```这个Python实现初始化一个空列表`triangle`保存所有行。 它从 0 迭代到`numRows - 1`构建每一行。 该行以全 1 开头，然后使用前一行的值更新内部元素。 每个完成的行都附加到`triangle`，最后返回。 

## 解决方案```go
func generate(numRows int) [][]int {
    triangle := make([][]int, 0, numRows)
    for i := 0; i < numRows; i++ {
        row := make([]int, i+1)
        row[0], row[i] = 1, 1
        for j := 1; j < i; j++ {
            row[j] = triangle[i-1][j-1] + triangle[i-1][j]
        }
        triangle = append(triangle, row)
    }
    return triangle
}
```Go 实现反映了 Python 解决方案。 我们预先分配`triangle`切片和每行切片。 该行的第一个和最后一个元素显式设置为 1，内部元素通过对前一行的相应元素求和来计算。 Go 需要显式创建切片，但逻辑在其他方面是相同的。

 ## 边缘情况

 第一个边缘情况是`numRows = 1`，其中仅存在单元素行。 该实现通过初始化长度为 1 的行来处理此问题，其中填充`1`。 内部元素不会发生迭代，从而防止索引错误。 

第二个边缘情况是`numRows = 2`，这确保算法正确处理小三角形。 这里，内部求和循环不执行，因为`i < 2`，所以只设置了第一个和最后一个元素，这是正确的。 

第三个边缘情况是最大尺寸`numRows = 30`。 这测试了正确性和性能。 该算法高效地构造三角形，无需冗余计算，并且不会超出内存限制。 迭代方法确保它随元素数量线性扩展。
