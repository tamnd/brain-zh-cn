 ## 解决方案

 ## 问题理解

 问题是要求我们在二叉树中找到**最大路径和**。 路径定义为由边连接的任何节点序列，其中每个节点**最多包含一次**。 该路径不需要从根开始或从叶结束。 路径的总和只是该路径上节点值的总和。 

输入是二叉树的根，可能包含负值，输出是表示最大可能路径和的单个整数。 约束告诉我们，树可以中等大，最多 30,000 个节点，并且节点值可以为负或正。 这意味着明确考虑每条可能路径的幼稚方法将太慢。 边缘情况包括所有负值的树、具有单个节点的树和倾斜树（类似链表的结构）。 

## 方法

 **暴力方法**将尝试枚举树中所有可能的路径并计算它们的总和。 这将涉及从每个节点开始探索节点的所有组合，这很快就变得不可行，因为二叉树中的路径数量随着节点数量呈指数增长。 虽然它保证了正确性，但对于具有数万个节点的树来说，它太慢了。 

**最佳方法**利用递归深度优先搜索 (DFS) 和一个关键观察：对于任何给定节点，**通过该节点**的最大路径和要么只是节点本身，要么是该节点加上其左子节点的最大路径和，要么是该节点加上其右子节点的最大路径和，要么是该节点加上两个子节点。 但是，当向父级返回值时，我们只能包含**一个分支**（左或右），以避免重用路径中的节点。 这种见解使我们能够使用后序 DFS 遍历有效地计算最大路径和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 探索从每个节点出发的所有可能路径； 对于大树来说速度太慢|
 | 最佳| O(n) | O(h) | 具有后序遍历的 DFS，一次通过一个子节点传播最大路径和； h 是树高 |

 ## 算法演练

 1.初始化一个全局变量`max_sum`为负无穷以跟踪总体最大路径总和。 
2. 定义递归函数`dfs(node)`返回从以下位置开始的最大路径总和`node`并向下延伸至**仅一个分支**。 
3. 对于每个`node`，递归计算左子节点和右子节点的最大路径和`dfs(node.left)`和`dfs(node.right)`。 
4. 如果一个孩子贡献了负数，则通过取`max(left_sum, 0)`和`max(right_sum, 0)`。 
5. 计算通过当前节点**的最大路径和：`node.val + left_sum + right_sum`。 
6.更新全局`max_sum`如果该路径总和大于当前路径`max_sum`。 
7. 向父级返回最大总和，包括**仅一个分支**：`node.val + max(left_sum, right_sum)`。 
8. 打电话`dfs(root)`遍历整棵树并最终返回`max_sum`。 

**为什么起作用：** 该算法维护一个不变量，即在每个节点，我们知道**从该节点开始向下延伸**的路径的最大总和。 通过考虑全局更新的两个子节点，我们考虑了通过该节点的路径，但通过仅返回一个分支，我们可以避免在扩展到父节点时重复计算节点。 这确保了正确性，同时保持线性时间复杂度。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.max_sum = float('-inf')
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            left = max(dfs(node.left), 0)
            right = max(dfs(node.right), 0)
            current_sum = node.val + left + right
            self.max_sum = max(self.max_sum, current_sum)
            return node.val + max(left, right)
        
        dfs(root)
        return self.max_sum
```这个Python解决方案初始化一个全局变量`max_sum`并使用递归 DFS 来计算最大路径和。 在每个节点，它评估左右子节点的贡献并更新`max_sum`用于通过当前节点的路径。 返回时，它仅将较大的子路径传播到父级，确保节点不被重用。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func maxPathSum(root *TreeNode) int {
    maxSum := -1 << 31 // initialize to minimum int value

    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil {
            return 0
        }
        left := max(dfs(node.Left), 0)
        right := max(dfs(node.Right), 0)
        currentSum := node.Val + left + right
        if currentSum > maxSum {
            maxSum = currentSum
        }
        return node.Val + max(left, right)
    }

    dfs(root)
    return maxSum
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```Go 的解决方案类似，使用递归`dfs`功能。 Go 需要显式处理 nil 指针，并且没有内置的整数 max 函数，因此需要一个辅助函数`max`被定义。

 ## 边缘情况

 **所有负节点：**当所有节点都为负时，算法必须正确选择**最小负单节点**作为最大路径和。 使用`max(left,0)`确保与父路径组合时丢弃负子路径。 

**单节点树：** 树只包含一个节点。 该算法通过初始化正确处理这个问题`max_sum`为负无穷并用节点值更新它。
