[LeetCode 第 100 题](https://leetcode.com/problems/same-tree/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们确定两个二叉树是否完全相同。 

我们有两个二叉树的根，`p`和`q`。 二叉树由节点组成，其中每个节点包含一个值以及对左子节点和右子节点的引用。 任务是比较这两棵树并返回`true`如果相同，否则返回`false`。 

要被认为是相同的，树必须同时满足**两个条件**：

 1. 它们的**结构必须相同**，即节点必须出现在相同的位置。 
2. **相应节点存储的值必须完全匹配**。 

这意味着即使两棵树总体上包含相同的值，如果这些值出现在不同的位置，它们也不会被视为相同。 

例如：

-`[1,2,3]`和`[1,2,3]`是相同的，因为每个节点都存在于相同的位置并且具有相同的值。 
-`[1,2]`和`[1,null,2]`不同是因为第二个节点出现在不同的位置，即使值相似。 
-`[1,2,1]`和`[1,1,2]`不同是因为对应的节点包含不同的值。 

输入由两个根节点组成，`p`和`q`，每个都可以是`None`（或者`nil`在 Go 中），代表一棵空树。 预期输出是一个布尔值：

 -`true`如果树在结构上与匹配的节点值相同
 -`false`否则

 限制相对较小：

 - 每棵树包含之间`0`和`100`节点。 
- 节点值范围为`-10^4`到`10^4`。 

由于树的大小很小，因此许多方法都可以足够有效地工作。 然而，这个问题自然适合递归深度优先遍历，因为树本身就是递归结构。 

尽早识别一些边缘情况非常重要。 两棵树都可能是空的，应该返回`true`因为两棵空树是相同的。 一棵树可能是空的，而另一棵树不是空的，这应该立即返回`false`。 树可能具有相同的值但不同的形状，这很容易欺骗仅比较遍历结果的朴素解决方案。 树也可能具有匹配的结构，但在某些级别上具有不同的节点值。 

## 方法

 ### 蛮力方法

 解决此问题的一种强力方法是使用遍历顺序（例如前序或级别顺序）将两棵树序列化为数组，显式包括`null`失踪儿童的标记。 序列化后，我们比较两个结果数组。 

例如：```
Tree 1: [1,2,null,null,3,null,null]
Tree 2: [1,2,null,null,3,null,null]
```如果序列化表示相同，则树是相同的。 

这种方法之所以有效，是因为包括`null`标记保留结构信息。 如果没有它们，不同的树可能会错误地看起来相同。 

然而，这种方法引入了不必要的额外工作和内存开销。 我们在比较之前创建两棵树的完整表示，即使在根附近发生不匹配。 在最坏的情况下，我们仍然访问每个节点并存储额外的数据。 

### 最佳方法

 关键的观察是我们不需要构建树的任何中间表示。 

由于二叉树是递归结构，我们可以逐个节点递归地比较它们：

 - 如果两个节点都是`null`，它们匹配。 
- 如果一个节点是`null`另一个则不是，树木不同。 
- 如果节点值不同，则树不同。 
- 否则，递归比较左孩子和右孩子。 

这自然适用于深度优先搜索（DFS）。 在每一步中，我们都会验证当前节点及其子树。 一旦出现不匹配，我们立即停止并返回`false`。 

这种方法既干净又高效，因为一旦发现差异就可以避免额外的存储和短路。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n + m) | O(n + m) | 序列化两棵树并比较数组 |
 | 最佳 | O(min(n, m)) 到 O(n + m) | O(h) | 递归 DFS 与提前终止的比较 |

 这里，`n`和`m`是两棵树中的节点数，并且`h`是树的高度。 

## 算法演练

 1. 从两棵树的根部开始。 

我们首先比较`p`和`q`。 由于树从根向下必须是相同的，所以这里的任何不匹配都立即意味着答案是`false`。 
2. 检查两个节点是否都`null`。 

如果当前两个节点都是`null`，这意味着两棵树在同一位置都缺少一个节点。 这部分树匹配，所以我们返回`true`。 
3. 检查是否只有一个节点`null`。 

如果一个节点存在而另一个节点不存在，则结构会有所不同。 由于树的结构不再相同，我们返回`false`。 
4. 比较节点值。 

如果两个节点都存在，则比较`p.val`和`q.val`。 如果不同，则树不一样，所以返回`false`。 
5. 递归比较左子树。 

我们调用该函数`p.left`和`q.left`验证两棵树的左侧是否匹配。 
6. 递归比较右子树。 

我们调用该函数`p.right`和`q.right`验证右侧。 
7. 合并结果。 

仅当左子树比较和右子树比较都返回时，树才是相同的`true`。 

### 为什么它有效

 该算法维护一个简单的不变量：在每次递归调用时，它都会验证以当前节点为根的两个子树是否相同。 

如果两个节点都不存在，则它们匹配。 如果仅存在一个或它们的值不同，则违反不变量并且算法返回`false`。 否则，它递归地验证两个子子树。 由于每个节点对都被检查一次并且立即检测到每个结构差异，因此该算法可以正确确定树是否相同。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def isSameTree(
        self,
        p: Optional[TreeNode],
        q: Optional[TreeNode]
    ) -> bool:
        # Both nodes are empty
        if p is None and q is None:
            return True

        # One node exists while the other does not
        if p is None or q is None:
            return False

        # Values do not match
        if p.val != q.val:
            return False

        # Compare left and right subtrees
        return (
            self.isSameTree(p.left, q.left)
            and self.isSameTree(p.right, q.right)
        )
```其实现直接遵循递归DFS算法。 

第一个条件检查两个节点是否`None`。 如果是，子树在这个位置匹配，所以我们返回`True`。 

第二个条件处理结构不匹配。 如果一个节点存在而另一个节点不存在，则两棵树不可能是相同的。 

接下来，我们比较节点值。 即使结构匹配，不同的值也意味着树不同。 

最后，我们递归地比较左子树和右子树。 由于这两个条件必须同时满足，因此我们使用逻辑`and`操作员。 Python 短路评估，这意味着如果左子树已经失败，则不会不必要地评估右子树。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isSameTree(p *TreeNode, q *TreeNode) bool {
    // Both nodes are nil
    if p == nil && q == nil {
        return true
    }

    // One node exists while the other does not
    if p == nil || q == nil {
        return false
    }

    // Values do not match
    if p.Val != q.Val {
        return false
    }

    // Compare left and right subtrees
    return isSameTree(p.Left, q.Left) &&
        isSameTree(p.Right, q.Right)
}
```Go 实现几乎完全反映了 Python 逻辑。 

主要区别在于使用`nil`而不是`None`。 由于 Go 使用指针作为树节点，因此我们比较`nil`判断节点是否存在。 

Go 还使用`&&`而不是Python的`and`布尔逻辑运算符。 这里不存在整数溢出问题，因为节点值保留在`int`范围并且不执行任何算术运算。

 ## 边缘情况

 ### 两棵树都是空的

 一个常见的边缘情况是当两者`p`和`q`是`None`。 由于两棵树都不包含任何节点，因此它们在结构上是相同的，并且根据定义包含相同的值。 幼稚的实现可能会意外返回`false`如果它假设至少存在一个节点。 我们的实现会立即处理这个问题，条件如下：```
if p is None and q is None:
    return True
```### 一棵树是空的

 当一棵树存在而另一棵树不存在时，会发生另一种重要情况。 即使到目前为止所有观察到的值都匹配，结构也不再相同。 如果仅比较节点值，这很容易引入错误。 该实现显式检查这种不匹配并返回`False`。 

### 相同的值但不同的结构

 两棵树可以包含完全相同的值，但排列方式不同。 例如：```
p = [1,2]
q = [1,null,2]
```仅比较遍历值的简单解决方案可能会错误地得出树相等的结论。 我们的递归比较检查每个位置的节点是否存在，确保立即检测到结构差异。 

### 结构相同但值不同

 即使两棵树具有相同的形状，相应的节点值也必须匹配。 如果单个节点不同，则树就不一样。 实现比较`p.val`和`q.val`在每个递归步骤中，确保在发生值不匹配时准确捕获它们。
