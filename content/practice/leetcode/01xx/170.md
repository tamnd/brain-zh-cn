 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个数据结构，该结构能够有效地支持整数流上的两个操作。 

第一次手术，`add(number)`，将一个数字插入到数据结构中。 数字可能会出现多次，因此必须正确处理重复项。 

第二次手术，`find(value)`，检查是否存在任何已添加的数字对，其总和等于给定的目标值。 该方法应该返回`true`如果存在这样的一对并且`false`否则。 

这与经典的二和问题不同，因为数字不是一次性给出的。 相反，它们通过重复调用逐步到达`add`。 我们必须保留足够的信息，以便未来`find`可以有效地接听电话。 

例如，假设发生以下操作：```
add(1)
add(3)
add(5)
```内部集合现在包含`[1, 3, 5]`。 

如果我们打电话：```
find(4)
```答案是`true`因为`1 + 3 = 4`。 

如果我们打电话：```
find(7)
```答案是`false`因为没有对的总和等于`7`。 

约束条件相对较小，最多`10^4`呼叫总数`add`和`find`。 尽管这不是很大，但我们仍然需要一个解决方案，避免从头开始重复检查每个可能的对。 

一个重要的细节是，仅当同一数字在数据结构中至少出现两次时，才可能需要使用两次。 例如：```
add(3)
find(6)
```应该返回`false`，因为只有一个`3`。 

但：```
add(3)
add(3)
find(6)
```应该返回`true`。 

负数也是允许的，因此算法不能依赖于纯正的假设，例如排序顺序或两指针扩展。 

## 方法

 ### 蛮力方法

 最直接的解决方案是将每个插入的数字存储在列表中。 

每当`find(value)`被调用时，我们检查列表中每对可能的数字并检查它们的总和是否等于`value`。 

例如，如果数字是：```
[1, 3, 5]
```然后`find(4)`会检查：

 -`1 + 3`-`1 + 5`-`3 + 5`直到找到有效的对。 

这种方法是正确的，因为它明确地测试了每种可能的组合。 如果存在有效的对，最终会找到它。 

然而，随着存储值数量的增加，这会变得低效。 如果有`n`数字，然后检查所有对需要`O(n^2)`最坏情况下的时间。 

自从`find`可能会被调用多次，重复扫描所有对的代价是不必要的。 

### 最佳方法

 更好的解决方案使用哈希图来存储每个数字的频率。 

关键的见解是对于任何数字`x`，完成目标总和所需的值为：```
complement = target - x
```如果两者都`x`和`complement`存在于数据结构中，那么我们就找到了一个有效的对。 

哈希映射允许恒定时间查找补集。 

例如，假设频率图为：```
{
    1: 1,
    3: 1,
    5: 1
}
```评估`find(4)`：

- 查看`1`，补数是`3`-`3`存在于地图中
 - 返回`true`我们还必须谨慎处理以下情况：```
x == complement
```在这种情况下，我们需要该数字至少出现两次。 

例如：```
find(6)
```需要两个`3`s。 

这种方法减少了`find`到`O(n)`时间同时保持`add`在`O(1)`时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 |`add: O(1), find: O(n^2)`| O(n) | 存储所有号码并检查每对 |
 | 最佳|`add: O(1), find: O(n)`| O(n) | 使用哈希图频率计数 |

 ## 算法演练

 1. 初始化一个名为的哈希图`counts`。 

键是已添加的数字，值是每个数字出现的次数。 

例子：```
{
    1: 1,
    3: 2,
    5: 1
}
```2. 什么时候`add(number)`被调用，增加该数字的频率计数。 

如果该数字之前没有出现过，则将其计数初始化为`1`。 

此操作非常高效，因为哈希图插入和查找平均时间是恒定的。 
3. 什么时候`find(value)`被调用，迭代哈希映射中的每个唯一数字。 

对于每个数字：```
complement = value - number
```4. 检查哈希图中是否存在补集。 

如果不存在，则继续下一个数字。 
5. 如果补集存在，则有两种可能的情况。 

如果：```
number != complement
```那么我们已经有了两个不同的数字，其总和等于目标。 

返回`true`。 
6. 如果：```
number == complement
```那么我们至少需要该数字的两个副本。 

例如：```
3 + 3 = 6
```需要计数`3`至少是`2`。 
7. 如果检查完所有数字后没有找到有效的对，则返回`false`。 

### 为什么它有效

 该算法之所以有效，是因为每个有效对都必须包含某个数字`x`及其补语`value - x`。 

通过迭代每个存储的数字并检查其补码是否存在，我们详尽地测试了所有可能的有效对。 哈希映射保证快速补码查找，并且重复计数检查正确处理两个数字相同的对。 

因此，算法总是返回正确的结果。 

## Python 解决方案```python
class TwoSum:

    def __init__(self):
        self.counts: dict[int, int] = {}

    def add(self, number: int) -> None:
        self.counts[number] = self.counts.get(number, 0) + 1

    def find(self, value: int) -> bool:
        for number in self.counts:
            complement = value - number

            if complement not in self.counts:
                continue

            if complement != number:
                return True

            if self.counts[number] >= 2:
                return True

        return False

# Your TwoSum object will be instantiated and called as such:
# obj = TwoSum()
# obj.add(number)
# param_2 = obj.find(value)
```实现首先创建一个名为的字典`counts`。 该字典存储每个数字被添加的次数。 

这`add`方法更新频率计数。 如果该数字已存在，则其计数加一。 否则，将插入计数`1`。 

这`find`方法迭代当前存储的每个唯一数字。 对于每个数字，它计算达到目标值所需的补数。 

哈希映射允许恒定时间检查补集是否存在。 

该实现仔细区分了两种情况：

 - 补数是不同的数
 - 补数是相同的数

 如果数字不同，则该对立即有效。 

如果它们相同，则代码验证频率计数至少为`2`。 

如果不存在有效的对，该方法返回`False`。 

## 解决方案```go
type TwoSum struct {
	counts map[int]int
}

func Constructor() TwoSum {
	return TwoSum{
		counts: make(map[int]int),
	}
}

func (this *TwoSum) Add(number int) {
	this.counts[number]++
}

func (this *TwoSum) Find(value int) bool {
	for number := range this.counts {
		complement := value - number

		count, exists := this.counts[complement]

		if !exists {
			continue
		}

		if complement != number {
			return true
		}

		if count >= 2 {
			return true
		}
	}

	return false
}

/**
 * Your TwoSum object will be instantiated and called as such:
 * obj := Constructor();
 * obj.Add(number);
 * param_2 := obj.Find(value);
 */
```Go 的实现与 Python 方法非常相似。 

Go 使用的不是 Python 字典，而是`map[int]int`来存储频率。 

一个小小的区别是 Go 地图查找返回两个值：```go
value, exists := map[key]
```这`exists`布尔值用于确定补集是否存在。 

Go 整数安全地支持问题约束，因此不需要额外的溢出处理。

 ## 边缘情况

 ### 两次使用相同的数字

 最常见的错误之一是错误地允许单个数字与其自身形成一对。 

例如：```
add(3)
find(6)
```应该返回`false`， 不是`true`。 

该实现通过检查频率计数是否至少是来处理这个问题`2`什么时候：```
number == complement
```这保证了存在两个单独的事件。 

### 重复插入

 数据结构必须正确支持重复的数字。 

例如：```
add(2)
add(2)
find(4)
```应该返回`true`。 

一个简单的集合在这里会失败，因为集合会丢弃重复项。 使用频率图可以保留出现次数并正确处理重复值。 

### 负数和零

 一些不正确的解决方案假设所有数字都是正数或依赖于排序的排序行为。 

该问题允许使用以下值：```
-100000
0
100000
```哈希映射方法对所有整数统一工作，因为补码计算：```
complement = value - number
```无论符号如何，都保持有效。 

这确保了正确处理负目标、混合符号对和零和情况。
