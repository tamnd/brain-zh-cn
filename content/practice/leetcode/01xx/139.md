[LeetCode 第 139 题](https://leetcode.com/problems/word-break/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、动态规划、Trie、记忆化

 ## 解决方案

 ## 问题理解

 该问题要求我们判断给定的字符串是否`s`可以从给定的字典中分解成一系列有效的单词`wordDict`。 本质上，我们需要检查是否可以插入空格`s`这样，由这些空格分隔的每个子字符串都存在于字典中。 输入由一个字符串组成`s`包含小写英文字母和独特的小写单词列表`wordDict`。 输出是一个布尔值，指示是否存在这样的分段。 

约束告诉我们，长度`s`最多 300 个字符，词典最多可包含 1000 个单词，每个单词最多 20 个字符长。 这些限制表明，递归地探索所有可能的分割的简单解决方案可能太慢，因为组合的数量可能呈指数级增长。 重要的边缘情况包括空字符串、没有单词匹配的字符串以及有效分段需要多次重复使用同一单词的情况。 

## 方法

 暴力方法是尝试对字符串的每一种可能的分割。 对于字符串中的每个索引，我们可以递归地检查从当前索引到末尾的子字符串是否可以使用字典中的单词进行分割。 虽然这保证了正确性，但速度非常慢，因为它会探索分段的所有组合。 由于可能的拆分的组合爆炸，它的时间复杂度是指数级的，O(2^n)，其中 n 是字符串的长度。 

改进解决方案的关键是使用动态规划。 我们可以维护一个布尔数组`dp`尺寸的`len(s) + 1`， 在哪里`dp[i]`表示子串是否`s[0:i]`可以使用字典进行分词。 对于每个位置`i`，我们检查所有之前的位置`j`在哪里`dp[j]`是真的并且`s[j:i]`字典中存在。 这通过为较小的子串构建解决方案并将其重用于较大的子串来避免冗余计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归检查所有子串组合 |
 | 动态规划| O(n^2 * m) | O(n^2 * m) | O(n + k) | 通过字典查找检查所有子字符串结尾； m = 最大字长，k = 字数 |

 ## 算法演练

 1. 转换`wordDict`到一个集合中进行 O(1) 查找。 这很重要，因为我们将重复检查字典中是否存在子字符串。 
2.初始化布尔数组`dp`尺寸的`len(s) + 1`。 放`dp[0] = True`表示可分段的空字符串。 
3. 使用索引迭代字符串`i`从 1 到`len(s)`。 对于每个`i`，用索引向后迭代`j`从 0 到`i`。 
4. 对于每个`j`，检查是否`dp[j]`是真的（意思是`s[0:j]`是可分段的）并且如果`s[j:i]`是在字典里的。 
5. 如果两个条件都满足，则设置`dp[i] = True`并打破内部循环，因为我们发现一个有效的分段结束于`i`。 
6. 填充数组后，`dp[len(s)]`包含完整字符串的答案。 

工作原理：DP 数组保持以下不变式：`dp[i]`当且仅当子串为 True`s[0:i]`可以使用字典中的单词进行分割。 通过检查所有可能的先前位置`j`，我们确保考虑每个有效的分段，但不会重复计算重叠的子字符串。 

## Python 解决方案```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        word_set = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        
        for i in range(1, n + 1):
            for j in range(max(0, i - 20), i):  # Optimization using max word length
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    break
        
        return dp[n]
```在此 Python 实现中，我们首先将字典转换为集合以加快查找速度。 这`dp`数组跟踪哪些前缀可以被分段。 嵌套循环检查每个结束索引`i`如果某个索引处存在有效的分割`j`。 通过仅考虑长度最多为 20（最大字长）的子串来优化内部循环。 

## 解决方案```go
func wordBreak(s string, wordDict []string) bool {
    wordSet := make(map[string]bool)
    for _, word := range wordDict {
        wordSet[word] = true
    }
    
    n := len(s)
    dp := make([]bool, n+1)
    dp[0] = true
    
    for i := 1; i <= n; i++ {
        for j := max(0, i-20); j < i; j++ {
            if dp[j] && wordSet[s[j:i]] {
                dp[i] = true
                break
            }
        }
    }
    
    return dp[n]
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```Go 实现反映了 Python 方法。 该字典被转换为 O(1) 查找的映射。 DP 数组是一个布尔值切片。 我们使用一个助手`max`通过最大字长优化时避免负索引的函数。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * m) | 我们迭代所有最终索引`i`以及最大字长`m`对于每个子字符串检查。 |
 | 空间| O(n + k) |`dp`大小为 n+1 的数组和大小为 k 的字典集/映射。 |

 时间复杂度是有效的，因为我们避免了冗余的递归调用，并且只检查最大字长的子串。 空间复杂度与字符串长度和字典大小呈线性关系。

 ## 边缘情况

 一个重要的边缘情况是空字符串。 根据DP设置，`dp[0] = True`表示一个空字符串，因此算法无需进一步处理即可正确返回 True。 另一个边缘情况是字符串包含字典中根本不存在的字符。 对于空字符串之外的所有索引，DP 数组将保持 False，正确返回 False。 第三种边缘情况涉及字典中在字符串中重复使用多次的单词，例如“aaaaaaa”分段为[“aaaa”，“aaa”]。 该算法可以正确处理此问题，因为 DP 数组允许多个有效分割向前传播 True 值，确保考虑所有可能的组合。
