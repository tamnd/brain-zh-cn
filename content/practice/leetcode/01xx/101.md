[LeetCode 第 101 题](https://leetcode.com/problems/symmetry-tree/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们确定二叉树是否绕其中心对称。 如果左子树是右子树的镜像，则树是对称的。 

在镜像关系中，必须满足以下条件：

 - 对应节点的值必须相等。 
- 一个子树的左子树必须与另一子树的右子树匹配。 
- 一个子树的右子树必须与另一子树的左子树匹配。 

输入是二叉树的根节点。 输出是一个布尔值：

 -`true`如果树是对称的
 -`false`否则

 例如，考虑这棵树：```
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```这棵树是对称的，因为左右两侧是精确的镜像。 

现在考虑：```
        1
      /   \
     2     2
      \     \
       3     3
```这棵树不是对称的，因为结构本身不同。 左子树缺少左子节点，而右子树在不同的镜像位置缺少左子节点。 

约束告诉我们树最多包含 1000 个节点。 这对于递归和迭代遍历来说足够小。 由于该问题明确提到了递归和迭代解决方案，因此我们应该理解这两种方法。 

一些边缘情况很重要：

 - 只有一个节点的树是对称的。 
- 缺少孩子的树很容易破坏对称性。 
- 仅相等的值是不够的，结构还必须正确镜像。 
- 空节点必须小心处理，因为镜像位置可能都是空的，这是有效的。 

## 方法

 ### 蛮力方法

 强力解决方案将显式构造两个遍历表示并比较它们。 

一种可能的策略是：

 1、按正常顺序遍历左子树。 
2. 按镜像顺序遍历右子树。 
3. 包含空标记，以便保留结构差异。 
4. 比较结果序列。 

例如，我们可以执行：

 - 左子树的前序遍历
 - 右子树上的镜像先序遍历

 如果序列完全匹配，则树是对称的。 

这种方法之所以有效，是因为它以保留节点值和结构的方式序列化双方。 如果没有空标记，结构不同的树可能会错误地显示为相同。 

然而，这种方法使用额外的内存来存储遍历结果并执行不必要的序列化工作。 我们实际上并不需要完整的遍历数组。 我们只需要直接比较对应的节点即可。 

### 最佳方法

 关键的见解是对称性本质上是一个成对比较问题。 

我们可以直接一次比较两个节点，而不是序列化树：

 - 值必须匹配。 
- 一个节点的左子节点必须与另一节点的右子节点匹配。 
- 一个节点的右子节点必须与另一节点的左子节点匹配。 

这自然会导致递归深度优先搜索解决方案。 

我们定义一个辅助函数：```
isMirror(node1, node2)
```该函数检查两个子树是否是镜像。 

递归关系为：```
isMirror(a, b) =
    a.val == b.val
    AND isMirror(a.left, b.right)
    AND isMirror(a.right, b.left)
```这避免了不必要的存储并直接处理树。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将两个子树序列化为数组 |
 | 最佳 | O(n) | O(h) | 直接递归镜像比较|

 这里：

-`n`是节点数
 -`h`是树的高度

 ## 算法演练

 ### 递归镜像比较

 1、从根节点开始，比较它的左右子树。 

根本身不需要与另一个节点进行比较。 对称性完全取决于它的两个子树是否互相镜像。 
2. 创建一个接受两个节点的辅助函数。 

该助手确定两个子树是否是镜像。 
3. 如果两个节点都是`None`， 返回`True`。 

根据定义，两个空子树是对称的。 
4. 如果恰好有一个节点`None`， 返回`False`。 

一棵子树存在，而另一棵不存在，因此该结构没有镜像。 
5. 比较节点值。 

如果值不同，对称性就会立即被破坏。 
6. 递归比较外部子级。 

比较：

 - 第一个节点的左子树
 - 第二个节点的右子树
 7. 递归比较内部孩子。 

比较：

 - 第一个节点的右子树
 - 第二个节点的左子树
 8. 返回`True`仅当两个递归比较都成功时。 

结构对称性和价值对称性必须在整个树中保持。 

### 为什么它有效

 该算法保持了每个递归调用都比较应该占据对称树中镜像位置的节点的不变性。 

每一步：

 - 相应的值必须匹配
 - 相应的镜像子项也必须匹配

 如果此属性适用于所有递归调用，则整个树是对称的。 如果发生任何不匹配，树就不能成为其自身的镜像。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        
        def is_mirror(left: Optional[TreeNode],
                      right: Optional[TreeNode]) -> bool:
            
            if left is None and right is None:
                return True
            
            if left is None or right is None:
                return False
            
            if left.val != right.val:
                return False
            
            return (
                is_mirror(left.left, right.right)
                and
                is_mirror(left.right, right.left)
            )
        
        return is_mirror(root.left, root.right)
```实现直接遵循递归镜像比较。 

辅助函数`is_mirror`接收两个应该互相镜像的节点。 

第一个条件处理两个节点都不存在的情况。 这代表完美镜像的空子树。 

第二个条件处理结构不匹配。 如果一个节点存在而另一个节点不存在，则对称性立即失效。 

第三个条件比较节点值。 即使结构是镜像的，不同的值也会使对称性失效。 

最后，递归调用比较：

 - 外部孩子
 - 内在小孩

 逻辑的运用`and`确保每个镜像对必须匹配才能使树保持对称。 

主函数只是使用根的左子节点和右子节点开始比较。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isSymmetric(root *TreeNode) bool {

    var isMirror func(left, right *TreeNode) bool

    isMirror = func(left, right *TreeNode) bool {

        if left == nil && right == nil {
            return true
        }

        if left == nil || right == nil {
            return false
        }

        if left.Val != right.Val {
            return false
        }

        return isMirror(left.Left, right.Right) &&
            isMirror(left.Right, right.Left)
    }

    return isMirror(root.Left, root.Right)
}
```Go 的实现与 Python 解决方案非常相似。 

主要区别是显式指针处理`nil`而不是`None`。 

Go 使用函数变量声明进行递归：```go
var isMirror func(left, right *TreeNode) bool
```这允许匿名函数递归地引用自身。 

递归逻辑保持相同：

 - 两个 nil 表示对称
 - 1 nil 表示不对称
 - 不相等的值会失败
 - 镜像子比较递归地继续

 不存在整数溢出问题，因为节点值很小并且我们只执行相等比较。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 递归调用堆栈高度|

 该算法只对每个节点处理一次，因此运行时间与节点数量成线性关系。 

辅助空间来自递归深度。 在平衡树中，高度为`O(log n)`。 在倾斜树的最坏情况下，高度变为`O(n)`。

 ## 边缘情况

 ### 单节点树

 仅包含根节点的树始终是对称的。 没有可比较的子树，因此镜像条件不成立。 

幼稚的实现可能会错误地假设左子节点和右子节点都必须存在。 我们的实现正确处理了这个问题，因为初始比较变为：```
is_mirror(None, None)
```返回`True`。 

### 具有相等值的结构不对称

 一种常见的错误是仅检查节点值而忽略结构。 

考虑：```
    1
   / \
  2   2
   \   \
    3   3
```这些值看起来是对称的，但结构不是镜像的。 

我们的实现明确地检查一个节点是否是`None`而另一个则不是：```
if left is None or right is None:
    return False
```这可以正确检测结构不对称性。 

### 深度递归比较

 另一种边缘情况涉及更深的树，其中不对称发生在几个级别以下。 

例如：```
        1
      /   \
     2     2
    /       \
   3         3
  /           \
 4             4
```尽管上层看起来是对称的，但每个递归层都必须保持镜像关系。 

递归策略自然地向下传播比较，并在发生不匹配时立即停止，从而确保所有深度的正确性。
