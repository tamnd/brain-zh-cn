[LeetCode 第 188 题](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iv/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 这个问题要求我们在严格的约束下最大化股票交易的利润：我们最多可以执行`k`交易，其中每笔交易包括买入然后卖出一股股票。 我们得到一个数组`prices`在哪里`prices[i]`代表股票的价格`i-th`天。 目标是在给定这些限制的情况下返回可实现的最大利润。 

输入`k`是1到100之间的整数，限制交易数量。 数组`prices`最多有 1000 个元素，每个元素在 0 到 1000 之间。这意味着我们不能使用指数暴力解决方案，因为`prices.length`足够大，使它们不切实际。 

要考虑的边缘情况包括以下场景：`k`相对于天数非常大，或者数组单调递增或递减。 如果`k`大于天数的一半，它实际上允许无限制的交易。 同样，空数组或只有单个元素的数组也无法产生利润。 

主要挑战是在几天内平衡交易数量和最佳买卖时机，同时保持在`k`交易。 

## 方法

 蛮力方法将尝试探索所有可能的买卖交易序列。 这可以通过为每个允许的交易尝试所有可能的买卖对来递归地完成。 虽然正确，但速度非常慢：组合的数量随着长度的增加而呈指数增长。`prices`以及允许的交易数量，使其不可行`prices.length`最多 1000 个。 

最佳解决方案的关键是使用动态规划。 我们定义一个状态`dp[t][d]`作为最多使用可实现的最大利润`t`按日交易`d`。 对于每一天和交易数量，我们有两种选择：什么都不做，或者在当天卖出股票，这需要知道在任何前一天买入可以实现的最大利润。 为了提高效率，我们保持运行最大值`dp[t-1][d'] - prices[d']`过去几天`d'`。 这避免了之前所有日子的嵌套循环的需要，从而降低了复杂性`O(k * n)`。 

什么时候`k`大于`n // 2`，我们可以将问题简化为无限交易。 在这种情况下，解决方案简化为对连续几天之间的所有正价格差求和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n*k)) | O(2^(n*k)) | O(n*k) | 递归尝试所有买卖对序列 |
 | 最佳DP | O(k * n) | O(k * n) | 使用运行 max 的动态编程来避免嵌套循环 |

 ## 算法演练

 1. 检查是否`prices`数组为空或只有一个元素。 如果是，则返回 0，因为不可能获利。 
2.如果`k`大于或等于`n // 2`（在哪里`n`的长度是`prices`），将其视为无限交易。 迭代`prices`并将连续几天之间的所有正差异相加以获得最大利润。 
3. 初始化一个2D数组`dp`尺寸的`(k+1) x n`， 在哪里`dp[t][d]`代表最多的最大利润`t`交易截止日期`d`。 
4. 对于每笔交易`t`从 1 到`k`，维护一个变量`maxDiff`初始化为`-prices[0]`。 这代表了最大值`dp[t-1][d'] - prices[d']`直到今天。 
5. 几天迭代`d`从 1 到`n-1`。 更新`dp[t][d]`作为最大值`dp[t][d-1]`（什么都不做）或`prices[d] + maxDiff`（今天出售）。 更新`maxDiff`作为其自身的最大值或`dp[t-1][d] - prices[d]`。 
6.填表后结果为`dp[k][n-1]`，代表最多的最大利润`k`交易截止到最后一天。 

为什么它有效：`dp`表保持不变式`dp[t][d]`是最多使用可实现的最大利润`t`交易截止日期`d`。 正在运行的`maxDiff`有效跟踪当前交易数量的最佳购买机会。 这确保所有交易均有效（先买后卖）和交易限额`k`受到尊重。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        n = len(prices)
        if n < 2 or k == 0:
            return 0
        
        if k >= n // 2:
            profit = 0
            for i in range(1, n):
                profit += max(0, prices[i] - prices[i-1])
            return profit
        
        dp = [[0] * n for _ in range(k+1)]
        
        for t in range(1, k+1):
            maxDiff = -prices[0]
            for d in range(1, n):
                dp[t][d] = max(dp[t][d-1], prices[d] + maxDiff)
                maxDiff = max(maxDiff, dp[t-1][d] - prices[d])
        
        return dp[k][n-1]
```在此实现中，我们首先处理空数组或零事务的简单情况。 对于无限交易的情况，我们将所有有利可图的连续差异相加。 否则，我们在维护运行的同时构建 DP 表`maxDiff`优化当日卖出时的利润计算。 The final result is stored at`dp[k][n-1]`。 

## 解决方案```go
func maxProfit(k int, prices []int) int {
    n := len(prices)
    if n < 2 || k == 0 {
        return 0
    }
    
    if k >= n/2 {
        profit := 0
        for i := 1; i < n; i++ {
            if prices[i] > prices[i-1] {
                profit += prices[i] - prices[i-1]
            }
        }
        return profit
    }
    
    dp := make([][]int, k+1)
    for t := range dp {
        dp[t] = make([]int, n)
    }
    
    for t := 1; t <= k; t++ {
        maxDiff := -prices[0]
        for d := 1; d < n; d++ {
            dp[t][d] = max(dp[t][d-1], prices[d]+maxDiff)
            maxDiff = max(maxDiff, dp[t-1][d]-prices[d])
        }
    }
    
    return dp[k][n-1]
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```The Go solution mirrors the Python version. 我们初始化 DP 切片并显式处理无限事务场景。 这`max`helper function is used to simplify comparisons. 与 Python 不同，Go 需要为 2D DP 数组进行显式切片分配。 

## 工作示例

 示例1：`k = 2, prices = [2,4,1]`| t\日 | 0 | 1 | 2 |
 | --- | --- | --- | --- |
 | 1 | 0 | 2 | 2 |
 | 2 | 0 | 2 | 2 |

 步骤：在第 1 天，我们以 2 买入并以 4 卖出，利润 = 2。第 2 天价格较低，没有更好的卖出，因此 DP 仍为 2。 

示例2：`k = 2, prices = [3,2,6,5,0,3]`| t\日 | 0 | 1 | 2 | 3 | 4 | 5 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 0 | 4 | 4 | 4 | 4 |
 | 2 | 0 | 0 | 4 | 4 | 4 | 7 |

 步骤：第一笔交易：第 1 天在 2 买入，第 2 天在 6 = 4 卖出。第二笔交易：第 4 天在 0 买入，第 5 天在 3 = 3 卖出。总计 = 7。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(k * n) | 我们填充一个大小为 k x n 的 DP 表并更新`maxDiff`每次迭代在恒定时间内 |
 | 空间| O(k * n) | DP表存储每次交易次数和日期的最大利润|

 对无限交易的优化将时间减少到 O(n)`k >= n/2`。
