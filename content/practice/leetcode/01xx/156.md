 **难度：** 🟡 中等

 ## 解决方案

 ## 问题理解

 该问题要求我们将二叉树转换为其“颠倒”版本。 更准确地说，我们得到一个二叉树，其中每个右节点要么有左兄弟，要么不存在，并且没有右节点有子节点。 该转换涉及旋转树，以便最左边的路径成为新的根到叶路径。 具体来说，对于每个节点，原来的左孩子成为新的根，原来的根成为新的右孩子，原来的右孩子成为新的左孩子。 

输入是一个`TreeNode`表示二叉树根的对象。 每个节点都有一个`val`,`left`， 和`right`指针。 输出应该是转换后的树的根。 

关键限制是树很小（0 到 10 个节点）并且关于正确的节点规则格式良好。 小输入大小表明递归是实用的并且性能不是主要问题。 边缘情况包括空树、单节点树和所有节点仅具有左子节点的树。 

## 方法

 一种简单的方法是递归地遍历树，跟踪最左边子节点的路径，并使用列表等辅助数据结构从头开始重建一棵新树。 虽然正确，但这种方法需要与树的高度成正比的额外内存，并且不太优雅。 

最佳方法直接在树上利用递归，利用树结构本身将其就地反转。 递归沿着最左边的路径进行，当调用堆栈展开时，每个节点的子节点都会根据颠倒的规则重新分配。 这种方法简洁、直观，一旦理解，并且不需要调用堆栈之外的额外数据结构。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 从最左边的路径重建树，使用额外的列表或数组 |
 | 最佳| O(n) | O(h) | 递归就地变换，仅调用高度为 h 的堆栈 |

 ## 算法演练

 1.如果根是`None`或者没有左孩子，返回根。 这是子树已经位于其新根的基本情况。 
2. 递归调用左子节点的函数，到达最左边的节点，该节点将成为新的根。 
3. 递归返回后，当前节点的左子节点即为倒排子树的根。 重新分配左孩子的`left`指向当前节点右子节点的指针。 这会将原来的右子节点设置为新的左子节点。 
4. 重新分配左孩子的`right`指向当前节点本身的指针。 这使得当前节点成为新的右子节点。 
5. 设置当前节点的`left`和`right`指向`None`以避免循环。 
6. 返回从递归调用中获得的新根。 

**为什么起作用**：递归确保最左边的节点成为根，并且当堆栈展开时，每个父节点都会根据颠倒规则重新定位。 每次重新分配都会保留树结构并避免过早覆盖任何节点。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def upsideDownBinaryTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root or not root.left:
            return root
        
        new_root = self.upsideDownBinaryTree(root.left)
        
        root.left.left = root.right  # original right becomes new left
        root.left.right = root       # original root becomes new right
        
        root.left = None
        root.right = None
        
        return new_root
```这个 Python 实现完全遵循递归算法。 基本情况处理空节点或叶节点，递归查找最左边的节点，指针重新分配会翻转树，同时清除旧链接。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func upsideDownBinaryTree(root *TreeNode) *TreeNode {
    if root == nil || root.Left == nil {
        return root
    }

    newRoot := upsideDownBinaryTree(root.Left)

    root.Left.Left = root.Right
    root.Left.Right = root

    root.Left = nil
    root.Right = nil

    return newRoot
}
```在 Go 中，我们处理`nil`与Python类似`None`。 递归和指针重新分配逻辑是相同的。 Go 的类型系统确保`root.Left`在访问其字段之前存在，匹配算法的基本情况。

 ## 边缘情况

 **空树**：应该返回一个空树`None`。 该实现在基本情况下通过立即返回来处理此问题`root`如果是的话`None`。 

**单节点树**：只有一个节点的树应保持不变。 基本情况还涵盖没有左子节点的节点，以防止不必要的重新分配。 

**左倾树**：如果树仅在左侧有节点，则随着递归展开，每个节点将成为前一个节点的父节点。 递归重新分配确保不会发生循环，因为`left`和`right`指针在重新分配后会被清除。 

这些案例确保了所有有保证的输入结构的稳健性，并验证了关于右子节点存在的假设没有被违反。
