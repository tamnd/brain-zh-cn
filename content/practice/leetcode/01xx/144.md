 # LeetCode 144，二叉树预序遍历

 ## 问题理解

 这个问题要求我们返回二叉树的前序遍历。 

二叉树由节点组成，其中每个节点可能有一个左子节点和一个右子节点。 输入`root`代表该树的根节点。 

在前序遍历中，节点按以下顺序访问：

 1.访问当前节点
 2. 遍历左子树
 3. 遍历右子树

 例如，考虑这棵树：```
    1
     \
      2
     /
    3
```前序遍历为：```
[1, 2, 3]
```因为我们第一次访问`1`，然后移动到右边的孩子`2`，然后访问`2`的左孩子`3`。 

输出应该是一个包含按前序排列的节点值的列表。 

限制比较小，最多100个节点。 这意味着即使是递归解决方案在实践中也完全不会出现递归深度问题。 然而，后续明确要求迭代解决方案，因此我们应该理解递归和基于堆栈的方法。 

一些边缘情况很重要：

 - 树可能是空的，这意味着`root = []`或者`root = None`- 树可能只包含一个节点
 - 树可能完全向左或向右倾斜
 - 某些节点可能只有一个子节点

 正确的解决方案必须处理所有这些结构，而不会丢失节点或以错误的顺序访问节点。 

## 方法

 ### 蛮力方法，递归 DFS

 最直接的解决方案就是使用递归。 

由于先序遍历自然遵循以下模式：

 1. 处理当前节点
 2. 递归到左子树
 3. 递归到右子树

 我们可以完全按照定义来实现遍历。 

在每个节点：

 - 将当前节点的值添加到结果中
 - 递归处理左孩子
 - 递归处理右孩子

 这是有效的，因为递归隐式地使用调用堆栈来记住完成每个子树后返回的位置。 

尽管这个解决方案对于约束来说已经足够有效，但面试官经常认为递归方法“微不足道”，因为它直接反映了遍历定义。 

### 最优方法，使用堆栈的迭代 DFS

 迭代解决方案使用堆栈手动模拟递归。 

关键的见解是递归内部使用调用堆栈。 我们可以自己重现相同的遍历顺序。 

在前序遍历中，我们总是希望处理：

 1.当前节点
 2. 左子树
 3. 右子树

 由于堆栈是后进先出的，因此我们必须在左孩子之前推送右孩子。 这样，当从堆栈中弹出时，首先处理左孩子。 

算法变为：

 - 从堆栈中的根节点开始
 - 弹出一个节点
 - 将其值添加到结果中
 - 推其右孩子
 - 推其左孩子

 这保证了预购订单。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力递归 DFS | O(n) | O(h) | 使用递归栈，简单直观|
 | 最优迭代 DFS | O(n) | O(h) | 使用显式堆栈，避免递归 |

 这里：

-`n`是节点数
 -`h`是树的高度

 在一棵倾斜的树的最坏情况下，`h = n`。 

## 算法演练

 ### 迭代前序遍历

 1. 初始化一个空的结果列表。 

该列表存储我们处理节点时的先序遍历。 
2. 处理空树箱。 

如果`root`是`None`，立即返回一个空列表。 
3. 创建一个堆栈并将根节点压入其中。 

堆栈跟踪我们仍然需要处理的节点。 
4. 当堆栈不为空时重复此操作。 

每次迭代处理一个节点。 
5. 从堆栈中弹出顶部节点。 

这是按预定顺序排列的下一个节点。 
6. 将节点的值添加到结果列表中。 

在前序遍历中，当前节点在其子节点之前被访问。 
7. 如果存在右子节点，则将其压入堆栈。 

我们首先推送右子节点，因为堆栈是后进先出的。 
8. 将左孩子推入堆栈（如果存在）。 

由于左孩子是最后推送的，因此它将首先被处理，从而保留预序顺序。 
9. 继续，直到堆栈变空。 

此时，所有节点都被访问过一次。 
10. 返回结果列表。 

### 为什么它有效

 该算法保持了栈包含其子树仍需要按先序顺序遍历的节点的不变量。 

通过将右子树推入左子树之前，我们确保当节点从堆栈中弹出时，首先处理左子树。 由于每个节点都在其子节点之前被访问，因此遍历顺序变为：```
node -> left subtree -> right subtree
```这与前序遍历完全匹配。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        result = []
        stack = [root]

        while stack:
            node = stack.pop()

            result.append(node.val)

            if node.right:
                stack.append(node.right)

            if node.left:
                stack.append(node.left)

        return result
```实现首先检查树是否为空。 如果`root`是`None`，该函数立即返回一个空列表。 

这`result`list 存储遍历输出，而`stack`模拟递归 DFS 行为。 

在循环内，我们弹出顶部节点并立即将其值附加到结果中，因为前序遍历首先访问当前节点。 

接下来，我们将右孩子推到左孩子之前。 这个顺序是必要的。 由于堆栈首先处理最近添加的元素，因此最后推送左子元素可确保它在右子元素之前得到处理。 

循环继续，直到每个节点都被处理完毕。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func preorderTraversal(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }

    result := []int{}
    stack := []*TreeNode{root}

    for len(stack) > 0 {
        lastIndex := len(stack) - 1
        node := stack[lastIndex]
        stack = stack[:lastIndex]

        result = append(result, node.Val)

        if node.Right != nil {
            stack = append(stack, node.Right)
        }

        if node.Left != nil {
            stack = append(stack, node.Left)
        }
    }

    return result
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

Go 没有使用 Python 列表，而是使用切片作为结果和堆栈。 

Go 使用`nil`而不是`None`对于缺少的指针。 堆栈被实现为一个切片`*TreeNode`。 

为了从堆栈中弹出，我们检索最后一个元素并使用切片语法缩小切片。 

不存在整数溢出问题，因为根据约束，节点值非常小。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 堆栈最多存储节点的树高值 |

 该算法对每个节点进行一次处理，因此运行时间与节点数量呈线性关系。 

空间复杂度取决于栈中同时存储的最大节点数。 在平衡树中，这与树的高度成正比，即`O(log n)`。 在完全倾斜的树的最坏情况下，堆栈可能包含`O(n)`节点。

 ## 边缘情况

 ### 空树

 一棵空树表示为`root = None`。 

如果算法假设根总是存在，这种情况很容易导致错误。 正在尝试访问`root.val`什么时候`root`是`None`会引发异常。 

实现立即处理这个问题：```
if not root:
    return []
```这保证了空输入的安全执行。 

### 单节点树

 仅包含一个节点的树是最小的有效非空树。 

某些实现意外地跳过处理，因为它们过于依赖子存在检查。 

我们的解决方案使用根节点正确初始化堆栈，处理一次，然后返回单个值。 

### 高度倾斜的树

 一棵树可能类似于一个链表，其中每个节点只有一个子节点。 

例如：```
1
 \
  2
   \
    3
```这种情况很重要，因为递归解决方案可能会在更大的问题中面临深度递归的风险。 迭代解决方案完全避免了递归，并使用显式堆栈自然地处理倾斜树。 

遍历仍然正确地遵循先序顺序，因为节点总是在其子节点之前被处理。 

### 失踪孩子的节点

 许多二叉树都是稀疏的，这意味着某些节点只有一个子节点。 

不正确的实现有时会尝试推动`None`将值放入堆栈或不必要地递归到丢失的子项。 

此实施检查：```
if node.right:
```和```
if node.left:
```在将子节点推入堆栈之前，确保仅处理有效节点。
