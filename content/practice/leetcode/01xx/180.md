 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们在表中查找按出现顺序**至少连续出现三次**的数字`id`。 桌子`Logs`由两列组成：`id`和`num`， 在哪里`id`是一个自动递增的主键并且`num`是一个代表数字的字符串。 连续属性由以下顺序决定`id`，因此我们不关心表中数字的总体频率，而是关心连续行中重复数字的序列。 

输入表示按顺序排列的日志列表，输出是包含单个列的表，`ConsecutiveNums`，其中列出了满足“连续出现三次”条件的所有数字。 表的大小没有明确的限制，但由于这是一个数据库问题，我们可以假设它可能包含数千到数百万行。 边缘情况包括恰好出现 3 次的序列、出现超过 3 次的序列以及不连续出现的数字。 

该问题保证了`id`列唯一标识每一行并加 1，这简化了检测连续数字。 它不需要对输出进行排序，从而为查询提供了一定的灵活性。 

## 方法

 **暴力方法**涉及多次自连接表以检查具有相同编号的三个连续行的序列。 具体来说，我们可以加入`Logs`与自身两次，偏移 1 和 2，并检查是否`num`在所有三行匹配中。 虽然这种方法是正确的，但它需要多次表扫描和联接，这对于大型数据集来说效率低下。 

**最佳方法**利用**窗口函数**，特别是`LEAD`SQL 中的函数。 通过同时查看当前行和接下来的两行，我们可以在一次检查中检查三个连续的相同数字。 这种方法避免了昂贵的连接，并且可以很好地扩展大型表。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 使用多个自连接； 对于大桌子效率低下|
 | 最佳| O(n) | O(n) | 使用窗口函数在单次扫描中检查序列 |

 ## 算法演练

 1. **使用`LEAD`函数**：对于每一行，计算`num`在接下来的一行和两行中使用`LEAD(num, 1)`和`LEAD(num, 2)`。 这允许我们访问连续的行，而无需多次连接表。 
2. **比较值**：检查当前值是否`num`匹配接下来的两个数字。 这确保了存在三个连续相同数字的序列。 
3. **选择不同的数字**：由于一个数字可能出现在多个重叠的三个序列中，因此使用`DISTINCT`以避免输出重复。 
4. **返回结果**：将结果数字输出到名为`ConsecutiveNums`。 

这种方法之所以有效，是因为窗口函数有效地评估序列中的下一行，并且比较保证至少连续出现三次。 

## Python 解决方案```python
class Solution:
    def consecutiveNumbers(self, logs: list[dict]) -> list[dict]:
        result = set()
        n = len(logs)
        for i in range(n - 2):
            if logs[i]['num'] == logs[i+1]['num'] == logs[i+2]['num']:
                result.add(logs[i]['num'])
        return [{'ConsecutiveNums': num} for num in result]
```在此 Python 实现中，我们迭代日志，检查连续行的每个三元组是否相等。 我们用一个集合来存储满足条件的数字，确保不重复，然后将集合转换为所需的字典列表格式。 

## 解决方案```go
package main

type Log struct {
    ID  int
    Num string
}

func ConsecutiveNumbers(logs []Log) []map[string]string {
    resultMap := make(map[string]bool)
    n := len(logs)
    for i := 0; i <= n-3; i++ {
        if logs[i].Num == logs[i+1].Num && logs[i].Num == logs[i+2].Num {
            resultMap[logs[i].Num] = true
        }
    }
    result := make([]map[string]string, 0, len(resultMap))
    for num := range resultMap {
        result = append(result, map[string]string{"ConsecutiveNums": num})
    }
    return result
}
```在 Go 中，我们定义一个`Log`结构体对输入进行建模。 我们使用映射作为集合来跟踪满足连续条件的数字，然后将其转换为映射的切片以获得最终输出。 该方法类似于 Python。

 ## 边缘情况

 一种重要的边缘情况是表包含的行少于三行。 在这种情况下，不可能有三个连续的数字，因此算法正确地返回空结果。 

另一种边缘情况是重叠的序列，例如四个或更多连续数字。 该算法通过将数字一次添加到集合中来处理此问题，即使多个三元组重叠，也可以避免重复条目。 

第三种边缘情况是非数字值`num`柱子。 由于问题处理`num`作为字符串，我们的比较可以正常工作，无需进行数字转换，并且可以检测到相同字符串的序列。
