[LeetCode 第 106 题](https://leetcode.com/problems/construct-binary-tree-from-inorder-and-postorder-traversal/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、分而治之、树、二叉树

 ## 解决方案

 ## 问题理解

 该问题提供了同一二叉树的两种遍历顺序：

 -`inorder`，遵循以下顺序：

 左子树、根、右子树
 -`postorder`，遵循以下顺序：

 左子树、右子树、根

 我们必须重建原始二叉树并返回其根节点。 

关键的挑战是理解这些遍历如何唯一地识别树的结构。 由于所有值都保证是唯一的，因此可以在两个数组中明确标识每个节点。 

例如：```
inorder   = [9,3,15,20,7]
postorder = [9,15,7,20,3]
```postorder 的最后一个元素始终是当前子树的根。 这里，`3`是根。 

在中序遍历中：```
[9, 3, 15, 20, 7]
    ^
```左边的所有内容`3`属于左子树，右侧的所有内容都属于右子树。 

这意味着：

 - 左子树顺序：`[9]`- 右子树顺序：`[15,20,7]`递归地使用相同的逻辑，我们可以重建整个树。 

约束条件很重要：

 - 多达 3000 个节点意味着低效的重复扫描解决方案可能会变得太慢。 
- 值是唯一的，这允许我们使用哈希映射来快速索引查找。 
- 保证遍历有效，因此我们不需要处理格式错误的输入。 

重要的边缘情况包括：

 - 一棵只有一个节点的树
 - 完全倾斜的树，递归深度变大
 - 一个子树为空的树
 - 大量输入，重复线性搜索会导致时间限制问题

 因为遍历保证正确并且值是唯一的，所以我们可以安全地递归地重建树而不会产生歧义。 

## 方法

 ### 蛮力方法

 一个简单的解决方案通过以下方式递归地重建树：

 1、以当前后序段的最后一个元素为根
 2. 通过中序数组线性搜索找到根位置
 3. 将中序数组拆分为左子树和右子树部分
 4. 递归重建两个子树

 这是有效的，因为：

 - 后序总是将根放在最后
 - Inorder 告诉我们节点如何在左子树和右子树之间划分

 然而，昂贵的部分是重复扫描有序数组以查找根位置。 在最坏的情况下，例如倾斜树，每个递归调用都会执行一次`O(n)`搜索。 

这导致总体`O(n^2)`时间复杂度。 

如果节点多达 3000 个，这可能会变得低效。 

### 最佳方法

 关键的优化是避免重复搜索中序数组。 

由于节点值是唯一的，我们可以将中序遍历预处理成哈希图：```
value -> inorder index
```这允许在中执行每个根位置查找`O(1)`时间。 

递归结构保持不变：

 - 最后一个后序值是根
 - 中序索引拆分左右子树
 - 先递归构造右子树，然后构造左子树

 首先构建右子树很重要，因为我们从末尾向后消耗后序值。 

这将总体时间复杂度降低到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 有序数组的重复线性扫描 |
 | 最佳| O(n) | O(n) | 使用哈希映射进行恒定时间中序查找 |

 ## 算法演练

 ### 第 1 步：构建中序索引图

 创建一个存储以下内容的哈希映射：```
node value -> index in inorder traversal
```例子：```
inorder = [9,3,15,20,7]

map = {
    9:0,
    3:1,
    15:2,
    20:3,
    7:4
}
```这使我们能够立即确定根在哪里分割中序遍历。 

### 第 2 步：跟踪当前的后订单位置

 后序中的最后一个元素始终是当前根。 

我们维护一个指针：```
postorder_index = len(postorder) - 1
```每次创建节点时，都会递减该指针。 

### 步骤 3：定义递归子树边界

 递归函数对中序数组的一段进行操作：```
build(left, right)
```在哪里：

-`left`是按顺序排列的左边界
 -`right`是按顺序排列的右边界

 如果：```
left > right
```该子树中没有节点，因此返回`None`。 

### 第四步：创建当前根节点

 采取：```
root_value = postorder[postorder_index]
```使用该值创建一个树节点并减少索引。 

###第五步：按中序查找根位置

 使用哈希映射：```
inorder_index = inorder_map[root_value]
```这将中序段分为：

 - 左子树：`left -> inorder_index - 1`- 右子树：`inorder_index + 1 -> right`### 步骤 6：首先构建右子树

 这一步至关重要。 

因为后序遍历是：```
left -> right -> root
```而我们是从尾向后处理，下一个节点首先属于右子树。 

所以我们递归构建：```
root.right
```前：```
root.left
```### 步骤7：返回构造的子树

 构造完两个子节点后，返回根节点。 

递归自然会重建整个树。 

### 为什么它有效

 该算法之所以有效，是因为当节点值唯一时，中序和后序遍历共同唯一地确定二叉树的结构。 

在每个递归步骤：

 - Postorder 标识当前根
 - Inorder 确定哪些节点属于左右子树
 - 递归细分保留了精确的子树结构

 在处理左子树之前处理右子树可确保后序指针始终与正确的节点对齐。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def buildTree(self, inorder: List[int], postorder: List[int]) -> Optional[TreeNode]:
        inorder_index_map = {
            value: index
            for index, value in enumerate(inorder)
        }

        postorder_index = len(postorder) - 1

        def build(left: int, right: int) -> Optional[TreeNode]:
            nonlocal postorder_index

            if left > right:
                return None

            root_value = postorder[postorder_index]
            postorder_index -= 1

            root = TreeNode(root_value)

            inorder_index = inorder_index_map[root_value]

            root.right = build(inorder_index + 1, right)
            root.left = build(left, inorder_index - 1)

            return root

        return build(0, len(inorder) - 1)
```该实现首先将中序遍历预处理为哈希映射。 这避免了重复的线性扫描，并提供对节点位置的恒定时间访问。 

变量`postorder_index`跟踪后序遍历中的当前根节点。 由于后序以根结束，因此我们从最后一个索引开始向后移动。 

递归`build(left, right)`函数重建与之间的中序段对应的子树`left`和`right`。 

如果边界变得无效，意味着`left > right`，子树为空并且函数返回`None`。 

否则，当前根值取自`postorder[postorder_index]`。 一个新的`TreeNode`创建后，后序指针递减。 

使用哈希映射，我们在中序遍历中定位根。 这将子树分为左部分和右部分。 

该算法首先递归地构造右子树，因为我们正在向后遍历后序。 右子树完成后，构建左子树。 

最后返回根节点。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func buildTree(inorder []int, postorder []int) *TreeNode {
    inorderIndexMap := make(map[int]int)

    for index, value := range inorder {
        inorderIndexMap[value] = index
    }

    postorderIndex := len(postorder) - 1

    var build func(left int, right int) *TreeNode

    build = func(left int, right int) *TreeNode {
        if left > right {
            return nil
        }

        rootValue := postorder[postorderIndex]
        postorderIndex--

        root := &TreeNode{Val: rootValue}

        inorderIndex := inorderIndexMap[rootValue]

        root.Right = build(inorderIndex+1, right)
        root.Left = build(left, inorderIndex-1)

        return root
    }

    return build(0, len(inorder)-1)
}
```Go 实现遵循与 Python 版本相同的递归逻辑。 

一个`map[int]int`存储用于恒定时间查找的有序索引。 

Go 使用指针作为树节点，因此子树构造返回`*TreeNode`。 空子树表示为`nil`。 

递归函数被定义为闭包，因此它可以访问`postorderIndex`和`inorderIndexMap`直接执行，无需额外参数。 

由于 Go 切片是对数组的引用，因此在递归期间不会发生额外的复制，从而保持内存使用效率。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |

 该算法访问每个节点一次并为每个节点执行恒定时间的工作。 中序索引图允许在以下位置找到根位置`O(1)`时间。 

递归栈可以达到`O(n)`倾斜树的深度。 哈希映射还存储所有节点值，需要线性空间。

    def buildTree(self, inorder, postorder):

def level_order(root):
    if not root:
        return []

    result = []
    queue = deque([root])

    while queue:
        node = queue.popleft()

        if node:
            result.append(node.val)
            queue.append(node.left)
            queue.append(node.right)
        else:
            result.append(None)

    while result and result[-1] is None:
        result.pop()

    return result

 ## 边缘情况

 ### 单节点树

 仅包含一个节点的树是最小的有效输入。 由于基本条件或索引处理不正确，递归实现有时会失败。 

例如：```
inorder = [-1]
postorder = [-1]
```该实现正确处理了这个问题，因为递归函数创建根节点，然后两个递归子树调用立即终止`left > right`。 

### 完全倾斜的树

 倾斜树的行为类似于链表，并创建最大递归深度。 

例子：```
    1
   /
  2
 /
3
```在这种情况下，递归深度变为`O(n)`。 某些实现错误地处理子树顺序并产生相反的结构。 

该解决方案通过始终在左子树之前构建右子树并同时从末尾消耗后序来避免此问题。 

### 递归期间的空子树

 许多递归调用最终都会遇到子树不存在的情况。 

例子：```
root.left = None
```如果边界条件不正确，递归可能会无限继续或尝试无效的数组访问。 

该实现使用以下方法安全地终止递归：```
if left > right:
    return None
```这保证了空子树范围得到正确处理，并且递归在适当的时间停止。
