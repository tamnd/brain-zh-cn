[LeetCode 第 123 题](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iii/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们确定在给定数组中股票的每日价格的情况下，我们最多可以从**两次股票交易**中获得的最大利润`prices`。 一笔交易的定义是买入**一次**并卖出**一次**。 关键的限制是您不能同时持有多于一只股票，因此您必须在再次购买之前卖出。 

输入`prices`是一个整数数组，其中每个整数代表当天股票的价格。 输出是一个整数，表示交易规则下可实现的最大利润。 

约束表明数组最多可达`10^5`元素长，每个价格可达`10^5`。 这意味着任何具有 **O(n^2)** 时间复杂度的解决方案都可能太慢并且会超出时间限制。 

重要的边缘情况包括：

 - 价格单调递减，不可能盈利。 
- 单调递增的价格，仅执行一笔交易就可以实现利润最大化。 
- 价格少于 2 个的数组，无法进行交易。 

## 方法

 ### 蛮力

 最简单的方法是尝试所有可能的交易对。 对于每笔可能的第一笔交易（当天购买`i`, 当天卖出`j`），我们在剩余的日子里尝试所有可能的第二笔交易。 我们计算每个组合的利润并返回两个利润的最大总和。 

虽然正确，但这种方法**太慢**，因为它需要迭代两个交易的所有日期对。 为了`n`天，这会导致 **O(n^3)** 时间复杂度，这对于`n = 10^5`。 

### 最佳方法

 关键的见解是，我们可以使用**动态规划**通过分阶段跟踪利润来解决这个问题。 我们可以定义四个变量来表示每个可能的操作后的最佳状态：

 1.`first_buy`- 购买第一只股票后的最大利润。 
2.`first_sell`- 卖出第一只股票后的最大利润。 
3.`second_buy`- 买入第二只股票后的最大利润（考虑到第一只卖出股票）。 
4.`second_sell`- 卖出第二只股票后的最大利润。 

每天，我们都会根据采取当前行动是否会提高利润来更新这些变量。 这是可行的，因为每个阶段的最大利润仅取决于前一阶段和当前价格，使其适合具有 **O(1) 空间**的**线性迭代**。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 尝试所有交易对，n 大时速度慢 |
 | 最佳| O(n) | O(1) | O(1) | Track 4状态迭代，高效|

 ## 算法演练

 1. 初始化四个变量来表示每次操作后的最佳利润：

 -`first_buy`=`-infinity`（我们希望购买后利润最大化，所以我们存储负价）
 -`first_sell`= 0（尚未盈利）
 -`second_buy`=`-infinity`（我们希望在购买第二个产品后最大化利润，考虑到第一个销售）
 -`second_sell`= 0（第二次卖出后的利润）
 2. 迭代每个价格`prices`:

 1. 更新`first_buy`作为自身的最大值和负当前价格（代表今天购买第一只股票）。 
2. 更新`first_sell`作为自身的最大值以及之后以当前价格出售的利润`first_buy`。 
3. 更新`second_buy`作为其自身的最大值并且`first_sell`减去当前价格（使用第一笔交易利润购买第二支股票）。 
4. 更新`second_sell`作为自身的最大值以及之后以当前价格出售的利润`second_buy`。 
3. 迭代后，`second_sell`包含可实现的最大利润。 

**为什么有效：**

 这种方法保持了一个不变量：在任何一天，每个状态变量都代表**该操作后可实现的最佳利润**。 迭代更新确保我们将每一天都视为潜在的买入或卖出点，而不会重复计算交易。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if not prices:
            return 0
        
        first_buy = float('-inf')
        first_sell = 0
        second_buy = float('-inf')
        second_sell = 0
        
        for price in prices:
            first_buy = max(first_buy, -price)
            first_sell = max(first_sell, first_buy + price)
            second_buy = max(second_buy, first_sell - price)
            second_sell = max(second_sell, second_buy + price)
        
        return second_sell
```**实施演练：**

 我们从代表没有交易的初始状态开始。 我们每天都会更新这些状态，以反映今天的买入或卖出是否会提高利润。`first_buy`捕获购买第一只股票的最佳价格，`first_sell`卖出后获取利润，`second_buy`使用第一笔交易的利润来模拟再次购买，并且`second_sell`最终获得总利润最大。 

## 解决方案```go
func maxProfit(prices []int) int {
    if len(prices) == 0 {
        return 0
    }

    firstBuy, firstSell := -1 << 31, 0
    secondBuy, secondSell := -1 << 31, 0

    for _, price := range prices {
        if -price > firstBuy {
            firstBuy = -price
        }
        if firstBuy+price > firstSell {
            firstSell = firstBuy + price
        }
        if firstSell-price > secondBuy {
            secondBuy = firstSell - price
        }
        if secondBuy+price > secondSell {
            secondSell = secondBuy + price
        }
    }

    return secondSell
}
```**Go 特定注释：**

 我们使用`-1 << 31`模拟负无穷大。 使用切片迭代代替 Python 列表迭代。 考虑到问题的限制，所有算术运算都是安全的。 不需要 nil 检查，因为在开始时处理的是空切片。
