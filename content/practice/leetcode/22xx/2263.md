[LeetCode 问题 2263](https://leetcode.com/problems/make-array-non-decreasing-or-non-increasing/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、贪婪、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们转换给定的整数数组`nums`转换为具有最少操作次数的 **非递减** 或 **非递增** 数组。 每个操作允许将元素精确地增加或减少 1。 

**非递减**数组是其中每个元素都大于或等于前一个元素的数组，即`nums[i] <= nums[i+1]`。 **非递增**数组是其中每个元素都小于或等于前一个元素的数组，即`nums[i] >= nums[i+1]`。 

输入是 0 到 1000 之间的整数列表，其长度最大可达 1000。输出是一个整数，表示满足两个单调条件之一所需的递增/递减操作的最小总数。 

需要考虑的重要边缘情况包括：

 - 长度为 1 的数组（已经单调，需要 0 次操作）。 
- 已经非减或非增的数组（需要 0 次操作）。 
- 所有元素都相等的数组（已经是单调的）。 
- 具有交替高/低模式的阵列，可能需要多次调整。 

关键的挑战是每个元素都可以单独调整，但我们在选择目标值时必须考虑**全局顺序**约束。 

## 方法

 ### 蛮力

 强力方法将尝试检查每个可能的非递减或非递增的最终阵列配置。 对于每个元素，我们可以尝试从 0 到 1000 的所有可能值并计算所需的操作数。 然后，我们将选择总操作最少的配置。 这种方法是正确的，但效率极低，时间复杂度为 O(n * 1000^n)，对于 n 高达 1000 来说是不可行的。 

### 最佳方法

 关键的观察是，我们可以将其建模为**动态规划（DP）问题**，其中状态表示完成第一个任务所需的最小操作数`i`元素单调如果`i-th`元素被设置为特定值。 由于值`nums[i]`有界（0 到 1000），我们可以将 DP 表限制为这些值。 

1. 对于**非递减数组**，我们可以从左到右迭代，并且对于每个可能的值`nums[i]`，考虑所有较小或等于先前值，选择最小操作成本。 
2. 对于**非递增数组**，我们可以做同样的事情，但方向相反（或者否定数组以重用相同的逻辑）。 

这相当于解决一个**单调 DP 问题**，值压缩为 0 到 1000。DP 表大小是可控的（`n * 1001`）对于给定的约束，使得这种方法可行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(1000^n) | O(1000^n) | O(1) | O(1) | 尝试每个元素的所有可能的最终值 |
 | 最优 (DP) | O(n * 最大值) | O(最大值) | 使用 DP 跟踪每个可能元素值的最小操作 (maxVal = 1001) |

 ## 算法演练

 1.初始化一个大小为DP的数组`maxVal = 1001`， 在哪里`dp[v]`表示使数组不递减至当前索引（最后一个元素为）所需的最少操作`v`。 
2. 迭代每个元素`num`在`nums`。 
3. 对于每个可能的目标值`v`从 0 到 1000：

 - 更新`dp[v]`作为总和`abs(num - v)`加上最小值`dp[u]`为所有人`u <= v`。 
- 这确保数组保持不递减。 
4.处理完所有元素后，非减变换的答案为`min(dp)`。 
5. 要处理非递增数组，请反转数组或取负值并重用相同的 DP 逻辑。 
6. 返回非减和非增结果中的最小值。 

**为什么有效：** DP 数组在每一步都保持不变式，`dp[v]`是以 value 结尾的有效单调数组的最小总操作数`v`。 通过考虑所有可能的最后值并与先前的最小值相结合，我们保证了数组的全局最小值。 

## Python 解决方案```python
from typing import List
import sys

class Solution:
    def convertArray(self, nums: List[int]) -> int:
        def min_operations(arr: List[int]) -> int:
            max_val = 1001
            dp = [0] * max_val
            for i, num in enumerate(arr):
                new_dp = [0] * max_val
                min_so_far = sys.maxsize
                for v in range(max_val):
                    min_so_far = min(min_so_far, dp[v])
                    new_dp[v] = min_so_far + abs(num - v)
                dp = new_dp
            return min(dp)
        
        inc_ops = min_operations(nums)
        dec_ops = min_operations(nums[::-1])
        return min(inc_ops, dec_ops)
```**说明：** 我们定义一个助手`min_operations`计算使数组不减的最少操作。 对于每个元素，我们迭代所有可能的值并使用运行最小值 (`min_so_far`）以有效地跟踪保持数组单调的最佳先前成本。 我们对原始数组（非递减）和反转数组（非递增）进行计算，并返回较小的结果。 

## 解决方案```go
import (
    "math"
)

func convertArray(nums []int) int {
    maxVal := 1001

    minOperations := func(arr []int) int {
        dp := make([]int, maxVal)
        for i := range arr {
            newDp := make([]int, maxVal)
            minSoFar := math.MaxInt32
            for v := 0; v < maxVal; v++ {
                if dp[v] < minSoFar {
                    minSoFar = dp[v]
                }
                newDp[v] = minSoFar + abs(arr[i]-v)
            }
            dp = newDp
        }
        minOps := math.MaxInt32
        for _, val := range dp {
            if val < minOps {
                minOps = val
            }
        }
        return minOps
    }

    incOps := minOperations(nums)
    decOps := minOperations(reverse(nums))
    if incOps < decOps {
        return incOps
    }
    return decOps
}

func abs(a int) int {
    if a < 0 {
        return -a
    }
    return a
}

func reverse(arr []int) []int {
    n := len(arr)
    res := make([]int, n)
    for i := 0; i < n; i++ {
        res[i] = arr[n-1-i]
    }
    return res
}
```**Go 特定说明：** Go 需要手动处理`abs`和数组反转。 我们还处理`math.MaxInt32`用于初始化运行最小值。 

## 工作示例

 ### 示例 1：nums = [3,2,4,5,0]

 非递减 DP 的分步操作：

 | 我| 编号 | dp[0..5] 样本 | min_so_far | new_dp[0..5] 样本 |
 | --- | --- | --- | --- | --- |
 | 0 | 3 | 0 | 0 | 3 |
 | 1 | 2 | 上一个 dp | 3 | 2+3=5 |
 | 2 | 4 | ... | ... | ... |

 DP之后，`min(dp)`= 4 表示非递增。 

结果：4 次操作。 

### 示例 2：nums = [2,2,3,4]

 已经不减，`min(dp)`= 0

 ### 示例 3：nums = [0]

 单元素，`min(dp)`= 0

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * 1001) | 对于 n 个元素中的每一个，我们迭代最大值范围 0-1000 |
 | 空间| O(1001) | 我们只保留当前大小为 1001 的 DP 数组 |

 该算法有效地将问题简化为有界值范围内的 DP，而不是尝试所有排列。
