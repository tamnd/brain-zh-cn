 ## 解决方案

 ## 问题理解

 该问题要求我们对不同整数的数组执行一系列替换操作。 具体来说，我们有一个初始数组`nums`含有`n`不同的正整数。 我们还被赋予`m`操作，每个操作由一对组成`[oldValue, newValue]`。 对于每个操作，我们必须定位元素`oldValue`在数组中并将其替换为`newValue`。 约束保证`oldValue`在操作时始终存在于数组中，并且`newValue`尚未存在于数组中，这简化了重复项的处理。 

预期输出是按顺序应用所有操作后数组的最终状态。 

约束的要点包括大尺寸限制（`n`和`m`最多 10^5）并且要求所有元素都不同。 这表明线性扫描数组以进行每次替换 (O(n * m)) 的简单方法效率低下。 要考虑的边缘情况包括最小数组（长度为 1）、具有连续替换的最大数组以及元素来回交换的序列。 

## 方法

 ### 蛮力

 一种简单的方法是迭代每个操作，并且对于每个操作`[oldValue, newValue]`, 扫描数组`nums`找到索引`oldValue`并将其替换为`newValue`。 这种方法保证了正确性，因为它直接遵循操作指令。 然而，它的效率很低，因为查找索引对于 m 个操作中的每一个都需要 O(n)，总时间复杂度为 O(n * m)，这对于最大约束 (`n, m <= 10^5`）。 

### 最佳

 关键的见解是使用哈希映射（Python 中的字典，Go 中的映射）来跟踪中元素的索引`nums`。 通过这种结构，每次替换操作都可以通过查找索引来在 O(1) 时间内完成`oldValue`在地图中并更新数组和地图`newValue`。 这将整体复杂度降低到 O(n + m)，因为我们最初构建映射，然后在恒定时间内执行每个操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 直接扫描数组进行每次替换 |
 | 最佳| O(n + m) | O(n) | 使用哈希图进行快速索引查找和更新 |

 ## 算法演练

 1. 初始化哈希图`value_to_index`其中键是来自的元素`nums`值是它的索引。 
2. 迭代数组`nums`并填充`value_to_index`所以每个数字都指向它的索引`nums`。 
3. 对于每个操作`[oldValue, newValue]`在`operations`，执行以下操作：

 1. 检索索引`oldValue`从`value_to_index`。 
2. 更换`nums[index]`和`newValue`。 
3. 删除`oldValue`从`value_to_index`并插入`newValue`具有相同的索引。 
4.返回更新后的内容`nums`大批。 

**为什么它有效：** 不变的是`value_to_index`总是准确地反映每个数字的当前位置`nums`。 由于所有数字都是不同的并且操作保证不重复，因此每次替换都可以在恒定时间内完成而不会发生冲突。 

## Python 解决方案```python
from typing import List

class Solution:
    def arrayChange(self, nums: List[int], operations: List[List[int]]) -> List[int]:
        # Step 1: Build a mapping from value to its index
        value_to_index = {num: i for i, num in enumerate(nums)}
        
        # Step 2: Apply each operation
        for old_value, new_value in operations:
            index = value_to_index.pop(old_value)  # Get index and remove old_value
            nums[index] = new_value               # Update the array
            value_to_index[new_value] = index     # Add new_value to the map
            
        return nums
```该实现首先构造哈希映射以启用 O(1) 索引查找。 每个操作都会更新数组并保持映射同步。 使用`pop`确保`oldValue`在检索其索引时被删除。 最后返回修改后的数组。 

## 解决方案```go
func arrayChange(nums []int, operations [][]int) []int {
    // Step 1: Build a map from value to index
    valueToIndex := make(map[int]int, len(nums))
    for i, num := range nums {
        valueToIndex[num] = i
    }
    
    // Step 2: Apply each operation
    for _, op := range operations {
        oldValue, newValue := op[0], op[1]
        index := valueToIndex[oldValue]
        nums[index] = newValue
        delete(valueToIndex, oldValue)
        valueToIndex[newValue] = index
    }
    
    return nums
}
```在 Go 中，地图是用以下命令创建的`make`为了效率。`delete`用于删除旧密钥。 所有其他步骤均反映 Python 解决方案。 Go 中的切片操作直接修改数组，确保映射保持一致。
