[LeetCode 第 2236 题](https://leetcode.com/problems/root-equals-sum-of-children/)

 **难度：** 🟢简单
 **主题：** 树、二叉树

 ## 解决方案

 ## 问题理解

 这个问题给我们提供了一个始终包含三个节点的二叉树。 有 1 个根节点、1 个左子节点和 1 个右子节点。 我们必须确定根节点中存储的值是否等于其两个子节点中存储的值之和。 

换句话说，如果：

 -`root.val`是根节点的值
 -`root.left.val`是左孩子的值
 -`root.right.val`是右孩子的价值

 那么我们必须返回：```
true  if root.val == root.left.val + root.right.val
false otherwise
```输入表示为二叉树，但由于问题保证恰好有三个节点，因此我们永远不需要担心更大的树遍历、递归深度或丢失中间节点。 

限制非常小：

 - 树总是恰好有三个节点
 - 节点值介于`-100`和`100`这些限制告诉我们一些重要的事情：

 - 我们不需要大量优化性能
 - Python 和 Go 中都不可能出现整数溢出
 - 保证左右子节点存在
 - 在正常问题情况下，我们不需要对失踪儿童进行空检查

 一个重要的观察是问题结构本身可以防止许多常见的树边缘情况。 例如：

 - 树不能为空
 - 根不能缺少孩子
 - 没有更深层次的处理

 然而，天真的实现仍然可能会犯一些错误，例如：

 - 比较错误的值
 - 忘记访问子节点值
 - 使用乘法或减法代替加法
 - 意外地不必要地遍历树

 由于输入大小是固定的且很小，因此最干净的解决方案也是最好的解决方案。 

## 方法

 ### 蛮力方法

 暴力式解决方案会将输入视为一般的二叉树问题。 我们可以递归地遍历这棵树，将所有节点值收集到一个列表中，然后检查第一个值是否等于其余两个值的总和。 

这是可行的，因为树总是包含恰好三个节点。 遍历后：

 - 第一个收集到的值将是根
 - 接下来的两个值是孩子
 - 我们可以直接比较这些值

 尽管这种方法产生了正确的答案，但它执行了不必要的工作。 我们不需要递归、额外的存储或遍历逻辑，因为问题已经保证了精确的树结构。 

### 最佳方法

 关键的观察结果是树结构是固定的并且非常小。 由于根总是有两个子节点，因此我们可以直接访问它们的值并立即比较它们。 

我们不遍历树，而是简单地计算：```
root.left.val + root.right.val
```并将结果与​​以下内容进行比较：```
root.val
```这是最简单且最有效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 遍历树并存储不必要的值 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 直接将根值与子项总和进行比较 |

 自从`n = 3`，这两种方法在实践中都是有效的恒定时间，但直接比较方法更清晰、更合适。 

## 算法演练

 1. 使用以下命令访问存储在根节点中的值`root.val`。 

这是我们必须根据子项总和验证的值。 
2. 使用以下方式访问左子值`root.left.val`。 

该问题保证左孩子存在。 
3. 使用以下方法访问右子值`root.right.val`。 

这个问题也保证了正确的孩子的存在。 
4. 将两个子值相加。 

这会产生应与根值匹配的预期总和。 
5. 将子项总和与根值进行比较。 

如果相等则返回`True`。 否则，返回`False`。 

### 为什么它有效

 问题定义直接指出，在以下情况下答案应该正确：```
root.val == root.left.val + root.right.val
```该算法直接计算该条件并返回比较结果。 由于每个所需的值都被访问一次并且不涉及其他逻辑，因此该算法既正确又最小。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def checkTree(self, root: Optional[TreeNode]) -> bool:
        return root.val == root.left.val + root.right.val
```实现直接遵循最优算法。 

该方法通过以下方式访问根值`root.val`。 然后它使用以下方法访问左右子值`root.left.val`和`root.right.val`。 

将两个子值相加，并将结果与​​根值进行比较。 比较本身会产生一个布尔值，该值会立即返回。 

因为该问题保证树始终包含恰好三个节点，所以我们不需要对丢失的子节点进行额外的安全检查。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func checkTree(root *TreeNode) bool {
    return root.Val == root.Left.Val+root.Right.Val
}
```Go 实现与 Python 版本几乎相同。 

主要区别在于 Go 的结构体字段命名约定。 使用以下方式访问节点值`Val`,`Left`， 和`Right`而不是 Python 的小写属性名称。 

该问题保证两个子指针都非 nil，因此不需要额外的 nil 检查。

 ## 边缘情况

 一种重要的边缘情况涉及负值。 某些实现意外地假设所有值都是正数，但约束明确允许负整数。 例如，根值为`-5`带孩子`-2`和`-3`应该返回`True`。 该实现可以正确处理此问题，因为整数加法通常适用于负值。 

另一个重要的边缘情况是所有值都为零时。 粗心的实现可能会意外地将零视为条件逻辑中的假值或无效值。 由于该解决方案仅执行直接算术比较，因此情况`[0,0,0]`处理自然且正确。 

第三种边缘情况涉及接近的边界值`-100`和`100`。 某些语言在大型算术运算中可能会遇到整数溢出，但这里的限制非常小。 Python 和 Go 都可以安全地处理这些添加，而不会出现任何溢出问题。 

最后，这个问题保证了根总是有左子节点和右子节点。 通用二叉树实现可能包括不必要的空检查，但此解决方案依赖于问题约束并直接访问子级。 这使代码保持简洁和高效，同时保持有效输入的完全正确性。
