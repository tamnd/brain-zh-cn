[LeetCode 问题 2246](https://leetcode.com/problems/longest-path-with- Different-adjacent-characters/)

 **难度：** 🔴难
 **主题：** 数组、字符串、树、深度优先搜索、图论、拓扑排序

 ## 解决方案

 ## 问题理解

 问题给出了一棵树`n`标记的节点`0`到`n-1`，以节点为根`0`。 这棵树用一个表示`parent`数组，其中`parent[i]`表示节点的父节点`i`。 节点`0`没有父母，所以`parent[0] == -1`。 每个节点还有一个从字符串分配的字符`s`， 在哪里`s[i]`对应节点`i`。 

我们被要求找到**树中最长的路径**，使得**路径上没有两个相邻节点共享相同的字符**。 该路径不必从根开始； 它可以是树中任何连接的节点序列。 结果是该路径的长度（以节点数表示）。 

约束表明`n`可以大到`10^5`，这排除了天真的探索所有可能路径的暴力解决方案。 该树是有效的，因此没有循环，并且`s`仅包含小写字母。 

重要的边缘情况包括小树（如单个节点）、所有字符都相同的树以及本质上是链形或星形的树。 

## 方法

 **暴力方法**是探索树中的所有路径并检查相邻字符是否不同。 人们可以通过每个节点的递归深度优先搜索（DFS）来做到这一点，并跟踪最大路径长度。 虽然这种方法最终会找到正确的答案，但它的速度非常慢，因为用`n = 10^5`节点可能需要指数时间。 

**最佳方法**以自下而上的方式使用 DFS。 对于每个节点，我们计算最长路径的长度**从该节点开始向下**，仅考虑具有不同字符的子节点。 在处理节点时，我们跟踪两个具有不同字符的**最长子路径**。 通过当前节点的最大路径可以通过将这两个最长的子路径加上当前节点本身的一相加来形成。 通过在遍历树一次的同时保持全局最大值，我们获得了一个有效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 探索来自所有节点的所有路径，对于大 n 来说太慢 |
 | 最佳| O(n) | O(n) | 跟踪最长子路径的单个 DFS，对于大 n 有效

 ## 算法演练

 1. 转换`parent`将数组转换为树结构（通常是邻接列表），以轻松访问任何节点的子节点。 
2.初始化全局变量`max_path`跟踪找到的最大路径长度。 
3. 定义一个采用节点的递归 DFS 函数`u`作为输入。 
4. 对于每个孩子`v`的`u`，递归调用DFS得到从 开始的最长路径`v`。 
5. 如果`s[v] != s[u]`，将此路径视为延伸路径的候选路径`u`。 
6. 跟踪节点的**两个最长的有效子路径**`u`。 
7.更新全局`max_path`作为两条最长子路径之和加一（包括`u`）。 
8. 将最长有效单个子路径的长度加一返回给父调用。 
9. DFS在根处完成后，`max_path`包含满足约束的最长路径的长度。 

**为什么有效：** 每个节点都会从自身开始计算最佳路径，同时考虑其子节点。 通过跟踪前两个最长的子路径，我们确保考虑到通过节点并包括多个分支的任何路径。 由于我们只访问每个节点一次，因此我们保证了正确性和效率。 

## Python 解决方案```python
from typing import List, Dict

class Solution:
    def longestPath(self, parent: List[int], s: str) -> int:
        n = len(parent)
        tree: Dict[int, List[int]] = {i: [] for i in range(n)}
        for i in range(1, n):
            tree[parent[i]].append(i)
        
        self.max_path = 1

        def dfs(node: int) -> int:
            longest = 0
            second_longest = 0
            for child in tree[node]:
                child_path = dfs(child)
                if s[child] != s[node]:
                    if child_path > longest:
                        second_longest = longest
                        longest = child_path
                    elif child_path > second_longest:
                        second_longest = child_path
            self.max_path = max(self.max_path, longest + second_longest + 1)
            return longest + 1

        dfs(0)
        return self.max_path
```该实现首先为树构建邻接表，然后从根开始执行 DFS。 每个 DFS 调用都会返回从该节点开始的最长路径，而全局路径`max_path`已更新以反映迄今为止找到的最佳路径。 这`longest`和`second_longest`变量确保正确考虑通过节点并分支到两个子节点的路径。 

## 解决方案```go
func longestPath(parent []int, s string) int {
    n := len(parent)
    tree := make([][]int, n)
    for i := 1; i < n; i++ {
        tree[parent[i]] = append(tree[parent[i]], i)
    }

    maxPath := 1

    var dfs func(int) int
    dfs = func(node int) int {
        longest, secondLongest := 0, 0
        for _, child := range tree[node] {
            childPath := dfs(child)
            if s[child] != s[node] {
                if childPath > longest {
                    secondLongest = longest
                    longest = childPath
                } else if childPath > secondLongest {
                    secondLongest = childPath
                }
            }
        }
        if longest+secondLongest+1 > maxPath {
            maxPath = longest + secondLongest + 1
        }
        return longest + 1
    }

    dfs(0)
    return maxPath
}
```在Go中，我们使用切片来表示邻接表。 DFS 函数作为闭包实现，以允许访问`maxPath`没有全局变量。 除此之外，逻辑与 Python 解决方案非常相似。 

## 工作示例

 **示例1：**```
parent = [-1,0,0,1,1,2], s = "abacbe"
```树结构：```
0(a)
├─1(b)
│ ├─3(a)
│ └─4(c)
└─2(a)
   └─5(e)
```DFS遍历：

 - 节点 3 返回 1（无子节点）。 
- 节点 4 返回 1。 
- 节点 1 看到子节点 3 和 4。具有不同字符的最长两条路径：1 (3)、1 (4)。 更新 max_path = 1+1+1 = 3。 
- 节点 5 返回 1。 
- 节点 2 看到孩子 5 具有不同的性格。 最长 = 1。 max_path 保持为 3。 
- 节点 0 看到子节点 1 和 2。子节点 1 最大路径 = 2 (1+1?)，子节点 2 最大路径 = 2。它们不能通过 0 组合，因为字符不同？ 实际上 0(a) 与 2(a) 相同，因此只考虑 1 个孩子（孩子 1）。 Max_path 仍为 3。 

最终结果：3

 **示例2：**```
parent = [-1,0,0,0], s = "aabc"
```树结构：```
0(a)
├─1(a)
├─2(b)
└─3(c)
```深度优先搜索：

 - 节点1返回1（与0相同的字符，不能扩展）。 
- 节点 2 返回 1（不同，最长=1）。 
- 节点 3 返回 1（不同，第二长=1）。 
- 节点 0 组合两条最长路径 1+1+1=3。 最大路径 = 3。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点都被访问一次，并且我们处理每个子节点一次。 |
 | 空间| O(n) | 存储 DFS 的邻接表和调用堆栈。 |

 我们遍历树一次，确保线性时间，并存储邻接列表，这需要与节点数量成比例的空间。
