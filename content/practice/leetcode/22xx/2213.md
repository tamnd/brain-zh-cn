[LeetCode 问题 2213](https://leetcode.com/problems/longest-substring-of-one-repeating-character/)

 **难度：** 🔴难
 **主题：** 数组、字符串、线段树、有序集

 ## 解决方案

 ## 问题理解

 问题给了我们一个初始字符串`s`以及一系列更新操作。 每次更新只更改字符串中的一个字符。 每次更新后，我们必须确定仅包含一个重复字符的最长连续子字符串的长度。 

子字符串是连续的，因此字符必须彼此相邻出现。 例如，在`"aaabbcccc"`，最长的重复子串是`"cccc"`与长度`4`。 

每个查询由两部分组成：

 -`queryIndices[i]`, 字符串中要修改的位置
 -`queryCharacters[i]`，放置在该位置的新字符

 应用更新后，我们立即计算修改后的字符串的答案并将其存储在结果数组中。 

约束条件非常重要：

 -`s.length`可以达到`10^5`- 查询数量也可以达到`10^5`每次更新后进行幼稚的重新计算会太慢。 甚至一个`O(n)`每个查询扫描会导致`O(n * k)`复杂性，这可能会变成`10^10`最坏情况下的操作。 

这立即表明我们需要一个能够：

 1. 高效更新单个仓位
 2. 高效维护最长重复子串

 核心挑战是改变一个角色可能会影响邻近的片段。 例如：```
aaaabaaa
```如果中间`'b'`变成`'a'`，两个单独的运行合并为一个大型运行：```
aaaaaaaa
```同样，更改可以将运行分成更小的部分。 

重要的边缘情况包括：

 - 长度的字符串`1`- 更新实际上并没有改变角色
 - 合并两个相邻运行的更新
 - 更新拆分了之前的大型运行
 - 所有字符都相同的字符串
 - 交替字符串，例如`"abababab"`该问题保证了有效的索引和小写英文字母，因此我们不需要处理无效的输入。 

## 方法

 ### 蛮力方法

 最简单的方法是：

 1.将每个更新直接应用于字符串
 2.从左到右扫描整个字符串
 3. 跟踪相同字符的最长连续块

 对于每个查询，我们都会比较相邻字符并计算条纹长度。 

这种方法是正确的，因为它每次都会根据更新的字符串显式地重新计算答案。 

然而，其性能却令人无法接受。 

如果：

-`n = 10^5`-`k = 10^5`然后在每次查询成本后扫描整个字符串：```
O(n * k) = O(10^10)
```这太慢了。 

### 最优方法，线段树

 关键的观察是单个字符更新仅影响较小的局部区域，但最长重复子串是全局属性。 

这是线段树的经典场景。 

我们构建一棵线段树，其中每个节点都存储有关其线段的足够信息，以便有效地组合两个子线段。 

对于每个细分，我们存储：

 -`left_char`, 段中的第一个字符
 -`right_char`, 段中的最后一个字符
 -`prefix`, 最长重复前缀的长度
 -`suffix`, 最长重复后缀的长度
 -`best`, 段中任意位置的最长重复子串
 -`length`，总段长度

 组合两个子段时：

 - 最好的答案可能完全在于左边的孩子
 - 完全在正确的孩子
 - 如果相邻字符匹配则跨越边界

 这允许更新和查询`O(log n)`时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(nk) | O(nk) | O(1) | O(1) | 每次更新后重新计算最长运行 |
 | 最佳| O((n + k) log n) | O((n + k) log n) | O(n) | 线段树动态维护最长重复子串 |

 ## 算法演练

 1. 在字符串上构建线段树。 

每个节点代表字符串的一个连续区间。 每个节点不是只存储一个值，而是存储足够的信息，以便在合并两个段时重建答案。 
2. 存储每个片段的元数据。 

对于每个节点，我们维护：

 - 最左边的角色
 - 最右边的角色
 - 最长重复前缀
 - 最长重复后缀
 - 段内最长的重复子串
 - 段长度

 该信息足以正确合并两个相邻段。 
3. 处理叶节点。 

一片叶子代表一个字符。 

对于单个字符：

 - 前缀长度 = 1
 - 后缀长度 = 1
 - 最佳长度 = 1
 4. 合并两个子节点。 

假设我们合并左段`A`和右段`B`。 

组合段长度为：```
A.length + B.length
```综合最佳答案最初是：```
max(A.best, B.best)
```如果：```
A.right_char == B.left_char
```那么重复的子串可以跨越边界。 

在这种情况下：```
cross = A.suffix + B.prefix
```我们更新：```
best = max(best, cross)
```5. 计算前缀长度。 

如果整个左段由相同的字符组成，并且它与右段的第一个字符匹配，则重复前缀将扩展到右子段。 
6. 计算后缀长度。 

类似地，如果整个右段是统一的并且与左段的最后一个字符匹配，则重复后缀将扩展到左子段。 
7. 流程更新。 

对于每个查询：

 - 更新更改索引对应的叶子
 - 重新计算返回根的路径上的所有祖先

 由于线段树的高度为`O(log n)`，更新效率高。 
8. 阅读答案。 

根节点始终存储整个字符串的答案。 

每次更新后，附加：```
tree[1].best
```到结果列表。 

### 为什么它有效

 线段树维护了每个区间的完整信息。 父区间内任何最长的重复子串必须是以下三种可能性之一：

 1. 完全在左孩子内部
 2. 完全在右孩子里面
 3、跨越孩子之间的界限

 存储的前缀和后缀长度正是评估第三种情况所需的长度。 由于每次合并都会从正确的子节点计算正确的值，因此整个树在每次更新后都保持正确。 

## Python 解决方案```python
from typing import List

class Node:
    def __init__(self):
        self.left_char = ""
        self.right_char = ""
        self.prefix = 0
        self.suffix = 0
        self.best = 0
        self.length = 0

class Solution:
    def longestRepeating(
        self,
        s: str,
        queryCharacters: str,
        queryIndices: List[int]
    ) -> List[int]:

        chars = list(s)
        n = len(chars)

        tree = [Node() for _ in range(4 * n)]

        def merge(left: Node, right: Node) -> Node:
            node = Node()

            node.length = left.length + right.length
            node.left_char = left.left_char
            node.right_char = right.right_char

            node.prefix = left.prefix
            if (
                left.prefix == left.length and
                left.right_char == right.left_char
            ):
                node.prefix = left.length + right.prefix

            node.suffix = right.suffix
            if (
                right.suffix == right.length and
                left.right_char == right.left_char
            ):
                node.suffix = right.length + left.suffix

            node.best = max(left.best, right.best)

            if left.right_char == right.left_char:
                node.best = max(
                    node.best,
                    left.suffix + right.prefix
                )

            return node

        def build(index: int, left: int, right: int) -> None:
            if left == right:
                node = tree[index]

                node.left_char = chars[left]
                node.right_char = chars[left]
                node.prefix = 1
                node.suffix = 1
                node.best = 1
                node.length = 1
                return

            mid = (left + right) // 2

            build(index * 2, left, mid)
            build(index * 2 + 1, mid + 1, right)

            tree[index] = merge(
                tree[index * 2],
                tree[index * 2 + 1]
            )

        def update(
            index: int,
            left: int,
            right: int,
            position: int,
            character: str
        ) -> None:

            if left == right:
                chars[position] = character

                node = tree[index]
                node.left_char = character
                node.right_char = character
                node.prefix = 1
                node.suffix = 1
                node.best = 1
                node.length = 1
                return

            mid = (left + right) // 2

            if position <= mid:
                update(
                    index * 2,
                    left,
                    mid,
                    position,
                    character
                )
            else:
                update(
                    index * 2 + 1,
                    mid + 1,
                    right,
                    position,
                    character
                )

            tree[index] = merge(
                tree[index * 2],
                tree[index * 2 + 1]
            )

        build(1, 0, n - 1)

        answer = []

        for character, position in zip(queryCharacters, queryIndices):
            update(1, 0, n - 1, position, character)
            answer.append(tree[1].best)

        return answer
```实现首先将字符串转换为可变列表，因为 Python 字符串是不可变的。 然后为线段树数组分配大小`4 * n`，它安全地容纳所有树节点。 

这`Node`类存储合并段所需的所有元数据。 这包括前缀和后缀长度、区间内的最佳答案以及边界字符。 

这`merge`函数是算法的核心。 它将两个子段合并为一个父段。 该逻辑仔细处理重复子串跨越中点的可能性。 

这`build`函数递归构造初始线段树。 叶节点对应单个字符，而内部节点则通过合并产生。 

这`update`函数递归下降到修改的位置，更新叶节点，然后重新计算所有受影响的祖先。 

每次查询后，根节点都会存储整个字符串的答案，因此`tree[1].best`直接附加到结果中。 

## 解决方案```go
package main

type Node struct {
	leftChar  byte
	rightChar byte
	prefix    int
	suffix    int
	best      int
	length    int
}

func longestRepeating(s string, queryCharacters string, queryIndices []int) []int {
	chars := []byte(s)
	n := len(chars)

	tree := make([]Node, 4*n)

	var merge func(Node, Node) Node

	merge = func(left Node, right Node) Node {
		node := Node{}

		node.length = left.length + right.length
		node.leftChar = left.leftChar
		node.rightChar = right.rightChar

		node.prefix = left.prefix
		if left.prefix == left.length &&
			left.rightChar == right.leftChar {
			node.prefix = left.length + right.prefix
		}

		node.suffix = right.suffix
		if right.suffix == right.length &&
			left.rightChar == right.leftChar {
			node.suffix = right.length + left.suffix
		}

		if left.best > right.best {
			node.best = left.best
		} else {
			node.best = right.best
		}

		if left.rightChar == right.leftChar {
			cross := left.suffix + right.prefix
			if cross > node.best {
				node.best = cross
			}
		}

		return node
	}

	var build func(int, int, int)

	build = func(index int, left int, right int) {
		if left == right {
			tree[index] = Node{
				leftChar:  chars[left],
				rightChar: chars[left],
				prefix:    1,
				suffix:    1,
				best:      1,
				length:    1,
			}
			return
		}

		mid := (left + right) / 2

		build(index*2, left, mid)
		build(index*2+1, mid+1, right)

		tree[index] = merge(
			tree[index*2],
			tree[index*2+1],
		)
	}

	var update func(int, int, int, int, byte)

	update = func(
		index int,
		left int,
		right int,
		position int,
		character byte,
	) {

		if left == right {
			chars[position] = character

			tree[index] = Node{
				leftChar:  character,
				rightChar: character,
				prefix:    1,
				suffix:    1,
				best:      1,
				length:    1,
			}
			return
		}

		mid := (left + right) / 2

		if position <= mid {
			update(index*2, left, mid, position, character)
		} else {
			update(index*2+1, mid+1, right, position, character)
		}

		tree[index] = merge(
			tree[index*2],
			tree[index*2+1],
		)
	}

	build(1, 0, n-1)

	answer := make([]int, 0, len(queryIndices))

	for i := 0; i < len(queryIndices); i++ {
		update(
			1,
			0,
			n-1,
			queryIndices[i],
			queryCharacters[i],
		)

		answer = append(answer, tree[1].best)
	}

	return answer
}
```Go 实现与 Python 版本非常相似，但一些特定于语言的差异值得注意。 

Go 字符串是不可变的，因此字符串被转换为`[]byte`切片以实现高效更新。 

线段树存储为切片`Node`结构。 结构体是 Go 中的值类型，因此合并返回完整`Node`价值观。 

Go 不直接支持嵌套命名函数，因此递归闭包声明为`var functionName func(...)`。 

所有整数都适合 Go 的默认值`int`类型，因为涉及的最大值最多是`10^5`。

 ## 边缘情况

 一种重要的边缘情况是字符串长度为`1`。 在这种情况下，每个查询仍然会产生一个答案`1`因为单个字符总是形成长度为重复的子串`1`。 该实现自然地处理这个问题，因为每个叶节点都有`best = 1`。 

当更新实际上没有改变角色时，就会发生另一种严重情况。 例如：```
"aaaa"
```更新索引`2`到`'a'`。 

有缺陷的实现可能会不必要地改变内部状态或意外地破坏合并逻辑。 线段树实现安全地重建受影响的路径，并且由于所有合并规则仍然有效，因此答案保持不变。 

当两个大的运行在更新的位置上合并时，会发生第三种棘手的情况。 考虑：```
aaabaaa
```如果中间`'b'`变成`'a'`，答案突然跳出`3`到`7`。 合并逻辑通过检查左孩子的最右边的字符是否等于右孩子的最左边的字符来专门处理这个问题。 如果是这样，则后缀和前缀长度组合正确。 

当一个大的运行被分割时，会发生另一种微妙的情况。 例如：```
aaaaa
```将中间字符更改为`'b'`创建：```
aabaa
```最佳答案来自`5`到`2`。 由于更新使用当前子值从头开始重建所有祖先节点，因此过时的信息永远不会保留在树中。
