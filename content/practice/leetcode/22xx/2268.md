[LeetCode 问题 2268](https://leetcode.com/problems/minimum-number-of-keypresses/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、贪婪、排序、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们确定输入给定字符串所需的**最小按键次数**`s`使用带有 9 个按钮的键盘。 每个按钮最多可以映射到 3 个字母，并且每个字母必须恰好映射到一个按钮。 键入字符时，按下的次数取决于其在按钮映射中的位置：第一个字母需要按一次，第二个字母需要按两次，第三个字母需要按三次。 

换句话说，我们得到了一串小写字母，我们需要以最佳方式将字母分配给键盘，以使按键总数最小化。 

问题要点：

 - 输入：一个字符串`s`长度可达`10^5`。 
- 输出：表示最小按键次数的单个整数。 
- 字符串仅包含小写英文字母（`a`到`z`）。 
- 26 个字母中的每一个都必须分配给一个按钮。 
- 每个按钮可以有 **1 到 3 个字母**。 

可能挑战简单实施的边缘情况包括：

 - 包含重复字母的字符串，尤其是那些出现超过 3 次的字符串。 
- 所有字母出现相同次数的字符串，需要小心放置。 
- 不需要使用所有按钮的短字符串。 

挑战在于有效地**将最常见的字母分配给需要较少按键的位置**。 

## 方法

 ### 蛮力方法

 一种强力方法是尝试 **将所有可能的字母分配给 9 个按钮**。 对于每个分配，我们将计算字符串所需的总按键次数`s`并选择最小值。 

这是有效的，因为它最终会找到最佳安排。 然而，可能的排列数量是天文数字：有 26 个字母和 9 个按钮，每个按钮最多有 3 个字母。 对于长度达到以下的字符串，计算所有组合是完全不可行的`10^5`。 这种方法具有**指数时间复杂度**。 

### 最佳方法

 关键的见解是，为了最大限度地减少按键次数，我们应该将**最常见的字母**分配给需要**较少按键**的位置。 也就是说，最常出现的字母应作为按钮上的第一个字母（按 1 次），其次最常出现的字母应作为第二个字母（按 2 次），依此类推。 

最佳方法的步骤：

 1.统计字符串中每个字母出现的频率`s`。 
2. 按照**频率降序**对字母进行排序。 
3. 按频率顺序将字母分配给按钮，填充每个按钮上的第一个位置，然后移至第二个位置，然后移至第三个位置。 
4. 根据分配的位置计算按键总数。 

这是一个**贪婪的解决方案**，因为我们总是将最频繁的剩余字母分配给最便宜的剩余位置。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(9^26) | O(9^26) | O(26) | 尝试所有可能的按钮分配 |
 | 最佳| O(n + 26 log 26) ≈ O(n) | O(26) | 计算频率、排序字母、贪婪分配 |

 ## 算法演练

 1.初始化一个hashmap，统计其中每个字符出现的频率`s`。 
2. 将所有字母及其出现频率提取到列表中。 
3. 按**频率降序**对此列表进行排序。 
4. 初始化总按键次数计数器。 
5. 循环排序列表并为每个字母计算其按键成本：

 - 确定其在按钮映射序列中的位置索引。 
- 位置指数`i`对应于`(i // 3) + 1`按下。 
- 将字母的频率乘以该成本并添加到总数中。 
6. 返回按键总数。 

**为什么有效：** 贪婪分配可确保将对总按键次数贡献最大的字母放置在需要较少按键的位置。 由于位置数量足够（9 个按钮 × 3 个位置 = 27 ≥ 26 个字母），因此可以对每个字母进行最佳分配。 

## Python 解决方案```python
class Solution:
    def minimumKeypresses(self, s: str) -> int:
        from collections import Counter
        
        # Step 1: Count frequency of each character
        freq = Counter(s)
        
        # Step 2: Sort frequencies in descending order
        sorted_freqs = sorted(freq.values(), reverse=True)
        
        total_presses = 0
        
        # Step 3: Assign letters to button positions
        for i, f in enumerate(sorted_freqs):
            presses_needed = (i // 3) + 1
            total_presses += f * presses_needed
        
        return total_presses
```**说明：** 我们计算每个字符的出现次数，从最频繁到最少对它们进行排序，然后将它们以三个为一组分配到按钮位置。 每组将所需的压力增加 1 次。 计算`(i // 3) + 1`准确地反映了这一点。 

## 解决方案```go
import "sort"

func minimumKeypresses(s string) int {
    freq := make(map[rune]int)
    
    // Step 1: Count frequency
    for _, ch := range s {
        freq[ch]++
    }
    
    // Step 2: Collect frequencies into a slice
    freqs := make([]int, 0, len(freq))
    for _, f := range freq {
        freqs = append(freqs, f)
    }
    
    // Step 3: Sort in descending order
    sort.Slice(freqs, func(i, j int) bool {
        return freqs[i] > freqs[j]
    })
    
    totalPresses := 0
    for i, f := range freqs {
        presses := (i / 3) + 1
        totalPresses += f * presses
    }
    
    return totalPresses
}
```**说明：** Go 可以高效地处理映射和切片。 频率图对出现次数进行计数，然后我们按降序对计数切片进行排序。 整数除法`(i / 3) + 1`计算每个字母所需的按键次数。

 ## 边缘情况

 1. **单字母字符串：**`s = "a"`。 只需按 1 次，算法即可将其正确分配给按钮。 这测试了最小的输入处理。 
2. **所有字母出现频率相同：**`s = "abcdefghijklmnopqrstuvwxyz"`。 排序不会改变顺序，但会确保每个字母都以最佳方式分配到按钮的第一个位置。 
3. **字母频率超出按钮容量：** 假设某个字母在 中出现超过 3 次`s`。 该算法正确地考虑了重复按键，因为每个按钮的字母数量仅影响每个字母实例所需的按键次数，而不影响频率计数。 

该解决方案可以正确处理大量输入、重复字母，并确保使用简单的贪婪方法最小化总按键次数。
