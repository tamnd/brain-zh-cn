[LeetCode 问题 2210](https://leetcode.com/problems/count-hills-and-valleys-in-an-array/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 该问题要求我们在整数数组中识别**山**和**山谷**`nums`。 **山**是两侧最接近的不相等邻居都小于当前值的位置，而**山谷**是这些邻居大于当前值的位置。 具有相同值的连续元素被视为同一山丘或山谷的一部分，因此不应重复计算重复项。 结果是不同山丘和山谷的总数。 

输入`nums`保证长度至少为 3，且所有值都在 1 到 100 之间。由于每个元素必须具有左和右不相等的邻居才有资格成为山或山谷，因此第一个和最后一个元素不能是山或山谷。 边缘情况包括连续的重复项和高原，其中多个相同的值被分组在一起； 如果周围的值允许，这些必须被视为单个山丘或山谷。 

预期输出是一个整数，表示数组中山丘和山谷的数量。 

## 方法

 **暴力**方法将检查每个元素，跳过第一个和最后一个元素，并找到最近的非相等邻居来检查山或山谷条件。 虽然正确，但这需要左右扫描每个元素，导致最坏情况的时间复杂度为 O(n²)，由于约束较小，这是可以接受的，但没有必要。 

**最佳方法**观察到我们可以首先**压缩连续的重复项**以减少冗余检查。 压缩后，每个剩余元素都可以与其直接邻居进行比较。 这样就无需反复左右扫描。 该方法相对于压缩数组长度在时间上是线性的，最多为`n`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 左右扫描每个元素以查找不相等的邻居 |
 | 最佳 | O(n) | O(n) | 压缩重复项并直接比较邻居 |

 ## 算法演练

 1.初始化一个空列表`compressed`存储不同连续数字的序列。 
2. 迭代`nums`。 对于每个元素，将其附加到`compressed`仅当它与前一个元素不同时。 
3. 初始化计数器`count`为零。 
4. 迭代`compressed`从第二个元素到倒数第二个元素。 
5. 对于每个元素，将其与它的直接邻居进行比较：如果它大于两者，则递增`count`对于一座山； 如果小于两者，则增加`count`对于一个山谷。 
6. 返回`count`。 

**为什么有效：** 通过首先压缩重复项，我们确保将平稳期视为一个单元。 仅比较压缩数组中的直接邻居准确地反映了原始数组中最接近的非相等邻居。 这保证了正确性，同时避免了多余的检查。 

## Python 解决方案```python
from typing import List

class Solution:
    def countHillValley(self, nums: List[int]) -> int:
        if not nums or len(nums) < 3:
            return 0

        # Step 1: compress consecutive duplicates
        compressed = [nums[0]]
        for num in nums[1:]:
            if num != compressed[-1]:
                compressed.append(num)

        count = 0
        # Step 2: check hills and valleys in compressed array
        for i in range(1, len(compressed) - 1):
            if compressed[i] > compressed[i-1] and compressed[i] > compressed[i+1]:
                count += 1
            elif compressed[i] < compressed[i-1] and compressed[i] < compressed[i+1]:
                count += 1

        return count
```Python 解决方案首先压缩连续的重复项以简化邻居比较。 然后，它迭代压缩数组，通过与左右邻居比较来检查每个元素是否形成山丘或山谷。 这消除了平台期的错误计数。 

## 解决方案```go
func countHillValley(nums []int) int {
    if len(nums) < 3 {
        return 0
    }

    // Step 1: compress consecutive duplicates
    compressed := []int{nums[0]}
    for i := 1; i < len(nums); i++ {
        if nums[i] != compressed[len(compressed)-1] {
            compressed = append(compressed, nums[i])
        }
    }

    count := 0
    // Step 2: check hills and valleys in compressed array
    for i := 1; i < len(compressed)-1; i++ {
        if compressed[i] > compressed[i-1] && compressed[i] > compressed[i+1] {
            count++
        } else if compressed[i] < compressed[i-1] && compressed[i] < compressed[i+1] {
            count++
        }
    }

    return count
}
```Go 解决方案反映了 Python 逻辑。 切片`compressed`处理重复压缩，并迭代检查紧邻的山丘和山谷。 Go 特定的注意事项包括动态切片附加和显式长度检查。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 1. **严格递增或递减数组**：在此类数组中，任何元素都不能是山丘或山谷，因为至少有一个相邻元素总是分别较大或较小。 我们的解决方案正确返回零，因为邻居比较永远不会成功。 
2. **开始或结束处的高原**：如果在数组的开始或结束处出现重复，则它们不能是山丘或山谷，因为一侧缺少邻居。 压缩可确保重复项不会导致错误计数。 
3. **中间多个连续重复**：长高原可以形成山丘、山谷，也可以两者都不形成。 通过首先压缩重复项，所有相同的连续值将被视为单个元素。 然后，相邻比较可以正确识别高原是否构成山丘或山谷，从而避免重复计算。
