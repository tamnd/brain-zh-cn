[LeetCode 问题 2288](https://leetcode.com/problems/apply-discount-to-prices/)

 **难度：** 🟡 中等
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们处理一个表示包含单词和价格的句子的字符串，其中价格是以美元符号开头的单词`⟦PROTECT_3⟧1e5`或者`5$`）应保持不变。 

输入`sentence`保证具有单空格分隔的单词，没有前导或尾随空格，并且所有有效价格都是没有前导零且最多 10 位数字的正整数。 这`discount`值范围从 0 到 100。主要挑战是正确识别有效价格并确保应用折扣后的精确格式，尤其是四舍五入到小数点后两位或应用 100% 折扣等情况。 

重要的边缘情况包括以`⟦PROTECT_4⟧`，接近10位数的非常大的价格，0%折扣（不变），以及100%折扣（价格变成`$0.00`）。 

## 方法

 暴力方法会迭代每个单词，检查它是否以`$`，尝试将子字符串解析为整数，如果解析成功，则计算折扣价格并将其格式化为两位小数。 这可以正常工作，但可以通过使用 Python 字符串和数字格式化工具使其更加简洁和高效，而无需手动解析和字符串连接逻辑。 

最佳解决方案的关键在于有效价格严格遵循`$`接下来是数字模式。 通过将句子拆分为单词，根据该模式检查每个单词，将数字部分转换为浮点数，应用折扣，并将其格式化回两位小数，我们可以一次有效地处理整个句子，而无需额外的数据结构。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n) | 将句子拆分为单词，使用条件检查解析每个单词，计算折扣，重新组合句子 |
 | 最佳| O(n) | O(n) | 单通道分割，检查数字模式，通过格式化计算折扣价格，重建句子 |

 这里`n`是句子中的字符数，并且`m`是平均单词长度。 

## 算法演练

 1. 使用空格字符作为分隔符将输入句子拆分为单词。 这使我们能够独立处理每个单词并稍后重建句子。 
2. 迭代每个单词。 对于每个单词：

 a. 检查它是否以以下开头`$`并且有多个字符。 

b. 验证后面的所有字符`$`是数字。 如果不是，则将其视为非价格词。 

c. 将数字部分转换为浮点数。 

d. 计算折扣价格为`price * (100 - discount) / 100`。 

e. 将折扣价格格式化为字符串，精确到两位小数，前缀为`$`。 
3. 如果有效，则将句子中的原词替换为折扣价，否则保持不变。 
4. 将所有单词重新连接成一个带有空格的字符串，形成最终的修改后的句子。 

工作原理：该算法可确保仅修改有效价格，并应用正确的折扣和格式。 不变的是，每个单词要么被其折扣版本替换，要么保持不变，保留原始句子结构。 

## Python 解决方案```python
class Solution:
    def discountPrices(self, sentence: str, discount: int) -> str:
        words = sentence.split(' ')
        result = []
        for word in words:
            if word.startswith('$') and len(word) > 1 and word[1:].isdigit():
                price = float(word[1:])
                discounted_price = price * (100 - discount) / 100
                result.append(f"${discounted_price:.2f}")
            else:
                result.append(word)
        return ' '.join(result)
```在此 Python 实现中，我们首先将句子拆分为单词，迭代它们，并通过验证每个单词的开头来检查它是否是有效价格`$`其余的都是数字。 如果它是有效价格，我们将其转换为浮点数，应用折扣，将其格式化为两位小数，并将其附加到结果列表中。 非价格词保持不变。 最后，我们将所有单词连接成一个字符串以返回。 

## 解决方案```go
import (
    "fmt"
    "strings"
    "unicode"
)

func discountPrices(sentence string, discount int) string {
    words := strings.Split(sentence, " ")
    for i, word := range words {
        if len(word) > 1 && word[0] == '$' {
            isDigit := true
            for _, ch := range word[1:] {
                if !unicode.IsDigit(ch) {
                    isDigit = false
                    break
                }
            }
            if isDigit {
                var price float64
                fmt.Sscanf(word[1:], "%f", &price)
                discounted := price * float64(100-discount) / 100
                words[i] = fmt.Sprintf("$%.2f", discounted)
            }
        }
    }
    return strings.Join(words, " ")
}
```在 Go 中，我们同样将句子分成单词并检查每个单词的`$`前缀。 我们迭代字符以确保它们是数字。 如果有效，我们使用以下方法解析数字部分`fmt.Sscanf`，应用折扣，并使用两位小数格式化结果`fmt.Sprintf`。 连接单词后返回重建的句子。
