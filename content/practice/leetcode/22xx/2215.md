 # LeetCode 2215，求两个数组的差异

 ## 问题理解

 此问题要求我们比较两个整数数组，并识别出现在一个数组中而不是另一个数组中的唯一值。 

我们有两个 0 索引的整数数组，`nums1`和`nums2`。 目标是返回一个包含两个单独列表的列表：

 - 第一个列表应包含存在于中的每个不同的整数`nums1`但不存在于`nums2`。 
- 第二个列表应包含存在于中的每个不同的整数`nums2`但不存在于`nums1`。 

关键词“独特”非常重要。 即使一个数字在数组中出现多次，它也只能在结果中出现一次。 

例如，如果`nums1 = [1,2,3,3]`和`nums2 = [1,1,2,2]`, 数量`3`出现两次`nums1`，但输出应该只包含一个`3`。 

返回整数的顺序并不重要，这给了我们实现的灵活性。 

限制相对较小：

 - 每个数组长度最多为`1000`- 值范围为`-1000`到`1000`尽管约束足够小，可以使用多种方法，但问题本质上是关于有效的成员资格检查和重复删除。 这自然建议使用基于哈希的数据结构，例如集合。 

需要考虑一些重要的边缘情况：

 - 包含重复项的数组
 - 完全相同的数组
 - 没有重叠值的数组
 - 包含负整数的数组
 - 一侧提供空结果列表的数组

 该问题保证两个数组都至少包含一个元素，因此我们不需要处理完全空的输入数组。 

## 方法

 ### 蛮力方法

 一种简单的解决方案是检查一个数组中的每个元素，并手动检查它是否存在于另一个数组中。 

对于每一个值`nums1`，我们可以扫描`nums2`查看该值是否存在。 如果它不存在，我们将其添加到结果中。 我们会在相反的方向重复相同的过程`nums2`。 

由于可能会出现重复，因此我们还需要一种额外的机制来避免多次添加相同的数字。 

这种方法可以正常工作，因为每个元素都与其他数组进行显式比较。 然而，循环内的成员资格检查会导致重复扫描。 

如果`n`的长度是`nums1`和`m`的长度是`nums2`，检查会员费用`O(m)`对于中的每个元素`nums1`，并且类似地`O(n)`对于元素在`nums2`。 

这会导致二次型行为。 

### 最佳方法

 关键的观察是我们反复需要回答这个问题：

 “这个值存在于另一个数组中吗？”

 哈希集是理想的选择，因为集成员资格检查大约是`O(1)`平均而言。 

我们可以将两个数组转换为集合：```
set1 = set(nums1)
set2 = set(nums2)
```这会立即删除重复项并允许快速查找。 

然后：

 - 任何值`set1`但不在`set2`属于第一个结果列表。 
- 任何值`set2`但不在`set1`属于第二个结果列表。 

这甚至可以直接使用集合差运算来表达。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n × m) | O(n + m) | 重复线性隶属度检查 |
 | 最佳| O(n + m) | O(n + m) | 使用哈希集进行快速查找和重复删除 |

 ## 算法演练

 1. 转换`nums1`到一个名为的哈希集`set1`。 

这会自动删除重复项并提供恒定时间的成员资格查找。 
2. 转换`nums2`到一个名为的哈希集`set2`。 

这对于第二个数组具有相同的目的。 
3. 创建一个名为的空列表`only_in_nums1`。 

这将存储存在于中的数字`set1`但缺席于`set2`。 
4. 迭代中的每个值`set1`。 

对于每个值，检查它是否不存在于`set2`。 如果该值缺失于`set2`，将其附加到`only_in_nums1`。 
5. 创建另一个空列表，名为`only_in_nums2`。 

这将存储存在于中的数字`set2`但缺席于`set1`。 
6. 迭代中的每个值`set2`。 

对于每个值，检查它是否不存在于`set1`。 如果缺少，请将其附加到`only_in_nums2`。 
7. 返回最终结果为：```
[only_in_nums1, only_in_nums2]
```### 为什么它有效

 该算法之所以有效，是因为集合仅包含不同的元素。 因此，在比较开始之前会自动消除重复项。 

对于每一个值`set1`，我们检查是否存在相同的值`set2`。 如果没有，该值必须只出现在`nums1`。 相同的逻辑对称地适用于`set2`。 

由于每个不同的值都会针对相反的集合进行一次检查，因此该算法可以正确地生成所有所需的差异。 

## Python 解决方案```python
from typing import List

class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        set1 = set(nums1)
        set2 = set(nums2)

        only_in_nums1 = []
        only_in_nums2 = []

        for num in set1:
            if num not in set2:
                only_in_nums1.append(num)

        for num in set2:
            if num not in set1:
                only_in_nums2.append(num)

        return [only_in_nums1, only_in_nums2]
```实现首先将两个输入数组转换为集合。 这是最重要的步骤，因为它同时删除重复项并实现快速成员资格检查。 

然后创建两个结果列表。 第一个循环检查每个唯一值`nums1`。 如果某个值不存在于`set2`，它专属于`nums1`，所以它被附加到`only_in_nums1`。 

第二个循环对唯一的值执行相反的相同逻辑`nums2`。 

最后，两个结果列表以所需的格式一起返回。 

另一种实现可以使用直接集合减法：```python
list(set1 - set2)
```然而，上面显示的显式循环使算法更容易遵循和解释。 

## 解决方案```go
func findDifference(nums1 []int, nums2 []int) [][]int {
    set1 := make(map[int]bool)
    set2 := make(map[int]bool)

    for _, num := range nums1 {
        set1[num] = true
    }

    for _, num := range nums2 {
        set2[num] = true
    }

    onlyInNums1 := []int{}
    onlyInNums2 := []int{}

    for num := range set1 {
        if !set2[num] {
            onlyInNums1 = append(onlyInNums1, num)
        }
    }

    for num := range set2 {
        if !set1[num] {
            onlyInNums2 = append(onlyInNums2, num)
        }
    }

    return [][]int{onlyInNums1, onlyInNums2}
}
```Go没有内置的集合类型，因此实现使用`map[int]bool`模拟哈希集。 键代表存储的值，布尔值除了指示存在之外并不特别重要。 

切片用于结果列表。 当一侧不存在唯一值时，自然会返回空切片。 

不存在整数溢出问题，因为约束非常小。

 ## 边缘情况

 ### 具有许多重复项的数组

 一个常见的错误是意外地在结果中返回重复的值。 例如：```
nums1 = [3,3,3]
nums2 = [1]
```幼稚的实现可能会错误地返回`[3,3,3]`。 将数组转换为集合会立即删除重复项，确保每个值在输出中仅出现一次。 

### 完全相同的数组

 如果两个数组包含完全相同的值，则任何一方都不应提供任何唯一元素。```
nums1 = [1,2,3]
nums2 = [1,2,3]
```正确的输出是：```
[[], []]
```该实现会自然地处理此问题，因为每个成员资格检查都会成功，因此不会将任何内容附加到任一结果列表中。 

### 没有重叠的数组

 如果数组没有共同值：```
nums1 = [1,2]
nums2 = [3,4]
```两组中的每个值都应出现在结果中。 

此案例验证了实现在比较期间不会意外删除有效的唯一元素。 

### 负数

 由于约束允许负整数，因此实现必须正确处理低于零的值。 

哈希集对正整数和负整数统一工作，因此不需要特殊处理。 价值观如`-1000`与正值的处理方式完全相同。
