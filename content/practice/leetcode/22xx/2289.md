 **难度：** 🟡 中等
 **主题：** 数组、链表、动态规划、堆栈、单调堆栈、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们确定制作给定数组需要多少步骤`nums`通过重复删除破坏非递减属性的元素来实现非递减。 具体来说，对于每个步骤，任何元素`nums[i]`在哪里`nums[i - 1] > nums[i]`被删除。 这个过程一直持续到数组完全不减为止。 输入是一个从 0 索引的整数数组，输出是一个表示所需步骤数的整数。 

约束表明数组可以很大，最多可以有 10^5 个元素，每个元素最多可以有 10^9 个。 这表明重复扫描并直接从数组中删除元素的简单方法可能太慢。 重要的边缘情况包括已经非递减的数组、严格递减的数组、具有重复元素的数组以及仅具有一个元素的数组。 

## 方法

 **暴力方法**涉及模拟问题陈述中描述的过程。 在每次迭代中，我们从左到右扫描数组，识别其中的所有元素`nums[i - 1] > nums[i]`，删除它们，然后重复，直到没有元素需要删除。 虽然这是正确的，但在最坏的情况下可能需要 O(n^2) 时间，因为每个步骤可能仅删除一个元素，并且重复扫描数组的成本很高。 

**最佳方法**依赖于这样的观察：删除元素所需的步骤数取决于其左侧的元素。 使用**单调堆栈**，我们可以跟踪递减序列并确定每个元素的步骤数，直到将其删除。 对于每个元素，我们检查堆栈中的元素，并将其步数计算为比大于它的元素的最大步数多 1。 这允许计算**单次**中的总步数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 显式模拟每个步骤，迭代删除违规元素 |
 | 最佳| O(n) | O(n) | 使用单调堆栈高效跟踪每个元素的步数 |

 ## 算法演练

 1. 初始化一个空堆栈。 每个堆栈元素都是一对`(value, steps)`在哪里`value`是来自的元素`nums`和`steps`is the number of steps until it would be removed.
 2. 初始化变量`max_steps`到 0。这将跟踪所有元素中的最大步数。 
3. 迭代每个元素`num`在`nums`:

 1.初始化本地计数器`steps`至 0。 
2. 当栈非空且栈顶元素的值小于或等于`num`，弹出并更新`steps`至最大`steps`以及弹出元素的步骤。 
3. 如果此后堆栈非空，则递增`steps`自 1 起`num`由于左侧元素较大，最终将被删除。 
4. 推`(num, steps)`到堆栈上。 
5. 更新`max_steps`至最大`max_steps`和`steps`。 
4.处理完所有元素后，返回`max_steps`。 

**为什么有效：** 堆栈维护着从左到右递减的元素序列。 通过存储删除每个元素所需的步数，我们可以在每个元素的 O(1) 摊销时间内计算每个新元素的步数。 这保证了计算的最大步数对应于使数组不减少所需的迭代总数。 

## Python 解决方案```python
from typing import List

class Solution:
    def totalSteps(self, nums: List[int]) -> int:
        stack = []  # Stack of pairs (value, steps)
        max_steps = 0
        
        for num in nums:
            steps = 0
            while stack and stack[-1][0] <= num:
                steps = max(steps, stack.pop()[1])
            if stack:
                steps += 1
            stack.append((num, steps))
            max_steps = max(max_steps, steps)
        
        return max_steps
```在此 Python 解决方案中，堆栈用于存储元组`(value, steps)`。 对于每个数字，我们通过检查之前较小或相等的元素来确定需要删除多少步。 如果堆栈中仍有更大的元素，我们将增加步数。`max_steps`跟踪所需的总体步骤。 
## 解决方案```go
func totalSteps(nums []int) int {
	type pair struct {
		val, steps int
	}
	stack := []pair{}
	maxSteps := 0

	for _, num := range nums {
		steps := 0
		for len(stack) > 0 && stack[len(stack)-1].val <= num {
			steps = max(steps, stack[len(stack)-1].steps)
			stack = stack[:len(stack)-1]
		}
		if len(stack) > 0 {
			steps++
		}
		stack = append(stack, pair{num, steps})
		if steps > maxSteps {
			maxSteps = steps
		}
	}

	return maxSteps
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}
```在 Go 中，使用相同的单调堆栈方法。 我们定义一个`pair`结构体同时保存值和步数。 切片操作用于模拟堆栈压入和弹出操作。 该逻辑与 Python 实现密切相关。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个元素最多从堆栈中压入和弹出一次 |
 | 空间| O(n) | 在最坏的情况下堆栈最多可以包含 n 个元素 |

 时间复杂度是线性的，因为每个元素仅检查一次，并且堆栈操作分摊为 O(1)。 空间复杂度与堆栈大小成正比。
