[LeetCode 问题 2217](https://leetcode.com/problems/find-palindrome-with-fixed-length/)

 **难度：** 🟡 中等
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 该问题要求我们为多个查询找到固定长度的第 k 个最小正回文。 具体来说，我们得到一个数组`queries`其中每个元素表示我们需要找到的回文的位置，以及一个整数`intLength`它指定了我们感兴趣的回文数中的位数。回文数是向前和向后读取相同的数字，并且不允许有前导零。 对于每个查询，如果第 k 个回文不存在（因为 k 太大），我们应该返回`-1`。 

输入`queries`最多可以有`50,000`元素，每个查询值可以大到`10^9`。 整数长度最大可达`15`。 这意味着一种暴力方法可以生成所有回文数`10^15`是不可行的。 这些约束告诉我们，我们需要一种可以直接计算第 k 个回文而无需枚举所有较小回文的算法。 

边缘情况包括较小的长度（例如`intLength = 1`）以及所请求的回文不存在的非常大的查询。 回文不能从零开始，因此对于长度大于 1 的情况，第一位数字必须至少为 1。超过给定长度的回文总数的查询必须返回`-1`。 

## 方法

 暴力方法将涉及顺序生成给定长度的所有回文，然后为每个查询选择第 k 个回文。 虽然概念上很简单，但效率极低，因为回文数的数量随着长度呈指数增长，尤其是对于`intLength > 10`。 这种方法对于大输入来说太慢并且消耗太多内存。 

最佳方法依赖于关键观察，即回文完全由其前半部分（如果长度为奇数，则由前半部分加上中间数字）决定。 例如，对于 5 位回文`abcde`，数量必须满足`a=e`,`b=d`， 和`c`可以是任何数字。 因此，如果我们枚举所有可能的前半部分，就可以直接构造相应的完整回文。 使用它，我们可以计算第 k 个回文，而无需生成所有先前的回文。 上半场不得从零开始。 我们可以将第 k 个前半部分计算为给定长度的最小可能前半部分的整数偏移量，然后对其进行镜像以生成回文。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(10^(intLength/2) * len(查询)) | O(10^(intLength/2)) | O(10^(intLength/2)) | 依次生成所有回文并为其建立索引。 对于大长度来说太慢。 |
 | 最佳| O(len(查询) * intLength) | O(len(查询)) | 直接计算前半部分，对其进行镜像，并处理奇数/偶数长度。 |

 ## 算法演练

 1. 计算回文数前半部分的位数。 如果长度是`intLength`， 让`halfLength = (intLength + 1) // 2`。 
2. 计算最小的可能前半部分为`start = 10^(halfLength - 1)`。 这确保没有前导零。 
3. 对于每个查询`k`在`queries`:

 a. 将第 k 个回文的前半部分计算为`firstHalf = start + k - 1`。 

b. 检查是否有位数`firstHalf`超过`halfLength`。 如果存在，则说明第k个回文不存在，所以追加`-1`到答案。 

c. 否则，转换`firstHalf`到一个字符串。 镜像它以形成完整的回文。 如果`intLength`为奇数时，镜像时排除前半部分的最后一位。 

d. 将镜像字符串转换回整数并将其附加到结果中。 
4. 返回结果数组。 

为什么有效：通过直接计算前半部分并对其进行镜像，我们保证该数字是正确长度的回文数。 该算法确保通过返回正确处理超过可能回文总数的查询`-1`。 

## Python 解决方案```python
from typing import List

class Solution:
    def kthPalindrome(self, queries: List[int], intLength: int) -> List[int]:
        halfLength = (intLength + 1) // 2
        start = 10 ** (halfLength - 1)
        result = []
        
        for k in queries:
            firstHalf = start + k - 1
            if len(str(firstHalf)) > halfLength:
                result.append(-1)
                continue
            
            firstHalfStr = str(firstHalf)
            if intLength % 2 == 0:
                fullPalindrome = firstHalfStr + firstHalfStr[::-1]
            else:
                fullPalindrome = firstHalfStr + firstHalfStr[:-1][::-1]
            
            result.append(int(fullPalindrome))
        
        return result
```在实现中，我们首先计算`halfLength`和`start`定义有效前半部分的范围。 对于每个查询，我们将起始部分增加一半`k - 1`to reach the k-th first half. 我们检查前半部分是否超出了处理无效查询所允许的位数。 然后，我们使用字符串操作构造完整的回文，适当镜像前半部分的奇数或偶数长度。 The result is collected in a list and returned.

 ## 解决方案```go
import (
    "strconv"
)

func kthPalindrome(queries []int, intLength int) []int64 {
    halfLength := (intLength + 1) / 2
    start := int64(1)
    for i := 1; i < halfLength; i++ {
        start *= 10
    }
    
    result := make([]int64, len(queries))
    
    for i, k := range queries {
        firstHalf := start + int64(k-1)
        if len(strconv.FormatInt(firstHalf, 10)) > halfLength {
            result[i] = -1
            continue
        }
        
        firstHalfStr := strconv.FormatInt(firstHalf, 10)
        var fullPalindromeStr string
        if intLength%2 == 0 {
            rev := reverseString(firstHalfStr)
            fullPalindromeStr = firstHalfStr + rev
        } else {
            rev := reverseString(firstHalfStr[:len(firstHalfStr)-1])
            fullPalindromeStr = firstHalfStr + rev
        }
        
        palindrome, _ := strconv.ParseInt(fullPalindromeStr, 10, 64)
        result[i] = palindrome
    }
    
    return result
}

func reverseString(s string) string {
    runes := []rune(s)
    for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
        runes[i], runes[j] = runes[j], runes[i]
    }
    return string(runes)
}
```在 Go 中，我们使用`strconv`用于字符串转换并实现辅助函数`reverseString`反映上半场。 算术和逻辑镜像Python版本，并注意处理int64转换和溢出。
