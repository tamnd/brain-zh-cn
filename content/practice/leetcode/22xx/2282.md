[LeetCode 问题 2282](https://leetcode.com/problems/number-of-people-that-can-be-seen-in-a-grid/)

 **难度：** 🟡 中等
 **主题：** 数组、堆栈、矩阵、单调堆栈

 ## 解决方案

 ## 问题理解

 该问题要求我们确定，对于二维高度网格中的每个人，根据特定的视线规则，他们可以看到多少其他人。 每个人在岗位上`(i, j)`可以在同一行的直接右侧或同一列的正下方看到另一个人。 关键的限制是观看者和目标之间的每个人都必须比他们都矮。 换句话说，观看者的视线被中间更高或同等身高的人阻挡。 

输入是一个二维数组`heights`尺寸的`m x n`在哪里`1 <= m, n <= 400`，每个高度值是一个正整数，最多`10^5`。 输出应该是`m x n`二维数组，其中每个单元格包含该位置的人可以看到的人数。 

限制表明，扫描每个人的每一行和每一列的强力方法可能会非常昂贵，特别是对于多达 400 行和列，这使得`O(m * n * max(m, n))`接近可能太慢。 

边缘情况包括高度单调增加或减少的行或列、单行或单列网格以及具有相同高度的网格，这可能会模糊可见性。 

## 方法

 **暴力方法**将迭代每个人，并且对于每个人，沿着他们的行向右扫描并沿着他们的列向下扫描，计算可见的人。 对于每个人，如果遇到更高或等高的人，我们就会停止沿某个方向扫描。 这种方法之所以有效，是因为它直接检查每个可能的视线，但效率很低，因为每行和每列都会被扫描多次。 

**最佳方法**利用**单调堆栈**来有效计算每行和每列中可见人员的数量。 对于给定的行（或列），我们以相反的顺序迭代（行从右到左，列从下到上），使用堆栈来维护高度的递减序列。 对于每个人，我们可以通过计算从堆栈中弹出的元素直到遇到更高或等高的人为止，快速确定他们可以看到右侧（或下方）的人数。 这减少了重复扫描并显着降低了复杂性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n * 最大(m, n)) | O(1) | O(1) | 直接向右和向下扫描每个人，简单但速度慢 |
 | 最佳| O(m * n) | O(最大(m, n)) | 每行每列使用单调堆栈，速度更快 |

 ## 算法演练

 1. 初始化一个2D数组`answer`尺寸的`m x n`用零填充以存储结果。 
2. 对于每一行，使用单调堆栈计算右侧可见人员的数量。 从最后一列迭代到第一列：

 - 维护一个堆栈，其中每个条目都存储高度和该位置可见人员的数量。 
- 当当前高度大于堆栈顶部时，弹出堆栈并将其计数添加到当前人员的计数中。 
- 如果弹出后堆栈不为空，则将计数加 1，因为下一个更高的人可见。 
- 将当前高度及其计数推入堆栈。 
3. 对每一列重复相同的过程，向下计算可见人员：

 - 从最后一行迭代到列中的第一行。 
- 应用相同的单调堆栈逻辑。 
4. 将按行和按列计算的计数求和为`answer`。 
5. 返回`answer`大批。 

**为什么起作用：** 单调堆栈保持了它包含严格递减顺序的身高的不变性，因此从堆栈中弹出可以有效地计算所有连续可见的矮个子，直到一个较高的人挡住视线。 这确保了正确计数，而无需重复扫描每行。 

## Python 解决方案```python
from typing import List

class Solution:
    def seePeople(self, heights: List[List[int]]) -> List[List[int]]:
        m, n = len(heights), len(heights[0])
        answer = [[0] * n for _ in range(m)]
        
        # Count visible people to the right for each row
        for i in range(m):
            stack = []
            for j in range(n - 1, -1, -1):
                count = 0
                while stack and heights[i][j] > stack[-1][0]:
                    count += stack.pop()[1]
                if stack:
                    count += 1
                stack.append((heights[i][j], count))
                answer[i][j] += count
        
        # Count visible people downward for each column
        for j in range(n):
            stack = []
            for i in range(m - 1, -1, -1):
                count = 0
                while stack and heights[i][j] > stack[-1][0]:
                    count += stack.pop()[1]
                if stack:
                    count += 1
                stack.append((heights[i][j], count))
                answer[i][j] += count
        
        return answer
```**实现演练：** 首先，我们初始化答案网格。 然后，对于每一行，我们使用堆栈从右向左扫描，以计算每个人可以看到右侧的人数。 采用同样的方法，从下到上扫描每一列，向下计数可见度。 堆栈条目存储可见人员的身高和数量，这使我们能够有效地聚合计数。 最后，将两个计数相加为`answer`。 

## 解决方案```go
func seePeople(heights [][]int) [][]int {
    m, n := len(heights), len(heights[0])
    answer := make([][]int, m)
    for i := range answer {
        answer[i] = make([]int, n)
    }
    
    // Count visible people to the right
    for i := 0; i < m; i++ {
        stack := [][2]int{}
        for j := n - 1; j >= 0; j-- {
            count := 0
            for len(stack) > 0 && heights[i][j] > stack[len(stack)-1][0] {
                count += stack[len(stack)-1][1]
                stack = stack[:len(stack)-1]
            }
            if len(stack) > 0 {
                count += 1
            }
            stack = append(stack, [2]int{heights[i][j], count})
            answer[i][j] += count
        }
    }
    
    // Count visible people downward
    for j := 0; j < n; j++ {
        stack := [][2]int{}
        for i := m - 1; i >= 0; i-- {
            count := 0
            for len(stack) > 0 && heights[i][j] > stack[len(stack)-1][0] {
                count += stack[len(stack)-1][1]
                stack = stack[:len(stack)-1]
            }
            if len(stack) > 0 {
                count += 1
            }
            stack = append(stack, [2]int{heights[i][j], count})
            answer[i][j] += count
        }
    }
    
    return answer
}
```**Go 特定注释：** 我们使用切片而不是列表。 堆栈存储一个二元素数组`[height, count]`。 切片操作`stack = stack[:len(stack)-1]`相当于`pop`在Python中。 我们初始化`answer`数组使用`make`以保证合理分配。 

## 工作示例

 **示例1：**`heights = [[3,1,4,2,5]]`处理行：

 - 从右开始：5看到0
 - 2 见 1 (5)
 - 4 看到 2（2 和 5）
 - 1 见 1 (4)
 - 3 看到 2（1 和 4）

 由于它是单行，所以没有向下的可见性。 最终的`answer = [[2,1,2,1,0]]`。 

**示例2：**`heights = [[5,1],[3,1],[4,1]]`按行计数：

 - 第 0 行：5 看到 1、0； 1 看到 0,0
 - 第 1 行：3 看到 1,0； 1 看到 0,0
 - 第 2 行：4 看到 1,0； 1 看到 0,0

 按列计数：

 - 第 0 列：5 见 2 (3,4)； 3见1(4)； 4 看到 0
 - 第 1 列：1 看到 2（1 个在下面，没有一个更高）； 1 看到 1； 1 看到 0

 决赛`answer = [[3,1],[2,1],[1,0]]`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 每个单元在每个方向最多从堆栈中推送和弹出一次，总计与单元数量呈线性 |
 | 空间| O(最大(m, n)) | 每行或每列的堆栈，最大长度等于行或列中的单元格数量 |

 原因是单调堆栈操作按每个元素分摊 O(1)，导致总体时间为 O(m * n)。 空间由最大的行或列长度决定。
