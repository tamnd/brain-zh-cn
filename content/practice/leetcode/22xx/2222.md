[LeetCode 问题 2222](https://leetcode.com/problems/number-of-ways-to-select-buildings/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算从表示为二进制字符串的街道中选择**恰好 3 栋建筑物**的方法数量`s`，使得所选建筑物中没有两个连续的建筑物具有相同的类型。 这里，`0`代表一个办事处，并且`1`代表一家餐厅。 本质上，对于位于以下位置的三座选定建筑物`i < j < k`, 子串`s[i]s[j]s[k]`必须是`"010"`或者`"101"`。 

输入`s`长度可达 10^5，因此任何单独检查所有可能的三元组（O(n^3)）的方法都是不可行的。 预期输出是满足交替类型约束的**有效三元组的总数**。 

要考虑的边缘情况包括具有所有相同字符的字符串（无有效选择）、长度恰好为 3 的字符串以及有效序列出现在边界处的字符串。 

## 方法

 蛮力方法将迭代所有可能的三元组`(i, j, k)`并检查是否`s[i] != s[j] != s[k]`以正确的交替模式。 这是正确的，但效率非常低，复杂度为 O(n^3)，这对于`n = 10^5`。 

最佳解决方案的关键观察是必须遵循有效的 3 构建序列`"010"`或者`"101"`。 我们可以预先计算计数的**前缀和**`'0'`和`'1'`直到每个位置。 那么对于每个位置`j`选择中间的建筑物，我们可以根据建筑物的类型统计左侧和右侧的有效建筑物`s[j]`。 具体来说，如果`s[j] == '0'`，有效三元组的数量`s[j]`中间是`(number of '1's to the left) * (number of '1's to the right)`。 同样，如果`s[j] == '1'`， 这是`(number of '0's to the left) * (number of '0's to the right)`。 将所有位置的总和得出 O(n) 时间内有效三元组的总数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 显式枚举所有三元组 |
 | 最佳| O(n) | O(n) | 使用前缀和有效地计算有效的三元组 |

 ## 算法演练

 1.初始化两个数组，`prefix0`和`prefix1`，长度`n+1`。`prefix0[i]`存储的数量`'0'`进入`s[0..i-1]`和`prefix1[i]`存储的数量`'1'`进入`s[0..i-1]`。 
2.填写`prefix0`和`prefix1`通过迭代字符串`s`。 对于每个位置`i`，增加各自的前缀和。 
3. 初始化变量`total_ways`到 0。这将累积有效的 3 栋建筑选择的数量。 
4. 迭代每个位置`j`在字符串中，将其视为**中间建筑物**。 
5. 如果`s[j] == '0'`， 计算`ways = prefix1[j] * (prefix1[n] - prefix1[j+1])`。 这表示有效三元组的数量`"101"`和`s[j]`在中间。 
6. 如果`s[j] == '1'`， 计算`ways = prefix0[j] * (prefix0[n] - prefix0[j+1])`。 这表示有效三元组的数量`"010"`和`s[j]`在中间。 
7. 添加`ways`到`total_ways`。 
8.处理完所有位置后，返回`total_ways`。 

**为什么有效**：通过将每个位置视为三元组的中间，并使用每一侧的预先计算的字符计数，我们确保所有有效序列都被精确计数一次。 前缀和使我们能够以 O(1) 的速度高效地计算每个位置的左右计数，从而形成整体 O(n) 算法。 

## Python 解决方案```python
class Solution:
    def numberOfWays(self, s: str) -> int:
        n = len(s)
        prefix0 = [0] * (n + 1)
        prefix1 = [0] * (n + 1)
        
        for i in range(n):
            prefix0[i+1] = prefix0[i] + (1 if s[i] == '0' else 0)
            prefix1[i+1] = prefix1[i] + (1 if s[i] == '1' else 0)
        
        total_ways = 0
        for j in range(n):
            if s[j] == '0':
                ways = prefix1[j] * (prefix1[n] - prefix1[j+1])
            else:
                ways = prefix0[j] * (prefix0[n] - prefix0[j+1])
            total_ways += ways
        
        return total_ways
```该实现首先为“0”和“1”字符构建前缀和。 然后，对于每个潜在的中间建筑物，它使用前缀和有效地计算有效三元组的数量。 乘法给出了与所需模式匹配的左右字符的所有组合。 

## 解决方案```go
func numberOfWays(s string) int64 {
    n := len(s)
    prefix0 := make([]int, n+1)
    prefix1 := make([]int, n+1)

    for i := 0; i < n; i++ {
        prefix0[i+1] = prefix0[i]
        prefix1[i+1] = prefix1[i]
        if s[i] == '0' {
            prefix0[i+1]++
        } else {
            prefix1[i+1]++
        }
    }

    var totalWays int64 = 0
    for j := 0; j < n; j++ {
        var ways int
        if s[j] == '0' {
            ways = prefix1[j] * (prefix1[n] - prefix1[j+1])
        } else {
            ways = prefix0[j] * (prefix0[n] - prefix0[j+1])
        }
        totalWays += int64(ways)
    }

    return totalWays
}
```Go 实现镜像了 Python 版本。 主要区别包括将结果显式整数转换为`int64`和使用`make`初始化切片。 

## 工作示例

 **示例1：`s = "001101"`**

 | j（中）| s[j] | 前缀 0[j] | 前缀1[j] | 左*右方式| 累计总数 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | '0'| 0 | 0 | 0*3 = 0 | 0*3 = 0 0 |
 | 1 | '0'| 1 | 0 | 0*3 = 0 | 0*3 = 0 0 |
 | 2 | '1'| 2 | 0 | 2*1 = 2 | 2*1 = 2 2 |
 | 3 | '1'| 2 | 1 | 2*1 = 2 | 2*1 = 2 4 |
 | 4 | '0'| 2 | 2 | 2*1 = 2 | 2*1 = 2 6 |
 | 5 | '1'| 3 | 2 | 3*0 = 0 | 3*0 = 0 6 |

 最终答案：6

 **示例2：`s = "11100"`**

 所有潜在的中间“1”或“0”字符都会导致零有效组合，因为所需相反类型的左侧或右侧计数为零。 总方式 = 0。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单遍计算前缀和 + 单遍计算总路 |
 | 空间| O(n) | 存储“0”和“1”的前缀和 |

 该算法随字符串长度线性缩放，并有效处理 10^5 个字符的上限。
