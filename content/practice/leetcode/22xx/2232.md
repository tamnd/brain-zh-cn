[LeetCode 问题 2232](https://leetcode.com/problems/minimize-result-by-adding-parentheses-to-expression/)

 **难度：** 🟡 中等
 **主题：** 字符串、枚举

 ## 解决方案

 ## 问题理解

 该问题呈现以下形式的字符串表达式`"<num1>+<num2>"`，其中两者`<num1>`和`<num2>`是表示为字符串的正整数。 任务是插入**恰好一对括号**，使得左括号出现在**加号**的左侧，右括号出现在**加号的右侧**，从而产生一个有效的算术表达式，其计算结果为**可能的最小整数值**。 

例如，如果输入是`"247+38"`，我们可以用几种有效的方式放置括号，例如`"2(47+38)"`,`"24(7+38)"`， 和`"(247+38)"`。 每个选项都会计算出不同的数值结果，我们想要给出最小结果的选项。 最终输出必须返回带括号的表达式，而不是计算的数值。 

约束很严格但易于管理：字符串长度很小（`3 <= expression.length <= 10`）并且恰好有一个`'+'`。 因此，该问题允许对所有可能的位置进行强力枚举以插入括号，而无需担心性能问题。 

重要的边缘情况包括非常小的数字、长度为 1 的数字或放置括号以包裹整个表达式。 该问题保证最终结果符合 32 位有符号整数。 

## 方法

 ### 蛮力方法

 暴力解决方案涉及尝试所有有效的方法来插入左括号和右括号。 对于像这样的表达式`"num1+num2"`，我们可以：

 1. 迭代每个可能的分割点`num1`对于左括号。 
2. 迭代每个可能的分割点`num2`为右括号。 
3. 计算应用括号后表达式的数值结果。 
4. 跟踪最小值及其对应的括号表达式。 

因为`num1`和`num2`都最多为 9 位数字（根据约束），这种强力方法是可行的，因为组合总数小于 100，计算起来很简单。 

### 最佳方法

 最佳方法在概念上类似于暴力破解，但侧重于通过考虑乘以 1 不会改变总和来减少不必要的操作。 因此，我们迭代所有可能的分割，但使用整数算术有效地计算乘法，避免重复段的不必要的字符串到整数转换。 这种方法通过检查**所有有效的分割**来保证最小值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 尝试左括号和右括号的所有分割点。 可行，因为 n ≤ 10 |
 | 最佳| O(n^2) | O(n^2) | O(1) | O(1) | 与暴力破解相同，但具有仔细的算术评估和字符串重建 |

 ## 算法演练

 1. 将输入字符串拆分为`num1`和`num2`基于`'+'`特点。 这有助于隔离两个数字以进行处理。 
2. 初始化`min_value`到无穷大和`result_expression`到一个空字符串。 
3. 迭代所有可能的位置以放置左括号`num1`。 让`i`范围从 0 到`len(num1) - 1`。 左括号放在前面`num1[i]`。 
4. 迭代所有可能的位置以将右括号放入`num2`。 让`j`范围从 1 到`len(num2)`。 右括号后面是`num2[j-1]`。 
5. 分裂`num1`到前缀 (`num1[:i]`) 和后缀 (`num1[i:]`）， 和`num2`到前缀 (`num2[:j]`) 和后缀 (`num2[j:]`）。 
6. 计算表达式的总值：`(left_multiplier * (middle_sum) * right_multiplier)`， 在哪里：

-`left_multiplier`是`int(num1[:i])`如果为空则为 1
 -`middle_sum`是`int(num1[i:]) + int(num2[:j])`-`right_multiplier`是`int(num2[j:])`如果为空则为 1
 7. 如果该评估值小于`min_value`， 更新`min_value`并存储相应的括号表达式。 
8. 一旦所有组合都被求值，则返回存储的表达式。 

**为什么有效：** 该算法详尽地检查括号的每个有效位置。 算术结构保证将总和乘以括号外的数字涵盖所有可能的评估场景，确保找到最小值。 

## Python 解决方案```python
class Solution:
    def minimizeResult(self, expression: str) -> str:
        plus_index = expression.index('+')
        num1 = expression[:plus_index]
        num2 = expression[plus_index+1:]
        
        min_value = float('inf')
        result_expression = ""
        
        for i in range(len(num1)):
            left = num1[:i]
            left_multiplier = int(left) if left else 1
            num1_suffix = num1[i:]
            
            for j in range(1, len(num2)+1):
                num2_prefix = num2[:j]
                num2_suffix = num2[j:]
                middle_sum = int(num1_suffix) + int(num2_prefix)
                right_multiplier = int(num2_suffix) if num2_suffix else 1
                total = left_multiplier * middle_sum * right_multiplier
                
                if total < min_value:
                    min_value = total
                    result_expression = f"{left}({num1_suffix}+{num2_prefix}){num2_suffix}"
        
        return result_expression
```Python 解决方案首先将加号周围的两个数字分开。 然后，它会迭代所有可能的位置以插入括号，通过将空字符串视为 1 进行乘法来小心处理空字符串。 计算出每个可能的总数后，它会更新最小值并构建相应的表达式。 一旦评估了所有可能性，就会返​​回最终结果。 

## 解决方案```go
import (
    "strconv"
    "math"
)

func minimizeResult(expression string) string {
    plusIndex := 0
    for i, c := range expression {
        if c == '+' {
            plusIndex = i
            break
        }
    }
    num1 := expression[:plusIndex]
    num2 := expression[plusIndex+1:]
    
    minValue := math.MaxInt32
    resultExpr := ""
    
    for i := 0; i < len(num1); i++ {
        left := num1[:i]
        leftMultiplier := 1
        if left != "" {
            leftMultiplier, _ = strconv.Atoi(left)
        }
        num1Suffix := num1[i:]
        
        for j := 1; j <= len(num2); j++ {
            num2Prefix := num2[:j]
            num2Suffix := num2[j:]
            middleSum, _ := strconv.Atoi(num1Suffix)
            tmp, _ := strconv.Atoi(num2Prefix)
            middleSum += tmp
            
            rightMultiplier := 1
            if num2Suffix != "" {
                rightMultiplier, _ = strconv.Atoi(num2Suffix)
            }
            
            total := leftMultiplier * middleSum * rightMultiplier
            if total < minValue {
                minValue = total
                resultExpr = left + "(" + num1Suffix + "+" + num2Prefix + ")" + num2Suffix
            }
        }
    }
    
    return resultExpr
}
```Go 解决方案遵循与 Python 相同的逻辑。 Go 需要使用以下方式在字符串和整数之间进行显式转换`strconv.Atoi`并小心处理空字符串。 嵌套循环生成所有可能的位置，计算相应的算术值，并跟踪最小值。
