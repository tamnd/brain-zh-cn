[LeetCode 2212 题](https://leetcode.com/problems/maximum-points-in-an-archery-competition/)

 **难度：** 🟡 中等
 **主题：** 数组、回溯、位操作、枚举

 ## 解决方案

 ## 问题理解

 问题是要求我们确定鲍勃分配他的最佳方式`numArrows`在射箭比赛中跨越 12 个得分部分（从 0 到 11），以最大化他对爱丽丝的总分。 爱丽丝的箭头分布如下`aliceArrows`。 评分规则是这样的，对于每个部分，拥有更多箭头的玩家获得该部分对应的分数。 如果两个玩家的箭数相同，则得分归爱丽丝所有。 如果两人的箭头都为零，则不会将分数授予任何人。 

输入包括`numArrows`，一个整数，表示鲍勃有多少个箭头，以及`aliceArrows`，一个由 12 个整数组成的数组，显示爱丽丝如何将箭头分布在各个部分。 输出应该是一个数组`bobArrows`长度为 12，显示鲍勃应如何分布他的箭头以最大化他的分数。 鲍勃的箭头之和必须等于`numArrows`。 

关键的边缘情况包括鲍勃由于箭头不足而无法在任何部分击败爱丽丝的场景，或者当多个分布产生相同的最大点时。 约束条件表明`numArrows`可以高达 10^5，因此需要一个有效的解决方案。 

## 方法

 暴力方法会考虑鲍勃分配他的所有可能的方式`numArrows`横跨12个部分。 对于每个分配，我们计算分数并选择得分最高的分配。 然而，分配数量呈指数增长`numArrows`，使得这种方法不可行。 

关键的观察是对于每个部分`i`，鲍勃只需击败爱丽丝至少放置`aliceArrows[i] + 1`该部分中的箭头。 这将问题简化为**子集选择问题**，其中我们考虑所有部分的组合以“获胜”并计算相应的箭头用法和点。 由于只有 12 个部分，因此子集总数为 2^12 = 4096，这在计算上是可行的。 对于每个子集，我们检查鲍勃是否有足够的箭头在所有选定的部分中击败爱丽丝。 我们还确保任何剩余的箭头被任意分配到一个部分以满足`numArrows`约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(numArrows^12) | O(numArrows^12) | O(1) | O(1) | 尝试所有可能的箭头分布； 由于指数组合而不可行 |
 | 最佳 | O(2^12 * 12) | O(2^12 * 12) | O(12) | 枚举所有部分子集以击败 Alice； 可行，因为 2^12 很小 |

 ## 算法演练

 1. 初始化变量`maxPoints`到 0 来跟踪 Bob 可以获得的最高分数，并列出一个列表`bestDistribution`存储该分数的箭头分配。 
2. 使用从 0 到 2^12 - 1 的位掩码迭代 12 个部分的所有子集。每个位代表 Bob 是否试图赢得该部分。 
3. 对于每个子集，初始化`arrowsUsed`到 0 和`points`为0。同时初始化一个临时箭头分布数组`tempDistribution`长度为 12，带零。 
4. 对于每个部分`i`（从0到11），检查子集是否包含此部分（位已设置）。 如果是这样，计算获胜所需的箭头：`aliceArrows[i] + 1`。 如果添加这些箭头超过`numArrows`，打破并丢弃这个子集。 
5. 如果子集有效（arrowsUsed <= numArrows），则通过对所包含的部分索引求和来计算子集的总分。 分配所需的箭头`tempDistribution`对于这些部分。 
6. 如果`arrowsUsed < numArrows`，将剩余的箭头任意分配给子集中得分最高的部分，以确保总和等于`numArrows`。 
7. 如果该子集的总分大于`maxPoints`， 更新`maxPoints`并复制`tempDistribution`到`bestDistribution`。 
8.迭代完所有子集后，返回`bestDistribution`。 

为什么有效：该算法考虑了鲍勃可能尝试获胜的部分的所有组合。 通过仅考虑鲍勃击败爱丽丝的子集，我们可以最大化每次箭头使用的分数。 剩余箭头分配确保解决方案满足`numArrows`约束。 由于我们评估每个子集，因此我们保证找到最佳解决方案。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumBobPoints(self, numArrows: int, aliceArrows: List[int]) -> List[int]:
        maxPoints = 0
        bestDistribution = [0] * 12

        for mask in range(1 << 12):
            arrowsUsed = 0
            points = 0
            tempDistribution = [0] * 12

            for i in range(12):
                if mask & (1 << i):
                    needed = aliceArrows[i] + 1
                    arrowsUsed += needed
                    if arrowsUsed > numArrows:
                        break
                    points += i
                    tempDistribution[i] = needed
            else:
                if arrowsUsed < numArrows:
                    for i in reversed(range(12)):
                        if mask & (1 << i):
                            tempDistribution[i] += numArrows - arrowsUsed
                            break
                if points > maxPoints:
                    maxPoints = points
                    bestDistribution = tempDistribution[:]

        return bestDistribution
```该实现使用位掩码迭代 12 个部分的所有可能子集。 对于每个子集，它计算赢得每个部分所需的箭头并检查它是否超过`numArrows`。 计算总点数，如果高于先前的最大值，则存储箭头分布。 任何剩余的箭头都分配给子集中的最高部分以满足总箭头约束。 

## 解决方案```go
func maximumBobPoints(numArrows int, aliceArrows []int) []int {
    maxPoints := 0
    bestDistribution := make([]int, 12)

    for mask := 0; mask < (1 << 12); mask++ {
        arrowsUsed := 0
        points := 0
        tempDistribution := make([]int, 12)

        valid := true
        for i := 0; i < 12; i++ {
            if mask&(1<<i) != 0 {
                needed := aliceArrows[i] + 1
                arrowsUsed += needed
                if arrowsUsed > numArrows {
                    valid = false
                    break
                }
                points += i
                tempDistribution[i] = needed
            }
        }

        if valid {
            if arrowsUsed < numArrows {
                for i := 11; i >= 0; i-- {
                    if mask&(1<<i) != 0 {
                        tempDistribution[i] += numArrows - arrowsUsed
                        break
                    }
                }
            }
            if points > maxPoints {
                maxPoints = points
                copy(bestDistribution, tempDistribution)
            }
        }
    }

    return bestDistribution
}
```Go 版本遵循与 Python 解决方案相同的逻辑。 一个关键的区别是显式处理切片复制`copy`以避免参考问题。
