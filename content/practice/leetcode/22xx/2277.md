 ## 解决方案

 ## 问题理解

 问题是要求我们处理树结构上的查询。 每个查询给出两个节点之间的路径`starti`和`endi`和第三个节点`nodei`。 我们被要求找到路径上最接近哪个节点`nodei`就分隔它们的边的数量而言，也称为**树中的距离**。 

该树表示为`n`节点标记为`0`到`n - 1`和一个`edges`双向连接节点的列表。 关键的约束是图保证是一棵树，这意味着它是连接的并且不包含循环。 节点和查询的数量相对较少（`n <= 1000`和`query.length <= 1000`），因此立方复杂度的解决方案可能是可以接受的，但我们可以使用树属性进一步优化。 

要考虑的边缘情况包括查询，其中`starti`等于`endi`（路径为单个节点），节点`nodei`本身就在路径上，并且树木高度不平衡（如链条）。 

## 方法

 ### 蛮力

 蛮力方法很简单。 对于每个查询，首先找到来自的路径`starti`到`endi`。 这可以使用 BFS 或 DFS 遍历树并记录每个节点的父节点来完成。 然后，对于路径上的每个节点，计算到`nodei`使用另一个 BFS`nodei`。 返回距离最小的节点。 

虽然这可行，但效率很低，因为对于每个查询，我们可能会对整个树执行多次 BFS。 为了`m`查询和`n`节点，时间复杂度大致为`O(m * n)`根据 BFS，给出`O(m * n^2)`总体而言，对于上限来说可能会很慢（`1000 * 1000^2 = 10^9`运营）。 

### 最佳方法

 关键的观察结果是，在树中，如果我们使用 BFS 预先计算每个节点的距离，或者更优雅地使用 **最低公共祖先 (LCA) 技术** 结合父映射来重建路径，则可以有效地计算 **节点之间的距离。 

1. 使用 BFS 从每个节点预先计算每个节点之间的距离。 这给出了`distance[node1][node2]`桌子。 
2. 对于每个查询，生成路径`starti`到`endi`使用 BFS 的父映射。 
3. 对于该路径上的每个节点，查找其到`nodei`从预先计算的表中。 
4. 返回距离最小的节点。 

这减少了每个查询的重复 BFS 调用，并确保快速查找距离。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n^2) | O(m * n^2) | O(n) | 每个路径节点每个查询的 BFS |
 | 最佳| O(n^2 + m * n) | O(n^2 + m * n) | O(n^2) | O(n^2) | 预先计算所有对的距离； 通过父地图提取路径 |

 ## 算法演练

 1. 构建邻接表`graph`从给定的`edges`方便遍历。 
2. 使用每个节点的 BFS 预先计算所有节点对之间的距离。 将其存储在二维列表中`distances[n][n]`。 
3. 对于每个查询`[start, end, node]`:

 1. 执行BFS或DFS`start`到`end`重建它们之间的路径。 跟踪每个节点的父节点以回溯路径。 
2. 初始化`closest_node`和`min_distance`变量。 
3. 遍历路径上的每个节点并检查`distances[node_on_path][node]`。 
4. 如果这个距离小于`min_distance`， 更新`closest_node`。 
5.遍历完路径后，追加`closest_node`到答案。 
4. 返回`answer`处理所有查询后列出。 

**为什么有效：** 预先计算的`distances`表确保我们可以在 O(1) 时间内检查从任何节点到任何其他节点的距离。 路径重建保证我们只考虑之间有效路径上的节点`start`和`end`。 这样就满足了查询的要求。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def closestNode(self, n: int, edges: List[List[int]], query: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # Precompute all-pairs distances
        distances = [[0]*n for _ in range(n)]
        
        def bfs(start: int):
            dist = [-1] * n
            dist[start] = 0
            q = deque([start])
            while q:
                node = q.popleft()
                for nei in graph[node]:
                    if dist[nei] == -1:
                        dist[nei] = dist[node] + 1
                        q.append(nei)
            return dist
        
        for i in range(n):
            distances[i] = bfs(i)
        
        res = []
        for start, end, node in query:
            # Reconstruct path from start to end using BFS parent map
            parent = [-1] * n
            q = deque([start])
            visited = [False] * n
            visited[start] = True
            while q:
                curr = q.popleft()
                if curr == end:
                    break
                for nei in graph[curr]:
                    if not visited[nei]:
                        visited[nei] = True
                        parent[nei] = curr
                        q.append(nei)
            
            # Build the path
            path = []
            curr = end
            while curr != -1:
                path.append(curr)
                curr = parent[curr]
            path.reverse()
            
            # Find closest node on path to the target node
            min_dist = float('inf')
            closest_node = -1
            for p in path:
                if distances[p][node] < min_dist:
                    min_dist = distances[p][node]
                    closest_node = p
            res.append(closest_node)
        
        return res
```**实现说明：** 对于小树，BFS 可以有效地预先计算所有节点对之间的距离。 父映射允许无需 DFS 递归的路径重建。 然后，每个查询变成使用 O(1) 距离查找对路径节点的简单扫描。 

## 解决方案```go
package main

func closestNode(n int, edges [][]int, query [][]int) []int {
    graph := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }

    // Precompute distances using BFS
    distances := make([][]int, n)
    for i := range distances {
        distances[i] = make([]int, n)
        for j := range distances[i] {
            distances[i][j] = -1
        }
        q := []int{i}
        distances[i][i] = 0
        for len(q) > 0 {
            node := q[0]
            q = q[1:]
            for _, nei := range graph[node] {
                if distances[i][nei] == -1 {
                    distances[i][nei] = distances[i][node] + 1
                    q = append(q, nei)
                }
            }
        }
    }

    res := []int{}
    for _, qu := range query {
        start, end, node := qu[0], qu[1], qu[2]

        parent := make([]int, n)
        for i := range parent {
            parent[i] = -1
        }
        visited := make([]bool, n)
        q := []int{start}
        visited[start] = true
        for len(q) > 0 {
            curr := q[0]
            q = q[1:]
            if curr == end {
                break
            }
            for _, nei := range graph[curr] {
                if !visited[nei] {
                    visited[nei] = true
                    parent[nei] = curr
                    q = append(q, nei)
                }
            }
        }

        path := []int{}
        for curr := end; curr != -1; curr = parent[curr] {
            path = append([]int{curr}, path...)
        }

        minDist := n + 1
        closest := -1
        for _, p := range path {
            if distances[p][node] < minDist {
                minDist = distances[p][node]
                closest = p
            }
        }
        res = append(res, closest)
    }

    return res
}
```**Go实现注意事项：** BFS使用切片作为队列。 预先计算的距离的处理方式类似。 切片前置用于有效地反转路径。 注意初始化距离矩阵`-1`。
