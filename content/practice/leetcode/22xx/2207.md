[LeetCode 问题 2207](https://leetcode.com/problems/maximize-number-of-subsequences-in-a-string/)

 **难度：** 🟡 中等
 **主题：** 字符串、贪婪、前缀和

 ## 解决方案

 ## 问题理解

 这个问题要求我们最大化两个字符字符串的出现次数`pattern`作为给定字符串中的子序列出现`text`，插入**恰好一个字符**后。 我们可以插入的字符仅限于`pattern[0]`或者`pattern[1]`，并且它可以插入到任何位置，包括开头或结尾`text`。 

子序列是通过删除零个或多个字符而不改变剩余字符的顺序而形成的。 因此，如果`pattern = "ac"`和`text = "abdcdbc"`，子序列“ac”出现多次，插入一个“a”或“c”可以增加总计数。 

约束表明`text`可以达到`10^5`字符长，因此任何具有二次复杂度的解决方案都太慢。 这`pattern`长度始终为 2，这简化了问题，因为我们只需要考虑两种类型的插入。 

重要的边缘情况包括`text`已经具有所有相同的字符，当`pattern[0]`等于`pattern[1]`，以及当`text`非常短（长度为 1），因为这些场景中的插入选择不同。 

## 方法

 蛮力方法是尝试插入`pattern[0]`或者`pattern[1]`在每一个可能的位置`text`并计算每个修改后的字符串中的子序列。 可以通过嵌套循环或动态编程来计算子序列。 虽然这最终会给出正确的答案，但它**太慢**，插入位置的复杂度为 O(n^2) 乘以计数的 O(n)，导致 O(n^3) - 对于 n = 10^5 来说是不可接受的。 

最佳方法的关键在于最大化子序列`pattern[0]pattern[1]`，我们只需要知道**个数`pattern[0]`每个位置之前和数量`pattern[1]`每个位置之后**。 由于我们只能插入一个字符，因此最好的选择是插入`pattern[0]`在开始时（所以它与所有`pattern[1]`之后）或`pattern[1]`最后（所以它与所有`pattern[0]`前）。 我们一次性有效地计算所有现有子序列，然后考虑最佳插入。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 在所有位置插入并计算子序列 |
 | 最佳 | O(n) | O(1) | O(1) | 一次计算子序列并使用前缀/后缀计数来确定最佳插入 |

 ## 算法演练

 1.初始化一个计数器`count_pattern0`到 0 来跟踪数量`pattern[0]`到目前为止所看到的。 
2. 初始化`current_subseq_count`到 0 来计算子序列`pattern[0]pattern[1]`。 
3. 迭代每个字符`ch`在`text`：

 1.如果`ch == pattern[0]`, 增量`count_pattern0`。 
2.如果`ch == pattern[1]`， 添加`count_pattern0`到`current_subseq_count`因为之前的每一个`pattern[0]`可以与这个配对`pattern[1]`。 
4.遍历之后`text`，现有的子序列计数为`current_subseq_count`。 
5. 统计出现的总次数`pattern[0]`作为`total_pattern0`和`pattern[1]`作为`total_pattern1`。 
6. 计算插入一个字符的两种情况：

 1. 插入`pattern[0]`开始时：总子序列 =`current_subseq_count + total_pattern1`。 
2. 插入`pattern[1]`最后：总子序列=`current_subseq_count + total_pattern0`。 
7. 返回两个值中的最大值。 

**为什么它有效**：不变性是对于给定的`pattern[0]pattern[1]`， 每个`pattern[0]`可以与所有配对`pattern[1]`在它之后。 插入一个`pattern[0]`一开始将其与所有现有的配对`pattern[1]`，并插入一个`pattern[1]`最后将其与所有现有的配对`pattern[0]`。 没有其他位置可以产生比这两个更多的子序列。 

## Python 解决方案```python
class Solution:
    def maximumSubsequenceCount(self, text: str, pattern: str) -> int:
        count_pattern0 = 0
        subseq_count = 0
        for ch in text:
            if ch == pattern[0]:
                count_pattern0 += 1
            elif ch == pattern[1]:
                subseq_count += count_pattern0
        total_pattern0 = text.count(pattern[0])
        total_pattern1 = text.count(pattern[1])
        return subseq_count + max(total_pattern0, total_pattern1)
```在此实现中，我们首先对单遍中的子序列进行计数。`count_pattern0`跟踪有多少`pattern[0]`到目前为止，角色已经出现，每当我们看到`pattern[1]`，它与所有的组成一个子序列`pattern[0]`算了。 然后我们计算插入的效果`pattern[0]`在开始时或`pattern[1]`最后并返回最大值。 

## 解决方案```go
func maximumSubsequenceCount(text string, pattern string) int64 {
    var countPattern0, subseqCount int64
    for _, ch := range text {
        if ch == rune(pattern[0]) {
            countPattern0++
        } else if ch == rune(pattern[1]) {
            subseqCount += countPattern0
        }
    }
    var totalPattern0, totalPattern1 int64
    for _, ch := range text {
        if ch == rune(pattern[0]) {
            totalPattern0++
        } else if ch == rune(pattern[1]) {
            totalPattern1++
        }
    }
    if totalPattern0 > totalPattern1 {
        return subseqCount + totalPattern0
    }
    return subseqCount + totalPattern1
}
```在 Go 中，我们明确使用`int64`以防止大输入的整数溢出。 字符转换为`rune`进行比较。 该逻辑反映了 Python 解决方案。
