[LeetCode 问题 2229](https://leetcode.com/problems/check-if-an-array-is-consecutive/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定整数数组是否形成完美的连续数字序列，没有间隙或重复。 

更正式地说，如果数组有长度`n`其最小值为`x`，那么如果数组包含范围内的每个整数，则该数组被认为是连续的：$$[x, x + n - 1]$$正好一次。 

例如，如果最小值是`3`数组长度是`4`，那么数组必须包含：$$3, 4, 5, 6$$以任何顺序。 

输入是一个整数数组`nums`，预期输出是一个布尔值：

 - 返回`true`如果数组包含所需范围内的所有连续整数
 - 返回`false`否则

 这些约束告诉我们一些重要的事情：

 - 数组长度可以大到`10^5`- 每个值也可以大到`10^5`由于输入大小很大，低效方法（例如重复扫描数组以查找丢失的数字）可能会变得太慢。 我们的目标应该是：

 -`O(n log n)`使用排序
 -`O(n)`使用散列

 有几个重要的边缘情况需要考虑：

 - 重复的值，例如`[1,2,2,3]`- 缺失值在预期范围内，例如`[1,3]`- 长度数组`1`，它们总是连续的
 - 未排序的数组，因为数字可能以任何顺序出现
 - 接近上限的大范围

 该问题保证数组至少包含一个元素，因此我们不需要处理空数组。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是首先找到最小值`x`，然后检查每个值是否来自`x`到`x + n - 1`存在于数组中。 

一种天真的方法是：

 1. 求最小值
 2. 对于所需范围内的每个数字：

 - 扫描数组，查看该数字是否存在

 这是有效的，因为连续性的定义直接要求范围内的每个数字都出现。 

然而，这种方法效率低下。 如果数组有`n`元素，对于每个所需的数字，我们再次扫描数组，总复杂度变为`O(n^2)`。 

和`n = 10^5`，二次时间太慢。 

### 最佳方法

 关键的观察是连续数组必须同时满足两个属性：

 1. 所有号码必须是唯一的
 2. 最大值和最小值之差必须等于`n - 1`为什么这有效？ 

如果有`n`唯一的整数并且范围大小恰好是`n`，那么该范围内的每个值都必须恰好出现一次。 

例如：

-`min = 3`-`max = 6`-`n = 4`范围大小为：$$6 - 3 + 1 = 4$$如果我们也知道确切有`4`唯一值，那么数组必须包含来自`3`通过`6`。 

哈希集在这里是理想的选择，因为它允许：

 - 快速重复检测
 - 快速唯一性计数

 我们可以在线性时间内解决这个问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 重复扫描数组以查找每个所需值 |
 | 最佳| O(n) | O(n) | 使用哈希集和范围属性 |

 ## 算法演练

 ### 最优算法

 1. 计算数组中的最小值。 

我们需要最小值，因为所需的连续范围总是从最小的数字开始。 
2. 计算数组中的最大值。 

最大值有助于确定数字范围的总大小。 
3. 从数组创建哈希集。 

集合会自动删除重复项。 这使我们能够检查是否存在重复的数字。 
4. 将集合的大小与数组长度进行比较。 

如果集合大小小于数组长度，则存在重复项。 连续数组不能包含重复项，因此我们立即返回`false`。 
5. 检查是否：$$\text{maxValue} - \text{minValue} + 1 = n$$这验证了数字范围的大小与元素数量完全相同。 

1. 如果两个条件都满足，则返回`true`。 

### 为什么它有效

 长度连续的序列`n`必须准确包含`n`跨越一定范围大小的不同整数`n`。 

如果存在重复项，则缺少某些必需的值。 同样，如果范围大小大于`n`，序列中某处必定存在间隙。 

因此，组合：

 - 独特的价值观
 - 正确的范围大小

 保证每个所需的整数恰好出现一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def isConsecutive(self, nums: List[int]) -> bool:
        n = len(nums)

        unique_values = set(nums)

        if len(unique_values) != n:
            return False

        min_value = min(nums)
        max_value = max(nums)

        return max_value - min_value + 1 == n
```实现首先将所有元素存储在集合中。 由于集合只保留唯一值，因此将集合大小与原始数组长度进行比较可以立即告诉我们是否存在重复项。 

接下来，该算法计算数组中的最小值和最大值。 这些值确定预期的连续范围。 

最后，表达：```python
max_value - min_value + 1 == n
```检查范围大小是否与元素数量匹配。 

如果唯一性条件和范围条件同时成立，则数组必须是连续的。 

## 解决方案```go
func isConsecutive(nums []int) bool {
	n := len(nums)

	seen := make(map[int]bool)

	minValue := nums[0]
	maxValue := nums[0]

	for _, num := range nums {
		if seen[num] {
			return false
		}

		seen[num] = true

		if num < minValue {
			minValue = num
		}

		if num > maxValue {
			maxValue = num
		}
	}

	return maxValue-minValue+1 == n
}
```Go 实现将多个操作组合到一个循环中：

 - 使用地图检测重复项
 - 跟踪最小值
 - 跟踪最大值

 Go 没有内置的集合类型，所以`map[int]bool`被用来代替。 

约束足够小，整数溢出不是这里的问题。 

与 Python 不同，Go 切片是对数组的引用，但该细节不会影响此解决方案，因为输入仅被读取，而不会被修改。

 ## 边缘情况

 ### 重复值

 一个数组，例如：```
[1,2,2,3]
```可以轻松欺骗仅检查最小和最大范围的错误实现。 

这里：

-`min = 1`-`max = 3`- 范围大小=`3`但数组长度是`4`，因为有一个值是重复的。 

该实现通过将设置大小与数组长度进行比较来正确处理此问题。 由于重复项减少了唯一值的数量，因此算法立即返回`false`。 

### 单元素数组

 仅包含一个数字的数组始终是连续的，因为所需的范围恰好包含一个值。 

例子：```
[7]
```这里：

-`min = max = 7`- 范围大小=`1`该算法自然地处理这种情况，不需要任何特殊逻辑。 

### 缺少内部值

 数组例如：```
[2,3,5]
```包含唯一数字，但在预期范围内存在差距。 

该实现通过范围大小检查来检测这一点：$$5 - 2 + 1 = 4$$但数组长度只有`3`。 

由于范围大小大于元素数量，因此必须至少缺少一个值。 因此，算法正确返回`false`。
