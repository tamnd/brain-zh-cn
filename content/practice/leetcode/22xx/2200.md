[LeetCode 问题 2200](https://leetcode.com/problems/find-all-k-distant-indices-in-an-array/)

 **难度：** 🟢简单
 **主题：** 数组、两个指针

 ## 解决方案

 ## 问题理解

 该问题需要识别数组中的所有索引`nums`与给定值的至少一次出现的“k 距离”`key`。 换句话说，对于每个索引`i`，我们需要判断是否存在某个索引`j`这样`nums[j] == key`和之间的距离`i`和`j`至多是`k`。 输出应该是所有此类索引的排序列表。 

输入由 0 索引的整数数组组成`nums`, 一个整数`key`保证存在于`nums`，和一个整数`k`其长度至少为 1，最多为`nums`。 约束条件（`nums.length <= 1000`）表明二次时间复杂度的解决方案可能是可以接受的，但我们可以进一步优化。 

重要的边缘情况包括每个元素都相等的情况`key`， 在哪里`k`等于数组长度，或者其中`key`仅发生在边界处。 该问题保证非空数组并且`key`存在于`nums`，这简化了一些验证。 

## 方法

 ### 蛮力方法

 暴力方法迭代每个索引`i`在`nums`并且，对于每个`i`, 扫描子数组`nums[max(0, i-k) : min(len(nums)-1, i+k)]`检查是否有任何元素等于`key`。 如果存在这样的元素，`i`被添加到结果中。 这种方法是正确的，因为它直接实现了 k 距离索引的定义，但需要检查`2k+1`每个索引都有一个元素，导致最坏情况的时间复杂度为 O(n * k)。 

### 最佳方法

 更有效的方法利用了以下事实：`key`位置可以预先计算。 首先，收集所有索引`j`在哪里`nums[j] == key`。 然后，迭代这些位置并标记来自的所有索引`max(0, j-k)`到`min(n-1, j+k)`作为 k 距离。 这避免了冗余检查并确保每个索引最多被考虑一次。 排序是可选的，因为可以按照从左到右的顺序进行标记，从而保证排序的输出。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * k) | O(n) | 根据所有索引的 k 距离窗口检查每个索引 |
 | 最佳| O(n) | O(n) | 预先计算关键位置并直接标记 k 距离索引 |

 ## 算法演练

 1.初始化一个空的布尔数组`isKDistant`长度`n`（长度为`nums`) 来跟踪哪些索引是 k 距离的。 
2. 迭代数组`nums`收集所有索引`j`这样`nums[j] == key`。 
3.对于每个关键索引`j`，计算k-距离范围的起点和终点：`start = max(0, j - k)`和`end = min(n - 1, j + k)`。 
4. 标记所有索引`start`到`end`包含为 k 距离`isKDistant`。 
5.处理完所有关键索引后，迭代`isKDistant`并收集所有标记的索引`True`到结果数组中。 
6. 返回结果数组，该数组已经排序，因为索引是按升序处理的。 

为什么它有效：通过标记每个出现的范围`key`，该算法确保满足 k 距离条件的每个索引仅被包含一次。 从左到右的迭代保留排序顺序。 

## Python 解决方案```python
from typing import List

class Solution:
    def findKDistantIndices(self, nums: List[int], key: int, k: int) -> List[int]:
        n = len(nums)
        is_k_distant = [False] * n
        
        for j, num in enumerate(nums):
            if num == key:
                start = max(0, j - k)
                end = min(n - 1, j + k)
                for i in range(start, end + 1):
                    is_k_distant[i] = True
        
        result = [i for i, val in enumerate(is_k_distant) if val]
        return result
```该实现首先初始化一个布尔数组来跟踪 k 距离索引。 然后它迭代每个元素`nums`，标记每个关键索引周围的范围。 最后，它将所有标记的索引收集到一个列表中，生成排序的输出。 

## 解决方案```go
func findKDistantIndices(nums []int, key int, k int) []int {
    n := len(nums)
    isKDistant := make([]bool, n)
    
    for j, num := range nums {
        if num == key {
            start := j - k
            if start < 0 {
                start = 0
            }
            end := j + k
            if end >= n {
                end = n - 1
            }
            for i := start; i <= end; i++ {
                isKDistant[i] = true
            }
        }
    }
    
    result := []int{}
    for i, val := range isKDistant {
        if val {
            result = append(result, i)
        }
    }
    return result
}
```在 Go 中，我们显式处理切片的边界并使用内置的`append`收集结果的函数。 布尔切片`isKDistant`反映了 Python 方法。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 迭代一遍`nums`一次并标记范围； 每个索引最多标记一次 |

 ## 边缘情况

 1. **单元素数组**：如果数组只有一个元素，并且它等于键，则唯一的索引通常是 k 距离。 实现通过正常范围计算来处理这个问题`max`和`min`。
