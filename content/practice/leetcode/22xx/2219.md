[LeetCode 2219 题](https://leetcode.com/problems/maximum-sum-score-of-array/)

 **难度：** 🟡 中等
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 该问题给了我们一个**0索引**整数数组`nums`长度`n`并要求我们计算数组所有索引中的**最大总分**。 索引处的**总分**`i`被定义为两个总和的最大值：第一个总和`i + 1`数组的元素（前缀总和到索引`i`) 和最后的总和`n - i`元素（从索引开始的后缀和`i`）。 

简而言之，对于数组中的每个位置，如果我们考虑从开始到该索引的所有内容以及从该索引到结束的所有内容，我们就会查看总和。 总分取两者中较大者。 然后我们想要所有指数的最大总分。 

约束表明数组可以非常大（`1 <= n <= 10^5`）并且数字可以在一定范围内为负数或正数`-10^5`到`10^5`。 这排除了任何以嵌套方式重复计算总和的强力解决方案，因为对于上限来说它太慢了。 

重要的边缘情况包括长度为 1 的数组、所有元素均为负数的数组以及最大总分来自前缀或后缀而不是整个数组的数组。 

## 方法

 **蛮力：**天真的方法是迭代每个索引`i`，计算第一个的总和`i + 1`元素和最后一个元素的和`n - i`分别元素，取最大值，并跟踪总体最大值。 虽然正确，但这种方法效率低下，因为单独计算每个索引的总和会导致重复工作，导致大小数组的时间复杂度为 O(n^2)`n`。 

**最佳方法：**关键的见解是我们可以在 O(n) 时间内预先计算**前缀和**和**后缀和**。 一旦我们有了这些累积总和，就可以计算任何索引的总分`i`简化为两个数字的单一比较：`prefix[i]`和`suffix[i]`。 这允许我们迭代数组一次来计算最大总分，从而实现 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 分别计算每个索引的总和 |
 | 最佳| O(n) | O(n) | 预先计算前缀和后缀总和，然后计算最大总分 |

 ## 算法演练

 1.初始化两个数组`prefix`和`suffix`长度`n`。`prefix[i]`将存储第一个的总和`i + 1`元素，以及`suffix[i]`将存储最后的总和`n - i`元素。 
2. 计算**前缀和**：从以下开始`prefix[0] = nums[0]`对于每个后续索引`i`， 放`prefix[i] = prefix[i-1] + nums[i]`。 
3. 计算**后缀和**：从`suffix[n-1] = nums[n-1]`对于每个先前的索引`i`从`n-2`下降到`0`， 放`suffix[i] = suffix[i+1] + nums[i]`。 
4. 初始化变量`max_score`到负无穷以跟踪最大总分。 
5. 迭代每个索引`i`从`0`到`n-1`, 计算`score = max(prefix[i], suffix[i])`，并更新`max_score`如果`score`更大。 
6. 返回`max_score`循环完成后。 

**为什么有效：** 通过预先计算前缀和后缀总和，我们消除了重复的总和计算。 该算法保证我们比较每个索引的正确前缀和后缀总和，确保找到最大总分。 每个数组仅被遍历固定次数，保持线性时间复杂度。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumSumScore(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * n
        suffix = [0] * n
        
        prefix[0] = nums[0]
        for i in range(1, n):
            prefix[i] = prefix[i-1] + nums[i]
        
        suffix[n-1] = nums[n-1]
        for i in range(n-2, -1, -1):
            suffix[i] = suffix[i+1] + nums[i]
        
        max_score = float('-inf')
        for i in range(n):
            max_score = max(max_score, max(prefix[i], suffix[i]))
        
        return max_score
```**实现说明：** 代码首先在单独的循环中计算前缀和后缀总和，这允许恒定时间访问任何索引的总和。 最后的循环有效地计算每个索引的总分。 使用`float('-inf')`确保正确处理仅负数数组。 

## 解决方案```go
func maximumSumScore(nums []int) int64 {
    n := len(nums)
    prefix := make([]int64, n)
    suffix := make([]int64, n)
    
    prefix[0] = int64(nums[0])
    for i := 1; i < n; i++ {
        prefix[i] = prefix[i-1] + int64(nums[i])
    }
    
    suffix[n-1] = int64(nums[n-1])
    for i := n-2; i >= 0; i-- {
        suffix[i] = suffix[i+1] + int64(nums[i])
    }
    
    maxScore := prefix[0]
    for i := 0; i < n; i++ {
        if prefix[i] > suffix[i] && prefix[i] > maxScore {
            maxScore = prefix[i]
        } else if suffix[i] >= prefix[i] && suffix[i] > maxScore {
            maxScore = suffix[i]
        }
    }
    
    return maxScore
}
```**Go 特定注释：** 我们使用`int64`防止整数溢出，因为总和可能超过`int`范围。 逻辑与 Python 相同，但 Go 在对整数求和时需要显式类型转换。

 ## 边缘情况

 **单元素数组：**只有一个元素，前缀和后缀之和相同。 我们的解决方案可以正确处理这个问题，因为前缀和后缀数组是用元素本身初始化的。 

**所有负数：** 幼稚的实现可能会初始化`max_score`为零，错误地返回不存在的正和。 使用负无穷大可以确保我们捕获最大的负值。 

**结束处的最大总和：**有时最大总和分数出现在第一个或最后一个索引处。 该算法正确地考虑了两端，因为前缀和从左侧开始，后缀和从右侧开始。
