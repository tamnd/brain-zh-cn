[LeetCode 问题 2283](https://leetcode.com/problems/check-if-number-has-equal-digit-count-and-digit-value/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 这个问题要求我们验证一串数字的自描述性。 给你一个字符串`num`长度`n`，其中每个字符都是“0”和“9”之间的数字。 要求是对于每个索引`i`在字符串中，数字`i`必须准确出现`num[i]`整个字符串中的次数。 

简单来说，如果`num[i] = '3'`，然后是数字`i`应该在字符串中恰好出现 3 次。 如果这个条件对于每个索引都成立，我们返回`true`; 否则，我们返回`false`。 

输入约束告诉我们`1 <= n <= 10`，这意味着字符串非常短，因此即使是 O(n²) 解决方案也是可行的。 该字符串仅包含数字，这简化了计数，因为我们可以使用大小为 10 的数组或哈希映射。重要的边缘情况包括计数为零的字符串、违反自描述属性的重复数字的字符串以及长度为 1 的字符串。 

## 方法

 蛮力方法很简单：对于每个索引`i`在`num`, 数一下这个数字有多少次`i`出现在字符串中，并将其与`num[i]`。 如果任何计数不匹配，则返回 false。 这是有效的，因为它直接实现了问题的定义。 考虑到约束条件（`n <= 10`），这种方法是可以接受的，但它会执行冗余工作，多次重新计算相同数字的计数。 

最佳方法通过使用单遍预先计算字符串中所有数字的出现次数来对此进行改进。 然后，我们迭代每个索引并简单地检查数字的计数`i`比赛`num[i]`。 这减少了重复计数并使逻辑更清晰。 由于字符串非常短，因此实际上性能增益很小，但这种方法在概念上可以更好地扩展。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 计算每个索引的每个数字 |
 | 最佳| O(n) | O(10) = O(1) | O(10) = O(1) | 预先计算数字，然后比较计数 |

 ## 算法演练

 1.初始化一个数组`digit_count`大小为 10，用于存储从 0 到 9 的每个数字的计数。 
2. 迭代每个字符`c`在字符串中`num`。 转变`c`为一个整数`d`并增加`digit_count[d]`。 
3. 迭代每个索引`i`范围从 0 到`n-1`。 转变`num[i]`为一个整数`expected_count`。 
4. 检查是否`digit_count[i]`等于`expected_count`。 如果没有，则返回`false`立即地。 
5. 如果循环完成没有返回`false`，所有条件都满足，所以返回`true`。 

**为什么有效：** 该算法在单次传递中正确捕获每个数字的频率，随后的检查确保自描述条件适用于每个索引。 使用预计数数组可保证每个数字的出现仅计算一次，从而使检查可靠且高效。 

## Python 解决方案```python
class Solution:
    def digitCount(self, num: str) -> bool:
        n = len(num)
        digit_count = [0] * 10
        
        for c in num:
            digit_count[int(c)] += 1
        
        for i in range(n):
            expected_count = int(num[i])
            if digit_count[i] != expected_count:
                return False
        
        return True
```该实现首先创建一个`digit_count`数组来存储每个数字的出现次数。 它迭代字符串以填充该数组。 然后，对于每个索引`i`，它检查实际位数是否`i`与定义的预期计数匹配`num[i]`。 如果发生任何不匹配，则返回`false`; 否则，它返回`true`。 

## 解决方案```go
func digitCount(num string) bool {
    n := len(num)
    digitCount := make([]int, 10)
    
    for i := 0; i < n; i++ {
        d := int(num[i] - '0')
        digitCount[d]++
    }
    
    for i := 0; i < n; i++ {
        expectedCount := int(num[i] - '0')
        if digitCount[i] != expectedCount {
            return false
        }
    }
    
    return true
}
```在 Go 中，我们使用长度为 10 的切片来存储计数。 我们通过减法将每个字符转换为整数`'0'`。 该逻辑在其他方面反映了 Python 版本，确保所有数字都计算一次并与预期值进行比较。

 ## 边缘情况

 **单个字符串：** 对于`num`长度为 1，唯一有效的字符串是`"0"`因为索引 0 处的数字必须出现 0 次。 字符串像`"1"`违反此条件。 该算法通过计算出现次数并检查索引 0 来正确处理此问题。 

**数字超过字符串长度：**如果某个数字的预期计数超过了字符串的长度，例如`num = "500"`（长度为3，但索引0期望出现5次），算法自然会检查失败，因为任何数字的计数都不能超过字符串长度。 

**全零：**类似的字符串`"0000"`可能会显得很棘手。 每个索引预计出现 0 次，但数字 0 出现多次。 该算法正确计算数字 0 并识别不匹配，返回`false`。 

这种方法通过直接计算实际发生次数并与预期计数进行比较，可靠地处理所有这些边缘情况。
