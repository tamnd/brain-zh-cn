[LeetCode 问题 2264](https://leetcode.com/problems/largest-3-same-digit-number-in-string/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题需要从给定的数字字符串中识别最大的“好”整数。 “好”整数被定义为长度为 3 的子串，其中所有数字都相同。 输入字符串`num`表示一个大整数，但以字符串形式提供，这使我们能够处理前导零和最大长度 1000，而不会出现数字溢出。 输出应该是表示最大的好整数的字符串，如果不存在这样的子字符串，则输出应该是空字符串。 

需要理解的关键方面包括：

 1. **子串要求**：好的整数必须是连续的三位数序列`num`。 
2. **单位数字重复**：所有三个字符必须相同。 
3. **返回格式**：结果必须是字符串，而不是整数。 
4. **约束**：输入长度在 3 到 1000 之间，所有字符都是数字（'0'-'9'），因此性能很重要，但可以通过单遍解决方案进行管理。 

重要的边缘情况包括没有重复三元组​​的字符串（例如“12345”）、唯一好的整数包含零的字符串（例如“2300019”）以及具有多个好的整数且必须选择最大整数的字符串（例如“6777133339”）。 该算法必须正确处理前导零并按字典顺序比较子字符串，因为它们是单位数重复。 

## 方法

 暴力方法将检查长度为 3 的每个可能的子字符串，并检查所有三个字符是否相同。 虽然正确，但这种方法对于大字符串来说效率有些低，因为它会重复检查重叠的子字符串，尽管在长度≤1000的约束下，它是可行的。 

优化的一个关键见解是我们只需要检查连续的三元组一次。 由于每个子字符串的长度为 3，因此我们可以线性迭代该字符串，一次比较三个连续的字符。 如果它们相同，我们会更新一个变量，跟踪迄今为止找到的最大好整数。 这种方法确保我们只遍历字符串一次，使其高效且简单。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 检查所有长度为 3 的子串是否有相同的数字，更新最大值。 实际上是线性的，因为只存在 n-2 个子串。 |
 | 最佳| O(n) | O(1) | O(1) | 单次通过字符串检查三元组并更新最大值，无需额外存储。 |

 ## 算法演练

 1. 初始化变量`max_good`到一个空字符串来跟踪找到的最大的好整数。 
2. 迭代从索引 0 到`len(num) - 3`，检查长度为 3 的每个子串。 
3.对于每个子串`num[i:i+3]`，检查所有三个字符是否相同。 
4. 如果子串是一个好的整数并且大于当前的`max_good`（按字典顺序），更新`max_good`。 
5、迭代完成后，返回`max_good`。 如果没有找到好的整数，它将保留为空字符串。 

为什么它有效：不变的是`max_good`始终存储迄今为止遇到的最大的好整数。 通过检查每个三元组一次并仅在它大于当前最大值时更新，该算法保证了最终值`max_good`是字符串中最大可能的好整数。 

## Python 解决方案```python
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        max_good = ""
        for i in range(len(num) - 2):
            if num[i] == num[i+1] == num[i+2]:
                substring = num[i:i+3]
                if substring > max_good:
                    max_good = substring
        return max_good
```这个 Python 实现完全遵循该算法。 我们迭代`num`检查每个三元组是否相等。 当找到一个三元组时，将其与`max_good`按字典顺序，这是有效的，因为所有好的整数的长度都是 3。这确保选择最大的三元组。 如果没有找到好的三元组，该函数将返回初始化的空字符串。 

## 解决方案```go
func largestGoodInteger(num string) string {
    maxGood := ""
    for i := 0; i <= len(num)-3; i++ {
        if num[i] == num[i+1] && num[i+1] == num[i+2] {
            substring := num[i:i+3]
            if substring > maxGood {
                maxGood = substring
            }
        }
    }
    return maxGood
}
```在 Go 中，逻辑反映了 Python。 我们遍历字符串并检查三个连续字节是否相等。 如果是这样，我们使用字符串比较将子字符串与当前最大值进行比较。 Go字符串直接支持字典序比较，因此安全高效。

 ## 边缘情况

 一种关键的边缘情况是字符串包含前导零，例如“00100”。 简单的数字比较会误解这些，但字典字符串比较可以正确地将“000”识别为一个好的整数。 

另一种边缘情况是所有数字都相同，例如“9999999”。 该实现正确识别第一个和后续的三元组，始终跟踪最大值。 即使是重叠的三元组也被认为是有效的。 

第三种边缘情况是根本没有好的整数，例如“123456”。 该算法通过维持最初为空来正确返回空字符串`max_good`并且仅在找到有效的三元组后才更新它。 这可确保不会出现误报。
