[LeetCode 问题 2267](https://leetcode.com/problems/check-if-there-is-a-valid-parentheses-string-path/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 本题要求我们判断是否存在从左上角开始的路径`(0, 0)`到右下角`(m-1, n-1)`的 2D 网格仅包含`'('`和`')'`字符，使得沿路径的字符序列形成**有效的括号字符串**。 路径被限制为每一步只能**向右**或**向下**移动。 

有效的括号字符串是递归定义的：要么是`"()"`，或者是两个有效字符串的串联，或者是括在括号中的有效字符串。 本质上，这是格式正确的括号的经典定义。 

输入`grid`是一个大小矩阵`m x n`和`1 <= m, n <= 100`。 每个单元格包含`'('`或者`')'`。 输出是一个布尔值：`true`如果存在有效的括号字符串路径，否则`false`。 

主要限制因素和观察结果是：

 1. 路径的长度`(0,0)`到`(m-1,n-1)`总是`m + n - 1`。 这意味着生成的括号字符串必须具有**偶数长度**，因为有效的括号字符串必须具有相同数量的左括号和右括号。 
2. 在路径上的任意点，右括号的数量`)`遇到的不能超过左括号的数量`(`; 否则，从该点开始就不可能形成有效的括号字符串。 
3. 可能导致简单解决方案失败的边缘情况包括第一个或最后一个单元格所在的网格`')'`或者`'('`，因为这些立即使有效路径变得不可能。 非常窄的网格（1 行或 1 列）也是边缘情况，因为它们只允许一条路径。 

## 方法

 ### 蛮力

 暴力方法将尝试枚举**所有可能的路径**`(0,0)`到`(m-1,n-1)`。 对于每个路径，它将构建生成的括号字符串并检查它是否有效。 这种方法将涉及深度优先搜索（DFS），探索向下和向右移动的每种可能的组合。 

尽管是正确的，但是暴力方法对于以下情况是不可行的：`m, n`最多 100 条。从左上角到右下角的路径数是组合的，具体来说`C(m+n-2, m-1)`，呈指数增长。 

### 优化方法

 关键的见解是我们不需要为每个路径存储完整的括号字符串。 相反，我们可以保持左括号的**运行平衡**：

 - 余额加 1`'('`。 
- 将余额减 1`')'`。 

余额代表未匹配的净数量`'('`目前为止遇到的。 为了使路径保持潜在有效：

 1. 余额绝不能为负数。 
2. 右下角单元格的余额必须为零。 

由于多个路径可以以不同的余额到达同一单元，因此我们可以使用**动态编程**（DP）来有效地跟踪每个单元的所有可能的余额。 具体来说，我们根据每个单元格顶部和左侧邻居的余额维护一组余额。 

这避免了重新计算并确保正确性，同时保持在可行的时间和空间复杂度内。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(m+n) | 递归探索所有路径并检查有效性 |
 | 最佳（DP 平衡）| O(m * n * (m+n)) | O(m * n * (m+n)) | O(m * n * (m+n)) | O(m * n * (m+n)) | 使用集合 | 跟踪每个单元格的所有可行余额

 ## 算法演练

 1. **初步检查**：如果`grid[0][0]`是`')'`， 返回`false`立即地。 同样，如果`grid[m-1][n-1]`是`'('`， 返回`false`。 
2. **DP表设置**：创建2D数组`dp`其中每个单元格在该单元格中保存一组可行的余额。 
3. **初始化DP**：设置`dp[0][0] = {1}`如果`grid[0][0]`是`'('`或者`{0}`如果是的话`')'`（尽管初步检查阻止了这种情况）。 
4. **遍历网格**：对于每个单元格`(i,j)`，合并顶部的余额`(i-1,j)`然后离开了`(i,j-1)`邻居。 对于每个余额`b`：

 - 如果当前单元格是`'('`， 添加`b+1`到当前单元格的集合。 
- 如果当前单元格是`')'`， 添加`b-1`仅当`b > 0`。 
5. **修剪无效余额**：在每一步中，忽略负余额，因为它们无法生成有效的字符串。 
6. **检查结果**：处理完所有单元格后，检查是否余额`0`存在于`dp[m-1][n-1]`。 返回`true`如果是，否则`false`。 

**为什么有效**：DP 保持一个不变量`dp[i][j]`包含沿任何有效路径可实现的所有余额`(i,j)`。 负余额将被丢弃，确保仅考虑潜在的有效路径。 这样就保证了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        if grid[0][0] == ')' or grid[m-1][n-1] == '(':
            return False
        
        dp = [[set() for _ in range(n)] for _ in range(m)]
        dp[0][0].add(1)
        
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                current = set()
                if i > 0:
                    for b in dp[i-1][j]:
                        if grid[i][j] == '(':
                            current.add(b + 1)
                        elif b > 0:
                            current.add(b - 1)
                if j > 0:
                    for b in dp[i][j-1]:
                        if grid[i][j] == '(':
                            current.add(b + 1)
                        elif b > 0:
                            current.add(b - 1)
                dp[i][j] = current
        return 0 in dp[m-1][n-1]
```**解释**：我们迭代网格，更新来自顶部和左侧邻居的可行余额集。 我们增加余额`'('`并递减`')'`仅当积极时。 最后，我们检查右下角是否可以达到零余额。 

## 解决方案```go
func hasValidPath(grid [][]byte) bool {
    m, n := len(grid), len(grid[0])
    if grid[0][0] == ')' || grid[m-1][n-1] == '(' {
        return false
    }
    
    dp := make([][]map[int]struct{}, m)
    for i := range dp {
        dp[i] = make([]map[int]struct{}, n)
        for j := range dp[i] {
            dp[i][j] = make(map[int]struct{})
        }
    }
    dp[0][0][1] = struct{}{}
    
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if i == 0 && j == 0 {
                continue
            }
            current := make(map[int]struct{})
            if i > 0 {
                for b := range dp[i-1][j] {
                    if grid[i][j] == '(' {
                        current[b+1] = struct{}{}
                    } else if b > 0 {
                        current[b-1] = struct{}{}
                    }
                }
            }
            if j > 0 {
                for b := range dp[i][j-1] {
                    if grid[i][j] == '(' {
                        current[b+1] = struct{}{}
                    } else if b > 0 {
                        current[b-1] = struct{}{}
                    }
                }
            }
            dp[i][j] = current
        }
    }
    _, ok := dp[m-1][n-1][0]
    return ok
}
```**Go 特定注释**：在 Go 中，集合是使用以下实现的`map[int]struct{}`。 该逻辑与 Python 类似，迭代顶部和左侧的邻居并相应地更新余额。
