 ## 问题理解

 问题给你`n`城市，编号为`0`到`n - 1`，以及连接城市对的双向道路列表。 每个城市必须分配一个**唯一的整数值`1`到`n`**，而**道路的重要性**定义为其两个相连城市的值之和。 目标是以**最大化所有道路的总重要性**的方式分配值。 

输入是：

 -`n`：城市数量，范围从 2 到 50,000 个。 
-`roads`：对的列表`[a, b]`代表双向连接。 每条路都是独一无二的。 

输出是一个整数，即所有道路的最大总重要性。 

主要观察结果包括，连接更多道路的城市应该获得更高的价值，以最大限度地提高总贡献。 这是因为每条道路的贡献是其两个城市价值的总和； 将更多的数字分配给连接程度更高的城市，对总数的贡献就更大。 

重要的边缘情况包括：

 - 没有联系的城市：它们的分配值不会影响总体重要性。 
- 道路网络稀疏，一些城市只有一条道路。 
- 密集的道路网络，一些城市有多个连接。 

该问题保证没有重复的道路并且`ai != bi`，所以我们不需要检查无效输入。 

## 方法

 ### 蛮力

 暴力解决方案会尝试数字的**每种排列**`1`到`n`分配到城市。 对于每个排列，通过求和来计算道路重要性的总和`value[a] + value[b]`每条道路`[a,b]`。 返回找到的最大总和。 

这种方法是正确的，但**计算上不可行**，因为有`n!`排列。 即使是为了`n = 10`,`10! = 3,628,800`，并且对于`n = 50,000`这是不可能的。 

### 最优贪心法

 关键的见解是，**拥有更多道路的城市对总重要性的贡献更大**，因为每条道路的重要性取决于其两个端点。 因此：

 1. 统计连接每个城市的道路数量（度数）。 
2. 将最高的数字分配给学位最高的城市。 
3. 使用这些作业总结重要性。 

这种方法保证了城市分配价值的每一个增长单位都应用于尽可能多的道路，从而最大化总体重要性。 按程度对城市进行排序使我们能够最佳地分配值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * m) | O(n) | 检查城市价值的每一个排列 |
 | 最优贪心 | O(n + m + n log n) | O(n + m + n log n) | O(n) | 按程度对城市进行排序、分配值、汇总贡献 |

 这里，`n`是城市的数量，并且`m`是道路的数量。 

## 算法演练

 1.初始化一个数组`degree`尺寸的`n`计算连接到每个城市的道路数量。 
2. 迭代`roads`，并且对于每条道路`[a, b]`, 增量`degree[a]`和`degree[b]`。 这会计算每个城市的连通性。 
3. 创建元组列表`(city_index, degree[city_index])`。 
4. 按程度**降序**对此列表进行排序。 连接较多的城市将首先出现。 
5. 赋值自`n`下降到`1`按照这个排序顺序。 连接最紧密的城市`n`，下一个得到`n-1`， 等等。 
6. 迭代原始内容`roads`列表，以及每条道路`[a, b]`, 总和`assigned_value[a] + assigned_value[b]`进入`total_importance`。 
7. 返回`total_importance`。 

**为什么有效：** 每个城市都为每条相连的道路贡献自己的价值。 为度数较高的城市分配较高的数字可以最大化总和，因为度数较高的城市中的每个增量都会传播到许多道路。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumImportance(self, n: int, roads: List[List[int]]) -> int:
        degree = [0] * n
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1
        
        # Sort cities by degree in descending order
        city_order = sorted(range(n), key=lambda x: degree[x], reverse=True)
        
        # Assign values from n down to 1
        assigned_value = [0] * n
        for i, city in enumerate(city_order):
            assigned_value[city] = n - i
        
        # Sum importance of all roads
        total_importance = 0
        for a, b in roads:
            total_importance += assigned_value[a] + assigned_value[b]
        
        return total_importance
```**说明：**

 - 首先，`degree`数组计算每个城市参与的道路数量。 
-`city_order`按程度对城市进行排序以决定价值分配。 
-`assigned_value`将每个城市索引映射到其指定的整数。 
- 最后，我们迭代`roads`并计算总重要性。 

## 解决方案```go
func maximumImportance(n int, roads [][]int) int64 {
    degree := make([]int, n)
    for _, road := range roads {
        degree[road[0]]++
        degree[road[1]]++
    }
    
    type cityDeg struct {
        idx int
        deg int
    }
    
    cities := make([]cityDeg, n)
    for i := 0; i < n; i++ {
        cities[i] = cityDeg{i, degree[i]}
    }
    
    // Sort by degree descending
    sort.Slice(cities, func(i, j int) bool {
        return cities[i].deg > cities[j].deg
    })
    
    assignedValue := make([]int, n)
    for i, city := range cities {
        assignedValue[city.idx] = n - i
    }
    
    var total int64
    for _, road := range roads {
        total += int64(assignedValue[road[0]] + assignedValue[road[1]])
    }
    
    return total
}
```**Go 特定注释：**

 - 我们定义一个结构体`cityDeg`将索引与度数配对。 
- 排序用途`sort.Slice`带有自定义比较器。 
- 使用`int64`为了`total`以避免整数溢出`n`最多可达 50,000。 

## 工作示例

 ### 示例 1

 输入：`n = 5, roads = [[0,1],[1,2],[2,3],[0,2],[1,3],[2,4]]`1. 计算度数：`[2, 3, 4, 2, 1]`2.按等级对城市进行排序：`[2, 1, 0, 3, 4]`3. 分配从 5 到 1 的值：`[3, 4, 5, 2, 1]`4. 计算道路重要性：

 | 道路| 总和 |
 | --- | --- |
 | 0,1 | 3 + 4 = 7 | 3 + 4 = 7
 | 1,2 | 4 + 5 = 9 | 4 + 5 = 9
 | 2,3 | 5 + 2 = 7 |
 | 0,2 | 3 + 5 = 8 |
 | 1,3 | 4 + 2 = 6 |
 | 2,4 | 5 + 1 = 6 |

 总计 = 7 + 9 + 7 + 8 + 6 + 6 = 43

 ### 示例 2

 输入：`n = 5, roads = [[0,3],[2,4],[1,3]]`1. 学位：`[1, 1, 1, 2, 1]`2. 排序：`[3,0,1,2,4]`3. 赋值：`[4,3,2,5,1]`4. 道路费用：

 | 道路| 总和 |
 | --- | --- |
 | 0,3 | 4 + 5 = 9 | 4 + 5 = 9
 | 2,4 | 2 + 1 = 3 |
 | 1,3 | 3 + 5 = 8 |

 总计 = 20
