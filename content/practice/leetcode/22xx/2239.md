[LeetCode 问题 2239](https://leetcode.com/problems/find-closest-number-to-zero/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 问题给了我们一个整数数组`nums`，我们需要返回其值最接近的数字`0`。 

短语“最接近零”意味着我们使用数字的绝对值来比较数字。 例如：

-`|-2| = 2`-`|5| = 5`自从`2 < 5`, 数量`-2`比 更接近于零`5`。 

还有一条重要的平局规则。 如果两个数字同样接近于零，我们必须返回较大的数字。 例如：

-`-1`和`1`都是距离`1`从零开始
 - 自从`1 > -1`，正确答案是`1`输入包括：

 - 整数数组`nums`- 数组长度`n`在哪里`1 <= n <= 1000`- 每个值都介于`-10^5`和`10^5`约束很小，这意味着即使是简单的线性扫描也足够有效。 我们不需要高级的数据结构或排序。 

一些边缘情况很重要：

 - 包含绝对值相等的正数和负数的数组
 - 仅包含负数的数组
 - 仅包含正数的数组
 - 包含单个元素的数组
 - 数组包含`0`，因为零自动是最接近的可能值

 该问题保证数组非空，因此总会有至少一个有效答案。 

## 方法

 ### 蛮力方法

 暴力方法会将每个数字与其他每个数字进行比较，以确定哪个数字最接近零。 

对于每个元素：

 1.计算其绝对值
 2. 将其与所有其他元素的绝对值进行比较
 3. 跟踪最佳候选人

 这种方法之所以有效，是因为最终每对数字都会进行比较，因此可以正确识别最接近的数字。 

然而，该方法执行了不必要的重复比较。 由于我们只需要单个最佳答案，因此不需要嵌套循环。 一次通过数组就足够了。 

### 最佳解决方案的关键见解

 重要的观察是，我们只需要在扫描一次数组时保持当前的最佳答案。 

对于每个数字：

 - 如果其绝对值小于当前最佳值，则更新答案
 - 如果绝对值相等，则选择较大的数字

 由于每个元素都是独立处理的，因此一次线性扫描就足够了。 

这将时间复杂度从二次时间降低到线性时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 将每个数字与其他每个数字进行比较 |
 | 最佳| O(n) | O(1) | O(1) | 单次通过同时跟踪最近的号码 |

 ## 算法演练

 1. 使用数组的第一个元素初始化答案。 

我们需要一些起始值来进行比较。 由于保证数组非空，因此使用第一个元素是安全的。 
2. 迭代数组中的每个数字。 

对于每个数字，计算其绝对值并将其与当前最佳答案的绝对值进行比较。 
3. 如果当前数字接近于零，则更新答案。 

如果：```
abs(current) < abs(answer)
```那么当前的数字绝对更好并成为新的答案。 
4. 处理平局情况。 

如果：```
abs(current) == abs(answer)
```那么两个数字都同样接近于零。 

在这种情况下，选择较大的值：```
max(current, answer)
```这确保了`1`被选择超过`-1`。 
5. 继续，直到阵列被完全处理。 
6. 返回最终答案。 

### 为什么它有效

 该算法保持了处理每个元素后的不变量，`answer`根据问题规则存储迄今为止看到的最佳候选者。 

每当我们遇到接近于零的数字时，我们都会立即更新答案。 当两个数字同样接近时，我们应用所需的平局规则并保留较大的值。 

由于每个元素都被处理一次，因此最终答案必须是正确的最接近的数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def findClosestNumber(self, nums: List[int]) -> int:
        closest = nums[0]

        for num in nums:
            if abs(num) < abs(closest):
                closest = num
            elif abs(num) == abs(closest):
                closest = max(closest, num)

        return closest
```实现首先将第一个数组元素存储在`closest`。 该变量始终代表迄今为止找到的最佳答案。 

循环处理数组中的每个数字。 对于每个数字：

 - 如果它的绝对值小于当前最好的值，则它成为新的最接近的数字。 
- 如果绝对值相等，`max()`用于保留较大的值。 

使用`max()`干净利落地处理打破平局的要求。 例如：```python
max(-1, 1) == 1
```循环结束后，`closest`包含正确答案并返回。 

## 解决方案```go
func findClosestNumber(nums []int) int {
    closest := nums[0]

    for _, num := range nums {
        if abs(num) < abs(closest) {
            closest = num
        } else if abs(num) == abs(closest) {
            if num > closest {
                closest = num
            }
        }
    }

    return closest
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```Go 解决方案遵循与 Python 版本相同的逻辑。 

由于 Go 没有提供内置整数`abs()`对于普通整数，我们手动实现一个辅助函数。 

迭代使用 Go 的`range`处理切片中每个元素的语法。 

因为约束很小并且值很适合 Go 的范围`int`类型，整数溢出不是这里的问题。

 ## 边缘情况

 ### 包含零的数组

 如果数组包含`0`， 然后`0`一定是答案，因为它距零的距离恰好为零，这是可能的最小距离。 

有缺陷的实现可能会在找到零后继续错误地更新答案。 此实现可以正确处理它，因为没有其他数字的绝对值可以小于`0`。 

### 绝对值相等

 平局决胜规则是最常见的错误来源。 例如：```
[-1, 1]
```两个数字都同样接近于零，但正确答案是`1`。 

该实现显式检查绝对值是否相等，并使用较大的数字：```
max(closest, num)
```这保证了正确的平局解析。 

### 单元素数组

 该数组可能只包含一个值。 在这种情况下，必须立即返回该元素，因为它自动是最接近的数字。 

该实现通过初始化来安全地处理这个问题`closest`和`nums[0]`。 由于约束保证数组非空，因此这始终有效。
