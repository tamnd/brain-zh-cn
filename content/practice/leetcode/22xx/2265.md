[LeetCode 问题 2265](https://leetcode.com/problems/count-nodes-equal-to-average-of-subtree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算二叉树中有多少个节点满足特定条件：节点的值必须等于**其子树中所有节点的平均值**。 

子树由当前节点及其下面的每个后代组成。 对于每个节点，我们需要计算：

 - 其子树中所有值的总和
 - 该子树中的节点总数
 - 整数平均值，使用楼层除法计算

 如果节点的值等于计算出的平均值，我们就对其进行计数。 

例如，假设子树包含值`[5, 6]`。 总和是`11`，节点数为`2`，平均值为：$$11 // 2 = 5$$由于整数除法向下舍入，节点`5`将有资格。 

输入是`root`的二叉树。 每个节点都包含一个整数值和指向其左子节点和右子节点的指针。 输出是一个整数，表示其值等于其各自子树的平均值的节点数。 

约束告诉我们树最多包含`1000`节点并且每个节点值都在`0`和`1000`。 

虽然`1000`节点不是很大，重复遍历子树的简单方法仍然会变得低效，因为许多节点会被多次访问。 这表明我们应该寻找一种只计算一次子树信息的方法。 

有几个重要的边缘情况需要记住：

 - **单节点树**始终符合条件，因为它的子树仅由其自身组成，因此其平均值等于其值。 
- 由于相同的原因，**叶节点**始终符合条件，因为子树大小为`1`。 
- 如果我们从头开始为每个节点重新计算子树总和，那么具有**许多重叠子树**的树可能会使重复计算变得昂贵。 
- 整数除法很重要。 由于问题明确指出平均值是向下舍入的，因此我们必须使用底除法（`//`在 Python 中，在 Go 中是整数除法）。 

## 方法

 ### 蛮力方法

 解决这个问题的一个直接方法是独立处理每个节点。 

对于每个节点，我们可以递归遍历其整个子树来计算两件事：

 1. 子树中所有值的总和
 2.子树的节点数

 计算这些值后，我们计算：$$\text{average} = \text{sum} // \text{count}$$如果平均值等于节点的值，我们就会增加我们的答案。 

该方法是正确的，因为每个节点都显式计算其子树的精确统计数据。 

然而，低效率来自于重复工作。 假设一个节点出现在许多祖先子树中。 它的值会被反复重新计算。 在一棵倾斜的树中`n`节点，第一个节点遍历`n`节点，接下来遍历`n - 1`等等，大致结果是：$$O(n^2)$$时间复杂度。 

### 最优方法，后序 DFS

 关键的观察是子树信息可以**自下而上**计算。 

要确定一个节点是否与其子树平均值匹配，我们只需要：

 - 左子树的总和
 - 左子树中的节点数
 - 右子树的总和
 - 右子树中的节点数

 这自然意味着**后序遍历**，我们在处理父级之前处理子级。 

对于每个节点，我们递归地收集：

 - 子树总和
 - 子树总大小

 然后我们计算平均值并立即检查节点是否合格。 

由于每个节点只处理一次，因此我们消除了多余的工作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(h) | 重复重新计算子树和 |
 | 最佳| O(n) | O(h) | 后序 DFS 计算一次子树数据 |

 这里，`h`代表树的高度。 

## 算法演练

 ### 最优算法，后序 DFS

 1. 使用递归从根开始深度优先遍历。 
2. 对于每个节点，先递归处理左子树。 递归调用返回两个值：

 - 左子树中值的总和
 - 左子树的节点数
 3、以同样的方式递归处理右子树。 
4.合并子树信息：

 - 当前子树和=左和+右和+当前节点值
 - 当前子树计数 = 左计数 + 右计数 + 1
 5. 使用整数除法计算子树平均值：$$\text{average} = \text{subtree sum} // \text{subtree count}$$6. 将平均值与当前节点值进行比较。 如果它们相等，则增加答案。 
7. 将子树总和和子树计数返回给父节点。 
8. 继续直到递归在根处完成。 

### 为什么它有效

 该算法之所以有效，是因为**后序遍历不变式**：

 在处理节点时，算法已经知道两个子子树的确切总和和大小。 

由于子树由当前节点及其后代组成，因此组合子结果可以给出当前节点的准确子树统计信息。 因此，每个平均计算都是正确的，并且每个节点只被评估一次。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional, Tuple

class Solution:
    def averageOfSubtree(self, root: Optional[TreeNode]) -> int:
        matching_nodes = 0

        def dfs(node: Optional[TreeNode]) -> Tuple[int, int]:
            nonlocal matching_nodes

            if not node:
                return 0, 0

            left_sum, left_count = dfs(node.left)
            right_sum, right_count = dfs(node.right)

            subtree_sum = left_sum + right_sum + node.val
            subtree_count = left_count + right_count + 1

            subtree_average = subtree_sum // subtree_count

            if subtree_average == node.val:
                matching_nodes += 1

            return subtree_sum, subtree_count

        dfs(root)
        return matching_nodes
```该实现遵循递归后序遍历。 

嵌套的`dfs()`函数返回一个包含子树总和和子树节点计数的元组。 这使得父节点可以轻松地组合其子节点的结果。 

底壳手柄`None`通过返回节点`(0, 0)`，这意味着空子树不贡献任何总和，也不贡献任何节点。 

递归处理左子树和右子树后，算法计算当前子树统计数据。 然后它使用整数除法计算平均值并将其与当前节点值进行比较。 

这`matching_nodes`变量在 DFS 函数外部声明并使用更新`nonlocal`，允许每次递归调用都对最终答案做出贡献。 

最后从根开始遍历，并返回累加的计数。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func averageOfSubtree(root *TreeNode) int {
    matchingNodes := 0

    var dfs func(node *TreeNode) (int, int)

    dfs = func(node *TreeNode) (int, int) {
        if node == nil {
            return 0, 0
        }

        leftSum, leftCount := dfs(node.Left)
        rightSum, rightCount := dfs(node.Right)

        subtreeSum := leftSum + rightSum + node.Val
        subtreeCount := leftCount + rightCount + 1

        subtreeAverage := subtreeSum / subtreeCount

        if subtreeAverage == node.Val {
            matchingNodes++
        }

        return subtreeSum, subtreeCount
    }

    dfs(root)
    return matchingNodes
}
```Go 的实现与 Python 版本非常相似。 

而不是嵌套函数`nonlocal`, Go 捕获`matchingNodes`通过一个闭包。 由于 Go 默认对整数使用整数除法，因此不需要额外的舍入逻辑。 

零节点通过以下方式显式处理：```go
if node == nil
```返回`(0, 0)`对于空子树。 

由于最大可能的子树和仅为`1000 * 1000 = 1,000,000`，整数溢出不是 Go 的问题`int`类型。

 ## 边缘情况

 ### 单节点树

 只有一个节点的树是最小的有效输入。 由于子树仅包含节点本身，因此总和等于节点值，计数为`1`。 因此平均值必须等于节点值。 有缺陷的实现可能会意外地错误地处理失踪的孩子或除以零，但我们的实现安全地返回`(0, 0)`对于空孩子并正确计算平均值。 

### 叶节点

 每个叶节点始终符合条件，因为它的子树仅包含其自身。 在实现递归时，这一点很容易被忽视。 由于我们的 DFS 自下而上返回子树信息，叶子自然会计算：```
sum = node.val
count = 1
average = node.val
```使条件自动更正。 

### 整数除法舍入

 该问题明确要求平均值向下舍入。 例如，如果子树和是`11`计数是`2`，平均值应该是`5`， 不是`5.5`或者`6`。 一个常见的错误是使用浮点除法并比较小数。 我们的实现通过使用整数除法完全避免了这个问题：```
subtree_sum // subtree_count
```和：```
subtreeSum / subtreeCount
```这自然会执行楼层划分。 

### 高度倾斜的树

 一棵树可能会退化为一个链表，其中每个节点只有一个子节点。 在这种情况下，递归深度变为`O(n)`而不是`O(log n)`。 我们的算法仍然保持正确，因为每个节点都被处理一次，尽管堆栈使用量与树高成比例增加。
