[LeetCode 问题 2276](https://leetcode.com/problems/count-integers-in-intervals/)

 **难度：** 🔴难
 **主题：** 设计、线段树、有序集

 ## 解决方案

 ## 问题理解

 这个问题要求我们设计一种数据结构，动态维护整数区间的集合，并有效地报告至少一个区间覆盖了多少个不同的整数。 

最初，间隔集是空的。 我们必须支持两种操作：

 -`add(left, right)`，插入一个新的区间`[left, right]`-`count()`，返回迄今为止添加的所有间隔所覆盖的唯一整数的总数

 重要的细节是重叠的整数只能计算一次。 如果多个间隔覆盖同一个整数，则该整数仍然只对最终计数贡献 1。 

例如，假设我们添加`[2,3]`和`[7,10]`。 涵盖的整数是：`{2, 3, 7, 8, 9, 10}`总计数为`6`。 

如果我们稍后添加`[5,8]`，一些数字与`[7,10]`。 工会成为：`{2, 3, 5, 6, 7, 8, 9, 10}`请注意`7`和`8`不被计算两次。 结果变成`8`。 

这些约束告诉我们很多关于预期解决方案的信息。 

区间界限可以大到`10^9`，这立即排除了任何显式存储间隔中每个整数的解决方案。 即使是像这样的单个间隔`[1, 10^9]`不可能在记忆中具体化。 

我们还有多达`10^5`总操作。 由于每`add()`调用可能涉及非常大的范围，我们需要比迭代每个数字更有效的方法。 

关键的观察是我们关心区间联合，而不是单个元素。 我们不应该存储每个整数，而应该维护一个不重叠的合并间隔的集合并跟踪它们的总覆盖长度。 

一些边缘情况很重要：

 - 新添加的间隔可能部分与现有间隔重叠。 
- 一个新的间隔可以完全包含一个或多个先前的间隔。 
- 新间隔可以完全包含在现有间隔内。 
- 相邻的间隔，例如`[1,3]`和`[4,5]`应该合并，因为整数范围是连续且包含的。 
- 非常大的间隔，例如`[1, 10^9]`必须在不枚举值的情况下有效处理。 

## 方法

 ### 蛮力方法

 一种简单的方法是将每个覆盖的整数显式存储在哈希集中。 

每当`add(left, right)`被调用，我们迭代每个整数`left`到`right`并将其插入到集合中。 

什么时候`count()`被调用时，我们只需返回集合的大小。 

这是有效的，因为集合自然会删除重复项。 如果一个整数已经存在，重新插入它不会改变。 

然而，这种方法太慢并且占用大量内存。 

考虑一个像这样的区间`[1, 10^9]`。 在限制范围内，单个操作迭代十亿个数字是不可能的。 所需的内存也将是巨大的。 

我们需要一种方法来集体推理范围而不是单个整数。 

### 最优方法，有序的合并区间集

 关键的见解是我们只关心间隔的并集。 

我们不存储单独的数字，而是维护一组代表合并覆盖范围的不重叠间隔。 

当新的间隔到来时：

 1. 找到所有与其重叠或接触的现有区间。 
2. 将它们合并为一个更大的区间。 
3. 删除旧的重叠间隔。 
4. 插入合并的区间。 
5. 增量更新总覆盖计数。 

这是有效的，因为重叠的间隔会导致重复的覆盖，因此合并它们可以防止重复计算。 

例如：

 现有间隔：`[2,3] [7,10]`添加：`[5,8]`自从`[5,8]`重叠`[7,10]`，我们合并：`[5,10]`最终结构：`[2,3] [5,10]`总计数变为：`2 + 6 = 8`我们可以使用以间隔开始为键的排序结构有效地实现这一点。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每次添加 | O(右 - 左) O(覆盖的整数总数) | 显式存储每个整数 |
 | 最佳| 每次添加 | O(log n + k) O(n) | 维护合并的不相交间隔 |

 这里，`k`是合并期间删除的重叠间隔的数量。 

## 算法演练

 我们维护两个状态：

 1.非重叠间隔的排序集合。 
2. 运行整数`total_count`存储覆盖了多少个不同的整数。 

间隔始终保持合并。 

### 第 1 步：初始化数据结构

 从以下开始：

 - 空区间集合
 -`total_count = 0`由于最初没有间隔，因此计数为零。 

### 第 2 步：添加新间隔

 当`add(left, right)`被调用时，我们首先假设新的间隔是：`[new_left, new_right] = [left, right]`然后我们搜索重叠或接触该范围的间隔。 

如果满足以下条件，则两个区间重叠：```
existing_right >= new_left - 1
AND
existing_left <= new_right + 1
```这`±1`调整很重要，因为间隔是包容性的。 相邻的间隔应该合并。 

例子：```
[1,3] and [4,5]
```自从`3 + 1 = 4`，它们形成一个连续的覆盖范围。 

### 步骤 3：合并重叠区间

 对于每个重叠间隔：

 1.扩大合并范围：

 -`new_left = min(new_left, existing_left)`-`new_right = max(new_right, existing_right)`2. 从存储中取出旧间隔。 
3.减去它的贡献`total_count`。 

这可以避免重复计算。 

### 步骤 4：插入最终合并间隔

 处理重叠后，将合并的间隔插入回结构中。 

然后添加：```
new_right - new_left + 1
```到`total_count`。 

这`+1`存在是因为区间包含在内。 

例子：```
[5,10]
```包含：```
10 - 5 + 1 = 6
```整数。 

### 第 5 步：返回计数

 的`count()`操作变得微不足道。 

只需返回`total_count`。 

由于我们增量地维护答案，因此不需要重新计算。 

### 为什么它有效

 数据结构的不变性是所有存储的区间总是不相交且完全合并的。 

每当添加新间隔时，每个重叠间隔都会被吸收到一个更大的间隔中。 由于我们减去删除的间隔大小并将合并的间隔大小恰好加回一次，因此每个整数恰好为 1 贡献`total_count`。 

因此，`total_count`始终等于不同覆盖整数的数量。 

## Python 解决方案```python
from bisect import bisect_left
from typing import List, Tuple

class CountIntervals:

    def __init__(self):
        self.intervals: List[Tuple[int, int]] = []
        self.total_count = 0

    def add(self, left: int, right: int) -> None:
        merged_left = left
        merged_right = right

        index = bisect_left(self.intervals, (left, -1))

        if index > 0 and self.intervals[index - 1][1] + 1 >= left:
            index -= 1

        remove_start = index

        while (
            index < len(self.intervals)
            and self.intervals[index][0] <= merged_right + 1
        ):
            current_left, current_right = self.intervals[index]

            merged_left = min(merged_left, current_left)
            merged_right = max(merged_right, current_right)

            self.total_count -= (
                current_right - current_left + 1
            )

            index += 1

        self.intervals[remove_start:index] = [
            (merged_left, merged_right)
        ]

        self.total_count += (
            merged_right - merged_left + 1
        )

    def count(self) -> int:
        return self.total_count

# Your CountIntervals object will be instantiated and called as such:
# obj = CountIntervals()
# obj.add(left, right)
# param_2 = obj.count()
```该实现按间隔的起点排序存储间隔。 

这`bisect_left()`call 查找新间隔的插入位置。 由于重叠可能从前一个间隔开始，因此我们向后检查一步。 

合并循环吸收所有重叠的间隔。 每个移除的区间都会减去其覆盖的大小`total_count`。 

合并完成后，我们用一个合并间隔替换重叠的切片。 这使间隔列表保持排序且不重叠。 

因为`count()`只返回维护的总数，它以恒定的时间执行。 

## 解决方案```go
package main

import "sort"

type CountIntervals struct {
	intervals [][2]int
	total     int
}

func Constructor() CountIntervals {
	return CountIntervals{
		intervals: make([][2]int, 0),
		total:     0,
	}
}

func (this *CountIntervals) Add(left int, right int) {
	mergedLeft := left
	mergedRight := right

	index := sort.Search(
		len(this.intervals),
		func(i int) bool {
			return this.intervals[i][0] >= left
		},
	)

	if index > 0 &&
		this.intervals[index-1][1]+1 >= left {
		index--
	}

	removeStart := index

	for index < len(this.intervals) &&
		this.intervals[index][0] <= mergedRight+1 {

		current := this.intervals[index]
		currentLeft := current[0]
		currentRight := current[1]

		if currentLeft < mergedLeft {
			mergedLeft = currentLeft
		}

		if currentRight > mergedRight {
			mergedRight = currentRight
		}

		this.total -= (
			currentRight - currentLeft + 1
		)

		index++
	}

	newIntervals := make([][2]int, 0)

	newIntervals = append(
		newIntervals,
		this.intervals[:removeStart]...,
	)

	newIntervals = append(
		newIntervals,
		[2]int{mergedLeft, mergedRight},
	)

	newIntervals = append(
		newIntervals,
		this.intervals[index:]...,
	)

	this.intervals = newIntervals

	this.total += (
		mergedRight - mergedLeft + 1
	)
}

func (this *CountIntervals) Count() int {
	return this.total
}

/**
 * Your CountIntervals object will be instantiated and called as such:
 * obj := Constructor();
 * obj.Add(left, right);
 * param_2 := obj.Count();
 */
```Go 实现遵循与 Python 相同的逻辑。 

由于 Go 没有内置的二等分支持，我们使用`sort.Search()`用于二分查找。 

切片替换是通过构造一个包含以下内容的新切片来手动处理的：

 1. 重叠前的间隔
 2. 合并区间
 3. 剩余间隔

 Go 使用`int`，它可以安全地处理高达`10^9`标准 64 位环境下。

 ## 边缘情况

 ### 新区间完全包含在现有区间内

 假设我们已经有：```
[1,10]
```并添加：```
[3,5]
```即使没有引入新的整数，有缺陷的实现也可能会意外地增加计数。 

我们的实现正确检测重叠，合并到`[1,10]`，减去旧的贡献，并重新添加相同的间隔大小。 总数保持不变。 

### 新间隔连接多个现有间隔

 考虑：```
[1,2]
[5,6]
```然后添加：```
[3,5]
```新的间隔将之前单独的组桥接为：```
[1,6]
```不正确的实现可能只合并一侧。 我们的合并循环一直持续到所有重叠间隔都被吸收为止，确保完全正确。 

### 极大的范围

 间隔可以达到：```
[1, 10^9]
```由于时间和内存的使用，存储每个整数的简单实现会立即失败。 

我们基于间隔的表示仅存储边界，因此即使是最大的间隔也会使用恒定的附加内存并高效处理。 

### 相邻间隔

 由于间隔是包含在内的，因此这些间隔：```
[1,3]
[4,5]
```表示一个连续的整数范围。 

如果没有仔细的边界处理，实现可能会错误地将它们分开。 

我们的重叠检查使用`+1`，确保相邻间隔合并为：```
[1,5]
```正确。
