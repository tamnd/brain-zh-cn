 **难度：** 🟡 中等
 **主题：** 数组、贪心、设计

 ## 解决方案

 ## 问题理解

 这个问题要求我们设计一个 ATM 机的模拟，它可以处理存款和取款，并严格规定如何分配资金。 ATM 存储五种纸币：$20, $50、$100, $200 美元和 500 美元。 关键的挑战是实施提款逻辑，该逻辑优先考虑首先发放较大面额的金额。 

这`deposit`函数接收一个数组，表示要添加到 ATM 的每张钞票的数量，顺序为`[20, 50, 100, 200, 500]`。 这`withdraw`函数接收总金额，并且必须返回一个数组，其中包含将给出每种类型的纸币数量，或者`[-1]`如果使用优先级规则无法满足请求。 ATM 不得违反最大先行政策部分提取或重新排列纸币。 

限制条件表明 ATM 可以处理大量纸币（每种面额最多 10^9 张）和大额取款（最多 10^9 张）。 最多 5000 次操作，这表明循环五种面值的算法就足够了。 边缘情况包括尝试提取无法用可用纸币形成的金额、不存入纸币以及以面额组合提取确切的总额。 

## 方法

 ### 蛮力方法

 暴力方法将尝试生成所有可能的纸币组合，其总和等于取款金额，并首先选择面额最大的纸币。 虽然理论上是正确的，但这在计算上是不可行的，因为组合的数量随着纸币的数量呈指数增长。 即使只有五种面额，计数也可能高达 10^9，无法进行计数。 

### 最佳方法

 最佳方法利用贪婪算法：始终首先尝试使用最大面额。 从最高面额（$500）开始，在不超过提款金额的情况下尽可能多地取。 Continue down to the smallest denomination. 如果在任何时候可用票据无法支付剩余金额，请取消操作并返回`[-1]`。 这是可行的，因为该问题明确要求最大优先取款； 不允许重新排列。 

关键的见解是我们**不需要**需要检查所有组合； 最大优先规则确保每一步都有一个确定性选择。

 ## 算法演练

 1.初始化一个数组`banknotes`大小为 5，用于存储计数`[20, 50, 100, 200, 500]`。 
2. 对于`deposit(banknotesCount)`，迭代 5 个面额并将相应的计数添加到`banknotes`。 
3.为了`withdraw(amount)`：

 1.初始化临时数组`used`尺寸为 5 的纸币可用于跟踪使用了多少张纸币。 
2. 按**降序**迭代面额：$500, $200,$100, $50，20 美元。 
3. 对于每种面额，确定可以使用多少张纸币而不超过剩余的纸币数量`amount`。 计数是可用音符的最小值，并且`amount // denomination`。 
4. 减去所用纸币的总价值`amount`并记录所使用的号码`used`。 
5. 在所有宗派之后，如果`amount`为零，则通过减去来提交提款`used`从`banknotes`并返回`used`按原来的顺序`[20,50,100,200,500]`。 
6.如果`amount`不为零，返回`[-1]`并且不要修改`banknotes`。 

**为什么有效**：贪婪方法之所以有效，是因为该问题强制执行严格的最大优先规则。 如果与规则相冲突，则不允许使用其他组合，因此首先尝试较小的面额将违反要求。 通过从最大到最小迭代，我们正确地模拟了 ATM 行为。 

## Python 解决方案```python
from typing import List

class ATM:
    def __init__(self):
        self.banknotes = [0] * 5  # counts for 20,50,100,200,500
        self.denominations = [20, 50, 100, 200, 500]

    def deposit(self, banknotesCount: List[int]) -> None:
        for i in range(5):
            self.banknotes[i] += banknotesCount[i]

    def withdraw(self, amount: int) -> List[int]:
        used = [0] * 5
        remaining = amount
        for i in reversed(range(5)):
            count = min(self.banknotes[i], remaining // self.denominations[i])
            used[i] = count
            remaining -= count * self.denominations[i]

        if remaining == 0:
            for i in range(5):
                self.banknotes[i] -= used[i]
            return used
        return [-1]
```这`__init__`方法将 ATM 设置为空计数。 这`deposit`方法迭代每个面额并添加计数。 这`withdraw`方法使用贪心自上而下循环来确定每种类型可以使用多少个音符。 如果取款可行，则更新 ATM 的状态； 否则，`[-1]`被返回。 

## 解决方案```go
type ATM struct {
	banknotes    [5]int
	denominations [5]int
}

func Constructor() ATM {
	return ATM{denominations: [5]int{20, 50, 100, 200, 500}}
}

func (this *ATM) Deposit(banknotesCount []int) {
	for i := 0; i < 5; i++ {
		this.banknotes[i] += banknotesCount[i]
	}
}

func (this *ATM) Withdraw(amount int) []int {
	used := [5]int{}
	remaining := amount
	for i := 4; i >= 0; i-- {
		count := remaining / this.denominations[i]
		if count > this.banknotes[i] {
			count = this.banknotes[i]
		}
		used[i] = count
		remaining -= count * this.denominations[i]
	}

	if remaining == 0 {
		for i := 0; i < 5; i++ {
			this.banknotes[i] -= used[i]
		}
		return used[:]
	}
	return []int{-1}
}
```Go 特定的细节包括使用固定大小的数组`banknotes`和`denominations`和切片`used`回来时。 算术运算很简单，因为在大多数平台上，Go 中的整数默认为 64 位，足以满足约束条件。
