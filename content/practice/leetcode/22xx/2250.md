 **难度：** 🟡 中等
 **主题：** 数组、哈希表、二分搜索、二叉索引树、排序

 ## 解决方案

 这是 **LeetCode 2250 - 在单个综合响应中计算包含每个点的矩形数量** 的完整、详细的技术解决方案指南。 

## 问题理解

 该问题提供了两个数组：`rectangles`和`points`。 的每个元素`rectangles`是`[li, hi]`，表示一个矩形，其左下角位于`(0, 0)`和右上角`(li, hi)`。 的每个元素`points`是`[xj, yj]`，表示 2D 平面中的一个点。 目标是计算每个点包含有多少个矩形。 如果一个点位于矩形的内部或边缘上，则该点被视为在矩形内部，这意味着`0 <= xj <= li`和`0 <= yj <= hi`。 

输入约束很重要：最多`5 * 10^4`矩形和点，矩形宽度和点 x 坐标最多`10^9`，矩形高度和点 y 坐标最大为`100`。 小的最大高度（`hi <= 100`）建议通过按高度对矩形进行分组来进行优化。 矩形和点是唯一的，这避免了重复计数问题。 边缘情况包括正好位于矩形边缘上的点以及具有最小或最大允许尺寸的点或矩形。 

预期输出是一个整数数组，其中每个元素对应于中的一个点`points`并表示包含该点的矩形的数量。 

## 方法

 ### 蛮力

 暴力方法迭代每个点的每个矩形，使用包含条件检查该点是否位于矩形内`0 <= xj <= li`和`0 <= yj <= hi`。 这是正确的但效率低下，因为它需要`O(N * M)`时间 地点`N = len(rectangles)`和`M = len(points)`。 With the upper bound of`5 * 10^4`对于这两个阵列，这种方法可能会导致多达 25 亿次操作，速度太慢。 

### 最佳方法

 关键的观察是矩形高度是有界的（`hi <= 100`）。 我们可以按高度对矩形进行分组，并对每个高度组的宽度进行排序。 那么对于给定点`(xj, yj)`, 仅高度`hi >= yj`是相关的。 对这些高度组中排序的宽度使用二分搜索，我们可以计算有多少个矩形`li >= xj`。 这显着降低了时间复杂度。 

该算法利用两种优化：高度分桶和排序宽度列表中的二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N * M) | O(1) | O(1) | 对每个点-矩形对进行简单的包含检查 |
 | 最佳| O(N + M * H * log N) | O(N + M * H * log N) | O(N + H) | H = 100，按高度分组，二分查找宽度 |

 ## 算法演练

 1. 初始化一个哈希图（或列表）`height_to_widths`其中每个键是一个矩形高度，值是具有该高度的矩形宽度的列表。 
2. 填充`height_to_widths`通过迭代`rectangles`并将每个矩形的宽度附加到相应的高度列表中。 
3. 按升序对每个宽度列表进行排序。 这允许稍后对宽度进行有效的二分搜索。 
4.初始化一个空列表`result`存储每个点的计数。 
5. 对于每个点`(xj, yj)`,初始化一个计数器`count = 0`。 
6. 迭代高度`yj`达到最大可能高度（`100`）。 对于每个高度：

 - 检索宽度的排序列表`widths`。 
- 使用二分查找查找第一个宽度的索引`>= xj`。 
- 添加从该索引到列表末尾的宽度数`count`。 
7. 追加`count`到`result`。 
8. 返回`result`。 

**为什么有效**：通过按高度对矩形进行分组并对宽度进行排序，我们可以有效地仅检查可能包含点的矩形。 二分查找确保我们计算宽度`>= xj`迅速地。 由于高度以 100 为界，因此可以接受迭代相关高度。 

## Python 解决方案```python
from typing import List
import bisect

class Solution:
    def countRectangles(self, rectangles: List[List[int]], points: List[List[int]]) -> List[int]:
        # Step 1: Group rectangles by height
        height_to_widths = [[] for _ in range(101)]  # Heights 1 to 100
        for li, hi in rectangles:
            height_to_widths[hi].append(li)
        
        # Step 2: Sort widths in each height group
        for h in range(1, 101):
            height_to_widths[h].sort()
        
        result = []
        
        # Step 3: For each point, count rectangles containing it
        for xj, yj in points:
            count = 0
            for h in range(yj, 101):
                widths = height_to_widths[h]
                # Binary search for first width >= xj
                idx = bisect.bisect_left(widths, xj)
                count += len(widths) - idx
            result.append(count)
        
        return result
```**说明**：我们创建一个列表列表，以按矩形宽度的高度对矩形进行分组。 对每个列表进行排序可以实现快速二分搜索。 对于每个点，我们迭代所有高度`>= yj`并计算宽度的矩形`li >= xj`。`bisect_left`返回第一个索引，其中`width >= xj`， 所以`len(widths) - idx`给出在该高度包含该点的矩形的数量.

 ## 解决方案```go
import (
    "sort"
)

func countRectangles(rectangles [][]int, points [][]int) []int {
    // Step 1: Group rectangles by height
    heightToWidths := make([][]int, 101) // Heights 1 to 100
    for _, rect := range rectangles {
        li, hi := rect[0], rect[1]
        heightToWidths[hi] = append(heightToWidths[hi], li)
    }

    // Step 2: Sort widths in each height group
    for h := 1; h <= 100; h++ {
        sort.Ints(heightToWidths[h])
    }

    result := make([]int, len(points))

    // Step 3: For each point, count rectangles containing it
    for i, pt := range points {
        xj, yj := pt[0], pt[1]
        count := 0
        for h := yj; h <= 100; h++ {
            widths := heightToWidths[h]
            idx := sort.Search(len(widths), func(j int) bool {
                return widths[j] >= xj
            })
            count += len(widths) - idx
        }
        result[i] = count
    }
    
    return result
}
```**说明**：Go 需要显式的切片处理和使用`sort.Search`用于二分查找。 否则，逻辑与 Python 类似。 Nil 切片的行为就像空切片，因此我们不需要额外的检查。 排序允许二分搜索，并且高度迭代可以保证对所有相关矩形进行计数。
