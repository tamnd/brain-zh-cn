 ## 解决方案

 ## 问题理解

 该问题需要确定给定鲍勃收到的一系列数字按键，爱丽丝可能发送了多少条文本消息。 每个数字从`'2'`到`'9'`maps to a set of letters on a phone keypad. 多次按某个键会选择该键上的不同字母。 例如，按`'2'`一旦给`'a'`, 两次给出`'b'`，三次给出`'c'`。 数字`'7'`和`'9'`很特别，因为它们映射到四个字母而不是三个。 数字`'0'`和`'1'`不映射到任何字母，也不包含在输入中。 

输入是一个字符串`pressedKeys`仅包含数字`'2'`到`'9'`长度可达100,000。 输出是 Alice 可以发送的有效短信总数，模数$10^9 + 7$。 

主要挑战是组合的数量可能呈指数级增长，因为连续的相同数字可能对应于多个字母。 尝试生成所有可能序列的简单方法无法适应大输入。 我们必须考虑重复数字的序列以及每个键允许的最大连续按下次数（数字为 3 次）`'2'`,`'3'`,`'4'`,`'5'`,`'6'`,`'8'`和四个`'7'`和`'9'`）。 

重要的边缘情况包括具有单个数字的字符串、具有长重复数字序列的字符串以及包含数字的序列`'7'`或者`'9'`有四种可能的压力机。 

## 方法

 暴力方法将通过尝试与重复数字序列相对应的每种字母组合来递归地生成所有可能的文本消息。 例如，如果输入是`"222"`，它可以对应于`"aaa"`,`"ab"`,`"ba"`,`"c"`等。虽然正确，但这种方法效率极低，因为可能性的数量随着长度的增加而呈指数增长。`pressedKeys`。 对于最大输入长度100,000，此方法不可行。 

最佳方法使用动态规划。 关键的见解是，对于字符串中的每个位置，以该位置结束的有效消息的数量仅取决于前几个位置，并受到该数字允许的最大连续按下次数的限制。 这使我们能够迭代计算答案，而无需显式生成所有序列。 具体来说，对于长度为每个数字序列`n`，我们考虑使用 1 来形成消息的方法总和`maxPresses`相同的数字，其中`maxPresses`对于大多数数字是 3，对于大多数数字是 4`'7'`和`'9'`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(3^n) 到 O(4^n) | O(n) | 递归生成所有可能的序列； 对于大的来说不可行`n`|
 | 最佳| O(n) | O(n) | 使用动态规划； 根据数字 | 最多考虑 3 或 4 个先前状态

 ## 算法演练

 1. 初始化一个`dp`长度数组`n + 1`， 在哪里`dp[i]`存储第一条可能的消息数`i`人物。 放`dp[0] = 1`因为空字符串有一种有效的解释。 
2. 遍历字符串`i = 1`到`n`。 
3. 对于每个位置`i`, 初始化`dp[i] = 0`。 
4. 确定当前数字允许的最大按键次数：`maxPresses = 4`如果数字是`'7'`或者`'9'`， 否则`maxPresses = 3`。 
5. 对于`k`从 1 到`maxPresses`，检查最后是否`k`字符是相同的。 如果是这样，请添加`dp[i - k]`到`dp[i]`。 
6. 应用模数$10^9 + 7$在每一步中防止整数溢出。 
7.处理完所有字符后，返回`dp[n]`。 

**为什么有效**：动态规划递归可确保在给定位置结束的所有有效序列都被精确计数一次。 该算法考虑了连续相同数字的所有可能的段长度，这保证了每个有效组合都被包括在内，没有冗余。 限制`k`到`maxPresses`确保我们永远不会计算不可能的字母序列。 

## Python 解决方案```python
class Solution:
    def countTexts(self, pressedKeys: str) -> int:
        MOD = 10**9 + 7
        n = len(pressedKeys)
        dp = [0] * (n + 1)
        dp[0] = 1

        for i in range(1, n + 1):
            dp[i] = 0
            maxPresses = 4 if pressedKeys[i - 1] in '79' else 3
            for k in range(1, maxPresses + 1):
                if i - k >= 0 and all(pressedKeys[i - j - 1] == pressedKeys[i - 1] for j in range(k)):
                    dp[i] = (dp[i] + dp[i - k]) % MOD

        return dp[n]
```Python 实现初始化一个 DP 数组来存储直到每个索引的有效消息的数量。 对于每个字符，它会考虑可以形成有效字母的连续相同数字的数量。 通过总结前面的`dp`值不超过允许值`maxPresses`，它有效地计算所有有效组合。 模运算确保大量数字仍然易于管理。 

## 解决方案```go
func countTexts(pressedKeys string) int {
    const MOD int = 1e9 + 7
    n := len(pressedKeys)
    dp := make([]int, n+1)
    dp[0] = 1

    for i := 1; i <= n; i++ {
        dp[i] = 0
        maxPresses := 3
        if pressedKeys[i-1] == '7' || pressedKeys[i-1] == '9' {
            maxPresses = 4
        }
        for k := 1; k <= maxPresses; k++ {
            if i-k >= 0 {
                valid := true
                for j := 0; j < k; j++ {
                    if pressedKeys[i-j-1] != pressedKeys[i-1] {
                        valid = false
                        break
                    }
                }
                if valid {
                    dp[i] = (dp[i] + dp[i-k]) % MOD
                }
            }
        }
    }

    return dp[n]
}
```在 Go 中，切片取代了 Python 列表，并且我们显式检查相同数字的序列。 使用模运算处理整数溢出。 其他方面的逻辑与 Python 版本相同。
