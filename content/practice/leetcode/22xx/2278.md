[LeetCode 问题 2278](https://leetcode.com/problems/percentage-of-letter-in-string/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算给定字符的百分比，`letter`，在一个字符串中`s`，并将其返回为向下舍入到最接近的整数百分比的整数。 本质上，我们需要确定字符出现的次数，除以字符总数，乘以 100，然后向下舍入。 

输入`s`是一个仅包含小写英文字母的非空字符串，并且`letter`是单个小写英文字母。 约束告诉我们字符串长度很小（最多 100），因此简单的计数方法是可行的。 

重要的边缘情况包括该字母未出现在字符串中（结果应为 0）、该字母每次出现时（结果应为 100）以及除法产生非整数百分比时（向下舍入）。 

## 方法

 暴力方法很简单：迭代字符串的每个字符，计算它匹配的次数`letter`，然后通过将计数除以字符串长度并乘以 100 来计算百分比。考虑到输入大小较小，这是正确且足够高效的，但它也足够简单，可以被认为是最佳的。 

最佳解决方案的关键在于我们只需要一次遍历字符串即可计算出现次数。 不需要额外的数据结构或复杂的操作。 百分比计算可以使用整数除法自动向下舍入来完成。

 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 迭代字符串以计算出现次数 |
 | 最佳| O(n) | O(1) | O(1) | 单次通过直接百分比计算 |

 ## 算法演练

 1. 初始化变量`count`为 0 来存储次数`letter`出现在`s`。 
2. 迭代每个字符`c`在`s`。 
3. 对于每个字符，检查是否`c == letter`。 如果是，则增加`count`。 
4.迭代结束后，除以计算百分比`count`除以字符串的总长度并乘以 100。使用整数除法自动向下舍入。 
5. 返回计算出的百分比作为结果。 

为什么有效：该算法之所以有效，是因为它准确地计算目标字母的所有出现次数，并使用整数算术强制向下舍入。 由于每个字符都被检查一次，并且我们最后只执行一次除法，因此保证结果是正确的。 

## Python 解决方案```python
class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:
        count = 0
        for c in s:
            if c == letter:
                count += 1
        return (count * 100) // len(s)
```该代码初始化一个计数器并迭代该字符串。 每次角色匹配时`letter`，计数器递增。 完成循环后，我们将计数乘以 100，并使用整数除以字符串的长度来计算向下舍入的百分比。 这直接遵循算法演练。 

## 解决方案```go
func percentageLetter(s string, letter byte) int {
    count := 0
    for i := 0; i < len(s); i++ {
        if s[i] == letter {
            count++
        }
    }
    return (count * 100) / len(s)
}
```在 Go 中，字符串按字节索引，因此我们迭代索引并将每个字符与`letter`。 百分比计算使用整数除法向下舍入，就像在 Python 中一样。 由于 Go 没有针对此问题的类结构，因此我们将其实现为一个简单的函数。

 ## 边缘情况

 一种重要的边缘情况是字符串仅包含目标字母。 这可能会导致百分比计算中出现相差一的错误，但整数除法可以正确处理它，给出 100%。 

另一种边缘情况是目标字母根本不出现。 不检查零除法的简单实现可能会失败，但由于我们除以字符串长度而不是计数，因此这种情况会正确返回 0。 

最后，考虑非常短的字符串，例如长度 1。实现通过计数和执行整数除法自然地处理这个问题。 例如，如果单个字符匹配，则百分比为 100，如果不匹配，则百分比为 0。这确保了最小输入大小的正确性。
