 **难度：** 🟡 中等
 **主题：** 数组、贪心

 ## 解决方案

 ## 问题理解

 该问题提出了一个顺序博弈，包括`n`等级，每个等级都会对玩家造成特定数量的伤害。 给你一个清单`damage`在哪里`damage[i]`代表等级伤害`i`。 此外，玩家还有一个`armor`可以使用**一次**的能力，减少单级伤害最多可达护甲值。 

目标是确定所需的**最低初始生命值**，以便玩家能够按顺序生存通过所有级别，并在每一步中严格保持健康值。 因此，输出是表示此最小健康状况的单个整数。 

来自约束和问题陈述的重要观察结果包括：

 - 级别数量`n`可以大到`10^5`，因此任何二次解或涉及检查所有可能序列的解都是不可行的。 
- 伤害值和护甲可以为零。 一个等级可能会造成零伤害，或者护甲可能不会提供任何减少。 
- 理想情况下，盔甲应该在**最大伤害**的水平上使用，因为在其他地方使用它不会最小化总起始生命值。 这是简化问题的关键见解。 
- 生命值必须严格保持为正值，因此即使在用护甲减少了一个等级的伤害后，最终也至少需要 1 点生命值。 

需要考虑的边缘情况包括：

 - 所有伤害值均为零，具有任何护甲值。 玩家只需要 1 点生命值。 
- 护甲为零，这意味着玩家只需承受所有伤害。 
- 只有一层存在，装甲可能会完全吸收它。 

## 方法

 ### 蛮力

 蛮力方法将尝试每一个可能的级别来应用装甲。 对于每个关卡，从头到尾模拟游戏，在该关卡上应用护甲，并计算在所有关卡中生存所需的起始生命值。 最后，在所有模拟中选择最小的起始健康状况。 

虽然这种方法是正确的，但效率很低，因为对于每个级别，您都必须迭代所有级别`n`级别来计算累积健康状况，时间复杂度为`O(n^2)`。 和`n`最多`10^5`, this is far too slow.

 ### 最佳方法

 关键的观察是**护甲应应用于具有最大伤害的级别**。 通过减少最大的单一伤害，您可以最大限度地减少健康损失的总和。 Therefore, the optimal starting health is simply the sum of all damage minus the reduction from armor, plus 1 to ensure strictly positive health at the end.

 形式上，该算法是：

 1. 计算所有损坏值的总和。 
2. 求最大伤害值。 
3. Calculate`min_health = total_damage - min(max_damage, armor) + 1`。 

这种方法非常高效，单次运行，并且适用于所有输入大小。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 模拟每个级别的盔甲游戏 |
 | 最佳| O(n) | O(1) | O(1) | 伤害总和减去护甲的最佳用途 |

 ## 算法演练

 1. 初始化`total_damage`到 0 和`max_damage`至 0。 
2. 遍历每个级别`damage`大批。 
3. 对于每个级别，添加`damage[i]`到`total_damage`。 
4. 更新`max_damage`如果`damage[i]`大于当前`max_damage`。 
5. 迭代后，计算护甲减少量的最小值`armor`和`max_damage`。 
6. 计算最小起始健康状况为`total_damage - reduction + 1`。 
7. 返回计算出的最小生命值。 

**为什么有效：** 不变的是，将护甲应用到伤害最高的级别可以最大化护甲的好处。 如果不使用护甲，将所有伤害相加即可计算出所有生命损失，并减去护甲减少量可确保我们以最佳方式减少生命损失。 加 1 可保证健康状况永远不会降至零。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumHealth(self, damage: List[int], armor: int) -> int:
        total_damage = 0
        max_damage = 0
        
        for d in damage:
            total_damage += d
            max_damage = max(max_damage, d)
        
        reduction = min(max_damage, armor)
        min_health = total_damage - reduction + 1
        
        return min_health
```实现迭代通过`damage`一次，记录累积伤害和最大伤害。 循环结束后，它会应用护甲的最佳使用方式，并确保最后至少保留 1 点生命值。 

## 解决方案```go
func minimumHealth(damage []int, armor int) int64 {
    var totalDamage int64 = 0
    var maxDamage int = 0

    for _, d := range damage {
        totalDamage += int64(d)
        if d > maxDamage {
            maxDamage = d
        }
    }

    reduction := maxDamage
    if armor < maxDamage {
        reduction = armor
    }

    return totalDamage - int64(reduction) + 1
}
```在 Go 中，我们使用`int64`为了`totalDamage`以避免整数溢出，因为`n`和`damage[i]`可以达到`10^5`。 其余逻辑反映了 Python 解决方案，迭代一次并计算归约。

 ## 边缘情况

 **边缘情况 1：护甲为零**

 如果`armor = 0`，该算法自然会减少到对所有伤害求和并加 1，这是正确的，因为装甲没有提供任何好处。 这可以防止负减少或误算。 

**边缘情况 2：单级游戏**

 与`n = 1`，算法正确识别装甲是否能完全吸收单次伤害。 这`min(max_damage, armor)`确保正确的计算。 

**边缘情况 3：全零损坏**

 如果每个级别都有`damage[i] = 0`，算法返回`1`作为最低起始生命值。 这可以确保即使没有受到伤害，健康状况仍然保持良好，满足游戏要求。
