 **难度：** 🟡 中等
 **主题：** 数组、哈希表、数学、几何、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们确定有多少格点位于二维网格上的一组圆中的至少一个内。 每个圆由一个三元组表示`[xi, yi, ri]`， 在哪里`(xi, yi)`是圆的中心并且`ri`是它的半径。 格点是网格上具有整数坐标的任意点`(x, y)`。 恰好位于圆圆周上的点被视为在圆内。 

鉴于`1 <= xi, yi <= 100`和`1 <= ri <= min(xi, yi)`，所有圆都被限制在第一象限网格内`(1, 1)`到`(100, 100)`。 最多有 200 个圆圈，因此对于尺寸高达 100 x 100 的网格，总计算必须保持高效。 

边缘情况包括半径为1的圆（单点覆盖）、重叠圆、靠近网格边界的圆以及具有相同圆心的多个圆。 简单的方法必须仔细考虑重叠的格点以避免重复计算。 

## 方法

 蛮力方法将迭代网格中的每个点（从`(0,0)`到`(100,100)`）并检查每个点是否位于任意圆内。 这保证了正确性，因为它明确地检查所有可能的格点。 然而，它可能效率低下，因为对于每个点，它都会迭代所有圆圈，从而导致`O(100^2 * n)`时间复杂度可以接受，但不是最优的。 

更优化的观察是半径为 1 的圆内的格点数量`r`仅限于边界正方形`[x-r, x+r] x [y-r, y+r]`。 我们只迭代每个圆的边界框，而不是检查整个网格中的每个点。 当圆重叠时，使用集合来存储发现的晶格点会自动处理重复项。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(100 * 100 * n) | O(1) | O(1) | 检查每个圆的每个网格点 |
 | 最佳| O(n * r^2) | O(n * r^2) | O(格点数) | 仅迭代每个圆的边界框并将点存储在集合中 |

 ## 算法演练

 1.初始化一个空集来存储唯一的格点。 
2. 对于每个圆`[cx, cy, r]`在输入列表中，计算可能格点的边界框为`[cx-r, cx+r]`对于 x 和`[cy-r, cy+r]`对于 y。 
3. 迭代所有整数坐标`(x, y)`在这个边界框中。 
4. 对于每个`(x, y)`，使用欧氏距离平方检查它是否位于圆内部或圆上：`(x - cx)^2 + (y - cy)^2 <= r^2`。 
5. 如果该点满足条件，则将其添加到集合中。 
6. 处理完所有圆之后，格点的数量就是集合的大小。 

工作原理：该集合确保重叠点仅计算一次。 检查每个圆的边界框可以减少不必要的计算，同时确保不会错过圆内的格点。 

## Python 解决方案```python
from typing import List

class Solution:
    def countLatticePoints(self, circles: List[List[int]]) -> int:
        lattice_points = set()
        
        for cx, cy, r in circles:
            for x in range(cx - r, cx + r + 1):
                for y in range(cy - r, cy + r + 1):
                    if (x - cx) ** 2 + (y - cy) ** 2 <= r ** 2:
                        lattice_points.add((x, y))
        
        return len(lattice_points)
```实现首先创建一个集合`lattice_points`存储所有独特点。 对于每个圆，我们仅迭代位于其边界正方形内的点。 平方欧几里德距离避免了浮点运算并确保了精确的检查。 该集合自然地避免了对重叠圆圈中的重复项进行计数。 

## 解决方案```go
func countLatticePoints(circles [][]int) int {
    latticePoints := make(map[[2]int]struct{})
    
    for _, circle := range circles {
        cx, cy, r := circle[0], circle[1], circle[2]
        for x := cx - r; x <= cx + r; x++ {
            for y := cy - r; y <= cy + r; y++ {
                dx := x - cx
                dy := y - cy
                if dx*dx + dy*dy <= r*r {
                    latticePoints[[2]int{x, y}] = struct{}{}
                }
            }
        }
    }
    
    return len(latticePoints)
}
```Go 实现使用带有键的映射：`[2]int`数组来模拟集合。 圆内的每个点都作为关键点添加。 由于地图的关键唯一性属性，重复点将被自动忽略。

 ## 边缘情况

 **1. 网格边界处的圆圈**

 中心附近的圆`(1,1)`或者`(100,100)`可能有部分位于网格之外的边界框。 该算法可以正常工作，因为有效网格之外的格点只是简单地进行计数，但不会影响正确性，因为负或大坐标仍然是有效整数。 

**2. 重叠的圆圈**

 多个圆圈覆盖的点仅计算一次。 使用集合或映射可以保证唯一性，防止重复计算。 

**3. 大半径圆**

 对于半径接近网格尺寸的圆，边界框会变大。 迭代`(2r+1)^2`点仍然可行，因为`r <= 100`每圈的总点数永远不会超过 10000。 使用距离检查可确保仅计算真正位于内部的点，从而避免高估。 

该解决方案可以有效、正确地处理所有边缘情况。
