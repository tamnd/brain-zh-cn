[LeetCode 问题 2261](https://leetcode.com/problems/k-divisible-elements-subarrays/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、Trie、滚动哈希、哈希函数、枚举

 ## 解决方案

 ## 问题理解

 该问题需要计算给定整数数组的**不同子数组**的数量`nums`满足特定约束：每个子数组最多可以包含**`k`元素可被整除`p`**。 子数组是数组的连续切片，“不同”意味着长度不同或至少一个元素不同。 

例如，考虑`nums = [2,3,3,2,2]`,`k = 2`， 和`p = 2`。 这里，元素可被`p`是`2`（索引 0、3、4）。 任何包含超过 2 个可被整除的元素的子数组`2`无效。 任务是枚举满足此标准的所有**唯一子数组**。 即使`[2,3]`在数组中出现多次，只计算一次。 

约束告诉我们数组很小（`1 <= nums.length <= 200`），意味着$O(n^2)$解决方案是可行的，但暴力方法可能仍然需要仔细优化，以避免低效地计算重复项。 关键边缘情况包括所有元素均可整除的数组`p`、没有可整除元素的数组、有重复数字的数组以及以下情况`k`等于`n`或者非常小（如 1）。 

## 方法

 **暴力方法**很简单：生成所有可能的子数组，计算可整除的元素`p`并将它们存储在哈希集中以确保唯一性。 这是正确的但效率低下，因为子数组的数量是$O(n^2)$，并且比较数组的唯一性会增加开销，导致$O(n^3)$如果没有优化的话时间。 

**最佳方法**使用我们可以以滑动窗口方式生成子数组的观察结果，即时计算可整除的元素。 我们维护一个表示子数组的**元组哈希集**，以有效避免重复。 一旦可除计数超过，就停止子数组的扩展`k`，我们修剪不必要的计算。 这减少了有效操作$O(n^2)$因为每个子数组最多检查一次，并且 Python 或 Go 哈希集可以有效地处理唯一性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 生成所有子数组，计数可整除的数，存储在数组集中 |
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 滑动窗口+提前停止+哈希集唯一性|

 ## 算法演练

 1. 初始化一个空的**哈希集**来存储唯一的子数组。 
2. 迭代每个起始索引`i`的`nums`。 
3.对于每个起始索引，初始化一个计数器`count_div`跟踪可被整除的元素数量`p`。 
4. 迭代每个结束索引`j`开始于`i`到数组的末尾。 
5. 对于每个`nums[j]`, 增量`count_div`如果`nums[j] % p == 0`。 
6. 如果`count_div > k`，打破内部循环，因为从此开始的任何更长的子数组也将超过`k`。 
7. 否则，**添加元组`nums[i:j+1]`到哈希集**以确保不同的子数组。 
8. 处理完所有子数组后，返回**哈希集的大小**，表示不同的有效子数组的数量。 

**为什么有效：** 该算法生成所有有效的连续子数组，并且使用哈希集可确保忽略重复项。 提前终止可以避免对无法满足条件的子数组进行不必要的迭代。 

## Python 解决方案```python
from typing import List

class Solution:
    def countDistinct(self, nums: List[int], k: int, p: int) -> int:
        seen = set()
        n = len(nums)
        for i in range(n):
            count_div = 0
            subarray = []
            for j in range(i, n):
                if nums[j] % p == 0:
                    count_div += 1
                if count_div > k:
                    break
                subarray.append(nums[j])
                seen.add(tuple(subarray))
        return len(seen)
```Python 实现迭代所有起始索引，维护可整除元素的计数，并增量构建子数组。 这`tuple(subarray)`确保集合中的可散列存储。 提前中断可以防止超出限制的子数组被考虑。 

## 解决方案```go
func countDistinct(nums []int, k int, p int) int {
    seen := make(map[string]struct{})
    n := len(nums)

    for i := 0; i < n; i++ {
        countDiv := 0
        subarray := []int{}
        for j := i; j < n; j++ {
            if nums[j]%p == 0 {
                countDiv++
            }
            if countDiv > k {
                break
            }
            subarray = append(subarray, nums[j])
            key := fmt.Sprint(subarray)
            seen[key] = struct{}{}
        }
    }
    return len(seen)
}
```在 Go 中，我们使用带有字符串键的映射来模拟集合。`fmt.Sprint(subarray)`将切片转换为字符串以进行可哈希存储。 这可以正确处理重复项，同时保持`O(n^2)`时间复杂度。
