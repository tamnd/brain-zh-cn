 ## 解决方案

 ## 问题理解

 这个问题要求我们实现一个`Encrypter`可以根据自定义字符映射加密和解密字符串的类。 这`keys`array 提供可以加密的字符，以及`values`提供每个键映射到的相应 2 字符字符串。 字符串的加密非常简单：每个字符都被其对应的 2 个字符的字符串替换。 解密更具挑战性，因为多个字符可以映射到同一个加密字符串，这意味着单个加密字符串可以对应于多个原始字符串。 仅给定中存在解密的字符串`dictionary`算作有效。 

输入约束保证`keys`具有独特的性格和`values`都是 2 个字符的字符串。`dictionary`仅包含唯一字符串，可用于过滤有效的解密结果。 最大长度是合理的（密钥≤26，字典≤100，字长≤2000），因此我们需要一种有效的方法来计算所有有效的解密字符串，但加密和解密的调用总数很少（≤200）。 

重要的边缘情况包括具有冲突的加密字符串（其中多个字符映射到相同的加密值）、所有字符都在`keys`，以及由于缺少某些字符而无法加密的字符串`keys`。 另一个微妙之处是解密必须仅检查有效的字典单词，而不是所有可能的字符组合。 

## 方法

 暴力方法将尝试通过递归尝试映射到每个 2 字符段的每个可能的字符来为给定的加密字符串生成所有可能的解密字符串。 生成所有可能性后，它会计算字典中有多少个。 这是可行的，但计算成本很高，因为可能性的数量随着字符串的长度呈指数增长，特别是如果多个字符映射到相同的加密值。 

最佳方法利用字典的小尺寸，并预先计算从加密字符串到字典中的计数的映射。 我们对字典中的每个单词加密一次并存储其加密形式的频率。 然后，在解密时，我们不是探索所有可能的原始字符串，而是简单地查找字典中有多少单词可以产生给定的加密字符串。 这将加密字符串长度的解密从指数减少到线性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) 解密最坏情况 | O(2^n) | O(2^n) | 递归生成所有可能的解密，对于长字符串来说很慢 |
 | 最佳| O(D * L + N) | O(D) | 预计算加密字典； D = 字典大小，L = 平均单词长度，N = word2 长度 |

 ## 算法演练

 1. 初始化`Encrypter`具有三个输入的类：`keys`,`values`， 和`dictionary`。 
2. 建立直接`encryption_map`从每个角色`keys`到其相应的 2 个字符值`values`。 
3. 构建反向`decryption_map`来自中的每个 2 个字符的字符串`values`到可以产生它的字符列表。 这是必要的，因为多个密钥可以映射到相同的加密值。 
4. 预计算`encrypted_dict_count`通过加密中的每个单词`dictionary`使用`encryption_map`并计算每个加密结果的频率。 这允许快速解密查询。 
5. 对于`encrypt`方法，迭代输入字符串的每个字符。 如果该字符存在于`encryption_map`，附加其映射值； 否则，返回一个空字符串。 
6. 对于`decrypt`方法，只需返回加密字符串的计数`encrypted_dict_count`。 如果不存在，则返回 0。 
7、核心思想是加密是确定性的、快速的，而解密则简化为字典查找，避免指数枚举。 

为什么有效：通过预先计算字典单词的所有可能的加密形式，我们保证`decrypt`仅计算有效的字典单词。 即使多个字符映射到同一加密字符串，这也能确保正确性，因为所有冲突都已在预计算中考虑在内。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Encrypter:

    def __init__(self, keys: List[str], values: List[str], dictionary: List[str]):
        self.encryption_map = {k: v for k, v in zip(keys, values)}
        self.decryption_map = defaultdict(list)
        for k, v in zip(keys, values):
            self.decryption_map[v].append(k)
        self.encrypted_dict_count = defaultdict(int)
        for word in dictionary:
            encrypted_word = self.encrypt(word)
            if encrypted_word:
                self.encrypted_dict_count[encrypted_word] += 1

    def encrypt(self, word1: str) -> str:
        result = []
        for ch in word1:
            if ch not in self.encryption_map:
                return ""
            result.append(self.encryption_map[ch])
        return "".join(result)

    def decrypt(self, word2: str) -> int:
        return self.encrypted_dict_count.get(word2, 0)
```此实现使用简单的哈希映射进行加密。 预先计算字典单词的加密形式允许`decrypt`以相对于调用次数恒定的时间运行，只需支付一次预付费用。 

## 解决方案```go
package main

type Encrypter struct {
    encryptionMap    map[byte]string
    encryptedDictMap map[string]int
}

func Constructor(keys []byte, values []string, dictionary []string) Encrypter {
    em := make(map[byte]string)
    for i, k := range keys {
        em[k] = values[i]
    }

    edm := make(map[string]int)
    for _, word := range dictionary {
        encrypted := ""
        valid := true
        for i := 0; i < len(word); i++ {
            if val, ok := em[word[i]]; ok {
                encrypted += val
            } else {
                valid = false
                break
            }
        }
        if valid {
            edm[encrypted]++
        }
    }

    return Encrypter{
        encryptionMap:    em,
        encryptedDictMap: edm,
    }
}

func (this *Encrypter) Encrypt(word1 string) string {
    res := ""
    for i := 0; i < len(word1); i++ {
        val, ok := this.encryptionMap[word1[i]]
        if !ok {
            return ""
        }
        res += val
    }
    return res
}

func (this *Encrypter) Decrypt(word2 string) int {
    return this.encryptedDictMap[word2]
}
```Go 特定注释：Go 使用`map[byte]string`用于加密和`map[string]int`用于存储计数。 字符串连接与`+=`对于小字符串是可以接受的； 对于较长的字符串，`strings.Builder`可以优化内存分配。

 ## 边缘情况

 首先，当字符串中包含不存在的字符时`keys`,`encrypt`
