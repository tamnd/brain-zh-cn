[LeetCode 问题 2523](https://leetcode.com/problems/closest-prime-numbers-in-range/)

 **难度：** 🟡 中等
 **主题：** 数学、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们在给定的包含范围内找到两个素数`[left, right]`使得它们之间的差异尽可能小。 

更正式地说，我们需要返回两个整数`[num1, num2]`在哪里：

-`left <= num1 < num2 <= right`- 两个数字都是质数
 - 差距`num2 - num1`在所有有效素数对中最小化

 如果多个对具有相同的最小间隙，我们返回第一个数字较小的对。 由于我们自然地按升序扫描数字，因此我们遇到的第一个最小间隙对自动满足此要求。 

输入由两个整数组成：

 -`left`，范围的下限
 -`right`，范围的上限

 The output is:

 - 包含最接近的素数对的二元素数组
 -`[-1, -1]`如果范围内存在少于两个素数

 约束条件很重要：

 -`1 <= left <= right <= 10^6`对于使用朴素试除法对每个数字进行重复昂贵的素性测试来说，高达一百万的范围太大了。 我们需要一种更有效的方法来生成素数。 

一些边缘情况很重要：

 - 例如，该范围可能包含少于两个素数`[4, 6]`- 范围可能从第一个素数以下开始，例如`[1, 10]`- 多个素数对可能具有相同的最小间隙
 - 可能存在连续的孪生素数，从而产生尽可能小的间隙`2`- 范围可能很大，需要高效的预处理

 该问题保证有效的整数界限并且`left <= right`。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是迭代范围内的每个数字，并使用试除法测试它是否是素数。 

对于每个数字`x`，我们检查整除性`2`通过`sqrt(x)`。 如果不存在除数，则该数是素数。 收集该范围内的所有素数后，我们扫描相邻对并计算它们的差异以找到最小间隙。 

这种方法是正确的，因为：

 1. 检查范围内的每个数字
 2.收集每个素数
 3. 检查每个相邻的素数对
 4. 相邻素数之间的最小差距必然是全局最小值

 然而，对于大范围来说，该解决方案变得昂贵。 在最坏的情况下，我们可能会对近百万个数字进行素性测试，每个数字最多需要`O(sqrt(n))`运营。 

### 最优方法，埃拉托斯特尼筛法

 关键的观察是我们需要连续范围内许多数字的素数信息。 我们可以预处理所有素数，而不是独立测试每个数字`right`使用埃拉托斯特尼筛法。 

筛子的工作原理是：

 1. 最初假设所有数字都是素数
 2. 迭代地将每个素数的倍数标记为合数
 3. 只留下真素数不标记

 这使我们能够确定每个数字的素性`10^6`在近线性时间内。 

一旦我们有了筛子：

 - 迭代`[left, right]`- 跟踪之前遇到的素数
 - 计算连续素数之间的间隙
 - 每当发现更小的差距时更新最佳答案

 由于连续素数之间的素数间隙被最小化，因此检查相邻素数就足够了。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((右 - 左 + 1) * sqrt(右)) | O(k) | 独立测试每个数字的素数 |
 | 最佳 | O(右对数对数右) | O（右）| 使用埃拉托色尼筛进行高效预处理 |

 这里，`k`是范围内的素数个数。 

## 算法演练

 ### 最优算法

 1. 创建布尔数组`is_prime`尺寸的`right + 1`。 

每个索引代表该数字是否是质数。 Initially, assume every number is prime except`0`和`1`。 
2. 运行埃拉托斯特尼筛法。 

开始于`2`。 对于仍标记为质数的每个数字，将其所有倍数标记为非质数。 

我们只需要迭代到`sqrt(right)`因为较大的合数已经有较小的因数。 
3. 初始化跟踪变量。 

维持：

-`previous_prime`，遇到的最后一个素数
 -`best_pair`，当前答案
 -`minimum_gap`，迄今为止发现的最小差异
 4. 迭代所有数字`left`到`right`。 

对于每个数字：

 - 如果不是素数，则跳过它
 - 否则：

 - 如果`previous_prime`存在，计算间隙
 - 比较差距`minimum_gap`- 如果差距较小则更新答案
 - 将当前素数存储为`previous_prime`5. 返回结果。 

如果没有找到有效的对，则返回`[-1, -1]`。 

### 为什么它有效

 埃拉托斯特尼筛法正确识别了直到`right`。 一旦素数已知，最小素数间隙必须出现在按排序顺序的两个连续素数之间。 任何不连续的对都必然有更大或相等的差异，因为它们之间有另一个素数。 因此，扫描相邻素数可以保证我们找到全局最小间隙对。 

## Python 解决方案```python
from typing import List

class Solution:
    def closestPrimes(self, left: int, right: int) -> List[int]:
        is_prime = [True] * (right + 1)

        if right >= 0:
            is_prime[0] = False
        if right >= 1:
            is_prime[1] = False

        limit = int(right ** 0.5)

        for num in range(2, limit + 1):
            if is_prime[num]:
                for multiple in range(num * num, right + 1, num):
                    is_prime[multiple] = False

        previous_prime = -1
        minimum_gap = float("inf")
        answer = [-1, -1]

        for num in range(left, right + 1):
            if not is_prime[num]:
                continue

            if previous_prime != -1:
                gap = num - previous_prime

                if gap < minimum_gap:
                    minimum_gap = gap
                    answer = [previous_prime, num]

            previous_prime = num

        return answer
```实现首先构建`is_prime`大批。 每个数字最初都被假定为素数。 我们立即标记`0`和`1`称为非素数，因为它们不满足素数的数学定义。 

接下来，筛选阶段开始。 对于每个素数`num`，我们标记所有从以下位置开始的倍数`num * num`作为复合材料。 开始于`num * num`是一种优化，因为较小的倍数已经由较小的素因数处理。 

预处理后，我们扫描目标范围`left`到`right`。 

变量`previous_prime`存储最近遇到的素数。 每当我们发现另一个素数时，我们都会计算两个连续素数之间的差。 

如果这个差异小于当前的最佳差距，我们就会更新答案。 

最后，如果不存在有效的对，则默认`[-1, -1]`被返回。 

## 解决方案```go
func closestPrimes(left int, right int) []int {
    isPrime := make([]bool, right+1)

    for i := 0; i <= right; i++ {
        isPrime[i] = true
    }

    if right >= 0 {
        isPrime[0] = false
    }

    if right >= 1 {
        isPrime[1] = false
    }

    for num := 2; num*num <= right; num++ {
        if isPrime[num] {
            for multiple := num * num; multiple <= right; multiple += num {
                isPrime[multiple] = false
            }
        }
    }

    previousPrime := -1
    minimumGap := int(^uint(0) >> 1)
    answer := []int{-1, -1}

    for num := left; num <= right; num++ {
        if !isPrime[num] {
            continue
        }

        if previousPrime != -1 {
            gap := num - previousPrime

            if gap < minimumGap {
                minimumGap = gap
                answer[0] = previousPrime
                answer[1] = num
            }
        }

        previousPrime = num
    }

    return answer
}
```Go 实现遵循与 Python 解决方案相同的算法结构。 

布尔切片用于筛数组。 由于 Go 没有为整数提供内置的无穷大常数，因此最大整数值是使用位操作计算的：```go
int(^uint(0) >> 1)
```切片用于返回值，因为 LeetCode 期望`[]int`。 

与 Python 不同，Go 需要显式初始化布尔切片`true`。

 ## 边缘情况

 ### 范围包含少于两个素数

 错误的常见来源是假设该范围内至少存在两个素数。 例如，`[4, 6]`仅包含素数`5`。 

该实现通过初始化答案来处理这个问题`[-1, -1]`并且只有在找到两个素数后才更新它。 

### 范围从 2 以下开始

 数字`0`和`1`不是素数，但粗心的实现有时会错误地将它们分类为素数。 

筛子明确标记：```
is_prime[0] = False
is_prime[1] = False
```这确保了诸如`[1, 10]`行为正确。 

### 多对共享相同的最小间隙

 该问题需要当多个对具有相同的间隙时返回具有较小第一个值的对。 

例如：```
[11, 13] and [17, 19]
```两者都有差距`2`。 

仅当发现严格较小的间隙时，实现才会更新答案：```
if gap < minimum_gap:
```这保留了遇到的第一个最小间隙对。 

### 范围内不存在素数

 有些区间根本不包含素数，例如`[14, 16]`。 

扫描永远不会更新答案，因此函数正确返回：```
[-1, -1]
```
