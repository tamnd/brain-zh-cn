[LeetCode 问题 2503](https://leetcode.com/problems/maximum-number-of-points-from-grid-queries/)

 **难度：** 🔴难
 **主题：** 数组、两个指针、广度优先搜索、并查找、排序、堆（优先级队列）、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们计算一系列查询可以在网格中收集的最大点数。 网格由一个表示`m x n`整数矩阵，其中每个单元格都有一个值。 对于每个查询值`q`，我们从左上角的单元格开始`(0,0)`并尝试在当前单元格的值**严格小于**的情况下移动到相邻单元格（上、下、左、右）`q`。 在这种情况下首次访问单元格时，我们会获得积分。 如果当前单元格的值等于或大于查询，我们就无法沿着该路径进一步移动。 

输入是：

 -`grid`： 一个`m x n`值介于之间的整数矩阵`1`和`10^6`。 
-`queries`：之间的整数数组`1`和`10^6`长度可达`10^4`。 

输出是一个整数数组，其中每个元素对应于相应查询可获得的最大点数。 

约束表明网格可以很大，最多`10^5`单元格，查询数量众多。 这使得每个查询的简单 BFS 不可行，因为它会产生以下的时间复杂度`O(k * m * n)`这太慢了。 

重要的边缘情况包括：

 1. 左上角的单元格大于或等于查询，产生零分。 
2. 网格中的所有单元格具有相同的值。 
3. 查询小于所有网格值或大于所有网格值。 

## 方法

 强力解决方案是为每个查询独立执行 BFS 或 DFS。 这种方法是正确的，因为它在查询的约束下探索所有可到达的单元格并计算点。 然而，随着高达`10^4`查询和`10^5`细胞，最坏情况的复杂性变成`O(k * m * n)`，这是令人望而却步的。 

最佳解决方案的关键见解是较小查询的点数始终是较大查询的点数的子集。 这表明了**全局遍历顺序**。 通过按值对单元格进行排序并使用**优先级队列或联合查找结构**，我们可以逐步将单元格标记为可达，并通过按升序处理它们来有效地回答所有查询。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 每个查询的强力 BFS | O(k * m * n) | O(m * n) | 每个查询独立地从左上角开始 BFS 或 DFS |
 | 最优排序增量 BFS | O(m * n + k * log k) | O(m * n + k * log k) | O(m * n) | 对查询和单元格进行排序，使用最小堆增量扩展可到达的单元格 |

 ## 算法演练

 1. 将网格扁平化为列表`(value, row, col)`元组并按值对它们进行排序。 
2. 对查询及其原始索引进行排序。 
3. 从左上角单元格开始初始化最小堆（优先级队列）`(0,0)`和一个访问集来跟踪已计数的单元格。 
4. 按升序迭代查询：

 a. 对于每个查询值`q`，扩展堆以包含值小于的所有可到达单元格`q`。 

b. 每个新访问的单元格都会增加一个点数计数器。 

c. 将总计数存储在结果数组中查询的原始索引处。 
5. 返回结果数组。 

**为什么有效：** 通过按排序顺序处理查询和单元格，每个单元格仅按值递增的顺序访问一次。 这保证了对于每个查询，我们严格计算查询值以下可访问的所有点，并且增量方法确保没有冗余计算。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def maxPoints(self, grid: List[List[int]], queries: List[int]) -> List[int]:
        m, n = len(grid), len(grid[0])
        cells = [(grid[i][j], i, j) for i in range(m) for j in range(n)]
        cells.sort()
        
        sorted_queries = sorted((q, i) for i, q in enumerate(queries))
        res = [0] * len(queries)
        
        visited = [[False]*n for _ in range(m)]
        heap = []
        count = 0
        
        if grid[0][0] < sorted_queries[-1][0]:
            heapq.heappush(heap, (grid[0][0], 0, 0))
            visited[0][0] = True
        
        directions = [(1,0), (-1,0), (0,1), (0,-1)]
        idx = 0  # Pointer in cells list
        
        for q, qi in sorted_queries:
            while idx < len(cells) and cells[idx][0] < q:
                val, i, j = cells[idx]
                if not visited[i][j]:
                    heapq.heappush(heap, (val, i, j))
                    visited[i][j] = True
                idx += 1
            
            while heap and heap[0][0] < q:
                val, i, j = heapq.heappop(heap)
                count += 1
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and not visited[ni][nj]:
                        heapq.heappush(heap, (grid[ni][nj], ni, nj))
                        visited[ni][nj] = True
            res[qi] = count
        
        return res
```Python 解决方案展平网格，对单元格和查询进行排序，并使用最小堆逐步扩展可到达的单元格。 这确保每个单元仅被考虑一次并且查询得到有效处理。 

## 解决方案```go
package main

import (
    "container/heap"
    "sort"
)

type Cell struct {
    val, r, c int
}

type PQ []Cell

func (pq PQ) Len() int { return len(pq) }
func (pq PQ) Less(i, j int) bool { return pq[i].val < pq[j].val }
func (pq PQ) Swap(i, j int) { pq[i], pq[j] = pq[j], pq[i] }
func (pq *PQ) Push(x interface{}) { *pq = append(*pq, x.(Cell)) }
func (pq *PQ) Pop() interface{} {
    old := *pq
    n := len(old)
    x := old[n-1]
    *pq = old[0 : n-1]
    return x
}

func maxPoints(grid [][]int, queries []int) []int {
    m, n := len(grid), len(grid[0])
    cells := make([]Cell, 0, m*n)
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            cells = append(cells, Cell{grid[i][j], i, j})
        }
    }
    sort.Slice(cells, func(i, j int) bool { return cells[i].val < cells[j].val })
    
    type Query struct {
        val, idx int
    }
    sortedQueries := make([]Query, len(queries))
    for i, q := range queries {
        sortedQueries[i] = Query{q, i}
    }
    sort.Slice(sortedQueries, func(i, j int) bool { return sortedQueries[i].val < sortedQueries[j].val })
    
    res := make([]int, len(queries))
    visited := make([][]bool, m)
    for i := range visited {
        visited[i] = make([]bool, n)
    }
    
    h := &PQ{}
    heap.Init(h)
    if grid[0][0] < sortedQueries[len(sortedQueries)-1].val {
        heap.Push(h, Cell{grid[0][0], 0, 0})
        visited[0][0] = true
    }
    
    directions := [][2]int{{1,0},{-1,0},{0,1},{0,-1}}
    count := 0
    idx := 0
    
    for _, q := range sortedQueries {
        for idx < len(cells) && cells[idx].val < q.val {
            c := cells[idx]
            if !visited[c.r][c.c] {
                heap.Push(h, c)
                visited[c.r][c.c] = true
            }
            idx++
        }
        for h.Len() > 0 && (*h)[0].val < q.val {
            c := heap.Pop(h).(Cell)
            count++
            for _, d := range directions {
                ni, nj := c.r + d[0], c.c + d[1]
                if ni >= 0 && ni < m && nj >= 0 && nj < n && !visited[ni][nj] {
                    heap.Push(h, Cell{grid[ni][nj], ni, nj})
                    visited[ni][nj] = true
                }
            }
        }
        res[q.idx] = count
    }
    
    return res
}
