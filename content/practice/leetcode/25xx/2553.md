[LeetCode 问题 2553](https://leetcode.com/problems/separate-the-digits-in-an-array/)

 **难度：** 🟢简单
 **主题：** 数组、模拟

 ## 解决方案

 ## 问题理解

 这个问题要求我们取一个正整数数组，`nums`，并将其转换为另一个数组，`answer`，其中每个元素`nums`按顺序分解为其组成数字。 关键要求是数字的顺序必须反映原始数字在数组中的顺序。 例如，如果数字是 10921，则数字应显示为`[1,0,9,2,1]`。 输入数组最多可以包含 1000 个整数，每个整数的值最多为 105，这意味着数字不超过 6 位。 输出应该是包含所有数字的单个扁平列表。 

该问题保证了`nums`是非空的并且所有值都是正整数。 边缘情况包括只有一位数的数字、具有最大位数的非常大的数字以及只有一个数字的数组。 这些很重要，因为简单的方法可能无法处理单位数字，或者可能错误地反转较大数字的数字。 

## 方法

 一种简单的方法是迭代中的每个整数`nums`，将其转换为字符串，然后迭代该字符串以将每个字符转换回整数。 这是正确的，因为字符串转换保留了数字顺序，并且迭代每个字符可确保我们获得所有数字。 对于给定的约束，该方法足够有效，因为即使是最大的数字也最多包含 6 位数字。 

避免转换为字符串的更优化方法是使用数学运算。 对于每个数字，我们可以通过重复除以 10 的幂来提取数字。但是，由于我们要保留原始数字顺序，因此该方法需要暂时以相反的顺序存储数字，然后将它们反转，然后附加到结果数组中。 虽然这避免了字符串转换，但它增加了复杂性，并且对于给定的约束没有显着的性能提升。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力破解（字符串转换）| O(n * k) | O(n * k) | n = 整数的数量，k = 每个整数的最大位数； 简单，易于实施 |
 | 最优（数学提取）| O(n * k) | O(n * k) | 稍微复杂一些； 避免字符串转换但需要反转数字 |

 ## 算法演练

 1. 初始化一个空列表，名为`answer`存储结果数字。 
2. 迭代中的每个数字`nums`。 
3. 将当前数字转换为字符串，以按顺序获取其数字。 
4. 迭代字符串中的每个字符，将其转换为整数，并将其附加到`answer`。 
5.处理完所有数字后，返回`answer`。 

工作原理：字符串转换可保证按照数字中出现的顺序提取数字。 为每个数字按顺序附加数字可以保留数组中的整体顺序。 该算法的不变性是每个数字的数字在移动到下一个数字之前都经过完全处理，确保最终的数组准确地表示展平的数字序列。 

## Python 解决方案```python
from typing import List

class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        answer = []
        for num in nums:
            for digit in str(num):
                answer.append(int(digit))
        return answer
```在这个实现中，我们首先创建一个空列表`answer`。 对于每个数字`nums`，我们将其转换为字符串，以便每个数字都是一个单独的字符。 然后我们迭代这些字符，将每个字符转换回整数，并将其附加到`answer`。 最后，我们返回完整构建的列表。 这直接反映了算法步骤并确保正确的顺序保存。 

## 解决方案```go
func separateDigits(nums []int) []int {
    var answer []int
    for _, num := range nums {
        digits := []int{}
        n := num
        for n > 0 {
            digits = append([]int{n % 10}, digits...)
            n /= 10
        }
        if num == 0 { // edge case for zero
            digits = append(digits, 0)
        }
        answer = append(answer, digits...)
    }
    return answer
}
```在 Go 中，我们以数学方式处理数字提取。 对于每个数字，我们重复取余数模 10 来提取最低有效数字并将其添加到临时切片中`digits`以维持秩序。 提取数字的所有数字后，我们附加`digits`到`answer`。 这种方法避免了字符串转换，但需要仔细处理切片以维持顺序。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * k) | 对于 n 个数字中的每一个，我们最多处理 k 个数字，其中 k ≤ 6 |
 | 空间| O(n * k) | 结果数组存储所有数字的所有数字，最多 n * k 个元素 |

 原因是，将数字转换为字符串或以数学方式提取数字都需要单独处理每个数字，从而使算法与数字总数呈线性关系。

 ## 边缘情况

 一个重要的边缘情况是当数字是一位数字时，应按原样返回。 另一个边缘情况是允许的最大数字 100000，它有六位数字并测试算法是否正确处理大数字。 第三种边缘情况是当数组同时包含单位数和多位数字时，这可确保算法在保持顺序的同时正确连接数字。 在所有这些场景中，字符串转换或仔细的数学提取可以正确处理数字，而不会丢失或逆转，从而保证准确的输出。
