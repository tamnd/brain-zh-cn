[LeetCode 问题 2500](https://leetcode.com/problems/delete-greatest-value-in-each-row/)

 **难度：** 🟢简单
 **主题：** 数组、排序、堆（优先级队列）、矩阵、模拟

 ## 解决方案

 ## 问题理解

 问题提出了一个`m x n`矩阵`grid`正整数，并要求我们模拟对其进行重复删除过程。 在每次操作中，对于矩阵中的每一行，我们删除最大的元素。 删除这些元素后，我们从所有行中取出最大的删除元素，并将其添加到运行总计中，这将是最终的答案。 这个过程一直持续到所有列都被删除，即矩阵变空。 

输入表示整数的矩形网格。 每行可能包含重复值，但每次操作仅删除每行最大值的一次出现。 预期输出是一个整数，表示每个删除步骤的最大值之和。 

限制条件适中：`1 <= m, n <= 50`和`1 <= grid[i][j] <= 100`，这意味着输入大小足够小，即使是相对简单的解决方案也可以有效地工作。 重要的边缘情况包括具有单行或单列的矩阵、所有元素相等或最小矩阵大小（`1x1`），这些都应该由算法正确处理。 

## 方法

 ### 蛮力

 蛮力方法直接模拟问题陈述。 对于每个操作，我们迭代每一行，找到最大元素，将其删除，然后计算这些删除元素中的最大值以添加到总和中。 虽然正确，但这种方法涉及对每次删除的每一行进行重复扫描，导致时间复杂度大致为`O(m * n^2)`因为每个`n`删除步骤需要扫描`m`每行最多可以包含`n`元素。 这在限制范围内有效，但并不是最佳的。 

### 最佳方法

 优化的关键见解是，行的最大值始终来自按排序顺序的最大剩余元素。 如果我们一开始就按升序对每一行进行排序，那么每次操作我们都可以简单地删除每一行的最后一个元素，而无需重复扫描该行。 行的所有最后元素中最大的元素可以计算为`O(m)`每次操作的时间。 这将有效时间复杂度降低到`O(m * n log n)`由于初始行排序，这对于给定的约束是有效的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n^2) | O(m * n^2) | O(1) | O(1) | 通过重复扫描每一行直接模拟删除 |
 | 最佳 | O(m * n log n) | O(m * n log n) | O(1) | O(1) | 对行进行一次排序，然后在每个操作中删除每行的最后一个元素 |

 ## 算法演练

 1. 初始化变量`answer`到`0`跟踪最大删除元素的累积和。 
2. 按升序对网格的每一行进行排序。 这确保了每行的最大元素位于末尾。 
3. 重复`n`步骤，其中`n`是网格中的列数：

 1. 初始化变量`current_max`到`0`对于此操作。 
2.对于每一行，删除最后一个元素（由于排序，这是最大的）并更新`current_max`如果这个元素大于`current_max`。 
3.添加`current_max`到`answer`。 
4. 返回`answer`。 

**为什么有效：** 对每行进行排序可确保删除始终针对最大的元素，而无需重复扫描该行。 不变的是，在每次操作中，我们正确地删除行最大值并计算其中的总体最大值，与问题描述相匹配。 

## Python 解决方案```python
from typing import List

class Solution:
    def deleteGreatestValue(self, grid: List[List[int]]) -> int:
        answer = 0
        
        # Sort each row so that the largest element is at the end
        for row in grid:
            row.sort()
        
        n = len(grid[0])
        
        # Perform n operations, each removing the largest element from each row
        for _ in range(n):
            current_max = 0
            for row in grid:
                val = row.pop()  # Remove largest element
                current_max = max(current_max, val)
            answer += current_max
        
        return answer
```在此 Python 实现中，我们首先对每一行进行排序，使最大的元素位于末尾。 然后，对于每个`n`操作中，我们从每一行中弹出最后一个元素并跟踪这些弹出值的最大值。 该最大值被添加到`answer`。 这种方法避免了重复扫描行以获得最大值，从而使其高效且简单。 

## 解决方案```go
func deleteGreatestValue(grid [][]int) int {
    answer := 0
    m := len(grid)
    n := len(grid[0])
    
    // Sort each row
    for i := 0; i < m; i++ {
        row := grid[i]
        for j := 0; j < len(row)-1; j++ {
            for k := 0; k < len(row)-j-1; k++ {
                if row[k] > row[k+1] {
                    row[k], row[k+1] = row[k+1], row[k]
                }
            }
        }
    }
    
    // Perform n operations
    for op := 0; op < n; op++ {
        currentMax := 0
        for i := 0; i < m; i++ {
            row := grid[i]
            val := row[len(row)-1]
            grid[i] = row[:len(row)-1]
            if val > currentMax {
                currentMax = val
            }
        }
        answer += currentMax
    }
    
    return answer
}
```Go 实现反映了 Python 逻辑。 为了清晰起见，每行都使用嵌套循环进行排序（也可以使用 Go 标准库排序）。 在每次操作期间，删除每行的最后一个元素，并将这些删除的元素中的最大值累加到`answer`。

 ## 边缘情况

 1. **单行或单列**：对于只有一行或一列的矩阵，算法必须正确计算最大删除数，且不会因空行而出错。 排序确保最大的元素位于末尾，因此弹出操作始终有效。 
2. **所有元素相等**：当所有元素都相同时，每次操作的最大删除次数相同。 如果实现错误地尝试删除每行的多个实例，这可能会造成混乱。 该算法通过每次操作删除每行一个元素来处理此问题。 
3. **最小矩阵 (1x1)**：最小的可能输入可以是 1x1 矩阵。 该算法通过弹出单个元素并将其添加到答案中来正确处理此问题，然后在矩阵变空时终止。
