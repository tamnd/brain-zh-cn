[LeetCode 问题 2570](https://leetcode.com/problems/merge-two-2d-arrays-by-summing-values/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、两个指针

 ## 解决方案

 ## 问题理解

 该问题给了我们两个排序的二维整数数组，`nums1`和`nums2`，其中每个元素都是一对整数，格式为`[id, value]`。 

每个`id`唯一标识其自己的数组中的一个条目，以及相应的`value`代表该 id 的关联号码。 由于两个数组已经按升序排序`id`，我们可以利用这种顺序来有效地处理它们。 

任务是将两个数组合并为一个排序数组，同时遵循一些重要规则：

 1. 每个`id`出现在任一数组中的元素必须在结果中恰好出现一次。 
2. 如果`id`存在于两个数组中，它的值应该加在一起。 
3. 如果`id`仅存在于一个数组中，我们将另一个数组中的缺失值视为`0`。 
4. 最终结果必须保持升序排列`id`。 

例如，如果`nums1`包含`[1,2]`和`nums2`包含`[1,4]`，那么合并结果应该包含`[1,6]`因为`2 + 4 = 6`。 

限制相对较小：

 -`1 <= nums1.length, nums2.length <= 200`- 值和 ID 的界限为`1000`- 每个数组都有唯一的ID
 - 两个数组都已排序

 这些约束告诉我们，即使效率较低的解决方案仍然会通过，但数组的排序性质强烈建议采用更优雅和更有效的方法。 

一些边缘情况值得预先考虑。 

如果数组具有完全不相交的 id，则结果应仅包含按排序顺序的所有条目。 如果每个 id 都重叠，我们必须正确地对每一对进行求和。 另一个重要的情况是一个数组先于另一个数组完成，因为我们仍然需要附加剩余的元素。 该问题保证了每个数组中的唯一 id，从而无需处理单个列表中的重复 id。 

## 方法

 ### 蛮力方法

 一种简单的方法是使用哈希图。 

我们迭代`nums1`并存储每个`id → value`字典中的配对。 然后，我们迭代`nums2`。 如果一个`id`已经存在，我们将其价值添加到现有的。 否则，我们将其插入字典中。 

处理完两个数组后，我们对字典键进行排序并重建答案数组。 

这是有效的，因为哈希映射保证每个`id`仅出现一次，并且在插入过程中很容易对值求和。 然而，缺点是我们忽略了两个输入数组已经排序的事实。 我们最终执行了额外的排序步骤。 

### 最优方法，两个指针

 关键的观察是两个数组已经按`id`。 

每当对两个序列进行排序时，我们通常可以使用与合并排序中的合并步骤相同的思想来有效地处理它们。 我们为每个数组维护一个指针并比较当前的 id。 

有以下三种可能：

 - 如果 id 相等，我们将它们的值相加并移动两个指针。 
- 如果一个 id 较小，我们会将该条目直接添加到答案中并仅移动该指针。 
- 一个数组用完后，我们追加另一个数组中的所有剩余条目。 

因为每个元素只处理一次，所以我们完全避免排序并自然地保留升序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((n + m) log(n + m)) | O((n + m) log(n + m)) | O(n + m) | 使用哈希映射，然后对 id 进行排序 |
 | 最佳| O(n + m) | O(n + m) | 使用两个指针合并已排序的数组 |

 这里，`n = len(nums1)`和`m = len(nums2)`。 

## 算法演练

 1.初始化两个指针，`i`和`j`，都开始于`0`。 

指针`i`跟踪当前位置`nums1`， 尽管`j`跟踪当前位置`nums2`。 
2. 创建一个空结果数组。 

这将按排序顺序存储合并的条目。 
3. 比较两个数组中的当前 id。 

让`id1 = nums1[i][0]`和`id2 = nums2[j][0]`。 

如果`id1 == id2`，两个数组包含相同的 id。 将它们的值加在一起并附加`[id1, summed_value]`到结果。 然后向前移动两个指针。 
4.处理较小的id。 

如果`id1 < id2`，那么当前的id在`nums1`不存在于`nums2`在这个位置，因为两个数组都已排序。 我们可以安全地附加`nums1[i]`到结果并移动`i`向前。 

同样，如果`id2 < id1`, 附加`nums2[j]`并移动`j`向前。 
5. 继续，直到完全处理完一个数组。 

当任一指针到达其数组末尾时，主比较循环停止。 
6. 附加剩余元素。 

如果`nums1`仍有未处理的元素，将它们全部追加。 

如果`nums2`仍有未处理的元素，将它们全部追加。 
7. 返回结果。 

由于遍历时元素是按升序添加的，所以结果已经排序了。 

### 为什么它有效

 正确性来自两个数组的排序属性。 在每一步中，我们都会处理两个数组中剩余的最小 id。 如果 ids 匹配，我们立即将它们组合起来。 如果一个 id 较小，我们知道它不能稍后出现在另一个数组中，因为两个数组都严格递增。 因此，立即添加它可以保留正确性和排序顺序。 

## Python 解决方案```python
from typing import List

class Solution:
    def mergeArrays(
        self,
        nums1: List[List[int]],
        nums2: List[List[int]]
    ) -> List[List[int]]:
        i = 0
        j = 0
        merged = []

        while i < len(nums1) and j < len(nums2):
            id1, value1 = nums1[i]
            id2, value2 = nums2[j]

            if id1 == id2:
                merged.append([id1, value1 + value2])
                i += 1
                j += 1
            elif id1 < id2:
                merged.append([id1, value1])
                i += 1
            else:
                merged.append([id2, value2])
                j += 1

        while i < len(nums1):
            merged.append(nums1[i])
            i += 1

        while j < len(nums2):
            merged.append(nums2[j])
            j += 1

        return merged
```其实现严格遵循两指针算法。 

我们首先初始化`i`和`j`，跟踪内部位置`nums1`和`nums2`。 这`merged`list 存储最终答案。 

主要`while`只要两个数组仍包含未处理的元素，循环就会运行。 在每次迭代期间，我们提取当前的 id-value 对并比较它们的 id。 

如果两个 id 匹配，我们将合并这些值并推进两个指针。 如果一个 id 较小，我们会立即追加它，因为排序属性保证它不会稍后出现在另一个数组中。 

主循环完成后，一个数组可能仍包含剩余元素。 由于这些元素已经排序并且没有剩余的匹配 id，因此我们直接附加它们。 

最后，我们返回完成的合并数组。 

## 解决方案```go
func mergeArrays(nums1 [][]int, nums2 [][]int) [][]int {
	i, j := 0, 0
	result := [][]int{}

	for i < len(nums1) && j < len(nums2) {
		id1, value1 := nums1[i][0], nums1[i][1]
		id2, value2 := nums2[j][0], nums2[j][1]

		if id1 == id2 {
			result = append(result, []int{id1, value1 + value2})
			i++
			j++
		} else if id1 < id2 {
			result = append(result, []int{id1, value1})
			i++
		} else {
			result = append(result, []int{id2, value2})
			j++
		}
	}

	for i < len(nums1) {
		result = append(result, nums1[i])
		i++
	}

	for j < len(nums2) {
		result = append(result, nums2[j])
		j++
	}

	return result
}
```Go 实现密切反映了 Python 逻辑。 由于 Go 使用切片而不是动态 Python 列表，因此我们使用以下命令构建答案`append`。 

对于整数溢出没有特别的担忧，因为最大可能的求和值仅为`2000`，它很容易适合 Go 的`int`类型。 

Go 区分`nil`切片和空切片，但在这个问题中，任一表示都是有效的，因为约束保证非空输入。 该函数自然会返回一个初始化的切片。

 ## 边缘情况

 ### 完全不相交的 ID

 错误的一个常见来源是假设 id 总是重叠。 例如：```
nums1 = [[1,2],[2,3]]
nums2 = [[5,10]]
```幼稚的实现可能会错误地尝试匹配不相关的 ID。 两指针方法通过始终附加较小的 id 并向前移动来自然地处理这个问题。 由于没有 id 匹配，所有元素都会按排序顺序简单地合并。 

### 一个数组提前结束

 当一个数组先于另一个数组耗尽时，就会出现另一种棘手的情况。```
nums1 = [[1,2]]
nums2 = [[2,3],[3,4],[4,5]]
```如果我们在主比较循环之后立即停止，我们将丢失剩余的元素。 该实现通过两个清理循环避免了此错误，这两个清理循环在一个指针到达末尾后附加所有剩余条目。 

### 每个 ID 都重叠

 当两个数组中都存在每个 id 时：```
nums1 = [[1,1],[2,2]]
nums2 = [[1,5],[2,10]]
```有缺陷的实现可能会意外地重复 id，而不是对它们求和。 我们的解决方案显式检查相等性，并在推进两个指针之前将两个值合并到一个条目中，从而保证每个 id 恰好出现一次。 

### 单元素数组

 最小输入是另一个重要的边缘情况：```
nums1 = [[1,5]]
nums2 = [[1,10]]
```该实现正确地处理了这个问题，因为主循环仍然执行一次，检测匹配的 id，对值求和，然后干净地终止，而不需要任何特殊情况逻辑。
