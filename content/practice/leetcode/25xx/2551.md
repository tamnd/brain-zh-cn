[LeetCode 问题 2551](https://leetcode.com/problems/put-marbles-in-bags/)

 **难度：** 🔴难
 **主题：** 数组、贪婪、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 问题要求我们分发`weights.length`弹珠进入`k`连续的袋子，其中袋子的成本定义为该袋子中第一个和最后一个弹珠的总和。 我们要计算所有有效分布的最大和最小可能总分之间的差异。 

输入`weights`是代表弹珠重量的正整数列表，并且`k`是袋子的数量。 关键限制是每个包在原始数组中必须是连续的，并且没有包可以为空。 预期输出是一个整数，即最大总分和最小总分之间的差。 

重要的约束表明`weights`最多可以有`10^5`元素，每个权重最多可达`10^9`， 和`k`范围可以从 1 到`weights.length`。 这排除了由于组合爆炸而对所有分布进行暴力枚举。 

需要注意的边缘情况包括：`k = 1`（分数始终是第一个和最后一个元素的总和，因此差值为 0）并且何时`k = weights.length`（每个弹珠都是它自己的袋子，同样差异为0）。 

## 方法

 **暴力方法**：

 暴力解决方案会尝试各种方法将数组划分为`k`连续的子数组，计算每个子数组的第一个和最后一个元素的总和，并跟踪最大和最小总分数。 这在原则上是正确的，但在计算上是不可行的，因为分割长度数组的方法数量`n`进入`k`部分是组合的：`C(n-1, k-1)`，这对于`n = 10^5`。 

**最佳方法**：

 关键的观察是，袋子的成本仅取决于它的第一个和最后一个弹珠。 因此，对于`k`袋子里，就会有`k-1`大理石之间的切割。 如果我们定义两个连续弹珠之间的“对和”`weights[i] + weights[i+1]`，那么总分就是`weights[0] + weights[n-1] + sum of selected (k-1) pair sums`。 为了最大化分数，选择最大的`k-1`对和； 要最小化，请选择最小的`k-1`对和。 因此，最大分数和最小分数之间的差值就是最大分数之和之间的差值。`k-1`对和以及最小的和`k-1`对和。 

这种方法将问题简化为排序或使用堆`n-1`对和，这对于大的情况是有效的`n`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n-1, k-1)) | O(C(n-1, k-1)) | O(n) | 枚举所有可能的分区，对于大 n | 来说不切实际
 | 最佳| O(n log n) | O(n log n) | O(n) | 计算对和并排序以选择最大/最小 k-1 和 |

 ## 算法演练

 1. 计算数组`pair_sums`其中每个元素是连续权重的总和：`pair_sums[i] = weights[i] + weights[i+1]`。 
2. 排序`pair_sums`按升序排列。 
3. 求最小分数，将最小的分数相加`k-1`配对求和并相加`weights[0] + weights[-1]`。 
4. 求最大分数，将最大的分数相加`k-1`配对求和并相加`weights[0] + weights[-1]`。 
5. 返回最大和最小分数之间的差值。 

**为什么有效**：包的分数仅取决于端点。 弹珠之间的每次切割决定了哪些端点对总分有贡献。 通过选择最大或最小的`k-1`削减，我们控制贡献以最大化或最小化分数。 这保证了正确计算最大和最小分数之间的差异。 

## Python 解决方案```python
from typing import List

class Solution:
    def putMarbles(self, weights: List[int], k: int) -> int:
        if k == 1:
            return 0
        
        pair_sums = [weights[i] + weights[i+1] for i in range(len(weights) - 1)]
        pair_sums.sort()
        
        min_score = sum(pair_sums[:k-1])
        max_score = sum(pair_sums[-(k-1):])
        
        return max_score - min_score
```**说明**：代码首先处理边缘情况，其中`k=1`。 它计算`pair_sums`表示所有连续弹珠总和的数组。 排序可以轻松选择最小和最大的`k-1`总和。 最后，它根据需要计算最高分数和最低分数之间的差值。 

## 解决方案```go
import "sort"

func putMarbles(weights []int, k int) int64 {
    n := len(weights)
    if k == 1 {
        return 0
    }
    
    pairSums := make([]int, n-1)
    for i := 0; i < n-1; i++ {
        pairSums[i] = weights[i] + weights[i+1]
    }
    
    sort.Ints(pairSums)
    
    var minSum, maxSum int64
    for i := 0; i < k-1; i++ {
        minSum += int64(pairSums[i])
        maxSum += int64(pairSums[n-2-i])
    }
    
    return maxSum - minSum
}
```**Go 特定注释**：我们明确使用`int64`以避免整数溢出，特别是因为权重可以达到`10^9`。 切片`pairSums`使用而不是列表，排序使用Go的标准库。 边缘情况`k=1`在开始时进行处理。 

## 工作示例

 **示例1**：`weights = [1,3,5,1], k = 2`1. 计算对和：`[1+3=4, 3+5=8, 5+1=6] => [4,8,6]`2. 排序：`[4,6,8]`3. 最低分数：`4`（最小 1 和）+ 端点`1 + 1 = 2`=>总计`6`4、最高分：`8`（最大 1 和）+ 端点`2`=>总计`10`5、区别：`10 - 6 = 4`**示例2**：`weights = [1,3], k = 2`1. 计算对和：`[1+3=4]`2. 仅需一笔款项； 最小值和最大值`4`3.差异=`0`## 复杂度分析

 ## 边缘情况

 **单个弹珠，k=1**：差值必须为 0，因为只有一袋存在。 该实现通过提前返回来处理这个问题。 

**最大袋数，k=n**：每个弹珠都是自己的袋，因此每个袋的成本是弹珠本身的两倍（第一个 + 最后一个），但差值仍然为 0。排序和求和逻辑仍然正确返回 0。 

**接近 10^9 的大权重**：为了防止 Go 中的溢出，总和被显式转换为`int64`。 Python 原生处理任意整数。 该算法仍然可以正确计算对和和差，没有数值错误。
