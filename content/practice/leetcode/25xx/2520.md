[LeetCode 问题 2520](https://leetcode.com/problems/count-the-digits-that-divide-a-number/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们确定，给定一个正整数`num`，它的多少位数字可以被整除`num`。 换句话说，对于每个数字`d`在数字中，我们检查是否`num % d == 0`。 输入是介于之间的单个整数`1`和`10^9`，并且该数字不会包含零，因此我们不需要处理被零除的情况。 输出是一个整数，表示除数的位数`num`。 

重申一下，如果`num`是`121`，我们检查它的数字`1`,`2`， 和`1`。 两次出现`1`划分`121`， 但`2`没有。 因此，答案是`2`。 约束表明输入大小是可控的； 中的位数`num`至多是`9`，因此即使是对数字进行简单的迭代也是高效的。 重要的边缘情况包括具有重复数字的数字、素数以及最大可能的数字`10^9`。 

## 方法

 蛮力方法涉及转换`num`转换为字符串或使用模运算提取数字，然后检查每个数字是否可以整除`num`。 这是可行的，因为位数很少，但它会单独迭代每个数字并每次执行除法检查。 鉴于最多有`9`如果位数较多，这种方法是可以接受的，尽管如果位数较多，理论上它不是最佳的。 

最佳方法依赖于相同的想法，但强调仔细处理重复的数字和避免零（尽管保证零不会出现在这个问题中）。 关键的见解是每个数字都可以单独检查，而不用担心重复或顺序，并且模运算是常数时间。 因此，迭代数字并计算有效除数既简单又高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(d) | O(d) | 将数字转换为字符串，检查每个数字的整除性。`d`是位数。 |
 | 最佳 | O(d) | O(1) | O(1) | 使用模/除法迭代数字，直接计算有效除数。 |

 ## 算法演练

 1.初始化一个计数器变量`count`为零。 这将跟踪除以的位数`num`。 
2. 在临时变量中创建输入数字的副本`n`提取数字而不修改原始数字。 
3.循环while`n > 0`。 在每次迭代中：

 a. 使用提取最后一位数字`digit = n % 10`。 

b. 如果`digit`不为零且`num % digit == 0`, 增量`count`一个。 

c. 删除最后一位数字`n`使用整数除法`n //= 10`。 
4.处理完所有数字后，返回`count`。 

**为什么有效**：每个数字都经过独立检查`num`为了可分性。 通过迭代所有数字，该算法保证计算每个可能的数字除数。 保证数字非零可以避免除零错误。 

## Python 解决方案```python
class Solution:
    def countDigits(self, num: int) -> int:
        count = 0
        n = num
        while n > 0:
            digit = n % 10
            if digit != 0 and num % digit == 0:
                count += 1
            n //= 10
        return count
```Python 实现按照该算法一步步进行。 的副本`num`存储在`n`以便模检查的原始值保持不变。 这`while`循环从右到左迭代所有数字，执行整除性检查并更新`count`。 最后，累计`count`被返回。 

## 解决方案```go
func countDigits(num int) int {
    count := 0
    n := num
    for n > 0 {
        digit := n % 10
        if digit != 0 && num % digit == 0 {
            count++
        }
        n /= 10
    }
    return count
}
```在 Go 中，实现是类似的。 我们使用一个`for`循环遍历数字`num`和一个变量`count`跟踪除数的数量。 整数除法和模运算的行为与 Python 中相同。 不需要对零进行特殊处理，因为约束保证非零数字。

 ## 边缘情况

 第一个边缘情况是最小的数字，`1`。 它很重要，因为它测试算法是否正确处理单位数输入并计算数字本身。 第二个边缘情况是具有重复数字的数字，例如`222`或者`121`。 这测试解决方案是否正确计算除数的每次出现，而不仅仅是唯一数字。 第三个边缘情况是附近有大量数字`10^9`，它检查整数处理和性能是否保持正确，尽管约束保证它是可行的。 该解决方案使用简单的数字提取和模检查来正确处理所有这些问题。
