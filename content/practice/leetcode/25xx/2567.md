[LeetCode 问题 2567](https://leetcode.com/problems/minimum-score-by-changing-two-elements/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们操作一个整数数组，`nums`，以一种非常具体的方式最小化称为“分数”的指标。 分数定义为两个量的总和：**高分**，它是数组中任意两个元素之间的最大绝对差值；**低分**，它是任意两个元素之间的最小绝对差值。 不同的是，我们可以**将数组的最多两个元素**更改为我们选择的任何值，以最小化此分数。 

换句话说，给定一个长度的数组`n`，我们希望找到两个要更改的元素，以便在这些更改之后，最大和最小数字之间的差值（高分）以及任意两个数字之间的最小差值（低分）合计起来为最小的可能值。 

约束告诉我们输入大小可能非常大（`3 <= nums.length <= 10^5`）并且数组值是正整数，最多`10^9`。 这意味着检查每对可能的更改的强力方法是不可行的，因为它需要组合时间。 

关键的边缘情况包括已经接近均匀的数组、重复最小或最大元素的数组或长度恰好为三的数组，因为可以更改任何两个元素以使所有值相等。 

## 方法

 暴力方法将涉及尝试将两个元素更改为任何整数值的每种可能的组合，然后计算所得分数。 这保证了正确性，但在计算上是不可行的，因为组合的数量呈二次方增长并且值的范围非常大（`1`到`10^9`）。 

最佳方法利用了这样的见解：**最大和最小元素**在很大程度上决定了高分，而**排序元素之间的最大差距**决定了低分。 通过对数组进行排序，我们可以只关注边界元素。 具体来说，为了最小化两次变化后的分数，我们只需要考虑三个主要策略：

 1. 更改两个最大的元素以匹配较小的元素。 
2. 更改两个最小的元素以匹配较大的元素。 
3. 更改最小和最大元素，保持中间不变。 

对数组进行排序使我们能够仅检查几个候选高分场景，而无需迭代每对可能的更改。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * n) | O(n^2 * n) | O(1) | O(1) | 尝试改变所有的元素对； 计算最小和最大差异； 对于 n=10^5 | 太慢
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 对数组进行排序； 仅考虑边界元素； 检查三个关键案例以获得最低分数 |

 ## 算法演练

 1. **对数组进行排序**。 排序使我们能够有效地考虑最小和最大的元素。 设排序后的数组为`nums_sorted`。 
2. **确定关键候选人**。 排序后，两次变化后的最低高分候选涉及极端元素：

 - 更改两个最大的元素以减少最大差异。 
- 更改两个最小的元素以减少最大差异。 
- 以混合方式更改最小和最大元素以平衡差异。 
3. **计算考生分数**。 对于已排序的数组`[a0, a1, ..., an-1]`，改变两个元素后可能的最小高分是：

 -`nums[n-3] - nums[0]`（改变两个最大的元素）
 -`nums[n-1] - nums[2]`（改变两个最小的元素）
 -`nums[n-2] - nums[1]`（改变一个最小和一个最大的元素）
 4. **返回这些候选者中的最小值**。 最小可能的高分压倒低分，因为通过为更改的元素选择适当的值，最小绝对差值始终可以减少到零。 

**为什么有效**：通过关注排序的边界元素，我们考虑了影响最大差异的所有情况。 该问题允许任意赋值，因此我们总是可以通过两次更改将最小差值减小到零，并且高分由剩余边界元素限制。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimizeSum(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 3:
            return 0  # Can always make all elements equal
        
        nums.sort()
        # Three strategies: change two largest, change two smallest, change smallest+largest
        option1 = nums[-3] - nums[0]  # change two largest
        option2 = nums[-1] - nums[2]  # change two smallest
        option3 = nums[-2] - nums[1]  # change one smallest, one largest
        
        return min(option1, option2, option3)
```该实现首先处理以下边缘情况`n <= 3`，我们可以简单地将所有元素设置为等于零分数。 对数组进行排序可以简化识别最大和最小元素的过程。 然后，根据边界操作计算三个可能的最小高分，并返回最小值作为答案。 

## 解决方案```go
import "sort"

func minimizeSum(nums []int) int {
    n := len(nums)
    if n <= 3 {
        return 0
    }
    
    sort.Ints(nums)
    
    option1 := nums[n-3] - nums[0] // change two largest
    option2 := nums[n-1] - nums[2] // change two smallest
    option3 := nums[n-2] - nums[1] // change one smallest and one largest
    
    min := option1
    if option2 < min {
        min = option2
    }
    if option3 < min {
        min = option3
    }
    
    return min
}
```在 Go 中，排序是使用`sort.Ints`。 首先处理小数组的边缘情况。 三个候选高分是手动计算和比较的，因为 Go 缺乏内置的`min`对于多个整数。 

## 工作示例

 **示例1**：`nums = [1, 4, 7, 8, 5]`1. 排序：`[1, 4, 5, 7, 8]`2. 候选人：

 -`nums[-3] - nums[0] = 5 - 1 = 4`-`nums[-1] - nums[2] = 8 - 5 = 3`-`nums[-2] - nums[1] = 7 - 4 = 3`3. 最低分数=`3`**示例2**：`nums = [1, 4, 3]`1.长度≤3→返回`0`直接地。

 ## 边缘情况

 **边缘情况 1：小型阵列**。 什么时候`n <= 3`，任何数组都可以通过更改两个元素来统一，从而得到 0 分。这是在算法开始时明确处理的。 

**边缘情况 2：已经是统一的数组**。 如果所有元素都相等，则分数已经为零。 该算法正确地将候选者计算为零或更少，返回零。 

**边缘情况 3：最大差异较大**。 如果数组中的一个元素比其他元素大得多，则可能会导致简单的解决方案错误计算要更改的最佳两个元素。 通过对前三个和后三个元素进行排序和关注，算法始终捕获最佳的变更场景。 

**边缘情况 4：具有连续重复项的数组**。 最小绝对差最初可能为零，但两次变化可能会改变边界。 仅排序和考虑边界差异可确保始终将低分最小化。
