[LeetCode 问题 2556](https://leetcode.com/problems/disconnect-path-in-a-binary-matrix-by-at-most-one-flip/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、深度优先搜索、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 问题是询问是否可以**断开左上角的路径`(0, 0)`到右下角`(m - 1, n - 1)`在二进制矩阵中**通过翻转**至多一个单元格**`1`到`0`或者`0`到`1`。 路径只允许**向下或向右**移动到包含`1`。 矩阵已经保证有`1`在两者中`(0, 0)`和`(m - 1, n - 1)`。 

输入是一个`m x n`二进制矩阵高达`10^5`细胞总数。 输出是一个布尔值：`true`是否可以通过一次翻转断开矩阵，以及`false`否则。 

主要限制包括只能翻转一个单元格，并且不能翻转起始单元格和结束单元格。 问题的规模表明，尝试翻转每个单元并检查连接性的强力尝试可能会太慢。 

重要的边缘情况包括小矩阵（`1x1`或者`1xN`），已经断开连接的矩阵，以及只有**关键单元**控制唯一路径的矩阵。 由于移动仅限于**向右和向下**，因此唯一路径的数量可能会受到限制，这对于最佳方法至关重要。 

## 方法

 ### 蛮力

 一个简单的方法是迭代每个单元格`(i, j)`那不是`(0, 0)`或者`(m - 1, n - 1)`，翻转它的值，然后执行DFS或BFS看是否`(m - 1, n - 1)`仍然可以从`(0, 0)`。 如果我们发现一个翻转断开了路径，我们就返回`true`。 如果没有效果，我们就返回`false`。 

虽然正确，但对于大型矩阵来说**太慢**。 每次连接检查都是`O(m * n)`，翻转每个单元格会导致`O(m * n * m * n)`最坏情况下的时间可以达到`10^10`行动——显然不可行。 

### 最佳方法

 关键的见解是，如果从开始到结束有**两条或更多条独立路径**，则删除一个单元不会断开矩阵。 因此，要通过单次翻转断开连接，网格必须具有从`(0, 0)`到`(m - 1, n - 1)`其中所有中间单元都很关键。 

我们可以通过执行**两次 DFS/BFS 遍历**来实现这一点：

 1. **转发 DFS** 来自`(0, 0)`记录哪些单元格是可达的。 
2.**后向DFS**来自`(m - 1, n - 1)`记录哪些单元格可以到达终点。 

如果有一个单元格**位于每个有效路径**上（即在向前和向后遍历中都被访问过），则翻转它会断开路径。 我们只需要检查**中间单元格**，而不是开始或结束。 

这种方法可以有效地工作在`O(m * n)`时间，因为每个单元最多被处理两次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m * n)^2) | O((m * n)^2) | O(m * n) | 翻转每个单元并检查连接性 |
 | 最佳| O(m * n) | O(m * n) | DFS/BFS 从头到尾识别唯一关键路径 |

 ## 算法演练

 1. **正向DFS**：从`(0, 0)`并标记所有可到达的单元格，仅向下或向右穿过单元格`1`。 将结果存储在`reachable_from_start`矩阵。 
2. **向后DFS**：从`(m - 1, n - 1)`并标记所有可以到达末端的单元格，仅向上或向左移动通过单元格`1`。 将结果存储在`reachable_to_end`矩阵。 
3. **检查关键单元**：迭代所有中间单元`(i, j)`排除`(0, 0)`和`(m - 1, n - 1)`。 如果`reachable_from_start[i][j]`和`reachable_to_end[i][j]`两者都是正确的，该单元格位于**独特的路径**上。 如果存在这样的单元格，则翻转它会断开路径，因此返回`true`。 
4. **未找到关键单元**：如果唯一路径上没有中间单元，则返回`false`。 

**为什么有效**：向前和向后遍历一起识别属于**某些路径**一部分的所有单元格。 在这两种情况下访问的单元格都是至关重要的。 由于翻转一个关键单元会断开唯一路径，因此检查所有此类单元可保证正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def isPossibleToCutPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        
        # Forward DFS from (0,0)
        reachable_from_start = [[False]*n for _ in range(m)]
        reachable_from_start[0][0] = True
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    if i > 0 and reachable_from_start[i-1][j]:
                        reachable_from_start[i][j] = True
                    if j > 0 and reachable_from_start[i][j-1]:
                        reachable_from_start[i][j] = True
        
        # Backward DFS from (m-1,n-1)
        reachable_to_end = [[False]*n for _ in range(m)]
        reachable_to_end[m-1][n-1] = True
        for i in range(m-1, -1, -1):
            for j in range(n-1, -1, -1):
                if grid[i][j] == 1:
                    if i < m-1 and reachable_to_end[i+1][j]:
                        reachable_to_end[i][j] = True
                    if j < n-1 and reachable_to_end[i][j+1]:
                        reachable_to_end[i][j] = True
        
        # Check intermediate critical cells
        for i in range(m):
            for j in range(n):
                if (i == 0 and j == 0) or (i == m-1 and j == n-1):
                    continue
                if reachable_from_start[i][j] and reachable_to_end[i][j]:
                    return True
        return False
```Python 代码构造两个布尔矩阵来跟踪从开头可到达的单元格和可到达末尾的单元格。 它在网格中迭代两次：一次向前，一次向后。 作为两个矩阵一部分的任何中间单元都是至关重要的。 翻转它会断开路径。 

## 解决方案```go
func isPossibleToCutPath(grid [][]int) bool {
    m, n := len(grid), len(grid[0])
    reachableFromStart := make([][]bool, m)
    reachableToEnd := make([][]bool, m)
    for i := 0; i < m; i++ {
        reachableFromStart[i] = make([]bool, n)
        reachableToEnd[i] = make([]bool, n)
    }
    
    reachableFromStart[0][0] = true
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == 1 {
                if i > 0 && reachableFromStart[i-1][j] {
                    reachableFromStart[i][j] = true
                }
                if j > 0 && reachableFromStart[i][j-1] {
                    reachableFromStart[i][j] = true
                }
            }
        }
    }
    
    reachableToEnd[m-1][n-1] = true
    for i := m-1; i >= 0; i-- {
        for j := n-1; j >= 0; j-- {
            if grid[i][j] == 1 {
                if i < m-1 && reachableToEnd[i+1][j] {
                    reachableToEnd[i][j] = true
                }
                if j < n-1 && reachableToEnd[i][j+1] {
                    reachableToEnd[i][j] = true
                }
            }
        }
    }
    
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if (i == 0 && j == 0) || (i == m-1 && j == n-1) {
                continue
            }
            if reachableFromStart[i][j] && reachableToEnd[i][j] {
                return true
            }
        }
    }
    return false
}
```Go 实现镜像 Python，但使用切片切片作为布尔矩阵。 迭代和边界检查是显式处理的，并且标记可达单元的逻辑是相同的。
