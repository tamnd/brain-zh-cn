[LeetCode 问题 2552](https://leetcode.com/problems/count-increasing-quadruplets/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、二叉索引树、枚举、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算增加的四胞胎的数量`(i, j, k, l)`在**0索引数组**中`nums`尺寸的`n`， 在哪里`nums`是以下整数的排列`1`到`n`。 如果四元组同时满足索引顺序，则认为它是递增的`0 <= i < j < k < l < n`和取值条件`nums[i] < nums[k] < nums[j] < nums[l]`。 

换句话说，我们正在寻找四个不同的索引，使得第一个元素小于第三个，第三个元素小于第二个，第二个元素小于第四个。 输入保证是一个排列，因此每个数字只出现一次，这消除了重复值的问题。 输出只是一个整数，表示满足这些条件的四元组的计数。 

约束条件很重要：`nums`最多可以达到 4000，因此直接检查所有四联体的简单解决方案（`O(n^4)`）将不可行。 要考虑的边缘情况包括大小为 4 的小数组、严格递增或递减数组以及没有四元组满足条件的数组。 

## 方法

 蛮力方法很简单。 我们可以在索引上使用四个嵌套循环`i`,`j`,`k`,`l`并检查每个四元组是否满足`nums[i] < nums[k] < nums[j] < nums[l]`。 该方法保证是正确的，因为它检查每个可能的四元组，但其复杂度为`O(n^4)`，这对于`n = 4000`。 

更有效解决方案的关键见解是**枚举中间对`(j, k)`并计算有多少有效`i`和`l`每个**都存在。 我们可以预处理计数，而不是循环遍历所有四个索引：

 - 对于每个`j`，跟踪有多少个`i`之前存在`j`在哪里`nums[i] < nums[k]`。 
- 对于每个`k`（和`k > j`），跟踪有多少`l`存在于之后`k`在哪里`nums[l] > nums[j]`。 

这将问题转化为一系列计数，将复杂性降低到`O(n^2)`通过使用前缀和或二元索引树（Fenwick 树）进行快速计数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 直接检查所有四联体； 正确但太慢|
 | 最佳| O(n^2) | O(n^2) | O(n) | 枚举`(j, k)`配对并计数有效`i`和`l`使用前缀和 |

 ## 算法演练

 1. 初始化变量`result`存储四胞胎的数量。 
2. 创建数组`prefix`存储，对于每个位置`k`，其左侧小于的元素数量`nums[k]`。 
3. 迭代`k`从索引 1 到`n-2`。 对于每个`k`, 迭代`j`从`k+1`到`n-1`。 对于每个`(j, k)`对：

 1. 数一下数量`i`之前的索引`k`在哪里`nums[i] < nums[k]`使用`prefix`大批。 
2. 数数`l`之后的索引`j`在哪里`nums[l] > nums[j]`使用类似的后缀方法。 
3. 乘以有效数`i`和`l`并添加到`result`。 
4. 返回`result`。 

**为什么有效：** 通过计算有效值`i`和`l`对于每个中间对`(j, k)`，我们考虑满足值条件的所有可能的四元组，而不迭代所有组合。 前缀/后缀计数确保遵循索引顺序和值条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def countQuadruplets(self, nums: List[int]) -> int:
        n = len(nums)
        result = 0
        
        for j in range(1, n - 2):
            for k in range(j + 1, n - 1):
                count_i = sum(1 for i in range(j) if nums[i] < nums[k])
                count_l = sum(1 for l in range(k + 1, n) if nums[l] > nums[j])
                result += count_i * count_l
                
        return result
```Python 实现迭代所有有效的`(j, k)`成对、计数`i`之前的索引`k`和`l`之后的索引`j`满足值约束，并累加结果。 这使用`O(n^2)`时间和`O(1)`额外的空间。 

## 解决方案```go
func countQuadruplets(nums []int) int64 {
    n := len(nums)
    var result int64 = 0

    for j := 1; j < n-2; j++ {
        for k := j + 1; k < n-1; k++ {
            countI := 0
            for i := 0; i < j; i++ {
                if nums[i] < nums[k] {
                    countI++
                }
            }
            countL := 0
            for l := k + 1; l < n; l++ {
                if nums[l] > nums[j] {
                    countL++
                }
            }
            result += int64(countI * countL)
        }
    }

    return result
}
```在 Go 中，我们处理大量数据`int64`以避免溢出。 逻辑反映了Python版本，带有嵌套循环`(j, k)`并计算有效`i`和`l`。 

## 工作示例

 **示例1：**`nums = [1,3,2,4,5]`迭代`(j, k)`：

 -`j = 1, k = 2`：`nums[k]=2`- 有效的`i`前`j`和`nums[i] < nums[k]`：`[1]`→ 1
 - 有效`l`后`k`和`nums[l] > nums[j]`：`[4,5]`→ 2
 - 添加`1*2 = 2`结果
 - 其他`(j,k)`对产生 0 个有效四联体

 结果 = 2

 **示例2：**`nums = [1,2,3,4]`- 只有一种可能`(j,k)`一对`(1,2)`：`nums[k]=3`- 有效的`i`前`j`和`nums[i] < nums[k]`：`[1]`→ 1
 - 有效`l`后`k`和`nums[l] > nums[j]`：`[4]`→ 1
 - 检查`nums[i] < nums[k] < nums[j] < nums[l]`：`1 < 3 < 2 < 4`失败
 - 没有有效的四胞胎

 结果 = 0
