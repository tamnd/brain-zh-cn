 ## 问题理解

 该问题要求我们取一个正整数`num`并将其数字分成两个非负整数`num1`和`num2`使得总和`num1 + num2`被最小化。 重要的是，数字`num`必须完全在之间使用`num1`和`num2`，但它们的顺序可以重新排列，并且两个数字中都允许有前导零。 输入`num`保证至少为两位数（`10 <= num <= 10^9`) 并且不会有前导零。 

输出是通过拆分和重新排序数字形成的两个整数的最小和`num`。 约束条件告诉我们，`num`最多为 9 或 10，这意味着检查所有排列的解决方案可能会很昂贵（最多阶乘时间），因此我们需要一种更有效的方法。 

重要的边缘情况包括具有重复数字的数字（例如，`num = 1111`），带有可以创建前导零的数字的数字（例如，`num = 1023`）和小数字（例如，`num = 10`）。 

## 方法

 蛮力方法将涉及生成数字的所有排列`num`，然后尝试各种可能的方法将每个排列分成两个数字，并计算它们的总和。 然后我们将返回最小金额。 虽然这保证了正确性，但排列的阶乘增长（`O(d! * 2^d)`在哪里`d`是位数）使得对于多于几位数的数字不可行。 

最佳解决方案的关键是通过从数字中形成尽可能小的数字来最小化总和。 这可以通过对数字进行排序并以交替方式分配它们来实现`num1`和`num2`。 将最小的数字分配给`num1`，下一个最小的`num2`，接下来`num1`，依此类推，确保两个数字的大小增长缓慢，从而最小化它们的总和。 这是有效的，因为较大的数字放在较高的位置时贡献更多，因此平衡两个数字之间的数字会减少总和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|

 | 蛮力 | O(d! * 2^d) | O(d! * 2^d) | O(d) | 生成所有排列和分割以找到最小总和，这对于较大的数字是不可行的 |
 | 最佳| O(d log d) | O(d log d) | O(d) | 对数字进行排序并交替分配给两个数字以最小化总和 |

 ## 算法演练

 1. 转换数字`num`到其数字列表以便于操作。 
2. 按升序对数字进行排序。 排序可确保首先使用最小的数字来最小化总和。 
3.初始化两个空列表（或字符串）`num1_digits`和`num2_digits`存储数字`num1`和`num2`。 
4. 迭代排序后的数字，并将每个数字交替附加到`num1_digits`和`num2_digits`。 这样可以平衡两个数字的数字，确保两个数字都不会变得太大。 
5. 转换`num1_digits`和`num2_digits`为整数`num1`和`num2`。 前导零由整数转换自动处理。 
6. 返回总和`num1`和`num2`。 

**为什么有效：** 通过对数字进行排序并交替分配，我们可以确保两个数字中较大的数字是平衡的，从而防止一个数字变得不成比例地大。 这保证了最小可能的总和，因为任何偏差（不均匀地放置较大的数字）都会增加总和。 

## Python 解决方案```python
class Solution:
    def splitNum(self, num: int) -> int:
        digits = sorted([int(d) for d in str(num)])
        num1_digits, num2_digits = [], []
        for i, d in enumerate(digits):
            if i % 2 == 0:
                num1_digits.append(str(d))
            else:
                num2_digits.append(str(d))
        num1 = int("".join(num1_digits))
        num2 = int("".join(num2_digits))
        return num1 + num2
```Python 实现首先将数字转换为数字列表并对它们进行排序。 然后，它交替分配给两个代表的列表`num1`和`num2`。 最后，列表被连接成字符串并转换为整数，并返回它们的总和。 

## 解决方案```go
import (
    "sort"
    "strconv"
)

func splitNum(num int) int {
    numStr := strconv.Itoa(num)
    digits := make([]int, len(numStr))
    for i, ch := range numStr {
        digits[i] = int(ch - '0')
    }
    sort.Ints(digits)
    num1Str, num2Str := "", ""
    for i, d := range digits {
        if i%2 == 0 {
            num1Str += strconv.Itoa(d)
        } else {
            num2Str += strconv.Itoa(d)
        }
    }
    num1, _ := strconv.Atoi(num1Str)
    num2, _ := strconv.Atoi(num2Str)
    return num1 + num2
}
```在 Go 中，主要区别在于处理字符串到整数的转换以及对数字使用切片。 排序是通过`sort.Ints`，并且整数转换是使用完成的`strconv.Atoi`。

 ## 边缘情况

 第一个重要的边缘情况是具有重复数字的数字，例如`1111`。 如果算法很幼稚，它可能会将一个数字中的所有 1 组合在一起，而另一个数字中的所有 0 组合在一起，但交替分布可确保均匀分割，从而给出最小的总和。 

第二个边缘情况是包含零的数字，例如，`1023`。 这可能会导致拆分数字之一出现前导零。 由于整数转换会丢弃前导零，因此该算法可以正确处理此问题。 

第三种边缘情况是最小的可能输入，`10`。 排序和交替分配确保`num1 = 0`和`num2 = 1`产生最小总和`1`，这表明该方法可以推广到小数。
