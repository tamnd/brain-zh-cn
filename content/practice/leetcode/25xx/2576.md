[LeetCode 问题 2576](https://leetcode.com/problems/find-the-maximum-number-of-marked-indices/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、二分查找、贪婪、排序

 ## 解决方案

 ## 问题理解

 这个问题要求我们最大化数组中可以使用特定操作“标记”的索引数量。 给你一个整数数组`nums`并且可以重复选择两个不同的**未标记**索引`i`和`j`这样`2 * nums[i] <= nums[j]`。 一旦选择，两个指数`i`和`j`已标记。 目标是在尽可能多次执行此操作后确定**可以标记的索引的最大数量**。 

简单来说，我们将较小的数字与足够大的数字配对以满足`2 * nums[i] <= nums[j]`健康）状况。 每个成功的配对都会标记两个索引，我们希望计算尽可能多的标记索引。 

约束告诉我们`nums`最多可以有 100,000 个元素，并且数字可能非常大（`<= 10^9`）。 这意味着对所有对进行强力检查是不可行的，因为`O(n^2)`时间复杂度。 

重要的边缘情况包括：

 - 没有有效对的数组，例如，`[7,6,8]`。 
- 存在多个有效配对的数组，例如，`[9,2,5,4]`。 
- 具有重复元素或所有相等元素的数组。 

## 方法

 ### 蛮力

 蛮力方法将迭代所有对`(i, j)`未标记的索引并在任何时候标记它们`2 * nums[i] <= nums[j]`。 我们将继续，直到不再存在有效对为止。 虽然这种方法是正确的，但它的时间复杂度为`O(n^2)`，这对于`n = 10^5`。 

### 最佳方法

 关键的见解是，对数组进行排序允许我们使用两指针或贪婪策略有效地将较小的数字与较大的数字配对。 排序后，最小的数在开始，最大的在最后。 我们可以尝试将最小的未标记数字与满足条件的最大数字配对`2 * nums[i] <= nums[j]`。 这种方法可确保最大程度的配对，因为：

 - 我们总是尝试使用最小的可用`nums[i]`，为未来潜在的配对留下更多的数字。 
- 排序保证一旦一个数字`nums[i]`无法配对`nums[j]`，它不能与任何较小的配对`nums[j]`任何一个。 

使用两个指针，我们从两端迭代数组。 我们计算可以形成多少个有效对，然后乘以 2 以获得总标记索引。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 重复迭代所有对 |
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 排序数组+两指针贪婪配对 |

 ## 算法演练

 1. **对数组进行排序`nums`按升序排列。** 排序可以帮助我们有效地找到较小数字可以与较大数字配对的对。 
2. **将数组分成两半：** 让前半部分成为潜在的`i`候选人（人数较少）和下半年是有潜力的`j`候选人（人数较多）。 使用整数除法`n // 2`来确定分割。 
3. **初始化两个指针：**`i`从上半场开始时开始，并且`j`从下半场开始时开始。 
4. **计数有效对：** 当两个指针都在边界内时，检查是否`2 * nums[i] <= nums[j]`。 如果是，则增加有效对的计数，并将两个指针向前移动。 如果条件失败，则仅移动`j`指针向前寻找可以配对的更大数字。 
5. **计算总标记索引：** 每个有效对标记两个索引，因此将对的数量乘以 2。 

**为什么有效：** 排序可确保较小的数字与最小的足够大的数字配对。 两指针策略确保没有重叠并最大化配对。 通过按顺序迭代，我们保证不会浪费或不必要地跳过任何数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxNumOfMarkedIndices(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        left = 0
        right = n // 2
        count = 0
        
        while left < n // 2 and right < n:
            if 2 * nums[left] <= nums[right]:
                count += 1
                left += 1
            right += 1
        
        return count * 2
```**说明：** 首先对数组进行排序以实现高效配对。 我们使用两个指针遍历两半，计算有效对的数量。 这`left`仅当找到有效对时指针才会移动，确保每个较小的数字最多使用一次。 这`right`指针始终移动，确保我们探索所有更大的数字。 将计数乘以 2 得出标记索引总数。 

## 解决方案```go
import "sort"

func maxNumOfMarkedIndices(nums []int) int {
    sort.Ints(nums)
    n := len(nums)
    left, right := 0, n/2
    count := 0
    
    for left < n/2 && right < n {
        if 2*nums[left] <= nums[right] {
            count++
            left++
        }
        right++
    }
    
    return count * 2
}
```**说明：** Go 版本镜像了 Python 解决方案。 我们使用`sort.Ints`对切​​片进行排序，并使用两个指针对对进行计数。 切片索引和循环条件安全地处理边界。 乘以 2 得出标记索引的数量。

 ## 边缘情况

 **情况 1：单元素数组**

 具有一个元素的数组不能形成一对，因此该函数正确返回 0。 

**情况 2：所有相同的数字**

 如果所有数字都相同，`2 * nums[i]`永远不会小于或等于数组中的任何其他数字。 该算法会处理这个问题，因为两指针检查总是会失败，返回 0。 

**情况 3：具有最大数量的大数组**

 算法正确处理`nums`大小可达 100,000，值可达`10^9`因为所有计算都涉及 Python 或 Go 整数范围内的整数乘法。 排序和线性遍历仍然高效。
