[LeetCode 问题 2546](https://leetcode.com/problems/apply-bitwise-operations-to-make-strings-equal/)

 **难度：** 🟡 中等
 **主题：** 字符串、位操作

 ## 解决方案

 ## 问题理解

 该问题提供了两个二进制字符串，`s`和`target`, 等长`n`。 您可以执行特定的按位运算`s`任意次数，其中涉及选择两个不同的索引`i`和`j`并更新`s[i]`到`s[i] OR s[j]`和`s[j]`到`s[i] XOR s[j]`。 目的是确定是否可以转型`s`进入`target`使用此操作。 

简而言之，您需要通过重复组合和交换位来检查是否`s`使用 OR 和 XOR 运算，您可以使每一位`s`完全匹配`target`。 输入字符串仅包含“0”或“1”，长度可达 100,000，因此对所有操作进行简单模拟是不切实际的。 

来自约束的关键观察结果是，该操作在某种意义上保留了“1”的总数：如果`s`不包含“1”，但是`target`确实如此，转型是不可能的。 该问题还保证两个字符串的长度至少为 2，这确保涉及两个索引的操作始终可行。 

重要的边缘情况包括全 0 的字符串、全 1 的字符串、1 不匹配的字符串或已经相等的字符串。 

## 方法

 蛮力方法将尝试模拟所有可能的对`(i, j)`并重复执行该操作，直到`s`比赛`target`或无法取得任何进展。 这种方法理论上是正确的，但对于大的情况来说是不可行的。`n`因为可能的操作数量随字符串长度呈二次方增长，并且可能导致指数操作序列。 

最佳方法依赖于一个关键的观察：该操作允许您将“1”传播到`s`但如果不存在则无法创建新的“1”。 因此，阻止转变的唯一条件是：`target`包含“1”但是`s`没有。 相反，如果`s`至少包含一个“1”，总是可以传播和操纵它`s`匹配任何目标。 

这一见解将问题简化为简单检查是否存在至少一个“1”`s`如果`target`包含任何“1”。 不需要完整的模拟。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 模拟所有索引对的所有操作； 对于 n 达到 10^5 来说太慢 |
 | 最佳| O(n) | O(1) | O(1) | 检查中是否存在“1”`s`和`target`; 简单高效|

 ## 算法演练

 1. 扫描字符串`target`检查它是否至少包含一个“1”。 这是必要的，因为如果`target`全部为零，我们必须确保`s`也可以变成全零。 
2. 扫描字符串`s`检查它是否至少包含一个“1”。 这告诉我们是否可以将“1”传播到`s`。 
3.如果`target`包含“1”但是`s`不包含“1”，返回`false`立即，因为不可能创建新的“1”。 
4.否则返回`true`因为我们可以改变`s`进入`target`使用允许的操作。 

**为什么有效**：该操作允许通过重复 OR/XOR 更新将“1”传播到任何位置。 如果其中至少有一个“1”`s`，你最终可以达到任何配置`target`。 如果`s`没有“1”，您无法创建“1”，因此中的任何“1”`target`使转型变得不可能。 

## Python 解决方案```python
class Solution:
    def makeStringsEqual(self, s: str, target: str) -> bool:
        # Check if target has at least one '1'
        target_has_one = '1' in target
        # Check if s has at least one '1'
        s_has_one = '1' in s
        # If target has '1' but s has none, impossible
        if target_has_one and not s_has_one:
            return False
        return True
```Python实现直接实现了该算法。 它首先使用以下命令检查两个字符串中是否存在“1”`in`操作员。 如果`target`需要至少一个“1”，但是`s`没有，函数返回`False`; 否则，它返回`True`。 

## 解决方案```go
func makeStringsEqual(s string, target string) bool {
    targetHasOne := false
    sHasOne := false

    // Check target for '1'
    for i := 0; i < len(target); i++ {
        if target[i] == '1' {
            targetHasOne = true
            break
        }
    }

    // Check s for '1'
    for i := 0; i < len(s); i++ {
        if s[i] == '1' {
            sHasOne = true
            break
        }
    }

    // If target requires '1' but s has none, impossible
    if targetHasOne && !sHasOne {
        return false
    }
    return true
}
```在 Go 中，我们将字符串作为字节切片进行迭代以检查“1”。 该逻辑反映了 Python 的逻辑，但使用显式循环，因为 Go 没有内置循环`in`字符串的运算符。
