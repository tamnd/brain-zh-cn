[LeetCode 问题 2544](https://leetcode.com/problems/alternating-digit-sum/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们计算正整数的数字的交替和。 交替从最高有效数字开始，该数字始终具有正号。 接下来的每个数字都会翻转前一个数字的符号。 

例如，如果数字是`521`，计算变为：

 -`+5`-`-2`-`+1`最终的答案是`4`。 

输入是单个正整数`n`。 我们需要按从左到右的顺序检查每个数字并应用交替的符号。 输出是表示带符号和的单个整数。 

限制很小：```
1 <= n <= 10^9
```这意味着该号码最多包含 10 位数字。 即使是简单的逐位解决方案也非常快。 由于输入量很小，因此在实践中效率不是问题，但我们仍然应该设计一个干净且正确的算法。 

一个重要的细节是符号分配取决于数字从左侧开始的位置，而不是右侧。 这很重要，因为使用提取数字`% 10`自然地从右到左处理数字。 在从最低有效数字开始处理时交替符号的简单实现可能会产生不正确的结果，除非它仔细补偿方向。 

该问题保证了`n`是正数，所以我们永远不需要处理负数或空输入。 

一些重要的边缘情况包括：

 - 一位数，答案就是数字本身。 
- 位数为偶数的数字，因为最后一个符号变为负数。 
- 具有重复数字的数字，很容易意外地丢失符号交替的轨迹。 
- 以零结尾的数字，其中数字提取仍然需要保留正确的交替模式。 

## 方法

 ### 蛮力方法

 暴力解决方案将整数转换为字符串，以便我们可以直接从左到右处理数字。 我们迭代每个字符，将其转换回整数，并根据索引交替符号。 

对于索引`0`，数字被添加。 

对于索引`1`，减去该数字。 

对于索引`2`，再次添加该数字，依此类推。 

这是可行的，因为字符串表示保留了问题所需的自然从左到右的数字顺序。 

尽管这种方法对于约束来说已经足够快，但它依赖于字符串转换而不是纯算术运算。 

### 最佳方法

 更清晰的数学解决方案仍然从左到右处理数字，但使用字符串遍历或仔细算术来有效地实现这一点。 

关键的观察结果是符号完全取决于数字位置：

 - 甚至指数头寸也有积极贡献
 - 奇数指数头寸产生负面影响

 由于该数字的位数很少，因此我们可以简单地迭代一次所有数字并维护一个运行总计。 

这给出了具有恒定额外空间的简单线性解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(d) | O(d) | 将数字转换为字符串并存储数字 |
 | 最佳| O(d) | O(1) | O(1) | 单次传递带有交替符号的数字 |

 这里，`d`表示中的位数`n`。 

## 算法演练

 ### 最优算法

 1. 转换整数`n`转换为字符串表示形式，以便可以从左到右处理数字。 
2. 初始化一个名为`result`存储运行交替和。 
3. 使用索引遍历每个数字。 
4. 将当前字符转换为整数。 
5. 如果索引是偶数，则将数字添加到`result`。 

这是有效的，因为第一个数字总是有一个正号，并且之后的每个第二个数字交替变回正号。 
6. 如果索引是奇数，则减去该数字`result`。 

奇数索引数字总是带有负号。 
7.处理完所有数字后，返回`result`。 

### 为什么它有效

 该算法直接遵循问题陈述中给出的定义。 第一个数字始终相加，后面的每个数字根据其位置在减法和加法之间交替。 由于每个数字按照从左到右的顺序只处理一次，因此每个数字都会收到正确的符号，从而保证最终的总和是正确的。 

## Python 解决方案```python
class Solution:
    def alternateDigitSum(self, n: int) -> int:
        result = 0
        digits = str(n)

        for index, ch in enumerate(digits):
            digit = int(ch)

            if index % 2 == 0:
                result += digit
            else:
                result -= digit

        return result
```该实现首先将整数转换为字符串，以便可以按照正确的从左到右的顺序处理数字。 

变量`result`存储运行交替和。 循环使用`enumerate`这样我们就可以访问数字及其位置。 索引的奇偶性决定了是否应该添加或减去该数字。 

偶数索引对应于正号，而奇数索引对应于负号。 处理完所有数字后，返回最终累加值。 

## 解决方案```go
func alternateDigitSum(n int) int {
    digits := []rune(string(runeSlice(n)))
    result := 0

    for i, ch := range digits {
        digit := int(ch - '0')

        if i%2 == 0 {
            result += digit
        } else {
            result -= digit
        }
    }

    return result
}

func runeSlice(n int) []rune {
    return []rune(fmt.Sprintf("%d", n))
}
```一个更干净的 LeetCode-ready Go 实现如下所示：```go

 ## 边缘情况

 ### 个位数

 单位数是最小的有效输入。 由于最高有效数字始终带有正号，因此答案应该简单地等于数字本身。 

例如：```
n = 7
```结果是：```
+7 = 7
```该实现自然地处理了这个问题，因为循环运行一次，并且索引`0`被视为阳性。 

### 包含零的数字

 有值的数字`0`如果实现跳过它们或错误处理符号交替，有时会导致逻辑错误。 

例如：```
n = 1010
```计算公式为：```
(+1) + (-0) + (+1) + (-0)
```该算法处理零的方式与任何其他数字完全相同，因此交替模式保持正确。 

### 偶数位数

 偶数位数的数字以负贡献结尾。 这可能会暴露符号处理中的差一错误。 

例如：```
n = 1234
```计算变为：```
(+1) + (-2) + (+3) + (-4) = -2
```该实现正确地使用索引奇偶校验，确保符号正确交替，而不管位数总数如何。
