[LeetCode 问题 2510](https://leetcode.com/problems/check-if-there-is-a-path-with-equal-number-of-0s-and-1s/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 本题要求我们判断二值矩阵中是否存在从左上角开始的路径`(0, 0)`到右下角`(m - 1, n - 1)`使得数量`0`沿路径访问的 s 等于`1`s。 矩阵是**二元**，因此每个单元格包含`0`或者`1`。 移动仅限于**向下**或**向右**，这定义了可能的路径。 

输入是一个二维列表`grid`尺寸`m x n`， 在哪里`2 <= m, n <= 100`。 输出是一个布尔值：`True`如果存在有效路径，`False`否则。 

重要的考虑因素包括：

 1. 路径不能对角或向后移动，限制了搜索空间，但对于暴力解决方案来说，其大小仍然可能呈指数级增长。 
2. 矩阵大小适中（最多`100 x 100`），这会阻止天真的 DFS 探索所有路径而不进行修剪。 
3.既然我们正在数`0`沙`1`s，沿路径的计数之间的差异是要跟踪的重要状态。 

可能会导致幼稚实现失败的边缘情况包括单元格总数为奇数的网格（不可能在单元格之间平均分配）`0`沙`1`s)，或移动受到限制以致无法实现某些计数的网格。 

## 方法

 ### 蛮力方法

 蛮力方法探索所有可能的路径`(0, 0)`到`(m - 1, n - 1)`递归地。 在每一步中，我们都会跟踪数量`0`沙`1`到目前为止已访问过。 当我们到达目的地时，我们检查计数是否相等。 虽然这保证了正确性，但它具有指数时间复杂度`O(2^(m+n))`因为每个细胞都可以向两个方向分支。 它还需要维护每个路径的状态，导致内存使用率很高。 

### 最佳方法

 关键的见解是，该问题可以转化为**动态规划**问题，其中状态为`(row, col, diff)`， 和`diff = count_of_ones - count_of_zeros`。 在每个单元中，我们只需要跟踪沿着通往该单元的任何路径实现了哪些差异。 通过使用传播这些差异`set`每个单元，我们可以有效地避免探索相同的冗余路径`diff`。 这显着减少了搜索空间，因为`diff`的边界是`-(m*n)`到`m*n`，但实际上，当我们向下或向右移动时，只有可行的差异才重要。 

方法比较：

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(m+n) 递归深度 | 递归地探索所有路径； 对于 m、n 至 100 来说太慢 |
 | 最佳| O(m * n * 分钟(m*n，total_diff_range)) | O(m * n * possible_diffs) | 使用集合动态规划来跟踪差异 |

 ## 算法演练

 1. 初始化一个2D数组`dp`尺寸的`m x n`其中每个元素都是一个存储可能的集合`diff`该单元格的值。 
2. 在`(0, 0)`, 初始化`diff = 1`如果`grid[0][0] == 1`别的`-1`。 
3. 迭代每个单元格`(i, j)`在矩阵中逐行：

 - 对于每一个可能的`diff`在`dp[i-1][j]`（从顶部）或`dp[i][j-1]`（从左起），计算新的`diff`通过添加`1`如果`grid[i][j] == 1`或者`-1`如果`0`。 
- 添加新的`diff`到`dp[i][j]`。 
4. 填写DP表后，检查是否`0`存在于`dp[m-1][n-1]`。 如果是，则存在一条路径的数量相等`0`沙`1`s。 
5. 返回`True`如果`0`存在，`False`否则。 

为什么它有效：通过传播所有可行的差异（`count_ones - count_zeros`）通过 DP 表，我们确保考虑所有可能的路径，而无需重新访问相同的状态。 不变的是`dp[i][j]`始终包含通过到达该单元格的某些路径可实现的所有差异。 

## Python 解决方案```python
from typing import List

class Solution:
    def isThereAPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        dp = [[set() for _ in range(n)] for _ in range(m)]
        dp[0][0].add(1 if grid[0][0] == 1 else -1)
        
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                current_set = set()
                if i > 0:
                    for diff in dp[i-1][j]:
                        current_set.add(diff + (1 if grid[i][j] == 1 else -1))
                if j > 0:
                    for diff in dp[i][j-1]:
                        current_set.add(diff + (1 if grid[i][j] == 1 else -1))
                dp[i][j] = current_set
        
        return 0 in dp[m-1][n-1]
```说明： 该代码初始化一个 DP 集合表来存储每个单元格的差异。 我们迭代矩阵并传播顶部和左侧邻居的差异，更新当前单元格的集合。 最后，我们检查是否`0`可以到达目的地。 

## 解决方案```go
func isThereAPath(grid [][]int) bool {
    m, n := len(grid), len(grid[0])
    dp := make([][]map[int]struct{}, m)
    for i := 0; i < m; i++ {
        dp[i] = make([]map[int]struct{}, n)
        for j := 0; j < n; j++ {
            dp[i][j] = make(map[int]struct{})
        }
    }

    startDiff := -1
    if grid[0][0] == 1 {
        startDiff = 1
    }
    dp[0][0][startDiff] = struct{}{}

    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if i == 0 && j == 0 {
                continue
            }
            currSet := make(map[int]struct{})
            if i > 0 {
                for diff := range dp[i-1][j] {
                    newDiff := diff
                    if grid[i][j] == 1 {
                        newDiff += 1
                    } else {
                        newDiff -= 1
                    }
                    currSet[newDiff] = struct{}{}
                }
            }
            if j > 0 {
                for diff := range dp[i][j-1] {
                    newDiff := diff
                    if grid[i][j] == 1 {
                        newDiff += 1
                    } else {
                        newDiff -= 1
                    }
                    currSet[newDiff] = struct{}{}
                }
            }
            dp[i][j] = currSet
        }
    }

    _, exists := dp[m-1][n-1][0]
    return exists
}
```Go 特定注释：我们使用`map[int]struct{}`模仿集合，因为 Go 没有原生集合类型。 Struct{} 用作节省内存的占位符。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(m * n * D) | D 是单元中可实现差异的最大范围，以 m*n | 为界

 动态规划方法通过仅跟踪可实现的差异，将指数搜索空间缩减为多项式时间算法。
