[LeetCode 问题 2508](https://leetcode.com/problems/add-edges-to-make- Degrees-of-all-nodes-even/)

 **难度：** 🔴难
 **主题：** 哈希表、图论

 ## 解决方案

 ## 问题理解

 该问题为我们提供了一个无向图`n`节点和边列表。 每条边连接两个不同的节点，并且该图可能包含多个断开连接的组件。 

我们的任务是确定是否可以添加最多两条新边，以便图中的每个节点最终都具有偶数度。 节点的度就是与其连接的边的数量。 

有几个重要的限制：

 - 我们无法添加自循环，这意味着我们无法将节点连接到自身。 
- 我们不能添加重复的边，这意味着如果两个节点之间已经存在一条边，我们不能再次添加它。 
- 我们可以添加零、一条或两条边。 

输出是一个布尔值：

 - 返回`true`是否可以使所有节点度数相等。 
- 返回`false`否则。 

限制条件很大：

 - 最多`10^5`节点
 - 最多`10^5`边缘

 这立即告诉我们，任何涉及详尽的图修改或所有边组合的强力测试的解决方案都将太慢。 我们需要一种接近线性时间的方法。 

图论的一个关键属性是，任何无向图中具有奇数度的节点数量始终是偶数。 这一事实非常重要，因为它极大地限制了我们需要考虑的可能情况。 

重要的边缘情况包括：

 - 该图可能已经具有所有偶数度，在这种情况下答案是立即`true`。 
- 可能恰好有两个奇数度节点。 
- 可能正好有四个奇数度节点。 
- 可能有超过四个奇数度节点，仅添加两条边是不可能修复的。 
- 一些必需的边可能已经存在，从而阻止我们使用其他有效的配对。 
- 图表可能会断开连接，但连通性对于度数奇偶性并不重要。 

## 方法

 ### 蛮力方法

 暴力解决方案将尝试每组最多两个附加边，并检查所有节点度数之后是否变得均匀。 

为此，我们可以：

 1. 枚举每一个可能的边`(u, v)`在哪里`u != v`并且边缘尚不存在。 
2. 尝试：

 - 不添加边缘
 - 添加一条边
 - 添加每对可能的边
 3. 每次尝试后，重新计算节点度并验证是否全部为偶数。 

这种方法是正确的，因为它明确地检查所有有效的可能性。 然而，它太慢了。 

最多有`O(n^2)`可能的边缘。 尝试所有的边对需要`O(n^4)`最坏情况下的组合，这是不可能的`n = 10^5`。 

### 最佳观察

 关键的观察来自图奇偶性。 

添加一条边会更改恰好两个节点的奇偶校验，因为两个端点度数都会增加 1。 

这意味着：

 - 添加的一条边可以恰好固定两个奇数度节点。 
- 添加的两条边最多可以固定四个奇数度节点。 

因此：

 - 如果图有四个以上奇数度节点，则答案是立即`false`。 
- 我们只需要处理奇数度节点数量为的情况：

 -`0`-`2`-`4`这极大地简化了问题。 

我们使用邻接集存储图，这样我们就可以快速确定边是否已经存在。 

然后我们分析奇数度节点：

 -`0`奇数节点 → 已经有效
 -`2`奇数节点→直接连接它们，或者通过中间节点连接它们
 -`4`奇数节点 → 测试所有配对

 这导致了有效的线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(n^2) | O(n^2) | 尝试所有可能的添加边缘组合 |
 | 最佳| O(n + m) | O(n + m) | 使用奇次宇称观测值 |

 ## 算法演练

 ### 第 1 步：构建图表

 创建：

 - 用于跟踪节点度数的度数数组
 - 为每个节点设置邻接集，以允许恒定时间边缘存在检查

 对于每一个边缘`(u, v)`：

 - 增量`degree[u]`- 增量`degree[v]`- 将每个节点添加到另一个节点的邻接集中

 我们使用集合是因为检查一条边是否已经存在必须是高效的。 

### 步骤 2：收集奇数度节点

 遍历所有节点`1`到`n`。 

如果`degree[node] % 2 == 1`，将节点添加到`odd_nodes`列表。 

由于图论特性，奇数度节点的数量始终是偶数。 

### 步骤 3：处理零奇数节点的情况

 如果没有奇数度节点，则每个节点都已经具有偶数度。 

返回`true`。 

### 步骤 4：处理两个奇数节点的情况

 假设奇数节点是`a`和`b`。 

有两种可能：

 1. 直接连接
 2.通过中间节点连接

 #### 直接连接

 如果边缘`(a, b)`尚不存在，我们可以添加它。 

两个度数都变得均匀，所以返回`true`。 

#### 中间节点

 如果`(a, b)`已经存在，我们无法再次添加。 

相反，尝试找到一些节点`x`这样：

 -`(a, x)`不存在
 -`(b, x)`不存在

 然后我们可以添加：

 -`(a, x)`-`(b, x)`这会翻转所有三个相关节点的奇偶校验：

 -`a`变得均匀
 -`b`变得均匀
 -`x`改变两次，所以它保持均匀

 如果存在这样的节点，则返回`true`。 

否则返回`false`。 

### 步骤 5：处理四个奇数节点的情况

 假设奇数节点是：`a, b, c, d`我们只能使用两条边，因此必须将它们配对。 

恰好有三种可能的配对：

 1.`(a, b)`和`(c, d)`2.`(a, c)`和`(b, d)`3.`(a, d)`和`(b, c)`对于每个配对：

 - 检查两条边是否尚不存在
 - 如果两者都有效，则返回`true`如果不起作用，则返回`false`。 

### 步骤 6：处理四个以上的奇数节点

 如果图的奇数度节点超过四个，则两条边是不够的。 

返回`false`。 

### 为什么它有效

 该算法之所以有效，是因为每个添加的边都会翻转恰好两个节点的奇偶校验。 

因此：

 - 两个奇数节点可以用一条边固定。 
- 四个奇数节点可以用两条边固定。 
- 仅用两条边不可能固定四个以上的奇数节点。 

该算法详尽地检查所有有效的奇偶校验固定配置，同时遵守禁止重复边缘的约束。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def isPossible(self, n: int, edges: List[List[int]]) -> bool:
        graph = defaultdict(set)
        degree = [0] * (n + 1)

        for u, v in edges:
            graph[u].add(v)
            graph[v].add(u)
            degree[u] += 1
            degree[v] += 1

        odd_nodes = []

        for node in range(1, n + 1):
            if degree[node] % 2 == 1:
                odd_nodes.append(node)

        if len(odd_nodes) == 0:
            return True

        if len(odd_nodes) == 2:
            a, b = odd_nodes

            if b not in graph[a]:
                return True

            for node in range(1, n + 1):
                if (
                    node != a
                    and node != b
                    and node not in graph[a]
                    and node not in graph[b]
                ):
                    return True

            return False

        if len(odd_nodes) == 4:
            a, b, c, d = odd_nodes

            pairings = [
                ((a, b), (c, d)),
                ((a, c), (b, d)),
                ((a, d), (b, c)),
            ]

            for (u1, v1), (u2, v2) in pairings:
                if v1 not in graph[u1] and v2 not in graph[u2]:
                    return True

            return False

        return False
```实现首先构建图的邻接集表示。 这允许恒定时间检查边缘是否已经存在，这是至关重要的，因为重复的边缘是被禁止的。 

这`degree`数组在处理边时跟踪每个节点的度数。 构建图后，我们将所有奇数度节点收集到`odd_nodes`。 

然后，解决方案根据奇数度节点的数量进行分支。 

如果奇数节点为零，则该图已满足要求。 

如果有两个奇数节点，则实现首先检查它们是否可以直接连接。 如果没有，它将搜索可以连接到两个奇数节点而不违反边缘约束的中间节点。 

如果有四个奇数节点，则实现会测试三种可能的配对。 

任何具有超过四个奇数度节点的情况都是立即不可能的。 

## 解决方案```go
package main

func isPossible(n int, edges [][]int) bool {
	graph := make([]map[int]bool, n+1)
	degree := make([]int, n+1)

	for i := 1; i <= n; i++ {
		graph[i] = make(map[int]bool)
	}

	for _, edge := range edges {
		u := edge[0]
		v := edge[1]

		graph[u][v] = true
		graph[v][u] = true

		degree[u]++
		degree[v]++
	}

	oddNodes := []int{}

	for node := 1; node <= n; node++ {
		if degree[node]%2 == 1 {
			oddNodes = append(oddNodes, node)
		}
	}

	if len(oddNodes) == 0 {
		return true
	}

	if len(oddNodes) == 2 {
		a := oddNodes[0]
		b := oddNodes[1]

		if !graph[a][b] {
			return true
		}

		for node := 1; node <= n; node++ {
			if node != a &&
				node != b &&
				!graph[a][node] &&
				!graph[b][node] {
				return true
			}
		}

		return false
	}

	if len(oddNodes) == 4 {
		a := oddNodes[0]
		b := oddNodes[1]
		c := oddNodes[2]
		d := oddNodes[3]

		pairings := [][][]int{
			{{a, b}, {c, d}},
			{{a, c}, {b, d}},
			{{a, d}, {b, c}},
		}

		for _, pairing := range pairings {
			u1 := pairing[0][0]
			v1 := pairing[0][1]

			u2 := pairing[1][0]
			v2 := pairing[1][1]

			if !graph[u1][v1] && !graph[u2][v2] {
				return true
			}
		}

		return false
	}

	return false
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 主要区别在于图形表示。 

Go 使用的不是 Python 集合`map[int]bool`用于邻接检查。 这提供了有效的恒定时间查找来确定边缘是否已经存在。 

切片用于存储奇数度节点和候选配对。 由于所有值都适合标准整数范围，因此不必担心整数溢出。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + m) | 构建图并扫描节点一次 |
 | 空间| O(n + m) | 邻接集存储所有边 |

 图构造对每条边恰好处理一次，给出`O(m)`工作。 扫描所有节点的奇数度数成本`O(n)`。 

其余逻辑最多处理四个奇数节点，因此这些检查是恒定时间，除了两个奇数节点情况下的中间节点搜索（它扫描所有节点一次）之外。 因此，总复杂度保持线性。 

邻接集要求`O(m)`存储，度数组需要`O(n)`空间。

 ## 边缘情况

 ### 图的度数已全部为偶数

 一个常见的错误是忘记允许添加零边。 如果每个节点的度数都是偶数，则正确答案是`true`。 

实现通过检查来处理这个问题：```
if len(odd_nodes) == 0:
    return True
```这样可以避免不必要的处理并确保正确性。 

### 两个奇数节点已连接

 假设该图恰好有两个奇数度节点，但它们已经共享一条边。 幼稚的实现可能会错误地假设该图是不可能的。 

但是，我们仍然可以使用中间节点来修复图。 

例如：```
a -- b
```如果存在一个节点`x`两者都没有边缘`a`或者`b`，我们可以添加：```
(a, x)
(b, x)
```该实现显式搜索这样的节点。 

### 四个具有阻塞配对的奇数节点

 当存在四个奇数节点，但一些所需的配对边已经存在时，会发生另一种微妙的情况。 

由于禁止重复边，因此并非每个配对都是有效的。 

该实现会仔细测试所有三种可能的配对，并在接受配置之前验证两条边均不存在。 

即使在许多候选边不可用的密集图中，这也保证了正确性。
