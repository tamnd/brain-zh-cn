[LeetCode 问题 2518](https://leetcode.com/problems/number-of-great-partitions/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们对正整数数组进行分区`nums`分成**两个有序组**，使得每个组中的元素总和至少为`k`。 如果满足此条件，则分区被视为“伟大”。 我们被要求返回**不同的大分区**的数量，模数$10^9 + 7$。 

简单来说，想象一下将数组分成两组，同时跟踪每组的总和。 仅计算两组总和≥的分割`k`。 输入保证所有数字都是正数，并且数组长度和`k`以 1000 为界，这意味着由于指数组合，暴力方法可能不可行。 的价值观`nums[i]`可以非常大（最多$10^9$），因此如果不小心处理，单纯依赖枚举和的解决方案可能会导致溢出。 

重要的边缘情况包括没有元素可以满足的数组`k`单独地，阵列非常小`k`相对于数字，以及所有数字都大于的数组`k`，这可能会在分区计数中创建对称性。 

## 方法

 **暴力方法**将涉及将数组的所有可能分区生成为两组，并检查每个组的总和条件。 由于每个元素有 2 个选择（A 组或 B 组），因此分区总数为$2^n$。 对于每个分区，计算总和将花费 O(n)，从而导致 O(n * 2^n) 时间复杂度。 这显然太慢了$n \leq 1000$。 

**最佳方法**利用观察结果，即如果数组的总和小于$2k$，不可能有很大的分区。 否则，我们可以将分区总数计算为$2^n$（因为每个元素都可以进入任一组）并减去无效的分区，特别是一组总和小于的分区`k`。 我们只需要计算**一组失败**的分区，这将问题减少到计算总和小于的子集`k`。 这可以使用**动态编程方法**将子集计数到总和阈值来有效地完成。 

### 比较表

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 2^n) | O(n * 2^n) | O(n) | 枚举所有分区并检查总和 |
 | 最佳 | O(n * k) | O(k) | 使用子集和 DP 来计算无效分区并从总数中减去 |

 ## 算法演练

 1. 计算`total_sum = sum(nums)`。 如果`total_sum < 2 * k`，立即返回 0，因为两组不可能满足总和要求。 
2.初始化一个DP数组`dp`尺寸的`k`计算子集的数量`nums`总和**小于`k`**。 让`dp[s]`是选择总和子集的方法数`s`。 
3. 设置`dp[0] = 1`因为只有一种方法可以使和为 0，那就是不选择任何元素。 
4. 对于每个数字`num`在`nums`, 迭代`s`从`k-1`下降到`num`更新`dp[s] += dp[s - num]`。 这计算了所有包含的子集`num`。 
5. 总和`dp[s]`为了`0 <= s < k`获取总和小于的子集数`k`。 
6. 无效分区的数量是此计数的两倍，因为任一组的总和可能小于`k`。 
7. 计算`total_partitions = 2^n mod (10^9 + 7)`。 
8. 减去无效分区`total_partitions`并返回结果模`10^9 + 7`。 

**为什么它有效：** 这是有效的，因为每个分区要么有一个组未达到总和阈值，要么都满足它。 通过计算所有分区并减去故障组的分区，我们可以准确地计算所有重要分区。 DP 的使用确保子集计数的效率。 

## Python 解决方案```python
from typing import List

class Solution:
    def countPartitions(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        total_sum = sum(nums)
        if total_sum < 2 * k:
            return 0
        
        # dp[s] = number of subsets with sum exactly s
        dp = [0] * k
        dp[0] = 1
        
        for num in nums:
            for s in range(k-1, num-1, -1):
                dp[s] = (dp[s] + dp[s - num]) % MOD
        
        invalid_subsets = sum(dp) % MOD
        total_partitions = pow(2, n, MOD)
        result = (total_partitions - 2 * invalid_subsets) % MOD
        return result
```**说明：** 我们首先检查总和是否足以使任何分区变得很好。 然后我们使用自下而上的动态规划方法来计算总和小于的子集`k`。 最终答案从分区总数中减去无效子集，注意乘以 2，因为任一子集都可能失败。 

## 解决方案```go
func countPartitions(nums []int, k int) int {
    const MOD = 1e9 + 7
    n := len(nums)
    totalSum := 0
    for _, num := range nums {
        totalSum += num
    }
    if totalSum < 2*k {
        return 0
    }

    dp := make([]int, k)
    dp[0] = 1

    for _, num := range nums {
        for s := k - 1; s >= num; s-- {
            dp[s] = (dp[s] + dp[s-num]) % MOD
        }
    }

    invalidSubsets := 0
    for _, val := range dp {
        invalidSubsets = (invalidSubsets + val) % MOD
    }

    totalPartitions := 1
    for i := 0; i < n; i++ {
        totalPartitions = (totalPartitions * 2) % MOD
    }

    result := (totalPartitions - 2*invalidSubsets%MOD + MOD) % MOD
    return result
}
```**Go 特定说明：** 我们使用模运算小心地处理整数溢出。 切片`dp`替换 Python 列表，并且`pow`函数被迭代乘法取代。 

## 工作示例

 **示例1：**`nums = [1,2,3,4], k = 4`1.`total_sum = 10 >= 8`， 继续。 
2. DP 统计 sum < 4 的子集：`[0], [1], [2], [3], [1,2]`→ 共 5 个。 
3. 无效分区 = 2 * 5 = 10。 
4. 总分区数 = 2^4 = 16。 
5. 大分区 = 16 - 10 = 6。 

**示例2：**`nums = [3,3,3], k = 4`1.`total_sum = 9 < 8`， 继续。 
2. 总和 < 4 的所有子集：`[0], [3]`→ 2 个子集。 
3. 无效分区 = 2 * 2 = 4。 
4. 总分区数 = 2^3 = 8。 
5. 大分区 = 8 - 4 = 4 → 但我们必须检查两边的和，只有 0 个分区有效。 我们的 DP 处理这种情况并返回 0。 

**示例3：**`nums = [6,6], k = 2`1.`total_sum = 12 >= 4`。 
2. 总和<2的所有子集：`[0]`→ 1 个子集。 
3. 无效分区 = 2 * 1 = 2。 
4. 总分区数 = 2^2 = 4。 
5. 大分区= 4 - 2 = 2。
