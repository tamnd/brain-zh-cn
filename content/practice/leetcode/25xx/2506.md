[LeetCode 问题 2506](https://leetcode.com/problems/count-pairs-of-similar-strings/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串、位操作、计数

 ## 解决方案

 ## 问题理解

 该问题给了我们一个名为的字符串数组`words`。 我们必须计算有多少对索引`(i, j)`满足两个条件：

 -`i < j`-`words[i]`和`words[j]`相似

 如果两个字符串包含完全相同的一组不同字符，则认为它们相似，无论顺序或频率如何。 

例如：

-`"aba"`和`"aabb"`是相似的，因为两者都只包含`'a'`和`'b'`-`"abc"`和`"cba"`相似，因为两者都包含`'a'`,`'b'`， 和`'c'`-`"abc"`和`"abd"`不相似，因为其中包含`'c'`而另一个包含`'d'`关键细节是字符频率并不重要。 只有角色的存在或不存在才重要。 

输入尺寸相对较小：

 - 最多`100`话
 - 每个单词长度可达`100`- 仅限小写英文字母

 这些约束告诉我们，即使是二次解也是可以接受的，因为`100 × 100 = 10,000`比较量很小。 然而，我们仍然可以使用位操作和哈希来设计更干净、更有效的解决方案。 

一个重要的观察是每个单词都可以由它包含的字符集表示。 由于只有 26 个小写字母，我们可以将这个集合编码为 26 位整数掩码。 

一些边缘情况很重要：

 - 多个相同的单词
 - 带有重复字符的单词，例如`"aaaa"`- 单字词
 - 根本没有相似的配对
 - 每个单词都与其他单词相似

 该问题保证所有字符串仅包含小写英文字母，这使得位掩码编码简单且高效。 

## 方法

 ### 蛮力方法

 最直接的解决方案是比较每对单词。 

对于每对`(i, j)`：

 1. 将两个单词转换为不同字符集
 2. 比较两组
 3. 如果相等，则增加答案

 这是有效的，因为当两个字符串的不同字符集匹配时，它们完全相同。 

例如：

-`"aabb"`变成`{'a', 'b'}`-`"ba"`变成`{'a', 'b'}`由于集合相等，因此对进行计数。 

虽然这个解决方案简单且正确，但它会重复重建字符集以进行多次比较。 和`n`单词和单词长度`m`，与基于哈希的分组解决方案相比，复杂性变得低效。 

### 最佳方法

 关键的见解是相似性仅取决于不同字符的集合。 

我们可以：

 1. 将每个单词转换为紧凑的表示形式
 2. 将相同的表示分组在一起
 3. 计算每组内可以组成多少对

 位掩码是这里的完美表示。 

我们使用 26 位整数，其中：

 - 位`0`代表`'a'`- 少量`1`代表`'b'`- ...
- 少量`25`代表`'z'`对于单词中的每个字符，我们设置相应的位。 

例子：

-`"aba"`生产面膜：

 -`'a'`→ 位 0
 -`'b'`→ 位 1
 - 面具=`000...011`-`"aabb"`生产完全相同的掩模

 一旦我们计算出每个单词的掩码，我们就将频率存储在哈希图中。 

如果面具出现了`k`times 已经，当前的单词形式`k`新的相似对。 

这避免了不必要的成对比较，并提供了干净的线性解决方案。

 ## 算法演练

 ### 最优算法

 1. 创建一个空的哈希映射，名为`mask_count`。 

键将是表示字符集的位掩码，值将是产生该掩码的先前单词数。 
2. 初始化`pairs = 0`。 

该变量存储相似对的总数。 
3. 迭代中的每个单词`words`。 

对于每个单词，计算其位掩码表示。 
4. 构建位掩码。 

开始于`mask = 0`。 

对于每个角色`c`在这个词中：

 - 计算其位置：```
ord(c) - ord('a')
```- 设置相应位：```
mask |= (1 << position)
```重复的字符并不重要，因为设置一个已经设置的位不会改变任何内容。 
5. 计算之前见过的匹配蒙版。 

如果这个掩码已经存在于`mask_count`，那么之前的每个出现都与当前单词形成有效的对。 

添加：```
mask_count[mask]
```到`pairs`。 
6.更新频率图。 

增量：```
mask_count[mask]
```7.处理完所有单词后，返回`pairs`。 

### 为什么它有效

 当且仅当两个单词包含相同的不同字符时，它们才是相似的。 

位掩码唯一地表示单词中的字符集。 因此：

 - 相似的词总是产生相同的面具
 - 不相似的词总是产生不同的面具

 通过对具有相同掩码的单词进行分组，我们可以准确计算有效的相似对。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def similarPairs(self, words: List[str]) -> int:
        mask_count = defaultdict(int)
        pairs = 0

        for word in words:
            mask = 0

            for char in word:
                bit_position = ord(char) - ord('a')
                mask |= (1 << bit_position)

            pairs += mask_count[mask]
            mask_count[mask] += 1

        return pairs
```该解决方案使用哈希映射按字符集位掩码对单词进行分组。 

变量`mask`开始于`0`对于每个单词。 每个字符在整数中设置一位。 由于重复的字母再次设置相同的位，因此重复的字母自然会从表示中消失。 

字典`mask_count`跟踪每个蒙版之前出现的次数。 在插入当前掩码之前，我们将现有频率添加到`pairs`，因为具有相同掩码的每个较早单词与当前单词形成有效对。 

这使得解决方案能够在一次遍历数组的过程中增量地对对进行计数。 

## 解决方案```go
func similarPairs(words []string) int {
	maskCount := make(map[int]int)
	pairs := 0

	for _, word := range words {
		mask := 0

		for _, ch := range word {
			bitPosition := int(ch - 'a')
			mask |= (1 << bitPosition)
		}

		pairs += maskCount[mask]
		maskCount[mask]++
	}

	return pairs
}
```Go 实现遵循与 Python 版本相同的逻辑。 

一个`map[int]int`用来代替Python的字典。 由于掩码正好适合标准整数，因此不需要特殊的溢出处理。 

Go 使用以下命令迭代字符串字符`range`，它返回 Unicode 符文。 由于输入保证小写英文字母，因此减去`'a'`安全地计算位位置。

 ## 边缘情况

 ### 含有重复字符的单词

 一个常见的错误是将字符频率视为重要的。 例如，`"aaaa"`和`"a"`应该被认为是相似的，因为两者都只包含字符`'a'`。 

位掩码方法可以自然地处理这个问题。 多次设置同一位不会更改掩码，因此重复的字母将被自动忽略。 

### 所有单词都是相似的

 如果每个单词都包含相同的字符集，则对的数量会快速增长。 

例如：```
["ab", "ba", "aabb", "baba"]
```所有四个字都映射到相同的位掩码。 正确答案是：```
4 choose 2 = 6
```该实现通过每次出现匹配掩码时添加现有频率来正确地增量累积对。 

### 没有相似的词

 另一个重要的边缘情况是每个单词都有唯一的字符集。 

例子：```
["a", "ab", "abc", "abcd"]
```每个单词都会生成不同的掩码，因此不应计算任何对。 

哈希映射查找对于每个新掩码返回零，确保最终答案保持正确。 

### 单字输入

 如果数组仅包含一个单词，则不存在有效的对，因为对需要两个不同的索引。 

该算法会自动处理此问题，因为频率图最初是空的，因此在处理过程中不会添加任何对。
