[LeetCode 问题 2557](https://leetcode.com/problems/maximum-number-of-integers-to-choose-from-a-range-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、二分搜索、贪心、排序

 ## 解决方案

 ## 问题理解

 问题是要求从范围中选择最大数量的整数`[1, n]`在多重限制下。 首先，整数`banned`无法选择数组。 其次，每个整数最多只能选择一次。 第三，所有选定整数的总和不得超过`maxSum`。 目标是确定满足所有这些条件的最大可能整数个数。 

输入由三个主要部分组成：`banned`，无法选择的整数数组；`n`，设置可选整数的上限； 和`maxSum`，它限制了所选数字的总和。 输出是一个整数，表示有效整数的最大计数。 

约束为我们提供了重要的见解。 长度为`banned`可以达到`10^5`，值`n`可以达到`10^9`， 和`maxSum`可以大到`10^15`。 这表明一种简单的方法是从`1`到`n`由于可能的值很大，检查条件将效率低下`n`。 该问题保证正整数，因此我们不必处理零或负数，但我们确实需要处理可能非常大的总和和范围。 

需要考虑的边缘情况包括：`banned`包含所有小数字，`maxSum`相对于非常小`n`，或`banned`列表为空。 这些边缘情况可能会影响正确性和效率。 

## 方法

 一种蛮力方法是迭代每个数字`1`到`n`，检查是否被禁止，添加后是否保持总和如下`maxSum`。 如果两个条件都满足，则将其包含在结果中。 这种方法是正确的，因为它按顺序检查所有可能性，但它在计算上是不可行的，因为迭代到`10^9`太慢了。 

最佳方法利用了最小的非禁止整数对总和的贡献最小这一事实。 因此，如果我们对非禁止整数进行排序，并从最小到最大贪婪地选择它们，直到添加下一个将超过`maxSum`，我们将最大化计数。 对禁止号码使用哈希集允许 O(1) 查找，并且仅对非禁止号码进行迭代，直到`n`或总和超过的点`maxSum`保持算法的效率。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(b) | 迭代所有数字直到 n，每次都检查禁止列表 |
 | 最佳| O(b + k) | O(b + k) | O(b) | 使用哈希集进行禁止，迭代有效数字，直到达到 maxSum，其中 k 是实际选择的数字数量 |

 ## 算法演练

 1. 转换`banned`数组转换为哈希集以进行 O(1) 成员资格检查。 这避免了重复的线性搜索。 
2. 初始化`current_sum`为零和`count`为零。 这些将分别跟踪所选数字的总和以及所选整数的数量。 
3. 迭代整数`i`从 1 到`n`按升序排列。 我们从 1 开始，因为较小的数字允许我们在总和约束下最大化计数。 
4. 对于每个整数，检查它是否在禁止集中。 如果被禁止，请跳过。 
5.如果没有禁止，检查是否添加到`current_sum`会超过`maxSum`。 如果是，请停止迭代，因为任何更大的数字只会进一步增加总和。 
6. 如果添加数量不超过`maxSum`, 增量`count`并将数字添加到`current_sum`。 
7. 继续，直到所有数字达到`n`已处理或达到总和限制。 
8. 返回`count`作为可以选择的最大整数数。 

该算法之所以有效，是因为它总是首先选择最小的可用数字。 由于总和约束是加性的并且所有数字都是正数，因此首先选择较小的数字可确保总和在计数方面最大化。 使用哈希集可保证 O(1) 查找以避免禁止号码。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxCount(self, banned: List[int], n: int, maxSum: int) -> int:
        banned_set = set(banned)
        current_sum = 0
        count = 0
        
        for i in range(1, n + 1):
            if i in banned_set:
                continue
            if current_sum + i > maxSum:
                break
            current_sum += i
            count += 1
        
        return count
```Python 实现首先将`banned`列表到一个集合中以便快速查找。 它初始化两个变量，`current_sum`和`count`。 然后它迭代从 1 到`n`。 如果某个号码被禁止，则会跳过该号码。 如果相加的数量超过`maxSum`，循环提前中断。 否则，将该数字添加到总和中并递增计数。 最后，`count`作为结果返回。 

## 解决方案```go
func maxCount(banned []int, n int, maxSum int64) int {
    bannedSet := make(map[int]struct{})
    for _, num := range banned {
        bannedSet[num] = struct{}{}
    }
    
    var currentSum int64 = 0
    count := 0
    
    for i := 1; i <= n; i++ {
        if _, exists := bannedSet[i]; exists {
            continue
        }
        if currentSum+int64(i) > maxSum {
            break
        }
        currentSum += int64(i)
        count++
    }
    
    return count
}
```Go 实现反映了 Python 解决方案。 它使用一个`map[int]struct{}`作为存储禁止号码的集合。 变量`currentSum`和`count`被初始化以跟踪所选整数的总和和数量。 整数的迭代是从 1 到`n`。 类型`int64`用于求和以防止溢出，因为`maxSum`可以非常大。
