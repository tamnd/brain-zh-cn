 **难度：** 🔴难
 **主题：** 数组、哈希表、数学、堆栈、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们计算所有长度连续的子数组中的**最大频率得分**`k`从给定的整数数组`nums`。 频率分数定义为子数组中每个不同元素的频率之和，取模`10^9 + 7`。 例如，对于数组`[5,4,5,7,4,4]`，每个不同元素的频率是`{5:2, 4:3, 7:1}`，因此得分计算为`5^2 + 4^3 + 7^1 = 25 + 64 + 7 = 96`模数`10^9 + 7`。 

输入包括：

 -`nums`：整数数组，其中`1 <= nums[i] <= 10^6`。 
-`k`：子数组的大小，保证满足`1 <= k <= len(nums)`。 

The expected output is a single integer representing the **maximum frequency score** among all subarrays of size`k`。 

限制和影响：

 - 数组长度可以大到`10^5`，这排除了任何检查所有内容的暴力解决方案`O(n*k)`的可能性。 
- 值在`nums`可以高达`10^6`，这意味着没有模运算的简单求幂可能会溢出。 
- 每个子数组都是连续的，因此滑动窗口方法是自然的选择。 

重要的边缘情况包括：

 1. 所有元素都是相同的，例如，`nums = [1,1,1]`。 每个子数组将具有相同的分数。 
2. 最大子数组大小，`k = len(nums)`。 仅存在一个子数组。 
3. 频率高或数值大的元素，测试模幂。 

## 方法

 **暴力方法**将涉及生成所有可能的大小子数组`k`，计算每个不同元素的频率，计算频率分数，并返回最大值。 这工作正常但效率低下，因为对于每个`O(n)`子数组、计数频率和计算幂可能需要长达`O(k)`， 导致`O(n*k)`时间，这对于`n = 10^5`。 

**最佳方法**利用带有频率图的滑动窗口。 当我们将窗口移动一个元素时：

 1. 从频率图中删除离开窗口的元素。 
2. 将进入窗口的元素添加到频数图中。 
3. 增量更新频率分数，而不是从头开始重新计算。 

关键的见解是可以使用幂的属性来增量更新模幂。 具体来说，当元素的频率从`f`到`f+1`，对总和的贡献从`x^f`到`x^(f+1)`。 使用模运算，我们可以有效地计算它。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n*k) | O(n*k) | O(k) | 计算大小为 k 的每个子数组的频率得分 |
 | 最佳 | O(n*log k) | O(n*log k) | O(k) | 具有频率图和增量模幂的滑动窗口 |

 ## 算法演练

 1.初始化一个频数图，统计当前大小窗口中每个元素的出现次数`k`。 
2. 通过将每个不同元素提升到其频率模数来计算第一个窗口的初始频率得分`10^9 + 7`。 
3. Set a variable`max_score`到这个初始分数。 
4. 将窗口从左向右滑动一个元素：

 - 减少元素离开窗口的频率。 通过减去之前的贡献并加上新的贡献来更新分数。 
- 增加元素进入窗口的频率。 类似地更新分数。 
5. 更新每个新窗口的分数后，将其与`max_score`并更新`max_score`如果新的分数更高。 
6. 继续直到所有子数组的大小`k`已被评估。 
7. 返回`max_score`。 

工作原理：滑动窗口确保每个子数组的大小`k`只考虑一次，并且增量更新保证正确的频率分数，而无需从头开始重新计算。 模运算确保值不会溢出。 

## Python 解决方案```python
from collections import defaultdict
from typing import List

MOD = 10**9 + 7

class Solution:
    def maxFrequencyScore(self, nums: List[int], k: int) -> int:
        def mod_pow(a: int, b: int) -> int:
            result = 1
            a %= MOD
            while b > 0:
                if b % 2 == 1:
                    result = (result * a) % MOD
                a = (a * a) % MOD
                b //= 2
            return result

        freq = defaultdict(int)
        score = 0
        # Initialize first window
        for i in range(k):
            freq[nums[i]] += 1
        for num, f in freq.items():
            score = (score + mod_pow(num, f)) % MOD
        max_score = score

        # Slide the window
        for i in range(k, len(nums)):
            left = nums[i - k]
            right = nums[i]

            # Remove left
            old_freq = freq[left]
            score = (score - mod_pow(left, old_freq) + MOD) % MOD
            freq[left] -= 1
            if freq[left] > 0:
                score = (score + mod_pow(left, freq[left])) % MOD
            else:
                del freq[left]

            # Add right
            old_freq = freq.get(right, 0)
            if old_freq > 0:
                score = (score - mod_pow(right, old_freq) + MOD) % MOD
            freq[right] = old_freq + 1
            score = (score + mod_pow(right, freq[right])) % MOD

            max_score = max(max_score, score)

        return max_score
```该实现初始化第一个窗口的频率图并计算初始分数。 当窗口滑动时，它会删除传出元素的贡献，更新其频率，并添加新的贡献。 类似地，它处理传入的元素。 这`mod_pow`函数确保有效地模幂运算。 

## 解决方案```go
package main

func modPow(a, b int) int {
    const MOD = 1_000_000_007
    result := 1
    a %= MOD
    for b > 0 {
        if b%2 == 1 {
            result = (result * a) % MOD
        }
        a = (a * a) % MOD
        b /= 2
    }
    return result
}

func maxFrequencyScore(nums []int, k int) int {
    const MOD = 1_000_000_007
    freq := make(map[int]int)
    score := 0

    for i := 0; i < k; i++ {
        freq[nums[i]]++
    }
    for num, f := range freq {
        score = (score + modPow(num, f)) % MOD
    }
    maxScore := score

    for i := k; i < len(nums); i++ {
        left := nums[i-k]
        right := nums[i]

        oldFreq := freq[left]
        score = (score - modPow(left, oldFreq) + MOD) % MOD
        freq[left]--
        if freq[left] > 0 {
            score = (score + modPow(left, freq[left])) % MOD
        } else {
            delete(freq, left)
        }

        oldFreq = freq[right]
        if oldFreq > 0 {
            score = (score - modPow(right, oldFreq) + MOD) % MOD
        }
        freq[right] = oldFreq + 1
        score = (score + modPow(right, freq[right])) % MOD

        if score > maxScore {
            maxScore = score
        }
    }
    return maxScore
}
```在 Go 中，使用映射而不是 Python 字典。 模运算和求幂遵循相同的逻辑。 我们明确处理频率为零的元素的删除。 

## 工作示例

 **示例1：`nums = [1,1,1,2,1,2], k = 3`**

 | 窗口| 频率图| 分数计算| 最大分数 |
 | ---| ---| ---| ---|
 | [1,1,1]| {1:3} | 1^3 = 1 | 1 |
 | [1,1,2]| {1:2,2:1} | 1^2 + 2^1 = 1+2=3 | 3 |
 | [1,2,1]| {1:2,2:1} | 1^2 + 2^1 = 3 | 3 |
 | [2,1,2]| {1:1,2:2} | 1^1 + 2^2 = 1+4=5 | 5 |

 最高分 = 5

 **示例2：`nums = [1,1,1,1,1,1], k = 4`**

 所有窗口均为{1:4}，分数 = 1^4 = 1。最大分数 = 1
