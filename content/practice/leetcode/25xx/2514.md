[LeetCode 问题 2514](https://leetcode.com/problems/count-anagrams/)

 **难度：** 🔴难
 **主题：** 哈希表、数学、字符串、组合、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定字符串可以形成多少个不同的字谜句子`s`。 

输入字符串包含一个或多个由单个空格分隔的单词。 字谜句子必须保留原句子的结构。 具体来说，`i-th`新句子中的单词必须是以下单词的排列`i-th`原句中的单词。 

例如：

-`"abc def"`可以成为`"bca fed"`-`"abc def"`不能成为`"def abc"`因为言语无法改变位置
 -`"abc"`有`3! = 6`排列
 -`"aa"`只有`1`不同的排列，因为交换相同的字符不会创建新的字符串

 最终答案是每个单词独立的不同排列数量的乘积。 

约束条件非常重要：

 -`s.length <= 10^5`- 单词可能很长
 - 可能有很多重复的字符

 强力排列生成方法是完全不可能的，因为即使对于中等字长，阶乘增长也会变得巨大。 

该问题本质上是一个组合问题。 对于一个字的长度`n`:

 - 总排列：`n!`- 如果字符重复，则除以重复频率的阶乘

 不同排列的数量为：$$\frac{n!}{f_1! \cdot f_2! \cdot \dots \cdot f_k!}$$在哪里`f_i`是字符频率。 

由于答案可能变得非常大，因此我们必须对所有内容进行模计算：$$10^9 + 7$$该模数是素数，它允许使用费马小定理进行模逆。 

重要的边缘情况包括：

 - 一个词
 - 字母全部相同的单词
 - 许多小词
 - 非常大的字
 - 每个角色都是独一无二的单词
 - 需要高效预处理的最大输入大小

 ## 方法

 ### 蛮力方法

 一个简单的解决方案将生成每个单词的每个排列，删除重复项，并计算剩余的唯一字符串数量。 

例如，对于`"too"`:

 - 生成排列：

 -`"too"`-`"oto"`-`"oot"`- 交换相同的重复项`'o'`然后组合单词之间的排列。 

这种方法是正确的，因为它明确枚举了所有可能的字谜词。 然而，这在计算上是不可行的。 

一个字的长度`10`已经有：$$10! = 3,628,800$$排列。 

输入尺寸高达`10^5`，无论是在时间上还是在记忆上，暴力破解都是不可能的。 

### 最佳方法

 关键的观察是我们永远不需要显式地生成排列。 

对于每个单词：$$\text{distinct permutations} = \frac{n!}{\prod f_i!}$$我们使用以下方法有效地计算：

 - 预先计算阶乘
 - 模逆
 - 频率计数

 由于单词是独立的，因此总答案只是每个单词计数的乘积。 

因为模是素数，所以除以模`MOD`可以使用模逆来执行：$$a^{-1} \equiv a^{MOD-2} \pmod{MOD}$$这允许整个计算以相对于输入大小的线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 显式生成排列 |
 | 最佳 | O(n) | O(n) | 使用组合数学和模运算 |

 ## 算法演练

 ### 步骤 1：将句子拆分为单词

 我们独立处理每个单词，因为一个单词的排列不会影响另一个单词。 

例如：```
"too hot"
```变成：```
["too", "hot"]
```### 步骤 2：预先计算阶乘

 我们需要重复求阶乘：$$0!, 1!, 2!, \dots, n!$$在哪里`n`是最大可能的字长。 

我们不再重复重新计算阶乘，而是预先计算一次。 

我们存储：```
factorial[i] = i! % MOD
```### 步骤 3：处理每个单词

 对于每个单词：

 - 使用哈希图计算字符频率
 - 计算：$$\text{ways} = n!$$- 除以每个重复频率阶乘：$$\text{ways} \div f_i!$$由于不允许直接进行模除法，因此我们乘以模逆。 

### 步骤 4：计算模逆

 使用费马小定理：$$a^{-1} \equiv a^{MOD-2} \pmod{MOD}$$所以：```
pow(x, MOD - 2, MOD)
```计算模逆`x`。 

### 步骤 5：将结果相乘

 每个单词独立贡献：$$\text{answer} = \prod \text{word\_ways}$$每次乘法后取模。 

### 为什么它有效

 对于一个字的长度`n`, 最初有`n!`安排。 

如果一个字符出现多次，交换相同的副本不会创建不同的排列。 因此，我们除以每个重复计数的阶乘。 

由于每个单词都可以独立排列，因此适用乘法原理。 将所有单词的计数相乘即可得出有效字谜句子的总数。 

## Python 解决方案```python
from collections import Counter
from typing import List

class Solution:
    def countAnagrams(self, s: str) -> int:
        MOD = 10**9 + 7
        
        words = s.split()
        max_len = max(len(word) for word in words)
        
        # Precompute factorials
        factorial = [1] * (max_len + 1)
        for i in range(1, max_len + 1):
            factorial[i] = factorial[i - 1] * i % MOD
        
        answer = 1
        
        for word in words:
            length = len(word)
            
            # Total permutations = length!
            ways = factorial[length]
            
            # Divide by factorial(freq) for duplicates
            freq = Counter(word)
            
            for count in freq.values():
                inverse = pow(factorial[count], MOD - 2, MOD)
                ways = ways * inverse % MOD
            
            answer = answer * ways % MOD
        
        return answer
```实现首先将句子拆分为单词。 由于每个单词都是独立处理的，这大大简化了问题。 

接下来，预先计算阶乘直至最大字长。 这允许在处理期间进行恒定时间阶乘查找。 

对于每个单词，我们计算排列总数为`length!`。 然后我们使用以下方法计算字符频率`Counter`。 

如果一个字符出现多次，我们除以`freq!`。 因为模运算不支持直接除法，所以我们乘以模逆。 

最后，将每个单词的排列数量乘以全局答案。 

## 解决方案```go
package main

import (
	"strings"
)

const MOD int64 = 1_000_000_007

func modPow(base, exp int64) int64 {
	result := int64(1)

	for exp > 0 {
		if exp%2 == 1 {
			result = result * base % MOD
		}

		base = base * base % MOD
		exp /= 2
	}

	return result
}

func countAnagrams(s string) int {
	words := strings.Split(s, " ")

	maxLen := 0
	for _, word := range words {
		if len(word) > maxLen {
			maxLen = len(word)
		}
	}

	// Precompute factorials
	factorial := make([]int64, maxLen+1)
	factorial[0] = 1

	for i := 1; i <= maxLen; i++ {
		factorial[i] = factorial[i-1] * int64(i) % MOD
	}

	answer := int64(1)

	for _, word := range words {
		ways := factorial[len(word)]

		freq := make(map[byte]int)

		for i := 0; i < len(word); i++ {
			freq[word[i]]++
		}

		for _, count := range freq {
			inverse := modPow(factorial[count], MOD-2)
			ways = ways * inverse % MOD
		}

		answer = answer * ways % MOD
	}

	return int(answer)
}
```Go 实现遵循与 Python 版本相同的数学方法。 

而不是Python内置的`pow(..., mod)`支持，Go 需要一个显式的快速幂函数来进行模幂计算。 

Go 还使用`int64`以避免模数减少之前的乘法期间溢出。 

字符频率使用存储`map[byte]int`，因为输入仅包含小写英文字母。

 ## 边缘情况

 一个重要的边缘情况是每个字符都相同的单词，例如`"aaaaaa"`。 幼稚的实现可能会错误地返回`6!`，即使所有排列都是相同的。 该公式正确地除以`6!`，精确地产生`1`。 

另一个重要的情况是具有所有独特字符的单词，例如`"abcdef"`。 在这种情况下，没有重复调整，因此结果应该是`6!`。 该实现自然地处理这个问题，因为每个频率都是`1`，并除以`1!`没有任何改变。 

第三个关键边缘情况是接近约束极限的非常大的输入。 自从`s.length`可以达到`10^5`，重复重新计算阶乘或生成排列将会超时。 预先计算阶乘一次并线性处理字符可确保算法即使在最大规模下也保持高效。
