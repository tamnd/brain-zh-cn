## 问题理解

 该问题提供了一个正整数数组，`nums`。 我们被要求模拟一个评分过程，在每一步中我们选择数组中**最小的未标记元素**。 如果多个元素都匹配最小值，我们选择**最左边的索引**。 一旦选择，该元素的值将被添加到运行分数中，并且元素本身及其直接邻居（如果存在）都会被标记。 重复此过程直到所有元素都被标记。 

输入是标准整数数组，输出是单个整数，表示根据此评分规则累积的总分。 

约束表明`nums`可以达到`10^5`elements long，每个元素最多可达`10^6`。 这排除了重复扫描数组以找到最小值的简单方法，因为重复的完整扫描会导致`O(n^2)`时间。 

关键边缘情况包括长度为 1 的数组、存在多个最小元素的数组，以及具有交替值的数组（其中标记邻居可以跳过其他小元素）。 

## 方法

 **暴力方法：**简单的方法是重复扫描数组以找到最小的未标记元素。 选择它后，标记它及其邻居，然后重复。 虽然这种方法正确地实现了规则，但它需要扫描数组`O(n)`次`n`元素，导致`O(n^2)`时间复杂度。 为了`n = 10^5`，这太慢了。 

**最佳方法：**关键的观察是，我们可以在跟踪索引的同时对数组进行预排序，然后使用**优先级队列（最小堆）**或排序列表来有效地选择下一个最小的未标记元素。 通过维护一个布尔数组来标记并按值的升序迭代元素，我们可以实现`O(n log n)`时间复杂度。

 ## 算法演练

 1. 创建元组列表`(value, index)`对于中的所有元素`nums`。 这使我们能够在记住原始位置的同时按值排序。 
2. 列表排序依据`value`。 Python 和 Go 的排序是稳定的，因此索引会自动打破联系。 
3.初始化布尔数组`marked`与相同长度`nums`跟踪哪些元素被标记。 
4. 初始化`score = 0`。 
5. 迭代排序列表。 对于每个元素`(value, index)`：

 - 如果元素位于`index`已经标记了，跳过。 
- 否则，添加`value`到`score`。 
- 标记当前索引及其邻居（如果存在）（索引`index - 1`和`index + 1`），确保我们保持在数组范围内。 
6. 继续，直到处理完所有元素。 返回`score`。 

**为什么有效：** 该算法保持不变性，即在每一步中，都会选择最小的未标记元素，完全按照问题的要求。 标记邻居可确保未来的迭代遵守标记规则。 排序保证我们以正确的顺序处理元素，而无需重新扫描数组。 

## Python 解决方案```python
from typing import List

class Solution:
    def findScore(self, nums: List[int]) -> int:
        n = len(nums)
        indexed_nums = [(num, i) for i, num in enumerate(nums)]
        indexed_nums.sort()  # sort by value, ties broken by index due to stable sort

        marked = [False] * n
        score = 0

        for value, i in indexed_nums:
            if not marked[i]:
                score += value
                marked[i] = True
                if i > 0:
                    marked[i - 1] = True
                if i < n - 1:
                    marked[i + 1] = True

        return score
```**解释：** 我们首先将每个值与其索引配对并对这些对进行排序。`marked`跟踪哪些元素已被邻接标记打分或失效。 通过迭代排序元素并标记邻居，我们避免了重复扫描，实现`O(n log n)`效率。 

## 解决方案```go
import (
    "sort"
)

func findScore(nums []int) int64 {
    n := len(nums)
    type pair struct {
        value int
        index int
    }

    pairs := make([]pair, n)
    for i, v := range nums {
        pairs[i] = pair{v, i}
    }

    sort.SliceStable(pairs, func(i, j int) bool {
        return pairs[i].value < pairs[j].value
    })

    marked := make([]bool, n)
    var score int64 = 0

    for _, p := range pairs {
        i := p.index
        if !marked[i] {
            score += int64(p.value)
            marked[i] = true
            if i > 0 {
                marked[i-1] = true
            }
            if i < n-1 {
                marked[i+1] = true
            }
        }
    }

    return score
}
```**去注意：**`int64`用于分数以避免大额金额可能溢出。`sort.SliceStable`确保稳定排序以尊重索引的平局打破。 标记的方式与 Python 相同。

 ## 边缘情况

 **单个元素：** 当数组只有一个元素时，算法会正确地将该元素添加到分数中并对其进行标记，而无需考虑邻居。 

**所有元素相等：** 当所有元素都相同时，只有最左边未标记的元素在每次迭代中对分数有贡献，因为邻居会立即被标记，确保不会发生重复计算。
