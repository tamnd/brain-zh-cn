[LeetCode 问题 2580](https://leetcode.com/problems/count-ways-to-group-overlapping-ranges/)

 **难度：** 🟡 中等
 **主题：** 数组、排序

 ## 解决方案

 ## 问题理解

 该问题给了我们一个整数范围列表，其中每个范围代表之间的所有整数`start`和`end`，包含在内。 我们必须将所有范围恰好分为两组。 任一组都可以为空。 

重要的限制是重叠的范围无法分开。 如果两个范围共享至少一个公共整数，则它们必须属于同一组。 该规则也可传递地适用。 例如，如果范围 A 与范围 B 重叠，范围 B 与范围 C 重叠，则所有三个范围都必须放入同一组中，即使 A 和 C 不直接重叠。 

任务是计算存在多少种有效方法将范围分配为两组，同时遵守这些重叠约束。 

输入大小可以大到`10^5`范围，因此解决方案必须是有效的。 简单的成对图构造或强力分配会太慢。 

一个关键的观察结果是重叠范围自然形成连接的组件。 同一连接组件内的每个范围都必须属于同一组。 一旦我们确定存在多少个独立的连接组件，每个组件就有两个选择：

 - 将整个组件放入组 1
 - 将整个组件放入组 2

 如果有`k`独立的重叠分量，则有效分配的总数为：$2^k$答案必须以模数形式返回：$10^9 + 7$一些边缘情况很重要：

 - 单个范围始终产生恰好 2 个有效分组。 
- 完全不相交的范围，每个范围形成单独的组件。 
- 完全重叠的范围都属于一个组件。 
- 触摸间隔，例如`[1,2]`和`[2,3]`是重叠的，因为整数`2`两个范围内都存在。 
- 嵌套间隔，例如`[1,10]`和`[3,5]`也有重叠。 

因为坐标可以大到`10^9`，我们不能使用任何坐标压缩网格或区间标记方法。 该解决方案必须依赖于排序和区间合并逻辑。 

## 方法

 ### 蛮力方法

 强力解决方案将尝试将范围的所有可能分配分为两组。 由于每个范围都有两个选择，因此有：$2^n$可能的任务。 

对于每个作业，我们都会检查所有重叠范围是否最终位于同一组中。 这需要比较成对的范围以确定重叠关系。 

两个范围`[a,b]`和`[c,d]`重叠如果：$\max(a,c) \leq \min(b,d)$检查所有对的成本`O(n^2)`，并且对每个作业执行此操作会导致指数级的复杂性。 

这种方法是正确的，因为它详尽地检查了每个可能的分组，但对于`n = 10^5`。 

### 最佳方法

 关键的见解是重叠的范围形成连接的组件。 

假设我们按起始位置对所有范围进行排序。 然后我们可以从左到右扫描并将所有重叠的间隔合并为一个组件。 

例如：```
[1,3], [2,5], [4,8]
```所有三个都属于同一组件，因为每个间隔都与下一个间隔重叠。 

一旦我们确定了独立合并组件的数量，问题就变得非常简单：

 - 每个组件必须保持在一起
 - 每个组件独立选择组1或组2

 因此，如果有`k`合并组件，有效分配的总数为：$2^k$我们计算这个值的模`10^9 + 7`。 

合并过程只需要排序加一次线性扫描。

 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(1) | O(1) | 尝试每个分组并验证重叠 |
 | 最佳| O(n log n) | O(n log n) | O(1) 排除排序空间 | 对间隔进行排序并计算合并的重叠分量 |

 ## 算法演练

 1. 按起始坐标对所有范围进行排序。 

排序允许我们从左到右处理间隔。 排序后，重叠的区间会连续出现。 
2. 初始化变量以跟踪当前合并的组件。 

我们维持：

 -`current_end`,当前组件的最远结束位置
 -`components`, 到目前为止发现的断开重叠组的数量
 3. 开始对排序后的范围进行一一处理。 

第一个间隔始终开始一个新组件。 
4. 对于每个下一个间隔，将其开始时间与`current_end`。 

如果：$start \leq current\_end$然后该间隔与当前组件重叠。 

我们通过更新来合并它：$current\_end = \max(current\_end, end)$5. 如果间隔不重叠，则启动一个新组件。 

这意味着：$start > current\_end$由于不存在重叠，因此该区间属于完全独立的一组范围。 

增加组件数量。 
6. 处理完所有范围后，计算答案。 

如果有`components`独立的重叠组，则有效分配的数量为：$2^{components} \bmod (10^9+7)$### 为什么它有效

 该算法之所以有效，是因为重叠间隔创建了连通分量。 同一连通分量内的每个间隔必须一起分配，否则将违反至少一个重叠约束。 

排序保证属于同一分量的所有区间连续出现。 合并扫描正确识别每个最大连接重叠组。 

由于每个组件可以独立选择两组中的一组，因此将每个组件的两个选择相乘得出：$2^k$在哪里`k`是组件的数量。 

## Python 解决方案```python
from typing import List

class Solution:
    def countWays(self, ranges: List[List[int]]) -> int:
        MOD = 10**9 + 7

        ranges.sort()

        components = 0
        current_end = -1

        for start, end in ranges:
            if start > current_end:
                components += 1
                current_end = end
            else:
                current_end = max(current_end, end)

        return pow(2, components, MOD)
```实现首先对间隔进行排序。 Python 的默认列表排序按字典顺序排序，这意味着间隔首先按起始坐标排序，然后按结束坐标排序。 这正是我们所需要的。 

变量`components`跟踪存在多少个断开连接的重叠组。 

变量`current_end`存储当前合并组件的最右端点。 

迭代期间：

 - 如果`start > current_end`，当前区间与之前的组件不重叠，因此我们开始一个新的组件。 
- 否则，区间会重叠，如有必要，我们会扩展合并的边界。 

最后，我们计算：$2^{components} \bmod (10^9+7)$使用 Python 的内置模幂运算。 

## 解决方案```go
package main

import (
	"sort"
)

func countWays(ranges [][]int) int {
	const MOD int = 1_000_000_007

	sort.Slice(ranges, func(i, j int) bool {
		if ranges[i][0] == ranges[j][0] {
			return ranges[i][1] < ranges[j][1]
		}
		return ranges[i][0] < ranges[j][0]
	})

	components := 0
	currentEnd := -1

	for _, interval := range ranges {
		start, end := interval[0], interval[1]

		if start > currentEnd {
			components++
			currentEnd = end
		} else if end > currentEnd {
			currentEnd = end
		}
	}

	result := 1

	for i := 0; i < components; i++ {
		result = (result * 2) % MOD
	}

	return result
}
```Go 实现遵循与 Python 版本相同的逻辑。 

由于 Go 不提供 Python 使用的标准样式中整数的内置模幂运算`pow`，我们迭代计算 2 的幂。 

排序步骤使用`sort.Slice`带有自定义比较器。 

该算法的其余部分使用整数变量和对间隔的简单线性扫描。

 ## 边缘情况

 当间隔仅接触边界时，就会出现一种重要的边缘情况。 例如，`[1,2]`和`[2,3]`重叠，因为两者都包含整数`2`。 一个常见的错误是使用严格的不等式，例如`start >= current_end`，这会错误地分隔触摸间隔。 实现正确使用`start > current_end`以确定不重叠。 

另一个重要的例子是传递重叠链。 考虑：```
[1,3], [3,5], [5,7]
```即使第一和第三间隔没有直接重叠太多，所有三个间隔都通过链接属于一个连通分量。 合并过程自然会处理这个问题，因为`current_end`随着处理重叠间隔而不断扩展。 

嵌套间隔也很容易处理不当。 例如：```
[1,100], [20,30], [40,50]
```幼稚的算法可能会错误地将较小的间隔分成不同的组。 当前的实现跟踪合并组件中的最大端点，确保所有嵌套间隔保持连接。 

最后，完全不相交的间隔产生最大数量的分组。 如果没有间隔重叠，则每个间隔形成自己的组成部分，从而导致：$2^n$可能的任务。 该实现在排序后通过一次传递就可以有效地处理这个问题。
