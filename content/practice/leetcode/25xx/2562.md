[LeetCode 问题 2562](https://leetcode.com/problems/find-the-array-concatenation-value/)

 **难度：** 🟢简单
 **主题：** 数组、两个指针、模拟

 ## 解决方案

 ## 问题理解

 问题是要求我们计算给定数组的**特殊总和**`nums`通过重复连接数组的第一个和最后一个元素直到它为空。 串联运算不是加法； 它涉及将数字视为字符串，将它们连接在一起，然后将它们转换回整数。 例如，连接`15`和`49`产生`1549`。 

该过程在两种情况下继续：如果至少有两个元素，我们在连接后删除第一个和最后一个元素； 如果只剩下一个元素，我们只需将其值添加到结果中并将其删除。 该数组是**0索引**并且最多可以有`1000`元素，每个元素都是介于`1`和`10^4`。 这意味着数组足够小，可以进行简单的模拟，但如果可能的话，我们应该避免不必要的字符串转换或额外的空间。 

重要的边缘情况包括长度数组`1`（单个元素）、具有所有相同元素的数组以及影响串联的具有不同数字长度的数组（例如，`[1, 1000]`结果`11000`）。 

## 方法

 **暴力方法**是直接模拟。 我们重复获取第一个和最后一个元素，将它们转换为字符串，连接它们，转换回整数，添加到运行总计中，然后从数组中删除元素。 这种方法是正确且简单的，但每次迭代中的字符串转换和数组切片对于较大的数组来说可能效率稍低。 

**最佳方法**是两指针技术。 我们没有对数组进行切片，而是维护两个索引（`left`和`right`) 指向开始和结束。 在每次迭代中，我们通过将数字转换为字符串然后再转换回整数来计算串联，将其添加到结果中，并将指针向内移动。 这样可以避免重复修改数组，并且内存效率更高。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n) | 在每次迭代中使用数组切片和字符串转换；`m`是数字中的位数 |
 | 两点最优 | O(n * m) | O(1) | O(1) | 使用两个指针来避免数组切片； 仍然需要字符串转换才能连接 |

 ## 算法演练

 1.初始化两个指针：`left = 0`和`right = len(nums) - 1`。 初始化`conc_val = 0`存储串联值。 
2. 虽然`left`小于或等于`right`，执行以下操作：

 a. 如果`left`等于`right`，这意味着只剩下一个元素。 添加`nums[left]`到`conc_val`并打破循环。 

b. 否则，计算串联`nums[left]`和`nums[right]`通过将两个数字转换为字符串，连接，然后转换回整数。 将此值添加到`conc_val`。 

c. 增量`left`并减少`right`向内移动。 
3. 返回`conc_val`作为最终答案。 

**为什么有效：** 每次迭代都会正确处理第一个和最后一个元素，确保所有元素都包含在总和中一次。 使用两个指针可保证 O(n) 次迭代，无需额外的数组操作。 连接保留了预期的数字顺序，因为转换为字符串并返回准确地模拟了问题中描述的操作。 

## Python 解决方案```python
from typing import List

class Solution:
    def findTheArrayConcVal(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        conc_val = 0
        
        while left <= right:
            if left == right:
                conc_val += nums[left]
            else:
                conc_val += int(str(nums[left]) + str(nums[right]))
            left += 1
            right -= 1
        
        return conc_val
```Python 实现遵循两指针策略。`left`和`right`跟踪当前的第一个和最后一个元素。 条件`left == right`处理单元素情况，而串联则使用字符串转换。 该解决方案避免了对数组进行切片，并以相对于元素数量的线性时间进行操作。 

## 解决方案```go
import "strconv"

func findTheArrayConcVal(nums []int) int64 {
    var concVal int64 = 0
    left, right := 0, len(nums)-1
    
    for left <= right {
        if left == right {
            concVal += int64(nums[left])
        } else {
            concatStr := strconv.Itoa(nums[left]) + strconv.Itoa(nums[right])
            val, _ := strconv.ParseInt(concatStr, 10, 64)
            concVal += val
        }
        left++
        right--
    }
    
    return concVal
}
```在 Go 中，我们使用`strconv.Itoa`将整数转换为字符串以进行连接和`strconv.ParseInt`转换回`int64`。 该解决方案使用`int64`处理潜在的溢出，因为串联可能会产生大量数字。 两指针方法反映了Python的实现，确保了效率。

 ## 边缘情况

 第一个边缘情况是**单元素数组**，例如，`[7]`。 这很重要，因为主循环处理两个元素的串联，因此如果我们不检查单个元素，代码可能会尝试访问无效索引。 我们的解决方案明确处理`left == right`添加单独的元素。 

例如，第二个边缘情况是**大数字**`[10, 1000]`。 连接产生的数字最多为`10^9`或更高。 在Python中，整数可以处理任意大小，但在Go中我们必须使用`int64`以避免溢出。 该解决方案正确地将连接的字符串转换为`int64`。 

第三种边缘情况是**奇数长度的数组**，例如`[1,2,3]`。 中间的元素最终会是单独的，我们需要添加一次。 这`left <= right`条件确保在以下情况下正确添加中间元素`left == right`。 这可以防止差一错误。
