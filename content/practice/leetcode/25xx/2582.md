[LeetCode 问题 2582](https://leetcode.com/problems/pass-the-pillow/)

 **难度：** 🟢简单
 **主题：** 数学、模拟

 ## 解决方案

 ## 问题理解

 问题描述了一行`n`人，按顺序编号`1`到`n`。 最初，人`1`拿着一个枕头。 每一秒，枕头都会被传递给相邻的人。 每当枕头到达线的任一端时，通过的方向都会改变。 

换句话说，枕头从人身上向前移动`1`对人`n`，然后反转方向并向后朝人移动`1`，无限地重复这个模式。 

我们有两个整数：

 -`n`，代表排队的人数。 
-`time`，表示已经过去的秒数。 

目标是准确地确定哪个人拿着枕头`time`秒。 

为了更好地理解运动，请考虑`n = 4`：

- 开始：`1`- 1 秒后：`2`- 2 秒后：`3`- 3 秒后：`4`- 4 秒后：`3`- 5 秒后：`2`- 6 秒后：`1`- 7 秒后：`2`请注意，该运动会在一个周期中重复进行。 

限制很小：

 -`2 <= n <= 1000`-`1 <= time <= 1000`因为两个值最多都是`1000`，即使直接模拟也足够快。 然而，运动的重复性质表明我们可以在恒定时间内以数学方式得出答案。 

一个重要的观察结果是枕头以重复的长度周期来回移动`2 × (n - 1)`：

 - 搬自`1`到`n`需要`n - 1`秒。 
- 从`n`到`1`需要另一个`n - 1`秒。 

这种重复结构是最佳解决方案的关键见解。 

一些边缘情况需要提前考虑。 什么时候`time`小于`n - 1`，枕头还没有到达终点，只是简单地向前移动。 什么时候`time`正是`n - 1`，枕头在人身上`n`。 什么时候`time`超过一个完整周期，我们必须使用模运算正确地考虑重复运动。 该问题保证了有效的正输入，因此我们永远不需要处理无效值，例如`n = 1`或负时间。 

## 方法

 ### 暴力模拟

 最直接的方法是模拟枕头一秒一秒地经过。 

我们维护两个变量：

 - 当前拿着枕头的人。 
- 移动方向，向前（`+1`）或向后（`-1`）。 

每一秒：

 1. 将枕头移给下一个人。 
2. 如果枕头到达线的任一端，则反转方向。 

这种方法之所以有效，是因为它忠实地再现了问题陈述中描述的确切行为。 模拟后`time`秒，当前持有者就是答案。 

虽然这种方法是正确的，但它每秒执行一次操作，导致相对于线性时间复杂度`time`。 

### 最优数学观察

 更好的解决方案来自于认识到枕头运动形成重复循环。 

一个完整的周期包括：

 - 搬自`1`到`n`，这需要`n - 1`秒。 
- 从`n`到`1`，这需要另一个`n - 1`秒。 

因此，周期长度为：$$2 \times (n - 1)$$我们不是模拟每一秒，而是计算当前时间在周期内的位置。 

首先，计算：$$cycle = n - 1$$然后确定：

 -`fullRounds = time // cycle`-`remaining = time % cycle`如果`fullRounds`是偶数，我们在前进，所以答案是：$$1 + remaining$$如果`fullRounds`很奇怪，我们正在向后移动，所以答案是：$$n - remaining$$这消除了模拟的需要并在恒定的时间内给出结果。

 ## 算法演练

 1. 计算两端之间的单向距离。 

自从搬离人`1`对人`n`需要`n - 1`通过，我们定义：```
cycle = n - 1
```这代表了重复运动模式的一半。 
2. 确定经过了多少个完整的方向段。 

计算：```
fullRounds = time // cycle
```如果这个数字是偶数，则枕头正在向前移动。 如果奇怪，则它正在向后移动。 
3. 确定当前段内的剩余运动。 

计算：```
remaining = time % cycle
```这告诉我们在完成定向运动后发生了多少次额外的通过。 
4. 检查当前方向。 

如果`fullRounds`均匀时，枕头从左向右移动：```
answer = 1 + remaining
```如果`fullRounds`奇怪的是，枕头从右向左移动：```
answer = n - remaining
```5. 返回结果。 

计算出的人指数正是之后谁拿着枕头`time`秒。 

### 为什么它有效

 枕头的运动是周期性的。 每一个`n - 1`几秒钟，方向翻转。 通过将时间划分为长度的块`n - 1`，我们知道枕头是向前移动还是向后移动。 余数告诉我们枕头沿当前方向移动了多远。 由于每种可能的状态都会按预期重复，因此模运算可以保证正确的答案。 

## Python 解决方案```python
class Solution:
    def passThePillow(self, n: int, time: int) -> int:
        cycle = n - 1
        full_rounds = time // cycle
        remaining = time % cycle

        if full_rounds % 2 == 0:
            return 1 + remaining

        return n - remaining
```实现直接遵循数学观察。 

首先，我们计算`cycle`，它表示从线路的一端移动到另一端所需的秒数。 然后，`full_rounds`确定已经经过了多少个方向段，而`remaining`表示当前段中还剩下多少步。 

如果`full_rounds`是均匀的，枕头从左向右移动，所以我们只需从人向前移动`1`。 否则，枕头是从右向左移动的，所以我们从人开始倒数`n`。 

由于该算法仅依赖于算术运算，因此它以恒定的时间运行并使用恒定的内存。 

## 解决方案```go
func passThePillow(n int, time int) int {
	cycle := n - 1
	fullRounds := time / cycle
	remaining := time % cycle

	if fullRounds%2 == 0 {
		return 1 + remaining
	}

	return n - remaining
}
```Go 实现与 Python 版本几乎相同。 由于 Go 自动对整数使用整数除法，`time / cycle`完全按照需要运行。 

不用担心整数溢出，因为约束非常小，值上限为`1000`。 不需要额外的数据结构，只使用几个整数变量。

 ## 边缘情况

 ### 最低人数

 当`n = 2`，枕头只在两个人之间交替。 这种情况可能会暴露一个错误，因为周期长度变为`1`。 幼稚的实现可能会错误地假设运动更复杂。 我们的公式可以正确运行，因为`cycle = n - 1 = 1`，所以每一秒都会按预期翻转方向。 

### 准确的端点到达

 当`time`等于`n - 1`，枕头正好落在最后一个人身上。 这是错误的常见来源，因为某些实现错误地过早反转方向。 我们的方法可以自然地处理这个问题，因为`remaining = 0`经过一个完整的定向段后，奇偶校验正确地将枕头放在人身上`n`。 

### 多个完整周期

 当`time`远大于`n`，重复模拟运动可能效率低下或在方向切换时引入逻辑错误。 由于该运动每重复一次`2 × (n - 1)`秒，我们的实现通过依靠除法和模运算直接跳转到正确的状态来避免不必要的工作。 

### 立即方向反转

 当枕头刚刚到达端点并需要反转方向时，实现可能会意外地重复计算端点或跳过一个人。 例如，与`n = 5`和`time = 5`，枕头应该从`5`回到`4`。 奇偶校验与余数计算相结合可确保精确处理反转。
