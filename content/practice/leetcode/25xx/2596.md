 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、广度优先搜索、矩阵、模拟

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个`n x n`矩阵称为`grid`，其中每个数字来自`0`到`n * n - 1`恰好出现一次。 每个值代表骑士在棋盘上游览期间访问该单元格的顺序。 

国际象棋中的马走L形。 从位置`(r, c)`，它可以移动到以下八个可能位置中的任何一个：

 -`(r + 2, c + 1)`-`(r + 2, c - 1)`-`(r - 2, c + 1)`-`(r - 2, c - 1)`-`(r + 1, c + 2)`-`(r + 1, c - 2)`-`(r - 1, c + 2)`-`(r - 1, c - 2)`任务是确定矩阵是否描述了有效的骑士之旅配置。 

有效的配置必须满足两个条件：

 1.骑士必须从左上角开始`(0, 0)`， 意义`grid[0][0]`必须等于`0`。 
2、每一次连续的移动都必须遵循骑士的合法移动规则。 

输入保证：

 - 每个数字都是独一无二的。 
- 每个值都在有效范围内。 
- 板尺寸介于`3`和`7`。 

这些限制很小。 即使最大的电路板也只包含`49`细胞。 这告诉我们我们不需要复杂的优化技术。 直接模拟方法就足够了。 

一些边缘情况很重要：

 - 如果`grid[0][0] != 0`，答案立即`false`因为骑士必须从左上角的单元格开始。 
- 连续的位置不能形成合法的骑士动作。 
- 小板，例如`3 x 3`通常包含无效的游览，因为在许多小维度上完整的骑士游览是不可能的。 
- 即使所有数字都是唯一且有效的，排序本身仍然可能违反骑士移动规则。 

## 方法

 ### 蛮力方法

 暴力策略将尝试通过重复搜索整个棋盘来寻找下一个移动编号来逐步重建骑士的移动序列。 

例如，查找移动位置`0`发生时，我们扫描矩阵。 然后我们再次扫描移动`1`, 再次移动`2`，依此类推，直到`n * n - 1`。 

找到每对连续的位置后，我们验证骑士是否可以在它们之间合法移动。 

这种方法之所以有效，是因为它明确地检查序列中的每个动作。 如果所有连续移动均有效且起始位置正确，则配置有效。 

然而，这种方法效率低下，因为每次查找都需要扫描整个板。 由于有`n^2`移动和每次搜索成本`O(n^2)`，总复杂度变为`O(n^4)`。 

尽管约束足够小，这仍然可以通过，但速度却不必要地慢。 

### 最佳方法

 关键的观察结果是，每个数字都唯一地标识了一个棋盘位置。 我们可以对棋盘进行一次预处理，然后直接将每个移动编号映射到其坐标，而不是重复搜索位置。 

我们创建一个数组，其中：```
position[k] = (row, col)
```这使我们能够立即检索移动的坐标`k`。 

然后我们简单地迭代所有连续的移动：```
0 -> 1
1 -> 2
2 -> 3
...
```对于每一对，我们计算行差和列差。 在以下情况下，马的移动是有效的：```
(abs(dr), abs(dc)) == (2, 1) or (1, 2)
```这将整体复杂性降低到`O(n^2)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 反复扫描棋盘寻找每一步棋|
 | 最佳| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 存储位置以便直接查找每个动作 |

 ## 算法演练

 1. 首先，确认骑士从要求的位置开始。 

该问题明确指出骑士必须从左上角的单元格开始。 因此，如果`grid[0][0] != 0`，我们立即返回`False`。 
2. 创建位置映射数组。 

我们分配一个大小的数组`n * n`，其中每个索引代表一个移动编号。 存储在该索引处的值将是该移动的坐标。 

例子：```
positions[5] = (0, 3)
```表示骑士访问了牢房`(0, 3)`移动期间号码`5`。 
3. 遍历棋盘一次以填充映射。 

对于每个细胞`(r, c)`：

- 读`move_number = grid[r][c]`- 店铺：```
positions[move_number] = (r, c)
```完成此步骤后，可以在恒定时间内访问每个手数。 
4. 验证每个连续的马移动。 

迭代自`0`到`n * n - 2`。 

对于每一步`k`：

 - 检索当前位置`(r1, c1)`- 检索下一个位置`(r2, c2)`计算：```
dr = abs(r1 - r2)
dc = abs(c1 - c2)
```仅当满足以下条件时，移动才有效：```
(dr == 2 and dc == 1)
or
(dr == 1 and dc == 2)
```如果两个条件都不成立，则返回`False`。 
5. 如果所有动作都有效，则返回`True`。 

### 为什么它有效

 该算法之所以有效，是因为每个移动编号都唯一地标识了一个棋盘位置。 通过提前存储所有位置，我们可以直接验证游览中的每个连续移动。 

当且仅当满足以下条件时，骑士之旅才有效：

 - 骑士开始于`(0, 0)`- 每个连续的移动都遵循骑士移动规则

 该算法对这两个条件仅检查一次，因此结果是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)

        # The knight must start at the top-left corner
        if grid[0][0] != 0:
            return False

        # positions[k] = (row, col) of move k
        positions = [None] * (n * n)

        for row in range(n):
            for col in range(n):
                move_number = grid[row][col]
                positions[move_number] = (row, col)

        # Check every consecutive move
        for move in range(n * n - 1):
            r1, c1 = positions[move]
            r2, c2 = positions[move + 1]

            row_diff = abs(r1 - r2)
            col_diff = abs(c1 - c2)

            if not (
                (row_diff == 2 and col_diff == 1)
                or
                (row_diff == 1 and col_diff == 2)
            ):
                return False

        return True
```该实现首先检查起始单元格是否包含`0`。 如果不是，函数立即返回`False`。 

接下来，代码创建一个`positions`数组，其中每个索引对应于一个移动编号。 通过遍历棋盘一次，我们存储每次移动的坐标。 

预处理后，算法迭代所有连续的移动编号。 对于每一对，它计算绝对行和列差异。 仅当差异与两种合法的骑士移动模式之一匹配时，移动才有效。 

如果任何移动验证失败，该函数将返回`False`立即地。 否则，在所有检查成功后，函数返回`True`。 

## 解决方案```go
func checkValidGrid(grid [][]int) bool {
	n := len(grid)

	// The knight must start at the top-left corner
	if grid[0][0] != 0 {
		return false
	}

	// positions[k] = {row, col}
	positions := make([][2]int, n*n)

	for row := 0; row < n; row++ {
		for col := 0; col < n; col++ {
			moveNumber := grid[row][col]
			positions[moveNumber] = [2]int{row, col}
		}
	}

	// Check every consecutive move
	for move := 0; move < n*n-1; move++ {
		r1, c1 := positions[move][0], positions[move][1]
		r2, c2 := positions[move+1][0], positions[move+1][1]

		rowDiff := abs(r1 - r2)
		colDiff := abs(c1 - c2)

		valid :=
			(rowDiff == 2 && colDiff == 1) ||
				(rowDiff == 1 && colDiff == 2)

		if !valid {
			return false
		}
	}

	return true
}

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于 Go 没有提供内置整数`abs`对于普通整数函数，我们定义了一个小辅助函数。 

位置映射使用固定大小数组的切片：```go
[][2]int
```这可以有效地存储坐标对，而无需额外的分配开销。 

Go 切片会自动使用零值进行初始化，因此除此之外不需要显式初始化`make`。

    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)

        if grid[0][0] != 0:
            return False

        positions = [None] * (n * n)

        for r in range(n):
            for c in range(n):
                positions[grid[r][c]] = (r, c)

            dc = abs(c1 - c2)

        return True

 ## 边缘情况

 ### 起始单元不为零

 One common mistake is forgetting that the knight must start at the top-left corner. Even if all knight moves are otherwise valid, the configuration must still be rejected if`grid[0][0] != 0`。 

该实现会立即处理此问题，并在进行任何其他处理之前提前返回。 

### 无效的移动出现在序列的后面

 棋盘可能包含许多有效的马动作，但最终在接近序列末尾时失败。 过早停止检查或在部分验证后错误地假设有效性的幼稚实现可能会产生错误的答案。 

该算法明确地检查从`0`通过`n * n - 2`，确保最终的转换也得到验证。 

### 小板尺寸

 小板如`3 x 3`特别棘手，因为许多配置看起来是结构化的，但并不代表有效的骑士之旅。 

该实现不依赖于关于棋盘大小或已知旅游存在属性的假设。 相反，它直接验证实际的移动顺序，从而保证所有有效约束的正确性。
