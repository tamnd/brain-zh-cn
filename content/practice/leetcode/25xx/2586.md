[LeetCode 问题 2586](https://leetcode.com/problems/count-the-number-of-vowel-strings-in-range/)

 **难度：** 🟢简单
 **主题：** 数组、字符串、计数

 ## 解决方案

 ## 问题理解

 该问题给了我们一个小写字符串数组，称为`words`和两个整数索引，`left`和`right`。 我们需要统计有多少个字符串在包含范围内`[left, right]`被视为元音字符串。 

如果这两个条件都为真，则字符串符合元音字符串的资格：

 1.第一个字符是元音。 
2.最后一个字符也是元音。 

有效的元音是：```
a, e, i, o, u
```范围`[left, right]`告诉我们应该检查数组的哪一部分。 我们不会检查数组中的每个字符串，除非范围覆盖整个数组。 

例如，如果：```
words = ["are","amy","u"]
left = 0
right = 2
```我们检查：```
"are", "amy", "u"
```这个词`"are"`开始于`'a'`并以`'e'`，所以很重要。 这个词`"amy"`开始于`'a'`但结束于`'y'`，所以不算。 这个词`"u"`开始和结束于`'u'`，所以很重要。 

限制很小：

 -`words.length <= 1000`-`words[i].length <= 10`这告诉我们，即使是简单的线性扫描也足够有效。 对于这个特定的问题大小，我们不需要先进的优化技术，例如前缀和或预处理。 

有几个重要的边缘情况需要考虑：

 - 一个单词只能包含一个字符，例如`"u"`。 在这种情况下，第一个字符和最后一个字符都是同一个字符。 
- 该范围可能只包含一个元素，其中`left == right`。 
- 有些单词可能以元音开头但以辅音结尾，反之亦然。 
- 输入保证所有单词只包含小写英文字母，因此我们不需要处理大写字符。 

## 方法

 ### 蛮力方法

 强力解决方案检查索引之间的每个字符串`left`和`right`。 对于每个单词，我们检查第一个和最后一个字符并确定它们是否属于元音集。 

这种方法是正确的，因为所需范围内的每个候选字符串都被检查一次。 如果一个单词满足这两个条件，我们就会增加答案计数器。 

虽然这个解决方案被称为暴力破解，但对于给定的约束来说它已经足够有效了，因为最大单词数只有 1000。 

### 最佳方法的关键见解

 关键的观察结果是每个单词可以仅使用其第一个和最后一个字符进行独立验证。 

我们不需要分析整个字符串。 相反：

 - 检查`word[0]`- 查看`word[-1]`如果都是元音，计算单词数。 

使用元音的散列集允许恒定时间的成员资格检查。 

由于每个单词都被处理一次并且每个操作都是恒定时间，因此整体解决方案以相对于范围内的单词数量的线性时间运行。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 扫描范围内的每个单词并检查第一个和最后一个字符 |
 | 最佳 | O(n) | O(1) | O(1) | 相同的线性扫描，使用恒定时间元音查找进行优化 |

 这里，`n`表示范围内的单词数`[left, right]`。 

## 算法演练

 1. 创建一个包含所有元音的集合。 

我们使用集合是因为​​成员资格检查非常快，通常为 O(1)。 该套装将包含：```
{'a', 'e', 'i', 'o', 'u'}
```2. 将计数器变量初始化为零。 

该变量存储迄今为止找到的有效元音字符串的数量。 
3. 从索引处迭代数组`left`索引`right`。 

我们只检查数组中所需的部分，因为问题明确限制了计数范围。 
4. 对于每个单词，提取第一个和最后一个字符。 

第一个字符是：```
word[0]
```最后一个字符是：```
word[-1]
```5. 检查两个字符是否都是元音。 

如果两者都属于元音集，则增加计数器。 
6. 处理完范围内的所有字后，返回计数器。 

### 为什么它有效

 该算法之所以有效，是因为所需范围内的每个单词都根据元音字符串的精确定义进行了一次精确检查。 当且仅当单词的第一个和最后一个字符是元音时，该单词才被计数。 由于没有跳过有效字并且没有计数无效字，因此保证最终计数器是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def vowelStrings(self, words: List[str], left: int, right: int) -> int:
        vowels = {'a', 'e', 'i', 'o', 'u'}
        count = 0

        for index in range(left, right + 1):
            word = words[index]

            if word[0] in vowels and word[-1] in vowels:
                count += 1

        return count
```该实现首先创建一组用于快速查找的元音。 变量`count`跟踪已找到多少个有效的元音字符串。 

循环仅迭代由范围指定的索引`[left, right]`。 对于每个单词，代码检查元音集中是否存在第一个和最后一个字符。 

如果两个条件都成立，则计数器加一。 

最后，该函数返回总计数。 

## 解决方案```go
func vowelStrings(words []string, left int, right int) int {
    vowels := map[byte]bool{
        'a': true,
        'e': true,
        'i': true,
        'o': true,
        'u': true,
    }

    count := 0

    for i := left; i <= right; i++ {
        word := words[i]

        if vowels[word[0]] && vowels[word[len(word)-1]] {
            count++
        }
    }

    return count
}
```Go 实现遵循与 Python 版本相同的逻辑。 映射用于恒定时间元音查找。 

由于 Go 中的字符串是 ASCII 字符的字节切片，因此我们可以使用索引直接访问字符，如下所示：```go
word[0]
```和```go
word[len(word)-1]
```该问题仅保证小写英文字母，因此字节索引在这里是完全安全的。

 ## 边缘情况

 一个重要的边缘情况是单个字符单词，例如`"u"`。 由于该单词的长度为一，因此第一个和最后一个字符相同。 粗心的实现可能会错误地假设该单词必须至少包含两个字符。 该解决方案正确处理了这种情况，因为`word[0]`和`word[-1]`引用同一个字符。 

另一个重要的边缘情况发生在`left == right`。 在这种情况下，该范围恰好包含一个单词。 某些实现意外地跳过处理，因为它们使用了不正确的循环边界。 该解决方案使用：```
range(left, right + 1)
```它正确地包括两个端点。 

第三种边缘情况是没有单词符合元音字符串的条件。 例如：```
["ab", "cd", "ef"]
```这些单词都不以元音开头和结尾。 该实现自然地处理了这个问题，因为计数器仅在满足两个条件时才会增加。 如果没有找到有效的单词，则初始值`0`返回原样。
