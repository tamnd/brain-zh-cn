 ## 解决方案

 ## 问题理解

 该问题要求我们计算正整数数组的乘积中**不同质因数**的数量，`nums`。 简单来说，我们得到一个数字列表，如果我们将所有数字相乘并对结果进行因式分解，我们想知道会出现多少个唯一的素数。 

输入`nums`是一个整数数组，其中每个整数至少为 2，最多为 1000，并且该数组最多可包含 10,000 个元素。 此约束确保单个数字很小，但它们的乘积可能非常大 - 太大而无法直接计算。 因此，将所有数字相乘然后对结果进行因式分解的简单方法将由于整数溢出或性能限制而失败。 

预期输出是一个整数：除以数组中所有元素的乘积的唯一素数的计数。 

重要的观察结果包括：

 - 每个数字都在 2 到 1000 之间，因此所有质因数也都 ≤ 1000。 
- 不同数量的重复素数只应计算一次。 
- 由于溢出，显式地将所有数字相乘是不必要且不切实际的。 

可能挑战简单解决方案的边缘情况包括：

 1. 所有数字都是同一个素数的幂（例如，`[2,4,8,16]`），其中乘积只有一个不同的素因数。 
2. 数字本身就是不同的素数。 
3. 具有重叠质因数的数字（例如，`[6,10,15]`）。 

## 方法

 蛮力方法是首先将所有数字相乘`nums`形成乘积，然后对乘积进行因式分解以计算不同的质因数。 这在数学上是正确的，但由于大型阵列的乘积尺寸巨大，因此不切实际。 它还需要高精度运算以避免溢出。 

最佳方法利用了所有数字都≤ 1000 的关键观察结果。我们可以使用埃拉托斯特尼筛法预先计算 1000 以内的所有素数。 然后，对于每个数字`nums`，我们直接分解它并将其素数因子插入到一个集合中以跟踪唯一的素数。 这避免了数字相乘并保持运算效率，因为每个数字都很小并且分解速度很快。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(1) | O(1) | 将所有数字相乘（m = 乘积中的位数），然后进行因式分解，由于溢出而不切实际 |
 | 最佳 | O(n * √maxNum) | O(n * √maxNum) | O(p) | 直接使用 maxNum (≤1000) 以内的素数对每个数字进行因式分解，存储在集合中 (p = 不同素数的数量 ≤1000) |

 ## 算法演练

 1. 使用埃拉托斯特尼筛法生成 1000 以内的所有素数。 这允许对数字进行有效的因式分解`nums`。 
2.初始化一个空集，`distinct_primes`，存储独特的质因数。 
3. 迭代每个数字`num`在`nums`。 
4. 对于每个`num`，迭代素数列表：

 - 如果素数整除`num`，将其添加到`distinct_primes`。 
- 继续划分`num`乘素数，直到它不再整除。 
- 停止检查进一步的素数，如果`num`变为 1。 
5.处理完所有数字后，返回大小`distinct_primes`。 

工作原理：每个数字中的每个质因数都只在集合中插入一次，以确保唯一性。 因为我们直接对每个数字进行因式分解，所以我们避免了不切实际的大数乘法。 筛子保证我们考虑所有可能出现的素数。 

## Python 解决方案```python
from typing import List

class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        def sieve(n: int) -> List[int]:
            is_prime = [True] * (n + 1)
            is_prime[0] = is_prime[1] = False
            for i in range(2, int(n**0.5) + 1):
                if is_prime[i]:
                    for j in range(i*i, n + 1, i):
                        is_prime[j] = False
            return [i for i, val in enumerate(is_prime) if val]
        
        primes = sieve(1000)
        distinct_primes = set()
        
        for num in nums:
            for prime in primes:
                if prime * prime > num:
                    break
                if num % prime == 0:
                    distinct_primes.add(prime)
                    while num % prime == 0:
                        num //= prime
            if num > 1:
                distinct_primes.add(num)
        
        return len(distinct_primes)
```Python 实现首先使用筛子预先计算 1000 以内的所有素数。 然后，对于数组中的每个数字，它检查每个素数的整除性并记录唯一的素数因子。 如果一个数本身是大于其原始值的平方根的素数，则将其直接添加到集合中。 

## 解决方案```go
func distinctPrimeFactors(nums []int) int {
    sieve := func(n int) []int {
        isPrime := make([]bool, n+1)
        for i := 2; i <= n; i++ {
            isPrime[i] = true
        }
        for i := 2; i*i <= n; i++ {
            if isPrime[i] {
                for j := i * i; j <= n; j += i {
                    isPrime[j] = false
                }
            }
        }
        primes := []int{}
        for i := 2; i <= n; i++ {
            if isPrime[i] {
                primes = append(primes, i)
            }
        }
        return primes
    }

    primes := sieve(1000)
    distinct := make(map[int]struct{})

    for _, num := range nums {
        temp := num
        for _, prime := range primes {
            if prime*prime > temp {
                break
            }
            if temp%prime == 0 {
                distinct[prime] = struct{}{}
                for temp%prime == 0 {
                    temp /= prime
                }
            }
        }
        if temp > 1 {
            distinct[temp] = struct{}{}
        }
    }

    return len(distinct)
}
```Go 解决方案遵循与 Python 相同的逻辑。 它使用具有空结构的映射来模拟用于存储不同素数的集合。 筛选和因式分解逻辑是等效的，适合 Go 的语法和类型。
