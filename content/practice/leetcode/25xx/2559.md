[LeetCode 问题 2559](https://leetcode.com/problems/count-vowel-strings-in-ranges/)

 **难度：** 🟡 中等
 **主题：** 数组、字符串、前缀和

 ## 解决方案

 ## 问题理解

 该问题给了我们一个名为的字符串数组`words`和一个名为的范围查询列表`queries`。 

对于每个查询`[li, ri]`，我们必须确定有多少个字符串`words`指数之间`li`和`ri`，包含在内，均以元音开头和结尾。 元音仅限于小写英语元音：`'a'`,`'e'`,`'i'`,`'o'`， 和`'u'`。 

如果满足以下条件，则字符串被视为有效：

 - 它的第一个字符是元音
 - 它的最后一个字符也是元音

 例如：

 -`"aba"`有效，因为它开头为`'a'`并以`'a'`-`"ece"`有效，因为它开头为`'e'`并以`'e'`-`"bcb"`无效，因为它开头为`'b'`输出应该是一个数组，其中每个元素对应于一个查询的答案。 

约束很重要，因为它们强烈影响算法的选择：

 -`words.length`可以大到`10^5`-`queries.length`也可以大到`10^5`在最坏的情况下，扫描每个查询范围内的每个单词的简单方法会变得太慢。 如果每个查询都需要迭代几乎整个数组，则总工作量可能达到`10^10`的操作，远远超出了可接受的范围。 

该问题保证：

 - 每个字符串仅包含小写英文字母
 - 每个字符串的长度至少为 1
 - 查询范围始终有效，意味着`0 <= li <= ri < words.length`这些保证简化了实现，因为我们永远不需要处理空字符串或无效索引。 

重要的边缘情况包括：

 - 每个字符串都有效的数组
 - 没有有效字符串的数组
 - 覆盖单个索引的查询，例如`[3,3]`- 投入非常大，效率变得至关重要
 - 长度为1的字符串，例如`"a"`或者`"b"`单字符字符串值得特别注意，因为第一个和最后一个字符是相同的字符。`"a"`是有效的，同时`"b"`不是。 

## 方法

 ### 蛮力方法

 最直接的解决方案是独立处理每个查询。 

对于每个查询`[li, ri]`，我们迭代索引中的所有单词`li`到`ri`。 对于每个单词，我们检查是否：

 - 第一个字符是元音
 - 最后一个字符是元音

 如果两个条件都成立，我们就增加一个计数器。 

这种方法是正确的，因为它显式检查请求范围内的每个候选字符串。 然而，对于大量输入来说，它的效率很低。 

认为：

-`n = 100000`-`q = 100000`如果每个查询几乎跨越整个数组，我们可以执行大约`10^10`检查。 

对于竞争性编程限制而言，这太慢了。 

### 最优方法，前缀和

 关键的观察是每个单词都可以独立分类为：

 - 有效，表示为`1`- 无效，表示为`0`一旦我们将数组转换为二进制值，问题就变成了经典的范围求和查询问题。 

例如：```
words = ["aba","bcb","ece","aa","e"]

valid = [1,0,1,1,1]
```现在问题变成：

 “有多少`1`索引之间存在 s`li`和`ri`？”

 这正是前缀和有效解决的问题。 

我们构建一个前缀和数组，其中：```
prefix[i]
```存储第一个中有效字符串的数量`i`元素。 

那么任意范围的答案`[li, ri]`可以在常数时间内计算：```
prefix[ri + 1] - prefix[li]
```这极大地减少了总查询处理时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(q × n) | O(1) | O(1) | 直接扫描每个范围 |
 | 最佳| O(n + q) | O(n) | 使用前缀和进行恒定时间范围查询 |

 ## 算法演练

 1. 创建一个包含所有元音的集合。 

我们使用集合是因为​​成员资格查找非常快，平均时间复杂度为 O(1)。```
vowels = {'a', 'e', 'i', 'o', 'u'}
```2.创建大小为前缀和的数组`len(words) + 1`。 

开头的额外位置简化了范围计算。```
prefix[0] = 0
```3. 迭代`words`大批。 

对于每个单词：

 - 检查第一个字符是否是元音
 - 检查最后一个字符是否是元音

 如果两个条件都为真，则将单词标记为有效值`1`。 否则使用`0`。 
4. 增量构建前缀和。 

在索引处`i`：```
prefix[i + 1] = prefix[i] + valid
```这意味着：

-`prefix[i]`存储索引之前的有效单词数`i`-`prefix[i + 1]`包括当前单词
 5. 处理每个查询。 

供查询`[li, ri]`，计算：```
prefix[ri + 1] - prefix[li]
```这会减去之前的所有有效单词`li`，只留下目标范围内的有效单词。 
6. 将每个查询结果存储在answer数组中。 
7. 返回完整的答案数组。 

### 为什么它有效

 前缀和数组保持以下不变量：```
prefix[i]
```等于索引中有效字符串的数量`[0, i-1]`。 

由于这个属性：```
prefix[ri + 1]
```包含从头到尾的有效字符串数`ri`。 

相似地：```
prefix[li]
```包含之前有效字符串的数量`li`。 

减去它们可以准确地隔离其中的有效字符串`[li, ri]`。 

这保证了每个查询的正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def vowelStrings(self, words: List[str], queries: List[List[int]]) -> List[int]:
        vowels = {'a', 'e', 'i', 'o', 'u'}

        n = len(words)

        # prefix[i] stores the number of valid words
        # among words[0:i]
        prefix = [0] * (n + 1)

        for i in range(n):
            word = words[i]

            is_valid = (
                word[0] in vowels and
                word[-1] in vowels
            )

            prefix[i + 1] = prefix[i] + (1 if is_valid else 0)

        answer = []

        for left, right in queries:
            count = prefix[right + 1] - prefix[left]
            answer.append(count)

        return answer
```实现首先创建一个元音集以进行快速成员资格检查。 

接下来，我们分配一个长度的前缀和数组`n + 1`。 附加的前导零允许更清晰的范围计算，无需对从索引开始的范围进行特殊处理`0`。 

主预处理循环单独检查每个单词。 如果一个单词的第一个和最后一个字符都属于元音集，则该单词是有效的。 

然后前缀和数组被增量更新。 每个位置存储迄今为止看到的有效单词的累积数量。 

预处理后，使用前缀和公式在恒定时间内回答每个查询：```python
prefix[right + 1] - prefix[left]
```最后，所有结果都以列表形式返回。 

## 解决方案```go
func vowelStrings(words []string, queries [][]int) []int {
    vowels := map[byte]bool{
        'a': true,
        'e': true,
        'i': true,
        'o': true,
        'u': true,
    }

    n := len(words)

    prefix := make([]int, n+1)

    for i := 0; i < n; i++ {
        word := words[i]

        isValid := vowels[word[0]] && vowels[word[len(word)-1]]

        if isValid {
            prefix[i+1] = prefix[i] + 1
        } else {
            prefix[i+1] = prefix[i]
        }
    }

    result := make([]int, 0, len(queries))

    for _, query := range queries {
        left := query[0]
        right := query[1]

        count := prefix[right+1] - prefix[left]

        result = append(result, count)
    }

    return result
}
```Go 实现遵循与 Python 版本相同的算法结构。 

一个显着的区别是 Go 字符串是使用字节进行索引的。 由于该问题仅保证小写英文字母，因此索引单个字节是完全安全的。 

元音查找使用`map[byte]bool`进行有效的会员测试。 

切片自然地用于前缀和数组和结果数组。 

整数溢出不是问题，因为最大计数不能超过`10^5`，它很容易适合 Go 的内部`int`类型。

 ## 边缘情况

 ### 单字符串

 长度为 1 的字符串具有相同的第一个和最后一个字符。 如果实现假设至少有两个字符，这很容易引入错误。 

例如：```
"a"
```应该算作有效，因为`'a'`既是第一个字符也是最后一个字符。 

该实现自然地处理了这个问题，因为：```
word[0] == word[-1]
```对于单字符字符串。 

### 覆盖一个元素的查询

 查询例如：```
[3,3]
```必须正确评估一个单词。 

一些不正确的实现意外地将范围视为半开区间或引入相差一的错误。 

使用前缀公式：```
prefix[right + 1] - prefix[left]
```正确处理单索引范围，没有任何特殊情况。 

### 没有有效字符串

 如果每个字符串都以辅音开头或结尾，则每个查询答案都应该为零。 

例如：```
words = ["b", "cd", "xyz"]
```前缀数组保持完全为零：```
[0,0,0,0]
```减法逻辑仍然可以正常工作，因为减去相等的前缀值会产生零。 

### 大输入

 高达`10^5`词和`10^5`查询，低效的解决方案将会超时。 

前缀和方法通过预处理一次并在恒定时间内回答每个查询来避免重复扫描。 

这保证了解决方案即使在最大输入大小下也保持高效。
