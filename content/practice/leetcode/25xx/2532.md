[LeetCode 问题 2532](https://leetcode.com/problems/time-to-cross-a-bridge/)

 **难度：** 🔴难
 **主题：** 数组、堆（优先级队列）、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们模拟一个场景，其中`k`工人运输`n`箱子从右侧仓库过桥到左侧仓库。 每个工人都有四个动作的单独计时：向右过桥（`righti`），拿起右边的一个盒子（`picki`），回到左边（`lefti`），然后将盒子放在左边（`puti`）。 所有工人都从左侧开始，桥上一次只能允许一名工人。 挑战是计算最后一个盒子到达桥左侧时所用的时间。 

输入包括盒子的数量`n`, 工人数量`k`，和一个二维数组`time`尺寸的`k x 4`代表个人的时间安排。 输出是一个整数，表示最后一个盒子到达左侧的时刻，**不包括放下时间**。 

约束条件如`1 <= n, k <= 10^4`和`1 <= time[i][j] <= 1000`表明该解决方案必须是高效的。 由于潜在的运行时间超过，每分钟迭代一次的简单模拟是不切实际的$10^8$步骤。 

这个问题引入了**工人效率**：如果一个工人的效率低于另一个工人，`left + right`时间越高，或者如果相等，具有较高索引的工人效率较低。 当多个工作人员等待时，桥接规则强制执行效率最低的工作人员的优先级。 

边缘情况包括只有一名工人、只有一个盒子或时间相同的工人，这可能会影响桥的优先级。 

## 方法

 ### 蛮力方法

 一种简单的方法是模拟桥梁和工人每分钟的移动。 我们会跟踪每个工人的状态，将他们移过桥，挑选箱子并放置它们。 在每次增量时，我们都会根据效率和桥梁是否空闲来决定下一个过桥的人。 这种方法是**正确**，但效率低下，因为`n`和`k`最多$10^4$，模拟可能需要数十亿步，使其不可行。 

### 最佳方法

 关键的见解是**事件发生在离散的时刻**而不是每一分钟。 我们不是每分钟迭代，而是使用**优先级队列**跟踪下一个可能的事件。 在左侧或右侧等待的工作人员存储在堆中，优先考虑**效率最低的工作人员**（根据问题规则）。 正在进行操作（拾取或放置箱子）的工人被存储在一个堆中，其键值是其完成时间。 

通过反复将时间提前到下一个最早的事件并更新状态，我们可以有效地模拟该过程。 该方法降低了潜在的复杂性`O(n * k * max(time))`到`O(n log k)`由于堆操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大(时间) * k) | O(k) | 逐分钟模拟，对于大 n 来说太慢 |
 | 最佳 | O(n log k) | O(n log k) | O(k) | 使用优先级队列进行基于事件的模拟以实现高效的工人管理

 ## 算法演练

 1. 预先计算每个工人的**效率关键**为`(lefti + righti, index)`。 该键用于对过桥的优先级进行排序。 效率较低（总穿越时间较长）是第一位的。 
2.初始化两个堆：`left_heap`对于在左边等候的工人`right_heap`对于右边的工人来说。 堆首先使用密钥优先考虑**效率最低的工人**。 
3. 初始化两个事件堆：`pick_heap`对于正在挑选箱子的工人，以及`put_heap`对于目前正在放下箱子的工人。 每个事件堆都以工作人员完成操作的时间为键。 
4. 启动一个变量`current_time = 0`。 
5. 当桥上还有剩余的箱子或工人时：

 1. 进阶`current_time`如果没有工人可以立即通过，则进入下一个终点事件。 
2. 通过将所有工人推到相应的桥堆上来处理完成拾取或放置操作的所有工人。 
3. 如果桥是空闲的，则从其中选择**效率最低的工人**`right_heap`第一的; 如果为空，则使用`left_heap`。 
4. 更新`current_time`当选定的工人过马路时。 
5、穿越后，将工人推入相应的动作堆中（`pick_heap`或者`put_heap`）与完成时间。 
6. 如果工人开始运输箱子，请减少剩余箱子数量。 
6. 工人最后到达左侧桥的时间就是答案。 

**为什么有效：** 堆保持不变性，即始终根据规则选择下一个可用的工作线程。 事件堆确保时间有效推进，并且工作状态正确转换。 这保证了正确性，而无需模拟每一分钟。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def findCrossingTime(self, n: int, k: int, time: List[List[int]]) -> int:
        # Precompute efficiency and initialize heaps
        left_heap = []
        right_heap = []
        pick_heap = []
        put_heap = []
        
        for i, (right, pick, left, put) in enumerate(time):
            # Efficiency key: higher sum first, then higher index
            heapq.heappush(left_heap, (-(left + right), -i, i))
        
        boxes_remaining = n
        current_time = 0
        last_cross_time = 0
        
        while boxes_remaining > 0 or right_heap or pick_heap or put_heap:
            # Move workers from pick_heap and put_heap to bridge heaps if finished
            while pick_heap and pick_heap[0][0] <= current_time:
                _, worker_idx = heapq.heappop(pick_heap)
                heapq.heappush(right_heap, (-(time[worker_idx][2] + time[worker_idx][0]), -worker_idx, worker_idx))
            
            while put_heap and put_heap[0][0] <= current_time:
                _, worker_idx = heapq.heappop(put_heap)
                heapq.heappush(left_heap, (-(time[worker_idx][2] + time[worker_idx][0]), -worker_idx, worker_idx))
            
            # Determine who can cross
            if right_heap:
                eff, neg_idx, worker_idx = heapq.heappop(right_heap)
                current_time += time[worker_idx][2]  # left crossing
                last_cross_time = current_time
                heapq.heappush(put_heap, (current_time + time[worker_idx][3], worker_idx))
            elif boxes_remaining > 0 and left_heap:
                eff, neg_idx, worker_idx = heapq.heappop(left_heap)
                current_time += time[worker_idx][0]  # right crossing
                heapq.heappush(pick_heap, (current_time + time[worker_idx][1], worker_idx))
                boxes_remaining -= 1
            else:
                # Advance time to the next event
                next_times = []
                if pick_heap:
                    next_times.append(pick_heap[0][0])
                if put_heap:
                    next_times.append(put_heap[0][0])
                if next_times:
                    current_time = max(current_time, min(next_times))
        
        return last_cross_time
```该实现使用四个堆来管理工作人员：`left_heap`和`right_heap`优先考虑效率最低的工人准备穿越，同时`pick_heap`和`put_heap`安排事件的完成时间。`current_time`始终跳转到下一个有意义的事件，确保高效的模拟。
