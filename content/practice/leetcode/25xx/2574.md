[LeetCode 问题 2574](https://leetcode.com/problems/left-and-right-sum-differences/)

 **难度：** 🟢简单
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定数组中每个元素左侧元素总和与右侧元素总和之间的绝对差`nums`。 换句话说，对于每个索引`i`，我们想知道该索引两侧的总和有多大差异。 输入是一个从 0 索引的整数数组，其中每个元素至少为 1，最多为 100,000，并且该数组最多可包含 1,000 个元素。 输出应该是一个相同长度的数组，其中每个元素都是以下的绝对值`leftSum[i] - rightSum[i]`。 

主要观察结果包括第一个元素始终具有`leftSum`为 0，最后一个元素总是有`rightSum`为 0。边缘情况包括长度为 1 的数组，其中左右总和为零，以及所有元素都相等或非常大的数组，测试数值限制和总和正确性。 

## 方法

 蛮力方法涉及计算`leftSum[i]`和`rightSum[i]`每个索引分别`i`通过迭代相关的子数组。 这是正确的，但效率很低，因为对于每个索引，在最坏的情况下我们会遍历数组两次，导致时间复杂度为$O(n^2)$，这对于小型数组来说是可以接受的，但效率较低`n`接近1000。 

最佳方法使用前缀和和运行总计。 我们首先计算数组的总和，而不是重复地重新计算总和。 然后我们保持运行`leftSum`当我们遍历数组时。 对于每个元素，`rightSum`可以计算为`totalSum - leftSum - nums[i]`，并且绝对差很容易计算。 这将时间复杂度降低到$O(n)$仅使用时$O(1)$输出数组之外的额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 分别计算每个索引的左右总和 |
 | 最佳| O(n) | O(1) | O(1) | 使用运行左总和和总和来动态计算右总和 |

 ## 算法演练

 1. 计算数组的总和`nums`。 这使我们能够得出`rightSum[i]`在任何索引处无需重新计算。 
2. 初始化`leftSum`到 0。当我们从左到右迭代时，这将累积元素的总和。 
3. 创建输出数组`answer`与相同长度`nums`。 
4. 迭代每个索引`i`的`nums`：

 1. 计算`rightSum[i]`作为`totalSum - leftSum - nums[i]`。 
2. 计算绝对差`|leftSum - rightSum[i]|`并将其分配给`answer[i]`。 
3. 更新`leftSum`通过添加`nums[i]`到下一次迭代。 
5. 返回`answer`大批。 

**为什么有效：** 通过维持运行`leftSum`并推导`rightSum`从总和中，我们避免了重复的求和运算。 这确保了每个索引的计算都是在恒定的时间内完成的，保证了正确性和效率。 

## Python 解决方案```python
from typing import List

class Solution:
    def leftRightDifference(self, nums: List[int]) -> List[int]:
        total_sum = sum(nums)
        left_sum = 0
        answer = []
        
        for num in nums:
            right_sum = total_sum - left_sum - num
            answer.append(abs(left_sum - right_sum))
            left_sum += num
        
        return answer
```在这个Python实现中，我们首先计算`total_sum`所有元素。 我们初始化`left_sum`归零并迭代每个数字，计算`right_sum`即时并将绝对差附加到`answer`列表。 最后我们更新一下`left_sum`用于下一次迭代。 

## 解决方案```go
func leftRightDifference(nums []int) []int {
    totalSum := 0
    for _, num := range nums {
        totalSum += num
    }

    leftSum := 0
    answer := make([]int, len(nums))
    
    for i, num := range nums {
        rightSum := totalSum - leftSum - num
        if leftSum > rightSum {
            answer[i] = leftSum - rightSum
        } else {
            answer[i] = rightSum - leftSum
        }
        leftSum += num
    }

    return answer
}
```Go 解决方案反映了 Python 方法。 我们计算`totalSum`首先，初始化`leftSum`为零，然后迭代数组。 绝对差是使用条件计算的，因为 Go 没有内置的`abs`整数函数。 我们更新`leftSum`在每次迭代中并返回结果切片。

 ## 边缘情况

 **单元素数组：** 唯一的元素没有左或右邻居，因此差值为 0。Python 和 Go 实现都通过将和初始化为零来自然地处理此问题。 

**所有元素相等：** 当内部元素的左右总和相同时，这测试代码是否正确计算总和。 我们的运行总和方法可以有效地处理这个问题，不会出现错误。 

**接近 100,000 的大数：** 大数的总和可能达到 100,000 * 1,000 = 100,000,000，这完全在 Python 整数限制之内，但需要在 Go 等静态类型语言中小心处理。 使用`int`在 Go 中是安全的，因为典型的 Go`int`至少是32位，加和到1亿是安全的。
