[LeetCode 问题 2515](https://leetcode.com/problems/shortest-distance-to-target-string-in-a-circular-array/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们找到从字符串循环数组中给定起始索引到目标字符串的最短距离。 数组的循环性质意味着移动经过末尾会回绕到开头，并且在第一个元素之前移动会回绕到最后一个元素。 这很重要，因为最短距离可能涉及沿任一方向环绕阵列。 

输入是`words`，小写字符串列表，`target`，我们想要到达的字符串，以及`startIndex`，我们开始的索引。 输出是一个整数，表示达到任何发生所需的最小步骤数`target`。 如果`target`没有出现在`words`，我们必须返回`-1`。 

约束表明数组长度很小（`1 <= words.length <= 100`）并且每个字符串都相对较短（`1 <= words[i].length <= 100`）。 这表明即使 O(n²) 解决方案也可能是可行的，但存在更简单的 O(n) 方法并且更优雅。 

关键的边缘情况包括：

 - 目标位于起始索引处。 
- 目标出现多次，最短路径可能是向左或向右。 
- 目标不存在。 
- 数组仅包含一个元素。 

## 方法

 暴力方法是从起始索引开始在两个方向上迭代数组，并计算到目标每次出现的距离。 对于每个元素，我们考虑圆形环绕来计算前向距离和后向距离。 然后我们取这些距离中的最小值。 这种方法之所以有效，是因为它显式检查所有可能的路径，但需要多次扫描数组。 

最佳方法利用了我们可以使用模算术计算索引之间的圆形距离的观察。 对于目标的每次出现，最短距离可以表示为顺时针或逆时针移动的最小值。 通过对数组进行一次迭代并应用此计算，我们可以有效地确定最小距离。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 针对每个目标出现重复双向扫描 |
 | 最佳 | O(n) | O(1) | O(1) | 单次计算到所有出现的目标的圆形距离 |

 ## 算法演练

 1. 初始化变量`min_distance`到无穷大。 这将记录找到的最小距离。 
2. 遍历数组`words`使用索引`i`。 
3. 对于每个`i`在哪里`words[i]`等于`target`，计算前进距离为`(i - startIndex + n) % n`向后距离为`(startIndex - i + n) % n`。 
4. 更新`min_distance`为自身、前向距离和后向距离的最小值。 
5. 遍历数组后，检查是否`min_distance`仍然是无穷大。 如果是，则返回`-1`因为没有找到目标。 否则，返回`min_distance`。 

为什么有效：通过考虑目标每次出现的前向和后向距离并取最小值，我们保证找到圆形阵列中的最短路径。 模运算确保正确的环绕计​​算。 

## Python 解决方案```python
from typing import List

class Solution:
    def closestTarget(self, words: List[str], target: str, startIndex: int) -> int:
        n = len(words)
        min_distance = float('inf')
        
        for i in range(n):
            if words[i] == target:
                forward = (i - startIndex + n) % n
                backward = (startIndex - i + n) % n
                min_distance = min(min_distance, forward, backward)
        
        return -1 if min_distance == float('inf') else min_distance
```实现首先初始化`min_distance`为无穷大来处理未找到目标的情况。 然后它迭代数组的所有索引。 每当它找到目标时，它就会使用模运算计算向前和向后的圆形距离。 存储所有出现的最小距离。 最后，如果没有发现任何事件，则返回`-1`; 否则，它返回计算的最小距离。 

## 解决方案```go
func closestTarget(words []string, target string, startIndex int) int {
    n := len(words)
    minDistance := n + 1 // larger than any possible distance
    
    for i, word := range words {
        if word == target {
            forward := (i - startIndex + n) % n
            backward := (startIndex - i + n) % n
            if forward < minDistance {
                minDistance = forward
            }
            if backward < minDistance {
                minDistance = backward
            }
        }
    }
    
    if minDistance > n {
        return -1
    }
    return minDistance
}
```Go 实现遵循相同的逻辑。 由于Go缺乏`inf`，我们初始化`minDistance`到`n+1`作为安全上限。 使用模运算计算前向和后向距离，并类似地更新最小值。 如果没有找到目标，函数返回`-1`。

 ## 边缘情况

 一种重要的边缘情况是目标位于起始索引本身。 在这种情况下，向前和向后的距离都为零，并且算法正确地返回 0，因为`min_distance`用其自身和这些距离的最小值进行更新。 

另一种边缘情况是目标多次出现。 最短路径可能需要环绕圆形阵列，并且使用模运算可确保在两个方向上正确计算最小距离。 

第三种边缘情况是当数组中不存在目标时。 自从`min_distance`初始化为无穷大 (Python) 或大于的值`n`(Go)，算法可以安全地检测到没有发现任何事件并返回 -1。 这避免了距离计算中的意外误报。
