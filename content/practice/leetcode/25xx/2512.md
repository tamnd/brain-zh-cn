[LeetCode 第 2512 题](https://leetcode.com/problems/reward-top-k-students/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们根据学生收到的文本反馈来计算学生的排名。 我们有两个单词列表：`positive_feedback`和`negative_feedback`。 每次学生收到报告时，我们都会为报告中出现的每个单词添加 3 分来对该报告进行评分`positive_feedback`每出现一个单词就扣 1 分`negative_feedback`。 每份报告都通过以下方式与一名学生相关联：`student_id`大批。 处理完所有报告后，我们被要求返回顶部`k`排名第一的学生按分数降序排列，如出现平局，则按学号升序排列。 

输入包括：

 -`positive_feedback`和`negative_feedback`包含不同单词的列表。 
-`report`，一个字符串列表，每个字符串代表一份学生报告。 
-`student_id`，表示与每个报告对应的学生 ID 的整数列表。 
-`k`，尖子生返校人数。 

约束表明输入大小适中（`n`最多 10^4 个单词，每个反馈单词列表最多 10^4 个单词），这意味着解决方案必须在时间和空间上都高效。 可能导致错误的边缘情况包括报告中仅包含正面或仅包含负面词语、多名学生得分相同或报告中的词语未出现在任一反馈列表中。 

## 方法

 暴力方法会迭代每个报告，将其拆分为单词，并针对每个单词检查它是否在`positive_feedback`或者`negative_feedback`。 然后我们在字典中更新学生的总分。 计算完所有分数后，我们将所有学生先按分数降序排序，然后按 ID 升序排序，取第一个`k`学生。 这种方法是正确的，但可能很慢，因为检查列表中的成员资格具有 O(m) 复杂度，其中 m 是反馈列表的长度，从而使总复杂度为 O(n * m * L)，其中 L 是每个报告的平均字数。 

最佳方法依赖于将正反馈列表和负反馈列表转换为集合，这允许 O(1) 成员资格检查。 然后，我们迭代每个报告，将其拆分为单词，使用这些集合有效地计算分数，并维护学生 ID 到累积分数的映射。 最后，我们根据元组对学生进行排序`(-score, student_id)`达到所需的排名并获得榜首`k`学生。 这大大降低了成员资格检查的复杂性，并使解决方案保持在可行的时间限制内。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m * L) | O(n) | 对于大型反馈列表，列表成员资格检查速度很慢 |
 | 最佳| O(n * L + m + p + n log n) | O(n * L + m + p + n log n) | O(n + m + p) | 使用集合进行 O(1) 查找并按分数和 ID 对学生进行排序 |

 在哪里`m`和`p`是正面和负面反馈列表的长度，`n`是报告的数量，并且`L`是每份报告的平均字数。 

## 算法演练

 1. 转换`positive_feedback`和`negative_feedback`成套`positive_set`和`negative_set`用于快速会员查找。 这确保了每个字检查的时间复杂度为 O(1)。 
2.初始化一个空字典`student_scores`跟踪每个学生的累积分数。 
3. 迭代每个报告及其对应的`student_id`。 对于每份报告，将其分成单词。 
4. 初始化一个`score`当前报告的计数器。 对于报告中的每个单词，如果该单词位于`positive_set`, 增量`score`3.如果是在`negative_set`, 递减`score`1. 不在任一组中的单词不会影响分数。 
5. 添加计算的`score`为当前学生的累计分数`student_scores`。 
6. 处理完所有报告后，创建元组列表`(student_id, score)`从`student_scores`。 
7. 根据键对此列表进行排序`(-score, student_id)`这样，分数越高，学生 ID 越低，平局就被打破。 
8. 提取第一个`k`从排序列表中查找学生 ID 并返回它们。 

**为什么有效**：该算法保证了正确性，因为我们严格根据规则计算每个学生的总分，并按指定的确切标准进行排序。 集合的使用可确保高效的单词查找，排序可确保根据学生 ID 正确解析关系。 

## Python 解决方案```python
from typing import List

class Solution:
    def topStudents(self, positive_feedback: List[str], negative_feedback: List[str], report: List[str], student_id: List[int], k: int) -> List[int]:
        positive_set = set(positive_feedback)
        negative_set = set(negative_feedback)
        
        student_scores = {}
        
        for sid, rep in zip(student_id, report):
            score = 0
            for word in rep.split():
                if word in positive_set:
                    score += 3
                elif word in negative_set:
                    score -= 1
            student_scores[sid] = student_scores.get(sid, 0) + score
        
        sorted_students = sorted(student_scores.items(), key=lambda x: (-x[1], x[0]))
        return [sid for sid, _ in sorted_students[:k]]
```该代码首先构建用于快速单词查找的集合，然后迭代每个报告并计算每个学生的分数。 字典会累积分数，最终排序确保学生根据学生 ID 打平的分数进行排名。 

## 解决方案```go
import (
    "sort"
    "strings"
)

func topStudents(positive_feedback []string, negative_feedback []string, report []string, student_id []int, k int) []int {
    positiveSet := make(map[string]struct{}, len(positive_feedback))
    negativeSet := make(map[string]struct{}, len(negative_feedback))
    
    for _, word := range positive_feedback {
        positiveSet[word] = struct{}{}
    }
    for _, word := range negative_feedback {
        negativeSet[word] = struct{}{}
    }
    
    studentScores := make(map[int]int)
    
    for i, rep := range report {
        score := 0
        words := strings.Fields(rep)
        for _, word := range words {
            if _, ok := positiveSet[word]; ok {
                score += 3
            } else if _, ok := negativeSet[word]; ok {
                score -= 1
            }
        }
        studentScores[student_id[i]] += score
    }
    
    type pair struct {
        id, score int
    }
    
    students := make([]pair, 0, len(studentScores))
    for id, score := range studentScores {
        students = append(students, pair{id, score})
    }
    
    sort.Slice(students, func(i, j int) bool {
        if students[i].score == students[j].score {
            return students[i].id < students[j].id
        }
        return students[i].score > students[j].score
    })
    
    res := make([]int, k)
    for i := 0; i < k; i++ {
        res[i] = students[i].id
    }
    return res
}
```Go 版本反映了 Python 逻辑。 主要区别在于处理切片与列表、使用具有空结构的映射作为集合以及使用`strings.Fields`将报告拆分成文字。
