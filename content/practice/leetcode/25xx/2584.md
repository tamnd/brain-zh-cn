 ## 解决方案

 ## 问题理解

 问题是要求我们在数组中找到有效的分割点`nums`其中分割左侧元素的乘积和右侧元素的乘积是**互质**。 形式上，如果我们在索引处拆分`i`，左积为`nums[0] * nums[1] * ... * nums[i]`正确的产品是`nums[i+1] * ... * nums[n-1]`。 分割有效，如果`gcd(left_product, right_product) == 1`。 

输入是一个从 0 索引的整数数组，其中`1 <= nums[i] <= 10^6`和数组长度`n`可以达到`10^4`。 输出是**最小的有效分割索引**，或者`-1`如果不存在有效的分割。 

由于直接计算乘积可能会变得非常大，因此简单的实现可能会由于整数溢出或过多的计算而失败。 此外，在每次拆分的完整产品上重复检查 GCD 效率很低。 边缘情况包括所有元素均为素数的数组、具有重复因子的数组或不存在有效分割的数组。 

## 方法

 **暴力方法：**朴素方法计算每个可能的分割索引的左右子数组的乘积`i`并检查它们的 GCD 是否为 1。这保证了正确性，但对于给定的约束是不可行的，因为乘积可以超过 64 位整数，并且重复计算它们会导致 O(n²) 复杂度。 

**最佳方法：** 关键的见解是，如果两个数字**不共享质因数**，则它们是互质的。 我们不计算完整的乘积，而是跟踪每个元素的**主要因素**。 通过维护数组中每个质因数的**最后一次出现**的映射，我们知道右侧仍然存在任何质因数的最早索引。 有效分割发生在**任何质因数最后一次出现之前**。 

这将问题简化为使用哈希映射有效地分解数字和跟踪素数范围，从而避免大整数乘法。

 | 蛮力 | O(n² log M) | O(n² log M) | O(1) | O(1) | 直接计算乘积和GCD，其中M是最大乘积值 |
 | 最佳 | O(n log M) | O(n log M) | O(n) | 对数字进行因式分解并跟踪每个质因数的最后一次出现 |

 ## 算法演练

 1. **质因数分解图：** 对于中的每个元素`nums`，计算其素因数。 使用最多 √num 的试除法以提高效率。 
2. **跟踪最近出现的情况：** 维护字典`last_occurrence`将每个质因数映射到它出现的最后一个索引`nums`。 
3. **初始化分割跟踪：** 设置`max_last_index = 0`它将跟踪最右边的索引，其中素数因子最后一次出现会影响当前的分割。 
4. **迭代数组：** 对于每个索引`i`:

 - 对于每个素因数`nums[i]`， 更新`max_last_index`到`max(max_last_index, last_occurrence[prime])`。 
- 如果`i == max_last_index`，从 0 到 i 的所有质因数不再存在于剩余数组中，使得左右乘积互质。 返回`i`。 
5. **No Split Found:** 如果迭代完成后没有找到这样的索引，则返回`-1`。 

**为什么有效：** 这是有效的，因为左右子数组中出现的任何质因数都会阻止互质性。 通过跟踪每个素数的最后一次出现，我们确保右子数组中的所有剩余元素与左子数组没有共享素数`i == max_last_index`。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def findValidSplit(self, nums: List[int]) -> int:
        def prime_factors(x):
            factors = set()
            d = 2
            while d * d <= x:
                while x % d == 0:
                    factors.add(d)
                    x //= d
                d += 1
            if x > 1:
                factors.add(x)
            return factors
        
        last_occurrence = {}
        n = len(nums)
        
        # Compute last occurrence of each prime factor
        for i, num in enumerate(nums):
            for p in prime_factors(num):
                last_occurrence[p] = i
        
        max_last_index = 0
        for i, num in enumerate(nums):
            for p in prime_factors(num):
                max_last_index = max(max_last_index, last_occurrence[p])
            if i == max_last_index:
                return i
        return -1
```Python 代码计算每个数字的质因数，映射每个质因数的最后一个索引，并迭代以确定最早的有效分割。 这避免了计算大型乘积并确保大量数字的正确性。 

## 解决方案```go
func findValidSplit(nums []int) int {
    n := len(nums)
    lastOccurrence := make(map[int]int)
    
    // Helper function to get prime factors
    primeFactors := func(x int) map[int]struct{} {
        factors := make(map[int]struct{})
        for d := 2; d*d <= x; d++ {
            for x%d == 0 {
                factors[d] = struct{}{}
                x /= d
            }
        }
        if x > 1 {
            factors[x] = struct{}{}
        }
        return factors
    }
    
    // Compute last occurrence of each prime factor
    for i, num := range nums {
        for p := range primeFactors(num) {
            lastOccurrence[p] = i
        }
    }
    
    maxLastIndex := 0
    for i, num := range nums {
        for p := range primeFactors(num) {
            if lastOccurrence[p] > maxLastIndex {
                maxLastIndex = lastOccurrence[p]
            }
        }
        if i == maxLastIndex {
            return i
        }
    }
    return -1
}
```在 Go 中，我们使用映射和结构体来表示素因数。 该方法类似于 Python，确保不会出现整数溢出并正确处理切片。
