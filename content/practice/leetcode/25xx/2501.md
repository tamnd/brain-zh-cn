 **难度：** 🟡 中等
 **主题：** 数组、哈希表、二分查找、动态规划、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们识别整数数组中的**最长的方形条纹**`nums`。 **方形条纹**是长度至少为 2 的子序列，其中排序后，每个元素都是前一个元素的平方。 换句话说，如果排序后的子序列是`[x1, x2, ..., xk]`， 然后`x2 = x1^2`,`x3 = x2^2`， 等等。 

输入`nums`是一个未排序的整数数组，其中每个元素的范围为 2 到 10^5，数组的长度最大可达 10^5。 输出应该是一个整数，即最长方形条纹的长度或`-1`如果不存在有效的条纹。 

需要考虑的重要边缘情况包括：

 1. 不存在方形条纹的数组，例如，`[2,3,5]`。 
2. 多个条纹重叠的数组，例如，`[2,4,16,256]`。 
3. 具有重复数字的数组，例如，`[2,2,4,16]`。 
4. 最小输入尺寸（`nums.length = 2`）和最大输入大小（`nums.length = 10^5`）。 

这些限制表明，由于组合爆炸，对所有子序列进行强力探索是不可行的，因此需要一种有效的方法。 

## 方法

 ### 蛮力方法

 暴力解决方案将涉及生成 **所有子序列**`nums`，对每个元素进行排序，然后检查每个元素是否是前一个元素的平方。 虽然这是正确的，但子序列的数量随着数组的长度呈指数增长，这使得它完全不可行`nums.length`最多 10^5。 

### 最佳方法

 更有效的解决方案的关键见解是可以**使用哈希集和贪婪链接**来解决该问题。 由于子序列只需要**排序**，所以我们在构造时可以忽略原来的顺序。 我们可以将所有数字存储在一个集合中以进行 O(1) 查找，然后对每个数字重复平方以查看链可以增长多长。 我们跟踪所有链的最大长度。 

按升序处理数字可以获得额外的效率。 如果一个数字`x`已经是从较小数字开始的较长链的一部分，我们可以跳过从以下开始的链`x`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n log n) | O(2^n * n log n) | O(n) | 生成所有子序列、排序和检查 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 使用集合进行快速查找，通过数字平方进行链式增长 |

 ## 算法演练

 1. 将所有数字插入`nums`转换为 O(1) 查找的哈希集。 
2. 排序`nums`按升序从最小的数字开始链。 
3. 初始化变量`max_len`跟踪找到的最长的方形条纹。 
4. 迭代每个数字`num`在已排序的数组中。 
5.如果`num`不在集合中（已作为另一个链的一部分访问过），请跳过它。 
6. 否则，初始化`length = 1`和一个变量`current = num`。 
7. 虽然`current^2`存在于集合中：

 1. 增量`length`1.
 2. 马克`current`通过从集合中删除它来访问它。 
3. 更新`current = current^2`。 
8. 更新`max_len`其当前值的最大值和`length`。 
9. 处理完所有数字后，如果`max_len >= 2`， 返回`max_len`，否则返回`-1`。 

**为什么有效：** 通过从每个潜在条纹中的最小数字开始并通过平方进行增长，我们确保找到最长的可能子序列。 使用集合可以防止重新访问数字，从而避免冗余计算。 

## Python 解决方案```python
from typing import List

class Solution:
    def longestSquareStreak(self, nums: List[int]) -> int:
        num_set = set(nums)
        nums.sort()
        max_len = -1

        for num in nums:
            if num not in num_set:
                continue

            length = 1
            current = num
            while current * current in num_set:
                current = current * current
                length += 1
                num_set.remove(current // current)  # previous current already used

            if length >= 2:
                max_len = max(max_len, length)

        return max_len
```**实现演练：** 代码首先将列表转换为用于 O(1) 查找的集合并对其进行排序。 对于每个数字，它通过重复平方来增长链，并从集合中删除元素以防止重复使用。`max_len`更新长度至少为 2 的条纹。 

## 解决方案```go
func longestSquareStreak(nums []int) int {
    numSet := make(map[int]bool)
    for _, num := range nums {
        numSet[num] = true
    }

    maxLen := -1

    // Sort nums
    sort.Ints(nums)

    for _, num := range nums {
        if !numSet[num] {
            continue
        }

        length := 1
        current := num
        for {
            square := current * current
            if _, exists := numSet[square]; !exists {
                break
            }
            current = square
            length++
            delete(numSet, current)
        }

        if length >= 2 && length > maxLen {
            maxLen = length
        }
    }

    return maxLen
}
```**Go 注意：** Go 版本使用集合的地图。 排序是通过`sort.Ints`。 从地图中删除会将元素标记为已访问，类似于从 Python 集中删除。

 ## 边缘情况

 1. **单链与多链：** 当存在多个方形条纹时，算法必须识别最长的。 排序确保首先考虑较小的数字，从而保证找到最长的链。
