[LeetCode 问题 2568](https://leetcode.com/problems/minimum-impossible-or/)

 **难度：** 🟡 中等
 **主题：** 数组、位操作、脑筋急转弯

 ## 解决方案

 ## 问题理解

 该问题要求我们找到**不能**表示为给定数组的任何子序列的按位或的最小正整数`nums`。 输入数组包含正整数，子序列可以具有任意长度，包括长度 1。输出必须是无法对这些子序列使用 OR 运算形成的大于零的最小整数。 

按位或是包容性的，因为它累积了序列中数字中设置的所有位。 例如，如果一个数字设置了第 1 位和第 3 位，而另一个数字设置了第 2 位，则 OR 将组合它们，设置所有三个位。 挑战在于有效地识别无法从此类组合中获得的第一个正整数，特别是因为`nums`最多可以有`10^5`元素，每个元素可以大到`10^9`。 

主要观察结果包括，这从根本上来说是一个关于**二的幂**的问题，因为每个整数都可以用二进制表示，并且“或”子集往往会生成二的幂之和。 需要注意的边缘情况包括丢失的数组`1`完全（在这种情况下`1`立即就是答案）和数组，其中元素形成带有间隙的连续的二的幂。 

## 方法

 ### 蛮力

 暴力方法将枚举所有子序列`nums`，计算它们的 OR 值，并跟踪哪些整数是可表达的。 一旦收集了所有 OR 值，我们将从 1 向上递增检查第一个缺失的整数。 虽然原则上是正确的，但该方法在计算上是不可行的，因为长度数组的子序列数`n`是`2^n`，这是指数级的。 这对于`n`最多`10^5`。 

### 最佳方法

 关键的见解是要认识到**最小不可能的 OR 总是对应于数组中缺少的 2 的幂**。 我们可以维护一组数字并迭代 2 的幂，从 1 开始，每次加倍。 如果数组中不存在 2 的幂，则该幂是最小不可能的 OR。 这是可行的，因为对较小的数字进行“或”运算只能生成最大为 2 的较小幂之和的数字。 通过对任何较小数字的组合进行“或”运算无法得出第一个缺失的 2 的幂，从而使其成为正确答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 枚举所有子序列及其 OR，这对于大 n 是不可行的 |
 | 最佳| O(n) | O(log(最大(nums))) | 跟踪 2 的幂，检查最小缺失，对于 n 最大为 10^5 可行 |

 ## 算法演练

 1. 初始化变量`power`到 1。这代表我们正在检查的当前 2 的幂。 
2. 创建一个集合`num_set`从数组`nums`允许 O(1) 查找数字。 
3.进入一个循环，检查是否`power`存在于`num_set`。 
4.如果`power`存在，乘以`power`2 并重复。 这会检查下一个 2 的幂。 
5. 如果`power`集合中**不**存在，返回`power`立即作为最小不可能的 OR。 

**为什么有效：** 因为每个 2 的幂都是二进制表示的基本构建块，所以任何可表示为现有数字的 OR 的数字都必须是数组中已有的 2 的幂的某种组合。 2 的第一个缺失的幂不能通过对较小的幂进行“或”运算来形成，因此保证它是最小的不可表达整数。 

## Python 解决方案```python
from typing import List

class Solution:
    def minImpossibleOR(self, nums: List[int]) -> int:
        num_set = set(nums)
        power = 1
        while power in num_set:
            power <<= 1
        return power
```此解决方案将列表转换为用于 O(1) 成员资格检查的集合。 然后，它使用位移位迭代 2 的幂，直到找到不在集合中的一个，并立即返回该值。 

## 解决方案```go
func minImpossibleOR(nums []int) int {
    numSet := make(map[int]struct{})
    for _, num := range nums {
        numSet[num] = struct{}{}
    }
    power := 1
    for {
        if _, exists := numSet[power]; !exists {
            return power
        }
        power <<= 1
    }
}
```在 Go 中，我们使用具有空结构值的映射来表示集合。 成员资格检查类似，我们使用左移迭代 2 的幂，直到找到丢失的幂。

 ## 边缘情况

 第一个边缘情况是当`nums`不包含`1`。 由于 1 是最小的正整数，因此答案立即为 1。这是一种常见的边缘情况，如果算法首先盲目检查较大的数字，则可能会错过这种情况。 

第二个边缘情况是当`nums`包含二的连续幂。 在这种情况下，算法必须正确识别最大当前值之外的下一个缺失幂，而不是假设之间的所有整数都是可表示的。 

第三种边缘情况是仅包含大于 1 的奇数的数组。这些数字都不能产生 OR 值 1，因此算法必须正确识别缺少 1，这验证了两个逻辑的幂的使用。 

这种方法系统地处理这些边缘情况，因为它从 2 的最小幂开始增量检查并返回第一个缺失的值。
