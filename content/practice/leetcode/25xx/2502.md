[LeetCode 问题 2502](https://leetcode.com/problems/design-memory-allocator/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、设计、模拟

 ## 解决方案

 ## 问题理解

 该问题需要设计一个管理固定大小内存阵列的内存分配器。 最初，所有内存单元都是空闲的，分配器支持两种操作：为给定 ID 分配一块连续的空闲内存单元（`mID`）并释放与给定关联的所有内存单元`mID`。 分配应始终选择所请求大小的最左边的可用块。 多个块可以分配给同一个块`mID`，并且释放内存 ID 应该释放与其关联的所有块`mID`。 

输入由整数参数组成：`n`对于内存大小，`size`对于分配请求，以及`mID`用于识别分配。 输出是分配块的起始索引（或`-1`如果分配失败）或释放的内存单元数。 

约束条件（`n, size, mID <= 1000`和多达 1000 次操作）表明直接的模拟方法是可行的，因为存储器阵列和操作数量相对较小。 边缘情况包括尝试分配比可用内存更多的内存、释放内存`mID`不存在，并且多次分配给同一个`mID`。 

## 方法

 ### 蛮力

 一个简单的强力解决方案是维护一个表示内存的数组。 对于分配，从左到右迭代并检查长度连续零的块`size`。 如果找到则填写`mID`并返回起始索引。 为了释放，迭代整个数组，计算出现的次数`mID`，并将这些位置重置为零。 

这种方法可以正常工作，因为它完全按照描述模拟内存。 然而，分配和释放都需要扫描整个数组，使得每次操作的时间复杂度为 O(n)。 虽然在给定限制的情况下可行，但如果内存大小或操作计数较大，则不是最佳选择。 

### 优化洞察

 更优化的方法是维护一个映射（哈希表）`mID`表示分配块的范围列表（起始索引和长度）。 释放变得更加高效，因为您可以直接访问与特定关联的所有块`mID`无需扫描整个内存阵列。 然而，分配仍然需要扫描数组中的空闲段。 考虑到约束条件（`n <= 1000`），简单的数组模拟就足够了，使用映射仅稍微提高了自由操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每次操作 O(n) | O(n) | 直接模拟内存阵列，扫描内存进行分配和释放操作 |
 | 优化| 每次分配 O(n)，每次释放 O(k) | O(n + k) | 跟踪每个 mID 分配的块以加快释放速度； 仍然扫描内存以进行分配|

 ## 算法演练

 1.初始化一个size的内存数组`n`所有元素设置为零以指示空闲内存单元。 
2. 对于分配，迭代数组以找到所需的最左边的连续零块`size`。 跟踪每个潜在空闲段的起始索引。 一旦找到一个块，通过填充它来更新内存数组`mID`并返回起始索引。 如果不存在这样的块，则返回`-1`。 
3. 为了释放，迭代内存数组。 如果一个元素等于给定的`mID`，增加计数器并将该位置重置为零。 完成扫描后，返回计数器作为释放的单位数。 
4. 在整个操作过程中维护内存阵列，以确保将来分配和释放的正确性。 

**工作原理：** 内存数组始终反映当前的分配状态，从左到右扫描可保证分配最左边的空闲块。 通过迭代数组来释放可确保与给定关联的所有块`mID`被释放。 

## Python 解决方案```python
class Allocator:

    def __init__(self, n: int):
        self.memory = [0] * n

    def allocate(self, size: int, mID: int) -> int:
        n = len(self.memory)
        start = 0
        while start <= n - size:
            # Check if there is a free block of required size
            if all(self.memory[i] == 0 for i in range(start, start + size)):
                for i in range(start, start + size):
                    self.memory[i] = mID
                return start
            start += 1
        return -1

    def freeMemory(self, mID: int) -> int:
        freed = 0
        for i in range(len(self.memory)):
            if self.memory[i] == mID:
                self.memory[i] = 0
                freed += 1
        return freed
```该实现用零初始化存储器阵列。 分配扫描所需大小的最左边的空闲块，并将其填充为`mID`，并返回起始索引。 释放会迭代数组，并使用指定的值重置单位`mID`，并计算释放的单位。 

## 解决方案```go
type Allocator struct {
	memory []int
}

func Constructor(n int) Allocator {
	return Allocator{
		memory: make([]int, n),
	}
}

func (this *Allocator) Allocate(size int, mID int) int {
	n := len(this.memory)
	for start := 0; start <= n-size; start++ {
		free := true
		for i := start; i < start+size; i++ {
			if this.memory[i] != 0 {
				free = false
				start = i // optimization: skip to next after occupied
				break
			}
		}
		if free {
			for i := start; i < start+size; i++ {
				this.memory[i] = mID
			}
			return start
		}
	}
	return -1
}

func (this *Allocator) FreeMemory(mID int) int {
	freed := 0
	for i := 0; i < len(this.memory); i++ {
		if this.memory[i] == mID {
			this.memory[i] = 0
			freed++
		}
	}
	return freed
}
```在 Go 中，内存数组被实现为整数切片。 分配函数检查连续的空闲块并更新切片，而空闲函数则迭代并重置内存单元。
