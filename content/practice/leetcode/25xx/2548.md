[LeetCode 问题 2548](https://leetcode.com/problems/maximum-price-to-fill-a-bag/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们最大化放置在具有固定容量的袋子中的物品的总价格。 每个物品都由价格和重量定义，但与传统的背包问题不同，物品可以**按比例划分**，这意味着我们可以取物品的分数。 具体来说，如果我们取一小部分`f`的一个项目，我们获得`f * price`为了`f * weight`。 目标是以最大化总价格的方式将袋子装满。 

输入由一个项目列表组成，每个项目都有一个正整数价格和重量，以及一个正整数容量。 输出是一个浮点数，表示可实现的最高价格，或者`-1`如果无法装满袋子（例如，如果所有物品单独重于容量，并且我们无法将它们组合起来以完全匹配容量）。 

限制很大：最多`10^5`物品，每件的价格和重量高达`10^4`，容量高达`10^9`。 这意味着尝试所有组合的任何简单方法都是不可行的。 

重要的边缘情况包括单独重量超过容量的物品、总重量小于容量的物品，或者需要分数选择才能精确达到容量的情况。 

## 方法

 蛮力方法会尝试每种物品的组合及其可能的分数，以准确地填充袋子。 这将涉及枚举子集并解决每个子集的连续分数问题，这**慢**并且在给定约束的情况下不可行。 

关键的观察结果是该问题是一个**分数背包问题**。 在分数背包中，为了最大化可分割物品的总价值，我们应该**按照价格与重量比递减的顺序获取物品**。 我们会尽可能多地获取比率最高的物品，直到容量被填满。 这种贪婪方法之所以有效，是因为任何偏离首先选择最高比率的行为都会产生较低的总价格。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试所有子集和分数除法，对于 n 达到 10^5 不可行 |
 | 最优（贪婪）| O(n log n) | O(n log n) | O(1) 或 O(n) | 按重量比对物品进行排序并贪婪地挑选 |

 ## 算法演练

 1. 计算每件商品的重量单价。 这代表每单位重量获得的价值。 
2. 按单价降序对物品进行排序。 这确保了首先考虑重量回报率最高的物品。 
3. 初始化`total_price = 0`和`remaining_capacity = capacity`。 
4. 迭代已排序的项目。 对于每个项目：

 a. 如果物品的重量小于或等于剩余容量，则取出整个物品，减去其重量`remaining_capacity`，并将其价格添加到`total_price`。 

b. 如果物品的重量超过剩余容量，则仅取适合的部分。 将分数计算为`remaining_capacity / item_weight`， 添加`fraction * item_price`到`total_price`，并设置`remaining_capacity = 0`。 
5. 循环结束后，如果`remaining_capacity`仍为正值，返回`-1`因为袋子无法装满。 否则，返回`total_price`。 

**为什么有效：** 贪心选择属性保证首先选择最高的每重量价格总是使总价格最大化。 由于物品可以拆分，因此在物品总重量足够的情况下，取分数可确保我们始终能够准确地达到袋子的容量。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxPrice(self, items: List[List[int]], capacity: int) -> float:
        # Compute price per weight for each item
        items = [(price / weight, price, weight) for price, weight in items]
        # Sort by price per weight descending
        items.sort(reverse=True, key=lambda x: x[0])
        
        total_price = 0.0
        remaining_capacity = capacity
        
        for ratio, price, weight in items:
            if remaining_capacity == 0:
                break
            if weight <= remaining_capacity:
                total_price += price
                remaining_capacity -= weight
            else:
                fraction = remaining_capacity / weight
                total_price += price * fraction
                remaining_capacity = 0
        
        return total_price if remaining_capacity == 0 else -1.0
```Python 代码首先计算每个商品的价值密度（每重量的价格）并对它们进行排序。 然后，它迭代这些项目，如果适合则完全获取一个项目，或者如果需要则部分获取一小部分。 最后检查确保袋子已装满； 如果没有，则返回`-1`。 

## 解决方案```go
import "sort"

func maxPrice(items [][]int, capacity int) float64 {
    type Item struct {
        ratio float64
        price int
        weight int
    }
    
    n := len(items)
    arr := make([]Item, n)
    
    for i, it := range items {
        arr[i] = Item{
            ratio: float64(it[0]) / float64(it[1]),
            price: it[0],
            weight: it[1],
        }
    }
    
    sort.Slice(arr, func(i, j int) bool {
        return arr[i].ratio > arr[j].ratio
    })
    
    totalPrice := 0.0
    remainingCapacity := capacity
    
    for _, item := range arr {
        if remainingCapacity == 0 {
            break
        }
        if item.weight <= remainingCapacity {
            totalPrice += float64(item.price)
            remainingCapacity -= item.weight
        } else {
            fraction := float64(remainingCapacity) / float64(item.weight)
            totalPrice += fraction * float64(item.price)
            remainingCapacity = 0
        }
    }
    
    if remainingCapacity > 0 {
        return -1.0
    }
    return totalPrice
}
```Go 实现镜像了 Python，但为了清晰起见使用了结构体。 排序和分数计算是用`float64`以保持精度。 Go 需要对除法进行显式转换以避免整数截断。 

## 工作示例

 **示例1：**`items = [[50,1],[10,8]], capacity = 5`计算比率：`[50/1=50, 10/8=1.25]`种类：`[[50,1], [10,8]]`- 完全拿走第一项：剩余容量 = 5-1=4，total_price = 50
 - 取第二项分数：分数 = 4/8 = 0.5，total_price += 10*0.5 = 5 →total_price = 55
 - 行李已满 → 返回 55.0

 **示例2：**`items = [[100,30]], capacity = 50`- 单件重量30<50→取满，剩余容量=50-30=20
 - 没有更多物品 → 袋子未满 → 返回 -1.0

 ## 边缘情况

 **单件物品完全适合：** 如果袋子容量等于一件物品的重量，算法会正确地完全接收该物品并返回其价格。 幼稚的实现可能会错误地尝试拆分它。 

**物品重量大于容量：**当所有物品都比袋子重时，算法将只取一小部分。 如果没有组合可以完全填满袋子，它会正确返回`-1`。 

**大量物品：** 有`n`高达 10^5，效率很重要。 排序确保我们按照值密度的顺序处理项目，而无需枚举子集。 分数法无需穷举搜索即可保证正确性。
