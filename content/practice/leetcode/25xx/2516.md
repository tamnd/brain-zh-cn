[LeetCode 问题 2516](https://leetcode.com/problems/take-k-of-each-character-from-left-and-right/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们确定 **从字符串两端获取的最小字符数**`s`仅由字母组成`'a'`,`'b'`， 和`'c'`这样我们至少收集**`k`每个字符**。 您可以在每个步骤中从字符串的**最左边**或**最右边**位置获取字符。 输出是所取的字符总数，或者`-1`如果不可能实现`k`每个角色。 

输入为：

 -`s`，长度可达的字符串`10^5`仅由`'a'`,`'b'`,`'c'`。 
-`k`，一个非负整数，表示每个字符所需的最小计数。 

输出是一个整数，表示**最小步数**，或者`-1`如果不能满足要求。 

问题约束告诉我们，字符串长度足够大，**暴力枚举所有左右组合是不可行的**，因此我们需要一种更有效的方法。 可能导致幼稚实现失败的边缘情况包括：

 -`k`是`0`，这应该简单地返回`0`因为不需要任何字符。 
- 中任意字符的总数`s`小于`k`，这使得无法满足要求。 
-`k`正好等于字符串中某些字符的个数，要求我们取几乎所有字符。 

## 方法

 ### 蛮力方法

 一个天真的方法是尝试**所有组合**`i`从左边开始的字符和`j`从右边开始的所有有效字符`i`和`j`这样`i + j <= len(s)`。 对于每个组合，数出有多少个`'a'`,`'b'`， 和`'c'`被收集。 如果所有计数都达到`k`，更新所取的最小字符数。 

这种方法是正确的，因为它**检查所有可能的方式**来获取字符，但它太慢了。 有`O(n^2)`可能的`(i, j)`长度为对的字符串`n`，这将是`~10^10`最坏情况下的操作。 显然，这是不可行的。 

### 最佳方法

 关键观察：由于我们只能从**任一端**获取字符，因此可以将问题重新定义为**滑动窗口问题**。 我们可以计算**中间留下的**，而不是计算我们拿走的东西。 

1. 设每个字符的总数为`total_counts`。 
2.我们至少需要`k`每个角色，所以我们可以把**留给`total_counts[c] - k`里面的每个字符**。 
3. 然后我们尝试找到**最长的连续子串**，其中没有字符超过`total_counts[c] - k`。 这个子字符串代表我们**不采用**的字符。 
4. 我们采用的最少字符数是`len(s) - length_of_this_substring`。 

这是有效的，因为我们可以使用**滑动窗口**来跟踪字符计数并找到**最长的有效窗口**`O(n)`时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 检查所有左右组合 |
 | 最优（滑动窗口）| O(n) | O(1) | O(1) | 找到可以保留的最长中间子串 |

 ## 算法演练

 1. **计算总出现次数**`'a'`,`'b'`,`'c'`在`s`。 
2. **检查可行性**：如果任何字符数小于`k`， 返回`-1`。 
3. 初始化`max_window_len = 0`，和两个指针`left = 0`。 
4. 迭代`right`从`0`到`len(s)-1`：

- 包括`s[right]`在当前窗口计数中。 
- 当当前窗口数超过`total_counts[c] - k`对于任何字符，**从左侧缩小窗口**直到它变得有效。 
- 更新`max_window_len`如果当前窗口有效且比前一个窗口长。 
5. 最少取字符数为`len(s) - max_window_len`。 
6. 返回该值。 

**为什么它有效**：不变的是，在每一步中，窗口代表我们可以留下的连续子字符串`s`在不违反至少采取的要求的情况下`k`每个角色。 通过最大化该子字符串的长度，我们可以最小化需要从末尾获取的字符数。 

## Python 解决方案```python
from collections import Counter

class Solution:
    def takeCharacters(self, s: str, k: int) -> int:
        total_counts = Counter(s)
        # Check if it is possible
        if total_counts['a'] < k or total_counts['b'] < k or total_counts['c'] < k:
            return -1
        
        n = len(s)
        max_window_len = 0
        window_counts = Counter()
        left = 0
        
        for right in range(n):
            window_counts[s[right]] += 1
            # Shrink window until valid
            while (window_counts['a'] > total_counts['a'] - k or
                   window_counts['b'] > total_counts['b'] - k or
                   window_counts['c'] > total_counts['c'] - k):
                window_counts[s[left]] -= 1
                left += 1
            max_window_len = max(max_window_len, right - left + 1)
        
        return n - max_window_len
```**解释**：我们首先统计每个字符的总数。 如果任何总数小于`k`，我们立即返回`-1`。 然后我们使用滑动窗口来找到可以保留的**最长的有效子串**，调整`left`当字符超过其允许的剩余计数时指针。 最后，`len(s) - max_window_len`给出所需的最少字符数。 

## 解决方案```go
func takeCharacters(s string, k int) int {
    count := map[byte]int{'a':0, 'b':0, 'c':0}
    for i := 0; i < len(s); i++ {
        count[s[i]]++
    }
    if count['a'] < k || count['b'] < k || count['c'] < k {
        return -1
    }
    
    n := len(s)
    maxWindow := 0
    window := map[byte]int{'a':0, 'b':0, 'c':0}
    left := 0
    
    for right := 0; right < n; right++ {
        window[s[right]]++
        for window['a'] > count['a'] - k || window['b'] > count['b'] - k || window['c'] > count['c'] - k {
            window[s[left]]--
            left++
        }
        if right - left + 1 > maxWindow {
            maxWindow = right - left + 1
        }
    }
    
    return n - maxWindow
}
```**解释**：与Python类似的逻辑。 我们使用地图来追踪计数。 Go 映射是零安全的，但我们初始化所有键以确保没有运行时错误。 当字符超过允许的剩余计数时，滑动窗口会缩小。 

## 工作示例

 **示例1：`s = "aabaaaacaabc", k = 2`**

 - 总计数：`a:7, b:2, c:3`- 允许剩余：`a:5, b:0, c:1`- 滑动窗口流程：

 | 左| 对| 窗口计数 | 有效的？ | 最大窗口长度 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 一个：1 | 是的 | 1 |
 | 0 | 1 | 一个：2 | 是的 | 2 |
 | 0 | 2 | a:2,b:1 | 没有| 2 |
 | ... | ... | ... | ... | ... |
 | 决赛| 7 | 窗口“aaaaca” | 是的 | 5 |

 - 最少字符数：`12 - 4 = 8`**示例2：`s = "a", k = 1`**

 - 总计数：`a:1, b:0, c:0`→ 不可能，返回`-1`。
