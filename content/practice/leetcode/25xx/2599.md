[LeetCode 问题 2599](https://leetcode.com/problems/make-the-prefix-sum-non-negative/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们操作一个整数数组，`nums`，因此它的前缀和永远不会为负。 索引处的前缀和`i`只是从数组开始到所有元素的总和`i`。 唯一允许的操作是获取其中的任何元素`nums`并将其移动到数组的末尾。 我们需要确定实现非负前缀和数组的此类操作的最小数量。 

换句话说，我们希望数组的运行总和永远不会低于零，我们可以通过将负数重新排序到末尾来实现这一点。 该问题保证了解决方案始终存在，这意味着始终可以重新排列数组以满足要求。 

约束很重要：数组长度最多可达 100,000，单个元素的范围为 -1,000,000,000 到 1,000,000,000。 这告诉我们，任何考虑每个排列的强力解决方案都是不可行的，我们需要一种贪婪或基于优先级的方法。 关键边缘情况包括已经是非负数的数组、以大负数开头的数组以及包含所有负数的数组。 

## 方法

 强力方法是重复检查前缀和，每当前缀变为负数时，尝试移动元素来修复它。 这种方法原则上是正确的，但速度极慢，因为它可能涉及多次移动元素并重新计算前缀和，导致阶乘时间复杂度。 

最佳解决方案的关键是从左到右处理数组，保持运行的前缀和。 每当前缀和变为负数时，我们就知道需要“消除”一些导致其降至零以下的大的负贡献。 使用迄今为止遇到的负数的最大堆（优先级队列），我们可以贪婪地删除最大的负数（按绝对值）到最后，每次增加操作计数。 这确保前缀和以有效的方式保持非负。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 反复检查和移动元素，每次都重新计算前缀和。 对于 n 达到 10^5 来说太慢了。 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 使用最大堆来存储负数，当前缀和低于零时贪婪地“删除”最大的负数。 |

 ## 算法演练

 1. 初始化变量`prefix_sum`为 0 以跟踪运行的前缀和。 初始化`operations`到 0 来计算移动次数。 初始化一个空的最大堆`negatives_heap`存储我们遇到的负数。 
2. 迭代中的每个元素`nums`。 
3. 将当前元素添加到`prefix_sum`。 
4.如果当前元素为负数，则将其压入`negatives_heap`。 在Python中，要使用最大堆，请存储负值，以便最大的负值在最小堆实现中成为最小的。 
5. 如果`prefix_sum`变为负数，重复从堆中弹出最大的负数，将其绝对值加回到`prefix_sum`（就好像将其从前缀中删除并将其移动到末尾），并递增`operations`。 重复直到`prefix_sum`是非负的。 
6. 继续，直到处理完所有元素。 
7. 返回`operations`。 

**为什么它有效：** 保持的不变量是`prefix_sum`每当它降至零以下时，删除最大负元素后就为非负数。 贪婪地删除最大的负数可以确保我们最大限度地减少移动次数，因为删除较小的负数不会有效地恢复前缀和。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def makePrefSumNonNegative(self, nums: List[int]) -> int:
        prefix_sum = 0
        operations = 0
        max_heap = []  # store negatives as negative numbers for max-heap behavior
        
        for num in nums:
            prefix_sum += num
            if num < 0:
                heapq.heappush(max_heap, num)
            while prefix_sum < 0:
                largest_negative = heapq.heappop(max_heap)
                prefix_sum -= largest_negative  # subtracting a negative increases the sum
                operations += 1
        
        return operations
```此实现维护一个运行的前缀和和一堆负数。 每当总和低于零时，它就会删除最大的负数以恢复非负数，并将每次删除视为一次操作。 

## 解决方案```go
package main

import (
    "container/heap"
)

type IntHeap []int

func (h IntHeap) Len() int            { return len(h) }
func (h IntHeap) Less(i, j int) bool  { return h[i] > h[j] } // max-heap
func (h IntHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

func makePrefSumNonNegative(nums []int) int {
    prefixSum := 0
    operations := 0
    maxHeap := &IntHeap{}
    heap.Init(maxHeap)
    
    for _, num := range nums {
        prefixSum += num
        if num < 0 {
            heap.Push(maxHeap, num)
        }
        for prefixSum < 0 {
            largestNegative := heap.Pop(maxHeap).(int)
            prefixSum -= largestNegative
            operations++
        }
    }
    
    return operations
}
```在 Go 中，我们通过定义自定义堆类型来实现最大堆`Less`倒。 其余逻辑反映了 Python 解决方案。
