[LeetCode 问题 2370](https://leetcode.com/problems/longest-ideal-subsequence/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、动态编程

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给定一个字符串`s`仅包含小写英文字母和整数`k`。 我们需要找到最长子序列的长度，使得该子序列中每对相邻字符之间的差异最多为`k`。 

子序列不要求字符是连续的。 我们可以在保留原始顺序的同时跳过字符。 例如，`"acbd"`是一个子序列`"acfgbd"`因为我们可以删除`'f'`和`'g'`同时保持其余字符的顺序。 

重要的条件是所选子序列内的邻接规则。 如果子序列中有两个连续的字符`x`和`y`， 然后：```
abs(ord(x) - ord(y)) <= k
```这意味着字符必须按字母顺序排列。 字母表不是循环的，所以`'a'`和`'z'`不同之处在于`25`， 不是`1`。 

输入约束很大：

 -`1 <= s.length <= 10^5`-`0 <= k <= 25`字符串长度为`100000`立即告诉我们指数或二次子序列生成方法是不可能的。 我们需要接近线性时间的东西。 

有几个重要的边缘情况需要考虑：

 - 当`k = 0`，子序列中的相邻字符必须相同。 答案成为任何字符的最大频率。 
- 什么时候`k = 25`，每个小写字符都可以跟在其他每个小写字符后面，因此整个字符串始终有效。 
- 具有重复字符的字符串需要仔细处理，因为以字符结尾的最佳子序列可能会提高多次。 
- 非常短的字符串，例如长度`1`应该总是返回`1`。 

## 方法

 ### 蛮力方法

 强力解决方案将生成字符串的每个可能的子序列，并检查每个子序列是否满足理想条件。 

对于一个长度的字符串`n`， 有`2^n`可能的子序列。 对于每个子序列，我们将扫描相邻字符并验证它们的字母差异最多为`k`。 

这种方法是正确的，因为它明确地检查每个可能的候选者并保留最长的有效候选者。 However, it is computationally impossible for`n = 100000`。 

即使是为了`n = 30`，已经有超过十亿个子序列。 

### 最佳解决方案的关键见解

 重要的观察是我们不需要记住整个子序列。 我们只需要知道：

 > 每个角色的最佳理想子序列结局是什么？ 

由于只有26个小写字母，我们可以为每个字母维护动态编程信息。 

假设我们当前正在处理字符`'d'`。 

如果`k = 2`， 然后`'d'`can follow:

 -`'b'`-`'c'`-`'d'`-`'e'`-`'f'`因为他们的字母距离`'d'`至多是`2`。 

因此，要构建以`'d'`，我们只需要以那些兼容字符结尾的最佳子序列。 

这将问题转化为只有 26 个状态的紧凑动态规划问题。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n × n) | O(2^n × n) | O(n) | 生成每个子序列并验证每个子序列 |

 ## 算法演练

 1. 创建一个大小为26的DP数组。 

每个索引代表一个小写字母：

 -`dp[0]`代表`'a'`-`dp[1]`代表`'b'`- ...
 -`dp[25]`代表`'z'`

`dp[i]`存储以该字符结尾的最长理想子序列的长度。 
2. 一次处理一个字符的字符串。 

对于每个角色`char`:

 - 将其转换为索引：```
current = ord(char) - ord('a')
```3. 确定哪些以前的字符是兼容的。 

索引不同于的任何字符`current`至多`k`在理想的子序列中可以紧邻当前字符出现。 

所以有效范围是：```
max(0, current - k) to min(25, current + k)
```4. 寻找兼容字符中的最佳子序列。 

扫描有效范围并计算：```
best_previous = max(dp[i])
```这给出了可以合法过渡到当前字符的最长理想子序列。 
5. 扩展该子序列。 

以当前字符结尾的新子序列长度变为：```
best_previous + 1
```6. 更新当前字符的 DP 条目。 

我们取最大值，因为相同的字符可能在字符串中出现多次。 
7. 处理完整个字符串后，返回DP数组中的最大值。 

### 为什么它有效

 DP 数组始终维护以每个字母结尾的最长有效理想子序列。 当处理一个新字符时，我们会考虑所有兼容的先前结尾字母并扩展最好的一个。 由于每个有效的理想子序列都必须以某个字符结尾，并且每个扩展都遵循邻接约束，因此该算法可以正确地逐步构建最佳答案。 

## Python 解决方案```python
class Solution:
    def longestIdealString(self, s: str, k: int) -> int:
        dp = [0] * 26

        for char in s:
            current_index = ord(char) - ord('a')

            left = max(0, current_index - k)
            right = min(25, current_index + k)

            best_previous = 0

            for index in range(left, right + 1):
                best_previous = max(best_previous, dp[index])

            dp[current_index] = max(
                dp[current_index],
                best_previous + 1
            )

        return max(dp)
```该实现首先创建一个包含 26 个元素的固定大小的 DP 数组。 每个位置存储以该字母结尾的最佳理想子序列。 

当我们迭代字符串时，我们将每个字符转换为其字母表索引。 这允许角色和 DP 位置之间的恒定时间映射。 

对于每个字符，我们使用以下方法计算兼容的字母表范围`k`。 然后我们只扫描那些有效的字符来找到我们可以扩展的最佳子序列。 

表达式：```python
best_previous + 1
```表示将当前字符附加到最佳兼容子序列上。 

我们使用：```python
max(dp[current_index], best_previous + 1)
```因为同一字符在早期处理中可能已经具有更长的子序列。 

最后，答案是DP数组中存储的最大值。 

## 解决方案```go
func longestIdealString(s string, k int) int {
	dp := make([]int, 26)

	for _, ch := range s {
		currentIndex := int(ch - 'a')

		left := currentIndex - k
		if left < 0 {
			left = 0
		}

		right := currentIndex + k
		if right > 25 {
			right = 25
		}

		bestPrevious := 0

		for i := left; i <= right; i++ {
			if dp[i] > bestPrevious {
				bestPrevious = dp[i]
			}
		}

		if bestPrevious+1 > dp[currentIndex] {
			dp[currentIndex] = bestPrevious + 1
		}
	}

	answer := 0

	for _, value := range dp {
		if value > answer {
			answer = value
		}
	}

	return answer
}
```Go 实现遵循与 Python 版本完全相同的动态编程逻辑。 

长度为 26 的切片存储 DP 值。 由于 Go 没有提供内置的`max`对于整数，比较是手动处理的`if`声明。 

字符串的迭代使用 Go runes，但由于输入仅包含小写英文字母，因此 rune 处理简单且安全。 

不需要特殊的溢出处理，因为最大答案最多是`100000`，它很容易适合 Go 的内部`int`类型。

 ## 边缘情况

 ### 边缘情况 1：`k = 0`什么时候`k`为零，则子序列中的相邻字符必须相同。 这将问题转变为寻找最常见的字符。 

由于范围计算不正确，天真的实现可能会意外地允许不同字母之间的转换。 

该实现可以正确处理这一问题，因为兼容范围正好变成一个字符：```
[current_index, current_index]
```因此，只有相同的字符才会构成子序列。 

### 边缘情况 2：`k = 25`什么时候`k = 25`，每个小写字母都与其他所有小写字母兼容。 

有缺陷的实现在计算时可能会意外超出数组边界：```
current_index + k
```该解决方案使用以下方法来防止这种情况发生：```
min(25, current_index + k)
```这可以安全地将搜索范围限制在有效的字母索引内。 

### 边缘情况 3：重复字符

 重复的字符可以改善多次以相同字母结尾的最佳子序列。 

例如：```
s = "abababab"
```最好的子序列以`'a'`和`'b'`在整个扫描过程中不断增长。 

一个常见的错误是错误地覆盖 DP 状态。 该实现通过使用以下方式避免了这种情况：```
dp[current_index] = max(
    dp[current_index],
    best_previous + 1
)
```这确保我们永远不会丢失以前更好的以相同字符结尾的子序列。
