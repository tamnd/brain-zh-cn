[LeetCode 问题 2309](https://leetcode.com/problems/greatest-english-letter-in-upper-and-lower-case/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、枚举

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅包含大写和小写英文字母。 我们的任务是找到字符串中某处以**小写和大写形式**出现的**最大的英文字母**。 答案必须以大写字母形式返回。 

为了清楚地理解这一点，请考虑一下“最伟大”在这种情况下的含义。 字母是按字母顺序排列的，所以`'Z'`大于`'Y'`,`'Y'`大于`'X'`， 等等。 我们并不是在寻找字符串中最常出现或第一个出现的字母。 我们只关心字母顺序排名。 

要使字母符合资格，输入中必须存在同一字符的两个版本。 例如，如果`'r'`和`'R'`两者都出现，那么`'R'`是一名候选人。 如果只有一个版本存在，例如`'e'`没有`'E'`，那么就不算数了。 

输入是单个字符串`s`， 在哪里：

-`s.length`范围从`1`到`1000`-`s`仅包含大写和小写英文字母

 输出是：

 - 最大有效字母的大写版本（如果存在）
 - 空字符串`""`如果两种形式都没有出现字母

 最多的约束`1000`人物告诉我们，对性能的要求并不高。 即使效率较低的方法也可以通过，但我们仍然应该寻求干净且最佳的解决方案。 

一些边缘情况值得预先识别。 该字符串可能仅包含小写或仅包含大写字母，这意味着不存在有效答案。 可能有多个有效字母，在这种情况下，我们必须返回按字母顺序排列最大的字母。 重复的字符是可能的，但频率并不重要，重要的是存在。 最后，最佳答案可能不会出现在字符串末尾附近，因此仅依靠遍历顺序可能会产生不正确的结果。 

## 方法

 ### 蛮力方法

 解决这个问题的一个直接方法是检查每个英文字母`'A'`通过`'Z'`，并确定字符串中是否同时出现大写和小写版本。 

一种简单的实现会重复扫描字符串中的每个字母。 例如，我们可以检查是否`'A'`和`'a'`存在，那么`'B'`和`'b'`，继续直到`'Z'`。 任何有效的字母都将被跟踪，并且最大的字母将被返回。 

这种方法是正确的，因为它详尽地评估了每个可能的英文字母并直接验证所需的条件。 由于只有 26 个字母，因此对于给定的约束，它仍然相当快。 

然而，重复搜索字符串会带来不必要的重复工作。 每次成员资格检查都可能会再次扫描字符串，从而使算法的效率低于所需的效率。 

### 最优方法，哈希集+字母逆向遍历

 关键的观察是我们只关心角色是否存在，而不关心它们出现了多少次。 这立即建议使用**哈希集**，因为集提供快速的成员资格检查。 

我们可以将所有字符放置在`s`成一个集合。 然后，我们不再以任意顺序搜索候选者，而是从`'Z'`下降到`'A'`。 对于每个大写字母，我们检查是否：

 1.大写字母在集合中存在
 2.集合中也存在小写版本

 满足这两个条件的第一个字母自动成为最大的有效答案，因为我们按字母降序顺序搜索。 

这种方法特别有效，因为英语字母表的大小固定，只有 26 个字母。 构建一次集合后，其余的工作就是恒定的时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(26 × n) | O(26 × n) | O(1) | O(1) | 重复扫描字符串中的每个字母 |
 | 最佳| O(n) | O(n) | 使用哈希集进行恒定时间成员资格检查 |

 ## 算法演练

 1. 创建一个包含输入字符串中每个字符的哈希集。 这允许恒定时间查找字母是否存在。 
2. 迭代大写字母`'Z'`下降到`'A'`。 我们按降序排列，因为找到的第一个有效字母将自动成为最大的字母。 
3. 对于每个大写字母：

 - 检查集合中是否存在大写版本。 
- 将其转换为小写并检查该版本是否也存在。 
4. 如果两个版本都存在，则立即返回大写字母，因为它是最大的有效答案。 
5. 如果循环结束时未找到有效字母，则返回空字符串。 

### 为什么它有效

 该算法之所以有效，是因为该集合准确地捕获了输入字符串中每个字符的存在。 通过迭代从`'Z'`到`'A'`，我们保证第一个有效匹配是按字母顺序排列最大的匹配。 由于每个可能的候选字母都被检查一次，因此不会错过任何有效的答案，并且不会在较大的答案之前返回较小的答案。 

## Python 解决方案```python
class Solution:
    def greatestLetter(self, s: str) -> str:
        characters = set(s)

        for ascii_code in range(ord('Z'), ord('A') - 1, -1):
            uppercase_letter = chr(ascii_code)
            lowercase_letter = uppercase_letter.lower()

            if (
                uppercase_letter in characters
                and lowercase_letter in characters
            ):
                return uppercase_letter

        return ""
```实现首先将字符串转换为名为的集合`characters`。 由于重复项是无关的，因此该集合仅有效地存储唯一字符，同时允许恒定时间的成员资格检查。 

该循环迭代 ASCII 值`'Z'`到`'A'`。 对于每个大写字母，我们使用以下方法计算其对应的小写字母`.lower()`。 然后我们检查这两种形式是否都存在于集合中。 

一旦发现有效信件，就会立即退回。 由于我们从最大到最小进行遍历，因此提前返回可以保证正确性。 如果循环完成时没有找到任何匹配项，则该函数返回一个空字符串。 

## 解决方案```go
func greatestLetter(s string) string {
	characters := make(map[rune]bool)

	for _, ch := range s {
		characters[ch] = true
	}

	for ch := 'Z'; ch >= 'A'; ch-- {
		lowercase := ch + ('a' - 'A')

		if characters[ch] && characters[lowercase] {
			return string(ch)
		}
	}

	return ""
}
```Go 实现使用`map[rune]bool`模拟哈希集。 字符串中的每个字符都会插入到映射中以进行恒定时间查找。 

与 Python 不同，Go 没有直接的`.lower()`符文的方法。 相反，我们使用 ASCII 算术通过添加之间的差异来计算小写等效值`'a'`和`'A'`。 

由于英文字母是ASCII字符，并且问题只保证英文字母，所以这种转换是安全高效的。

 ## 边缘情况

 ### 不存在有效信件

 当没有字符以小写和大写形式出现时，就会出现常见的边缘情况。 例如，`"abc"`或者`"ABC"`仅包含一种案例类型。 幼稚的实现可能会意外返回部分匹配或不正确的默认值。 我们的实现通过检查所有字母并在未找到有效对时返回空字符串来正确处理此问题。 

### 多个有效候选人

 输入可能包含几个符合条件的字母。 例如，`"aAbBcC"`包含有效对`A`,`B`， 和`C`。 有缺陷的实现可能会返回字符串中遇到的第一个有效匹配项，而不是按字母顺序排列的最大匹配项。 通过迭代从`'Z'`到`'A'`，我们的解决方案保证返回最大的有效字母。 

### 重复字符

 字符串可能包含重复出现的相同字符，例如`"xXxXxX"`。 频率无关紧要，因为问题只问这两种形式是否存在。 使用集合自然可以消除重复并防止不必要的重复检查，从而使实现更简单、更高效。 

### 缺少一对的一半

 当高级字母仅存在一种形式时，就会出现一种微妙的情况。 例如，`"AaBbYyZ"`包括大写`Z`但没有小写`z`。 不正确的实现可能会错误地返回`Z`只是因为它是目前最大的字母。 我们的解决方案在返回结果之前显式检查大写和小写成员资格，以确保正确性。
