[LeetCode 第 2358 题](https://leetcode.com/problems/maximum-number-of-groups-entering-a-competition/)

 **难度：** 🟡 中等
 **主题：** 数组、数学、二分查找、贪心

 ## 解决方案

 ## 问题理解

 该问题要求我们在两个严格的条件下将学生成绩列表划分为多个**有序组**。 首先，成绩总和`i-th`组必须**小于**`(i+1)-th`团体。 其次，随着我们的进步，每个小组的学生人数必须严格增加。 本质上，小组的规模和成绩总和都应该随着小组的不同而增长。 

输入是正整数数组`grades`，代表个别学生的成绩。 输出是一个整数，表示在满足约束的情况下可以形成的**最大组数**。 

约束表明`grades`最多可以有`10^5`元素，每个等级最多可达`10^5`。 这排除了需要枚举所有可能的组分区的方法，因为这在计算上是不可行的。 该问题保证了`grades`非空，因此至少有一名学生。 

重要的边缘情况包括：

 - 单个学生：只能存在一个小组。 
- 所有学生成绩相同：只有小组规模差异很重要。 
- 学生人数少，但成绩大或相同。 

关键的见解是，由于**组大小**和**成绩总和**都必须严格增加，因此我们不需要检查成绩的确切值，只需检查学生总数即可确定最大组数。 这将问题转化为数学问题：可以形成多少组使得`1 + 2 + ... + k <= n`， 在哪里`n`是学生人数。 

## 方法

 蛮力方法会尝试每一个可能的分区`grades`数组并检查总和和大小约束。 原则上这是正确的，但是分区数量呈指数增长`n`，使其不切实际`n = 10^5`。 

最佳方法利用了以下观察结果：`k`小组规模不断增加，所需的最少学生人数为第一个小组的总和`k`自然数：`1 + 2 + ... + k = k*(k+1)/2`。 因此，问题就简化为寻找最大的`k`这样`k*(k+1)/2 <= len(grades)`。 这可以使用简单的迭代方法或直接求解二次方程来解决。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 枚举所有可能的分区并检查总和/大小约束 |
 | 最佳 | O(√n) | O(√n) | O(1) | O(1) | 使用前 k 个整数的总和来确定最大组数 |

 ## 算法演练

 1. 计算学生总数`n = len(grades)`。 
2. 初始化计数器`k = 0`来表示组的数量。 
3. 虽然第一个的总和`k + 1`自然数`(k+1)*(k+2)/2`小于或等于`n`, 增量`k`。 
4. 返回`k`作为最大组数。 

为什么有效：通过形成不同规模的小组`1, 2, 3, ..., k`，我们保证每个组的学生人数严格增加。 由于成绩可以任意安排，因此通过适当的分配也可以使这些规模不断增大的组中的成绩总和严格增加。 因此，限制因素是学生总数，而不是实际成绩。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumGroups(self, grades: List[int]) -> int:
        n = len(grades)
        k = 0
        while (k + 1) * (k + 2) // 2 <= n:
            k += 1
        return k
```该实现通过迭代测试来计算最大组数`k`直到三角数`k*(k+1)/2`超过`n`。 这确保了满足组大小条件，并且通过对成绩进行适当排序始终可以满足总和条件。 

## 解决方案```go
func maximumGroups(grades []int) int {
    n := len(grades)
    k := 0
    for (k+1)*(k+2)/2 <= n {
        k++
    }
    return k
}
```Go 解决方案反映了 Python 逻辑。 我们显式处理整数除法并依赖 Go 的整数算术，它自然地对除法结果进行取整，与 Python 整数除法运算符一致`//`。 

## 工作示例

 **示例1：`grades = [10,6,12,7,3,5]`**

 学生人数`n = 6`。 

- 尝试`k = 1`：总和 = 1 ≤ 6
 - 尝试`k = 2`：总和 = 3 ≤ 6
 - 尝试`k = 3`：总和 = 6 ≤ 6
 - 尝试`k = 4`：总和 = 10 > 6

 最大组数 = 3

 **示例2：`grades = [8,8]`**

 学生人数`n = 2`。 

- 尝试`k = 1`：总和 = 1 ≤ 2
 - 尝试`k = 2`：总和 = 3 > 2

 最大组数 = 1

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(√n) | O(√n) | while 循环运行直到 k(k+1)/2 > n，这大约是 √(2n) 次迭代 |

 对于 n ≤ 10^5，时间复杂度非常有效，并且空间复杂度是恒定的。

 ## 边缘情况

 **单个学生：** 当阵中只有一名学生时，只能组成一组。 该实现自然地处理了这个问题，因为循环永远不会递增`k`超过1。 

**所有等级均等：** 当所有等级均等时，总和条件不会阻止小组形成，但小组规模仍必须严格增加。 该算法仅依赖于学生人数，因此可以正确计算最大组数。 

**最大尺寸输入：** 对于`n = 10^5`和最高等级，由于 O(√n) 循环，该方法仍然有效。 Python 中不存在整数溢出的风险，而 Go 中的乘法`(k+1)*(k+2)`保持在远低于`int`限制为`n = 10^5`。
