 # LeetCode 2381 - 移动字母 II

 ## 问题理解

 这个问题给了我们一个小写英文字符串`s`以及轮班操作列表。 每个操作表示为：```
[start, end, direction]
```该操作影响索引中的每个字符`start`索引`end`，包含在内。 

如果`direction == 1`，该范围内的每个字符在字母表中向前移动一个字母：```
a -> b
b -> c
...
z -> a
```如果`direction == 0`，每个字符向后移动：```
b -> a
a -> z
```目标是应用所有操作并返回最终转换后的字符串。 

重要的细节是多个操作可能会重叠。 一个角色可以向前或向后移动多次。 我们需要确定每个位置的总净偏移量，而不是立即应用每个操作。 

限制条件很大：

 -`s.length <= 5 * 10^4`-`shifts.length <= 5 * 10^4`为每个操作更新每个角色的简单解决方案可能需要：```
5 * 10^4 * 5 * 10^4 = 2.5 * 10^9
```在最坏的情况下，操作速度太慢了。 

输入保证：

 - 所有指数均有效。 
- 字符串仅包含小写英文字母。 
- 每个移位方向要么向前，要么向后。 

一些边缘情况很重要：

 - 操作可能会严重重叠。 
- 一个角色可以在两个方向上移动多次。 
- 大的累积移位必须使用模 26 正确换行。 
- 单字符范围，例如`[3,3,1]`必须正确工作。 
- 向后移位可能会产生负总数，因此模数处理必须小心。 

## 方法

 ### 蛮力方法

 最直接的解决方案是完全按照描述模拟每一个操作。 

对于每个班次操作：

 1. 阅读`start`,`end`， 和`direction`。 
2. 迭代每个索引`start`到`end`。 
3. 将对应的字符向前或向后移动一位。 

这种方法是正确的，因为它确实遵循问题陈述。 

然而，它的效率很低。 如果每个操作几乎影响整个字符串，那么每个操作都会花费`O(n)`。 高达`5 * 10^4`操作，总复杂度变为`O(n * m)`在哪里：

-`n = len(s)`-`m = len(shifts)`最坏情况下的运行时间太大了。 

### 最优方法，前缀和/差数组

 关键的观察是我们实际上并不需要在每次操作期间更新字符。 

相反，我们只需要知道应用于每个指数的最终净偏移。 

例如：```
+1
-1
+1
```同一字符上的总偏移量为`+1`。 

这将问题转化为范围更新问题。 

差异数组允许我们有效地应用范围增量：

 - 添加`+1`在前进范围的开始处。 
- 添加`-1`在向后范围的开始处。 
- 范围结束后立即减去相同的值。 

随后，前缀和重建每个位置的实际累积偏移。 

这减少了每次操作`O(length of range)`到`O(1)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(1) | O(1) | 直接模拟每个班次 |
 | 最佳| O(n + m) | O(n) | 使用差异数组和前缀和 |

 ## 算法演练

 1.创建大小不同的数组`n + 1`，用零初始化。 

额外的插槽可以帮助我们标记范围效果停止的位置。 
2. 处理每个班次操作。 

对于每个操作：

 - 将方向转换为值：

 -`1 -> +1`-`0 -> -1`- 将此值添加到`start`。 
- 减去该值`end + 1`如果存在的话。 

这会记录范围效果，而无需单独更新每个元素。 
3. 遍历字符串时计算前缀和。 

运行前缀总和表示影响当前索引的总移位。 
4. 将每个字符转换为其字母表索引。 

例如：```
a -> 0
b -> 1
...
z -> 25
```5. 应用累积班次。 

使用模 26 正确环绕字母表。 
6. 将移位后的值转换回字符。 
7. 构建并返回最终字符串。 

### 为什么它有效

 差异数组记录跨范围的移位如何开始和结束。 当我们计算前缀和时，每个位置都会准确累积覆盖该索引的所有范围的贡献。 因此，计算出的每个字符的累积移位与单独应用每个操作的结果相匹配。 由于模 26 可以正确处理字母换行，因此最终的字符串保证是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def shiftingLetters(self, s: str, shifts: List[List[int]]) -> str:
        n = len(s)
        
        # Difference array
        diff = [0] * (n + 1)
        
        # Apply range updates
        for start, end, direction in shifts:
            shift_value = 1 if direction == 1 else -1
            
            diff[start] += shift_value
            
            if end + 1 < len(diff):
                diff[end + 1] -= shift_value
        
        result = []
        current_shift = 0
        
        # Build final string using prefix sums
        for i in range(n):
            current_shift += diff[i]
            
            original_position = ord(s[i]) - ord('a')
            
            shifted_position = (original_position + current_shift) % 26
            
            shifted_character = chr(shifted_position + ord('a'))
            
            result.append(shifted_character)
        
        return "".join(result)
```实现首先创建一个名为的差异数组`diff`。 该数组跟踪移位如何跨范围变化，而不是直接修改字符。 

对于每个操作：```python
[start, end, direction]
```该代码将方向转换为`+1`或者`-1`。 

更新：```python
diff[start] += shift_value
```标记转变开始的位置。 

更新：```python
diff[end + 1] -= shift_value
```标记转变停止影响未来位置的位置。 

处理完所有操作后，算法将遍历字符串一次，同时维护运行的前缀和`current_shift`。 该值表示当前字符的总净偏移量。 

每个字符都使用以下方法转换为数字字母索引：```python
ord(s[i]) - ord('a')
```使用模 26 应用移位，因此对于正移位和负移位都可以正确进行换行。 

最后，将转换后的字符连接到答案字符串中。 

## 解决方案```go
func shiftingLetters(s string, shifts [][]int) string {
	n := len(s)

	// Difference array
	diff := make([]int, n+1)

	// Apply range updates
	for _, shift := range shifts {
		start := shift[0]
		end := shift[1]
		direction := shift[2]

		shiftValue := -1
		if direction == 1 {
			shiftValue = 1
		}

		diff[start] += shiftValue

		if end+1 < len(diff) {
			diff[end+1] -= shiftValue
		}
	}

	result := []byte(s)

	currentShift := 0

	// Build final string
	for i := 0; i < n; i++ {
		currentShift += diff[i]

		originalPosition := int(result[i] - 'a')

		shiftedPosition := (originalPosition + currentShift) % 26

		// Handle negative modulo
		if shiftedPosition < 0 {
			shiftedPosition += 26
		}

		result[i] = byte(shiftedPosition) + 'a'
	}

	return string(result)
}
```Go 实现遵循与 Python 版本相同的算法。 

Go 特有的一项重要细节是模处理。 在Python中：```go
(-1) % 26 == 25
```但在 Go 中：```go
-1 % 26 == -1
```因此，Go 解决方案显式调整负值：```go
if shiftedPosition < 0 {
    shiftedPosition += 26
}
```该解决方案还使用了`[]byte`由于 Go 字符串是不可变的，切片可实现高效的就地字符更新。

 ## 边缘情况

 ### 较大的负变化

 一个角色可能会接受多次向后移动，导致累积移动值变得非常负。 如果模运算处理不正确，这可能会产生错误。 

例如：```
"a" shifted backward 27 times
```应该变成：```
"z"
```该实现使用模 26 算术安全地处理这个问题。 Python 自动将负模结果转换为正等值。 

### 全字符串范围更新

 一个操作可能会影响整个字符串：```
[0, n - 1, 1]
```这很重要，因为更新`end + 1`不得访问无效索引。 

该实现通过检查来避免越界错误：```
if end + 1 < len(diff):
```在从差异数组中减去之前。 

### 大量重叠操作

 许多操作可能会在相同的索引上重叠。 幼稚的实现会重复更新相同的字符，从而导致严重的性能问题。 

差异数组方法可以有效地处理重叠，因为无论范围大小如何，每个操作都只执行两次恒定时间更新。 前缀和自然地将所有重叠效应组合成每个位置的最终累积移位。
