[LeetCode 问题 2324](https://leetcode.com/problems/product-sales-analysis-iv/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 这个问题要求我们分析销售数据，以确定每个用户在哪些产品上花费最多的钱。 我们有两张表：`Sales`和`Product`。 这`Sales`表包含单独的交易，显示哪个用户购买了哪种产品以及购买的数量。 这`Product`表包含每种产品的价格。 

任务是计算每个用户在每个产品上花费的总金额，确定每个用户花费的最大金额，然后报告用户花费该最大金额的所有产品。 输出应包括每个`user_id`与一个或多个配对`product_id`与他们花最多钱的产品相对应。 

约束意味着`sale_id`和`product_id`是唯一标识符，表的大小对于数据库操作来说是可管理的，但我们必须处理用户拥有多个与最大支出相关的产品的情况。 边缘情况包括仅购买一种产品的用户、多次购买且最大支出总和相同的用户以及零购买的用户（尽管后者未在样本中明确列出）。 

## 方法

 暴力方法将通过迭代所有销售来计算每个用户-产品对的总支出，然后针对每个用户扫描所有产品总计以找到最大值。 这种方法是正确的，但效率低下，特别是在有很多用户和产品的情况下，因为它需要多个嵌套循环。 

最佳方法利用 SQL 聚合和连接。 首先我们加入`Sales`和`Product`计算每笔交易的支出，然后使用以下方法汇总每个用户-产品对的支出`SUM(quantity * price)`。 最后，我们使用窗口函数或子查询来确定每个用户的最大支出，并过滤结果以仅包含支出等于最大值的产品。 这避免了嵌套循环，并利用数据库优化来进行连接、聚合和过滤。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(U * P * S) | O(U * P) | 迭代每个用户和产品； S 是销售数量 |
 | 最佳| O(S + U * P) | O(U * P) | 使用子查询或窗口函数进行联接+聚合+过滤 |

 ## 算法演练

 1. **连接表**：在表之间执行内连接`Sales`和`Product`在`product_id`获取每笔销售的价格和数量。 这允许计算每笔交易的支出。 
2. **汇总支出**：对结果表进行分组`user_id`和`product_id`,求和`quantity * price`获取每个用户在每个产品上花费的总金额。 
3. **确定最大支出**：对于每个用户，计算所有产品的最大总支出。 这可以使用窗口函数来完成`MAX()`超过`user_id`或每个用户的子查询。 
4. **筛选结果**：仅选择总支出等于该用户最高支出的用户-产品对。 
5. **返回输出**：产生包含以下内容的最终结果：`user_id`和`product_id`。 无需订购。 

**为什么有效**：此方法之所以有效，是因为聚合可以正确计算总支出，并且对计算出的最大值进行过滤可确保仅包含每个用户支出最高的产品。 即使多个产品具有相同的支出，使用 SQL 集操作也能确保效率和正确性。 

## Python 解决方案```python
import sqlite3
from typing import List, Tuple

def product_sales_analysis(sales: List[Tuple[int, int, int, int]],
                           products: List[Tuple[int, int]]) -> List[Tuple[int, int]]:
    # Create in-memory SQLite database
    conn = sqlite3.connect(":memory:")
    cursor = conn.cursor()

    # Create tables
    cursor.execute("CREATE TABLE Sales(sale_id INT, product_id INT, user_id INT, quantity INT)")
    cursor.execute("CREATE TABLE Product(product_id INT, price INT)")

    # Insert data
    cursor.executemany("INSERT INTO Sales VALUES (?, ?, ?, ?)", sales)
    cursor.executemany("INSERT INTO Product VALUES (?, ?)", products)

    # SQL query to find products with max spending per user
    query = """
    WITH UserProductTotal AS (
        SELECT s.user_id, s.product_id, SUM(s.quantity * p.price) AS total_spent
        FROM Sales s
        JOIN Product p ON s.product_id = p.product_id
        GROUP BY s.user_id, s.product_id
    ),
    MaxSpent AS (
        SELECT user_id, MAX(total_spent) AS max_spent
        FROM UserProductTotal
        GROUP BY user_id
    )
    SELECT u.user_id, u.product_id
    FROM UserProductTotal u
    JOIN MaxSpent m ON u.user_id = m.user_id AND u.total_spent = m.max_spent
    """
    
    cursor.execute(query)
    result = cursor.fetchall()
    conn.close()
    return result
```Python 实现使用 SQLite 来模拟 SQL 环境。 首先，它创建`Sales`和`Product`表并插入给定的数据。 SQL 查询使用公用表表达式 (CTE) 来计算每个用户-产品对的总支出 (`UserProductTotal`），然后找到每个用户的最大支出（`MaxSpent`）。 最终连接仅选择支出等于最大值的产品。 

## 解决方案```go
package main

import (
    "database/sql"
    _ "github.com/mattn/go-sqlite3"
)

func ProductSalesAnalysis(sales [][4]int, products [][2]int) [][2]int {
    db, _ := sql.Open("sqlite3", ":memory:")
    defer db.Close()

    db.Exec("CREATE TABLE Sales(sale_id INT, product_id INT, user_id INT, quantity INT)")
    db.Exec("CREATE TABLE Product(product_id INT, price INT)")

    for _, s := range sales {
        db.Exec("INSERT INTO Sales VALUES (?, ?, ?, ?)", s[0], s[1], s[2], s[3])
    }
    for _, p := range products {
        db.Exec("INSERT INTO Product VALUES (?, ?)", p[0], p[1])
    }

    query := `
    WITH UserProductTotal AS (
        SELECT s.user_id, s.product_id, SUM(s.quantity * p.price) AS total_spent
        FROM Sales s
        JOIN Product p ON s.product_id = p.product_id
        GROUP BY s.user_id, s.product_id
    ),
    MaxSpent AS (
        SELECT user_id, MAX(total_spent) AS max_spent
        FROM UserProductTotal
        GROUP BY user_id
    )
    SELECT u.user_id, u.product_id
    FROM UserProductTotal u
    JOIN MaxSpent m ON u.user_id = m.user_id AND u.total_spent = m.max_spent
    `

    rows, _ := db.Query(query)
    defer rows.Close()

    var result [][2]int
    for rows.Next() {
        var userID, productID int
        rows.Scan(&userID, &productID)
        result = append(result, [2]int{userID, productID})
    }

    return result
}
```在 Go 中，实现类似，但具有数据库/sql 处理和切片操作。 Go 需要对查询结果进行显式迭代来构造输出切片。 为了简洁起见，错误处理被省略，但应该包含在生产中。 

## 工作示例

 对于输入：

 销售表：```
sale_id | product_id | user_id | quantity
1       | 1          | 101     | 10
2       | 3          | 101     | 7
3       | 1          | 102     | 9
4       | 2          | 102     | 6
5       | 3          | 102     | 10
6       | 1          | 102     | 6
```产品表：```
product_id | price
1          | 10
2          | 25
3          | 15
```第1步：加入并计算支出：```
user_id | product_id | total_spent
101     | 1          | 100
101     | 3          | 105
102     | 1          | 150
102     | 2          | 150
102     | 3          | 150
```第 2 步：确定每个用户的最大数量：```
user_id | max_spent
101     | 105
102     | 150
```步骤 3：过滤等于 max 的乘积：```
user_id | product_id
101     | 3
102     | 1
102     | 2
102     | 3
```## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(S + U * P) | S为销售数量； 每个用户-产品对的聚合和过滤占主导地位
 | 空间| O(U * P) | 存储每个用户-产品对的总支出的空间|

 SQL 引擎有效地优化连接和分组。 使用 CTE 可以避免重复扫描并减少冗余计算。
