 **难度：** 🔴难
 **主题：** 数组、并查集、图论、拓扑排序、排序、矩阵

 ## 解决方案

 ## 问题理解

 问题呈现一个矩阵`grid`尺寸的`m x n`具有**不同的正整数**。 目标是转换此矩阵，以便每个元素都替换为另一个正整数，同时**保持每行和列中的相对顺序**。 这意味着如果一个元素最初比同一行或同一列中的另一个元素大，则转换后它必须保持更大。 在所有可能的变换中，矩阵的**最大值**应该最小化。 

简而言之，您希望“压缩”矩阵值，同时保留行和列顺序。 例如，如果一行有`[3,1,5]`，你可以将它映射到`[2,1,3]`只要订单`3>1<5`被保留。 

约束表明`m`和`n`每个最多可以达到 1000 个，元素总数最多为 105 个。`grid`包含**不同的整数**，我们不需要处理相等的值，简化了排序逻辑。 重要的边缘情况包括单元素矩阵、具有连续数字的行或列，以及最小值和最大值出现在不同行和列中的矩阵。 

## 方法

 强力方法是尝试所有可能的正整数替换并验证行和列的顺序。 虽然这保证了正确性，但排列的数量却是天文数字（`O((max(grid))^(m*n))`）并且考虑到限制是不可行的。 

最佳方法的关键见解是可以使用**图论**对该问题进行建模。 每个矩阵元素可以被视为一个节点。 如果一个元素`a`大于`b`在同一行或同一列中，我们可以添加一条有向边`b -> a`，表示`b`必须得到一个小于或等于的数字`a`。 一旦我们拥有了所有边，我们实际上就拥有了**有向无环图（DAG）**，因为矩阵具有不同的数字并且比较是严格的。 现在的问题简化为在尊重所有 DAG 边的同时为每个节点分配尽可能小的整数，这可以使用**拓扑排序**结合动态编程来增量分配等级来解决。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((最大(网格))^(m*n)) | O(m*n) | 尝试所有可能的替代方案，但对于大输入来说不切实际 |
 | 最佳| O(m_n * log(m_n)) | O(m_n * log(m_n)) | O(m*n) | 使用排序、拓扑约束和并查找或行/列排名跟踪 |

 ## 算法演练

 1. 将矩阵展平为列表`(value, row, column)`元组以按值递增的顺序处理元素。 
2.初始化两个数组，`row_max`和`col_max`，跟踪分配给每行和每列的**当前最大排名**。 
3. 按值升序对展平列表进行排序。 
4. 迭代已排序的元素。 对于每个元素`(r, c)`:

 - 分配给的新值`grid[r][c]`应该是`max(row_max[r], col_max[c]) + 1`。 这确保了相对顺序的维持。 
- 更新`row_max[r]`和`col_max[c]`到这个新值。 
5.处理完所有元素后，矩阵已经变换，并且最大值被最小化。 
6. 返回结果矩阵。 

**为什么起作用：** 通过从最小到最大处理元素并根据迄今为止在其行或列中看到的最大排名分配排名，该算法保证满足所有相对顺序约束。 每个元素都获得与约束一致的最小可能数，从而最小化全局最大值。 

## Python 解决方案```python
from typing import List

class Solution:
    def minScore(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        row_max = [0] * m
        col_max = [0] * n
        result = [[0] * n for _ in range(m)]
        
        # Flatten grid with coordinates and sort by value
        elements = sorted([(grid[r][c], r, c) for r in range(m) for c in range(n)])
        
        for value, r, c in elements:
            rank = max(row_max[r], col_max[c]) + 1
            result[r][c] = rank
            row_max[r] = rank
            col_max[c] = rank
        
        return result
```**实施演练：**`row_max`和`col_max`数组跟踪迄今为止在每行和每列中分配的最大数字。 排序确保我们首先处理较小的元素，这对于维持相对顺序至关重要。 分配`rank = max(row_max[r], col_max[c]) + 1`保证新数字严格大于同一行或同一列中的所有较小数字。 

## 解决方案```go
func minScore(grid [][]int) [][]int {
    m, n := len(grid), len(grid[0])
    rowMax := make([]int, m)
    colMax := make([]int, n)
    result := make([][]int, m)
    for i := range result {
        result[i] = make([]int, n)
    }

    type Element struct {
        val, r, c int
    }
    elements := make([]Element, 0, m*n)
    for r := 0; r < m; r++ {
        for c := 0; c < n; c++ {
            elements = append(elements, Element{grid[r][c], r, c})
        }
    }

    sort.Slice(elements, func(i, j int) bool {
        return elements[i].val < elements[j].val
    })

    for _, e := range elements {
        rank := max(rowMax[e.r], colMax[e.c]) + 1
        result[e.r][e.c] = rank
        rowMax[e.r] = rank
        colMax[e.c] = rank
    }

    return result
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```**Go特定注释：** 我们定义一个结构体`Element`存储值和坐标。`sort.Slice`用于排序。 逻辑与 Python 相同。 切片是预先分配的以避免重复追加。 这`max`辅助函数简化了排名分配。
