[LeetCode 第 2354 题](https://leetcode.com/problems/number-of-excellent-pairs/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、二分查找、位操作

 ## 解决方案

 ## 问题理解

 该问题提供了一个 0 索引的正整数数组`nums`和一个正整数`k`。 任务是计算所有**不同的对**`(num1, num2)`这样两个数字都存在于`nums`以及设置位数的总和`num1 OR num2`和`num1 AND num2`至少是`k`。 一对`(num1, num2)`被认为不同于`(num2, num1)`即使数字相同。 配对在哪里`num1 == num2`是允许的。 

正式来说，对于一对`(a, b)`要**优秀**，它必须满足：```
count_bits(a | b) + count_bits(a & b) >= k
```在哪里`count_bits(x)`是二进制表示中 1 的数量`x`。 

约束条件告诉我们`nums`可以非常大（最多 100,000 个元素）并且中的值`nums`可以很大（最多 10^9）。 这意味着对所有对进行简单的双循环会太慢。 该问题还强调，配对计数时必须小心避免重复`num1 != num2`并且必须允许`num1 == num2`正确。 

重要的边缘情况包括所有元素都相同的数组、没有一对满足的数组`k`，以及包含非常大整数的数组，其中位计数接近 30，如`nums[i] <= 10^9`。 

## 方法

 **暴力方法**将迭代所有对`(i, j)`在哪里`i`和`j`索引数组，计算`(nums[i] | nums[j])`和`(nums[i] & nums[j])`，对设置的位进行计数，并检查总和是否大于或等于`k`。 这是正确的，但时间复杂度为 O(n^2)，这对于`n`最多 10^5。 

最佳方法的**关键洞察**是观察以下几点：```
count_bits(a | b) + count_bits(a & b) = count_bits(a) + count_bits(b)
```这是一个重要的位操作属性。 它允许我们用每个数字的位计数的更简单的总和来替换对上的按位运算。 因此，而不是检查`(a | b)`和`(a & b)`，我们只需要每个唯一数字的设置位数`nums`。 

接下来，我们可以通过将**唯一数字**存储在中来减少重复计算`nums`。 我们将每个数字转换为其`bit_count`并对这些计数进行排序。 然后，对于每个位计数`c1`，我们可以使用二分查找来统计`c2`这样`c1 + c2 >= k`。 

这会带来更快的算法。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 直接检查所有对。 对于 n=1e5 太慢 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 使用唯一值、计数位、排序和二分搜索 |

 ## 算法演练

 1. 删除重复项`nums`以减少不必要的计算。 这确保我们正确地计算不同的对。 
2. 计算每个唯一数字的设置位数`nums`使用类似的函数`bin(num).count('1')`在Python中。 
3. 对位数列表进行排序。 排序允许有效的二分搜索来查找补集。 
4. 初始化计数器`total_pairs = 0`。 
5. 对于每一位计数`c1`在排序列表中，计算`target = k - c1`。 这是最小位数`c2`需要形成一个优秀的搭档。 
6. 使用二分查找查找第一个的索引`c2 >= target`在排序列表中。 
7、有效数量`c2`为此的值`c1`是`len(bit_counts) - index`。 将此计数添加到`total_pairs`。 
8. 迭代完所有之后`c1`， 返回`total_pairs`。 每对都会自动单独计数，因为我们根据排序的位计数来计算组合。 

**为什么有效：** 该属性`count_bits(a | b) + count_bits(a & b) = count_bits(a) + count_bits(b)`将问题简化为位计数的总和检查。 通过使用排序位计数和二分搜索，我们可以有效地计算满足总和条件的所有对，而无需显式迭代所有 n^2 组合。 重复数据删除可确保唯一编号的正确性。 

## Python 解决方案```python
from typing import List
import bisect

class Solution:
    def countExcellentPairs(self, nums: List[int], k: int) -> int:
        unique_nums = list(set(nums))
        bit_counts = [bin(num).count('1') for num in unique_nums]
        bit_counts.sort()
        
        total_pairs = 0
        n = len(bit_counts)
        
        for c1 in bit_counts:
            target = k - c1
            idx = bisect.bisect_left(bit_counts, target)
            total_pairs += n - idx
        
        return total_pairs
```在此实现中，我们首先使用删除重复项`set(nums)`。 然后我们计算位数并对它们进行排序。 对于每个`c1`，我们确定最小的`c2`满足总和使用`bisect_left`。 结果有效地累积了所有有效对。 

## 解决方案```go
import (
    "sort"
    "math/bits"
)

func countExcellentPairs(nums []int, k int) int64 {
    uniqueMap := make(map[int]struct{})
    for _, num := range nums {
        uniqueMap[num] = struct{}{}
    }
    
    bitCounts := make([]int, 0, len(uniqueMap))
    for num := range uniqueMap {
        bitCounts = append(bitCounts, bits.OnesCount(uint(num)))
    }
    
    sort.Ints(bitCounts)
    var totalPairs int64 = 0
    n := len(bitCounts)
    
    for _, c1 := range bitCounts {
        target := k - c1
        idx := sort.Search(n, func(i int) bool { return bitCounts[i] >= target })
        totalPairs += int64(n - idx)
    }
    
    return totalPairs
}
```在 Go 中，我们使用`map`删除重复项和`bits.OnesCount`对设置的位进行计数。`sort.Search`实现二分搜索以有效地找到满足目标总和条件的第一个索引。
