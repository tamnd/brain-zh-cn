 # LeetCode 2357 - 通过减去等量使数组为零

 ## 问题理解

 这个问题给了我们一个数组`nums`包含非负整数。 我们想要使用特定的操作将整个数组转换为零。 

在单次运算中，我们必须选择一个正整数`x`小于或等于数组中当前存在的最小非零值。 选择后`x`，我们从数组中的每个正元素中减去它。 已经为零的元素保持不变。 

我们的目标是确定使每个元素等于零所需的最少操作数。 

一个关键细节是所选值`x`不得超过最小的非零元素。 由于所有正元素都减少相同的量，如果我们选择，最小的非零元素在运算后将始终变为零`x`等于该最小值。 

限制非常小：

 -`1 <= nums.length <= 100`-`0 <= nums[i] <= 100`这意味着即使是相对低效的方法也能发挥作用。 然而，该问题包含一个重要的观察结果，可以得出非常简单的最优解决方案。 

### 重要的边缘案例

 如果数组仅包含零，则无需进行任何操作，答案为`0`。 

如果数组仅包含一个正值，则只需要进行一次操作。 

重复值很重要，因为可以一起消除多次出现的相同正数。 

在计算所需操作时，混合有零和正数的数组应忽略零。 

## 方法

 ### 蛮力

 直接模拟完全按照描述进行操作。 

每一步：

 1. 找到最小的非零元素。 
2. 使用该值作为`x`。 
3.从每一个积极的元素中减去它。 
4. 计算操作次数。 
5. 重复直到所有元素变为零。 

这是可行的，因为选择最小的非零值始终是最佳的。 任何较小的值都需要稍后进行额外的操作。 

该方法是正确的，因为它确实执行了问题陈述中描述的过程。 但是，它会重复扫描数组以找到最小的非零值，然后再次扫描以执行减法。 

### 关键见解

 不要模拟该过程，而是考虑实际发生的情况。 

假设正值为：```
1, 3, 5
```减去后`1`，值变为：```
0, 2, 4
```减去后`2`，他们变成：```
0, 0, 2
```减去后`2`再次，一切都归零。 

请注意，每个操作恰好消除了一个不同的正值级别。 

更一般地说：

 - 每个唯一的正数最终都会成为最小的非零值一次。 
- 当它成为最小的非零值时，一次操作会完全消除该级别。 
- 重复的值在同一操作中一起消失。 

因此，答案就是数组中不同正整数的数量。 

例如：```
[1,5,0,3,5]
```独特的正值：```
{1,3,5}
```计数 = 3

 答案=3。

 ## 算法演练

 ### 最优算法

 1. 创建一个空的哈希集。 
2. 迭代中的每个数字`nums`。 
3. 如果当前数字大于零，则将其插入到集合中。 
4. 忽略所有零，因为它们已经不需要任何工作。 
5. 处理完整个数组后，返回集合的大小。 

哈希集会自动删除重复项，因此每个不同的正值都会被精确计数一次。 

### 为什么它有效

 每个操作都会从数组中删除当前最小的正值。 不同的正值一次会消失一个级别。 如果有`k`唯一的正数，恰好`k`需要进行操作，因为每次操作只能消除一个不同的正水平。 相反，选择最小的正值总是完全消除一个级别，因此`k`操作就足够了。 因此，答案等于不同正整数的数量。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        distinct_positive = set()

        for num in nums:
            if num > 0:
                distinct_positive.add(num)

        return len(distinct_positive)
```该实现创建了一个名为`distinct_positive`。 

当我们迭代数组时，每个正数都会插入到集合中。 由于集合自动存储唯一值，因此重复的数字仅计算一次。 

零被忽略，因为它们已经满足目标状态并且从不参与额外的操作。 

最后，返回集合的大小，它等于不同正值的数量，因此等于最小操作数。 

## 解决方案```go
func minimumOperations(nums []int) int {
	distinctPositive := make(map[int]struct{})

	for _, num := range nums {
		if num > 0 {
			distinctPositive[num] = struct{}{}
		}
	}

	return len(distinctPositive)
}
```Go 解决方案使用映射作为哈希集，因为 Go 没有提供内置的集合类型。 

映射键存储不同的正数，而空结构值基本上不消耗额外的存储空间。 

其他方面的逻辑与 Python 实现相同。 不用担心整数溢出，因为所有值最多都是`100`。

 ## 边缘情况

 ### 数组仅包含零

 An input such as:```
[0,0,0]
```已经满足目标了。 A buggy implementation might incorrectly count zero as a distinct value. The solution explicitly ignores zeros, producing an empty set and returning`0`。 

### 所有正值都相等

 考虑：```
[7,7,7,7]
```虽然有四个元素，但通过选择，它们都会在一次操作中消失`x = 7`。 该集合仅包含一个不同的正值，因此算法正确返回`1`。 

### 每个正值都是不同的

 考虑：```
[1,2,3,4,5]
```每个不同的级别最终都必须单独消除。 该集合包含五个值，所以答案是`5`。 这验证了该算法计算的是不同的正值而不是总元素。 

### 零与正数混合

 考虑：```
[0,0,2,2,5]
```零不应该影响答案，因为它们从不参与运算。 该实现完全忽略零并且仅计数`{2,5}`，返回`2`，这是正确的。
