[LeetCode 问题 2313](https://leetcode.com/problems/minimum-flips-in-binary-tree-to-get-result/)

 **难度：** 🔴难
 **主题：** 动态规划、树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 问题提出了一个二叉树，其中叶节点代表布尔值`0`（假）或`1`(true)，内部节点表示布尔运算`OR`,`AND`,`XOR`， 和`NOT`，编码为整数`2`,`3`,`4`， 和`5`。 You are also given a target boolean result. 任务是确定**叶节点所需的最小翻转次数**，以便评估树产生目标结果。 

Each operation is flipping a leaf node from`0`到`1`反之亦然。 非叶节点根据其类型及其子节点的评估递归计算值。`OR`,`AND`， 和`XOR`节点有两个子节点，而`NOT`节点只有一个子节点。 叶节点不能翻转多次。 

树可能很大，最多有 100,000 个节点，因此考虑翻转叶节点的每个组合的简单方法在计算上是不可行的。 该问题保证总是有可能达到期望的结果，因此不需要处理不可能的情况。 

重要的边缘情况包括只有一个节点（叶子）的树，所有操作都在的树`NOT`，或者当树已经评估到目标时。 处理`NOT`正确是至关重要的，因为它只有一个孩子，这会改变递归评估。 

## 方法

 **暴力方法**将探索叶子翻转的所有可能组合。 对于每个组合，您将递归地评估树并检查它是否与目标结果匹配。 虽然原则上是正确的，但这**慢**，因为叶节点的数量可能很大，使得该方法对于问题约束不可行。 

**最佳方法**依赖于**树上的动态编程**。 对于每个节点，我们计算两个值：该子树评估所需的最小翻转次数`true`以及评估所需的最少翻转次数`false`。 叶节点具有简单的值（`0`需要翻转 1 次才能变成`true`,`1`需要翻转 1 次才能变成`false`）。 内部节点根据其操作及其子节点的结果计算其真/假翻转计数。 使用后序 DFS 可确保在父级之前计算子级的值，从而实现最小翻转的自下而上计算。 

这将问题简化为计算单次遍历中每个节点的最小值，从而给出线性时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^L * N) | O(2^L * N) | O(N) | L = 叶节点数，评估所有翻转组合，不切实际 |
 | 最佳| O(N) | O(H) | 使用动态规划的 DFS，H = 树的高度，自下而上计算最小翻转次数 |

 ## 算法演练

 1. **定义一个 DFS 函数**，对于给定节点，返回一个元组`(min_flips_false, min_flips_true)`表示使子树评估为的最小翻转次数`false`或者`true`。 
2. **叶子节点的基本情况：** 如果节点是叶子，则最小翻转次数为`0`如果当前值与目标匹配，并且`1`如果没有。 具体来说，对于叶子值`0`，翻转到`false`是`0`，翻转到`true`是`1`。 对于叶子值`1`，翻转到`false`是`1`，翻转到`true`是`0`。 
3. **内部节点的递归计算：**

 - 计算`left`和`right`左右子节点翻转（如果存在）。 为了`NOT`，只计算一个孩子。 
- 取决于操作（`OR`,`AND`,`XOR`,`NOT`），根据**布尔真值表**并结合子翻转计数来计算正确和错误的最小翻转。 
4. **返回适当的值：** DFS完成后，使用目标布尔结果选择从根开始的最小翻转。 
5. **DFS 遍历确保**每个节点只处理一次，将最优解从叶子传播到根。 

**为什么有效：** 每个节点的最小翻转计数都是根据其子节点计算的。 通过使用后序 DFS，我们确保在计算节点时，我们已经知道其子节点的最佳翻转。 这保证了获得树的全局最小翻转。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minimumFlips(self, root: Optional[TreeNode], result: bool) -> int:
        def dfs(node: Optional[TreeNode]) -> tuple[int, int]:
            if not node.left and not node.right:  # leaf node
                if node.val == 0:
                    return (0, 1)  # (flips to false, flips to true)
                else:
                    return (1, 0)
            
            if node.val == 5:  # NOT operation
                child_false, child_true = dfs(node.left or node.right)
                return (child_true, child_false)
            
            left_false, left_true = dfs(node.left)
            right_false, right_true = dfs(node.right)
            
            if node.val == 2:  # OR
                flips_true = min(left_true + right_true, left_true + right_false, left_false + right_true)
                flips_false = left_false + right_false
            elif node.val == 3:  # AND
                flips_true = left_true + right_true
                flips_false = min(left_false + right_false, left_false + right_true, left_true + right_false)
            elif node.val == 4:  # XOR
                flips_true = min(left_true + right_false, left_false + right_true)
                flips_false = min(left_true + right_true, left_false + right_false)
            else:
                raise ValueError("Invalid node value")
            
            return (flips_false, flips_true)
        
        flips_false, flips_true = dfs(root)
        return flips_true if result else flips_false
```Python 实现直接遵循 DFS 方法。 叶节点返回`(flips to false, flips to true)`内部节点根据布尔运算计算组合。 这`NOT`操作是通过交换孩子的值来处理的。 然后根节点的元组用于根据所需目标返回正确的结果。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func minimumFlips(root *TreeNode, result bool) int {
    var dfs func(node *TreeNode) (int, int)
    dfs = func(node *TreeNode) (int, int) {
        if node.Left == nil && node.Right == nil {
            if node.Val == 0 {
                return 0, 1
            }
            return 1, 0
        }

        if node.Val == 5 { // NOT
            var childFalse, childTrue int
            if node.Left != nil {
                childFalse, childTrue = dfs(node.Left)
            } else {
                childFalse, childTrue = dfs(node.Right)
            }
            return childTrue, childFalse
        }

        leftFalse, leftTrue := dfs(node.Left)
        rightFalse, rightTrue := dfs(node.Right)

        var flipsFalse, flipsTrue int
        switch node.Val {
        case 2: // OR
            flipsTrue = min(leftTrue+rightTrue, leftTrue+rightFalse, leftFalse+rightTrue)
            flipsFalse = leftFalse + rightFalse
        case 3: // AND
            flipsTrue = leftTrue + rightTrue
            flipsFalse = min(leftFalse+rightFalse, leftFalse+rightTrue, leftTrue+rightFalse)
        case 4: // XOR
            flipsTrue = min(leftTrue+rightFalse, leftFalse+rightTrue)
            flipsFalse = min(leftTrue+rightTrue, leftFalse+rightFalse)
        }
        return flipsFalse, flipsTrue
    }

    flipsFalse, flipsTrue := dfs(root)
    if result {
        return flipsTrue
    }
    return flipsFalse
}

func min(a ...int) int {
    m := a[0]
    for _, v := range a[1:] {
        if v < m {
            m = v
        }
    }
    return m
}
```Go 实现反映了 Python 逻辑。 Go 手柄`nil`而不是`None`。 这`min`函数被定义为采用可变数量的参数以便于计算。 

## 工作示例

 **示例 1：root = [3,5,4,2,null,1,1,1,0]，结果 = true**

 遍历DFS后序：

 1. 叶子节点`1,1,1,0`返回`(1,0)`,`(1,0)`,`(1,0)`,`(0,1)`分别。 
2.`NOT`节点翻转其子节点：`(childFalse, childTrue) -> (childTrue, childFalse)`。 
3.`XOR`节点组合子节点：计算 true/false 的最小翻转次数。 
4.`AND`节点组合子节点：计算最小翻转次数。 
5.`OR`节点（根）组合子节点。 
6. 在根处提取 Flips_true →`2`。 

**示例 2：root = [0]，结果 = false**

 1.单叶节点：值`0`→`(0,1)`。 
2.结果是`false`→ 返回`0`。
