[LeetCode 问题 2342](https://leetcode.com/problems/max-sum-of-a-pair-with-equal-sum-of-digits/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题需要找到数组中一对数字的最大和，使得两个数字的数字之和相等。 具体来说，您将获得一个 0 索引的数组`nums`包含正整数。 您可以选择两个不同的索引`i`和`j`这样`i != j`，以及数字之和`nums[i]`等于数字之和`nums[j]`。 目标是返回最大值`nums[i] + nums[j]`在所有有效对上。 如果不存在这样的对，该函数应返回 -1。 

输入`nums`可以非常大（最多 100,000 个元素），单个元素可以大到 10^9。 这意味着比较所有对的强力方法效率低下。 重要的边缘情况包括所有数字都具有唯一数字和的数组、大小为 1 的数组或具有相同数字和但只有一对有效数字的多个数字的数组。 该问题保证正整数，因此我们不需要处理零或负数。 

## 方法

 暴力方法会检查每一个可能的对`(i, j)`在数组中，计算它们的数字和，如果数字和匹配则更新最大和。 虽然正确，但这种方法的时间复杂度为 O(n^2)，这对于`n`最多 10^5。 

最佳解决方案的关键见解是，我们不需要跟踪具有相同位数和的所有数字 - 只需跟踪每个位数和的两个最大数字。 这是因为通过选择两个最大的数字来最大化来自同一数字和组的任何对的和。 通过使用哈希映射按数字和对数字进行分组，并只保留每组中最大的两个数字，我们可以将时间复杂度降低到 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 比较所有对，每次计算数字和 |
 | 最佳 | O(n) | O(n) | 哈希映射跟踪每个数字总和的最大两个数字 |

 ## 算法演练

 1. 初始化哈希图`digit_sum_map`将数字和映射到具有该数字和的两个最大数字的列表。 
2. 迭代每个数字`num`在`nums`。 
3. 计算数字之和`num`使用辅助函数。 
4. 如果数字和不在`digit_sum_map`，用包含的列表初始化它`num`。 
5. 如果数字和为`digit_sum_map`，更新列表以包括`num`同时只保留两个最大的数字。 
6.处理完所有数字后，初始化`max_sum`至-1。 
7. 迭代每个数字列表`digit_sum_map`。 
8. 如果列表至少有两个数字，则计算它们的总和并更新`max_sum`如果它更大。 
9. 返回`max_sum`。 

为什么它有效：不变的是对于每个数字和，我们只跟踪两个最大的数字。 这保证了当我们计算每个组的总和时，我们正在考虑该数字总和的最大可能总和。 因此，迭代所有组可确保我们找到全局最大总和。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        def digit_sum(n: int) -> int:
            s = 0
            while n > 0:
                s += n % 10
                n //= 10
            return s
        
        digit_sum_map = {}
        for num in nums:
            s = digit_sum(num)
            if s not in digit_sum_map:
                digit_sum_map[s] = [num]
            else:
                digit_sum_map[s].append(num)
                digit_sum_map[s] = sorted(digit_sum_map[s], reverse=True)[:2]
        
        max_sum = -1
        for numbers in digit_sum_map.values():
            if len(numbers) >= 2:
                max_sum = max(max_sum, numbers[0] + numbers[1])
        
        return max_sum
```实现首先定义一个辅助函数`digit_sum`计算给定数字的数字总和。 哈希映射存储每个数字和的最大两个数字。 然后，该算法迭代这些数字，更新哈希图，最后计算所有数字和组的最大和。 

## 解决方案```go
func maximumSum(nums []int) int {
    digitSum := func(n int) int {
        s := 0
        for n > 0 {
            s += n % 10
            n /= 10
        }
        return s
    }
    
    digitSumMap := make(map[int][]int)
    
    for _, num := range nums {
        s := digitSum(num)
        digitSumMap[s] = append(digitSumMap[s], num)
        if len(digitSumMap[s]) > 2 {
            if digitSumMap[s][0] < digitSumMap[s][1] {
                digitSumMap[s][0], digitSumMap[s][1] = digitSumMap[s][1], digitSumMap[s][0]
            }
            if len(digitSumMap[s]) > 2 {
                minIdx := 0
                if digitSumMap[s][1] < digitSumMap[s][0] {
                    minIdx = 1
                }
                digitSumMap[s] = digitSumMap[s][:2]
            }
        }
    }
    
    maxSum := -1
    for _, numbers := range digitSumMap {
        if len(numbers) >= 2 {
            if numbers[0]+numbers[1] > maxSum {
                maxSum = numbers[0] + numbers[1]
            }
        }
    }
    
    return maxSum
}
```Go 实现反映了 Python 方法。 辅助函数计算数字和。 哈希映射存储每个数字和中最大的两个数字，并注意对元素进行排序或交换以维护最大的两个数字。 算法的其余部分计算最大总和。 

## 工作示例

 **示例 1：nums = [18,43,36,13,7]**

 | 编号 | 数字总和 | 数字和图状态 |
 | --- | --- | --- |
 | 18 | 18 9 | {9：[18]}|
 | 43 | 43 7 | {9：[18]，7：[43]} |
 | 36 | 36 9 | {9: [36,18], 7: [43]} |
 | 13 | 4 | {9: [36,18], 7: [43], 4: [13]} |
 | 7 | 7 | {9: [36,18], 7: [43,7], 4: [13]} |

 每组最大总和：36+18=54、43+7=50、13（仅限一个）。 最大总和为 54。 

**示例 2：nums = [10,12,19,14]**

 所有数字和都是唯一的：1,3,10,5。 没有组有两个数字。 返回-1。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个数字被处理一次。 数字和计算为 O(log(num))，最大 num 10^9 的上限为 10，因此实际上为 O(n)。 |
 | 空间| O(n) | 哈希映射的每个数字和最多存储 2 个数字，总共最多 O(n)。 |

 该算法非常高效，因为它避免了检查所有对。 使用哈希映射可确保更新最大对的恒定时间访问。

 ## 边缘情况

 一种边缘情况是数组仅包含一个数字。 无法形成对，因此该函数正确返回 -1。 另一种情况是多个数字具有相同的数字和，但有些数字是重复的。 该实现处理重复项，因为它考虑两个最大的数字，而不管是否相等。 第三种边缘情况是所有数字都具有唯一的数字和，在这种情况下函数返回 -1。 这是正确处理的，因为该算法仅计算总和
