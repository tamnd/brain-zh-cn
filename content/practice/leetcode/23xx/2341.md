[LeetCode 问题 2341](https://leetcode.com/problems/maximum-number-of-pairs-in-array/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们获取一个整数数组，`nums`，并重复形成相等数量的对，直到无法形成更多对为止。 每个操作都会从数组中精确删除**两个相同的数字**，我们继续这样做，直到不再可能为止。 目标是返回两个整数的列表：形成的对的总数和未配对的整数的数量。 

换句话说，输入`nums`是一个标准的整数数组，其中每个整数的范围可以是`0`到`100`，数组长度范围为`1`到`100`。 输出是一个二元素数组`[pairs, leftover]`。 例如，如果数组包含多次出现的相同数字，则每一对都会贡献`pairs`计数，并且任何剩余的单个事件都会导致`leftover`。 

重要的边缘情况包括具有所有唯一元素的数组（不可能成对）、具有所有相同元素的数组（最大对数）以及长度数组`1`（不能形成任何对）。 该问题保证输入数组非空并且所有数字都是范围内的非负整数`[0, 100]`。 

## 方法

 **暴力方法**涉及迭代数组并重复搜索重复项以形成对。 对于每个元素，我们将在数组的其余部分中搜索匹配的数字，删除这两个元素，并增加对计数。 虽然这种方法最终会产生正确的结果，但其时间复杂度很差，`O(n^2)`，由于反复扫描和删除。 

**最佳方法**使用哈希映射（Python 中的字典，Go 中的映射）来利用数字的频率计数。 我们计算每个数字出现的次数。 任何值的对数只是其频率除以`2`，剩下的就是余数。 对所有数字求和即可得到总对和剩余元素。 这种方法将时间复杂度降低到`O(n)`以及空间复杂度`O(k)`， 在哪里`k`是数组中唯一数字的范围，最多是`101`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 重复扫描数组以查找对、删除它们并进行计数。 对于较大的阵列效率较低。 |
 | 最佳 | O(n) | O(k) | 使用频率图来计算出现次数并使用整数除法计算对。 高效且简单。 |

 ## 算法演练

 1. 初始化一个频数图（哈希图或字典）来统计每个数字出现的次数`nums`。 
2. 遍历数组`nums`。 对于每个数字，增加其在频率图中的计数。 
3.初始化两个变量，`pairs`和`leftover`， 到`0`。 
4. 对于频率图中的每个唯一数字，计算使用整数除法可以形成多少对`count // 2`并将其添加到`pairs`。 
5. 使用模运算计算每个数字的剩余部分`count % 2`并将其添加到`leftover`。 
6. 返回结果为`[pairs, leftover]`。 

**为什么有效：** 计算出现次数可以确保我们可以直接计算所有可能的对，而无需修改原始数组或执行重复搜索。 整数除法给出每个数字的最大配对数，模运算给出剩余的未配对数字。 此方法保证了正确性，因为每对都只计算一次。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def numberOfPairs(self, nums: List[int]) -> List[int]:
        freq = Counter(nums)
        pairs = 0
        leftover = 0
        
        for count in freq.values():
            pairs += count // 2
            leftover += count % 2
        
        return [pairs, leftover]
```Python 实现使用`collections.Counter`有效地计算每个数字的出现次数。 对于字典中的每个计数，`count // 2`添加对的数量，同时`count % 2`计算剩余的数字。 最后，我们将结果以列表的形式返回`[pairs, leftover]`。 

## 解决方案```go
func numberOfPairs(nums []int) []int {
    freq := make(map[int]int)
    for _, num := range nums {
        freq[num]++
    }
    
    pairs := 0
    leftover := 0
    for _, count := range freq {
        pairs += count / 2
        leftover += count % 2
    }
    
    return []int{pairs, leftover}
}
```在 Go 中，我们使用映射来计算频率。 整数除法`/`计算对，并取模`%`计算剩菜。 然后我们将结果作为两个整数的切片返回。 Go 没有内置的 Counter，所以标准的 Map 就足够了。

 ## 边缘情况

 一个重要的边缘情况是长度数组`1`。 由于不存在两个数，因此无法形成对。 执行正确计数`0`对和`1`剩下的。 

另一种极端情况是所有数字都相同。 该算法使用整数除法正确计算最大对数并报告零剩余数。 

第三种边缘情况是所有数字都是唯一的。 不存在对，因此算法正确报告零对并且`n`剩菜。 

最后，要考虑的边缘情况是数组包含频率不同的多个数字（包括奇数和偶数计数）。 该算法单独处理每个频率，确保剩余计算对于出现奇数的数字是准确的。
