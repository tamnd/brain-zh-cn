[LeetCode 问题 2302](https://leetcode.com/problems/count-subarrays-with-score-less-than-k/)

 **难度：** 🔴难
 **主题：** 数组、二分查找、滑动窗口、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定数组的连续子数组的数量`nums`其**分数**严格低于给定阈值`k`。 子数组的 **score** 定义为其总和与其长度的乘积。 形式上，对于子数组`nums[i:j]`与长度`len = j - i + 1`和总和`sum(nums[i:j])`，得分为`sum(nums[i:j]) * len`。 

输入由正整数数组组成`nums`和一个正整数`k`。 预期输出是一个整数，表示满足分数条件的子数组的总数。 

约束表明`nums`最多可以有`10^5`元素和单个元素以及`k`可以非常大（最多`10^5`对于元素，最多`10^15`为了`k`）。 这立即排除了任何显式生成所有子数组的强力解决方案，因为子数组的数量与`n`。 边缘情况包括所有值都很小的数组、值很大的数组、没有子数组满足条件的数组以及所有单元素子数组都满足条件的数组。 

## 方法

 暴力方法将迭代所有可能的子数组，计算每个子数组的总和，将其乘以其长度，并检查它是否小于`k`。 虽然这是简单且正确的，但如果不使用前缀和进行优化，则生成子数组的时间复杂度为 O(n^2)，计算其总和的时间复杂度为 O(n)，导致在简单情况下总时间复杂度为 O(n^3)。 使用前缀和将其减少到 O(n^2)，但这对于`n = 10^5`。 

更优化方法的关键观察是，如果我们固定起始索引，则得分函数相对于子数组长度是单调的。 此属性允许我们使用 **滑动窗口技术**，只要分数保持在以下位置即可扩展窗口的右端`k`，当分数超过时，移动左端以减少总和`k`。 由于所有数字都是正数，扩大窗口会增加总和和分数，缩小窗口会减少总和和分数。 这保证了每个有效子数组都被精确计数一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 迭代所有子数组，计算总和和分数 |
 | 滑动窗口/两个指针| O(n) | O(1) | O(1) | 当分数 < k 时展开右指针，根据需要缩小左指针 |

 ## 算法演练

 1.初始化两个指针`left = 0`和`right = 0`, 一个变量`window_sum = 0`跟踪当前窗口的总和，以及`count = 0`累积有效子数组的数量。 
2. 迭代`right`从`0`到`len(nums) - 1`。 添加`nums[right]`到`window_sum`。 
3.当前窗口的分数`(window_sum * (right - left + 1)) >= k`，通过减去从左侧缩小窗口`nums[left]`从`window_sum`并递增`left`。 
4. 调整窗口后，所有以`right`并从`left`到`right`是有效的。 添加`(right - left + 1)`到`count`。 
5. 继续此过程直到`right`到达数组末尾。 
6. 返回`count`作为满足条件的子数组的总数。 

工作原理：滑动窗口保证当前窗口的总和始终产生严格小于`k`。 由于我们添加了`(right - left + 1)`每个有效窗口的子数组结束于`right`，我们利用分数相对于窗口扩展的单调性，对所有子数组进行一次计数。 

## Python 解决方案```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        left = 0
        window_sum = 0
        count = 0
        for right in range(len(nums)):
            window_sum += nums[right]
            while window_sum * (right - left + 1) >= k:
                window_sum -= nums[left]
                left += 1
            count += (right - left + 1)
        return count
```在 Python 实现中，我们维护当前窗口的运行总和。 这`while`循环确保分数条件始终满足。 这`(right - left + 1)`term 正确计算所有以以下结尾的子数组`right`满足评分条件。 

## 解决方案```go
func countSubarrays(nums []int, k int64) int64 {
    var left int
    var windowSum int64
    var count int64
    for right := 0; right < len(nums); right++ {
        windowSum += int64(nums[right])
        for windowSum*int64(right-left+1) >= k {
            windowSum -= int64(nums[left])
            left++
        }
        count += int64(right - left + 1)
    }
    return count
}
```Go 解决方案镜像了 Python 实现，具有显式类型转换`int64`处理大值并防止整数溢出。 滑动窗口逻辑保持不变。
