[LeetCode 问题 2311](https://leetcode.com/problems/longest-binary-subsequence-less-than-or-equal-to-k/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划、贪心、记忆

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定二进制字符串的**最长子序列**的长度**`s`使得生成的二进制数小于或等于给定整数`k`。 子序列是任意选择的字符`s`按照原来的顺序，可能会跳过一些。 重要的是，允许使用前导零，空字符串计为 0。 

输入由一个字符串组成`s`长度最大为 1000，其中每个字符是`'0'`或者`'1'`，和一个整数`k`最大可达 10^9。 输出是一个整数，表示有效子序列的最大长度。 

需要注意的要点包括允许前导零、子序列不需要连续的事实以及形成的二进制数必须**不超过`k`**。 可能会导致幼稚实现失败的边缘情况包括全零的字符串、非常大的值`k`，或大多数为 1 的字符串，其中包含所有 1 会超过`k`。 

## 方法

 暴力方法是生成所有可能的子序列`s`，将每个转换为十进制整数，检查它是否小于或等于`k`，并跟踪最大长度。 虽然这是正确的，但速度非常慢，因为长度为`n`有`2^n`可能的子序列，以及`n`最多可达 1000，这在计算上是不可行的。 

最佳方法利用**贪婪策略**。 由于零不会增加十进制值，因此我们始终可以在子序列中包含所有零。 对于那些，我们需要小心，因为它们会增加小数点的值。 我们从**最低有效位到最高有效位**（即，在字符串中从右到左）进行迭代。 我们尝试将其一一相加，并记录十进制值。 如果加一会超过`k`，我们跳过它。 这使我们能够最大化长度，同时确保生成的二进制数保持有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 生成所有子序列，根据 k | 检查每个子序列
 | 最优（贪婪）| O(n) | O(1) | O(1) | 计算零并从 LSB 到 MSB 添加 1，直到达到 k |

 ## 算法演练

 1.初始化一个计数器`count`对于可以安全包含的零和一。 
2. 初始化变量`value`跟踪所选值的小数值。 
3.**向后**迭代`s`从最右边到最左边的字符。 
4.如果角色是`'0'`, 增量`count`因为零不会增加数字。 
5. 如果角色是`'1'`，计算潜在的新值（如果包含该值），并考虑其相对于子序列的 LSB 的位位置。 
6. 如果包括一项不符合`value`超过`k`, 增量`count`并更新`value`。 
7. 否则，请跳过这一项，因为包含它会超出`k`。 
8. 遍历字符串后，`count`表示最长有效子序列的长度。 

**为什么有效：** 贪心策略之所以有效，是因为零永远不会增加二进制值，所以我们总是可以包含它们。 从最不重要到最重要的顺序处理可确保我们优先考虑对十进制值贡献较小的字符，从而允许总共有更多字符而不超过`k`。 

## Python 解决方案```python
class Solution:
    def longestSubsequence(self, s: str, k: int) -> int:
        n = len(s)
        count = 0
        value = 0
        power = 1

        for i in range(n - 1, -1, -1):
            if s[i] == '0':
                count += 1
            else:
                if value + power <= k:
                    value += power
                    count += 1
                power <<= 1  # Multiply by 2 for next bit
        return count
```**说明：** 我们从最低有效位（最右边的字符）迭代到最高有效位。 对于零，我们增加`count`直接地。 对于 1，我们检查当前 2 的幂是否会超过`k`。 如果没有，我们将其包含在内并更新总值。 这`power`变量每次迭代加倍以表示下一个较高位。 这保证了结果子序列保持在限制内`k`。 

## 解决方案```go
func longestSubsequence(s string, k int) int {
    n := len(s)
    count := 0
    value := 0
    power := 1

    for i := n - 1; i >= 0; i-- {
        if s[i] == '0' {
            count++
        } else {
            if value + power <= k {
                value += power
                count++
            }
            if power <= (1<<30) { // prevent overflow
                power <<= 1
            }
        }
    }
    return count
}
```**说明：** Go 版本与 Python 类似。 一个区别是显式检查以防止移位时整数溢出`power`。 Go 不会自动处理大整数，所以我们确保`power`从最右边的位到最左边的迭代时保持在界限内。
