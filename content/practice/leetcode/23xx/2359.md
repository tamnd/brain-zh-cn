[LeetCode 问题 2359](https://leetcode.com/problems/find-closest-node-to-given-two-nodes/)

 **难度：** 🟡 中等
 **主题：** 深度优先搜索、图论

 ## 解决方案

 ## 问题理解

 该问题要求我们在**有向图中**中找到一个具有非常具体属性的节点：它必须可以从**两个给定的起始节点**到达（`node1`和`node2`）使得从任一起始节点到该节点的**最大距离**被**最小化**。 该图由数组描述`edges`在哪里`edges[i]`是节点`i`指向，或`-1`如果没有出边。 每个节点至多有一个出边，因此该图由**链和环**组成。 

输入是单个数组`edges`长度`n`和两个代表起始节点的整数。 输出是满足最小-最大距离标准的节点的索引。 如果多个节点并列，我们返回具有**最小索引**的节点。 如果不存在这样的节点（两个起始节点不能到达公共节点），我们返回`-1`。 

约束表明`n`可以达到`10^5`，所以 **O(n^2) 算法** 将无法扩展。 该图的结构 - **每个节点最多一个传出边 ** - 表明来自每个节点的简单线性遍历可能是有效的。 

重要的边缘情况包括起始节点指向的情况`-1`立即，或者当循环存在时。 我们还需要处理只能从两个起点之一到达的节点。 

## 方法

 ### 蛮力

 一种简单的方法是计算距离`node1`到每个其他节点并从`node2`使用 BFS 或 DFS 到每个其他节点。 对于从两者均可到达的每个节点，我们将计算最大距离并选择具有最小最大值的节点。 虽然正确，但效率很低，因为在长链的最坏情况下，从每个起始节点重复遍历路径可能会导致 **O(n^2)** 时间复杂度。 

### 最佳方法

 最佳观察是**每个节点最多有一个出边**，因此可以通过遍历链一次在线性时间内**计算从一个节点到所有可达节点的距离。 我们可以计算两个数组，`dist1`和`dist2`， 在哪里`dist1[i]`是距离`node1`到`i`， 和`dist2[i]`是距离`node2`到`i`。 如果从起始节点无法到达某个节点，我们将距离标记为`-1`或无穷大。 然后，我们迭代所有节点，并计算从两个数组均可到达的节点到两个数组的最大距离。 答案是具有这些最大值中最小值的节点。 

这可以有效地工作，因为每个起始节点最多访问每个节点一次，从而导致 **O(n)** 时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 重复计算到所有节点的距离 |
 | 最佳 | O(n) | O(n) | 使用从每个节点开始的线性遍历并存储距离 |

 ## 算法演练

 1.初始化两个距离数组`dist1`和`dist2`长度`n`, 充满`-1`指示尚未到达的节点。 
2. 定义辅助函数`walk(start)`遍历图表从`start`。 对于每个访问过的节点，将距离记录在数组中，并在到达已访问过的节点时停止或`-1`。 
3. 通话`walk(node1)`并将距离存储在`dist1`。 
4. 打电话`walk(node2)`并将距离存储在`dist2`。 
5. 初始化变量`minMaxDist`作为无穷大和`answer`作为`-1`。 
6. 迭代所有节点`0`到`n-1`。 如果一个节点可以从两个 (`dist1[i] != -1`和`dist2[i] != -1`), 计算`max(dist1[i], dist2[i])`。 如果该值小于`minMaxDist`， 更新`minMaxDist`并设置`answer`到这个节点。 如果相等，则选择较小的索引。 
7. 返回`answer`。 

**为什么有效：** 该算法确保每次开始时所有可到达的节点都被考虑一次。 最小-最大比较可确保所选节点最小化距两个起点的最大距离。 字典顺序打破平局是通过按索引顺序迭代来自动处理的。 

## Python 解决方案```python
from typing import List

class Solution:
    def closestMeetingNode(self, edges: List[int], node1: int, node2: int) -> int:
        n = len(edges)
        
        def walk(start):
            dist = [-1] * n
            current = start
            steps = 0
            while current != -1 and dist[current] == -1:
                dist[current] = steps
                steps += 1
                current = edges[current]
            return dist
        
        dist1 = walk(node1)
        dist2 = walk(node2)
        
        minMaxDist = float('inf')
        answer = -1
        
        for i in range(n):
            if dist1[i] != -1 and dist2[i] != -1:
                maxDist = max(dist1[i], dist2[i])
                if maxDist < minMaxDist:
                    minMaxDist = maxDist
                    answer = i
        return answer
```**实施演练：**我们定义`walk`从起始节点遍历，标记距离。 然后我们从两个地方步行`node1`和`node2`。 迭代所有节点允许我们选择一个能够最小化与两个起始节点的最大距离的节点，并且按顺序迭代可确保最小的索引平局打破。 

## 解决方案```go
func closestMeetingNode(edges []int, node1 int, node2 int) int {
    n := len(edges)
    
    walk := func(start int) []int {
        dist := make([]int, n)
        for i := 0; i < n; i++ {
            dist[i] = -1
        }
        current := start
        steps := 0
        for current != -1 && dist[current] == -1 {
            dist[current] = steps
            steps++
            current = edges[current]
        }
        return dist
    }
    
    dist1 := walk(node1)
    dist2 := walk(node2)
    
    minMaxDist := 1 << 60
    answer := -1
    
    for i := 0; i < n; i++ {
        if dist1[i] != -1 && dist2[i] != -1 {
            maxDist := dist1[i]
            if dist2[i] > maxDist {
                maxDist = dist2[i]
            }
            if maxDist < minMaxDist {
                minMaxDist = maxDist
                answer = i
            }
        }
    }
    
    return answer
}
```**Go特定注释：** 我们初始化`dist`和`-1`使用循环，因为 Go 不允许切片具有除零之外的默认值。 使用大常量可以避免整数溢出`1 << 60`。 

## 工作示例

 **示例1：**`edges = [2,2,3,-1], node1 = 0, node2 = 1`步行从`node1`：```
0 -> 2 -> 3 -> -1
dist1 = [0, -1, 1, 2]
```步行从`node2`：```
1 -> 2 -> 3 -> -1
dist2 = [-1, 0, 1, 2]
```迭代节点：

 - 节点 0：无法从节点 2 访问
 - 节点 1：无法从节点 1 访问
 - 节点 2：可达，max(1,1) = 1 → 答案 = 2
 - 节点 3：可达，max(2,2) = 2 → 大于当前 minMaxDist → 忽略

 答案=2。 

**示例2：**`edges = [1,2,-1], node1 = 0, node2 = 2`步行从`node1`：```
0 -> 1 -> 2 -> -1
dist1 = [0,1,2]
```步行从`node2`：```
2 -> -1
dist2 = [-1,-1,0]
```迭代节点：

 - 节点 2：两者均可到达，max(2,0) = 2 → 答案 = 2

 答案=2。
