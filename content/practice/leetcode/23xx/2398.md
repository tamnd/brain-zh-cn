[LeetCode 问题 2398](https://leetcode.com/problems/maximum-number-of-robots-within-budget/)

 **难度：** 🔴难
 **主题：** 数组、二分查找、队列、滑动窗口、堆（优先级队列）、前缀和、单调队列

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定在不超过给定预算的情况下可以运行的**连续机器人**的最大数量。 我们有两个长度的数组`n`:`chargeTimes`和`runningCosts`。 对于任意连续的子集`k`机器人，总成本计算如下：```
total_cost = max(chargeTimes of the k robots) + k * sum(runningCosts of the k robots)
```目标是找到最大的`k`使得总成本不超过`budget`。 

换句话说，我们需要在机器人上滑动一个窗口，计算每个窗口的成本，并跟踪适合预算的最大窗口长度。 限制因素很大：`n`最多可达 50,000 个，并且`budget`可以大到`10^15`。 因此，检查每个可能的连续子集的简单解决方案将太慢。 该问题保证了两者`chargeTimes`和`runningCosts`是正整数，这简化了某些计算。 

重要的边缘情况包括没有机器人可以在预算内运行、只能运行单个机器人或所有机器人都可以在不超出预算的情况下运行的情况。 

## 方法

 **暴力方法**将涉及检查机器人的所有可能的连续窗口。 对于每个窗口，计算`max(chargeTimes)`和`sum(runningCosts)`，然后计算总成本。 这种方法是正确的，因为它直接评估总成本公式。 然而，它的效率极低，因为窗口的数量呈二次方增长（`O(n^2)`）和计算`max`和`sum`每个窗口都需要额外的时间。 和`n`达到 50,000 时，这种方法在计算上是不可行的。 

**最佳方法**使用滑动窗口与单调队列（deque）相结合来有效地跟踪最大充电时间。 在向前移动窗口右端的同时，我们保持一个运行总和`runningCosts`并更新双端队列以反映当前最大值`chargeTimes`在窗口中。 如果总成本超过预算，我们将窗口的左端向前移动，相应地调整运行总和和双端队列。 这种方法保证了相对于输入大小的线性时间性能，因为每个元素最多在双端队列中添加和删除一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) 或 O(n) | 检查所有连续的窗口； 对于大 n | 效率低下
 | 最佳| O(n) | O(n) | 具有单调双端队列的滑动窗口，可实现最大费用； 高效追踪运行金额 |

 ## 算法演练

 1.初始化两个指针，`left`和`right`，定义滑动窗口。 初始化运行总和`window_sum`为了`runningCosts`和一个双端队列`max_charge_deque`维持指数`chargeTimes`按降序排列。 
2. 迭代`right`在数组上从`0`到`n-1`。 对于每个`right`：

- 添加`runningCosts[right]`到`window_sum`。 
- 维护双端队列，使得`chargeTimes[max_charge_deque[0]]`是当前窗口中的最大值。 从双端队列的后面删除索引，如果它们`chargeTimes`小于`chargeTimes[right]`，然后附加`right`。 
3. 总成本`max(chargeTimes in window) + window_length * window_sum`超过`budget`， 移动`left`转发：

 - 减法`runningCosts[left]`从`window_sum`。 
- 消除`left`如果双端队列位于前面，则从双端队列中获取。 
- 增量`left`。 
4. 将最大窗口长度更新为`right - left + 1`只要总成本在预算之内。 
5. 继续直到`right`到达数组末尾。 返回最大窗口长度。 

**为什么有效**：双端队列确保`max(chargeTimes)`可以在任何窗口的 O(1) 时间内检索。 滑动窗口保证所有连续的段都被检查一次。 当窗口扩展和收缩时，该算法保持正确的运行总和和最大值，从而产生可以在预算内运行的正确的最大机器人数量。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def maximumRobots(self, chargeTimes: List[int], runningCosts: List[int], budget: int) -> int:
        n = len(chargeTimes)
        max_charge_deque = deque()
        left = 0
        window_sum = 0
        max_len = 0

        for right in range(n):
            window_sum += runningCosts[right]
            
            while max_charge_deque and chargeTimes[max_charge_deque[-1]] <= chargeTimes[right]:
                max_charge_deque.pop()
            max_charge_deque.append(right)
            
            while max_charge_deque and chargeTimes[max_charge_deque[0]] + (right - left + 1) * window_sum > budget:
                if max_charge_deque[0] == left:
                    max_charge_deque.popleft()
                window_sum -= runningCosts[left]
                left += 1
            
            max_len = max(max_len, right - left + 1)
        
        return max_len
```Python 实现小心地维护了一个运行总和`runningCosts`和一个跟踪索引的双端队列`chargeTimes`按降序排列。 这允许检索最大`chargeTimes`在 O(1) 时间内。 每当超出预算时，滑动窗口就会收缩，确保所有窗口都有效，并相应地更新最大长度。 

## 解决方案```go
package main

func maximumRobots(chargeTimes []int, runningCosts []int, budget int64) int {
    n := len(chargeTimes)
    maxLen := 0
    left := 0
    windowSum := int64(0)
    deque := []int{}

    for right := 0; right < n; right++ {
        windowSum += int64(runningCosts[right])

        for len(deque) > 0 && chargeTimes[deque[len(deque)-1]] <= chargeTimes[right] {
            deque = deque[:len(deque)-1]
        }
        deque = append(deque, right)

        for len(deque) > 0 && int64(chargeTimes[deque[0]])+int64(right-left+1)*windowSum > budget {
            if deque[0] == left {
                deque = deque[1:]
            }
            windowSum -= int64(runningCosts[left])
            left++
        }

        if currentLen := right - left + 1; currentLen > maxLen {
            maxLen = currentLen
        }
    }

    return maxLen
}
```在 Go 中，要小心使用`int64`为了`windowSum`防止整数溢出，因为`budget`可以大到`10^15`。 切片操作模仿 Python 中的双端队列操作。 滑动窗口和维护最大元素的逻辑是相同的。 

## 工作示例

 **示例1**：```
chargeTimes = [3,6,1,3,4]
runningCosts = [2,1,3,4,5]
budget = 25
```步骤：

 | 对| 窗口总和 | 双端队列（最大索引）| 总成本| 左| 最大长度 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | 2 | [0]| 3+1*2=5 | 0 | 1 |
 | 1 | 3 | [1] | 6+2*3=12 | 0 | 2 |
 | 2 | 6 | [1,2]| 6+3*6=24 | 0 | 3 |
 | 3 | 10 | 10 [1,3]| 6+4*10=46 > 25 | 6+4*10=46 > 25 | 1->2->3 | 3 |
 | 4 | 15 | 15 [4] | 4+2*15=34 > 25 | 4+2*15=34 > 25 | 左=4 | 3 |

 最大有效窗口长度为`3`。 

**示例2**：```
chargeTimes = [11,12,19]
runningCosts = [10,8,7]
budget = 19
```每个机器人单独超出预算：最大长度为`0`。

 | 测量| 复杂性 | 说明|
