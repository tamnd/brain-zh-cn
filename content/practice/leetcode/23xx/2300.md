[LeetCode 第 2300 题](https://leetcode.com/problems/successful-pairs-of-spells-and-potions/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、二分查找、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定对于每个咒语，它可以与多少药水配对以获得至少`success`。 数组`spells`和`potions`分别代表法术和药剂的强度。 输出是一个整数数组，其中每个元素对应于相应咒语的成功药水配对的数量。 

本质上，对于每个`spell[i]`，我们需要计算的数量`potions[j]`这样：```
spells[i] * potions[j] >= success
```约束表明两者`spells`和`potions`最多可以有 100,000 个元素，强度可以高达 100,000，而`success`可以达到10^10。 这意味着在最坏的情况下，检查所有对的简单解决方案最多需要 10^10 次操作，这太慢了。 

关键边缘情况包括非常小或非常大的数字，没有药水满足咒语的情况，或者所有药水都满足该咒语的情况。 输入保证正整数，因此我们不需要处理零或负值。 

## 方法

 ### 蛮力

 最简单的方法是迭代每个咒语并将其与每个药水相乘，检查乘积是否至少`success`。 这保证了正确性，因为它显式地评估所有可能对的条件。 然而，时间复杂度为 O(n * m)，在最大约束下最多可达 10^10 次操作，这使得它不切实际。 

### 最佳方法

 关键的见解是对于固定咒语`s`，条件`s * p >= success`可以重写为`p >= ceil(success / s)`。 这意味着我们只需要计算大于或等于的药水数量`success / s`。 如果我们排序`potions`首先，我们可以使用二分查找来有效地找到这个计数。 

该算法进行如下：

 1. 排序`potions`大批。 
2. 对于每个咒语`s`，计算所需的最低药水强度`min_potion = ceil(success / s)`。 
3.使用二分查找找到第一个满足或超过的部分`min_potion`。 
4. 该法术成功配对的数量是药水总数减去找到的索引。 

这显着降低了时间复杂度，因为排序为 O(m log m)，每个拼写都需要 O(log m) 进行二分搜索，从而导致总体复杂度为 O(m log m + n log m)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 显式检查所有对 |
 | 最佳| O(m log m + n log m) | O(m log m + n log m) | O(1) | O(1) | 对药水进行排序并对每个咒语使用二分搜索 |

 ## 算法演练

 1. 排序`potions`数组按升序排列。 排序使我们能够使用二分搜索有效地找到阈值部分。 
2. 初始化一个空的结果数组`pairs`存储每个咒语的计数。 
3. 迭代每个`spell`在`spells`：

 a. 计算`min_potion = ceil(success / spell)`。 这是药剂要组成成功配对所必须具备的最低强度。 

b. 对已排序的结果执行二分查找`potions`数组查找第一个药水的索引`>= min_potion`。 

c. 计算成功配对的数量为`len(potions) - index_found`。 

d. 将此计数附加到`pairs`。 
4. 返回`pairs`大批。 

**为什么有效**：排序确保二分搜索索引之外的所有部分都满足成功条件。 二分查找保证我们有效地找到最小的这样的部分。 因此，算法会正确计算每个咒语的所有成功对。 

## Python 解决方案```python
from typing import List
import bisect
import math

class Solution:
    def successfulPairs(self, spells: List[int], potions: List[int], success: int) -> List[int]:
        potions.sort()
        n = len(potions)
        pairs = []
        
        for spell in spells:
            min_potion = (success + spell - 1) // spell  # ceil division
            idx = bisect.bisect_left(potions, min_potion)
            pairs.append(n - idx)
        
        return pairs
```该实现首先对`potions`数组以启用二分搜索。 对于每个咒语，我们使用上限除法计算精确处理整数数学所需的最小药水强度。 这`bisect_left`函数找到第一个满足此要求的药水，并从药水总数中减去其索引即可得出成功对的计数。 

## 解决方案```go
import (
    "sort"
)

func successfulPairs(spells []int, potions []int, success int64) []int {
    sort.Slice(potions, func(i, j int) bool { return potions[i] < potions[j] })
    n := len(potions)
    pairs := make([]int, len(spells))
    
    for i, spell := range spells {
        minPotion := (success + int64(spell) - 1) / int64(spell)
        left, right := 0, n
        for left < right {
            mid := (left + right) / 2
            if int64(potions[mid]) >= minPotion {
                right = mid
            } else {
                left = mid + 1
            }
        }
        pairs[i] = n - left
    }
    
    return pairs
}
```在 Go 中，我们排序`potions`使用`sort.Slice`。 整数除法需要转换为`int64`以防止溢出。 手动执行二分查找来找到第一个符合要求的部分。 结果数组存储每个咒语成功配对的数量。
