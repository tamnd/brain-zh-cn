[LeetCode 问题 2331](https://leetcode.com/problems/evaluate-boolean-binary-tree/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们评估一个**完整二叉树**，其中每个节点代表一个布尔值或一个布尔运算。 叶子节点有值`0`（错误）或`1`（真的）。 非叶子节点有值`2`（或）或`3`（和）。 目标是通过根据树的规则递归地评估所有子节点来计算根处的布尔值。 

输入是二叉树的根，其中每个节点都是一个实例`TreeNode`。 输出是单个布尔值，`True`或者`False`，代表整棵树的评价。 完整二叉树约束确保每个节点有 0 或 2 个子节点，因此我们不需要处理只有 1 个子节点的节点。 节点数量最多1000个，允许递归遍历，无需担心典型环境下的堆栈溢出。 

重要的边缘情况包括具有单个叶节点的树、所有节点评估为 True 或所有节点评估为 False。 树保证遵循约束，因此我们不需要处理无效的节点值或非二元结构。 

## 方法

 蛮力方法涉及完全按照问题陈述中的描述递归地评估树。 从根开始，我们检查该节点是否是叶子。 如果是，我们返回它的布尔值。 否则，我们递归地评估左子节点和右子节点，然后在当前节点应用运算（OR 或 AND）。 这种方法可以正确工作，因为它直接遵循树的布尔评估规则。 对于给定的约束，这已经很有效了，因为每个节点都被访问一次。 

关键的见解是，由于树的结构，递归方法是最佳的。 每个节点仅被访问一次，并且除了递归堆栈之外不需要其他数据结构。 不需要记忆或动态编程，因为树中没有重复的子问题评估。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(h) | 递归地评估每个节点； h 是树的高度 |
 | 最佳| O(n) | O(h) | 与暴力破解相同； 完全二叉树的最优|

 ## 算法演练

 1. 从根节点开始。 通过验证左子节点和右子节点是否都是叶子节点来检查节点是否是叶子节点`None`。 
2.如果该节点是叶子，则返回`True`如果`node.val == 1`和`False`如果`node.val == 0`。 这处理基本情况。 
3. 如果该节点不是叶子，则通过调用函数来递归计算左子节点`node.left`。 
4. 同样，通过调用函数来递归地计算右子节点`node.right`。 
5. 计算完两个子节点后，检查当前节点的值。 如果是的话`2`，对两个子值执行布尔或。 如果是的话`3`，对两个子值执行布尔 AND。 
6. 将操作结果返回给父调用。 
7. 重复步骤 1-6，直到计算完根节点，此时函数返回最终的布尔值。 

为什么有效：该算法有效是因为它尊重树的递归结构。 每个节点的值都是根据其子节点正确计算的，并且叶节点作为基本情况。 递归计算保证每个子树在父节点应用其操作之前被计算，从而确保正确性。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def evaluateTree(self, root: Optional[TreeNode]) -> bool:
        if root.left is None and root.right is None:
            return root.val == 1
        
        left_val = self.evaluateTree(root.left)
        right_val = self.evaluateTree(root.right)
        
        if root.val == 2:
            return left_val or right_val
        elif root.val == 3:
            return left_val and right_val
```实现完全遵循算法。 基本情况检查节点是否是叶子并返回相应的布尔值。 对于非叶节点，该函数递归地计算左子树和右子树，然后根据节点值应用适当的布尔运算。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func evaluateTree(root *TreeNode) bool {
    if root.Left == nil && root.Right == nil {
        return root.Val == 1
    }
    
    leftVal := evaluateTree(root.Left)
    rightVal := evaluateTree(root.Right)
    
    if root.Val == 2 {
        return leftVal || rightVal
    }
    return leftVal && rightVal
}
```在 Go 中，我们遵循相同的逻辑。 我们检查节点是否是叶子并返回布尔值。 对于非叶节点，我们递归地评估两个子节点并应用 OR 或 AND 运算。 Go 的严格类型需要显式的布尔比较（`root.Val == 1`）。 

## 工作示例

 ### 示例 1

 输入树：`[2,1,3,null,null,0,1]`逐步评估：

 1. 根是`2`（或者）。 评估左右孩子。 
2. 左孩子是`1`（叶）→ 评估为`True`。 
3. 右孩子是`3`（和）。 评估它的孩子。 
4. 右孩子是`0`（叶）→ 评估为`False`。 
5. 右边的孩子是`1`（叶）→ 评估为`True`。 
6. 右节点`3`→ 与`False`和`True`=`False`。 
7. 根`2`→ 或`True`和`False`=`True`。 

输出：`True`。 

### 示例 2

 输入树：`[0]`1. 根是`0`（叶）→ 评估为`False`。 

输出：`False`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点都被访问一次。 |
 | 空间| O(h) | 递归栈使用的空间与树的高度成正比； 最坏情况下 h ≤ n。 |

 时间复杂度是最优的，因为我们无法避免访问树中的所有节点。 空间复杂度由递归栈决定，与树的高度成正比。

 ## 边缘情况

 一个重要的边缘情况是具有单个节点的树。 该实现通过检查节点是否是叶子来处理这个问题。 另一个边缘情况是当所有叶节点评估为`True`或者`False`，它测试布尔运算是否通过 AND 和 OR 节点正确传播。 第三种边缘情况是树严重不平衡，例如退化树（链表形状）； 递归解决方案仍然可以正确处理此问题，但递归深度将等于节点数，这是在限制范围内的。 

总的来说，递归评估保证了正确性并自然地处理所有这些边缘情况。
