[LeetCode 问题 2332](https://leetcode.com/problems/the-latest-time-to-catch-a-bus/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、二分查找、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们根据公交车的出发时间、其他乘客的到达时间以及每辆公交车的最大载客量来确定**我们可以到达公交车站搭乘公交车的最晚时间**。 公共汽车和乘客都表示为具有唯一值的整数数组，乘客按照到达时间的顺序登上公共汽车。 

本质上，我们试图找到最大的整数`t`这样如果我们准时到达`t`，我们仍然可以上车，而不必与其他乘客同时到达。 我们不能“超越”排队的乘客，也不能在公交车发车后到达。 每辆巴士只能容纳固定数量的乘客，因此如果巴士在我们到达之前就达到了载客量，我们必须考虑乘坐更早的巴士或更早的时间。 

这些约束表明潜在的大输入大小（`n, m, capacity <= 10^5`）和大值（`buses[i], passengers[i] <= 10^9`）。 这排除了任何以简单的方式迭代**所有可能的时间**的解决方案。 巴士和乘客时间的独特性简化了考虑到达时间时的冲突，并且避免与其他乘客同时到达的要求迫使仔细检查。 

边缘情况包括最早的巴士在我们到达之前离开、巴士完全满员时以及乘客到达时间存在间隙时可以让我们选择准确的时段登机的情况。 

## 方法

 **暴力方法**将模拟从`1`直到最晚的巴士发车时间，每次都检查是否可以上车。 对于每个候选时间，我们都会检查所有排队的乘客，看看巴士是否满员。 虽然这在概念上可行，但考虑到限制，它太慢了：时间点的数量可能达到`10^9`，乘客人数最多为`10^5`。 这使得暴力方法不可行。 

**最佳方法**依赖于对公共汽车和乘客进行分类。 通过排序，我们可以按时间顺序处理公交车，并使用最早到达时间的乘客来装满每辆公交车。 巴士载满乘客后，我们会检查最后一个可用座位，并确定我们可以到达但尚未被其他乘客占用的最晚时间。 这避免了检查所有可能的时间，而是专注于乘客到达时间和巴士可用性的差距，从而降低了复杂性`O(n log n + m log m)`由于排序，之后是线性遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(max(总线) * m) | O(米) | 每次增量检查总线容量，对于大输入来说太慢 |
 | 最佳| O(n log n + m log m) | O(n log n + m log m) | O(1) 或 O(m) | 对公交车和乘客进行排序，用两个指针模拟登机，高效|

 ## 算法演练

 1. **按升序对公共汽车和乘客进行排序**。 这确保我们可以按时间顺序处理公交车并按到达时间正确分配乘客。 
2. 在乘客列表的开头初始化**乘客指针**。 该指针将跟踪哪些乘客已经登上公交车。 
3. 遍历已排序的每条总线`buses`数组：

 - 初始化一个计数器，记录**该公交车上的乘客数量**。 
- 当乘客指针指向到达时间小于或等于公交车出发时间且公交车未满员的乘客时，向前移动指针并使计数器递增。 这模拟了乘客登上公交车。 
4. 乘车后（或到达发车时间）：

 - 如果巴士**未满员**，那么搭乘这辆巴士的最晚时间是**其出发时间**，或没有其他乘客占用的任何较早时间。 
- 如果巴士**已满**，最晚时间为**最后一位乘客上车前一分钟**。 
5. 为了确保我们**不会与其他乘客同时到达**，我们会递减候选时间，直到它不等于任何乘客的到达时间。 
6. 跟踪所有总线的**最大有效时间**并将其作为答案返回。 

**为什么有效**：通过排序和使用两指针技术，我们保持乘客登机的正确顺序。 检查满载巴士上的最后一位乘客可确保我们不会超出容量，并且向后迭代乘客时间可确保我们不会与其他乘客发生碰撞。 

## Python 解决方案```python
from typing import List

class Solution:
    def latestTimeCatchTheBus(self, buses: List[int], passengers: List[int], capacity: int) -> int:
        buses.sort()
        passengers.sort()
        passenger_index = 0
        passenger_set = set(passengers)
        latest_time = 0

        for bus in buses:
            seats_taken = 0
            while passenger_index < len(passengers) and passengers[passenger_index] <= bus and seats_taken < capacity:
                last_boarded = passengers[passenger_index]
                passenger_index += 1
                seats_taken += 1

            if seats_taken < capacity:
                candidate_time = bus
            else:
                candidate_time = last_boarded - 1

            while candidate_time in passenger_set:
                candidate_time -= 1

            latest_time = max(latest_time, candidate_time)

        return latest_time
```该代码对公共汽车和乘客进行排序，然后使用指针将乘客分配给公共汽车。 每趟公交车结束后，它都会计算候选最晚到达时间，如果与现有乘客时间冲突，则将其递减。 返回所有总线上的最大候选者。 

## 解决方案```go
import "sort"

func latestTimeCatchTheBus(buses []int, passengers []int, capacity int) int {
    sort.Ints(buses)
    sort.Ints(passengers)
    passengerSet := make(map[int]bool)
    for _, p := range passengers {
        passengerSet[p] = true
    }

    passengerIndex := 0
    latestTime := 0

    for _, bus := range buses {
        seatsTaken := 0
        var lastBoarded int
        for passengerIndex < len(passengers) && passengers[passengerIndex] <= bus && seatsTaken < capacity {
            lastBoarded = passengers[passengerIndex]
            passengerIndex++
            seatsTaken++
        }

        candidateTime := 0
        if seatsTaken < capacity {
            candidateTime = bus
        } else {
            candidateTime = lastBoarded - 1
        }

        for passengerSet[candidateTime] {
            candidateTime--
        }

        if candidateTime > latestTime {
            latestTime = candidateTime
        }
    }

    return latestTime
}
```在 Go 中，我们使用`map[int]bool`用于快速乘客查找而不是集合。 排序和迭代逻辑反映了 Python 实现。 减少候选时间可以避免与乘客到达发生冲突。
