[LeetCode 问题 2353](https://leetcode.com/problems/design-a-food- rating-system/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、设计、堆（优先级队列）、有序集

 ## 解决方案

 ## 问题理解

 问题是要求我们实现一个食品评级系统，该系统支持动态更新单个食品的评级，并允许查询给定菜肴的最高评级食品。 每种食物都有一个独特的名称，完全属于一种菜系，并且具有相关的评级。 系统必须有效地处理两个操作：`changeRating`，更新指定食物的评级，以及`highestRated`，它返回特定菜肴中评分最高的食物，并按食物名称的字典顺序打破联系。 

输入由三个并行数组组成：`foods`,`cuisines`， 和`ratings`，每个长度`n`。`foods[i]`给出第 i 个食物的名称，`cuisines[i]`美食类型，以及`ratings[i]`初始评级。 约束条件表明`n`最多可以有 20,000 个，并且最多可以有 20,000 个组合操作，因此为每个查询扫描所有食物的简单方法会太慢。 食物名称的唯一性确保我们可以通过哈希图直接识别食物，并且有关菜肴存在的保证简化了查询中的错误处理。 

重要的边缘情况包括：多种食物具有相同的最高评级（需要字典顺序比较）、更新评级以成为美食的新最高评级以及同一食物多次快速更改评级。 

## 方法

 ### 蛮力方法

 最简单的解决方案是将食物及其评级存储在哈希图中，并且对于每个`highestRated`查询，迭代指定菜系的所有食物以找到最大评分。 更新食物的评级很简单：只需替换哈希图中的值即可。 这种做法是正确的，但是查询操作需要扫描潜在的所有`n`食物，每个食物的时间复杂度为 O(n)`highestRated`调用，这对于问题的上限来说太慢了。 

### 最佳方法

 最佳方法依赖于为每种美食维护一个最大堆（优先级队列），存储负面评级和食物名称的元组。 通过使用堆，我们可以有效地查询评分最高的食物，检索时间复杂度为 O(1)，更新时间复杂度 O(log n)。 由于Python堆不支持直接更新，因此我们通过将新评级推入堆并同时保留旧评级来处理评级更改； 当提取最大值时，我们使用记录每种食物当前评级的哈希图来跳过过时的条目。 这确保了两者`changeRating`和`highestRated`是高效的。 字典顺序的平局决胜是由存储食物名称和负面评级的堆来处理的，这自然会正确地对它们进行排序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(n) | O(n) | 简单的哈希图，每次扫描整个菜品列表 |
 | 最佳 | 每次更新 O(log n)，每次查询摊销 O(log n) | O(n) | 使用当前评级图进行延迟删除的每种菜肴的堆 |

 ## 算法演练

 1. 初始化哈希图`foodToCuisine`将每种食物名称映射到其美食类型。 这样可以在更新评级时快速查找美食。 
2. 初始化哈希图`foodToRating`将每个食物名称映射到其当前评级。 这存储了每种食物的权威评级。 
3. 初始化哈希图`cuisineHeap`将每种美食映射到最大元组堆`(-rating, foodName)`。 使用负评级以便堆作为最大堆运行。 
4. 对于每一种初始食物`foods`,插入一个元组`(-ratings[i], foods[i])`放入相应的美食堆并填充评级图。 
5. 至`changeRating(food, newRating)`，更新食物的评级`foodToRating`并推`(-newRating, food)`放入相应的菜系堆中。 我们不会立即删除旧的评级； 查询时它们会被懒惰地忽略。 
6. 至`highestRated(cuisine)`，查看堆的顶部。 如果评级在`foodToRating`与存储的堆评级的负值匹配，返回食物。 否则，弹出过时的条目，直到堆顶部与当前评级匹配。 

**为什么有效：** 堆保证具有最高评级的元组（以及按字典顺序最小的关系名称）始终位于顶部附近。 延迟删除确保我们不会浪费时间删除过时的条目，而权威的`foodToRating`地图保证正确性。 

## Python 解决方案```python
from typing import List
import heapq

class FoodRatings:

    def __init__(self, foods: List[str], cuisines: List[str], ratings: List[int]):
        self.foodToCuisine = {}
        self.foodToRating = {}
        self.cuisineHeap = {}

        for food, cuisine, rating in zip(foods, cuisines, ratings):
            self.foodToCuisine[food] = cuisine
            self.foodToRating[food] = rating
            if cuisine not in self.cuisineHeap:
                self.cuisineHeap[cuisine] = []
            heapq.heappush(self.cuisineHeap[cuisine], (-rating, food))

    def changeRating(self, food: str, newRating: int) -> None:
        cuisine = self.foodToCuisine[food]
        self.foodToRating[food] = newRating
        heapq.heappush(self.cuisineHeap[cuisine], (-newRating, food))

    def highestRated(self, cuisine: str) -> str:
        heap = self.cuisineHeap[cuisine]
        while True:
            rating, food = heap[0]
            if -rating == self.foodToRating[food]:
                return food
            heapq.heappop(heap)
```此实现为每个美食维护一个单独的堆，以便快速检索评分最高的食物。 更改评级是通过添加新条目来完成的，而过时的条目在查询时会被延迟删除。 

## 解决方案```go
package main

import (
    "container/heap"
)

type FoodEntry struct {
    rating int
    name   string
}

type FoodHeap []FoodEntry

func (h FoodHeap) Len() int { return len(h) }
func (h FoodHeap) Less(i, j int) bool {
    if h[i].rating == h[j].rating {
        return h[i].name < h[j].name
    }
    return h[i].rating > h[j].rating
}
func (h FoodHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }

func (h *FoodHeap) Push(x any) { *h = append(*h, x.(FoodEntry)) }
func (h *FoodHeap) Pop() any {
    old := *h
    n := len(old)
    item := old[n-1]
    *h = old[:n-1]
    return item
}

type FoodRatings struct {
    foodToCuisine map[string]string
    foodToRating  map[string]int
    cuisineHeap   map[string]*FoodHeap
}

func Constructor(foods []string, cuisines []string, ratings []int) FoodRatings {
    fr := FoodRatings{
        foodToCuisine: make(map[string]string),
        foodToRating:  make(map[string]int),
        cuisineHeap:   make(map[string]*FoodHeap),
    }
    for i := range foods {
        food, cuisine, rating := foods[i], cuisines[i], ratings[i]
        fr.foodToCuisine[food] = cuisine
        fr.foodToRating[food] = rating
        if _, exists := fr.cuisineHeap[cuisine]; !exists {
            h := &FoodHeap{}
            heap.Init(h)
            fr.cuisineHeap[cuisine] = h
        }
        heap.Push(fr.cuisineHeap[cuisine], FoodEntry{rating, food})
    }
    return fr
}

func (fr *FoodRatings) ChangeRating(food string, newRating int) {
    cuisine := fr.foodToCuisine[food]
    fr.foodToRating[food] = newRating
    heap.Push(fr.cuisineHeap[cuisine], FoodEntry{newRating, food})
}

func (fr *FoodRatings) HighestRated(cuisine string) string {
    h := fr.cuisineHeap[cuisine]
    for {
        top := (*h)[0]
        if fr.foodToRating[top.name] == top.rating {
            return top.name
        }
        heap.Pop(h)
    }
}
```Go 实现使用自定义`FoodHeap`具有 max-heap 属性的类型，保持与 Python 中相同的惰性删除逻辑。
