[LeetCode 问题 2385](https://leetcode.com/problems/amount-of-time-for-binary-tree-to-be-infected/)

 **难度：** 🟡 中等
 **主题：** 哈希表、树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们对感染在二叉树上的传播进行建模。 树中的每个节点都有一个唯一的整数值，感染从特定节点开始，由`start`。 感染每分钟都会传播到相邻节点（这意味着受感染节点的父节点和子节点）。 我们的目标是计算树中每个节点被感染所需的总分钟数。 

输入是由根节点以及起始节点值表示的二叉树。 输出是一个整数，表示感染整个树所需的时间。 约束告诉我们树可以非常大，最多 100,000 个节点，并且每个节点值都是唯一的，因此我们不需要担心重复的节点。 每个节点都保证存在，并且起始值的节点存在。 

重要的边缘情况包括具有单个节点的树（其中感染在第 0 分钟就已经完成）和高度不平衡的树（其中从起始节点开始的最长路径可能在树的一侧很深）。 不考虑父关系的简单递归 DFS 可能无法有效地向上传播感染。 

## 方法

 暴力方法需要每分钟重复遍历树以找到所有未受感染的邻居。 每分钟，我们都可以从起始节点执行 DFS 或 BFS 并逐步感染邻居。 虽然这种方法是正确的，但效率很低，因为每次遍历可能需要 O(n) 时间，并且我们可能每分钟重复一次，直到树完全被感染，从而导致倾斜树的时间复杂度为 O(n^2)。 

得出最佳解决方案的关键观察结果是感染以波浪形式传播，类似于 BFS。 然而，标准的树遍历并不考虑从子树向上移动到父树。 为了克服这个问题，我们可以使用哈希图将树预处理为图形表示，该哈希图记录每个节点（包括子节点和父节点）的邻接关系。 一旦建立了邻接图，就会从`start`node efficiently models the spread of the infection minute by minute. This reduces the problem to a single BFS traversal over the entire tree.

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | Repeated DFS per minute, slow for deep or large trees |
 | 最佳 | O(n) | O(n) | 将树转换为邻接图，一次 BFS |

 ## 算法演练

 1. **Convert Tree to Graph**: Traverse the tree once using DFS. For each node, record its children in an adjacency map, and also record the parent for upward traversal. This ensures we can traverse to any adjacent node efficiently.
 2. **Initialize BFS**: Use a queue initialized with the starting node. Also maintain a`visited`set to track infected nodes. 开始一个`minutes`计数器为 -1，因为在 BFS 期间将计算第 0 分钟。 
3. **BFS遍历**：当队列不为空时，递增`minutes`柜台。 For each node in the current level of the BFS, mark its unvisited neighbors as visited and enqueue them. This step ensures infection spreads to all adjacent nodes in each minute.
 4. **终止**：当队列为空时，所有节点都已被感染。 返回`minutes`计数器，现在反映感染整棵树所需的总分钟数。 

**为什么有效**：BFS 确保远处的所有节点`d`从起始节点开始每分钟就被感染`d`。 邻接图保证向上和向下传播都被考虑。 因此，最后一个 BFS 级别对应于从起始节点到任何其他节点的最大距离，给出总的感染时间。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque, defaultdict
from typing import Optional

class Solution:
    def amountOfTime(self, root: Optional[TreeNode], start: int) -> int:
        # Step 1: Build adjacency graph
        graph = defaultdict(list)
        
        def dfs(node, parent):
            if not node:
                return
            if parent:
                graph[node.val].append(parent.val)
                graph[parent.val].append(node.val)
            if node.left:
                dfs(node.left, node)
            if node.right:
                dfs(node.right, node)
        
        dfs(root, None)
        
        # Step 2: BFS to simulate infection
        queue = deque([start])
        visited = set([start])
        minutes = -1
        
        while queue:
            minutes += 1
            for _ in range(len(queue)):
                node = queue.popleft()
                for neighbor in graph[node]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
        
        return minutes
```**说明**：DFS 构建一个双向图，其中每个节点都指向其邻居。 BFS 开始于`start`节点并在每个级别传播感染一分钟。 这`minutes`计数器在每一层递增，当所有节点都被访问过时，遍历停止。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func amountOfTime(root *TreeNode, start int) int {
    // Build adjacency graph
    graph := make(map[int][]int)
    var dfs func(node, parent *TreeNode)
    dfs = func(node, parent *TreeNode) {
        if node == nil {
            return
        }
        if parent != nil {
            graph[node.Val] = append(graph[node.Val], parent.Val)
            graph[parent.Val] = append(graph[parent.Val], node.Val)
        }
        dfs(node.Left, node)
        dfs(node.Right, node)
    }
    dfs(root, nil)
    
    // BFS to simulate infection
    queue := []int{start}
    visited := make(map[int]bool)
    visited[start] = true
    minutes := -1
    
    for len(queue) > 0 {
        minutes++
        size := len(queue)
        for i := 0; i < size; i++ {
            node := queue[0]
            queue = queue[1:]
            for _, neighbor := range graph[node] {
                if !visited[neighbor] {
                    visited[neighbor] = true
                    queue = append(queue, neighbor)
                }
            }
        }
    }
    
    return minutes
}
```**Go 特定说明**：我们使用切片来实现队列，并使用映射来跟踪访问的节点。`nil`检查取代Python的`None`，切片动态增长`append`。 BFS 逻辑镜像 Python，但使用显式索引。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点在 DFS 中被访问一次以构建图，在 BFS 中被访问一次以模拟感染 |
 | 空间| O(n) | 邻接图存储每个节点及其邻居，BFS队列和访问集在最坏情况下可能保存所有节点|

 考虑到每个节点必须至少被处理一次，线性时间和空间复杂度是最佳的。
