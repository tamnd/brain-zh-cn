[LeetCode 问题 2395](https://leetcode.com/problems/find-subarrays-with-equal-sum/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表

 ## 解决方案

 ## 问题理解

 该问题要求我们判断给定数组中是否存在两个连续的长度为2的子数组`nums`具有相同的总和。 长度为 2 的子数组就是数组中任意连续的元素对。 两个子数组必须从不同的索引开始，这意味着即使它们具有相同的元素，如果它们在数组中的位置不同，它们也会被视为不同。 

输入`nums`是长度在 2 到 1000 之间的整数列表，每个整数的范围是 -10^9 到 10^9。 输出是一个布尔值，`true`如果至少两个长度为 2 的子数组的总和相等，并且`false`否则。 

重要的边缘情况包括所有元素都相同的数组、负数数组以及最小长度为 2 的数组。这些约束保证我们始终至少有一个长度为 2 的子数组，因此我们不需要处理空数组或长度小于 2 的数组。 

## 方法

 强力方法是计算长度为 2 的每个可能子数组的总和，然后检查所有总和对以查看是否有两个相等。 虽然这有效，但它需要检查 O(n^2) 对，这对于较大的数组来说效率很低。 

最佳解决方案的关键观察是，当我们迭代数组一次时，我们只需要跟踪长度为 2 的子数组的总和。 通过使用哈希集来存储计算出的每个和，我们可以在 O(1) 时间内检查我们之前是否见过相同的和。 这将时间复杂度降低到 O(n)，并且只需要 O(n) 额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 计算所有子数组对的和并进行比较 |
 | 最佳| O(n) | O(n) | 迭代时使用哈希集跟踪长度为 2 的子数组的总和 |

 ## 算法演练

 1.初始化一个空的哈希集`seen_sums`存储长度为 2 的子数组的总和。 
2. 从索引 0 到`len(nums) - 2`。 各指标`i`表示长度为 2 的子数组的起始位置。 
3. 计算当前子数组的总和：`current_sum = nums[i] + nums[i+1]`。 
4. 检查是否`current_sum`已经存在于`seen_sums`。 如果是，则返回`true`立即，因为我们找到了两个总和相等的子数组。 
5. 如果`current_sum`不在`seen_sums`，将其添加到集合中。 
6. 继续到下一个索引并重复步骤 3-5。 
7. 如果迭代完成后没有发现任何重复的和，则返回`false`。 

**为什么有效：** 每个子数组总和都会针对之前使用哈希集计算的所有总和进行一次精确检查。 该集合确保我们有效地检测重复项。 正确性得到保证，因为我们检查每个连续的对，并且任何重复的和都会立即检测到。 

## Python 解决方案```python
from typing import List

class Solution:
    def findSubarrays(self, nums: List[int]) -> bool:
        seen_sums = set()
        for i in range(len(nums) - 1):
            current_sum = nums[i] + nums[i + 1]
            if current_sum in seen_sums:
                return True
            seen_sums.add(current_sum)
        return False
```Python 实现使用了一个集合`seen_sums`存储每个长度为 2 的子数组的和。 该循环迭代数组直到倒数第二个元素，以避免索引超出范围错误。 在每一步中，它都会计算当前对的总和并检查它是否以前见过。 如果是，则返回`true`; 否则，它将总和添加到集合中并继续。 如果没有找到重复的和，函数返回`false`。 

## 解决方案```go
func findSubarrays(nums []int) bool {
    seenSums := make(map[int]struct{})
    for i := 0; i < len(nums)-1; i++ {
        currentSum := nums[i] + nums[i+1]
        if _, exists := seenSums[currentSum]; exists {
            return true
        }
        seenSums[currentSum] = struct{}{}
    }
    return false
}
```在 Go 中，我们使用地图`seenSums`使用空结构值来模拟集合。 循环以相同的方式迭代数组。 计算每个连续对的总和，然后检查它是否存在于映射中。 作为值类型的空结构是内存高效的，因为我们只需要键。

 ## 边缘情况

 第一个边缘情况是数组恰好有两个元素。 在这种情况下，只有一个子数组存在，因此该函数应该正确返回`false`。 该实现自然地处理这个问题，因为循环范围`len(nums)-1`是1，并且不可能有重复的和。 

第二种边缘情况涉及负数或正数和负数的混合。 例如，`[-5,-5,-5,-5]`产生重复的总和 -10。 该解决方案可以正确处理此问题，因为总和存储在哈希集中，并且负数不会对相等性检查造成问题。 

第三种边缘情况是当数组包含非常大或非常小的整数时，测试整数溢出。 在Python中，整数是任意精度的，所以溢出不是问题。 在 Go 中，整数和可能超过`int`如果数字较大，则有界限，但由于问题约束为 -10^9 到 10^9，两个元素的总和可以安全地容纳在 32 位或 64 位整数内。 实现通过使用标准来解释这一点`int`输入Go。
