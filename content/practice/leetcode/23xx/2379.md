[LeetCode 问题 2379](https://leetcode.com/problems/minimum-recolors-to-get-k-consecutive-black-blocks/)

 **难度：** 🟢简单
 **主题：** 字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 问题给了我们一个名为`blocks`，其中每个字符代表块的颜色。 一个角色`'B'`表示该块是黑色的，并且是一个字符`'W'`表示该块是白色的。 

我们还得到一个整数`k`。 我们的目标是确保至少存在一组`k`连续的块都是黑色的。 

唯一允许的操作是将白色块重新着色为黑色块。 黑色块已经满足要求，因此不需要修改。 我们需要计算所需的最小重新着色操作次数。 

换句话说，我们必须检查长度为的每个连续子串`k`并确定其中有多少个白色块。 由于该窗口中的每个白色块都必须重新着色为黑色，因此白色块的数量直接等于该窗口所需的操作数量。 答案是所有大小窗口中的最小值`k`。 

限制很小：

 -`1 <= n <= 100`-`1 <= k <= n`由于输入量很小，因此即使相对低效的方法也能发挥作用。 然而，这个问题是为了教授滑动窗口技术而设计的，它给出了一个干净且最优的解决方案。 

一些重要的边缘情况包括：

 - 当字符串已经包含`k`连续的黑色块，答案应该是`0`。 
- 当所有块都是白色时，所选窗口中的每个块都必须重新着色。 
- 什么时候`k == 1`，我们只需要字符串中某处有一个黑色块。 
- 什么时候`k == n`，整个字符串成为一个窗口。 
- 字符串开头或结尾的窗口必须正确处理，没有索引错误。 

## 方法

 ### 蛮力方法

 暴力解决方案检查每个可能的长度子串`k`。 

对于每个起始位置：

 1. 提取长度窗口`k`。 
2. 计算有多少个字符`'W'`。 
3. 跟踪迄今为止看到的最小计数。 

这是有效的，因为每个有效组`k`连续的块恰好对应于长度的一个子串`k`。 计算白色块可以告诉我们该子字符串需要多少次重新着色操作。 

尽管这种方法很简单，但它会重复扫描重叠的窗口。 如果我们从头开始重新计算每个窗口的白色计数，我们就会做不必要的重复工作。 

时间复杂度变为`O(n * k)`因为有`O(n)`窗口和每个窗口都需要`O(k)`工作。 

### 最优滑动窗口方法

 关键的观察结果是相邻的窗口严重重叠。 

假设我们已经知道一个窗口中白色块的数量。 将窗口向右移动一位时：

 - 一名角色离开窗口。 
- 一名新角色进入窗口。 

我们可以逐步更新白色计数，而不是重新计数所有内容：

 - 如果传出字符是白色，则减少计数。 
- 如果传入的字符是白色，则增加计数。 

这正是滑动窗口技术的设计目的。 

滑动窗口方法最多处理每个字符两次，一次进入窗口时，一次离开窗口时。 这将时间复杂度降低到`O(n)`仅使用时`O(1)`额外的空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(1) | O(1) | 重新计算每个窗口的白色块 |
 | 最佳| O(n) | O(1) | O(1) | 使用滑动窗口增量更新计数 |

 ## 算法演练

 1. 初始化变量`white_count`存储当前窗口中白色块的数量。 
2.计算第一个size窗口中白色块的数量`k`。 
3.初始化answer变量`minimum_operations`与第一个窗口计数。 这是迄今为止看到的最好答案。 
4. 开始从左向右滑动窗口。 
5. 对于每个班次：

 - 删除即将离任角色的贡献。 
- 添加传入角色的贡献。 
- 更新`minimum_operations`如果当前窗口的白色块较少。 
6. 继续，直到所有窗口的大小都达到`k`已被处理。 
7. 返回`minimum_operations`。 

### 为什么它有效

 每个有效的解决方案都对应于选择一些连续的长度窗口`k`。 该窗口所需的重新着色次数等于其内部白色块的数量。 

滑动窗口始终保持当前窗口的精确白块计数。 由于每个可能的窗口都被检查一次，并且我们保留其中的最小白色计数，因此该算法正确返回所需的重新着色操作的最小数量。 

## Python 解决方案```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        white_count = 0

        # Count white blocks in the first window
        for i in range(k):
            if blocks[i] == 'W':
                white_count += 1

        minimum_operations = white_count

        # Slide the window
        for right in range(k, len(blocks)):
            left = right - k

            # Remove outgoing character
            if blocks[left] == 'W':
                white_count -= 1

            # Add incoming character
            if blocks[right] == 'W':
                white_count += 1

            minimum_operations = min(minimum_operations, white_count)

        return minimum_operations
```该实现首先计算第一个大小窗口中白色块的数量`k`。 这建立了滑动窗口的初始状态。 

变量`minimum_operations`存储迄今为止遇到的最小数量的白色块。 由于每个白色块都需要一次重新着色操作，因此该变量直接代表答案。 

第二个循环将窗口滑过字符串。 传出字符位于索引处`left`，而传入的字符位于索引处`right`。 

每当白色块离开窗口时，计数就会减少。 每当白色块进入窗口时，计数就会增加。 

更新窗口后，算法将当前的白色计数与迄今为止看到的最佳答案进行比较。 

最后，返回所需重新着色的最小数量。 

## 解决方案```go
func minimumRecolors(blocks string, k int) int {
    whiteCount := 0

    // Count white blocks in the first window
    for i := 0; i < k; i++ {
        if blocks[i] == 'W' {
            whiteCount++
        }
    }

    minimumOperations := whiteCount

    // Slide the window
    for right := k; right < len(blocks); right++ {
        left := right - k

        // Remove outgoing character
        if blocks[left] == 'W' {
            whiteCount--
        }

        // Add incoming character
        if blocks[right] == 'W' {
            whiteCount++
        }

        if whiteCount < minimumOperations {
            minimumOperations = whiteCount
        }
    }

    return minimumOperations
}
```Go 实现遵循与 Python 解决方案完全相同的逻辑。 

Go 中的字符串可以直接索引，因为输入仅包含 ASCII 字符`'W'`和`'B'`。 无需符文转换。 

该解决方案仅使用整数变量和常量额外空间。 由于最大字符串长度仅为`100`，整数溢出从来都不是问题。

 ## 边缘情况

 一种重要的边缘情况发生在以下情况：`k`等于字符串的长度。 在这种情况下，整个字符串成为唯一可能的窗口。 有缺陷的实现可能会错误地尝试滑出有效范围。 当前的解决方案自然地处理了这个问题，因为当没有附加窗口时滑动循环永远不会执行。 

另一个重要的情况是当字符串已经包含`k`连续的黑色块。 正确答案应该是`0`，因为不需要重新着色。 The algorithm correctly detects this because a fully black window contains zero white blocks, making the minimum value zero.

 A third important edge case is when every block is white. In this scenario, every position inside the chosen window must be recolored. The algorithm correctly counts all white blocks in each window, so the answer becomes exactly`k`。 

一个微妙的情况发生时`k == 1`。 在这里，任何单个黑色块都立即满足要求。 一种幼稚的实现可能会使逻辑过于复杂，但滑动窗口仍然可以完美地工作，因为每个窗口只包含一个字符。 该算法只是简单地查找是否有`'B'`存在。
