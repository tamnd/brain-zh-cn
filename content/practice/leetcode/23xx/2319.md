[LeetCode 2319 题](https://leetcode.com/problems/check-if-matrix-is-x-matrix/)

 **难度：** 🟢简单
 **主题：** 数组、矩阵

 ## 解决方案

 ## 问题理解

 该问题给了我们一个方阵`grid`尺寸的`n x n`。 我们必须确定这个矩阵是否满足 X 矩阵的定义。 

X 矩阵具有非常特殊的结构。 矩阵的两条对角线必须仅包含非零值，并且每个其他位置必须恰好包含`0`。 

两条对角线是：

 - 主对角线，其中`row == col`- 次对角线，其中`row + col == n - 1`属于任一对角线的每个单元格都必须非零。 不在任一对角线上的每个单元格都必须为零。 

例如，在一个`4 x 4`矩阵：```
X . . X
. X X .
. X X .
X . . X
```这`X`位置是对角线位置并且必须包含非零值。 这`.`位置是非对角位置并且必须包含`0`。 

输入保证是方阵，因此我们不需要验证维度。 限制相对较小：

 -`3 <= n <= 100`-`0 <= grid[i][j] <= 10^5`由于矩阵大小最多为`100 x 100`, 最多有`10,000`细胞。 这意味着即使是简单的完整遍历也很容易足够快。 

有几个重要的边缘情况需要考虑。 奇数大小的矩阵中心的单元同时属于两条对角线。 这样的单元只需要满足对角线规则，这意味着它必须是非零的。 另一个重要的情况是当对角线元素是`0`，这会立即使矩阵无效。 同样，任何非零的非对角元素也会使矩阵无效。 

## 方法

 ### 蛮力方法

 蛮力的想法是显式存储所有对角线位置，然后扫描矩阵以验证每个单元格。 

我们可以首先通过将它们插入到一个集合中来识别属于任一对角线的所有位置。 之后，我们再次迭代矩阵。 如果一个单元格属于对角线集，我们验证它是否非零。 否则，我们验证它是否为零。 

这种方法是正确的，因为每个矩阵单元都根据确切的 X 矩阵定义进行检查。 然而，它需要额外的内存来存储对角坐标，这是不必要的，因为可以使用简单的公式直接计算对角隶属度。 

### 最佳方法

 关键的观察是我们不需要任何额外的数据结构来确定单元格是否属于对角线。 

对于任何职位`(row, col)`：

 - 它属于主对角线如果`row == col`- 它属于次对角线如果`row + col == n - 1`这使我们能够在遍历矩阵一次的同时在恒定时间内确定对角线隶属度。 

遍历过程中：

 - 如果当前单元格位于任一对角线上，则其值必须非零
 - 否则，其值必须为零

 一旦发现违规，我们可以立即退货`false`。 

这种方法既简单又节省空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n²) | 使用附加集来存储对角线位置 |
 | 最佳| O(n²) | O(1) | O(1) | 遍历期间直接检查对角线成员资格 |

 ## 算法演练

 1. 存储矩阵大小`n`。 

我们需要矩阵大小，因为次对角线条件取决于`n - 1`。 
2. 使用嵌套循环遍历矩阵中的每个单元格。 

外循环遍历行，内循环遍历列。 这保证了每个矩阵位置都被检查一次。 
3. 判断当前单元格是否属于对角线。 

一个细胞`(row, col)`如果满足以下任一条件，则为对角单元格：

 -`row == col`-`row + col == n - 1`4. 处理对角单元格。 

如果当前单元格位于对角线上，则其值不得为零。 如果我们遇到零对角线值，我们立即返回`false`。 
5. Handle non-diagonal cells.

 如果当前单元格不在对角线上，则其值必须恰好为零。 如果我们在对角线之外遇到非零值，我们立即返回`false`。 
6. 返回`true`遍历结束后。 

如果每个单元都满足所需条件，则该矩阵是有效的 X 矩阵。 

### 为什么它有效

 该算法直接实现了 X 矩阵的数学定义。 每个细胞都被准确地分为两类之一：

 - 对角细胞
 - 非对角细胞

 该算法验证每个类别的正确规则。 由于每个矩阵位置都被检查一次并且每次违规都会立即失败，因此算法返回`true`当且仅当矩阵满足 X 矩阵定义。 

## Python 解决方案```python
from typing import List

class Solution:
    def checkXMatrix(self, grid: List[List[int]]) -> bool:
        n = len(grid)

        for row in range(n):
            for col in range(n):
                is_diagonal = (row == col) or (row + col == n - 1)

                if is_diagonal:
                    if grid[row][col] == 0:
                        return False
                else:
                    if grid[row][col] != 0:
                        return False

        return True
```实现首先将矩阵大小存储在`n`。 这是检查某个位置是否属于次对角线所必需的。 

嵌套循环对每个矩阵单元恰好迭代一次。 对于每个位置，变量`is_diagonal`确定当前单元格是否属于任一对角线。 

如果单元格是对角线的，则代码将验证该值是否非零。 如果该值为零，则矩阵违反 X 矩阵条件，因此函数立即返回`False`。 

如果单元格不是对角线，则该值必须恰好为零。 对角线之外的任何非零值都会立即使矩阵无效。 

如果遍历完成而没有发现任何违规，则矩阵满足所有要求，因此函数返回`True`。 

## 解决方案```go
func checkXMatrix(grid [][]int) bool {
    n := len(grid)

    for row := 0; row < n; row++ {
        for col := 0; col < n; col++ {
            isDiagonal := (row == col) || (row+col == n-1)

            if isDiagonal {
                if grid[row][col] == 0 {
                    return false
                }
            } else {
                if grid[row][col] != 0 {
                    return false
                }
            }
        }
    }

    return true
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 Go 切片用于表示矩阵。 由于约束很小并且值适合标准整数范围，因此不存在溢出问题。 

与 Python 不同，Go 不使用类型提示，但函数签名已经指定了`grid`是一个二维整数切片。

 ## 边缘情况

 一种重要的边缘情况出现在奇数大小的矩阵中，因为中心单元同时属于两条对角线。 有缺陷的实现可能会意外地处理该单元两次或应用冲突的逻辑。 当前的实现避免了这个问题，因为它只是使用单个布尔条件检查单元格是否属于任一对角线。 因此，中心单元被正确地视为对角元素，并且只需非零即可。 

另一个重要的边缘情况是对角线元素为零时。 由于对角单元格必须包含非零值，因此即使是一个零也会立即使矩阵无效。 一旦遇到对角单元格并返回，该实现就会检查此条件`False`无需不必要的额外工作。 

第三个重要的边缘情况是非对角单元格包含非零值时。 如果实现只关注验证对角线，这一点很容易被忽视。 该算法显式检查每个非对角位置并确保其等于零，从而保证正确检测到 X 形状之外的额外值。 

最后的边缘情况涉及允许的最小矩阵大小，即`3 x 3`。 小矩阵经常会暴露索引错误或不正确的对角线计算。 公式`row + col == n - 1`即使在最小的有效大小下也能正常工作，确保所有允许的输入的可靠行为。
