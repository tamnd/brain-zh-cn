[LeetCode 问题 2308](https://leetcode.com/problems/arrange-table-by-gender/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们重新排列 a 的行`Genders`表以特定的重复顺序排列，同时保持内部排序。 该表有两列：`user_id`和`gender`。 这`user_id`每行都是唯一的，并且`gender`列可以采用三个值之一：`'female'`,`'male'`， 或者`'other'`。 该表保证每种性别的行数相等，因此任何性别的行数都不会比其他性别多或少。 

目标是返回性别以重复序列出现的行`'female'`,`'other'`,`'male'`同时确保在每个性别中，`user_id`s 按升序排序。 输出应该是一个完整的表格，按照指定的顺序一致地交替显示三种性别。 

重要的细节包括序列必须完全重复`'female'`,`'other'`,`'male'`并且同一性别内的所有 ID 均已排序。 可能会导致幼稚实现失败的边缘情况包括假设任何任意的性别顺序都是可接受的或无法维护内部 ID 排序。 该问题保证计数相等，因此我们不需要处理不均匀分布。 

## 方法

 一种强力方法是获取所有行，按性别将它们分成三个列表，对每个列表进行排序，然后手动交错它们。 这是有效的，因为排序可确保升序，而交错可确保正确的性别顺序。 然而，对于大型表来说，完全在 SQL 之外或在多个嵌套查询中执行此操作可能会很冗长且效率低下。 

最佳解决方案利用 SQL 窗口函数，特别是`ROW_NUMBER()`，为每个用户分配其性别内的排名。 通过按升序为每个性别分配一个行号`user_id`，然后我们可以根据这些行号对所有性别进行连接或排序。 这保证了内部排序和交替模式，而无需复杂的过程逻辑。

 ## 算法演练

 1. 对每个性别使用通用表表达式 (CTE)（`female`,`other`,`male`) 为每个用户分配一个行号，按其性别排序，按`user_id`按升序排列。 这将创建三个单独的临时表，其中包含列`user_id`,`gender`， 和`rn`为行号。 
2. 使用组合所有三个 CTE`UNION ALL`。 这给出了一个表，其中每一行都有其`user_id`,`gender`，及其在其性别组中的位置。 
3. 首先对组合行进行排序`rn`（行号）然后按自定义`CASE`将性别转换为序列索引的语句（`'female'`= 1,`'other'`= 2,`'male'`= 3）。 这确保了重复模式和内部 ID 排序。 
4.返回带有列的结果表`user_id`和`gender`在最终的顺序中。 

为什么有效：排名确保每个性别的内部排序。 按行号排序可以保证我们每次迭代都从每个性别中选择一个，并且`CASE`确保性别顺序正确。 这种方法产生了一个完美交错和排序的表。 

## Python 解决方案

 由于这是一个数据库问题，Python 解决方案通常涉及使用 SQL 执行。 下面是一个可以使用任何数据库连接器在 Python 中执行的直接 SQL 查询：```python
# Python solution using SQL execution
query = """
WITH female AS (
    SELECT user_id, gender, ROW_NUMBER() OVER (ORDER BY user_id) AS rn
    FROM Genders
    WHERE gender = 'female'
),
other AS (
    SELECT user_id, gender, ROW_NUMBER() OVER (ORDER BY user_id) AS rn
    FROM Genders
    WHERE gender = 'other'
),
male AS (
    SELECT user_id, gender, ROW_NUMBER() OVER (ORDER BY user_id) AS rn
    FROM Genders
    WHERE gender = 'male'
)
SELECT user_id, gender
FROM (
    SELECT * FROM female
    UNION ALL
    SELECT * FROM other
    UNION ALL
    SELECT * FROM male
) t
ORDER BY rn, CASE gender
    WHEN 'female' THEN 1
    WHEN 'other' THEN 2
    WHEN 'male' THEN 3
END
"""
```该查询利用 CTE 直接实现算法`ROW_NUMBER()`以简化交错。

 ## 边缘情况

 第一个边缘情况是一个最小的表，每种性别只有一行。 该实现可以正确处理它，因为`ROW_NUMBER()`为每行分配 1，按行号和性别顺序排序会产生所需的准确输出。 

第二个边缘情况是当`user_id`s 已按性别排序，但表中的原始顺序是混合的。 该算法仍然可以正确排序，因为`ROW_NUMBER()`函数强制每个性别内的排序，而不管原始表的顺序如何。 

第三种边缘情况是如果`user_id`s 不连续或者是大整数。 该算法可以正确处理这个问题，因为排序是基于值比较，而不是连续数字的假设。
