[LeetCode 问题 2384](https://leetcode.com/problems/largest-palindromic-number/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、贪婪、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们使用给定字符串中的数字形成**最大回文整数**`num`。 回文是一个向前和向后读取相同的数字，例如`121`或者`7449447`。 输入字符串`num`仅由数字组成 (`0`到`9`) 并且可能包含重复的数字。 我们可以对数字进行“重新排序”，并且允许使用其中的“部分或全部”，但至少必须使用一位数字。 结果不得**没有前导零**，除非数字为`0`。 

例如，如果`num`是`"444947137"`，我们可以形成的最大回文是`"7449447"`。 这里的关键是回文是对称的，因此我们需要平衡两侧的数字，并根据需要选择在中间放置一个数字。 

约束表明`num`**最长可达 100,000 个字符**，因此我们需要一个**在时间上呈线性或接近线性的算法**。 需要考虑的边缘情况包括：

 - 全零的字符串，例如，`"0000"`（应该返回`"0"`）。 
- 只有一位数字的字符串，例如，`"7"`（应该返回`"7"`）。 
- 由于对称性，最大回文数不能使用所有数字的字符串。 

## 方法

 暴力方法将生成数字的**所有排列**，检查每个排列是否为回文，然后选择最大的。 这是正确的，但由于阶乘时间复杂度，对于大输入长度来说完全不切实际。 

最佳解决方案的**关键见解**是回文由其**左半部分和可选的中心数字**定义。 因此，我们可以：

 1. 统计每个数字出现的次数。 
2. 首先使用**最高数字**构建回文的左半部分。 
3. 如果有任何数字剩余（出现奇数次），我们可以将**最大剩余数字**放在中间。 
4. 镜像左半部分以形成右半部分。 

这将问题简化为**计数和贪婪选择**，使得对于大输入来说是可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成所有排列并过滤回文。 不可行。 |
 | 最佳 | O(n) | O(1) | O(1) | 计算数字并从最高到最低贪婪地构建回文。 位数固定为 10。 

## 算法演练

 1. 初始化一个大小为 10 的 **计数数组** 来存储每个数字的出现次数`0`到`9`。 
2. 迭代`num`并增加每个数字的计数。 
3.初始化一个空字符串`left_half`对于回文的左侧。 
4. 对于数字`9`下降到`0`, 附加`count[digit] // 2`该数字的副本`left_half`。 减少`count[digit]`经过`2 * (count[digit] // 2)`。 
5. 识别**中间数字**：最大的数字`d`和`count[d] > 0`。 这将是回文的中心。 
6. 将 **完整回文** 形成为`left_half + middle + reversed(left_half)`。 
7. 处理生成的回文串开头的边缘情况`'0'`。 如果是这样，则整个数字必须是`"0"`（所有数字均为零）。 

**为什么有效：** 通过在两半中首先使用最大的数字，我们可以最大化数值。 通过镜像保证回文的对称性`left_half`。 选择中间最大的奇数位可以确保整体价值最大化。 

## Python 解决方案```python
class Solution:
    def largestPalindromic(self, num: str) -> str:
        count = [0] * 10
        for ch in num:
            count[int(ch)] += 1

        left_half = []
        for d in range(9, -1, -1):
            if count[d] >= 2:
                times = count[d] // 2
                left_half.append(str(d) * times)
                count[d] -= times * 2

        left_str = ''.join(left_half)
        middle = ''
        for d in range(9, -1, -1):
            if count[d] > 0:
                middle = str(d)
                break

        # Remove leading zeros if the left half is empty
        if left_str and left_str[0] == '0':
            left_str = ''
            middle = '0' if middle else '0'

        return left_str + middle + left_str[::-1]
```**解释：** 我们计算数字并使用尽可能多的数字对贪婪地构建左半部分，从`9`。 中间的数字是最大的剩余数字。 我们通过检查第一个字符来处理所有数字都为零的情况。 

## 解决方案```go
func largestPalindromic(num string) string {
    count := [10]int{}
    for _, ch := range num {
        count[ch-'0']++
    }

    leftHalf := ""
    for d := 9; d >= 0; d-- {
        if count[d] >= 2 {
            times := count[d] / 2
            for i := 0; i < times; i++ {
                leftHalf += string('0' + d)
            }
            count[d] -= times * 2
        }
    }

    middle := ""
    for d := 9; d >= 0; d-- {
        if count[d] > 0 {
            middle = string('0' + d)
            break
        }
    }

    if len(leftHalf) > 0 && leftHalf[0] == '0' {
        leftHalf = ""
        if middle == "" {
            middle = "0"
        }
    }

    rightHalf := ""
    for i := len(leftHalf) - 1; i >= 0; i-- {
        rightHalf += string(leftHalf[i])
    }

    return leftHalf + middle + rightHalf
}
```**Go 特定说明：** 我们使用大小为 10 的固定数组来计数数字。 为了简单起见，使用字符串连接。 处理前导零需要检查第一个字符`leftHalf`。
