[LeetCode 问题 2375](https://leetcode.com/problems/construct-smallest-number-from-di-string/)

 **难度：** 🟡 中等
 **主题：** 字符串、回溯、堆栈、贪婪

 ## 解决方案

 ## 问题理解

 该问题要求我们从由以下组成的字符串模式构造字典顺序最小的数字：`'I'`和`'D'`。 模式中的每个字符定义数字的连续数字之间的关系：`'I'`表示下一个数字应该比当前数字**大**，并且`'D'`表示下一个数字应该**小**。 数字是由数字组成的`'1'`到`'9'`没有重复，并且其长度比模式的长度大一。 

输入是一个长度的字符串`n`（`1 <= n <= 8`），它足够小，我们可以考虑非严格线性的方法。 输出是一个长度的字符串`n+1`表示满足该模式的字典顺序中的最小数字。 重要的限制包括确保**没有重复的数字**以及遵守每个位置增加/减少的要求。 

边缘情况包括所有的模式`'I'`（要求严格增加数量），所有`'D'`（要求严格递减数字），或交替`'I'`和`'D'`。 由于最大长度为8，因此涉及的最大数字最多为9位。 

## 方法

 蛮力方法将生成所有数字排列`'1'`通过`'9'`长度`n+1`并检查哪些排列满足该模式。 虽然正确，但这种方法效率非常低，因为排列的数量随阶乘增长`n`（`O(9!)`最坏情况为`n = 8`）。 检查每个排列需要迭代模式进行验证，这使得过程变得缓慢且不必要。 

更优化解决方案的关键见解来自**贪婪和基于堆栈的构造**。 观察任意连续的序列`'D'`s 应以**相反的顺序**填充最大的可用数字。 实现这一点的最简单方法是迭代该模式，每当我们遇到一个`'D'`，我们可以将当前数字压入堆栈，继续直到模式结束或者我们看到`'I'`。 此时，我们从堆栈中弹出所有元素，以确保递减顺序正确反转。 此方法保证了字典顺序上最小的数字，因为我们总是将最小的可用数字放在前面。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(9!) | O(n+1) | 生成所有排列并根据模式检查每一个排列 |
 | 最佳| O(n) | O(n) | 使用栈处理连续递减序列，贪心构造最小数 |

 ## 算法演练

 1.初始化一个空列表`result`存储数字的数字和一个空堆栈`stack`管理递减序列。 
2. 迭代从 1 到`n+1`，代表要放置的候选数字。 
3. 将每个数字压入堆栈。 
4. 如果当前位置是模式末尾或下一个字符是`'I'`，从堆栈中弹出所有元素并将它们追加到`result`。 这确保了任何前面的`'D'`顺序颠倒正确。 
5. 继续此过程，直到处理完所有号码。 
6. 连接数字`result`转换为字符串并返回。 

**为什么起作用**：堆栈确保所有连续递减位置都正确反转以满足`'D'`要求，同时数字尽可能按升序排列，保证字典顺序最小的结果。 

## Python 解决方案```python
class Solution:
    def smallestNumber(self, pattern: str) -> str:
        result = []
        stack = []
        n = len(pattern)
        
        for i in range(n + 1):
            stack.append(str(i + 1))
            
            if i == n or pattern[i] == 'I':
                while stack:
                    result.append(stack.pop())
        
        return ''.join(result)
```Python 实现直接遵循该算法。 我们从 0 迭代到`n`（包含）和推送`i+1`到堆栈上。 每当我们到达终点或`'I'`，我们从堆栈中弹出所有元素并将它们附加到`result`。 这确保了所有递减序列都正确反转，而递增序列自然地按推送的数字顺序处理。 

## 解决方案```go
func smallestNumber(pattern string) string {
    result := []byte{}
    stack := []byte{}
    n := len(pattern)
    
    for i := 0; i <= n; i++ {
        stack = append(stack, byte('1'+i))
        
        if i == n || pattern[i] == 'I' {
            for len(stack) > 0 {
                result = append(result, stack[len(stack)-1])
                stack = stack[:len(stack)-1]
            }
        }
    }
    
    return string(result)
}
```在 Go 中，我们使用切片`byte`为了`result`和`stack`。 从整数到字符的转换是使用`byte('1'+i)`。 出栈操作使用切片，这在 Go 中是惯用的。 该逻辑与 Python 解决方案非常相似。

 ## 边缘情况

 一个重要的边缘情况是所有的模式`'I'`，这需要严格增加数字。 如果不仔细处理，算法可能会不必要地错误地反转序列。 堆栈方法通过仅在出现时弹出来处理此问题`'I'`遇到，所以序列`'I'`按顺序自然附加。 

另一个边缘情况是所有的模式`'D'`，这需要严格递减数字。 该算法首先将所有数字压入堆栈，然后在末尾弹出它们以反转整个序列，产生正确的降序数字。 

第三种边缘情况涉及交替`'I'`和`'D'`。 简单的方法可能无法正确处理短递减序列。 堆栈确保每个`'D'`序列被单独反转，在满足模式的同时保留字典顺序最小的顺序。 

此方法还可以正确处理最大模式长度 8，避免整数溢出或数字重复问题。
