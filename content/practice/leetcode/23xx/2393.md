[LeetCode 问题 2393](https://leetcode.com/problems/count-strictly-increasing-subarrays/)

 **难度：** 🟡 中等
 **主题：** 数组、数学、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定数组中所有**严格递增的子数组**`nums`正整数。 严格递增子数组是一个连续的数字序列，其中每个元素都严格大于前一个元素。 输出应该是一个整数，表示此类子数组的总数。 

输入`nums`是一个数组`1 <= nums.length <= 10^5`，每个元素是`1 <= nums[i] <= 10^6`。 这些约束表明，迭代所有可能的子数组的强力方法会太慢，因为长度数组中的子数组数量`n`是 O(n^2)。 我们需要一种以线性时间或接近线性时间运行的算法。 

Important edge cases include arrays of length 1 (where the only subarray is the element itself), arrays with all equal elements (no subarrays longer than 1), and arrays that are strictly increasing or strictly decreasing.

 ## 方法

 暴力方法将生成每个可能的子数组并检查它是否严格递增。 对于每个子数组，我们将迭代其元素来验证严格递增的属性。 虽然正确，但这种方法效率低下，因为对于长度的数组`n`，有 O(n^2) 个子数组，检查每个子数组最多需要 O(n) 时间。 这会产生 O(n^3) 算法，对于 n 高达 10^5 的情况不可行。 

最佳解决方案的关键观察是**严格增加的子数组可以通过它们的长度来计数**。 如果我们知道从某个索引开始的最大严格递增子数组的长度，我们可以使用第一个子数组之和的公式来计算其中严格递增子数组的总数`k`正整数。 具体来说，如果严格递增序列的长度`L`，它包含`L * (L + 1) / 2`严格增加子数组。 使用单次遍历数组，我们可以计算这个长度并有效地累积计数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 生成所有子数组并检查严格递增属性 |
 | 最佳| O(n) | O(1) | O(1) | 单遍，计算递增序列的长度并对子数组计数求和 |

 ## 算法演练

 1. 初始化变量`count`为 0 以存储严格递增子数组的总数。 
2. 初始化变量`length`到 1，表示严格递增序列的当前长度。 
3. 从第二个元素到末尾迭代数组。 
4. 对于每个元素，将其与前一个元素进行比较。 如果严格大于，则增加`length`加 1 因为当前子数组可以扩展。 
5. 如果当前元素不严格大于前一个元素，则使用以下公式计算当前递增序列中的子数组数`length * (length + 1) // 2`并将其添加到`count`。 然后重置`length`到 1 开始计算下一个递增序列。 
6、循环结束后，可能还有剩余的递增序列，所以将其子数组计数添加到`count`。 
7. 返回`count`作为最终答案。 

**为什么有效：** 通过维护每个连续严格递增段的长度并使用第一个段之和的公式`k`整数，我们可以有效地计算所有有效的子数组，而无需显式生成它们。 这保证了正确性，因为每个严格递增的子数组都是某个最大递增序列的一部分。 

## Python 解决方案```python
from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        count = 0
        length = 1
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                length += 1
            else:
                count += length * (length + 1) // 2
                length = 1
        
        count += length * (length + 1) // 2
        return count
```Python 解决方案维护严格递增序列的运行长度，并使用整数和公式有效地对子数组进行计数。 循环外的最后添加处理最后一个序列，这避免了差一错误。 

## 解决方案```go
func countSubarrays(nums []int) int64 {
    var count int64 = 0
    length := 1
    
    for i := 1; i < len(nums); i++ {
        if nums[i] > nums[i-1] {
            length++
        } else {
            count += int64(length * (length + 1) / 2)
            length = 1
        }
    }
    
    count += int64(length * (length + 1) / 2)
    return count
}
```在 Go 中，我们使用`int64`为了`count`以防止大输入大小的整数溢出。 否则，逻辑反映了 Python 解决方案，迭代数组并计算严格递增序列的长度。

 ## 边缘情况

 **单元素数组：**唯一的子数组是元素本身。 Python 和 Go 解决方案都初始化`length = 1`并处理循环结束加法，正确返回 1。 

**所有元素相等：** 长度大于 1 的子数组不严格递增。 算法重置`length`每当当前元素不大于前一个元素时，确保仅计算长度为 1 的子数组。 

**严格递减数组：** 每个元素形成长度为1的有效子数组。算法正确重置`length`在每一步中，生成等于数组长度的正确计数。 

这种方法能够可靠地处理所有这些具有线性复杂度和恒定空间的情况。
