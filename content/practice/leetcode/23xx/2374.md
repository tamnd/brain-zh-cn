[LeetCode 问题 2374](https://leetcode.com/problems/node-with-highest-edge-score/)

 **难度：** 🟡 中等
 **主题：** 哈希表、图论

 ## 解决方案

 ## 问题理解

 该问题要求我们分析一个有向图，其中每个节点恰好有一个出边，由数组表示`edges`。 各指标`i`代表一个节点，并且`edges[i]`表示从节点开始的有向边`i`到节点`edges[i]`。 我们需要计算每个节点的**边缘得分**，定义为指向该节点的所有节点的标签之和。 目标是找到具有**最高边缘分数**的节点，在平局的情况下返回具有最小索引的节点。 

简单来说，我们计算每个节点的传入节点标签的总和并确定最大值。 约束指定最多 100,000 个节点（`n <= 10^5`），这意味着需要一种有效的线性方法。 边缘情况包括具有相同最大边缘得分的多个节点、没有传入边缘的节点或所有节点都指向链或循环的图形。 

## 方法

 **暴力方法**将迭代每个节点，并且对于每个节点，迭代`edges`数组来求和指向它的节点标签。 这保证了正确性，但复杂度为 O(n^2)，这对于`n = 10^5`。 

**最佳方法**利用了每个节点恰好指向另一个节点这一事实。 我们可以对数组进行一次迭代，并且对于每个节点`i`，将其标签添加到边缘得分`edges[i]`。 这会产生一个具有 O(n) 空间来存储边缘分数的线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 对每个节点迭代所有边以求和传入标签 |
 | 最佳| O(n) | O(n) | 单遍累积边缘分数，然后找到最大值|

 ## 算法演练

 1.初始化一个数组`score`长度`n`存储每个节点的累积边缘分数。 所有元素都从 0 开始。 
2. 迭代每个节点`i`从 0 到`n-1`。 
3.对于每个节点`i`, 增量`score[edges[i]]`经过`i`。 这会累积指向每个节点的所有节点。 
4.初始化两个变量：`max_score`跟踪当前最高边缘分数，以及`result_node`跟踪对应的节点索引`max_score`。 
5. 迭代`score`大批。 对于每个节点`i`， 如果`score[i]`超过`max_score`， 更新`max_score`和`result_node`和`i`。 如果`score[i]`等于`max_score`和`i`小于`result_node`， 更新`result_node`到`i`。 
6. 返回`result_node`。 

**为什么有效：** 通过对所有节点进行一次迭代并将它们的标签累积到目标节点的分数中，我们确保所有传入的边都被计算在内。 同时跟踪最大分数和最小指数可确保正确的平局打破行为。 

## Python 解决方案```python
from typing import List

class Solution:
    def edgeScore(self, edges: List[int]) -> int:
        n = len(edges)
        score = [0] * n

        for i, target in enumerate(edges):
            score[target] += i

        max_score = -1
        result_node = -1

        for i, s in enumerate(score):
            if s > max_score or (s == max_score and i < result_node):
                max_score = s
                result_node = i

        return result_node
```**说明：** 我们首先分配一个`score`数组来存储边缘分数。 迭代`edges`，我们将每个节点的标签添加到它指向的节点。 积累完毕后，我们扫描`score`确定最大值，使用最小的节点索引打破联系。 

## 解决方案```go
func edgeScore(edges []int) int {
    n := len(edges)
    score := make([]int, n)

    for i, target := range edges {
        score[target] += i
    }

    maxScore := -1
    resultNode := -1

    for i, s := range score {
        if s > maxScore || (s == maxScore && i < resultNode) {
            maxScore = s
            resultNode = i
        }
    }

    return resultNode
}
```**Go 特定注释：** 我们使用切片`score`存储边缘分数。 整数溢出与给定的约束无关。 切片索引是从 0 开始的，符合问题要求。 平局决胜逻辑使用标准比较来确保返回最小的索引。

 ## 边缘情况

 一种重要的边缘情况是多个节点共享相同的最大边缘分数的图。 该解决方案通过比较索引并返回最小索引来处理此问题。 

另一个边缘情况是只有两个节点的最小图。 该算法必须用最少的数据正确处理累积和打破平局。 

最后，不得选择节点没有传入边的图作为结果。 该解决方案正确地将分数初始化为零，并且仅在节点指向目标时更新它们，确保没有传入边缘的节点被正确忽略，除非它们具有最高分数（如果所有节点都被隔离，则分数为零）。
