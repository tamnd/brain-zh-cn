 ## 解决方案

 ## 问题理解

 该问题要求我们找到**无向图中**中无法通过任何路径相互到达的节点对的数量。 给你一个整数`n`表示标记为的节点总数`0`到`n - 1`和一个列表`edges`表示节点之间的连接。 每条边都是双向的。 输出应该是一个整数：无序节点对的总数`(i, j)`使得没有路径连接节点`i`到节点`j`。 

这个问题本质上要求我们识别图中的**连通组件**，因为属于同一连通组件的节点可以相互到达，而来自不同组件的节点则不能。 然后可以根据这些组件的大小计算不可达对的数量。 

约束表明`n`可以大到`10^5`边的数量最多可达`2 * 10^5`。 这排除了任何需要单独检查每对节点的连接性的解决方案，因为这将是 O(n^2)，这是不可行的。 

重要的边缘情况包括：

 - 完全连接的图，其中所有节点彼此可达，导致 0 个不可达对。 
- 没有边的图，其中所有节点对都是不可到达的。 
- 具有多个小型断开组件的图表，必须仔细组合这些组件才能正确计数对。 

## 方法

 **暴力方法**将涉及迭代所有可能的节点对，并对每对节点执行 BFS 或 DFS，以检查是否存在连接它们的路径。 虽然这保证了正确性，但其时间复杂度是 O(n^2) 乘以 O(n + m) 的遍历成本，这对于输入限制而言过于昂贵（`n`最多 10^5)。 

**最佳方法**利用了图形可以分为连接组件的关键观察。 如果我们知道每个组件的大小，我们可以将不可达对的数量计算为不同组件大小的所有乘积的总和。 或者，我们可以迭代组件并使用运行总计公式计算不可达对的数量：`size_so_far`是之前组件中统计的节点总数，那么对于当前组件的size`sz`，新贡献的不可达对的数量为`sz * (n - size_so_far - sz)`。 这种方法需要一次遍历来查找组件，然后通过简单的算术来计算答案，从而使其高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * (n + m)) | O(n^2 * (n + m)) | O(n + m) | 使用 DFS/BFS 检查每对的连接性 |
 | 最佳| O(n + m) | O(n + m) | 查找连接的组件并计算不可达对 |

 ## 算法演练

 1. 将图初始化为邻接表来存储所有连接。 这允许在遍历过程中 O(1) 访问邻居。 
2. 创建一个大小为visited的数组`n`初始化为False。 这会跟踪组件中已包含的节点。 
3. 迭代每个节点`i`从 0 到 n-1。 如果某个节点未被访问，则从该节点启动 DFS 或 BFS 来探索其连接的组件。 
4、每次遍历，统计节点数`sz`在组件中并将其标记为已访问。 
5. 保持累计金额`seen`累积先前组件中已处理的节点数。 
6.对于当前组件的尺寸`sz`，计算新的不可达对的数量：`sz * (n - seen - sz)`并将其添加到总答案中。 
7. 更新`seen`通过添加`sz`到它。 
8. 处理完所有组件后返回总计数。 

**为什么有效**：通过计算每个连接组件的大小，我们可以准确地知道有多少个节点是相互可达的。 给定组件外部的任何节点都无法从组件内部的节点访问。 该算术保证所有对都被计数一次而不会重复。 

## Python 解决方案```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def countPairs(self, n: int, edges: List[List[int]]) -> int:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        visited = [False] * n
        
        def bfs(start: int) -> int:
            queue = deque([start])
            visited[start] = True
            size = 1
            while queue:
                node = queue.popleft()
                for neighbor in graph[node]:
                    if not visited[neighbor]:
                        visited[neighbor] = True
                        queue.append(neighbor)
                        size += 1
            return size
        
        total_pairs = 0
        seen = 0
        for node in range(n):
            if not visited[node]:
                component_size = bfs(node)
                total_pairs += component_size * (n - seen - component_size)
                seen += component_size
                
        return total_pairs
```Python 代码首先从边列表构造邻接表。 BFS 用于计算每个连接组件的大小，标记访问过的节点。 对于每个组件，公式`size * (n - seen - size)`计算从此组件无法访问的所有对，避免重复计算。 最终答案累计在`total_pairs`。 

## 解决方案```go
package main

func countPairs(n int, edges [][]int) int64 {
    graph := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }
    
    visited := make([]bool, n)
    
    var bfs func(int) int
    bfs = func(start int) int {
        queue := []int{start}
        visited[start] = true
        size := 1
        for len(queue) > 0 {
            node := queue[0]
            queue = queue[1:]
            for _, neighbor := range graph[node] {
                if !visited[neighbor] {
                    visited[neighbor] = true
                    queue = append(queue, neighbor)
                    size++
                }
            }
        }
        return size
    }
    
    var totalPairs int64 = 0
    seen := 0
    for i := 0; i < n; i++ {
        if !visited[i] {
            componentSize := bfs(i)
            totalPairs += int64(componentSize) * int64(n - seen - componentSize)
            seen += componentSize
        }
    }
    
    return totalPairs
}
```在 Go 中，切片和`int64`用于安全处理大量数据。 BFS 逻辑与 Python 相同，但队列操作是使用切片追加和切片手动管理的。 

## 工作示例

 **示例2：**`n = 7, edges = [[0,2],[0,5],[2,4],[1,6],[5,4]]`- 发现的组件：`[0,2,4,5]`尺寸 4，`[1,6]`尺寸 2，`[3]`尺寸 1。 
- 运行总计：

 | 组件| 尺寸| 之前看过 | 新双 |
 | ---| ---| ---| ---|
 | [0,2,4,5] | 4 | 0 | 4 * (7 - 0 - 4) = 12 | 4 * (7 - 0 - 4) = 12 |
 | [1,6]| 2 | 4 | 2 * (7 - 4 - 2) = 2 |
 | [3] | 1 | 6 | 1 * (7 - 6 - 1) = 0 |

 无法到达的对总数 = 12 + 2 + 0 = 14
