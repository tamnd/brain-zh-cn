[LeetCode 问题 2321](https://leetcode.com/problems/maximum-score-of-spliced-array/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 问题提出了两个整数数组，`nums1`和`nums2`, 等长`n`。 您可以从两个数组中选择一个连续的子数组并**将它们交换一次**，或者选择根本不交换。 在此可选交换之后，**分数**计算为两个数组之和的最大值。 您的任务是在考虑所有有效交换后确定**可能的最大分数**。 

关键的见解是该操作是**一次性**并且仅影响连续的部分。 输入约束表明`n`可以大到 100,000，因此任何算法都会天真地迭代所有子数组（`O(n^2)`）会太慢。 数组中的值都是正数，这允许某些优化，因为子数组的总和始终为非负数。 

重要的边缘情况包括长度为 1 的数组、所有元素都相等的数组，或者如果天真地进行交换会**降低**分数的数组。 该问题保证非空数组和正整数。 

## 方法

 ### 暴力方法

 一个幼稚的解决方案会迭代所有可能的`left`和`right`索引，交换相应的子数组，计算总和`nums1`和`nums2`，并记录最大值。 这保证了正确性，因为它探索了所有可能性。 然而，随着`n`最多 10^5，这会导致 **O(n^2)** 时间复杂度，这是不可行的。 

### 最佳方法

 关键的观察是交换子数组`nums1`进入`nums2`改变总和`nums1`通过**交换元素之间的差异**。 具体来说，增益总和为`nums1`如果我们交换一个子数组`[i...j]`是：```
gain = sum(nums2[i..j]) - sum(nums1[i..j])
```因此，问题简化为寻找具有**最大增益**的连续子阵列。 这是一个经典的**最大子数组和问题**，可以使用 Kadane 算法在 **O(n)** 中解决。 由于我们可以选择任意一种方式进行交换，因此我们需要计算最大增益`nums1`（通过采取`nums2 - nums1`）和对于`nums2`（通过采取`nums1 - nums2`) 并将其添加到原始总和中。 

方法比较：

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 检查所有子数组并计算总和 |
 | 最佳| O(n) | O(1) | O(1) | 在差异数组上使用 Kadane 算法 |

 ## 算法演练

 1. 计算总和`nums1`和`nums2`。 让这些成为`sum1`和`sum2`。 
2. 创建差异数组`diff1 = nums2[i] - nums1[i]`来表示增益`nums1`如果我们单独交换每个元素。 
3. 使用 Kadane 算法`diff1`找到**最大子数组和**，代表最佳可能增益`nums1`交换后。 
4. 重复步骤 2-3`diff2 = nums1[i] - nums2[i]`计算最佳增益`nums2`。 
5. 计算`max_score1 = sum1 + max_gain1`和`max_score2 = sum2 + max_gain2`。 
6. 返回`max(max_score1, max_score2)`作为最终答案。 

**为什么有效**：该算法确保使用 Kadane 算法有效评估每个可能的子数组交换，从而保证最大子数组总和。 通过将两个阵列视为潜在的增益接收者，可以确保获得全局最高分数。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumsSplicedArray(self, nums1: List[int], nums2: List[int]) -> int:
        def max_subarray_gain(diff: List[int]) -> int:
            max_gain = current_gain = 0
            for val in diff:
                current_gain = max(val, current_gain + val)
                max_gain = max(max_gain, current_gain)
            return max_gain

        sum1 = sum(nums1)
        sum2 = sum(nums2)

        diff1 = [b - a for a, b in zip(nums1, nums2)]
        diff2 = [a - b for a, b in zip(nums1, nums2)]

        max_gain1 = max_subarray_gain(diff1)
        max_gain2 = max_subarray_gain(diff2)

        return max(sum1 + max_gain1, sum2 + max_gain2)
```此实现首先计算两个数组的总和。 差异数组对交换中的潜在增益进行编码。 Kadane 的算法有效地找到产生最大增益的子数组，然后将其添加到原始总和中以计算最大分数。 

## 解决方案```go
func maximumsSplicedArray(nums1 []int, nums2 []int) int {
    maxSubarrayGain := func(diff []int) int {
        maxGain, currentGain := 0, 0
        for _, val := range diff {
            if currentGain + val > val {
                currentGain += val
            } else {
                currentGain = val
            }
            if currentGain > maxGain {
                maxGain = currentGain
            }
        }
        return maxGain
    }

    sum1, sum2 := 0, 0
    n := len(nums1)
    diff1 := make([]int, n)
    diff2 := make([]int, n)

    for i := 0; i < n; i++ {
        sum1 += nums1[i]
        sum2 += nums2[i]
        diff1[i] = nums2[i] - nums1[i]
        diff2[i] = nums1[i] - nums2[i]
    }

    maxGain1 := maxSubarrayGain(diff1)
    maxGain2 := maxSubarrayGain(diff2)

    if sum1 + maxGain1 > sum2 + maxGain2 {
        return sum1 + maxGain1
    }
    return sum2 + maxGain2
}
```Go 特定说明：切片用于差异数组。 Kadane 算法是使用标准整数变量实现的，并且`if`语句确保正确处理最大子数组和。 由于问题限制，溢出不是问题。
