[LeetCode 问题 2336](https://leetcode.com/problems/smallest-number-in-infinite-set/)

 **难度：** 🟡 中等
 **主题：** 哈希表、设计、堆（优先级队列）、有序集

 ## 解决方案

 ## 问题理解

 该问题要求我们实现一个表示无限正整数集合的数据结构，最初包含从 1 开始的所有整数。我们需要提供两个主要操作：`popSmallest`，删除并返回集合中的最小整数，并且`addBack`，如果之前删除的整数尚不存在，则将其添加回集合中。 输入由对这些方法的顺序调用组成，输出由以下结果组成`popSmallest`来电。 

约束条件告诉我们`num`值很小，从 1 到 1000，并且操作总数也限制为 1000。这使我们能够使用可以有效处理这些范围的数据结构，而不必担心无界内存，因为集合在概念上是无限的，但只需要管理已显式弹出或添加回来的元素。 要考虑的边缘情况包括添加回从未弹出的数字，连续弹出数字以使“当前最小”的数字超出我们明确跟踪的数字范围，以及多次重新添加数字。 

## 方法

 强力方法是使用动态增长的数组或列表来维护字面上的无限集，并在每次弹出时检查最小元素。 虽然理论上是正确的，但这种方法是不可行的，因为我们无法存储无限数量的元素，并且搜索最小值会很慢。 

最佳方法利用了这样的观察：我们只需要跟踪已弹出并添加回来的数字。 我们可以为已添加回来的数字维护一个最小堆，以便`popSmallest`可以有效地检索最小的“可用”数字。 对于从未弹出的数字，我们可以简单地维护一个表示下一个最小整数的计数器。 与堆并行使用集合可以防止重复项被添加回来。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每次弹出 O(n) | O(n) | 维护完整的整数列表/集合并每次搜索最小值 |
 | 最佳 | 每次 pop/addBack | O(log k) | O(k) | 使用最小堆并设置跟踪添加回的数字，并使用计数器来记录未见过的数字 |

 ## 算法演练

 1. 初始化一个最小堆和一组来跟踪添加回的数字。 还初始化一个计数器，`current`，从 1 开始表示尚未弹出或添加回来的最小数字。 
2. 对于`popSmallest`，检查堆中是否有数字。 如果是，则从堆中弹出最小的，将其从集合中删除，然后返回。 否则，返回`current`和增量`current`1.
 3.为了`addBack`,检查数量是否小于`current`并且尚未在集合中。 如果是这样，请将其添加到集合和最小堆中。 忽略集合中已经存在或大于的数字`current`。 
4. 堆确保我们总是返回加回来的最小数字，而计数器则确保按顺序返回未见过的数字。 

这是有效的，因为下面的每个数字`current`要么已被弹出并位于堆/集合中，要么已被返回。 堆始终跟踪添加回来的下一个最小数字，从而保留顺序。 

## Python 解决方案```python
import heapq

class SmallestInfiniteSet:

    def __init__(self):
        self.current = 1
        self.heap = []
        self.added_back = set()

    def popSmallest(self) -> int:
        if self.heap:
            smallest = heapq.heappop(self.heap)
            self.added_back.remove(smallest)
            return smallest
        else:
            smallest = self.current
            self.current += 1
            return smallest

    def addBack(self, num: int) -> None:
        if num < self.current and num not in self.added_back:
            heapq.heappush(self.heap, num)
            self.added_back.add(num)
```该实现首先初始化一个计数器`current`跟踪未见过的数字，用于添加回数字的最小堆，以及防止重复的集合。`popSmallest`返回堆中的最小数字（如果可用）或下一个未见过的数字，从而增加计数器。`addBack`只压入小于的数字`current`尚未在堆/集中。 

## 解决方案```go
package main

import (
	"container/heap"
)

type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[0 : n-1]
	return x
}

type SmallestInfiniteSet struct {
	current    int
	heap       *IntHeap
	addedBack  map[int]bool
}

func Constructor() SmallestInfiniteSet {
	h := &IntHeap{}
	heap.Init(h)
	return SmallestInfiniteSet{
		current:   1,
		heap:      h,
		addedBack: make(map[int]bool),
	}
}

func (this *SmallestInfiniteSet) PopSmallest() int {
	if this.heap.Len() > 0 {
		smallest := heap.Pop(this.heap).(int)
		delete(this.addedBack, smallest)
		return smallest
	} else {
		smallest := this.current
		this.current++
		return smallest
	}
}

func (this *SmallestInfiniteSet) AddBack(num int) {
	if num < this.current {
		if _, exists := this.addedBack[num]; !exists {
			heap.Push(this.heap, num)
			this.addedBack[num] = true
		}
	}
}
```在Go中，我们定义了一个自定义的`IntHeap`使用标准堆接口。 地图用于防止重复。 其逻辑与 Python 相似，通过堆操作确保高效检索，并使用计数器跟踪未见过的数字。

 ## 边缘情况

 一个重要的边缘情况是添加回一个从未被弹出或已经大于的数字`current`。 我们的实现正确地忽略了这些数字，因为它们已经有效地存在于集合中。 另一个边缘情况反复弹出，直到`current`变大； 计数器确保我们不需要显式存储所有未见过的数字。 最后，多次添加相同的数字来测试我们的集合是否可以防止重复，这是通过`addedBack`在 Python 和 Go 实现中都设置。 这些情况确保所有允许的操作下的正确性。
