[LeetCode 问题 2351](https://leetcode.com/problems/first-letter-to-appear-twice/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、位操作、计数

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅包含小写英文字母。 我们需要返回字符串中第二次出现最早的第一个字母。 

这个细节非常重要。 问题不在于要求第一个字符稍后在某个地方重复。 相反，当我们从左到右扫描时，它会询问哪个字符首先到达第二次出现。 

例如，在`"abccbaacz"`：

 -`'a'`出现在索引处`0`,`5`， 和`6`-`'b'`出现在索引处`1`和`4`-`'c'`出现在索引处`2`,`3`， 和`7`虽然`'a'`出现早于`'c'`，第二次出现`'c'`发生在索引处`3`，它早于第二次出现`'b'`在索引处`4`和`'a'`在索引处`5`。 因此，答案是`'c'`。 

输入大小非常小：

 -`2 <= s.length <= 100`这告诉我们，即使是低效的解决方案在实践中也能发挥作用。 然而，目标是设计一个干净且最优的算法。 

该字符串仅包含小写英文字母，这意味着最多有 26 个不同的字符。 这一限制为高效计数或位操作解决方案打开了大门。 

该问题还保证至少一个字母出现多次。 这意味着我们永远不需要担心返回默认值或处理没有重复的情况。 

一些重要的边缘情况包括：

 - 立即出现的重复项，例如`"aabc"`。 
- 仅最后一个字符重复的字符串，例如`"abcdd"`。 
- 一个角色出现两次以上，例如`"abcaad"`。 
- 多个重复字符，其中最早的第二次出现确定答案。 

幼稚的实现可能会错误地返回总共出现多次的第一个字符，而不是第二次出现最早的字符。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是检查每个字符并计算它到当前位置出现的次数。 

对于每个索引`i`，我们可以扫描所有之前的索引`0`通过`i - 1`并检查当前字符之前是否出现过。 第一次找到匹配项时，我们返回该字符。 

这是有效的，因为从左到右扫描时遇到的第一个重复字符正是第二次出现最早的字符。 

然而，这种方法使用嵌套循环。 对于每个字符，我们可能会扫描所有先前的字符，从而导致时间复杂度为二次方。 

尽管输入大小足够小，可以通过，但这并不是最有效或最优雅的解决方案。 

### 最佳方法

 关键的观察是我们只需要知道我们以前是否见过某个角色。 

当我们从左到右扫描字符串时：

 - 如果当前字符未被看到，我们会记录它。 
- 如果当前字符已经被看到，那么这是它的第二次出现，并且由于我们是从左到右扫描，所以它一定是迄今为止遇到的最早的第二次出现。 

哈希集是一个自然的选择，因为它提供了平均值`O(1)`查找和插入操作。 

由于只有小写英文字母，我们还可以使用固定大小的布尔数组或位掩码。 然而，集合使实现变得简单且可读。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 将每个字符与所有先前的字符进行比较 |
 | 最佳| O(n) | O(1) | O(1) | 使用一组来跟踪以前见过的字符 |

 尽管最优解决方案在技术上使用了额外的空间，但该空间以 26 个小写字母为界，因此它实际上是恒定的。 

## 算法演练

 1. 创建一个空集，名为`seen`。 

该集合将存储我们在扫描字符串时迄今为止遇到的所有字符。 
2. 从左到右一次遍历字符串一个字符。 

从左到右的遍历至关重要，因为在这次扫描期间遇到的第一个重复字符保证是最早的第二次出现。 
3. 对于每个字符，检查它是否已经存在于`seen`。 

- 如果是，立即返回该字符。 
- 如果没有，请将其添加到集合中。 
4. 继续，直到找到重复的字符。 

该问题保证至少存在一个重复字符，因此算法在循环结束之前始终会返回一个值。 

### 为什么它有效

 该算法保持不变式`seen`准确包含当前索引之前遇到的字符。 

当我们遇到一个已经存在的角色时`seen`，我们知道这是第二次出现。 由于我们从左到右扫描，这是迄今为止处理的所有字符中最早的第二次出现。 因此，我们遇到的第一个重复字符就是正确答案。 

## Python 解决方案```python
class Solution:
    def repeatedCharacter(self, s: str) -> str:
        seen = set()

        for char in s:
            if char in seen:
                return char

            seen.add(char)

        return ""
```该解决方案首先初始化一个名为`seen`。 该集合记录了迄今为止遇到的所有字符。 

该循环遍历字符串中的每个字符。 对于每个字符，代码首先检查它是否已存在于集合中。 

如果该字符已经存在，则意味着我们已经找到它的第二次出现，因此我们立即返回它。 

否则，我们将字符添加到集合中并继续扫描。 

决赛`return ""`包含语句只是为了满足功能完整性。 根据问题约束，执行将始终从循环内部返回，因为输入保证包含重复字符。 

## 解决方案```go
func repeatedCharacter(s string) byte {
    seen := make(map[byte]bool)

    for i := 0; i < len(s); i++ {
        if seen[s[i]] {
            return s[i]
        }

        seen[s[i]] = true
    }

    return 0
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 使用的不是 Python 集，而是`map[byte]bool`跟踪以前见过的角色。 由于输入仅由小写英文字母组成，因此将字符视为`byte`价值观是高效且直接的。 

该函数返回一个`byte`因为这是问题陈述中所需的签名。 

决赛`return 0`由于至少存在一个重复字符的保证问题，从技术上讲是无法访问的。

 ## 边缘情况

 一种重要的边缘情况是重复字符立即出现，例如`"aabc"`。 有缺陷的实现可能会在找到第一个重复项后错误地继续扫描。 该解决方案在检测到第二次出现时立即返回，因此它正确返回`'a'`。 

另一个重要的情况是多个字符重复，但它们的第二次出现发生在不同的位置。 例如，在`"abccbaacz"`， 两个都`'a'`和`'b'`重复，但是`'c'`首先到达第二次出现。 从左到右的扫描保证了最早的第二次出现被正确返回。 

第三种边缘情况涉及字符出现两次以上，例如`"aaab"`或者`"abcaad"`。 该算法不关心总共存在多少次。 它只检查当前字符之前是否已经出现过。 因此，无论字符串中后面是否有其他重复，都会正确检测到第二次出现。 

另一个微妙的情况是最小有效输入大小，例如`"zz"`。 第一个字符被添加到集合中，第二个字符立即触发重复检测逻辑。 这证实了该实现正确处理了尽可能小的输入。
