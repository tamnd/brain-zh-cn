 **难度：** 🟡 中等
 **主题：** 数组、动态规划、回溯、位操作、位掩码

 ## 解决方案

 ## 问题理解

 该问题要求我们将一组饼干袋分发给`k`以便将分配的**不公平**降到最低。 在这里，不公平性被定义为**任何单个孩子收到的 cookie 的最大总数**。 

输入由一个数组组成`cookies`在哪里`cookies[i]`代表cookies的数量`i-th`包和一个整数`k`代表孩子的数量。 每个饼干袋必须完全分配给一个孩子，因此不允许分裂。 目标是计算分发所有袋子后任何孩子收到的 cookie 最大总和的最小可能值。 

约束表明`cookies.length`很小（最多 8 个），这表明穷举或组合方法是可行的。 每个饼干袋最多可容纳`10^5`饼干，以及`k`可以小至 2 个，也可以大至饼干袋的数量。 

重要的边缘情况包括儿童数量等于行李数量的情况，一个孩子最终可能会携带多个高价值行李，或者所有行李都有相同的饼干。 

## 方法

 一种强力方法是考虑将每个 cookie 包的 **每一种可能的分配** 分配给其中一个`k`孩子们。 由于每个袋子都可以独立地交给任何一个孩子，因此有`k^n`可能的分配，其中`n`是饼干袋的数量。 对于每项作业，我们都会计算每个孩子收到的 cookie 总数并跟踪最大值。 所有这些最大值中的最小值就是答案。 虽然这种方法是正确的，但它呈指数级增长，对于规模更大的应用来说变得不切实际。`n`（尽管`n <= 8`让它在这里易于管理）。 

优化的关键见解是**回溯和修剪**。 我们递归地将袋子分配给孩子，同时维护每个孩子当前 cookie 总数的数组。 如果在任何时候当前的最大值超过已知的最小不公平性，我们可以修剪该分支，因为继续无法改善结果。 这避免了探索所有`k^n`实践中的组合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k^n * n) | O(k^n * n) | O(n) | 尝试给孩子们分配所有的袋子，每次计算最大不公平性 |
 | 最优（回溯与修剪）| 最坏情况下为 O(k^n)，实践中更快 | O(k + n) | 根据当前最大值进行剪枝递归分配包 |

 ## 算法演练

 1.初始化一个数组`totals`长度`k`用零来跟踪每个孩子当前的 cookie 总数。 
2. 定义递归函数`dfs(index)`在哪里`index`代表当前要分配的 cookie bag。 
3.如果`index == n`，所有行李均已分配。 计算最大值`totals`如果全局最小不公平性更小，则更新它。 
4. 对于每个孩子`i`从 0 到`k-1`， 分配`cookies[index]`给孩子`i`并更新`totals[i]`。 
5. 在递归之前，检查是否`totals[i]`已经大于或等于当前的最小不公平性。 如果是这样，请跳过此分支。 
6. 递归到`dfs(index + 1)`。 
7. 递归后，通过删除回溯`cookies[index]`从`totals[i]`。 
8. 对所有儿童继续此操作，探索所有可行的分布。 

为什么有效：回溯方法探索所有可行的分布，同时修剪无法改进解决方案的路径。 这确保我们发现最小的不公平。 递归树的每个叶子对应于所有cookie袋的完整分配。 

## Python 解决方案```python
from typing import List

class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        n = len(cookies)
        totals = [0] * k
        self.min_unfairness = float('inf')

        def dfs(index: int):
            if index == n:
                self.min_unfairness = min(self.min_unfairness, max(totals))
                return
            for i in range(k):
                totals[i] += cookies[index]
                if totals[i] < self.min_unfairness:
                    dfs(index + 1)
                totals[i] -= cookies[index]
                if totals[i] == 0:
                    break

        dfs(0)
        return self.min_unfairness
```此 Python 解决方案使用递归深度优先搜索。 这`totals`数组记录每个孩子拥有的 cookie 总数。 这`if totals[i] == 0: break`line 是一种优化，可以避免多个子项具有零 cookie 的冗余对称分配。 

## 解决方案```go
func distributeCookies(cookies []int, k int) int {
    n := len(cookies)
    totals := make([]int, k)
    minUnfairness := 1 << 60

    var dfs func(int)
    dfs = func(index int) {
        if index == n {
            maxTotal := 0
            for _, t := range totals {
                if t > maxTotal {
                    maxTotal = t
                }
            }
            if maxTotal < minUnfairness {
                minUnfairness = maxTotal
            }
            return
        }
        for i := 0; i < k; i++ {
            totals[i] += cookies[index]
            if totals[i] < minUnfairness {
                dfs(index + 1)
            }
            totals[i] -= cookies[index]
            if totals[i] == 0 {
                break
            }
        }
    }

    dfs(0)
    return minUnfairness
}
```在 Go 中，主要区别在于切片的使用`totals`和无穷大的整数常量。 递归逻辑与Python 相同。

 ## 边缘情况

 一种重要的边缘情况是孩子的数量等于饼干袋的数量。 每个孩子只收到一个袋子，因此最小的不公平性是该袋子中的最大值`cookies`大批。 该算法自然地处理这个问题，因为递归树中的每个叶子都会为每个子节点分配一个包。
