[LeetCode 2312 题](https://leetcode.com/problems/ sell-pieces-of-wood/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、记忆化

 ## 解决方案

 ## 问题理解

 问题提出了一块尺寸为的矩形木头`m x n`以及某些子矩形的具体价格列表。 中的每个条目`prices`大批，`[hi, wi, pricei]`，表示一块木头的高度`hi`和宽度`wi`可以卖`pricei`美元。 您可以在一块的整个高度或宽度上进行任意数量的水平或垂直切割，以将其分成更小的块。 关键是木片**不能旋转**，也就是说`2 x 3`一块不等于一个`3 x 2`片。 切割完成后，您可以根据价格表任意出售一块，并且可以出售多块相同的块。 

目标是**最大化从一块大小的木头获得的总金钱**`m x n`。 

输入的边界为`1 <= m, n <= 200`直至`2 * 10^4`价格条目。 这表明，由于指数分裂的可能性，没有缓存的强力递归方法可能会太慢。 该问题保证了每个`(hi, wi)`配对是不同的，所有价格都是正整数。 

重要的优势考虑因素包括：如果一件作品与定价形状完全匹配，则出售它可能是最佳选择； 小尺寸或主要尺寸可能会限制切割选择； 有些作品可能不会直接出售，但可以用作最佳切割的一部分。 

## 方法

 **暴力方法**将递归地尝试对一块木头的每一种可能的垂直和水平切割，计算每块所得的最大收入，并将结果结合起来。 虽然正确，但由于指数组合，这种方法很快就变得不可行，特别是因为`m`和`n`最多可达 200 个。 

**优化的关键见解**是问题表现出**重叠的子问题**。 子矩形的最大收入仅取决于其尺寸和价目表。 因此，我们可以使用**带记忆的动态规划**，存储每个的最大收入`(height, width)`子矩形。 通过这样做，每个子问题最多计算一次，大大减少了冗余计算。 

我们维护一个记忆表映射`(height, width)`至可获得的最高价格。 对于每个矩形，我们首先考虑直接出售它是否有利可图，然后递归地尝试所有水平和垂直切割，结合子结果找到最大值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(1) | O(1) | 指数递归分裂； m、n 不超过 200 | 不可行
 | 最优（DP + 记忆）| O(m * n * (m + n)) | O(m * n * (m + n)) | O(m * n + p) | 计算每个子矩形一次； 尝试所有水平和垂直切割； p = 价格数量 |

 ## 算法演练

 1. **预处理价格**：将价格存储在哈希映射或字典中，键为`(height, width)`用于恒定时间查找。 如果矩形与列出的形状匹配，则可以快速访问该矩形的价格。 
2. **初始化Memoization Table**：创建字典`dp`在哪里`dp[(h, w)]`将存储高度矩形可获得的最大收入`h`和宽度`w`。 
3. **定义递归函数**：实现一个函数`dfs(h, w)`返回尺寸矩形的最大收入`h x w`。 
4. **基本情况**：如果`(h, w)`位于价格图中，将初始最大收入设置为`price_map[(h, w)]`。 否则，从零开始。 
5. **Try Horizontal Cuts**: For every possible horizontal cut`i`从`1`到`h-1`，将矩形分割成`(i x w)`和`(h-i x w)`，并递归计算他们的收入。 更新最大收入。 
6. **尝试垂直切割**：对于每种可能的垂直切割`j`从`1`到`w-1`，将矩形分割成`(h x j)`和`(h x (w-j))`，递归计算收入，并更新最大收入。 
7. **Memoize and Return**：将计算出的最大收入存储在`dp[(h, w)]`并归还它。 
8. **最终通话**：首先通话`dfs(m, n)`计算原始木材的最大收入。 

**为什么有效**：递归保证考虑所有可能的切割组合。 记忆化确保每个子矩形仅求解一次，从而提供有效的解决方案。 由于矩形的价格仅取决于其尺寸，因此子问题分解满足最优子结构。 

## Python 解决方案```python
from typing import List, Tuple
from functools import lru_cache

class Solution:
    def sellingWood(self, m: int, n: int, prices: List[List[int]]) -> int:
        price_map = {(h, w): price for h, w, price in prices}

        from functools import lru_cache

        @lru_cache(None)
        def dfs(h: int, w: int) -> int:
            max_val = price_map.get((h, w), 0)
            
            # Try horizontal cuts
            for i in range(1, h):
                max_val = max(max_val, dfs(i, w) + dfs(h - i, w))
            
            # Try vertical cuts
            for j in range(1, w):
                max_val = max(max_val, dfs(h, j) + dfs(h, w - j))
            
            return max_val

        return dfs(m, n)
```**解释**：我们首先绘制 O(1) 访问的价格。 这`dfs`函数递归地探索矩形的所有切割选项。 使用`lru_cache`实现记忆化，防止子矩形的重新计算。 该函数返回所请求维度的最大可能收入。 

## 解决方案```go
func sellingWood(m int, n int, prices [][]int) int64 {
    priceMap := make(map[[2]int]int64)
    for _, p := range prices {
        priceMap[[2]int{p[0], p[1]}] = int64(p[2])
    }

    memo := make(map[[2]int]int64)

    var dfs func(h, w int) int64
    dfs = func(h, w int) int64 {
        key := [2]int{h, w}
        if val, ok := memo[key]; ok {
            return val
        }
        maxVal := priceMap[key]

        for i := 1; i < h; i++ {
            maxVal = max(maxVal, dfs(i, w)+dfs(h-i, w))
        }
        for j := 1; j < w; j++ {
            maxVal = max(maxVal, dfs(h, j)+dfs(h, w-j))
        }

        memo[key] = maxVal
        return maxVal
    }

    var max func(a, b int64) int64
    max = func(a, b int64) int64 {
        if a > b {
            return a
        }
        return b
    }

    return dfs(m, n)
}
```**Go 特定注释**：我们使用带有数组键的映射`[2]int`来表示矩形尺寸。 所有整数都被转换为`int64`以避免溢出。 记忆化是通过显式实现的`memo`地图。 

## 工作示例

 **示例 1：m = 3，n = 5，价格 = [[1,4,2],[2,2,7],[2,1,3]]**

 | 步骤| 运营| 收入计算| 最大收入|
 | ---| ---| ---| ---|
 | 初始| 没有削减| 最大(0, 价格.get(3,5)=0) | 0 |
 | 水平切割 2 | 分割 2x5 + 1x5 | dfs(2,5)+dfs(1,5) | dfs(2,5)+dfs(1,5) | 19 | 19
 | 垂直切割 2 | 分割 3x2 + 3x3 | dfs(3,2)+dfs(3,3) | dfs(3,2)+dfs(3,3) | 18 | 18
 | 水平切割 1 | 分割 1x5 + 2x5 | dfs(1,5)+dfs(2,5) | dfs(1,5)+dfs(2,5) | 19 | 19
 | 4 | 垂直切割 分割 3x4 + 3x1 | dfs(3,4)+dfs(3,1) | dfs(3,4)+dfs(3,1) | 18 | 18

 返回的最大收入：19

 **示例 2：m = 4，n = 6，价格 = [[3,2,10],[1,4,2],[4,1,3]]**

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(m * n * (m + n)) | O(m * n * (m + n)) | 每个子矩形计算一次。 对于每个子矩形，我们最多尝试`h-1`水平和`w-1`垂直切割。 |
 | 空间| O(m * n + p) | 记忆表存储每个子矩形的结果，以及价格图`p`条目。 |

 推理：记忆确保每个`(h, w)`只解决一次，并且尝试所有切割在高度和宽度上花费线性时间。
