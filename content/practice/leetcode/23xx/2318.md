[LeetCode 问题 2318](https://leetcode.com/problems/number-of-distinct-roll-sequences/)

 **难度：** 🔴难
 **主题：** 动态规划、记忆化

 ## 解决方案

 ## 问题理解

 问题是要求我们计算不同长度的骰子序列的总数`n`满足两个约束：任意两个连续掷骰子的最大公约数 (GCD) 必须是`1`，并且序列中的任何重复值必须至少由两个卷分隔开。 换句话说，如果一个值出现在索引处`i`，它不能出现在索引中`i+1`或者`i+2`。 

输入`n`表示掷骰子的次数，输出为有效序列数模`10^9 + 7`。 自从`n`可以大到`10^4`，我们无法显式生成所有序列，因为序列总数呈指数增长`6^n`。 

重要的边缘情况包括较小的值`n`例如`1`和`2`，以及重复数字或 GCD 约束可能排除大部分序列的情况。 

## 方法

 暴力方法将生成所有`6^n`可能的序列并根据两个约束检查每个序列的有效性。 虽然这会产生正确的答案，但对于大型计算来说这是不可行的`n`因为`6^10000`是一个天文数字。 

最佳解决方案的关键见解是，该问题可以表述为**动态规划问题**，其中我们根据最后滚动的两个数字来跟踪序列。 这是有效的，因为约束仅取决于最后两个数字：GCD 约束取决于前一个数字，而“2 的间隙”约束取决于最后两个位置。 通过记住结果`(previous_roll, pre_previous_roll, remaining_length)`，我们避免了冗余计算，可以有效地解决问题。

 ## 算法演练

 1.定义递归函数`dp(prev, prev2, remaining)`表示有效长度序列的数量`remaining`最后一卷在哪里`prev`倒数第二卷是`prev2`。 如果`prev`或者`prev2`是`0`，将其视为“没有上一卷”。 
2. 基本情况：如果`remaining`是`0`， 返回`1`因为空的延续是有效的序列。 
3.对于每一个可能的`next_roll`从`1`到`6`，检查两个约束：

 - 如果`prev`非零，确保`gcd(prev, next_roll) == 1`。 
- 确保`next_roll`不等于`prev`或者`prev2`满足两个间隙规则。 
4. 如果满足约束条件，则递归计算`dp(next_roll, prev, remaining - 1)`并累加计数模`10^9 + 7`。 
5. 使用 memoization 来存储结果`(prev, prev2, remaining)`以避免重新计算。 
6. 调用递归函数`prev=0`,`prev2=0`， 和`remaining=n`。 

**为什么有效**：该算法正确枚举所有有效序列，而不会生成无效序列，并且记忆化确保每个子问题仅计算一次。 不变量是`prev`和`prev2`始终表示部分序列中的最后两个数字，保持约束。 

## Python 解决方案```python
from math import gcd
from functools import lru_cache

class Solution:
    def distinctSequences(self, n: int) -> int:
        MOD = 10**9 + 7

        @lru_cache(None)
        def dp(prev: int, prev2: int, remaining: int) -> int:
            if remaining == 0:
                return 1
            count = 0
            for next_roll in range(1, 7):
                if next_roll == prev or next_roll == prev2:
                    continue
                if prev != 0 and gcd(prev, next_roll) != 1:
                    continue
                count = (count + dp(next_roll, prev, remaining - 1)) % MOD
            return count

        return dp(0, 0, n)
```Python 解决方案使用`lru_cache`用于记忆，减少重复计算。 嵌套函数`dp`跟踪最后两卷和剩余的序列长度。 for 循环迭代可能的骰子滚动，并在递归之前应用 GCD 和两间隙约束。 模运算确保我们不会超出整数限制。 

## 解决方案```go
package main

func gcd(a, b int) int {
	for b != 0 {
		a, b = b, a%b
	}
	return a
}

func distinctSequences(n int) int {
	const MOD = 1_000_000_007

	type key struct {
		prev, prev2, rem int
	}

	memo := make(map[key]int)

	var dp func(prev, prev2, rem int) int
	dp = func(prev, prev2, rem int) int {
		if rem == 0 {
			return 1
		}
		k := key{prev, prev2, rem}
		if val, exists := memo[k]; exists {
			return val
		}
		count := 0
		for next := 1; next <= 6; next++ {
			if next == prev || next == prev2 {
				continue
			}
			if prev != 0 && gcd(prev, next) != 1 {
				continue
			}
			count = (count + dp(next, prev, rem-1)) % MOD
		}
		memo[k] = count
		return count
	}

	return dp(0, 0, n)
}
```在 Go 中，我们使用`map`用于由代表最后两卷和剩余长度的结构键控的记忆。 Go 没有像 Python 那样的内置装饰器，因此我们显式存储计算值。 其余逻辑反映了 Python 版本。 

## 工作示例

 **示例 1：n = 4**

 初始调用：`dp(0, 0, 4)`我们迭代`next_roll`从 1 到 6。假设`next_roll = 1`：

- 称呼`dp(1, 0, 3)`- 下一个，`next_roll = 2`满足`gcd(1, 2) = 1`并且不等于 1 或 0
 - 打电话`dp(2, 1, 2)`- 继续递归，通过约束过滤无效序列

 使用记忆化完全枚举所有有效序列后，我们得到的总计数`184`。 

**示例 2：n = 2**

 初始调用：`dp(0, 0, 2)`- 选择`next_roll = 1`， 称呼`dp(1, 0, 1)`- 下一次掷骰可以是 2, 3, 4, 5（不是 1，因为它会违反二的间隙），只允许 GCD=1
 - 有效序列总和，总计数 =`22`。

 **单次掷骰 (n = 1)**：仅发生一次骰子掷骰。 1-6 中的任意一卷均有效。 执行正确返回`6`因为不存在相邻的 GCD 或两间隙约束。
