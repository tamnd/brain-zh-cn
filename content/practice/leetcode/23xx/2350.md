## 问题理解

 该问题要求我们确定在给定的骰子列表中**无法**找到的最短骰子序列的长度。 我们得到一个数组`rolls`长度`n`代表滚动的结果`k`单面模具`n`次，和一个整数`k`代表骰子的面数。 

简单来说，想象一下长度不断增加的所有可能的骰子序列。 我们想要找到第一个长度`len`至少存在一个长度为一卷的序列`len`**没有出现在任何地方`rolls`**。 这个长度就是答案。 

约束表明`n`和`k`可以大到 10^5。 因此，生成所有可能的卷序列是不可行的，因为序列的数量随着长度呈指数增长（`k^len`）。 这需要一种不依赖于暴力枚举的巧妙方法。 

重要的边缘情况包括：

 - 当`rolls`不包含来自的每个数字`1`到`k`，答案是`1`，因为长度为 1 的序列已经不可能了。 
- 什么时候`rolls`包含每个数字的多次出现，算法应该计算有多少**完整的集合`1..k`** 可以形成并从中导出最小不可能长度。 
- 大的`k`值相对于`n`可能会限制可以出现的完整序列的数量。 

## 方法

 ### 暴力方法

 一种简单的方法会尝试生成长度为 1、然后为 2 等的所有序列，并检查每个序列是否作为子序列出现在`rolls`。 对于每个长度`len`，我们需要枚举所有`k^len`序列并验证它们的存在。 虽然这最终会给出正确的答案，但对于大的情况来说**计算不可行**`k`和`n`因为序列的数量呈指数增长。 

### 最佳方法

 关键的见解是，最短的不可能序列长度取决于有多少**完整的集合`1..k`** 出现在`rolls`。 每次我们看到来自的所有数字`1`到`k`至少一次，我们知道当前长度的所有序列都存在。 一旦我们不能形成完整的集合，下一个序列长度就变得不可能。 

这意味着我们可以迭代`rolls`同时保留**当前不完整的集合**中看到的一组数字。 每次集合达到大小时`k`，我们知道一整套`1..k`存在，因此我们重置该集合并增加所看到的完整集合的计数。 最后，答案是完整组数加1。 

这种方法是线性的`n`并且最多使用`O(k)`额外的空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k^len * n) | O(k^len * n) | O(k^len) | O(k^len) | 枚举所有序列，对于大输入不可行 |
 | 最佳| O(n) | O(k) | 跟踪卷中的数字组以查找完整的序列 |

 ## 算法演练

 1.初始化一个空集`current_set`跟踪哪些号码来自`1..k`在当前的不完整集中已经看到。 
2. 初始化计数器`complete_sets`为零，代表全套的数量`1..k`看到了。 
3. 迭代每一卷`r`在`rolls`：

 1.添加`r`到`current_set`。 
2.如果`current_set`包含所有`k`数字、增量`complete_sets`并重置`current_set`清空。 
4.处理完所有的卷后，最短不可能序列的长度为`complete_sets + 1`。 

**为什么有效：** 每个完整集合都保证当前长度的所有序列都存在。 一旦我们不能形成另一个完整的集合，长度的序列`complete_sets + 1`是不可能的。 这个不变量确保了正确性，而无需枚举序列。 

## Python 解决方案```python
from typing import List

class Solution:
    def shortestSequence(self, rolls: List[int], k: int) -> int:
        current_set = set()
        complete_sets = 0
        
        for r in rolls:
            current_set.add(r)
            if len(current_set) == k:
                complete_sets += 1
                current_set.clear()
        
        return complete_sets + 1
```**说明：**`current_set`跟踪唯一的号码，直到我们看到所有号码`1..k`。 当检测到完整的集合时，我们增加`complete_sets`并重置设置。 最后，答案是`complete_sets + 1`，表示第一个无法形成的序列长度。 

## 解决方案```go
func shortestSequence(rolls []int, k int) int {
    currentSet := make(map[int]bool)
    completeSets := 0
    
    for _, r := range rolls {
        currentSet[r] = true
        if len(currentSet) == k {
            completeSets++
            currentSet = make(map[int]bool)
        }
    }
    
    return completeSets + 1
}
```**说明：** Go 解决方案镜像了 Python 逻辑，使用映射来模拟集合。 每次地图达到大小时`k`，我们增加`completeSets`并重置地图。
