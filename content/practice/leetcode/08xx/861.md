[LeetCode 861 题](https://leetcode.com/problems/score-after-flipping-matrix/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、位操作、矩阵

 ## 解决方案

 ## 问题理解

 该问题提供了一个`m x n`二元矩阵，`grid`，其中每个元素是`0`或者`1`。 您可以执行**移动**，其中包括选择任何行或列并翻转其所有值 - 翻转每个`0`变成一个`1`和每一个`1`变成一个`0`。 目标是最大化矩阵的**分数**。 矩阵中的每一行都被解释为二进制数，最左边的元素是最高有效位。 总分是以此方式解释的所有行值的总和。 

输入保证矩阵维度很小（`1 <= m, n <= 20`）并且所有条目都是有效的二进制值。 这些约束表明，穷举方法在某种意义上是可行的，但可能的行/列翻转 (2^(m+n)) 的指数增长使得朴素的强力方法效率低下。 

重要的边缘情况包括具有单个元素的矩阵、所有元素都存在的矩阵`0`或全部`1`，以及具有单行或单列的矩阵。 该问题保证至少一行一列，因此不需要空矩阵处理。 

本质上，我们想要一种通过巧妙的行和列翻转来最大化每行的二进制表示的策略。 

## 方法

 **暴力方法**将涉及探索行和列翻转的每种组合。 对于每个组合，您将计算结果矩阵，将每一行解释为二进制数，并对总分求和。 这保证了正确性，因为它确实测试了所有可能性，但时间复杂度是`O(2^(m+n) * m * n)`- 太大了`m, n <= 20`。 

**最佳方法**依赖于两个关键的观察结果。 首先，行中最左边的位对该行的数值贡献最大。 因此，我们应该翻转第一个元素所在的行`0`以确保最高位是`1`。 其次，在确保第一列全部都是之后`1`s，我们可以逐列最大化剩余位。 对于每一列，如果`0`s 超过数量`1`s，我们翻转该列。 这种贪婪方法之所以有效，是因为翻转一列只会影响列的数量`1`沙`0`s，并且我们总是选择最大化每个位贡献的排列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m+n) * m * n) | O(2^(m+n) * m * n) | O(m*n) | 尝试所有行/列翻转组合 |
 | 最佳| O(m*n) | O(1) | O(1) | 基于最高有效位和列多数的贪婪翻转 |

 ## 算法演练

 1. **确保第一列全部为 1**。 迭代每一行。 如果一行的第一个元素是`0`，翻转整行。 这保证了每行的最高有效位贡献最大。 
2. **最大化剩余列**。 对于从第二个到最后一个的每一列，计算`1`s。 如果数量`0`s 超过数量`1`s，翻转该列以增加总分。 
3. **计算总分**。 对于每一行，将其解释为二进制数并对结果求和。 

**为什么有效**：翻转行可确保所有行的最高有效位最大化。 贪婪地翻转列可确保每个剩余位都做出最大贡献，而不会违反已经建立的第一列。 每个决策都是局部且独立的，因为翻转列不会影响第 1 步之后最左边的列，这保证了最优性。 

## Python 解决方案```python
from typing import List

class Solution:
    def matrixScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        # Step 1: Ensure first column is all ones
        for i in range(m):
            if grid[i][0] == 0:
                for j in range(n):
                    grid[i][j] ^= 1  # Flip the row
        
        # Step 2: Maximize remaining columns
        for j in range(1, n):
            ones = sum(grid[i][j] for i in range(m))
            if ones < m - ones:
                for i in range(m):
                    grid[i][j] ^= 1  # Flip the column
        
        # Step 3: Compute total score
        total_score = 0
        for row in grid:
            value = 0
            for bit in row:
                value = (value << 1) | bit
            total_score += value
        
        return total_score
```此实现首先翻转任何具有前导的行`0`确保最高有效位是`1`。 然后它迭代每一列，如果有更多则翻转它`0`比`1`s 最大化总和。 最后，它使用位移位计算每行的二进制值，将总分相加得出最终分数。 

## 解决方案```go
func matrixScore(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    
    // Step 1: Ensure first column is all ones
    for i := 0; i < m; i++ {
        if grid[i][0] == 0 {
            for j := 0; j < n; j++ {
                grid[i][j] ^= 1
            }
        }
    }
    
    // Step 2: Maximize remaining columns
    for j := 1; j < n; j++ {
        ones := 0
        for i := 0; i < m; i++ {
            ones += grid[i][j]
        }
        if ones < m - ones {
            for i := 0; i < m; i++ {
                grid[i][j] ^= 1
            }
        }
    }
    
    // Step 3: Compute total score
    total := 0
    for i := 0; i < m; i++ {
        value := 0
        for j := 0; j < n; j++ {
            value = (value << 1) | grid[i][j]
        }
        total += value
    }
    
    return total
}
```Go 解决方案反映了 Python 逻辑，使用整数算术和按位异或进行翻转。 与 Python 不同，Go 需要在循环中显式索引，并且`sum`必须手动计算。 

## 工作示例

 **示例1：`grid = [[0,0,1,1],[1,0,1,0],[1,1,0,0]]`**

 第 1 步之后（翻转带前导 0 的行）：

 | 行| 二进制 |
 | ---| ---|
 | [1,1,0,0]| 12 | 12
 | [1,0,1,0] | 10 | 10
 | [1,1,0,0]| 12 | 12

 步骤 2（最大化列）：

 - 第 1 列已经全部为 1。 
- 第 2 列：ones=2，zeros=1 → 保留
 - 第 3 列：ones=1，zeros=2 → 翻转 → 列变为`[1,0,1]`- 第 4 列：ones=1，zeros=2 → 翻转 → 列变为`[1,1,1]`最终矩阵：

 | 行| 二进制 |
 | ---| ---|
 | [1,1,1,1]| 15 | 15
 | [1,0,0,1] | 9 |
 | [1,1,1,1]| 15 | 15

 总计 = 15+9+15 = 39

 **示例2：`grid = [[0]]`**

 - 翻转行→`[1]`→ 分数 = 1

 | 测量 | 复杂性 | 说明|
