 # LeetCode 863 - 二叉树中所有节点距离 K

 ## 问题理解

 这个问题给了我们一个二叉树的根，该树内的一个特定目标节点，以及一个整数`k`。 我们的任务是返回与目标节点距离恰好为的所有节点值`k`。 

重要的细节是距离的定义。 两个节点之间的距离是连接它们的最短路径中的边数。 在二叉树中，我们通常从父节点向下移动到子节点，但距离计算可能也需要向上移动。 例如，一个节点是`k`距目标的步骤可能是：

 - 在目标的左子树中
 - 在目标的右子树中
 - 通过父链接位于目标上方
 - 在先向上到达的兄弟子树中

 这意味着在解决这个问题时，树实际上表现得像无向图。 

输入包括：

 -`root`，二叉树的根节点
 -`target`, a reference to one node in the tree
 -`k`，所需距离

 The output should be a list of node values whose shortest path distance from`target`等于`k`。 顺序并不重要。 

限制相对较小：

 - 最多500个节点
 - 节点值是唯一的
 -`k`最大可达 1000

 节点值的唯一性很有帮助，因为它使我们能够清楚地识别节点。 小树大小意味着可以采用多种方法，但我们仍然需要一个高效且干净的解决方案。 

一些边缘情况很重要：

 -`k = 0`，其中答案应该只是目标节点本身
 - 单节点树
 -`k`大于树的高度，这应该返回一个空列表
 - The target being the root node
 - The target being a leaf node
 - 只能通过向上移动才能到达的节点，然后再向下移动

 仅从目标向下搜索的简单实现将会失败，因为有效节点可能通过父路径存在。 

## 方法

 ### 蛮力方法

 暴力解决方案会将树中的每个节点视为候选答案。 

对于每个节点：

 1. 计算该节点到目标的距离
 2. If the distance equals`k`，将其包含在结果中

 为了计算距离，我们可以重复搜索树中节点之间的路径。 一种常见的暴力方法是：

 - 对于每个节点，从根运行 DFS 以查找到目标的路径
 - 运行另一个DFS来查找当前节点的路径
 - 比较路径以计算距离

 这是可行的，因为两个节点之间的距离可以从它们的最低公共祖先导出。 

然而，这是低效的。 如果有`n`节点和每个距离计算需要`O(n)`，总复杂度变为`O(n²)`。 

虽然`n <= 500`是可以管理的，但这种方法不必要地昂贵和复杂。 

### 最佳方法

 关键的见解是，如果我们可以向下和向上移动，树中的距离问题就会变得容易得多。 

普通二叉树节点仅包含对其子节点的引用。 它不包含指向其父级的指针。 因此，我们首先通过记录父关系将树转化为无向图结构。 

一旦每个节点都知道其父节点，每个节点就可以向三个方向移动：

 - 左孩子
 - 右孩子
 - 家长

 那时，问题就变成了标准的广度优先搜索问题：

 - 从目标节点启动BFS
 - 逐级扩展
 - 恰好之后`k`级别，当前队列中的所有节点都是答案

 BFS 是理想的，因为它自然地按距离递增的顺序探索节点。

 ## 算法演练

 ### 第 1 步：建立父参考

 使用 DFS 或 BFS 遍历树，并将每个节点的父节点存储在哈希图中。 

我们使用哈希映射是因为树节点自然不包含父指针。 这允许在遍历期间恒定时间访问节点的父节点。 

例如：```
parent[5] = 3
parent[6] = 5
parent[2] = 5
```根节点没有父节点。 

### 步骤 2：从目标节点初始化 BFS

 创建BFS队列并插入目标节点。 

还创建一个`visited`设置为防止重新访问节点。 这很重要，因为一旦添加父链接，树的行为就像无向图，并且循环成为可能。 

如果没有访问集，遍历可能会在父级和子级之间无休止地跳跃。 

### 步骤3：逐级处理BFS

 每个 BFS 级别代表距目标一定距离的节点。 

对于从队列中删除的每个节点：

 - 探索它的左孩子
 - 探索它的右孩子
 - 探索其父级

 任何未访问的邻居都会添加到队列中。 

处理完一整层后，增加当前距离。 

### 步骤 4：当距离相等时停止`k`一旦 BFS 深度达到`k`，当前队列中的每个节点正好是距离`k`远离目标。 

提取它们的值并返回它们。 

### 为什么它有效

 广度优先搜索保证按照距起始节点距离递增的顺序来探索节点。 由于我们使用父引用将树转换为无向图，因此 BFS 只探索每个可到达节点一次。 因此，当BFS达到水平时`k`，该级别中的所有节点都是精确距离`k`从目标。 

## Python 解决方案```python
from collections import deque
from typing import List, Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def distanceK(
        self,
        root: TreeNode,
        target: TreeNode,
        k: int
    ) -> List[int]:

        parent_map = {}

        def build_parent_map(node: Optional[TreeNode], parent: Optional[TreeNode]) -> None:
            if not node:
                return

            parent_map[node] = parent

            build_parent_map(node.left, node)
            build_parent_map(node.right, node)

        build_parent_map(root, None)

        queue = deque([target])
        visited = {target}

        current_distance = 0

        while queue:
            if current_distance == k:
                return [node.val for node in queue]

            level_size = len(queue)

            for _ in range(level_size):
                current_node = queue.popleft()

                neighbors = [
                    current_node.left,
                    current_node.right,
                    parent_map[current_node]
                ]

                for neighbor in neighbors:
                    if neighbor and neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)

            current_distance += 1

        return []
```解决方案首先构建父映射。 此步骤将树转换为类似图的结构，其中每个节点都可以向上和向下移动。 

递归辅助函数遍历整个树并记录每个节点的父节点。 根映射到`None`因为它没有父母。 

接下来，BFS从目标节点开始。 队列存储当前距离级别要处理的节点，而`visited`set 防止重新访问节点。 

在BFS循环内部，我们首先检查当前级别是否对应于距离`k`。 如果是，则当前队列中的每个节点都属于答案。 

否则，我们处理整个级别并通过探索所有有效邻居向外扩展：

 - 左孩子
 - 右孩子
 - 家长

 处理完一级后，距离计数器加一。 

如果 BFS 完成但未到达距离`k`，该函数返回一个空列表。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func distanceK(root *TreeNode, target *TreeNode, k int) []int {
    parentMap := make(map[*TreeNode]*TreeNode)

    var buildParentMap func(node, parent *TreeNode)

    buildParentMap = func(node, parent *TreeNode) {
        if node == nil {
            return
        }

        parentMap[node] = parent

        buildParentMap(node.Left, node)
        buildParentMap(node.Right, node)
    }

    buildParentMap(root, nil)

    queue := []*TreeNode{target}
    visited := make(map[*TreeNode]bool)
    visited[target] = true

    currentDistance := 0

    for len(queue) > 0 {
        if currentDistance == k {
            result := []int{}

            for _, node := range queue {
                result = append(result, node.Val)
            }

            return result
        }

        levelSize := len(queue)

        for i := 0; i < levelSize; i++ {
            currentNode := queue[0]
            queue = queue[1:]

            neighbors := []*TreeNode{
                currentNode.Left,
                currentNode.Right,
                parentMap[currentNode],
            }

            for _, neighbor := range neighbors {
                if neighbor != nil && !visited[neighbor] {
                    visited[neighbor] = true
                    queue = append(queue, neighbor)
                }
            }
        }

        currentDistance++
    }

    return []int{}
}
```Go 实现遵循与 Python 解决方案相同的算法结构。 

使用从节点指针到父指针的映射来存储父关系。 由于Go没有Python的动态可哈希对象，因此指针引用直接用作映射键。 

BFS队列是用切片来实现的。 使用切片操作从前面删除节点。 

访问的结构是`map[*TreeNode]bool`，它有效地跟踪已处理的节点。 

在探索邻居之前需要进行 Nil 检查，因为 Go 使用`nil`指针而不是Python的`None`。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点在 DFS 期间最多访问一次，在 BFS 期间最多访问一次 |

 该算法对树执行两次遍历。 

第一次遍历构建父映射，仅访问每个节点一次。 第二次遍历从目标节点执行 BFS，由于访问集，再次访问每个节点最多一次。 

辅助数据结构都与树中节点的数量线性缩放。

            parent_map[node] = parent

            build_parent_map(node.left, node)
            build_parent_map(node.right, node)

 ## 边缘情况

 ### 案例 1：`k = 0`什么时候`k`等于 0，正确答案就是目标节点本身，因为节点到其自身的距离为零。 

如果 BFS 在检查当前级别之前错误地增加了距离计数器，则很容易导致差一错误。 

该实现通过检查来正确处理此问题：```
if current_distance == k:
```在处理下一个 BFS 级别之前。 

### 情况 2：目标节点是叶子

 叶节点没有子节点，因此仅向下遍历将无法找到许多有效答案。 

例如，距离较远的节点`2`来自一片叶子可能需要：

 - 向上移动到父级
 - 然后向下进入另一个子树

 父地图通过允许各个方向的遍历来解决这个问题。 

### 案例 3：`k`大于树高

 如果`k`超过距目标的最大可达距离，不存在有效节点。 

有错误的实现可能会无限期地继续下去或返回不正确的部分结果。 

这种实现自然可以处理这种情况，因为 BFS 最终会耗尽所有可到达的节点。 一旦队列变空，算法就会返回一个空列表。 

### 案例 4：防止循环

 一旦引入父指针，该结构的行为就像一个无向图。 

例如：```
5 <-> 3
```如果没有访问集，BFS 可能会永远在连接的节点之间反复来回移动。 

这`visited`set 保证每个节点最多被处理一次，防止无限循环并保留`O(n)`复杂。
