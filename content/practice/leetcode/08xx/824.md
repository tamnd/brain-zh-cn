[LeetCode 824 题](https://leetcode.com/problems/goat-latin/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们遵循一组特定的字符串操作规则，将给定的句子转换为一种名为“**山羊拉丁语**”的虚构语言。 

输入是一个名为`sentence`，其中单词之间用一个空格分隔。 每个单词仅包含英文字母字符，即大写和小写字母。 我们必须单独处理每个单词，然后将转换后的单词组合回最终句子。 

对于每个单词，转换取决于第一个字符是元音还是辅音：

 - 如果单词以元音开头 (`a`,`e`,`i`,`o`,`u`，不区分大小写），我们只需附加`"ma"`到单词的末尾。 
- 如果单词以辅音开头，我们删除第一个字符，将其放在单词的末尾，然后追加`"ma"`。 

在第一次转换之后，我们必须附加一系列`'a'`基于单词在句子中的位置的字符。 第一个词得到一个`'a'`，第二个得到两个`'a'`，等等。 

例如：

-`"apple"`以元音开头，所以它变成`"applema"`。 
-`"goat"`以辅音开头，因此将第一个字母移到后面给出`"oatg"`，然后添加`"ma"`给出`"oatgma"`。 

最终的输出是转换后的句子，其中每个单词都经过了这些修改并保持由空格分隔。 

这些约束告诉我们一些重要的事情：

 -`sentence.length <= 150`，这是非常小的。 
- 保证单词之间恰好有一个空格分隔。 
- 没有前导或尾随空格。 
- 每个单词仅包含字母。 

由于输入量很小，因此效率不是主要问题。 即使优化程度较低的解决方案也很容易通过。 然而，我们仍然应该以干净高效的线性时间实现为目标。 

预先识别一些边缘情况很重要。 仅包含一个单词的句子仍必须收到正确的结果`'a'`后缀。 大写元音，例如`"I"`或者`"Apple"`必须被视为元音，这意味着必须小心处理区分大小写。 非常短的单词，包括单字符单词，例如`"I"`或者`"a"`，移动辅音时不应破坏转换逻辑。 该问题保证了有效的格式，因此我们不需要处理多个空格或空字。 

## 方法

 ### 蛮力方法

 解决这个问题的一个强力方法是逐个字符地重复重建字符串。 对于每个单词，我们可以手动检查第一个字符，使用循环重建转换后的单词，附加`"ma"`，然后附加所需的数量`'a'`另一个循环的字符。 

例如，在处理以辅音开头的单词时，我们可以通过从第二个字符向前迭代来创建一个新字符串，然后手动附加第一个字符。 同样，对于成长中的`'a'`后缀，我们可以重复连接一个`'a'`一次。 

这种方法之所以有效，是因为它直接遵循转换规则。 然而，在字符串不可变的语言中，重复的字符串连接可能会变得低效，因为每次连接都可能分配一个新字符串。 尽管约束足够小，仍然可以轻松地通过，但它是不必要的麻烦。 

### 最佳方法

 关键的观察结果是，这从根本上来说是一个**单遍字符串转换问题**。 我们只需要对每个单词处理一次。 

我们可以将句子拆分成单词，使用哈希集进行恒定时间查找来确定每个单词是否以元音开头，应用所需的转换，附加正确的单词数`'a'`使用字符串乘法计算字符，并将结果存储在列表中。 

最后，我们用空格连接所有转换后的单词。 

这种方法非常有效，因为每个单词都被访问一次，并且执行的每个操作都与单词本身的大小成正比。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 重复字符串串联可能会重复重建字符串 |
 | 最佳| O(n) | O(n) | 具有高效字符串构建的单次传递单词 |

 这里，`n`表示句子中的字符总数。 

## 算法演练

 1. 创建一个包含所有小写和大写形式元音的集合。 

我们使用集合是因为​​成员资格检查是`O(1)`。 这让我们可以快速确定一个单词是否以元音开头。 
2. 将句子分成单独的单词。 

由于该问题保证单词由单个空格分隔并且没有前导或尾随空格，因此使用`.split()`给了我们我们所需要的准确的词语。 
3. 创建一个空列表来存储转换后的单词。 

我们不是重复连接字符串，而是将处理过的单词累积在一个列表中，并在最后将它们连接起来以提高效率。 
4. 遍历单词及其索引。 

索引很重要，因为每个单词的数量都在增加`'a'`人物。 由于索引开始于`0`，我们添加`1`以获得正确的单词位置。 
5. 对于每个单词，检查其第一个字符是否是元音。 

- 如果是元音，则附加`"ma"`直接地。 
- 如果是辅音，则将第一个字符移至末尾并追加`"ma"`。 
6. 追加所需数量`'a'`人物。 

如果这是`i-th`从零开始的索引中的单词，追加`'a' * (i + 1)`。 
7. 将转换后的单词添加到结果列表中。 
8. 将所有转换后的单词用空格连接起来并返回最终的字符串。 

### 为什么它有效

 该算法之所以有效，是因为每个单词都是根据精确的山羊拉丁语规则独立转换的。 对于每个单词，我们正确区分元音和辅音，应用所需的修饰，并附加适当数量的`'a'`基于位置的字符。 由于每个单词都被处理一次并按顺序添加回来，因此生成的句子保留了原始结构，同时满足所有转换要求。 

## Python 解决方案```python
class Solution:
    def toGoatLatin(self, sentence: str) -> str:
        vowels = set("aeiouAEIOU")
        words = sentence.split()
        transformed_words = []

        for index, word in enumerate(words, start=1):
            if word[0] in vowels:
                transformed_word = word + "ma"
            else:
                transformed_word = word[1:] + word[0] + "ma"

            transformed_word += "a" * index
            transformed_words.append(transformed_word)

        return " ".join(transformed_words)
```该实现首先创建一组包含小写和大写字母的元音。 这确保了像这样的词`"I"`和`"Apple"`被正确识别为元音起始词。 

接下来，使用以下方法将句子拆分为单词`.split()`。 由于该问题保证了干净的间距，因此无需额外的预处理即可生成准确的单词列表。 

然后我们使用迭代遍历单词`enumerate(..., start=1)`。 开始于`1`使索引直接对应所需的数量`'a'`字符，避免以后进行额外的调整。 

在循环内，我们检查单词的第一个字符。 如果是元音，我们附加`"ma"`直接地。 否则，我们将第一个字符移到末尾并追加`"ma"`。 

最后，我们附加所需的`'a'`使用字符串乘法添加后缀，将转换后的单词添加到结果列表中，然后使用返回最终句子`" ".join(...)`。 

## 解决方案```go
import "strings"

func toGoatLatin(sentence string) string {
	vowels := map[byte]bool{
		'a': true, 'e': true, 'i': true, 'o': true, 'u': true,
		'A': true, 'E': true, 'I': true, 'O': true, 'U': true,
	}

	words := strings.Split(sentence, " ")
	result := make([]string, 0, len(words))

	for i, word := range words {
		var transformed string

		if vowels[word[0]] {
			transformed = word + "ma"
		} else {
			transformed = word[1:] + string(word[0]) + "ma"
		}

		transformed += strings.Repeat("a", i+1)
		result = append(result, transformed)
	}

	return strings.Join(result, " ")
}
```Go 实现遵循与 Python 版本相同的逻辑，但适应 Go 语言约定。 

一个`map[byte]bool`用于元音查找，因为 Go 中的字符串是字节切片，并且访问`word[0]`返回一个字节。 由于输入仅包含英文字母，因此字节索引是完全安全的。 

Go 使用的不是 Python 字符串乘法`strings.Repeat("a", i+1)`生成重复的`'a'`后缀。 最终句子是使用以下方法有效组装的`strings.Join()`。 

由于微小的约束，无需担心整数溢出，并且不需要 nil 处理，因为输入保证了有效的非空句子。

 ## 边缘情况

 ### 单字符词

 像这样的话`"I"`或者`"a"`可能是错误的来源，因为移动辅音转换中的第一个字符可能会意外地产生无效的子字符串操作。 在此实现中，切片可以安全地处理这些情况。 例如，`"b"[1:]`变成空字符串，使得转换后的结果`"bma"`添加后缀之前。 

### 大写字母

 该问题允许小写和大写英文字母。 仅检查小写元音的幼稚实现会错误地对待`"Apple"`或者`"I"`作为辅音开头的词。 此实现明确地将大写元音包含在元音集中，以确保正确的分类。 

### 单字句子

 仅包含一个单词的句子仍然需要第一个位置后缀，它恰好是一个`'a'`。 通过使用`enumerate(..., start=1)`在Python和`i + 1`在 Go 中，实现自然地处理这种情况，而不需要特殊的逻辑。 

### 所有辅音或所有元音单词

 每个单词都以同一类别开头的句子可能会暴露隐藏的分支错误。 例如，全元音句子必须始终附加`"ma"`直接移动，而全辅音句子必须一致地移动第一个字符。 由于每个单词都会根据元音集进行独立检查，因此这两种情况都会得到正确且一致的处理。
