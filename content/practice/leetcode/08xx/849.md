[LeetCode 第 849 题](https://leetcode.com/problems/maximize-distance-to-closest-person/)

 **难度：** 🟡 中等
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出了一个二进制数组，称为`seats`。 数组中的每个位置代表一行中的一个座位：

 -`1`表示座位已被占用。 
-`0`意思是座位是空的。 

我们需要确定 Alex 应该坐在哪里，以便与最近的占用座位的距离尽可能大。 最终的答案是最大可能的最小距离。 

关键细节是，我们不是最大化与每个人的距离，而是最大化与最近的人的距离。 对于任何空座位，我们计算到最近的已占用座位的距离。 在所有空座位中，我们选择距离最大的座位。 

例如：```
[1,0,0,0,1]
```如果 Alex 坐在中间的空座位上：```
[1,0,X,0,1]
```最近的已占用座位在两侧各有两个位置，因此最小距离为`2`。 

约束条件很重要：

 -`2 <= seats.length <= 2 * 10^4`- 该数组仅包含`0`和`1`- 至少有一个空座位
 - 至少有一个座位被占用

 由于数组长度可以达到两万个元素，我们应该以线性时间解决方案为目标，`O(n)`。 在某些语言中，二次方法可能仍然可以通过这种大小，但它们效率低下且不必要。 

一些边缘情况尤其重要：

 - 队列开头的空座位

 - 示例：`[0,0,0,1]`- 队列末尾的空座位

 - 示例：`[1,0,0,0]`- 两个已占用座位之间的空座位

 - 示例：`[1,0,0,0,1]`- 非常小的阵列

 - 示例：`[0,1]`幼稚的实现很容易错误地处理前导零或尾随零，因为这些情况与中间间隙不对称。 

## 方法

 ### 蛮力方法

 蛮力策略很简单。 对于每个空座位：

 1. 向左扫描直至找到有人的座位。 
2. 向右扫描直至找到有人的座位。 
3. 计算到最近的占用座位的距离。 
4. 跟踪所有空座位中的最大值。 

这种方法是正确的，因为它明确评估每一种可能的坐姿并计算每个坐姿的准确的最近人距离。 

然而，它的效率很低。 假设有`n`座位。 对于每个空座位，我们可以从两个方向扫描几乎整个阵列。 在最坏的情况下，这会导致`O(n^2)`时间复杂度。 

和`n = 20,000`，与线性解相比，二次行为不必要地慢。 

### 最佳方法

 重要的观察是，答案取决于连续的空座位的长度。 

存在三种不同的情况：

 1、一开始就座无虚席
 2. 结束时座无虚席
 3. 两个已占用座位之间的空座位

 对于中间段，最好的座位始终是间隙的中间。 如果间隙长度为`k`，最佳可达到的距离是：```
(k + 1) // 2
```对于前导或尾随间隙，Alex 可以坐在最远端，因此距离等于整个间隙长度。 

我们可以处理连续的零块并直接计算它们的贡献，而不是独立评估每个空座位。 这将运行时间减少到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 通过左右扫描检查每个空座位 |
 | 最佳| O(n) | O(1) | O(1) | 直接处理连续的零段 |

 ## 算法演练

 ### 最佳线性扫描算法

 1. 初始化变量以跟踪最佳答案和先前占用的座位的索引。 

我们使用：

 -`max_distance`存储迄今为止找到的最佳结果
 -`previous_person`记住最后占用的座位的索引

 最初，`previous_person = -1`因为我们还没有看到任何有人占用的座位。 
2. 从左到右遍历数组。 

对于每个索引`i`：

- 如果`seats[i] == 0`，继续扫描。 
- 如果`seats[i] == 1`，我们找到了一个被占用的座位，并且可以评估它之前的间隙。 
3. 单独处理第一个占用的座位。 

如果`previous_person == -1`，那么这是数组中第一个被占用的座位。 

前导零所贡献的距离很简单：```
i
```因为亚历克斯可以坐在索引处`0`。 
4. 处理中间间隙。 

如果我们已经看到先前占用的座位，则以下之间的零：```
previous_person and i
```形成中间间隙。 

间隙尺寸为：```
i - previous_person
```该间隙内的最佳可能距离是：```
(i - previous_person) // 2
```因为最佳座位靠近中心。 
5. 更新`previous_person`。 

处理完当前占用的座位后，设置：```
previous_person = i
```6. 循环结束后处理尾随零。 

如果最后占用的座位位于索引处`previous_person`，那么尾随零贡献：```
len(seats) - 1 - previous_person
```因为亚历克斯可以坐在最后一个座位。 
7. 返回找到的最大距离。 

### 为什么它有效

 该算法之所以有效，是因为每个空座位都属于以下三个类别之一：

 - 前导零
 - 尾随零
 - 占用座位之间的零

 对于中间间隙，最佳位置始终是中点，因为向任一占用的座位移动会减少最小距离。 对于边缘间隙，最远端点是最佳选择，因为附近只有一个有人占用的座位。 

由于该算法仅对每个零段进行一次评估并计算该段的数学最佳距离，因此保证最终的最大值是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxDistToClosest(self, seats: List[int]) -> int:
        max_distance = 0
        previous_person = -1

        for i, seat in enumerate(seats):
            if seat == 1:
                if previous_person == -1:
                    # Leading zeros
                    max_distance = i
                else:
                    # Middle gap
                    gap_distance = (i - previous_person) // 2
                    max_distance = max(max_distance, gap_distance)

                previous_person = i

        # Trailing zeros
        trailing_distance = len(seats) - 1 - previous_person
        max_distance = max(max_distance, trailing_distance)

        return max_distance
```实现直接遵循算法。 

我们首先初始化`max_distance`和`previous_person`。 变量`previous_person`存储遍历过程中遇到的最近占用座位的索引。 

当我们遍历数组时，我们仅在遇到一个时才执行工作`1`。 这是因为占用的座位定义了零段的边界。 

如果这是第一个占用的座位，则所有前面的位置都是前导零。 距离贡献等于指数本身。 

否则，我们使用整数除法计算连续占用座位之间间隙的中点距离。 

处理完所有占用的席位后，我们单独处理尾随零，因为它们不在循环内处理。 

该解决方案使用恒定的额外内存并一次性处理数组。 

## 解决方案```go
package main

func maxDistToClosest(seats []int) int {
	maxDistance := 0
	previousPerson := -1

	for i, seat := range seats {
		if seat == 1 {
			if previousPerson == -1 {
				// Leading zeros
				maxDistance = i
			} else {
				// Middle gap
				gapDistance := (i - previousPerson) / 2
				if gapDistance > maxDistance {
					maxDistance = gapDistance
				}
			}

			previousPerson = i
		}
	}

	// Trailing zeros
	trailingDistance := len(seats) - 1 - previousPerson
	if trailingDistance > maxDistance {
		maxDistance = trailingDistance
	}

	return maxDistance
}
```Go 的实现与 Python 版本非常相似。 

Go 使用显式整数除法`/`，它会自动将整数截断为零，以匹配所需的中点计算。 

与 Python 不同，Go 不提供内置的`max`函数用于整数，因此需要手动执行比较`if`声明。 

切片自然用于输入数组，不需要额外的分配。

 ## 边缘情况

 ### 领先空座

 当数组以零开头时，会出现常见的错误来源，例如：```
[0,0,0,1]
```在这种情况下，最佳座位位于最左边缘。 简单的中点公式不起作用，因为左侧没有座位。 

该实现通过使用以下方法单独检测第一个占用的座位来处理此问题：```
if previous_person == -1:
```该距离只是第一个占用座位的索引。 

### 尾随空座位

 当数组以零结尾时，会出现另一个重要的边缘情况：```
[1,0,0,0]
```最好的座位在最右边缘，有距离`3`。 

这种情况很容易被忽略，因为循环只在遇到占用的座位时才处理间隙。 由于尾随零之后没有出现占用的座位，因此必须在循环结束后处理它们。 

该实现计算：```
len(seats) - 1 - previous_person
```正确测量尾部间隙。 

### 偶数和奇数长度的中间间隙

 中间间隙需要仔细的整数除法行为。 

例如：```
[1,0,0,0,1]
```最佳距离为：```
(4 - 0) // 2 = 2
```对于均匀大小的间隙：```
[1,0,0,1]
```最佳距离变为：```
(3 - 0) // 2 = 1
```正确使用整数除法可确保针对奇数和偶数间隙长度准确计算最近的占用座位距离。
