[LeetCode 886 题](https://leetcode.com/problems/possible-bipartition/)

 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、并查找、图论

 ## 解决方案

 ## 问题理解

 这个问题问是否可以划分`n`将人们精确地分成两个群体，这样一来，没有一对互相不喜欢的人最终会分到同一群体中。 

输入包含：

 - 一个整数`n`，代表标记为`1`到`n`- 一份清单`dislikes`，其中每对`[a, b]`指人`a`和人`b`不能属于同一组

 任务是返回：

 -`true`如果可以分成两组
 -`false`否则

 这本质上是一个图问题。 每个人都可以看作一个节点，每个不喜欢的关系都是两个节点之间的一条无向边。 那么问题就变成了：

 > 我们可以仅使用两种颜色对图进行着色，这样相邻节点就不会共享相同的颜色吗？ 

这正是二分图的定义。 

例如，如果人`1`不喜欢的人`2`和`3`， 然后`1`必须被放置在与两者相反的组中`2`和`3`。 

约束条件很重要：

 -`n <= 2000`-`dislikes.length <= 10000`这些限制足够大，以至于指数或强力分区方法不可行。 我们需要一种相对于节点和边的数量具有大致线性复杂度的图算法。 

一些边缘情况很重要：

 - 没有不喜欢关系的图始终是二分图
 - 图表可能包含多个断开连接的组件
 - 奇数循环使得二分不可能
 - 即使循环也有效
 - 一个没有棱角的人不应该引起问题
 - 该图是无向的，因此每个不喜欢的关系都必须在两个方向上添加

 ## 方法

 ### 蛮力方法

 暴力解决方案会尝试将所有可能的人员分配为两组。 

由于每个人都有两个选择，因此可能的分区总数为：$$2^n$$对于每个分区，我们将检查每个不喜欢的对，以确保两个人不在同一组中。 

这种方法是正确的，因为它详尽地探索了所有有效的配置。 如果任何分区满足条件，我们返回`true`。 

然而，这在计算上很快就变得不可能。 和`n = 2000`，分区的数量是天文数字。 

因此，暴力法在限制条件下无法发挥作用。 

### 最优方法，图二分检查

 关键的观察是这个问题正是二分图问题。 

如果我们治疗：

 - 每个人作为一个节点
 - 每个人都不喜欢将关系视为无向边缘

 那么问题问是否可以将图分为两个集合，使得每条边都连接来自不同集合的节点。 

这可以使用以下任一方法解决：

 - 广度优先搜索
 - 深度优先搜索

 同时为每个节点分配两种颜色之一。 

这个想法是：

 - 为起始节点分配颜色
 - 每个邻居都必须收到相反的颜色
 - 继续遍历图
 - 如果我们找到两个具有相同颜色的相邻节点，则该图不是二分图

 因为图可能是断开的，所以我们必须从每个未访问过的节点开始遍历。 

这种方法非常有效，因为每个节点和边仅被处理少量次。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n × m) | O(2^n × m) | O(n) | 尝试所有可能的分区 |
 | 最佳| O(n + m) | O(n + m) | 使用 BFS 或 DFS 进行图形着色 |

 这里，`m`是不喜欢关系的数量。 

## 算法演练

 我们将使用广度优先搜索和图形着色。 

### 第 1 步：构建图表

 创建一个邻接表，其中：

 -`graph[a]`包含所有不喜欢的人`a`- 由于不喜欢是相互制约的，所以在两个方向上添加边缘

 例如：```
dislikes = [[1,2],[1,3]]
```变成：```
1 -> [2,3]
2 -> [1]
3 -> [1]
```邻接列表非常高效，因为它允许快速遍历邻居。 

### 第 2 步：创建颜色数组

 我们维护一个名为`color`:

 -`0`表示未访问过
 -`1`表示第一组
 -`-1`表示第二组

 这使我们能够有效地跟踪小组作业。 

### Step 3: Traverse Every Component

The graph may not be fully connected.

 例如：```
1 -- 2

3 -- 4
```如果我们只从节点启动BFS`1`, 节点`3`和`4`永远不会被处理。 

所以我们循环遍历每个人`1`到`n`。 

每当我们找到一个未着色的节点时，我们就会启动一个新的 BFS。 

### 步骤 4：启动 BFS

 为起始节点分配颜色：```
color[start] = 1
```将其推入队列。 

### 步骤 5：处理邻居

 当队列不为空时：

 1.移除当前节点
 2.拜访所有邻居
 3. 如果邻居是无色的：

 - 分配相反的颜色
 - 将其添加到队列中
 4. 如果邻居已经有相同的颜色：

 - 返回`False`相反的颜色是通过以下方式获得的：```
-color[current]
```###第6步：完成遍历

 如果 BFS 对每个组件都完成且没有冲突，则该图是二分图。 

返回`True`。 

### 为什么它有效

 该算法保持了每条边连接具有相反颜色的节点的不变性。 

每当我们访问一个节点时，它的所有邻居都会被迫进入相反的组。 如果我们遇到连接具有相同颜色的两个节点的边，则不存在有效的二分。 

这可以正确检测奇数循环，这些奇数循环正是使图成为非二分图的结构。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def possibleBipartition(self, n: int, dislikes: List[List[int]]) -> bool:
        graph = [[] for _ in range(n + 1)]

        for a, b in dislikes:
            graph[a].append(b)
            graph[b].append(a)

        color = [0] * (n + 1)

        for person in range(1, n + 1):
            if color[person] != 0:
                continue

            queue = deque([person])
            color[person] = 1

            while queue:
                current = queue.popleft()

                for neighbor in graph[current]:
                    if color[neighbor] == 0:
                        color[neighbor] = -color[current]
                        queue.append(neighbor)
                    elif color[neighbor] == color[current]:
                        return False

        return True
```实现首先构建一个邻接表。 由于该图是无向的，因此每个不喜欢对都会在两个方向上插入。 

这`color`数组存储组分配。 值为`0`表示该节点尚未被访问过。 

我们遍历所有人，因为图表可能包含断开连接的组件。 每当找到未着色的节点时，我们就会从该节点启动 BFS 遍历。 

在 BFS 内部，每个邻居接收与当前节点相反的颜色。 如果邻居已经与当前节点具有相同的颜色，则该图不能是二分图，因此我们立即返回`False`。 

如果所有节点都处理成功，则该图满足二分条件，我们返回`True`。 

## 解决方案```go
func possibleBipartition(n int, dislikes [][]int) bool {
	graph := make([][]int, n+1)

	for _, edge := range dislikes {
		a, b := edge[0], edge[1]
		graph[a] = append(graph[a], b)
		graph[b] = append(graph[b], a)
	}

	color := make([]int, n+1)

	for person := 1; person <= n; person++ {
		if color[person] != 0 {
			continue
		}

		queue := []int{person}
		color[person] = 1

		for len(queue) > 0 {
			current := queue[0]
			queue = queue[1:]

			for _, neighbor := range graph[current] {
				if color[neighbor] == 0 {
					color[neighbor] = -color[current]
					queue = append(queue, neighbor)
				} else if color[neighbor] == color[current] {
					return false
				}
			}
		}
	}

	return true
}
```Go 实现遵循与 Python 版本相同的逻辑。 

切片用于邻接列表和 BFS 队列。 由于Go没有提供内置的deque结构，因此队列操作是使用slice切片来实现的。 

这`color`slice 使用整数与 Python 版本完全相同：

 -`0`对于未访问过的
 -`1`一组
 -`-1`对于另一组

 不存在整数溢出问题，因为所有操作仅涉及小整数。

        from collections import deque

        graph = [[] for _ in range(n + 1)]

        for a, b in dislikes:
            graph[a].append(b)
            graph[b].append(a)

        color = [0] * (n + 1)

 ## 边缘情况

 ### 清空不喜欢列表

 如果`dislikes`is empty, no restrictions exist between people. 任何分区都有效。 

A naive implementation might incorrectly assume every node must be connected or visited through edges. Our solution correctly handles this because every unvisited node starts its own BFS traversal, even if it has no neighbors.

 ### 断开的组件

 The graph may contain several isolated sections.

 例如：```
1 -- 2

3 -- 4
```如果算法只从节点开始BFS`1`，它会完全错过节点`3`和`4`。 

我们的实现通过迭代每个人来防止这种情况发生`1`到`n`and launching BFS whenever an unvisited node is found.

 ### 奇数周期

 奇数循环是使二分不可能的关键结构。 

例如：```
1 -- 2
 \  /
  3
```当遍历该图时，最终两个相邻节点被迫共享相同的颜色。 

实现明确检查：```
elif color[neighbor] == color[current]:
    return False
```这会立即检测到无效配置。 

### 孤立节点

 有些人可能不会出现在任何不喜欢的配对中。 

例如：```
n = 5
dislikes = [[1,2]]
```人们`3`,`4`， 和`5`被孤立。 

该算法可以正确处理它们，因为孤立的节点只是立即启动和完成 BFS，而不会发生冲突。
