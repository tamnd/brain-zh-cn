[LeetCode 第 872 题](https://leetcode.com/problems/leaf-similar-trees/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们仅根据叶节点来比较两个二叉树。 叶节点是没有左子节点和右子节点的节点。 对于每棵树，我们必须按从左到右的顺序收集叶子值，然后确定两个结果序列是否相同。 

重要的细节是树的整体结构并不重要。 如果两棵树的叶子以相同的从左到右的顺序出现并且包含相同的值，那么两棵树的内部看起来可能完全不同，但仍然被认为是叶子相似的。 

例如，假设第一棵树生成叶序列：```
[6, 7, 4, 9, 8]
```第二棵树也产生：```
[6, 7, 4, 9, 8]
```那么答案就是`true`，即使树木本身的形状不同。 

输入由两个根节点组成，`root1`和`root2`，每个代表一棵二叉树。 预期输出是一个布尔值：

 -`true`如果两棵树具有完全相同的叶子序列
 -`false`否则

 约束告诉我们每棵树最多包含 200 个节点。 这是一个相对较小的输入大小，因此我们不需要非常高级的优化。 简单的深度优先遍历就足够高效了。 

需要考虑一些重要的边缘情况：

 - 只有一个节点的树，其中根本身就是叶子
 - 结构不同但叶子序列相同的树
 - 具有相同叶子值但顺序不同的树
 - 叶子数量不同的树木
 - 深度不平衡的树，递归深度遵循长链

 该问题保证每棵树至少有一个节点，因此我们永远不会收到一棵空树。 

## 方法

 ### 蛮力方法

 暴力式解决方案将重复搜索每棵树的下一个叶节点，并一次比较一个叶节点。 对于每次比较，我们可能会再次遍历树的大部分以找到下一个叶子。 

这种方法是正确的，因为它最终会按从左到右的顺序检查每个叶子。 然而，它的效率很低，因为在重复搜索过程中可能会多次重新访问相同的节点。 

在最坏的情况下，这种重复遍历可能会导致二次行为。 

### 最佳方法

 关键的见解是我们只关心叶子序列，而不关心内部树结构。 

我们可以对每棵树执行一次深度优先遍历，并按顺序记录所有叶子值。 由于 DFS 自然会在处理右子树之前处理左子树，因此收集到的叶子会自动按从左到右的顺序出现。 

收集两个序列后，我们只需比较两个数组。 

这很有效，因为：

 - 每个节点都被访问一次
 - 叶子检测是恒定时间
 - 数组比较是线性的

 递归 DFS 在这里特别干净，因为二叉树自然适合递归遍历模式。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(h) | 反复搜索叶子，多次重新访问节点 |
 | 最佳| O(n + m) | O(n + m) | 每棵树进行一次 DFS 遍历，存储叶子序列 |

 这里：

-`n`是第一棵树中的节点数
 -`m`是第二棵树中的节点数
 -`h`是树的高度

 ## 算法演练

 1. 创建一个空列表来存储第一棵树的叶子值。 

该列表将保留遍历过程中遇到的叶子从左到右的顺序。 
2. 对第一棵树进行深度优先遍历。 

遍历过程中：

 - 如果当前节点是`None`，立即返回。 
- 如果该节点没有左子节点和右子节点，则它是叶节点。 
- 将节点的值追加到叶列表中。 
- 否则，首先递归处理左子树，然后处理右子树。 
3. 对第二棵树重复相同的过程。 

这会产生另一个叶序列列表。 
4. 比较两个叶子序列。 

如果两个列表的长度和元素顺序相同，则返回`true`。 否则，返回`false`。 

### 为什么它有效

 该算法之所以有效，是因为当我们在处理右子节点之前递归处理左子节点时，DFS 按从左到右的顺序访问节点。 每个叶节点仅收集一次并按正确的顺序附加。 

由于叶相似树的定义完全取决于叶值的有序序列，因此比较两个结果列表直接给出正确答案。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional, List

class Solution:
    def leafSimilar(
        self,
        root1: Optional[TreeNode],
        root2: Optional[TreeNode]
    ) -> bool:
        
        def collect_leaves(node: Optional[TreeNode], leaves: List[int]) -> None:
            if not node:
                return
            
            if not node.left and not node.right:
                leaves.append(node.val)
                return
            
            collect_leaves(node.left, leaves)
            collect_leaves(node.right, leaves)
        
        leaves1 = []
        leaves2 = []
        
        collect_leaves(root1, leaves1)
        collect_leaves(root2, leaves2)
        
        return leaves1 == leaves2
```实现首先定义一个名为的辅助函数`collect_leaves`。 该函数执行递归 DFS 遍历。 

第一个条件检查当前节点是否为`None`。 如果是，则遍历立即停止，因为没有子树可供处理。 

接下来，该函数检查当前节点是否是叶节点。 当两个节点都被认为是叶子时`left`和`right`是`None`。 在这种情况下，它的值将被附加到叶序列列表中。 

如果该节点不是叶子，则首先继续递归到左子树，然后再到右子树。 这种顺序很重要，因为该问题需要从左到右收集叶子。 

定义辅助函数后，解决方案创建两个列表：```python
leaves1 = []
leaves2 = []
```DFS 遍历用每棵树的叶序列填充这些列表。 

最后，该解决方案使用 Python 的列表相等运算符直接比较两个列表。 这会检查以下两项：

 - 叶子的数量
 - 叶子值的精确排序

 如果两者匹配，该方法返回`True`。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func leafSimilar(root1 *TreeNode, root2 *TreeNode) bool {
    leaves1 := []int{}
    leaves2 := []int{}

    var collectLeaves func(node *TreeNode, leaves *[]int)

    collectLeaves = func(node *TreeNode, leaves *[]int) {
        if node == nil {
            return
        }

        if node.Left == nil && node.Right == nil {
            *leaves = append(*leaves, node.Val)
            return
        }

        collectLeaves(node.Left, leaves)
        collectLeaves(node.Right, leaves)
    }

    collectLeaves(root1, &leaves1)
    collectLeaves(root2, &leaves2)

    if len(leaves1) != len(leaves2) {
        return false
    }

    for i := 0; i < len(leaves1); i++ {
        if leaves1[i] != leaves2[i] {
            return false
        }
    }

    return true
}
```Go 实现遵循与 Python 版本相同的 DFS 策略。 

一个重要的区别是切片是使用指针通过引用传递的：```go
func(node *TreeNode, leaves *[]int)
```这允许辅助函数直接附加到共享切片中。 

Go 不支持非 nil 切片的直接切片相等，因此我们手动比较长度和单个元素，而不是编写：```go
leaves1 == leaves2
```Nil 处理很简单，因为 Go 使用`nil`为失踪儿童提供线索。 

整数溢出不是问题，因为节点值限制在范围内`[0, 200]`。

 ## 边缘情况

 ### 单节点树

 仅包含一个节点的树是一种重要的边缘情况，因为根本身也是叶子。 一些实现错误地假设叶子只出现在树的较深处。 

当前的实现自然地处理这个问题，因为它检查：```
if not node.left and not node.right:
```即使对于根节点，这个条件也成立。 

### 结构不同但叶子相同

 两棵树可能具有完全不同的内部布局，但仍然共享相同的叶子序列。 有缺陷的实现可能会比较结构而不是叶子。 

该解决方案完全避免了该问题，因为它在比较期间忽略非叶节点并且仅存储叶值。 

### 不同顺序的相同叶子值

 叶子的顺序很重要。 例如：```
[2, 3]
```不同于：```
[3, 2]
```使用集合或排序数组的有缺陷的实现会错误地将它们视为相等。 

此实现通过在 DFS 期间始终在探索右子树之前探索左子树来保留遍历顺序，从而确保序列保持准确。
