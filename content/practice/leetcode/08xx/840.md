 **难度：** 🟡 中等
 **主题：** 数组、哈希表、数学、矩阵

 ## 解决方案

 ## 问题理解

 这个问题要求我们数一下有多少个`3 x 3`更大网格内的幻方。 幻方被定义为所有数字都是从 1 到 9 的不同整数，并且每行、每列和两条对角线的总和都相同的正方形。 

输入是具有维度的整数的二维网格`row x col`，其中每个元素的范围为 0 到 15。输出是一个整数，表示有多少个`3 x 3`子网格满足幻方标准。 

需要注意的要点：

 - 幻方必须包含数字 **1 到 9** 且恰好一次。 任何超出此范围的数字都会立即取消子网格的资格。 
- 任意行、列或对角线的总和`3 x 3`幻方必须等于 **15**，因为`(1+2+...+9)/3 = 15`。 
- 边缘情况包括非常小的网格（小于 3x3）、填充 1-9 之外的数字的网格以及包含重复数字的网格。 

限制很小：`row`和`col`最多 10 个，因此暴力方法是可行的，但有机会通过早期消除无效候选者来进行较小的优化。 

## 方法

 蛮力方法会迭代所有可能的方法`3 x 3`内的子网格`row x col`网格。 对于每个子网格，我们将检查数字是否不同并在 1-9 范围内，然后计算所有行、列和对角线的总和以验证幻方属性。 这种方法工作正常，但涉及重复的求和计算。 其时间复杂度为 O((row-2)*(col-2) * 9) 因为有`(row-2)*(col-2)`子网格和每个子网格要检查的 9 个数字。 

最佳方法利用了以下观察结果：`3 x 3`数字 1-9 的幻方**始终有 5 位于中心**。 这使我们能够快速跳过中心不是 5 的子网格。此外，我们可以使用集合来确保所有数字都不同且在 1-9 之内。 然后我们检查行、列和对角线的总和 15，这是一种快速的恒定时间检查。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((行 2)*(列 2) * 9) | O(1) | O(1) | 检查每个`3 x 3`彻底子网格|
 | 最佳| O((行 2)*(列 2)) | O(1) | O(1) | 使用 center=5 和设置检查、恒定时间总和检查进行早期消除 |

 ## 算法演练

 1.初始化一个计数器变量`count`到 0。这将存储找到的幻方数量。 
2. 迭代每个可能的左上角`(i, j)`的一个`3 x 3`子网格。 循环范围是`i = 0 to row-3`和`j = 0 to col-3`。 
3. 对于每个子网格，首先检查中心元素是否为 5。如果不是，则跳过该子网格，因为数字 1-9 的 3x3 幻方不能有不同的中心。 
4. 将子网格压平为列表，并使用集合检查所有数字是否不同且在 1 到 9 的范围内。 
5. 检查每行、每列和对角线的总和是否为 15。 
6. 如果满足所有条件，则递增`count`。 
7. 迭代完所有子网格后，返回`count`。 

**为什么有效：** 该算法利用两个强不变量：中心必须为 5，行、列和对角线的总和必须为 15。通过检查这些条件和 1-9 范围内的唯一性，它保证任何计数的子网格都是有效的幻方。 

## Python 解决方案```python
from typing import List

class Solution:
    def numMagicSquaresInside(self, grid: List[List[int]]) -> int:
        def is_magic(i: int, j: int) -> bool:
            # Check if center is 5
            if grid[i+1][j+1] != 5:
                return False
            
            # Flatten the 3x3 subgrid and check if numbers 1-9 are all present
            nums = [grid[i+r][j+c] for r in range(3) for c in range(3)]
            if set(nums) != set(range(1, 10)):
                return False
            
            # Check rows and columns sums
            for r in range(3):
                if sum(grid[i+r][j+c] for c in range(3)) != 15:
                    return False
            for c in range(3):
                if sum(grid[i+r][j+c] for r in range(3)) != 15:
                    return False
            
            # Check diagonals
            if grid[i][j] + grid[i+1][j+1] + grid[i+2][j+2] != 15:
                return False
            if grid[i][j+2] + grid[i+1][j+1] + grid[i+2][j] != 15:
                return False
            
            return True
        
        count = 0
        rows, cols = len(grid), len(grid[0])
        for i in range(rows - 2):
            for j in range(cols - 2):
                if is_magic(i, j):
                    count += 1
        return count
```该解决方案首先检查中心，然后验证唯一性和总和约束。 辅助函数`is_magic`封装了所有验证逻辑，使主循环干净且易于理解。 

## 解决方案```go
func numMagicSquaresInside(grid [][]int) int {
    rows, cols := len(grid), len(grid[0])
    count := 0
    
    isMagic := func(i, j int) bool {
        if grid[i+1][j+1] != 5 {
            return false
        }
        seen := make(map[int]bool)
        for r := 0; r < 3; r++ {
            for c := 0; c < 3; c++ {
                val := grid[i+r][j+c]
                if val < 1 || val > 9 || seen[val] {
                    return false
                }
                seen[val] = true
            }
        }
        for r := 0; r < 3; r++ {
            sumRow := 0
            for c := 0; c < 3; c++ {
                sumRow += grid[i+r][j+c]
            }
            if sumRow != 15 {
                return false
            }
        }
        for c := 0; c < 3; c++ {
            sumCol := 0
            for r := 0; r < 3; r++ {
                sumCol += grid[i+r][j+c]
            }
            if sumCol != 15 {
                return false
            }
        }
        if grid[i][j]+grid[i+1][j+1]+grid[i+2][j+2] != 15 {
            return false
        }
        if grid[i][j+2]+grid[i+1][j+1]+grid[i+2][j] != 15 {
            return false
        }
        return true
    }
    
    for i := 0; i <= rows-3; i++ {
        for j := 0; j <= cols-3; j++ {
            if isMagic(i, j) {
                count++
            }
        }
    }
    return count
}
```在 Go 中，逻辑类似于 Python，使用映射来确保不同的数字并显式迭代以对行、列和对角线求和。 Go 没有列表推导式，因此使用嵌套循环。
