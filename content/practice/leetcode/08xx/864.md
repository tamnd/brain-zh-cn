 **难度：** 🔴难
 **主题：** 数组、位操作、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到收集二维网格迷宫中所有钥匙的最短路径。 网格包含墙壁、开放空间、钥匙、锁和起点。 你可以在四个基本方向上移动，但不能沿对角线、穿过墙壁或在网格外移动。 每个锁只有在收集到相应的钥匙后才能通过。 网格保证每把钥匙都有一个对应的锁，反之亦然，钥匙标记为`'a'`到`'f'`和锁标记为`'A'`到`'F'`。 

输入是表示网格的字符串列表。 每个字符编码细胞类型。 输出是一个整数，表示收集所有密钥所需的最少步骤数。 如果不可能收集所有密钥，则输出应该是`-1`。 

约束告诉我们网格大小是小到中等（`1 <= m, n <= 30`）并且键的数量是有限的（`1 <= k <= 6`）。 有限数量的键至关重要，因为它允许我们使用位操作有效地表示收集的键集。 重要的边缘情况包括网格，其中由于墙壁而无法访问钥匙，所有钥匙都在起始单元格上，或者锁阻挡了重要路径。 

## 方法

 一种朴素的暴力方法将从起始位置探索所有可能的移动序列，考虑收集密钥的每种可能的顺序。 这可以通过使用已访问集的递归回溯来完成，以避免重新访问相同的状态。 虽然这会给出正确的答案，但在计算上是不可行的，因为状态数量随着网格大小和键数量呈指数增长。 具体来说，最多可能有`m*n * 2^k`状态，如果不进行优化则太大而无法探索。 

最佳解决方案的关键见解是将其视为状态空间中的最短路径问题，定义为`(row, col, keys_collected)`。 广度优先搜索（BFS）自然会找到未加权图中的最短路径，我们可以将收集的键编码为位掩码，以有效地跟踪我们收集了哪些键。 BFS 确保我们逐级探索所有可能的移动，保证我们第一次到达所有键的状态时，都是通过最短路径。 通过使用一组来跟踪访问过的状态`(row, col, keys_bitmask)`，我们避免重新访问冗余状态并大幅修剪搜索空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m_n) * (2^k) * 4^(m_n)) | O(m*n * 2^k) | O(m*n * 2^k) | 递归探索所有可能的路径； 对于更大的网格来说不可行|
 | 最佳| O(m*n * 2^k) | O(m*n * 2^k) | O(m*n * 2^k) | O(m*n * 2^k) | 带状态的 BFS`(row, col, keys_bitmask)`和键的位掩码|

 ## 算法演练

 1. **初始化**：扫描网格定位起始位置`@`并计算键的总数。 将每个键编码为位掩码位置（0 表示`'a'`, 1 为`'b'`等），以便收集到的密钥集可以存储为整数。 
2. **状态表示**：将BFS状态定义为`(row, col, keys_bitmask)`， 在哪里`keys_bitmask`是一个整数，其中为每个收集的密钥设置了位。 例如，如果键`'a'`和`'c'`被收集，`keys_bitmask`是`0b101`。 
3. **BFS队列和Visited Set**：用起始状态初始化一个队列`(start_row, start_col, 0)`和一个访问集来跟踪已经探索过的状态`(row, col, keys_bitmask)`。 这可以防止重新访问状态并保证 BFS 效率。 
4. **BFS Iteration**：以层序方式处理队列，进行步数统计。 对于每个州，请考虑朝四个基本方向发展。 忽略出界或撞墙的动作`'#'`。 
5. **密钥收集**：如果新位置包含密钥，则更新密钥`keys_bitmask`通过设置相应的位。 
6. **锁检查**：如果新位置有锁，则检查对应的钥匙是否已被收集。 仅当密钥存在于`keys_bitmask`。 
7. **完成检查**：如果更新`keys_bitmask`等于`(1 << total_keys) - 1`，返回所采取的步数，因为所有密钥均已收集。 
8. **队列更新**：如果之前没有被访问过，则将新状态放入队列。 
9. **终止**：如果队列变空而没有收集到所有key，则返回`-1`来表明这是不可能的。 

**为什么有效**：BFS 保证未加权图中的最短路径，因为它逐级探索状态。 通过在状态中包含密钥位掩码，BFS 确保我们第一次到达收集了所有密钥的状态时，是通过最短的可能路径。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def shortestPathAllKeys(self, grid: List[str]) -> int:
        m, n = len(grid), len(grid[0])
        all_keys = 0
        start_row = start_col = 0
        
        # Find start and total keys
        for i in range(m):
            for j in range(n):
                char = grid[i][j]
                if char == '@':
                    start_row, start_col = i, j
                elif 'a' <= char <= 'f':
                    all_keys |= (1 << (ord(char) - ord('a')))
        
        # BFS
        queue = deque([(start_row, start_col, 0)])
        visited = set((start_row, start_col, 0))
        steps = 0
        directions = [(0,1),(1,0),(0,-1),(-1,0)]
        
        while queue:
            for _ in range(len(queue)):
                row, col, keys = queue.popleft()
                if keys == all_keys:
                    return steps
                for dr, dc in directions:
                    r, c = row + dr, col + dc
                    if 0 <= r < m and 0 <= c < n:
                        cell = grid[r][c]
                        if cell == '#':
                            continue
                        new_keys = keys
                        if 'a' <= cell <= 'f':
                            new_keys |= (1 << (ord(cell) - ord('a')))
                        if 'A' <= cell <= 'F' and not (keys & (1 << (ord(cell) - ord('A')))):
                            continue
                        state = (r, c, new_keys)
                        if state not in visited:
                            visited.add(state)
                            queue.append(state)
            steps += 1
        
        return -1
```此 Python 实现使用起始位置和零键的位掩码来初始化 BFS 队列。 它逐级处理队列，每当收集到密钥时更新密钥位掩码，并且仅在收集到相应密钥时才允许通过锁进行移动。 访问集可防止重新处理冗余状态，从而确保 BFS 探索每个唯一状态一次。 当收集到所有密钥后，将返回所采取的步数。 

## 解决方案```go
package main

import "container/list"

func shortestPathAllKeys(grid []string) int {
    m, n := len(grid), len(grid[0])
    var allKeys int
    startRow, startCol := 0, 0
    
    // Find start and total keys
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            char := grid[i][j]
            if char == '@' {
                startRow, startCol = i, j
            } else if char >= 'a' && char <= 'f' {
                allKeys |= 1 << (char - 'a')
            }
        }
    }
    
    type state struct {
        row, col, keys int
    }
    
    queue := list.New()
    queue.PushBack(state{startRow, startCol, 0})
    visited := make(map[state]bool)
    visited[state{startRow, startCol, 0}] = true
    steps := 0
    directions := [][2]int{{0,1},{1,0},{0,-1},{-1,0}}
    
    for queue.Len() > 0 {
        for size := queue.Len(); size > 0; size-- {
            front := queue.Remove(queue.Front()).(state)
            row, col, keys := front.row, front.col, front.keys
            if keys == allKeys {
                return steps
            }
            for _, d := range directions {
                r, c := row + d[0], col + d[1]
                if r >= 0 && r < m && c >= 0 && c < n {
                    cell := grid[r][c]
                    if cell == '#' {
                        continue
                    }
                    newKeys := keys
                    if cell >= 'a' && cell <= 'f' {
                        newKeys |= 1 << (cell - 'a')
                    }
                    if cell >= 'A' && cell <= 'F' && (keys&(1<<(cell-'A')) == 0) {
                        continue
                    }
                    newState := state{r, c, newKeys}
                    if !visited[newState] {
                        visited[newState] = true
                        queue.PushBack(newState)
                    }
                }
            }
        }
        steps++
    }
    
    return -1
}
