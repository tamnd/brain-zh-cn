 **难度：** 🔴难
 **主题：** 数组、哈希表、广度优先搜索

 ## 解决方案

 ## 问题理解

 该问题要求我们确定从给定的起始巴士站出发所需的最少巴士数量（`source`）到目的地巴士站（`target`）给定一组巴士路线。 每条路线都表示为特定公交车无限循环经过的公交车站列表。 例如，如果`routes[0] = [1,5,7]`，公交车反复从车站出发`1`到`5`到`7`并回到`1`。 

输入由二维数组组成`routes`, 一个整数`source`，和一个整数`target`。 预期输出是一个整数，表示到达目的地所需的最少公交车数或`-1`如果不可能的话。 

约束告诉我们问题的规模：路线数量最多为 500 条，每条路线最多可以有 105 个站点，所有路线的站点总数不超过 105 个。每个站点都是小于 10^6 的非负整数，并且单个路线内的所有站点都是唯一的。 这表明直接尝试所有停靠点到停靠点路径的强力方法会太慢； 需要一种更有效的方法。 边缘情况包括以下场景：`source`等于`target`（需要 0 辆巴士），或者与源或目标不相交的路线（需要`-1`结果）。 

## 方法

 蛮力方法将尝试从`source`到`target`通过探索所有可能的公交车站顺序。 这可能涉及递归检查每个站点的每个可能的公交车路线换乘。 虽然这会产生正确的答案，但由于大量的停靠点和路线，计算量巨大，可能会导致指数时间复杂度。 

最佳方法依赖于将问题表示为图遍历。 我们可以将**公交车视为节点**，而不是单独对待停靠站。 如果两辆公共汽车至少共享一个公共站点，则它们是相连的。 我们还维护从每个站点到所有访问该站点的巴士的地图。 使用它，我们可以从包含以下内容的所有总线开始执行**广度优先搜索（BFS）**`source`停止。 在每个 BFS 级别，我们都会增加乘坐的公交车数量。 当我们遇到一辆到达终点站的公交车时`target`停止，我们返回当前级别作为答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(Σ(路线[i].长度)!) | O(Σ(路线[i].长度)) | 探索所有停止序列，对于大输入呈指数增长 |
 | 最佳 | O(N + R^2 + Σ(routes[i].length)) | O(N + R^2 + Σ(routes[i].length)) | O(N + R^2) | O(N + R^2) | 公交车图上的 BFS，将站点映射到公交车，避免冗余路径； N = 总停靠站数，R = 公交车数量 |

 ## 算法演练

 1.如果`source`等于`target`，立即返回`0`因为不需要公共汽车。 
2. 构建从每个公交车站到访问该车站的所有公交车的映射。 这使我们能够快速确定可以从任何站点乘坐哪些巴士。 
3. 构建一个图，其中每个节点代表一辆公交车，如果两辆公交车共用一个公共车站，则它们之间存在一条边。 这代表可能的巴士换乘。 
4. 初始化一个 BFS 队列，其中包含所有总线`source`停止。 跟踪访问过的公交车以避免循环。 
5.逐级进行BFS。 在每个级别，增加一个计数器，表示到目前为止乘坐的公交车数量。 
6. 对于当前级别的每条总线，检查是否达到`target`。 如果是，则返回当前总线数。 
7. 否则，将连接到当前总线的所有未访问总线入队并将它们标记为已访问。 
8. 如果 BFS 完成后没有找到到达目的地的总线`target`， 返回`-1`因为目标遥不可及。 

**为什么有效：** 该算法保证了最少的总线数量，因为 BFS 逐级探索所有可能的路径。 当我们第一次到达包含目标车站的巴士时，我们使用了尽可能少的换乘次数。 

## Python 解决方案```python
from collections import defaultdict, deque
from typing import List, Set

class Solution:
    def numBusesToDestination(self, routes: List[List[int]], source: int, target: int) -> int:
        if source == target:
            return 0
        
        stop_to_buses = defaultdict(set)
        for bus_index, stops in enumerate(routes):
            for stop in stops:
                stop_to_buses[stop].add(bus_index)
        
        bus_graph = [set() for _ in range(len(routes))]
        for stop, buses in stop_to_buses.items():
            buses = list(buses)
            for i in range(len(buses)):
                for j in range(i + 1, len(buses)):
                    bus_graph[buses[i]].add(buses[j])
                    bus_graph[buses[j]].add(buses[i])
        
        start_buses = stop_to_buses[source]
        target_buses = stop_to_buses[target]
        
        queue = deque([(bus, 1) for bus in start_buses])
        visited_buses: Set[int] = set(start_buses)
        
        while queue:
            bus, buses_taken = queue.popleft()
            if bus in target_buses:
                return buses_taken
            for neighbor in bus_graph[bus]:
                if neighbor not in visited_buses:
                    visited_buses.add(neighbor)
                    queue.append((neighbor, buses_taken + 1))
        
        return -1
```**说明：** Python 解决方案首先将车站映射到公交车，并构建由共享车站连接的公交车图。 BFS 从包含以下内容的所有总线发起`source`。 每个 BFS 级别都代表占用一条额外的总线。 当我们第一次遇到包含以下内容的总线时，我们返回级别`target`。 跟踪访问过的巴士以避免重复探索。 

## 解决方案```go
package main

func numBusesToDestination(routes [][]int, source int, target int) int {
    if source == target {
        return 0
    }

    stopToBuses := make(map[int][]int)
    for i, stops := range routes {
        for _, stop := range stops {
            stopToBuses[stop] = append(stopToBuses[stop], i)
        }
    }

    busGraph := make([]map[int]struct{}, len(routes))
    for i := range busGraph {
        busGraph[i] = make(map[int]struct{})
    }

    for _, buses := range stopToBuses {
        for i := 0; i < len(buses); i++ {
            for j := i + 1; j < len(buses); j++ {
                busGraph[buses[i]][buses[j]] = struct{}{}
                busGraph[buses[j]][buses[i]] = struct{}{}
            }
        }
    }

    startBuses := stopToBuses[source]
    targetBuses := make(map[int]struct{})
    for _, b := range stopToBuses[target] {
        targetBuses[b] = struct{}{}
    }

    queue := make([][2]int, 0)
    visited := make(map[int]struct{})
    for _, b := range startBuses {
        queue = append(queue, [2]int{b, 1})
        visited[b] = struct{}{}
    }

    for len(queue) > 0 {
        current := queue[0]
        queue = queue[1:]
        bus, busesTaken := current[0], current[1]
        if _, ok := targetBuses[bus]; ok {
            return busesTaken
        }
        for neighbor := range busGraph[bus] {
            if _, ok := visited[neighbor]; !ok {
                visited[neighbor] = struct{}{}
                queue = append(queue, [2]int{neighbor, busesTaken + 1})
            }
        }
    }

    return -1
}
```**说明：** Go 实现镜像了 Python 逻辑。 必要时地图会取代集合。 BFS 使用切片队列来执行。 总线图用邻接图表示。 该算法有效地找到所需的最少总线。
