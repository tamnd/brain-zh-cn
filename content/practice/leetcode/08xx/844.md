 # LeetCode 844 - 退格字符串比较

 ## 问题理解

 该问题要求我们确定两个字符串在处理退格操作后是否变得相同。 每个字符串代表在文本编辑器中输入的字符，其中`'#'`字符的意思是“删除前一个字符”，类似于按键盘上的退格键。 

我们有两个输入字符串，`s`和`t`。 两个字符串都包含小写英文字母并且`'#'`特点。 我们必须模拟所有键入和退格操作完成后每个字符串的外观，然后比较最终结果。 

例如，如果我们处理字符串`"ab#c"`：

- 类型`'a'`→`"a"`- 类型`'b'`→`"ab"`-`'#'`删除`'b'`→`"a"`- 类型`'c'`→`"ac"`最终处理后的字符串为`"ac"`。 

约束相对较小，两个字符串的长度最多`200`。 因此，即使是简单的模拟方法也足够快。 然而，后续的问题是我们是否可以解决这个问题`O(n)`时间和`O(1)`额外的空间，这鼓励更优化的解决方案。 

一些边缘情况很重要：

 - 多个连续的退格键，例如`"a###"`- 退格应用于空字符串，例如`"###"`- 处理后变空的字符串
 - 不同的原始字符串产生相同的最终字符串
 - 处理后不同长度的字符串

 如果幼稚的实现在不首先检查的情况下尝试从空结构中删除字符，则很容易失败。 

## 方法

 ### 蛮力方法

 最直接的解决方案是显式构建每个字符串的最终处理版本。 

我们可以使用堆栈来模拟打字：

 - 当我们遇到普通字符时，将其压入堆栈。 
- 当我们遇到`'#'`，如果堆栈不为空，则弹出顶部字符。 

处理整个字符串后，堆栈包含最终的文本编辑器状态。 

我们对两个字符串重复此过程并比较结果字符串。 

这种方法是正确的，因为堆栈自然地模拟了文本编辑器的行为。 最近输入的字符是第一个被退格操作删除的字符。 

尽管此解决方案对于给定的约束足够有效，但它需要与字符串长度成比例的额外空间。 

### 最佳两指针方法

 关键的观察是我们实际上不需要构造最终处理后的字符串。 

相反，我们可以从右到左处理两个字符串。 向后遍历时：

 - A`'#'`意味着我们应该跳过一个未来的角色。 
- 多种的`'#'`字符会累积多次跳跃。 

这使我们能够确定每个字符串中的下一个有效字符，而无需构建中间结果。 

使用两个指针：

 - 从每个字符串的末尾开始。 
- 向后移动，同时考虑退格键。 
- 比较下一个有效字符。 
- 如果不同，则返回`False`。 
- 如果两个字符串同时完成，则返回`True`。 

这种方法实现了`O(1)`额外的空间，因为我们只使用指针和计数器。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n + m) | O(n + m) | 使用堆栈模拟打字 |
 | 最佳| O(n + m) | O(1) | O(1) | 使用两个指针向后遍历 |

 ## 算法演练

 ### 最优两指针算法

 1.初始化两个指针，一个在末尾`s`和最后一个`t`。 
2. 为每个字符串创建一个帮助进程，通过跳过已删除的字符来查找下一个有效字符。 
3. 向后处理字符串时：

 - 如果当前字符是`'#'`，增加跳过计数器并向左移动。 
- 如果当前字符是字母并且跳跃计数器大于零，则递减跳跃计数器并向左移动。 
- 否则，当前字符有效并准备进行比较。 
4. 在两个字符串中找到下一个有效字符后：

 - 如果只有一个字符串仍然包含有效字符，则返回`False`。 
- 如果两个字符都存在但不同，则返回`False`。 
5. 将两个指针向左移动一步并重复该过程。 
6. 如果两个字符串都被完全处理且没有不匹配，则返回`True`。 

### 为什么它有效

 该算法之所以有效，是因为向后遍历可以让我们立即确定一个字符是否能在所有未来的退格中幸存下来。 每一个`'#'`取消一个前面的字符。 通过维护跳过计数器，我们可以正确忽略已删除的字符，而无需显式构造最终字符串。 由于每个字符最多处理一次，因此比较准确地匹配真实的最终编辑器状态。 

## Python 解决方案```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        i = len(s) - 1
        j = len(t) - 1

        while i >= 0 or j >= 0:
            skip_s = 0
            while i >= 0:
                if s[i] == '#':
                    skip_s += 1
                    i -= 1
                elif skip_s > 0:
                    skip_s -= 1
                    i -= 1
                else:
                    break

            skip_t = 0
            while j >= 0:
                if t[j] == '#':
                    skip_t += 1
                    j -= 1
                elif skip_t > 0:
                    skip_t -= 1
                    j -= 1
                else:
                    break

            if i >= 0 and j >= 0:
                if s[i] != t[j]:
                    return False
            elif i >= 0 or j >= 0:
                return False

            i -= 1
            j -= 1

        return True
```该实现首先将两个指针放置在输入字符串的末尾。 只要至少一个字符串仍包含未处理的字符，主循环就会继续。 

在循环内，每个字符串都会被独立处理以找到下一个有效字符。 这`skip_s`和`skip_t`计数器跟踪有多少个字符由于退格而应被忽略。 

当一个`'#'`遇到时，跳过计数器增加。 当跳过计数器为正值时出现正常字符时，该字符将被跳过，因为它已被退格键删除。 

一旦在两个字符串中找到有效字符，算法就会对它们进行比较。 如果它们不同，则处理后字符串不可能相等。 

如果一个字符串还有剩余字符而另一个字符串没有剩余字符，则最终处理后的字符串不同，因此函数返回`False`。 

如果循环完成且没有不匹配，则处理后的字符串是相同的，因此函数返回`True`。 

## 解决方案```go
func backspaceCompare(s string, t string) bool {
	i := len(s) - 1
	j := len(t) - 1

	for i >= 0 || j >= 0 {
		skipS := 0
		for i >= 0 {
			if s[i] == '#' {
				skipS++
				i--
			} else if skipS > 0 {
				skipS--
				i--
			} else {
				break
			}
		}

		skipT := 0
		for j >= 0 {
			if t[j] == '#' {
				skipT++
				j--
			} else if skipT > 0 {
				skipT--
				j--
			} else {
				break
			}
		}

		if i >= 0 && j >= 0 {
			if s[i] != t[j] {
				return false
			}
		} else if i >= 0 || j >= 0 {
			return false
		}

		i--
		j--
	}

	return true
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于 Go 字符串内部是字节切片，因此索引为`s[i]`直接有效地访问单个字符。 

无需特殊处理`nil`是必需的，因为该问题保证有效的字符串输入。 该算法使用整数索引和恒定的额外内存，满足最佳复杂性要求。

 ## 边缘情况

 ### 连续退格键

 输入如`"a###"`很容易导致错误，因为退格符比实际字符多。 幼稚的实现可能会尝试从空堆栈或无效索引位置中删除字符。 

两指针解决方案使用跳过计数器自然地处理这个问题。 额外的退格键只会增加跳过计数，并且不会发生无效操作。 

### 变为空的字符串

 案例如`"ab##"`或者`"###"`产生空的最终字符串。 某些实现错误地比较中间状态而不是完全处理的结果。 

此实现会继续处理，直到两个指针都耗尽，从而确保正确比较空的最终字符串。 

### 剩余字符不相等

 当一个已处理的字符串仍然包含有效字符而另一个已耗尽时，可能会出现微妙的错误。 

例如：```
s = "a"
t = ""
```处理后，一个指针仍然有效，而另一个则不再有效。 实现显式检查此条件：```
elif i >= 0 or j >= 0:
    return False
```当处理的字符串长度不同时，这保证了正确的行为。
