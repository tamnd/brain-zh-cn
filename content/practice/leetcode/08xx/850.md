[LeetCode 850 题](https://leetcode.com/problems/rectangle-area-ii/)

 **难度：** 🔴难
 **主题：** 数组、线段树、扫描线、有序集

 ## 解决方案

 ## 问题理解

 该问题要求我们计算 2D 平面上一组轴对齐矩形覆盖的总面积。 每个矩形由其左下角和右上角坐标定义`[xi1, yi1, xi2, yi2]`。 挑战在于矩形可以重叠，并且任何重叠区域只能计算**一次**。 最终面积必须按模返回`10^9 + 7`由于潜在的巨大结果。 

输入`rectangles`是最多 200 个矩形的列表，每个矩形的坐标最多可达`10^9`。 这些约束保证矩形具有非零面积并且坐标正确排序（`xi1 <= xi2`和`yi1 <= yi2`）。 

边缘情况包括完全重叠的矩形、在边缘或角落接触的矩形以及如果不小心处理可能导致整数溢出的非常大的矩形。 该问题本质上需要计算**多个矩形的并集面积**，这是一个经典的计算几何问题。 

## 方法

 ### 暴力方法

 一种强力解决方案是迭代矩形覆盖的 2D 平面中的每个单位正方形，将单元格标记为已覆盖，然后对它们进行计数。 虽然这种方法在概念上是正确的，但它是不可行的，因为坐标可以大到`10^9`，使得网格表示变得不可能。 由于潜在的点数量较多，即使使用集合或地图来存储覆盖点的优化版本也太慢。 

### 最佳方法

 最佳方法使用**带有线段树**的扫描线算法**或**带有线扫描的坐标压缩**。 关键思想是：

 1. 用一条垂直线从左向右扫过所有矩形。 
2. 跟踪**活动间隔**（与当前垂直线相交的矩形的 y 范围）并计算总垂直覆盖范围。 
3. 将垂直覆盖范围乘以自上次事件以来移动的水平距离，以计算添加的面积。 
4. 当扫描线经过矩形边缘时，使用线段树或排序列表有效地管理添加和删除间隔。 

这将问题从不可行的 2D 网格简化为沿 y 轴的一系列可管理的 1D 间隔计算，并在离散的 x 坐标处进行处理。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(X*Y) | O(X*Y) | 由于坐标大而不可行 |
 | 扫描线+线段树| O(N log N) | O(N log N) | O(N) | 高效处理重叠和大坐标 |

 ## 算法演练

 1. **提取事件**：对于每个矩形`[x1, y1, x2, y2]`，创建两个事件：`(x1, y1, y2, 1)`对于矩形起点和`(x2, y1, y2, -1)`对于矩形末端。 这`1`或者`-1`指示是添加还是删除间隔。 
2. **对事件进行排序**：按 x 坐标对所有事件进行排序。 这确保我们按从左到右的顺序处理扫描线。 
3. **y 值的坐标压缩**：从矩形收集所有唯一的 y 值并将它们映射到压缩索引。 这使我们能够有效地维护线段树或数组中的间隔。 
4. **初始化线段树或计数数组**：创建一个结构体来维护每个y区间被覆盖的次数。 
5. **扫线流程**：

 1. 对于每个 x 坐标事件，根据活动间隔计算总垂直覆盖范围。 
2. 将覆盖范围乘以自上次事件以来的 x 差值即可得到面积贡献。 
3. 通过在当前矩形中添加或删除 y 间隔来更新活动间隔。 
6. **面积贡献总和**：保持面积模数的运行总计`10^9 + 7`。 

**为什么起作用**：通过按排序的 x 顺序处理事件并维护活动的 y 间隔，该算法可确保平面的每个部分都被精确计数一次，即使在具有多个重叠的区域也是如此。 

## Python 解决方案```python
from typing import List
from bisect import bisect_left

class Solution:
    def rectangleArea(self, rectangles: List[List[int]]) -> int:
        MOD = 10**9 + 7
        events = []
        y_coords = set()

        # Collect events and y-coordinates
        for x1, y1, x2, y2 in rectangles:
            events.append((x1, y1, y2, 1))
            events.append((x2, y1, y2, -1))
            y_coords.add(y1)
            y_coords.add(y2)
        
        # Coordinate compression
        ys = sorted(y_coords)
        y_i = {v: i for i, v in enumerate(ys)}

        count = [0] * (len(ys) - 1)
        events.sort()
        prev_x = 0
        area = 0

        def calc_covered_length():
            length = 0
            for i, c in enumerate(count):
                if c > 0:
                    length += ys[i + 1] - ys[i]
            return length

        for x, y1, y2, typ in events:
            covered_length = calc_covered_length()
            area += covered_length * (x - prev_x)
            area %= MOD
            # Update counts
            for i in range(y_i[y1], y_i[y2]):
                count[i] += typ
            prev_x = x
        
        return area % MOD
```**说明**：代码首先收集矩形边缘作为事件并压缩 y 坐标以减少内存使用。 这`count`数组跟踪活动间隔。 在每次事件中，它都会计算覆盖的垂直长度，并将其乘以自上次事件以来的水平距离，并将其添加到总面积中。 间隔根据矩形的开始或结束进行更新。 

## 解决方案```go
import (
    "sort"
)

func rectangleArea(rectangles [][]int) int {
    MOD := int(1e9 + 7)
    type Event struct {
        x, y1, y2, typ int
    }

    events := []Event{}
    ySet := map[int]struct{}{}
    for _, r := range rectangles {
        events = append(events, Event{r[0], r[1], r[3], 1})
        events = append(events, Event{r[2], r[1], r[3], -1})
        ySet[r[1]] = struct{}{}
        ySet[r[3]] = struct{}{}
    }

    ys := []int{}
    for y := range ySet {
        ys = append(ys, y)
    }
    sort.Ints(ys)
    yIndex := map[int]int{}
    for i, y := range ys {
        yIndex[y] = i
    }

    count := make([]int, len(ys)-1)
    sort.Slice(events, func(i, j int) bool {
        return events[i].x < events[j].x
    })

    prevX := 0
    area := 0

    calcCovered := func() int {
        length := 0
        for i, c := range count {
            if c > 0 {
                length += ys[i+1] - ys[i]
            }
        }
        return length
    }

    for _, e := range events {
        covered := calcCovered()
        area += covered * (e.x - prevX)
        area %= MOD
        for i := yIndex[e.y1]; i < yIndex[e.y2]; i++ {
            count[i] += e.typ
        }
        prevX = e.x
    }

    return area % MOD
}
```**Go Notes**：我们使用切片和贴图来压缩 y 坐标。 排序是显式使用的`sort.Slice`。 算术模`10^9 + 7`在累积期间应用以防止溢出。 

## 工作示例

 ### 示例 1

 输入：`[[0,0,2,2],[1,0,2,3],[1,0,3,1]]`逐步浏览事件：

 | --- | --- | --- | --- | --- |
 | 0 | [0,2]| 2 | 0 | 0 |
 | 1 | [0,2],[0,3] | 3 | 1 | 3 |
 | 2 | [0,3],[0,1] 已删除 | 3 | 1 | 3 |
 | 3 | 无 | 0 | 1 | 0 |

 总面积 = 6

 ### 示例 2

 输入：`[[0,0,1000000000,1000000000]]`只有一个矩形：

 | --- | --- | --- | --- | --- |
 | 0 | [0,1e9] | [0,1e9] | 1e9 | 1e9 0 | 0 |
 | 1e9 | 1e9 删除 | 1e9 | 1e9 1e9 | 1e9 1e18 % MOD = 49 | 1e18 % MOD = 49 |

 总面积 = 49
