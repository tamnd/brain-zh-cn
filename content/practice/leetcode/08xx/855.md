[LeetCode 855 题](https://leetcode.com/problems/exam-room/)

 **难度：** 🟡 中等
 **主题：** 设计、堆（优先级队列）、有序集

 ## 解决方案

 ## 问题理解

 这个问题需要设计一个考试室座位安排的模拟。 我们有`n`单排座位，标记为`0`到`n - 1`。 学生一一进入，每个学生选择一个座位，使得与最近的占用座位的距离最大化。 如果有多个座位达到相同的最大距离，则学生选择索引最小的座位。 如果房间是空的，则第一个学生坐在座位上`0`。 

输入代表一系列的操作`ExamRoom`班级：初始化座位数、安排学生座位或将学生从特定座位上移走。 输出是返回的座位号`seat()`致电或`null`用于不产生返回值的操作。 

限制因素很大。`n`可以大到`10^9`，这意味着我们无法将所有座位明确存储在内存中。 最多`10^4`将执行操作，因此解决方案必须有效地找到最佳的座椅和手柄拆卸方式。 该问题保证了`leave(p)`只会针对当前占用的座位进行调用，这简化了错误处理。 

边缘情况包括一个空房间、一个有一名学生的房间、坐在排末端的学生以及可能合并空闲座位间隔的连续叶子。 有效处理最大可能的座位索引而不迭代所有位置至关重要。 

## 方法

 暴力方法将维护一个已占用席位的列表或数组。 对于每个`seat()`操作时，我们将迭代所有空闲位置，计算到最近的占用座位的距离，并选择最大化该距离的位置。 虽然正确，但这种方法对于大型企业来说太慢了`n`因为迭代潜在的数十亿个席位是不可行的。 

最佳解决方案的关键见解是我们只需要跟踪**空座位的间隔**而不是单个座位。 每个间隔可以由其起始和结束占用位置（或边缘的边界）来表示。 所选择的座位始终位于最大间隔的中点（如果是第一个或最后一个座位，则位于边界）。 使用**优先级队列（最大堆）**通过潜在的最大距离来存储间隔允许`seat()`要有效率。 我们还需要一个数据结构（如集合或地图）来在学生离开时有效地合并间隔。 

通过关注间隔而不是单个座位，我们可以有效地维持这些间隔并找到最大的间隔来减少问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | 每个座位 O(n) | O(n) | 迭代所有座位以找到最大距离。 仅适用于小n。 |
 | 最佳| 每个座位/休假 O(log k) | O(k) | 维护优先级队列中的间隔，其中 k 是占用的座位数。 对于大 n 和许多操作非常有效。 |

 ## 算法演练

 1. 初始化一个空房间`n`座位。 维护间隔的最大堆，最初包含间隔`[0, n - 1]`。 
2. 当学生进入（`seat()`）：

 a. 弹出距堆最大潜在距离的区间。 计算占用的座位：如果区间包含第一个或最后一个座位，则选择边界； 否则，选择中点。 

b. 将间隔分成两个较小的间隔（不包括所选座位），并将它们推回到堆中。 

c. 将座位标记为已占用。 
3. 当学生离开时（`leave(p)`）：

 a. 确定座位附近的间隔`p`需要合并的。 从堆中删除旧的间隔。 

b. 创建一个新的合并间隔，其中包括释放的席位并将其推回堆中。 
4. 对堆使用比较函数，首先按距离确定间隔的优先级，如果距离相等，则再按较低的座位索引确定优先级。 

**为什么有效**：该算法保持堆始终包含最大可用间隔的不变性。 坐在最大间隔的中点可以保证与其他学生的最大距离。 合并间隔时，堆会更新，因此下一个座位始终是最佳的。 

## Python 解决方案```python
import heapq

class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.heap = []
        self.occupied = set()
        # store intervals as (-distance, start, end)
        heapq.heappush(self.heap, (-self.distance(0, n - 1), 0, n - 1))

    def distance(self, start, end):
        if start == 0 or end == self.n - 1:
            return end - start
        return (end - start) // 2

    def seat(self) -> int:
        while True:
            neg_dist, start, end = heapq.heappop(self.heap)
            if start not in self.occupied or end not in self.occupied or start == 0 or end == self.n - 1:
                break

        if start == 0:
            seat = 0
        elif end == self.n - 1:
            seat = self.n - 1
        else:
            seat = (start + end) // 2

        self.occupied.add(seat)

        if seat > start:
            heapq.heappush(self.heap, (-self.distance(start, seat - 1), start, seat - 1))
        if seat < end:
            heapq.heappush(self.heap, (-self.distance(seat + 1, end), seat + 1, end))

        return seat

    def leave(self, p: int) -> None:
        self.occupied.remove(p)
        left = p - 1
        right = p + 1
        start, end = p, p

        while left in self.occupied:
            left -= 1
        if left >= 0:
            start = left + 1

        while right in self.occupied:
            right += 1
        if right < self.n:
            end = right - 1

        heapq.heappush(self.heap, (-self.distance(start, end), start, end))
```Python 解决方案使用最大堆来跟踪按学生可以达到的最大距离排序的间隔。 它有效地弹出最大间隔，选择最佳座位，并将生成的子间隔推回到堆中。 这`occupied`set 允许对间隔边界进行恒定时间检查。 

## 解决方案```go
package main

import (
    "container/heap"
)

type Interval struct {
    start, end int
    dist       int
}

type MaxHeap []Interval

func (h MaxHeap) Len() int { return len(h) }
func (h MaxHeap) Less(i, j int) bool {
    if h[i].dist == h[j].dist {
        return h[i].start < h[j].start
    }
    return h[i].dist > h[j].dist
}
func (h MaxHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x any)  { *h = append(*h, x.(Interval)) }
func (h *MaxHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

type ExamRoom struct {
    n        int
    heap     MaxHeap
    occupied map[int]bool
}

func Constructor(n int) ExamRoom {
    h := MaxHeap{{0, n - 1, n - 1}}
    return ExamRoom{n, h, make(map[int]bool)}
}

func distance(n, start, end int) int {
    if start == 0 || end == n-1 {
        return end - start
    }
    return (end - start) / 2
}

func (this *ExamRoom) Seat() int {
    for {
        interval := heap.Pop(&this.heap).(Interval)
        if !this.occupied[interval.start] || !this.occupied[interval.end] || interval.start == 0 || interval.end == this.n-1 {
            var seat int
            if interval.start == 0 {
                seat = 0
            } else if interval.end == this.n-1 {
                seat = this.n - 1
            } else {
                seat = (interval.start + interval.end) / 2
            }
            this.occupied[seat] = true
            if seat > interval.start {
                heap.Push(&this.heap, Interval{interval.start, seat - 1, distance(this.n, interval.start, seat-1)})
            }
            if seat < interval.end {
                heap.Push(&this.heap, Interval{seat + 1, interval.end, distance(this.n, seat+1, interval.end)})
            }
            return seat
        }
    }
}

func (this *ExamRoom) Leave(p int) {
    delete(this.occupied, p)
    left, right := p, p
    for this.occupied[left-1] {
        left--
    }
    for this.occupied[right+1] {
        right++
    }
    heap.Push(&this.heap, Interval{left, right, distance(this.n, left, right)})
}
```Go 实现镜像了 Python 版本，但使用了`container/heap`为优先级队列。 间隔存储在结构中，堆比较优先考虑较大的距离，打破索引较低的关系。 这`occupied`地图可以进行有效的成员资格检查。
