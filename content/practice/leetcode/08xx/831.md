 ## 解决方案

 ## 问题理解

 该问题需要创建个人信息字符串的**屏蔽版本**`s`可以是**电子邮件地址**或**电话号码**。 目标是隐藏敏感信息，同时保留足够的数据以最小程度地识别用户。 

对于 **电子邮件**，我们需要小写所有字符，并将名称的中间字母（除了第一个和最后一个字符之外的所有字符）替换为 5 个星号`"*****"`。 该域保持小写而不进行修改。 即使名称很短（如两个字符），中间仍必须用 5 个星号替换。 

对于**电话号码**，我们首先删除所有非数字字符。 然后，我们将**本地号码**（最后 10 位数字）与**国家/地区代码**（剩余的前导数字，最多 3 位）分开。 本地号码始终掩码为`"***-***-XXXX"`国家/地区代码前面带有`+`以及与它的长度一样多的星号。 

约束保证输入是**有效**，这意味着我们不需要验证格式。 电子邮件的输入长度限制为 40 个字符，电话号码的输入长度限制为 20 个字符，因此效率不是主要问题。 边缘情况通常源于非常短的电子邮件名称、最少的电话号码（10 位数字）或最多的国家/地区代码（3 位数字）。 

## 方法

 **暴力方法**是手动检查每个字符并根据规则屏蔽它们。 对于电子邮件，我们可以迭代字符串，直到`'@'`符号，收集第一个和最后一个字符，并用 5 个星号替换中间。 对于电话号码，我们可以迭代字符串，删除非数字字符，确定国家/地区代码长度，然后构建最终字符串。 虽然这可以正常工作，但它涉及多次迭代和不必要的字符串操作，这些可以被简化。 

**最佳方法**利用**直接字符串操作和切片**。 对于电子邮件，我们可以按`'@'`，将两个部分都小写，并连接第一个字符 +`"*****"`+ 域名的最后一个字符。 对于电话号码，我们可以使用列表理解来过滤数字，计算国家/地区代码长度，并使用格式化字符串插值构造屏蔽字符串。 这减少了不必要的循环和中间结构。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 逐字符迭代，手动构造字符串 |
 | 最佳| O(n) | O(n) | 使用分割、小写、切片和字符串格式来实现简洁的屏蔽 |

 ## 算法演练

 1. **检查输入类型**：如果`s`包含`'@'`，这是一封电子邮件； 否则，它是一个电话号码。 
2. **电子邮件屏蔽**：

 1. 将字符串拆分为`name`和`domain`使用`'@'`分隔符。 
2. 两者都转换`name`和`domain`为小写。 
3. 将屏蔽名称构造为第一个字符、5 个星号和最后一个字符。 
4. 将屏蔽名称与`'@'`和域名。 
3. **电话号码屏蔽**：

 1. 删除所有非数字字符`s`。 
2. 将**本地号码**识别为最后 10 位数字。 
3. 将**国家代码**识别为所有剩余的前导数字。 
4. 将国家代码的掩码前缀构造为`+`后跟与国家/地区代码长度一样多的星号，如果没有国家/地区代码则为空。 
5. 连接国家代码前缀，`"***-***-"`，以及本地号码的最后 4 位数字。 

**为什么有效**：该算法正确地将电子邮件与电话号码分开，精确应用各自的屏蔽规则，并保证敏感部分被遮挡。 切片和格式化等字符串操作可确保输出与所需的模式完全匹配。 

## Python 解决方案```python
class Solution:
    def maskPII(self, s: str) -> str:
        if '@' in s:
            # Email masking
            name, domain = s.split('@')
            name = name.lower()
            domain = domain.lower()
            masked_name = name[0] + '*****' + name[-1]
            return masked_name + '@' + domain
        else:
            # Phone number masking
            digits = [c for c in s if c.isdigit()]
            local = ''.join(digits[-10:])
            country_len = len(digits) - 10
            country_prefix = '+' + '*' * country_len + '-' if country_len else ''
            return f"{country_prefix}***-***-{local[-4:]}"
```Python 实现使用简单的字符串操作。 对于电子邮件，`split`和`lower`简化流程。 对于电话号码，列表理解可以有效地过滤数字，字符串格式可以处理掩码。 这确保了清晰度和正确性。 

## 解决方案```go
import (
    "strings"
    "unicode"
)

func maskPII(s string) string {
    if strings.Contains(s, "@") {
        // Email masking
        parts := strings.Split(s, "@")
        name := strings.ToLower(parts[0])
        domain := strings.ToLower(parts[1])
        maskedName := string(name[0]) + "*****" + string(name[len(name)-1])
        return maskedName + "@" + domain
    } else {
        // Phone number masking
        digits := []rune{}
        for _, c := range s {
            if unicode.IsDigit(c) {
                digits = append(digits, c)
            }
        }
        local := string(digits[len(digits)-10:])
        countryLen := len(digits) - 10
        countryPrefix := ""
        if countryLen > 0 {
            countryPrefix = "+" + strings.Repeat("*", countryLen) + "-"
        }
        return countryPrefix + "***-***-" + local[len(local)-4:]
    }
}
```在 Go 中，我们使用切片来处理字符串`rune`正确管理人物。 屏蔽逻辑反映了 Python。`strings.Repeat`用于星号，并且`unicode.IsDigit`有效过滤数字字符。
