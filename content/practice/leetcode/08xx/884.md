 ## 解决方案

 # LeetCode 884，两句话中的生僻字

 ## 问题理解

 这个问题要求我们找到两个句子之间所有被认为“不常见”的单词。 

每个句子都由小写单词组成，并用单个空格分隔。 如果一个单词满足两个条件，则该单词被视为不常见：

 1. 它在一个句子中只出现一次。 
2.它根本没有出现在另一句话中。 

我们有两个输入字符串，`s1`和`s2`。 每个字符串代表一个句子。 任务是返回一个列表，其中包含两个句子中不常见的每个单词。 

例如，考虑：```
s1 = "this apple is sweet"
s2 = "this apple is sour"
```的话`"this"`和`"apple"`都出现在两个句子中，因此它们并不罕见。 这个词`"is"`也出现在两个句子中。 这个词`"sweet"`恰好出现一次`s1`并且无处可去`s2`，所以这种情况并不常见。 相似地，`"sour"`恰好出现一次`s2`并且无处可去`s1`，所以这也是不常见的。 

限制非常小：

 - 每个句子长度最多 200 个字符。 
- 单词仅包含小写英文字母。 
- 单词之间恰好间隔一个空格。 

这些限制告诉我们，效率并不是主要问题，因为总字数很少。 然而，问题本质上是关于频率计数，因此使用哈希图是最自然、最干净的解决方案。 

有几个重要的边缘情况需要考虑：

 - 一个单词可能会在同一个句子中多次出现，这会立即使其失去不常见的资格。 
- 一个单词可能在每个句子中出现一次，这也会使其失去资格。 
- 一个句子可能只包含重复的单词，而另一个句子则包含一个有效的不常见单词。 
- 答案可以按任意顺序返回，因此顺序并不重要。 

该问题保证有效的格式，意思是：

 - 没有前导或尾随空格
 - 单词之间恰好有一个空格
 - 仅限小写字母和空格

 由于这些保证，用空格分割句子是安全且直接的。 

## 方法

 ### 蛮力方法

 强力解决方案将检查每个唯一的单词并手动计算它在两个句子中出现的次数。 

一种方法是：

 1. 将两个句子拆分为单词数组。 
2. 将所有不同的单词组合成一个集合。 
3. 对于每个单词，扫描两个数组并计算出现次数。 
4. 如果总出现次数恰好为 1，则将其添加到答案中。 

这是有效的，因为不常见单词的定义完全取决于频率计数。 如果一个单词在两个句子中全局出现一次，那么它必须在一个句子中恰好出现一次，而在另一个句子中出现零次。 

然而，这种方法会重复扫描单词数组中的每个候选单词。 如果有`n`总字数和`u`独特的单词，重复计数会导致不必要的工作。 

尽管约束足够小，可以让这种方法通过，但与频率图解决方案相比，它的效率较低。 

### 最佳方法

 关键的见解是这个问题从根本上来说是一个频率计数问题。 

我们可以使用哈希映射对每个单词精确计数一次，而不是重复计算出现次数。 建立频率图后，任何具有频率的单词`1`并不常见。 

这是有效的，因为：

 - 如果一个单词在两个句子中总共出现一次，那么它只出现在一个句子中，而不会出现在其他地方。 
- 如果一个单词出现多次，无论是在同一个句子中还是在两个句子中出现，这种情况并不少见。 

哈希图允许恒定的时间频率更新和查找，使解决方案既简单又高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 反复扫描单词列表以计算频率 |
 | 最佳| O(n) | O(n) | 使用哈希映射一次计算频率 |

 这里，`n`表示两个句子中的单词总数。 

## 算法演练

 ### 最优算法

 1. 将两个句子分成单词列表。 

我们使用内置的字符串分割操作，因为输入格式保证单词之间有单个空格。 
2. 创建哈希图来存储词频。 

键是单词，值是每个单词在两个句子中出现的次数。 
3. 遍历第一句中的所有单词。 

对于每个单词，增加其在哈希图中的频率计数。 
4. 遍历第二句中的所有单词。 

再次增加每个单词的频率计数。 
5. 创建一个空结果列表。 

该列表将存储所有不常见的单词。 
6. 迭代哈希映射条目。 

如果一个词的频率恰好等于`1`，将其附加到结果列表中。 
7. 返回结果列表。 

由于该问题允许任何顺序，因此不需要排序。 

### 为什么它有效

 该算法之所以有效，是因为哈希图存储了两个句子中每个单词出现的总数。 

一个单词当且仅当它在全球范围内只出现一次时才是不常见的。 任何出现频率大于的单词`1`要么在一个句子中多次出现，要么在两个句子中都出现。 因此，选择所有出现频率的单词`1`保证正确性。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def uncommonFromSentences(self, s1: str, s2: str) -> List[str]:
        words = s1.split() + s2.split()

        frequency = Counter(words)

        result = []

        for word, count in frequency.items():
            if count == 1:
                result.append(word)

        return result
```实现首先将两个句子分成单词列表。 这些列表连接成一个名为`words`。 

这`Counter`来自 Python 的类`collections`模块自动计算每个单词出现的次数。 这是解决该问题的理想选择，因为它消除了手动频率簿记的需要。 

构建频率图后，我们迭代每个`(word, count)`一对。 每当计数等于`1`，我们将单词附加到结果列表中。 

最后返回结果列表。 

实现很简洁，因为Python提供了内置的频率计数工具，但底层逻辑直接遵循前面描述的算法。 

## 解决方案```go
package main

import "strings"

func uncommonFromSentences(s1 string, s2 string) []string {
	words1 := strings.Split(s1, " ")
	words2 := strings.Split(s2, " ")

	frequency := make(map[string]int)

	for _, word := range words1 {
		frequency[word]++
	}

	for _, word := range words2 {
		frequency[word]++
	}

	result := []string{}

	for word, count := range frequency {
		if count == 1 {
			result = append(result, word)
		}
	}

	return result
}
```Go 实现遵循与 Python 版本相同的总体策略。 

而不是使用Python的`Counter`, Go 使用`map[string]int`手动跟踪频率。 每个单词都会增加其在地图中的计数。 

结果存储在字符串切片中。 由于 Go 切片是动态的，因此添加不常见的单词很简单。 

不存在整数溢出问题，因为输入大小非常小。 此外，如果不存在不常见的单词，则返回空切片是完全有效的。

 ## 边缘情况

 ### 同一个句子中重复的单词

 一个常见的错误是只检查另一个句子中是否存在某个单词。 然而，一个词在同一个句子中多次重复的情况并不少见。 

例如：```
s1 = "apple apple"
s2 = "banana"
```虽然`"apple"`没有出现在`s2`，它出现两次`s1`，因此不得将其包括在内。 频率图正确地处理了这个问题，因为`"apple"`得到计数`2`。 

### 在两个句子中都出现一次的单词

 当一个单词在每个句子中只出现一次时，就会出现另一种棘手的情况。 

例子：```
s1 = "cat"
s2 = "cat"
```这个词`"cat"`在全球范围内出现两次，因此并不罕见。 该实现正确地排除了它，因为它的频率变为`2`。 

### 没有生僻字

 某些输入会产生空结果。 

例子：```
s1 = "x x"
s2 = "x"
```每次出现都会产生相同的频率计数，从而导致`"x"`有计数`3`。 因为没有一个词是重要的`1`，该算法返回一个空列表。 

这种情况很重要，因为假设至少一个不常见单词的实现可能会失败或返回不正确的值。
