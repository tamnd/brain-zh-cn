[LeetCode 第 870 题](https://leetcode.com/problems/advantage-shuffle/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、贪婪、排序

 ## 解决方案

 ## 问题理解

 这个问题要求我们**最大化一个数组相对于另一个数组的优势**。 给定两个数组`nums1`和`nums2`相同长度的情况下，**优势**定义为位置数`i`在哪里`nums1[i] > nums2[i]`。 我们的任务是重新安排`nums1`以最大限度地发挥这一优势。 

输入数组代表两组数字，我们想要“击败”中的数字`nums2`尽可能多地使用来自`nums1`。 输出应该是一个排列`nums1`其中每个元素都被分配到一个位置`nums2`最大化计数`nums1[i] > nums2[i]`。 约束表明数组可以长达 100,000 个元素，值最多可以达到 10 亿，因此对所有排列进行强力比较是不可行的。 

重要的边缘情况包括所有元素都相等的数组、其中`nums1`元素小于`nums2`、具有重复元素的数组以及具有最大允许大小的数组。 

## 方法

 **蛮力：**一种天真的方法是生成`nums1`并计算每个排列的优势。 然后我们将选择具有最大优势的排列。 虽然这保证了正确性，但在计算上是不可行的，因为生成`nums1`需要`O(n!)`时间，这是不可能的`n`最多`10^5`。 

**最佳方法：**关键见解是使用**贪婪策略与排序相结合**。 按排序`nums1`按升序排列并将其配对`nums2`按值排序，我们可以分配 **最小的数字`nums1`仍然大于当前的`nums2`元素**。 如果不存在这样的数字，我们分配最小的数字`nums1`（“牺牲”）将损失降到最低。 这确保了每个数字`nums2`要么被最小的足够数量击败`nums1`或者以最小的元素输掉，从而最大化总优势。

 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 检查 nums1 | 的所有排列
 | 最佳| O(n log n) | O(n log n) | O(n) | 使用两个指针对数组进行排序并贪婪地赋值

 ## 算法演练

 1. **排序`nums1`** 按升序排列，这样我们就可以有效地找到可以击败其中元素的最小数字`nums2`。 
2. **配对元素`nums2`及其原始索引**并按值排序。 这使我们能够重建最终的排列`nums1`按照原来的顺序`nums2`。 
3. **使用双端队列`nums1`**（或两个指针方法）。 对于每个元素`val`在已排序的`nums2`:

 - 如果剩余的最大数`nums1`大于`val`，将其分配到该位置。 
- 否则，分配最小的剩余数`nums1`（“牺牲”）到那个位置。 
4. **返回构造的排列**`nums1`从而最大化优势。 

**为什么有效：** 排序使我们能够做出全局最优的局部最优决策。 中的每个数字`nums2`要么被最小的数字击败`nums1`较大的，或分配最小的剩余数字，以尽量减少浪费的价值。 这保证了总优势的最大化。 

## Python 解决方案```python
from typing import List
from collections import deque

class Solution:
    def advantageCount(self, nums1: List[int], nums2: List[int]) -> List[int]:
        sorted_nums1 = deque(sorted(nums1))
        sorted_nums2 = sorted([(val, idx) for idx, val in enumerate(nums2)])
        res = [0] * len(nums1)
        
        for val, idx in reversed(sorted_nums2):
            if sorted_nums1[-1] > val:
                res[idx] = sorted_nums1.pop()
            else:
                res[idx] = sorted_nums1.popleft()
        
        return res
```**解释：** 我们首先排序`nums1`和`nums2`（带有索引）。 使用双端队列`nums1`允许从两端有效去除。 我们迭代一遍`nums2`按降序排列，或者指定可以击败的最大可用数字`val`或剩余的最小数。 这`res`array 存储最终的排列。 

## 解决方案```go
package main

import (
    "sort"
)

func advantageCount(nums1 []int, nums2 []int) []int {
    n := len(nums1)
    sortedNums1 := make([]int, n)
    copy(sortedNums1, nums1)
    sort.Ints(sortedNums1)
    
    type pair struct {
        val, idx int
    }
    
    sortedNums2 := make([]pair, n)
    for i, v := range nums2 {
        sortedNums2[i] = pair{v, i}
    }
    sort.Slice(sortedNums2, func(i, j int) bool { return sortedNums2[i].val < sortedNums2[j].val })
    
    res := make([]int, n)
    left, right := 0, n-1
    for i := n-1; i >= 0; i-- {
        if sortedNums1[right] > sortedNums2[i].val {
            res[sortedNums2[i].idx] = sortedNums1[right]
            right--
        } else {
            res[sortedNums2[i].idx] = sortedNums1[left]
            left++
        }
    }
    
    return res
}
```**Go 特定说明：** 由于 Go 没有元组，因此我们使用结构体将值与索引配对。 对切​​片进行排序并使用两个指针实现了与 Python 的双端队列方法相同的逻辑。 切片复制避免改变输入`nums1`。 

## 工作示例

 **示例1：**`nums1 = [2,7,11,15], nums2 = [1,10,4,11]`1. 排序`nums1`:`[2,7,11,15]`2. 配对和排序`nums2`:`[(1,0),(4,2),(10,1),(11,3)]`3. 反向迭代：

 - 11：最大的15>11，分配15→索引3
 - 10：最大的11>10，分配11→索引1
 - 4：最大的7>4，分配7→索引2
 - 1：最大的2>1，分配2→索引0

 结果：`[2,11,7,15]`**示例2：**`nums1 = [12,24,8,32], nums2 = [13,25,32,11]`1. 排序`nums1`:`[8,12,24,32]`2. 配对和排序`nums2`:`[(11,3),(13,0),(25,1),(32,2)]`3. 反向迭代：

 - 32：最大的 32 ≤ 32，分配最小的 8 → 索引 2
 - 25：最大的32>25，分配32→索引1
 - 13：最大的24>13，分配24→索引0
 - 11：最大的12>11，分配12→索引3

 结果：`[24,32,8,12]`## 复杂度分析
