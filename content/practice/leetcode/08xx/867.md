 # LeetCode 867，转置矩阵

 ## 问题理解

 这个问题要求我们计算给定二维矩阵的转置。 转置运算将矩阵翻转到其主对角线上。 实际上，位置上的每个元素`(row, column)`原矩阵中的元素变为位置`(column, row)`在转置矩阵中。 

如果输入矩阵有`m`行和`n`列，那么结果矩阵将有`n`行和`m`列。 这种维度交换是问题中最重要的观察结果之一。 

例如，考虑矩阵：```
[
  [1, 2, 3],
  [4, 5, 6]
]
```这个矩阵有`2`行和`3`列。 转置后，行变成列：```
[
  [1, 4],
  [2, 5],
  [3, 6]
]
```输入表示有效的矩形矩阵，这意味着每行具有相同的列数。 该问题保证：

 -`1 <= m, n <= 1000`-`1 <= m * n <= 10^5`这些限制告诉我们一些重要的事情：

 - 矩阵可以很大，总元素可达十万。 
- 一个`O(m * n)`解决方案是预期的并且足够有效。 
- 任何明显较慢的方法都是不必要的。 
- 因为输出本身包含`m * n`元素，我们必须至少触及每个值一次。 

该问题还保证矩阵非空，因此我们不需要处理完全空的输入。 然而，仍然有几个重要的边缘情况需要考虑：

 - 单行矩阵
 - 单列矩阵
 - 方阵
 - 行和列不同的矩形矩阵
 - 负数和零值

 幼稚的实现很容易在维度上犯错误，尤其是在分配结果矩阵时。 

## 方法

 ### 蛮力方法

 蛮力的想法很简单。 我们创建一个具有交换维度的新矩阵，然后迭代原始矩阵中的每个元素并将其放置到其转置位置。 

对于每个职位`(i, j)`在原始矩阵中：```
result[j][i] = matrix[i][j]
```这是可行的，因为转置直接交换行索引和列索引。 

尽管这种方法对于问题约束来说已经足够有效，但它仍然可以被认为是蛮力，因为它机械地处理每个元素，没有任何优化或更深层次的结构技巧。 

该算法是正确的，因为每个原始元素都被精确地复制到其数学上正确的转置位置一次。 

### 最佳方法

 关键的观察是转置只是一个索引交换操作。 不需要额外的计算、排序或复杂的数据结构。 

最优解创建一个大小为的结果矩阵`n x m`并使用规则直接填充：```
transposed[col][row] = original[row][col]
```由于每个元素必须在输出中恰好出现一次，因此我们不能比访问所有元素更好。 所以，`O(m * n)`既是必要的，也是最优的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(m * n) | 将每个元素复制到新矩阵 |
 | 最佳| O(m * n) | O(m * n) | 以最小的开销进行直接索引交换 |

 ## 算法演练

 1. 确定原始矩阵的维度。 

让：

-`rows = len(matrix)`-`cols = len(matrix[0])`这是必要的，因为转置矩阵将反转这些维度。 
2. 创建具有交换维度的结果矩阵。 

转置矩阵必须包含：

 -`cols`行
 -`rows`列

 我们初始化一个用零填充的矩阵：```
result = [[0] * rows for _ in range(cols)]
```3. 迭代原始矩阵中的每个元素。 

使用嵌套循环：

 - 外循环迭代行
 - 内循环遍历列
 4. 将每个值置于其转置位置。 

对于每个元素：```
result[j][i] = matrix[i][j]
```这会交换行索引和列索引。 
5. 返回完成的转置矩阵。 

### 为什么它有效

 转置操作在数学上定义为交换行和列坐标。 位置处的每个元素`(i, j)`原来的矩阵被移动到`(j, i)`在结果矩阵中。 由于该算法对每个元素仅应用一次此变换，因此保证最终矩阵是正确的转置。 

## Python 解决方案```python
from typing import List

class Solution:
    def transpose(self, matrix: List[List[int]]) -> List[List[int]]:
        rows = len(matrix)
        cols = len(matrix[0])

        transposed = [[0] * rows for _ in range(cols)]

        for row in range(rows):
            for col in range(cols):
                transposed[col][row] = matrix[row][col]

        return transposed
```实现首先确定原始矩阵中的行数和列数。 需要此信息是因为转置矩阵的维度是相反的。 

接下来，该解决方案分配一个名为`transposed`。 其尺寸为`cols x rows`，确保每个转置坐标都是有效的。 

嵌套循环只访问每个元素一次。 对于位置处的每个值`(row, col)`，算法将其存储在`(col, row)`在结果矩阵中。 

最后，返回完成的转置矩阵。 

## 解决方案```go
func transpose(matrix [][]int) [][]int {
    rows := len(matrix)
    cols := len(matrix[0])

    transposed := make([][]int, cols)

    for i := 0; i < cols; i++ {
        transposed[i] = make([]int, rows)
    }

    for row := 0; row < rows; row++ {
        for col := 0; col < cols; col++ {
            transposed[col][row] = matrix[row][col]
        }
    }

    return transposed
}
```Go 实现遵循与 Python 解决方案相同的算法结构。 主要区别在于切片的分配方式。 

在 Go 中，我们首先使用以下命令创建外部切片`make([][]int, cols)`，然后单独分配每个内部切片。 这确保了转置矩阵具有正确的维度。 

由于问题约束完全符合 Go 的整数范围，因此整数溢出在这里不是问题。

 ## 边缘情况

 单行矩阵是一种重要的边缘情况，因为转置变成了列向量。 不正确的尺寸处理很容易产生索引错误。 该实现通过在复制值之前分配具有交换维度的结果矩阵来正确处理此问题。 

单列矩阵是另一个重要的情况。 在这里，转置变成单行。 一些不正确的解决方案会意外地保留原始形状而不是交换尺寸。 这个实现显式地构造了一个`cols x rows`矩阵，所以变换总是正确的。 

矩形矩阵通常是错误的最大来源，因为行数和列数不同。 当维度不相等时，假设方阵的解决方案将失败。 该实现通过独立跟踪避免了这个问题`rows`和`cols`并在整个算法中一致地使用它们。 

负数和零值也值得考虑。 由于该算法仅重新定位值而不修改它们，因此在转置过程中所有整数都被准确保留。
