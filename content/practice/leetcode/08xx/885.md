 **难度：** 🟡 中等
 **主题：** 数组、矩阵、模拟

 ## 解决方案

 ## 问题理解

 问题是要求我们生成 2D 网格中单元格的坐标，如果我们从给定单元格开始，我们将访问该坐标`(rStart, cStart)`并以顺时针螺旋模式行走。 网格有尺寸`rows x cols`，左上角是`(0, 0)`而右下角是`(rows - 1, cols - 1)`。 我们从面向东开始，一步一步地移动，并遵循螺旋模式：东、南、西、北，然后以扩展的步骤重复。 

输入参数是`rows`和`cols`指定网格大小，以及`rStart`和`cStart`指定起始位置。 输出应该是按照我们遇到的确切顺序访问的所有位置的列表，包括网格边界之外的处理步骤（这些应该在输出中跳过）。 

约束告诉我们网格相对较小（`1 <= rows, cols <= 100`），所以暴力方法是可行的，但没有必要。 边缘情况包括从网格边界开始，仅具有单行或单列，以及尺寸为 1x1 的网格，其中螺旋运动最小。 该问题保证网格内的有效起始位置。 

## 方法

 蛮力方法涉及在无界坐标平面中模拟螺旋的每一步，并在每一步检查当前单元格是否位于网格内部。 我们将继续此操作，直到访问了网格中的所有单元格。 这是有效的，因为螺旋最终到达所有细胞。 然而，它的效率稍低，因为它计算了网格外的许多位置，这些位置对结果没有贡献。 

最佳方法利用了这样一个事实：螺旋以可预测的步长移动，每两个方向后步长增加。 通过使用方向向量并增量控制步长，我们可以系统地仅生成我们需要的坐标。 关键的见解是螺旋的运动模式是重复的和结构化的，因此我们可以在受控循环中迭代，直到访问完所有`rows * cols`细胞。 这避免了对访问单元的不必要的检查或额外的内存开销，因为每个网格单元都保证被访问一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(最大(行数, 列数)^2) | O(行数 * 列数) | 模拟每个螺旋步骤，检查网格边界 |
 | 最佳| O(行数 * 列数) | O(行数 * 列数) | 具有受控步长增量的系统螺旋生成 |

 ## 算法演练

 1. 初始化一个结果列表来存储网格内访问过的单元格的坐标。 添加起始位置`(rStart, cStart)`到这个列表。 
2. 将四个可能的移动方向定义为一个序列：东`(0, 1)`， 南`(1, 0)`, 西`(0, -1)`，和北`(-1, 0)`。 
3. 设置变量来跟踪当前位置`(r, c)`和当前的步长。 步长从 1 开始，完成两个方向（即水平和垂直移动）后增加 1。 
4. 循环直到结果列表包含`rows * cols`坐标。 对于序列中的每个方向，移动`step_length`沿该方向进行多次，每次移动时更新当前坐标。 
5. 每次移动后，检查当前位置是否在网格边界内。 如果是，则将其附加到结果列表中。 
6. 完成两个方向（东和南，或西和北）的移动后，步长加 1 以展开螺旋。 
7. 继续此过程，直到所有单元格都记录在结果列表中。 

**为什么有效：** 该算法之所以有效，是因为它模仿了问题所需的精确螺旋模式，并确保网格中的每个单元都被访问一次。 每两个方向的步长增量可确保螺旋正确向外扩展，并且检查边界可确保结果中仅包含有效的网格位置。 

## Python 解决方案```python
from typing import List

class Solution:
    def spiralMatrixIII(self, rows: int, cols: int, rStart: int, cStart: int) -> List[List[int]]:
        result = [[rStart, cStart]]
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]  # east, south, west, north
        steps = 1
        r, c = rStart, cStart

        while len(result) < rows * cols:
            for i in range(4):
                dr, dc = directions[i]
                for _ in range(steps):
                    r += dr
                    c += dc
                    if 0 <= r < rows and 0 <= c < cols:
                        result.append([r, c])
                if i % 2 == 1:
                    steps += 1  # increment step length after every vertical move
        return result
```Python 解决方案完全遵循该算法。 这`directions`阵列确保螺旋图案中的一致运动。 这`steps`变量控制螺旋的扩展。 内循环移动当前位置并检查坐标是否在网格内，然后添加到`result`。 每两次移动（垂直方向）后步长就会增加，以保持螺旋扩展。 

## 解决方案```go
func spiralMatrixIII(rows int, cols int, rStart int, cStart int) [][]int {
    result := [][]int{{rStart, cStart}}
    directions := [][]int{{0,1},{1,0},{0,-1},{-1,0}} // east, south, west, north
    steps := 1
    r, c := rStart, cStart

    for len(result) < rows*cols {
        for i := 0; i < 4; i++ {
            dr, dc := directions[i][0], directions[i][1]
            for j := 0; j < steps; j++ {
                r += dr
                c += dc
                if r >= 0 && r < rows && c >= 0 && c < cols {
                    result = append(result, []int{r, c})
                }
            }
            if i % 2 == 1 {
                steps++
            }
        }
    }
    return result
}
```在 Go 中，切片用于动态数组构造，该方法类似于 Python。 Go 需要对 2D 切片进行显式索引，并且边界检查是通过`>=`和`<`。 切片附加对于构建结果非常有效。

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 时间 | O(行数 * 列数) | 网格中的每个单元格都被访问一次 |
