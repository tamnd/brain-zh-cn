[LeetCode 841 题](https://leetcode.com/problems/keys-and-rooms/)

 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、图论

 ## 解决方案

 ## 问题理解

 这个问题可以解释为图遍历挑战。 每个房间都是图中的一个节点，标记为`0`到`n-1`，房间内的钥匙代表可以解锁的其他节点的有向边。 输入`rooms`是一个列表列表，其中`rooms[i]`包含在房间中找到的一组钥匙`i`。 Each key in`rooms[i]`允许进入另一个房间，可能会解锁额外的钥匙。 

目标是确定是否可以从 room 开始访问所有房间`0`。 输出是一个布尔值：`true`如果所有房间都可以参观的话`false`否则。 约束条件表明房间数量`n`最多可以达到 1000 个，所有房间的键总数最多为 3000 个。这确保了图相对于完全连接的图是稀疏的，并允许深度优先搜索 (DFS) 或广度优先搜索 (BFS) 等线性遍历算法高效执行。 

重要的边缘情况包括没有钥匙的房间、钥匙访问循环（例如，房间 A 有 B 的钥匙，B 有 A 的钥匙），以及钥匙无法通往任何未访问过的房间的房间。 该问题保证房间中的所有键都是唯一的且在范围内，因此我们不需要处理无效键。 

## 方法

 暴力方法将尝试生成所有可能的访问房间序列，并检查是否有任何序列允许访问所有房间。 这是正确的，但在计算上不可行，因为序列的数量随阶乘增长`n`。 

最佳解决方案的关键在于我们不需要考虑所有序列； 我们只需要使用 DFS 或 BFS 遍历房间图。 一旦访问了一个房间，我们就会将其标记为已访问，以避免多余的遍历。 使用 DFS 或 BFS 可确保从 room 到达所有可到达的房间`0`得到有效探索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 生成房间访问的所有序列； 对于大 n | 不可行
 | 最优（DFS/BFS）| O(n + k) | O(n) | 遍历图，`n`房间和`k`总按键 |

 这里，`k`是所有房间的钥匙总数。 

## 算法演练

 1. 初始化一个集合或布尔数组`visited`跟踪已访问过的房间。 
2.初始化一个栈（对于DFS）或队列（对于BFS）并从空间开始`0`。 
3. 当堆栈或队列不为空时，弹出一个房间来访问。 
4. 如果该房间已被访问过，则跳过该房间。 
5. 将房间标记为已访问。 
6. 对于当前房间中找到的每个键，将相应的房间压入或入队到堆栈或队列。 
7. 继续，直到处理完所有可到达的房间。 
8.最后检查已访问的房间数是否等于`n`。 返回`true`如果所有房间都被参观过，`false`否则。 

**为什么有效：** 遍历探索从 room 可到达的每个房间`0`。 如果任何房间无法到达，则不会将其添加到访问集中，并且最终检查可确保正确性。 这种方法保证了相对于输入大小的线性时间探索。 

## Python 解决方案```python
from typing import List

class Solution:
    def canVisitAllRooms(self, rooms: List[List[int]]) -> bool:
        visited = [False] * len(rooms)
        stack = [0]

        while stack:
            room = stack.pop()
            if not visited[room]:
                visited[room] = True
                for key in rooms[room]:
                    if not visited[key]:
                        stack.append(key)
        
        return all(visited)
```在此 Python 实现中，`visited`是一个布尔数组，指示哪些房间已被访问过。 堆栈用于 DFS。 我们迭代直到堆栈为空，访问房间并添加通过键找到的新房间。 最后，`all(visited)`确保每个房间都被访问过。 

## 解决方案```go
func canVisitAllRooms(rooms [][]int) bool {
    n := len(rooms)
    visited := make([]bool, n)
    stack := []int{0}

    for len(stack) > 0 {
        room := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        if !visited[room] {
            visited[room] = true
            for _, key := range rooms[room] {
                if !visited[key] {
                    stack = append(stack, key)
                }
            }
        }
    }

    for _, v := range visited {
        if !v {
            return false
        }
    }
    return true
}
```在 Go 中，切片用于堆栈和访问数组。 该逻辑反映了 Python DFS，具有用于推送和弹出元素的显式切片操作。 最终检查迭代`visited`确认所有房间均可进入。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |

 ## 边缘情况

 1. **没有钥匙的房间：** 如果房间没有钥匙，则无法解锁其他房间。 该实现正确地处理了这个问题，因为只有带有密钥的未访问过的房间才会被推入堆栈。 
2. **钥匙通道的循环：** 房间可能会形成循环。 例如，房间 2 可能包含已被访问过的房间 0 的钥匙。 访问过的数组确保我们不会重新访问房间并避免无限循环。 
3. **断开连接的房间：** 如果没有钥匙通向某些房间，则可能无法从房间 0 到达这些房间。 该算法在最后检测到这一点`all(visited)`检查、返回`false`如果有任何房间未被访问。 即使在稀疏图中，这也保证了正确性。 

该解决方案稳健、高效，并且可以处理问题指定的所有约束和边缘情况。
