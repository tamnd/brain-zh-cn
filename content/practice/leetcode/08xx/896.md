[LeetCode 第 896 题](https://leetcode.com/problems/monotonic-array/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定给定的整数数组是否是单调的。 如果一个数组完全不递减（单调递增）或完全不递增（单调递减），则该数组被认为是单调的。 简单来说，当我们从左到右遍历数组时，元素应该永远不会减少或永远不会增加。 输入是单个整数列表，输出是布尔值：`true`如果数组是单调的，`false`否则。 

约束告诉我们数组长度最多可以有 100,000 个元素，整数值范围在 -100,000 到 100,000 之间。 这意味着任何具有二次时间复杂度 O(n²) 的解决方案都可能太慢，而线性时间复杂度 O(n) 的解决方案是可以接受的。 该问题保证数组至少有一个元素，因此我们不需要处理空数组的情况。 

重要的边缘情况包括仅具有一个元素的数组、所有元素都相等的数组以及单调性切换一次或多次的数组。 

## 方法

 暴力方法将涉及检查每对元素以确定数组是增加还是减少。 我们可以首先假设它正在增加并检查违规情况，然后假设它正在减少并再次检查。 这种方法可以正常工作，但效率低下，因为它可能会多次检查所有元素对。 

最佳解决方案的关键见解是我们只需要一次遍历数组即可跟踪它是增加还是减少。 我们可以维护两个布尔标志，一个用于增加，一个用于减少。 当我们迭代时，如果我们发现任何违反递增顺序的情况，我们会将递增标志设置为 false，对于递减顺序也是如此。 最后，如果任一标志保持为真，则该数组是单调的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 检查所有对的单调性； 正确但缓慢 |
 | 最佳 | O(n) | O(1) | O(1) | 使用两个布尔标志进行单遍检查以增加/减少 |

 ## 算法演练

 1.初始化两个布尔变量，`increasing`和`decreasing`，并将两者都设置为`True`。 这些标志表示当我们迭代时数组是否仍然可以单调增加或减少。 
2. 从第二个元素开始迭代数组。 对于每个元素，将其与前一个元素进行比较。 
3.如果当前元素大于前一个元素，则设置`decreasing`到`False`因为数组不能单调递减。 
4. 如果当前元素小于前一个元素，则设置`increasing`到`False`因为数组不能单调递增。 
5. 完成迭代后，如果`increasing`或者`decreasing`是`True`， 返回`True`因为数组是单调的。 否则，返回`False`。 

Why it works: The algorithm maintains an invariant that the flags`increasing`和`decreasing`反映单调关系是否在任何点被违反。 如果发生任何违规，则相应的标志被关闭，并且只有至少一个标志保持为真，数组才能保持单调。 

## Python 解决方案```python
from typing import List

class Solution:
    def isMonotonic(self, nums: List[int]) -> bool:
        increasing = True
        decreasing = True
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                decreasing = False
            elif nums[i] < nums[i - 1]:
                increasing = False
        
        return increasing or decreasing
```在此 Python 实现中，我们首先假设数组可以递增或递减。 当我们迭代数组时，每当我们检测到违反任一类型的单调性时，我们都会更新标志。 最后，返回`increasing or decreasing`正确判断数组是否单调。 

## 解决方案```go
func isMonotonic(nums []int) bool {
    increasing := true
    decreasing := true

    for i := 1; i < len(nums); i++ {
        if nums[i] > nums[i-1] {
            decreasing = false
        } else if nums[i] < nums[i-1] {
            increasing = false
        }
    }

    return increasing || decreasing
}
```在 Go 中，我们处理切片的方式与 Python 列表类似。 这`for`循环遍历索引，我们使用相同的布尔标志方法。 边缘情况（例如长度为 1 的数组）会自动处理，因为循环不执行，使两个标志都为 true，从而正确返回`true`。

 ## 边缘情况

 一种重要的边缘情况是只有一个元素的数组。 这样的数组基本上是单调的，因为没有任何对违反递增或递减顺序。 我们的实现处理这个问题，因为循环不运行，使两个标志都为 true。 

第二个边缘情况是所有元素都相等。 在这种情况下，增加或减少都不会严格改变，因此两个标志都保持为真，并且算法正确返回`True`。 

第三种边缘情况涉及看似单调但切换方向一次的数组。 例如，`[1,2,3,2]`最初出现增加，但随后减少。 该算法检测到违规，将递增标志设置为 false，并且由于递减标志在开始时也为 false，因此返回`False`，正确地将数组识别为非单调的。 这凸显了该方法无需依赖单独的扫描即可可靠地检测违规行为。
