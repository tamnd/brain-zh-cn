[LeetCode 第 893 题](https://leetcode.com/problems/groups-of-special-equivalent-strings/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们根据特殊的等价属性对字符串进行分组。 具体来说，如果您可以多次交换偶数索引处的字符和奇数索引处的字符以使两个字符串相同，则两个字符串是**特殊等效**。 输入是一个字符串数组`words`，都具有相同的长度。 输出是一个整数，表示特殊等效字符串的不同组的数量。 

约束条件告诉我们`words`最多可以有 1000 个字符串，每个字符串最多可以有 20 个字符。 这排除了在所有可能的交换之后逐字符比较所有字符串对的任何暴力方法，因为它很快就会变得太慢。 此外，所有字符串均由小写英文字母组成，这使得可以紧凑地表示字符数。 

关键边缘情况包括非常短的字符串（长度为 1）、所有字符串都相同的数组或没有两个字符串特殊等效的字符串。 该问题保证所有字符串具有相同的长度，因此我们不需要处理变长字符串。 

## 方法

 **暴力方法**将涉及尝试每个字符串上的所有可能的交换序列，并将其与其他每个字符串进行比较，看看它们是否可以相等。 虽然这最终会产生正确的答案，但交换次数随字符串长度呈阶乘增长（大致为`(n/2)!`对于偶数和`(n/2)!`对于奇数位置），使得这种方法即使对于小字符串也不可行。 

**最佳方法**利用了以下关键见解：**特殊等价仅取决于偶数索引处的字符多集和奇数索引处的字符多集**。 也就是说，如果对两个字符串的偶数索引字符进行排序并对其奇数索引字符进行排序会生成同一对已排序字符串，则这两个字符串是特殊等效的。 这使我们能够将每个字符串映射到规范的“签名”，并使用哈希集有效地计算唯一组的数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * ((m/2)! * (m/2)!)) | O(n * ((m/2)! * (m/2)!)) | O(n) | 生成偶数和奇数索引交换的所有排列后比较所有对。 对于约束来说太慢了。 |
 | 最佳 | O(n * m log m) | O(n * m log m) | O(n * m) | 使用已排序的偶数和奇数索引字符的规范签名来有效地识别组。 |

 ## 算法演练

 1. **初始化一组签名**：这将存储代表特殊等效组的唯一字符串签名。 
2. **迭代每个字符串**：对于每个字符串，在偶数和奇数索引处分隔字符。 
3. **对每组字符进行排序**：对偶数索引字符和奇数索引字符独立排序。 无论原始顺序如何，排序都提供唯一的表示。 
4. **组合成元组或字符串签名**：这对排序序列充当字符串的规范表示。 
5. **将签名添加到集合**：这会自动确保唯一性，因为集合不能包含重复项。 
6. **返回集合的大小**：唯一签名的数量就是特殊等效组的数量。 

**为什么有效**：对偶数和奇数字符进行排序会产生在允许的交换下不变的规范形式。 具有相同排序偶数和奇数字符的两个字符串始终可以重新排列以彼此匹配。 这保证了正确性并避免不必要的排列。 

## Python 解决方案```python
from typing import List

class Solution:
    def numSpecialEquivGroups(self, words: List[str]) -> int:
        signatures = set()
        
        for word in words:
            even_chars = sorted(word[i] for i in range(0, len(word), 2))
            odd_chars = sorted(word[i] for i in range(1, len(word), 2))
            signature = (tuple(even_chars), tuple(odd_chars))
            signatures.add(signature)
        
        return len(signatures)
```Python 实现使用切片分离偶数和奇数字符，对它们进行排序以创建规范签名，并使用集合来跟踪唯一组。 使用`tuple`确保存储在集合中的散列性。 

## 解决方案```go
import (
	"sort"
	"strings"
)

func numSpecialEquivGroups(words []string) int {
	signatures := make(map[string]struct{})
	
	for _, word := range words {
		var evenChars, oddChars []string
		for i, c := range word {
			if i%2 == 0 {
				evenChars = append(evenChars, string(c))
			} else {
				oddChars = append(oddChars, string(c))
			}
		}
		sort.Strings(evenChars)
		sort.Strings(oddChars)
		signature := strings.Join(evenChars, "") + "|" + strings.Join(oddChars, "")
		signatures[signature] = struct{}{}
	}
	
	return len(signatures)
}
```在 Go 中，切片用于偶数和奇数字符，使用排序`sort.Strings`，并用分隔符连接成单个字符串。 具有空结构的映射可以有效地跟踪唯一的签名。

 ## 边缘情况

 **单字符字符串**：长度为 1 的字符串没有奇数或偶数索引交换。 所有单字符字符串仅相当于相同的字符串。 该解决方案自然地处理了这个问题，因为对单个字符进行排序会返回相同的字符。 

**相同字符串**：多个相同字符串应算作一组。 设置的数据结构可确保重复项自动合并到一组中。 

**没有特殊等价**：如果没有两个字符串共享相同的偶数和奇数字符多重集，则每个字符串形成自己的组
