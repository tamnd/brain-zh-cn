[LeetCode 823 题](https://leetcode.com/problems/binary-trees-with-factors/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、动态规划、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定可以从给定的唯一整数数组构造的不同二叉树的数量，其中每个整数严格大于 1。关键约束是对于树中的每个非叶节点，其值必须等于其两个子节点的乘积。 叶节点可以是数组中的任何值。 

输入，`arr`，是唯一整数的列表，每个整数在 2 到 10^9 之间，长度为`arr`最多 1000。输出是一个整数，表示有效二叉树的数量，以 10^9 + 7 为模，因为树的数量可以增长得非常大。 

重要的观察结果包括每个元素都可以充当叶子（单节点树），并且数组中因素的多种组合可以形成相同的产品。 由于组合爆炸，尝试递归构建所有树的简单暴力方法很快就会变得不可行。 要考虑的边缘情况包括长度为 1 的数组（只有一棵树）、具有素数的数组（除了叶子之外，树不能有子代）以及包含多个数组元素乘积的数字的数组。 

## 方法

 暴力方法将尝试通过考虑与元素值相乘的所有可能的子元素对，为数组中的每个元素递归生成所有树。 虽然正确，但这种方法效率极低，因为它探索指数数量的树组合，并且很快就会超出较大数组的时间限制。 

最佳解决方案利用动态编程和哈希图。 首先，对数组进行排序。 然后，对于每个元素，我们将其视为潜在的根。 我们迭代所有较小的元素以检查它们是否是当前根的因子。 如果`arr[i] % arr[j] == 0`和商`arr[i] / arr[j]`也存在于数组中，我们知道我们可以用以下方式形成树`arr[i]`作为根和`arr[j]`和孩子时的商。 使用哈希映射来存储每个值的树数量使我们能够增量计算较大元素的树数量，确保 O(n^2) 解决方案而不是指数时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归构建所有树； 对于 n ~ 1000 来说不切实际 |
 | 最佳| O(n^2) | O(n^2) | O(n) | 对数组进行排序，利用DP和hashmap高效计数树 |

 ## 算法演练

 1. 对输入数组进行排序，以确保我们始终首先考虑较小的元素。 这确保了在计算树时`arr[i]`，所有潜在因素`arr[j]`已经被处理了。 
2. 初始化哈希图`dp`在哪里`dp[x]`存储二叉树的数量`x`作为根。 
3. 迭代每个元素`arr[i]`。 最初，设置`dp[arr[i]] = 1`因为每个元素都可以构成一棵单节点树。 
4. 对于每个`arr[i]`, 迭代所有`arr[j]`这样`arr[j] < arr[i]`。 如果`arr[i] % arr[j] == 0`和商`arr[i] / arr[j]`存在于哈希映射中，增量`dp[arr[i]]`经过`dp[arr[j]] * dp[arr[i] / arr[j]]`。 这对通过组合有效子对形成的所有树进行计数。 
5. 将所有值相加`dp`对 10^9 + 7 求模以获得最终答案。 

**为什么有效：** 排序可确保所有潜在因素都已计算在内。 使用哈希映射允许 O(1) 查找因子是否存在以及以这些因子为根的树的数量。 乘法考虑了每个因子对的左子树和右子树的所有组合。 

## Python 解决方案```python
from typing import List

class Solution:
    def numFactoredBinaryTrees(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        arr.sort()
        dp = {}
        arr_set = set(arr)
        
        for x in arr:
            dp[x] = 1
            for y in arr:
                if y >= x:
                    break
                if x % y == 0 and (x // y) in arr_set:
                    dp[x] += dp[y] * dp[x // y]
                    dp[x] %= MOD
        
        return sum(dp.values()) % MOD
```该实现首先对数组进行排序并初始化`dp`每个元素的计数为 1 以说明单节点树。 嵌套循环迭代较小的元素以查找有效的因子对，并且哈希映射允许快速进行存在性检查。 模运算确保结果符合整数限制。 

## 解决方案```go
func numFactoredBinaryTrees(arr []int) int {
    const MOD = 1_000_000_007
    n := len(arr)
    sort.Ints(arr)
    dp := make(map[int]int)
    arrSet := make(map[int]bool)
    for _, x := range arr {
        arrSet[x] = true
    }
    
    for _, x := range arr {
        dp[x] = 1
        for _, y := range arr {
            if y >= x {
                break
            }
            if x%y == 0 {
                if _, exists := arrSet[x/y]; exists {
                    dp[x] = (dp[x] + dp[y]*dp[x/y]) % MOD
                }
            }
        }
    }
    
    result := 0
    for _, count := range dp {
        result = (result + count) % MOD
    }
    return result
}
```Go 版本镜像了 Python 实现。 Go 需要显式的模运算和整数映射。 排序和哈希图设置类似，保证了算法的正确性。 

## 工作示例

 **示例1：`arr = [2,4]`**

种类：`[2,4]`初始化`dp = {}`-`x = 2`:`dp[2] = 1`（单节点树）
 -`x = 4`:`dp[4] = 1`- 查看`y = 2`: 4 % 2 == 0, 4/2 = 2 存在 →`dp[4] += dp[2]*dp[2] = 1 + 1*1 = 2`总和：1（对于 2）+ 2（对于 4）= 3

 **示例2：`arr = [2,4,5,10]`**

种类：`[2,4,5,10]`初始化`dp = {}`-`x = 2`:`dp[2] = 1`-`x = 4`:`dp[4] = 1`-`y = 2`: 4 % 2 == 0, 4/2 = 2 存在 →`dp[4] = 1 + 1*1 = 2`-`x = 5`:`dp[5] = 1`（无有效因素）
 -`x = 10`:`dp[10] = 1`-`y = 2`: 10 % 2 == 0, 10/2 = 5 存在 →`dp[10] = 1 + 1*1 = 2`-`y = 5`: 10 % 5 == 0, 10/5 = 2 存在 →`dp[10] = 2 + 1*1 = 3`总和：1 + 2 + 1 + 3 = 7
