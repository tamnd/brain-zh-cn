 # LeetCode 836，矩形重叠

 ## 问题理解

 该问题给了我们两个**轴对齐的矩形**，这意味着它们的边平行于 X 轴和 Y 轴。 每个矩形表示为：```
[x1, y1, x2, y2]
```在哪里：

-`(x1, y1)`是**左下角**
 -`(x2, y2)`是**右上角**

 任务是确定这两个矩形是否**与正区域重叠**。 

**积极区域**这句话很重要。 仅当共享区域的面积大于零时，两个矩形才被视为重叠。 如果矩形仅在边缘或角落接触，则**不**算作重叠。 

例如：```
rec1 = [0,0,2,2]
rec2 = [1,1,3,3]
```这些矩形共享一个正方形区域`(1,1)`到`(2,2)`，其面积为正，所以答案是`true`。 

然而：```
rec1 = [0,0,1,1]
rec2 = [1,0,2,1]
```矩形恰好在垂直边缘接触`x = 1`。 由于重叠区域的宽度为零，因此面积为零，因此答案是`false`。 

这些约束告诉我们一些有用的信息：

 - 每个矩形始终恰好有四个整数。 
- 坐标可以非常大，范围从`-10^9`到`10^9`。 
- 矩形保证具有**非零面积**，这意味着`x1 < x2`和`y1 < y2`。 

由于输入大小是固定的，因此性能在这里不是实际问题。 然而，问题是测试几何推理和边界条件的仔细处理。 

一些边缘情况可能会导致简单的实现失败。 仅在边缘或角落接触的矩形是最常见的错误来源。 另一种微妙的情况是一个矩形完全位于另一个矩形内。 负坐标也很重要，但无论符号如何，重叠逻辑都应该以相同的方式工作。 

## 方法

 ### 蛮力方法

 思考这个问题的一种强力方法是显式计算相交矩形并检查其面积是否为正。 

对于两个矩形，我们可以确定重叠区域：

 - 左边界：`max(rec1.x1, rec2.x1)`- 右边界：`min(rec1.x2, rec2.x2)`- 底部边界：`max(rec1.y1, rec2.y1)`- 顶部边界：`min(rec1.y2, rec2.y2)`一旦我们计算出这些边界，我们就计算：```
width = right - left
height = top - bottom
```如果宽度和高度均为正数，则矩形重叠。 

这种方法是正确的，因为两个轴对齐矩形的交集本身就是一个矩形。 如果任一维度为零或负数，则重叠面积为零。 

由于输入大小是恒定的，因此这种方法已经非常有效。 然而，我们可以构建更清晰的几何洞察力。 

### 最佳方法的关键见解

 我们可以逆向思考，而不是直接计算重叠面积。 

如果发生以下情况之一，则两个矩形**不重叠**：

 1. 一个矩形完全位于另一个矩形的**左侧**。 
2. 一个矩形完全位于另一个矩形的**右侧**。 
3. 一个矩形完全**在另一个矩形上方**。 
4. 一个矩形完全**位于**另一个矩形下方。 

如果这些分离条件都不成立，则矩形必须重叠。 

这一观察将逻辑简化为一些比较。 

例如：```
rec1 = [0,0,1,1]
rec2 = [1,0,2,1]
```我们看到：```
rec1.x2 <= rec2.x1
1 <= 1
```这意味着`rec1`完全在左侧`rec2`，或触摸边缘。 由于触摸不算数，因此我们使用`<=`而不是`<`。

 ## 算法演练

 ### 最优算法

 1. 提取矩形边界`rec1`和`rec2`。 

每个矩形给我们四个值：

 - 左边缘：`x1`底部边缘：`y1`- 右边缘：`x2`- 顶边：`y2`由于矩形是轴对齐的，因此这些值完全定义了几何形状。 
2. 检查一个矩形是否完全位于另一个矩形的左侧。 

出现这种情况时：```
rec1[2] <= rec2[0]
```或者```
rec2[2] <= rec1[0]
```这`<=`很重要，因为接触边缘不算重叠。 
3. 检查一个矩形是否完全位于另一个矩形的上方或下方。 

出现这种情况时：```
rec1[3] <= rec2[1]
```或者```
rec2[3] <= rec1[1]
```4. 如果任何分离条件为真，则返回`false`。 

分离轴意味着矩形不能共享正面积。 
5.否则返回`true`。 

如果没有水平分隔且没有垂直分隔，则矩形必须重叠。 

### 为什么它有效

 该算法依赖于几何属性：两个轴对齐的矩形重叠当且仅当它们之间水平或垂直地**没有分隔间隙**。 

如果水平或垂直范围未能与正长度相交，则相交面积必须为零。 相反，如果两个尺寸都与正长度重叠，则相交面积为正。 由于我们详尽地检查了所有不重叠的情况，因此保证结果是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        # Check for horizontal separation
        if rec1[2] <= rec2[0] or rec2[2] <= rec1[0]:
            return False

        # Check for vertical separation
        if rec1[3] <= rec2[1] or rec2[3] <= rec1[1]:
            return False

        return True
```实现完全遵循算法。 

第一个`if`语句检查矩形是否水平分隔。 如果一个矩形的右边缘小于或等于另一个矩形的左边缘，则不存在正水平重叠。 

第二个`if`语句使用相同的想法检查垂直间距。 

如果都不存在分隔，则矩形与正区域重叠，因此函数返回`True`。 

该实现避免了不必要的计算并直接对几何观察进行编码。

 ## 边缘情况

 ### 边缘相连的矩形

 一个非常常见的错误是将边缘接触视为重叠。 

例如：```
[0,0,1,1]
[1,0,2,1]
```矩形恰好相交于`x = 1`，但重叠宽度为零。 由于问题需要**正面积**，因此必须返回`false`。 

该实现使用正确处理这个问题`<=`而不是`<`。 

### 角点相连的矩形

 角接触是另一个微妙的情况：```
[0,0,1,1]
[1,1,2,2]
```矩形仅相交于一点，`(1,1)`。 点的面积为零，因此这不是重叠。 

由于水平和垂直重叠长度均为零，因此分离逻辑正确返回`false`。 

### 一个矩形完全位于另一个矩形内

 有时一个矩形完全包含在另一个矩形内：```
[0,0,10,10]
[2,2,3,3]
```幼稚的实现可能会意外地只关注边缘交叉点并错过这种情况。 

我们的解决方案之所以有效，是因为没有水平或垂直分离。 由于两个矩形都不完全位于另一个矩形之外，因此算法正确返回`true`。
