 ## 解决方案

 ## 问题理解

 问题是要求我们设计一个自定义的类似堆栈的数据结构，它支持两种操作：将值推入堆栈并弹出最频繁的元素。 与传统堆栈的一个关键区别是`pop`操作并不一定删除顶部的元素； 相反，它会删除频率最高的元素。 如果多个元素共享相同的频率，则应删除最靠近堆栈顶部的元素。 

输入由一系列`push`和`pop`运营。 每个`push`将一个值添加到堆栈中，并且每个`pop`根据描述的规则返回最频繁的元素。 预期输出为`pop`是与删除的元素相对应的整数。 

约束表明`val`最多可以有 10^9 并且最多可以有 2 * 10^4 操作，这表明任何解决方案都必须有效地处理频繁的查找和更新。 保证`pop`仅当堆栈非空时才会调用，简化了错误处理。 

要考虑的边缘情况包括多次推送同一元素、多个元素共享相同频率时弹出以及有效处理大量操作。 

## 方法

 蛮力方法将维护一个标准堆栈，并且对于每个`pop`，扫描堆栈找到出现频率最高的元素，将其删除。 这保证了正确性，但效率低下。 每个`pop`可能需要扫描整个堆栈，从而使每个堆栈的时间复杂度为 O(n)`pop`，其中 n 是当前堆栈大小。 超过 2 * 10^4 操作，此方法可能太慢。 

最佳方法的关键观察是我们只需要快速访问频率最高的元素。 使用哈希映射来跟踪频率以及从频率到值堆栈的二次映射允许我们在恒定时间内推送和弹出。 每个`pop`只是从堆栈中删除当前最大频率对应的最新元素，并且最大频率是动态更新的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每次弹出 O(n) | O(n) | 使用单个堆栈并扫描它以查找每次弹出 | 中最频繁出现的元素。 
| 最佳 | 每次推送/弹出 O(1) | O(n) | 使用哈希映射和频率堆栈映射来有效地跟踪元素 |

 ## 算法演练

 1. 初始化哈希图`freq`存储每个值的频率。 
2. 初始化哈希图`group`其中键是频率，值是具有该频率的元素堆栈。 
3. 维护一个变量`maxfreq`跟踪堆栈中当前的最大频率。 
4. 对于`push(val)`, 增量`freq[val]`。 推`val`到`group[freq[val]]`。 更新`maxfreq`如果需要的话。 
5. 对于`pop()`，从中取出元素`group[maxfreq]`（栈顶对应当前最大频率）。 减少其频率`freq[val]`。 如果`group[maxfreq]`变空，减量`maxfreq`。 
6. 返回弹出的元素。 

这有效是因为`group`始终包含每个频率最近添加的元素。 从顶部弹出`group[maxfreq]`，我们满足频率和堆栈顺序约束。 

## Python 解决方案```python
class FreqStack:

    def __init__(self):
        self.freq = {}  # maps val -> frequency
        self.group = {}  # maps frequency -> stack of vals
        self.maxfreq = 0

    def push(self, val: int) -> None:
        f = self.freq.get(val, 0) + 1
        self.freq[val] = f
        if f not in self.group:
            self.group[f] = []
        self.group[f].append(val)
        self.maxfreq = max(self.maxfreq, f)

    def pop(self) -> int:
        val = self.group[self.maxfreq].pop()
        self.freq[val] -= 1
        if not self.group[self.maxfreq]:
            self.maxfreq -= 1
        return val
```这`push`方法增加该值的频率并将其附加到与该频率对应的堆栈中。 这`pop`方法检索具有最大频率的最新元素，减少其频率，并调整`maxfreq`如果需要的话。 这确保了两个操作的时间都是 O(1)。 

## 解决方案```go
type FreqStack struct {
    freq    map[int]int
    group   map[int][]int
    maxfreq int
}

func Constructor() FreqStack {
    return FreqStack{
        freq:  make(map[int]int),
        group: make(map[int][]int),
    }
}

func (this *FreqStack) Push(val int) {
    this.freq[val]++
    f := this.freq[val]
    this.group[f] = append(this.group[f], val)
    if f > this.maxfreq {
        this.maxfreq = f
    }
}

func (this *FreqStack) Pop() int {
    vals := this.group[this.maxfreq]
    val := vals[len(vals)-1]
    this.group[this.maxfreq] = vals[:len(vals)-1]
    this.freq[val]--
    if len(this.group[this.maxfreq]) == 0 {
        this.maxfreq--
    }
    return val
}
```在 Go 中，切片用作堆栈。 我们附加到push和slice以弹出顶部元素。 其余逻辑反映了 Python 实现。 地图数据结构确保恒定时间频率和组查找。
