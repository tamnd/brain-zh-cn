[LeetCode 第 819 题](https://leetcode.com/problems/most-common-word/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们处理一段文本并确定哪个单词出现最频繁，同时忽略给定的禁用单词列表。 最终答案必须以小写形式返回。 

几个重要的细节使这个问题比简单的字数统计稍微复杂一些。 首先，该段落可以包含标点符号，例如逗号、句号、感叹号、撇号、分号和问号。 这些标点符号不被视为单词的一部分，在处理过程中必须被忽略。 二、单词不区分大小写，意思是`"Ball"`,`"BALL"`， 和`"ball"`都应该被视为同一个词。 

输入由两个值组成：

 -`paragraph`，包含单词、空格和标点符号的字符串
 -`banned`，不允许被考虑作为答案的小写单词数组

 输出是一个字符串，表示未被禁止的最常见单词。 

限制相当小。 段落长度最多为 1000 个字符，禁止列表最多包含 100 个单词。 由于这些限制，我们不需要高度专业化的优化。 带有基于散列计数的简单线性扫描就足够了。 

有几个重要的边缘情况需要考虑：

 - 单词可能会以不同的大小写形式出现，因此需要标准化为小写。 
- 标点符号可能会出现在单词旁边，例如`"ball,"`或者`"hit."`，因此必须删除标点符号或将其视为分隔符。 
- 禁止列表可能为空。 
- 该段落只能包含一个单词。 
- 多个标点符号可能连续出现。 
- 该问题保证至少有一个非禁用单词，并且答案是唯一的，因此我们永远不需要处理联系。 

## 方法

 ### 蛮力方法

 暴力解决方案首先从段落中提取每个单词，将它们标准化为小写，然后对于每个不同的单词，重复扫描整个单词列表以计算它出现的次数。 

该算法的工作原理如下：

 1. 将段落转换为小写。 
2. 删除标点符号并将段落拆分为单词。 
3. 对于每个单词：

 - 如果被禁止，请跳过。 
- 再次扫描整个单词列表来计算它出现的次数。 
4. 跟踪出现频率最高的单词。 

这种方法是正确的，因为每个词频都是精确计算的。 然而，它的效率很低，因为计算每个单词需要再次遍历列表。 

如果有`n`单词，并且我们通过重新扫描列表中的每个单词来计算频率，总复杂度变为`O(n²)`。 

### 最佳方法

 关键的观察是频率计数正是哈希图的设计目的。 我们可以一次计算出现次数，而不是重复地重新扫描整个列表。 

改进方法的工作原理如下：

 1. 将段落转换为小写。 
2. 将标点符号替换为空格。 
3. 将清理后的字符串拆分为单词。 
4. 将禁止的单词存储在哈希集中`O(1)`抬头。 
5. 使用哈希映射来计算每个非禁止单词的出现次数。 
6. 计数时跟踪出现频率最高的单词。 

这种方法非常高效，因为每个单词都被处理一次，并且哈希映射操作平均时间是恒定的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复扫描所有单词以计算频率 |
 | 最佳 | O(n) | O(n) | 在单次传递中使用哈希图频率计数 |

 ## 算法演练

 1. 将整个段落转换为小写。 

这确保仅大小写不同的单词被视为相同。 例如，`"BALL"`和`"ball"`变成同一个词。 
2. 将标点符号替换为空格。 

由于标点符号不是单词的一部分，因此诸如`.`,`,`,`!`,`?`,`;`， 和`'`应充当分隔符。 用空格替换它们可以简化拆分。 
3. 将清理后的段落拆分为单独的单词。 

删除标点符号后，调用`split()`给出一个干净的单词列表。 
4. 将禁止的单词存储在哈希集中。 

哈希集允许恒定时间的成员资格检查。 这很重要，因为我们可能会根据禁止列表检查每个单词。 
5. 创建哈希图来计算频率。 

当我们迭代这些词时：

 - 如果该词被禁止，请跳过该词。 
- 否则增加其在频率图中的计数。 
6. 在计数时跟踪最常见的有效单词。 

更新单词频率后：

 - 将其与当前最大频率进行比较。 
- 如果超过最大值，请更新答案。 
7. 返回最常见的非禁用词。 

### 为什么它有效

 该算法对每个有效单词只处理一次，并在哈希图中维护准确的频率计数。 由于禁用的单词被完全跳过，因此只有符合条件的单词才会计入计数。 通过不断跟踪遇到的最大频率，算法保证返回的单词是最常见的非禁用单词。 问题保证了唯一性，因此最终结果不会有歧义。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def mostCommonWord(self, paragraph: str, banned: List[str]) -> str:
        banned_set = set(banned)

        normalized = paragraph.lower()

        for char in "!?',;.":
            normalized = normalized.replace(char, " ")

        words = normalized.split()

        frequency = defaultdict(int)

        most_common = ""
        max_count = 0

        for word in words:
            if word in banned_set:
                continue

            frequency[word] += 1

            if frequency[word] > max_count:
                max_count = frequency[word]
                most_common = word

        return most_common
```实施首先将禁止列表转换为集合。 这允许在处理单词时进行有效的成员资格检查。 

接下来，将该段落转换为小写，以便比较不区分大小写。 问题中指定的标点符号被替换为空格，这确保标点符号不会成为单词的一部分。 

然后使用将清理后的段落分成单词`split()`。 Python 自动正确处理多个空格。 

一个`defaultdict(int)`用于频率计数。 这避免了手动检查地图中是否已存在单词。 

处理每个单词时：

 - 立即跳过禁止的单词。 
- 有效单词的频率增加。 
- 如果新频率超过当前最大值，则更新答案。 

最后，返回存储的最常用单词。 

## 解决方案```go
package main

import (
	"strings"
)

func mostCommonWord(paragraph string, banned []string) string {
	bannedSet := make(map[string]bool)

	for _, word := range banned {
		bannedSet[word] = true
	}

	normalized := strings.ToLower(paragraph)

	punctuation := "!?',;."
	for _, ch := range punctuation {
		normalized = strings.ReplaceAll(normalized, string(ch), " ")
	}

	words := strings.Fields(normalized)

	frequency := make(map[string]int)

	mostCommon := ""
	maxCount := 0

	for _, word := range words {
		if bannedSet[word] {
			continue
		}

		frequency[word]++

		if frequency[word] > maxCount {
			maxCount = frequency[word]
			mostCommon = word
		}
	}

	return mostCommon
}
