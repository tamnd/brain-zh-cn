 # LeetCode 858 - 镜面反射

 ## 问题理解

 该问题描述了一个带有完美反射墙壁的方形房间。 房间有边长`p`，并且在正方形的三个角放置了三个接收器：

 - 受体`0`在东南角
 - 受体`1`位于东北角
 - 受体`2`位于西北角

 激光从西南角开始，斜向向东墙行进。 它首先以垂直距离撞击东墙`q`来自受体`0`。 

目标是确定激光在墙壁反复反射后首先击中哪个受体。 

重要的细节是反射的行为与几何镜面反射完全相同。 我们可以将房间视为以平铺图案无限重复，而不是单独模拟每次反弹。 在这个扩展视图中，激光沿直线穿过重复的镜面房间。 这条直线第一次到达角落对应于原始房间中的第一个接收器命中。 

输入由两个整数组成：

 -`p`, 房间的边长
 -`q`，激光第一次到达东墙时的垂直位移

 输出是表示受体编号的单个整数。 

限制很小：

 -`1 <= q <= p <= 1000`尽管限制不大，但如果直接模拟，几何体可能会产生许多反射。 简单的模拟可能会变得混乱且容易出错，因为浮点精度和重复反射会带来不必要的复杂性。 

一些边缘情况很重要：

 - 当`q == p`，激光直接射向东北角，即接收器`1`- 什么时候`q`均分`p`，该模式可能会很快终止
 - 当`p`和`q`共享公约数，降低比率至关重要
 - 房间分机数量的奇偶性决定接收器

 这个问题保证了激光最终到达接收器，因此我们永远不需要处理无限循环或不可能的情况。 

## 方法

 ### 暴力模拟

 一种直接的方法是模拟激光的运动和反射。 我们可以追踪：

 - 当前位置
 - 当前方向
 - 接下来会撞到哪堵墙
 - 反射后方向如何变化

 最终，激光到达其中一个受体。 

这种方法在概念上很简单，因为它反映了物理过程。 然而，它带来了一些复杂性：

 - 浮点运算可能会导致精度问题
 - 反射逻辑变得繁琐
 - 确定准确的角击球是很棘手的
 - 终止前可能会发生许多反思

 尽管限制很小，但实现复杂度却过高。 

### 最优数学观察

 关键的见解是可以通过展开房间来消除反射。 

想象一下每次激光击中墙壁时都会反射房间本身，而不是反射激光。 在这个无限扩大的房间网格中，激光以完美的直线传播。 

当两个条件同时成立时，激光到达接收器：

 - 水平方向移动了整数倍`p`- 垂直方向上，它也与房间边界对齐

 在数学上，我们寻求最小的正整数`L`这样：$$L = k \cdot p = m \cdot q$$这意味着`L`必须是最小公倍数`p`和`q`。 

一旦我们发现：$$\text{LCM}(p, q)$$我们确定：

 -`m = LCM / q`-`n = LCM / p`这些值的奇偶性决定了受体：

 -`n`奇数和`m`奇数 → 受体`1`-`n`奇数和`m`偶→受体`0`-`n`甚至和`m`奇数 → 受体`2`更简洁的实现避免显式计算 LCM。 我们反复划分两者`p`和`q`经过`2`而两者都是偶数。 然后：

-`p`奇数和`q`奇数 → 受体`1`-`p`奇数和`q`偶→受体`0`-`p`甚至和`q`奇数 → 受体`2`这是有效的，因为在删除公因数后，只有奇偶性才重要`2`。

 ## 算法演练

 ### 最优算法

 1. 重复将两者分开`p`和`q`经过`2`而它们都是偶数。 

这消除了两人的所有共享权力。 只有剩余值的奇偶性对于确定受体很重要。 
2. 还原后，检查是否`p`和`q`是奇数或偶数。 

有效的情况只有三种：

 - 如果`p`是奇数并且`q`为奇数，返回`1`- 如果`p`是奇数并且`q`是偶数，返回`0`- 如果`p`是偶数并且`q`为奇数，返回`2`3. 返回对应的受体编号。 

### 为什么它有效

 当垂直和水平距离在拐角处对齐时，激光到达接收器。 这发生在以下的最小公倍数处：`p`和`q`。 

去除两个共享因子后，只有奇偶校验才能确定激光到达哪一侧和哪一个角：

 - 奇怪的水平延伸意味着激光在东墙上结束
 - 即使是水平延伸也意味着它在西墙上结束
 - 奇怪的垂直延伸意味着它终止于顶壁

 结合这些奇偶条件可以唯一地识别受体。 

## Python 解决方案```python
class Solution:
    def mirrorReflection(self, p: int, q: int) -> int:
        while p % 2 == 0 and q % 2 == 0:
            p //= 2
            q //= 2

        if p % 2 == 1 and q % 2 == 1:
            return 1

        if p % 2 == 1 and q % 2 == 0:
            return 0

        return 2
```实现首先从删除两个的所有公共因素`p`和`q`。 这个标准化步骤很重要，因为最终的受体仅取决于减少的值是奇数还是偶数。 

第一个`while`循环使用整数除法有效地执行此缩减。 

归约后，代码检查奇偶校验组合：

 - 两个奇数对应于受体`1`-`p`奇数和`q`甚至对应于受体`0`- 剩余有效案例为受体`2`逻辑很紧凑，因为数学结构将问题简化为简单的奇偶分析。 

## 解决方案```go
func mirrorReflection(p int, q int) int {
    for p%2 == 0 && q%2 == 0 {
        p /= 2
        q /= 2
    }

    if p%2 == 1 && q%2 == 1 {
        return 1
    }

    if p%2 == 1 && q%2 == 0 {
        return 0
    }

    return 2
}
```Go 实现遵循与 Python 版本完全相同的数学推理。 

由于所有操作都涉及小整数，因此不存在整数溢出问题。 Go 整数除法自然会截断为零，这与重复除以二的预期行为相匹配。 

不需要额外的数据结构，因此实现保持简洁和高效。

 ## 边缘情况

 ### 案例 1：`q == p`什么时候`q`等于`p`，激光直接向东北角传播，不需要任何反射。 这对应于受体`1`。 

有缺陷的实现可能会错误地模拟不必要的反射或错误地处理直接对角路径。 基于奇偶校验的方法可以自然地处理这个问题，因为两个减少的值都变成奇数。 

### 案例 2：两人的巨大共同权力

 输入如`p = 128`和`q = 64`包含许多两个的公因数。 如果实现没有正确减少这些因素，奇偶校验逻辑就会变得不正确。 

该解决方案在检查奇偶校验之前明确删除了两个人的所有共享权力，从而确保正确性，无论需要减少多少次。 

### 情况 3：一个值是奇数，一个值是偶数

 一个值为奇数而另一个值为偶数的情况尤其重要，因为它们决定激光是在东墙还是西墙上结束。 

例如：```
p = 6, q = 4
```减少后：```
p = 3, q = 2
```这映射到受体`0`。 

不正确的实施常常会让受体感到困惑`0`和`2`因为它们在标准化后没有正确解释奇偶校验。 此实现中的显式奇偶校验完全避免了该错误。
