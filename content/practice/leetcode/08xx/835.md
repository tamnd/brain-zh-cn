[LeetCode 835 题](https://leetcode.com/problems/image-overlap/)

 **难度：** 🟡 中等
 **主题：** 数组、矩阵

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定两个二元方阵之间的最大重叠（`img1`和`img2`）当一个矩阵平移到另一个矩阵上时。 每个矩阵仅包含`0`沙`1`s，其中`1`代表一个填充像素并且`0`代表一个空像素。 **翻译**意味着转移所有`1`一张图像中的上、下、左或右方向的任意组合。 任何移动到矩阵边界之外的像素都将被丢弃。 目标是找到使两个图像都有一个位置的数量最大化的翻译`1`同时地。 

输入有两个`n x n`矩阵其中`1 <= n <= 30`。 这个小尺寸暗示暴力方法可能是可行的，但可能有一些优化可以使解决方案更加优雅和更快。 边缘情况包括全零矩阵（导致零重叠）、大小矩阵`1 x 1`，或具有单个的矩阵`1`在一个角落。 该问题保证了方阵，因此我们不需要处理矩形输入。 

## 方法

 ### 蛮力方法

 蛮力方法考虑了**所有可能的翻译**`img1`超过`img2`。 对于每个翻译，我们通过迭代矩阵中的每个元素并计算两个元素都有一个的位置来计算重叠`1`。 给定最大矩阵大小`30 x 30`， 有`2n-1`水平和垂直方向上可能发生的偏移。 因此，总翻译次数为`(2n-1) * (2n-1)`并检查每个翻译需要`O(n^2)`时间，导致总时间复杂度为`O(n^4)`。 这是正确的，但效率不高。 

### 最佳方法

 一个关键的见解是**对待以下职位`1`s 作为点**并计算所有对之间的向量偏移`1`是从`img1`和`img2`。 对于每个`1`在`img1`在`(i1, j1)`和每个`1`在`img2`在`(i2, j2)`，平移向量`(i2 - i1, j2 - j1)`会将这两个对齐`1`s。 如果多个对共享相同的平移向量，则该向量对应于对数量的重叠。 使用哈希图来计算每个平移向量的频率使我们能够有效地找到具有最大重叠的向量。 

这种方法显着减少了冗余计算，并避免显式地迭代每个可能的翻译。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 迭代所有翻译并计算重叠 |
 | 最佳| 最坏情况为 O(n^4)，但实践中速度更快 | O(n^2) | O(n^2) | 使用哈希图来计算之间的平移向量`1`s |

 ## 算法演练

 1. **提取坐标`1`s**：迭代两个矩阵并记录位置`(i, j)`全部的`1`进入`img1`和`img2`。 
2. **计算翻译向量**：对于每对`1`s`(x1, y1)`从`img1`和`(x2, y2)`从`img2`，计算平移向量`(dx, dy) = (x2 - x1, y2 - y1)`。 
3. **计算向量频率**：维护一个哈希映射，其中键是平移向量，值是产生该向量的对的计数。 
4. **查找最大重叠**：哈希图中的最大值对应于最大可能的重叠。 
5. **返回结果**：如果没有`1`s存在，返回`0`; 否则，返回最大计数。 

**为什么有效**：每个平移向量都对齐特定的`1`是从`img1`和`1`是从`img2`。 计算有多少对产生相同的向量可以直接给出该翻译的重叠。 由于我们检查所有对，我们考虑所有可能的重叠，保证正确性。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def largestOverlap(self, img1: List[List[int]], img2: List[List[int]]) -> int:
        n = len(img1)
        ones_img1 = [(i, j) for i in range(n) for j in range(n) if img1[i][j] == 1]
        ones_img2 = [(i, j) for i in range(n) for j in range(n) if img2[i][j] == 1]
        
        vector_count = Counter()
        for x1, y1 in ones_img1:
            for x2, y2 in ones_img2:
                vector_count[(x2 - x1, y2 - y1)] += 1
        
        return max(vector_count.values(), default=0)
```该解决方案首先提取所有的坐标`1`两个矩阵中都有 s。 嵌套循环计算每对的平移向量`1`s 并增加哈希映射中的计数。 最后，`max`函数识别给出最大重叠的平移向量。 这`default=0`确保没有时的正确性`1`s。 

## 解决方案```go
func largestOverlap(img1 [][]int, img2 [][]int) int {
    n := len(img1)
    type point struct{ x, y int }
    onesImg1 := []point{}
    onesImg2 := []point{}

    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            if img1[i][j] == 1 {
                onesImg1 = append(onesImg1, point{i, j})
            }
            if img2[i][j] == 1 {
                onesImg2 = append(onesImg2, point{i, j})
            }
        }
    }

    vectorCount := make(map[point]int)
    maxOverlap := 0
    for _, p1 := range onesImg1 {
        for _, p2 := range onesImg2 {
            vec := point{p2.x - p1.x, p2.y - p1.y}
            vectorCount[vec]++
            if vectorCount[vec] > maxOverlap {
                maxOverlap = vectorCount[vec]
            }
        }
    }

    return maxOverlap
}
```在 Go 中，我们使用结构体`point`表示坐标和平移向量。 地图用于计算向量，并且我们动态更新最大重叠。 与 Python 元组不同，Go 需要显式处理切片和映射键。 

## 工作示例

 ### 示例 1```
img1 = [[1,1,0],[0,1,0],[0,1,0]]
img2 = [[0,0,0],[0,1,1],[0,0,1]]
```坐标为`1`s:`img1`：(0,0)、(0,1)、(1,1)、(2,1)`img2`：（1,1）、（1,2）、（2,2）

 计算平移向量：

 - (1,1)-(0,0) = (1,1)
 - (1,2)-(0,0) = (1,2)
 - (2,2)-(0,0) = (2,2)
 - ...
 - 向量的最大计数：(1,1) 出现 3 次 → 重叠 = 3

 ### 示例 2```
img1 = [[1]]
img2 = [[1]]
```向量：(0,0) → 重叠 = 1

 ### 示例 3```
img1 = [[0]]
img2 = [[0]]
```不`1`s → 重叠 = 0

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n^4) 最坏情况 | 为了`n x n`矩阵，最多有`n^2` `1`s in each image. 计算所有对的平移向量是 O(n^2 * n^2) |
 | 空间| O(n^2) | O(n^2) | Store coordinates of`1`s 和翻译向量的哈希图 |

 实际运行时间通常更好，因为大多数矩阵都是稀疏的，并且矩阵的数量`1`s 远小于`n^2`。
