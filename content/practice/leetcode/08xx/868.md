[LeetCode 868 题](https://leetcode.com/problems/binary-gap/)

 **难度：** 🟢简单
 **主题：** 位操作

 ## 解决方案

 ## 问题理解

 该问题要求我们检查正整数的二进制表示`n`并确定两个相邻之间的最大距离`1`位。 

一个二进制数是由`0`沙`1`s。 例如：

-`22`二进制是`10110`-`5`二进制是`101`-`8`二进制是`1000`我们只对位所在的位置感兴趣`1`。 其中`1`s，我们查看相邻的对，因为没有其他对`1`他们之间。 

例如，在`10110`:

 - 第一和第二`1`位之间用一分隔`0`，所以他们的距离是`2`- 第二个和第三个`1`位彼此相邻，因此它们的距离是`1`答案是这些距离中的最大值。 

输入是单个整数`n`， 在哪里：

-`1 <= n <= 10^9`自从`10^9`适合 32 位，二进制表示非常小。 这立即表明，即使逐一扫描也将非常有效。 

有几个重要的边缘情况：

 - 只有一个的数字`1`一点，比如`8`（`1000`），应该返回`0`- 连续的数字`1`s，例如`3`（`11`），应该返回`1`- 数字之间差距较大`1`s，例如`17`（`10001`），应该正确计算较大的距离
 - 最小的有效输入，`1`，仅包含一个`1`，所以答案是`0`该问题保证了`n`是正数，所以我们永远不需要处理负值或空的二进制表示。 

## 方法

 ### 蛮力方法

 一种简单的方法是首先使用内置转换函数将数字转换为二进制字符串。 

例如：```
22 -> "10110"
```然后我们可以从左到右扫描字符串并记录每个字符串的位置`1`。 每当我们遇到新的`1`，我们计算与前一个的距离`1`并更新最大距离。 

这种方法是正确的，因为每对相邻的`1`s 仅检查一次。 

尽管此解决方案对于给定的约束来说已经足够快，但它使用额外的空间来进行二进制字符串转换。 

### 最佳方法

 更高效、更优雅的解决方案使用直接位操作。 

我们不是将数字转换为字符串，而是使用按位运算一次处理一位：

 -`n & 1`检查当前位是否为`1`-`n >>= 1`将位向右移动

 在扫描这些位时，我们跟踪：

 - 当前位位置
 - 前一个的位置`1`- 迄今为止发现的最大差距

 每当我们遇到新的`1`，我们计算与前一个的距离`1`。 

这很有效，因为二进制表示本质上是基于位的，因此位操作让我们可以直接处理数字，而无需额外的内存分配。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(log n) | O(log n) | 将整数转换为二进制字符串并扫描它 |
 | 最佳| O(log n) | O(1) | O(1) | 使用位操作直接处理位 |

 ## 算法演练

 1. 初始化变量`max_gap`到`0`。 这将存储相邻之间找到的最大距离`1`s。 
2. 初始化变量`previous_one_position`到`-1`。 该变量会记住最后一个的位置`1`我们遇到的一点。 值为`-1`意味着我们还没有看到任何`1`然而。 
3. 初始化变量`position`到`0`。 这表示从右向左扫描时的当前位位置。 
4. 虽然`n`大于`0`，继续一次处理一位。 
5. 检查当前位是否为`1`使用`n & 1`。 
6. 如果当前位是`1`:

 1.如果`previous_one_position`不是`-1`，计算距离：```
position - previous_one_position
```2. 更新`max_gap`如果这个距离更大。 
3. 将当前位置存储为新位置`previous_one_position`。 
7. 使用以下命令将数字右移一位：```
n >>= 1
```这会将下一位移动到最低有效位置。 
8. 增量`position`经过`1`。 
9. 处理完所有位后，返回`max_gap`。 

### 为什么它有效

 该算法按从最低有效位到最高有效位的顺序对每个位精确扫描一次。 每当一个`1`遇到位时，算法将其位置与前一个进行比较`1`位位置。 由于相邻`1`在扫描过程中连续遇到 s，每个有效间隙仅测量一次。 取这些距离中的最大值可以保证正确的答案。 

## Python 解决方案```python
class Solution:
    def binaryGap(self, n: int) -> int:
        max_gap = 0
        previous_one_position = -1
        position = 0

        while n > 0:
            if n & 1:
                if previous_one_position != -1:
                    gap = position - previous_one_position
                    max_gap = max(max_gap, gap)

                previous_one_position = position

            n >>= 1
            position += 1

        return max_gap
```该实现紧密遵循前面描述的算法。 

变量`max_gap`存储迄今为止找到的最佳答案。 变量`previous_one_position`跟踪最后一个的位置`1`少量。 变量`position`跟踪当前位索引。 

表达式`n & 1`检查最低有效位是否是`1`。 如果是，我们计算与前一个的距离`1`并在必要时更新答案。 

操作`n >>= 1`将位向右移动，使我们能够在下一次迭代期间处理下一位。 

因为我们从不显式存储二进制表示，所以该解决方案使用恒定的额外空间。 

## 解决方案```go
func binaryGap(n int) int {
    maxGap := 0
    previousOnePosition := -1
    position := 0

    for n > 0 {
        if n&1 == 1 {
            if previousOnePosition != -1 {
                gap := position - previousOnePosition

                if gap > maxGap {
                    maxGap = gap
                }
            }

            previousOnePosition = position
        }

        n >>= 1
        position++
    }

    return maxGap
}
```Go 实现几乎完全反映了 Python 逻辑。 

一个小小的区别是 Go 不提供 Python 的内置功能`max()`整数函数，所以我们使用标准`if`更新声明`maxGap`。 

由于约束很小，因此不必担心整数溢出。 该解决方案还使用 Go 中的恒定额外空间。

 ## 边缘情况

 一个重要的边缘情况是当数字仅包含一个`1`少量。 例子包括`1`,`2`,`4`， 和`8`。 在这些情况下，没有相邻的一对`1`s 存在，所以答案一定是`0`。 有缺陷的实现可能会意外返回未初始化的值或计算出无效的距离。 此实现通过初始化避免了该问题`previous_one_position`到`-1`并且只计算前一个之后的间隙`1`已经被看到了。 

另一个重要的边缘情况是当二进制表示包含连续的`1`s，例如`3`（`11`） 或者`6`（`110`）。 连续位位置之间的距离是`1`，这是最小有效间隙。 一些不正确的实现错误地计算了之间的零数量`1`s 而不是位置之间的距离。 该实现正确地计算了位置差异，因此连续`1`s 产生间隙`1`。 

第三个重要的边缘情况是当最大间隙出现在最高有效位附近时，例如`17`（`10001`）。 不正确的实现可能会过早终止或无法在移位期间跟踪正确的位位置。 该解决方案增加了`position`每次迭代时都有变量，确保无论在何处，所有位距离都能准确测量`1`s 出现在号码中。
