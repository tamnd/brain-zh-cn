[LeetCode 806 题](https://leetcode.com/problems/number-of-lines-to-write-string/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定如何写一个字符串`s`当每个字符具有特定的像素宽度并且每行不能超过 100 像素时，在多行上。 我们得到一个数组`widths`长度为26，其中每个索引对应一个小写英文字母，其值表示该字母的宽度有多少像素。 目标是计算两件事：写入整个字符串所需的总行数，以及最后一行的宽度（以像素为单位）。 

输入`s`为仅包含小写字母的字符串，长度范围为1～1000。`widths`array 包含 2 到 10 之间的整数，这些整数很小且固定。 输出是一个长度为 2 的数组，其中第一个元素是行数，第二个元素是最后一行的宽度。 

可能会妨碍简单实现的边缘情况包括每个字符都接近最大宽度 10 的字符串，这可能需要频繁换行，或者完全由宽度为 2 或 10 的单个字母组成的字符串。该问题保证`widths`正好有 26 个元素`s`仅包含小写字母，因此我们不需要处理无效字符或越界索引。 

## 方法

 暴力方法很简单：我们迭代字符串中的每个字符`s`，查找其宽度`widths`，并将其添加到当前行的运行总计中。 每当该运行总计超过 100 时，我们就会增加行数并将运行总计重置为当前字符的宽度。 这种方法可以正常工作，因为它完全按照问题中的描述模拟了写入过程。 由于限制，它的复杂性在这里是可以接受的，但从概念上讲，它的效率较低，因为它没有利用任何预计算或优化。 

在此问题中，最佳方法本质上与暴力方法相同，因为必须单独处理每个字符以确定它是否适合当前行。 关键的观察是，除了当前行宽的简单计数器和行数计数器之外，我们不需要任何额外的数据结构。 这最大限度地减少了空间使用并简化了实施。

 ## 算法演练

 1. 初始化变量`lines`为 1，代表第一行。 初始化`current_width`为 0，表示当前行使用的宽度。 
2. 迭代每个字符`ch`在字符串中`s`。 对于每个字符，通过索引计算其宽度`widths`数组使用`ord(ch) - ord('a')`。 
3. 检查是否添加该字符的宽度`current_width`将超过 100 像素。 如果是，则增加`lines`加 1 并重置`current_width`到当前字符的宽度。 
4. 如果添加的字符不超过100像素，只需递增`current_width`通过字符的宽度。 
5.处理完所有字符后，返回`[lines, current_width]`， 在哪里`lines`是使用的总行数，`current_width`是最后一行的宽度。 

**为什么有效**：该算法保持一个不变量`current_width`始终是当前行的宽度。 每当一个字符不适合时，就会开始一个新行。 这保证了没有一行超过 100 像素，并且所有字符都只计算一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def numberOfLines(self, widths: List[int], s: str) -> List[int]:
        lines = 1
        current_width = 0

        for ch in s:
            ch_width = widths[ord(ch) - ord('a')]
            if current_width + ch_width > 100:
                lines += 1
                current_width = ch_width
            else:
                current_width += ch_width

        return [lines, current_width]
```Python 实现按照该算法一步步进行。 我们初始化行计数器和当前行宽度。 对于每个字符，我们确定其宽度并决定是继续当前行还是开始新行。 最后，我们返回总行数和最后一行的宽度。 

## 解决方案```go
func numberOfLines(widths []int, s string) []int {
    lines := 1
    currentWidth := 0

    for _, ch := range s {
        chWidth := widths[ch-'a']
        if currentWidth + chWidth > 100 {
            lines++
            currentWidth = chWidth
        } else {
            currentWidth += chWidth
        }
    }

    return []int{lines, currentWidth}
}
```在 Go 中，我们使用`for`循环字符串，得到符文。 我们减去`'a'`将索引放入`widths`。 这里整数算术的工作方式与 Python 相同，我们返回一个包含结果的切片。 不需要对空字符串进行特殊处理，因为约束保证至少有一个字符。

 ## 边缘情况

 一个重要的边缘情况是完全由最小宽度字母组成的字符串。 如果宽度为 2 并且字符串长度为 1000 个字符，则这需要很多行，但算法可以处理它，因为每当达到 100 个像素时，无论字符数如何，它都会增加行数。 

另一种边缘情况是字符串中每个字符的最大宽度为 10。在这种情况下，行几乎总是恰好包含 10 个字符，最后一行的字符可能更少。 当添加下一个字符超过 100 时，该算法仍然正确地开始新行。 

最后，如果算法没有正确重置，最后一行恰好是 100 像素宽的字符串可能会很棘手`current_width`填充一行后。 我们的实现正确更新`current_width`当一行已满时，确保最后一行的宽度准确地反映剩余的字符。
