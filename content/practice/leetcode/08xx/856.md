[LeetCode 第 856 题](https://leetcode.com/problems/score-of-parentheses/)

 **难度：** 🟡 中等
 **主题：** 字符串、堆栈

 ## 解决方案

 ## 问题理解

 问题是要求我们根据一组规则计算一串平衡括号的**分数**。 平衡括号字符串是其中每个左括号`'('`有相应的右括号`')'`并且这些对正确嵌套。 评分规则如下：

 1. 一对`"()"`分数`1`。 
2.平衡字符串的串联`AB`分数`A + B`。 
3. 括号内的字符串`(A)`分数`2 * A`。 

换句话说，字符串的分数是递归定义的：原子`"()"`贡献`1`，嵌套乘以`2`，并且顺序结构求和。 输入`s`保证是平衡的并且仅包含`'('`和`')'`。 约束很小（`2 <= s.length <= 50`），它允许具有线性或接近线性复杂性的解决方案，但由于重复的字符串操作，诸如使用子字符串切片的完全递归解析之类的低效方法仍然可能较慢。 

要考虑的重要边缘情况包括仅具有一对的字符串`"()"`，完全嵌套的结构，例如`"(())"`，以及串联结构，例如`"()()"`。 这些涵盖了三种评分规则：原子、嵌套和顺序。 

## 方法

 **暴力方法**是一种递归解决方案，通过查找匹配的括号并根据规则计算分数来解析字符串。 对于每个子字符串，它将递归地计算其分数：`1`为了`"()"`或者`2 * score(A)`为了`(A)`。 这种方法的问题在于，每个子字符串操作可能需要 O(n) 时间，导致整体复杂度为 O(n²) 或更糟，即使对于中等长度的字符串，这也是低效的。 它工作正常，但不是最佳的。 

**最佳方法**依赖于使用**堆栈**来跟踪不同嵌套级别的分数。 当我们遍历字符串时：

 1.当我们遇到`'('`，我们推一个`0`代表新范围的开始。 
2.当我们遇到`')'`，我们弹出顶部值。 如果是的话`0`，这代表一个简单的`"()"`并做出贡献`1`。 否则，它代表一个嵌套分数，我们将其乘以`2`。 
3. 我们将计算出的分数添加到堆栈顶部的值（代表外层）。 

这可以在**线性时间内**高效地工作，并避免重复的字符串切片。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 递归地切片字符串并计算分数 |
 | 基于堆栈的优化 | O(n) | O(n) | 使用堆栈来跟踪当前级别分数； 单程|

 ## 算法演练

 1. 用单个元素初始化堆栈`0`。 这代表最外层的分数。 
2. 遍历字符串中的每个字符`s`。 
3. 如果角色是`'('`，推一个`0`到堆栈上。 这标志着一个新的嵌套级别的开始。 
4.如果角色是`')'`，从堆栈中弹出顶部元素。 让这个弹出值是`v`。 

- 如果`v`是`0`，刚刚关闭的括号是`"()"`，得分为`1`。 
- 如果`v`大于`0`，括号内包含一些嵌套的字符串和分数`2 * v`。 
5. 将计算出的分数添加到新的堆栈顶部。 这会更新包含级别的分数。 
6、处理完所有字符后，栈中只剩下一个元素，即该字符串的总分。 

**为什么起作用**：堆栈不变式确保堆栈顶部始终保存当前嵌套级别的分数。 通过推送占位符`0`在`'('`并更新父级别`')'`，我们正确处理嵌套和顺序结构，同时保持线性复杂性。 

## Python 解决方案```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        stack = [0]  # Initialize stack with outermost level score
        for char in s:
            if char == '(':
                stack.append(0)  # Start a new score frame
            else:
                v = stack.pop()
                stack[-1] += 1 if v == 0 else 2 * v  # Update parent level
        return stack[0]
```在这个实现中，`stack`跟踪每个嵌套级别的分数。 每一个`'('`表示新嵌套帧的开始，而`')'`结束它。 有条件的`1 if v == 0 else 2 * v`处理原子`"()"`并嵌套`(A)`案例。 堆栈确保顺序结构自动将其分数相加，因为加法发生在父帧级别。 

## 解决方案```go
func scoreOfParentheses(s string) int {
    stack := []int{0}  // Initialize stack with outermost level
    for _, ch := range s {
        if ch == '(' {
            stack = append(stack, 0)  // Start new frame
        } else {
            v := stack[len(stack)-1]
            stack = stack[:len(stack)-1]  // Pop top
            if v == 0 {
                stack[len(stack)-1] += 1  // Atomic "()"
            } else {
                stack[len(stack)-1] += 2 * v  // Nested "(A)"
            }
        }
    }
    return stack[0]
}
```在 Go 中，切片被用作堆栈。 追加和切片模拟推入和弹出操作。 与 Python 不同，我们必须显式地对堆栈进行切片以弹出元素。 逻辑是相同的，条件确保原子结构和嵌套结构都能正确评分。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 单次遍历字符串，每个字符恒定时间 |
 | 空间| O(n) | 堆栈的深度可以增长到等于最大嵌套深度 |

 因为堆栈随着嵌套深度而增长，所以空间与最大括号深度成正比，而不是典型情况下的字符串长度，但在所有嵌套的最坏情况下，O(n)。

 ## 边缘情况

 第一个边缘情况是一个完全由顺序组成的字符串`"()"`成对喜欢`"()()()"`。 这测试算法是否正确地求和多个顶级分数。 堆栈确保连续分数累积在外帧中。 

第二个边缘情况是深层嵌套的括号，例如`"(((())))"`。 这验证了该算法是否正确地将每个嵌套级别的分数加倍。 通过推动`0`对于每个`'('`并乘以 2，当`')'`遇到这种情况时，算法会保持正确的评分规则。 

第三种边缘情况是混合结构，例如`"(()(()))"`。 这测试嵌套规则和顺序规则是否正确交互。 基于堆栈的解决方案自然可以处理这个问题
