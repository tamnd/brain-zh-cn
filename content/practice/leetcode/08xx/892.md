[LeetCode 第 892 题](https://leetcode.com/problems/surface-area-of-3d-shapes/)

 **难度：** 🟢简单
 **主题：** 数组、数学、几何、矩阵

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个`n x n`矩阵称为`grid`，其中每个单元格包含一个非负整数。 价值`grid[i][j]`代表有多少个`1 x 1 x 1`立方体垂直堆叠在适当的位置`(i, j)`。 

每个立方体通过其暴露的面贡献表面积。 单个立方体有 6 个面，但当立方体相互接触时，接触的面变为内部，不再对总表面积产生影响。 

目标是计算网格中所有堆栈形成的整个 3D 结构的总暴露表面积。 重要的是，底面会计入表面积，即使它们位于地面上。 

例如，如果一个单元格包含`3`，这意味着三个立方体垂直堆叠。 没有任何相邻的立方体，堆栈贡献：

 - 顶部和底部 2 个面
 - 每层 4 个侧面

 然而，同一垂直堆叠内的立方体彼此共享面，并且相邻堆叠也水平共享面。 

限制相对较小：

 -`1 <= n <= 50`-`0 <= grid[i][j] <= 50`这意味着网格最多可以包含`2500`单元格，每个堆栈最多可以包含`50`立方体。 由于输入大小适中，`O(n^2)`解决方案绰绰有余。 

一些边缘情况很重要：

 - 有价值的细胞`0`不包含任何立方体并且不贡献任何内容。 
- 单个孤立的立方体贡献了所有 6 个面。 
- 相邻的大堆垛互相隐藏了许多面孔。 
- 相邻高度不均匀只需减去重叠部分。 
- 整行或整列的零不应影响结果。 

简单的实现可以轻松地重复计算相邻堆栈之间的共享面，这是此问题中最常见的错误来源。 

## 方法

 ### 蛮力方法

 强力解决方案将对每个立方体进行单独建模。 

对于每个单元格`(i, j)`与高度`h`，我们可以想象放置`h`3D 空间中的独立立方体。 每个立方体最初有 6 个面。 然后，对于每个立方体，我们检查所有六个方向以确定是否存在相邻的立方体。 如果存在相邻的立方体，则该面被隐藏并且不应被计算在内。 

这种方法是正确的，因为它直接模拟了结构的实际几何形状。 每张暴露的脸都被精确计数一次。 

然而，该解决方案不必要地昂贵，因为它单独处理每个立方体。 在最坏的情况下：

 - 网格包含`50 x 50 = 2500`细胞
 - 每个细胞包含`50`立方体
 - 总立方体 =`125000`检查每个立方体的所有邻居变得比必要的工作多得多。 

### 最佳方法

 关键的观察是我们不需要对单个立方体进行建模。 

相反，我们可以用数学方法计算每个堆栈的贡献。 

对于任何具有高度的堆栈`h > 0`:

 - 顶面贡献`1`- 底面有贡献`1`- 四方贡献`4 * h`所以最初的贡献是：$2 + 4h$然而，相邻的堆叠彼此隐藏面孔。 

如果两个相邻的堆栈有高度`a`和`b`，那么它们之间的隐藏面数为：$2\min(a,b)$这是可行的，因为每个重叠层都隐藏每个堆栈中的一个面。 

我们不会检查所有四个邻居并冒重复计算的风险，而是只比较：

 - 当前单元格与上面的单元格
 - 当前单元格左侧的单元格

 这可确保每个共享边界仅被处理一次。 

最终算法对每个单元处理一次，并且每个单元仅执行恒定的工作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² * h) | O(1) 或 O(n² * h) | 模拟每个单独的立方体并检查相邻的立方体 |
 | 最佳| O(n²) | O(1) | O(1) | 使用堆叠高度以数学方式计算暴露面积 |

 ## 算法演练

 1. 初始化变量`surface_area`到`0`。 

该变量将累积整个结构的总暴露表面积。 
2. 迭代每个单元格`(row, col)`在网格中。 

每个单元格代表一组垂直的立方体。 
3. 读取当前堆栈的高度。 

让：```
height = grid[row][col]
```如果`height == 0`, skip the cell because no cubes exist there.
 4. Add the standalone contribution of the stack.

 Every non-empty stack contributes:

 - 一张顶面
 - 一张底面
 - 四个垂直边

 所以我们添加：$2 + 4h$5. 删除与上面的堆栈共享的隐藏面。 

如果当前单元格上方有一行，则计算重叠：```
overlap = min(current_height, upper_height)
```每个重叠层都隐藏两个面，每层都有一个面。 

所以减去：$2\min(a,b)$6. 删除与左侧堆栈共享的隐藏面。 

对左邻居使用相同的逻辑。 

再次减去两倍的重叠高度。 
7. 继续，直到处理完所有细胞。 
8. 返回`surface_area`。 

### 为什么它有效

 该算法之所以有效，是因为每个堆栈最初都会贡献其所有潜在的可见面。 每当两个堆栈接触时，共享的面就会变成内部的，并且不应计入外表面积。 

通过减去相邻堆栈之间重叠的两倍，我们可以准确地删除隐藏的面。 由于我们只比较每个相邻对一次，因此不会重复计算或遗漏共享表面。 

## Python 解决方案```python
from typing import List

class Solution:
    def surfaceArea(self, grid: List[List[int]]) -> int:
        n = len(grid)
        surface_area = 0

        for row in range(n):
            for col in range(n):
                height = grid[row][col]

                if height == 0:
                    continue

                # Top and bottom faces
                surface_area += 2

                # Four side faces
                surface_area += 4 * height

                # Remove shared faces with upper neighbor
                if row > 0:
                    surface_area -= 2 * min(
                        height,
                        grid[row - 1][col]
                    )

                # Remove shared faces with left neighbor
                if col > 0:
                    surface_area -= 2 * min(
                        height,
                        grid[row][col - 1]
                    )

        return surface_area
```实现直接遵循数学观察。 

嵌套循环遍历网格中的每个单元格。 对于每个非零堆栈，我们首先添加其全部贡献，就好像它是孤立的一样。 

然后，代码仅检查上方和左侧的邻居。 这很重要，因为检查所有四个方向会重复计算共享表面。 

减法步骤删除相邻堆栈创建的隐藏面。 使用`min(height, neighbor_height)`正确处理不均匀的堆叠高度，因为只有重叠部分被隐藏。 

该算法仅使用几个整数变量，因此空间使用量保持不变。 

## 解决方案```go
func surfaceArea(grid [][]int) int {
    n := len(grid)
    surfaceArea := 0

    for row := 0; row < n; row++ {
        for col := 0; col < n; col++ {
            height := grid[row][col]

            if height == 0 {
                continue
            }

            // Top and bottom faces
            surfaceArea += 2

            // Four side faces
            surfaceArea += 4 * height

            // Remove shared faces with upper neighbor
            if row > 0 {
                overlap := min(height, grid[row-1][col])
                surfaceArea -= 2 * overlap
            }

            // Remove shared faces with left neighbor
            if col > 0 {
                overlap := min(height, grid[row][col-1])
                surfaceArea -= 2 * overlap
            }
        }
    }

    return surfaceArea
}

func min(a int, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 实现密切反映了 Python 逻辑。 

Go 没有提供内置的`min`函数用于整数，因此我们手动定义一个辅助函数。 

切片自然地用于 2D 网格表示。 由于约束很小，整数溢出不是问题，因为最大可能的表面积很容易适合 Go 的范围`int`类型。 

与 Python 不同，Go 需要显式变量声明和类型定义，但底层算法保持不变。

 ## 边缘情况

 一个重要的边缘情况是完全空的网格，例如`[[0]]`或完全充满零的更大网格。 幼稚的实现可能仍然为每个单元添加顶面和底面，而不检查立方体是否实际存在。 该实现通过立即跳过高度为零的单元格来避免这种情况。 

另一个重要的边缘情况是相邻堆栈不均匀，例如`[[1,3]]`。 有缺陷的实现可能会通过假设较高的堆栈完全隐藏较短的堆栈来减去太多共享的面。 正确的逻辑只做减法`2 * min(a, b)`，它精确地删除了重叠的隐藏面并保留了较高堆栈的暴露的上部部分。 

第三个重要的边缘情况涉及重复计算相邻重叠。 如果算法检查每个单元的所有四个方向，则每个共享边界将被处理两次。 这会减去太多的面并产生不正确的结果。 该实现通过仅检查上部和左侧邻居来避免这种情况，确保每个共享边界仅处理一次。
