[LeetCode 827 题](https://leetcode.com/problems/making-a-large-island/)

 **难度：** 🔴难
 **主题：** 数组、深度优先搜索、广度优先搜索、并查找、矩阵

 ## 解决方案

 ## 问题理解

 这个问题要求我们在二元网格中最多改变一个之后找到最大可能的岛尺寸`0`进入`1`。 

网格是一个`n x n`矩阵其中：

 -`1`代表土地
 -`0`代表水

 岛屿由在四个基本方向上连接的陆地单元形成：

 - 向上
 - 向下
 - 左
 - 右

 对角线连接不算数。 

允许的操作非常重要。 我们最多可以将一个水细胞翻转到陆地上。 执行此操作后，我们必须计算网格中任何位置可以存在的最大连通岛的大小。 

输出是表示最大岛屿面积的单个整数。 

限制条件很大：

 -`n`可以大到`500`- 因此网格可能包含最多`250,000`细胞

 这立即告诉我们昂贵的重复遍历是行不通的。 任何比粗略更糟糕的算法`O(n²)`可能会超时。 

一个天真的方法可能会尝试翻转每一个`0`每次都从头开始重新计算岛屿大小，但这需要反复扫描网格。 由于可能有`O(n²)`零个单元格，并且每次扫描本身可能会花费`O(n²)`，总复杂度变为`O(n⁴)`，这太慢了。 

一些边缘情况很重要：

 - 网格可能已经完全`1`s。 在这种情况下，我们无法增加岛屿的大小，所以答案很简单`n²`。 
- 网格可能包含所有`0`s。 翻转任何一个单元格都会形成一个大小的岛屿`1`。 
- 翻转了`0`可以将多个不同的岛屿连接在一起。 
- 多个相邻小区可能属于同一个岛屿，因此我们必须避免重复计算岛屿大小。 
- 大型连接组件需要有效的遍历策略。 

关键的挑战是有效地确定当特定的情况下岛屿会变得有多大。`0`单元格被翻转。 

## 方法

 ### 蛮力方法

 蛮力解决方案考虑了每一个`0`细胞独立。 

对于每个水单元：

 1.暂时改为`1`2. 运行 DFS 或 BFS 来计算所得岛屿的大小
 3. 将单元恢复到`0`4. 跟踪所看到的最大岛屿尺寸

 这种方法是正确的，因为它显式地评估每个有效操作并准确计算结果岛的大小。 

然而，它的效率极低。 

最多可以有`n²`零细胞。 对于每一个，我们都可以在网格中执行完整的 DFS 或 BFS 遍历，这本身就需要成本`O(n²)`。 

这导致：

 -`O(n²)`候选人翻转
 -`O(n²)`每次翻转的遍历成本

 总复杂度变为`O(n⁴)`。 

和`n = 500`，这是完全不切实际的。 

### 最佳方法

 关键的观察结果是，除了翻转单元之外，岛的形状不会发生变化。 

我们可以对网格进行一次预处理，而不是重复重新计算岛屿大小：

 1. 识别每个现有岛屿
 2.为每个岛屿分配一个唯一的ID
 3.存储每个岛屿的面积

 经过预处理后，每个陆地单元都知道它属于哪个岛屿。 

然后，对于每个`0`细胞：

 - 看看它的四个邻居
 - 确定哪些独特的岛屿接触到它
 - 将它们的面积加在一起
 - 添加`1`对于翻转的单元格本身

 这是有效的，因为翻转`0`只影响与其直接相邻的岛屿。 

我们通过重用预先计算的岛大小来完全避免重新计算。 

结果是一个高效的`O(n²)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n⁴) | O(n²) | 重新计算每个可能的翻转的岛屿大小 |
 | 最佳| O(n²) | O(n²) | 对岛屿进行一次标记，然后有效地评估每个零单元 |

 ## 算法演练

 ### 第 1 步：为岛屿分配唯一 ID

 我们遍历网格寻找未访问过的陆地单元。 

每当我们发现一个`1`对于尚未处理的部分，我们启动 DFS 或 BFS 来探索其整个连接组件。 

而不是将单元格保留为`1`，我们用唯一的岛屿 ID 重新标记它们，例如`2`,`3`,`4`， 等等。 

我们避免使用`0`和`1`因为：

-`0`已经意味着水
 -`1`指未加工的土地

 使用唯一的 ID 可以让我们稍后在恒定时间内识别单元属于哪个岛。 

### 第 2 步：计算并存储岛屿大小

 在 DFS 遍历过程中，我们计算有多少个单元属于当前岛屿。 

我们将其存储在哈希映射中：```
island_size[island_id] = area
```例如：```
{
    2: 5,
    3: 8,
    4: 2
}
```这种预处理允许稍后即时查找任何岛屿的区域。 

### 第 3 步：追踪现有最大的岛屿

 在标记岛屿时，我们还跟踪现有的最大岛屿面积。 

这处理网格不包含的特殊情况`0`s。 

### 步骤 4：评估每个零单元格

 现在我们再次迭代每个单元格。 

对于每个`0`细胞：

 1. 创建一个空集
 2. 检查它的四个邻居
 3. 将邻近岛屿ID添加到集合中
 4. 将所有独特的邻近岛屿的大小相加
 5. 添加`1`对于翻转的单元格本身

 该集合是必不可少的，因为同一个岛可能从多个方向接触零单元。 

如果没有重复数据删除，我们就会多次错误地计算同一个岛屿。 

### 步骤 5：更新最大答案

 在计算翻转单元格的合并岛大小后，我们更新全局最大值。 

最后，这个最大值就是答案。 

### 为什么它有效

 每个岛屿都被标记一次，其大小也被计算一次。 

当评估一个`0`细胞中，唯一可能连接的岛屿是其相邻的岛屿。 由于我们已经知道每个相邻岛屿的确切大小，因此我们可以直接计算合并区域，而无需任何额外的遍历。 

使用集合可以保证每个岛仅贡献一次其面积，即使它从多个侧面接触翻转的单元格。 

因此，每个可能的有效翻转都会被正确评估，并返回最大可实现的岛大小。 

## Python 解决方案```python
from typing import List

class Solution:
    def largestIsland(self, grid: List[List[int]]) -> int:
        n = len(grid)
        island_size = {}
        island_id = 2

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        def dfs(r: int, c: int, island_id: int) -> int:
            stack = [(r, c)]
            grid[r][c] = island_id
            area = 1

            while stack:
                row, col = stack.pop()

                for dr, dc in directions:
                    nr = row + dr
                    nc = col + dc

                    if (
                        0 <= nr < n
                        and 0 <= nc < n
                        and grid[nr][nc] == 1
                    ):
                        grid[nr][nc] = island_id
                        area += 1
                        stack.append((nr, nc))

            return area

        max_island = 0

        for r in range(n):
            for c in range(n):
                if grid[r][c] == 1:
                    area = dfs(r, c, island_id)
                    island_size[island_id] = area
                    max_island = max(max_island, area)
                    island_id += 1

        for r in range(n):
            for c in range(n):
                if grid[r][c] == 0:
                    neighboring_islands = set()
                    current_size = 1

                    for dr, dc in directions:
                        nr = r + dr
                        nc = c + dc

                        if 0 <= nr < n and 0 <= nc < n:
                            neighbor_id = grid[nr][nc]

                            if neighbor_id > 1:
                                neighboring_islands.add(neighbor_id)

                    for neighbor_id in neighboring_islands:
                        current_size += island_size[neighbor_id]

                    max_island = max(max_island, current_size)

        return max_island
```该解决方案首先扫描网格以定位所有现有岛屿。 

每当发现未处理的陆地单元时，DFS 函数都会探索完全连接的组件并使用当前岛屿 ID 重新标记其所有单元。 DFS 使用显式堆栈而不是递归来避免大型网格上的递归深度问题。 

每个岛屿的面积都存储在`island_size`字典，允许稍后进行恒定时间查找。 

预处理后，算法再次扫描网格寻找水细胞。 对于每个`0`，它检查四个相邻位置并将所有不同的相邻岛屿 ID 收集到一个集合中。 

这些岛屿的大小相加，`1`为翻转的单元格本身添加。 

该算法不断更新找到的最大岛屿尺寸并返回最终答案。 

## 解决方案```go
package main

func largestIsland(grid [][]int) int {
	n := len(grid)

	directions := [][]int{
		{1, 0},
		{-1, 0},
		{0, 1},
		{0, -1},
	}

	islandSize := make(map[int]int)
	islandID := 2

	var dfs func(int, int, int) int

	dfs = func(r int, c int, id int) int {
		stack := [][]int{{r, c}}
		grid[r][c] = id
		area := 1

		for len(stack) > 0 {
			last := len(stack) - 1
			cell := stack[last]
			stack = stack[:last]

			row := cell[0]
			col := cell[1]

			for _, d := range directions {
				nr := row + d[0]
				nc := col + d[1]

				if nr >= 0 && nr < n && nc >= 0 && nc < n && grid[nr][nc] == 1 {
					grid[nr][nc] = id
					area++
					stack = append(stack, []int{nr, nc})
				}
			}
		}

		return area
	}

	maxIsland := 0

	for r := 0; r < n; r++ {
		for c := 0; c < n; c++ {
			if grid[r][c] == 1 {
				area := dfs(r, c, islandID)
				islandSize[islandID] = area

				if area > maxIsland {
					maxIsland = area
				}

				islandID++
			}
		}
	}

	for r := 0; r < n; r++ {
		for c := 0; c < n; c++ {
			if grid[r][c] == 0 {
				seen := make(map[int]bool)
				currentSize := 1

				for _, d := range directions {
					nr := r + d[0]
					nc := c + d[1]

					if nr >= 0 && nr < n && nc >= 0 && nc < n {
						neighborID := grid[nr][nc]

						if neighborID > 1 && !seen[neighborID] {
							seen[neighborID] = true
							currentSize += islandSize[neighborID]
						}
					}
				}

				if currentSize > maxIsland {
					maxIsland = currentSize
				}
			}
		}
	}

	return maxIsland
}
```Go 的实现与 Python 解决方案非常相似。 

Go 没有使用 Python 集合，而是使用`map[int]bool`追踪哪些邻近岛屿已被统计在内。 

DFS 使用显式的基于切片的堆栈来避免递归深度限制。 

Go 切片在堆栈操作期间动态调整大小，从而方便迭代 DFS 遍历。 

由于最大可能的岛屿大小最多为`250,000`，标准 Go 整数是完全足够的，溢出不是问题。

 ## 边缘情况

 ### 网格仅包含土地

 如果网格已经完全填满`1`s，没有有效的`0`翻转。 有错误的实现可能会错误地返回`0`或者无法处理这种情况。 

此实现可以正确处理它，因为预处理阶段计算现有岛屿的大小并立即存储最大岛屿大小。 即使第二遍从未找到`0`，正确的最大值已经存在。 

### 网格仅包含水

 如果每个细胞都是`0`，则不存在现有岛屿。 

简单的实现可能会失败，因为没有可供参考的岛 ID 或岛大小。 

这个解决方案很自然地处理了这个问题。 每个零单元格的计算结果为：```
1
```因为翻转单个细胞会形成一个单细胞岛。 

### 零多次接触同一个岛屿

 考虑：```
[
  [1,1],
  [1,0]
]
```右下角的零从顶部和左侧接触同一个岛。 

如果没有重复数据删除，岛的大小将被错误地计算两次。 

此实现在求和区域之前使用一组相邻岛屿 ID，保证每个岛屿仅贡献一次。 

### 大型连接组件

 与`n = 500`，在某些语言中，递归 DFS 可能会超出递归限制。 

此实现使用具有显式堆栈的迭代 DFS，避免了堆栈溢出问题，同时仍然有效地探索岛屿。
