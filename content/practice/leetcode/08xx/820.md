[LeetCode 820 题](https://leetcode.com/problems/short-encoding-of-words/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、Trie

 ## 解决方案

 ## 问题理解

 该问题要求我们找到可以对单词列表进行编码的**最短参考字符串**的长度。 参考字符串是通过将一些单词与`'#'`每个单词末尾的字符。 重要的是，如果一个单词作为另一个单词的**后缀**出现，则它可以由参考字符串的子字符串表示。 

例如，如果我们有`["time", "me", "bell"]`，这个词`"me"`是一个后缀`"time"`，因此不需要单独包含。 有效编码`"time#bell#"`涵盖所有单词，因为`"time"`和`"bell"`直接在字符串中，并且`"me"`可以作为子串找到`"time"[2:]`。 

输入是一个单词数组，其中每个单词的长度最多为 7，并且最多可以有 2000 个单词。 这足够小，可以有效地考虑使用尝试或集合的解决方案。 关键点是单词都是小写的，并且可以有重叠的后缀。 

边缘情况包括单个单词、相同的单词或完全是其他单词的后缀。 例如，`["a", "aa", "aaa"]`需要小心处理以避免重复计算。 

## 方法

 ### 蛮力

 蛮力方法会尝试所有可能的单词连接顺序`'#'`然后检查每个单词是否是在 a 之前结尾的子串`'#'`。 虽然这最终可以找到最短的参考字符串，但排列的数量随着单词的数量呈阶乘增长（`O(n!)`），使其不可行`n = 2000`。 

### 最佳方法

 关键的观察是，如果某个单词**不是另一个单词的后缀**，则只需在参考字符串中显式包含**该单词即可。 这意味着我们可以专注于删除作为其他单词后缀的单词。 

一种有效的方法是使用**所有单词的集合**。 对于每个单词，我们从集合中删除它的所有后缀（除了它本身）。 最后，只保留不属于任何其他单词后缀的单词，总编码长度为它们的长度之和加一`'#'`每个字。 

或者，我们可以使用基于反向单词构建的 **Trie**。 以 Trie 的叶节点结尾的单词必须包含在编码中。 该方法可扩展性良好，并且实施起来很干净。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 尝试所有串联，对于 n=2000 来说不切实际 |
 | 后缀集 / Trie | O(n * k^2) | O(n * k^2) | O(n * k) | 删除后缀或使用反向 Trie 查找必要的单词 |

 ## 算法演练

 1. 初始化一个包含所有单词的集合。 
2. 迭代列表中的每个单词。 
3. 对于每个单词，生成所有可能的非空后缀（不包括单词本身）并将其从集合中删除。 

这可确保仅保留不是其他单词后缀的单词。 
4. 处理完所有单词后，集合中剩余的每个单词都必须出现在编码中。 
5、最短参考串长度为剩余单词长度之和加一`'#'`每个字。 
6. 返回总长度。 

**为什么有效：** 通过删除所有作为另一个单词后缀的单词，我们保证没有单词被冗余编码。 每个剩余的单词对最终编码只贡献一次，确保最小长度。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumLengthEncoding(self, words: List[str]) -> int:
        unique_words = set(words)
        for word in words:
            for k in range(1, len(word)):
                suffix = word[k:]
                if suffix in unique_words:
                    unique_words.discard(suffix)
        return sum(len(word) + 1 for word in unique_words)
```**说明：**

 我们首先创建一组所有单词，以允许 O(1) 删除后缀。 对于每个单词，我们生成所有可能的后缀，并将其从集合中删除（如果存在）。 最后，我们将剩余单词的长度加一`'#'`每个单词的字符以获得最小编码长度。 

## 解决方案```go
func minimumLengthEncoding(words []string) int {
    uniqueWords := make(map[string]struct{})
    for _, word := range words {
        uniqueWords[word] = struct{}{}
    }

    for _, word := range words {
        for k := 1; k < len(word); k++ {
            suffix := word[k:]
            delete(uniqueWords, suffix)
        }
    }

    total := 0
    for word := range uniqueWords {
        total += len(word) + 1
    }
    return total
}
```**说明：**

 在 Go 中，我们使用`map[string]struct{}`来表示唯一单词的集合。 对于每个单词，我们从地图中删除其所有后缀。 最后，我们迭代剩余的单词并将它们的长度加一`'#'`得到结果。

 ## 边缘情况

 一种重要的边缘情况是当单个字符单词与以相同字符结尾的较长单词同时存在时，例如，`["a", "ba"]`。 单个字符`"a"`应删除，因为它是后缀`"ba"`。 

另一个边缘情况是多个相同的单词。 该算法必须使用一组正确处理重复项，确保每个单词仅对编码长度贡献一次。 

最后，完全嵌套的后缀链，例如`["a", "aa", "aaa", "aaaa"]`必须进行处理，以便仅包含本身不是后缀的最长单词，以确保最小的编码长度。
