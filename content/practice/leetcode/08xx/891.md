 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组的所有非空子序列的**宽度**之和`nums`。 子序列是通过从原始数组中删除零个或多个元素同时保持顺序而导出的任何序列。 序列的**宽度**定义为其最大元素和最小元素之间的差。 

输入`nums`是一个有约束的整数数组`1 <= nums.length <= 10^5`和`1 <= nums[i] <= 10^5`。 输出是所有非空子序列的宽度模的总和`10^9 + 7`。 由于子序列的数量呈指数增长 (2^n)，因此对于大型输入来说，显式生成每个子序列的简单方法是不可行的。 

关键边缘情况包括长度为 1 的数组（其中所有子序列的宽度为 0）、具有重复元素的数组以及已排序的数组。 该问题保证非空输入和正整数，从而简化了负数或空情况的处理。 

## 方法

 ### 蛮力方法

 暴力解决方案将生成所有可能的非空子序列`nums`，计算每个的最大值和最小值，然后总结差异。 这种方法在逻辑上是正确的，但不切实际，因为生成所有子序列的时间复杂度为 O(2^n)，这对于 n 高达 10^5 来说太慢了。 

### 最佳方法

 最佳解决方案的关键观察是每个元素作为最大值或最小值对多个子序列做出贡献。 如果我们对数组进行排序，我们可以计算一个元素贡献的子序列的最大数量和最小数量。 具体来说，对于排序数组：

 -`nums[i]`是**最大值**`2^i`通过选择其前面的元素的任意组合而形成的子序列。 
-`nums[i]`是 **最小值**`2^(n-1-i)`通过选择其后元素的任意组合而形成的子序列。 

因此，总贡献为`nums[i]`宽度之和为：```
nums[i] * (2^i - 2^(n-1-i))
```我们将所有元素的这些贡献相加并取模`10^9 + 7`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(2^n * n) | O(2^n * n) | 显式生成所有子序列，对于 n ~ 10^5 不切实际 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 使用排序和预先计算的 2 次幂，对于大型数组非常高效 |

 ## 算法演练

 1. 对数组进行排序`nums`按升序排列。 排序可确保较低索引的元素小于较高索引的元素。 
2. 预先计算 2 模的幂`10^9 + 7`对于从 0 到 n-1 的索引。 这允许快速计算每个元素的贡献。 
3. 初始化变量`total`累加宽度的总和。 
4. 按索引迭代数组`i`:

 - 计算子序列的数量，其中`nums[i]`是最大值：`2^i`。 
- 计算子序列的数量，其中`nums[i]`是最小值：`2^(n-1-i)`。 
- 更新`total`通过添加差值乘以`nums[i]`模数`10^9 + 7`。 
5. 返回`total`模数`10^9 + 7`。 

**为什么起作用：** 每个元素对子序列宽度的贡献可以分为其作为最大值或最小值的角色。 排序可确保我们准确地了解这些贡献，而无需生成子序列。 对所有元素求和即可得出所有子序列。 

## Python 解决方案```python
from typing import List

class Solution:
    def sumSubseqWidths(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        nums.sort()
        
        # Precompute powers of 2 modulo MOD
        pow2 = [1] * n
        for i in range(1, n):
            pow2[i] = (pow2[i-1] * 2) % MOD
        
        total = 0
        for i in range(n):
            total = (total + nums[i] * (pow2[i] - pow2[n-1-i])) % MOD
        
        return total
```**说明：** 我们首先对数组进行排序以建立顺序。 这`pow2`数组存储 2 模的幂`10^9 + 7`用于快速计算。 对于每个元素，我们计算其净贡献为`maximum - minimum`跨越它参与的所有子序列。模数确保不会出现整数溢出。 

## 解决方案```go
func sumSubseqWidths(nums []int) int {
    const MOD = 1_000_000_007
    n := len(nums)
    
    // Sort the array
    sort.Ints(nums)
    
    // Precompute powers of 2 modulo MOD
    pow2 := make([]int, n)
    pow2[0] = 1
    for i := 1; i < n; i++ {
        pow2[i] = (pow2[i-1] * 2) % MOD
    }
    
    total := 0
    for i := 0; i < n; i++ {
        contribution := ((pow2[i] - pow2[n-1-i]) * nums[i]) % MOD
        total = (total + contribution + MOD) % MOD // handle negative
    }
    
    return total
}
```**Go 特定说明：** Go 需要处理负模结果，因此`+ MOD`在最终模数之前。`sort.Ints`用于排序，切片用于动态数组。 在每一步中使用模数可以避免溢出。

 ## 边缘情况

 第一个边缘情况是具有单个元素的数组。 由于只有一个子序列`[x]`，其宽度为 0。我们的算法正确处理了这个问题，因为`pow2[0] - pow2[0] = 0`。 

第二个边缘情况是所有元素都相等的数组。 任何子序列的宽度都是 0，我们的公式自然可以计算`nums[i] * (2^i - 2^(n-1-i)) = 0`对于每个元素。 

第三种边缘情况是接近上限约束的大型数组（长度 10^5）。 显式生成子序列是不可能的，但预计算能力和使用排序数组方法可确保算法高效运行而不会出现内存问题。 模数
