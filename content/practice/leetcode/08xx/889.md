[LeetCode 第 889 题](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-postorder-traversal/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、分而治之、树、二叉树

 ## 解决方案

 ## 问题理解

 该问题给出了同一二叉树的两个遍历顺序：

 -`preorder`，按以下顺序访问节点：

 根→左子树→右子树
 -`postorder`，按以下顺序访问节点：

 左子树→右子树→根

 我们的任务是重建并返回产生这些遍历的二叉树。 

一个重要的细节是所有节点值都是不同的。 这很重要，因为它允许我们根据节点值唯一地标识子树的开始和结束位置。 如果没有明确的价值观，重建就会变得模糊。 

该问题还指出，如果存在多个有效树，我们可能会返回其中任何一个。 这很重要，因为单独的前序和后序遍历并不总是唯一地确定二叉树。 例如，如果一个节点只有一个子节点，我们无法仅通过这些遍历来确定该子节点是左子节点还是右子节点。 该问题接受任何有效的重建。 

限制相对较小：

 -`1 <= n <= 30`- 所有值都是唯一的
 - 两个数组都是同一棵树的有效遍历

 尽管输入大小足够小，效率较低的解决方案可以通过，但问题本质上是关于理解遍历属性和递归树构造。 

一些边缘情况很重要：

 - 一棵只有一个节点的树。 
- 一棵倾斜的树，其中每个节点只有一个子节点。 
- 一棵完美平衡的树。 
- 子树变空的递归边界条件。 
- 从遍历边界正确识别子树大小。 

当切片遍历范围或错误地确定子树边界时，幼稚的实现很容易犯下相差一的错误。 

## 方法

 ### 蛮力方法

 蛮力策略将尝试递归地尝试所有可能的方法将遍历分为左子树和右子树。 

前序遍历总是从根开始，而后序遍历总是以根结束。 然而，如果没有额外的信息，我们最初不知道有多少节点属于左子树和右子树。 

强力解决方案可以尝试所有可能的子树大小，递归地验证生成的遍历是否匹配，并在找到后返回有效的树。 

这是可行的，因为最终一个分区将对应于一个有效的树结构。 然而，可能的分区数量呈指数增长，使得这种方法对于较大的输入来说不切实际。 

### 最优递归分而治之方法

 关键的观察是遍历属性使我们能够有效地确定子树边界。 

在前序遍历中：```
[root][left subtree][right subtree]
```在后序遍历中：```
[left subtree][right subtree][root]
```从预序识别出根后，假设左子树存在，下一个预序值必须是左子树的根。 

如果我们知道左子树根值，我们可以在后序遍历中找到它。 包含该值之前的所有内容都属于左子树。 这立即给出了左子树的大小。 

一旦我们知道了子树的大小，我们就可以递归地构造：

 - 左子树
 - 右子树

 哈希图允许在后序遍历中恒定时间查找节点位置，从而将整体复杂性降低到线性时间。

 ## 算法演练

 ### 最优递归构造

 1. 从当前预订范围的第一个元素开始。 

在前序遍历中，第一个元素始终是当前子树的根。 使用该值创建一个树节点。 
2. 处理基本情况。 

如果当前子树范围仅包含一个节点，则立即返回该节点。 这可以防止不必要的递归。 
3. 确定左子树根。 

在先序遍历根之后，如果存在左子树，则下一个元素必须属于左子树。 

例如：```
preorder = [1, 2, 4, 5, 3, 6, 7]
            ^
            root
               ^
               left subtree root
```4、后序遍历求左子树边界。 

使用哈希映射存储：```
value -> index in postorder
```这让我们可以立即在后序遍历中找到左子树根。 
5. 计算左子树大小。 

在后序遍历中，直到左子树根的所有节点都属于左子树。 

例子：```
postorder = [4, 5, 2, 6, 7, 3, 1]
                     ^
               left subtree root
```左子树大小：```
left_size = left_root_index - post_left + 1
```6. 递归构建左子树。 

使用计算出的子树大小来确定正确的前序和后序范围。 
7. 递归构建右子树。 

左子树之后剩余的所有内容都属于右子树。 
8. 返回构建的根节点。 

### 为什么它有效

 该算法依赖于两个遍历不变量：

 - 预购总是首先揭示根源
 - 后序总是显示子树完成顺序

 通过将下一个前序值作为左子树根并在后序遍历中定位，我们可以精确地确定子树边界。 每个递归调用都适用于较小的有效遍历范围，确保正确重建整个树。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def constructFromPrePost(
        self,
        preorder: List[int],
        postorder: List[int]
    ) -> Optional[TreeNode]:

        post_index = {
            value: idx for idx, value in enumerate(postorder)
        }

        def build(
            pre_left: int,
            pre_right: int,
            post_left: int,
            post_right: int
        ) -> Optional[TreeNode]:

            if pre_left > pre_right:
                return None

            root = TreeNode(preorder[pre_left])

            if pre_left == pre_right:
                return root

            left_root_value = preorder[pre_left + 1]
            left_root_index = post_index[left_root_value]

            left_subtree_size = left_root_index - post_left + 1

            root.left = build(
                pre_left + 1,
                pre_left + left_subtree_size,
                post_left,
                left_root_index
            )

            root.right = build(
                pre_left + left_subtree_size + 1,
                pre_right,
                left_root_index + 1,
                post_right - 1
            )

            return root

        return build(
            0,
            len(preorder) - 1,
            0,
            len(postorder) - 1
        )
```该解决方案首先在后序遍历中构建从节点值到其索引的哈希映射。 这避免了在递归调用期间重复扫描数组。 

这`build`函数使用索引边界而不是切片数组来重建子树。 这很重要，因为切片会创建额外的副本并增加内存开销。 

第一个预序元素始终被选为子树根。 

如果子树仅包含一个节点，则该函数立即返回该节点。 这是递归基本情况。 

否则，算法从以下位置识别左子树根：`preorder[pre_left + 1]`。 使用哈希图，在后序遍历中定位该节点并计算子树大小。 

然后，递归使用仔细计算的索引范围构造左子树和右子树。 

最后，返回根节点及其附加子树。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func constructFromPrePost(preorder []int, postorder []int) *TreeNode {
    postIndex := make(map[int]int)

    for i, val := range postorder {
        postIndex[val] = i
    }

    var build func(
        int,
        int,
        int,
        int,
    ) *TreeNode

    build = func(
        preLeft int,
        preRight int,
        postLeft int,
        postRight int,
    ) *TreeNode {

        if preLeft > preRight {
            return nil
        }

        root := &TreeNode{
            Val: preorder[preLeft],
        }

        if preLeft == preRight {
            return root
        }

        leftRootValue := preorder[preLeft+1]
        leftRootIndex := postIndex[leftRootValue]

        leftSubtreeSize := leftRootIndex - postLeft + 1

        root.Left = build(
            preLeft+1,
            preLeft+leftSubtreeSize,
            postLeft,
            leftRootIndex,
        )

        root.Right = build(
            preLeft+leftSubtreeSize+1,
            preRight,
            leftRootIndex+1,
            postRight-1,
        )

        return root
    }

    return build(
        0,
        len(preorder)-1,
        0,
        len(postorder)-1,
    )
}
```Go 实现遵循与 Python 版本相同的递归逻辑。 

主要的语言特定差异是 Go 使用指针作为树节点，因此子树分配使用`*TreeNode`。 

Go 还要求递归匿名函数显式函数变量声明。 因此，递归助手首先声明，然后分配。 

与 Python 不同，Go 没有`None`， 所以`nil`对于空子树返回。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点被处理一次 |

 ## 边缘情况

 ### 单节点树

 当输入仅包含一个节点时，前序和后序是相同的。 一个常见的错误是不必要地继续递归并访问无效索引，例如`pre_left + 1`。 

该实现通过检查来防止这种情况：```
if pre_left == pre_right:
    return root
```这会立即终止叶节点的递归。 

### 倾斜的树

 当每个节点只有一个子节点时，就会出现一棵倾斜树。 在这种情况下，前序和后序遍历并不能唯一地确定孩子是左孩子还是右孩子。 

该问题明确允许返回任何有效的树。 该实现始终将子级构造为左子树的一部分，因为它始终将下一个预序值视为左子树根。 

这保证了有效的重建。 

### 空递归范围

 在递归细分期间，子树范围可能会变得无效：```
pre_left > pre_right
```如果不处理这种情况，递归将尝试无效的数组访问。 

实现安全返回`None`或者`nil`对于空范围：```
if pre_left > pre_right:
    return None
```这会正确终止递归并在适当的情况下附加空子指针。
