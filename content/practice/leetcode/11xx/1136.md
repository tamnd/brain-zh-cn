[LeetCode 第 1136 题](https://leetcode.com/problems/parallel-courses/)

 **难度：** 🟡 中等
 **主题：** 图论、拓扑排序

 ## 解决方案

 ## 问题理解

 问题是要求我们确定完成课程所需的最少学期数`n`课程给出了一组先决关系。 每门课程都标记为`1`到`n`，并且先决条件成对描述`[prevCourse, nextCourse]`在`relations`数组，意义`prevCourse`必须在之前完成`nextCourse`。 在一个学期内，您可以选修任意数量的课程，前提是所有课程的先决条件已在前几个学期完成。 

输入由课程数量组成`n`以及先决条件对的列表。 输出是一个整数，表示完成所有课程所需的最短学期。 如果由于循环依赖而不可能，该函数应该返回`-1`。 

约束告诉我们`n`最多可以达到 5000 个，并且关系的数量也最多可达 5000 个。这排除了指数级的解决方案`n`或者需要遍历课程的所有排列，因为这些在计算上是不可行的。 每对都是唯一的并且不包含自我依赖性。 

重要的边缘情况包括图中的循环、没有先决条件的课程以及断开的子图（相互不依赖的课程）。 该问题保证了有效的课程标签和唯一的先决条件对，因此我们不需要处理无效的输入。 

## 方法

 暴力方法将通过生成所有课程排列并检查它们是否满足先决条件来尝试所有可能的学期序列。 这保证了正确性，因为它探索了每一个可能的顺序，但对于`n = 5000`因为排列的数量呈阶乘增长。 

最佳解决方案的关键观察是，该问题可以建模为有向无环图 (DAG)，其中节点是路线，边是先决条件。 计算最短学期相当于在 DAG 中找到**最长的路径长度**，因为依赖于其他课程的课程必须在它们之后进行。 这自然会导致**拓扑排序**方法。 通过按依赖性顺序处理课程并统计学期数，我们可以有效地找到最小学期数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 生成所有课程订单并检查先决条件，这对于大 n 来说是不可行的 |
 | 最佳 | O(n + m) | O(n + m) | 使用 BFS（卡恩算法）进行拓扑排序来计算学期，可扩展到给定的约束 |

 ## 算法演练

 1. 使用邻接列表构建图形表示，其中每个课程映射到依赖于它的课程列表。 维护一个数组`in_degree`跟踪每门课程的先决条件数量。 
2. 初始化具有零先决条件（入度 0）的课程的队列。 这些课程可以在第一学期学习。 
3. 初始化计数器`semester = 0`。 当队列不空时，增加学期。 对于当前学期的每门课程，将其从图表中删除并减少其相关课程的入度。 如果相关课程的学位为零，则将其添加到下学期的队列中。 
4. 跟踪处理的课程数量。 BFS 完成后，如果所有课程均已处理，则返回学期计数。 否则，如果还有课程未处理，则说明是一个循环，所以返回`-1`。 

工作原理：BFS 拓扑排序确保只有在完成所有先决条件后才能学习课程。 每个 BFS 级别代表一个学期，因此计算级别即可得出最小学期数。 入度数组保证在其先决条件之前不会处理任何课程，从而防止无效序列。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def minimumSemesters(self, n: int, relations: List[List[int]]) -> int:
        graph = [[] for _ in range(n + 1)]
        in_degree = [0] * (n + 1)

        for prev_course, next_course in relations:
            graph[prev_course].append(next_course)
            in_degree[next_course] += 1

        queue = deque(course for course in range(1, n + 1) if in_degree[course] == 0)
        semester = 0
        processed = 0

        while queue:
            semester += 1
            for _ in range(len(queue)):
                course = queue.popleft()
                processed += 1
                for neighbor in graph[course]:
                    in_degree[neighbor] -= 1
                    if in_degree[neighbor] == 0:
                        queue.append(neighbor)

        return semester if processed == n else -1
```此代码构造邻接列表和入度数组，用具有零先决条件的课程初始化 BFS 队列，并将每个级别作为一个学期处理。 它确保只有满足所有先决条件后才能学习课程。 如果存在循环，则处理的课程数将小于`n`， 和`-1`被返回。 

## 解决方案```go
package main

func minimumSemesters(n int, relations [][]int) int {
    graph := make([][]int, n+1)
    inDegree := make([]int, n+1)
    
    for _, rel := range relations {
        prev, next := rel[0], rel[1]
        graph[prev] = append(graph[prev], next)
        inDegree[next]++
    }
    
    queue := []int{}
    for i := 1; i <= n; i++ {
        if inDegree[i] == 0 {
            queue = append(queue, i)
        }
    }
    
    semester := 0
    processed := 0
    
    for len(queue) > 0 {
        semester++
        size := len(queue)
        nextQueue := []int{}
        for i := 0; i < size; i++ {
            course := queue[i]
            processed++
            for _, neighbor := range graph[course] {
                inDegree[neighbor]--
                if inDegree[neighbor] == 0 {
                    nextQueue = append(nextQueue, neighbor)
                }
            }
        }
        queue = nextQueue
    }
    
    if processed == n {
        return semester
    }
    return -1
}
```Go 解决方案使用切片而不是双端队列来反映 Python 逻辑。 我们通过创建一个来仔细跟踪 BFS 队列`nextQueue`以避免在迭代时修改切片。 

## 工作示例

 **示例1：`n = 3, relations = [[1,3],[2,3]]`**

 | 学期 | 队列| 加工课程 | 笔记|
 | ---| ---| ---| ---|
 | 1 | [1,2]| 2 | 课程 1 和 2 没有先决条件 |
 | 2 | [3] | 3 | 课程 3 在课程 1 和 2 完成后可用 |

 返回`2`学期。 

**示例2：`n = 3, relations = [[1,2],[2,3],[3,1]]`**

 队列开始为空，因为由于循环，所有课程的入度 > 0。`processed = 0 < 3`，所以返回`-1`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + m) | 我们在 BFS 期间访问每条路线一次并处理每条边一次 |
 | 空间| O(n + m) | 邻接表存储所有边，入度数组存储n个值，队列最多可存储n个路线|

 BFS 拓扑排序相对于节点和边是线性的，这使得它对于给定的约束非常有效。

 ## 边缘情况

 关键的边缘情况是**图中的循环**。 如果存在循环，则无法进行拓扑排序，并且在处理所有课程之前，BFS 队列将变空。 算法正确返回`-1`在这种情况下。 

另一个边缘情况是**独立课程**。 如果多门课程没有先决条件，则可以在同一学期内全部修读。 我们的 BFS 实现自然地通过初始化队列来处理这个问题，其中所有课程的入度都为零。 

最后的边缘情况是**先决条件的线性链**。 如果每门课程都依赖于前一门课程，则每门课程必须在单独的学期内修读。 BFS 正确增加学期
