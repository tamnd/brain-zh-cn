[LeetCode 第 1101 题](https://leetcode.com/problems/the-earliest-moment-when-everyone-become-friends/)

 **难度：** 🟡 中等
 **主题：** 数组、并查、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们确定一组`n`通过一系列带有时间戳的友谊形成事件，人们都会相互熟悉。 每场活动`[timestamp, xi, yi]`表示那个人`xi`和人`yi`在那一刻成为朋友。 友谊是对称的，也就是说如果`xi`是朋友`yi`， 然后`yi`是朋友`xi`。 此外，友谊在这个问题中是传递的：如果`xi`是朋友`yi`和`yi`是朋友`zi`， 然后`xi`和`zi`也算是认识了。 

输入由一个列表组成`logs`长度可达`10^4`，其中每个元素都是一个三元组，代表一个时间戳和两个不同的人形成的友谊。 时间戳是唯一的，范围可达`10^9`。 输出应该是所有的最小时间戳`n`人们通过直接或间接的友谊相互联系。 如果不存在这样的时间戳，我们返回`-1`。 

限制因素的主要见解包括：`n`相对较小（`n <= 100`）但事件数量可能很大（`logs.length <= 10^4`）。 这表明能够有效合并组的数据结构（如并查）是合适的。 时间戳的唯一性简化了排序，因为按时间戳对事件进行排序非常简单。 

重要的边缘情况包括以下场景：`n`人们永远不会完全联系在一起，或者当事件稀疏或有序，以致多个不相交的群体长期存在时。 

## 方法

 暴力方法涉及使用邻接列表或矩阵来模拟友谊，并在每次友谊事件后重复检查所有对之间的连接性。 虽然这保证了正确性，但在每个事件之后检查完整连接需要`O(n^2)`每个事件的时间，导致总的复杂性`O(n^2 * m)`在哪里`m`是日志的数量。 为了`n = 100`和`m = 10^4`，这变得太慢了。 

最佳方法使用 Union-Find（不相交集并集）数据结构。 每个人都是从自己的群体开始的，每段友谊都会融合两个人所在的群体。 我们维护存在多少不相交集合的计数。 当这个计数达到`1`，所有人都是有联系的，当前时间戳是大家最早成为好友的时间。 这避免了重复的 O(n^2) 连接检查并大大减少了总运行时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * m) | O(n^2 * m) | O(n^2) | O(n^2) | 使用邻接矩阵/列表检查每个事件后的完整连接 |
 | 最佳 | O(m log m + m α(n)) | O(m log m + m α(n)) | O(n) | 对日志进行排序并使用 Union-Find 进行路径压缩并按等级并集，α(n) 是逆阿克曼函数 |

 ## 算法演练

 1. **对日志进行排序**：按照时间戳升序对好友事件进行排序。 这确保我们按时间顺序处理友谊。 
2. **初始化并查**：创建并查结构`n`元素。 每个人最初都属于自己的群体。 最初维护一个连接组件数量的计数器`n`。 
3. **处理事件**：迭代排序的日志。 为了每一份友谊`[timestamp, xi, yi]`，执行并集运算`xi`和`yi`。 
4. **检查连通性**：每次并集后，检查连通分量的数量是否变为`1`。 如果有，则返回当前时间戳，因为这是所有人连接的最早时刻。 
5. **无完整连接**：如果处理完所有日志后，连接的组件数大于`1`， 返回`-1`因为并不是每个人都成为朋友。 

**为什么有效**：Union-Find 保持了不变式，即每个集合代表一组相互熟悉的人。 通过计算连接组件的数量，我们可以有效地检测所有人何时互连，而无需重复检查所有对。 

## Python 解决方案```python
from typing import List

class UnionFind:
    def __init__(self, size: int):
        self.parent = list(range(size))
        self.rank = [0] * size
        self.components = size

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        rootX = self.find(x)
        rootY = self.find(y)
        if rootX == rootY:
            return False
        if self.rank[rootX] > self.rank[rootY]:
            self.parent[rootY] = rootX
        elif self.rank[rootX] < self.rank[rootY]:
            self.parent[rootX] = rootY
        else:
            self.parent[rootY] = rootX
            self.rank[rootX] += 1
        self.components -= 1
        return True

class Solution:
    def earliestAcq(self, logs: List[List[int]], n: int) -> int:
        logs.sort(key=lambda x: x[0])
        uf = UnionFind(n)
        for timestamp, x, y in logs:
            uf.union(x, y)
            if uf.components == 1:
                return timestamp
        return -1
```这`UnionFind`类可以有效地处理分组。 这`find`方法应用路径压缩来展平结构，同时`union`按等级合并两个集合以使树保持浅。 这`components`计数器跟踪单独组的数量，允许在每次联合后立即检查完整连接。 

## 解决方案```go
package main

import (
    "sort"
)

type UnionFind struct {
    parent     []int
    rank       []int
    components int
}

func NewUnionFind(size int) *UnionFind {
    parent := make([]int, size)
    rank := make([]int, size)
    for i := 0; i < size; i++ {
        parent[i] = i
    }
    return &UnionFind{parent, rank, size}
}

func (uf *UnionFind) Find(x int) int {
    if uf.parent[x] != x {
        uf.parent[x] = uf.Find(uf.parent[x])
    }
    return uf.parent[x]
}

func (uf *UnionFind) Union(x, y int) bool {
    rootX := uf.Find(x)
    rootY := uf.Find(y)
    if rootX == rootY {
        return false
    }
    if uf.rank[rootX] > uf.rank[rootY] {
        uf.parent[rootY] = rootX
    } else if uf.rank[rootX] < uf.rank[rootY] {
        uf.parent[rootX] = rootY
    } else {
        uf.parent[rootY] = rootX
        uf.rank[rootX]++
    }
    uf.components--
    return true
}

func earliestAcq(logs [][]int, n int) int {
    sort.Slice(logs, func(i, j int) bool {
        return logs[i][0] < logs[j][0]
    })
    uf := NewUnionFind(n)
    for _, log := range logs {
        timestamp, x, y := log[0], log[1], log[2]
        uf.Union(x, y)
        if uf.components == 1 {
            return timestamp
        }
    }
    return -1
}
```在 Go 中，切片和整数运算非常简单。 与 Python 的主要区别在于手动切片管理和显式构造函数的使用。 零切片在这里不是问题，因为我们用`make`。
