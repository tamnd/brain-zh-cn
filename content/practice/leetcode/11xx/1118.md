[LeetCode 第 1118 题](https://leetcode.com/problems/number-of-days-in-a-month/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定年份的特定月份的天数。 输入是两个整数：`year`，范围从 1583 到 2100，并且`month`，范围从 1（1 月）到 12（12 月）。 输出是一个整数，表示该年该月的总天数。 

主要的复杂性来自二月，二月可能有 28 或 29 天，具体取决于该年是否是闰年。 当年份能被 4 整除时，即为闰年，能被 100 整除的年份除外，除非它们也能被 400 整除。这意味着 2000 年是闰年，1900 年不是闰年，1992 年是闰年。 

重要的边缘情况包括闰年 2 月、非闰年 2 月以及有 30 天或 31 天的月份。 该问题保证了有效的输入，因此我们不需要处理给定范围之外的无效月份或年份。 

## 方法

 一种强力方法是将每个月的天数存储在固定数组中，并根据年份是否为闰年动态调整二月。 这种方法是正确的并且非常有效，但是“强力”一词可能意味着整天迭代，这是不必要的。 关键的见解是每个月的天数是确定性的，可以通过简单的条件逻辑推导出二月的天数。 

最佳解决方案利用静态数组来计算标准月份长度，并仅对二月应用闰年计算。 这种方法在时间和空间恒定的情况下非常有效。

 ## 算法演练

 1. 定义一个由 12 个整数组成的数组，表示非闰年每月的天数。 一月有 31 个，二月有 28 个，三月有 31 个，依此类推。 
2. 检查给定月份是否为二月。 
3. 如果是二月，则使用以下规则确定该年份是否为闰年：能被 4 整除，不能被 100 整除，除非能被 400 整除。 
4. 如果是闰年，则返回29。否则，返回28。 
5. 对于所有其他月份，从月日数组中返回相应的值。 

为什么有效：除了二月之外，每个月都有固定的天数，这取决于闰年规则。 通过存储标准月份长度并根据明确定义的闰年规则调整二月，该算法可以正确计算任何有效输入的天数。 

## Python 解决方案```python
class Solution:
    def numberOfDays(self, year: int, month: int) -> int:
        month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        
        if month == 2:
            if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
                return 29
            else:
                return 28
        
        return month_days[month - 1]
```此实现首先定义非闰年中每个月的天数。 然后它检查二月并应用闰年计算。 对于所有其他月份，它只是简单地索引到预定义的数组中。 索引使用`month - 1`因为Python数组是从0开始索引的。 

## 解决方案```go
func numberOfDays(year int, month int) int {
    monthDays := [12]int{31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}
    
    if month == 2 {
        if (year%4 == 0 && year%100 != 0) || (year%400 == 0) {
            return 29
        } else {
            return 28
        }
    }
    
    return monthDays[month-1]
}
```在 Go 中，我们使用固定大小的数组来存储月日。 闰年检查与 Python 实现相同。 数组索引是从零开始的，所以我们访问`monthDays[month-1]`。 Go 不像 Python 那样需要类型提示，但逻辑在其他方面是相同的。 

## 工作示例

 示例1：`year = 1992, month = 7`7月有31天。 现在不是二月，所以我们回来了`monthDays[6] = 31`。 

示例2：`year = 2000, month = 2`闰年二月。`2000 % 4 == 0`,`2000 % 100 == 0`,`2000 % 400 == 0`。 闰年，返回 29。 

示例3：`year = 1900, month = 2`非闰年的二月。`1900 % 4 == 0`,`1900 % 100 == 0`,`1900 % 400 != 0`。 非闰年，返回 28。

 ## 边缘情况

 闰年二月：这是一个典型的错误来源。 如果闰年计算不正确，二月可能会错误地返回 28 天。 实现正确应用了可被 4 整除的规则，不能被 100 整除，除非能被 400 整除的规则。 

非闰年的百年年份中的二月：像 1900 年这样的年份可以被 100 整除，但不能被 400 整除，因此它们不是闰年。 简单的模 4 检查在这里会失败。 我们的代码明确地解释了这个异常。 

月份边界：具有 30 天和 31 天的月份需要在数组中正确索引。 使用`month - 1`从零开始的索引确保不会发生相差一的错误。 这涵盖了除二月之外的所有月份，二月是单独处理的。
