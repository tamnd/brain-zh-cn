[LeetCode 第 1105 题](https://leetcode.com/problems/filling-bookcase-shelves/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们在具有多个书架的书架上排列一系列书籍，同时最小化书架的总高度。 每本书都通过其厚度和高度进行描述，并且书籍必须按给定的顺序放置。 每个书架都有固定的宽度限制，单个书架上的书籍厚度之和不能超过这个宽度。 一旦书架被装满，它的高度就会影响书架的总高度，而书架的总高度由该书架上最高的书决定。 

输入由一个数组组成`books`在哪里`books[i] = [thickness, height]`和一个整数`shelfWidth`。 输出是一个整数，表示书架的最小可能总高度。 

约束表明`books.length`可以高达 1000，厚度和高度可以高达 1000，这意味着任何强力解决方案都必须仔细考虑效率。 重要的边缘情况包括具有最大可能厚度的书籍、单独等于书架宽度的书籍以及影响书架高度计算的不同高度的书​​籍。 该问题保证至少有一本书，因此我们不需要处理空输入数组。 

## 方法

 蛮力方法是尝试将所有可能的书籍划分到书架上。 对于每本书，我们可以启动一个新书架，或者在宽度允许的情况下将其添加到当前书架。 这保证了正确性，但对于大输入来说是不可行的，因为可能的分区数量随着书籍数量呈指数增长，导致 O(2^n) 时间复杂度。 

更有效的解决方案的关键是使用动态编程。 我们定义`dp[i]`作为排列第一个的最小总高度`i`图书。 计算`dp[i]`，我们考虑所有可能的先前位置`j < i`哪里的`j+1`到`i`书可以放在同一个书架上。 然后我们取所有此类分区的最小高度。 这种方法将问题从指数时间缩短为多项式时间，因为我们系统地计算所有子问题的解决方案并重用它们。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试各种货架隔板组合； 对于 n = 1000 不可​​行 |
 | 动态规划| O(n^2) | O(n^2) | O(n) | 使用 DP 逐步构建最小高度； 对于 n ≤ 1000 可行 |

 ## 算法演练

 1.初始化一个DP数组`dp`长度`n + 1`在哪里`dp[i]`表示第一个的最小总高度`i`图书。 放`dp[0] = 0`因为零本书需要零高度。 
2. 迭代每本书索引`i`从 1 到`n`。 对于每个`i`，我们尝试放置书籍`j`到`i-1`在当前货架上，`j`来自`i-1`降至 0。 
3. 维护变量`width`跟踪厚度和`height`跟踪当前书架上最高的书。 开始于`width = 0`和`height = 0`。 
4. 对于每位候选人`j`，添加厚度`books[j]`到`width`。 如果`width`超过`shelfWidth`，因为书架上放不下更多的书而破裂。 
5. 更新`height`为最大电流`height`和`books[j][1]`。 
6. 更新`dp[i]`作为其当前值的最小值和`dp[j] + height`，代表放置书籍`j`到`i-1`在当前货架上。 
7. 迭代完所有之后`i`， 返回`dp[n]`作为最小总书架高度。 

关键的不变量是`dp[i]`始终存储第一个的最小高度`i`书籍，确保当我们到达时`dp[n]`，我们已经考虑了所有有效的货架分区。 

## Python 解决方案```python
from typing import List

class Solution:
    def minHeightShelves(self, books: List[List[int]], shelfWidth: int) -> int:
        n = len(books)
        dp = [0] + [float('inf')] * n
        
        for i in range(1, n + 1):
            width = 0
            height = 0
            for j in range(i - 1, -1, -1):
                width += books[j][0]
                if width > shelfWidth:
                    break
                height = max(height, books[j][1])
                dp[i] = min(dp[i], dp[j] + height)
        
        return dp[n]
```Python 实现初始化一个 DP 数组并迭代每本书以计算最小总高度。 它考虑所有可能适合当前书架的先前书籍，并相应地更新 DP 阵列。 这确保了 O(n^2) 时间内的最优解决方案。 

## 解决方案```go
func minHeightShelves(books [][]int, shelfWidth int) int {
    n := len(books)
    dp := make([]int, n+1)
    for i := 1; i <= n; i++ {
        dp[i] = 1 << 60
    }

    for i := 1; i <= n; i++ {
        width := 0
        height := 0
        for j := i - 1; j >= 0; j-- {
            width += books[j][0]
            if width > shelfWidth {
                break
            }
            if books[j][1] > height {
                height = books[j][1]
            }
            if dp[j]+height < dp[i] {
                dp[i] = dp[j] + height
            }
        }
    }

    return dp[n]
}
```Go 实现遵循相同的 DP 逻辑。 我们初始化`dp`与大量进行比较，跟踪当前货架的宽度和高度，并相应地更新 DP 数组。 Go 可以高效地处理切片，并且在问题约束下整数溢出不是问题。
