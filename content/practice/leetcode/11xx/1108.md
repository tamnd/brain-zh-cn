 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们将有效的 IPv4 地址转换为其“被砍掉的”版本。 通过替换每个句点字符来创建经过修改的 IP 地址`"."`用字符串`"[.]"`。 

IPv4 地址由四个用句点分隔的数字段组成。 例如，`"1.1.1.1"`包含由三个句点分隔的四个数字。 所需的转换会更改每个分隔符，因此最终结果变为`"1[.]1[.]1[.]1"`。 

输入是一个名为`address`。 该问题保证该字符串已经是有效的 IPv4 地址，这意味着我们不需要执行验证检查，例如确保数字在范围内或确认格式。 我们唯一的任务就是更换每一个`"."`特点。 

预期输出是另一个字符串，其中所有句点都已被替换，而所有数字字符保持不变。 

限制条件故意很简单。 由于保证输入是有效的 IPv4 地址，因此字符串长度非常小并且结构固定。 有效的 IPv4 地址恰好包含三个句点和四个数字段。 因此，效率并不是这个特定问题的主要关注点，但讨论干净和最佳的字符串操作技术仍然很有用。 

一种重要的边缘情况是段包含多个数字的地址，例如`"255.100.50.0"`。 错误处理字符或不正确分割字符串的幼稚实现可能会意外更改数字部分。 另一个考虑因素是确保每个时期都被替换，而不仅仅是第一个时期。 输入有效的问题保证消除了对格式错误的字符串、空输入或丢失段的担忧。 

## 方法

 ### 蛮力方法

 解决这个问题的一个直接方法是迭代字符串中的每个字符并手动构造一个新的结果字符串。 

对于每个字符：

 - 如果字符是句点`"."`, 附加`"[.]"`到结果。 
- 否则，附加原始字符。 

这种方法是正确的，因为每个字符都被检查一次，并且每个句点都被替换为所需的子字符串。 

但是，如果使用重复的字符串连接来实现效率低下，那么在字符串不可变的语言中，它可能会变得比所需的速度慢。 每次连接都可能创建一个新字符串，从而导致不必要的复制工作。 

### 最佳方法

 关键的观察是这个问题只是一个全局字符串替换操作。 大多数现代语言都提供了优化的内置方法来替换子字符串。 

我们可以直接替换每个字符，而不是手动处理每个字符`"."`和`"[.]"`使用：

-`replace()`在Python中
 -`strings.ReplaceAll()`在围棋中

 这些库函数实现高效，使解决方案简洁易读。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 逐个字符迭代并构建一个新字符串 |
 | 最佳 | O(n) | O(n) | 使用内置字符串替换来实现更清晰的实现 |

 ## 算法演练

 ### 最优算法

 1.从输入字符串开始`address`。 
2. 搜索字符串中每次出现的句点字符`"."`。 
3. 将每个句点替换为子字符串`"[.]"`。 
4. 返回新构造的字符串。 

这样做的原因是这个问题只需要直接的字符替换。 无需解析或验证，因为输入保证已经是有效的 IPv4 地址。 

### 为什么它有效

 该算法之所以有效，是因为它保留了原始字符串中除句点之外的每个字符。 每个`"."`确定性地被替换为`"[.]"`，这与损坏的 IP 地址的问题定义完全匹配。 由于每个字符都被处理并且每个句点都被恰好替换一次，因此最终的字符串保证是正确的。 

## Python 解决方案```python
class Solution:
    def defangIPaddr(self, address: str) -> str:
        return address.replace(".", "[.]")
```该实现使用Python的内置`replace()`方法。 该方法扫描字符串并替换每次出现的`"."`和`"[.]"`。 

这直接匹配前面描述的算法：

 - 原始字符串用作输入。 
- 每个时期都会在全球范围内替换。 
- 返回转换后的字符串。 

因为Python字符串是不可变的，`replace()`创建并返回一个新字符串，而不是修改原始字符串。 

## 解决方案```go
package main

import "strings"

func defangIPaddr(address string) string {
    return strings.ReplaceAll(address, ".", "[.]")
}
```Go 解决方案使用`strings.ReplaceAll()`来自标准库。 此函数将每次出现的目标子字符串替换为替换子字符串。 

Go 特有的一个细节是字符串实用程序是通过`strings`包，因此必须显式导入。 与直接附加到字符串对象的 Python 方法不同，Go 使用包函数来执行这些操作。 

在此问题中，无需担心整数溢出、nil 处理或可变字符串行为，因为该操作纯粹是字符串替换。

 ## 边缘情况

 一个重要的边缘情况是每个段都是单个数字的地址，例如`"1.1.1.1"`。 这测试算法是否正确替换所有句点，而不会意外删除或重复数字。 该实现自然地处理了这个问题，因为它只针对`"."`人物。 

另一个重要的情况是具有大数字段的地址，例如`"255.255.255.255"`。 有缺陷的实现可能会错误地解析或操作数字本身。 由于我们的解决方案仅执行直接字符串替换，因此数字内容保持不变。 

第三种边缘情况涉及前导零，例如`"001.002.003.004"`。 一些尝试以数字方式解析地址的实现可能会在转换期间意外地去除零。 我们的实现完全避免了数字解析，因此除了替换的句点之外，所有字符都保持与原始字符串中显示的完全相同。
