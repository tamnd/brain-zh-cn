[LeetCode 第 1186 题](https://leetcode.com/problems/maximum-subarray-sum-with-one-deletion/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 问题是要求我们找到给定整数数组中**连续子数组**的最大总和，并且允许我们从该子数组中删除**至多一个元素**。 子数组必须保持非空，因此我们不能删除单元素子数组中的唯一元素。 

输入是一个整数数组`arr`，其中长度可达`10^5`和元素范围从`-10^4`到`10^4`。 输出是一个整数，表示从子数组中可获得的最大可能总和，其中可以选择删除一个元素。 

要记住的重要限制包括我们必须处理带有负数的数组、全部带有负数的数组以及同时带有正数和负数的数组。 数组大小很大意味着检查所有子数组的强力解决方案将太慢。 

边缘情况包括：

 1. 只有一个元素的数组。 在这里，我们无法删除该元素，因此最大和是该元素本身。 
2. 删除任何元素实际上会增加最大总和的数组。 
3. 所有元素均为负数的数组，在这种情况下，最大和将是单个最小负数。 

## 方法

 暴力方法是生成所有可能的子数组，并针对每个子数组，尝试单独删除每个元素以查看总和是否有所改善。 这种方法保证了正确性，因为它显式地检查每个选项，但它在计算上是不可行的，因为子数组的数量是 O(n^2) 并且尝试删除会进一步乘以这个数，对于大的情况给出大约 O(n^3) 时间复杂度`n`。 

最佳解决方案的关键见解来自**动态规划**。 我们可以维护两个数组（或两个变量以节省空间）：`forward`对于以给定索引结束且没有删除的最大子数组总和，以及`backward`对于以该索引结尾的最大子数组总和**最多删除一次**。 我们可以使用 Kadane 算法的变体一次计算这些数组。 

对于每个元素，我们要么继续前一个子数组，要么重新开始，对于删除情况，我们考虑删除当前元素或结转先前删除的子数组。 这将时间复杂度从 O(n^3) 降低到 O(n)，仅需要 O(n) 或 O(1) 额外空间（具体取决于实现）。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 检查所有子数组和所有删除 |
 | 最佳| O(n) | O(1) | O(1) | 使用 Kadane 扩展的两个变量动态规划 |

 ## 算法演练

 1.初始化两个变量，`max_end_here`和`max_end_here_deleted`。 第一个跟踪以当前索引结尾的子数组的最大和**不删除**，第二个跟踪以当前索引结尾的子数组的最大和**允许一次删除**。 另外，初始化`max_sum`与第一个元素。 
2. 从索引 1 开始迭代数组。 
3. 对于每个元素，更新`max_end_here_deleted`作为前一个的最大值`max_end_here`（即删除当前元素）或将当前元素添加到前一个元素`max_end_here_deleted`（即，继续删除已使用的一项）。 
4. 更新`max_end_here`使用标准 Kadane 方法：在当前元素处启动一个新子数组或扩展前一个子数组。 
5. 更新`max_sum`作为自身的最大值，`max_end_here`， 和`max_end_here_deleted`。 
6. 返回`max_sum`循环完成后。 

**为什么它有效：** 这里的不变量是`max_end_here`始终包含以当前索引结尾且没有任何删除的最大子数组总和，而`max_end_here_deleted`包含以当前索引结尾的最大子数组总和，其中最多删除一个元素。 通过迭代一次并仔细更新这些状态，我们确保每种可能的删除场景都被恰好考虑一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumSum(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 0:
            return 0

        max_end_here = arr[0]
        max_end_here_deleted = arr[0]
        max_sum = arr[0]

        for i in range(1, n):
            max_end_here_deleted = max(max_end_here, max_end_here_deleted + arr[i])
            max_end_here = max(arr[i], max_end_here + arr[i])
            max_sum = max(max_sum, max_end_here, max_end_here_deleted)

        return max_sum
```此实现初始化最大总和并迭代数组一次。 在每一步中，它都会计算删除和不删除的最佳子数组总和，并跟踪全局最大值。 它自动处理边缘情况，因为它使用第一个元素进行初始化，并确保始终考虑至少一个元素。 

## 解决方案```go
func maximumSum(arr []int) int {
    n := len(arr)
    if n == 0 {
        return 0
    }

    maxEndHere := arr[0]
    maxEndHereDeleted := arr[0]
    maxSum := arr[0]

    for i := 1; i < n; i++ {
        maxEndHereDeleted = max(maxEndHere, maxEndHereDeleted + arr[i])
        maxEndHere = max(arr[i], maxEndHere + arr[i])
        maxSum = max(maxSum, maxEndHere, maxEndHereDeleted)
    }

    return maxSum
}

func max(nums ...int) int {
    m := nums[0]
    for _, num := range nums[1:] {
        if num > m {
            m = num
        }
    }
    return m
}
```Go 解决方案反映了 Python 解决方案。 Go 需要一个帮手`max`可以处理多个整数的函数，并且使用切片代替 Python 列表。 即使问题约束保证至少一个元素，也会显式检查空输入等边缘情况。 

## 工作示例

 **示例1：**`arr = [1, -2, 0, 3]`| 我| 到达[我] | 此处最大结束 | max_end_here_deleted | max_end_here_deleted | 最大总和 |
 | ---| ---| ---| ---| ---|
 | 0 | 1 | 1 | 1 | 1 |
 | 1 | -2 | 最大值(-2,1-2)= -1 | 最大（1,1-2）= -1 | 1 |
 | 2 | 0 | 最大(0,-1+0)=0 | 最大值(-1,-1+0)= -1 | 1 |
 | 3 | 3 | 最大(3,0+3)=3 | 最大(0,-1+3)=2 | 3 |

 我们看到全局最大值是通过删除来实现的`-2`给予`[1,0,3] = 4`。 表计算需要检查全局最大值`max_end_here_deleted + arr[i]`，导致最终`max_sum = 4`。 

**示例2：**`arr = [1,-2,-2,3]`删除任何负面信息可能会有所帮助，但`[3]`单独给出最大总和 = 3。 

**示例3：**`arr = [-1,-1,-1,-1]`删除没有帮助，因为删除任何元素都会使总和小于选择单个元素`-1`。 最大总和 = -1。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 单次遍历数组，每个元素的常数时间操作 |
 | 空间| O(1) | O(1) | 仅使用了几个变量； 不需要额外的阵列|

 时间复杂度是线性的，因为我们只迭代数组一次。 空间复杂度是恒定的，因为无论数组大小如何，我们都只维护三个整数。
