[LeetCode 第 1178 题](https://leetcode.com/problems/number-of-valid-words-for-each-puzzle/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、字符串、位操作、Trie

 ## 解决方案

 ## 问题理解

 该问题要求我们确定，对于每个给定的`puzzle`字符串，给定列表中有多少个单词`words`对于该谜题_有效_。 如果一个单词包含拼图的第一个字符并且该单词的所有字符也出现在拼图中，则该单词对于拼图来说是有效的。 输入由一个单词列表和一个谜题列表组成，每个谜题的长度正好是 7 个字母，并且具有唯一的字符。 输出是一个数组，其中每个元素对应于相应谜题的有效单词数。 

约束表明潜在的大输入大小（`words`最多 10^5，`puzzles`最多 10^4），这意味着一个简单的解决方案，根据每个谜题检查每个单词（`O(n*m)`其中 n 是单词数，m 是谜题数）会太慢。 边缘情况包括没有有效单词的谜题、超过 7 个字母的单词或共享谜题中不存在的字母的单词。 

## 方法

 ### 蛮力

 暴力解决方案将迭代每个谜题，然后检查每个单词的有效性条件：第一个字母必须匹配，并且所有字母必须存在于谜题中。 这种方法是正确的，但效率低下，因为它需要`O(n * m * k)`操作，其中`n`是单词数，`m`是谜题的数量，并且`k`是平均单词长度。 鉴于限制，这是不可行的。 

### 最佳

 最佳方法利用**位操作**和**哈希映射**。 每个单词和谜题都可以表示为 26 位的位掩码，每个位代表一个字母。 这允许使用按位运算快速检查子集包含情况。 

关键见解：对于一个谜题，我们只需要考虑其 6 个字母的子集（不包括第一个字母），将每个子集与第一个字母组合，并检查预处理的单词位掩码图中有多少个单词匹配。 这降低了复杂性，因为每个谜题最多有 2^6 = 64 个子集，即使有 10^4 个谜题也是可以管理的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m * k) | O(n * m * k) | O(n * k) | 检查每个单词和每个谜题，太慢了 |
 | 最佳| O(n * k + m * 2^6) | O(n * k + m * 2^6) | O(n) | 使用bitmask + hashmap进行子集检查，非常高效 |

 ## 算法演练

 1. 将每个单词转换为表示其字母的 26 位整数位掩码。 将每个唯一位掩码的计数存储在哈希图中。 
2. 对于每个拼图，为其所有字母创建一个位掩码。 
3. 生成最后 6 个字母的所有 2^6 个子集（不包括第一个字符）。 对于每个子集，添加第一个字母的位。 
4. 对于每个子集位掩码，检查它是否存在于字位掩码映射中并对它们的计数求和。 
5. 将总和附加到答案数组中。 

**为什么有效：** 将单词和谜题表示为位掩码允许恒定时间子集检查。 生成所有子集可确保对所有有效单词组合进行计数，同时确保满足首字母约束。 

## Python 解决方案```python
from typing import List
from collections import Counter
from itertools import combinations

class Solution:
    def findNumOfValidWords(self, words: List[str], puzzles: List[str]) -> List[int]:
        word_count = Counter()
        
        # Convert each word into a bitmask
        for word in words:
            mask = 0
            for ch in set(word):
                mask |= 1 << (ord(ch) - ord('a'))
            word_count[mask] += 1
        
        res = []
        for puzzle in puzzles:
            first = 1 << (ord(puzzle[0]) - ord('a'))
            total = 0
            # Generate all subsets of the last 6 letters
            mask_letters = [1 << (ord(ch) - ord('a')) for ch in puzzle[1:]]
            for k in range(0, 7):
                for combo in combinations(mask_letters, k):
                    mask = first
                    for c in combo:
                        mask |= c
                    total += word_count.get(mask, 0)
            res.append(total)
        return res
```**说明：** 该解决方案首先预先计算单词位掩码并存储它们的频率。 对于每个谜题，它会迭代最后六个字母的所有子集，并将它们与第一个字母组合起来，检查频率图。 结果是该谜题的所有有效匹配的总和。 

## 解决方案```go
package main

func findNumOfValidWords(words []string, puzzles []string) []int {
    wordCount := make(map[int]int)
    
    for _, word := range words {
        mask := 0
        seen := make(map[rune]bool)
        for _, ch := range word {
            if !seen[ch] {
                mask |= 1 << (ch - 'a')
                seen[ch] = true
            }
        }
        wordCount[mask]++
    }
    
    res := make([]int, len(puzzles))
    
    for i, puzzle := range puzzles {
        first := 1 << (puzzle[0] - 'a')
        var masks []int
        // generate masks of subsets of last 6 letters
        masks = append(masks, 0)
        for j := 1; j < 7; j++ {
            letterMask := 1 << (puzzle[j] - 'a')
            newMasks := make([]int, len(masks))
            copy(newMasks, masks)
            for _, m := range masks {
                newMasks = append(newMasks, m|letterMask)
            }
            masks = newMasks
        }
        count := 0
        for _, m := range masks {
            count += wordCount[m|first]
        }
        res[i] = count
    }
    
    return res
}
```**说明：** Go 实现遵循相同的位掩码逻辑。 地图跟踪词频，并迭代生成子集。 每个谜题的第一个字母始终包含在掩码检查中以满足有效性条件。 

## 工作示例

 示例：`words = ["aaaa","asas","able","ability","actt","actor","access"], puzzles = ["aboveyz"]`1. 将字转换为位掩码：

 - “aaaa” → 1 (`a`）
 - “阿萨斯” → 3 (`a|s`）
 - “能够”→ 15 (`a|b|l|e`）
 - “能力” → 1027 (`a|b|i|l|t|y`）
 -“行动”→21（`a|c|t`）
 - “演员” → 23 (`a|c|t|o|r`）
 - “访问” → 23 (`a|c|e|s`）
 2. 谜题“aboveyz”，第一个字母位 = 1 (`a`）
 3. 生成剩余字母的子集：“boveyz”
 4. 将第一个字母与每个子集组合并检查单词映射。 仅面膜`1`匹配→“aaaa”
 5. 该谜题的结果 = 1

 ## 边缘情况

 1. **单词比拼图长：** 超过 7 个字母的单词无效，因为所有字母都必须在拼图中。 位掩码自然地处理这个问题，因为这样的单词包括拼图掩码之外的字母。 
2. **没有有效单词的谜题：** 有些谜题可能包含未出现在任何单词中的字母。 我们的算法仍然生成所有子集，但哈希映射查找将为不存在的掩码返回 0。 
3. **具有重复字母的单词：** 单词中的重复字母不会影响有效性，因为我们在创建位掩码之前将每个单词转换为一个集合。 这可确保重复项不会增加计数。
