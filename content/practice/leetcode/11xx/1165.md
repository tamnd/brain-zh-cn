 ## 解决方案

 ## 问题理解

 该问题描述了一个单行键盘，其中每个键都位于从 0 到 25 的唯一索引处。您将获得一个字符串`keyboard`长度为26，指定所有小写英文字母的布局。 初始手指位置在索引0处，将手指从索引处移动`i`索引`j`需要`|i - j|`时间单位。 然后系统会要求您输入一个字符串`word`并通过对连续键入的字母之间的位置绝对差求和来计算键入它所需的总时间。 

输入由两个字符串组成：`keyboard`，它始终是小写英文字母的排列，并且`word`，仅包含小写字母。 输出是一个表示所用总时间的整数。 

约束条件确保`keyboard`恰好包含 26 个唯一字母，因此我们不需要处理丢失或重复的字母。 长度为`word`最多可达 10,000，这表明解决方案必须在每个字符的恒定时间内有效地处理每个字母。 重要的边缘情况包括键入第一个字符（起始位置为 0）、重复键入相同的字符（这应该增加零移动成本）以及键盘上字母相距较远的布局。 

## 方法

 蛮力方法很简单：对于`word`，我们在其中搜索它的索引`keyboard`使用线性搜索。 然后，我们计算当前手指位置和新索引之间的绝对差。 我们将这些差异相加得到总时间。 这种方法是正确的，但是每次查找`keyboard`是 O(26)，并且`word`最多 10,000 个字符，这实际上会导致 O(26 * n) = O(n)，但这不是最佳选择，因为不需要对每个字符进行线性搜索。 

最佳解决方案使用哈希映射（或Python中的字典）来预先计算每个字母的索引`keyboard`。 这使得每次查找的时间复杂度为 O(1)。 然后，我们迭代`word`，计算连续位置之间的绝对差并对它们求和。 这将每个字符的查找从 O(26) 减少到 O(1)，从而实现真正的 O(n) 时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 26) ≈ O(n) | O(1) | O(1) | 线性搜索键盘中每个字母的位置 |
 | 最佳| O(n) | O(26) ≈ O(1) | O(26) ≈ O(1) | 使用哈希映射预先计算字母位置以进行恒定时间查找 |

 ## 算法演练

 1. 初始化变量`time`为 0 以存储总打字时间。 
2. 根据中的每个字符创建一个映射`keyboard`使用字典到其索引。 这允许快速查找任何字母的位置。 
3. 初始化变量`current_pos`到 0，代表起始手指位置。 
4. 迭代每个字符`ch`在`word`。 
5. 对于每个`ch`，在键盘映射中查找其索引。 
6. 添加之间的绝对差`current_pos`和新索引`time`。 
7. 更新`current_pos`到新索引。 
8.循环结束后，返回`time`。 

为什么它有效：该算法保持一个不变量`current_pos`始终反映手指的当前位置。 使用绝对差正确计算每个运动，并将所有运动相加得出所需的总时间。 

## Python 解决方案```
class Solution:
    def calculateTime(self, keyboard: str, word: str) -> int:
        # Create a mapping from each character to its index in the keyboard
        char_to_index = {ch: i for i, ch in enumerate(keyboard)}
        
        time = 0
        current_pos = 0
        
        # Iterate through each character in word
        for ch in word:
            next_pos = char_to_index[ch]
            time += abs(next_pos - current_pos)
            current_pos = next_pos
        
        return time
```Python 实现首先构建一个字典，将字母映射到其位置，以进行 O(1) 查找。 它初始化`current_pos`到 0 并迭代`word`, 更新`time`通过每个角色移动的距离。 使用`abs`无论方向如何，都能确保正确的距离计算。 

## 解决方案```
func calculateTime(keyboard string, word string) int {
    // Create a map from character to its index
    charToIndex := make(map[rune]int)
    for i, ch := range keyboard {
        charToIndex[ch] = i
    }
    
    time := 0
    currentPos := 0
    
    // Iterate through each character in word
    for _, ch := range word {
        nextPos := charToIndex[ch]
        if nextPos > currentPos {
            time += nextPos - currentPos
        } else {
            time += currentPos - nextPos
        }
        currentPos = nextPos
    }
    
    return time
}
```在 Go 中，我们使用`map[rune]int`用于恒定时间字符索引查找。 与 Python 不同，Go 没有内置的`abs`对于标准库中的整数，因此我们使用条件手动计算绝对差。 对字符串的迭代是使用`range`循环处理每个符文。

 ## 边缘情况

 一个重要的边缘情况是键入不在索引 0 处的第一个字符。算法通过计算距起始位置的距离来正确处理此问题。 另一个边缘情况是重复字符`word`，如果不正确使用绝对差值，可能会错误地累积时间。 该实现正确处理了这个问题，当`current_pos`等于下一个字符的索引。 最后，字母顺序完全相反的布局
