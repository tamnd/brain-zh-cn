[LeetCode 第 1174 题](https://leetcode.com/problems/immediate-food-delivery-ii/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题提供了一个`Delivery`记录送餐订单的表。 每行代表客户下的一个订单。 除了订单日期外，每个客户还指定了首选交货日期。 如果首选交货日期与订单日期完全相同，则该订单被视为即时订单。 否则，它被视为预定订单。 

这个问题的关键细节是我们并不对所有订单感兴趣。 我们只关心每个客户的第一个订单。 第一个订单定义为最早的订单`order_date`对于该客户。 该问题保证每个客户都有一个确切的第一个订单，这意味着最早日期没有联系。 

在确定每个客户的第一个订单后，我们必须确定这些第一个订单中有多少是即时订单。 最终结果应该是立即下单的客户百分比，四舍五入到小数点后两位。 

输入表示为关系数据库表。 预期输出是一个单行结果，其中包含名为`immediate_percentage`。 

尽管没有列出明确的约束，但问题结构表明效率很重要。 对于大型数据集来说，重复扫描每个客户的表的简单解决方案会变得昂贵。 这促使我们有效地使用 SQL 聚合和过滤技术。 

预先识别一些边缘情况很重要。 客户可能只有一个订单，该订单自动成为他们的第一个订单。 有些客户可能会立即收到第一笔订单，而另一些则可能不会。 也有可能所有第一订单都是立即的，或者没有一个是立即的。 另一个重要的保证是每个客户都有一个最早的订单日期，这简化了逻辑，因为我们不需要处理关系。 

## 方法

 暴力方法将独立处理每个客户。 对于每个客户，我们可以扫描整个表以找到最小值`order_date`，然后再次扫描检索对应行并判断是否是立即数。 在处理完所有客户后，我们会计算有多少个即时订单并除以客户总数。 

这种方法是正确的，因为它明确标识了每个客户的最早订单，并检查首选交货日期是否与订单日期匹配。 然而，它的效率很低，因为可能会为每个顾客重复扫描桌子。 

更好的解决方案的关键在于 SQL 是为分组聚合而设计的。 我们可以在单个分组查询中计算每个客户的最早订单日期，而不是重复搜索每个客户的第一个订单。 一旦我们有了这些一阶行，我们就可以使用聚合直接计算立即交付的百分比。 

这种方法避免了冗余扫描并利用 SQL 操作，例如`GROUP BY`、有效地连接和聚合函数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 重复扫描每位顾客的桌子|
 | 最佳| O(n log n) 或 O(n) 取决于索引 | O(n) | 使用分组和过滤来有效地隔离第一订单 |

 ## 算法演练

 1. 首先，确定每个客户的最早订单日期。 这可以使用子查询来完成`GROUP BY customer_id`和`MIN(order_date)`。 
2.接下来加入原来的`Delivery`带有子查询结果的表。 连接条件同时满足`customer_id`以及最早的`order_date`。 这会隔离每个客户的第一个订单行。 
3. 一旦我们收到第一批订单，请确定每个订单是否是即时的。 如果满足以下条件，订单将立即生效：`order_date = customer_pref_delivery_date`。 
4. 计算有多少个第一订单是即时的。 在 SQL 中，这可以使用条件聚合来完成`CASE WHEN`。 
5. 将直接首单数量除以首单总数。 乘以`100`将比率转换为百分比。 
6. 使用 SQL 将结果四舍五入到小数点后两位`ROUND`功能。 

### 为什么它有效

 该算法之所以有效，是因为子查询保证只选择每个客户的最早订单日期。 由于该问题保证每个客户都有一个唯一的第一个订单，因此连接正确地为每个客户检索一行。 从这里开始，计算即时订单并除以客户总数即可得出所需的百分比。 

## Python 解决方案

 LeetCode 数据库问题使用 SQL 而不是可执行的 Python 代码。 然而，为了完整起见，Python 中的逻辑等效项可以表示如下。```python
from typing import List, Dict

class Solution:
    def immediateFoodDeliveryPercentage(self, delivery: List[Dict]) -> float:
        first_orders = {}

        for order in delivery:
            customer_id = order["customer_id"]

            if (
                customer_id not in first_orders or
                order["order_date"] < first_orders[customer_id]["order_date"]
            ):
                first_orders[customer_id] = order

        immediate_count = 0

        for order in first_orders.values():
            if order["order_date"] == order["customer_pref_delivery_date"]:
                immediate_count += 1

        percentage = (immediate_count * 100) / len(first_orders)

        return round(percentage, 2)
```该实现首先将每个客户的最早订单存储在一个字典中，该字典的键为`customer_id`。 处理每一行时，算法会将当前订单日期与存储的最早日期进行比较。 如果当前订单较早，则它将替换存储的订单。 

收集所有第一批订单后，代码会迭代它们并计算有多少是立即交付的。 最后，它计算百分比并将结果四舍五入到小数点后两位。 

Python 版本反映了 SQL 解决方案在概念上使用的相同逻辑。 

## 解决方案```go
package main

import (
	"math"
	"time"
)

type Delivery struct {
	DeliveryID              int
	CustomerID              int
	OrderDate               string
	CustomerPrefDeliveryDate string
}

func immediateFoodDeliveryPercentage(deliveries []Delivery) float64 {
	firstOrders := make(map[int]Delivery)

	for _, order := range deliveries {
		currentDate, _ := time.Parse("2006-01-02", order.OrderDate)

		existing, exists := firstOrders[order.CustomerID]

		if !exists {
			firstOrders[order.CustomerID] = order
			continue
		}

		existingDate, _ := time.Parse("2006-01-02", existing.OrderDate)

		if currentDate.Before(existingDate) {
			firstOrders[order.CustomerID] = order
		}
	}

	immediateCount := 0

	for _, order := range firstOrders {
		if order.OrderDate == order.CustomerPrefDeliveryDate {
			immediateCount++
		}
	}

	percentage := (float64(immediateCount) * 100.0) / float64(len(firstOrders))

	return math.Round(percentage*100) / 100
}
```Go 实现遵循与 Python 版本相同的整体结构。 由于Go没有内置对这种格式的字符串进行日期比较而无需解析，因此解决方案使用`time`包来安全地比较日期。 

地图用于存储每个客户的最早订单。 最终百分比计算使用`float64`转换以避免整数除法。 

## SQL 解决方案```sql
SELECT
    ROUND(
        100.0 * SUM(
            CASE
                WHEN d.order_date = d.customer_pref_delivery_date THEN 1
                ELSE 0
            END
        ) / COUNT(*),
        2
    ) AS immediate_percentage
FROM Delivery d
JOIN (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
) first_orders
ON d.customer_id = first_orders.customer_id
AND d.order_date = first_orders.first_order_date;
```SQL 解决方案首先计算子查询中每个客户的最早订单日期。 然后它将这些结果连接回`Delivery`表来检索相应的行。 

这`CASE WHEN`表达式将立即命令转换为`1`并将预定订单放入`0`。 将这些值相加即可得出直接第一阶的数量。 除以一阶总数并乘以`100.0`产生所需的百分比。 

这`ROUND(..., 2)`函数确保结果按照问题的要求格式化为两位小数。

 ## 边缘情况

 当每个客户的第一个订单都是即时的时，就会出现一个重要的边缘情况。 在这种情况下，结果应该是准确的`100.00`。 某些实现在乘以之前错误地执行整数除法`100`，可以截断小数结果。 该解决方案通过乘以来避免这种情况`100.0`，确保浮点运算。 

另一个重要的情况是没有客户的第一个订单是立即完成的。 正确的结果应该是`0.00`。 有缺陷的实现可能会意外地计算后面的即时订单，而不是仅将计算限制为第一个订单。 SQL 解决方案中的连接条件保证仅评估第一顺序。 

第三种边缘情况涉及有多个订单的客户。 幼稚的实现可能会意外地检查所有行并计算任何直接顺序，即使它不是第一个。 该解决方案在计算百分比之前仅正确隔离每个客户的最早订单日期，从而防止后续订单影响结果。
