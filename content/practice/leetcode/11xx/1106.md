 **主题：** 字符串、堆栈、递归

 ## 解决方案

 ## 问题理解

 该问题要求我们**评估表示为字符串的布尔表达式**。 表达式可以包含文字`'t'`和`'f'`对于 true 和 false，以及三种类型的运算符：逻辑 NOT`'!'`, 逻辑与`'&'`，和逻辑或`'|'`。 每个运算符都有特定的语法：`'!(subExpr)'`否定子表达式，`'&(subExpr1,subExpr2,...)'`计算一个或多个子表达式的逻辑与，并且`'|(subExpr1,subExpr2,...)'`计算一个或多个子表达式的逻辑或。 子表达式本身可以嵌套任意深度。 

**输入**是一个字符串`expression`长度最多 20,000 个字符，这保证了解析必须高效且理想的线性。 **输出**是一个布尔值，要么`true`或者`false`，它对应于根据标准布尔逻辑对表达式进行求值。 

重要的约束包括保证输入的有效性，因此我们不需要处理格式错误的字符串。 潜在的边缘情况包括仅具有一个文字的表达式、深度嵌套的表达式或应用于单个子表达式的运算符。 此外，由于限制，不会出现空子表达式列表。 

## 方法

 **暴力方法**将尝试递归地解析字符串，手动以逗号分割，并评估每个子表达式。 虽然这种方法是正确的，但在嵌套表达式中以逗号进行简单的字符串分割可能很容易出错，并且可能需要对每个子表达式进行多次扫描，这使得对于大型嵌套表达式来说，时间复杂度可能为 O(n^2)。 

**最佳方法**使用**基于堆栈的解析技术**，在一次从左到右的传递中处理字符串。 每个字符都被推入堆栈，直到出现右括号`')'`遇到。 此时，堆栈将被弹出，直到匹配的开口`'('`找到，收集所有子表达式。 对应的运算符就在前面`'('`，因此我们可以计算应用于所有子表达式的运算符的结果并将结果推送`'t'`或者`'f'`回到堆栈中。 这种方法确保每个字符只处理一次，从而产生 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 递归地分割和评估字符串，可能会多次重新扫描嵌套子表达式 |
 | 最佳 | O(n) | O(n) | 基于堆栈的单通道评估，每个字符处理一次，深度嵌套高效 |

 ## 算法演练

 1. 初始化一个空堆栈来保存迭代时表达式中的字符。 
2. 迭代每个字符`ch`在输入字符串中：

 1.如果`ch`是一个字面意思`'t'`或者`'f'`，或运算符`'!'`,`'&'`,`'|'`， 或者`'('`，将其压入堆栈。 
2.如果`ch`是一个右括号`')'`，这表示子表达式的结束：

 1. 从堆栈中弹出元素，直到出现空位`'('`被发现。 收集所有文字`'t'`或者`'f'`在一个列表中。 
2. 弹出`'('`从堆栈中。 
3.弹出之前的操作符`'('`来确定操作。 
4. 将运算符应用于子表达式结果列表：

 -`'!'`否定单个值。 
-`'&'`计算所有值的逻辑与。 
-`'|'`计算所有值的逻辑或。 
5.推送结果`'t'`或者`'f'`回到堆栈中。 
3. 迭代结束时，堆栈将包含单个元素`'t'`或者`'f'`，代表结果。 返回`True`如果是的话`'t'`， 别的`False`。 

**为什么有效**：堆栈维护当前的计算上下文。 通过立即处理每个右括号并将其子表达式折叠为单个布尔值，我们确保嵌套表达式在其父表达式之前计算，尊重运算和括号的顺序。 

## Python 解决方案```python
class Solution:
    def parseBoolExpr(self, expression: str) -> bool:
        stack = []
        
        for ch in expression:
            if ch == ',':
                continue
            elif ch != ')':
                stack.append(ch)
            else:
                vals = []
                while stack[-1] != '(':
                    vals.append(stack.pop())
                stack.pop()  # pop '('
                op = stack.pop()  # operator
                if op == '!':
                    result = 't' if vals[0] == 'f' else 'f'
                elif op == '&':
                    result = 't' if all(v == 't' for v in vals) else 'f'
                else:  # '|'
                    result = 't' if any(v == 't' for v in vals) else 'f'
                stack.append(result)
        
        return stack[0] == 't'
```该代码使用**堆栈来处理嵌套表达式**。 我们跳过逗号，因为它们仅分隔操作数。 当遇到右括号时，我们弹出所有文字，直到`'('`到达后，确定运算符，计算结果，然后推回。 最后，堆栈包含一个最终值，该值被转换为布尔值。 

## 解决方案```go
func parseBoolExpr(expression string) bool {
    stack := []rune{}
    
    for _, ch := range expression {
        if ch == ',' {
            continue
        } else if ch != ')' {
            stack = append(stack, ch)
        } else {
            vals := []rune{}
            for stack[len(stack)-1] != '(' {
                vals = append(vals, stack[len(stack)-1])
                stack = stack[:len(stack)-1]
            }
            stack = stack[:len(stack)-1] // pop '('
            op := stack[len(stack)-1]
            stack = stack[:len(stack)-1] // pop operator
            
            var result rune
            switch op {
            case '!':
                if vals[0] == 't' {
                    result = 'f'
                } else {
                    result = 't'
                }
            case '&':
                result = 't'
                for _, v := range vals {
                    if v == 'f' {
                        result = 'f'
                        break
                    }
                }
            case '|':
                result = 'f'
                for _, v := range vals {
                    if v == 't' {
                        result = 't'
                        break
                    }
                }
            }
            stack = append(stack, result)
        }
    }
    
    return stack[0] == 't'
}
```Go 在语法上略有不同：切片用作堆栈，符文用于字符操作。 该逻辑在其他方面与 Python 相似，确保单遍求值和嵌套表达式的正确处理。 

## 工作示例

 **示例1**：`&(|(f))`| 步骤| 堆栈内容 | 运营|
 | ---| ---| ---|
 | '&'| ['&'] | 推算子|
 | '(' | ['&','('] | 推 '(' |
 | ' | ' | ['&','(',' |
 | '(' | ['&','(',' | ','('] | '(' | ['&','(',' | ','('] |
 | 'f' | ['&','(',' | ','(','f'] |
 | ')' | ['&','(',' | ','f'] |
 | ')' | ['&','f'] | 评价`&(f)`=`f`|
 | 结束 | [‘f’]| 最终结果 = false |

 **示例2**：`|(f,f,f,t)`| 步骤| 堆栈内容 | 运营|
 | ---| ---| ---|
 | ' | ' | [' |
 | '(' | [' | ','('] |
 | 'f' | ['| ','(','f'] |
 | 'f' | [' | ','(','f','f'] |
 | 'f' | ['| ','(','f','f','f'] |
 | 't' | ['| ','(','f','f','f','t'] |
 | ')' | [‘t’] | 评估或 =`t`|
 | 结束 | [‘t’] | 最终结果 = true |

 **示例3**：`!(&(f,t))`| 步骤| 堆栈内容 | 运营|
 | ---| ---| ---|
 | '！' | ['！'] | 推算子|
 | '(' | ['!','('] | 推 '(' |
 | '&'| ['!','(','&'] | 推送运算符 |
 | '(' | ['!','(','&','('] | 推 '(' |
 | 'f' | ['!','(','&','(','f'] | 推送文字 |
 | 't' | ['!','(','&','(','f','t'] | 推送文字 |
 | ')' | ['!','&','f'] | 评价`&(f,t)`=`f`|
 | ')' | [‘t’] | 评价`!(f)`=`t`|
 | 结束 | [‘t’] | 最终结果 = true |
