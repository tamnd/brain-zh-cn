[LeetCode 第 1133 题](https://leetcode.com/problems/largest-unique-number/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们找出数组中只出现一次的最大整数。 换句话说，在所有唯一（只出现一次）的整数中，我们需要找到最大值。 如果不存在这样的整数，则输出应该是`-1`。 输入`nums`是一个整数列表，每个整数的范围从 0 到 1000，数组长度最大可达 2000。这告诉我们输入大小相对较小，因此 O(n log n) 甚至 O(n^2) 时间的算法是可以接受的，但使用额外空间的 O(n) 解决方案可能更好、更优雅。 

重要的边缘情况包括所有元素都重复的数组（返回`-1`）、只有一个元素的数组（返回该元素）以及最大元素本身重复的数组，因此我们必须仔细检查唯一性，而不是简单地选择最大值。 

## 方法

 暴力方法将迭代数组，并为每个元素计算它在数组中出现的次数。 然后我们将跟踪只出现一次的最大元素。 虽然正确，但这种方法需要扫描整个数组中的每个元素，导致时间复杂度为 O(n^2)，这对于较大的数组来说效率较低。 

最佳方法使用哈希图来计算每个数字的出现次数。 一旦我们有了计数，我们就可以迭代哈希图来找到计数恰好为 1 的最大数字。 这种方法利用了这样一个事实：我们可以在 O(n) 时间和空间内有效地跟踪计数。 对于给定的约束，它简单、可读且快速。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 单独计算每个数字的出现次数 |
 | 最佳 | O(n) | O(n) | 使用哈希映射来计算出现次数，然后找到最大唯一 |

 ## 算法演练

 1. 初始化一个空的哈希映射（Python 中的字典，Go 中的映射）来存储数组中每个整数的计数。 
2. 迭代数组，对于每个数字，增加其在哈希映射中的计数。 这可确保有效跟踪每个数字的频率。 
3. 初始化变量`largest_unique`到`-1`存储找到的最大唯一编号。 
4. 迭代哈希映射条目。 对于每个计数恰好为 1 的数字，将其与`largest_unique`。 如果较大则更新`largest_unique`。 
5. 处理完所有条目后，返回`largest_unique`。 如果没有数字恰好出现一次，则变量保留`-1`，它正确地处理了这种情况。 

为什么它有效：该算法之所以有效，是因为哈希映射保证了每个数字的出现都被准确地计数。 通过迭代地图并仅考虑计数为一的数字，我们确保只评估唯一的数字。 因此，这些数字中的最大值是最大的唯一数字。 

## Python 解决方案```
from typing import List

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        count_map = {}
        for num in nums:
            count_map[num] = count_map.get(num, 0) + 1
        
        largest_unique = -1
        for num, count in count_map.items():
            if count == 1 and num > largest_unique:
                largest_unique = num
                
        return largest_unique
```这个 Python 解决方案首先使用字典计算所有数字。 这`get`如果键不存在，方法提供默认值0，简化增量操作。 然后它扫描所有键值对，检查唯一性并跟踪找到的最大数字。 这直接实现了上面概述的算法。 

## 解决方案```
func largestUniqueNumber(nums []int) int {
    countMap := make(map[int]int)
    for _, num := range nums {
        countMap[num]++
    }
    
    largestUnique := -1
    for num, count := range countMap {
        if count == 1 && num > largestUnique {
            largestUnique = num
        }
    }
    
    return largestUnique
}
```在 Go 中，我们使用映射来计算出现次数。 增量操作`countMap[num]++`自动处理丢失键的初始化。 查找最大唯一数字的逻辑与 Python 版本相同。 Go 不需要映射值的类型提示，因为映射声明指定了它。

 ## 边缘情况

 一个重要的边缘情况是具有单个元素的数组。 该算法正确地处理了这一问题，因为哈希映射将有一个计数为 1 的条目，该条目将被返回。 

另一种边缘情况是数组中最大的数字重复出现。 简单地返回最大值的简单实现在这里会失败。 我们的方法明确检查计数是否等于 1，因此避免了这个陷阱。 

最后，所有元素都是重复的数组需要小心处理。 的初始化`largest_unique`到`-1`确保如果没有元素满足唯一性标准，函数会正确返回`-1`。 这可以防止从数组返回错误的最大值。
