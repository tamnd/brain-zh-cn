[LeetCode 第 1189 题](https://leetcode.com/problems/maximum-number-of-balloons/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们确定使用给定字符串中的字符可以形成单词 **“balloon”** 的最大次数`text`。 中的每个角色`text`每次出现该单词最多可以使用一次。 输入为仅由小写英文字母组成的字符串，长度最大为10000。 输出是一个整数，表示可以构造的**“气球”**实例的最大数量。 

换句话说，我们本质上是在计算单词 **“balloon”** 所需的字母的频率 - 具体来说，`'b'`,`'a'`,`'l'`,`'o'`， 和`'n'`。 因为`'l'`和`'o'`在**“气球”**中出现两次，我们必须在计算中考虑到这一点。 **“气球”**可以形成的最大次数受到可用计数（调整重复项后）最小的字母的限制。 

重要的边缘情况包括不包含某些所需字母的输入字符串、仅包含足以形成单个“气球”的字母的字符串以及包含过多字母的字符串，其中限制因素将是出现次数较少的字母。 

## 方法

 暴力方法将涉及重复检查是否可以从当前字符计数形成“气球”并每次减少计数。 虽然这是正确的，但效率很低，因为它可能需要 O(n * m) 次操作，其中 n 是字符串的长度，m 是可以形成 **“气球”** 的次数。 鉴于问题简化为计算字符频率，这种方法是不必要的。 

最佳方法利用频率计数器（哈希图）来计算每个字符的出现次数`text`。 然后，对于 **“balloon”** 中的每个字母，我们计算它可以帮助形成单词的次数，同时考虑到重复的字母`'l'`和`'o'`。 答案是除以所有必需字母的计数后的最小计数`'l'`和`'o'`2（因为每个单词出现两次）。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 反复形成“气球”，直到不可能|
 | 最佳| O(n) | O(1) | O(1) | 计算频率，调整重复项，取最小值 |

 ## 算法演练

 1. 初始化一个字典或者哈希映射来统计每个字符出现的次数`text`。 
2. 迭代中的每个字符`text`并更新频率计数器。 
3. 对于单词**“balloon”**，创建所需计数的映射：`'b':1`,`'a':1`,`'l':2`,`'o':2`,`'n':1`。 
4. 对于每个所需的字符，通过将频率除以来计算它可以做出多少个完整贡献`text`按所需的数量。 
5. 返回这些值中的最小值作为可以形成 **“气球”** 的最大次数。 

**为什么有效：** 这里的不变量是形成“气球”需要固定数量的所有字母。 最大字数受最稀有调整字母的限制。 通过计算这个最小值，我们确保没有字母被过度使用，从而保证正确性。 

## Python 解决方案```python
class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        from collections import Counter

        freq = Counter(text)
        required = {'b': 1, 'a': 1, 'l': 2, 'o': 2, 'n': 1}

        # For each required letter, calculate how many times it can contribute to "balloon"
        return min(freq.get(char, 0) // count for char, count in required.items())
```实现首先使用`Counter`计算每个字符的出现次数。 然后它定义 **“气球”** 所需的计数。 可用计数除以所需计数的最小值给出了可以形成的完整字的数量。 使用`freq.get(char, 0)`确保丢失的字母返回 0，处理边缘情况。 

## 解决方案```go
func maxNumberOfBalloons(text string) int {
    freq := make(map[rune]int)
    for _, ch := range text {
        freq[ch]++
    }

    required := map[rune]int{'b': 1, 'a': 1, 'l': 2, 'o': 2, 'n': 1}
    minCount := int(^uint(0) >> 1) // Max int

    for ch, count := range required {
        available := freq[ch] / count
        if available < minCount {
            minCount = available
        }
    }
    return minCount
}
```在 Go 中，我们使用`map[rune]int`来计算字符出现的次数。 我们迭代所需的字母并将其计数除以所需的数量。 返回最小的结果值。 Go没有内置的Counter，所以一个简单的map就足够了。 Max int 使用位操作进行初始化，以确保正确的最小比较。

 ## 边缘情况

 一个重要的边缘情况是空字符串。 由于不存在字母，因此该算法正确返回 0，不会出现错误，因为频率字典将为空，并且`min`对于缺失的字母，计算将默认为 0。 

另一个边缘情况是当字符串包含“balloon”所需的一些但不是全部字母时。 例如，“balon”缺少重复项，因此算法将正确计算调整后的计数，如果缺少任何所需的字母，则返回 0。
