 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定二叉树的所有子树中的最大平均值。 **子树**定义为任何节点及其所有后代。 子树的**平均值**是其节点值的总和除以该子树中的节点数。 

输入是二叉树的根节点。 每个节点包含一个整数值，树最多可以有 10,000 个节点。 节点值的范围为`0`到`10^5`。 预期输出是一个浮点数，表示所有可能子树中的最大平均值。 如果答案在范围内，则被认为是正确的`10^-5`实际最大平均值。 

重要的边缘情况包括只有一个节点的树、所有节点都具有相同值的树或高度不平衡的树。 这些约束确保每棵树至少有一个节点，并且节点数量足够适中以允许深度优先遍历解决方案。 

## 方法

 **暴力方法**涉及分别计算每个可能的子树的节点总和和数量。 对于每个节点，我们将递归计算其子树的总和和计数，计算平均值并跟踪最大值。 虽然正确，但这种方法效率低下，因为它多次重新计算子树总和。 对于一棵树来说`n`节点，这可能导致`O(n^2)`最坏情况下的时间复杂度是无法接受的`n = 10^4`。 

**最佳方法**使用自下而上的深度优先搜索 (DFS)。 通过执行后序遍历，我们可以计算每个子树的节点总和和计数一次。 在每个节点，我们通过组合左右子节点的结果来计算子树总和和大小，计算平均值，并根据需要更新全局最大值。 这确保每个节点仅被访问一次，从而产生`O(n)`时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(h) | 分别递归计算每个子树的总和和计数； 重新计算的代价是昂贵的|
 | 最佳 | O(n) | O(h) | DFS后序遍历； 每个节点计算一次总和并计数； h 是树高 |

 ## 算法演练

 1. 初始化一个全局变量来跟踪迄今为止找到的最大平均值。 
2. 定义一个接受节点并返回元组的递归辅助函数`(subtree_sum, subtree_count)`。 
3. 如果节点是`None`， 返回`(0, 0)`因为空子树不贡献任何总和或节点。 
4. 递归调用左右子节点的辅助函数来获取它们的总和和计数。 
5. 计算当前子树的总和，即节点值加上左右子树总和的总和。 
6. 计算当前子树中的节点总数为`1 + left_count + right_count`。 
7. 计算当前子树的平均值：`total_sum / total_count`。 
8. 如果当前平均值较大，则更新全局最大平均值。 
9. 返回`(total_sum, total_count)`给家长打电话。 
10.最后遍历整棵树后，返回最大平均值。 

**为什么有效**：这种方法确保每个子树的总和和大小只计算一次。 通过将这些值从叶子向上传播到根，我们可以避免冗余计算，同时正确考虑每个子树的最大平均值。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional

class Solution:
    def maximumAverageSubtree(self, root: Optional[TreeNode]) -> float:
        self.max_avg = float('-inf')
        
        def dfs(node: Optional[TreeNode]) -> tuple[int, int]:
            if not node:
                return (0, 0)
            left_sum, left_count = dfs(node.left)
            right_sum, right_count = dfs(node.right)
            
            total_sum = node.val + left_sum + right_sum
            total_count = 1 + left_count + right_count
            current_avg = total_sum / total_count
            
            self.max_avg = max(self.max_avg, current_avg)
            
            return (total_sum, total_count)
        
        dfs(root)
        return self.max_avg
```Python 解决方案使用递归 DFS。 帮手`dfs`返回以每个节点为根的子树的总和和计数。 最大平均值在后序遍历期间更新。 使用元组可以避免重新计算并保持代码简洁。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func maximumAverageSubtree(root *TreeNode) float64 {
    var maxAvg float64 = -1
    var dfs func(node *TreeNode) (int, int)
    
    dfs = func(node *TreeNode) (int, int) {
        if node == nil {
            return 0, 0
        }
        leftSum, leftCount := dfs(node.Left)
        rightSum, rightCount := dfs(node.Right)
        
        totalSum := node.Val + leftSum + rightSum
        totalCount := 1 + leftCount + rightCount
        currentAvg := float64(totalSum) / float64(totalCount)
        
        if currentAvg > maxAvg {
            maxAvg = currentAvg
        }
        return totalSum, totalCount
    }
    
    dfs(root)
    return maxAvg
}
```Go 解决方案反映了 Python 方法，使用递归 DFS 函数。 在 Go 中，需要注意将整数转换为`float64`用于平均计算。 这`nil`check 取代了 Python 的`None`。
