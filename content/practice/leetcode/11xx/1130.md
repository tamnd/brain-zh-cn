[LeetCode 问题 1130](https://leetcode.com/problems/minimum-cost-tree-from-leaf-values/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、堆栈、贪婪、单调堆栈

 ## 解决方案

 ## 问题理解

 该问题要求我们从输入数组构造二叉树`arr`正整数，其中每个整数代表中序遍历中的一个**叶节点**。 每个非叶节点恰好有两个子节点，其值计算为其左右子树中**最大叶值**的乘积。 我们的目标是在所有有效树中找到**所有非叶节点值的最小可能总和**。 

换句话说，我们不被要求构建树本身，只需要确定通过最佳组合叶节点可实现的最小总和。 

这些约束提供了重要的指导：数组长度很小（`2 <= arr.length <= 40`），并且所有元素都是 1 到 15 之间的正整数。这些小界限表明动态编程或基于堆栈的方法在不达到性能限制的情况下是可行的。 

边缘情况包括仅具有两个元素的数组、所有元素都相等的数组或首先组合最小值的数组可能会最小化中间产物。 该问题保证总和符合 32 位整数，因此我们不需要处理整数溢出。 

## 方法

 **暴力方法**是递归地考虑所有可能的二叉树结构。 对于将数组分成左子树和右子树的每个可能，我们计算每个子树中的最大叶子值并计算根的乘积。 然后，我们递归计算左右子树的最小和并将它们加在一起。 这保证了正确性，因为它探索了所有可能性，但它是**指数慢**，时间复杂度为 O(2^n)，使得它不可行`n`最多 40 个。 

最佳解决方案的**关键见解**是我们不需要考虑所有树结构。 最小总和可以通过**始终将最小的叶子与其最近的较大邻居配对**来实现，有效地使用**单调堆栈**贪婪地组合叶子。 在每一步中，我们通过将最小元素与最近的较大邻居相乘来删除它，这确保我们最小化中间产物。 这种见解将问题从组合爆炸简化为使用堆栈的线性遍历。

 ## 算法演练

 1. 初始化一个空堆栈。 该堆栈将维护叶值的递减序列。 
2. 迭代数组中的每个元素。 对于每个元素：

 a. 当栈顶小于或等于当前元素时，将其弹出。 这表示移除一片叶子并将其与较小的邻居合并。 

b. 出栈时，计算出栈值与其两个相邻元素（当前元素或新的栈顶元素）中较小者的乘积。 将此乘积添加到运行总和中。 
3. 将当前元素压入堆栈。 这确保堆栈保持递减顺序。 
4.处理完所有元素后，栈中可能还剩下多个元素。 将它们逐一弹出，始终将弹出的值与新的堆栈顶部相乘，然后添加到总和中。 
5. 返回累加和，表示非叶子节点的最小和。 

**为什么起作用：** 堆栈确保在每一步中，最小的可用叶子首先与其最近的较大邻居组合。 这种贪婪配对策略保证中间产物保持最小，从而最小化非叶节点的总和。 不变的是堆栈始终保持递减序列，因此最小的元素会被移除并以最佳方式组合。 

## Python 解决方案```python
from typing import List

class Solution:
    def mctFromLeafValues(self, arr: List[int]) -> int:
        stack = []
        result = 0
        for num in arr:
            while stack and stack[-1] <= num:
                mid = stack.pop()
                if stack:
                    result += mid * min(stack[-1], num)
                else:
                    result += mid * num
            stack.append(num)
        while len(stack) > 1:
            result += stack.pop() * stack[-1]
        return result
```**说明：** 该算法迭代每个元素`arr`，使用堆栈来维护值的递减序列。 每当弹出较小或相等的值时，我们都会计算与其最佳邻居的乘积并将其添加到结果中。 最后将栈中剩余的元素按顺序组合起来，完成最小和计算。 

## 解决方案```go
func mctFromLeafValues(arr []int) int {
    stack := []int{}
    result := 0
    for _, num := range arr {
        for len(stack) > 0 && stack[len(stack)-1] <= num {
            mid := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            if len(stack) > 0 {
                result += mid * min(stack[len(stack)-1], num)
            } else {
                result += mid * num
            }
        }
        stack = append(stack, num)
    }
    for len(stack) > 1 {
        mid := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        result += mid * stack[len(stack)-1]
    }
    return result
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```**说明：** Go 处理的是切片而不是列表，逻辑与 Python 版本相同。 这`min`函数被显式定义。 出栈操作是通过对堆栈进行切片来完成的，贪婪的单调堆栈逻辑确保了叶子值的最佳配对。

 ## 边缘情况

 **边缘情况 1：** 长度为 2 的数组。只能有一棵树，必须将两个值相乘。 堆栈正确地将其处理为最终的 while 循环计算。 

**边缘情况 2：** 具有相同元素的数组。 幼稚的实现可能会错误地对重复的乘积求和，但单调堆栈确保我们始终先组合最小的，从而最小化总和。 

**边缘情况 3：** 在边界处具有最大值的数组。 该算法正确地选择首先将较小的内部元素与其最近的较大邻居配对，从而避免不必要的大型中间产品。 

这个全面的解决方案可以有效地处理所有典型和边界场景。
