 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出了二叉树的根节点。 每个节点都属于树中的特定级别。 根处于水平位置`1`，其直接子级处于同一级别`2`，他们的孩子处于同一水平`3`， 等等。 

我们的目标是计算每一层节点值的总和，并返回总和最大的层数。 如果多个级别的最大总和相同，我们必须返回其中最小的级别号。 

输入是标准二叉树结构，其中每个节点包含：

 - 整数值
 - 对左孩子的参考
 - 对右孩子的引用

 输出是一个整数，表示总和最高的级别。 

这些约束告诉我们一些重要的事情：

 - 树最多可以包含`10^4`节点，因此解决方案必须是有效的。 
- 节点值可能为负，这意味着我们不能假设总和总是增加。 
- 由于不能保证树是平衡的，因此高度可能与节点数一样大。 

逐级重复遍历树的简单解决方案可能会变得效率低下。 我们需要一种只访问每个节点一次的方法。 

有几个重要的边缘情况需要考虑：

 - 一棵只包含一个节点的树
 - 所有值为负数的树
 - 多个级别具有相同的最大总和
 - 高度不平衡的树，类似于链表
 - 树木稀疏，树木较多`null`儿童

 该问题保证至少有一个节点存在，因此我们永远不需要处理一棵空树。 

## 方法

 ### 蛮力方法

 暴力策略首先计算树的高度。 然后，对于每个级别`1`到`height`，我们将执行遍历来计算该特定深度处的节点之和。 

例如：

 - 遍历树以计算该级别的所有节点`1`- 再次遍历水平`2`- 再次遍历水平`3`- 继续直到最深的一层

 这是有效的，因为每个级别的总和都被正确计算。 然而，由于要反复遍历树，因此效率很低。 

如果树的高度是`h`并且有`n`节点，这种方法可能需要`O(n * h)`时间。 在一棵倾斜的树的最坏情况下，`h = n`，导致`O(n^2)`复杂。 

### 最佳方法

 关键的观察是我们可以在树的单次遍历期间计算级别和。 

广度优先搜索，也称为层序遍历，是理想的选择，因为它自然地一次处理一层节点。 

使用队列：

 - 从根节点开始
 - 处理当前队列中的所有节点，这些节点属于同一级别
 - 计算它们的总和
 - 将他们的孩子添加到队列中
 - 进入下一个级别

 这保证了每个节点都被访问一次。 

因为我们一次处理一个级别，所以很容易跟踪：

 - 当前等级数
 - 该级别的总和
 - 迄今为止看到的最大总和
 - 对应的等级编号

 这将时间复杂度降低到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * h) | O(h) | 重复遍历树的每一层|
 | 最佳| O(n) | O(w) | 单次BFS遍历，其中`w`是最大树宽度 |

 ## 算法演练

 1. 创建一个队列，并将根节点插入其中。 

队列允许我们逐级处理树。 这正是广度优先搜索的设计目的。 
2. 初始化跟踪变量。 

我们维持：

 -`current_level`，开始于`1`-`best_level`， 最初`1`-`max_sum`，最初为负无穷大

 这些变量有助于跟踪当前哪个级别的总和最大。 
3. 当队列不为空时对其进行处理。 

循环的每次迭代都会处理树的整个级别。 
4. 确定当前层的节点数。 

迭代开始时的队列长度准确地告诉我们有多少节点属于该级别。 
5. 计算级别总和。 

从队列中删除每个节点：

 - 将其价值添加到`level_sum`- 将其左孩子推入队列（如果存在）
 - 将其右子节点推入队列（如果存在）
 6. 将当前级别总和与迄今为止看到的最佳总和进行比较。 

如果`level_sum > max_sum`：

- 更新`max_sum`- 更新`best_level`我们严格使用更大的比较，以便平局自动保留最小的级别数。 
7. 增加电平计数器。 

处理完当前级别的所有节点后，移动到下一个级别。 
8. 返回`best_level`。 

遍历完成后，该变量包含具有最大总和的最小级别。 

### 为什么它有效

 广度优先搜索按照从上到下的精确顺序逐级处理节点。 在每次迭代开始时，队列仅包含属于当前级别的节点。 因此，对当前处理的所有节点求和即可得出该级别的精确总和。 

由于每个节点都被访问一次，并且每个级别的总和都与全局最大值进行比较，因此该算法可以正确识别具有最大总和的最小级别。 

## Python 解决方案```
from collections import deque
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxLevelSum(self, root: Optional[TreeNode]) -> int:
        queue = deque([root])

        current_level = 1
        best_level = 1
        max_sum = float("-inf")

        while queue:
            level_size = len(queue)
            level_sum = 0

            for _ in range(level_size):
                node = queue.popleft()
                level_sum += node.val

                if node.left:
                    queue.append(node.left)

                if node.right:
                    queue.append(node.right)

            if level_sum > max_sum:
                max_sum = level_sum
                best_level = current_level

            current_level += 1

        return best_level
```实现首先创建一个包含根节点的队列。 队列可以进行层序遍历。 

变量`current_level`,`best_level`， 和`max_sum`跟踪遍历进度和迄今为止找到的最佳答案。 

在主循环内部，`level_size`捕获有多少个节点属于当前级别。 这很重要，因为在迭代过程中会添加新的子节点，而我们只想在每次传递中处理当前级别。 

内循环将节点一一删除，将它们的值添加到`level_sum`，并将任何现有的子项插入队列中以供将来处理。 

完成关卡后，算法会将当前总和与迄今为止看到的最大总和进行比较。 如果当前水平更好，则更新答案变量。 

最后，级别计数器增加并继续遍历，直到处理完所有节点。 

## 解决方案```
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func maxLevelSum(root *TreeNode) int {
    queue := []*TreeNode{root}

    currentLevel := 1
    bestLevel := 1
    maxSum := -(1 << 60)

    for len(queue) > 0 {
        levelSize := len(queue)
        levelSum := 0

        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]

            levelSum += node.Val

            if node.Left != nil {
                queue = append(queue, node.Left)
            }

            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        if levelSum > maxSum {
            maxSum = levelSum
            bestLevel = currentLevel
        }

        currentLevel++
    }

    return bestLevel
}
```Go 实现遵循与 Python 解决方案相同的 BFS 逻辑。 

而不是Python的`deque`，Go 使用切片作为队列。 删除前面的元素是使用以下方法完成的：```
queue = queue[1:]
```Go 使用`nil`检查子节点而不是真实检查。 

变量`maxSum`初始化为一个非常小的负数，以正确处理仅包含负值的树。 

由于约束完全符合 Go 的整数范围，因此整数溢出在这里不是问题。

 该算法执行标准的广度优先搜索遍历。 每个节点只进入和离开队列一次，产生线性时间复杂度。 

空间使用量取决于队列中同时存储的最大节点数。 在完整二叉树的最坏情况下，这可能是大约一半的节点，给出`O(w)`空间复杂度其中`w`是最大树宽度。

 ## 边缘情况

 一个重要的边缘情况是仅包含单个节点的树。 在这种情况下，根既是唯一节点也是唯一级别。 粗心的实现可能会错误地初始化变量或无法正确处理队列。 该解决方案可以自然地处理这种情况，因为 BFS 循环运行一次并返回级别`1`。 

另一个关键情况涉及所有节点值为负的树。 某些实现错误地将最大总和初始化为`0`，这会失败，因为每个级别的总和都小于零。 该实现初始化`max_sum`到负无穷大，确保正确处理负和。 

第三个重要的边缘情况是多个级别共享相同的最大总和。 该问题具体要求返回最小的级别数。 此实现使用严格的更大比较：```
if level_sum > max_sum:
```由于等和不会覆盖之前的答案，因此会自动保留最早的级别。 

高度不平衡的树是错误的另一个潜在来源。 在倾斜树中，高度可以接近节点的数量。 在某些语言中，递归 DFS 解决方案可能会出现堆栈深度问题。 迭代 BFS 解决方案完全避免了递归并安全地处理倾斜树。
