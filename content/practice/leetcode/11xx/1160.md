[LeetCode 第 1160 题](https://leetcode.com/problems/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定给定列表中的哪些单词可以使用另一个字符串中的可用字符来构造，`chars`。 如果一个单词需要的每个字符都存在于`chars`数量充足。 重要的是，其中的人物`chars`**每个单词**只能使用一次，这意味着重复的字母很重要。 

例如，如果`chars = "atach"`一个词是`"cat"`，这个词是有效的，因为字母`c`,`a`， 和`t`全部存在于`chars`。 然而，如果一个词是`"tree"`，它是无效的，因为`"tree"`需要两个`'e'`字符，同时`chars`不包含任何内容。 

输入包括：

 -`words`，小写英文字符串数组。 
-`chars`，包含可用小写英文字符的字符串。 

目标不是返回有效单词本身，而是返回所有好单词的**长度之和**。 

限制相对较小：

 - 至多`1000`字。 
- 每个单词最多有长度`100`。 
-`chars`也有最多长度`100`。 

这些限制表明，有效的基于计数的方法将很容易满足性能要求。 由于字母表仅包含小写英文字母，因此只有`26`可能的字符。 这一观察结果强烈暗示字符频率计数是一个自然的选择。 

预先考虑一些边缘情况很重要。 一个单词可能需要重复的字符，例如`"hello"`需要两个`'l'`字符，因此仅检查字符是否存在是不够的。 有些单词可能比`chars`，使得它们不可能立即形成。 单词可能共享字母，但每个单词都是独立检查的，这意味着不会在所有单词中全局消耗字符。 该问题只保证非空输入和小写英文字母，因此我们不需要处理无效的输入格式或大写字符。 

## 方法

 ### 蛮力方法

 一种简单的方法是逐个字符检查每个单词`chars`。 对于每个单词，我们可以制作一个可变副本`chars`，然后尝试删除匹配的字符。 

例如，要检查`"cat"`反对`"atach"`，我们寻找`'c'`，删除它，搜索`'a'`，删除它，依此类推。 如果在任何时候找不到某个字符，则该单词无效。 

之所以有效，是因为它直接模拟了每个角色只能使用一次的问题要求。 然而，重复搜索和删除字符效率很低。 字符串删除的成本很高，而且重复扫描会使解决方案比必要的速度慢。 

关键的低效之处在于我们为每次查找重复地重新计算字符可用性。 

### 最佳方法

 关键的见解是，真正重要的是**字符频率**，而不是字符顺序。 

而不是反复寻找`chars`，我们首先计算每个字符出现的次数。 然后，对于每个单词，我们计算其字符频率并将它们与中的可用频率进行比较`chars`。 

如果单词中每个字符出现的次数不超过`chars`，该单词是有效的，我们将其长度添加到答案中。 

由于只有`26`小写英文字母，频率比较极其高效。 我们可以使用哈希映射或固定大小的长度数组来表示计数`26`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(宽 × 长 × 厚) | O(C)| 对于每个单词，重复搜索并删除其中的字符`chars`|
 | 最佳| O(宽 × (长 + 26)) | O(26) | 使用字符频率计数进行高效验证 |

 在哪里：

-`W`= 字数
 -`L`= 平均字长
 -`C`= 的长度`chars`自从`26`是常数，最佳方法有效地以相对于总输入大小的线性时间运行。 

## 算法演练

 1. 创建频率计数`chars`。 

我们首先统计每个字母出现的次数`chars`。 由于只允许小写英文字母，因此我们使用大小为的数组`26`，其中索引`0`代表`'a'`， 指数`1`代表`'b'`， 等等。 

此预处理步骤为我们提供了可重复使用的可用字符清单。 
2. 初始化一个变量来存储总长度。 

我们维护一个整数`total_length`，开始于`0`。 每当我们找到一个有效的单词时，我们都会将其长度添加到总数中。 
3. 独立处理每个单词。 

对于其中的每一个词`words`，创建另一个大小的频率数组`26`计算每个字符在该单词中出现的次数。 

这一步是必要的，因为重复的字母很重要。 例如，`"book"`需要两个`'o'`人物。 
4. 将词频与可用频率进行比较。 

检查每一个`26`字符位置。 

如果该词需要的任何字符多于`chars`规定，该词无效，我们立即停止检查。 

如果所有字符数都在限制范围内，则该单词有效。 
5. 添加字长（如果有效）。 

如果该单词通过验证，则添加`len(word)`到`total_length`。 
6. 返回最终答案。 

处理完所有单词后，返回`total_length`。 

### 为什么它有效

 该算法之所以有效，是因为它直接强制执行好单词的定义属性：每个字符都必须存在于`chars`以足够的频率。 

对于每个单词，我们将所需计数与可用计数进行比较。 如果每个所需的计数小于或等于可用计数，则可以准确地形成该单词。 如果哪怕只有一个角色超出了可用范围，建造就变得不可能。 

因为每个单词都是独立检查的，并且所有字符约束都经过验证，所以最终的总和保证是正确的。 

## Python 解决方案```
from typing import List

class Solution:
    def countCharacters(self, words: List[str], chars: str) -> int:
        char_count = [0] * 26

        for ch in chars:
            char_count[ord(ch) - ord('a')] += 1

        total_length = 0

        for word in words:
            word_count = [0] * 26

            for ch in word:
                word_count[ord(ch) - ord('a')] += 1

            is_good = True

            for i in range(26):
                if word_count[i] > char_count[i]:
                    is_good = False
                    break

            if is_good:
                total_length += len(word)

        return total_length
```该实现首先创建一个固定大小的频率数组`chars`。 每个字符根据其字母位置递增相应的索引。 

接下来，我们迭代每个单词。 对于每个单词，我们构建另一个频率数组，表示组成该单词所需的字母。 

计算单词的字符数后，我们将其要求与存储在中的可用库存进行比较`char_count`。 如果任何字符要求超出可用性，我们会将该单词标记为无效并立即停止检查`break`。 

如果该单词通过了所有检查，我们将其长度添加到`total_length`。 

最后，处理完所有单词后，我们返回累积结果。 

## 解决方案```
func countCharacters(words []string, chars string) int {
	charCount := make([]int, 26)

	for _, ch := range chars {
		charCount[ch-'a']++
	}

	totalLength := 0

	for _, word := range words {
		wordCount := make([]int, 26)

		for _, ch := range word {
			wordCount[ch-'a']++
		}

		isGood := true

		for i := 0; i < 26; i++ {
			if wordCount[i] > charCount[i] {
				isGood = false
				break
			}
		}

		if isGood {
			totalLength += len(word)
		}
	}

	return totalLength
}
```Go 的实现与 Python 解决方案非常相似。 由于问题保证小写英文字母，所以长度固定的整数切片`26`用于计算频率。 

Go 特有的一个细节是迭代字符串`range`产生符文。 因为输入的字符都是小写英文字母，所以减去`'a'`安全地生成之间的索引`0`和`25`。 

没有什么特别的`nil`处理问题，因为该问题保证有效的非空输入。 由于约束大小较小，整数溢出也不是问题。

 ## 边缘情况

 ### 含有重复字符的单词

 错误的常见来源是仅检查字符是否存在，而不是验证它出现的次数。 例如，`"hello"`需要两个`'l'`人物。 如果`chars`仅包含一个`'l'`，这个词必须被拒绝。 该实现通过比较频率计数而不是简单的成员资格来正确处理这个问题。 

### 独立检查的单词

 天真的解释可能会错误地消耗所有单词中的全局字符。 例如，如果`chars = "a"`和`words = ["a", "a"]`，这两个词都是有效的，因为每个词都会经过新的检查`chars`。 实现正确重建`word_count`每个词都不会改变`char_count`。 

### 单词长于`chars`一个比这个长的单词`chars`不可能形成。 尽管该算法没有显式检查长度，但它在频率比较期间自然会处理这种情况。 最终，至少有一个字符数超出了可用字符数，导致该单词被拒绝。 

### 完全缺少字符

 有些单词可能需要不存在的字母`chars`根本不。 例如，`"cat"`不能由`"ab"`。 由于不可用字母的计数为`0`在`char_count`，比较立即失败，无需任何特殊处理即可确保正确性。
