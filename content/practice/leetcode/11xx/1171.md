[LeetCode 问题 1171](https://leetcode.com/problems/remove-zero-sum-consecutive-nodes-from-linked-list/)

 **难度：** 🟡 中等
 **主题：** 哈希表、链表

 ## 解决方案

 ## 问题理解

 该问题要求我们重复删除单链表中值总和为零的连续节点。 输入是`head`单链表，其中每个节点都有一个范围内的整数值`-1000`到`1000`，列表长度范围为1到1000个节点。 输出应该是删除所有零和连续序列后修改后的链表的头。 

简单来说，想象一下沿着链表行走并跟踪连续节点的总和。 如果在任何时候总和达到零，则应删除该序列中的所有节点。 重复此过程，直到不存在这样的序列为止。 该问题保证了非空链表和整数值，因此我们不必处理空输入或非整数节点。 

重要的边缘情况包括列表开头或结尾的序列、重叠的序列、只有一个节点具有值的序列`0`，以及整个列表总和为零的情况。 

## 方法

 暴力方法将迭代每个可能的连续子列表并检查其总和是否为零。 对于每个节点，我们将其前面的所有连续节点相加，如果总和为零，我们通过调整指针来删除该子列表。 这种方法是正确的，但效率低下，因为检查所有可能的子列表需要嵌套迭代，导致时间复杂度为 O(n²)，对于最大输入大小 1000 来说速度很慢。 

最佳方法利用带有哈希映射的**前缀和**。 关键的见解是，如果从开始到节点的节点总和`i`是`S`以及节点的总和`j`也是`S`，那么之间的节点`i`和`j`总和为零。 通过将每个前缀和的最后一次出现存储在哈希映射中，我们可以一次性直接跳过零和序列。 此方法使用单次传递并仔细更新指针，并以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 迭代检查所有连续序列并删除零和序列 |
 | 最佳| O(n) | O(n) | 使用前缀和和哈希图有效删除零和序列 |

 ## 算法演练

 1. 在链表的开头引入一个虚拟节点，以简化序列从头部开始的边缘情况。 初始化`prefix_sum = 0`并创建一个空的哈希图`sum_to_node`存储每个前缀和的最后一个节点。 
2. 迭代链表。 对于每个节点，更新`prefix_sum`通过添加节点的值。 如果`prefix_sum`以前曾见过`sum_to_node`，这表示前一个节点和当前节点之间的所有节点之和为零。 
3. 要删除零和节点，请调整`next`前一个节点（存储在哈希映射中）的指针以跳过零和子序列。 此外，从哈希映射中删除所有中间前缀和以保持正确性。 
4. 如果`prefix_sum`以前没有见过，将其添加到以当前节点为值的哈希映射中。 
5、遍历完列表后，返回`dummy.next`作为修改后的列表的新头。 

**为什么起作用：** 前缀和不变量保证任何连续序列的总和为零对应于累积和中的重复。 通过存储每个前缀和的最后一次出现，该算法确保在一次线性传递中跳过任何零和序列。 

## Python 解决方案```python
from typing import Optional

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeZeroSumSublists(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        dummy.next = head
        prefix_sum = 0
        sum_to_node = {0: dummy}
        current = head
        
        while current:
            prefix_sum += current.val
            if prefix_sum in sum_to_node:
                prev = sum_to_node[prefix_sum]
                node = prev.next
                temp_sum = prefix_sum
                # Remove intermediate sums
                while node != current:
                    temp_sum += node.val
                    if temp_sum in sum_to_node:
                        del sum_to_node[temp_sum]
                    node = node.next
                prev.next = current.next
            else:
                sum_to_node[prefix_sum] = current
            current = current.next
        
        return dummy.next
```Python 实现紧密遵循该算法。 虚拟节点处理头部的边缘情况。 这`sum_to_node`哈希图跟踪前缀和，并且我们在跳过零和序列时删除中间和以防止与未来节点发生冲突。 该算法仅迭代链表一次，实现线性时间复杂度。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func removeZeroSumSublists(head *ListNode) *ListNode {
    dummy := &ListNode{0, head}
    sumToNode := map[int]*ListNode{0: dummy}
    prefixSum := 0
    for current := head; current != nil; current = current.Next {
        prefixSum += current.Val
        if prev, exists := sumToNode[prefixSum]; exists {
            node := prev.Next
            tempSum := prefixSum
            for node != current {
                tempSum += node.Val
                delete(sumToNode, tempSum)
                node = node.Next
            }
            prev.Next = current.Next
        } else {
            sumToNode[prefixSum] = current
        }
    }
    return dummy.Next
}
```在 Go 中，逻辑几乎相同。 Nil 处理是 Go 指针固有的，而映射操作用于存储前缀和。 删除中间和可确保未来迭代的正确性。 

## 工作示例

 ### 示例 1：`[1,2,-3,3,1]`初始列表：1→2→-3→3→1

 1. prefix_sum = 1 → 存储{1:node1}
 2. prefix_sum = 3 → 存储{3:node2}
 3. prefix_sum = 0 → 之前在 dummy 看到的 → 节点 1→2→-3 总和为 0 → 删除它们
 4.列表变为3→1，前缀和相应更新
 5. 到达列表末尾

 输出：`[3,1]`### 示例 2：`[1,2,3,-3,4]`1. prefix_sum = 1 → 存储
 2. prefix_sum = 3 → 存储
 3. prefix_sum = 6 → 存储
 4. prefix_sum = 3 → 之前在带有 prefix_sum 3 的节点处看到 → 节点 3 → -3 被删除
 5.列表变为1→2→4

 输出：`[1,2,4]`### 示例 3：`[1,2,3,-3,-2]`1. prefix_sum = 1 → 存储
 2. prefix_sum = 3 → 存储
 3. prefix_sum = 6 → 存储
 4. prefix_sum = 3 → 之前见过 → 删除 3 → -3
 5. prefix_sum = 1 → 之前见过 → 删除 2 → -2
 6.列表变为1

 输出：`[1]`## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点被访问一次，哈希图操作平均为 O(1) |
 | 空间| O(n) | 哈希映射存储最坏情况下所有节点的前缀和 |

 线性时间复杂度来自于链表的单次遍历，而哈希图则确保恒定时间访问先前看到的前缀和。 空间复杂度是线性的，因为在最坏的情况下，不存在零和序列并且存储所有前缀和。
