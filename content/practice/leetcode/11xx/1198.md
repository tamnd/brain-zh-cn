 ## 解决方案

 ## 问题理解

 该问题要求我们找到出现在给定的**每一行**中的最小元素`m x n`矩阵`mat`，其中每一行都按严格升序排序。 换句话说，我们需要一个所有行共有的元素，并且是所有此类元素中的最小值。 

输入`mat`是一个二维整数数组`m`行和`n`列。 每行严格递增，确保行内没有重复元素，并且行中的值按从小到大排序。 输出是一个整数：所有行中出现的最小元素，或者`-1`如果不存在这样的元素。 

这些约束对于理解潜在的解决方案很重要。 两个都`m`和`n`最多可以达到 500，这意味着针对每一行检查每个元素的简单暴力方法可能会太慢。 矩阵中的数字范围为`1`到`10^4`，因此我们可以在某些计数或基于哈希的方法中利用这个有界范围。 

关键边缘情况包括没有公共元素的矩阵、只有一行或一列的矩阵以及最小元素不在每行第一列的矩阵。 

## 方法

 暴力方法将迭代第一行中的每个元素，并检查它是否存在于所有其他行中。 这可以正常工作，因为它系统地测试每个候选人，但效率低下。 如果我们在剩余的每个中执行线性搜索`m-1`对于第一行中的每个元素，时间复杂度变为`O(n * m * n)`可以达到`O(500 * 500 * 500) = 125,000,000`操作对于大量输入来说可能太慢。 

允许更好的解决方案的关键观察是每一行都被**排序**。 正因为如此，我们可以执行更有效的搜索。 一种最佳方法使用哈希表（或计数数组）来计算每个数字出现的行数。我们只需要跟踪可能是常见的候选数字。 由于数字的上限为`10^4`，我们可以维护一个频率计数器并扫描第一行以按升序迭代。 另一种方法是使用多个指针（每行一个）来跟踪候选者并有效地向前移动指针，从而有效地合并已排序的行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m * n) | O(n * m * n) | O(1) | O(1) | 使用线性搜索检查第一行中的每个元素与所有其他行 |
 | 最优（计数/哈希）| O(m * n) | O(10^4) | O(10^4) | 计算每个数字的出现次数，并使用 count = m | 选择最小的数字

 ## 算法演练

 1.初始化一个字典（或数组）`count`存储所有行中每个元素的频率。 
2. 迭代矩阵中的每一行。 
3. 对于行中的每个元素，如果当前行尚未对它进行计数，则增加其在字典中的计数。 
4. 处理完所有行后，按排序顺序迭代键（或按顺序迭代第一行）并返回 count 等于的第一个元素`m`。 
5. 如果没有元素的计数等于`m`， 返回`-1`。 

原理：通过计算每个元素出现的行数，我们可以直接确定哪些元素是所有行共有的。 按顺序排序或迭代可以保证我们首先找到最小的元素。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestCommonElement(self, mat: List[List[int]]) -> int:
        m = len(mat)
        count = defaultdict(int)
        
        for row in mat:
            for num in row:
                if count[num] < m:  # only increment once per row
                    count[num] += 1
        
        for num in sorted(mat[0]):
            if count[num] == m:
                return num
        return -1
```Python 实现创建一个频率字典来跟踪各行中每个数字的出现情况。 支票`count[num] < m`确保我们每行只增加一次，避免重复计数（尽管行严格增加，这是安全的）。 最后，按顺序迭代第一行可确保我们返回最小的公共元素。 

## 解决方案```go
func smallestCommonElement(mat [][]int) int {
    m := len(mat)
    count := make(map[int]int)
    
    for _, row := range mat {
        for _, num := range row {
            if count[num] < m {
                count[num]++
            }
        }
    }
    
    for _, num := range mat[0] {
        if count[num] == m {
            return num
        }
    }
    
    return -1
}
```在 Go 中，我们使用`map[int]int`跟踪计数。 迭代第一行可确保首先检查最小的候选者。 不需要排序，因为第一行已经排序，保留了顺序。

 ## 边缘情况

 一种边缘情况是矩阵**没有公共元素**。 天真的解决方案可能会错误地假设第一个元素是公共的，但我们的实现会检查计数并正确返回`-1`。 

另一个边缘情况是**单行**。 该行中的任何元素对于所有行来说都是普通的（因为只有一个）。 我们的解决方案可以解决这个问题，因为`count[num] == m`将自动满足第一个元素。 

第三种边缘情况是**约束边界处有大量数字**。 因为我们的频率字典使用实际数字作为键，所以它可以正确处理元素
