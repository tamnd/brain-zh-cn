 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定格式的日期的一年中的序数`YYYY-MM-DD`。 例如，1 月 1 日始终是第 1 天，1 月 2 日是第 2 天，12 月 31 日是第 365 天或第 366 天，具体取决于年份是否为闰年。 输入是一个严格遵循以下规则的字符串`YYYY-MM-DD`格式，它表示 1900 年 1 月 1 日到 2019 年 12 月 31 日之间的有效公历日期。输出是一个整数，表示该日期是一年中的第几天。 

约束保证输入有效，因此我们不需要处理无效日期或格式错误的字符串。 重要的边缘情况包括月份边界上的日期，特别是闰年的 2 月 28 日和 29 日，以及一年中的最后一天 12 月 31 日。 

## 方法

 蛮力方法是从 1 月 1 日迭代到给定日期，每天计数。 虽然这会给出正确的结果，但没有必要，因为每个月的天数是固定的（闰年的二月除外）。 这种方法相对于一年中的某一天具有线性时间复杂度，与直接计算相比效率较低。 

最佳方法利用两个见解：首先，我们可以在每个月初预先计算累计天数； 其次，我们需要考虑闰年，即为二月增加一天。 有了这两条信息，我们就可以直接计算出天数，方法是将当月的天数与前几个月的累计天数相加，并在必要时调整闰年。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N) | O(1) | O(1) | 计算从 1 月 1 日到给定日期的天数 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 使用预先计算的月份偏移和闰年调整 |

 ## 算法演练

 1. 解析输入的日期字符串，以整数形式提取年、月、日。 这使我们能够对组件进行算术和比较。 
2. 创建非闰年每个月初的累积天数列表：`[0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334]`。 这表示每月第一天之前的总天数。 
3. 计算该年份是否为闰年。 如果一年能被 4 整除，那么它就是闰年，能被 100 整除的年份除外，除非它也能被 400 整除。 
4. 通过将当月的日期与当月之前的累计天数相加来计算天数。 
5. 如果日期在闰年的 2 月之后，则将天数加 1 以表示 2 月 29 日。 
6. 返回最后一天的数字。 

**为什么有效：** 通过使用累积天数并调整闰年，我们可以保证从年初开始的正确天数。 该算法仅使用算术运算和小型查找表，因此既正确又高效。 

## Python 解决方案```python
class Solution:
    def dayOfYear(self, date: str) -> int:
        year, month, day = map(int, date.split('-'))
        days_before_month = [0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334]
        
        day_of_year = days_before_month[month - 1] + day
        
        # Check for leap year
        if month > 2 and ((year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)):
            day_of_year += 1
        
        return day_of_year
```Python 实现完全遵循该算法。 我们首先将日期字符串拆分为年、月、日的整数。 使用每个月之前预先计算的累积天数列表，我们计算出初步的天数。 然后，我们检查该年份是否为闰年，以及该月份是否在二月之后，如有必要，添加一天。 最后，我们返回计算出的天数。 

## 解决方案```go
func dayOfYear(date string) int {
    var year, month, day int
    fmt.Sscanf(date, "%d-%d-%d", &year, &month, &day)
    
    daysBeforeMonth := [12]int{0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334}
    dayOfYear := daysBeforeMonth[month-1] + day
    
    isLeap := (year%4 == 0 && year%100 != 0) || (year%400 == 0)
    if month > 2 && isLeap {
        dayOfYear++
    }
    
    return dayOfYear
}
```在 Go 中，我们使用`fmt.Sscanf`将日期字符串解析为整数。 我们使用固定大小的数组来表示累积天数，类似于 Python。 闰年处理是相同的，并且结果以整数形式返回。 Go 需要显式数组类型，并避免小型固定数据的动态列表，这就是我们使用数组而不是切片的原因。

 ## 边缘情况

 一个重要的边缘情况是闰年的 2 月 29 日。 如果闰年逻辑不正确，二月之后的日期的天数将减少一位。 我们的实现会在添加额外的一天之前检查年份是否为闰年以及月份是否大于 2，以确保正确性。
