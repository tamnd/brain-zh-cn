 ## 解决方案

 ## 问题理解

 问题是要求我们计算列表中所有等价的多米诺骨牌对，其中两个多米诺骨牌`[a, b]`和`[c, d]`如果一个是另一个的旋转，则被认为是等效的，这意味着`(a == c and b == d)`或者`(a == d and b == c)`。 换句话说，数字的顺序并不重要 -`[1,2]`相当于`[2,1]`。 

输入是多米诺骨牌列表，其中每个多米诺骨牌表示为 1 到 9 之间的两个整数的列表。输出是单个整数，表示对的数量`(i, j)`和`i < j`这样索引处的多米诺骨牌`i`和`j`是等价的。 约束条件允许最多 40,000 个多米诺骨牌，因此复杂度为 O(n²) 的解决方案会太慢。 

重要的边缘情况包括多次出现的多米诺骨牌、具有相同数字的多米诺骨牌，例如`[1,1]`，并确保我们不会重复计算对。 

## 方法

 暴力方法会比较每对多米诺骨牌。 对于每张多米诺骨牌`i`，我们将迭代所有多米诺骨牌`j > i`并检查它们是否相等。 这保证了正确性，因为我们明确地检查每一对，但它的时间复杂度为 O(n²)，这对于像这样的大输入是不切实际的`n = 40,000`。 

最佳方法利用了关键观察结果，即每个多米诺骨牌都可以标准化为规范形式。 通过始终按排序顺序存储多米诺骨牌（数字较小的优先），我们确保`[1,2]`和`[2,1]`两者都成为`[1,2]`。 然后我们可以使用哈希图来计算每个规范形式出现的次数。 如果出现特定形式`k`次，该形式的对数是`k * (k - 1) / 2`。 这将问题降低到 O(n) 时间复杂度和 O(n) 空间复杂度。

 ## 算法演练

 1. 初始化一个空的哈希图（`count_map`）来跟踪每个规范多米诺骨牌出现的次数。 
2. 初始化变量`total_pairs`到 0，这将累加最终计数。 
3. 迭代输入列表中的每个多米诺骨牌。 对于每个多米诺骨牌，对两个数字进行排序以形成规范密钥。 
4. 如果密钥存在于`count_map`，这意味着我们以前见过这个多米诺骨牌。 增量`total_pairs`通过该键的当前计数，因为之前的每个出现都与当前的多米诺骨牌形成一个新的对。 
5. 增加此规范键的计数`count_map`。 
6.处理完所有多米诺骨牌后，返回`total_pairs`。 

**为什么有效：** 无论旋转如何，每个多米诺骨牌都会简化为唯一的规范表示。 计算每个多米诺骨牌先前出现的次数可确保所有有效对都被精确计数一次，满足要求`i < j`。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def numEquivDominoPairs(self, dominoes: List[List[int]]) -> int:
        count_map = defaultdict(int)
        total_pairs = 0
        
        for domino in dominoes:
            key = tuple(sorted(domino))
            total_pairs += count_map[key]
            count_map[key] += 1
        
        return total_pairs
```该实现首先创建一个`defaultdict`计算每个规范的多米诺骨牌形式。 对于每个多米诺骨牌，它对数字进行排序以处理轮换，并检查到目前为止该形式出现的次数。 之前的每一次出现都会贡献一对新的。 最后，它返回对的总数。 

## 解决方案```go
func numEquivDominoPairs(dominoes [][]int) int {
    countMap := make(map[[2]int]int)
    totalPairs := 0
    
    for _, domino := range dominoes {
        key := [2]int{domino[0], domino[1]}
        if domino[0] > domino[1] {
            key = [2]int{domino[1], domino[0]}
        }
        totalPairs += countMap[key]
        countMap[key]++
    }
    
    return totalPairs
}
```在 Go 中，我们使用带有数组键的映射`[2]int`存储规范的多米诺骨牌。 排序是通过条件交换手动完成的。 每张多米诺骨牌都有助于`totalPairs`基于其规范形式先前出现的次数。 Go 本身将数组作为映射键来处理，因此工作效率很高。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 一种边缘情况是只有一个多米诺骨牌。 由于没有其他多米诺骨牌可以配对，因此该函数必须正确返回 0。我们的解决方案可以处理此问题，因为循环永远找不到先前的计数。 

另一种边缘情况是所有多米诺骨牌都相同或彼此旋转。 该算法必须正确计算所有对，不得重复计算。 通过在增加计数之前将总对增加规范形式的当前计数，我们确保所有有效对都只包含一次。
