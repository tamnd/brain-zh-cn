[LeetCode 第 1102 题](https://leetcode.com/problems/path-with-maximum-minimum-value/)

 **难度：** 🟡 中等
 **主题：** 数组、二分搜索、深度优先搜索、广度优先搜索、联合查找、堆（优先级队列）、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们从左上角找到一条路径的最大可能**分数**`(0, 0)`到右下角`(m-1, n-1)`二维网格。 网格中的每个单元格都包含一个整数值，路径的分数定义为**沿该路径的最小值**。 换句话说，如果一条路径经过数字`[8, 4, 5, 9]`，该路径的得分为`4`因为它是该路径上最小的数字。 

输入是一个`m x n`整数矩阵`grid`，我们可以在四个基本方向上移动（上、下、左、右）。 目标是找到**最大化沿路径**的最小值的路径。 

约束表明`m`和`n`最多可达100个，每个网格值可达10亿。 因此，探索每条路径的简单解决方案在计算上是不可行的。 要考虑的边缘情况包括具有最小可能值的网格（`0`) 或者最大最小值位于不遵循明显高值单元格的路径上。 

重要的保证包括网格总是至少有一个单元格，并且我们总是可以到达目的地，因为网格是有限的并且是连通的。 

## 方法

 一种蛮力方法是探索**所有可能的路径**`(0, 0)`到`(m-1, n-1)`并计算每条路径上的最小值。 然后，我们将选择这些最小值中的最大值。 这在理论上是正确的，但在计算上是不可行的，因为路径的数量随着网格大小呈指数增长，特别是`O(4^(m*n))`。 

最佳解决方案的关键见解是我们**不需要显式计算每条路径**。 相反，我们可以使用 **基于优先级的搜索**，例如 **最大堆 BFS** 或 **Union-Find 方法**。 这个想法是优先访问具有较高值的​​单元格。 在最大堆 BFS 中，我们总是用可用的最大值扩展当前单元，确保沿路径的最小值尽可能高。 这种方法保证了我们第一次到达右下角单元格时，我们就找到了最大的最小分数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(4^(m*n)) | O(4^(m*n)) | O(m*n) | 探索所有路径并计算每条路径的最小值 |
 | 最优（最大堆 BFS）| O(m_n_log(m*n)) | O(m_n_log(m*n)) | O(m*n) | 使用优先级队列首先扩展最高价值的路径 |

 ## 算法演练

 1. 以起始单元初始化最大堆（优先级队列）`(0, 0)`及其价值。 堆存储元组`(value, row, col)`，我们否定`value`因为大多数堆实现都是最小堆。 
2. 创建一个`visited`矩阵来跟踪哪些单元格已经被处理。 
3. 初始化变量`score`当我们遍历时跟踪路径上的最小值。 
4. 当堆不为空时，弹出具有最大值的单元格。 
5. 更新`score`作为电流的最小值`score`和单元格的值。 
6. 如果我们到达右下角的单元格`(m-1, n-1)`， 返回`score`因为这是最大堆属性导致的最大最小路径。 
7. 对于每个相邻单元格（上、下、左、右），如果它在边界内并且未被访问，则将其标记为已访问并将其推入堆中。 
8. 继续前进，直至到达目的地。 

**为什么有效**：通过始终首先扩展最大的可用单元格，首先到达右下角的路径将具有最大可能的最小值。 较低值的路径将被忽略，因为它们无法产生更高的最小值。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def maximumMinimumPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        max_heap = [(-grid[0][0], 0, 0)]
        visited = [[False]*n for _ in range(m)]
        visited[0][0] = True
        score = grid[0][0]

        directions = [(0,1),(1,0),(-1,0),(0,-1)]

        while max_heap:
            value, x, y = heapq.heappop(max_heap)
            value = -value
            score = min(score, value)
            if x == m-1 and y == n-1:
                return score
            for dx, dy in directions:
                nx, ny = x+dx, y+dy
                if 0 <= nx < m and 0 <= ny < n and not visited[nx][ny]:
                    visited[nx][ny] = True
                    heapq.heappush(max_heap, (-grid[nx][ny], nx, ny))
```**实现演练**：我们使用起始单元初始化最大堆。 这`visited`矩阵防止循环。 在每一步中，我们都会从堆中弹出最高值的单元格并更新`score`跟踪路径上的最小值。 第一次到达目的地的时候，`score`反映最大最小值，因为算法总是首先探索最大的可用选项。 

## 解决方案```go
package main

import (
    "container/heap"
)

type Cell struct {
    value, x, y int
}

type MaxHeap []Cell

func (h MaxHeap) Len() int { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i].value > h[j].value }
func (h MaxHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(v interface{}) { *h = append(*h, v.(Cell)) }
func (h *MaxHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

func maximumMinimumPath(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    visited := make([][]bool, m)
    for i := range visited {
        visited[i] = make([]bool, n)
    }
    h := &MaxHeap{{grid[0][0], 0, 0}}
    heap.Init(h)
    visited[0][0] = true
    score := grid[0][0]

    dirs := [][]int{{0,1},{1,0},{0,-1},{-1,0}}

    for h.Len() > 0 {
        cell := heap.Pop(h).(Cell)
        score = min(score, cell.value)
        if cell.x == m-1 && cell.y == n-1 {
            return score
        }
        for _, d := range dirs {
            nx, ny := cell.x + d[0], cell.y + d[1]
            if nx >= 0 && nx < m && ny >= 0 && ny < n && !visited[nx][ny] {
                visited[nx][ny] = true
                heap.Push(h, Cell{grid[nx][ny], nx, ny})
            }
        }
    }
    return score
}

func min(a, b int) int {
    if a < b { return a }
    return b
}
```**Go 特定注释**：Go 需要自定义`MaxHeap`实施使用`container/heap`。 与 Python 不同，Go 没有内置的最大堆，因此我们反转比较。 我们还明确定义了一个`Cell`结构体来存储坐标和值。 切片用于`visited`和方向。 

## 工作示例

 **示例1**：`grid = [[5,4,5],[1,2,6],[7,4,6]]`一步一步：

 | 步骤| 堆（值，x，y）| 分数 | 行动|
 | ---| ---| ---| ---|
 | 1 | [(5,0,0)] | 5 | 弹出启动单元|
 | 2 | [(4,0,1),(1,1,0)] | 最小值(5,5)=5 | 推邻居|
 | 3 | [(4,0,1),(1,1,0)] | 最小值(5,4)=4 | 流行 (0,1) |
 | 4 | [...] | ... | 继续扩展直到 (2,2) |
 | 决赛| 达到 (2,2) | 4 | 找到最大最小路径|

 **示例 2** 和 **示例 3** 遵循类似的步骤，始终首先扩展最高值的单元格。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(m_n_log(m*n)) | O(m_n_log(m*n)) | 每个单元格都会从堆中推送/弹出一次； 堆操作是 O(log(m*n)) |
 | 空间| O(m*n) | 这`visited`矩阵和堆最多可以存储所有单元|

 该算法是高效的，因为它避免了探索具有较小值的不必要路径，并保证到达目的地的第一条路径具有最大最小值。
