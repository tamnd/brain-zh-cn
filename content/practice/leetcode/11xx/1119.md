 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们从给定的字符串中删除元音`s`。 具体来说，元音被定义为小写字符`'a'`,`'e'`,`'i'`,`'o'`， 和`'u'`。 输入字符串仅由小写英文字母组成，长度范围为 1 到 1000。预期输出是包含以下所有原始字符的字符串`s`除元音外，保留辅音的原始顺序。 

限制相当小：最多 1000 个字符意味着即使是简单的迭代解决方案也能高效运行。 边缘情况包括全是元音的字符串、没有元音的字符串以及只有单个字符的字符串。 例如，如果假设至少有一个辅音，这些边缘情况很容易使幼稚的实现出错。 

## 方法

 暴力方法将迭代字符串中的每个字符，并针对每个字符检查它是否是元音。 如果它不是元音，我们将它附加到一个新字符串中。 这种方法工作正常，但它涉及可以优化的重复成员资格测试。 

最佳方法使用一组来存储元音。 通过使用集合，每个字符的成员资格检查变为 O(1)。 然后，我们迭代该字符串一次，构建一个不包括元音的新字符串（或字符列表）。 这种方法简单、高效，并利用简单的 Python 或 Go 习惯用法来构建字符串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n) | 根据元音列表检查每个字符（m = 元音数量，5） |
 | 最佳 | O(n) | O(n) | 使用集合进行 O(1) 成员资格检查并增量构建结果 |

 ## 算法演练

 1. 创建一个包含所有元音的集合：`{'a', 'e', 'i', 'o', 'u'}`。 这允许对每个字符进行 O(1) 成员资格检查。 
2. 初始化一个空列表来存储结果字符。 
3. 迭代输入字符串中的每个字符。 
4. 对于每个字符，检查它是否**不在**元音集中。 
5. 如果不是元音，则将其添加到结果列表中。 
6. 处理完所有字符后，将列表连接成单个字符串。 
7. 返回结果字符串。 

工作原理：该算法保证原始字符串中的每个字符都被检查一次，并且只保留非元音字符。 使用集合可以确保有效的元音检查，并且构造新字符串可以保留辅音的顺序。 

## Python 解决方案```
class Solution:
    def removeVowels(self, s: str) -> str:
        vowels = {'a', 'e', 'i', 'o', 'u'}
        result = []
        for char in s:
            if char not in vowels:
                result.append(char)
        return ''.join(result)
```Python 实现直接遵循该算法。 我们首先定义一组元音，然后初始化一个空列表`result`积累辅音。 对于字符串中的每个字符，我们检查它是否不是元音，并将其附加到`result`如果通过测试。 最后，`''.join(result)`将列表连接成单个字符串以返回。 

## 解决方案```
func removeVowels(s string) string {
    vowels := map[rune]bool{
        'a': true,
        'e': true,
        'i': true,
        'o': true,
        'u': true,
    }
    result := []rune{}
    for _, char := range s {
        if !vowels[char] {
            result = append(result, char)
        }
    }
    return string(result)
}
```在 Go 中，我们使用`map[rune]bool`存储元音以进行 O(1) 成员资格检查。 使用 a 迭代该字符串`for _, char := range s`循环将每个字符作为符文处理。 非元音字符被附加到一段符文中，然后使用以下命令将其转换回字符串`string(result)`。

 ## 边缘情况

 一种边缘情况是完全由元音组成的字符串，例如`"aeiou"`。 这测试实现是否正确返回空字符串而不是意外插入占位符字符。 我们的解决方案通过仅将非元音附加到结果列表中来自然地处理这个问题。 

第二种边缘情况是完全由辅音组成的字符串。 这测试算法不会删除有效字符。 使用集合成员资格检查可确保保留所有辅音，因为它们永远不会出现在元音集中。 

第三种边缘情况是单字符字符串，可以是元音或辅音。 这对于确保算法处理最小输入大小而不会出现错误非常重要，并且我们的实现根据字符是否为元音正确返回相同字符或空字符串。
