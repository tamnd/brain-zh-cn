[LeetCode 第 1123 题](https://leetcode.com/problems/lowest-common-ancestor-of-deepest-leaves/)

 **难度：** 🟡 中等
 **主题：** 哈希表、树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到二叉树中所有最深叶节点的最低公共祖先（缩写为 LCA）。 

叶节点是没有子节点的任何节点。 根的深度为`0`，每层向下都会增加深度`1`。 因此，最深的叶子是位于树中最大深度的叶节点。 

一组节点的最低公共祖先是树中最深的节点，该树包含其子树内的所有这些节点。 节点被视为其自身子树的一部分，因此如果只有一个最深的叶子，则该叶子本身就是答案。 

The input is the root of a binary tree. 输出应该是代表所有最深叶子的 LCA 的实际树节点。 

For example, consider this tree:```
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```最深的叶子是`7`和`4`，都在深度`3`。 它们的最低共同祖先是节点`2`， 因为`2`是其子树包含两个叶子的最深节点。 

约束条件相对较小，最多`1000`节点。 这意味着即使是相当昂贵的方法也可以通过，但这个问题强烈表明存在一个干净的深度优先搜索解决方案。 

一些边缘情况很重要：

 - 一棵只有一个节点的树，根既是最深的叶子，也是答案。 
- 一棵完全倾斜的树，最深的叶子完全位于一侧。 
- 多个最深的叶子分布在左右子树上。 
- 一侧比另一侧更深的子树，这意味着答案应该从较深的一侧而不是当前节点向上传播。 

由于所有节点值都是唯一的，因此我们在识别节点时无需担心歧义。 

## 方法

 ### 蛮力方法

 强力解决方案首先确定树的最大深度，然后收集该深度的所有叶节点。 收集最深的叶子后，我们可以重复计算成对的 LCA，直到只剩下一个节点。 

一种可能的实现是：

 1. 执行 DFS 或 BFS 来计算最大深度。 
2. 再次遍历以收集所有最深的叶子。 
3. 对于每对最深的叶子，使用父指针或递归遍历计算它们的 LCA。 
4. 减少集合直到剩下一个共同祖先。 

这种方法之所以有效，是因为 LCA 操作被明确定义，并且成对组合 LCA 最终会产生整个集合的共同祖先。 

然而，该解决方案效率低下，因为每个 LCA 计算可能需要重复遍历树的大部分。 如果有很多最深的叶子，重复的搜索就会变得不必要的昂贵。 

### 最佳方法

 关键的见解是我们可以在单个后序 DFS 遍历期间同时计算最深深度和正确的祖先。 

对于每个节点，我们要求：

 - 从该节点可到达的最深深度是多少？ 
- 哪个节点是该子树中最深叶子的 LCA？ 

递归逻辑变得优雅：

 - 如果左右子树的最大深度相同，则当前节点是其下方最深叶子的LCA。 
- 如果一侧更深，那么答案必须完全位于该更深的子树中。 

这是很自然的，因为递归在处理父母之前处理孩子，这与 LCA 问题的结构相匹配。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N²) | O(N) | 多次遍历和重复LCA计算|
 | 最佳| O(N) | O(H) | 单次 DFS 遍历同时返回深度和祖先 |

 这里，`N`是节点数，`H`是树的高度。 

## 算法演练

 1. 定义一个每次处理一颗子树的递归 DFS 函数。 

该函数应返回两个值：

 - 当前子树中最深叶子的深度
 - 当前子树中所有最深叶子的LCA
 2. 处理空节点的基本情况。 

空子树没有深度，也没有祖先。 我们可以返回：```
depth = 0
ancestor = null
```3. 递归处理左子树。 

递归调用给出：

 - 左侧可达到的最大深度
 - 左侧最深叶子的 LCA
 4. 递归处理右子树。 

同样，我们得到：

 - 右侧可达到的最大深度
 - 右侧最深叶子的 LCA
 5. 比较左右深度。 

分三种情况：

 - 如果左深度更大，则最深的叶子完全存在于左子树中。 返回左祖。 
- 如果右深度更大，则最深的叶子完全存在于右子树中。 返回正确的祖先。 
- 如果深度相等，则两侧都有最深的叶子。 当前节点成为它们的最低共同祖先。 
6. 返回之前，将深度增加一倍。 

由于当前节点位于其子节点之上一级，因此我们随着递归向上展开而增加深度。 
7. 从根开始DFS，返回结果的祖先分量。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 > 对于每个子树，递归函数正确返回该子树内的最深深度以及其中包含的所有最深叶子的 LCA。 

如果两棵子树的深度相等，则两边都存在最深的叶子，因此当前节点一定是连接它们的最低节点。 如果一棵子树更深，则所有最深的叶子完全位于该子树内部，因此其祖先仍然有效。 由于递归在处理父节点之前处理子节点，因此每个节点都使用已经正确的子树信息做出决策。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional, Tuple

class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        
        def dfs(node: Optional[TreeNode]) -> Tuple[int, Optional[TreeNode]]:
            if not node:
                return 0, None
            
            left_depth, left_lca = dfs(node.left)
            right_depth, right_lca = dfs(node.right)
            
            if left_depth > right_depth:
                return left_depth + 1, left_lca
            
            if right_depth > left_depth:
                return right_depth + 1, right_lca
            
            return left_depth + 1, node
        
        return dfs(root)[1]
```实现直接遵循递归策略。 

这`dfs`函数返回一个元组，其中包含：

 - 从当前节点可达的最大深度
 - 该子树中最深叶子的 LCA

 基本情况通过返回深度来处理空节点`0`并且没有祖先。 

对于每个非空节点，该算法递归地计算左右子节点的信息。 获得两个结果后，它比较子树深度。 

如果一棵子树更深，则最深的叶子必须完全位于那里，因此相应的 LCA 向上传播不变。 

如果两个深度相等，则两个子树中都存在最深的叶子，这意味着当前节点是它们相遇的第一个点。 因此，当前节点成为LCA。 

最后，主函数仅返回根调用的祖先部分。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func lcaDeepestLeaves(root *TreeNode) *TreeNode {

    var dfs func(node *TreeNode) (int, *TreeNode)

    dfs = func(node *TreeNode) (int, *TreeNode) {
        if node == nil {
            return 0, nil
        }

        leftDepth, leftLCA := dfs(node.Left)
        rightDepth, rightLCA := dfs(node.Right)

        if leftDepth > rightDepth {
            return leftDepth + 1, leftLCA
        }

        if rightDepth > leftDepth {
            return rightDepth + 1, rightLCA
        }

        return leftDepth + 1, node
    }

    _, lca := dfs(root)
    return lca
}
```Go 实现密切反映了 Python 逻辑。 

Go 函数自然返回多个值，而不是元组。 递归助手返回一个整数深度和一个指向祖先节点的指针。 

Go 使用`nil`而不是Python的`None`对于缺失的节点。 由于问题约束很小，因此递归深度是安全的，并且不需要特殊的堆栈处理。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N) | 每个节点都被访问一次 |
 | 空间| O(H) | 递归调用栈最多存储一条从根到叶的路径 |

 该算法执行单次 DFS 遍历。 每个节点都贡献持续的工作，主要包括比较子树深度和选择正确的祖先。 因此，总运行时间与节点数量呈线性关系。 

空间复杂度完全来自于递归。 在倾斜树的最坏情况下，递归深度变为`N`。 在平衡树中，它仍然是`O(log N)`。

 ## 边缘情况

 ### 单节点树

 仅包含根节点的树是重要的边界条件。 幼稚的实现可能会错误地返回`None`因为没有可以比较的子节点。 在此实现中，当两个子树深度等于零时，叶节点返回自身作为祖先，因此正确返回根。 

### 完全倾斜的树

 在一棵形状像链表的树中，所有节点只有一个子节点。 最深的叶子是唯一的，所以答案应该是那片叶子本身。 一些不正确的解决方案错误地返回根，因为它们假设祖先必须涉及多个分支。 此实现正确地向上传播最深的子树祖先不变。 

### 不同子树上的多个最深叶子

 当最深的叶子同时存在于节点的左侧和右侧时，该节点成为真正的最低共同祖先。 这是问题的核心场景。 该实现通过检查左右深度何时相等并返回当前节点来处理它。 

### 最深的叶子完全位于一个子树内

 当两个最深的叶子完全包含在一个子树中时，就会出现一种微妙的情况。 当前节点不应该仅仅因为它连接了整棵树就成为祖先。 通过比较子树深度，该算法正确地忽略较浅的分支并保留较深的子树的祖先结果。
