[LeetCode 第 1147 题](https://leetcode.com/problems/longest-chunked-palindrome-decomposition/)

 **难度：** 🔴难
 **主题：** 两个指针、字符串、动态规划、贪心、滚动哈希、哈希函数

 ## 解决方案

 ## 问题理解

 该问题要求我们分解给定的字符串`text`成最大可能数量的连续子串，使得子串序列形成回文模式。 具体来说，第一个子字符串必须等于最后一个子字符串，第二个子字符串必须等于倒数第二个子字符串，依此类推。 目标是最大化这些块的数量，表示为`k`。 

输入`text`长度不超过1000个字符的字符串，仅由小写英文字母组成。 输出是一个整数，表示在保留回文块属性的同时可以将字符串拆分成的最大块数。 

这些限制意味着对所有可能的分裂进行强力检查可能效率低下。 边缘情况包括已经是回文的字符串、没有重复模式的字符串以及最大分解涉及许多小块的字符串。 该问题保证字符串非空，这简化了边界情况的处理。 

## 方法

 **暴力方法**将尝试在每个可能的前缀处拆分字符串，并递归检查剩余的字符串是否也可以拆分为回文块。 虽然这保证了正确性，但效率非常低，因为它探索了指数数量的子字符串组合，这对于 1000 个字符的上限是不可行的。 

最佳解决方案的**关键见解**是我们不需要检查每种可能的组合。 我们可以使用**双指针方法**从字符串的左端和右端开始。 在每一步中，我们都会逐步检查字符串的前缀是否与相应的后缀匹配。 当找到匹配时，它形成一个回文块，我们递归或迭代地处理剩余的中间部分。 这种方法之所以有效，是因为一旦识别出匹配对，就可以保证最佳分解必须包含它以最大化`k`。 可选地，**滚动哈希**可以优化字符串比较，但是对于`n <= 1000`，直接子串比较就足够了。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归尝试所有拆分组合； 指数时间|
 | 最佳 | O(n^2) | O(n^2) | O(1) | O(1) | 两指针增量比较； 子字符串检查占主导地位 |

 ## 算法演练

 1.初始化两个指针，`left`从字符串的开头开始并且`right`在最后。 初始化一个计数器`count`跟踪回文块的数量。 
2. 虽然`left <= right`，尝试找到从以下位置开始的最小非空前缀`left`匹配结尾为的后缀`right`。 
3. 使用内循环逐步扩展前缀大小。 在每一步中，检查是否`text[left:left+size] == text[right-size+1:right+1]`。 
4. 如果找到匹配项：

 - 增量`count`如果前缀和后缀不同则加 2，如果则加 1`left`和`right`指向相同的剩余子串（即奇数长度分解中的中间块）。 
- 移动`left`过去匹配的前缀和`right`在匹配的后缀之前。 
5. 重复此操作，直至指针交叉。 返回`count`。 

**为什么有效：** 在每次迭代中，算法都会贪婪地识别最小的匹配前缀后缀对。 由于任何最佳解决方案都必须包括最外层的匹配块以最大化块的总数，因此这种方法保证了最大可能`k`。 它通过仅检查连续的前缀后缀对来避免冗余工作。 

## Python 解决方案```
class Solution:
    def longestDecomposition(self, text: str) -> int:
        n = len(text)
        left, right = 0, n - 1
        count = 0
        
        while left <= right:
            size = 1
            found = False
            while left + size - 1 < right:
                if text[left:left+size] == text[right-size+1:right+1]:
                    count += 2
                    left += size
                    right -= size
                    found = True
                    break
                size += 1
            if not found:
                count += 1
                break
        
        return count
```**实现演练：** 我们初始化两个指针和一个块计数器。 内部循环根据相应的后缀检查前缀。 当找到匹配时，我们对两个块进行计数并向内移动指针。 如果指针交叉之前没有找到匹配项，则剩余的中间子串被计为一个块。 

## 解决方案```
func longestDecomposition(text string) int {
    left, right := 0, len(text)-1
    count := 0
    
    for left <= right {
        size := 1
        found := false
        for left+size-1 < right {
            if text[left:left+size] == text[right-size+1:right+1] {
                count += 2
                left += size
                right -= size
                found = true
                break
            }
            size++
        }
        if !found {
            count++
            break
        }
    }
    
    return count
}
```**Go 特定说明：** Go 切片使子字符串比较变得简单，类似于 Python。 主要区别是处理字符串切片`[start:end]`符号和显式管理索引。

 ## 边缘情况

 **单字符串：** 对于`text = "a"`，结果一定是 1。该算法正确处理了这个问题，因为`left`等于`right`，循环计算剩余的中间块。 

**没有匹配的前缀-后缀：** 对于像这样的字符串`"abcd"`，整个字符串之外没有回文块。 内部循环未能找到匹配项，剩余的字符串将被计为一个块。 

**所有相同的字符：** 对于`text = "aaaa"`，算法在每一步都会找到匹配的前缀和后缀。 它递增`count`正确的话，最多可以分解 4 个块。 这确保了即使存在多个有效的前缀后缀选择，贪婪方法也能发挥作用。
