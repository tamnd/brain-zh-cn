[LeetCode 第 1187 题](https://leetcode.com/problems/make-array-strictly-increasing/)

 **难度：** 🔴难
 **主题：** 数组、二分查找、动态规划、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们转换数组`arr1`使用最少的操作次数将其转换为严格递增的数组。 每个操作都允许替换一个元素`arr1`与一个元素`arr2`。 最终数组必须满足严格递增条件，这意味着每个元素都严格大于前一个元素。 

输入由两个数组组成：`arr1`长度`n`和`arr2`长度`m`。 输出是一个整数，表示所需的最小替换操作数。 如果无法制作`arr1`严格增加，我们返回`-1`。 

约束表明`arr1`和`arr2`每个元素最多可以包含 2000 个元素，每个元素最大可以为$10^9$。 这意味着尝试所有组合的简单暴力解决方案在计算上是不可行的，因为组合的数量随着数组的长度呈指数增长。 

边缘情况包括已经严格递增的数组、无法进行替换的数组、具有重复元素的数组`arr2`，以及所有元素都相等的场景。 

## 方法

 ### 暴力方法

 暴力解决方案考虑了所有可能的替换顺序。 在每个位置`arr1`，我们可以选择保留当前元素或用其中的任何元素替换它`arr2`。 这导致了一个可能性树，其中每个节点代表数组的当前状态和执行的操作数。 我们将递归地探索所有路径，并选择一条能够以最少的操作产生严格递增数组的路径。 虽然这种方法是正确的，但对于大输入来说是不可行的，因为它的时间复杂度是指数级的：$O(2^n \cdot m^n)$在最坏的情况下，这对于$n, m \le 2000$。 

### 最佳方法

 关键的见解是可以使用动态编程和记忆技术来解决该问题。 我们可以维护由当前索引定义的状态`arr1`以及递增序列中的前一个数字。 对于每个索引，我们有两个选择：保留`arr1[i]`如果它大于之前的数字，或者用其中最小的数字替换它`arr2`该数字大于之前的数字。 为了有效地找到最小的替代品，我们可以排序`arr2`并使用二分查找。 通过记住每个状态的结果，我们避免了冗余计算，从而获得更快的解决方案。

 ## 算法演练

 1. **排序`arr2`并删除重复项**以促进高效的二分搜索。 这确保了我们可以快速找到最小的数字`arr2`大于任何给定值。 
2. **定义一个DP函数**`dfs(index, prev)`表示完成所需的最少操作数`arr1[index:]`鉴于前一个元素是严格增加`prev`。 
3. **基本情况：** 如果`index`等于长度`arr1`，我们已经处理了所有元素并返回`0`运营。 
4. **选项 1 - 保留当前元素：** 如果`arr1[index] > prev`,递归调用`dfs(index + 1, arr1[index])`。 这代表我们不替换当前元素的场景。 
5. **选项 2 - 替换为以下元素`arr2`:** 使用二分查找`arr2`找到大于的最小元素`prev`。 如果存在这样的元素，则递归调用`dfs(index + 1, arr2[j]) + 1`来解释替换操作。 
6. **记住每个结果**`(index, prev)`组合以避免重新计算。 
7. **返回两个选项中的最少操作**。 如果两个选项都无效，则传播无穷大以表明不可能使数组严格递增。 
8. **最终结果：** 通话`dfs(0, -1)`（或任何小于最小可能元素的值）并返回`-1`如果结果是无穷大。 

**工作原理：** DP 函数使用递归探索所有有效路径，但通过记忆避免冗余计算。 通过始终考虑保留和替换当前元素，并使用二分搜索进行有效替换，该算法保证找到最少的操作数或正确识别不可能。 

## Python 解决方案```python
from typing import List
import bisect
from functools import lru_cache

class Solution:
    def makeArrayIncreasing(self, arr1: List[int], arr2: List[int]) -> int:
        arr2 = sorted(set(arr2))  # Remove duplicates and sort for binary search

        @lru_cache(None)
        def dfs(index: int, prev: int) -> int:
            if index == len(arr1):
                return 0  # Reached the end

            min_ops = float('inf')

            # Option 1: Keep current element if strictly greater than prev
            if arr1[index] > prev:
                min_ops = dfs(index + 1, arr1[index])

            # Option 2: Replace with element from arr2
            j = bisect.bisect_right(arr2, prev)  # Find smallest element > prev
            if j < len(arr2):
                min_ops = min(min_ops, 1 + dfs(index + 1, arr2[j]))

            return min_ops

        result = dfs(0, -1)
        return result if result != float('inf') else -1
```实现从预处理开始`arr2`允许快速查找替代候选者。 这`dfs`函数递归地处理每个索引，探索保留元素并使用二分搜索替换它。`lru_cache`记住结果以避免重新计算。 最终调用返回最少的操作或`-1`如果不可能的话。 

## 解决方案```go
package main

import (
    "sort"
    "math"
)

func makeArrayIncreasing(arr1 []int, arr2 []int) int {
    arr2Map := map[int]bool{}
    for _, v := range arr2 {
        arr2Map[v] = true
    }
    arr2Unique := []int{}
    for k := range arr2Map {
        arr2Unique = append(arr2Unique, k)
    }
    sort.Ints(arr2Unique)

    memo := map[[2]int]int{}
    var dfs func(index int, prev int) int
    dfs = func(index int, prev int) int {
        if index == len(arr1) {
            return 0
        }
        key := [2]int{index, prev}
        if val, exists := memo[key]; exists {
            return val
        }

        minOps := math.MaxInt32

        // Option 1: Keep current element
        if arr1[index] > prev {
            minOps = dfs(index+1, arr1[index])
        }

        // Option 2: Replace from arr2
        j := sort.Search(len(arr2Unique), func(i int) bool { return arr2Unique[i] > prev })
        if j < len(arr2Unique) {
            temp := dfs(index+1, arr2Unique[j])
            if temp != math.MaxInt32 {
                minOps = min(minOps, 1+temp)
            }
        }

        memo[key] = minOps
        return minOps
    }

    res := dfs(0, -1)
    if res == math.MaxInt32 {
        return -1
    }
    return res
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 版本使用地图处理记忆`[2]int`作为钥匙。 排序`arr2`并使用`sort.Search`允许有效的替换查找。 递归和基本情况逻辑反映了 Python 实现。
