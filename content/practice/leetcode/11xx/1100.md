[LeetCode 问题 1100](https://leetcode.com/problems/find-k-length-substrings-with-no-repeated-characters/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 问题要求我们计算有多少个子串的长度`k`仅包含唯一字符。 

子字符串是字符串的连续部分。 对于每个可能的长度子串`k`，我们必须确定其中的所有字符是否不同。 如果是，我们将该子字符串计入最终答案。 

例如，考虑：```
s = "havefunonleetcode"
k = 5
```子串`"havef"`包含字符`h`,`a`,`v`,`e`， 和`f`，全部不同，因此它是有效的。 子串`"funon"`包含两个`n`字符，因此无效。 

输入包括：

 - 一根绳子`s`仅包含小写英文字母
 - 一个整数`k`输出是一个整数，表示长度为有效的子字符串的数量`k`。 

约束条件很重要：

 -`1 <= s.length <= 10^4`-`1 <= k <= 10^4`字符串长度为`10^4`足够大，以至于逐字符重复检查每个子字符串可能会变得低效。 这表明我们应该寻找线性时间或近线性时间的解决方案。 

有几个重要的边缘情况：

 -`k > len(s)`, 没有长度的子串`k`可以存在
 -`k == 1`，每个单个字符子串自动有效
 - 包含所有重复字符的字符串，例如`"aaaaa"`- 每个字符都是唯一的字符串
 - 当滑动窗口移动时重复项进入和离开的窗口

 该问题保证字符串仅包含小写英文字母，这意味着如果需要，我们可以使用固定大小的频率数组。 

## 方法

 ### 蛮力方法

 暴力解决方案检查每个长度的子串`k`。 

对于每个起始索引：

 1.提取size的子串`k`2. 检查所有字符是否唯一
 3. 如果唯一，则增加答案

 为了测试唯一性，我们可以将字符插入到集合中。 如果我们遇到集合中已有的字符，则该子字符串无效。 

这种方法是正确的，因为它直接根据问题定义准确地评估每个可能的子串。 

然而，它的效率很低。 大致有`n - k + 1`子串，并检查唯一性成本`O(k)`时间。 因此，总复杂度变为`O(n * k)`。 

和`n = 10^4`，这可能会变得不必要的缓慢。 

### 最优滑动窗口方法

 关键的观察结果是连续的子串严重重叠。 

例如：```
"havef"
"avefu"
```这两个子字符串共享四个字符。 我们可以重用前一个窗口的信息，而不是从头开始为每个窗口重建字符集。 

这自然会导致滑动窗口方法。 

我们维持：

 - 左指针
 - 右指针
 - 当前窗口内字符的频率图

 当右指针展开窗口时：

 - 添加新角色
 - 如果出现重复，则从左侧缩小窗口，直到所有字符再次唯一
 - 每当窗口大小变得精确时`k`, 视为有效

 由于每个字符最多进入和离开窗口一次，因此该算法以线性时间运行。

 ## 算法演练

 ### 最优滑动窗口算法

 1、先处理不可能的情况。 

如果`k > len(s)`， 返回`0`立即因为没有长度的子串`k`可以存在。 
2. 创建频率图。 

我们需要跟踪每个字符在当前窗口中出现的次数。 由于字符串仅包含小写英文字母，因此我们可以使用大小为 26 的数组。 
3. 初始化指针并应答。 

放：

-`left = 0`-`answer = 0`窗口将使用`right`指针。 
4. 一次将窗口展开一个字符。 

对于索引处的每个字符`right`:

 - 将其添加到频率图
 - 增加其数量
 5. 如有必要，删除重复项。 

如果当前字符出现多次，则该窗口无效，因为它包含重复项。 

虽然存在重复项：

 - 删除`s[left]`从频率图
 - 移动`left`前进

 这恢复了窗口内所有字符都是唯一的不变性。 
6. 保持窗口大小。 

如果窗口变得大于`k`，从左边缩小它，直到它的大小变为最大`k`。 
7. 计算有效窗口。 

每当窗口大小变得精确时`k`，所有角色的构造都是独一无二的。 

因此：

 - 增加答案
 8. 继续，直到处理完整个字符串。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 > 当前滑动窗口始终包含唯一字符。 

每当出现重复项时，窗口的左侧都会向前移动，直到重复项被删除。 因此，如果窗口大小正好达到`k`，我们都知道`k`人物性格鲜明。 

由于每个有效子串在滑动窗口移动时只出现一次，因此该算法可以正确计算所有有效子串。 

## Python 解决方案```python
class Solution:
    def numKLenSubstrNoRepeats(self, s: str, k: int) -> int:
        n = len(s)

        if k > n:
            return 0

        frequency = [0] * 26

        left = 0
        answer = 0

        for right in range(n):
            right_index = ord(s[right]) - ord('a')
            frequency[right_index] += 1

            while frequency[right_index] > 1:
                left_index = ord(s[left]) - ord('a')
                frequency[left_index] -= 1
                left += 1

            while right - left + 1 > k:
                left_index = ord(s[left]) - ord('a')
                frequency[left_index] -= 1
                left += 1

            if right - left + 1 == k:
                answer += 1

        return answer
```实施首先检查是否`k`超过字符串长度。 如果是，该函数立即返回`0`。 

这`frequency`数组存储每个小写字母在当前窗口中出现的次数。 使用数组而不是字典是有效的，因为字母表大小固定为 26。 

的`right`指针一次将窗口展开一个字符。 每添加一个字符，它的出现频率就会增加。 

如果添加的字符导致重复，则第一个`while`循环从左侧缩小窗口，直到重复项消失。 

第二个`while`循环确保窗口永远不会超过大小`k`。 

最后，每当窗口大小等于`k`，子字符串保证包含唯一字符，因此答案增加。 

## 解决方案```go
func numKLenSubstrNoRepeats(s string, k int) int {
	n := len(s)

	if k > n {
		return 0
	}

	frequency := make([]int, 26)

	left := 0
	answer := 0

	for right := 0; right < n; right++ {
		rightIndex := s[right] - 'a'
		frequency[rightIndex]++

		for frequency[rightIndex] > 1 {
			leftIndex := s[left] - 'a'
			frequency[leftIndex]--
			left++
		}

		for right-left+1 > k {
			leftIndex := s[left] - 'a'
			frequency[leftIndex]--
			left++
		}

		if right-left+1 == k {
			answer++
		}
	}

	return answer
}
```Go 实现遵循与 Python 版本相同的逻辑。 

频率结构被实现为长度为 26 的固定大小整数切片。由于 Go 字符串是字节索引的并且输入仅包含小写英文字母，因此可以使用`s[i]`安全高效。 

Go 在这里不需要对整数溢出进行特殊处理，因为所有计数都保持在标准整数范围内。

 ## 边缘情况

 ### 案例 1：`k`大于字符串长度

 如果`k > len(s)`，不能存在所需大小的子串。 幼稚的实现可能仍会尝试创建窗口或访问无效索引。 

该解决方案通过立即返回来防止这种情况发生`0`在任何滑动窗口逻辑开始之前。 

### 情况 2：到处都有重复的字符

 考虑：```
s = "aaaaaa"
k = 2
```每个窗口都包含重复的字符。 某些实现仅在缩小一次后就错误地计算窗口。 

该解决方案反复缩小窗口，直到删除所有重复项，从而保证正确性。 

### 情况 3：窗口大小完全等于整个字符串

 考虑：```
s = "abcdef"
k = 6
```只有一个可能的子串。 

该实现自然会处理这个问题，因为滑动窗口最终会增长到一定大小`6`，如果所有字符都是唯一的，则答案只会递增一次。 

### 案例 4：`k = 1`每个单独的字符形成一个有效的子字符串，因为单个字符不能包含重复项。 

算法会自动处理这个问题。 每当窗口大小变为`1`，答案递增。
