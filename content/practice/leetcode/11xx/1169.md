[LeetCode Problem 1169](https://leetcode.com/problems/invalid-transactions/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们根据两条规则来识别可能无效的交易。 First, any transaction with an amount greater than`$1000`无效。 其次，如果存在另一个同名交易，则任何交易无效`60`分钟但在不同的城市。 

The input is a list of strings, each representing a transaction in the format`"name,time,amount,city"`。 这`time`是在几分钟内，`amount`是一个整数值，并且`city`是一个小写字符串。 输出是输入中满足任一无效条件的所有交易的列表。 输出的顺序并不重要。 

约束告诉我们最多有`1000`交易，每个交易字符串格式良好，名称和城市均为小写且长度`1`到`10`, and times and amounts are within reasonable bounds. Because the input size is small, a quadratic-time solution is feasible, but we should aim for something more structured.

 重要的边缘情况包括具有相同名称和城市的交易、相隔 60 分钟发生的交易、恰好达到 1000 美元门槛的交易以及来自不同城市的同一个人的多笔交易。 

## 方法

 A brute-force approach would be to check each transaction against all others. 对于每笔交易，我们都会解析其组成部分，然后迭代所有其他交易以检查是否有相同的名称以及不同城市最多 60 分钟的时间差。 This approach works and correctly identifies invalid transactions, but it has a time complexity of$O(n^2)$, which may be slow if the input size approaches the upper bound.

 更优化的方法是利用按名称对事务进行分组。 这样，我们只需要比较同名的交易即可。 按时间对每个组进行排序使我们能够有效地检查 60 分钟窗口状况，而无需将每笔交易与所有其他交易进行比较。 超过 1000 美元的交易可以立即标记为无效。 This approach reduces unnecessary comparisons while maintaining correctness.

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | Compare each transaction against all others. 正确但缓慢。 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 按名称分组，按时间对每组进行排序，有效标记无效交易。 |

 ## 算法演练

 1. 将所有交易解析为结构化对象或元组，其中包含`name`,`time`,`amount`,`city`，以及原始字符串。 这样可以轻松访问组件进行比较。 
2. 立即将金额大于1000的交易标记为无效。 
3. 使用哈希映射或字典按名称对事务进行分组。 这确保我们只比较同名的交易。 
4. 对于每组交易，按时间升序排列。 排序允许线性扫描有效检查 60 分钟的差异。 
5. 对于排序组中的每笔交易，检查 60 分钟窗口内的相邻交易。 如果任何交易发生在不同的城市，则将两笔交易标记为无效。 
6. 将所有无效交易收集到结果列表中并返回。 

**Why it works:** The algorithm guarantees that all transactions exceeding 1000 are marked, and the grouping by name ensures we only compare relevant transactions. 排序可确保我们在 60 分钟内高效找到对。 这涵盖了所有可能的无效情况，无需多余的检查。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def invalidTransactions(self, transactions: List[str]) -> List[str]:
        txn_data = []
        invalid = set()
        
        # Step 1: Parse transactions and mark by amount > 1000
        for txn in transactions:
            name, time, amount, city = txn.split(',')
            time = int(time)
            amount = int(amount)
            txn_data.append((name, time, amount, city, txn))
            if amount > 1000:
                invalid.add(txn)
        
        # Step 2: Group transactions by name
        name_groups = defaultdict(list)
        for txn in txn_data:
            name_groups[txn[0]].append(txn)
        
        # Step 3: Check 60-minute different city condition
        for group in name_groups.values():
            group.sort(key=lambda x: x[1])  # sort by time
            n = len(group)
            for i in range(n):
                for j in range(i+1, n):
                    if group[j][1] - group[i][1] > 60:
                        break
                    if group[i][3] != group[j][3]:
                        invalid.add(group[i][4])
                        invalid.add(group[j][4])
        
        return list(invalid)
```The Python solution first parses each transaction and marks those exceeding $1000 as invalid. 然后，它按名称对交易进行分组，按时间对每个组进行排序，并仅检查 60 分钟内附近的交易是否存在城市差异，并根据需要将它们添加到无效集中。 

## 解决方案```go
package main

import (
    "strconv"
    "strings"
)

func invalidTransactions(transactions []string) []string {
    type txn struct {
        name   string
        time   int
        amount int
        city   string
        orig   string
    }
    
    txnData := make([]txn, 0, len(transactions))
    invalid := make(map[string]bool)
    
    for _, t := range transactions {
        parts := strings.Split(t, ",")
        timeInt, _ := strconv.Atoi(parts[1])
        amountInt, _ := strconv.Atoi(parts[2])
        txnData = append(txnData, txn{parts[0], timeInt, amountInt, parts[3], t})
        if amountInt > 1000 {
            invalid[t] = true
        }
    }
    
    nameGroups := make(map[string][]txn)
    for _, t := range txnData {
        nameGroups[t.name] = append(nameGroups[t.name], t)
    }
    
    for _, group := range nameGroups {
        for i := 0; i < len(group); i++ {
            for j := i + 1; j < len(group); j++ {
                if group[j].time - group[i].time > 60 {
                    break
                }
                if group[i].city != group[j].city {
                    invalid[group[i].orig] = true
                    invalid[group[j].orig] = true
                }
            }
        }
    }
    
    result := make([]string, 0, len(invalid))
    for t := range invalid {
        result = append(result, t)
    }
    return result
}
```Go 解决方案反映了 Python 方法。 It uses a struct to store transaction data, a map to mark invalid transactions, and nested loops within each name group to identify cross-city transactions within 60 minutes.

 ## 工作示例

 **示例1：**`["alice,20,800,mtv","alice,50,100,beijing"]`解析：`alice,20,800,mtv`和`alice,50,100,beijing`。 两者都不超过 1000 美元。 按名称分组给出一组。 按时间排序：20、50。时差30 < 60，城市不同，所以均无效。 输出：`["alice,20,800,mtv","alice,50,100,beijing"]`。 

**示例2：**`["alice,20,800,mtv","alice,50,1200,mtv"]`

`alice,50,1200,mtv`超过 1000 美元。 按时间排序的名称分组：20、50。城市相同，因此仅触发金额规则。 输出：`["alice,50,1200,mtv"]`。 

**示例3：**`["alice,20,800,mtv","bob,50,1200,mtv"]`只有 Bob 的交易超过 1000 美元。 输出：`["bob,50,1200,mtv"]`。
