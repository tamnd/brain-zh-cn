[LeetCode 第 1175 题](https://leetcode.com/problems/prime-arrangements/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们计算从 1 到 1 的数字有多少种排列`n`满足特定条件：所有素数必须出现在素数索引处（1-索引）。 例如，在排列中`[1,2,5,4,3]`为了`n = 5`，素数 2、3 和 5 分别出现在索引 2、3 和 5 处，它们都是素数位置，因此这个排列是有效的。 相比之下，`[5,2,3,4,1]`无效，因为 5 位于索引 1，它不是质数。 

输入`n`是 1 到 100 之间的整数。输出是单个整数，有效排列的数量取模`10^9 + 7`。 

约束表明该解决方案必须处理相对较小的`n`，但排列总数呈阶乘增长（`n!`），因此所有排列的简单生成在计算上是不可行的。 重要的边缘情况包括较小的值`n`（如 1 或 2），其中素数可能很少或没有，以及所有数字都是素数或非素数的值。 

## 方法

 蛮力方法会生成从 1 到 1 的所有数字排列`n`并检查每个排列是否所有素数都位于素数索引处。 虽然这保证了正确性，但它具有阶乘时间复杂度（`O(n!)`），这对于`n`最多 100 个。 

最佳解决方案的关键洞察力是组合。 我们不需要生成所有排列。 相反，我们可以将数字分为素数和非素数。 让`p`是素数的个数`1..n`。 正好有`p`主要位置和`n-p`非主要职位。 计算有效排列：

 1. 我们可以安排`p`素数在`p`的主要位置`p!`方式。 
2. 我们可以安排`n-p`中的非素数`n-p`非主要职位`(n-p)!`方式。 
3. 将这两个阶乘相乘即可得到有效排列的总数。 

最后返回取模后的结果`10^9 + 7`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 生成所有排列并过滤有效排列 |
 | 最佳| O(n * sqrt(n)) | O(n * sqrt(n)) | O(n) | 使用筛子计算素数，然后计算阶乘模`10^9+7`|

 ## 算法演练

 1. **计算素数：** 使用简单的筛子或素数检查最多`n`计算有多少个数字`1..n`是素数。 这决定了我们需要填补多少个主要职位。 
2. **计算阶乘模`10^9+7`:** 计算阶乘`p`（素数）和`n-p`（非素数）模`10^9+7`。 这可以防止整数溢出。 
3. **阶乘相乘：** 相乘`p!`和`(n-p)!`模数`10^9+7`。 结果是有效排列的数量。 
4. **返回结果：** 输出计算出的值。 

为什么它有效：不变的是素数必须占据素数索引，非素数占据非素数索引。 通过分别计算素数和非素数并将它们独立排列在各自的位置，我们确保所有计算的排列都是有效的。 

## Python 解决方案```python
class Solution:
    def numPrimeArrangements(self, n: int) -> int:
        MOD = 10**9 + 7

        # Helper function to count primes using simple primality check
        def count_primes(x: int) -> int:
            if x < 2:
                return 0
            primes = [True] * (x + 1)
            primes[0] = primes[1] = False
            for i in range(2, int(x**0.5) + 1):
                if primes[i]:
                    for j in range(i*i, x + 1, i):
                        primes[j] = False
            return sum(primes)

        prime_count = count_primes(n)
        non_prime_count = n - prime_count

        # Helper function to compute factorial modulo MOD
        def factorial(k: int) -> int:
            result = 1
            for i in range(2, k + 1):
                result = (result * i) % MOD
            return result

        return (factorial(prime_count) * factorial(non_prime_count)) % MOD
```该实现首先计算素数`n`使用筛子。 然后计算素数和非素数的阶乘模`10^9 + 7`。 将这些阶乘相乘即可得到有效排列的数量。 为了清晰和正确性，每个函数都是独立的。 

## 解决方案```go
func numPrimeArrangements(n int) int {
    const MOD = 1_000_000_007

    // Count primes using sieve
    primes := make([]bool, n+1)
    for i := 2; i <= n; i++ {
        primes[i] = true
    }
    for i := 2; i*i <= n; i++ {
        if primes[i] {
            for j := i * i; j <= n; j += i {
                primes[j] = false
            }
        }
    }

    primeCount := 0
    for i := 2; i <= n; i++ {
        if primes[i] {
            primeCount++
        }
    }
    nonPrimeCount := n - primeCount

    // Factorial modulo MOD
    factorial := func(k int) int {
        res := 1
        for i := 2; i <= k; i++ {
            res = (res * i) % MOD
        }
        return res
    }

    return (factorial(primeCount) * factorial(nonPrimeCount)) % MOD
}
```Go 版本遵循与 Python 相同的逻辑。 主要区别是 Go 特定的：我们显式地为筛子创建一个布尔切片，并且整数算术需要在每次乘法时取模以防止溢出。 

## 工作示例

 **示例 1：n = 5**

 计算素数：`[2,3,5]`→ 3 个素数

 主要头寸：指数`[2,3,5]`→ 3 个位置

 非素数：`[1,4]`→ 2 个位置

 阶乘：`3! = 6`,`2! = 2`乘：`6 * 2 = 12`→ 有效的排列。 

**示例 2：n = 100**

 计算素数最多 100 → 25 个素数，75 个非素数

 阶乘取模`10^9 + 7`:`25! * 75! % (10^9 + 7) = 682289015`## 复杂度分析

 ## 边缘情况

 1. **n = 1：** 没有素数，所以唯一的排列`[1]`是非常有效的。 实现可以正确处理阶乘 (0) = 1 的零素数。 
2. **n = 2：** 仅存在一个素数 (2)，并且仅存在一个素数位置（索引 2）。 这可确保阶乘计算正确处理 1 和 1 的素数和非素数计数。 
3. **n = 100：** 允许的最大输入强调阶乘和模运算。 每次乘法时如果没有取模，就会发生整数溢出。 该算法正确应用模数以防止溢出。 

该解决方案适用于任何 n ≤ 100，同时处理边缘情况，例如最小输入、只有一个素数或具有多个素数的大输入。
