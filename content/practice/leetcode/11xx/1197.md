 **难度：** 🟡 中等
 **主题：** 广度优先搜索

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算马从原点出发所需的最少移动次数`[0, 0]`到目标位置`[x, y]`在无限的棋盘上。 骑士以“L 形”移动，这意味着它可以在一个基本方向（上、下、左、右）上移动两个方格，并在垂直方向上移动一个方格。 每一步都算作一步。 

输入`x`和`y`代表目标坐标。 它们可以为负值，表示目标位于原点左侧或下方的象限之一。 输出是一个整数，表示达到目标所需的最小骑士移动次数`[x, y]`。 

限制条件是`-300 <= x, y <= 300`和`0 <= |x| + |y| <= 300`。 这告诉我们，尽管棋盘是无限的，但目标相对接近原点。 它还允许我们使用广度优先搜索，而不必担心无限的内存，因为搜索空间实际上是有限的。 重要的边缘情况包括非常接近原点的坐标、负坐标和沿轴的位置，因为简单的 BFS 可能会意外地探索不必要的象限。 该问题保证了解决方案的存在，因此我们不需要处理无法到达的位置。 

## 方法

 蛮力方法是从以下位置执行 BFS：`[0, 0]`，每一步探索所有 8 个可能的骑士动作，直到达到目标`[x, y]`。 这种方法是正确的，因为 BFS 保证第一次到达节点时是通过最短路径。 然而，完整无限板上的 BFS 可能会探索所有四个象限中的冗余位置，从而使其变慢。 

优化的关键点是对称性：因为骑士的移动是对称的，所以最短路径`[x, y]`与最短路径相同`[|x|, |y|]`。 这样，我们只需要在第一象限（`x >= 0, y >= 0`）。 此外，我们可以将 BFS 绑定到目标周围的区域，而不是探索完整的无限棋盘，因为可以保证骑士不需要在边界框之外移动太远。`[0, 0]`到`[|x|, |y|]`。

 ## 算法演练

 1. 使用绝对值将目标坐标转换到第一象限：`x = abs(x)`和`y = abs(y)`。 由于骑士移动的对称性，这减少了搜索空间。 
2. 初始化一个 BFS 队列，起始时间为`(0, 0)`步数为 0。此外，维护一个访问集以防止重新访问位置。 
3. 将 8 个可能的马动作定义为偏移对：`(2,1)`,`(1,2)`,`(-1,2)`,`(-2,1)`,`(-2,-1)`,`(-1,-2)`,`(1,-2)`,`(2,-1)`。 
4. 当队列不为空时，弹出最前面的节点`(cx, cy, steps)`。 如果`(cx, cy)`等于`(x, y)`， 返回`steps`。 
5. 对于 8 次移动中的每一次，计算新坐标`(nx, ny) = (cx + dx, cy + dy)`。 
6. 如果`(nx, ny)`为非负且未访问过，则添加`(nx, ny, steps + 1)`到队列并将其标记为已访问。 
7. 重复直到达到目标。 

**为什么起作用：** BFS 保证第一次到达节点时，会通过最少的步数，因为每次移动都被认为是在同一“级别”。 使用对称性可以确保我们不会探索不必要的负坐标。 访问集可以防止循环和重复工作。 

## Python 解决方案```python
from collections import deque

class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        x, y = abs(x), abs(y)
        directions = [(2,1),(1,2),(-1,2),(-2,1),(-2,-1),(-1,-2),(1,-2),(2,-1)]
        queue = deque([(0, 0, 0)])
        visited = set([(0, 0)])
        
        while queue:
            cx, cy, steps = queue.popleft()
            if (cx, cy) == (x, y):
                return steps
            for dx, dy in directions:
                nx, ny = cx + dx, cy + dy
                if nx >= -1 and ny >= -1 and (nx, ny) not in visited:
                    visited.add((nx, ny))
                    queue.append((nx, ny, steps + 1))
```这个Python解决方案首先将目标映射到第一象限，然后执行BFS。 我们初始化队列`(0,0,0)`跟踪坐标和步数。 访问集确保每个位置最多被访问一次。 支票`nx >= -1 and ny >= -1`是一种微妙的优化，以避免探索远离原点的位置，而这些位置永远不需要到达第一象限目标。 每次迭代都会系统地探索所有 8 个骑士动作。 

## 解决方案```go
package main

import "container/list"

func minKnightMoves(x int, y int) int {
    x, y = abs(x), abs(y)
    directions := [8][2]int{{2,1},{1,2},{-1,2},{-2,1},{-2,-1},{-1,-2},{1,-2},{2,-1}}
    visited := make(map[[2]int]bool)
    queue := list.New()
    queue.PushBack([3]int{0,0,0})
    visited[[2]int{0,0}] = true

    for queue.Len() > 0 {
        elem := queue.Front()
        queue.Remove(elem)
        node := elem.Value.([3]int)
        cx, cy, steps := node[0], node[1], node[2]
        if cx == x && cy == y {
            return steps
        }
        for _, d := range directions {
            nx, ny := cx+d[0], cy+d[1]
            key := [2]int{nx, ny}
            if nx >= -1 && ny >= -1 && !visited[key] {
                visited[key] = true
                queue.PushBack([3]int{nx, ny, steps+1})
            }
        }
    }
    return 0
}

func abs(a int) int {
    if a < 0 {
        return -a
    }
    return a
}
```Go 实现反映了 Python BFS 方法。 我们使用一个`list.List`队列和已访问位置的地图。 数组用于存储坐标和步数。 主要区别包括显式使用`abs`函数和处理切片与元组。
