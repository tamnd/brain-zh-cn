[LeetCode 第 1131 题](https://leetcode.com/problems/maximum-of-absolute-value-expression/)

 **难度：** 🟡 中等
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 该问题给了我们两个整数数组，`arr1`和`arr2`，两者具有相同的长度。 我们必须计算每对索引中以下表达式的最大可能值`(i, j)`:$$|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|$$任务不是要求指数本身，而是要求最大的可实现值。 

乍一看，这看起来像是在所有元素对上直接应用绝对值计算。 由于有`n`元素，有`n^2`可能的`(i, j)`组合。 对于小型数组，检查每一对都可以，但约束允许数组大小最大为`40000`，这使得二次解太慢。 

输入表示两个类似坐标的数组。 对于每个索引`i`，我们可以想到这一点：$$(arr1[i], arr2[i], i)$$该表达式测量三维空间中两个此类点之间的曼哈顿距离。 

输出是一个整数，是从任何有效的索引对获得的最大值。 

这些约束提供了几个重要的观察结果：

 -`arr1.length == arr2.length`，因此每个索引都存在于两个数组中。 
- 最大数组大小为`40000`，这强烈表明我们需要一个线性或近线性算法。 
- 值可能为负，因此我们必须小心处理符号更改。 
- 绝对值是关键挑战，因为它们创建了多种可能的符号组合。 

一些边缘情况很重要：

 - 包含负数的数组，因为符号处理变得至关重要。 
- 所有值都相同的数组，其中索引差异单独决定结果。 
- 长度非常小的数组`2`，其中仅存在一对有意义的。 
- 附近的大震级值`10^6`，其中溢出问题在某些语言中很重要。 
- 最佳答案来自于跨维度混合正负差异的情况。 

## 方法

 ### 蛮力方法

 最直接的解决方案是评估每对的表达式`(i, j)`。 

对于每一对，我们计算：$$|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|$$并跟踪遇到的最大值。 

这种方法是正确的，因为它明确地检查每个可能的候选对，因此它不会错过最佳答案。 

但时间复杂度太高。 和`n`元素，有`n^2`对。 什么时候`n = 40000`，这变成：$$40000^2 = 1.6 \times 10^9$$这远远超出了 LeetCode 时间限制可接受的范围。 

### 最佳方法

 关键的观察是绝对值可以使用符号组合重写。 

考虑以下表达式：$$|a-b| + |c-d| + |i-j|$$每个绝对值可以根据顺序做出正向或负向贡献。 扩展所有可能的符号选择仅给出固定数量的线性形式。 

对于这个问题，表达式总是可以转换为以下形式之一：$$(\pm arr1[i]) + (\pm arr2[i]) + i$$更具体地说，只有四种独特的组合很重要：

 1.`arr1[i] + arr2[i] + i`2.`arr1[i] + arr2[i] - i`3.`arr1[i] - arr2[i] + i`4.`arr1[i] - arr2[i] - i`对于这些形式中的任何一种，两个指数之间的最大差异很简单：$$\max(expression) - \min(expression)$$因此，我们不是检查所有对，而是为每个符号组合迭代一次数组，跟踪最小值和最大值，并计算它们的差异。 

这将问题从二次复杂性转变为线性复杂性。

 ## 算法演练

 1. 观察表达式包含三个绝对值。 

表达式为：$$|arr1[i]-arr1[j]| + |arr2[i]-arr2[j]| + |i-j|$$每个绝对值可以表现为正或负，具体取决于哪个操作数较大。 
2. 使用符号组合重写表达式。 

扩展可能性会产生四种不同的线性表达式：$$arr1[i] + arr2[i] + i$$

$$arr1[i] + arr2[i] - i$$

$$arr1[i] - arr2[i] + i$$

$$arr1[i] - arr2[i] - i$$原始表达式的任何有效值都对应于这些形式之一的两个值之间的差异。 
3. 独立处理每份表格。 

对于每个表达式类型：

 - 计算每个索引的值。 
- 跟踪迄今为止看到的最小值。 
- 跟踪迄今为止看到的最大值。 
4. 计算最佳差异。 

该形式的最大可能差异是：$$maxValue - minValue$$5. 保持全局最大值。 

比较所有四种形式的结果并返回最大的形式。 

### 为什么它有效

 正确性来自于曼哈顿距离表达式可以表示为多个线性变换之间的最大差值。 四种形式之一涵盖了绝对值符号的每种可能的组合。 由于最佳对必须最大化这些变换表达式之一，因此取最大和最小变换值之间的差可以保证我们找到真正的答案。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxAbsValExpr(self, arr1: List[int], arr2: List[int]) -> int:
        n = len(arr1)
        
        expressions = [
            lambda a, b, i: a + b + i,
            lambda a, b, i: a + b - i,
            lambda a, b, i: a - b + i,
            lambda a, b, i: a - b - i,
        ]
        
        answer = 0
        
        for expression in expressions:
            minimum = float('inf')
            maximum = float('-inf')
            
            for i in range(n):
                value = expression(arr1[i], arr2[i], i)
                
                minimum = min(minimum, value)
                maximum = max(maximum, value)
            
            answer = max(answer, maximum - minimum)
        
        return answer
```实现首先定义代表所有有意义的符号组合的四个转换表达式。 

对于每个转换，算法都会扫描数组一次。 在扫描期间，它计算当前索引的转换值并更新运行的最小值和最大值。 

处理给定形式的所有索引后，最大和最小变换值之间的差异代表该形式的最佳可能贡献。 

全局答案存储所有四种转换的最佳结果。 

该解决方案使用恒定的额外内存，因为它在迭代时仅维护一些变量。 

## 解决方案```go
func maxAbsValExpr(arr1 []int, arr2 []int) int {
	n := len(arr1)

	maximum := func(a, b int) int {
		if a > b {
			return a
		}
		return b
	}

	result := 0

	for k := 0; k < 4; k++ {
		minVal := int(1e9)
		maxVal := -int(1e9)

		for i := 0; i < n; i++ {
			var value int

			switch k {
			case 0:
				value = arr1[i] + arr2[i] + i
			case 1:
				value = arr1[i] + arr2[i] - i
			case 2:
				value = arr1[i] - arr2[i] + i
			case 3:
				value = arr1[i] - arr2[i] - i
			}

			if value < minVal {
				minVal = value
			}

			if value > maxVal {
				maxVal = value
			}
		}

		result = maximum(result, maxVal-minVal)
	}

	return result
}
```Go 实现遵循与 Python 版本相同的逻辑，但使用`switch`语句而不是 lambda 函数。 

Go 没有提供内置的`min`和`max`旧版本中的整数函数，因此比较是手动处理的。 

这里不必担心整数溢出，因为最大可能的转换值仍然在 32 位有符号整数范围内：$$10^6 + 10^6 + 40000 < 2^{31}$$解决方案依然采用`int`，对于 LeetCode 来说这是标准且足够的。

 ## 边缘情况

 当所有数组值都相同时，就会出现一种重要的边缘情况。 在这种情况下，数组元素之间的差异变为零，因此整个结果仅取决于`|i - j|`。 有缺陷的实现可能会在简化公式时意外地忽略索引贡献。 此实现正确地将索引包含在每个转换后的表达式中，因此自然会考虑索引之间的最大距离。 

另一个关键的边缘情况涉及负数。 带有负操作数的绝对值通常是错误的根源，因为符号转换很容易变得不正确。 四表达式转换保证表示每个有效的符号配置，因此可以正确处理负值，而不需要特殊的分支逻辑。 

第三个重要的边缘情况是接近约束限制的非常大的整数值。 由于值可以达到`10^6`，如果使用较小的整数类型，在某些语言中组合多个术语可能会溢出。 该实现安全地使用标准整数算术，因为最大可能的表达式仍然在 32 位有符号整数限制内。
