[LeetCode 第 1143 题](https://leetcode.com/problems/longest-common-subsequence/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们找到两个输入字符串中出现的最长子序列的长度。 

子序列是通过从字符串中删除一些字符，同时保持其余字符保持相同的相对顺序而形成的。 字符不需要是连续的。 

例如，在字符串中`"abcde"`:

 -`"ace"`是一个有效的子序列，因为我们可以删除`'b'`和`'d'`-`"aec"`不是有效的子序列，因为相对顺序发生了变化

 我们有两个字符串，`text1`和`text2`，我们需要确定两个字符串中存在的子序列的最大可能长度。 

关键细节是我们只需要最长公共子序列的长度，而不是子序列本身。 

例如：

-`text1 = "abcde"`-`text2 = "ace"`最长公共子序列是`"ace"`，其长度为`3`。 

约束条件很重要：

 - 每个字符串长度可达`1000`- 仅使用小写英文字母

 简单的暴力解决方案会太慢，因为子序列的数量呈指数增长。 带有长度的字符串`1000`，我们需要一个多项式时间算法。 

一些边缘情况很重要：

 - 两个字符串可能根本没有共同字符
 - 一根绳子可以完全包含在另一根绳子内
 - 多个不同的子序列可能具有相同的最大长度
 - 重复的字符会产生许多重叠的子问题
 - 最优子序列可能会跳过两个字符串中的许多字符

 这些观察结果强烈表明动态规划是正确的方法，因为该问题包含重叠的子问题和最优子结构。 

## 方法

 ### 蛮力方法

 暴力方法将生成一个字符串的所有可能的子序列，并检查它是否也是另一个字符串的子序列。 

一个长度的字符串`n`有`2^n`子序列，因为每个字符都可以包含或排除。 

对于每个生成的子序列，我们可以检查它是否出现在第二个字符串中，同时保留顺序。 

这种方法是正确的，因为它详尽地检查了每个可能的子序列，因此不会错过最佳答案。 

然而，对于给定的约束，它在计算上是不可行的。 即使是一段长度的字符串`50`已经产生了超过一万亿个子序列。 由于输入大小可以达到`1000`，暴力是不可能的。 

### 最优动态规划方法

 关键的见解是该问题具有重叠的子问题。 

假设我们正在比较：

 -`text1[i:]`-`text2[j:]`这些后缀的答案仅取决于较小的后缀。 

有两种可能：

 1.当前字符匹配
 2.当前字符不匹配

 如果字符匹配，我们可以将该字符包含在子序列中并继续求解剩余的后缀。 

如果它们不匹配，我们必须从任一字符串中跳过一个字符并获取更好的结果。 

这自然会导致动态规划的重现。 

定义：`dp[i][j]`= 之间最长公共子序列的长度：

 -`text1[0:i]`-`text2[0:j]`转换规则：

 - 如果字符匹配：`dp[i][j] = dp[i-1][j-1] + 1`- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`这将问题从指数时间减少到多项式时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * m) | O(2^n * m) | O(n) | 生成所有子序列并检查有效性 |
 | 最优动态规划| O(n * m) | O(n * m) | 有效地使用重叠子问题结果 |

 ## 算法演练

 1.让`n`的长度是`text1`和`m`的长度是`text2`。 
2. 创建一个二维动态规划表，名为`dp`有尺寸`(n + 1) x (m + 1)`。 

额外的行和列表示空前缀。 这简化了边界处理，因为空字符串具有 LCS 长度`0`与任何字符串。 
3. 初始化每个单元格`0`。 

最初，我们假设不存在公共子序列。 
4. 使用嵌套循环遍历字符串。 

外循环处理来自的字符`text1`。 

内循环处理来自的字符`text2`。 
5. 对于每对索引`(i, j)`：

比较：

-`text1[i - 1]`-`text2[j - 1]`我们使用`i - 1`和`j - 1`因为DP表有一个额外的前导行和列。 
6. 如果字符匹配：

 添加`1`到前一个对角线单元格的结果：`dp[i][j] = dp[i - 1][j - 1] + 1`对角线表示包含匹配字符之前的最佳 LCS。 
7. 如果字符不匹配：

 取最大值：

 - 跳过当前字符`text1`- 跳过当前字符`text2`公式：`dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`8. 继续，直到表填满。 
9. 最终答案存储在：`dp[n][m]`这表示整个字符串的 LCS 长度。 

### 为什么它有效

 动态规划解决方案之所以有效，是因为每个最优子序列问题都可以简化为更小的最优子序列问题。 

如果两个字符匹配，则以这些字符结尾的任何最佳子序列都必须包含它们，因此我们扩展了先前的最佳解决方案。 

如果它们不匹配，则至少有一个字符不能属于同一子序列，因此我们尝试两种可能性并保留更好的结果。 

由于每个状态仅取决于先前解决的较小状态，因此自下而上填充表可以保证正确性。 

## Python 解决方案```
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        n = len(text1)
        m = len(text2)

        dp = [[0] * (m + 1) for _ in range(n + 1)]

        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[n][m]
```实现首先确定两个字符串的长度。 

这`dp`表用维度初始化`(n + 1) x (m + 1)`。 每个值开始于`0`，它正确地表示涉及空前缀的 LCS。 

嵌套循环迭代两个字符串中的每对位置。 

当字符匹配时，我们从对角单元扩展前一个子序列的长度。 

当它们不匹配时，我们会继承从其中删除字符的最佳结果`text1`或从中删除一个字符`text2`。 

最后，右下角的单元格包含完整字符串的最长公共子序列的长度。 

## 解决方案```
func longestCommonSubsequence(text1 string, text2 string) int {
	n := len(text1)
	m := len(text2)

	dp := make([][]int, n+1)

	for i := range dp {
		dp[i] = make([]int, m+1)
	}

	for i := 1; i <= n; i++ {
		for j := 1; j <= m; j++ {
			if text1[i-1] == text2[j-1] {
				dp[i][j] = dp[i-1][j-1] + 1
			} else {
				if dp[i-1][j] > dp[i][j-1] {
					dp[i][j] = dp[i-1][j]
				} else {
					dp[i][j] = dp[i][j-1]
				}
			}
		}
	}

	return dp[n][m]
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 使用嵌套切片来创建 DP 表，而不是列表推导式。 

Go 字符串是字节索引的，这在这里是安全的，因为问题只保证小写英文字母。 

不需要对 nil 值进行特殊处理，因为 DP 表在使用前已完全初始化。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * m) | 每对索引都被处理一次 |
 | 空间| O(n * m) | DP表存储所有子问题的结果 |

 该算法只对每个 DP 状态处理一次。 由于有`n * m`状态，时间复杂度是字符串长度的二次方。 

空间复杂度也是二次的，因为我们存储整个 DP 表。 这可以优化为`O(min(n, m))`使用滚动阵列，但标准的 2D 解决方案更清晰、更容易理解。

 ## 边缘情况

 ### 完全不同的字符串

 当两个字符串不共享字符时，答案应该是`0`。 

例子：```
text1 = "abc"
text2 = "def"
```有缺陷的实现可能会意外地计算部分匹配或无法正确初始化 DP 表。 

此实现可以自然地处理这种情况，因为没有发生字符匹配，因此每个 DP 单元都保留`0`。 

### 重复字符

 重复的字符可以创造许多重叠的可能性。 

例子：```
text1 = "aaaa"
text2 = "aa"
```贪婪的方法可能会错误地重用字符或计数太多匹配项。 

DP 解决方案避免了这个问题，因为每个状态都代表精确的前缀比较，确保字符按有效顺序匹配而不会重复。 

### 一个字符串包含在另一个字符串中

 有时，整个较小的字符串已经是较大字符串的子序列。 

例子：```
text1 = "abcde"
text2 = "ace"
```该算法必须正确地跳过不相关的字符，同时保持顺序。 

DP 递归自然支持通过转换跳过字符：```
max(dp[i - 1][j], dp[i][j - 1])
```这保证了不必要的字符被忽略，同时保留最佳可能的子序列长度。
