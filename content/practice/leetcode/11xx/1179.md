[LeetCode 第 1179 题](https://leetcode.com/problems/reformat-department-table/)

 **难度：** 🟢简单
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 问题是要求我们拿一张桌子`Department`以垂直格式记录每个部门每月的收入，并将其转换为水平格式，通常称为“数据透视表”。 在输入中，每行包含一个部门`id`、收入值和`month`。 主键确保每个部门每月最多有一个收入条目，因此不会有重复的处理。 

预期输出是一个表，每个部门一行，其中每一列对应一个月（从一月到十二月）并包含该部门当月的收入。 如果一个月没有记录收入，则该列应包含`NULL`。 输出必须包括所有十二个月，无论收入是否存在。 结果可以按任意顺序返回。 

重要的约束包括保证`(id, month)`是唯一的，这简化了聚合，而固定的月份值则可以显式命名输出列。 边缘情况包括只有部分月份有收入的部门、根本没有收入的月份或输入表为空的部门。 

## 方法

 强力方法是手动迭代所有部门和月份，逐行构建结果表。 对于每个部门，您将扫描整个表格以查找每个月的收入。 这种方法是正确的，但效率低下，因为`D`部门和`R`记录，需要`O(D * 12 * R)`查找，这是不必要的。 

最佳方法利用 SQL`CASE`在一次传递中对表进行透视的表达式。 对于每个月，我们使用以下命令创建一个列`SUM(CASE WHEN month = 'Jan' THEN revenue END) AS Jan_Revenue`。 分组依据`id`确保每个部门生产一行。 这种方法非常高效，因为它只扫描表一次并在单个查询中生成所有输出列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(D * 12 * R) | O(D * 12) | 跨部门和月份的嵌套循环； 大输入速度慢|
 | 最佳| O(R)| O(D * 12) | 使用 CASE 和 GROUP BY 的单遍 SQL 聚合 |

 ## 算法演练

 1. 首先从以下位置选择所有记录`Department`桌子。 
2. 对于从 1 月到 12 月的每个月，使用`CASE`表达。 如果该行对应于当月，则返回收入； 否则，返回`NULL`。 
3. 使用`SUM()`汇总每个部门的收入。 自从`(id, month)`是独一无二的，`SUM()`将简单地返还收入或`NULL`。 
4. 按部门对结果进行分组`id`将每个部门的多行折叠为一行。 
5. 返回结果表。 输出将为每个部门一行和每月一列。 

为什么它有效：通过使用`CASE`通过聚合函数中的表达式，我们可以有效地将行转换为列。 按部门分组可确保所有月份在同一行中对齐。 的独特性`(id, month)`保证不会发生聚合冲突，因此结果与预期格式匹配。 

## Python 解决方案```python
class Solution:
    def reformatDepartmentTable(self, department: list[dict]) -> list[dict]:
        import pandas as pd

        if not department:
            return []

        df = pd.DataFrame(department)
        months = ["Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec"]
        
        pivot_df = df.pivot(index='id', columns='month', values='revenue')
        
        # Rename columns
        pivot_df = pivot_df.reindex(columns=months)
        pivot_df.columns = [f"{month}_Revenue" for month in pivot_df.columns]
        pivot_df = pivot_df.reset_index()
        
        # Convert DataFrame to list of dicts
        result = pivot_df.to_dict(orient='records')
        return result
```在此实现中，我们首先将输入加载到 pandas DataFrame 中。 然后我们对表进行透视，使每个月都成为一列。 缺失月份自动生成`NaN`， pandas 将转换为`None`使用时`to_dict(orient='records')`。 最后，我们重命名列以匹配`_Revenue`命名约定并重置索引`id`成为一列。 

## 解决方案```go
package main

type Department struct {
    Id      int
    Revenue int
    Month   string
}

type Result struct {
    Id          int
    JanRevenue  *int
    FebRevenue  *int
    MarRevenue  *int
    AprRevenue  *int
    MayRevenue  *int
    JunRevenue  *int
    JulRevenue  *int
    AugRevenue  *int
    SepRevenue  *int
    OctRevenue  *int
    NovRevenue  *int
    DecRevenue  *int
}

func reformatDepartmentTable(departments []Department) []Result {
    monthMap := map[string]func(r *Result, val int){
        "Jan": func(r *Result, val int) { r.JanRevenue = &val },
        "Feb": func(r *Result, val int) { r.FebRevenue = &val },
        "Mar": func(r *Result, val int) { r.MarRevenue = &val },
        "Apr": func(r *Result, val int) { r.AprRevenue = &val },
        "May": func(r *Result, val int) { r.MayRevenue = &val },
        "Jun": func(r *Result, val int) { r.JunRevenue = &val },
        "Jul": func(r *Result, val int) { r.JulRevenue = &val },
        "Aug": func(r *Result, val int) { r.AugRevenue = &val },
        "Sep": func(r *Result, val int) { r.SepRevenue = &val },
        "Oct": func(r *Result, val int) { r.OctRevenue = &val },
        "Nov": func(r *Result, val int) { r.NovRevenue = &val },
        "Dec": func(r *Result, val int) { r.DecRevenue = &val },
    }

    resMap := make(map[int]*Result)
    for _, d := range departments {
        if _, exists := resMap[d.Id]; !exists {
            resMap[d.Id] = &Result{Id: d.Id}
        }
        monthMap[d.Month](resMap[d.Id], d.Revenue)
    }

    result := make([]Result, 0, len(resMap))
    for _, v := range resMap {
        result = append(result, *v)
    }
    return result
}
```在Go中，我们需要使用指针来进行可选操作`int`值来表示空值。 我们维护一个从月份名称到设置器函数的映射，以将收入分配到正确的字段。 每个部门都存储在地图中`id`确保每个部门一行。 

## 工作示例

 **输入表：**

 | 编号 | 收入| 月 |
 | ---| ---| ---|
 | 1 | 8000 | 简 |
 | 2 | 9000 | 简 |
 | 3 | 10000 | 二月 |
 | 1 | 7000 | 二月 |
 | 1 | 6000 | 三月 |

 **逐步旋转：**

 1.初始化一张空地图`resMap`。 
2. 工艺行`(1, 8000, Jan)`：为 id 1 创建结果，设置 JanRevenue = 8000。 
3. 工艺行`(2, 9000, Jan)`：为 id 2 创建结果，设置 JanRevenue = 9000。 
4. 工艺行`(3, 10000, Feb)`：为 id 3 创建结果，设置 FebRevenue = 10000。 
5. 工艺行`(1, 7000, Feb)`：更新 id 1 的结果，设置 FebRevenue = 7000。 
6. 工艺行`(1, 6000, Mar)`：更新 id 1 的结果，设置 MarRevenue = 6000。 

决赛`resMap`对应输出表。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(R)| 我们对所有行进行一次迭代以填充数据透视表 |
 | 空间| O(D * 12) | 我们为每个部门存储 12 个月的 Result 对象 |

 复杂度与输入行数成线性关系。 空间随着部门数量的增加而增长，这是可以管理的，因为每个部门存储固定数量的 12 个月列。
