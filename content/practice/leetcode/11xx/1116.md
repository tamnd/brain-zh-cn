[LeetCode 第 1116 题](https://leetcode.com/problems/print-zero-even-odd/)

 **难度：** 🟡 中等
 **主题：** 并发

 ## 解决方案

 ## 问题理解

 问题需要我们实现一个多线程的类`ZeroEvenOdd`它协调三个独立的线程以特定顺序打印数字。 线程 A 打印`0`s，线程B打印偶数，线程C打印奇数。 输出必须将零与从开始的递增数字交错`1`最多`n`，产生一个像这样的序列`"010203..."`长度`2n`。 

输入`n`确定序列中的最大数字。 例如，如果`n = 5`，序列将是`"0102030405"`。 限制条件`1 <= n <= 1000`表明序列可能很长，但不会大到导致性能或内存成为标准并发控制机制中的问题。 

重要的边缘情况包括`n = 1`，输出应该是`"01"`，以及更高的值，例如`n = 1000`，其中线程同步必须正确缩放。 该问题保证始终存在三个线程，并且线程将异步调用各自的方法。 这意味着简单的顺序实现将不起作用； 正确的同步对于维持交织模式至关重要。 

## 方法

 暴力方法将涉及忙等待循环，其中每个线程重复检查是否轮到它们打印。 虽然这可以产生正确的输出，但效率非常低，因为线程浪费 CPU 周期来不断检查条件，而不是阻塞和等待正确的信号。 

最佳方法是使用信号量或锁等同步原语。 关键的见解是打印顺序是确定性的：每个零后面必须按顺序跟随奇数或偶数。 通过使用信号量控制线程执行，我们确保线程仅在轮到它们时才继续执行，从而避免忙等待并保证正确的顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 线程忙等待检查条件|
 | 最佳 | O(n) | O(1) | O(1) | 使用信号量高效同步线程 |

 ## 算法演练

 1.初始化三个信号量：`zero_sem`从 1 开始，`odd_sem`和`even_sem`从 0 开始。这确保了`zero`首先打印。 
2. 的`zero`线程进入循环`1`到`n`。 每次迭代，它都会获得`zero_sem`（如果不可用则阻塞），打印`0`，并释放`odd_sem`或者`even_sem`取决于下一个数字是奇数还是偶数。 
3. 的`odd`线程循环遍历所有奇数，直到`n`。 每次迭代，它都会获得`odd_sem`，打印数字，然后释放`zero_sem`允许打印下一个零。 
4. 的`even`线程循环遍历所有偶数，直到`n`。 每次迭代，它都会获得`even_sem`，打印数字，然后释放`zero_sem`。 
5. 不变的是`zero_sem`仅由`odd`或者`even`打印数字后，以及`odd_sem`或者`even_sem`仅由`zero`。 这确保了严格的交替。 

为什么有效：在任何时候，只允许一个线程进行打印。 信号量强制零和数字正确交替。 每个数字后面都有一个零，并且仅在轮到它们时才打印零。 这保证了任何的正确顺序`n`。 

## Python 解决方案```python
from threading import Semaphore
from typing import Callable

class ZeroEvenOdd:
    def __init__(self, n: int):
        self.n = n
        self.zero_sem = Semaphore(1)
        self.odd_sem = Semaphore(0)
        self.even_sem = Semaphore(0)
        
    def zero(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1):
            self.zero_sem.acquire()
            printNumber(0)
            if i % 2 == 1:
                self.odd_sem.release()
            else:
                self.even_sem.release()
    
    def even(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(2, self.n + 1, 2):
            self.even_sem.acquire()
            printNumber(i)
            self.zero_sem.release()
    
    def odd(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1, 2):
            self.odd_sem.acquire()
            printNumber(i)
            self.zero_sem.release()
```在此实现中，信号量用于阻塞线程，直到轮到它们打印为止。`zero_sem`允许`zero`开始，然后交替使用`odd_sem`或者`even_sem`取决于要打印的数量。 这强制执行正确的交错顺序。 

## 解决方案```go
package main

import "sync"

type ZeroEvenOdd struct {
	n        int
	zeroSem  chan struct{}
	oddSem   chan struct{}
	evenSem  chan struct{}
}

func NewZeroEvenOdd(n int) *ZeroEvenOdd {
	return &ZeroEvenOdd{
		n:       n,
		zeroSem: make(chan struct{}, 1),
		oddSem:  make(chan struct{}, 0),
		evenSem: make(chan struct{}, 0),
	}
}

func (z *ZeroEvenOdd) Zero(printNumber func(int)) {
	for i := 1; i <= z.n; i++ {
		<-z.zeroSem
		printNumber(0)
		if i%2 == 1 {
			z.oddSem <- struct{}{}
		} else {
			z.evenSem <- struct{}{}
		}
	}
}

func (z *ZeroEvenOdd) Even(printNumber func(int)) {
	for i := 2; i <= z.n; i += 2 {
		<-z.evenSem
		printNumber(i)
		z.zeroSem <- struct{}{}
	}
}

func (z *ZeroEvenOdd) Odd(printNumber func(int)) {
	for i := 1; i <= z.n; i += 2 {
		<-z.oddSem
		printNumber(i)
		z.zeroSem <- struct{}{}
	}
}
```在 Go 中，大小为 1 的缓冲通道充当信号量。 零线程首先发送到`zeroSem`，然后交替释放`oddSem`或者`evenSem`取决于数量。 其他线程会阻塞，直到通道可用。 

## 工作示例

 对于`n = 2`:

 | 迭代 | 零扫描电镜 | 奇数扫描电镜 | 偶数扫描电镜 | 输出|

 | i = 1 零 | 0 | 1 | 0 | 0 |
