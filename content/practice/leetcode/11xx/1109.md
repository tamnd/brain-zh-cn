 **难度：** 🟡 中等
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 问题是要求我们在给定航班预订列表的情况下计算为每个航班预订的座位总数。 每次预订都会指定一系列连续航班`[firsti, lasti]`以及座位数`seatsi`为该范围内的**每个航班**保留。 航班编号从`1`到`n`，结果应该是一个数组`answer`长度`n`， 在哪里`answer[i]`代表航班预订的总座位数`i+1`。 

输入`bookings`可以被认为是一组“范围更新”：每次预订都会向连续的航班范围添加固定数量的座位。 The challenge is to efficiently process multiple overlapping bookings without iterating through every flight in every booking, which could be too slow for large inputs.

 约束告诉我们`n`和`bookings.length`最多可达 20,000 个，因此迭代每个预订的航班的简单解决方案可能会达到 4 亿次操作，这太慢了。 输入保证所有索引都有效（`1 <= firsti <= lasti <= n`）并且座位数始终为正数，因此我们不必处理无效预订或负值。 

重要的边缘情况包括涵盖单个航班的预订、涵盖整个航班范围的预订、多个重叠预订以及在边界航班开始或结束的预订。 

## 方法

 **暴力方法**会迭代每个预订并更新指定范围内每个航班的座位数。 这保证了正确性，因为它直接应用座位预订，但效率低下。 对于每次预订`[first, last, seats]`，它执行`(last - first + 1)`运营。 在最坏的情况下，这会导致时间复杂度为 O(n * m)，其中`m`是预订数量，最大输入大小最多可达 4 亿次操作。 

**最佳方法**利用**前缀和技巧**，这是一种有效应用范围更新的常用技术。 我们不是更新每次预订范围内的每个元素，而是用以下标记范围的开始`+seatsi`以及范围结束后的位置`-seatsi`。 处理完所有预订后，单个前缀总和通道会将这些标记转换为每个航班的总座位数。 这将时间复杂度降低到 O(n + m)，这对于给定的约束是可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n) | 直接更新每个预订范围内的每个航班 |
 | 最佳 | O(n + m) | O(n) | 使用前缀和技术有效应用范围更新 |

 ## 算法演练

 1.初始化一个数组`res`长度`n`全为零。 该数组最终将保存每个航班的总座位数。 
2. 迭代每个预订`[first, last, seats]`在`bookings`。 对于每次预订，增量`res[first-1]`经过`seats`标记预订范围的开始。 如果`last < n`, 递减`res[last]`经过`seats`标记预订范围的结束。 
3. 处理完所有预订后，迭代`res`来自索引`1`到`n-1`，将每个元素更新为其自身与前一个元素的总和。 这将计算前缀总和，将范围标记转换为实际座位总数。 
4. 返回最终结果`res`大批。 

为什么它有效：`+seatsi`在开始索引处和`-seatsi`在结束索引之后创建一个差异数组。 应用前缀总和可确保该范围内的所有航班`[first, last]`积累`seatsi`，而范围外的航班不受影响。 这保证了正确性，同时减少了不必要的更新。 

## Python 解决方案```python
from typing import List

class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        res = [0] * n
        for first, last, seats in bookings:
            res[first - 1] += seats
            if last < n:
                res[last] -= seats
        for i in range(1, n):
            res[i] += res[i - 1]
        return res
```Python 实现首先为所有航班初始化一个零数组。 然后，它通过在数组中标记预订的开始和结束来处理每个预订。 前缀总和循环有效地在范围内传播座位数，产生最终结果。 

## 解决方案```go
func corpFlightBookings(bookings [][]int, n int) []int {
    res := make([]int, n)
    for _, booking := range bookings {
        first, last, seats := booking[0], booking[1], booking[2]
        res[first-1] += seats
        if last < n {
            res[last] -= seats
        }
    }
    for i := 1; i < n; i++ {
        res[i] += res[i-1]
    }
    return res
}
```在 Go 中，我们初始化一个切片`res`长度`n`。 该方法类似于 Python：我们应用差分数组技术，然后应用前缀和。 Go 需要显式创建切片和整数索引，但逻辑保持不变。 无需处理`nil`因为`make([]int, n)`总是返回一个适当大小的切片。
