 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定字符串中最长子字符串的长度`text`其中所有字符都是相同的，并且我们可以在字符串中交换**恰好两个字符**。 交换可以在任意两个字符之间进行，不一定是相邻的，但我们仅限于每次评估一次交换。 输入`text`是一串小写英文字母，长度可达`2 * 10^4`。 输出是一个整数，表示最佳交换后由重复字符组成的子字符串的最大长度。 

约束表明`text`可能相当长，因此检查所有可能交换的简单方法在计算上是不可行的。 重要的边缘情况包括已经统一的字符串（例如，`"aaaaa"`），只有两个字符交替的字符串（例如，`"ababab"`)，或最佳交换不会立即组合相邻字符组的字符串。 

我们需要考虑每个字符的频率以及重复字符块之间的间隙。 关键的观察是，我们可能只需要合并**由单个不同字符分隔的同一字符的两个块**，并且最多允许一次交换，可能会利用该字符在字符串中其他位置的其他出现。 

## 方法

 **暴力方法**将尝试两个字符的所有可能的交换，重新计算最长重复字符子字符串的长度，并跟踪最大值。 虽然这保证了正确的答案，但效率非常低，因为有`O(n^2)`可能的交换并评估每个子串是`O(n)`，导致`O(n^3)`时间复杂度。 为了`n`最多`2 * 10^4`，这是不可行的。 

**最佳方法**依赖于对连续的相同字符进行分组，并通过与同一字符的其他实例交换或合并由单个不同字符分隔的块来分析扩展这些组的机会。 主要步骤是识别字符块，计算每个字符出现的总次数，并检查每个块以确定一次交换可实现的最大扩展长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 交换所有对并每次重新计算最长的重复子串 |
 | 最佳 | O(n) | O(26 + n) ≈ O(n) | O(26 + n) ≈ O(n) | 使用连续字符分组和频率计数来有效计算最大长度 |

 ## 算法演练

 1.遍历字符串`text`并创建一个块列表，其中每个块代表相同字符的连续序列。 每个块存储字符、其起始索引及其长度。 
2. 创建整个字符串中每个字符的总出现次数的频率图。 这有助于检查是否有其他角色实例需要交换。 
3. 初始化变量`max_len`存储找到的最大重复子串长度。 
4. 迭代每个块并计算两个可能的扩展：

 - **同一块内的扩展**：如果字符串中其他位置（来自频率图）至少再出现一次相同字符，则当前块的长度可以增加 1，从而允许交换。 
- **跨单字符间隙合并**：如果一个块与同一字符的另一个块仅被一个不同的字符分隔开，请考虑将它们合并。 如果其他地方存在该字符的其他实例，则合并长度可以增加 1。 
5. 更新`max_len`对于每个评估的场景。 
6. 返回`max_len`。 

**为什么有效：** 通过对连续的相同字符进行分组并使用字符频率信息，我们可以有效地捕获所有扩展重复字符子字符串的机会。 我们要么在一个块内扩展，要么跨一个字符间隙合并，以确保我们考虑所有有效的交换。 由于我们只检查每个块及其邻居，因此该算法相对于字符串长度呈线性运行。 

## Python 解决方案```python
class Solution:
    def maxRepOpt1(self, text: str) -> int:
        from collections import Counter

        n = len(text)
        if n == 1:
            return 1

        # Step 1: Count total occurrences of each character
        freq = Counter(text)

        # Step 2: Create blocks of consecutive characters
        blocks = []
        i = 0
        while i < n:
            char = text[i]
            start = i
            while i < n and text[i] == char:
                i += 1
            blocks.append((char, start, i - start))  # (character, start index, length)

        max_len = 0

        # Step 3: Evaluate each block
        for j, (char, start, length) in enumerate(blocks):
            # Option 1: Extend block with another occurrence of same char
            if freq[char] > length:
                max_len = max(max_len, length + 1)
            else:
                max_len = max(max_len, length)

            # Option 2: Merge with block two positions away if separated by one different char
            if j > 0 and j < len(blocks) - 1:
                prev_char, _, prev_len = blocks[j - 1]
                next_char, _, next_len = blocks[j + 1]
                if prev_char == next_char and length == 1 and prev_char == char:
                    continue  # single-char block not matching the previous, skip
                if prev_char == next_char and length == 1 and prev_char == char:
                    continue
                if prev_char == next_char and length == 1:
                    merged_len = prev_len + next_len
                    # Can we swap one more char in?
                    if freq[prev_char] > merged_len:
                        merged_len += 1
                    max_len = max(max_len, merged_len)

            # Option 3: Merge with next block if same char
            if j < len(blocks) - 1:
                next_char, _, next_len = blocks[j + 1]
                if next_char == char:
                    merged_len = length + next_len
                    if freq[char] > merged_len:
                        merged_len += 1
                    max_len = max(max_len, merged_len)

        return max_len
```**实现演练：** 该解决方案首先计算字符出现的总数，然后构造连续相同字符的块。 它迭代每个块，以考虑使用交换扩展它或与相邻块合并（如果由单个不同字符分隔）。 结果被追踪到`max_len`。 

## 解决方案```go
func maxRepOpt1(text string) int {
    n := len(text)
    if n == 1 {
        return 1
    }

    freq := make(map[byte]int)
    for i := 0; i < n; i++ {
        freq[text[i]]++
    }

    type block struct {
        char  byte
        start int
        length int
    }

    var blocks []block
    i := 0
    for i < n {
        ch := text[i]
        start := i
        for i < n && text[i] == ch {
            i++
        }
        blocks = append(blocks, block{ch, start, i - start})
    }

    maxLen := 0
    for j := 0; j < len(blocks); j++ {
        ch := blocks[j].char
        length := blocks[j].length

        if freq[ch] > length {
            maxLen = max(maxLen, length+1)
        } else {
            maxLen = max(maxLen, length)
        }

        if j > 0 && j < len(blocks)-1 && blocks[j].length == 1 {
            if blocks[j-1].char == blocks[j+1].char {
                mergedLen := blocks[j-1].length + blocks[j+1].length
                if freq[blocks[j-1].char] > mergedLen {
                    mergedLen++
                }
                maxLen = max(maxLen, mergedLen)
            }
        }

        if j < len(blocks)-1 && blocks[j+1].char == ch {
            mergedLen := length + blocks[j+1].length
            if freq[ch] > mergedLen {
                mergedLen++
            }
            maxLen = max(maxLen, mergedLen)
        }
    }

    return maxLen
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```**Go 注释：** Go 实现反映了 Python 方法。 地图用于频率计数。 一个结构体`block`表示连续的字符序列。 切片索引安全处理邻居，还有一个帮手`max`函数取代了Python的内置函数`max`。
