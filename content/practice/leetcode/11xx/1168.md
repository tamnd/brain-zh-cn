 **难度：** 🔴难
 **主题：**并查集、图论、堆（优先级队列）、最小生成树

 ## 解决方案

 ## 问题理解

 问题要求我们以最具成本效益的方式为一个村庄的所有房屋供水。 每栋房屋都有两种选择：要么以固定成本在房屋内建造一口井，要么通过管道将房屋连接到另一栋房屋，其中每根管道都有自己的建筑成本。 目标是找到水井和管道的组合，最大限度地降低向所有房屋供水的总成本。 

输入如下：`n`是房屋数量，`wells`是一个数组，其中`wells[i - 1]`代表在室内建造一口井的成本`i`， 和`pipes`是一个三元组列表`[house1, house2, cost]`表示之间的双向管道建设成本`house1`和`house2`。 输出是一个整数，表示供水的最低总成本。 

约束表明`n`管道数量可达1万根，成本可达10万。 这告诉我们，探索井和管道的所有组合的强力方法是不可行的。 重要的边缘情况包括建造一口井比任何管道连接都便宜的情况，或者多条管道连接同一对房屋但成本不同的情况。 

## 方法

 强力方法会考虑建井和连接管道的每一种组合。 对于每个带有水井的房屋子集，我们将尝试所有可能的管道配置来为其余房屋供水。 虽然这可以保证找到最小成本，但由于组合爆炸，在计算上是不可行的，特别是因为房屋和管道的数量可以达到 10,000 个。 

最佳解决方案的关键见解来自图论。 我们可以将这个问题视为寻找最小生成树（MST）。 我们引入一个代表水源的虚拟节点，并将其连接到每个房屋，其边权重等于建井成本。 然后，我们将所有管道视为房屋之间的规则边缘。 使用带有并查找的 Kruskal 算法或带有优先级队列的 Prim 算法，我们可以有效地找到 MST，它表示向所有房屋供水的水井和管道的最小组合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * m) | O(2^n * m) | O(n + m) | 探索所有井和管道组合，对于 n ~ 10^4 不可行 |
 | 最佳 (MST) | O((n + m) log (n + m)) | O((n + m) log (n + m)) | O(n + m) | 将井视为虚拟节点的边，使用 Kruskal 或 Prim 算法 |

 ## 算法演练

 1.引入虚拟节点0代表水源。 将这个节点连接到每个房子`i`边权重等于`wells[i-1]`。 
2. 处理原件`pipes`数组作为房屋之间的边缘。 
3. 将所有边合并到一个列表中：从虚拟节点到每个房屋的边加上所有管道。 
4. 按成本升序对所有边进行排序。 这确保了 MST 算法首先考虑更便宜的连接。 
5. 初始化并查（不相交集并集）数据结构来跟踪连接的组件。 
6. 迭代已排序的边。 对于每条边，如果两个节点尚未连接，则将该边添加到 MST 并合并它们的集合。 积累成本。 
7. 继续进行，直到所有房屋都连接到供水系统。 此时，累计成本就是总成本最小。 

工作原理：MST 保证连接图中所有节点的总权重最小。 通过将井视为虚拟源节点的边，该算法自然会在建造井和连接管道之间选择更便宜的选项。 

## Python 解决方案```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return False
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1
        return True

class Solution:
    def minCostToSupplyWater(self, n: int, wells: List[int], pipes: List[List[int]]) -> int:
        edges = [[0, i + 1, wells[i]] for i in range(n)]
        edges.extend(pipes)
        edges.sort(key=lambda x: x[2])

        uf = UnionFind(n + 1)
        total_cost = 0

        for u, v, cost in edges:
            if uf.union(u, v):
                total_cost += cost

        return total_cost
```Python 解决方案首先构建从虚拟节点到每栋房屋的边，并将它们与给定的管道组合起来。 排序确保我们首先处理最便宜的连接。 Union-Find 管理连接并防止循环，同时累积总的最低成本。 

## 解决方案```go
package main

import "sort"

type UnionFind struct {
	parent []int
	rank   []int
}

func NewUnionFind(n int) *UnionFind {
	parent := make([]int, n)
	rank := make([]int, n)
	for i := 0; i < n; i++ {
		parent[i] = i
	}
	return &UnionFind{parent, rank}
}

func (uf *UnionFind) Find(x int) int {
	if uf.parent[x] != x {
		uf.parent[x] = uf.Find(uf.parent[x])
	}
	return uf.parent[x]
}

func (uf *UnionFind) Union(x, y int) bool {
	rootX, rootY := uf.Find(x), uf.Find(y)
	if rootX == rootY {
		return false
	}
	if uf.rank[rootX] < uf.rank[rootY] {
		uf.parent[rootX] = rootY
	} else if uf.rank[rootX] > uf.rank[rootY] {
		uf.parent[rootY] = rootX
	} else {
		uf.parent[rootY] = rootX
		uf.rank[rootX]++
	}
	return true
}

func minCostToSupplyWater(n int, wells []int, pipes [][]int) int {
	edges := make([][]int, n)
	for i := 0; i < n; i++ {
		edges[i] = []int{0, i + 1, wells[i]}
	}
	edges = append(edges, pipes...)

	sort.Slice(edges, func(i, j int) bool {
		return edges[i][2] < edges[j][2]
	})

	uf := NewUnionFind(n + 1)
	totalCost := 0
	for _, edge := range edges {
		if uf.Union(edge[0], edge[1]) {
			totalCost += edge[2]
		}
	}
	return totalCost
}
```在 Go 中，实现镜像了 Python，但注意切片分配和排序函数语法。 Union-Find 被实现为带有方法的结构体。
