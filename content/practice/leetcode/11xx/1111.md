[LeetCode 第 1111 题](https://leetcode.com/problems/maximum-nesting-depth-of-two-valid-parentheses-strings/)

 **难度：** 🟡 中等
 **主题：** 字符串、堆栈

 ## 解决方案

 ## 问题理解

 该问题要求我们采用有效的括号字符串`seq`并将其分成两个不相交的子序列`A`和`B`这样每个子序列本身就是一个有效的括号字符串（VPS）。 目标是将每个角色分配给`seq`到任一`A`或者`B`以最小化两个子序列之间的最大嵌套深度的方式。 

输入`seq`是一个仅包含`'('`和`')'`并且保证是VPS。 输出是一个长度相同的整数数组`seq`， 在哪里`0`表示该角色属于`A`和`1`表明它属于`B`。 

约束告诉我们输入的长度最多可达 10,000 个字符。 这排除了时间复杂度低于 O(n) 的解决方案。 边缘情况包括非常浅的 VPS 字符串，例如`"()"`和非常深的字符串，例如`"(((((())))))"`，以及嵌套深度已经完美平衡的字符串。 

## 方法

 暴力方法会尝试所有可能的方法将括号划分为两个 VPS，然后计算每个 VPS 的深度。 虽然这在原则上是正确的，但这是不可行的，因为分区方式的数量随着字符串的长度呈指数增长，从而给出 O(2^n) 时间复杂度。 

最佳解决方案的关键洞察是观察嵌套深度与括号级别的交替。 如果我们在遍历字符串时跟踪当前深度，我们可以在偶数深度处分配括号`A`和奇数深度`B`（或反之亦然）。 这保证了每个子序列仍然是有效的 VPS 并平衡它们之间的嵌套深度。 

通过基于深度奇偶校验的分割，我们确保两个子序列在任何位置都不会超过总嵌套的一半，从而最大限度地减少`max(depth(A), depth(B))`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 将 seq 的所有分区枚举到 VPS 中，计算深度，选择最小最大深度 |
 | 最佳 | O(n) | O(n) | 根据当前深度奇偶校验分配括号，增量跟踪深度 |

 ## 算法演练

 1. 初始化变量`depth`到 0。这将在我们迭代序列时跟踪当前的嵌套级别。 
2.初始化一个空数组`answer`保存每个括号的赋值。 
3. 迭代每个字符`c`在`seq`。 
4. 如果`c`是`'('`, 增量`depth`by 1.然后分配这个`'('`到子序列`A`如果`depth % 2 == 1`，否则到`B`。 店铺`0`或者`1`在`answer`因此。 
5. 如果`c`是`')'`，将其分配给与其对应的相同子序列`'('`使用`depth % 2`，然后递减`depth`乘 1。这可确保右括号与同一子序列中的左括号平衡。 
6. 继续，直到分配完所有字符。 
7. 返回`answer`。 

**为什么有效：** 通过基于深度奇偶性的交替分配，每个子序列接收一半的嵌套级别。 这保证了双方`A`和`B`保持有效的 VPS 并且最大嵌套深度被最小化。 这些分配确保所有打开都与同一子序列中的关闭相匹配。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        answer = []
        depth = 0
        for c in seq:
            if c == '(':
                depth += 1
                answer.append(depth % 2)
            else:
                answer.append(depth % 2)
                depth -= 1
        return answer
```Python解决方案保持运行`depth`柜台。 对于每个`'('`，我们增加深度并根据奇偶校验进行分配。 对于每个`')'`，我们首先根据奇偶校验进行分配，然后递减。 使用`depth % 2`确保平衡分裂的交替分配。 

## 解决方案```go
func maxDepthAfterSplit(seq string) []int {
    answer := make([]int, len(seq))
    depth := 0
    for i, c := range seq {
        if c == '(' {
            depth++
            answer[i] = depth % 2
        } else {
            answer[i] = depth % 2
            depth--
        }
    }
    return answer
}
```Go 版本反映了 Python 逻辑。 一片`answer`是为了效率而预先分配的。 深度递增/递减，并使用模 2 进行交替分配，确保最小的最大嵌套深度。

 ## 边缘情况

 一种边缘情况是空字符串。 该算法正确返回一个空数组，因为没有要分配的括号，从而保持了 O(1) 时间行为。 

另一个边缘情况是深度嵌套的字符串，例如`"((((()))))"`。 如果不跟踪深度，天真的拆分可能会将所有括号放入一个子序列中，从而不必要地最大化嵌套。 深度奇偶校验方法平衡子序列之间的括号。 

第三种边缘情况是具有重复对的扁平 VPS，例如`"()()()()"`。 每个`'('`和`')'`对应该在子序列之间交替。 未能交替将导致一个子序列占据所有对并具有不必要的深度。 基于模的分配确保最小的最大深度。
