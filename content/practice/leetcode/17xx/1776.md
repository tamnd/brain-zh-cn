[LeetCode 问题 1776](https://leetcode.com/problems/car-fleet-ii/)

 **难度：** 🔴难
 **主题：** 数组、数学、堆栈、堆（优先级队列）、单调堆栈

 ## 解决方案

 ## 问题理解

 问题是要求我们计算一排汽车中的每辆车与其前面的汽车相撞的时间，或者返回`-1`如果它永远不会碰撞。 每辆车都由其位置和速度表示。 汽车最初按位置升序排列，速度可能会有所不同。 当两辆车占据相同位置时就会发生碰撞。 碰撞后，汽车以两辆车的**较慢速度**一起移动。 

输入`cars`是一个列表`[position, speed]`对，其中`position`是严格增加的。 这保证了没有两辆车在同一位置出发。 输出是一个数组`answer`相同长度，其中`answer[i]`是以秒为单位的时间`i-th`汽车与其正前方的汽车相撞，或者`-1`如果它永远不会碰撞。 答案应在以下范围内准确`10^-5`。 

重要的限制和观察：

 - 最多`10^5`汽车，所以天真的 O(n²) 方法会太慢。 
- 位置和速度为正整数，最大可达`10^6`。 
- 汽车已经按位置排序，简化了我们的遍历逻辑。 
- 碰撞传播：车队形成后，车队的速度是组成车辆速度中的最小值。 随后的车辆可能会与该车队发生碰撞。 

关键边缘情况：

 1. 一辆车比前面的车快，最终会相撞。 
2. 一辆车比前面的车慢，永远不会相撞。 
3. 一辆汽车与车队相撞，而不是与单辆汽车相撞。 
4. 只有一辆车存在。 

## 方法

 暴力方法将迭代每辆车，计算与前面的每辆车碰撞直到发现碰撞所需的时间，并记录第一次碰撞。 虽然正确，但由于嵌套循环，这是 O(n²)，并且对于`n = 10^5`。 

最佳方法利用**单调堆栈**从后到前处理汽车。 通过跟踪前方潜在的碰撞，我们只需要检查下一辆车/车队的碰撞时间。 如果在我们当前的汽车到达后下一辆车/车队更快或发生碰撞，我们会跳过它。 这保证了 O(n) 时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 通过检查前面的所有汽车来计算每辆车的碰撞时间。 对于大输入来说速度太慢。 |
 | 最佳 | O(n) | O(n) | 单调堆栈从后到前跟踪汽车/车队，有效计算碰撞时间。 |

 ## 算法演练

 1. 初始化一个堆栈以从后到前跟踪汽车的索引。 该堆栈将代表当前汽车可能发生碰撞的汽车。 
2. 初始化`answer`数组到`-1`对于所有汽车，默认表示没有碰撞。 
3. 从右到左遍历汽车。 对于每辆车：

 1. 当堆栈不为空时，使用以下公式计算与堆栈顶部的汽车的碰撞时间`(position[next] - position[current]) / (speed[current] - speed[next])`。 
2.如果当前车比前车慢或者前车与另一辆车相撞后将发生碰撞，则弹出堆栈并检查下一辆车。 
3. 如果存在有效的碰撞时间，则将其存储在`answer[current]`。 
4. 将当前汽车索引压入堆栈。 
5. 返回`answer`大批。 

工作原理：通过从后到前处理并维护一堆潜在碰撞，我们确保每辆车只检查前方的相关车辆。 该堆栈有效地使汽车保持“潜在碰撞时间的单调顺序”，从而确保了 O(n) 复杂性。 

## Python 解决方案```python
from typing import List

class Solution:
    def getCollisionTimes(self, cars: List[List[int]]) -> List[float]:
        n = len(cars)
        answer = [-1.0] * n
        stack = []  # stores indices of cars that are potential collisions
        
        for i in range(n - 1, -1, -1):
            position_i, speed_i = cars[i]
            
            while stack:
                j = stack[-1]
                position_j, speed_j = cars[j]
                
                if speed_i <= speed_j:
                    stack.pop()
                    continue
                
                time_to_collide = (position_j - position_i) / (speed_i - speed_j)
                
                if answer[j] != -1 and time_to_collide > answer[j]:
                    stack.pop()
                    continue
                
                answer[i] = time_to_collide
                break
            
            stack.append(i)
        
        return answer
```代码初始化`answer`以及一个维护潜在冲突索引的堆栈。 我们向后迭代，计算与下一辆车/车队的碰撞时间，并更新`answer`因此。 无法碰撞的汽车将从堆叠中移除。 

## 解决方案```go
func getCollisionTimes(cars [][]int) []float64 {
    n := len(cars)
    answer := make([]float64, n)
    for i := range answer {
        answer[i] = -1.0
    }
    stack := []int{}
    
    for i := n - 1; i >= 0; i-- {
        positionI, speedI := cars[i][0], cars[i][1]
        
        for len(stack) > 0 {
            j := stack[len(stack)-1]
            positionJ, speedJ := cars[j][0], cars[j][1]
            
            if speedI <= speedJ {
                stack = stack[:len(stack)-1]
                continue
            }
            
            timeToCollide := float64(positionJ-positionI) / float64(speedI-speedJ)
            
            if answer[j] != -1 && timeToCollide > answer[j] {
                stack = stack[:len(stack)-1]
                continue
            }
            
            answer[i] = timeToCollide
            break
        }
        
        stack = append(stack, i)
    }
    
    return answer
}
```在 Go 中，使用切片而不是列表。 类型转换为`float64`确保正确划分。 该逻辑在其他方面反映了 Python 解决方案。 

## 工作示例

 **示例1：**`cars = [[1,2],[2,1],[4,3],[7,2]]`从右开始迭代：

 | 我| 堆栈| 碰撞时间计算 | 答案|
 | --- | --- | --- | --- |
 | 3 | []| 前面没有车 | [-1,-1,-1,-1] |
 | 2 | [3] | (7-4)/(3-2)=3 | [-1,-1,3,-1] |
 | 1 | [2,3]| 速度1 <= 3 → 弹出2； 速度 1 <= 2 → 弹出 3 → 无碰撞 | [-1,-1,3,-1] |
 | 0 | [1] | (2-1)/(2-1)=1 | (2-1)/(2-1)=1 | [1,-1,3,-1] |

 **示例2：**`cars = [[3,4],[5,4],[6,3],[9,1]]`| 我| 堆栈| 碰撞时间 | 答案|
 | --- | --- | --- | --- |
 | 3 | []| -1 | [-1,-1,-1,-1] |
 | 2 | [3] | (9-6)/(3-1)=1.5 | [-1,-1,1.5,-1] |
 | 1 | [2,3]| (6-5)/(4-3)=1 | [-1,1,1.5,-1] |
 | 0 | [1,2,3]| (5-3)/(4-4) 无效 → 跳过，下一个 j=2 (6-3)/(4-3)=3 > 答案[2]=1.5 → 跳过 → j=3 (9-3)/(4-1)=2 → 有效 | [2,1,1.5,-1] |

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每辆车最多从堆栈中推送和弹出一次，给出线性时间。 |
 | 空间| O(n) | 堆栈和答案数组各自占用 O(n) 空间。 |

 单调堆栈确保我们只考虑碰撞计算所需的汽车，避免 O(n²) 强力比较。
