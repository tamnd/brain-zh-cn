[LeetCode 问题 1771](https://leetcode.com/problems/maximize-palindrome-length-from-subsequences/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 这个问题给了我们两个字符串，`word1`和`word2`。 我们必须从每个字符串中选择一个非空子序列，将它们连接在一起，形成一个回文。 我们的目标是最大化回文的长度。 

子序列不要求字符是连续的。 只要剩余字符保留其原始顺序，我们就可以跳过字符。 这种灵活性很重要，因为它意味着我们正在有效地搜索许多可能的组合。 

关键限制是最终回文必须使用至少一个字符`word1`并且至少有一个字符来自`word2`。 我们不允许仅从一根字符串中取出整个回文。 

输入大小很重要：

 -`1 <= word1.length, word2.length <= 1000`这意味着总的组合长度可以达到2000。对所有子序列进行暴力搜索是完全不可行的，因为子序列的数量呈指数级增长。 

预期输出是表示最大可能回文长度的单个整数。 如果无法使用两个字符串中的字符形成回文，我们返回`0`。 

一些边缘情况很重要：

 - 两个字符串可能根本不共享公共字符，从而无法形成有效的回文。 
- 最佳回文可能不会使用所有字符。 
- 回文长度可以是偶数或奇数。 
- A naive longest palindromic subsequence solution on the concatenated string is not enough, because we must guarantee usage of both original strings.

 The core challenge is therefore not just finding a palindrome, but finding one whose left and right portions cross the boundary between the two strings.

 ## 方法

 ### 蛮力方法

 暴力解决方案将生成每个非空子序列`word1`以及每个非空子序列`word2`。 对于每一对，我们将它们连接起来并检查生成的字符串是否是回文。 

认为`word1`有长度`n`和`word2`有长度`m`。 

-`word1`有`2^n - 1`非空子序列。 
-`word2`有`2^m - 1`非空子序列。 

因此，我们将粗略地检查：$$(2^n - 1)(2^m - 1)$$可能的串联。 

即使对于长度为 30 的字符串，这也会变得天文数字般大。 当长度达到 1000 时，这种方法是不可能的。 

蛮力方法在概念上是正确的，因为它详尽地检查了每个有效的构造，但它不能满足约束。 

### 最优动态规划洞察

 关键的观察是该问题可以转化为连接字符串上的最长回文子序列问题：```
s = word1 + word2
```然而，我们不能简单地计算最长回文子序列`s`，因为该回文可能完全位于一根字符串内。 

重要的见解是：

 - 任何有效的回文必须至少包含一个匹配对，其中：

 - 左边的字符来自`word1`- 正确的字符来自`word2`一旦我们识别出这样的匹配对，内部部分就可以是它们之间的任何回文子序列。 

这自然暗示了区间动态规划。 

定义：```
dp[i][j]
```作为内部最长回文子序列的长度`s[i:j+1]`。 

递归是标准的最长回文子序列递归：

 - 如果`s[i] == s[j]`：```
dp[i][j] = dp[i+1][j-1] + 2
```- 否则：```
dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```附加约束单独处理：

 每当我们找到匹配的字符时：

 -`i`属于`word1`-`j`属于`word2`然后`dp[i][j]`表示一个肯定使用两个字符串中的字符的回文，因此我们可以更新答案。 

这给出了有效的多项式时间解。

 ## 算法演练

 ### 第 1 步：连接字符串

 我们创造：```
s = word1 + word2
```这使我们能够将该问题视为单区间 DP 问题。 

让：

-`n = len(word1)`-`m = len(word2)`-`total = n + m`指数：

 -`[0, n-1]`属于`word1`-`[n, total-1]`属于`word2`### Step 2: Define the DP State

 我们定义：```
dp[i][j]
```意思是：

 > 子串内最长回文子序列的长度`s[i:j+1]`。 

这是一个经典的区间 DP 定义。 

### 第 3 步：初始化基本案例

 每个字符都是长度为 1 的回文：```
dp[i][i] = 1
```### 步骤 4：按长度处理间隔

 我们计算越来越大的子串的答案。 

对于每个间隔`[i, j]`：

- 如果`s[i] == s[j]`：

 - 这些字符可以形成回文的外部对。 
- 所以：```
dp[i][j] = dp[i+1][j-1] + 2
```- 否则：

 - 我们跳过一个端点：```
dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```### 步骤 5：跟踪有效的交叉字符串回文

 该问题需要使用两个字符串中的字符。 

因此，每当：

 -`s[i] == s[j]`-`i < n`-`j >= n`我们知道：

 - 左边的字符来自`word1`- 正确的字符来自`word2`所以`dp[i][j]`表示使用两个字符串的有效回文。 

我们更新：```
answer = max(answer, dp[i][j])
```###第6步：返回结果

 填完DP表后，`answer`包含最大有效回文长度。 

如果不存在有效的跨串回文，`answer`遗迹`0`。 

### 为什么它有效

 DP 递归正确计算每个间隔的最长回文子序列，因为每个最佳回文子序列要么：

 - 如果两个端点匹配，则使用它们，或者
 - 否则排除一个端点。 

附加的交叉字符串检查可确保回文包含两个原始字符串中的字符。 由于每个有效的回文最终都必须包含一个跨越边界的外部匹配对，因此检查这些对足以确保正确性。 

## Python 解决方案```python
class Solution:
    def longestPalindrome(self, word1: str, word2: str) -> int:
        s = word1 + word2
        n1 = len(word1)
        total = len(s)

        dp = [[0] * total for _ in range(total)]

        for i in range(total):
            dp[i][i] = 1

        answer = 0

        for length in range(2, total + 1):
            for i in range(total - length + 1):
                j = i + length - 1

                if s[i] == s[j]:
                    if length == 2:
                        dp[i][j] = 2
                    else:
                        dp[i][j] = dp[i + 1][j - 1] + 2

                    if i < n1 and j >= n1:
                        answer = max(answer, dp[i][j])
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        return answer
```该实现首先将两个输入字符串连接成一个字符串`s`。 这简化了区间 DP 公式，因为现在每个回文都可以被视为一个字符串内的子序列。 

DP 表用零初始化，每个对角线条目都设置为`1`因为单个字符始终是回文。 

外循环迭代子字符串长度`2`直到整个字符串长度。 这个顺序很重要，因为`dp[i][j]`取决于较小的间隔，例如`dp[i+1][j-1]`。 

当端点匹配时，我们从内部区间扩展回文。 对长度进行特殊处理`2`避免访问无效的内部间隔。 

每当匹配对从`word1`进入`word2`，我们更新答案。 这保证了回文使用两个字符串中的字符。 

如果端点不匹配，我们将继承排除左端点或排除右端点的最佳答案。 

最后，算法返回找到的最大有效回文长度。 

## 解决方案```go
func longestPalindrome(word1 string, word2 string) int {
	s := word1 + word2
	n1 := len(word1)
	total := len(s)

	dp := make([][]int, total)
	for i := range dp {
		dp[i] = make([]int, total)
		dp[i][i] = 1
	}

	answer := 0

	for length := 2; length <= total; length++ {
		for i := 0; i+length-1 < total; i++ {
			j := i + length - 1

			if s[i] == s[j] {
				if length == 2 {
					dp[i][j] = 2
				} else {
					dp[i][j] = dp[i+1][j-1] + 2
				}

				if i < n1 && j >= n1 {
					if dp[i][j] > answer {
						answer = dp[i][j]
					}
				}
			} else {
				if dp[i+1][j] > dp[i][j-1] {
					dp[i][j] = dp[i+1][j]
				} else {
					dp[i][j] = dp[i][j-1]
				}
			}
		}
	}

	return answer
}
```Go 实现遵循与 Python 版本相同的动态编程结构。 主要区别在于二维 DP 表的显式切片分配。 

Go 字符串是字节索引的，这里可以正常工作，因为输入仅包含小写英文字母。 不需要 Unicode 处理。 

由于 Go 没有提供内置的`max`整数函数，比较是手动处理的`if`声明。

 ## 边缘情况

 ### 字符串之间没有共享字符

 如果两个字符串没有共同字符，则不可能使用这两个字符串形成回文，因为每个回文都需要两侧的字符匹配。 

例子：```
word1 = "abc"
word2 = "def"
```执行正确返回`0`因为没有找到跨界匹配对。 

### 单字符串

 非常小的输入可能会暴露索引错误，特别是在涉及间隔 DP 转换的情况下`dp[i+1][j-1]`。 

例子：```
word1 = "a"
word2 = "a"
```该实现通过长度子字符串的特殊情况安全地处理这个问题`2`。 

### 完全在一个字符串内的回文

 标准的最长回文子序列算法会错误地允许解决方案完全包含在一个字符串中。 

例子：```
word1 = "racecar"
word2 = "x"
```连接字符串内最长的回文是`"racecar"`长度为 7，但不使用以下字符`word2`。 

该实现通过仅在匹配端点跨越两个原始字符串之间的边界时更新答案来避免此错误。
