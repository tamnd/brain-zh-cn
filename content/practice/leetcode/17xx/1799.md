 ## 解决方案

 ## 问题理解

 该问题要求我们最大化通过执行获得的总分`n`对数组的操作`nums`尺寸的`2 * n`。 在每个操作中，您从数组中选择两个元素，计算这两个元素的最大公约数 (GCD)，将其乘以操作索引（1 索引），将其添加到您的分数中，然后从数组中删除这两个元素。 目标是确定在所有操作完成后产生最大可能分数的元素配对序列。 

输入`nums`是一个正整数数组。 输出是一个整数，表示执行后可达到的最大分数`n`运营。 考虑到约束条件（`1 <= n <= 7`,`nums.length == 2 * n`,`1 <= nums[i] <= 10^6`），数组相对较小，但可能配对的数量呈阶乘增长。 这使得暴力方法对于较大的值不可行`n`。 

要考虑的关键边缘情况包括所有元素都相同的数组（所有对的 GCD 都最大）、具有素数的数组（GCD 可能为 1）以及策略配对对于最大化加权分数至关重要的数组。 

## 方法

 暴力方法将生成所有可能的配对序列并计算每个配对的分数。 这保证了正确的答案，但计算成本很高，因为`2 * n`元素，唯一配对的数量是`(2 * n)! / (2^n * n!)`，增长速度极快。 这种方法只适用于非常小的情况`n`。 

最佳方法使用**带位掩码的动态编程**。 我们使用位掩码表示数组的状态，其中每个位指示元素是否仍然可用。 对于每个状态，我们尝试所有可能的未使用元素对，计算该操作的分数，并递归地找到剩余元素的最大分数。 记忆化存储先前计算的状态以避免冗余计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((2n)!) | O((2n)!) | O((2n)!) | O((2n)!) | 生成所有配对并计算分数，对于 n > 4 不可行 |
 | 最佳（DP + 位掩码）| O(4^n * n^2) | O(4^n * n^2) | O(2^(2n)) | O(2^(2n)) | 位掩码 DP 跟踪使用的元素； 递归记忆避免重新计算|

 ## 算法演练

 1. 预先计算所有可能的 GCD 对。 由于数组有`2 * n`元素，这需要计算所有对的 GCD，这允许在递归期间快速查找。 
2. 定义递归函数`dfs(mask)`在哪里`mask`是表示所使用元素的位掩码。 位设置为 1 表示该元素已使用，0 表示该元素可用。 
3. 如果使用所有元素（`mask == (1 << 2*n) - 1`)，返回 0，因为无法获得进一步的分数。 
4. 计算已使用的元素数量（在中设置的位数）`mask`) 确定当前运行索引：`op_index = used_count // 2 + 1`。 
5. 迭代所有未使用的元素对`(i, j)`。 对于每对：

 a. 计算新掩码，并将两个元素标记为已使用。 

b. 计算此操作的分数：`op_index * gcd(nums[i], nums[j])`。 

c. 递归调用`dfs(new_mask)`以获得剩余元素的最大分数。 

d. 追踪所有配对的最高分。 
6. 记住结果`mask`以避免重新计算。 
7. 返回从以下位置开始的最高分数`mask = 0`。 

**为什么有效**：带有位掩码的 DP 确保数组的每个子集都被恰好考虑一次。 通过存储每个掩码的结果，我们避免了冗余计算。 操作索引正确递增，因为它取决于到目前为止使用的元素数量。 这保证了所有配对都得到最佳探索。 

## Python 解决方案```python
from math import gcd
from functools import lru_cache
from typing import List

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums) // 2
        
        # Precompute all pairwise GCDs
        pair_gcd = [[0] * (2*n) for _ in range(2*n)]
        for i in range(2*n):
            for j in range(i+1, 2*n):
                pair_gcd[i][j] = gcd(nums[i], nums[j])
        
        @lru_cache(None)
        def dfs(mask: int) -> int:
            used_count = bin(mask).count("1")
            if used_count == 2 * n:
                return 0
            op_index = used_count // 2 + 1
            max_score = 0
            for i in range(2*n):
                if not (mask & (1 << i)):
                    for j in range(i+1, 2*n):
                        if not (mask & (1 << j)):
                            new_mask = mask | (1 << i) | (1 << j)
                            score = op_index * pair_gcd[i][j] + dfs(new_mask)
                            max_score = max(max_score, score)
            return max_score
        
        return dfs(0)
```**实现说明**：为了提高效率，我们首先预先计算所有成对的 GCD。 递归函数`dfs`使用位掩码来表示已使用的元素。 对于每个状态，它会尝试所有未使用的对，计算当前操作的分数，并递归地评估剩余元素。 记忆通过`lru_cache`确保每个掩码仅计算一次。 

## 解决方案```go
package main

import (
    "math/bits"
)

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func maxScore(nums []int) int {
    n := len(nums) / 2
    pairGCD := make([][]int, 2*n)
    for i := range pairGCD {
        pairGCD[i] = make([]int, 2*n)
    }
    for i := 0; i < 2*n; i++ {
        for j := i + 1; j < 2*n; j++ {
            pairGCD[i][j] = gcd(nums[i], nums[j])
        }
    }

    memo := make(map[int]int)

    var dfs func(mask int) int
    dfs = func(mask int) int {
        if val, ok := memo[mask]; ok {
            return val
        }
        usedCount := bits.OnesCount(uint(mask))
        if usedCount == 2*n {
            return 0
        }
        opIndex := usedCount/2 + 1
        maxScore := 0
        for i := 0; i < 2*n; i++ {
            if mask&(1<<i) == 0 {
                for j := i + 1; j < 2*n; j++ {
                    if mask&(1<<j) == 0 {
                        newMask := mask | (1 << i) | (1 << j)
                        score := opIndex*pairGCD[i][j] + dfs(newMask)
                        if score > maxScore {
                            maxScore = score
                        }
                    }
                }
            }
        }
        memo[mask] = maxScore
        return maxScore
    }

    return dfs(0)
}
```**Go 实现说明**：Go 解决方案反映了 Python 逻辑。 我们使用`bits.OnesCount`计算已使用的元素和`map[int]int`用于记忆，因为 Go 缺乏本机函数装饰器，例如`lru_cache`。 预先计算 GCD 可以避免重复计算。 

## 工作示例

 ### 示例 1：nums = [1,2]

 - 初始掩码 = 0
 - 只能进行一种操作：pair (1,2)，op_index = 1，score = 1 * gcd(1,2) = 1
 - 返回1

 ### 示例 2：nums = [3,4,6,8]

 | 步骤| 掩码（二进制）| 使用次数 | 经营指数| 配对 | 分数 | 总计 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 0000 | 0000 0 | 1 | (3,6) | 3 | 3 + dfs(1010) | dfs(1010)
 | 2 | 1010 | 1010 2 | 2 | (4,8) | 8 | 3+8=11 | 3+8=11

 最终最高分 = 11

 ### 示例 3：nums = [1,2,3,4,5,6]

 - 最佳配对：(1,5)、(2,4)、(3,6)
 - 分数：1_1 + 2_2 + 3*3 = 1 + 4 + 9 = 14
