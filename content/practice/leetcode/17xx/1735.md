 **难度：** 🔴难
 **主题：** 数组、数学、动态规划、组合学、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们计算填充大小数组的方法数`ni`**正整数**使得所有元素的乘积等于`ki`。 输入数组中的每个查询`queries`是独立的，这意味着我们计算每个的答案`(ni, ki)`分别配对。 输出是一个数组，其中每个元素对应于相应查询的有效数组的数量，模`10^9 + 7`由于潜在的巨大结果。 

输入`queries`是一个二维数组，其中每个元素`[ni, ki]`分别表示数组和目标产品的大小。 限制条件`1 <= ni, ki <= 10^4`表明暴力枚举所有数组是不可行的。 我们需要一种数学或组合方法。 要考虑的边缘情况包括数组，其中`ki = 1`（所有元素必须为 1）和素数`ki`（有限的分解选项）。 

该问题保证所有数字都是正整数，因此不会出现零或负数，并且`ni`和`ki`至少为 1。 

## 方法

 **暴力**方法会尝试枚举所有大小的序列`ni`与产品`ki`。 这显然是不可行的，因为即使对于小`ni`和`ki`，可能的序列数量呈指数增长，例如，`ni = 10`和`ki = 100`，有数千种可能的组合。 因此，这种方法将无法达到上限`10^4`。 

**最佳方法**利用**质因数分解和组合数学**。 关键的见解是因式分解`ki`化为素数，例如`ki = 2^a * 3^b * 5^c ...`。 对于每个质因数，将其指数分布在`ni`数组元素相当于**星条问题**，其中非负整数解的数量`x1 + x2 + ... + x_ni = exponent`由二项式系数给出`C(exponent + ni - 1, ni - 1)`。 将这些计数乘以所有质因数即可得出形成数组的方式总数。 我们计算所有内容的模数`10^9 + 7`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(ki^ni) | O(ki^ni) | O(ni) | 枚举所有序列，对于大输入不可行 |
 | 最佳 | O(√ki * log MOD + 查询次数 * log MOD) | O(√ki + 阶乘的 MOD 数组) | 对 ki 进行因式分解并使用组合数学（星形和条形），使用模算术和预先计算的阶乘 |

 ## 算法演练

 1. **预计算阶乘和模逆**：有效计算二项式系数模`10^9 + 7`，预先计算阶乘和逆阶乘，直到最大可能值`ni + max exponent`（约束条件≤ 2*10^4）。 使用费马小定理计算模逆。 
2. **ki的质因数分解**：对于每个查询`(ni, ki)`,因式分解`ki`进入其主要组成部分。 这可以有效地完成到 √ki。 
3. **星形和条形计算**：对于每个带有指数的质因数`e`,计算分配方式的数量`e`之间的相同项目`ni`垃圾箱：`C(e + ni - 1, ni - 1)`。 将所有质因数的结果乘以模`10^9 + 7`。 
4. **聚合结果**：将每个查询的组合计数的乘积存储在输出数组中。 

**为什么有效**：素因数分解减少了乘法问题，从而在数组位置之间分配素数幂。 星形和条形公式保证所有非负整数解都只计算一次。 将结果与素数相乘可确保数组的乘积等于`ki`。 

## Python 解决方案```python
from typing import List

MOD = 10**9 + 7
MAX = 20000  # sufficiently large for factorials

# Precompute factorials and inverses
fact = [1] * (MAX + 1)
inv_fact = [1] * (MAX + 1)

for i in range(1, MAX + 1):
    fact[i] = fact[i - 1] * i % MOD

inv_fact[MAX] = pow(fact[MAX], MOD - 2, MOD)
for i in range(MAX, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def comb(n: int, k: int) -> int:
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

class Solution:
    def waysToFillArray(self, queries: List[List[int]]) -> List[int]:
        def prime_factors(x: int) -> List[int]:
            factors = []
            d = 2
            while d * d <= x:
                count = 0
                while x % d == 0:
                    x //= d
                    count += 1
                if count:
                    factors.append(count)
                d += 1
            if x > 1:
                factors.append(1)
            return factors

        result = []
        for n, k in queries:
            counts = prime_factors(k)
            ways = 1
            for e in counts:
                ways = ways * comb(e + n - 1, n - 1) % MOD
            result.append(ways)
        return result
```该代码首先预先计算阶乘和逆阶乘以进行模二项式系数计算。 对于每个查询，它都会分解`ki`，将星形和条形应用于每个指数，将结果乘以模`10^9 + 7`，并附加到结果列表中。 

## 解决方案```go
package main

const MOD int = 1e9 + 7
const MAX int = 20000

var fact [MAX + 1]int
var invFact [MAX + 1]int

func initFactorials() {
    fact[0] = 1
    for i := 1; i <= MAX; i++ {
        fact[i] = fact[i-1] * i % MOD
    }
    invFact[MAX] = pow(fact[MAX], MOD-2)
    for i := MAX; i > 0; i-- {
        invFact[i-1] = invFact[i] * i % MOD
    }
}

func pow(a, b int) int {
    res := 1
    for b > 0 {
        if b&1 == 1 {
            res = res * a % MOD
        }
        a = a * a % MOD
        b >>= 1
    }
    return res
}

func comb(n, k int) int {
    if k < 0 || k > n {
        return 0
    }
    return fact[n] * invFact[k] % MOD * invFact[n-k] % MOD
}

func primeFactors(x int) []int {
    factors := []int{}
    for d := 2; d*d <= x; d++ {
        count := 0
        for x%d == 0 {
            x /= d
            count++
        }
        if count > 0 {
            factors = append(factors, count)
        }
    }
    if x > 1 {
        factors = append(factors, 1)
    }
    return factors
}

func waysToFillArray(queries [][]int) []int {
    initFactorials()
    res := make([]int, len(queries))
    for i, q := range queries {
        n, k := q[0], q[1]
        counts := primeFactors(k)
        ways := 1
        for _, e := range counts {
            ways = ways * comb(e+n-1, n-1) % MOD
        }
        res[i] = ways
    }
    return res
}
```Go 处理切片和整数乘法模`MOD`。`initFactorials`被调用一次以准备组合计算，并且`primeFactors`返回指数切片。 main 函数类似于 Python 聚合结果。 

## 工作示例

 **示例`[[2,6],[5,1],[73,660]]`：**

询问`(2,6)`主要因素：`6 = 2^1 * 3^1`。 方式=`C(1+2-1, 2-1) * C(1+2-1,2-1) = C(2,1)*C(2,1)=2*2=4`。 

询问`(5,1)`主要因素：`1`隐含地没有素因数`0`指数。 方式=`1`（全 1）。 

询问`(73,660)`主要因素：`660 = 2^2 * 3^1 * 5^1 * 11^1`。 方式=`C(2+73-1,72)*C(1+73-1,72)^3`。 计算模数`10^9 + 7`= 50734910。
