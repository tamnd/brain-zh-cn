 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个身份验证系统来管理具有过期时间的令牌。 每个令牌的有效期是固定的`timeToLive`从生成或更新那一刻算起的秒数。 系统必须支持三种操作：生成新令牌、更新现有未过期令牌以及计算给定时间未过期令牌的数量。 

输入代表该系统上的一系列操作。 为了`generate(tokenId, currentTime)`，一个新的令牌被创建。 为了`renew(tokenId, currentTime)`，仅当令牌尚未过期时，系统才应延长令牌的过期时间。 为了`countUnexpiredTokens(currentTime)`，我们需要返回此时有多少令牌仍然有效。 

重要的限制和观察包括：所有`currentTime`值严格递增，因此我们永远不需要处理过去的事件。 全部`generate`调用具有唯一的令牌 ID，因此两个令牌不会共享相同的 ID。 最大操作数较小（最多 2000 个），但`timeToLive`和`currentTime`可以非常大（最多 10^8），这排除了迭代所有可能次数或每秒模拟的简单方法。 

关键的边缘情况包括尝试续订已过期的令牌、在不同时间生成具有不同 ID 的多个令牌，以及在过期时间精确计算未过期令牌，这发生在该时间戳的任何操作之前。 

## 方法

 暴力方法会将每个令牌及其过期时间存储在列表或字典中。 每次`renew`或者`countUnexpiredTokens`被调用时，我们迭代所有令牌并检查它们是否已过期。 这种方法是正确的，但对于大量令牌来说效率低下，因为每个操作可能是 O(n)，在最坏的情况下导致总共 O(n^2) 复杂度。 

最佳方法利用哈希映射进行 O(1) 令牌查找，并使用允许我们有效丢弃过期令牌的数据结构。 自从`currentTime`是严格递增的，我们可以按照令牌过期的顺序维护一个令牌队列（或有序字典）。 每次发生操作时，我们都可以从队列前面删除所有已经过期的令牌。 哈希映射确保我们可以在恒定时间内更新或检查令牌，而队列允许有效删除过期令牌。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 将标记存储在字典/列表中； 每个操作都会检查所有令牌 |
 | 最佳 | O(n) | O(n) | 使用哈希图+队列来高效跟踪过期情况； 每个令牌最多被处理两次 |

 ## 算法演练

 1. 初始化一个`AuthenticationManager`对象与`timeToLive`。 维护哈希图`tokens`映射`tokenId`到其过期时间，以及一个队列`expiryQueue`按过期顺序跟踪令牌。 
2. 生成token`currentTime`，计算其过期时间为`currentTime + timeToLive`。 将令牌添加到哈希映射并将其追加到队列中。 
3. 更新令牌：`currentTime`，首先通过检查队列的前面并删除过期时间≤的任何令牌来清除过期令牌`currentTime`。 然后，如果该令牌存在于哈希映射中并且未过期，则在哈希映射中更新其过期时间并将新的过期时间附加到队列中。 
4. 要统计未过期的令牌，请先清除过期的令牌。 哈希图的长度给出了当前有效令牌的数量。 

工作原理：通过按过期顺序维护队列并严格按升序处理时间戳，我们保证在当时的任何操作之前始终删除过期的令牌。 哈希映射允许恒定时间访问各个令牌，而队列确保有效丢弃过期令牌。 

## Python 解决方案```python
from collections import deque

class AuthenticationManager:

    def __init__(self, timeToLive: int):
        self.timeToLive = timeToLive
        self.tokens = {}  # tokenId -> expiry time
        self.expiryQueue = deque()  # stores tuples (expiryTime, tokenId)

    def _purge(self, currentTime: int) -> None:
        while self.expiryQueue and self.expiryQueue[0][0] <= currentTime:
            expiry, tokenId = self.expiryQueue.popleft()
            if self.tokens.get(tokenId, 0) == expiry:
                del self.tokens[tokenId]

    def generate(self, tokenId: str, currentTime: int) -> None:
        expiry = currentTime + self.timeToLive
        self.tokens[tokenId] = expiry
        self.expiryQueue.append((expiry, tokenId))

    def renew(self, tokenId: str, currentTime: int) -> None:
        self._purge(currentTime)
        if tokenId in self.tokens:
            expiry = currentTime + self.timeToLive
            self.tokens[tokenId] = expiry
            self.expiryQueue.append((expiry, tokenId))

    def countUnexpiredTokens(self, currentTime: int) -> int:
        self._purge(currentTime)
        return len(self.tokens)
```这`_purge`helper 确保在任何操作之前删除所有过期的令牌。 这`generate`方法添加令牌及其计算的到期时间，而`renew`首先清除过期的令牌并仅更新未过期的令牌。 计数只是返回字典中剩余键的数量。 

## 解决方案```go
package main

type tokenEntry struct {
	expiry  int
	tokenId string
}

type AuthenticationManager struct {
	timeToLive int
	tokens     map[string]int
	expiryQueue []tokenEntry
}

func Constructor(timeToLive int) AuthenticationManager {
	return AuthenticationManager{
		timeToLive: timeToLive,
		tokens:     make(map[string]int),
		expiryQueue: []tokenEntry{},
	}
}

func (this *AuthenticationManager) purge(currentTime int) {
	i := 0
	for i < len(this.expiryQueue) {
		entry := this.expiryQueue[i]
		if entry.expiry > currentTime {
			break
		}
		if this.tokens[entry.tokenId] == entry.expiry {
			delete(this.tokens, entry.tokenId)
		}
		i++
	}
	this.expiryQueue = this.expiryQueue[i:]
}

func (this *AuthenticationManager) Generate(tokenId string, currentTime int) {
	expiry := currentTime + this.timeToLive
	this.tokens[tokenId] = expiry
	this.expiryQueue = append(this.expiryQueue, tokenEntry{expiry, tokenId})
}

func (this *AuthenticationManager) Renew(tokenId string, currentTime int) {
	this.purge(currentTime)
	if _, exists := this.tokens[tokenId]; exists {
		expiry := currentTime + this.timeToLive
		this.tokens[tokenId] = expiry
		this.expiryQueue = append(this.expiryQueue, tokenEntry{expiry, tokenId})
	}
}

func (this *AuthenticationManager) CountUnexpiredTokens(currentTime int) int {
	this.purge(currentTime)
	return len(this.tokens)
}
```在 Go 中，主要区别在于使用切片来模拟令牌条目的队列和结构。 删除过期令牌是通过对队列进行切片来处理的，并且映射查找提供 O(1) 令牌访问。 

## 工作示例

 | 运营| 代币状态 | 队列状态| 输出|
 | --- | --- | --- | --- |
 | 生成（“aaa”，2）| {“aaa”：7} | [（7，“aaa”）] | - |
 | 计数未过期令牌(6) | {“aaa”：7} | [（7，“aaa”）] | 1 |
 | 生成（“bbb”，7）| {"aaa":7,"bbb":12} | [(7,"aaa"),(12,"bbb")] | - |
 | 更新（“aaa”，8）| {“bbb”：12} | [(12，“bbb”)] | - |
 | 更新（“bbb”，10）| {“bbb”：15} | [（12，“bbb”），（15，“bbb”）] | - |
 | 计数未过期令牌(15) | {} | []| 0 |

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个令牌最多在队列中添加和删除一次； 每个操作都是 O(1) 摊销 |
 | 空间| O(n) | 我们将所有令牌存储在映射和队列中，每个令牌最多存储两次 |

 因为`currentTime`严格递增，清除过期代币的每次操作摊销为 O(1)。

am = AuthenticationManager(5)
