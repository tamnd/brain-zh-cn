[LeetCode 问题 1721](https://leetcode.com/problems/swapping-nodes-in-a-linked-list/)

 **难度：** 🟡 中等
 **主题：** 链表、两个指针

 ## 解决方案

 ## 问题理解

 该问题提供了一个单链表和一个整数`k`。 任务是交换`kth`节点从开始`kth`从列表末尾开始的节点。 该列表是 **1-indexed**，这意味着第一个节点的位置为 1，而不是 0。输入`head`代表链表的开始，输出应该是执行交换后修改后的列表。 

换句话说，如果链表有`n`节点，我们需要交换位置节点的值`k`和`n-k+1`。 列表节点本身保持相同的顺序； 只是他们的价值观改变了。 

这些约束表明链表可以相当大，最多可达`105`节点，节点值是之间的小整数`0`和`100`。 这允许 O(n) 解决方案，但不鼓励任何需要 O(n²) 时间的解决方案。 我们保证`k`始终有效，因此无需检查超出范围的索引。 

重要的边缘情况包括单节点列表，`k`指向第一个或最后一个节点，以及情况`kth`从开始和结束的节点是相同的节点（即奇数长度列表中的中间节点），在这种情况下不需要交换。 

## 方法

 **暴力方式**是首先遍历整个链表，将所有节点存储在一个数组中。 一旦我们有了数组访问权限，`kth`从头开始的节点位于索引处`k-1`和`kth`末尾的节点位于索引处`n-k`。 然后我们可以交换它们的值并重建列表。 这是可行的，因为通过数组进行随机访问允许 O(1) 交换。 然而，这需要 O(n) 额外的空间来存储节点，这是不必要的。 

**最佳方法**利用**两指针技术**。 首先，迭代到`kth`从头开始并记住它。 然后使用第二个指针来定位`kth`通过迭代到末尾同时维护指针，从末尾开始节点`first`落后 k 步，或者简单地计算总节点并计算目标索引。 就地交换值而不使用额外的空间。 这将空间复杂度降低到 O(1)，同时保持时间复杂度 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 将列表转换为数组、交换值、重建列表 |
 | 最佳 | O(n) | O(1) | O(1) | 两指针进场，互换值到位|

 ## 算法演练

 1、从链表头开始遍历`k-1`达到的步骤`kth`从头开始的节点。 将此节点的引用存储为`first`。 
2. 初始化另一个指针`second`在头部和一个`current`指针指向头部。 
3. 遍历列表`current`。 到达终点后，`second`应该指向`kth`使用总节点数或两指针技术从末尾查找节点。 
4. 交换以下值`first`和`second`。 
5. 返回`head`的链接列表。 

**为什么有效：** 交换值而不是节点本身可以​​避免复杂的指针调整并确保 O(1) 空间。 两指针技术保证`second`最终准确地结束`k`从末尾开始的节点，当`current`到达列表尾部。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
from typing import Optional

class Solution:
    def swapNodes(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        first = head
        for _ in range(k - 1):
            first = first.next
        
        kth_from_start = first
        kth_from_end = head
        current = first
        
        while current.next:
            current = current.next
            kth_from_end = kth_from_end.next
        
        kth_from_start.val, kth_from_end.val = kth_from_end.val, kth_from_start.val
        return head
```在这个Python实现中，我们首先找到`kth`从头开始的节点。 然后，通过前进`current`移动到最后`kth_from_end`一路上，我们降落在`kth`从末尾开始的节点。 交换是在`val`属性以避免重组列表。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func swapNodes(head *ListNode, k int) *ListNode {
    first := head
    for i := 1; i < k; i++ {
        first = first.Next
    }
    
    kthFromStart := first
    kthFromEnd := head
    current := first
    
    for current.Next != nil {
        current = current.Next
        kthFromEnd = kthFromEnd.Next
    }
    
    kthFromStart.Val, kthFromEnd.Val = kthFromEnd.Val, kthFromStart.Val
    return head
}
```在 Go 中，方法是相同的。 主要区别在于循环语法和结构字段访问。 这`nil`check 取代了 Python 的隐式检查`None`处理。

 ## 边缘情况

 **单节点列表：** 由于列表只有一个节点，`kth`从开始到结束都是相同的。 交换值不会改变任何内容，算法可以正确处理这一点。 

**k 指向第一个或最后一个节点：** 当`k`是 1 或等于`n`，交换影响头部或尾部。 该实现通过使用简单的指针遍历来定位节点来正确处理这些问题。 

**具有中间节点的奇数长度列表：**当`kth`从开始和结束的节点是相同的，交换值没有效果。 该算法自然会处理这个问题，因为指针将引用同一节点，并且与自身交换值是安全的。 

这种方法有效地覆盖了所有边缘情况，同时保持最佳的时间和空间复杂性。
