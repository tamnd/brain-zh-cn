 **难度：** 🟡 中等
 **主题：** 数组、矩阵、模拟

 ## 解决方案

 ## 问题理解

 这个问题要求我们模拟球落入由网格表示的二维盒子中的运动。 网格中的每个单元格都有一个对角板，可将球引导到右侧（`1`）或向左（`-1`）。 我们将一个球放入盒子顶部的每一列中，并需要确定每个球将在底部退出的位置，或者它是否卡在盒子内。 

输入`grid`是一个二维整数数组`m`行和`n`列，其中`grid[i][j]`表示行中板的方向`i`和列`j`。 输出应该是一个大小的数组`n`，其中`i`th 元素告诉球从哪一列落下`i`第 列退出框的底部，或者`-1`如果球被卡住。 

重要的观察结果包括，如果球移动到墙上，就会被卡住（`j < 0`或者`j >= n`）或者如果它在两个相邻的板之间遇到“V”形状并指向彼此（即，`1`其次是`-1`或者`-1`其次是`1`）。 限制条件`1 <= m, n <= 100`表明直接模拟是可行的，因为操作总数最多为 10,000，这对于现代系统来说是可以接受的。 

关键的边缘情况包括单列网格、立即撞到墙壁的球以及将球困在两个相邻单元格之间的图案。 

## 方法

 暴力方法是逐行模拟每个球的路径。 对于每一行，检查当前方向并确定球是向左还是向右移动。 如果球试图移出网格或遇到“V”形状，请将其标记为卡住。 这种方法是正确的，但涉及对每个球的每一行进行迭代。 

最佳解决方案本质上与蛮力方法相同，因为我们需要模拟路径来了解球是否被卡住。 关键是认识到每个球的路径是独立的，因此我们可以独立地迭代每一列。 除了存储结果之外，不需要额外的数据结构或记忆。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(n) | 逐行模拟每个球； 检查边界和“V”形。 |
 | 最佳 | O(m * n) | O(n) | 与暴力破解相同； 每个球的独立模拟，将结果存储在数组中。 |

 ## 算法演练

 1.初始化一个数组`result`尺寸的`n`所有值设置为`-1`作为卡住的球的默认设置。 
2. 迭代每一列`c`从`0`到`n-1`。 这代表从柱子上掉下一个球`c`。 
3. 对于每个球，从顶行开始（`row = 0`) 和当前列`col = c`。 
4. 对于每一行：

 1. 将下一列计算为`col + grid[row][col]`。 
2. 检查下一列是否越界（`next_col < 0`或者`next_col >= n`）。 如果是，则球被卡住； 打破这个球的模拟。 
3. 检查下一个单元格是否有与当前方向相反的棋盘（`grid[row][col] != grid[row][next_col]`）。 如果为 true，则球被卡住；如果为 true，则球被卡住； 打破模拟。 
4. 将球移至`next_col`为下一行。 
5. 如果球到达最后一行而没有被卡住，则将其最后一列记录在`result[c]`。 
6. 返回`result`大批。 

**为什么起作用：** 每个球都独立移动，唯一阻止它的因素是明确的：墙壁和“V”形。 模拟路径准确地保留了这些条件，确保了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def findBall(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        result = [-1] * n
        
        for c in range(n):
            col = c
            for row in range(m):
                next_col = col + grid[row][col]
                if next_col < 0 or next_col >= n or grid[row][col] != grid[row][next_col]:
                    col = -1
                    break
                col = next_col
            result[c] = col
            
        return result
```此实现将结果初始化为`-1`对于每一列。 对于每个球，它逐行模拟运动，根据板的方向更新列并检查边界或“V”形状。 如果球成功到达最后一行，则记录其最后一列； 否则，`-1`遗迹。 

## 解决方案```go
func findBall(grid [][]int) []int {
    m, n := len(grid), len(grid[0])
    result := make([]int, n)
    
    for c := 0; c < n; c++ {
        col := c
        for row := 0; row < m; row++ {
            nextCol := col + grid[row][col]
            if nextCol < 0 || nextCol >= n || grid[row][col] != grid[row][nextCol] {
                col = -1
                break
            }
            col = nextCol
        }
        result[c] = col
    }
    
    return result
}
```Go 版本反映了 Python 逻辑。 主要区别在于切片初始化和使用`:=`用于变量声明。 由于静态类型，Go 不需要类型提示。
