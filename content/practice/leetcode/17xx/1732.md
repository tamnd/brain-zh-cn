[LeetCode 1732 题](https://leetcode.com/problems/find-the-highest-altitude/)

 **难度：** 🟢简单
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 在这个问题中，骑自行车的人从海拔高度开始`0`并穿过一系列道路。 输入数组`gain`描述骑车人在行程中连续点之间的海拔高度如何变化。 

如果`gain[i]`为正，骑车人在点之间向上爬`i`并点`i + 1`。 如果为负，骑车人就会下降。 每个点的实际高度是通过累积应用这些高度变化来确定的。 

任务是计算旅途中任何一点达到的最高高度。 

例如，如果：```
gain = [-5, 1, 5, 0, -7]
```那么海拔高度就变成：```
Start: 0
After -5: -5
After +1: -4
After +5: 1
After +0: 1
After -7: -6
```达到的最高海拔是`1`。 

输入数组有长度`n`，意味着有`n + 1`海拔点。 由于骑自行车的人从高海拔开始`0`，我们可以将问题视为构建运行总计并跟踪遇到的最大值。 

限制很小：

 -`1 <= n <= 100`-`-100 <= gain[i] <= 100`这些限制告诉我们，性能并不是主要问题。 即使效率较低的解决方案也会被通过。 然而，这个问题本质上是一个前缀和问题，并且有一个非常干净的线性时间解决方案。 

一些边缘情况很重要：

 - 所有海拔高度增益都可能为负，这意味着骑车人永远不会升至起始海拔以上。 
- 最高海拔​​可能出现在起点本身。 
- 多个连续增益可能会产生相同的最大高度。 
- 数组仅包含一个元素，这是可能的最小输入大小。 

因为骑自行车的人总是从海拔高度出发`0`，答案永远不能小于`0`。 

## 方法

 ### 蛮力方法

 强力解决方案将明确构建全高度阵列。 

我们从海拔高度开始`0`，然后重复应用每个增益值来计算下一个高度。 构建完整的海拔列表后，我们扫描列表以查找最大值。 

例如：```
gain = [-5,1,5,0,-7]

altitudes:
[0, -5, -4, 1, 1, -6]
```然后我们从该数组返回最大高度。 

这种方法是正确的，因为每个高度都是根据问题定义精确计算的。 然而，它使用额外的空间来存储所有中间高度，即使我们只需要当前高度和迄今为止看到的最大高度。 

### 最佳方法

 关键的观察是我们不需要存储每个高度。 

在任何时候，我们只需要：

 - 当前海拔高度
 - 迄今为止遇到的最高海拔

 当我们迭代时`gain`，我们使用前缀和不断更新跑步高度。 每次更新后，我们都会将当前高度与最大高度进行比较。 

这是有效的，因为每个高度仅取决于先前的高度和当前的增益值。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 在找到最大值之前构建完整的高度数组 |
 | 最佳 | O(n) | O(1) | O(1) | 使用运行前缀和并直接跟踪最大值 |

 ## 算法演练

 1.初始化两个变量：

 -`current_altitude = 0`-`highest_altitude = 0`骑自行车的人从高海拔开始`0`，所以两个变量都从那里开始。 
2. 迭代中的每个值`gain`大批。 
3. 对于每个增益值：

 - 添加到`current_altitude`- 这会计算骑车人到达下一个点后的新高度。 
4. 比较`current_altitude`和`highest_altitude`。 
5. 如果当前海拔较高，则更新`highest_altitude`。 
6. 继续，直到处理完所有增益值。 
7. 返回`highest_altitude`。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 -`current_altitude`始终代表处理当前段后骑车人的高度。 
-`highest_altitude`始终存储迄今为止看到的最大高度。 

由于每个高度都是通过运行前缀和生成一次，并且每个高度都与最大值进行比较，因此最终结果必须是行程中到达的最高高度。 

## Python 解决方案```python
from typing import List

class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        current_altitude = 0
        highest_altitude = 0

        for altitude_gain in gain:
            current_altitude += altitude_gain
            highest_altitude = max(highest_altitude, current_altitude)

        return highest_altitude
```该实现直接遵循最优前缀和方法。 

变量`current_altitude`在每个路段之后存储骑车人的高度。 中的每个元素`gain`添加到此运行总计中。 

变量`highest_altitude`跟踪迄今为止遇到的最大高度。 更新当前高度后，我们将其与当前最大高度进行比较`max()`。 

该算法一次性处理数组，并且不会分配与输入大小成比例的任何额外数据结构。 

## 解决方案```go
func largestAltitude(gain []int) int {
    currentAltitude := 0
    highestAltitude := 0

    for _, altitudeGain := range gain {
        currentAltitude += altitudeGain

        if currentAltitude > highestAltitude {
            highestAltitude = currentAltitude
        }
    }

    return highestAltitude
}
```Go 的实现与 Python 解决方案非常相似。 

Go 没有提供内置的`max()`标准语言语法中的整数函数，因此我们使用一个简单的`if`更新声明`highestAltitude`。 

对于空输入不需要特殊处理，因为该问题保证`gain.length >= 1`。 

整数溢出也不是问题，因为约束非常小。

 ## 边缘情况

 当所有增益均为负时，就会出现一种重要的边缘情况。 在这种情况下，骑自行车的人会不断降低高度，并且永远不会升到起点以上。 有缺陷的实现可能会错误地将最大高度初始化为非常小的数字，或者无法考虑起始高度本身。 此实现正确初始化`highest_altitude`到`0`，确保始终考虑起点。 

另一种重要的情况是输入仅包含一个元素时。 由于最小数组大小是`1`，算法对于单个路段仍然必须正确工作。 该实现自然地处理了这个问题，因为循环只处理一个值并更新运行高度一次。 

当多个高度都达到最高值时，就会出现第三种边缘情况。 例如：```
gain = [2, -2, 2, -2]
```骑自行车的人到达海拔高度`2`多次。 一旦达到最大值，实现就会正确地保持最大值不变。 

最后的边缘情况涉及所有零值。 在这种情况下，骑自行车的人永远不会改变高度。 运行高度保持不变`0`在整个计算过程中，算法正确返回`0`。
