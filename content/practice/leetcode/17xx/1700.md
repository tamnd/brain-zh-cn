[LeetCode 第 1700 题](https://leetcode.com/problems/number-of-students-unable-to-eat-lunch/)

 **难度：** 🟢简单
 **主题：** 数组、堆栈、队列、模拟

 ## 解决方案

 ## 问题理解

 此问题模拟学校食堂，学生排队从一堆三明治中取三明治。 每个学生都偏爱圆形三明治（`0`）或方形三明治（`1`）。 三明治排列成一堆，其中第一个元素`sandwiches`array 代表**栈顶**。 学生们排成队列，队列中的第一个学生检查他们是否喜欢最上面的三明治。 如果他们这样做了，他们就会接受并离开队列。 如果没有，他们就会移到队列的后面。 这样一直持续到队列中的任何学生都无法吃到最上面的三明治为止。 

输入由两个数组组成：`students`和`sandwiches`。 两个数组具有相同的长度和值`0`或者`1`。 输出是进程终止时无法吃任何三明治的学生人数。 

约束告诉我们输入规模很小（最多 100 名学生），因此中等复杂度的算法将高效运行。 要考虑的边缘情况包括所有学生都喜欢相同的三明治，所有三明治都相同，或者一些学生无法满意的混合物。 

主要观察结果是，一旦三明治类型没有学生喜欢它，该过程就会立即停止。 这种见解使我们能够避免模拟每个队列轮换。 

## 方法

 ### 蛮力

 暴力法直接模拟问题中描述的过程。 您为学生维护一个队列，并为三明治维护一堆。 在每次迭代中，检查前面的学生是否与顶部的三明治相对应。 如果学生不喜欢，请将他们移到队列后面并继续。 保留连续拒绝顶级三明治的学生的柜台。 如果该计数器等于队列的长度，则没有学生想要最上面的三明治，并且该过程停止。 

这种方法是正确的，因为它直接遵循问题陈述，但它涉及在队列中重复移动学生，从而给出 **O(n^2)** 最坏情况的复杂性。 对于较小的输入大小（≤100），这是可以接受的，但它不是最佳的。 

### 最佳方法

 最佳方法依赖于计数而不是模拟。 计算有多少学生喜欢圆形（`0`）和正方形（`1`）三明治。 然后从上到下迭代三明治堆栈。 如果三明治的类型至少有一名学生喜欢它，则减少该计数。 如果没有学生喜欢当前的三明治，则停止该过程，因为剩下的学生不能吃。 

这种方法之所以有效，是因为一旦我们知道了偏好的数量，队列中学生的确切顺序就不再重要了。 它消除了重复队列轮换的需要。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 完全按照描述模拟队列和堆栈 |
 | 最佳 | O(n) | O(1) | O(1) | 计算学生的偏好并迭代三明治，无需排队模拟 |

 ## 算法演练

 1.初始化两个计数器`count0`和`count1`计算喜欢圆形的学生（`0`）和正方形（`1`）三明治。 
2. 迭代`students`数组和增量`count0`或者`count1`根据学生的喜好。 
3. 迭代`sandwiches`从上到下堆叠。 
4. 对于每个三明治，检查是否有学生喜欢它（检查`count0`为了`0`和`count1`为了`1`）。 
5. 如果学生喜欢三明治，则减少相应的计数器。 这代表学生拿三明治。 
6. 如果没有学生喜欢当前的三明治，则停止迭代。 剩下的三明治拿不到，剩下的学生也吃不下。 
7. 通过对剩余计数求和，返回剩余学生总数。 

**为什么有效：** 该算法之所以有效，是因为它依赖于不变量，即只有学生的数量才重要，而不是他们的顺序。 只要至少有一个学生喜欢三明治类型，这个过程就可以继续。 第一个不能吃的三明治会停止该过程，这与问题陈述完全一致。 

## Python 解决方案```python
from typing import List

class Solution:
    def countStudents(self, students: List[int], sandwiches: List[int]) -> int:
        count0 = students.count(0)
        count1 = students.count(1)
        
        for s in sandwiches:
            if s == 0:
                if count0 > 0:
                    count0 -= 1
                else:
                    break
            else:
                if count1 > 0:
                    count1 -= 1
                else:
                    break
        
        return count0 + count1
```**实现说明：** 首先，我们统计喜欢每种三明治的学生人数。 然后，我们从上到下迭代三明治。 如果某个学生可以拿走三明治，我们就会减少计数。 如果没有学生能拿走当前的三明治，我们就停止。 剩余的计数总和给出了无法吃饭的学生人数。 

## 解决方案```go
func countStudents(students []int, sandwiches []int) int {
    count0, count1 := 0, 0
    for _, s := range students {
        if s == 0 {
            count0++
        } else {
            count1++
        }
    }

    for _, s := range sandwiches {
        if s == 0 {
            if count0 > 0 {
                count0--
            } else {
                break
            }
        } else {
            if count1 > 0 {
                count1--
            } else {
                break
            }
        }
    }
    return count0 + count1
}
```**Go 特定注释：** Go 没有内置的`count`切片方法，因此我们手动迭代。 该方法在其他方面与 Python 相同，使用整数计数器。 不存在零问题，因为切片保证具有相等的非零长度。 

## 工作示例

 **示例1：**`students = [1,1,0,0], sandwiches = [0,1,0,1]`| 步骤| 三明治| 计数0 | 计数1 | 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 0 | 2 | 2 | count0 > 0，拿三明治，count0 = 1 |
 | 2 | 1 | 1 | 2 | count1 > 0，拿三明治，count1 = 1 |
 | 3 | 0 | 1 | 1 | count0 > 0，拿三明治，count0 = 0 |
 | 4 | 1 | 0 | 1 | count1 > 0，拿三明治，count1 = 0 |

 所有学生都吃完，返回0。 

**示例2：**`students = [1,1,1,0,0,1], sandwiches = [1,0,0,0,1,1]`| 步骤| 三明治| 计数0 | 计数1 | 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 1 | 2 | 4 | 拿三明治，count1 = 3 |
 | 2 | 0 | 2 | 3 | 拿三明治，count0 = 1 |
 | 3 | 0 | 1 | 3 | 拿三明治，count0 = 0 |
 | 4 | 0 | 0 | 3 | 不能接受，停止|

 剩余学生 = count0 + count1 = 0 + 3 = 3。
