[LeetCode 问题 1736](https://leetcode.com/problems/latest-time-by-replacing-hidden-digits/)

 **难度：** 🟢简单
 **主题：** 字符串、贪婪

 ## 解决方案

 ## 问题理解

 问题呈现一个字符串`time`格式为`hh:mm`， 在哪里`h`和`m`是分别代表小时和分钟的数字。 某些数字可能被隐藏并用问号表示`?`。 目标是取代`?`带有数字的字符，使得结果时间是**可能的最晚有效时间**，考虑到 24 小时格式约束（`00:00`到`23:59`）。 

输入保证可以通过填写来构造有效时间`?`人物。 边缘情况涉及小时或分钟的一位或两位数字未知的时间。 例如，`?4:5?`和`2?:?0`需要小心处理，因为在不考虑约束的情况下替换数字可能会导致无效的小时或分钟。 输出应保留原始格式`hh:mm`。 

约束告诉我们输入长度始终为 5，并且`:`并且数字是固定的。 我们不需要处理格式错误的字符串或完全无效的输入。 

## 方法

 **暴力方法**是通过替换来生成所有可能的有效时间`?`带数字`0`通过`9`，过滤掉无效次数，然后选择最大值。 虽然正确，但这种方法不必要地复杂，因为它需要检查`10^4`每个的组合`?`在字符串中，考虑到简单的约束，这有点过分了。 

**关键见解**是，可以通过确定中每个位置的最大有效数字来**贪婪地**计算最新有效时间`hh:mm`同时尊重 24 小时格式的限制。 例如，如果第一个小时数字是`2`，第二个必须是`0-3`保持有效。 如果第一个数字是`0`或者`1`，第二个可以是`0-9`。 分钟更简单，因为第一位数字可以是`0-5`和第二个数字`0-9`。

 | 最佳 | O(1) | O(1) | O(1) | O(1) | 贪婪地替换`?`具有基于约束的最大有效数字|

 ## 算法演练

 1.从原来开始`time`细绳。 
2. 检查小时的第一位数字（索引`0`）。 如果是的话`?`，将其替换为`2`如果第二个小时数字未知或小于`4`; 否则，替换为`1`。 
3. 检查小时的第二位数字（索引`1`）。 如果是的话`?`，将其替换为`3`如果第一个小时数字是`2`; 否则，替换为`9`。 
4. 检查分钟的第一位数字（索引`3`）。 如果是的话`?`，将其替换为`5`因为最大有效值为`59`。 
5. 检查分钟的第二位数字（索引`4`）。 如果是的话`?`，将其替换为`9`。 
6. 返回所有替换后的结果字符串。 

**为什么有效**：每个位置的贪婪选择保证了该位置的最大有效数字，而不违反 24 小时或分钟的限制。 考虑到之前的约束，每个数字都是独立的，因此保证解决方案是最晚的可能时间。 

## Python 解决方案```python
class Solution:
    def maximumTime(self, time: str) -> str:
        time_list = list(time)
        
        # Hour first digit
        if time_list[0] == '?':
            time_list[0] = '2' if time_list[1] == '?' or time_list[1] < '4' else '1'
        
        # Hour second digit
        if time_list[1] == '?':
            time_list[1] = '3' if time_list[0] == '2' else '9'
        
        # Minute first digit
        if time_list[3] == '?':
            time_list[3] = '5'
        
        # Minute second digit
        if time_list[4] == '?':
            time_list[4] = '9'
        
        return ''.join(time_list)
```Python 解决方案将字符串转换为列表以进行可变操作。 然后它替换每个`?`基于保持结果时间有效的最大允许值。 最后，它将列表重新连接成字符串。 

## 解决方案```go
func maximumTime(time string) string {
    t := []byte(time)
    
    if t[0] == '?' {
        if t[1] == '?' || t[1] < '4' {
            t[0] = '2'
        } else {
            t[0] = '1'
        }
    }
    
    if t[1] == '?' {
        if t[0] == '2' {
            t[1] = '3'
        } else {
            t[1] = '9'
        }
    }
    
    if t[3] == '?' {
        t[3] = '5'
    }
    
    if t[4] == '?' {
        t[4] = '9'
    }
    
    return string(t)
}
```Go 实现遵循与 Python 相同的逻辑。 字节片用于允许就地替换。 Go 中的索引和字符比较非常简单，最终的切片将转换回字符串。
