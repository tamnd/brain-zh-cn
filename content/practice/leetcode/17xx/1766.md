 ## 解决方案

 ## 问题理解

 这个问题给了我们一棵树`n`节点编号从`0`到`n-1`，以节点为根`0`。 每个节点都有一个来自数组的关联值`nums`，树结构以边列表的形式给出。 对于每个节点`i`，我们被要求找到最接近的祖先，其值为 **coprime** 与`nums[i]`。 如果两个数的最大公约数 (gcd) 为，则它们互质`1`。 如果不存在这样的祖先，答案应该是`-1`。 

输入`nums`定义每个节点的值，而`edges`定义树连接。 预期输出是一个数组`ans`尺寸的`n`在哪里`ans[i]`是距离节点最近的互质祖先`i`。 

约束条件告诉我们`nums[i]`值很小（`1 <= nums[i] <= 50`）但是树可以很大（`n <= 10^5`）。 这表明我们必须避免对每个节点进行强力祖先搜索，因为这可能导致 O(n^2) 时间复杂度，这对于大型树来说是不可行的。 重要的边缘情况包括没有互质祖先的节点（结果`-1`）以及多个祖先互质的节点（我们必须选择最接近的）。 

## 方法

 **暴力方法**很简单：对于每个节点`i`，遍历其祖先直到根，计算`gcd(nums[i], nums[ancestor])`对于每个，并跟踪最接近的互质祖先。 这是正确的，但效率低下。 在最坏的情况下，每个节点需要遍历 O(n) 个祖先，总时间复杂度为 O(n^2)，这对于`n = 10^5`。 

**最佳方法**依赖于以下关键见解：`nums[i]`值很小（≤ 50）。 我们可以预先计算从 1 到 50 的所有互质对。然后，使用深度优先搜索 (DFS)，我们沿着从根到当前节点的路径维护从值到最新节点索引的映射。 在每个节点，我们检查路径上的哪些祖先节点与`nums[i]`并选择距离当前节点最近的一个。 通过访问子项后回溯，我们确保映射始终反映当前的 DFS 路径。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 检查每个节点的所有祖先； 对于大 n 来说太慢 |
 | 最佳 | O(n * V^2) | O(n * V^2) | O(n + V^2) | O(n + V^2) | 预先计算互质对； 带路径映射的DFS； V = 50 |

 ## 算法演练

 1. 预先计算数字 1 到 50 的所有互质对。为每个数字存储与其互质的值列表。 这允许 DFS 的恒定时间查找。 
2. 根据给定的边构建树的邻接表表示。 
3. 初始化映射`last_occurrence`从节点值到 DFS 路径上的最新节点索引。 
4. 初始化结果数组`ans`和`-1`。 
5.定义带参数的递归DFS函数`node`和`parent`。 对于每个节点：

 a. 初始化变量以跟踪最近的互质祖先：`closest_node = -1`和`closest_depth = -1`。 

b. 对于每个值`v`与`nums[node]`，检查是否`v`存在于`last_occurrence`。 如果有，请更新`closest_node`如果它的深度比当前的更近`closest_depth`。 

c. 更新`ans[node] = closest_node`。 

d. 暂时记录当前节点`last_occurrence[nums[node]]`。 

e. 对非父级的所有子级重复 DFS。 

f. 通过删除当前节点来回溯`last_occurrence[nums[node]]`。 
6.从根节点启动DFS`0`和`parent = -1`。 
7. 返回`ans`大批。 

**为什么有效**：DFS 确保`last_occurrence`始终反映从根到当前节点的路径，因此在检查互素祖先时，我们只考虑实际祖先。 预先计算的互质映射和回溯保持了正确性和效率。 

## Python 解决方案```python
from math import gcd
from typing import List, Dict

class Solution:
    def getCoprimes(self, nums: List[int], edges: List[List[int]]) -> List[int]:
        n = len(nums)
        
        # Precompute coprime relationships
        coprime_map: Dict[int, List[int]] = {i: [] for i in range(1, 51)}
        for i in range(1, 51):
            for j in range(1, 51):
                if gcd(i, j) == 1:
                    coprime_map[i].append(j)
        
        # Build tree adjacency list
        tree = [[] for _ in range(n)]
        for u, v in edges:
            tree[u].append(v)
            tree[v].append(u)
        
        ans = [-1] * n
        last_occurrence: Dict[int, List[int]] = {i: [] for i in range(1, 51)}
        
        def dfs(node: int, parent: int):
            closest_node = -1
            closest_depth = -1
            
            # Find closest coprime ancestor
            for val in coprime_map[nums[node]]:
                if last_occurrence[val]:
                    candidate = last_occurrence[val][-1]
                    if candidate > closest_depth:
                        closest_depth = candidate
                        closest_node = candidate
            
            ans[node] = closest_node
            
            # Record current node in last_occurrence
            last_occurrence[nums[node]].append(node)
            
            for child in tree[node]:
                if child != parent:
                    dfs(child, node)
            
            # Backtrack
            last_occurrence[nums[node]].pop()
        
        dfs(0, -1)
        return ans
```Python 解决方案预先计算值 1 到 50 的互质对。DFS 维护路径上每个值最后一次出现的映射。 对于每个节点，它找到具有互质值的最近祖先并正确回溯以保持路径准确。 

## 解决方案```go
package main

import "math"

func gcd(a, b int) int {
	for b != 0 {
		a, b = b, a%b
	}
	return a
}

func getCoprimes(nums []int, edges [][]int) []int {
	n := len(nums)
	ans := make([]int, n)
	for i := range ans {
		ans[i] = -1
	}

	// Precompute coprime map
	coprimeMap := make([][]int, 51)
	for i := 1; i <= 50; i++ {
		for j := 1; j <= 50; j++ {
			if gcd(i, j) == 1 {
				coprimeMap[i] = append(coprimeMap[i], j)
			}
		}
	}

	// Build tree
	tree := make([][]int, n)
	for _, e := range edges {
		u, v := e[0], e[1]
		tree[u] = append(tree[u], v)
		tree[v] = append(tree[v], u)
	}

	lastOccurrence := make([][]int, 51)

	var dfs func(node, parent int)
	dfs = func(node, parent int) {
		closestNode := -1
		for _, val := range coprimeMap[nums[node]] {
			if len(lastOccurrence[val]) > 0 {
				candidate := lastOccurrence[val][len(lastOccurrence[val])-1]
				if candidate > closestNode {
					closestNode = candidate
				}
			}
		}
		ans[node] = closestNode

		lastOccurrence[nums[node]] = append(lastOccurrence[nums[node]], node)
		for _, child := range tree[node] {
			if child != parent {
				dfs(child, node)
			}
		}
		lastOccurrence[nums[node]] = lastOccurrence[nums[node]][:len(lastOccurrence[nums[node]])-1]
	}

	dfs(0, -1)
	return ans
}
```Go 解决方案反映了 Python 逻辑。 主要区别在于切片管理`lastOccurrence`和显式循环索引而不是字典查找。
