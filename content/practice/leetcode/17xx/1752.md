[LeetCode 问题 1752](https://leetcode.com/problems/check-if-array-is-sorted-and-rotated/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 问题是要求我们判断给定的数组是否`nums`可能是按非降序排列的排序数组然后将其旋转一定数量的位置的结果。 非递减数组是指每个元素都大于或等于前一个元素的数组。 旋转数组意味着获取元素的一些前缀并将它们移动到末尾，同时保持元素顺序不变。 

输入`nums`是一个整数数组，可能包含重复项，长度在 1 到 100 之间，值在 1 到 100 之间。预期输出是布尔值：`true`如果`nums`可以是旋转排序数组，并且`false`否则。 

重要的边缘情况包括长度为 1 的数组（通常被认为是排序和旋转的）、已经排序但没有任何旋转的数组、所有元素都相等的数组以及具有多个位置递减的数组（这将导致旋转不可能）。 

该问题保证了数组包含小范围内的整数，使我们能够考虑线性时间解决方案而无需考虑性能问题。 

## 方法

 一种暴力方法是尝试数组的每一种可能的旋转并检查它是否已排序。 对于每次旋转，我们将生成旋转数组并迭代它以查看它是否处于非递减顺序。 虽然这适用于小型数组，但它的时间复杂度为 O(n²)，即使对于问题约束也是不必要的。 

关键的见解是，排序和旋转的数组将**最多有一个数组“环绕”**的位置，即一个元素大于下一个元素的位置。 如果我们计算数组中此类减少的数量，它应该是 0（数组已完全排序且未旋转）或 1（数组已排序并旋转一次）。 如果减少不止一次，则该数组不可能是旋转排序数组。 

这种洞察力允许单遍获得最佳解决方案：迭代数组一次，计数减少，包括最后一个元素和第一个元素之间的环绕。

 ## 算法演练

 1.初始化一个计数器`count`到 0。这将跟踪一个元素大于后面元素的次数。 
2. 从第一个元素到最后一个元素迭代数组。 对于每个索引`i`， 比较`nums[i]`到`nums[(i + 1) % n]`。 使用模可确保比较环绕到第一个元素。 
3.如果`nums[i] > nums[(i + 1) % n]`, 增量`count`。 这标识了违反排序顺序的点，代表潜在的“旋转点”。 
4. 迭代完成后，检查是否`count`小于或等于1。如果是，则返回`true`因为数组可以排序和旋转。 否则，返回`false`。 

**为什么有效：** 非递减数组的元素按顺序排列且不递减。 旋转版本在旋转点最多引入一次减少。 任何额外的减少都表明该数组不可能是旋转的排序数组。 

## Python 解决方案```python
from typing import List

class Solution:
    def check(self, nums: List[int]) -> bool:
        n = len(nums)
        count = 0
        for i in range(n):
            if nums[i] > nums[(i + 1) % n]:
                count += 1
            if count > 1:
                return False
        return True
```该实现初始化一个计数器，迭代所有元素（包括环绕），然后立即返回`False`如果发现不止一项减少。 如果循环完成但没有超过 1 个减少，则返回`True`。 

## 解决方案```go
func check(nums []int) bool {
    n := len(nums)
    count := 0
    for i := 0; i < n; i++ {
        if nums[i] > nums[(i+1)%n] {
            count++
        }
        if count > 1 {
            return false
        }
    }
    return true
}
```在 Go 中，我们以类似的方式处理数组。 Go 中的切片是零索引的，并使用模算术进行环绕。 尽管限制很小，但早期返回可确保较大数组的效率。

 ## 边缘情况

 单元素数组通常被认为是排序和旋转的，因为旋转不会改变顺序。 该实现通过迭代一次并发现零减少来正确处理这个问题。 

所有元素都相等的数组也是边缘情况，因为每次比较`nums[i] > nums[i+1]`是假的。 我们的实施计数为零减少，返回`True`。 

具有多个递减点或反转的数组，尤其是存在重复项时，可能会导致简单的实现失败。 通过计数减少并使用环绕比较，该解决方案可以正确识别该数组是否可以是旋转排序数组。
