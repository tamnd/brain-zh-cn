[LeetCode 第 1746 题](https://leetcode.com/problems/maximum-subarray-sum-after-one-operation/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 问题给了我们一个整数数组`nums`，并且我们必须对数组执行一次操作。 该操作允许我们选择单个索引`i`并替换该值`nums[i]`以其正方形，`nums[i] * nums[i]`。 

执行完这一所需操作后，我们必须计算任何非空连续子数组的最大可能总和。 

子数组是数组的连续段。 应用运算后，我们可以自由选择任何子数组，但必须使用通过对一个元素进行平方而得到的修改后的数组。 

重要的细节是该操作是强制性的。 我们不能跳过它，即使对数字进行平方看起来有害。 幸运的是，对任何整数进行平方都会产生一个非负值，因此该运算通常会改善结果，尤其是在应用于大负数时。 

约束条件很重要：

 - 数组长度可以大到`10^5`- 每个值的范围可以是`-10^4`到`10^4`这些约束立即排除了昂贵的二次或三次解。 在所有可能的操作之后检查所有可能的子数组的任何方法都太慢了。 自从`n`可以是`100000`，我们应该以线性时间动态规划解决方案为目标。 

一些边缘情况尤其重要：

 - 具有单个元素的数组
 - 包含所有负数的数组
 - 包含零的数组
 - 正数的平方比负数的平方更好的情况
 - 最优子数组仅包含平方元素的情况
 - 最优子数组同时涵盖正值和负值的情况

 幼稚的实现很容易因以下原因而犯错误：

 - 忘记该操作是强制性的
 - 不知道该操作是否已被使用
 - 不正确地处理子数组之间的转换

 这自然暗示了具有状态跟踪的动态规划公式。 

## 方法

 ### 蛮力方法

 最直接的解决方案是尝试所有可能的索引作为平方元素。 

对于每个索引`i`：

 1. 创建数组的修改版本，其中`nums[i]`变成`nums[i]^2`2.运行Kadane算法来计算修改后的数组的最大子数组和
 3. 在所有选择中保留最佳答案

 这种方法是正确的，因为它显式地评估每个可能的有效操作，然后计算最佳子数组。 

然而，复杂性太高。 有`n`操作索引的选择，每个 Kadane pass 需要`O(n)`时间。 这会产生一个`O(n^2)`解决方案。 

和`n = 10^5`，这需要大约`10^10`在最坏的情况下，操作速度太慢了。 

### 最优动态规划方法

 关键的见解是我们不需要为每个可能的操作位置显式重建数组。 

相反，当从左到右扫描数组时，我们可以保持两种动态编程状态：

 1. 尚未使用该操作时，以当前位置结束的最大子数组和
 2. 已经使用该操作后，当前位置结束的最大子数组和

 这是有效的，因为每个子数组都以索引结尾`i`必须来自：

 - 扩展先前的子数组
 - 从当前位置重新开始

 该操作只能使用一次，因此在更新第二个状态时，我们可以：

 - 扩展已经使用该操作的先前子数组
 - 第一次使用当前元素的操作

 这将问题转换为单个线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 尝试将每个索引作为平方元素，然后运行 ​​Kadane 算法 |
 | 最佳 | O(n) | O(1) | O(1) | 具有两种运行状态的动态规划|

 ## 算法演练

 1. 定义两个DP状态。 

让：

-`no_operation`表示在不使用平方运算的情况下以当前索引结束的最大子数组和
 -`with_operation`表示已经使用该操作后以当前索引结尾的最大子数组和

 这些状态使我们能够跟踪操作是否已被消耗。 
2. 使用第一个元素初始化状态。 

对于第一个元素：

 -`no_operation = nums[0]`-`with_operation = nums[0] * nums[0]`由于该操作是强制性的，因此第二状态从平方值开始。 
3. 迭代剩余元素。 

对于每个值`num`：

 首先计算`squared = num * num`。 
4. 更新`with_operation`状态。 

有以下三种可能：

 - 扩展已经使用该操作的先前子数组：`with_operation + num`- 在扩展先前未触及的子数组时，对当前元素使用操作：`no_operation + squared`- 仅使用当前元素的平方开始一个全新的子数组：`squared`我们采取这些选择中的最大值。 
5. 更新`no_operation`状态。 

这遵循标准 Kadane 算法：

 - 扩展前一个子数组：`no_operation + num`- 在当前元素处开始一个新的子数组：`num`取最大值。 
6. 跟踪全局答案。 

在每个索引处，使用最佳索引更新结果`with_operation`迄今为止看到的价值。 

我们只使用`with_operation`因为这个问题只需要一次操作。 
7. 返回最终答案。 

### 为什么它有效

 该算法保持精确的不变量：

 -`no_operation`始终存储以当前索引结尾的最大子数组总和，而不对任何元素进行平方
 -`with_operation`始终存储在对一个元素进行平方后以当前索引结尾的最大子数组和

 以当前位置结尾的每个有效子数组都必须属于这些类别之一，并且转移方程考虑构建此类子数组的所有可能方法。 由于每个索引都被处理一次并且每次转换都是最优的，因此最终结果保证是在一次操作后可实现的最大子数组和。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxSumAfterOperation(self, nums: List[int]) -> int:
        no_operation = nums[0]
        with_operation = nums[0] * nums[0]

        answer = with_operation

        for num in nums[1:]:
            squared = num * num

            new_with_operation = max(
                with_operation + num,
                no_operation + squared,
                squared
            )

            new_no_operation = max(
                no_operation + num,
                num
            )

            with_operation = new_with_operation
            no_operation = new_no_operation

            answer = max(answer, with_operation)

        return answer
```实现直接遵循动态规划公式。 

变量`no_operation`跟踪以当前索引结尾的最佳子数组，而不使用平方运算。 这与 Kadane 的算法完全相同。 

变量`with_operation`在使用一次操作后跟踪以当前索引结尾的最佳子数组。 

对于每个数字，我们计算一次平方值并在转换中重复使用它。 

过渡为`with_operation`考虑所有合法的可能性：

 - 继续已经修改的子数组
 - 在当前索引处应用操作
 - 使用平方值开始一个全新的子数组

 答案仅使用更新`with_operation`因为该问题要求该操作只能使用一次。 

该算法仅使用恒定的额外内存并一次性处理数组。 

## 解决方案```go
func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func maxSumAfterOperation(nums []int) int {
	noOperation := nums[0]
	withOperation := nums[0] * nums[0]

	answer := withOperation

	for i := 1; i < len(nums); i++ {
		num := nums[i]
		squared := num * num

		newWithOperation := max(
			max(withOperation+num, noOperation+squared),
			squared,
		)

		newNoOperation := max(
			noOperation+num,
			num,
		)

		withOperation = newWithOperation
		noOperation = newNoOperation

		answer = max(answer, withOperation)
	}

	return answer
}
```Go 的实现与 Python 解决方案非常相似。 

Go 不提供内置的`max`函数用于整数，因此我们手动定义一个辅助函数。 

切片自然地用于数组遍历。 由于约束足够小，整数溢出对于 Go 来说不是问题`int`在标准 LeetCode 环境中输入，不需要特殊的溢出处理。 

该解决方案使用恒定的额外内存并执行单个线性扫描。

 ## 边缘情况

 一种重要的边缘情况是单元素数组。 由于该运算是强制性的，因此唯一可能的结果是该元素的平方。 有缺陷的实现可能会意外返回原始值。 初始化步骤通过设置正确处理这个问题`with_operation`到`nums[0] * nums[0]`立即地。 

另一个重要的边缘情况是仅包含负值的数组。 标准最大子数组问题通常返回最小的负数，但这里对大负数进行平方可以创建大的正结果。 该算法正确地考虑通过转换开始一个仅包含平方元素的新子数组：`with_operation = max(..., squared)`。 

当最佳子阵列在几个有害元素之后应该重新启动时，就会出现第三种关键边缘情况。 如果我们总是盲目地扩展先前的子数组，我们可能会向前携带不必要的负和。 Kadane 风格转换通过比较每个索引处的扩展与重新开始来避免此问题。 

当正数的平方比负数的平方更好时，就会出现第四种微妙的边缘情况。 人们很容易假设该操作应该始终以负数为目标，但对足够大的正数进行平方可以产生更大的增益。 由于该算法动态评估所有可能性，因此无论符号如何，它自然会发现最佳操作位置。
