[LeetCode 问题 1740](https://leetcode.com/problems/find-distance-in-a-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 哈希表、树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们在给定值的情况下确定二叉树中两个节点之间的距离`p`和`q`。 距离定义为连接两个节点的最短路径中的边数。 输入是二叉树的根和表示该树中节点值的两个整数。 输出是表示这两个节点之间的距离的单个整数。 

约束提供了重要信息。 该树包含 1 到 10,000 个节点，每个节点都有一个介于 0 到 10^9 之间的唯一值，并且这些值`p`和`q`保证存在于树中。 这些限制表明我们可以依靠值的唯一性来识别节点，并且不需要处理重复项。 由于节点数量最多可达 10,000 个，因此 O(n²) 解决方案可能效率较低，我们应该以 O(n) 时间复杂度为目标。 

重要的边缘情况包括`p`和`q`当一个节点是另一个节点的父节点（距离为 1），并且当两个节点都位于大树的最大深度时，它们是相同的（距离为零）。 由于所有值都是唯一的，因此我们不必考虑一个值的多个匹配。 

## 方法

 **暴力方法**首先会找到从根到`p`和`q`单独存储两条路径，然后比较它们以找到最后一个公共节点（最低公共祖先，LCA）。 然后，距离将被计算为从每个节点到 LCA 的步数之和。 虽然正确，但这需要存储两条路径，这会使用额外的空间并涉及遍历树两次，从而降低了大型树的效率。 

**最佳方法**利用了最低共同祖先 (LCA) 的概念。 关键的见解是两个节点之间的距离`p`和`q`可以计算为它们距 LCA 的距离之和。 为了实现这一点，我们执行单个 DFS 来查找 LCA 并计算沿途的距离。 这减少了对额外路径存储的需求并确保了树的线性遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 分别查找到 p 和 q 的路径，比较路径以查找 LCA，求和 |
 | 最佳 | O(n) | O(h) | 单个 DFS 查找 LCA 和距离，h = 树的高度 |

 ## 算法演练

 1. 定义辅助函数`lca(node, p, q)`递归地找到具有值的节点的最低公共祖先`p`和`q`。 
2. 在同一次递归中，如果当前节点是`p`或者`q`，返回节点本身。 
3. 递归遍历左右子树。 
4. 如果左右递归调用都返回非空节点，则当前节点是LCA。 
5. 否则，传播非空的子级。 
6. 找到 LCA 后，计算从 LCA 到`p`并从 LCA 到`q`单独使用助手`distance_from(node, target)`。 
7. 返回两个距离之和作为最终结果。 

**为什么有效：** 这是有效的，因为 LCA 是位于从根到两者的路径上的最深节点`p`和`q`。 通过对从 LCA 到每个节点的距离求和，我们在连接的最短路径中对每条边精确计数一次`p`和`q`。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def findDistance(self, root: Optional[TreeNode], p: int, q: int) -> int:
        def lca(node: Optional[TreeNode], p: int, q: int) -> Optional[TreeNode]:
            if not node or node.val == p or node.val == q:
                return node
            left = lca(node.left, p, q)
            right = lca(node.right, p, q)
            if left and right:
                return node
            return left or right
        
        def distance_from(node: Optional[TreeNode], target: int) -> int:
            if node.val == target:
                return 0
            if node.left:
                left_distance = distance_from(node.left, target)
                if left_distance != -1:
                    return left_distance + 1
            if node.right:
                right_distance = distance_from(node.right, target)
                if right_distance != -1:
                    return right_distance + 1
            return -1
        
        ancestor = lca(root, p, q)
        return distance_from(ancestor, p) + distance_from(ancestor, q)
```Python 实现定义了两个辅助函数。`lca`确定最低共同祖先`p`和`q`使用标准递归方法。`distance_from`计算从给定节点到目标节点的边数。 从 LCA 到每个节点的距离之和就是总距离。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func findDistance(root *TreeNode, p int, q int) int {
    var lca func(node *TreeNode, p, q int) *TreeNode
    lca = func(node *TreeNode, p, q int) *TreeNode {
        if node == nil || node.Val == p || node.Val == q {
            return node
        }
        left := lca(node.Left, p, q)
        right := lca(node.Right, p, q)
        if left != nil && right != nil {
            return node
        }
        if left != nil {
            return left
        }
        return right
    }

    var distanceFrom func(node *TreeNode, target int) int
    distanceFrom = func(node *TreeNode, target int) int {
        if node.Val == target {
            return 0
        }
        if node.Left != nil {
            leftDist := distanceFrom(node.Left, target)
            if leftDist != -1 {
                return leftDist + 1
            }
        }
        if node.Right != nil {
            rightDist := distanceFrom(node.Right, target)
            if rightDist != -1 {
                return rightDist + 1
            }
        }
        return -1
    }

    ancestor := lca(root, p, q)
    return distanceFrom(ancestor, p) + distanceFrom(ancestor, q)
}
```Go 实现反映了 Python 逻辑。 Nil 检查取代了 Python 的检查`None`。 函数闭包允许使用本地状态进行递归。 返回值使用 -1 来表示不存在，就像在 Python 中一样。 

## 工作示例

 **示例1：**根=`[3,5,1,6,2,0,8,null,null,7,4]`，p = 5，q = 0

 1. 求 5 和 0 → 节点 3 的 LCA。 
2.从3到5的距离→1条边到5的父3，然后1条边到5→总共1（实际上3-5=1）等等，小心一步：3→5=1条边。 正确的。 
3. 3 到 0 → 3 → 1 → 0 = 2 条边的距离。 
4. 总距离 = 1 + 2 = 3。 

**示例2：**根=`[3,5,1,6,2,0,8,null,null,7,4]`，p = 5，q = 7

 1. 5 和 7 的 LCA → 节点 5。 
2. 5 到 5 → 0 条边的距离。 
3. 5 到 7 → 5 → 2 → 7 = 2 条边的距离。 
4. 总距离 = 0 + 2 = 2。 

**示例3：**根=`[3,5,1,6,2,0,8,null,null,7,4]`，p = 5，q = 5

 1. 5 和 5 → 节点 5 的 LCA。 
2. 5 到 5 → 0 条边的距离。 
3. 5 到 5 → 0 条边的距离。 
4. 总距离 = 0 + 0 = 0。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单个 DFS 查找 LCA 和距离，最多接触每个节点两次。 |
 | 空间| O(h) | 递归栈空间与树高h成正比。 在最坏的情况下，h = n（倾斜树）。 |

 该算法与节点数量呈线性关系，因为每个节点最多被访问两次，一次用于查找 LCA，一次用于计算距离。
