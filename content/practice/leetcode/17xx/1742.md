[LeetCode 问题 1742](https://leetcode.com/problems/maximum-number-of-balls-in-a-box/)

 **难度：** 🟢简单
 **主题：** 哈希表、数学、计数

 ## 解决方案

 ## 问题理解

 该问题描述了一种场景，其中您有一系列连续编号的球`lowLimit`到`highLimit`，包含在内。 每个球必须放入一个盒子中，盒子的编号由球编号的数字之和确定。 例如，球`321`进入盒子`3 + 2 + 1 = 6`。 任务是确定哪个盒子最终包含最多的球并返回该盒子中的球数。 

输入由两个整数组成，`lowLimit`和`highLimit`。 它们之间的差加上一，就得到了球的总数。 预期输出是一个整数，表示放置所有球后在任何盒子中找到的最大球数。 

约束表明数量相对较小（`1 <= lowLimit <= highLimit <= 10^5`），因此迭代每个球并计算数字和的暴力解决方案是可行的。 该问题还保证了`lowLimit`和`highLimit`是正数且有序，因此我们不需要处理无效范围。 

边缘情况包括：`lowLimit == highLimit`（只有一个球存在），或者当所有数字由于数字总和太低而落入同一个盒子时。 另一个微妙的情况是当数字之和缓慢增加时，导致某些框保持为空。 

## 方法

 蛮力方法很简单：迭代每个数字`lowLimit`到`highLimit`，计算其数字之和，并在哈希映射或数组中增加该框的计数器。 处理完所有球后，只需找到所有盒子中的最大数量即可。 这种方法是正确的，因为每个球都是独立处理的，但重复计算每个数字的数字总和可能效率稍低。 

关键的优化源于认识到连续数字的数字之和是可预测变化的。 搬家时从`x`到`x + 1`，数字之和加 1，除非有进位（例如，来自`19`到`20`）。 虽然这种观察可以允许数字和“增量更新”，但约束足够小，以至于使用简单哈希图的强力方法已经高效且易于实现。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * d) | O(k) | n = highLimit - lowLimit + 1，d = 位数，k = 最大可能的框数 |
 | 最佳 | O(n * d) | O(k) | 与此输入范围的暴力破解相同； 使用哈希映射来跟踪计数 |

 ## 算法演练

 1. 初始化哈希映射（或字典）来存储每个盒子的球数。 键代表盒子编号（数字之和），值代表每个盒子中的球数。 
2. 迭代所有数字`lowLimit`到`highLimit`。 
3. 对于每个数字，计算其数字之和。 这个总和就是盒子的数量。 
4. 增加哈希图中此框的计数。 
5. 处理完所有数字后，找到哈希图中的最大值。 
6.返回这个最大值，它代表了盒子里球最多的球的数量。 

**为什么有效：** 每个球都按照其数字之和准确地放入盒子中。 对每个位置进行计数可确保具有最大计数的盒子正确反映具有最多球的盒子。 

## Python 解决方案```python
class Solution:
    def countBalls(self, lowLimit: int, highLimit: int) -> int:
        from collections import defaultdict

        box_counts = defaultdict(int)

        for number in range(lowLimit, highLimit + 1):
            box_number = sum(int(digit) for digit in str(number))
            box_counts[box_number] += 1

        return max(box_counts.values())
```在此实现中，我们使用`defaultdict`自动处理尚未遇到的盒子。 对于每个数字，我们将其转换为字符串并将其数字相加以确定盒子编号，然后递增计数。 最后，`max`返回最高球数。 

## 解决方案```go
func countBalls(lowLimit int, highLimit int) int {
    boxCounts := make(map[int]int)
    maxCount := 0

    for num := lowLimit; num <= highLimit; num++ {
        n := num
        sum := 0
        for n > 0 {
            sum += n % 10
            n /= 10
        }
        boxCounts[sum]++
        if boxCounts[sum] > maxCount {
            maxCount = boxCounts[sum]
        }
    }

    return maxCount
}
```在 Go 中，我们使用`map[int]int`用于计数。 使用模和除法计算数字和以避免字符串转换。 我们还保持运行`maxCount`以避免最后迭代地图。

 ## 边缘情况

 首先，情况`lowLimit`等于`highLimit`测试算法处理单个球的能力。 该实现正确地将其计数到适当的框中并返回 1。 

其次，所有数字具有相同数字和的范围可能会给计数逻辑带来压力。 该算法使用哈希图，因此所有球都会正确累积。 

第三，非常大的范围，接近 10^5 的上限，测试性能。 该算法仍然高效，因为迭代具有较小数字和的 10^5 个数字在计算上是可行的。 此外，Go 的整数运算可以防止溢出问题。
