[LeetCode 问题 1769](https://leetcode.com/problems/minimum-number-of-operations-to-move-all-balls-to-each-box/)

 **难度：** 🟡 中等
 **主题：** 数组、字符串、前缀和

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算将一串盒子中的所有球收集到每个单独的盒子中所需的最小移动次数。 每个框可以为空（`'0'`) 或包含一个球 (`'1'`）。 单个操作包括将球从一个盒子移动到相邻的盒子。 

给定二进制字符串`boxes`，我们必须返回一个数组`answer`相同长度，其中`answer[i]`代表将**所有球**移至盒子所需的最少操作`i`从初始配置开始。 关键的一点是，对于每个盒子，我们总是考虑**球的初始位置**，而不是之前操作后的位置。 

约束条件告诉我们`1 <= n <= 2000`，这使得朴素的 O(n²) 解决方案可行，但并不理想。 每个`boxes[i]`保证是`'0'`或者`'1'`，所以我们不必处理无效字符。 关键边缘情况包括带有所有球的字符串（`"111"`），所有空盒子（`"000"`），以及交替模式，例如`"101010"`。 

这个问题本质上要求我们计算所有距离的总和`'1'`高效地发送到每个盒子。 

## 方法

 蛮力方法迭代每个盒子并计算到每个包含球的其他盒子的距离。 对于盒子`i`，我们求和`abs(i - j)`对于每个索引`j`在哪里`boxes[j] == '1'`。 这是正确的但效率低下，因为对于每个`n`盒子，我们可能需要扫描所有`n`位置，时间复杂度为 O(n²)。 对于大型`n`（截至 2000 年），在最坏的情况下这会导致 4,000,000 次操作，虽然很慢但仍然可行。 

最佳方法的关键观察是我们可以使用**前缀和**来计算线性时间内的操作数量。 我们遍历数组两次：一次从左到右，一次从右到左。 在遍历时，我们会保存到目前为止所看到的球的总数以及累积的移动次数。 这使我们能够使用先前计算的信息来计算每个框的移动，避免重复的距离计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 单独计算每个框的距离 |
 | 最佳 | O(n) | O(n) | 使用两次传球并计算总和和球数 |

 ## 算法演练

 1.初始化一个数组`answer`长度`n`带零。 这将保存每个框的最小移动次数。 
2. 遍历`boxes`字符串从左到右。 跟踪两个变量：`balls_left`（到目前为止看到的球数）和`moves_left`（将球从左侧带到当前索引的总步数）。 对于每个框，更新`answer[i]`通过添加`moves_left`。 如果当前盒子包含一个球，则增加`balls_left`。 然后递增`moves_left`经过`balls_left`。 
3. 遍历`boxes`字符串从右到左。 同样，保留`balls_right`和`moves_right`。 更新`answer[i]`通过添加`moves_right`以同样的方式。 更新`balls_right`和`moves_right`和以前一样。 
4. 返回`answer`大批。 

**为什么有效：** 在从左到右传递的每一步中，`moves_left`累积将所有球从左侧移至当前盒子所需的操作。 从右向左的传球对于右侧的球具有相同的作用。 添加这些给出了每个盒子的总最小移动量，因为该问题需要将初始配置中所有球的距离相加。 

## Python 解决方案```python
from typing import List

class Solution:
    def minOperations(self, boxes: str) -> List[int]:
        n = len(boxes)
        answer = [0] * n
        
        # Left to right pass
        balls_left = 0
        moves_left = 0
        for i in range(n):
            answer[i] += moves_left
            if boxes[i] == '1':
                balls_left += 1
            moves_left += balls_left
        
        # Right to left pass
        balls_right = 0
        moves_right = 0
        for i in range(n - 1, -1, -1):
            answer[i] += moves_right
            if boxes[i] == '1':
                balls_right += 1
            moves_right += balls_right
        
        return answer
```**实现演练：** 首先，我们分配答案数组。 从左到右的传球使用连续的球数和累积的移动来计算从左侧带球所需的移动。 每次迭代都会更新`answer[i]`为左侧贡献。 从右向左的传球反映了这种向右传球的逻辑。 将两个贡献相加得出每个框的最终最少操作。 

## 解决方案```go
func minOperations(boxes string) []int {
    n := len(boxes)
    answer := make([]int, n)
    
    // Left to right pass
    ballsLeft, movesLeft := 0, 0
    for i := 0; i < n; i++ {
        answer[i] += movesLeft
        if boxes[i] == '1' {
            ballsLeft++
        }
        movesLeft += ballsLeft
    }
    
    // Right to left pass
    ballsRight, movesRight := 0, 0
    for i := n - 1; i >= 0; i-- {
        answer[i] += movesRight
        if boxes[i] == '1' {
            ballsRight++
        }
        movesRight += ballsRight
    }
    
    return answer
}
```**Go 特定注释：** 我们用以下命令初始化答案切片`make`，它会自动填充零。 循环和运行总计遵循与 Python 相同的逻辑。 Go 不需要单独的类型提示，并且字符串索引直接生成字节，这工作得很好，因为我们与`'1'`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
