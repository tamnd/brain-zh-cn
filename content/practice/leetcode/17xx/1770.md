[LeetCode 问题 1770](https://leetcode.com/problems/maximum-score-from-performing-multiplication-operations/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 这个问题要求我们最大化通过执行一系列**精确**获得的分数`m`对数组的操作`nums`长度`n`使用另一个数组中的乘法器`multipliers`长度`m`。 在每个操作中，我们可以从 **start** 或 **end** 中选择一个元素`nums`，乘以当前乘数，将结果添加到运行分数中，并从其中删除元素`nums`。 目标是最大化之后的总分`m`运营。 

输入是两个数组：`nums`代表我们可以从中选择的数字池，并且`multipliers`表示在每个操作中应用的因素的序列。 输出是一个整数，即可达到的最大分数。 限制条件`1 <= m <= 300`和`m <= n <= 10^5`表明虽然`nums`数组可以很大，操作次数却很少。 这表明有效的算法应该关注`m`操作而不是迭代整个`nums`大批。 

边缘情况包括所有数字均为负数、所有乘数均为负数的情况，或者`m`等于`n`，这迫使我们使用所有数字。 这些情况可能会导致天真的贪婪算法失败，因为选择最大的直接乘积可能不会产生全局最优分数。 

## 方法

 ### 蛮力方法

 暴力方法将从每个乘数的开始或结束开始尝试**所有可能的选择序列**。 对于每个操作，我们有两个选择：选择最左边或最右边的数字。 这会产生一个决策树`2^m`可能的路径，这在计算上是不可行的`m = 300`， 自从`2^300`是一个天文数字。 

### 最优方法 - 动态规划

 关键的观察结果是，在每一步中，问题都表现出**重叠的子问题**和**最佳子结构**。 分数取决于从开始到结束选取的元素数量。 如果我们定义一个DP状态`dp[i][left]`使用第一个作为最大分数`i`乘数和选取`left`元素从开头开始，然后剩余的元素从末尾开始。 其递归式为：```sql
dp[i][left] = max(
    dp[i-1][left-1] + multipliers[i-1] * nums[left-1],   # pick from start
    dp[i-1][left] + multipliers[i-1] * nums[n-(i-left)]   # pick from end
)
```这将复杂性从指数降低到`O(m^2)`时间和`O(m^2)`空间，这是可行的`m <= 300`。 我们可以进一步优化空间`O(m)`通过使用一维 DP 阵列，因为每个步骤仅依赖于前一步。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^m) | O(2^m) | O(米) | 探索所有可能的选秀顺序 |
 | 最佳 | O(m^2) | O(米) | 动态规划用滚动数组来减少空间 |

 ## 算法演练

 1.初始化一个DP数组`dp`尺寸的`m+1`全为零。`dp[left]`将使用第一个存储最大分数`i`乘数和`left`从一开始就选择。 
2. 从第一个乘数到最后一个乘数数组迭代。 在步骤`i`,计算下一个状态`next_dp`使用当前的`dp`价值观。 
3. 对于每个可能的左选择数`left`从 0 到`i`：

 - 如果我们从头开始选择，请添加`multipliers[i] * nums[left]`到`dp[left-1]`。 
- 如果我们从末尾选择，则添加`multipliers[i] * nums[n - 1 - (i - left)]`到`dp[left]`。 
- 取两个选项中的最大值作为新的`next_dp[left]`。 
4. 处理完所有乘数后，得到最大值`dp`代表最优分数。 

**为什么有效：** DP 状态从一开始就正确跟踪所有选秀组合的最高得分。 因为每个乘数仅使用一次，并且我们在每一步都探索这两个选项，所以递归保证找到全局最大值。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumScore(self, nums: List[int], multipliers: List[int]) -> int:
        n = len(nums)
        m = len(multipliers)
        dp = [0] * (m + 1)
        
        for i in range(1, m + 1):
            next_dp = dp[:]
            multiplier = multipliers[i - 1]
            for left in range(i, -1, -1):
                if left > 0:
                    next_dp[left] = max(next_dp[left], dp[left - 1] + multiplier * nums[left - 1])
                if i - left > 0:
                    next_dp[left] = max(next_dp[left], dp[left] + multiplier * nums[n - (i - left)])
            dp = next_dp
        return max(dp)
```此实现初始化 DP 数组并使用滚动方法迭代更新它，以避免`O(m^2)`空间。 在每一步中，它都会考虑从开始或结束处进行选择的两种选择，以确保保持最佳分数。 

## 解决方案```go
func maximumScore(nums []int, multipliers []int) int {
    n := len(nums)
    m := len(multipliers)
    dp := make([]int, m+1)

    for i := 1; i <= m; i++ {
        nextDp := make([]int, m+1)
        copy(nextDp, dp)
        multiplier := multipliers[i-1]
        for left := i; left >= 0; left-- {
            if left > 0 {
                val := dp[left-1] + multiplier*nums[left-1]
                if val > nextDp[left] {
                    nextDp[left] = val
                }
            }
            if i-left > 0 {
                val := dp[left] + multiplier*nums[n-(i-left)]
                if val > nextDp[left] {
                    nextDp[left] = val
                }
            }
        }
        dp = nextDp
    }
    maxScore := dp[0]
    for _, val := range dp {
        if val > maxScore {
            maxScore = val
        }
    }
    return maxScore
}
```在 Go 中，我们处理切片而不是数组，并确保正确复制滚动 DP 数组。 整数溢出不是问题，因为约束保证数字在合理的范围内。 

## 工作示例

 ### 示例 1```
nums = [1,2,3], multipliers = [3,2,1]
```一步一步：

 | 我| 左| 从头开始选择 | 从末尾选择 | DP |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 3*1 = 3 | 3*1 = 3 - | 3 |
 | 1 | 0 | - | 3*3 = 9 | 3*3 = 9 9 |
 | 2 | 2 | 上一个+2*2 = 7 | - | 7 |
 | 2 | 1 | 上一页+2*1=5 | 上一页+2*2=13 | 13 |
 | 2 | 0 | - | 上一个+2*3=11 | 11 | 11
 | 3 | ... | 最终最大值 = 14 | | 14 | 14

 ### 示例 2```
nums = [-5,-3,-3,-2,7,1], multipliers = [-10,-5,3,4,6]
```遵循类似的 DP 更新产量`102`作为最终最高分。

 | 测量 | 复杂性 | 说明|

 | 时间 | O(m^2) | 每个`m`乘法器循环`0..m`左镐|
