[LeetCode 问题 1723](https://leetcode.com/problems/find-minimum-time-to-finish-all-jobs/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、回溯、位操作、位掩码

 ## 解决方案

 ## 问题理解

 这个问题要求我们分配一组作业，每个作业都有特定的时间要求，以`k`以便每项工作都分配给一名工人，并且我们最大限度地减少所有工人的**最大总工作时间**。 输入`jobs`是一个整数数组，其中`jobs[i]`代表完成该任务所需的时间`i`第 - 个工作。 整数`k`指定可用的工人数量。 输出是一个整数，表示分配给任何工作人员的最大工作负载的最小可能值。 

约束条件提供了重要信息：工作岗位数量`n`最多 12 个，每个作业最多需要 10^7 个时间单位。 的小值`n`暗示指数方法（如回溯和修剪）是可行的。 关键边缘情况包括以下场景：`k`等于`n`（每个工人只能从事一份工作）或在哪里`k`是 1（所有工作必须由一个工人负责）。 该问题保证了至少一名工人和至少一份工作，因此我们不需要处理空输入。 

挑战在于，尝试每一个可能的任务的天真方法会导致组合爆炸。 我们需要一种策略，可以有效地探索任务空间，同时修剪不可行或次优的解决方案。 

## 方法

 **暴力方法**将尝试在工人之间进行所有可能的工作分配。 由于每项工作都可以分配给任何工人，因此有`k^n`可能的任务。 对于每项任务，我们都会计算最大工作时间并跟踪最小的最大值。 虽然这种方法是正确的，但即使对于`n = 12`和`k = 4`，因为它需要检查数百万种可能性。 

最佳解决方案的**关键见解**是我们可以在答案上使用**回溯和修剪**结合**二分搜索**。 最大工作时间必须介于最大单次工作时间与所有工作时间之和之间。 我们可以在此范围上执行二分搜索，并针对每个候选人的最大时间，检查是否可以在不超过此限制的情况下将工作分配给工人。 检查可以通过递归回溯算法来完成，该算法尝试一项一项地分配作业，跳过超出候选限制的分配。 这极大地减少了搜索空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 尝试所有可能的工作分配； 对于 n > 10 不可行 |
 | 回溯+二分查找| O(k * 2^n) | O(k * 2^n) | O(n) | 使用回溯和修剪； 对答案范围进行二分搜索 |

 ## 算法演练

 1. **初始化搜索范围**：设置`low`最大工作时间（因为没有工人可以拥有少于最长的工作时间）和`high`所有作业的总和（分配给一名工人的所有作业）。 
2. **二分查找循环**：While`low < high`, 计算`mid = (low + high) // 2`。 这代表了候选人的最大工作量。 
3. **检查可行性**：使用递归函数尝试将每个作业分配给其中一个`k`工人不超过`mid`工作量。 如果任何工人超过`mid`，回溯。 
4. **有效修剪**：如果某个工作人员已经具有与在此递归级别尝试的前一个工作人员相同的工作负载，则跳过向该工作人员分配作业（避免对称状态）。 
5. **更新界限**：如果候选人`mid`可行，减少`high = mid`; 否则，增加`low = mid + 1`。 
6. **返回结果**：搜索结束后，`low`（或者`high`）将保持尽可能最小的最大工作负载。 

**为什么有效**：二分搜索确保我们系统地缩小可能的最大工作负载的范围。 回溯确保我们探索每个候选人最大的所有有效工作分配。 剪枝避免了多余的探索，保证了效率。 该组合保证算法找到尽可能小的最大工作负载。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        def can_assign(jobs, workloads, idx, limit):
            if idx == len(jobs):
                return True
            current_job = jobs[idx]
            for i in range(k):
                if workloads[i] + current_job <= limit:
                    workloads[i] += current_job
                    if can_assign(jobs, workloads, idx + 1, limit):
                        return True
                    workloads[i] -= current_job
                # Prune identical states to reduce redundant recursion
                if workloads[i] == 0:
                    break
            return False

        jobs.sort(reverse=True)
        low, high = max(jobs), sum(jobs)
        while low < high:
            mid = (low + high) // 2
            if can_assign(jobs, [0] * k, 0, mid):
                high = mid
            else:
                low = mid + 1
        return low
```**实现演练**：我们首先排序`jobs`按降序排列，首先分配较大的作业，这通常会更早地触发修剪。 帮手`can_assign`递归地尝试在不超过当前候选限制的情况下将工作分配给工人。 修剪条件`if workloads[i] == 0: break`避免探索对称状态，将工作分配给相同的空工人。 二分搜索迭代地缩小可行的最大工作负载范围。 

## 解决方案```go
func minimumTimeRequired(jobs []int, k int) int {
    var canAssign func(jobs []int, workloads []int, idx int, limit int) bool
    canAssign = func(jobs []int, workloads []int, idx int, limit int) bool {
        if idx == len(jobs) {
            return true
        }
        job := jobs[idx]
        for i := 0; i < k; i++ {
            if workloads[i]+job <= limit {
                workloads[i] += job
                if canAssign(jobs, workloads, idx+1, limit) {
                    return true
                }
                workloads[i] -= job
            }
            if workloads[i] == 0 {
                break
            }
        }
        return false
    }

    sort.Slice(jobs, func(i, j int) bool { return jobs[i] > jobs[j] })
    low, high := 0, 0
    for _, job := range jobs {
        if job > low {
            low = job
        }
        high += job
    }

    for low < high {
        mid := (low + high) / 2
        workloads := make([]int, k)
        if canAssign(jobs, workloads, 0, mid) {
            high = mid
        } else {
            low = mid + 1
        }
    }
    return low
}
```**Go 特定注释**：我们使用切片`workloads`和`jobs`。 排序用途`sort.Slice`。 递归函数是使用变量定义的`canAssign`带有递归闭包。 不需要像 Python 中那样的类型提示。 切片会自动用零初始化，类似于 Python 列表。 

## 工作示例

 **示例1**：`jobs = [3,2,3], k = 3`| 步骤| 剩余职位 | 工作负载 | 行动|
 | ---| ---| ---| ---|
 | 开始| [3,2,3]| [0,0,0]| 将最大的作业 3 分配给工人 0 |
 | 递归| [2,3]| [3,0,0]| 将 2 分配给工人 1 |
 | 递归| [3] | [3,2,0]| 将 3 分配给工人 2 |
 | 完成 | []| [3,2,3]| 最大工作量3，可行|

 **示例2**：`jobs = [1,2,4,7,8], k = 2`二分搜索将测试候选者的最大工作负载。 mid=11时，回溯可以分配：Worker1：1+2+8=11，Worker2：4+7=11。 可行，因此搜索范围缩小到 11。没有更低的值是可行的。 最小最大工作负载为 11。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(k * 2^n) | O(k * 2^n) | 可以探索每个工作子集； 修剪减少实用时间|
 | 空间| O(n) | 递归栈深度可达n； 工作负载数组使用 O(k) |
