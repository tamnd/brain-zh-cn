[LeetCode 第 1763 题](https://leetcode.com/problems/longest-nice-substring/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、分而治之、位操作、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们在给定字符串中找到**最长的“好”子字符串**`s`。 如果子字符串包含的每个字母都出现其小写形式和大写形式，则该子字符串被认为是**好**。 例如，`"aAa"`很好，因为它包含`'a'`和`'A'`。 反过来，`"abA"`不好因为`'b'`出现但是`'B'`没有。 输入字符串`s`仅由英文字母组成，长度在 1 到 100 之间。输出应该是最长的好子串，如果有多个相同长度的候选，则应返回最早的一个。 如果不存在好的子字符串，则应返回空字符串。 

关键点包括需要检查子字符串中所有字母的**大小写对应关系**并有效处理**小字符串**。 边缘情况包括长度为 1 的字符串（总是不好）、所有字母都在一种情况下的字符串以及已经完全好的字符串。 

## 方法

 **暴力方法**涉及检查所有可能的子字符串`s`。 对于每个子字符串，我们将计算其字母并验证每个字母是否同时存在大写和小写形式。 虽然这保证了正确性，但效率很低，因为存在 O(n²) 个子字符串，并且检查每个子字符串可能需要 O(n) 时间，从而导致 O(n³) 复杂性。 

**最佳方法**利用**分而治之的策略**。 关键的见解是，如果子字符串包含子字符串中缺少相反大小写的字符，则该字符不能成为任何好的子字符串的一部分。 因此，我们可以在这些字符处分割字符串，并递归地搜索左右子字符串。 这减少了不必要的检查并有效地找到最长的好子串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 检查所有子字符串并验证是否良好 |
 | 最佳 | O(n²) | O(n) | 使用缺少相反大小写的字符进行分而治之 |

 ## 算法演练

 1. 定义一个以子字符串作为输入的辅助函数。 
2. 将子字符串转换为**字符集**，以有效检查是否缺少相反的情况。 
3. 迭代子字符串。 对于每个字符，检查集合中是否存在其相反的情况。 
4. 如果所有字符都有相反的大小写，则立即返回子字符串，因为这样很好。 
5. 如果某个字符缺少相反的大小写，则将该字符处的字符串拆分为**左右子字符串**。 
6. 对左右子串递归调用辅助函数，以找到每个子串中最长的好子串。 
7. 比较左右结果，返回长度较大的结果。 如果长度相等，则返回左子字符串（较早出现的）。 
8. 从整个字符串开始递归`s`。 

**为什么有效：** 该算法之所以有效，是因为任何没有相反大小写的字符都不能成为好的子字符串的一部分。 通过分割这些字符，我们确保递归中所有剩余的候选者都可能是好的。 这种分而治之的特性保证了我们最终检查所有有效的候选者，而无需多余的计算。 

## Python 解决方案```python
class Solution:
    def longestNiceSubstring(self, s: str) -> str:
        def helper(sub: str) -> str:
            if len(sub) < 2:
                return ""
            chars = set(sub)
            for i, c in enumerate(sub):
                if c.swapcase() not in chars:
                    left = helper(sub[:i])
                    right = helper(sub[i+1:])
                    return left if len(left) >= len(right) else right
            return sub
        
        return helper(s)
```**实施演练：**`helper`函数通过将子字符串转换为一组字符来检查子字符串是否合适。 对于每个字符，它使用以下方法验证其相反情况的存在`c.swapcase()`。 如果发现不匹配，它将子串分成左右两部分，并递归地找到最长的好子串。 递归确保有效地探索所有候选者。 

## 解决方案```go
func longestNiceSubstring(s string) string {
    var helper func(sub string) string
    helper = func(sub string) string {
        if len(sub) < 2 {
            return ""
        }
        chars := make(map[rune]bool)
        for _, c := range sub {
            chars[c] = true
        }
        for i, c := range sub {
            if !chars[rune(swapcase(byte(c)))] {
                left := helper(sub[:i])
                right := helper(sub[i+1:])
                if len(left) >= len(right) {
                    return left
                } else {
                    return right
                }
            }
        }
        return sub
    }
    
    return helper(s)
}

func swapcase(c byte) byte {
    if 'a' <= c && c <= 'z' {
        return c - 'a' + 'A'
    } else if 'A' <= c && c <= 'Z' {
        return c - 'A' + 'a'
    }
    return c
}
```**Go 特定注释：** 我们使用`map[rune]bool`有效地跟踪字符。 这`swapcase`函数将字母从大写转换为小写，反之亦然。 切片用于子字符串提取。 递归逻辑与 Python 非常相似。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n²) | 每次分割都会检查子字符串集，迭代 n 个字符。 在最坏的情况下，可能会有 n 次递归调用。 |

 ## 边缘情况

 **单字符字符串：**类似的字符串`"c"`或者`"A"`从定义上来说它们并不好，因为它们缺乏相反的情况。 该实现通过在长度小于 2 时返回空字符串来处理此问题。 

**具有多个分割的字符串：** 字符串，例如`"YazaAay"`需要对缺少相反大小写的字符进行多次递归分割。 递归确保考虑所有段，返回其中最长的好子串。 

**完整的字符串已经很好了：**对于像这样的字符串`"aAbBcCdD"`，不会发生分割，因为每个字符都有相反的大小写。 该算法正确地将整个字符串识别为最长的好子串。 

这种仔细的处理确保了算法对于各种场景都具有鲁棒性，同时保持高效。
