[LeetCode 问题 1743](https://leetcode.com/problems/restore-the-array-from-adjacent-pairs/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、深度优先搜索

 ## 解决方案

 ## 问题理解

 该问题为我们提供了未知数组中的所有相邻对`nums`，我们的任务是重建原始数组。 

假设原始数组是：```
[1, 2, 3, 4]
```相邻的对将是：```
[1,2], [2,3], [3,4]
```重要的细节是，这些对可以以任何顺序出现，也可以颠倒。 所以输入可能如下所示：```
[[2,1], [3,4], [3,2]]
```即使顺序被打乱，邻接关系仍然完整地描述了原始数组。 

该数组包含唯一的整数，这一点极其重要。 由于每个值都是唯一的，因此每个数字只能出现在数组中的特定位置。 在有效的线性数组中：

 - 内部元素恰好有两个邻居。 
- 两个端点恰好有一个邻居。 

这立即表明了图形解释。 每个数字都是一个节点，每个相邻的对在两个节点之间创建一条无向边。 由于原始数组形成一个简单的链，因此生成的图是路径图。 

限制条件很大：

 -`n`可以大到`10^5`- 我们必须处理最多`100000`有效配对

 这排除了昂贵的回溯或重复扫描方法。 我们需要一个接近线性时间的解决方案。 

有几个重要的边缘情况：

 - 数组可能包含负数。 
- 数组只能包含两个元素。 
- 相邻对可以完全随机的顺序呈现。 
- 任一有效的重建方向都是可接受的。 例如，`[1,2,3]`和`[3,2,1]`都是正确的。 
- 我们必须避免在重建路径时重新访问元素。 

因为问题保证存在有效的解决方案，所以我们不需要处理格式错误的图形或断开连接的组件。 

## 方法

 ### 蛮力方法

 强力解决方案将尝试通过尝试每个可能的起始元素并使用未使用的相邻对递归地扩展序列来尝试重建数组。 

在每一步中，我们都会搜索包含当前数字的对，附加匹配的邻居，将该对标记为已使用，然后继续，直到重建所有元素。 

这种方法是正确的，因为它通过邻接关系探索所有可能的有效路径。 最终，它会发现原始的顺序。 

然而，对于大量输入来说，这变得极其低效。 每个递归步骤可能会扫描许多对，并且分支因子会显着增长。 在最坏的情况下，时间复杂度会变成二次或更糟。 

和`10^5`元素，这种方法太慢了。 

### 最佳方法

 关键的观察是相邻关系形成路径图。 

在路径图中：

 - 恰好两个节点有度数`1`，这些是端点。 
- 每个其他节点都有度`2`。 

因此我们可以：

 1. 使用哈希映射构建邻接表。 
2. 通过定位只有一个邻居的节点来找到一个端点。 
3. 按顺序遍历链，始终选择下一个未访问过的邻居。 

因为每个节点都被处理一次，所以解变成线性的。 

这非常有效，因为图结构保证表示单个有效数组。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n) | 反复扫描配对并探索路径 |
 | 最佳 | O(n) | O(n) | 使用邻接表和线性遍历 |

 ## 算法演练

 1. 使用哈希映射创建邻接表。 

对于每对`[u, v]`， 添加：

-`v`到`u`的邻居列表
 -`u`到`v`的邻居列表

 这会将输入转换为无向图表示。 
2. 找到起始节点。 

在原始数组中，两个端点各只有一个邻居。 因此，在邻接表中，端点具有度数`1`。 

我们迭代哈希图并选择邻居列表长度为的任何节点`1`。 
3. 初始化结果数组。 

添加起始端点作为答案的第一个元素。 
4. 跟踪前一个元素。 

在遍历过程中，每个内部节点都有两个邻居：

 - 我们来自的节点
 - 我们应该去的下一个节点

 为了避免向后移动，我们跟踪前一个节点。 
5. 按顺序重建数组。 

每一步：

 - 查看当前节点的邻居。 
- 选择不等于前一个节点的邻居。 
- 将其附加到结果中。 
- 前进。 
6. 继续，直到添加所有节点。 

由于该图是一个简单的链，因此我们最终只访问每个节点一次。 

### 为什么它有效

 由相邻对形成的图保证是单一路径。 路径图恰好有两个带有度数的端点`1`，并且每个其他节点都有度`2`。 

从任一端点开始并重复移动到不是先前访问过的节点的邻居，唯一地重建路径。 由于每个节点都被访问一次，因此生成的序列是原始数组的有效重建。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def restoreArray(self, adjacentPairs: List[List[int]]) -> List[int]:
        graph = defaultdict(list)

        # Build adjacency list
        for u, v in adjacentPairs:
            graph[u].append(v)
            graph[v].append(u)

        # Find endpoint
        start = None
        for node, neighbors in graph.items():
            if len(neighbors) == 1:
                start = node
                break

        n = len(adjacentPairs) + 1
        result = [0] * n
        result[0] = start

        # Handle array of length 2
        if n == 2:
            result[1] = graph[start][0]
            return result

        # Second element must be the only neighbor of start
        result[1] = graph[start][0]

        # Reconstruct remaining elements
        for i in range(2, n):
            neighbors = graph[result[i - 1]]

            # Choose neighbor different from previous element
            if neighbors[0] == result[i - 2]:
                result[i] = neighbors[1]
            else:
                result[i] = neighbors[0]

        return result
```实现首先使用构造邻接表`defaultdict(list)`。 这允许恒定时间插入邻居，同时自然地表示图结构。 

接下来，代码搜索端点。 由于端点只有一个邻居，因此我们只需定位邻接列表具有长度的节点`1`。 

然后使用起始端点初始化结果数组。 如果数组长度仅为 2，则重构很简单，因为端点的唯一邻居必须是第二个元素。 

对于较大的数组，第二个元素是唯一确定的，因为起始端点只有一个邻居。 

从那时起，每个内部节点都有两个邻居。 一个邻居是重建序列中的前一个元素，而另一个是我们需要的下一个元素。 通过与之前的值进行比较，我们可以确定接下来要添加哪个邻居。 

继续遍历直到重建整个数组。 

## 解决方案```go
package main

func restoreArray(adjacentPairs [][]int) []int {
	graph := make(map[int][]int)

	// Build adjacency list
	for _, pair := range adjacentPairs {
		u, v := pair[0], pair[1]

		graph[u] = append(graph[u], v)
		graph[v] = append(graph[v], u)
	}

	// Find endpoint
	start := 0
	for node, neighbors := range graph {
		if len(neighbors) == 1 {
			start = node
			break
		}
	}

	n := len(adjacentPairs) + 1
	result := make([]int, n)

	result[0] = start

	// Handle length 2
	if n == 2 {
		result[1] = graph[start][0]
		return result
	}

	// Second element
	result[1] = graph[start][0]

	// Reconstruct array
	for i := 2; i < n; i++ {
		neighbors := graph[result[i-1]]

		if neighbors[0] == result[i-2] {
			result[i] = neighbors[1]
		} else {
			result[i] = neighbors[0]
		}
	}

	return result
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 一个`map[int][]int`用于邻接表。 

切片自然有效地表示邻居列表。 由于每个内部节点恰好有两个邻居，因此访问`neighbors[0]`和`neighbors[1]`初始设置后是安全的。 

不需要对整数溢出进行特殊处理，因为这些约束很适合 Go 的范围`int`类型。

空间使用是线性的，因为图存储了每个节点和边。 结果数组还需要`O(n)`空间。

 ## 边缘情况

 一种重要的边缘情况是原始数组仅包含两个元素。 在这种情况下，两个节点都是端点，并且每个节点只有一个邻居。 粗心的实现可能会尝试访问不存在的第二个邻居。 该解决方案通过特殊情况明确处理此问题`n == 2`。 

另一个重要的边缘情况涉及负整数。 由于值的范围可以是`-10^5`到`10^5`，错误地依赖数组索引而不是哈希映射的实现可能会失败或浪费大量内存。 使用哈希映射允许算法自然地处理任意整数值。 

第三个关键边缘情况是相邻对的任意排序。 不保证输入对按遍历顺序出现。 假设输入的本地排序的简单实现会立即崩溃。 邻接列表表示完全避免了这个问题，因为它存储独立于输入顺序的关系。 

遍历内部节点期间会出现微妙的边缘情况。 每个内部节点都有两个邻居，选择错误的节点会导致遍历向后而不是向前移动。 该实现通过始终与先前访问的元素进行比较并选择另一个邻居来避免这种情况。 

最后，可以从任一端点重建图，生成原始数组或其反向数组。 由于问题接受任何有效的重建，因此算法只需选择它遇到的第一个端点。
