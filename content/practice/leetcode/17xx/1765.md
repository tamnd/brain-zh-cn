[LeetCode 问题 1765](https://leetcode.com/problems/map-of-highest-peak/)

 **难度：** 🟡 中等
 **主题：** 数组、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 问题呈现一个矩阵`isWater`尺寸的`m x n`其中每个单元格要么是水（`1`）或土地（`0`）。 我们被要求以满足三个规则的方式为每个单元指定高度。 首先，所有高度必须是非负整数。 其次，水池的高度必须为`0`。 第三，任何两个相邻单元格（北、南、东、西）之间的高度绝对差不得超过`1`。 目标是分配高度，以便矩阵中的**最大高度**尽可能大。 

实际上，这要求我们从水单元向外“增加”高度，每远离水一步就增加 1，同时确保满足邻接约束。 可能存在多种解决方案，因为可以通过多种方式从多个水源向外传播高度。 

输入约束告诉我们矩阵可以大到 1000x1000，所以算法的时间复杂度比`O(m * n)`可能太慢了。 至少有一个水细胞，这保证了任何基于传播的方法的起点。 

重要的边缘情况包括水细胞聚集的矩阵、矩阵只有一行或一列的矩阵以及水细胞位于角落或边缘的矩阵。 

## 方法

 **强力方法**将涉及基于相邻单元迭代地增加陆地单元的高度，直到满足所有相邻约束。 例如，可以重复扫描矩阵，更新陆地单元以`min(neighbor heights + 1)`直到不再发生任何变化。 虽然这最终会收敛到一个有效的解决方案，但它可能需要`O((m * n)^2)`在最坏的情况下，对于大型矩阵来说，考虑到限制，这是不可接受的。 

最佳方法的**关键见解**是该问题相当于同时从所有水单元开始的**多源广度优先搜索（BFS）**。 由于每个单元格的高度最多可以增加`1`每远离水一步，BFS 确保每个陆地单元接收到 **距水的最小可能距离**，这直接转化为它的高度。 BFS 自然地传播正确的高度，同时尊重邻接差约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m * n)^2) | O((m * n)^2) | O(m * n) | 重复扫描矩阵，直到满足所有邻接约束 |
 | 最优（多源 BFS）| O(m * n) | O(m * n) | 从所有水单元开始 BFS，将高度指定为距最近水的距离 |

 ## 算法演练

 1. 初始化一个矩阵`height`尺寸的`m x n`和`-1`表示未访问的单元格。 水细胞稍后将被设置为`0`。 
2.初始化一个队列`q`并添加所有水细胞`(i, j)`到队列中，同时设置`height[i][j] = 0`。 
3. 当队列不为空时，移除一个cell`(i, j)`从前面。 
4. 对于四个相邻方向（北、东、南、西）中的每一个，计算相邻单元格`(ni, nj)`。 
5. 如果邻居在边界内并且`height[ni][nj] == -1`（尚未分配），设置`height[ni][nj] = height[i][j] + 1`并入队`(ni, nj)`。 
6. 继续，直到队列为空。 此时，所有单元都已根据距最近水域的距离指定了高度。 

**为什么起作用：** BFS 保证第一次访问陆地单元时，它与任何水单元的距离最小。 将高度指定为该距离可确保遵守邻接差异规则，因为 BFS 逐层传播。 矩阵中的最大高度对应于距水最远的陆地单元，这最大化了高度分配。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def highestPeak(self, isWater: List[List[int]]) -> List[List[int]]:
        m, n = len(isWater), len(isWater[0])
        height = [[-1] * n for _ in range(m)]
        q = deque()
        
        # Initialize water cells
        for i in range(m):
            for j in range(n):
                if isWater[i][j] == 1:
                    height[i][j] = 0
                    q.append((i, j))
        
        # Directions: north, south, east, west
        directions = [(-1,0),(1,0),(0,-1),(0,1)]
        
        # BFS to assign heights
        while q:
            x, y = q.popleft()
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and height[nx][ny] == -1:
                    height[nx][ny] = height[x][y] + 1
                    q.append((nx, ny))
        
        return height
```实施首先将所有水单元标记为高度`0`并将它们添加到队列中。 BFS 确保每个陆地单元接收到的高度等于其距水单元的最小距离。 通过使用`-1`作为未访问单元的哨兵，我们避免重新访问任何单元。 队列以波浪形式传播高度，确保满足邻接约束。 

## 解决方案```go
package main

func highestPeak(isWater [][]int) [][]int {
    m, n := len(isWater), len(isWater[0])
    height := make([][]int, m)
    for i := 0; i < m; i++ {
        height[i] = make([]int, n)
        for j := 0; j < n; j++ {
            height[i][j] = -1
        }
    }

    type pair struct{ x, y int }
    queue := []pair{}

    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if isWater[i][j] == 1 {
                height[i][j] = 0
                queue = append(queue, pair{i, j})
            }
        }
    }

    directions := []pair{{-1,0},{1,0},{0,-1},{0,1}}

    for len(queue) > 0 {
        curr := queue[0]
        queue = queue[1:]
        for _, d := range directions {
            nx, ny := curr.x + d.x, curr.y + d.y
            if nx >= 0 && nx < m && ny >= 0 && ny < n && height[nx][ny] == -1 {
                height[nx][ny] = height[curr.x][curr.y] + 1
                queue = append(queue, pair{nx, ny})
            }
        }
    }

    return height
}
```在 Go 中，我们使用切片作为矩阵和一个简单的结构体`pair`为坐标。 BFS 逻辑是相同的。 注意初始化切片`-1`对于未访问的单元格，类似于Python哨兵值。 

## 工作示例

 **示例1：**`isWater = [[0,1],[0,0]]`逐步 BFS：

 1.水细胞队列：`[(0,1)]`， 高度`[[ -1,0], [-1,-1]]`2. 流程`(0,1)`： 分配`(0,0)=1`,`(1,1)=1`→ 队列`[(0,0),(1,1)]`， 高度`[[1,0],[-1,1]]`3. 流程`(0,0)`： 分配`(1,0)=2`→ 队列`[(1,1),(1,0)]`， 高度`[[1,0],[2,1]]`4. 处理剩余单元：不需要新的分配
 5.最终高度：`[[1,0],[2,1]]`**示例2：**`isWater = [[0,0,1],[1,0,0],[0,0,0]]`1.水细胞队列：`[(0,2),(1,0)]`，高度初始化为`0`在这些位置
 2. BFS逐层传播高度，为每个陆地单元分配距最近水域的距离
 3.最终高度矩阵：`[[1,1,0],[0,1,1],[1,2,2]]`## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 在 BFS 中，每个单元都被访问一次 |

 由于 BFS 同时从所有水细胞传播，因此我们可以有效地分配高度，而无需重复扫描。
