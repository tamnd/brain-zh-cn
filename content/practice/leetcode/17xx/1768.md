[LeetCode 问题 1768](https://leetcode.com/problems/merge-strings-alternately/)

 **难度：** 🟢简单
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 该问题需要合并两个输入字符串`word1`和`word2`以交替的方式，从第一个字符开始`word1`。 这意味着我们从`word1`，然后是一个字符`word2`，并重复此过程，直到一个或两个字符串耗尽。 如果一个字符串比另一个字符串长，则应将较长字符串中的剩余字符附加到合并结果的末尾。 

输入字符串保证只包含小写英文字母，长度范围为 1 到 100。这确保了我们不需要处理空字符串，并且性能限制适中，因此简单的线性时间解决方案就足够了。 重要的边缘情况包括一个字符串明显长于另一个字符串或两个字符串长度相等的情况。 

输出是表示根据所描述的交替模式的合并结果的单个字符串。 这意味着该算法必须正确处理不均匀的长度并维护每个原始字符串中的字符顺序。 

## 方法

 暴力方法是重复删除每个字符串中的第一个字符并将其附加到结果中，直到两个字符串都为空。 虽然这会产生正确的结果，但在像 Python 这样的语言中效率很低，因为循环中的字符串连接在每一步都会创建一个新字符串。 在这种情况下，时间复杂度可能会降低到 O(n^2)。 

最佳方法利用两个指针或索引计数器同时遍历两个字符串。 在每一步中，角色都来自`word1`然后是来自的角色`word2`被附加到结果列表中。 一旦一个字符串用完，另一字符串的剩余部分将在一次操作中附加。 这保持了线性时间复杂度并避免了重复的字符串复制。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n+m) | 每一步重复字符串连接，Python 效率低下 |
 | 最佳 | O(n + m) | O(n + m) | 使用两个指针和一个列表来收集字符，然后加入|

 ## 算法演练

 1.初始化一个空列表`merged`当我们遍历两个字符串时存储字符。 
2.初始化两个指针，`i`和`j`，从0开始迭代`word1`和`word2`分别。 
3. 当两个指针都在各自字符串的范围内时：

 - 追加`word1[i]`到`merged`和增量`i`。 
- 追加`word2[j]`到`merged`和增量`j`。 
4. 一个字符串用完后，将另一字符串中剩余的子字符串直接追加到`merged`。 这处理字符串长度不等的情况。 
5. 转换`merged`使用列表到字符串`''.join(merged)`并归还它。 

**为什么有效：** 该算法确保两个字符串中的字符以交替顺序添加，直到一个字符串用完。 不变的是，在每一步中，从两个字符串到当前指针的字符都按顺序包含。 任何剩余的字符都会附加在末尾，以保证正确性。 

## Python 解决方案```python
class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        merged = []
        i, j = 0, 0
        while i < len(word1) and j < len(word2):
            merged.append(word1[i])
            i += 1
            merged.append(word2[j])
            j += 1
        # Append the remaining part of the longer string
        if i < len(word1):
            merged.append(word1[i:])
        if j < len(word2):
            merged.append(word2[j:])
        return ''.join(merged)
```实现紧密遵循算法。 使用列表来提高效率，而不是重复的字符串连接。 指针`i`和`j`跟踪进度通过`word1`和`word2`。 最终的连接操作将字符列表转换为所需的输出字符串。 

## 解决方案```go
func mergeAlternately(word1 string, word2 string) string {
    var merged []byte
    i, j := 0, 0
    for i < len(word1) && j < len(word2) {
        merged = append(merged, word1[i])
        i++
        merged = append(merged, word2[j])
        j++
    }
    // Append remaining substring if any
    if i < len(word1) {
        merged = append(merged, word1[i:]...)
    }
    if j < len(word2) {
        merged = append(merged, word2[j:]...)
    }
    return string(merged)
}
```在 Go 中，我们使用`[]byte`切片以有效地构建合并的字符串。 该逻辑反映了 Python 实现。 Go 的切片附加允许我们使用以下方式简洁地处理剩余字符`...`。

 ## 边缘情况

 一个重要的边缘情况是一根绳子比另一根绳子长。 这可能会导致假定字符串长度相等的简单实现失败。 该解决方案通过在主循环之后附加剩余的子字符串来处理此问题。 

另一种边缘情况是长度为 1 的字符串。如果某些实现依赖于假设多个字符的循环，则它们可能会失败。 即使长度为 1，当前方法也能正确迭代。 

最后，处理其中一个为空的字符串是另一个潜在的错误来源，尽管约束保证每个字符串中至少有一个字符。 通过在交替循环之后附加每个字符串的剩余部分，如果放松约束，这种情况仍然可以正常工作。
