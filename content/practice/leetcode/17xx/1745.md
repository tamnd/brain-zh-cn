[LeetCode 问题 1745](https://leetcode.com/problems/palindrome-partitioning-iv/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们判断给定的字符串是否`s`可以正好分割成三个**非空子串**，每个子串都是一个回文。 回文是向前和向后读相同的字符串。 例如，字符串`"aba"`是一个回文，而`"abc"`不是。 输入`s`长度保证至少3个字符，最多2000个字符，并且完全由小写英文字母组成。 

输出是一个布尔值：`true`如果存在这样的分区，`false`否则。 重要的是，三个子字符串中的每一个都必须是**非空**，这意味着像一个空子字符串这样的琐碎分区是无效的。 

关键边缘情况包括完全回文的字符串（例如，`"aaa"`) 或包含重复字符但不能形成三个长度至少为 1 的回文的字符串。 另外，长度正好为 3 的字符串很有趣，因为每个字符都必须单独是回文。 

## 方法

 暴力方法是尝试所有可能的方法将字符串分成三部分，并检查每个部分是否是回文。 这涉及第一次和第二次切割的嵌套循环。 虽然它保证了正确性，但对于最大输入大小来说它太慢了，因为它会导致`O(n^3)`复杂：`O(n^2)`分割，每个子串检查回文都需要`O(n)`时间。 

最佳解决方案的一个关键观察是我们可以使用动态规划预先计算所有回文子串。 通过构建二维布尔表`dp[i][j]`表示子串是否`s[i:j+1]`是一个回文，我们可以有效地检查所有可能的分裂`O(n^2)`时间。 这减少了多次检查回文的重复工作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 尝试每个分割并检查每个部分是否是回文 |
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 预计算回文表并有效检查分割 |

 ## 算法演练

 1. 初始化一个二维布尔数组`dp`尺寸的`n x n`在哪里`dp[i][j]`将`True`如果子串`s[i:j+1]`是一个回文。 
2. 填写`dp`表使用以下规则：如果子字符串的端点匹配并且内部子字符串是回文，则该子字符串是回文。 对于长度为1的子串，标记为`True`，对于长度 2，标记`True`如果两个字符匹配。 
3. 迭代所有可能的第一次切割`i`从 1 到`n-2`。 这定义了第一个子字符串`s[0:i]`。 
4. 对于每个第一次切割，迭代所有可能的第二次切割`j`从`i+1`到`n-1`。 这定义了第二个子字符串`s[i:j]`和第三个子串`s[j:n]`。 
5. 对于每对切口`(i,j)`，检查是否`dp[0][i-1]`,`dp[i][j-1]`， 和`dp[j][n-1]`都是`True`。 
6. 如果存在这样的分割，则返回`True`。 如果拆分不起作用，则返回`False`。 

为什么它有效：`dp`table 保证检查子字符串是否是回文`O(1)`。 通过迭代所有有效的切割位置，我们确保考虑每个可能的三部分分区。 因此，如果存在有效分区，就会找到它。 

## Python 解决方案```python
class Solution:
    def checkPartitioning(self, s: str) -> bool:
        n = len(s)
        dp = [[False] * n for _ in range(n)]
        
        for length in range(1, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if length == 1:
                    dp[i][j] = True
                elif length == 2:
                    dp[i][j] = s[i] == s[j]
                else:
                    dp[i][j] = s[i] == s[j] and dp[i + 1][j - 1]
        
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                if dp[0][i - 1] and dp[i][j - 1] and dp[j][n - 1]:
                    return True
        return False
```该实现首先构造一个回文表`dp`其中每个单元格`dp[i][j]`告诉如果`s[i:j+1]`是一个回文。 这两个嵌套循环检查每个有效的两次切割配置，以查看所有三个结果子字符串是否都是回文。 

## 解决方案```go
func checkPartitioning(s string) bool {
    n := len(s)
    dp := make([][]bool, n)
    for i := 0; i < n; i++ {
        dp[i] = make([]bool, n)
    }

    for length := 1; length <= n; length++ {
        for i := 0; i <= n-length; i++ {
            j := i + length - 1
            if length == 1 {
                dp[i][j] = true
            } else if length == 2 {
                dp[i][j] = s[i] == s[j]
            } else {
                dp[i][j] = s[i] == s[j] && dp[i+1][j-1]
            }
        }
    }

    for i := 1; i < n-1; i++ {
        for j := i + 1; j < n; j++ {
            if dp[0][i-1] && dp[i][j-1] && dp[j][n-1] {
                return true
            }
        }
    }
    return false
}
```Go 实现镜像了 Python 逻辑，使用 DP 表的切片。 所有子字符串比较都使用字节索引，因为字符串在 Go 中是不可变的。 

## 工作示例

 ### 示例 1：`s = "abcbdd"`1. 构建`dp`桌子：`dp[0][2] = False`,`dp[1][3] = True`为了`"bcb"`,`dp[4][5] = True`为了`"dd"`。 
2.检查分割：第一次切割`i=1`（`"a"`），第二次剪切`j=4`（`"bcb"`), 最后一个子串`"dd"`- 都是回文。 
3. 返回`True`。 

### 示例 2：`s = "bcbddxy"`1. 构建`dp`表：只有回文数`"b"`,`"c"`,`"b"`,`"d"`,`"d"`,`"x"`,`"y"`和`"bcb"`。 
2. 检查所有拆分：没有组合给出三个回文。 
3. 返回`False`。

 ## 边缘情况

 一种重要的边缘情况是字符串恰好包含三个字符。 每个字符都必须是回文。 The algorithm handles this naturally since`dp[i][j]`将单个字符标记为回文。 

Another edge case occurs when the string is entirely composed of the same character. This could lead a naive algorithm to try invalid splits if it does not ensure three non-empty substrings. Using the two nested loops for cuts ensures non-empty partitions.
