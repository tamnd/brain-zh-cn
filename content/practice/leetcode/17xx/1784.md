[LeetCode 问题 1784](https://leetcode.com/problems/check-if-binary-string-has-at-most-one-segment-of-ones/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出一个二进制字符串`s`仅包含字符`'0'`和`'1'`。 该字符串保证以`'1'`，这意味着没有前导零。 任务是确定字符串是否最多包含一个连续的 1 段。 

连续的 1 段意味着一系列连续的`'1'`字符不间断。 例如：

-`"111"`包含一段 1。 
-`"110011"`包含两段 1。 
-`"1000"`包含一段 1。 
-`"10101"`包含三个独立的部分。 

预期输出是一个布尔值：

 - 返回`true`如果字符串有零个或一段 1。 
- 返回`false`如果字符串有两个或多个单独的部分。 

限制非常小：

 - 字符串长度介于`1`和`100`。 
- 每个角色都是`'0'`或者`'1'`。 
- 第一个字符始终是`'1'`。 

这些限制告诉我们，即使是低效的解决方案也能快速运行。 然而，目标仍然是设计一个干净且正确的算法。 

一个重要的观察是，因为字符串总是以`'1'`，第一段总是从索引处开始`0`。 因此，我们唯一需要检测的是是否有另一个`'1'`出现在 a 之后`'0'`第一节已经结束了。 

一些边缘情况很重要：

 - 只包含 1 的字符串，例如`"11111"`，应该返回`true`。 
- 一个字符串，其中一个段后跟零，例如`"111000"`，应该返回`true`。 
- 一个字符串，其中 1 重新出现在零之后，例如`"110011"`，应该返回`false`。 
- 单字符字符串`"1"`应该返回`true`。 

## 方法

 ### 蛮力方法

 一种直接的方法是显式地计算 1 的连续段的数量。 

我们可以从左到右扫描字符串并检测每个新段的开头。 每当出现以下情况时，新的段就会开始：

 - 当前角色是`'1'`, 和
 - 要么是第一个字符，要么是前一个字符`'0'`。 

每次发生这种情况时，我们都会增加一个计数器。 最后，我们返回计数器是否小于或等于 1。 

这种方法是正确的，因为每个连续的组都有一个起始位置。 通过计算这些起始位置，我们可以计算段的数量。 

尽管这个解决方案对于给定的约束已经足够有效，但我们可以进一步简化逻辑。 

### 最佳方法

 关键的观察是字符串以`'1'`。 因此，第一段必须从字符串的开头开始。 

如果我们遇到子串`"01"`，这意味着：

 - 一段结束于`'0'`- 另一部分从以下开始`'1'`这立即证明了至少有两段。 

所以问题减少到检查字符串是否包含`"01"`。 

- 如果`"01"`存在，返回`false`。 
- 否则，返回`true`。 

这导致了一个非常简洁和有效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 计算 1 的连续段 |
 | 最佳 | O(n) | O(1) | O(1) | 检测是否`"01"`存在 |

 ## 算法演练

 1. 开始从左到右扫描字符串。 
2. 检查子串是否`"01"`出现在字符串中的任何位置。 这种模式很重要，因为它代表一段的结束和另一段的开始。 
3.如果`"01"`发现立即返回`false`，因为该字符串包含多个 1 段。 
4. 如果扫描完成后没有找到`"01"`， 返回`true`，因为所有的都属于一个连续的段。 

### 为什么它有效

 该字符串开头为`'1'`，所以第一段总是从索引开始`0`。 仅当零之后再次出现时才会出现第二段。 子串`"01"`准确地捕捉到了这种转变。 因此，存在`"01"`相当于有多个段。 

## Python 解决方案```python
class Solution:
    def checkOnesSegment(self, s: str) -> bool:
        return "01" not in s
```实现完全依赖于对问题的核心观察。 

表达式`"01" in s`检查字符串是否包含紧随其后的 0。 如果存在这样的模式，则该字符串必须包含至少两个单独的 1 段。 

通过返回`"01" not in s`，我们返回`True`仅当字符串最多包含一段 1 时。 

该解决方案很简洁，因为 Python 直接在字符串上提供高效的子字符串搜索操作。 

## 解决方案```go
func checkOnesSegment(s string) bool {
    for i := 0; i < len(s)-1; i++ {
        if s[i] == '0' && s[i+1] == '1' {
            return false
        }
    }

    return true
}
```Go 实现通过扫描相邻字符来手动执行子字符串检测。 

在每个索引处，它检查当前字符是否是`'0'`下一个字符是`'1'`。 如果找到该模式，该函数立即返回`false`。 

与 Python 不同，Go 没有针对这种具体用例的简洁的内置子字符串语法，因此循环是最清晰的方法。 

无需担心整数溢出或特殊内存处理，因为输入大小非常小并且算法使用恒定的额外空间。

 ## 边缘情况

 一种重要的边缘情况是仅包含一个字符的字符串，例如`"1"`。 粗心的实现可能会错误地假设在检查相邻对时至少有两个字符。 提供的解决方案可以正确处理此问题，因为当字符串长度为 1 时，循环根本不执行。 

另一个重要的情况是完全由 1 组成的字符串，例如`"111111"`。 在这种情况下，只有一个连续的段。 算法正确返回`true`因为子串`"01"`永远不会出现。 

第三个重要的边缘情况是当 1 在一长串零之后重新出现时，例如`"1000001"`。 一些天真的解决方案可能会错误地在第一个零之后停止检查。 实现的算法继续扫描整个字符串，因此它可以正确检测到`"01"`模式接近结束并返回`false`。 

最后一个微妙的情况是`"10"`。 有一段 1 后面跟着 0，这是有效的。 算法正确返回`true`因为没有发生`"01"`。
