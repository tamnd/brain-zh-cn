[LeetCode 问题 1794](https://leetcode.com/problems/count-pairs-of-equal-substrings-with-minimum-difference/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、贪婪

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算**四元组**`(i, j, a, b)`其中两个给定字符串的子字符串相等且差值`j - a`被最小化。 具体来说，`i`和`j`定义一个子串`firstString`， 尽管`a`和`b`定义一个子串`secondString`。 子串本身必须相同，并且在所有有效四元组中，我们只考虑那些达到**最小可能值的子串`j - a`**。 输出是这样的四元组的计数。 

输入是两个非空小写英文字符串，每个字符串最多`2 * 10^5`人物。 这个约束立即表明，检查所有子串对的简单暴力解决方案会太慢，因为它会涉及`O(n^2 * m^2)`长度字符串的运算`n`和`m`。 

重要的观察结果包括需要仔细有效地管理子字符串比较，可能使用滚动哈希或直接逐字符滑动技术，并跟踪最小的`j - a`遭遇。 

可能会导致幼稚方法失败的边缘情况包括不共享公共字符的字符串、相同的字符串或在不同偏移处存在多个匹配项并产生不同结果的字符串。`j - a`价值观。 

## 方法

 **暴力方法**将迭代所有子字符串`firstString`并将它们与所有子串进行比较`secondString`。 对于每场比赛，计算`j - a`并更新找到的最小值的计数。 这原则上是正确的，因为它检查了所有可能性，但由于所有可能的子串对上的嵌套循环，效率极低。 

**最佳方法**依赖于这样的观察：问题本质上是寻找从某些索引开始的等长子字符串并最小化它们之间的偏移。 我们可以使用滑动窗口或滚动哈希技术来有效地比较子字符串。 我们不是生成所有子字符串，而是生成从每个索引开始的所有子字符串，并跟踪哈希映射或字典中的匹配项，同时更新最小值`j - a`并计算实现这一目标的四元组。 这大大降低了时间复杂度，使其达到可行的程度`n, m <= 2 * 10^5`。

 | 蛮力 | O(n^2 * m^2) | O(n^2 * m^2) | O(1) | O(1) | 检查所有子串对，太慢 |
 | 最佳 | O(n * m) | O(min(n, m)) | 滑动窗口或滚动哈希可有效比较子字符串并跟踪最小值`j - a`|

 ## 算法演练

 1. 初始化`min_diff`到一个大的值并且`count`至 0。`min_diff`将存储最小值`j - a`到目前为止所看到的，以及`count`将跟踪达到此最小值的四元数的数量。 
2. 迭代所有起始索引`i`在`firstString`。 
3. 对于每个`i`，迭代起始索引`a`在`secondString`。 
4. 对于每对`(i, a)`, 当字符匹配时扩展子字符串 (`firstString[i+k] == secondString[a+k]`) 并跟踪结束索引`j = i + k`和`b = a + k`。 
5. 计算`diff = j - a`。 
6. 如果`diff < min_diff`， 更新`min_diff = diff`并重置`count = 1`。 
7. 如果`diff == min_diff`, 增量`count`。 
8. 返回`count`。 

为什么它有效：该算法确保我们检查所有子串对，但只计算那些达到最小值的子串对`j - a`。 通过逐个字符比较，我们有效地避免显式生成所有子字符串，并跟踪`min_diff`保证正确性。 

## Python 解决方案```python
class Solution:
    def countQuadruples(self, firstString: str, secondString: str) -> int:
        n, m = len(firstString), len(secondString)
        min_diff = float('inf')
        count = 0

        for i in range(n):
            for a in range(m):
                k = 0
                while i + k < n and a + k < m and firstString[i + k] == secondString[a + k]:
                    j = i + k
                    b = a + k
                    diff = j - a
                    if diff < min_diff:
                        min_diff = diff
                        count = 1
                    elif diff == min_diff:
                        count += 1
                    k += 1

        return count
```Python实现直接翻译了算法步骤。 外部循环迭代所有可能的起始索引。 内部`while`循环扩展子字符串，直到发现不匹配。 我们追踪`diff = j - a`并更新`min_diff`并相应地计数。 这避免了显式的子串构造并确保了效率。 

## 解决方案```go
func countQuadruples(firstString string, secondString string) int {
    n, m := len(firstString), len(secondString)
    minDiff := int(1e9)
    count := 0

    for i := 0; i < n; i++ {
        for a := 0; a < m; a++ {
            k := 0
            for i+k < n && a+k < m && firstString[i+k] == secondString[a+k] {
                j := i + k
                diff := j - a
                if diff < minDiff {
                    minDiff = diff
                    count = 1
                } else if diff == minDiff {
                    count++
                }
                k++
            }
        }
    }

    return count
}
```Go 实现反映了 Python 解决方案。 差异包括显式整数处理和使用大量数字进行初始化`minDiff`。 子字符串比较使用索引算术，因为 Go 字符串不能像符文切片一样在不进行转换的情况下进行索引，但对于 ASCII 小写字母，直接字节索引是有效的。

 ## 边缘情况

 一个重要的边缘情况是**完全不重叠的字符串**，例如`"ab"`和`"cd"`。 该算法自然地处理这个问题，因为内部`while`循环永远不会运行，并且计数保持为零。 

另一种情况是**单字符字符串**，它测试算法在以下情况下是否正确识别匹配：`i == j`和`a == b`。 Python 和 Go 解决方案都可以无缝处理这个问题，因为循环条件包括相等检查和数组边界。 

第三种情况是**有重复字符的字符串**，比如`"aaaa"`和`"aa"`，它可以产生多个有效的四元组。 该算法正确地计算了所有达到最小值的四元组`j-a`通过扩展每个起始索引的匹配并仅在以下情况下更新计数`diff == min_diff`。 这可以防止过度计数，同时确保正确性。
