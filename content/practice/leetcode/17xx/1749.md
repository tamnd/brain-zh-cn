[LeetCode 第 1749 题](https://leetcode.com/problems/maximum-absolute-sum-of-any-subarray/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组中任何连续子数组的最大**绝对和**`nums`。 子数组是连续元素的序列，其绝对和定义为该子数组中所有元素之和的绝对值。 

换句话说，对于一个子数组`[nums[l], nums[l+1], ..., nums[r]]`，我们计算`sum(nums[l:r+1])`然后采取`abs(sum)`。 任务是在所有可能的子数组中找到最大可能的绝对和，包括空子数组（其和为零）。 

输入是一个整数数组`nums`长度最大为 100,000，每个元素的范围为 -10,000 到 10,000。 这些约束意味着检查所有可能的子数组的简单暴力解决方案（时间复杂度为 O(n²)）太慢了。 该解决方案必须高效，理想情况下是线性的。 

要考虑的边缘情况包括所有数字均为正数、所有数字均为负数的数组，或者混合有可能相互抵消的正数和负数的数组。 

## 方法

 暴力方法将考虑所有子数组，计算它们的总和，并跟踪最大绝对值。 这可以正确工作，但效率非常低，因为子数组的数量为 O(n²)，对每个子数组求和需要 O(n) 时间，导致总时间为 O(n3)。 

最佳解决方案的关键观察是问题简化为最大子数组和问题（Kadane 算法）的变体。 我们不只是跟踪最大和，而是跟踪最大和和最小和子数组。 绝对最大值将是以下值中的较大者`max_sum`和`abs(min_sum)`。 这是可行的，因为具有较大负和的子数组的绝对值可能超过所有正和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 计算所有子数组的总和并取最大绝对值 |
 | 最佳 | O(n) | O(1) | O(1) | 使用修改后的 Kadane 算法计算最大和最小子数组和 |

 ## 算法演练

 1.初始化两个变量：`max_sum`跟踪以当前索引结尾的最大子数组总和，以及`min_sum`跟踪以当前索引结尾的最小子数组和。 另外，初始化`max_abs_sum`跟踪迄今为止遇到的最大绝对总和。 
2. 初始化两个累加器：`current_max`和`current_min`两者都设置为 0。它们表示以当前元素结尾的最佳子数组和。 
3. 迭代每个数字`x`在`nums`。 
4. 更新`current_max`作为最大值`x`和`current_max + x`。 这是以当前元素结束的最大和子数组的标准 Kadane 步骤。 
5. 更新`current_min`作为最小值`x`和`current_min + x`。 这跟踪以当前元素结束的最小（最负）总和。 
6. 更新`max_abs_sum`作为自身的最大值，`current_max`， 和`abs(current_min)`。 
7. 循环结束后，`max_abs_sum`包含任何子数组的最大绝对和。 

**为什么有效：** 在每一步，`current_max`确保我们捕获以当前索引结尾的最大可能子数组总和，同时`current_min`确保我们捕获最负的子数组和。 取最小值的绝对值即为最大的负贡献。 由于每个子数组都是连续的，并且 Kadane 的算法有效地考虑了所有可能的端点，因此结果是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxAbsoluteSum(self, nums: List[int]) -> int:
        max_abs_sum = 0
        current_max = 0
        current_min = 0
        
        for x in nums:
            current_max = max(x, current_max + x)
            current_min = min(x, current_min + x)
            max_abs_sum = max(max_abs_sum, current_max, abs(current_min))
        
        return max_abs_sum
```实现直接遵循算法演练。`current_max`计算以当前元素结尾的最大子数组和，而`current_min`跟踪最小值。 这`max_abs_sum`在每次迭代中更新，以确保它始终包含遇到的最大绝对和。 

## 解决方案```go
func maxAbsoluteSum(nums []int) int {
    maxAbsSum := 0
    currentMax := 0
    currentMin := 0

    for _, x := range nums {
        if currentMax + x > x {
            currentMax = currentMax + x
        } else {
            currentMax = x
        }

        if currentMin + x < x {
            currentMin = currentMin + x
        } else {
            currentMin = x
        }

        if currentMax > maxAbsSum {
            maxAbsSum = currentMax
        }
        if -currentMin > maxAbsSum {
            maxAbsSum = -currentMin
        }
    }

    return maxAbsSum
}
```在 Go 中，主要区别是显式的 if 语句而不是`max`/`min`函数，并且循环使用 range 关键字进行迭代。 逻辑与 Python 版本保持相同。

 ## 边缘情况

 一种边缘情况是单元素数组。 该解决方案正确返回该元素的绝对值，处理正数和负数情况。 

另一个重要的边缘情况是所有负数的数组。 仅跟踪最大总和的简单实现在这里可能会失败，但跟踪最小值可确保考虑绝对值。 

第三种边缘情况是最大绝对和来自不是完整数组而是内部部分的子数组。 例如，`[1,-3,2,3,-4]`有子数组`[2,3]`给出最大绝对和 5。Kadane 算法适用于两者
