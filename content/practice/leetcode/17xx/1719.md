[LeetCode 问题 1719](https://leetcode.com/problems/number-of-ways-to-reconstruct-a-tree/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、树、图论、模拟

 ## 解决方案

 ## 问题理解

 该问题提供了一系列`pairs`，其中每对`[xi, yi]`表明`xi`是一个祖先`yi`或者`yi`是的祖先`xi`在一棵有根的树上。 关键的挑战是确定有多少不同的有根树满足所有给定的对。 我们不仅限于二叉树； 节点可以有任意数量的子节点。 输出是`0`如果不存在有效的树，`1`如果恰好存在一棵树，并且`2`如果可能存在多棵树。 

输入保证没有重复的对，并且每对都保证没有重复的对`xi < yi`。 树的节点只是成对出现的节点。 一个重要的方面是，一对暗示着祖先-后代关系，但没有给出方向； 我们只知道这两个节点通过树以某种祖先-后代方式连接。 

这些限制表明我们需要一个在时间和空间上都有效的解决方案。 高达`10^5`对和节点值高达`500`，该算法应避免组合树枚举，而是使用哈希图或邻接集来处理类似图形的关系。 

边缘情况包括：线性树（如链表）、星形树（所有节点都连接到一个根）、断开连接的节点（无效树）以及一个节点存在多个有效父节点的情况（导致多个有效树）。 

## 方法

 暴力方法将尝试从节点集中生成所有可能的有根树，然后根据节点对验证每棵树。 对于每个候选树，我们将检查所有祖先-后代关系。 这种方法保证是正确的，但由于树排列的组合爆炸，在计算上不可行，特别是给定`n`最多`500`。 

最佳方法依赖于图论。 输入中每个节点的邻接集表示潜在的父子关系。 该算法首先将具有最大度数的节点识别为候选根，因为根应该以某种祖先-后代方式连接到所有其他节点。 然后，对于每个节点，我们选择具有严格大于其自身的最小度数的父节点作为相邻节点。 如果一个节点的邻接不是其父节点邻接的子集，则该树无效。 当一个节点与其父节点具有相同的度数时，就会出现多个有效树，因为父子分配可以在不违反祖先约束的情况下交换。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n^2) | O(n^2) | 生成所有树并针对对进行验证； 对于大 n | 不可行
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 使用邻接集和度数来分配父级并有效检测多种树的可能性 |

 ## 算法演练

 1. 转换列表`pairs`从每个节点到其邻接集的映射。 这捕获直接连接到每个节点的所有节点。 
2. 辨根。 根应该连接到所有其他节点，因此它是具有最大邻接集的节点。 如果没有节点连接到所有其他节点，则返回`0`。 
3.对于每个节点`v`（不包括根），确定父候选。 父节点必须是相邻节点`u`其邻接集大小严格大于`v`是最小的这样的集合。 如果不存在这样的父树，则该树无效。 
4. 验证每个节点的邻接集是其父节点的邻接集的子集。 如果任何节点违反此属性，则树无效，我们返回`0`。 
5. 检测是否可能存在多棵树。 如果一个节点与其父节点具有相同的邻接大小，则交换它们的角色可以保留祖先-后代关系，因此我们设置一个标志来指示多个有效树。 
6. 返回`2`如果可能存在多棵树，否则`1`。 

**为什么有效：** 邻接集编码祖先-后代关系。 通过选择其邻接集严格包含该节点的邻接集的最小父节点，我们确保了有效的父节点分配。 根是唯一连接到所有其他节点的节点。 子集的性质保证了所有祖先对`pairs`很满意。 

## Python 解决方案```python
from typing import List, Dict, Set

class Solution:
    def checkWays(self, pairs: List[List[int]]) -> int:
        from collections import defaultdict

        # Step 1: Build adjacency sets
        adj: Dict[int, Set[int]] = defaultdict(set)
        nodes = set()
        for u, v in pairs:
            adj[u].add(v)
            adj[v].add(u)
            nodes.add(u)
            nodes.add(v)

        # Step 2: Find the root (node connected to all others)
        n = len(nodes)
        root = None
        for node in nodes:
            if len(adj[node]) == n - 1:
                root = node
                break
        if root is None:
            return 0

        multiple = False

        # Step 3: Assign parent for each node
        for node in nodes:
            if node == root:
                continue
            parent = None
            for neighbor in adj[node]:
                if len(adj[neighbor]) >= len(adj[node]):
                    if parent is None or len(adj[neighbor]) < len(adj[parent]):
                        parent = neighbor
            if parent is None or not adj[node].issubset(adj[parent]):
                return 0
            if len(adj[parent]) == len(adj[node]):
                multiple = True

        return 2 if multiple else 1
```**说明：** 邻接集是为了存储直接连接而构建的。 通过查找连接到所有其他节点的节点来识别根。 对于每个非根节点，我们选择其邻接集严格包含该节点的邻接集并且大小最小的父节点。 子集检查保证满足所有必需的祖先-后代关系。 如果一个节点与其父节点具有相同的邻接大小，则可能存在多棵树。 

## 解决方案```go
func checkWays(pairs [][]int) int {
    adj := make(map[int]map[int]struct{})
    nodes := make(map[int]struct{})
    
    // Step 1: Build adjacency sets
    for _, p := range pairs {
        u, v := p[0], p[1]
        if adj[u] == nil {
            adj[u] = make(map[int]struct{})
        }
        if adj[v] == nil {
            adj[v] = make(map[int]struct{})
        }
        adj[u][v] = struct{}{}
        adj[v][u] = struct{}{}
        nodes[u] = struct{}{}
        nodes[v] = struct{}{}
    }

    n := len(nodes)
    root := -1
    for node := range nodes {
        if len(adj[node]) == n-1 {
            root = node
            break
        }
    }
    if root == -1 {
        return 0
    }

    multiple := false

    // Step 3: Assign parent for each node
    for node := range nodes {
        if node == root {
            continue
        }
        var parent int = -1
        for neighbor := range adj[node] {
            if len(adj[neighbor]) >= len(adj[node]) {
                if parent == -1 || len(adj[neighbor]) < len(adj[parent]) {
                    parent = neighbor
                }
            }
        }
        if parent == -1 {
            return 0
        }
        for v := range adj[node] {
            if _, ok := adj[parent][v]; !ok {
                return 0
            }
        }
        if len(adj[parent]) == len(adj[node]) {
            multiple = true
        }
    }

    if multiple {
        return 2
    }
    return 1
}
```**说明：** Go 版本镜像 Python。 整数集的映射表示邻接。 根选择、父代分配、子集检查和多树检测遵循相同的逻辑。 Go 需要使用映射手动处理集合。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^2) | O(n^2) | 每个节点检查其邻接集中的所有邻居； n ≤ 500 使得这变得可行 |
