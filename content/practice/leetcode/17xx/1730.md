[LeetCode 问题 1730](https://leetcode.com/problems/shortest-path-to-get-food/)

 **难度：** 🟡 中等
 **主题：** 数组、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们找到从起始位置到二维网格中任何食物单元的最短路径。 网格由四种类型的单元组成：`'*'`指示您的起始位置，`'#'`代表食物，`'O'`作为您可以移动的自由空间，并且`'X'`作为你无法跨越的障碍。 输出应该是到达任何食物单元所需的最少步数。 如果没有通往食物的路径，则输出应该是`-1`。 

输入是大小为 2D 的矩阵`m x n`， 在哪里`1 <= m, n <= 200`，所以我们最多可以有 40,000 个单元。 网格保证恰好有一个起始位置`'*'`，但可能有多个食物细胞`'#'`和障碍`'X'`。 允许在四个基本方向上移动：北、东、南、西。 不允许对角线移动。 这些约束意味着，由于潜在的大网格尺寸，递归地探索每条可能路径的强力解决方案可能效率不高，因此需要更结构化的搜索。 

重要的边缘情况包括：起始单元与食物单元直接相邻，食物完全被障碍物包围，或者在不同距离处有多个食物单元，我们必须找到最小值。 

## 方法

 蛮力方法将涉及递归地探索从起点到任何食物细胞的每条可能路径，同时跟踪行进的距离。 这保证了正确性，因为它最终会检查所有路径，但效率很低，因为它可能会多次重新访问同一单元，并且对于大型网格可能会花费指数时间。 

最佳方法利用**广度优先搜索 (BFS)**。 BFS 非常适合这个问题，因为它逐级探索所有节点，确保我们遇到的第一个食物单元距离起点最短。 BFS 使用队列来维护探索的边界和访问集或就地标记以避免重新访问单元。 由于网格相对较大，BFS 通过在发现第一个食物单元后立即停止来保证效率。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(4^(m*n)) | O(4^(m*n)) | O(m*n) | 递归探索所有路径，对于大型网格来说效率极低 |
 | 最佳 | O(m*n) | O(m*n) | BFS保证最短路径，每个cell最多访问一次 |

 ## 算法演练

 1. 扫描整个网格，定位起始位置`'*'`。 将其坐标记录为`(start_row, start_col)`。 
2. 初始化一个 BFS 队列，并将起始单元格与初始距离一起入队`0`。 
3. 或者，通过替换将起始单元标记为已访问`'*'`和`'X'`或维护一个单独的访问矩阵。 
4. 定义四个可能的移动方向：北、南、东、西。 
5. 当队列不为空时，将单元出队`(row, col, distance)`。 
6. 检查当前细胞是否为食物细胞`'#'`。 如果是，立即返回当前距离。 
7. 否则，探索所有四个相邻单元格。 对于每个邻居，确保它在边界内并且是自由空间`'O'`或食物`'#'`。 
8. 将每个有效邻居标记为已访问并将其排入队列`distance + 1`。 
9. 如果队列变空而没有找到任何食物单元，则返回`-1`表示不存在路径。 

**为什么有效：** BFS 保证按照距起点距离递增的顺序来探索单元。 因此，第一次遇到食物细胞时，我们保证记录的距离是可能的最小距离。 最多访问每个单元一次可以防止循环并确保效率。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def getFood(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        # Find the starting position
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '*':
                    start = (i, j)
                    break

        queue = deque([(start[0], start[1], 0)])  # (row, col, distance)
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        grid[start[0]][start[1]] = 'X'  # mark start as visited

        while queue:
            r, c, dist = queue.popleft()
            if grid[r][c] == '#':
                return dist
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and (grid[nr][nc] == 'O' or grid[nr][nc] == '#'):
                    queue.append((nr, nc, dist + 1))
                    grid[nr][nc] = 'X'  # mark as visited
        return -1
```Python 实现首先找到起始单元格。 BFS 队列存储当前位置以及行驶距离。 对于每个出队的单元格，我们立即检查它是否是食物。 如果没有，我们将所有有效的邻居放入队列。 将单元格标记为`'X'`确保我们不会再次访问它们。 这保证了有效地找到最短路径。 

## 解决方案```go
package main

func getFood(grid [][]byte) int {
    m, n := len(grid), len(grid[0])
    var startRow, startCol int
    found := false
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == '*' {
                startRow, startCol = i, j
                found = true
                break
            }
        }
        if found {
            break
        }
    }

    type cell struct{ r, c, dist int }
    queue := []cell{{startRow, startCol, 0}}
    directions := [][2]int{{-1, 0}, {1, 0}, {0, -1}, {0, 1}}
    grid[startRow][startCol] = 'X'

    for len(queue) > 0 {
        curr := queue[0]
        queue = queue[1:]
        r, c, dist := curr.r, curr.c, curr.dist
        if grid[r][c] == '#' {
            return dist
        }
        for _, d := range directions {
            nr, nc := r+d[0], c+d[1]
            if nr >= 0 && nr < m && nc >= 0 && nc < n && (grid[nr][nc] == 'O' || grid[nr][nc] == '#') {
                queue = append(queue, cell{nr, nc, dist + 1})
                grid[nr][nc] = 'X'
            }
        }
    }
    return -1
}
```在Go中，我们定义一个结构体`cell`存储行、列和距离。 BFS 逻辑反映了 Python。 与 Python 不同，Go 中的切片需要追加到队列中，但应用相同的级别顺序遍历逻辑。 将单元格标记为已访问可避免重新访问。 

## 工作示例

 **示例1：**```
Grid:
X X X X X X
X * O O O X
X O O # O X
X X X X X X
```1. 开始于`(1,1)`, 入队`(1,1,0)`。 
2. 出队`(1,1,0)`并探索邻居：`(1,2,1)`和`(2,1,1)`是有效的。 
3. 出队`(1,2,1)`。 邻居：`(1,3,2)`是有效的。 
4. 出队`(2,1,1)`。 邻居：`(2,2,2)`是有效的。 
5. 出队`(1,3,2)`。 邻居：`(2,3,3)`是食物。 
6. 返回`3`。 

其他示例也类似，逐层探索，直到到达第一个食物单元。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(m*n) | 在 BFS 中每个单元最多被访问一次 |
 | 空间| O(m*n) | 最坏情况下队列可能容纳所有单元|

 BFS 确保相对于细胞数量的线性时间。 标记已访问的单元可防止重新访问并确保队列不会增长超过 O(m*n)。
