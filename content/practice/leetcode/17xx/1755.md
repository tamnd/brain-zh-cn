 **难度：** 🔴难
 **主题：** 数组、两个指针、动态规划、位操作、排序、位掩码

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定整数数组的子序列`nums`使得该子序列的总和尽可能接近给定的整数`goal`。 子序列可以包含按原始顺序排列的任何元素子集，包括选择不选择任何元素（总和为 0）或选择所有元素（总和为数组总和）的可能性。 输出是任何子序列之和与目标之间的最小可能绝对差`goal`。 

约束告诉我们数组的长度`nums`很小（最多 40 个），但是 elements 和 的值`goal`可以很大（最多 ±10^9）。 这种组合表明，依赖于直接迭代所有可能和的方法通过优化是可行的，但生成所有 2^40 子集的简单方法会太慢。 重要的边缘情况包括全部为正数或全部为负数的数组，`goal`超出可能的总和范围，以及需要忽略所有元素的子序列（总和 = 0）。 

## 方法

 蛮力方法很简单：生成每个可能的子序列`nums`，计算其总和，并跟踪与的绝对差`goal`。 这保证了正确性，因为它会检查所有可能性，但速度太慢。 长度数组的子序列数`n`是 2^n，呈指数增长。 对于 n = 40，这大约是 1 万亿，这是无法计算的。 

更高效解决方案的关键洞察是**中间相遇**。 因为数组长度最多为40，所以我们可以拆分`nums`分成两半，每半约 20 个元素。 然后我们为每一半生成所有可能的子序列和，从而产生两组和。 对于前半部分的每个和，我们可以在后半部分搜索最接近的补集以接近`goal`。 对二分之一的和进行排序使我们能够使用二分搜索有效地找到最接近的和，将时间复杂度从 O(2^n) 降低到 O(2^(n/2) * log(2^(n/2))) = O(2^(n/2) * n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 生成所有子序列，计算总和，跟踪最小差异 |
 | 最佳 | O(2^(n/2) * n) | O(2^(n/2) * n) | O(2^(n/2)) | O(2^(n/2)) | 中间相遇：分割数组、生成和、二分搜索最接近的补集 |

 ## 算法演练

 1. 分割数组`nums`分成两半，`left`和`right`，长度大致相等。 这减少了组合爆炸，因为 2^(n/2) 对于 n ≤ 40 是可行的。 
2. 生成所有可能的子序列和`left`和`right`。 这可以使用位掩码或递归回溯来完成。 对于每个元素，决定是否将其包含在总和中。 
3. 对总和列表进行排序`right`。 排序使我们能够在寻找最能补充以下总和的总和时执行有效的二分搜索`left`来接近`goal`。 
4. 初始化变量`min_diff`到无穷大。 这将跟踪迄今为止发现的最小绝对差异。 
5. 对于每笔金额`s`在`left`求和，计算互补目标`target = goal - s`。 在中执行二分查找`right`求和求和`r`最接近`target`。 更新`min_diff`作为`min(min_diff, abs(s + r - goal))`。 
6. 检查所有金额后`left`反对`right`求和，返回`min_diff`。 

**为什么有效：** 通过生成每一半的所有和并将它们组合起来，我们确保整个数组的每个可能的子序列和都表示为`s_left + s_right`。 二分查找保证我们有效地找到最接近的匹配，而对一半进行排序可以保持正确性。 

## Python 解决方案```python
from typing import List
import bisect

class Solution:
    def minAbsDifference(self, nums: List[int], goal: int) -> int:
        def generate_sums(arr: List[int]) -> List[int]:
            sums = [0]
            for num in arr:
                new_sums = [num + s for s in sums]
                sums += new_sums
            return sums
        
        n = len(nums)
        left, right = nums[:n//2], nums[n//2:]
        
        left_sums = generate_sums(left)
        right_sums = generate_sums(right)
        right_sums.sort()
        
        min_diff = float('inf')
        for s in left_sums:
            target = goal - s
            idx = bisect.bisect_left(right_sums, target)
            if idx < len(right_sums):
                min_diff = min(min_diff, abs(s + right_sums[idx] - goal))
            if idx > 0:
                min_diff = min(min_diff, abs(s + right_sums[idx-1] - goal))
        
        return min_diff
```这`generate_sums`函数递归地为给定的一半构建所有可能的子序列之和。 排序`right_sums`使二分搜索能够有效地找到最接近的补集。 两次二分搜索检查确保我们考虑最接近的较大和较小的总和以最小化差异。 

## 解决方案```go
import (
    "math"
    "sort"
)

func minAbsDifference(nums []int, goal int) int {
    generateSums := func(arr []int) []int {
        sums := []int{0}
        for _, num := range arr {
            newSums := make([]int, len(sums))
            for i, s := range sums {
                newSums[i] = s + num
            }
            sums = append(sums, newSums...)
        }
        return sums
    }

    n := len(nums)
    leftSums := generateSums(nums[:n/2])
    rightSums := generateSums(nums[n/2:])
    sort.Ints(rightSums)
    
    minDiff := math.MaxInt64
    for _, s := range leftSums {
        target := goal - s
        idx := sort.Search(len(rightSums), func(i int) bool { return rightSums[i] >= target })
        if idx < len(rightSums) {
            diff := abs(s + rightSums[idx] - goal)
            if diff < minDiff {
                minDiff = diff
            }
        }
        if idx > 0 {
            diff := abs(s + rightSums[idx-1] - goal)
            if diff < minDiff {
                minDiff = diff
            }
        }
    }
    return minDiff
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```在Go中，切片是动态附加的，并且排序加上`sort.Search`提供了一种执行二分搜索的有效方法。 要注意处理二分搜索的边界。 

## 工作示例

 示例1：`nums = [5, -7, 3, 5], goal = 6`分裂：`left = [5, -7]`,`right = [3, 5]`左总和：`[0, 5, -7, -2]`, 右和：`[0, 3, 5, 8]`对于每个剩余的总和：

 -`0 → target = 6 → closest in right_sums = 5 → abs(0+5-6)=1`-`5 → target=1 → closest = 0 → abs(5+0-6)=1, 3 → abs(5+3-6)=2 → min=1`-`-7 → target=13 → closest = 8 → abs(-7+8-6)=5`-`-2 → target=8 → closest = 8 → abs(-2+8-6)=0`结果：`0`## 复杂度分析
