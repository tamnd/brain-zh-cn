[LeetCode 问题 1722](https://leetcode.com/problems/minimize-hamming-distance-after-swap-operations/)

 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、并查

 ## 解决方案

 ## 问题理解

 该问题要求我们找到两个数组之间的**最小汉明距离**，`source`和`target`，在执行任意次数的交换后`source`在允许的位置`allowedSwaps`。 **汉明距离**定义为索引的数量`i`为此`source[i] != target[i]`。 

输入由两个长度的整数数组组成`n`以及允许交换的列表。 每个允许的交换都是一对索引`[ai, bi]`，这意味着这些位置的元素可以按任意顺序交换任意次数。 目标不是输出最终数组，而是计算通过利用这些交换可实现的最小可能汉明距离。 

约束条件表明`n`和长度`allowedSwaps`可以达到`10^5`，因此尝试所有可能的交换排列的简单暴力方法是不可行的。 我们需要一个线性或近线性扩展的解决方案。 重要的边缘情况包括`allowedSwaps`为空（不允许交换），当所有元素都已匹配（最小距离为零）时，或者当`source`和`target`有可以重新排列的重复项。 

关键的观察是交换定义了数组中的**连接组件**。 在每个连接的组件内，元素可以自由排列。 因此，最小汉明距离是通过比较每个分量中的多组值来确定的`source`与相应的值`target`。 

## 方法

 暴力方法将尝试模拟所有可能的交换序列，生成每个排列`source`允许的`allowedSwaps`，然后计算每个的汉明距离。 这种方法是正确的，但不切实际，因为排列的数量随着组件的大小呈指数增长。 

最佳方法使用 **Union-Find**（不相交集并集）根据以下条件将索引分组为连接的组件：`allowedSwaps`。 在每个组件中，我们可以自由地重新排列元素`source`。 对于每个组件，我们计算元素的出现次数`source`和`target`，然后减去匹配计数以计算最小不匹配数。 这避免了枚举排列并且对于大输入有效地工作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((n!)^k) | O((n!)^k) | O(n) | 生成连通分量的所有排列； 不可行 |
 | 最佳 | O(n + m) | O(n) | 使用 Union-Find 对索引进行分组，对每个组件的不匹配进行计数，可扩展 |

 这里，`m`是允许的交换次数。 

## 算法演练

 1. **初始化并查找**中的所有索引`source`。 每个索引都以其自己的父索引开始。 
2. **处理允许的交换**。 对于每个`[ai, bi]`，并集`ai`和`bi`。 这会将索引分组到允许交换的连接组件中。 
3. **按成分对指数进行分组**。 在所有联合之后，迭代每个索引并将根父级映射到该组件中的索引列表。 
4. **计算每个组件的元素频率**。 对于每个组件，计算每个值出现的次数`source`和`target`。 
5. **计算每个分量的汉明距离贡献**。 对于每个值，计算计数之间的差异`source`和`target`。 对多余的出现次数进行求和，以获得该组件中的不匹配项。 
6. **跨组件的总和不匹配**。 总和是任何允许交换后的最小汉明距离。 

**为什么有效**：在每个连接的组件中，任何排列`source`值是可以实现的。 比较值的计数`source`和`target`在组件内保证我们有效地考虑所有可能的交换。 对齐计数后剩余的任何不匹配对应于无法通过交换纠正的位置。 

## Python 解决方案```python
from collections import defaultdict, Counter
from typing import List

class Solution:
    def minimumHammingDistance(self, source: List[int], target: List[int], allowedSwaps: List[List[int]]) -> int:
        n = len(source)
        
        # Union-Find setup
        parent = list(range(n))
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[py] = px
        
        # Union allowed swaps
        for a, b in allowedSwaps:
            union(a, b)
        
        # Group indices by component
        components = defaultdict(list)
        for i in range(n):
            root = find(i)
            components[root].append(i)
        
        # Count mismatches per component
        result = 0
        for indices in components.values():
            src_count = Counter(source[i] for i in indices)
            tgt_count = Counter(target[i] for i in indices)
            for val in src_count:
                if val in tgt_count:
                    matched = min(src_count[val], tgt_count[val])
                    src_count[val] -= matched
                    tgt_count[val] -= matched
            # Remaining counts in src_count contribute to Hamming distance
            result += sum(src_count.values())
        
        return result
```**实现说明**：我们在中使用路径压缩`find`优化并查。 组件通过将根映射到索引列表的字典进行分组。 计算不匹配项`Counter`确保正确处理重复项。 

## 解决方案```go
package main

func minimumHammingDistance(source []int, target []int, allowedSwaps [][]int) int {
    n := len(source)
    parent := make([]int, n)
    for i := range parent {
        parent[i] = i
    }

    var find func(int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }

    union := func(x, y int) {
        px, py := find(x), find(y)
        if px != py {
            parent[py] = px
        }
    }

    for _, swap := range allowedSwaps {
        union(swap[0], swap[1])
    }

    components := make(map[int][]int)
    for i := 0; i < n; i++ {
        root := find(i)
        components[root] = append(components[root], i)
    }

    result := 0
    for _, indices := range components {
        srcCount := make(map[int]int)
        tgtCount := make(map[int]int)
        for _, idx := range indices {
            srcCount[source[idx]]++
            tgtCount[target[idx]]++
        }
        for val, count := range srcCount {
            if tgtCount[val] > 0 {
                matched := min(count, tgtCount[val])
                srcCount[val] -= matched
            }
        }
        for _, count := range srcCount {
            result += count
        }
    }
    return result
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```**Go 特定说明**：Go 缺乏像 Python 一样的内置计数器，因此我们使用映射。 并查找是通过递归和路径压缩来实现的。 我们小心地处理切片和映射，避免零差异和空差异。 

## 工作示例

 ### 示例 1`source = [1,2,3,4]`,`target = [2,1,4,5]`,`allowedSwaps = [[0,1],[2,3]]`并查组件：

 | 索引 | 根|
 | ---| ---|
 | 0 | 0 |
 | 1 | 0 |
 | 2 | 2 |
 | 3 | 2 |

 成分：`{0: [0,1], 2: [2,3]}`计数：

 - 组件[0,1]：源{1:1,2:1}，目标{2:1,1:1}→全部匹配→0个不匹配
 - 组件 [2,3]：源 {3:1,4:1}，目标 {4:1,5:1} → 源中 3 个不匹配 → 1 个不匹配

 结果：1

 ### 示例 2`source = [1,2,3,4]`,`target = [1,3,2,4]`,`allowedSwaps = []`每个索引都是其自己的组成部分。 比较源[i]与目标[i]：

 - 索引 0: 1==1 → 匹配
 - 索引 1: 2!=3 → 不匹配
 - 索引 2: 3!=2 → 不匹配
 - 索引 3: 4==4 → 匹配

 结果：2

 ### 示例 3`source = [5,1,2,4,3]`,`target = [1,5,4,2,3]`,`allowedSwaps = [[0,4],[4,2],[1,3],[1,4]]`由于交换，所有指数都属于单个连接组件。 计算多重集：

 - 来源计数：{5:1,1:1,2:1,4:1,3:1}
 - 目标计数：{1:1,5:1,4:1,2:1,3:1} → 所有计数匹配 → 0 个不匹配

 结果：0
