[LeetCode 问题 1764](https://leetcode.com/problems/form-array-by-concatenating-subarrays-of-another-array/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、贪婪、字符串匹配

 ## 解决方案

 ## 问题理解

 该问题要求我们确定是否可以从给定数组中选择**不相交的子数组**`nums`使得每个子数组与中的子数组之一完全匹配`groups`数组，按顺序。 子数组是连续的，“不相交”意味着子数组中没有元素`nums`是多个选定子数组的一部分。 顺序约束要求对于每个`i > 0`，对应的子数组`groups[i-1]`必须出现在对应的子数组**之前**`groups[i]`在`nums`。 

输入由两个主要部分组成：`groups`，整数列表的列表，以及`nums`，整数的平面列表。 目标是确定所有组是否可以按顺序匹配而不会重叠。 约束告诉我们`nums`以及所有的总长度`groups`很小（最多 1000 个元素），因此复杂度约为 O(n*m) 的方法是可行的。 重要的边缘情况包括：

 1. 某个组无法匹配，因为它的序列不存在于`nums`。 
2. 组出现的顺序错误`nums`。 
3. 如果使用朴素匹配，则组会重叠。 

## 方法

 **暴力方法**是尝试每个可能的起始索引`nums`对于每个组。 对于每个组，您迭代`nums`并检查从该索引开始的子数组是否与当前组匹配。 找到匹配项后，您将继续从紧随匹配子数组之后的索引开始处理下一组。 这种方法是正确的，但可能效率低下，因为每次检查都可能需要重复扫描组的长度，从而导致潜在的 O(n * m * k) 复杂度，其中`n`是组的数量，`m`的长度是`nums`， 和`k`是组的平均长度。 

**最佳方法**利用**带有子阵列匹配的贪婪线性扫描**。 我们不是测试每个起始索引，而是扫描`nums`顺序并尝试在每个位置匹配当前组。 如果当前元素与组的开头匹配，我们将检查接下来的几个元素是否也与该组完全匹配。 如果是这样，我们将指针移入`nums`越过这个匹配的子数组并继续到下一组。 这保证了顺序和不相交约束，而无需过多的冗余扫描。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m * k) | O(n * m * k) | O(1) | O(1) | 检查每个组的所有可能的起始位置`nums`|
 | 最佳 | O(m * k) | O(1) | O(1) | 依次扫描`nums`，贪婪地匹配每个组而不重叠 |

 ## 算法演练

 1. 初始化一个指针`i`遍历`nums`和一个指针`g`跟踪当前组`groups`。 
2. 虽然`i`小于的长度`nums`和`g`小于组数，则执行以下操作：

 1. 检查子数组是否`nums[i:i+len(groups[g])]`比赛`groups[g]`。 
2. 如果匹配，则移动`i`向前移动的长度为`groups[g]`和增量`g`检查下一组。 
3. 如果不匹配，则递增`i`加 1 以尝试匹配下一个索引处的组。 
3. If all groups (`g == len(groups)`) 已匹配，返回`True`。 
4. 如果结束`nums`在匹配所有组之前到达，返回`False`。 

**为什么它起作用**：该算法保证组按顺序匹配并且不相交，因为一旦匹配了一个组，我们就会移过它的子数组`nums`。 每个组都会在每个有效的起始位置进行尝试，以确保不会错过任何潜在的比赛。 

## Python 解决方案```python
from typing import List

class Solution:
    def canChoose(self, groups: List[List[int]], nums: List[int]) -> bool:
        i = 0  # pointer in nums
        for group in groups:
            found = False
            while i + len(group) <= len(nums):
                if nums[i:i + len(group)] == group:
                    found = True
                    i += len(group)  # move past the matched subarray
                    break
                i += 1  # try next position
            if not found:
                return False
        return True
```此实现迭代每个组并尝试将其匹配`nums`。 它维护一个指针`i`以确保匹配是不相交的。 如果没有找到组，则立即返回`False`。 否则，所有组匹配后，返回`True`。 

## 解决方案```go
func canChoose(groups [][]int, nums []int) bool {
    i := 0
    for _, group := range groups {
        found := false
        for i+len(group) <= len(nums) {
            match := true
            for j := 0; j < len(group); j++ {
                if nums[i+j] != group[j] {
                    match = false
                    break
                }
            }
            if match {
                found = true
                i += len(group)
                break
            }
            i++
        }
        if !found {
            return false
        }
    }
    return true
}
```在 Go 中，我们显式检查每个元素`nums`反对当前组，因为 Go 切片不支持直接切片相等。 否则，逻辑会反映 Python 实现。 

## 工作示例

 **示例1**：`groups = [[1,-1,-1],[3,-2,0]], nums = [1,-1,0,1,-1,-1,3,-2,0]`| 步骤| 我| 组 | nums[i:i+len(组)] | 行动|
 | --- | --- | --- | --- | --- |
 | 1 | 0 | [1,-1,-1] | [1,-1,0]| 不等于，i -> 1 |
 | 2 | 1 | [1,-1,-1] | [-1,0,1]| 不等于，i -> 2 |
 | 3 | 2 | [1,-1,-1] | [0,1,-1]| 不等于，i -> 3 |
 | 4 | 3 | [1,-1,-1] | [1,-1,-1] | 匹配，i -> 6，移至下一组 |
 | 5 | 6 | [3,-2,0] | [3,-2,0] | 匹配，i -> 9，所有组均匹配 |

 返回`True`。 

**示例2**：`groups = [[10,-2],[1,2,3,4]], nums = [1,2,3,4,10,-2]`未找到第一组的匹配序列`[10,-2]`在开始时。 扫描完成后返回`False`。 

**示例3**：`groups = [[1,2,3],[3,4]], nums = [7,7,1,2,3,4,7,7]`第一组`[1,2,3]`比赛开始于`i=2`。 然后`[3,4]`需要重叠在`i=4`（`nums[4:6] = [3,4]`），但算法移动`i`超过第一组，确保不相交。 返回`False`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * k) | 我们扫描`nums`对于每个组和每个位置一次，我们可以比较组的长度。 |
 | 空间| O(1) | O(1) | 仅使用指针和循环变量； 不需要与输入大小成比例的额外空间。 |
