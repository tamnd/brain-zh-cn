 **主题：** 数组、哈希表

 ## 解决方案

 ## 问题理解

 该问题要求我们计算从给定的食物列表中可以形成的**好饭菜**的数量。 一顿美餐的定义是两种不同的食物，其组合的美味程度是**二的幂**。 输入是一个整数数组，`deliciousness`，其中每个元素代表单个食品的美味程度。 输出是此类对的总数模$10^9 + 7$。 

约束表明数组的长度最多可达$10^5$每个美味度值都在 0 到 220 之间。这些约束很重要，因为它们告诉我们，检查每一对的强力解决方案对于大型数组来说可能太慢。 该问题还阐明，具有相同美味但不同指数的两个项目被视为不同的项目，这意味着我们不能跳过重复项。 

重要的边缘情况包括最小尺寸的数组（1 或 2 个元素）、所有元素相同的数组以及美味度为零的数组。 该问题保证非空输入，但不一定是唯一值，因此我们的解决方案必须正确处理重复项。 

## 方法

 **暴力方法**将迭代数组中所有可能的项目对，计算它们的总和，并检查它是否是 2 的幂。 这种方法是正确的，因为它显式地检查每个可能的组合，但它太慢了，因为它有$O(n^2)$时间复杂度，这是令人望而却步的$n = 10^5$。 

**最佳方法**使用**哈希图来计算每个美味值的出现次数**，同时迭代数组。 对于每个项目，我们检查该项目可能形成的两个总和的所有可能幂，并查找到目前为止互补值（总和减去当前值）出现了多少次。 这将时间复杂度降低到大约$O(n \cdot \log C)$， 在哪里$C$是两项的最大可能总和（在这个问题中，至多$2^{22+1} = 2^{23}$），因为每个元素只需要检查大约 22 个 2 的幂。 这种方法为哈希图使用额外的空间，但考虑到问题的限制，它足够有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 检查所有对，对于大 n | 来说太慢
 | 最佳 | O(n * logC) | O(n * logC) | O(n) | 使用哈希映射计算 2 的幂的补数 |

 ## 算法演练

 1. 初始化哈希图`count_map`存储迄今为止遇到的每个美味值的频率。 
2. 初始化变量`result`为零以记录好饭菜的数量。 
3. 预先计算 2 的幂列表，直到最大可能的总和。 由于最大`deliciousness[i]`是 220，最大可能的和是 440，但为了安全起见，请考虑 2 的幂$2^{22}$或略高。 
4. 迭代每个`value`在`deliciousness`大批。 
5. 对于每个`value`，迭代所有预先计算的两个幂`power`。 
6. 计算补码`needed = power - value`。 
7. 如果`needed`存在于哈希映射中，添加`count_map[needed]`到`result`。 这计算了形成的所有有效对`value`作为第二个元素。 
8. 增量`count_map[value]`考虑到未来迭代的当前元素。 
9.处理完所有元素后，返回`result % (10^9 + 7)`。 

**为什么它有效：** 对于每个元素，我们计算所有以前见过的可以与其形成二次幂总和的元素。 这确保我们对每个有效对精确计数一次，并且高效，而无需显式检查每个对。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, deliciousness: List[int]) -> int:
        MOD = 10**9 + 7
        count_map = defaultdict(int)
        result = 0
        # Precompute powers of two up to 2^22 (enough for sums up to 2*2^20)
        powers_of_two = [1 << i for i in range(22)]
        
        for value in deliciousness:
            for power in powers_of_two:
                needed = power - value
                if needed in count_map:
                    result += count_map[needed]
            count_map[value] += 1
            
        return result % MOD
```**实现说明：**我们使用`defaultdict`以避免在检查补集是否存在时出现关键错误。`powers_of_two`存储所有为 2 的有效幂的和。 对于每个美味值，我们检查 2 的所有幂，找到所需的补集，并更新结果。 最后，我们增加哈希映射以包含未来对的当前值。 

## 解决方案```go
func countPairs(deliciousness []int) int {
    const MOD int = 1e9 + 7
    countMap := make(map[int]int)
    result := 0
    powersOfTwo := make([]int, 22)
    
    for i := 0; i < 22; i++ {
        powersOfTwo[i] = 1 << i
    }
    
    for _, value := range deliciousness {
        for _, power := range powersOfTwo {
            needed := power - value
            if count, ok := countMap[needed]; ok {
                result = (result + count) % MOD
            }
        }
        countMap[value]++
    }
    
    return result
}
```**Go 特定注释：** Go 需要使用以下命令显式检查映射键`ok`。 模运算以增量方式应用以避免整数溢出。 逻辑反映了 Python 版本，具有显式数组和映射处理。
