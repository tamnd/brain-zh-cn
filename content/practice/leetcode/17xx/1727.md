[LeetCode 问题 1727](https://leetcode.com/problems/largest-submatrix-with-rearrangements/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序、矩阵

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个二元矩阵，这意味着每个单元格都包含`0`或者`1`。 我们可以按照我们想要的任何顺序重新排列矩阵的列。 对于正在考虑的行配置来说，重新排列是全局的，这意味着我们可以有效地自由排列列，以最大化完全由以下组成的矩形子矩阵的大小`1`s。 

重要的细节是我们不会更改列内的值。 我们只是改变列的顺序。 这意味着垂直连续性`1`每列内的 s 保持不变。 

The goal is to compute the largest possible rectangular area made entirely of`1`优化重新排列列后。 

输入是：

 -`matrix`， 一个`m x n`二元矩阵
 -`m`是行数
 -`n`是列数

 输出是：

 - 子矩阵的最大面积完全由`1`最佳地重新排列列后

 约束条件很重要：

 -`1 <= m * n <= 10^5`这立即告诉我们，所有单元格的二次或三次解可能会太慢。 我们需要一些接近线性或`O(m * n log n)`。 

一种简单的方法可能会尝试每个列排列，但是有`n!`可能的排列，这很快就变得不可能了。 

有几个重要的观察结果和边缘情况：

 - 一行可能包含全零，这没有任何贡献。 
- 矩阵可能包含所有 1，在这种情况下，答案是整个矩阵区域。 
- 单行矩阵简化为计算最大数量`1`重新排列后。 
- 单列矩阵简化为找到最高的连续垂直段`1`s。 
- 最佳矩形可能在任何行结束，不一定是最后一行。 
- 为每行独立地重新排列列可以有效地最大化以该行结尾的矩形，因为只有高度很重要。 

关键的挑战是确定如何在对列重新排序后有效地评估最佳矩形。 

## 方法

 ### 蛮力方法

 蛮力策略将尝试生成不同的列排列，然后计算最大的矩形`1`s 代表每个安排。 

对于每个排列：

 1. 重新排列矩阵列。 
2. 计算最大的全1子矩阵。 
3. 追踪最大面积。 

这是有效的，因为尝试所有排列可以保证我们最终检查最佳排列。 

然而，排列的数量是`n!`，即使对于中等值，这也是一个天文数字`n`。 即使矩形检查是有效的，排列计数也使得这完全不可行。 

另一种强力变体可能会枚举所有可能的子矩阵，并检查某些列重新排列是否可以使它们全部为子矩阵。 这也非常昂贵。 

我们需要更好的洞察力。 

### 关键见解

 关键的观察是，列顺序仅与连续的高度有关`1`s 以当前行结束。 

假设我们对矩阵进行预处理，使每个单元存储连续的高度`1`s 垂直结束于该位置。 

例如：```
Original:
1 0 1
1 1 1
1 0 1

Heights:
1 0 1
2 1 2
3 0 3
```现在考虑一排的高度：```
2 1 2
```如果我们按降序对这些高度进行排序：```
2 2 1
```那么：

 - 使用宽度`1`，高度为`2`，面积=`2`- 使用宽度`2`，高度为`2`，面积=`4`- 使用宽度`3`，高度为`1`，面积=`3`最好的区域是`4`。 

为什么排序有效？ 

因为重新排列列后，我们可以将更高的列彼此相邻放置。 如果排序后的高度是：```
h1 >= h2 >= h3 ...
```然后对于宽度`k`，极限高度为`hk`，给定面积：```
hk * k
```所以对于每一行：

 1. 计算连续高度。 
2. 对行进行降序排序。 
3. 使用每个位置作为最小高度计算最佳矩形。 

这将问题简化为高效的直方图处理。

 ## 算法演练

 1. 创建矩阵的高度表示。 

对于每个单元格，计算连续的数量`1`s 垂直于该行结束。 

如果`matrix[row][col] == 1`:

 - 如果是第一行，则高度为`1`- 否则：```
height[row][col] = height[row - 1][col] + 1
```如果细胞含有`0`，高度变为`0`。 
2. 独立处理每一行。 

现在，每一行代表以该行结束的直方图高度。 
3. 按降序对行进行排序。 

由于我们可以任意重新排列列，因此最好的排列方式是首先放置较高的列。 
4. 计算矩形面积。 

对于每个职位`i`在已排序的行中：

 - 宽度=`i + 1`- 高度=sorted_heights[i]

 面积变为：```
area = height * width
```5. 追踪全局最大面积。 

每当找到更大的矩形时更新答案。 
6. 返回处理完所有行后的最大面积。 

### 为什么它有效

 对于以特定行结束的任何矩形，矩形高度受该矩形中包含的最短列的约束。 

排序高度降序确保当我们取第一个时`k`列，其中最小的高度被最大化。 因此，最佳的矩形宽度`k`总是通过使用获得`k`最高的柱子。 

通过在对每行进行排序后检查每个可能的宽度，我们检查每个最佳候选矩形。 

## Python 解决方案```python
from typing import List

class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        rows = len(matrix)
        cols = len(matrix[0])

        # Build height histogram in-place
        for row in range(1, rows):
            for col in range(cols):
                if matrix[row][col] == 1:
                    matrix[row][col] += matrix[row - 1][col]

        max_area = 0

        for row in matrix:
            sorted_heights = sorted(row, reverse=True)

            for width, height in enumerate(sorted_heights, start=1):
                area = width * height
                max_area = max(max_area, area)

        return max_area
```该实现首先将矩阵转换为垂直高度直方图表示。 输入矩阵会就地更新以节省空间，而不是分配另一个矩阵。 

对于每个包含`1`，我们从上面的行开始累积连续的垂直计数。 细胞含有`0`自然将高度重置为零。 

预处理后，每一行的行为就像一个直方图。 由于列可以自由重新排列，因此我们按降序对每一行进行排序。 这模拟将最高的柱子放在一起。 

循环使用`enumerate(..., start=1)`将当前索引视为矩形宽度。 当前高度成为该宽度的限制高度。 将它们相乘得出候选区域。 

该算法检查每行结束的每个可能的矩形，并保留找到的最大区域。 

## 解决方案```go
package main

import "sort"

func largestSubmatrix(matrix [][]int) int {
	rows := len(matrix)
	cols := len(matrix[0])

	// Build height histogram in-place
	for row := 1; row < rows; row++ {
		for col := 0; col < cols; col++ {
			if matrix[row][col] == 1 {
				matrix[row][col] += matrix[row-1][col]
			}
		}
	}

	maxArea := 0

	for _, row := range matrix {
		heights := make([]int, cols)
		copy(heights, row)

		sort.Sort(sort.Reverse(sort.IntSlice(heights)))

		for width, height := range heights {
			area := (width + 1) * height

			if area > maxArea {
				maxArea = area
			}
		}
	}

	return maxArea
}
```Go 实现遵循与 Python 版本相同的逻辑。 

一个重要的区别是 Go 排序是就地执行的。 由于我们不想在迭代时破坏原始行排序，因此我们首先在排序之前将行复制到单独的切片中。 

Go 切片是有引用支持的，因此复制失败会直接改变原始矩阵行。 

整数溢出在这里不是一个问题，因为最大可能的区域最多是`10^5`，它很容易适合 Go 的内部`int`。

 ## 边缘情况

 一种重要的边缘情况是仅包含零的矩阵。 在这种情况下，每个直方图高度在整个预处理过程中保持为零。 排序后，每个候选矩形区域也为零。 有缺陷的实现可能会意外地假设至少存在一个有效矩形，但该解决方案自然会返回零，因为所有计算区域仍然为零。 

另一个重要的边缘情况是单行矩阵。 由于没有垂直累积，该算法实际上变成了对所有数据进行分组的问题`1`通过列重新排列组合在一起。 正确排序行将所有`1`首先，允许算法直接计算最大连续宽度。 

第三个关键边缘情况是单列矩阵。 由于当仅存在一列时，列重新排列不起作用，因此该算法仍必须正确计算垂直连续高度。 直方图累积步骤通过计算连续的数据来自然地处理这个问题`1`s向下。 

当不同的列具有不同的高度时，会出现微妙的边缘情况。 例如：```
[3,1,2]
```如果在面积计算之前未对行进行排序，我们可能会错误地低估最佳矩形。 排序可确保最高的列首先分组，从而最大化每个宽度的最小高度。 

另一个棘手的情况涉及零中断累积的行。 每当一个单元格包含`0`，其高度必须重置为零，而不是从上方继续累积。 该实现可以正确处理此问题，因为只有当当前单元格等于时高度才会增加`1`。
