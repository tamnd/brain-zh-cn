[LeetCode 第 425 题](https://leetcode.com/problems/word-squares/)

 **难度：** 🔴难
 **主题：** 数组、字符串、回溯、Trie

 ## 解决方案

 ## 问题理解

 问题是要求我们从给定的唯一单词列表中生成所有可能的**单词方块**。 单词方块是单词的方形排列，使得位于行的单词`i`与列中的单词相同`i`对于每一个`i`。 换句话说，跨行和向下读取列会产生相同的字符串集。 

输入是字符串列表`words`其中所有单词的长度相同并且仅包含小写字母。 输出是一个列表列表，其中每个内部列表代表一个有效的单词方块。 即使原始列表包含唯一的单词，单词也可能在一个方块中出现多次。 

主要限制因素包括：

 -`words.length`最多为 1000，因此暴力生成所有排列会太慢。 
-`words[i].length`最大为 4，意味着每个方块最多为 4x4。 
- 所有单词都是唯一的，简化了查找和索引。 
- 每个单词仅包含小写字母。 

重要的边缘情况包括：

 - 非常小的单词列表，例如形成 1x1 正方形的单个单词。 
- 具有重叠前缀的单词，可能允许多个有效方块。 
- 长度为 1 的单词，它们本身很容易形成正方形。 

## 方法

 ### 蛮力

 暴力方法生成所有可能的长度单词序列`n`（在哪里`n`是每个单词的长度）并检查每个序列是否形成有效的单词方块。 对于每个候选序列，我们按行和列比较字符。 如果所有位置都匹配，则序列有效。 

这种方法是正确的，因为它考虑了每个组合，确保没有遗漏任何方块。 然而，它太慢了，因为`m`长度的单词`n`， 有`O(m^n)`可能的序列。 即使有小`n`,`m^n`增长速度很快并且不可行`m = 1000`。 

### 最佳方法

 关键的见解是**有效的单词方块是由其前缀定义的**。 对于当前部分构造的方块，下一个单词必须与前面的单词形成的列前缀匹配。 例如，如果我们有：```
ball
area
```第三行下一个单词的前缀是`"le"`因为它必须与前一行形成的第三列的前两个字母匹配。 

为了有效地查找具有给定前缀的单词，我们可以使用**Trie**（前缀树）或**单词前缀的哈希图**。 然后，我们执行**回溯**，尝试与所需前缀匹配的每个候选单词，并递归地构建正方形，直到达到长度`n`。 

与暴力方法相比，这大大减少了搜索空间，因为我们只考虑与当前前缀匹配的单词而不是所有单词。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m^n * n^2) | O(m^n * n^2) | O(n) | 生成所有序列，检查每个方块 |
 | 最佳 | O(n * m * 4^n) | O(m * n^2) | O(m * n^2) | 使用前缀查找+回溯来修剪无效序列 |

 ## 算法演练

 1. 计算所有可能的**前缀到单词的映射**。 对于每个单词和每个可能的前缀（从长度 1 到 n-1），存储以该前缀开头的单词列表。 这允许在回溯期间进行 O(1) 前缀查找。 
2.初始化一个空列表`square`这将存储当前正在构建的单词方块。 
3.定义一个递归**回溯函数**：

 1.如果`square`包含`n`一句话，就完整了。 添加副本`square`到结果并返回。 
2. 确定下一个单词的前缀`i-th`每个现有单词的字符，其中`i`是当前深度。 
3. 使用前缀映射查找与此前缀匹配的所有候选词。 
4. 对于每个候选词，将其附加到`square`并递归调用该函数。 
5. 递归后，将单词从`square`（回溯）。 
4. 迭代输入列表中的每个单词，并以该单词作为第一行开始回溯过程。 

**为什么它有效**：

 前缀属性确保添加到方块中的每个单词都保持单词方块不变性。 通过递归探索所有候选者并在必要时回溯，该算法探索所有有效配置，而不会在不可能的序列上浪费时间。 

## Python 解决方案```python
from typing import List, Dict
from collections import defaultdict

class Solution:
    def wordSquares(self, words: List[str]) -> List[List[str]]:
        if not words:
            return []
        
        n = len(words[0])
        prefix_map: Dict[str, List[str]] = defaultdict(list)
        
        # Build prefix map
        for word in words:
            for i in range(1, n):
                prefix_map[word[:i]].append(word)
        
        results: List[List[str]] = []
        
        def backtrack(square: List[str]):
            if len(square) == n:
                results.append(square[:])
                return
            
            # Build prefix for the next row
            prefix = ''.join(word[len(square)] for word in square)
            
            for candidate in prefix_map.get(prefix, []):
                square.append(candidate)
                backtrack(square)
                square.pop()
        
        for word in words:
            backtrack([word])
        
        return results
```该实现首先构造一个`prefix_map`用于快速查找。 这`backtrack`函数增量构建每个方块，确保下一个单词与列前缀匹配。 回溯保证了所有有效的方格都被有效地探索。 

## 解决方案```go
package main

func wordSquares(words []string) [][]string {
    if len(words) == 0 {
        return nil
    }
    
    n := len(words[0])
    prefixMap := make(map[string][]string)
    
    // Build prefix map
    for _, word := range words {
        for i := 1; i < n; i++ {
            prefix := word[:i]
            prefixMap[prefix] = append(prefixMap[prefix], word)
        }
    }
    
    var results [][]string
    var square []string
    
    var backtrack func()
    backtrack = func() {
        if len(square) == n {
            tmp := make([]string, n)
            copy(tmp, square)
            results = append(results, tmp)
            return
        }
        
        prefix := ""
        for _, w := range square {
            prefix += string(w[len(square)])
        }
        
        for _, candidate := range prefixMap[prefix] {
            square = append(square, candidate)
            backtrack()
            square = square[:len(square)-1]
        }
    }
    
    for _, word := range words {
        square = []string{word}
        backtrack()
    }
    
    return results
}
```Go 特定注意事项：附加完整正方形时需要进行切片复制，以避免在递归期间修改它。 Go 中的字符串是不可变的，因此构建前缀需要连接。 Nil 切片通过附加自动处理。 

## 工作示例

 ### 示例 1

 输入：`["area","lead","wall","lady","ball"]`1. 构建前缀映射：```
"a": ["area"]
"ar": ["area"]
"l": ["lead","lady"]
"le": ["lead"]
"w": ["wall"]
"wa": ["wall"]
"b": ["ball"]
"ba": ["ball"]
```1. 开始于`"ball"`, 正方形 = ["球"]
 2. 第二行的前缀=“a”→候选项：[“area”]
 3. 正方形 = ["球","面积"]
 4. 第三行的前缀=“le”→候选项：[“lead”]
 5. Square = ["球","面积","领先"]
 6. 第 4 行前缀=“lady”→候选：[“lady”]
 7. Square = ["ball","area","lead","lady"] → 完成

 重复开始于`"wall"`→ 产生第二个正方形。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * m * 4^n) | 回溯在 n 个级别中每个级别最多探索 4 个候选者，对每个起始单词重复。 |
 | 空间| O(m * n^2) | O(m * n^2) | 前缀映射存储所有前缀，递归堆栈每个路径最多存储 n 个单词。 |

 尽管最坏的情况可能呈指数级增长`n`， 小的`n <= 4`保持其可行性。
