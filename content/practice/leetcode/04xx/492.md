 ## 解决方案

 ## 问题理解

 这个问题给了我们一个整数，`area`，它表示矩形的面积。 我们的任务是找到两个整数：

 -`L`, 长度
 -`W`，宽度

 这样：

 1.`L * W == area`2.`L >= W`3.`L - W`尽可能小

 换句话说，在所有有效因子对中`area`，我们想要最接近的一对。 

例如，如果`area = 36`，可能的因子对是：

 -`(36, 1)`-`(18, 2)`-`(12, 3)`-`(9, 4)`-`(6, 6)`这对`(6, 6)`两个值之间的差异最小，因此它是最佳答案。 

输入是介于之间的单个正整数`1`和`10^7`。 这个上限很重要，因为它告诉我们，一种简单的方法可以检查每个可能的数字`area`理论上仍然可行，但有更有效的数学观察可用。 

预期输出是一个数组`[L, W]`包含按该顺序选择的尺寸。 

一些边缘情况很重要：

 - 当`area`是一个完美的正方形，最佳矩形本身就是一个正方形。 
- 什么时候`area`是素数，唯一有效的维度是`[area, 1]`。 
- 什么时候`area = 1`，答案是`[1, 1]`。 

该问题保证输入始终是正整数，因此我们不需要处理无效或负值。 

## 方法

 ### 蛮力方法

 最直接的解决方案是检查每个可能的宽度`1`最多`area`。 

对于每个候选宽度`W`：

 - 检查是否`area % W == 0`- 如果均匀划分，则计算`L = area // W`- 确保`L >= W`- 追踪差异最小的一对

 这种方法是正确的，因为它评估每个可能的因素对，因此不会错过最佳答案。 

然而，它的效率很低，因为它可能执行最多`area`迭代。 自从`area`可以大到`10^7`，这会变得不必要的昂贵。 

### 最佳解决方案的关键见解

 重要的数学观察是，差异最小的因子对始终是最接近数字平方根的对。 

考虑一个具有面积的矩形`A`。 

如果：$$L \times W = A$$那么：

 - 当`W`很小，`L`变得很大
 - 作为`W`方法`sqrt(A)`，两个值变得更接近

 因此，与其搜索`1`向上，我们可以从：$$\lfloor \sqrt{A} \rfloor$$并向下移动，直到找到第一个除数。 

我们遇到的第一个除数立即给出了最佳对，因为它是最接近平方根的因子。 

例如，与`area = 122122`：$$\sqrt{122122} \approx 349$$我们开始向下检查`349`直到我们找到除数：

 -`286`均匀分配
 -`122122 / 286 = 427`所以答案是`[427, 286]`。 

这降低了时间复杂度`O(area)`到`O(sqrt(area))`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(面积) | O(1) | O(1) | 检查每个可能的除数 |
 | 最佳 | O(sqrt(面积)) | O(1) | O(1) | 从平方根附近开始并找到最接近的因子对 |

 ## 算法演练

 1. 计算整数平方根`area`。 

平方根表示矩形尺寸最接近的点。 从这里开始可以最大限度地提高快速找到最佳因子对的机会。 
2. 从平方根向下迭代至`1`。 

对于每个候选宽度`W`，检查是否`area % W == 0`。 
3. 找到除数后，计算：$$L = \frac{area}{W}$$由于我们是从平方根向下搜索，因此这是差异最小的因子对。 
4. 返回`[L, W]`。 

该问题保证至少有一个有效的对，因为每个正整数都可以被整除`1`。 

### 为什么它有效

 该算法依赖于这样一个事实：当我们远离平方根时，因子对之间的距离会变得更远。 通过从平方根开始向下搜索，找到的第一个除数必然会产生最接近的因子对。 自从`L * W = area`和`W <= sqrt(area) <= L`，返回的对满足所有问题要求。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def constructRectangle(self, area: int) -> List[int]:
        width = int(math.sqrt(area))

        while area % width != 0:
            width -= 1

        length = area // width

        return [length, width]
```该实现首先计算以下的整数平方根`area`。 这给出了可能产生最小尺寸差异的最大候选宽度。 

这`while`循环向下移动，直到找到除数`area`。 因为我们从平方根向下搜索，所以第一个有效除数自动是最佳宽度。 

找到宽度后，使用整数除法计算相应的长度。 该方法最终返回`[length, width]`。 

该解决方案使用恒定的额外空间并且最多执行`sqrt(area)`迭代。 

## 解决方案```go
package main

import "math"

func constructRectangle(area int) []int {
	width := int(math.Sqrt(float64(area)))

	for area%width != 0 {
		width--
	}

	length := area / width

	return []int{length, width}
}
```Go 实现遵循与 Python 版本相同的逻辑。 主要区别在于 Go 的`math.Sqrt`函数运行于`float64`，所以我们在求平方根之前先转换整数，然后将结果转换回`int`。 

结果以整数切片的形式返回，使用`[]int{length, width}`。 

因为输入约束只有`10^7`，整数溢出不是 Go 标准中的问题`int`类型。

 ## 边缘情况

 ### 完全平方输入

 当面积是完全正方形时，最佳矩形本身就是正方形。 有缺陷的实现可能会继续不必要的搜索或返回相反的维度。 

例如：```
area = 36
```该算法开始于`sqrt(36) = 6`，立即找到除数，并返回`[6, 6]`。 

### 质数

 素数只有两个约数：`1`和他们自己。 幼稚的实现可能会错误地假设存在更大的因子对。 

例如：```
area = 37
```该算法向下检查`6`直到达到`1`，生产`[37, 1]`，这是唯一有效的矩形。 

### 最小输入值

 允许的最小输入是：```
area = 1
```一些实现在这里失败，因为它们假设宽度搜索至少从`2`。 

该解决方案正确计算：$$\sqrt{1} = 1$$自从`1 % 1 == 0`，它立即返回`[1, 1]`。
