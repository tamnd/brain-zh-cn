 **难度：** 🟡 中等

 ## 解决方案

 ## 问题理解

 该问题要求我们为二叉搜索树（Binary Search Tree，缩写为 BST）设计两个操作：

 -`serialize(root)`将 BST 转换为字符串表示形式。 
-`deserialize(data)`从该字符串重建完全相同的 BST。 

重要的要求是反序列化的树必须与原始树结构和节点值匹配。 格式本身完全由我们决定，这意味着我们可以选择任何编码策略，只要它是可逆的。 

二叉搜索树有一个关键属性：

 - 左子树中的每个节点的值都小于当前节点。 
- 右子树中的每个节点的值都大于当前节点。 

此属性是允许我们创建紧凑序列化格式的关键观察结果。 

输入是 BST 的根节点。 序列化的输出是一个字符串。 反序列化的输出是重建的根节点。 

这些约束告诉我们一些重要的事情：

 - 树最多可以包含`10^4`节点，因此算法必须高效。 
- 节点值介于`0`和`10^4`。 
- 该树保证是有效的 BST，这使我们能够在重建过程中利用 BST 排序规则。 

简单的序列化格式可能包括显式的`null`失踪儿童的标记。 虽然这适用于任何二叉树，但它浪费了空间，因为 BST 结构已经可以从遍历顺序推断出来。 

重要的边缘情况包括：

 - 空树，其中序列化应生成空字符串，反序列化应返回`None`。 
- 一棵只有一个节点的树。 
- 完全倾斜的 BST，其中所有节点仅向左或仅向右。 这会产生递归深度问题和最坏情况的递归堆栈使用。 
- 具有多个级别的树，重建逻辑必须正确维护 BST 边界。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是将 BST 视为普通二叉树，并使用显式的层序遍历或先序遍历对其进行序列化`null`标记。 

例如，预购序列化可能如下所示：```
2,1,null,null,3,null,null
```在反序列化过程中，我们通过一一读取值来递归地重建树。 每当我们遇到`null`，我们返回一个空的孩子。 

这种方法可以正常工作，因为每个节点和每个丢失的子节点都经过显式编码，使得重建变得明确。 

然而，该解决方案空间利用率不高。 BST 已经包含排序信息，可以帮助重建结构而不存储空占位符。 包含空标记会显着增加序列化大小，尤其是对于稀疏树。 

### 最佳方法

 关键的见解是 BST 可以仅根据其先序遍历来唯一地重建。 

在前序遍历中：

 1.访问根目录
 2. 遍历左子树
 3. 遍历右子树

 由于 BST 节点遵循排序约束，因此我们可以确定左子树的结束位置和右子树的开始位置，而无需存储空标记。 

例如：```
      8
     / \
    5   10
   / \    \
  1   7    12
```前序遍历变为：```
8,5,1,7,10,12
```反序列化期间：

 - 第一个值始终是根。 
- 任何小于根的以下值都属于左子树。 
- 任何大于根的后续值都属于右子树。 
- 递归值界限使我们能够有效地重建树。 

这会产生紧凑的序列化，同时保持线性时间复杂度。

 ## 算法演练

 ### 序列化

 1. 对 BST 进行前序遍历。 

前序遍历按顺序访问节点：

 - 根
 - 左子树
 - 右子树

 这种遍历很重要，因为第一个元素始终标识子树根。 
2. 将每个节点值附加到字符串列表中。 

我们完全避免空标记，因为 BST 排序规则足以进行重建。 
3. 使用逗号连接所有值。 

最终的序列化字符串是紧凑的，因为它只存储实际的节点值。 

### 反序列化

 1. 用逗号分割序列化字符串。 

这重建了前序遍历序列。 
2. 维护共享索引指针。 

指针跟踪我们当前正在处理的值。 
3. 在重建过程中使用递归边界。 

每个递归调用都会收到：

 - 下限
 - 上限

 这些边界定义当前子树中节点的有效范围。 
4. 读取当前预购值。 

如果该值超出了允许的范围，则它不属于当前子树，因此返回`None`。 
5. 创建当前节点。 

增加预购索引，因为该值现已被消耗。 
6. 递归构建左子树。 

左子树必须包含值：```
lower < value < current node value
```7. 递归构建右子树。 

右子树必须包含值：```
current node value < value < upper
```8. 返回构造好的节点。 

### 为什么它有效

 前序遍历保证每个子树根出现在该子树中的所有节点之前。 BST 排序属性保证每个节点都属于唯一的数值范围。 将预序顺序与递归边界相结合可确保每个节点都在正确的位置重建。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

from typing import Optional
import math

class Codec:

    def serialize(self, root: Optional[TreeNode]) -> str:
        """Encodes a tree to a single string."""
        
        preorder_values = []

        def preorder(node: Optional[TreeNode]) -> None:
            if not node:
                return

            preorder_values.append(str(node.val))
            preorder(node.left)
            preorder(node.right)

        preorder(root)

        return ",".join(preorder_values)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        """Decodes your encoded data to tree."""
        
        if not data:
            return None

        preorder_values = list(map(int, data.split(",")))
        index = 0

        def build(lower: int, upper: int) -> Optional[TreeNode]:
            nonlocal index

            if index >= len(preorder_values):
                return None

            value = preorder_values[index]

            if value < lower or value > upper:
                return None

            index += 1

            node = TreeNode(value)

            node.left = build(lower, value)
            node.right = build(value, upper)

            return node

        return build(-math.inf, math.inf)

# Your Codec object will be instantiated and called as such:
# ser = Codec()
# deser = Codec()
# tree = ser.serialize(root)
# ans = deser.deserialize(tree)
# return ans
```序列化方法执行前序DFS遍历并按遍历顺序记录节点值。 因为前序总是先访问根，所以自然支持后面的递归重建。 

反序列化方法将字符串转换回整数，并使用递归边界重建 BST。 这`index`变量跟踪当前正在处理的预购元素。 每个递归调用都会验证当前值是否属于允许的 BST 范围内。 

下限和上限自动强制 BST 正确性。 如果一个值超出了有效范围，则它属于不同的子树，因此递归停止。 

这种方法完全避免了空标记，从而使序列化表示变得紧凑。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

import (
	"math"
	"strconv"
	"strings"
)

type Codec struct {
	
}

func Constructor() Codec {
	return Codec{}
}

// Serializes a tree to a single string.
func (this *Codec) serialize(root *TreeNode) string {
	values := []string{}

	var preorder func(node *TreeNode)

	preorder = func(node *TreeNode) {
		if node == nil {
			return
		}

		values = append(values, strconv.Itoa(node.Val))

		preorder(node.Left)
		preorder(node.Right)
	}

	preorder(root)

	return strings.Join(values, ",")
}

// Deserializes your encoded data to tree.
func (this *Codec) deserialize(data string) *TreeNode {
	if data == "" {
		return nil
	}

	parts := strings.Split(data, ",")
	preorderValues := make([]int, len(parts))

	for i, part := range parts {
		value, _ := strconv.Atoi(part)
		preorderValues[i] = value
	}

	index := 0

	var build func(lower int, upper int) *TreeNode

	build = func(lower int, upper int) *TreeNode {
		if index >= len(preorderValues) {
			return nil
		}

		value := preorderValues[index]

		if value < lower || value > upper {
			return nil
		}

		index++

		node := &TreeNode{Val: value}

		node.Left = build(lower, value)
		node.Right = build(value, upper)

		return node
	}

	return build(math.MinInt, math.MaxInt)
}

/**
 * Your Codec object will be instantiated and called as such:
 * ser := Constructor()
 * deser := Constructor()
 * tree := ser.serialize(root)
 * ans := deser.deserialize(tree)
 * return ans
 */
```Go 实现遵循与 Python 版本相同的算法结构。 主要差异是特定于语言的。 

Go 使用切片而不是 Python 列表，并且需要使用显式字符串到整数转换`strconv.Atoi`。 Nil 指针表示为`nil`而不是`None`。 

递归辅助函数捕获共享`index`通过闭包语义传递变量，类似于Python`nonlocal`。

 ## 边缘情况

 ### 空树

 空 BST 是最常见的错误来源之一，因为序列化可能会意外地产生无效的分隔符，或者反序列化可能会尝试解析空输入。 

该实现显式地处理这种情况。 序列化返回空字符串，反序列化立即返回`None`当给定空数据时。 

### 完全倾斜的树

 BST 可以完全左偏或右偏，表现得像链表。 这会产生最坏情况的递归深度。 

例如：```
5
 \
  6
   \
    7
```该实现仍然可以正常工作，因为前序遍历自然地保留了插入顺序，并且递归边界正确地限制了子树的放置。 

尽管递归堆栈深度变为，复杂性仍然是线性的`O(n)`。 

### 边界值

 该问题允许节点值来自`0`到`10^4`。 边界处理很重要，因为不正确的比较可能会意外拒绝有效节点。 

该实现在 Python 中使用负无穷大和正无穷大`math.MinInt`和`math.MaxInt`在 Go 中确保所有有效节点值安全地适合初始边界。 

这保证了即使是允许的最小和最大节点值也能正确反序列化。
