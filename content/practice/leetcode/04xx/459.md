[LeetCode 第 459 题](https://leetcode.com/problems/repeated-substring-pattern/)

 **难度：** 🟢简单
 **主题：** 字符串、字符串匹配

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的字符串是否可以通过多次重复其子字符串之一来形成。 

换句话说，我们想知道是否存在某种子字符串模式，以便重复连接该模式可以精确地重新创建整个字符串。 

例如，考虑字符串`"abab"`:

 - 子串`"ab"`重复两次就变成`"abab"`- 因此，答案是`true`现在考虑`"aba"`:

 - 可能的子串是`"a"`和`"ab"`- 重复`"a"`给出`"aaa"`- 重复`"ab"`给出`"abab"`- 都不匹配`"aba"`- 因此，答案是`false`输入是单个字符串`s`仅包含小写英文字母。 最大长度为`10^4`，它足够小，足以使二次解在技术上通过，但首选高效的线性或近线性方法。 

一个重要的细节是重复的子字符串必须出现多次。 整个字符串本身不算重复单元，除非它出现多次。 

一些边缘情况很重要：

 - 单个字符串永远无法满足条件，因为没有更小的子字符串可以重复。 
- 包含所有相同字符的字符串，例如`"aaaa"`，应该返回`true`。 
- 长度为质数的字符串通常会减少有效子字符串长度的数量。 
- 几乎重复的字符串，例如`"abababa"`，如果不仔细处理部分匹配，可能会欺骗幼稚的实现。 

## 方法

 ### 蛮力方法

 蛮力的想法是尝试每一个可能的子字符串长度，以均匀地划分整个字符串长度。 

假设字符串长度为`n`。 如果一个子串的长度`k`通过重复形成整个字符串，然后：

 -`k`必须划分`n`- 候选子串是`s[:k]`- 重复该子字符串`n // k`时间应该等于`s`对于每个有效长度：

 1.提取候选子串
 2.重复足够多次
 3. 与原字符串比较

 如果有候选人工作，请返回`true`。 否则，返回`false`。 

这是有效的，因为每个可能的重复单元都经过明确测试。 但是，它会重复构造字符串并执行比较，从而降低了效率。 

### 最佳方法

 关键的观察基于巧妙的字符串属性。 

如果一个字符串由重复的模式组成，那么它将出现在由以下方式形成的字符串内部：```
(s + s)[1:-1]
```为什么这有效？ 

如果原始字符串重复较小的模式，则通过删除第一个和最后一个字符来移动双倍字符串仍会在内部留下原始字符串的另一个匹配项。 

例如：```
s = "abab"

s + s = "abababab"

Remove first and last:
"bababa"

"abab" exists inside "bababa"
```现在考虑一个不重复的字符串：```
s = "aba"

s + s = "abaaba"

Remove first and last:
"baab"

"aba" does not exist inside "baab"
```这提供了使用子字符串搜索的简洁而优雅的解决方案。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 尝试每个可能的子字符串长度 |
 | 最佳| 平均 O(n)，最坏情况 O(n²) | O(n) | 使用双字符串模式属性 |

 ## 算法演练

 1. 设输入字符串为`s`。 
2. 通过将字符串与其自身连接来构造一个新字符串。```
doubled = s + s
```这会创建原始字符串的所有可能的循环移位。 
3. 删除双倍字符串中的第一个和最后一个字符。```
trimmed = doubled[1:-1]
```此步骤可防止原始字符串在开头或结尾处简单地匹配自身。 
4.检查是否是原字符串`s`存在于里面`trimmed`。```
s in trimmed
```5. 如果子串存在，则返回`true`。 

这意味着字符串具有内部重复结构。 
6.否则返回`false`。 

### 为什么它有效

 假设字符串是通过重复子字符串模式构建的。 

例如：```
s = "abcabc"
```当我们将字符串与其自身连接时：```
"abcabcabcabc"
```重复的结构导致原始字符串的移位副本出现在内部。 删除第一个和最后一个字符仍然会使这些移动的副本中的一个完好无损。 

如果字符串不具有重复结构，则修剪后不存在完整字符串的内部出现。 

该属性保证了正确性。 

## Python 解决方案```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        doubled = s + s
        trimmed = doubled[1:-1]
        
        return s in trimmed
```实施直接遵循最佳观察。 

首先，使用复制字符串`s + s`。 这将创建一个更大的字符串，其中包含原始模式的所有循环移位。 

接下来，删除第一个和最后一个字符。 如果没有这一步，每个字符串都会简单地出现在其自己的双倍版本中。 

最后，Python 的子字符串搜索运算符检查原始字符串是否存在于修剪结果中。 

如果是，则该字符串必须由重复的子字符串模式组成。 

## 解决方案```go
package main

import "strings"

func repeatedSubstringPattern(s string) bool {
    doubled := s + s
    trimmed := doubled[1 : len(doubled)-1]

    return strings.Contains(trimmed, s)
}
```Go 实现密切反映了 Python 逻辑。 

主要区别在于 Go 使用`strings.Contains`函数而不是Python的`in`操作员。 

Go 中的字符串切片使用索引范围，因此：```go
doubled[1 : len(doubled)-1]
```删除第一个和最后一个字符。 

由于输入大小很小，因此不存在溢出问题。 Go 字符串是不可变的，就像 Python 字符串一样。

 ## 边缘情况

 ### 单字符串

 有长度的字符串`1`不可能通过多次重复较小的子串来形成。 这是错误的常见来源，因为某些实现意外地允许完整字符串本身作为有效的重复单元。 

例如：```
"a"
```算法正确返回`false`因为`"a"`里面没有出现：```
("a" + "a")[1:-1]
```它变成一个空字符串。 

### 具有所有相同字符的字符串

 字符串像`"aaaaaa"`可以使用多个不同的子串大小来形成：

 -`"a"`重复6次
 -`"aa"`重复3次
 -`"aaa"`重复2次

 一些幼稚的实现在仅检查一种候选大小后错误地停止。 双字符串方法自然可以同时处理所有可能性。 

### 部分重复

 字符串如`"abababa"`看起来重复，但并不是较小子串的精确重复。 

这很重要，因为幼稚的实现有时只比较前缀，而不确保均匀地覆盖整个字符串。 

该算法避免了此问题，因为修剪后的双字符串内的包含仅发生在完全可重复的结构中。
