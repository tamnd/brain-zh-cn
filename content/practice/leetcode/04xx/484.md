 **难度：** 🟡 中等
 **主题：** 数组、字符串、堆栈、贪婪

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅由字符组成`'I'`和`'D'`。 该字符串描述隐藏排列中相邻数字之间的关系。 

如果`s[i] == 'I'`，那么排列必须满足：```
perm[i] < perm[i + 1]
```如果`s[i] == 'D'`，那么排列必须满足：```
perm[i] > perm[i + 1]
```由于字符串有长度`n - 1`，结果排列必须恰好包含`n`数字，特别是来自的所有整数`1`到`n`无需重复。 

任务不仅仅是找到任何有效的排列。 我们必须返回字典顺序最小的有效排列。 

词典顺序的工作原理与词典顺序类似。 比较两个数组时，我们从左到右比较元素。 第一个较小的元素决定较小的排列。 例如：```
[2,1,3] < [3,1,2]
```因为`2 < 3`在第一位置。 

约束条件很重要：```
1 <= s.length <= 100000
```这意味着解决方案必须高效。 任何阶乘或指数方法都是不可能的，因为排列增长得非常快。 甚至一个`O(n^2)`对于上限来说，解决方案可能会变得有风险。 一个`O(n)`解决方案是理想的。 

有几个重要的边缘情况需要考虑：

 - 一个字符串只包含`'I'`， 例如`"III"`，应该产生自然递增的排列`[1,2,3,4]`。 
- 一个字符串只包含`'D'`， 例如`"DDD"`，应该产生递减排列`[4,3,2,1]`。 
- 交替模式，例如`"DIDID"`可以暴露订购错误。 
- 长时间连续`'D'`序列特别重要，因为它们需要反转局部范围以保持字典编序的最小性。 
- 输入保证只包含`'I'`和`'D'`，所以我们不需要处理无效字符。 

## 方法

 ### 蛮力方法

 蛮力解决方案将生成所有可能的数字排列`1`到`n`，然后检查每个排列是否与描述的模式匹配`s`。 

对于每个排列：

 - 比较相邻元素。 
- 验证每对是否满足相应的`'I'`或者`'D'`健康）状况。 
- 在所有有效排列中，返回字典顺序最小的排列。 

这种方法是正确的，因为它详尽地检查了所有可能性。 然而，这是完全不切实际的。 

如果字符串长度为`n - 1`，那么有`n!`可能的排列。 即使对于相对较小的值，例如`n = 12`，排列的数量变得巨大。 

因为约束允许最多`100000`人物，暴力是不可能的。 

### 最优贪心法

 关键的观察是，词典编纂的最小性意味着我们应该尽早放置尽可能小的数字。 

如果我们最初按升序写数字：```
1, 2, 3, 4, 5, ...
```然后所有`'I'`条件已经自动满足。 

唯一的挑战来自连续`'D'`段。 

例如：```
s = "DDI"
```递增序列为：```
1 2 3 4
```但前两个关系一定是递减的：```
? > ? > ?
```为了满足这一点，同时保持排列在字典顺序上尽可能小，我们仅反转最小的必要片段。 

将前三个数字反转即可得到：```
3 2 1 4
```这是最小的有效排列。 

贪心的核心见解是：

 - 从数字开始`1`通过`n`。 
- 每当我们遇到连续的块时`'D'`，反转排列中相应的段。 
- 仅反转所需的精确范围，不能更大。 

这会在线性时间内产生字典顺序最小的有效排列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! × n) | O(n! × n) | O(n) | 生成每个排列并验证每个排列 |
 | 最优贪心 | O(n) | O(n) | 反转对应于连续的段`'D'`运行|

 ## 算法演练

 ### 最优贪心算法

 1. 创建一个包含以下数字的初始排列`1`到`n`， 在哪里`n = len(s) + 1`。 

例如，如果：```
s = "DIID"
```然后初始化：```
perm = [1,2,3,4,5]
```在应用约束之前，这种排列在字典顺序上已经是最小的。 
2. 从左到右遍历字符串。 

在每个位置，检查当前字符是否是`'D'`。 
3. 当`'D'`找到后，标记递减段的开始。 

继续前进，同时保留连续字符`'D'`。 

例如：```
s = "IDDDI"
```子串`"DDD"`forms one decreasing block.
 4. Reverse the corresponding range in the permutation.

 假设`'D'`块从索引开始`start`并以索引结束`end`。 

然后反转：```
perm[start : end + 2]
```额外的`+1`是必要的，因为关系连接相邻的数字，意味着一个长度块`k`影响`k + 1`数字。 
5. 在反向段后继续扫描。 
6. 处理整个字符串后，返回结果排列。 

### 为什么它有效

 该算法在最早的位置保留尽可能小的数字。 最初使用递增顺序可以保证全局的最小字典顺序。 

每当需要递减关系时，仅反转最小必要的连续范围即可准确创建所需的递减结构，同时尽可能少地干扰数组。 

任何较大的修改都会将不必要的较大数字放在排列的前面，从而使结果按字典顺序更大。 

因此，该算法始终构造字典顺序上最小的有效排列。 

## Python 解决方案```python
from typing import List

class Solution:
    def findPermutation(self, s: str) -> List[int]:
        n = len(s) + 1
        
        # Start with the lexicographically smallest arrangement
        perm = list(range(1, n + 1))
        
        i = 0
        
        while i < len(s):
            if s[i] == 'D':
                start = i
                
                # Find the entire consecutive D segment
                while i < len(s) and s[i] == 'D':
                    i += 1
                
                # Reverse the affected range
                perm[start:i + 1] = reversed(perm[start:i + 1])
            else:
                i += 1
        
        return perm
```实现从构造递增序列开始`[1,2,3,...,n]`。 这保证了尽可能最小的词典起点。 

变量`i`扫描模式字符串。 

每当算法遇到`'I'`，不必做任何改变，因为当前的增加安排已经满足条件。 

当一个`'D'`遇到时，算法使用记录递减块的开头`start`。 然后它前进直到整个连续的`'D'`序列已经确定。 

定位完整段后，排列的相应部分被反转。 这将局部递增顺序转换为递减顺序，同时保持排列的其余部分不变。 

Python 切片使反转变得简洁：```python
perm[start:i + 1] = reversed(perm[start:i + 1])
```范围包括`i + 1`因为一块`k`关系涉及`k + 1`数字。 

最后，返回完成的排列。 

## 解决方案```go
func findPermutation(s string) []int {
	n := len(s) + 1

	// Start with increasing order
	perm := make([]int, n)
	for i := 0; i < n; i++ {
		perm[i] = i + 1
	}

	i := 0

	for i < len(s) {
		if s[i] == 'D' {
			start := i

			// Find the full consecutive D segment
			for i < len(s) && s[i] == 'D' {
				i++
			}

			// Reverse the affected range
			reverse(perm, start, i)
		} else {
			i++
		}
	}

	return perm
}

func reverse(arr []int, left int, right int) {
	for left < right {
		arr[left], arr[right] = arr[right], arr[left]
		left++
		right--
	}
}
```Go 实现遵循与 Python 版本相同的逻辑，但手动执行反转，因为 Go 切片不支持内置反转操作。 

辅助函数`reverse`将元素从两端向中心交换。 

Go 切片是对底层数组的引用，因此反转切片会直接修改原始排列，而无需额外复制。 

不需要特殊的溢出处理，因为所有值都保持在范围内`[1, n]`， 在哪里`n <= 100001`。

from typing import List

class Solution:
    def findPermutation(self, s: str) -> List[int]:
        n = len(s) + 1
        perm = list(range(1, n + 1))

        i = 0

        while i < len(s):
            if s[i] == 'D':
                start = i

                while i < len(s) and s[i] == 'D':
                    i += 1

                perm[start:i + 1] = reversed(perm[start:i + 1])
            else:
                i += 1

        return perm

 ## 边缘情况

 ### 所有递增字符

 像这样的字符串：```
"IIII"
```很重要，因为算法应该认识到不需要反转。 有缺陷的实现可能仍然会尝试不必要的操作或错误处理边界。 

当前的实现自然地处理这个问题，因为它只在遇到`'D'`。 

### 所有递减字符

 像这样的字符串：```
"DDDD"
```创建一个影响整个排列的大递减块。 

这种情况很容易处理不当，因为反转范围必须包括所有涉及的数字，特别是`length + 1`元素。 

该实现正确地反转了整个数组：```
[1,2,3,4,5] -> [5,4,3,2,1]
```### 连续减少的段

 输入例如：```
"IIDDDI"
```很重要，因为连续`'D'`字符必须作为一个统一的块来处理，而不是单独的反转。 

如果每个`'D'`单独反转，结果不会同时满足所有条件。 

该实现显式向前扫描以识别完整的连续`'D'`在对受影响的范围执行一次反转之前运行。
