 # LeetCode 411 - 最小唯一单词缩写

 ## 问题理解

 这个问题要求我们为给定的目标单词生成尽可能短的缩写，使得该缩写不能代表字典中的任何单词。 

缩写用一个或多个不相邻的子字符串的长度替换它们。 例如，这个词`"apple"`可以变成：

 -`"5"`因为整个单词都被替换了
 -`"a4"`因为`"pple"`被替换
 -`"1p3"`因为第一个字符被替换了，`"p"`保留，并替换最后三个字符

 重要的规则是替换的部分不能相邻。 这意味着像这样的缩写`"s55n"`无效，因为两个数字部分代表相邻的省略区域。 

输入包括：

 -`target`，我们要缩写的词
 -`dictionary`，单词列表

 输出必须是：

 - 有效的缩写`target`- 最短的缩写
 - 与任何字典单词都不匹配的缩写

 如果保留的字符出现在相同的位置并且省略的段可以解释剩余的字符，则两个单词共享缩写。 

约束在这里非常重要：

 -`target.length <= 21`-`log2(n) + m <= 21`小目标长度强烈表明对字符位置进行位掩码是可行的。 自从`2^21`大约是 200 万，通过修剪和优化，枚举掩码成为可能。 

另一个关键的观察是，不同长度的词典单词永远不会与目标的缩写发生冲突。 只有长度相同的字典单词才重要。 

重要的边缘情况包括：

 - 空字典，其中最短的缩写只是目标的长度
 - 不同长度的词典单词，应忽略
 - 多个最短答案，返回任何有效答案都是可以接受的
 - 目标长度为1，其中答案可能需要保留唯一的字符
 - 每个高度压缩的缩写都发生冲突的情况，迫使我们保留更多字母

 ## 方法

 ### 蛮力方法

 强力解决方案将生成目标字符串的所有可能的缩写，并测试每个缩写是否与任何字典单词冲突。 

由于每个字符可以保留或省略，因此有`2^m`长度目标的可能掩码`m`。 

对于每个面具：

 1. 构造缩写
 2. 将其与每个字典单词进行比较
 3. 确定该缩写是否也可以代表该词典单词

 这是有效的，因为它详尽地检查了所有可能性并保证找到最短的有效缩写。 

然而，实施变得非常昂贵。 直接检查每个生成的缩写的缩写等效性涉及重复的解析和匹配操作。 

暴力破解的复杂性迅速增长，因为：

 - 有`2^m`面具
 - 每个面罩可能需要检查最多`n`字典单词
 - 每张支票可能需要`O(m)`这导致大约`O(2^m * n * m)`时间。 

### 最佳解决方案的关键见解

 关键的见解是缩写是由我们保留的位置唯一确定的。 

假设我们将字符保留在某些位置并缩写其他所有内容。 如果所有保留的位置都包含与目标相同的字符，则字典单词与我们的缩写冲突。 

这自然会导致位掩码。 

对于每个相同长度的字典单词：

 - 计算差异掩模
 - 有一点是`1`如果字典单词与该位置的目标单词不同

 现在考虑候选缩写掩码：

 -`1`意味着我们保留角色
 -`0`意味着我们缩写它

 如果满足以下条件，则缩写可将目标与字典单词区分开来：```
candidate_mask & difference_mask != 0
```这意味着至少一个保留的位置暴露了不同的字符。 

那么问题就变成了：

 > 找到具有最小缩写长度的掩码，使其与每个字典差异掩码相交。 

这将问题转化为紧凑的位掩码搜索问题。

 ## 算法演练

 ### 第 1 步：过滤字典单词

 只有与目标长度相同的字典单词才可能共享缩写。 

例如：```
target = "apple"
dictionary = ["blade", "orange"]
```仅有的`"blade"`重要的是因为`"orange"`长度为 6。 

这立即减少了不必要的工作。 

### 第 2 步：构建差异掩模

 对于每个剩余的字典单词：

 - 与目标字符逐个比较
 - 当字符不同时设置一点

 示例：```
target = apple
word   = blade
```人物对比：

 | 职位| 目标| 词| 不同|
 | --- | --- | --- | --- |
 | 0 | 一个 | 乙| 是的 |
 | 1 | p| 我| 是的 |
 | 2 | p| 一个 | 是的 |
 | 3 | 我| d | 是的 |
 | 4 | 电子| 电子| 没有|

 差异掩模：```
11110
```这意味着职位`0,1,2,3`不同。 

### 步骤 3：枚举候选掩码

 候选掩码确定保留哪些位置。 

例子：```
00100
```意思是：

 - 只保留索引2
 - 缩写所有其他内容

 对于`"apple"`这变成：```
2p2
```### 步骤 4：检查掩码是否唯一

 对于每个字典差异掩码：```
candidate_mask & difference_mask
```如果结果为零，则每个保留位置都与字典单词匹配，这意味着缩写是不明确的。 

有效的缩写必须满足：```
(candidate_mask & diff) != 0
```对于每个字典单词。 

### 步骤 5：计算缩写长度

 缩写长度不是位数。 

连续省略的位置合并为一个数字。 

例如：```
mask = 10101
```产生：```
a1p1e
```长度：

 - 3个字母
 - 2 个数字段

 总计 = 5。 

我们通过扫描掩模并计数来计算：

 - 保留的信件
 - 过渡到省略的区域

 ### 第 6 步：追踪最佳面膜

 枚举掩码时：

 - 计算缩写长度
 - 跳过比当前最好的口罩更差的口罩
 - 验证唯一性
 - 存储最好的有效掩码

 ### 步骤 7：将掩码转换为缩写

 最后，重建缩写字符串：

 - 保留的位变成字母
 - 连续省略的部分成为计数

 示例：```
target = apple
mask   = 00100
```输出：```
2p2
```### 为什么它有效

 每个缩写完全对应于一组保留的位置。 仅当字典单词在每个保留位置与目标匹配时，它才会与缩写冲突。 因此，要求每个字典差异掩码与候选掩码相交可以保证唯一性。 枚举所有掩码可确保我们最终检查最佳解决方案，而最小化缩写长度可确保返回最短的有效缩写。 

## Python 解决方案```python
from typing import List

class Solution:
    def minAbbreviation(self, target: str, dictionary: List[str]) -> str:
        n = len(target)

        dictionary = [word for word in dictionary if len(word) == n]

        if not dictionary:
            return str(n)

        diff_masks = []

        for word in dictionary:
            mask = 0

            for i in range(n):
                if target[i] != word[i]:
                    mask |= (1 << i)

            diff_masks.append(mask)

        def abbreviation_length(mask: int) -> int:
            length = 0
            i = 0

            while i < n:
                if mask & (1 << i):
                    length += 1
                    i += 1
                else:
                    length += 1
                    while i < n and not (mask & (1 << i)):
                        i += 1

            return length

        def is_unique(mask: int) -> bool:
            for diff in diff_masks:
                if (mask & diff) == 0:
                    return False
            return True

        best_mask = 0
        best_length = float("inf")

        for mask in range(1 << n):
            current_length = abbreviation_length(mask)

            if current_length >= best_length:
                continue

            if is_unique(mask):
                best_mask = mask
                best_length = current_length

        result = []
        count = 0

        for i in range(n):
            if best_mask & (1 << i):
                if count > 0:
                    result.append(str(count))
                    count = 0
                result.append(target[i])
            else:
                count += 1

        if count > 0:
            result.append(str(count))

        return "".join(result)
```该实现首先将字典单词过滤为仅与目标长度相同的单词。 这是安全的，因为缩写保留了总长度结构。 

接下来，代码构造差异掩码。 每个位代表字典单词是否与该位置的目标单词不同。 

这`abbreviation_length`助手计算真实的缩写长度。 连续的省略位置形成一个数字块，因此该函数对进入省略区域而不是单个省略字符的转换进行计数。 

这`is_unique`助手检查当前掩码是否区分目标和每个字典单词。 如果任何字典单词与保留的位置没有重叠，则缩写是不明确的。 

主循环枚举所有掩码`0`到`2^n - 1`。 已经超过当前最佳缩写长度的掩码将被提前跳过。 

最后，将最佳掩码转换为最终的缩写字符串。 

## 解决方案```go
package main

import (
	"strconv"
	"strings"
)

func minAbbreviation(target string, dictionary []string) string {
	n := len(target)

	filtered := []string{}

	for _, word := range dictionary {
		if len(word) == n {
			filtered = append(filtered, word)
		}
	}

	if len(filtered) == 0 {
		return strconv.Itoa(n)
	}

	diffMasks := []int{}

	for _, word := range filtered {
		mask := 0

		for i := 0; i < n; i++ {
			if target[i] != word[i] {
				mask |= (1 << i)
			}
		}

		diffMasks = append(diffMasks, mask)
	}

	abbreviationLength := func(mask int) int {
		length := 0
		i := 0

		for i < n {
			if (mask & (1 << i)) != 0 {
				length++
				i++
			} else {
				length++

				for i < n && (mask&(1<<i)) == 0 {
					i++
				}
			}
		}

		return length
	}

	isUnique := func(mask int) bool {
		for _, diff := range diffMasks {
			if (mask & diff) == 0 {
				return false
			}
		}

		return true
	}

	bestMask := 0
	bestLength := 1 << 30

	for mask := 0; mask < (1 << n); mask++ {
		currentLength := abbreviationLength(mask)

		if currentLength >= bestLength {
			continue
		}

		if isUnique(mask) {
			bestMask = mask
			bestLength = currentLength
		}
	}

	var builder strings.Builder
	count := 0

	for i := 0; i < n; i++ {
		if (bestMask & (1 << i)) != 0 {
			if count > 0 {
				builder.WriteString(strconv.Itoa(count))
				count = 0
			}

			builder.WriteByte(target[i])
		} else {
			count++
		}
	}

	if count > 0 {
		builder.WriteString(strconv.Itoa(count))
	}

	return builder.String()
}
```Go 实现遵循与 Python 版本相同的算法结构。 

一个`strings.Builder`用于缩写重建期间的高效字符串构造。 位操作使用标准整数掩码执行，这是安全的，因为最大目标长度仅为 21 位。 

Go 切片用于存储过滤后的字典单词和差异掩码。 由于 Go 没有具有自动变量捕获行为的 Python 动态闭包，因此辅助函数被实现为本地匿名函数。

 ## 边缘情况

 一个重要的边缘情况是空字典。 在这种情况下，任何缩写都不能与任何其他单词冲突，因此最短的缩写就是目标长度本身。 幼稚的实现可能仍会尝试不必要的搜索，但此解决方案会立即返回`str(n)`。 

当字典单词与目标单词的长度不同时，就会出现另一个棘手的情况。 这些单词永远不能与目标共享缩写，因为缩写保留了整体字符计数结构。 该实现在处理之前安全地过滤掉这些单词。 

当许多缩写冲突并且需要多个保留字符时，会出现更微妙的边缘情况。 例如，如果每个字典单词在不同位置都不同，则解决方案可能需要保留几个字母来唯一标识目标。 位掩码相交逻辑正确地处理了这个问题，因为候选缩写只有在与每个字典差异掩码相交时才有效。 

最后一种边缘情况涉及将整个字符串压缩为一个数字的缩写。 例如，`"5"`为了`"apple"`。 这个缩写非常短，但它与长度为 5 的每个字典单词冲突。只要任何字典差异掩码无法与候选掩码相交，算法就会正确拒绝它。
