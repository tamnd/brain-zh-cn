 ## 解决方案

 ## 问题理解

 该问题要求我们计算二维网格中表示的岛屿的周长。 网格中的每个单元格要么是土地（`1`）或水（`0`）。 该岛由一个或多个相连的陆地单元组成，其中的连接严格是水平或垂直的。 该网格完全被水包围，并且没有湖泊，这意味着不存在任何完全被陆地包围的水单元。 输出是一个整数，表示岛屿的总周长。 

关键限制是网格尺寸很小（最多 100x100），网格仅包含一个岛屿，并且每个单元格要么是陆地，要么是水。 这些约束意味着我们可以提供 O(mn) 的解决方案，其中 m 和 n 是行数和列数。 重要的边缘情况包括非常小的网格、单个陆地单元或网格边界上的陆地单元。 该问题保证了岛屿是连续且完全连接的，因此我们不需要处理多个不相连的陆地块。 

## 方法

 一种天真的、蛮力的方法将涉及检查每个陆地单元并检查所有四个侧面，看看它是否与水接壤或位于网格边界上。 我们将对满足此条件的所有边求和。 虽然这种方法有效，但它需要单独检查每个单元及其邻居，从而导致重复计算和稍微冗余的逻辑。 

最佳解决方案的关键观察结果是，每个陆地单元对周长的贡献为 4，每个相邻陆地单元的周长减去 2。 我们可以迭代网格一次，而不是多次检查所有单元格，并且对于每个陆地单元格，从已计数的每个相邻陆地单元格的周长中减去 2（顶部和左侧邻居就足够了）。 这减少了重复的邻居检查并保持逻辑干净，以最小的额外空间实现 O(mn) 时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(百万) | O(1) | O(1) | 检查每个陆地单元的所有四个邻居 |
 | 最佳| O(百万) | O(1) | O(1) | 为每个陆地单元计数 4，并为每个已处理的邻居减去 2 |

 ## 算法演练

 1. 初始化一个`perimeter`变量为零。 这将累计岛屿的总周长。 
2. 迭代每一行`i`和列`j`网格的。 
3. 如果当前单元格`grid[i][j]`是土地（`1`），从对周长的贡献为 4 开始。 
4. 检查上面的单元格（`i-1, j`）并向左（`i, j-1`）。 对于每个相邻的陆地单元，从周长中减去 2。 我们只需要顶部和左侧，因为底部和右侧将在以后的迭代中检查。 
5. 继续迭代，直到处理完所有单元格。 
6. 返回最终结果`perimeter`价值。 

工作原理：每个陆地单元最初都有四个边，代表该单元的最大可能周长。 对于已计算相邻陆地单元的每个共享边，我们减去 2，一次用于当前单元，一次隐式用于邻居，确保每个共享边仅计算一次。 这样就保证了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def islandPerimeter(self, grid: List[List[int]]) -> int:
        perimeter = 0
        rows = len(grid)
        cols = len(grid[0])
        
        for i in range(rows):
            for j in range(cols):
                if grid[i][j] == 1:
                    perimeter += 4
                    if i > 0 and grid[i-1][j] == 1:
                        perimeter -= 2
                    if j > 0 and grid[i][j-1] == 1:
                        perimeter -= 2
        return perimeter
```该实现在网格中迭代一次。 每个陆地单元贡献四个边，然后我们仅检查顶部和左侧的邻居。 如果任一邻居是陆地，则意味着这一边是共享的，因此我们减去 2。这种方法避免了重复计算共享边并确保 O(mn) 时间复杂度，而无需使用超出几个计数器的额外空间。 

## 解决方案```go
func islandPerimeter(grid [][]int) int {
    perimeter := 0
    rows := len(grid)
    cols := len(grid[0])
    
    for i := 0; i < rows; i++ {
        for j := 0; j < cols; j++ {
            if grid[i][j] == 1 {
                perimeter += 4
                if i > 0 && grid[i-1][j] == 1 {
                    perimeter -= 2
                }
                if j > 0 && grid[i][j-1] == 1 {
                    perimeter -= 2
                }
            }
        }
    }
    
    return perimeter
}
```Go 解决方案反映了 Python 实现。 差异包括使用`len(grid)`确定维度，使用从零开始的 for 循环而不是 Python`range`，并显式管理整数加法。 不需要额外的切片或地图。

 ## 边缘情况

 The first edge case is a single land cell in a grid, which could be at the edge or center. 周长必须为 4，并且我们的邻居检查可确保不会发生减法，因为不存在相邻单元格。 

第二个边缘情况是一行陆地单元，水平或垂直。 中间的每个单元格与邻居共享两侧，每个相邻单元格减去 2 可确保正确计算周长。 

第三种边缘情况是接触网格边界的孤岛。 我们的实现正确处理`i == 0`或者`j == 0`无需尝试访问负索引，防止越界错误。 

这种方法可以有效、正确地处理所有有保证的输入条件。
