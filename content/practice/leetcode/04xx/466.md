[LeetCode 第 466 题](https://leetcode.com/problems/count-the-repetitions/)

 **难度：** 🔴难
 **主题：** 两个指针、字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们找到一个字符串的最大出现次数`str2`可以从另一个字符串中获取`str1`当两者重复多次时。 具体来说，`str1`是字符串`s1`重复`n1`次，以及`str2`是字符串`s2`重复`n2`次。 为了“获得”`str2`从`str1`意味着我们可以从中删除字符`str1`无需重新排列剩余字符以使其匹配`str2`。 

简单来说，我们试图找出有多少次完整的重复`s2`可以适应多次重复`s1`，考虑到我们可以跳过中的字符`s1`但无法重新排序。 输出是一个整数`m`代表最大满数`str2`可以达到的重复次数。 

约束条件很重要：`s1`和`s2`很小（最多 100 个），但是`n1`和`n2`可以非常大（最多 1,000,000）。 这意味着显式构造重复字符串的简单方法会太慢并且占用内存。 相反，我们在匹配过程中需要依赖模式和重复周期。 

关键的边缘情况包括以下情况`s2`包含不在其中的字符`s1`，情况下`n1`小或等于 1，或者其中`s1`和`s2`是相同的。 这些条件可能会破坏简单的字符串构建方法，但必须在最佳解决方案中正确处理。 

## 方法

 蛮力方法很简单：重复连接`s1`建造`str1`并尝试匹配`s2`依次使用指针。 每次都满载`s2`匹配时，增加一个计数器。 这种方法是正确的，因为它直接遵循问题定义。 然而，它太慢了，因为`n1`和`n2`可以达到一百万，使得完整的字符串构造在时间和内存上都不可行。 

最佳方法利用了这样的观察：由于匹配过程的重复性质，匹配过程具有循环。`s1`和`s2`。 重复几次后，相对位置`s2`当开始新的`s1`重复开始重复。 一旦我们检测到这个循环，我们就可以使用算术计算匹配的总数，而不是模拟每次重复。 这大大降低了复杂性，因为我们避免了迭代完整的每个字符`str1`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n1 * len(s1) * len(s2)) | O(n1 * len(s1) * len(s2)) | O(n1 * len(s1)) | O(n1 * len(s1)) | 构建完整的重复字符串并模拟匹配； 对于大的 n1 来说太慢 |
 | 最佳| O(len(s1) * len(s2) + n1) | O(len(s2)) | O(len(s2)) | 检测循环以有效地跳过重复 |

 ## 算法演练

 1.初始化计数器：`s1_count`我们用过多少次`s1`,`s2_count`多少次`s2`已完全匹配，并且`index`追踪我们的位置`s2`。 
2. 使用字典`recall`每次重复后存储状态`s1`。 关键是现在`index`在`s2`，该值是一个元组`(s1_count, s2_count)`。 
3. 启动一个递增的循环`s1_count`每次我们重复处理一次`s1`。 
4. 在循环内部，迭代`s1`。 对于每个字符，如果它与中的当前字符匹配`s2`在位置`index`, 增量`index`。 如果`index`达到的长度`s2`，将其重置为零并递增`s2_count`。 
5.处理后一张`s1`，检查当前是否`index`之前曾出现过`recall`。 如果有，则检测到循环。 
6. 计算剩余的重复次数可以容纳多少个完整周期`s1`并添加相应的`s2_count`批量。 
7. 继续处理剩余的重复项`s1`循环后。 
8.最后返回`s2_count // n2`确定有多少个满`str2`可以获得序列。 

该算法之所以有效，是因为由于位置数量有限，重复的匹配过程最终会进入一个循环。`s2`。 一旦检测到循环，我们就可以计算每个循环恒定时间内所有重复的贡献，即使对于非常大的情况也能确保效率`n1`。 

## Python 解决方案```python
class Solution:
    def getMaxRepetitions(self, s1: str, n1: int, s2: str, n2: int) -> int:
        if n1 == 0:
            return 0
        
        s1_count = 0
        s2_count = 0
        index = 0
        recall = dict()
        
        while s1_count < n1:
            s1_count += 1
            for char in s1:
                if char == s2[index]:
                    index += 1
                    if index == len(s2):
                        index = 0
                        s2_count += 1
            
            if index in recall:
                prev_s1_count, prev_s2_count = recall[index]
                cycle_s1_count = s1_count - prev_s1_count
                cycle_s2_count = s2_count - prev_s2_count
                remaining_s1 = n1 - s1_count
                cycles = remaining_s1 // cycle_s1_count
                s1_count += cycles * cycle_s1_count
                s2_count += cycles * cycle_s2_count
            else:
                recall[index] = (s1_count, s2_count)
        
        return s2_count // n2
```此 Python 实现使用字典根据当前索引来检测循环`s2`。 它迭代了`s1`每次重复一次，跟踪次数`s2`已匹配。 一旦找到循环，算法就会向前跳跃该循环的倍数，从而防止不必要的重复模拟。 最终划分为`n2`给出完整的最大数量`str2`重复。 

## 解决方案```go
func getMaxRepetitions(s1 string, n1 int, s2 string, n2 int) int {
    if n1 == 0 {
        return 0
    }

    s1Count, s2Count, index := 0, 0, 0
    recall := make(map[int][2]int)

    for s1Count < n1 {
        s1Count++
        for i := 0; i < len(s1); i++ {
            if s1[i] == s2[index] {
                index++
                if index == len(s2) {
                    index = 0
                    s2Count++
                }
            }
        }

        if val, ok := recall[index]; ok {
            prevS1Count, prevS2Count := val[0], val[1]
            cycleS1Count := s1Count - prevS1Count
            cycleS2Count := s2Count - prevS2Count
            remainingS1 := n1 - s1Count
            cycles := remainingS1 / cycleS1Count
            s1Count += cycles * cycleS1Count
            s2Count += cycles * cycleS2Count
        } else {
            recall[index] = [2]int{s1Count, s2Count}
        }
    }

    return s2Count / n2
}
```Go 版本密切反映了 Python 解决方案。 主要区别包括使用固定大小的数组`[2]int`用于在映射中存储元组以及整数除法的显式类型处理。 检测循环和跳过重复的逻辑是相同的。
