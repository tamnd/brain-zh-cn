[LeetCode 第 429 题](https://leetcode.com/problems/n-ary-tree-level-order-traversal/)

 **难度：** 🟡 中等
 **主题：** 树、广度优先搜索

 ## 解决方案

 ## 问题理解

 该问题要求我们执行 n 叉树的_层序遍历_。 换句话说，我们需要返回按深度分组的树节点的值。 根节点代表级别 0，其直接子节点表示级别 1，其子节点表示级别 2，依此类推。 

输入是由节点表示的 n 叉树，其中每个节点可以有零个或多个子节点。 该树使用级别顺序格式进行序列化，其中`null`将儿童分组。 输出是一个列表列表，其中每个内部列表包含特定深度的节点值。 

约束提供了有用的信息：树的高度最多为 1000，并且最多可以有 10,000 个节点。 这意味着该算法需要处理相对较深的树，但不需要处理超过 10,000 个节点的极宽树。 

重要的边缘情况包括一棵空树（根是`None`），一棵某些节点没有子节点的树，或者一棵严重倾斜的树（所有节点都在一个分支上）。 该问题保证了有效的n叉树输入，因此我们不需要处理无效的结构。 

## 方法

 暴力方法将尝试递归遍历而不分离级别。 人们可以执行前序或后序遍历，然后通过使用辅助列表跟踪深度来对值进行分组。 虽然这在理论上可行，但它需要遍历树，然后执行额外的操作以按深度分组，这在时间和空间上效率较低。 

最佳方法是使用广度优先搜索（BFS）。 BFS 自然是逐层遍历树。 通过使用队列，我们​​可以将给定级别的节点出队，记录它们的值，并将它们的子节点放入下一个级别的队列。 这确保了每个级别都被单独且高效地处理，从而避免了额外的分组步骤的需要。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N) | O(N) | 遍历所有节点，然后使用额外内存按深度分组。 |
 | 最佳 | O(N) | O(N) | BFS直接使用队列逐级处理节点。 |

 ## 算法演练

 1.初始化一个空列表`result`来存储最终的输出。 这将保存树的每个级别的子列表。 
2.如果根是`None`，返回空值`result`当树是空的时立即。 
3. 初始化队列并将根节点入队。 这个队列将帮助我们逐级处理节点。 
4. 当队列不为空时，重复以下步骤：

 1. 通过测量队列大小确定当前级别的节点数。 
2.初始化一个空列表`current_level`存储该级别的节点值。 
3. 根据level大小将节点一一出队。 对于每个节点，将其值附加到`current_level`。 
4. 将当前节点的所有子节点放入队列中，以便在下一次迭代中处理它们。 
5.处理完当前level的所有节点后，追加`current_level`到`result`。 
5.队列为空后，返回`result`。 

**为什么有效：** BFS 保证节点被逐级访问。 通过跟踪当前队列大小，我们隔离每个深度的节点。 不变的是，在我们开始处理它们之前，队列始终包含下一级的所有节点，确保输出列表正确表示树级顺序遍历。 

## Python 解决方案```python
from typing import List, Optional

"""
# Definition for a Node.
class Node:
    def __init__(self, val: Optional[int] = None, children: Optional[List['Node']] = None):
        self.val = val
        self.children = children
"""

class Solution:
    def levelOrder(self, root: 'Node') -> List[List[int]]:
        result: List[List[int]] = []
        if not root:
            return result
        
        from collections import deque
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            current_level: List[int] = []
            
            for _ in range(level_size):
                node = queue.popleft()
                current_level.append(node.val)
                if node.children:
                    queue.extend(node.children)
            
            result.append(current_level)
        
        return result
```**说明：** 我们初始化结果列表和包含根的队列。 对于每个级别，我们测量要处理的节点数量。 我们迭代该级别的节点，记录它们的值，并将它们的子节点排队到下一个级别。 BFS 确保我们按顺序处理每个级别并正确捕获所有节点值。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */

func levelOrder(root *Node) [][]int {
    var result [][]int
    if root == nil {
        return result
    }
    
    queue := []*Node{root}
    
    for len(queue) > 0 {
        levelSize := len(queue)
        var currentLevel []int
        
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            currentLevel = append(currentLevel, node.Val)
            if node.Children != nil {
                queue = append(queue, node.Children...)
            }
        }
        
        result = append(result, currentLevel)
    }
    
    return result
}
```**说明：** Go 需要小心处理切片。 我们用根初始化一个队列。 对于每个级别，我们跟踪其大小，从切片前面删除节点，附加它们的值，并使用`append`。 当节点没有子节点时，零检查可以防止出现恐慌。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N) | 每个节点都被访问一次。 |
 | 空间| O(N) | 在最坏的情况下，队列最多可以容纳一级的所有节点。 |

 复杂性与节点数量成线性关系，因为 BFS 接触每个节点一次，并且队列的增长与树的最大宽度成正比，在最坏的情况下可达 N。
