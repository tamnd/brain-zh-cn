[LeetCode 第 467 题](https://leetcode.com/problems/unique-substrings-in-wraparound-string/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题定义了一个由小写英文字母构建的无限循环字符串：```
"...zabcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyzabcd..."
```这意味着序列永远持续下去，之后`'z'`来了`'a'`再次。 遵循此循环顺序的任何子字符串都存在于无限环绕字符串中的某个位置。 

我们得到一个字符串`s`，并且我们必须确定有多少个不同的非空子串`s`也出现在这个环绕字符串中。 

重要的细节是我们计算的是唯一子字符串，而不是总子字符串。 如果相同的有效子字符串出现多次`s`，应该只计算一次。 

例如，与：```
s = "zab"
```有效的子字符串是：```
"z", "a", "b", "za", "ab", "zab"
```它们都遵循环绕排序，因为：

 -`'z' -> 'a'`有效
 -`'a' -> 'b'`有效

 所以答案是`6`。 

限制因素很重要：```
1 <= s.length <= 100000
```一个长度的字符串`10^5`使得任何显式生成所有子串的算法都不切实际。 由于字符串长度`n`有`O(n^2)`子串，我们需要一个更有效的解决方案。 

一些边缘情况很重要：

 - 具有重复字符的字符串，例如`"aaaaa"`- 反复破坏环绕序列的字符串，例如`"cac"`- 环绕式过渡，例如`'z' -> 'a'`- 长连续有效链，例如`"abcdefghijklmnopqrstuvwxyz"`- 重复的有效子字符串出现多次

 幼稚的实现很容易过度计算重复项或由于子字符串生成而变得太慢。 

## 方法

 ### 蛮力方法

 最直接的解决方案是生成每个可能的子串`s`，然后检查每个子字符串是否存在于无限环绕字符串中。 

为了验证子串，我们可以检查每个相邻对是否遵循循环字母表规则：```
next_char == previous_char + 1
```或特殊的环绕式案例：```
'z' -> 'a'
```我们将有效的子字符串存储在一个集合中以避免重复计数。 

这种方法是正确的，因为它显式地检查每个子字符串并根据问题定义对其进行验证。 然而，对于输入限制来说，它太慢了。 

一个长度的字符串`n`包含：```
n * (n + 1) / 2
```子串，即`O(n^2)`。 即使优化了验证，生成和存储所有子字符串仍然会超出可行的限制`n = 100000`。 

### 最优动态规划方法

 关键的观察是我们实际上不需要单独存储每个子字符串。 

假设我们知道以字符结尾的有效环绕序列`'c'`有最大长度`k`。 

例如：```
"...abcd"
```结束于`'d'`与长度`4`。 

那么所有较短的后缀都自动有效：```
"d"
"cd"
"bcd"
"abcd"
```这意味着如果最长的有效子字符串以`'d'`有长度`4`，那么正好有`4`以以下结尾的唯一有效子字符串`'d'`。 

我们不需要存储子字符串本身，而是只需要跟踪：```
max_length_ending[character]
```其中每个条目存储以该字符结尾的有效环绕子字符串的最大长度。 

如果我们稍后遇到另一个以相同字符结尾但长度较短的子字符串，它不会贡献任何新内容，因为它的所有后缀都已被较长的子字符串计算在内。 

这将问题从子串枚举转换为线性动态规划扫描。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n2) 到 O(n3) | O(n²) | 生成所有子字符串并验证每个子字符串 |
 | 最佳| O(n) | O(1) | O(1) | 跟踪以每个字符结尾的最长有效链 |

 ## 算法演练

 1.创建一个大小的数组`26`被称为`max_lengths`。 

每个索引对应一个小写字母：```
0 -> 'a'
1 -> 'b'
...
25 -> 'z'
```

`max_lengths[i]`存储以该字符结尾的最长有效环绕子字符串。 
2. 维护一个变量`current_length`。 

这表示以当前字符结束的当前有效环绕链的长度。 
3. 从左到右迭代字符串。 

对于每个角色`s[i]`，确定是否继续回绕序列`s[i - 1]`。 
4. 如果满足以下任一条件，则延续有效：```
ord(s[i]) - ord(s[i - 1]) == 1
```或者：```
s[i - 1] == 'z' and s[i] == 'a'
```5. 如果序列继续，则递增`current_length`。 

否则，将其重置为`1`因为单个字符始终是有效的子字符串。 
6. 更新当前结束字符的最大长度。 

假设当前字符是`'d'`当前链长度为`4`。 

然后：```
max_lengths['d'] = max(existing_value, 4)
```7. 继续，直到处理完整个字符串。 
8. 最终答案是所有值的总和`max_lengths`。 

每个值表示以该字符结尾的唯一子字符串的数量。 

### 为什么它有效

 核心不变量是：```
If the longest valid substring ending with character c has length k,
then there are exactly k unique valid substrings ending with c.
```所有较短的后缀都会自动包含在最长的子字符串中。 

通过仅存储每个结束字符的最大长度，我们可以避免重复计数，同时仍然只计算每个唯一的有效子字符串一次。 

## Python 解决方案```python
class Solution:
    def findSubstringInWraproundString(self, s: str) -> int:
        max_lengths = [0] * 26
        current_length = 0

        for i in range(len(s)):
            if (
                i > 0
                and (
                    ord(s[i]) - ord(s[i - 1]) == 1
                    or (s[i - 1] == 'z' and s[i] == 'a')
                )
            ):
                current_length += 1
            else:
                current_length = 1

            char_index = ord(s[i]) - ord('a')
            max_lengths[char_index] = max(
                max_lengths[char_index],
                current_length
            )

        return sum(max_lengths)
```该实现紧密遵循前面描述的算法。 

这`max_lengths`数组存储以每个字符结尾的最大有效链长度。 由于只有 26 个小写字母，因此该结构使用恒定的空间。 

变量`current_length`跟踪正在进行的环绕子字符串的长度。 在迭代期间，代码检查当前字符是否扩展了先前的环绕序列。 如果是这样，链长度就会增加。 否则，链重置为`1`。 

更新步骤是最重要的部分：```python
max_lengths[char_index] = max(
    max_lengths[char_index],
    current_length
)
```这保证了我们只保留以该字符结尾的最长有效子字符串。 已隐含任何以相同字符结尾的较短有效子字符串。 

最后，将所有值相加`max_lengths`给出唯一有效子字符串的总数.

 ## 解决方案```go
func findSubstringInWraproundString(s string) int {
    maxLengths := make([]int, 26)
    currentLength := 0

    for i := 0; i < len(s); i++ {
        if i > 0 &&
            ((s[i]-s[i-1] == 1) ||
                (s[i-1] == 'z' && s[i] == 'a')) {
            currentLength++
        } else {
            currentLength = 1
        }

        index := s[i] - 'a'

        if currentLength > maxLengths[index] {
            maxLengths[index] = currentLength
        }
    }

    total := 0

    for _, length := range maxLengths {
        total += length
    }

    return total
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

一个小小的区别是 Go 字符串是可字节索引的，这在这里工作得很好，因为输入仅包含小写英文字母。 这允许使用字节值进行直接字符算术。 

这`maxLengths`切片具有固定大小`26`，确保恒定的辅助空间使用。 

不需要对整数溢出进行特殊处理，因为最大答案受长度字符串中子字符串数量的限制`100000`，它很容易适合 Go 的`int`。

 ## 边缘情况

 ### 重复字符

 像这样的字符串：```
"aaaaa"
```很容易导致过度计数的错误。 每个字符单独有效，但子字符串如`"aa"`不是有效的环绕子字符串，因为`'a' -> 'a'`不遵循循环字母顺序。 

该实现通过重置来正确处理这个问题`current_length`到`1`每当顺序规则失败时。 

### 从“z”到“a”的环绕

 过渡：```
'z' -> 'a'
```是问题的定义特殊情况。 天真的字母比较会错误地拒绝它。 

实现明确检查：```
s[i - 1] == 'z' and s[i] == 'a'
```这确保环绕连续性被视为有效。 

### 重复的有效子字符串

 考虑：```
"zabzab"
```子串`"zab"`出现多次。 幼稚的计数方法可能会重复计数。 

动态规划策略完全避免了这种情况。 由于我们只存储以每个字符结尾的最大有效长度，因此重复的较短链不会增加计数。 这会自动保证唯一性。
