[LeetCode 第 417 题](https://leetcode.com/problems/pacific-atlantic-water-flow/)

 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 该问题给了我们一个矩形网格，称为`heights`，其中每个单元代表一块土地的海拔。 如果相邻单元格的高度小于或等于当前单元格，则水可以从一个单元格流到另一个单元格。 只允许在四个基本方向上移动：上、下、左、右。 

太平洋接触网格的顶部和左侧边界，而大西洋接触底部和右侧边界。 如果从单元格开始的水最终可以通过有效的下坡或平坦高度路径到达两个海洋，则该单元格被认为是有效的。 

关键细节是水流方向。 水从较高的海拔流向较低或相同的海拔。 乍一看，这表明从每个细胞开始并模拟水向外流动。 然而，为每个单元独立执行此操作会重复探索相同的区域并且效率低下。 

输入是一个`m x n`两个维度都可以大到的矩阵`200`。 这意味着最多可以有`40,000`细胞总数。 任何比单元数量大致线性或接近线性更糟糕的解决方案都有超时的风险。 

输出应包含所有坐标`[r, c]`这样来自该位置的水就可以流向两个海洋。 

尽早识别一些边缘情况很重要：

 - A`1 x 1`网格很容易到达两个海洋，因为单个单元格触及所有边界。 
- 高度相等的网格允许水向各个方向自由流动。 
- 严格增加或减少网格会产生单向流约束，从而可能暴露不正确的遍历逻辑。 
- 海洋边界上的细胞已经可以进入一个海洋，并且可能会也可能不会到达另一个海洋。 
- 当相邻单元具有相同高度时，可能会发生循环，因此需要访问结构。 

## 方法

 ### 蛮力方法

 暴力解决方案从每个单独的单元启动 DFS 或 BFS。 对于每个起始位置，我们尝试确定水是否最终可以到达太平洋以及是否可以最终到达大西洋。 

从给定的单元格，我们递归地移动到高度小于或等于当前单元格的相邻单元格，因为水只能向下流动或保持水平。 如果我们最终触及太平洋边界，那么细胞就可以到达太平洋。 同样，如果我们接触大西洋边界，那么细胞就可以到达大西洋。 

这种方法是正确的，因为它直接模拟了问题中描述的精确运动规则。 然而，它执行大量的重复工作。 相邻的细胞经常重复探索几乎相同的路径。 

在最坏的情况下，每个 DFS 可能会遍历大部分网格。 由于有`m * n`开始细胞，总的复杂性变得非常大。 

### 最佳方法

 关键的见解是反转搜索的方向。 

而不是问：

 >“水可以从这个细胞流到海洋吗？”

 我们问：

 > “从海洋出发，最终哪些细胞能够流入其中？”

 这种逆转之所以有效，是因为水流是有方向的。 如果水可以从低处流`A`到`B`，那么在反向遍历期间我们可以从`B`到`A`每当`A >= B`。 

因此，我们只执行两次遍历，而不是从内部单元格执行数千次搜索：

 - 从所有太平洋边界单元格开始一次遍历
 - 从所有大西洋边界单元格开始一次遍历

 在这些遍历过程中，我们仅移动到高度大于或等于当前单元格的相邻单元格。 这确保了反向可达性与正向水流完全对应。 

在最后：

-`pacific_reachable[r][c]`告诉我们细胞可以到达太平洋
 -`atlantic_reachable[r][c]`告诉我们细胞可以到达大西洋

 两次搜索均可到达的任何单元格都属于答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m * n)^2) | O((m * n)^2) | O(m * n) | 每个单元独立的 DFS/BFS |
 | 最佳| O(m * n) | O(m * n) | 从海洋边界反向遍历 |

 ## 算法演练

 1. 创建两个访问集，一组用于太平洋，一组用于大西洋。 

这些数据集记录了哪些细胞可以到达每个海洋。 我们将它们分开，因为细胞可能到达一个海洋，但不能到达另一个海洋。 
2. 识别所有太平洋边境单元。 

太平洋触及：

 - 最上面一行
 - 左栏

 这些细胞是穿越太平洋的起点，因为水可以立即从它们流入太平洋。 
3. 识别所有大西洋边界单元。 

大西洋触及：

 - 最底行
 - 右栏

 这些细胞成为横贯大西洋的起点。 
4. 从所有太平洋边境单元运行 DFS 或 BFS。 

遍历时，只移动到高度大于或等于当前单元格的相邻单元格。 

这种相反的条件是至关重要的。 如果邻居更高或相等，则水可以从该邻居向下流到原始问题方向的当前单元格中。 
5. 使用相同的规则从所有大西洋边界单元运行 DFS 或 BFS。 

两次遍历完成后，每个访问的结构都包含能够到达该海洋的所有单元格。 
6. 迭代网格中的每个单元格。 

如果一个单元存在于两个访问的集合中，那么来自该单元的水可以到达两个海洋。 
7. 返回所有此类坐标。 

### 为什么它有效

 该算法依赖于反向可达性。 

如果水可以从细胞中流出`A`到细胞`B`在原来的问题中，那么在反向遍历期间我们可以从`B`到`A`。 通过从海洋边界开始并探索所有反向有效路径，我们发现了每个最终可能流入海洋的细胞。 

由于太平洋和大西洋的遍历是独立的，因此它们的可达集的交集恰好包含可以流向两个海洋的像元。 

## Python 解决方案```python
from typing import List, Set, Tuple

class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        rows = len(heights)
        cols = len(heights[0])

        pacific_reachable: Set[Tuple[int, int]] = set()
        atlantic_reachable: Set[Tuple[int, int]] = set()

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        def dfs(row: int, col: int, visited: Set[Tuple[int, int]]) -> None:
            visited.add((row, col))

            for dr, dc in directions:
                new_row = row + dr
                new_col = col + dc

                if (
                    0 <= new_row < rows
                    and 0 <= new_col < cols
                    and (new_row, new_col) not in visited
                    and heights[new_row][new_col] >= heights[row][col]
                ):
                    dfs(new_row, new_col, visited)

        # Pacific Ocean traversal
        for col in range(cols):
            dfs(0, col, pacific_reachable)

        for row in range(rows):
            dfs(row, 0, pacific_reachable)

        # Atlantic Ocean traversal
        for col in range(cols):
            dfs(rows - 1, col, atlantic_reachable)

        for row in range(rows):
            dfs(row, cols - 1, atlantic_reachable)

        result = []

        for row in range(rows):
            for col in range(cols):
                if (
                    (row, col) in pacific_reachable
                    and (row, col) in atlantic_reachable
                ):
                    result.append([row, col])

        return result
```实施过程严格遵循逆流策略。 

这`dfs`helper 探索从给定海洋边界可到达的所有单元格。 这`visited`set 可防止无限循环和重复工作，尤其是在高度相等的区域中。 

遍历条件：```python
heights[new_row][new_col] >= heights[row][col]
```是解决方案的核心见解。 由于我们是从海洋向后移动，因此我们向相同或更高的单元移动。 

该算法执行四次边界遍历：

 - 太平洋的顶排
 - 左栏为太平洋
 - 底排为大西洋
 - 大西洋右栏

 两个可达性地图完成后，我们扫描整个网格并收集两个集合中出现的单元格。 

## 解决方案```go
package main

func pacificAtlantic(heights [][]int) [][]int {
	rows := len(heights)
	cols := len(heights[0])

	pacific := make([][]bool, rows)
	atlantic := make([][]bool, rows)

	for i := 0; i < rows; i++ {
		pacific[i] = make([]bool, cols)
		atlantic[i] = make([]bool, cols)
	}

	directions := [][]int{
		{1, 0},
		{-1, 0},
		{0, 1},
		{0, -1},
	}

	var dfs func(int, int, [][]bool)

	dfs = func(row int, col int, visited [][]bool) {
		visited[row][col] = true

		for _, dir := range directions {
			newRow := row + dir[0]
			newCol := col + dir[1]

			if newRow < 0 || newRow >= rows ||
				newCol < 0 || newCol >= cols {
				continue
			}

			if visited[newRow][newCol] {
				continue
			}

			if heights[newRow][newCol] < heights[row][col] {
				continue
			}

			dfs(newRow, newCol, visited)
		}
	}

	// Pacific traversal
	for col := 0; col < cols; col++ {
		dfs(0, col, pacific)
	}

	for row := 0; row < rows; row++ {
		dfs(row, 0, pacific)
	}

	// Atlantic traversal
	for col := 0; col < cols; col++ {
		dfs(rows-1, col, atlantic)
	}

	for row := 0; row < rows; row++ {
		dfs(row, cols-1, atlantic)
	}

	result := [][]int{}

	for row := 0; row < rows; row++ {
		for col := 0; col < cols; col++ {
			if pacific[row][col] && atlantic[row][col] {
				result = append(result, []int{row, col})
			}
		}
	}

	return result
}
```Go 实现使用`[][]bool`而不是用于访问跟踪的哈希集。 这是有效的，因为网格尺寸是预先已知的。 

Go 切片的大小是动态调整的，因此结果是使用增量构建的`append`。 

与Python不同，Go默认不具有隐式闭包行为的嵌套函数递归，因此DFS函数在赋值之前被声明为变量。 

不存在整数溢出问题，因为相对于 Go 的整数容量而言，问题约束很小。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 每次海洋穿越时，每个单元最多被访问一次 |

from typing import List

class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        rows = len(heights)
        cols = len(heights[0])

        pacific = set()
        atlantic = set()

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        def dfs(r, c, visited):
            visited.add((r, c))

            for dr, dc in directions:
                nr, nc = r + dr, c + dc

                if (
                    0 <= nr < rows
                    and 0 <= nc < cols
                    and (nr, nc) not in visited
                    and heights[nr][nc] >= heights[r][c]
                ):
                    dfs(nr, nc, visited)

        for c in range(cols):
            dfs(0, c, pacific)
            dfs(rows - 1, c, atlantic)

        for r in range(rows):
            dfs(r, 0, pacific)
            dfs(r, cols - 1, atlantic)

        return sorted([
            [r, c]
            for r in range(rows)
            for c in range(cols)
            if (r, c) in pacific and (r, c) in atlantic
        ])

 ## 边缘情况

 单单元格网格是最小的有效输入，很容易暴露不正确的边框处理。 由于单个细胞同时接触每个边缘，因此它属于两个海洋。 该实现自然地处理了这个问题，因为两次 DFS 遍历中都包含相同的单元格。 

所有高度都相等的网格是另一个重要的边缘情况。 在这样的矩阵中，水可以在所有相邻单元之间自由移动。 错误地使用严格的大于比较而不是大于或等于的实现将在此处失败。 该解决方案正确地允许在高度相等时进行遍历。 

室内盆也很棘手。 考虑一个被较高单元包围的低单元。 该盆地的水无法向外逸出，因为只允许向下或水平移动。 反向遍历可以完美地处理这个问题，因为如果周围的单元更高，来自海洋的 DFS 就无法爬入盆地。 

长的单调路径可以创建深度递归链。 例如，穿过矩阵的蛇形增加路径可能会导致 DFS 深度接近单元总数。 该算法仍然保持正确，因为每个海洋中的每个单元仅被访问一次，尽管在 Python 中，如果递归深度成为实践中的一个问题，则可以使用迭代 BFS。
