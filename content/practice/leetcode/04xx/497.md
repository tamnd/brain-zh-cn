 ## 解决方案

 ## 问题理解

 该问题要求我们从二维空间中一组不重叠的矩形中随机选取一个整数点。 每个矩形由其左下角定义`(ai, bi)`和右上角`(xi, yi)`角落。 目标是确保所有矩形并集内的每个整数点都有相同的被选择概率。 矩形边缘上的点算作矩形的一部分。 

输入`rects`是一个矩形列表，每个矩形由四个整数表示。 输出是随机选择的整数点`[u, v]`在其中一个矩形内。 约束告诉我们最多可以有 100 个矩形，每个矩形的边长最多为 2000，并且坐标可以非常大（大小最多为 10^9）。 我们可以调用`pick()`最多可运行 10^4 次。 

重要的边缘情况包括面积最小的矩形（如 1x1）、共享边缘但不重叠的矩形以及负坐标。 该问题保证不重叠，因此我们不必处理重叠区域。 

## 方法

 强力解决方案将枚举所有矩形中的所有整数点，将它们存储在列表中，然后从列表中选择一个随机元素。 这保证了一致性，因为每个点只出现一次。 然而，这种方法是不可行的，因为总点数可以达到`100 * 2001 * 2001`，超过4亿点。 对于这个输入范围来说，空间和时间复杂度太高。 

最佳解决方案的关键在于我们不需要枚举每个点。 相反，我们可以计算每个矩形中的点数，维护这些计数的前缀和，并用它来选择一个与其面积成比例的概率的矩形。 一旦选择了一个矩形，我们就可以使用简单的算术随机选择其中的一个点。 这极大地减少了内存使用量和运行时间，同时保持了一致性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(总点数) | O(总点数) | 枚举所有整数点 |
 | 最佳| 每次选择 O(log n) | O(n) | 在矩形上使用前缀和和二分搜索 |

 ## 算法演练

 1. **初始化**：计算每个矩形内的整数点数。 对于矩形`[ai, bi, xi, yi]`，点数为`(xi - ai + 1) * (yi - bi + 1)`。 将这些计数的累积和存储在列表中`prefix_sum`。 
2. **随机矩形选择**：生成随机整数`k`之间`1`以及总点数。 使用二分查找`prefix_sum`数组来查找哪个矩形包含`k`第-点。 
3. **矩形中的随机点**：一次矩形`[ai, bi, xi, yi]`被选中，生成一个随机整数`dx`在`[0, xi - ai]`和`dy`在`[0, yi - bi]`。 所选点是`(ai + dx, bi + dy)`。 
4. **返回结果**：以两个整数的列表形式返回生成的点。 

**为什么起作用**：前缀和确保每个矩形的选择概率与其包含的整数点的数量成正比。 在矩形内均匀选取一个点可以保证每个点的可能性相同。 

## Python 解决方案```python
import random
from typing import List

class Solution:

    def __init__(self, rects: List[List[int]]):
        self.rects = rects
        self.prefix_sum = []
        total = 0
        for x1, y1, x2, y2 in rects:
            points = (x2 - x1 + 1) * (y2 - y1 + 1)
            total += points
            self.prefix_sum.append(total)

    def pick(self) -> List[int]:
        k = random.randint(1, self.prefix_sum[-1])
        # Binary search to find the rectangle
        low, high = 0, len(self.prefix_sum) - 1
        while low < high:
            mid = (low + high) // 2
            if k <= self.prefix_sum[mid]:
                high = mid
            else:
                low = mid + 1
        rect_index = low
        x1, y1, x2, y2 = self.rects[rect_index]
        dx = random.randint(0, x2 - x1)
        dy = random.randint(0, y2 - y1)
        return [x1 + dx, y1 + dy]
```Python 实现首先预先计算每个矩形中点的前缀和。 选择随机点涉及通过二分搜索选择一个矩形并在其中生成一个随机点。 这避免了生成所有点，从而提供了高效的 O(log n) 拾取时间。 

## 解决方案```go
package main

import (
    "math/rand"
    "time"
)

type Solution struct {
    rects      [][]int
    prefixSum  []int
}

func Constructor(rects [][]int) Solution {
    rand.Seed(time.Now().UnixNano())
    prefix := make([]int, len(rects))
    total := 0
    for i, rect := range rects {
        x1, y1, x2, y2 := rect[0], rect[1], rect[2], rect[3]
        points := (x2 - x1 + 1) * (y2 - y1 + 1)
        total += points
        prefix[i] = total
    }
    return Solution{
        rects:     rects,
        prefixSum: prefix,
    }
}

func (this *Solution) Pick() []int {
    totalPoints := this.prefixSum[len(this.prefixSum)-1]
    k := rand.Intn(totalPoints) + 1

    // Binary search
    low, high := 0, len(this.prefixSum)-1
    for low < high {
        mid := (low + high) / 2
        if k <= this.prefixSum[mid] {
            high = mid
        } else {
            low = mid + 1
        }
    }
    rect := this.rects[low]
    x1, y1, x2, y2 := rect[0], rect[1], rect[2], rect[3]
    dx := rand.Intn(x2 - x1 + 1)
    dy := rand.Intn(y2 - y1 + 1)
    return []int{x1 + dx, y1 + dy}
}
```Go 版本与 Python 非常相似。 差异包括随机数生成器的播种和使用`rand.Intn(n)`产生价值`[0, n)`。 这`+1`调整确保包含范围。 

## 工作示例

 **输入示例**：`[[-2, -2, 1, 1], [2, 2, 4, 6]]`1.计算点：第一个矩形`(1-(-2)+1)*(1-(-2)+1) = 4*4=16`，第二个矩形`(4-2+1)*(6-2+1)=3*5=15`。 前缀和`[16, 31]`。 
2. 随机选择一个`k`1 到 31 之间。假设`k = 18`。 
3. 二分查找`[16, 31]`给出矩形 1（第二个矩形）.
 4. 第二个矩形中的随机点：dx = rand(0,2)，dy = rand(0,4)。 假设dx=1，dy=2。 结果`[2+1,2+2]=[3,4]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) 初始化，O(log n) 每次选取 | Init 计算前缀和； pick 使用二分搜索 |

 拾取操作不依赖于矩形大小，只依赖于矩形的数量，即使对于大矩形也是高效的。
