[LeetCode 第 482 题](https://leetcode.com/problems/license-key-formatting/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`代表许可证密钥。 该字符串包含大写字母、小写字母、数字和破折号。 现有的破折号只是分隔符，并不一定代表正确的最终分组。 

我们必须根据两个规则重新格式化字符串：

 1. 格式化后的每组必须准确包含`k`字符，第一组除外。 
2. 第一组可能包含少于`k`字符，但必须至少包含一个字符。 

此外，所有字母字符必须转换为大写，并且组必须用单破折号分隔。 

例如，假设输入是：```
"5F3Z-2e-9-w"
```和`k = 4`。 

如果我们先删除所有破折号，我们会得到：```
"5F3Z2e9w"
```转换为大写后：```
"5F3Z2E9W"
```现在我们从左到右分成大小为 4 的块：```
"5F3Z-2E9W"
```这将成为最终的答案。 

约束条件很重要：

 -`s.length`可以大到`10^5`-`k`可以大到`10^4`这立即告诉我们我们需要一个线性时间解决方案。 任何重复将字符插入字符串前面或低效重建字符串的方法都可能变得太慢。 

有几种边缘情况可能会导致简单实现中的错误：

 - 带有许多破折号的字符串，例如`"---a---"`- 字符总数可以整除的字符串`k`- 第一组应包含少于的字符串`k`人物
 - 必须正确转换的小写字母
 - 非常小的值`k`， 例如`1`- 已正确显示格式的输入

 该问题保证字符串中某处至少有一个字母数字字符，因此最终结果将始终包含至少一组。 

## 方法

 ### 蛮力方法

 一种简单的方法是首先删除所有破折号并将剩余字符转换为大写。 然后我们从字符串的前面重复构建组。 

一种简单的实现会重复对子字符串进行切片，并使用正常的字符串加法将它们连接到结果字符串中。 由于字符串在许多语言中都是不可变的，因此重复连接可能会变得昂贵，因为每个追加都可能创建字符串的新副本。 

例如：```
result = result + "-" + next_group
```如果在大输入上重复此操作多次，则总运行时间可能会降低到二次复杂度。 

这种方法是正确的，因为它根据分组规则显式地重建格式化字符串。 然而，对于大量输入来说，它的效率很低。 

### 最佳方法

 关键的见解是，如果我们从右到左处理字符，格式化就会变得容易得多。 

除第一个组外，每个组都必须完全包含`k`人物。 这意味着如果我们向后构建字符串，我们可以简单地在每个后面插入一个破折号`k`人物。 

该过程变为：

 1、从尾部遍历原字符串。 
2. 忽略破折号。 
3. 将字母转换为大写。 
4. 将字符追加到结果缓冲区中。 
5. 每次之后`k`字符，附加破折号。 
6.最后反转最终结果。 

使用可变列表或字符串生成器可以避免昂贵的重复字符串连接，从而为我们提供线性性能。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复字符串串联可重复复制数据 |
 | 最佳 | O(n) | O(n) | 具有高效缓冲结构的单程 |

 ## 算法演练

 1. 创建一个空的结果缓冲区，以相反的顺序存储字符。 
2. 初始化一个计数器来跟踪有多少字符已添加到当前组中。 
3. 从右向左遍历字符串。 向后处理是有用的，因为除了第一个组之外的所有组都必须精确地具有`k`人物。 从最后开始构建自然会强制执行这条规则。 
4. 对于每个字符：

 - 如果字符是破折号，则跳过它，因为原始破折号不相关。 
- 否则：

 - 将字符转换为大写。 
- 将其附加到结果缓冲区。 
- 增加组计数器。 
5. 每当组计数器达到`k`，将破折号添加到结果缓冲区并将计数器重置为零。 这会在向后处理时创建适当大小的组。 
6. 遍历结束后，反转缓冲区末尾可能会多出一个破折号。 如有必要，请将其移除。 
7. 反转缓冲区并将其连接到最终的字符串中。 

### 为什么它有效

 该算法保持了反转缓冲区中每个完成的组都准确包含的不变式`k`人物。 由于我们从右向左处理，因此除了可能的第一个组之外，所有组自然都满足分组约束。 反转缓冲区后，各组以正确的从左到右顺序出现，并且第一组自动包含剩余字符，该字符可能少于`k`。 

## Python 解决方案```python
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        result = []
        group_size = 0

        for index in range(len(s) - 1, -1, -1):
            char = s[index]

            if char == "-":
                continue

            result.append(char.upper())
            group_size += 1

            if group_size == k:
                result.append("-")
                group_size = 0

        if result and result[-1] == "-":
            result.pop()

        return "".join(reversed(result))
```该实现使用一个名为的列表`result`作为可变缓冲区，因为在 Python 中追加到列表是高效的。 直接通过重复连接构建字符串会比较慢。 

该循环向后迭代输入字符串。 这使得创建精确的组变得容易`k`字符，因为我们可以在每次计数器到达时简单地插入一个破折号`k`。 

每个非破折号字符在附加之前都会立即转换为大写。 

处理完所有字符后，缓冲区可能会以不必要的破折号结束。 当字符总数被整除时会发生这种情况`k`。 有条件的`pop()`安全地将其移除。 

最后，缓冲区被反转并连接成格式正确的字符串。 

## 解决方案```go
func licenseKeyFormatting(s string, k int) string {
    result := make([]byte, 0)
    groupSize := 0

    for i := len(s) - 1; i >= 0; i-- {
        ch := s[i]

        if ch == '-' {
            continue
        }

        if ch >= 'a' && ch <= 'z' {
            ch = ch - 'a' + 'A'
        }

        result = append(result, ch)
        groupSize++

        if groupSize == k {
            result = append(result, '-')
            groupSize = 0
        }
    }

    if len(result) > 0 && result[len(result)-1] == '-' {
        result = result[:len(result)-1]
    }

    for left, right := 0, len(result)-1; left < right; left, right = left+1, right-1 {
        result[left], result[right] = result[right], result[left]
    }

    return string(result)
}
```Go 实现遵循与 Python 版本相同的算法结构，但有一些特定于语言的细节。 

Go 字符串是不可变的，所以我们使用`[]byte`切片作为可变缓冲区。 附加到字节片是高效的并且可以避免重复分配。 

大写转换是使用 ASCII 算术手动完成的，因为我们只处理英文字母。 

由于 Go 没有提供内置的切片反转函数，因此解决方案使用两指针交换循环就地反转切片。

 ## 边缘情况

 当字母数字字符的数量恰好可以被以下整除时，就会出现一种重要的边缘情况`k`。 在这种情况下，向后构建过程会在最后一组后面附加一个尾随破折号。 如果在反转之前未删除该破折号，则输出将错误地以破折号开头。 该实现通过检查缓冲区中的最后一个字符是否是来处理这个问题`'-'`并在反转前将其移除。 

另一个重要的情况是当输入包含许多不必要的破折号时，例如`"---a---"`。 幼稚的实现可能会意外地保留空组或创建格式错误的输出。 该算法在遍历过程中完全忽略所有破折号，确保只有有效的字母数字字符参与分组。 

当出现第三种边缘情况时`k = 1`。 在这种情况下，每个角色都必须成为自己的群体。 某些实现错误地插入了额外的分隔符或错误地处理了第一组。 因为此解决方案在每个已处理大小的字符组之后插入破折号`k`，它自然会产生正确的格式，而无需任何特殊情况逻辑。 

最后的边缘情况涉及小写字母与数字混合，例如`"2-4A0r7-4k"`。 忘记大写转换会产生不正确的输出。 该实现在插入之前立即将每个非破折号字符转换为大写，以保证整个结果的格式一致。
