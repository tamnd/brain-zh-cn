[LeetCode 第 498 题](https://leetcode.com/problems/diagonal-traverse/)

 **难度：** 🟡 中等
 **主题：** 数组、矩阵、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们以特定的对角线模式遍历矩阵，并按访问顺序返回所有元素。 

我们被赋予了一个`m x n`矩阵`mat`， 在哪里`m`代表行数和`n`代表列数。 目标是返回一个包含每个矩阵元素的一维数组，以对角线之字形顺序访问。 

遍历遵循以下规则：

 - 元素是对角线对角线访问的。 
- 每个对角线包含行索引和列索引之和恒定的单元格。 
- 方向在对角线之间交替：

 - 向右上方穿过一条对角线。 
- 下一条对角线向左下方遍历。 

例如，在：```
1 2 3
4 5 6
7 8 9
```遍历变成：```
[1]          -> upward
[2,4]        -> downward
[7,5,3]      -> upward
[6,8]        -> downward
[9]          -> upward
```结果：```
[1,2,4,7,5,3,6,8,9]
```约束条件很重要：

 -`1 <= m, n <= 10^4`-`1 <= m * n <= 10^4`元素总数最多为`10^4`，这表明`O(m × n)`解决方案是理想的并且完全可以接受。 由于每个元素都必须出现在输出中，因此就访问的单元总数而言，我们无法比线性时间做得更好。 

一些重要的边缘情况立即脱颖而出：

 只有一行的矩阵必须简单地从左到右遍历。 只有一列的矩阵必须从上到下遍历。 矩形矩阵，其中`m != n`，需要仔细的边界处理，因为对角线终止于不同的边缘。 小矩阵如`1 x 1`也是容易犯一错的地方。 

该问题保证矩阵非空且为矩形，这意味着每行具有相同的列数。 

## 方法

 ### 蛮力方法

 解决此问题的一种直接方法是按对角线显式对矩阵元素进行分组。 

关键的观察结果是每个细胞`(row, col)`属于由下式确定的对角线：```
row + col
```我们可以迭代矩阵并将元素存储在哈希图中，其中键是`row + col`。 收集所有对角线后，我们按顺序迭代它们。 

对于偶数对角线，我们反转收集的元素，因为遍历应该向右上移动。 对于奇数对角线，我们保持原样，因为遍历应该向左下移动。 

这是有效的，因为所有单元共享相同的`row + col`属于同一条对角线。 

然而，这种方法需要对角组进行额外的存储，并且需要对反转列表进行额外的工作。 虽然对于约束仍然足够有效，但它使用了不必要的辅助空间。 

### 最佳解决方案的关键见解

 我们可以直接模拟遍历，而不是单独存储对角线。 

在任何时刻，我们都知道：

 - 我们目前的位置`(row, col)`- 当前移动方向

 只有两个方向：

 1. 右上：`(-1, +1)`2. 左下：`(+1, -1)`每当我们遇到边界时，我们都会小心地改变方向并重新定位：

 - 如果向右上方移动：

 - 撞到右边的墙意味着向下移动。 
- 撞到顶墙意味着向右移动。 
- 如果向左下移动：

 - 撞到底墙意味着向右移动。 
- 撞到左边的墙意味着向下移动。 

这避免了完全存储对角线并只处理每个元素一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m × n) | O(m × n) | 按对角线和反向交替组对元素进行分组 |
 | 最佳| O(m × n) | O(1) 不包括输出 | 通过边界处理直接模拟运动 |

 ## 算法演练

 1. 初始化矩阵维度。 

存储行数和列数：```
rows = len(mat)
cols = len(mat[0])
```遍历期间的边界检查需要这些值。 
2. 准备结果存储。 

创建一个空结果数组，该数组将按遍历顺序保存元素。 
3. 从左上角开始遍历。 

初始化：```
row = 0
col = 0
```这始终是第一个元素。 
4. 追踪运动方向。 

使用变量来表示方向：```
direction = 1
```在哪里：

-`1`意思是向右上方
 -`-1`意思是左下
 5. 准确处理`m × n`元素。 

由于每个单元格必须被访问一次，因此精确循环`rows * cols`次。 

在每次迭代期间：

 - 将当前元素附加到结果中。 
- 计算暂定的下一个位置。 
6. 处理向右上方的运动。 

如果向右上方移动：```
row -= 1
col += 1
```如果我们超出范围：

 - 右边界：```
col == cols
```向下移动一排并反转方向。 
- 顶部边界：```
row < 0
```重置为第一个有效行并反转方向。 
7. 处理左下运动。 

如果向左下移动：```
row += 1
col -= 1
```如果我们超出范围：

 - 底部边界：```
row == rows
```向右移动并反转方向。 
- 左边界：```
col < 0
```重置为第一个有效列并反转方向。 
8. 继续，直到访问完所有元素。 

由于每次迭代只添加一个元素，之后`m × n`迭代，结果就完成了。 

### 为什么它有效

 该算法保持不变式`(row, col)`始终指向下一个有效的矩阵单元。 每次移动都遵循所需的对角线方向，每当遇到边界时，算法都会在反转方向的同时转换到下一个对角线的正确起点。 由于每个单元格都被访问一次并且遍历顺序与对角线之字形规范匹配，因此最终输出是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def findDiagonalOrder(self, mat: List[List[int]]) -> List[int]:
        rows = len(mat)
        cols = len(mat[0])

        result = []
        row = 0
        col = 0
        direction = 1  # 1 = upward-right, -1 = downward-left

        for _ in range(rows * cols):
            result.append(mat[row][col])

            if direction == 1:
                row -= 1
                col += 1

                if col == cols:
                    col = cols - 1
                    row += 2
                    direction = -1
                elif row < 0:
                    row = 0
                    direction = -1

            else:
                row += 1
                col -= 1

                if row == rows:
                    row = rows - 1
                    col += 2
                    direction = 1
                elif col < 0:
                    col = 0
                    direction = 1

        return result
```实现首先确定矩阵维度并初始化遍历状态。 这`result`list 按访问顺序存储元素，而`row`和`col`跟踪当前位置。 

这`direction`变量控制运动。 值为`1`代表向右上方的运动，而`-1`代表左下运动。 

循环准确执行`rows * cols`次，保证每个矩阵元素都被处理一次。 在每次迭代时，当前单元格被附加到`result`。 

添加元素后，算法根据当前方向更新坐标。 如果移动退出矩阵边界，边界校正逻辑会将遍历移动到正确的下一个起点并翻转方向。 

例如，当向右上方移动并且遍历穿过右墙时，我们通过向下移动并切换到向左下方移动来重新定位。 所有四个边界都存在类似的修正。 

这种直接模拟避免了显式存储对角线并实现了最佳效率。 

## 解决方案```go
func findDiagonalOrder(mat [][]int) []int {
	rows := len(mat)
	cols := len(mat[0])

	result := make([]int, 0, rows*cols)

	row, col := 0, 0
	direction := 1 // 1 = upward-right, -1 = downward-left

	for i := 0; i < rows*cols; i++ {
		result = append(result, mat[row][col])

		if direction == 1 {
			row--
			col++

			if col == cols {
				col = cols - 1
				row += 2
				direction = -1
			} else if row < 0 {
				row = 0
				direction = -1
			}
		} else {
			row++
			col--

			if row == rows {
				row = rows - 1
				col += 2
				direction = 1
			} else if col < 0 {
				col = 0
				direction = 1
			}
		}
	}

	return result
}
```Go 实现遵循与 Python 版本完全相同的遍历逻辑。 

使用以下方法预先分配切片：```go
make([]int, 0, rows*cols)
```这避免了在附加元素时重复重新分配。 

与 Python 列表不同，Go 切片受益于显式容量预留以提高效率。 这里不关心整数溢出，因为矩阵元素的最大数量仅为`10^4`。 

由于 LeetCode 保证有效的非空矩阵，因此不需要对空输入进行特殊处理。

 ## 边缘情况

 ### 单行矩阵

 只有一行的矩阵很容易破坏对角线遍历逻辑，因为向上移动会立即触及边界。 例如：```
[[1,2,3,4]]
```预期的输出只是从左到右的遍历。 该实现自然地处理了这个问题，因为每个向右上方的移动都会立即触发顶部边界校正。 

### 单列矩阵

 单列矩阵带来了相反的挑战：```
[[1],
 [2],
 [3]]
```左下运动快速通过左边界退出。 不正确的边界处理可能会导致索引错误或重复元素。 该实现正确地将列重置为`0`并切换方向。 

### 矩形矩阵

 Non-square matrices are a common source of bugs because many implementations implicitly assume equal dimensions. 例如：```
[
 [1,2,3,4],
 [5,6,7,8]
]
```一些对角线终止于右边缘，而另一些对角线终止于下边缘。 该实现显式地独立检查所有四个矩阵边界，确保无论形状如何都能正确遍历。 

### 单元素矩阵

 最小有效输入：```
[[5]]
```一错就能暴露。 由于循环准确执行`m × n`有时，实现会处理单个值一次并干净地终止，而不会发生无效移动。
