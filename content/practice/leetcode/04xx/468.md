[LeetCode 468 题](https://leetcode.com/problems/validate-ip-address/)

 **难度：** 🟡 中等
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的字符串是否代表有效的 IPv4 地址、有效的 IPv6 地址，或者两者都不代表。 我们得到一个名为`queryIP`，并且我们必须返回三个确切的字符串之一：

 -`"IPv4"`如果输入是有效的 IPv4 地址
 -`"IPv6"`如果输入是有效的 IPv6 地址
 -`"Neither"`如果输入不满足任一格式

 IPv4 地址恰好由四个用点分隔的十进制数字组成 (`.`）。 每个数字必须满足几个严格的规则：

 - 该值必须介于`0`和`255`- 该段不能为空
 - 不允许使用前导零，除非该段本身恰好是`"0"`例如：

-`"192.168.1.1"`有效
 -`"01.2.3.4"`无效，因为`"01"`有一个前导零
 -`"256.1.1.1"`无效，因为`256 > 255`IPv6 地址由八个以冒号分隔的十六进制组组成（`:`）。 每组：

 - 必须包含 1 到 4 个字符
 - 可能包含数字`0-9`- 可能包含小写字母`a-f`- 可能包含大写字母`A-F`- 可能包含前导零

 例如：

 -`"2001:0db8:85a3:0:0:8A2E:0370:7334"`有效
 -`"02001:db8:85a3:0:0:8A2E:0370:7334"`无效，因为一组的长度为 5
 -`"2001:db8:85a3::8A2E:037j:7334"`无效，因为`j`不是十六进制

 由于输入只是单个字符串，因此约束相对较小。 这意味着运行时效率并不难实现，但正确性至关重要，因为存在许多边缘情况。 

一些边缘情况很容易破坏简单的实现：

 - 由连续分隔符引起的空段，例如`"1..1.1"`或者`"2001::1"`- 尾随分隔符，例如`"1.1.1.1."`- IPv4 中的前导零，例如`"192.168.01.1"`- IPv6 中无效的十六进制字符
 - 段数不正确
 - 混合分隔符，例如点和冒号在一起

 该问题保证字符串只包含字母、数字、`'.'`， 和`':'`，所以我们不需要担心其他特殊字符。 

## 方法

 暴力方法会尝试使用许多临时检查和重复转换将字符串解析为每种可能的 IP 格式。 例如，我们可以尝试每种分区可能性，重复验证数字范围，并手动重建地址。 虽然这最终会产生正确的答案，但它会变得不必要的复杂且容易出错。 它还引入了冗余工作，因为格式规则已经明确定义了字符串应如何分段。 

关键在于 IPv4 和 IPv6 都有严格的结构规则。 我们可以直接根据分隔符验证结构，而不是尝试任意解析策略：

 - 如果字符串包含点，则尝试 IPv4 验证
 - 如果字符串包含冒号，则尝试 IPv6 验证
 - 否则立即返回`"Neither"`对于 IPv4，分割为`.`必须恰好生产四个零件。 必须检查每个部件：

 - 非空
 - 仅限数字
 - 除非长度为 1，否则没有前导零
 - 数值范围内`[0, 255]`对于 IPv6，分割为`:`必须生产正好八个零件。 必须检查每个部件：

 - 长度在 1 到 4 之间
 - 所有字符都是有效的十六进制数字

 由于输入大小很小，并且每个字符最多被检查恒定次数，因此这种方法既简单又高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 反复的解析和重构尝试 |
 | 最佳| O(n) | O(n) | 分割后单次验证 |

 ## 算法演练

 1. 首先确定该字符串可能代表哪种格式。 

如果字符串包含一个点 (`.`），可能是 IPv4。 如果它包含冒号（`:`），可能是 IPv6。 如果它不包含任何格式或错误地混合了格式，则它无效。 
2. 对于 IPv4 验证，使用分割字符串`.`。 

有效的 IPv4 地址必须恰好产生四个段。 如果分割结果不包含四部分，则返回`"Neither"`立即地。 
3. 单独验证每个 IPv4 段。 

对于每个细分：

 - 确保它不为空
 - 确保每个字符都是数字
 - 当长度大于 1 时拒绝前导零
 - 将段转换为整数并确保它位于`0`和`255`如果任何段失败，则该地址无效。 
4. 如果所有 IPv4 段都通过验证，则返回`"IPv4"`。 

至此，所有结构和数字要求均已满足。 
5. 对于 IPv6 验证，使用分割字符串`:`。 

有效的 IPv6 地址必须恰好产生八个组。 任何其他计数都会立即使该地址无效。 
6. 验证每个 IPv6 组。 

对于每个组：

 - 确保其长度在 1 到 4 之间
 - 确保每个字符都属于十六进制集：`0123456789abcdefABCDEF`允许使用前导零，因此不需要特殊处理。 
7. 如果所有 IPv6 组都通过验证，则返回`"IPv6"`。 
8. 如果两个验证器都没有成功，则返回`"Neither"`。 

### 为什么它有效

 该算法之所以有效，是因为两种 IP 格式完全由严格的结构规则定义。 IPv4 需要正好四个小数段，且数字范围有限并且没有前导零。 IPv6 需要正好八个长度有限的十六进制组。 通过直接检查每条规则并在违反时立即拒绝，该算法保证只接受格式正确的地址。 

## Python 解决方案```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        
        def is_ipv4(ip: str) -> bool:
            parts = ip.split(".")
            
            if len(parts) != 4:
                return False
            
            for part in parts:
                if len(part) == 0:
                    return False
                
                if not part.isdigit():
                    return False
                
                if len(part) > 1 and part[0] == "0":
                    return False
                
                value = int(part)
                
                if value < 0 or value > 255:
                    return False
            
            return True
        
        def is_ipv6(ip: str) -> bool:
            hex_chars = set("0123456789abcdefABCDEF")
            
            parts = ip.split(":")
            
            if len(parts) != 8:
                return False
            
            for part in parts:
                if len(part) == 0 or len(part) > 4:
                    return False
                
                for char in part:
                    if char not in hex_chars:
                        return False
            
            return True
        
        if "." in queryIP and is_ipv4(queryIP):
            return "IPv4"
        
        if ":" in queryIP and is_ipv6(queryIP):
            return "IPv6"
        
        return "Neither"
```该实现分为两个辅助函数，一个用于 IPv4 验证，另一个用于 IPv6 验证。 这种分离保持逻辑清晰并直接反映问题陈述。 

这`is_ipv4`函数首先将字符串分成四个部分。 它在单独检查每个段之前验证段计数。 每个段必须非空，仅包含数字，避免前导零，并保持在数字范围内`[0, 255]`。 

这`is_ipv6`函数类似地将字符串分为八组。 每个组的长度必须介于 1 和 4 之间，并且完全由十六进制字符组成。 

然后，main 方法检查该字符串是否类似于 IPv4 或 IPv6，并调用相应的验证器。 如果验证均未成功，则函数返回`"Neither"`。 

## 解决方案```go
package main

import (
	"strconv"
	"strings"
)

func validIPAddress(queryIP string) string {

	isIPv4 := func(ip string) bool {
		parts := strings.Split(ip, ".")

		if len(parts) != 4 {
			return false
		}

		for _, part := range parts {

			if len(part) == 0 {
				return false
			}

			if len(part) > 1 && part[0] == '0' {
				return false
			}

			for _, ch := range part {
				if ch < '0' || ch > '9' {
					return false
				}
			}

			value, err := strconv.Atoi(part)

			if err != nil || value < 0 || value > 255 {
				return false
			}
		}

		return true
	}

	isIPv6 := func(ip string) bool {
		parts := strings.Split(ip, ":")

		if len(parts) != 8 {
			return false
		}

		for _, part := range parts {

			if len(part) == 0 || len(part) > 4 {
				return false
			}

			for _, ch := range part {
				isDigit := ch >= '0' && ch <= '9'
				isLower := ch >= 'a' && ch <= 'f'
				isUpper := ch >= 'A' && ch <= 'F'

				if !isDigit && !isLower && !isUpper {
					return false
				}
			}
		}

		return true
	}

	if strings.Contains(queryIP, ".") && isIPv4(queryIP) {
		return "IPv4"
	}

	if strings.Contains(queryIP, ":") && isIPv6(queryIP) {
		return "IPv6"
	}

	return "Neither"
}
```Go 实现遵循与 Python 版本相同的整体结构，但有一些特定于语言的细节。 

Go 没有内置的`isdigit()`方法，因此使用字符比较手动执行数字验证。 同样，十六进制验证对数字和大写或小写字母使用显式范围检查。 

整数转换使用以下方法处理`strconv.Atoi`，它返回解析的整数和错误值。 这使得无效的数字解析很容易被安全地检测到。 

返回的切片`strings.Split`行为与 Python 列表类似，因此分段逻辑仍然简单。

 ## 边缘情况

 一种重要的边缘情况是 IPv4 段中的前导零。 许多实现错误地接受诸如`"192.168.01.1"`因为转换`"01"`到一个整数产生`1`，这在数值上是有效的。 然而，这个问题明确禁止前导零，除非该段完全是`"0"`。 该实现通过检查段长度是否超过 1 来处理此问题`'0'`。 

另一个关键的边缘情况是由连续分隔符或尾随分隔符引起的空段。 输入如`"1..1.1"`或者`"1.1.1.1."`分割后产生空字符串。 天真的解析器可能会意外地忽略这些。 该实现显式检查零长度段并立即拒绝它们。 

第三个重要的边缘情况是 IPv6 地址中的无效十六进制字符。 IPv6 组只能包含数字和字母`a-f`或者`A-F`。 输入如`"2001:db8:85a3:0:0:8A2E:0370:zzzz"`看起来结构正确但包含无效字符。 该实现根据允许的十六进制集单独验证每个字符，确保正确性。 

最后一个微妙的边缘情况是不正确的段计数。 IPv4 必须恰好包含四个段，而 IPv6 必须恰好包含八个组。 即使所有单独的部分看起来都是正确的，分隔符过多或过少的输入也是无效的。 该实现在进行任何更深入的检查之前验证段计数，以防止格式错误的地址漏掉。
