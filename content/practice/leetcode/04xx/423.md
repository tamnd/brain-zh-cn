 **难度：** 🟡 中等
 **主题：** 哈希表、数学、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们从代表数字的混乱英文字母字符串中重建数字`0`到`9`。 输入字符串`s`仅包含集合中的字符`["e","g","f","i","h","o","n","s","r","u","t","w","v","x","z"]`，对应于英语单词中用于数字的字母（`"zero"`,`"one"`,`"two"`， ETC。）。 输入中字母的顺序是任意的，如果数字重复，某些字母可能会出现多次。 

预期输出是一个字符串，其中包含输入中存在的所有数字，并按升序排序。 例如，如果`s = "owoztneoer"`，字母可以重新排列形成`"one"`,`"zero"`， 和`"two"`，所以输出应该是`"012"`。 

约束告诉我们输入可以很长（`1 <= s.length <= 10^5`），但保证有效，这意味着每个字母都构成有效数字。 要考虑的边缘情况包括所有字母对应于单个数字的字符串、数字重复多次的字符串以及最小输入长度 1。 

## 方法

 暴力方法会尝试生成输入字母的所有排列并将它们与单词进行匹配`"zero"`通过`"nine"`。 这保证了正确性，因为它检查了每种可能的排列，但在计算上是不可行的，因为排列的阶乘增长对于上限来说太大了`s.length = 10^5`。 

最佳方法利用了一些数字包含与其英文表示**唯一**的字母的观察结果。 例如，`z`只出现在`"zero"`,`w`只出现在`"two"`,`u`仅在`"four"`,`x`仅在`"six"`， 和`g`仅在`"eight"`。 通过首先计算这些唯一字母，我们可以确定其中出现了多少个数字。 处理完这些后，可以通过减去已经计算出的字母来推导出剩余的数字。 这种方法完全避免了排列，并将问题简化为计算字母和简单的算术。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成针对数字单词的所有排列和匹配。 对于大输入不可行。 |
 | 最佳 | O(n) | O(1) | O(1) | 计算字母数、通过唯一标记识别数字、减去已计算的字母、对结果进行排序。 |

 ## 算法演练

 1.初始化输入字符串中字符的频率图`s`。 这样可以快速查找每个字母出现的次数。 
2. 识别具有**唯一字母**的数字：`"z"`→ 0,`"w"`→ 2,`"u"`→ 4,`"x"`→ 6,`"g"`→ 8. 计算这些字母的出现次数并存储相应的位数。 
3. 使用出现在多个数字中的字母处理剩余的数字，减去已经计算在内的字母：

 -`"h"`出现在`"three"`和`"eight"`，所以 3 的计数是`count(h) - count(8)`。 
-`"f"`出现在`"five"`和`"four"`，所以 5 的计数是`count(f) - count(4)`。 
-`"s"`出现在`"seven"`和`"six"`，所以 7 的计数是`count(s) - count(6)`。 
-`"o"`出现在`"one"`,`"zero"`,`"two"`， 和`"four"`，所以 1 的计数是`count(o) - count(0) - count(2) - count(4)`。 
-`"i"`出现在`"nine"`,`"five"`,`"six"`， 和`"eight"`，所以 9 的计数是`count(i) - count(5) - count(6) - count(8)`。 
4. 通过按升序重复每个数字出现的次数来创建结果字符串。 
5. 返回结果字符串。 

**为什么有效**：通过首先识别具有唯一字母的数字，我们建立了几个数字的基线计数。 剩余的数字可以通过减去已经处理的数字的计数来唯一确定。 这可确保每个字母只计算一次，从而保证正确的重建。 

## Python 解决方案```python
from collections import Counter

class Solution:
    def originalDigits(self, s: str) -> str:
        count = Counter(s)
        out = {}

        out[0] = count['z']
        out[2] = count['w']
        out[4] = count['u']
        out[6] = count['x']
        out[8] = count['g']

        out[3] = count['h'] - out[8]
        out[5] = count['f'] - out[4]
        out[7] = count['s'] - out[6]
        out[1] = count['o'] - out[0] - out[2] - out[4]
        out[9] = count['i'] - out[5] - out[6] - out[8]

        result = ''.join(str(i) * out[i] for i in range(10))
        return result
```Python 代码首先使用以下方法计算所有字母`Counter`。 唯一的字母可以立即识别数字 0、2、4、6 和 8。后续数字是通过消除已计算数字的影响来计算的。 最后，通过根据频率重复每个数字，按升序构造输出。 

## 解决方案```go
func originalDigits(s string) string {
    count := make(map[rune]int)
    for _, ch := range s {
        count[ch]++
    }

    out := make([]int, 10)
    out[0] = count['z']
    out[2] = count['w']
    out[4] = count['u']
    out[6] = count['x']
    out[8] = count['g']

    out[3] = count['h'] - out[8]
    out[5] = count['f'] - out[4]
    out[7] = count['s'] - out[6]
    out[1] = count['o'] - out[0] - out[2] - out[4]
    out[9] = count['i'] - out[5] - out[6] - out[8]

    result := ""
    for i := 0; i <= 9; i++ {
        for j := 0; j < out[i]; j++ {
            result += string(rune('0' + i))
        }
    }
    return result
}
```Go 的实现与 Python 非常相似，使用`map[rune]int`为频率计数。 切片用于存储位数，字符串连接用于组合最终输出。 不存在 nil 问题，因为 Go 中的映射对于缺少的键返回零。
