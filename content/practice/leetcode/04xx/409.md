[LeetCode 第 409 题](https://leetcode.com/problems/longest-palindrome/)

 **难度：** 🟢简单

 ## 解决方案

 ## 问题理解

 该问题要求我们找到可以使用给定字符串的字符构造的**最长回文**的长度`s`。 回文是向前和向后读取相同的字符串。 输入字符串`s`仅包含小写和大写英文字母，并且字母大小写很重要，因此`'A'`和`'a'`是不同的字符。 输出是一个整数，表示我们可以形成的回文的最大长度。 

例如，如果输入是`"abccccdd"`，一种可能的回文是`"dccaccd"`，其长度为 7。这表明该解决方案不需要返回实际的回文数，只返回其长度。 

关键限制是字符串长度在 1 到 2000 之间，这使我们能够考虑具有线性或接近线性时间复杂度的解决方案。 边缘情况包括包含所有唯一字符的字符串、包含所有相同字符的字符串或长度为 1 的字符串。 

## 方法

 暴力方法将涉及生成字符串的所有排列并检查每个排列是否是回文，然后跟踪最长的排列。 这保证了正确的答案，因为它详尽地搜索了所有可能性。 然而，时间复杂度是阶乘，O(n!)，使得 n = 2000 时不可行。 

最佳解决方案的关键观察是回文可以在两侧对称地使用**字符对**。 出现偶数次的字符可以完全贡献回文数，而出现奇数次的字符可以贡献回文数`count - 1`。 我们还可以在中间放置一个奇数的单个字符，将回文长度增加 1。 

我们可以使用哈希映射（或字典）来计算每个字符的出现次数，迭代计数，对偶数贡献进行求和，并跟踪中心位置是否存在奇数计数。 这将问题的时间和空间复杂度降低到 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 生成所有排列并检查每个排列的回文 |
 | 最佳 | O(n) | O(n) | 计算字符和总和对，可选中心奇数计数 |

 ## 算法演练

 1.初始化一个哈希图（字典）来统计字符串中每个字符的出现频率`s`。 
2. 迭代字符串`s`，更新地图中每个字符的计数。 
3. 初始化变量`length`到 0。这将存储回文的总长度。 
4. 初始化布尔标志`odd_found`为 False，这将指示我们是否有任何具有奇数计数的字符。 
5. 迭代所有字符数：

 - 如果计数为偶数，则直接相加`length`因为它可以完全促成回文。 
- 如果计数为奇数，则添加`count - 1`到`length`包括最大的偶数部分。 放`odd_found`为真。 
6. 处理完所有计数后，如果`odd_found`为真，增量`length`用1来占中心人物。 
7. 返回`length`作为最长回文的长度。 

**为什么有效**：该算法确保所有字符对都围绕中心对称使用。 中间最多可以有一个奇数字符，这就是为什么如果存在奇数个字符我们就加 1。 该方法保证最大长度，因为每个字符对回文的贡献要么完全（偶数）要么最大减一（奇数）。 

## Python 解决方案```python
class Solution:
    def longestPalindrome(self, s: str) -> int:
        from collections import Counter
        
        char_count = Counter(s)
        length = 0
        odd_found = False
        
        for count in char_count.values():
            if count % 2 == 0:
                length += count
            else:
                length += count - 1
                odd_found = True
        
        if odd_found:
            length += 1
        
        return length
```这个Python实现使用`Counter`有效地计算字符。 计数循环区分偶数和奇数出现，将对求和`length`。 这`odd_found`flag 确保单个奇数字符可以放置在中心。 

## 解决方案```go
func longestPalindrome(s string) int {
    charCount := make(map[rune]int)
    for _, ch := range s {
        charCount[ch]++
    }
    
    length := 0
    oddFound := false
    
    for _, count := range charCount {
        if count%2 == 0 {
            length += count
        } else {
            length += count - 1
            oddFound = true
        }
    }
    
    if oddFound {
        length++
    }
    
    return length
}
```在 Go 中，我们使用`map[rune]int`来计算字符数。 迭代`s`as runes 确保正确处理每个字符。 该逻辑反映了 Python，处理偶数和奇数计数，并在需要时添加中心字符。

 ## 边缘情况

 **单个字符串**：如果`s`只有一个字符，回文长度为1。这是通过初始化来处理的`length = 0`如果存在奇数则加 1。 

**所有字符唯一**：如果每个字符只出现一次，则最长回文长度为 1，因为中间只能有一个字符。 该算法正确识别单个奇数计数并加 1。 

**区分大小写**：字符如`'A'`和`'a'`是不同的。 单独计算它们可以确保算法不会错误地将它们配对，从而保持混合大小写输入的正确性。 

此方法系统地处理奇数和偶数计数的所有其他组合，保证任何有效字符串的最大回文长度。
