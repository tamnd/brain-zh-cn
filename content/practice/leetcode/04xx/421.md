 # LeetCode 421 - 数组中两个数字的最大异或

 ## 问题理解

 该问题给了我们一个非负整数数组，称为`nums`。 我们必须选择两个指数`i`和`j`这样`0 <= i <= j < n`，然后计算：```
nums[i] XOR nums[j]
```目标是返回可以从数组中的任何对生成的最大 XOR 值。 

XOR 运算逐位置比较位：

 -`0 XOR 0 = 0`-`1 XOR 1 = 0`-`0 XOR 1 = 1`-`1 XOR 0 = 1`这意味着当两个数字在高位位置不同时，XOR 会变大。 例如：```
5  = 00101
25 = 11001
XOR= 11100 = 28
```输入数组最多可以包含`2 * 10^5`数字，每个数字可以大到`2^31 - 1`。 这些约束很重要，因为它们立即排除了大输入的缓慢二次解。 

检查每一对的简单解决方案需要：```
O(n^2)
```比较，当`n = 200000`。 

该问题保证：

 - 数组中至少存在一个数字
 - 所有数字均为非负数
 - 值适合 31 位

 重要的边缘情况包括仅具有一个元素的数组、所有数字都相同的数组、包含零的数组以及最大 XOR 取决于不同的高位而不是低位的数组。 

## 方法

 ### 蛮力方法

 最直接的解决方案是尝试每对可能的数字。 

对于每个索引`i`，我们迭代每个索引`j >= i`，计算：```
nums[i] XOR nums[j]
```并跟踪迄今为止看到的最大结果。 

这是有效的，因为它会详尽地检查所有有效组合，因此不能错过最大的 XOR 值。 

然而，时间复杂度为：```
O(n^2)
```和`200000`元素，这大致需要：```
200000^2 = 40,000,000,000
```在最坏的情况下，操作速度太慢了。 

### 最优方法，按位 Trie

 关键的见解是，当相应位不同时，XOR 会变大。 

为了最大化一个数字的异或，我们希望尽可能找到另一个其位相反的数字。 

例如，如果当前位是：

 -`1`，我们更喜欢将其与`0`-`0`，我们更喜欢将其与`1`由于数字是用二进制表示的，因此我们可以从最高有效位到最低有效位逐位处理它们。 

Trie（也称为前缀树）非常适合此目的，因为它根据二进制表示形式存储数字。 Trie 的每一层对应一个位位置。 

为某个数字搜索最佳异或伙伴时：

 - 在每个位位置，我们贪婪地尝试移动到相反的位
 - 如果存在相反的位，我们得到`1`在该位置的 XOR 结果中
 - 否则，我们移动到相同的位

 这种贪婪的选择之所以有效，是因为较高的位比较低的位对最终数值的贡献更大。

 ## 算法演练

 ### 第 1 步：构建二进制 Trie

 我们创建一个 Trie，其中每个节点有两个可能的子节点：

 -`0`-`1`每个数字从第 31 位一直到第 0 位逐位插入。 

我们使用 31 位是因为约束保证值适合有符号的 32 位整数。 

例如，数字`5`变成：```
000...00101
```每一位都决定我们移动到 Trie 中的哪个子节点。 

### 第 2 步：插入每个数字

 当我们处理数组时，我们将每个数字插入到 Trie 中。 

这通过二进制前缀来组织数字，从而允许以后进行有效的按位搜索。 

### 第 3 步：寻找最佳异或合作伙伴

 对于每个数字，我们再次遍历 Trie。 

在每个位位置：

 1. 提取当前位
 2. 计算相反位
 3.先尝试移动到相反的位
 4. 如果存在，则将对应的XOR位设置为`1`5. 否则移至同一位

 这种贪心策略首先最大化高阶位，这保证了最大的数字异或值。 

### 步骤 4：跟踪最大异或

 对于每个数字，我们都会根据 Trie 中已有的数字计算其最佳可能的异或值。 

我们不断更新全局最大值。 

### 步骤5：返回最终结果

 处理完所有数字后，存储的最大值就是答案。 

### 为什么它有效

 该算法之所以有效，是因为当位在最高可能位置不同时，XOR 被最大化。 Trie 使我们能够有效地搜索每个级别的最佳互补位。 由于我们从最重要到最不重要的顺序处理位，因此较高位置的贪婪选择总是主导任何后续选择。 因此，构造的 XOR 值对于每个数字都是最佳的，并且在所有数字中取最大值会产生正确的最终答案。 

## Python 解决方案```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        root = TrieNode()

        def insert(num: int) -> None:
            node = root

            for bit_position in range(31, -1, -1):
                bit = (num >> bit_position) & 1

                if bit not in node.children:
                    node.children[bit] = TrieNode()

                node = node.children[bit]

        def find_best_xor(num: int) -> int:
            node = root
            current_xor = 0

            for bit_position in range(31, -1, -1):
                bit = (num >> bit_position) & 1
                opposite_bit = 1 - bit

                if opposite_bit in node.children:
                    current_xor |= (1 << bit_position)
                    node = node.children[opposite_bit]
                else:
                    node = node.children[bit]

            return current_xor

        for num in nums:
            insert(num)

        maximum_xor = 0

        for num in nums:
            maximum_xor = max(maximum_xor, find_best_xor(num))

        return maximum_xor
```该解决方案首先定义一个`TrieNode`班级。 每个节点存储二进制数字的子指针`0`和`1`。 

这`insert`函数将一个数字一次一位地放入 Trie 中。 我们从位开始迭代`31`下降到`0`，使用以下方法提取每一位：```python
(num >> bit_position) & 1
```如果对应的子节点不存在，我们就创建它。 

这`find_best_xor`函数执行贪心异或搜索。 在每个位位置，我们尝试向相反的位移动，因为相反的位会产生`1`在异或中。 当存在这样的分支时，我们使用以下方法更新当前的 XOR 值：```python
current_xor |= (1 << bit_position)
```这会设置 XOR 结果中的当前位。 

如果相反的分支不存在，我们就沿着匹配的位分支移动。 

在使用所有数字构建 Trie 后，我们查询 Trie 中的每个数字并保留遇到的最大 XOR。 

## 解决方案```go
package main

type TrieNode struct {
	children [2]*TrieNode
}

func insert(root *TrieNode, num int) {
	node := root

	for bitPosition := 31; bitPosition >= 0; bitPosition-- {
		bit := (num >> bitPosition) & 1

		if node.children[bit] == nil {
			node.children[bit] = &TrieNode{}
		}

		node = node.children[bit]
	}
}

func findBestXOR(root *TrieNode, num int) int {
	node := root
	currentXOR := 0

	for bitPosition := 31; bitPosition >= 0; bitPosition-- {
		bit := (num >> bitPosition) & 1
		oppositeBit := 1 - bit

		if node.children[oppositeBit] != nil {
			currentXOR |= (1 << bitPosition)
			node = node.children[oppositeBit]
		} else {
			node = node.children[bit]
		}
	}

	return currentXOR
}

func findMaximumXOR(nums []int) int {
	root := &TrieNode{}

	for _, num := range nums {
		insert(root, num)
	}

	maximumXOR := 0

	for _, num := range nums {
		current := findBestXOR(root, num)

		if current > maximumXOR {
			maximumXOR = current
		}
	}

	return maximumXOR
}
```Go 实现遵循与 Python 版本相同的算法结构。 Go 不使用子节点的字典，而是使用固定大小的数组：```go
children [2]*TrieNode
```由于只有两个可能的分支，因此内存效率更高且速度更快。 

Go 整数在给定约束下安全地支持所需的位操作。 Nil 指针检查取代了 Python 字典成员资格检查。

 ## 边缘情况

 ### 单元素数组

 如果数组仅包含一个数字，则唯一有效的对是该数字与其自身：```
x XOR x = 0
```有缺陷的实现可能会错误地假设需要两个不同的数字。 该解决方案可以自然地处理这种情况，因为 Trie 包含正在查询的相同数字。 

### 所有数字都相同

 考虑：```
[7,7,7]
```每个 XOR 结果都等于 0，因为相同的位在 XOR 中总是产生零。 

某些实现错误地尝试在 Trie 中强制使用不同的路径，即使不存在路径也是如此。 当相反的分支不可用时，该实现安全地回退到匹配的位分支。 

### 具有大高位的数字

 考虑：```
[2147483647, 0]
```最大异或完全来自高位。 

一个常见的错误是迭代的位位置太少。 该实现处理来自的所有 32 个相关位`31`下降到`0`，确保正确处理大值。 

### 包含零的数组

 零很重要，因为：```
0 XOR x = x
```有时，最大异或包括与大值配对的零。 

Trie 正确地将零存储为完全由以下内容组成的路径`0`位，允许与任何其他数字进行比较，无需特殊处理。
