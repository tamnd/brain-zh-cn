 # LeetCode 478 - 生成圆中的随机点

 ## 问题理解

 这个问题要求我们在圆内均匀地生成随机点。 圆由其半径和圆心坐标定义。 每次致电`randPoint()`必须返回一个点`[x, y]`使得该点要么位于圆内，要么正好位于其边界上。 

关键要求是均匀随机性。 这意味着圆内每个面积相等的区域必须具有相同的包含生成点的概率。 这个要求比最初看起来更加微妙。 即使所有生成的点在技术上都位于圆内，简单的实现也很容易引入偏差。 

输入由三个浮点值组成：

 -`radius`, 圆的半径
 -`x_center`, 中心的 x 坐标
 -`y_center`, 中心的 y 坐标

 的输出`randPoint()`是圆内随机生成的坐标对。 

约束很重要，因为它们告诉我们期望什么样的解决方案。 半径可以非常大，可达`10^8`，但这不会对复杂性产生有意义的影响，因为我们没有迭代圆的面积。 来电次数`randPoint()`至多是`3 * 10^4`，这意味着每次调用理想情况下应该以恒定的时间运行。 

最大的边缘情况之一是确保真正的一致性。 一个常见的错误是统一选择半径`[0, r]`。 这种方法在中心附近创建了更高密度的点，因为面积随半径呈二次方增长。 另一个重要的考虑因素是浮点精度，因为输出坐标是浮点值。 该问题保证有效的正半径值，因此我们不需要处理退化圆。 

## 方法

 ### 蛮力方法

 一种直接的方法是拒绝抽样。 我们在包围圆的正方形内生成随机点，然后丢弃落在圆外的点。 

边界正方形的范围为：

 -`x_center - radius`到`x_center + radius`-`y_center - radius`到`y_center + radius`对于每个生成的点`(x, y)`，我们计算：```
(x - x_center)^2 + (y - y_center)^2
```如果该值小于或等于`radius^2`，该点位于圆内，我们将其返回。 否则，我们会生成另一个点。 

这种方法是正确的，因为接受的点均匀分布在圆上。 然而，它的效率很低，因为许多生成的点被丢弃。 圆圈只占大约`π/4 ≈ 78.5%`边界平方，意味着平均大约 21.5% 的样本被浪费。 

### 最佳方法

 更好的解决方案是直接使用极坐标生成圆内的点。 

圆内的点可以表示为：$x=x_{center}+r\cos(\theta),\quad y=y_{center}+r\sin(\theta)$角度`θ`应该统一选择`[0, 2π)`。 

关键的见解涉及半径。 如果我们选择`r`统一从`[0, radius]`，分布变得偏向中心。 发生这种情况是因为较大的半径对应于较大的圆形区域。 

为了实现均匀的区域分布，我们生成：$r=R\sqrt{u}$在哪里：

-`R`是圆的半径
 -`u`是一个均匀随机值`[0, 1)`平方根补偿面积的二次增长。 

该方法在恒定时间内直接在圆内生成点，不会被拒绝。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(1) 平均 | O(1) | O(1) | 采用剔除抽样，将样品浪费在圈外 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 使用极坐标直接生成均匀分布的点 |

 ## 算法演练

 1. 将半径和中心坐标存储在构造函数中，以便以后每次调用时都可以使用它们`randPoint()`。 
2. 生成随机角度`theta`之间均匀地`0`和`2π`。 从中心开始的每个方向的可能性都必须相同。 
3. 生成随机值`u`之间均匀地`0`和`1`。 
4. 使用以下公式计算距中心的实际距离：$r=R\sqrt{u}$此步骤对于实现均匀的区域覆盖至关重要。 
5. 使用以下方法将极坐标转换为笛卡尔坐标：$x=x_{center}+r\cos(\theta),\quad y=y_{center}+r\sin(\theta)$6. 将生成的点返回为`[x, y]`。 

### 为什么它有效

 该算法之所以有效，是因为概率密度与圆的几何形状相匹配。 以半径为圆的面积`r`正比于`r²`。 通过将半径生成为`sqrt(u) * R`，我们确保在任何子区域内着陆的概率仅取决于其面积，而不是其距中心的距离。 由于角度也是均匀分布的，因此最终的点分布在整个圆上是均匀的。 

## Python 解决方案```python
import math
import random
from typing import List

class Solution:

    def __init__(self, radius: float, x_center: float, y_center: float):
        self.radius = radius
        self.x_center = x_center
        self.y_center = y_center

    def randPoint(self) -> List[float]:
        theta = random.uniform(0, 2 * math.pi)

        random_radius = self.radius * math.sqrt(random.random())

        x = self.x_center + random_radius * math.cos(theta)
        y = self.y_center + random_radius * math.sin(theta)

        return [x, y]
```构造函数将圆参数存储为实例变量，以便可以在每次随机点生成时有效地重用它们。 

里面`randPoint()`，该算法首先生成一个随机角度`0`和`2π`。 这保证了所有方向都有相同的可能性。 

接下来，该方法使用以下方法计算半径`sqrt(random.random())`。 这是解决方案中最重要的部分，因为它校正分布以考虑圆形面积的增长。 

最后，该方法利用三角函数将极坐标转换为笛卡尔坐标，并将结果偏移圆心。 

由于数学自然地对问题的几何形状进行了建模，因此实现很紧凑。 

## 解决方案```go
package main

import (
	"math"
	"math/rand"
)

type Solution struct {
	radius  float64
	xCenter float64
	yCenter float64
}

func Constructor(radius float64, x_center float64, y_center float64) Solution {
	return Solution{
		radius:  radius,
		xCenter: x_center,
		yCenter: y_center,
	}
}

func (this *Solution) RandPoint() []float64 {
	theta := rand.Float64() * 2 * math.Pi

	randomRadius := this.radius * math.Sqrt(rand.Float64())

	x := this.xCenter + randomRadius*math.Cos(theta)
	y := this.yCenter + randomRadius*math.Sin(theta)

	return []float64{x, y}
}

/**
 * Your Solution object will be instantiated and called as such:
 * obj := Constructor(radius, x_center, y_center);
 * param_1 := obj.RandPoint();
 */
```Go 的实现与 Python 解决方案非常相似。 该结构体存储圆参数，并且`RandPoint()`在将极坐标转换为笛卡尔坐标之前生成随机极坐标。 

Go 特有的一个细节是使用`float64`整个实施过程中。 由于所有几何计算都涉及浮点运算，`float64`是自然的选择。 

该方法返回一个切片`float64`值而不是固定数组，因为它与所需的 LeetCode 签名相匹配。

 ## 边缘情况

 一个重要的边缘情况是半径非常小。 当坐标非常接近时，浮点精度误差可能会变得明显。 该实现自然地处理了这个问题，因为所有计算都一致地使用浮点算术，并且无论半径大小如何，距离缩放在数学上都保持有效。 

另一个重要的情况是圆心不在原点的圆。 一个常见的错误是在周围正确生成点`(0, 0)`但忘记通过中心坐标来平移它们。 该实现明确添加了`x_center`和`y_center`将极坐标转换为笛卡尔坐标后，确保定位正确。 

更微妙的边缘情况涉及分布正确性。 如果均匀选择半径而不进行平方根变换，点将聚集在中心附近。 这是此问题的解决方案中最常见的错误之一。 该实现通过缩放半径来避免这种情况`sqrt(u)`，保证了整个圆的面积分布均匀。
