[LeetCode 第 422 题](https://leetcode.com/problems/valid-word-square/)

 **难度：** 🟢简单
 **主题：** 数组、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的字符串列表是否形成有效的**单词方块**。 单词方块是单词的特殊排列，使得`kth`行和`kth`对于每个有效索引，列包含相同的字母序列`k`。 本质上，如果您水平阅读单词为行，垂直阅读单词为列，则字母必须匹配。 

输入`words`是一个字符串数组，其中每个字符串代表潜在单词方块中的一行。 长度为`words`（`numRows`) 不一定等于字符串的长度 (`numColumns`），但算法必须确保对于任何`k`， 这`kth`行和列对齐。 输出是一个布尔值：`true`如果这些单词形成一个有效的单词方块并且`false`否则。 

这些约束告诉我们，单词数和任何单词的长度最多可达 500，这意味着解决方案必须有效处理最多 500x500 的字符比较。 输入保证所有字符都是小写英文字母。 

关键边缘情况包括长度不等的行、短于单词数的行或空字符串。 如果不小心处理，这些可能会破坏简单的行列比较。 

## 方法

 **暴力方法**将为每个索引显式构造列字符串`k`并将它们与相应的行字符串进行比较。 这是有效的，因为它直接验证单词方块的定义，但它需要构造额外的字符串并重复迭代所有字符。 虽然正确，但对于最大的输入大小可能效率低下。 

**最佳方法**通过就地比较字符来避免构造新字符串。 对于每一行`i`以及每个角色`j`在该行中，我们直接比较`words[i][j]`和`words[j][i]`如果两个索引都存在。 这种方法利用了这样的见解：我们只需要验证相应字符的相等性，而不是整个字符串，这减少了开销并简化了逻辑。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n * m) | 构造每个列字符串并与行 | 进行比较
 | 最佳| O(n * m) | O(1) | O(1) | 直接比较字符，无需额外存储 |

 这里，`n`是单词数，`m`是单词的最大长度。 

## 算法演练

 1.确定行数`numRows`作为`len(words)`。 
2. 迭代每一行`i`从 0 到`numRows - 1`。 
3.对于每个字符索引`j`在行中`i`，检查是否`j`是有效的行索引（`j < numRows`）和行的长度`j`就足够了（`len(words[j]) > i`）。 如果任一检查失败，则单词 square 无效，因此返回`false`。 
4. 比较字符`words[i][j]`和`words[j][i]`。 如果不相等，则square这个词无效，所以返回`false`。 
5. 如果所有比较都通过，则返回`true`。 

**为什么有效：** 该算法确保每个字符位置`(i, j)`，行和列字符相同。 此属性保证每一行与相应的列匹配，满足有效单词方块的定义。 

## Python 解决方案```python
from typing import List

class Solution:
    def validWordSquare(self, words: List[str]) -> bool:
        numRows = len(words)
        for i in range(numRows):
            for j in range(len(words[i])):
                if j >= numRows or i >= len(words[j]) or words[i][j] != words[j][i]:
                    return False
        return True
```Python 实现首先计算行数。 它迭代每一行和字符，执行边界检查以确保行和列都存在。 如果发生任何字符不匹配或越界情况，则立即返回`false`。 否则，完成所有迭代后，返回`true`。 

## 解决方案```go
func validWordSquare(words []string) bool {
    numRows := len(words)
    for i := 0; i < numRows; i++ {
        for j := 0; j < len(words[i]); j++ {
            if j >= numRows || i >= len(words[j]) || words[i][j] != words[j][i] {
                return false
            }
        }
    }
    return true
}
```Go 实现镜像了 Python 版本。 切片自然地处理可变长度的行，并且边界检查可以防止超出范围的恐慌。 主要区别在于显式索引和切片迭代，而不是 Python 的动态 for-in 循环。

 ## 边缘情况

 **不相等的行长度：**如果行有不同的长度，访问`words[j][i]`可能超出范围。 该解决方案明确检查`i < len(words[j])`以防止出现此错误。 

**单行/列：** 根据定义，单字符单词或单行数组是有效的正方形。 该算法自然地通过迭代可用索引来处理这个问题。 

**空字符串：** 行可能包含空字符串，这是索引的边缘情况。 算法正确返回`true`如果所有检查都通过，因为这些行中不存在字符不匹配。 

这种仔细的处理确保了不同输入形状的正确性。
