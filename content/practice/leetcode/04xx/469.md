 ## 解决方案

 ## 问题理解

 该问题为我们提供了二维平面上的一系列点。 这些点按顺序连接，最后一个点连接回第一个点，形成一个多边形。 我们的任务是确定该多边形是否是凸多边形。 

如果每个内角都小于 180 度，则多边形是凸多边形。 另一个等效的几何属性是，在按顺序遍历多边形时，每次转弯都必须发生在同一方向。 换句话说，多边形必须始终顺时针或逆时针旋转。 

例如，正方形是凸的，因为每个角都朝同一方向弯曲。 然而，具有向内凹陷的多边形不是凸多边形，因为至少有一个角向相反方向弯曲。 

输入是一个数组`points`，其中每个元素包含坐标`[x, y]`一个顶点的。 顶点已按顺时针或逆时针遍历顺序给出。 该问题保证多边形是简单的，这意味着边仅在相邻顶点处相交，而不会在其他地方相互交叉。 这种保证很重要，因为自相交的多边形需要额外的几何处理。 

约束允许最多`10^4`点，这意味着解决方案必须是有效的。 一个`O(n)`或者`O(n log n)`解决方案是可以接受的，但是`O(n^2)`或者更糟糕的方法可能会变得太慢。 

一些边缘情况很重要：

 - 共线连续点可以产生零叉积。 
-多边形可以按顺时针或逆时针顺序提供。 
- 允许负坐标。 
- 多边形可能包含一个使凸度无效的向内弯曲。 
- 由于多边形保证是简单的，因此我们不需要检查边的相交。 

## 方法

 ### 蛮力方法

 确定多边形是否凸的一种直接方法是显式计算每个内角。 对于每个顶点，我们可以使用其相邻顶点形成向量，并使用点积或三角函数计算它们之间的角度。 

如果每个内角都严格小于 180 度，则该多边形是凸多边形。 

这种方法是正确的，因为凸性是直接根据内角定义的。 然而，角度计算涉及浮点运算、反余弦运算以及精度问题的仔细处理。 此外，显式计算角度比必要的更复杂。 

更详尽的强力解释还将检查每条对角线是否完全位于多边形内部，这会导致更高的复杂性。 

虽然对于给定的约束是可行的，但这些方法过于昂贵且容易出错。 

### 最佳方法

 关键的几何见解是，凸多边形在穿过其顶点时始终沿相同方向转动。 

我们可以使用二维叉积来检测转动方向。 

连续获得三分`A`,`B`， 和`C`，我们形成两个向量：

 -`AB = B - A`-`BC = C - B`叉积的符号告诉我们转动方向：

 - 正叉积表示逆时针旋转
 - 负叉积表示顺时针旋转
 - 零表示共线点

 对于凸多边形，所有非零叉积必须具有相同的符号。 

这使我们能够通过一次遍历顶点来解决问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 使用几何公式显式计算内角 |
 | 最佳| O(n) | O(1) | O(1) | 使用跨积符号一致性来检测凸性 |

 ## 算法演练

 1. 迭代多边形的每个顶点。 

由于多边形是循环的，因此每个顶点都需要其前一个和下一个邻居。 我们使用模运算，以便最后一个点自然地连接回第一个点。 
2. 对于每个连续点的三元组`(A, B, C)`，计算叉积。 

公式为：$(B_x-A_x)(C_y-B_y)-(B_y-A_y)(C_x-B_x)$该值决定是否在顶点处转弯`B`是顺时针或逆时针。 
3. 忽略零交叉积。 

零交叉积意味着三个点共线。 共线边不影响凸性，因此我们跳过它们。 
4. 存储第一个非零叉积的符号。 

这确定了整个多边形的预期转向方向。 
5. 继续检查所有剩余的叉积。 

如果任何后来的非零叉积具有相反的符号，则多边形改变转向方向，因此不能是凸的。 
6. 如果整个遍历完成没有矛盾，则返回`true`。 

这意味着所有转弯都是一致的。 

### 为什么它有效

 当且仅当每个边界转弯都发生在相同的旋转方向上时，简单多边形才是凸多边形。 叉积精确地捕获了该方向转弯信息。 因为保证多边形是简单的，所以旋转方向的任何变化都必然会产生向内的凹痕，这使得多边形非凸。 因此，一致的叉积符号对于凸性来说既是必要的也是充分的。 

## Python 解决方案```python
from typing import List

class Solution:
    def isConvex(self, points: List[List[int]]) -> bool:
        n = len(points)
        previous_cross = 0

        for i in range(n):
            x1, y1 = points[i]
            x2, y2 = points[(i + 1) % n]
            x3, y3 = points[(i + 2) % n]

            dx1 = x2 - x1
            dy1 = y2 - y1
            dx2 = x3 - x2
            dy2 = y3 - y2

            cross = dx1 * dy2 - dy1 * dx2

            if cross != 0:
                if previous_cross != 0 and cross * previous_cross < 0:
                    return False

                previous_cross = cross

        return True
```其实现直接遵循几何观察。 

变量`previous_cross`存储第一个有意义的转弯的符号。 在迭代过程中，我们不断计算每组三个连续点的叉积。 

模运算符允许多边形遍历自然地环绕，这避免了对最终顶点的特殊处理。 

当叉积为零时，这些点共线，因此算法会忽略该转弯并继续。 

条件：```python
cross * previous_cross < 0
```检测到符号变化。 如果发生这种情况，多边形会改变转动方向，因此函数立即返回`False`。 

如果循环成功完成，则每一圈都是一致的，并且多边形是凸的。 

## 解决方案```go
func isConvex(points [][]int) bool {
	n := len(points)
	prevCross := 0

	for i := 0; i < n; i++ {
		x1, y1 := points[i][0], points[i][1]
		x2, y2 := points[(i+1)%n][0], points[(i+1)%n][1]
		x3, y3 := points[(i+2)%n][0], points[(i+2)%n][1]

		dx1 := x2 - x1
		dy1 := y2 - y1
		dx2 := x3 - x2
		dy2 := y3 - y2

		cross := dx1*dy2 - dy1*dx2

		if cross != 0 {
			if prevCross != 0 && cross*prevCross < 0 {
				return false
			}

			prevCross = cross
		}
	}

	return true
}
```Go 实现与 Python 版本几乎相同。 由于 Go 使用固定宽度整数，因此值得考虑溢出。 然而，坐标约束仅`10^4`，因此叉积安全地保持在 32 位整数范围内。 

Go 切片自然地用于输入结构。 除了一些整数变量之外，不需要额外的内存分配。

 ## 边缘情况

 ### 共线连续点

 多边形可以包含位于同一条直线上的连续点。 在这种情况下，叉积变为零。 

幼稚的实现可能会错误地将零视为方向变化。 此实现明确忽略零叉积，这正确地保留了凸性行为。 

### 顺时针与逆时针排序

 多边形顶点可以设置在任一遍历方向上。 

一些不正确的解决方案假设多边形必须始终产生正叉积。 实际上，有效的凸多边形可以根据方向产生全正叉积或全负叉积。 

此实现仅检查符号的一致性，而不检查特定符号本身。 

### 遍历后期出现的凹性

 多边形的大多数顶点可能呈凸形，并且仅在末端附近包含一个向内的弯曲。 

提前停止的不完整实现可能会错过这种情况。 该算法按循环顺序检查每个顶点，确保即使是较晚的符号变化也能被正确检测到。
