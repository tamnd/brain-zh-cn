 ## 解决方案

 ## 问题理解

 问题给了我们一个整数数组`nums`长度`n`，其中每个值都保证在范围内`[1, n]`。 每个数字出现一次或两次。 我们的任务是返回所有恰好出现两次的数字。 

重要的要求不仅是正确性，而且是效率。 解决方案必须运行在`O(n)`时间并仅使用恒定的辅助空间，不包括输出数组。 此限制立即排除了许多直接的解决方案，例如使用哈希集或频率图，因为这些方法需要与输入大小成比例的额外内存。 

约束揭示了输入的一个非常重要的属性。 由于每个数字都介于`1`和`n`，每个值都可以直接映射到数组中的有效索引。 具体来说，该值`x`自然对应于索引`x - 1`。 这种关系是实现最佳就地解决方案的关键见解。 

输入数组可以包含重复项，但每个数字最多出现两次。 这种保证简化了逻辑，因为我们永远不需要跟踪大于二的计数。 如果第二次遇到一个数字，我们立即知道它属于结果。 

尽早识别一些边缘情况非常重要。 没有重复项的数组应返回空列表。 每个重复值连续出现的数组仍然需要正常工作。 大小的数组`1`也必须安全处理。 另一个微妙之处是，最优解会暂时修改数组，因此我们必须确保即使在值变为负数后逻辑仍然有效。 

## 方法

 ### 蛮力方法

 最直接的解决方案是对照每个其他元素检查每个元素。 对于每个数字，我们扫描数组的其余部分以查看是否再次出现相同的值。 

这种方法之所以有效，是因为它详尽地比较了所有元素对。 每当我们找到相同数字的另一个出现时，我们就把它添加到结果中。 

然而，这种方法效率低下。 对于大小的数组`n`，每个元素可能需要扫描几乎整个剩余数组。 这导致`O(n^2)`时间复杂度，当`n`可以大到`10^5`。 

另一个简单的替代方法是使用哈希集或字典来计算频率。 这将运行时间提高到`O(n)`，但它需要`O(n)`额外的空间，这违反了恒定的空间要求。 

### 最佳方法

 关键的观察结果是所有值都在范围内`[1, n]`。 这意味着每个数字都可以映射到数组中的索引。 

我们使用输入数组本身作为簿记结构。 当我们遇到一个数字`x`，我们看索引`x - 1`。 

如果该指数的值为正，则意味着我们看到`x`第一次，所以我们否定该索引处的值以将其标记为已访问。 

如果该索引处的值已经是负数，则意味着我们已经访问过`x`前。 所以，`x`是重复的，我们将其添加到结果中。 

This technique works in place and requires only constant extra memory because we reuse the original array for tracking visits.

 ## 算法演练

 1. 初始化一个空的结果列表，用于存储所有重复的数字。 
2. 迭代数组中的每个数字。 
3. 由于数字可能已在前面的步骤中被求反，因此取当前数字的绝对值。 这确保我们恢复原始值。 
4. 使用以下命令将数字转换为索引`index = abs(num) - 1`。 因为值保证在`1`和`n`，这个索引永远有效。 
5. 检查存储在的值`nums[index]`。 
6.如果`nums[index]`为正数，这意味着这是我们第一次遇到这个数字。 对该索引处的值取反以将其标记为已访问。 
7. 如果`nums[index]`已经是负数了，这意味着我们以前见过这个数字。 因此，当前数字是重复的，因此将其附加到结果列表中。 
8. 继续，直到处理完整个数组。 
9. 返回结果列表。 

### 为什么它有效

 该算法依赖于以下不变量：索引处值的符号`x - 1`表示是否有号码`x`已经出现了。 

正值表示尚未看到该数字。 负值表示已经遇到过一次。 由于每个数字最多出现两次，因此第二次遇到唯一地标识重复项。 

由于每个值都映射到唯一索引，因此标记过程中不会出现歧义或冲突。 

## Python 解决方案```python
from typing import List

class Solution:
    def findDuplicates(self, nums: List[int]) -> List[int]:
        duplicates = []

        for num in nums:
            index = abs(num) - 1

            if nums[index] < 0:
                duplicates.append(abs(num))
            else:
                nums[index] *= -1

        return duplicates
```实现首先创建一个名为的空列表`duplicates`存储出现两次的数字。 

循环遍历中的每个值`nums`。 因为早期的操作可能已经否定了一些元素，所以我们使用`abs(num)`恢复原来的号码。 

表达式`abs(num) - 1`将数字转换为其相应的数组索引。 然后我们检查该位置的值。 

如果该值已经是负数，则该数字之前已经见过，因此我们将其附加到结果列表中。 

否则，我们否定该索引处的值以将数字标记为已访问。 

遍历结束时，`duplicates`列表包含所有出现两次的数字。 

## 解决方案```go
func findDuplicates(nums []int) []int {
    duplicates := []int{}

    for _, num := range nums {
        if num < 0 {
            num = -num
        }

        index := num - 1

        if nums[index] < 0 {
            duplicates = append(duplicates, num)
        } else {
            nums[index] *= -1
        }
    }

    return duplicates
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于 Go 没有提供内置的`abs`标准库中的整数函数无需导入额外的包，代码手动将负值转换回正值。 

Go 中的切片的行为与动态数组类似，因此附加重复项很自然。 返回空切片是有效的，相当于不返回重复项。 

整数溢出不是问题，因为约束将值限制为最多`10^5`。

 ## 边缘情况

 一个重要的边缘情况是一个完全没有重复项的数组，例如`[1,2,3,4]`。 有缺陷的实现可能会由于符号处理不正确而意外附加值。 在此实现中，每个数字都将其相应的索引翻转一次，因此除非再次遇到该索引，否则不会报告重复项。 

另一个关键的边缘情况是尽可能最小的数组，`[1]`。 由于该算法使用以下方式将值转换为索引`value - 1`，重要的是指数计算即使在下限也保持有效。 实现安全映射`1`索引`0`。 

更微妙的边缘情况涉及迭代期间已经修改的值。 例如，处理一些数字后，数组的部分内容变为负值。 如果我们直接使用原始值，我们可能会产生无效的索引。 该实现通过始终使用来避免此问题`abs(num)`在计算指数之前。 

另一种边缘情况是当重复项彼此靠近时，例如`[2,2]`。 一些不正确的解决方案可能会重复计算或失败，因为它们修改值太早。 在这里，第一个`2`分数指数`1`为负，第二个`2`立即检测到索引已经为负，正确识别重复项一次。
