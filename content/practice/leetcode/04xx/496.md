[LeetCode 第 496 题](https://leetcode.com/problems/next-greater-element-i/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、堆栈、单调堆栈

 ## 解决方案

 ## 问题理解

 问题是要求我们为中的每个元素找到**下一个更大的元素**`nums1`在另一个数组中`nums2`。 形式上，对于中的每个元素`nums1`，我们需要找到它的位置`nums2`然后找到其**右侧**的第一个元素`nums2`那**比它本身更大**。 如果不存在这样的元素，我们返回`-1`对于该元素。 

输入数组具有以下特征：`nums1`是一个子集`nums2`，两个数组都包含**不同的整数**，并且长度适中（`1 <= nums1.length <= nums2.length <= 1000`）。 这意味着中的所有元素`nums1`**出现在**的某处`nums2`，所以我们不需要处理缺失的元素。 这些限制还意味着像这样的简单算法`O(n^2)`对于较小的投入是可行的，但对于较大的投入来说效率较低。 

关键的边缘情况包括当元素位于`nums1`是 **最大的元素**`nums2`（所以下一个更大的元素是`-1`)，当该元素**位于 nums2** 的末尾时，并且当`nums1`包含所有元素`nums2`或者只有一个元素。 

## 方法

 ### 蛮力方法

 最简单的方法是迭代每个元素`nums1`，找到它的索引`nums2`，然后向右扫描所有元素，直到找到更大的数字。 如果没有找到更大的数字，我们分配`-1`。 这种方法之所以有效，是因为它直接实现了问题的描述，但它需要嵌套循环：一遍`nums1`和一个潜在的切片`nums2`。 对于大型数组，这可能效率低下，达到 **O(n1 * n2)** 时间复杂度，其中`n1`的长度是`nums1`和`n2`的长度是`nums2`。 

### 使用单调堆栈的最佳方法

 有效解决方案的关键观察是我们可以为中的每个数字预先计算**下一个更大的元素**`nums2`使用**单调堆栈**进行**一次**。 堆栈维护着一个递减的数字序列`nums2`。 当一个大于堆栈顶部的新数字到达时，我们从堆栈中弹出并将当前数字记录为弹出数字的下一个更大元素。 这允许我们从每个数字构建一个映射`nums2`在 **O(n2)** 时间内到达下一个更大的元素。 一旦这个映射准备好，我们就可以简单地查找每个数字`nums1`在 **O(n1)** 时间内。 这产生了总体 **O(n1 + n2)** 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n1 * n2) | O(n1 * n2) | O(1) | O(1) | 嵌套循环为每个查询搜索下一个更大的元素 |
 | 最佳| O(n1 + n2) | O(n1 + n2) | O(n2) | O(n2) | 使用单调堆栈和哈希图预先计算下一个更大的元素 |

 ## 算法演练

 1.初始化一个空栈和一个空字典`next_greater_map`。 
2. 迭代每个元素`num`在`nums2`。 对于每个数字：

 - 当栈非空且栈顶小于**时`num`**，弹出顶部元素并将其映射到`num`在`next_greater_map`。 这意味着`num`是弹出数字的下一个更大的元素。 
- 推`num`到堆栈上。 稍后它可能会有下一个更大的元素。 
3.处理完所有元素后`nums2`，堆栈中的任何剩余数字都没有下一个更大的元素，因此它们可以保持未映射状态，我们将默认为`-1`。 
4. 构造结果数组`nums1`通过查找中的每个元素`next_greater_map`。 如果地图上没有号码，请追加`-1`。 

**为什么有效：** 单调堆栈确保每个数字`nums2`仅与其右侧的数字进行比较，并且它保持严格的递减序列。 通过在遇到较大数字时弹出较小数字，我们可以在**线性时间内**为每个数字正确分配下一个更大元素。 

## Python 解决方案```python
from typing import List

class Solution:
    def nextGreaterElement(self, nums1: List[int], nums2: List[int]) -> List[int]:
        stack = []
        next_greater_map = {}
        
        for num in nums2:
            while stack and stack[-1] < num:
                smaller = stack.pop()
                next_greater_map[smaller] = num
            stack.append(num)
        
        # For remaining elements in stack, there is no next greater element
        result = [next_greater_map.get(num, -1) for num in nums1]
        return result
```该代码首先为中的所有数字构建**下一个更大元素的映射**`nums2`使用单调堆栈。 每个元素要么被压入堆栈，要么用于弹出较小的元素。 最后，我们构建答案`nums1`使用字典查找。 

## 解决方案```go
func nextGreaterElement(nums1 []int, nums2 []int) []int {
    stack := []int{}
    nextGreaterMap := make(map[int]int)
    
    for _, num := range nums2 {
        for len(stack) > 0 && stack[len(stack)-1] < num {
            smaller := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            nextGreaterMap[smaller] = num
        }
        stack = append(stack, num)
    }
    
    result := make([]int, len(nums1))
    for i, num := range nums1 {
        if val, exists := nextGreaterMap[num]; exists {
            result[i] = val
        } else {
            result[i] = -1
        }
    }
    return result
}
```在 Go 中，我们使用切片作为堆栈和下一个更大元素的映射。 我们仔细处理查找`exists`来区分未映射的元素，我们将最终结果附加到`nums1`。
