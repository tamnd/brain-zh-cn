[LeetCode 第 452 题](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定爆破所有气球所需的最小垂直箭头数量，这些气球表示为沿 x 轴的间隔。 每个气球由其起始和结束 x 坐标定义，`[xstart, xend]`。 箭射向指定位置`x`爆破任何其区间包含的气球`x`。 箭头无限向上移动，因此只有水平重叠很重要。 

输入是表示气球间隔的整数对列表。 输出是一个整数，表示所需的最小箭头数量。 约束表明气球的数量可以很大，最多可达`10^5`，x 坐标的范围可以很广`-2^31`到`2^31-1`。 这意味着任何解决方案都必须在时间和空间上都有效。 

边缘情况包括：具有相同起点和终点的气球、完全重叠的气球、不重叠的气球和单个气球。 该问题保证了`xstart < xend`对于每个气球，因此不存在零长度间隔。 

## 方法

 蛮力方法将涉及迭代所有气球并尝试所有可能的箭头位置。 人们可以为第一个气球选择一个箭头位置，移除它破裂的所有气球，然后重复直到所有气球都消失。 虽然正确，但这种方法对于大输入大小是不可行的，因为它可能涉及潜在的嵌套迭代`10^5`气球，时间复杂度约为 O(n²)，这太慢了。 

最佳解决方案的关键见解来自于注意到问题可以贪婪地解决。 如果我们按气球的结束 x 坐标对气球进行排序，我们总是可以在第一个气球的末端射一支箭，它会炸毁与该点重叠的所有气球。 然后我们跳过所有已经破裂的气球并重复。 这是有效的，因为在气球末端射击可以最大限度地与后续气球重叠，从而最大限度地减少箭头总数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 尝试所有位置并迭代计数重叠 |
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 按末端排序间隔，在间隔末端贪婪地射箭 |

 ## 算法演练

 1. 检查是否`points`数组为空。 如果是，则返回 0，因为不需要箭头。 
2. 按气球间隔的结束 x 坐标对气球间隔进行排序。 这确保了我们始终首先考虑最早完成的气球。 
3. 将箭头计数器初始化为 1，因为第一个气球至少需要一个箭头。 
4. 初始化变量`arrow_pos`到第一个气球的结束 x 坐标。 这表示当前箭头的 x 位置。 
5. 从第二个气球开始迭代气球的排序列表。 对于每个气球：

 a. 如果气球的起始 x 坐标大于`arrow_pos`，这意味着该气球没有与当前箭头重叠。 

b. 增加箭头计数器并更新`arrow_pos`到当前气球的末尾。 

c. 如果气球的开始时间小于或等于`arrow_pos`，它已经被当前箭头覆盖，所以什么也不做。 
6. 迭代完所有气球后，返回箭头计数器。 

工作原理：按末端坐标排序并始终在末端放置箭头可确保每个箭头覆盖尽可能多的重叠气球。 这种贪婪的选择保证了最少的箭头数量，因为延迟箭头只需要稍后再添加一个箭头。 

## Python 解决方案```python
from typing import List

class Solution:
    def findMinArrowShots(self, points: List[List[int]]) -> int:
        if not points:
            return 0
        
        points.sort(key=lambda x: x[1])
        arrows = 1
        arrow_pos = points[0][1]
        
        for start, end in points[1:]:
            if start > arrow_pos:
                arrows += 1
                arrow_pos = end
        
        return arrows
```该代码首先检查输入是否为空。 然后，它根据气球的结束坐标对气球进行排序，以方便贪婪的方法。`arrows`从 1 开始，因为第一个气球至少需要一个箭头。 当我们迭代时，任何未与当前箭头重叠的气球都会触发新箭头，更新`arrow_pos`。 

## 解决方案```go
import "sort"

func findMinArrowShots(points [][]int) int {
    if len(points) == 0 {
        return 0
    }

    sort.Slice(points, func(i, j int) bool {
        return points[i][1] < points[j][1]
    })

    arrows := 1
    arrowPos := points[0][1]

    for _, p := range points[1:] {
        if p[0] > arrowPos {
            arrows++
            arrowPos = p[1]
        }
    }

    return arrows
}
```在 Go 中，我们处理排序`sort.Slice`并显式管理数组切片。 逻辑与Python相同。 Go 需要仔细处理切片并避免 nil 检查，因为我们只检查长度。 

## 工作示例

 ### 示例 1

 输入：`[[10,16],[2,8],[1,6],[7,12]]`按结尾排序：`[[1,6],[2,8],[7,12],[10,16]]`| 气球| 箭头位置 | 箭头|
 | --- | --- | --- |
 | [1,6]| 6 | 1 |
 | [2,8]| 6 | 1（覆盖）|
 | [7,12] | 12 | 12 2（新箭头）|
 | [10,16]| 12 | 12 2（覆盖）|

 输出：2

 ### 示例 2

 输入：`[[1,2],[3,4],[5,6],[7,8]]`按结尾排序：`[[1,2],[3,4],[5,6],[7,8]]`每个气球都不重叠，因此每个气球都需要一个新箭头。 输出：4

 ### 示例 3

 输入：`[[1,2],[2,3],[3,4],[4,5]]`按结尾排序：`[[1,2],[2,3],[3,4],[4,5]]`箭头射向 2 和 4。输出：2

 ## 边缘情况

 一种边缘情况是输入列表为空。 该实现返回 0，避免不必要的计算。 

另一种情况是完全嵌套的间隔，其中一个箭头可以覆盖多个气球。 按末端排序可确保箭头最佳地放置在尽可能小的末端，覆盖所有嵌套的气球。 

第三种边缘情况涉及具有大范围或负坐标的气球。 由于整数比较，排序仍然可以正确工作，并且不会发生溢出，因为 Python 处理任意整数，而 Go 在约束内隐式使用 64 位整数。 

该解决方案对于各种输入模式都具有鲁棒性，可确保正确性和效率。
