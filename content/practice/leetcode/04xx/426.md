[LeetCode 问题 426](https://leetcode.com/problems/convert-binary-search-tree-to-sorted-doubly-linked-list/)

 **难度：** 🟡 中等
 **主题：** 链表、堆栈、树、深度优先搜索、二叉搜索树、二叉树、双向链表

 ## 解决方案

 ## 问题理解

 该问题要求我们将二叉搜索树（Binary Search Tree，缩写为 BST）转换为已排序的循环双向链表。 转换必须就地进行，这意味着我们不允许为链表创建全新的节点。 相反，我们重用现有的树节点并重新解释它们`left`和`right`指针作为双向链表指针。 

在双向链表中，每个节点都有两个方向连接：

 - 一个指向前一个节点的指针
 - 一个指向下一个节点的指针

 在这个问题中：

 -`left`成为前驱指针
 -`right`成为后继指针

 该列表也必须是循环的。 这意味着：

 - 最小节点的前驱指向最大节点
 - 最大节点的后继指向最小节点

 输入是二叉搜索树的根。 BST 具有重要的属性：

 - 左子树中的每个值都小于当前节点
 - 右子树中的每个值都大于当前节点

 由于此属性，BST 的中序遍历会按排序顺序访问节点。 这一观察是有效解决问题的关键。 

预期输出是循环双向链表的头，特别是按排序顺序的最小节点。 

约束告诉我们树最多可以包含 2000 个节点。 这个值足够小，即使不太理想的方法也可以通过，但问题明确要求进行就地转换，因此我们应该寻求一种有效地重用树结构的解决方案。 

一些边缘情况很重要：

 - 树可能是空的，在这种情况下我们应该返回`None`- 树可能只包含一个节点，该节点应在两个方向上都指向自身
 - 树可能严重倾斜，使得递归深度成为一个重要的考虑因素
 - BST 属性保证唯一值，因此我们永远不需要处理重复项

 ## 方法

 ### 蛮力方法

 一个简单的解决方案是对 BST 进行中序遍历，并将所有访问过的节点存储在数组或列表中。 由于 BST 的中序遍历会按排序顺序生成值，因此数组将按照双向链表所需的确切顺序包含节点。 

收集完所有节点后，我们迭代数组并手动连接相邻节点：

 -`nodes[i].right = nodes[i + 1]`-`nodes[i + 1].left = nodes[i]`最后，我们连接第一个和最后一个节点以使列表循环。 

这种方法是正确的，因为中序遍历保证了 BST 中的排序顺序。 但是，它使用与节点数量成比例的额外内存，因为每个节点引用都存储在辅助列表中。 

### 最佳方法

 关键的见解是我们实际上并不需要中间数组。 

由于中序遍历已经按排序顺序访问节点，因此我们可以在遍历树时立即连接节点。 我们在遍历的过程中维护两个指针：

 -`prev`, 之前访问过的节点
 -`head`, 迄今为止遇到的最小节点

 当我们访问每个节点时：

 - 我们连接`prev.right`到当前节点
 - 我们连接`current.left`到`prev`这将按排序顺序逐步构建双向链表。 

遍历完成后：

 -`head`指向最小的节点
 -`prev`指向最大的节点

 然后我们将它们连接在一起以使列表循环。 

此解决方案是最佳解决方案，因为它就地执行转换并避免单独存储所有节点。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 使用中序遍历加上辅助节点数组 |
 | 最佳 | O(n) | O(h) | 遍历过程中构建列表，递归堆栈取决于树高 |

 ## 算法演练

 1. 立即处理空树箱。 

如果根是`None`，没有链表可供构建，所以我们返回`None`。 
2.初始化两个指针，`head`和`prev`。`head`最终会指向BST中最小的节点，该节点成为链表的头。`prev`在中序遍历期间跟踪先前处理的节点。 这允许我们按排序顺序连接相邻节点。 
3. 对 BST 进行中序遍历。 

中序遍历按以下顺序访问节点：

 - 左子树
 - 当前节点
 - 右子树

 因为该树是 BST，所以这种遍历自然会按升序顺序访问节点。 
4. 遍历时处理当前节点。 

访问节点时：

 - 如果`prev`存在，连接：

 -`prev.right = current`-`current.left = prev`这将当前节点与先前访问过的节点链接起来。 

- 如果`prev`不存在，这是访问的第一个节点，意味着它是 BST 中最小的节点。 放`head = current`。 
5. 更新`prev`。 

处理完当前节点后，赋值：```
prev = current
```这为链接下一个访问的节点做好了准备。 
6. 继续遍历右子树。 

中序遍历继续递归，保留排序顺序。 
7. 遍历完成后将链表循环。 

在最后：

-`head`指向最小的节点
 -`prev`指向最大的节点

 将它们连接在一起：

 -`head.left = prev`-`prev.right = head`8. 返回`head`。 

这是所需的输出指针。 

### 为什么它有效

 正确性来自于BST的中序遍历性质。 中序遍历总是按升序访问 BST 节点。 通过在遍历过程中将每个节点链接到先前访问过的节点，我们逐步构造一个正确排序的双向链表。 最后一步连接最小和最大的节点，使结构呈圆形而不破坏排序顺序。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
"""

from typing import Optional

class Solution:
    def treeToDoublyList(self, root: 'Optional[Node]') -> 'Optional[Node]':
        if not root:
            return None

        self.head = None
        self.prev = None

        def inorder(node: 'Optional[Node]') -> None:
            if not node:
                return

            inorder(node.left)

            if self.prev:
                self.prev.right = node
                node.left = self.prev
            else:
                self.head = node

            self.prev = node

            inorder(node.right)

        inorder(root)

        self.head.left = self.prev
        self.prev.right = self.head

        return self.head
```实现首先处理空树的情况。 如果`root`是`None`，函数立即返回`None`。 

然后初始化两个实例变量：

 -`self.head`存储最小的节点
 -`self.prev`遍历过程中存储之前访问过的节点

 嵌套的`inorder`函数执行递归中序遍历。 

遍历首先处理左子树，确保在当前节点之前访问较小的值。 处理当前节点时：

 - 如果`self.prev`存在，当前节点链接到前一个节点
 - 否则，当前节点是最小节点，因此成为头节点

 处理后，`self.prev`更新到当前节点，以便下一个访问的节点可以连接回它。 

遍历完成后，列表几乎完整，但仍然是线性的。 最后两个作业将头部和尾部连接在一起，使结构呈圆形。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Left *Node
 *     Right *Node
 * }
 */

func treeToDoublyList(root *Node) *Node {
    if root == nil {
        return nil
    }

    var head *Node
    var prev *Node

    var inorder func(*Node)

    inorder = func(node *Node) {
        if node == nil {
            return
        }

        inorder(node.Left)

        if prev != nil {
            prev.Right = node
            node.Left = prev
        } else {
            head = node
        }

        prev = node

        inorder(node.Right)
    }

    inorder(root)

    head.Left = prev
    prev.Right = head

    return head
}
```Go 实现遵循与 Python 版本相同的逻辑结构。 主要区别在于 Go 使用显式指针处理而不是 Python 引用。 

Go 使用`nil`而不是`None`，并且递归辅助函数是使用函数变量声明的，因此它们可以递归地引用自身。 

因为 Go 不支持像 Python 类那样具有隐式对象状态的嵌套函数闭包，`head`和`prev`被递归闭包捕获。

 ## 边缘情况

 ### 空树

 一棵空树表示为`root = None`。 这种情况很重要，因为递归遍历假设节点存在。 如果没有提前返回，实现可能会尝试无效的指针操作。 

该解决方案一开始就立即处理这个问题：```
if not root:
    return None
```这保证了空输入不会发生遍历。 

### 单节点树

 仅包含一个节点的 BST 是一种微妙的边缘情况，因为该节点必须在两个方向上都指向自身。 

例如：```
1
```生成的循环双向链表应满足：```
1.left = 1
1.right = 1
```该实现自然地处理了这个问题，因为：

 - 单个节点成为两个节点`head`和`prev`- 最后的循环链接步骤将节点连接回自身

 ### 倾斜的树

 倾斜 BST 的行为类似于链表而不是平衡树。 

例子：```
1
 \
  2
   \
    3
```这种情况很重要，因为递归深度变成`O(n)`而不是`O(log n)`。 不正确的遍历顺序或指针更新很容易产生损坏的链接。 

中序遍历仍然按排序顺序处理节点，并且算法保持正确性，因为每个节点仅在其前一个节点已被处理后才被链接。
