[LeetCode 第 414 题](https://leetcode.com/problems/third-maximum-number/)

 **难度：** 🟢简单
 **主题：** 数组、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们在整数数组中找到第三个不同的最大数字。 关键词很明确。 确定排名时，重复值只应计算一次。 

例如，在数组中`[2,2,3,1]`，不同的值是`{3,2,1}`。 虽然`2`出现两次，仅算作一个不同的数字。 因此，第三个不同的最大值是`1`。 

如果数组包含的不同值少于三个，我们将返回总体最大数量。 例如，在`[1,2]`，只有两个不同的数字，所以答案是最大值，`2`。 

输入是一个名为的整数数组`nums`。 输出是一个整数，表示：

 - 第三个不同的最大值，或
 - 如果存在少于三个不同值，则为最大值

 这些约束告诉我们一些重要的事情：

 - 数组长度可以大到`10^4`- 值的范围可以是`-2^31`到`2^31 - 1`- 负数是有效输入
 - 重复值很常见，必须小心处理

 后续特别要求`O(n)`解决方案，这意味着我们应该尽可能避免排序。 排序需要`O(n log n)`时间，对于约束来说是可以接受的，但根据后续要求并不是最优的。 

一些边缘情况很重要：

 - Arrays with fewer than three distinct numbers
 - Arrays where all numbers are identical
 - Arrays containing negative values
 - 包含最小可能整数值的数组
 - 具有许多重复项的数组可能会错误地增加最大值的计数

 如果单独计算重复项或错误处理极端整数值，幼稚的实现很容易失败。 

## 方法

 ### 蛮力方法

 最直接的解决方案是删除重复项，按降序对剩余数字进行排序，然后返回：

 - 如果至少存在三个不同的数字，则为第三个元素
 - the first element otherwise

 例如：

 - 输入：`[2,2,3,1]`- 独特的价值观：`[2,3,1]`- 降序排序：`[3,2,1]`- 第三个不同的最大值：`1`这种方法很容易理解并保证正确性，因为排序会将所有不同的值按顺序排列。 

然而，排序需要`O(n log n)`时间，不满足后续要求`O(n)`复杂。 

### 最佳方法

 关键的见解是我们不需要数组的完整排序顺序。 我们只关心前三个不同的值。 

我们可以扫描一次数组，同时维护：

 - 最大的不同值
 - 第二大不同值
 - 第三大独特值

 每当我们遇到一个新数字时：

 - 如果它已经是跟踪的最大值之一，则忽略它
 - 如果跟踪值属于前三名，则适当更新跟踪值

 这是有效的，因为在遍历过程中的任何一点，我们都保持不变，即三个变量始终包含迄今为止看到的三个最大的不同数字。 

由于每个数字只处理一次，因此该算法以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 删除重复项并按降序排序 |
 | 最佳| O(n) | O(1) | O(1) | 在一次传递期间跟踪前三个不同的值 |

 ## 算法演练

 1.初始化三个变量，名为`first`,`second`， 和`third`代表迄今为止看到的最大、第二大和第三大的不同数字。 最初，所有内容均未设置。 
2. 迭代数组中的每个数字。 
3. 在更新任何内容之前，请检查当前数量是否已等于跟踪的最大值之一。 如果是，请跳过它，因为重复项不应多次计数。 
4. 如果当前数量大于`first`，将现有值向下移动：

 -`third`变成`second`-`second`变成`first`-`first`变为当前号码
 5. 否则，如果数量小于`first`但大于`second`， 更新：

-`third`变成`second`-`second`变为当前号码
 6. 否则，如果数字小于两者`first`和`second`但大于`third`， 更新`third`。 
7. 处理完所有数字后：

 - 如果`third`存在，返回
 - 否则，返回`first`我们只使用三个变量，因为问题只需要第三个不同的最大值。 追踪前三名之外的任何内容都是不必要的。 

### 为什么它有效

 在每次迭代中，变量`first`,`second`， 和`third`按降序存储迄今为止遇到的三个最大的不同值。 重复的值将被跳过，因此每个跟踪的值保持不同。 由于每个数字都被检查一次并正确插入到前三个数字中的位置，因此遍历后的最终值代表数组中真正的前三个不同的最大值。 

## Python 解决方案```python
from typing import List

class Solution:
    def thirdMax(self, nums: List[int]) -> int:
        first = second = third = None

        for num in nums:
            # Skip duplicates
            if num == first or num == second or num == third:
                continue

            # Update first maximum
            if first is None or num > first:
                third = second
                second = first
                first = num

            # Update second maximum
            elif second is None or num > second:
                third = second
                second = num

            # Update third maximum
            elif third is None or num > third:
                third = num

        return third if third is not None else first
```实现直接遵循算法。 

变量`first`,`second`， 和`third`跟踪前三个不同的值。 它们被初始化为`None`因为数组可能包含负数，包括最小可能的整数值。 使用`None`避免需要特殊的哨兵值。 

重复检查非常重要。 如果没有它，重复的值可能会错误地占据多个排名位置。 

当找到新的最大值时，现有的最大值向下移动以保持排序。 更新第二个最大值时适用相同的逻辑。 

最后，如果`third`仍然是`None`，这意味着存在少于三个不同的值，因此我们返回存储在中的最大值`first`。 

## 解决方案```go
package main

import "math"

func thirdMax(nums []int) int {
	first := math.MinInt64
	second := math.MinInt64
	third := math.MinInt64

	hasFirst := false
	hasSecond := false
	hasThird := false

	for _, num := range nums {
		// Skip duplicates
		if (hasFirst && num == first) ||
			(hasSecond && num == second) ||
			(hasThird && num == third) {
			continue
		}

		// Update first maximum
		if !hasFirst || num > first {
			third = second
			hasThird = hasSecond

			second = first
			hasSecond = hasFirst

			first = num
			hasFirst = true

		} else if !hasSecond || num > second {
			// Update second maximum
			third = second
			hasThird = hasSecond

			second = num
			hasSecond = true

		} else if !hasThird || num > third {
			// Update third maximum
			third = num
			hasThird = true
		}
	}

	if hasThird {
		return third
	}

	return first
}
```Go 实现使用显式布尔标志，因为 Go 整数不能自然地表示像 Python 那样的未初始化状态`None`。 

我们使用`math.MinInt64`作为占位符初始值，但布尔标志确定值是否实际上有效。 这可以避免输入本身包含最小整数值时出现的问题。 

其余逻辑完全反映了 Python 解决方案。

 ## 边缘情况

 ### 少于三个不同值的数组

 一个常见的错误是假设数组始终包含至少三个唯一的数字。 例如，`[1,2]`仅具有两个不同的值。 正确的行为是返回最大值，而不是产生错误或不正确的第三个值。 

该实现通过检查是否`third`曾经被分配过。 如果没有，则返回`first`。 

### 具有许多重复项的数组

 重复很容易破坏简单的解决方案。 在`[2,2,3,1]`，值`2`出现两次，但在排名中只应计入一次。 

该实现显式跳过任何已经等于的数字`first`,`second`， 或者`third`。 这保证了只跟踪不同的值。 

### 包含极端整数值的数组

 约束允许值小至`-2^31`。 当哨兵本身出现在输入中时，不小心使用哨兵值可能会产生微妙的错误。 

Python 解决方案通过使用完全避免了这种情况`None`对于未初始化的值。 Go 解决方案使用布尔标志来区分有效值和占位符初始化值。
