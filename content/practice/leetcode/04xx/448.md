 **难度：** 🟢简单
 **主题：** 数组、哈希表

 ## 解决方案

 ## 问题理解

 该问题要求我们找到范围内的所有整数`[1, n]`输入数组中缺少的内容`nums`长度`n`。 Each element in`nums`保证是一个介于`1`和`n`包含在内，但这个范围内的某些数字可能不会出现在数组中，而某些数字可能会出现多次。 输出是一个包含所有整数的数组`1`到`n`不存在于`nums`。 

例如，给定`nums = [4,3,2,7,8,2,3,1]`，数组有重复项（2 和 3）并且缺少 5 和 6。正确的输出是`[5,6]`。 

约束表明`n`可以大到`10^5`，这意味着朴素的二次解可能会太慢。 每个元素都落在范围内`[1, n]`，这很重要，因为它允许我们使用输入数组本身来标记存在而无需额外的空间。 

重要的边缘情况包括所有数字都存在的数组（返回空）、除 1 之外所有数字均缺失的数组、长度为 1 的数组以及重复项覆盖除 1 之外的整个范围的数组。 

## 方法

 蛮力方法迭代从 1 到 n 的每个数字，并检查它是否存在于`nums`通过扫描阵列。 这可以正确工作，因为它直接验证每个可能的数字，但速度很慢。 对于每个`n`数字，扫描长度数组`n`导致时间复杂度为 O(n²)，这对于大输入来说是不可接受的。 

最佳方法利用了以下事实：`nums`都在范围内`[1, n]`。 这允许我们通过修改输入数组本身来标记数字。 关键的见解是将数组视为哈希映射：对于每个数字`num`，我们标记索引处的元素`num - 1`为负数表明`num`存在。 处理完所有数字后，保持正值的索引对应于缺失的数字。 此方法使用 O(1) 额外空间（忽略输出数组）并在 O(n) 时间内运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 扫描数组中从 1 到 n 的每个数字 |
 | 最佳| O(n) | O(1) | O(1) | 通过否定相应的索引 | 就地标记访问过的数字

 ## 算法演练

 1. 迭代输入数组中的每个数字`nums`。 对于每个数字`num`,计算对应的索引`idx = abs(num) - 1`。 这`abs`是必要的，因为我们可能已经在之前的迭代中将该索引标记为负数。 
2. 标记索引处的数字`idx`为负数表明`idx + 1`存在于数组中。 如果它已经是负数，则保持原样。 
3. 第一次遍历后，再次遍历数组。 对于每个索引`i`在哪里`nums[i]`为正数，表示数量`i + 1`没有出现在原数组中。 
4. 将所有这些数字收集到结果数组中并返回。 

为什么它有效：通过标记与所看到的数字相对应的索引，我们维护了索引和数字之间的直接映射。 负标记是一种安全的就地修改，因为我们在将来的计算中永远不需要数字的原始符号，只需要它的绝对值。 这保证了每个缺失的数字都可以通过其正索引来检测。 

## Python 解决方案```python
from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        # Step 1: Mark indices corresponding to numbers present
        for num in nums:
            idx = abs(num) - 1
            if nums[idx] > 0:
                nums[idx] = -nums[idx]
        
        # Step 2: Collect indices that remain positive
        result = []
        for i, num in enumerate(nums):
            if num > 0:
                result.append(i + 1)
        
        return result
```Python 实现完全遵循该算法。 第一个循环通过对它们取反来标记与所看到的数字相对应的所有索引。 第二个循环扫描正值，这表明缺少数字。 使用`abs(num)`确保先前标记的负数不会干扰索引计算。 

## 解决方案```go
func findDisappearedNumbers(nums []int) []int {
    n := len(nums)
    
    // Step 1: Mark indices corresponding to numbers present
    for _, num := range nums {
        idx := abs(num) - 1
        if nums[idx] > 0 {
            nums[idx] = -nums[idx]
        }
    }
    
    // Step 2: Collect indices that remain positive
    var result []int
    for i, num := range nums {
        if num > 0 {
            result = append(result, i+1)
        }
    }
    
    return result
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```在 Go 中，主要区别是需要显式的`abs`功能。 其他方面的逻辑是相同的：将索引标记到位并收集正值。 Go 切片自然地处理动态附加。
