 **难度：** 🔴难
 **主题：** 树、深度优先搜索、广度优先搜索、设计、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们设计两种不同树结构之间的可逆变换：

 - N 叉树，其中每个节点可以有任意数量的子节点
 - 二叉树，每个节点最多有两个子节点

 重要的要求不是编码内部看起来如何，而是过程是无损的。 将 N 叉树编码为二叉树，然后将其解码回来后，我们必须恢复准确的原始 N 叉结构。 

输入的 N 叉树使用层序遍历来表示`null`儿童组之间的分隔符。 例如：```
[1,null,3,2,4,null,5,6]
```方法：```
        1
      / | \
     3  2  4
    / \
   5   6
```编码器将此结构转换为二叉树。 然后解码器必须准确地重建原始的 N 叉树。 

该问题故意不限制编码格式。 这意味着我们可以自由设计两种树类型之间的任何映射，只要：

 1. 每棵N叉树都可以被编码
 2. 每个编码的二叉树都可以正确解码回来
 3.算法是无状态的，这意味着我们不能依赖全局变量或持久的外部存储

 约束条件很重要：

 - 最多`10^4`节点
 - 树高可达`1000`这告诉我们：

 - 我们需要线性时间遍历算法
 - 递归解决方案原则上是可以接受的，但是非常深的递归可能会接近Python中的递归限制
 - 内存使用量应与树大小保持成正比

 一些边缘情况尤其重要：

 - 空树（`root = []`）
 - 具有零子节点的节点
 - 极度倾斜的树木
 - 节点有许多子节点的树
 - 接近高度的深树`1000`失去子顺序或无法区分兄弟关系的幼稚实现将无法正确重建原始结构。 

## 方法

 ### 蛮力方法

 一个蛮力的想法是将整个 N 叉树序列化为辅助表示，例如：

 - 邻接表
 - 嵌套数组
 - 带分隔符的预序遍历

 然后我们可以将该序列化信息存储在二叉树节点内的某个位置。 

例如，我们可以尝试：

 - 明确存储子计数
 - 引入人工分隔符节点
 - 从遍历元数据重建树

 虽然这些方法可行，但它们过于复杂，并且经常浪费内存。 一些暴力方法也违反了问题的精神，因为它们依赖于外部状态或冗余元数据。 

此外，重复扫描子项或低效重建列表的方法可能会退化为二次行为。 

### 关键见解

 最佳解决方案使用经典的左子右兄弟表示。 

关键的观察结果是，N 叉树可以自然地用每个节点仅使用两个指针来表示：

 - 左指针存储节点的第一个子节点
 - 右指针存储节点的下一个兄弟节点

 这是有效的，因为：

 - 每个节点的子节点形成一个有序列表
 - 链表样式的兄弟链可以表示该列表
 - 第一个子级可以访问整个子级序列

 例如：```
N-ary:
      1
    / | \
   2  3  4

Binary representation:
      1
     /
    2
     \
      3
       \
        4
```左指针下降到子级，右指针移过兄弟级。 

这种表示很优雅，因为：

 - 不需要额外的元数据
 - 编码和解码都是线性的
 - 该转变是完全可逆的

 ## 算法演练

 ### 编码算法

 1. 从N叉树的根开始。 

如果根是`None`， 返回`None`立即，因为空树编码为空二叉树。 
2、创建当前N元节点对应的二叉树节点。 

节点值保持相同。 仅指针结构发生变化。 
3. 将 N 元节点的第一个子节点存储在二元节点的`left`指针。 

这是关键的转变。 左子节点成为节点子节点列表的入口点。 
4. 使用链接所有剩余的子项`right`指针。 

假设一个 N 元节点有子节点：```
[c1, c2, c3, c4]
```那么二进制结构就变成：```
parent.left = c1
c1.right = c2
c2.right = c3
c3.right = c4
```这将创建一个兄弟链。 
5. 递归地编码每个子子树。 

每个孩子本身可能有孩子，因此我们递归地应用相同的转换。 

### 解码算法

 1. 从二叉树根开始。 

如果是的话`None`， 返回`None`。 
2. 创建一个具有相同值的N元节点。 
3. 移动到二进制节点`left`指针。 

该指针表示原始 N 叉树中的第一个子节点。 
4. 遍历兄弟链使用`right`指针。 

遇到的每个节点都代表当前 N 元节点的另一个子节点。 
5. 递归解码每个子子树。 

将每个重建的子节点附加到节点的`children`列表。 
6. 继续，直到同级链结束。 

一个`None`右指针意味着不再有兄弟姐妹。 

### 为什么它有效

 该算法保留了两个基本关系：

 - 亲子关系通过存储`left`- 兄弟订单通过存储`right`每个 N 元节点的有序子列表成为二叉树中的一条链接链。 由于两种关系都被准确保留，因此解码可以毫无歧义地重建原始树。 

该表示是双射的，这意味着每个编码的二叉树恰好对应于一个原始的 N 叉树。 

## Python 解决方案```python
from typing import Optional, List

# Definition for a Node.
class Node:
    def __init__(self, val: Optional[int] = None, children: Optional[List['Node']] = None):
        self.val = val
        self.children = children if children is not None else []

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

class Codec:
    # Encodes an n-ary tree to a binary tree.
    def encode(self, root: 'Optional[Node]') -> Optional[TreeNode]:
        if root is None:
            return None

        binary_root = TreeNode(root.val)

        if not root.children:
            return binary_root

        # Encode first child as left child
        binary_root.left = self.encode(root.children[0])

        current_binary = binary_root.left

        # Remaining children become right siblings
        for child in root.children[1:]:
            current_binary.right = self.encode(child)
            current_binary = current_binary.right

        return binary_root

    # Decodes your binary tree to an n-ary tree.
    def decode(self, data: Optional[TreeNode]) -> 'Optional[Node]':
        if data is None:
            return None

        nary_root = Node(data.val, [])

        current_binary = data.left

        # Traverse sibling chain
        while current_binary:
            child_node = self.decode(current_binary)
            nary_root.children.append(child_node)
            current_binary = current_binary.right

        return nary_root
```该实现直接遵循左子右兄弟变换。 

这`encode`方法为每个 N 元节点创建一个二元节点。 第一个子节点附加到二进制节点的`left`指针。 剩下的孩子都被拴在`right`指针。 

这`decode`方法逆转了这个过程。 它首先遍历左孩子，然后使用以下方法遍历兄弟链`right`重建原始子列表的指针。 

递归结构特别干净，因为每个子树都是独立编码和解码的。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */

/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

type Codec struct {
    
}

func Constructor() *Codec {
    return &Codec{}
}

func (this *Codec) encode(root *Node) *TreeNode {
    if root == nil {
        return nil
    }

    binaryRoot := &TreeNode{Val: root.Val}

    if len(root.Children) == 0 {
        return binaryRoot
    }

    // First child becomes left child
    binaryRoot.Left = this.encode(root.Children[0])

    currentBinary := binaryRoot.Left

    // Remaining children become right siblings
    for i := 1; i < len(root.Children); i++ {
        currentBinary.Right = this.encode(root.Children[i])
        currentBinary = currentBinary.Right
    }

    return binaryRoot
}

func (this *Codec) decode(root *TreeNode) *Node {
    if root == nil {
        return nil
    }

    naryRoot := &Node{
        Val: root.Val,
        Children: []*Node{},
    }

    currentBinary := root.Left

    for currentBinary != nil {
        child := this.decode(currentBinary)
        naryRoot.Children = append(naryRoot.Children, child)
        currentBinary = currentBinary.Right
    }

    return naryRoot
}

/**
 * Your Codec object will be instantiated and called as such:
 * obj := Constructor();
 * bst := obj.encode(root);
 * ans := obj.decode(bst);
 */
```Go 的实现与 Python 解决方案非常相似。 

主要的语言特定差异是：

 - Go 使用`nil`而不是`None`- 子项存储在切片中
 - 显式使用结构指针
 - 树节点分配有`&TreeNode{}`和`&Node{}`不存在整数溢出问题，因为节点值受以下限制`10^4`。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点在编码期间被访问一次，在解码期间被访问一次 |

 该算法是线性的，因为每个节点在遍历过程中都参与不断的工作。 

辅助空间仅来自递归深度。 在高度倾斜的树的最坏情况下，高度可能会变为`O(n)`。 对于平衡树，递归深度要小得多。

 ## 边缘情况

 ### 空树

 输入可能是`None`，表示一棵空的 N 叉树。 这是一个重要的情况，因为如果递归算法假设节点始终存在，则可能会意外地取消引用空指针。 

该实现在两者开始时立即处理这个问题`encode`和`decode`：```
if root is None:
    return None
```这保证了空输入的安全处理。 

### 没有子节点的节点

 叶节点是另一个微妙的情况。 如果编码器错误地假设每个节点都有子节点，它可能会尝试无效的索引操作，例如：```
root.children[0]
```当列表为空时。 

实现明确检查：```
if not root.children:
    return binary_root
```这确保叶节点生成没有左子节点的二进制节点。 

### 大量兄弟姐妹

 一个节点可以有很多子节点。 不正确的实现可能会丢失排序信息或意外覆盖同级指针。 

例如：```
1 -> [2,3,4,5,6]
```必须保留确切的子顺序。 

该解决方案通过顺序构建右兄弟链来维持顺序：```
current_binary.right = self.encode(child)
current_binary = current_binary.right
```解码时，遍历`right`chain 按原始顺序重建子项。 

### 深树

 树高可达`1000`，这会产生潜在的递归深度问题。 

递归方法仍然在预期的问题约束内有效，但递归堆栈与树高度成比例增长。 每个递归调用只处理一个子树，因此不会发生不必要的堆栈增长。 

由于该算法一次仅存储一个递归路径，因此即使对于深树，内存使用仍然高效。
