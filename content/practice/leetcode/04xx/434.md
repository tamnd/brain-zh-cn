[LeetCode 第 434 题](https://leetcode.com/problems/number-of-segments-in-a-string/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们计算字符串内存在多少个独立的类词组。 在此问题中，“段”被定义为非空格的连续字符序列。 每当我们遇到由空格分隔的非空格字符块时，该块就算作一个段。 

例如，在字符串中`"Hello, my name is John"`，有五组独立的非空格字符：

 -`"Hello,"`-`"my"`-`"name"`-`"is"`-`"John"`因此，答案是`5`。 

输入是单个字符串`s`，输出是一个整数，表示该字符串中出现了多少个段。 该字符串可以包含大写字母、小写字母、数字、标点符号和空格。 重要的是，唯一允许的空白字符是常规空格字符`' '`。 

限制非常小，因为字符串的最大长度仅为 300 个字符。 这意味着即使效率较低的方法仍然可以在限制内舒适地运行。 然而，目标仍然是设计一个干净且最佳的解决方案。 

有几个边缘情况需要仔细考虑。 字符串可以为空，应该返回`0`。 该字符串只能包含空格，也应该返回`0`。 单词之间可能会出现多个连续的空格，因此我们不能简单地计算空格并假设每个空格分隔段。 前导空格和尾随空格也必须正确处理，因为它们不会创建额外的段。 

正确的解决方案必须只计算到非空间序列的转换。 

## 方法

 ### 蛮力方法

 一种简单的方法是使用空格分割字符串并计算有多少个结果片段是非空的。 

例如：```
"Hello, my name".split(" ")
```产生：```
["Hello,", "my", "name"]
```但是，连续的空格会创建空字符串：```
"Hello   world".split(" ")
```产生：```
["Hello", "", "", "world"]
```然后，我们需要迭代结果数组并仅计算非空字符串。 

这种方法之所以有效，是因为每个有效段在分割后都成为一个非空子串。 空字符串仅因重复空格而出现。 

尽管此解决方案对于给定的约束是可以接受的，但它使用额外的内存来存储拆分操作期间创建的所有子字符串。 

### 最佳方法

 更好的方法是扫描一次字符串并直接计算每个段的开头。 

关键的观察是，每当出现以下情况时，新的段就会开始：

 - 当前字符不是空格，并且
 - 要么是字符串中的第一个字符，要么前一个字符是空格

 这使我们能够准确识别每个段的开始位置，而无需拆分字符串或存储中间子字符串。 

例如，在：```
"Hello, my name"
```该段开始于：

 -`'H'`-`'m'`-`'n'`这些字符中的每一个都出现在索引处`0`或紧跟一个空格。 

这种方法是最佳的，因为它一次性处理字符串并使用恒定的额外内存。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 分割字符串并计算非空部分 |
 | 最佳| O(n) | O(1) | O(1) | 计数段在一次遍历期间开始 |

 ## 算法演练

 ### 最优算法

 1.初始化一个计数器变量`count`到`0`。 

该变量将存储字符串中找到的段数。 
2. 使用索引逐个字符地遍历字符串。 

我们需要索引，因为确定段是否开始取决于前一个字符。 
3. 对于每个字符，检查它是否不是空格。 

只有非空格字符才能属于段。 
4、如果当前字符不是空格，判断是否开始新的段。 

如果满足以下条件，则角色开始新的片段：

 - 它位于索引处`0`，表示字符串以段开头，或者
 - 前一个字符是空格
 5. 如果任一条件为真，则递增`count`。 

这保证了每个段在其第一个字符处只被计数一次。 
6. 继续，直到处理完整个字符串。 
7. 返回`count`。 

### 为什么它有效

 该算法依赖于每个段都只有一个起始字符这一不变量。 当非空格字符出现在字符串开头或紧跟在空格后面时，段就开始了。 通过仅计算这些起始位置，该算法对每个段只计算一次，并且不会过度计算同一段内的连续字符。 

## Python 解决方案```python
class Solution:
    def countSegments(self, s: str) -> int:
        count = 0

        for index in range(len(s)):
            if s[index] != ' ':
                if index == 0 or s[index - 1] == ' ':
                    count += 1

        return count
```实现从初始化开始`count`为零。 该变量跟踪已找到的段起始数量。 

该循环遍历字符串中的每个索引。 对于每个字符，代码首先检查该字符是否是非空格字符。 如果它是一个空格，则不能开始一个段，因此迭代继续。 

当发现非空格字符时，代码检查它是否是新段的开始。 当字符位于索引处时会发生这种情况`0`或者当前一个字符是空格时。 如果任一条件为真，则计数器递增。 

循环结束后，该函数返回检测到的段起始总数，它等于段数。 

## 解决方案```go
func countSegments(s string) int {
    count := 0

    for i := 0; i < len(s); i++ {
        if s[i] != ' ' {
            if i == 0 || s[i-1] == ' ' {
                count++
            }
        }
    }

    return count
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 由于 Go 中的字符串可以按字节进行索引，因此使用索引迭代字符串在这里可以正常工作，因为该问题只能保证标准 ASCII 字符和空格。 

没有特别担心整数溢出的问题，因为最大字符串长度仅为 300。空字符串自然会被处理，因为循环只执行零次。

 ## 边缘情况

 ### 空字符串

 空字符串不包含任何字符，因此它不能包含任何段。 有缺陷的实现可能会意外地假设至少存在一个段。 在此解决方案中，当字符串为空时，循环永远不会执行，因此计数器正确保留`0`。 

### 多个连续空格

 字符串可能连续包含多个空格，例如`"hello   world"`。 计算空格并添加一个的幼稚实现可能会错误地对段进行计数。 该解决方案通过仅计算从空格到非空格字符的转换来避免该问题。 

### 前导空格和尾随空格

 输入如`"   hello world   "`如果实现假设第一个或最后一个字符始终是段的一部分，则可能会导致错误。 该算法可以正确处理此问题，因为它仅在遇到开始段的非空格字符时才增加计数。 两端多余的空格自然会被忽略。 

### 仅包含空格的字符串

 输入如`"     "`即使字符串非空，也没有有效的段。 某些实现错误地将空子字符串计为单词。 由于此解决方案仅计算段开始的非空格字符，因此结果正确地保留`0`。
