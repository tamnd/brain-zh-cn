[LeetCode 第 427 题](https://leetcode.com/problems/construct-quad-tree/)

 **难度：** 🟡 中等
 **主题：** 数组、分而治之、树、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们将二元矩阵转换为四叉树表示。 四叉树是一种递归树结构，其中每个内部节点恰好有四个子节点，每个子节点代表当前正方形区域的一个象限。 

输入是一个`n x n`矩阵称为`grid`，其中每个值都是`0`或者`1`。 尺寸`n`保证是 2 的幂，这很重要，因为它确保矩阵在每个递归步骤中始终可以均匀地分为四个相等的子方格。 

输出应该是构造的四叉树的根节点。 每个节点包含：

 -`val`，代表该区域的值
 -`isLeaf`，它告诉我们该区域是否均匀
 - 四个象限的四个子指针

 如果一个节点所代表的整个区域仅包含相同的值，则该节点将成为叶节点。 例如，如果一个区域完全由`1`s，那么它可以被压缩为单个叶节点：```
val = True
isLeaf = True
```如果该区域同时包含`0`沙`1`s，则无法压缩。 在这种情况下，我们创建一个内部节点并将该区域递归地划分为：

 - 左上角
 - 右上角
 - 左下角
 - 右下角

 重要的观察是，四叉树本质上是一种分而治之的结构。 每个递归调用处理矩阵的一个平方部分。 

限制相对较小：

 -`n <= 64`-`n`总是 2 的幂

 即使矩阵很小，低效的重复扫描仍然会产生不必要的开销。 问题主要是如何正确实现递归细分。 

一些边缘情况很重要：

 - 每个值都相同的网格应该恰好生成一个叶节点。 
- 棋盘式网格交替值并强制细分到单个单元格。 
- A`1 x 1`grid 已经是一个叶节点，代表最小的可能输入。 
- 内部节点可以使用`True`或者`False`为了`val`，因为问题明确指出`val`被忽略时`isLeaf == False`。 

## 方法

 ### 蛮力方法

 暴力方法通过扫描区域内的所有单元来递归地检查每个子网格是否均匀。 

对于给定的正方形区域：

 1. 迭代每个单元格。 
2. 将所有值与第一个单元格进行比较。 
3. 如果每个值都匹配，则创建一个叶节点。 
4. 否则，将该区域分为四个相等的象限并递归。 

这是有效的，因为每个递归调用都会正确确定一个区域是否可以压缩为叶子或必须进一步细分。 

然而，缺点是重复扫描。 矩阵的大部分可以通过递归调用多次重新访问。 在最坏的情况下，例如棋盘图案，每个级别都会执行重复的全扫描。 

### 最佳方法

 最佳递归分而治之解决方案遵循相同的递归结构，但经过精心组织，以避免不必要的开销并保持实现简洁。 

关键的见解是四叉树自然对应于正方形区域的递归细分。 每个递归调用只需要三个信息：

 - 起始行
 - 起始栏
 - 当前方块大小

 The recursion mirrors the exact tree structure we are building. 如果一个区域是均匀的，则递归立即停止。 Otherwise, the region is split into four smaller squares.

 因为最大尺寸只有`64 x 64`，这种递归方法足够高效，不需要高级优化，例如前缀和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² log n) | O(n² log n) | O(log n) | 反复扫描区域以检查均匀性 |
 | 最佳 | O(n² log n) | O(n² log n) | O(log n) | 递归分而治之构造 |

 ## 算法演练

 1. 从整个网格开始。 

根节点代表完整矩阵，因此第一个递归调用覆盖从`(0, 0)`有尺寸`n`。 
2. 检查当前区域是否统一。 

扫描当前方形区域内的每个单元格并将每个值与第一个单元格进行比较。 如果所有值都匹配，则该区域可以被压缩为单个叶节点。 
3. 如果区域是均匀的，则创建叶节点。 

如果每个值都相同：

 - 设置`isLeaf = True`- 放`val`到区域值
 - 将所有孩子设置为`None`这成为一个终端递归情况。 
4. 将不均匀区域划分为四个象限。 

如果该区域包含混合值，那么我们必须对其进行细分。 计算：```
half = size // 2
```然后递归构造：

 - 左上角：`(row, col)`- 右上角：`(row, col + half)`- 左下角：`(row + half, col)`- 右下角：`(row + half, col + half)`5. 创建内部节点。 

内部节点有：

 -`isLeaf = False`- 任何值`val`- 通过递归分配的四个子指针
 6. 返回构造好的节点。 

每个递归调用都会返回其区域的根节点，从而允许完整的四叉树从底部向上自然地组装。 

### 为什么它有效

 该算法之所以有效，是因为每次递归调用都正确地代表了矩阵的一个正方形区域。 

如果一个区域是均匀的，则四叉树定义要求它成为叶节点。 如果不统一，则定义需要精确细分为四个相等的象限。 由于递归对每个子区域应用相同的逻辑，因此生成的树与所需的四叉树表示完全匹配。 

## Python 解决方案```python
from typing import List

# Definition for a QuadTree node.
class Node:
    def __init__(
        self,
        val,
        isLeaf,
        topLeft,
        topRight,
        bottomLeft,
        bottomRight,
    ):
        self.val = val
        self.isLeaf = isLeaf
        self.topLeft = topLeft
        self.topRight = topRight
        self.bottomLeft = bottomLeft
        self.bottomRight = bottomRight

class Solution:
    def construct(self, grid: List[List[int]]) -> 'Node':
        n = len(grid)

        def build(row: int, col: int, size: int) -> Node:
            first_value = grid[row][col]
            is_uniform = True

            for r in range(row, row + size):
                for c in range(col, col + size):
                    if grid[r][c] != first_value:
                        is_uniform = False
                        break
                if not is_uniform:
                    break

            if is_uniform:
                return Node(
                    val=bool(first_value),
                    isLeaf=True,
                    topLeft=None,
                    topRight=None,
                    bottomLeft=None,
                    bottomRight=None,
                )

            half = size // 2

            top_left = build(row, col, half)
            top_right = build(row, col + half, half)
            bottom_left = build(row + half, col, half)
            bottom_right = build(row + half, col + half, half)

            return Node(
                val=True,
                isLeaf=False,
                topLeft=top_left,
                topRight=top_right,
                bottomLeft=bottom_left,
                bottomRight=bottom_right,
            )

        return build(0, 0, n)
```实现直接遵循递归分治结构。 

嵌套的`build()`函数为一个正方形区域构造四叉树。 其参数确定：

 - 起始行
 - 起始列
 - 正方形的边长

 第一部分检查该区域是否均匀。 它扫描每个单元格并与该区域中的第一个值进行比较。 如果发现任何不匹配，则该区域不统一。 

如果该区域是均匀的，该函数立即返回一个叶节点。 

否则，该区域被分为四个相等的象限。 递归调用为每个象限构建子节点。 最后，当前节点成为包含这四个子节点的内部节点。 

递归自然终止，因为每次细分都会将区域大小减少一半，最终到达单单元区域。 

## 解决方案```go
/**
 * Definition for a QuadTree node.
 * type Node struct {
 *     Val bool
 *     IsLeaf bool
 *     TopLeft *Node
 *     TopRight *Node
 *     BottomLeft *Node
 *     BottomRight *Node
 * }
 */

func construct(grid [][]int) *Node {
    n := len(grid)

    var build func(row, col, size int) *Node

    build = func(row, col, size int) *Node {
        firstValue := grid[row][col]
        isUniform := true

        for r := row; r < row+size; r++ {
            for c := col; c < col+size; c++ {
                if grid[r][c] != firstValue {
                    isUniform = false
                    break
                }
            }

            if !isUniform {
                break
            }
        }

        if isUniform {
            return &Node{
                Val:         firstValue == 1,
                IsLeaf:      true,
                TopLeft:     nil,
                TopRight:    nil,
                BottomLeft:  nil,
                BottomRight: nil,
            }
        }

        half := size / 2

        topLeft := build(row, col, half)
        topRight := build(row, col+half, half)
        bottomLeft := build(row+half, col, half)
        bottomRight := build(row+half, col+half, half)

        return &Node{
            Val:         true,
            IsLeaf:      false,
            TopLeft:     topLeft,
            TopRight:    topRight,
            BottomLeft:  bottomLeft,
            BottomRight: bottomRight,
        }
    }

    return build(0, 0, n)
}
```Go 实现密切反映了 Python 逻辑。 

主要区别在于内存处理。 在 Go 中，节点是使用指针分配的`&Node{}`。 儿童参考资料的使用`nil`而不是`None`。 

布尔转换也略有不同。 由于网格包含整数，因此表达式：```go
firstValue == 1
```将整数转换为布尔值。 

Go 递归在这里自然起作用，因为递归深度很小，最多`log₂(64) = 6`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n² log n) | O(n² log n) | 每个递归级别扫描矩阵区域 |
 | 空间| O(log n) | 递归调用堆栈深度|

 递归深度是对数的，因为每个细分将边长减半。 

时间复杂度来自于重复扫描区域以确定均匀性。 在最坏的情况下，会发生许多递归调用，并且每个级别都会再次集体检查矩阵的大部分内容。 

自从`n <= 64`，这种复杂性很容易被接受。

 ## 边缘情况

 ### 单细胞网格

 一个`1 x 1`矩阵是最小的有效输入。 这种情况很重要，因为递归必须正确终止，而不尝试进一步细分。 

该实现自然地处理了这个问题，因为单个单元格始终是统一的。 递归函数立即创建一个叶节点。 

### 完全均匀矩阵

 每个值都相同的网格应该恰好生成一个叶节点，而不是许多较小的节点。 

有缺陷的实现可能会继续不必要的细分。 一致性扫描通过在所有值匹配后立即停止递归来防止这种情况发生。 

例如：```
[
 [1,1],
 [1,1]
]
```产生单个叶节点。 

### 最大细分模式

 棋盘图案是递归的最坏情况，因为没有更大的区域是均匀的。 

例子：```
[
 [0,1],
 [1,0]
]
```每个区域大于`1 x 1`必须细分。 这强调了递归结构并验证了象限坐标的计算是否正确。 

该实现可以安全地处理这个问题，因为每次递归调用都会将区域大小减少一半，直到到达单单元区域。
