 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 该问题给了我们一个名为的二进制数组`nums`，其中每个元素都是`0`或者`1`。 我们的任务是确定连续的最大数量`1`出现在数组中任意位置的 s。 

换句话说，我们需要扫描数组并找出最长的不间断序列`1`s。 每当我们遇到一个序列时，序列就会结束`0`。 最终答案是最长的序列的长度。 

例如，在数组中`[1,1,0,1,1,1]`，有两组连续的`1`是：
 - 第一组是`[1,1]`，其长度为`2`- 第二组是`[1,1,1]`，其长度为`3`自从`3`较大，则正确答案是`3`。 

约束告诉我们数组长度可以大到`10^5`。 这很重要，因为这意味着我们应该避免不必要的昂贵算法，例如检查每个可能的子数组。 首选有效的线性时间解决方案。 

输入还保证每个元素都是`0`或者`1`。 这大大简化了逻辑，因为我们只需要区分两种情况：

 - 继续连续`1`s
 - 重置连胜`0`出现

 预先考虑一些边缘情况很重要。 该数组可能包含所有`1`s，这意味着答案就是整个数组的长度。 该数组可能包含所有`0`s，意味着答案是`0`。 也可能存在多个长度相等的条纹，并且算法仍必须返回正确的最大值。 由于最小数组大小是`1`，我们永远不需要处理空输入数组。 

## 方法

 ### 蛮力方法

 一个简单的暴力解决方案是检查数组中每个可能的起始位置并计算有多少个连续的位置`1`从该位置继续。 

对于每个索引：

 - 如果当前值为`1`，继续前进，直到`0`被发现
 - 计算条纹长度
 - 更新迄今为止看到的最大连胜纪录

 这是有效的，因为每个可能的连续序列`1`s 被显式检查。 然而，该方法效率低下，因为相同的元素可能会被多次重新访问。 

考虑所有的数组`1`s:```
[1,1,1,1,1,1]
```从索引开始`0`，我们扫描几乎整个数组。 从索引开始`1`，我们再次扫描几乎整个剩余数组，依此类推。 这种重复的工作导致了二次时间复杂度。 

和`n`最多`10^5`， 一个`O(n^2)`解决办法太慢了。 

### 最佳方法

 关键的观察是我们不需要重复地重新扫描数组。 我们只需要在从左到右遍历一次时跟踪两个值：

 - 当前连续的条纹长度`1`s
 - 迄今为止看到的最大条纹长度

 每当我们遇到：

 - A`1`，我们延长当前的连续
 - A`0`，我们将当前连胜重置为`0`这是有效的，因为连续序列自然是在一次传递中处理的。 每个元素对连胜的贡献只有一次。 

由于我们只遍历数组一次并使用恒定的额外空间，因此这会产生最佳解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 重复扫描重叠的条纹`1`s |
 | 最佳 | O(n) | O(1) | O(1) | 单次通过同时跟踪当前和最大条纹 |

 ## 算法演练

 ### 最佳单遍算法

 1.初始化两个变量：

 -`current_streak = 0`-`max_streak = 0`

`current_streak`跟踪当前连续序列的长度`1`s。`max_streak`存储迄今为止看到的最大序列。 
2. 从左到右遍历数组。 

我们对每个元素只处理一次，因为数组只需要一次扫描。 
3. 如果当前元素是`1`, 增量`current_streak`。 

这意味着当前的连续序列`1`s继续。 
4. After incrementing, compare`current_streak`和`max_streak`。 

如果当前条纹较大，则更新`max_streak`。 
5. 如果当前元素是`0`， 重置`current_streak`到`0`。 

一个`0`打破了连续的顺序，因此任何未来的连续都必须重新开始。 
6. 继续直到数组末尾。 
7. 返回`max_streak`。 

遍历结束时，该变量包含最长连续序列的长度`1`s。 

### 为什么它有效

 该算法在整个执行过程中保持一个重要的不变量：

 -`current_streak`总是代表连续的数量`1`s 以当前位置结束
 -`max_streak`总是代表迄今为止遇到的最大连胜

 每当一个`0`出现时，当前序列无效并被重置。 由于每个元素都按顺序处理一次，因此每个可能的条纹都被恰好考虑一次。 因此，最终`max_streak`保证是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        current_streak = 0
        max_streak = 0

        for num in nums:
            if num == 1:
                current_streak += 1
                max_streak = max(max_streak, current_streak)
            else:
                current_streak = 0

        return max_streak
```实现首先初始化两个计数器。`current_streak`跟踪当前运行的连续`1`s，同时`max_streak`存储迄今为止找到的最佳结果。 

该循环仅迭代数组中的每个元素一次。 如果当前值为`1`，当前的连续性通过增加来延长`current_streak`。 随后，算法立即更新`max_streak`如果当前的条纹变得大于之前的最大值。 

如果当前值为`0`，连续序列被破坏。 算法重置`current_streak`回到`0`因为任何未来的连续走势都必须在这一点之后开始。 

最后该方法返回`max_streak`，其中包含遍历过程中遇到的最长序列。 

## 解决方案```go
func findMaxConsecutiveOnes(nums []int) int {
    currentStreak := 0
    maxStreak := 0

    for _, num := range nums {
        if num == 1 {
            currentStreak++

            if currentStreak > maxStreak {
                maxStreak = currentStreak
            }
        } else {
            currentStreak = 0
        }
    }

    return maxStreak
}
```Go 实现遵循与 Python 版本相同的逻辑。 Go 使用一个`range`循环遍历切片。 由于该问题中的整数非常小，因此不必担心整数溢出。 

从技术上讲，Go 切片可以为空，但问题是保证至少有一个元素。 即便如此，这个实现仍然会安全返回`0`对于空切片，因为循环根本不会执行。

 ## 边缘情况

 ### 数组仅包含一个

 输入如`[1,1,1,1]`可能会暴露实现中的错误，这些错误仅在遇到`0`。 在这种情况下，条纹会一直持续到数组末尾，因此实现必须在遍历期间不断更新最大值。 提供的解决方案通过更新正确处理这个问题`max_streak`每当发生时立即`1`已处理。 

### 数组仅包含零

 输入如`[0,0,0]`很重要，因为没有有效的条纹`1`根本没有。 一些不正确的实现可能会意外地初始化答案`1`或无法正常复位。 The current implementation initializes both counters to`0`并且仅在遇到`1`，所以结果正确地保持不变`0`。 

### 最长连胜出现在最后

 输入如`[0,1,1,1]`可能会破坏仅在连续结束时才确定结果的实现。 由于最长的条纹到达了最后一个元素，因此算法在迭代期间必须已经保持最大值。 提供的解决方案更新`max_streak`紧接在每个之后`1`，确保最后的连胜计数正确。 

### 多条等长条纹

 输入如`[1,1,0,1,1]`包含两条最大长度相同的条纹。 该算法应该返回长度本身，而不关心哪个条纹首先出现。 由于该实现仅跟踪数值最大值，因此自然可以正确处理等长条纹。
