[LeetCode 第 483 题](https://leetcode.com/problems/smallest-good-base/)

 **难度：** 🔴难
 **主题：** 数学、二分查找

 ## 解决方案

 ## 问题理解

 问题是要求我们找到最小的整数`k >= 2`使得给定的数字`n`可以用基数表示`k`所有数字都等于`1`。 换句话说，我们想要`n`是 的连续幂的总和`k`， 喜欢`1 + k + k^2 + ... + k^(m-1)`对于某个整数`m >= 2`。 输入`n`以字符串形式给出，因为它可能非常大，最多可达`10^18`，这超出了某些语言中典型的 32 位甚至 64 位整数限制。 输出也应为表示最小有效基数的字符串。 

该问题的重要方面包括理解`n`可能非常大，因此天真地迭代所有可能的基数是行不通的。 此外，数字序列全部`1`s 表示我们正在寻找几何级数和形式的数字。 要考虑的边缘情况是最小的有效情况`n`(3)、附近有很大的数`10^18`，以及 2 或 3 的幂，可能有多个有效底数。 

## 方法

 ### 蛮力

 天真的暴力方法会尝试每一个基地`k`从 2 到`n-1`， 转变`n`到该基数，并检查所有数字是否都是`1`。 虽然这保证了正确的答案，但速度非常慢，因为`n`可以大到`10^18`。 检查所有碱基`n-1`显然是不可行的。 

### 最佳方法

 关键的见解是`n`以基数表示`k`和大家一样`1`s 可以写成几何级数：`n = 1 + k + k^2 + ... + k^(m-1)`对于某些人来说`m >= 2`。 使用几何级数的公式，则变为：```
n = (k^m - 1) / (k - 1)
```这个方程允许我们重新表述问题：对于每一个可能的`m`（1的个数），找到一个整数`k`满足方程。 最大可能长度`m`发生在`k=2`因为较大的碱基会产生较短的序列。 因此，`m`范围从地板`log2(n)`减少到 2。对于每个`m`，我们可以解出`k`在 2 和 之间使用二分查找`n^(1/(m-1))`。 

这种方法大大减少了搜索空间，因为不是迭代潜在的`10^18`基数，我们最多迭代`log2(n)`序列长度和每个较小范围内的二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(log n) | 迭代所有碱基和校验位 |
 | 最佳 | O(log n * log n) | O(log n * log n) | O(1) | O(1) | 迭代可能的长度 m 和二分查找 k |

 ## 算法演练

 1. 转换输入字符串`n`为一个整数。 
2. 计算最大可能长度`max_m`的序列，即`floor(log2(n)) + 1`。 
3.循环`m`从`max_m`降至 2。 
4. 对于每个`m`，执行二分查找`k`在范围内`[2, n^(1/(m-1))]`。 
5. 对于每位候选人`k`,计算几何级数和`1 + k + k^2 + ... + k^(m-1)`。 
6. 如果总和等于`n`， 返回`k`作为字符串。 
7. 如果没有`k`被发现对于任何`m`， 返回`n-1`作为一个字符串（因为`n`在基地`n-1`总是`11`）。 

**为什么有效：** 循环确保我们首先尝试最长的序列，这将产生最小的碱基。 二分查找保证找到一个整数`k`完全满足几何级数和，避免精度误差。 

## Python 解决方案```python
class Solution:
    def smallestGoodBase(self, n: str) -> str:
        n_int = int(n)
        max_m = n_int.bit_length()  # floor(log2(n)) + 1

        for m in range(max_m, 1, -1):
            left, right = 2, int(n_int ** (1 / (m - 1))) + 1
            while left <= right:
                k = (left + right) // 2
                # geometric sum: (k**m - 1) // (k - 1)
                sum_ = 1
                curr = 1
                for _ in range(m - 1):
                    curr *= k
                    sum_ += curr
                    if sum_ > n_int:
                        break
                if sum_ == n_int:
                    return str(k)
                elif sum_ < n_int:
                    left = k + 1
                else:
                    right = k - 1
        return str(n_int - 1)
```Python实现首先转换`n`为一个整数并使用位长度计算最大序列长度`n`。 它从最长到最短的可能序列进行迭代，以优先考虑较小的碱基。 对于每个序列长度，二分搜索识别候选碱基`k`。 迭代计算几何级数和以避免溢出，如果总和超过，循环会提前中断`n`。 如果没有找到有效的碱基，则默认碱基是`n-1`。 

## 解决方案```go
import (
    "math"
    "strconv"
)

func smallestGoodBase(n string) string {
    nInt, _ := strconv.ParseInt(n, 10, 64)
    maxM := int(math.Log2(float64(nInt))) + 1

    for m := maxM; m >= 2; m-- {
        left, right := int64(2), int64(math.Pow(float64(nInt), 1.0/float64(m-1)))+1
        for left <= right {
            k := (left + right) / 2
            sum := int64(1)
            curr := int64(1)
            for i := 0; i < m-1; i++ {
                curr *= k
                sum += curr
                if sum > nInt {
                    break
                }
            }
            if sum == nInt {
                return strconv.FormatInt(k, 10)
            } else if sum < nInt {
                left = k + 1
            } else {
                right = k - 1
            }
        }
    }
    return strconv.FormatInt(nInt-1, 10)
}
```在围棋中，`strconv.ParseInt`将字符串转换为整数，并且`math.Log2`确定最大序列长度。 二分搜索迭代候选基并使用迭代计算几何级数`int64`算术。 结果以字符串形式返回，使用`strconv.FormatInt`。

 | 测量 | 复杂性 | 说明|
