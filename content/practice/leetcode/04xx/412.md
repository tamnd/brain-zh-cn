 # LeetCode 412，菲兹嗡嗡声

 ## 问题理解

 该问题要求我们为所有整数生成一个字符串列表`1`到`n`。 对于每个数字，我们应用一组整除规则：

 - 如果该数字可以被两者整除`3`和`5`，我们追加`"FizzBuzz"`。 
- 如果该数字只能被`3`，我们追加`"Fizz"`。 
- 如果该数字只能被`5`，我们追加`"Buzz"`。 
- 否则，我们将数字本身作为字符串附加。 

结果必须作为字符串数组返回，其中索引在概念上对应于来自的数字`1`通过`n`。 

例如，如果`n = 5`，序列变为：

 -`1`→`"1"`-`2`→`"2"`-`3`→`"Fizz"`-`4`→`"4"`-`5`→`"Buzz"`所以最终的输出是：```
["1","2","Fizz","4","Buzz"]
```约束条件`1 <= n <= 10^4`告诉我们输入大小相对较小。 即使是简单的线性扫描`1`到`n`是完全可以接受的。 不需要先进的优化技术或复杂的数据结构。 

一个重要的细节是条件的排序。 一个幼稚的实现可能会通过以下方式检查整除性`3`首先，然后整除`5`。 这会错误地对数字进行分类，例如`15`作为`"Fizz"`而不是`"FizzBuzz"`。 因此，必须在单独条件之前检查组合条件。 

该问题保证了`n`总是至少`1`，所以我们永远不需要处理空范围或无效输入。 

## 方法

 ### 蛮力方法

 蛮力方法是迭代每个数字`1`到`n`并确定应将哪个字符串添加到结果中。 

对于每个整数：

 - 检查它是否可以被两者整除`3`和`5`- 否则检查整除性`3`- 否则检查整除性`5`- 否则将整数转换为字符串

 这种方法之所以有效，是因为每个数字都独立地属于这些类别之一。 通过直接评估每个条件，我们保证数组中每个位置的正确输出。 

由于我们对每个数字只处理一次，并且每次整除性检查都需要恒定的时间，因此该解决方案对于问题约束来说已经足够有效。 

### 最佳解决方案的关键见解

 关键的观察是该问题不需要任何重复计算、嵌套迭代或辅助搜索结构。 每个数字都可以在常数时间内独立分类。 

由于可分性检查是极其廉价的操作，因此最佳解决方案只是从`1`到`n`。 

一个小的实现改进是增量构建输出字符串：

 - 以空字符串开头
 - 追加`"Fizz"`如果能整除`3`- 追加`"Buzz"`如果能整除`5`- 如果字符串为空，则使用数字值

 这避免了显式检查组合`15`条件并保持实现的整洁和可扩展性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 直接检查每个数字的所有整除条件 |
 | 最佳 | O(n) | O(n) | 使用增量字符串构造的单遍 |

 ## 算法演练

 1. 初始化一个空结果列表，用于存储最终的字符串。 
2. 迭代所有整数`1`到`n`，包含在内。 每次迭代都会确定一个数字的正确表示。 
3. 对于当前号码，创建一个空的临时字符串。 
4. 检查数字是否能被整除`3`。 如果是，请附加`"Fizz"`到临时字符串。 这是有效的，因为任何倍数`3`必须贡献`"Fizz"`输出的一部分。 
5. 检查数字是否能被整除`5`。 如果是，请附加`"Buzz"`到临时字符串。 如果这个数能被两者整除`3`和`5`，字符串自动变为`"FizzBuzz"`。 
6. 两次检查后，确定临时字符串是否仍为空。 如果为空，则该数字不能被两者整除`3`也不`5`，因此将数字本身转换为字符串。 
7. 将该数字的最终字符串附加到结果列表中。 
8. 继续，直到所有数字都来自`1`通过`n`已被处理。 
9. 返回完成的结果列表。 

### 为什么它有效

 每个整数来自`1`到`n`恰好属于以下四个类别之一：

 - 可被两者整除`3`和`5`- 只能被整除`3`- 只能被整除`5`- 不能被任何一个整除

 该算法系统地检查可分性，并为每个类别构建正确的字符串表示形式。 由于每个数字都只处理一次并附加一次，因此返回的数组是完整且排序正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def fizzBuzz(self, n: int) -> List[str]:
        result = []

        for number in range(1, n + 1):
            current = ""

            if number % 3 == 0:
                current += "Fizz"

            if number % 5 == 0:
                current += "Buzz"

            if current == "":
                current = str(number)

            result.append(current)

        return result
```实现首先创建一个名为的空列表`result`，它存储最终的输出。 

循环迭代自`1`通过`n`。 对于每个数字，都有一个名为的临时字符串`current`初始化为空。 

第一个条件检查整除性`3`。 如果属实的话，`"Fizz"`已附加。 第二个条件检查整除性`5`。 如果两个条件都为真，则自然形成串联`"FizzBuzz"`。 

在可除性检查之后，代码确定是否添加了任何内容`current`。 如果字符串仍然为空，则数字本身将转换为字符串。 

最后，计算值被附加到结果列表中。 处理完所有数字后，将返回列表。 

## 解决方案```go
func fizzBuzz(n int) []string {
    result := make([]string, 0, n)

    for number := 1; number <= n; number++ {
        current := ""

        if number%3 == 0 {
            current += "Fizz"
        }

        if number%5 == 0 {
            current += "Buzz"
        }

        if current == "" {
            current = fmt.Sprintf("%d", number)
        }

        result = append(result, current)
    }

    return result
}
```Go 实现遵循与 Python 版本相同的逻辑。 主要区别在于 Go 切片是使用容量显式初始化的`make`。 

字符串转换是使用`fmt.Sprintf("%d", number)`。 另一种常见的选择是`strconv.Itoa(number)`，这对于整数转换来说稍微更有效。 

与 Python 列表不同，Go 切片受益于预分配容量，因为它减少了追加操作期间的内部大小调整。

 ## 边缘情况

 一种重要的边缘情况是最小输入值，`n = 1`。 有缺陷的实现可能会错误地假设至少存在一个整除性匹配。 在这种情况下，算法正确返回`["1"]`因为这两个整除条件都不满足。 

另一个关键的边缘情况涉及可被两者整除的数字`3`和`5`， 例如`15`或者`30`。 一个常见的错误是检查整除性`3`首先并立即返回`"Fizz"`，这可以防止`"FizzBuzz"`从生产开始。 该实现通过独立附加来避免这个问题`"Fizz"`和`"Buzz"`到同一个字符串中。 

第三种边缘情况是处理连续的特殊值。 例如，围绕范围`14`,`15`， 和`16`，输出从正常数转变为`"FizzBuzz"`并恢复到正常数字。 该实现在每次迭代期间正确重置临时字符串，防止先前迭代的剩余值影响未来的输出。
