 ## 解决方案

 ## 问题理解

 该问题要求我们确定使整数数组中的所有元素相等所需的最小移动次数，其中移动包括将单个元素递增或递减`1`。 换句话说，我们希望找到一个目标值，当所有元素都调整到该目标值时，需要的总步骤最少。 

输入是整数列表，其中可以包含负数，并且最多可以包含 100,000 个元素。 输出是一个表示最小移动次数的整数。 这些约束意味着简单的方法（例如尝试数组元素范围内的每个可能的目标值）将会太慢，因为数组长度和元素范围很大。 

要记住的边缘情况包括所有元素都已相等的数组、长度数组`1`、负数数组以及最小值或最大值极值的数组（例如`-10^9`或者`10^9`）。 该问题保证移动次数适合 32 位整数，因此我们不需要处理输出中的整数溢出。 

## 方法

 **暴力方法**将涉及尝试将数组的最小和最大元素之间的每个整数值作为目标，并计算将每个元素转换为该目标所需的移动总和。 虽然这是正确的，因为它评估了所有可能性，但效率很低，因为元素范围可达`2 * 10^9`，使得这种方法不可行。 

**最佳方法**依赖于统计学的一个关键见解：一组数字的绝对差之和在中位数处最小化。 中位数将数组划分为一半元素较小，一半元素较大。 将所有元素转换为中位数可确保每个增量和减量以产生最小总移动的方式平衡。 为了实现这一点，我们可以对数组进行排序并选择中间元素作为中位数。 对于具有偶数个元素的数组，两个中间值之间的任何数字都将产生相同的最小移动量，因此选择任一中间元素都有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((max-min) * n) | O(1) | O(1) | 尝试元素范围内的每个整数； 对于大范围来说太慢|
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 对数组进行排序，选择中位数，求和绝对差 |

 ## 算法演练

 1. 对数组进行排序`nums`按非递减顺序。 Sorting allows us to identify the median directly, which is the key to minimizing absolute differences.
 2. 确定中位数。 If the length of the array is odd, it is the middle element. If it is even, pick either of the two middle elements.
 3. 初始化变量`moves`到`0`累计移动总数。 
4. 迭代数组的每个元素，并将该元素与中位数的绝对差值相加`moves`。 这表示将该元素带到中位数所需的移动次数。 
5. 返回`moves`作为最终答案。 

**为什么有效：** 中位数可以最小化绝对偏差的总和。 任何大于中位数的数字都会增加数组较小的一半贡献的总移动量，任何小于中位数的数字都会增加较大的一半贡献的总移动量。 因此，中位数是最优目标。 

## Python 解决方案```python
from typing import List

class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        nums.sort()
        median = nums[len(nums) // 2]
        moves = 0
        for num in nums:
            moves += abs(num - median)
        return moves
```解决方案首先排序`nums`直接访问中位数。 中位数在索引处找到`len(nums) // 2`，循环计算每个元素与中位数之间的绝对差之和。 结果是利用中位数的统计特性的最小移动次数。 

## 解决方案```go
import (
    "sort"
    "math"
)

func minMoves2(nums []int) int {
    sort.Ints(nums)
    median := nums[len(nums)/2]
    moves := 0
    for _, num := range nums {
        moves += int(math.Abs(float64(num - median)))
    }
    return moves
}
```在 Go 中，我们使用`sort.Ints`对切​​片进行排序。 自从`math.Abs`使用浮点数，我们将整数差转换为`float64`并回到`int`。 逻辑与 Python 相同，迭代切片以将绝对差值与中位数相加。

 ## 边缘情况

 **单元素数组：** 只有一个数字，无需移动。 该实现会自动处理这个问题，因为循环结束了`nums`计算`abs(num - median)`，为零。 

**所有元素相等：** 如果所有元素都相同，则中位数就是该元素本身。 循环求和`abs(num - median)`， 导致`0`。 

**负数和极值：** 数组可能包含非常大的正数或负数。 该算法可以正常工作，因为绝对差计算可以自然地处理负数。 排序处理整个整数范围而不会溢出，32 位答案保证确保`moves`不超过整数限制。
