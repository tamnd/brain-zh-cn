 **主题：** 数组、字符串、动态规划、深度优先搜索、Trie、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们识别给定列表中的所有单词，这些单词可以通过连接同一列表中的至少两个其他单词来形成。 换句话说，每个连接的单词必须完全由输入数组中存在的较小单词组成。 输入是唯一小写字符串的列表，输出是满足串联标准的字符串列表。 

约束告诉我们，单词总数最多可达 10,000 个，所有单词的总组合长度最多可达 100,000 个字符。 每个单词都相对较短（最多 30 个字符）。 这表明有效的解决方案必须避免过度重复的子字符串检查并利用单词的快速查找。 

边缘情况包括本身非常短的单词、由于列表中不存在更小的单词而无法连接的单词以及本身是子串的单词。 保证单词唯一可以防止重复，但不能防止单词成为其他单词的前缀。 

## 方法

 暴力方法涉及检查每个单词是否可以通过连接列表中的两个或多个其他单词来形成。 这可以通过尝试将单词每一个可能的分割成两部分并递归检查每个部分是否是有效的连接单词来完成。 虽然正确，但这种方法很快就会变得非常慢，因为子字符串分割的数量随着单词的长度呈指数增长。 

最佳方法结合使用哈希集进行快速单词查找和动态编程，以避免冗余计算。 对于每个单词，我们维护一个布尔数组，其中`dp[i]`指示子串是否达到索引`i`可以通过连接集合中的单词来形成。 通过以系统的方式检查所有可能的分割并重用较小子串的结果，我们减少了冗余计算并获得了更好的性能。 此外，按长度对单词进行排序允许我们只尝试从较小的单词组成较长的单词，这自然会强制执行“至少两个单词”的要求。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 2^L) | O(L) | 递归地检查每个长度为 L 的单词的所有分割，对于约束来说太慢了 |
 | 最佳| O(N * L^2) | O(N * L^2) | O(N + L) | 使用哈希集进行快速查找，使用 DP 进行子字符串连接 |

 ## 算法演练

 1. 按长度对单词进行排序。 这确保了在评估单词时，所有潜在的较小组件都已被考虑。 
2. 初始化一个哈希集来存储我们到目前为止看到的所有单词。 这允许恒定时间查找来检查子字符串是否是有效单词。 
3. 迭代排序列表中的每个单词。 
4.对于每个字，使用动态编程数组`dp`长度`len(word) + 1`， 在哪里`dp[i]`表示子串是否`word[0:i]`可以通过连接较小的单词来形成。 
5. 设置`dp[0] = True`因为空字符串是非常有效的。 
6. 对于每个索引`i`从 1 到`len(word)`,检查每个索引`j`从 0 到`i`。 如果`dp[j]`是真的并且`word[j:i]`存在于集合中，集合`dp[i] = True`并打破。 
7. 如果`dp[len(word)]`为 True 并且单词长度非零，则将该单词添加到结果列表中。 
8. 将当前单词添加到哈希集中，以便它可用于形成更长的单词。 

**为什么有效**：DP 数组确保每个可能的子字符串组合都被检查一次。 通过首先迭代较小的单词，我们保证只有当一个单词可以完全由以前见过的单词组成时，才将其视为连接单词。 这种方法避免了将单词本身算作一个组成部分，并且满足“至少两个单词”的约束。 

## Python 解决方案```python
from typing import List

class Solution:
    def findAllConcatenatedWordsInADict(self, words: List[str]) -> List[str]:
        words.sort(key=len)
        word_set = set()
        result = []
        
        for word in words:
            if not word:
                continue
            dp = [False] * (len(word) + 1)
            dp[0] = True
            for i in range(1, len(word) + 1):
                for j in range(i):
                    if dp[j] and word[j:i] in word_set:
                        dp[i] = True
                        break
            if dp[len(word)]:
                result.append(word)
            word_set.add(word)
        
        return result
```此实现首先对单词进行排序，以确保首先处理较小的组件。 DP 数组针对每个单词进行初始化，并且嵌套循环有效地确定是否可以从先前看到的单词形成子串。 在处理后将当前单词添加到集合中可确保它有助于形成更长的单词，但不会错误地形成自身。 

## 解决方案```go
func findAllConcatenatedWordsInADict(words []string) []string {
    sort.Slice(words, func(i, j int) bool {
        return len(words[i]) < len(words[j])
    })
    
    wordSet := make(map[string]bool)
    result := []string{}
    
    for _, word := range words {
        if len(word) == 0 {
            continue
        }
        dp := make([]bool, len(word)+1)
        dp[0] = true
        for i := 1; i <= len(word); i++ {
            for j := 0; j < i; j++ {
                if dp[j] && wordSet[word[j:i]] {
                    dp[i] = true
                    break
                }
            }
        }
        if dp[len(word)] {
            result = append(result, word)
        }
        wordSet[word] = true
    }
    
    return result
}
```在 Go 中，切片用于 DP 数组，映射用于单词查找。 排序是用`sort.Slice`。 逻辑反映了 Python 版本，仔细处理了切片索引和映射查找。 处理后向映射添加单词可确保其可用于后续迭代中的串联。

 ## 边缘情况

 一种边缘情况是输入中的空字符串。 我们的实现会跳过空词，防止误报或越界错误。 

另一个重要的情况是，当一个单词可以通过多次重复一个较小的单词来形成时，例如`["a","aa","aaa"]`。 即使同一单词多次使用，DP 方法也能正确识别串联，因为该算法允许重复使用单词来形成更长的单词。
