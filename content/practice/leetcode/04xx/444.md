[LeetCode 第 444 题](https://leetcode.com/problems/sequence-reconstruction/)

 **难度：** 🟡 中等
 **主题：** 数组、图论、拓扑排序

 ## 解决方案

 ## 问题理解

 这道题要求我们判断给定的数组是否`nums`两者都是：

 1. 中所有数组的有效最短超序列`sequences`2.唯一可能的最短超序列

 超序列是包含以下每个序列的序列`sequences`作为子序列。 由于子序列仅需要相对排序，因此每个序列在元素之间施加排序约束。 

例如，如果一个序列是`[1, 3]`，那么任何有效的超序列必须放置`1`前`3`。 

关键的挑战是独特性。 如果排序约束不完整，则可能存在多个有效的最短超序列。 

考虑：```
sequences = [[1,2],[1,3]]
```两个都`[1,2,3]`和`[1,3,2]`满足约束条件，因为没有任何内容指定是否`2`必须先来`3`反之亦然。 

问题给出：

 -`nums`，整数的排列`1`到`n`-`sequences`，派生自的子序列的集合`nums`我们必须回来`true`仅当：

 -`nums`可以根据排序约束重建
 - 不可能有其他最短订购

 约束条件很重要：

 -`n`可以达到`10^4`- 总序列长度可达`10^5`这立即排除了排列或所有拓扑排序的强力生成。 

问题自然就变成了图问题：

 - 每个数字都是一个节点
 - 序列中的每个相邻对定义一条有向边

 例如：```
[1,2,3]
```创建边缘：```
1 -> 2
2 -> 3
```那么问题就变成了：

 “这个有向图是否恰好具有一个有效的拓扑排序，它是否等于`nums`？”

 一些边缘情况很重要：

 - 缺少数字`sequences`- 多个有效订单
 - 序列太短，无法唯一确定排序
 - 多个序列引入的重复边缘
 - 有效订购时间短于`nums`- 断开连接的图形组件

 该问题保证：

 -`nums`是一个排列`1..n`- 每个序列都是以下序列的子序列`nums`这意味着我们不需要验证序列是否违反`nums`，但我们仍然必须验证唯一性和完整性。 

## 方法

 ### 蛮力方法

 强力解决方案将尝试生成所有可能的最短超序列，以满足以下条件所施加的排序约束：`sequences`。 

我们可以：

 1. 构建所有排序约束
 2. 生成每个有效的拓扑排序
 3. 计算有多少个存在
 4. 检查1是否存在且等于`nums`这是有效的，因为每个最短的超序列都对应于依赖图的拓扑排序。 

然而，生成所有拓扑排序的成本极其昂贵。 仅具有几个不受约束的节点的图已经可以产生阶乘许多排序。 

例如：```
[1,2]
[1,3]
[1,4]
```允许：```
1,2,3,4
1,2,4,3
1,3,2,4
1,3,4,2
...
```有效订单数量呈爆炸式增长。 

和`n = 10^4`，暴力破解是完全行不通的。 

### 关键见解

 关键的观察是：

 有向无环图具有唯一的拓扑排序当且仅当在拓扑排序的每一步都恰好有一个具有入度的节点`0`。 

这将问题转换为带有附加唯一性检查的标准拓扑排序。 

我们从构建依赖图`sequences`并执行卡恩算法：

 - 保持度数
 - 重复删除具有入度的节点`0`如果在任意时刻有多个节点具有入度`0`，存在多个有效排序，因此重建不是唯一的。 

我们还验证生成的订单是否完全匹配`nums`。 

这给出了有效的线性时间解决方案。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成所有有效的拓扑排序 |
 | 最佳| O(V + E) | O(V + E) | 使用具有唯一性检查的拓扑排序 |

 这里：

-`V = n`-`E`是排序关系的数量

 由于总序列长度最多为`10^5`，最优解很容易满足约束条件。 

## 算法演练

 ### 1. 构建图表

 我们创造：

 - 有向边的邻接表
 - 用于计算传入边的入度数组

 对于每一个相邻的对`(a, b)`在每个序列中：```
a must come before b
```所以我们添加：```
a -> b
```我们在邻接列表中使用一个集合来避免重复的边，因为重复的边会错误地增加入度。 

### 2.初始化入度

 每次我们添加一条边：```
a -> b
```我们增加：```
indegree[b]
```入度告诉我们一个节点还有多少个先决条件。 

### 3.查找所有入度为0的节点

 这些节点当前没有未满足的依赖关系，并且可以合法地出现在排序中的下一个节点。 

我们将它们放入队列中。 

### 4. 在拓扑排序期间强制唯一性

 在每次迭代时：

 - 如果队列包含多个节点，则存在多个有效选择
 - 因此存在多种拓扑排序
 - 因此重建并不是唯一的

 于是我们立即返回`false`。 

这是核心唯一性条件。 

### 5. 与 nums 比较

 当我们从队列中删除一个节点时，它必须与`nums`。 

如果不是，那么即使该图具有唯一的排序，它也不是由下式给出的排序`nums`。 

### 6. 删除出边

 对于当前节点：

 - 减少所有邻居的入度
 - 如果邻居的入度变为`0`，将其添加到队列中

 这模拟了令人满意的依赖关系。 

### 7. 验证完整重建

 最后：

 - 如果我们准确处理`n`节点，重建成功
 - 否则某些节点丢失或无法访问

 返回处理后的计数是否等于`n`。 

### 为什么它有效

 卡恩的拓扑排序始终为 DAG 生成有效的拓扑排序。 

唯一性属性来自以下事实：如果两个或多个节点同时具有入度`0`，我们可以先选择其中一个，从而产生不同的有效顺序。 

因此：

 - 恰好有一个具有入度的节点`0`每一步都意味着独特的顺序
 - 匹配每个提取的节点`nums`保证唯一排序等于`nums`因此算法正确地判断是否`nums`是唯一的最短超序列。 

## Python 解决方案```python
from collections import defaultdict, deque
from typing import List

class Solution:
    def sequenceReconstruction(self, nums: List[int], sequences: List[List[int]]) -> bool:
        n = len(nums)

        graph = defaultdict(set)
        indegree = [0] * (n + 1)

        seen = set()

        for sequence in sequences:
            for num in sequence:
                seen.add(num)

            for i in range(len(sequence) - 1):
                u = sequence[i]
                v = sequence[i + 1]

                if v not in graph[u]:
                    graph[u].add(v)
                    indegree[v] += 1

        if len(seen) != n:
            return False

        queue = deque()

        for num in range(1, n + 1):
            if indegree[num] == 0:
                queue.append(num)

        index = 0

        while queue:
            if len(queue) > 1:
                return False

            current = queue.popleft()

            if nums[index] != current:
                return False

            index += 1

            for neighbor in graph[current]:
                indegree[neighbor] -= 1

                if indegree[neighbor] == 0:
                    queue.append(neighbor)

        return index == n
```实现首先构建有向图和入度数组。 

邻接表使用`defaultdict(set)`而不是列表，因为必须忽略重复的边。 如果我们允许重复，入度可能会人为地变大并阻止有效节点进入队列。 

这`seen`设置跟踪是否每个数字来自`1`到`n`出现在某处`sequences`。 如果数字从未出现，则没有足够的信息来重建`nums`，所以我们立即返回`False`。 

接下来，我们用所有具有入度的节点来初始化队列`0`。 

主循环执行卡恩的拓扑排序。 在处理一个节点之前，我们检查队列中是否存在多个选择。 如果是这样，则排序不是唯一的。 

我们还将每个提取的节点与中的相应值进行比较`nums`。 这确保了唯一的排序与目标排列完全匹配。 

最后，在处理完所有可达节点后，我们验证是否准确`n`节点被重建。 

## 解决方案```go
package main

import "container/list"

func sequenceReconstruction(nums []int, sequences [][]int) bool {
	n := len(nums)

	graph := make([]map[int]bool, n+1)
	indegree := make([]int, n+1)

	seen := make(map[int]bool)

	for _, seq := range sequences {
		for _, num := range seq {
			seen[num] = true
		}

		for i := 0; i < len(seq)-1; i++ {
			u := seq[i]
			v := seq[i+1]

			if graph[u] == nil {
				graph[u] = make(map[int]bool)
			}

			if !graph[u][v] {
				graph[u][v] = true
				indegree[v]++
			}
		}
	}

	if len(seen) != n {
		return false
	}

	queue := list.New()

	for i := 1; i <= n; i++ {
		if indegree[i] == 0 {
			queue.PushBack(i)
		}
	}

	index := 0

	for queue.Len() > 0 {
		if queue.Len() > 1 {
			return false
		}

		front := queue.Front()
		current := front.Value.(int)
		queue.Remove(front)

		if nums[index] != current {
			return false
		}

		index++

		for neighbor := range graph[current] {
			indegree[neighbor]--

			if indegree[neighbor] == 0 {
				queue.PushBack(neighbor)
			}
		}
	}

	return index == n
}
```Go 的实现与 Python 解决方案非常相似。 

由于Go没有内置的双端队列，我们​​使用`container/list`作为队列结构。 

邻接表的实现如下：```go
[]map[int]bool
```这允许有效的重复边缘检测。 

Go 切片自动用零值初始化，因此入度数组从全零开始正确。 

不存在整数溢出问题，因为所有值都在问题约束之内。

 ## 边缘情况

 当一些数字来自`nums`从未出现在任何地方`sequences`。 在这种情况下，没有足够的信息来迫使这些数字处于独特的位置。 例如：```
nums = [1,2,3]
sequences = [[1,2]]
```数字`3`永远不会出现，因此多个最短超序列是可能的。 该实现通过跟踪所有看到的数字并准确验证来处理此问题`n`出现不同的数字。 

另一个微妙的边缘情况涉及重复边缘。 多个序列可能包含相同的相邻关系：```
[[1,2],[1,2],[2,3]]
```如果重复添加重复的边，入度将变得不正确。 节点`2`可能会错误地接收入度`2`而不是`1`。 该解决方案通过将邻居存储在集合中并仅在首次添加新边时增加入度来避免这种情况。 

第三个重要的边缘情况是断开连接的组件：```
[[1,2],[3,4]]
```两个都`[1,2,3,4]`和`[3,4,1,2]`满足约束条件。 由于多个分量具有入度`0`同时存在多个有效排序。 队列大小检查正确检测到这种歧义并返回`False`。 

当图表产生不等于的唯一排序时，就会出现另一个棘手的情况`nums`。 即使重建是唯一的，它也必须与提供的排列完全匹配。 该实现通过将从队列中删除的每个节点与相应的索引进行比较来验证这一点`nums`。
