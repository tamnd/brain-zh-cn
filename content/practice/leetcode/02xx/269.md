 # LeetCode 269，外星人词典

 ## 问题理解

 这个问题要求我们重建未知外星语言中的字符顺序。 

我们得到了一个已经根据外来语言的词典顺序排序的单词列表。 字母表本身仍然使用小写英文字母，但字母之间的顺序未知。 我们的任务是推断这些字母的有效顺序。 

重要的观察是，词典排序的工作方式与英语中的词典排序类似。 比较两个单词时，字符不同的第一个位置决定这两个字符之间的顺序。 

例如：```
"wrt"
"wrf"
```第一个不同的字符是`t`和`f`，因此我们知道：```
t comes before f
```这些关系形成一个有向图：```
t -> f
```最终答案是该图的拓扑排序。 

输入是一个字符串数组：```
words[i]
```每个单词都包含小写英文字母。 保证单词仅包含有效字符，但顺序本身可能无效。 

输出应该是：

 - 如果可能的话，表示一个有效字符顺序的字符串
 - 空字符串`""`如果字典顺序矛盾

 限制相对较小：

 - 最多100字
 - 每个单词长度最多100
 - 仅限小写英文字母

 这意味着我们不需要极其高级的优化，但我们确实需要一个正确的基于图的解决方案。 

一些边缘情况尤其重要：

 1. 排序图中的循环

 如果我们推导出如下关系：```
a -> b
b -> c
c -> a
```那么不存在有效的排序。 

1. 前缀失效

 这是最棘手的案例之一。 

例子：```
["abc", "ab"]
```这是无效的，因为较长的单词出现在其自己的前缀之前。 在任何字典顺序中，`"ab"`必须先来`"abc"`。 

1. Characters with no edges

 有些字母可能会出现在单词中，但从不参与排序约束。 They still must appear in the final answer.

 1. Multiple valid orderings

 该问题允许返回任何有效的拓扑排序。 

## 方法

 ### 蛮力方法

 暴力方法将尝试生成唯一字符的所有可能排列，并测试每个排列是否满足字典顺序。 

假设有`k`独特的人物。 我们可以：

 1. 生成这些字符的每个排列
 2. 构建排列的排名图
 3. 验证所有相邻单词是否排序正确

 这种方法在理论上是正确的，因为它最终会检查所有可能的字母顺序。 

然而，它太慢了。 

排列数为：```
k!
```即使只有 10 个独特的角色：```
10! = 3,628,800
```搜索空间很快就会变得巨大。 

### 最优方法，图+拓扑排序

 关键的见解是每对相邻的单词都为我们提供了直接的排序信息。 

当两个相邻单词在某个位置不同时：```
word1[i] != word2[i]
```那么我们立即知道：```
word1[i] comes before word2[i]
```这些关系自然地形成一个有向图。 

例如：```
w -> e
e -> r
r -> t
t -> f
```找到有效的字母顺序就相当于找到图的有效拓扑顺序。 

拓扑排序之所以有效，是因为：

 - 有向边表示排序约束
 - 有效的拓扑顺序尊重所有约束
 - 循环表明矛盾的约束

 我们可以使用卡恩算法（基于 BFS 的拓扑排序）来有效地计算排序。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k! * n * m) | O(k! * n * m) | O(k) | 生成所有可能的字符顺序 |

 在哪里：

-`C`= 唯一字符总数
 -`E`= 排序关系的数量

 ## 算法演练

 1. 初始化图和入度图

 我们首先从所有单词中收集每个独特的字符。 

即使一个字符没有传入或传出边缘，它仍然属于最终排序，因此每个字符都必须存在于图结构中。 

我们维持：

 -`graph[char]`, 邻接表
 -`indegree[char]`, 传入边数

 1.比较相邻的单词

 我们比较：```
words[i]
words[i + 1]
```因为只有相邻的单词才提供直接的词典编排约束。 

1. 检测无效前缀情况

 在比较字符之前，我们检查：```
if len(word1) > len(word2) and word1.startswith(word2)
```例子：```
["abc", "ab"]
```这在字典顺序中是不可能的，所以我们立即返回`""`。 

1. 找到第一个不同的字符

 我们逐个比较角色的位置。 

第一个不匹配决定了排序关系。 

例子：```
"wrt"
"wrf"
```第一个区别是：```
t != f
```所以：```
t -> f
```我们添加一条有向边。 

我们只使用第一个不同的字符，因为一旦字典顺序已经确定，后面的字符就不会提供任何信息。 

1. 仔细建立入度

 添加边时：```
u -> v
```我们增加：```
indegree[v]
```我们还使用集合检查来避免重复的边。 

1.初始化BFS队列

 所有具有入度的字符`0`没有先决条件。 

这些可以首先出现在排序中。 

我们将它们放入队列中。 

1. 进行拓扑排序

 我们反复强调：

 - 从队列中删除一个节点
 - 将其添加到答案中
 - 减少邻居的度数
 - 推入入度变为的邻居`0`这确保了字符仅在满足所有先决条件后才出现。 

1. 检测周期

 如果生成的排序长度小于唯一字符的数量，则某些节点永远不会被处理。 

这意味着存在一个循环。 

在这种情况下我们返回`""`。 

### 为什么它有效

 该图精确地表示了从字典派生的所有排序约束。 

拓扑排序保证每个有向边：```
u -> v
```出现与`u`前`v`。 

如果存在循环，则不可能进行此类排序，因为某些字符将间接依赖于自身。 

因此：

 - 成功的拓扑排序给出了有效的外星字母表
 - 未能正确处理所有节点识别矛盾

 ## Python 解决方案```python
from typing import List
from collections import defaultdict, deque

class Solution:
    def alienOrder(self, words: List[str]) -> str:
        # Initialize graph and indegree for all unique characters
        graph = defaultdict(set)
        indegree = {}

        for word in words:
            for char in word:
                indegree[char] = 0

        # Build graph
        for i in range(len(words) - 1):
            word1 = words[i]
            word2 = words[i + 1]

            # Invalid prefix case
            if len(word1) > len(word2) and word1.startswith(word2):
                return ""

            min_length = min(len(word1), len(word2))

            for j in range(min_length):
                if word1[j] != word2[j]:
                    parent = word1[j]
                    child = word2[j]

                    # Avoid duplicate edges
                    if child not in graph[parent]:
                        graph[parent].add(child)
                        indegree[child] += 1

                    break

        # Start with all nodes having indegree 0
        queue = deque()

        for char in indegree:
            if indegree[char] == 0:
                queue.append(char)

        result = []

        # Kahn's topological sort
        while queue:
            current = queue.popleft()
            result.append(current)

            for neighbor in graph[current]:
                indegree[neighbor] -= 1

                if indegree[neighbor] == 0:
                    queue.append(neighbor)

        # Cycle detection
        if len(result) != len(indegree):
            return ""

        return "".join(result)
```实现首先初始化中的所有唯一字符`indegree`地图。 这保证了最终答案中保留了孤立的字符。 

该图使用了一个`defaultdict(set)`因此自然避免了重复的边缘。 防止重复边很重要，因为多个相同的约束不应人为地增加入度计数。 

相邻词比较阶段提取排序关系。 只有第一个不同的字符很重要，因为字典顺序是在第一次不匹配时立即决定的。 

前缀验证在字符比较之前处理。 这会捕获无效输入，例如：```python
["abc", "ab"]
```BFS 阶段实现了 Kahn 算法。 有入度的字符`0`首先处理它们，因为它们没有先决条件。 

最后，循环检测将已处理节点的数量与唯一字符的数量进行比较。 如果它们不同，则循环会阻止拓扑排序的完成。 

## 解决方案```go
package main

import (
	"strings"
)

func alienOrder(words []string) string {
	graph := make(map[byte]map[byte]bool)
	indegree := make(map[byte]int)

	// Initialize all characters
	for _, word := range words {
		for i := 0; i < len(word); i++ {
			indegree[word[i]] = 0
		}
	}

	// Build graph
	for i := 0; i < len(words)-1; i++ {
		word1 := words[i]
		word2 := words[i+1]

		// Invalid prefix case
		if len(word1) > len(word2) &&
			strings.HasPrefix(word1, word2) {
			return ""
		}

		minLen := len(word1)
		if len(word2) < minLen {
			minLen = len(word2)
		}

		for j := 0; j < minLen; j++ {
			if word1[j] != word2[j] {
				parent := word1[j]
				child := word2[j]

				if graph[parent] == nil {
					graph[parent] = make(map[byte]bool)
				}

				// Avoid duplicate edges
				if !graph[parent][child] {
					graph[parent][child] = true
					indegree[child]++
				}

				break
			}
		}
	}

	// Queue for BFS
	queue := []byte{}

	for char, degree := range indegree {
		if degree == 0 {
			queue = append(queue, char)
		}
	}

	result := []byte{}

	// Kahn's algorithm
	for len(queue) > 0 {
		current := queue[0]
		queue = queue[1:]

		result = append(result, current)

		for neighbor := range graph[current] {
			indegree[neighbor]--

			if indegree[neighbor] == 0 {
				queue = append(queue, neighbor)
			}
		}
	}

	// Cycle detection
	if len(result) != len(indegree) {
		return ""
	}

	return string(result)
}
```Go 实现遵循与 Python 解决方案相同的算法结构。 

一个区别是图形表示。 Go 没有内置的集合类型，因此邻接表使用：```go
map[byte]bool
```模拟一组。 

BFS队列是使用切片来实现的。 删除第一个元素：```go
queue = queue[1:]
```对于给定的约束，工作效率足够高。 

Go 还需要显式处理缺失的映射，因此邻接映射在插入边之前会被延迟初始化。

from typing import List

class Solution:
    def alienOrder(self, words: List[str]) -> str:
        from collections import defaultdict, deque

        graph = defaultdict(set)
        indegree = {}

        for word in words:
            for char in word:
                indegree[char] = 0

        for i in range(len(words) - 1):
            word1 = words[i]
            word2 = words[i + 1]

            if len(word1) > len(word2) and word1.startswith(word2):
                return ""

            for j in range(min(len(word1), len(word2))):
                if word1[j] != word2[j]:
                    if word2[j] not in graph[word1[j]]:
                        graph[word1[j]].add(word2[j])
                        indegree[word2[j]] += 1
                    break

        queue = deque(
            [c for c in indegree if indegree[c] == 0]
        )

        result = []

        while queue:
            current = queue.popleft()
            result.append(current)

            for neighbor in graph[current]:
                indegree[neighbor] -= 1

                if indegree[neighbor] == 0:
                    queue.append(neighbor)

        if len(result) != len(indegree):
            return ""

        return "".join(result)

 ## 边缘情况

 ### 无效的前缀关系

 此问题中最常见的错误之一来自未能处理前缀违规。 

例子：```
["abc", "ab"]
```幼稚的实现可能会比较字符，发现没有不匹配，并错误地得出排序有效的结论。 

然而，按照字典顺序，较短的前缀必须始终出现在较长的单词之前。 自从`"abc"`出现在之前`"ab"`，输入无效。 

实现明确检查：```
if len(word1) > len(word2) and word1.startswith(word2):
```并立即返回`""`。 

### 依赖图中的循环

 另一个关键的边缘情况是循环依赖。 

例子：```
["z","x","z"]
```这将创建：```
z -> x
x -> z
```没有有效的字母表可以同时满足这两个约束。 

该实现通过拓扑排序自然地检测到这一点。 如果某些节点从未达到入度`0`，它们无法被处理，这意味着存在循环。 

### 没有约束的字符

 有些角色可能永远不会参与任何排序关系。 

例子：```
["abc"]
```没有边缘，因为只有一个单词。 

有缺陷的实现可能会完全忽略这些字符。 

该解决方案通过在图形构建之前初始化每个唯一字符来避免该问题：```
for word in words:
    for char in word:
        indegree[char] = 0
```结果，孤立的字符仍然出现在最终的排序中。
