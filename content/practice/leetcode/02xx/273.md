 ## 解决方案

 ## 问题理解

 该问题要求我们将一个非负整数转换为其英文单词表示形式。 而不是返回数字，例如`12345`，我们必须生成一个格式正确的英语短语，例如`"Twelve Thousand Three Hundred Forty Five"`。 

输入是单个整数`num`在哪里：

-`0 <= num <= 2^31 - 1`- 最大可能值为`2147483647`输出必须遵循数字的标准英文命名约定。 这包括处理：

 - 单位如`One`,`Two`,`Three`- 数十个，例如`Twenty`,`Thirty`,`Forty`- 来自的特殊号码`10`到`19`- 缩放单词，例如`Thousand`,`Million`， 和`Billion`最重要的观察是英语数字自然地分为三位数的块。 例如：

-`1,234,567`-`1`百万
-`234`千
 -`567`每个三位数组都可以独立翻译，然后与正确的音阶词组合。 

从计算角度来看，约束很小，因为即使是最大的可能整数也最多包含十位数字。 这意味着性能不是关于处理大量输入大小，而是关于正确、干净地实现转换逻辑。 

几种边缘情况很容易导致幼稚实现中的错误：

 -`0`必须返回`"Zero"`直接
 - 之间的数字`10`和`19`使用独特的英语单词
 - 数十个喜欢`20`,`30`,`40`不得包含尾随单元字
 - 精确数百个，例如`100`不应产生额外的空格
 - 包含零的组，例如`1000010`，应该干净地跳过空白部分
 - 最大可能值的格式仍必须正确

 正确的解决方案必须仔细处理间距、比例词和特殊命名规则。 

## 方法

 ### 蛮力方法

 暴力方法会尝试使用许多条件分支来硬编码或直接模拟每个可能的数字模式。 例如，我们可以单独处理：

 - 一位数字
 - 两位数
 - 三位数
 - 数千
 - 数百万
 - 数十亿

 这种方法会重复分解数字并针对每个特殊情况手动连接单词。 

虽然这种方法最终可以产生正确的答案，但它很快就会变得难以维护并且容易出错。 英文数字格式包含许多例外，特别是对于介于`10`和`19`，并且手动处理所有组合会导致深度嵌套的条件。 

暴力方法还会重复逻辑，因为相同的转换规则重复应用于每个三位数块。 

### 最佳解决方案的关键见解

 关键的观察结果是，英语数字遵循基于三位数组的递归结构。 

每个数字都可以分解为多个块，例如：

 - 数十亿
 - 数百万
 - 数千
 - 数百个

 每个块最多包含三位数字，并且每个三位数都遵循完全相同的转换规则。 

例如：

-`1234567`-`1`百万
-`234`千
 -`567`如果我们创建一个辅助函数来将任何数字转换为`1`到`999`到英语单词中，我们可以重复地将其应用到每个块并附加适当的音阶单词。 

这极大地简化了实施，因为：

 - 我们干净利落地解决了一个小子问题
 - 我们为每个块重用相同的逻辑
 - 递归自然地反映了英语数字结构

## 算法演练

 1.首先处理特殊情况`num == 0`。 零的英文表示是唯一的，不遵循正常的分组规则，所以我们立即返回`"Zero"`。 
2. 创建查找数组：

 - 号码来自`1`到`19`- 十的倍数`20`到`90`- 缩放单词，例如`Thousand`,`Million`， 和`Billion`这些数组允许恒定时间查找英语单词。 
3. 定义一个辅助函数，将数字转换为`1`到`999`。 
4. 助手内部：

 - 如果数量小于`20`，直接返回对应的单词，因为这些值具有唯一的名称。 
- 如果数量小于`100`，计算：

 - 十位数字
 - 剩余个位数

 然后将十位字与余数的递归结果结合起来。 
- 否则：

 - 提取百位数字
 - 追加`"Hundred"`- 递归处理剩余两位数
 5. 使用重复除法和取模运算以三位数为单位处理原始数字：

 -`num % 1000`提取当前块
 -`num //= 1000`移动到下一个块
 6. 对于每个非零块：

 - 使用辅助函数转换它
 - 附加正确的音阶词，例如`"Thousand"`或者`"Million"`7. 通过添加新处理的块，从左到右构建最终结果。 
8. 修剪多余的空格并返回最终的字符串。 

### 为什么它有效

 英文数字命名是分层的并且基于三个数字组。 之间的每一块`0`和`999`可以使用相同的规则独立翻译。 通过正确转换每个块并附加适当的比例词，该算法可以完全按照标准英语语法的定义重建完整的英语表示。 

## Python 解决方案```python
class Solution:
    def numberToWords(self, num: int) -> str:
        if num == 0:
            return "Zero"

        below_twenty = [
            "", "One", "Two", "Three", "Four", "Five",
            "Six", "Seven", "Eight", "Nine", "Ten",
            "Eleven", "Twelve", "Thirteen", "Fourteen",
            "Fifteen", "Sixteen", "Seventeen", "Eighteen",
            "Nineteen"
        ]

        tens = [
            "", "", "Twenty", "Thirty", "Forty",
            "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"
        ]

        thousands = ["", "Thousand", "Million", "Billion"]

        def helper(n: int) -> str:
            if n == 0:
                return ""

            if n < 20:
                return below_twenty[n]

            if n < 100:
                return (
                    tens[n // 10] +
                    (" " + helper(n % 10) if n % 10 != 0 else "")
                )

            return (
                below_twenty[n // 100] +
                " Hundred" +
                (" " + helper(n % 100) if n % 100 != 0 else "")
            )

        result = []
        index = 0

        while num > 0:
            current_chunk = num % 1000

            if current_chunk != 0:
                chunk_words = helper(current_chunk)

                if thousands[index]:
                    chunk_words += " " + thousands[index]

                result.append(chunk_words)

            num //= 1000
            index += 1

        return " ".join(reversed(result))
```实现从直接检查零开始，因为`"Zero"`是一个特殊的独立案例。 

数组`below_twenty`,`tens`， 和`thousands`作为英语单词的查找表。 这可以避免重复的条件并保持代码整洁。 

这`helper`函数负责将数字转换为`1`到`999`。 

对于以下数字`20`，函数直接返回对应的单词，因为这些值的英文名称不规则。 

对于以下数字`100`，函数：

 - 查找十位数字
 - 递归转换剩余个位数

 对于大于或等于的数字`100`，函数：

 - 提取百位数字
 - 附加`"Hundred"`- 递归转换剩余部分

 主循环使用重复提取三位数块`% 1000`。 每个块都是独立翻译的，并与来自`thousands`大批。 

最后，由于处理从最低有效数字开始，因此块被颠倒。 

## 解决方案```go
package main

import "strings"

func numberToWords(num int) string {
	if num == 0 {
		return "Zero"
	}

	belowTwenty := []string{
		"", "One", "Two", "Three", "Four", "Five",
		"Six", "Seven", "Eight", "Nine", "Ten",
		"Eleven", "Twelve", "Thirteen", "Fourteen",
		"Fifteen", "Sixteen", "Seventeen", "Eighteen",
		"Nineteen",
	}

	tens := []string{
		"", "", "Twenty", "Thirty", "Forty",
		"Fifty", "Sixty", "Seventy", "Eighty", "Ninety",
	}

	thousands := []string{
		"", "Thousand", "Million", "Billion",
	}

	var helper func(int) string

	helper = func(n int) string {
		if n == 0 {
			return ""
		}

		if n < 20 {
			return belowTwenty[n]
		}

		if n < 100 {
			if n%10 == 0 {
				return tens[n/10]
			}

			return tens[n/10] + " " + helper(n%10)
		}

		if n%100 == 0 {
			return belowTwenty[n/100] + " Hundred"
		}

		return belowTwenty[n/100] + " Hundred " + helper(n%100)
	}

	result := []string{}
	index := 0

	for num > 0 {
		currentChunk := num % 1000

		if currentChunk != 0 {
			chunkWords := helper(currentChunk)

			if thousands[index] != "" {
				chunkWords += " " + thousands[index]
			}

			result = append([]string{chunkWords}, result...)
		}

		num /= 1000
		index++
	}

	return strings.Join(result, " ")
}
```Go 实现遵循与 Python 版本相同的算法结构。 主要区别在于 Go 需要显式的切片处理和字符串连接。 

Go 不像 Python 那样自然地支持嵌套命名函数，因此辅助函数是使用函数变量声明的。 

另一个显着的区别是结果的构建方式。 由于 Go 切片不提供方便的反向迭代器，因此块会直接添加到结果切片中。

 ## 边缘情况

 ### 输入等于零

 零是唯一不自然地适合基于块的分解方法的数字。 如果我们尝试正常处理，则不会将任何块添加到结果中，从而生成一个空字符串而不是`"Zero"`。 

该实现在开始时立即通过返回来处理这个问题`"Zero"`在执行任何进一步的逻辑之前。 

### 10 到 19 之间的数字

 之间的数字的英文名称`10`和`19`是不规则的。 例如：

-`11`是`"Eleven"`-`13`是`"Thirteen"`这些不能从通用的十和单位规则构建。 

该实现通过存储来自的所有值来避免错误`0`到`19`在查找表中并直接返回它们。 

### 包含零的块

 数字例如：```
1000010
```中间包含空块。 一个幼稚的实现可能会意外生成：```
One Million Thousand Ten
```这是不正确的。 

该算法通过跳过任何值为`0`。 仅非零块被转换并附加到最​​终结果。 

### 百或千的精确倍数

 数字如：

 -`100`-`1000`-`1000000`可能会意外地产生尾随空格或不必要的单词。 

辅助函数在递归附加其他单词之前仔细检查余数是否为零。 这保证了干净的格式，没有额外的空格或无效的短语。
