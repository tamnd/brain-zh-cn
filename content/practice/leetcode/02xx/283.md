[LeetCode 第 283 题](https://leetcode.com/problems/move-zeroes/)

 **难度：** 🟢简单
 **主题：** 数组、两个指针

 ## 解决方案

 ## 问题理解

 问题给了我们一个整数数组`nums`并要求我们移动每一个`0`元素到数组末尾，同时保留所有非零元素的相对顺序。 

“相对顺序”这个词极其重要。 这意味着，如果非零数字最初以某个顺序出现，那么在运算后它们必须保持在同一顺序中。 例如，在数组中`[0,1,0,3,12]`，非零值按顺序出现`1, 3, 12`。 移动零后，该顺序必须仍然保持不变，从而导致`[1,3,12,0,0]`。 

另一个关键要求是操作必须就地进行。 我们不允许创建另一个数组并返回它。 相反，我们必须直接修改输入数组本身。 

约束告诉我们数组长度可以大到`10^4`。 这足够小，以至于`O(n^2)`解决方案在某些环境下可能在技术上通过，但效率低且不必要。 该问题旨在鼓励`O(n)`使用两个指针技术的解决方案。 

数组中的值可以是负数、正数或零。 因为只有值`0`重要的是，数字的实际大小无关紧要。 

尽早考虑几个边缘情况很重要：

 - 仅包含零的数组，例如`[0,0,0]`- 不包含零的数组，例如`[1,2,3]`- 单元素数组，例如`[0]`或者`[5]`- 末尾已经有零，例如`[1,2,3,0,0]`- 零位于开头或在整个数组中交错

 简单的实现很容易破坏相对排序要求或执行不必要的操作。 

## 方法

 ### 蛮力方法

 一种简单的方法是首先创建一个包含所有非零元素的临时数组，然后添加所有零。 

例如：

 - 遍历数组
 - 将每个非零值存储到临时列表中
 - 计算存在多少个零
 - 将许多零添加到临时列表中
 - 将所有内容复制回原始数组

 这是有效的，因为它明确地重建了所需的顺序。 所有非零元素按顺序保留，所有零都放置在末尾。 

然而，这种方法使用与数组大小成比例的额外内存。 该问题明确要求就地解决，因此这种方法虽然易于理解，但并不能完全满足预期的优化要求。 

### 最佳两指针方法

 关键的见解是我们实际上不需要另一个数组。 相反，我们可以跟踪下一个非零元素应该放置的位置。 

我们使用一个名为`insert_position`表示非零数字所属的下一个索引。 

当我们扫描数组时：

 - 如果当前值非零，我们将其交换为`insert_position`- 然后我们递增`insert_position`- 如果当前值为零，我们只需继续

 这是有效的，因为每个非零元素都会向前移动到最早的可用位置，而零自然会漂移到末尾。 

另一个优点是这可以最大限度地减少不必要的写入。 如果当前元素已经位于正确的位置，则交换实际上不会改变任何内容。

 ## 算法演练

 1. 初始化一个名为`insert_position`到`0`。 

该指针跟踪下一个非零元素应放置的索引。 
2. 使用另一个指针从左到右遍历数组，通常称为`current`。 

这`current`指针只检查每个元素一次。 
3. 对于每个元素，检查它是否非零。 

如果元素为零，我们会跳过它，因为零属于末尾。 
4. 如果当前元素非零，则将其与处的值交换`insert_position`。 

这会将非零值放置到靠近数组前面的正确位置。 
5. 增量`insert_position`。 

正确放置一个非零元素后，下一个非零元素应该进入下一个位置。 
6. 继续，直到处理完整个数组。 

到最后：

 - 所有非零元素按其原始顺序出现在开头
 - 所有零都已移至末尾

 ### 为什么它有效

 整个算法保持的不变量是：

 - 之前的每个索引`insert_position`包含按原始顺序正确放置的非零元素。 
- 每个索引来自`insert_position`下一步尚未最终确定。 

每当我们遇到非零元素时，我们都会将其放入下一个可用的正确位置。 由于我们从左到右处理元素，因此它们的相对顺序会自动保留。 

## Python 解决方案```python
from typing import List

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        
        insert_position = 0
        
        for current in range(len(nums)):
            if nums[current] != 0:
                nums[insert_position], nums[current] = (
                    nums[current],
                    nums[insert_position]
                )
                insert_position += 1
```实现从初始化开始`insert_position`到`0`。 该变量标记下一个非零值应写入的位置。 

该循环使用以下方式迭代数组中的每个索引`current`。 

每当找到非零值时，它就会被交换到正确的前面位置。 这确保了所有非零元素都被压缩到数组的开头。 

交换后，`insert_position`增加是因为又正确放置了一个非零元素。 

如果当前值为零，则算法不执行任何操作并继续扫描。 

当遍历完成时，所有非零元素已按顺序向前移动，所有零占据最后的剩余位置。 

## 解决方案```go
func moveZeroes(nums []int) {
    insertPosition := 0

    for current := 0; current < len(nums); current++ {
        if nums[current] != 0 {
            nums[insertPosition], nums[current] =
                nums[current], nums[insertPosition]

            insertPosition++
        }
    }
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

一个显着的区别是 Go 使用切片而不是 Python 列表。 由于切片是类似引用的结构，因此函数内部的修改会直接影响调用者传递的原始数组。 

这个问题不存在整数溢出问题，因为我们只是比较和交换值，而不是对它们执行算术运算。 

尽管约束保证了至少一个元素，但 Go 也自然地在此循环结构中安全地处理空或 nil 切片。

 ## 边缘情况

 一个重要的边缘情况是仅包含零的数组，例如`[0,0,0]`。 当不存在非零元素时，有缺陷的实现可能会意外地覆盖值或错误地移动指针。 在这个实现中，`insert_position`指针永远不会前进，因为没有遇到非零元素。 数组保持不变，这是正确的行为。 

另一个重要的情况是完全没有零的数组，例如`[1,2,3]`。 某些实现可能会执行不必​​要的移位操作或意外更改顺序。 在这里，每个元素都与自身交换，因为`insert_position`和`current`总是平等的。 这使数组保持原样。 

第三种边缘情况是零出现在数组的开头，例如`[0,0,1,2]`。 朴素的方法有时无法在向前压缩非零值时保持顺序。 此实现从左到右处理元素，确保`1`被放置在之前`2`，保留原来的相对顺序。 

另一个微妙的情况是包含负数的数组，例如`[-1,0,-2,3]`。 由于该算法仅检查值是否为零，因此所有非零值，无论符号如何，都会被统一处理并正确保留。
