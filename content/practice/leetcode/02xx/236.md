[LeetCode 第 236 题](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到二叉树中两个节点的最低共同祖先（Lowest Common Ancestor），通常缩写为 LCA。 

二叉树由节点组成，其中每个节点可能有一个左子节点和一个右子节点。 我们得到三个输入：

 -`root`，这是二叉树的根节点
 -`p`, 树中的一个目标节点
 -`q`，树中的另一个目标节点

 目标是返回树中具有两者的最低节点的节点`p`和`q`作为后代。 

节点被视为其自身的后代。 这个细节非常重要，因为它意味着目标节点之一本身可以是 LCA。 

例如，如果节点`5`包含节点`4`在其子树中的某个位置，则 LCA 为`5`和`4`是`5`。 

这些约束告诉我们有关该问题的几个重要信息：

 - 树最多可以包含`10^5`节点，这意味着低效的重复遍历可能会变得昂贵。 
- 节点值是唯一的，因此每个节点都可以明确标识。 
- 两个都`p`和`q`保证存在于树中。 
-`p != q`，所以我们永远不需要处理相同的目标节点。 

输入作为实际节点引用给出，而不仅仅是值。 这意味着应该使用节点标识进行比较，而不是按值搜索。 

一些边缘情况很重要：

 - 一个节点可能是另一个节点的祖先。 
- LCA 可以是根节点。 
- 树可能高度不平衡，实际上表现得像链表。 
- 两个节点可能存在于完全不同的子树中。 
- 树可能只包含两个节点。 

当一个节点本身是另一个节点的祖先时，幼稚的实现很容易失败，特别是如果它只搜索分裂点而不考虑自传行为。 

## 方法

 ### 蛮力方法

 一种直接的方法是重复确定祖先关系。 

一种方法是：

 1. 使用 DFS 或 BFS 为每个节点构建父映射。 
2.从节点开始`p`并将其所有祖先存储在一个集合中。 
3.从节点向上移动`q`直到我们找到第一个祖先也属于`p`的祖先设定。 

这是有效的，因为在从`q`必须是最低共同祖先。 

虽然这种方法是正确的，但它需要为父映射和祖先集提供额外的存储空间。 在解决实际查询之前，还需要遍历树一次以构建父关系。 

### 最优递归 DFS 方法

 关键的见解是二叉树结构本身自然支持递归推理。 

在任何节点，只有三种可能：

 - 两个目标节点都在左子树中。 
- 两个目标节点都位于右子树中。 
- 每个子树中有一个目标节点。 

第三种情况立即告诉我们当前节点是LCA。 

我们可以使用后序 DFS 遍历将信息从孩子向上传播到父母。 

递归函数返回：

 -`None`如果子树中两个目标都不存在
 -`p`如果子树包含`p`-`q`如果子树包含`q`- LCA 节点（如果已经确定）

 这使得算法能够识别两个目标出现在不同分支中的第一个节点。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 构建父指针和祖先集 |
 | 最佳| O(n) | O(h) | 单次DFS遍历，仅使用递归栈 |

 这里，`n`是节点数，`h`是树的高度。 

## 算法演练

 1. 从根节点开始递归DFS遍历。 

递归自下而上探索树。 这很重要，因为在决定当前节点是否是 LCA 之前，我们需要来自子子树的信息。 
2. 定义基本案例。 

如果当前节点是`None`， 返回`None`因为子树不包含任何目标。 

如果当前节点等于`p`或者`q`，立即返回当前节点。 这意味着我们找到了目标之一。 
3. 递归搜索左子树。 

将结果存储在变量中，例如`left_result`。 

该变量告诉我们左子树是否包含目标节点或已经包含 LCA。 
4. 递归搜索右子树。 

将结果存储在`right_result`。 

现在我们知道两个子树中存在什么。 
5. 判断当前节点是否为LCA。 

如果两者都`left_result`和`right_result`非空，则在每个子树中找到一个目标。 

这意味着当前节点是连接两个目标的最低节点，因此返回当前节点。 
6. 向上传播非空结果。 

如果只有一侧返回一个节点，则向上返回该节点。 

这会将有关已发现目标或先前发现的 LCA 的信息传播到根。 
7. 继续直到递归完成。 

根调用最终返回的节点是 LCA。 

### 为什么它有效

 递归函数保持一个重要的不变量：

 - 子树返回非空值当且仅当它包含以下任一值时`p`,`q`，或他们的 LCA。 

当左子树和右子树都返回非空值时，当前节点是路径的第一个点`p`和`q`发散。 由于 DFS 在处理父节点之前处理子节点，因此该节点必须是最低公共祖先。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

from typing import Optional

class Solution:
    def lowestCommonAncestor(
        self,
        root: 'TreeNode',
        p: 'TreeNode',
        q: 'TreeNode'
    ) -> 'TreeNode':

        if root is None:
            return None

        if root == p or root == q:
            return root

        left_result = self.lowestCommonAncestor(root.left, p, q)
        right_result = self.lowestCommonAncestor(root.right, p, q)

        if left_result and right_result:
            return root

        return left_result if left_result else right_result
```该实现直接反映了递归算法。 

第一个基本情况处理空子树。 如果当前节点是`None`，子树不包含两个目标。 

第二个基本情况检查当前节点是否是目标节点之一。 这很重要，因为节点被视为其自己的后代。 

然后递归独立地搜索两个子树。 返回值向上携带有关是否已找到目标节点或 LCA 的信息。 

条件：```python
if left_result and right_result:
```识别每个子树中存在一个目标的确切时刻。 此时，当前节点就是LCA。 

最后，如果只有一个子树返回非空值，则该值将不变地向上传播。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	if root == nil {
		return nil
	}

	if root == p || root == q {
		return root
	}

	leftResult := lowestCommonAncestor(root.Left, p, q)
	rightResult := lowestCommonAncestor(root.Right, p, q)

	if leftResult != nil && rightResult != nil {
		return root
	}

	if leftResult != nil {
		return leftResult
	}

	return rightResult
}
```Go 实现遵循与 Python 版本相同的递归逻辑。 

主要区别在于使用`nil`而不是`None`。 

Go 中的指针比较自然适用于树节点，因此`root == p`和`root == q`正确比较节点身份。 

因为 Go 不支持像 Python 那样的隐式真实性检查，所以需要显式`nil`需要进行比较。 

## 工作示例

 ### 示例 1

 输入：```
root = [3,5,1,6,2,0,8,null,null,7,4]
p = 5
q = 1
```树结构：```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```该算法进行如下：

 | 当前节点| 左结果 | 正确的结果 | 返回值 |
 | --- | --- | --- | --- |
 | 5 | 5 | 无 | 5 |
 | 1 | 1 | 无 | 1 |
 | 3 | 5 | 1 | 3 |

 在节点处`3`，左子树和右子树都返回非空值。 所以，`3`是生命周期评估。 

### 示例 2

 输入：```
p = 5
q = 4
```遍历：

 | 当前节点| 左结果 | 正确的结果 | 返回值 |
 | --- | --- | --- | --- |
 | 4 | 无 | 无 | 4 |
 | 2 | 无 | 4 | 4 |
 | 5 | 5 | 4 | 5 |

 在节点处`5`，左子树标识节点`5`其自身，而右子树包含节点`4`。 

因此，节点`5`是生命周期评估。 

### 示例 3

 输入：```
root = [1,2]
p = 1
q = 2
```树：```
   1
  /
 2
```遍历：

 | 当前节点| 左结果 | 正确的结果 | 返回值 |
 | --- | --- | --- | --- |
 | 2 | 无 | 无 | 2 |
 | 1 | 2 | 无 | 1 |

 节点`1`本身就是目标之一，也是`2`，所以它是 LCA。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点被访问一次 |
 | 空间| O(h) | 递归调用栈高度等于树高|

 该算法对树执行一次 DFS 遍历。 

每个节点只处理一次，因此总运行时间与节点数量呈线性关系。 

空间复杂度来自递归深度。 在平衡树中，高度为`O(log n)`。 在完全倾斜的树的最坏情况下，递归深度变为`O(n)`。

        right_result = self.lowestCommonAncestor(root.right, p, q)

root.left = TreeNode(5)
root.right = TreeNode(1)

    root,
    root.left,
    root.right

# Example 2

    root.left,

small_root.left = TreeNode(2)

 ## 边缘情况

 当一个目标节点是另一个目标节点的祖先时，就会出现一种重要的边缘情况。 许多不正确的解决方案继续进行更深入的搜索，并且无法认识到节点可以是其自己的后代。 此实现正确处理这种情况，因为它在遇到任一情况时立即返回`p`或者`q`。 

另一个重要的边缘情况是高度不平衡的树。 倾斜树的行为几乎类似于链表，这可能会暴露递归遍历逻辑中的缺陷。 由于该解决方案仅依赖于 DFS 遍历，而不依赖于平衡结构假设，因此它仍然可以正常工作。 

当 LCA 本身是根时，会出现第三种边缘情况。 当两个目标节点存在于根的完全不同的子树中时，就会发生这种情况。 该算法自然会检测到这一点，因为来自根的两个递归调用都返回非空值。 

最后一个微妙的情况是目标是直系兄弟姐妹。 在这种情况下，他们的父母应立即被识别为 LCA。 两个子节点的递归返回导致父节点满足左右结果都非空的条件。
