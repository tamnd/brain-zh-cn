[LeetCode 第 298 题](https://leetcode.com/problems/binary-tree-longest-consecutive-sequence/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到二叉树中最长的连续序列路径的长度，其中连续序列路径被定义为从父级到子级的值恰好增加 1 的路径。 路径必须**向下**，即从节点到其子节点，并且不能移回父节点。 输入是二叉树的根，最多可包含 30,000 个节点，值范围为 -30,000 到 30,000。 输出是一个整数，表示树中任何位置的此类序列的最大长度。 

了解限制因素有助于指导该方法。 树的大小足够大，以至于单独检查每个节点的每个可能路径的强力解决方案可能会太慢。 要考虑的边缘情况包括仅具有一个节点的树、所有节点都具有相同值的树（无连续序列）以及具有多个包含相同最大长度序列的分支的树。 

## 方法

 一种简单的暴力方法会尝试从**每个节点**开始遍历，递归地找到从该节点开始的最长连续路径。 虽然这在原则上是正确的，但它具有严重的性能限制，因为它多次重新访问相同的子树，导致重复计算。 具体来说，如果有`n`对于高度不平衡的树，在最坏的情况下，时间复杂度可能高达 O(n^2)。 

最佳解决方案的关键见解是使用**单个深度优先搜索 (DFS)** 遍历，同时在遍历时沿着连续序列的长度进行遍历。 在每个节点，我们将节点值与其父值进行比较，以确定序列是否继续。 这样，每个节点都被访问一次，避免了冗余工作，并且我们维护一个全局最大值来跟踪迄今为止找到的最长序列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 从每个节点开始 DFS，重新计算子树中的序列 |
 | 最佳 | O(n) | O(h) | 单次DFS，携带序列长度，h=树高（栈空间）|

 ## 算法演练

 1. 初始化变量`max_length`为零。 这将跟踪遍历期间找到的最长连续路径的长度。 
2. 定义一个辅助 DFS 函数，该函数采用当前节点、其父值和当前连续长度。 
3. 在每个节点，将该节点的值与父值进行比较。 如果节点值等于父值加一，则增加连续长度。 否则，将连续长度重置为 1，因为新序列从这里开始。 
4. 更新`max_length`如果当前连续长度大于先前记录的最大值。 
5. 对左子节点和右子节点递归调用 DFS，传递当前节点的值作为新的父值和更新的连续长度。 
6. 从根节点开始 DFS 遍历，初始长度为 0，父值不能匹配任何节点（例如，根值负 1 或哨兵）。 
7. 返回`max_length`DFS 完成后。 

**为什么有效**：这是有效的，因为每个节点都被访问一次，并且在每个节点上，我们正确地维护了包含该节点的连续序列的长度。 通过向下传递序列长度，我们不需要重复地重新计算子树的序列，并且跟踪最大值可确保我们捕获整个树中最长的序列。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def longestConsecutive(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        self.max_length = 0
        
        def dfs(node: Optional[TreeNode], parent_val: int, length: int) -> None:
            if not node:
                return
            if node.val == parent_val + 1:
                length += 1
            else:
                length = 1
            self.max_length = max(self.max_length, length)
            dfs(node.left, node.val, length)
            dfs(node.right, node.val, length)
        
        dfs(root, root.val - 1, 0)
        return self.max_length
```在此 Python 实现中，我们使用类变量`self.max_length`维持全局最大值。 DFS函数根据当前节点是否继续序列来更新连续长度。 遍历确保每个节点只被考虑一次，从而使其对于大型树来说非常高效。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func longestConsecutive(root *TreeNode) int {
    if root == nil {
        return 0
    }
    
    maxLength := 0
    
    var dfs func(node *TreeNode, parentVal int, length int)
    dfs = func(node *TreeNode, parentVal int, length int) {
        if node == nil {
            return
        }
        if node.Val == parentVal+1 {
            length++
        } else {
            length = 1
        }
        if length > maxLength {
            maxLength = length
        }
        dfs(node.Left, node.Val, length)
        dfs(node.Right, node.Val, length)
    }
    
    dfs(root, root.Val-1, 0)
    return maxLength
}
```Go 实现反映了 Python 方法。 我们使用局部变量`maxLength`和一个内部递归函数`dfs`遍历树。 处理`nil`相当于检查`None`在Python中，Go中的整数可以处理给定的节点值范围而无需担心溢出。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 在 DFS 期间，每个节点仅被访问一次 |
 | 空间| O(h) | DFS 中的调用堆栈深度，其中 h 是树的高度 |

 该算法有效地遍历树一次，并且只有调用堆栈深度会影响空间复杂度。

 ## 边缘情况

 一种边缘情况是单节点树。 最长的连续序列应该正确返回 1，因为该序列仅包含该节点。 另一个边缘情况是所有节点具有相同的值。 任何不在非连续节点重置序列的幼稚实现都可能会错误地计算更长的序列； 我们的解决方案正确地重置了序列长度。 第三个重要的情况是一棵不平衡的树，只有一个方向有长分支。 DFS 确保单独考虑每个分支，因此无论树的形状如何，都能准确找到最长路径。
