 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的整数是否`n`是一个丑陋的数字。 

丑数被定义为一个正整数，其质因数仅限于`2`,`3`， 和`5`。 这意味着将数字完全分解为素数后，每个素数因子都必须属于集合`{2, 3, 5}`。 

例如：

-`6`很丑因为`6 = 2 × 3`-`8`很丑因为`8 = 2 × 2 × 2`-`30`很丑因为`30 = 2 × 3 × 5`-`14`并不丑因为`14 = 2 × 7`， 和`7`不允许

 输入是单个整数`n`，输出是一个布尔值：

 - 返回`true`如果`n`很丑
 - 返回`false`否则

 一个重要的细节是丑陋的数字必须是正数。 负数和零自然不会难看。 

约束允许的值来自`-2^31`到`2^31 - 1`。 这告诉我们输入符合标准 32 位有符号整数范围。 由于仅处理一个数字，因此我们无需担心大型数据集或占用大量内存的解决方案。 重点纯粹在于数学正确性和边缘情况处理。 

一些边缘情况尤其重要：

 -`n <= 0`应立即返回`false`-`n = 1`应该返回`true`， 因为`1`没有素因数，因此不违反条件
 - 包含除以下以外的任何质因数的数字`2`,`3`， 或者`5`必须返回`false`- 大国，例如`2^30`应该仍然有效地工作

 ## 方法

 ### 蛮力方法

 暴力策略会尝试将数字完全分解为素数，然后验证每个发现的素数因子是否属于`{2, 3, 5}`。 

该过程将涉及从以下位置开始检查整除性`2`最多`sqrt(n)`，尽可能重复划分因子。 收集完所有素数因子后，我们将检查它们以确保不存在不允许的素数。 

这种方法是正确的，因为素因数分解唯一地标识了一个数的所有素因数。 如果连一个素因数都不存在`2`,`3`， 或者`5`，这个数字不能是丑陋的。 

然而，这种方法会执行不必​​要的工作。 我们实际上并不关心所有主要因素。 我们只需要知道除此之外的因素是否`2`,`3`， 和`5`存在。 执行完全素因数分解的成本比所需的要高。 

### 最佳方法

 关键的观察是丑陋的数字可以完全减少到`1`通过反复除以`2`,`3`， 和`5`。 

例如：

-`30 → 15 → 5 → 1`-`8 → 4 → 2 → 1`如果去除所有因素后`2`,`3`， 和`5`剩余值变为`1`，那么这个数字不包含其他素因数并且很难看。 

如果存在其他因素，减少过程将停止在大于`1`。 

例如：

-`14 → 7`-`7`不能除以`2`,`3`， 或者`5`- 由于剩余价值不`1`，这个数字并不难看

 这种方法更简单、更高效，因为它只检查相关因素。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(√n) | O(√n) | O(1) | O(1) | 执行一般素因数分解 |
 | 最佳 | O(log n) | O(1) | O(1) | 反复删除因数 2、3 和 5 |

 ## 算法演练

 1.首先检查是否`n`是积极的。 

丑数必须是正整数。 如果`n <= 0`，立即返回`false`。 
2. 反复除以`2`虽然可能。 

如果该数字可以被`2`，除以`2`直到它不再可分为止。 这会删除所有出现的质因数`2`。 
3. 反复除以`3`虽然可能。 

对因子应用相同的过程`3`。 
4. 反复除以`5`虽然可能。 

对因子应用相同的过程`5`。 
5. 检查最终剩余价值。 

如果所有质因数都只有`2`,`3`， 和`5`，数量最终会减少到`1`。 

如果存在任何其他素因数，则某个值大于`1`将保留。 
6、返回最终值是否等于`1`。 

### 为什么它有效

 每个整数都有唯一的质因数分解。 通过重复划分所有因素`2`,`3`， 和`5`，我们从数字中删除每个允许的质因数。 

如果剩余值为`1`，则不存在不允许的素因数。 否则，剩余的值必须包含其他一些质因数，这意味着这个数字并不难看。 

这个不变量保证了正确性。 

## Python 解决方案```python
class Solution:
    def isUgly(self, n: int) -> bool:
        if n <= 0:
            return False

        for factor in [2, 3, 5]:
            while n % factor == 0:
                n //= factor

        return n == 1
```实现从处理无效输入开始。 由于丑数必须为正数，因此任何小于或等于零的值都会立即返回`False`。 

接下来，代码迭代允许的素因数：`2`,`3`， 和`5`。 

对于每个因素，有一个`while`循环重复除法`n`只要划分准确。 这将从数字中删除所有出现的该质因数。 

例如，如果`n = 72`：

 - 除以`2`反复：

 -`72 → 36 → 18 → 9`- 除以`3`反复：

 -`9 → 3 → 1`最后，算法检查剩余值是否为`1`。 

如果结果是`1`，那么每个素因数都属于`{2, 3, 5}`。 否则，必定存在另一个素因数。 

## 解决方案```go
func isUgly(n int) bool {
    if n <= 0 {
        return false
    }

    factors := []int{2, 3, 5}

    for _, factor := range factors {
        for n%factor == 0 {
            n /= factor
        }
    }

    return n == 1
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

一个小的区别是切片的使用`[]int{2, 3, 5}`to iterate through the valid factors. Go 中的整数除法会自动截断为零，这正是我们想要的。 

不需要特殊的溢出处理，因为所有操作都会减少`n`，并且输入已经在整数范围内。

 ## 边缘情况

 ### 输入为零

 零是错误的常见来源，因为它可以被每个非零整数整除。 重复划分因子的幼稚实现可能会意外地进入不正确的逻辑或无限循环。 

该实现通过立即返回来避免此问题`False`每当`n <= 0`。 

### 输入为一

 价值`1`是一个特殊的数学情况，因为它没有素因数。 一些实现错误地返回`False`因为没有分裂发生。 

算法正确返回`True`因为在尝试除以之后`2`,`3`， 和`5`，该值保持不变`1`。 

### 数字包含额外质因数

 像这样的数字`14`,`22`， 或者`77`外部至少包含一个素因数`{2, 3, 5}`。 

该实现正确地检测到了这一点，因为删除所有允许的因素仍然留下一个大于`1`。 

例如：

-`14 → 7`- 剩余价值是`7`- 自从`7 != 1`，结果是`False`### 允许因子的大幂

 价值观如`2^30`或者`5^20`测试重复除法是否仍然有效。 

由于每次除法大大减少了数量，因此该算法可以在对数时间内有效地处理这些情况，而无需额外的内存使用。
