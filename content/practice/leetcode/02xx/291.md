[LeetCode 第 291 题](https://leetcode.com/problems/word-pattern-ii/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、回溯

 ## 解决方案

 ## 问题理解

 该问题要求我们判断给定的字符串是否`s`可以通过替换a中的每个字符来形成`pattern`具有**非空字符串**，在**双射映射**下。 双射意味着每个字符恰好映射到一个唯一的子字符串，并且没有两个字符映射到相同的子字符串。 本质上，模式中的每个字符都是不同字符串的占位符`s`。 

输入很简单：`pattern`是代表映射键的小写字母短字符串，并且`s`是可以使用此映射重建的目标字符串。 输出是一个布尔值，`true`如果存在这样的映射，或者`false`如果没有。 

约束很小（`1 <= pattern.length, s.length <= 20`），这意味着尽管时间复杂度可能很高，但使用**回溯或递归**的解决方案是可行的。 重要的边缘情况包括所有字符都相同的模式、比字符串长的模式或无法拆分以满足映射的字符串。 该问题仅保证非空字符串和小写字母，因此我们不需要处理空输入或无效字符。 

## 方法

 蛮力方法会尝试**所有可能的分割**`s`对于每个字符`pattern`。 对于每个字符，我们尝试所有子串`s`并递归检查剩余的子字符串是否与剩余的模式匹配，并跟踪使用的映射。 虽然这保证了正确的答案，但组合的数量随着字符串和模式的长度呈指数增长。 例如，如果模式的长度`n`字符串是长度`m`，最多可能有$O(m^n)$组合。 

最佳解决方案的关键见解是使用**带有哈希映射的回溯**来强制执行双射映射。 我们维护两种映射：一种从模式字符到子字符串，另一种从子字符串到模式字符。 当映射已经分配时，我们检查一致性。 如果没有，我们尝试为当前字符分配所有可能的子字符串并递归。 回溯可确保探索所有潜在的映射，但在检测到不一致时尽早修剪无效路径。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m^n) | O(m^n) | O(n) | 尝试模式 | 中每个字符的所有可能的子字符串分割
 | 使用哈希图回溯| O(n * 2^m) | O(n * 2^m) | O(n + m) | 通过早期剪枝递归地分配子串并维护双射映射 |

 ## 算法演练

 1. 初始化两个哈希映射：一个用于将模式字符映射到子字符串（`char_to_word`) 和另一个用于字符 (`word_to_char`）。 这确保了双射性质。 
2. 定义递归函数`dfs(i, j)`在哪里`i`是模式中的当前索引，并且`j`是字符串中的当前索引`s`。 
3.如果`i`等于图案的长度并且`j`等于长度`s`， 返回`true`因为成功找到了完整的映射。 
4. 如果`i`等于图案的长度，但是`j`不返回，反之亦然`false`因为模式和字符串长度与任何映射都不一致。 
5. 检查当前模式字符是否已经有映射：

 - 如果是，检索映射的子字符串并检查相应部分是否`s`匹配它。 如果存在则递归调用`dfs`为下一个指数。 如果没有，则返回`false`。 
6. 如果当前字符没有映射，则尝试分配从索引开始的每个可能的子字符串`j`到当前模式字符：

 - 跳过已经映射到另一个模式字符的子字符串。 
- 分配子字符串并递归调用`dfs`为下一个指数。 
- 如果递归返回`true`，传播它。 否则，通过删除分配来回溯。 
7. 如果所有子字符串选项都用尽而没有有效的映射，则返回`false`。 

**为什么有效**：该算法系统地探索所有有效映射，同时确保双射性。 回溯可确保尽早放弃无效路径，从而防止不必要的计算并保证正确性。 

## Python 解决方案```python
class Solution:
    def wordPatternMatch(self, pattern: str, s: str) -> bool:
        def dfs(i: int, j: int, char_to_word: dict, word_to_char: dict) -> bool:
            if i == len(pattern) and j == len(s):
                return True
            if i == len(pattern) or j == len(s):
                return False
            
            char = pattern[i]
            
            if char in char_to_word:
                word = char_to_word[char]
                if not s.startswith(word, j):
                    return False
                return dfs(i + 1, j + len(word), char_to_word, word_to_char)
            
            for end in range(j + 1, len(s) + 1):
                word = s[j:end]
                if word in word_to_char:
                    continue
                char_to_word[char] = word
                word_to_char[word] = char
                if dfs(i + 1, end, char_to_word, word_to_char):
                    return True
                del char_to_word[char]
                del word_to_char[word]
            
            return False
        
        return dfs(0, 0, {}, {})
```Python 实现使用递归辅助函数`dfs`探索所有可能的映射。 两个哈希图`char_to_word`和`word_to_char`强制执行双射映射。 已分配的子字符串将被跳过以避免冲突，回溯可确保删除不正确的分配。 

## 解决方案```go
func wordPatternMatch(pattern string, s string) bool {
    charToWord := make(map[byte]string)
    wordToChar := make(map[string]byte)
    
    var dfs func(int, int) bool
    dfs = func(i int, j int) bool {
        if i == len(pattern) && j == len(s) {
            return true
        }
        if i == len(pattern) || j == len(s) {
            return false
        }
        
        char := pattern[i]
        if word, ok := charToWord[char]; ok {
            if j+len(word) > len(s) || s[j:j+len(word)] != word {
                return false
            }
            return dfs(i+1, j+len(word))
        }
        
        for end := j + 1; end <= len(s); end++ {
            word := s[j:end]
            if _, exists := wordToChar[word]; exists {
                continue
            }
            charToWord[char] = word
            wordToChar[word] = char
            if dfs(i+1, end) {
                return true
            }
            delete(charToWord, char)
            delete(wordToChar, word)
        }
        
        return false
    }
    
    return dfs(0, 0)
}
```Go 解决方案反映了 Python 方法，使用`map[byte]string`为了`charToWord`和`map[string]byte`为了`wordToChar`。 Go 在检查子字符串匹配时需要仔细处理切片索引。
