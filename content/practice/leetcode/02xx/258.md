 ## 解决方案

 ## 问题理解

 该问题要求我们通过将数字相加来重复变换一个数字，直到只剩下一个数字。 然后应返回最后一位数字。 

例如，如果输入是`38`，我们首先计算`3 + 8 = 11`。 自从`11`仍然超过一位数字，我们重复该过程并计算`1 + 1 = 2`。 结果`2`是个位数，所以这就是答案。 

输入是一个非负整数`num`。 输出也是一个整数，具体来说就是重复数字求和后得到的最终一位数值。 

约束条件`0 <= num <= 2^31 - 1`告诉我们输入可以与 32 位有符号整数一样大。 尽管这不是很大，但后续问题强烈暗示存在一种数学属性，可以让我们完全避免模拟并在恒定时间内计算结果。 

有几个重要的边缘情况需要考虑：

 - 如果`num = 0`，答案必须保留`0`。 这是特殊的，因为数学快捷方式对于零的表现略有不同。 
- 如果`num`已经是个位数，答案应该只是数字本身。 
- 大值，例如`2147483647`必须仍然正常工作，没有溢出或过多的计算。 
- 数字和多次重复折叠的数字，例如`99999`，最终应该正确收敛到一位数。 

## 方法

 ### 暴力模拟

 最直接的解决办法是重复计算数字之和，直到数字变成个位数。 

为了计算数字和，我们可以使用模除法和整数除法重复提取数字：

 -`digit = num % 10`-`num //= 10`我们不断地将提取的数字添加到总计中。 处理完所有数字后，我们用数字和替换原始数字，并重复该过程，直到数字小于`10`。 

这种方法是正确的，因为它完全遵循问题陈述中描述的过程。 每次迭代都会将数字减少到较小的值，最终产生一个数字。 

尽管该解决方案对于给定的约束足够有效，但它仍然涉及循环和重复的数字提取。 后续具体询问我们是否可以完全避免循环和递归。 

### 最佳数学洞察力

 关键的观察结果是，重复对数字求和会产生数字的数字根。 

数字根具有众所周知的基于模的数学特性`9`:

 - 如果一个数可以被`9`，其数字根为`9`- 否则，数字根是`num % 9`- 唯一的例外是`0`，其数字根是`0`这是有效的，因为一个数字及其数字之和具有相同的模余数`9`。 

例如：

-`38 % 9 = 2`-`3 + 8 = 11`-`1 + 1 = 2`两者产生相同的最终结果。 

利用这个属性，我们可以在常数时间内计算答案，无需循环或递归。

 ## 算法演练

 ### 最优算法

 1. 检查输入的号码是否为`0`。 

这是必要的，因为数字根公式对于零的表现不同。 如果我们直接应用模数规则，我们将错误地返回`9`为了`0`。 
2. 计算`num % 9`。 

模余数`9`捕获与模拟过程相同的重复数字和行为。 
3. 如果余数是`0`， 返回`9`。 

任何正倍数`9`最终减少为`9`。 示例包括：

 -`9 -> 9`-`18 -> 1 + 8 = 9`-`99 -> 9 + 9 = 18 -> 1 + 8 = 9`4. 否则，返回余数。 

对于所有非倍数`9`，余数本身就是最终的个位数答案。 

### 为什么它有效

 正确性来自模数`9`小数的性质。 每一个力量`10`是一致的`1`模数`9`，这意味着一个数字及其数字之和始终具有相同的模余数`9`。 

例如：$$38 = 3 \times 10 + 8$$自从：$$10 \equiv 1 \pmod{9}$$我们得到：$$38 \equiv 3 + 8 \pmod{9}$$重复此过程将保留相同的模值，直到只剩下一位数字。 最后一个数字是数字根。 

中心数学关系是：$\operatorname{digital\_root}(n)=\begin{cases}0 & n=0 \\ 9 & n\bmod 9=0 \text{ and } n>0 \\ n\bmod 9 & \text{otherwise}\end{cases}$## Python 解决方案```python
class Solution:
    def addDigits(self, num: int) -> int:
        if num == 0:
            return 0
        
        remainder = num % 9
        
        if remainder == 0:
            return 9
        
        return remainder
```该实现首先处理输入为的特殊情况`0`。 

接下来，它计算除以时的余数`9`。 该余数决定了数字根。 

如果余数是`0`，该数字必须是正倍数`9`，所以答案是`9`。 

否则，返回余数本身。 

该实现直接遵循数学推导并避免任何循环或递归。 

## 解决方案```go
func addDigits(num int) int {
    if num == 0 {
        return 0
    }

    remainder := num % 9

    if remainder == 0 {
        return 9
    }

    return remainder
}
```Go 实现与 Python 版本几乎相同。 由于输入约束非常适合 Go 的`int`在 LeetCode 上输入，不需要特殊的溢出处理。 

Go 使用显式变量声明`:=`，而 Python 依赖于动态类型。 否则，逻辑和边缘情况处理保持不变。

 ## 边缘情况

 ### 输入等于零

 价值`0`是这个问题中最重要的特殊情况。 如果我们盲目应用模公式，我们可能会错误地返回`9`因为`0 % 9 == 0`。 

实现明确检查：```
if num == 0:
    return 0
```这保证了零的正确行为。 

### 已经输入一个数字

 如果输入已经在`1`和`9`，答案应该只是数字本身。 例如：

-`5 -> 5`-`8 -> 8`模公式自然可以处理这些情况，因为：

 -`5 % 9 = 5`-`8 % 9 = 8`不需要额外的逻辑。 

### 九的正倍数

 像这样的数字`9`,`18`,`99`， 和`9999`很棘手，因为它们的模`9`结果是`0`，但他们的数字根应该是`9`， 不是`0`。 

例如：```
18 -> 1 + 8 = 9
```实现正确地处理了这个问题：```
if remainder == 0:
    return 9
```这确保了所有正倍数`9`产生正确的结果。
