 ## 解决方案

 ## 问题理解

 该问题给出了二维平面上两个轴对齐的矩形的坐标。 每个矩形都使用两个角点表示：

 - 左下角`(x1, y1)`- 右上角`(x2, y2)`对于第一个矩形，坐标为：

 -`(ax1, ay1)`对于左下角
 -`(ax2, ay2)`对于右上角

 对于第二个矩形，坐标为：

 -`(bx1, by1)`对于左下角
 -`(bx2, by2)`对于右上角

 任务是计算两个矩形组合所覆盖的总面积。 

乍一看，单独计算每个矩形的面积并将它们加在一起似乎就足够了。 然而，矩形可能重叠。 如果这样做，重叠区域将被计算两次。 为了获得正确的总覆盖面积，我们必须减去一次重叠面积。 

这些矩形是直线的，这意味着它们的边平行于 x 轴和 y 轴。 此属性使重叠计算变得简单，因为可以沿 x 轴和 y 轴独立计算重叠。 

坐标约束范围为`-10^4`到`10^4`。 这些是相对较小的值，但重要的观察结果是输入大小是恒定的。 我们只处理两个矩形，因此效率不是关于输入大小的缩放，而是关于选择正确的几何计算。 

一些边缘情况很重要：

 - 矩形可能根本不重叠
 - 一个矩形可能完全位于另一个矩形内部
 - 矩形只能在边缘或角落接触
 - 矩形可以是相同的
 - 坐标可能为负

 当矩形不相交时，简单的实现很容易产生负重叠宽度或高度。 正确的处理需要将重叠尺寸夹紧为零。 

## 方法

 ### 蛮力方法

 一种强力的几何方法是将平面视为网格并计算至少一个矩形覆盖的每个单位正方形。 

对于边界区域内的每个整数坐标，我们可以确定该点是否位于矩形 A、矩形 B 或两者内。 通过计算所有被覆盖的晶胞，我们就可以得到总面积。 

这种方法在概念上是正确的，因为它直接测量覆盖的空间。 然而，它的计算成本很高。 坐标范围可达`20,000`每个维度都有一个单位，因此在最坏的情况下迭代整个平面将需要数亿次操作。 

尽管约束不是很大，但这种方法是不必要的，因为几何提供了直接的公式。 

### 最佳几何方法

 关键的见解是可以使用包含排除原理来计算总覆盖面积。 

公式为：$$\text{Total Area} = \text{Area of A} + \text{Area of B} - \text{Overlap Area}$$唯一具有挑战性的部分是正确计算重叠区域。 

如果两个矩形的投影在两个轴上重叠，则两个矩形重叠。 

重叠宽度为：$$\min(ax2, bx2) - \max(ax1, bx1)$$重叠高度为：$$\min(ay2, by2) - \max(ay1, by1)$$如果任一值为负，则矩形不会沿该维度重叠，因此重叠面积为零。 

这种方法非常高效，因为它只执行恒定数量的算术运算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(W × H) | O(1) | O(1) | 遍历平面并计算覆盖的单元格 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 使用矩形面积公式和重叠计算 |

 ## 算法演练

 1. 计算第一个矩形的面积。 

The width is`ax2 - ax1`，高度为`ay2 - ay1`。 

面积为：$$(ax2 - ax1) \times (ay2 - ay1)$$2. 计算第二个矩形的面积。 

相似地：$$(bx2 - bx1) \times (by2 - by1)$$3. 计算重叠宽度。 

重叠区域的左边界是较大的左边缘：$$\max(ax1, bx1)$$右边界是较小的右边缘：$$\min(ax2, bx2)$$所以：$$\text{overlapWidth} = \min(ax2, bx2) - \max(ax1, bx1)$$4. 计算重叠高度。 

相似地：$$\text{overlapHeight} = \min(ay2, by2) - \max(ay1, by1)$$5. 防止负重叠尺寸。 

如果矩形不重叠，则一个或两个重叠尺寸将变为负值。 

由于负面积没有意义，因此将它们钳制为零：$$\text{overlapWidth} = \max(0, \text{overlapWidth})$$

$$\text{overlapHeight} = \max(0, \text{overlapHeight})$$6. 计算重叠面积。$$\text{overlapArea} = \text{overlapWidth} \times \text{overlapHeight}$$7. 应用包含-排除。 

将两个矩形区域相加并减去重复的重叠部分：$$\text{result} = \text{areaA} + \text{areaB} - \text{overlapArea}$$### 为什么它有效

 每个矩形区域贡献其所有覆盖空间。 如果矩形重叠，则重叠区域将被计算两次，一次在每个矩形的区域中。 减去重叠区域一次就可以消除这种重复，并准确地留下两个矩形的并集区域。 

重叠计算之所以有效，是因为当两个轴对齐的矩形的间隔在两个轴上重叠时，它们就会精确相交。 

## Python 解决方案```python
class Solution:
    def computeArea(
        self,
        ax1: int,
        ay1: int,
        ax2: int,
        ay2: int,
        bx1: int,
        by1: int,
        bx2: int,
        by2: int
    ) -> int:

        # Area of rectangle A
        area_a = (ax2 - ax1) * (ay2 - ay1)

        # Area of rectangle B
        area_b = (bx2 - bx1) * (by2 - by1)

        # Compute overlap dimensions
        overlap_width = min(ax2, bx2) - max(ax1, bx1)
        overlap_height = min(ay2, by2) - max(ay1, by1)

        # Clamp negative overlaps to zero
        overlap_width = max(0, overlap_width)
        overlap_height = max(0, overlap_height)

        # Overlapping area
        overlap_area = overlap_width * overlap_height

        # Total covered area
        return area_a + area_b - overlap_area
```该实现直接遵循先前开发的几何公式​​。 

第一部分使用宽度乘以高度来计算各个矩形面积。 

下一部分独立计算 x 轴和 y 轴的重叠尺寸。 使用`min`对于右侧或顶部边界以及`max`对于左边界或下边界，隔离相交间隔。 

夹紧步骤至关重要。 如果没有它，非重叠矩形将产生负重叠尺寸，导致不正确的负重叠区域。 

最后，通过包含排除公式将结果组合成最终答案。 

## 解决方案```go
func computeArea(ax1 int, ay1 int, ax2 int, ay2 int, bx1 int, by1 int, bx2 int, by2 int) int {
    // Area of rectangle A
    areaA := (ax2 - ax1) * (ay2 - ay1)

    // Area of rectangle B
    areaB := (bx2 - bx1) * (by2 - by1)

    // Compute overlap dimensions
    overlapWidth := min(ax2, bx2) - max(ax1, bx1)
    overlapHeight := min(ay2, by2) - max(ay1, by1)

    // Clamp negative overlaps to zero
    overlapWidth = max(0, overlapWidth)
    overlapHeight = max(0, overlapHeight)

    // Overlap area
    overlapArea := overlapWidth * overlapHeight

    // Total covered area
    return areaA + areaB - overlapArea
}

func min(a int, b int) int {
    if a < b {
        return a
    }
    return b
}

func max(a int, b int) int {
    if a > b {
        return a
    }
    return b
}
```Go 的实现与 Python 解决方案非常相似。 由于 Go 没有提供内置整数`min`和`max`原始整数的函数，辅助函数是手动实现的。 

整数溢出在这里不是一个问题，因为坐标范围足够小，所有中间区域计算都可以安全地适合 Go 的范围`int`类型。

 ## 边缘情况

 当矩形根本不重叠时，就会出现一种重要的边缘情况。 在这种情况下，重叠宽度或高度变为负值。 有缺陷的实现可能会将这些负值相乘并意外地产生正重叠区域。 该解决方案通过使用以下方法将重叠尺寸限制为零来防止这种情况发生：`max(0, value)`。 

另一个关键情况是矩形仅在边缘或角落接触。 从几何角度来看，接触边界不会产生区域重叠。 例如，如果一个矩形恰好在另一个矩形的开始处结束，则重叠宽度将变为零。 由于零乘以任何值都为零，因此实现自然会正确处理此问题。 

第三个重要的边缘情况是完全遏制，其中一个矩形完全位于另一个矩形内部。 在这种情况下，重叠面积等于较小矩形的整个面积。 包含-排除公式仍然可以完美地工作，因为减去重叠可以消除一次重复的计数。 

负坐标也值得考虑。 由于矩形尺寸是使用坐标差计算的，因此实际的坐标符号并不重要。 该实现可以正确处理平面任何象限中的矩形。
