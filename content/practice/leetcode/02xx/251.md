[LeetCode 第 251 题](https://leetcode.com/problems/flatten-2d-vector/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、设计、迭代器

 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个迭代器，它可以像单个平面序列一样遍历二维数组。 迭代器不应返回嵌套列表，而应通过两种方法一次公开一个元素，`next()`和`hasNext()`。 

输入是一个 2D 向量，表示列表的列表。 每个内部列表可以包含零个或多个整数。 迭代器必须按行优先顺序访问元素，这意味着它会在移动到第二行之前处理第一行中的所有元素，依此类推。 

例如，给定：```
[[1, 2], [3], [4]]
```扁平化的遍历顺序变为：```
1, 2, 3, 4
```这`next()`方法返回下一个可用整数并将迭代器向前推进一个位置。 这`hasNext()`方法检查剩余结构中的某个位置是否仍然存在另一个元素。 

一个重要的细节是该问题保证所有调用`next()`是有效的。 这意味着我们永远不需要处理以下情况`next()`迭代器耗尽后调用。 

就行而言，约束相对较小，但元素总数仍然可能很大：

 - 最多 200 行
 - 每行最多可包含 500 个元素
 - 最多`10^5`打电话给`next()`和`hasNext()`这些限制强烈表明重复扫描整个结构效率很低。 自从`hasNext()`可能会被调用很多次，我们需要一个两个操作都接近恒定时间的实现。 

一些边缘情况很重要：

 - 外部向量可能为空，`[]`- 一些内部向量可能为空，`[[], [], [1]]`- 可能会出现连续的空行
 -`hasNext()`之前可能被调用多次`next()`- 最后一行可能为空

 幼稚的实现通常会在空内部数组上失败，因为行之间的前进很容易被忽视。 

## 方法

 ### 蛮力方法

 最简单的方法是在初始化期间将整个二维向量展平为单个一维数组。 

例如：```
[[1,2],[3],[4]]
```会立即变成：```
[1,2,3,4]
```然后，迭代器将简单地在这个扁平列表中维护一个索引。 

这种方法是正确的，因为展平保留了原始的遍历顺序。 每次致电`next()`返回展平序列中的下一个元素，并且`hasNext()`检查索引是否仍在范围内。 

但是，此解决方案使用与元素总数成比例的额外内存，因为它将数据复制到另一个数组中。 虽然对于给定的约束是可以接受的，但从设计角度来看它并不是最佳的，因为迭代器可以直接遍历原始结构。 

### 最佳方法

 更好的方法是维护两个指针：

 - 行指针
 - 列指针

 这些指针表示原始 2D 矢量内的当前位置。 

关键的观察是我们实际上不需要提前展平结构。 我们只需要一种方法来跳过空行并在请求时找到下一个有效元素。 

迭代器延迟工作：

 -`hasNext()`使指针前进，直到：

 - 找到有效元素，或者
 - 所有行均已耗尽
 -`next()`简单地返回当前元素并前进列指针

 这种方法避免了复制数据并且仅使用恒定的额外内存。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N) 初始化，O(1) 每次操作 | O(N) | 将整个向量展平为一个单独的数组 |
 | 最佳| O(1) 每次操作摊销 | O(1) | O(1) | 使用行和列指针惰性遍历原始结构 |

 这里，`N`表示所有行中的元素总数。 

## 算法演练

 ### 最优惰性迭代算法

 1. 将原始2D向量存储在类内部。 

我们保留对输入结构的引用，而不是将其展平。 这可以避免不必要的复制并减少内存使用。 
2. 初始化两个索引：

 -`row`-`col`两者都开始于`0`，表示第一个元素的位置。 
3. 实施`hasNext()`所以它会前进到空行之前。 

尽管：

-`row`仍在向量内部，并且
 -`col`已到达当前行的末尾

 移动到下一行并重置`col`回到`0`。 

此步骤至关重要，因为某些行可能为空。 
4. 跳过耗尽的行后，判断是否存在有效位置。 

如果`row < len(vec)`，另一个元素存在。 

否则，迭代器就会耗尽。 
5. 实施`next()`首先确保存在有效的位置。 

由于问题保证了有效的调用，我们只需：

 - 阅读`vec[row][col]`- 增量`col`- 返回值
 6. 未来的电话`hasNext()`根据需要继续推进。 

迭代器总是向前前进并且从不重新访问之前的位置。 

### 为什么它有效

 该算法保持了每次成功后的不变量`hasNext()`呼叫, 的`(row, col)`对要么指向有效元素，要么迭代器完全耗尽。 

由于行是按顺序处理的，列是从左到右前进的，因此每个元素都会以正确的顺序访问一次。 安全地跳过空行，确保不会发生无效索引。 

## Python 解决方案```python
from typing import List

class Vector2D:

    def __init__(self, vec: List[List[int]]):
        self.vec = vec
        self.row = 0
        self.col = 0

    def next(self) -> int:
        value = self.vec[self.row][self.col]
        self.col += 1
        return value

    def hasNext(self) -> bool:
        while self.row < len(self.vec) and self.col >= len(self.vec[self.row]):
            self.row += 1
            self.col = 0

        return self.row < len(self.vec)

# Your Vector2D object will be instantiated and called as such:
# obj = Vector2D(vec)
# param_1 = obj.next()
# param_2 = obj.hasNext()
```该实现存储原始 2D 向量并维护两个指针，`row`和`col`。 

这`hasNext()`方法是解决问题的核心。 它的职责是将迭代器向前移动，直到：

 - 找到有效的元素位置，或者
 - 所有行均已耗尽

 循环：```python
while self.row < len(self.vec) and self.col >= len(self.vec[self.row]):
```检查当前行是否已完全消耗。 如果是，迭代器将移动到下一行并重置列索引。 

这`next()`方法故意简单。 因为该问题保证了有效的调用，所以我们可以安全地直接访问当前位置。 返回当前值后，列指针前进一。 

一个重要的细节是`next()`本身不跳过空行。 该逻辑仍然集中在内部`hasNext()`，保持职责清晰并防止逻辑重复。 

## 解决方案```go
type Vector2D struct {
	vec [][]int
	row int
	col int
}

func Constructor(vec [][]int) Vector2D {
	return Vector2D{
		vec: vec,
		row: 0,
		col: 0,
	}
}

func (this *Vector2D) Next() int {
	value := this.vec[this.row][this.col]
	this.col++
	return value
}

func (this *Vector2D) HasNext() bool {
	for this.row < len(this.vec) && this.col >= len(this.vec[this.row]) {
		this.row++
		this.col = 0
	}

	return this.row < len(this.vec)
}

/**
 * Your Vector2D object will be instantiated and called as such:
 * obj := Constructor(vec);
 * param_1 := obj.Next();
 * param_2 := obj.HasNext();
 */
```Go 的实现与 Python 版本非常相似。 主要区别在于 Go 使用具有显式字段的结构而不是实例属性。 

Go 中的切片自然支持空内部数组，因此不需要对 nil 或空行进行特殊处理。 相同的指针前进逻辑工作正常。 

整数溢出不是问题，因为索引仍然在 Go 的整数范围内。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(1) 摊销 | 每个元素和行最多处理一次 |
 | 空间| O(1) | O(1) | 仅存储两个索引 |

 ## 边缘情况

 ### 空外部向量

 输入如下：```
[]
```根本不包含任何行。 幼稚的实现可能会立即尝试访问`vec[0]`，导致索引错误。 

这个实现可以安全地处理这种情况，因为`hasNext()`首先检查：```
self.row < len(self.vec)
```如果向量为空，则条件立即失败并返回`False`。 

### 空内行

 输入例如：```
[[], [], [1]]
```特别棘手，因为迭代器必须在到达有效元素之前跳过无效行。 

有缺陷的实现可能会错误地假设每一行至少包含一个值。 该解决方案通过重复推进行内的行来避免该问题`while`循环进入`hasNext()`直到找到包含剩余元素的行。 

### 多次致电`hasNext()`许多迭代器问题在以下情况下都会失败`hasNext()`被连续调用多次。 

例如：```
obj.hasNext()
obj.hasNext()
obj.hasNext()
```不应多次推进迭代器或跳过元素。 

这个实现可以正常工作，因为`hasNext()`仅当当前行耗尽时才向前移动。 一旦定位到有效元素，重复调用将使状态保持不变。
