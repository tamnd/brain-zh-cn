 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的整数是否`n`是二的幂。 

如果一个数字可以写成以下形式，则该数字被视为 2 的幂：$$n = 2^x$$在哪里`x`是一个非负整数。 

2 的幂的一些例子是：

 -`1 = 2^0`-`2 = 2^1`-`4 = 2^2`-`8 = 2^3`-`16 = 2^4`输入是单个整数`n`，预期输出是一个布尔值：

 - 返回`true`如果`n`是二的幂
 - 返回`false`否则

 约束指定：$$-2^{31} \le n \le 2^{31} - 1$$这意味着输入可以是负数、零或正数。 负数永远不可能是 2 的幂，因为 2 的幂总是正数。 零也不是二的幂。 

该问题包括后续询问我们是否可以在没有循环或递归的情况下解决它。 这个暗示强烈表明我们应该利用数学或位操作属性，而不是重复除以二。 

一些边缘情况很重要：

 -`n = 0`，应该返回`false`- 负数，例如`-8`-`n = 1`， 因为`1 = 2^0`- 接近整数限制的数字
 - 奇数大于`1`，它不能是两个的幂

 如果在应用位操作之前没有正确处理非正值，则简单的实现很容易失败。 

## 方法

 ### 蛮力方法

 最直接的方法是将数字重复除以`2`。 

这个想法很简单：

 - 如果`n`可以整除`2`，除以`2`- 继续直到：

 - 数字变为`1`，这意味着它是二的幂
 - 或者该数字不再能被整除`2`，这意味着它不是

 例如，与`n = 16`:

 -`16 -> 8 -> 4 -> 2 -> 1`由于我们最终达到`1`，该数字是 2 的幂。 

为了`n = 12`:

 -`12 -> 6 -> 3`现在`3`不能被整除`2`，所以答案是`false`。 

这种方法可以正确工作，因为每个 2 的幂都可以重复减半，直到只`1`遗迹。 

尽管此方法对于给定的约束已经足够有效，但它仍然使用循环。 后续内容鼓励我们寻找更优雅的恒定时间解决方案。 

### 最佳位操作方法

 关键的观察来自二进制表示。 

2 的幂恰好有一位设置为`1`。 

示例：

 | 十进制| 二进制|
 | --- | --- |
 | 1 |`0001`|
 | 2 |`0010`|
 | 4 |`0100`|
 | 8 |`1000`|

 现在考虑当我们减去时会发生什么`1`:

 | n | n | 的二进制 n - 1 | n - 1 n - 1 的二进制 |
 | --- | --- | --- | --- |
 | 1 |`0001`| 0 |`0000`|
 | 2 |`0010`| 1 |`0001`|
 | 4 |`0100`| 3 |`0011`|
 | 8 |`1000`| 7 |`0111`|

 注意一个重要的属性：

 -`n`恰好有一个`1`少量
-`n - 1`将该位变成`0`并将所有低位更改为`1`所以：$$n \& (n - 1) = 0$$对于每一个 2 的正幂。 

例如：```
8      = 1000
7      = 0111
----------------
8 & 7  = 0000
```这为我们提供了一个非常紧凑且高效的解决方案。

 ## 算法演练

 ### 最佳位操作算法

 1.首先检查是否`n`小于或等于`0`。 

二的幂始终是正整数。 如果`n <= 0`，立即返回`false`。 
2. 计算`n & (n - 1)`。 

此操作删除最低设置位`n`。 
3. 如果结果等于`0`， 返回`true`。 

2 的幂恰好包含一个设置位，因此删除该位会使所有位保持为`0`。 
4.否则返回`false`。 

具有多个设置位的数字在操作后仍将至少有一个剩余的设置位。 

### 为什么它有效

 正确性依赖于二进制表示不变量。 

2 的正幂总是恰好包含一个设置位。 减法`1`翻转将位设置为`0`并将所有低位转换为`1`。 在这两个数字之间执行按位与会删除每个设置位并产生`0`。 

2 的非幂包含多个设置位，因此在 AND 运算之后，至少有一位保持设置状态，从而产生非零结果。 

## Python 解决方案```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n <= 0:
            return False

        return (n & (n - 1)) == 0
```实现从处理无效输入开始。 由于 2 的幂必须为正，因此任何小于或等于零的值都会立即返回`False`。 

核心逻辑是这样的表达式：```python
(n & (n - 1)) == 0
```这使用了二的幂的二元属性。 对于 2 的有效幂，该操作会清除唯一设置的位并产生零。 

实现很简洁，因为位操作属性完全捕获了我们需要的数学定义。 

## 解决方案```go
func isPowerOfTwo(n int) bool {
    if n <= 0 {
        return false
    }

    return (n & (n - 1)) == 0
}
```Go 实现几乎与 Python 版本相同，因为两种语言都支持直接对整数进行位运算符。 

一个重要的细节是位操作之前的显式正性检查。 负整数使用二进制补码表示，未经验证直接应用位技巧可能会产生不正确的结果。 

Go 整数是固定宽度的机器整数，但问题约束可以轻松地适应标准整数大小。

 ## 边缘情况

 ### 零输入

 价值`0`是错误的常见来源。 在二进制中，`0 & (-1)`评估为`0`，如果我们只使用按位条件，这可能会错误地表明零是 2 的幂。 该实现通过首先检查是否`n <= 0`。 

### 负数

 负整数使用二进制补码表示。 由于这种表示形式，某些负数在位运算中可能会出现意外的行为。 由于 2 的幂在数学上是正的，因此该实现在执行位技巧之前立即拒绝所有非正输入。 

### 价值一

 许多开发者忘记了这一点`1`从技术上讲是 2 的幂，因为：$$1 = 2^0$$该算法正确处理了这个问题：```
1 & 0 = 0
```所以函数正确返回`true`。 

### 具有多个设置位的数字

 值例如`3`,`5`， 或者`12`包含多个`1`二进制形式的位。 这些不是两个人的力量。 按位 AND 运算至少保留一组位，产生非零结果并正确返回`false`。
