[LeetCode 第 250 题](https://leetcode.com/problems/count-univalue-subtrees/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们计算二叉树中有多少个子树是“单值”子树。 单值子树是每个节点具有相同值的子树。 

子树由一个节点及其所有后代组成。 这意味着树中的每个节点都可以作为子树的根。 我们的任务是检查所有这样的子树并确定有多少满足单值属性。 

输入是二叉树的根。 每个节点包含：

 - 整数值
 - 指向左孩子的指针
 - 指向右孩子的指针

 输出是一个整数，表示单值子树的数量。 

考虑第一个例子：```
        5
       / \
      1   5
     / \   \
    5   5   5
```四个单值子树是：

 - 有值的左叶节点`5`- 有值的中间叶子节点`5`- 有值的右叶节点`5`- 以右孩子为根的子树`5`子树的根为`1`不是单一值，因为它的子项具有不同的值。 整棵树也不是单值的。 

约束条件告诉我们：

 - 树最多包含 1000 个节点
 - 节点值范围为`-1000`到`1000`大小为 1000 的树相对较小，但低效的重复子树遍历仍然会导致二次复杂度。 这表明我们的目标应该是`O(n)`如果可能的话解决方案。 

重要的边缘情况包括：

 - 一棵空树
 - 一棵只有一个节点的树
 - 每个节点具有相同值的树
 - 没有内部子树是单值的树
 - 类似于链表的倾斜树

 这些情况可能会暴露有关递归、空处理或子树验证的错误假设。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是独立检查每个子树。 

对于每个节点：

 1.将该节点视为子树的根
 2.遍历整个子树
 3. 检查里面的所有节点是否共享相同的值
 4. 如果是，则增加答案

 为了验证子树，我们递归地将每个后代节点与根值进行比较。 

这种方法是正确的，因为每个子树都被显式检查。 然而，它执行了多余的工作。 验证重叠子树时会重复遍历相同的节点。 

例如，在一棵倾斜的树中`n`节点：

 - 根子树检查`n`节点
 - 下一个子树检查`n - 1`节点
 - 等等

 这导致：```
n + (n - 1) + (n - 2) + ... + 1 = O(n²)
```虽然限制是适度的，但我们可以做得更好。 

### 最佳方法

 关键的观察是子树是否是单值完全取决于它的子树。 

以节点为根的子树`X`如果满足以下条件，则为单值：

 1.它的左子树是单值的
 2.它的右子树是单值的
 3. 左子节点（如果存在）具有与`X`4. 右子节点（如果存在）与以下值相同`X`这自然暗示了后序遍历：

 - 首先判断左子树是否为单值
 - 然后判断右子树是否为单值
 - 最后判断当前子树是否为uni-value

 通过自下而上计算该信息，每个节点仅被处理一次。 

这消除了冗余的子树遍历并给出了`O(n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(h) | 重复验证重叠子树 |
 | 最佳| O(n) | O(h) | 具有自下而上验证的单次 DFS 遍历 |

 这里，`h`代表树的高度。 

## 算法演练

 1. 创建一个计数器来存储单值子树的数量。 
2. 定义一个递归DFS函数，返回以当前节点为根的子树是否为单值。 
3. 如果当前节点是`None`， 返回`True`。 

空子树被视为单值，因为它不违反条件。 
4. 递归检查左子树。 
5. 递归检查右子树。 
6. 如果任一子树不是单值，则返回`False`。 

由于当前子树取决于两个子树是否有效，因此任何一个子树的失败都会立即取消当前子树的资格。 
7. 如果左孩子存在且其值与当前节点的值不同，则返回`False`。 
8. 如果右孩子存在且其值与当前节点的值不同，则返回`False`。 
9. 如果所有检查均通过：

 - 增加全局计数器
 - 返回`True`10. DFS 完成后，返回计数器。 

### 为什么它有效

 该算法之所以有效，是因为它自下而上地处理树。 每个节点使用来自其子节点的已计算信息来确定其子树是否为单值。 

仅当两个子子树本身都是单值并且所有子值都与当前节点的值匹配时，子树才可以是单值。 由于这些条件既是必要的又是充分的，因此每个子树都被正确分类一次。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def countUnivalSubtrees(self, root: Optional[TreeNode]) -> int:
        count = 0

        def dfs(node: Optional[TreeNode]) -> bool:
            nonlocal count

            if node is None:
                return True

            left_is_unival = dfs(node.left)
            right_is_unival = dfs(node.right)

            if not left_is_unival or not right_is_unival:
                return False

            if node.left and node.left.val != node.val:
                return False

            if node.right and node.right.val != node.val:
                return False

            count += 1
            return True

        dfs(root)
        return count
```该实现使用嵌套的 DFS 辅助函数，该函数返回一个布尔值，指示当前子树是否为单值。 

底壳手柄`None`通过返回节点`True`。 这简化了逻辑，因为丢失的子节点不会使子树无效。 

递归调用首先评估左子树和右子树。 这是后序遍历，因为当前节点依赖于来自其后代的信息。 

两个递归调用返回后，函数检查：

 - 两个子子树是否都是单值
 - 子节点值是否与当前节点值匹配

 如果任何条件失败，则子树不是单值的。 

否则，子树符合条件，因此计数器增加并且`True`被返回。 

这`nonlocal`关键字允许嵌套的 DFS 函数更新共享计数器变量。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func countUnivalSubtrees(root *TreeNode) int {
    count := 0

    var dfs func(node *TreeNode) bool

    dfs = func(node *TreeNode) bool {
        if node == nil {
            return true
        }

        leftIsUnival := dfs(node.Left)
        rightIsUnival := dfs(node.Right)

        if !leftIsUnival || !rightIsUnival {
            return false
        }

        if node.Left != nil && node.Left.Val != node.Val {
            return false
        }

        if node.Right != nil && node.Right.Val != node.Val {
            return false
        }

        count++
        return true
    }

    dfs(root)
    return count
}
```Go 实现遵循与 Python 解决方案相同的递归结构。 

主要区别在于 Go 使用显式指针检查`nil`而不是 Python 的真实性检查。 递归助手被声明为函数变量，因为 Go 要求在赋值之前定义递归匿名函数。 

整数溢出不是问题，因为最大节点数仅为 1000。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 递归栈深度等于树高|

 该算法对树执行一次 DFS 遍历。 每个节点在处理其子节点后都会持续工作，因此总时间与节点数量呈线性关系。 

空间复杂度来自递归调用堆栈的使用。 在平衡树中，高度为`O(log n)`。 在倾斜树的最坏情况下，高度变为`O(n)`。

 ## 边缘情况

 ### 空树

 空树不包含子树，所以正确答案是`0`。 

如果实现假设根始终存在，这种情况可能会导致错误。 该解决方案自然地处理了这个问题，因为 DFS 立即返回`True`为了`None`，而计数器保持为零。 

### 单节点树

 单个节点始终是单值子树，因为没有不同的后代。 

某些实现错误地要求在验证子树之前两个子节点都存在。 该解决方案通过将失踪儿童视为有效来避免该问题。 

### 父母匹配一个孩子但不匹配另一个

 考虑：```
    1
   / \
  1   2
```叶节点是有效的单值子树，但根子树不是。 

一个常见的错误是仅检查子子树是否有效，而不将子值与父值进行比较。 该实现在计算当前子树之前显式检查两个子值。 

### 倾斜的树

 形状像链表的树可能会暴露递归问题或关于平衡结构的错误假设。 

例如：```
1
 \
  1
   \
    1
```每个子树都应该正确计数。 由于该算法仅依赖于递归子树的有效性和局部比较，因此无论树的形状如何，它都能正确工作。
