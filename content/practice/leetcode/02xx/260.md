 ## 解决方案

 ## 问题理解

 问题给出一个整数数组`nums`其中每个值恰好出现两次，除了两个仅出现一次的数字。 任务是找到这两个唯一的数字并以任意顺序返回它们。 

换句话说，数组大部分包含重复对，但恰好有两个元素没有匹配的重复项。 我们必须隔离并返回这两个值。 

例如，在数组中`[1,2,1,3,2,5]`, 数字`1`和`2`每个出现两次，而`3`和`5`仅出现一次。 因此，答案是`[3,5]`或者`[5,3]`。 

这些约束很重要，因为它们强烈影响算法的选择：

 - 数组长度可以大到`3 * 10^4`- 值可以为负数
 - 解决方案必须在线性时间内运行，`O(n)`- 解决方案必须使用恒定的额外空间，`O(1)`这些要求立即排除了几种常见的方法。 例如，排序需要`O(n log n)`时间，并且使用哈希映射需要`O(n)`额外的空间。 

该问题保证：

 - 两个数字恰好出现一次
 - 每个其他数字恰好出现两次

 此保证至关重要，因为它支持使用 XOR 属性的位操作解决方案。 

一些边缘情况值得预先考虑。 这两个唯一的数字可能都是负数，其中一个可能为零，或者数组可能仅包含两个元素。 实现还必须正确分隔两个唯一值，即使它们仅相差一位。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是计算每个数字出现的次数。 我们可以使用哈希映射，其中键是数字，值是其频率。 

我们迭代数组一次来构建频率表。 然后我们迭代地图并收集频率为的数字`1`。 

这种方法是正确的，因为地图明确记录了每个数字出现的次数。 任何有计数的数字`1`必须是必填答案之一。 

然而，该解决方案违反了恒定空间要求，因为哈希图可能最多存储`O(n)`不同的数字。 

### 使用异或和位操作的最佳方法

 关键的观察结果来自 XOR 属性：

 -`a ^ a = 0`-`a ^ 0 = a`- XOR 是可交换的和结合的

 如果我们将数组中的所有数字异或在一起，则每个重复的数字都会自行抵消。 最终结果变成：```
x ^ y
```在哪里`x`和`y`是两个唯一的数字。 

自从`x`和`y`不同的是，它们的异或结果必须至少包含一个设置位。 该设置位告诉我们`x`和`y`在那个位置上有所不同。 

我们可以使用这个不同的位将数字分为两组：

 - 已设置位的数字
 - 该位未设置的数字

 因为重复的数字是相同的，所以两个副本总是进入同一组并再次相互抵消。 

这两个唯一的数字最终位于不同的组中，使我们能够单独恢复它们。

 ## 算法演练

 1. 将数组中的所有数字异或在一起。 

在此步骤之后，每个重复的数字都会自行抵消。 剩余值为：```
xor_all = unique1 ^ unique2
```由于两个唯一编号不同，`xor_all`是非零的。 
2. 找到两个唯一数字的不同之处。 

我们使用以下方法隔离最右边的设置位：```
differing_bit = xor_all & (-xor_all)
```该操作提取等于的最低位`1`。 
3. 将数字分为两组。 

使用`differing_bit`，我们将所有数字分为：

 - A 组：该位被设置的数字
 - B 组：未设置该位的数字

 这两个唯一的数字必须属于不同的组，因为它们在该位位置上不同。 
4. 对每组内的数字进行异或。 

重复的数字保留在同一组中并通过 XOR 消除。 

处理后：

 - 一组生产`unique1`- 另一组生产`unique2`5. 返回两个唯一的数字。 

### 为什么它有效

 正确性取决于异或取消。 每个重复的数字恰好出现两次，因此 XOR 可以将它们完全删除。 剩余的 XOR 值标识两个唯一数字不同的位。 按该位进行分区可确保两个唯一的数字位于不同的组中，而重复的数字仍保留在一起并仍然相互抵消。 因此，每一组都简化为一个唯一的数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        xor_all = 0

        # XOR all numbers together
        for num in nums:
            xor_all ^= num

        # Isolate the rightmost set bit
        differing_bit = xor_all & -xor_all

        unique1 = 0
        unique2 = 0

        # Divide numbers into two groups
        for num in nums:
            if num & differing_bit:
                unique1 ^= num
            else:
                unique2 ^= num

        return [unique1, unique2]
```实现首先对数组中的每个数字进行异或。 由于重复项相互抵消，因此结果变为仅两个唯一值的异或。 

接下来，代码使用以下命令提取最右边的设置位：```python
differing_bit = xor_all & -xor_all
```两个唯一数字之间的该位必须不同。 

然后，该算法再次循环遍历数组，并根据该位是否设置来分隔数字。 每个组执行自己的异或累加。 

由于重复的值总是进入同一组，因此它们会再次抵消。 每个累加器最终都包含一个唯一的数字。 

最后，该解决方案以列表形式返回两个结果。 

## 解决方案```go
func singleNumber(nums []int) []int {
	xorAll := 0

	// XOR all numbers together
	for _, num := range nums {
		xorAll ^= num
	}

	// Isolate the rightmost set bit
	differingBit := xorAll & -xorAll

	unique1 := 0
	unique2 := 0

	// Divide numbers into two groups
	for _, num := range nums {
		if num&differingBit != 0 {
			unique1 ^= num
		} else {
			unique2 ^= num
		}
	}

	return []int{unique1, unique2}
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 使用 Go 切片代替 Python 列表，并且位操作直接对整数进行操作。 

一个小的语法差异是条件检查：```go
if num&differingBit != 0
```Go 要求按位条件与零进行显式比较。 

负数可以正确处理，因为 Go 整数使用补码表示，就像 Python 内部对按位运算所做的那样。

 ## 边缘情况

 当数组仅包含两个元素时，会出现一种重要的边缘情况，例如`[0,1]`。 在这种情况下，两个数字都是唯一的，并且根本不存在重复对。 某些实现错误地假设必须存在重复项。 该算法仍然有效，因为 XOR 简单地变为`0 ^ 1`，并且分区步骤将两个数字完全分开。 

另一个重要的情况涉及负整数。 由于二进制的补码表示形式，负数的位操作有时会导致混乱。 例如，在`[-1,0]`，该算法仍然正确地提取不同的位并正确地划分数字。 XOR 运算对于有符号整数的行为一致，因此实现无需特殊逻辑即可处理负数。 

当重复值中出现零时，会出现第三种边缘情况，例如`[0,0,7,8]`。 自从`0 ^ 0 = 0`，重复的零完全像任何其他数字一样抵消。 该算法在异或累加和组划分期间自然地处理零。 

另一个微妙的情况是两个唯一数字仅相差一位。 在这种情况下，XOR 结果仅包含一个设置位。 表达式：```
xor_all & -xor_all
```仍然正确地隔离该位，确保数字被分成不同的组。
