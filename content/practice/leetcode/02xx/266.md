[LeetCode 第 266 题](https://leetcode.com/problems/palindrome-permutation/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、位操作

 ## 解决方案

 ## 问题理解

 该问题询问给定字符串的字符是否可以重新排列以形成回文。 回文是向前和向后读相同的字符串。 例子包括`"racecar"`,`"abba"`， 和`"a"`。 

重要的细节是我们没有被要求实际生成回文。 我们只需要确定输入字符串的至少一种排列是否可以形成一种排列。 

输入是一个字符串`s`仅包含小写英文字母。 输出是一个布尔值：

 - 返回`true`如果字符的某些重新排列形成回文。 
- 返回`false`否则。 

约束告诉我们字符串长度最多可达 5000 个字符。 这个大小足够大，以至于生成所有排列是完全不可行的。 由于字母表仅限于小写英文字母，因此频率计数成为一种非常自然的方法。 

要理解回文的关键属性，请考虑字符在回文中的排列方式：

 - 在偶数长度回文中，每个字符必须出现偶数次，因为字符在中心周围相互镜像。 
- 在奇数长度回文中，只有一个字符可能出现奇数次，因为中间的字符不需要匹配对。 

这一观察直接导致最优解。 

一些边缘情况很重要：

 - 应始终返回单字符字符串`true`。 
- 每个字符数为偶数的字符串应该返回`true`。 
- 应返回具有多个奇数频率的字符串`false`。 
- 输入仅包含小写字母，因此我们不需要处理大写标准化或特殊字符。 

## 方法

 ### 蛮力方法

 强力解决方案将生成字符串的所有可能的排列，并检查任何排列是否是回文。 

为此，我们将：

 1. 生成字符串的所有排列。 
2. 对于每个排列，检查其向前和向后读是否相同。 
3. 返回`true`如果至少存在一个回文。 

这种方法是正确的，因为它详尽地检查了字符的每种可能的排列。 如果存在回文排列，算法最终会找到它。 

然而，这种方法太慢了。 一个长度的字符串`n`有`n!`排列。 即使对于相对较小的值`n`，阶乘增长变得巨大。 由于限制最多允许 5000 个字符，因此暴力破解是完全不切实际的。 

### 最佳方法

 关键的见解是我们不关心角色的实际排列。 我们只关心它们的频率。 

回文具有严格的结构特性：

 - 左侧的字符必须与右侧的字符匹配。 
- 因此，大多数字符必须出现偶数次。 
- 至多一个字符可能具有奇数频率。 

因此，问题归结为计算字符频率并检查有多少字符具有奇数计数。 

如果奇数频率字符的数量为：

 -`0`，字符串可以形成偶数长度的回文。 
-`1`，该字符串可以形成奇数长度的回文。 
- 大于`1`，形成回文是不可能的。 

这将问题从阶乘复杂性转变为简单的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! × n) | O(n! × n) | O(n!) | 生成所有排列并检查每一个 |
 | 最佳 | O(n) | O(1) | O(1) | 计算字符频率并检查奇数计数 |

 ## 算法演练

 ### 最优频率计数算法

 1. 创建哈希图或频率数组来统计每个字符在字符串中出现的次数。 

我们需要频率信息，因为回文有效性完全取决于字符计数。 由于输入仅包含小写英文字母，因此我们可以使用哈希映射或长度为 26 的固定大小数组。 
2. 逐个字符地遍历字符串。 

对于每个字符，增加其频率计数。 经过这一步，我们就可以准确地知道每个字母出现了多少次。 
3. 计算有多少个字符出现奇数频率。 

具有奇数频率的字符不能在回文中完美镜像，除非它占据中心位置。 
4. 检查奇数频率字符的个数。 

- 如果多个字符的计数为奇数，则返回`false`。 
- 否则，返回`true`。 
5. 完成计算。 

结果直接来自回文的数学性质。 

### 为什么它有效

 该算法之所以有效，是因为每个回文都需要镜像字符对。 偶数频率字符始终可以均匀地分为左右两半。 奇数频率字符会留下一个额外的不匹配副本，这仅对奇数长度回文中的单个中心位置有效。 因此，当且仅当至多一个字符具有奇数频率时，字符串才能形成回文。 

## Python 解决方案```python
class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        frequency = {}

        for char in s:
            frequency[char] = frequency.get(char, 0) + 1

        odd_count = 0

        for count in frequency.values():
            if count % 2 == 1:
                odd_count += 1

            if odd_count > 1:
                return False

        return True
```实现首先创建一个名为的字典`frequency`。 该字典存储每个字符在字符串中出现的次数。 

第一个循环迭代输入字符串中的每个字符并更新其计数。 使用`frequency.get(char, 0)`允许我们安全地将丢失的字符初始化为零。 

接下来，算法迭代所有频率值。 对于每个计数，它使用模运算符检查该值是否为奇数`%`。 

每当发现奇数时，`odd_count`增加一。 如果存在多个奇数频率，该函数立即返回`False`因为回文排列是不可能的。 

如果循环完成时未超过一个奇数频率，则该函数返回`True`。 

## 解决方案```go
func canPermutePalindrome(s string) bool {
    frequency := make(map[rune]int)

    for _, char := range s {
        frequency[char]++
    }

    oddCount := 0

    for _, count := range frequency {
        if count%2 == 1 {
            oddCount++
        }

        if oddCount > 1 {
            return false
        }
    }

    return true
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 一个`map[rune]int`用于存储字符频率。 

Go 字符串是 UTF-8 编码的，因此迭代`for _, char := range s`产生符文而不是原始字节。 虽然这个问题只包含小写英文字母，但使用符文仍然是惯用且安全的。 

与 Python 字典不同，Go 映射会自动返回缺失键的零值，因此增加频率很简单`frequency[char]++`。 

不用担心整数溢出，因为最大字符串长度仅为 5000。

 ## 边缘情况

 ### 单字符字符串

 仅包含一个字符的字符串始终是回文，因为它向前和向后读取相同。 幼稚的实现可能会错误地假设至少需要一对。 此实现可以正确处理这种情况，因为只有一个奇数频率是允许的。 

### 包含所有唯一字符的字符串

 输入如`"abc"`很重要，因为每个角色都出现一次。 这意味着多个奇数频率同时存在。 该实现通过计算奇数出现次数并返回来正确检测到这一点`False`一旦计数超过一。 

### 频率均为偶数的字符串

 输入如`"aabbcc"`代表完美配对案例。 每个字符都可以镜像到回文的中心。 执行正确返回`True`因为奇数频率计数在整个检查过程中保持为零。 

### 奇数长度有效回文

 类似的情况`"aabbc"`是微妙的，因为允许一个字符保持不匹配。 一些不正确的实现错误地要求所有计数都是偶数。 该解决方案明确允许一个奇数频率，确保此类输入得到正确处理。
