[LeetCode 第 272 题](https://leetcode.com/problems/closest-binary-search-tree-value-ii/)

 **难度：** 🔴难
 **主题：** 两个指针、堆栈、树、深度优先搜索、二叉搜索树、堆（优先级队列）、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到`k`二叉搜索树（BST）中的值，其值在数值上最接近给定的浮点数`target`。 

BST 有一个非常重要的性质：

 - 左子树中的每个值都小于当前节点。 
- 右子树中的每个值都大于当前节点。 

这种排序使我们能够避免扫描某些优化解决方案中的每个节点。 

输入包括：

 -`root`，BST的根节点
 -`target`, 一个浮点数
 -`k`，我们必须返回的最接近值的数量

 输出应准确包含`k`树中的节点值，其绝对差值是`target`是最小的。 

例如，如果目标是`3.7`， 然后：

-`4`有距离`|4 - 3.7| = 0.3`-`3`有距离`|3 - 3.7| = 0.7`-`5`有距离`1.3`所以两个最接近的值是`[4, 3]`。 

该问题保证只有一组唯一正确的`k`最接近的值。 当可能存在多个答案时，这消除了歧义。 

约束条件很重要：

 - 最多`10^4`节点
 - 值可能非常大
 -`k`可能大到`n`对所有节点进行排序的简单解决方案是可以接受的`10^4`，但后续具​​体询问我们是否可以做得更好`O(n)`对于平衡 BST。 

一些边缘情况很重要：

 - 一棵只有一个节点的树
 -`k = n`，意味着必须返回每个值
 - 小于所有节点值的目标
 - 大于所有节点值的目标
 - 目标恰好等于节点值
 - 高度不平衡的树木

 当决定探索 BST 的哪一侧或正确处理前驱和后继遍历时，幼稚的实现很容易失败。 

## 方法

 ### 蛮力方法

 最简单的解决方案是遍历整棵树并将所有节点值收集到一个数组中。 

一旦我们有了所有的值：

 1. 计算每个值与`target`2.按绝对差值排序
 3.返回第一个`k`元素

 因为每个节点都会被检查，所以这种方法总是正确的。 我们直接比较所有候选人并选择最接近的候选人。 

然而，它完全忽略了 BST 结构。 即使树是有序的，我们仍然扫描每个节点并执行排序。 

复杂度变为：

 - 遍历：`O(n)`- 排序：`O(n log n)`这比必要的要慢，尤其是当 BST 平衡时。 

### 最佳方法

 关键的见解是 BST 中序遍历产生按排序顺序的值。 

我们可以使用 BST 结构来有效地从目标值向外移动，而不是收集每个节点然后进行排序。 

最佳解决方案使用两个堆栈：

 - 小于目标值的前驱堆栈
 - 大于或等于目标值的后继堆栈

 这些堆栈模拟两个迭代器：

 - 通过排序的 BST 值向后移动
 - 通过排序的 BST 值向前移动

 在每一步中，我们都会比较：

 - 最接近的较小候选者
 - 最接近的较大候选者

 无论哪个更接近目标，都会添加到结果中。 

这与合并目标周围的两个排序流类似。 

由于每个堆栈操作都遵循 BST 路径，因此运行时变为：

 -`O(log n)`平衡 BST 的设置
 -`O(k log n)`在最坏的情况下提取结果

 这比遍历所有节点要好得多`k`很小。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 遍历整棵树并按距离排序 |
 | 最佳 | 平均 O(log n + k)，最差 O(n) | O(log n) 平均 | 对前驱堆栈和后继堆栈使用 BST 排序 |

 ## 算法演练

 ### 使用两个 BST 迭代器的最优算法

 1.初始化两个栈，`predecessors`和`successors`。 

前趋堆栈将存储值小于目标的节点。 后继堆栈将存储值大于或等于目标的节点。 
2. 从根开始遍历 BST 以初始化两个堆栈。 

穿越时：

 - 如果`node.val < target`，将节点推入`predecessors`并向右移动。 
- 否则，将节点推入`successors`并向左移动。 

这有效地将两个迭代器定位在目标周围。 
3. 定义一个辅助函数来获取下一个前驱。 

前驱迭代器的行为类似于反向中序遍历：

 - 弹出顶部节点
 - 移至其左孩子
 - 然后在推动节点的同时反复向右移动

 这给出了下一个较小的 BST 值。 
4. 定义另一个辅助函数来获取下一个后继函数。 

后继迭代器的行为类似于正常的中序遍历：

 - 弹出顶部节点
 - 移至其右子节点
 - 然后在推动节点的同时反复向左移动

 这给出了下一个更大的 BST 值。 
5. 重复`k`次。 

每一步：

 - 如果一个堆栈是空的，则使用另一堆栈。 
- 否则比较：

 -`abs(predecessor - target)`-`abs(successor - target)`选择更接近的值并推进该迭代器。 
6. 将选定的值附加到结果列表中。 
7.准确采集后返回结果`k`价值观。 

### 为什么它有效

 BST 中序遍历产生排序值。 前驱堆栈始终指向小于目标的下一个最大值，而后继堆栈始终指向大于或等于目标的下一个最小值。 

在每一步中，最接近目标的剩余值必须位于这两个堆栈之一的顶部。 通过始终选择更接近的顶部元素，我们贪婪地构造了正确的集合`k`按邻近顺序排序的最接近值。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def closestKValues(
        self,
        root: Optional['TreeNode'],
        target: float,
        k: int
    ) -> List[int]:

        predecessors = []
        successors = []

        def init_predecessors(node):
            while node:
                if node.val < target:
                    predecessors.append(node)
                    node = node.right
                else:
                    node = node.left

        def init_successors(node):
            while node:
                if node.val >= target:
                    successors.append(node)
                    node = node.left
                else:
                    node = node.right

        def get_predecessor():
            node = predecessors.pop()
            value = node.val

            node = node.left

            while node:
                predecessors.append(node)
                node = node.right

            return value

        def get_successor():
            node = successors.pop()
            value = node.val

            node = node.right

            while node:
                successors.append(node)
                node = node.left

            return value

        init_predecessors(root)
        init_successors(root)

        result = []

        for _ in range(k):

            if not predecessors:
                result.append(get_successor())

            elif not successors:
                result.append(get_predecessor())

            else:
                pred_diff = abs(predecessors[-1].val - target)
                succ_diff = abs(successors[-1].val - target)

                if pred_diff <= succ_diff:
                    result.append(get_predecessor())
                else:
                    result.append(get_successor())

        return result
```实现首先构建两个堆栈。 

前驱栈存储小于目标的候选节点。 在初始化期间，每当节点值小于目标时，算法就会将其推送并向右移动，因为较大的值可能仍低于目标。 

后继堆栈存储大于或等于目标的候选节点。 每当一个节点符合条件时，它就会被推送，并继续向左遍历以搜索更小的有效后继节点。 

这`get_predecessor()`helper 模拟逆序遍历。 删除当前前驱节点后，它会探索左子树并推送所有右后代。 这保证了下一个顶部元素是下一个较小的 BST 值。 

相似地，`get_successor()`模拟标准中序遍历。 删除当前后继节点后，它会探索右子树并推送所有左后代。 

主循环完全运行`k`次。 在每次迭代中，算法都会比较最接近的可用前驱值和后继值。 较接近的一个被附加到答案中，并且其迭代器前进。 

由于堆栈始终按排序顺序表示下一个可用候选者，因此算法在整个执行过程中保持正确。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

import "math"

func closestKValues(root *TreeNode, target float64, k int) []int {

    predecessors := []*TreeNode{}
    successors := []*TreeNode{}

    initPredecessors := func(node *TreeNode) {
        for node != nil {
            if float64(node.Val) < target {
                predecessors = append(predecessors, node)
                node = node.Right
            } else {
                node = node.Left
            }
        }
    }

    initSuccessors := func(node *TreeNode) {
        for node != nil {
            if float64(node.Val) >= target {
                successors = append(successors, node)
                node = node.Left
            } else {
                node = node.Right
            }
        }
    }

    var getPredecessor func() int
    getPredecessor = func() int {

        n := len(predecessors)
        node := predecessors[n-1]
        predecessors = predecessors[:n-1]

        value := node.Val
        node = node.Left

        for node != nil {
            predecessors = append(predecessors, node)
            node = node.Right
        }

        return value
    }

    var getSuccessor func() int
    getSuccessor = func() int {

        n := len(successors)
        node := successors[n-1]
        successors = successors[:n-1]

        value := node.Val
        node = node.Right

        for node != nil {
            successors = append(successors, node)
            node = node.Left
        }

        return value
    }

    initPredecessors(root)
    initSuccessors(root)

    result := []int{}

    for i := 0; i < k; i++ {

        if len(predecessors) == 0 {
            result = append(result, getSuccessor())

        } else if len(successors) == 0 {
            result = append(result, getPredecessor())

        } else {

            predDiff := math.Abs(float64(predecessors[len(predecessors)-1].Val) - target)
            succDiff := math.Abs(float64(successors[len(successors)-1].Val) - target)

            if predDiff <= succDiff {
                result = append(result, getPredecessor())
            } else {
                result = append(result, getSuccessor())
            }
        }
    }

    return result
}
```Go 实现遵循与 Python 解决方案相同的逻辑，但一些特定于语言的细节有所不同。 

Go 不像 Python 那样方便地支持具有自动闭包的嵌套命名函数，因此辅助函数被声明为函数变量。 

堆栈是使用切片来实现的。 追加用途`append()`，弹出操作使用切片截断删除最后一个元素。 

Go 还需要显式转换`int`到`float64`在距离计算之前。 

自然支持 Nil 树处理，因为当指针变为`nil`。

 ## 边缘情况

 ### 目标小于每个节点

 如果目标小于所有 BST 值，则前趋堆栈在初始化期间变空。 有错误的实现可能会尝试访问空堆栈的顶部。 

该解决方案在比较距离之前显式检查堆栈是否为空。 如果前任不可用，则仅从后继者获取值。 

### 目标大于每个节点

 这是对称的相反情况。 这里，后继堆栈变空，因为没有节点值大于或等于目标。 

该实现安全地退回到仅提取前辈，直到`k`值被收集。 

### 高度不平衡的 BST

 倾斜的 BST 的行为几乎就像一个链接列表。 递归解决方案可能会带来递归深度过大或失去预期对数性能的风险。 

此实现使用迭代堆栈遍历而不是递归，完全避免了递归深度问题。 尽管最坏情况的复杂性变成`O(n)`，正确性保持不变。 

### k 等于节点总数

 一些实现意外地提前停止或在一个迭代器变空后失败。 

该算法继续从仍然有剩余节点的迭代器中提取值，确保所有`n`值最终会正确返回。
