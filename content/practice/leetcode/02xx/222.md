[LeetCode 第 222 题](https://leetcode.com/problems/count-complete-tree-nodes/)

 **难度：** 🟢简单
 **主题：** 二分查找、位操作、树、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们计算一棵完全二叉树中存在多少个节点。 完全二叉树具有非常具体的结构。 除了最后一层之外，每一层都被完全填充，并且最后一层上的节点尽可能地显示在左侧。 

输入是二叉树的根节点。 每个节点都包含一个值以及指向其左子节点和右子节点的指针。 输出应该是表示树中节点总数的单个整数。 

一个简单的解决方案就是简单地遍历每个节点并对它们进行计数。 虽然这工作正常，但该问题明确要求算法比`O(n)`。 这个要求很重要，因为它表明可以利用完整的树属性来避免单独访问每个节点。 

约束允许最多`5 * 10^4`节点，虽然不是很大，但仍然足够大，足以让面试官期望得到一个优化的解决方案。 由于保证树是完整的，因此我们可以利用任意二叉树中不可用的结构属性。 

有几个重要的边缘情况需要考虑：

 - 树可能是空的，这意味着`root = None`。 在这种情况下，答案是`0`。 
- 一棵树可能只包含一个节点。 该算法必须正确识别这个最小的非空情况。 
- 最后一层可能已部分填充。 这是大多数错误发生的地方，因为树不一定是完美的。 
- 完整树内的某些子树本身可能是完美二叉树。 有效地检测这一点是关键的优化。 

## 方法

 ### 蛮力方法

 最简单的解决方案是遍历整棵树并手动统计每个节点。 这可以使用深度优先搜索或广度优先搜索来完成。 

例如，使用 DFS：

 - 将当前节点计为`1`- 递归计算左子树中的节点
 - 递归计算右子树中的节点
 - 返回总数

 这是有效的，因为每个节点都被访问过一次，所以最终的计数是准确的。 

然而，这种方法需要访问所有`n`节点，时间复杂度为`O(n)`。 该问题特别要求比线性时间更快的解决方案，因此虽然暴力解决方案是正确的，但它不满足优化要求。 

### 最佳方法

 关键的见解来自完全二叉树的属性。 

在完美二叉树中：

 - 每个级别都已完全填满
 - 节点数量为：$2^h-1$在哪里`h`是树的高度。 

对于完全二叉树中的任意子树，我们可以通过比较来判断它是否完美：

 - 连续向左移动得到的高度
 - 连续向右移动得到的高度

 如果两个高度相等，则子树是完美的，因此我们可以使用上面的公式立即计算其节点数，而不是遍历每个节点。 

如果高度不同，则子树并不完美，因此我们递归地计算左右子树中的节点。 

这大大减少了我们需要检查的节点数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 |`O(n)`|`O(h)`| 遍历每个节点 |
 | 最佳|`O(log^2 n)`|`O(log n)`| 使用完整的树结构和子树高度检查 |

 ## 算法演练

 1. 从树的根节点开始。 如果根是`None`， 返回`0`立即因为树是空的。 
2. 重复跟踪左孩子，直到到达，计算左高度`None`。 计算经过了多少层。 
3. 重复跟随右孩子直到到达，计算出正确的高度`None`。 
4. 比较两个高度：

 - 如果高度相等，则子树是完美的。 
- 有高度的完美二叉树`h`包含：$2^h-1$节点，所以直接返回这个值。 

1. 如果高度不同，则子树并不完美。 在这种情况下：

 - 递归计算左子树中的节点
 - 递归计算右子树中的节点
 - 添加`1`对于当前根节点
 2. 继续递归，直到处理完所有必要的子树。 

### 为什么它有效

 该算法依赖于完全二叉树的基本属性。 如果最左边的路径高度等于最右边的路径高度，则子树一定是完美的。 完美二叉树具有已知的封闭形式节点数，使我们能够避免遍历其中的所有节点。 

如果高度不同，则至少有一颗子树是不完整的，因此需要递归。 因为每次递归调用都会减少树的高度，并且每次高度计算都需要`O(log n)`，总运行时间变为`O(log^2 n)`。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def countNodes(self, root: Optional[TreeNode]) -> int:
        
        def left_height(node: Optional[TreeNode]) -> int:
            height = 0
            
            while node:
                height += 1
                node = node.left
            
            return height
        
        def right_height(node: Optional[TreeNode]) -> int:
            height = 0
            
            while node:
                height += 1
                node = node.right
            
            return height
        
        if not root:
            return 0
        
        left_h = left_height(root)
        right_h = right_height(root)
        
        if left_h == right_h:
            return (1 << left_h) - 1
        
        return (
            1
            + self.countNodes(root.left)
            + self.countNodes(root.right)
        )
```实现首先定义两个辅助函数：

 -`left_height()`通过连续遍历左子节点来计算高度。 
-`right_height()`通过不断遍历右子节点来计算高度。 

这些辅助函数用于确定当前子树是否完美。 

如果高度匹配，则子树是完美的，因此直接使用位操作计算节点数：```python
(1 << height) - 1
```该表达式计算：$2^h-1$高效。 

如果高度不同，则子树不完整。 该算法递归地计算左右子树中的节点并相加`1`对于当前节点。 

由于完整树包含许多完美子树，因此该算法避免显式遍历树的大部分。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func countNodes(root *TreeNode) int {
    
    var leftHeight func(*TreeNode) int
    leftHeight = func(node *TreeNode) int {
        height := 0
        
        for node != nil {
            height++
            node = node.Left
        }
        
        return height
    }
    
    var rightHeight func(*TreeNode) int
    rightHeight = func(node *TreeNode) int {
        height := 0
        
        for node != nil {
            height++
            node = node.Right
        }
        
        return height
    }
    
    if root == nil {
        return 0
    }
    
    leftH := leftHeight(root)
    rightH := rightHeight(root)
    
    if leftH == rightH {
        return (1 << leftH) - 1
    }
    
    return 1 + countNodes(root.Left) + countNodes(root.Right)
}
```Go 实现遵循与 Python 版本相同的逻辑。 

主要区别在于辅助函数的声明方式。 Go 使用带有闭包的函数变量，因为不直接支持嵌套命名函数。 

该算法使用`nil`检查而不是Python的`None`。 

Go 中也使用移位来计算：$2^h-1$高效。 

由于最大节点数仅为`5 * 10^4`, Go 的标准不关心整数溢出`int`类型。

 ## 边缘情况

 ### 空树

 一棵空树表示为`root = None`。 在编写递归逻辑时，这种情况很容易被忽视，因为尝试访问子指针`None`会导致运行时错误。 

实现立即处理这个问题：```
if not root:
    return 0
```这保证了空输入的安全执行。 

### 单节点树

 仅包含一个节点的树是最小的非空有效输入。 在这种情况下，左高度和右高度都是`1`，这意味着子树是完美的。 

该算法正确计算：$2^1-1=1$没有任何递归调用。 

### 不完整的最终关卡

 最重要的边缘情况是最终关卡仅部分填充时。 这是完全二叉树的定义特征。 

例如：```
    1
   / \
  2   3
 / \
4   5
```根子树并不完美，因为左右高度不同。 有缺陷的实现可能会错误地认为完整性意味着完美。 

此实现通过在决定是否应用完美树公式之前显式比较每个子树的最左边和最右边的高度来避免该错误。 

### 深度完美子树

 完整的树通常包含嵌套在不完整的整体树中的大型完美子树。 有效处理这些情况是优化算法发挥作用的原因。 

例如，即使整棵树不完美，左子树仍然可能是完美的。 该算法立即检测到这一点，并在高度计算后在恒定时间内计算其节点数，避免不必要地遍历所有后代节点。
