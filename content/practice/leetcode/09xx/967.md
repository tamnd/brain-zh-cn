[LeetCode 967 题](https://leetcode.com/problems/numbers-with-same-consecutive-differences/)

 **难度：** 🟡 中等
 **主题：** 回溯、广度优先搜索

 ## 解决方案

 ## 问题理解

 该问题要求我们生成所有长度的整数`n`使得每两个连续数字之间的绝对差恰好是`k`。 输入由两个整数组成：`n`，整数必须具有的位数，以及`k`，连续数字之间的差异约束。 输出是满足这些条件的整数数组，不允许有前导零。 

约束条件澄清了`n`介于 2 和 9 之间，并且`k`介于 0 和 9 之间。这意味着数字不会超过九位数字，并且数字之间的差始终是个位数的非负数。 当出现以下情况时，会出现关键的边缘情况：`k = 0`，这要求数字中的所有数字都相同，并且当`n = 2`，这是仍然允许差异存在的最小长度。 另一个考虑因素是避免以零开头的数字，因为前导零无效。 

本质上，我们被要求探索满足严格连续差异规则的数字组合，类似于在图中遍历路径，其中每个节点代表一个数字，边连接不同的数字`k`。 

## 方法

 暴力方法将生成所有`n`- 位数字，然后根据连续差异条件进行过滤。 这是可行的，因为我们可以一一检查每个数字，但效率很低。 为了`n = 9`，有潜在的`9 * 10^8`数字（所有 9 位数字），单独检查的计算成本很高。 

最佳方法依赖于回溯或广度优先搜索策略。 我们逐位构造数字。 从数字 1 到 9（以避免前导零）开始，如果保持连续差异，我们递归或迭代地添加下一个数字`k`。 该方法完全避免了生成无效数字，而不是在生成后进行过滤，从而显着减少了搜索空间。

 ## 算法演练

 1. 初始化一个列表来存储有效数字。 首先考虑从 1 到 9 的所有个位数。 
2. 对于每个数字，考虑最后一位数字并尝试附加一个新数字，使得与最后一位数字的绝对差恰好是`k`。 
3. 如果新的数字在0-9之间，则将其附加到当前数字上，并递归地继续该过程，直到数字达到长度`n`。 
4. 一旦数字达到长度`n`，将其添加到结果列表中。 
5. 对从 1 到 9 的所有起始数字重复此过程。 

工作原理：通过一次构建一位数字并在每一步强制执行差异条件，我们确保所有生成的数字满足连续差异要求。 由于我们从非零数字开始并且仅附加有效数字，因此没有数字会有前导零，并且所有数字都将具有精确的长度`n`。 

## Python 解决方案```python
from typing import List

class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        if n == 1:
            return [i for i in range(10)]
        
        result = []

        def dfs(num: int, length: int):
            if length == n:
                result.append(num)
                return
            last_digit = num % 10
            next_digits = set([last_digit + k, last_digit - k])
            for next_digit in next_digits:
                if 0 <= next_digit <= 9:
                    dfs(num * 10 + next_digit, length + 1)
        
        for starting_digit in range(1, 10):
            dfs(starting_digit, 1)
        
        return result
```Python 解决方案使用深度优先搜索策略。 我们定义一个递归函数`dfs`将有效数字附加到当前数字。 通过使用下一个数字的集合，我们可以自动处理以下情况：`k = 0`没有重复。 我们迭代所有起始数字以避免前导零。 每次递归调用都会构建数字，直到达到所需的长度`n`已达到。 

## 解决方案```go
func numsSameConsecDiff(n int, k int) []int {
    if n == 1 {
        result := make([]int, 10)
        for i := 0; i < 10; i++ {
            result[i] = i
        }
        return result
    }

    var result []int

    var dfs func(num int, length int)
    dfs = func(num int, length int) {
        if length == n {
            result = append(result, num)
            return
        }
        lastDigit := num % 10
        nextDigits := []int{lastDigit + k, lastDigit - k}
        for _, next := range nextDigits {
            if next >= 0 && next <= 9 {
                dfs(num*10 + next, length+1)
            }
        }
    }

    for start := 1; start <= 9; start++ {
        dfs(start, 1)
    }

    return result
}
```Go 解决方案与 Python 版本非常相似。 我们对递归 DFS 函数使用闭包。 切片操作处理附加有效数字。 由于 Go 没有内置集合，因此我们隐式处理重复项，因为递归可以避免两次添加相同的数字。 

## 工作示例

 ### 示例 1：`n = 3, k = 7`我们从数字 1-9 开始。 考虑`1`：

 1. 最后一位数字是`1`。 下一个可能的数字：`1+7=8`,`1-7=-6`（无效）
 2. 追加`8`→ 数字是`18`。 最后一位数字`8`: 下一个数字`1`和`15`（仅有的`1`有效）
 3. 追加`1`→ 数字是`181`，长度达到3→添加到结果中

 重复起始数字 2-9 得到`[181, 292, 707, 818, 929]`。 

### 示例 2：`n = 2, k = 1`起始数字 1-9：

 - 开始于`1`: 下一个数字`0`和`2`→ 数字`10`,`12`- 开始于`2`: 下一个数字`1`和`3`→ 数字`21`,`23`- 继续此过程生成`[10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]`## 复杂度分析

 ## 边缘情况

 第一个边缘情况是当`k = 0`。 在这里，下一个数字必须等于最后一个数字，从而产生具有重复数字的数字。 正确处理这一点可以避免重复并确保正确性。 我们的 DFS 方法自然会使用一组可能的下一个数字来处理这个问题。 

第二种边缘情况发生在`n = 1`。 由于长度为 1，数字可以包含零，这通常作为较长数字中的前导数字无效。 我们的实现会单独检查这一点并返回所有数字 0-9。
