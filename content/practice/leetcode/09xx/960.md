 ## 问题理解

 这个问题要求我们找到从一组等长字符串中删除的最小列数，以便每个单独的字符串都按字典顺序排序。 换句话说，我们可以删除所有字符串中的一些位置（列），目标是确保每个字符串独立地从左到右按非递减字母顺序排列。 

输入由一个数组组成`strs`和`n`字符串，每个长度`m`。 输出是一个整数，表示实现目标所需的最小列删除数。 约束表明两者`n`和`m`可以达到 100，这表明 O(n * m²) 算法是可以接受的，但 O(2^m) 暴力破解是不可行的。 

重要的边缘情况包括已排序的字符串（需要零删除）、相反顺序的字符串（需要删除除一列之外的所有字符串）以及删除一列可以对多个字符串进行排序的情况。 

## 方法

 暴力方法将尝试列删除的所有可能组合，并检查结果字符串是否已排序。 为了`m`列，有`2^m`可能的删除集，对于每个集，我们将检查所有`n`长度可达的字符串`m`。 这显然是不可行的`m`最多 100 因为`2^100`是一个天文数字。 

更好解决方案的关键观察是将问题视为最长递增子序列 (LIS) 问题的变体，但在列中。 我们考虑的不是要删除哪些列，而是要保留哪些列。 我们可以迭代列并跟踪使所有行按字典顺序排序的最长列序列的长度。 对于每一列`j`，我们检查所有之前的列`i < j`。 如果对于每个字符串`strs[k]`,`strs[k][i] <= strs[k][j]`，然后列`j`可以关注专栏`i`按递增顺序。 这产生了动态规划解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m * n * m) | O(2^m * n * m) | O(米) | 检查列的所有子集，对于 m = 100 不可​​行 |
 | 最佳 | O(m² * n) | O(米) | 对列使用动态规划来查找要保留的列的 LIS |

 ## 算法演练

 1.初始化一个DP数组`dp`长度`m`（列数），其中`dp[j]`表示以column结尾的最长列序列的长度`j`使所有字符串保持排序。 
2. 设置所有条目`dp`为 1，因为始终可以单独保留每一列。 
3. 迭代列`j`从左到右。 
4. 对于每个`j`，迭代所有先前的列`i < j`。 
5. 对于每对`(i, j)`，检查是否对于每个字符串`k`,`strs[k][i] <= strs[k][j]`。 如果属实，则更新`dp[j] = max(dp[j], dp[i] + 1)`。 
6. 填充DP数组后，要保留的最长列序列的长度为`max(dp)`。 
7. 所需的最少删除是`m - max(dp)`。 

工作原理：DP 数组保证对于由 表示的任何列序列`dp[j]`，所有行中的字符序列都是非递减的。 通过最大化保留的列，我们最小化删除的列。 

## Python 解决方案```python
from typing import List

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        n = len(strs)
        m = len(strs[0])
        dp = [1] * m  # Each column can be a sequence by itself
        
        for j in range(m):
            for i in range(j):
                if all(strs[k][i] <= strs[k][j] for k in range(n)):
                    dp[j] = max(dp[j], dp[i] + 1)
        
        return m - max(dp)
```该代码初始化一个 DP 数组，其中每个条目代表以该列结束的最长排序序列。 它迭代每对列并检查是否保留列`j`后`i`保持按行排序。 最终答案是不属于最长序列的列数。 

## 解决方案```go
func minDeletionSize(strs []string) int {
    n := len(strs)
    m := len(strs[0])
    dp := make([]int, m)
    for j := range dp {
        dp[j] = 1
    }
    
    for j := 0; j < m; j++ {
        for i := 0; i < j; i++ {
            valid := true
            for k := 0; k < n; k++ {
                if strs[k][i] > strs[k][j] {
                    valid = false
                    break
                }
            }
            if valid {
                if dp[i]+1 > dp[j] {
                    dp[j] = dp[i] + 1
                }
            }
        }
    }
    
    maxLen := 0
    for _, val := range dp {
        if val > maxLen {
            maxLen = val
        }
    }
    
    return m - maxLen
}
```Go 实现反映了 Python 逻辑。 主要区别是显式切片初始化、显式变量`valid`，以及用于计算最大值的基于范围的循环。

 ## 边缘情况

 一个重要的边缘情况是严格降序的多个列的单个字符串。 如果不仔细检查，简单的解决方案可能无法删除足够的列。 我们的 DP 正确识别出只能保留一列。 

另一种边缘情况是所有行都相同。 在这里，无论行数或列长如何，都不需要删除。 DP 方法可以自然地处理这个问题，因为所有比较都会通过。
