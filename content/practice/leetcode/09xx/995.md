 ## 解决方案

 ## 问题理解

 问题给了我们一个二进制数组`nums`由 0 和 1 以及一个整数组成`k`。 任务是转换数组，使所有元素都`1`使用称为**k 位翻转**的最少操作数。 每个 k 位翻转都包含选取一个长度为连续的子数组`k`并反转该子数组中的每一位`0`到`1`和`1`到`0`。 

输入`nums`最多可以有`10^5`元素，以及`k`可以小至`1`或大至`nums.length`。 输出是所需的最小翻转次数，或者`-1`如果不可能完成所有位`1`。 

重要的边缘情况包括已经全部存在的数组`1`s，具有以下序列的数组`0`s 短于`k`（不能独立翻转），以及多个翻转以影响后续翻转的方式重叠的数组。 例如，翻转重叠子数组可能需要仔细记账以避免重复计算翻转的效果。 

## 方法

 蛮力方法很简单。 从数组的开头开始，每当`0`遇到了，翻下一个`k`位。 重复直到数组末尾。 这保证了正确性，因为每个`0`尽早被翻转。 这种方法的问题在于，每次操作实际上翻转数组中的位会产生成本`O(k)`，并且对于`n`元素，这可能会导致`O(n * k)`时间复杂度，对于`n`最多`10^5`。 

最佳方法的关键见解是我们**不需要实际物理地翻转位**。 我们只需要跟踪影响每个位置的翻转的奇偶性，即影响当前索引的翻转次数是奇数还是偶数。 这可以使用带有单个计数器或**队列**的**滑动窗口**技术来有效地实现，以记录翻转开始的索引。 这使我们能够确定某个位是否有效`0`或者`1`在恒定的时间内，仅在必要时翻转，从而将复杂性降低到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * k) | O(1) | O(1) | 每当遇到 0 时，物理翻转每个子数组 |
 | 最佳| O(n) | O(n) 或 O(1) | 使用滑动窗口/翻转奇偶校验来有效地跟踪翻转，而无需修改数组 |

 ## 算法演练

 1.初始化一个计数器`flip_count`为零。 这将跟踪到目前为止执行的翻转次数。 初始化一个变量`current_flips`为零，代表有多少次翻转影响当前索引。 
2. 创建数组或队列`is_flipped`尺寸的`n`初始化为零。 它将指示翻转是否从给定索引开始。 
3. 迭代每个索引`i`在`nums`。 
4. 如果`i >= k`, 减去`is_flipped[i - k]`从`current_flips`因为翻转的效果开始了`k`之前的步骤不再影响当前位置。 
5. 确定有效值`nums[i]`考虑后`current_flips`。 如果`current_flips % 2 == 1`，该位被反转。 
6. 如果有效值为`0`，我们必须翻转下一个`k`位。 如果少于`k`剩余元素，返回`-1`。 
7. 马克`is_flipped[i] = 1`, 增量`current_flips`和`flip_count`。 
8. 继续直到数组末尾。 
9. 返回`flip_count`。 

**为什么有效：** 该算法保证每个`0`在其最早可能的位置翻转。 通过仅跟踪影响每个索引的翻转的奇偶性，可以正确地考虑重叠翻转。 滑动窗口确保翻转效果在`k`位置，保持正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def minKBitFlips(self, nums: List[int], k: int) -> int:
        n = len(nums)
        flip_count = 0
        current_flips = 0
        is_flipped = [0] * n
        
        for i in range(n):
            if i >= k:
                current_flips ^= is_flipped[i - k]
            
            if nums[i] ^ current_flips == 0:
                if i + k > n:
                    return -1
                is_flipped[i] = 1
                current_flips ^= 1
                flip_count += 1
        
        return flip_count
```该代码使用单次遍历数组，同时保持`current_flips`变量，它跟踪当前索引是否已有效翻转奇数次。`is_flipped`标记翻转开始的位置，当滑动窗口向前移动时，我们对进出翻转进行异或。 这避免了对阵列进行物理修改并实现最佳性能。 

## 解决方案```go
func minKBitFlips(nums []int, k int) int {
    n := len(nums)
    flipCount := 0
    currentFlips := 0
    isFlipped := make([]int, n)

    for i := 0; i < n; i++ {
        if i >= k {
            currentFlips ^= isFlipped[i-k]
        }
        if nums[i]^currentFlips == 0 {
            if i+k > n {
                return -1
            }
            isFlipped[i] = 1
            currentFlips ^= 1
            flipCount++
        }
    }

    return flipCount
}
```Go 版本密切反映了 Python 解决方案。 切片初始化和整数异或运算的使用方式相同。 带有切片边界的边缘情况会被显式检查，就像在 Python 中一样。
