 **难度：** 🟡 中等
 **主题：** 数组、数学、分而治之、几何、排序、堆（优先级队列）、快速选择

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到`k`最接近原点的点`(0,0)`来自二维点列表。 每个点都作为一对给出`[x, y]`，距离使用欧几里德公式定义，`sqrt(x^2 + y^2)`。 输入由点列表和整数组成`k`，输出应该是一个列表`k`距原点距离最小的点。 输出中点的顺序并不重要。 

约束告诉我们，点的数量最多可达 10,000 个，坐标本身的范围可以从 -10,000 到 10,000。 这意味着任何时间复杂度低于 O(n log n) 的算法对于大输入都可能效率低下。 我们也知道该问题保证了除了顺序之外的唯一性，因此我们不必担心重复距离冲突的正确性。 重要的边缘情况包括`k = 1`或者`k = n`、负坐标以及正好位于轴上的点。 

## 方法

 强力方法是计算每个点的欧几里德距离，将这些距离与点坐标一起存储，按距离对所有点进行排序，然后返回第一个`k`点。 这种方法之所以有效，是因为排序保证了最接近的点出现在开头。 然而，排序需要 O(n log n) 时间，这可能比大数据所需的时间慢。`n`什么时候`k`远小于`n`。 

更优化的方法使用最大堆（优先级队列）来维护`k`到目前为止看到的最近点。 当我们迭代这些点时，我们将负距离压入堆中（因为Python堆默认是最小堆），如果堆超过大小，则弹出最远的点`k`。 这种方法很有效，因为堆操作每次插入只花费 O(log k) 时间，导致总时间复杂度为 O(n log k)，当`k << n`。 另一种最佳方法是使用Quickselect，它根据距离对点进行划分，并在预期的O(n)时间内找到第k个最小的距离，但堆方法实现起来更简单，实用性也很高。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 计算距离，对所有点进行排序，取前 k |
 | 最大堆 ​​| O(n log k) | O(n log k) | O(k) | 维护一个大小为 k 的堆来跟踪最近的点 |
 | 快速选择| O(n) 平均 | O(1) 额外 | 围绕第 k 个距离划分点，更复杂 |

 ## 算法演练

 1. 初始化一个空的最大堆。 这个堆最多可以存储`k`基于距原点的负平方距离的点。 使用平方距离可以避免不必要的平方根计算。 
2. 迭代每个点`[x, y]`在输入列表中。 对于每个点，计算距离的平方`d = x*x + y*y`。 
3. 推送元组`(d, point)`到堆中。 堆性质保证了点中距离最大的点`k`到目前为止看到的最近的总是在顶部。 
4.如果堆的大小超过`k`，弹出顶部元素。 这确保堆只保留`k`最近的点。 
5. 处理完所有点后，堆中正好包含`k`最接近原点的点。 提取这些点并返回它们。 

**为什么它有效：** 最大堆确保在任何时刻，我们都保持最接近的`k`到目前为止遇到的点。 任何比堆中当前最远点更远的点都会被自动丢弃。 迭代结束时，堆包含`k`距离最小的点。 平方距离保留了顺序，因此结果是正确的，无需计算平方根。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        max_heap = []
        
        for x, y in points:
            dist = -(x * x + y * y)  # Use negative for max-heap
            heapq.heappush(max_heap, (dist, [x, y]))
            if len(max_heap) > k:
                heapq.heappop(max_heap)
        
        return [point for (_, point) in max_heap]
```在此 Python 解决方案中，我们迭代每个点，计算平方距离，并维护大小为的最大堆`k`。 通过推动负距离，Python 的最小堆的行为类似于最大堆。 循环结束后，我们从堆中提取点，这保证了它们是`k`最近的点。 

## 解决方案```go
package main

import (
    "container/heap"
    "math"
)

type PointHeap [][2]int

func (h PointHeap) Len() int { return len(h) }
func (h PointHeap) Less(i, j int) bool {
    return dist(h[i]) > dist(h[j]) // max-heap by distance
}
func (h PointHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }

func (h *PointHeap) Push(x any) {
    *h = append(*h, x.([2]int))
}
func (h *PointHeap) Pop() any {
    n := len(*h)
    x := (*h)[n-1]
    *h = (*h)[:n-1]
    return x
}

func dist(p [2]int) int {
    return p[0]*p[0] + p[1]*p[1]
}

func kClosest(points [][]int, k int) [][]int {
    h := &PointHeap{}
    heap.Init(h)
    
    for _, p := range points {
        pt := [2]int{p[0], p[1]}
        heap.Push(h, pt)
        if h.Len() > k {
            heap.Pop(h)
        }
    }
    
    result := make([][]int, 0, k)
    for h.Len() > 0 {
        p := heap.Pop(h).([2]int)
        result = append(result, []int{p[0], p[1]})
    }
    return result
}
```在Go中，我们定义了自定义堆类型`PointHeap`并实现所需的方法来维持最大堆距离。 不需要负距离，因为我们可以定义`Less`反转比较。 其余的遵循与Python相同的逻辑。
