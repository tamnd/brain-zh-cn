 **难度：** 🔴难
 **主题：** 数组、哈希表、深度优先搜索、广度优先搜索、并查找、图论

 ## 解决方案

 ## 问题理解

 问题是关于使用邻接矩阵表示为无向图的计算机网络。 每个节点代表一台计算机，两个节点之间的边表示直接连接。 一些节点最初感染了恶意软件，并且感染沿着网络传播：如果一个节点被感染，则与其直接连接的所有节点也将被感染，如此循环下去，直到没有更多的节点可以被感染。 

任务是从最初感染的列表中删除一个节点，以**最小化最终感染节点的数量**。 如果有多个节点达到相同的最小感染，我们必须返回索引最小的节点。 

输入由邻接矩阵组成`graph`（尺寸`n x n`,`n ≤ 300`）和一个列表`initial`受感染的节点。 邻接矩阵是对称的 (`graph[i][j] == graph[j][i]`）并且每个节点都与其自身相连（`graph[i][i] == 1`）。 这`initial`列表包含代表最初感染节点的唯一索引。 

主要观察结果包括恶意软件传播到至少包含一个受感染节点的连接组件中的所有节点这一事实。 删除节点可以防止感染在该节点是**唯一受感染节点**的组件中传播，但如果一个组件包含多个受感染节点，则删除单个节点并不能阻止该组件中的感染。 

重要的边缘情况包括所有受感染节点属于同一连接组件的网络，其中多个节点可以同等地减少感染，或者一些受感染节点被隔离。 

## 方法

 暴力方法将模拟每个节点的感染过程`initial`已删除。 对于每个候选删除，我们将从剩余的受感染节点开始将节点标记为受感染，为每个候选执行 BFS 或 DFS。 将返回导致最小最终感染的节点删除。 虽然正确，但这种方法太慢，因为对于每个节点删除，我们可能会遍历整个图，从而导致时间复杂度`O(n^3)`在最坏的情况下`n ≤ 300`。 

最佳解决方案的关键见解是，可以根据**逐个组件**推断出受感染节点的最终数量。 我们可以首先识别图中所有连接的组件。 对于每个组件，如果它恰好包含**一个最初被感染的节点**，则删除该节点可以防止整个组件被感染。 如果它包含多个最初被感染的节点，则该组件无论如何都会被感染。 这种见解使我们能够避免模拟每个候选删除的感染，而是直接使用组件大小和最初感染节点的数量来计算效果。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 使用 DFS/BFS 模拟每个节点删除的感染 |
 | 最佳| O(n^2) | O(n^2) | O(n) | 识别连接的组件并跟踪每个组件的感染贡献 |

 ## 算法演练

 1. 排序`initial`列表以满足平局要求（最小的索引节点是首选）。 
2. 计算图的所有连通分量。 这可以从未访问的节点开始使用 DFS 或 BFS 来完成。 对于每个节点，存储它属于哪个组件以及每个组件的大小。 
3. 计算每个组件存在多少个最初受感染的节点。 
4. 对于每个最初感染的节点，检查其组件的大小。 如果其组件恰好包含一个受感染节点（其本身），则通过删除该节点对减少感染的贡献是该组件的大小。 
5. 跟踪最大限度减少受感染节点的节点。 如果多个节点产生相同的归约，则排序中较早的节点`initial`被选中。 
6. 返回步骤 5 中标识的节点。 

**为什么有效**：不变的是，任何具有多个最初感染节点的组件都将始终被完全感染，无论删除哪个单个节点。 通过删除该节点，可以完全保存只有一个受感染节点的组件。 因此，该算法正确地识别了删除减少最多感染的节点。 

## Python 解决方案```python
from typing import List

class Solution:
    def minMalwareSpread(self, graph: List[List[int]], initial: List[int]) -> int:
        n = len(graph)
        
        # Step 1: Sort initial for tie-breaking
        initial.sort()
        
        # Step 2: Find connected components
        visited = [False] * n
        component_id = [-1] * n
        component_size = []
        
        def dfs(node: int, cid: int) -> int:
            visited[node] = True
            component_id[node] = cid
            size = 1
            for nei, connected in enumerate(graph[node]):
                if connected and not visited[nei]:
                    size += dfs(nei, cid)
            return size
        
        cid = 0
        for node in range(n):
            if not visited[node]:
                size = dfs(node, cid)
                component_size.append(size)
                cid += 1
        
        # Step 3: Count initially infected nodes per component
        infected_count = [0] * cid
        for node in initial:
            infected_count[component_id[node]] += 1
        
        # Step 4: Find the best node to remove
        result = initial[0]
        max_saved = -1
        for node in initial:
            c = component_id[node]
            if infected_count[c] == 1:
                if component_size[c] > max_saved:
                    max_saved = component_size[c]
                    result = node
        
        return result
```**说明**：

 我们首先排序`initial`用于打破平局。 We compute connected components using DFS, tracking the size and component ID for each node. Then, we count how many initially infected nodes are in each component. Only nodes that are the **sole infected node in a component** can reduce the infection. We select the node that saves the largest component.

 ## 解决方案```go
func minMalwareSpread(graph [][]int, initial []int) int {
    n := len(graph)
    
    // Step 1: Sort initial for tie-breaking
    sort.Ints(initial)
    
    // Step 2: Find connected components
    visited := make([]bool, n)
    componentID := make([]int, n)
    componentSize := []int{}
    
    var dfs func(node, cid int) int
    dfs = func(node, cid int) int {
        visited[node] = true
        componentID[node] = cid
        size := 1
        for nei, connected := range graph[node] {
            if connected == 1 && !visited[nei] {
                size += dfs(nei, cid)
            }
        }
        return size
    }
    
    cid := 0
    for i := 0; i < n; i++ {
        if !visited[i] {
            size := dfs(i, cid)
            componentSize = append(componentSize, size)
            cid++
        }
    }
    
    // Step 3: Count initially infected nodes per component
    infectedCount := make([]int, cid)
    for _, node := range initial {
        infectedCount[componentID[node]]++
    }
    
    // Step 4: Find the best node to remove
    result := initial[0]
    maxSaved := -1
    for _, node := range initial {
        c := componentID[node]
        if infectedCount[c] == 1 && componentSize[c] > maxSaved {
            maxSaved = componentSize[c]
            result = node
        }
    }
    
    return result
}
```**说明**：Go 实现与 Python 非常相似。 我们使用切片来进行访问跟踪、组件大小和 ID。 DFS 被实现为闭包，以允许在访问外部变量时进行递归。 排序`initial`slice 确保通过最小索引打破平局。 

## 工作示例

 **示例1**

 输入：`graph = [[1,1,0],[1,1,0],[0,0,1]], initial = [0,1]`1. 连接组件：

 - 组件 0：节点 {0,1}，大小 2
 - 组件 1：节点 {2}，大小 1
 2. 每个组件的初始感染计数：{2, 0}（同一组件中的节点 0 和 1）
 3. 没有一个组件恰好有一个受感染节点，因此删除其中最小的索引`initial`→ 0

 输出：0

 **示例2**

 输入：`graph = [[1,1,0],[1,1,1],[0,1,1]], initial = [0,1]`1.连通分量：节点{0,1,2}，大小3
 2. 感染数 = 2 → 无法保存任何节点
 3. 删除最小索引 → 1

 输出：1

 **示例3**

 输入：`graph = [[1,1,0,0],[1,1,1,0],[0,1,1,1],[0,0,1,1]], initial = [0,1]`1.连通分量：节点{0,1,2,3}，大小4
 2. 感染数 = 2 → 无法保存任何节点
 3. 删除最小索引 → 1

 输出：1
