 ## 解决方案

 ## 问题理解

 这道题要求我们取一个整数数组`nums`并执行一系列增量操作，使数组中的每个元素都变得唯一。 增量操作将元素精确地增加 1。目标是计算所需的此类移动的最小数量。 

简而言之，我们被问到：给定一个可能存在重复项的数组，我们如何以最少的总增量调整重复项，以便没有两个元素是相同的？ 输出是一个表示最小移动次数的整数。 

输入数组最多可包含 100,000 个元素，值范围为 0 到 100,000。 这意味着重复搜索下一个可用数字的强力解决方案可能太慢。 重要的边缘情况包括已经唯一的数组、具有所有相同元素的数组、包含零的数组或具有接近 100,000 的非常大的数字的数组。 该问题保证存在适合 32 位整数的解决方案。 

## 方法

 **暴力方法**简单但效率低下。 对于数组中的每个元素，我们可以检查它是否已经出现在数组或集合中。 如果有，我们将其加一并重复此检查，直到找到唯一的数字。 我们累积所有增量。 这种方法是正确的，因为它在每一步都强制执行唯一性，但对于大型数组来说太慢了，因为在最坏的情况下我们可以执行`O(n^2)`运营。 

**最佳方法**依赖于首先对数组进行排序。 一旦数组排序完毕，重复项就会相邻。 然后，我们可以迭代排序后的数组，并确保每个元素至少比前一个元素大 1。 如果不是，我们计算所需的增量数并调整当前元素。 这是可行的，因为排序确保所有重复项都是连续的，因此我们只需要考虑前一个元素即可保持唯一性。 这种方法速度更快，并且将问题简化为排序后的线性遍历。

 | 蛮力 | O(n^2) | O(n^2) | O(n) | 使用集合递增元素直到唯一； 对于大型数组效率低下 |

 ## 算法演练

 1. 对数组进行排序`nums`。 排序可确保重复项连续出现，从而轻松有效地处理冲突。 
2. 初始化变量`moves`到`0`跟踪增量总数。 
3. 从第二个元素开始迭代已排序的数组。 对于每个元素，检查它是否小于或等于前一个元素。 
4.如果当前元素小于等于前一个元素，则计算差值`prev + 1 - current`以确定需要多少增量才能使其唯一。 
5. 添加所需的增量`moves`。 
6. 将当前元素更新为`prev + 1`，确保它现在严格大于前一个元素。 
7. 继续，直到处理完所有元素。 
8. 返回总计`moves`。 

为什么有效：通过排序，重复项是连续的。 通过确保每个元素至少比其前一个元素大一，我们保证所有元素都是唯一的且增量最小。 就地调整和计数增量可确保最佳移动，而无需进行不必要的操作。 

## Python 解决方案```python
from typing import List

class Solution:
    def minIncrementForUnique(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        nums.sort()
        moves = 0
        
        for i in range(1, len(nums)):
            if nums[i] <= nums[i - 1]:
                increment = nums[i - 1] + 1 - nums[i]
                moves += increment
                nums[i] = nums[i - 1] + 1
        
        return moves
```这个 Python 实现首先对数组进行排序。 然后它迭代每个元素，检查它是否小于或等于前一个元素。 如果是这样，它会计算所需增量的确切数量，更新移动计数器，并将当前元素调整为唯一。 使用`nums[i - 1] + 1`确保最小的调整，同时保持独特性。 

## 解决方案```go
import "sort"

func minIncrementForUnique(nums []int) int {
    if len(nums) == 0 {
        return 0
    }

    sort.Ints(nums)
    moves := 0

    for i := 1; i < len(nums); i++ {
        if nums[i] <= nums[i-1] {
            increment := nums[i-1] + 1 - nums[i]
            moves += increment
            nums[i] = nums[i-1] + 1
        }
    }

    return moves
}
```在 Go 中，实现镜像了 Python 版本。 排序是通过`sort.Ints`。 诸如空切片之类的边缘情况会被显式处理。 由于 Go 没有像 Python 那样的动态列表，因此所有操作都在输入切片上就地执行。

 ## 边缘情况

 第一个边缘情况是空数组。 不检查长度的简单实现可能会失败。 正确的处理是立即返回 0，因为不需要移动。
