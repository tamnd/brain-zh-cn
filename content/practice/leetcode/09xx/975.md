 ## 解决方案

 ## 问题理解

 该问题要求我们通过执行一系列定义为奇数或偶数的跳转来确定数组中有多少个起始索引可以到达最后一个元素。 奇数跳转和偶数跳转的区别至关重要：奇数跳转必须移动到大于或等于当前元素的最小值，而偶数跳转必须移动到小于或等于当前元素的最大值。 如果值相同，则选择最小的索引。 一个“好的”起始索引是一系列跳转可以到达数组的最终索引的索引。 

输入是单个整数数组`arr`尺寸可达`2 * 10^4`，元素范围为 0 到 100,000。 输出是一个整数，表示良好起始索引的数量。 限制表明，探索所有可能的跳跃序列的强力方法会太慢，因为它可能需要指数时间。 重要的边缘情况包括长度为 1 的数组（其中唯一的索引非常好）、具有所有相同元素的数组、严格递增或递减的数组，以及具有可能导致多个候选跳转索引的稳定状态的数组。 

## 方法

 暴力方法将尝试模拟来自每个起始索引的每个可能的跳转序列。 对于每个索引，我们将重复向前扫描以查找奇数或偶数跳转的下一个有效跳转。 这种方法是正确的，但非常慢，因为对于每个起始索引`i`，我们可以扫描所有剩余的索引`j > i`， 导致`O(n^2)`或者更糟，可能达到`O(n^3)`当包括递归或顺序检查到最后时。 

最佳解决方案的关键在于可以使用动态规划来分解问题。 我们可以预先计算每个索引`i`使用单调堆栈技术与排序相结合来进行下一个有效的奇数跳转和偶数跳转。 一旦知道了奇数跳转和偶数跳转的“下一个跳转”，我们就可以从末尾向后传播可达性。 这种方法避免了冗余扫描并允许问题得到解决`O(n log n)`排序和堆栈操作所花费的时间。

 ## 算法演练

 1.首先创建两个数组`odd_next`和`even_next`长度`n`， 在哪里`odd_next[i]`是通过奇数跳转可到达的下一个索引`i`， 和`even_next[i]`是通过偶数跳转可到达的下一个索引。 初始化所有条目`None`表示不可能进行跳跃。 
2. 按奇数跳转的值（升序）和偶数跳转的值（降序）对数组索引进行排序。 由于必须选择最小的索引，因此原始索引打破了价值的联系。 
3. 使用单调堆栈计算下一个跳转索引。 对于奇数跳转，迭代排序的索引。 对于每个索引，当堆栈不为空且当前索引大于堆栈顶部时，从堆栈中弹出并设置弹出索引的`odd_next`到当前索引。 对具有降序排序索引的偶数跳转重复类似的操作。 
4.初始化两个布尔数组`odd_reach`和`even_reach`， 在哪里`odd_reach[i]`如果从索引开始则为 True`i`用奇数的跳跃最终可以到达终点。 放`odd_reach[-1]`和`even_reach[-1]`为 True，因为最后一个索引是可以访问的。 
5. 从倒数第二个索引开始向后迭代。 对于每个索引`i`， 如果`odd_next[i]`存在，设置`odd_reach[i] = even_reach[odd_next[i]]`。 如果`even_next[i]`存在，设置`even_reach[i] = odd_reach[even_next[i]]`。 这确保了交替跳跃的要求得到遵守。 
6. 计算索引的数量，其中`odd_reach[i]`为真，因为问题陈述要求从第一次跳跃开始为奇数。 

**为什么有效：** 该方法之所以有效，是因为它根据问题的规则预先计算每个索引的唯一有效的“下一个跳转”。 向后传播可达性可确保我们正确考虑交替跳跃约束，同时避免冗余扫描。 

## Python 解决方案```python
from typing import List

class Solution:
    def oddEvenJumps(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 1:
            return 1

        def make_next(indices):
            result = [None] * n
            stack = []
            for i in indices:
                while stack and i > stack[-1]:
                    prev = stack.pop()
                    result[prev] = i
                stack.append(i)
            return result

        # Precompute next jumps
        odd_next = make_next(sorted(range(n), key=lambda i: (arr[i], i)))
        even_next = make_next(sorted(range(n), key=lambda i: (-arr[i], i)))

        # Initialize reachability arrays
        odd_reach = [False] * n
        even_reach = [False] * n
        odd_reach[-1] = even_reach[-1] = True

        # Backward propagation of reachability
        for i in range(n - 2, -1, -1):
            if odd_next[i] is not None:
                odd_reach[i] = even_reach[odd_next[i]]
            if even_next[i] is not None:
                even_reach[i] = odd_reach[even_next[i]]

        return sum(odd_reach)
```**实现说明：**该函数`make_next`使用单调堆栈计算奇数或偶数跳转的下一个可达索引。 排序可确保堆栈以正确的顺序接收索引，以满足“具有最小索引的最小/最大值”要求。 这`odd_reach`和`even_reach`数组使用向后传播来确定哪些索引可以到达末尾，同时考虑跳转交替。 最后总结一下`odd_reach`产生良好起始索引的数量。 

## 解决方案```go
package main

func oddEvenJumps(arr []int) int {
    n := len(arr)
    if n == 1 {
        return 1
    }

    makeNext := func(indices []int) []int {
        result := make([]int, n)
        for i := range result {
            result[i] = -1
        }
        stack := []int{}
        for _, i := range indices {
            for len(stack) > 0 && i > stack[len(stack)-1] {
                prev := stack[len(stack)-1]
                stack = stack[:len(stack)-1]
                result[prev] = i
            }
            stack = append(stack, i)
        }
        return result
    }

    oddIndices := make([]int, n)
    evenIndices := make([]int, n)
    for i := 0; i < n; i++ {
        oddIndices[i] = i
        evenIndices[i] = i
    }
    // sort for odd jumps ascending
    sort.Slice(oddIndices, func(i, j int) bool {
        if arr[oddIndices[i]] == arr[oddIndices[j]] {
            return oddIndices[i] < oddIndices[j]
        }
        return arr[oddIndices[i]] < arr[oddIndices[j]]
    })
    // sort for even jumps descending
    sort.Slice(evenIndices, func(i, j int) bool {
        if arr[evenIndices[i]] == arr[evenIndices[j]] {
            return evenIndices[i] < evenIndices[j]
        }
        return arr[evenIndices[i]] > arr[evenIndices[j]]
    })

    oddNext := makeNext(oddIndices)
    evenNext := makeNext(evenIndices)

    oddReach := make([]bool, n)
    evenReach := make([]bool, n)
    oddReach[n-1], evenReach[n-1] = true, true

    for i := n - 2; i >= 0; i-- {
        if oddNext[i] != -1 {
            oddReach[i] = evenReach[oddNext[i]]
        }
        if evenNext[i] != -1 {
            evenReach[i] = oddReach[evenNext[i]]
        }
    }

    count := 0
    for _, val := range oddReach {
        if val {
            count++
        }
    }
    return count
}
```**Go 注意事项：** Go 要求使用默认值初始化切片并使用`-1`而不是`None`。 排序用途`sort.Slice`具有比较功能。 该逻辑在其他方面反映了 Python 解决方案。
