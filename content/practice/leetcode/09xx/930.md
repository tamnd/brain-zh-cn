 ## 解决方案

 ## 问题理解

 该问题要求我们计算二进制数组中连续子数组的数量`nums`其总和等于给定整数`goal`。 二进制数组仅包含`0`沙`1`s。 子数组是数组中任意连续的元素序列，这意味着顺序很重要并且元素不能被跳过。 

输入`nums`表示二进制值的序列，并且`goal`表示我们想要从子数组中获得的目标总和。 输出是一个整数，表示子数组的总数，其总和恰好等于`goal`。 

约束条件告诉我们`nums`可以相当大，最多`3 * 10^4`元素，并且值严格`0`或者`1`。 这`goal`范围可以从`0`的长度为`nums`。 这意味着检查所有可能的子数组的简单方法将太慢，因为子数组的数量随数组长度呈二次方增长。 

重要的边缘情况包括全零的数组、零的目标、等于数组长度的目标，或者零和一的混合，其中多个重叠子数组的总和等于目标。 该问题保证数组仅包含二进制值，因此我们不需要处理负数或非整数输入。 

## 方法

 **暴力方法**迭代所有可能的子数组并对它们求和以查看它们是否相等`goal`。 这是正确的，因为它显式地检查每个组合，但由于其 O(n²) 时间复杂度，对于大输入来说速度太慢。 

**最佳方法**使用前缀和与哈希映射相结合来计算出现次数。 关键的见解是，如果从开始到索引的元素总和`i`是`current_sum`以及从开始到某个较早索引的元素总和`j`是`current_sum - goal`，那么子数组来自`j+1`到`i`总和为`goal`。 通过在哈希映射中存储前缀和的计数，我们可以在恒定时间内确定有多少有效子数组以当前索引结尾。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 迭代所有子数组并分别对它们求和 |
 | 最佳| O(n) | O(n) | 使用前缀和和哈希图高效计数子数组 |

 ## 算法演练

 1. 初始化哈希图`prefix_count`具有单个条目`{0:1}`表示开始前出现一次的总和为零。 
2. 初始化`current_sum`到 0。这将跟踪直到当前索引的元素总和。 
3. 初始化`result`到 0。这将累积子数组的数量，总和为`goal`。 
4. 迭代每个元素`num`在`nums`。 

1.添加`num`到`current_sum`。 
2. 计算`current_sum - goal`。 如果该值存在于`prefix_count`，这意味着有很多子数组以当前索引结尾，其总和为`goal`。 
3. 将哈希映射中的计数添加到`result`。 
4. 增加计数`current_sum`在`prefix_count`by 1.如果不存在则初始化为1。 
5. 返回`result`处理完所有元素后。 

**为什么它有效：** 不变的是`prefix_count`始终存储每个前缀和出现的次数。 对于任何结束索引`i`, 有效起始索引的数量`j`其中子数组的总和为`goal`正是`prefix_count[current_sum - goal]`。 这确保我们正确计算所有子数组而不会丢失重叠。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def numSubarraysWithSum(self, nums: List[int], goal: int) -> int:
        prefix_count = defaultdict(int)
        prefix_count[0] = 1
        current_sum = 0
        result = 0
        
        for num in nums:
            current_sum += num
            if (current_sum - goal) in prefix_count:
                result += prefix_count[current_sum - goal]
            prefix_count[current_sum] += 1
        
        return result
```Python 实现使用`defaultdict`存储前缀和的计数，允许我们在不检查是否存在的情况下增加计数。 我们迭代数组一次，更新`current_sum`并使用映射来计算有效子数组的数量。 这`if`检查确保我们只添加到`result`当存在有效的前缀和时。 

## 解决方案```go
func numSubarraysWithSum(nums []int, goal int) int {
    prefixCount := make(map[int]int)
    prefixCount[0] = 1
    currentSum := 0
    result := 0

    for _, num := range nums {
        currentSum += num
        if count, exists := prefixCount[currentSum - goal]; exists {
            result += count
        }
        prefixCount[currentSum]++
    }
    
    return result
}
```Go 解决方案反映了 Python 逻辑。 我们使用映射来存储前缀和并使用以下命令检查是否存在`exists`布尔值。 递增映射值很简单，并且迭代逻辑是相同的。

 ## 边缘情况

 **边缘情况 1：目标为零。** 当`goal`为 0，则必须对所有连续的零子数组进行计数。 使用前缀和方法可以自然地处理这个问题，因为差异`current_sum - goal`等于`current_sum`，并且 0 的前缀和被正确计数。 

**边缘情况 2：数组全是零。** 与前一种情况类似，多个重叠子数组对结果有贡献。 每个新零都会增加之前零的数量`prefix_count`，给出正确的总数。 

**边缘情况 3：单元素数组。** 当数组只有一个元素时，如果该元素匹配，算法会正确返回 1`goal`否则为 0。 前缀和映射初始化为`{0:1}`以正确处理本案。
