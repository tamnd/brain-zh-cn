 **难度：** 🟡 中等
 **主题：** 数组、分而治之、排序、堆（优先级队列）、归并排序、桶排序、基数排序、计数排序

 ## 解决方案

 ## 问题理解

 该问题要求我们在不使用任何内置排序函数的情况下按升序对整数数组进行排序。 结果必须包含与输入相同的元素，但按从小到大的顺序排列。 

输入是一个数组`nums`包含整数。 这些整数可以是正数、负数或零，并且允许重复。 输出只是同一数组的排序版本。 

重要的约束是所需的时间复杂度。 该问题明确要求`O(n log n)`解决方案，它立即排除了较慢的二次算法，例如针对大输入的冒泡排序、选择排序或插入排序。 由于数组长度可以大到`5 * 10^4`， 一个`O(n^2)`在最坏的情况下，算法可能需要数十亿次操作，这将超出时间限制。 

约束还告诉我们整数值本身的界限是`-5 * 10^4`和`5 * 10^4`。 这意味着像计数排序这样的非比较排序方法在技术上是可行的。 然而，最普遍适用且面试友好的方法是合并排序或堆排序。 

另一个重要要求是尽量减少额外空间的使用。 合并排序保证`O(n log n)`时间，但它使用额外的内存进行合并。 堆排序实现`O(1)`辅助空间，但实现更复杂并且通常不太直观。 在本指南中，我们将使用合并排序，因为它可靠、稳定且易于推理。 

一些边缘情况很重要：

 - 包含重复值的数组，因为算法必须正确保留所有出现的值。 
- 包含负数的数组，因为比较必须在正数和负数范围内正确进行。 
- 大小的数组`1`，因为它们已经排序并且应该立即返回。 
- 已经排序的数组，因为算法应该仍然正确运行。 
- 反向排序数组，因为它们通常代表更简单排序算法的最坏情况模式。 

## 方法

 强力方法将使用简单的二次排序算法，例如冒泡排序。 冒泡排序会反复比较相邻元素，如果它们无序，则交换它们。 经过足够多的传递后，最大的元素“冒泡”到数组的末尾。 

这是有效的，因为数组中的每个反转最终都会通过重复交换得到纠正。 然而，冒泡排序需要`O(n^2)`最坏情况下的比较。 和`5 * 10^4`元素，这变得太慢了。 

更好的解决方案的关键在于，我们可以将数组分成更小的部分，对这些更小的部分进行递归排序，然后有效地将排序后的部分合并在一起。 这是归并排序的基础。 

合并排序工作效率很高，因为合并两个已排序的数组可以在线性时间内完成。 通过反复将问题一分为二，我们大大减少了比较的次数。 递归分裂创建`log n`级别，每个级别处理所有`n`元素恰好出现一次，导致`O(n log n)`总的复杂性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 冒泡排序重复交换相邻元素 |

 ## 算法演练

 ### 归并排序概述

 合并排序遵循分而治之的范式。 该算法重复将数组拆分为更小的子数组，直到每个子数组仅包含一个元素。 单个元素本质上是排序的。 然后，该算法将较小的已排序子数组按排序顺序合并在一起。 

### 逐步过程

 1. 将数组分成两半。 

我们找到当前数组段的中点并将其分成左半部分和右半部分。 这减少了每次递归调用时的问题大小。 
2. 递归地对左半部分进行排序。 

左半部分可能仍未排序，因此我们再次应用相同的过程，直到最终到达大小为 1 的子数组。 
3. 递归地对右半部分进行排序。 

相同的递归逻辑应用于右侧。 
4. 合并已排序的两半。 

一旦两半都排序完毕，我们将它们合并成一个排序数组。 我们使用两个指针，每个指针代表一半。 

- 比较两半的当前元素。 
- 将较小的元素放入合并数组中。 
- 将指针向前移动到从中获取元素的一半。 
- 继续直到一半用完。 
- 附加另一半的任何剩余元素。 
5. 返回合并后的排序数组。 

合并后，当前递归调用将完全排序的段返回给其父调用。 

### 为什么它有效

 合并排序之所以有效，是因为一个简单的不变量：每当我们合并两个数组时，这些数组就已经单独排序了。 由于我们在合并时总是选择较小的前面元素，因此合并后的数组也是排序的。 递归除法保证最终每个子数组都被简单排序，并且重复合并按排序顺序重建整个数组。 

## Python 解决方案```python
from typing import List

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        def merge_sort(left: int, right: int) -> None:
            if left >= right:
                return

            mid = (left + right) // 2

            merge_sort(left, mid)
            merge_sort(mid + 1, right)

            merge(left, mid, right)

        def merge(left: int, mid: int, right: int) -> None:
            temp = []

            i = left
            j = mid + 1

            while i <= mid and j <= right:
                if nums[i] <= nums[j]:
                    temp.append(nums[i])
                    i += 1
                else:
                    temp.append(nums[j])
                    j += 1

            while i <= mid:
                temp.append(nums[i])
                i += 1

            while j <= right:
                temp.append(nums[j])
                j += 1

            for index in range(len(temp)):
                nums[left + index] = temp[index]

        merge_sort(0, len(nums) - 1)

        return nums
```实现从递归开始`merge_sort`功能。 该函数接收当前子数组的边界。 如果子数组包含零个或一个元素，则它已经排序，因此递归立即停止。 

使用整数除法计算中点。 该算法独立地递归地对左半部分和右半部分进行排序。 

两半排序后，`merge`函数将它们组合成一个排序的段。 两个指针跟踪每一半中的当前位置。 较小的值将附加到临时数组中。 

一旦一半耗尽，另一半中的任何剩余元素都会直接附加，因为它们已经排序。 

最后，合并的值被复制回原始数组段。 这确保父递归调用接收到正确排序的子数组。 

## 解决方案```go
func sortArray(nums []int) []int {
    var mergeSort func(int, int)

    mergeSort = func(left int, right int) {
        if left >= right {
            return
        }

        mid := (left + right) / 2

        mergeSort(left, mid)
        mergeSort(mid+1, right)

        merge(nums, left, mid, right)
    }

    mergeSort(0, len(nums)-1)

    return nums
}

func merge(nums []int, left int, mid int, right int) {
    temp := []int{}

    i := left
    j := mid + 1

    for i <= mid && j <= right {
        if nums[i] <= nums[j] {
            temp = append(temp, nums[i])
            i++
        } else {
            temp = append(temp, nums[j])
            j++
        }
    }

    for i <= mid {
        temp = append(temp, nums[i])
        i++
    }

    for j <= right {
        temp = append(temp, nums[j])
        j++
    }

    for k := 0; k < len(temp); k++ {
        nums[left+k] = temp[k]
    }
}
```Go 实现遵循与 Python 版本相同的递归合并排序策略。 Go 中的切片自然支持动态增长`append`，这简化了合并过程中的临时数组管理。 

与 Python 不同，Go 不以同样的方式直接支持嵌套命名函数，因此递归助手在赋值之前被声明为函数变量。 

Go 切片是对底层数组的引用，因此辅助函数内部的修改会自动影响原始数组。

 ## 边缘情况

 单元素数组是一种重要的边缘情况，因为递归必须正确终止。 如果当子数组大小变为 1 时执行未能停止，则可能会发生无限递归。 条件`if left >= right:`当段无法进一步分割时，通过立即返回来防止这种情况。 

具有重复值的数组是错误的另一个常见来源。 一些不正确的合并实现会在合并过程中意外地跳过重复项或错误地覆盖值。 此实现保留了重复项，因为两半中的每个元素都被复制到临时数组中一次。 

负数也会导致某些排序策略出现问题，尤其是非基于比较的方法。 合并排序仅依赖于标准整数比较，因此负值自然起作用，无需任何特殊处理。 

反向排序数组特别重要，因为它们暴露了冒泡排序或插入排序等简单算法的弱点。 归并排序可以有效地处理逆序，因为它的性能仅取决于递归拆分和合并，而不取决于输入的初始排序。
