[LeetCode 952 题](https://leetcode.com/problems/largest-component-size-by-common-factor/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、数学、并查集、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们找到从唯一正整数数组派生的图中的最大连通分量`nums`。 数组中的每个整数代表一个节点，如果相应的数字共享大于 1 的公因数，则两个节点之间存在无向边。本质上，如果数字具有非平凡的最大公约数，则数字是连通的。 目标是确定最大数字簇的大小，其中每个数字都通过共享因子间接连接。 

输入`nums`最多包含 20,000 个整数，每个整数最多 100,000 个，并且都是唯一的。 这保证了我们不必处理重复的节点。 主要挑战是根据因素有效地查找连接，因为检查所有对在计算上会令人望而却步。 边缘情况包括素数、仅具有一个公共因子的数字以及与不同数字共享多个因子的数字。 

## 方法

 ### 蛮力

 一种简单的方法是考虑每对数字并检查它们是否具有大于 1 的公因数。如果是，我们可以在图中的相应节点之间添加一条边。 构建图后，我们可以运行深度优先搜索或广度优先搜索来查找连接的组件并返回最大组件的大小。 

虽然正确，但这种方法太慢，因为检查所有对需要$O(n^2)$gcd 计算，每个 gcd 操作最多可达$O(\log(\text{maxNum}))$。 为了`n = 20,000`，这变得不切实际。 

### 最佳方法

 关键的观察是，我们可以将每个数字与其质因数相关联，而不是检查所有对。 共享相同素因数的数字属于同一个连通分量。 使用并查（不相交集并集）数据结构，我们可以通过素因子有效地联合数字。 

1. 将每个数字分解为素数。 
2. 使用并查找合并共享一个因子的数字。 
3. 通过跟踪每个数字的根来计算每个连接组件的大小。 

这将问题简化为分解和联合查找操作，这比成对 gcd 检查更有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 log m) | O(n^2 log m) | O(n^2) | O(n^2) | 使用 gcd | 检查所有对
 | 最佳| O(n * sqrt(m)) | O(n * sqrt(m)) | O(n + m) | 因式分解 + 并查，m = max(nums) |

 ## 算法演练

 1. **初始化并查**：创建一个并查数据结构，可以通过数字索引跟踪并集。 这使我们能够有效地合并具有共同因子的数字。 
2. **质因数分解**：对于每个数字，计算其质因数直至其平方根。 这确保每个因素仅被考虑一次。 
3. **按因子并集**：维护从每个因子到数字索引的映射。 如果某个因子已与某个数字关联，则将当前数字与之前的数字合并。 
4. **统计分量大小**：所有并集完成后，遍历所有数字，找到它们的根，统计每个根有多少个数字。 
5. **返回最大尺寸**：最大组件尺寸是所有根中的最大计数。 

**为什么有效：** 每个并集运算可确保共享任何因子的数字位于同一组件中。 由于共享一个因子的所有数字都会被传递合并，因此并查结构中的连通分量与图中共享因子定义的连通分量完全对应。 

## Python 解决方案```python
from typing import List
from collections import defaultdict
import math

class Solution:
    def largestComponentSize(self, nums: List[int]) -> int:
        parent = {}
        size = {}

        def find(x):
            if parent.setdefault(x, x) != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[py] = px
                size[px] = size.get(px, 1) + size.get(py, 1)

        factor_to_num = {}

        for num in nums:
            for i in range(2, int(math.isqrt(num)) + 1):
                if num % i == 0:
                    if i in factor_to_num:
                        union(num, factor_to_num[i])
                    else:
                        factor_to_num[i] = num
                    j = num // i
                    if j in factor_to_num:
                        union(num, factor_to_num[j])
                    else:
                        factor_to_num[j] = num

        count = defaultdict(int)
        max_size = 0
        for num in nums:
            root = find(num)
            count[root] += 1
            max_size = max(max_size, count[root])
        return max_size
```**说明：** 我们使用并查找结构和路径压缩。 每个因素对应一个数字； 如果另一个数字共享该因素，我们将它们合并。 计算最后出现的根的次数就可以得出组件的大小。 

## 解决方案```go
package main

import (
    "math"
)

func largestComponentSize(nums []int) int {
    parent := make(map[int]int)
    size := make(map[int]int)

    var find func(int) int
    find = func(x int) int {
        if _, ok := parent[x]; !ok {
            parent[x] = x
        }
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }

    union := func(x, y int) {
        px, py := find(x), find(y)
        if px != py {
            parent[py] = px
            size[px] = size[px] + size[py]
        }
    }

    factorToNum := make(map[int]int)

    for _, num := range nums {
        for i := 2; i <= int(math.Sqrt(float64(num))); i++ {
            if num%i == 0 {
                if prev, ok := factorToNum[i]; ok {
                    union(num, prev)
                } else {
                    factorToNum[i] = num
                }
                j := num / i
                if prev, ok := factorToNum[j]; ok {
                    union(num, prev)
                } else {
                    factorToNum[j] = num
                }
            }
        }
    }

    count := make(map[int]int)
    maxSize := 0
    for _, num := range nums {
        root := find(num)
        count[root]++
        if count[root] > maxSize {
            maxSize = count[root]
        }
    }
    return maxSize
}
```**Go 特定说明：** Go 映射可以优雅地处理缺失的键，但我们显式初始化父映射。 整数平方根需要 float64 转换`math.Sqrt`。 切片与数组不是这里的一个因素，因为`nums`作为切片传递。 

## 工作示例

 ### 示例：`[4,6,15,35]`逐步因子映射和联合运算：

 | 数量 | 因素| 联盟运营|
 | ---| ---| ---|
 | 4 | 2 | 4 首先是 2 → 映射 2→4 |
 | 6 | 2,3 | 2→4，并集6和4→6-4； 地图3→6 |
 | 15 | 15 3,5| 3→6，并集15和6→15-6-4； 地图5→15 |
 | 35 | 35 5,7 | 5,7 5→15，并集35和15→35-15-6-4； 地图7→35 |

 计算根可得出大小为 4 的一个分量。
