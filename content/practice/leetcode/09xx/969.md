[LeetCode 第 969 题](https://leetcode.com/problems/pancake-sorting/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、贪婪、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们仅使用**煎饼翻转**对一组唯一整数进行排序。 煎饼翻转被定义为从索引反转数组的前缀`0`索引`k-1`对于某个整数`k`之间`1`和数组的长度。 输入是来自以下整数的排列`1`到`arr.length`，保证不重复，并且输出必须是一系列`k`代表翻转的值最终将按升序对数组进行排序。 

需要注意的关键点是，每次翻转只影响一个前缀，而不是整个数组，并且问题并不要求最少翻转次数。 对数组进行排序的任何有效的翻转序列`10 * arr.length`翻转是可以接受的。 

重要的边缘情况包括已经排序的数组、逆序的数组以及长度为 1 的数组。约束 (`1 <= arr.length <= 100`）足够小，二次时间复杂度的算法是可以接受的。 

## 方法

 ### 蛮力

 暴力方法将尝试所有可能的翻转序列，以查看哪些序列最终对数组进行排序。 这可以通过尝试每一种可能的方式递归地完成`k`每一步，直到数组排序完毕。 虽然这保证了正确的答案，但可能的翻转序列的数量随着数组长度呈阶乘增长，使得即使对于小数组也是不可行的。 

### 最佳方法

 高效解决方案的关键在于对数组进行排序**从最大到最小**，类似于选择排序，但使用翻转而不是交换。 对于每个值`n`从最大到`1`，定位其在数组中的当前位置。 如果它尚未处于正确位置，请通过翻转将其带到前面（如有必要），然后将其翻转到最终位置。 通过重复地将最大的未排序元素移动到正确的位置，我们可以有效地对数组进行排序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 尝试所有可能的翻转顺序； 对于 n > 10 不可行 |
 | 最佳| O(n^2) | O(n^2) | O(1) | O(1) | 贪婪方法，每个元素最多使用 2 次翻转将最大元素移动到正确位置 |

 ## 算法演练

 1.初始化一个空列表`res`存储翻转的顺序。 
2. 迭代自`n = len(arr)`下降到`1`。 这代表当前要放置的最大元素。 
3.查找当前索引`idx`的`n`在数组中。 如果`idx + 1 == n`，该元素已经处于正确的位置，因此跳过它。 
4. 如果`idx != 0`，翻转子数组`0`到`idx`带来元素`n`到前面。 附加`idx + 1`到`res`。 
5. 翻转子数组`0`到`n-1`移动`n`到其最终位置。 附加`n`到`res`。 
6. 重复此操作，直到所有元素都按降序排列，从而对数组进行排序。 

**为什么有效：** 该算法保持不变，即所有大于当前目标的元素都已处于正确位置。 通过最多两次翻转将最大的剩余元素移动到正确的位置，数组逐渐排序。 每一步都会将数组的未排序部分减少一个元素。 

## Python 解决方案```python
from typing import List

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        res = []
        n = len(arr)
        for target in range(n, 0, -1):
            idx = arr.index(target)
            if idx + 1 == target:
                continue
            if idx != 0:
                arr[:idx+1] = arr[:idx+1][::-1]
                res.append(idx + 1)
            arr[:target] = arr[:target][::-1]
            res.append(target)
        return res
```该代码从最大元素到最小元素进行迭代。 对于每个元素，它首先检查它是否已经位于正确的位置。 如果没有，它会根据需要将该元素翻转到前面，然后将其翻转到最终位置。 名单`res`累积所有`k`用于翻转的值。 

## 解决方案```go
func pancakeSort(arr []int) []int {
    res := []int{}
    n := len(arr)
    
    for target := n; target >= 1; target-- {
        idx := 0
        for i, v := range arr {
            if v == target {
                idx = i
                break
            }
        }
        if idx+1 == target {
            continue
        }
        if idx != 0 {
            for i, j := 0, idx; i < j; i, j = i+1, j-1 {
                arr[i], arr[j] = arr[j], arr[i]
            }
            res = append(res, idx+1)
        }
        for i, j := 0, target-1; i < j; i, j = i+1, j-1 {
            arr[i], arr[j] = arr[j], arr[i]
        }
        res = append(res, target)
    }
    
    return res
}
```在 Go 中，我们使用两指针交换方法手动反转切片，因为 Go 不支持反向切片赋值。 该逻辑与 Python 版本非常相似，处理目标搜索和翻转。 

## 工作示例

 **示例1：**`arr = [3,2,4,1]`| 步骤| 行动| 数组| 资源 |
 | ---| ---| ---| ---|
 | 1 | 目标 = 4，idx = 2 | [3,2,4,1] | 翻转 idx+1 = 3 → [4,2,3,1] |
 | 2 | 翻转目标 = 4 → [1,3,2,4] | [1,3,2,4] | [3,4]|
 | 3 | 目标 = 3，idx = 1 | [1,3,2,4] | 翻转 idx+1 = 2 → [3,1,2,4] |
 | 4 | 翻转目标 = 3 → [2,1,3,4] | [2,1,3,4] | [3,4,2,3] |
 | 5 | 目标 = 2，idx = 0 | [2,1,3,4] | 翻转目标 = 2 → [1,2,3,4] |

 获得排序数组。 

**示例2：**`arr = [1,2,3]`已经排序； 不需要翻转，结果是`[]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 时间 | O(n^2) | O(n^2) | 每次迭代都会搜索目标元素，并且最多可以执行两次翻转，每次 O(n) |
 | 空间| O(1) | O(1) | 翻转是就地完成的，只有结果列表存储翻转 |

 ## 边缘情况

 单元素数组`[1]`不需要翻转。 该算法正确地跳过所有迭代。 

二元素反转数组`[2,1]`测试最小翻转。 第一个翻转将 2 移到前面（微不足道），然后另一个翻转将其正确放置。 

逆序排列的数组`[n,...,1]`测试最大翻转下算法的效率。 每个元素最多需要翻转两次，表明该解决方案最多执行`2*n`在问题允许的范围内翻转。 

该解决方案正确处理所有边缘情况，保证仅使用有效的煎饼翻转对数组进行排序。
