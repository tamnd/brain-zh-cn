 ## 解决方案

 ## 问题理解

 该问题要求我们获取一个整数数组`nums`已经按非降序排序并返回一个新数组，其中包含每个数字的**平方**，也按非降序排序。 简单来说，我们首先对每个数字进行变换`x`在数组中`x * x`，然后我们生成一个最终数组，其中平方数按从小到大的顺序排列。 

输入数组`nums`可以包含负数、零和正数。 负数很重要，因为对它们进行平方会产生正值，这可以重新排序它们与原始数组相比的相对位置。 例如，`[-4, -1, 0, 3, 10]`平方变成`[16, 1, 0, 9, 100]`然后排序为`[0, 1, 9, 16, 100]`。 

约束表明长度`nums`最多可以有 10,000 个元素，值的范围可以是`-10,000`到`10,000`。 这意味着一个简单的解决方案，涉及平方后排序（`O(n log n)`）是可行的，但问题暗示了一种更有效的方法`O(n)`解决方案，利用原始数组已经排序的事实。 

关键边缘情况包括全部非负、全部非正、包含零或仅包含一个元素的数组。 这些案例测试解决方案是否正确处理边界并且不假设负数和正数的混合。 

## 方法

 最直接的方法是**强力方法**：对每个数字求平方，然后对结果数组进行排序。 这是可行的，因为平方是一个简单的转换，并且排序保证了正确的非递减顺序。 然而，它比必要的要慢，因为排序需要`O(n log n)`时间。 

**最佳方法**利用了数组已经排序的事实。 关键的见解是最大的正方形总是来自数组的任一端（最大负数或最大正数）。 使用两指针技术，一个指针从开头（左）开始，一个指针从结尾（右）开始。 我们比较这些元素的绝对值，将较大的正方形放在结果数组的末尾，并将相应的指针向内移动。 该方法有效地从最大到最小填充结果数组`O(n)`时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 将所有元素平方，然后排序 |
 | 最佳 | O(n) | O(n) | 两指针技术，从末尾填充结果数组 |

 ## 算法演练

 1.初始化两个指针，`left`在索引处`0`和`right`在最后一个索引处`nums`。 这些指针跟踪具有潜在最大绝对值的元素。 
2. 创建一个与以下长度相同的结果数组`nums`存储平方值。 我们将从头到尾填充这个数组。 
3. 初始化位置指针`pos`到结果数组的最后一个索引。 
4. 虽然`left`小于或等于`right`， 比较`abs(nums[left])`和`abs(nums[right])`。 
5. 如果`abs(nums[left])`更大，正方形`nums[left]`并将其放置在`result[pos]`，然后递增`left`。 
6. 否则，正方形`nums[right]`并将其放置在`result[pos]`，然后递减`right`。 
7. 减量`pos`并重复直到结果数组完全填充。 
8. 返回结果数组，该数组现在包含按非降序排列的所有方块。 

**为什么它起作用：** 该算法依赖于每一步的不变量，最大的未处理的正方形被放置在当前的位置`pos`。 由于原始数组已排序，因此最大绝对值必须位于端点之一。 这确保了线性时间的正确性，而不需要完整排序。 

## Python 解决方案```python
from typing import List

class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        n = len(nums)
        result = [0] * n
        left, right = 0, n - 1
        pos = n - 1
        
        while left <= right:
            if abs(nums[left]) > abs(nums[right]):
                result[pos] = nums[left] ** 2
                left += 1
            else:
                result[pos] = nums[right] ** 2
                right -= 1
            pos -= 1
        
        return result
```Python 解决方案遵循上述两指针方法。 我们分配一个长度相同的结果数组`nums`并使用`left`和`right`在每一步寻找较大绝对值的指针。 通过填充`result`从最后开始，我们就不需要进行额外的排序。 

## 解决方案```go
func sortedSquares(nums []int) []int {
    n := len(nums)
    result := make([]int, n)
    left, right := 0, n-1
    pos := n-1
    
    for left <= right {
        if abs(nums[left]) > abs(nums[right]) {
            result[pos] = nums[left] * nums[left]
            left++
        } else {
            result[pos] = nums[right] * nums[right]
            right--
        }
        pos--
    }
    
    return result
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```Go 解决方案反映了 Python 方法。 Go 需要明确的`abs`函数，并且使用切片而不是列表。 内存分配是显式使用的`make`，并且两指针方法的逻辑保持相同。
