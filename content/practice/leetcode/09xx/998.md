 # LeetCode 998 - 最大二叉树 II

 ## 问题陈述

 最大树是一种特殊的二叉树，其中每个节点包含的值都大于其子树内的所有值。 该树是从数组递归构建的，选择最大元素作为根，然后从最大值之前的元素递归构建左子树，从最大值之后的元素递归构建右子树。 

在这个问题中，我们没有直接给出原始数组。 相反，我们得到一个已经构造的最大二叉树的根和一个新整数`val`。 该问题保证这个新值被附加到原始数组的末尾。 

我们的任务是构造追加后产生的新的最大树`val`到原始数组。 

重要的观察是，向数组附加值只会影响树的右侧。 由于新元素是添加在末尾的，因此它永远不会出现在任何现有节点的左子树中。 这种结构特性可以提供有效的解决方案。 

约束相对较小，最多 100 个节点，但目标仍然是了解最佳结构方法，而不是不必要地重建整个树。 

一些边缘情况很重要：

 - 新值可能大于当前根，这意味着它成为整个树的新根。 
- 新值可能小于所有现有节点，这意味着它会沿着右脊柱插入某处。 
- 一棵树可能只包含一个节点。 
- 插入点可能出现在右子树深处。 

该问题还保证所有值都是唯一的，这避免了确定最大关系时的歧义。 

## 方法

 ### 蛮力方法

 一种直接的方法是从给定的树重建原始数组，追加`val`，然后从头开始重建最大二叉树。 

为了重建数组，我们可以对最大树进行中序遍历。 这是可行的，因为原始构造保留了数组元素的有序序列。 

获取数组后：

 1、中序遍历恢复原数组。 
2. 追加`val`。 
3. 使用标准构造算法递归地重建最大树。 

这种方法是正确的，因为它完全模拟了原始的问题定义。 但是，重建树会重复搜索子数组中的最大元素，这可能会变得低效。 

### 最佳方法

 关键的见解来自于理解附加如何影响最大树。 

自从`val`附加到数组的末尾，它只能出现在现有树的最右边路径上的某个位置。 

只有两种可能：

 - 如果`val`大于当前根，则`val`成为新的根，整个现有树成为其左子树。 
- 否则，我们继续在右子树中搜索，因为附加元素只影响右侧。 

这一观察使我们能够仅递归地遍历树的右脊柱，直到找到正确的插入点。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 从重建的数组重建整个树 |
 | 最佳| O(h) | O(h) | 仅遍历树的右脊柱 |

 这里，`n`是节点数，`h`是树的高度。 

## 算法演练

 1. 从最大树的根开始。 
2. 比较`val`与当前节点的值。 
3.如果`val`大于当前节点值，创建一个包含以下内容的新节点`val`。 使当前树成为该新节点的左子节点，然后返回新节点作为新根。 
4. 否则，插入必须发生在右子树中的某个位置，因为新值已附加到数组中，因此属于右侧。 
5. 递归插入到右子树中。 
6. 递归返回后，将更新后的右子树重新连接回当前节点。 
7. 返回当前节点。 

递归自然地沿着右脊柱向下走，直到找到正确的插入点。 

### 为什么它有效

 该算法之所以有效，是因为向数组追加元素只会更改最大树的右边界。 

如果附加值大于某个节点，则它必须成为该节点及其左侧所有内容的父节点。 如果它较小，它必须保留在右子树内的某个位置，因为附加元素按中序顺序出现在所有先前元素之后。 

通过递归遍历右侧，我们保留了最大树构建过程的精确结构属性。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def insertIntoMaxTree(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        if not root:
            return TreeNode(val)

        if val > root.val:
            new_root = TreeNode(val)
            new_root.left = root
            return new_root

        root.right = self.insertIntoMaxTree(root.right, val)
        return root
```实现直接遵循前面描述的递归逻辑。 

第一个基本情况处理空子树。 当我们达到一个`None`节点，我们创建一个新节点，其中包含`val`。 

第二个条件检查是否`val`大于当前根。 如果是这样，新值必须成为父节点，因为最大树根始终包含子树中的最大值。 

如果这两个条件都不适用，我们将递归地继续进入右子树。 这保留了与在原始数组末尾附加元素相对应的中序结构。 

最后，我们重新连接更新后的右子树并返回当前节点。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func insertIntoMaxTree(root *TreeNode, val int) *TreeNode {
    if root == nil {
        return &TreeNode{Val: val}
    }

    if val > root.Val {
        return &TreeNode{
            Val:  val,
            Left: root,
        }
    }

    root.Right = insertIntoMaxTree(root.Right, val)
    return root
}
```Go 的实现与 Python 解决方案非常相似。 

主要区别在于显式指针处理。 在Go中，树节点是通过指针操作的，因此新创建的节点使用`&TreeNode{}`句法。 

Go 还使用`nil`而不是Python的`None`。 

由于约束很小并且值在整数范围限制内，因此不必担心整数溢出。

## 测试用例```python
# Helper utilities for testing

from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def insertIntoMaxTree(self, root, val):
        if not root:
            return TreeNode(val)

        if val > root.val:
            new_root = TreeNode(val)
            new_root.left = root
            return new_root

        root.right = self.insertIntoMaxTree(root.right, val)
        return root

def build_tree(values):
    if not values:
        return None

    nodes = [None if v is None else TreeNode(v) for v in values]
    kids = deque(nodes[1:])
    root = nodes[0]

    for node in nodes:
        if node:
            if kids:
                node.left = kids.popleft()
            if kids:
                node.right = kids.popleft()

    return root

def tree_to_list(root):
    if not root:
        return []

    result = []
    queue = deque([root])

    while queue:
        node = queue.popleft()

        if node:
            result.append(node.val)
            queue.append(node.left)
            queue.append(node.right)
        else:
            result.append(None)

    while result and result[-1] is None:
        result.pop()

    return result

solution = Solution()

# Example 1
root = build_tree([4,1,3,None,None,2])
result = solution.insertIntoMaxTree(root, 5)
assert tree_to_list(result) == [5,4,None,1,3,None,None,2]  # new value becomes root

# Example 2
root = build_tree([5,2,4,None,1])
result = solution.insertIntoMaxTree(root, 3)
assert tree_to_list(result) == [5,2,4,None,1,None,3]  # insert at rightmost position

# Example 3
root = build_tree([5,2,3,None,1])
result = solution.insertIntoMaxTree(root, 4)
assert tree_to_list(result) == [5,2,4,None,1,3]  # insert between nodes

# Single node, larger value
root = build_tree([1])
result = solution.insertIntoMaxTree(root, 2)
assert tree_to_list(result) == [2,1]  # new root created

# Single node, smaller value
root = build_tree([5])
result = solution.insertIntoMaxTree(root, 3)
assert tree_to_list(result) == [5,None,3]  # inserted as right child

# Deep right insertion
root = build_tree([10,None,8,None,7])
result = solution.insertIntoMaxTree(root, 6)
assert tree_to_list(result) == [10,None,8,None,7,None,6]  # append deep in chain

# Insert in middle of right spine
root = build_tree([10,None,7,None,5])
result = solution.insertIntoMaxTree(root, 6)
assert tree_to_list(result) == [10,None,7,None,6,5]  # inserted above smaller node

 ## 边缘情况

 当新值大于当前根时，就会出现一种重要的边缘情况。 如果实现忘记将现有树保留为新节点的左子节点，则很容易导致错误。 正确的行为是创建一个新的根并将整个先前的树附加在其下面。 

当新值小于树中的每个节点时，会发生另一个重要情况。 在这种情况下，算法必须沿着右脊柱一直遍历，直到到达零位置。 不正确的实现可能会意外地过早插入并违反最大树属性。 

第三种边缘情况涉及插入右脊柱中部。 当新值大于某个右后代但小于其祖先时，就会发生这种情况。 该实现必须正确地将新节点放置在这些节点之间，同时保留子树结构。 递归方法自然地处理这个问题，因为较小的子树成为插入节点的左子树。 

最后，非常小的树（例如单节点树）对于正确处理非常重要。 这些案例验证了基本案例是否已正确实现，并且空子级是否已安全处理，没有取消引用错误。
