[LeetCode 934 题](https://leetcode.com/problems/shortest-bridge/)

 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个`n x n`二进制矩阵称为`grid`。 每个单元格包含`1`或者`0`。 

值为`1`代表土地，价值为`0`代表水。 垂直或水平连接的陆地单元形成一个岛屿。 该问题保证网格中恰好存在两个独立的岛屿。 

我们的目标是通过将水细胞翻转为陆地细胞来连接这两个岛屿。 每翻一次都会改变一个`0`进入`1`。 我们必须确定所需的最少翻转次数，以便将两个岛连接成一个更大的岛。 

关键细节是我们不会被要求返回实际的桥或路径。 我们只需要必须转换的最少数量的水细胞。 

例如，在此网格中：```
0 1
1 0
```两个岛屿呈对角线分开。 翻转任一水池都会产生连接，所以答案是`1`。 

约束条件很重要：

 -`2 <= n <= 100`- 网格恰好包含两个岛屿

 由于网格大小最多为`100 x 100`, 最多有`10,000`细胞。 对于深度优先搜索 (DFS) 和广度优先搜索 (BFS) 等图遍历算法来说，这个大小足够小，这两种算法都可以在限制内轻松运行。 

一些边缘情况很重要：

 - 这些岛屿可能已经非常接近，仅由一个水池隔开。 
- 一个岛屿可能完全包围另一个岛屿。 
- 岛屿可能具有不规则形状，而不是简单的矩形。 
- 除非系统地探索，否则最短的桥可能不会来自视觉上最接近的一对细胞。 
- 从一个岛的每个单元到另一个岛的每个单元的简单搜索可能会变得不必要的昂贵。 

保证恰好有两个岛大大简化了逻辑，因为我们永远不需要处理两个以上的连接组件。 

## 方法

 ### 蛮力方法

 强力解决方案将首先识别属于第一个岛的所有单元和属于第二个岛的所有单元。 

收集两组坐标后，我们可以计算两个岛屿上每对像元之间的曼哈顿距离：```
distance = abs(r1 - r2) + abs(c1 - c2) - 1
```减法为`1`解释了陆地单元本身不需要翻转的事实。 

这种方法之所以有效，是因为任何有效的桥都对应于第一个岛的一个单元和第二个岛的一个单元之间的路径。 这个距离的最小值给出了答案。 

然而，这种方法效率低下，因为每个岛屿最多可以容纳`O(n^2)`细胞。 比较每对结果`O(n^4)`最坏情况下的时间复杂度。 

为了`n = 100`，这可能会变得非常昂贵。 

### 最佳方法

 关键的见解是，这个问题实际上要求从一个岛到达另一个岛的最短扩展。 

这自然表明了多源 BFS。 

最优策略分两个阶段进行：

 1. 使用DFS（或BFS）定位并标记第一个岛的所有单元格。 
2. 从该岛的每个单元同时启动 BFS，通过水单元逐层向外扩展。 

当 BFS 到达属于第二个岛的单元格时，当前的 BFS 距离表示所需的最小翻转次数。 

为什么 BFS 在这里表现得这么好？ 

因为 BFS 会远距离探索所有位置`1`距离之前`2`，所有距离位置`2`距离之前`3`， 等等。 因此，我们第一次接触第二个岛时，保证已经找到了最短的桥。 

这将复杂性降低到`O(n^2)`因为每个单元格最多被处理一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(n^2) | O(n^2) | 比较每对岛状细胞 |
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | DFS寻找第一个岛屿，BFS向外扩张 |

 ## 算法演练

 1. 遍历网格，直到找到第一个陆地单元。 

我们需要第一个岛屿的起点。 一旦我们遇到一个`1`，我们停止搜索并从该单元格开始 DFS。 
2. 执行DFS标记整个第一个岛。 

DFS 期间：

 - 标记每个访问过的岛屿单元
 - 将每个岛单元添加到 BFS 队列中

 我们使用 DFS 是因为它可以有效地探索所有连接的陆地单元。 
3. 使用第一个岛中的所有单元初始化 BFS。 

这称为多源 BFS，因为搜索同时从第一个岛的每个单元开始。 

这很重要，因为最短的桥梁可能源自岛屿的任何边缘。 
4、逐级向外拓展。 

对于每个 BFS 层：

 - 探索四个方向
 - 跳过越界单元格
 - 跳过已经访问过的单元格
 5. 处理水池。 

如果相邻单元格是水（`0`）：

 - 标记已访问
 - 将其添加到队列中

 这代表将水细胞翻转到陆地上。 
6. 检测第二个岛屿。 

如果我们遇到一个陆地单元（`1`）那不是第一个岛的一部分，那么我们就到达了第二个岛。 

当前的 BFS 距离是所需的最小翻转次数。 
7. 返回 BFS 级别。 

由于 BFS 按距离递增顺序扩展，因此保证第一个成功的连接是最优的。 

### 为什么它有效

 DFS 正确识别了属于第一个岛的每个单元格。 然后BFS同时从所有边界点均匀向外扩展。 由于 BFS 按距离递增的顺序探索位置，因此第一次到达第二个岛时对应的是必须翻转的最小水单元数。 不可能存在更短的桥，因为 BFS 会更早发现它。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def shortestBridge(self, grid: List[List[int]]) -> int:
        n = len(grid)

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        visited = set()
        queue = deque()

        def dfs(row: int, col: int) -> None:
            if (
                row < 0
                or row >= n
                or col < 0
                or col >= n
                or (row, col) in visited
                or grid[row][col] == 0
            ):
                return

            visited.add((row, col))
            queue.append((row, col))

            for dr, dc in directions:
                dfs(row + dr, col + dc)

        found = False

        for row in range(n):
            if found:
                break

            for col in range(n):
                if grid[row][col] == 1:
                    dfs(row, col)
                    found = True
                    break

        steps = 0

        while queue:
            for _ in range(len(queue)):
                row, col = queue.popleft()

                for dr, dc in directions:
                    new_row = row + dr
                    new_col = col + dc

                    if (
                        new_row < 0
                        or new_row >= n
                        or new_col < 0
                        or new_col >= n
                        or (new_row, new_col) in visited
                    ):
                        continue

                    if grid[new_row][new_col] == 1:
                        return steps

                    visited.add((new_row, new_col))
                    queue.append((new_row, new_col))

            steps += 1

        return -1
```实现首先定义四个可能的移动方向。 由于岛屿仅在垂直和水平方向上连接，因此从不考虑对角线移动。 

这`visited`set 可以防止在 DFS 和 BFS 期间重新访问单元格。 这避免了无限循环和冗余处理。 

DFS 函数识别第一个岛屿。 每个发现的陆地单元都被标记为已访问并添加到 BFS 队列中。 这为多源 BFS 初始化做好了准备。 

第一个岛屿完全被发现后，BFS 开始。 变量`steps`tracks how many water layers have been expanded.

 每个 BFS 层对应于翻转一层额外的水细胞。 当 BFS 到达不属于第一个岛屿的新陆地单元时，我们立即返回当前的步数。 

决赛`return -1`从技术上讲是无法到达的，因为该问题保证了恰好两个岛屿。 

## 解决方案```go
package main

func shortestBridge(grid [][]int) int {
	n := len(grid)

	directions := [][]int{
		{1, 0},
		{-1, 0},
		{0, 1},
		{0, -1},
	}

	type Pair struct {
		row int
		col int
	}

	queue := []Pair{}
	visited := make([][]bool, n)

	for i := 0; i < n; i++ {
		visited[i] = make([]bool, n)
	}

	var dfs func(int, int)

	dfs = func(row int, col int) {
		if row < 0 || row >= n || col < 0 || col >= n {
			return
		}

		if visited[row][col] || grid[row][col] == 0 {
			return
		}

		visited[row][col] = true
		queue = append(queue, Pair{row, col})

		for _, dir := range directions {
			dfs(row+dir[0], col+dir[1])
		}
	}

	found := false

	for row := 0; row < n; row++ {
		if found {
			break
		}

		for col := 0; col < n; col++ {
			if grid[row][col] == 1 {
				dfs(row, col)
				found = true
				break
			}
		}
	}

	steps := 0

	for len(queue) > 0 {
		size := len(queue)

		for i := 0; i < size; i++ {
			current := queue[0]
			queue = queue[1:]

			for _, dir := range directions {
				newRow := current.row + dir[0]
				newCol := current.col + dir[1]

				if newRow < 0 || newRow >= n || newCol < 0 || newCol >= n {
					continue
				}

				if visited[newRow][newCol] {
					continue
				}

				if grid[newRow][newCol] == 1 {
					return steps
				}

				visited[newRow][newCol] = true
				queue = append(queue, Pair{newRow, newCol})
			}
		}

		steps++
	}

	return -1
}
```Go 实现遵循与 Python 解决方案相同的整体逻辑。 

由于 Go 没有元组，因此有一个自定义`Pair`struct 存储坐标。 而不是Python`set`，一个二维布尔切片跟踪访问过的单元格。 

Go 切片通过从前面删除元素来用作队列：```go
queue = queue[1:]
```该算法在行为和复杂性方面保持相同。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^2) | O(n^2) | 在 DFS 和 BFS 期间每个单元最多被访问一次 |
 | 空间| O(n^2) | O(n^2) | 队列和访问结构可以存储所有单元|

 DFS 遍历对第一个岛屿的每个陆地单元进行一次处理。 BFS 遍历也最多处理每个单元一次，因为访问过的单元永远不会被重新访问。 

尽管 DFS 和 BFS 是独立的阶段，但它们一起仍然仅接触每个单元恒定的次数，从而给出总体时间复杂度`O(n^2)`。 

辅助空间复杂度也为`O(n^2)`因为访问的结构和 BFS 队列可能都包含网格的很大一部分。

 ## 边缘情况

 当岛屿恰好被一个水单元隔开时，就会出现一种重要的边缘情况。 如果 BFS 级别管理不正确，粗心的实现可能会意外地过多计算翻转次数。 在我们的解决方案中，BFS 仅在处理整个层后才增加步数计数器，因此第一个直接连接正确返回`1`。 

另一个重要的情况是一个岛屿包围另一个岛屿的情况。 在这种情况下，视觉上最近的路径可能同时存在于多个方向上。 仅从一个岛单元进行单源搜索最初可能会错过最佳网桥。 多源 BFS 通过同时从第一个岛的每个单元向外扩展来解决这个问题。 

不规则的岛屿形状是虫子的另一个常见来源。 岛屿不保证是矩形或简单结构。 DFS 确保发现每个连接的陆地单元，无论其形状如何，因为它递归地探索每个陆地单元的所有四个方向。 

边界处理也很关键。 如果不小心访问邻居，网格边缘或角落的单元格很容易导致索引超出范围错误。 DFS 和 BFS 都会在访问网格值之前显式验证坐标，确保安全遍历所有位置。
