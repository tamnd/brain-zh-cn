[LeetCode 第 943 题](https://leetcode.com/problems/find-the-shortest-superstring/)

 **难度：** 🔴难
 **主题：** 数组、字符串、动态规划、位操作、位掩码

 ## 解决方案

 ## 问题理解

 该问题要求我们找到包含数组中所有给定字符串的**最短超字符串**`words`作为子串。 换句话说，我们需要一个包含其中每个字符串的字符串`words`至少一次，以某种顺序连接，但我们希望这个超字符串具有最小的长度。 该问题保证中没有字符串`words`是另一个字符串的子字符串，这简化了重叠处理。 

输入`words`是由小写英文字母组成的唯一字符串数组。 数组长度在 1 到 12 之间，每个字符串最多可包含 20 个字符。 输出是一个字符串，它是包含所有内容的最短可能组合`words`。 如果存在多个最小长度超字符串，则多个输出可以有效。 

边缘情况包括：数组中的单个字符串、完全不重叠的字符串以及除少数字符外完全重叠的字符串。 这些情况测试了如何处理重叠以及算法是否有效地找到最短的串联。 

## 方法

 ### 蛮力

 暴力方法是生成单词的所有排列，并通过贪婪地合并重叠部分来计算每个排列的结果超串。 对于排列中的每对连续单词，您可以找到最大重叠并附加不重叠的后缀。 检查所有排列后，返回找到的最短超字符串。 

这种方法是正确的，因为它考虑了字符串的每一种可能的顺序，因此它不会错过最佳排列。 然而，排列的阶乘增长使得上限不可行`words.length = 12`因为12！ 超过 4.79 亿种可能性。 即使使用快速重叠计算，这也太慢了。 

### 最佳方法

 最佳方法的关键见解是使用**带有位掩码的动态编程**。 每个单词子集都可以用位掩码表示，并且我们可以计算每个子集的以每个单词结尾的最短超字符串。 具体来说，定义`dp[mask][i]`作为使用所有单词的最短超字符串的长度`mask`并以单词结尾`i`。 我们可以填写`dp`使用先前计算的较小子集和单词之间的最大重叠。 最后，我们通过从最佳端点回溯来重建路径。 

这种方法工作效率很高，因为状态数是`2^n * n`（在哪里`n`是字数），这是可以管理的`n <= 12`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n^2 * L) | O(n! * n^2 * L) | O(n * L) | 生成所有排列并根据重叠合并单词。 对于 n=12 来说太慢了。 |
 | 最佳| O(n^2 * 2^n + n^2 * L) | O(n * 2^n + n^2) | O(n * 2^n + n^2) | 使用带有位掩码的 DP，预先计算重叠，并重建最短的超字符串。 |

 ## 算法演练

 1. **计算重叠**：对于每对单词`(i, j)`，计算最大后缀`words[i]`匹配前缀`words[j]`。 将其存储在二维数组中`overlap[i][j]`。 这允许快速计算附加时需要多少额外字符串`words[j]`后`words[i]`。 
2. **初始化DP表**：创建DP表`dp[mask][i]`在哪里`mask`代表单词的子集并且`i`表示最后使用的单词。 初始化`dp[1 << i][i] = len(words[i])`因为单个单词的超串就是那个单词。 
3. **填充 DP 表**：按位集升序迭代所有掩码。 对于每个`mask`和每个`i`在`mask`，尝试通过附加另一个单词来扩展超字符串`j`不在`mask`。 更新`dp[mask | (1 << j)][j]`如果附加`j`后`i`给出较短的长度。 
4. **跟踪父指针**：在 DP 表旁边，维护一个`parent`存储前一个单词的数组`i`导致最佳长度为`dp[mask][j]`。 这允许重建词序。 
5. **重建超字符串**：识别端点`i`在`dp[(1 << n) - 1][i]`以最小的长度。 回溯通过`parent`找到最佳的单词顺序。 使用预先计算的重叠连接单词。 

**为什么有效**：每个 DP 状态都会考虑所有子集并以特定单词结尾，确保覆盖所有组合而不重复。 通过使用重叠，我们可以最小化每一步增加的长度。 父指针确保我们可以从 DP 解决方案重建有效的超字符串。 

## Python 解决方案```python
from typing import List

class Solution:
    def shortestSuperstring(self, words: List[str]) -> str:
        n = len(words)
        overlap = [[0] * n for _ in range(n)]
        
        # Compute maximum overlap between words[i] suffix and words[j] prefix
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                m = min(len(words[i]), len(words[j]))
                for k in range(m, 0, -1):
                    if words[i][-k:] == words[j][:k]:
                        overlap[i][j] = k
                        break
        
        dp = [[0] * n for _ in range(1 << n)]
        parent = [[-1] * n for _ in range(1 << n)]
        
        # Fill DP
        for mask in range(1, 1 << n):
            for j in range(n):
                if not (mask & (1 << j)):
                    continue
                prev_mask = mask ^ (1 << j)
                if prev_mask == 0:
                    dp[mask][j] = len(words[j])
                else:
                    for i in range(n):
                        if not (prev_mask & (1 << i)):
                            continue
                        val = dp[prev_mask][i] + len(words[j]) - overlap[i][j]
                        if dp[mask][j] == 0 or val < dp[mask][j]:
                            dp[mask][j] = val
                            parent[mask][j] = i
        
        # Reconstruct path
        mask = (1 << n) - 1
        j = min(range(n), key=lambda x: dp[mask][x])
        path = []
        while j != -1:
            path.append(j)
            j, mask = parent[mask][j], mask ^ (1 << path[-1])
        path = path[::-1]
        
        # Build superstring
        res = words[path[0]]
        for k in range(1, len(path)):
            i, j = path[k - 1], path[k]
            res += words[j][overlap[i][j]:]
        return res
```Python 解决方案首先预先计算重叠以实现高效合并，使用位掩码填充 DP 表以跟踪以每个单词结尾的每个子集的最小超字符串，然后重建最佳顺序以生成最终字符串。
