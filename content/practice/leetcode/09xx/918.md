 **难度：** 🟡 中等
 **主题：** 数组、分而治之、动态规划、队列、单调队列

 ## 解决方案

 ## 问题理解

 该问题要求**圆形数组**中**子数组**的和。 简单来说，我们得到一个整数列表`nums`列表末尾环绕到开头的位置。 我们需要找到此列表中总和最高的连续部分，请记住子数组可以从末尾“环绕”到开头。 输入是一个整数数组，可以是正数，也可以是负数，并且我们必须始终从**非空子数组**返回总和。 

约束条件告诉我们`nums`最长可达 30,000 个元素，每个元素的范围为 -30,000 到 30,000。 这排除了检查所有可能的子数组的简单解决方案，因为子数组的数量随数组长度呈二次方增长。 重要的边缘情况包括所有数字均为负数的数组、只有一个元素的数组以及最大子数组跨越圆形边界的数组。 

总之，任务是有效地处理标准子数组和以及子数组环绕数组的特殊情况。 

## 方法

 **强力方法**会考虑每个可能的子数组，计算其总和并跟踪最大值。 对于循环数组，这需要考虑可能从末尾附近开始并环绕到开头的子数组。 虽然这保证了正确性，但其时间复杂度为 O(n²)，对于`n`最多 30,000 个。 

最佳解决方案的**关键见解**是圆形数组的最大子数组和可以是**正常子数组**（不环绕）或**环绕子数组**。 对于普通子数组，我们可以使用 **Kadane 算法**，它在 O(n) 时间内找到最大连续和。 对于环绕情况，最大总和可以从**总数组总和减去最小子数组总和**得出。 减去最小子数组总和实际上会留下环绕末端的最大总和。 此方法两次利用 **Kadane 算法**：一次用于最大总和，一次用于最小总和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 枚举所有可能的子数组，包括环绕情况 |
 | 最佳| O(n) | O(1) | O(1) | 对最大和最小子数组使用 Kadane 算法，并对圆形情况使用总和减法 |

 ## 算法演练

 1. **使用标准 Kadane 算法计算最大子数组和**。 迭代数组，同时保持运行总和。 如果运行总和变为负数，请将其重置为零。 跟踪遇到的最大总和。 
2. **使用类似 Kadane 的方法计算最小子数组总和**，但跟踪最小总和。 这使我们能够将循环最大值计算为总和减去该最小和。 
3. **计算数组的总和**。 这是处理环绕场景所必需的。 
4. **确定最大循环子数组和**。 从总和中减去最小子数组和即可得到环绕子数组的总和。 
5. **边缘情况检查**：如果所有数字均为负数，则环绕计算将错误地给出零（总和减去最小子数组和等于零）。 在这种情况下，返回使用普通 Kadane 算法找到的最大元素。 
6. **返回非包裹和包裹总和的最大值**。 这确保我们考虑这两种情况并选择正确的最大值。 

**为什么有效**：该算法之所以有效，是因为循环数组中的任何子数组要么环绕，要么不环绕。 标准 Kadane 处理非回绕情况，同时从总和中减去最小子数组和，有效地找到回绕子数组的最大和。 当所有数字均为负数时，边缘情况可确保正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxSubarraySumCircular(self, nums: List[int]) -> int:
        if not nums:
            return 0

        total = 0
        max_sum = float('-inf')
        min_sum = float('inf')
        curr_max = 0
        curr_min = 0

        for num in nums:
            curr_max = max(num, curr_max + num)
            max_sum = max(max_sum, curr_max)

            curr_min = min(num, curr_min + num)
            min_sum = min(min_sum, curr_min)

            total += num

        if max_sum < 0:
            return max_sum

        return max(max_sum, total - min_sum)
```该实现首先初始化总计、当前最大值、当前最小值以及相应的总体最大/最小总和的运行变量。 它迭代数组一次，更新运行总和并跟踪整体最大值和最小值。 最后，它检查全负边缘情况并返回适当的最大总和，无论是非循环还是循环。 

## 解决方案```go
func maxSubarraySumCircular(nums []int) int {
    total, maxSum, minSum := 0, nums[0], nums[0]
    currMax, currMin := 0, 0

    for _, num := range nums {
        currMax = max(num, currMax+num)
        maxSum = max(maxSum, currMax)

        currMin = min(num, currMin+num)
        minSum = min(minSum, currMin)

        total += num
    }

    if maxSum < 0 {
        return maxSum
    }

    return max(maxSum, total-minSum)
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```在 Go 中，主要区别在于显式处理`max`和`min`通过辅助函数，并初始化`maxSum`和`minSum`与数组的第一个元素一起以避免从零开始的边缘问题。 

## 工作示例

 **示例 1：nums = [1, -2, 3, -2]**

 | 步骤| 当前最大 | 最大总和 | curr_min | 最小总和 | 总计 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | 1 | 1 | 1 | 1 | 1 |
 | 2 | -1 | 1 | -2 | -2 | -1 |
 | 3 | 3 | 3 | 1 | -2 | 2 |
 | 4 | 1 | 3 | -2 | -2 | 0 |

 环绕 = 0 - (-2) = 2，因此 max(3, 2) = 3

 **示例 2：nums = [5, -3, 5]**

 | 步骤| 当前最大 | 最大总和 | curr_min | 最小总和 | 总计 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | 5 | 5 | 5 | 5 | 5 |
 | 2 | 2 | 5 | -3 | -3 | 2 |
 | 3 | 7 | 7 | 2 | -3 | 7 |

 环绕 = 7 - (-3) = 10, 最大值(7,10) = 10

 **示例 3：nums = [-3, -2, -3]**

 | 步骤| 当前最大 | 最大总和 | curr_min | 最小总和 | 总计 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | -3 | -3 | -3 | -3 | -3 |
 | 2 | -2 | -2 | -2 | -3 | -5 |
 | 3 | -3 | -2 | -3 | -3 | -8 |

 环绕 = -8 - (-3) = -5, 最大值(-2, -5) = -2

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 单次遍历数组以获取最大和最小子数组以及总和计算 |
 | 空间| O(1) | O(1) | 仅使用恒定数量的变量来运行总计和最大值/最小值 |

 原因是每个元素都被访问一次，并且无论数组大小如何，我们都只存储几个整数。
