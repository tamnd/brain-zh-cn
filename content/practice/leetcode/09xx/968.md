[LeetCode 第 968 题](https://leetcode.com/problems/binary-tree-cameras/)

 **难度：** 🔴难
 **主题：** 动态规划、树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定监控二叉树中所有节点所需的最少摄像机数量。 放置在节点上的每个摄像机都可以监视其父级、自身及其直接子级。 输入是`root`二叉树，其中每个节点都有一个值`0`并且可能有左孩子和右孩子。 输出是一个整数，表示覆盖所有节点所需的最少摄像机数量。 

约束告诉我们，树最多可以有 1000 个节点，这对于线性或稍微超过线性的解决方案来说足够小，但探索所有相机位置的纯粹强力递归方法会太慢。 重要的边缘情况包括单节点树（始终需要一个摄像机）、类似于链表的倾斜树，以及最佳摄像机放置位置不在叶节点上而是在树中稍高的位置的树。 

这里的挑战是找到一种系统的方法来放置摄像机，以便监控每个节点，同时最大限度地减少摄像机总数。 单纯地将摄像机放置在叶子或每个节点上的效率并不高。 

## 方法

 ### 蛮力

 蛮力方法会考虑每个节点并递归地决定是否在那里放置相机。 对于每个节点，我们可以尝试其子节点的所有相机放置组合，并对所需的相机总数进行求和。 虽然这最终会产生正确的结果，但可能的相机放置数量随着节点数量呈指数增长，这使得它不可行`n = 1000`。 

### 最佳方法

 最佳解决方案的关键见解是通过深度优先搜索和动态规划使用贪婪的自下而上方法。 对于每个节点，我们可以将其状态分为以下三种状态之一：

 1. **有摄像头** - 节点本身有摄像头。 
2. **覆盖** - 该节点没有摄像头，但由其子节点或父节点监控。 
3. **需要覆盖** - 该节点不受任何摄像头监控。 

通过执行后序遍历，我们根据子节点的状态决定节点的状态。 如果任何子节点需要覆盖，我们必须在当前节点放置一个摄像机。 这可确保放置最少的摄像机，因为仅在必要时放置摄像机，并尽可能覆盖多个节点。 

这种方法保证了最佳解决方案，因为它贪婪地确保每个子树都被完全覆盖，同时避免冗余的相机放置。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归地探索所有相机位置，速度太慢 |
 | 最佳 | O(n) | O(h) | 后序DFS，h为树高，仅在儿童需要覆盖时放置相机|

 ## 算法演练

 1. 对二叉树进行后序深度优先遍历。 
2. 对于每个节点，检查其左右子节点的状态。 
3. 如果任何子节点处于“需要覆盖”状态，则在当前节点放置一个摄像头并将其标记为“有摄像头”。 
4. 如果任何子节点“有摄像头”，则将当前节点标记为“被覆盖”。 
5. 如果两个子节点都被“覆盖”但没有摄像头，则将当前节点标记为“需要覆盖”。 
6. 遍历后，如果根本身处于“需要覆盖”状态，则在根处再放置一台摄像机。 
7. 统计遍历过程中放置​​的所有相机并返回总数。 

**为什么起作用：** 后序遍历确保决策是从叶到根做出的，因此仅在需要覆盖未覆盖的子节点时才将相机放置在节点上。 这保证了最少的相机使用，同时确保完全覆盖。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def minCameraCover(self, root: Optional[TreeNode]) -> int:
        HAS_CAMERA = 0
        COVERED = 1
        NEEDS_COVERAGE = 2

        self.camera_count = 0

        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return COVERED

            left = dfs(node.left)
            right = dfs(node.right)

            if left == NEEDS_COVERAGE or right == NEEDS_COVERAGE:
                self.camera_count += 1
                return HAS_CAMERA
            if left == HAS_CAMERA or right == HAS_CAMERA:
                return COVERED
            return NEEDS_COVERAGE

        if dfs(root) == NEEDS_COVERAGE:
            self.camera_count += 1

        return self.camera_count
```**实现说明：**`dfs`函数返回每个节点的状态。 叶节点返回`COVERED`默认情况下，如果它们是`None`。 如果一个节点有一个需要覆盖的子节点，则会在该节点放置一个摄像机。 如果一个节点有一个带有摄像头的子节点，则该节点本身会被覆盖。 最后，在DFS之后，如果根仍然需要覆盖，我们再添加一个摄像头。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func minCameraCover(root *TreeNode) int {
    const (
        HAS_CAMERA = iota
        COVERED
        NEEDS_COVERAGE
    )

    cameraCount := 0

    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil {
            return COVERED
        }

        left := dfs(node.Left)
        right := dfs(node.Right)

        if left == NEEDS_COVERAGE || right == NEEDS_COVERAGE {
            cameraCount++
            return HAS_CAMERA
        }
        if left == HAS_CAMERA || right == HAS_CAMERA {
            return COVERED
        }
        return NEEDS_COVERAGE
    }

    if dfs(root) == NEEDS_COVERAGE {
        cameraCount++
    }

    return cameraCount
}
```**Go 特定注释：** 在 Go 中，我们使用`iota`定义状态常数。`nil`用于失踪儿童。 递归和状态逻辑与Python相同，并且`cameraCount`每当放置相机时都会更新。

 | 根 0 | 有相机 | 不适用 | 被孩子覆盖 | 覆盖|

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 一个关键的边缘情况是**单节点树**，其中始终需要相机； 该算法通过检查 DFS 后是否需要覆盖根来正确检测到这一点。 另一个边缘情况是**完全倾斜的树**，它类似于链表； 该算法每两个节点最佳地放置相机以覆盖所有节点。 第三种边缘情况涉及**不同高度的子树**，其中仅将相机放置在较高的子树上可能会导致较短的子树未被覆盖； 自下而上的 DFS 确保在放置相机之前检查所有子项，并正确处理此问题。
