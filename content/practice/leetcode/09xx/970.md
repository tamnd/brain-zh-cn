 # LeetCode 970 - 强大的整数

 ## 问题理解

 这个问题要求我们生成所有可以写成以下形式的整数：$x^i + y^j$在哪里：

-`i >= 0`-`j >= 0`- 结果值小于或等于`bound`输入是三个整数：

 -`x`，第一个指数项的底
 -`y`，第二个指数项的底数
 -`bound`，最大允许值

 我们必须返回满足条件的每个不同整数。 返回值的顺序并不重要。 

重要的细节是指数从零开始。 由于任何数字的幂`0`等于`1`，最小可能的强力整数是：$x^0 + y^0 = 1 + 1 = 2$这意味着如果`bound < 2`，答案必须始终是一个空列表。 

限制相对较小：

 -`1 <= x, y <= 100`-`0 <= bound <= 10^6`尽管界限可能高达一百万，但指数增长发生得非常快。 甚至权力`2`仅经过大约 20 次乘法就超过了 100 万。 这一观察结果是有效解决方案的关键。 

一些边缘情况很重要：

 - 当`x == 1`, 的所有权力`x`总是`1`- 什么时候`y == 1`, 的所有权力`y`总是`1`- 可能会出现重复值，因此我们需要一个自动删除重复项的结构
 - 非常小的界限，例如`0`或者`1`应该立即返回一个空列表

 ## 方法

 ### 蛮力方法

 一个简单的解决方案是尝试每一个可能的指数对`(i, j)`在某个大范围内并计算：$x^i + y^j$对于每个计算值，我们将检查它是否小于或等于`bound`。 如果是，我们将其存储。 

这种方法是正确的，因为它详尽地检查了所有可能的组合。 然而，困难在于确定指数应该走多远。 如果不使用指数增长洞察力，强力实施可能会测试许多不必要的能力。 

例如，如果我们任意循环指数`0`到`1000`，该算法执行超过一百万种组合，其中大多数组合是无用的，因为值变得远远大于`bound`。 

### 最佳方法

 关键的观察是权力呈指数增长。 因此，相关权力的数量实际上是很少的。 

例如：

-`2^20 > 10^6`-`3^13 > 10^6`-`10^6`本身只有大约20种对小型基地有意义的权力

 我们可以逐步生成幂，直到它们超过`bound`。 

我们产生所有有效的权力`x`以及所有有效权力`y`，然后将它们两两组合起来。 每个有效的总和都会插入到一个集合中以避免重复。 

当任一基数等于时需要特殊处理`1`， 因为：$1^i = 1$为所有人`i`。 

如果没有特殊处理，我们将在重复乘以时进入无限循环`1`。

 ## 算法演练

 1. 创建一个空集来存储唯一的强大整数。 
2. 生成所有有效权力`x`小于或等于`bound`。 

开始于`1`，这代表`x^0`。 反复乘以`x`直到该值超过`bound`。 

如果`x == 1`,添加后立即停止`1`，因为所有未来的权力都是相同的。 
3. 生成所有有效权力`y`使用相同的过程。 
4. 迭代每对幂。 

对于每对`(px, py)`，计算：$px + py$如果总和小于或等于`bound`，将其插入集合中。 
5. 将集合转换为列表并返回。 

### 为什么它有效

 该算法之所以有效，是因为每个有效的强大整数都必须由`x`和一些力量`y`。 生成的幂列表包含可以得出有效答案的所有可能的幂，因为任何更大的幂都会超过`bound`甚至在添加第二项之前。 通过检查每对生成的功率，我们仅检查每个有效组合一次。 当不同的指数对产生相同的和时，该集合保证唯一性。 

## Python 解决方案```python
from typing import List

class Solution:
    def powerfulIntegers(self, x: int, y: int, bound: int) -> List[int]:
        if bound < 2:
            return []

        x_powers = []
        y_powers = []

        value = 1
        while value <= bound:
            x_powers.append(value)

            if x == 1:
                break

            value *= x

        value = 1
        while value <= bound:
            y_powers.append(value)

            if y == 1:
                break

            value *= y

        powerful_numbers = set()

        for px in x_powers:
            for py in y_powers:
                total = px + py

                if total <= bound:
                    powerful_numbers.add(total)

        return list(powerful_numbers)
```实施从提前返回开始`bound < 2`。 由于最小可能的强大整数是`2`，低于该阈值不存在有效答案。 

下一部分生成的所有权力`x`。 循环开始于`1`，对应于`x^0`。 添加当前功率后，算法乘以`x`来产生下一次的力量。 

特殊情况为`x == 1`是必不可少的。 没有它，乘以`1`永远不会改变该值，从而导致无限循环。 

对于以下幂重复相同的逻辑`y`。 

建立两个功率列表后，算法会检查每对功率。 每个有效的总和都会插入到一个集合中，该集合会自动删除重复项。 

最后，将集合转换为列表并返回。 

## 解决方案```go
func powerfulIntegers(x int, y int, bound int) []int {
    if bound < 2 {
        return []int{}
    }

    xPowers := []int{}
    yPowers := []int{}

    value := 1
    for value <= bound {
        xPowers = append(xPowers, value)

        if x == 1 {
            break
        }

        value *= x
    }

    value = 1
    for value <= bound {
        yPowers = append(yPowers, value)

        if y == 1 {
            break
        }

        value *= y
    }

    powerfulSet := make(map[int]bool)

    for _, px := range xPowers {
        for _, py := range yPowers {
            total := px + py

            if total <= bound {
                powerfulSet[total] = true
            }
        }
    }

    result := []int{}

    for value := range powerfulSet {
        result = append(result, value)
    }

    return result
}
```Go 实现遵循与 Python 解决方案相同的结构。 由于 Go 没有内置的集合类型，`map[int]bool`用于模拟一组。 

切片用于存储能量。 实施仔细处理`x == 1`和`y == 1`避免无限循环的情况。 

不需要特殊的整数溢出处理，因为约束确保值安全地保持在 Go 的整数范围内。

 ## 边缘情况

 ### 什么时候`bound`小于 2

 可能的最小有效整数是：$1 + 1 = 2$因此，如果`bound`是`0`或者`1`，不存在有效答案。 幼稚的实现可能仍会尝试生成不必要的幂和组合。 该解决方案通过立即提前返回来避免这种情况。 

＃＃＃ 什么时候`x`或者`y`等于 1

 这是最重要的边缘情况。 自从：$1^i = 1$对于每个指数`i`, 反复乘以`1`永远不会改变该值。 通过乘法产生幂的循环将变得无限。 该实现显式检查此条件并在添加第一个电源后立即中断。 

### 重复强大的整数

 不同的指数对可以产生相同的结果。 例如：$2^0 + 2^1 = 3$和：$2^1 + 2^0 = 3$两者生成相同的整数。 如果没有重复处理，结果列表将包含重复的值。 该实现通过将结果存储在集合中来解决这个问题。 

### 非常大的界限

 虽然`bound`可以大到一百万，但由于指数增长很快，产生的功率数量仍然很小。 简单的暴力解决方案可能会浪费时间探索巨大的指数范围。 优化的实现仅生成实际有用的能力，即使在最大约束下也能保持运行时的效率。
