[LeetCode 972 题](https://leetcode.com/problems/equal-rational-numbers/)

 **难度：** 🔴难
 **主题：** 数学、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们判断两个字符串是否`s`和`t`，每个表示十进制有理数，对应相同的数值。 这些数字可以表示为整数、有限小数或重复部分用括号表示的小数。 例如，`0.1(6)`代表 0.1666...无限重复，而`1.`代表整数1。 

输入字符串的整数部分最多为 4 位，非重复小数部分最多为 4 位，重复部分为 1 至 4 位。 除个位数零外，整数部分不能有前导零。 任务是返回`true`如果这两个表示在数学上相等并且`false`否则。 

重要的边缘情况包括重复部分最终向上舍入以更改整数部分的数字，例如`0.9(9)`等于`1.`，以及具有不同长度的重复周期的数字，例如`0.(52)`相对`0.5(25)`。 

挑战在于直接字符串比较会失败，因为重复循环可以用多种等效方式表示，因此需要数字表示或标准化技术。 

## 方法

 一种强力方法是将十进制数扩展到非常大的位数，然后逐位比较它们。 原则上这是正确的，因为最终两个相等的有理数在其十进制展开式中会匹配。 然而，这是不实用的，因为重复循环可能是无限的并且无法完全枚举。 

最佳方法是将给定的数字表示形式转换为分数。 通过分别处理整数、非重复和重复部分，我们可以计算每个数字的精确分子和分母。 两个数相等当且仅当它们的约分数相等。 这种方法避免了无限小数扩展和舍入误差的陷阱。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N) 每位数扩展 | O(N) | 将重复小数扩展为固定的大长度并比较 |
 | 最佳| O(M + R) | O(1) | O(1) | 将整数、非重复和重复部分转换为精确分数并进行比较 |

 ## 算法演练

 1. **解析数字部分**：将每个字符串拆分为整数部分、不重复小数部分和重复小数部分。 使用字符串操作来识别重复段的括号。 
2. **转换为分数**：计算精确的分数表示形式。 对于一个号码`A.B(C)`：

- 让`int_part = A`。 
- 让`non_repeat = B`。 
- 让`repeat = C`。 
- 使用以下公式转换为分数：```
numerator = int_part * denominator + non_repeat_contrib + repeat_contrib
denominator = 10^(len(B)) * (10^(len(C)) - 1)
```这确保了重复部分得到正确处理。 
3. **减少分数**：（可选）通过将分子和分母除以其最大公约数 (GCD)，将分数减少到最低项。 这保证了精确比较而没有浮点错误。 
4. **比较分数**：两个有理数相等，如果`numerator1 * denominator2 == numerator2 * denominator1`。 

**为什么有效**：通过将每个十进制表示形式转换为其精确分数，我们避免了重复小数和有限近似的歧义。 有理数具有作为不可约分数的唯一表示，因此分数相等保证了原始数字的相等。 

## Python 解决方案```python
from math import gcd

class Solution:
    def isRationalEqual(self, s: str, t: str) -> bool:
        def to_fraction(num: str):
            if '.' not in num:
                return int(num), 1
            
            int_part, frac_part = num.split('.')
            if '(' in frac_part:
                non_repeat, repeat = frac_part.split('(')
                repeat = repeat.rstrip(')')
            else:
                non_repeat, repeat = frac_part, ''
            
            int_val = int(int_part) if int_part else 0
            
            if not repeat:
                if not non_repeat:
                    return int_val, 1
                numerator = int(non_repeat)
                denominator = 10 ** len(non_repeat)
            else:
                numerator = int(non_repeat + repeat) - int(non_repeat or '0')
                denominator = (10 ** len(non_repeat + repeat) - 10 ** len(non_repeat))
            
            numerator += int_val * denominator
            g = gcd(numerator, denominator)
            return numerator // g, denominator // g
        
        n1, d1 = to_fraction(s)
        n2, d2 = to_fraction(t)
        return n1 * d2 == n2 * d1
```**实现说明**：该函数`to_fraction`将输入分为整数部分、非重复部分和重复部分。 如果没有重复部分，分数就很简单。 对于重复小数，它使用几何级数公式计算贡献。 通过 GCD 减少分数以确保精确比较。 最后，交叉乘法可以避免除法错误。 

## 解决方案```go
package main

import (
	"strconv"
	"strings"
)

func gcd(a, b int) int {
	if b == 0 {
		return a
	}
	return gcd(b, a%b)
}

func toFraction(num string) (int, int) {
	parts := strings.Split(num, ".")
	intPart := 0
	if len(parts) > 0 && parts[0] != "" {
		intPart, _ = strconv.Atoi(parts[0])
	}

	if len(parts) == 1 || parts[1] == "" {
		return intPart, 1
	}

	fracPart := parts[1]
	nonRepeat := ""
	repeat := ""
	if strings.Contains(fracPart, "(") {
		subparts := strings.Split(fracPart, "(")
		nonRepeat = subparts[0]
		repeat = strings.TrimRight(subparts[1], ")")
	} else {
		nonRepeat = fracPart
	}

	var numerator, denominator int
	if repeat == "" {
		numerator, _ = strconv.Atoi(nonRepeat)
		denominator = pow10(len(nonRepeat))
	} else {
		full, _ := strconv.Atoi(nonRepeat + repeat)
		base, _ := strconv.Atoi(nonRepeat)
		numerator = full - base
		denominator = pow10(len(nonRepeat+repeat)) - pow10(len(nonRepeat))
	}

	numerator += intPart * denominator
	g := gcd(numerator, denominator)
	return numerator / g, denominator / g
}

func pow10(n int) int {
	res := 1
	for i := 0; i < n; i++ {
		res *= 10
	}
	return res
}

func isRationalEqual(s string, t string) bool {
	n1, d1 := toFraction(s)
	n2, d2 := toFraction(t)
	return n1*d2 == n2*d1
}
```**Go 特定注释**：Go 使用`strconv.Atoi`将字符串转换为整数，以及`strings.Split`解析输入。 这`pow10`helper 避免浮点运算。 逻辑几乎与 Python 相同，但整数类型和字符串处理需要显式转换。 

## 工作示例

 **示例：s =“0.(52)”，t =“0.5(25)”**

 | 步骤| s 分数计算 | t 分数计算 |
 | ---| ---| ---|
 | 整数部分 | 0 | 0 |
 | 不重复| “” | “5”|
 | 重复 | “52”| “25”|
 | 分数| 分子 = 52-0=52，分母=99 → 52/99 | 分子 = 525-5=520，分母=990 → 52/99 |
 | 约简分数 | 52/99 | 52/99 52/99 | 52/99
 | 比较| 52_99 == 52_99 → 真 | 真实|

 **示例：s =“0.9(9)”，t =“1。”**

 | 步骤| 分数计算 |
 | ---| ---|
 | s：分子 = 9-0=9，分母 = 10-1=9，加 int=0 → 9/9 → 1/1 | |
 | t：分子=1，分母=1 → 1/1 | |
 | 比较| 1_1 == 1_1 → 真 |

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(M + R) | 解析整数、非重复和重复部分需要相对于它们的长度呈线性时间 |
