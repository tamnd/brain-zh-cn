 **难度：** 🟡 中等
 **主题：** 数组、字符串、并查集、图论

 ## 解决方案

 ## 问题理解

 问题是要求我们确定单字母变量之间的一组方程是否可以同时满足。 每个方程都是以下形式之一`"xi==yi"`或者`"xi!=yi"`， 在哪里`xi`和`yi`是小写字母`'a'`到`'z'`。 任务是为每个变量分配一个整数值，使得所有相等 (`==`）和不平等（`!=`）约束成立。 如果可能的话，我们返回`true`; 否则，我们返回`false`。 

输入是一个字符串列表，每个字符串正好有 4 个字符长。 第一个和最后一个字符表示变量，中间两个字符表示关系类型。 这些约束确保方程的数量最多为 500 个，这对于联合查找或基于图的解决方案来说足够小，但对于显式尝试所有可能的变量分配的强力方法来说可能太大。 

边缘情况包括将变量与其自身进行比较的方程，例如`"a==a"`或者`"b!=b"`。 第一个总是满足的，而第二个是不可能的，应该立即返回`false`。 另一个微妙的情况是不平等与一系列平等相矛盾，例如`["a==b", "b==c", "a!=c"]`，无法满足。 该问题保证所有输入字符串都是有效的方程，因此不需要额外的输入验证。 

## 方法

 暴力方法会尝试将整数值分配给每个可能组合中的变量，然后检查所有方程。 虽然理论上是正确的，但由于可能的赋值呈指数级增长（具有任意整数赋值的 26 个变量），这种方法是不可行的。 即使将范围缩小到一小组整数也是低效的，因为这些关系会创建许多依赖约束，并且检查所有组合会随着变量数量呈指数增长。 

最佳解决方案的关键见解是使用 **Union-Find（不相交集并集）** 数据结构对问题进行建模。 连接变量`"=="`形成等价类，可以有效地表示为连接组件。 处理完所有等式后，我们可以检查每个不等式，以确保涉及的两个变量不属于同一分量。 如果它们满足，则方程组是不可满足的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(26^N * N) | O(26^N * N) | O(26) | 尝试对变量进行所有可能的整数赋值，变量数量呈指数增长 |
 | 联查| O(N * α(N)) | O(N * α(N)) | O(26) | 处理等式以构建组件，然后验证不等式； α(N) 是阿克曼反函数，实际上是常数 |

 ## 算法演练

 1. **初始化并查：** 创建一个大小为 26 的父数组，每个小写字母一个。 最初，每个变量都是其自己的父变量。 
2. **过程等式：** 迭代`equations`大批。 对于每个`"xi==yi"`方程，联合各分量`xi`和`yi`。 此步骤确保所有必须相等的变量属于同一连接组件。 
3. **处理不等式：** 迭代`equations`再次阵列。 对于每个`"xi!=yi"`方程，检查是否`xi`和`yi`属于同一个连接组件，使用`find`手术。 如果他们这样做，请返回`false`立即，因为不可能满足这个不等式。 
4. **返回True：** 如果处理完所有不等式后没有发现矛盾，则返回`true`。 

**为什么有效：** 并查结构保持了同一连接组件中的所有变量都相等的不变性。 通过在构建组件后检查不等式，我们可以有效地确定是否违反了任何不等式，而无需尝试所有可能的分配。 

## Python 解决方案```python
from typing import List

class Solution:
    def equationsPossible(self, equations: List[str]) -> bool:
        parent = list(range(26))  # 'a' -> 0, 'b' -> 1, ..., 'z' -> 25

        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])  # path compression
            return parent[x]

        def union(x: int, y: int):
            parent[find(x)] = find(y)

        # First, process all equalities
        for eq in equations:
            if eq[1:3] == "==":
                x = ord(eq[0]) - ord('a')
                y = ord(eq[3]) - ord('a')
                union(x, y)

        # Then, check all inequalities
        for eq in equations:
            if eq[1:3] == "!=":
                x = ord(eq[0]) - ord('a')
                y = ord(eq[3]) - ord('a')
                if find(x) == find(y):
                    return False

        return True
```该实现首先为 26 个小写字母建立并查数据结构。 等式用于合并可变分量，而不等式用于检测矛盾。 路径压缩确保`find`操作几乎以恒定的时间运行，保持整体算法的高效。 

## 解决方案```go
func equationsPossible(equations []string) bool {
    parent := make([]int, 26)
    for i := 0; i < 26; i++ {
        parent[i] = i
    }

    var find func(int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }

    union := func(x, y int) {
        parent[find(x)] = find(y)
    }

    // Process equalities first
    for _, eq := range equations {
        if eq[1:3] == "==" {
            x := int(eq[0] - 'a')
            y := int(eq[3] - 'a')
            union(x, y)
        }
    }

    // Check inequalities
    for _, eq := range equations {
        if eq[1:3] == "!=" {
            x := int(eq[0] - 'a')
            y := int(eq[3] - 'a')
            if find(x) == find(y) {
                return false
            }
        }
    }

    return true
}
```Go 解决方案反映了 Python 实现。 Go 特有的一个区别是切片是显式初始化的，并且使用整数算术将字符转换为索引。 并查找逻辑是相同的，并且递归地应用路径压缩。 

## 工作示例

 **示例1：**`["a==b","b!=a"]`| 步骤| 行动| 父数组| 说明|
 | ---| ---| ---| ---|
 | 1 | 初始化父级|`[0,1,2,...,25]`| 每个变量都是它自己的父变量 |
 | 2 | 进程“a==b” |`[1,1,2,...,25]`| 并集 a(0) 和 b(1)，现在 a 和 b 已连接 |
 | 3 | 检查“b！=a” |`[1,1,2,...,25]`| Find(a) == Find(b) → 矛盾，返回 False |

 **示例2：**`["b==a","a==b"]`| 步骤| 行动| 父数组| 说明|
 | ---| ---| ---| ---|
 | 1 | 初始化父级|`[0,1,2,...,25]`| 每个变量都是它自己的父变量 |
 | 2 | 进程“b==a” |`[1,1,2,...,25]`| 并集 b (1) 和 a (0) |
 | 3 | 进程“a==b” |`[1,1,2,...,25]`| 已连接，无变化 |
 | 4 | 没有不平等|`[1,1,2,...,25]`| 不矛盾，返回True |

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N * α(N)) | O(N * α(N)) | 由于路径压缩，每个并集/查找操作几乎恒定，其中 N 是方程的数量 |
 | 空间| O(26) | 只需要一个26个小写字母的父数组 |

 由于变量数量固定为 26，因此空间复杂度实际上是恒定的。 处理等式和不等式最多需要两次遍历方程数组。
