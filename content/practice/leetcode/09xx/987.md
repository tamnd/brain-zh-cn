 ## 解决方案

 ## 问题理解

 该问题要求我们计算二叉树的垂直顺序遍历。 简而言之，我们被要求“从侧面看树”并收集在同一垂直列中对齐的节点。 每个节点都有一个由下式定义的位置`(row, col)`在哪里`row`是它的深度（根在 0 处）并且`col`是其相对于根的水平偏移量（根位于 0 处）。 向左移动该列将减少 1，向右移动该列将增加 1。 

输入是`root`二叉树的结构，可能包含 1 到 1000 个节点。 节点值的范围从 0 到 1000。输出应该是一个列表列表，其中每个内部列表包含一个垂直列的节点值，首先按行（从上到下）排序，对于共享相同行和列的节点，按值（升序）排序。 输出列本身必须从最左列到最右列排序。 

重要的边缘情况包括仅具有根的树、同一行和列中具有重复值的节点以及完全倾斜的树（所有节点向左或向右）。 如果不仔细管理排序和列处理，这些可能会导致实现失败。 

## 方法

 强力方法是遍历树并将节点存储在按列索引的二维数组中。 我们必须首先扫描树以确定最小和最大列索引。 然后，对于每一列，按行排序节点，然后按值排序。 虽然这种方法可行，但很麻烦，需要多次传递，并且涉及对每列进行重复排序。 

最佳方法利用单次遍历（BFS 或 DFS）来收集节点及其`(row, col)`坐标。 我们可以将节点存储在字典中，键为`col`，带有元组列表`(row, val)`作为价值观。 遍历完之后，我们对每个列表进行排序`(row, val)`然后仅提取值。 BFS 是首选，因为它自然地逐层遍历，自动维护行顺序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N log N + C log C) | O(N log N + C log C) | O(N + C) | 按列将节点存储在二维数组中，按行和值对每列进行排序 |
 | 最佳 | O(N log N) | O(N log N) | O(N) | BFS 或 DFS 收集 (row, col, val) 元组，然后按行和值对每个列列表进行排序 |

 ## 算法演练

 1.初始化一个字典`columns`将每个列索引映射到一个列表`(row, value)`元组。 同时初始化一个队列`q`对于 BFS，包含`(root, row=0, col=0)`。 
2.执行BFS：当队列不为空时，将节点及其节点出队`(row, col)`位置。 附加`(row, node.val)`到`columns[col]`。 
3. 如果该节点有左子节点，则入队`(node.left, row+1, col-1)`。 如果有正确的孩子，则入队`(node.right, row+1, col+1)`。 
4. BFS完成后，收集所有列索引，从小到大排序。 
5. 对于每个列索引，对列表进行排序`(row, val)`首先按行，然后按值，并仅提取节点值。 
6. 返回排序列的列表作为最终的垂直顺序遍历。 

**为什么有效**：BFS 确保我们逐级处理节点，从而保留行顺序。 使用`(row, val)`当多个节点共享相同的行和列时，元组允许正确排序。 最后对键进行排序并提取值可以保证垂直顺序和从上到下的顺序，处理包括重复在内的所有边缘情况。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import defaultdict, deque
from typing import List, Optional

class Solution:
    def verticalTraversal(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        columns = defaultdict(list)
        q = deque([(root, 0, 0)])  # node, row, col

        while q:
            node, row, col = q.popleft()
            columns[col].append((row, node.val))
            if node.left:
                q.append((node.left, row + 1, col - 1))
            if node.right:
                q.append((node.right, row + 1, col + 1))

        result = []
        for col in sorted(columns.keys()):
            sorted_col = sorted(columns[col], key=lambda x: (x[0], x[1]))
            result.append([val for row, val in sorted_col])

        return result
```实现首先初始化 BFS 队列和列字典。 每个节点都与其一起存储`(row, col)`坐标。 BFS 之后，列按顺序处理，每个列表按行和值排序。 最终结果是通过以正确的顺序提取节点值来构建的。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
import "sort"

func verticalTraversal(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }

    type NodeInfo struct {
        row int
        val int
    }

    columns := map[int][]NodeInfo{}
    queue := []struct {
        node *TreeNode
        row  int
        col  int
    }{{root, 0, 0}}

    for len(queue) > 0 {
        curr := queue[0]
        queue = queue[1:]
        columns[curr.col] = append(columns[curr.col], NodeInfo{curr.row, curr.node.Val})

        if curr.node.Left != nil {
            queue = append(queue, struct {
                node *TreeNode
                row  int
                col  int
            }{curr.node.Left, curr.row + 1, curr.col - 1})
        }
        if curr.node.Right != nil {
            queue = append(queue, struct {
                node *TreeNode
                row  int
                col  int
            }{curr.node.Right, curr.row + 1, curr.col + 1})
        }
    }

    cols := make([]int, 0, len(columns))
    for k := range columns {
        cols = append(cols, k)
    }
    sort.Ints(cols)

    result := make([][]int, 0, len(cols))
    for _, col := range cols {
        nodes := columns[col]
        sort.Slice(nodes, func(i, j int) bool {
            if nodes[i].row != nodes[j].row {
                return nodes[i].row < nodes[j].row
            }
            return nodes[i].val < nodes[j].val
        })
        vals := make([]int, len(nodes))
        for i, n := range nodes {
            vals[i] = n.val
        }
        result = append(result, vals)
    }

    return result
}
```Go 实现遵循相同的 BFS 方法。 主要区别包括使用切片而不是双端队列、定义结构体`(row, val)`信息，并使用`sort.Slice`对每列中的节点进行排序。 Nil root 处理是显式的，并且切片用于动态存储。
