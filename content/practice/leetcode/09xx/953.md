[LeetCode 953 题](https://leetcode.com/problems/verifying-an-alien-dictionary/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们验证单词列表是否按照自定义字母顺序排序，而不是按照正常的英文字母顺序排序。 

在正常的字典顺序中，使用标准字母表从左到右比较字符。 在这里，外星语言仍然使用小写英文字母，但这些字母的相对顺序可能完全不同。 这`order`字符串告诉我们每个字符在这种外星语言中的排名。 

输入包括：

 -`words`，用外星语言编写的字符串数组
 -`order`，长度为 26 的字符串，定义外星字母顺序

 目标是确定单词是否已根据此自定义词典顺序排序。 

词典比较的工作方式与词典比较完全相同：

 - 从左到右一一比较字符
 - 第一个不同的字符决定哪个单词更小
 - 如果所有比较的字符都相同，则较短的单词被认为较小

 例如：

 -`"app"`出现在之前`"apple"`-`"apple"`之前没有来过`"app"`限制相对较小：

 - 最多100字
 - 每个单词的长度最多为20
 - 仅使用小写英文字母

 这些限制告诉我们，性能并不是极其关键，但我们仍然应该设计一个干净、高效的解决方案。 由于字母大小固定为 26，因此构建字符排名查找表的成本非常低。 

一些边缘情况尤其重要：

 - 一个单词可能是另一个单词的前缀
 - 第一个不同的字符可能出现在字符串中很晚的地方
 - 相邻的单词可能相同
 - 外国人的顺序可能与正常的英语顺序有很大不同

 幼稚的实现很容易在前缀情况下失败，例如`["apple", "app"]`，其中所有共享字符都匹配，但较长的单词错误地首先出现。 

## 方法

 ### 蛮力方法

 强力解决方案将直接模拟每个相邻单词对的词典比较。 

对于每对：

 1. 逐个比较字符
 2. 找到第一个不同的字符
 3. 使用外星字母确定排序
 4. 如果不存在不同字符，则比较字长

 为了确定字符顺序，暴力方法可以重复搜索`order`使用类似操作的字符串`order.index(char)`每当比较字符时。 

这是正确的，因为字典顺序仅取决于第一个不同的字符。 然而，反复扫描`order`字符串效率低下，因为每个字符查找都会花费成本`O(26)`时间。 

尽管限制很小，但这种重复搜索是不必要的。 

### 最佳方法

 关键的见解是字符比较频繁发生，因此我们应该将外来字母预处理为直接查找结构。 

我们创建一个哈希图：```
character -> rank
```例如：```
h -> 0
l -> 1
a -> 2
...
```现在每个字符比较变成`O(1)`而不是扫描整个字母串。 

然后，我们使用这些排名按字典顺序比较每对相邻的单词。 

这提供了一个干净且有效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N × M × 26) | O(1) | O(1) | 反复扫描顺序字符串进行字符排名 |
 | 最佳 | O(N × M) | O(26) | 使用哈希映射进行恒定时间字符排名 |

 在哪里：

-`N`= 字数
 -`M`= 最大字长

 ## 算法演练

 1. 创建一个名为的哈希图`rank`。 

该地图存储了外星字母表中每个字符的位置。 

例如：```
rank['h'] = 0
rank['l'] = 1
rank['a'] = 2
```这允许字符之间进行恒定的时间比较。 
2. 迭代所有相邻的单词对。 

由于排序列表只需要每个相邻对都正确排序，因此我们比较：```
words[0] vs words[1]
words[1] vs words[2]
...
```3.逐个比较两个单词。 

在两个单词的最小长度上使用循环。 

在每个位置：

 - 如果字符相等，则继续
 - 如果字符不同：

 - 比较他们的外星人等级
 - 如果第一个单词的字符具有较大的排名，则返回`False`- 否则，该对的排序正确，因此停止检查该对
 4. 处理前缀大小写。 

如果所有比较的字符都匹配，则排序完全取决于长度。 

例子：```
"app" < "apple"
```如果所有共享字符匹配后第一个单词较长，则排序无效。 
5. 如果所有相邻对都有效，则返回`True`。 

### 为什么它有效

 字典顺序完全由两个字符串之间的第一个不同字符决定。 如果所有字符都与较短单词的长度匹配，则较短单词必须排在前面。 

该算法直接对每个相邻的单词对实现此规则。 由于当且仅当每个相邻对都已排序时，序列才会被排序，因此检查所有相邻对可以保证正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        rank = {char: index for index, char in enumerate(order)}

        for i in range(len(words) - 1):
            word1 = words[i]
            word2 = words[i + 1]

            found_difference = False

            for j in range(min(len(word1), len(word2))):
                if word1[j] != word2[j]:
                    if rank[word1[j]] > rank[word2[j]]:
                        return False

                    found_difference = True
                    break

            if not found_difference and len(word1) > len(word2):
                return False

        return True
```实现首先构建`rank`字典。 此预处理步骤将外星字母表转换为恒定时间查找。 

外循环迭代相邻的单词对，因为验证每个相邻的单词对足以确认整个列表已排序。 

对于每一对，内部循环逐个位置地比较字符。 

如果角色不同，他们的外星人等级会立即决定顺序。 如果第一个单词包含排名较大的字符，则列表不会排序，因此函数返回`False`。 

变量`found_difference`跟踪是否遇到不匹配。 这对于正确处理前缀情况很重要。 如果不存在不同的字符并且第一个单词较长，则排序无效。 

如果所有对都通过检查，则函数返回`True`。 

## 解决方案```go
func isAlienSorted(words []string, order string) bool {
	rank := make(map[byte]int)

	for i := 0; i < len(order); i++ {
		rank[order[i]] = i
	}

	for i := 0; i < len(words)-1; i++ {
		word1 := words[i]
		word2 := words[i+1]

		foundDifference := false

		minLength := len(word1)
		if len(word2) < minLength {
			minLength = len(word2)
		}

		for j := 0; j < minLength; j++ {
			if word1[j] != word2[j] {
				if rank[word1[j]] > rank[word2[j]] {
					return false
				}

				foundDifference = true
				break
			}
		}

		if !foundDifference && len(word1) > len(word2) {
			return false
		}
	}

	return true
}
```Go 实现遵循与 Python 版本相同的逻辑。 

一个显着的区别是 Go 字符串以字节为索引，这在这里完美地工作，因为问题只保证小写英文字母。 

Go 不提供内置的`min()`旧版本中的整数函数，因此最小长度是手动计算的。 

哈希映射使用`map[byte]int`因为字符是用字节表示的。

 ## 边缘情况

 ### 前缀关系

 当一个单词是另一个单词的前缀时，就会出现最重要的边缘情况之一。 

例如：```
["apple", "app"]
```所有共享字符都匹配，因此较短的单词应排在第一位。 仅比较不同字符的幼稚实现可能会错误地接受此排序。 

该实现显式检查所有比较的字符是否匹配以及第一个单词是否更长。 如果两者都为真，则返回`False`。 

### 相同的词

 相邻的词可能完全相同。 

例如：```
["same", "same"]
```不存在不同的字符，但长度相等，因此排序有效。 

该实现自然地处理了这个问题，因为前缀检查仅在第一个单词严格较长时才会失败。 

### 自定义字母顺序

 外星字母可能与标准英语顺序完全不同。 

例如：```
order = "zyxwvutsrqponmlkjihgfedcba"
```在这种语言中，`'z'`是最小的字符。 

意外依赖正常 ASCII 排序的解决方案将会失败。 该实现通过始终使用预先计算的比较字符来完全避免此问题`rank`映射而不是直接的字符比较。
