[LeetCode 第 919 题](https://leetcode.com/problems/complete-binary-tree-inserter/)

 **难度：** 🟡 中等
 **主题：** 树、广度优先搜索、设计、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们设计一种数据结构，允许插入**完整二叉树**，同时保持其完整性。 完全二叉树是所有层都被完全填充的树，除了最后一层，它是从左到右填充的。 关键要求是每次插入后，树必须保持完整。 

给定一个现有完全二叉树的根，我们必须实现三个操作。 一、构造函数`CBTInserter(TreeNode root)`用树初始化我们的数据结构。 第二，`insert(int val)`添加一个新节点，同时保持树完整并返回其父节点的值。 第三，`get_root()`只是返回树的根节点。 

约束告诉我们树最初最多可以有 1000 个节点，我们可以调用`insert`最多10,000次。 这表明在每次插入时执行完整树遍历的解决方案会太慢，因为每次插入重复遍历可能会产生 O(n) 时间复杂度，累积到 O(n * 10^4)。 另外，所有节点值都是小的非负整数，这不影响结构，但简化了存储。 

边缘情况包括具有单个节点的树（插入必须首先创建根的子节点）、最后一层部分填充的几乎完整的树（插入必须正确找到最左边的可用位置）以及填充多个级别的多个顺序插入。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是每次我们想要插入节点时在树上执行**层序遍历**（BFS）。 我们将所有节点放入队列中并从左到右遍历。 我们遇到的第一个没有左或右子节点的节点将成为新节点的父节点。 这保证了正确性，因为 BFS 确保我们总是逐级处理节点，首先填充最左边的可用位置。 

虽然这种方法是正确的，但效率很低。 每次插入都需要遍历整个树，每次插入的时间复杂度为 O(n)。 如果插入次数很多，总时间可能会变成 O(n * k)，其中 k 是插入次数，导致性能不可接受。 

### 最佳方法

 关键的见解是**维护当前少于两个子节点的候选父节点队列**。 在初始化期间，我们执行单个 BFS 来填充此队列。 然后，每次插入只需将队列中的第一个节点作为父节点，将新节点添加为其左或右子节点，如果父节点现在有两个子节点，我们将其从队列中删除。 新节点始终附加到队列末尾，因为它可能会在将来的插入中成为父节点。 

这种方法很有效，因为每次插入都是 O(1) 摊销的。 最初的 BFS 遍历是 O(n)，但这只会发生一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | 每次插入 O(n) | O(n) | 每次遍历整棵树寻找插入点 |
 | 最佳| O(n) 初始化后每次插入 O(1) | O(n) | 维护少于 2 个子节点的节点队列以快速插入 |

 ## 算法演练

 1. **初始化（构造函数）**：从根节点开始。 执行树的层序遍历 (BFS)。 对于每个节点，如果它的子节点少于两个，请将其添加到**候选队列**。 该队列代表有资格接收新子节点的节点。 
2. **插入操作**：将候选队列最前面的节点作为父节点。 如果没有左子节点，则添加新节点作为其左子节点。 否则，将其添加为右子节点。 如果父级现在有两个子级，请将其从队列中删除。 将新插入的节点追加到队列的后面，因为它将来可能会收到子节点。 返回父节点的值。 
3. **获取根操作**：简单地返回初始化时存储的根节点。 

**为什么有效**：不变的是候选队列始终包含少于两个子节点的节点，按级别顺序遍历排序。 这确保每次插入都会填充树中最左边的可用位置，从而保持完整性。 

## Python 解决方案```python
from collections import deque
from typing import Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class CBTInserter:

    def __init__(self, root: Optional[TreeNode]):
        self.root = root
        self.candidates = deque()
        queue = deque([root])
        while queue:
            node = queue.popleft()
            if not node.left or not node.right:
                self.candidates.append(node)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

    def insert(self, val: int) -> int:
        parent = self.candidates[0]
        new_node = TreeNode(val)
        if not parent.left:
            parent.left = new_node
        else:
            parent.right = new_node
            self.candidates.popleft()
        self.candidates.append(new_node)
        return parent.val

    def get_root(self) -> Optional[TreeNode]:
        return self.root
```**说明**：构造函数填充一个双端队列`candidates`具有少于两个子节点的节点。`insert`始终使用第一个候选节点并相应地添加新节点。 插入后，双端队列将被更新以保持不变性。`get_root`只是返回存储的根。 

## 解决方案```go
package main

type TreeNode struct {
    Val int
    Left *TreeNode
    Right *TreeNode
}

type CBTInserter struct {
    root *TreeNode
    candidates []*TreeNode
}

func Constructor(root *TreeNode) CBTInserter {
    c := CBTInserter{root: root}
    queue := []*TreeNode{root}
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        if node.Left != nil {
            queue = append(queue, node.Left)
        }
        if node.Right != nil {
            queue = append(queue, node.Right)
        }
        if node.Left == nil || node.Right == nil {
            c.candidates = append(c.candidates, node)
        }
    }
    return c
}

func (this *CBTInserter) Insert(val int) int {
    parent := this.candidates[0]
    newNode := &TreeNode{Val: val}
    if parent.Left == nil {
        parent.Left = newNode
    } else {
        parent.Right = newNode
        this.candidates = this.candidates[1:]
    }
    this.candidates = append(this.candidates, newNode)
    return parent.Val
}

func (this *CBTInserter) Get_root() *TreeNode {
    return this.root
}
```**说明**：Go 使用切片而不是双端队列，因此第一个元素通过索引 0 访问。第一个元素的删除是通过切片完成的 (`this.candidates = this.candidates[1:]`）。 否则，逻辑将完全反映 Python 版本。 

## 工作示例

 ### 示例 1

 输入操作：```
["CBTInserter", "insert", "insert", "get_root"]
[[[1, 2]], [3], [4], []]
```**第1步：构造函数**

 - 队列 = [1, 2]
 - BFS = [1, 2] 之后的候选双端队列，因为节点 1 只有左子节点，节点 2 有 0 个子节点

 **步骤 2：插入(3)**

 - 父= 1
 - 节点 3 变为 1.right
 - 节点 1 现在有两个子节点 → 从候选节点中删除 1
 - 向候选人追加 3
 - 返回1

 候选人 = [2, 3]

 **步骤 3：插入(4)**

 - 父= 2
 - 节点 4 变为 2.left
 - 节点 2 只剩下 → 保留在候选者中
 - 向候选人追加 4
 - 返回2

 候选人 = [2, 3, 4]

 **步骤4：get_root()**

 - 返回具有树结构的根节点：```
        1
       / \
      2   3
     /
    4
```## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) 初始化，O(1) 每次插入 | 初始化在n个节点上进行BFS； 后续插入仅触及候选节点 |
 | 空间| O(n) | 在最坏的情况下，候选节点队列可以增长到 O(n) |

 该空间主要通过将候选者存储在双端队列或切片中来实现。 每次插入只更新指针，因此非常高效。
