 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组的所有排列`nums`这样数组就是**平方**，这意味着每对相邻元素的总和是**完全平方**。 换句话说，对于一个排列`[a1, a2, a3, ..., an]`， 每个`a[i] + a[i+1]`一定是一个完美的正方形。 该数组可能包含重复项，如果存在元素不同的任何索引，则两个排列被视为不同。 

输入是一个整数数组，受以下约束`1 <= nums.length <= 12`和`0 <= nums[i] <= 10^9`。 这告诉我们，暴力排列（长度为阶乘）是可行的，只是因为数组相对较小，但需要仔细处理重复项。 大值在`nums`意味着我们需要使用算术仔细检查完美平方，而不是预先计算所有可能性。 

重要的边缘情况包括所有元素都相同的数组、元素无法形成任何方形排列的数组以及具有多个重复项的数组，其中排列可能看起来相同，除非仔细进行重复数据删除。 

## 方法

 ### 蛮力

 暴力方法会产生所有排列`nums`并检查每一项的所有相邻和是否都是完全平方数。 这种方法工作正常，因为它详尽地检查了所有可能性，但效率低下。 排列数为`n!`，检查每个排列涉及计算相邻元素的总和。 此外，除非我们处理重复项，否则会导致计数过多。 

### 最佳方法

 关键的观察是我们不需要盲目地生成所有排列。 相反，我们可以**使用回溯构建排列**，仅扩展保持平方属性的序列。 为了有效地管理重复项，我们对数组进行排序并使用计数器来跟踪剩余元素，避免重复序列。 这种方法本质上是一个带有修剪的 DFS：我们只沿着有效的路径继续递归。 预先计算哪些元素可以跟随其他元素作为完美平方和的一部分也可以优化解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 生成所有排列并检查每个 |
 | 最佳| O(n * 2^n) | O(n * 2^n) | O(n + n^2) | O(n + n^2) | 通过修剪和重复处理进行回溯 |

 ## 算法演练

 1. **对元素进行排序和计数**：排序有助于管理重复项。 对每个元素进行计数可以让我们有效地了解每个步骤可以使用哪些元素。 
2. **构建邻接图**：对于每对`(x, y)`在`nums`，检查是否`x + y`是一个完美的正方形。 将有效的下一个元素存储在哈希映射中以进行快速查找。 
3. **回溯功能**：通过根据邻接图选择仍然可用（计数> 0）并且是有效的下一个元素的元素，递归地尝试构建序列。 
4. **使用计数进行重复数据删除**：选择元素时，减少其计数。 递归调用后，恢复计数。 如果元素与前一个元素相同且前一个元素尚未使用，则跳过这些元素以防止生成相同的序列。 
5. **基本情况**：当序列长度等于`n`，增加结果计数器。 
6. **返回总数**：所有递归调用完成后，计数器包含唯一平方排列的总数。 

**为什么有效**：通过仅扩展有效序列并使用计数来管理重复项，我们确保我们计数的每个序列都是有效且唯一的。 回溯保证了所有可能性都被探索。 

## Python 解决方案```python
from collections import Counter
from math import isqrt
from typing import List

class Solution:
    def numSquarefulPerms(self, nums: List[int]) -> int:
        def is_square(n: int) -> bool:
            root = isqrt(n)
            return root * root == n
        
        n = len(nums)
        counter = Counter(nums)
        adj = {x: [] for x in counter}
        
        for x in counter:
            for y in counter:
                if is_square(x + y):
                    adj[x].append(y)
        
        def backtrack(x: int, remaining: int) -> int:
            counter[x] -= 1
            if remaining == 1:
                counter[x] += 1
                return 1
            total = 0
            for y in adj[x]:
                if counter[y] > 0:
                    total += backtrack(y, remaining - 1)
            counter[x] += 1
            return total
        
        result = 0
        for x in counter:
            result += backtrack(x, n)
        return result
```**实施演练**：`is_square`函数检查一个数是否是完全平方数。 我们构建一个元素计数器和一个有效下一个元素的邻接列表。 递归`backtrack`函数通过递减计数、探索有效的延续以及随后恢复计数来构建序列。 我们从每个唯一元素开始递归并对所有有效序列求和。 

## 解决方案```go
package main

import (
	"math"
)

func numSquarefulPerms(nums []int) int {
	n := len(nums)
	counter := make(map[int]int)
	for _, x := range nums {
		counter[x]++
	}
	
	adj := make(map[int][]int)
	for x := range counter {
		for y := range counter {
			if isSquare(x + y) {
				adj[x] = append(adj[x], y)
			}
		}
	}
	
	var backtrack func(x, remaining int) int
	backtrack = func(x, remaining int) int {
		counter[x]--
		if remaining == 1 {
			counter[x]++
			return 1
		}
		total := 0
		for _, y := range adj[x] {
			if counter[y] > 0 {
				total += backtrack(y, remaining-1)
			}
		}
		counter[x]++
		return total
	}
	
	result := 0
	for x := range counter {
		result += backtrack(x, n)
	}
	return result
}

func isSquare(n int) bool {
	root := int(math.Sqrt(float64(n)))
	return root*root == n
}
```**Go-specific notes**: We use maps for the counter and adjacency list. Integer arithmetic ensures no overflow because Go ints are large enough for sums of numbers within constraints. Slices are used instead of lists, and recursion is handled similarly to Python.

 ## 工作示例

 ### 示例 1

 输入：`[1,17,8]`邻接图：```
1: [8]        (1+8=9)
8: [1,17]     (8+1=9, 8+17=25)
17: [8]       (17+8=25)
```从1开始：`1 -> 8 -> 17`有效

 从8点开始：`8 -> 1 -> 17`无效（1+17=18 不是平方），`8 -> 17 -> 8`无效（不能重复使用）

 从17号开始：`17 -> 8 -> 1`有效

 输出：2

 ### 示例 2

 输入：`[2,2,2]`邻接图：`2: [2]`(2+2=4)

 唯一的顺序：`[2,2,2]`输出：1

 ## 边缘情况

 **所有元素相同**：数组如`[2,2,2]`只允许一个序列。 未能进行重复数据删除将会导致计算过多。 我们使用计数器来处理重复项。 

**单一元素**：`[5]`应该返回 1，因为单个元素通常满足邻接规则。 递归中的基本情况确保了这一点。 

**没有有效序列**：`[1,2,3,4]`不能形成方形对。 回溯中的早期修剪可以防止不必要的探索和返回
