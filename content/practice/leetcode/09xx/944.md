[LeetCode 944 题](https://leetcode.com/problems/delete-columns-to-make-sorted/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 该问题给了我们一个字符串数组，其中每个字符串的长度完全相同。 如果我们将所有字符串逐个字符垂直放置，这些字符串将形成一个矩形网格。 

例如，给定：```
["abc", "bce", "cae"]
```网格变为：```
abc
bce
cae
```每列都是通过从所有行的同一索引中获取字符来形成的。 任务是确定有多少列未按非降序字典顺序排序。 

如果从上到下移动，每个字符都小于或等于其下方的字符，则认为列已排序。 换句话说，对于每对相邻的行：```
strs[row][col] <= strs[row + 1][col]
```必须成立。 

如果任何相邻对违反此排序规则，则必须删除该列。 最终的答案是此类无效列的总数。 

限制相对较小：

 - 最多可以有 100 个字符串
 - 每个字符串的长度最多为 1000

 这意味着总网格大小最多为：```
100 * 1000 = 100,000 characters
```检查每个字符一次或几次的解决方案是完全可以接受的。 

一些边缘情况很重要：

 - 单个字符串意味着每列都会自动排序，因为没有要比较的相邻行。 
- 单列网格仍然遵循相同的逻辑。 
- 允许重复字符，因为排序要求是非递减的，而不是严格递增的。 
- 列可能在第一次比较时立即失败，因此在列检查中有效的提前终止非常有用。 

## 方法

 ### 蛮力方法

 解决问题最直接的方法就是对每一列进行独立检查。 

对于每一列：

 1. 比较每对相邻的行。 
2. 如果在任何时候上部字符大于下部字符，则将该列标记为无效。 
3. 统计存在多少无效列。 

这种方法对于约束来说已经足够有效，因为网格中的每个单元最多被检查一次。 

这里的强力术语是指直接模拟问题陈述，而不需要任何额外的优化技巧或预处理。 

正确性很简单，因为问题定义本身表明，如果任何相邻对无序，则列无效。 

### 最佳解决方案的关键见解

 重要的观察结果是每列完全独立于其他列。 

一列是否排序不会影响任何其他列。 因此，我们不需要复杂的数据结构或排序操作。 我们只需垂直扫描每一列并验证其顺序。 

一旦我们在一列中发现一个反转：```
strs[row][col] > strs[row + 1][col]
```我们已经知道必须删除该列，因此我们可以立即停止检查该列。 

这为我们提供了对网格的干净且高效的线性扫描。

 ## 算法演练

 1. 确定行数和列数。 

行数很简单`len(strs)`，列数为`len(strs[0])`因为所有字符串的长度都相等。 
2. 初始化已删除列的计数器。 

该变量跟踪有多少列违反排序条件。 
3. 迭代每一列。 

对于每个列索引`col`，我们将验证从上到下的字符是否保持非递减顺序。 
4. 比较当前列中的相邻行。 

对于每行索引`row`从`0`到`rows - 2`， 比较：```
strs[row][col]
```和：```
strs[row + 1][col]
```5. 检测无效订单。 

如果：```
strs[row][col] > strs[row + 1][col]
```那么该列不会按字典顺序排序。 

增加删除计数器并立即停止检查当前列，因为一次违规就足以使其无效。 
6. 继续，直到处理完所有列。 

检查每一列后，返回无效列的总数。 

### 为什么它有效

 该算法之所以有效，是因为当且仅当每个相邻字符对都按非递减顺序排列时，列才会被排序。 通过检查一列中所有相邻的行对，我们充分验证了排序条件。 如果即使有一对违反了排序规则，则必须删除该列。 由于每一列都经过独立、详尽的检查，因此最终计数保证是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        rows = len(strs)
        cols = len(strs[0])

        deletions = 0

        for col in range(cols):
            for row in range(rows - 1):
                if strs[row][col] > strs[row + 1][col]:
                    deletions += 1
                    break

        return deletions
```实现首先确定网格的尺寸。 由于所有字符串的长度相同，因此第一个字符串提供总列数。 

外循环独立地迭代每一列。 对于每一列，内部循环从上到下比较相邻行。 

关键条件是：```python
strs[row][col] > strs[row + 1][col]
```如果这是真的，则该列违反了字典顺序，必须删除。 删除计数器递增，并且`break`语句立即停止对该列的进一步检查，因为不需要进行额外的比较。 

最后，处理完所有列后，该函数返回无效列的总数。 

## 解决方案```go
func minDeletionSize(strs []string) int {
    rows := len(strs)
    cols := len(strs[0])

    deletions := 0

    for col := 0; col < cols; col++ {
        for row := 0; row < rows-1; row++ {
            if strs[row][col] > strs[row+1][col] {
                deletions++
                break
            }
        }
    }

    return deletions
}
```Go 实现遵循与 Python 解决方案完全相同的逻辑。 

Go 中的字符串可以直接索引，因为输入只包含小写英文字母，这些字母是单字节 ASCII 字符。 这避免了与 UTF-8 多字节字符相关的复杂性。 

该算法使用恒定的额外内存，并按照前面所述的方式逐列扫描网格。

 ## 边缘情况

 单行输入是一种重要的边缘情况，因为没有可以比较的相邻行。 每列都会自动排序。 有缺陷的实现可能会错误地假设至少存在两行并尝试进行无效比较。 此实现自然地处理这种情况，因为内部循环从`0`到`rows - 2`，当`rows == 1`。 

包含相同相邻字符的列是另一个微妙的情况。 该问题需要非递减的字典顺序，而不是严格的递增顺序。 这意味着像这样的值：```
a
a
b
```是完全有效的。 实现正确使用了条件：```
>
```而不是：```
>=
```这确保相同的字符保持有效。 

完全降序的列也很重要，因为算法应该提前终止以提高效率。 考虑：```
z
a
```第一次比较已经证明该列无效。 实现使用`break`发现违规后立即进行，避免不必要的比较并提高实际性能。
