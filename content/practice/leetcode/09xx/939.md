 **难度：** 🟡 中等
 **主题：** 数组、哈希表、数学、几何、排序

 ## 解决方案

 ## 问题理解

 该问题为我们提供了 2D 平面上不同点的集合。 每个点都表示为`[x, y]`， 在哪里`x`是水平坐标并且`y`是纵坐标。 

我们的任务是确定可以使用其中四个点作为角形成的轴对齐矩形的最小可能面积。 轴对齐的矩形意味着：

 - 它的边必须平行于X轴和Y轴
 - 矩形不能旋转
 - 四个角必须全部存在于输入中

 对于有角的矩形：

 -`(x1, y1)`-`(x1, y2)`-`(x2, y1)`-`(x2, y2)`该面积是：$\text{Area} = |x_2 - x_1| \times |y_2 - y_1|$目标是返回所有有效矩形中最小的此类区域。 如果无法形成矩形，则返回`0`。 

约束条件很重要：

 - 最多`500`点
 - 坐标可以大到`40000`- 所有点都是独一无二的

 由于点的数量相对较少，算法围绕`O(n²)`是合理的，但暴力方法周围`O(n³)`或者`O(n⁴)`变得太贵了。 

一些边缘情况很重要：

 - 点可能少于四个，无法形成矩形。 
- 点可能全部位于一条线上。 
- 可能存在多个矩形，我们必须返回最小的面积。 
- 大坐标值需要仔细的面积计算，尽管标准整数算术就足够了。 
- 宽度或高度为零的矩形是不可能的，因为所有点都是唯一的。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是检查四个点的每种可能组合，并确定它们是否形成有效的矩形。 

对于四个点形成一个轴对齐的矩形：

 - 必须有两个不同的 x 坐标
 - 必须有两个不同的 y 坐标
 - 所有四个角组合都必须存在

 这是可行的，因为此问题中的每个有效矩形都必须遵循该结构。 

然而，检查每个四倍点的成本非常昂贵。 和`n`点，有：$\binom{n}{4}$可能的四点组。 

为了`n = 500`，这变得太大了。 

### 最佳解决方案的关键见解

 轴对齐矩形完全由两个对角点确定。 

假设我们选择两个点：

 -`(x1, y1)`-`(x2, y2)`如果：

-`x1 != x2`-`y1 != y2`那么这两个点可以作为矩形的对角。 

其余两个所需的角是：

 -`(x1, y2)`-`(x2, y1)`因此，我们可以：而不是检查四个点的组：

 1. 迭代每对点
 2. 将它们视为可能的对角线
 3、检查另外两个角是否存在

 哈希集允许恒定时间查找点，从而提高效率。

 ## 算法演练

 ### 最优算法

 1. 将每个点存储在哈希集中。 

我们需要快速检查任意点的存在性。 哈希集允许平均`O(1)`查找时间。 

每个点都存储为一个元组`(x, y)`。 
2. 初始化一个变量来跟踪最小面积。 

我们可以从无穷大开始，以便任何有效的矩形都成为当前的最佳答案。 
3. 迭代每对点。 

对于每对：

 -`(x1, y1)`-`(x2, y2)`我们检查它们是否可以形成矩形对角线。 
4. 跳过无效的对角线。 

如果：

 -`x1 == x2`-`y1 == y2`那么这些点位于同一垂直或水平线上，因此它们不能形成矩形的对角。 
5. 计算另外两个所需的角点。 

矩形需要：

 -`(x1, y2)`-`(x2, y1)`6. 检查哈希集中是否存在两个角点。 

如果两个点都存在，则存在有效的矩形。 
7. 计算矩形面积。 

面积为：$|x_2-x_1|\times|y_2-y_1|$1. 如果新矩形更小，则更新最小面积。 
2. 处理完所有对后：

 - 如果找到矩形，则返回最小面积
 - 否则返回`0`### 为什么它有效

 每个轴对齐的矩形都恰好有两个对角。 通过迭代每对点，我们保证考虑每个可能的矩形对角线。 

对于任何有效的矩形，其他两个角是唯一确定的。 因为我们检查哈希集中是否存在这些角，所以最终会发现每个有效的矩形。 

由于我们计算每个有效矩形的面积并保持最小值，因此最终答案必须是可能的最小矩形面积。 

## Python 解决方案```python
from typing import List

class Solution:
    def minAreaRect(self, points: List[List[int]]) -> int:
        point_set = set()

        for x, y in points:
            point_set.add((x, y))

        min_area = float("inf")
        n = len(points)

        for i in range(n):
            x1, y1 = points[i]

            for j in range(i + 1, n):
                x2, y2 = points[j]

                # Cannot form a rectangle diagonal
                if x1 == x2 or y1 == y2:
                    continue

                # Check if the other two corners exist
                if (x1, y2) in point_set and (x2, y1) in point_set:
                    area = abs(x2 - x1) * abs(y2 - y1)
                    min_area = min(min_area, area)

        return 0 if min_area == float("inf") else min_area
```实现首先将所有点转换为哈希集。 这是关键的优化，因为矩形验证依赖于快速点存在检查。 

嵌套循环迭代每对点。 每对都被视为潜在的矩形对角线。 

如果两个点共享相同的 x 坐标或 y 坐标，则它们不能形成轴对齐矩形的对角线，因此算法会立即跳过它们。 

对于有效的对角线，代码会计算两个缺失的角点并检查这两个角点是否都存在于集合中。 如果存在，则存在一个矩形并计算其面积。 

每当发现更小的矩形时，最小面积就会更新。 

最后，如果没有发现矩形，则该值保持无穷大，因此算法返回`0`。 

## 解决方案```go
package main

import "math"

func minAreaRect(points [][]int) int {
	pointSet := make(map[[2]int]bool)

	for _, point := range points {
		x, y := point[0], point[1]
		pointSet[[2]int{x, y}] = true
	}

	minArea := math.MaxInt32
	n := len(points)

	for i := 0; i < n; i++ {
		x1, y1 := points[i][0], points[i][1]

		for j := i + 1; j < n; j++ {
			x2, y2 := points[j][0], points[j][1]

			// Cannot form a rectangle diagonal
			if x1 == x2 || y1 == y2 {
				continue
			}

			// Check if the other two corners exist
			if pointSet[[2]int{x1, y2}] &&
				pointSet[[2]int{x2, y1}] {

				area := abs(x2-x1) * abs(y2-y1)

				if area < minArea {
					minArea = area
				}
			}
		}
	}

	if minArea == math.MaxInt32 {
		return 0
	}

	return minArea
}

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}
```Go 实现遵循与 Python 版本相同的逻辑。 

由于Go不支持元组作为映射键，因此解决方案使用固定大小的数组`[2]int`来代表一个点。 

最小面积初始化为`math.MaxInt32`。 如果没有找到矩形，函数返回`0`。 

一个帮手`abs`包含 function 是因为 Go 在标准库中没有提供整数绝对值函数。

 ## 边缘情况

 ### 不存在矩形

 当这些点从未形成四个有效的矩形角时，就会出现常见的边缘情况。 例如：```
[[1,1],[2,2],[3,3]]
```所有点都位于对角线上，因此不存在轴对齐的矩形。 

有缺陷的实现可能会错误地假设任何四个点都可以形成一个矩形。 该解决方案通过显式检查是否存在两个所需的角点来避免该问题。 

如果没有找到矩形，`min_area`保持无穷大并且算法正确返回`0`。 

### 点共享同一行或同一列

 共享相同 x 坐标或 y 坐标的点对不能用作矩形对角线。 

例如：```
(1,1), (1,3)
```这些点形成垂直线段，而不是对角线。 

没有条件的话：```
if x1 == x2 or y1 == y2:
    continue
```该算法可能会错误地尝试计算面积为零的退化矩形。 

### 存在多个矩形

 输入可能包含许多有效的矩形，算法必须返回最小的面积。 

例如：```
[[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]]
```有两个有效的矩形：

 - 面积`4`- 区域`2`一个幼稚的实现可能会在找到第一个矩形后停止。 该解决方案而是评估每个有效矩形并不断更新最小面积，保证正确的结果。
