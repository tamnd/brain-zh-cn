[LeetCode 958 题](https://leetcode.com/problems/check-completeness-of-a-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 树、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的二叉树是否是_完全二叉树_。 完全二叉树具有特定的结构属性：除了最后一层之外，每一层都被完全填充，并且在最后一层中，所有节点都尽可能地显示在左侧。 输入是`root`二叉树的结构，它是指向树的顶部节点的指针或引用。 预期输出是一个布尔值`true`如果树是完整的并且`false`否则。 

约束告诉我们，树将具有 1 到 100 个节点，并且所有节点值都是最大 1000 的正整数。这个规模足够小，线性时间复杂度 O(n) 的算法将是高效的。 

重要的边缘情况包括以下树：

 1.只有一个节点，是简单完整的。 
2. 完全填满，也就是完整的。 
3.最后一层缺少节点，但左对齐，完成。 
4、最后一层中间缺少节点，不完整。 

该问题保证树非空，所以我们不需要处理`None`作为输入。 

## 方法

 暴力方法可能涉及遍历树并逐级收集节点，然后在遍历后检查节点是否对齐以形成完整的结构。 例如，可以执行级别顺序遍历，记录`None`丢失子节点的位置，并确保在 a 之后没有节点出现`None`。 这可行，但需要额外的簿记，并且稍微不太优雅。 

最佳方法的关键观察是，在广度优先遍历期间，一旦`None`遇到子节点时，按级别顺序排列的所有后续节点也必须是`None`使树完整。 这种观察允许使用队列进行简单的线性扫描来检查完整性，而无需额外的复杂性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 记录结构的同时进行层序遍历，然后检查对齐 |
 | 最佳 | O(n) | O(n) | BFS，先None后提前停止，简单而优雅|

 ## 算法演练

 1. 以根节点初始化队列。 该队列将用于层序遍历（BFS）。 
2. 通过重复使节点出队来执行 BFS。 
3. 如果节点不是`None`，将其左右孩子放入队列中。 
4. 如果节点是`None`，设置一个标志，指示所有后续节点也必须是`None`。 
5. 继续处理队列。 如果一个非`None`设置标志后找到节点，返回`false`因为这违反了完整性。 
6. 如果队列的处理没有违反规则，则返回`true`。 

**为什么有效：** 不变的是，在完全二叉树中，一旦在任何级别观察到丢失的子节点，则在级别顺序遍历中不应存在更多的子节点。 BFS 确保我们逐级处理节点，因此遇到`None`随后是一个非`None`节点直接违反了完整性属性。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
from typing import Optional

class Solution:
    def isCompleteTree(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        
        queue = deque([root])
        end = False
        
        while queue:
            node = queue.popleft()
            if node:
                if end:
                    return False
                queue.append(node.left)
                queue.append(node.right)
            else:
                end = True
        
        return True
```该实现初始化 BFS 队列并迭代所有节点。 什么时候`None`遇到时，`end`设置标志以强制所有后续节点也必须是`None`。 这直接映射到算法步骤。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isCompleteTree(root *TreeNode) bool {
    if root == nil {
        return true
    }

    queue := []*TreeNode{root}
    end := false

    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]

        if node != nil {
            if end {
                return false
            }
            queue = append(queue, node.Left)
            queue = append(queue, node.Right)
        } else {
            end = true
        }
    }
    return true
}
```Go 解决方案反映了 Python 方法。 Go 需要显式处理`nil`指针和切片用于队列，并使用附加操作将子项排队。

 ## 边缘情况

 1. **单节点树：**这是最简单的完全二叉树。 该算法通过用根初始化队列来处理它。 由于没有孩子，BFS 成功完成并返回`true`。 
2. **最后一层部分填充左对齐：** 如果最后一层有一些节点缺失但所有节点都左对齐，BFS会遇到`None`在所有有效节点之后。 这`end`标志确保没有进一步的非`None`节点出现，函数正确返回`true`。 
3. **最后一层部分填充但不左对齐：** 如果最后一层左侧缺少节点但右侧存在节点，BFS会遇到`None`随后是一个非`None`节点。 这`end`flag 检测到这种违规，并且函数返回`false`。 这可以防止形状不规则的边缘情况出现误报。
