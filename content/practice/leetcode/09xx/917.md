[LeetCode 917 题](https://leetcode.com/problems/reverse-only-letters/)

 **难度：** 🟢简单
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们仅反转字符串中的英文字母，同时将所有非字母字符固定在其原始位置。 换句话说，字母会移动，但符号、数字和标点符号仍准确地保留在它们开始的位置。 

例如，考虑字符串`"ab-cd"`。 这些字母是`"a"`,`"b"`,`"c"`， 和`"d"`。 仅反转字母给出`"d"`,`"c"`,`"b"`,`"a"`。 连字符保留在索引处`2`，所以最终的结果就变成了`"dc-ba"`。 

输入是单个字符串`s`，应用此转换后输出是另一个相同长度的字符串。 该问题保证字符串长度在`1`和`100`，因此输入尺寸非常小。 尽管约束足够小，多种解决方案都可以有效地工作，但目标仍然是设计一种简洁且最佳的方法。 

字符串中的字符属于 ASCII 值范围`[33, 122]`，表示字符串可以包含大写字母、小写字母、数字、标点符号和符号。 只有英文字母才能参与逆转。 

预先识别一些边缘情况很重要。 完全不包含字母的字符串应该保持不变，因为没有什么可以反转。 仅包含字母的字符串的行为应类似于正常的全字符串反转。 混合大小写字母在反转过程中必须保留其确切字符，这意味着大写字母保持大写，小写字母保持小写，因为我们正在移动字符，而不是转换它们。 如果不仔细处理指针移动，连续的符号或数字也可能会产生错误。 

## 方法

 一种简单的暴力方法是首先将字符串中的所有字母提取到一个单独的列表中，反转该列表，然后通过用反转列表中的字符替换字母位置来重建字符串。 非字母字符直接复制到结果中。 

这是有效的，因为提取的列表恰好包含需要反转的字母。 在重建过程中，每个字母位置接收相反序列中的下一个字符，而非字母字符保持不变。 

尽管这种方法对于给定的约束是完全可以接受的，但它需要对字符串进行额外的传递以及与字母数量成比例的额外存储。 我们可以通过使用两指针技术反转字母来在概念上做得更好。 

关键的见解是只有字母应该移动，所有非字母字符都应该保持固定。 这自然建议使用左侧的一个指针和右侧的另一个指针。 每当两个指针都指向字母时，我们就会交换它们并向内移动。 如果任一指​​针落在非字母字符上，我们会跳过它，因为它的位置必须保持不变。 

这种方法避免了显式地单独存储颠倒的字母。 相反，它直接交换字符串两端的匹配字母。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 提取字母，反转它们，重建字符串 |
 | 最佳| O(n) | O(n) | 两个指针交换字母并跳过符号 |

 尽管最佳方法在 Python 和 Go 中仍然使用 O(n) 空间，因为字符串是不可变的并且必须转换为可变数组，但它避免了存储单独的反向字母集合。 

## 算法演练

 1. 将输入字符串转换为可变字符数组。 

字符串在 Python 和 Go 中都是不可变的，因此我们不能直接在原始字符串中交换字符。 将字符串转换为列表或字节切片允许就地修改。 
2. 初始化两个指针。 

左指针从数组的开头开始，右指针从数组的末尾开始。 在搜索要交换的字母时，这些指针将向彼此移动。 
3. 移动左指针直至到达一个字母。 

如果当前字符不是英文字母，则它必须保持固定在其原始位置。 因此，我们跳过它，继续将左指针向前移动。 
4. 移动右侧指针直至到达一个字母。 

同样的逻辑也适用于右侧。 非字母字符将被跳过，因为它们不应移动。 
5. 交换两个字母。 

一旦两个指针都指向字母，就交换它们的值。 这会将正确的反转字母放置到目标位置。 
6. 将两个指针向内移动。 

成功交换后，递增左指针并递减右指针，以便算法继续处理剩余的字符。 
7. 继续直至指针交叉。 

当指针相遇或交叉时，所有字母都已正确反转，整个过程完成。 
8. 将字符数组转换回字符串。 

返回最终转换后的字符串。 

### 为什么它有效

该算法在整个执行过程中保持一个重要的不变量：每个处理过的字母对都已被放置到其最终的反转位置，而所有非字母字符保持不变。 由于左指针总是从前面找到下一个可用字母，而右指针总是从后面找到下一个可用字母，因此每次交换都正确地模拟了反转字母序列。 当指针交叉时，每个字母都已翻转一次。 

## Python 解决方案```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        characters = list(s)

        left = 0
        right = len(characters) - 1

        while left < right:
            while left < right and not characters[left].isalpha():
                left += 1

            while left < right and not characters[right].isalpha():
                right -= 1

            characters[left], characters[right] = (
                characters[right],
                characters[left],
            )

            left += 1
            right -= 1

        return "".join(characters)
```实现首先将字符串转换为名为的列表`characters`。 这使得字符交换成为可能，因为 Python 字符串不能直接修改。 

两个指针，`left`和`right`，在列表的两端初始化。 主循环继续进行`left < right`。 

在循环内部，第一个内部循环使左指针前进，直到它指向一个字母。 第二个内部循环向后移动右指针，直到它也指向一个字母。 这些检查可确保非字母字符保持固定。 

一旦两个指针都引用字母，字符就会交换。 交换后，两个指针向内移动以继续处理字符串的剩余部分。 

最后，修改后的字符列表被连接回字符串并返回。 

## 解决方案```go
func reverseOnlyLetters(s string) string {
    characters := []byte(s)

    left := 0
    right := len(characters) - 1

    for left < right {
        for left < right && !isLetter(characters[left]) {
            left++
        }

        for left < right && !isLetter(characters[right]) {
            right--
        }

        characters[left], characters[right] =
            characters[right], characters[left]

        left++
        right--
    }

    return string(characters)
}

func isLetter(ch byte) bool {
    return (ch >= 'a' && ch <= 'z') ||
        (ch >= 'A' && ch <= 'Z')
}
```Go 解决方案遵循与 Python 版本相同的算法结构。 由于 Go 字符串是不可变的，因此该字符串被转换为`[]byte`用于就地交换的切片。 

而不是像 Python 那样使用内置的字母检查`isalpha()`, 辅助函数`isLetter`显式检查字节是否属于大写或小写英文字母的 ASCII 范围。 

Go 没有像 Python 那样的元组赋值，但它仍然支持切片元素的简洁交换语法。

 ## 边缘情况

 一个非常重要的边缘情况是根本不包含字母的字符串，例如`"123-+="`。 幼稚的实现可能会尝试不必要的交换，或者在搜索不存在的字母时失败。 双指针方法可以自然地处理这个问题，因为两个指针都会跳过非字母字符直到它们交叉，从而使字符串保持不变。 

另一个重要的情况是只包含字母的字符串，例如`"abcdef"`。 在这种情况下，算法的行为应该与标准字符串反转完全相同。 由于每个字符都符合字母的要求，因此指针不断地从两端交换字符，直到反转完成。 

连续的非字母字符也会产生微妙的错误。 例如，`"a---b"`中间包含多个符号。 不正确的指针移动可能会意外地交换符号或过早停止。 该实现通过在执行任何交换之前重复推进指针直到找到有效字母来避免这种情况。 

混合大写和小写字母是另一个潜在的混乱来源。 该算法必须在反转位置时保留准确的字符值。 例如，`"a-Bc"`变成`"c-Ba"`， 不是`"C-ba"`或任何大小写转换的变体。 由于实现直接交换字符而不是修改它们，因此大小写保存会自动发生。
