 # LeetCode 965 - 无值二叉树

 ## 问题理解

 该问题给出了二叉树的根节点，并询问该树是否是“单值”的。 如果树中的每个节点都包含完全相同的整数值，则二叉树被视为单值。 

简而言之，我们需要检查树中的每个节点并验证所有节点值是否与一个公共值匹配。 即使单个节点有不同的值，答案也一定是`false`。 否则，如果所有值都相同，则答案为`true`。 

输入表示标准二叉树结构，其中每个节点包含：

 - 整数值
 - 对左孩子的参考
 - 对右孩子的引用

 预期输出是一个布尔值：

 -`true`如果所有节点包含相同的值
 -`false`如果至少有一个节点不同

 限制相对较小：

 - 树包含之间`1`和`100`节点
 - 节点值范围为`0`到`99`因为树的大小很小，所以我们不需要非常先进的优化技术。 简单的树遍历就足够了。 

预先识别一些边缘情况很重要。 只有一个节点的树始终是单值的，因为不存在不同的值。 缺少孩子的树，例如倾斜的树或稀疏的树，仍然需要适当的遍历。 当大多数值相等但单个深度节点不同时，会发生另一个重要情况，错误地停止遍历的幼稚实现可能会错过这一点。 

该问题保证树至少有一个节点，因此`root`永远不会`None`。 

## 方法

 ### 蛮力方法

 强力解决方案将首先遍历整个树并将所有节点值收集到列表或集合中。 遍历之后，我们可以检查所有收集到的值是否相同。 

例如，我们可以执行 DFS 遍历并将每个节点值插入到一个集合中。 如果最终设定的尺寸是`1`，那么这棵树是单值的。 否则，就不是。 

此方法可以正常工作，因为集合会自动删除重复项。 如果树中存在多个不同值，则集合大小将大于 1。 

然而，这个解决方案使用了不必要的额外内存，因为我们存储每个不同的值，即使我们只需要将值与根值进行比较。 

### 最佳方法

 关键的见解是每个节点只需要与一个参考值（特别是根的值）进行比较。 

我们可以遍历树并立即验证每个节点是否与根值匹配，而不是存储所有值。 如果发现任何不匹配，我们可以返回`false`立即执行，而无需继续不必要的遍历。 

这是可行的，因为单值树的定义完全取决于所有节点是否等于单个值。 由于根已经提供了该目标值，因此每个其他节点只需要进行一次比较。 

深度优先搜索是一个自然的选择，因为树是递归构造的。 我们在携带期望值的同时递归地验证左子树和右子树。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 遍历树并将值存储在集合中 |
 | 最佳| O(n) | O(h) | 直接比较的DFS遍历|

 这里，`n`是节点数，`h`是树的高度。 

## 算法演练

 1. 将根节点的值存储为每个节点必须匹配的目标值。 
2. 从根开始执行深度优先搜索遍历。 
3.对于每个访问过的节点，首先检查该节点是否是`None`。 如果是，则返回`true`因为空子树不能违反单值属性。 
4. 将当前节点的值与目标值进行比较。 
5. 如果值不同，立即返回`false`因为树不再是单值的。 
6. 递归验证左子树。 
7. 递归验证右子树。 
8. 返回`true`仅当两个递归子树检查都返回时`true`。 

递归遍历确保树中的每个节点都被检查一次。 

### 为什么它有效

 该算法保持每个访问节点必须等于根值的不变量。 如果发现不匹配，则不变量被破坏，算法立即返回`false`。 

如果遍历完成后没有发现任何不同的值，则每个节点都与根值匹配，这完全满足单值树的定义。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        target_value = root.val

        def dfs(node: Optional[TreeNode]) -> bool:
            if node is None:
                return True

            if node.val != target_value:
                return False

            return dfs(node.left) and dfs(node.right)

        return dfs(root)
```实现首先将根节点的值存储在`target_value`。 该值成为所有其他节点必须匹配的参考。 

嵌套的`dfs`函数执行递归遍历。 底壳手柄`None`通过返回节点`True`，因为空子树总是有效的。 

每个非空节点都与`target_value`。 如果发生不匹配，函数立即返回`False`。 

然后递归调用验证两个子子树。 逻辑性`and`确保两个子树都必须满足单值条件，当前子树才有效。 

最后算法从根节点开始遍历并返回结果。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isUnivalTree(root *TreeNode) bool {
	targetValue := root.Val

	var dfs func(node *TreeNode) bool

	dfs = func(node *TreeNode) bool {
		if node == nil {
			return true
		}

		if node.Val != targetValue {
			return false
		}

		return dfs(node.Left) && dfs(node.Right)
	}

	return dfs(root)
}
```Go 实现遵循与 Python 版本相同的递归 DFS 策略。 

一个显着的区别是递归的显式函数变量声明：```go
var dfs func(node *TreeNode) bool
```这个声明是必需的，因为 Go 需要在赋值之前定义递归函数变量。 

Go指针自然代表树节点引用，所以`nil`使用检查代替Python的`None`。 

由于节点值是非常小的整数，因此整数溢出不是这个问题的问题。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 递归调用堆栈取决于树的高度 |

 时间复杂度是线性的，因为算法可能需要检查树中的每个节点一次。 

空间复杂度来自递归深度。 在平衡树中，高度约为`log n`。 在最坏的情况下，例如完全倾斜的树，高度变为`n`。

 ## 边缘情况

 单节点树是一种重要的边缘情况，因为没有可比较的子节点。 某些实现错误地假设必须至少进行一次比较。 此实现可以自然地处理这种情况，因为 DFS 访问单个节点，确认其与目标值匹配，然后返回`true`。 

倾斜的树是另一个重要的例子。 一棵树可能类似于一个深度接近于的链表`n`。 递归遍历仍然必须正确访问每个节点。 由于约束将树限制为仅 100 个节点，因此递归深度在这里是完全安全的。 

在结构深处具有一个不同节点的树可能会在不完整遍历中暴露错误。 例如，如果解决方案仅检查根的直接子级，则可能会错误地返回`true`。 此实现递归地探索整个树，保证甚至可以检测到深层嵌套的不匹配。 

树木稀疏和儿童失踪也很重要。 有些节点可能只有一个子节点，而其他节点则没有。 该实现使用以下方法安全地处理这些情况`None`或者`nil`基本情况，确保丢失的子项不会导致运行时错误或不正确的比较。
