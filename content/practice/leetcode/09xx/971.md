[LeetCode 问题 971](https://leetcode.com/problems/flip-binary-tree-to-match-preorder-traversal/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们操作一棵二叉树，使其**前序遍历**匹配给定的序列，称为`voyage`。 换句话说，我们给定了一棵树和一个整数列表，我们想看看是否可以通过**翻转节点**（交换它们的左右子节点）来转换树，以便当我们按前序（根→左→右）遍历树时，节点值的序列完全匹配`voyage`。 

输入由一个二叉树组成`n`节点，其中每个节点值都是唯一的，范围从 1 到`n`，和一个数组`voyage`长度`n`包含从 1 到 的唯一值`n`。 输出应该是我们翻转以实现匹配遍历的节点值列表。 如果**不可能**匹配`voyage`，输出应该是`[-1]`。 

问题约束相对较小（`n <= 100`），这表明递归或深度优先方法将足够有效。 每个节点值都是唯一的，这保证了在遍历过程中我们总能识别子树是否正确或需要翻转。 

需要考虑的重要边缘情况包括：

 1. 树已经处于正确的预序状态，不需要翻转。 
2. 错配发生在翻转无法修复顺序的节点处。 
3. 树只有一个节点或者是倾斜的（全部向左或全部向右），这测试了简单的基本情况。 

## 方法

 **暴力方法**将递归地尝试每个节点处的翻转的每种组合，生成所有可能的前序遍历并与`voyage`。 虽然正确，但这种方法的计算成本很高，因为每个节点都可以翻转或不翻转，从而导致`O(2^n)`组合。 

**最佳方法**利用**DFS 遍历和贪婪翻转**。 我们按预序遍历树，同时跟踪位置`voyage`。 在每个节点，如果左子节点存在但其值与下一个值不匹配`voyage`，我们知道我们必须翻转当前节点。 这避免了对无效路径的不必要探索，并且仅在需要时翻转。 如果节点的值在任何一点与期望值不匹配，则遍历是不可能的，我们返回`[-1]`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归探索所有翻转组合并检查预购 |
 | 最佳| O(n) | O(n) | 贪婪翻转的单次 DFS 传递由`voyage`|

 ## 算法演练

 1.初始化一个索引指针`i`跟踪当前位置`voyage`。 
2.初始化一个空列表`flipped`存储我们翻转的节点。 
3. 定义一个以节点作为输入的递归 DFS 函数。 
4. 如果节点是`None`， 返回`True`因为空子树的匹配很简单。 
5. 如果节点的值不匹配`voyage[i]`， 返回`False`因为不可能匹配。 
6. 增量`i`因为当前节点与期望值匹配。 
7. 如果左孩子存在且其值不匹配`voyage[i]`（下一个期望值），翻转节点：交换其左右子节点，并将其值记录在`flipped`。 
8. 对左孩子递归调用DFS。 如果返回的话`False`， 返回`False`。 
9. 对右孩子递归调用DFS。 如果返回的话`False`， 返回`False`。 
10.如果所有递归调用成功，则返回`True`。 
11、DFS完成后，如果返回`True`，返回`flipped`列表。 否则，返回`[-1]`。 

**为什么有效：** 该算法维护一个不变量，即已遍历的树部分与`voyage`直至索引`i`。 通过仅在下一个期望值与左子节点不匹配时进行翻转，我们可以最大限度地减少翻转并保证正确性。 每个节点被访问一次，保证线性时间。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def flipMatchVoyage(self, root: Optional[TreeNode], voyage: List[int]) -> List[int]:
        flipped = []
        i = 0

        def dfs(node: Optional[TreeNode]) -> bool:
            nonlocal i
            if not node:
                return True
            if node.val != voyage[i]:
                return False
            i += 1
            if node.left and i < len(voyage) and node.left.val != voyage[i]:
                flipped.append(node.val)
                node.left, node.right = node.right, node.left
            if dfs(node.left) and dfs(node.right):
                return True
            return False

        return flipped if dfs(root) else [-1]
```**说明：**`dfs`函数递归地确保当前子树与`voyage`。 仅当左子节点的值与下一个期望值不匹配时，我们才会翻转节点。 指数`i`跟踪我们的位置`voyage`。 这`flipped`list 累积被翻转的节点。 如果在任何时候节点值不匹配`voyage[i]`，我们返回`[-1]`表明失败。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func flipMatchVoyage(root *TreeNode, voyage []int) []int {
    flipped := []int{}
    i := 0

    var dfs func(node *TreeNode) bool
    dfs = func(node *TreeNode) bool {
        if node == nil {
            return true
        }
        if node.Val != voyage[i] {
            return false
        }
        i++
        if node.Left != nil && i < len(voyage) && node.Left.Val != voyage[i] {
            flipped = append(flipped, node.Val)
            node.Left, node.Right = node.Right, node.Left
        }
        return dfs(node.Left) && dfs(node.Right)
    }

    if dfs(root) {
        return flipped
    }
    return []int{-1}
}
```**Go 特定注释：**`nil`被用来代替`None`。 切片附加句柄动态增长`flipped`列表。 这`dfs`函数是一个闭包捕获`i`和`flipped`。 

## 工作示例

 **示例1：**`root = [1,2], voyage = [2,1]`从根开始`1`， 预期的`voyage[0] = 2`。 不匹配立即→返回`[-1]`。 

**示例2：**`root = [1,2,3], voyage = [1,3,2]`- 根`1`比赛`voyage[0]`, 增量`i = 1`。 
- 左孩子`2`≠`voyage[1] = 3`， 翻动`1`。 记录`1`在`flipped`。 
- 向左递归：现在`3`比赛`voyage[1]`, 增量`i = 2`。 
- 左右递归：`None`→ 返回`True`。 
- 右递归：`2`比赛`voyage[2]`, 增量`i = 3`。 完毕。 返回`[1]`。 

**示例3：**`root = [1,2,3], voyage = [1,2,3]`- 根`1`比赛`voyage[0]`, 增量`i = 1`。 
- 左孩子`2`比赛`voyage[1]`, 增量`i = 2`。 
- 右孩子`3`比赛`voyage[2]`, 增量`i = 3`。 无需翻转 → 返回`[]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 在 DFS 期间，每个节点仅被访问一次 |
 | 空间| O(n) | 最坏情况倾斜树中的递归堆栈，加上翻转列表 |

 该算法非常高效，因为它只遍历每个节点一次，并在每个节点执行常数时间操作。
