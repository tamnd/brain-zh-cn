[LeetCode 931 题](https://leetcode.com/problems/minimum-falling-path-sum/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求通过一条路径的任何下降路径的最小总和`n x n`整数矩阵。 下降路径定义为从第一行中的任何元素开始并逐行移动到最后一行的元素序列。 在每一步中，路径可能会直接向下、向左对角或向右对角移动。 输入是方阵，因此行数等于列数，每个元素可以是正数、负数或零。 输出是一个整数，表示任何有效下降路径可实现的最小总和。 

约束表明矩阵可以达到`100 x 100`大小，元素值范围为`-100`到`100`。 这意味着对所有下降路径进行强力枚举在计算上是不可行的，因为可能有多达`3^(n-1)`路径，呈指数级增长。 

重要的边缘情况包括大小矩阵`1 x 1`、全部为负数的矩阵，以及最小路径紧贴边缘的矩阵，测试对角线移动。 

## 方法

 **暴力方法**将从第一行中的每个元素开始递归地探索每条下降路径。 对于每个位置`(row, col)`，该算法将递归计算位置的最小路径和`(row+1, col-1)`,`(row+1, col)`， 和`(row+1, col+1)`，然后返回这些和加上当前元素的最小值。 虽然正确，但此方法的速度呈指数级缓慢（`O(3^n)`）因为它多次重新计算相同的子问题。 

**最佳方法**使用动态规划（DP）。 关键的见解是，到给定单元格的最小下降路径总和仅取决于到其正上方的三个单元格的最小总和。 我们可以构建一个 DP 矩阵，其中每个单元存储以该单元结束的最小下降路径总和。 通过逐行迭代，我们可以根据前一行中的值更新每个单元格。 这将时间复杂度降低到`O(n^2)`因为每个单元都被访问一次，空间复杂度可以为`O(n^2)`或优化为`O(n)`使用单个数组来存储前一行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(3^n) | O(3^n) | O(n) | 递归探索所有路径 |
 | 最优 (DP) | O(n^2) | O(n^2) | O(n^2) 或 O(n) | 存储每个单元格的最小路径总和 |

 ## 算法演练

 1.初始化一个DP矩阵`dp`大小相同`matrix`并复制第一行`matrix`因为到达第一行中任何单元格的最小路径总和就是值本身。 
2. 迭代每一行`i`从`1`到`n-1`。 
3. 对于每一列`j`在行中`i`，计算到达的最小路径和`(i, j)`作为`matrix[i][j] + min(dp[i-1][j], dp[i-1][j-1] if j>0 else inf, dp[i-1][j+1] if j<n-1 else inf)`。 
4. 填充DP矩阵后，最小下降路径和为最后一行中的最小值`dp`。 
5. 返回该最小值。 

**为什么有效**：在每一步，算法都保证`dp[i][j]`存储到达该单元格的最小路径总和，这确保了当我们到达最后一行时，我们已经有效地考虑了所有可能的路径。 这是一种标准的自下而上的动态编程技术，利用重叠的子问题。 

## Python 解决方案```python
from typing import List

class Solution:
    def minFallingPathSum(self, matrix: List[List[int]]) -> int:
        n = len(matrix)
        if n == 1:
            return matrix[0][0]
        
        dp = [row[:] for row in matrix]
        
        for i in range(1, n):
            for j in range(n):
                left = dp[i-1][j-1] if j > 0 else float('inf')
                up = dp[i-1][j]
                right = dp[i-1][j+1] if j < n-1 else float('inf')
                dp[i][j] += min(left, up, right)
        
        return min(dp[-1])
```该实现首先处理矩阵为的边缘情况`1x1`。 DP 矩阵被初始化为`matrix`。 对于每个单元格`(i, j)`从第二行开始，通过考虑三个潜在的前驱来计算到达该单元的最小总路径。 通过查找最后一行中的最小值获得最终答案。 

## 解决方案```go
import "math"

func minFallingPathSum(matrix [][]int) int {
    n := len(matrix)
    if n == 1 {
        return matrix[0][0]
    }
    
    dp := make([][]int, n)
    for i := range matrix {
        dp[i] = make([]int, n)
        copy(dp[i], matrix[i])
    }
    
    for i := 1; i < n; i++ {
        for j := 0; j < n; j++ {
            left, up, right := math.MaxInt, dp[i-1][j], math.MaxInt
            if j > 0 {
                left = dp[i-1][j-1]
            }
            if j < n-1 {
                right = dp[i-1][j+1]
            }
            dp[i][j] += min(left, up, right)
        }
    }
    
    minVal := dp[n-1][0]
    for _, val := range dp[n-1] {
        if val < minVal {
            minVal = val
        }
    }
    return minVal
}

func min(a, b, c int) int {
    if a < b {
        if a < c {
            return a
        }
        return c
    }
    if b < c {
        return b
    }
    return c
}
```Go 版本镜像了 Python 实现。 它将 DP 矩阵初始化为`matrix`并根据三个潜在的前辈迭代更新每个单元。 这`min`辅助函数选择三个整数中的最小值，并且`math.MaxInt`代表边缘情况的无穷大。 

## 工作示例

 ### 示例 1

 矩阵：```
[[2,1,3],
 [6,5,4],
 [7,8,9]]
```一步步DP：

 | 我\j | 0 | 1 | 2 |
 | ---| ---| ---| ---|
 | 0 | 2 | 1 | 3 |
 | 1 | 2+6=8 | 最小值(2,1,3)+5=6 | 1+4=5？ 等待重新计算 |```
Row 1:
dp[1][0] = 6+min(2,inf,1)=6+1=7
dp[1][1] = 5+min(2,1,3)=5+1=6
dp[1][2] = 4+min(1,3,inf)=4+1=5
Row 2:
dp[2][0] = 7+min(7,inf,6)=7+6=13
dp[2][1] = 8+min(7,6,5)=8+5=13
dp[2][2] = 9+min(6,5,inf)=9+5=14
```最后一行的最小值：`min(13,13,14)=13`。 

### 示例 2

 矩阵：```
[[-19,57],
 [-40,-5]]
```一步步DP：

 | 我\j | 0 | 1 |
 | ---| ---| ---|
 | 0 | -19 | -19 57 | 57
 | 1 | -40+分钟(-19,inf)=-59 | -5+分钟(-19,57)=-24 |

 最后一行的最小值：`-59`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^2) | O(n^2) | 我们对矩阵的每个单元格迭代一次，计算三个值的最小值。 |
 | 空间| O(n^2) | O(n^2) | DP 矩阵复制输入矩阵。 通过仅保留前一行，可以将 O(n) 减少到 O(n)。 |

 时间复杂度是二次的，因为我们必须考虑每行中的每个单元格。 空间复杂度最初是二次的，但由于每行仅依赖于前一行，因此我们可以将其优化为单个大小的数组`n`。
