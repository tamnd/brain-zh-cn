 **难度：** 🟡 中等
 **主题：** 字符串、堆栈、贪婪

 ## 解决方案

 ## 问题理解

 该问题要求我们确定使给定的括号字符串有效所需的最小括号插入次数。 如果每个左括号都被认为是有效的，则一串括号被认为是有效的`'('`有匹配的右括号`')'`并且这些对正确嵌套。 

输入`s`是一个仅包含以下内容的字符串`'('`和`')'`，并且长度保证在 1 到 1000 之间。预期输出是一个整数，表示需要在字符串中的任何位置添加才能使其有效的最小括号数。 

重要的边缘情况包括已经平衡的字符串（不需要插入）、仅具有左括号或仅右括号的字符串（需要等于字符串长度的插入）以及交替或嵌套的不平衡序列。 该问题保证我们只有`'('`和`')'`字符，因此我们不需要处理无效字符。 

## 方法

 暴力方法涉及通过在每个可能的位置插入括号来生成所有可能的字符串，直到字符串变得有效。 这种方法是正确的，因为它最终会探索所有有效的配置，但效率极低。 插入的数量随着字符串长度的增加而增加，使得这种方法对于长度达到 1000 的字符串不可行。 

最佳方法依赖于使用贪婪方法计算不匹配的括号。 我们可以遍历字符串，同时跟踪不匹配的左括号和右括号的数量。 当遇到`'('`，我们增加左括号的计数器。 当遇到`')'`，我们要么将它与之前见过的匹配`'('`如果可用或增加不匹配右括号的计数器。 末尾不匹配的左括号和右括号的总和给出了所需的最小插入次数。

 | 蛮力 | O(2^n) | O(2^n) | O(n) | 通过插入括号生成所有有效字符串，直到有效 |
 | 最佳| O(n) | O(1) | O(1) | 使用常量额外空间一次性计算不匹配的括号 |

 ## 算法演练

 1. 初始化两个计数器：`open_needed`追踪不匹配的`'('`和`close_needed`追踪不匹配的`')'`。 
2. 遍历字符串中的每个字符`s`。 
3. 如果角色是`'('`, 增量`open_needed`因为我们有一个额外的左括号需要匹配。 
4.如果角色是`')'`,检查是否有不匹配的`'('`配对。 如果`open_needed > 0`, 递减`open_needed`来匹配这个右括号。 否则，增加`close_needed`因为我们有一个不匹配的右括号。 
5、处理完所有字符后，总共需要插入的次数为`open_needed + close_needed`。 
6. 返回该总和作为结果。 

**为什么有效：** 该算法保持了以下不变式：`open_needed`始终表示到字符串中当前点为止不匹配的左括号的数量，并且`close_needed`计算不匹配的右括号。 到迭代结束时，它们的总和正确反映了平衡所有括号所需的最小插入量。 

## Python 解决方案```python
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        open_needed = 0
        close_needed = 0
        
        for char in s:
            if char == '(':
                open_needed += 1
            else:  # char == ')'
                if open_needed > 0:
                    open_needed -= 1
                else:
                    close_needed += 1
        
        return open_needed + close_needed
```该代码为不匹配的括号定义了两个计数器。 字符串中的每个字符都按顺序处理，根据它是左括号还是右括号更新这些计数器。 返回不匹配的开盘和闭盘的最终总和。 

## 解决方案```go
func minAddToMakeValid(s string) int {
    openNeeded := 0
    closeNeeded := 0

    for _, char := range s {
        if char == '(' {
            openNeeded++
        } else { // char == ')'
            if openNeeded > 0 {
                openNeeded--
            } else {
                closeNeeded++
            }
        }
    }

    return openNeeded + closeNeeded
}
```Go 实现反映了 Python 逻辑。 我们对不匹配的括号使用整数计数器，并使用范围循环迭代字符串。 Go 自动处理符文迭代，因此逻辑仍然简单。

 ## 边缘情况

 一个重要的边缘情况是带有交替括号的字符串，例如`")()("`。 此案例测试算法是否正确处理字符串开头和结尾处不匹配的括号。 实现正确递增`close_needed`在开始时和`open_needed`在最后。 

另一种边缘情况是完全由一种类型的括号组成的字符串，或者全部`'('`或全部`')'`。 如果不仔细计数，人们可能会错误地认为存在部分匹配。 计数器方法可确保准确计算每个不匹配的括号。 

第三种边缘情况是空字符串。 即使没有字符，该算法也会正确返回 0，因为不需要插入。 正确处理这一点可确保最小输入大小的稳健性。
