[LeetCode 986 题](https://leetcode.com/problems/interval-list-intersections/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、扫描线

 ## 解决方案

 ## 问题理解

 该问题给了我们两个闭区间列表。 每个区间表示为`[start, end]`，意味着每个值来自`start`通过`end`，包含在内，属于该区间。 

重要的保证是：

 - 每个单独的列表已按间隔开始时间排序
 - 同一列表内的间隔不会相互重叠
 - 间隔是闭间隔，这意味着端点算作间隔的一部分

 我们需要计算区间之间的所有交集`firstList`和间隔`secondList`。 

当两个区间重叠时，它们之间存在交集。 例如：

-`[1, 5]`和`[2, 7]`相交于`[2, 5]`-`[3, 4]`和`[5, 6]`不相交
 -`[5, 10]`和`[10, 12]`相交于`[10, 10]`因为区间是闭合的

 输出应包含两个列表之间的每个重叠间隔（按排序顺序）。 

约束相对较小，两个列表中最多有 1000 个间隔。 尽管这个大小在实践中允许二次解通过，但输入的结构强烈建议采用更有效的线性解。 由于两个列表都已排序且内部不重叠，因此我们可以与合并排序的合并阶段类似地处理它们。 

一些边缘情况很重要：

 - 一个或两个列表可能为空
 - 间隔可能正好触及一个端点
 - 一个区间可以完全包含另一个区间
 - 一个列表中的多个间隔可能会与另一列表中的不同间隔重叠
 - 列表在内部保证排序且不重叠，因此我们永远不需要合并同一列表中的间隔

 ## 方法

 ### 蛮力方法

 最直接的解决办法就是比较每个区间`firstList`针对每个区间`secondList`。 

对于每对间隔：

 - 将重叠开始计算为`max(start1, start2)`- 将重叠端计算为`min(end1, end2)`- 如果`overlap_start <= overlap_end`，然后区间相交

 这种方法是正确的，因为每个可能的对都会被检查，因此不会错过任何有效的交集。 

但时间复杂度较低。 如果有`n`间隔在`firstList`和`m`间隔在`secondList`，我们执行`n * m`比较。 

输入结构为我们提供了更好的利用机会。 由于两个列表都是排序的并且内部不相交，一旦我们知道哪个间隔首先结束，我们也知道哪个间隔永远不会与未来的间隔重叠。 

### 最佳两指针方法

 关键的观察是间隔是排序的并且在每个列表内不重叠。 

假设我们当前正在比较：

 -`firstList[i]`-`secondList[j]`检查它们的交集后，无论哪个间隔先结束，都可以安全地丢弃。 

为什么？ 

因为区间是排序的。 如果`firstList[i]`之前结束`secondList[j]`， 然后`firstList[i]`不可能与任何未来间隔重叠`secondList`，因为未来的间隔开始得更晚。 

这允许我们使用两个指针一次遍历两个列表。 

这将问题转化为线性时间合并式遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × m) | O(1) 不包括输出 | 比较每个区间对 |
 | 最佳 | O(n + m) | O(1) 不包括输出 | 两个指针利用排序顺序 |

 ## 算法演练

 1.初始化两个指针，`i`和`j`，都开始于`0`。 

指针`i`跟踪当前间隔`firstList`, 而指针`j`跟踪当前间隔`secondList`。 
2. 创建一个空结果列表。 

该列表将存储我们在遍历过程中发现的所有交叉点。 
3. 当两个指针都保持在边界内时继续处理。 

一旦列表用完，我们就会停止，因为此后不可能有更多的交叉点。 
4. 提取当前间隔。 

让：

-`first = firstList[i]`-`second = secondList[j]`5. 计算可能的重叠。 

重叠开始于：```
max(first.start, second.start)
```because the intersection cannot start before both intervals begin.

 重叠结束于：```
min(first.end, second.end)
```因为在任何一个间隔结束后，相交都无法继续。 
6. 检查间隔是否确实重叠。 

如果：```
overlap_start <= overlap_end
```那么存在有效的交集，我们将其附加到结果中。 
7. 将指针移至最先结束的时间间隔。 

如果`first.end < second.end`, 增量`i`。 

否则，增加`j`。 

这是最关键的优化。 首先结束的间隔不能与其他列表中的任何未来间隔重叠。 
8. 重复此操作，直到一个指针到达其列表的末尾。 

### 为什么它有效

 该算法保持了以下不变性：所有涉及指针之前的区间的交集`i`和`j`已经完全处理完毕。 

在每一步中，我们都会比较当前可能重叠的唯一一对间隔。 处理完它们后，具有较小端点的间隔永远不会与未来的间隔重叠，因为由于排序顺序，未来的间隔开始较晚。 因此，前进该指针永远不会跳过有效的交叉点。 

由于每个间隔最多处理一次，因此该算法可以在线性时间内正确找到所有交点。 

## Python 解决方案```python
from typing import List

class Solution:
    def intervalIntersection(
        self,
        firstList: List[List[int]],
        secondList: List[List[int]]
    ) -> List[List[int]]:
        
        i = 0
        j = 0
        
        intersections = []
        
        while i < len(firstList) and j < len(secondList):
            first_start, first_end = firstList[i]
            second_start, second_end = secondList[j]
            
            overlap_start = max(first_start, second_start)
            overlap_end = min(first_end, second_end)
            
            if overlap_start <= overlap_end:
                intersections.append([overlap_start, overlap_end])
            
            if first_end < second_end:
                i += 1
            else:
                j += 1
        
        return intersections
```该实现首先初始化两个指针，每个指针对应一个区间列表。 这些指针始终代表当前考虑的间隔。 

在循环内部，当前间隔被解包为可读的变量名称。 这提高了清晰度并使重叠逻辑更容易理解。 

重叠计算直接反映了区间交集的数学定义：

 - 重叠从较大的起始值开始
 - 重叠以较小的结束值结束

 如果计算的起点小于或等于计算的终点，则间隔重叠，并将交集追加到结果列表中。 

最后，算法将属于最先结束的区间的指针前进。 这确保我们永远不会重新访问无法再产生交叉点的区间。 

循环一直持续到一个列表被完全处理为止。 

## 解决方案```go
func intervalIntersection(firstList [][]int, secondList [][]int) [][]int {
    i := 0
    j := 0

    result := [][]int{}

    for i < len(firstList) && j < len(secondList) {
        firstStart := firstList[i][0]
        firstEnd := firstList[i][1]

        secondStart := secondList[j][0]
        secondEnd := secondList[j][1]

        overlapStart := max(firstStart, secondStart)
        overlapEnd := min(firstEnd, secondEnd)

        if overlapStart <= overlapEnd {
            result = append(result, []int{overlapStart, overlapEnd})
        }

        if firstEnd < secondEnd {
            i++
        } else {
            j++
        }
    }

    return result
}

func max(a int, b int) int {
    if a > b {
        return a
    }
    return b
}

func min(a int, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 实现遵循与 Python 版本相同的逻辑，但有一些特定于语言的细节值得注意。 

Go 没有提供内置的`min`和`max`整数函数，因此辅助函数是手动实现的。 

结果存储在整数切片的切片中，`[][]int`。 当发现重叠时，每个交叉间隔都会动态附加。 

Go 切片自然会处理空结果和填充结果，因此不需要对空输出进行特殊处理。 

整数溢出不是问题，因为区间边界完全符合 Go 的标准整数范围。

 ## 边缘情况

 ### 空输入列表

 一个或两个列表可能为空。 这是错误的常见来源，因为某些实现假设至少存在一个间隔。 

当前的实现通过循环条件自然地处理这个问题：```
while i < len(firstList) and j < len(secondList):
```如果任一列表为空，则循环永远不会执行，并立即返回空结果。 

### 单点交叉点

 由于间隔是闭合的，因此端点算作有效重叠。 

例如：```
[1,5] and [5,10]
```相交于：```
[5,5]
```一个常见的错误是使用：```
overlap_start < overlap_end
```而不是：```
overlap_start <= overlap_end
```该实现正确地包括单点交叉点。 

### 一个区间完全包含另一个区间

 一个列表中的区间可以完全包含另一列表中的区间。 

例子：```
[1,10] and [3,5]
```重叠逻辑仍然可以正常工作，因为：```
max(1,3) = 3
min(10,5) = 5
```生产`[3,5]`。 

指针前进逻辑也保持正确，因为较短的间隔首先结束，然后被安全地丢弃。
