 ## 解决方案

 ## 问题理解

 该问题要求我们对整数数组进行排序`arr`根据数量`1`每个元素的二进制表示中的位。 这意味着我们不是按整数值本身排序，而是按计数排序`1`s 的二进制形式。 如果两个数的个数相同`1`s，然后我们按数值升序对它们进行排序。 

输入是一个整数列表，每个整数的范围是 0 到 10,000，列表本身最多有 500 个元素。 输出是一个新数组，其中具有根据描述的规则排序的相同整数。 

关键约束足够小，带有自定义比较器的高效排序算法将表现良好。 可能需要仔细处理的边缘情况包括所有元素具有相同数量的数组`1`s、包含零的数组以及包含重复项的数组。 

## 方法

 蛮力方法首先需要计算`1`每个元素的位，存储此信息，然后根据此计数执行排序，然后进行数字比较以打破平局。 虽然简单，但如果实施不仔细，可能会效率低下。 

最佳解决方案利用 Python 或 Go 使用自定义键或比较器进行排序的能力。 关键的见解是，对于每个整数，排序标准可以表示为一个元组`(number_of_1_bits, integer_value)`。 对此类元组的数组进行排序可确保正确的排序，因为排序是按字典顺序排序的，首先按元组的数量进行排序`1`s，然后乘以整数值。 这种方法干净、高效且易于实施。 

| 方法| 时间复杂度| 空间复杂度| 笔记|

 ## 算法演练

 1. 迭代数组中的每个整数并计算其个数`1`位。 这可以使用内置函数来完成，例如`bin(x).count('1')`在 Python 中或`bits.OnesCount(uint(x))`在围棋中。 
2. 将每个整数与其相应的位数配对，有效地创建一个元组`(bit_count, integer)`。 
3. 对元组数组进行排序。 排序将优先考虑元组的第一个元素（位数）并使用第二个元素（整数值）来打破平局。 
4. 从已排序的元组中提取整数，得到最终的排序数组。 

为什么它有效：基于元组排序`(bit_count, integer)`保证所有数字首先按其二进制排序`1`s 计数，然后以数字方式获取相等的位计数。 元组排序确保了正确性，因为字典比较可以自然地处理平局。 

## Python 解决方案```python
from typing import List

class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        return sorted(arr, key=lambda x: (bin(x).count('1'), x))
```这个实现使用Python的`sorted()`以 lambda 作为键的函数。 lambda 构造一个元组`(bin(x).count('1'), x)`。 这里`bin(x).count('1')`计算数量`1`s 的二进制表示形式。 Python 按字典顺序对元组进行排序，因此这会自动根据整数值处理平局打破。 代码简洁、可读，并且在给定的约束下高效运行。 

## 解决方案```go
import (
    "sort"
    "math/bits"
)

func sortByBits(arr []int) []int {
    sort.Slice(arr, func(i, j int) bool {
        countI := bits.OnesCount(uint(arr[i]))
        countJ := bits.OnesCount(uint(arr[j]))
        if countI == countJ {
            return arr[i] < arr[j]
        }
        return countI < countJ
    })
    return arr
}
```在 Go 中，我们使用`sort.Slice`具有自定义比较器功能。 该函数计算数量`1`使用`bits.OnesCount`，这是一种高效的标准库方法。 如果两个元素具有相同的位数，则比较器首先返回较小的整数，以确保正确的平局顺序。

 ## 边缘情况

 1. **单元素数组**：如果数组仅包含一个数字，则函数必须将其原样返回。 这测试了算法处理最小输入并且不假设多个元素。 
2. **所有元素的数量相同`1`s**：数组如`[2,4,8,16]`应该按数字排序。 这种边缘情况确保了平局决胜逻辑是正确的。 
3. **数组包含零**：零有零`1`s。 如果排序正确，它必须首先出现，这可能会导致假设所有数字均为正且非零的算法出错。
