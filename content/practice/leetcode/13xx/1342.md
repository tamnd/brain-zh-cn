 # LeetCode 1342，将数字归零的步骤数

 ## 问题理解

 该问题给我们一个非负整数`num`并要求我们计算需要多少次操作才能将其一直减少到`0`。 

在每一步中，我们都应用以下两个规则之一：

 - 如果当前数字是偶数，则除以`2`- 如果当前数字是奇数，则减去`1`该过程持续进行，直到该值变为`0`。 答案就是执行的操作总数。 

例如，如果输入是`14`，序列变为：`14 → 7 → 6 → 3 → 2 → 1 → 0`这需要六次操作，所以输出是`6`。 

约束条件是：```
0 <= num <= 10^6
```这是一个相对较小的范围，这意味着即使是直接模拟方法也是完全可行的。 由于每个操作要么通过除以删除一位`2`或者通过减法将奇数变成偶数，数字减少得很快。 

一个重要的观察结果是，操作的数量与数字的二进制表示形式密切相关。 每个划分由`2`从右侧删除一个二进制数字，而每次减法处理一个奇数位。 

一些边缘情况很重要：

 -`num = 0`, 无需任何操作
 -`num = 1`，正好需要一次减法
 - 两个的幂，例如`8`反复分割干净
 - 奇数，例如`123`减法和除法交替进行

 该问题保证输入是有效的非负整数，因此我们不需要处理无效值或负数。 

## 方法

 ### 蛮力方法

 最直接的解决方案是完全按照描述模拟该过程。 

我们反复检查当前数字是偶数还是奇数：

 - 如果是偶数，则除以`2`- 否则，减去`1`我们维护一个计数器来跟踪已执行的操作数量。 一旦数字达到，循环就会停止`0`。 

这种方法是正确的，因为它直接按照问题陈述一步步进行。 执行的每个操作都完全符合所需的规则。 

虽然这被称为暴力模拟，但实际上它已经足够高效了，因为数量迅速减少。 每个划分由`2`将值减半，因此操作总数与数字中的位数成正比。 

### 最佳方法

 最佳方法使用相同的模拟思想，但认识到重要的位操作见解。 

一个数字是：

 - 即使它的最低有效位是`0`- 如果其最低有效位是奇数`1`我们可以使用按位运算来代替模运算：

 -`num & 1`检查奇偶校验
 -`num >>= 1`除以`2`这是可行的，因为将二进制数右移一位会删除最低有效位，这相当于整数除以`2`。 

该算法在概念上保持相同，但位操作对于此问题来说非常自然，因为这些操作直接对应于二进制行为。

 ## 算法演练

 1. 初始化变量`steps`到`0`。 

该变量将计算在数字变为之前执行了多少次操作`0`。 
2. 继续循环 while`num > 0`。 

只要数字不为零，我们仍然需要更多的操作。 
3. 检查数字是偶数还是奇数。 

我们可以使用以下方法确定这一点：```
num & 1
```如果结果是`0`，数字是偶数。 否则，那就奇怪了。 
4. 如果数字是偶数，则除以`2`。 

使用位操作：```
num >>= 1
```这会将所有位向右移动一位，相当于整数除以`2`。 
5. 如果数字是奇数，则减去`1`。 

这会将奇数转换为偶数，以便将来进行除法运算。 
6. 增量`steps`每次操作后。 

每一次减法或除法都算作一步。 
7.循环结束后，返回`steps`。 

此时，数量已变为`0`，所以总计数就是答案。 

### 为什么它有效

 该算法是正确的，因为每次迭代都完全执行问题陈述所需的操作。 如果数字是偶数，则除以`2`是强制性的。 如果数字是奇数，则减去`1`是强制性的。 由于每个操作都会严格减少数量，因此该过程最终必须终止于`0`。 计数器准确记录每一次操作，因此最终结果是正确的。 

## Python 解决方案```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        steps = 0

        while num > 0:
            if num & 1:
                num -= 1
            else:
                num >>= 1

            steps += 1

        return steps
```实现首先初始化一个`steps`计数器跟踪操作次数。 

这`while`循环继续，直到数字变为`0`。 在循环内部，我们使用按位表达式确定数字是否为奇数`num & 1`。 

如果数字是奇数，我们减去`1`。 否则，我们除以`2`使用右移操作。 

每次操作后，步数计数器都会加一。 

最后，一旦循环终止，该函数就会返回将数字减少到零所需的总步数。 

## 解决方案```go
func numberOfSteps(num int) int {
    steps := 0

    for num > 0 {
        if num&1 == 1 {
            num--
        } else {
            num >>= 1
        }

        steps++
    }

    return steps
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

Go 使用相同的按位运算符进行奇偶校验和右移。 由于输入约束非常小，因此不必担心整数溢出。 不需要额外的内存结构，因此实现保持紧凑和高效。

 ## 边缘情况

 一个重要的边缘情况是`num = 0`。 粗心的实现可能会不必要地进入循环或返回错误的正值。 在这个实现中，循环条件是`while num > 0`，所以函数立即返回`0`而不执行任何操作。 

另一个重要的情况是当输入是 2 的幂时，例如`8`或者`1024`。 这些数字重复地除以`2`直到达到`1`，然后进行最后一次减法。 该实现通过重复右移自然地处理这个问题。 

第三个重要的情况涉及奇数，尤其是奇数序列，例如`15`。 奇数不能直接除以`2`，所以减去`1`首先是必不可少的。 有缺陷的实现可能会立即尝试除法或错误处理奇偶校验。 使用`num & 1`保证在减法发生之前正确识别奇数。
