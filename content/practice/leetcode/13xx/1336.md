[LeetCode 问题 1336](https://leetcode.com/problems/number-of-transactions-per-visit/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们分析两个数据库表，`Visits`和`Transactions`，并计算有多少访问者每次访问执行了给定数量的交易。 中的每一行`Visits`表表示用户在特定日期的唯一访问。 这`Transactions`表可能包含每个用户每个日期的多行，表示同一访问中有多个事务。 

目标是生成一个汇总表，其中每一行对应于特定数量的事务（`transactions_count`）并包含恰好有那么多交易的访问次数（`visits_count`）。 我们还需要包括零交易的访问，以及`transactions_count`值必须涵盖从 0 到单次访问中观察到的最大事务数的整个范围。 结果应按以下顺序排序`transactions_count`。 

关键细节和限制包括：

 1. 每个`(user_id, visit_date)`在`Visits`是独一无二的。 
2. 每笔交易`Transactions`对应于有效访问`Visits`。 
3. 可能存在零交易的访问，我们必须考虑到这一点。 
4. 每次访问的交易计数可能会跳过数字（例如，可能有 0、1、3 个交易，但没有 2 次访问），但输出必须包括从 0 到最大值的所有计数。 

边缘情况包括没有交易的用户、有多个交易的访问以及同一访问的潜在重复交易行。 

## 方法

 暴力方法将涉及迭代每次访问，通过扫描来计算该访问的事务数`Transactions`表，然后构建交易计数的频率图。 虽然正确，但效率很低，因为它需要对每次访问的所有事务进行嵌套扫描，导致潜在的 O(V * T) 时间复杂度，其中 V 是访问次数，T 是事务数量。 

最佳方法利用 SQL 聚合和连接。 通过执行`LEFT JOIN`的`Visits`和`Transactions`在`(user_id, date)`然后使用`COUNT`分组依据`(user_id, visit_date)`，我们可以有效地计算每次访问的交易数量。 最后，我们汇总这些计数以确定每个交易计数的访问次数，包括零。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(V * T) | O(V) | 迭代每次访问并扫描事务，正确但效率低下。 |
 | 最佳| O(V + T) | O(V + T) | 使用 SQL 聚合`LEFT JOIN`和`GROUP BY`有效计算每次访问的计数以及计数频率。 |

 ## 算法演练

 1. 执行`LEFT JOIN`之间`Visits`和`Transactions`在`(user_id, visit_date)`将交易与每次访问关联起来。 没有交易的访问将有`NULL`在交易栏里。 
2. 使用`COUNT(transaction_date)`分组依据`(user_id, visit_date)`计算`transactions_count`每次访问。 使用`COUNT(column)`忽略 NULL，因此没有交易的访问将正确计为 0。 
3. 汇总第 2 步的结果以计算每次访问的次数`transactions_count`。 使用`GROUP BY transactions_count`和`COUNT(*)`得到`visits_count`。 
4.生成从0到最大值的一系列数字`transactions_count`进行观察以确保包括所有交易计数。`LEFT JOIN`该系列的聚合计数用 0 填充缺失计数。 
5. 对最终结果进行排序`transactions_count`。 

为什么有效：每次访问都是唯一标识的，通过计算每次访问的交易量，然后汇总计数，我们可以捕获每次访问的交易量分布。 使用系列可确保不会遗漏任何事务计数，从而满足包含零和任何跳过计数的要求。 

## Python 解决方案```python
class Solution:
    def numberOfTransactionsPerVisit(self, visits: List[Tuple[int, str]], transactions: List[Tuple[int, str, int]]) -> List[Tuple[int, int]]:
        from collections import defaultdict

        # Count transactions per visit
        visit_tx_count = defaultdict(int)
        for user_id, visit_date, *_ in transactions:
            visit_tx_count[(user_id, visit_date)] += 1

        # Count visits per transaction count
        tx_count_freq = defaultdict(int)
        for user_id, visit_date in visits:
            count = visit_tx_count.get((user_id, visit_date), 0)
            tx_count_freq[count] += 1

        max_count = max(tx_count_freq.keys(), default=0)
        result = [(i, tx_count_freq.get(i, 0)) for i in range(max_count + 1)]
        return result
```在这个Python实现中，我们首先构建一个字典`visit_tx_count`映射每个`(user_id, visit_date)`其交易数量。 然后，我们使用以下方法计算每个交易计数中有多少访问次数`tx_count_freq`。 最后，我们生成从 0 到最大计数的完整范围，以确保代表每个事务计数。 

## 解决方案```go
package main

type Visit struct {
    UserID    int
    VisitDate string
}

type Transaction struct {
    UserID          int
    TransactionDate string
    Amount          int
}

func NumberOfTransactionsPerVisit(visits []Visit, transactions []Transaction) [][]int {
    visitTxCount := make(map[string]int)
    for _, tx := range transactions {
        key := fmt.Sprintf("%d-%s", tx.UserID, tx.TransactionDate)
        visitTxCount[key]++
    }

    txCountFreq := make(map[int]int)
    maxCount := 0
    for _, v := range visits {
        key := fmt.Sprintf("%d-%s", v.UserID, v.VisitDate)
        count := visitTxCount[key]
        txCountFreq[count]++
        if count > maxCount {
            maxCount = count
        }
    }

    result := make([][]int, maxCount+1)
    for i := 0; i <= maxCount; i++ {
        result[i] = []int{i, txCountFreq[i]}
    }

    return result
}
```在Go中，我们在map中使用字符串键来表示`(user_id, visit_date)`对。 这避免了为映射键创建自定义结构。 该逻辑在其他方面反映了 Python 版本：首先对每次访问的交易进行计数，然后对每个交易计数的访问次数进行计数，最后生成从 0 到最大值的范围。
