 ## 解决方案

 ## 问题理解

 这个问题需要设计一个专门的栈数据结构，称为`CustomStack`，不仅支持通常的push和pop操作，还支持增量操作，可以增加底部的值`k`给定量的元素。 换句话说，该堆栈的行为类似于用于推送和弹出元素的标准堆栈，但它还允许高效地对堆栈前缀进行批量修改。 

系统的输入由最大堆栈大小组成`maxSize`以及一系列操作：`push(x)`如果堆栈未达到其限制，则添加一个元素，`pop()`删除顶部元素（或返回`-1`如果为空），并且`increment(k, val)`增加第一个`k`从底部开始的元素`val`。 预计输出仅适用于`pop()`操作，如`push()`和`increment()`返回`None`。 

约束表明`maxSize`并且操作数量适中（≤ 1000），允许使用简单的数据结构，例如列表或切片。 然而，天真的方法`increment`如果我们通过循环元素来实现它，可能会导致不必要的重复更新，从而激发更有效的方法。 

关键的边缘情况包括尝试压入完整堆栈、从空堆栈中弹出或增加比当前存在更多的元素。 

## 方法

 **暴力方法**是实现一个标准的列表支持堆栈并执行每个`increment(k, val)`通过迭代第一个操作`k`元素。 这是正确的，但效率低下，因为每个增量都需要 O(k) 时间。 在最坏的情况下，通过在整个堆栈上重复增量，解决方案可以达到 O(n * k) 时间，这对于小输入来说是可以接受的，但可以优化。 

**最佳方法**使用辅助数组将增量推迟到弹出时间。 而不是立即更新底部`k`对于元素，我们维护一个“增量挂起”数组，其中每个位置跟踪弹出该元素时应应用的总增量。 弹出时，我们将任何挂起的增量传播到下面的下一个元素。 这确保了`push`和`pop`操作仍为 O(1) 且`increment`也变为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | 每个增量 O(k)，O(1) 推入/弹出 | O(最大尺寸) | 增量期间直接更新底部 k 个元素 |
 | 最佳 | 每次操作 O(1) | O(最大尺寸) | 使用延迟增量传播来实现恒定时间操作 |

 ## 算法演练

 1. 初始化一个固定最大大小的栈和一个辅助数组`inc`具有相同的大小来跟踪每个元素的待处理增量。 
2.`push(x)`检查堆栈是否已满。 如果没有，则附加`x`到堆栈。 
3.`pop()`删除顶部元素。 在返回之前，它应用为该元素存储的任何待处理增量。 它还将挂起的增量传播到堆栈中下面的下一个元素（如果存在）。 
4.`increment(k, val)`添加`val`到`inc`索引处的数组`min(k, len(stack)) - 1`。 这会推迟增量，直到弹出相应的元素。 
5. 每个操作都保持堆栈不变：堆栈中的元素加上它们的延迟增量等于任何时候的有效堆栈值。 

为什么有效：通过延迟增量，我们可以避免堆栈中间元素的重复更新。 期间的传播`pop()`确保增量按顺序正确应用，保持正确性，同时降低时间复杂度。 

## Python 解决方案```python
class CustomStack:

    def __init__(self, maxSize: int):
        self.stack = []
        self.inc = [0] * maxSize
        self.maxSize = maxSize

    def push(self, x: int) -> None:
        if len(self.stack) < self.maxSize:
            self.stack.append(x)

    def pop(self) -> int:
        if not self.stack:
            return -1
        index = len(self.stack) - 1
        if index > 0:
            self.inc[index - 1] += self.inc[index]
        res = self.stack.pop() + self.inc[index]
        self.inc[index] = 0
        return res

    def increment(self, k: int, val: int) -> None:
        if self.stack:
            index = min(k, len(self.stack)) - 1
            self.inc[index] += val
```这个Python实现使用了一个列表`stack`用于存储和数组`inc`对于延迟增量。`push`如果空间允许，只需附加即可。`pop`应用延迟增量并将其向下传播。`increment`仅更新其中一个元素`inc`推迟操作。 

## 解决方案```go
type CustomStack struct {
    stack   []int
    inc     []int
    maxSize int
}

func Constructor(maxSize int) CustomStack {
    return CustomStack{
        stack:   make([]int, 0, maxSize),
        inc:     make([]int, maxSize),
        maxSize: maxSize,
    }
}

func (this *CustomStack) Push(x int) {
    if len(this.stack) < this.maxSize {
        this.stack = append(this.stack, x)
    }
}

func (this *CustomStack) Pop() int {
    n := len(this.stack)
    if n == 0 {
        return -1
    }
    if n > 1 {
        this.inc[n-2] += this.inc[n-1]
    }
    res := this.stack[n-1] + this.inc[n-1]
    this.stack = this.stack[:n-1]
    this.inc[n-1] = 0
    return res
}

func (this *CustomStack) Increment(k int, val int) {
    n := len(this.stack)
    if n == 0 {
        return
    }
    index := k
    if k > n {
        index = n
    }
    this.inc[index-1] += val
}
```Go中，切片用于动态存储，有一个辅助切片`inc`对于延迟增量。 这`Push`和`Pop`函数安全地处理切片大小调整，并且传播的工作方式与 Python 版本相同。 

## 工作示例

 对于输入：```
stk = CustomStack(3)
stk.push(1)   -> [1], inc=[0,0,0]
stk.push(2)   -> [1,2], inc=[0,0,0]
stk.pop()     -> returns 2, stack=[1], inc=[0,0,0]

stk.pop()     -> returns -1
```状态传播确保正确性，同时避免 O(k) 增量操作。
