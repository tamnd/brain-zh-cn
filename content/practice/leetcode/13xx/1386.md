## 问题理解

 该问题描述了一家电影院`n`行，每行恰好包含 10 个座位，标记为 1 到 10。其中一些座位已被保留，在输入数组中给出`reservedSeats`，其中每个元素是一对`[row, seat]`。 目标是确定可以分配给电影院的四人小组的最大数量，以便每个小组占据**同一排的四个连续座位**。 

四人小组不能跨越过道。 在此问题中，过道概念上位于 2 号和 3 号座位、4 号和 5 号座位、6 号和 7 号座位以及 8 号和 9 号座位之间，这意味着对于一个团体来说，唯一可行的区域是 2-5 号座位、4-7 号座位和 6-9 号座位。 然而，4-7 号座位的团体可以共用中间部分，以最大限度地利用。 

输入保证`1 <= n <= 10^9`和`1 <= reservedSeats.length <= min(10*n, 10^4)`。 这意味着`n`可以很大，但预留座位数量比较少（最多10000个）。 这是一个关键的见解，因为我们无法直接迭代每一行 - 我们必须使用更有效的方法，仅处理具有保留席位的行。 

边缘情况包括没有预留座位的行、中间完全被挡住的行以及预留座位位于边缘的行，这些行仍可能允许一组人。 该问题还保证了没有重复的座位`reservedSeats`。 

## 方法

 蛮力方法将迭代每一行并检查每行的每个可能的四座位块。 为了`n`最多`10^9`，这是不可行的，即使我们每行只使用恒定时间。 

最佳方法利用了这样一个事实：只有**保留座位的行需要仔细检查**。 没有预留座位的排可以自动容纳**两组**（一组在 2-5 号座位，另一组在 6-9 号座位）。 对于保留座位的行，我们使用 **位掩码** 跟踪哪些座位被阻止，然后检查三个候选块（2-5、4-7、6-9）的可用性。 

这一观察减少了问题`O(n)`到`O(reservedSeats.length)`时间复杂度和`O(reservedSeats.length)`在空间上，考虑到限制，这是可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 迭代所有行，对于大 n | 不可行
 | 最佳 | O(r) | O(r) | 仅处理具有预留座位的行， r = len(reservedSeats) |

 ## 算法演练

 1. 初始化哈希图`reserved_map`将行号映射到代表阻塞座位的位掩码。 
2. 对于每个预留座位`[row, seat]`，将行位掩码中的相应位设置为 1。席位编号为 1-10，因此位 1 对应席位 1，位 2 对应席位 2，依此类推。 
3. 初始化变量`max_groups`作为`2 * n`。 这假设所有行都是空闲的并且可以容纳两组。 
4. 对于每一行`reserved_map`，检查三个可能的座位块的可用性：

 - 左座：2-5个座位
 - 中座：4-7 座
 - 右座：6-9 座位

 每个块都表示为一个掩码，我们可以检查是否`row_mask & block_mask == 0`以确定可用性。 
5. 计算该行中实际可以放置多少个组：

 - 如果左右块都空闲，则该行可以有 2 组。 
- 如果左侧、中间或右侧块空闲，则该行可以有 1 个组。 
- 如果没有空闲块，则该行有 0 个组。 
6. 减法`2`从`max_groups`（我们最初的超额计数）并添加该行的实际组数。 这确保我们只调整有保留的行。 
7. 返回`max_groups`。 

**为什么有效：** 不变的是没有预留座位的行总是贡献 2 个组。 具有预留的行会根据实际可用性进行更正，并且不会重复计算任何行。 这保证了最大组数。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def maxNumberOfFamilies(self, n: int, reservedSeats: List[List[int]]) -> int:
        reserved_map = defaultdict(int)
        for row, seat in reservedSeats:
            reserved_map[row] |= 1 << (seat - 1)
        
        max_groups = 2 * n
        for row_mask in reserved_map.values():
            left_block = 0b00011110   # seats 2-5
            middle_block = 0b00111100 # seats 4-7
            right_block = 0b11110000  # seats 6-9
            
            groups = 0
            if (row_mask & left_block) == 0:
                groups += 1
            if (row_mask & right_block) == 0:
                groups += 1
            if groups == 0 and (row_mask & middle_block) == 0:
                groups = 1
            
            max_groups += groups - 2  # adjust overcount for this row
        
        return max_groups
```**说明：**

 我们首先将每个保留座位转换为其所在行的位掩码。 然后，通过使用按位与，我们可以有效地检查候选块中是否有任何座位被占用。 这`max_groups`变量在假设所有行都是空闲的情况下初始化，然后我们根据实际保留的座位进行调整。 这避免了遍历所有`n`明确的行。 

## 解决方案```go
func maxNumberOfFamilies(n int, reservedSeats [][]int) int {
    reservedMap := make(map[int]int)
    for _, seat := range reservedSeats {
        row := seat[0]
        s := seat[1] - 1
        reservedMap[row] |= 1 << s
    }

    maxGroups := 2 * n
    for _, rowMask := range reservedMap {
        leftBlock := 0b00011110   // seats 2-5
        middleBlock := 0b00111100 // seats 4-7
        rightBlock := 0b11110000  // seats 6-9

        groups := 0
        if rowMask&leftBlock == 0 {
            groups++
        }
        if rowMask&rightBlock == 0 {
            groups++
        }
        if groups == 0 && rowMask&middleBlock == 0 {
            groups = 1
        }
        maxGroups += groups - 2
    }

    return maxGroups
}
```**Go 特定注释：**

 Go 使用`map[int]int`对于保留行。 位运算与 Python 相同，并且使用二进制文字来初始化掩码很简单。 由于映射会动态增长，因此无需预定义数组大小。
