 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组中数字的除数之和`nums`，但仅适用于那些具有**恰好四个除数**的数字。 对于每个数字`n`在`nums`，我们需要确定它的所有约数，检查是否正好有四个，如果是，则将它们相加。 输出是所有符合条件的数字的总和。 如果没有数字正好有四个约数，则结果应该是`0`。 

输入数组`nums`长度可达`10^4`，每个元素最多可达`10^5`。 这种规模表明，一种简单的方法可以检查所有数字`n`对于除数可能太慢，因为它会`O(n * sqrt(max(nums)))`在最坏的情况下。 有效检查除数至关重要。 

重要的边缘情况包括少于四个因数的数字（例如素数或 1）、正好四个因数的数字（例如 6、10、14、21）、数组中的重复项以及允许的最小或最大数字。 

## 方法

 ### 蛮力

 暴力解决方案迭代中的每个数字`nums`并通过检查从 1 到 的每个整数来找到所有除数`n`。 我们收集除数，计算它们，如果正好有四个，则将它们相加并添加到总数中。 虽然正确，但此方法效率低下，因为对于高达`10^5`，迭代至`n`甚至`sqrt(n)`对于每个数字最多可以导致`10^4 * 316`操作，这是可接受的，但对于时间敏感的场景来说并不理想。 

### 最佳方法

 关键的观察结果是，恰好有四个约数的数字具有特定的形式：

 1.它是**两个不同素数的乘积**：`p * q`在哪里`p != q`。 它的除数是`{1, p, q, p*q}`。 
2.它是一个**素数的立方**：`p^3`。 它的除数是`{1, p, p^2, p^3}`。 

我们可以使用生成的质数列表来有效地检查一个数字是否属于这两种形式之一，而不是检查每个数字的所有除数`sqrt(max(nums))`。 一旦我们检测到形式，计算四个除数的总和就很简单了。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * sqrt(max(nums))) | O(n * sqrt(max(nums))) | O(1) | O(1) | 检查每个数字的除数到 sqrt(n) |
 | 最佳 | O(n * sqrt(n)) | O(n * sqrt(n)) | O(sqrt(max(nums))) | O(sqrt(max(nums))) | 使用素数检查和恰好有四个除数的数字的属性 |

 ## 算法演练

 1. 生成直到`sqrt(max(nums))`使用埃拉托斯特尼筛法。 这允许有效的素数检查和因式分解。 
2. 初始化变量`total_sum`存储除数的累积和。 
3. 迭代每个数字`num`在`nums`。 
4. 对于每个`num`，尝试确定其素因数分解直至`sqrt(num)`。 
5. 检查是否`num`是这样的形式`p^3`（素数的立方）或`p * q`（两个不同素数的乘积）。 
6. 如果是，则使用上面的公式计算其四个除数之和，并将其添加到`total_sum`。 
7. 返回`total_sum`处理完所有数字后。 

**为什么有效**：恰好有四个除数的数字属于这两类。 通过直接识别这些形式的数字，我们避免了不必要的除数计算并保证了正确性。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def sumFourDivisors(self, nums: List[int]) -> int:
        def sieve(limit: int) -> List[int]:
            is_prime = [True] * (limit + 1)
            is_prime[0] = is_prime[1] = False
            for i in range(2, int(limit**0.5) + 1):
                if is_prime[i]:
                    for j in range(i*i, limit+1, i):
                        is_prime[j] = False
            return [i for i, val in enumerate(is_prime) if val]
        
        primes = sieve(int(max(nums)**0.5) + 1)
        prime_set = set(primes)
        total_sum = 0
        
        for num in nums:
            found = False
            for p in primes:
                if p * p * p > num:
                    break
                if num % p == 0:
                    q = num // p
                    if q == p * p:  # case p^3
                        total_sum += 1 + p + p*p + p*p*p
                        found = True
                        break
                    elif q in prime_set and q != p:  # case p*q
                        total_sum += 1 + p + q + num
                        found = True
                        break
            # special case when num is a perfect cube of a prime larger than sqrt(num)
            if not found:
                cube_root = round(num ** (1/3))
                if cube_root ** 3 == num:
                    # check if cube_root is prime
                    if all(cube_root % d != 0 for d in range(2, int(cube_root**0.5)+1)):
                        total_sum += 1 + cube_root + cube_root**2 + cube_root**3
        
        return total_sum
```**解释**：`sieve`函数生成直到最大数的平方根的所有素数。 对于每个数字，我们检查它是否是`p^3`或者`p*q`使用素数列表。 如果是这样，我们计算其四个除数的总和并将其添加到总数中。 

## 解决方案```go
package main

import (
    "math"
)

func sumFourDivisors(nums []int) int {
    maxNum := 0
    for _, n := range nums {
        if n > maxNum {
            maxNum = n
        }
    }

    // Sieve of Eratosthenes
    limit := int(math.Sqrt(float64(maxNum))) + 1
    isPrime := make([]bool, limit+1)
    for i := 2; i <= limit; i++ {
        isPrime[i] = true
    }
    for i := 2; i*i <= limit; i++ {
        if isPrime[i] {
            for j := i * i; j <= limit; j += i {
                isPrime[j] = false
            }
        }
    }
    primes := []int{}
    primeSet := make(map[int]bool)
    for i := 2; i <= limit; i++ {
        if isPrime[i] {
            primes = append(primes, i)
            primeSet[i] = true
        }
    }

    totalSum := 0
    for _, num := range nums {
        found := false
        for _, p := range primes {
            if p*p*p > num {
                break
            }
            if num%p == 0 {
                q := num / p
                if q == p*p {
                    totalSum += 1 + p + p*p + p*p*p
                    found = true
                    break
                } else if primeSet[q] && q != p {
                    totalSum += 1 + p + q + num
                    found = true
                    break
                }
            }
        }
        if !found {
            cubeRoot := int(math.Round(math.Pow(float64(num), 1.0/3.0)))
            if cubeRoot*cubeRoot*cubeRoot == num {
                isCubePrime := true
                for d := 2; d*d <= cubeRoot; d++ {
                    if cubeRoot%d == 0 {
                        isCubePrime = false
                        break
                    }
                }
                if isCubePrime {
                    totalSum += 1 + cubeRoot + cubeRoot*cubeRoot + num
                }
            }
        }
    }
    return totalSum
}
```**说明**：Go 实现通过仔细的类型处理和显式整数舍入反映了 Python 逻辑。 它使用素数切片和快速素数查找映射。 完美立方体超出筛限的边缘情况通过直接底漆检查进行处理。 

## 工作示例

 **示例 1：nums = [21,4,7]**

 1. 21：因数为 1, 3, 7, 21 → 正好四个除数 → sum = 32
 2. 4：因数为 1, 2, 4 → 三个约数 → 忽略
 3. 7:素数→两个约数→忽略`total_sum = 32`**示例 2：nums = [21,21]**

 两者都是 21：除数之和 = 每个 32 → 总计 = 64

 **示例 3：nums = [1,2,3,4,5]**

 没有数字恰好有 4 个约数 → 总计 = 0
