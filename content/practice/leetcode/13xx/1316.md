[LeetCode 第 1316 题](https://leetcode.com/problems/distinct-echo-substrings/)

 **难度：** 🔴难
 **主题：** 字符串、Trie、滚动哈希、哈希函数

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定字符串的 **不同非空子字符串** 的数量`text`可以表示为某个字符串与其自身的串联。 换句话说，我们需要计算该形式的所有子字符串`a + a`， 在哪里`a`是任何非空字符串。 例如，`"abcabc"`可以表示为`"abc" + "abc"`，使其成为回显子字符串。 子串如`"aa"`和`"abab"`如果它们满足此重复属性，也符合资格。 

输入是一个字符串`text`长度在1到2000之间，仅包含小写英文字母。 输出是一个整数，表示不同回显子字符串的计数。 

重要的一点包括认识到子字符串可能重叠，并且只应计算**不同的子字符串**。 边缘情况涉及非常短的字符串（长度为 1，不能有回显子字符串）或具有重复单个字符的字符串（例如`"aaaaa"`）其中存在多个重叠的回显子串。 

这些约束告诉我们，复杂度为 O(n^3) 的强力解决方案可能太慢，我们需要一种更优化的方法，可能使用散列或尝试有效地检测重复模式。 

## 方法

 蛮力方法涉及生成所有可能的子串`text`并检查每个是否可以分成相等的两半。 这是通过迭代每个可能的起始索引来实现的`i`并且每个偶数长度`l`（因为只有偶数长度的字符串才能形成`a + a`）。 对于每个候选子串，我们检查前半部分是否等于后半部分。 虽然正确，但这种方法的时间复杂度为 O(n^3)，因为生成所有子字符串的时间复杂度为 O(n^2)，比较一半的时间复杂度为 O(n)，这使得它不可行`n = 2000`。 

最佳方法的关键见解是使用**滚动哈希**或**基于特里树的技术**来有效地比较子字符串。 滚动哈希允许在预处理所有前缀的哈希值后进行恒定时间的子字符串比较。 通过迭代可能的长度并使用散列，我们可以在每个子字符串的 O(1) 时间内检查子字符串的两半是否相等。 这显着降低了时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 生成所有子串并直接比较两半 |
 | 滚动哈希/特里树| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 使用哈希有效比较子字符串 |

 ## 算法演练

 1. 预先计算所有前缀的**滚动哈希**`text`。 选择一个基数（例如 26）和一个大的素数模数以避免碰撞。 
2.初始化一个空集`seen`存储不同的回显子字符串。 
3. 迭代所有可能的长度`length`回声子字符串。 由于 echo 子串是`a + a`，仅考虑偶数长度。 
4. 对于每个起始索引`i`，计算前半部分的哈希值（`i`到`i + length // 2`）和下半场（`i + length // 2`到`i + length`）。 
5. 如果两半的哈希值相等，则将子串相加`text[i:i + length]`到`seen`。 
6. 继续，直到处理完所有偶数长度和起始索引。 
7. 返回尺寸`seen`set，它给出不同回显子串的数量。 

**为什么起作用：** 滚动散列通过正确选择基数和模数确保子字符串相等性检查高效且抗冲突。 通过迭代所有起始索引和长度，我们保证考虑所有潜在的回显子串。 使用集合可确保重复项仅计算一次。 

## Python 解决方案```python
class Solution:
    def distinctEchoSubstrings(self, text: str) -> int:
        n = len(text)
        base = 26
        mod = 10**9 + 7
        
        # Precompute prefix hashes and powers of base
        prefix_hash = [0] * (n + 1)
        power = [1] * (n + 1)
        
        for i in range(n):
            prefix_hash[i + 1] = (prefix_hash[i] * base + ord(text[i]) - ord('a')) % mod
            power[i + 1] = (power[i] * base) % mod
        
        def get_hash(l, r):
            return (prefix_hash[r] - prefix_hash[l] * power[r - l]) % mod
        
        seen = set()
        
        for length in range(2, n + 1, 2):
            for i in range(n - length + 1):
                mid = i + length // 2
                if get_hash(i, mid) == get_hash(mid, i + length):
                    seen.add(text[i:i + length])
        
        return len(seen)
```**实现说明：** 首先，代码计算所有前缀的滚动哈希值，并预先计算基数的幂以启用 O(1) 子串哈希查询。 对于每个可能的偶数长度，它迭代所有起始位置，计算两半的哈希值，如果它们匹配，则将子字符串添加到集合中`seen`。 最后，它返回不同回显子字符串的数量。 

## 解决方案```go
func distinctEchoSubstrings(text string) int {
    n := len(text)
    base := 26
    mod := int(1e9 + 7)
    
    prefixHash := make([]int, n+1)
    power := make([]int, n+1)
    power[0] = 1
    
    for i := 0; i < n; i++ {
        prefixHash[i+1] = (prefixHash[i]*base + int(text[i]-'a')) % mod
        power[i+1] = (power[i] * base) % mod
    }
    
    getHash := func(l, r int) int {
        return (prefixHash[r] - prefixHash[l]*power[r-l]%mod + mod) % mod
    }
    
    seen := make(map[string]struct{})
    
    for length := 2; length <= n; length += 2 {
        for i := 0; i <= n-length; i++ {
            mid := i + length/2
            if getHash(i, mid) == getHash(mid, i+length) {
                seen[text[i:i+length]] = struct{}{}
            }
        }
    }
    
    return len(seen)
}
```**Go 注释：** Go 版本镜像了 Python 解决方案。 使用映射而不是集合，并且模运算确保正值。 切片用于在存储到映射时提取子字符串。
