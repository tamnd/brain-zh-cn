[LeetCode 问题 1351](https://leetcode.com/problems/count-negative-numbers-in-a-sorted-matrix/)

 **难度：** 🟢简单
 **主题：** 数组、二分搜索、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们计算二维矩阵中的所有负数`grid`其中每行和每列都按**非递增顺序**排序。 换句话说，当您在行中向右移动和在列中向下移动时，值会减小或保持不变。 输入是一个整数矩阵，输出是一个整数，表示矩阵中有多少个元素为负数。 

约束表明矩阵可以大到 100x100，即最多 10,000 个元素。 每个元素的范围在 -100 到 100 之间。排序属性是关键，它使我们能够避免单独检查每个元素的负数。 

重要的边缘情况包括全正数、全负数、单行或单列的矩阵，以及负数仅出现在右下角的矩阵。 非递增顺序的保证简化了搜索，因为一旦在行中找到负数，则右侧的所有元素也均为负数，而一旦在列中找到负数，则同一列中低于该负数的所有元素也均为负数。 

## 方法

 **暴力方法**会迭代矩阵中的每个元素，计算是否为负数，并对结果求和。 这很简单并且总是正确的，但效率低下，特别是对于较大的矩阵，因为它没有利用排序的属性。 

**最佳方法**使用排序属性。 从**右上角**开始，我们可以在 O(n + m) 时间内遍历矩阵。 如果当前数为负数，则同一列下面的所有元素都为负数，所以我们计数并左移。 如果当前数字非负，我们向下移动到下一行。 这有效地跳过了矩阵的大部分，并确保我们计算所有负数而无需进行不必要的检查。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(1) | O(1) | 单独检查每个元素 |
 | 最佳| O(m + n) | O(1) | O(1) | 从右上角开始，使用排序属性 | 进行遍历

 ## 算法演练

 1.初始化一个计数器`count`到 0。这将存储负数的总数。 
2. 将起始位置设置为矩阵的**右上角元素**：row = 0，col = n - 1。 
3. 当 row 在边界内并且 col 在边界内时：

 1.如果当前元素`grid[row][col]`是负数：

 1.同一列中低于该元素的所有元素都是负数，因为该列已排序。 
2.添加`(m - row)`到`count`自从`m - row`元素位于当前元素下方并包括当前元素。 
3. 递减左移`col`检查下一列。 
2. 否则，如果当前元素非负：

 1. 递增向下移动`row`检查下一行。 
4. 继续，直到移过最后一行或第一列。 
5. 返回`count`。 

**为什么有效：** 该算法利用排序属性。 从右上角开始可确保向左移动遇到较小的数字，向下移动遇到列中较小的数字。 这保证了我们对所有负数只计算一次，而无需重新访问元素。 

## Python 解决方案```python
from typing import List

class Solution:
    def countNegatives(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        row, col = 0, n - 1
        count = 0
        
        while row < m and col >= 0:
            if grid[row][col] < 0:
                count += m - row
                col -= 1
            else:
                row += 1
        
        return count
```此实现初始化右上角的指针。 while 循环根据当前位置的值来导航矩阵。 负值将计数增加下面所有剩余的行，然后向左移动，而非负值则向下移动。 循环继续，直到有效遍历所有行和列。 

## 解决方案```go
func countNegatives(grid [][]int) int {
    m := len(grid)
    if m == 0 {
        return 0
    }
    n := len(grid[0])
    row, col := 0, n - 1
    count := 0

    for row < m && col >= 0 {
        if grid[row][col] < 0 {
            count += m - row
            col--
        } else {
            row++
        }
    }

    return count
}
```Go 解决方案遵循与 Python 解决方案相同的逻辑。 这`len`函数确定行数和列数。 遍历使用带有 row 和 col 指针的 for 循环，递增`count`每当遇到负面因素时。 Go 可以有效地处理切片，并且对于给定的约束，整数溢出不是问题。 

## 工作示例

 **示例1：**`grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]`从右上角开始 (0,3 = -1)。 计数 = 4（下面的所有行包括这一行）。 向左移动到 (0,2 = 2)。 非负数，向下移动 (1,2 = 1)。 非负数，向下移动 (2,2 = -1)。 计数 += 2（第 2 行和第 3 行），左移 (2,1 = 1)，下移 (3,1 = -1)，计数 += 1。总计 = 8。 

**示例2：**`grid = [[3,2],[1,0]]`右上角 (0,1 = 2)。 非负数，向下移动 (1,1 = 0)。 非负数，向下移动 (2,1)。 出界了，停下来。 计数 = 0。

 ## 边缘情况

 第一个重要的边缘情况是**只有一个元素**的矩阵，可以是负、零或正。 这测试了算法是否正确处理尽可能小的输入而没有错误，并准确地计算负数。 

第二种边缘情况是一个**矩阵，其中负数仅出现在右下角**。 朴素的方法可能不必要地遍历左上角部分，但最佳算法可以根据排序的属性有效地跳转，并计算负数，而无需额外的迭代。 

第三种边缘情况是一个**矩阵，其中所有元素均为负数**或全部为非负数。 第一个确保算法正确计算每个元素而不跳过，第二个确保算法正确返回零。 这两种情况都证实了遍历逻辑遵循矩阵边界并且不会产生相差一错误。
