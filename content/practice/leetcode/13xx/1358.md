 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定字符串的所有子字符串`s`包含**每个字符至少出现一次**`'a'`,`'b'`， 和`'c'`。 字符串`s`保证只包含这三个字符。 本质上，我们需要找到连续序列的数量`s`其中没有一个`'a'`,`'b'`， 或者`'c'`失踪了。 

输入是长度最大为 50,000 的字符串，这排除了任何单独检查所有子字符串的算法，因为子字符串的数量呈二次方增长。 预期输出是一个整数，表示有效子字符串的总数。 边缘情况包括最小长度为 3 的字符串、完全缺少一个字符的字符串或具有重复字符块的字符串。 

## 方法

 **暴力方法**将涉及生成所有可能的子串`s`，然后检查每个子字符串是否存在`'a'`,`'b'`， 和`'c'`。 这保证了正确性，因为每个子字符串都会被检查，但效率非常低。 对于一个长度的字符串`n`， 有`n * (n + 1) / 2`子串，检查每个子串需要花费`O(n)`时间。 这导致总体复杂度为`O(n^3)`，这对于`n`最多 50,000 个。 

**最佳方法**利用带有两个指针的**滑动窗口**（`left`和`right`）和一个**哈希图**来跟踪计数`'a'`,`'b'`， 和`'c'`。 关键的观察结果是，一旦窗口包含每个字符至少一个，**所有从`left`并在任意位置结束`right`到字符串末尾都是有效的**。 通过移动`left`在保持计数的同时，我们可以有效地计算所有有效子字符串，而无需显式枚举它们。 这将时间复杂度降低到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 生成所有子字符串并检查每个子字符串的所有三个字符 |
 | 最佳 | O(n) | O(1) | O(1) | 带哈希图的滑动窗口进行字符计数，高效计数有效子串 |

 ## 算法演练

 1. 初始化哈希图`count`带钥匙`'a'`,`'b'`， 和`'c'`设置为 0。这将跟踪当前窗口中每个字符的数量。 
2. 设置两个指针`left`和`right`至 0。`right`将扩大窗口，`left`会缩小它。 
3. 初始化变量`result`为 0 以存储有效子字符串的总数。 
4. 迭代`right`在字符串上：

 1. 增量`count[s[right]]`因为角色在`right`现在是窗口的一部分。 
2. 虽然所有三个字符的计数都大于 0：

 1. 增量`result`经过`len(s) - right`，因为所有子串开始于`left`并结束于`right`到最后都是有效的。 
2. 减量`count[s[left]]`并移动`left`期待尝试较小的窗户。 
5. 遍历字符串后，`result`包含包含所有三个字符的子字符串总数。 

**为什么它有效：** 不变的是，当我们计数时，当前窗口总是至少包含一个字符。 通过计数`len(s) - right`每个有效的子字符串`left`位置，我们有效地考虑了所有有效的子串而没有冗余。 

## Python 解决方案```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        count = {'a': 0, 'b': 0, 'c': 0}
        left = 0
        result = 0
        
        for right in range(len(s)):
            count[s[right]] += 1
            
            while all(count[c] > 0 for c in 'abc'):
                result += len(s) - right
                count[s[left]] -= 1
                left += 1
        
        return result
```该实现维护了一个滑动窗口，该窗口随着`right`和合同`left`。 这`while`循环确保一旦窗口包含所有三个字符，我们就会计算从以下位置开始的所有可能的子字符串`left`然后缩小窗口以检查其他可能性。 哈希映射有效地跟踪每个字符的计数。 

## 解决方案```go
func numberOfSubstrings(s string) int {
    count := map[byte]int{'a': 0, 'b': 0, 'c': 0}
    left := 0
    result := 0

    for right := 0; right < len(s); right++ {
        count[s[right]]++

        for count['a'] > 0 && count['b'] > 0 && count['c'] > 0 {
            result += len(s) - right
            count[s[left]]--
            left++
        }
    }

    return result
}
```在 Go 中，我们使用`map[byte]int`跟踪计数`'a'`,`'b'`， 和`'c'`。 该方法与 Python 相同，但我们使用字符串的字节索引和标准`for`环形。 这`for`内部循环确保我们缩小窗口，同时保留所有字符。
