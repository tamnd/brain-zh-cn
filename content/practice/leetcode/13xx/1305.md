[LeetCode 问题 1305](https://leetcode.com/problems/all-elements-in-two-binary-search-trees/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉搜索树、排序、二叉树

 ## 解决方案

 ## 问题理解

 这个问题给了我们两个二叉搜索树，`root1`和`root2`。 二叉搜索树（通常缩写为 BST）具有以下重要属性：对于每个节点：

 - 左子树中的所有值都小于该节点的值
 - 右子树中的所有值都大于该节点的值

 我们需要收集存储在两棵树中的每个整数，并将它们按升序返回到一个排序列表中。 

关键细节是输入树已经是 BST。 这意味着每棵树都单独包含可以通过执行中序遍历按排序顺序检索的值。 中序遍历按以下顺序访问节点：

 1. 左子树
 2.当前节点
 3. 右子树

 对于 BST，这种遍历自然会产生排序值。 

输入由两个树根组成。 任一树都可以为空，表示为`None`在 Python 中或`nil`在围棋中。 输出必须包含两个树中的每个值，包括重复项，按从小到大排序。 

约束告诉我们每棵树最多可以包含 5000 个节点。 这个大小足够大，如果我们可以直接利用 BST 属性，我们应该避免不必要的昂贵排序操作。 然而，它仍然足够小，线性或近线性算法是完全可以接受的。 

一些边缘情况很重要：

 - 一棵或两棵树可能是空的
 - 两棵树中的树可能包含重复的值
 - 树可能极度不平衡，实际上表现得像链表
 - 允许负值
 - 一棵树可能比另一棵树包含更多的节点

 忽略 BST 排序的简单实现将会错过优化的机会。 

## 方法

 ### 蛮力方法

 最直接的解决方案是将两棵树中的所有值收集到一个数组中，然后对最终数组进行排序。 

我们可以使用任何遍历方法（例如前序或中序）来遍历每棵树，因为暴力方法不依赖于 BST 排序。 收集每个值后，我们使用标准排序算法对组合列表进行排序。 

这种方法是正确的，因为它最终将每个值放入数组中，并且排序保证升序。 

然而，它执行了不必要的工作。 由于 BST 已经包含有序结构，再次排序会浪费计算量。 

如果节点总数为`n`, 排序需要`O(n log n)`时间。 

### 最佳方法

 重要的见解是 BST 的中序遍历已经产生了按排序顺序的值。 

我们可以：而不是收集未排序的值并随后进行排序：

 1.分别对两棵树进行中序遍历
 2. 获取两个单独排序的数组
 3. 使用与合并排序相同的技术合并两个已排序的数组

 这避免了额外的排序步骤。 

合并过程是线性的，因为两个数组都已排序。 在每一步中，我们都会比较两个数组中的当前元素并附加较小的元素。 

这给出了总体线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 收集所有元素并随后排序 |
 | 最佳| O(n) | O(n) | 使用中序遍历加线性合并 |

 这里，`n`表示两棵树的节点总数。 

## 算法演练

 ### 最优算法

 1. 对第一个 BST 进行中序遍历。 

在遍历过程中，递归地访问左子树，然后是当前节点，然后是右子树。 由于该树是 BST，因此会按升序生成值。 将这些值存储在一个名为的数组中`values1`。 
2. 对第二个 BST 进行中序遍历。 

使用相同的遍历策略并将结果存储在另一个名为的排序数组中`values2`。 
3. 初始化两个指针。 

创建指针`i`为了`values1`和指针`j`为了`values2`。 两者都从索引开始`0`。 
4. 合并两个已排序的数组。 

比较`values1[i]`和`values2[j]`。 

- 如果`values1[i]`较小，将其附加到结果并递增`i`- 否则，附加`values2[j]`并增加`j`这是可行的，因为两个数组都已经排序了。 
5. 处理剩余元素。 

一个数组用完后，追加另一数组中的所有剩余元素。 
6. 返回合并结果。 

最终合并的数组包含按升序排列的所有元素。 

### 为什么它有效

 正确性依赖于两个属性：

 - BST 的中序遍历总是产生排序值
 - 合并两个排序数组保留排序顺序

 由于两棵树中的每个节点在遍历数组中只出现一次，并且合并步骤在保持顺序的同时处理所有元素，因此保证最终结果按升序包含所有值。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def getAllElements(
        self,
        root1: Optional[TreeNode],
        root2: Optional[TreeNode]
    ) -> List[int]:

        def inorder(node: Optional[TreeNode], values: List[int]) -> None:
            if not node:
                return

            inorder(node.left, values)
            values.append(node.val)
            inorder(node.right, values)

        values1 = []
        values2 = []

        inorder(root1, values1)
        inorder(root2, values2)

        merged = []
        i = 0
        j = 0

        while i < len(values1) and j < len(values2):
            if values1[i] <= values2[j]:
                merged.append(values1[i])
                i += 1
            else:
                merged.append(values2[j])
                j += 1

        while i < len(values1):
            merged.append(values1[i])
            i += 1

        while j < len(values2):
            merged.append(values2[j])
            j += 1

        return merged
```实现首先定义一个名为的辅助函数`inorder`。 该函数按顺序递归遍历 BST，并将节点值附加到列表中。 

两个数组，`values1`和`values2`，存储两棵树排序后的遍历结果。 

在获得两个排序数组后，该算法使用两个指针来有效地合并它们。 合并逻辑与合并排序的合并阶段相同。 由于两个数组都已排序，因此比较当前最小的未使用元素可以保证下一个附加元素是全局最小的。 

最后，在一个数组耗尽后，将附加所有剩余元素。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func getAllElements(root1 *TreeNode, root2 *TreeNode) []int {

    var inorder func(node *TreeNode, values *[]int)

    inorder = func(node *TreeNode, values *[]int) {
        if node == nil {
            return
        }

        inorder(node.Left, values)
        *values = append(*values, node.Val)
        inorder(node.Right, values)
    }

    values1 := []int{}
    values2 := []int{}

    inorder(root1, &values1)
    inorder(root2, &values2)

    merged := []int{}

    i := 0
    j := 0

    for i < len(values1) && j < len(values2) {
        if values1[i] <= values2[j] {
            merged = append(merged, values1[i])
            i++
        } else {
            merged = append(merged, values2[j])
            j++
        }
    }

    for i < len(values1) {
        merged = append(merged, values1[i])
        i++
    }

    for j < len(values2) {
        merged = append(merged, values2[j])
        j++
    }

    return merged
}
```Go 版本遵循与 Python 解决方案相同的算法结构。 主要的实现差异在于，切片在中序遍历期间通过引用传递，以便递归调用可以有效地附加值。 

Go 使用`nil`而不是`None`对于空节点。 切片附加是使用内置的`append`功能。 

不存在整数溢出问题，因为节点值完全在 Go 的标准整数范围内。

 ## 边缘情况

 ### 两棵树都是空的

 一个常见的错误来源是忘记任一树都可能是`None`。 如果两棵树都是空的，则遍历数组保持为空并且合并循环永远不会执行。 

该实现自然地处理了这个问题，因为中序遍历在给定时立即返回`None`。 最终的合并数组只是一个空列表。 

### 一棵树比另一棵大得多

 一个 BST 可能包含数千个节点，而另一个仅包含几个节点。 不正确的合并逻辑可能会在一个指针到达末尾后意外地跳过剩余元素。 

该实现通过在主合并循环之后使用两个附加循环来避免这种情况。 这些循环会追加仍具有未使用值的数组中的所有剩余元素。 

### 高度不平衡的树

 如果节点按排序顺序插入，BST 可能会退化为类似链表的结构。 在这种情况下，递归深度与节点数量成正比。 

该算法仍然会产生正确的输出，因为中序遍历逻辑不依赖于树平衡。 即使在倾斜树中，访问左子树、当前节点和右子树仍然会产生排序顺序。
