 **难度：** 🟡 中等
 **主题：** 数组、哈希表、设计

 ## 解决方案

 ## 问题理解

 该问题描述了一家超市，该超市销售由唯一整数 ID 标识的产品。 每种产品都有相应的价格。 客户购买一定数量的产品，生成的账单是价格乘以购买数量的总和。 超市定期打折：每`nth`客户可以从小计中获得百分比折扣。 

输入由用于初始化的参数组成`Cashier`目的：`n`（折扣间隔），`discount`（折扣百分比），`products`（产品 ID 列表），以及`prices`（与产品 ID 对应的价格列表）。 然后，一系列的电话`getBill(product, amount)`模拟顾客结账。 输出是客户支付的最终金额，仅当客户是客户时才应用折扣`nth`一。 

约束确保产品 ID 唯一、购买金额有效、调用次数可控。 这保证了我们不必在单个账单中处理无效的产品 ID 或重复的产品，从而简化了我们的实施。 边缘情况包括零折扣，如果满足以下条件，则对第一个客户应用折扣`n=1`，并正确处理多个顺序调用。 

## 方法

 天真的或蛮力方法将通过迭代每个购买的产品来计算小计`getBill`称呼。 对于每个产品`product`数组，代码将搜索`products`数组查找相应的价格，乘以金额，对结果求和，然后检查是否适用折扣。 虽然正确，但这种方法需要对每个产品进行线性搜索，如果`products`很大。 

最佳方法在初始化期间利用哈希映射（字典）将产品 ID 映射到价格。 这允许对每个产品进行 O(1) 价格查找，避免重复的线性搜索。 一个简单的计数器会跟踪顾客数量，以确定何时应用折扣。 这产生了逻辑简单、省时的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(m * k) | O(1) | O(1) |`m`= 产品数组的长度，`k`= 产品数组的长度； 线性搜索价格 |
 | 最佳 | O(米) | O(p) |`p`= 产品数量； 使用哈希映射进行恒定时间价格查找 |

 ## 算法演练

 1. **初始化Cashier对象**：存储折扣区间`n`和折扣百分比`discount`。 构建哈希图`price_map`将每个产品 ID 映射到其价格以进行 O(1) 查找。 初始化客户计数器`customer_count`至 0。 
2. **在 getBill 中计算账单**：对于每次调用`getBill`，将顾客计数器加 1。 
3. **计算小计**：迭代购买的`product`身份证。 对于每个产品 ID，乘以相应的`amount`根据检索到的价格`price_map`并将其添加到运行小计中。 
4. **如果适用则应用折扣**：如果`customer_count`可以整除`n`，将小计乘以`(100 - discount) / 100`应用折扣。 否则，小计保持不变。 
5. **返回最终账单**：以浮点数形式返回结果总计。 

**为什么有效**：哈希图确保恒定时间的价格查找，因此我们避免重复搜索。 增加计数器可确保折扣准确地应用于每个`nth`顾客。 该算法可以正确地按顺序处理任意数量的呼叫，并根据客户订单准确地应用折扣。 

## Python 解决方案```python
from typing import List

class Cashier:

    def __init__(self, n: int, discount: int, products: List[int], prices: List[int]):
        self.n = n
        self.discount = discount
        self.price_map = {prod: price for prod, price in zip(products, prices)}
        self.customer_count = 0

    def getBill(self, product: List[int], amount: List[int]) -> float:
        self.customer_count += 1
        subtotal = 0
        for prod_id, amt in zip(product, amount):
            subtotal += self.price_map[prod_id] * amt
        if self.customer_count % self.n == 0:
            subtotal *= (100 - self.discount) / 100
        return subtotal
```在此 Python 实现中，我们首先创建产品 ID 到价格的映射，以便快速查找。 每次致电`getBill`使用此映射更新客户计数并计算小计。 根据计数器有条件地应用折扣，最终小计以浮点数形式返回，满足精度要求`10^-5`。 

## 解决方案```go
type Cashier struct {
	n            int
	discount     int
	priceMap     map[int]int
	customerCount int
}

func Constructor(n int, discount int, products []int, prices []int) Cashier {
	priceMap := make(map[int]int)
	for i, prod := range products {
		priceMap[prod] = prices[i]
	}
	return Cashier{
		n:            n,
		discount:     discount,
		priceMap:     priceMap,
		customerCount: 0,
	}
}

func (this *Cashier) GetBill(product []int, amount []int) float64 {
	this.customerCount++
	subtotal := 0
	for i, prodID := range product {
		subtotal += this.priceMap[prodID] * amount[i]
	}
	if this.customerCount%this.n == 0 {
		return float64(subtotal) * float64(100-this.discount) / 100.0
	}
	return float64(subtotal)
}
```Go 实现反映了 Python 解决方案。 地图提供产品价格的恒定时间查找。 注意将整数转换为`float64`当应用折扣以确保正确的浮点除法时。 顾客柜台和折扣逻辑保持不变。
