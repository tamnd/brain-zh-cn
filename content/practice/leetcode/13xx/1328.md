[LeetCode 第 1328 题](https://leetcode.com/problems/break-a-palindrome/)

 **难度：** 🟡 中等
 **主题：** 字符串、贪婪

 ## 解决方案

 ## 问题理解

 该问题要求我们修改给定的回文字符串，使其不再是回文字符串，同时确保生成的字符串在字典顺序上尽可能最小。 回文是向前和向后读取相同的字符串。 在这个问题中，输入`palindrome`仅由小写英文字母组成，长度在 1 到 1000 之间。 

需要理解的关键点是：我们可以替换**恰好一个字符**，目标不仅仅是打破回文，而且还要确保结果字符串按字典顺序尽可能小。 如果不可能打破回文（例如，如果字符串只有一个字符），我们返回一个空字符串。 

边缘情况包括单字符回文、完全由`'a'`字符，以及奇数长度的回文，其中中间字符如果是最小的可能字符，则不会影响字典顺序。 

## 方法

 ### 蛮力方法

 暴力方法会尝试用每个可能的小写字母替换字符串中的每个字符（`'a'`到`'z'`）并检查结果是否是回文。 在所有非回文结果中，我们将选择字典顺序最小的一个。 虽然这保证了正确性，但效率极低：对于长度为`n`，我们会生成`25 * n`候选者并检查每个候选者的回文状态，时间复杂度为 O(n^2)，因为回文检查的时间复杂度为 O(n)。 

### 最佳方法

 最佳解决方案利用两个观察结果：

 1. 为了获得按字典顺序最小的字符串，我们要替换最左边的字符`'a'`** 和`'a'`。 更改后面的字符或`'a'`字符不会最小化字典顺序。 
2. 对于奇数长度的字符串，如果所有字符都为奇数长度，则中间字符不需要改变。`'a'`因为改变它不会影响字典排序的优势。 如果所有字符都是`'a'`，我们能做的最好的就是将**最后一个字符**更改为`'b'`。 

这种见解使我们能够扫描字符串的前半部分（如果长度为奇数，则排除中间字符）并替换第一个非`'a'`字符与`'a'`。 如果不存在这样的字符，则将最后一个字符替换为`'b'`。 这种方法在时间上是 O(n)，在空间上是 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 尝试用每个字母替换每个字符并检查回文 |
 | 最佳 | O(n) | O(n) | 扫描前半部分，将第一个非“a”替换为“a”，最后一个字符替换为“b” |

 ## 算法演练

 1. 如果输入字符串长度为1，则返回空字符串，因为单字符回文无法被破坏。 
2. 将输入字符串转换为字符列表，以便于变异。 
3. 循环遍历字符串的前半部分（索引 0 到 n//2 - 1）：

 1.如果当前字符不是`'a'`，将其替换为`'a'`并返回连接后的字符串。 
4. 如果前半部分的所有字符都是`'a'`，将最后一个字符替换为`'b'`。 
5. 返回修改后的字符串。 

**为什么有效**：替换最左边的非`'a'`字符保证字典最小化，因为进一步向右更改任何字符都会产生更大的字符串。 如果所有字符都是`'a'`，打破回文的唯一方法是更改​​最后一个字符，这也是字典顺序上可能的最小调整。 

## Python 解决方案```python
class Solution:
    def breakPalindrome(self, palindrome: str) -> str:
        n = len(palindrome)
        if n == 1:
            return ""
        
        chars = list(palindrome)
        for i in range(n // 2):
            if chars[i] != 'a':
                chars[i] = 'a'
                return "".join(chars)
        
        chars[-1] = 'b'
        return "".join(chars)
```该实现首先处理单字符字符串的简单情况。 然后，它将字符串转换为列表以允许就地突变。 通过仅扫描前半部分，它可以保证回文以字典顺序最小的方式被破坏。 最后，如果前半部分的所有字符都是`'a'`，它将最后一个字符更改为`'b'`最小限度地打破回文。 

## 解决方案```go
func breakPalindrome(palindrome string) string {
    n := len(palindrome)
    if n == 1 {
        return ""
    }
    
    chars := []byte(palindrome)
    for i := 0; i < n/2; i++ {
        if chars[i] != 'a' {
            chars[i] = 'a'
            return string(chars)
        }
    }
    
    chars[n-1] = 'b'
    return string(chars)
}
```Go 解决方案遵循相同的逻辑。 将字符串转换为字节片允许进行可变操作。 单字符处理和全“a”字符串的最后一个字符替换的实现方式相同。

 ## 边缘情况

 **单字符字符串**：像这样的字符串`"a"`或者`"z"`不能成为非回文。 该实现显式检查`len(palindrome) == 1`并返回一个空字符串。 

**所有“a”字符串**：诸如此类的字符串`"aa"`或者`"aaaa"`需要将最后一个字符更改为`'b'`最小限度地打破回文。 该代码通过检查前半部分并在之前没有发生替换的情况下替换最后一个字符来处理此问题。 

**奇数长度回文**：对于像这样的回文`"aba"`或者`"aaa"`, 中间的字符不能改为`'a'`如果已经存在，则最小化字典顺序`'a'`。 该算法仅正确扫描前半部分，并在需要时调整最后一个字符，确保正确性和最小的词典输出。
