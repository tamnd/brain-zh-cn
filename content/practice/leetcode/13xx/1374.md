[LeetCode 问题 1374](https://leetcode.com/problems/generate-a-string-with-characters-that-have-odd-counts/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 问题要求我们生成一个长度的字符串`n`这样**字符串中的每个字符出现奇数次**。 该字符串只能由小写英文字母组成。 输入`n`是一个范围从 1 到 500 的正整数，因此算法需要有效地处理小字符串和中等大的字符串。 输出可以是任何满足奇数条件的有效字符串； 它不需要匹配特定的模式。 

实际上，我们需要分配字符，以便每个字符出现奇数次。 一个关键的观察结果是，奇数长度的字符串可以完全用一个重复的字符填充，而偶数长度的字符串则需要至少两个不同的字符，以便每个字符出现奇数次。 该问题保证了`n`至少为 1，因此始终至少有一个有效解。 

重要的边缘情况包括最小的输入`n = 1`甚至像这样的数字`n = 2`，其中重复单个字符的简单解决方案将失败，因为重复偶数次的字符不满足要求。 

## 方法

 暴力方法会尝试生成所有可能的长度字符串`n`并检查每个字符的计数，这对于大的情况是不可行的`n`因为组合的数量呈指数增长。 

最佳方法利用了关键见解：**只有计数奇偶性重要**，而不是特定字符。 如果`n`是奇数，我们可以用重复的单个字符填充字符串`n`次。 如果`n`是偶数，我们可以重复一个字符`n - 1`次并使用不同的字符一次。 这保证了所有字符计数都是奇数并且字符串长度匹配`n`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(26^n) | O(26^n) | O(n) | 生成所有字符串、计算出现次数、检查奇数条件 |
 | 最佳 | O(n) | O(n) | 根据奇偶校验直接使用 1 或 2 个字符构造字符串 |

 ## 算法演练

 1. 检查是否`n`很奇怪。 
2.如果`n`是奇数，选择任意字符，例如`'a'`，然后重复`n`次。 这自动满足奇数计数条件，因为`n`很奇怪。 
3.如果`n`是偶数，选择两个字符，例如`'a'`和`'b'`。 重复`'a'` `n - 1`次和`'b'`一次。 这确保了`'a'`出现奇数次（`n - 1`，这很奇怪，因为`n`是偶数）并且`'b'`出现一次（奇数），满足要求。 
4. 返回结果字符串。 

**为什么有效：** 根据是否仔细选择每个字符的计数`n`是奇数还是偶数，我们保证每个字符都有奇数频率。 这种构造总是会生成有效的字符串，而不需要额外的检查。 

## Python 解决方案```python
class Solution:
    def generateTheString(self, n: int) -> str:
        if n % 2 == 1:
            return 'a' * n
        else:
            return 'a' * (n - 1) + 'b'
```在Python实现中，我们使用一个简单的条件检查来确定是否`n`是奇数还是偶数。 对于奇数`n`，我们重复`'a'` `n`次。 对于甚至`n`，我们重复`'a'` `n - 1`次并附加`'b'`。 这保证了所有字符都有奇数个并且字符串长度恰好是`n`。 

## 解决方案```go
func generateTheString(n int) string {
    if n % 2 == 1 {
        return strings.Repeat("a", n)
    } else {
        return strings.Repeat("a", n-1) + "b"
    }
}
```在 Go 中，我们使用`strings.Repeat`函数多次重复一个字符。 逻辑反映了 Python 解决方案：if`n`是奇数，重复`"a"` `n`次； 如果偶数，则重复`"a"` `n-1`次并附加`"b"`。 不需要对内存或切片进行特殊处理，因为 Go 可以有效地处理这种情况下的字符串连接。 

## 工作示例

 **示例 1：n = 4**`n`是均匀的。 我们重复`'a'` `4 - 1 = 3`次并附加`'b'`一次。

 **示例 2：n = 2**`n`是均匀的。 我们重复`'a'` `1`时间并附加`'b'`。 

细绳：`"ab"`计数：`'a': 1`,`'b': 1`- 都是奇数

 **示例 3：n = 7**`n`很奇怪。 我们重复`'a'` `7`次。 

细绳：`"aaaaaaa"`计数：`'a': 7`- 奇数

 ## 边缘情况

 **n = 1：** 这是最小的可能输入。 只需要一个字符，该字符自动为奇数。 该实现通过返回正确地处理了这个问题`'a'`。 

**偶数 n = 2：** 最小的偶数输入需要至少两个字符才能满足奇数计数条件。 该代码附加第二个字符`'b'`以确保两个计数都是奇数。 

**接近 500 的大 n：** 测试大的奇数和偶数可确保解决方案的扩展。 对于奇数`n`，单个字符重复； 对于甚至`n`, 重复一个字符`n-1`次并附加另一个字符。 这可以防止性能问题并保证正确性。
