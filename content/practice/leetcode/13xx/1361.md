[LeetCode 问题 1361](https://leetcode.com/problems/validate-binary-tree-nodes/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、并查找、图论、二叉树

 ## 解决方案

 ## 问题理解

 问题给了我们`n`节点标记为`0`到`n - 1`。 对于每个节点`i`，我们通过数组得知哪个节点是其左子节点，哪个节点是其右子节点`leftChild`和`rightChild`。 

如果`leftChild[i] = x`，然后节点`x`是节点的左子节点`i`。 同样，如果`rightChild[i] = y`，然后节点`y`是节点的右子节点`i`。 值为`-1`意味着孩子不存在。 

我们必须确定所有节点是否一起形成一棵有效的二叉树。 

有效的二叉树必须同时满足几个条件：

 - 必须只有一个根节点。 
- 除根节点外的每个节点都必须有一个父节点。 
- 结构必须是连接的，这意味着每个节点都可以从根到达。 
- 该结构不得包含循环。 

输入未明确提供根。 我们必须从亲子关系中推断出来。 

约束条件很重要：

 -`n`可以大到`10^4`- 每个节点最多有两个出边
 - 子值是`-1`或有效的节点索引

 自从`n`是相当大的，一个`O(n^2)`解决方案是不可取的。 我们的目标应该是线性或近线性算法。 

几种边缘情况很容易破坏简单的实现：

 - 一个节点可以有两个父节点。 
- 可能存在多个断开连接的组件。 
- 可能存在循环。 
- 可能有多个根。 
- 可能根本没有根。 
- 单节点树仍应被视为有效。 

关键的挑战是认识到所有四个有效性条件必须同时成立。 

## 方法

 ### 蛮力方法

 暴力策略将尝试通过独立检查每个节点来验证树。 

一种可能的暴力方法是：

 1. 将每个节点视为可能的根。 
2. 从该节点运行 DFS 或 BFS。 
3. 检查所有节点是否都被访问过一次。 
4. 验证没有循环。 
5. 验证没有节点有多个父节点。 

这是可行的，因为一棵有效的二叉树必须恰好有一个节点，从该节点可以访问所有其他节点，而无需重新访问任何节点。 

然而，这种方法效率低下，因为我们可能从每个节点运行遍历。 每次遍历成本`O(n)`，导致最坏情况的复杂性`O(n^2)`。 

和`n = 10^4`，二次复杂度不必要地昂贵。 

### 最佳方法

 关键的见解是有效的二叉树具有非常严格的结构属性：

 - 恰好有一个节点有入度`0`，这就是根。 
- 每个其他节点都有入度`1`。 
- 节点的入度不能大于`1`。 
- 从根开始，我们必须访问每个节点一次。 

我们可以直接计算入度，而不是测试每个节点作为根。 

我们首先处理所有子关系：

 - 如果任何节点收到两个父节点，则该结构立即无效。 
- 处理完所有边后，只有一个节点必须具有入度`0`。 

一旦我们识别出根，我们就执行 DFS 或 BFS：

 - 如果我们两次遇到一个节点，则存在循环。 
- 如果没有访问所有节点，则图将断开连接。 

这给出了一个干净的线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 从每个可能的根开始遍历 |
 | 最佳 | O(n) | O(n) | 使用入度分析加一次遍历 |

 ## 算法演练

 1. 创建一个大小为入度的数组`n`，初始化为`0`。 

节点的入度表示它有多少个父节点。 在一棵有效的二叉树中，除根之外的每个节点都必须有一个父节点。 
2. 迭代每个节点并处理其左子节点和右子节点。 

对于每个有效的子项：

 - 增加该孩子的入度。 
- 如果入度大于`1`，立即返回`False`。 

此步骤确保没有节点有多个父节点。 
3. 找到根节点。 

根是唯一保留入度的节点`0`。 

扫描入度数组时：

 - 计算有多少个节点有入度`0`。 
- 如果计数不准确`1`， 返回`False`。 

多个根意味着断开的组件。 没有根意味着有循环。 
4. 从根开始执行DFS或BFS。 

使用一个`visited`设置为跟踪已经看到的节点。 

遍历过程中：

 - 如果一个节点遇到两次，则存在循环，返回`False`。 
- 否则，继续遍历其子级。 
5. 遍历完成后，验证连通性。 

如果访问的节点数不等于`n`，某些节点无法从根到达。 

在这种情况下，返回`False`。 
6. 如果所有检查都通过，则返回`True`。 

### 为什么它有效

 该算法强制执行二叉树的每个结构要求。 

入度检查保证每个节点至多有一个父节点并且恰好存在一个根。 DFS 遍历保证不存在环并且图是全连接的。 由于所有必需的属性都经过验证，因此该结构必须是一棵有效的二叉树。 

## Python 解决方案```python
from typing import List

class Solution:
    def validateBinaryTreeNodes(
        self,
        n: int,
        leftChild: List[int],
        rightChild: List[int]
    ) -> bool:
        
        indegree = [0] * n

        # Build indegree array
        for node in range(n):
            left = leftChild[node]
            right = rightChild[node]

            if left != -1:
                indegree[left] += 1
                if indegree[left] > 1:
                    return False

            if right != -1:
                indegree[right] += 1
                if indegree[right] > 1:
                    return False

        # Find root
        roots = [i for i in range(n) if indegree[i] == 0]

        if len(roots) != 1:
            return False

        root = roots[0]

        # DFS traversal
        visited = set()
        stack = [root]

        while stack:
            node = stack.pop()

            if node in visited:
                return False

            visited.add(node)

            left = leftChild[node]
            right = rightChild[node]

            if left != -1:
                stack.append(left)

            if right != -1:
                stack.append(right)

        # Check connectivity
        return len(visited) == n
```实现首先构建入度数组。 每当一个节点作为子节点出现时，它的入度就会增加。 如果任何节点接收到多个父节点，该函数立即返回`False`。 

接下来，代码识别根。 一棵有效的树必须恰好包含一个具有入度的节点`0`。 如果有零根或多根，则该结构不能是有效的二叉树。 

DFS遍历使用栈和`visited`放。 该堆栈支持迭代遍历，而无需考虑递归深度。 这`visited`set 确保立即检测到循环。 

最后，算法检查是否每个节点都被访问过。 如果不是，则图表将断开连接。 

## 解决方案```go
func validateBinaryTreeNodes(n int, leftChild []int, rightChild []int) bool {
	indegree := make([]int, n)

	// Build indegree array
	for node := 0; node < n; node++ {
		left := leftChild[node]
		right := rightChild[node]

		if left != -1 {
			indegree[left]++
			if indegree[left] > 1 {
				return false
			}
		}

		if right != -1 {
			indegree[right]++
			if indegree[right] > 1 {
				return false
			}
		}
	}

	// Find root
	root := -1

	for i := 0; i < n; i++ {
		if indegree[i] == 0 {
			if root != -1 {
				return false
			}
			root = i
		}
	}

	if root == -1 {
		return false
	}

	// DFS traversal
	visited := make([]bool, n)
	stack := []int{root}

	for len(stack) > 0 {
		node := stack[len(stack)-1]
		stack = stack[:len(stack)-1]

		if visited[node] {
			return false
		}

		visited[node] = true

		left := leftChild[node]
		right := rightChild[node]

		if left != -1 {
			stack = append(stack, left)
		}

		if right != -1 {
			stack = append(stack, right)
		}
	}

	// Check connectivity
	count := 0
	for _, seen := range visited {
		if seen {
			count++
		}
	}

	return count == n
}
```Go 的实现与 Python 版本非常相似。 而不是Python的`set`，它使用一个名为的布尔切片`visited`。 DFS堆栈是用切片来实现的。 

Go 没有 Python 的列表推导式，因此根检测是通过标准循环完成的。 该实现还在最后显式地计算访问过的节点，因为 Go 切片不提供与 Python 等效的内置功能`len(set)`行为。

from typing import List

class Solution:
    def validateBinaryTreeNodes(
        self,
        n: int,
        leftChild: List[int],
        rightChild: List[int]
    ) -> bool:
        
        indegree = [0] * n

        for node in range(n):
            left = leftChild[node]
            right = rightChild[node]

            if left != -1:
                indegree[left] += 1
                if indegree[left] > 1:
                    return False

            if right != -1:
                indeegree = indegree[right] + 1
                indegree[right] = indeegree
                if indeegree > 1:
                    return False

        roots = [i for i in range(n) if indegree[i] == 0]

        if len(roots) != 1:
            return False

        root = roots[0]

        visited = set()
        stack = [root]

        while stack:
            node = stack.pop()

            if node in visited:
                return False

            visited.add(node)

            if leftChild[node] != -1:
                stack.append(leftChild[node])

            if rightChild[node] != -1:
                stack.append(rightChild[node])

        return len(visited) == n

 ## 边缘情况

 当节点有两个父节点时，会出现一个非常重要的边缘情况。 如果我们只从根开始进行 DFS 遍历，很容易忽略这一点。 例如，两个不同的节点可能都指向同一个子节点，同时仍然形成以其他方式连接的结构。 天真的遍历可能仍然只访问所有节点一次，并错误地得出图表有效的结论。 入度检查通过立即拒绝任何入度超过的节点来防止这种情况发生`1`。 

另一个关键的边缘情况是循环。 在循环图中，每个节点可能只有一个父节点，因此仅进行入度分析是不够的。 例如，节点`0`可能指向节点`1`而节点`1`指向回节点`0`。 DFS 遍历通过检测重新访问来正确处理此问题`visited`放。 

断开连接的图表也很微妙。 可以有一个完全有效的树组件加上几个孤立的节点。 此类输入可能仍仅包含主组件中的一个根，因此仅检查根是不够的。 最终的连接检查确保每个节点都可以从根到达。 

最后的边缘情况涉及多个根。 如果存在两棵独立的树，则多个节点将具有入度`0`。 该实现显式地计算根的数量并拒绝任何不具有唯一根的结构。
