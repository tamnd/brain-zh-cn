[LeetCode 1360 题](https://leetcode.com/problems/number-of-days- Between-two-dates/)

 **难度：** 🟢简单
 **主题：** 数学、字符串

 ## 解决方案

 ## 问题理解

 问题给出了格式中的两个日期`YYYY-MM-DD`并要求我们计算它们之间的绝对天数。 

每个输入字符串代表一个有效的日历日期。 年、月、日用连字符分隔。 例如：

-`"2019-06-29"`指 2019 年 6 月 29 日
 -`"2020-01-15"`指 2020 年 1 月 15 日

 预期输出是一个整数，表示两个日期相隔多少天。 日期的顺序并不重要，因为答案是绝对差异。 

主要挑战是正确处理公历，尤其是闰年。 闰年有 366 天，而不是 365 天，这会影响二月的天数。 

如果满足以下条件，一年就是闰年：

 - 能被 400 整除，或者
 - 能被4整除但不能被100整除

 示例：

 - 2020年是闰年
 - 2000年是闰年
 - 1900 年不是闰年

 限制相对较小，日期仅在 1971 年至 2100 年之间。即使是简单的模拟方法也可以在这些限制内发挥作用。 然而，更清晰、更具可扩展性的解决方案是将每个日期转换为距固定参考点的天数，然后计算绝对差。 

一些边缘情况很重要：

 - 同月的日期
 - 不同月份的日期
 - 不同年份的日期
 - 闰年过渡，尤其是 2 月 29 日
 - 输入在哪里`date1 > date2`- 边界年份，如 1971 年和 2100 年

 该问题保证所有日期都有效，因此我们不需要自己验证月份范围或日期范围。 

## 方法

 ### 蛮力方法

 蛮力方法模拟从一个日期到另一个日期的日常运动。 

这个想法很简单：

 1. 确定哪个日期较早。 
2. 反复将较早的日期提前一天。 
3. 计算需要多少增量，直到日期相等。 

为了正确提前日期，我们必须：

 - 了解每个月的天数
 - 处理闰年
 - 当日期超过月份限制时移至下个月
 - 当月份超过 12 月时移至下一年

 这种方法是正确的，因为每次迭代都恰好代表一个日历日。 

然而，它的效率很低，因为我们可能需要模拟数万天。 虽然约束足够小，可以通过，但该方法不必要地复杂且比所需的速度慢。 

### 最佳方法

 更好的方法将每个日期转换为一个整数，表示自固定参考日期以来经过的总天数。 

例如：

 - 计算从 0 年到目标年的所有天数
 - 添加当年已完成月份中的所有天数
 - 添加当前日期

 将两个日期转换为天数后，答案将变为：```
abs(days1 - days2)
```关键的见解是，一旦日期被表示为累积天数，比较日期就变得微不足道。 

这避免了重复模拟并将问题简化为算术问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(D) | O(1) | O(1) | 模拟两个日期之间的每一天 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 将每个日期转换为绝对天数 |

 这里，`D`是两个日期之间的天数。 

## 算法演练

 ### 最优算法

 1. 将日期字符串解析为年、月、日的整数。 

输入格式固定为`YYYY-MM-DD`，所以我们可以将字符串分割为`"-"`并将每个部分转换为整数。 
2. 创建一个辅助函数来确定某一年是否为闰年。 

这是必要的，因为二月有 28 天或 29 天，具体取决于年份。 
3. 创建一个辅助函数，将日期转换为经过的总天数。 

该函数计算：

 - 由当年之前的完整年份贡献的所有天数
 - 当月之前完整月份贡献的所有天数
 - 当日值
 4. 计算往年的天数。 

对于当前年份之前的每一年：

 - 添加 365 天
 - 如果年份是闰年，则额外添加 1 天
 5. 计算当年前几个月的天数。 

使用月份长度数组：```
[31,28,31,30,31,30,31,31,30,31,30,31]
```如果当前年份是闰年，则 2 月变为 29 天。 
6. 添加当前日期。 

处理完月份后，添加日期值本身。 
7. 计算绝对差。 

将两个日期转换为总天数并返回：```
abs(days1 - days2)
```### 为什么它有效

 该算法之所以有效，是因为每个日期都映射到从固定原点测量的唯一累积天数。 两个累积计数之间的差异恰好是日期之间间隔的天数。 在年和月计算期间显式处理闰年，确保正确表示日历结构。 

## Python 解决方案```python
class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        
        def is_leap(year: int) -> bool:
            return (
                year % 400 == 0 or
                (year % 4 == 0 and year % 100 != 0)
            )
        
        def to_days(date: str) -> int:
            year, month, day = map(int, date.split("-"))
            
            month_days = [
                31, 28, 31, 30, 31, 30,
                31, 31, 30, 31, 30, 31
            ]
            
            total_days = 0
            
            # Add days from previous years
            for y in range(year):
                total_days += 365
                if is_leap(y):
                    total_days += 1
            
            # Adjust February for leap year
            if is_leap(year):
                month_days[1] = 29
            
            # Add days from previous months
            for m in range(month - 1):
                total_days += month_days[m]
            
            # Add current day
            total_days += day
            
            return total_days
        
        return abs(to_days(date1) - to_days(date2))
```实施开始于`is_leap`辅助函数，封装了闰年规则。 将此逻辑分离到其自己的函数中可以提高可读性并避免重复。 

这`to_days`帮助器将日期字符串转换为累积天数。 首先，将日期解析为整数。 然后，我们迭代目标年之前的所有年份，并根据该年是否为闰年添加 365 或 366 天。 

接下来，如果当前年份是闰年，我们会调整二月。 之后，我们添加当前月份之前所有已完成月份的长度。 

最后，我们添加当天本身并返回总累计计数。 

主函数只是计算两个转换值之间的绝对差。 

## 解决方案```go
func daysBetweenDates(date1 string, date2 string) int {

	isLeap := func(year int) bool {
		return year%400 == 0 || (year%4 == 0 && year%100 != 0)
	}

	toDays := func(date string) int {
		var year, month, day int
		fmt.Sscanf(date, "%d-%d-%d", &year, &month, &day)

		monthDays := []int{
			31, 28, 31, 30, 31, 30,
			31, 31, 30, 31, 30, 31,
		}

		totalDays := 0

		// Add days from previous years
		for y := 0; y < year; y++ {
			totalDays += 365
			if isLeap(y) {
				totalDays++
			}
		}

		// Adjust February for leap year
		if isLeap(year) {
			monthDays[1] = 29
		}

		// Add days from previous months
		for m := 0; m < month-1; m++ {
			totalDays += monthDays[m]
		}

		// Add current day
		totalDays += day

		return totalDays
	}

	result := toDays(date1) - toDays(date2)

	if result < 0 {
		return -result
	}

	return result
}
```Go 解决方案遵循与 Python 版本相同的逻辑。 主要区别在于日期解析。 而不是`split`, Go 使用`fmt.Sscanf`直接从格式化字符串中提取年、月和日值。 

Go does not provide a built-in absolute value function for integers in the standard library without conversion, so the code manually checks whether the result is negative.

 切片用于表示月份长度，类似于 Python 列表。

 ## 边缘情况

 ### 闰年二月

 二月左右的日期是最常见的错误来源，因为二月的长度会根据年份而变化。 例如，2020 年有 2 月 29 日，而 2019 年则没有。 如果实现始终假设 2 月有 28 天，则对于闰年，答案将变得不正确。 该解决方案通过在当前年份满足闰年条件时将 2 月动态更改为 29 天来处理此问题。 

### 相同的输入日期

 如果两个日期相同，则正确答案是`0`。 一些实现意外返回`1`因为它们计算包含范围而不是差异。 此实现避免了该问题，因为它将两个日期转换为累积计数并直接将它们相减。 

### 日期按相反顺序给出

 问题并不能保证`date1`早于`date2`。 简单的减法可能会产生负结果。 该实现通过返回差值的绝对值来解决这个问题，确保输出始终为非负数。 

### 年份边界转换

 手动模拟日期时，像 12 月 31 日到 1 月 1 日这样的过渡很容易处理不当。 累积天数方法自然可以处理年份翻转，因为总天数在年份中不断增加。 

### 闰年规则

 能被 100 整除的年份不是闰年，除非它们也能被 400 整除。这条规则很容易被忘记。 例如：

 - 1900 年不是闰年
 - 2000年是闰年

 该实现显式地将此规则编码在`is_leap`功能，确保正确的日历计算。
