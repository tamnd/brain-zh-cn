 **难度：** 🟡 中等
 **主题：** 数组、字符串、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们取一个字符串`s`包含由单个空格分隔的多个单词，并返回表示垂直书写的单词的字符串列表。 换句话说，输出的每一列对应于原始单词中同一位置的字符。 如果单词比最长的单词短，则缺失的字符将被视为空格，但应删除每个垂直字符串中的尾随空格。 

例如，如果输入是`"HOW ARE YOU"`，第一个垂直字符串由每个单词的第一个字母构成，给出`"HAY"`。 第二个垂直字符串由每个单词的第二个字母组成，给出`"ORO"`，第三个给出`"WEU"`。 

约束告诉我们输入长度相对较小（`1 <= s.length <= 200`) 并且只包含大写英文字母，并且单词之间只有一个空格。 这保证了我们不需要处理多个连续的空格或空字，但我们确实需要正确处理不同长度的单词。 

重要的边缘情况包括具有单个字母的字符串、其中一个单词比其他单词长得多的字符串，以及尾随空格出现在垂直输出中但必须删除的字符串。 

## 方法

 一种暴力方法将涉及迭代每个单词并尝试一次构建一个字符的每个垂直字符串。 这种方法将涉及嵌套循环，其中外部循环迭代字符位置直至最长单词的长度，而内部循环迭代单词。 对于每个位置，如果存在字符，我们会附加该字符；如果不存在，我们会附加一个空格。 最后，我们修剪每个垂直字符串的尾随空格。 虽然这很简单，但需要额外的步骤来管理尾随空格，并且实施起来可能不太干净。 

最佳解决方案的关键在于认识到我们可以首先计算最大字长，然后直接逐列迭代。 通过检查单词在当前列索引处是否有字符，我们追加它或空格。 构造每个垂直字符串后，修剪尾随空格可确保我们满足输出约束。 这种方法干净、高效，并且直接符合问题的要求。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n * m) | 使用嵌套循环构建每个垂直字符串，手动处理空格 |
 | 最佳 | O(n * m) | O(n * m) | 预先计算最大字长、逐列迭代、修剪尾随空格 |

 这里，`n`是单词数，`m`是最长单词的长度。 

## 算法演练

 1.分割输入字符串`s`使用空格字符作为分隔符进入单词列表。 这提供了对每个单词的直接访问。 
2. 计算所有单词中的最大单词长度。 这决定了要生成的垂直字符串的数量。 
3.初始化一个空列表`result`存储最终的垂直字符串。 
4. 迭代每个列索引`0`到`max_length - 1`。 
5.对于每个列索引，初始化一个空字符串`vertical_word`。 
6. 迭代每个单词。 如果该单词在当前列索引处有一个字符，则将其附加到`vertical_word`。 如果没有，请添加一个空格。 
7. 处理完当前列的所有单词后，去掉尾随空格`vertical_word`并将其附加到`result`。 
8. 处理完所有列索引后，返回`result`列表。 

工作原理：每个垂直字符串与原始单词中的一列字符完全对应。 通过迭代到最大单词长度并为较短的单词添加空格，然后修剪尾随空格，我们保证每个垂直字符串都具有正确的字符并且没​​有尾随空格。 这会产生所需的垂直表示。 

## Python 解决方案```python
from typing import List

class Solution:
    def printVertically(self, s: str) -> List[str]:
        words = s.split()
        max_length = max(len(word) for word in words)
        result = []
        
        for i in range(max_length):
            vertical_word = ""
            for word in words:
                if i < len(word):
                    vertical_word += word[i]
                else:
                    vertical_word += " "
            result.append(vertical_word.rstrip())
        
        return result
```Python 实现将输入字符串拆分为单词并计算最大单词长度。 对于每个列索引，它会迭代所有单词，在该索引处附加字符（如果存在），否则附加空格。 这`rstrip()`函数在将字符串附加到结果列表之前删除所有尾随空格。 

## 解决方案```go
func printVertically(s string) []string {
    words := strings.Fields(s)
    maxLength := 0
    for _, word := range words {
        if len(word) > maxLength {
            maxLength = len(word)
        }
    }

    result := []string{}
    for i := 0; i < maxLength; i++ {
        var sb strings.Builder
        for _, word := range words {
            if i < len(word) {
                sb.WriteByte(word[i])
            } else {
                sb.WriteByte(' ')
            }
        }
        verticalWord := strings.TrimRight(sb.String(), " ")
        result = append(result, verticalWord)
    }

    return result
}
```在围棋中，`strings.Fields`用于将输入字符串拆分为单词。 我们计算最大字长，对于每一列，我们使用`strings.Builder`有效构建垂直词。 使用删除尾随空格`strings.TrimRight`。

 ## 边缘情况

 1. **单字符输入：**时`s`仅包含一个字符，输出应该是一个列表，其中包含一个包含该字符的字符串。 这测试了最小的输入处理。 
2. **不同的单词长度：** 如果某些单词比其他单词长，则在垂直字符串中引入中间空格。 该算法通过附加空格然后去除尾随空格来处理此问题。 
3. **最大长度字符串：** 如果`s`即使长度为 200 个字符，算法仍然可以正确分割、计算最大字长并构造垂直字符串，而不会超出内存限制或运行时间，从而确认解决方案可以扩展到问题的上限约束。
