[LeetCode 1331 题](https://leetcode.com/problems/rank-transform-of-an-array/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们在数组按升序排序时用其排名替换输入数组中的每个数字。 

排名由值的相对顺序定义：

 - 最小的唯一值获得排名`1`- 第二小的唯一值获得排名`2`- 相同的值必须获得相同的排名
 - 排名应该是连续的并且尽可能小

 输入是一个整数数组`arr`，输出应该是另一个相同长度的数组，其中每个元素已被其相应的排名替换。 

例如，考虑：```
arr = [40, 10, 20, 30]
```如果我们对唯一值进行排序：```
[10, 20, 30, 40]
```那么他们的排名就变成了：```
10 -> 1
20 -> 2
30 -> 3
40 -> 4
```将这些映射应用回原始顺序会产生：```
[4, 1, 2, 3]
```约束条件很重要：

 - 该数组最多可以包含`10^5`元素
 - 值的范围可以是`-10^9`到`10^9`因为输入可能非常大，所以我们需要一种比二次时间更好的算法。 任何直接将每个元素与其他元素进行比较的方法都会太慢。 

有几个重要的边缘情况需要记住：

 - 空数组应该返回空数组
 - 所有元素都相同的数组应分配排名`1`到处
 - 负数仍必须正确排列
 - 重复的值必须始终共享相同的排名
 - 非常大的数组需要高效的基于排序的解决方案

 ## 方法

 ### 蛮力方法

 一种简单的方法是独立计算每个元素的排名。 

对于数组中的每个元素，我们可以计算有多少个不同的值小于它。 那么排名将是：```
(number of distinct smaller elements) + 1
```例如：```
arr = [40, 10, 20, 30]
```为了`40`，较小的不同值是：```
[10, 20, 30]
```所以它的排名是`4`。 

这是正确的，因为排名完全取决于有多少唯一值较小。 

然而，这种方法效率低下。 对于每个元素，我们可以再次扫描整个数组以确定更小的唯一值。 这导致大约`O(n^2)`时间复杂度，对于`10^5`元素。 

### 最佳方法

 关键的观察结果是排名仅取决于唯一值的排序顺序。 

我们可以：

 1. 提取所有唯一值
 2. 对它们进行排序
 3. 按顺序分配排名
 4. 将映射存储在哈希映射中
 5. 使用map替换每个原始值

 这是有效的，因为对唯一值进行排序会立即为我们提供准确的排名顺序。 

哈希映射允许在将原始数组转换为等级时进行恒定时间查找。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 将每个元素与所有其他元素进行比较 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对唯一值进行一次排序，然后映射排名 |

 ## 算法演练

 ### 最优算法

 1. 从输入数组创建一个集合。 

该集合会自动删除重复项。 由于相同的值共享相同的排名，因此在分配排名时我们只关心唯一的数字。 
2. 按升序对唯一值进行排序。 

排序建立正确的排名顺序。 最小的数字应该获得排名`1`，下一个最小的应该获得排名`2`， 等等。 
3. 创建一个哈希图来存储排名。 

迭代排序的唯一值并按顺序分配排名。 

例子：```
sorted_unique = [10, 20, 30, 40]
```建造：```
{
    10: 1,
    20: 2,
    30: 3,
    40: 4
}
```4. 遍历原数组。 

对于每个值，在哈希映射中查找其排名并将其附加到结果数组中。 
5. 返回结果。 

### 为什么它有效

 该算法之所以有效，是因为对唯一值进行排序会产生排名规则所需的确切顺序。 在排序列表中，每个较小的唯一数字都出现在较大数字之前。 按顺序分配排名可以保证：

 - 较小的值获得较小的排名
 - 相同的值获得相同的排名
 - 排名保持连续且最低限度

 哈希映射保留了这种关系并允许有效地重建转换后的数组。 

## Python 解决方案```python
from typing import List

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        # Get all unique values and sort them
        sorted_unique = sorted(set(arr))

        # Assign ranks starting from 1
        rank_map = {}

        for index, value in enumerate(sorted_unique):
            rank_map[value] = index + 1

        # Replace each value with its rank
        result = []

        for value in arr:
            result.append(rank_map[value])

        return result
```实现首先将数组转换为集合以删除重复项。 这很重要，因为相同的值必须具有相同的等级。 

接下来，对唯一值进行排序。 他们的排名直接决定了他们的排名。 

有一本字典叫`rank_map`存储从值到排名的映射。 使用`enumerate`，我们分配排名开始于`1`。 

最后，我们迭代原始数组并用其映射的排名替换每个值。 由于字典查找平均时间是恒定的，因此这一步非常有效。 

## 解决方案```go
package main

import "sort"

func arrayRankTransform(arr []int) []int {
    // Handle empty input
    if len(arr) == 0 {
        return []int{}
    }

    // Create a set of unique values
    uniqueSet := make(map[int]bool)

    for _, value := range arr {
        uniqueSet[value] = true
    }

    // Convert set to slice
    uniqueValues := make([]int, 0, len(uniqueSet))

    for value := range uniqueSet {
        uniqueValues = append(uniqueValues, value)
    }

    // Sort unique values
    sort.Ints(uniqueValues)

    // Assign ranks
    rankMap := make(map[int]int)

    for index, value := range uniqueValues {
        rankMap[value] = index + 1
    }

    // Build result
    result := make([]int, len(arr))

    for index, value := range arr {
        result[index] = rankMap[value]
    }

    return result
}
```Go 解决方案遵循与 Python 版本相同的整体算法。 

由于 Go 没有内置的集合类型，`map[int]bool`用于模拟一个。 唯一值被收集到一个切片中，并使用排序`sort.Ints`，然后映射到等级。 

为了提高效率，结果切片预先分配了正确的长度。 

Go 切片自然会处理空数组，因此为空输入返回空切片很简单。

 ## 边缘情况

 ### 空数组

 空输入数组是错误的常见来源，因为某些实现假设至少存在一个元素。 在这个问题中，一个空数组应该简单地返回另一个空数组。 

该实现自然地处理了这个问题，因为：```
sorted(set([]))
```生成一个空列表，并且迭代原始数组不会向结果添加任何内容。 

### 所有元素都相等

 如果每个元素都相同，则所有位置都必须获得排名`1`。 

如果在排名之前未删除重复项，则有错误的实现可能会意外地将递增的排名分配给重复值。 

使用集合可保证仅对唯一值进行排名。 由于只有一个不同的值，因此它正确地获得排名`1`，并且每次出现都映射到相同的排名。 

### 负数和大数

 约束允许的值来自`-10^9`到`10^9`。 一些不正确的解决方案可能仅假设非负数或使用基于值的数组索引。 

此实现完全避免了该问题，因为它使用排序和哈希映射而不是直接按值索引。 Python 整数和 Go 整数都安全地支持此问题所需的范围。
