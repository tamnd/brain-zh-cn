## 问题理解

 该问题提供了一个二进制`m x n`矩阵`mat`，其中每个元素是`1`（代表士兵）或`0`（代表平民）。 在每一排中，士兵始终位于平民**之前**，这意味着所有士兵`1`s 出现在行的左侧，后面是`0`s。 任务是确定`k`最弱的行，其中一行的弱点主要取决于其所包含的士兵数量。 如果两行的士兵数量相同，则索引较小的行被认为较弱。 

输入由一个矩阵和一个整数组成`k`。 输出是行索引的列表`k`最弱的行，从最弱到最强排序。 

约束告诉我们矩阵维度适中（`2 <= m, n <= 100`），因此检查每一行的简单解决方案是可行的，但不一定是最佳的。 边缘情况包括完全是士兵的行、完全是平民的行或与士兵数量相关的行。 

## 方法

 暴力方法涉及通过迭代所有元素来计算每行中士兵的数量，将这些计数及其行索引存储起来，然后按士兵计数和行索引对列表进行排序。 这种方法有效，但没有利用以下事实：所有`1`s 在左侧，因此可以优化计数。 

最佳方法是在每行中使用二分搜索来查找士兵的数量。 因为所有的士兵都在左边，所以第一次出现`0`表示边界。 一旦我们知道了士兵的数量，我们就将每个计数与其行索引配对，然后根据计数和索引进行排序，以有效地检索最弱的行。

 ## 算法演练

 1. 初始化一个空列表来存储成对的`(soldier_count, row_index)`对于所有行。 
2. 对于矩阵中的每一行：

 1. 执行二分查找找到第一个`0`。 这个的索引`0`是该排士兵的数量。 
2. 存储该对`(soldier_count, row_index)`在列表中。 
3. 首先按士兵数量，然后按行索引对配对列表进行排序。 
4. 提取第一个`k`排序列表中的行索引。 
5. 返回这些索引作为结果。 

工作原理：二分查找可确保我们在每行 O(log n) 时间内有效找到士兵数量，对对进行排序可确保通过行索引解决关系问题。 因此，输出始终代表`k`正确地显示最弱的行。 

## Python 解决方案```python
from typing import List
import bisect

class Solution:
    def kWeakestRows(self, mat: List[List[int]], k: int) -> List[int]:
        soldier_counts = []
        
        for index, row in enumerate(mat):
            # Use binary search to find the first 0 in the row
            count = bisect.bisect_left(row, 0)
            soldier_counts.append((count, index))
        
        # Sort by soldier count, then by row index
        soldier_counts.sort()
        
        # Extract the first k indices
        return [index for _, index in soldier_counts]
```实现首先使用`bisect_left`来自Python的`bisect`模块来定位第一个`0`在每一行中，有效地计算 O(log n) 中的士兵。 我们将此计数与行索引配对，对列表进行排序，然后提取`k`最弱的行索引。 这与算法步骤精确匹配。 

## 解决方案```go
import "sort"

func kWeakestRows(mat [][]int, k int) []int {
    type pair struct {
        count int
        index int
    }
    
    soldierCounts := make([]pair, len(mat))
    
    for i, row := range mat {
        left, right := 0, len(row)
        for left < right {
            mid := left + (right-left)/2
            if row[mid] == 1 {
                left = mid + 1
            } else {
                right = mid
            }
        }
        soldierCounts[i] = pair{count: left, index: i}
    }
    
    sort.Slice(soldierCounts, func(i, j int) bool {
        if soldierCounts[i].count == soldierCounts[j].count {
            return soldierCounts[i].index < soldierCounts[j].index
        }
        return soldierCounts[i].count < soldierCounts[j].count
    })
    
    result := make([]int, k)
    for i := 0; i < k; i++ {
        result[i] = soldierCounts[i].index
    }
    
    return result
}
```在 Go 中，我们定义一个`pair`结构体来存储`(count, index)`并使用二分搜索循环来计算士兵数量。 切片使用排序`sort.Slice`使用尊重士兵计数和行索引的自定义比较器。 然后我们收集第一个`k`结果切片的索引。
