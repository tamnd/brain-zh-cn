[LeetCode 问题 1317](https://leetcode.com/problems/convert-integer-to-the-sum-of-two-no-zero-integers/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们分割给定的整数`n`化为两个正整数`a`和`b`这样：

 -`a + b = n`- 两者都不`a`也不`b`包含数字`0`十进制表示形式中的任何位置
 这样的整数称为_无零整数_。 
输入是单个整数`n`，输出应该是包含两个有效整数的列表或切片。 该问题保证至少有一个有效答案始终存在，因此我们不需要处理不可能的情况。 

例如，如果`n = 11`，一个有效答案是`[2, 9]`因为：

-`2`不包含`0`-`9`不包含`0`-`2 + 9 = 11`然而，`[10, 1]`将会无效，因为`10`包含数字`0`。 

限制很小：

 -`2 <= n <= 10^4`这立即告诉我们，效率并不是主要问题。 即使是对所有可能的分裂进行简单的暴力搜索`n`是完全可行的，因为最多有大约`10,000`的可能性。 

仍有一些重要的边缘情况需要考虑：

 - 非常小的值，例如`n = 2`，其中唯一有效的分割是`[1, 1]`- 在一个分量中自然产生零的数字，例如`n = 101`- 一个候选者包含多个零的情况，例如`1000`- 确保我们正确拒绝诸如`10`,`20`， 或者`101`解决方案始终存在的问题保证简化了实现，因为一旦我们找到有效的对，我们就可以立即返回它。 

## 方法

 ### 暴力方法

 最直接的解决办法就是尝试每一个可能的分割`n`。 

我们迭代所有整数`a`从`1`到`n - 1`。 对于每个值：

 - 计算`b = n - a`- 检查是否`a`包含数字`0`- 检查是否`b`包含数字`0`如果两个数字都是有效的非零整数，我们返回该对。 

要检查数字是否包含零，我们可以将其转换为字符串并搜索字符`'0'`。 

这种方法保证有效，因为我们检查了每个可能的分解`n`化为两个正整数。 由于问题保证存在有效答案，因此我们最终会找到一个。 

因为`n`至多是`10^4`，这个暴力解决方案已经足够快了。 

### 关键见解

 关键的观察结果是搜索空间非常小。 

不需要高等数学、动态规划或贪婪优化。 我们只需要一种有效的方法来测试一个数字是否包含零数字。 

因此，最佳的实际解决方案仍然基于暴力，但实施得干净而高效：

 - 迭代所有候选对
 - 使用辅助函数来验证非零整数
 - 一旦找到有效的配对，立即返回

 这对于给定的约束是最佳的，因为在实践中搜索完成得非常快。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * d) | O(d) | 尝试每个分割并使用字符串转换检查数字 |
 | 最佳| O(n * d) | O(d) | 同样实用的方法，足够高效，因为约束很小 |

 这里，`d`表示正在检查的数字中的位数。 自从`n <= 10^4`,`d`至多是`5`。 

## 算法演练

 1. 创建辅助函数`is_no_zero(num)`确定一个数字是否包含该数字`0`。 
2. 在辅助函数内，将整数转换为字符串并检查是否`'0'`存在于字符串表示形式中。 
3. 迭代所有可能的第一个数字`a`从`1`到`n - 1`。 
4. 对于每个`a`，将第二个数字计算为`b = n - a`。 
5. 检查两者是否`a`和`b`是使用辅助函数的非零整数。 
6. 一旦我们找到有效的对，就返回`[a, b]`。 
7. 由于问题保证至少存在一个解，因此算法总是会在循环结束之前返回。 

### 为什么它有效

 该算法检查所有可能的写入方式`n`作为两个正整数之和。 对于每一对，它验证问题所需的确切属性，即两个数字都不包含该数字`0`。 因为每个可能的对都会被检查，所以找到的第一个有效对一定是正确的答案。 

## Python 解决方案```python
from typing import List

class Solution:
    def getNoZeroIntegers(self, n: int) -> List[int]:
        def is_no_zero(num: int) -> bool:
            return '0' not in str(num)

        for a in range(1, n):
            b = n - a

            if is_no_zero(a) and is_no_zero(b):
                return [a, b]

        return []
```实现首先定义一个名为的辅助函数`is_no_zero`。 该函数将数字转换为字符串并检查字符是否`'0'`出现在其中的任何地方。 如果不是，则该数字满足非零条件。 

主循环迭代所有可能的值`a`从`1`到`n - 1`。 对于每个候选人，我们计算`b`以便`a + b = n`。 

然后我们使用辅助函数验证这两个数字。 一旦我们找到有效的对，我们就会立即将其返回。 因为问题保证了解决方案的存在，所以后备`return []`在有效执行期间永远不会到达语句，但它使函数在语法上保持完整。 

## 解决方案```go
package main

import "strconv"

func getNoZeroIntegers(n int) []int {
	isNoZero := func(num int) bool {
		s := strconv.Itoa(num)

		for _, ch := range s {
			if ch == '0' {
				return false
			}
		}

		return true
	}

	for a := 1; a < n; a++ {
		b := n - a

		if isNoZero(a) && isNoZero(b) {
			return []int{a, b}
		}
	}

	return []int{}
}
```Go 解决方案遵循与 Python 实现完全相同的逻辑。 

一个区别是 Go 没有 Python 的方便`'0' not in str(num)`语法，因此我们显式迭代数字的字符串表示形式并检查每个字符。 

该函数返回一个整数切片。 由于问题保证存在解决方案，因此包含末尾的空切片只是为了完整性。 

整数溢出不是问题，因为最大值只是`10^4`。

 ## 边缘情况

 一种重要的边缘情况是最小输入值，`n = 2`。 分裂只有一种可能，`[1, 1]`。 有缺陷的实现可能会错误地从以下位置开始迭代`0`，这将违反两个整数必须为正数的要求。 我们的实施从`1`，所以它可以正确处理这个问题。 

另一个重要的情况涉及包含零的数字，例如`n = 101`。 许多候选对将包括类似的数字`10`,`20`， 或者`100`，这些都是无效的。 辅助函数通过字符串转换显式检查每个数字，因此这些数字会被正确拒绝。 

第三个重要的边缘情况是十的大幂，例如`1000`或者`10000`。 这些数字自然会产生许多无效的分解，因为零经常出现在十进制表示中。 暴力搜索仍然有效，因为搜索空间很小，并且算法只是跳过无效对，直到找到有效对。 

一个微妙的边缘情况是前几个候选对无效。 例如，与`n = 11`，这对`(1, 10)`失败是因为`10`包含一个零。 算法必须继续搜索，而不是在第一次失败后停止。 我们的循环将继续，直到找到有效的对。
