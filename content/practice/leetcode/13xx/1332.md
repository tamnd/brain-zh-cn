[LeetCode 问题 1332](https://leetcode.com/problems/remove-palindromic-subsequences/)

 **难度：** 🟢简单
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅包含字符`'a'`和`'b'`。 在一次操作中，我们可以删除字符串的任何子序列，只要该子序列形成回文即可。 

子序列与子字符串不同。 子字符串必须是连续的，但子序列可以跳过字符，同时保留相对顺序。 例如，在字符串中`"baabb"`，子序列`"baab"`可以通过在索引处获取字符来形成`0, 1, 2, 4`。 

目标是确定完全删除字符串所需的最少操作数。 

关键细节是我们要删除回文子序列，而不是回文子串。 这使得问题比最初看起来容易得多。 

约束很小，`1 <= s.length <= 1000`，但真正的见解是答案只能是`1`或者`2`。 

如果整个字符串本身已经是回文，那么我们可以通过一次操作将其删除。 

如果字符串不是回文，我们总是可以删除所有`'a'`一次操作中的字符和所有`'b'`另一个操作中的字符。 由于完全由一个重复字符组成的序列始终是回文，因此两种删除都是有效的。 

这意味着：

 - 如果`s`是回文，答案是`1`- 否则，答案是`2`不存在需要两次以上操作的情况，因为字符串仅包含两个不同的字符。 

一些重要的边缘情况包括：

 - 单字符字符串，例如`"a"`或者`"b"`，这始终是回文。 
- 具有所有相同字符的字符串，例如`"aaaa"`，一步即可去除。 
- 非回文混合字符串，例如`"abb"`或者`"baabb"`，这需要两次操作。 
- 该问题保证字符串非空且仅包含`'a'`和`'b'`，所以我们不需要处理无效字符或空输入。 

## 方法

 ### 蛮力方法

 暴力解决方案将尝试模拟以所有可能的方式删除回文子序列的过程。 

对于每一步，我们都可以生成当前字符串的每个可能的子序列，检查它是否是回文，将其删除，并递归计算最少的剩余操作。 

这种方法在理论上是正确的，因为它探索每个有效的移除序列并最终找到最佳答案。 

然而，这在计算上是不可行的。 一个长度的字符串`n`有`2^n`可能的子序列。 递归地检查所有子序列将导致指数时间复杂度，即使对于相对较小的值，这也变得不切实际`n`。 

虽然约束条件只是`1000`，指数算法在这种规模上是完全不可能的。 

### 最佳方法

 关键的观察结果是该字符串仅包含两个字符：`'a'`和`'b'`。 

如果字符串已经是回文，我们可以通过一次操作删除整个字符串。 

如果它不是回文，我们仍然可以通过两个操作来完成：

 1. 全部删除`'a'`字符作为一个回文子序列。 
2. 全部删除`'b'`字符作为另一个回文子序列。 

任何完全由一个重复字符组成的序列自动成为回文。 

因此，答案永远不会大于`2`。 

整个问题简化为检查字符串本身是否是回文。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) 或更糟 | O(2^n) | O(2^n) | 生成并测试所有回文子序列 |
 | 最佳| O(n) | O(1) | O(1) | 检查字符串是否为回文 |

 ## 算法演练

 1.从输入字符串开始`s`。 
2. 检查是否`s`向前读和向后读都一样。 

这可以使用两个指针来完成：

 - 一个指针从头开始。 
- 一个指针从末尾开始。 

在每一步中，比较字符。 
3. 如果每个镜像对都匹配，则该字符串是回文。 

由于整个字符串本身就是一个回文子序列，因此我们可以通过一次操作将其删除。 
4. 如果任意一对字符不匹配，则该字符串不是回文。 

在这种情况下，我们知道我们始终可以：

 - 删除所有`'a'`一次操作中的字符。 
- 删除所有`'b'`另一个操作中的字符。 

因此，返回`2`。 

### 为什么它有效

 正确性取决于两个事实：

 - 任何由相同字符组成的字符串都是回文。 
- 输入仅包含`'a'`和`'b'`。 

如果整个字符串是回文，则一次操作就足够了。 

否则，所有`'a'`来自一个回文子序列和所有的字符`'b'`字符形成另一个字符。 删除两者可以保证字符串最多在两次操作中变空。 

由于对于非回文字符串不可能进行一次操作，因此最小值必须恰好是`2`。 

## Python 解决方案```python
class Solution:
    def removePalindromeSub(self, s: str) -> int:
        left = 0
        right = len(s) - 1

        while left < right:
            if s[left] != s[right]:
                return 2

            left += 1
            right -= 1

        return 1
```该实现使用经典的两指针回文检查。 

这`left`指针从字符串的开头开始，而`right`指针从末尾开始。 

在每次迭代期间，算法都会比较这些位置处的字符。 如果它们不同，则该字符串不是回文，因此答案必须是`2`。 

如果循环完成后没有发现不匹配，则该字符串是回文，所以答案是`1`。 

该解决方案避免了额外的内存分配并以线性时间运行。 

## 解决方案```go
func removePalindromeSub(s string) int {
    left := 0
    right := len(s) - 1

    for left < right {
        if s[left] != s[right] {
            return 2
        }

        left++
        right--
    }

    return 1
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 中的字符串可以直接使用索引`s[i]`，它返回一个字节。 由于输入仅包含 ASCII 字符`'a'`和`'b'`，字节索引是完全安全的。 

不需要额外的切片或内存分配，因此该实现在空间使用方面保持不变。

 ## 边缘情况

 ### 单字符串

 仅包含一个字符的字符串始终是回文，因为它向前和向后读取相同。 

例子包括`"a"`和`"b"`。 

这种情况有时会在两指针实现中导致差一错误，特别是当指针开始相等时。 该实现正确处理了这个问题，因为循环条件是`left < right`。 对于单字符字符串，循环永远不会运行，并且函数正确返回`1`。 

### 具有所有相同字符的字符串

 字符串如`"aaaa"`或者`"bbbbbb"`是回文，因为每个镜像字符对都匹配。 

幼稚的解决方案可能会使问题变得过于复杂，并尝试进行不必要的删除。 回文检查立即识别这些字符串并返回`1`。 

### 非回文字符串

 字符串像`"ab"`或者`"abb"`不是回文。 

重要的观察是它们仍然不需要两次以上的操作。 由于输入仅包含`'a'`和`'b'`，我们总是可以先删除所有出现的一个字符，然后删除所有出现的另一个字符。 

执行正确返回`2`一旦在回文检查期间检测到第一个不匹配。
