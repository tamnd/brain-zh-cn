[LeetCode 1301 题](https://leetcode.com/problems/number-of-paths-with-max-score/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出了一个`n x n`板，其中每个单元格包含四个可能值之一：

 -`'E'`，结束位置位于左上角
 -`'S'`，起始位置位于右下角
 - 一个数字字符`'1'`通过`'9'`, 代表可以收集的点数
 -`'X'`，代表无法跨越的障碍物

 目标是从`'S'`到`'E'`同时最大化沿路径收集的总分。 分数是访问的所有数字单元格的总和。 这`'S'`和`'E'`细胞本身对分数没有贡献。 

移动规则受到限制。 从任何位置，我们只能移动：

 - 向上
 - 左
 - 左上对角线

 因为我们从右下角开始并向左上角移动，所以这些是唯一合法的方向。 

输出需要两个值：

 1. 所有有效路径中可获得的最高分数
 2. 达到最高分数的不同路径的数量

 路径数必须以模数返回：```
10^9 + 7
```如果不存在有效路径`'S'`到`'E'`，答案应该是：```
[0, 0]
```电路板尺寸可以大到`100 x 100`。 这个约束非常重要，因为它告诉我们指数路径探索是不可行的。 强力深度优先搜索可能会探索大量路径。 由于状态空间相对较小并且运动是有方向的，这强烈建议采用动态规划解决方案。 

一些边缘情况很重要：

 - 路径可能被障碍物完全阻挡
 - 多条路径可能获得相同的最高分数
 - 最佳路径可能需要对角线移动
 - 棋盘上可能包含许多断开区域的障碍物
 - 最高分路径不一定是最短路径
 - 细胞`'S'`和`'E'`不应贡献数值

 ## 方法

 ### 蛮力方法

 一个简单的解决方案是递归地探索从`'S'`到`'E'`。 

在每个单元格中，我们尝试三个允许的移动：

 - 向上
 - 左
 - 左上对角线

 对于每条最终到达的有效路径`'E'`，我们计算沿该路径收集的分数。 在探索了所有可能的路径之后，我们确定：

 - 所有路径中的最高分
 - 有多少条路径达到该最大值

 这种方法是正确的，因为它明确枚举了每一条合法路径并对它们进行了评估。 

然而，它太慢了。 即使没有障碍，每个位置也可以分支为多达三个递归调用。 路径数量随着电路板尺寸呈指数增长。 对于一个`100 x 100`板，详尽的探索变得完全不切实际。 

核心的低效率是重复计算。 许多不同的递归路径会重新访问相同的子问题，这意味着我们多次重新计算同一单元的最佳结果。 

### 最优动态规划方法

 关键的见解是，细胞的最佳结果仅取决于能够到达它的细胞的最佳结果。 

由于运动方向是固定的，棋盘形成有向无环图。 这使得动态编程成为一种自然的选择。 

对于每个细胞`(r, c)`，我们想要计算两条信息：

 - 到达该单元格后可获得的最高分数
 - 达到最高分数的方法数量

 我们可以从：

 -`(r + 1, c)`， 以下
-`(r, c + 1)`， 正确的
-`(r + 1, c + 1)`，右下对角线

 这更容易，因为我们从右下角到左上角进行处理。 

对于每个候选前任：

 - 如果它提供了更大的分数，我们将替换当前最好的分数
 - 如果它提供相同的分数，我们添加它的路径计数

 这完全避免了重新计算并处理每个单元一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(3^(n²)) | O(3^(n²)) | O(n²) 递归堆栈 | 探索每一条可能的路径 |
 | 最优动态规划| O(n²) | O(n²) | 每个单元计算一次最佳分数和路径计数 |

 ## 算法演练

 1.创建两个大小的DP表`n x n`。 

第一个表，`max_score`, stores the maximum score obtainable when reaching each cell.

 第二个表，`path_count`，存储有多少条路径达到最高分数。 
2. 将所有单元初始化为不可访问。 

我们可以使用`-1`在`max_score`代表无法到达的状态。 
3. 设置起始位置。 

因为我们开始于`'S'`，位于`(n-1, n-1)`:

 -`max_score[n-1][n-1] = 0`-`path_count[n-1][n-1] = 1`分数从零开始，因为`'S'`不贡献任何积分。 
4. 从右下角到左上角迭代面板。 

这种遍历顺序保证了在处理一个单元格时，所有可以移入该单元格的单元格都已经被计算过。 
5. 跳过无效单元格。 

如果一个单元格包含`'X'`，已被封锁，无法进入。 
6. 对于每个单元格，检查三个可能的前导位置。 

这些是：

 - 向下`(r + 1, c)`- 正确的`(r, c + 1)`- 右下对角线`(r + 1, c + 1)`这些对应于有效的向前移动`'S'`。 
7. 确定最佳前驱分数。 

在所有可到达的前辈中，找到最高分。 
8. 计算最佳路径的数量。 

对于每一位取得最佳成绩的前辈：

 - 将其路径计数添加到当前单元格
 - 应用模数`10^9 + 7`9. 添加当前单元格的数值。 

如果当前单元格包含数字，则将其添加到最佳前任分数中。 

不添加值`'S'`或者`'E'`。 
10. 继续，直到整个板都处理完毕。 
11. 返回左上角单元格的结果。 

如果左上角的单元格无法访问，则返回`[0, 0]`。 

### 为什么它有效

 动态规划不变量是：

 >`max_score[r][c]`达到时始终存储可达到的最高分数`(r, c)`， 和`path_count[r][c]`存储完全达到该分数的路径数。 

到单元格的每条有效路径都必须来自三个允许的前驱单元格之一。 由于我们以逆拓扑顺序处理单元，因此在计算当前单元之前，所有前驱状态都已经确定。 因此，选择最大前驱分数并合并平局计数可以保证正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def pathsWithMaxScore(self, board: List[str]) -> List[int]:
        MOD = 10**9 + 7
        n = len(board)

        max_score = [[-1] * n for _ in range(n)]
        path_count = [[0] * n for _ in range(n)]

        max_score[n - 1][n - 1] = 0
        path_count[n - 1][n - 1] = 1

        for row in range(n - 1, -1, -1):
            for col in range(n - 1, -1, -1):

                if board[row][col] == 'X':
                    continue

                if row == n - 1 and col == n - 1:
                    continue

                best_score = -1
                ways = 0

                directions = [
                    (row + 1, col),
                    (row, col + 1),
                    (row + 1, col + 1)
                ]

                for nr, nc in directions:
                    if nr >= n or nc >= n:
                        continue

                    if max_score[nr][nc] == -1:
                        continue

                    candidate_score = max_score[nr][nc]

                    if candidate_score > best_score:
                        best_score = candidate_score
                        ways = path_count[nr][nc]

                    elif candidate_score == best_score:
                        ways = (ways + path_count[nr][nc]) % MOD

                if best_score == -1:
                    continue

                cell = board[row][col]

                if cell.isdigit():
                    best_score += int(cell)

                max_score[row][col] = best_score
                path_count[row][col] = ways % MOD

        if max_score[0][0] == -1:
            return [0, 0]

        return [max_score[0][0], path_count[0][0]]
```实现首先创建两个动态编程表。`max_score[row][col]`存储到达该单元格后可获得的最佳分数。 值为`-1`表示该单元格不可达。`path_count[row][col]`存储有多少条最佳路径达到最佳分数。 

起始位置`'S'`用分数初始化`0`和路径计数`1`。 

电路板是从右下角到左上角进行处理的。 这种排序至关重要，因为每个单元格仅取决于下方、右侧或右下对角线的状态。 

对于每个单元，算法检查所有有效的前驱状态。 如果前任产生了更大的分数，它就成为新的最佳选择。 如果另一个前任产生相同的分数，则添加其路径计数。 

确定最佳前任分数后，如果适用，将添加当前单元格的数字值。 

最后，检查左上角的单元格。 如果不可达，函数返回`[0, 0]`。 

## 解决方案```go
func pathsWithMaxScore(board []string) []int {
    const MOD int = 1e9 + 7

    n := len(board)

    maxScore := make([][]int, n)
    pathCount := make([][]int, n)

    for i := 0; i < n; i++ {
        maxScore[i] = make([]int, n)
        pathCount[i] = make([]int, n)

        for j := 0; j < n; j++ {
            maxScore[i][j] = -1
        }
    }

    maxScore[n-1][n-1] = 0
    pathCount[n-1][n-1] = 1

    for row := n - 1; row >= 0; row-- {
        for col := n - 1; col >= 0; col-- {

            if board[row][col] == 'X' {
                continue
            }

            if row == n-1 && col == n-1 {
                continue
            }

            bestScore := -1
            ways := 0

            directions := [][]int{
                {row + 1, col},
                {row, col + 1},
                {row + 1, col + 1},
            }

            for _, dir := range directions {
                nr := dir[0]
                nc := dir[1]

                if nr >= n || nc >= n {
                    continue
                }

                if maxScore[nr][nc] == -1 {
                    continue
                }

                candidate := maxScore[nr][nc]

                if candidate > bestScore {
                    bestScore = candidate
                    ways = pathCount[nr][nc]
                } else if candidate == bestScore {
                    ways = (ways + pathCount[nr][nc]) % MOD
                }
            }

            if bestScore == -1 {
                continue
            }

            cell := board[row][col]

            if cell >= '0' && cell <= '9' {
                bestScore += int(cell - '0')
            }

            maxScore[row][col] = bestScore
            pathCount[row][col] = ways % MOD
        }
    }

    if maxScore[0][0] == -1 {
        return []int{0, 0}
    }

    return []int{maxScore[0][0], pathCount[0][0]}
}
```Go 实现密切反映了 Python 逻辑。 由于 Go 不提供默认值非零的自动多维数组初始化，`maxScore`矩阵必须显式初始化为`-1`。 

字符处理也略有不同。 而不是`isdigit()`, Go 检查字节值是否位于`'0'`和`'9'`。 

所有算术都可以安全地适合 Go 的内部`int`因为最大可能得分相对较小，最多`9 * 100 * 100`。

 ## 边缘情况

 当之间不存在有效路径时，就会出现一种重要的边缘情况`'S'`和`'E'`。 幼稚的实现可能会意外地返回一条路径的分数为零，因为目标单元格存在。 然而，必须明确区分不可达状态。 该实现使用`-1`在`max_score`代表无法到达的单元格，确保阻塞的配置正确返回`[0,0]`。 

另一个微妙的边缘情况涉及多个最佳路径。 某些实现仅跟踪最佳分数，并在出现匹配分数时覆盖计数。 这会丢失有关同等最佳路径的信息。 每当两个前任产生相同的最高分数时，该解决方案就会仔细地累积计数。 

对角线运动是错误的另一个常见来源。 由于该问题允许左上对角线移动，因此即使直线方向被阻挡，路径也可能存在。 仅考虑向上和向左移动的实现将无法通过有效的测试用例。 该解决方案显式检查每个单元格的所有三个前驱方向。 

最后的边缘情况涉及处理`'E'`和`'S'`正确。 这些单元格不是数字，不应该对分数产生影响。 意外地将它们转换为整数或将它们视为零值数字单元格可能会创建不正确的总计。 该实现仅在以下情况下添加值：`cell.isdigit()`是真的。
