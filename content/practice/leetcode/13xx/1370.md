[LeetCode 第 1370 题](https://leetcode.com/problems/increasing-decreasing-string/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 该问题需要我们对字符串重新排序`s`通过以特定的递增和递减模式重复选取字符。 换句话说，我们需要模拟一个过程，在每次迭代中，我们首先选择最小的字符，然后继续选择越来越大的字符，直到我们无法再选择为止。 然后，我们改变方向：我们选择最大的字符并继续选择较小的字符，直到我们无法再选择为止。 重复此过程直到消耗完所有字符。 

输入是一个字符串`s`长度在1到500之间，仅由小写英文字母组成。 预期输出是一个字符串，表示`s`根据所描述的算法重新排序。 这些约束保证字符串非空，并且字母表大小限制为 26 个字母，这表明基于计数或频率的方法可能是有效的。 

要考虑的边缘情况包括所有字符都相同的字符串、已按升序或降序排列的字符串以及长度为 1 的非常短的字符串。该问题仅保证小写字母，因此我们不需要处理大写或特殊字符。 

## 方法

 蛮力方法会从字面上模拟该过程。 在每一步中，您都会扫描字符串以查找满足规则的最小或最大字符，将其删除，然后将其附加到结果中。 这是正确的，但效率很低，因为每次扫描字符串都需要 O(n) 时间，并且重复扫描会导致 O(n^2) 时间复杂度，对于 n 高达 500 的情况来说这是可以接受的，但不是最佳的。 

最佳方法利用了只有 26 个可能的字符这一事实。 我们可以维护每个字符的频率计数，并按升序和降序遍历字母表，根据频率计数添加字符。 这减少了对字符串的重复扫描，并在字符集上提供了更加结构化、可预测的迭代。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 重复扫描字符串以查找最小/最大字符 |
 | 最佳 | O(n) | O(1) | O(1) | 使用固定大小的频率数组（26 个字母）来跟踪计数并迭代字符 |

 ## 算法演练

 1.初始化一个大小为26的频率数组，其中每个索引对应一个小写字母。 计算输入字符串中每个字符的出现次数`s`。 
2. 初始化一个空列表或字符串来存储结果。 
3. 当结果的长度小于`s`，执行以下两遍：
 4. 升序遍历：从“a”到“z”迭代频率数组。 对于每个具有非零频率的字符，将其附加到结果中并减少其频率。 
5. 降序遍历：从“z”到“a”迭代频率数组。 对于每个具有非零频率的字符，将其附加到结果中并减少其频率。 
6. 重复步骤 3-5，直到附加所有字符。 
7. 将连接结果作为重新排序的字符串返回。 

工作原理：频率数组可确保字符的附加次数与其出现的次数完全一致。 按升序和降序迭代可保证算法遵循递增-递减模式。 由于频率计数固定为 26 个元素，因此数组上的每次迭代都是有界且可预测的。 

## Python 解决方案```python
class Solution:
    def sortString(self, s: str) -> str:
        freq = [0] * 26  # frequency array for 'a' to 'z'
        for char in s:
            freq[ord(char) - ord('a')] += 1
        
        result = []
        n = len(s)
        
        while len(result) < n:
            # ascending pass
            for i in range(26):
                if freq[i] > 0:
                    result.append(chr(i + ord('a')))
                    freq[i] -= 1
            # descending pass
            for i in range(25, -1, -1):
                if freq[i] > 0:
                    result.append(chr(i + ord('a')))
                    freq[i] -= 1
        
        return ''.join(result)
```该实现首先创建一个频率数组来有效地跟踪字符计数。 这`while`循环确保该过程继续进行，直到添加所有字符。 频率数组上的升序和降序遍历模拟了问题所描述的算法。 这`ord`和`chr`函数处理字符和数组索引之间的映射。 

## 解决方案```go
func sortString(s string) string {
    freq := [26]int{}
    for _, char := range s {
        freq[char - 'a']++
    }

    result := make([]byte, 0, len(s))
    
    for len(result) < len(s) {
        // ascending pass
        for i := 0; i < 26; i++ {
            if freq[i] > 0 {
                result = append(result, byte('a'+i))
                freq[i]--
            }
        }
        // descending pass
        for i := 25; i >= 0; i-- {
            if freq[i] > 0 {
                result = append(result, byte('a'+i))
                freq[i]--
            }
        }
    }
    
    return string(result)
}
```在Go中，我们使用固定大小的数组`[26]int`存储频率和结果的字节切片。 索引和字符之间的转换使用算术`'a'`。 切片附加是高效的，因为我们预先分配了容量。

 ## 边缘情况

 一个重要的边缘情况是包含所有相同字符的字符串，例如`"bbbb"`。 简单的算法可能会尝试选择比最后附加的下一个字符更大的字符，但由于没有，因此它必须正确处理重复相同的字符，直到耗尽为止。 

另一个边缘情况是单字符字符串。 该算法必须返回相同的字符，而不会进入不必要的循环或导致越界错误。 

第三种边缘情况涉及相反顺序的字符串，例如`"zyx"`。 该算法必须在开始时正确处理降序序列，而不是最初假设升序，确保结果仍然按照定义的递增-递减模式排序。
