 ## 解决方案

 ## 问题理解

 该问题要求我们按升序独立对矩阵的每个对角线进行排序。 对角线定义为从第一行或第一列开始的一系列单元格，然后重复向下移动一行和向右移动一列。 

例如，在矩阵中：

 1 2 34 5 67 8 9

 对角线从位置开始`(0, 0)`包含值`[1, 5, 9]`，而对角线起始于`(0, 1)`包含`[2, 6]`。 

输入是一个二维整数矩阵`mat`和`m`行和`n`列。 任务是对每个对角线进行独立排序，同时保留整体矩阵形状。 对对角线排序后，必须将值写回其原始对角线位置。 

约束告诉我们两个维度最多是`100`，这意味着矩阵最多包含`10,000`细胞。 这足够小，独立地对每个对角线进行排序是完全可行的。 由于每个矩阵元素恰好属于一个对角线，因此`O(m * n log(min(m, n)))`样式解决方案足够高效。 

预先识别一些边缘情况很重要。 只有一行或一列的矩阵已经具有长度的对角线`1`，所以排序不会改变任何东西。 另一种边缘情况是当多个对角线具有重复值时，因为实现仍然必须正确保留排序顺序。 矩形矩阵也需要小心处理，因为对角线可以有不同的长度。 

## 方法

 ### 蛮力方法

 强力解决方案将重复扫描矩阵并尝试通过交换操作对对角线重新排序，类似于沿每个对角线重复应用冒泡排序。 

对于每个对角线，我们可以重复比较相邻的对角线元素，如果它们无序，则交换它们。 这种方法是正确的，因为重复的相邻交换最终对对角线进行排序。 

然而，这种方法效率低下，因为每个对角线在排序之前可能需要多次通过。 如果对角线有长度`k`，冒泡排序的成本`O(k^2)`。 由于矩阵可能包含许多对角线，因此总运行时间变得不必要的大。 

### 最佳方法

 关键的观察是每个矩阵单元恰好属于一个对角线，并且对角线彼此完全独立。 这意味着我们可以单独处理每个对角线。 

我们可以：

 1. 提取对角线中的所有值。 
2. 对提取的值进行排序。 
3. 将排序后的值写回到相同的对角位置。 

这种方法非常有效，因为现代排序算法经过了高度优化。 每个矩阵元素仅被访问少量次。 

一个重要的属性有助于清晰地识别对角线。 属于同一左上到右下对角线的任何单元格共享相同的值：

 行-列

 例如：

 (0,0) -> 0(1,1) -> 0(2,2) -> 0

 都属于同一条对角线。 

因此，我们可以使用哈希映射对元素进行分组，其中键是`row - column`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n * 分钟(m, n)^2) | O(1) | O(1) | 沿对角线重复交换 |
 | 最佳 | O(m * n log(min(m, n))) | O(m * n log(min(m, n))) | O(m * n) | 对角线分组，排序一次，重写值 |

 ## 算法演练

 1. 创建一个哈希映射，其中键为`row - column`该值是一个包含该对角线中所有数字的列表。 

这是有效的，因为同一对角线上的每个元素在行索引和列索引之间具有相同的差异。 
2. 遍历一次矩阵。 

对于每个细胞`(row, column)`, 计算`row - column`并将矩阵值附加到相应的对角线列表中。 
3. 对每个对角线列表进行排序。 

现在，每个列表都包含一条对角线的所有值。 对列表进行独立排序可保证对角线值稍后按升序显示。 
4. 反转每个已排序的列表。 

反转可有效去除`pop()`从Python的末尾开始。 自从`pop()`从最后开始是`O(1)`，这避免了昂贵的前部拆除。 
5. 再次遍历矩阵。 

对于每个单元格`(row, column)`，计算相同的对角键`row - column`。 从该对角线列表中删除下一个最小值并将其放回矩阵中。 
6. 返回修改后的矩阵。 

至此，每条对角线都已独立排序。 

### 为什么它有效

 该算法之所以有效，是因为所有元素共享相同的`row - column`值属于同一对角线且不属于其他对角线。 通过收集每个对角线的所有值，对它们进行排序，然后按遍历顺序将它们写回，每个对角线都可以独立排序，同时保留矩阵结构。

分组后，每个对角线列表按降序排序。 这个细节很重要，因为 Python 列表支持高效`pop()`只能从最后开始操作。 通过反转排序顺序，最小的剩余值始终位于列表末尾。

最后，返回修改后的矩阵。

Go 特有的一个细节是切片不提供直接的`pop()`方法。 相反，该实现手动检索最后一个元素并使用切片语法缩小切片。

由于矩阵值很小且约束有限，因此 Go 中不存在整数溢出问题。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n log(min(m, n))) | O(m * n log(min(m, n))) | 每个元素都分组一次，并且每个对角线都排序 |
 | 空间| O(m * n) | 对角线组的额外存储 |

 矩阵元素总数为`m * n`。 Every element is inserted into exactly one diagonal list. 排序在运行时占据主导地位。 最长可能对角线的长度`min(m, n)`，这导致对数排序因子。 

额外的空间来自于在重建矩阵之前将所有对角线值存储在哈希图中。
