 **主题：** 数组、矩阵、前缀和

 ## 解决方案

 ## 问题理解

 该问题需要计算**矩阵块和**。 给定一个矩阵`mat`尺寸的`m x n`和一个整数`k`，任务是产生一个新的矩阵`answer`具有相同的尺寸。 每个元素`answer[i][j]`定义为所有元素的总和`mat[r][c]`位于以`(i, j)`有半径`k`。 该块由条件定义`i - k <= r <= i + k`和`j - k <= c <= j + k`，但该块必须保持在有效的矩阵索引内。 

保证输入矩阵具有维度`1 <= m, n <= 100`和之间的值`1`和`100`。 整数`k`满足`1 <= k <= 100`，这意味着块可能会超出矩阵边界，因此我们必须仔细处理边界条件以避免索引错误。 

关键边缘情况包括位于矩阵角落或边缘的块，其中块的一部分位于矩阵外部。 由于重复求和，对每个矩阵位置的块中的每个元素进行迭代的简单方法对于大型矩阵来说可能会变得低效。 

我们的目标是一个**有效的解决方案**，无需过多的重新计算即可计算这些总和。 

## 方法

 ### 蛮力方法

 蛮力解决方案迭代每个元素`(i, j)`并将其所有元素相加`k`-半径块。 对于每个`answer[i][j]`，我们检查所有有效的`r`和`c`内的索引`i-k`到`i+k`和`j-k`到`j+k`。 虽然这种方法是正确的，但效率很低。 对于大小矩阵`m x n`和一个大小高达`(2k+1)^2`，时间复杂度为`O(m * n * (2k+1)^2)`。 给定`m, n, k <= 100`，这可能需要多达 1 亿次操作，这对于在线编码平台来说速度非常慢。 

### 最佳方法：前缀和

 关键的见解是我们可以使用 **2D 前缀和矩阵** 在常数时间内计算任何子矩阵和。 前缀和矩阵`psum`被定义为`psum[i][j]`表示所有元素的总和`(0,0)`到`(i-1,j-1)`（从 1 开始的偏移量以简化边界）。 有了这个矩阵，任意矩形的和`(r1,c1)`到`(r2,c2)`可以计算为：```
sum = psum[r2+1][c2+1] - psum[r1][c2+1] - psum[r2+1][c1] + psum[r1][c1]
```这种方法允许每个`answer[i][j]`在构建前缀和后在 **O(1)** 时间内计算，将整体时间复杂度降低到`O(m * n)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n * k^2) | O(m * n * k^2) | O(1) | O(1) | 分别对每个块求和 |
 | 最佳| O(m * n) | O(m * n) | 使用 2D 前缀和进行快速矩形和 |

 ## 算法演练

 1. **构建前缀和矩阵**：创建一个矩阵`psum`尺寸的`(m+1) x (n+1)`初始化为零。 对于每个元素`(i,j)`在`mat`, 计算`psum[i+1][j+1] = psum[i][j+1] + psum[i+1][j] - psum[i][j] + mat[i][j]`。 这确保了`psum[i+1][j+1]`包含所有元素的总和`(0,0)`到`(i,j)`。 
2. **计算答案矩阵**：初始化`answer`作为大小的零矩阵`m x n`。 对于每个元素`(i,j)`，定义块的边界：```
r1 = max(0, i-k)
c1 = max(0, j-k)
r2 = min(m-1, i+k)
c2 = min(n-1, j+k)
```使用前缀 sum 来计算该块的和：```
answer[i][j] = psum[r2+1][c2+1] - psum[r1][c2+1] - psum[r2+1][c1] + psum[r1][c1]
```3. **返回答案**：填写完所有元素后，返回`answer`矩阵。 

**为什么有效**：前缀和确保可以使用包含-排除在恒定时间内计算每个矩形块和。 通过钳位索引正确处理边界条件，因此不会发生无效访问。 

## Python 解决方案```python
from typing import List

class Solution:
    def matrixBlockSum(self, mat: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        psum = [[0] * (n + 1) for _ in range(m + 1)]

        # Build prefix sum
        for i in range(m):
            for j in range(n):
                psum[i+1][j+1] = psum[i][j+1] + psum[i+1][j] - psum[i][j] + mat[i][j]

        # Compute answer using prefix sum
        answer = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                r1, c1 = max(0, i - k), max(0, j - k)
                r2, c2 = min(m - 1, i + k), min(n - 1, j + k)
                answer[i][j] = psum[r2+1][c2+1] - psum[r1][c2+1] - psum[r2+1][c1] + psum[r1][c1]

        return answer
```该代码首先构造一个前缀和矩阵，以允许对任何矩形进行 O(1) 求和查询。 然后，对于每个矩阵元素，它计算有效的块边界并应用前缀和公式。 夹紧用`max`和`min`处理边缘和角落。 

## 解决方案```go
func matrixBlockSum(mat [][]int, k int) [][]int {
    m, n := len(mat), len(mat[0])
    psum := make([][]int, m+1)
    for i := range psum {
        psum[i] = make([]int, n+1)
    }

    // Build prefix sum
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            psum[i+1][j+1] = psum[i][j+1] + psum[i+1][j] - psum[i][j] + mat[i][j]
        }
    }

    // Compute answer using prefix sum
    answer := make([][]int, m)
    for i := range answer {
        answer[i] = make([]int, n)
        for j := range answer[i] {
            r1, c1 := max(0, i-k), max(0, j-k)
            r2, c2 := min(m-1, i+k), min(n-1, j+k)
            answer[i][j] = psum[r2+1][c2+1] - psum[r1][c2+1] - psum[r2+1][c1] + psum[r1][c1]
        }
    }

    return answer
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 的实现与 Python 非常相似。 主要区别是显式切片分配、助手的使用`max`和`min`函数和从零开始的索引通过处理`m+1`和`n+1`在前缀和矩阵中。 

## 工作示例

 **示例1：**`mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1`计算前缀和：

 | 0 | 0 | 0 | 0 | 0 |
 | 1 | 0 | 1 | 3 | 6 |

 | 3 | 0 | 12 | 12 27 | 27 45 | 45
