 # LeetCode 1330 - 反转子数组以最大化数组值

 ## 问题理解

 问题给了我们一个整数数组`nums`并将数组的“值”定义为每对相邻元素之间的绝对差之和。 

形式上，该值为：$$\sum_{i=0}^{n-2} |nums[i] - nums[i+1]|$$我们可以精确地反转一个子数组，或者等效地选择任何连续的段并反转其顺序。 我们的目标是在最多执行一次反转后最大化结果数组值。 

重要的观察是，反转子阵列不会影响阵列中的每个相邻对。 反转区域内的大多数内部相邻对在反转之前和之后贡献相同的总差。 唯一的变化发生在反转段的边界处。 

例如，如果我们从索引反转子数组`l`到`r`，那么只有这两条边可能会改变：

 - 之间的边缘`nums[l-1]`和`nums[l]`- 之间的边缘`nums[r]`和`nums[r+1]`所有内部对仅颠倒顺序，但绝对差异保持相同。 

限制条件很大：

 -`nums.length`可以达到`3 * 10^4`- 值可能为负
 - 二次或三次解会太慢

 这些限制强烈表明我们需要一个`O(n)`或者`O(n log n)`解决方案。 

一些边缘情况很重要：

 - 长度数组`2`- 反转不会改变任何内容的数组
 - 包含负值的数组
 - 涉及第一个或最后一个元素的反转
 - 最佳逆转完全是内部的情况
 - 最佳逆转触及终点的情况

 显式反转每个子数组的简单实现会太慢。 

## 方法

 ### 蛮力方法

 暴力解决方案尝试每一个可能的子数组`(l, r)`。 

对于每个候选子数组：

 1. 反转子数组
 2. 重新计算整个数组值
 3. 跟踪最大值

 这种方法是正确的，因为它详尽地检查了每一个合法的逆转。 

然而，有`O(n^2)`可能的子数组，计算数组值需要`O(n)`时间。 因此总复杂度变为`O(n^3)`。 

和`n = 3 * 10^4`，这是完全不可行的。 

### 最优贪婪观察

 关键的见解是反转子数组只会改变边界边缘的贡献。 

假设我们反转索引`[l, r]`。 

在逆转之前，受影响的贡献是：$$|nums[l-1] - nums[l]| + |nums[r] - nums[r+1]|$$逆转后，他们变成：$$|nums[l-1] - nums[r]| + |nums[l] - nums[r+1]|$$其他一切保持不变。 

这意味着我们不需要显式地模拟反转。 相反，我们计算每次逆转可以产生多少改进。 

主要有两大类：

 1. 触及终点的反转
 2. 完全内部逆转

 可以在线性时间内直接检查端点反转。 

对于内部反转，数学简化使我们能够使用区间属性得出最大可能的改进。 

这导致`O(n)`贪婪的解决方案。

 ## 算法演练

 ### 步骤 1：计算原始数组值

 我们首先计算基值：```
base = Σ |nums[i] - nums[i+1]|
```这表示任何反转之前的当前数组值。 

### 步骤 2：考虑触及左端点的反转

 假设我们反转一个子数组`[0, i]`。 

只有一个边界发生变化：

 之前：```
|nums[i] - nums[i+1]|
```后：```
|nums[0] - nums[i+1]|
```所以增益为：```
|nums[0] - nums[i+1]| - |nums[i] - nums[i+1]|
```我们为每个有效的`i`。 

### 步骤 3：考虑触及正确端点的逆转

 同样，反转`[i, n-1]`变化：

 之前：```
|nums[i-1] - nums[i]|
```后：```
|nums[i-1] - nums[n-1]|
```获得：```
|nums[i-1] - nums[n-1]| - |nums[i-1] - nums[i]|
```我们计算出最佳的增益。 

### 步骤 4：处理完全内部逆转

 现在考虑逆转`[l, r]`其中两端都是内部的。 

改进之处在于：```
|a - d| + |b - c| - |a - b| - |c - d|
```在哪里：```
a = nums[l-1]
b = nums[l]
c = nums[r]
d = nums[r+1]
```一个关键的数学观察是最大增益可以从区间重叠行为中得出。 

对于每一个相邻的对`(x, y)`：

- 让`small = min(x, y)`- 让`large = max(x, y)`我们维持：```
max_of_smalls
min_of_larges
```最好的内部改进变成：```
2 * (max_of_smalls - min_of_larges)
```如果是积极的。 

### 第5步：返回最终结果

 答案是：```
base + best_gain
```在哪里`best_gain`是所有反转类型中发现的最大改进。 

### 为什么它有效

 该算法之所以有效，是因为反转子数组仅影响穿过反转边界的边。 内部相邻对在反转后保留其绝对差异。 

因此，最佳解决方案简化为最大化这些边界贡献的变化。 端点反转可以直接评估，而内部反转允许基于区间分离的数学简化。 

由于每个可能的逆转都属于这些类别之一，因此该算法保证了最佳答案。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxValueAfterReverse(self, nums: List[int]) -> int:
        n = len(nums)

        base_value = 0

        for i in range(n - 1):
            base_value += abs(nums[i] - nums[i + 1])

        best_gain = 0

        # Reverse prefix or suffix
        for i in range(n - 1):
            best_gain = max(
                best_gain,
                abs(nums[0] - nums[i + 1]) - abs(nums[i] - nums[i + 1])
            )

            best_gain = max(
                best_gain,
                abs(nums[n - 1] - nums[i]) - abs(nums[i] - nums[i + 1])
            )

        # Internal reversal optimization
        max_of_smalls = float("-inf")
        min_of_larges = float("inf")

        for i in range(n - 1):
            x = nums[i]
            y = nums[i + 1]

            max_of_smalls = max(max_of_smalls, min(x, y))
            min_of_larges = min(min_of_larges, max(x, y))

        best_gain = max(
            best_gain,
            2 * (max_of_smalls - min_of_larges)
        )

        return base_value + best_gain
```实现首先计算原始数组值。 这在任何逆转之前建立了基线分数。 

接下来，代码评估触及左边界或右边界的所有反转。 这些情况比较简单，因为只有一个相邻的边发生变化。 

最后一部分处理完全内部逆转。 该算法不是显式测试所有对，而是跟踪相邻对之间的最大下端点和最小上端点。 这种紧凑的表示体现了可实现的最佳改进。 

最后，算法返回原始值加上最佳增益。 

## 解决方案```go
package main

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}

func maxValueAfterReverse(nums []int) int {
	n := len(nums)

	baseValue := 0

	for i := 0; i < n-1; i++ {
		baseValue += abs(nums[i] - nums[i+1])
	}

	bestGain := 0

	// Reverse prefix or suffix
	for i := 0; i < n-1; i++ {
		bestGain = max(
			bestGain,
			abs(nums[0]-nums[i+1])-abs(nums[i]-nums[i+1]),
		)

		bestGain = max(
			bestGain,
			abs(nums[n-1]-nums[i])-abs(nums[i]-nums[i+1]),
		)
	}

	maxOfSmalls := -1 << 60
	minOfLarges := 1 << 60

	for i := 0; i < n-1; i++ {
		x := nums[i]
		y := nums[i+1]

		maxOfSmalls = max(maxOfSmalls, min(x, y))
		minOfLarges = min(minOfLarges, max(x, y))
	}

	bestGain = max(
		bestGain,
		2*(maxOfSmalls-minOfLarges),
	)

	return baseValue + bestGain
}
```Go 实现密切反映了 Python 逻辑。 由于 Go 没有提供内置的`abs`,`min`， 或者`max`整数函数，辅助函数是手动实现的。 

该算法仅使用整数运算，并且约束保证结果符合 32 位整数。 切片处理很简单，因为 Go 切片已经提供了高效的索引访问。

 ## 边缘情况

 ### 长度为 2 的数组

 当数组仅包含两个元素时，反转唯一可能的子数组不会更改数组值。 如果边界逻辑假设存在其他邻居，这种情况很容易产生索引错误。 该实现自然地处理了这个问题，因为所有循环都安全地迭代`n - 1`相邻对。 

### 元素相等的数组

 如果所有值都相同，则每个相邻差值为零。 任何反转都会使数组保持不变。 由于边界计算有缺陷，一些不正确的解决方案会意外地产生负收益或人为收益。 该实现正确地计算了最佳增益为零。 

### 接触端点的最佳逆转

 有些数组只有通过反转前缀或后缀才能实现最大的改进。 仅考虑内部逆转的解决方案在这些情况下会失败。 该实现显式评估每个前缀和后缀反转候选者以保证正确性。 

### 负数

 绝对差对于负值表现正确，但符号处理错误在贪婪推导中很常见。 由于实现总是使用`abs`，并且比较仅依赖于相对大小，负整数无需特殊处理即可正确处理。 

### 不存在有利的逆转

 有些数组已经是最优的，这意味着每次反转都会减少或保留该值。 算法初始化`best_gain`为零，确保它永远不会应用有害的逆转。
