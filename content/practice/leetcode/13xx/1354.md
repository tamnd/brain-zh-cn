[LeetCode 问题 1354](https://leetcode.com/problems/construct-target-array-with-multiple-sums/)

 **难度：** 🔴难
 **主题：** 数组、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题询问是否可以构造给定的`target`来自初始数组的数组`arr`相同长度，完全由`1`s，重复使用特定的变换。 转换涉及选择任何索引`i`并更换`arr[i]`中所有当前元素的 ** 总和`arr`**。 

换句话说，从`[1, 1, 1, ..., 1]`，在每一步中您都可以选择一个元素并使其等于数组的当前总和。 目标是确定我们是否能够达到`target`使用此操作的数组。 

输入`target`是一个长度数组`n`（最多 50,000 个），每个元素可以大到`10^9`。 输出是一个布尔值：`true`如果可以构建目标数组，`false`否则。 这些限制表明我们需要一个有效的解决方案，因为直接模拟所有可能的操作对于大型数组来说太慢了。 

重要的边缘情况包括`target`已经全为 1 的数组、只有一个元素的数组以及由于某些值小于数组其余部分的总和而无法访问的数组。 

## 方法

 暴力方法会尝试模拟重复选择索引并更新其值直到到达目标数组的过程。 在每一步中，我们都会尝试替换索引的所有可能性。 虽然这种方法原则上是正确的，但它的速度呈指数级缓慢，因为可能的操作数量随着数组长度和元素值而快速增长。 

实现最佳解决方案的关键观察是从目标数组**向后**。 在每个步骤中，必须通过用前一个数组的总和替换某些元素来创建目标数组中的最大元素。 因此，我们可以使用 **最大堆** 来重复将最大元素减少剩余元素的总和，从而有效地反转转换，直到达到全为 1 的数组。 

这种方法之所以有效，是因为在每个步骤中，目标中的最大数字必须来自所有其他数字加上该索引处的先前值的总和。 通过不断减少最大数，我们可以检查是否有可能达到起始数组。

 | ---| ---| ---| ---|
 | 蛮力 | O（？） | O(n) | 模拟每一种可能的替换，以 n 为指数 |
 | 最优（最大堆，反向模拟）| O(n log n) | O(n log n) | O(n) | 使用最大堆总是减少最大元素； 反向模拟|

 ## 算法演练

 1. 将目标数组转换为**最大堆**，存储负值，因为Python的`heapq`默认情况下是最小堆。 
2. 计算数组的**总和**。 
3. 重复以下操作，直到最大元素为 1：

 1. 从堆中取出最大的元素（转回正数）。 
2. 计算其余元素的总和：`rest = total_sum - largest`。 
3.如果`rest`是 1，我们总是可以通过不断地从最大元素中减去 1 来构造数组。 
4. 如果`rest`为零或大于最大元素，返回`False`因为这是不可能的。 
5. 计算最大元素的**前一个值**：`largest % rest`。 
6. 如果之前的值为零或者没有改变最大元素，则返回`False`。 
7. 将之前的值推回到堆中并更新总和。 
4. 如果所有元素最终都减为1，则返回`True`。 

**为什么有效**：通过始终减少最大元素，我们确保每一步都反转用于构造数组的操作。 该算法保持不变式，即总和减去最大元素代表该步骤中所有其他元素的总和。 如果这个不变量被打破，就不可能到达起始数组。 

## Python 解决方案```python
import heapq
from typing import List

class Solution:
    def isPossible(self, target: List[int]) -> bool:
        if len(target) == 1:
            return target[0] == 1
        
        total_sum = sum(target)
        # Python heapq is a min-heap, use negatives for max-heap
        max_heap = [-x for x in target]
        heapq.heapify(max_heap)
        
        while True:
            largest = -heapq.heappop(max_heap)
            rest = total_sum - largest
            if largest == 1 or rest == 1:
                return True
            if rest == 0 or largest <= rest:
                return False
            previous = largest % rest
            if previous == 0:
                return False
            heapq.heappush(max_heap, -previous)
            total_sum = rest + previous
```该实现首先检查单元素数组的边缘情况。 然后它使用负值初始化最大堆。 在循环中，我们反复减少最大值并更新总和。 关键操作包括检查剩余的和是否可以逻辑地产生当前最大元素并相应地更新堆。 

## 解决方案```go
package main

import (
    "container/heap"
)

type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] > h[j] } // max-heap
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *IntHeap) Push(x any) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

func isPossible(target []int) bool {
    if len(target) == 1 {
        return target[0] == 1
    }
    
    totalSum := 0
    h := &IntHeap{}
    for _, x := range target {
        totalSum += x
        *h = append(*h, x)
    }
    heap.Init(h)
    
    for {
        largest := heap.Pop(h).(int)
        rest := totalSum - largest
        if largest == 1 || rest == 1 {
            return true
        }
        if rest == 0 || largest <= rest {
            return false
        }
        previous := largest % rest
        if previous == 0 {
            return false
        }
        heap.Push(h, previous)
        totalSum = rest + previous
    }
}
```Go 解决方案镜像了 Python 版本。 它使用定义最大堆类型`container/heap`，推送所有元素，并在检查可行性的同时反复减小最大值。 主要区别是 Go 需要显式实现堆接口。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log n) | O(n log n) | 每个堆操作都是 log n，我们可以为每个归约步骤执行它。 |
