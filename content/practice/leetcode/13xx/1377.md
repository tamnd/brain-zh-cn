[LeetCode 第 1377 题](https://leetcode.com/problems/frog-position-after-t-seconds/)

 **难度：** 🔴难
 **主题：** 树、深度优先搜索、广度优先搜索、图论

 ## 解决方案

 ## 问题理解

 这个问题描述了一只青蛙穿过一棵无向树。 树是一种没有环的连通图，这意味着任意两个顶点之间只有一条路径。 

青蛙总是从节点开始`1`。 每一秒，青蛙都必须跳到其未访问过的相邻节点之一。 如果有多个有效选择，则以相等的概率选择每一个。 一旦访问了一个节点，青蛙就永远无法返回该节点，因为移动规则只允许跳转到未访问过的顶点。 

如果青蛙到达所有邻居都已被访问过的节点，那么它就会被卡住并永远保留在该节点上。 

输入包括：

 -`n`, 顶点数
 -`edges`，顶点之间的无向连接列表
 -`t`，经过的秒数
 -`target`，我们要计算其概率的节点

 目标是返回准确之后的概率`t`几秒钟，青蛙站在`target`。 

限制相对较小：

 -`n <= 100`-`t <= 50`这些限制告诉我们不需要高级优化。 简单的图遍历（例如 DFS 或 BFS）就足够了。 

一些边缘情况很重要：

 - 目标可能提前达到`t`秒。 
- 到达目标后可能仍有未访问过的邻居。 
- 目标可能是叶节点。 
- 青蛙可能会在时间耗尽之前被卡住。 
- 目标可能永远无法在准确的时间达到`t`。 

错误的一个常见来源是误解青蛙提前到达目标时会发生什么。 如果目标仍有未访问过的邻居，则青蛙必须在稍后的几秒内继续远离它，因此概率变为零，除非`t`与到达时间完全一致。 然而，如果目标是一片叶子，青蛙一旦到达就会永远呆在那里。 

## 方法

 ### 蛮力方法

 暴力解决方案将模拟青蛙可以采取的每条可能的路径。 

从节点开始`1`，每一秒我们都会递归地分支到所有有效的未访问的邻居。 对于每条路径，我们通过乘以计算概率贡献`1 / choices`步步。 恰好之后`t`几秒钟后，我们检查青蛙是否到达目标。 

这种方法是正确的，因为它明确地枚举了每个有效的运动序列并准确地累积了概率。 

然而，这种方法变得低效，因为可能的路径数量随着深度呈指数增长。 尽管限制不是很大，但不必要的重新计算使这种方法不太优雅并且更难以推理。 

### 最佳方法

 关键的观察是该图是一棵树。 

因为一棵树的任意两个节点之间只有一条路径，所以青蛙只能通过一条唯一的路径到达目标。 我们不需要探索任意循环或重新审视状态。 

我们可以在跟踪时执行 DFS 或 BFS 遍历：

 - 当前节点
 - 当前时间
 - 当前概率
 - 父节点，避免重访

 在每个节点：

 - 计算有多少个未访问过的邻居。 
- 将当前概率平均分配给他们。 
- 继续遍历。 

当我们达到目标时，重要的逻辑就会出现：

 - 如果我们准时到达`t`，返回当前概率。 
- 如果我们提前到达`t`目标是一片叶子，青蛙永远呆在那里，所以返回概率。 
- 如果我们提前到达`t`但目标有未访问过的邻居，青蛙必须离开，所以返回`0`。 

由于每条边和节点仅被访问一次，因此该算法是线性的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(分支^t) | O(t) | 探索每一种可能的运动顺序 |
 | 最佳 | O(n) | O(n) | 利用树属性进行DFS/BFS遍历 |

 ## 算法演练

 1. 从边列表构建邻接列表。 

由于图是无向的，所以每条边`[u, v]`必须在两个方向上添加。 邻接列表允许在遍历期间进行有效的邻居查找。 
2. 从节点启动DFS`1`。 

DFS 跟踪：

 - 当前节点
 - 父节点
 - 当前已过去时间
 - 当前概率

 父节点是必要的，因为青蛙无法重新访问已经访问过的节点。 
3. 计算有效的下一步移动次数。 

对于当前节点，有效的移动是除父节点之外的邻居。 这代表所有未访问过的邻居。 
4. 检查当前节点是否为目标节点。 

在两种有效情况下，青蛙可以保持在目标位置：

 - 我们准时到达`t`- 我们到达时间早于`t`，但目标没有未访问过的邻居

 否则，青蛙必须继续离开，因此概率为零。 
5. 在孩子们之间分配概率。 

如果节点有`k`有效的下一步动作，那么每个孩子都会收到：$$\text{next probability} = \frac{\text{current probability}}{k}$$对每个孩子继续递归 DFS。 
6. 返回找到目标后的概率。 

因为图是一棵树，所以只有一条路径可以通向目标。 

### 为什么它有效

 该算法之所以有效，是因为树只包含节点之间的一条简单路径。 青蛙的运动完全由每一步可用的未访问过的邻居决定。 通过在所有有效子代之间递归地平均分配概率，我们精确地模拟了随机过程。 停止条件正确地处理了特殊规则，即一旦不存在未访问的邻居，青蛙就永远保留在节点上。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def frogPosition(
        self,
        n: int,
        edges: List[List[int]],
        t: int,
        target: int
    ) -> float:
        
        graph = defaultdict(list)

        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def dfs(node: int, parent: int, time: int, probability: float) -> float:
            children = 0

            for neighbor in graph[node]:
                if neighbor != parent:
                    children += 1

            # If we reached the target
            if node == target:
                # Valid if:
                # 1. exact time match
                # 2. no further moves available
                if time == t or (children == 0 and time < t):
                    return probability
                return 0.0

            # No more time left
            if time == t:
                return 0.0

            next_probability = probability / children

            for neighbor in graph[node]:
                if neighbor != parent:
                    result = dfs(
                        neighbor,
                        node,
                        time + 1,
                        next_probability
                    )

                    if result > 0:
                        return result

            return 0.0

        return dfs(1, 0, 0, 1.0)
```实现首先构建树的邻接表表示。 由于该图是无向的，因此每条边都在两个方向上插入。 

DFS 函数负责探索树，同时跟踪时间和概率。 这`parent`参数防止重新访问节点，这符合青蛙不能跳到已经访问过的顶点的问题要求。 

对于每个节点，我们计算有效子节点的数量。 该值决定概率如何在可能的移动之间分配。 

当当前节点等于目标节点时，最重要的逻辑发生。 代码仔细检查当前时间是否允许青蛙留在那里。 如果目标仍然有未访问过的邻居并且时间还剩，青蛙必须继续移动，因此概率为零。 

DFS 最终返回通向目标的唯一有效路径的概率。 

## 解决方案```go
package main

func frogPosition(n int, edges [][]int, t int, target int) float64 {
	graph := make([][]int, n+1)

	for _, edge := range edges {
		u := edge[0]
		v := edge[1]

		graph[u] = append(graph[u], v)
		graph[v] = append(graph[v], u)
	}

	var dfs func(node, parent, time int, probability float64) float64

	dfs = func(node, parent, time int, probability float64) float64 {
		children := 0

		for _, neighbor := range graph[node] {
			if neighbor != parent {
				children++
			}
		}

		// Reached target
		if node == target {
			if time == t || (children == 0 && time < t) {
				return probability
			}
			return 0.0
		}

		// No time left
		if time == t {
			return 0.0
		}

		nextProbability := probability / float64(children)

		for _, neighbor := range graph[node] {
			if neighbor != parent {
				result := dfs(
					neighbor,
					node,
					time+1,
					nextProbability,
				)

				if result > 0 {
					return result
				}
			}
		}

		return 0.0
	}

	return dfs(1, 0, 0, 1.0)
}
```Go 的实现与 Python 版本非常相似。 邻接列表是使用整数切片的切片来实现的。 

一个重要的区别是除概率时的显式类型转换。 自从`children`是一个整数，必须转换为`float64`划分之前。 

Go 还要求在定义之前使用变量赋值来声明递归 DFS 函数，以便该函数可以递归地引用自身。

 ## 边缘情况

 当提前达到目标时会出现一种重要的边缘情况`t`，但目标仍有未访问过的邻居。 在这种情况下，青蛙被迫继续远离目标。 有缺陷的实现可能会在达到目标后立即错误地返回概率。 该解决方案通过检查目标节点是否有可用的子节点来避免这种情况。 

当目标是叶节点时，会发生另一个重要情况。 一旦青蛙到达一片叶子，它就会永远留在那里，因为不存在未拜访过的邻居。 该实现通过允许概率保持有效来正确处理这个问题，即使`time < t`。 

第三种边缘情况是当目标是起始节点时`1`。 如果`t > 0`和节点`1`有邻居了，青蛙必须立即离开。 因此，除非该图仅由一个节点组成，否则答案应该为零。 DFS 逻辑自然会处理这个问题，因为根的可用子节点会强制移动远离节点`1`。 

最后一个微妙的情况是线性链树。 在这样的树中，每一步都是确定性的，因为每一步只有一个未访问过的邻居。 概率应该保持不变`1.0`整个遍历过程中。 由于该算法除以可用子代的数量，并且该值始终是`1`，实现正确处理了这个问题。
