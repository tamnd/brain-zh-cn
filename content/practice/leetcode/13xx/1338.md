## 问题理解

 该问题要求我们减少整数数组的大小`arr`通过删除所有出现的选定整数集。 具体来说，我们想要找到这样一个集合的**最小大小**，以便删除集合中的所有数字使原始数组减少**至少一半**。 

例如，如果数组长度为10，我们需要通过选择一些整数来消除，从而删除至少5个元素。 我们选择的整数可以在数组中多次出现，因此删除多次出现的数字对于减小数组大小来说更“有效”。 

输入数组`arr`具有以下属性：它至少有 2 个元素，长度为偶数，值范围为 1 到 105。由于最大数组大小为 10^5，任何时间复杂度低于 O(n log n) 或 O(n) 的解决方案都可能太慢。 

重要的边缘情况包括所有元素都相同的数组、每个元素唯一的数组以及多个数字具有相同频率的数组。 

输出是一个整数，表示删除至少一半数组所需的**不同整数的最小数量**。 

## 方法

 ### 蛮力方法

 暴力方法会尝试数组中所有可能的整数子集，删除所有出现的整数，并检查数组大小是否至少减少一半。 然后，在实现这一目标的所有子集中，我们选择尺寸最小的子集。 

虽然这种方法是正确的，但它**计算上不可行**，因为子集的数量随着不同元素的数量呈指数增长。 对于一个数组`n`不同的整数，这是 O(2^n)，对于`n`最多 10^5。 

### 最佳方法

 关键的见解是关注每个整数的**频率**。 删除最常出现的整数可以更快地缩小数组。 这将问题转化为：

 1. 统计每个整数出现的次数。 
2. 按降序对这些计数进行排序。 
3. 选择最常见的整数，直到删除的元素之和至少为数组大小的一半。 

这种贪婪方法之所以有效，是因为首先选择频率较小的数字不会导致达到数组大小一半所需的更少的数字，从而使其**可证明是最佳的**。

 ## 算法演练

 1. **计数频率：** 创建一个哈希映射，其中键是数组中的整数，值是它们的频率。 这允许快速访问每个整数出现的次数。 
2. **排序频率：** 提取频率计数并按降序排序。 这确保我们可以首先删除最大的组，从而最大限度地减少我们需要选择的整数的数量。 
3. **贪心去除：** 初始化一个变量`removed`跟踪我们删除了多少元素以及`count`跟踪我们选择了多少个整数。 迭代排序后的频率计数，将每个频率添加到`removed`并递增`count`。 停一次`removed`至少达到数组大小的一半。 
4. **返回结果：**`count`此时就是所需的最小整数个数。 

**为什么有效：** 该算法之所以有效，是因为按频率降序删除数字可以保证达到数组大小一半所需的整数最少。 没有其他整数组合可以用更少的选择来删除相同数量的元素。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def minSetSize(self, arr: List[int]) -> int:
        n = len(arr)
        half_size = n // 2
        freq = Counter(arr)
        
        # Sort frequencies in descending order
        freq_counts = sorted(freq.values(), reverse=True)
        
        removed = 0
        count = 0
        
        for f in freq_counts:
            removed += f
            count += 1
            if removed >= half_size:
                return count
        return count
```**说明：**我们使用Python的`Counter`有效地计算出现次数。 按降序对频率进行排序允许首先贪婪地选择最频繁的元素。 循环累积删除的元素，直到达到数组大小的一半，然后返回所选的不同整数的数量。 

## 解决方案```go
import (
    "sort"
)

func minSetSize(arr []int) int {
    freq := make(map[int]int)
    for _, num := range arr {
        freq[num]++
    }
    
    freqCounts := make([]int, 0, len(freq))
    for _, count := range freq {
        freqCounts = append(freqCounts, count)
    }
    
    sort.Sort(sort.Reverse(sort.IntSlice(freqCounts)))
    
    removed := 0
    count := 0
    halfSize := len(arr) / 2
    
    for _, f := range freqCounts {
        removed += f
        count++
        if removed >= halfSize {
            return count
        }
    }
    
    return count
}
```**说明：** Go 缺乏内置计数器，因此我们使用映射来存储频率。 排序需要转换为切片并使用`sort.Reverse`。 否则，逻辑反映了 Python 解决方案。

 ## 边缘情况

 1. **所有相同的元素：** 通过仅选择一个数字可以减少数组。 该实现自然地处理了这个问题，因为`Counter`返回一个等于数组长度的频率。 
2. **所有独特元素：** 每个元素出现一次。 在这种情况下，必须通过选择一半元素来删除一半数组。 频率降序排序仍然有效，因为所有频率均为 1。 
3. **具有相同频率的多个数字：** 频率上的联系不会影响正确性，因为任何具有最高频率的整数选择都是有效的。 该算法始终按照频率降序选择第一个元素，这满足了最小集合要求。 
4. **非常大的数组：** 接近最大大小（10^5）的数组可以得到有效处理，因为我们避免了指数子集枚举并依赖于计数和排序。 
5. **最小偶数数组（长度=2）：** 边缘情况，以确保代码在仅需要删除一个元素时返回 1。
