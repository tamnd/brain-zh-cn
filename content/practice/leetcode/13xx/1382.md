## 问题理解

 该问题要求我们采用可能不平衡的二叉搜索树 (BST)，并生成一个新的平衡的 BST，同时保留原始节点值。 如果对于每个节点，其左子树和右子树的深度最多相差 1，则 BST 是**平衡的**。 

输入是`root`的 BST。 每个节点都有一个整数值，并且 BST 属性成立：左子节点值小于该节点，右子节点值大于该节点。 输出应该是另一个包含相同值但重组为平衡的 BST。 如果多个平衡 BST 是可能的，则任何有效的 BST 都是可接受的。 

约束告诉我们，树最多可以有 10,000 个节点，值的范围可以从 1 到 100,000。 这表明重复平衡子树或执行昂贵的树旋转的简单方法可能太慢。 

重要的边缘情况包括：

 - 已经平衡的树。 
- 高度倾斜的树（如链表）。 
- 具有单个节点的树。 
- 节点具有连续值的树（可以形成长链）。 

这些情况确保我们的算法能够正确处理 BST 的平凡形状和极端形状。 

## 方法

 **暴力：** 暴力方法可能会重复检查子树高度并旋转节点以平衡它们，类似于 AVL 树在插入后重新平衡的方式。 虽然这最终会产生一个平衡的 BST，但每次插入需要 O(n log n) 次旋转，而且不必要地复杂。 给定 10,000 个节点，重复的高度计算可能会降低效率。 

**最佳方法：** 关键的见解是 **BST 的中序遍历会按排序顺序生成节点**。 如果我们可以将节点提取到有序数组中，那么我们可以通过递归地选择中间元素作为根，左子数组作为左子树，右子数组作为右子树，直接构建平衡二叉搜索树。 这保证了树的高度平衡，因为每个子树接收大约一半的节点。

 | 最佳 | O(n) | O(n) | 排序数组的中序遍历+递归树构建 |

 ## 算法演练

 1. **中序遍历：** 中序遍历输入的 BST，并将节点引用存储在列表中。 这会生成所有节点的排序列表，并保留它们的值。 
2. **递归 BST 构造：** 定义一个递归函数，该函数采用列表段的开始和结束索引。 选择中间索引作为根，从左段递归构造左子树，从右段递归构造右子树。 
3. **基本情况：** 如果段为空（开始>结束），则返回`None`。 
4. **返回根：** 递归调用结束后，顶层中间节点成为平衡二叉搜索树的根。 

**为什么有效：** 在每个递归步骤中选择中间元素作为根可确保左子树和右子树具有几乎相等的大小。 这会产生具有最小高度并满足平衡条件的 BST。 中序遍历保证所有节点值都保持 BST 属性。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional, List

class Solution:
    def balanceBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        def inorder(node: Optional[TreeNode], nodes: List[TreeNode]) -> None:
            if not node:
                return
            inorder(node.left, nodes)
            nodes.append(node)
            inorder(node.right, nodes)

        def build_balanced(start: int, end: int) -> Optional[TreeNode]:
            if start > end:
                return None
            mid = (start + end) // 2
            root = nodes[mid]
            root.left = build_balanced(start, mid - 1)
            root.right = build_balanced(mid + 1, end)
            return root

        nodes: List[TreeNode] = []
        inorder(root, nodes)
        return build_balanced(0, len(nodes) - 1)
```**实施演练：**

 我们首先使用排序顺序收集所有节点`inorder`。 然后，`build_balanced`递归地选择每个段的中间节点以保证平衡。 左右子指针就地更新原始节点，以有效地构造新树。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func balanceBST(root *TreeNode) *TreeNode {
    var nodes []*TreeNode

    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil {
            return
        }
        inorder(node.Left)
        nodes = append(nodes, node)
        inorder(node.Right)
    }

    var buildBalanced func(start, end int) *TreeNode
    buildBalanced = func(start, end int) *TreeNode {
        if start > end {
            return nil
        }
        mid := (start + end) / 2
        root := nodes[mid]
        root.Left = buildBalanced(start, mid-1)
        root.Right = buildBalanced(mid+1, end)
        return root
    }

    inorder(root)
    return buildBalanced(0, len(nodes)-1)
}
```**去注意：**

 切片存储类似于 Python 列表的节点引用。 递归函数被定义为局部变量。`nil`用于空子树。 其他方面的逻辑与 Python 解决方案相同。

 ## 边缘情况

 **单节点：** 具有一个节点的树是平凡平衡的。 该算法返回节点本身，递归通过立即返回空段来处理它。 

**高度倾斜的树：**类似于链表的树（所有节点都在右侧或左侧）可能会导致简单的平衡方法失败或堆栈溢出。 中序提取确保我们始终拥有一个排序数组，而递归构造保证了对数深度。 

**重复值：** 虽然 BST 通常具有唯一值，但该算法保留原始节点身份。 即使存在重复项，节点也会被视为对象，而不仅仅是值，因此平衡可以正常工作。 

这种方法稳健、高效，并且直接利用 BST 属性以最小的努力生成平衡树。
