 ## 解决方案

 ## 问题理解

 该问题要求我们构造一个数组，其中包含`n`**唯一整数**，其总和等于`0`。 关键字 **any** 在这里很重要，因为问题不需要特定的排列或字典顺序最小的答案。 只要整数唯一并且它们的总和为零，解就是有效的。 

输入由单个整数组成`n`，它表示结果数组中必须出现多少个数字。 输出应该是一个列表`n`不同的整数。 数组中的每个值都必须不同，如果我们将所有元素加在一起，结果必须完全相同`0`。 

例如，如果`n = 3`，一个有效答案是`[-1, 0, 1]`。 这些值是唯一的并且总和为零。 如果`n = 5`，我们可以返回`[-2, -1, 0, 1, 2]`，但也存在许多其他有效答案。 

约束条件告诉我们`1 <= n <= 1000`。 这是一个相对较小的输入量，意味着效率并不是特别要求。 然而，问题的简单性表明可能存在直接的数学构造，而不是昂贵的搜索过程。 

一个重要的观察是，整数在正负对中自然地相互抵消。 例如，`1 + (-1) = 0`,`2 + (-2) = 0`， 等等。 这立即提出了一个建设性的解决方案。 

有一些重要的边缘情况需要预先考虑。 什么时候`n = 1`，唯一有效的答案是`[0]`，因为我们只需要一个数字，并且它的和必须为零。 什么时候`n`是偶数，我们可以完美地配对数字，例如`[-1, 1, -2, 2]`。 什么时候`n`很奇怪，我们可以使用这些抵消对并包括`0`作为中间元素。 问题保证`n >= 1`，所以我们永远不需要处理无效的输入，例如`0`或负数。 

## 方法

 ### 蛮力方法

 暴力解决方案将尝试生成唯一整数的组合并检查它们的总和是否为零。 例如，我们可能会重复尝试随机不同的数字，计算它们的总和，并验证总数是否为零。 

这种方法在理论上是正确的，因为它会探索可能的有效数组，直到找到满足约束的数组。 然而，它的效率非常低。 可能的组合数量增长得非常快`n`增加，即使对于适中的值，详尽的搜索也不切实际`n`。 

此外，蛮力忽略了问题的数学结构。 由于我们只需要_any_有效数组，因此当存在直接构造时没有理由盲目搜索。 

### 最优方法，数学对构建

 关键的见解是正负对自然抵消。 

对于每个正整数`x`，我们可以将两者都包括在内`x`和`-x`。 他们对总和的贡献为零：$$x + (-x) = 0$$如果`n`是偶数，我们只需生成`n / 2`这样的对。 

如果`n`是奇数，我们生成`(n - 1) / 2`配对并包括`0`。 由于加零不会改变总和，因此总和仍为零。 

这种方法保证了唯一性，因为使用的每个整数都是不同的。 它还通过构造保证总和为零。

 ## 算法演练

 1. 创建一个空结果数组来存储唯一整数。 
2. 迭代从以下位置开始的整数`1`最多`n // 2`。 对于每个数字`i`，将两者相加`i`和`-i`到结果数组。 这确保了每个添加的对贡献的净和为零。 
3. 检查是否`n`很奇怪。 如果是，请附加`0`到结果数组。 这给了我们准确的`n`元素，同时保持总和不变。 
4. 返回完成的结果数组。 

### 为什么它有效

 正确性依赖于每个插入对的不变性`(i, -i)`对总和的贡献为零。 因此，无论我们添加多少对，累积和仍然为零。 如果`n`是奇数，加上`0`保留总和，同时将数组大小增加一。 由于每个整数值仅使用一次，因此保证了唯一性。 因此，该算法总是准确地产生`n`不同的整数之和为零。 

## Python 解决方案```python
from typing import List

class Solution:
    def sumZero(self, n: int) -> List[int]:
        result = []

        for value in range(1, n // 2 + 1):
            result.append(value)
            result.append(-value)

        if n % 2 == 1:
            result.append(0)

        return result
```实现首先创建一个名为的空列表`result`。 该列表将存储总和为零的整数。 

这`for`循环迭代自`1`通过`n // 2`。 对于每个值，算法都会附加该数字的正数和负数版本。 由于每一对都相互抵消，因此运行总和始终保持为零。 

生成所有对后，该实现检查是否`n`是奇怪的使用`n % 2 == 1`。 如果为 true，则附加`0`。 这确保最终列表准确包含`n`元素，同时保留总和要求。 

最后返回完成的列表。 

## 解决方案```go
func sumZero(n int) []int {
	result := make([]int, 0, n)

	for value := 1; value <= n/2; value++ {
		result = append(result, value)
		result = append(result, -value)
	}

	if n%2 == 1 {
		result = append(result, 0)
	}

	return result
}
```Go 的实现与 Python 解决方案非常相似。 一个名为`result`是用能力创造的`n`以避免追加期间不必要的重新分配。 

该循环生成正负对，与 Python 中完全相同。 如果`n`是奇数，`0`附加以完成所需数量的元素。 

与 Python 列表不同，Go 切片受益于使用预分配容量`make([]int, 0, n)`，可以稍微提高效率。 整数溢出在这里不是一个问题，因为`n <= 1000`，并且生成的值仍然非常小。

 ## 边缘情况

 ###`n = 1`这是最小的有效输入，很容易破坏简单的实现。 如果算法仅生成正负对，它将返回一个空数组，因为没有要生成的对。 该实现通过检测奇数来正确处理这个问题`n`并附加`0`， 导致`[0]`。 

＃＃＃ 甚至`n`什么时候`n`为偶数，不应添加额外的元素。 有缺陷的实现可能会意外地包括`0`，产生过多的元素。 当前的解决方案通过仅附加来避免这种情况`0`什么时候`n % 2 == 1`。 

＃＃＃ 奇怪的`n`对于奇数值`n`，仅正负对是不够的，因为它们总是产生偶数个元素。 该实现通过添加正确解决了这个问题`0`，这会将计数加一而不改变总和。 

### 最大约束，`n = 1000`虽然`1000`不是很大，仍然测试算法是否有效扩展。 暴力搜索将变得越来越不切实际，因为`n`成长。 数学结构可以在线性时间内有效地处理这个问题，几乎立即生成答案。
