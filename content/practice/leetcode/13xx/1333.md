[LeetCode 1333 题](https://leetcode.com/problems/filter-restaurants-by-vegan-friend-price-and-distance/)

 **难度：** 🟡 中等
 **主题：** 数组、排序

 ## 解决方案

 ## 问题理解

 问题是要求我们根据多个标准对餐厅列表进行过滤和排序。 每个餐厅都表示为一个数组`[id, rating, veganFriendly, price, distance]`。 我们得到了三个过滤器：`veganFriendly`,`maxPrice`， 和`maxDistance`。 这`veganFriendly`过滤器为 1 或 0，其中 1 表示我们仅包括素食友好的餐厅，0 表示我们忽略此过滤器。 这`maxPrice`和`maxDistance`过滤器定义了餐厅必须考虑的最高价格和距离。 

根据这些条件过滤餐厅后，我们需要返回主要按**评级**从最高到最低排序的餐厅ID列表。 如果两家餐厅的评级相同，我们将按照 **ID** 从最高到最低来打破平局。 

约束条件表明餐厅数量最多可达10^4个，属于中等规模。 每个属性都以 10^5 为界，并且所有餐厅 ID 都是不同的，因此我们不需要处理重复项。 关键的边缘情况包括所有餐厅都被过滤掉、所有餐厅都具有相同的评级或只有一部分餐厅通过素食友好过滤器的情况。 

## 方法

 暴力方法很简单：遍历所有餐馆并检查每个过滤条件。 如果一家餐厅过去了，我们会保留它。 过滤后，我们根据评级和 ID 对餐厅进行排序。 这是可行的，因为餐厅的数量 (10^4) 可以管理排序。 

最佳方法使用相同的想法，但有效地结合了过滤和排序。 由于在 Python 或 Go 中使用自定义键进行排序是高效的（`O(n log n)`），这里没有更快的渐近方法。 关键的见解是使用一个排序键，该排序键自然地按降序实现主要和次要排序标准（评级和 ID）。

 ## 算法演练

 1. 初始化一个空列表，用于存储通过过滤器的餐厅。 
2. 迭代输入数组中的每个餐厅：

 - 如果`veganFriendly`过滤器为 1，跳过其中的任何餐厅`veganFriendly`是 0。 
- 跳过任何一家餐厅`price`超过`maxPrice`。 
- 跳过任何一家餐厅`distance`超过`maxDistance`。 
- 如果餐厅通过了所有筛选，则将其添加到筛选列表中。 
3. 将过滤后的列表按降序排序`rating`。 对于具有相同评级的餐厅，按以下顺序排序`id`按降序排列。 在Python中，这可以使用自定义排序键来实现`(rating, id)`和`reverse=True`。 
4. 提取`id`从排序列表中的每个餐厅中获取并返回 ID 列表。 

**为什么有效**：过滤可确保仅考虑有效的餐厅。 按组合键排序可保证遵守主要和次要排序条件，从而生成指定的正确结果。 

## Python 解决方案```python
from typing import List

class Solution:
    def filterRestaurants(self, restaurants: List[List[int]], veganFriendly: int, maxPrice: int, maxDistance: int) -> List[int]:
        filtered = []
        for r in restaurants:
            id, rating, vegan, price, distance = r
            if veganFriendly and vegan == 0:
                continue
            if price > maxPrice or distance > maxDistance:
                continue
            filtered.append(r)
        
        # Sort by rating descending, then by id descending
        filtered.sort(key=lambda x: (x[1], x[0]), reverse=True)
        
        return [r[0] for r in filtered]
```在此 Python 解决方案中，代码迭代所有餐厅以检查过滤器并构造一个新列表`filtered`唯一有效的餐厅。 这`sort`函数使用 lambda 键首先排序`rating`然后通过`id`，均按降序排列。 最后，列表理解仅提取 ID。 

## 解决方案```go
import "sort"

func filterRestaurants(restaurants [][]int, veganFriendly int, maxPrice int, maxDistance int) []int {
    filtered := [][]int{}
    
    for _, r := range restaurants {
        id, rating, vegan, price, distance := r[0], r[1], r[2], r[3], r[4]
        if veganFriendly == 1 && vegan == 0 {
            continue
        }
        if price > maxPrice || distance > maxDistance {
            continue
        }
        filtered = append(filtered, r)
    }
    
    sort.Slice(filtered, func(i, j int) bool {
        if filtered[i][1] != filtered[j][1] {
            return filtered[i][1] > filtered[j][1]
        }
        return filtered[i][0] > filtered[j][0]
    })
    
    result := make([]int, len(filtered))
    for i, r := range filtered {
        result[i] = r[0]
    }
    
    return result
}
```在围棋中，`sort.Slice`与自定义比较器一起使用来实现评级和 ID 的降序排序。 过滤后的餐厅被附加到切片中，ID 被提取到`result`片。
