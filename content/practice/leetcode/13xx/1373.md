[LeetCode 第 1373 题](https://leetcode.com/problems/maximum-sum-bst-in-binary-tree/)

 **难度：** 🔴难
 **主题：** 动态规划、树、深度优先搜索、二叉搜索树、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们检查二叉树内的每个可能的子树，并确定该子树是否形成有效的二叉搜索树（缩写为 BST）。 在所有有效的 BST 子树中，我们必须返回节点值的最大可能总和。 

子树由一个节点及其所有后代组成。 树中的每个节点都可能是子树的根，因此我们必须评估树的许多重叠区域。 

二叉搜索树遵循三个规则：

 1. 左子树中的每个值必须严格小于当前节点的值。 
2. 右子树中的每个值必须严格大于当前节点的值。 
3. 左子树和右子树本身也必须是 BST。 

输入是二叉树的根节点。 不保证该树总体上是 BST。 树的某些部分可能满足 BST 规则，而其他部分则不满足。 

输出是所有有效 BST 子树中最大的值之和。 如果所有值都是负数，我们可以选择空的 BST，其总和被考虑`0`。 

约束条件很重要：

 - 该树最多可以包含`4 * 10^4`节点。 
- 节点值范围为`-4 * 10^4`到`4 * 10^4`。 

这些限制立即排除了低效的重复遍历。 一个`O(n^2)`对于 40,000 个节点来说，解决方案会太慢。 我们需要一个能够高效处理每个节点的解决方案，最好一次处理。 

一些边缘情况尤其重要：

 - 整棵树可能已经是一个有效的 BST。 
- 大于一个节点的子树不能形成 BST。 
- 所有节点值都可能为负数，要求我们返回`0`。 
- 子树可能会因为深层后代（而不仅仅是直接子代）而失败 BST 规则。 
- 重复值会使 BST 条件无效，因为规则要求严格不等式。 

## 方法

 ### 蛮力方法

 一种简单的方法是独立检查每个子树。 

对于树中的每个节点：

 1. 将该节点视为子树的根。 
2. 检查子树是否是有效的二叉搜索树。 
3. 如果有效，则计算该子树中所有节点的总和。 
4. 跟踪迄今为止看到的最大总和。 

为了正确验证 BST，我们需要确保所有后代都满足有效的下限和上限。 这通常需要完全遍历子树。 

类似地，计算子树和也需要遍历该子树中的所有节点。 

由于有`n`可能的子树根和每次验证可能会花费`O(n)`在最坏的情况下，总复杂度变为`O(n^2)`。 

对于多达 40,000 个节点，这种方法太慢了。 

### 最佳方法

 关键的观察是 BST 验证和子树和计算都可以在单个后序遍历期间执行。 

仅当满足以下条件时，节点才能形成有效的 BST：

 - 它的左子树是 BST。 
- 它的右子树是 BST。 
- 左子树中的最大值小于当前节点值。 
- 右子树中的最小值大于当前节点值。 

这意味着每个节点都依赖于来自其子节点的信息。 

后序遍历是理想的，因为它在父级之前处理子级。 当我们评估一个节点时，我们已经知道它的左子树和右子树的所有信息。 

对于每个子树，我们返回四条信息：

 - 子树是否是有效的 BST。 
- 子树内的最小值。 
- 子树内的最大值。 
- 子树中所有节点的总和。 

使用此信息，父节点可以确定将两个子子树与当前节点组合是否仍然形成有效的 BST。 

每个节点只处理一次，给出`O(n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(h) | 反复验证子树并求和 |
 | 最佳 | O(n) | O(h) | 单后序DFS遍历|

 这里，`h`是树的高度。 

## 算法演练

 1. 执行后序 DFS 遍历。 

我们首先处理左子树，然后处理右子树，最后处理当前节点。 这个顺序确保在评估一个节点时，我们已经知道它的子节点是否形成有效的 BST。 
2.定义DFS返回的信息。 

对于每个子树，返回：

 -`is_bst`，子树是否是有效的 BST
 -`min_value`, 子树中的最小值
 -`max_value`, 子树中的最大值
 -`subtree_sum`,子树的总和
 3. 处理基本情况。 

空子树被视为有效的 BST。 

对于空节点：

 -`is_bst = True`-`min_value = +infinity`-`max_value = -infinity`-`subtree_sum = 0`在评估父节点时，使用无穷大可以使比较变得容易。 
4. 递归处理左右孩子。 

DFS 调用返回两个子子树的四个值。 
5. 判断当前子树是否是BST。 

以当前节点为根的子树仅在以下情况下有效：

 - 左子树是 BST
 - 右子树是 BST
 -`left_max < node.val < right_min`6. 计算子树和（如果有效）。 

如果子树形成 BST：```
total_sum = left_sum + right_sum + node.val
```用这个总和更新全局最大答案。 
7. 计算子树边界。 

最小值变为：```
min(left_min, node.val)
```最大值变为：```
max(right_max, node.val)
```8. 处理无效的BST。 

如果子树无效，则返回`False`为了`is_bst`。 

剩余的值并不重要，因为无效的 BST 无法生成更大的有效 BST。 
9. 继续直到遍历完成。 

全局最大值存储在树中任何位置找到的最大 BST 子树和。 

### 为什么它有效

 该算法之所以有效，是因为父树的每个 BST 条件完全取决于其左子树和右子树的属性。 通过在父节点之前处理子节点，我们在评估节点时始终可以获得完整的信息。 

返回的`(is_bst, min_value, max_value, subtree_sum)`元组充当每个子树的紧凑摘要。 此摘要准确包含父级验证 BST 有效性和正确计算总和所需的信息。 

由于每个节点都被处理一次并且每个子树都被精确评估一次，因此该算法既正确又高效。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional
import math

class Solution:
    def maxSumBST(self, root: Optional[TreeNode]) -> int:
        self.best_sum = 0

        def dfs(node: Optional[TreeNode]):
            if not node:
                return True, math.inf, -math.inf, 0

            left_is_bst, left_min, left_max, left_sum = dfs(node.left)
            right_is_bst, right_min, right_max, right_sum = dfs(node.right)

            if (
                left_is_bst
                and right_is_bst
                and left_max < node.val < right_min
            ):
                current_sum = left_sum + right_sum + node.val

                self.best_sum = max(self.best_sum, current_sum)

                current_min = min(left_min, node.val)
                current_max = max(right_max, node.val)

                return True, current_min, current_max, current_sum

            return False, 0, 0, 0

        dfs(root)

        return self.best_sum
```实现直接遵循后序遍历策略。 

这`dfs()`函数返回四个值，描述以当前节点为根的子树。 递归调用首先从左子节点和右子节点收集信息。 

使用以下方法检查 BST 条件：```python
left_max < node.val < right_min
```这保证了左子树中的所有值都较小，而右子树中的所有值都较大。 

如果子树有效，则代码计算子树总和并更新全局最大值。 

使用`math.inf`和`-math.inf`简化了空子树的比较。 例如，叶子节点自动满足 BST 条件，因为：```python
-inf < node.val < inf
```返回无效的子树`False`，防止它们被错误地组合成更大的 BST。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

import "math"

type Result struct {
	isBST bool
	minVal int
	maxVal int
	sum int
}

func maxSumBST(root *TreeNode) int {
	bestSum := 0

	var dfs func(node *TreeNode) Result

	dfs = func(node *TreeNode) Result {
		if node == nil {
			return Result{
				isBST: true,
				minVal: math.MaxInt32,
				maxVal: math.MinInt32,
				sum: 0,
			}
		}

		left := dfs(node.Left)
		right := dfs(node.Right)

		if left.isBST &&
			right.isBST &&
			left.maxVal < node.Val &&
			node.Val < right.minVal {

			currentSum := left.sum + right.sum + node.Val

			if currentSum > bestSum {
				bestSum = currentSum
			}

			minValue := min(left.minVal, node.Val)
			maxValue := max(right.maxVal, node.Val)

			return Result{
				isBST: true,
				minVal: minValue,
				maxVal: maxValue,
				sum: currentSum,
			}
		}

		return Result{
			isBST: false,
		}
	}

	dfs(root)

	return bestSum
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}
```Go 的实现与 Python 方法非常相似。 

由于 Go 不像 Python 那样方便地支持元组返回，因此`Result`struct用于封装子树信息。 

而不是`math.inf`，实现使用：

 -`math.MaxInt32`-`math.MinInt32`这些用作空子树的哨兵边界值。 

Go 还需要显式的辅助函数`min()`和`max()`运营。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点只被处理一次 |
 | 空间| O(h) | 递归调用堆栈深度等于树高 |

 DFS 遍历访问每个节点一次，并对每个节点执行持续的工作。 因此，总时间复杂度是线性的。 

空间复杂度来自递归深度。 在完全倾斜的树的最坏情况下，高度变为`n`，导致`O(n)`堆栈使用。 在平衡树中，递归深度为`O(log n)`。

 ## 边缘情况

 ### 所有值都是负数

 一个常见的错误是强制算法返回最大的负 BST 和。 然而，该问题明确允许选择具有 sum 的空 BST`0`。 

例如：```
[-4, -2, -5]
```每个子树都有负和，所以正确答案是`0`。 

The implementation handles this naturally because the global answer starts at`0`并且仅当发现更大的总和时才更新。 

### 重复值

 BST 规则要求严格的不平等。 

这意味着：```
left_max < node.val < right_min
```使用`<=`或者`>=`会错误地接受重复值。 

例如：```
    2
   /
  2
```这不是有效的 BST。 

该实现显式使用严格的比较运算符，确保重复项使子树无效。 

### 无效的深层后代

 当仅检查直接子节点时，子树可能会显示为有效，但由于更深的后代而失败。 

例子：```
      10
     /  \
    5   15
       /
      6
```虽然`6 < 15`，整个右子树违反了 BST 规则，因为右子树中的所有节点都必须大于`10`。 

该算法通过在 DFS 期间向上传播子树最小值和最大值来正确检测到这一点。 

### 高度倾斜的树

 一棵树可能会退化为链表形状：```
1
 \
  2
   \
    3
```这会创建与节点数量成正比的递归深度。 

该算法仍然可以正常工作，因为每个节点都被处理一次，尽管递归深度变为`O(n)`在最坏的情况下。
