[LeetCode 问题 1460](https://leetcode.com/problems/make-two-arrays-equal-by-reversing-subarrays/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序

 ## 解决方案

 ## 问题理解

 此问题询问是否有一个整数数组，`arr`，可以转化为另一个数组，`target`，通过重复反转任何非空连续子数组。 

子数组反转意味着选择数组的连续段并反转其元素的顺序。 例如，反转`[2,4,1]`将其更改为`[1,4,2]`。 

关键细节是您可以执行**任意数量的反转**，并且所选子数组可以是**任何非零长度**。 因为对可以执行的操作数量没有限制，所以问题不在于找到操作的顺序。 相反，它是在问这样的转变在理论上是否可能。 

输入由两个数组组成：

 -`target`, 期望的最终排列
 -`arr`, 起始安排

 两个数组的长度相同。 

输出是一个布尔值：

 - 返回`true`如果`arr`可以重新排列成`target`- 返回`false`否则

 这些约束告诉我们一些重要的事情：

 - 数组长度最多为`1000`，相对较小
 - 元素值范围为`1`到`1000`- 两个数组的长度始终相等

 由于值可能会重复，因此我们必须考虑**频率**，而不仅仅是存在。 例如，`[1,2,2]`和`[1,1,2]`包含相似的值，但由于计数不同，因此不能相互转换。 

最重要的观察是理解重复的子数组反转允许我们做什么。 由于反转了长度的子数组`2`有效地交换相邻元素，并且相邻交换可以生成数组的任何排列，元素的确切顺序并不重要。 重要的是两个数组是否包含**相同的元素多重集**，即具有相同频率的相同数字。 

一些可能会导致幼稚实现失败的边缘情况包括长度数组`1`、重复值或包含相同数字但顺序截然不同的数组。 幸运的是，该问题保证了相等的长度，因此我们永远不需要处理不匹配的大小。 

## 方法

 ### 蛮力方法

 强力解决方案将尝试模拟所有可能的子数组反转序列，以查看是否`arr`最终可以成为`target`。 

在每一步中，我们都可以生成每个可能的子数组反转，并递归或迭代地探索所有结果状态。 由于有`O(n²)`每个操作都有可能的子数组，并且转换可以无限期地继续，可达状态的数量呈爆炸性增长。 

这种方法在理论上是正确的，因为它最终探索了通过反转所能达到的每一种可能的排列。 如果`target`是可达的，蛮力最终会找到它。 

然而，这种方法太慢了。 数组的排列数为`n!`，并且即使对于中等输入大小，探索它们之间的转换在计算上也是不可行的。 和`n = 1000`，这样的做法是完全不切实际的。 

### 最佳方法，比较元素频率

 关键的见解是认识到重复的子数组反转允许什么。 

反转长度的子数组`2`交换相邻元素。 由于任何排列都可以通过一系列相邻交换来实现，因此我们可以重新排列`arr`进入其元素的**任何顺序**。 

这意味着唯一重要的是两个数组是否包含具有相同计数的完全相同的元素。 

有两种常见的方法可以验证这一点：

 1. 对两个数组进行排序并比较它们。 
2. 使用哈希图计算频率。 

频率图更直接并且避免排序。 我们计算每个值出现的次数`target`，然后在遍历时减去计数`arr`。 如果一切都完美平衡，转型是可能的。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n!) | 探索可能的逆转序列，但计算上不可行 |
 | 最佳 | O(n) | O(n) | 使用哈希图来比较元素频率 |

 ## 算法演练

 我们将使用哈希图来计算元素频率。 

1. 创建频率图`target`。 

我们首先统计每个数字出现的次数`target`。 键是数字，值是其频率。 

例如：```
target = [1,2,3,4]
```生产：```
{
    1: 1,
    2: 1,
    3: 1,
    4: 1
}
```该地图代表了构建所需的确切元素`target`。 
2. 遍历`arr`并减少计数。 

对于每一个数字`arr`，减少其在地图中的数量。 

如果某个数字在地图中不存在或者其计数变为负数，则`arr`包含太多该值，这意味着转换是不可能的。 
3. 验证所有计数均为零。 

处理完中的每个元素后`arr`，每个所需的计数都应该恰好为零。 

如果任何值仍然具有非零计数，则`arr`缺少一些必需的元素。 
4. 返回结果。 

如果所有频率完美匹配，则返回`True`。 否则，返回`False`。 

### 为什么它有效

 正确性依赖于一个重要的属性：数组的任何排列都可以使用相邻交换生成，并且相邻交换只是长度子数组的反转`2`。 

由于任意重新排序是可能的，因此在反转期间保持不变的唯一不变量是**元素的多重集**。 逆转永远不会创造或破坏价值，它们只会重新排列价值。 所以，`arr`可以成为`target`当且仅当两个数组包含具有相同频率的完全相同的值时。 

## Python 解决方案```python
from collections import defaultdict
from typing import List

class Solution:
    def canBeEqual(self, target: List[int], arr: List[int]) -> bool:
        frequency = defaultdict(int)

        # Count elements in target
        for num in target:
            frequency[num] += 1

        # Remove counts using arr
        for num in arr:
            if frequency[num] == 0:
                return False
            frequency[num] -= 1

        return True
```实现直接遵循算法。 

我们首先创建一个名为的哈希图`frequency`使用`defaultdict(int)`，它会自动将缺失的键初始化为`0`。 这简化了频率跟踪，因为我们不需要手动检查密钥是否存在。 

接下来，我们迭代`target`并计算每个数字出现的次数。 这建立了预期的元素分布。 

然后我们处理`arr`。 对于每个数字，我们检查该值在频率图中是否仍然可用。 如果它的计数已经是`0`，这意味着`arr`包含该数字的额外出现或无效值，因此我们立即返回`False`。 

否则，我们会递减计数以指示已匹配一个所需的出现。 

如果我们完成处理而没有任何不匹配，则数组包含相同的元素多重集，因此转换始终是可能的，并且我们返回`True`。 

## 解决方案```go
func canBeEqual(target []int, arr []int) bool {
	frequency := make(map[int]int)

	// Count elements in target
	for _, num := range target {
		frequency[num]++
	}

	// Remove counts using arr
	for _, num := range arr {
		if frequency[num] == 0 {
			return false
		}
		frequency[num]--
	}

	return true
}
```Go 实现密切反映了 Python 逻辑。 

一个`map[int]int`用于存储频率。 丢失钥匙自动返回`0`，这简化了存在性检查。 

穿越时`arr`，我们立即返回`false`如果某个值没有可用的剩余计数。 否则，我们减少频率。 

不用担心整数溢出，因为值和计数都很小。 由于 Go 中的切片是动态大小的引用，因此我们可以直接处理它们，而不需要显式的数组处理。 空对`nil`切片在这里无关紧要，因为问题保证了长度相等的有效输入数组。

 ## 边缘情况

 ### 长度为 1 的数组

 最小可能的输入大小是`1`。 在这种情况下，不可能进行有意义的重新排列，因为只有一个元素。 结果完全取决于值是否匹配。 

有缺陷的实现可能会使这种情况变得过于复杂或尝试无效的操作。 我们基于频率的解决方案可以自然地处理它，因为匹配计数会立即成功或失败。 

### 重复值

 重复的元素是错误的常见来源。 例如：```
target = [1,2,2]
arr = [1,1,2]
```仅检查元素是否存在的简单解决方案将错误地返回`True`。 问题需要匹配**频率**，而不仅仅是存在。 

我们的哈希图跟踪精确的计数，确保正确处理重复项。 

### 不同顺序的相同元素

 数组可能包含相同的值，但看起来完全打乱：```
target = [1,2,3,4]
arr = [4,1,3,2]
```使用直接相等的简单比较会失败，因为顺序不同。 

我们的实现正确地认识到无限的子数组反转允许任意重新排序，因此只有值的多重集才重要。 

### 缺少或多余的元素

 如果`arr`包含一个不存在于中的数字`target`，转型是不可能的。 

例如：```
target = [1,2,3]
arr = [1,2,99]
```加工时`99`，频率计数已经`0`，立即引起`False`返回。 这种提前退出避免了不必要的计算并保证了正确性。
