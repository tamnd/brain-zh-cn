[LeetCode 第 1494 题](https://leetcode.com/problems/parallel-courses-ii/)

 **难度：** 🔴难
 **主题：** 动态规划、位操作、图论、位掩码

 ## 解决方案

 ## 问题理解

 该问题要求我们确定完成所需的**最小学期数**`n`当某些课程之间存在先决条件限制和限制时的课程`k`一个学期可以修读的课程数量。 输入由一个整数组成`n`，先决关系列表`relations`，和整数`k`。 各关系`[a, b]`表示该课程`a`必须在课程之前完成`b`。 

目标是跨学期安排课程，以满足所有先决条件，并且每个学期的课程数量都不会超过`k`课程，返回**所需的最低学期数**。 

约束条件告诉我们`n`很小（`<= 15`），这暗示可以使用位操作和子集上的 DP。 这些关系形成**有向无环图**（DAG），因此不存在循环并且存在有效的过程顺序。 重要的边缘情况包括`k`等于`n`（如果先决条件允许，所有课程都可以在一学期内完成），当`relations`为空（所有课程都是独立的），或者当某些课程有很多先决条件时。 

## 方法

 ### 蛮力方法

 一种简单的方法是生成课程的所有排列并检查哪些排列满足先决条件，然后将有效的排列分成尊重以下条件的学期：`k`限制。 这保证了正确性，因为它探索了所有可能的订单。 然而，这是 **指数级缓慢**：有`n!`排列和`n`可以是15，所以在计算上是不可行的。 由于组合爆炸，即使基于先决条件的修剪也是不够的。 

### 最佳方法

 最佳方法使用**位掩码动态编程**。 每个状态都由一个位掩码表示`mask`哪里的`i-th`如果当然位为 1`i+1`已完成。 我们还存储达到该状态的**最小学期数**。 在每一步中，我们都可以考虑哪些课程是**可用的**（已完成所有先决条件），并选择这些课程的子集，规模可达`k`在当前学期参加。 我们用新的位掩码状态更新 DP 表并增加学期数。 

主要观察结果：

 1. 使用位掩码 DP 是可行的，因为`n <= 15`，所以有`2^15 = 32768`可能的状态。 
2. 先决条件可以被编码为位掩码以进行快速检查：如果与先决条件相对应的所有位都设置为当前状态，则课程可用。 
3. 枚举大小可达的子集`k`可以使用标准位操作技术有效地完成。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 生成课程的所有排列，检查先决条件，对于 n=15 不可行 |
 | 位掩码 DP | O(3^n) | O(3^n) | O(2^n) | O(2^n) | 使用状态位掩码，有效枚举每学期可用的课程 |

 ## 算法演练

 1. **编码前提条件：** 构建数组`pre`长度`n`在哪里`pre[i]`是课程之前必须完成的课程位掩码`i`。 
2. **初始化DP表：** 创建数组`dp`尺寸的`2^n`， 在哪里`dp[mask]`是要达到的最短学期`mask`。 放`dp[0] = 0`作为基本案例（未修读任何课程）。 
3. **迭代状态：** 对于每个`mask`从`0`到`2^n - 1`，通过检查是否满足所有先决条件来确定**可以**学习哪些课程。 可用课程形成位掩码`avail`。 
4. **枚举可用课程的子集：** 生成以下课程的所有子集`avail`最多的大小`k`。 对于每个子集，将新掩码计算为`next_mask = mask | subset`并更新`dp[next_mask] = min(dp[next_mask], dp[mask] + 1)`。 
5. **返回结果：** 答案是`dp[(1 << n) - 1]`，完成所有课程所需的最短学期。 

**为什么有效：** 每个 DP 状态都会准确编码已完成的课程，并且转换会考虑所有有效的课程组合，直至`k`课程。 通过迭代所有州和子集，该算法保证考虑每个有效的时间表，并找到最小学期数。 

## Python 解决方案```python
from typing import List
from itertools import combinations

class Solution:
    def minNumberOfSemesters(self, n: int, relations: List[List[int]], k: int) -> int:
        pre = [0] * n
        for u, v in relations:
            pre[v - 1] |= 1 << (u - 1)
        
        size = 1 << n
        dp = [float('inf')] * size
        dp[0] = 0
        
        for mask in range(size):
            avail = 0
            for i in range(n):
                if not (mask & (1 << i)) and (mask & pre[i]) == pre[i]:
                    avail |= 1 << i
            
            subset = avail
            sub = subset
            while sub:
                if bin(sub).count('1') <= k:
                    dp[mask | sub] = min(dp[mask | sub], dp[mask] + 1)
                sub = (sub - 1) & avail
        
        return dp[size - 1]
```**说明：** 我们首先将先决条件编码在位掩码数组中。 DP 数组存储每个已完成课程状态的最短学期。 对于每个州，我们计算可用课程，枚举大小 ≤ 的所有有效子集`k`，并更新DP数组中的下一个状态。 最后，`dp[(1 << n) - 1]`给出完成所有课程的最短学期。 

## 解决方案```go
func minNumberOfSemesters(n int, relations [][]int, k int) int {
	pre := make([]int, n)
	for _, r := range relations {
		u, v := r[0]-1, r[1]-1
		pre[v] |= 1 << u
	}
	size := 1 << n
	dp := make([]int, size)
	for i := range dp {
		dp[i] = 1 << 30
	}
	dp[0] = 0

	for mask := 0; mask < size; mask++ {
		avail := 0
		for i := 0; i < n; i++ {
			if mask&(1<<i) == 0 && mask&pre[i] == pre[i] {
				avail |= 1 << i
			}
		}
		sub := avail
		for sub > 0 {
			if bits.OnesCount(uint(sub)) <= k {
				next := mask | sub
				if dp[mask]+1 < dp[next] {
					dp[next] = dp[mask] + 1
				}
			}
			sub = (sub - 1) & avail
		}
	}

	return dp[size-1]
}
```**Go 特定注释：** 我们使用`bits.OnesCount`计算子集中的设置位，并初始化`dp`用大量而不是`inf`。 子集的枚举方式与 Python 相同，使用`(sub - 1) & avail`。 

## 工作示例

 **示例 1：n=4，关系=[[2,1],[3,1],[1,4]]，k=2**

 | 掩码（二进制）| 课程已完成 | 可用课程 | 行动|
 | ---| ---| ---| ---|
 | 0000 | 0000 {} | 0100 (2), 0010 (3) | 取 2 和 3 → mask=0110 |
 | 0110| {2,3} | 0001 (1) | 取1 → 掩码=0111 |
 | 0111| {1,2,3} | 1000 (4) | 1000 (4) 取4→掩码=1111|

 答：3个学期。 

**示例 2：n=5，关系=[[2,1],[3,1],[4,1],[1,5]], k=2**

 我们迭代地获取尊重先决条件和 k=2 的子集。 在评估所有状态后，`dp[11111] = 4`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(3^n) | O(3^n) | 每个州都列举了可用课程的子集； 有 2^n 个状态，每个状态最多有 2^n 个子集，但是大小 ≤ k 的剪枝将其减少到大约 3^n |
 | 空间| O(2^n) | O(2^n) | DP 数组存储已完成课程的每个位掩码的最少学期 |

 位掩码 DP 对于 n ≤ 15 是有效的。通过仅考虑可用课程的子集来优化子集枚举。
