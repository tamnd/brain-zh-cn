[LeetCode 问题 1493](https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、滑动窗口

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到最长的连续子数组`1`二进制数组中的 s`nums`**恰好删除一个元素之后**。 换句话说，我们可以删除单个元素（可以是`0`或者`1`）然后考虑最长的连续块`1`剩下的就是。 该数组是二进制的，因此元素可以是`0`或者`1`。 该函数必须返回该最长子数组的长度。 

这些约束表明数组可能很大，最多有 100,000 个元素，因此任何简单地检查每个可能的子数组的解决方案都会太慢。 该数组保证至少有一个元素，但它可能完全由以下组成`1`或全部`0`s。 由于我们必须删除一个元素，即使数组已全部`1`是，最大子数组长度是`len(nums) - 1`。 类似地，如果数组全部是`0`是，输出必须是`0`。 

重要的边缘情况包括所有的数组`1`s，全部为数组`0`s 和数组，其中`0`s 位于开头或结尾，这可能会影响“删除一个元素”操作对最长序列的影响`1`s。 

## 方法

 暴力方法会考虑删除数组中的每个元素并计算最长连续元素的长度`1`s 表示结果数组。 这涉及到遍历数组以查找每个删除，然后扫描连续的`1`s，导致时间复杂度为二次方。 这是正确的，但对于长度高达 100,000 的数组来说效率较低。 

实现更有效解决方案的关键观察是我们只需要跟踪`1`s 最多相隔 1`0`。 通过考虑一个滑动窗口，我们最多允许一个`0`被跳过**（就像被删除一样），我们可以找到连续两个的最大组合长度`1`由单个分隔的段`0`。 这将问题变成了**滑动窗口问题**，其中窗口最多可以包含一个`0`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 删除每个元素并计算1s的最长子数组 |
 | 最佳 | O(n) | O(1) | O(1) | 滑动窗口方法最多跟踪一个零 |

 ## 算法演练

 1.初始化两个指针`left`和`right`在数组的开头。 这些将定义正在考虑的元素的滑动窗口。 
2. 初始化变量`zero_count`跟踪当前窗口中零的数量。 
3. 初始化变量`max_len`存储迄今为止找到的有效窗口的最大长度。 
4. 展开`right`指针通过数组。 每次遇到零时，递增`zero_count`。 
5.如果`zero_count`超过`1`，从左侧缩小窗口，直到窗口中最多有一个零，递减`zero_count`每当零离开窗口时。 
6. 更新`max_len`当前窗口的大小减一，因为我们必须恰好删除一个元素。 
7. 继续直到`right`到达数组末尾。 返回`max_len`。 

**为什么有效**：通过保持滑动窗口最多有一个零，我们有效地考虑删除该零以最大化连续的`1`s。 不变的是`zero_count <= 1`确保我们总是可以删除一个零来形成有效的子数组。 

## Python 解决方案```python
from typing import List

class Solution:
    def longestSubarray(self, nums: List[int]) -> int:
        left = 0
        zero_count = 0
        max_len = 0
        
        for right in range(len(nums)):
            if nums[right] == 0:
                zero_count += 1
            
            while zero_count > 1:
                if nums[left] == 0:
                    zero_count -= 1
                left += 1
            
            max_len = max(max_len, right - left)
        
        return max_len
```Python 代码使用右指针迭代数组，同时维护零计数。 如果窗口中存在多个零，它将向前移动左指针以将零计数减少到最多 1。 当前有效窗口的长度减一用于更新最大长度。 

## 解决方案```go
func longestSubarray(nums []int) int {
    left, zeroCount, maxLen := 0, 0, 0
    
    for right := 0; right < len(nums); right++ {
        if nums[right] == 0 {
            zeroCount++
        }
        
        for zeroCount > 1 {
            if nums[left] == 0 {
                zeroCount--
            }
            left++
        }
        
        if right - left > maxLen {
            maxLen = right - left
        }
    }
    
    return maxLen
}
```在 Go 中，逻辑反映了 Python。 这`for`循环使用整数索引，变量使用以下方式初始化`:=`。 切片`nums`直接使用，并且窗口长度计算为`right - left`。

 ## 边缘情况

 一个重要的边缘情况是包含所有内容的数组`1`s。 由于我们必须删除一个元素，所以最长的子数组是`len(nums) - 1`。 另一个边缘情况是所有的数组`0`s，应该返回`0`因为去掉一个`0`仍然没有留下`1`s。 第三种边缘情况是单元素数组，删除后变为空，因此函数应该返回`0`。 滑动窗口实现可以正确处理这些情况，因为它跟踪零并确保最大长度正好删除一个元素。
