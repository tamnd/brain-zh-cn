 **难度：** 🔴难
 **主题：** 数组、数学、几何

 ## 解决方案

 ## 问题理解

 在这个问题中，我们得到了扔到 2D 平面上的几个飞镖的坐标。 每个飞镖都表示为一个点`(x, y)`。 我们还给出了一个半径`r`，表示圆形飞镖靶的半径。 

任务是放置一个半径为`r`位于平面上的某处，使得位于圆内部或恰好位于圆边界上的飞镖数量最大化。 我们必须返回该最大数量。 

重要的细节是圆心不固定。 我们可以将其放置在平面上的任何位置，包括非整数坐标。 因此，挑战不仅仅是检查现有点，而是确定哪些圆圈放置是最佳的。 

输入约束相对较小：

 - 至多`100`点
 - 坐标可以很大，最多`10^4`- 半径可以大到`5000`由于只有`100`点、算法围绕`O(n^3)`是可以接受的，同时`O(n^4)`方法可能会变得太慢。 

一个重要的几何观察是，如果一个圆包含最佳的点集，那么我们通常可以移动该圆，直到至少有两个点位于其边界上，而不会减少覆盖点的数量。 这极大地减少了搜索空间。 

有几个重要的边缘情况：

 - 只有一支飞镖存在，答案一定是`1`。 
- 多个省道可能已经适合以一个省道为中心的单个圆内。 
- 相距较远的两点`2r`不能位于同一个半径的边界圆上`r`。 
- 浮点精度很重要，因为圆心是使用平方根和除法计算的。 
- 有些点可能正好位于边界上，这些点必须算在飞镖盘内。 

## 方法

 ### 蛮力方法

 一种简单的方法是尝试测试平面上许多可能的圆心，并计算每个圆包含多少个点。 

思考暴力的一种方法是：

 1. 从密集网格中生成候选中心。 
2. 对于每个中心，计算到所有点的距离。 
3. 计算半径内有多少个点`r`。 

这显然是不切实际的，因为平面是连续的，这意味着存在无限多个可能的中心。 即使将平面离散化也不能保证正确性。 

另一个蛮力的想法是考虑每一个三重点并计算穿过它们的圆。 然而，三元组的圆拟合变得不必要的复杂，并且仍然导致高复杂性。 

蛮力概念有助于揭示一个重要的属性：最佳圆受到其边界上的点的严格约束。 

### 关键见解

 如果一个圆的半径`r`包含多个点，我们可以滑动圆，直到一两个点接触边界，同时仍然保留所有被覆盖的点。 

对于任意一对点，其距离最大为`2r`，恰好有两个半径的圆`r`通过这两个点。 

这意味着：

 - 每个有意义的候选圆都可以由一对点生成。 
- 我们只需要检查由成对飞镖定义的圆。 

因此该算法变为：

 1. 选取每对点。 
2. 计算可能的圆心半径`r`穿过他们。 
3. 计算每个圆圈包含多少个飞镖。 
4. 跟踪最大值。 

由于只有`100`点，这种方法足够有效。

 | ---| ---| ---| ---|
 | 蛮力 | 无限或不切实际| O(1) | O(1) | 圆心连续搜索空间|
 | 最佳 | O(n3) | O(1) | O(1) | 从点对生成候选圆 |

 ## 算法演练

 1. 首先将答案初始化为`1`，因为任何单个省道总是可以被以该省道为中心的圆覆盖。 
2. 迭代每对点`(p1, p2)`。 
3. 计算两点之间的欧氏距离。 
4. 如果距离大于`2r`，跳过这一对，因为没有半径圆`r`可以通过这两个点。 
5. 否则，计算两点之间的中点。 该中点位于连接它们的线段上。 
6. 圆心必须位于连接点的线段的垂直平分线上。 
7. 使用几何计算中点到圆心的距离：

 所形成的三角形为：

 - 中心，
 - 中点，
 - 一个端点

 是一个直角三角形。 

使用毕达哥拉斯定理：$h = \sqrt{r^2 - \left(\frac{d}{2}\right)^2}$在哪里：

-`d`是点之间的距离
 -`h`是中点到圆心的距离
 8. 确定垂直方向矢量。 
9. 使用中点和垂直向量，计算两个可能的圆心。 
10. 对于每个候选中心：

 - 迭代所有的飞镖。 
- 计算从中心到省道的距离。 
- 如果距离小于或等于，则计算飞镖数`r`。 
11. 更新最大计数。 
12. 处理完所有对后，返回最大值。 

### 为什么它有效

 任何最佳圆都可以平移，直到至少两个包含的点接触圆的边界。 因此，每个最优解都对应于由某对点生成的圆。 

通过检查每个有效的对以及从该对导出的两个可能的圆中心，我们保证考虑最佳的圆配置。 计算每个候选圆内的所有点可确保找到最大可能的数量。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def numPoints(self, darts: List[List[int]], r: int) -> int:
        n = len(darts)

        if n == 1:
            return 1

        EPSILON = 1e-7
        best = 1

        def count_points(cx: float, cy: float) -> int:
            count = 0

            for x, y in darts:
                dx = x - cx
                dy = y - cy

                if dx * dx + dy * dy <= r * r + EPSILON:
                    count += 1

            return count

        for i in range(n):
            x1, y1 = darts[i]

            for j in range(i + 1, n):
                x2, y2 = darts[j]

                dx = x2 - x1
                dy = y2 - y1

                distance_sq = dx * dx + dy * dy
                distance = math.sqrt(distance_sq)

                if distance > 2 * r + EPSILON:
                    continue

                mid_x = (x1 + x2) / 2
                mid_y = (y1 + y2) / 2

                half_distance = distance / 2

                height = math.sqrt(r * r - half_distance * half_distance)

                perp_x = -dy / distance
                perp_y = dx / distance

                center1_x = mid_x + perp_x * height
                center1_y = mid_y + perp_y * height

                center2_x = mid_x - perp_x * height
                center2_y = mid_y - perp_y * height

                best = max(best, count_points(center1_x, center1_y))
                best = max(best, count_points(center2_x, center2_y))

        return best
```实现直接遵循几何推导。 

辅助函数`count_points`计算候选圆圈内有多少飞镖。 为了避免浮点精度问题，比较包括一个小的 epsilon 值。 

The nested loops enumerate all point pairs. 对于每一对，算法首先检查点是否足够接近以适合在同一个半径的圆内`r`。 

一旦找到有效的对，就计算中点。 然后使用归一化的垂直矢量计算垂直平分线方向。 

The geometry formula gives the offset distance from the midpoint to the circle center. 使用正垂直方向和负垂直方向生成两个可能的中心。 

最后，每个飞镖都针对两个圆进行测试，并更新最大计数。 

## 解决方案```go
package main

import (
	"math"
)

func numPoints(darts [][]int, r int) int {
	n := len(darts)

	if n == 1 {
		return 1
	}

	const EPSILON = 1e-7

	best := 1
	radiusSquared := float64(r * r)

	countPoints := func(cx, cy float64) int {
		count := 0

		for _, point := range darts {
			dx := float64(point[0]) - cx
			dy := float64(point[1]) - cy

			if dx*dx+dy*dy <= radiusSquared+EPSILON {
				count++
			}
		}

		return count
	}

	for i := 0; i < n; i++ {
		x1 := float64(darts[i][0])
		y1 := float64(darts[i][1])

		for j := i + 1; j < n; j++ {
			x2 := float64(darts[j][0])
			y2 := float64(darts[j][1])

			dx := x2 - x1
			dy := y2 - y1

			distanceSquared := dx*dx + dy*dy
			distance := math.Sqrt(distanceSquared)

			if distance > float64(2*r)+EPSILON {
				continue
			}

			midX := (x1 + x2) / 2.0
			midY := (y1 + y2) / 2.0

			halfDistance := distance / 2.0

			height := math.Sqrt(float64(r*r) - halfDistance*halfDistance)

			perpX := -dy / distance
			perpY := dx / distance

			center1X := midX + perpX*height
			center1Y := midY + perpY*height

			center2X := midX - perpX*height
			center2Y := midY - perpY*height

			best = max(best, countPoints(center1X, center1Y))
			best = max(best, countPoints(center2X, center2Y))
		}
	}

	return best
}

func max(a, b int) int {
	if a > b {
		return a
	}

	return b
}
```Go 实现密切反映了 Python 逻辑。 由于 Go 没有提供内置的`max`对于整数函数，添加了一个辅助函数。 

所有几何计算都使用`float64`因为整数运算在中点和平方根计算期间会失去精度。 

该解决方案使用切片来存储点，直接匹配 LeetCode 函数签名。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n3) | O(n²) 对，每对检查所有 n 个点 |
 | 空间| O(1) | O(1) | 仅使用常量额外变量 |

 该算法迭代所有点对，这需要`O(n²)`工作。 对于每个生成的圆心，它会扫描所有点以计算有多少个点位于圆内，并添加另一个因子`n`。 

自从`n ≤ 100`，最坏的情况大约是`100³ = 1,000,000`操作，这很容易足够快。 

该算法仅使用固定数量的浮点变量和计数器，因此额外的空间使用量是恒定的。

 ## 边缘情况

 当两点之间的距离恰好是时，就会出现一种重要的边缘情况`2r`。 在这种情况下，两点位于直径的两端，并且只有一个有效的圆心。 从数字上讲，这可能会导致浮点不稳定，因为计算的高度变为零。 该实现自然地处理了这个问题，因为垂直偏移变为零，产生相同的中心两次。 

另一个重要的情况是所有点相距极远。 幼稚的实现可能会错误地尝试计算不可能对的圆心，从而导致平方根运算中出现负值。 该解决方案通过首先检查距离是否超过来避免这种情况`2r`。 

浮点精度是另一个主要问题。 由于舍入误差，数学上精确位于圆边界上的点在进行数值计算时可能会稍微出现在外侧。 该实现在比较中使用较小的 epsilon 容差解决了这个问题。 

当只有一个飞镖存在时，会出现最后一种微妙的边缘情况。 由于配对迭代永远不会执行，因此答案必须已正确初始化。 将初始答案设置为`1`保证这个最小输入的正确行为。
