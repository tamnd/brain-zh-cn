[LeetCode 第 1400 题](https://leetcode.com/problems/construct-k-palindrome-strings/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、贪婪、计数

 ## 解决方案

 ## 问题理解

 问题是询问给定的字符串是否`s`可以重新排列以精确形成`k`使用 **all** 字符的非空回文字符串`s`。 换句话说，我们需要分区`s`进入`k`回文使得每个字符`s`仅使用一次。 

回文是向前和向后读相同的字符串。 对于一个字符串来说，回文最多有一个字符可以有奇数个频率； 所有其他字符必须出现偶数次才能围绕中心进行镜像。 

输入由一个字符串组成`s`长度不超过 100,000 的小写英文字母和一个整数`k`（最多 100,000）。 输出是一个布尔值：`true`如果字符串可以重新排列成`k`回文，和`false`否则。 

需要注意的重要边缘情况是`k`大于长度`s`（不可能产生比字符更多的回文），或者当所有字符都是唯一且`k`很小（需要长度 >1 的回文，但这可能是不可能的）。 

## 方法

 暴力方法将尝试生成所有可能的分区`s`进入`k`子串，然后检查每个子串是否是回文。 虽然这保证了正确性，但时间复杂度是指数级的，对于给定的约束（字符串长度最多 10^5）来说完全不切实际。 

最佳解决方案的关键洞察来自字符频率。 对于每个回文，我们最多可以有一个奇数字符（作为中间字符）。 因此，所需的最小回文数等于中的字符数`s`数量为奇数的。 如果这个数字大于`k`, 不可能构造出`k`回文。 此外，我们不能创建比字符总数更多的回文（`k > len(s)`），因为每个回文必须是非空的。 

这就产生了一种有效的方法：计算每个字符的频率，确定有多少个字符具有奇数计数，并检查两个条件：`odd_count <= k <= len(s)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 生成所有分区并检查回文，对于大n | 不可行
 | 最佳 | O(n) | O(1) | O(1) | 计算字符频率、计算奇数字符、检查条件 |

 ## 算法演练

 1. 初始化一个频率数组或哈希图来统计每个字符出现的次数`s`。 
2. 迭代字符串`s`并填充频率计数。 
3. 初始化计数器`odd_count`为零。 
4. 迭代频率计数。 对于每个具有奇数频率的字符，增量`odd_count`。 
5. 检查是否`odd_count`小于或等于`k`（每个回文最多可以容纳一个奇数字符）。 
6. 还要检查是否`k`小于或等于的长度`s`（回文数不能多于字符数）。 
7. 返回`true`如果两个条件都满足，否则返回`false`。 

**为什么有效**：每个回文最多可以有一个在其中心出现频率为奇数的字符。 因此，所需的最少回文数正是出现奇数频率的字符数。 如果`k`小于这个数，是不可能的。 另一个约束（`k <= len(s)`) 确保每个回文都非空。 这样就保证了正确性。 

## Python 解决方案```python
class Solution:
    def canConstruct(self, s: str, k: int) -> bool:
        if k > len(s):
            return False
        
        freq = [0] * 26
        for char in s:
            freq[ord(char) - ord('a')] += 1
        
        odd_count = sum(1 for count in freq if count % 2 == 1)
        return odd_count <= k
```Python 实现首先检查以下简单情况：`k`大于字符串长度。 然后，它使用固定大小的数组进行字符计数，以优化空间和性能。 奇数频率之和决定了所需的最小回文数。 最终的布尔表达式直接检查可行性条件。 

## 解决方案```go
func canConstruct(s string, k int) bool {
    if k > len(s) {
        return false
    }

    freq := [26]int{}
    for _, c := range s {
        freq[c-'a']++
    }

    oddCount := 0
    for _, count := range freq {
        if count%2 == 1 {
            oddCount++
        }
    }

    return oddCount <= k
}
```Go 实现反映了 Python 逻辑。 包含 26 个整数的固定大小数组用于频率计数。 迭代字符串和数组计算`oddCount`。 最终条件检查可行性。 Go 将字符串迭代处理为符文，但由于输入是小写英文字母，因此减去`'a'`给出正确的索引。 

## 工作示例

 **示例1**：`s = "annabelle"`,`k = 2`频率计数：a:2、n:2、b:1、e:3、l:2

 奇数计数：b(1), e(3) → 总 odd_count = 2

 检查：2 <= 2 且 2 <= 9 → True

 **示例2**：`s = "leetcode"`,`k = 3`频率计数：l:1、e:3、t:1、c:1、o:1、d:1

 奇数计数：l、e、t、c、o、d → odd_count = 6

 检查：6 <= 3？ 否 → 假

 **示例3**：`s = "true"`,`k = 4`频率计数：t:1、r:1、u:1、e:1

 奇数计数 = 4

 检查：4 <= 4 且 4 <= 4 → True

 ## 边缘情况

 一个重要的边缘情况是当`k`超过字符串的长度。 这是不可能的，因为每个回文必须至少包含一个字符，并且实现会明确检查这一点。 

另一种边缘情况是所有字符都有奇数频率。 所需的最小回文数等于奇数字符的数量。 该解决方案通过计算奇数频率并将它们与`k`。 

第三种边缘情况是当`k`等于字符串长度。 在这里，每个字符都必须成为自己的回文。 该算法正确地允许这种情况，因为奇数字符的数量不能超过`k`，以及支票`k <= len(s)`确保可行性。
