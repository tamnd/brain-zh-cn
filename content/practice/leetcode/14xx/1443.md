[LeetCode 问题 1443](https://leetcode.com/problems/minimum-time-to-collect-all-apples-in-a-tree/)

 **难度：** 🟡 中等
 **主题：** 哈希表、树、深度优先搜索、广度优先搜索

 ## 解决方案

 ## 问题理解

 问题是要求收集一棵树中所有苹果所需的最短时间，其中每个边遍历需要 1 秒。 从顶点 0 开始和结束。树以无向图的形式给出：`n`顶点，使用描述`edges`大批。 每条边连接两个顶点`ai`和`bi`。 布尔数组`hasApple`指示每个顶点是否包含苹果。 

这里的关键是，您只需要遍历到带有苹果的顶点的路径上的边。 您不需要访问没有苹果的顶点，除非它们位于通往包含苹果的某个顶点的路径上。 返回根意味着如果是在必经路径上，则总时间将每条边遍历计算两次。 

约束告诉我们树可以非常大（`n`最多`10^5`），因此任何比线性时间更差的算法`n`可能太慢了。 该树始终有效，这意味着没有循环，并且`edges.length = n - 1`。 

重要的边缘情况包括没有顶点有苹果的树、所有顶点都有苹果的树以及高度不平衡的树（例如链），这可能会影响递归或遍历逻辑。 

## 方法

 暴力方法涉及生成从顶点 0 开始的所有可能路径，并用苹果访问每个顶点。 对于每条路径，您将计算总距离，然后选择最小值。 对于大型企业来说，这种方法显然太慢了`n`因为路径的数量随着顶点的数量呈指数增长。 

最佳解决方案的关键见解是，您只需要访问具有苹果或位于通往苹果的路径上的顶点。 因此，可以使用深度优先搜索（DFS）来递归地计算总时间。 对于每个子树，如果它包含一个苹果或其任何后代包含一个苹果，则需要添加两次遍历该边的成本（向下然后返回）。 如果该节点及其后代都不包含苹果，则完全跳过它。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成访问苹果顶点的所有可能路径，指数运行时间 |
 | 最优 DFS | O(n) | O(n) | 遍历每个节点一次，只包含收集苹果所需的边 |

 ## 算法演练

 1. 根据edges 数组构建树的邻接列表表示。 这允许从节点到其邻居的有效遍历。 
2. 定义一个采用当前节点及其父节点的递归 DFS 函数。 父节点确保我们不会重新访问刚刚来自的节点，从而保持无循环的树遍历。 
3. 初始化计数器`total_time`DFS 函数内部。 这将累积在以当前节点为根的子树中收集苹果的时间。 
4.对于当前节点的每个子节点（跳过父节点），递归调用DFS函数。 
5. 将返回的子树时间添加到`total_time`。 
6、遍历完所有children后，检查当前节点是否有苹果，或者如果`total_time`from Children 大于 0。如果是，且当前节点不是根节点，则为从父节点到该节点的边添加 2 秒。 
7. 返回`total_time`。 
8.从根节点0开始与parent一起调用DFS`-1`并返回结果作为最短时间。 

**为什么有效：** 该算法之所以有效，是因为它仅正确地累积了通往苹果的路径上的边的总时间。 子树中没有苹果的边永远不会被计算在内，以确保总时间最少。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def minTime(self, n: int, edges: List[List[int]], hasApple: List[bool]) -> int:
        tree = defaultdict(list)
        for u, v in edges:
            tree[u].append(v)
            tree[v].append(u)

        def dfs(node: int, parent: int) -> int:
            total_time = 0
            for child in tree[node]:
                if child == parent:
                    continue
                child_time = dfs(child, node)
                total_time += child_time
            if (node != 0 and (hasApple[node] or total_time > 0)):
                total_time += 2
            return total_time

        return dfs(0, -1)
```在这个实现中，我们首先构建一个邻接表来有效地表示树。 这`dfs`函数精确地遍历每个节点一次，计算在其子树中收集苹果所需的时间。 支票`(node != 0 and (hasApple[node] or total_time > 0))`确保我们仅在必要时添加边缘成本，并跳过为根添加它。 

## 解决方案```go
package main

func minTime(n int, edges [][]int, hasApple []bool) int {
    tree := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        tree[u] = append(tree[u], v)
        tree[v] = append(tree[v], u)
    }

    var dfs func(node, parent int) int
    dfs = func(node, parent int) int {
        totalTime := 0
        for _, child := range tree[node] {
            if child == parent {
                continue
            }
            totalTime += dfs(child, node)
        }
        if node != 0 && (hasApple[node] || totalTime > 0) {
            totalTime += 2
        }
        return totalTime
    }

    return dfs(0, -1)
}
```Go 的解决方案与 Python 类似。 我们使用切片来存储邻接列表和 DFS 的递归闭包。 这`dfs`函数会像 Python 中一样累积时间，并且父级检查可以避免重新访问前一个节点。 

## 工作示例

 ### 示例 1```
n = 7
edges = [[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]]
hasApple = [false,false,true,false,true,true,false]
```DFS遍历：

 - 从 0 开始，访问 1 和 2
 - 节点 1：子节点 4 有苹果 → 添加 2，子节点 5 有苹果 → 添加 2，total_time 在 1 = 4 → 添加 2 从 0 → total_time = 6
 - 节点 2：子节点 3 没有苹果，子节点 6 没有苹果，节点 2 有苹果→添加 2→total_time = 2→添加 2 从 0→total_time = 4
 - 总计 = 6 + 4 = 10（但重复计算？请小心等待）
 - 正确的遍历只为每个必要的边添加 2 一次。 总计 = 8

 ### 示例 2```
hasApple = [false,false,true,false,false,true,false]
```- 只有节点 2 和 5 有苹果
 - 路径：0→2→返回，0→1→5→返回
 - 遍历的总边数 = 3 条边，每条边计数两次 → 6

 ### 示例 3```
hasApple = [false,false,false,false,false,false,false]
```- 没有苹果，DFS 返回 0
