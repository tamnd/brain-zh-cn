[LeetCode 第 1496 题](https://leetcode.com/problems/path-crossing/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们根据一串方向指令来模拟 2D 平面上的运动。 字符串中的每个字符代表在基本方向上移动一个单位：`'N'`对于北（向上），`'S'`向南（向下），`'E'`东（右），以及`'W'`向西（左）。 你总是从原点开始`(0, 0)`并一步一步地遵循路径。 任务是确定您是否在任何时候重新访问过您已经去过的位置。 如果这样做，该函数应该返回`true`; 否则，它应该返回`false`。 

输入是长度在 1 到 10,000 之间的字符串，因此任何解决方案都必须有效地处理潜在的长路径。 边缘情况包括非常短的路径（长度为1）、立即返回原点的路径以及穿越大面积而不相交的路径。 

要点：在整数坐标上移动是离散的，重新访问路径中任何位置的点都算作交叉，并且不存在对角线移动。 该问题保证输入字符有效，因此不需要输入验证。 

## 方法

 暴力方法涉及将所有访问过的坐标存储在列表中，并在每一步检查新位置是否已存在于该列表中。 虽然正确，但这需要扫描每次移动的列表，这导致 n 个步骤的时间复杂度为 O(n²)，这对于 n 高达 10,000 来说太慢了。 

最佳解决方案的关键观察是基于哈希的结构允许 O(1) 成员资格检查。 通过将访问过的坐标存储在哈希集中，我们可以在每一步立即检查是否有重新访问，从而得到时间和空间上的 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 将坐标存储在列表中并线性检查成员资格 |
 | 最佳 | O(n) | O(n) | 使用哈希集来存储访问过的坐标以进行恒定时间检查 |

 ## 算法演练

 1. 初始化一个哈希集来存储访问过的坐标。 首先添加`(0, 0)`因为那是起点。 
2.设置两个变量`x`和`y`代表当前位置，最初`(0, 0)`。 
3. 迭代路径字符串中的每个字符：

 1. 更新`x`或者`y`根据方向：`'N'`增量`y`,`'S'`递减`y`,`'E'`增量`x`,`'W'`递减`x`。 
2. 形成一个元组`(x, y)`为了新的职位。 
3. 检查该元组是否已经存在于访问位置的哈希集中。 

- 如果是，立即返回`true`。 
- 否则，将该元组添加到哈希集中。 
4. 如果循环完成后没有找到重复项，则返回`false`。 

**为什么有效：** 该算法保持一个不变量，即该集合始终包含迄今为止访问过的所有位置。 通过检查每一步的成员资格，可以确保立即检测到任何重复的位置。 

## Python 解决方案```python
class Solution:
    def isPathCrossing(self, path: str) -> bool:
        visited = set()
        x, y = 0, 0
        visited.add((x, y))
        
        for move in path:
            if move == 'N':
                y += 1
            elif move == 'S':
                y -= 1
            elif move == 'E':
                x += 1
            elif move == 'W':
                x -= 1
            
            if (x, y) in visited:
                return True
            visited.add((x, y))
        
        return False
```Python 实现完全遵循该算法。 它使用一组来存储访问过的坐标，更新`(x, y)`根据每次移动的位置，检查重新访问，并返回正确的布尔值。 使用元组作为集合中的键可确保快速查找。 

## 解决方案```go
func isPathCrossing(path string) bool {
    visited := make(map[[2]int]bool)
    x, y := 0, 0
    visited[[2]int{x, y}] = true
    
    for _, move := range path {
        switch move {
        case 'N':
            y++
        case 'S':
            y--
        case 'E':
            x++
        case 'W':
            x--
        }
        
        pos := [2]int{x, y}
        if visited[pos] {
            return true
        }
        visited[pos] = true
    }
    
    return false
}
```在 Go 中，带有数组键的映射用于访问的坐标。 Go 数组是可比较的，这使得它们成为有效的映射键。 该实现镜像了 Python 版本`switch`方向更新声明。

 ## 边缘情况

 第一个重要的边缘情况是立即返回原点的路径，例如`"NS"`。 幼稚的实现可能会忘记标记`(0, 0)`正如最初访问的那样，导致它错过了十字路口。 我们的实现将原点添加到循环之前的访问集中。 

第二个边缘情况是由长距离的单个重复方向组成的路径，例如`"N"*10000`。 这测试了算法在不存在交叉点时不会错误地报告交叉点，并且可以有效地扩展到最大输入长度。 

第三种边缘情况是在完成另一个维度之前在一个维度中形成循环的路径，例如`"EEWW"`。 一些仅跟踪最后位置的实现可能会错误地得出没有交叉的结论，但我们的解决方案将所有访问过的位置保留在哈希集中，以确保正确性。
