[LeetCode 问题 1458](https://leetcode.com/problems/max-dot-product-of-two-subsequences/)

 **难度：** 🔴难
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 问题是要求找到两个数组的**非空子序列**的最大点积`nums1`和`nums2`使得子序列具有相同的长度。 通过将相应元素相乘并对结果求和来计算两个长度相等的序列的点积。 例如，点积`[a, b]`和`[c, d]`是`a*c + b*d`。 

简单来说，您可以从两个数组中删除任意数量的元素以形成两个子序列，目标是最大化这些子序列的两两乘积之和。 

输入由两个整数数组组成`nums1`和`nums2`，长度最大为 500。每个整数的范围为 -1000 到 1000。这些约束表明，暴力枚举所有子序列在计算上是不可行的，因为子序列的数量呈指数增长。 可能导致朴素解决方案失败的边缘情况包括全负数的数组、全零的数组或最佳子序列由单个元素组成的数组。 

## 方法

 暴力方法是为两个数组生成所有可能的子序列，将所有具有相同长度的子序列组合配对，计算它们的点积，并返回最大值。 虽然这是正确的，但效率极低，因为长度数组的子序列数`n`是`2^n`，使得这种方法不可行`n`最多 500 个。 

最佳解决方案的关键洞察是**动态规划**。 我们定义一个2D DP表`dp[i][j]`使用第一个存储子序列的最大点积`i`的元素`nums1`和第一个`j`的元素`nums2`。 递归关系考虑三种可能性：将两个数组的当前元素包含在点积中、从`nums1`，或跳过当前元素`nums2`。 这种方法确保我们考虑所有有效的子序列，而无需显式枚举它们。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m * 2^n) | O(2^m * 2^n) | O(1) | O(1) | 生成两个数组的所有子序列，比较所有对 |
 | 最佳 | O(m * n) | O(m * n) | 动态规划，计算所有前缀的最大点积 |

 ## 算法演练

 1.初始化2D DP表`dp`尺寸的`(m+1) x (n+1)`， 在哪里`m`的长度是`nums1`和`n`的长度是`nums2`。 将所有单元格初始化为一个非常小的数字，例如`-inf`，正确处理负值。 
2. 迭代每个索引`i`的`nums1`和每个索引`j`的`nums2`。 
3. 对于每对`(i, j)`，如果我们包含元素，则计算点积`nums1[i]`和`nums2[j]`。 这是`nums1[i] * nums2[j]`。 
4. 考虑三种选择`dp[i+1][j+1]`:

 - 获取当前产品并添加最大值`dp[i][j]`（如果存在非空子序列）。 
- 跳过`nums1[i]`并结转`dp[i][j+1]`。 
- 跳过`nums2[j]`并结转`dp[i+1][j]`。 
- 此外，考虑仅将当前乘积作为长度为 1 的子序列，以防所有先前组合均为负数。 
5. 返回`dp[m][n]`其中包含使用两个数组的所有元素的最大点积。 

**为什么有效：** DP 表维护了以下不变式：`dp[i][j]`存储使用数组前缀可获得的最大点积。 在每一步中，我们都会考虑包含或排除当前元素，这确保有效地考虑所有可能的子序列。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        dp = [[float('-inf')] * (n + 1) for _ in range(m + 1)]
        
        for i in range(m):
            for j in range(n):
                product = nums1[i] * nums2[j]
                dp[i+1][j+1] = max(product,
                                   product + dp[i][j],
                                   dp[i][j+1],
                                   dp[i+1][j])
        return dp[m][n]
```在此 Python 实现中，`dp[i+1][j+1]`使用第一个跟踪最大点积`i`的元素`nums1`和第一个`j`的元素`nums2`。 我们通过单独考虑当前产品、与先前最佳产品的总和来更新每个单元格（`dp[i][j]`)，或跳过任一数组中的元素。 

## 解决方案```go
func maxDotProduct(nums1 []int, nums2 []int) int {
    m, n := len(nums1), len(nums2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
        for j := range dp[i] {
            dp[i][j] = -1 << 60 // simulate -inf
        }
    }
    
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            product := nums1[i] * nums2[j]
            dp[i+1][j+1] = max(product,
                               product + dp[i][j],
                               dp[i][j+1],
                               dp[i+1][j])
        }
    }
    return dp[m][n]
}

func max(nums ...int) int {
    res := nums[0]
    for _, x := range nums[1:] {
        if x > res {
            res = x
        }
    }
    return res
}
```Go 的实现与 Python 版本非常相似。 由于 Go 没有`-inf`对于整数，我们使用非常大的负数来模拟它。 我们还使用一个助手`max`函数计算多个整数的最大值。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(m * n) | 我们填充一个大小为 m x n 的 DP 表，每个单元的计算量为 O(1) |

 这种复杂性对于`m, n <= 500`，因为它最多会产生 250,000 个表条目。
