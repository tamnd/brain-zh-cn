## 问题理解

 这个问题给了我们一个`rows x cols`代表樱桃田的网格。 每个单元格包含一个非负整数，表示该位置的樱桃数量。 两个机器人从左上角开始`(0, 0)`和右上角`(0, cols - 1)`角，并且两者都必须到达网格的底行。 机器人每一步都可以向左对角移动、向下直行或向右对角移动。 当机器人访问某个牢房时，它会收集那里的所有樱桃； 如果两个机器人都落在同一个单元格上，则只有一个机器人收集樱桃。 

输入是一个二维整数列表`grid`，有约束条件`2 <= rows, cols <= 70`和`0 <= grid[i][j] <= 100`。 输出是两个机器人按照移动规则**采集到的最大樱桃总数**。 

重要的边缘情况包括：具有最小尺寸的网格（`2x2`）、全零的网格、机器人频繁降落在同一个单元上，以及在不同位置具有最大樱桃的网格，强制路径不重叠。 

该问题需要一个有效的解决方案，因为对两个机器人的所有可能路径进行强力探索将呈指数级增长。`rows * cols`考虑到限制，这是不可行的。 

## 方法

 **暴力方法：**

 最简单的方法是递归地尝试两个机器人的所有可能路径。 在每一行，对于机器人 1 和机器人 2，我们考虑三个动作（`left-diagonal`,`down`,`right-diagonal`）并递归直到到达最后一行。 在每一步中，我们都会对两个机器人收集的樱桃进行求和，避免它们占据同一单元格时的重复计算。 

这种方法是正确的，因为它探索了所有组合，但速度非常慢。 和`cols`列和`rows`行，可能的状态数大致为`O(3^rows * 3^rows) = O(9^rows)`，这是指数且不可行的`rows`最多 70。 

**最优方法（动态规划）：**

 关键见解：该问题具有重叠的子问题。 从行中收集的最大樱桃数`i`向前取决于**仅取决于行中两个机器人**的当前位置`i`。 因此，我们可以定义一个DP状态`dp[i][j1][j2]`代表从行中收集的最大樱桃数`i`当机器人1在列时到底部`j1`机器人2在列`j2`。 

过渡：从`dp[i][j1][j2]`，考虑所有 9 个可能的下一步行动（`j1-1, j1, j1+1`×`j2-1, j2, j2+1`） 到`dp[i+1][new_j1][new_j2]`。 从当前行添加樱桃（注意只计算一次，如果`j1 == j2`）。 最终的答案是`dp[0][0][cols-1]`。 

该 DP 将复杂性从指数级降低到`O(rows * cols * cols * 9) = O(rows * cols^2)`与记忆。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(9^行) | O（行）| 递归尝试所有机器人动作，太慢 |
 | 最优 (DP) | O(行数 * 列数^2) | O(行数 * 列数^2) | 记忆递归或 3D DP，适用于行，列数 ≤ 70 |

 ## 算法演练

 1. **定义 DP 状态：** 让`dp[i][j1][j2]`是从行中收集的最大樱桃数`i`如果机器人 1 在列，则到底部`j1`和机器人 2 在列`j2`。 
2. **基本情况：** 如果`i == rows`，返回 0。机器人已经越过最后一排，因此没有剩余樱桃。 
3. **当前樱桃：** 对于职位`(i, j1)`和`(i, j2)`， 收集`grid[i][j1] + grid[i][j2]`如果`j1 != j2`; 否则，仅`grid[i][j1]`。 
4. **递归/转换：**迭代`dj1`和`dj2`超过`[-1, 0, 1]`代表左、下、右移动。 对于每个有效的`(new_j1, new_j2)`在界限内，递归计算`dp[i+1][new_j1][new_j2]`。 
5. **记忆：** 将结果存储在 3D 表中以避免重新计算。 
6. **返回：** 开始递归`dp[0][0][cols-1]`，它代表左上角和右上角的起始位置。 

**为什么有效：** 每个州`dp[i][j1][j2]`在给定机器人位置的情况下，正确地表示从该行开始可收集的最佳樱桃。 通过探索每步的所有 9 个动作并存储结果，DP 确保没有子问题被解决两次，并且所有组合都会被考虑。 这保证了最优解决方案。 

## Python 解决方案```python
from typing import List
from functools import lru_cache

class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        @lru_cache(maxsize=None)
        def dp(i: int, j1: int, j2: int) -> int:
            if j1 < 0 or j1 >= cols or j2 < 0 or j2 >= cols:
                return float('-inf')  # invalid position

            # Cherries collected at current positions
            result = grid[i][j1]
            if j1 != j2:
                result += grid[i][j2]

            if i == rows - 1:  # last row
                return result

            # Recurse for all 9 possible next moves
            max_cherries = float('-inf')
            for dj1 in [-1, 0, 1]:
                for dj2 in [-1, 0, 1]:
                    max_cherries = max(max_cherries, dp(i + 1, j1 + dj1, j2 + dj2))

            result += max_cherries
            return result

        return dp(0, 0, cols - 1)
```**说明：**我们使用`lru_cache`记住`dp(i, j1, j2)`结果。 在每一步中，我们都会检查边界、计算收集到的樱桃，并递归地探索所有 9 个动作。 递归构建从底行向后收集的最大樱桃。 

## 解决方案```go
func cherryPickup(grid [][]int) int {
	rows := len(grid)
	cols := len(grid[0])

	memo := make([][][]int, rows)
	for i := 0; i < rows; i++ {
		memo[i] = make([][]int, cols)
		for j := 0; j < cols; j++ {
			memo[i][j] = make([]int, cols)
			for k := 0; k < cols; k++ {
				memo[i][j][k] = -1
			}
		}
	}

	var dp func(i, j1, j2 int) int
	dp = func(i, j1, j2 int) int {
		if j1 < 0 || j1 >= cols || j2 < 0 || j2 >= cols {
			return -1 << 60
		}
		if memo[i][j1][j2] != -1 {
			return memo[i][j1][j2]
		}

		result := grid[i][j1]
		if j1 != j2 {
			result += grid[i][j2]
		}

		if i == rows-1 {
			memo[i][j1][j2] = result
			return result
		}

		maxCherries := -1 << 60
		for dj1 := -1; dj1 <= 1; dj1++ {
			for dj2 := -1; dj2 <= 1; dj2++ {
				next := dp(i+1, j1+dj1, j2+dj2)
				if next > maxCherries {
					maxCherries = next
				}
			}
		}

		result += maxCherries
		memo[i][j1][j2] = result
		return result
	}

	return dp(0, 0, cols-1)
}
```**Go 特定注释：** 我们预先分配一个 3D`memo`切片并使用`-1`作为未初始化的标记。 Go 需要显式整数溢出安全初始化（`-1 << 60`) 为负无穷大。
