[LeetCode 第 1419 题](https://leetcode.com/problems/minimum-number-of-frogs-croaking/)

 **难度：** 🟡 中等
 **主题：** 字符串、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们确定产生由字符串表示的给定序列的呱呱叫声所需的最小青蛙数量`croakOfFrogs`。 每只青蛙按顺序发出呱呱叫声`"c" -> "r" -> "o" -> "a" -> "k"`，并且多只青蛙可以同时发出叫声。 挑战在于不同青蛙的字母可以交织，但每只青蛙都必须完成完整的字母`"croak"`为了。 输入字符串仅包含字符`'c'`,`'r'`,`'o'`,`'a'`,`'k'`，长度最大可达 100,000 个字符。 

预期输出是一个整数，表示同时完成所有呱呱叫声所需的最小青蛙数量，或者`-1`如果字符串不是有效的组合`"croak"`序列。 要考虑的边缘情况包括不完整的叫声、违反字母顺序的重叠叫声以及多个青蛙并行叫声的情况。 

约束告诉我们，由于输入的潜在大小，解决方案需要高效（O(n) 或接近）。 该问题保证仅存在有效的呱呱声字符，但不能保证它们形成有效的呱呱声。 

## 方法

 暴力方法会尝试通过动态地将字母分配给不同的青蛙来模拟每种可能的青蛙叫声序列。 对于每个角色，我们都会尝试继续现有的青蛙叫声或开始新的叫声。 对于大型输入来说，这是麻烦、缓慢且难以正确实现的，因为在检查哪个青蛙可以接受下一个字符时，它可能会接近 O(n^2) 时间复杂度。 

最佳方法的关键洞察是使用固定大小的数组或哈希图来跟踪呱呱序列每个阶段中青蛙的数量。 具体来说，我们统计当前有多少只青蛙`'c'`,`'r'`,`'o'`,`'a'`， 和`'k'`。 每个新角色要么将一只青蛙推进到下一个阶段，要么在以下位置开始一只新青蛙`'c'`。 通过跟踪每个阶段活跃的青蛙，我们可以确定同时发出叫声的最大数量，从而给出所需的最小青蛙数量。 如果在任何时候计数不一致（例如，更多`'r'`比`'c'`)，输入无效，我们返回`-1`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 单独模拟每只青蛙，输入较大时速度较慢 |
 | 最佳 | O(n) | O(1) | O(1) | 跟踪每个叫声阶段的青蛙数量，只需要大小为 5 的固定数组 |

 ## 算法演练

 1.初始化固定数组`counts`大小为 5，用于跟踪每个阶段的青蛙数量`"c"`,`"r"`,`"o"`,`"a"`,`"k"`。 
2. 初始化变量`max_frogs`跟踪同时青蛙的最大数量。 
3. 遍历每个字符`croakOfFrogs`。 
4. 将每个角色映射到其阶段索引：`'c'->0`,`'r'->1`,`'o'->2`,`'a'->3`,`'k'->4`。 
5. 如果角色是`'c'`, 增量`counts[0]`因为它开始发出新的呱呱声。 
6. 对于其他字符，检查前一阶段是否有正计数。 如果是，则递减前一阶段并递增当前阶段。 如果没有，则返回`-1`因为呱呱叫的顺序被破坏了。 
7. 更新计数后，计算当前呱呱叫的青蛙数量：`sum(counts[:4])`（排除`'k'`当完成的呱呱声释放青蛙时）。 更新`max_frogs`如果这个数字更高。 
8. 遍历字符串后，检查除`'k'`为零。 如果没有，则返回`-1`。 
9. 返回`max_frogs`。 

**为什么有效**：通过维护每个阶段的计数，我们确保了顺序`"croak"`被保留，并且通过跟踪最大并发青蛙，我们得到所需的最小数量。 该算法保证了正确性，因为任何违反命令的行为都会立即被捕获。 

## Python 解决方案```python
class Solution:
    def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
        stages = {'c': 0, 'r': 1, 'o': 2, 'a': 3, 'k': 4}
        counts = [0] * 5
        max_frogs = 0

        for char in croakOfFrogs:
            index = stages[char]
            if index == 0:
                counts[0] += 1
            else:
                if counts[index - 1] == 0:
                    return -1
                counts[index - 1] -= 1
                counts[index] += 1

            current_frogs = sum(counts[:4])
            max_frogs = max(max_frogs, current_frogs)

        if any(counts[:4]):
            return -1
        return max_frogs
```该实现使用固定数组`counts`追踪每个呱呱叫声阶段的青蛙数量。 每个角色要么推进一只青蛙，要么开始一只新的青蛙。 通过对阶段计数求和来跟踪同时进行的青蛙的最大数量`'c'`通过`'a'`。 该函数通过确保所有的嘎嘎声都正确完成来验证输入。 

## 解决方案```go
func minNumberOfFrogs(croakOfFrogs string) int {
    stages := map[rune]int{'c': 0, 'r': 1, 'o': 2, 'a': 3, 'k': 4}
    counts := [5]int{}
    maxFrogs := 0

    for _, char := range croakOfFrogs {
        index := stages[char]
        if index == 0 {
            counts[0]++
        } else {
            if counts[index-1] == 0 {
                return -1
            }
            counts[index-1]--
            counts[index]++
        }

        currentFrogs := counts[0] + counts[1] + counts[2] + counts[3]
        if currentFrogs > maxFrogs {
            maxFrogs = currentFrogs
        }
    }

    for i := 0; i < 4; i++ {
        if counts[i] != 0 {
            return -1
        }
    }
    return maxFrogs
}
```Go 的实现与 Python 版本非常相似。 差异包括使用`rune`用于字符和固定大小的数组用于计数。 索引映射使用映射将字符转换为阶段索引。 所有边缘情况的处理方式都是相同的。
