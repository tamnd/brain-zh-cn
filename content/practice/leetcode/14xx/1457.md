[LeetCode 问题 1457](https://leetcode.com/problems/pseudo-palindromic-paths-in-a-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 位操作、树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算二叉树中有多少根到叶路径是“伪回文”。 

回文是向前和向后读取相同的序列。 例如，`[1,2,1]`和`[3,4,4,3]`是回文。 回文的重要属性是最多一个值可能出现奇数次。 每个其他值必须出现偶数次。 

如果路径的值可以重新排列成回文，则该路径被视为伪回文。 我们不关心路径上值的原始顺序。 我们只关心每个数字出现的频率。 

该树包含来自的数字`1`到`9`。 从根开始，我们向下移动，直到到达叶节点。 对于每个这样的根到叶路径，我们必须确定值的多重集是否可以形成回文。 如果是，我们增加答案。 

输入是标准二叉树。 每个节点有：

 - 介于之间的值`1`和`9`- 一个左孩子
 - 一个正确的孩子

 输出是一个整数，表示伪回文根到叶路径的数量。 

约束条件很重要：

 - 该树最多可以包含`10^5`节点
 - 节点值仅限于数字`1`通过`9`大量的节点数告诉我们，昂贵的每路径操作可能会太慢。 然而，只有九个可能数字的小值范围强烈表明紧凑的频率跟踪或位操作可能是有用的。 

有几个边缘情况值得注意。 

只有一个节点的树始终是伪回文树，因为单个字符回文是有效的。 在某些语言中，极深的树可能会导致递归深度问题。 应正确拒绝具有许多不同奇数频率的路径。 像链表这样倾斜的树仍然必须有效地处理。 

## 方法

 ### 蛮力方法

 最直接的方法是使用深度优先搜索来探索每条从根到叶的路径。 

对于每条路径，我们将所有节点值存储在列表中。 一旦到达叶节点，我们就使用哈希图或数组计算每个数字的频率。 然后我们计算有多少个数字出现奇数次。 

如果奇数频率的数量最多为 1，则该路径是伪回文，因此我们增加答案。 

这种方法是正确的，因为它根据问题定义显式评估每个根到叶路径。 

然而，它的效率很低。 如果树的高度很大，则重复复制和扫描路径数组会变得昂贵。 在最坏的情况下，每片叶子都需要扫描一条长度的路径`O(H)`， 在哪里`H`是树的高度。 

高达`10^5`节点，我们需要更高效的东西。 

### 关键见解

 当且仅当至多一位数字具有奇数频率时，路径才能形成回文。 

我们不需要存储完整的频率，而只需要知道每个数字当前出现的次数是偶数还是奇数。 

这非常适合位操作。 

我们使用整数位掩码，其中：

 - 位`i`代表是否为数字`i`目前出现奇数次
 -`0`表示偶数
 -`1`表示奇数计数

 每当我们访问一个数字时，我们都会使用异或来切换它的位。 

例如：

 - 访问数字`3`切换位`3`- 访问数字`3`再次将其切换回来

 在叶节点：

 - 如果掩码包含零个或一组位，则该路径是伪回文

 如果满足以下条件，则一个数最多有一个设置位：```
mask & (mask - 1) == 0
```这使得叶子检查非常高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N × H) | O(H) | 存储完整路径并重新计算频率 |
 | 最佳 | O(N) | O(H) | 在 DFS 期间使用位掩码奇偶校验跟踪 |

 这里：

-`N`是节点数
 -`H`是树的高度

 ## 算法演练

 1. 从根节点开始深度优先遍历。 
2. 维护表示沿当前路径的数字频率奇偶性的位掩码。 
3、访问有值的节点时`v`, 切换位`v`:```
mask ^= (1 << v)
```这改变了数字的奇偶校验`v`。 

1. 继续递归到左子树和右子树，同时传递更新的掩码。 
2. 当到达叶子节点时，检查当前掩码是否最多包含一个设置位。```
mask & (mask - 1) == 0
```这是有效的，因为：

 -`0`没有设置位
 - 2 的幂恰好有一个设置位

 1. 如果条件为真，则增加答案。 
2. 继续遍历，直到处理完所有根到叶路径。 

### 为什么它有效

 该算法保持一个不变量：

 > 在每个节点，位掩码准确地表示哪些数字当前沿着根到当前节点的路径具有奇数频率。 

如果至多一位数字的计数为奇数，则路径可以形成回文。 因此，通过检查掩码是否最多有一个设置位来正确确定该路径是否是伪回文。 

由于每个节点都被访问一次并且奇偶校验更新的时间恒定，因此该算法既正确又高效。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def pseudoPalindromicPaths(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode], mask: int) -> int:
            if not node:
                return 0

            # Toggle the bit corresponding to node.val
            mask ^= (1 << node.val)

            # Check if this is a leaf node
            if not node.left and not node.right:
                # At most one bit set
                return 1 if (mask & (mask - 1)) == 0 else 0

            return dfs(node.left, mask) + dfs(node.right, mask)

        return dfs(root, 0)
```该解决方案使用递归深度优先搜索。 

这`mask`整数存储当前路径上遇到的数字的奇偶校验信息。 每一位对应一个数字值。 

当我们访问一个节点时，我们使用 XOR 来切换其相应的位。 这可以有效地跟踪数字出现的次数是奇数还是偶数。 

在叶节点，我们应用标准位技巧：```python
mask & (mask - 1)
```如果结果为零，则掩码最多包含一组位，这意味着最多一位数字具有奇数频率。 在这种情况下，该路径可以形成回文。 

递归自然地探索所有从根到叶的路径，同时有效地维护路径状态。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func pseudoPalindromicPaths(root *TreeNode) int {
    var dfs func(node *TreeNode, mask int) int

    dfs = func(node *TreeNode, mask int) int {
        if node == nil {
            return 0
        }

        // Toggle parity bit
        mask ^= (1 << node.Val)

        // Leaf node
        if node.Left == nil && node.Right == nil {
            if (mask & (mask - 1)) == 0 {
                return 1
            }
            return 0
        }

        return dfs(node.Left, mask) + dfs(node.Right, mask)
    }

    return dfs(root, 0)
}
```Go 的实现与 Python 版本非常相似。 

Go 使用`nil`检查而不是 Python 的真实性检查。 递归助手是使用函数变量声明的，因为 Go 需要命名递归闭包。 

整数溢出不是问题，因为只有位`1`通过`9`被使用。

 ## 边缘情况

 ### 单节点树

 仅包含一个节点的树始终是伪回文树，因为单个值本身形成回文。 

如果实现错误地要求零奇数频率而不是允许一个奇数频率，则这种情况可能会暴露错误。 

该实现自然地处理了这个问题，因为单个设置位通过了条件：```
mask & (mask - 1) == 0
```### 完全倾斜的树

 一棵树的行为可能类似于链表，其中每个节点只有一个子节点。 

这会创建最大递归深度并测试算法是否在没有分支假设的情况下仍然正确处理路径。 

DFS 实现可以正常工作，因为它只是遵循现有的子指针，直到到达叶子。 

### 具有多个奇数频率的路径

 像这样的路径`[1,2,3]`不能形成回文，因为所有三个数字出现的次数均为奇数。 

幼稚的实现有时会错误地仅检查路径长度是奇数还是偶数。 

位掩码方法通过独立跟踪每个数字的精确奇偶校验信息来避免这种错误。 如果叶上保留设置了不止一位，则该路径将被拒绝。
