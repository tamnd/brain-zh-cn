[LeetCode 问题 1479](https://leetcode.com/problems/sales-by-day-of-the-week/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们生成一份销售报告，总结一周中每一天每个类别的销售总量。 数据在两个表中提供：`Orders`和`Items`。 这`Orders`表包含交易信息，包括哪个客户购买了哪些商品、数量以及日期。 这`Items`表将每个项目映射到其类别和名称。 目标是生成一个表，其中每行对应一个类别，每列对应一周中的一天（`Monday`通过`Sunday`），显示当天该类别的总销量。 

输出必须按类别排序，没有销售的天数应显示为零。 值得注意的是，即使某个类别没有订单，它仍然必须全天出现在输出中且为零。 该问题突出显示，输入表可能包含从未订购的项目，这些项目仍应是最终报告的一部分。 

关键点和限制：

 - 星期几源自`order_date`。 
- 没有订单的类别仍必须包含在内。 
- 每个`(order_id, item_id)`对是唯一的`Orders`。 
- 数据库可以包含同一天同一类别的多个订单，因此对数量求和至关重要。 
- SQL 函数如`DAYOFWEEK`或者`DATE_FORMAT`可能因数据库而异，但逻辑保持一致。 

重要的边缘情况包括没有订单的类别、同一类别中不同商品的同一天订单以及根本没有订单的稀疏日期。 

## 方法

 蛮力方法是迭代每个类别，并针对一周中的每一天查询来自类别的数量总和。`Orders`桌子。 这种方法是正确的，但效率很低，因为它需要与类别数乘以 7 天成比例的多次查询。 

最佳的方法是加入`Orders`表与`Items`桌上`item_id`，提取每个订单的星期几，按类别和日期对结果进行分组，并对聚合数量进行透视，以便每一天都成为一列。 这种方法非常高效，因为它使用单个聚合查询并利用 SQL`GROUP BY`和条件聚合一次性生成数据透视表。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(C * D * O) | O(C * D) | 单独查询每个类别和日期； 对于大型数据集效率低下 |
 | 最佳 | O(O + C) | O(C * D) | 在一个查询中加入并聚合，然后进行透视； 高效|

 在哪里`C`是类别数，`D`是 7（一周中的几天），并且`O`是订单数量。 

## 算法演练

 1. 加入`Orders`表与`Items`桌上`item_id`将每个订单与其商品类别相关联。 这确保我们可以按类别进行聚合。 
2. 使用 SQL 函数从其中提取星期几`order_date`。 确切的功能可能会有所不同（`DAYOFWEEK`在MySQL中，`TO_CHAR`在 PostgreSQL 中）。 
3. 对连接表进行分组`item_category`和星期几，总结`quantity`列以获取每天每个类别的总销售额。 
4. 对分组数据进行透视，使一周中的每一天都成为一列。 这可以通过条件聚合来完成：仅当该天与特定日期匹配时才对数量求和。 
5. 确保所有类别都出现在最终结果中。 如果某个类别一天没有销售额，则总和应默认为零。 
6. 按类别对最终结果进行排序。 

原理：通过将订单与其类别连接起来，对按类别和日期分组的数量进行求和，然后进行透视，我们保证每个类别都会获得一行包含所有日期的数据。 当类别-天对不存在订单时，总和默认为零，满足问题约束。 

## Python 解决方案```python
class Solution:
    def salesByDayOfWeek(self, orders: 'List[Dict]', items: 'List[Dict]') -> 'List[Dict]':
        import pandas as pd

        # Convert lists of dicts into DataFrames
        orders_df = pd.DataFrame(orders)
        items_df = pd.DataFrame(items)

        # Merge orders with items to get categories
        merged_df = orders_df.merge(items_df, on='item_id', how='right')

        # Fill missing quantities with 0
        merged_df['quantity'] = merged_df['quantity'].fillna(0)

        # Extract day name from order_date
        merged_df['day_of_week'] = pd.to_datetime(merged_df['order_date']).dt.day_name()

        # Define all days to ensure all columns are present
        days = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday']

        # Group by category and day, sum quantities
        pivot_df = merged_df.pivot_table(index='item_category',
                                         columns='day_of_week',
                                         values='quantity',
                                         aggfunc='sum',
                                         fill_value=0).reindex(columns=days, fill_value=0).reset_index()

        # Rename index column to 'Category'
        pivot_df.rename(columns={'item_category': 'Category'}, inplace=True)

        return pivot_df.to_dict('records')
```该代码首先将订单与商品类别合并，然后进行转换`order_date`进入工作日名称。 它使用数据透视表，对每个类别每天的数量进行求和，用零填充缺失值。 栏目按周一至周日排序，也包括没有排序的类别。 

## 解决方案```go
package main

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

func SalesByDayOfWeek(db *sql.DB) (*sql.Rows, error) {
    query := `
        SELECT
            i.item_category AS Category,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 2 THEN o.quantity ELSE 0 END) AS Monday,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 3 THEN o.quantity ELSE 0 END) AS Tuesday,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 4 THEN o.quantity ELSE 0 END) AS Wednesday,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 5 THEN o.quantity ELSE 0 END) AS Thursday,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 6 THEN o.quantity ELSE 0 END) AS Friday,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 7 THEN o.quantity ELSE 0 END) AS Saturday,
            SUM(CASE WHEN DAYOFWEEK(o.order_date) = 1 THEN o.quantity ELSE 0 END) AS Sunday
        FROM Items i
        LEFT JOIN Orders o ON i.item_id = o.item_id
        GROUP BY i.item_category
        ORDER BY i.item_category
    `
    return db.Query(query)
}
```在 Go 中，解决方案直接使用 SQL`database/sql`。 这`DAYOFWEEK`函数将从星期日开始的天数映射为 1，因此情况会相应调整。 左连接可确保包含所有类别，即使没有订单也是如此。
