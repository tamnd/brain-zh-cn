[LeetCode 问题 1420](https://leetcode.com/problems/build-array-where-you-can-find-the-maximum-exactly-k-comparisons/)

 **难度：** 🔴难
 **主题：** 动态规划、前缀和

 ## 解决方案

 ## 问题理解

 这道题要求我们统计长度数组的个数`n`其中每个元素之间`1`和`m`包含在内，查找最大元素的“搜索成本”恰好是`k`。 搜索成本定义为从左到右迭代数组时找到新最大值的次数。 

换句话说，我们被要求生成数组并跟踪当前最大值增加的次数。 输入由三个整数组成：`n`是数组长度，`m`是元素可以取的最大值，并且`k`是最大值应该增加的确切次数。 输出是满足这些条件的数组的计数，模`10^9 + 7`。 

约束表明`n`最多 50 并且`m`最大为 100。这表明暴力生成所有可能的数组是不可行的，因为数组的总数为`m^n`，这可能是一个天文数字。 边缘情况包括`k = 0`（不可能，如果`n > 0`),`m = 1`（所有元素必须为 1），并且`k > n`（不可能的）。 

## 方法

 暴力方法会尝试生成所有可能的长度数组`n`有价值观`1`到`m`，计算每个的搜索成本，并计算搜索成本等于的那些`k`。 虽然这种方法很简单，但速度太慢：生成`m^n`数组对于上限不可行`n`和`m`。 

最佳方法的关键见解是认识到可以使用动态规划来解决该问题。 状态可以定义为`dp[i][j][c]`表示长度的数组的数量`i`具有最大值`j`和搜索成本`c`。 对于每个数组位置，我们可以选择一个小于或等于当前最大值的值（这不会增加搜索成本），也可以选择一个大于当前最大值的值（这会使搜索成本增加 1）。 使用这个 DP 公式，我们可以有效地计算所有有效数组，而无需显式生成它们。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(m^n) | O(m^n) | O(1) | O(1) | 生成所有数组，检查搜索成本，对于大 n 和 m 不可行 |
 | 最优 (DP) | O(n * m * k) | O(n * m * k) | O(n * m * k) | O(n * m * k) | 对数组长度、最大值和成本进行动态规划； 给定约束条件下可行|

 ## 算法演练

 1.定义3D DP数组`dp[i][j][c]`表示长度的数组的数量`i`，最大值`j`，以及搜索成本`c`。 
2. 初始化基本情况：对于长度为1的数组，`dp[1][j][1] = 1`为所有人`1 <= j <= m`因为单个元素数组的搜索成本为 1。 
3. 迭代长度`i`从 2 到`n`。 
4. 对于每个长度`i`，迭代所有可能的最大值`j`从 1 到`m`。 
5. 对于每个搜索成本`c`从 1 到`k`:

 1. 添加下一个元素小于或等于当前最大值的数组的贡献`j`。 在这种情况下，搜索成本不会增加。 这增加了`dp[i-1][j][c] * j`因为有`j`新元素的选择。 
2. 添加下一个元素大于当前最大值的数组的贡献。 在这种情况下，搜索成本增加 1。对于每个`p`少于`j`， 添加`dp[i-1][p][c-1]`。 
6.填写完DP表后，求和`dp[n][j][k]`全面的`1 <= j <= m`获取有效数组的总数。 
7. 返回模数结果`10^9 + 7`。 

**为什么有效**：DP 通过一次构建一个元素来正确地对数组进行计数，并将当前最大值和搜索成本保持为状态。 每次转换要么增加搜索成本，要么保持相同，确保所有有效数组都被精确计数一次。 

## Python 解决方案```python
class Solution:
    def numOfArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7
        
        dp = [[[0] * (k+1) for _ in range(m+1)] for _ in range(n+1)]
        
        for j in range(1, m+1):
            dp[1][j][1] = 1
        
        for i in range(2, n+1):
            for j in range(1, m+1):
                for c in range(1, k+1):
                    # Case 1: adding element <= current max j
                    dp[i][j][c] += dp[i-1][j][c] * j
                    dp[i][j][c] %= MOD
                    # Case 2: adding element > current max
                    for p in range(1, j):
                        dp[i][j][c] += dp[i-1][p][c-1]
                        dp[i][j][c] %= MOD
        
        result = sum(dp[n][j][k] for j in range(1, m+1)) % MOD
        return result
```该代码初始化 3D DP 数组并根据上述规则填充它。 对于每个长度、最大值和成本，它都会对维持当前最大值或增加当前最大值的数组进行计数。 模运算确保值不会溢出。 

## 解决方案```go
func numOfArrays(n int, m int, k int) int {
    const MOD int = 1e9 + 7
    dp := make([][][]int, n+1)
    for i := range dp {
        dp[i] = make([][]int, m+1)
        for j := range dp[i] {
            dp[i][j] = make([]int, k+1)
        }
    }
    
    for j := 1; j <= m; j++ {
        dp[1][j][1] = 1
    }
    
    for i := 2; i <= n; i++ {
        for j := 1; j <= m; j++ {
            for c := 1; c <= k; c++ {
                dp[i][j][c] = (dp[i-1][j][c] * j) % MOD
                for p := 1; p < j; p++ {
                    dp[i][j][c] = (dp[i][j][c] + dp[i-1][p][c-1]) % MOD
                }
            }
        }
    }
    
    result := 0
    for j := 1; j <= m; j++ {
        result = (result + dp[n][j][k]) % MOD
    }
    return result
}
```Go 明确地处理切片，因此 3D DP 数组是使用嵌套切片构建的。 模运算可确保结果不会溢出 32 位整数。 

## 工作示例

 **示例1：**`n = 2, m = 3, k = 1`初始化`dp[1][j][1] = 1`对于 j=1,2,3。 

长度 2，成本 1：

 - j=1：可以加1（<=1），`dp[2][1][1] = dp[1][1][1] * 1 = 1`- j=2：添加 <=2 → 1,2； 添加 > 上一个最大值 1 → dp[2][2][1] = 1*2 + dp[1][1][0] = 2
 - j=3：类似的逻辑

 总和`dp[2][1][1] + dp[2][2][1] + dp[2][3][1] = 6`**示例2：**`n=5, m=2, k=3`→ DP 永远不会达到成本 3、结果 0。 

**示例3：**`n=9, m=1, k=1`→ 只有数组全为 1，结果为 1。
