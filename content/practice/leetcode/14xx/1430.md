[LeetCode 问题 1430](https://leetcode.com/problems/check-if-a-string-is-a-valid-sequence-from-root-to-leaves-path-in-a-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的整数数组是否`arr`表示二叉树中从根到叶的有效序列。 树中的每个节点都有一个介于 0 和 9 之间的值，有效序列定义为从根节点开始到任何叶节点的路径，使得沿该路径的节点值的串联与数组匹配`arr`。 

输入由根节点表示的二叉树和整数数组组成`arr`。 输出是一个布尔值：`true`如果`arr`对应于树中有效的根到叶序列，并且`false`否则。 

约束告诉我们数组长度最多为 5000，并且每个节点值都是单个数字，因此树可能很大，但节点值是有界的。 边缘情况包括比任何根到叶路径更长的序列、匹配路径的一部分但不以叶结束的序列以及空树或数组。 

需要注意的要点：

 1. 仅**根到叶**路径计数。 与非叶节点匹配的序列无效。 
2. 序列的长度必须与路径的深度匹配。 
3. 节点值和数组元素为数字0-9。 

## 方法

 暴力方法将涉及生成树中所有从根到叶的路径，将每个路径转换为序列，并将其与`arr`。 这是有效的，因为它会检查每种可能性，但效率很低，因为路径的数量随着树的高度呈指数增长。 

更好的解决方案的关键在于我们不需要生成所有路径。 相反，我们可以**递归地遍历树**并将每个节点的值与中的相应元素进行比较`arr`。 如果当前节点的值与当前数组元素不匹配，我们可以停止遍历该路径。 如果我们到达一片叶子并且最后一个元素`arr`与叶子匹配，我们找到了一个有效的序列。 这种方法使用深度优先搜索，并且非常高效，因为它会在发生不匹配时尽早修剪路径。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^h * h) | O(2^h * h) | O(h) | 生成所有路径并进行比较； h 是树高 |
 | 最佳| O(n) | O(h) | 带剪枝的 DFS； n 是节点数，h 是树高 |

 ## 算法演练

 1.从根节点和第一个元素开始`arr`。 
2. 如果当前节点是`null`， 返回`false`因为这条路无法继续。 
3. 将节点的值与当前元素进行比较`arr`。 如果不匹配，则返回`false`。 
4. 如果当前节点是叶子节点（没有左子节点或右子节点）并且索引位于最后一个元素`arr`， 返回`true`。 
5. 递归调用左孩子和下一个元素的函数`arr`。 
6. 递归调用右孩子和下一个元素的函数`arr`。 
7. 返回`true`如果左或右递归调用返回`true`。 

为什么它起作用：递归保持了不变式，即路径上的每个节点必须与中的相应元素匹配`arr`。 早期修剪可确保效率，检查叶节点可保证只有完整的根到叶路径才被认为是有效的。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional, List

class Solution:
    def isValidSequence(self, root: Optional[TreeNode], arr: List[int]) -> bool:
        def dfs(node: Optional[TreeNode], index: int) -> bool:
            if not node:
                return False
            if index >= len(arr) or node.val != arr[index]:
                return False
            if not node.left and not node.right and index == len(arr) - 1:
                return True
            return dfs(node.left, index + 1) or dfs(node.right, index + 1)
        
        return dfs(root, 0)
```Python 实现使用辅助函数`dfs`有两个参数：当前节点和当前索引`arr`。 它首先处理空节点和不匹配的基本情况。 然后它检查当前节点是否是叶子并且最后一个元素是否匹配，返回`true`如果是这样。 否则，它递归地检查两个子节点。 这确保了所有路径都得到有效探索。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isValidSequence(root *TreeNode, arr []int) bool {
    var dfs func(node *TreeNode, index int) bool
    dfs = func(node *TreeNode, index int) bool {
        if node == nil {
            return false
        }
        if index >= len(arr) || node.Val != arr[index] {
            return false
        }
        if node.Left == nil && node.Right == nil && index == len(arr)-1 {
            return true
        }
        return dfs(node.Left, index+1) || dfs(node.Right, index+1)
    }
    
    return dfs(root, 0)
}
```Go 解决方案反映了 Python 解决方案。 主要区别是子节点的显式 nil 检查和递归辅助函数的闭包语法。 切片索引和比较遵循与 Python 相同的逻辑。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点都被访问一次，早期修剪可确保跳过不必要的路径 |
 | 空间| O(h) | 递归栈深度对应树高h |

 该算法仅有效地探索相关路径，因此整体复杂度与节点数量呈线性关系。 由于递归，空间复杂度与高度成正比。
