[LeetCode 1451 题](https://leetcode.com/problems/rearrange-words-in-a-sentence/)

 **难度：** 🟡 中等
 **主题：** 字符串、排序

 ## 解决方案

 ## 问题理解

 该问题给出了一个句子，其中单词由单个空格分隔，句子的第一个字符是大写的，所有其余字符都是小写的。 我们必须重新排列单词，使它们按照单词长度递增的顺序出现。 

如果两个单词具有相同的长度，我们必须保留它们在输入句子中的原始相对顺序。 这个要求很重要，因为它意味着排序必须表现稳定。 我们不能随意对等长单词进行重新排序。 

重新排列单词后，输出句子仍必须遵循相同的格式规则：

 - 第一个单词必须以大写字母开头。 
- 所有剩余字母必须为小写。 

换句话说，我们需要对句子进行规范化，在保留联系的同时按长度对单词进行排序，然后以适当的大写形式重建句子。 

例如，考虑：```
"Keep calm and code on"
```字长为：

 | 词| 长度 |
 | ---| ---|
 | 保留| 4 |
 | 冷静| 4 |
 | 和| 3 |
 | 代码| 4 |
 | 上 | 2 |

 按长度排序后，同时保留等长单词之间的原始顺序：```
on and keep calm code
```然后我们将第一个字符大写：```
"On and keep calm code"
```约束条件允许句子长度达到`10^5`，这意味着我们应该避免不必要的昂贵操作。 解决方案与`O(n log n)`复杂性是完全可以接受的，因为排序在运行时占主导地位。 对于大输入来说，二次方法可能会变得太慢。 

一些边缘情况很重要：

 - 只包含一个单词的句子。 
- 多个单词具有相同的长度。 
- 非常简短的单词，例如`"a"`或者`"i"`。 
- 第一个单词在重新排序的句子中变得很晚的情况。 
- 效率至关重要的大量投入。 

该问题保证：

 - 单词之间恰好间隔一个空格。 
- 句子的第一个字母是大写的。 
- 所有其他字母均为小写。 

由于这些保证，解析变得简单。 

## 方法

 ### 蛮力方法

 暴力策略会重复搜索最短的未使用单词并将其附加到结果中。 我们可以每次扫描所有剩余的单词，找到尚未被选择的最小长度单词。 

例如：

 1. 找到最短的未使用单词。 
2. 将其附加到答案中。 
3. 将其标记为已使用。 
4. 重复，直到处理完所有单词。 

这是有效的，因为每次迭代都会按排序顺序选择下一个正确的单词。 然而，每次选择都需要扫描剩余的单词，从而导致二次复杂度。 

如果有`k`单词，每个选择最多可以扫描`k`的话，大致给出：```
O(k^2)
```如果输入量很大，这就会变得低效。 

### 最佳方法

 关键的观察结果是，该问题本质上是一个稳定的排序问题。 

我们可以：

 1. 将整个句子转换为小写。 
2. 将句子拆分为单词。 
3. 按字长进行稳定排序。 
4. 将最后一句话的第一个字符大写。 

现代排序实现高效且稳定。 Python 的内置`sort()`是稳定的，Go 的`sort.SliceStable()`保留相等键的相对顺序。 

由于排序在工作中占主导地位，因此复杂性变为：```
O(k log k)
```这对于给定的约束是有效的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k²) | O(k) | 反复扫描剩余单词以找到最短的 |
 | 最佳| O(k log k) | O(k log k) | O(k) | 使用按字长进行稳定排序 |

 这里，`k`代表句子中的单词数。 

## 算法演练

 1. 将整个句子转换为小写。 

这简化了以后的大写处理。 由于最终输出只要求整个句子的第一个字母为大写，因此首先将所有内容转换为小写可以保证格式一致。 
2. 将句子拆分为单词列表。 

由于输入保证单词之间有单个空格，因此正常的拆分操作可以干净地提取每个单词。 
3. 以字长为排序关键字进行稳定排序。 

排序基于比较单词`len(word)`。 稳定性很重要，因为相等长度的单词必须保持其原始顺序。 
4. 将排序后的单词重新连接成句子。 

排序后，我们使用空格重构句子。 
5. 将结果句子的第一个字符大写。 

该问题要求最后的句子以大写字母开头。 由于其他所有内容都已经是小写，因此将第一个字符大写即可完成格式化。 

### 为什么它有效

 该算法之所以有效，是因为稳定排序保证了相同长度的单词保持其原始顺序。 按单词长度排序可确保单词按大小递增顺序显示。 首先将句子转换为小写，然后仅将第一个字符大写，以保证所需的输出格式。 

## Python 解决方案```python
class Solution:
    def arrangeWords(self, text: str) -> str:
        words = text.lower().split()

        words.sort(key=len)

        result = " ".join(words)

        return result.capitalize()
```实现首先将句子转换为小写并将其拆分为单独的单词。```python
words = text.lower().split()
```这保证了肠衣的均匀性并简化了后续加工。 

接下来，单词按长度排序：```python
words.sort(key=len)
```Python 内置的排序算法是稳定的，这意味着长度相同的单词会自动保留其原始顺序。 

排序后，单词会重新连接成句子：```python
result = " ".join(words)
```最后，第一个字符大写：```python
return result.capitalize()
```由于整个句子之前已转换为小写，因此这会产生完全所需的格式。 

## 解决方案```go
package main

import (
	"sort"
	"strings"
)

func arrangeWords(text string) string {
	words := strings.Fields(strings.ToLower(text))

	sort.SliceStable(words, func(i, j int) bool {
		return len(words[i]) < len(words[j])
	})

	result := strings.Join(words, " ")

	return strings.ToUpper(result[:1]) + result[1:]
}
```Go 实现遵循与 Python 版本相同的总体策略。 

Go 不提供使用键对切片进行直接稳定排序，因此我们使用：```go
sort.SliceStable(...)
```这保留了等长单词的相对顺序。 

字符串大小写是手动处理的，因为 Go 字符串是不可变的，并且没有与 Python 直接等效的字符串`capitalize()`完全符合所需的行为。 

输入保证句子至少包含一个字符，因此访问`result[:1]`是安全的。

 ## 边缘情况

 一个重要的边缘情况是只包含一个单词的句子。 粗心的实现可能会错误地修改大小写或尝试不必要的排序逻辑。 在此实现中，拆分生成一个单元素列表，排序使其保持不变，而大写则保留正确的格式。 

当许多单词具有相同的长度时，会发生另一个重要的情况。 该问题特别需要保持等长单词的原始相对顺序。 不稳定的排序算法可能会错误地对这些单词进行重新排序。 使用Python的稳定版`sort()`和Go的`sort.SliceStable()`保证正确的行为。 

第三个边缘情况涉及大写处理。 由于输入以大写字母开头，因此未经标准化直接排序可能会在句子中间产生不正确的大小写。 通过首先将整个句子转换为小写并仅将末尾的第一个字符大写，无论单词如何重新排列，该实现都能保证格式一致。
