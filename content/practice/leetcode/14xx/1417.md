[LeetCode 问题 1417](https://leetcode.com/problems/reformat-the-string/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 问题给了我们一个字母数字字符串`s`仅包含小写英文字母和数字。 我们的任务是重新排列字符，使两个相邻的字符不属于同一类别。 换句话说，每个字母必须紧邻一个数字，每个数字也必须紧邻一个字母。 

重要的细节是我们可以返回字符串的任何有效排列。 我们不需要保留字符的原始顺序。 如果存在多个有效答案，则其中任何一个都可以接受。 

例如，如果输入是`"a0b1c2"`，我们可以将其重新排列为`"a0b1c2"`,`"0a1b2c"`，或许多其他有效的交替模式。 但是，如果输入仅包含字母或仅包含数字，则无法替换字符类型，因此我们必须返回空字符串。 

输入长度最多为 500，这个长度足够小，以至于许多方法在技术上都可以运行得足够快。 尽管如此，我们的目标是设计一个干净高效的解决方案，而不是依赖昂贵的强力排列生成。 

关键的观察结果是字母和数字的计数决定了是否可以进行有效的排列。 如果字母和数字的数量之差大于1，则不可能交替。 例如：

-`"abcde1"`有5个字母和1个数字，不可能
 -`"ab12"`有 2 个字母和 2 个数字，可能
 -`"abc12"`有 3 个字母和 2 个数字，可能

 一些边缘情况很重要：

 - 仅包含字母的字符串
 - 仅包含数字的字符串
 - 字母比数字多一个的字符串
 - 数字比字母恰好多一位的字符串
 - 长度为 1 的字符串
 - 字符已经交替的输入
 - 需要重新排序的输入

 该问题保证字符串只包含小写字母和数字，因此我们不需要处理大写字母、空格或特殊符号。 

## 方法

 ### 蛮力方法

 强力解决方案将生成字符串的所有可能的排列，并检查相邻字符是否在字母和数字之间交替。 

该算法的工作原理如下：

 1. 生成输入字符串的所有排列。 
2. 对于每个排列，从左到右扫描。 
3. 验证每个相邻对是否包含不同的字符类型。 
4. 返回找到的第一个有效排列。 
5. 如果都不起作用，则返回空字符串。 

这种方法是正确的，因为它详尽地检查了每种可能的排列，因此如果存在有效答案，它最终会找到一个。 

然而，这种方法效率极低。 一个长度的字符串`n`有`n!`排列。 即使与`n = 10`，这变得太大了。 由于限制最多允许 500 个字符，因此暴力破解是完全不切实际的。 

### 最佳方法

 关键的见解是我们不需要随机探索排列。 我们只需要在两组之间交替：

 - 信件
 - 数字

 如果计数相差超过 1，则不可能进行有效的排列，因为一个类别将不可避免地连续出现在字符串中的某处。 

否则，我们可以：

 1. 将字母和数字分成两个列表。 
2. 从角色较多的一组开始。 
3. 交替两组字符，直到结果完成。 

这是有效的，因为贪婪地交替保证没有两个相邻的字符共享相同的类型。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n! × n) | O(n! × n) | O(n!) | 生成每个排列并检查有效性 |
 | 最佳 | O(n) | O(n) | 分隔字符并交替它们 |

 ## 算法演练

 ### 第 1 步：区分字母和数字

 遍历字符串一次并将每个字符放入两个列表之一：

 -`letters`-`digits`我们使用两个列表是因为我们稍后需要在两个类别之间有效地交替。 

### 步骤 2：检查解决方案是否可行

 计算字母和数字数量之间的绝对差。 

如果：```
abs(len(letters) - len(digits)) > 1
```然后立即返回一个空字符串。 

这个条件是必要的，因为交替需要计数保持平衡。 如果一个类别超过另一类别超过一类，则同一类型的两个相邻字符将不可避免。 

### 第 3 步：决定首先启动哪个类别

 具有更多字符的组必须在交替序列中首先出现。 

例如：

 - 3 个字母和 2 个数字 → 以字母开头
 - 4 位数字和 3 个字母 → 以数字开头

 如果计数相等，则任何一组都可以开始。 

### 步骤 4：构建结果字符串

 创建一个空结果列表。 

反复：

 1. 添加第一组中的一个字符。 
2. 附加第二组中的一个字符（如果有）。 

继续，直到两组都精疲力尽。 

使用列表是高效的，因为在某些语言中重复的字符串连接可能会代价高昂。 

###第五步：转换并返回

 将结果列表连接成字符串并返回。 

### 为什么它有效

 该算法在整个构建过程中保持严格的交替模式。 在每一步中，字符都取自相反的类别，因此相邻字符的类型始终不同。 

可行性检查保证了较大类别永远不会耗尽有效位置。 由于尺寸差异至多为一，因此交替排列总能成功完成。 

## Python 解决方案```python
class Solution:
    def reformat(self, s: str) -> str:
        letters = []
        digits = []

        for char in s:
            if char.isdigit():
                digits.append(char)
            else:
                letters.append(char)

        if abs(len(letters) - len(digits)) > 1:
            return ""

        # Ensure letters is the larger or equal group
        if len(digits) > len(letters):
            letters, digits = digits, letters

        result = []

        for i in range(len(letters)):
            result.append(letters[i])

            if i < len(digits):
                result.append(digits[i])

        return "".join(result)
```该实现首先根据字符是数字还是字母将字符分成两个列表。 此预处理步骤使后续的交替变得简单。 

接下来，代码检查有效的排列在数学上是否可行。 如果大小差异超过一，该函数立即返回一个空字符串。 

交换步骤很重要，因为它保证较大的组始终存储在`letters`。 尽管有变量名称，但交换后它实际上可能包含数字。 目的只是确保第一个列表永远不会短于第二个列表。 

结果是增量构建的。 对于较大组中的每个字符，算法会在可用时附加较小组中的一个字符。 由于较大的组的大小最多相差一个，因此此过程始终会产生有效的交替排列。 

最后，该列表被连接成单个字符串并返回。 

## 解决方案```go
func reformat(s string) string {
    letters := []byte{}
    digits := []byte{}

    for i := 0; i < len(s); i++ {
        ch := s[i]

        if ch >= '0' && ch <= '9' {
            digits = append(digits, ch)
        } else {
            letters = append(letters, ch)
        }
    }

    if abs(len(letters)-len(digits)) > 1 {
        return ""
    }

    // Ensure letters is the larger or equal group
    if len(digits) > len(letters) {
        letters, digits = digits, letters
    }

    result := make([]byte, 0, len(s))

    for i := 0; i < len(letters); i++ {
        result = append(result, letters[i])

        if i < len(digits) {
            result = append(result, digits[i])
        }
    }

    return string(result)
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```Go 实现遵循与 Python 版本相同的算法结构。 一个区别是 Go 字符串是不可变的，因此解决方案使用`[]byte`切片以实现高效施工。 

字符分类是使用 ASCII 比较手动执行的，而不是像这样的辅助方法`isdigit()`。 

结果切片已预先分配容量`len(s)`以避免追加期间不必要的重新分配。

def is_valid(result: str) -> bool:
    for i in range(len(result) - 1):
        if result[i].isdigit() == result[i + 1].isdigit():
            return False
    return True

 ## 边缘情况

 ### 仅包含一种字符类型的字符串

 像这样的输入`"abcdef"`或者`"12345"`仅包含字母或仅包含数字。 幼稚的实现可能会尝试无论如何交替并产生无效的相邻对。 

该实现通过检查计数差异来处理此问题。 由于一组的大小为零，而另一组的大小大于 1，因此该算法正确返回空字符串。 

### 计数差异大于 1

 输入如`"abcd1"`有四个字母和一个数字。 即使重新排列后，至少有两个字母必须相邻。 

这是错误的常见来源，因为某些实现在没有首先验证可行性的情况下尝试贪婪放置。 显式计数检查可以立即防止此问题。 

### 单字符字符串

 输入如`"a"`或者`"5"`已经有效，因为根本没有相邻字符。 

某些实现错误地拒绝这些情况，因为完全缺少一个类别。 此处，计数之差恰好为 1，因此算法正确返回原始字符。
