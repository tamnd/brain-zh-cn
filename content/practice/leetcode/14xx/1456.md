[LeetCode 问题 1456](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

 **难度：** 🟡 中等
 **主题：** 字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定长度的任何子串中出现的元音的最大数量`k`在一个字符串内`s`。 输入字符串`s`仅由小写英文字母组成，并且`k`保证至少为 1 并且不大于字符串的长度。 元音被定义为字符`'a'`,`'e'`,`'i'`,`'o'`， 和`'u'`。 

预期输出是一个整数，表示任意长度的连续子串中存在的元音的最大数量`k`。 例如，如果`s = "abciiidef"`和`k = 3`，我们必须检查所有长度为 3 的子串：`"abc"`,`"bci"`,`"cii"`,`"iii"`,`"iid"`,`"ide"`,`"def"`，并发现`"iii"`包含最多元音，为 3 个。 

约束表明`s`可以长达 100,000 个字符，因此任何复杂度高于 O(n) 的算法都可能太慢。 边缘情况包括`k = 1`我们只检查单个字符，`k = len(s)`其中子串是整个字符串、没有元音的字符串以及完全由元音组成的字符串。 

## 方法

 ### 蛮力

 暴力方法涉及生成所有可能的长度子串`k`并计算每个子串中的元音。 这是有效的，因为它直接检查每个候选子串并比较元音计数以找到最大值。 但是，对于大字符串，生成所有长度的子字符串`k`计算每个元音的时间复杂度为 O(n*k)，当`n`最多可达 100,000。 

### 最优方法 - 滑动窗口

 关键的见解是该问题涉及固定长度的连续子串。 这表明采用滑动窗口方法。 我们可以在窗口移动时维护一个运行计数，而不是从头开始重新计算每个子字符串的元音数量：

 1. 从一个大小的窗口开始`k`在字符串的开头并计算它的元音。 
2、将窗口向右移动一个字符：减去离开窗口的字符的贡献，加上进入窗口的字符的贡献。 
3. 记录在此过程中看到的最大元音计数。 

这种方法将时间复杂度降低到 O(n)，因为每个字符最多被处理两次（一次进入窗口，一次离开）。 空间复杂度是 O(1)，因为我们只维护几个计数器。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n*k) | O(1) | O(1) | 计算长度为 k 的每个子串中的元音 |
 | 滑动窗| O(n) | O(1) | O(1) | 当窗口滑动时保持运行计数 |

 ## 算法演练

 1. 初始化一个包含所有元音的集合，用于 O(1) 成员资格检查。 
2. 初始化两个计数器：`current_vowels`当前窗口中元音的数量和`max_vowels`为观察到的最大值。 
3. 迭代第一个`k`字符并计算元音。 放`current_vowels`到这个值并初始化`max_vowels`。 
4. 滑动窗口浏览从索引开始的字符串`k`到`len(s) - 1`。 

一个。 如果字符离开窗口（在索引`i - k`) 是元音，减量`current_vowels`。 

b. 如果字符进入窗口（在索引`i`) 是元音，增量`current_vowels`。 

c. 更新`max_vowels`其自身的最大值和`current_vowels`。 
5.处理完所有窗口后，返回`max_vowels`。 

**为什么有效：** 滑动窗口保证每个长度的子串`k`只被考虑一次。 通过增量更新计数，我们避免了冗余计算，同时始终保持当前窗口中元音的正确计数。 

## Python 解决方案```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        current_vowels = sum(1 for c in s[:k] if c in vowels)
        max_vowels = current_vowels
        
        for i in range(k, len(s)):
            if s[i - k] in vowels:
                current_vowels -= 1
            if s[i] in vowels:
                current_vowels += 1
            max_vowels = max(max_vowels, current_vowels)
        
        return max_vowels
```该实现首先计算初始大小窗口中的元音数量`k`。 然后它迭代该字符串，根据离开和进入窗口的字符调整计数。 这`max_vowels`变量始终包含观察到的最大元音计数。 

## 解决方案```go
func maxVowels(s string, k int) int {
    vowels := map[byte]bool{'a': true, 'e': true, 'i': true, 'o': true, 'u': true}
    currentVowels := 0
    
    for i := 0; i < k; i++ {
        if vowels[s[i]] {
            currentVowels++
        }
    }
    maxVowels := currentVowels
    
    for i := k; i < len(s); i++ {
        if vowels[s[i-k]] {
            currentVowels--
        }
        if vowels[s[i]] {
            currentVowels++
        }
        if currentVowels > maxVowels {
            maxVowels = currentVowels
        }
    }
    
    return maxVowels
}
```Go 实现镜像 Python。 差异包括使用映射进行元音查找和显式比较，而不是使用映射`max`功能。 Go 切片处理字符索引的方式与 Python 字符串类似。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个字符最多被处理两次：一次进入滑动窗口，一次离开滑动窗口。 |
 | 空间| O(1) | O(1) | 仅使用恒定数量的计数器和固定大小的集合/映射。 |

 该算法与字符串的长度成线性比例，并且不需要与`n`，使其对于最大输入大小有效。
