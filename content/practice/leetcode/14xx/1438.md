[LeetCode 问题 1438](https://leetcode.com/problems/longest-continuous-subarray-with-absolute-diff-less-than-or-equal-to-limit/)

 **难度：** 🟡 中等
 **主题：** 数组、队列、滑动窗口、堆（优先级队列）、有序集、单调队列

 ## 解决方案

 ## 问题理解

 该问题要求我们找到整数数组中最长连续子数组的长度`nums`使得该子数组中任意两个元素之间的绝对差不超过给定值`limit`。 换句话说，对于任何有效的子数组，如果`max_val`是最大元素并且`min_val`是最小元素，那么`max_val - min_val <= limit`。 

输入由整数数组组成`nums`和一个整数`limit`。 输出是一个整数，表示满足绝对差条件的子数组的最大长度。 

这些约束很重要，因为它们表明检查所有可能子数组的简单解决方案将太慢。 具体来说，`nums.length`可以达到`10^5`，因此任何具有 O(n²) 时间复杂度的解决方案都不会在合理的时间限制内完成。 元素值和限制也可以非常大（`up to 10^9`），这意味着我们不能依赖计数排序或其他依赖于小整数范围的技巧。 

重要的边缘情况包括具有所有相同元素的数组，其中的数组`limit`为零，以及元素严格递增或递减的数组。 这些场景测试算法是否正确处理最小值或最大值频繁变化的情况。 

## 方法

 暴力方法将检查每个可能的子数组，计算该子数组中的最小值和最大值，并检查差异是否在范围内`limit`。 这保证了正确性，因为它确实检查了每种可能性，但它太慢了，时间复杂度为 O(n²) 或更糟，这对于`n = 10^5`。 

最佳解决方案的关键在于我们可以维持一个满足绝对差条件的**滑动窗口**。 为了有效地做到这一点，我们需要快速确定当前窗口中的最小值和最大值。 使用**单调队列**（以递增或递减顺序维护元素的双端队列）允许我们在移动窗口时每次操作以 O(1) 时间完成此操作。 每当差异超过时调整左边界`limit`，我们可以动态地扩展和缩小窗口并在 O(n) 时间内找到最大长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 检查每个子数组并每次计算最小值和最大值 |
 | 最优（滑动窗口+单调队列）| O(n) | O(n) | 使用两个单调队列有效跟踪最小值和最大值 |

 ## 算法演练

 1.初始化两个双端队列`minDeque`和`maxDeque`。`minDeque`将使元素按升序排列以跟踪最小值，并且`maxDeque`将使元素按降序排列以跟踪最大值。 
2.初始化两个指针`left = 0`和`right = 0`代表滑动窗口，以及一个变量`maxLength = 0`。 
3. 迭代`right`从 0 到结束`nums`:

 a. 添加`nums[right]`到`minDeque`通过从末尾删除大于的元素`nums[right]`。 这保持了递增的顺序。 

b. 添加`nums[right]`到`maxDeque`通过从末尾删除小于的元素`nums[right]`。 这保持了降序。 
4. 检查第一个元素之间是否存在差异`maxDeque`和`minDeque`超过`limit`。 如果是这样，请移动`left`向前缩小窗口：

 a. 如果`nums[left]`等于第一个元素`minDeque`，将其弹出`minDeque`。 

b. 如果`nums[left]`等于第一个元素`maxDeque`，将其弹出`maxDeque`。 

c. 增量`left`1.
 5、调整后`left`， 更新`maxLength`到其当前值的最大值并且`right - left + 1`。 
6. 返回`maxLength`循环完成后。 

该算法之所以有效，是因为滑动窗口不变性保证了窗口中的最大值和最小值始终满足`max - min <= limit`。 当违反不变量时，窗口从左侧缩小，直到恢复。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        minDeque = deque()
        maxDeque = deque()
        left = 0
        maxLength = 0

        for right, num in enumerate(nums):
            while minDeque and num < minDeque[-1]:
                minDeque.pop()
            minDeque.append(num)

            while maxDeque and num > maxDeque[-1]:
                maxDeque.pop()
            maxDeque.append(num)

            while maxDeque[0] - minDeque[0] > limit:
                if nums[left] == minDeque[0]:
                    minDeque.popleft()
                if nums[left] == maxDeque[0]:
                    maxDeque.popleft()
                left += 1

            maxLength = max(maxLength, right - left + 1)

        return maxLength
```Python 实现使用`deque`对于单调队列。 每次迭代都会通过维护队列顺序来更新队列，确保每个元素的摊销操作为 O(1)。 这`while`仅当违反限制时，主循环内的循环才会调整左边界。 

## 解决方案```go
package main

func longestSubarray(nums []int, limit int) int {
    minDeque := []int{}
    maxDeque := []int{}
    left, maxLength := 0, 0

    for right, num := range nums {
        for len(minDeque) > 0 && num < minDeque[len(minDeque)-1] {
            minDeque = minDeque[:len(minDeque)-1]
        }
        minDeque = append(minDeque, num)

        for len(maxDeque) > 0 && num > maxDeque[len(maxDeque)-1] {
            maxDeque = maxDeque[:len(maxDeque)-1]
        }
        maxDeque = append(maxDeque, num)

        for maxDeque[0] - minDeque[0] > limit {
            if nums[left] == minDeque[0] {
                minDeque = minDeque[1:]
            }
            if nums[left] == maxDeque[0] {
                maxDeque = maxDeque[1:]
            }
            left++
        }

        if right-left+1 > maxLength {
            maxLength = right - left + 1
        }
    }

    return maxLength
}
```在 Go 中，切片用于单调队列。 追加和切片操作模拟双端队列行为。 Go 需要显式的切片管理，但其逻辑与 Python 实现非常相似。
