## 问题理解

 该问题要求我们实现一个**HTML 实体解析器**。 我们得到一个字符串`text`其中可能包含 HTML 实体，例如`&quot;`为了`"`或者`&amp;`为了`&`。 目标是用相应的特殊字符替换字符串中的所有有效实体，保留任何无效或无法识别的实体。 例如，`&ambassador;`在此上下文中不是有效的 HTML 实体，因此它应保持原样。 

输入是单个字符串，输出是转换后的字符串，其中识别的实体被它们代表的字符替换。 约束表明`text`可以长达 100,000 个字符，并且可以包含任何 ASCII 字符，因此效率很重要。 边缘情况包括位于字符串开头或结尾的实体、多个连续实体或类似于有效实体但并非如此的部分/无效实体。 

关键的挑战是**有效地扫描和替换实体，而无需重复搜索字符串**，这对于长输入来说可能成本高昂。 使用哈希映射（字典）进行实体查找允许 O(1) 替换检查。 我们还需要仔细处理重叠或部分匹配的实体。 

## 方法

 暴力方法将迭代字符串，在每个位置检查子字符串是否与任何有效实体匹配。 这涉及重复比较子字符串，并且可能效率低下，尤其是对于长字符串，因为每次比较可能涉及最多 7 个字符（最长的实体`&frasl;`是 7 个字符）。 

最佳方法是**从左到右扫描一次字符串**，然后构建结果字符串。 每当我们遇到`&`，我们尝试使用哈希映射来匹配从该位置开始的有效实体。 如果找到匹配项，我们将附加相应的字符并将指针前进实体的长度。 否则，我们追加当前字符并继续前进。 这保证了**线性时间复杂度 O(n)**，因为每个字符最多被处理一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 针对所有实体重复检查每个子字符串；`m`是最大实体长度。 |
 | 最佳| O(n) | O(1) | O(1) | 扫描一次，使用哈希图进行实体替换，增量构建结果字符串。 |

 ## 算法演练

 1. 初始化哈希图`entity_map`包含所有 HTML 实体作为键及其相应的字符作为值。 
2.初始化一个空列表`result`有效地构建输出字符串。 
3. 初始化指针`i = 0`扫描输入字符串`text`。 
4. 虽然`i < len(text)`，检查当前字符：

 1.如果`text[i] != '&'`, 附加`text[i]`到`result`并增加`i`1.
 2.如果`text[i] == '&'`，尝试匹配一个实体：

 1. 遍历所有可能的实体`entity_map`。 
2. 对于每个实体，检查是否`text[i:i+len(entity)] == entity`。 
3. 如果找到匹配项，则将映射的字符附加到`result`, 增量`i`通过实体长度，并打破内部循环。 
4. 如果没有实体匹配，则追加`&`到`result`并增加`i`1.
 5.循环结束后，加入`result`成一个字符串并返回它。 

**为什么有效：** 该算法保持了以下不变式：`result`始终包含正确解析的子字符串`text`直到位置`i`。 通过从左到右扫描并使用哈希映射查找潜在实体，我们确保每个识别的实体仅被替换一次，并且不匹配的字符保持不变。 

## Python 解决方案```python
class Solution:
    def entityParser(self, text: str) -> str:
        entity_map = {
            "&quot;": "\"",
            "&apos;": "'",
            "&amp;": "&",
            "&gt;": ">",
            "&lt;": "<",
            "&frasl;": "/"
        }
        
        result = []
        i = 0
        n = len(text)
        
        while i < n:
            if text[i] != '&':
                result.append(text[i])
                i += 1
            else:
                matched = False
                for entity, char in entity_map.items():
                    if text.startswith(entity, i):
                        result.append(char)
                        i += len(entity)
                        matched = True
                        break
                if not matched:
                    result.append('&')
                    i += 1
        
        return ''.join(result)
```Python 解决方案使用字典进行 O(1) 实体查找，并使用列表来有效累积字符。 这`text.startswith(entity, i)`函数确保我们正确匹配实体，而无需进行不必要的切片。 如果没有实体匹配，则`&`被保留，保持正确的输出。 

## 解决方案```go
func entityParser(text string) string {
    entityMap := map[string]string{
        "&quot;": "\"",
        "&apos;": "'",
        "&amp;":  "&",
        "&gt;":   ">",
        "&lt;":   "<",
        "&frasl;": "/",
    }
    
    result := []byte{}
    i := 0
    n := len(text)
    
    for i < n {
        if text[i] != '&' {
            result = append(result, text[i])
            i++
        } else {
            matched := false
            for entity, char := range entityMap {
                if len(text[i:]) >= len(entity) && text[i:i+len(entity)] == entity {
                    result = append(result, char[0])
                    i += len(entity)
                    matched = true
                    break
                }
            }
            if !matched {
                result = append(result, '&')
                i++
            }
        }
    }
    
    return string(result)
}
```在 Go 中，我们使用映射进行实体查找，并使用字节切片来高效构建字符串。 由于 Go 字符串是不可变的，因此切片优于重复连接字符串。 其他方面的逻辑与 Python 解决方案相同。
