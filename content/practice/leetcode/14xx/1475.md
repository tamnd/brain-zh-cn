[LeetCode 问题 1475](https://leetcode.com/problems/final-prices-with-a-special-discount-in-a-shop/)

 **难度：** 🟢简单
 **主题：** 数组、堆栈、单调堆栈

 ## 解决方案

 ## 问题理解

 该问题提出了一个场景，您在商店中购买商品，每个商品都有存储在数组中的给定价格`prices`。 对于索引处的每个项目`i`, 可能存在基于下一个项目的折扣`j`（在哪里`j > i`）这样`prices[j] <= prices[i]`。 如果这样一个`j`存在，折扣等于`prices[j]`; 否则，不享受折扣。 您的任务是计算应用此折扣后每件商品的最终价格，并以与输入长度相同的数组形式返回结果。 

输入是长度在 1 到 500 之间的整数列表，每个整数的范围是 1 到 1000。这些约束意味着数组相对较小，因此即使 O(n²) 的强力解决方案在实践中也可以工作，但使用单调堆栈的最佳方法可以将时间复杂度降低到 O(n)。 

重要的边缘情况包括：长度为 1 的数组（无法应用折扣）、严格递增的数组（无法应用折扣）以及可以连续使用多个折扣的数组。 

## 方法

 蛮力方法很简单：对于指数的每个价格`i`，您迭代所有后续价格以找到第一个价格`prices[j]`小于或等于`prices[i]`。 找到后，将其减去`prices[i]`以获得最终价格。 虽然正确，但此方法的时间复杂度为 O(n²)，因为每个元素可能需要扫描所有剩余元素。 

最佳方法使用单调堆栈。 关键的见解是我们可以按价格降序维护一堆指数。 当我们遍历数组时，如果当前价格小于或等于堆栈顶部索引处的价格，我们就会从堆栈中弹出并将折扣应用于该索引。 这确保了对于每个项目，从第一个更小或相等的未来价格应用折扣，实现 O(n) 时间复杂度，因为每个元素最多被推送和弹出一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 检查每个项目的每个未来元素 |
 | 最佳 | O(n) | O(n) | 使用单调堆栈跟踪需要折扣的指数 |

 ## 算法演练

 1. 初始化一个空堆栈来保存尚未确定折扣的商品索引。 
2. 遍历`prices`从左到右排列。 
3. 对于每个当前索引`i`：

 a. 当堆栈不为空并且当前价格`prices[i]`小于或等于`prices[stack[-1]]`，从堆栈中弹出索引。 

b. 对于弹出的索引，将最终价格设置为`prices[popped_index] - prices[i]`。 
4.推送当前索引`i`进入堆栈，因为它可以作为未来价格的折扣。 
5. 遍历结束后，堆栈中剩余的任何索引都没有找到折扣。 他们的最终价格仍然与原始价格相同。 
6. 返回最终价格的结果数组。 

**为什么有效：** 堆栈始终按降序维护价格指数。 当遇到较小或相同的价格时，它会正确识别每个先前商品的第一个合格折扣，从而保证问题折扣规则的正确应用。 

## Python 解决方案```python
from typing import List

class Solution:
    def finalPrices(self, prices: List[int]) -> List[int]:
        final_prices = prices.copy()
        stack = []

        for i, price in enumerate(prices):
            while stack and price <= prices[stack[-1]]:
                idx = stack.pop()
                final_prices[idx] -= price
            stack.append(i)

        return final_prices
```在这个实现中，`final_prices`被初始化为副本`prices`来存储结果。 该堆栈存储折扣待定的索引。 这`while`循环将折扣应用于所有大于或等于当前价格的先前价格。 指数`i`然后添加到堆栈中以供将来处理。 这可确保每个价格最多从第一个后续合格价格获得一个折扣。 

## 解决方案```go
func finalPrices(prices []int) []int {
    n := len(prices)
    finalPrices := make([]int, n)
    copy(finalPrices, prices)
    stack := []int{}

    for i, price := range prices {
        for len(stack) > 0 && price <= prices[stack[len(stack)-1]] {
            idx := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            finalPrices[idx] -= price
        }
        stack = append(stack, i)
    }

    return finalPrices
}
```在 Go 中，切片用于复制堆栈行为，并且`copy`确保`finalPrices`以副本开始`prices`。 循环逻辑反映了 Python 版本，维护索引堆栈并在遇到较小或相等的价格时应用折扣。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个索引在堆栈中最多被压入和弹出一次 |
 | 空间| O(n) | 最坏情况下堆栈可能存储所有索引 |

 该算法在时间上是线性的，因为堆栈确保每个元素仅被处理两次，并且由于堆栈和价格数组的副本，空间与输入大小成正比。
