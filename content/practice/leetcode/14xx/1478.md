## 问题理解

 问题提供了一个列表`houses`，其中每个元素代表街道上房屋的位置。 要求您准确分配`k`邮箱，以尽量减少每栋房屋到最近邮箱的总距离。 使用的距离度量是沿街道的绝对距离，即|房屋位置 - 邮箱位置|。 

输入`houses`保证具有唯一的整数，其长度在1到100之间。 邮箱的数量`k`范围从 1 到长度`houses`。 因为答案适合 32 位整数，所以在实际实现中我们不需要担心整数溢出。 

需要仔细考虑的边缘情况包括邮箱数量等于房屋数量的情况（每个房屋可以有自己的邮箱，因此总距离为零）或当`k`是 1（所有房屋必须共享一个邮箱，因此将其放置在中间位置可以最小化距离）。 事实是`houses`可以包含大整数（最多 10^4）意味着必须仔细处理排序和绝对差计算。 

关键的挑战是，将邮箱简单地放置在所有可能的位置中的组合成本很高，特别是因为位置的数量可能很大。 因此，需要预先计算成本的动态规划解决方案。 

## 方法

 蛮力方法是尝试所有可能的位置`k`街道两旁的邮箱。 对于每个位置，计算从每个房屋到最近的邮箱的距离总和。 这保证了正确的答案，因为我们探索了所有配置，但在计算上是不可行的。 可能的放置数量与`n`和`k`，导致时间复杂度呈指数级增长。 

实现最佳解决方案的关键观察是，对于连续的房屋段，单个邮箱的最佳位置是该段的中间位置。 这将问题简化为计算房屋各部分的最小总距离，并将它们最佳地组合起来`k`邮箱。 通过使用动态规划，我们可以通过考虑子问题来有效地计算最小总距离：分配的最小距离`j`第一个邮箱`i`房屋。 预先计算为房屋的每个连续部分最佳放置邮箱的成本进一步减少了冗余计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^k * n) | O(n^k * n) | O(1) | O(1) | 尝试 n 个房屋的 k 个邮箱的所有放置位置。 指数级且不可行。 |
 | 最佳DP | O(k * n^2) | O(k * n^2) | O(n^2) | O(n^2) | 使用具有预先计算的中值成本的 DP。 对于 n <= 100 且 k <= n 有效。 |

 ## 算法演练

 1. **对房屋进行排序**：排序可确保房屋有序。 这一点至关重要，因为连续部分房屋的最佳邮箱位于中间位置，只有在房屋被订购时才有效。 
2. **预先计算分段成本**：对于每对指数`(i, j)`在哪里`i <= j`，如果邮箱已针对该段进行最佳放置，则计算最小距离`houses[i..j]`。 将邮箱放置在该区域中间的房子里。 将这些成本存储在二维数组中`cost[i][j]`。 
3. **初始化DP表**：定义`dp[i][k]`作为分配的最小总距离`k`第一个邮箱`i`房屋。 初始化`dp[0][0] = 0`因为零房子和零邮箱的成本为零。 
4. **填充 DP 表**：对于每个`i`从 1 到 n，对于每个邮箱数量`m`从 1 到 k，计算`dp[i][m]`作为最小值`dp[j][m-1] + cost[j][i-1]`为所有人`j`从 0 到 i-1。 这表示为该段最佳地放置最后一个邮箱`houses[j..i-1]`并使用`m-1`前面房子的邮箱。 
5. **返回结果**：填写DP表后，`dp[n][k]`包含最小总距离`n`房屋有`k`邮箱。 

**为什么有效**：DP 公式保证在每一步，解决方案`i`房屋和`m`Mailboxes 对之前所有邮箱数量较少的子问题使用最优解。 使用中位数的分段成本确保了局部最优性，将其结合到DP中确保了全局最优性。 

## Python 解决方案```python
from typing import List

class Solution:
    def minDistance(self, houses: List[int], k: int) -> int:
        houses.sort()
        n = len(houses)
        
        # Precompute the cost of placing one mailbox for all segments
        cost = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i, n):
                median = houses[(i + j) // 2]
                for l in range(i, j + 1):
                    cost[i][j] += abs(houses[l] - median)
        
        # Initialize DP array
        dp = [[float('inf')] * (k + 1) for _ in range(n + 1)]
        dp[0][0] = 0
        
        for i in range(1, n + 1):
            for m in range(1, k + 1):
                for j in range(i):
                    dp[i][m] = min(dp[i][m], dp[j][m-1] + cost[j][i-1])
        
        return dp[n][k]
```**解释**：代码对房屋进行排序，预先计算每个部分的中位成本，用无穷大初始化 DP 表，并使用先前计算的结果迭代填充它。 最终答案摘自`dp[n][k]`。 

## 解决方案```go
import "math"

func minDistance(houses []int, k int) int {
    n := len(houses)
    sort.Ints(houses)
    
    cost := make([][]int, n)
    for i := range cost {
        cost[i] = make([]int, n)
        for j := i; j < n; j++ {
            median := houses[(i+j)/2]
            for l := i; l <= j; l++ {
                cost[i][j] += abs(houses[l] - median)
            }
        }
    }
    
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, k+1)
        for j := range dp[i] {
            dp[i][j] = math.MaxInt32
        }
    }
    dp[0][0] = 0
    
    for i := 1; i <= n; i++ {
        for m := 1; m <= k; m++ {
            for j := 0; j < i; j++ {
                if dp[j][m-1]+cost[j][i-1] < dp[i][m] {
                    dp[i][m] = dp[j][m-1] + cost[j][i-1]
                }
            }
        }
    }
    
    return dp[n][k]
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```**Go 特定注释**：Go 使用`math.MaxInt32`初始化 DP 值。 使用切片而不是数组。 辅助函数`abs`处理绝对差异。

 3、DP灌装：
