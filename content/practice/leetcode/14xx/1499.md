[LeetCode 第 1499 题](https://leetcode.com/problems/max-value-of-equation/)

 **难度：** 🔴难
 **主题：** 数组、队列、滑动窗口、堆（优先级队列）、单调队列

 ## 解决方案

 本指南将重点关注最佳单调队列解决方案，该解决方案实现线性时间复杂度，并且对于处理输入大小限制是必要的`10^5`。 

## 问题理解

 我们得到一个 2D 点列表，按 x 坐标严格按升序排序。 每个点都表示为`[xi, yi]`，我们还得到一个整数`k`。 

我们的目标是找到以下方程的最大可能值：$$yi + yj + |xi - xj|$$须符合以下条件：$$|xi - xj| \leq k$$在哪里`i < j`。 

由于点按以下顺序排序`x`和`xi < xj`，绝对值自然简化：$$|xi - xj| = xj - xi$$因为`xj`总是大于`xi`。 

这将等式转换为：$$yi + yj + xj - xi$$我们可以将其重新排列为：$$(yi - xi) + (yj + xj)$$这种转变是问题的关键观察点。 

对于每一点`j`，我们想要找到一个有效的早期点`i`这样：$$xj - xi \leq k$$在所有这些有效点中，我们想要最大可能的值：$$yi - xi$$因为`(yj + xj)`对于当前点是固定的`j`。 

约束在这里尤其重要：

 -`points.length`可以大到`100,000`- 坐标可以很大，最多`10^8`- 点已按 x 坐标排序

 检查每一对的二次解决方案最多需要：$$O(n^2) = 10^{10}$$在最坏的情况下，操作速度太慢了。 

该问题保证至少存在一对有效的结果，因此我们永远不需要担心返回无效的结果。 

重要的边缘情况包括只有相邻点满足距离条件，负数的情况`y`影响方程评分的值，以及许多候选点仍然有效的大窗口。 我们还必须小心地删除 x 距离超过的过期点`k`。 

## 方法

 ### 蛮力

 最直接的方法是检查每一个可能的对`(i, j)`在哪里`i < j`。 

对于每一对，我们计算：$$yi + yj + |xi - xj|$$并检查是否：$$|xi - xj| \leq k$$如果该对有效，我们将更新最大答案。 

这种方法保证是正确的，因为它评估每个可能的有效对。 然而，由于有`O(n²)`对，它变得不可行`n = 100,000`。 

### 最优方法，单调队列

 关键的数学观察是：$$yi + yj + |xi - xj|$$变成：$$(yi - xi) + (yj + xj)$$对于固定点`j`，值`(yj + xj)`是恒定的。 

因此，我们只需要找到最大的：$$yi - xi$$在所有有效的先前点中满足：$$xj - xi \leq k$$这自然意味着在数据结构中维护候选点。 

我们使用 deque（双端队列）来按降序维护候选点：$$yi - xi$$双端队列有两个目的：

 1. 删除不再满足距离约束的过期点。 
2. 它只保留最大化方程的最佳候选者。 

通过保持单调顺序，最佳候选者始终位于双端队列的前面。 

由于每个点最多进入和离开双端队列一次，因此总运行时间变为线性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 检查每对有效的 |
 | 最佳 | O(n) | O(n) | 使用单调双端队列来维护最佳候选者 |

 ## 算法演练

 1.初始化一个双端队列和一个变量`best_answer`。 

双端队列将候选点存储为元组：`(x, y - x)`我们按照降序维护双端队列`(y - x)`。 
2. 迭代每个点`(x, y)`在`points`。 

该点作为当前`j`。 
3. 从双端队列的前面删除过期的点。 

如果：$$x - old_x > k$$那么该点不能再与当前点或任何未来点形成有效对，因为 x 值只会增加。 
4. 计算候选方程值。 

如果双端队列不为空，则前面包含最大的可用：$$yi - xi$$所以我们计算：$$(x + y) + deque[0]$$并更新最大答案。 
5. 保持单调顺序。 

在添加当前点之前，删除后面的元素 while：$$current(y - x) \geq deque[-1]$$这些点永远不再有用，因为当前点具有相同或更好的分数以及更大的 x 值。 
6. 将当前点插入双端队列。 

店铺：`(x, y - x)`7. 继续，直到处理完所有点。 

### 为什么它有效

 双端队列始终维护按降序排列的有效候选点`(yi - xi)`。 因此，前面始终包含用于最大化当前位置处的方程的最佳可能的先前点。 由于过期的点会立即被删除，并且主导的候选点会被丢弃，因此每个点都只会被考虑一次，同时保持正确性。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def findMaxValueOfEquation(self, points: List[List[int]], k: int) -> int:
        candidate_points = deque()
        best_answer = float("-inf")

        for x, y in points:
            # Remove points outside distance k
            while candidate_points and x - candidate_points[0][0] > k:
                candidate_points.popleft()

            # Compute equation value
            if candidate_points:
                best_answer = max(
                    best_answer,
                    x + y + candidate_points[0][1]
                )

            current_value = y - x

            # Maintain decreasing order of (y - x)
            while candidate_points and candidate_points[-1][1] <= current_value:
                candidate_points.pop()

            candidate_points.append((x, current_value))

        return best_answer
```实现直接遵循算法。 

我们首先创建一个双端队列来存储候选点。 每个条目包含 x 坐标和转换后的值`(y - x)`。 

对于每个点，我们首先从前面删除过期的候选者。 由于点按 x 坐标排序，因此一旦点无效，它就永远不会再次有效。 

修剪掉无效点后，我们使用双端队列的前面来计算方程。 因为双端队列是按降序维护的`(y - x)`，前面的总是代表最好的候选者。 

在插入当前点之前，我们从后面删除较弱的候选点。 如果当前点有大于或等于`(y - x)`，任何较小的值将永久占主导地位，并且不再有用。 

最后，我们附加当前点并继续。 

## 解决方案```go
func findMaxValueOfEquation(points [][]int, k int) int {
	type pair struct {
		x     int
		value int // y - x
	}

	deque := make([]pair, 0)
	bestAnswer := -(1 << 60)

	for _, point := range points {
		x, y := point[0], point[1]

		// Remove expired points
		for len(deque) > 0 && x-deque[0].x > k {
			deque = deque[1:]
		}

		// Compute equation value
		if len(deque) > 0 {
			candidate := x + y + deque[0].value
			if candidate > bestAnswer {
				bestAnswer = candidate
			}
		}

		currentValue := y - x

		// Maintain decreasing order
		for len(deque) > 0 &&
			deque[len(deque)-1].value <= currentValue {
			deque = deque[:len(deque)-1]
		}

		deque = append(deque, pair{
			x:     x,
			value: currentValue,
		})
	}

	return bestAnswer
}
```Go 的实现与 Python 解决方案非常相似。 由于 Go 不提供内置双端队列，因此我们使用切片来模拟双端队列。 

使用切片从前面移除：```go
deque = deque[1:]
```Go 中的整数范围足以解决此问题，因为最大可能结果保持在 32 位范围内，但使用非常负的初始化值，例如`-(1 << 60)`确保正确性而无需担心溢出。

class Solution:
    def findMaxValueOfEquation(self, points, k):
        from collections import deque

        ans = float("-inf")

        return ans

 ## 边缘情况

 ### 仅存在一对有效的

 有时只有一对满足距离约束。 幼稚的实现可能会由于窗口维护不当而意外错过它。 由于双端队列仅在以下情况下删除过期点：`x - old_x > k`，该实现保留所有有效候选者并保证评估唯一的有效对。 

### 坐标中的负值

 当以下情况时，方程可能会产生负结果：`y`值为负数。 不正确的实现可能会将答案初始化为`0`，在这种情况下会失败。 该解决方案将答案初始化为负无穷大，确保即使是完全负的结果也能得到正确处理。 

### 大型有效窗口

 当`k`非常大，很多点同时保持有效。 如果不修剪主导候选者，性能可能会显着下降。 单调双端队列立即删除较弱的候选点，确保仅保留潜在的最佳点并保留线性复杂性。 

### 前面的过期候选人

 如果在计算方程之前未删除过期点，则会出现一个微妙的错误。 这可能会错误地使用 x 距离超过的无效点`k`。 该实现首先显式删除过期点，保证每个计算的方程满足约束。
