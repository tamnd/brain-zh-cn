[LeetCode 第 1429 题](https://leetcode.com/problems/first-unique-number/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、设计、队列、数据流

 ## 解决方案

 ## 问题理解

 该问题需要设计一种数据结构，能够有效地维护和检索数字队列中的第一个唯一整数。 给你一个初始的整数列表，之后，数据结构应该有效地支持两个操作：检索第一个唯一的数字（`showFirstUnique`）并将新号码添加到队列中（`add`）。 

输入`nums`表示初始整数队列，整数在 [1, 10^8] 范围内。 输出为`showFirstUnique`应返回队列中仅出现一次的第一个整数的值，或者`-1`如果不存在这样的号码。 约束表明`nums`最多可以包含 10^5 个元素，并且最多可以调用 50,000 次`showFirstUnique`和`add`。 这意味着扫描每个查询的队列的简单方法将太慢。 该问题还隐式保证所有输入都是指定范围内的有效整数。 

重要的边缘情况包括所有数字都是重复的、队列开始为空时，或者在添加重复项时从队列前面删除第一个唯一数字时。 

## 方法

 蛮力方法是将队列维护为列表，并在任何时候从前面扫描它`showFirstUnique`被调用，检查每个数字的计数。 这可以正常工作，但效率很低，因为计算每个查询在队列中的出现次数会导致每个查询的 O(n) 时间，从而导致 O(n*m) 时间`m`查询，考虑到限制，这是不可接受的。 

最佳方法利用哈希图和队列的组合。 哈希映射跟踪每个数字的频率，而双端队列（deque）则维护当前唯一的数字的顺序。 添加数字时，我们会更新其计数，如果它变得唯一，则将其附加到双端队列，或者如果它不再唯一，则将其删除。 然后，检索第一个唯一编号就变成了 O(1) 操作，因为它始终位于双端队列的前面。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n*m) | O(n) | 扫描整个队列中的每个`showFirstUnique`打电话，太慢|
 | 最佳| O(1) 每次操作摊销 | O(n) | 使用 hashmap 进行计数，使用 deque 进行唯一元素的顺序 |

 ## 算法演练

 1. 初始化哈希图`count_map`跟踪每个号码和队列的频率`unique_queue`存储当前唯一的数字。 
2. 初始化时，迭代输入列表`nums`。 对于每个数字，更新其计数`count_map`。 如果计数变为1，则将其附加到`unique_queue`。 如果计数超过1，则将其从`unique_queue`如果存在的话。 
3.为了`showFirstUnique`，检查前面`unique_queue`。 如果为空则返回`-1`。 否则，返回前面的数字。 
4. 对于`add(value)`, 增量`count_map[value]`。 如果计数变为 1，则将值附加到`unique_queue`。 如果计数变为 2 或更多，则将其从`unique_queue`。 
5. 队列始终保持当前唯一的数字顺序，因此检索第一个元素始终是正确的。 

这有效是因为`unique_queue`始终仅包含在整个数据流中唯一的数字并保持插入顺序。 队列的前面保证在任何时候都是第一个唯一的数字。 

## Python 解决方案```python
from collections import deque
from typing import List

class FirstUnique:

    def __init__(self, nums: List[int]):
        self.count_map = {}
        self.unique_queue = deque()
        for num in nums:
            self.add(num)

    def showFirstUnique(self) -> int:
        while self.unique_queue and self.count_map[self.unique_queue[0]] > 1:
            self.unique_queue.popleft()
        return self.unique_queue[0] if self.unique_queue else -1

    def add(self, value: int) -> None:
        self.count_map[value] = self.count_map.get(value, 0) + 1
        if self.count_map[value] == 1:
            self.unique_queue.append(value)
```在此实现中，构造函数迭代初始列表并使用`add`初始化计数映射和队列。`showFirstUnique`确保队列的前面始终是唯一的数字。 这`add`方法更新计数并将新的唯一编号附加到队列中。 双端队列确保从前面添加和删除元素的摊销操作为 O(1)。 

## 解决方案```go
package main

type FirstUnique struct {
	countMap    map[int]int
	uniqueQueue []int
}

func Constructor(nums []int) FirstUnique {
	fu := FirstUnique{
		countMap:    make(map[int]int),
		uniqueQueue: []int{},
	}
	for _, num := range nums {
		fu.Add(num)
	}
	return fu
}

func (this *FirstUnique) ShowFirstUnique() int {
	for len(this.uniqueQueue) > 0 && this.countMap[this.uniqueQueue[0]] > 1 {
		this.uniqueQueue = this.uniqueQueue[1:]
	}
	if len(this.uniqueQueue) == 0 {
		return -1
	}
	return this.uniqueQueue[0]
}

func (this *FirstUnique) Add(value int) {
	this.countMap[value]++
	if this.countMap[value] == 1 {
		this.uniqueQueue = append(this.uniqueQueue, value)
	}
}
```在Go中，切片被用作队列。 从正面去除是通过切片切片来实现的。 该地图跟踪计数，类似于 Python 实现。 的语义`ShowFirstUnique`和`Add`镜像 Python 版本。 Go没有内置的双端队列，因此使用了仔细切片的切片。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(1) 每次操作摊销 | 从双端队列的前/后添加或删除元素的时间复杂度为 O(1) 摊销，哈希图查找的时间复杂度为 O(1) |
 | 空间| O(n) | 我们存储每个元素的计数和唯一元素的队列 |

 时间复杂度摊销为 O(1)，因为每个元素最多可以从双端队列中添加和删除一次。 空间复杂度为 O(n)，因为映射和队列都可以与唯一元素的数量成比例增长。
