 ## 解决方案

 ## 问题理解

 该问题要求我们遍历一个锯齿状的二维整数数组`nums`对角线。 具体来说，元素通过其“对角线级别”进行访问，其中每个对角线包含行索引和列索引之和相同的元素。 在每个对角线中，元素应按其行的相反顺序出现，这意味着我们从对角线的最底行开始向上移动。 

输入`nums`是整数列表的列表。 列表是锯齿状的，这意味着每个子列表可能具有不同的长度。 输出应该是单个整数列表，表示根据上述规则对所有元素进行对角线遍历。 

约束很重要：所有子列表中的元素总数最多可达`10^5`。 这排除了任何涉及二次时间完全展平或排序的方法。 每个元素都可以很大，但范围对于遍历逻辑并不重要。 

边缘情况包括空子列表（尽管`nums[i].length >= 1`保证每行至少有一个元素）、高度锯齿状数组（长度差异很大的行）和最小输入（`nums`包含单行或单列）。 

## 方法

 强力方法是迭代所有可能的对角线级别（索引之和），将属于每个对角线的元素收集到临时数组中，反转每个对角线，然后将它们附加到结果中。 这是有效的，因为对角线自然地分组为`row + column`，但是比较麻烦，可能会涉及到很多临时数组。 

最佳方法使用哈希图（字典），其中键是对角线级别`d = row + column`。 当我们迭代每个元素时，我们将其附加到与其对角线对应的列表中。 处理完所有元素后，我们按照对角线级别递增的顺序连接对角线，反转每个对角线，因为元素是从上到下收集的，但必须在同一对角线内从下到上出现。 

此方法工作效率很高，因为它在一次传递中收集对角线，并且仅再次迭代所有元素以产生最终输出。 它自然地处理锯齿状数组，并且不需要在不同长度的对角线上进行嵌套迭代。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N + D^2) | O(N + D^2) | O(N + D) | 按对角线收集元素并反转每个元素； 对于具有许多对角线的锯齿状数组可能效率低下 |
 | 最佳| O(N) | O(N) | 哈希图有效收集对角线； 单遍遍历所有元素，然后遍历对角线以形成结果 |

 这里，`N`是元素总数 (`sum(len(row) for row in nums)`） 和`D`是最大对角线索引。 

## 算法演练

 1.初始化一个空字典`diagonals`映射对角线索引`d = row + col`到元素列表。 
2. 初始化变量`max_diag`跟踪所见的最大对角线索引。 
3. 迭代每一行`r`和每一列`c`在该行内。 
4. 计算对角线索引`d = r + c`。 
5. 追加`nums[r][c]`到`diagonals[d]`。 
6. 更新`max_diag`如果`d`大于当前最大值。 
7. 初始化一个空列表`result`存储最终的对角线遍历。 
8. 迭代自`d = 0`到`max_diag`。 
9. 对于每个对角线列表`diagonals[d]`，将其元素以相反的顺序附加到`result`。 
10. 返回`result`。 

为什么它有效：每个元素都被精确地分配给一个对角键，基于`row + col`，这确保了正确的分组。 反转每条对角线可确保问题所需的自下而上的顺序。 以升序迭代对角线可以保证正确的遍历顺序。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def findDiagonalOrder(self, nums: List[List[int]]) -> List[int]:
        diagonals = defaultdict(list)
        max_diag = 0
        
        for r, row in enumerate(nums):
            for c, val in enumerate(row):
                diagonals[r + c].append(val)
                max_diag = max(max_diag, r + c)
        
        result = []
        for d in range(max_diag + 1):
            result.extend(reversed(diagonals[d]))
        
        return result
```此实现首先使用按对角线索引分组的元素填充哈希映射。 然后将每个对角线列表反转并附加到最​​终结果。 使用`defaultdict`通过避免显式检查丢失的键来简化逻辑。 

## 解决方案```go
func findDiagonalOrder(nums [][]int) []int {
    diagonals := make(map[int][]int)
    maxDiag := 0
    
    for r, row := range nums {
        for c, val := range row {
            diagonals[r+c] = append(diagonals[r+c], val)
            if r+c > maxDiag {
                maxDiag = r + c
            }
        }
    }
    
    result := []int{}
    for d := 0; d <= maxDiag; d++ {
        diag := diagonals[d]
        for i := len(diag) - 1; i >= 0; i-- {
            result = append(result, diag[i])
        }
    }
    
    return result
}
```在 Go 中，映射存储对角线列表，并且元素的附加方式类似。 在迭代过程中反转每条对角线会产生所需的从下到上的顺序。 Nil 切片是自然处理的，因为附加到 nil 切片会创建一个新切片。
