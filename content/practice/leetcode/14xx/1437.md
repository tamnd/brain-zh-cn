[LeetCode 问题 1437](https://leetcode.com/problems/check-if-all-1s-are-at-least-length-k-places-away/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 问题要求我们检查是否所有`1`给定二进制数组中的 s`nums`至少分开`k`职位。 换句话说，对于任意两个索引`i`和`j`在哪里`nums[i] == nums[j] == 1`和`i < j`， 区别`j - i`至少应该是`k + 1`。 输入由二进制数组组成`nums`其中每个元素是`0`或者`1`，和一个整数`k`它表示任意两个之间所需的最小距离`1`是。 预期输出是一个布尔值：`true`如果所有人都满足条件`1`数组中的 s，或者`false`如果至少有一对`1`太近了。 

这些约束表明数组可能非常大，最多可达 100,000 个元素，因此需要高效的线性时间解决方案。 要考虑的边缘情况包括没有的数组`1`s，所有元素都为的数组`1`s，以及情况`k`为零，意味着没有距离限制。 

## 方法

 蛮力方法将涉及检查每对之间的距离`1`s 在数组中。 对于每个`1`在索引处`i`，我们将扫描数组的其余部分以查找其他`1`s 并计算距离`j - i`。 这种方法工作正常，但在最坏情况下时间复杂度为 O(n²)，这对于大型数组来说效率很低。 

最佳方法利用单个线性扫描。 我们维护最后看到的索引`1`并且，对于每个新的`1`，我们计算到前一个的距离。 如果这个距离小于或等于`k`，我们立即返回`false`。 否则，我们继续扫描。 此方法的工作时间为 O(n)，并使用 O(1) 额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 检查所有对`1`s，对于大型数组效率低下 |
 | 最佳| O(n) | O(1) | O(1) | 单次扫描，跟踪最后一个索引`1`，如果距离 < k | 则立即返回

 ## 算法演练

 1. 初始化变量`lastOne`存储最后一次看到的索引`1`。 从值开始`-1`来表明没有`1`已经见过了。 
2. 遍历数组`nums`有索引`i`从 0 到`len(nums) - 1`。 
3. 每当`nums[i] == 1`，检查是否`lastOne`不是`-1`。 
4. 如果`lastOne`不是`-1`，计算距离`i - lastOne`。 如果这个距离小于或等于`k`， 返回`false`立即，因为条件被违反。 
5. 更新`lastOne`到`i`来标记最近的`1`。 
6. 继续直到数组末尾。 如果没有发现违规，则返回`true`。 

**为什么有效：** 该算法确保每对连续的`1`s 仅检查一次。 因为我们只比较与前一个的距离`1`，我们保持所有的不变量`1`目前为止看到的至少有`k`分开。 如果任何对未通过距离检查，该函数将正确返回`false`。 

## Python 解决方案```python
from typing import List

class Solution:
    def kLengthApart(self, nums: List[int], k: int) -> bool:
        lastOne = -1
        for i, num in enumerate(nums):
            if num == 1:
                if lastOne != -1 and i - lastOne - 1 < k:
                    return False
                lastOne = i
        return True
```实现初始化`lastOne`作为`-1`处理没有的情况`1`还没有遇到过。 这`enumerate`函数用于迭代数组，同时跟踪索引。 对于每个`1`，它检查到最后一个的距离是否`1`足够了并且有更新`lastOne`。 算法返回`True`仅当所有对`1`s 满足距离约束。 

## 解决方案```go
func kLengthApart(nums []int, k int) bool {
    lastOne := -1
    for i, num := range nums {
        if num == 1 {
            if lastOne != -1 && i - lastOne - 1 < k {
                return false
            }
            lastOne = i
        }
    }
    return true
}
```Go 实现镜像了 Python 版本。 这`range`循环提供索引和值，我们检查连续之间的距离`1`以同样的方式。 Go 切片有效地处理数组索引，并且`lastOne`被初始化为`-1`代表没有以前的`1`。
