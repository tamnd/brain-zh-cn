 ## 解决方案

 ## 问题理解

 问题提出了两个数据库表：`NPV`和`Queries`。 这`NPV`表包含由某个项目标识的不同库存项目的历史净现值 (NPV) 数据`id`和一个`year`。 这`Queries`表包含特定年份特定库存项目的 NPV 请求。 中的每一行`Queries`代表单个查询。 

任务是返回一个结果表，其中每个查询来自`Queries`被映射到其对应的`npv`值来自于`NPV`桌子。 如果查询到`(id, year)`对不存在于`NPV`表，该`npv`应默认为`0`。 输出行的顺序没有限制。 

关键点包括主键约束：`(id, year)`在两个表中都是唯一的。 这确保了对于任何`(id, year)`一对，最多有一个匹配的 NPV 记录。 边缘情况涉及查询`(id, year)`中缺失的对`NPV`表，它应该返回零。 

## 方法

 天真的或蛮力方法将涉及迭代中的每个查询`Queries`表并在整个表中执行搜索`NPV`表来查找匹配的`(id, year)`一对。 虽然这保证了正确性，但效率很低，因为时间复杂度为 O(Q * N)，其中`Q`是查询的数量，`N`是行数`NPV`桌子。 对于大型表，这在计算上变得昂贵。 

最佳方法利用基于散列的连接。 通过从以下位置创建字典（哈希图）`NPV`键是元组的表`(id, year)`其值为`npv`，我们可以在常数时间内回答每个查询 O(1)。 这将整体时间复杂度降低到 O(N + Q)，效率更高。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(Q * N) | O(1) | O(1) | 迭代每个查询并搜索 NPV 来匹配 |
 | 最佳 | O(N + Q) | O(N) | 使用哈希图高效存储 NPV 值和查找查询 |

 ## 算法演练

 1.初始化一个空字典`npv_map`这将映射`(id, year)`元组到其对应的`npv`值来自`NPV`桌子。 这允许恒定时间查找。 
2. 迭代每一行`NPV`桌子。 对于每一行，插入一个条目`npv_map`用钥匙`(row.id, row.year)`和价值`row.npv`。 
3.初始化一个空列表`result`来存储最终的输出。 
4. 迭代每一行`Queries`桌子。 对于每个查询`(id, year)`，尝试获取对应的`npv`从`npv_map`。 如果key不存在，则默认为`0`。 
5. 将表示查询及其 NPV 的字典附加到`result`列表。 
6. 返回`result`列表。 

**为什么有效：** 字典保证每个`(id, year)`配对来自`NPV`映射正确。 每个查询的查找时间复杂度为 O(1)。 如果查询中缺少`NPV`，使用默认值`0`确保正确性。 由于每个查询只处理一次，因此所有查询的结果都是正确的。 

## Python 解决方案```python
import pandas as pd

def npv_queries(NPV: pd.DataFrame, Queries: pd.DataFrame) -> pd.DataFrame:
    # Step 1: Build the mapping from (id, year) -> npv
    npv_map = {(row.id, row.year): row.npv for row in NPV.itertuples(index=False)}
    
    # Step 2: Prepare the result list
    result = []
    for row in Queries.itertuples(index=False):
        npv_value = npv_map.get((row.id, row.year), 0)
        result.append({'id': row.id, 'year': row.year, 'npv': npv_value})
    
    # Step 3: Convert to DataFrame
    return pd.DataFrame(result)
```**说明：** 字典理解构造哈希图以进行快速查找。 迭代`Queries`允许我们有效地获取每个 NPV，对于丢失的条目默认为零。 最后将结果列表转换回DataFrame进行提交。 

## 解决方案```go
package main

type NPVRecord struct {
    Id   int
    Year int
    Npv  int
}

type Query struct {
    Id   int
    Year int
}

type Result struct {
    Id   int
    Year int
    Npv  int
}

func NPVQueries(npvTable []NPVRecord, queries []Query) []Result {
    npvMap := make(map[[2]int]int)
    
    // Build the map
    for _, row := range npvTable {
        key := [2]int{row.Id, row.Year}
        npvMap[key] = row.Npv
    }
    
    // Prepare the result
    results := make([]Result, 0, len(queries))
    for _, q := range queries {
        key := [2]int{q.Id, q.Year}
        npvValue, exists := npvMap[key]
        if !exists {
            npvValue = 0
        }
        results = append(results, Result{Id: q.Id, Year: q.Year, Npv: npvValue})
    }
    
    return results
}
```**说明：** Go 使用映射`[2]int`作为存储的密钥`(id, year)`组合。 每个查询使用的查找`exists`处理丢失的键，默认为零。 结果被附加到切片中`Result`。
