[LeetCode 问题 1455](https://leetcode.com/problems/check-if-a-word-occurrs-as-a-prefix-of-any-word-in-a-sentence/)

 **难度：** 🟢简单
 **主题：** 两个指针、字符串、字符串匹配

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的`searchWord`作为句子中任何单词的前缀出现。 句子被定义为由单个空格分隔的小写英文字母的字符串，前缀是单词的任何连续的前导子串。 我们被要求返回以以下开头的句子中第一个单词的 **1 索引位置**`searchWord`。 如果不存在这样的单词，我们返回`-1`。 

输入由一个句子和一个搜索词组成，两者的大小都受到限制（`sentence`长度可达100，`searchWord`长度最大为 10)。 这些约束表明，由于输入很小，性能不是主要问题，但解决方案必须正确处理基本字符串操作。 

重要的边缘情况包括：`searchWord`比句子中任何单词都长，`searchWord`与一个完整的单词相同，`searchWord`匹配多个单词（我们需要第一个），以及只有一个单词的句子。 

## 方法

 蛮力方法很简单：将句子分成单词，然后对于每个单词，检查是否`searchWord`是一个前缀。 这是可行的，因为检查前缀是一个简单的字符串操作。 考虑到限制，这种方法已经很有效了，但从理论上讲，它涉及迭代每个单词的每个字符，直到找到匹配项。 

对于这个问题，最佳方法本质上是相同的，因为输入很小。 我们观察到 Python 和 Go 提供了高效的字符串方法（`startswith`Python 中的切片比较和 Go 中的切片比较）允许在恒定时间内检查每个单词的前缀，因此迭代单词就足够了。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n) | 将句子拆分为单词并检查每个前缀； n 是单词数，m 是 searchWord | 的长度
 | 最佳 | O(n * m) | O(n) | 与暴力破解相同，但有效使用内置前缀检查 |

 ## 算法演练

 1. 分割输入`sentence`按空格转换为单词列表。 
2. 使用 1 索引计数器遍历单词列表。 
3. 对于每个单词，检查它是否以`searchWord`。 
4. 如果找到匹配，立即返回当前索引。 
5. 如果检查完所有单词后没有找到匹配项，则返回`-1`。 

工作原理：该算法保持返回遇到的第一个匹配单词的不变式，满足最小索引的要求。 通过按顺序检查每个单词，不会跳过任何潜在的前缀匹配，从而确保正确性。 

## Python 解决方案```python
class Solution:
    def isPrefixOfWord(self, sentence: str, searchWord: str) -> int:
        words = sentence.split(" ")
        for index, word in enumerate(words, start=1):
            if word.startswith(searchWord):
                return index
        return -1
```Python 解决方案首先使用以下命令将句子拆分为单词`split(" ")`。 然后它从索引 1 开始枚举这些单词。`startswith`方法有效地检查前缀匹配。 第一个匹配的单词触发立即返回，如果没有找到匹配，`-1`被返回。 

## 解决方案```go
func isPrefixOfWord(sentence string, searchWord string) int {
    words := strings.Split(sentence, " ")
    for i, word := range words {
        if len(word) >= len(searchWord) && word[:len(searchWord)] == searchWord {
            return i + 1
        }
    }
    return -1
}
```在 Go 中，我们使用以下方法将句子拆分为单词`strings.Split`。 然后我们迭代每个单词，检查从单词开头到长度的子字符串是否`searchWord`比赛`searchWord`。 索引调整为1索引。 这可以安全地处理空字符串，因为约束保证每个单词中至少有一个字符。

 ## 边缘情况

 1. **单字句子**：如果句子只有一个单词，则该函数必须正确处理 1 索引并检查前缀。 这是通过从索引 1 进行枚举并使用标准字符串方法来管理的。 
2. **SearchWord 比单词长**：如果`searchWord`比句子中的任何单词都长，则不会发生匹配。 执行自然返回`-1`因为`startswith`(Python) 或切片比较 (Go) 安全失败。 
3. **多个匹配单词**：如果多个单词以相同的前缀开头，则算法必须返回第一个。 这是可以保证的，因为函数在找到第一个匹配项后立即返回，保持正确性和最小索引。
