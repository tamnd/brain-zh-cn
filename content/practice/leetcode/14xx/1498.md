[LeetCode 第 1498 题](https://leetcode.com/problems/number-of-subsequences-that-satisfy-the-given-sum-condition/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、二分查找、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定数组的**非空子序列**的数量`nums`这样对于每个子序列，**最小**和**最大**元素的总和小于或等于给定值`target`。 可以通过从数组中删除零个或多个元素而不改变剩余元素的顺序来获得子序列。 由于子序列的数量可以呈指数增长，因此必须以模数形式返回答案$10^9 + 7$。 

输入`nums`是一个整数数组，可能包含重复项，长度可达$10^5$。 每个元素可以大到$10^6$， 和`target`也可以达到$10^6$。 这意味着由于子序列数量呈指数增长，生成所有子序列的强力方法在计算上是不可行的。 

关键点包括处理重复元素、确保子序列非空以及有效地计算子序列而不枚举所有子序列。 边缘情况包括非常小的数组，所有元素都大于的数组`target`，以及所有元素都小于一半的数组`target`。 

## 方法

 **暴力方法**将生成以下的所有子序列`nums`，计算每个的最小值和最大值，并计算满足总和条件的数。 虽然这是正确的，但它是不切实际的，因为生成长度数组的所有子序列`n`需要$O(2^n)$时间，对于`n = 10^5`。 

**最佳方法**利用**排序**和**双指针技术**与**预先计算的二的幂**相结合。 排序使我们能够轻松识别潜在子序列中的最小和最大元素。 使用两个指针，一个从左侧开始 (`l`）和右边的一个（`r`），我们可以计算可以形成多少个子序列`nums[l]`作为最小值和之间的任何元素`l`和`r`作为最大值。 每个有效对的子序列数由下式给出$2^{r-l}$，代表其间元素的所有组合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 生成所有子序列并检查每个子序列的最小+最大条件 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 排序 + 两个指针 + 预先计算 2 的幂以计算子序列 |

 ## 算法演练

 1. 对输入数组进行排序`nums`按升序排列。 这允许有效确定子序列的有效最小和最大元素。 
2. 预先计算 2 模的幂$10^9 + 7$最多`n`因为每个子序列计数都需要计算$2^k$迅速地。 
3.初始化两个指针：`l = 0`对于最左边（最小）元素和`r = n-1`对于最右边（潜在的最大值）元素。 
4. 初始化`count = 0`存储有效子序列的总数。 
5. 虽然`l <= r`，检查是否`nums[l] + nums[r] <= target`：

 1. 如果是，则所有包含的子序列`nums[l]`作为最小值和之间的元素的任何子集`l+1`和`r`是有效的。 增量`count`经过`2^(r-l)`模数$10^9 + 7$。 移动`l`向右移动 1。 
2. 如果否，则当前`r`太大，无法配对`l`。 移动`r`向左移动 1。 
6. 返回`count`。 

**为什么它有效：** 排序保证对于固定的`l`， 如果`nums[l] + nums[r] > target`，右侧任何较大的值都不能形成有效的子序列。 通过计数$2^{r-l}$，我们考虑两个指针之间的所有元素组合。 这确保所有有效子序列都被精确计数一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def numSubseq(self, nums: List[int], target: int) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        nums.sort()
        
        # Precompute powers of 2 modulo MOD
        pow2 = [1] * n
        for i in range(1, n):
            pow2[i] = (pow2[i-1] * 2) % MOD
        
        l, r = 0, n - 1
        count = 0
        
        while l <= r:
            if nums[l] + nums[r] <= target:
                count = (count + pow2[r-l]) % MOD
                l += 1
            else:
                r -= 1
        
        return count
```该实现首先对数组进行排序，预先计算 2 的幂以实现高效的子序列计数，并使用两个指针来遍历数组。 如果最小和最大元素和有效，则计算当前元素形成的所有子序列`l`以及任何元素`r`。 不然会减少`r`尝试较小的最大元素。 

## 解决方案```go
func numSubseq(nums []int, target int) int {
    const MOD = 1000000007
    n := len(nums)
    sort.Ints(nums)
    
    pow2 := make([]int, n)
    pow2[0] = 1
    for i := 1; i < n; i++ {
        pow2[i] = (pow2[i-1] * 2) % MOD
    }
    
    l, r := 0, n-1
    count := 0
    
    for l <= r {
        if nums[l]+nums[r] <= target {
            count = (count + pow2[r-l]) % MOD
            l++
        } else {
            r--
        }
    }
    
    return count
}
```Go 解决方案与 Python 解决方案密切相关。 差异包括切片初始化和整数算术模$10^9 + 7$。 排序用途`sort.Ints`，并且切片索引很简单。 在每次乘法时使用模来避免溢出。
