[LeetCode 第 1482 题](https://leetcode.com/problems/minimum-number-of-days-to-make-m-bouquets/)

 **难度：** 🟡 中等
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定从不同日期开花的花园中制作给定数量的花束所需的最少天数。 我们提供了一个数组`bloomDay`， 在哪里`bloomDay[i]`表示日期`i`第朵花绽放。 一束花恰好由以下部分组成`k`**相邻的花**，我们需要准确地制作`m`花束。 输出是可以创建所有内容的最短日期`m`花束。 如果没有足够的鲜花来满足要求（`m * k > n`），我们返回`-1`。 

该问题本质上结合了两个约束：花束中花朵的相邻性和各个开花天数。 我们必须仔细跟踪特定日期有哪些鲜花可用，并确保它们可以形成必要的花束。 约束表明数组大小最多可达`10^5`开花天数可能非常长（`10^9`），因此日复一日检查的简单解决方案效率很低。 关键的边缘情况包括以下情况`m * k > n`（不可能的情况），`k = 1`（最简单的邻接要求），或者所有花在同一天开花。 

## 方法

 **蛮力方法**需要日复一日地迭代，检查哪些花已经盛开，并计算每天可以制作多少花束。 这保证了正确性，但速度太慢，因为开花天数可以达到`10^9`和数组大小`10^5`。 迭代可能数十亿天的时间是不可行的。 

**最佳方法**利用**对答案进行二分搜索**。 我们知道最短日数必须介于最早开花和最晚开花之间。 对于任何候选人日，我们都可以有效地检查是否可以形成`m`通过计算已盛开的连续花朵块来计算花束。 通过根据可行性调整搜索范围，我们可以有效地收敛到最小日。 这是一种标准的“决策问题”技术，其中单调属性（更多天总是允许至少同样多的花束）允许二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(D * n), D = max(bloomDay) | O(D * n), D = max(bloomDay) | O(1) | O(1) | 每天检查是否可以形成花束，对于大的最大bloomDay来说非常慢|
 | 最佳 | O(n log(max(bloomDay))) | O(n log(max(bloomDay))) | O(1) | O(1) | 数天的二分搜索，每次都用线性扫描检查可行性 |

 ## 算法演练

 1. **初步检查**：如果`m * k > n`， 返回`-1`立即，因为没有足够的花朵来形成所需的花束。 
2. **二分查找设置**：定义`left`作为最短开花日和`right`作为最大开花日。 
3. **可行性检查**：编写辅助函数`canMake(day)`返回`True`如果我们至少可以形成`m`给定的花束`day`。 扫描`bloomDay`数组，计算连续盛开的花朵，并且每当`k`找到连续的花，增加花束计数并重置连续计数器。 
4. **二分查找执行**：While`left < right`,检查中间日`mid = (left + right) // 2`。 如果`canMake(mid)`为真，设定`right = mid`找到一个更小的可行日。 否则，设置`left = mid + 1`。 
5. **返回结果**：二分查找后，`left`将保留最少的天数`m`花束。 返回`left`。 

**为什么有效**：二分查找之所以有效是因为该函数`canMake(day)`是单调的。 如果当天可以制作花束的话`d`，也有可能在任何一天`> d`。 这就保证了二分查找找到的第一个可行日确实是最小的。 

## Python 解决方案```python
from typing import List

class Solution:
    def minDays(self, bloomDay: List[int], m: int, k: int) -> int:
        n = len(bloomDay)
        if m * k > n:
            return -1
        
        def canMake(day: int) -> bool:
            bouquets = 0
            consecutive = 0
            for bloom in bloomDay:
                if bloom <= day:
                    consecutive += 1
                    if consecutive == k:
                        bouquets += 1
                        consecutive = 0
                else:
                    consecutive = 0
            return bouquets >= m
        
        left, right = min(bloomDay), max(bloomDay)
        while left < right:
            mid = (left + right) // 2
            if canMake(mid):
                right = mid
            else:
                left = mid + 1
        return left
```**说明**：我们首先检查花的数量是否足够。 这`canMake`函数执行单次传递`bloomDay`计算可能的花束，只要候选日当天某朵花没有盛开，就重置连续的花。 然后，二分搜索有效地找到最小可行日。 

## 解决方案```go
func minDays(bloomDay []int, m int, k int) int {
    n := len(bloomDay)
    if m*k > n {
        return -1
    }

    minDay, maxDay := bloomDay[0], bloomDay[0]
    for _, day := range bloomDay {
        if day < minDay {
            minDay = day
        }
        if day > maxDay {
            maxDay = day
        }
    }

    canMake := func(day int) bool {
        bouquets, consecutive := 0, 0
        for _, bloom := range bloomDay {
            if bloom <= day {
                consecutive++
                if consecutive == k {
                    bouquets++
                    consecutive = 0
                }
            } else {
                consecutive = 0
            }
        }
        return bouquets >= m
    }

    left, right := minDay, maxDay
    for left < right {
        mid := (left + right) / 2
        if canMake(mid) {
            right = mid
        } else {
            left = mid + 1
        }
    }
    return left
}
```**Go Notes**：我们明确计算`minDay`和`maxDay`因为 Go 缺乏内置的`min`或者`max`对于切片。 这`canMake`函数和二分查找逻辑与Python相同。 小心处理切片和整数除法可以避免差一错误。 

## 工作示例

 **示例1**：`bloomDay = [1,10,3,10,2], m = 3, k = 1`二分查找范围：左=1，右=10。 检查中点和可行性：

 | 日 | 可以做花束吗？ | 评论 |
 | --- | --- | --- |
 | 5 | 是的 | 花 <= 5: [1, _, 3, _, 2]，可以制作 3 束花 |
 | 3 | 是的 | 花 <= 3: [1, _, 3, _, 2]，可以制作 3 束花 |
 | 2 | 没有 | 花 <= 2：[1, _, _, _, 2]，可以制作 2 束花 |

 找到的最小天数为 3。 

**示例2**：`bloomDay = [1,10,3,10,2], m = 3, k = 2`所需花数 = 3 * 2 = 6，总花数 = 5 → 立即返回-1。 

**示例3**：`bloomDay = [7,7,7,7,12,7,7], m = 2, k = 3`二分查找发现第 12 天是获得 3 朵相邻花的 2 束花的最低限度。
