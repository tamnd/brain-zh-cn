[LeetCode 问题 1433](https://leetcode.com/problems/check-if-a-string-can-break-another-string/)

 **难度：** 🟡 中等
 **主题：** 字符串、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定一个字符串是否可以通过某种排列“破坏”另一个字符串。 给定两个字符串`s1`和`s2`长度相等的字符串`x`可以断弦`y`如果按某种顺序排列两个字符串后，其中的每个字符`x`大于或等于中对应的字符`y`按字母顺序比较时。 换句话说，对于所有指数`i`,`x[i] >= y[i]`。 

输入由两个长度相同的小写英文字符串组成`n`在哪里`1 <= n <= 10^5`。 输出是一个布尔值，指示是否存在排列`s1`可以打破排列`s2`，或反之亦然。 这些约束允许字符串最多 100,000 个字符，因此具有阶乘甚至二次复杂度的算法是不可行的。 

要考虑的边缘情况包括所有字符都相同的字符串、已按相反顺序排序的字符串以及长度最小的字符串 (`n = 1`）。 该问题保证两个字符串的长度相同，因此我们不需要处理长度不匹配的情况。 

## 方法

 暴力方法会产生所有排列`s1`和`s2`然后检查每一对，看看其中一个是否可以打破另一个。 这种方法在理论上是正确的，因为它详尽地检查了所有可能性，但时间复杂度是阶乘的，`O(n!)`，使其完全不切实际`n`最多`10^5`。 

关键的见解是我们不需要检查所有排列。 对两个字符串进行排序提供了一种保留字符相对顺序的规范形式。 如果一个排序版本`s1`可以破坏排序版本`s2`在每个索引处，都存在一些排列`s1`可以打破`s2`。 同样的逻辑也适用于相反的方向。 这将问题简化为简单地对两个字符串进行排序并执行线性扫描来验证中断条件。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((n!)^2) | O((n!)^2) | O(n!) | 生成所有排列`s1`和`s2`并比较每一对 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对两个字符串进行排序并逐个字符进行比较 |

 ## 算法演练

 1. **对两个字符串进行排序**：转换`s1`和`s2`到排序的字符列表中。 排序确保我们考虑最大化一个字符串破坏另一个字符串的机会的排列。 
2. **初始化标志**：设置两个布尔标志，`s1_can_break_s2`和`s2_can_break_s1`， 到`True`。 这些标志将跟踪是否`s1`可以打破`s2`以及是否`s2`可以打破`s1`。 
3. **比较字符**：迭代已排序字符串的索引。 在每个索引处`i`， 比较`s1[i]`和`s2[i]`。 如果`s1[i] < s2[i]`， 然后`s1`不能打破`s2`，所以设`s1_can_break_s2`到`False`。 相反，如果`s2[i] < s1[i]`， 然后`s2`不能打破`s1`，所以设`s2_can_break_s1`到`False`。 
4. **返回结果**：迭代后，如果有`s1_can_break_s2`或者`s2_can_break_s1`是`True`， 返回`True`。 否则，返回`False`。 

**为什么有效**：排序可确保我们考虑每个字符串的排列，从而最大限度地发挥其破坏另一个字符串的潜力。 如果没有一个排序排列可以破坏另一个排列，那么其他排列也不能破坏另一个排列，因此这种方法保证了正确性。 

## Python 解决方案```python
class Solution:
    def checkIfCanBreak(self, s1: str, s2: str) -> bool:
        sorted_s1 = sorted(s1)
        sorted_s2 = sorted(s2)
        
        s1_can_break_s2 = True
        s2_can_break_s1 = True
        
        for c1, c2 in zip(sorted_s1, sorted_s2):
            if c1 < c2:
                s1_can_break_s2 = False
            if c2 < c1:
                s2_can_break_s1 = False
                
        return s1_can_break_s2 or s2_can_break_s1
```此实现对两个字符串进行排序，初始化标志，并迭代比较它们的字符。 使用`zip`允许对两个已排序的字符串进行干净的一次性迭代。 如果在任何索引处一个字符串小于另一个字符串，则更新相应的标志。 结果返回为`True`如果其中一根绳子可以折断另一根绳子。 

## 解决方案```go
import "sort"

func checkIfCanBreak(s1 string, s2 string) bool {
    s1Runes := []rune(s1)
    s2Runes := []rune(s2)
    
    sort.Slice(s1Runes, func(i, j int) bool { return s1Runes[i] < s1Runes[j] })
    sort.Slice(s2Runes, func(i, j int) bool { return s2Runes[i] < s2Runes[j] })
    
    s1CanBreakS2 := true
    s2CanBreakS1 := true
    
    for i := 0; i < len(s1Runes); i++ {
        if s1Runes[i] < s2Runes[i] {
            s1CanBreakS2 = false
        }
        if s2Runes[i] < s1Runes[i] {
            s2CanBreakS1 = false
        }
    }
    
    return s1CanBreakS2 || s2CanBreakS1
}
```Go 版本将字符串作为符文片段来处理，以进行安全的字符比较。 排序是使用完成的`sort.Slice`，迭代逻辑反映了 Python 实现。 Go 没有`zip`等价的，所以传统的`for`使用带索引的循环。
