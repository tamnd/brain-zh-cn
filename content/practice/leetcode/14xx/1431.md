[LeetCode 第 1431 题](https://leetcode.com/problems/kids-with-the-greatest-number-of-candies/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定如果我们向任何一个孩子分发固定数量的额外糖果，哪些孩子可能拥有最多数量的糖果。 输入是一个数组`candies`其中每个元素代表特定孩子拥有的糖果数量，以及一个整数`extraCandies`代表可以给予的额外糖果。 输出应该是一个布尔数组`result`与相同长度`candies`，其中每个元素是`true`如果给予所有`extraCandies`该孩子将使他们的总计数大于或等于当前最大值，并且`false`否则。 

约束条件告诉我们`n`范围从 2 到 100，糖果数量范围从 1 到 100，这足够小以允许简单的线性扫描解决方案。 重要的边缘情况包括多个孩子拥有相同最大糖果数量的情况，其中`extraCandies`很小（例如 1），或者孩子已经拥有最大数量的糖果而没有额外的糖果。 

## 方法

 蛮力方法将涉及对每个孩子添加`extraCandies`然后将这个新总数与其他孩子的糖果数量进行比较。 虽然这是正确的，但它需要嵌套循环并且需要 O(n²) 时间，这对于给定的约束是不必要的。 

最佳方法依赖于简单的观察，即我们不需要反复将每个孩子与所有其他孩子进行比较。 相反，我们可以首先计算任何孩子当前拥有的最大糖果数量。 然后，对于每个孩子，我们只需检查他们当前的糖果是否加上`extraCandies`达到或超过这个最大值。 这将时间复杂度降低到 O(n) 并为结果数组使用 O(n) 空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 将每个孩子的新总数与所有其他孩子进行比较 |
 | 最佳| O(n) | O(n) | 计算一次 max，然后将每个子项与 max + extraCandies | 进行比较

 ## 算法演练

 1. 初始化变量`maxCandies`到最大值`candies`大批。 这代表了目前所有孩子持有的糖果数量最多的纪录。 
2.初始化一个空列表`result`为每个孩子存储布尔值。 
3. 迭代每个孩子的糖果数：

 1.添加`extraCandies`到孩子当前的计数。 
2. 将此总数与`maxCandies`。 
3. 如果大于或等于`maxCandies`, 附加`true`到`result`。 
4. 否则，追加`false`。 
4. 返回`result`列表。 

**为什么有效：** 该算法之所以有效，是因为对每个孩子来说唯一重要的是添加后他们的糖果总数是否为`extraCandies`达到或超过当前最大值。 通过预先计算一次最大值，我们避免了冗余比较并确保每个决策都是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
        maxCandies = max(candies)
        result = []
        for candy in candies:
            result.append(candy + extraCandies >= maxCandies)
        return result
```Python 实现首先计算最大糖果数量。 然后，对于每个孩子，它会检查给他们所有额外的糖果是否至少等于最大值。 该布尔表达式直接附加到最终返回的结果列表中。 

## 解决方案```go
func kidsWithCandies(candies []int, extraCandies int) []bool {
    maxCandies := candies[0]
    for _, candy := range candies {
        if candy > maxCandies {
            maxCandies = candy
        }
    }
    
    result := make([]bool, len(candies))
    for i, candy := range candies {
        result[i] = candy + extraCandies >= maxCandies
    }
    
    return result
}
```Go 解决方案反映了 Python 方法。 它首先使用一个简单的循环找到最大糖果数。 然后它初始化一个布尔切片`result`并通过比较每个孩子的总数来填充它`maxCandies`。 Go 处理切片的方式与 Python 列表不同，但逻辑是相同的。

 ## 边缘情况

 一种重要的边缘情况是多个孩子已经拥有最大糖果数。 如果没有额外的糖果，他们应该都会回来`true`如果额外的足够大。 该实现通过将每个子项的新总数与预先计算的最大值进行比较来处理此问题。 

另一个边缘情况是当`extraCandies`为零。 这测试了实现是否正确识别已经达到最大值的子级。 算法正确返回`true`仅适用于糖果数量等于最大值的人。 

第三种边缘情况是当`extraCandies`太大以至于所有的孩子都超过了原来的最大值。 该解决方案自动将所有孩子标记为`true`因为比较`candy + extraCandies >= maxCandies`自然评估为`true`对于所有元素。 这确保了正确性，无需任何特殊处理。
