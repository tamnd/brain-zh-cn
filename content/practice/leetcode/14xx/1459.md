## 问题理解

 这个问题要求我们识别所有可能的**轴对齐矩形**，这些矩形可以使用数据库表中的点对形成。 中的每个点`Points`table 表示二维平面中的坐标，其中`x_value`和一个`y_value`。 

关键的观察是每个矩形由**两个相对的角点**定义。 由于矩形必须**轴对齐**，因此其边必须平行于 x 轴和 y 轴。 这意味着两个对角的 x 坐标和 y 坐标必须不同。 如果任一坐标相同，则矩形将折叠成线段并且面积为零，这是明确无效的。 

输入由名为的数据库表组成`Points`三列：

 | 专栏 | 意义|
 | ---| ---|
 |`id`| 点的唯一标识符 |
 |`x_value`| X坐标|
 |`y_value`| Y坐标|

 输出应包含：

 | 专栏 | 意义|
 | ---| ---|
 |`p1`| 第一个点 ID |
 |`p2`| 第二个点 ID |
 |`area`| 矩形面积|

 矩形面积计算如下：$$|x_1 - x_2| \times |y_1 - y_2|$$结果必须满足三个排序条件：

 1. 排序依据`area`按降序排列。 
2. 如果面积相等，则排序`p1`按升序排列。 
3. 如果仍然平局，则排序`p2`按升序排列。 

一个重要的微妙之处是我们只想要**唯一的对角对**。 自从`(p1, p2)`和`(p2, p1)`代表同一个矩形，我们应该只对每一对计数一次。 共同的策略是执行`p1.id < p2.id`。 

有几个重要的边缘情况。 如果两个点共享相同的 x 坐标，则宽度变为零，从而生成必须排除的零面积矩形。 类似地，如果两个点共享相同的 y 坐标，则高度为零且矩形无效。 该问题保证了唯一的点标识符，但坐标本身可能会跨行重复。 

## 方法

 ### 蛮力方法

 一种简单的方法会考虑每对可能的点，并确定它们是否可以形成轴对齐的矩形。 

对于每对`(point1, point2)`，我们计算：

 宽度：`abs(x1 - x2)`- 高度：`abs(y1 - y2)`如果两个值均非零，则该对定义有效矩形的对角。 

这种方法是正确的，因为每个有效的矩形必须恰好由一对对角确定。 通过检查每一对，我们保证不会遗漏任何有效的矩形。 

但是，如果不仔细过滤，我们会生成重复的结果，因为`(A, B)`和`(B, A)`代表同一个矩形。 我们通过将搜索限制为对来解决这个问题`p1.id < p2.id`。 

尽管这听起来很暴力，但它已经足够高效了，因为检查所有点对只需要二次时间。 

### 高效解决方案的关键见解

 重要的观察是我们不需要任何复杂的几何算法。 每个矩形都是通过选择两个对角来唯一确定的。 

由于我们只关心**轴对齐的矩形**，有效性变得非常简单：

 - x 值必须不同
 - y 值必须不同

 这将问题变成了 SQL 中的**自连接**问题。 

我们可以加入`Points`表与自身，强制执行`p1.id < p2.id`为了避免重复，过滤掉零面积矩形，直接计算面积，然后根据所需的顺序进行排序。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 比较每对点 |
 | 最佳 SQL 自连接 | O(n²) | O(1) | O(1) | 使用自连接进行过滤和排序 |

 实际上，这两种方法本质上是相同的想法。 最佳 SQL 公式只是使用关系运算有效地表达成对比较。 

## 算法演练

 1. 执行自连接`Points`桌子。 

我们将表与其自身连接起来，因为我们需要将每个点与其他点进行比较。 
2. 限制配对使用`p1.id < p2.id`。 

这确保每个矩形仅被计数一次。 如果没有这个限制，`(1,2)`和`(2,1)`都会出现，导致重复。 
3. 过滤掉无效的矩形。 

我们只在以下情况下保留对：

 -`p1.x_value != p2.x_value`-`p1.y_value != p2.y_value`如果任一坐标匹配，则矩形的宽度或高度为零，从而使面积为零。 
4. 计算矩形面积。 

使用：```
ABS(p1.x_value - p2.x_value) *
ABS(p1.y_value - p2.y_value)
```无论点排序如何，绝对值都能保证正面积。 
5. 返回所需的列。 

选择：

-`p1.id AS p1`-`p2.id AS p2`- 计算面积
 6. 对结果进行排序。 

订购方式：

 -`area DESC`-`p1 ASC`-`p2 ASC`### 为什么它有效

 该算法之所以有效，是因为每个轴对齐的矩形都由一对 x 和 y 坐标不同的对角唯一标识。 通过考虑所有独特的点对并过滤掉宽度或高度为零的退化情况，我们精确地枚举了所有有效的矩形。 排序步骤确保输出满足问题要求。 

## SQL 解决方案```sql
SELECT
    p1.id AS p1,
    p2.id AS p2,
    ABS(p1.x_value - p2.x_value) *
    ABS(p1.y_value - p2.y_value) AS area
FROM Points p1
JOIN Points p2
    ON p1.id < p2.id
WHERE p1.x_value != p2.x_value
  AND p1.y_value != p2.y_value
ORDER BY area DESC, p1 ASC, p2 ASC;
```解决方案首先加入`Points`表与自身。 使用`p1.id < p2.id`防止重复的矩形表示并避免将点与其自身配对。 

这`WHERE`子句删除由于匹配 x 值或 y 值而面积为零的无效矩形。 

面积计算使用 x 坐标之间的绝对差乘以 y 坐标之间的绝对差。 最后，根据需要的排序规则对结果进行排序。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n²) | 自连接比较所有唯一的点对 |
 | 空间| O(1) | O(1) | 没有使用额外的数据结构 |

 主要成本来自自连接，它从概念上将每个点与其他点进行比较。 由于大约有`n(n−1)/2`唯一的对，运行时间是二次的。 额外的内存使用量是恒定的，因为我们仅在查询执行期间直接计算值。 

## 测试用例```python
def rectangles_area(points):
    result = []

    n = len(points)

    for i in range(n):
        for j in range(i + 1, n):
            id1, x1, y1 = points[i]
            id2, x2, y2 = points[j]

            if x1 != x2 and y1 != y2:
                area = abs(x1 - x2) * abs(y1 - y2)
                result.append((id1, id2, area))

    result.sort(key=lambda x: (-x[2], x[0], x[1]))
    return result

 ## 边缘情况

 ### 共享相同 X 坐标的点

 如果两个点具有相同的 x 坐标，则矩形宽度为零。 如果幼稚的实现仅计算面积而不进行验证，则可能会意外地包含此类情况。 该解决方案显式过滤使用`p1.x_value != p2.x_value`，防止无效矩形。 

### 共享相同 Y 坐标的点

 类似地，相同的 y 坐标产生零高度。 这是错误的另一个常见来源，因为乍一看这对在几何上仍然有效。 查询排除了这些情况`p1.y_value != p2.y_value`。 

### 重复矩形生成

 不限制对`p1.id < p2.id`，同一个矩形会出现两次，一次为`(A,B)`并一度作为`(B,A)`。 这会产生不正确的输出，并可能破坏订购预期。 该实现通过始终首先选择较小的 id 来保证唯一性。 

### 负坐标

 坐标可能为负值，如果直接使用减法，可能会导致面积计算不正确。 使用`ABS(x1 - x2)`和`ABS(y1 - y2)`保证面积保持正值，无论点排序或坐标符号如何。
