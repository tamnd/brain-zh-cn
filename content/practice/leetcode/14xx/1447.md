[LeetCode 1447 题](https://leetcode.com/problems/simplified-fractions/)

 **难度：** 🟡 中等
 **主题：** 数学、字符串、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们生成 0 到 1（不包括）之间的所有**简化分数**，其中分母不超过给定的整数`n`。 简化分数是分子和分母互质的分数，这意味着它们的最大公约数 (GCD) 为 1。例如，`2/4`没有被简化，因为它简化为`1/2`。 输入是单个整数`n`，表示允许的最大分母，输出是表示所有有效简化分数的字符串列表。 输出中分数的顺序并不重要。 

限制条件是`1 <= n <= 100`，这表明输入大小很小，因此迭代所有可能的分子分母对的直接方法是可行的。 重要的边缘情况包括`n = 1`，其中 0 和 1 之间没有分数，并且`n = 2`，这是产生有效分数的最小情况（`1/2`）。 

## 方法

 **暴力方法**很简单：迭代所有整数对`(numerator, denominator)`在哪里`1 <= numerator < denominator <= n`并通过计算分子和分母的 GCD 来检查分子和分母是否互质。 如果它们互质，则将分数包含在结果中。 这种方法保证了正确性，因为它检查了每个可能简化的分数。 

**最佳解决方案的关键见解**是检查每对的 GCD 已经对于`n <= 100`，但是我们可以通过仅生成小于分母的分子的分数来稍微改进，从而避免不必要的迭代。 除此之外，问题足够小，使用 GCD 检查进行暴力破解实际上是最优的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * log(max(分子, 分母))) | O(n^2) | O(n^2) | 迭代所有分子分母对并通过 GCD 检查互质 |
 | 最佳| O(n^2 * log n) | O(n^2 * log n) | O(n^2) | O(n^2) | 与暴力破解相同； 通过跳过分子 >= 分母 | 进行优化

 ## 算法演练

 1.初始化一个空列表`result`存储简化分数字符串。 
2. 循环遍历每个`denominator`从 2 到`n`包容性。 从 2 开始，因为分母为 1 的分数不在 0 和 1 之间。 
3. 对于每个分母，循环`numerator`从 1 到`denominator - 1`。 这可确保所有分数都严格小于 1。 
4. 对于每个`(numerator, denominator)`对，计算分子和分母的 GCD。 
5. 如果 GCD 等于 1，则分数被简化。 将其转换为以下格式的字符串`"numerator/denominator"`并将其附加到`result`。 
6.所有循环结束后，返回`result`。 

**为什么有效：** 通过迭代所有可能的分子分母对（其中分子小于分母）并过滤掉非互质对，我们确保所有分数都是唯一的、简化的并且严格在 0 和 1 之间。GCD 检查保证没有分数可以进一步减少。 

## Python 解决方案```python
from typing import List
from math import gcd

class Solution:
    def simplifiedFractions(self, n: int) -> List[str]:
        result = []
        for denominator in range(2, n + 1):
            for numerator in range(1, denominator):
                if gcd(numerator, denominator) == 1:
                    result.append(f"{numerator}/{denominator}")
        return result
```Python 实现完全遵循该算法。 我们进口`gcd`从`math`互质性检查模块。 外循环从 2 开始迭代分母，内循环迭代小于分母的分子。 只有 GCD 1 的分数才会作为字符串包含在最终结果中。 

## 解决方案```go
package main

import (
    "fmt"
    "strconv"
)

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func simplifiedFractions(n int) []string {
    result := []string{}
    for denominator := 2; denominator <= n; denominator++ {
        for numerator := 1; numerator < denominator; numerator++ {
            if gcd(numerator, denominator) == 1 {
                fraction := strconv.Itoa(numerator) + "/" + strconv.Itoa(denominator)
                result = append(result, fraction)
            }
        }
    }
    return result
}
```在Go中，我们使用Euclid算法手动实现GCD函数。 我们将结果构建为字符串切片。 循环逻辑反映了 Python 版本。 字符串转换是使用完成的`strconv.Itoa`，并且切片随着分数的添加而动态增长。

 ## 边缘情况

 **边缘情况 1：n = 1**

 0 和 1 之间不存在分母 ≤ 1 的分数。实现通过在 2 处启动分母循环来正确返回空列表。 

**边缘情况 2：分数可简化为更小的分数**

 像这样的分数`2/4`必须排除。 GCD 检查保证只包含互质分子分母对。 

**边缘情况 3：大 n 接近约束极限**

 对于`n = 100`，有很多分子分母对。 该算法使用简单的循环和 GCD 检查来有效地处理这个问题，并且结果列表会动态增长以容纳所有简化的分数，而不会超出内存限制。
