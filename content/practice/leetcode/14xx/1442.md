[LeetCode 问题 1442](https://leetcode.com/problems/count-triplets-that-can-form-two-arrays-of-equal-xor/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、数学、位操作、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们找到三元组的数量`(i, j, k)`在一个数组中`arr`这样索引中元素的异或`i`到`j-1`等于索引中元素的异或`j`到`k`。 正式来说，为了`0 <= i < j <= k < arr.length`， 定义：```
a = arr[i] ^ arr[i+1] ^ ... ^ arr[j-1]
b = arr[j] ^ arr[j+1] ^ ... ^ arr[k]
```我们需要计算所有三元组`a == b`。 

输入是一个一维整数数组，长度最大为300，每个元素最多为`10^8`。 输出是一个表示有效三元组数量的整数。 

主要观察结果包括：

 1. XOR 运算具有结合性和交换性，这使得我们可以使用**前缀 XOR 和**来有效地计算范围。 
2. 边缘情况包括具有相同元素的数组、非常短的数组或不存在三元组的数组。 
3. 约束允许 O(n^2) 解决方案，但 O(n^3) 暴力方法可能太慢。 

## 方法

 ### 蛮力

 蛮力解决方案迭代所有可能的三元组`(i, j, k)`并计算`a`和`b`直接通过迭代子数组。 虽然正确，但此方法具有三个嵌套循环，时间复杂度为 O(n^3)。 对于 n = 300，这可能涉及多达 2700 万次迭代，效率很低。 

### 最佳方法

 关键的见解是使用**前缀 XOR**。 定义`prefixXOR[x]`作为从索引 0 到 x-1 的所有元素的 XOR。 然后，任意子数组的异或`arr[i:j]`可以在 O(1) 中计算为：```
arr[i] ^ ... ^ arr[j] = prefixXOR[j+1] ^ prefixXOR[i]
```我们可以重写条件`a == b`作为：```
prefixXOR[j] ^ prefixXOR[i] == prefixXOR[k+1] ^ prefixXOR[j]
```简化给出：```
prefixXOR[i] == prefixXOR[k+1]
```这使我们能够修复`i`和`k`然后计算有效的数量`j`之间的值。 每对`(i, k)`在哪里`prefixXOR[i] == prefixXOR[k+1]`贡献`(k - i)`有效的三元组。 这将时间复杂度降低到 O(n^2)。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 显式检查所有三元组 |
 | 最佳| O(n^2) | O(n^2) | O(n) | 使用前缀 XOR 并计算有效范围 |

 ## 算法演练

 1. 初始化一个`prefixXOR`长度数组`n+1`， 和`prefixXOR[0] = 0`。 
2. 计算`prefixXOR[i+1] = prefixXOR[i] ^ arr[i]`为所有人`i`从 0 到 n-1。 这存储直到但不包括索引 i+1 的所有元素的 XOR。 
3. 初始化计数器`count = 0`。 
4. 迭代所有`i`从 0 到 n-1。 
5. 对于每个`i`, 迭代所有`k`从`i+1`至n-1。 
6. 如果`prefixXOR[i] == prefixXOR[k+1]`， 添加`(k - i)`到`count`。 
7. 返回`count`。 

**为什么有效**：XOR 具有以下属性：`x ^ x = 0`和`x ^ 0 = x`。 By computing prefix XOR, we reduce the problem of comparing two subarrays to a simple equality check between`prefixXOR[i]`和`prefixXOR[k+1]`。 有效数量`j`之间的指数`i`和`k`正是`(k - i)`。 

## Python 解决方案```python
from typing import List

class Solution:
    def countTriplets(self, arr: List[int]) -> int:
        n = len(arr)
        prefixXOR = [0] * (n + 1)
        
        for i in range(n):
            prefixXOR[i + 1] = prefixXOR[i] ^ arr[i]
        
        count = 0
        for i in range(n):
            for k in range(i + 1, n):
                if prefixXOR[i] == prefixXOR[k + 1]:
                    count += (k - i)
        
        return count
```**解释**：我们首先计算`prefixXOR`允许 O(1) 子数组异或计算。 然后我们迭代所有可能的对`(i, k)`并检查它们是否满足条件。 每个有效对都贡献`(k - i)`三胞胎。 

## 解决方案```go
func countTriplets(arr []int) int {
    n := len(arr)
    prefixXOR := make([]int, n+1)
    
    for i := 0; i < n; i++ {
        prefixXOR[i+1] = prefixXOR[i] ^ arr[i]
    }
    
    count := 0
    for i := 0; i < n; i++ {
        for k := i + 1; k < n; k++ {
            if prefixXOR[i] == prefixXOR[k+1] {
                count += k - i
            }
        }
    }
    
    return count
}
```**Go 特定注释**：切片`prefixXOR`是预先分配的`make`并自动初始化为零。 整数溢出不是问题，因为 Go 默认使用 64 位整数对切片进行异或运算`int`。 

## 工作示例

 ### 示例 1：arr = [2,3,1,6,7]

 计算`prefixXOR`:`[0, 2, 1, 0, 6, 1]`。 

迭代`(i, k)`对：

 | 我| k | 前缀XOR[i] | 前缀XOR[k+1] | k-i | 加起来算吗？ |

 | 0 | 2 | 0 | 0 | 2 | 是的，计数+=2 |
 | 0 | 3 | 0 | 6 | 3 | 没有 |
 | 0 | 4 | 0 | 1 | 4 | 没有 |
 | 1 | 2 | 2 | 0 | 1 | 没有 |

 | 1 | 4 | 2 | 1 | 3 | 没有 |

 | 2 | 4 | 1 | 1 | 2 | 是的，计数+=2 |

### 示例 2：arr = [1,1,1,1,1]

 计算`prefixXOR`:`[0,1,0,1,0,1]`。 

遵循相同的逻辑，每一对`(i,k)`在哪里`prefixXOR[i] == prefixXOR[k+1]`贡献`k-i`三胞胎。 总计数 = 10。
