[LeetCode 问题 1558](https://leetcode.com/problems/minimum-numbers-of-function-calls-to-make-target-array/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、位操作

 ## 解决方案

 ## 问题理解

 这个问题要求我们变换一个初始数组`arr`将零放入目标数组中`nums`使用最少数量的操作。 有两种允许的操作：将数组的任何单个元素递增 1，或将数组的所有元素加倍。 目标是计算达到目标所需的最小总操作数`nums`。 

输入`nums`是一个长度可达的整数数组`10^5`，每个元素可以大到`10^9`。 输出是一个表示最小函数调用次数的整数。 边缘情况包括元素为零、值全部相等的数组或值非常大且需要多次加倍的数组。 

该问题保证答案符合 32 位有符号整数，因此我们无需担心整数溢出。 

需要注意的要点是，加倍会同时影响所有元素，而递增会影响单个元素。 这意味着模拟每个操作的简单方法`0`到`nums[i]`会太慢。 

## 方法

 暴力方法将直接模拟该过程：重复检查哪些元素需要递增以及何时应用加倍操作。 对于每次加倍，我们都会将所有非零元素加倍，并单独增加其他元素。 这可以正确工作，但对于大量数据来说效率非常低，因为我们最多可以执行`10^9`每个元素的操作，导致 O(n * max(nums)) 时间复杂度。 

最佳解决方案的关键见解是使用位操作**向后工作**。 每个增量操作对应于在数字的二进制表示中设置一个位。 每个加倍操作对应于二进制的左移。 因此，计算数量`1`每个数字的二进制表示中的 s 给出增量的数量，所有数字的最高位位置给出所需的加倍数量。 这种方法非常高效，并且在 O(n log max(nums)) 时间内运行。

 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大(nums)) | O(n) | 模拟每个操作，对于大数字来说太慢 |
 | 最佳 | O(n log max(nums)) | O(n log max(nums)) | O(n log max(nums)) | O(1) | O(1) | 使用位操作来有效地计算增量和加倍 |

 ## 算法演练

 1. 初始化两个计数器：`increments`计算增量操作的数量，以及`doublings`计算加倍运算的次数。 
2. 迭代每个元素`num`在`nums`。 
3. 对于每个`num`，将其转换为二进制。 数一下数量`1`位并添加到`increments`。 
4. 跟踪所有数字中的最大位长度，它表示所需的加倍操作的次数。 减一是因为最高位对应加倍次数（单个元素 1 需要 0 次加倍）。 
5. 返回总操作数的总和`increments`和`doublings`。 

**为什么有效：** 每个`1`二进制表示形式对应于该位级别的必要增量操作。 加倍对应于将当前值向左移动，因此最高设置位决定需要加倍多少次才能达到最大数字。 此方法保证了最少的操作，因为它以最佳方式将每个位的操作分开。 

## Python 解决方案```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        increments = 0
        max_bits = 0
        
        for num in nums:
            bits = 0
            temp = num
            while temp > 0:
                if temp & 1:
                    increments += 1
                temp >>= 1
                bits += 1
            max_bits = max(max_bits, bits)
        
        doublings = max_bits - 1 if max_bits > 0 else 0
        return increments + doublings
```该实现迭代每个数字，使用按位运算进行计数`1`s（增量）和总位数（加倍）。 我们保持运行的最大位长度来确定最大数所需的加倍。 

## 解决方案```go
func minOperations(nums []int) int {
    increments := 0
    maxBits := 0
    
    for _, num := range nums {
        bits := 0
        temp := num
        for temp > 0 {
            if temp&1 == 1 {
                increments++
            }
            temp >>= 1
            bits++
        }
        if bits > maxBits {
            maxBits = bits
        }
    }
    
    doublings := 0
    if maxBits > 0 {
        doublings = maxBits - 1
    }
    
    return increments + doublings
}
```Go 实现反映了 Python 逻辑。 我们使用按位运算来计算增量和位长度。 Go 与 Python 类似地处理大整数，并且切片代替数组进行迭代。

 ## 边缘情况

 第一个重要的边缘情况是所有元素都为零时。 这测试实现是否可以正确处理无操作。 我们的算法对位进行计数，因此零对增量或加倍没有任何贡献，而是返回零。 

第二种边缘情况是数组包含单个元素时。 这确保算法处理最小的输入长度而不会出现错误。 该算法按预期工作，因为它迭代一个元素，计算其二进制位。 

第三种边缘情况是当元素是 2 的大幂时。 在这种情况下，仅需要加倍，如果 2 的幂大于 1，则增量恰好为 1。该算法使用二进制表示的最高位和增量正确计算加倍。 这确认了大数的正确性并验证没有发生溢出。
