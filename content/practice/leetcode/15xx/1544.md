[LeetCode 1544 题](https://leetcode.com/problems/make-the-string-great/)

 **难度：** 🟢简单
 **主题：** 字符串、堆栈

 ## 解决方案

 ## 问题理解

 问题要求我们处理一个字符串`s`由小写和大写英文字母组成，删除相同字符但大小写不同的相邻字母对。 具体来说，任何一个字符为小写且相邻字符为大写字符（反之亦然）的字符对都被视为“坏”。 我们必须迭代地删除这些对，直到不再有坏对留下，从而产生“好”字符串。 

输入`s`保证长度在 1 到 100 之间，该长度足够小，可以允许简单的迭代解决方案，而无需担心性能问题。 输出应该是最终的好字符串，并且问题保证唯一性。 如果删除所有字符，则空字符串被视为有效。 

关键点包括认识到删除一对可能会产生新的坏对，需要在后续迭代中解决。 边缘情况包括已经好的字符串、完全取消的大小写字母交替的字符串以及单字符字符串。 

## 方法

 暴力方法会重复扫描字符串中是否有坏的相邻对，将其删除，然后重复，直到没有坏的对留下。 虽然正确，但这种方法效率低下，因为重复扫描和字符串切片在最坏的情况下会导致 O(n²) 时间复杂度。 

最佳解决方案利用堆栈一次性处理字符串。 这个想法是迭代每个字符并将其与堆栈顶部进行比较。 如果该角色与堆栈顶部形成了不良配对，则弹出堆栈。 否则，将字符压入堆栈。 此方法确保我们始终立即解决相邻冲突并在线性时间内处理字符串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 反复扫描并删除坏对，直到串好 |
 | 最佳 | O(n) | O(n) | 单通堆栈解决方案，立即解决冲突 |

 ## 算法演练

 1. 在迭代时初始化一个空堆栈来保存当前“好”字符串的字符。 
2. 迭代每个字符`c`在输入字符串中`s`。 
3. 如果栈不为空且栈顶字符与`c`（IE。，`abs(ord(stack[-1]) - ord(c)) == 32`），弹出堆栈以删除冲突对。 
4. 否则，推`c`到堆栈上。 
5. 处理完所有字符后，通过连接其元素将堆栈转换为字符串。 
6. 返回结果字符串作为最终的好字符串。 

**为什么有效：** 堆栈始终保持包含良好字符串的不变量。 每当发现坏对时，都会立即将其删除，这保证了最终不会留下坏对。 该过程是完整的，因为每个字符都被添加或删除一次。 

## Python 解决方案```python
class Solution:
    def makeGood(self, s: str) -> str:
        stack = []
        for c in s:
            if stack and abs(ord(stack[-1]) - ord(c)) == 32:
                stack.pop()
            else:
                stack.append(c)
        return ''.join(stack)
```Python 解决方案使用列表作为堆栈。 对于每个字符，它会检查它是否与堆栈顶部形成不良对。 这`abs(ord(stack[-1]) - ord(c)) == 32`条件有效，因为小写和大写 ASCII 字母相差 32。未形成错误对的字符将附加到堆栈中，最后，堆栈内容将连接到输出字符串中。 

## 解决方案```go
func makeGood(s string) string {
    stack := []rune{}
    for _, c := range s {
        if len(stack) > 0 && abs(int(stack[len(stack)-1]-c)) == 32 {
            stack = stack[:len(stack)-1]
        } else {
            stack = append(stack, c)
        }
    }
    return string(stack)
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```在 Go 中，我们使用一片符文作为堆栈。 使用相同的 ASCII 差异检查将每个字符与堆栈顶部进行比较。 通过重新切片弹出切片，并正常附加字符。 这`abs`需要辅助函数是因为 Go 没有内置的整数绝对值。

 ## 边缘情况

 一个重要的边缘情况是长度为 1 的字符串。 由于单个字符不能形成坏对，因此应按原样返回。 另一个边缘情况是字符串在大小写字母之间完美交替，例如`"aAaA"`，这需要多次连续删除。 该实现使用堆栈方法正确处理了这个问题，因为每次冲突都会触发弹出。 第三种边缘情况是根本没有坏对的字符串； 在这种情况下，算法不得删除任何内容，堆栈只是累积所有字符。 这是自然处理的，因为移除条件仅在坏对上触发。
