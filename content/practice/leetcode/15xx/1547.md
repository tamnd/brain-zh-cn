[LeetCode 问题 1547](https://leetcode.com/problems/minimum-cost-to-cut-a-stick/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定在指定位置将木棍切成碎片的最小总成本。 棍子有长度`n`，我们得到一个数组`cuts`代表应该进行削减的位置。 重要的是，切割的顺序并不固定，每次切割的成本等于当时被切割的木棍的长度。 我们的目标是选择最佳的切割顺序，以最小化所有切割成本的总和。 

例如，如果一根长度为`7`被切断的位置`[1,3,4,5]`，按照给定的顺序进行切割可能会很昂贵，因为早期切割可能会将木棍分成较大的剩余长度。 重新安排切割顺序可以降低总体成本。 约束表明`n`可以非常大（最多`10^6`），但切割次数最多为`100`，这表明需要一种根据切割次数而不是棒长度进行缩放的解决方案。 

边缘情况包括只有一次切割的情况、在棒的最末端进行切割或已经排序而不是随机分布的切割。 

## 方法

 ### 蛮力

 蛮力方法是生成所有排列`cuts`数组并模拟每个排列的总成本。 对于每个排列，我们将依次切割木棍，更新所得碎片的长度，并对成本求和。 这保证了正确的答案，因为它详尽地考虑了所有可能的订单。 然而，时间复杂度为`O(m!)`在哪里`m`是切割次数，这对于`m = 100`。 

### 最佳方法

 关键的见解是，这个问题表现出最优的子结构：切割棒的一段的最小成本仅取决于该段内部的切割，与棒的其余部分无关。 这使得它适合动态规划。 首先对剪辑进行排序，然后在位置添加虚拟剪辑`0`和`n`，我们可以定义一个DP表`dp[i][j]`代表在位置之间切断棍子的最小成本`cuts[i]`和`cuts[j]`。 对于每个区间，我们尝试所有可能的切割`k`之间`i`和`j`作为第一次切割并递归计算成本：```
dp[i][j] = min(dp[i][k] + dp[k][j] + cost_of_cut)
```在哪里`cost_of_cut = cuts[j] - cuts[i]`。 这种方法将问题从阶乘时间减少到多项式时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(米！) | O(米) | 生成切割的所有排列 |
 | 最佳DP | O(m^3) | O(m^2) | 在间隔内使用记忆，m = 切割次数 |

 ## 算法演练

 1. 对切割数组进行排序，以确保片段可以按顺序处理。 
2. 追加`0`在开始时和`n`在cuts数组的末尾来处理棍子边界。 
3. 初始化2D DP表`dp`尺寸的`(m+2) x (m+2)`在哪里`m`是切割次数。`dp[i][j]`将存储切割棍子的最低成本`cuts[i]`到`cuts[j]`。 
4.从length开始迭代所有可能的段长度`2`因为间隔长度`1`或者`0`不需要削减。 
5. 对于每个间隔`(i, j)`，迭代所有可能的第一次切割`k`之间`i`和`j`。 计算切割成本`k`作为`cuts[j] - cuts[i]`加上左右子段的DP结果。 
6. 更新`dp[i][j]`在所有可能的第一次切割中成本最低`k`。 
7. 最终答案存储在`dp[0][m+1]`，代表切割整根棍子的最小成本。 

**为什么有效**：DP方法之所以有效，是因为每个区间都是独立求解的，并且递归确保对于任何段，都考虑所有可能的第一次切割，从而保证最小成本。 该问题具有重叠的子问题，DP 可以有效地利用这些子问题。 

## Python 解决方案```python
from typing import List

class Solution:
    def minCost(self, n: int, cuts: List[int]) -> int:
        cuts = [0] + sorted(cuts) + [n]
        m = len(cuts)
        dp = [[0] * m for _ in range(m)]
        
        for length in range(2, m):
            for i in range(m - length):
                j = i + length
                dp[i][j] = min(
                    dp[i][k] + dp[k][j] + cuts[j] - cuts[i]
                    for k in range(i + 1, j)
                )
        
        return dp[0][m - 1]
```**实施演练**：我们首先对切口进行排序并添加边界`0`和`n`。 DP表`dp[i][j]`用零初始化。 然后，我们填充表格以增加线段长度，并考虑每个可能的第一次切割`k`在段内并更新`dp[i][j]`以最小的成本。 最后，`dp[0][m-1]`给出最小的总成本。 

## 解决方案```go
func minCost(n int, cuts []int) int {
    cuts = append([]int{0}, cuts...)
    cuts = append(cuts, n)
    sort.Ints(cuts)
    
    m := len(cuts)
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, m)
    }
    
    for length := 2; length < m; length++ {
        for i := 0; i < m - length; i++ {
            j := i + length
            dp[i][j] = 1 << 30
            for k := i + 1; k < j; k++ {
                cost := dp[i][k] + dp[k][j] + cuts[j] - cuts[i]
                if cost < dp[i][j] {
                    dp[i][j] = cost
                }
            }
        }
    }
    
    return dp[0][m-1]
}
```**Go 注释**：Go 实现密切反映了 Python 逻辑。 我们使用`1 << 30`作为初始大值而不是`inf`。 切片用于DP表的动态分配，排序使用`sort.Ints`。

 | 间隔`(i,j)`| 可能的削减`k`| 成本计算| 最低成本|
 | --- | --- | --- | --- |
 | (0,5) | 1,2,3,4 | 7+... | 16 | 16

 DP 表确保每个子段都得到最佳评估。

 ## 边缘情况

 **单次切割**：如果只有一次切割，则成本只是棍子的长度。 我们的 DP 表通过初始化长度为 2 的段来处理这个问题。
