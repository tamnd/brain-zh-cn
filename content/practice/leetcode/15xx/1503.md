[LeetCode Problem 1503](https://leetcode.com/problems/last-moment-before-all-ants-fall-out-of-a-plank/)

 **难度：** 🟡 中等
 **主题：** 数组、脑筋急转弯、模拟

 ## 解决方案

 ## 问题理解

 问题描述了一块长度的木板`n`on which ants are walking either to the left or to the right at a constant speed of 1 unit per second. 我们有两个数组：`left`包含蚂蚁向左移动的起始位置，并且`right`包含蚂蚁向右移动的起始位置。 当两只向相反方向移动的蚂蚁相遇时，它们会“交换”方向，但关键的见解是，交换相当于它们互相穿过，而不影响最终的坠落时间，因为蚂蚁是为了确定最后一次坠落的目的而无法区分的。 

目标是在所有蚂蚁掉落之前确定蚂蚁仍在木板上的**最后时刻**。 一只蚂蚁到达两端后立即从木板上掉下来。 平板支撑从位置 0 开始，结束于位置`n`。 

约束条件保证了木板长度`n`最多为10000个单位，蚂蚁总数最多为`n + 1`。 每个位置都是唯一的，并且位置之间不共享`left`和`right`数组。 这意味着我们不必处理重复的蚂蚁或重叠的位置。 

重要的边缘情况包括空`left`或者`right`阵列中，蚂蚁从最末端开始，所有蚂蚁都朝同一方向移动。 

## 方法

 ### 蛮力

 暴力方法每秒模拟蚂蚁的运动。 在每个时间步，我们都会根据每只蚂蚁的方向移动它，通过交换方向来处理碰撞，并移除掉下来的蚂蚁。 我们将继续这个模拟，直到所有蚂蚁都掉下来。 

虽然这种方法是正确的，但效率很低。 例如，如果一只蚂蚁从其下落方向的另一端开始，它可能需要最多`n`秒坠落。 对于多只蚂蚁，这种方法可能会导致 O(n * k) 模拟，其中`k`是蚂蚁的数量。 给定`n`最多 10,000 个，这可能会很慢。 

### 最佳方法

 关键的观察结果是，**蚂蚁相互穿过相当于忽略碰撞**，因为如果我们只跟踪到最近端点的距离，则每只蚂蚁掉落所需的时间与碰撞无关。 对于向左移动的蚂蚁，其下落时间等于其起始位置。 对于向右移动的蚂蚁，它的下落时间是`n - position`。 因此，最后一刻就是**这些下降时间的最大值**。 

这种方法完全避免了模拟运动，并在线性时间内计算出相对于蚂蚁数量的答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(k) | 模拟所有蚂蚁的每一秒，处理碰撞 |
 | 最佳 | O(k) | O(1) | O(1) | 计算最大值`left[i]`和`n - right[i]`对于所有蚂蚁|

 ## 算法演练

 1. 初始化变量`last_moment`到 0。这将存储任何蚂蚁从木板上掉下来的最新时间。 
2. 遍历数组中的每只蚂蚁`left`数组：

 - 蚂蚁向左移动，所以它的下落时间正是它的起始位置`pos`。 
- 更新`last_moment`成为最大的`last_moment`和`pos`。 
3. 遍历数组中的每只蚂蚁`right`数组：

 - 蚂蚁向右移动，所以它的下落时间是`n - pos`。 
- 更新`last_moment`成为最大的`last_moment`和`n - pos`。 
4.处理完所有蚂蚁后，返回`last_moment`。 

**为什么有效：** 如果我们忽略碰撞，每只蚂蚁都会独立下落。 通过取所有下落时间的最大值，我们捕获了蚂蚁留在木板上的最后一刻。 由于蚂蚁交换方向的对称性，碰撞不会影响最终时间。 

## Python 解决方案```python
from typing import List

class Solution:
    def getLastMoment(self, n: int, left: List[int], right: List[int]) -> int:
        last_moment = 0
        
        for pos in left:
            last_moment = max(last_moment, pos)
            
        for pos in right:
            last_moment = max(last_moment, n - pos)
            
        return last_moment
```**解释：** 我们迭代`left`检查每只向左移动的蚂蚁需要多长时间才能掉落，这就是它的位置。 同样，向右移动的蚂蚁`n - pos`秒坠落。 我们保持运行最大值`last_moment`并在最后返回它。 

## 解决方案```go
func getLastMoment(n int, left []int, right []int) int {
    lastMoment := 0
    
    for _, pos := range left {
        if pos > lastMoment {
            lastMoment = pos
        }
    }
    
    for _, pos := range right {
        if n - pos > lastMoment {
            lastMoment = n - pos
        }
    }
    
    return lastMoment
}
```**说明：** Go 解决方案镜像了 Python 逻辑。 我们迭代`left`和`right`切片，更新`lastMoment`每只蚂蚁掉落的最长时间。 Go 需要显式比较最大值，而不是像 Python 那样使用内置函数`max`。

 ## 边缘情况

 1. **空`left`或者`right`数组：** 如果没有蚂蚁朝一个方向移动，算法仍然必须正确考虑另一个方向。 该解决方案通过仅迭代现有数组来处理此问题。 
2. **蚂蚁在末端：** 如果蚂蚁从位置 0 开始向左移动或位置`n`向右移动，它立即掉落。 算法正确计算`0`或者`n - n = 0`对于这些情况，由`max`功能。 
3. **单蚂蚁板：** 对于`n = 1`或者很短的木板，计算必须正确处理最小距离。 由于我们直接根据位置计算下降时间，因此自然会覆盖这种边缘情况。
