 ## 解决方案

 ## 问题理解

 这个问题要求我们检查一个整数列表，`arr`，并判断数组中任意位置是否存在**三个连续奇数**的序列。 简单来说，我们需要从左到右扫描数组，并检查在任意点是否连续三个数字都是奇数。 如果存在这样的序列，我们返回`true`; 否则，我们返回`false`。 

输入为一维整数数组，取值范围为1～1000，数组长度为1～1000。输出为布尔值。 重要的观察结果包括保证数组非空且足够小（最多 1000 个元素），使得简单的线性扫描是可行的。 

潜在的边缘情况包括少于三个元素的数组（其中答案必须是`false`)、恰好具有三个元素的数组、全部为偶数的数组或偶数和奇数交替的数组。 我们还必须确保在检查连续奇数序列时正确处理第一个和最后一个元素。 

## 方法

 **暴力方法**涉及检查数组中每个可能的连续三元组。 对于每个索引`i`，我们会检查是否`arr[i]`,`arr[i+1]`， 和`arr[i+2]`都是奇怪的。 这种方法之所以有效，是因为它彻底验证了所有可能的三元素窗口。 对于长度数组`n`，这需要`n-2`检查。 

**最佳方法**利用带有计数器的简单线性扫描。 当我们迭代数组时，我们维护连续奇数的运行计数。 每次遇到奇数时，我们都会增加计数器； 如果遇到偶数，我们将计数器重置为零。 如果计数器在任何时候达到 3，我们立即返回`true`。 这更优雅，因为它只需要一次通过数组和最小的额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 显式检查所有三元组，稍微更详细 |
 | 最佳 | O(n) | O(1) | O(1) | 使用运行计数器来跟踪连续赔率 |

 ## 算法演练

 1.初始化一个计数器变量`consecutive_odds`到 0。这将跟踪到目前为止看到的连续奇数的数量。 
2. 迭代每个数字`num`在数组中`arr`。 
3. 对于每个`num`，使用检查它是否为奇数`num % 2 != 0`。 
4.如果`num`为奇数，增量`consecutive_odds`1. 否则，重置`consecutive_odds`至 0。 
5. 更新计数器后，检查是否`consecutive_odds`已达到3。如果已达到，则立即返回`true`因为我们找到了三个连续的奇数。 
6. 如果循环结束但计数器未达到 3，则返回`false`。 

**为什么有效：** 计数器确保我们始终拥有准确数量的连续奇数。 对偶数进行重置可确保仅对连续奇数的序列进行计数，并且当计数器达到 3 时立即返回可确保正确性和效率。 

## Python 解决方案```python
from typing import List

class Solution:
    def threeConsecutiveOdds(self, arr: List[int]) -> bool:
        consecutive_odds = 0
        for num in arr:
            if num % 2 != 0:
                consecutive_odds += 1
                if consecutive_odds == 3:
                    return True
            else:
                consecutive_odds = 0
        return False
```Python 解决方案初始化一个计数器来跟踪连续的奇数。 当它迭代数组时，它会增加奇数的计数器并重置偶数的计数器。 一旦计数器达到三，它立即返回`true`。 如果迭代完成后没有找到三个连续的赔率，则返回`false`。 这完全遵循算法。 

## 解决方案```go
func threeConsecutiveOdds(arr []int) bool {
    consecutiveOdds := 0
    for _, num := range arr {
        if num % 2 != 0 {
            consecutiveOdds++
            if consecutiveOdds == 3 {
                return true
            }
        } else {
            consecutiveOdds = 0
        }
    }
    return false
}
```Go 解决方案反映了 Python 方法。 它使用整数计数器来跟踪连续的奇数，并迭代切片。 主要区别在于语法和范围迭代。 不需要对 nil 切片进行特殊处理，因为该问题保证至少有一个元素。

 ## 边缘情况

 **短数组：** 元素少于三个的数组不能包含三个连续的奇数。 执行正确返回`false`在这些情况下，永远不会达到三。 

**边界处的序列：** 如果三个连续赔率的序列出现在数组的开头或结尾，该算法仍然有效，因为它按顺序检查每个元素并动态更新计数器。 不需要对边界进行特殊处理。 

**奇数和偶数交替：** 在奇数和偶数频繁交替的数组中，每次遇到偶数时计数器都会重置。 这确保了仅对真实的连续序列进行计数，从而防止误报。 

该解决方案非常高效，可以处理所有边缘情况，并在 Python 和 Go 中清晰地实现所需的逻辑。
