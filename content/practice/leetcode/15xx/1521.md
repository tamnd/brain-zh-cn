[LeetCode 问题 1521](https://leetcode.com/problems/find-a-value-of-a-mysterious-function-closest-to-target/)

 **难度：** 🔴难
 **主题：** 数组、二分查找、位操作、线段树

 ## 解决方案

 ## 问题理解

 该问题定义了一个神秘的函数`func(arr, l, r)`从索引计算子数组中所有元素的按位与`l`索引`r`，包含在内。 

形式上，该函数是：$func(arr,l,r)=arr[l]\ \&\ arr[l+1]\ \&\ \cdots\ \&\ arr[r]$我们给定一个整数数组`arr`和目标值`target`。 我们的任务是选择指数`l`和`r`这样子数组 AND 结果和之间的绝对差`target`尽可能小。 

换句话说，在所有可能的连续子数组中，我们必须找到按位与值最接近的子数组`target`。 

输入包括：

 -`arr`，正整数数组
 -`target`, 一个非负整数

 输出是一个整数，表示以下各项的最小可能值：$|func(arr,l,r)-target|$约束条件非常重要：

 -`arr.length`可以大到`10^5`- 每个元素最多`10^6`检查每个子数组的简单解决方案将需要大约检查`n^2`子数组，这对于`n = 100000`。 

按位与的关键属性是向与运算添加更多数字只能保持位相同或关闭位。 位永远不会重新打开。 这种单调的行为可以实现高效的解决方案。 

一些边缘情况很重要：

 - 单个元素可能已经等于目标。 
- 所有子数组 AND 值可能比目标大得多。 
- 重复的数字会产生许多重复的 AND 结果。 
- 长数组可能会创建大量子数组，因此我们必须避免显式枚举它们。 
- 由于 AND 值仅随着子数组的增长而减少，因此许多不同的子数组结果会分解为一小组唯一值。 

## 方法

 ### 蛮力方法

 最直接的解决方案是枚举每个可能的子数组。 

对于每个起始索引`l`，我们将子数组扩展到每个可能的结束索引`r`。 在扩展时，我们不断地计算运行按位与。 

对于每个子数组：

 1. 计算 AND 值。 
2. 计算`abs(and_value - target)`。 
3. 更新最小差值。 

这种方法是正确的，因为它显式检查每个有效子数组，保证找到最佳答案。 

然而，子数组的数量是：$\frac{n(n+1)}{2}$为了`n = 100000`，这太大了。 即使使用增量 AND 计算，该算法仍然需要粗略的`O(n^2)`操作，这是不可行的。 

### 最佳方法

 关键的见解是，以固定位置结束的子数组的不同按位 AND 值的数量惊人地小。 

假设我们从左到右处理数组。 在位置`i`，考虑所有以`i`。 

如果我们知道以以下结尾的子数组的所有 AND 值`i - 1`，然后每个子数组结束于`i`可以由下式组成：

 - 开始一个新的子数组，仅包含`arr[i]`- 扩展先前的子数组并将其值与`arr[i]`关键的观察是，重复的 AND 运算会迅速减少值，因为位只能关闭。 由于整数仅包含有限数量的位，因此不同 AND 值的数量仍然很小，通常最多大约 20 到 30 个唯一值。 

因此，我们不存储每个子数组，而是仅存储以当前索引结尾的子数组的不同 AND 结果。 

这大大降低了复杂性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 枚举所有子数组 |
 | 最佳| O(n log M) | O(n log M) | O(log M) | 保持不同的 AND 值，其中`M`是最大元素 |

 这里，`log M`对应于整数中的位数，对于高达 20 的值大约为 20`10^6`。 

## 算法演练

 ### 步骤 1：维护以当前索引结尾的子数组的 AND 结果

 我们从左到右迭代数组。 

在每个索引处`i`，我们维护一个集合，其中包含完全结束于的子数组的所有不同的按位 AND 值`i`。 

我们称这个集合为`current`。 

### 步骤 2：开始一个新的子数组

 每个索引都可以构成长度为 1 的子数组。 

所以最初：```
new_set = {arr[i]}
```这代表子数组`[i, i]`。 

### 步骤 3：扩展之前的子数组

 假设`previous`包含以结尾的子数组的所有不同 AND 结果`i - 1`。 

对于每个值`v`在`previous`，将子数组扩展为`arr[i]`产生：```
v & arr[i]
```我们将所有这些值插入到`new_set`。 

### 步骤 4：自动删除重复项

 许多不同的子数组可以产生相同的 AND 结果。 

使用集合会自动仅保留不同的值，这是关键的优化。 

### 第 5 步：更新答案

 对于每个 AND 值`new_set`，计算：```
abs(value - target)
```如果此差异较小，则更新全局最小答案。 

### 第 6 步：移动到下一个位置

 分配：```
previous = new_set
```然后继续处理下一个数组元素。 

### 为什么它有效

 该算法之所以有效，是因为每个子数组都以索引结尾`i`是：

 - 一个新的单元素子数组`[i, i]`- 结束于的子数组的扩展`i - 1`因此，该算法通过动态构造一次性生成每个可能的子数组 AND 结果。 

优化是有效的，因为重复的 AND 值对于将来的计算是等效的。 由于按位与仅删除位，因此不同值的数量仍然很少，从而确保了效率。 

## Python 解决方案```python
from typing import List

class Solution:
    def closestToTarget(self, arr: List[int], target: int) -> int:
        answer = float("inf")
        
        previous = set()
        
        for num in arr:
            current = {num}
            
            for value in previous:
                current.add(value & num)
            
            for value in current:
                answer = min(answer, abs(value - target))
            
            previous = current
        
        return answer
```该实现遵循前面描述的确切算法。 

变量`previous`存储以前一个索引结尾的子数组的所有不同 AND 值。 

对于每个新元素`num`，我们创建一个新集合，名为`current`。 

首先，我们插入`num`本身，表示仅包含当前元素的子数组。 

接下来，我们通过计算来扩展之前的每个子数组`value & num`。 

因为`current`是一个集合，重复的 AND 值将被自动删除。 

在为以当前索引结尾的子数组生成所有不同的 AND 值后，我们计算与目标的绝对差并更新答案。 

最后我们替换`previous`和`current`并继续。 

实现很简洁，因为按位 AND 的数学属性完成了大部分工作。 

## 解决方案```go
package main

import "math"

func closestToTarget(arr []int, target int) int {
	answer := math.MaxInt32

	previous := map[int]bool{}

	for _, num := range arr {
		current := map[int]bool{}
		current[num] = true

		for value := range previous {
			current[value&num] = true
		}

		for value := range current {
			diff := abs(value - target)
			if diff < answer {
				answer = diff
			}
		}

		previous = current
	}

	return answer
}

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}
```Go 的实现与 Python 解决方案非常相似。 

由于 Go 没有内置的集合类型，我们使用`map[int]bool`模拟一组。 

其余逻辑保持不变：

 -`previous`存储与前一个索引不同的 AND 结果。 
-`current`存储当前索引的不同 AND 结果。 
- 通过映射键自然消除重复值。 

整数溢出不是问题，因为所有值都保持在标准 32 位整数限制内。

因此，虽然理论上有`O(n²)`对于子数组，该算法仅处理它们的一小部分压缩表示。

 ## 边缘情况

 一个重要的边缘情况是数组仅包含单个元素。 在这种情况下，可能只有一个子数组。 粗心的实现可能会假设多个子数组始终存在或错误地初始化运行结构。 该解决方案自然地处理这个问题，因为每次迭代总是创建单例集`{num}`。 

当所有数字都相同时，会发生另一个重要情况。 许多子数组会产生完全相同的 AND 结果。 如果没有重复数据删除，算法可能会浪费大量时间来处理重复值。 使用集合可确保每个不同的 AND 结果仅处理一次。 

第三个重要的边缘情况是“与”运算迅速变为零时。 当数字具有不相交的位时，通常会发生这种情况。 一旦子数组 AND 达到零，进一步扩展子数组将使其保持为零。 该算法可以有效地处理这个问题，因为零在一组不同值中只出现一次。 

第四种微妙的情况是目标比每个可能的 AND 结果大得多或小得多。 该算法仍然可以正确计算最小绝对差，因为它根据目标评估每个不同的 AND 值，而不对相对顺序做出假设。 

最后，非常大的阵列是一个关键的压力情况。 一个天真的`O(n²)`解决方案将立即超时`n = 100000`。 优化的解决方案成功了，因为由于按位 AND 的单调性质，每个位置的不同 AND 值的数量仍然非常小。
