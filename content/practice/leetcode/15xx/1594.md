[LeetCode 第 1594 题](https://leetcode.com/problems/maximum-non-negative-product-in-a-matrix/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 这个问题要求我们导航`m x n`整数矩阵`grid`从左上角开始`(0, 0)`到右下角`(m - 1, n - 1)`，每一步仅**向右**或**向下**移动。 沿着路径，我们将经过的所有整数相乘，我们的目标是**最大化乘积**，同时确保它**非负**。 如果不存在非负积，我们返回`-1`。 如果存在非负乘积，我们将其模返回`10^9 + 7`。 

输入是一个矩阵，其中每个元素的范围为`-4`到`4`，并且两个尺寸都很小（`1 <= m, n <= 15`），这表明计算复杂度较高的解决方案可能是可行的，但理想情况下应该是多项式。 负数的存在使问题变得复杂：路径的乘积可以根据遇到的负值的数量在负值和正值之间切换。 这需要仔细跟踪每个单元的**最大和最小乘积**。 

重要的边缘情况包括包含零的矩阵、所有路径都产生负积的矩阵以及具有单行或单列的矩阵。 这些约束保证矩阵非空且足够小，适合动态规划解决方案。 

## 方法

 **暴力方法**将递归地探索所有可能的路径，计算每个路径的乘积，然后选择最大的非负结果。 这是正确的，但在计算上不可行，因为路径的数量是指数级的：对于`m x n`网格，有`C(m+n-2, m-1)`路径，即使对于适度的值，其增长也非常快`m`和`n`。 

**最佳方法**是使用**动态规划**。 关键的观察是在任何细胞`(i, j)`，最大非负乘积可以由前一个单元的正乘积或两个负乘积相乘得到。 因此，我们需要维护每个单元格的**最大和最小乘积**。 转换很简单：计算`(i, j)`，我们认为产品来自**顶层**`(i-1, j)`和**左**`(i, j-1)`，更新该单元格中的最大和最小乘积。 这确保了无论路径上遇到的数字的符号如何，我们始终拥有正确的产品。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(m+n) | 递归地探索所有路径，对于 m,n=15 | 指数且不可行的路径
 | 最佳DP | O(m*n) | O(m*n) | 跟踪每个单元格的最大和最小乘积，以及来自顶部和左侧邻居的更新 |

 ## 算法演练

 1. **初始化**：创建两个矩阵，`max_dp`和`min_dp`，大小相同`grid`存储每个单元可实现的最大和最小乘积。 初始化`max_dp[0][0] = min_dp[0][0] = grid[0][0]`。 
2. **首行首列**：对于第一行`(0, j)`和第一列`(i, 0)`，唯一可能的路径是从一开始就是直线。 更新`max_dp`和`min_dp`将前一个单元格的值乘以当前单元格的值。 
3. **动态规划迭代**：对于每个单元格`(i, j)`开始于`(1,1)`，通过考虑顶部来计算潜在的最大和最小乘积`(i-1, j)`然后离开了`(i, j-1)`细胞：

 - 计算所有四种可能的产品：`grid[i][j] * max_dp[i-1][j]`,`grid[i][j] * min_dp[i-1][j]`,`grid[i][j] * max_dp[i][j-1]`,`grid[i][j] * min_dp[i][j-1]`。 
- 更新`max_dp[i][j]`作为这四个值中的最大值。 
- 更新`min_dp[i][j]`作为这四个值中的最小值。 
4. **结果提取**：最终结果为`max_dp[m-1][n-1]`。 如果为负数，则返回`-1`。 否则，返回模数`10^9 + 7`。 

**为什么有效**：通过维护每个单元格的最大和最小乘积，该算法可以正确处理负数和零。 这确保了即使两个负数相乘形成正积也能捕获最佳路径。 DP 确保我们只计算每个单元一次，从而提高效率。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxProductPath(self, grid: List[List[int]]) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])
        
        max_dp = [[0] * n for _ in range(m)]
        min_dp = [[0] * n for _ in range(m)]
        
        max_dp[0][0] = min_dp[0][0] = grid[0][0]
        
        # Initialize first row
        for j in range(1, n):
            max_dp[0][j] = max_dp[0][j-1] * grid[0][j]
            min_dp[0][j] = max_dp[0][j]
        
        # Initialize first column
        for i in range(1, m):
            max_dp[i][0] = max_dp[i-1][0] * grid[i][0]
            min_dp[i][0] = max_dp[i][0]
        
        # Fill DP table
        for i in range(1, m):
            for j in range(1, n):
                candidates = [
                    grid[i][j] * max_dp[i-1][j],
                    grid[i][j] * min_dp[i-1][j],
                    grid[i][j] * max_dp[i][j-1],
                    grid[i][j] * min_dp[i][j-1]
                ]
                max_dp[i][j] = max(candidates)
                min_dp[i][j] = min(candidates)
        
        return max_dp[m-1][n-1] % MOD if max_dp[m-1][n-1] >= 0 else -1
```该实现首先初始化第一行和第一列的 DP 表，因为到每个单元只有一个可能的路径。 然后，它迭代网格的其余部分，考虑到每个单元格的所有可能的先前路径。 使用`max`和`min`确保正确处理负值。 

## 解决方案```go
func maxProductPath(grid [][]int) int {
    const MOD = 1_000_000_007
    m, n := len(grid), len(grid[0])
    
    maxDP := make([][]int, m)
    minDP := make([][]int, m)
    for i := 0; i < m; i++ {
        maxDP[i] = make([]int, n)
        minDP[i] = make([]int, n)
    }
    
    maxDP[0][0], minDP[0][0] = grid[0][0], grid[0][0]
    
    for j := 1; j < n; j++ {
        maxDP[0][j] = maxDP[0][j-1] * grid[0][j]
        minDP[0][j] = maxDP[0][j]
    }
    
    for i := 1; i < m; i++ {
        maxDP[i][0] = maxDP[i-1][0] * grid[i][0]
        minDP[i][0] = maxDP[i][0]
    }
    
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            candidates := []int{
                grid[i][j] * maxDP[i-1][j],
                grid[i][j] * minDP[i-1][j],
                grid[i][j] * maxDP[i][j-1],
                grid[i][j] * minDP[i][j-1],
            }
            maxDP[i][j] = max(candidates...)
            minDP[i][j] = min(candidates...)
        }
    }
    
    if maxDP[m-1][n-1] < 0 {
        return -1
    }
    return maxDP[m-1][n-1] % MOD
}

func max(nums ...int) int {
    res := nums[0]
    for _, n := range nums[1:] {
        if n > res {
            res = n
        }
    }
    return res
}

func min(nums ...int) int {
    res := nums[0]
    for _, n := range nums[1:] {
        if n < res {
            res = n
        }
    }
    return res
}
```Go 实现反映了 Python 逻辑。 由于Go不支持`max`和`min`默认情况下，对于切片，定义了辅助函数。 DP 数组是显式初始化的切片的切片。
