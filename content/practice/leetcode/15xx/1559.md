 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、广度优先搜索、并查找、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们检测二维字符网格中的循环，其中循环中的所有单元格必须包含**相同的字符**。 循环被定义为在同一单元格开始和结束且长度为**四或更长**的路径。 只允许在四个基本方向上移动：上、下、左、右。 重要的是，您不能立即返回到上一个单元格，这意味着像这样的移动`(1,1) -> (1,2) -> (1,1)`不是一个有效的循环。 

输入是一个大小为 2D 的数组`m x n`带有小写英文字母。 约束表明`m`和`n`最大可达 500，这排除了每个操作时间复杂度高于 O(m*n) 的任何方法。 输出是一个布尔值：`true`如果存在任何有效循环并且`false`否则。 

关键的边缘情况包括：

 - 具有所有相同字符的网格形成大循环。 
- 由于所有独特字符或孤立的相同字符区域，网格没有可能的循环。 
- 不可能循环的小网格（例如 1xN 或 Nx1）。 

了解运动限制和最小周期长度对于避免误报至关重要。 

## 方法

 强力方法是从每个单元开始，尝试使用 DFS 或 BFS 找到所有可能的路径，检查循环。 虽然这在概念上很简单，但效率极低，因为可能存在指数数量的路径，尤其是在尺寸高达 500x500 的网格中。 

最佳方法使用**DFS 和父跟踪**。 这个想法是从每个未访问的单元执行 DFS 并跟踪前一个单元以避免立即回溯到它。 如果在 DFS 期间我们到达的访问单元不是**直接父单元**，那么我们就找到了一个有效的循环。 这种方法可以有效地探索相同字符的每个连接组件一次，并保证在不重新访问不必要的路径的情况下检测到循环。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(4^(m*n)) | O(4^(m*n)) | O(m*n) | 探索所有路径； 对于大网格来说不可行|
 | 具有家长跟踪功能的 DFS | O(m*n) | O(m*n) | 每个单元格访问一次； 使用 DFS 和父级检测循环 |

 ## 算法演练

 1. 初始化一个二维布尔数组`visited`尺寸的`m x n`跟踪访问过的单元格。 
2. 迭代每个单元格`(i, j)`在网格中。 
3. 如果该cell没有被访问过，则从该cell开始一次DFS，通过`(-1, -1)`作为父母（最初没有父母）。 
4. 在DFS中：

 1. 将当前单元格标记为已访问。 
2. 探索所有四个邻居（上、下、左、右）。 
3. 跳过网格外或具有不同字符的邻居。 
4. 如果邻居已经被访问过并且不是父邻居，则存在循环。 返回真。 
5. 否则，递归地 DFS 到以当前单元作为其父单元的邻居。 
5. 如果 DFS 完成但未找到所有组件的循环，则返回 false。 

**为什么有效：** DFS 确保探索同一角色的每个连接组件。 父级跟踪可防止误报立即返回到前一个单元格。 如果到达先前访问过的单元格，但该单元格不是父单元格，则确认存在至少长度为 4 的循环。 

## Python 解决方案```python
from typing import List

class Solution:
    def containsCycle(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        visited = [[False] * n for _ in range(m)]
        
        def dfs(x: int, y: int, px: int, py: int, char: str) -> bool:
            visited[x][y] = True
            for dx, dy in [(-1,0), (1,0), (0,-1), (0,1)]:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == char:
                    if not visited[nx][ny]:
                        if dfs(nx, ny, x, y, char):
                            return True
                    elif (nx, ny) != (px, py):
                        return True
            return False
        
        for i in range(m):
            for j in range(n):
                if not visited[i][j]:
                    if dfs(i, j, -1, -1, grid[i][j]):
                        return True
        return False
```该实现初始化已访问的网格并将 DFS 应用于每个未访问的单元格。 DFS 函数递归地探索邻居并使用父坐标`(px, py)`以避免回溯到前一个单元格。 如果它遇到不是父级的已访问邻居，则会检测到循环。 

## 解决方案```go
func containsCycle(grid [][]byte) bool {
    m, n := len(grid), len(grid[0])
    visited := make([][]bool, m)
    for i := range visited {
        visited[i] = make([]bool, n)
    }

    var dfs func(x, y, px, py int, char byte) bool
    dfs = func(x, y, px, py int, char byte) bool {
        visited[x][y] = true
        directions := [][2]int{{-1,0},{1,0},{0,-1},{0,1}}
        for _, d := range directions {
            nx, ny := x + d[0], y + d[1]
            if nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == char {
                if !visited[nx][ny] {
                    if dfs(nx, ny, x, y, char) {
                        return true
                    }
                } else if nx != px || ny != py {
                    return true
                }
            }
        }
        return false
    }

    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if !visited[i][j] {
                if dfs(i, j, -1, -1, grid[i][j]) {
                    return true
                }
            }
        }
    }
    return false
}
```Go 解决方案反映了 Python 实现，使用切片来跟踪访问的单元格。 递归 DFS 处理邻居探索，并使用父坐标来避免错误的循环检测。 

## 工作示例

 **示例1：**

 输入：```
grid = [
 ["a","a","a","a"],
 ["a","b","b","a"],
 ["a","b","b","a"],
 ["a","a","a","a"]
]
```开始于`(0,0)`，DFS 向右和向下探索，标记访问过的单元格。 最终，DFS返回到`(0,0)`从`(0,3)`没有立即回溯，确认一个循环。 

**示例2：**

 输入：```
grid = [
 ["c","c","c","a"],
 ["c","d","c","c"],
 ["c","c","e","c"],
 ["f","c","c","c"]
]
```DFS 开始于`(0,0)`探索`c`簇。 之前访问过的单元格`(0,2)`到达自`(1,2)`无需成为父母，确认一个循环。 

**示例3：**

 输入：```
grid = [
 ["a","b","b"],
 ["b","z","b"],
 ["b","b","a"]
]
```DFS探索所有`a`和`b`簇，但没有以形成有效循环的方式重新访问单元格，返回 false。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m*n) | 每个单元格在DFS中被访问一次； 邻居检查是恒定时间|
 | 空间| O(m*n) | 在最坏的情况下，访问的数组和递归 DFS 堆栈可能会达到 m*n |

 该算法随网格大小线性缩放，这对于高达 500x500 的约束是最佳的。
