[LeetCode 第 1588 题](https://leetcode.com/problems/sum-of-all-odd-length-subarrays/)

 **难度：** 🟢简单
 **主题：** 数组、数学、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定正整数数组的所有**奇数长度子数组**的总和。 子数组是原始数组中任意连续的元素序列。 例如，在数组中`[1, 2, 3]`，长度为 1 的子数组是`[1]`,`[2]`,`[3]`，长度为3的子数组是`[1, 2, 3]`。 奇数长度子数组就是长度为 1、3、5 等的子数组。 

输入`arr`是一个整数数组，长度范围为 1 到 100，每个元素介于 1 到 1000 之间。输出应该是一个整数，表示所有奇数长度子数组中所有数字的总和。 

这些约束表明，直接的暴力解决方案可能会起作用，因为数组大小相对较小，但问题还询问是否可以在 O(n) 时间内解决它以提高效率。 

边缘情况包括长度为 1 的数组、所有元素都相同的数组以及仅存在一个奇数长度子数组的数组。 这些可能会导致假设存在多个子数组的简单实现失败。 

## 方法

 ### 蛮力方法

 暴力方法会迭代从 1 到数组长度的所有可能的奇数长度。 对于每个长度，我们迭代该长度的子数组的所有起始索引，计算总和，并将其累加到总数中。 这是有效的，因为我们显式地访问每个子数组并对它的元素求和。 缺点是它需要嵌套循环，这对于较大的数组来说效率较低。 具体来说，如果我们在另一个循环中对每个子数组的元素求和，则该方法的复杂度为 O(n^3)，如果我们使用前缀和，则复杂度为 O(n^2)。 

### 最佳方法

 最佳方法的关键见解是**组合计数**。 我们不是显式地对每个子数组求和，而是计算每个元素的次数`arr[i]`出现在奇数长度子数组中。 考虑索引处的元素`i`：

 1.有`i + 1`子数组的可能起始位置包括`arr[i]`。 
2.有`n - i`子数组可能的结束位置包括`arr[i]`。 
3. 子数组总数包括`arr[i]`是`(i + 1) * (n - i)`。 
4. 这些子数组的一半（向上舍入）具有奇数长度，因此`count = ((i + 1) * (n - i) + 1) // 2`。 

我们可以乘以`arr[i]`通过这个计数和所有元素的总和。 这给出了 O(n) 解决方案，无需显式生成子数组。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 迭代所有奇数长度和所有子数组 |
 | 最佳 | O(n) | O(1) | O(1) | 组合计算每个元素的贡献 |

 ## 算法演练

 1. 初始化`total_sum`为 0。这将保存所有奇数长度子数组的累积和。 
2. 使用索引迭代数组`i`和价值`num`。 
3. 对于每个元素，计算包含该元素的子数组总数：`(i + 1) * (n - i)`。 
4. 使用以下命令计算这些子数组中有多少个具有奇数长度`odd_count = (total_subarrays + 1) // 2`。 
5. 添加`num * odd_count`到`total_sum`。 
6. 返回`total_sum`处理完所有元素后。 

为什么它有效：每个元素都贡献于多个子数组。 通过计算包含每个元素的奇数长度子数组的数量并乘以它的值，我们将每个子数组精确计算一次，从而确保正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def sumOddLengthSubarrays(self, arr: List[int]) -> int:
        total_sum = 0
        n = len(arr)
        for i, num in enumerate(arr):
            total_subarrays = (i + 1) * (n - i)
            odd_count = (total_subarrays + 1) // 2
            total_sum += num * odd_count
        return total_sum
```在此 Python 实现中，我们迭代数组的每个元素。 我们计算有多少个子数组包含该元素，并确定其中有多少是奇数长度。 将元素乘以该计数即可累加其对总和的贡献。 使用整数除法可确保奇数计数正确舍入。 

## 解决方案```go
func sumOddLengthSubarrays(arr []int) int {
    totalSum := 0
    n := len(arr)
    for i, num := range arr {
        totalSubarrays := (i + 1) * (n - i)
        oddCount := (totalSubarrays + 1) / 2
        totalSum += num * oddCount
    }
    return totalSum
}
```在 Go 中，我们使用与 Python 相同的逻辑处理数组。 整数除法自然会向零截断，所以`(totalSubarrays + 1) / 2`给出奇数长度子数组的正确计数.

 ## 边缘情况

 首先，像这样的单元素数组`[1]`是微不足道但很重要的。 该代码处理它是因为组合公式正确地计算出单个元素位于一个奇数长度子数组中。 

其次，一个包含所有相同元素的数组，例如`[5,5,5,5,5]`，测试算法是否正确计算重复贡献。 每个元素都乘以包含它的奇数长度子数组的数量，并且总和正确地反映了重复值。 

第三，最大输入大小`[1000]*100`确认算法不会超出 Go 等语言的时间限制或整数溢出，因为计数和乘积保持在问题约束的合理整数范围内。 

这些情况确保了最小、典型和最大输入的稳健性。
