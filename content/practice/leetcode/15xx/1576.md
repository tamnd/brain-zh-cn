[LeetCode 问题 1576](https://leetcode.com/problems/replace-all-s-to-avoid-consecutive-repeating-characters/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们取一个字符串`s`由小写英文字母和字符组成`'?'`并替换 **每个`'?'`** 使用小写字母，以便 **结果字符串中没有两个连续字符相同**。 重要的是，我们**不允许更改字符串中的任何现有字母**。 

输入字符串的长度可以是1到100，这个长度比较小。 这意味着我们可以使用简单的线性解决方案，而不必担心性能问题。 该问题保证输入字符串**不具有连续的重复字母，除非可能`'?'`**，所以我们不需要处理无效的输入字符串。 此外，它还保证始终可以进行有效的替换，因此我们不必返回失败案例。 

关键边缘情况包括完全是字符串`'?'`, 开头或结尾的字符串`'?'`和字符串，其中`'?'`两侧都被相同的字母包围，例如`"a?b"`或者`"a?aa"`。 

## 方法

 天真的或蛮力方法是尝试每个可能的小写字母替换`'?'`在字符串中，递归生成所有可能的字符串并检查连续的重复项。 虽然这在理论上可行，但效率极低，时间复杂度为$O(26^k)$在哪里$k$是的数量`'?'`人物。 这个数字呈指数级增长，因此即使是少数`'?'`可能会使暴力方法变得不可行。 

最佳方法利用了我们**不需要尝试所有字母**的观察结果。 对于每个`'?'`，我们可以选择一个**与其前一个和下一个字符不同**的字母。 由于有 26 个字母，而我们最多只需要避免两个字母（前一个和下一个），因此总是有一个有效的选择。 这会导致对字符串进行简单的**线性扫描**，替换`'?'`贪婪地同时确保不会创建连续的重复项。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(26^k) | O(26^k) | O(n) | 递归地尝试所有可能的替换，对于多个“？”效率低下 |
 | 最佳 | O(n) | O(n) | 线性扫描，取代'?' 贪婪地，总能找到有效的解决方案 |

 ## 算法演练

 1. 将输入字符串转换为可变字符列表。 Python 和 Go 中的字符串是不可变的，因此我们需要一个列表或切片来进行就地修改。 
2. 从左到右迭代字符串中的每个字符。 
3. 每当`'?'`遇到时，通过检查前一个字符（如果有）和下一个字符（如果有）来确定**有效字母**。 我们必须避免使用这些字母，以防止连续重复。 
4. 从剩余的有效选项中选择任意字母。 一个简单的方法是迭代`'a'`到`'z'`并取第一个允许的字母。 
5. 更换`'?'`与所选的字母。 
6. 处理完所有字符后，将列表重新连接成字符串并返回。 

**为什么有效：** 在每一步中，我们确保所选的替换字符与相邻字符不同。 由于有 26 个字母，避免两个特定字母将**始终留下至少 24 个选项**，保证有效的替换。 这种贪婪的选择会产生正确的最终字符串。 

## Python 解决方案```python
class Solution:
    def modifyString(self, s: str) -> str:
        s_list = list(s)
        n = len(s_list)
        
        for i in range(n):
            if s_list[i] == '?':
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    prev_char = s_list[i - 1] if i > 0 else None
                    next_char = s_list[i + 1] if i < n - 1 else None
                    if c != prev_char and c != next_char:
                        s_list[i] = c
                        break
        return ''.join(s_list)
```该实现将字符串转换为列表以实现可变性，从左到右扫描并替换`'?'`贪婪地。 这`prev_char`和`next_char`检查保证不会创建连续的重复项。 循环结束后，列表将重新连接成字符串。 

## 解决方案```go
func modifyString(s string) string {
    n := len(s)
    sList := []byte(s)
    
    for i := 0; i < n; i++ {
        if sList[i] == '?' {
            for c := byte('a'); c <= 'z'; c++ {
                var prevChar, nextChar byte
                if i > 0 {
                    prevChar = sList[i-1]
                }
                if i < n-1 {
                    nextChar = sList[i+1]
                }
                if c != prevChar && c != nextChar {
                    sList[i] = c
                    break
                }
            }
        }
    }
    return string(sList)
}
```在 Go 中，我们将字符串转换为`[]byte`为了可变性。 逻辑与 Python 版本相同，但存在类型差异和零值处理`prevChar`和`nextChar`。

 ## 边缘情况

 一个重要的边缘情况是完全由以下内容组成的字符串`'?'`， 喜欢`"???"`。 该算法通过替换每个“？”来处理这个问题 按顺序使用不重复前一个字母的字母。 由于第一个字符没有前一个字符，因此任何字母都有效。 

另一个边缘情况是当`'?'`出现在字符串的开头或结尾。 例如，`"?a"`或者`"a?"`。 在这两种情况下，算法都会检查前一个或下一个字符，并在替换过程中避免使用它们，从而确保不会出现连续重复。 

第三个边缘情况是连续的`'?'`字符，例如`"a??b"`。 该算法从左到右逐一替换它们，始终考虑前一个字符（刚刚替换）和下一个字符（固定或“？”）。 这确保了替换不会发生冲突，并且不会出现连续的重复项。
