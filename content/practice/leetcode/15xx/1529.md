[LeetCode 问题 1529](https://leetcode.com/problems/minimum-suffix-flips/)

 **难度：** 🟡 中等
 **主题：** 字符串、贪婪

 ## 解决方案

 ## 问题理解

 这个问题要求我们转换一个初始的二进制字符串`s`（全零）转换为目标二进制字符串`target`使用最少数量的**后缀翻转操作**。 后缀翻转操作涉及选择索引`i`并翻转索引中的每一位`i`到字符串的末尾。 翻转一点就意味着转动`'0'`到`'1'`和`'1'`到`'0'`。 

输入`target`是一个长度的字符串`n`只含有`'0'`和`'1'`。 输出是进行翻转操作所需的最少次数`s`等于`target`。 

约束告诉我们`1 <= n <= 10^5`，这意味着任何复杂度超过 O(n) 的解决方案都可能太慢。 输入保证有效，仅包含`'0'`和`'1'`。 

重要的边缘情况包括：

 -`target`包含全零：无需任何操作。 
-`target`包含所有：可能需要翻转一次。 
-`target`在零和一之间交替：每次值发生变化时都需要翻转。 

预先了解这些情况可确保我们不会过于复杂或错过简单的优化。 

## 方法

 ### 蛮力

 暴力方法会模拟字符串`s`并对每个可能的索引应用翻转操作，看看它是否会导致`target`。 这需要迭代`s`并重复翻转后缀，时间可能为 O(n^2)，因为每个翻转操作可能会修改最多`n`人物。 虽然这种方法是正确的，但对于输入限制而言，这种方法太慢了。 

### 最佳方法

 关键的观察是**我们只需要在当前状态时翻转`s`与当前索引处的目标不匹配**。 自从`s`从全零开始，我们可以迭代`target`从左到右。 每次当前位与最后一个“有效”状态不同时`s`，我们执行翻转。 

我们跟踪“翻转奇偶校验”——到目前为止执行的翻转次数模 2——以了解当前位是否在`s`已翻转偶数或奇数次。 这使我们能够确定它是否匹配`target`无需显式修改字符串。 每次不匹配都会触发一次翻转，从而增加我们的操作计数。 这是 O(n) 时间和 O(1) 空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 模拟所有翻转，对于 n 达到 10^5 太慢 |
 | 最佳 | O(n) | O(1) | O(1) | 跟踪翻转的奇偶性并计数不匹配 |

 ## 算法演练

 1. 初始化变量`flips`到 0，计算执行的翻转操作的次数。 
2. 初始化`current_state`到0，代表有效值`s[i]`考虑到目前为止执行的所有翻转（0 表示无翻转效果，1 表示翻转）。 
3. 迭代`target`从索引 0 到 n-1。 
4. 在每个索引处`i`， 转变`target[i]`为整数`bit`（`0`或者`1`）。 
5. 比较`bit`和`current_state`。 如果它们不同，则需要在该位置翻转。 
6. 增量`flips`并更新`current_state`到`1 - current_state`以反映翻转对后续位置的影响。 
7. 继续直到结束`target`。 返回`flips`作为最小操作次数。 

**为什么有效：**

 每次翻转都会更改所有后续位，因此精确翻转当前有效状态与目标不同的位置可确保最少的操作。 奇偶校验跟踪保证我们无需模拟整个字符串即可知道有效位。 

## Python 解决方案```python
class Solution:
    def minFlips(self, target: str) -> int:
        flips = 0
        current_state = 0  # 0 means no flip, 1 means flipped

        for char in target:
            bit = int(char)
            if bit != current_state:
                flips += 1
                current_state = 1 - current_state

        return flips
```代码初始化`flips`和`current_state`。 遍历中的每个字符`target`，检查有效位是否匹配。 如果没有，我们翻转后缀，增加计数并更新状态。 这与上面的算法完全一致。 

## 解决方案```go
func minFlips(target string) int {
    flips := 0
    currentState := 0

    for _, ch := range target {
        bit := int(ch - '0')
        if bit != currentState {
            flips++
            currentState = 1 - currentState
        }
    }

    return flips
}
```在 Go 中，我们使用 a 迭代字符串`for`循环与`range`，将每个符文转换为整数位。 逻辑与Python版本相同。 Go 小心地处理字符串和整数转换，减法`'0'`得到 0 或 1。

 ## 边缘情况

 **单个字符：** 当`target`长度为 1，答案为 0 或 1。这测试算法处理小输入时不会出现错误。 

**全零或全一：** 这些情况测试不执行不必要的翻转。 对于所有 0，翻转仍为 0。对于所有 1，索引 0 处的一次翻转就足够了。 

**交替位：**字符串如`"010101..."`每次改变都需要翻转。 这测试了算法正确跟踪翻转奇偶校验并在每次不匹配时递增计数器，而不会丢失翻转或重复计数。 

**连续块：** 字符串，例如`"001100"`验证是否正确处理多个连续更改，而不仅仅是交替位，确保逻辑适用于零和一序列。
