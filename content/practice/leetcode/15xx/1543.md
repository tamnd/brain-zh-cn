 **难度：** 🟢简单
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们清理和汇总来自`Sales`桌子。 每行包含一个唯一的`sale_id`, 一个`product_name`，和一个`sale_date`。 由于手动数据输入错误，`product_name`可能包含额外的前导或尾随空格，并且可能使用不一致的字母大小写。 我们的任务是生成一份报告，对产品名称进行标准化（小写、修剪）并汇总每个产品每月的销售总数。 这`sale_date`输出中的年份和月份应被截断`'YYYY-MM'`格式。 

输入表示原始销售记录，文本格式可能存在不一致。 输出必须是一个包含三列的表：`product_name`,`sale_date`， 和`total`代表该产品在相应月份的销售数量。 输出应按字母顺序排序`product_name`，并且如果多行具有相同的`product_name`，它们应该按以下顺序排序`sale_date`。 

由于表相对较小（自 2000 年以来的每日销售额），因此关键约束很少。 但是，我们必须处理文本不一致并确保正确聚合。 边缘情况包括仅包含空格的产品名称、大小写不同、产品没有销售的月份以及确保日期格式正确截断为年份和月份。 

## 方法

 ### 蛮力方法

 一种简单的方法是迭代所有销售，通过修剪空格并转换为小写来清理每个产品名称，然后在代码中手动按产品名称和月份进行分组。 我们可以将计数存储在字典中，键为`(product_name, year-month)`。 虽然这可以保证正确性，但在 SQL 中是不必要的，因为 SQL 提供了聚合函数，例如`COUNT()`和字符串函数，例如`TRIM()`和`LOWER()`。 使用编程方法还会引入内存管理和排序的开销。 

### 最佳方法

 关键的观察是 SQL 已经具有清理和聚合数据的功能。 我们可以使用`TRIM()`删除空格，`LOWER()`使情况正常化，并且`DATE_FORMAT()`（MySQL）或`TO_CHAR()`(PostgreSQL) 提取`YYYY-MM`从`sale_date`。 那么，我们可以`GROUP BY`规范化的产品名称和月份，以及`ORDER BY`因此。 这利用数据库引擎进行高效聚合和排序，从而最大限度地减少应用程序代码中的内存使用和计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 使用字典或映射在代码中手动迭代和聚合 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 使用SQL聚合，由数据库引擎处理排序|

 ## 算法演练

 1. 选择`product_name`从`Sales`桌子。 
2. 使用`TRIM()`删除前导和尾随空格。 
3. 使用`LOWER()`将产品名称转换为小写。 
4. 提取年份和月份`sale_date`使用`DATE_FORMAT(sale_date, '%Y-%m')`。 
5. 计算每个行的行数`(product_name, year-month)`组合使用`COUNT(*)`。 
6. 按标准化对结果进行分组`product_name`并被截断`sale_date`。 
7. 将最终结果先排序`product_name`上升，然后通过`sale_date`上升。 

**为什么有效：** SQL 聚合保证具有相同规范化产品名称和月份的所有行都被精确计数一次。 使用`TRIM()`和`LOWER()`确保命名一致，并且`DATE_FORMAT()`标准化日期。 排序可确保输出满足所需的顺序。 

## Python 解决方案```python
# Python does not directly run SQL in LeetCode; this is a demonstration using sqlite3
import sqlite3

def fix_product_name_format(conn: sqlite3.Connection) -> list[tuple[str, str, int]]:
    cursor = conn.cursor()
    query = """
    SELECT LOWER(TRIM(product_name)) AS product_name,
           STRFTIME('%Y-%m', sale_date) AS sale_date,
           COUNT(*) AS total
    FROM Sales
    GROUP BY product_name, sale_date
    ORDER BY product_name ASC, sale_date ASC
    """
    cursor.execute(query)
    return cursor.fetchall()
```在此 Python 版本中，我们假设有一个活动的数据库连接`conn`。 SQL 查询规范化`product_name`, 格式`sale_date`到`YYYY-MM`，计算每个产品每月的销售额，按两个字段进行分组，并正确订购结果。 

## 解决方案```go
package main

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
    "fmt"
)

type ProductSale struct {
    ProductName string
    SaleDate    string
    Total       int
}

func FixProductNameFormat(db *sql.DB) ([]ProductSale, error) {
    query := `
    SELECT LOWER(TRIM(product_name)) AS product_name,
           DATE_FORMAT(sale_date, '%Y-%m') AS sale_date,
           COUNT(*) AS total
    FROM Sales
    GROUP BY product_name, sale_date
    ORDER BY product_name ASC, sale_date ASC
    `
    rows, err := db.Query(query)
    if err != nil {
        return nil, err
    }
    defer rows.Close()

    var results []ProductSale
    for rows.Next() {
        var ps ProductSale
        if err := rows.Scan(&ps.ProductName, &ps.SaleDate, &ps.Total); err != nil {
            return nil, err
        }
        results = append(results, ps)
    }
    return results, nil
}

func main() {
    db, err := sql.Open("mysql", "user:password@/dbname")
    if err != nil {
        panic(err)
    }
    defer db.Close()

    results, err := FixProductNameFormat(db)
    if err != nil {
        panic(err)
    }

    for _, r := range results {
        fmt.Println(r)
    }
}
```在 Go 中，主要区别包括使用`sql.DB`对于数据库操作，将行扫描到结构中，并显式处理错误。 SQL 查询保持不变。
