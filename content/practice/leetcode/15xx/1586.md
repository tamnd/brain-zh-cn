 **难度：** 🟡 中等
 **主题：** 堆栈、树、设计、二叉搜索树、二叉树、迭代器

 ## 解决方案

 ## 问题理解

 该问题需要实现一个`BSTIterator`允许对二叉搜索树 (BST) 的有序序列进行向前和向后遍历的类。 BST 的中序遍历按升序访问节点。 迭代器必须支持四种操作：`next()`,`prev()`,`hasNext()`， 和`hasPrev()`。 Initially, the iterator is positioned just before the first element in the traversal, so the first call to`next()`返回最小元素。 输入是由其根节点表示的 BST，输出是通过迭代器方法访问的元素序列。 

约束表明 BST 最多可以包含`10^5`节点并且最多可以有`10^5`调用迭代器方法。 节点的值范围为`0`到`10^6`。 这意味着我们需要一个在时间和空间上都高效的解决方案。 边缘情况包括具有单个节点的 BST、调用`prev()`初始化后立即发生，并且树倾斜（完全不平衡）。 

## 方法

 **暴力方式**是在初始化时执行完整的中序遍历，将所有值存储在一个列表中，并维护一个指针来向前和向后遍历。 这保证了正确性，因为列表将包含按排序顺序的所有节点，但它需要`O(n)`存储空间和`O(n)`初始遍历的时间。 每个操作（`next`和`prev`）然后会采取`O(1)`时间。 

后续的**最佳方法**是避免预先存储整个遍历。 我们可以使用堆栈的受控有序遍历来按需生成元素。 这允许`next()`摊销运行`O(1)`时间和用途`O(h)`堆栈的空间，其中`h`是树的高度。 支持`prev()`，我们需要维护列表中先前访问过的元素的历史记录，这允许向后遍历`O(1)`每次操作的时间，同时仍将空间使用限制为已遍历的元素数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) 初始化，O(1) 每次操作 | O(n) | 预计算完整的中序遍历 |
 | 最佳 | O(1) 每次操作摊销 | O(h + k) | 用于生成下一个元素的堆栈，用于历史记录的列表，h = 树高度，k = 访问过的元素 |

 ## 算法演练

 1. 使用 BST 根初始化迭代器。 使用堆栈来帮助按需有序遍历。 遍历树的最左边的分支并将所有节点压入堆栈。 这会准备堆栈，以便最小的元素位于顶部。 
2. 维持`history`列表来存储返回的元素`next()`或者`prev()`。 保留一个`index`跟踪历史记录中当前位置的指针。 
3.`next()`首先检查是否`index`指向已经存在的元素`history`。 如果是，只需增加`index`并返回该元素。 如果没有，则从堆栈中弹出顶部节点，并将其值附加到`history`，将其右子节点的最左边的分支压入堆栈，递增`index`，并返回值。 
4.`prev()`递减`index`并返回元素`history`在新的`index`。 由于我们维护历史列表，因此向后移动不需要遍历树。 
5.`hasNext()`返回 true 如果`index`小于的长度`history`或者如果堆栈不为空。`hasPrev()`返回 true 如果`index`大于 0。 

**为什么有效**：堆栈确保我们始终准备好下一个最小的元素`next()`，并且历史列表保证正确`prev()`运营。 不变的是当前元素之前的所有元素`index`在`history`已经被访问过，并且堆栈总是有下一个未访问的元素。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional

class BSTIterator:

    def __init__(self, root: Optional[TreeNode]):
        self.stack = []
        self.history = []
        self.index = -1
        self._push_left_branch(root)

    def _push_left_branch(self, node: Optional[TreeNode]):
        while node:
            self.stack.append(node)
            node = node.left

    def hasNext(self) -> bool:
        return self.index + 1 < len(self.history) or bool(self.stack)

    def next(self) -> int:
        self.index += 1
        if self.index == len(self.history):
            node = self.stack.pop()
            self.history.append(node.val)
            self._push_left_branch(node.right)
        return self.history[self.index]

    def hasPrev(self) -> bool:
        return self.index > 0

    def prev(self) -> int:
        self.index -= 1
        return self.history[self.index]
```Python 实现使用堆栈按顺序跟踪 BST 中未访问的部分。`_push_left_branch`将节点的所有左子节点推入堆栈。`history`商店访问过的元素，允许`prev()`以恒定的时间工作。`index`保持历史地位。 

## 解决方案```go
type BSTIterator struct {
	stack   []*TreeNode
	history []int
	index   int
}

func Constructor(root *TreeNode) BSTIterator {
	it := BSTIterator{stack: []*TreeNode{}, history: []int{}, index: -1}
	it.pushLeftBranch(root)
	return it
}

func (this *BSTIterator) pushLeftBranch(node *TreeNode) {
	for node != nil {
		this.stack = append(this.stack, node)
		node = node.Left
	}
}

func (this *BSTIterator) HasNext() bool {
	return this.index+1 < len(this.history) || len(this.stack) > 0
}

func (this *BSTIterator) Next() int {
	this.index++
	if this.index == len(this.history) {
		n := len(this.stack) - 1
		node := this.stack[n]
		this.stack = this.stack[:n]
		this.history = append(this.history, node.Val)
		this.pushLeftBranch(node.Right)
	}
	return this.history[this.index]
}

func (this *BSTIterator) HasPrev() bool {
	return this.index > 0
}

func (this *BSTIterator) Prev() int {
	this.index--
	return this.history[this.index]
}
```在 Go 中，切片用于堆栈和历史记录。 弹出是通过切掉最后一个元素来完成的。 Nil 检查取代了 Python 的检查`None`。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(1) 每次操作摊销 | 每个节点在堆栈上都会被压入/弹出一次。`next`/`prev`历史上的复杂度是O(1)。 |
 | 空间| O(h + k) | 堆栈使用 O(h) 作为树高，历史记录存储 k 个访问过的节点。 |

 摊销时间占偶尔的`_push_left_branch`移动到节点的右子树时进行遍历。
