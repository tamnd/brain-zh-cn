[LeetCode 问题 1519](https://leetcode.com/problems/number-of-nodes-in-the-sub-tree-with-the-same-label/)

 **难度：** 🟡 中等
 **主题：** 哈希表、树、深度优先搜索、广度优先搜索、计数

 ## 解决方案

 ## 问题理解

 这个问题给了我们一棵树`n`节点编号从`0`到`n - 1`。 树由一个数组表示`edges`，其中每条边连接两个节点`ai`和`bi`。 每个节点还有一个标签，表示为字符串`labels`， 在哪里`labels[i]`是节点的标签`i`。 树的根始终是节点`0`。 

我们被要求返回一个数组`ans`尺寸的`n`， 在哪里`ans[i]`是以节点为根的 **子树中的节点数`i`** 与节点具有相同标签`i`。 子树包括节点本身及其所有后代。 

输入保证图是一棵树：它是连通的并且没有循环，并且`edges.length`正是`n - 1`。 标签由小写英文字母组成。 约束条件允许`n`达到`10^5`，这意味着任何比线性或接近线性复杂度更差的解决方案都可能太慢。 

需要注意的要点：

 1. 每个节点都在其子树中计数自己。 
2. 我们需要比较标签进行计数，这需要某种形式的频率跟踪。 
3. 边缘情况包括具有唯一标签的节点、具有相同标签的所有节点或树是直线（退化树）。 

## 方法

 ### 蛮力

 一种简单的方法是对每个节点分别执行**深度优先搜索（DFS）**或**宽度优先搜索（BFS）**来遍历其子树并统计具有相同标签的节点数量。 对于每个节点，这需要遍历所有可能的节点`n`最坏情况下的节点，导致总时间复杂度为`O(n^2)`。 这是正确的，但对于具有以下特征的大树来说是不可行的`n`最多`10^5`。 

### 最佳方法

 关键的观察是我们不需要独立遍历每个节点的子树。 我们可以从根执行**单个 DFS，并将标签计数从子级传播到其父级。 使用频率数组（或哈希图）来计算子树中每个标签的出现次数使我们能够有效地计算`ans[i]`对于**一次遍历**中的每个节点。 这将复杂性降低到相对于节点数量的线性时间。 

我们可以存储每个子树的所有 26 个小写字母的计数，并通过添加子树的计数来更新父树的计数。 节点自身标签的计数给出了该节点的答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 每个节点上分别进行DFS/BFS |
 | 最佳| O(n) | O(n) | 单个 DFS，将标签计数从子级传播到父级 |

 ## 算法演练

 1. 建立邻接表`edges`来代表树。 这允许快速访问每个节点的子节点。 
2.初始化一个答案数组`ans`尺寸的`n`带零。 
3.定义递归DFS函数`dfs(node, parent)`:

 1. 创建频率数组`count`大小 26 初始化为 0。 
2. 迭代每个子项`node`在邻接表中：

 1. 跳过父节点，避免重新访问上一个节点。 
2. 递归调用`dfs(child, node)`获取孩子的频率数组。 
3. 将子节点的计数添加到当前节点的计数中`count`。 
3. 增加对应的计数`labels[node]`1.
 4. 设置`ans[node]`到计数`labels[node]`。 
5. 返回`count`大批。 
4. 打电话`dfs(0, -1)`从根目录启动 DFS。 
5. 返回`ans`大批。 

**工作原理：** 每个 DFS 调用都会聚合来自所有后代节点（包括其自身）的标签计数。 这确保了对于每个节点，我们正确计算其子树中有多少节点共享其标签。 通过向上传播计数，我们可以在一次遍历中有效地计算所有节点的答案。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubTrees(self, n: int, edges: List[List[int]], labels: str) -> List[int]:
        adj = defaultdict(list)
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        
        ans = [0] * n
        
        def dfs(node: int, parent: int) -> List[int]:
            count = [0] * 26
            for child in adj[node]:
                if child == parent:
                    continue
                child_count = dfs(child, node)
                for i in range(26):
                    count[i] += child_count[i]
            label_index = ord(labels[node]) - ord('a')
            count[label_index] += 1
            ans[node] = count[label_index]
            return count
        
        dfs(0, -1)
        return ans
```**说明：** 邻接列表允许快速访问子项。 DFS 函数聚合子树中每个标签的计数。 对于每个节点，处理完所有子节点后，我们增加节点标签的计数并将其存储在`ans`。 此方法可确保单次 DFS 遍历的所有计数都是正确的。 

## 解决方案```go
func countSubTrees(n int, edges [][]int, labels string) []int {
    adj := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        adj[u] = append(adj[u], v)
        adj[v] = append(adj[v], u)
    }
    
    ans := make([]int, n)
    
    var dfs func(node, parent int) [26]int
    dfs = func(node, parent int) [26]int {
        var count [26]int
        for _, child := range adj[node] {
            if child == parent {
                continue
            }
            childCount := dfs(child, node)
            for i := 0; i < 26; i++ {
                count[i] += childCount[i]
            }
        }
        idx := labels[node] - 'a'
        count[idx]++
        ans[node] = count[idx]
        return count
    }
    
    dfs(0, -1)
    return ans
}
```**说明：** Go 版本镜像了 Python 逻辑。 我们使用固定大小的数组`[26]int`用于计数而不是动态列表。 切片用于邻接列表。 递归DFS函数更新计数并填充`ans`大批。 Go 没有默认字典，因此预先初始化了邻接切片。 

## 工作示例

 **示例1：**`n = 7, edges = [[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], labels = "abaedcd"`DFS 期间：

 | 节点| 子树标签 | 标签计数[节点] | ans[节点] |
 | --- | --- | --- | --- |
 | 4 | d | 1 | 1 |
 | 5 | c | 1 | 1 |
 | 1 | b、d、c | b = 1 | 1 |
 | 3 | 电子| 1 | 1 |
 | 6 | d | 1 | 1 |
 | 2 | a、e、d | a = 1 | 1 |
 | 0 | a、b、a、e、c、d、d | a = 2 | 2 |

 **输出：**`[2,1,1,1,1,1,1]`**示例2：**`n = 4, edges = [[0,1],[1,2],[0,3]], labels = "bbbb"`DFS 累积每个子树中“b”的计数，给出`[4,2,1,1]`。 

**示例3：**`n = 5, edges = [[0,1],[0,2],[1,3],[0,4]], labels = "aabab"`DFS 收益率`[3,2,1,1,1]`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | DFS中每个节点被访问一次，每条边被遍历两次。 |
 | 空间| O(n) | 邻接列表使用 O(n)，在最坏情况（倾斜树）中递归堆栈高达 O(n)，计数数组每个节点使用 O(26)，但可重复使用。 |

 这种线性复杂性使解决方案高效`n`最多`10^5`。
