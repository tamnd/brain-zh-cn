 # LeetCode 1520 - 不重叠子串的最大数量

 ## 问题理解

 这个问题要求我们从给定的小写字符串中选择尽可能多的不重叠的子字符串`s`，同时满足严格的收容规则。 

仅当子字符串包含字符时，子字符串才被视为有效`c`，它还包含每次出现的`c`存在于原始字符串中的任何位置。 换句话说，如果子字符串甚至包含一个字母，则该子字符串必须完全覆盖原始字符串中该字母的整个范围。 

目标不仅仅是找到有效的子字符串。 我们必须最大化不重叠的有效子串的数量。 如果多个解包含相同数量的子串，我们必须选择总组合长度最小的一个。 

输入是单个字符串`s`仅包含小写英文字母。 字符串长度可以大到`10^5`，它立即告诉我们所有子串的指数或二次强力枚举将无法有效地工作。 

关键的难点来自于角色之间的互动。 如果我们在子字符串中包含一个字符，我们可能会被迫扩展子字符串以包含该字符的所有出现位置。 在扩展过程中，我们可能会遇到新的角色，它们的出现范围会进一步扩大，从而导致额外的扩展。 这种连锁效应使得问题比普通的区间选择更加微妙。 

一些边缘情况很重要：

 - 所有字符都是唯一的字符串，每个字符都成为其自己的有效子字符串。 
- 所有字符都相同的字符串，仅可能有一个子字符串。 
- 嵌套字符范围可能会导致较小的子字符串更合适的情况，因为它允许更多的总子字符串。 
- 重叠的有效间隔需要仔细的贪婪选择，以最大化计数，同时最小化总长度。 

## 方法

 ### 蛮力方法

 暴力解决方案将生成每个可能的子字符串并测试它是否有效。 

为了验证子字符串，我们将检查其中的每个字符，并验证原始字符串中该字符的所有出现位置是否也位于子字符串内。 收集所有有效子串后，我们可以尝试每一种不重叠子串的组合来找到最佳答案。 

这种方法是正确的，因为它详尽地探索了所有可能性。 然而，这在计算上是不可行的。 

一个长度的字符串`n`包含`O(n^2)`子串。 验证每个子字符串的成本高达`O(n)`，并且搜索所有不重叠的组合呈指数增长。 和`n = 10^5`，这种方法是不可能的。 

### 最优贪心区间法

 重要的见解是每个有效子字符串都对应于某些起始字符的最小有效间隔。 

对于每个字符，我们首先计算：

 - 字符第一次出现
 - 字符的最后一次出现

 然后，从字符第一次出现开始，我们尝试构造包含所有所需字符的最小有效区间。 

扫描间隔时：

 - 如果我们遇到第一次出现在当前间隔开始之前的字符，则该间隔无效。 
- 否则，我们扩展间隔结束以包括我们遇到的每个字符的最后一次出现。 

此过程创建作为最小有效子串的候选间隔。 

一旦我们有了所有有效的间隔，问题就变成了经典的间隔调度问题。 为了最大化非重叠间隔的数量同时最小化总长度，我们通过增加结束位置来贪婪地选择间隔。 

由于只有 26 个小写英文字母，候选区间的数量极少，使得该算法即使对于大型字符串也非常高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n³) 或更糟 | O(n²) | 枚举并验证所有子字符串 |
 | 最佳| O(n) | O(1) | O(1) | 构建最小有效间隔并贪婪地选择 |

 ## 算法演练

 1. 计算字符串中每个字符的第一次出现和最后一次出现。 

我们创建两个大小为 26 的数组：

 -`first[c]`存储第一个索引 where 字符`c`出现。 
-`last[c]`存储最后一个索引 where 字符`c`出现。 

这些范围定义了每个字符所需的最小跨度。 
2. 迭代字符串并仅在第一次出现时尝试构造区间。 

如果索引`i`不是第一次出现`s[i]`，那么从那里开始一个子串就不能产生最小有效间隔。 
3. 构造最小有效区间。 

最初：

-`start = i`-`end = last[s[i]]`然后扫描从`start`到`end`。 
4.必要时扩大间隔。 

扫描区间内的字符时：

 - 如果某个字符之前第一次出现过`start`，该间隔无效，因为我们无法在不向左扩展的情况下包含该字符的所有出现位置。 
- 否则，更新`end`到电流的最大值`end`以及当前字符的最后一次出现。 

这保证了间隔包含每个包含的字符的所有出现。 
5. 存储每个有效间隔。 

每个成功的间隔代表以字符第一次出现为根的最小有效子串。 
6. 贪婪地选择不重叠的区间。 

按结束位置对间隔进行排序或处理。 

维持：

-`previous_end`，最后一个选定区间的结束索引。 

如果间隔的开始大于，则选择一个间隔`previous_end`。 

选择最早的完成时间间隔可以为未来的时间间隔留下最大的空间。 
7. 从选定的区间中提取子字符串。 

使用切片将间隔边界转换回实际的子串。 

### 为什么它有效

 每个有效的子字符串必须完全包含它所包含的所有字符的范围。 间隔扩展过程通过重复扩展间隔以包含所需的字符范围来保证此属性。 

构造的间隔是最小的，因为我们只在必要时扩展。 在所有有效区间中，贪婪地选择具有最早结束位置的区间可以最大化非重叠选择的数量。 这是间隔调度问题中使用的标准证明。 

当多个解包含相同数量的子串时，选择最小间隔自然会最小化总长度。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxNumOfSubstrings(self, s: str) -> List[str]:
        n = len(s)

        first = [n] * 26
        last = [-1] * 26

        # Record first and last occurrence of each character
        for i, ch in enumerate(s):
            idx = ord(ch) - ord('a')
            first[idx] = min(first[idx], i)
            last[idx] = i

        def build_interval(start: int) -> tuple[int, int]:
            end = last[ord(s[start]) - ord('a')]
            i = start

            while i <= end:
                idx = ord(s[i]) - ord('a')

                # Invalid interval
                if first[idx] < start:
                    return -1, -1

                end = max(end, last[idx])
                i += 1

            return start, end

        intervals = []

        # Generate all minimal valid intervals
        for i in range(n):
            idx = ord(s[i]) - ord('a')

            if i == first[idx]:
                interval = build_interval(i)

                if interval[0] != -1:
                    intervals.append(interval)

        # Greedy interval scheduling by end position
        intervals.sort(key=lambda x: x[1])

        result = []
        previous_end = -1

        for start, end in intervals:
            if start > previous_end:
                result.append(s[start:end + 1])
                previous_end = end

        return result
```该实现首先预处理字符串以确定每个字符的第一次出现和最后一次出现。 这允许在间隔构造期间恒定时间访问字符范围。 

这`build_interval`辅助函数尝试从给定索引开始构造最小有效子字符串。 每当间隔内的字符出现进一步向右扩展时，间隔就会动态扩展。 

如果扫描遇到第一次出现在间隔开始之前的字符，则间隔将变为无效，因为它无法包含该字符的所有出现而不向左延伸。 

生成所有有效间隔后，该解决方案按结束索引对它们进行排序，并应用经典的贪婪间隔调度策略。 选择最早完成的间隔可以最大化非重叠子串的数量。 

最后，将选定的间隔转换为实际的子字符串并返回。 

## 解决方案```go
package main

import "sort"

func maxNumOfSubstrings(s string) []string {
	n := len(s)

	first := make([]int, 26)
	last := make([]int, 26)

	for i := 0; i < 26; i++ {
		first[i] = n
		last[i] = -1
	}

	// Record first and last occurrence
	for i := 0; i < n; i++ {
		idx := int(s[i] - 'a')

		if i < first[idx] {
			first[idx] = i
		}

		last[idx] = i
	}

	buildInterval := func(start int) (int, int) {
		end := last[int(s[start]-'a')]

		for i := start; i <= end; i++ {
			idx := int(s[i] - 'a')

			// Invalid interval
			if first[idx] < start {
				return -1, -1
			}

			if last[idx] > end {
				end = last[idx]
			}
		}

		return start, end
	}

	intervals := make([][2]int, 0)

	// Generate valid intervals
	for i := 0; i < n; i++ {
		idx := int(s[i] - 'a')

		if i == first[idx] {
			start, end := buildInterval(i)

			if start != -1 {
				intervals = append(intervals, [2]int{start, end})
			}
		}
	}

	// Sort by ending position
	sort.Slice(intervals, func(i, j int) bool {
		return intervals[i][1] < intervals[j][1]
	})

	result := make([]string, 0)
	previousEnd := -1

	for _, interval := range intervals {
		start := interval[0]
		end := interval[1]

		if start > previousEnd {
			result = append(result, s[start:end+1])
			previousEnd = end
		}
	}

	return result
}
```Go 实现遵循与 Python 解决方案相同的算法结构。 使用数组代替字典，因为只有 26 个小写字母。 

间隔列表存储为固定大小整数数组的切片。 Go 需要使用显式排序`sort.Slice`。 

Go 中的字符串切片使用字节索引，这在这里是安全的，因为输入仅包含小写英文字母。 不需要特殊的 Unicode 处理。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个字符都会被处理固定次数 |

 对字符串的预处理需要线性时间。 区间构造总体上也保持线性，因为每次扫描都受到字符串大小的限制，并且最多有 26 个候选区间。

 ## 边缘情况

 当字符串中的每个字符都是唯一的时，就会出现一种重要的边缘情况。 在这种情况下，每个字符的第一次出现和最后一次出现都是相同的索引。 每个字符都成为长度为 1 的有效子字符串。 有缺陷的实现可能会不必要地合并间隔，但间隔扩展逻辑正确地将它们分开。 

另一个关键情况是所有字符完全重叠，例如`"aaaa"`或者`"ababa"`。 在这里，选择较小的子字符串将违反要求包含每个字符的所有出现的规则。 该实现通过扩展间隔来处理此问题，直到完全覆盖所有相关字符范围。 

一种更微妙的边缘情况涉及嵌套间隔，其中一个有效间隔完全包含另一个有效间隔。 例如，在`"abbaccd"`, 区间`"abba"`包含`"bb"`。 选择较小的间隔更好，因为它允许更多的总子串和更小的总长度。 基于最早完成间隔的贪心策略正确地优先考虑了较短的间隔。 

当区间扩展发现首次出现位于当前区间开始之前的字符时，会发生最后一个重要情况。 这意味着如果不向左延伸，候选区间永远不会有效。 该实现会立即检测到这一点并丢弃该间隔，从而防止无效子字符串进入结果集。
