[LeetCode 问题 1565](https://leetcode.com/problems/unique-orders-and-customers-per-month/)

 **难度：** 🟢简单
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题需要分析订单表来计算每月的统计数据。 具体来说，对于出现在`Orders`表中，我们需要确定两个指标：唯一订单数和订单发票大于 20 的唯一客户数。输入由一个包含四列的表组成：`order_id`（唯一标识符），`order_date`（订单日期），`customer_id`（谁下的订单），以及`invoice`（支付金额）。 预期输出是一个按月聚合的表（在`YYYY-MM`格式），列出该月合格订单的数量和唯一客户的数量。 

关键约束和细节是：所有订单都有唯一的`order_id`,`invoice`金额是数字，没有订单超过 20 的月份应从结果中排除。 边缘情况包括所有发票 ≤ 20 的月份、同一客户有多个订单的月份以及订单跨越年度界限的月份。 

## 方法

 蛮力方法将涉及迭代表中的每一行，从`order_date`，并为每个月的合格订单和客户维护单独的列表或集合。 虽然这种方法有效，但当数据集很大时，它会变得很麻烦，因为它需要迭代多次并手动管理聚合。 

最佳方法是使用 SQL 聚合函数。 首先过滤掉订单`invoice <= 20`，然后我们可以按提取的月份进行分组并计算不同的`order_id`和`customer_id`在单个查询中。 关键的见解是利用 SQL`COUNT(DISTINCT ...)`和`DATE_FORMAT`（或等效方法）直接在数据库中执行聚合，避免任何手动迭代或中间存储。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 迭代所有订单，在哈希图中手动聚合每月统计数据 |
 | 最佳 | O(n) | O(米) | SQL 聚合：过滤、按月分组、计算不同的订单和客户，其中 n = 总行数，m = 月数 |

 ## 算法演练

 1. 过滤`Orders`表只保留其中的行`invoice > 20`。 这确保只有符合条件的订单才会计入计数。 
2. 从中提取月份`order_date`柱子。 在 SQL 中，这可以通过使用来完成`DATE_FORMAT(order_date, '%Y-%m')`。 这会产生一个字符串`YYYY-MM`格式。 
3. 按提取的月份对过滤表进行分组。 这会为每个独特的月份创建一个组。 
4. 计算每组中不同的数量`order_id`得到的值`order_count`。 
5. 计算每组中不同的数量`customer_id`得到的值`customer_count`。 
6.返回包含列的聚合表`month`,`order_count`， 和`customer_count`。 不需要排序。 

为什么有效：通过首先过滤，我们确保只考虑发票数量大于 20 的订单。 按月汇总可确保正确计算正确月份的所有订单和客户。 使用`COUNT(DISTINCT ...)`防止重复计算订单或客户，即使同一个月内某个客户存在多个订单。 

## Python 解决方案```python
import pandas as pd

def unique_orders_customers_per_month(orders: pd.DataFrame) -> pd.DataFrame:
    # Filter orders with invoice > 20
    filtered = orders[orders['invoice'] > 20].copy()
    
    # Extract month in YYYY-MM format
    filtered['month'] = filtered['order_date'].dt.to_period('M').astype(str)
    
    # Group by month and compute distinct counts
    result = filtered.groupby('month').agg(
        order_count=('order_id', 'nunique'),
        customer_count=('customer_id', 'nunique')
    ).reset_index()
    
    return result
```Python 实现反映了 SQL 方法。 首先，它会在 DataFrame 中筛选超过 20 张的发票。然后，它会创建一个新列，其中包含从订单日期中提取的月份。 最后，它按月分组并使用以下方法计算唯一订单和唯一客户的数量`nunique`。 

## 解决方案```go
package main

import (
    "database/sql"
    "fmt"
    _ "github.com/go-sql-driver/mysql"
)

type Result struct {
    Month         string
    OrderCount    int
    CustomerCount int
}

func UniqueOrdersCustomersPerMonth(db *sql.DB) ([]Result, error) {
    query := `
        SELECT 
            DATE_FORMAT(order_date, '%Y-%m') AS month,
            COUNT(DISTINCT order_id) AS order_count,
            COUNT(DISTINCT customer_id) AS customer_count
        FROM Orders
        WHERE invoice > 20
        GROUP BY month
    `
    
    rows, err := db.Query(query)
    if err != nil {
        return nil, err
    }
    defer rows.Close()

    var results []Result
    for rows.Next() {
        var r Result
        if err := rows.Scan(&r.Month, &r.OrderCount, &r.CustomerCount); err != nil {
            return nil, err
        }
        results = append(results, r)
    }
    
    return results, nil
}
```Go 解决方案执行类似于 Python Pandas 方法的 SQL 查询。 主要区别在于与数据库的显式连接以及对 Go 结构的行扫描。`COUNT(DISTINCT ...)`自动处理独特的订单和客户。 错误处理对于数据库操作至关重要。 

## 工作示例

 使用示例表：

 1. 过滤订单`invoice > 20`。 剩余行：1、2、4、7、8、9。 
2.提取月份：2020-09、2020-09、2020-10、2020-12、2020-12、2021-01。 
3. 按月份分组：

 - 2020-09：订单 = [1, 2]，客户 = [1, 2]
 - 2020-10：订单 = [4]，客户 = [3]
 - 2020-12：订单 = [7, 8]，客户 = [4]
 - 2021 年 1 月：订单 = [9]，客户 = [3]
 4. 统计每个月的不同订单和客户，生成输出表。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们对每行迭代一次以过滤和提取月份，然后进行聚合，这与订单数 n | 呈线性关系。 
| 空间| O(米) | 分组结果和中间结构所需的空间，其中 m 是唯一月份的数量 |

 复杂性是有效的，因为过滤和分组操作是通过Python中的向量化操作或Go中的SQL引擎优化来处理的。

 ## 边缘情况

 一种边缘情况是所有订单的发票 ≤ 20 的月份。算法首先通过过滤正确排除此类月份。 另一个边缘情况是客户在同一个月内发出多个合格订单； 使用`COUNT(DISTINCT customer_id)`确保它们只被计算一次。 第三个边缘情况涉及年份边界，例如 12 月 31 日和 1 月 1 日的订单； 提取月份为`YYYY-MM`确保这些被视为单独的月份并正确计数。 这些情况都可以通过过滤和分组步骤自然处理。
