[LeetCode 问题 1579](https://leetcode.com/problems/remove-max-number-of-edges-to-keep-graph-filled-traversable/)

 **难度：** 🔴难
 **主题：** 并查集、图论

 ## 解决方案

 ## 问题理解

 该问题提出了一个无向图`n`节点和三种类型的边：类型 1 代表 Alice，类型 2 代表 Bob，类型 3 代表 Alice 和 Bob。 输入`edges`是一个数组，其中每个元素`[type, u, v]`表示连接节点的双向边`u`和`v`指定类型的。 目标是确定**可以删除的最大边数**，同时仍然允许 Alice 和 Bob 遍历整个图。 如果 Alice 或 Bob 都不可能遍历所有节点，我们必须返回`-1`。 

简单来说，我们需要同时维护 Alice 和 Bob 的**连接**，并且可以删除对这种连接没有贡献的边。 由于 Alice 和 Bob 共享类型 3 边，这些边是最有价值的，因为它们计入双方的连接。 类型 1 和类型 2 边缘仅对其各自的用户有用。 约束条件，与`n`最多`10^5`和边缘到`3 * n * (n - 1) / 2`，表明暴力解决方案是不可行的，并且有效的并查（不相交集并集）方法是合适的。 

重要的边缘情况包括没有所有边就无法连接的图、所有边均为类型 3 的图以及一个用户但另一个用户不连接的组件。 

## 方法

 **暴力方法**：可以尝试一条一条地删除每条边，并检查结果图是否仍然可以由 Alice 和 Bob 使用 BFS 或 DFS 完全遍历。 这种做法是正确的，但是效率极低。 对于每个边缘移除，检查连通性是`O(n + m)`，导致整体复杂性`O(m*(n+m))`，这对于上限约束是不可行的。 

**最佳方法**：关键的见解是使用 **Union-Find** 来跟踪连接。 我们首先处理**类型 3 边**，因为它们有助于 Alice 和 Bob 的连接。 然后我们分别处理 **Alice 的类型 1 边** 和 **Bob** 的类型 2 边。 如果一条边连接了同一连接组件中已有的节点，则它是多余的，可以删除。 处理完所有边后，我们检查 Alice 和 Bob 是否都已连接（即，它们各自的并查结构只有一个组件）。 如果是这样，冗余边的计数给出了我们可以删除的最大数量。 否则，返回`-1`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m*(n+m)) | O(n) | 一条一条地删除边并使用 BFS/DFS 检查连通性 |
 | 最佳 | O(m * α(n)) | O(m * α(n)) | O(n) | 使用并查，首先处理类型 3 边，然后处理类型 1 和类型 2 |

 这里，`α(n)`是阿克曼反函数，对于所有实际目的来说它几乎是恒定的。 

## 算法演练

 1. 初始化两个并查结构，一个为 Alice，一个为 Bob，每个包含`n`节点。 
2. 将边排序或分成类型 3、类型 1 和类型 2 列表。 
3. 初始化计数器`removed = 0`对于多余的边缘。 
4. **首先处理类型 3 的边**：对于每条边`(u, v)`， 如果`u`和`v`已经在 Alice 的 Union-Find 中连接（和 Bob 的，因为类型 3 影响两者），递增`removed`。 否则，联合`u`和`v`在 Alice 和 Bob 的 Union-Find 中。 
5. **处理 Alice 的类型 1 边**：如果`u`和`v`已在 Alice 的并查、增量中连接`removed`。 否则，将它们联合起来。 
6. **处理 Bob 的类型 2 边**：类似地，如果断开连接则并集，否则递增`removed`。 
7. 处理完所有边后，检查 Alice 和 Bob 的并查结构是否都具有一个连通分量。 如果没有，则返回`-1`。 
8. 返回值`removed`。 

**为什么有效**：通过优先考虑类型 3 边缘，我们可以最大限度地提高共享连接性并最大限度地减少对单独的类型 1 或类型 2 边缘的需求。 冗余边缘对连接没有贡献，可以安全地删除。 Union-Find 保证有效地正确跟踪连接的组件。 

## Python 解决方案```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n + 1))
        self.rank = [0] * (n + 1)
        self.components = n
    
    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x: int, y: int) -> bool:
        xr, yr = self.find(x), self.find(y)
        if xr == yr:
            return False
        if self.rank[xr] < self.rank[yr]:
            self.parent[xr] = yr
        elif self.rank[xr] > self.rank[yr]:
            self.parent[yr] = xr
        else:
            self.parent[yr] = xr
            self.rank[xr] += 1
        self.components -= 1
        return True

class Solution:
    def maxNumEdgesToRemove(self, n: int, edges: List[List[int]]) -> int:
        alice_uf = UnionFind(n)
        bob_uf = UnionFind(n)
        removed = 0
        
        # Process Type 3 edges first
        for t, u, v in edges:
            if t == 3:
                if not alice_uf.union(u, v):
                    removed += 1
                else:
                    bob_uf.union(u, v)
        
        # Process Type 1 edges for Alice
        for t, u, v in edges:
            if t == 1:
                if not alice_uf.union(u, v):
                    removed += 1
        
        # Process Type 2 edges for Bob
        for t, u, v in edges:
            if t == 2:
                if not bob_uf.union(u, v):
                    removed += 1
        
        if alice_uf.components != 1 or bob_uf.components != 1:
            return -1
        return removed
```**说明**：我们为 Alice 和 Bob 维护单独的并查结构。 类型 3 边缘适用于两者。 联盟运营回归`False`如果节点已经连接，则允许我们计算冗余边。 处理完所有边后，我们确认每个图都是全连接的。 

## 解决方案```go
package main

type UnionFind struct {
	parent     []int
	rank       []int
	components int
}

func NewUnionFind(n int) *UnionFind {
	parent := make([]int, n+1)
	rank := make([]int, n+1)
	for i := 0; i <= n; i++ {
		parent[i] = i
	}
	return &UnionFind{parent, rank, n}
}

func (uf *UnionFind) Find(x int) int {
	if uf.parent[x] != x {
		uf.parent[x] = uf.Find(uf.parent[x])
	}
	return uf.parent[x]
}

func (uf *UnionFind) Union(x, y int) bool {
	xr, yr := uf.Find(x), uf.Find(y)
	if xr == yr {
		return false
	}
	if uf.rank[xr] < uf.rank[yr] {
		uf.parent[xr] = yr
	} else if uf.rank[xr] > uf.rank[yr] {
		uf.parent[yr] = xr
	} else {
		uf.parent[yr] = xr
		uf.rank[xr]++
	}
	uf.components--
	return true
}

func maxNumEdgesToRemove(n int, edges [][]int) int {
	aliceUF := NewUnionFind(n)
	bobUF := NewUnionFind(n)
	removed := 0

	for _, edge := range edges {
		if edge[0] == 3 {
			if !aliceUF.Union(edge[1], edge[2]) {
				removed++
			} else {
				bobUF.Union(edge[1], edge[2])
			}
		}
	}

	for _, edge := range edges {
		if edge[0] == 1 {
			if !aliceUF.Union(edge[1], edge[2]) {
				removed++
			}
		} else if edge[0] == 2 {
			if !bobUF.Union(edge[1], edge[2]) {
				removed++
			}
		}
	}

	if aliceUF.components != 1 || bobUF.components != 1 {
		return -1
	}
	return removed
}
```**Go 特定注释**：我们定义一个`UnionFind`结构体和构造函数`NewUnionFind`。 切片处理父数组和排名数组。 Union 返回一个布尔值，表示冗余。 使用以下方式访问边缘索引`edge[1]`和`edge[2]`，与基于 1 的节点索引一致。
