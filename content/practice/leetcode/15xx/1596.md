[LeetCode 问题 1596](https://leetcode.com/problems/the-most-frequently-ordered-products-for-each-customer/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们从一组三个表中找到每个客户最常订购的产品：`Customers`,`Orders`， 和`Products`。 每个`customer_id`可以有多个订单，每个订单包含一个`product_id`。 目标是为每个至少下了一个订单的客户输出`product_id`和`product_name`他们订购最多的产品。 

输入表示一个关系数据库结构，其中客户、他们的订单和产品详细信息单独存储。 预期输出是包含以下内容的元组（或行）列表`customer_id`,`product_id`， 和`product_name`每个客户的顶级产品。 如果客户有多个与最高订单数相关的产品，则必须包括所有此类产品。 没有订单的客户被排除在输出之外。 

主要限制和观察包括：

 - 每个`order_id`是独一无二的。 
- 客户可以多次订购同一产品，但每天不得超过一次。 
- 可能有多个产品与客户最常订购的产品相关。 
- 数据集可以有很多客户和订单，因此效率很重要。 

重要的边缘情况是没有订单的客户、拥有与最大订单数相关的多种产品的客户以及仅订购一次的产品。 

## 方法

 蛮力方法是迭代每个客户并计算他们订购每种产品的次数。 计数完毕后，选择最大值并输出该频率的所有乘积。 虽然正确，但这需要对客户和产品进行嵌套循环，如果数据集很大，则会导致时间复杂度很高。 

最佳方法是利用 SQL 窗口函数。 首先，我们统计每个客户订购每种产品的次数。 然后，我们使用窗口函数来计算每个客户的最大订单数。 最后，我们仅过滤与此最大计数匹配的产品。 这避免了对每个客户的重复扫描和聚合，并确保最大频率的单次计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(C * P) | O(C * P) | 手动计算每个客户-产品组合的订单 |
 | 最佳 | O(N) | O(N) | 使用 SQL 窗口函数有效计算每个客户的频率和最大值 |

 ## 算法演练

 1. 加入`Orders`表与`Products`桌上`product_id`要得到`product_name`连同订单。 
2. 对结果进行分组`customer_id`和`product_id`计算每个客户订购每种产品的次数。 这给出了每个客户-产品对的频率表。 
3. 使用窗口函数（例如`MAX`过度分区`customer_id`）以确定每个客户的最大订单数。 
4. 过滤频率表以仅包含产品计数等于该客户的最大计数的行。 
5. 选择所需的列`customer_id`,`product_id`， 和`product_name`对于输出。 

这是有效的，因为窗口函数确保我们无需额外查询即可计算每个客户的最大频率，并且按此最大值进行过滤可以直接给出顶级产品。 

## Python 解决方案```python
import pandas as pd

def most_frequent_products(customers: pd.DataFrame, orders: pd.DataFrame, products: pd.DataFrame) -> pd.DataFrame:
    # Merge Orders with Products to get product_name
    order_products = orders.merge(products, on="product_id")
    
    # Count how many times each customer ordered each product
    freq = order_products.groupby(["customer_id", "product_id", "product_name"]).size().reset_index(name="count")
    
    # Compute maximum frequency per customer
    freq["max_count"] = freq.groupby("customer_id")["count"].transform("max")
    
    # Filter rows where count matches max_count
    result = freq[freq["count"] == freq["max_count"]][["customer_id", "product_id", "product_name"]]
    
    return result
```这个实现首先合并`Orders`和`Products`访问产品名称，然后按客户和产品分组以计算订单。 使用`transform("max")`函数中，我们以向量化的方式计算每个客户的最大订单数。 过滤可确保仅返回最频繁的产品。 

## 解决方案```go
package main

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
    "fmt"
)

func MostFrequentProducts(db *sql.DB) (*sql.Rows, error) {
    query := `
        SELECT o.customer_id, o.product_id, p.product_name
        FROM Orders o
        JOIN Products p ON o.product_id = p.product_id
        JOIN (
            SELECT customer_id, product_id, COUNT(*) AS cnt,
                   MAX(COUNT(*)) OVER (PARTITION BY customer_id) AS max_cnt
            FROM Orders
            GROUP BY customer_id, product_id
        ) AS t ON o.customer_id = t.customer_id AND o.product_id = t.product_id
        WHERE t.cnt = t.max_cnt
        GROUP BY o.customer_id, o.product_id, p.product_name
    `
    return db.Query(query)
}
```Go 实现直接使用 SQL 和窗口函数。 SQL 查询对每个客户-产品对的订单进行计数，计算每个客户的最大计数，并筛选与最大计数匹配的产品。 Go 代码执行此查询并返回结果。 与 Python 的区别包括依赖 SQL 而不是内存中的 DataFrame 操作以及通过以下方式处理结果：`sql.Rows`。 

## 工作示例

 **示例：客户 1 (Alice)**

 1、订单：产品1（键盘）1次，产品2（鼠标）3次。 
2、计数表：产品1→1，产品2→3。 
3. 最大数量：3。 
4. 过滤结果：产品2（小鼠）。 

**示例：客户 2 (鲍勃)**

 1. 订单：产品 1 → 1、产品 2 → 1、产品 3 → 1。 
2. 最大数量：1。 
3. 过滤结果：产品1、2、3。 

此流程适用于至少下了一个订单的每位客户。

 一种极端情况是没有订单的客户，例如约翰。 该实施通过仅对现有订单进行分组和计数来正确排除此类客户。
