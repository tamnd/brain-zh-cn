[LeetCode 问题 1551](https://leetcode.com/problems/minimum-operations-to-make-array-equal/)

 **难度：** 🟡 中等
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 问题提出了一个数组`arr`长度`n`其中每个元素由公式定义`arr[i] = 2 * i + 1`。 这会生成一个从 1 开始的连续奇数数组。任务是使用特定操作使所有元素相等：选择两个索引`x`和`y`，减去 1`arr[x]`并加 1 到`arr[y]`。 目标是尽量减少此类操作的数量以使数组元素相等。 

输入`n`表示数组的大小，输出是需要的最少运算次数。 限制条件`1 <= n <= 10^4`表明模拟每个操作的简单方法会太慢，因此我们需要一个数学或基于模式的解决方案。 边缘情况包括非常小的数组，例如`n = 1`不需要任何操作，偶数与奇数`n`因为阵列围绕中间对称。 

该问题保证了数组元素总是可能相等，这很有帮助，因为我们不需要检查是否不可能。 

## 方法

 ### 蛮力

 蛮力方法将模拟每个操作：重复查找最大和最小元素，减少最大值并增加最小值，并对操作进行计数，直到所有元素都相等。 这种方法之所以有效，是因为每次操作都会减少最大数字和最小数字之间的差异。 不过对于大的来说速度太慢了`n`因为每个操作只改变两个元素，并且最多可以有`O(n^2)`差异来平衡。 

### 最佳

 最佳方法利用对称性。 数组`[1, 3, 5, ..., 2n-1]`围绕中位数对称。 为了均衡数组，每个元素与中值的差值都会影响操作总数。 具体来说，运算次数等于数组前半部分与中位数之差之和。 这将问题简化为简单的算术级数计算。 

关键的见解是数组的中位数始终是`n`（自从`arr`具有连续的奇数）。 对于数组的前半部分，我们求和`median - arr[i]`为了`i`前半部分给出了一个封闭式公式：

 - 如果`n`为偶数，则运算次数为`(n/2) * (n/2)`。 
- 如果`n`为奇数，则运算次数为`(n//2) * ((n//2) + 1)`。 

这允许在无需模拟的情况下进行恒定时间计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 通过重复查找最大值和最小值来模拟每个操作 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 使用基于数组中位数的对称性和算术级数公式 |

 ## 算法演练

 1. 计算数组的中位数。 为了`arr[i] = 2*i + 1`，中位数是`n`因为数组包含`n`从1开始的连续奇数。 
2.确定前半部分的元素个数：`half = n // 2`。 这些元素小于中位数。 
3. 计算所需的总运算量，即中位数与前半部分每个元素之间的差值之和。 对于第一个`half`数字，差值之和形成算术级数`2, 4, 6, ..., 2*half`。 
4. 使用公式计算第一个的总和`half`正整数并乘以 1（因为每个差值对每个单位差值贡献一次操作）以获得结果：`operations = half * (n - half)`。 
5. 返回计算出的操作数。 

工作原理：每次操作都会将低于中位数的元素与高于中位数的元素之间的差异减少 2，从而有效地将两个数字移近中位数。 对低于中位数的元素的差异求和给出了所需的单位更改的确切数量，并且根据对称性，相同数量的操作适用于高于中位数的元素。 这确保所有元素最佳地收敛到中值。 

## Python 解决方案```python
class Solution:
    def minOperations(self, n: int) -> int:
        half = n // 2
        return half * (n - half)
```Python实现首先计算`half`作为`n // 2`。 这表示低于中位数的元素数量。 然后，它会乘以`half`经过`(n - half)`，它解释了与中位数之差的算术和。 计算是直接的并且避免了循环，使得对于大型`n`。 

## 解决方案```go
func minOperations(n int) int {
    half := n / 2
    return half * (n - half)
}
```在 Go 中，整数除法会自动截断为零，因此`n / 2`正确计算`half`。 乘法`half * (n - half)`与Python的公式相同。 不需要额外的处理，因为约束保证`1 <= n <= 10000`，因此整数溢出不是问题。

 ## 边缘情况

 **单个元素 (n = 1)：** 数组`[1]`所有元素已经相等，因此算法返回`0`。 这可确保公式正确处理最小的输入。 

**偶数与奇数 n：** 公式`half * (n - half)`适用于偶数和奇数尺寸。 对于甚至`n`，两半相等，对于奇数`n`，该公式仍然使用整数除法正确计算差值之和`n // 2`。 

**大n：**解决方案处理最大允许值`n = 10^4`无循环，避免性能问题。 Python中不存在整数溢出的风险，而Go中则最大乘积`5000 * 5000 = 25,000,000`适合 32 位整数。 

这种方法非常稳健，可以处理问题指定的所有约束。
