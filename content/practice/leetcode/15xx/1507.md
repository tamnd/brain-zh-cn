 # LeetCode 1507 - 重新格式化日期

 ## 问题理解

 该问题给出了人类可读格式的日期字符串，例如`"20th Oct 2052"`并要求我们将其转换为标准化的 ISO 样式格式`YYYY-MM-DD`。 

输入字符串始终包含三个部分：

 1. 带有序数后缀的日期值，例如`"1st"`,`"2nd"`,`"3rd"`,`"4th"`， 等等。 
2. 三个字母的月份缩写，例如`"Jan"`或者`"Oct"`。 
3. 四位数年份。 

输出必须始终遵循精确的结构：

 - 年份的四位数字
 - 月份的两位数
 - 两位数字表示日期

 这意味着单位数月份和日期必须包含前导零。 例如：

-`"6th Jun 1933"`变成`"1933-06-06"`-`"1st Jan 2000"`变成`"2000-01-01"`限制非常小。 该问题保证所有日期都是有效的，因此我们不需要执行任何错误检查或验证。 这立即告诉我们，主要的挑战只是正确地解析和格式化字符串。 

一个微妙的边缘情况是处理个位数的天数，例如`"1st"`或者`"6th"`。 一个幼稚的实现可能会意外地产生`"1933-06-6"`而不是`"1933-06-06"`。 另一个重要的细节是从日期部分正确删除序数后缀。 后缀可能是`"st"`,`"nd"`,`"rd"`， 或者`"th"`。 

由于保证日期格式有效且高度结构化，因此直接解析方法是最自然的解决方案。 

## 方法

 ### 蛮力方法

 暴力式解决方案将手动检查输入字符串的每个字符并逐个构建输出。 例如，我们可以逐个字符地遍历字符串，识别空格出现的位置，手动分隔日、月和年，然后单独处理每个段。 

对于白天部分，我们将扫描直到遇到非数字字符。 对于月份，我们将使用条件语句与所有十二个可能的月份名称进行比较。 最后，我们将格式化的片段连接在一起。 

这种方法可以正常工作，因为输入格式是固定且可预测的。 然而，实现变得不必要地冗长并且更难以维护。 几个月来重复的条件逻辑也让代码变得不那么优雅。 

### 最佳方法

 关键的观察结果是格式已经结构良好。 我们可以简单地使用空格将字符串分成三个部分。 

一旦我们有了：

 - 天
 - 月
 - 年

 我们可以独立处理每个：

 - 通过仅采用数字部分来删除日期的后缀。 
- 使用哈希映射将月份缩写转换为其数字表示形式。 
- 连接所有内容`YYYY-MM-DD`格式。 

这种方法干净、高效且易于理解。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 带有许多条件的手动解析 |
 | 最佳 | O(n) | O(1) | O(1) | 分割字符串并使用哈希图查找 |

 这里，`n`是输入字符串的长度，它很小。 

## 算法演练

 1. 使用空格分割输入字符串。 

这给了我们三个部分：

 -`day`-`month`-`year`例如：```
"20th Oct 2052"
```变成：```
["20th", "Oct", "2052"]
```2. 创建从月份缩写到月份编号的映射。 

我们使用哈希映射是因为它提供恒定时间查找。 例如：```
"Jan" -> "01"
"Feb" -> "02"
...
"Dec" -> "12"
```3. 提取当天的数字部分。 

最后两个字符始终是序数后缀。 所以：

-`"20th"`变成`"20"`-`"6th"`变成`"6"`我们可以通过获取除最后两个字符之外的所有字符来删除后缀。 
4. 确保日期有两位数。 

如果该日期仅包含一位数字，请在前面添加前导零。 

示例：

 -`"6"`变成`"06"`-`"1"`变成`"01"`5. 从哈希映射中查找数字月份值。 

例子：

-`"Oct"`变成`"10"`6. 使用所需的格式组合年、月和日。 

例子：```
"2052" + "-" + "10" + "-" + "20"
```变成：```
"2052-10-20"
```### 为什么它有效

 该算法之所以有效，是因为保证了输入格式的一致性。 每个日期始终包含三个空格分隔的组成部分，并且每个月份缩写唯一地映射到数字月份值。 通过删除日期的最后两个后缀字符并在必要时用零填充，我们始终生成格式正确的 ISO 样式日期字符串。 

## Python 解决方案```python
class Solution:
    def reformatDate(self, date: str) -> str:
        month_map = {
            "Jan": "01",
            "Feb": "02",
            "Mar": "03",
            "Apr": "04",
            "May": "05",
            "Jun": "06",
            "Jul": "07",
            "Aug": "08",
            "Sep": "09",
            "Oct": "10",
            "Nov": "11",
            "Dec": "12",
        }

        day, month, year = date.split()

        # Remove ordinal suffix
        day_number = day[:-2]

        # Ensure two digits
        day_number = day_number.zfill(2)

        return f"{year}-{month_map[month]}-{day_number}"
```该实现首先定义一个字典，将每个三个字母的月份缩写映射到其两位数字的数字表示形式。 这允许从名称进行恒定时间转换，例如`"Oct"`到`"10"`。 

接下来，使用以下命令将输入​​字符串分为三个部分`split()`。 由于问题保证格式始终有效，因此我们可以安全地将结果直接解包到`day`,`month`， 和`year`。 

使用切片删除日期后缀。 由于后缀始终包含恰好两个字符，`day[:-2]`仅提取数字部分。 

这`zfill(2)`方法确保日期始终包含两位数字。 这会自动正确处理个位数的天数。 

最后，使用 f 字符串构造格式化字符串。 

## 解决方案```go
package main

import (
	"fmt"
	"strings"
)

func reformatDate(date string) string {
	monthMap := map[string]string{
		"Jan": "01",
		"Feb": "02",
		"Mar": "03",
		"Apr": "04",
		"May": "05",
		"Jun": "06",
		"Jul": "07",
		"Aug": "08",
		"Sep": "09",
		"Oct": "10",
		"Nov": "11",
		"Dec": "12",
	}

	parts := strings.Split(date, " ")

	day := parts[0]
	month := parts[1]
	year := parts[2]

	// Remove ordinal suffix
	dayNumber := day[:len(day)-2]

	// Add leading zero if needed
	if len(dayNumber) == 1 {
		dayNumber = "0" + dayNumber
	}

	return fmt.Sprintf("%s-%s-%s", year, monthMap[month], dayNumber)
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 一个小小的区别是 Go 没有内置与 Python 相当的功能`zfill`，所以我们手动添加`"0"`当日期仅包含一位数字时。 

另一个区别是字符串格式。 Go 使用`fmt.Sprintf`而不是 Python f 字符串。 

由于约束很小，因此不必担心整数溢出或内存使用。

 ## 边缘情况

 一个重要的边缘情况是一位数的日期，例如`"6th Jun 1933"`。 有缺陷的实现可能会正确删除后缀，但无法在前面添加前导零。 该解决方案使用安全地处理这个问题`zfill(2)`在 Python 中或在 Go 中手动补零。 

另一个边缘情况涉及不同的序数后缀。 日子可能结束于`"st"`,`"nd"`,`"rd"`， 或者`"th"`。 幼稚的解析器可能会尝试单独显式处理每个后缀。 此实现通过简单地删除最后两个字符来完全避免不必要的分支，这适用于所有有效的后缀。 

第三个重要的边缘情况是确保月份转换始终正确。 由于月份名称是缩写而不是数字，因此使用固定映射可以保证准确的转换。 这可以防止错误排序或意外的字符串解析错误等错误。
