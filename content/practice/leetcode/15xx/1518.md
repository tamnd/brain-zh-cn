[LeetCode 1518 题](https://leetcode.com/problems/water-bottles/)

 **难度：** 🟢简单
 **主题：** 数学、模拟

 ## 解决方案

 ## 问题理解

 问题是要求我们在给定两个整数的情况下确定一个人可以喝的最大水瓶数量：`numBottles`，满瓶的初始数量，以及`numExchange`，可以兑换一整瓶的空瓶数量。 每次喝完一瓶满酒，它就会变成一个空瓶，有可能有助于交换。 

换句话说，你从`numBottles`满瓶。 喝完后，你收集空瓶，每当空瓶数量达到`numExchange`，您可以用它们换取额外的整瓶酒。 重复此过程，直到您不再有足够的空瓶来换取满瓶。 

约束表明两者`numBottles`和`numExchange`相对较小，每个最多 100 个。这意味着我们不需要担心极大数量的性能问题，简单的模拟就足够了。 

重要的边缘情况包括以下情况`numBottles`小于`numExchange`（不可交换），`numBottles`正好可以整除`numExchange`（全部交易），或`numExchange`只是略大于`numBottles`（只能喝最初的几瓶）。 

## 方法

 暴力方法将单独模拟每个瓶子的饮用和交换步骤。 我们将跟踪空瓶的数量，尽可能更换，直到不再发生更换为止。 这是正确的，但它涉及重复循环，并且对于小约束可能会过于冗长。 

最佳方法利用了我们可以使用整数除法计算从空瓶收到的满瓶数量的观察结果。 每个周期，我们喝完所有满瓶，累积空瓶，并计算我们还能得到多少额外的满瓶。 如此反复进行，直到无法获得更多满瓶为止。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 一步步模拟饮酒、交换|
 | 最佳| O(log n) | O(1) | O(1) | 使用迭代除法来计算交换，直到耗尽 |

 ## 算法演练

 1. 初始化变量`total_drunk`满瓶的初始数量`numBottles`。 这代表迄今为止消耗的总瓶数。 
2. 初始化变量`empty_bottles`具有相同的值`numBottles`追踪饮用后收集的空瓶子。 
3. 输入一个循环，只要`empty_bottles`大于或等于`numExchange`。 
4.在循环内部，通过整数除法计算可以得到多少个新的满瓶`empty_bottles`经过`numExchange`。 
5.将此号码添加到`total_drunk`因为这些新瓶子也会被消耗掉。 
6. 更新`empty_bottles`考虑交换中使用的瓶子：`empty_bottles = empty_bottles % numExchange + new_full_bottles`。 
7. 重复循环直到`empty_bottles < numExchange`。 
8. 返回`total_drunk`作为消耗的最大瓶子数。 

为什么它有效：每次迭代都保持不变`empty_bottles`正确计算所有剩余的可用于交换的瓶子。 通过反复交换、消费，确保无一漏掉可能的瓶子。 当无法进行进一步的交换时，循环终止。 

## Python 解决方案```python
class Solution:
    def numWaterBottles(self, numBottles: int, numExchange: int) -> int:
        total_drunk = numBottles
        empty_bottles = numBottles
        
        while empty_bottles >= numExchange:
            new_full_bottles = empty_bottles // numExchange
            total_drunk += new_full_bottles
            empty_bottles = empty_bottles % numExchange + new_full_bottles
        
        return total_drunk
```Python 实现直接遵循该算法。`total_drunk`跟踪消耗的瓶子总数，同时`empty_bottles`记录所有可供交换的瓶子的数量。 该循环计算新的满瓶并在每次迭代中更新空瓶计数，直到不再可能进行交换。 

## 解决方案```go
func numWaterBottles(numBottles int, numExchange int) int {
    totalDrunk := numBottles
    emptyBottles := numBottles

    for emptyBottles >= numExchange {
        newFullBottles := emptyBottles / numExchange
        totalDrunk += newFullBottles
        emptyBottles = emptyBottles % numExchange + newFullBottles
    }

    return totalDrunk
}
```Go 实现镜像了 Python 版本。 变量`totalDrunk`和`emptyBottles`跟踪消耗总量和当前空瓶。 整数除法和模运算用于计算交换并更新空瓶计数。

 ## 边缘情况

 一个重要的边缘情况是当初始瓶子数量小于`numExchange`。 在这种情况下，不可能进行交换，并且喝完的瓶子总数恰好是`numBottles`。 该算法正确地处理了这个问题，因为循环条件`empty_bottles >= numExchange`立即失败。 

另一种边缘情况发生在`numBottles`正好可以整除`numExchange`。 这可能会导致一系列完美的交换，其中没有剩余的空瓶，但算法仍然正确地计算每个新的满瓶，直到空瓶不足以进行进一步的交换。 

第三种边缘情况是当`numExchange`只是略大于`numBottles`。 在这种情况下，只能消耗初始瓶子，算法会正确返回初始计数，而无需尝试任何交换，确保不会发生相差一错误。
