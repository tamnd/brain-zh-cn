[LeetCode 问题 1542](https://leetcode.com/problems/find-longest-awesome-substring/)

 **难度：** 🔴难
 **主题：** 哈希表、字符串、位操作

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定字符串中最长的**很棒的子字符串**的长度`s`由数字组成。 如果子字符串可以重新排列（通过任意数量的交换）以形成回文，则该子字符串被认为是**棒**。 换句话说，可以对子字符串中的字符进行排列，使其向前和向后读取相同的内容。 

输入`s`是一个长度可达的字符串`10^5`，仅包含来自的数字`'0'`到`'9'`。 输出是一个整数，表示子串的最大长度`s`可以重新排列成回文。 

回文的一个关键属性是最多**一个字符**可以出现奇数次，而所有其他字符必须出现偶数次。 这种洞察力对于设计有效的解决方案至关重要。 

重要的边缘情况包括所有字符都是唯一的字符串、已经是回文的字符串、长度为 1 的字符串以及散布重复字符的字符串。 

## 方法

 最简单的方法是检查每个可能的子串，计算每个数字的频率，然后检查该子串是否可以形成回文。 这涉及生成的所有子字符串`s`并检查每一个的回文条件。 

虽然正确，但这种方法对于约束来说太慢了，因为有`O(n^2)`子字符串，检查每个子字符串可能需要`O(10)`用于计算数字。 这导致`O(n^2)`时间复杂度，这是不可行的`n`最多`10^5`。 

最佳解决方案的关键洞察是**位操作**。 我们可以使用 10 位整数来表示每个数字的奇偶校验（奇数或偶数）。 每一位对应一个数字`'0'`通过`'9'`，如果该数字的计数为奇数，则设置一位。 使用这种表示形式，如果子字符串的位掩码最多设置一位，则它可以形成回文。 通过跟踪每个位掩码的第一次出现，我们可以计算线性时间内最长的真棒子串的长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 检查所有子串，计算数字频率，验证回文条件 |
 | 最佳 | O(n) | O(2^10) | O(2^10) | 使用位掩码跟踪奇数/偶数计数，利用前缀掩码检测有效子字符串 |

 ## 算法演练

 1.初始化一个字典`mask_to_index`存储每个掩码出现的第一个索引。 放`mask_to_index[0] = -1`处理从索引 0 开始的子字符串。 
2. 初始化`mask = 0`表示数字计数的当前奇偶校验和`max_length = 0`跟踪结果。 
3. 迭代每个字符`c`在字符串中`s`使用其索引`i`。 
4. 将字符转换为整数`digit = int(c)`。 
5. 使用 XOR 更新掩码​​：`mask ^= (1 << digit)`。 这会切换与该数字相对应的位，从而有效地更新奇偶校验。 
6. 如果之前曾见过该面具`mask_to_index`， 更新`max_length = max(max_length, i - mask_to_index[mask])`。 这意味着前一个索引和当前索引之间的子字符串可以形成回文。 
7. 要考虑最多包含一位奇数数字的子字符串，请迭代`j`从 0 到 9 并检查`mask ^ (1 << j)`在`mask_to_index`。 更新`max_length`如果找到的话也同样。 
8. 如果之前没有见过掩码，则存储当前索引：`mask_to_index[mask] = i`。 
9.处理完所有字符后，返回`max_length`。 

**为什么有效**：位掩码捕获数字计数的奇偶校验。 两个具有相同掩码的子串意味着其间的数字有偶数个（或只有一个奇数），满足回文条件。 XOR 使我们能够有效地计算掩码并比较它们。 

## Python 解决方案```python
class Solution:
    def longestAwesome(self, s: str) -> int:
        mask_to_index = {0: -1}
        mask = 0
        max_length = 0
        
        for i, c in enumerate(s):
            digit = int(c)
            mask ^= (1 << digit)
            
            if mask in mask_to_index:
                max_length = max(max_length, i - mask_to_index[mask])
            
            for j in range(10):
                test_mask = mask ^ (1 << j)
                if test_mask in mask_to_index:
                    max_length = max(max_length, i - mask_to_index[test_mask])
            
            if mask not in mask_to_index:
                mask_to_index[mask] = i
        
        return max_length
```这个 Python 实现精确地遵循了该算法。`mask_to_index`跟踪每个奇偶校验掩码的第一次出现。 XOR 运算会切换与当前数字相对应的位。 检查`mask`和`mask ^ (1 << j)`有效地找到可以重新排列成回文的子串。 

## 解决方案```go
func longestAwesome(s string) int {
    maskToIndex := make(map[int]int)
    maskToIndex[0] = -1
    mask := 0
    maxLength := 0

    for i, c := range s {
        digit := int(c - '0')
        mask ^= 1 << digit

        if prev, ok := maskToIndex[mask]; ok {
            if i - prev > maxLength {
                maxLength = i - prev
            }
        }

        for j := 0; j < 10; j++ {
            testMask := mask ^ (1 << j)
            if prev, ok := maskToIndex[testMask]; ok {
                if i - prev > maxLength {
                    maxLength = i - prev
                }
            }
        }

        if _, ok := maskToIndex[mask]; !ok {
            maskToIndex[mask] = i
        }
    }

    return maxLength
}
```在 Go 中，实现是类似的。 主要区别在于使用`map[int]int`为了`maskToIndex`、数字的显式类型转换和惯用语`ok`检查地图是否存在。
