[LeetCode 问题 1592](https://leetcode.com/problems/rearrange-spaces- Between-words/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题需要重新排列给定字符串中的空格`text`以便所有单词都由**最大可能的相等数量的空格**分隔，并且任何剩余的空格都放置在字符串的末尾。 输入`text`由小写英文字母和空格组成，保证至少包含一个单词，这样可以简化空输入的处理。 

输出是与输入长度相同的字符串，其中单词之间的间距尽可能均匀。 限制条件`1 <= text.length <= 100`表明输入大小很小，因此即使是线性传递字符串的简单解决方案也是有效的。 

要考虑的关键边缘情况包括只有一个单词的字符串、空格不能均匀分布在单词之间的字符串以及具有前导、尾随或多个连续空格的字符串。 

## 方法

 ### 蛮力

 暴力方法涉及迭代字符串，手动计算空格和单词，然后在单词之间重复插入空格，直到用完所有空格。 虽然正确，但此方法很麻烦，因为它涉及手动空间管理和对字符串的多次传递。 虽然对于给定的约束是可以接受的，但它不必要地复杂。 

### 最佳方法

 最佳方法依赖于一些观察。 首先，我们可以通过迭代字符串一次来计算总空格数。 接下来，我们通过按空格分割字符串来提取所有单词。 如果有多个单词，则单词之间的空格数为总空格的整数除以`(number of words - 1)`。 该除法的任何余数都会成为附加在末尾的额外空格。 如果只有一个单词，则所有空格都附加在该单词后面。 

这种方法很简单，只需要对输入进行线性扫描，并直接在一次传递中构造输出。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 多次插入空格，手动管理字符串连接 |
 | 最佳 | O(n) | O(n) | 计算一次空格和单词，计算间距，构造最终字符串 |

 ## 算法演练

 1. 统计其中的空格总数`text`。 This can be done with a single iteration or using a built-in count method.
 2. 分裂`text`到使用空格作为分隔符的单词列表中。 这将自动删除多余的空格。 
3.确定字数。 如果只有一个单词，则所有空格都将放在最后。 
4. 计算单词之间的空格数。 这是`total_spaces // (number_of_words - 1)`。 如果只有一个单词，则该值为零。 
5. 使用模运算计算剩余空间`total_spaces % (number_of_words - 1)`。 这些额外的空格附加到末尾。 
6. 通过将单词与计算出的空格数连接起来，然后在末尾附加任何额外的空格来构造最终字符串。 

**为什么有效：** 该算法之所以有效，是因为它显式地计算资源（空间）并根据单词之间的间隙数量均匀分配它们。 模运算确保不丢失空间，而连接运算则保证适当的间距。 

## Python 解决方案```python
class Solution:
    def reorderSpaces(self, text: str) -> str:
        total_spaces = text.count(' ')
        words = text.split()
        if len(words) == 1:
            return words[0] + ' ' * total_spaces
        
        spaces_between_words = total_spaces // (len(words) - 1)
        extra_spaces = total_spaces % (len(words) - 1)
        
        return (' ' * spaces_between_words).join(words) + ' ' * extra_spaces
```该实现对空格进行计数，将文本拆分为单词，处理单单词的特殊情况，计算间距，最后有效地构造输出字符串。 这`' '.join(words)`操作确保单词与确切数量的空格连接。 

## 解决方案```go
import (
    "strings"
)

func reorderSpaces(text string) string {
    totalSpaces := strings.Count(text, " ")
    words := strings.Fields(text)
    
    if len(words) == 1 {
        return words[0] + strings.Repeat(" ", totalSpaces)
    }
    
    spacesBetweenWords := totalSpaces / (len(words) - 1)
    extraSpaces := totalSpaces % (len(words) - 1)
    
    return strings.Join(words, strings.Repeat(" ", spacesBetweenWords)) + strings.Repeat(" ", extraSpaces)
}
```Go版本使用`strings.Count`计算空格和`strings.Fields`来分割单词。`strings.Repeat`处理重复的空格。 逻辑与 Python 相同，但要注意 Go 中的切片处理和字符串连接。

 ## 边缘情况

 **单个单词输入：** 只有一个单词的字符串应在末尾附加所有空格。 这可以防止在计算单词之间的空格时被零除。 

**一端所有空格：** 前导或尾随空格不得影响单词提取； 按空格分割会自动处理此问题。 

**不均匀的空间分布：** 当空格不能均匀分布时，模数可确保在末尾添加剩余的空格，从而保持字符串长度的完整性和单词间隙之间的均匀性。
