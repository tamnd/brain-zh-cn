[LeetCode 问题 1554](https://leetcode.com/problems/strings-differ-by-one-character/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、滚动哈希、哈希函数

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个唯一的字符串数组，称为`dict`，其中每个字符串具有相同的长度。 我们必须确定是否存在至少一对在同一位置仅相差一个字符的字符串。 

换句话说，我们正在寻找两个字符串，其中：

 - 它们的长度相等，这是已经保证的。 
- 除一个字符外，所有字符均匹配。 
- 不同的字符必须出现在同一索引处。 

例如：

-`"abcd"`和`"aacd"`仅在索引处不同`1`。 
-`"abcd"`和`"abyd"`仅在索引处不同`2`。 

预期输出是：

 -`true`如果存在这样的一对。 
-`false`否则。 

约束条件很重要：

 - 所有字符串的字符总数最多为`10^5`。 
- 所有字符串的长度相同。 
- 字符串是独一无二的。 
- 仅使用小写英文字母。 

这些限制立即告诉我们，对每对进行简单的比较可能会变得太慢。 如果有`n`长度的字符串`m`，比较每对成本`O(n^2 * m)`，当`n`很大。 

一些边缘情况很重要：

 - 非常小的输入，例如只有一根字符串。 
- 多个位置不同的字符串。 
- 删除同一索引处的一个字符后变得相同的字符串。 
- 许多字符串共享大的公共前缀或后缀的情况。 
- 具有最大允许大小的输入，其中效率非常重要。 

唯一性保证简化了问题，因为我们永远不需要担心相同的字符串被错误地计数。 

## 方法

 ### 蛮力方法

 最直接的解决方案是比较每对字符串。 

对于每对：

 1. 逐个位置比较字符位置。 
2. 计算有多少个索引不同。 
3. 如果恰好有一个索引不同，则返回`true`。 

如果我们完成检查所有对而没有找到这样的匹配，则返回`false`。 

这是有效的，因为它显式地验证每个可能对的条件。 然而，对于大输入来说它太慢了。 

认为：

-`n`是字符串的数量
 -`m`是字符串长度

 有`O(n^2)`成对，并且每次比较的成本`O(m)`。 因此，总复杂度变为`O(n^2 * m)`。 

高达`10^5`总字符数，这种方法很容易超时。 

### 最佳方法

 关键的观察是：

 如果两个字符串在索引处仅相差一个字符`i`，然后删除索引处的字符`i`两个字符串产生相同的结果。 

例子：```
abcd  -> remove index 1 -> acd
aacd  -> remove index 1 -> acd
```这将问题转化为：

 > 任何生成的“屏蔽”字符串是否出现多次？ 

我们迭代每个角色的位置：

 1. 从每个字符串中删除该位置的字符。 
2. 将结果字符串存储在哈希集中。 
3. 如果我们两次生成相同的屏蔽字符串，则两个原始字符串仅在该位置不同。 

哈希集提供`O(1)`平均查找时间，使解决方案高效。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 |`O(n^2 * m)`|`O(1)`| 直接比较每一对 |
 | 最佳 |`O(n * m^2)`|`O(n)`| 使用屏蔽字符串和散列 |

 ## 算法演练

 ### 最优算法

 1.让`word_length`是每个字符串的长度。 

由于所有字符串都具有相同的长度，因此我们只需要迭代来自`0`到`word_length - 1`。 
2.对于每个字符位置`i`，创建一个空的哈希集，名为`seen`。 

该集存储通过删除索引处的字符生成的所有屏蔽版本`i`。 
3. 遍历每个字符串`dict`。 

对于每个字符串：

 - 通过删除索引处的字符来创建一个新字符串`i`。 
- 例子：```
"abcd" with i = 2 becomes "abd"
```4. 检查屏蔽字符串是否已存在`seen`。 

- 如果是，则另一个字符串产生相同的屏蔽结果。 
- 这意味着两个原始字符串仅在索引处不同`i`。 
- 返回`true`。 
5. 否则，将屏蔽字符串插入到`seen`。 
6. 继续处理当前索引的所有字符串。 
7. 如果没有找到任何索引的重复项，则返回`false`。 

### 为什么它有效

 当且仅当从两个字符串中删除该索引会产生相同的剩余字符时，两个字符串在同一索引处恰好有一个字符不同。 

该算法系统地检查每个可能索引的此属性。 由于哈希集可以有效地检测重复项，因此可以立即发现任何有效的对。 

## Python 解决方案```python
from typing import List

class Solution:
    def differByOne(self, dict: List[str]) -> bool:
        word_length = len(dict[0])

        for index in range(word_length):
            seen = set()

            for word in dict:
                masked = word[:index] + word[index + 1:]

                if masked in seen:
                    return True

                seen.add(masked)

        return False
```实现直接遵循算法。 

首先，我们确定公共字符串长度。 然后，对于每个索引位置，我们创建一个名为的新哈希集`seen`。 

对于每个单词，我们通过排除当前字符来构造一个屏蔽版本。 Python 切片使这变得简洁：```python
word[:index] + word[index + 1:]
```如果掩码字符串已存在于集合中，则除已删除的索引外，另一个单词将在所有位置匹配。 我们立即返回`True`。 

否则，我们插入屏蔽字符串并继续。 

如果所有位置均已处理且没有重复项，则不存在有效对，因此函数返回`False`。 

## 解决方案```go
func differByOne(dict []string) bool {
    wordLength := len(dict[0])

    for index := 0; index < wordLength; index++ {
        seen := make(map[string]bool)

        for _, word := range dict {
            masked := word[:index] + word[index+1:]

            if seen[masked] {
                return true
            }

            seen[masked] = true
        }
    }

    return false
}
```Go 的实现与 Python 版本非常相似。 

而不是Python`set`, Go 使用`map[string]bool`用于恒定时间的成员资格检查。 

Go 中的字符串切片与 Python 类似：```go
word[:index] + word[index+1:]
```由于所有字符串仅包含小写英文字母，因此字节索引安全且高效。 

这里不存在整数溢出问题，因为我们只使用索引和字符串操作。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |`O(n * m^2)`| 有`m`职位，对于我们处理的每个职位`n`创建长度为掩码的字符串时的字符串`m`|
 | 空间|`O(n)`| 哈希集最多存储`n`屏蔽字符串|

 主要成本来自字符串创建。 删除一个字符会创建一个新的长度字符串`m - 1`，这需要花费`O(m)`时间。 由于我们对每个字符串和每个位置都执行此操作，因此总复杂度变为`O(n * m^2)`。 

给定问题约束，总字符数最多为`10^5`，这个解决方案在实践中足够有效。

 ## 边缘情况

 ### 单字符串输入

 如果输入仅包含一个字符串，则不可能存在一对相差一个字符的字符串。 粗心的实现可能会假设至少存在两个字符串，并意外地产生不正确的结果。 

这个实现很自然地处理它。 循环正常执行，但不会出现重复的屏蔽字符串，因此函数正确返回`False`。 

### 单字符串

 输入如：```
["a", "b"]
```很重要，因为删除唯一的字符会产生空字符串。 

两个字符串都会生成：```
""
```在索引处`0`，这正确地表明它们仅相差一个字符。 

该实现可以正确处理此问题，因为空字符串是有效的哈希集键。 

### 字符串之间的多重差异

 考虑：```
["abcd", "wxyz"]
```这些字符串在每个位置都不同。 

删除任何单个字符仍然会产生不同的屏蔽字符串：```
bcd vs xyz
acd vs wyz
abd vs wxz
abc vs wxy
```因此，哈希集中不会出现重复项，算法正确返回`False`。 

### 共享前缀或后缀

 具有许多相似字符串的输入有时会暴露散列或屏蔽错误。 

例子：```
["aaaa", "aaab", "aaba"]
```该实现独立地正确检查每个索引。 尽管许多屏蔽字符串相似，但只有当原始字符串在一个位置完全相同时才会出现重复。
