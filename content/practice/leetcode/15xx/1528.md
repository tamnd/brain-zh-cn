[LeetCode 第 1528 题](https://leetcode.com/problems/shuffle-string/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 问题要求我们取一个字符串`s`和一个整数数组`indices`相同长度，并生成一个新字符串，其中每个字符`s`被移动到指定的位置`indices`。 换句话说，对于每个索引`i`在`s`, 字符`s[i]`应放置在位置`indices[i]`在结果字符串中。 输出是应用此映射后完全重新排列的字符串。 

约束条件提供了重要保证：`s`和`indices`具有相同的长度`n`，范围从 1 到 100，所有值都在`indices`是唯一的，并且每个值都在有效范围内`[0, n-1]`。 这些保证确保每个角色都有唯一的目标位置，并且不存在重复或越界索引，从而简化了实现。 需要注意的边缘情况包括尽可能小的字符串（长度为 1）、已经按顺序排列的字符串以及需要完全反转或复杂混洗的字符串。 

## 方法

 暴力方法将迭代中的每个字符`s`并重复将其插入到相应索引处的新字符串或列表中。 虽然这种方法简单且正确，但在 Python 等语言中重复插入字符串可能效率低下，因为字符串是不可变的，在最坏的情况下会导致 O(n²) 时间复杂度。 使用列表可以缓解这个问题，但是暴力破解的想法仍然比必要的更复杂。 

最佳方法利用了关键的观察结果，即我们可以直接将每个字符放入预先分配的数组或正确大小的切片中的目标位置。 通过迭代一次`s`和`indices`，我们可以在 O(n) 时间内填充这个数组，然后将数组连接成最终的字符串。 这种方法简单直接，避免了不必要的重复操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复向字符串插入字符，对于长字符串效率低下 |
 | 最佳 | O(n) | O(n) | 预分配数组并将字符直接放置在目标索引处 |

 ## 算法演练

 1. 初始化数组或切片`result`长度`n`，用占位符字符（或空值）填充。 
2. 遍历字符串`s`使用索引`i`。 
3. 对于每个角色`s[i]`，从中检索其目标位置`indices[i]`。 
4. 地点`s[i]`直接进入`result[indices[i]]`。 
5.循环完成后，进行转换`result`通过按顺序连接所有字符返回到字符串。 
6. 返回结果字符串。 

为什么它有效：该算法有效是因为每个索引`indices`是唯一的并且在范围内。 不变量是对于每个`i`,`result[indices[i]]`包含`s[i]`。 由于所有索引都是唯一的，并且我们只迭代一次，因此不会有字符相互覆盖，从而保证了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def restoreString(self, s: str, indices: List[int]) -> str:
        n = len(s)
        result = [''] * n
        for i in range(n):
            result[indices[i]] = s[i]
        return ''.join(result)
```在此 Python 实现中，我们首先创建一个列表`result`与相同长度`s`，最初用空字符串填充。 我们迭代通过`s`使用索引`i`并将每个字符放置在其目标位置`indices[i]`。 最后，我们使用以下命令将列表转换回字符串`join`并归还它。 

## 解决方案```go
func restoreString(s string, indices []int) string {
    n := len(s)
    result := make([]byte, n)
    for i := 0; i < n; i++ {
        result[indices[i]] = s[i]
    }
    return string(result)
}
```在Go中，我们分配一个字节片`result`与相同的长度`s`。 我们迭代通过`s`并将每个字节分配给正确的索引`indices`。 最后，我们将字节切片转换回字符串并返回它。 Go 需要将字符串作为字节切片处理，因为字符串是不可变的，类似于 Python。

 ## 边缘情况

 第一种边缘情况是输入字符串的长度为 1 时。在这种情况下，算法必须正确处理简单的映射，确保单个字符保持在其位置。 由于索引数组也将是`[0]`，算法自然正确地放置它，没有错误。 

第二种边缘情况涉及输入字符串已经按顺序排列。 如果`indices`是`[0, 1, 2, ..., n-1]`，算法必须保持字符串不变。 该实现可以很好地处理这个问题，因为将每个字符直接分配到其现有位置不会改变它。 

第三种边缘情况是完全逆转或复杂的洗牌，其中每个字符移动到新位置，可能包括第一个和最后一个字符。 该算法正确地处理了这个问题，因为它根据`indices`，并且唯一性保证确保不会发生覆盖。
