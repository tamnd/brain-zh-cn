[LeetCode 问题 1546](https://leetcode.com/problems/maximum-number-of-non-overlapping-subarrays-with-sum-equals-target/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、贪婪、前缀和

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到给定整数数组中**不重叠子数组的最大数量**`nums`使得每个子数组的总和等于给定的`target`。 简单来说，我们扫描数组以查找总和匹配的连续数字序列`target`并确保没有两个选定的序列共享任何元素。 挑战在于最大化此类序列的数量。 

输入`nums`可以包含负数、零或正数。 数组长度最大可达`10^5`，这排除了考虑每个可能的子数组的强力解决方案。 输出是一个整数，表示满足条件的子数组的最大数量。 

重要的观察结果包括**子数组必须是连续的**和**非空**，并且子数组不能重叠。 要考虑的边缘情况包括所有数字都为零的数组、总和为目标的负数数组以及目标本身为零的情况。 

## 方法

 **暴力方法**会考虑每个可能的子数组`nums`，计算其总和，并检查是否等于`target`。 对于每个有效的子数组，我们会尝试对其进行计数，同时确保不重叠。 这保证了正确性，但对于大型数组来说太慢，因为子数组的数量随数组长度呈二次方增长。 

**最佳方法**依赖于**前缀和技术**与**哈希集**相结合。 关键的见解是，如果索引中的元素总和`i`到`j`等于`target`，则前缀和之间的差为`j`和`i-1`等于`target`。 通过跟踪所有看到的前缀和并在找到有效子数组时重置它们，我们可以在**线性时间内**贪婪地最大化非重叠子数组的数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 显式检查所有子数组； 对于 n 达到 10^5 来说太慢 |
 | 最佳 | O(n) | O(n) | 使用前缀和和哈希集贪婪地检测有效子数组 |

 ## 算法演练

 1. 初始化变量`count`为 0 以跟踪找到的非重叠子数组的数量。 
2. 初始化变量`current_sum`为 0 以维持运行前缀和。 
3. 初始化一个哈希集`seen_sums`并添加 0。 0 表示从第一个元素开始的子数组。 
4. 迭代中的每个数字`nums`：

 1. 将当前号码添加到`current_sum`。 
2. 检查是否`current_sum - target`存在于`seen_sums`。 如果是，则意味着存在一个以当前索引结尾的子数组，其总和等于`target`。 
3. 如果找到有效的子数组，则递增`count`， 重置`current_sum`为 0，并清除`seen_sums`，然后将 0 添加回`seen_sums`处理未来的子数组。 
4. 如果没有找到有效的子数组，则添加`current_sum`到`seen_sums`。 
5.循环结束后，返回`count`。 

**为什么起作用：** 哈希集跟踪自上次计数子数组以来的所有前缀和。 什么时候`current_sum - target`发现于`seen_sums`，我们知道存在一个有效的非重叠子数组。 重置状态可确保后续子数组不会与已计数的子数组重叠。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxNonOverlapping(self, nums: List[int], target: int) -> int:
        count = 0
        current_sum = 0
        seen_sums = set()
        seen_sums.add(0)
        
        for num in nums:
            current_sum += num
            if current_sum - target in seen_sums:
                count += 1
                current_sum = 0
                seen_sums.clear()
                seen_sums.add(0)
            else:
                seen_sums.add(current_sum)
        
        return count
```Python 实现直接遵循该算法。`seen_sums`存储自上次计数的子数组以来的前缀和。 如果有差异`current_sum - target`存在，我们找到一个有效的子数组并重置未来非重叠子数组的状态。 

## 解决方案```go
func maxNonOverlapping(nums []int, target int) int {
    count := 0
    currentSum := 0
    seenSums := make(map[int]struct{})
    seenSums[0] = struct{}{}
    
    for _, num := range nums {
        currentSum += num
        if _, exists := seenSums[currentSum - target]; exists {
            count++
            currentSum = 0
            seenSums = make(map[int]struct{})
            seenSums[0] = struct{}{}
        } else {
            seenSums[currentSum] = struct{}{}
        }
    }
    
    return count
}
```在 Go 中，使用映射而不是集合，其中键是前缀和，值是空结构。 否则，逻辑会反映 Python 版本。 Map 初始化和重置在 Go 中是明确的。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们迭代通过`nums`一次，设置/映射操作平均为 O(1) |
 | 空间| O(n) | 哈希集在最坏的情况下最多可以存储n个前缀和|

 线性时间复杂度是可以实现的，因为我们避免了嵌套循环并维护运行总和，利用哈希集快速检测总和达到目标的子数组。
