[LeetCode 问题 1504](https://leetcode.com/problems/count-submatrices-with-all-ones/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、堆栈、矩阵、单调堆栈

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个`m x n`二元矩阵，其中每个单元格包含`0`或者`1`。 我们必须计算有多少个完全由 1 组成的矩形子矩阵。 

子矩阵是矩阵内任何连续的矩形区域。 对于每个可能的矩形，我们需要确定其中的每个元素是否等于`1`。 如果是的话，我们就算。 

例如，考虑这个矩阵：```
1 0 1
1 1 0
1 1 0
```有效的子矩阵可以是：```
1 1
1 1
```因为所有的细胞都是一个。 但是，即使包含一个零的矩形也是无效的。 

约束条件很重要：

 -`1 <= m, n <= 150`- 细胞总数最多为`22500`由于矩形的数量快速增长，逐个单元检查每个可能的矩形的简单暴力方法变得太慢。 因此，我们需要一种更有效的方法来计算有效子矩阵。 

一些边缘情况很重要：

 - 应该返回一个完全由零填充的矩阵`0`- 完全由 1 填充的矩阵会产生最大数量的子矩阵
 - 单行和单列矩阵需要小心处理，因为矩形会退化为区间
 - 交替的零和一可以打破关于连续性的假设
 - 大型密集矩阵需要有效的算法来避免超时

 关键的挑战是有效地确定每个位置有多少个全 1 矩形。 

## 方法

 ### 蛮力方法

 蛮力解决方案考虑了每个可能的子矩阵。 

矩形可以通过以下方式定义：

 - 顶排
 - 底排
 - 左栏
 - 右栏

 对于每个矩形，我们扫描其中的所有单元格以验证每个值都等于`1`。 

这种方法是正确的，因为它明确地检查每个可能的候选矩形。 然而，它的计算成本很高。 

有：

-`O(m²)`行边界的选择
 -`O(n²)`列边界的选择

 这已经给出了`O(m² * n²)`矩形。 验证每个矩形最多需要`O(m * n)`时间。 

总复杂度变为：```
O(m³ * n³)
```对于矩阵来说太慢了`150 x 150`。 

### 最佳方法

 关键的观察是我们可以将问题转化为计算直方图中的矩形。 

对于每一行，我们计算一个高度数组：```
height[j] = number of consecutive ones ending at current row
```例子：```
1 0 1
1 1 0
1 1 0
```在第 2 行，高度变为：```
3 2 0
```这意味着：

 - 第 0 列的高度为 3
 - 第 1 列的高度为 2
 - 第 2 列的高度为 0

 现在问题变成：

 当前行结束有多少个子矩形？ 

对于每一列，我们想要计算有多少个矩形使用该列作为右边界。 

我们使用单调递增堆栈来有效地确定直方图条的贡献。 堆栈有助于保持之前较小的高度，使我们能够在每行的线性时间内计算矩形计数。 

这将整体复杂性降低到：```
O(m * n)
```这很容易满足约束条件。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m3 * n3) | O(1) | O(1) | 枚举每个矩形并检查所有单元格 |
 | 最佳 | O(m * n) | O(n) | 使用单调堆栈的直方图高度 |

 ## 算法演练

 ### 第 1 步：构建直方图高度

 对于每一行，维护一个名为`heights`。 

如果`mat[row][col] == 1`：```
heights[col] += 1
```否则：```
heights[col] = 0
```这会将矩阵行转换为直方图，其中每个条代表以当前行结束的连续垂直条。 

### 步骤 2：计算直方图中的矩形数量

 对于当前直方图，我们计算以当前行结尾的所有子矩形。 

我们从左到右处理列。 

我们维持：

 - 单调递增堆栈
 - 一个数组`dp`-`dp[j]`存储以列结尾的有效子矩阵的数量`j`### 步骤 3：维护单调堆栈

 堆栈存储高度递增的列索引。 

当当前高度小于或等于堆栈顶部的高度时，我们弹出元素。 

这可以确保：```
heights[stack[0]] < heights[stack[1]] < ...
```堆栈有助于有效地找到最近的先前较小高度。 

### 步骤 4：计算矩形贡献

 假设最近的较小高度指数是`prev`。 

然后：```
dp[j] = dp[prev] + heights[j] * (j - prev)
```为什么？ 

每个子数组结束于`j`可以从之前较小的高度延伸。 

该范围内的最小高度决定了可能有多少个矩形。 

如果不存在先前的较小高度：```
dp[j] = heights[j] * (j + 1)
```因为每个左边界`0`到`j`是有效的。 

### 第 5 步：积累答案

 添加全部`dp[j]`值到最终结果。 

每个`dp[j]`计算所有以列结尾的有效矩形`j`对于当前行。 

### 为什么它有效

 直方图变换保证以当前行结尾的每个矩形都对应于高度数组中的连续段。 

单调堆栈确保我们可以有效地确定每个段的最小高度，而无需重复重新计算范围。 

复发：```
dp[j] = dp[prev] + heights[j] * width
```正确计算通过将间隔扩展到列而引入的所有新矩形`j`。 

由于每个全 1 子矩阵都有唯一的底行和右边界，因此每个有效矩形都会被精确计数一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def numSubmat(self, mat: List[List[int]]) -> int:
        rows = len(mat)
        cols = len(mat[0])

        heights = [0] * cols
        total = 0

        for row in range(rows):
            # Build histogram heights
            for col in range(cols):
                if mat[row][col] == 1:
                    heights[col] += 1
                else:
                    heights[col] = 0

            stack = []
            dp = [0] * cols

            for col in range(cols):
                while stack and heights[stack[-1]] >= heights[col]:
                    stack.pop()

                if stack:
                    prev_smaller = stack[-1]
                    width = col - prev_smaller
                    dp[col] = dp[prev_smaller] + heights[col] * width
                else:
                    dp[col] = heights[col] * (col + 1)

                stack.append(col)
                total += dp[col]

        return total
```该实现首先维护一个直方图高度数组。 每个值都会跟踪当前行垂直出现的连续值的数量。 

对于每一行，我们更新直方图`O(n)`时间。 

接下来，我们使用单调递增堆栈处理直方图。 堆栈存储高度严格递增的列的索引。 

当出现更小的或相等的高度时，更高的条会被弹出，因为它们不能再充当未来列的最近的较小边界。 

这`dp`array 存储当前行每列结束有多少个有效子矩阵。 

如果存在先前的较小高度，我们将重用先前计算的结果：```python
dp[col] = dp[prev_smaller] + heights[col] * width
```否则，以当前列结尾的每个前缀都会贡献矩形。 

最后将所有贡献添加到`total`。 

## 解决方案```go
func numSubmat(mat [][]int) int {
	rows := len(mat)
	cols := len(mat[0])

	heights := make([]int, cols)
	total := 0

	for r := 0; r < rows; r++ {
		// Build histogram heights
		for c := 0; c < cols; c++ {
			if mat[r][c] == 1 {
				heights[c]++
			} else {
				heights[c] = 0
			}
		}

		stack := []int{}
		dp := make([]int, cols)

		for c := 0; c < cols; c++ {
			for len(stack) > 0 && heights[stack[len(stack)-1]] >= heights[c] {
				stack = stack[:len(stack)-1]
			}

			if len(stack) > 0 {
				prevSmaller := stack[len(stack)-1]
				width := c - prevSmaller
				dp[c] = dp[prevSmaller] + heights[c]*width
			} else {
				dp[c] = heights[c] * (c + 1)
			}

			stack = append(stack, c)
			total += dp[c]
		}
	}

	return total
}
```Go 实现遵循与 Python 版本相同的逻辑。 

切片用于：

 -`heights`-`stack`-`dp`Go没有Python的动态列表方法，因此堆栈弹出是使用切片截断来实现的：```go
stack = stack[:len(stack)-1]
```所有计算都安全地适合 Go 的范围`int`类型，因为 a 的子矩阵的最大数量`150 x 150`矩阵远低于整数溢出限制。

 ## 边缘情况

 ### 仅包含零的矩阵

 一个矩阵如：```
[
  [0,0],
  [0,0]
]
```可能会暴露算法意外计算空矩形或无法正确重置直方图高度的错误。 

该实现通过重置来处理此问题：```
heights[col] = 0
```每当出现零时。 这保证了没有无效的矩形延伸穿过零单元格。 

### 单行或单列

 矩阵例如：```
[[1,1,1]]
```或者：```
[
 [1],
 [1],
 [1]
]
```很重要，因为矩形简化为简单的连续间隔。 

某些实现错误地假设二维行为并错误处理宽度或高度。 

该解决方案自然有效，因为直方图方法独立处理宽度和高度。 单调堆栈甚至可以正确处理一维直方图。 

### 直方图中的等高

 直方图如：```
[2,2,2]
```如果堆栈条件错误，可能会产生重复计数问题。 

使用：```
while heights[stack[-1]] >= heights[col]:
```而不是仅仅`>`很关键。 

这可确保正确合并相同的高度，并防止多次计算相同的矩形配置。
