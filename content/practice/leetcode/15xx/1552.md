[LeetCode 问题 1552](https://leetcode.com/problems/Magnetic-force- Between-two-balls/)

 **难度：** 🟡 中等
 **主题：** 数组、二分查找、排序

 ## 解决方案

 ## 问题理解

 问题要求我们分发`m`球进入`n`篮子位于一条线上的给定位置，使得**任意两个球之间的最小距离**最大化。 两个球之间的磁力定义为它们位置的绝对差。 简单来说，我们希望放置球时，使最近的一对球的距离尽可能远。 

输入由一个数组组成`position`代表篮子坐标的整数和一个整数`m`代表球的数量。 输出是一个整数，是最佳分布时任意两个球之间的最小距离的最大可能值。 

约束告诉我们`n`可以达到`10^5`位置可以大到`10^9`。 立场不同，而且`m`至少为 2。这些约束表明时间复杂度低于 O(n log n) 的算法可能会太慢，并且需要仔细处理大整数。 

重要的边缘情况包括篮筐间距较远、球少于篮筐或球必须放置在阵列的最末端以最大化距离的情况。 

## 方法

 ### 蛮力方法

 一个天真的方法是尝试放置的所有组合`m`球进入`n`篮子，计算每个配置的最小距离，并返回找到的最大最小距离。 这保证了正确性，因为我们详尽地检查了所有可能性，但对于大型计算来说这是不可行的`n`和`m`因为组合的数量是组合的：O(C(n, m))，它随着输入大小而快速增长。 

### 最佳方法

 关键的见解是对答案使用**二分搜索**。 我们可以确定是否存在某个最小距离，而不是检查每个位置`d`是可行的：如果我们可以将所有`m`球，使得每个球至少`d`单位分开。 如果距离可行，则更大的距离也是可行的，否则需要更小的距离。 

排序`position`数组允许我们贪婪地放置球：从第一个篮子开始，然后将每个后续球放置在至少`d`远离最后放置的球。 如果我们可以把所有`m`使用这种方法的球，距离`d`是可行的。 

然后，我们对从 1 到最小和最大篮子位置之间的最大差值的可能距离范围执行二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(C(n, m) * m) | O(C(n, m) * m) | O(1) | O(1) | 彻底检查所有布局，对于 n 达到 10^5 不可行 |
 | 最佳 | O(n log(max_pos - min_pos)) | O(n log(max_pos - min_pos)) | O(1) | O(1) | 使用排序和二分搜索进行贪婪可行性检查 |

 ## 算法演练

 1. 排序`position`大批。 排序使我们能够在一次从左到右的遍历中检查可行的位置。 
2. 定义二分查找的搜索范围。`low`是 1（最小可能的最小距离），`high`是第一个篮子和最后一个篮子之间的距离（`position[-1] - position[0]`）。 
3. 执行二分查找：

 1. 计算中间距离`mid = (low + high) // 2`。 
2.检查是否可以放置`m`球至少有`mid`他们之间的距离：

 1. 将第一个球放入第一个篮筐。 
2. 迭代位置，只要与最后放置的球的距离至少为`mid`。 
3. 计算放置的球总数。 
3.如果我们可以把所有`m`球，`mid`是可行的。 放`low = mid + 1`尝试更大的距离。 
4. 否则，设置`high = mid - 1`尝试更小的距离。 
4. 当二分查找完成后，`high`包含最大可行的最小距离。 

**为什么它有效：** 贪心放置确保如果距离`d`是可行的，任何更小的距离也是可行的。 二分查找有效地找到最大可行值`d`通过利用可行性的单调性。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()
        
        def can_place(distance: int) -> bool:
            count = 1
            last_position = position[0]
            for pos in position[1:]:
                if pos - last_position >= distance:
                    count += 1
                    last_position = pos
                    if count == m:
                        return True
            return False
        
        low, high = 1, position[-1] - position[0]
        result = 0
        while low <= high:
            mid = (low + high) // 2
            if can_place(mid):
                result = mid
                low = mid + 1
            else:
                high = mid - 1
        return result
```Python 实现首先对位置进行排序以允许贪婪放置。 这`can_place`辅助函数计算给定最小距离可以放置多少个球。 二分搜索迭代地细化可行距离并返回最大的距离。 

## 解决方案```go
import "sort"

func maxDistance(position []int, m int) int {
    sort.Ints(position)
    
    canPlace := func(distance int) bool {
        count := 1
        last := position[0]
        for _, pos := range position[1:] {
            if pos - last >= distance {
                count++
                last = pos
                if count == m {
                    return true
                }
            }
        }
        return false
    }
    
    low, high := 1, position[len(position)-1] - position[0]
    result := 0
    for low <= high {
        mid := (low + high) / 2
        if canPlace(mid) {
            result = mid
            low = mid + 1
        } else {
            high = mid - 1
        }
    }
    return result
}
```Go 版本反映了 Python 逻辑。 排序是使用完成的`sort.Ints`。 关闭`canPlace`检查可行性。 整数除法用于二分查找中点。 Go 切片自然地处理迭代，避免索引错误。 

## 工作示例

 **示例1：**`position = [1,2,3,4,7], m = 3`排序后：`[1,2,3,4,7]`。 

二分查找范围：`low = 1`,`high = 6`。 

| 迭代 | 中| 可以放置（中）| 低| 高| 结果|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 3 | 真实| 4 | 6 | 3 |
 | 2 | 5 | 假 | 4 | 4 | 3 |
 | 3 | 4 | 假 | 4 | 3 | 3 |

 输出：`3`。 

**示例2：**`position = [5,4,3,2,1,1000000000], m = 2`排序后：`[1,2,3,4,5,1000000000]`。 

二分查找很快就能发现将球放在的位置`1`和`1000000000`最大化距离：`999999999`。
