 ## 解决方案

## 问题理解

 该问题提供了一个`m x n`二元矩阵`mat`仅由`0`沙`1`s，并要求我们找到**特殊位置**的数量。 一个位置`(i, j)`是特殊的，如果`mat[i][j] == 1`以及行中的所有其他元素`i`和列`j`是`0`。 换句话说，一个`1`如果它是**其行和列**中唯一的 1，则它是特殊的。 

输入约束是`1 <= m, n <= 100`，这告诉我们矩阵相对较小，并且简单的 O(m × n × max(m, n)) 强力解决方案可能有效，但效率低下。 输出是一个表示特殊位置总数的整数。 

要考虑的边缘情况包括：全零矩阵（应返回`0`），所有的矩阵都位于同一行或同一列（没有一个是特殊的），或者具有单个元素的矩阵（或者`0`或者`1`）。 该问题保证矩阵仅包含`0`沙`1`s，所以我们不需要处理其他数据类型。 

## 方法

 **暴力方法：**

 最简单的方法是迭代每个单元格`(i, j)`。 对于每一个`1`找到了，扫描整行`i`和列`j`以确保没有其他`1`s。 如果两项检查均通过，则该职位很特殊。 

这种方法之所以有效，是因为它直接实现了定义，但效率低下。 对于每个`1`，我们可以扫描到`m + n`元素，如果几乎所有元素都是 O(m × n × (m + n))，则最坏情况的复杂度为`1`。 考虑到输入大小，这是不必要的。 

**最佳方法：**

 关键的见解是对于一个职位`(i, j)`特殊的是，它的**整行整列必须恰好包含一个`1`**。 我们可以使用两个数组预先计算每行和每列中的 1 的数量：`row_count`和`col_count`。 计数完毕后，我们迭代矩阵，任意位置`(i, j)`在哪里`mat[i][j] == 1`,`row_count[i] == 1`， 和`col_count[j] == 1`很特别。 

这种方法非常高效，因为计算行和列需要 O(m × n) 时间，然后检查每个元素又需要 O(m × n) 时间，从而导致总体时间复杂度为 O(m × n)。 两个计数数组的空间复杂度为 O(m + n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m × n × (m + n)) | O(m × n × (m + n)) | O(1) | O(1) | 扫描每一行和每一列`1`|
 | 最佳 | O(m × n) | O(m + n) | 预先计算行数和列数，然后检查条件 |

 ## 算法演练

 1.初始化两个数组，`row_count`尺寸的`m`和`col_count`尺寸的`n`，分别存储每行和每列中的个数。 
2. 迭代每个单元格`(i, j)`在矩阵中。 如果`mat[i][j] == 1`, 增量`row_count[i]`和`col_count[j]`。 这将计算每行和每列的总数。 
3. 初始化计数器`special_positions`至 0。 
4. 再次迭代矩阵。 对于每个单元格`(i, j)`在哪里`mat[i][j] == 1`，检查是否`row_count[i] == 1`和`col_count[j] == 1`。 如果两个条件都成立，则增加`special_positions`。 
5. 返回`special_positions`。 

**为什么有效：**

 通过预先计算每行和每列中的个数，我们将问题简化为每个单元格的简单检查。 任何`1`具有唯一的行数和列数保证是唯一的`1`在其行和列中，满足特殊位置条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def numSpecial(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        row_count = [0] * m
        col_count = [0] * n

        # Count ones in each row and column
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 1:
                    row_count[i] += 1
                    col_count[j] += 1

        special_positions = 0
        # Check for special positions
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 1 and row_count[i] == 1 and col_count[j] == 1:
                    special_positions += 1

        return special_positions
```**说明：**

 第一个嵌套循环计算每行和每列中的个数。 第二个嵌套循环通过利用预先计算的计数来检查特殊位置的条件。 使用数组进行计数可以确保我们不会重复扫描行或列，从而保持最佳的时间复杂度。 

## 解决方案```go
func numSpecial(mat [][]int) int {
    m, n := len(mat), len(mat[0])
    rowCount := make([]int, m)
    colCount := make([]int, n)

    // Count ones in each row and column
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if mat[i][j] == 1 {
                rowCount[i]++
                colCount[j]++
            }
        }
    }

    specialPositions := 0
    // Check for special positions
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if mat[i][j] == 1 && rowCount[i] == 1 && colCount[j] == 1 {
                specialPositions++
            }
        }
    }

    return specialPositions
}
```**Go 特定注释：**

 在 Go 中，切片用于`rowCount`和`colCount`数组。 索引和迭代与Python 类似。 不需要处理 nil 矩阵，因为问题约束保证至少 1 行和 1 列。 

## 工作示例

 **示例1：**`mat = [[1,0,0],[0,0,1],[1,0,0]]`第一步：数数：

 | 行| 计数|

 | 1 | 1 |
 | 2 | 1 |

 | 上校 | 计数|
 | --- | --- |
 | 0 | 2 |
 | 1 | 0 |
 | 2 | 1 |

 第二步：查看特殊位置：

 - (0,0) → row_count[0]=1, col_count[0]=2 → 不特殊
 - (1,2) → row_count[1]=1, col_count[2]=1 → 特殊
 - (2,0) → row_count[2]=1, col_count[0]=2 → 不特殊

 结果 = 1

 **示例2：**`mat = [[1,0,0],[0,1,0],[0,0,1]]`行数：`[1,1,1]`列数：`[1,1,1]`所有对角线位置 (0,0)、(1,1)、(2,2) 满足条件 → 结果 = 3

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m × n) | 计算行和列中的个数 (O(m × n)) 并检查条件 (O(m × n)) |
