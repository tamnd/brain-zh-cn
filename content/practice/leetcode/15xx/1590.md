[LeetCode 第 1590 题](https://leetcode.com/problems/make-sum-divisible-by-p/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、前缀和

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定可以从给定的正整数数组中删除的最小连续子数组，`nums`，这样剩余元素的总和就可以被给定的整数整除`p`。 这里的关键是子数组必须是连续的，不能是整个数组。 如果数组的和已经可以被`p`，那么我们不需要删除任何东西，答案是零。 如果总和不可能被整除`p`通过删除子数组，该函数应该返回`-1`。 

输入`nums`可以非常大，最多 100,000 个元素，并且数组中的每个数字可以大到 10^9。 相似地，`p`可以大到 10^9。 这告诉我们，由于嵌套循环可能导致 O(n^2) 或 O(n^3) 时间复杂度，因此检查所有可能子数组的强力方法将太慢。 

重要的边缘情况包括当总和已被整除时`p`，当没有子数组可以使总和整除时，当删除单个元素就足够时，以及当要删除的子数组位于数组的开头或结尾时。 

## 方法

 **暴力方法**涉及迭代所有可能的子数组，在删除每个子数组后计算剩余元素的总和，并通过以下方式检查整除性：`p`。 虽然这种方法很简单并且保证了正确性，但对于大型数组来说效率非常低，因为它需要 O(n^2) 或 O(n^3) 操作，这对于 n 高达 10^5 来说是不可行的。 

**最佳方法**使用前缀和与哈希图相结合来跟踪余数模`p`。 关键的见解是我们只需要考虑其总和模数的子数组`p`匹配从总和模中得出的特定值`p`。 让数组的总和取模`p`是`total_mod = sum(nums) % p`。 删除子数组并使总和可整除`p`，子数组模的总和`p`必须等于`total_mod`。 通过维护前缀和模的哈希映射`p`到它们的最新索引，我们可以在 O(n) 时间内有效地确定要删除的子数组的长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 检查每个子数组； 对于大 n 来说太慢 |
 | 最佳 | O(n) | O(n) | 使用前缀和和哈希图有效地找到最短子数组 |

 ## 算法演练

 1. 计算总和`nums`模数`p`并将其存储在`total_mod`。 如果`total_mod`为零，总和已经可以被整除`p`，所以立即返回0。 
2. 初始化哈希图`mod_index`存储最后一个索引，其中每个前缀和模`p`发生。 预填充它`{0: -1}`处理从索引 0 开始的子数组。 
3. 初始化`prefix_mod = 0`和`min_length = n + 1`，其中 n 是数组的长度。 
4. 使用索引迭代数组`i`和价值`num`：

 a. 更新前缀和模`p`使用`prefix_mod = (prefix_mod + num) % p`。 

b. 计算我们需要在哈希图中找到的目标模：`target = (prefix_mod - total_mod + p) % p`。 这解释了模数的负差异`p`。 

c. 如果`target`存在于`mod_index`， 更新`min_length`以及要删除的子数组的长度：`i - mod_index[target]`。 

d. 使用当前前缀模更新哈希映射：`mod_index[prefix_mod] = i`。 
5. 迭代后，如果`min_length`小于`n`，退货。 否则，返回`-1`因为不允许删除整个数组。 

**为什么它有效**：该算法有效是因为我们正在寻找一个子数组，其总和模`p`等于`total_mod`。 通过使用前缀和和哈希映射，我们可以有效地跟踪先前的前缀和模`p`并在一次传递中找到最短的有效子数组。 不变式是对于任何索引`i`,`prefix_mod[i] - prefix_mod[j]`模数`p`给出子数组的和`nums[j+1..i]`模数`p`。 

## Python 解决方案```python
from typing import List

class Solution:
    def minSubarray(self, nums: List[int], p: int) -> int:
        total_mod = sum(nums) % p
        if total_mod == 0:
            return 0
        
        mod_index = {0: -1}
        prefix_mod = 0
        min_length = len(nums) + 1
        
        for i, num in enumerate(nums):
            prefix_mod = (prefix_mod + num) % p
            target = (prefix_mod - total_mod + p) % p
            if target in mod_index:
                min_length = min(min_length, i - mod_index[target])
            mod_index[prefix_mod] = i
        
        return min_length if min_length < len(nums) else -1
```Python 实现完全遵循该算法。 我们首先计算`total_mod`并对不需要拆除的情况进行处理。 这`mod_index`字典存储每个前缀模的最后一次看到的索引，并且我们更新`min_length`每当找到有效的子数组时。 最后，我们在返回之前检查最小长度是否有效。 

## 解决方案```go
func minSubarray(nums []int, p int) int {
    totalSum := 0
    for _, num := range nums {
        totalSum += num
    }
    totalMod := totalSum % p
    if totalMod == 0 {
        return 0
    }
    
    modIndex := map[int]int{0: -1}
    prefixMod := 0
    minLength := len(nums) + 1
    
    for i, num := range nums {
        prefixMod = (prefixMod + num) % p
        target := (prefixMod - totalMod + p) % p
        if idx, exists := modIndex[target]; exists {
            if i - idx < minLength {
                minLength = i - idx
            }
        }
        modIndex[prefixMod] = i
    }
    
    if minLength < len(nums) {
        return minLength
    }
    return -1
}
```Go 实现反映了 Python 解决方案。 我们使用整数键和值显式处理索引映射。 Go 没有内置的负模校正，所以我们确保`target`是积极的。 切片索引和映射查找取代了 Python 字典操作。 

## 工作示例

 **示例1：**`nums = [3,1,4,2], p = 6`

`total_mod = (3+1+4+2) % 6 = 10 % 6 = 4`我们需要删除一个模 6 之和为 4 的子数组。 

| 我| 编号 | 前缀_mod | 目标| 模组索引 | 最小长度 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | 3 | 3 | (3-4+6)%6=5 | {0:-1} | 7 |
 | 1 | 1 | 4 | (4-4+6)%6=6%6=0 | {0:-1,3:0} | 我 - (-1) = 2 |
 | 2 | 4 | 2 | (2-4+6)%6=4 | {0:-1,3:0,4:1} | 2 |
 | 3 | 2 | 4 | (4-4+6)%6=0 | {0:-1,3:0,4:2} | 我 - (-1)=4 |

 最小有效长度为 1（删除`[4]`）。 

**示例2：**`nums = [6,3,5,2], p = 9`

`total_mod = (6+3+5+2)%9 = 16%9 = 7`目标子数组总和模 = 7。根据该算法，最短子数组为`[5,2]`长度为 2。 

**示例3：**`nums = [1,2,3], p = 3`

`total_mod = 6 % 3 = 0`不需要删除，返回0。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单次遍历数组，具有恒定时间映射操作 |
 | 空间| O(n) | 哈希映射最多存储 n 个模前缀和`p`|

 时间复杂度是线性的，因为我们只在数组上迭代一次。 由于存储前缀和模，空间复杂度是线性的`p`在哈希映射中。
