## 问题理解

 这个问题给了我们两个严格递增的整数数组，`nums1`和`nums2`，并要求我们计算沿**有效路径**可获得的最大总和。 有效路径从任一数组开始并从左到右移动。 当遇到两个数组中都存在的值时，我们可以**切换数组**。 每个数字沿路径仅对分数产生一次影响。 

我们的任务是计算**所有可能路径的最大总和**，模$10^9 + 7$。 

需要注意的要点：

 1. 数组是**排序且不同的**，这允许高效的遍历和比较。 
2. 仅允许在**公共元素**处切换数组。 
3. 输入大小可达$10^5$，元素值高达$10^7$，这排除了由于指数组合而导致的所有路径的暴力递归。 
4. 边缘情况包括没有交集的数组、所有元素都相同的数组以及最小大小的数组（长度为 1）。 

核心挑战是选择何时切换数组以使总和最大化，而不必显式枚举每条路径。 

## 方法

 **暴力方法：** 一种简单的方法是递归地探索从两个数组开始的所有可能路径。 在每一步中，我们可以继续使用同一个数组，也可以切换数组（如果当前元素存在于两个数组中）。 虽然这会产生正确的答案，但时间复杂度是**指数**，$O(2^n)$，这对于$n$最多$10^5$。 

**最佳方法：** 关键的观察是，由于数组是排序的，我们可以使用**两个指针**同时遍历两个数组。 我们分别维护每个数组的**累积和**。 当我们遇到公共元素时，我们将任一数组的**最大累积和添加到总数中，然后重置超出此交集的各个累积和。 这种贪婪方法确保我们始终在每个交叉点采取最佳子路径，并将问题减少到线性时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归地探索所有路径，这对于大型数组来说是不可行的 |
 | 最佳 | O(n + m) | O(1) | O(1) | 累加和、线性时间、常量额外空间的两指针遍历 |

 ## 算法演练

 1.初始化两个指针，`i`为了`nums1`和`j`为了`nums2`，都从 0 开始。 
2. 维持两项累计金额，`sum1`和`sum2`，表示沿途收集的值的总和`nums1`和`nums2`自上次交叉路口以来分别。 
3. 同时遍历两个数组：

 1.如果`nums1[i] < nums2[j]`， 添加`nums1[i]`到`sum1`并增加`i`。 
2.如果`nums1[i] > nums2[j]`， 添加`nums2[j]`到`sum2`并增加`j`。 
3.如果`nums1[i] == nums2[j]`，添加最大值`sum1`和`sum2`将当前值加上`total_sum`。 然后重置`sum1`和`sum2`到 0。将两者都增加`i`和`j`。 
4. 循环结束后，如果任一数组中仍有元素，则将它们的剩余总和添加到`sum1`或者`sum2`。 
5. 添加最大值`sum1`和`sum2`到`total_sum`并返回模数$10^9 + 7$。 

**为什么有效：** 两指针方法之所以有效，是因为数组是排序的。 在每个交叉点，采用最大累积和的贪婪选择确保保留所有最优子路径，并且在不包含来自两条路径之一的元素的情况下，超出该点不可能有更好的路径。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxSum(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10**9 + 7
        i, j = 0, 0
        sum1, sum2 = 0, 0
        total_sum = 0
        n, m = len(nums1), len(nums2)
        
        while i < n and j < m:
            if nums1[i] < nums2[j]:
                sum1 += nums1[i]
                i += 1
            elif nums1[i] > nums2[j]:
                sum2 += nums2[j]
                j += 1
            else:
                total_sum += max(sum1, sum2) + nums1[i]
                sum1 = 0
                sum2 = 0
                i += 1
                j += 1
        
        # Add remaining elements in either array
        while i < n:
            sum1 += nums1[i]
            i += 1
        while j < m:
            sum2 += nums2[j]
            j += 1
        
        total_sum += max(sum1, sum2)
        return total_sum % MOD
```**说明：** Python代码直接实现了该算法。`sum1`和`sum2`沿着每个数组跟踪累积和，直到发生交集。 在交叉点处，最大值被添加到`total_sum`。 剩余元素在遍历后处理。 

## 解决方案```go
func maxSum(nums1 []int, nums2 []int) int {
    const MOD = int(1e9 + 7)
    i, j := 0, 0
    sum1, sum2, totalSum := 0, 0, 0
    n, m := len(nums1), len(nums2)
    
    for i < n && j < m {
        if nums1[i] < nums2[j] {
            sum1 += nums1[i]
            i++
        } else if nums1[i] > nums2[j] {
            sum2 += nums2[j]
            j++
        } else {
            totalSum += max(sum1, sum2) + nums1[i]
            sum1, sum2 = 0, 0
            i++
            j++
        }
    }
    
    for i < n {
        sum1 += nums1[i]
        i++
    }
    for j < m {
        sum2 += nums2[j]
        j++
    }
    
    totalSum += max(sum1, sum2)
    return totalSum % MOD
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```**Go 特定注释：** Go 使用`int`类型； 这`max`函数单独定义。 切片处理剩余元素的方式与 Python 列表类似。 通过在最后一步应用模来避免溢出。
