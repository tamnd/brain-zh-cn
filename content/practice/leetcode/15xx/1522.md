 # LeetCode 1522 - N 叉树的直径

 ## 问题理解

 这个问题要求我们计算 N 叉树的直径。 N 叉树是每个节点可以有任意数量的子节点的树，这与每个节点最多有两个子节点的二叉树不同。 

树的直径定义为树中任意两个节点之间的最长路径的长度。 该路径不需要经过根。 路径的长度是通过两个节点之间的边数来测量的。 

例如，如果最长路径通过 3 条边连接节点，则直径为 3。 

输入作为 N 叉树的根节点提供。 每个节点包含：

 - 一个值
 - 子节点列表

 示例中显示的序列化格式使用级别顺序遍历`null`子组之间的分隔符，但在实际的解决方案中，我们只与树结构本身交互。 

约束条件很重要：

 - 树的深度最多为`1000`- 节点数量最多为`10^4`这些限制告诉我们`O(n^2)`对于大树来说，解决方案可能会变得太慢。 理想情况下，我们应该以线性时间解决方案为目标`O(n)`。 

一些边缘情况很重要：

 - 只有一个节点的树有直径`0`，因为没有边。 
- 高度倾斜的树的行为类似于链表。 
- 最长的路径可能不经过根。 
- 节点可能有很多子节点，因此我们不能依赖二叉树特定的逻辑。 

关键的挑战是有效地确定最长路径，同时仅访问每个节点一次。 

## 方法

 ### 蛮力方法

 强力解决方案将计算每对节点之间的最长路径。 

一种方法是：

 1. 将树视为无向图。 
2. 对于每个节点：

 - 运行 DFS 或 BFS 来计算到所有其他节点的距离。 
- 跟踪找到的最大距离。 

这是可行的，因为直径只是任意两个节点之间的最大最短路径距离。 

然而，这种方法的效率非常低。 如果有`n`节点，我们从每个节点执行遍历，结果是`O(n^2)`时间复杂度。 

高达`10^4`节点，这变得太昂贵了。 

### 最佳方法

 关键的见解是可以在单次深度优先遍历期间计算直径。 

对于每个节点，我们想知道：

 - 从该节点开始的最长向下路径。 
- 组合通过当前节点的两个子路径是否会创建更大的直径。 

这类似于二叉树中的直径问题，只不过这里每个节点可能有许多子节点。 

在每个节点：

 - 计算每个子树的高度。 
- 记录两个最大的儿童身高。 
- 经过当前节点的最长路径为：```
largest_height + second_largest_height
```这是可行的，因为通过节点的最长路径必须连接两个最深的子分支。 

在递归计算高度的同时，我们不断更新全局直径值。 

由于每个节点只处理一次，因此解决方案以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 从每个节点运行遍历 |
 | 最佳| O(n) | O(h) | 使用子树高度进行单次DFS遍历 |

 这里，`h`是树的高度。 

## 算法演练

 1.初始化一个全局变量`diameter`到`0`。 

该变量存储遍历树时迄今为止发现的最大直径。 
2. 从根开始执行深度优先搜索。 

DFS 函数将返回以当前节点为根的子树的高度。 
3. 对于每个节点，检查其所有子节点。 

对于每个孩子：

 - 递归计算子树的高度。 
- 添加`1`表示从当前节点到子节点的边。 
4. 跟踪两个最大的儿童身高。 

我们只需要顶部的两个高度，因为通过当前节点的最长路径只能使用两个分支。 
5. 计算通过当前节点的候选直径。 

路径长度为：```
longest_height + second_longest_height
```如果该值较大，则更新全局直径。 
6. 将最大的向下高度返回给父级。 

父级只需要单个最长的向下分支。 
7. 继续递归，直到处理完所有节点。 
8. 返回最终直径。 

### 为什么它有效

 对于每个节点，经过该节点的最长路径必须连接两个最深的子子树。 通过自下而上计算子树高度，我们保证在处理节点时，所有子树高度都是已知的。 

由于每个可能的直径：

 - 完全位于子树内，或者
 - 通过连接两个子分支的某个节点，

 检查每个节点可确保找到真实的直径。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: Optional[int] = None, children: Optional[List['Node']] = None):
        self.val = val
        self.children = children if children is not None else []
"""

from typing import Optional, List

class Solution:
    def diameter(self, root: 'Node') -> int:
        self.max_diameter = 0

        def dfs(node: 'Node') -> int:
            if not node:
                return 0

            longest = 0
            second_longest = 0

            for child in node.children:
                child_height = dfs(child) + 1

                if child_height > longest:
                    second_longest = longest
                    longest = child_height
                elif child_height > second_longest:
                    second_longest = child_height

            self.max_diameter = max(
                self.max_diameter,
                longest + second_longest
            )

            return longest

        dfs(root)

        return self.max_diameter
```该解决方案使用递归 DFS 来计算子树高度。 

这`dfs()`函数返回以当前节点为根的子树的高度。 在处理子项时，代码使用以下方法跟踪两个最大的子项高度：`longest`和`second_longest`。 

每当发现较大的孩子身高时：

 - 之前最大的变为第二大。 
- 新高度变为最大。 

在每个节点，通过该节点的潜在直径为：```python
longest + second_longest
```全局最大直径相应更新。 

最后，该函数返回最长的向下路径，以便父节点可以继续构建更大的路径。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */

func diameter(root *Node) int {
    maxDiameter := 0

    var dfs func(node *Node) int

    dfs = func(node *Node) int {
        if node == nil {
            return 0
        }

        longest := 0
        secondLongest := 0

        for _, child := range node.Children {
            childHeight := dfs(child) + 1

            if childHeight > longest {
                secondLongest = longest
                longest = childHeight
            } else if childHeight > secondLongest {
                secondLongest = childHeight
            }
        }

        if longest+secondLongest > maxDiameter {
            maxDiameter = longest + secondLongest
        }

        return longest
    }

    dfs(root)

    return maxDiameter
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

使用基于闭包的 DFS 函数，因此它可以访问共享`maxDiameter`多变的。 

Go 使用`nil`检查而不是 Python 的真实检查。 子节点存储为切片，并使用`range`环形。 

由于对于标准整数运算来说约束足够小，因此整数溢出不是问题。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 递归调用堆栈每个树级别存储一帧 |

 该算法执行单次 DFS 遍历。 每个节点除了迭代其子节点之外还贡献持续的工作，整个树的子节点关系总数为`n - 1`。 

递归堆栈深度取决于树的高度。 在最坏的情况下，倾斜的树可能有高度`n`，尽管典型的平衡树使用的堆栈空间要少得多。

 ## 边缘情况

 ### 单节点树

 一棵只包含一个节点的树没有边，因此它的直径必须是`0`。 

如果实现错误地计算节点而不是边缘，这种情况很容易导致错误。 DFS正确返回高度`0`对于叶节点，直径永远不会增加超过`0`。 

### 高度倾斜的树

 N 叉树可以退化为线性链，其中每个节点只有一个子节点。 

在这种情况下，直径等于树的深度减一。 一些实现错误地假设直径总是组合两个分支，但这里每个节点仅存在一个分支。 

该算法自然地处理这个问题，因为`second_longest`遗迹`0`。 

### 直径不穿过根部

 最长的路径可能完全存在于一棵子树内。 

仅考虑通过根的路径的简单解决方案将在此类输入上失败。 

此实现会在 DFS 期间更新每个节点的直径，确保考虑所有可能的子树直径。 

### 具有许多子节点的节点

 与二叉树不同，N 元节点可能有许多子节点。 

有缺陷的实现可能会不必要地对所有孩子的身高进行排序，或者错误地仅处理两个孩子。 

该解决方案在迭代子列表一次时仅有效地跟踪顶部的两个高度。
