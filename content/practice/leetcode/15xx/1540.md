[LeetCode 问题 1540](https://leetcode.com/problems/can-convert-string-in-k-moves/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 问题是问是否可以转换一个字符串`s`到另一个字符串中`t`最多使用`k`移动，遵循特定的移动规则。 每个动作都可以让你选择一个角色`s`之前没有移动过的，并将其在字母表中准确地向前移动`i`时间、地点`i`是移动编号（从1开始）。 转变从`'z'`到`'a'`。 您还可以选择跳过移动而不移动任何角色。 输入由字符串组成`s`和`t`，和整数`k`代表允许的最大移动次数。 输出是一个布尔值，指示是否可以进行转换。 

约束条件告诉我们`s`和`t`每个最多可以有`10^5`字符和`k`可以非常大，最多`10^9`。 这意味着我们无法按顺序模拟每一个可能的动作； 我们需要一个直接计算可行性的解决方案。 重要的边缘情况包括`s`和`t`已经相等，当所需的班次超过`k`，或者当多个角色需要相同的移动时，可能会超出可用的移动数量。 

## 方法

 蛮力方法将尝试每种组合，选择每次移动时要移动的角色`1`到`k`。 这是正确的，但不可行，因为有`k`移动和`n`字符，使其呈指数级增长并且不可能满足输入约束。 

最佳方法基于这样的见解：每个角色所需的移位可以独立计算。 对于每个位置`i`，计算之间的差异`t[i]`和`s[i]`在字母表中模 26。如果多个字符需要相同的移位`d`，第一次出现之后的每次出现都必须延迟 26 次移动（因为移位以 26 为模）。 这使我们能够计算每个班次所需的最大移动数并检查它是否小于或等于`k`。 如果所有需要的班次都可以分配给一个移动编号 ≤`k`，转换是可能的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 尝试每个角色的所有动作组合 |
 | 最佳 | O(n) | O(26) | 以 26 为模计算所需的班次并检查可行性 |

 ## 算法演练

 1.初始化一个数组`shift_count`大小 26 到零。 各指标`i`将存储需要移动的字符数`i`。 
2. 迭代每个字符索引`i`从`0`到`n-1`。 计算转换所需的平移`s[i]`到`t[i]`作为`(ord(t[i]) - ord(s[i])) % 26`。 
3. 增量`shift_count[shift]`如果移位不为零，则为计算出的移位。 
4. 对于每个移位值`d`从 1 到 25，计算所需的最大移动次数：`d + 26 * (count - 1)`， 在哪里`count`是`shift_count[d]`。 这说明了需要相同移动且间隔 26 步的角色。 
5. 如果任何所需的步数超过`k`， 返回`False`因为转换是不可能的。 
6. 如果所有需要的班次都适合`k`移动、返回`True`。 

该算法之所以有效，是因为模 26 算法确保每次移位只能发生在移动中`d, d+26, d+52,...`，对应于重复使用相同的班次要求。 通过跟踪每个班次所需的最大移动次数，我们保证没有班次超过`k`移动。 

## Python 解决方案```python
class Solution:
    def canConvertString(self, s: str, t: str, k: int) -> bool:
        if len(s) != len(t):
            return False
        
        shift_count = [0] * 26
        
        for i in range(len(s)):
            diff = (ord(t[i]) - ord(s[i])) % 26
            if diff != 0:
                shift_count[diff] += 1
        
        for d in range(1, 26):
            if shift_count[d] > 0:
                max_move = d + 26 * (shift_count[d] - 1)
                if max_move > k:
                    return False
        
        return True
```Python 代码首先确保`s`和`t`具有相同的长度。 然后，它计算每个字符所需的移位并计算每个移位发生的次数。 对于每个非零移位，它计算所需的最大移动数。 如果这超过`k`，函数返回`False`; 否则，它返回`True`。 

## 解决方案```go
func canConvertString(s string, t string, k int) bool {
    if len(s) != len(t) {
        return false
    }
    
    shiftCount := make([]int, 26)
    
    for i := 0; i < len(s); i++ {
        diff := (int(t[i]-s[i]) + 26) % 26
        if diff != 0 {
            shiftCount[diff]++
        }
    }
    
    for d := 1; d < 26; d++ {
        if shiftCount[d] > 0 {
            maxMove := d + 26*(shiftCount[d]-1)
            if maxMove > k {
                return false
            }
        }
    }
    
    return true
}
```Go 实现反映了 Python 解决方案。 它仔细处理模算术以避免负数，使用切片进行移位计数，并迭代检查最大移动。 其他方面的逻辑是相同的。
