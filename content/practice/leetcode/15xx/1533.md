 ## 解决方案

 ## 问题理解

 问题提出了一个数组`arr`其中，除了一个元素严格大于其他元素之外，所有元素都相等。 但是，我们无法直接访问数组元素。 相反，我们通过一个名为的 API 与数组交互`ArrayReader`。 该API提供了两个功能：`compareSub(l, r, x, y)`，它允许我们比较两个子数组的总和，并且`length()`，它返回数组的大小。 

目标是使用最多 20 次调用来识别单个最大元素的索引`compareSub()`。 该问题保证恰好有一个元素较大，从而确保搜索策略可以唯一标识正确的索引。 该数组最多可包含 500,000 个元素，因此任何按顺序检查元素的解决方案都会太慢或超过允许的比较次数。 

关键边缘情况包括非常小的数组（长度为 2 或 3）、最大元素位于数组开头或结尾的情况，以及需要重复子数组比较以有效缩小搜索空间的情况。 

## 方法

 **暴力方法**将涉及使用以下方法将每个元素与其他元素单独进行比较`compareSub`。 虽然这保证找到最大的元素，但可能需要最多`n-1`比较，这对于大型数组来说不可行，并且违反了 20 次调用的限制。 例如，与`arr.length = 500,000`，我们可能需要 499,999 个调用。 

**最佳方法**依赖于二分搜索启发的技术，使用`compareSub`将数组分成两半。 关键的见解是我们可以比较任何段的左半部分和右半部分的总和。 如果总和相等，则较大的元素不在任一半中，但由于恰好有一个较大的元素，因此不等和的一半必须包含它。 然后，我们递归地缩小搜索空间，直到只剩下一个元素，该元素必须是最大的。 这种方法最多可以保证`O(log n)`电话，完全在 20 次电话限制之内。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| --- |
 | 蛮力 | O(n) | O(1) | O(1) | 单独比较每个元素； 超出大型数组的 API 调用限制 |
 | 最佳 | O(log n) | O(1) | O(1) | 使用二分查找`compareSub`; 保证 ≤ 20 次要求`n <= 5 * 10^5`|

 ## 算法演练

 1.从阵列的全范围开始，`[0, n-1]`， 在哪里`n = reader.length()`。 
2. 当该范围包含多个元素时，将其分成几乎相等的两半。 
3. 如果线段的长度是偶数，则使用以下方法比较左半部分和右半部分`compareSub`。 如果左半部分的和较大，则较大的元素位于左半部分。 如果右半部分的和较大，则位于右半部分。 
4. 如果长度是奇数，则排除中间元素并比较剩余一半的总和。 如果总和相等，则中间元素最大。 否则，请关注总和较大的一半。 
5. 重复这一过程，直到只剩下一个索引。 返回该索引作为最大元素的位置。 

**为什么有效**：在每一步中，算法都会保持最大元素始终在当前搜索范围内的不变量。 通过将每一步的搜索空间减半，我们保证对数收敛到单个最大元素。 这可以确保正确性，同时保持在 API 调用限制之内。 

## Python 解决方案```python
class Solution:
    def getIndex(self, reader: 'ArrayReader') -> int:
        left, right = 0, reader.length() - 1
        
        while left < right:
            n = right - left + 1
            if n % 2 == 0:
                mid = left + n // 2 - 1
                cmp = reader.compareSub(left, mid, mid + 1, right)
                if cmp == 1:
                    right = mid
                else:
                    left = mid + 1
            else:
                mid = left + n // 2
                cmp = reader.compareSub(left, mid - 1, mid + 1, right)
                if cmp == 0:
                    return mid
                elif cmp == 1:
                    right = mid - 1
                else:
                    left = mid + 1
        return left
```该代码初始化两个代表当前搜索范围的指针。 它反复分割范围并使用`compareSub`以确定哪一半包含较大的元素。 如果需要，可以通过直接检查中间元素来处理奇数长度段。 循环继续，直到剩下一个索引，该索引作为答案返回。 

## 解决方案```go
func getIndex(reader *ArrayReader) int {
    left, right := 0, reader.length()-1

    for left < right {
        n := right - left + 1
        if n%2 == 0 {
            mid := left + n/2 - 1
            cmp := reader.compareSub(left, mid, mid+1, right)
            if cmp == 1 {
                right = mid
            } else {
                left = mid + 1
            }
        } else {
            mid := left + n/2
            cmp := reader.compareSub(left, mid-1, mid+1, right)
            if cmp == 0 {
                return mid
            } else if cmp == 1 {
                right = mid - 1
            } else {
                left = mid + 1
            }
        }
    }
    return left
}
```在 Go 中，我们遵循与 Python 版本相同的逻辑。 Go 要求仔细处理整数除法，并且显式声明循环变量。 零处理是不必要的，因为`reader`保证存在，并且由于限制，数组溢出不是问题。
