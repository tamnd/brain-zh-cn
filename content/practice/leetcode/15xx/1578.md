 ## 解决方案

 ## 问题理解

 该问题需要将一根气球绳变成一根“彩色”绳，这意味着没有两个连续的气球具有相同的颜色。 输入提供一个字符串`colors`按顺序和数组表示气球的颜色`neededTime`表示移除每个相应气球所需的时间（以秒为单位）。 任务是确定移除气球所需的最短总时间，以便没有两个连续的气球具有相同的颜色。 

关键是，当连续的气球具有相同的颜色时，您必须删除除其中一个之外的所有气球。 最简单的方法可能会尝试所有可能的移除顺序，但我们只需要将移除时间最长的气球保留在每个连续组中，以最小化总时间。 

约束表明气球的数量最多可达`10^5`并且每次移除时间最多为`10^4`。 这表明有效的线性时间解决方案是必要的，因为任何明显比 O(n) 差的算法都会太慢。 

重要的边缘情况包括没有连续重复颜色的字符串、所有气球颜色相同的字符串以及最佳选择需要在组中保留非第一个或非最后一个气球的字符串。 

## 方法

 **暴力方法**会迭代字符串，每次两个连续的颜色匹配时，考虑删除一个。 然而，这可能会导致反复重新计算要移除哪个气球，特别是对于长时间连续运行相同颜色的情况。 对于最坏情况的输入，复杂性可能会降低到 O(n²)，例如`"aaaaa..."`。 

**最佳方法**利用贪婪策略：对于任何具有相同颜色的连续气球组，删除除最大气球之外的所有气球`neededTime`。 其基本原理是，用更短的时间去除气球可以最大限度地降低总去除成本。 这可以通过阵列的单次线性传递来实现，从而保持成本的运行总计。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 迭代地删除每个重复对的气球，每次都重新计算冲突 |
 | 最优（贪婪）| O(n) | O(1) | O(1) | 将最大成本气球保留在每组连续相同颜色中，求和其他移除时间 |

 ## 算法演练

 1. 初始化`total_time`为 0。这将累积最小移除时间。 
2. 初始化`prev_time`到`neededTime`第一个气球的。 这会跟踪当前连续颜色组中的最长时间。 
3. 从第二个气球到最后一个气球迭代：

 1. 如果当前气球的颜色与前一个气球的颜色相同：

 1. 添加较小的`prev_time`和当前气球的`neededTime`到`total_time`。 
2. 更新`prev_time`至最大`prev_time`和当前气球的`neededTime`（保留最昂贵的气球）。 
2. 如果当前气球的颜色与前一个不同，则更新`prev_time`到当前气球的`neededTime`。 
4. 处理完所有气球后，`total_time`将代表使绳子变色的最短时间。 

**为什么有效：** 这种方法保证在相同颜色的任何连续组中，保留移除时间最长的气球，并移除所有其他气球，从而最大限度地减少总移除时间。 保持的不变量是在任何一步，`prev_time`总是包含最大值`neededTime`当前色块的。 

## Python 解决方案```python
from typing import List

class Solution:
    def minCost(self, colors: str, neededTime: List[int]) -> int:
        total_time = 0
        prev_time = neededTime[0]

        for i in range(1, len(colors)):
            if colors[i] == colors[i - 1]:
                total_time += min(prev_time, neededTime[i])
                prev_time = max(prev_time, neededTime[i])
            else:
                prev_time = neededTime[i]

        return total_time
```**说明：** 我们从第一个气球开始，然后迭代其余的气球。 对于每个连续的重复项，我们删除更便宜的气球并更新当前组的最大成本。 当我们遇到新颜色时，我们将之前的最大值重置为当前气球的移除时间。 这保证了总时间最少。 

## 解决方案```go
func minCost(colors string, neededTime []int) int {
    totalTime := 0
    prevTime := neededTime[0]

    for i := 1; i < len(colors); i++ {
        if colors[i] == colors[i-1] {
            if neededTime[i] < prevTime {
                totalTime += neededTime[i]
            } else {
                totalTime += prevTime
                prevTime = neededTime[i]
            }
        } else {
            prevTime = neededTime[i]
        }
    }

    return totalTime
}
```**说明：** Go 解决方案镜像了 Python 逻辑。 由于Go没有动态类型，我们直接使用整数比较。 这`prevTime`变量跟踪连续组中的最高移除时间，确保最小的移除成本。
