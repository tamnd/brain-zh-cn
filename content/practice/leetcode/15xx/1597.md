[LeetCode 问题 1597](https://leetcode.com/problems/build-binary-expression-tree-from-infix-expression/)

 **难度：** 🔴难
 **主题：** 字符串、堆栈、树、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们从有效的中缀算术表达式字符串构造二叉表达式树。 

中缀表达式是标准数学符号，其中运算符出现在操作数之间，例如`3+4`或者`2*(5-1)`。 输入字符串可能包含：

 - 个位数操作数
 - 运营商：`+`,`-`,`*`,`/`- 括号`(`和`)`输出必须是二叉表达式树，其中：

 - 叶节点代表操作数
 - 内部节点代表运营商
 - 每个内部节点都有两个子节点
 - 树根据正常算术优先规则进行评估

 重要的要求是结果树的中序遍历必须在删除括号后重现原始表达式。 

这意味着树结构必须保留：

 1. 操作数排序
 2. 运算符优先级
 3. 表达式隐含的结合性

 例如，在表达式中：```
3*4-2*5
```乘法的优先级高于减法，因此树必须表示：```
(3*4) - (2*5)
```而不是：```
3 * (4-2) * 5
```限制相对较小：

 -`1 <= s.length <= 100`- 操作数是个位数
 - 表达式始终有效

 由于输入量很小，因此许多解析方法都是可行的。 然而，挑战在于在直接构建树结构时正确处理优先级和括号。 

一些边缘情况很重要：

 - 包含深层嵌套括号的表达式
 - 具有相同优先级的多个运算符
 - 左结合性，例如`1-2-3`- 单操作数表达式，例如`"7"`- 长链运营商，例如`"1+2+3+4+5"`如果忽略优先级或关联性，幼稚的实现很容易构建不正确的树。 

## 方法

 ### 蛮力方法

 强力策略将在每个运算符位置递归地分割表达式字符串，并尝试构造所有可能的二叉树。 

对于每个子串：

 1. 尝试将每个操作符作为 root
 2. 递归构建左右子树
 3. 验证生成的树是否保留优先级并正确评估

 这是有效的，因为每个有效的二叉表达式树都对应于中缀表达式的某些递归分区。 

然而，可能的二叉树结构的数量呈指数增长。 许多递归分区是无效的，因为它们违反了优先级规则或括号分组。 

此外，验证每个候选树需要额外的计算。 

即使对于中等大小的输入，这种方法也变得不切实际。 

### 最佳方法，基于堆栈的表达式解析

 更好的解决方案使用带有两个堆栈的经典运算符优先级解析技术：

 - 操作数和子树节点的一个堆栈
 - 操作员的一套堆栈

 这种方法与调车场算法密切相关。 

关键的见解是，处理运算符可以根据优先级和括号规则正确解析中缀表达式。 

当遇到优先级较低或相同的运算符时，必须首先计算之前未决的运算符。 这样自然就构造出了正确的表达式树结构。 

例如：```
3*4-2
```什么时候`-`遇到：

 -`*`已经具有更高的优先级
 - 因此`3*4`在处理减法之前必须成为子树

 这使我们能够在一次从左到右的遍历中增量地构建表达式树。

 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 尝试许多无效的树结构 |

 ## 算法演练

 ### 第 1 步：创建两个堆栈

 我们维持：

 -`node_stack`对于操作数和部分表达式树
 -`operator_stack`对于运算符和括号

 节点堆栈存储完全构造的子树。 

运算符堆栈会延迟操作，直到优先级规则确定应处理它们。 

### 步骤 2：从左到右处理表达式

 我们遍历字符串中的每个字符。 

有四种可能的情况。 

### 步骤 3：处理操作数

 如果当前字符是数字：

 1.创建一个新的树节点
 2. 将其推到`node_stack`例子：```
Input: 3
```我们创造：```
Node("3")
```并将其压入堆栈。 

### 步骤 4：处理左括号

 如果我们遇到`(`:

 - 将其推到`operator_stack`这充当边界标记，因此括号内的运算符将被独立处理。 

### 步骤 5：处理右括号

 当`)`遇到：

 1. 重复处理算子，直到`(`被发现
 2. 移除`(`从堆栈中

 这确保整个带括号的表达式成为完整的子树。 

### 第 6 步：处理运算符

 当遇到`+`,`-`,`*`， 或者`/`:

 1. 与栈顶运算符比较优先级
 2. 虽然顶级运算符具有更高或相同的优先级：

 - 构建一个子树
 3.推送当前操作符

 这会强制执行正确的优先级和左关联性。 

### 第 7 步：构建子树

 处理运算符：

 1.弹出操作符
 2.弹出右子树
 3.弹出左子树
 4.创建新的算子节点
 5.附加左右孩子
 6. 将新的子树推回到`node_stack`例子：```
3 * 4
```变成：```
    *
   / \
  3   4
```### 第 8 步：完成剩余的操作员

 扫描完整字符串后：

 - 处理堆栈中所有剩余的运算符

 最后剩下的节点`node_stack`是表达式树的根。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 - 每个操作数或完成的子树都存储在`node_stack`- 仅当优先规则保证运算符应立即绑定时才会处理运算符

 由于运算符的处理顺序与算术求值的顺序完全相同，因此构造的树保留了优先级和结合性。 

括号自然起作用，因为它们会延迟处理，直到封闭的子表达式完成为止。 

## Python 解决方案```python
# Definition for a binary tree node.
# class Node(object):
#     def __init__(self, val=" ", left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def expTree(self, s: str) -> 'Node':

        def precedence(op: str) -> int:
            if op in ('+', '-'):
                return 1
            if op in ('*', '/'):
                return 2
            return 0

        def build():
            operator = operator_stack.pop()

            right = node_stack.pop()
            left = node_stack.pop()

            node = Node(operator)
            node.left = left
            node.right = right

            node_stack.append(node)

        node_stack = []
        operator_stack = []

        for ch in s:

            if ch.isdigit():
                node_stack.append(Node(ch))

            elif ch == '(':
                operator_stack.append(ch)

            elif ch == ')':

                while operator_stack and operator_stack[-1] != '(':
                    build()

                operator_stack.pop()

            else:

                while (
                    operator_stack
                    and operator_stack[-1] != '('
                    and precedence(operator_stack[-1]) >= precedence(ch)
                ):
                    build()

                operator_stack.append(ch)

        while operator_stack:
            build()

        return node_stack[-1]
```该实现遵循前面描述的确切算法。 

这`precedence()`helper 决定操作员的优先级。 乘法和除法的优先级高于加法和减法。 

这`build()`helper 从顶部运算符和两个最近的节点创建一个子树。 首先弹出右子树，因为堆栈反转操作数顺序。 

在主要遍历过程中：

 - 数字立即成为叶节点
 - 括号控制分组边界
 - 运算符按优先级处理

 条件：```python
precedence(operator_stack[-1]) >= precedence(ch)
```至关重要，因为它强制执行左关联性。 

例如：```python
1-2-3
```必须成为：```python
(1-2)-3
```而不是：```python
1-(2-3)
```最后，处理所有剩余的运算符，只留下一个树根。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type Node struct {
 *     Val string
 *     Left *Node
 *     Right *Node
 * }
 */

type Solution struct{}

func (s *Solution) expTree(expression string) *Node {

    precedence := func(op byte) int {
        if op == '+' || op == '-' {
            return 1
        }
        if op == '*' || op == '/' {
            return 2
        }
        return 0
    }

    nodeStack := []*Node{}
    operatorStack := []byte{}

    build := func() {
        operator := operatorStack[len(operatorStack)-1]
        operatorStack = operatorStack[:len(operatorStack)-1]

        right := nodeStack[len(nodeStack)-1]
        nodeStack = nodeStack[:len(nodeStack)-1]

        left := nodeStack[len(nodeStack)-1]
        nodeStack = nodeStack[:len(nodeStack)-1]

        node := &Node{
            Val: string(operator),
            Left: left,
            Right: right,
        }

        nodeStack = append(nodeStack, node)
    }

    for i := 0; i < len(expression); i++ {

        ch := expression[i]

        if ch >= '0' && ch <= '9' {

            nodeStack = append(nodeStack, &Node{
                Val: string(ch),
            })

        } else if ch == '(' {

            operatorStack = append(operatorStack, ch)

        } else if ch == ')' {

            for len(operatorStack) > 0 &&
                operatorStack[len(operatorStack)-1] != '(' {

                build()
            }

            operatorStack = operatorStack[:len(operatorStack)-1]

        } else {

            for len(operatorStack) > 0 &&
                operatorStack[len(operatorStack)-1] != '(' &&
                precedence(operatorStack[len(operatorStack)-1]) >= precedence(ch) {

                build()
            }

            operatorStack = append(operatorStack, ch)
        }
    }

    for len(operatorStack) > 0 {
        build()
    }

    return nodeStack[len(nodeStack)-1]
}
```Go 的实现与 Python 解决方案非常相似。 

主要区别是堆栈操作的显式切片操作。 

Go 使用指针作为树节点，因此子树构建自然会共享引用而无需复制数据。 

由于操作数保证为单位数且表达式长度很小，因此不存在整数溢出问题。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个字符和运算符都会处理一次 |
 | 空间| O(n) | 堆栈可以存储所有操作数/运算符 |

 每个操作数只被压入一次。 

每个运算符是：

 - 推过一次
 - 弹出一次

 因此，总工作量与表达式长度呈线性关系。 

每个堆栈都可以增长到一定大小`O(n)`在最坏的情况下，特别是对于深度嵌套的表达式。

 ## 边缘情况

 ### 单操作数表达式

 像这样的表达式：```
"7"
```根本不包含任何运算符。 

有缺陷的实现可能会假设每个有效表达式至少包含一个运算符，并且在子树构建期间尝试弹出操作数时会失败。 

此实现可以自然地处理这种情况，因为单位数节点被推到`node_stack`，并且没有任何运算符被处理。 直接返回最终的节点。 

### 深层嵌套括号

 表达式例如：```
"1*(2+(3*(4+5)))"
```可以很容易地破坏不正确的优先级处理。 

如果没有正确的括号跟踪，嵌套表达式之外的运算符可能会被过早处理。 

该算法通过推动来防止这种情况发生`(`到运算符堆栈上并拒绝处理超出它的内容，直到匹配`)`出现。 

### 左结合性

 表达式如：```
"1-2-3"
```必须解析为：```
(1-2)-3
```而不是：```
1-(2-3)
```这很微妙但很重要。 

条件：```
precedence(top) >= precedence(current)
```确保立即处理具有相同优先级的运算符，从而正确执行左关联性。
