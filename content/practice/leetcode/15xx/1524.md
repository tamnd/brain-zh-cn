 **难度：** 🟡 中等
 **主题：** 数组、数学、动态规划、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组中子数组的数量`arr`其总和为奇数。 **子数组** 定义为原始数组的连续段。 输入是一个整数列表，我们需要返回总和为奇数的子数组的数量。 结果必须按模返回`10^9 + 7`因为计数可能会变得非常大。 

约束告诉我们数组最多可以达到`10^5`元素，每个元素的范围是`1`到`100`。 这表明检查每个可能的子数组的简单解决方案将太慢，因为子数组的数量是`O(n^2)`，最多可达`10^10`在最坏的情况下。 

重要的边缘情况包括所有数字均为偶数的数组（无奇数和子数组）、所有数字均为奇数、具有单个元素的数组或具有交替偶数和奇数的数组。 该问题保证数组非空，因此我们不必处理空输入。 

## 方法

 **暴力方法**涉及生成所有可能的子数组，计算它们的总和，并检查每个总和是否为奇数。 虽然这种方法很简单并且保证是正确的，但由于其`O(n^2)`子数组枚举和`O(n)`每个子数组的总和计算，结果是`O(n^3)`大型数组的时间复杂度。 

**最佳方法**依赖于我们不需要单独计算每个子数组总和的关键见解。 相反，我们可以使用**前缀和和奇偶校验跟踪**。 子数组和的奇偶校验仅取决于其端点处的前缀和的奇偶校验。 具体来说，如果前缀和是奇数，并且我们减去偶数前缀和，则得到的子数组和是奇数。 因此，通过在迭代时跟踪奇数和偶数前缀和的数量，我们可以在 **O(n)** 时间内增量计算具有奇数和的子数组的数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 生成所有子数组，对它们求和，检查奇数 |
 | 最佳 | O(n) | O(1) | O(1) | 动态跟踪奇数/偶数前缀和并更新计数 |

 ## 算法演练

 1.初始化三个变量：`odd_count = 0`,`even_count = 1`， 和`total_odd_subarrays = 0`。 这里，`even_count`从 1 开始，以考虑偶数的“空前缀和”。 
2. 初始化运行变量`current_sum = 0`当我们迭代数组时跟踪前缀和。 
3. 迭代中的每个元素`arr`。 对于每个元素，将其添加到`current_sum`。 
4. 检查奇偶性`current_sum`：

- 如果`current_sum`是奇数，它可以与之前所有的**偶数前缀和**形成奇数和，所以递增`total_odd_subarrays`经过`even_count`。 还增加`odd_count`加 1 来记录这个新的奇数前缀和。 
- 如果`current_sum`是偶数，它可以与之前所有的**奇数前缀和**形成奇数和，所以递增`total_odd_subarrays`经过`odd_count`。 增量`even_count`加 1 来记录这个新的偶数前缀和。 
5. 取模`10^9 + 7`每次增量后以避免溢出。 
6.处理完所有元素后，返回`total_odd_subarrays`。 

**为什么它有效：** 关键的不变量是索引中子数组和的奇偶校验`i`到`j`等于之间的奇偶校验差`prefix_sum[j]`和`prefix_sum[i-1]`。 通过计算有多少前缀和是偶数和奇数，我们可以在恒定时间内确定有多少以当前索引结尾的子数组具有奇数和。 

## Python 解决方案```python
from typing import List

class Solution:
    def numOfSubarrays(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        odd_count = 0
        even_count = 1  # account for the empty prefix sum
        total_odd_subarrays = 0
        current_sum = 0

        for num in arr:
            current_sum += num
            if current_sum % 2 == 0:
                total_odd_subarrays = (total_odd_subarrays + odd_count) % MOD
                even_count += 1
            else:
                total_odd_subarrays = (total_odd_subarrays + even_count) % MOD
                odd_count += 1

        return total_odd_subarrays
```Python 实现完全遵循该算法。 这`current_sum`跟踪运行的前缀和。 根据它是奇数还是偶数，我们使用先前计算的相反奇偶校验的前缀和来更新奇数子数组的总数。 我们使用模运算来处理大结果。 

## 解决方案```go
func numOfSubarrays(arr []int) int {
    const MOD = 1_000_000_007
    oddCount, evenCount := 0, 1
    totalOddSubarrays, currentSum := 0, 0

    for _, num := range arr {
        currentSum += num
        if currentSum % 2 == 0 {
            totalOddSubarrays = (totalOddSubarrays + oddCount) % MOD
            evenCount++
        } else {
            totalOddSubarrays = (totalOddSubarrays + evenCount) % MOD
            oddCount++
        }
    }

    return totalOddSubarrays
}
```Go 实现镜像了 Python 版本，但使用显式类型声明和`const`为模数。 切片迭代为`range`。 每次更新后取模可以防止溢出。

 ## 边缘情况

 **单元素数组：** 如果数组只有一个元素，则结果为 0 或 1，具体取决于奇偶校验。 该算法通过正确初始化来处理这个问题`even_count`并更新`total_odd_subarrays`。 

**所有偶数：** 在这种情况下，`current_sum`永远不会变得奇怪，所以`total_odd_subarrays`保持为零。 该算法计数正确，因为没有进行任何更新`odd_count`。 

**所有奇数：** 每个新奇数
