[LeetCode 问题 1568](https://leetcode.com/problems/minimum-number-of-days-to-disconnect-island/)

 **难度：** 🔴难
 **主题：** 数组、深度优先搜索、广度优先搜索、矩阵、强连通分量

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个二进制矩阵，其中每个单元格要么是陆地（`1`）或水（`0`）。 垂直或水平接触的陆地单元属于同一个岛屿。 仅当整个网格中只有一个岛时，网格才被认为是连通的。 

每天，我们可能恰好将一个陆地细胞转化为水。 我们的目标是确定断开电网所需的最短天数。 断开的电网意味着：

 - 岛屿为零，或者
 - 有两个或更多岛屿

 换句话说，当网格不再包含恰好一个相连的土地组成部分时，我们就完成了。 

网格尺寸最多为`30 x 30`，所以最多有`900`细胞总数。 它足够小，足以允许重复的图遍历，例如 DFS 或 BFS。 

一些重要的观察立即简化了问题：

 - 如果网格已包含零个岛屿或多个岛屿，则答案为`0`因为它已经断开了。 
- 如果移除一个陆地单元会断开岛屿的连接，答案是`1`。 
- 否则，答案总是`2`。 

最终的观察结果是最佳解决方案背后的关键见解。 它来自图论。 任何连接的岛屿始终可以通过移除最多两个单元来断开连接。 直观上，如果不存在单个铰接点，移除两个精心选择的单元总是有效的。 

一些边缘情况很重要：

 - 仅含有水的电网已断开。 
- 删除该单个单元后，仅包含一个陆地单元的网格会断开连接。 
- 具有两个连接单元的网格需要两次移除，因为移除一个仍然留下一个岛。 
- 诸如线或桥之类的细结构可能包含关节点，从而得出答案`1`。 

## 方法

 ### 蛮力方法

 暴力解决方案会尝试所有可能的删除顺序。 

首先，我们检查电网是否已经断开。 如果是，则返回`0`。 

否则，对于每个陆地单元：

 1. 暂时将其移除。 
2. 使用DFS或BFS统计岛屿的数量。 
3. 如果电网断开，返回`1`。 
4. 恢复细胞。 

如果单个移除不起作用，理论上我们可以尝试所有成对的陆地单元：

 1. 取出两个电池。 
2. 重新计算连接。 
3. 检查电网是否断线。 

这种方法是正确的，因为它详尽地检查了每组可能的删除。 然而，测试所有对的成本是不必要的。 

如果有`k`陆地细胞，检查所有对需要`O(k²)`尝试，并且每次尝试都会在网格上执行完整的 DFS。 由于网格最多可以包含`900`细胞，这变得太慢了。 

### 关键见解

 关键的观察是答案只能是`0`,`1`， 或者`2`。 

为什么？ 

-`0`如果电网已经断开。 
-`1`如果存在一个连接点，即一个陆地单元，其移除将断开该岛的连接。 
- 否则`2`。 

该属性来自网格的连通性理论。 没有铰接点的连接岛始终可以通过两次移除来断开连接。 

因此，我们不需要检查所有对，我们只需要：

 1. 初始连接检查
 2. 尝试将每个陆地单元移除一次
 3. 如果不起作用，则返回`2`这大大降低了复杂性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((mn)³) | O(百万) | 反复尝试所有的删除对并重新计算岛屿 |
 | 最佳 | O((mn)²) | O(百万) | 仅检查单细胞去除，因为答案最多为 2 |

 ## 算法演练

 1. 创建辅助函数`count_islands()`它计算网格中存在多少个相连的土地组成部分。 

该函数从每个未访问的陆地单元执行 DFS。 每个 DFS 都将整个岛屿标记为已访问过。 
2. 打电话`count_islands()`在原来的网格上。 

如果结果不准确`1`，电网已经断开，所以返回`0`。 
3. 迭代网格中的每个单元格。 

每当我们遇到陆地细胞时：

 - 暂时将其更改为`1`到`0`- 重新计算岛屿数量
 - 如果结果不准确`1`， 返回`1`- 将细胞恢复到`1`4. 如果没有任何一次移除使岛屿断开连接，则返回`2`。 

DFS 是一个自然的选择，因为网格很小，我们只需要连通性信息。 BFS 也同样可以很好地工作。 

### 为什么它有效

 该算法检查所有可能的单细胞去除。 如果任何拆除行动使岛屿失去联系，那么一天就足够了。 

如果没有，该岛就没有连接点。 连接网格图的一个已知属性保证最多两次删除始终足以断开岛屿。 因此返回`2`总是正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def minDays(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        cols = len(grid[0])

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        def count_islands() -> int:
            visited = [[False] * cols for _ in range(rows)]

            def dfs(r: int, c: int) -> None:
                visited[r][c] = True

                for dr, dc in directions:
                    nr = r + dr
                    nc = c + dc

                    if (
                        0 <= nr < rows
                        and 0 <= nc < cols
                        and not visited[nr][nc]
                        and grid[nr][nc] == 1
                    ):
                        dfs(nr, nc)

            island_count = 0

            for r in range(rows):
                for c in range(cols):
                    if grid[r][c] == 1 and not visited[r][c]:
                        island_count += 1
                        dfs(r, c)

            return island_count

        if count_islands() != 1:
            return 0

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1:
                    grid[r][c] = 0

                    if count_islands() != 1:
                        grid[r][c] = 1
                        return 1

                    grid[r][c] = 1

        return 2
```实现首先定义 DFS 遍历期间使用的四种可能的移动方向。 

这`count_islands()`助手构造一个`visited`矩阵并扫描整个网格。 每当它发现一个未访问过的陆地单元时，它就会启动 DFS 来标记整个连接的组件。 每个DFS调用对应一个岛屿。 

主要算法首先检查电网是否已经断开。 如果是，则立即返回`0`。 

接下来，代码迭代每个陆地单元并暂时将其删除。 每次删除后，它都会重新计算岛屿的数量。 如果网格不再包含一个岛屿，那么单次移除就会成功断开网格，所以答案是`1`。 

如果所有单细胞移除失败，算法将返回`2`。 

## 解决方案```go
func minDays(grid [][]int) int {
	rows := len(grid)
	cols := len(grid[0])

	directions := [][]int{
		{1, 0},
		{-1, 0},
		{0, 1},
		{0, -1},
	}

	var dfs func(int, int, [][]bool)

	dfs = func(r int, c int, visited [][]bool) {
		visited[r][c] = true

		for _, dir := range directions {
			nr := r + dir[0]
			nc := c + dir[1]

			if nr >= 0 && nr < rows &&
				nc >= 0 && nc < cols &&
				!visited[nr][nc] &&
				grid[nr][nc] == 1 {

				dfs(nr, nc, visited)
			}
		}
	}

	countIslands := func() int {
		visited := make([][]bool, rows)

		for i := range visited {
			visited[i] = make([]bool, cols)
		}

		islandCount := 0

		for r := 0; r < rows; r++ {
			for c := 0; c < cols; c++ {
				if grid[r][c] == 1 && !visited[r][c] {
					islandCount++
					dfs(r, c, visited)
				}
			}
		}

		return islandCount
	}

	if countIslands() != 1 {
		return 0
	}

	for r := 0; r < rows; r++ {
		for c := 0; c < cols; c++ {
			if grid[r][c] == 1 {
				grid[r][c] = 0

				if countIslands() != 1 {
					grid[r][c] = 1
					return 1
				}

				grid[r][c] = 1
			}
		}
	}

	return 2
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

Go 没有使用 Python 集合或带有闭包的嵌套函数，而是使用`visited`2D 切片和递归 DFS 函数。 由于 Go 不像 Python 那样清晰地支持默认的嵌套递归语法，因此 DFS 函数在赋值之前被声明为变量。 

网格在临时​​拆除过程中进行了适当修改，并在之后恢复。 

因为最大网格尺寸只有`30 x 30`，递归深度在两种语言中都是安全的。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O((mn)²) | 我们对每个陆地单元在整个网格上运行一次 DFS |
 | 空间| O(百万) | 访问矩阵和递归堆栈 |

 让`N = m × n`。 

这`count_islands()`函数需要`O(N)`时间，因为每个单元最多被访问一次。 

在最坏的情况下，每个单元格都是陆地，所以我们的性能达到`N`删除尝试。 每次尝试都会重新计算岛屿`O(N)`时间。 

因此总复杂度是`O(N²)`。 

辅助空间来自访问矩阵和DFS递归深度。

 ## 边缘情况

 不包含土地的网格是一个重要的极端情况。 由于连接的定义恰好需要一个岛屿，因此具有零个岛屿的网格已经断开。 幼稚的实现可能会错误地假设仅当存在多个岛屿时才需要删除。 该实现正确处理了这个问题，因为初始岛屿计数检查返回除`1`。 

单个陆地单元是另一个棘手的情况。 移除该单元会产生零个岛，这被视为断开连接。 某些实现错误地期望删除后至少有两个组件。 该算法反而检查岛屿数量是否不等于`1`，它正确地将零个岛屿视为断开连接。 

密集的土地，例如`2x2`正方形或更大的矩形也可能有问题。 移除任何单个单元仍然会使剩余的土地保持连接。 基于低度单元的朴素启发式可能会错误地返回`1`。 该实现通过在每次删除尝试后显式重新计算连接来避免此问题。 

薄桥状结构尤其重要，因为它们包含铰接点。 拆除桥梁会将岛屿分成多个部分。 基于 DFS 的连接检查正确识别这种情况并返回`1`。
