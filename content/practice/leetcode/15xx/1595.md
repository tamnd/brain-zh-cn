[LeetCode 问题 1595](https://leetcode.com/problems/minimum-cost-to-connect-two-groups-of-points/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、位操作、矩阵、位掩码

 ## 解决方案

 ## 问题理解

 问题是要求我们找到连接两组点的最小成本，其中第一组有`size1`点，第二组有`size2`点。 我们给定一个成本矩阵`cost`尺寸的`size1 x size2`在哪里`cost[i][j]`表示连接的成本`i`第一组中的第 - 个点`j`第二组中的第 - 点。 

有效连接意味着第一组中的每个点都连接到第二组中的至少一个点，并且第二组中的每个点都连接到第一组中的至少一个点。 单个点可以有多个连接，因此将一个点连接到另一组中的多个点没有限制。 目标是找到使总成本最小化的连接配置。 

对于动态规划来说，约束足够小：`size1`和`size2`最多 12，这表明位掩码 DP 是可行的，因为`2^12 = 4096`。`size1 >= size2`告诉我们我们可以有效地迭代较小组的子集。 这`cost[i][j]`值范围从 0 到 100，可以进行求和。 

重要的边缘情况包括`size1`或者`size2`当所有成本相等以及某些成本为 0 时，值为 1。这些情况可能会影响朴素贪婪解决方案的正确性。 

## 方法

 蛮力方法是生成所有可能的方式将第一组的点连接到第二组，以便所有点都连接起来。 对于每种配置，我们将成本相加并选择最小值。 这是正确的，但不可行，因为组合的数量呈指数增长：第一组中的每个点都有`2^size2 - 1`连接到第二组的有效方法，导致`(2^size2 - 1)^size1`总的组合，即使对于`size1 = 12`和`size2 = 12`。 

最佳方法使用带有位掩码的动态编程来表示已连接的第二组的子集。 我们迭代第一组中的每个点，并考虑将其连接到第二组的所有可能的子集，更新 DP 表以跟踪每个连接子集的最小成本。 关键的见解是我们可以将第二组的连接状态表示为位掩码，使我们能够在考虑所有组合的同时有效地存储和更新状态。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((2^大小2 - 1)^大小1) | O(1) | O(1) | 枚举所有有效的连接子集，对于最大约束不切实际 |
 | 最佳 | O(尺寸1 * 2^尺寸2 * 尺寸2) | O(2^大小2) | 在第二组的子集上使用带有位掩码的 DP，对于大小 <= 12 是可行的

 ## 算法演练

 1.初始化一个大小为DP的数组`2^size2`表示第二组中连接点的所有可能子集。 每个元素`dp[mask]`将存储将迄今为止处理的第一组中的点连接到由下式表示的子集的最小成本`mask`。 最初，`dp[0] = 0`所有其他都是无穷大。 
2. 迭代每个点`i`在第一组中。 对于每个`i`,初始化一个新的DP数组`new_dp`存储更新的成本。 我们将计算包含点后连接点的每个子集的最小成本`i`。 
3. 对于每个子集`mask`第二组，检查所有点`j`在第二组中。 对于每个`j`,计算新的掩码`mask | (1 << j)`表示当前子集的并集并连接`i`到`j`。 更新`new_dp[new_mask]`作为其当前值的最小值和`dp[mask] + cost[i][j]`。 
4.处理第二组中的所有点后`i`， 分配`dp = new_dp`。 
5. 处理完第一组中的所有点后，完全连接两组的最小成本为`dp[(1 << size2) - 1]`，它表示连接的第二组中的所有点。 

为什么它有效：DP 不变量是`dp[mask]`始终表示连接第一个的最低成本`i`指向由下式表示的第二组的子集`mask`。 通过迭代更新第一组中每个点的子集，我们确保有效地考虑所有连接组合，而无需多余的重新计算。 

## Python 解决方案```python
from typing import List

class Solution:
    def connectTwoGroups(self, cost: List[List[int]]) -> int:
        size1, size2 = len(cost), len(cost[0])
        max_mask = 1 << size2
        dp = [float('inf')] * max_mask
        dp[0] = 0
        
        for i in range(size1):
            new_dp = [float('inf')] * max_mask
            for mask in range(max_mask):
                if dp[mask] == float('inf'):
                    continue
                for j in range(size2):
                    new_mask = mask | (1 << j)
                    new_dp[new_mask] = min(new_dp[new_mask], dp[mask] + cost[i][j])
            dp = new_dp
        
        return dp[max_mask - 1]
```该代码为第二组的所有可能子集初始化一个 DP 数组。 对于第一组中的每个点，它会考虑与第二组中每个点的连接来更新 DP 数组。 处理完所有点后，最后一个元素`dp[max_mask - 1]`给出连接两组中所有点的最小成本。 

## 解决方案```go
import "math"

func connectTwoGroups(cost [][]int) int {
    size1, size2 := len(cost), len(cost[0])
    maxMask := 1 << size2
    dp := make([]int, maxMask)
    for i := 1; i < maxMask; i++ {
        dp[i] = math.MaxInt32
    }

    for i := 0; i < size1; i++ {
        newDP := make([]int, maxMask)
        for k := range newDP {
            newDP[k] = math.MaxInt32
        }
        for mask := 0; mask < maxMask; mask++ {
            if dp[mask] == math.MaxInt32 {
                continue
            }
            for j := 0; j < size2; j++ {
                newMask := mask | (1 << j)
                if dp[mask]+cost[i][j] < newDP[newMask] {
                    newDP[newMask] = dp[mask] + cost[i][j]
                }
            }
        }
        dp = newDP
    }

    return dp[maxMask-1]
}
```Go 实现遵循与 Python 相同的逻辑，但使用`math.MaxInt32`来代表无穷大。 切片用于 DP 数组，我们确保每个子集更新在分配之前检查较低的成本。 

## 工作示例

 **示例1：**`cost = [[15, 96], [36, 2]]`最初的`dp = [0, inf, inf, inf]`处理第一点`i = 0`:

 - 连接到`j=0`-> new_mask=1, new_dp[1] = 0+15=15
 - 连接到`j=1`-> new_mask=2, new_dp[2] = 0+96=96

 处理第二点`i = 1`:

 - 对于 mask=1，连接到 j=0 -> new_mask=1, new_dp[1] = 15+36=51，连接到 j=1 -> new_mask=3, new_dp[3]=15+2=17
 - 对于 mask=2，连接到 j=0 -> new_mask=3, new_dp[3]=min(17, 96+36=132)=17，连接到 j=1 -> new_mask=2, new_dp[2]=96+2=98

 最终 dp = [inf, 51, 98, 17] → 答案 = 17

 | 测量| 复杂性 | 说明|
