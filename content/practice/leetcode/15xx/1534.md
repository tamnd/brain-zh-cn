 **难度：** 🟢简单
 **主题：** 数组、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们计算整数数组中**好三元组**的数量`arr`基于三个差异约束`a`,`b`， 和`c`。 三胞胎`(arr[i], arr[j], arr[k])`如果同时满足三个条件，则被认为是好的： 指数`i`,`j`， 和`k`严格递增（`0 <= i < j < k < arr.length`），并且元素之间的绝对差值满足阈值：`|arr[i] - arr[j]| <= a`,`|arr[j] - arr[k]| <= b`， 和`|arr[i] - arr[k]| <= c`。 

简而言之，我们正在寻找数组中三个不同元素（按顺序）的所有组合，其成对差异满足给定的界限。 输入`arr`最多可以有 100 个元素，每个整数在 0 到 1000 之间，差值阈值也在 0 到 1000 之间。这个有限的数组大小允许我们考虑使用三个嵌套循环的强力解决方案，因为三元组的总数最多为`100 choose 3 = 161700`，这在计算上是可行的。 

重要的边缘情况包括没有三元组满足条件的数组（例如，所有差异都超过阈值）、所有元素都相同的数组（所有差异均为零）以及最小长度为 3 的数组。该问题保证数组至少有 3 个元素，因此我们不需要处理较小的输入。 

## 方法

 **暴力方法**很简单：我们生成每个可能的三元组`(i, j, k)`在哪里`i < j < k`并检查是否满足所有三个差异条件。 这保证找到所有好的三元组，因为它详尽地检查了每个候选者，但它使用了三个嵌套循环，导致`O(n^3)`时间复杂度。 考虑到约束条件（`n <= 100`），这种做法是可以接受的。 

就该问题的最坏情况复杂性而言，没有明显更快的方法，因为我们必须检查每个三元组以确保满足所有条件。 考虑到输入大小较小，进一步优化（例如，使用排序或前缀结构）不会提供有意义的渐近改进。 关键的见解是问题的约束足够小，以至于暴力方法实际上是最优的。

 ## 算法演练

 1.初始化一个计数器`count`为零。 这将保存找到的好三元组的数量。 
2. 迭代第一个索引`i`从 0 到`len(arr) - 3`。 这代表三元组的第一个元素。 
3. 对于每个`i`，迭代第二个索引`j`从`i + 1`到`len(arr) - 2`。 这确保了`j > i`并避免重复的三元组。 
4. 对于每个`j`，迭代第三个索引`k`从`j + 1`到`len(arr) - 1`。 这确保了`k > j`并保持指数的升序。 
5. 对于每个三元组`(i, j, k)`，计算绝对差：`|arr[i] - arr[j]|`,`|arr[j] - arr[k]|`， 和`|arr[i] - arr[k]|`。 
6. 如果所有三个差异都在各自的阈值内`a`,`b`， 和`c`, 增量`count`1.
 7.检查完所有可能的三元组后，返回`count`。 

**为什么有效：** 通过按递增索引顺序迭代三个不同元素的每个组合，我们确保不会遗漏任何有效的三元组。 条件检查保证只有满足所有三个绝对差约束的三元组才会被计数。 

## Python 解决方案```python
from typing import List

class Solution:
    def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
        count = 0
        n = len(arr)
        for i in range(n - 2):
            for j in range(i + 1, n - 1):
                if abs(arr[i] - arr[j]) > a:
                    continue
                for k in range(j + 1, n):
                    if abs(arr[j] - arr[k]) <= b and abs(arr[i] - arr[k]) <= c:
                        count += 1
        return count
```该实现首先迭代索引`i`和`j`。 它适用于早期`continue`检查第一个差异`|arr[i] - arr[j]| > a`跳过不必要的计算`k`。 然后，对于每个有效的`(i, j)`对，它迭代`k`并检查剩下的两个差异。 使用`abs`确保我们正确处理负面差异。 柜台`count`累积好三元组的数量并在最后返回。 

## 解决方案```go
func countGoodTriplets(arr []int, a int, b int, c int) int {
    count := 0
    n := len(arr)
    for i := 0; i < n-2; i++ {
        for j := i + 1; j < n-1; j++ {
            if abs(arr[i]-arr[j]) > a {
                continue
            }
            for k := j + 1; k < n; k++ {
                if abs(arr[j]-arr[k]) <= b && abs(arr[i]-arr[k]) <= c {
                    count++
                }
            }
        }
    }
    return count
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```在Go中，我们定义了一个辅助函数`abs`因为Go没有提供内置的`abs`对于整数。 迭代结构反映了 Python 解决方案。 这`continue`优化会跳过无效的不必要的迭代`(i, j)`对，减少冗余计算。
