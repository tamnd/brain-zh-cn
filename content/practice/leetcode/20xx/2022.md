[LeetCode 2022 题](https://leetcode.com/problems/convert-1d-array-into-2d-array/)

 **难度：** 🟢简单
 **主题：** 数组、矩阵、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们变换一个一维数组，`original`，转化为二维数组`m`行和`n`列。 构建是连续的：第一个`n`的元素`original`形成第一行，下一行`n`元素形成第二行，这种情况一直持续到所有行都被填满为止。 如果元素总数`original`不等于`m * n`，不可能形成完整的`m x n`数组，因此应返回一个空的二维数组。 

输入`original`是一个整数列表，`m`代表行数，并且`n`表示二维数组的列数。 预期输出是 Python 中的列表列表（或 Go 中的切片），其中每个内部列表代表 2D 数组的一行。 

约束表明长度`original`可以大到 50,000 并且`m`和`n`最多可达 40,000。 这告诉我们解决方案必须高效并避免不必要的元素复制。 

重要的边缘情况包括当元素数量`original`不匹配`m * n`， 什么时候`original`只有一个元素，或者当`m`或者`n`是一，这将有效地产生行向量或列向量。 该问题保证了`original`是非空的并且`m`和`n`是积极的。 

## 方法

 一种强力方法是手动迭代每一行和每一列，从`original`一个接一个，并将它们附加到新行，直到我们填满`m`行。 虽然这很简单，但主要的限制是我们需要嵌套循环，这可能有点冗长，尽管时间复杂度对于约束来说仍然是可以接受的。 

最佳方法的关键是首先通过验证是否可以重新调整阵列`len(original) == m * n`。 如果没有，我们可以立即返回一个空数组。 否则，我们可以使用 Python 中的切片或 Go 中的索引赋值来高效地逐行填充二维数组。 这避免了嵌套循环并保持实现简单和干净。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(m * n) | O(m * n) | 嵌套循环填充每一行和每一列|
 | 最佳| O(m * n) | O(m * n) | 检查可行性并使用切片/索引来有效地填充行 |

 ## 算法演练

 1. 计算二维数组所需的元素总数，即`m * n`。 
2. 将其与长度进行比较`original`。 如果它们不匹配，则立即返回一个空数组，因为无法进行整形。 
3.初始化一个空列表`result`（或 Go 中的切片）来保存 2D 数组的行。 
4. 迭代`original`的步骤`n`（列数）。 对于每一步，切片`original[i:i+n]`提取下一行。 
5. 将每个提取的行附加到`result`。 
6.处理完所有元素后，返回`result`。 

为什么它有效：该算法有效是因为我们按顺序获取连续大小的块`n`从`original`并形成与问题描述完全一致的行。 可行性检查确保我们永远不会尝试无效的重塑。 

## Python 解决方案```python
from typing import List

class Solution:
    def construct2DArray(self, original: List[int], m: int, n: int) -> List[List[int]]:
        if len(original) != m * n:
            return []
        
        result = []
        for i in range(0, len(original), n):
            result.append(original[i:i+n])
        
        return result
```该代码首先检查重塑是否可能。 循环遍历`original`增量为`n`对表示行的连续段进行切片。 每个切片都附加到`result`，最后返回。 

## 解决方案```go
func construct2DArray(original []int, m int, n int) [][]int {
    if len(original) != m*n {
        return [][]int{}
    }
    
    result := make([][]int, 0, m)
    for i := 0; i < len(original); i += n {
        row := make([]int, n)
        copy(row, original[i:i+n])
        result = append(result, row)
    }
    
    return result
}
```在Go中，我们首先检查可行性，然后创建切片`result`有能力`m`。 对于每一行，我们分配一个长度的切片`n`并使用`copy`有效地复制元素的函数`original`。 这确保了内存安全和正确的行分隔。

 ## 边缘情况

 第一个边缘情况是元素数量不匹配时`m * n`。 如果实现无论如何都尝试填充数组，这是一个常见的错误来源。 该解决方案通过立即返回空数组来处理此问题。 

第二个边缘情况是当`m = 1`或者`n = 1`，有效地生成行或列向量。 切片或索引复制无需任何特殊逻辑即可处理这些问题，因为该算法不假设多行或多列。 

第三种边缘情况是单元素输入。 尽管微不足道，但它验证了该算法可以无错误地处理最小输入并生成正确的二维数组`[[element]]`。 这测试了切片和可行性逻辑。
