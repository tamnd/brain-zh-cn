[LeetCode 问题 2046](https://leetcode.com/problems/sort-linked-list-already-sorted-using-absolute-values/)

 **难度：** 🟡 中等
 **主题：** 链表、两个指针、排序

 ## 解决方案

 ## 问题理解

 该问题提供了一个单链表，其中节点**按其绝对值**而不是其实际值按非降序排序。 任务是重新排列此列表，以便节点根据其**实际值**按非降序排序。 

例如，考虑输入`[0, 2, -5, 5, 10, -10]`。 虽然绝对值`[0, 2, 5, 5, 10, 10]`已排序，负数在考虑其真实值时是乱序的。 输出应该是`[-10, -5, 0, 2, 5, 10]`。 

输入是单链表，而不是数组。 约束条件很大：列表最多可以包含 100,000 个节点，其值在范围内`[-5000, 5000]`。 这意味着，如果依赖于使用额外内存的基于比较的排序，将列表转换为数组并对其进行排序的简单方法会太慢。 

重要的边缘情况包括：

 1. 仅包含非负数的列表，该列表已按实际值排序。 
2. 只包含负数的列表，这将需要反转负数段。 
3. 单节点列表，它是普通排序的。 
4. 包含零和重复项的列表，应保持正确的顺序。 

该问题还暗示了**线性时间解决方案**，这表明无需完全排序即可巧妙地使用链表属性。 

## 方法

 **暴力方法**涉及遍历链表，将所有值提取到数组中，使用标准比较排序对数组进行排序，然后重建链表。 虽然这可以正常工作，但对于大型列表来说并不是最佳选择，因为它为数组使用了额外的内存并导致`O(n log n)`时间复杂度。 

**最佳方法**利用了列表已按绝对值排序的观察结果。 这保证了所有负数（按绝对值顺序）出现在其对应的正数之前。 如果我们**反转负子列表**，然后**将其与正子列表合并**，我们可以在**O(n)时间**和**O(1)额外空间**中实现完全排序的链表。 这些步骤包括在第一个非负节点处拆分列表、反转负子列表以及执行两个排序列表的标准合并。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 将列表转换为数组、排序、重建链表 |
 | 最佳| O(n) | O(1) | O(1) | 反转负子列表并就地与正子列表合并 |

 ## 算法演练

 1. **识别负子列表**：从头部开始，当节点有负值时向前移动。 在第一个非负节点处停止。 这会将列表分为负子列表和非负子列表。 
2. **反转负数子列表**：由于负数是按绝对递减顺序排列的，因此反转此子列表将按实际值正确排序。 
3. **合并两个已排序的子列表**：对链表使用标准的两指针合并技术。 初始化一个虚拟头并比较两个子列表中的节点，每次都附加较小的节点。 
4. **返回合并后的链表**：合并后，虚拟头指向按实际值完全排序的链表。 

**为什么有效**：输入列表中的负数按绝对值排序，但实际值递减。 反转它们可确保升序。 正数已经排序。 合并两个排序列表可以保证得到完全排序的结果。 这保留了线性时间复杂度和恒定的额外空间。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def sortLinkedList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        # Step 1: Split the negative and non-negative lists
        neg_dummy = ListNode(0)
        pos_dummy = ListNode(0)
        neg_tail, pos_tail = neg_dummy, pos_dummy
        curr = head

        while curr:
            next_node = curr.next
            curr.next = None
            if curr.val < 0:
                curr.next = neg_dummy.next
                neg_dummy.next = curr
            else:
                pos_tail.next = curr
                pos_tail = pos_tail.next
            curr = next_node

        # Step 2: Merge the two lists
        neg_head = neg_dummy.next
        pos_head = pos_dummy.next
        dummy = ListNode(0)
        tail = dummy

        while neg_head and pos_head:
            if neg_head.val < pos_head.val:
                tail.next = neg_head
                neg_head = neg_head.next
            else:
                tail.next = pos_head
                pos_head = pos_head.next
            tail = tail.next

        tail.next = neg_head if neg_head else pos_head
        return dummy.next
```该实现首先将输入列表分为负数段和非负数段。 负节点在遍历过程中预先添加，以就地反转它们。 最后，标准合并将反向否定列表与肯定列表合并。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func sortLinkedList(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }

    var negHead *ListNode
    dummyPos := &ListNode{}
    posTail := dummyPos
    curr := head

    for curr != nil {
        next := curr.Next
        curr.Next = nil
        if curr.Val < 0 {
            curr.Next = negHead
            negHead = curr
        } else {
            posTail.Next = curr
            posTail = posTail.Next
        }
        curr = next
    }

    dummy := &ListNode{}
    tail := dummy
    for negHead != nil && dummyPos.Next != nil {
        if negHead.Val < dummyPos.Next.Val {
            tail.Next = negHead
            negHead = negHead.Next
        } else {
            tail.Next = dummyPos.Next
            dummyPos.Next = dummyPos.Next.Next
        }
        tail = tail.Next
    }

    if negHead != nil {
        tail.Next = negHead
    } else if dummyPos.Next != nil {
        tail.Next = dummyPos.Next
    }

    return dummy.Next
}
```Go 版本反映了 Python 解决方案。 指针经过仔细更新，并且`nil`用来代替Python的`None`。 负节点通过前置进行内联反转，而正节点保持其顺序。 与 Python 版本类似，合并使用两个指针。 

## 工作示例

 ### 示例 1：`[0, 2, -5, 5, 10, -10]`第 1 步：分割

 - 负面清单：`-5 -> -10`（前置→`-10 -> -5`）
 - 正面清单：`0 -> 2 -> 5 -> 10`第 2 步：合并

 | 负| 邮政 | 合并|
 | --- | --- | --- |
 | -10 | 0 | -10 |
 | -5 | 0 | -10 -> -5 |
 | 无 | 0 | -10 -> -5 -> 0 -> 2 -> 5 -> 10 |

 输出：`[-10, -5, 0, 2, 5, 10]`### 示例 2：`[0, 1, 2]`负面清单：空

 正面清单：`0 -> 1 -> 2`合并结果：`0 -> 1 -> 2`### 示例 3：`[1]`只有一个节点，按原样返回：`[1]`## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点被访问一次用于分裂，一次用于合并 |
 | 空间| O(1) | O(1) | 反转负节点并就地完成合并，无需额外数组 |

 线性时间复杂度的产生是因为列表被遍历了恒定的次数，并且没有使用嵌套循环。 恒定空间是通过使用指针操作而不是辅助数据结构来维护的。
