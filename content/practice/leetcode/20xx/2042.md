[LeetCode 问题 2042](https://leetcode.com/problems/check-if-numbers-are-ascending-in-a-sentence/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们分析一个字符串表示的句子`s`并判断句子中嵌入的所有数字是否严格从左到右递增。 这里的句子被定义为由**单个空格**分隔的标记序列，其中每个标记要么是小写英文字母的单词，要么是不带前导零的正整数。 挑战是忽略单词并仅按顺序考虑数字标记。 

输入字符串`s`长度介于 3 到 200 个字符之间，并且至少包含两个数字。 每个数字都小于 100，因此它适合一个较小的整数范围。 任务是返回`true`如果每个数字都严格小于出现的下一个数字，否则`false`。 

重要的边缘情况包括数字重复、数字减少、数字出现在开头或结尾以及数字在标记位置方面不连续的句子。 例如，`"a 1 b 2"`是有效的，同时`"a 2 b 1"`不是。 

## 方法

 蛮力方法很简单：将句子拆分为标记，迭代每个标记，每当标记是数字时，将其转换为整数并将其附加到列表中。 提取所有数字后，迭代列表以检查每个数字是否严格小于下一个数字。 这可以正常工作，但需要两次传递：一次提取数字，另一次检查顺序。 

最佳方法将这两个步骤合并为一个过程。 我们不存储所有数字，而是维护一个变量`prev`跟踪之前看到的数字。 在迭代标记时，如果标记是数字，我们将其与`prev`。 如果不大于`prev`，我们立即返回`false`。 否则，我们更新`prev`并继续。 这降低了空间复杂度并略微提高了效率，因为如果检测到顺序违规，我们可以提前终止。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(米) | 一次提取数字，第二次检查严格递增；`n`是代币数量，`m`是数字的个数 |
 | 最佳| O(n) | O(1) | O(1) | 使用先前数字变量的单遍解决方案；`n`是令牌数量 |

 ## 算法演练

 1. 初始化变量`prev`到 0 来跟踪最后看到的号码。 零是安全的，因为所有数字都是正数。 
2.分割输入字符串`s`通过空格来获取单独的令牌。 
3. 迭代句子中的每个标记。 
4. 对于每个令牌，使用以下命令检查它是否是数字：`.isdigit()`方法。 
5.如果token是数字，则将其转换为整数`num`。 
6. 比较`num`和`prev`。 如果`num <= prev`， 返回`false`立即，因为序列不是严格递增的。 
7. 否则，更新`prev = num`并继续迭代。 
8.迭代完成后不返回`false`， 返回`true`。 

为什么它有效：在每一步，`prev`保持不变式，即它保存句子中看到的最后一个数字。 任何违反严格递增顺序的行为都会立即被检测到。 这保证了正确性，而无需存储所有数字。 

## Python 解决方案```python
class Solution:
    def areNumbersAscending(self, s: str) -> bool:
        prev = 0
        tokens = s.split()
        
        for token in tokens:
            if token.isdigit():
                num = int(token)
                if num <= prev:
                    return False
                prev = num
                
        return True
```在Python实现中，我们首先初始化`prev`为 0 并将句子拆分为标记。 该循环遍历每个标记，检查它是否仅由数字组成。 如果它是一个数字，我们将其转换为整数并与之前的数字进行比较。 如果顺序被违反，我们立即返回`false`。 否则，我们更新`prev`并继续。 该函数返回`true`如果所有数字都满足严格递增条件。 

## 解决方案```go
import (
    "strconv"
    "strings"
)

func areNumbersAscending(s string) bool {
    prev := 0
    tokens := strings.Split(s, " ")
    
    for _, token := range tokens {
        if num, err := strconv.Atoi(token); err == nil {
            if num <= prev {
                return false
            }
            prev = num
        }
    }
    
    return true
}
```在 Go 中，实现遵循相同的逻辑。 我们将句子分成标记并使用`strconv.Atoi`尝试转换。 如果转换成功（`err == nil`)，标记是数字。 该数字与`prev`，函数返回`false`如果它不是严格更大。 否则，`prev`已更新。

 ## 边缘情况

 第一个边缘情况是当数字出现在句子的开头或结尾时，例如，`"1 apple and 2 oranges"`。 该解决方案可以自然地处理这个问题，因为它会检查所有数字标记，无论位置如何。 

第二种边缘情况是当数字相等或减少时，这违反了严格递增条件。 例子如`"5 5"`或者`"3 2"`处理正确，因为比较`num <= prev`立即返回`false`。 

第三种边缘情况是当数字与单词交错时，中间可能有许多单词。 例如，`"a 1 b 2 c 3"`确保算法正确忽略非数字标记，同时保持先前的数字状态。 

该解决方案对于问题约束中定义的所有有效输入都是稳健的。
