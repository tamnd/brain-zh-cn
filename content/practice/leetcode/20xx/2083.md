[LeetCode 问题 2083](https://leetcode.com/problems/substrings-that-begin-and-end-with-the-same-letter/)

 **难度：** 🟡 中等
 **主题：** 哈希表、数学、字符串、计数、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定字符串中的所有子字符串`s`以相同的字符开始和结束。 子字符串是连续的字符序列，因此字符的顺序和相邻性很重要。 输入`s`是一个仅由小写英文字母组成的非空字符串，其长度可以大到`10^5`。 输出是一个整数，表示满足“相同的起始和结束字符”条件的子字符串的数量。 

从示例中，我们可以看到所有单字符子字符串都很重要，因为它们通常以相同的字符开头和结尾。 长度大于 1 的子串必须按字符频率仔细计数。 约束保证字符串永远不为空，因此我们不需要处理空输入情况。 

重要的边缘情况包括长度为 1 的字符串（最简单的情况）、所有字符都相同的字符串（子字符串的最大数量）以及所有字符都是唯一的字符串（超过长度 1 的子字符串的最小数量）。 

## 方法

 暴力方法很简单：使用两个嵌套循环迭代所有可能的子字符串，并检查每个子字符串的第一个和最后一个字符是否相同。 这保证了正确性，因为它显式地检查每个子字符串。 然而，时间复杂度为 O(n²)，因为长度为 n 的字符串中大约有 n*(n+1)/2 个子串，这对于`n`最多`10^5`。 

最佳方法依赖于一个关键观察：对于任何角色`c`，如果出现`k`字符串中以 开头和结尾的子字符串的数量`c`可以组合计算。 每个匹配项都可以与其自身（单字符子字符串）以及字符串中后面的任何其他匹配项配对。 这给出了一个公式`k + k*(k-1)/2`，这简化为`k*(k+1)/2`。 使用频率计数器来跟踪每个字符的出现次数使我们能够计算出字符串单次出现的总数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 显式检查所有子字符串 |
 | 最佳 | O(n) | O(1) | O(1) | 使用字符频率计数和组合公式 |

 ## 算法演练

 1.初始化一个数组`freq`大小为26来存储每个小写英文字母的出现频率。 每个索引对应一个字母。 
2. 遍历字符串中的每个字符`s`。 对于每个字符，增加其在`freq`大批。 
3. 初始化变量`result`为 0 以累加有效子串的总数。 
4. 对于每个频率`k`在`freq`，使用公式计算以相应字符开头和结尾的子字符串的数量`k*(k+1)//2`。 将此值添加到`result`。 
5. 返回`result`。 

**为什么有效：** 每个角色都有贡献`k*(k+1)/2`子字符串，因为对于每个出现的情况，它可以与自身和所有后续出现的情况形成子字符串。 对所有字符求和即可计算所有有效子字符串，而无需重复计算。 

## Python 解决方案```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        freq = [0] * 26  # frequency array for 'a' to 'z'
        for char in s:
            freq[ord(char) - ord('a')] += 1
        
        result = 0
        for count in freq:
            result += count * (count + 1) // 2
        
        return result
```Python 实现初始化 26 个字母的固定大小数组，以确保输入之外的空间为 O(1)。 这`ord`函数将每个字符映射到数组中的索引。 然后，我们迭代频率数组来计算每个字符的有效子字符串的数量，将它们相加得出最终答案。 

## 解决方案```go
func numberOfSubstrings(s string) int64 {
    var freq [26]int64
    for _, c := range s {
        freq[c-'a']++
    }
    
    var result int64
    for _, count := range freq {
        result += count * (count + 1) / 2
    }
    
    return result
}
```在 Go 中，我们使用数组类型`int64`安全地处理大量计数。 符文减法`c - 'a'`给出每个字母的索引。 结果累加还使用`int64`以防止长字符串溢出。

 ## 边缘情况

 **单字符串：** If`s`长度为 1，唯一的子串是字符串本身。 由于单个字符的频率为 1，该实现自然地处理了这个问题，产生`1*(1+1)/2 = 1`。 

**所有字符相同：** 对于像这样的字符串`"aaaaa"`，子串的数量呈二次方增长。 使用组合公式可以避免显式生成子字符串，从而防止超时。 

**所有字符都是唯一的：** 对于像这样的字符串`"abcde"`，仅单字符子字符串有效。 该公式仍然有效，因为`k*(k+1)/2 = 1`对于每个独特的角色。 这可以避免对不存在的较长子字符串进行不必要的迭代。 

这种方法无需特殊的条件逻辑即可有效地正确处理所有这些情况。
