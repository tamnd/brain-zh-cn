[LeetCode 2031 题](https://leetcode.com/problems/count-subarrays-with-more-ones-than-zeros/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、二分查找、分而治之、二叉索引树、线段树、归并排序、有序集

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算二进制数组的所有**子数组**`nums`包含更多`1`比`0`s。 换句话说，对于数组的任何连续切片，如果`1`s 超过数量`0`s，应该算。 输入数组仅包含`0`沙`1`s，并且输出必须以模数形式返回$10^9 + 7$因为有效子数组的数量可能非常大。 

约束条件告诉我们`nums`最多可以有$10^5$元素，因此采用强力方法检查所有可能的子数组（这将是$O(n^2)$）可能太慢了。 要考虑的边缘情况包括具有所有`0`，全部`1`s，或单个元素。 

## 方法

 **暴力方法**很简单：迭代所有可能的子数组，计算子数组的数量`1`沙`0`每个中都有 s，并且每当`1`超过`0`s。 这保证了正确性，因为它直接检查每个子数组，但对于大输入来说，由于以下原因，速度非常慢$O(n^2)$子数组和$O(n)$在简单的实现中对每个子数组进行计数，导致$O(n^3)$总时间复杂度。 

**最佳方法**依赖于一个关键的见解：我们可以通过映射来转换数组`1`→`+1`和`0`→`-1`。 然后，问题就简化为计算总和为**正**的子数组。 使用**前缀和**，索引中任何子数组的总和`i`到`j`是`prefix[j+1] - prefix[i]`。 我们可以使用**芬威克树（二叉索引树）**或**平衡有序集**来有效地计算有多少个先前的前缀和小于当前的前缀和。 

步骤是：转换数组，计算前缀和，并维护一个数据结构，允许查询小于当前前缀和的数量。 这将时间复杂度降低到大约$O(n \log n)$。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 直接检查所有子数组，对于 n=10^5 太慢 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 转换为前缀和并使用 BIT 或有序集有效计数正数 |

 ## 算法演练

 1. 转换二进制数组`nums`使得每个`0`变成`-1`和每个`1`遗迹`1`。 这使得这个问题相当于计算具有**正和**的子数组。 
2. 初始化一个前缀和数组，从0开始。这有助于有效地计算子数组的和。 
3. 使用 **Fenwick 树（二叉索引树）** 来维护迄今为止看到的前缀和的频率计数。 
4. 对于转换后的数组中的每个元素，更新当前的前缀和并查询 Fenwick Tree 以统计有多少个先前的前缀和**小于当前的前缀和**。 这给出了以当前索引结尾且总和为正的子数组的数量。 
5. 更新 Fenwick 树以包含当前的前缀和。 
6. 对这些计数进行模累加$10^9 + 7$并返回结果。 

**为什么有效：** 每个子数组总和`prefix[j+1] - prefix[i] > 0`通过查询前缀和的个数来统计`prefix[i] < prefix[j+1]`。 芬威克树允许我们在对数时间内有效地维护和查询这些计数。 

## Python 解决方案```python
from typing import List

class FenwickTree:
    def __init__(self, size: int):
        self.tree = [0] * (size + 2)
        self.size = size + 2
    
    def update(self, index: int, delta: int):
        while index < self.size:
            self.tree[index] += delta
            index += index & -index
    
    def query(self, index: int) -> int:
        res = 0
        while index > 0:
            res += self.tree[index]
            index -= index & -index
        return res

class Solution:
    def subarraysWithMoreOnesThanZeroes(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        arr = [1 if num == 1 else -1 for num in nums]
        prefix = [0]
        for num in arr:
            prefix.append(prefix[-1] + num)
        
        # Coordinate compression
        sorted_prefix = sorted(set(prefix))
        rank = {val: i+1 for i, val in enumerate(sorted_prefix)}
        
        ft = FenwickTree(len(rank))
        count = 0
        for p in prefix:
            r = rank[p]
            # Count of prefix sums < current prefix sum
            count += ft.query(r - 1)
            count %= MOD
            ft.update(r, 1)
        return count
```**实现说明：**我们首先进行改造`nums`进入`+1/-1`值，然后计算前缀和。 坐标压缩将前缀和映射到适合芬威克树的较小索引。 对于每个前缀和，查询之前小于它的前缀和的数量，给出在该点结束的正子数组的数量。 计数后，芬威克树将更新为当前前缀和。 

## 解决方案```go
package main

func lowbit(x int) int { return x & -x }

type FenwickTree struct {
    tree []int
    size int
}

func NewFenwickTree(size int) *FenwickTree {
    return &FenwickTree{tree: make([]int, size+2), size: size + 2}
}

func (ft *FenwickTree) Update(index, delta int) {
    for index < ft.size {
        ft.tree[index] += delta
        index += lowbit(index)
    }
}

func (ft *FenwickTree) Query(index int) int {
    res := 0
    for index > 0 {
        res += ft.tree[index]
        index -= lowbit(index)
    }
    return res
}

func subarraysWithMoreOnesThanZeroes(nums []int) int {
    MOD := 1000000007
    n := len(nums)
    arr := make([]int, n)
    for i, num := range nums {
        if num == 1 {
            arr[i] = 1
        } else {
            arr[i] = -1
        }
    }

    prefix := make([]int, n+1)
    for i := 0; i < n; i++ {
        prefix[i+1] = prefix[i] + arr[i]
    }

    // Coordinate compression
    m := make(map[int]struct{})
    for _, p := range prefix {
        m[p] = struct{}{}
    }
    sorted := make([]int, 0, len(m))
    for key := range m {
        sorted = append(sorted, key)
    }
    sort.Ints(sorted)
    rank := make(map[int]int)
    for i, val := range sorted {
        rank[val] = i + 1
    }

    ft := NewFenwickTree(len(rank))
    count := 0
    for _, p := range prefix {
        r := rank[p]
        count = (count + ft.Query(r-1)) % MOD
        ft.Update(r, 1)
    }
    return count
}
```**Go 特定注释：** Go 需要显式创建地图以进行坐标压缩。 使用切片而不是数组进行动态大小处理。 应用整数模以避免溢出。
