[LeetCode 问题 2086](https://leetcode.com/problems/minimum-number-of-food-buckets-to-feed-the-hamsters/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划、贪心

 ## 解决方案

 ## 问题理解

 问题是要求我们将最少数量的食物桶放置在单元格线性排列的空白空间上，以便所有仓鼠都能吃饱。 字符串中的每个单元格`hamsters`代表一只仓鼠 (`'H'`）或空位（`'.'`）。 如果仓鼠旁边至少有一个食物桶（无论是在仓鼠的左边还是右边），它就可以吃东西。 我们被要求确定**所需的最小桶数**或返回`-1`如果不可能喂养所有仓鼠。 

输入字符串长度可达`10^5`，因此任何比线性时间更差的方法都可能太慢。 关键的挑战是决定**在哪里放置水桶最佳**，因为不假思索地贪婪地放置它们可能会导致仓鼠无法进食。 

边缘情况包括具有连续仓鼠的字符串、没有空白的字符串、边缘有单个仓鼠以及具有所有空白点的字符串。 

## 方法

 暴力方法将尝试**存储桶放置的所有组合**。 对于每个空单元格，我们可以考虑是否放置一个桶，然后检查是否所有仓鼠都被喂饱了。 虽然这保证了正确性，但在计算上是不可行的，因为组合的数量随着空点的数量呈指数增长。 

最佳方法依赖于**贪婪放置**。 观察结果是，将一个桶**放在仓鼠的右侧**通常会更好，因为它可以同时喂养当前的仓鼠和下一只仓鼠（如果它们是连续的）。 如果右侧单元格不为空，我们将桶放在左侧。 如果两边都不空，就不可能喂食。 这种贪婪策略确保了最小的桶和字符串的线性遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试桶放置的所有组合，对于 n 达到 10^5 不可行 |
 | 最优贪心 | O(n) | O(1) | O(1) | 线性扫描以最佳方式放置桶来喂养仓鼠，最小化额外空间 |

 ## 算法演练

 1.初始化一个计数器`buckets`为 0 以跟踪放置的桶数。 如果需要，将字符串转换为列表以实现可变性。 
2.使用索引从左到右遍历字符串`i`。 
3.在某个位置遇到仓鼠时`i`，检查它是否已经与一个桶相邻（我们可以用`'B'`或跟踪位置）。 如果是，则继续下一个索引。 
4. 如果仓鼠还没有喂食，请尝试在其右侧放置一个桶（`i+1`) 如果该索引存在并且为空。 标记桶和增量`buckets`。 跳过`i+1`在下一次迭代中，因为该单元现在包含一个存储桶。 
5. 如果无法放置在右侧，请尝试将水桶放置在左侧（`i-1`）如果为空。 标记桶和增量`buckets`。 
6. 如果两边都不为空或有效，则返回`-1`因为仓鼠不能喂食。 
7. 继续直到字符串末尾。 返回`buckets`。 

为什么有效：贪婪选择总是将一个桶放置在可以连续喂食尽可能多的仓鼠的位置，以确保总数量最少。 每只仓鼠只被考虑一次，我们只在需要时才放置水桶。 

## Python 解决方案```python
class Solution:
    def minimumBuckets(self, hamsters: str) -> int:
        buckets = 0
        hamsters = list(hamsters)
        n = len(hamsters)
        i = 0
        
        while i < n:
            if hamsters[i] == 'H':
                if i + 1 < n and hamsters[i + 1] == '.':
                    buckets += 1
                    hamsters[i + 1] = 'B'
                    i += 2
                elif i - 1 >= 0 and hamsters[i - 1] == '.':
                    buckets += 1
                    hamsters[i - 1] = 'B'
                    i += 1
                else:
                    return -1
            else:
                i += 1
        
        return buckets
```该实现将字符串转换为列表，以允许使用标记放置的存储桶`'B'`。 我们从左到右扫描，如果可能的话，将桶放在右侧，否则放在左侧。 如果两者都不可能，我们返回`-1`。 放置桶后跳过索引可确保我们不会重复计算。 

## 解决方案```go
func minimumBuckets(hamsters string) int {
    buckets := 0
    n := len(hamsters)
    hamstersArr := []rune(hamsters)
    
    for i := 0; i < n; i++ {
        if hamstersArr[i] == 'H' {
            if i+1 < n && hamstersArr[i+1] == '.' {
                buckets++
                hamstersArr[i+1] = 'B'
                i++ 
            } else if i-1 >= 0 && hamstersArr[i-1] == '.' {
                buckets++
                hamstersArr[i-1] = 'B'
            } else {
                return -1
            }
        }
    }
    
    return buckets
}
```Go 版本镜像了 Python 解决方案，使用`rune`切片以允许突变。 索引处理和贪婪放置逻辑是相同的。

 ## 边缘情况

 第一个边缘情况是**单个仓鼠，没有相邻的空单元格**。 算法正确返回`-1`因为左桶和右桶都不可能放置。 

第二个边缘情况是**连续仓鼠**。 如果连续有两只或更多仓鼠，且它们之间没有空白空间，则算法会检测到不可能性，因为单个桶无法同时喂食两只仓鼠。 

第三种边缘情况是**仓鼠位于字符串边界**。 对于索引处的仓鼠`0`，只有右侧可以放置桶。 在索引处`n-1`，只有左侧可用。 该实现在放置存储桶之前正确检查数组边界。
