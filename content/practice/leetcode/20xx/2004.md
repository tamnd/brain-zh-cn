[LeetCode 2004 题](https://leetcode.com/problems/the-number-of-seniors-and-juniors-to-join-the-company/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 这个问题需要确定一家公司在固定预算下可以雇用多少名高级和初级候选人`$70000`，遵循严格的优先顺序：首先雇用尽可能多的高级人员，然后使用剩余的预算雇用初级人员。 输入是一个表`Candidates`含有`employee_id`（唯一标识符），`experience`（“高级”或“初级”），以及`salary`（月薪）。 输出应该是一个表格，显示根据优先级和预算限制可以雇用多少高级和初级人员。 

约束表明每个候选人都有正整数工资，并且经验保证为“高级”或“初级”。 重要的边缘情况包括所有高级人员的费用都太昂贵，或者预算允许只雇用部分候选人的情况。 该问题保证不会出现负工资，并且所有员工 ID 都是唯一的。 

## 方法

 暴力方法会尝试枚举所有可能的高级人员和初级人员的组合，以检查哪种组合可以最大限度地提高高级人员的第一和初级人员的第二，将他们的工资相加，看看他们是否符合预算。 虽然这种方法是正确的，但效率很低，因为它随着候选者数量呈指数增长，并且对于问题约束来说是不必要的。 

最佳解决方案的关键是通过按工资对每个组进行排序来分别处理高级人员和初级人员。 通过排序，我们可以依次选择工资最低的老年人，最大限度地增加符合预算的老年人数量。 雇用高级人员后，我们可以使用剩余的预算为初级人员重复此过程。 这种贪婪的方法确保我们总是雇佣最多数量的高级人员，然后是初级人员，而不会探索不必要的组合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 检查高级人员和初级人员的所有组合，以找到预算范围内的最大雇用人数 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 按薪资对前辈和后辈分别进行排序，利用贪婪积累来最大化招聘人数 |

 ## 算法演练

 1. 通过扫描为高级和初级初始化两个单独的列表`Candidates`表格并根据`experience`柱子。 
2. 按工资升序对两个列表进行排序。 排序可确保首先考虑最便宜的候选人，从而最大限度地增加雇用数量。 
3. 为已接受的高年级和初级学生初始化两个计数器，并为剩余预算初始化一个变量，起始于`$70000`。 
4. 迭代已排序的高级列表。 对于每个老年人，检查他们的工资是否小于或等于剩余预算。 如果是这样，请从预算中减去他们的工资并增加高级计数器。 当无法负担下一位高级人员时就停止。 
5. 使用剩余预算对初级组重复此过程。 这确保了在最大限度地雇用高级人员后，剩余的预算可以最佳地用于雇用初级人员。 
6. 返回一张表格，其中包含已录取的高年级学生和低年级学生的人数。 行的顺序并不重要。 

为什么有效：按薪水对候选人进行排序，并首先挑选成本最低的候选人，可以保证雇用尽可能多的高年级学生。 同样的逻辑也适用于高级选拔后的初级球员。 这是一种经典的贪婪策略，它之所以有效，是因为问题约束允许每个组内进行独立选择，并且没有附加条件将高级人员和初级人员的聘用联系起来。 

## Python 解决方案```python
class Solution:
    def numberOfSeniorAndJunior(self, candidates: list[dict]) -> list[dict]:
        BUDGET = 70000
        seniors = []
        juniors = []
        
        for c in candidates:
            if c['experience'] == 'Senior':
                seniors.append(c['salary'])
            else:
                juniors.append(c['salary'])
        
        seniors.sort()
        juniors.sort()
        
        accepted_seniors = 0
        accepted_juniors = 0
        remaining_budget = BUDGET
        
        for salary in seniors:
            if salary <= remaining_budget:
                remaining_budget -= salary
                accepted_seniors += 1
            else:
                break
        
        for salary in juniors:
            if salary <= remaining_budget:
                remaining_budget -= salary
                accepted_juniors += 1
            else:
                break
        
        return [
            {'experience': 'Senior', 'accepted_candidates': accepted_seniors},
            {'experience': 'Junior', 'accepted_candidates': accepted_juniors}
        ]
```该实现首先将候选人分成两个列表，按薪水对他们进行排序，然后贪婪地从每组中挑选成本最低的候选人，直到预算用完。 计数器跟踪雇佣人数，剩余预算确保我们永远不会超出限制。 

## 解决方案```go
func numberOfSeniorAndJunior(candidates []map[string]interface{}) []map[string]int {
    const BUDGET = 70000
    seniors := []int{}
    juniors := []int{}
    
    for _, c := range candidates {
        experience := c["experience"].(string)
        salary := c["salary"].(int)
        if experience == "Senior" {
            seniors = append(seniors, salary)
        } else {
            juniors = append(juniors, salary)
        }
    }
    
    sort.Ints(seniors)
    sort.Ints(juniors)
    
    acceptedSeniors := 0
    acceptedJuniors := 0
    remainingBudget := BUDGET
    
    for _, salary := range seniors {
        if salary <= remainingBudget {
            remainingBudget -= salary
            acceptedSeniors++
        } else {
            break
        }
    }
    
    for _, salary := range juniors {
        if salary <= remainingBudget {
            remainingBudget -= salary
            acceptedJuniors++
        } else {
            break
        }
    }
    
    return []map[string]int{
        {"experience": "Senior", "accepted_candidates": acceptedSeniors},
        {"experience": "Junior", "accepted_candidates": acceptedJuniors},
    }
}
```Go 的实现与 Python 非常相似。 我们处理类型断言`map[string]interface{}`并使用切片。 排序是使用标准库完成的，整数处理预算计算。 

## 工作示例

 示例 1：预算 $70000，候选人 [Senior 20000、Senior 20000、Senior 50000、Junior 10000、Junior 10000、Junior 40000]

 - 对老年人进行排序：[20000, 20000, 50000]
 - 雇用老年人：第一个20000 -> 预算50000，第二个20000 -> 预算30000，第三个50000 -> 不能雇用
 - 对青少年进行排序：[10000, 10000, 40000]
 - 聘用初级员工：第一名 10000 -> 预算 20000，第二名 10000 -> 预算 10000，第三名 40000 -> 无法聘用
 - 输出：高级 2、初级 2

 示例2：预算$70000，候选人[高级80000，高级80000，高级80000，初级10000，初级10000，初级40000]

 - 对老年人进行排序：[80000, 80000, 80000]，不能雇用任何
 - 对初级人员进行排序：[10000, 10000, 40000]，雇用所有三个 -> 预算 70000 - 60000 = 10000
 - 输出：高级 0，初级 3

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log n) | O(n log n) | 对高年级和低年级进行排序主导时间复杂度，其中 n 是候选人总数 |
 | 空间| O(n) | 为高年级和低年级创建了两个单独的列表|

 排序可确保最佳候选选择，并且对每个排序列表的贪婪传递是线性的。
