[LeetCode 问题 2060](https://leetcode.com/problems/check-if-an-original-string-exists-given-two-encoded-strings/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 问题是要求我们确定是否存在一个**单个原始字符串**可以被编码成两个不同的给定字符串，`s1`和`s2`。 每个编码字符串可能包含字母和数字。 编码字符串中的数字表示原始字符串中某些子字符串的长度，而字母表示原始字符串中的文字字符。 

输入由两个字符串组成`s1`和`s2`长度最多为40，每个字符串包含小写字母和数字`1-9`。 连续数字最多为 3 个，这意味着代表长度的数字范围为 1 到 999。预期输出是一个布尔值：`true`如果存在可以编码为两者的原始字符串`s1`和`s2`， 和`false`否则。 

要点和边缘情况：

 - 编码字符串中的数字可以表示原始字符串中的**任何连续子字符串长度**。 
- 字母必须与原始字符串中相应位置完全匹配。 
- 最多 3 位的连续数字意味着我们可能需要解释多位数字（例如，`"12"`如长度 12)。 
- 生成所有可能的解码字符串的简单解决方案将发生组合爆炸。 

要考虑的边缘情况：

 - 仅由字母组成的编码字符串应完全匹配。 
- 仅包含数字的编码字符串可以代表各种原始字符串。 
- 前导字符不匹配（例如，`s1 = "a5b"`,`s2 = "c5b"`）应该返回`false`。 

## 方法

 **蛮力：**人们可以尝试从生成所有可能的原始字符串`s1`和`s2`通过将每个数字段扩展为该长度的所有可能的子字符串，然后检查交集。 虽然正确，但组合爆炸使得这种方法不可行，因为长度为 40 的字符串可以产生天文数字的可能原始字符串，特别是当编码字符串中的数字可以表示多个子字符串长度时。 

**最佳方法：**关键的见解是使用**动态编程**将问题视为**带有记忆**的状态空间搜索。 我们不需要显式生成所有原始字符串。 相反，我们跟踪位置`s1`和`s2`以及一个**差异计数器**，它表示由于一个字符串中的数字与另一个字符串中的数字而剩下多少额外的字符需要匹配。 这将问题简化为探索 3D 状态空间：`dfs(i, j, diff)`， 在哪里`i`的位置是`s1`,`j`的位置是`s2`， 和`diff`是待处理数字段之间的长度差。 记忆化避免了重叠子问题的重新计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O（？） | O（？） | 枚举 s1 和 s2 的所有已解码原始字符串，然后检查交集。 由于组合爆炸而不可行。 |
 | 最佳 | O(L1 * L2 * D) | O(L1 * L2 * D) | 具有记忆功能的 DFS，其中 L1 和 L2 是字符串长度，D 是可能的长度差异范围。 对于长度不超过 40 的字符串有效。 

## 算法演练

 1.定义递归DFS函数`dfs(i, j, diff)`在哪里`i`是索引`s1`,`j`是索引`s2`， 和`diff`是待定长度差（如果为正值`s1`有额外的字母要匹配，如果为负`s2`有额外的字母要匹配）。 
2. **基本情况：** 如果两者都`i`和`j`已经到了琴弦的末端并且`diff`为零，返回`true`。 这表明两个编码字符串可以表示相同的原始字符串。 
3. 如果当前状态`(i, j, diff)`已经访问过，则返回存储的结果以避免重新计算。 
4. **数值扩展：** 如果`s1[i]`或者`s2[j]`是一个数字，尝试扩展由最多三个连续数字组成的所有数字，更新`diff`因此。 为了`s1`， 增加`diff`; 为了`s2`， 减少`diff`。 
5. **字母匹配：** 如果`diff`为零并且两者`s1[i]`和`s2[j]`是字母，它们必须完全匹配。 如果匹配，则递归调用`dfs(i+1, j+1, diff)`。 
6. **消耗差异：** 如果`diff`是正数，我们可以使用其中的一个字符`s2`不动`i`。 如果`diff`是负数，我们可以使用其中的一个字符`s1`不动`j`。 调整`diff`因此。 
7. 使用记忆法存储结果`(i, j, diff)`以避免重新计算。 

**为什么有效：**`diff`变量捕获由于数字编码而导致的要匹配的字母数量之间的不平衡。 通过利用记忆递归地探索所有有效的数字扩展和字母匹配，我们有效地遍历了所有可行的方法`s1`和`s2`可以对应于一个公共的原始字符串，而无需显式生成它们。 

## Python 解决方案```python
from functools import lru_cache

class Solution:
    def possiblyEquals(self, s1: str, s2: str) -> bool:
        n1, n2 = len(s1), len(s2)

        @lru_cache(None)
        def dfs(i, j, diff):
            if i == n1 and j == n2:
                return diff == 0

            # s1 digit expansion
            if i < n1 and s1[i].isdigit():
                num = 0
                for k in range(i, min(i+3, n1)):
                    if s1[k].isdigit():
                        num = num * 10 + int(s1[k])
                        if dfs(k+1, j, diff + num):
                            return True
                    else:
                        break

            # s2 digit expansion
            if j < n2 and s2[j].isdigit():
                num = 0
                for k in range(j, min(j+3, n2)):
                    if s2[k].isdigit():
                        num = num * 10 + int(s2[k])
                        if dfs(i, k+1, diff - num):
                            return True
                    else:
                        break

            # matching letters
            if diff == 0 and i < n1 and j < n2 and s1[i] == s2[j]:
                if dfs(i+1, j+1, diff):
                    return True

            # consume differences
            if diff > 0 and j < n2:
                if dfs(i, j+1, diff - 1):
                    return True
            if diff < 0 and i < n1:
                if dfs(i+1, j, diff + 1):
                    return True

            return False

        return dfs(0, 0, 0)
```此 Python 实现使用带有记忆功能的递归 DFS。 关键部分是两个字符串的数字扩展循环，仅在以下情况下处理字母匹配`diff`为零，并且消耗`diff`当一个字符串有额外的字母需要解释时，就会出现不平衡。 这`lru_cache`确保重复状态被计算一次，从而显着降低复杂性。
