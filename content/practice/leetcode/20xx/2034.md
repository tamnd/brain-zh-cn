## 问题理解

 该问题提出了**股票价格记录流**，其中每条记录都包含一个`timestamp`和一个`price`。 但是，不保证该流按时间顺序排列，并且某些记录可能会更正同一时间戳以前的错误价格。 

我们的任务是设计一个`StockPrice`有效支持的类：

 1. **更新**某个时间戳的价格（这可能会纠正以前的数据）。 
2. **查询最新价格**（时间戳最大的价格）。 
3. **查询当前所有记录中的最高价格**。 
4. **查询当前所有记录中的最低价格**。 

输入约束表明时间戳和价格可以达到$10^9$并且最多可以有$10^5$更新或查询。 这可以防止对每个查询进行简单的线性扫描，因为这可能会导致$O(n^2)$最坏情况下的行为。 

主要观察结果：

 - 我们必须**跟踪每个时间戳的价格**才能正确处理更新。 
- 最大值和最小值的查询必须有效地反映更正。 
-`current()`需要知道任意时刻的**最大时间戳**。 

要考虑的边缘情况：

 - 更新更正之前的价格。 
- 最高或最低价格因更正而更新。 
- 迄今为止仅记录了一个时间戳。 

## 方法

 ### 蛮力

 天真的方法是存储所有`(timestamp, price)`列表或字典中的对。 

- 为了`update()`，只需插入或替换时间戳即可。 
- 为了`current()`，迭代所有时间戳以找到最大的时间戳。 
- 为了`maximum()`和`minimum()`，每次迭代所有存储的价格。 

这工作正常但效率低下。 每次查询最大值或最小值都需要$O(n)$时间，并且最多$10^5$调用，这可能导致总时间复杂度为$O(n^2)$。 

### 最佳方法

 关键的见解是**使用适当的数据结构来有效地维护当前、最大值和最小值**：

 1. 使用**哈希映射**将时间戳映射到价格，以进行恒定时间更新和更正。 
2. 单独跟踪**最新时间戳**以获取恒定时间`current()`。 
3.维护**两个堆**（优先级队列）：

 - 用于最低价格查询的**最小堆**。 
- 用于最大价格查询的**最大堆**。 
4. 将 **(价格，时间戳)** 存储在堆中。 当价格被更正时，堆可能包含陈旧的条目。 在返回最大值/最小值之前，我们**弹出陈旧条目**，直到顶部与当前时间戳到价格映射一致。 

这种方法确保`update()`是$O(\log n)$用于堆插入，以及`maximum()`,`minimum()`是$O(\log n)$由于懒惰地删除陈旧条目而摊销。`current()`是$O(1)$。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(n) | O(n) | 存储简单； 查询迭代所有记录 |
 | 最佳| 每次更新/查询 O(log n) | O(n) | 使用哈希映射 + 最小/最大堆来提高效率和延迟删除 |

 ## 算法演练

 1. **初始化数据结构**：

 创建字典`timestamp_to_price`存储每个时间戳的最新价格。 初始化`latest_timestamp`为 0。使用`min_heap`和`max_heap`以维持价格。 
2. **更新操作**：

 - 更新`timestamp_to_price[timestamp] = price`。 
- 更新`latest_timestamp = max(latest_timestamp, timestamp)`。 
- 推`(price, timestamp)`到`min_heap`。 
- 推`(-price, timestamp)`到`max_heap`（否定最大堆模拟的价格）。 
3. **当前操作**：

 - 返回`timestamp_to_price[latest_timestamp]`。 
4. **最大运行**：

 - 虽然`max_heap[0]`已过时（顶部时间戳的价格！=存储的价格），将其弹出。 
- 返回`-max_heap[0][0]`。 
5. **最低限度操作**：

 - 虽然`min_heap[0]`已过时（顶部时间戳的价格！=存储的价格），将其弹出。 
- 返回`min_heap[0][0]`。 

**为什么有效**：堆允许有效检索最小值/最大值，而哈希映射则确保即使条目过时也能保持正确性。 延迟删除可确保更正的条目不会影响结果，并且始终跟踪最新的时间戳`current()`。 

## Python 解决方案```python
import heapq

class StockPrice:

    def __init__(self):
        self.timestamp_to_price = {}
        self.latest_timestamp = 0
        self.min_heap = []
        self.max_heap = []

    def update(self, timestamp: int, price: int) -> None:
        self.timestamp_to_price[timestamp] = price
        self.latest_timestamp = max(self.latest_timestamp, timestamp)
        heapq.heappush(self.min_heap, (price, timestamp))
        heapq.heappush(self.max_heap, (-price, timestamp))

    def current(self) -> int:
        return self.timestamp_to_price[self.latest_timestamp]

    def maximum(self) -> int:
        while True:
            price, timestamp = self.max_heap[0]
            if -price == self.timestamp_to_price[timestamp]:
                return -price
            heapq.heappop(self.max_heap)

    def minimum(self) -> int:
        while True:
            price, timestamp = self.min_heap[0]
            if price == self.timestamp_to_price[timestamp]:
                return price
            heapq.heappop(self.min_heap)
```**实施说明**：

 -`min_heap`商店`(price, timestamp)`自然。 
-`max_heap`商店`(-price, timestamp)`模拟最大堆。 
- 延迟删除可以有效地处理更正后的价格。 

## 解决方案```go
package main

import (
    "container/heap"
)

type PriceTimestamp struct {
    price, timestamp int
}

type MinHeap []PriceTimestamp
func (h MinHeap) Len() int { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].price < h[j].price }
func (h MinHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any) { *h = append(*h, x.(PriceTimestamp)) }
func (h *MinHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

type MaxHeap []PriceTimestamp
func (h MaxHeap) Len() int { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i].price > h[j].price }
func (h MaxHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x any) { *h = append(*h, x.(PriceTimestamp)) }
func (h *MaxHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

type StockPrice struct {
    timestampToPrice map[int]int
    latestTimestamp  int
    minHeap          *MinHeap
    maxHeap          *MaxHeap
}

func Constructor() StockPrice {
    mh := &MinHeap{}
    hh := &MaxHeap{}
    heap.Init(mh)
    heap.Init(hh)
    return StockPrice{
        timestampToPrice: make(map[int]int),
        minHeap:          mh,
        maxHeap:          hh,
        latestTimestamp:  0,
    }
}

func (this *StockPrice) Update(timestamp int, price int) {
    this.timestampToPrice[timestamp] = price
    if timestamp > this.latestTimestamp {
        this.latestTimestamp = timestamp
    }
    heap.Push(this.minHeap, PriceTimestamp{price, timestamp})
    heap.Push(this.maxHeap, PriceTimestamp{price, timestamp})
}

func (this *StockPrice) Current() int {
    return this.timestampToPrice[this.latestTimestamp]
}

func (this *StockPrice) Maximum() int {
    for {
        top := (*this.maxHeap)[0]
        if this.timestampToPrice[top.timestamp] == top.price {
            return top.price
        }
        heap.Pop(this.maxHeap)
    }
}

func (this *StockPrice) Minimum() int {
    for {
        top := (*this.minHeap)[0]
        if this.timestampToPrice[top.timestamp] == top.price {
            return top.price
        }
        heap.Pop(this.minHeap)
    }
}
```**去注释**：

 - 分开`MinHeap`和`MaxHeap`结构体是使用实现的`container/heap`。 
- 延迟删除的处理方式与 Python 类似。 
- MaxHeap是通过反转比较逻辑来实现的。
