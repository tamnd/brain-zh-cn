[LeetCode 2027 题](https://leetcode.com/problems/minimum-moves-to-convert-string/)

 **难度：** 🟢简单
 **主题：** 字符串、贪婪

 ## 解决方案

 ## 问题理解

 问题要求我们转换一个字符串`s`仅包含字符`'X'`和`'O'`让所有的角色都变成`'O'`。 移动包括选择**三个连续的字符**并将它们转换为`'O'`。 如果一个角色已经`'O'`，它保持不变。 目标是确定实现整个字符串的转换所需的**最小移动次数**。 

输入是一个字符串`s`长度在 3 到 1000 个字符之间，这保证了我们总是有至少 3 个字符来进行移动。 输出是一个整数，表示转换所有内容所需的最少移动次数`'X'`字符进入`'O'`。 

主要观察结果包括：

 1.仅`'X'`字符需要转换。`'O'`角色不需要行动。 
2. 每一步可能最多可转化 3 个`'X'`立刻。 
3. 移动可能会重叠，因此最佳放置对于最大限度地减少移动非常重要。 
4. 要考虑的边缘情况包括已经全部存在的字符串`'O'`, 字符串仅`'X'`，和分散的字符串`'X'`那里没有三个`'X'`s 是连续的。 

了解这些要点可确保解决方案不会过度计算步数或错过步数`'X'`人物。 

## 方法

 暴力方法将尝试尝试**三字符选择的每种组合**，直到字符串完全转换为`'O'`。 这是正确的，因为最终，所有`'X'`s 将被覆盖，但它的效率非常低，可能呈指数级增长，并且对于给定的约束（最多 1000 个字符）来说是不必要的。 

更有效的解决方案的关键见解是**贪婪遍历**。 由于移动会转换三个连续的字符，因此我们可以从左到右迭代，并且每当遇到`'X'`，从该位置开始应用移动。 然后我们跳过接下来的两个字符，因为它们已经转换，确保我们不会重复计算移动。 这是有效的，因为每个`'X'`必须转换，并且最左边`'X'`确定最早可能的移动。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 尝试所有移动组合，对于 n 最多 1000 来说太慢 |
 | 最佳| O(n) | O(1) | O(1) | 贪婪地从左到右转换，跳过已处理的字符 |

 ## 算法演练

 1.初始化一个计数器`moves`到 0。这将跟踪所应用的移动次数。 
2. 开始迭代字符串`s`使用索引从左到右`i`。 
3.如果`s[i]`是`'O'`, 增量`i`减 1 并继续，因为不需要移动。 
4. 如果`s[i]`是`'X'`, 增量`moves`1，因为我们需要从这个位置开始移动。 
5. 通过递增跳过接下来的两个字符`i`乘以 3，因为当前的移动会转换`s[i]`,`s[i+1]`， 和`s[i+2]`到`'O'`。 
6. 重复步骤 3-5，直到到达字符串末尾。 
7. 返回总计`moves`作为所需的最小移动次数。 

**为什么有效：** 每个`'X'`遇到触发最多覆盖三个连续字符的移动。 通过跳过接下来的两个字符，我们确保不会计算多余的移动。 这种贪心方法保证了最少的移动次数，因为每次移动都覆盖了最大可能的范围`'X'`就在那个位置。 

## Python 解决方案```python
class Solution:
    def minimumMoves(self, s: str) -> int:
        moves = 0
        i = 0
        n = len(s)
        
        while i < n:
            if s[i] == 'X':
                moves += 1
                i += 3  # Skip next two characters as they are converted
            else:
                i += 1
        return moves
```Python 实现按照该算法一步步进行。 变量`moves`跟踪总移动次数。 我们使用以下方法迭代字符串`i`，每当我们遇到`'X'`，我们增加`moves`并跳过接下来的两个字符，因为一次移动会覆盖三个字符。 否则，我们只需继续下一个字符。 

## 解决方案```go
func minimumMoves(s string) int {
    moves := 0
    n := len(s)
    i := 0
    
    for i < n {
        if s[i] == 'X' {
            moves++
            i += 3 // Skip next two characters
        } else {
            i++
        }
    }
    return moves
}
```在 Go 中，解决方案几乎与 Python 相同。 字符串按字节索引，这里可以正常工作，因为`'X'`和`'O'`是单字节字符。 主要区别在于变量的显式声明和类型处理，但算法逻辑保持不变。

 ## 边缘情况

 **单人`'X'`在结尾或开头：** 该移动仍然涵盖三个字符，因此即使剩余的字符少于三个，单个移动也算在内。 实现处理这个问题是因为我们增加了`moves`并跳过`i += 3`与字符串长度无关。 

**所有角色`'O'`：** 无需移动。 循环递增`i`每次加 1，但是`moves`保持为零。 这可确保不会出现误报。 

**交替`'X'`和`'O'`:** 需要小心跳过以避免重复计算。 贪心方法确保我们转换最左边的`'X'`首先跳过被覆盖的角色，给出最少的动作。
