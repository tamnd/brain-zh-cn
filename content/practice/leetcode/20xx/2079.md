 ## 解决方案

 ## 问题理解

 这个问题要求我们模拟用一个固定容量的喷壶给一排植物浇水。 植物沿着直线排列，索引代表它们的位置。 你从位于位置的河流开始`x = -1`您可以在那里给喷壶加水。 每种植物都需要一定量的水，见表中给出`plants`大批。 

目标是计算在遵循浇水规则的同时浇灌所有植物所需的**总步骤**。 您必须按从左到右的顺序给植物浇水。 给植物浇水后，如果罐中剩余的水不足以浇灌下一株植物，则必须返回河中重新加满水，然后才能继续。 步数以沿 x 轴的单位距离来测量； 向左或向右移动一个位置算作一步。 这些限制确保喷壶始终足够大，可以浇灌任何单一植物（`capacity >= max(plants[i])`），所以我们永远不会遇到一株植物不能一次浇水的情况。 

输入由整数数组组成`plants`和一个整数`capacity`。 输出是一个整数，表示所需的步骤总数。 

重要的边缘情况包括拥有与罐中剩余水完全匹配的植物、拥有单一植物以及需要多次返回河流的情况。 

## 方法

 蛮力方法包括模拟沿 x 轴的每一步，为每次移动增加计数器，并跟踪剩余的水。 虽然这会给出正确的答案，但对于大型阵列和高容量来说效率很低，因为它不必要地模拟每个单独的步骤。 例如，如果容量与植物数量相比非常大，则可以在简单的每步模拟中重复计算从河流来回的移动。 

最佳解决方案的关键是**在植物级别而不是步骤级别模拟浇水**。 我们只需要跟踪罐子里的剩余水、下一个植物的位置，以及需要补充水时移回河边的成本。 如果剩余的水足够下一株植物生长，我们只需向前迈一步即可。 否则，我们计算到河流的往返距离，将其添加到步数中，重新装满罐子，然后给植物浇水。 

该模拟与植物数量成线性关系，因为每个植物都被访问一次，并且每次重新填充仅在需要时发生。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(S) 其中 S = 总步数 | O(1) | O(1) | 模拟沿 x 轴的每一步 |
 | 最佳 | O(n) | O(1) | O(1) | 在植物层面模拟浇水，仅计算植物和补充之间的步数 |

 ## 算法演练

 1. 初始化`steps`到 0 以跟踪步行的总距离。 
2. 初始化`water`到`capacity`代表罐中当前的水量。 
3. 迭代索引处的每个工厂`i`在`plants`。 
4. 检查是否`water`小于`plants[i]`。 如果是，则需要补充：

 - 添加`(i * 2)`到`steps`考虑步行回到河边然后返回当前工厂。`i`是从河流到当前工厂的距离。 
- 重置`water`到`capacity`。 
5.通过减少浇水当前植物`plants[i]`从`water`。 
6. 增量`steps`加 1 以说明从之前的位置移动到该工厂。 
7.迭代结束后，返回`steps`作为总步数。 

**为什么有效：** 该算法保持了不变式，即在给植物浇水之前，我们总是有足够的水。 这`steps`计数器准确地累积位置和补充之间移动的距离。 由于植物是按顺序浇水的，并且仅在必要时才进行补充，因此总步骤数最少且正确。 

## Python 解决方案```python
from typing import List

class Solution:
    def wateringPlants(self, plants: List[int], capacity: int) -> int:
        steps = 0
        water = capacity
        for i, need in enumerate(plants):
            if water < need:
                steps += i * 2
                water = capacity
            water -= need
            steps += 1
        return steps
```实现直接遵循算法。 我们初始化步数计数器和水位。 对于每个植物，我们检查是否需要补充，更新往返的步数，补充，减去植物所需的水，并增加前进的步数。 决赛`steps`值给出了所采取的总步数。 

## 解决方案```go
func wateringPlants(plants []int, capacity int) int {
    steps := 0
    water := capacity
    for i, need := range plants {
        if water < need {
            steps += i * 2
            water = capacity
        }
        water -= need
        steps += 1
    }
    return steps
}
```Go 的实现与 Python 版本非常相似。`steps`和`water`被初始化，我们迭代`plants`切片与`range`。 再填充条件、水减去和步进增量逻辑是相同的。 Go 原生处理整数运算，无需对溢出进行特殊处理，因为约束确保值保持可管理性。
