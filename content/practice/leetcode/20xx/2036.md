[LeetCode 2036 题](https://leetcode.com/problems/maximum-alternating-subarray-sum/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组的**最大交替子数组和**。 **子数组**是数组中任何连续的元素序列。 子数组的**交替和**是通过交替添加和减去元素来计算的：从第一个元素的加号开始，然后为下一个元素减号，为后面的元素加号，依此类推。 

例如，对于一个子数组`[a, b, c, d]`，交替和是`a - b + c - d`。 我们的目标是在所有可能的非空子数组中找到最大化交替总和的子数组。 

输入是长度可达的整数列表`10^5`，每个元素的范围可以是`-10^5`到`10^5`。 这意味着任何复杂性比以下更差的解决方案`O(n)`或者`O(n log n)`不太可能有效运行，因此对所有子数组进行暴力枚举（这将是`O(n^2)`或者`O(n^3)`取决于实施）太慢了。 

重要的边缘情况包括：

 - 仅包含一个元素的数组（结果是该元素本身）。 
- 所有元素都相等的数组（交替总和可能不会超过第一个元素）。 
- 具有负数和零的数组，这可能会影响在某个点开始或结束子数组是否更好。 

## 方法

 **暴力方法**：暴力方法是考虑所有可能的子数组，计算它们的交替和，并跟踪最大值。 这种方法保证有效，因为它确实评估了每个选项，但复杂性是`O(n^2)`用于生成子数组和`O(n)`将每一项相加，得出总体`O(n^3)`，这对于`n = 10^5`。 

**最佳方法**：关键的观察结果是交替和可以解释为**最大子数组和**问题（Kadane 算法）的变体，不同之处在于符号交替。 我们可以在迭代数组时维护两个变量：一个代表最大交替和**如果下一个元素添加为正数**，另一个代表**如果下一个元素添加为负数**。 在每一步中，我们都会使用当前元素更新这两个值并跟踪全局最大值。 这将问题简化为**线性时间 O(n)** 和**恒定空间 O(1)**。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 迭代所有子数组并计算交替和 |
 | 最佳 | O(n) | O(1) | O(1) | 使用具有两种运行状态的动态规划来跟踪正负交替 |

 ## 算法演练

 1.初始化两个变量：`even`表示如果下一个元素被正向添加，则最大交替和，并且`odd`表示下一个元素加负数时的最大交替和。 最初，`even = nums[0]`和`odd = 0`。 
2. 初始化变量`max_sum`跟踪全局最大交替和。 开始于`max_sum = nums[0]`。 
3. 从第二个元素到末尾迭代数组。 
4. 对于每个元素`num`， 更新`even`和`odd`如下：

 -`even_new = max(even, odd + num)`; 要么继续正交替，要么使用负状态开始新的序列。 
-`odd_new = max(odd, even - num)`; 要么继续负交替，要么从正状态切换。 
5. 更新`even`和`odd`到新计算的值。 
6. 更新`max_sum`和`even`因为总和以正项开头，所以`even`始终表示有效的子数组和。 
7. 迭代完所有元素后，`max_sum`包含最大交替子数组和。 

**为什么有效**：通过跟踪两个交替状态（`even`和`odd`），我们确保在每个位置，如果我们添加带有正号或负号的当前元素，我们就知道在那里结束的最大总和。 这是一种经典的动态规划技术，其中状态捕获所有必要的信息以做出最佳选择。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumAlternatingSubarraySum(self, nums: List[int]) -> int:
        even = nums[0]  # max alternating sum starting with positive
        odd = 0         # max alternating sum starting with negative
        max_sum = nums[0]
        
        for num in nums[1:]:
            new_even = max(even, odd + num)
            new_odd = max(odd, even - num)
            even, odd = new_even, new_odd
            max_sum = max(max_sum, even)
        
        return max_sum
```Python 实现反映了该算法。`even`如果下一个元素为正，则跟踪最大和，`odd`如果为负数。 在每次迭代中，我们计算新状态并更新全局最大值。 这确保我们永远不会丢失在任何点结束的最佳子数组。 

## 解决方案```go
func maximumAlternatingSubarraySum(nums []int) int64 {
    even := int64(nums[0])
    odd := int64(0)
    maxSum := even

    for i := 1; i < len(nums); i++ {
        num := int64(nums[i])
        newEven := max(even, odd + num)
        newOdd := max(odd, even - num)
        even, odd = newEven, newOdd
        maxSum = max(maxSum, even)
    }

    return maxSum
}

func max(a, b int64) int64 {
    if a > b {
        return a
    }
    return b
}
```在 Go 中，我们需要处理`int64`因为如果输入很大，交替和可能会超出 32 位整数范围。 其他方面的逻辑与 Python 相同，具有显式辅助函数`max`。

 | 3 | 2 | 最大 (5, 4 + 2) = 6 | 最大(4, 5 - 2) = 4 | 6 |

 最大交替子数组和为`5`对于子数组`[3, -1, 1]`。

 | 空间| O(1) | O(1) | 仅使用恒定空间来跟踪`even`,`odd`， 和`max_sum`。 |
