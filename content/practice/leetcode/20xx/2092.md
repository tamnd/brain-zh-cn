[LeetCode 问题 2092](https://leetcode.com/problems/find-all-people-with-secret/)

 **难度：** 🔴难
 **主题：** 深度优先搜索、广度优先搜索、并查、图论、排序

 ## 解决方案

 ## 问题理解

 该问题描述了在不同时间见面的人的网络。 每当一个已经知道秘密的人参加会议时，他们会立即与其他参与者分享该秘密。 关键细节是共享是在同一时间戳内即时进行的。 这意味着如果有人在会议期间得知了这个秘密`t`，他们可以立即在同样发生的另一次会议中传递它`t`。 

我们得到：

 -`n`，标记的总人数`0`到`n - 1`-`meetings`，其中每个条目是`[x, y, time]`-`firstPerson`，直接从人那里得知秘密的人`0`在某个时间`0`最初：

 - 人`0`知道秘密
 - 人`firstPerson`也知道这个秘密，因为人`0`及时告诉他们`0`我们必须确定在所有会议结束后最终得知秘密的每个人。 

主要挑战来自同时举行的会议。 考虑同一时间戳的这个序列：```
1 meets 2
2 meets 3
3 meets 4
```如果人`1`最初知道秘密，然后在同一时间戳内：

 -`1`告诉`2`-`2`立即告诉`3`-`3`立即告诉`4`所以四个人最终在同一时间段内知道了这个秘密。 

限制条件很大：

 - 最多`10^5`人
 - 最多`10^5`会议

 这立即排除了在所有会议中重复传播秘密的天真的重复模拟方法。 

一些边缘情况很重要：

 - 多个会议在同一时间举行
 - 断开连接的会议组
 - 同一时间戳内的循环
 - 参加多个同时会议的人员
 - 参与者都不知道秘密的会议
 - 传播链完全在一个时间戳内

 该问题保证有效的会议数据和每次会议的不同参与者。 

## 方法

 ### 蛮力方法

 强力解决方案将按时间顺序重复扫描所有会议，并不断传播秘密，直到不再发生任何变化。 

对于每个时间戳：

 1. 迭代当时的所有会议。 
2. 如果任何一个参与者知道这个秘密，就把它告诉另一个。 
3. 由于同一时间戳内的传播是瞬时的，因此请重复扫描，直到没有新人知道该秘密。 

这种方法是正确的，因为最终时间戳内所有可到达的人都会收到该秘密。 

然而，它太慢了。 在最坏的情况下，每个时间戳可能需要重复重新扫描许多会议。 高达`10^5`会议中，重复传播变得昂贵并且可能退化为二次行为。 

### 关键见解

 重要的观察结果是，同时举行的会议形成临时通信图。 

在一个时间戳内：

 - 每个连接的组件都表现为一个完全传播的网络
 - 如果该连接组件中的任何人已经知道该秘密，则整个组件都会了解该秘密

 这将问题转化为：

 1. 按时间分组处理会议
 2. 为该时间戳构建连接组件
 3. 检查每个组件是否包含已经知道秘密的人
 4. 如果是，则该组件中的每个人都知道这个秘密

 并查数据结构非常适合此目的，因为：

 - 它有效地对连接的参与者进行分组
 - 支持接近恒定时间的合并和查找
 - 我们可以独立处理每个时间戳

 微妙之处在于连接仅在一个时间戳期间暂时存在。 因此，在处理完一个时间组后，我们必须重置未获得秘密的组件。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |

 在哪里`m = len(meetings)`。 

## 算法演练

 ### 第 1 步：按时间对会议进行排序

 我们首先按时间戳对所有会议进行排序。 

这可确保会议按时间顺序进行，因为秘密无法及时回溯。```
meetings.sort(key=lambda x: x[2])
```### 步骤 2：初始化并查

 我们为所有人创建并查结构`n`人们。 

最初：

 - 人`0`知道秘密
 - 人`firstPerson`也知道这个秘密

 我们立即在 Union-Find 中将它们连接起来。 

这意味着与此人有联系的任何人`0`就被认为知道这个秘密。 

### 步骤 3：按时间段处理会议

 具有相同时间戳的会议必须一起处理，因为同一时间内的传播是瞬时的。 

对于每个时间戳：

 1. 收集当时发生的所有会议
 2. 联合所有会议参与者
 3.记录该时间戳内所有涉及的人员

 ### 步骤 4：确定哪些组件获得秘密

 当前时间戳的所有并集完成后：

 - 任何与人相关的参与者`0`知道秘密
 - 整个连接的组件同时获得秘密

 ### 步骤 5：在没有秘密的情况下重置组件

 这是最重要的一步。 

有些人可能会在此时间戳期间建立联系，但仍然无法联系到人`0`。 

这些临时连接不得持续到未来的时间戳。 

对于当前时间戳涉及的每个参与者：

 - 如果他们与人没有联系`0`- 将父母重置为自己

 这将删除无效的临时连接。 

### 第 6 步：继续，直到处理完所有会议

 对每个时间戳重复相同的过程。 

### 第 7 步：收集最终答案

 最后：

 - 每个人都与人相连`0`知道秘密

 将这样的人全部归还。 

## 为什么它有效

 在每个时间戳，Union-Find 都会正确地将在该时间段内可以即时通信的所有人员分组。 如果连接组件的任何成员已经知道该秘密，则该秘密将在整个组件中传播。 重置从不与人连接的组件`0`确保临时通信链接不会错误地保留到未来的时间戳中。 因此，在处理所有时间戳之后，通过有效的时间顺序传播可到达的人仍然与人保持连接`0`。 

## Python 解决方案```python
from typing import List

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> None:
        root_x = self.find(x)
        root_y = self.find(y)

        if root_x == root_y:
            return

        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1

    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)

    def reset(self, x: int) -> None:
        self.parent[x] = x

class Solution:
    def findAllPeople(self, n: int, meetings: List[List[int]], firstPerson: int) -> List[int]:
        meetings.sort(key=lambda x: x[2])

        uf = UnionFind(n)
        uf.union(0, firstPerson)

        i = 0
        total_meetings = len(meetings)

        while i < total_meetings:
            current_time = meetings[i][2]
            participants = set()

            j = i

            while j < total_meetings and meetings[j][2] == current_time:
                x, y, _ = meetings[j]

                uf.union(x, y)

                participants.add(x)
                participants.add(y)

                j += 1

            for person in participants:
                if not uf.connected(person, 0):
                    uf.reset(person)

            i = j

        result = []

        for person in range(n):
            if uf.connected(person, 0):
                result.append(person)

        return result
```实施首先按时间顺序对会议进行排序。 这保证了信息仅及时向前流动。 

这`UnionFind`类有效地管理连接的组件。 路径压缩在`find()`并按等级联合`union()`保持操作时间几乎恒定。 

该算法在检查连接性之前将同一时间戳内的所有参与者联合起来。 这是至关重要的，因为时间戳内的秘密共享是瞬时的，并且可能需要多步传播。 

这`participants`设置记录当前时间戳期间涉及的每个人。 所有联合完成后，我们检查每个参与者：

 - 如果他们与人有联系`0`，他们永久保守秘密
 - 否则，它们的临时时间戳连接将被删除`reset()`最后，每个人都与人建立了联系`0`被返回。 

## 解决方案```go
package main

import (
	"sort"
)

type UnionFind struct {
	parent []int
	rank   []int
}

func NewUnionFind(n int) *UnionFind {
	parent := make([]int, n)
	rank := make([]int, n)

	for i := 0; i < n; i++ {
		parent[i] = i
	}

	return &UnionFind{
		parent: parent,
		rank:   rank,
	}
}

func (uf *UnionFind) Find(x int) int {
	if uf.parent[x] != x {
		uf.parent[x] = uf.Find(uf.parent[x])
	}
	return uf.parent[x]
}

func (uf *UnionFind) Union(x int, y int) {
	rootX := uf.Find(x)
	rootY := uf.Find(y)

	if rootX == rootY {
		return
	}

	if uf.rank[rootX] < uf.rank[rootY] {
		uf.parent[rootX] = rootY
	} else if uf.rank[rootX] > uf.rank[rootY] {
		uf.parent[rootY] = rootX
	} else {
		uf.parent[rootY] = rootX
		uf.rank[rootX]++
	}
}

func (uf *UnionFind) Connected(x int, y int) bool {
	return uf.Find(x) == uf.Find(y)
}

func (uf *UnionFind) Reset(x int) {
	uf.parent[x] = x
}

func findAllPeople(n int, meetings [][]int, firstPerson int) []int {
	sort.Slice(meetings, func(i, j int) bool {
		return meetings[i][2] < meetings[j][2]
	})

	uf := NewUnionFind(n)
	uf.Union(0, firstPerson)

	i := 0
	totalMeetings := len(meetings)

	for i < totalMeetings {
		currentTime := meetings[i][2]
		participantsMap := make(map[int]bool)

		j := i

		for j < totalMeetings && meetings[j][2] == currentTime {
			x := meetings[j][0]
			y := meetings[j][1]

			uf.Union(x, y)

			participantsMap[x] = true
			participantsMap[y] = true

			j++
		}

		for person := range participantsMap {
			if !uf.Connected(person, 0) {
				uf.Reset(person)
			}
		}

		i = j
	}

	result := []int{}

	for person := 0; person < n; person++ {
		if uf.Connected(person, 0) {
			result = append(result, person)
		}
	}

	return result
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 Go 不提供内置集合，因此`map[int]bool`用于跟踪时间戳参与者。 切片用于父数组和等级数组。 整数溢出不是问题，因为所有值都保持在 Go 的整数限制内。

from typing import List

class Solution:
    def findAllPeople(self, n: int, meetings: List[List[int]], firstPerson: int) -> List[int]:
        parent = list(range(n))
        rank = [0] * n

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(x, y):
            rx = find(x)
            ry = find(y)

            if rx == ry:
                return

            if rank[rx] < rank[ry]:
                parent[rx] = ry
            elif rank[rx] > rank[ry]:
                parent[ry] = rx
            else:
                parent[ry] = rx
                rank[rx] += 1

        def connected(x, y):
            return find(x) == find(y)

        meetings.sort(key=lambda x: x[2])

        union(0, firstPerson)

        i = 0

        while i < len(meetings):
            t = meetings[i][2]
            participants = set()

            j = i

            while j < len(meetings) and meetings[j][2] == t:
                x, y, _ = meetings[j]

                union(x, y)

                participants.add(x)
                participants.add(y)

                j += 1

            for p in participants:
                if not connected(p, 0):
                    parent[p] = p

            i = j

        return [i for i in range(n) if connected(i, 0)]

 ## 边缘情况

 ### 同时召开多个会议

 错误的一个主要来源是无法一起处理具有相同时间戳的所有会议。 如果一一独立处理，同一时间戳内的传播链将错误地中断。 

例如：```
1 meets 2 at time 5
2 meets 3 at time 5
```如果人`1`知道这个秘密的人`3`也应该立即学习。 该实现通过在检查连接之前联合每个会议的时间戳来处理此问题。 

### 不应持续的临时连接

 另一个微妙的问题是允许断开连接的组在不同的时间戳之间保持联合。 

例如：```
1 meets 2 at time 1
2 meets 3 at time 2
```如果最初没有人知道这个秘密，那么之间的联系`1`和`2`从时间`1`不应该在某个时间保持活跃`2`。 

重置步骤可确保临时组件消失，除非它们连接到人`0`。 

### 一个时间戳内的链

 传播可以通过同一时间戳内的多个中间人进行。 

例如：```
1 meets 2
2 meets 3
3 meets 4
```全部同时进行。 

天真的顺序更新可能无法完全传播秘密。 由于算法首先构建整个连接组件，因此时间戳内可到达的每个人都可以正确接收秘密。
