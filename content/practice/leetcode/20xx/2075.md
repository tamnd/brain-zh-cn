[LeetCode 问题 2075](https://leetcode.com/problems/decode-the-slanted-ciphertext/)

 **难度：** 🟡 中等
 **主题：** 字符串、模拟

 ## 解决方案

 ## 问题理解

 该问题需要解码使用 **倾斜转置密码** 编码的字符串。 在这个密码中，原始文本被对角地写在具有固定行数的网格中。 具体来说，放置从左上角开始，以之字形方式向下和向右移动。 填充网格后，通过逐行读取网格形成编码字符串，包括未填充单元格的空格。 

输入由编码字符串组成`encodedText`和一个整数`rows`，它指定编码期间使用的行数。 预期输出是原始字符串`originalText`，没有尾随空格。 

要点包括：

 -`encodedText`可以达到`10^6`字符很长，因此低效的方法可能会超时。 
- 只出现小写字母和空格`encodedText`。 
- 总有一个唯一有效的`originalText`。 
- 边缘情况包括`rows = 1`其中字符串未更改或为空字符串。 

该任务需要从按行编码的字符串重建原始对角线读取顺序。 

重要限制：

 -`1 <= rows <= 1000`确保行数可管理。 
- 原始文本中的尾随空格被删除。 
- 编码保证网格中的最后一列非空，避免歧义。 

可能会导致幼稚方法失败的边缘情况包括单行编码、非常短的字符串或具有多个连续空格的字符串。 

## 方法

 暴力方法涉及重建编码中使用的精确网格。 这需要首先确定列数，用编码字符串逐行填充网格，然后对角读取以重建原始文本。 虽然正确，但这种方法使用`O(rows * cols)`空间，这可能会超出非常大的字符串的限制。 

最佳解决方案的关键在于我们不需要存储整个网格。 我们可以直接模拟对角线遍历，方法是迭代每行的起点，然后对角线向下和向右移动，收集字符，直到到达字符串的末尾。 这将空间复杂度降低到`O(n)`仅适用于输出字符串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(行数 * 列数) | 建立完整的网格并沿对角线阅读。 可以工作，但会占用额外的空间。 |
 | 最佳 | O(n) | O(n) | 直接模拟对角线遍历，无需存储完整网格。 |

 ## 算法演练

 1. 确定网格中的列数。 由于字符串是逐行填充的，因此列数为`len(encodedText) // rows`。 
2.初始化一个空列表来收集字符`originalText`。 
3. 迭代每一行`r`从`0`到`rows - 1`。 
4. 对于每个起始行`r`，通过将行和列增加`1`在每一步。 收集对应位置的字符`encodedText`。 
5. 继续直至到达最后一行或最后一列。 
6. 将收集到的字符连接成字符串并去除所有尾随空格。 

**为什么有效：** 该算法直接模仿编码过程中使用的对角线读取模式。 每条对角线对应于原始文本序列中的一个位置。 通过以行为起点迭代，所有对角线都被恰好覆盖一次，保证了原始文本的重建。 

## Python 解决方案```python
class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        if rows == 1:
            return encodedText.rstrip()
        
        n = len(encodedText)
        cols = n // rows
        result = []
        
        for r in range(rows):
            c = 0
            row, col = r, 0
            while row < rows and col < cols:
                idx = row * cols + col
                result.append(encodedText[idx])
                row += 1
                col += 1
        
        return ''.join(result).rstrip()
```**说明：** 代码首先处理只有一行的边缘情况。 然后，它通过将总长度除以行数来计算列数。 使用嵌套迭代，它模拟从每一行开始的对角线遍历，将字符附加到结果列表中。 最后，它将列表连接成一个字符串并删除尾随空格。 

## 解决方案```go
func decodeCiphertext(encodedText string, rows int) string {
    if rows == 1 {
        return strings.TrimRight(encodedText, " ")
    }

    n := len(encodedText)
    cols := n / rows
    result := make([]byte, 0, n)

    for r := 0; r < rows; r++ {
        row, col := r, 0
        for row < rows && col < cols {
            idx := row*cols + col
            result = append(result, encodedText[idx])
            row++
            col++
        }
    }

    return strings.TrimRight(string(result), " ")
}
```**Go 特定说明：** Go 要求将结果字节切片转换回字符串。 修剪尾随空格的使用`strings.TrimRight`。 切片用于在不知道确切的最终大小的情况下有效地附加字符，尽管容量是为了性能而预先分配的。 

## 工作示例

 **示例1：**`encodedText = "ch   ie   pr", rows = 3`- 网格大小：3行，4列（`len(encodedText)//rows`）
 - 网格模拟：

 | c0 | c1 | c2 | c3 |
 | --- | --- | --- | --- |
 | c | 小时 | | |
 | | 我| 电子| |
 | | | p| r |

 - 对角线遍历：

 1. 起始行 0：索引 (0,0),(1,1),(2,2) → "c", "i", "p"
 2. 起始行 1：索引 (1,0),(2,1) → "h", "e"
 3. 开始第 2 行：索引 (2,0) → “r”

 - 组合→“密码”

 **示例2：**`encodedText = "iveo    eed   l te   olc", rows = 4`- 列=`len(encodedText)//rows = 24//4 = 6`- 网格遍历对角重构“我爱leetcode”。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个字符在对角线遍历中只被访问一次。 |
 | 空间| O(n) | 仅存储长度为 n 的结果字符串，不需要完整的网格。 |

 最佳复杂性的关键是在不创建完整的二维矩阵的情况下模拟遍历，减少空间使用，同时仍然只访问每个字符一次。

 ## 边缘情况

 **单排（`rows = 1`)**：在这种情况下，编码不会改变字符串。 任何解决方案都必须检查此条件以避免不必要的计算。 

**空字符串**：输入可能为空，在这种情况下输出也必须为空字符串。 未经检查访问索引可能会导致错误。 

**encodedText 中的尾随空格**：在填充期间添加的编码字符串中的空格不得出现在输出中。 该解决方案使用`rstrip()`（Python）或`TrimRight`(Go) 安全地删除尾随空格，确保符合问题约束。
