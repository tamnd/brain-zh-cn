[LeetCode 问题 2078](https://leetcode.com/problems/two-furthest-houses-with- Different-colors/)

 **难度：** 🟢简单
 **主题：** 数组，贪婪

 ## 解决方案

 ## 问题理解

 问题是要求我们找到**不同颜色**的两栋房子之间的最大距离。 给你一个 0 索引的列表`colors`其中每个元素代表房子的颜色。 指数处两栋房屋之间的距离`i`和`j`定义为`abs(i - j)`- 它们的指数的绝对差。 

这里的关键是识别两栋距离尽可能远的**不同颜色**的房子。 保证数组至少有两种不同的颜色，并且数组的大小`n`范围从2到100，相对较小，但我们仍然可以优化解决方案。 

重要的边缘情况包括当第一个和最后一个房子具有相同颜色时，或者当最大距离出现在阵列的末端时。 另一个考虑因素是只有两个房屋的阵列，如果颜色不同，则最大距离通常为 1。 

## 方法

 ### 蛮力方法

 暴力方法将涉及检查**每对房屋**`(i, j)`在哪里`i < j`，并计算它们的距离（如果它们的颜色不同）。 这确保了正确性，因为我们确实检查了所有可能的对，但效率很低。 为了`n`房子，这需要`O(n^2)`比较，对于小规模来说是可以接受的`n`但当我们可以利用观察结果时就没有必要了。 

### 最佳方法

 关键的见解是**最大距离**将始终涉及阵列两端的房屋之一。 具体来说，与第一个或最后一个房子颜色不同的最远的房子将产生最大距离。 这是因为距离函数随着索引的分开而增长。 因此，我们只需将第一栋房子与从末尾开始的房子进行比较，直到找到不同的颜色为止，最后一个房子与从头开始向前的房子也是如此。 

这种方法将复杂性从二次降低到线性，`O(n)`，并且只需要恒定的额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 比较所有成对的房屋，找出不同颜色的最大距离 |
 | 最佳 | O(n) | O(1) | O(1) | 比较边缘与相对端以有效找到最大距离 |

 ## 算法演练

 1. 识别**第一所房子**的颜色（`colors[0]`）和**最后的房子**（`colors[-1]`）。 
2. 从**最后一个房子**开始向后移动，找到第一个颜色与`colors[0]`。 计算到第一所房子的距离。 
3.从**第一栋房子**开始，向前寻找第一栋颜色与`colors[-1]`。 计算到最后一个房子的距离。 
4. 返回上面计算的两个距离的**最大值**。 

**为什么有效：** 两栋不同颜色的房子之间的最远距离必须涉及其中一个端点，因为靠近中间总是会缩短距离。 通过仅从边缘检查，我们保证有效地找到最大距离。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxDistance(self, colors: List[int]) -> int:
        n = len(colors)
        first_color = colors[0]
        last_color = colors[-1]

        # Maximum distance using first house
        max_dist_from_first = 0
        for i in range(n-1, -1, -1):
            if colors[i] != first_color:
                max_dist_from_first = i
                break

        # Maximum distance using last house
        max_dist_from_last = 0
        for i in range(n):
            if colors[i] != last_color:
                max_dist_from_last = n - 1 - i
                break

        return max(max_dist_from_first, max_dist_from_last)
```Python 实现定义了两个循环：一个循环从最后一个房子向后移动以查找与第一个房子不同的颜色，一个从第一个房子向前移动以查找与最后一个房子不同的颜色。 结果是两个距离中的最大值。 

## 解决方案```go
func maxDistance(colors []int) int {
    n := len(colors)
    firstColor := colors[0]
    lastColor := colors[n-1]

    maxDistFromFirst := 0
    for i := n-1; i >= 0; i-- {
        if colors[i] != firstColor {
            maxDistFromFirst = i
            break
        }
    }

    maxDistFromLast := 0
    for i := 0; i < n; i++ {
        if colors[i] != lastColor {
            maxDistFromLast = n - 1 - i
            break
        }
    }

    if maxDistFromFirst > maxDistFromLast {
        return maxDistFromFirst
    }
    return maxDistFromLast
}
```在 Go 中，切片的使用方式与 Python 列表类似。 这些循环是等效的，并且距离计算在适当的情况下从最后一个索引中减去该索引。 Go 不需要类型提示，但使用显式索引。
