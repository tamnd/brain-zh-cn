[LeetCode 2033 题](https://leetcode.com/problems/minimum-operations-to-make-a-uni-value-grid/)

 **难度：** 🟡 中等
 **主题：** 数组、数学、排序、矩阵

 ## 解决方案

 ## 问题理解

 该问题给了我们一个二维整数矩阵，称为`grid`和一个整数`x`。 在一次操作中，我们可以添加`x`到一个单元格或减去`x`来自一个细胞。 我们的目标是使用最少的操作次数使网格中的每个值相等。 

一个关键细节是每个操作都会精确地更改一个数字`x`。 我们不能按任意值递增或递减。 例如，如果`x = 3`，那么一个值可以从`1`到`4`,`7`,`10`，等等，但它永远不可能成为`2`或者`5`。 

输出应该是将整个网格转换为单值网格所需的最少操作数。 如果在这些规则下无法使所有数字相等，我们返回`-1`。 

约束条件很重要：

 - 网格最多可以包含`10^5`总元素。 
- 每个值最多`10^4`。 
- 对每个单元格组合的所有可能目标值进行强力搜索会太慢。 

这告诉我们我们需要一个数学上有效的解决方案。 

一个重要的观察是，只有当两个数字的差能被整除时，它们才能相互转换`x`。 

例如：

 - 与`x = 2`,`2`可以成为`4`,`6`,`8`， 等等。 
- 但`2`永远不可能成为`3`因为重复的加减`2`保持奇偶校验。 

因此，在做任何其他事情之前，我们必须验证所有数字具有相同的模余数`x`。 

一些重要的边缘情况包括：

 - 只有一个元素的网格，该元素已经满足条件。 
- 数值的差异不能被整除`x`，立即给出答案`-1`。 
- 效率至关重要的大型电网。 
- 多个有效的目标值，我们必须选择一个最小化总操作的目标值。 

## 方法

 ### 蛮力方法

 一个简单的想法是尝试每个可能的目标值并计算需要多少次操作才能将所有单元格转换为该目标。 

首先，将网格展平为单个数组。 然后，对于每个候选目标：

 1. 检查每个值是否都能转换为目标值。 
2. 计算所需的操作数：$$\frac{|value - target|}{x}$$3. 保留最小总数。 

这是有效的，因为我们直接评估每个可能的最终值并选择最好的一个。 

然而，当元素数量很大时，这种方法会变得低效。 如果有`k`元素，我们尝试每个元素作为目标，复杂度变成`O(k^2)`，这对于`k = 10^5`。 

### 最佳方法

 关键的见解来自两个数学观察。 

一、可行性：

 所有数字必须具有相同的模余数`x`。 否则，就不可能将它们转化为共同的价值观。 

二、尽量减少操作：

 一旦我们将问题标准化，每个操作都会有效地将数字移动一步。 最小化总绝对距离的最佳目标是中位数。 

假设我们将所有值除以`x`从概念上讲。 那么问题就变成了最小化：$$\sum |a_i - target|$$这是一个经典的结果：中位数使绝对偏差之和最小化。 

因此，算法为：

 1.压平网格。 
2. 检查模一致性。 
3. 对数组进行排序。 
4. 选择中位数作为目标。 
5. 对所需运算求和。 

这将复杂性降低到`O(k log k)`因为排序在运行时占据主导地位。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k²) | O(k) | 尝试每一个可能的目标值 |
 | 最佳| O(k log k) | O(k log k) | O(k) | 使用模可行性检查和中值属性 |

 这里，`k = m * n`。 

## 算法演练

 1. 将 2D 网格展平为 1D 数组。 

使用单个列表可以简化排序和迭代。 由于元素的位置并不重要，只有它们的值才重要。 
2. 存储第一个值模的余数`x`。 

每个其他值必须具有相同的模余数`x`。 如果不是，就不可能使所有值相等。 
3. 迭代所有值并验证模一致性。 

对于每个值：$$value \bmod x$$必须等于第一个元素的余数。 

如果任何值未通过此检查，则立即返回`-1`。 
4. 对展平的数组进行排序。 

排序使我们可以轻松选择中值。 
5. 选择中值元素作为目标。 

如果有`k`元素，中值索引为：$$k // 2$$中位数使总绝对距离最小化。 
6. 计算总操作数。 

对于每个值：$$operations += \frac{|value - median|}{x}$$由于可行性已经得到验证，因此划分总是准确的。 
7. 返回操作总数。 

### 为什么它有效

 模条件保证在重复加法或减法的情况下所有数字属于同一个变换组`x`。 

标准化后，每个操作都会将值更改一个单位。 然后问题就变成最小化到目标值的绝对距离之和。 中位数的数学特性保证绝对偏差之和在中位数处最小，因此该策略始终产生最少的操作数。 

## Python 解决方案```python
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        values = []

        for row in grid:
            values.extend(row)

        remainder = values[0] % x

        for value in values:
            if value % x != remainder:
                return -1

        values.sort()

        median = values[len(values) // 2]

        operations = 0

        for value in values:
            operations += abs(value - median) // x

        return operations
```实现首先将网格扁平化为一个名为`values`。 这简化了后续处理，因为元素的相对位置并不重要。 

接下来，代码存储第一个值的模余数。 除以时，所有其他数字都必须共享相同的余数`x`。 如果任何值不同，函数立即返回`-1`因为没有顺序`±x`操作可以弥补不匹配。 

验证可行性后，对数组进行排序，以便可以有效地选择中位数。 选择中值元素作为目标值是因为它最小化了绝对距离之和。 

最后，该算法计算将每个值移动到中位数所需的操作总数。 由于每个操作都会精确地更改一个值`x`，操作次数为：$$\frac{|value - median|}{x}$$累计总数作为最终答案返回。 

## 解决方案```go
package main

import (
	"sort"
)

func minOperations(grid [][]int, x int) int {
	values := []int{}

	for _, row := range grid {
		values = append(values, row...)
	}

	remainder := values[0] % x

	for _, value := range values {
		if value%x != remainder {
			return -1
		}
	}

	sort.Ints(values)

	median := values[len(values)/2]

	operations := 0

	for _, value := range values {
		diff := value - median
		if diff < 0 {
			diff = -diff
		}

		operations += diff / x
	}

	return operations
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 一个小区别是 Go 没有提供内置的整数绝对值函数，因此代码手动将负差转换为正差。 

展平数组是使用切片附加构建的，排序是使用`sort.Ints`。 

由于约束条件完全符合标准整数范围，因此常规`int`算术就足够了。

 ## 边缘情况

 一种重要的边缘情况是网格已经包含相同的值。 在这种情况下，不需要任何操作，所以答案应该是`0`。 有缺陷的实现可能仍然会尝试不必要的转换或错误地计算距离。 当前的实现自然地处理了这个问题，因为到中位数的每个距离都变为零。 

当模值不同时，会出现另一种关键的边缘情况。 例如，与`x = 2`, 值`1`和`2`永远不可能相等，因为重复加减`2`保持奇偶校验。 如果不首先检查模一致性，实现可能会错误地计算不可能场景的数字答案。 该解决方案通过在排序之前验证所有余数来防止这种情况发生。 

第三个重要的情况是元素数量为偶数。 在这种情况下，从技术上讲，排序后有两个中间值。 任一中位数都会产生相同的最小总绝对偏差。 某些实现错误地尝试对两个中位数进行平均，但这可能会产生在操作规则下无法达到的无效目标。 该实现只是直接从数组中选择一个有效中位数，保证了正确性。
