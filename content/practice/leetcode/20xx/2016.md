[LeetCode 2016 问题](https://leetcode.com/problems/maximum-difference- Between-increasing-elements/)

 **难度：** 🟢简单
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 问题是要求我们找到数组中两个元素之间的最大差异，条件是较小的元素出现在较大的元素之前。 形式上，给定一个 0 索引数组`nums`长度`n`，我们需要找到最大的值`nums[j] - nums[i]`在哪里`i < j`和`nums[i] < nums[j]`。 如果不存在这样的对，我们返回`-1`。 

输入表示一个整数数组，其中每个元素至少保证`1`并且至多`10^9`。 该数组至少有两个元素，最多有 1000 个元素，这个元素足够小，O(n^2) 解决方案在技术上可能可行，但 O(n) 解决方案更可取。 预期输出是一个整数，可以是最大有效差值，也可以是`-1`。 

重要的边缘情况包括严格递减的数组（不存在有效对）、最大差值位于最后一个元素减去第一个元素的数组以及多个对具有相同最大差值的数组。 

## 方法

 蛮力方法迭代所有可能的对`(i, j)`在哪里`i < j`。 对于每一对，我们检查是否`nums[i] < nums[j]`并计算差值。 然后我们跟踪遇到的最大差异。 这是正确的，因为它显式地评估每个有效对，但由于其 O(n^2) 时间复杂度，对于较大的数组来说效率较低。 

最佳方法依赖于最大化的关键洞察力`nums[j] - nums[i]`和`i < j`，我们只需要跟踪迭代数组时看到的最小值。 对于每个元素`nums[j]`，使用该元素的最大差异是`nums[j] - min_value_so_far`。 每当该值超过当前最大值时，我们都会更新最大差值，并且我们还会更新`min_value_so_far`如果`nums[j]`小于当前最小值。 这需要 O(n) 时间和 O(1) 空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 迭代所有对`(i, j)`并计算差异|
 | 最佳| O(n) | O(1) | O(1) | 跟踪迄今为止的最小值并即时计算差异 |

 ## 算法演练

 1.初始化两个变量：`min_value`到数组的第一个元素并且`max_diff`到`-1`。`min_value`将跟踪迄今为止看到的最小元素，确保`i < j`。`max_diff`将存储满足的最大差异`nums[i] < nums[j]`。 
2.从索引开始迭代数组`1`（因为索引`0`是我们最初的最小值）。 
3. 对于每个元素`nums[j]`， 如果`nums[j]`大于`min_value`,计算差值`nums[j] - min_value`并更新`max_diff`如果这个差异大于当前的`max_diff`。 
4.不管比较，更新`min_value`如果`nums[j]`小于当前的`min_value`。 
5. 继续此过程直到数组末尾。 
6. 返回`max_diff`，这将是找到的最大差异或`-1`如果不存在有效的对。 

**为什么有效：** 在每一步，`min_value`保证候选差异是使用当前元素之前出现的前一个元素计算的。 这确保了`i < j`。 通过迭代数组一次，我们间接考虑所有有效对并跟踪最大差异，从而有效地给出正确的结果。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumDifference(self, nums: List[int]) -> int:
        min_value = nums[0]
        max_diff = -1
        
        for num in nums[1:]:
            if num > min_value:
                max_diff = max(max_diff, num - min_value)
            min_value = min(min_value, num)
        
        return max_diff
```实现从初始化开始`min_value`到第一个元素和`max_diff`到`-1`。 我们从第二个元素开始迭代数组。 对于每个元素，我们检查它是否大于`min_value`。 如果是这样，我们更新`max_diff`。 不管怎样，我们更新`min_value`确保它始终代表迄今为止看到的最小元素。 这遵循上述最优算法。 

## 解决方案```go
func maximumDifference(nums []int) int {
    minValue := nums[0]
    maxDiff := -1
    
    for _, num := range nums[1:] {
        if num > minValue {
            diff := num - minValue
            if diff > maxDiff {
                maxDiff = diff
            }
        }
        if num < minValue {
            minValue = num
        }
    }
    
    return maxDiff
}
```在 Go 中，我们遵循相同的逻辑。 我们初始化`minValue`到第一个元素和`maxDiff`到`-1`。 迭代索引 1 的切片，我们更新`maxDiff`每当发现更大的有效差异并更新时`minValue`如果当前数字较小。 不需要额外的数据结构，我们可以原生处理大整数。
