 **难度：** 🔴难
 **主题：** 数组、动态规划、树、深度优先搜索、并查找

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算，对于有根树中的每个节点，**不**出现在以该节点为根的子树中的最小正整数。 我们有两个数组：`parents`描述树结构，并且`nums`包含分配给每个节点的不同遗传值。 节点`0`是根，所有节点都从`0`到`n - 1`。 

输入`parents`告诉我们，对于每个节点，它的父节点是谁。 输入`nums`为每个节点分配一个范围内唯一的整数`[1, 10^5]`。 输出是一个长度的数组`n`在哪里`ans[i]`是以节点为根的子树中最小的缺失数`i`。 

需要注意的关键限制是树的大小（`n`可以达到`10^5`）和取值范围`nums`（`1`到`10^5`）。 这些限制使得扫描每个子树的暴力解决方案太慢。 此外，其独特之处在于`nums[i]`简化了对缺失值的检查，因为我们不需要处理重复项。 

重要的边缘情况包括树木，其中`1`根本不存在，最大数量位于根的树，以及缺失值通过祖先传播的线性链。 

## 方法

 一种简单的方法是，对于每个节点，遍历其子树并将所有遗传值收集到一个集合中。 然后，对于每个节点，我们将从`1`向上查找第一个缺失的数字。 虽然这种方法是正确的，但它需要遍历每个节点的所有后代，导致最坏情况的复杂性为`O(n^2)`对于大树来说，这是不可行的`n <= 10^5`。 

最佳方法利用了缺失值从叶子传播的观察结果，其中`nums[i] = 1`存在。 仅包含以下节点的路径`1`到根的缺失值将大于`1`。 因此，我们可以先检测是否`1`存在； 如果没有，则每个节点都有`1`作为最小缺失值。 否则，当我们从包含的节点移动时，我们可以增量地标记子树中存在的数字`1`直到根，动态跟踪最小的缺失数。 使用集合或布尔数组来表示存在可以有效地进行传播，从而减少冗余子树遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 收集子树中每个节点的所有值，扫描最小缺失 |
 | 最佳| O(n + 最大值) | O(n + 最大值) | 沿着从包含 1 的节点到根的路径跟踪存在情况，动态更新缺失值 |

 ## 算法演练

 1. 构建邻接表`tree`从`parents`数组来表示树结构。 这允许快速访问子级以进行 DFS 遍历。 
2.初始化答案数组`ans`所有值为`1`因为`1`是最小可能的缺失值。 
3.如果`1`不存在于`nums`， 返回`ans`立即从`1`所有子树都缺失。 
4.如果`1`存在，找到它的索引`start`。 这是缺失值传播开始的节点。 
5. 初始化布尔数组`seen`标记已观察到的遗传值。 最初，所有值均未标记。 
6.从节点开始`start`并向上遍历树到根：

 1. 对于当前节点，标记其`nums[node]`如所见。 
2. 递归地标记其子树中的所有数字（不包括已处理的祖先）。 
3. 增量更新最小缺失数`mex`直到找到一个没见过的号码。 
4. 设置`ans[node] = mex`。 
7. 继续此过程直至到达根部。 
8. 返回`ans`大批。 

**为什么有效：** 通过仅处理包含以下内容的节点的路径：`1`to the root and marking seen numbers in all subtrees of that path, we guarantee that all relevant numbers are considered exactly once. 这条路径之外的节点总是有`1`作为缺失值，满足正确性。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def smallestMissingValueSubtree(self, parents: List[int], nums: List[int]) -> List[int]:
        n = len(parents)
        tree = defaultdict(list)
        for i, p in enumerate(parents):
            if p != -1:
                tree[p].append(i)
        
        ans = [1] * n
        num_to_node = {num: i for i, num in enumerate(nums)}
        if 1 not in num_to_node:
            return ans
        
        seen = [False] * (10**5 + 2)
        start = num_to_node[1]
        mex = 1
        
        def dfs(node: int):
            if seen[nums[node]]:
                return
            seen[nums[node]] = True
            for child in tree[node]:
                dfs(child)
        
        node = start
        while node != -1:
            dfs(node)
            while seen[mex]:
                mex += 1
            ans[node] = mex
            node = parents[node]
        
        return ans
```该代码首先构造树，将值映射到节点，并检查是否`1`存在。 如果`1`不存在，答案就微不足道。 否则，我们使用 DFS 沿着包含节点的路径标记子树中的可见值`1`到根。 这`mex`变量跟踪最小的缺失值。 对于每个祖先，处理子树后，我们更新`mex`并将其记录在`ans`。 

## 解决方案```go
package main

func smallestMissingValueSubtree(parents []int, nums []int) []int {
    n := len(parents)
    tree := make([][]int, n)
    for i := 0; i < n; i++ {
        if parents[i] != -1 {
            tree[parents[i]] = append(tree[parents[i]], i)
        }
    }
    
    ans := make([]int, n)
    for i := range ans {
        ans[i] = 1
    }
    
    numToNode := make(map[int]int)
    for i, num := range nums {
        numToNode[num] = i
    }
    
    if _, ok := numToNode[1]; !ok {
        return ans
    }
    
    seen := make([]bool, 100002)
    mex := 1
    start := numToNode[1]
    
    var dfs func(int)
    dfs = func(node int) {
        if seen[nums[node]] {
            return
        }
        seen[nums[node]] = true
        for _, child := range tree[node] {
            dfs(child)
        }
    }
    
    node := start
    for node != -1 {
        dfs(node)
        for seen[mex] {
            mex++
        }
        ans[node] = mex
        node = parents[node]
    }
    
    return ans
}
```Go 解决方案反映了 Python 方法。 切片初始化、映射处理和递归均适应 Go 语法。 切片用于邻接表和`seen`大批。 DFS和DFS的逻辑相同`mex`更新适用。
