 ## 问题理解

 该问题要求我们找到从顶点出发的**第二个最短时间**`1`到顶点`n`在加权无向图中，每条边的权重相同（`time`）。 不同的是，**每个顶点都有一个交通信号**，每隔一段时间就会在绿色和红色之间交替。`change`分钟。 **仅当信号为绿色**时我们才能离开顶点，但我们可以随时进入它。 

输入由顶点数组成`n`，边列表`edges`，和两个整数`time`和`change`。 输出是一个整数，表示从顶点开始的**第二个最短行程时间**`1`到顶点`n`。 第二最小值严格大于最短时间。 

输入要点：

 - 图是连通的，没有自环或重复边。 
- 遍历任何边的时间是均匀的。 
- 如果我们遇到红灯，交通灯可能会强制等待。 
- 旅程可以重访顶点，包括起点和终点。 

重要的边缘情况包括：

 1. 最短路径也是循环的图 - 第二最小值可能需要重新访问节点。 
2. 信号有时会发生变化，需要等待，可能会延长成为第二个最小值的路径。 
3. 具有相同最小长度的多条路径的图表，其中信号的时序确定哪条路径是第二短的。 

## 方法

 ### 蛮力方法

 强力解决方案将从顶点枚举**所有可能的路径**`1`到`n`，考虑交通信号计算每条路径的总行驶时间，然后选择第二小的值。 这种方法**保证正确**，因为它探索了所有可能性，但对于大型来说是不可行的`n`因为路径的数量呈指数级增长。 

### 最佳方法

 最佳方法利用**修改的 BFS**。 我们不只跟踪到达每个顶点的最短时间，而是跟踪**第一和第二最短到达时间**。 BFS 自然地以递增的步骤顺序找到路径，并且通过计算考虑交通信号灯的实际时间，我们可以保持不变式，即对于每个顶点，我们知道可以到达它的两个最小时间。 

关键的观察结果是，即使有交通信号，**离开顶点的时间在给定到达时间**的情况下也是确定的，因此我们可以轻松模拟等待绿灯。 通过为每个顶点存储两次，BFS 确保我们捕获最小时间和第二最小时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 枚举从 1 到 n 的所有路径，考虑交通信号 |
 | 最佳| O(E log V) | O(V) | 修改后的 BFS 每个顶点存储两个最小时间 |

 ## 算法演练

 1. **图表示**：从边缘构建邻接列表以进行高效的邻居查找。 
2. **时间跟踪**：对于每个顶点，维护可以到达的**两个最小时间**的列表。 初始化顶点`1`和`[0]`。 
3. **BFS队列**：使用一个队列`(current_vertex, elapsed_time)`按照路径遍历的顺序处理顶点。 
4. **模拟交通信号**：对于访问的每个顶点，计算我们是否需要等待绿色信号`elapsed_time`和`change`。 如果我们处于红色时期，请等到绿色时期。 
5. **更新时间**：如果新计算的邻居时间小于任何记录的时间并且**不同**，则将其附加。 每个顶点仅维护前两个最小时间。 
6. **BFS终止**：当目标顶点第二小的时间`n`一经发现，退回。 

**为什么起作用**：BFS 保证我们以递增的步骤顺序探索路径，并且每个顶点维护两个到达时间可确保我们捕获第二个最短时间。 模拟交通信号可确保我们正确计算等待时间。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def secondMinimum(self, n: int, edges: List[List[int]], time: int, change: int) -> int:
        # Build graph
        graph = [[] for _ in range(n + 1)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # Store the first and second shortest arrival times for each node
        times = [[] for _ in range(n + 1)]
        queue = deque([(1, 0)])  # (node, elapsed_time)
        times[1].append(0)
        
        while queue:
            node, elapsed = queue.popleft()
            
            for neighbor in graph[node]:
                # Compute waiting time due to traffic signal
                cycles = elapsed // change
                if cycles % 2 == 1:
                    # Currently red, wait until green
                    wait = change - (elapsed % change)
                else:
                    wait = 0
                next_time = elapsed + wait + time
                
                if len(times[neighbor]) < 2 and next_time not in times[neighbor]:
                    times[neighbor].append(next_time)
                    queue.append((neighbor, next_time))
        
        # Return second minimum time
        return sorted(times[n])[1]
```此 Python 实现构建邻接列表，在计算信号导致的等待时间时模拟 BFS，并跟踪到达每个节点的前两个不同时间。 对目标时间进行排序可确保我们返回**第二个最小值**。 

## 解决方案```go
package main

func secondMinimum(n int, edges [][]int, time int, change int) int {
    graph := make([][]int, n+1)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }

    times := make([][]int, n+1)
    queue := [][2]int{{1, 0}} // {node, elapsed}
    times[1] = append(times[1], 0)

    for len(queue) > 0 {
        node, elapsed := queue[0][0], queue[0][1]
        queue = queue[1:]

        for _, neighbor := range graph[node] {
            cycles := elapsed / change
            wait := 0
            if cycles%2 == 1 {
                wait = change - (elapsed % change)
            }
            nextTime := elapsed + wait + time

            if len(times[neighbor]) < 2 {
                distinct := true
                for _, t := range times[neighbor] {
                    if t == nextTime {
                        distinct = false
                        break
                    }
                }
                if distinct {
                    times[neighbor] = append(times[neighbor], nextTime)
                    queue = append(queue, [2]int{neighbor, nextTime})
                }
            }
        }
    }

    if times[n][0] < times[n][1] {
        return times[n][1]
    }
    return times[n][0]
}
```在 Go 中，我们显式处理每个节点的重复检查和切片。 Go 的切片语义需要仔细处理队列和追加操作。

 | 2 | 2 | 3 | ... | 流程2 |
 | 3 | 3 | 3 | ... | 进程 3，next_time = 6 |
 | 4 | 4 | 3 | ... | 进程 4，等待第二条路径变为绿色，next_time = 10 |
 | 5 | 5 | 6 | ... | 第二个最小值 = 13 |

 **示例2：**`n = 2, edges = [[1,2]], time = 3, change = 2`- 最小路径：1 -> 2，时间 = 3
 - 第二个最小路径：1 -> 2 -> 1 -> 2，考虑红色信号，时间 = 11

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(E) | BFS 最多探索每条边两次（每个节点两次）|
 | 空间| O(V + E) | 邻接表+每个顶点两次+队列|

 BFS 非常高效，因为我们只跟踪每个节点两次，并且边的数量受到约束。
