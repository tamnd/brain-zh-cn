[LeetCode 问题 2062](https://leetcode.com/problems/count-vowel-substrings-of-a-string/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 该问题需要计算给定字符串中**元音子串**的数量`word`。 子字符串是字符串中任何连续的字符序列。 **元音子串**定义为仅包含元音的子串（`'a'`,`'e'`,`'i'`,`'o'`,`'u'`) 并且必须至少包含一次所有五个元音。 

输入是一个长度在1到100之间的小写字符串，所以比较小。 输出是一个整数，表示有多少子串满足元音子串标准。 重要的边缘情况包括没有元音的字符串、短于 5 个字符的字符串以及具有元音但缺少所需的 5 个元音中的一个或多个的字符串。 该问题保证小写英文字母，从而避免大写或非字母字符的复杂化。 

## 方法

 **暴力方法**是生成所有可能的子串`word`并检查每个子字符串，看看它是否仅由元音组成并包含所有五个元音。 虽然这种方法是正确的，但效率很低。 生成所有子字符串需要 O(n²) 时间，检查每个子字符串中的所有五个元音可能需要 O(n) 时间，总体时间复杂度为 O(n³)。 为了`n = 100`，这是可行的，但不是最优的。 

**最佳方法**利用了元音子串是连续元音序列的观察结果。 我们可以迭代字符串，对于开始元音子串的每个位置，向右扩展，同时使用频率图计算元音的出现次数。 一旦子串包含所有五个元音，则该子串向右的每一个进一步扩展也算作有效的元音子串。 这减少了冗余检查并避免考虑包含辅音的子串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 生成所有子字符串并检查每个子字符串 |
 | 最佳 | O(n²) | O(1) | O(1) | 从每个元音起点展开并使用固定大小的映射来计数元音 |

 ## 算法演练

 1. 定义一个集合`vowels`含有`'a'`,`'e'`,`'i'`,`'o'`,`'u'`。 这有助于快速检查字符是否为元音。 
2. 初始化变量`count`为零以跟踪元音子串的总数。 
3. 迭代每个索引`i`在字符串中。 如果字符位于`i`是一个元音，开始考虑从以下位置开始的子串`i`。 
4. 对于每个起始索引`i`，初始化频率字典`freq`跟踪每个元音在当前子字符串中出现的次数。 
5. 展开指针`j`从`i`到字符串的末尾。 对于每个字符`j`，如果它是元音，则增加其计数`freq`。 如果它是辅音，则中断内部循环，因为子字符串不能再是元音子字符串。 
6.更新后`freq`，检查是否所有五个元音都存在（每个计数 >= 1）。 如果是，则增加`count`。 
7. 继续扩张`j`直到遇到辅音或到达字符串末尾。 
8. 返回`count`作为元音子串的总数。 

**为什么有效：** 通过从每个元音起点扩展并在第一个辅音处停止，我们确保所考虑的每个子串仅由元音组成。 频率图保证我们只计算那些包含所有五个元音的子串。 此方法避免了不必要的子字符串生成，减少了运行时间，同时保持了正确性。 

## Python 解决方案```python
class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set("aeiou")
        count = 0
        n = len(word)
        
        for i in range(n):
            if word[i] not in vowels:
                continue
            freq = {}
            for j in range(i, n):
                if word[j] not in vowels:
                    break
                freq[word[j]] = freq.get(word[j], 0) + 1
                if len(freq) == 5:
                    count += 1
        return count
```这个 Python 实现紧密遵循最优算法。 它首先检查字符是否可以启动元音子串，然后在跟踪字典中元音计数的同时向右扩展。 只有包含所有五个元音的子串才会增加`count`。 字典`freq`确保每个元音的恒定时间查找和更新。 

## 解决方案```go
func countVowelSubstrings(word string) int {
    vowels := map[rune]bool{'a': true, 'e': true, 'i': true, 'o': true, 'u': true}
    count := 0
    n := len(word)

    for i := 0; i < n; i++ {
        if !vowels[rune(word[i])] {
            continue
        }
        freq := map[rune]int{}
        for j := i; j < n; j++ {
            ch := rune(word[j])
            if !vowels[ch] {
                break
            }
            freq[ch]++
            if len(freq) == 5 {
                count++
            }
        }
    }
    return count
}
```Go 实现反映了 Python 解决方案。 我们使用一个`map[rune]int`跟踪当前子串中元音的频率。 Go 需要显式转换`word[i]`到`rune`正确处理 Unicode，即使输入是小写英文字母。 

## 工作示例

 **示例1：**`word = "aeiouu"`从索引 0 开始，子字符串`"aeiou"`包含所有元音。 延伸至`"aeiouu"`还包含所有元音。 计数 = 2。 

**示例2：**`word = "unicornarihan"`迭代所有起始位置。 没有子串包含所有五个元音。 计数 = 0。 

**示例3：**`word = "cuaieuouac"`从索引 1 开始：`"uaieu"`包含所有元音。 扩展子字符串会产生多个有效子字符串。 计数 = 7。

 ## 边缘情况

 第一个重要的边缘情况是短于 5 个字符的字符串，它永远不能形成元音子串。 该实现通过自然地跳过此类子字符串来处理此问题。 

第二种边缘情况涉及辅音破坏元音序列。 一旦遇到辅音，算法就会正确地停止扩展子字符串。 

第三种边缘情况是子字符串与所有元音重叠，这是通过检查有效起始索引的所有扩展来处理的。 每个包含所有五个元音的扩展都单独计算。 这确保了如果共享字符的子串独立地满足元音子串条件，则仍然对它们进行计数。
