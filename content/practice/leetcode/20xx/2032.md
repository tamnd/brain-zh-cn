[LeetCode 2032 题](https://leetcode.com/problems/two-out-of- Three/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、位操作

 ## 解决方案

 ## 问题理解

 该问题要求我们识别至少出现在**三个给定整数数组中的两个**中的所有**不同整数**。 输入由三个数组组成`nums1`,`nums2`， 和`nums3`，每个包含范围内的整数`[1, 100]`。 输出是出现在**至少两个数组**中的整数数组，输出的顺序并不重要。 

关键点是：输出中的值必须**不同**，并且每个数组中的每个值仅计数一次（单个数组中的重复项不会增加计数）。 约束告诉我们每个数组都很小（最大长度为 100），并且值本身也限制在 1 到 100 之间。这意味着我们可以安全地使用 **基于哈希的结构** 或 **位掩码** 而不必担心性能或内存。 

要考虑的边缘情况包括元素完全不相交的数组、所有元素都相同的数组、包含重复项的数组以及最小长度为 1 的数组。 

## 方法

 **暴力方法**是迭代数组的每个元素，并使用嵌套循环计算数组中的出现次数。 对于中的每个元素`nums1`，我们检查它是否存在于`nums2`或者`nums3`，并类似地重复`nums2`和`nums3`。 计数后，如果该值至少出现在两个数组中，则将该值添加到结果中。 这种方法是正确的，但它需要 **对每个元素进行多次线性搜索**，即使对于小型数组，这也可能效率低下。 

**最佳方法**利用**集合**或**哈希表**来存储每个数组中的不同值，然后计算有多少个集合包含每个数字。 我们可以将每个数组转换为一个集合，以删除该数组中的重复项。 然后，我们迭代这些集合的并集中的所有可能数字，并计算有多少个集合包含每个数字。 如果一个数字出现在两个或多个集合中，则会将其添加到结果中。 这减少了冗余比较并自然地确保了唯一性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n) | 针对每个数组检查每个元素，对于较大的输入来说速度较慢 |
 | 最佳| O(n) | O(n) | 使用集合来计算数组出现次数，有效处理唯一性 |

 ## 算法演练

 1. 转换`nums1`,`nums2`， 和`nums3`分成集合，命名`set1`,`set2`， 和`set3`。 这会删除同一数组中的重复项并允许进行 O(1) 成员资格检查。 
2.初始化一个空列表`result`存储输出。 
3. 计算所有三个集合的**并**，以获得数组中所有不同的数字。 
4. 迭代并集中的每个数字。 对于每个数字，计算三个集合中有多少个包含该数字。 
5. 如果某个数字出现在**至少两组**中，则将其附加到`result`。 
6. 返回`result`。 

为什么有效：将数组转换为集合可确保每个数组中的每个数字仅计数一次。 迭代联合保证我们检查所有可能的候选人而不会遗漏任何一个。 计算集合成员资格直接给出每个值出现的数组数量。任何出现在至少两个集合中的值都保证满足问题条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int], nums3: List[int]) -> List[int]:
        set1, set2, set3 = set(nums1), set(nums2), set(nums3)
        result = []
        
        for num in set1 | set2 | set3:
            count = (num in set1) + (num in set2) + (num in set3)
            if count >= 2:
                result.append(num)
        
        return result
```在实现中，我们首先将每个输入列表转换为一个集合以删除重复项。 然后，我们计算所有三个集合的并集，这给出了任何数组中出现的每个数字。 对于每个数字，我们使用布尔成员资格检查（`num in setX`) 评估为`True`或者`False`，我们对其求和以获得包含该数字的数组总数。 如果该计数为两个或更多，我们将该数字添加到结果列表中。 该方法简单、可读且高效。 

## 解决方案```go
func twoOutOfThree(nums1 []int, nums2 []int, nums3 []int) []int {
    set1, set2, set3 := make(map[int]bool), make(map[int]bool), make(map[int]bool)
    for _, n := range nums1 {
        set1[n] = true
    }
    for _, n := range nums2 {
        set2[n] = true
    }
    for _, n := range nums3 {
        set3[n] = true
    }

    result := []int{}
    seen := make(map[int]bool)
    
    for n := range set1 {
        if (set2[n] || set3[n]) && !seen[n] {
            result = append(result, n)
            seen[n] = true
        }
    }
    for n := range set2 {
        if set3[n] && !seen[n] {
            result = append(result, n)
            seen[n] = true
        }
    }
    
    return result
}
```在 Go 中，我们使用`map[int]bool`模拟集合，因为 Go 没有原生集合类型。 我们为三个数组填充三个映射。 然后我们迭代每个映射以检查一个数字是否存在于至少两个映射中，使用单独的`seen`映射以确保我们只附加不同的数字。 该逻辑反映了 Python 方法，但需要显式处理结果的唯一性。
