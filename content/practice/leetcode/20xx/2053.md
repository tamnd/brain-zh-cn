[LeetCode 问题 2053](https://leetcode.com/problems/kth-distinct-string-in-an-array/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 问题要求我们找到`kth`字符串数组中的不同字符串。 如果一个字符串在整个数组中只出现一次，则该字符串被认为是不同的。 

重要的细节是顺序很重要。 我们不会以任何方式对字符串进行排序或重新排列。 相反，我们必须按照它们最初在数组中出现的顺序来考虑不同的字符串。 

例如，如果数组是：```
["d","b","c","b","c","a"]
```然后：

-`"d"`出现一次，所以很明显
 -`"b"`出现两次，所以不明显
 -`"c"`出现两次，所以不明显
 -`"a"`出现一次，所以很明显

 不同的字符串按顺序是：```
["d", "a"]
```如果`k = 2`，答案是`"a"`。 

输入包括：

 -`arr`，小写字符串数组
 -`k`, 一个正整数

 输出应该是：

 - 的`kth`出现顺序不同的字符串
 - 或空字符串`""`如果少于`k`存在不同的字符串

 限制相对较小：

 -`arr.length <= 1000`- 每个字符串的长度最多为`5`这些限制意味着即使是二次解在技术上也会通过，但我们仍然应该寻求一种干净而高效的方法。 

一些边缘情况很重要：

 - 没有不同字符串的数组
 - 每个字符串都不同的数组
 - 情况`k`大于不同字符串的数量
 - 重复的字符串多次出现
 - 非常小的数组，包括长度`1`正确的解决方案必须保留原始顺序，同时准确计算出现次数。 

## 方法

 ### 蛮力方法

 暴力方法单独检查每个字符串并计算它在数组中出现的次数。 

对于每个字符串：

 1.再次扫描整个数组
 2. 统计出现次数
 3. 如果计数正好`1`，它是独特的
 4. 跟踪找到了多少个不同的字符串
 5. 返回`kth`一

 这种方法是正确的，因为它显式验证每个字符串的出现次数。 但是，它会重复扫描数组中的每个元素，效率很低。 

如果数组有`n`元素，并且每个元素都需要再次完整扫描`n`，总时间复杂度变为`O(n²)`。 

虽然`n <= 1000`足够小，可以通过，这是不必要的工作。 

### 最佳方法

 关键的观察是我们重复计算相同的频率计数。 

我们可以使用哈希映射对所有出现的字符串进行一次计数，而不是多次重新计数每个字符串。 

该算法分两次运行：

 1.第一遍：

 - 计算每个字符串出现的次数
 2.第二遍：

 - 按顺序迭代原始数组
 - 仅选择具有频率的字符串`1`- 返回`kth`这样的字符串

 A hash map is ideal here because it provides average`O(1)`查找和插入时间。 

这将整体时间复杂度降低到线性时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 重新计算每个字符串的出现次数 |
 | 最佳 | O(n) | O(n) | 使用哈希图进行频率计数 |

 ## 算法演练

 ### 最优算法

 1. 创建一个名为的哈希图`frequency`。 

该映射存储每个字符串在数组中出现的次数。 键是字符串，值是其出现次数。 
2. 遍历数组一次以建立频率。 

对于每个字符串`s`在`arr`：

 - 增量`frequency[s]`经过这一步，我们就确切地知道每个字符串出现了多少次。 
3. 按照原来的顺序再次遍历数组。 

我们必须保持出现的顺序，所以我们迭代`arr`完全按照给定的。 
4. 检查当前字符串是否不同。 

如果满足以下条件，则字符串是不同的：```
frequency[s] == 1
```5. 计算出现的不同字符串。 

每次我们找到一个不同的字符串：

 - 递减`k`6. 何时返回答案`k == 0`。 

一旦我们遇到了`kth`不同的字符串，立即返回。 
7. 如果遍历结束后没有找到足够多的不同字符串，则返回`""`。 

### 为什么它有效

 频率图保证我们正确识别字符串是否不同。 第二次遍历保留了问题所需的原始顺序。 由于我们递减`k`仅当遇到不同的字符串时，该时刻`k`达到零正好对应于`kth`按顺序排列的不同字符串。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def kthDistinct(self, arr: List[str], k: int) -> str:
        frequency = Counter(arr)

        for string in arr:
            if frequency[string] == 1:
                k -= 1

                if k == 0:
                    return string

        return ""
```实施开始于使用`Counter`来自Python的`collections`模块。 这会自动计算数组中每个字符串的频率。```python
frequency = Counter(arr)
```例如：```python
Counter({
    "b": 2,
    "c": 2,
    "d": 1,
    "a": 1
})
```接下来，我们按原始顺序迭代数组。```python
for string in arr:
```对于每个字符串，我们检查它的频率是否准确`1`。```python
if frequency[string] == 1:
```如果不同，我们就递减`k`。```python
k -= 1
```什么时候`k`变为零，我们就达到了`kth`不同的字符串。```python
if k == 0:
    return string
```如果循环结束而没有返回，则少于`k`不同的字符串，因此我们返回一个空字符串。```python
return ""
```## 解决方案```go
func kthDistinct(arr []string, k int) string {
    frequency := make(map[string]int)

    for _, str := range arr {
        frequency[str]++
    }

    for _, str := range arr {
        if frequency[str] == 1 {
            k--

            if k == 0 {
                return str
            }
        }
    }

    return ""
}
```Go 解决方案遵循与 Python 实现完全相同的逻辑。 

一个`map[string]int`用于存储频率。```go
frequency := make(map[string]int)
```第一个循环计算出现次数。```go
frequency[str]++
```第二个循环保留原始顺序并识别不同的字符串。 

Go 字符串是不可变且可比较的，因此它们可以自然地用作哈希映射键。 

与 Python 不同，Go 没有内置的`Counter`，所以我们手动增加计数。 

返回`""`很简单，因为空字符串是 Go 中字符串的零值。

 ## 边缘情况

 ### 情况 1，没有不同的字符串

 考虑：```
["a", "a", "b", "b"]
```每个字符串都出现多次。 有错误的实现可能会错误地返回第一个元素或无法处理有效答案的缺失。 

我们的实现正确检查：```
frequency[string] == 1
```由于没有字符串满足此条件，因此循环完成并返回`""`。 

### 情况 2，所有字符串都是不同的

 考虑：```
["x", "y", "z"]
```每个字符串都只出现一次。 这测试算法是否正确保留原始顺序。 

我们的实现按顺序处理数组并递减`k`每次找到不同的字符串，因此顺序保持准确。 

### 案例 3,`k`大于不同字符串的数量

 考虑：```
["a", "b", "a"]
k = 5
```只有一个不同的字符串，`"b"`。 

粗心的实现可能会访问无效索引或假设答案始终存在。 

我们的算法安全地遍历整个数组。 如果`k`永远达不到`0`，它最后返回一个空字符串。 

### 情况 4，不同字符串出现较晚

 考虑：```
["x", "x", "x", "y"]
```唯一不同的字符串出现在最后。 

这验证了算法继续扫描整个数组，并且当重复项占据开头时不会提前停止。 

因为我们对数组执行了完整的第二次传递，所以实现正确地识别了`"y"`作为答案。
