[LeetCode 2002 问题](https://leetcode.com/problems/maximum-product-of-the-length-of-two-palindromic-subsequences/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划、回溯、位操作、位掩码

 ## 解决方案

 ## 问题理解

 问题是要求我们从给定的字符串中找到两个**不相交的回文子序列**`s`使得它们的长度的乘积最大化。 通过从原始字符串中删除零个或多个字符同时保持相对顺序不变来导出子序列。 回文向前和向后读起来相同，例如“aba”或“cdc”。 如果两个子序列在原始字符串中的同一索引处不共享任何字符，则它们是**不相交的**。 

输入是一个字符串`s`长度在 2 到 12 之间，由小写字母组成。 小的最大长度表明解决方案可以考虑**所有可能的子序列**，因为子序列的总数是`2^n`和`2^12 = 4096`，这在计算上是可行的。 

The expected output is a single integer representing the **maximum product of the lengths** of any two disjoint palindromic subsequences. 边缘情况包括非常短的字符串（长度为 2）、所有字符都相同的字符串或最佳回文使用不连续字母的字符串。 

## 方法

 The brute-force approach is to generate all possible subsequences of`s`。 对于每个子序列，检查它是否是回文并存储其位掩码表示形式和长度。 然后，迭代所有回文子序列对并使用位掩码检查它们是否不相交。 如果是，则计算它们的长度的乘积并记录最大值。 这种方法是正确的，因为它详尽地考虑了每种可能的子序列组合，但它很慢，因为有`2^n`子序列直至`(2^n)^2`配对进行检查。 

优化这一点的关键观察是**每个子序列都可以表示为位掩码**，其中设置的位指示包含相应的字符。 检查两个子序列之间的不相交简化为按位与运算。 通过迭代所有位掩码一次并仅存储回文，我们避免了冗余检查并实现了更好的性能，同时对于给定的约束仍然可行。

 | 蛮力 | O(2^n * n + 2^(2n)) | O(2^n * n + 2^(2n)) | O(2^n) | O(2^n) | 生成所有子序列，检查回文，检查所有对 |

 ## 算法演练

 1.初始化一个空字典`palindrome_masks`将有效的回文子序列存储为`{bitmask: length}`。 
2. 迭代所有整数`1`到`2^n - 1`使用其位掩码表示所有可能的非空子序列。 掩码中的每一位代表是否对应的字符`s`包括在内。 
3. 对于每个掩码，通过包含设置了掩码位的字符来构造相应的子序列。 检查子序列是否是回文。 
4. 如果子序列是回文，则存储在`palindrome_masks`以其长度。 
5. 迭代所有回文掩码对。 对于每一对，使用按位 AND 检查两个掩码是否不相交 (`mask1 & mask2 == 0`）。 
6. 如果不相交，则计算它们的长度的乘积。 跟踪看到的最大产品。 
7. 返回最大乘积。 

工作原理：每个子序列都由其位掩码唯一表示，因此我们可以有效地检查不相交性，而无需重复重建子序列。 通过迭代所有子序列并检查回文，我们确保考虑所有有效组合。 当 AND 为零时，位掩码保证字符不会重叠。 

## Python 解决方案```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)
        palindrome_masks = {}

        def is_palindrome(subseq: str) -> bool:
            return subseq == subseq[::-1]

        for mask in range(1, 1 << n):
            subseq = ''.join(s[i] for i in range(n) if (mask >> i) & 1)
            if is_palindrome(subseq):
                palindrome_masks[mask] = len(subseq)

        max_product = 0
        masks = list(palindrome_masks.keys())
        for i in range(len(masks)):
            for j in range(i + 1, len(masks)):
                if masks[i] & masks[j] == 0:
                    product = palindrome_masks[masks[i]] * palindrome_masks[masks[j]]
                    max_product = max(max_product, product)

        return max_product
```该实现首先使用位掩码计算所有回文子序列。 帮手`is_palindrome`检查每个候选人。 存储掩码可以避免生成不必要的重叠对。 掩码上的双循环有效地计算不相交子序列的最大乘积。 

## 解决方案```go
func maxProduct(s string) int {
    n := len(s)
    palindromeMasks := make(map[int]int)

    isPalindrome := func(subseq string) bool {
        left, right := 0, len(subseq)-1
        for left < right {
            if subseq[left] != subseq[right] {
                return false
            }
            left++
            right--
        }
        return true
    }

    for mask := 1; mask < (1 << n); mask++ {
        subseq := ""
        for i := 0; i < n; i++ {
            if (mask>>i)&1 == 1 {
                subseq += string(s[i])
            }
        }
        if isPalindrome(subseq) {
            palindromeMasks[mask] = len(subseq)
        }
    }

    maxProduct := 0
    masks := make([]int, 0, len(palindromeMasks))
    for m := range palindromeMasks {
        masks = append(masks, m)
    }

    for i := 0; i < len(masks); i++ {
        for j := i + 1; j < len(masks); j++ {
            if masks[i]&masks[j] == 0 {
                product := palindromeMasks[masks[i]] * palindromeMasks[masks[j]]
                if product > maxProduct {
                    maxProduct = product
                }
            }
        }
    }

    return maxProduct
}
```Go 实现反映了 Python 逻辑。 字符串使用以下方式连接`+=`对于每个选定的字符。 回文检查是通过两指针方法显式进行的。 映射和切片用于存储掩码并迭代组合。 

## 工作示例

 **示例1：**`s = "leetcodecom"`- 所有子序列均通过位掩码生成。 回文子序列包括“l”、“e”、“t”、“ee”、“ete”、“cdc”等。 
- 最佳组合：代表“ete”的掩码和代表“cdc”的掩码不相交。 
- 产品：`3 * 3 = 9`。 

**示例2：**`s = "bb"`- 子序列掩码：“b”（第一个）、“b”（第二个）、“bb”。 
- 不相交的对：第一个“b”和第二个“b”。 
- 产品：`1 * 1 = 1`。 

**示例3：**`s = "accbcaxxcxx"`- 回文包括“accca”、“xxcxx”。 
- 面具是不相交的，产品：`5 * 5 = 25`。
