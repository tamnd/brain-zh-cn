[LeetCode 2049 题](https://leetcode.com/problems/count-nodes-with-the-highest-score/)

 **难度：** 🟡 中等
 **主题：** 数组、树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 输入描述使用父数组的有根二叉树。 每个节点都由一个整数标识`0`到`n - 1`， 和`parents[i]`告诉我们哪个节点是节点的父节点`i`。 根节点始终是`0`，所以它的父级是`-1`。 

目标是计算每个节点的分数。 为了计算节点的分数，我们想象删除该节点以及与其连接的所有边。 这将原始树分成几个不相连的子树。 分数是所有生成的非空子树的大小的乘积。 

例如，假设删除一个节点会创建三个不相连的部分，其大小`2`,`4`， 和`5`。 该节点的得分为：```
2 * 4 * 5 = 40
```任务不是返回最高分本身。 相反，我们必须计算有多少节点获得最高分。 

约束条件很重要：

 -`n`可以大到`10^5`- 该结构保证是有效的二叉树
 - 每个节点最多有两个子节点

 自从`n`非常大，任何重复遍历树中每个节点的解决方案都会太慢。 我们需要一种接近线性时间的算法。 

有几个重要的边缘情况需要记住：

 - 根节点的行为有所不同，因为删除它不会留下“父侧”子树。 
- 叶节点的行为有所不同，因为删除它们只会留下剩余的树。 
- 分数可能变得非常大，因为它们是子树大小的乘积，因此我们必须使用足够大的整数类型。 
- 一些生成的子树大小可能为零。 这些不应该包含在产品中，因为问题只考虑非空子树。 

## 方法

 ### 蛮力方法

 一种简单的方法是独立处理每个节点。 

对于每个节点：

 1. 从概念上删除节点。 
2. 确定剩余的所有连接组件。 
3. 使用 DFS 或 BFS 计算每个组件的大小。 
4. 将组件尺寸相乘。 
5. 跟踪最高得分及其频率。 

这种方法是正确的，因为它直接模拟了分数的定义。 

然而，它太慢了。 对于每个节点，我们可能需要再次遍历几乎整个树来计算组件大小。 由于有`n`节点，总复杂度大约变为`O(n^2)`。 

和`n = 10^5`，这是不可行的。 

### 最佳方法

 关键的见解是删除节点会将树分为最多三个部分：

 1. 左子树
 2.右子树
 3. 节点上方树的剩余部分

 如果我们已经知道每个子树的大小，我们可以立即计算节点的分数。 

认为：

-`left_size`是左子树的大小
 -`right_size`是右子树的大小
 -`remaining = n - 1 - left_size - right_size`那么分数就是：```
left_size * right_size * remaining
```除非我们跳过任何大小为零的组件。 

这提出了 DFS 解决方案：

 - 从父数组构建子邻接列表。 
- 使用 DFS 计算子树大小。 
- 从 DFS 返回时，计算每个节点的分数。 
- 跟踪最高分以及达到该分数的节点数量。 

由于每个节点仅被访问一次，因此该算法以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重新计算每个节点的子树/组件大小 |
 | 最佳| O(n) | O(n) | 单个 DFS 同时计算子树大小和分数 |

 ## 算法演练

 1. 建立一个子邻接表`parents`大批。 

由于输入仅告诉我们每个节点的父节点，因此我们首先将其转换为允许向下遍历的结构。 对于每个节点`i > 0`，我们追加`i`到`children[parents[i]]`。 
2. 初始化变量以跟踪最佳分数。 

我们维持：

 -`max_score`，迄今为止看到的最大分数
 -`count`，达到该分数的节点数量
 3. 从根开始执行深度优先搜索。 

DFS 函数返回以当前节点为根的子树的大小。 
4. 递归计算所有子树的子树大小。 

对于每个孩子：

 - 递归调用DFS
 - 存储返回的子树大小
 - 将其添加到当前子树大小
 5. 计算剩余树的大小。 

计算完所有子子树的大小后，当前子树之外的部分树的大小为：```
n - subtree_size
```6. 计算节点的得分。 

开始于`score = 1`。 

对于每个子树大小：

 - 将其乘以分数

 如果剩余的树大小大于零：

 - 将其乘以分数

 我们排除零大小的组件，因为问题只计算非空子树。 
7.更新全局最高分。 

- 如果当前分数大于`max_score`，更新最大值并将计数重置为`1`。 
- 如果当前分数等于`max_score`，增加计数。 
8. 返回子树大小。 

子树大小为：```
1 + sum(child subtree sizes)
```这`1`占当前节点本身。 

### 为什么它有效

 DFS 保证在计算节点的分数之前，我们已经知道其所有子子树的大小。 删除节点会将树精确地划分为其子子树和剩余的父端组件。 这些组件是不相交的，并且共同包含树中的所有其他节点。 因此，将它们的大小相乘与问题陈述中的分数定义完全匹配。 

## Python 解决方案```python
from typing import List

class Solution:
    def countHighestScoreNodes(self, parents: List[int]) -> int:
        n = len(parents)

        children = [[] for _ in range(n)]

        for node in range(1, n):
            parent = parents[node]
            children[parent].append(node)

        max_score = 0
        count = 0

        def dfs(node: int) -> int:
            nonlocal max_score, count

            subtree_size = 1
            score = 1

            for child in children[node]:
                child_size = dfs(child)

                subtree_size += child_size
                score *= child_size

            remaining_size = n - subtree_size

            if remaining_size > 0:
                score *= remaining_size

            if score > max_score:
                max_score = score
                count = 1
            elif score == max_score:
                count += 1

            return subtree_size

        dfs(0)

        return count
```实现首先构建`children`邻接表。 这会将父表示转换为适合 DFS 遍历的树结构。 

这`dfs`函数计算节点的子树大小。 从尺寸开始`1`因为子树总是包含节点本身。 

对于每个子节点，DFS 递归地计算子节点的子树大小。 这个尺寸有两个作用：

 - 它增加当前子树的大小
 - 它对节点的分数有成倍的贡献

 处理完所有子节点后，我们计算当前子树之外剩余组件的大小。 如果该分量非空，我们将其乘以分数。 

全局变量`max_score`和`count`跟踪迄今为止遇到的最佳分数以及有多少节点达到该分数。 

最后，DFS 返回子树大小，以便父级可以在自己的计算中使用它。 

## 解决方案```go
func countHighestScoreNodes(parents []int) int {
	n := len(parents)

	children := make([][]int, n)

	for node := 1; node < n; node++ {
		parent := parents[node]
		children[parent] = append(children[parent], node)
	}

	var maxScore int64 = 0
	count := 0

	var dfs func(int) int

	dfs = func(node int) int {
		subtreeSize := 1
		score := int64(1)

		for _, child := range children[node] {
			childSize := dfs(child)

			subtreeSize += childSize
			score *= int64(childSize)
		}

		remainingSize := n - subtreeSize

		if remainingSize > 0 {
			score *= int64(remainingSize)
		}

		if score > maxScore {
			maxScore = score
			count = 1
		} else if score == maxScore {
			count++
		}

		return subtreeSize
	}

	dfs(0)

	return count
}
```Go 实现遵循与 Python 版本相同的算法结构。 

一个重要的区别是整数处理。 分数可能变得非常大，因为它们是子树大小的乘积，因此实现使用`int64`用于分数计算。 

邻接表是使用整数切片的切片来实现的：```go
children := make([][]int, n)
```DFS 函数使用以下方式声明为递归闭包：```go
var dfs func(int) int
```这允许函数递归地引用自身。

 ## 边缘情况

 ### 根节点删除

 根节点很特殊，因为删除它不会留下任何“父端”组件。 一个常见的错误是丢失的剩余子树意外地乘以零。 

该实现通过仅在其大小大于零时乘以剩余分量来正确处理此问题：```
if remaining_size > 0:
    score *= remaining_size
```这确保了根的分数仅包括其实际的子子树。 

### 叶节点

 叶节点没有子节点。 移除一片叶子后，整个剩余的树将成为一个单独的组件。 

例如，在一棵大小为`n`，移除一片叶子恰好产生大小的一个组成部分`n - 1`。 

DFS 自然会处理这个问题，因为子循环不会执行，留下：```
score = 1
```然后将剩余部分相乘。 

### 高度倾斜的树

 一棵树可能会退化为一个链表，其中每个节点只有一个子节点。 这将创建最大可能的递归深度。 

该算法仍然可以正确工作，因为每个节点的子树大小都是从底部向上计算的。 即使递归深度变为`O(n)`，总功保持线性。 

这种情况很重要，因为许多不正确的解决方案会意外地重复重新计算子树大小，从而导致倾斜树上的二次运行时间。
