 # LeetCode 2019，学生解决数学表达式的成绩

 ## 问题理解

 该问题给了我们一个数学表达式字符串`s`仅包含：

 - 个位数`0-9`- 加法运算符`+`- 乘法运算符`*`该表达式保证有效。 例如：```
3+5*2
7+3*1*2
```学生应该使用正确的优先规则来评估表达式：

 1. 从左到右执行所有乘法
 2.然后从左到右执行所有加法

 这是标准算术优先级，其中乘法发生在加法之前。 

我们还得到了一个数组`answers`，其中每个值代表学生提交的答案。 我们必须根据以下评分规则分配分数：

 - 如果答案等于正确结果，奖励`5`点
 - 否则，如果答案可能来自不同但有效的括号，并且算术本身仍然正确，则奖励`2`点
 - 否则，奖励`0`点

 重要的微妙之处在于理解什么算作“错误顺序”答案。 

学生可能会通过选择任意括号来错误地计算表达式，从而有效地改变运算符优先级。 然而：

 - 他们仍然必须正确地执行算术
 - 仅从有效的二进制表达式分组中获得的结果才有效
 - 中间值和最终值必须保持在允许的范围内
 - 我们只关心结果`1000`例如：```
3+5*2
```正确评价：```
3 + (5*2) = 13
```可能的错误评估：```
(3+5) * 2 = 16
```所以`16`赚到`2`点。 

约束条件非常重要：

 - 表达式长度最多为`31`- 最多有`15`运营商
 - 因此，最多有`16`数字

 这对于区间动态规划来说足够小。 

主要挑战是有效计算通过不正确的括号获得的所有可能结果。 

重要的边缘情况包括：

 - 错误评估意外等于正确答案的表达式
 - 包含的表达式`0`- 重复答案
 - 许多不同的括号产生相同的值
 - 中间结果超过`1000`，应该被丢弃

 ## 方法

 ### 蛮力方法

 强力解决方案将生成表达式的所有可能的括号并评估每个括号。 

这相当于生成所有二叉表达式树。 括号的数量根据加泰罗尼亚数字增长：```
C(n) ≈ 4^n / (n^(3/2))
```为了`15`运营商，这变得非常大。 

暴力算法将：

 1. 在每个运算符处递归地拆分表达式
 2. 计算左右子表达式的所有可能结果
 3.根据运算符进行组合
 4. 收集所有生成的值
 5. 将学生的答案与结果集进行比较

 尽管这会产生正确的结果，但重复重新计算相同的子表达式会使其速度太慢。 

### 关键见解

 关键的观察是许多递归调用重复解决相同的子问题。 

例如：```
3+5*2+4
```子表达式`5*2`可能出现在许多递归分解中。 

我们可以使用带有记忆功能的区间动态规划，而不是每次都重新计算结果。 

对于代表有效子表达式的每个子字符串，我们计算：```sql
all possible values obtainable from that subexpression
```然后：

 - 将结果存储在备忘录表中
 - 需要时重复使用它们
 - 有效组合左右结果

 因为最多只有`16`数字，子表达式的总数是可以管理的。 

我们还积极修剪大于`1000`，因为学生的答案永远不会超过`1000`。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 重复重新计算相同的子表达式 |
 | 最佳| O(n3 × 平方米) | O(n² × m) | 具有记忆结果集的间隔 DP |

 这里：

-`n`是表达式中数字的个数
 -`m`是每个间隔的不同结果的最大数量

 ## 算法演练

 ### 第 1 步：解析表达式

 将表达式分解为：

 - 数字列表
 - 运营商列表

 例如：```
"3+5*2"
```变成：```
nums = [3, 5, 2]
ops = ['+', '*']
```这使得间隔处理变得更加容易。 

### 第 2 步：计算正确答案

 我们必须使用标准优先级规则来评估表达式。 

由于乘法的优先级高于加法，因此我们可以按如下方式处理表达式：

 1. 维护一个正在运行的乘法积
 2.每当我们遇到`+`，将累积的乘积添加到总数中
 3. 使用下一个编号重置产品

 对于：```
3+5*2
```我们计算：```
3 + (5*2) = 13
```这给出了官方正确答案的价值`5`点。 

### 步骤 3：定义 DP 状态

 我们定义：```
dp(l, r)
```作为：```sql
all possible results obtainable from nums[l:r+1]
```每个状态返回一组整数。 

例如：```
dp(0, 2)
```为了：```
3+5*2
```可能会产生：```
{13, 16}
```### 步骤 4：基本案例

 如果区间只包含一个数字：```
l == r
```那么唯一可能的值就是该数字本身。 

例子：```
dp(1,1) = {5}
```### 第 5 步：在每个操作员处进行拆分

 对于每个操作员位置`k`之间`l`和`r`：

 1. 递归计算所有剩下的结果
 2. 递归计算所有正确的结果
 3. 将每个左值与每个右值组合

 如果操作员是`+`：```
value = left + right
```如果操作员是`*`：```
value = left * right
```### 步骤 6：修剪大值

 问题保证答案在`0`和`1000`。 

任何大于的中间结果`1000`可以忽略。 

这大大减少了存储状态的数量。 

### 第 7 步：记住结果

 递归期间会重复许多间隔。 

记忆确保每个间隔仅计算一次。 

如果没有记忆，运行时间将会呈指数级增长。 

### 第 8 步：对学生的答案进行评分

 现在我们有：

 -`correct_answer`-`possible_answers`对于每个学生的回答：

 - 如果等于`correct_answer`， 添加`5`- 否则如果它存在于`possible_answers`， 添加`2`- 否则添加`0`## 为什么它有效

 递归考虑表达式的每个可能的二进制分区。 每个有效的括号恰好对应一个递归分解树，因此生成每个可获得的值。 

记忆化保证每个子表达式都被解决一次，而集合存储则防止重复值不受控制地增长。 

因为我们结合了每个分割点的所有左右可能性，DP 准确地枚举了所有有效的错误评估。 

## Python 解决方案```python
from typing import List
from functools import lru_cache

class Solution:
    def scoreOfStudents(self, s: str, answers: List[int]) -> int:
        nums = []
        ops = []

        for i, ch in enumerate(s):
            if i % 2 == 0:
                nums.append(int(ch))
            else:
                ops.append(ch)

        # Compute correct answer using standard precedence
        correct = 0
        current = nums[0]

        for i, op in enumerate(ops):
            if op == '*':
                current *= nums[i + 1]
            else:
                correct += current
                current = nums[i + 1]

        correct += current

        @lru_cache(None)
        def dp(left: int, right: int):
            if left == right:
                return {nums[left]}

            results = set()

            for k in range(left, right):
                left_values = dp(left, k)
                right_values = dp(k + 1, right)

                for a in left_values:
                    for b in right_values:
                        if ops[k] == '+':
                            value = a + b
                        else:
                            value = a * b

                        if value <= 1000:
                            results.add(value)

            return results

        possible = dp(0, len(nums) - 1)

        score = 0

        for ans in answers:
            if ans == correct:
                score += 5
            elif ans in possible:
                score += 2

        return score
```实现首先将表达式解析为单独的数字和运算符数组。 这简化了区间处理，因为每个子问题都可以用数字索引而不是子字符串解析来表示。 

使用乘法优先级计算正确答案。 我们不是构建一个完整的解析器，而是维护一个正在运行的乘法组，并在每当`+`出现。 

递归`dp(left, right)`函数返回可从子表达式跨越索引获得的所有可能值`left`通过`right`。 

记忆化装饰器至关重要，因为许多间隔会重复。 如果没有缓存，递归将多次重新计算相同的子表达式。 

对于每个操作员位置`k`，该函数根据运算符将每个左结果与每个右结果组合起来。 这系统地探索了每个有效的括号。 

这`value <= 1000`修剪使状态空间易于管理并匹配问题约束。 

最后，评分循环检查每个答案是否完全正确或仅通过不正确的优先顺序获得。 

## 解决方案```go
package main

func scoreOfStudents(s string, answers []int) int {
	nums := []int{}
	ops := []byte{}

	for i := 0; i < len(s); i++ {
		if i%2 == 0 {
			nums = append(nums, int(s[i]-'0'))
		} else {
			ops = append(ops, s[i])
		}
	}

	// Compute correct answer
	correct := 0
	current := nums[0]

	for i, op := range ops {
		if op == '*' {
			current *= nums[i+1]
		} else {
			correct += current
			current = nums[i+1]
		}
	}

	correct += current

	type Key struct {
		l int
		r int
	}

	memo := map[Key]map[int]bool{}

	var dp func(int, int) map[int]bool

	dp = func(left int, right int) map[int]bool {
		key := Key{left, right}

		if val, exists := memo[key]; exists {
			return val
		}

		results := map[int]bool{}

		if left == right {
			results[nums[left]] = true
			memo[key] = results
			return results
		}

		for k := left; k < right; k++ {
			leftValues := dp(left, k)
			rightValues := dp(k+1, right)

			for a := range leftValues {
				for b := range rightValues {
					value := 0

					if ops[k] == '+' {
						value = a + b
					} else {
						value = a * b
					}

					if value <= 1000 {
						results[value] = true
					}
				}
			}
		}

		memo[key] = results
		return results
	}

	possible := dp(0, len(nums)-1)

	score := 0

	for _, ans := range answers {
		if ans == correct {
			score += 5
		} else if possible[ans] {
			score += 2
		}
	}

	return score
}
```Go 实现遵循与 Python 版本相同的算法结构。 

主要区别在于记忆处理。 由于 Go 没有像 Python 那样提供内置的记忆化装饰器`lru_cache`，我们将计算出的间隔显式存储在由以下键控的映射内`(left, right)`。 

集合使用以下方式表示：```go
map[int]bool
```因为 Go 没有原生的集合类型。 

在给定的约束下，所有算术都安全地符合 Go 的标准整数范围。

 ## 边缘情况

 ### 边缘情况 1：不正确的评估等于正确的评估

 考虑：```
6+0*1
```正确的优先级给出：```
6 + (0*1) = 6
```不正确的优先级可能会导致：```
(6+0) * 1 = 6
```两者产生相同的值。 

有缺陷的实现可能会错误地仅奖励`2`点，因为该值出现在替代结果集中。 

我们的实现通过始终检查来避免这种情况：```
if ans == correct:
```在检查它是否属于替代集之前。 

### 边缘情况 2：学生答案重复

 学生可以多次提交相同的答案。 

例如：```
answers = [13,13,13]
```每个学生必须独立评分。 

错误地使用频率的错误实现可能会少算或多算点数。 

我们的解决方案单独迭代每个答案并独立添加分数。 

### 边缘情况 3：中间结果数量呈爆炸式增长

 具有许多运算符的表达式可以生成许多可能的括号。 

如果不进行修剪，结果集可能会变得非常大。 

例如：```
9*9*9+9*9
```可以产生很多组合。 

学生回答的约束最多为`1000`允许我们立即安全地丢弃较大的值：```
if value <= 1000:
```这极大地限制了内存使用和运行时间，同时保持了正确性。
