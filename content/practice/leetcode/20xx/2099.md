[LeetCode 问题 2099](https://leetcode.com/problems/find-subsequence-of-length-k-with-the-largest-sum/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们找到长度的**子序列**`k`从给定的整数数组`nums`使得子序列中的元素之和最大化。 子序列被定义为可以通过删除零个或多个元素而从原始数组中获得的序列，而不改变剩余元素的顺序。 输入由一个数组组成`nums`长度可达 1000，元素范围为`-10^5`到`10^5`，和一个整数`k`保证在 1 和数组长度之间。 

预期输出是一个长度数组`k`形成总和最大的子序列。 重要的是，如果存在重复元素或导致相同总和的不同排序，则可能存在多个有效答案。 

关键边缘情况包括具有负数的数组、多个子序列产生相同总和的数组以及其中`k`等于数组的长度或者为 1。这些约束允许解决方案的时间复杂度高达大约 O(n log n)，给定`n <= 1000`。 

## 方法

 **暴力方法**将涉及生成所有可能的长度子序列`k`，计算它们的总和，并返回总和最大的那个。 虽然这保证了正确性，但子序列的数量按组合方式增长`C(n, k) = n! / (k! * (n-k)!)`。 即使是适度的值`n`和`k`，这在计算上变得不可行。 

最佳方法的**关键见解**是具有最大总和的子序列必须包含`k`最大的数字来自`nums`，但为了保持子序列属性，它们的原始顺序为`nums`必须保存。 因此，策略是首先确定`k`最大的数字，然后按照它们在原始数组中出现的顺序重建它们。 

我们可以使用**堆或排序**来有效地找到`k`最大的数字，然后迭代数组以通过按原始顺序选择数字来构建子序列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n, k) * k) | O(C(n, k) * k) | O(C(n, k)) | O(C(n, k)) | 生成长度为 k 的所有子序列并计算总和 |
 | 最佳| O(n log k) 或 O(n log n) | O(k) | 使用堆或排序找到 k 个最大元素，然后重建子序列 |

 ## 算法演练

 1. **将值与索引配对**：创建一个元组列表，其中每个元组包含一个元素`nums`及其索引。 这允许我们在选择最大元素后按原始顺序重建子序列。 
2. **选择 k 个最大的元素**：使用 size 的最小堆`k`当我们迭代数组时跟踪 k 个最大的元素。 或者，按值降序对元组数组进行排序，并取第一个`k`元素。 
3. **按原始索引排序**：为了保留原始数组中的顺序，对所选内容进行排序`k`元素按其原始索引排列。 
4. **提取值**：返回排序后的元素的值作为最终的子序列。 

**为什么有效**：通过选择 k 个最大的数字，我们保证总和最大化。 按原始索引排序保留了子序列属性，因此结果数组是有效的。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        # Step 1: Pair each number with its index
        indexed_nums = [(num, i) for i, num in enumerate(nums)]
        
        # Step 2: Find the k largest elements based on value
        indexed_nums.sort(key=lambda x: -x[0])
        top_k = indexed_nums[:k]
        
        # Step 3: Sort the selected k elements by their original index
        top_k.sort(key=lambda x: x[1])
        
        # Step 4: Extract the values to form the subsequence
        return [num for num, _ in top_k]
```该实现首先将每个数字与其索引配对，使我们能够按顺序重建子序列。 按值对对进行排序可确定 k 个最大的数字。 按原始索引对这些前 k 个元素进行排序可确保子序列遵循原始顺序。 最后，我们提取并返回值。 

## 解决方案```go
import "sort"

func maxSubsequence(nums []int, k int) []int {
    type pair struct {
        val, idx int
    }

    n := len(nums)
    indexedNums := make([]pair, n)
    for i := 0; i < n; i++ {
        indexedNums[i] = pair{nums[i], i}
    }

    // Step 2: Sort by value descending
    sort.Slice(indexedNums, func(i, j int) bool {
        return indexedNums[i].val > indexedNums[j].val
    })
    topK := indexedNums[:k]

    // Step 3: Sort top k by original index
    sort.Slice(topK, func(i, j int) bool {
        return topK[i].idx < topK[j].idx
    })

    // Step 4: Extract values
    result := make([]int, k)
    for i := 0; i < k; i++ {
        result[i] = topK[i].val
    }
    return result
}
```在 Go 中，我们定义一个`pair`跟踪值和索引的结构。 排序是通过`sort.Slice`对于降序值和升序索引。 切片操作和分配是明确的，但遵循与 Python 版本相同的逻辑。 

## 工作示例

 **示例1**：`nums = [2,1,3,3], k = 2`1. 与索引配对：`[(2,0), (1,1), (3,2), (3,3)]`2. 按值降序排序：`[(3,2), (3,3), (2,0), (1,1)]`3. 取前2名：`[(3,2), (3,3)]`4、按索引排序：`[(3,2), (3,3)]`5. 提取值：`[3,3]`**示例2**：`nums = [-1,-2,3,4], k = 3`1. 配对：`[(-1,0), (-2,1), (3,2), (4,3)]`2. 按值排序：`[(4,3), (3,2), (-1,0), (-2,1)]`3. 前三名：`[(4,3), (3,2), (-1,0)]`4、按索引排序：`[(-1,0), (3,2), (4,3)]`5、结果：`[-1,3,4]`**示例3**：`nums = [3,4,3,3], k = 2`1. 配对：`[(3,0),(4,1),(3,2),(3,3)]`2. 按值排序：`[(4,1),(3,0),(3,2),(3,3)]`3. 前2名：`[(4,1),(3,0)]`4、按索引排序：`[(3,0),(4,1)]`5、结果：`[3,4]`## 复杂度分析
