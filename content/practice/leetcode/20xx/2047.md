 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算一个句子中**有效单词**的数量。 该句子由小写字母、数字、连字符、标点符号 (`!`,`.`,`,`) 和空格。 **单词**定义为由空格分隔的标记，如果满足三个条件，则认为它**有效**：

 1、仅包含小写字母，最多1个连字符，最多1个标点符号。 它**不能**包含数字。 
2. 如果包含连字符，则连字符必须用小写字母包围。 代币如`"a-b"`是有效的，但是`"-ab"`和`"ab-"`不是。 
3. 如果包含标点符号，则它必须出现在标记的**末尾**。 代币如`"ab,"`和`"c!"`是有效的，但是`"a!b"`无效。 

输入是一个字符串`sentence`至少有一个标记，长度最多为 1000。我们需要返回一个整数，表示句子中有效单词的数量。 

重要的边缘情况包括多个连续空格、包含数字的标记、标记中间的标点符号以及具有多个连字符的标记。 

## 方法

 暴力方法将句子按空格分割成标记，然后根据所有三个规则逐个字符检查每个标记。 这是正确的，因为我们可以按顺序验证每个规则。 但是，它需要仔细处理多个连字符和标点符号的放置。 

**最佳方法**使用相同的想法，但更清晰：迭代每个标记，检查数字，计算连字符和标点符号，并强制执行它们的放置规则。 由于每个 token 的长度最多为 1000，因此这种方法是有效的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 拆分句子并按顺序检查每个标记 |
 | 最佳| O(n) | O(1) | O(1) | 与暴力破解相同，但开销最小； 迭代时有效检查规则 |

 ## 算法演练

 1. **用空格将句子分割成标记**。 忽略由多个空格产生的空标记。 
2. **初始化有效单词计数器**。 
3. 对于每个代币：

 1. 如果令牌包含任何数字，则跳过该令牌。 
2. 计算连字符的数量。 如果超过一个，则该令牌无效。 
3. 确保所有连字符都被小写字母包围。 如果不是，则令牌无效。 
4. 数标点符号。 如果超过一个，则该令牌无效。 
5. 确保所有标点符号仅出现在标记的末尾。 如果不是，则令牌无效。 
6. 如果令牌通过了所有检查，则递增有效字计数器。 
4. 返回计数器。 

**为什么有效：** 通过按顺序检查每个令牌并根据所有三个规则对其进行验证，我们保证只有有效的令牌才会参与计数。 每个标记都经过独立检查，与问题定义保持一致。 

## Python 解决方案```python
class Solution:
    def countValidWords(self, sentence: str) -> int:
        def is_valid(token: str) -> bool:
            if not token:
                return False
            hyphen_count = 0
            for i, char in enumerate(token):
                if char.isdigit():
                    return False
                if char == '-':
                    hyphen_count += 1
                    if hyphen_count > 1:
                        return False
                    if i == 0 or i == len(token) - 1:
                        return False
                    if not (token[i-1].isalpha() and token[i+1].isalpha()):
                        return False
                if char in "!.,": 
                    if i != len(token) - 1:
                        return False
            return True
        
        tokens = sentence.split()
        count = 0
        for token in tokens:
            if is_valid(token):
                count += 1
        return count
```Python 实现分割句子，然后使用助手`is_valid`函数根据规则检查每个令牌。 连字符和标点符号规则是明确强制执行的，数字会立即使令牌无效。 来自多个空间的空标记将被忽略。 

## 解决方案```go
import "strings"
import "unicode"

func countValidWords(sentence string) int {
    isValid := func(token string) bool {
        if len(token) == 0 {
            return false
        }
        hyphenCount := 0
        for i, ch := range token {
            if unicode.IsDigit(ch) {
                return false
            }
            if ch == '-' {
                hyphenCount++
                if hyphenCount > 1 {
                    return false
                }
                if i == 0 || i == len(token)-1 {
                    return false
                }
                if !unicode.IsLetter(rune(token[i-1])) || !unicode.IsLetter(rune(token[i+1])) {
                    return false
                }
            }
            if ch == '!' || ch == '.' || ch == ',' {
                if i != len(token)-1 {
                    return false
                }
            }
        }
        return true
    }

    tokens := strings.Fields(sentence)
    count := 0
    for _, token := range tokens {
        if isValid(token) {
            count++
        }
    }
    return count
}
```在 Go 中，我们使用`strings.Fields`按空格分割并迭代每个标记。 这`unicode`包装可确保正确检查字母和数字。 索引检查强制执行连字符和标点符号规则。

 ## 边缘情况

 **多个连续空格：** 句子可能有多个空格，在拆分时创建空标记。 使用`split()`在 Python 中或`strings.Fields()`Go 会通过忽略空字符串来自动处理这个问题。 

**边界处的连字符：** 标记如`"-ab"`或者`"ab-"`无效，因为连字符必须位于字母之间。 该实现显式检查连字符之前和之后的字符。 

**单字符标点符号：** 诸如此类的标记`"!"`或者`"."`是有效的。 该代码允许标点符号单独出现在标记的末尾，这涵盖了这种情况。 

这些边缘情况涵盖了可能导致简单解决方案失败的主要陷阱。
