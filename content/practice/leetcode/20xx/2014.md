 **难度：** 🔴难
 **主题：** 哈希表、两个指针、字符串、回溯、计数、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们找到字符串的**最长子序列**`s`可以重复的`k`次，同时仍然是`s`。 通过从字符串中删除零个或多个字符而不改变剩余字符的顺序来导出子序列。 一个子序列`seq`重复`k`次意味着`seq`串联的`k`次（`seq * k`）本身应该是一个子序列`s`。 

输入由一个字符串组成`s`与长度`n`和一个整数`k`（2 到 2000 之间）。 约束条件告诉我们`n`相对较小，小于`min(2001, k * 8)`。 这暗示如果仔细修剪，组合或回溯方法可能是可行的。 

预期输出是一个字符串，它是**最长的重复子序列`k`次**，或者如果存在多个相同长度的序列，则为**字典顺序上最大的**一次。 如果不存在这样的子序列，我们返回一个空字符串。 

边缘情况包括：

 - 具有所有相同字符的字符串。 
- 字符串在哪里`k`大于任何字符的重复次数。 
- 不能出现子序列的字符串`k`次。 
- 当存在多个最长子序列时，词典顺序很重要。 

## 方法

 ### 蛮力

 蛮力方法将枚举**所有可能的子序列**`s`并检查哪些可以重复`k`次作为子序列。 这保证了正确性，但是子序列的数量是`2^n`，这是**指数级大**，并且每次检查`k`重复可能需要`O(n)`时间。 因此，这种方法对于上限是不可行的。`n = 2000`。 

### 最佳方法

 关键的见解是我们可以使用**回溯与修剪**相结合，使用**字符频率计数**。 

1. 仅限至少出现的字符`k`时间有资格构成重复子序列的一部分。 
2. 我们可以使用这些符合条件的字符构建候选序列，首先探索更长的序列以确保找到最长的序列。 
3. 我们可以按照**字典序降序**生成候选序列，确保我们找到的第一个有效序列也是字典序最大的。 
4. 有效检查候选序列是否重复`k`times 是一个子序列`s`，我们可以模拟两个指针`s`候选人重复了一遍`k`次。 

这显着减少了搜索空间，因为我们忽略了不可能满足的字符`k`重复要求。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 枚举所有子序列并检查每个子序列是否有 k 次重复 |
 | 最佳| O(26^(len(seq)) * n * k) | O(26^(len(seq)) * n * k) | O(n * k) | 基于字符计数和字典顺序的修剪回溯 |

 ## 算法演练

 1.统计每个字符出现的频率`s`。 
2、过滤出现频率至少为的字符`k`。 这些字符有资格出现在重复子序列中。 
3. 按降序对符合条件的字符进行排序，以优先考虑字典顺序上较大的序列。 
4. 执行 **DFS/回溯搜索** 以构建候选序列：

 - 在每一步中，尝试将符合条件的字符附加到当前序列。 
- 在递归之前，检查新候选者是否重复`k`times 是一个子序列`s`。 
- 如果是，则继续递归； 如果没有，请修剪该分支。 
5. 跟踪找到的**最长有效序列**。 
6. 返回末尾最长的序列。 

**为什么有效：** 修剪步骤确保我们只探索可能出现的序列`k`次。 按降序对字符进行排序可保证给定长度的第一个有效序列按字典顺序是最大的。 这种方法有效地缩小了子序列的组合爆炸范围。 

## Python 解决方案```python
class Solution:
    def longestSubsequenceRepeatedK(self, s: str, k: int) -> str:
        from collections import Counter

        def is_k_subsequence(candidate: str) -> bool:
            i = 0  # Pointer for s
            count = 0  # How many times candidate has been found
            for char in s:
                if char == candidate[i]:
                    i += 1
                    if i == len(candidate):
                        i = 0
                        count += 1
                        if count == k:
                            return True
            return False

        freq = Counter(s)
        # Only keep characters that appear at least k times
        chars = [c for c in freq if freq[c] >= k]
        chars.sort(reverse=True)  # Lexicographically descending

        result = ""

        def dfs(path: str):
            nonlocal result
            if len(path) > len(result):
                if is_k_subsequence(path):
                    result = path
            for c in chars:
                candidate = path + c
                if is_k_subsequence(candidate):
                    dfs(candidate)

        dfs("")
        return result
```**实现注意事项：**我们首先过滤掉不能出现的字符`k`次，减少搜索空间。 这`is_k_subsequence`函数检查候选人是否重复`k`times 是一个子序列`s`。 DFS 确保探索所有可行的序列，字典排序保证我们优先考虑较大的序列。 

## 解决方案```go
func longestSubsequenceRepeatedK(s string, k int) string {
    freq := make(map[byte]int)
    for i := 0; i < len(s); i++ {
        freq[s[i]]++
    }

    chars := []byte{}
    for c, f := range freq {
        if f >= k {
            chars = append(chars, c)
        }
    }

    sort.Slice(chars, func(i, j int) bool { return chars[i] > chars[j] })

    var result string

    var isKSubsequence func(candidate string) bool
    isKSubsequence = func(candidate string) bool {
        i := 0
        count := 0
        for j := 0; j < len(s); j++ {
            if s[j] == candidate[i] {
                i++
                if i == len(candidate) {
                    i = 0
                    count++
                    if count == k {
                        return true
                    }
                }
            }
        }
        return false
    }

    var dfs func(path string)
    dfs = func(path string) {
        if len(path) > len(result) && isKSubsequence(path) {
            result = path
        }
        for _, c := range chars {
            candidate := path + string(c)
            if isKSubsequence(candidate) {
                dfs(candidate)
            }
        }
    }

    dfs("")
    return result
}
```**Go 特定注释：** Go 需要显式转换`byte`和`string`连接字符时。 映射结构处理频率计数。 递归的工作原理类似，但要仔细处理切片与字符串连接。 

## 工作示例

 **示例1：**`s = "letsleetcode", k = 2`- 计数频率：`{'l':2, 'e':4, 't':2, 's':1, 'c':1, 'o':1, 'd':1}`- 符合条件的角色：`['l', 'e', 't']`（频率 >= k）
 - DFS 探索类似的序列`l`,`e`,`t`,`le`,`lt`,`et`,`let`,`ete`, ...
 -`let`和`ete`是有效的重复子序列。 
- 按字典顺序最大：`"let"`**示例2：**`s = "bb", k = 2`- 频率：`{'b':2}`- 符合条件的角色：`['b']`- DFS发现`"b"`重复两次是一个子序列。 
- 结果：`"b"`**示例3：**`s = "ab", k = 2`- 频率：`{'a':1, 'b':1}`- 没有字符出现至少两次。 
- 结果：`""`（空字符串）

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(26^(len(seq)) * n * k) | O(26^(len(seq)) * n * k) | DFS 探索符合条件的字符序列。 每次检查需要 O(n) 来验证 k 次重复。 |
 | 空间| O(n * k) | 候选序列的递归堆栈和字符串副本。 |
