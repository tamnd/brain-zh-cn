[LeetCode 2050 题](https://leetcode.com/problems/parallel-courses-iii/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、图论、拓扑排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定在给定前提关系和每门课程所需时间的情况下完成所有课程所需的最短月数。 每门课程都标记为`1`到`n`， 和`relations`描述哪些课程必须先于其他课程完成。 这`time`数组提供每门课程的持续时间，其中`time[i]`是时候完成课程了`(i+1)`。 

关键是**可以同时修读任意数量的课程**，但课程只有在完成所有先决条件后才能开始。 这自然形成了课程依赖关系的**有向无环图（DAG）**，其中目标是根据累积时间计算**通过该图的最长路径**，因为整体时间表是由最慢的相关课程链决定的。 

输入约束告诉我们`n`可以达到`50,000`和`relations`可以达到`50,000`边缘。 这立即排除了尝试所有课程排序的暴力方法，因为组合的可能性是巨大的。 此外，该图保证是一个 DAG，因此没有循环，将问题简化为 **DAG 最长路径计算**。 

重要的边缘情况包括没有先决条件的课程（可以立即开始）、有多个先决条件的课程（我们必须等待最长的链）和稀疏图（根本没有依赖关系）。 

## 方法

 ### 蛮力

 一种简单的暴力方法会尝试课程排序的所有排列，并计算每个有效排序所需的总时间，同时尊重先决条件。 这将正确地产生最小的总时间，但对于`n = 50,000`因为排列的数量呈阶乘增长，并且检查每个排序的先决条件有效性的成本很高。 

### 最佳方法

 最佳方法利用 **DAG 上的拓扑排序和动态规划**。 这个想法是计算每门课程的最早完成时间。 我们可以执行拓扑排序来按依赖关系顺序处理课程。 对于每门课程，最早完成时间是其所有先决条件的完成时间加上当前课程时间的最大值。 最后，完成所有课程的最短总月数是所有课程的最长完成时间。 

这种方法很有效，因为它只处理每个课程和关系一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 尝试课程顺序的所有排列 |
 | 最佳| O(n + m) | O(n + m) | DAG上的拓扑排序+DP； m 是关系的数量 |

 ## 算法演练

 1. **初始化数据结构：** 构建邻接表`graph`对于 DAG 其中`graph[u]`包含依赖于的所有课程`u`。 另外，初始化`in_degree`数组来跟踪每门课程的先决条件。 
2. **拓扑队列：** 用没有先决条件的课程初始化队列（`in_degree == 0`），因为这些可以立即开始。 
3. **DP数组：** 创建一个`dp`大小数组`n+1`存储每门课程的最早完成时间。 对于没有先决条件的课程，设置`dp[course] = time[course-1]`。 
4. **进程队列：** 当队列不为空时，弹出一个课程`u`，以及每个相关课程`v`在`graph[u]`， 更新`dp[v] = max(dp[v], dp[u] + time[v-1])`考虑最长的先决条件链。 减少`in_degree[v]`减 1，如果达到 0，则压入`v`进入队列。 
5. **结果：** 处理完所有课程后，答案为`max(dp[1:])`，所有课程中完成时间最长的。 

**为什么有效：** 该算法确保每门课程的完成时间占其所有先决条件的最大时间。 通过按拓扑顺序处理，我们保证只有在处理了所有课程的先决条件后才考虑每门课程。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def minimumTime(self, n: int, relations: List[List[int]], time: List[int]) -> int:
        graph = [[] for _ in range(n + 1)]
        in_degree = [0] * (n + 1)
        
        for u, v in relations:
            graph[u].append(v)
            in_degree[v] += 1
        
        dp = [0] * (n + 1)
        queue = deque()
        
        for course in range(1, n + 1):
            if in_degree[course] == 0:
                dp[course] = time[course - 1]
                queue.append(course)
        
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                dp[v] = max(dp[v], dp[u] + time[v - 1])
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)
        
        return max(dp[1:])
```**实施说明：** 我们首先构建图表并计算每门课程的先决条件。 没有先决条件的课程立即开始。 使用队列进行拓扑排序可确保我们仅在满足所有先决条件后才处理课程。 对于每门课程，我们动态计算其最早完成时间。 最后，在最大`dp`数组给出了总的最小月份数。 

## 解决方案```go
package main

func minimumTime(n int, relations [][]int, time []int) int {
    graph := make([][]int, n+1)
    inDegree := make([]int, n+1)
    
    for _, rel := range relations {
        u, v := rel[0], rel[1]
        graph[u] = append(graph[u], v)
        inDegree[v]++
    }
    
    dp := make([]int, n+1)
    queue := []int{}
    
    for course := 1; course <= n; course++ {
        if inDegree[course] == 0 {
            dp[course] = time[course-1]
            queue = append(queue, course)
        }
    }
    
    for len(queue) > 0 {
        u := queue[0]
        queue = queue[1:]
        for _, v := range graph[u] {
            if dp[v] < dp[u]+time[v-1] {
                dp[v] = dp[u] + time[v-1]
            }
            inDegree[v]--
            if inDegree[v] == 0 {
                queue = append(queue, v)
            }
        }
    }
    
    maxTime := 0
    for _, t := range dp[1:] {
        if t > maxTime {
            maxTime = t
        }
    }
    return maxTime
}
```**Go 注释：** Go 解决方案与 Python 非常相似。 切片处理动态邻接列表。 队列操作是使用切片操作完成的。 DP 更新使用简单的比较而不是`max`功能。 

## 工作示例

 ### 示例 1

 输入：`n = 3, relations = [[1,3],[2,3]], time = [3,2,5]`一步一步：

 1.图表：`{1:[3], 2:[3], 3:[]}`,`in_degree = [0,0,0,2]`2. 队列开头为`[1,2]`3. DP：`[0,3,2,0]`4.过程1：更新dp[3] = max(0,3+5)=8
 5.过程2：更新dp[3] = max(8,2+5)=8
 6. dp数组=`[0,3,2,8]`，最大值 = 8 → 输出：8

 ### 示例 2

 输入：`n = 5, relations = [[1,5],[2,5],[3,5],[3,4],[4,5]], time = [1,2,3,4,5]`一步一步：

 1.图表：`{1:[5],2:[5],3:[5,4],4:[5],5:[]}`,`in_degree=[0,0,0,0,1,4]`2. 队列：`[1,2,3]`, DP:`[0,1,2,3,0,0]`3、过程1：dp[5] = 1+5=6
 4.过程2：dp[5] = max(6,2+5)=7
 5、过程3：dp[4]=3+4=7，dp[5]=max(7,3+5)=8
 6、过程4：dp[5]=max(8,7+5)=12
 7. 过程5完成。 max(dp)=12 → 输出：12
