[LeetCode 2000 题](https://leetcode.com/problems/reverse-prefix-of-word/)

 **难度：** 🟢简单
 **主题：** 两个指针、字符串、堆栈

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`word`和一个角色`ch`。 我们必须找到第一次出现的位置`ch`字符串内部。 一旦找到它，我们就反转从索引开始的子字符串`0`并以该事件结束，包括在内。 

反转该前缀后，字符串的其余部分保持完全相同。 

例如，如果：```
word = "abcdefd"
ch = "d"
```第一次出现`"d"`位于索引处`3`。 来自索引的前缀`0`通过`3`是：```
"abcd"
```反转它给出：```
"dcba"
```字符串的其余部分是：```
"efd"
```将它们结合起来产生：```
"dcbaefd"
```如果角色`ch`没有出现在字符串中的任何位置，我们只需原样返回原始字符串。 

限制非常小：

 -`1 <= word.length <= 250`- 仅使用小写英文字母

 由于输入大小很小，几乎任何合理的字符串处理解决方案都可以高效运行。 然而，目标仍然是设计一个干净且正确的算法。 

一些边缘情况很重要：

 -`ch`字符串中可能根本不存在
 -`ch`可能会出现在索引处`0`，意味着反转的前缀有长度`1`，所以字符串保持不变
 -`ch`可能会出现多次，但只有第一次出现才重要
 - 如果第一次出现在最后一个索引处，则可能需要反转整个字符串

 ## 方法

 ### 蛮力方法

 暴力解决方案可以在逐字符扫描字符串时重复构建候选前缀。 一旦找到目标字符，我们可以使用另一个循环手动反转前缀，然后连接剩余的后缀。 

例如：

 1. 扫描字符串以查找第一次出现的`ch`2. 复制该位置之前的所有字符（包括该位置）到临时数组中
 3. 手动反转该临时数组
 4. 附加字符串中未更改的其余部分

 这是有效的，因为它直接遵循问题陈述。 然而，它涉及额外的手动复制和反转逻辑，这使得实现比必要的更加冗长。 

尽管约束足够小，这种方法完全可以接受，但我们可以显着简化解决方案。 

### 最佳方法

 关键的观察是我们只需要反转字符串的单个前缀。 现代编程语言已经提供了高效的子串和反转操作。 

最优策略是：

 1. 查找第一次出现的索引`ch`2.如果不存在，则返回原字符串
 3. 反转子串`0`通过该索引
 4. 附加未修改的后缀

 这种方法简单、可读且高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 手动复制和反转字符 |
 | 最佳 | O(n) | O(n) | 使用直接前缀反转和串联 |

 ## 算法演练

 ### 最优算法

 1. 搜索第一次出现的`ch`在`word`。 

我们需要第一个匹配位置，因为问题明确表示仅反转到第一次出现的位置。 一旦我们知道了这个索引，我们就确切地知道要反转哪个前缀。 
2. 如果没有找到该字符，则返回原始字符串。 

在这种情况下，不应执行任何操作。 提早返回可以避免不必要的工作。 
3. 从索引中提取前缀`0`通过找到的索引。 

如果第一次出现在索引处`i`，那么前缀是：```
word[:i+1]
```4. 反转提取的前缀。 

使用 Python 中的切片或 Go 中的字节交换循环可以有效地完成反转。 
5. 提取找到的索引后的后缀。 

字符串的这一部分保持不变。 
6. 连接颠倒的前缀和后缀。 

得到的字符串就是所需的答案。 

### 为什么它有效

 该算法之所以有效，是因为它与问题陈述中描述的操作完全匹配。 唯一允许的修改是反转以第一次出现结尾的前缀`ch`。 通过定位该索引并精确反转该部分，同时保持其余部分不变，我们保证了正确的输出。 

## Python 解决方案```python
class Solution:
    def reversePrefix(self, word: str, ch: str) -> str:
        index = word.find(ch)

        if index == -1:
            return word

        reversed_prefix = word[:index + 1][::-1]
        suffix = word[index + 1:]

        return reversed_prefix + suffix
```实现首先定位第一次出现的`ch`使用Python的内置`find()`方法。 如果`find()`回报`-1`，该字符不存在，因此立即返回原始字符串。 

如果该字符存在，代码将提取以该索引结尾的前缀。 Python 切片`[::-1]`高效、简洁地反转子字符串。 

然后，目标索引后面的后缀将被原样提取。 最后，将反转的前缀和后缀连接起来以产生最终结果。 

该实现紧密反映了算法步骤，这使得代码易于验证和维护。 

## 解决方案```go
func reversePrefix(word string, ch byte) string {
    index := -1

    for i := 0; i < len(word); i++ {
        if word[i] == ch {
            index = i
            break
        }
    }

    if index == -1 {
        return word
    }

    bytes := []byte(word)

    left := 0
    right := index

    for left < right {
        bytes[left], bytes[right] = bytes[right], bytes[left]
        left++
        right--
    }

    return string(bytes)
}
```Go 解决方案遵循与 Python 版本相同的逻辑，但使用显式字节操作，因为 Go 字符串是不可变的。 

找到第一次出现的位置后`ch`，字符串被转换为字节切片，以便可以就地交换字符。 两个指针，`left`和`right`，在交换角色的同时向对方移动。 这可以有效地直接反转字节片内部的前缀。 

最后，修改后的字节片被转换回字符串并返回。 

由于输入仅包含小写英文字母，因此将字符串视为字节是完全安全的。

 ## 边缘情况

 ### 角色不存在

 错误的一个常见来源是忘记处理以下情况`ch`永远不会出现在字符串中。 如果实现盲目地尝试使用无效索引反转前缀，则可能会产生不正确的结果或运行时错误。 

该解决方案通过检查搜索结果是否是安全地处理这个问题`-1`。 如果是这样，它立即返回原始字符串不变。 

### 字符出现在索引 0 处

 如果第一次出现`ch`已经位于字符串的开头，前缀长度只有一个字符。 反转单个字符不应改变字符串。 

例如：```
word = "abc"
ch = "a"
```实现正确提取`"a"`，将其反转为`"a"`，并附加未更改的后缀`"bc"`。 

### 整个字符串必须反转

 如果第一次出现`ch`位于最终索引处，整个字符串成为前缀。 

例如：```
word = "abc"
ch = "c"
```该算法反转整个字符串并产生`"cba"`。 

该实现自然地处理了这个问题，因为目标索引后面的后缀只是一个空字符串。
