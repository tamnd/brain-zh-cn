[LeetCode 2010 题](https://leetcode.com/problems/the-number-of-seniors-and-juniors-to-join-the-company-ii/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们模拟固定薪资预算为 70,000 美元的招聘流程，其中候选人被分类为“高级”或“初级”，并且每个人都有独特的薪资。 招聘规则很严格：我们必须首先尝试雇用尽可能多的老年人，总是先挑选工资最低的，直到我们再也无法雇用更多的老年人为止。 之后，剩余的预算用于雇用初级人员，也是从最低工资开始雇用，直到预算用完为止。 目标是返回一张表`employee_id`s 代表被聘用的候选人。 

输入是一个表`Candidates`三列：`employee_id`（唯一标识符），`experience`（“高级”或“初级”），以及`salary`（唯一整数）。 输出是一个列表`employee_id`已聘用候选人的数量。 边缘情况包括无法聘用高级人员的情况，或聘用高级人员后无法聘用初级人员的情况，以及预算允许聘用所有候选人的情况。 

重要的保证和限制是薪资是独一无二的，预算固定为70,000美元。 这使得按工资排序变得简单，无需担心关系。 我们还必须考虑预算不足以雇用特定类型候选人的情况。 

## 方法

 蛮力方法很简单：遍历所有按薪水排序的高级人员，从预算中减去他们的薪水，直到不可能雇用另一名高级人员为止。 然后用剩余的预算对初级人员重复相同的过程。 虽然这很简单，但它依赖于对两组候选者分别进行排序，这是优化它的关键。 

最优的解决方案利用了这样一个事实：我们只需要按薪水对高年级和低年级的人员进行单独排序，然后执行线性扫描来选择候选人，直到预算用完。 排序可确保我们始终首先选择最便宜的候选人，从而满足招聘标准。 这种方法避免了不必要的重复预算检查或嵌套循环。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 按薪水对前辈和后辈进行排序，迭代招聘直至预算用完|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 与暴力破解相同，因为需要排序，排序后线性扫描 |

 ## 算法演练

 1. 根据以下条件将候选人分为两个列表`experience`： 一套适合高年级学生，一套适合低年级学生。 这确保了我们遵循优先雇用高级人员的规则。 
2. 对两个列表进行排序`salary`按升序排列。 排序保证我们始终首先选择成本最低的候选人，从而最大限度地提高雇用数量。 
3. 初始化变量`remaining_budget`到 70,000 来跟踪我们可以花多少钱。 
4.初始化一个空列表`hired_ids`来存储`employee_id`已聘用候选人的数量。 
5. 迭代已排序的前辈列表。 对于每个高级人员，检查他们的工资是否小于或等于`remaining_budget`。 如果是，请附加它们`employee_id`到`hired_ids`并从中减去他们的工资`remaining_budget`。 当无法负担更多老年人时就停止。 
6. 迭代已排序的初级列表。 对于每个初级人员，检查他们的工资是否小于或等于`remaining_budget`。 如果是，请附加它们`employee_id`到`hired_ids`并从中减去他们的工资`remaining_budget`。 当没有更多的初级学生负担得起时就停止。 
7. 返回`hired_ids`作为最终结果。 

为什么有效：按薪水排序可确保我们始终首先雇用最便宜的候选人，从而在预算限制下最大化雇用数量。 通过先于后辈处理高年级学生，我们尊重招聘优先规则。 排序后的线性扫描确保高效选择。 

## Python 解决方案```python
import pandas as pd

class Solution:
    def hiredEmployees(self, candidates: pd.DataFrame) -> pd.DataFrame:
        budget = 70000
        hired_ids = []

        seniors = candidates[candidates['experience'] == 'Senior'].sort_values('salary')
        juniors = candidates[candidates['experience'] == 'Junior'].sort_values('salary')

        for _, row in seniors.iterrows():
            if row['salary'] <= budget:
                hired_ids.append(row['employee_id'])
                budget -= row['salary']

        for _, row in juniors.iterrows():
            if row['salary'] <= budget:
                hired_ids.append(row['employee_id'])
                budget -= row['salary']

        return pd.DataFrame({'employee_id': hired_ids})
```Python 实现使用 pandas 来有效地过滤和排序候选者。 我们首先将高级人员和初级人员分开，按工资排序，然后在预算范围内迭代招聘。 这`iterrows()`函数用于对 DataFrame 行进行清晰且可读的迭代。 

## 解决方案```go
package main

import (
    "sort"
)

type Candidate struct {
    EmployeeID int
    Experience string
    Salary     int
}

func HiredEmployees(candidates []Candidate) []int {
    budget := 70000
    var hiredIDs []int

    var seniors, juniors []Candidate
    for _, c := range candidates {
        if c.Experience == "Senior" {
            seniors = append(seniors, c)
        } else {
            juniors = append(juniors, c)
        }
    }

    sort.Slice(seniors, func(i, j int) bool {
        return seniors[i].Salary < seniors[j].Salary
    })
    sort.Slice(juniors, func(i, j int) bool {
        return juniors[i].Salary < juniors[j].Salary
    })

    for _, s := range seniors {
        if s.Salary <= budget {
            hiredIDs = append(hiredIDs, s.EmployeeID)
            budget -= s.Salary
        }
    }

    for _, j := range juniors {
        if j.Salary <= budget {
            hiredIDs = append(hiredIDs, j.EmployeeID)
            budget -= j.Salary
        }
    }

    return hiredIDs
}
```在Go中，切片用于存储过滤后的候选者。 排序是使用完成的`sort.Slice`带有自定义比较器。 其余的逻辑与 Python 类似：首先迭代排序的高级产品，然后是初级产品，相应地调整预算。 

## 工作示例

 **示例 1 逐步说明**

 初始预算：70000

 老年人按工资排序：[(11, 16000), (2, 20000), (13, 50000)]

 青年人按工资排序：[(1, 10000), (9, 15000), (4, 40000)]

 聘请前辈：

 - 雇佣11人→预算70000-16000=54000
 - 雇用2人→预算54000-20000=34000
 - 无法雇用 13 → 工资 50000 > 34000

 聘用新人：

 - 雇用 1 → 预算 34000-10000=24000
 - 雇佣9人→预算24000-15000=9000
 - 无法雇佣4人→工资40000 > 9000

 最终聘用的 ID：[11,2,1,9]

 **示例 2 逐步**

 初始预算：70000

 按工资排序的老年人：[(11, 80000), (2, 85000), (13, 90000)]

 低年级按薪资排序：[(9, 10000), (1, 25000), (4, 30000)]

 雇用的老年人：无（全部> 70000）

 聘用新人：

 - 雇佣9人→预算70000-10000=60000
 - 雇用 1 → 预算 60000-25000=35000
 - 雇用4人→预算35000-30000=5000

 最终聘用的 ID：[9,1,4]
