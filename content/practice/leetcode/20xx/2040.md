 **难度：** 🔴难
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 该问题要求通过将排序数组中的一个元素相乘而形成第 k 个最小的乘积`nums1`与排序数组中的一个元素`nums2`。 两个数组都可以包含负数、零和正数。 的价值`k`是从 1 开始的，意思是`k = 1`对应于总体上最小的产品。 数组已排序，但它们可能具有不同的长度，并且产品总数可以大到`nums1.length * nums2.length`，最多可达$2.5 \times 10^9$考虑到约束条件。 

需要注意的要点包括负数的存在，它反转乘积的顺序（两个负数相乘产生一个正数）和零，如果满足以下条件，它可以主导第 k 个最小的乘积：`k`很小。 简单地计算所有可能的产品并对它们进行排序将超出时间和空间的限制，因为产品数组可能达到数十亿个条目。 因此，需要一种利用数组排序性质的更有效的方法。 

重要的边缘情况包括全部为负数的数组、包含零的数组或带有混合符号的数组，其中第 k 个乘积可能来自负数与正数的乘积。 

## 方法

 蛮力方法将涉及生成所有可能的产品`nums1[i] * nums2[j]`，将它们存储在列表中，对列表进行排序，然后返回第 k 个元素。 虽然正确，但这种方法的时间和空间复杂度与数组长度的乘积成正比，这对于大输入来说是不可行的。 

最佳方法使用**对产品值的二分搜索**而不是索引。 关键的见解是对于固定的候选产品`x`，我们可以有效地计算有多少个产品小于或等于`x`对第二个数组使用双指针或二分搜索策略来查找第一个数组中的每个元素。 通过此计数，我们可以调整搜索范围以定位第 k 个最小的产品，而无需生成所有产品。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m log(n * m)) | O(n * m log(n * m)) | O(n * m) | 生成所有产品，排序并挑选第 k 个 |
 | 最佳| O((n + m) * log(max_val - min_val)) | O((n + m) * log(max_val - min_val)) | O(1) | O(1) | 使用双指针/二分搜索对产品值进行二分搜索并进行计数 |

 ## 算法演练

 1. **定义搜索边界：** 可能的最小乘积是`min(nums1) * min(nums2)`或者`min(nums1) * max(nums2)`，最大的是`max(nums1) * max(nums2)`或者`max(nums1) * min(nums2)`取决于迹象。 使用它们作为初始二分搜索范围。 
2. **对产品值进行二分搜索：** 重复直到搜索区间收敛。 对于每位候选人`mid`value，统计有多少个产品小于或等于`mid`。 
3. **计算产品 <= mid:**

 对于每个数字`a`在`nums1`：

- 如果`a`为正数，计算其中的元素`nums2`这样`a * b <= mid`使用二分搜索（因为`nums2`已排序）。 
- 如果`a`为负数，计算其中的元素`nums2`这样`a * b <= mid`，这意味着从另一端开始计数`nums2`.
- If `a` is zero and `mid >= 0`， 全部`nums2`元素对计数有贡献。 
4. **调整搜索间隔：** 如果产品数量 <=`mid` is less than `k`, set `low = mid + 1`; 否则，设置`high = mid`. Repeat.
5. **Return the final result:** Once `low` equals `high`，它代表第 k 个最小的乘积。 

**为什么有效：** 不变的是二分搜索维持第 k 个最小乘积必须位于的范围。 计数函数保证如果至少有`k`小于或等于某个候选值的乘积，则真正的第 k 个乘积不能小于该候选值。 这确保了收敛到正确答案。 

## Python 解决方案```python
from bisect import bisect_right, bisect_left
from typing import List

class Solution:
    def kthSmallestProduct(self, nums1: List[int], nums2: List[int], k: int) -> int:
        def count_leq(x: int) -> int:
            count = 0
            for a in nums1:
                if a > 0:
                    count += bisect_right(nums2, x // a)
                elif a < 0:
                    count += len(nums2) - bisect_left(nums2, (x + (-a-1)) // a)  # careful integer division
                else:
                    if x >= 0:
                        count += len(nums2)
            return count

        left, right = -10**10, 10**10
        while left < right:
            mid = (left + right) // 2
            if count_leq(mid) < k:
                left = mid + 1
            else:
                right = mid
        return left
```

**Implementation walkthrough:** The `count_leq` function efficiently counts products <= `x` using binary search on `nums2`。 积极的`a`价值观的运用`bisect_right`， 消极的`a`价值观的运用`bisect_left`通过转换来处理负乘积，并且当`x >= 0`。 对乘积值进行二分搜索可确保找到第 k 个最小乘积，而无需生成所有乘积。 

## 解决方案```go
import "sort"

func kthSmallestProduct(nums1 []int, nums2 []int, k int64) int64 {
    countLEQ := func(x int64) int64 {
        var count int64 = 0
        for _, a := range nums1 {
            if a > 0 {
                idx := sort.Search(len(nums2), func(i int) bool {
                    return int64(nums2[i])*int64(a) > x
                })
                count += int64(idx)
            } else if a < 0 {
                idx := sort.Search(len(nums2), func(i int) bool {
                    return int64(nums2[i])*int64(a) > x
                })
                count += int64(len(nums2) - idx)
            } else {
                if x >= 0 {
                    count += int64(len(nums2))
                }
            }
        }
        return count
    }

    left, right := int64(-1e10), int64(1e10)
    for left < right {
        mid := (left + right) / 2
        if countLEQ(mid) < k {
            left = mid + 1
        } else {
            right = mid
        }
    }
    return left
}
```**Go 特定说明：** 整数溢出是通过将乘积转换为`int64`。 这`sort.Search`函数复制二分搜索功能，类似于 Python`bisect`。 切片用于`nums2`无需复制，最大限度地减少内存使用。
