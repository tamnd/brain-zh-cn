[LeetCode 问题 2098](https://leetcode.com/problems/subsequence-of-size-k-with-the-largest-even-sum/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们找到长度子序列的**最大可能的偶数和**`k`从给定的整数数组`nums`。 子序列是通过从数组中删除一些元素而不改变剩余元素的相对顺序而获得的序列。 输入由整数数组组成`nums`和一个整数`k`，它指定所需的子序列长度。 输出要么是可获得的最大偶数和，要么是`-1`如果不存在这样的总和。 

约束表明数组可以非常大，最多`10^5`元素，数组中的值最多可达`10^5`。 这排除了尝试所有可能的长度子序列的暴力解决方案`k`，因为有`C(n, k)`可能的子序列，这对于大的情况是不可行的`n`。 

要考虑的边缘情况包括所有数字均为奇数或所有数字均为偶数的数组，其中`k`等于`nums.length`、带有零的数组，以及长度总和不为偶数的情况`k`存在。 

## 方法

 **暴力方法**将生成所有长度的子序列`k`，计算它们的总和，并跟踪最大的偶数总和。 这保证了正确性，但由于可能的子序列的组合爆炸，在计算上是不可行的。 具体来说，生成`C(n, k)`子序列具有指数时间复杂度。 

**最佳方法**利用排序和贪婪策略。 主要观点是，为了最大化总和，我们通常想要最大的`k`数字。 如果这些总和`k`最大的数字是偶数，我们就完成了。 如果是奇数，我们需要将该子序列中的一个元素与其外部的一个元素交换以使总和为偶数，并选择使总和损失最小化的交换。 具体来说，我们考虑将所选子序列中的最小奇数替换为其外部最大的偶数，或者将最小偶数替换为其外部最大的奇数。 这种方法之所以有效，是因为排序使我们能够有效地识别交换的候选者。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n, k) * k) | O(C(n, k) * k) | O(k) | 生成长度为 k 的所有子序列并计算总和 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对数组进行排序并使用贪婪交换来确保最大偶数和 |

 ## 算法演练

 1. **按降序对数组进行排序**，最大的数字排在前面。 
2. **选择第一个`k`elements** 作为初始候选子序列并计算其总和。 
3. 如果总和是偶数，则立即返回，因为它是最大可能的总和`k`数字。 
4. 如果总和为奇数，则确定要交换的候选者：

 - 所选子序列中的最小奇数。 
- 所选子序列中的最小偶数。 
- 子序列之外的最大偶数。 
- 子序列之外的最大奇数。 
5. **尝试交换**：

 - 将子序列中最小的奇数替换为其外部最大的偶数。 
- 将子序列中最小的偶数替换为其外部最大的奇数。 
6. 计算两次交换的结果总和（如果可能）并返回其中的最大偶数总和。 
7. 如果没有交换结果为偶数，则返回`-1`。 

**为什么有效：** 通过排序，我们确保初始总和最大化。 互换是经过精心选择的，以尽量减少总和，同时纠正奇偶校验，保证最大可能的偶数总和。 

## Python 解决方案```python
from typing import List

class Solution:
    def largestEvenSum(self, nums: List[int], k: int) -> int:
        nums.sort(reverse=True)
        selected = nums[:k]
        sum_selected = sum(selected)
        
        if sum_selected % 2 == 0:
            return sum_selected
        
        smallest_odd_in = None
        smallest_even_in = None
        for num in selected[::-1]:
            if num % 2 == 0 and smallest_even_in is None:
                smallest_even_in = num
            if num % 2 == 1 and smallest_odd_in is None:
                smallest_odd_in = num
        
        largest_even_out = None
        largest_odd_out = None
        for num in nums[k:]:
            if num % 2 == 0 and largest_even_out is None:
                largest_even_out = num
            if num % 2 == 1 and largest_odd_out is None:
                largest_odd_out = num
            if largest_even_out is not None and largest_odd_out is not None:
                break
        
        candidates = []
        if smallest_odd_in is not None and largest_even_out is not None:
            candidates.append(sum_selected - smallest_odd_in + largest_even_out)
        if smallest_even_in is not None and largest_odd_out is not None:
            candidates.append(sum_selected - smallest_even_in + largest_odd_out)
        
        return max(candidates) if candidates else -1
```Python 实现完全遵循该算法。 排序找出最大的`k`元素。 然后我们检查奇偶校验并尝试交换以修复奇数和。 对最小和最大元素使用变量可确保交换时损失最小，从而最大化总和。 

## 解决方案```go
import "sort"

func largestEvenSum(nums []int, k int) int64 {
    sort.Sort(sort.Reverse(sort.IntSlice(nums)))
    selected := nums[:k]
    var sumSelected int64 = 0
    for _, num := range selected {
        sumSelected += int64(num)
    }
    
    if sumSelected%2 == 0 {
        return sumSelected
    }
    
    var smallestOddIn, smallestEvenIn *int
    for i := k - 1; i >= 0; i-- {
        if selected[i]%2 == 0 && smallestEvenIn == nil {
            smallestEvenIn = &selected[i]
        }
        if selected[i]%2 == 1 && smallestOddIn == nil {
            smallestOddIn = &selected[i]
        }
    }
    
    var largestEvenOut, largestOddOut *int
    for i := k; i < len(nums); i++ {
        if nums[i]%2 == 0 && largestEvenOut == nil {
            largestEvenOut = &nums[i]
        }
        if nums[i]%2 == 1 && largestOddOut == nil {
            largestOddOut = &nums[i]
        }
        if largestEvenOut != nil && largestOddOut != nil {
            break
        }
    }
    
    var candidates []int64
    if smallestOddIn != nil && largestEvenOut != nil {
        candidates = append(candidates, sumSelected-int64(*smallestOddIn)+int64(*largestEvenOut))
    }
    if smallestEvenIn != nil && largestOddOut != nil {
        candidates = append(candidates, sumSelected-int64(*smallestEvenIn)+int64(*largestOddOut))
    }
    
    if len(candidates) == 0 {
        return -1
    }
    
    var max int64 = candidates[0]
    if len(candidates) == 2 && candidates[1] > max {
        max = candidates[1]
    }
    return max
}
```在 Go 中，我们处理指针来跟踪最小和最大的交换候选者。 我们还使用`int64`以防止对可能较大的数字求和时溢出。 其逻辑与 Python 完全一致。 

## 工作示例

 **示例 1：nums = [4,1,5,3,1], k = 3**

 1. 排序：`[5,4,3,1,1]`2. 选择前 3 个：`[5,4,3]`, sum = 12 (偶数) → 返回 12

 **示例 2：nums = [4,6,2], k = 3**

 1. 排序：`[6,4,2]`2. 选择前 3 个：`[6,4,2]`, sum = 12 (偶数) → 返回 12

 **示例 3：nums = [1,3,5]，k = 1**

 1. 排序：`[5,3,1]`2. 选择第一个 1：`[5]`，总和 = 5（奇数）
 3.无偶外→返回-1
