[LeetCode 问题 2077](https://leetcode.com/problems/paths-in-maze-that-lead-to-same-room/)

 **难度：** 🟡 中等
 **主题：** 图论

 ## 解决方案

 ## 问题理解

 该问题要求我们分析一个用无向图表示的迷宫`n`房间由走廊相连。 每个走廊都允许双向行驶，并且输入`corridors`列出所有此类连接。 目标是确定该迷宫中存在的 **长度为 3** 的不同循环（在图论中也称为 **三角形**） 的数量。 如果两个循环包含相同的房间集，则认为它们是相同的，无论遍历的顺序如何。 

输入由一个整数组成`n`表示房间数量，以及表示为成对相连房间的走廊列表。 约束表明`n`最多可达1000条，走廊数量可达5万条。 这意味着对所有路径进行强力枚举将是低效的。 每条走廊都是独一无二的，没有房间与其自身相连。 

边缘情况包括没有循环的迷宫、每个三元组的房间形成一个三角形的完全连接的图或具有断开连接的组件的图。 这些案例测试算法是否正确地仅计算不同的三角形并同样处理稀疏和密集的图。 

## 方法

 暴力方法将涉及生成三个房间的所有可能序列并检查它们是否形成循环。 这种方法将检查三个房间的每种组合并验证每对房间之间的连接性。 虽然正确，但该方法的时间复杂度为 O(n3)，当 n 达到 1000 时，这会导致多达 10 亿次检查。 

最佳方法利用图形表示和邻接检查。 通过将图存储为邻接列表或邻接集，我们可以迭代每条边`(u, v)`对于每个节点`w`与两者相邻`u`和`v`, 识别一个三角形`(u, v, w)`。 使用集合允许 O(1) 成员资格检查，与暴力相比，显着减少了操作数量。 此方法通过强制执行命令来确保每个三角形仅计算一次（例如，`u < v < w`）。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n²) | 检查所有三人间的房间是否有自行车 |
 | 最佳 | O(n * d²) | O(n²) | 使用邻接集有效检测三角形； d 是平均节点度 |

 ## 算法演练

 1. 初始化邻接集`adj`对于每个房间，将每个房间映射到与其直接连接的一组房间。 这允许 O(1) 检查直接连接。 
2. 初始化计数器`triangle_count`为零。 这将累积不同三角形的数量。 
3. 遍历所有房间`u`从 1 到 n。 每个房间`u`，考虑其所有邻居对`(v, w)`这样`v > u`和`w > v`以避免多次计算同一个三角形。 
4. 对于每一对这样的`(v, w)`，检查是否`w`是在`adj[v]`。 如果是的话，那么`u, v, w`形成一个三角形，所以增加`triangle_count`。 
5. 返回`triangle_count`作为迷宫的混乱分数。 

**为什么有效：** 通过按升序迭代邻居，我们保证每个三角形都被精确计数一次。 邻接集允许快速验证两个节点之间的连接性。 这种方法可以有效地找到长度为 3 的所有循环，且没有冗余。 

## Python 解决方案```python
from typing import List

class Solution:
    def numberOfPaths(self, n: int, corridors: List[List[int]]) -> int:
        adj = {i: set() for i in range(1, n + 1)}
        for u, v in corridors:
            adj[u].add(v)
            adj[v].add(u)
        
        triangle_count = 0
        
        for u in range(1, n + 1):
            neighbors = list(adj[u])
            neighbors.sort()
            for i in range(len(neighbors)):
                v = neighbors[i]
                if v <= u:
                    continue
                for j in range(i + 1, len(neighbors)):
                    w = neighbors[j]
                    if w in adj[v]:
                        triangle_count += 1
        
        return triangle_count
```该代码首先为每个房间构建一个邻接集，允许 O(1) 检查连接。 对于每个房间，它按排序顺序迭代所有邻居对，以确保每个三角形只计算一次。 如果相邻对之间存在第三条边，则找到三角形并对其进行计数。 

## 解决方案```go
func numberOfPaths(n int, corridors [][]int) int {
    adj := make([]map[int]bool, n+1)
    for i := 1; i <= n; i++ {
        adj[i] = make(map[int]bool)
    }
    for _, c := range corridors {
        u, v := c[0], c[1]
        adj[u][v] = true
        adj[v][u] = true
    }

    triangleCount := 0

    for u := 1; u <= n; u++ {
        neighbors := make([]int, 0, len(adj[u]))
        for v := range adj[u] {
            neighbors = append(neighbors, v)
        }
        // sort neighbors to enforce u < v < w
        sort.Ints(neighbors)
        for i := 0; i < len(neighbors); i++ {
            v := neighbors[i]
            if v <= u {
                continue
            }
            for j := i + 1; j < len(neighbors); j++ {
                w := neighbors[j]
                if adj[v][w] {
                    triangleCount++
                }
            }
        }
    }

    return triangleCount
}
```Go 实现反映了 Python 方法。 它使用映射切片来表示邻接集，并强制执行顺序 u < v < w 以防止重复计数。 对相邻切片进行排序可确保正确排序。 

## 工作示例

 **示例1：**`n = 5, corridors = [[1,2],[5,2],[4,1],[2,4],[3,1],[3,4]]`邻接集：

 | 房间| 邻居 |
 | --- | --- |
 | 1 | 2, 3, 4 |
 | 2 | 1, 4, 5 |
 | 3 | 1, 4 |
 | 4 | 1、2、3 |
 | 5 | 2 |

 发现三角形：

 - 1-2-4 (1<2<4)
 - 1-3-4 (1<3<4)

 总计 = 2。 

**示例2：**`n = 4, corridors = [[1,2],[3,4]]`邻接集：

 | 房间| 邻居 |
 | --- | --- |
 | 1 | 2 |
 | 2 | 1 |
 | 3 | 4 |
 | 4 | 3 |

 没有找到三角形。 总计 = 0。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 **稀疏图：** 边数很少的图可能有零个三角形。 该算法正确返回 0，因为所有邻居对的邻接检查都失败。 

**完全连通图：** 对于完整的图`n`房间，每个三元组形成一个三角形。 邻接集确保使用 u < v < w 的顺序将所有三角形精确计数一次。 

**断开连接的组件：**图可能具有孤立的集群。 该算法独立正确地迭代所有房间，计算每个组件内的三角形，而不会受到其他组件的干扰。 这可以防止少算或重复计算。 

**单个三角形：** 恰好三个房间连接成三角形的图测试最小的非平凡情况。
