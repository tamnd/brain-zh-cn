[LeetCode 2039 题](https://leetcode.com/problems/the-time-when-the-network-becomes-idle/)

 **难度：** 🟡 中等
 **主题：** 数组、广度优先搜索、图论

 ## 解决方案

 ## 问题理解

 这个问题涉及到服务器网络，其中服务器`0`是主服务器，所有其他服务器都是数据服务器。 每个数据服务器首先向主站发送消息，主站收到消息后立即做出响应。 根据规定，如果数据服务器未收到回复，则定期重新发送消息`patience`大批。 目标是确定网络空闲的最早时间，这意味着没有消息在传输或待处理。 

输入由一个`edges`列表，它描述了服务器的无向图，以及`patience`数组，其中`patience[i]`告诉服务器的频率`i`重新发送消息。 输出是一个整数，表示网络空闲后的第一秒。 

需要注意的要点是：所有服务器都已连接，`patience[0]`为 0（主服务器从不重新发送），消息沿着最短路径进行最佳传输，并且每个服务器仅在前一条消息的回复尚未到达时才重新发送。 

边缘情况包括距离主服务器一跳的服务器、具有`patience[i]`大于往返时间，以及强调消息定时的链式或星形网络。 

## 方法

 暴力方法会每秒模拟整个网络。 每一秒，它都会沿着边缘移动消息，检查回复是否到达，并在需要时重新发送消息。 虽然正确，但这种方法对于以下情况不可行`n`最多 10^5，因为它需要为每个服务器模拟可能 10^5 秒，从而导致 O(n^2) 或更糟糕的复杂性。 

最佳方法依赖于两个观察结果。 首先，消息遵循最短路径，因此我们可以使用主服务器的广度优先搜索（BFS）来计算每个服务器的往返时间（RTT）。 其次，服务器仅按其数倍重新发送消息`patience[i]`在收到回复之前。 使用 RTT，我们可以计算服务器发送的最后一条消息，确定回复何时到达，然后有效地计算网络空闲时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力模拟| O(n^2) | O(n^2) | O(n + e) | 模拟每一秒； 对于大 n | 不可行
 | BFS + 数学计算 | O(n + e) | O(n + e) | BFS 获取最短路径； 使用 RTT 和耐心计算最后回复时间 |

 ## 算法演练

 1. 建立邻接表`edges`来表示网络图。 每个节点都会存储其邻居的列表，以便高效遍历。 
2.从主服务器开始初始化BFS队列`0`。 跟踪访问过的节点以避免再次访问。 
3.执行BFS计算距服务器的最短距离`0`到所有其他服务器。 这里的距离是边的数量，因为每条边需要 1 秒。 
4. 对于每个数据服务器`i`(1 到 n-1)，计算往返时间为`2 * distance[i]`。 
5. 计算服务器收到回复之前发送的最后一条消息的时间。 如果`round_trip_time <= patience[i]`，服务器在时间 0 处仅发送一条消息。否则，它将每隔`patience[i]`直到回复到达之前。 
6. 该服务器的网络空闲时间为`last_reply_time + 1`， 在哪里`last_reply_time = last_sent_time + round_trip_time`。 
7. 返回所有服务器中最大的网络空闲时间。 

**工作原理：** BFS 确保我们计算从主服务器到所有服务器的最短路径，这一点至关重要，因为消息会以最佳方式传输。 通过根据 RTT 计算最后的回复并`patience`，我们可以有效地确定网络何时空闲，而无需每秒进行模拟。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def networkBecomesIdle(self, edges: List[List[int]], patience: List[int]) -> int:
        n = len(patience)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        dist = [0] * n
        visited = [False] * n
        queue = deque([0])
        visited[0] = True
        
        while queue:
            node = queue.popleft()
            for neighbor in graph[node]:
                if not visited[neighbor]:
                    visited[neighbor] = True
                    dist[neighbor] = dist[node] + 1
                    queue.append(neighbor)
        
        max_idle = 0
        for i in range(1, n):
            rtt = 2 * dist[i]
            if rtt <= patience[i]:
                last_sent = 0
            else:
                last_sent = ((rtt - 1) // patience[i]) * patience[i]
            last_reply = last_sent + rtt
            max_idle = max(max_idle, last_reply + 1)
        
        return max_idle
```Python 实现首先构建邻接列表并运行 BFS 来查找距主节点的最短距离。 然后，对于每个数据服务器，它使用整数除法计算最后一条消息时间，以确定回复到达之前的最后一次重新发送，计算回复返回的时间，并跟踪最大空闲时间。 

## 解决方案```go
package main

func networkBecomesIdle(edges [][]int, patience []int) int {
    n := len(patience)
    graph := make([][]int, n)
    for _, e := range edges {
        u, v := e[0], e[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }

    dist := make([]int, n)
    visited := make([]bool, n)
    queue := []int{0}
    visited[0] = true

    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        for _, neighbor := range graph[node] {
            if !visited[neighbor] {
                visited[neighbor] = true
                dist[neighbor] = dist[node] + 1
                queue = append(queue, neighbor)
            }
        }
    }

    maxIdle := 0
    for i := 1; i < n; i++ {
        rtt := 2 * dist[i]
        var lastSent int
        if rtt <= patience[i] {
            lastSent = 0
        } else {
            lastSent = ((rtt - 1) / patience[i]) * patience[i]
        }
        lastReply := lastSent + rtt
        if lastReply+1 > maxIdle {
            maxIdle = lastReply + 1
        }
    }

    return maxIdle
}
```Go 解决方案反映了 Python 实现。 它使用切片作为邻接列表，使用队列作为 BFS，并使用整数运算来计算最后发送消息的时间。 Go 特定的差异包括显式切片初始化和边界感知追加操作。 

## 工作示例

 **示例1：**`edges = [[0,1],[1,2]], patience = [0,2,1]`BFS 距离：`[0,1,2]`，RTT：`[0,2,4]`。 

- 服务器1：RTT=2，耐心=2→last_sent=0，last_reply=2→idle_time=3
 - 服务器2：RTT=4，耐心=1→last_sent=((4-1)//1)*1=3，last_reply=7→idle_time=8

 最大空闲时间 = 8

 **示例2：**`edges = [[0,1],[0,2],[1,2]], patience = [0,10,10]`BFS 距离：`[0,1,1]`，RTT：`[0,2,2]`。 

- 服务器1：RTT=2，耐心=10→last_sent=0，last_reply=2→idle_time=3
 - 服务器2：RTT=2，耐心=10→last_sent=0，last_reply=2→idle_time=3

 最大空闲时间 = 3
