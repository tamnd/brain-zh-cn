[LeetCode 问题 2067](https://leetcode.com/problems/number-of-equal-count-substrings/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、滑动窗口、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们计算字符串中**子字符串**的数量`s`这样**子字符串中的每个唯一字符都准确出现`count`次**。 子字符串是字符串的连续段，因此我们只考虑连续的字符。 

输入是：

 -`s`：一串小写英文字母，长度可达`3 * 10^4`。 
-`count`：一个整数`1`到`3 * 10^4`，表示子字符串中每个字母必须出现的确切次数。 

输出是一个整数，即满足条件的子字符串的数量。 

关于该问题的主要见解：

 - 子串可以重叠； 相同的字符可能出现在多个有效子字符串中。 
- 如果`count`大于任何字符出现的总次数，则该字符不能构成有效的子字符串。 
- 最大子串长度由下式确定`count`乘以该子字符串中唯一字符的数量。 
- 边缘情况包括非常短的字符串、非常大的字符串`count`，以及没有字符出现的字符串`count`次。 

潜在陷阱：

 - 所有子字符串的暴力枚举对于`s`长度可达`3 * 10^4`。 
- 扩展或收缩子串时必须仔细管理频率计数。 

## 方法

 ### 蛮力

 蛮力方法将生成所有可能的子串`s`并且，对于每个子字符串，计算每个字符的出现次数。 如果所有唯一字符都准确出现`count`次，增加答案。 

虽然正确，但这太慢了。 生成所有子字符串的复杂度为 O(n²)，计算每个子字符串中的字符频率会增加一个 O(n) 因子，从而导致 O(n³) 时间，这对于`n`最多 30,000 个。 

### 最佳方法

 关键的见解是有效子字符串的长度必须是`count`。 设子字符串中唯一字符的数量为`k`。 那么子串的长度必须恰好是`k * count`。 这一观察使我们能够**枚举唯一字符的数量`k`从 1 到 26** 并使用长度的滑动窗口`k * count`有效地检查子字符串是否满足条件。 

滑动窗口保留窗口中字母的频率计数，并检查所有存在的字母是否具有准确的频率`count`。 通过在字符串上移动窗口，我们可以有效地计算有效子字符串。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(26) | 枚举所有子串，统计频率 |
 | 最佳| O(26 * n) = O(n) | O(26 * n) = O(n) | O(26) = O(1) | 每个可能的唯一字符计数的滑动窗口 |

 ## 算法演练

 1. 循环可能的唯一字符数`k`从 1 到 26。这表示有效子字符串中不同字母的数量。 
2. 计算所需的窗口长度`window_len = k * count`。 跳过如果`window_len > len(s)`因为没有子字符串可以比字符串长。 
3.使用长度的滑动窗口`window_len`遍历`s`。 维护一个大小为 26 的哈希图或数组来统计当前窗口中的字母频率。 
4. 还保留准确出现的 ** 字母的计数`count`次**在窗口中。 
5. 对于每个窗口，检查字母数量是否准确`count`比赛`k`。 如果是，则增加答案。 
6. 一次移动窗口一个字符：将新字符添加到计数图中并删除旧字符。 相应地更新“精确计数”跟踪器。 
7. 继续，直到当前的所有窗口`k`处理完毕，然后进入下一步`k`。 

**为什么它有效**：

 通过迭代可能的唯一字母数量，我们保证考虑所有潜在的子字符串长度。 滑动窗口确保使用频率图和精确计数跟踪器在每个班次中以 O(1) 的时间检查每个子串，从而提供有效的解决方案。 

## Python 解决方案```python
class Solution:
    def equalCountSubstrings(self, s: str, count: int) -> int:
        result = 0
        n = len(s)
        for unique_chars in range(1, 27):
            window_len = unique_chars * count
            if window_len > n:
                break
            freq = [0] * 26
            exact_count = 0
            for i in range(window_len):
                idx = ord(s[i]) - ord('a')
                freq[idx] += 1
                if freq[idx] == count:
                    exact_count += 1
                elif freq[idx] == count + 1:
                    exact_count -= 1
            if exact_count == unique_chars:
                result += 1
            for i in range(window_len, n):
                idx_add = ord(s[i]) - ord('a')
                idx_remove = ord(s[i - window_len]) - ord('a')
                
                freq[idx_add] += 1
                if freq[idx_add] == count:
                    exact_count += 1
                elif freq[idx_add] == count + 1:
                    exact_count -= 1
                
                freq[idx_remove] -= 1
                if freq[idx_remove] == count:
                    exact_count += 1
                elif freq[idx_remove] == count - 1:
                    exact_count -= 1
                
                if exact_count == unique_chars:
                    result += 1
        return result
```该代码迭代可能的唯一字符计数并滑动长度的窗口`unique_chars * count`。 频率阵列`freq`跟踪每个字符的出现情况，以及`exact_count`准确跟踪有多少个字符出现频率`count`。 这允许在每个窗口移位的 O(1) 时间内检查条件。 

## 解决方案```go
func equalCountSubstrings(s string, count int) int {
    result := 0
    n := len(s)
    for uniqueChars := 1; uniqueChars <= 26; uniqueChars++ {
        windowLen := uniqueChars * count
        if windowLen > n {
            break
        }
        freq := [26]int{}
        exactCount := 0
        for i := 0; i < windowLen; i++ {
            idx := s[i] - 'a'
            freq[idx]++
            if freq[idx] == count {
                exactCount++
            } else if freq[idx] == count+1 {
                exactCount--
            }
        }
        if exactCount == uniqueChars {
            result++
        }
        for i := windowLen; i < n; i++ {
            idxAdd := s[i] - 'a'
            idxRemove := s[i-windowLen] - 'a'
            
            freq[idxAdd]++
            if freq[idxAdd] == count {
                exactCount++
            } else if freq[idxAdd] == count+1 {
                exactCount--
            }
            
            freq[idxRemove]--
            if freq[idxRemove] == count {
                exactCount++
            } else if freq[idxRemove] == count-1 {
                exactCount--
            }
            
            if exactCount == uniqueChars {
                result++
            }
        }
    }
    return result
}
```Go 特定注释：我们使用固定大小的数组`[26]int`而不是用于频率跟踪的地图。 对字节值进行算术可确保正确的索引。 不需要 nil 处理，因为切片永远不会为零。 

## 工作示例

 | ---| ---| ---| ---| ---|
 | 唯一字符= 1 | “aaa”| a = 3 | 1 | 1 |
 | 唯一字符 = 2 | “bcbbcc”| b=3，c=3 | 2 | 2 |
 | 唯一字符= 3 | “aaabcbbcc”| a = 3，b = 3，c = 3 | 3 | 3 |

 最终答案：3

 ### 示例 2：`s = "abcd", count = 2`所有子串都太短而无法满足`count = 2`。 结果：0

 ### 示例 3：`s = "a", count = 5`单个字符，无法达到计数。 结果：0

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(26 * n) = O(n) | O(26 * n) = O(n) | 循环 26 个可能的唯一字符计数，在 n 长度字符串上滑动窗口 |
 | 空间| O(26) = O(1) | 固定大小的频率阵列|

 该算法非常高效，因为 26 因子是常数，并且每次窗口操作都是 O(1)。
