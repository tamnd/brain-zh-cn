[LeetCode 问题 1877](https://leetcode.com/problems/minimize-maximum-pair-sum-in-array/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们将偶数长度的数组中的元素配对，以使所有对中的最大和最小化。 简单来说，假设我们有一个数字集合，并且我们希望每个数字组成两个数字对。 每个数字只能属于一对。 一旦我们将它们配对，每对就有一个总和。 在所有这些总和中，我们寻找最大的一个 - 这就是“最大对总和”。 我们的目标是组织配对，使这个最大值尽可能小。 

输入是一个数组`nums`长度均匀的`n`，其中每个数字都是正整数。 输出是一个整数，即最佳配对后最小化的最大对和。 约束表明`n`最多可达 100,000 个，每个元素最多可达 100,000 个。 这意味着任何比以下更糟糕的方法`O(n log n)`或者`O(n)`时间复杂度可能太慢。 保证输入的长度均匀，这简化了配对逻辑。 

重要的边缘情况包括所有元素都相同的数组、混合有非常大和非常小的数字的数组以及最小长度为 2 的数组。 

## 方法

 蛮力方法将考虑所有可能的配对，计算每种排列的最大配对总和，并返回找到的最小最大值。 这保证了正确性，但不可行，因为配对的数量随`n`。 具体来说，与`n`元素，有`(n-1)!!`配对它们的方法，这在计算上是不可能的`n`最多 100,000。 

最佳方法的关键见解是基于排序。 如果我们按升序对数组进行排序，则将最小的元素与最大的元素配对，将第二小的元素与第二大的元素配对，依此类推，可确保总和平衡且最大对和最小化。 这是有效的，因为极值配对可以防止用两个大数创建非常大的和，这会不必要地增加最大值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((n-1)!!) | O((n-1)!!) | O(n) | 检查所有可能的配对，对于大 n | 不可行
 | 最佳| O(n log n) | O(n log n) | O(1) 或 O(n) | 对数组进行排序并迭代地将最小与最大配对 |

 ## 算法演练

 1. 对输入数组进行排序`nums`按升序排列。 这样可以轻松访问最小和最大的元素。 
2. 初始化变量`max_pair_sum`到 0。这将存储找到的最大对和。 
3.使用两个指针，`left`从数组的开头开始并且`right`从最后开始。 
4. 虽然`left`小于`right`，计算总和`nums[left] + nums[right]`。 
5. 更新`max_pair_sum`为其当前值与上一步计算的总和中的最大值。 
6. 增量`left`并减少`right`向内移动并形成下一对。 
7. 处理完所有对后，返回`max_pair_sum`。 

**为什么有效**：将最小和最大的元素配对可以最大限度地减少大数对最大总和的影响。 这种贪婪策略保证总和不会超过最小可能的最大值，因为任何其他配对要么使大数字配对在一起，从而增加最大值，要么使小数字与小数字配对，这不会减少最大值。 排序可确保极端情况始终以最佳方式配对。 

## Python 解决方案```python
from typing import List

class Solution:
    def minPairSum(self, nums: List[int]) -> int:
        nums.sort()
        max_pair_sum = 0
        left, right = 0, len(nums) - 1
        while left < right:
            pair_sum = nums[left] + nums[right]
            max_pair_sum = max(max_pair_sum, pair_sum)
            left += 1
            right -= 1
        return max_pair_sum
```该实现首先对数组进行排序，以便轻松访问最小和最大元素。 这`while`循环从外到内迭代对，计算总和并跟踪看到的最大总和。 最后，结果作为最小化的最大对和返回。 

## 解决方案```go
import "sort"

func minPairSum(nums []int) int {
    sort.Ints(nums)
    maxPairSum := 0
    left, right := 0, len(nums)-1
    for left < right {
        pairSum := nums[left] + nums[right]
        if pairSum > maxPairSum {
            maxPairSum = pairSum
        }
        left++
        right--
    }
    return maxPairSum
}
```在 Go 中，实现与 Python 非常相似。 我们对切片进行排序`sort.Ints`，然后使用两个索引从两端遍历数组，沿途更新最大和。 Go 可以高效地处理切片，因此除了排序数组之外不需要额外的空间。

 ## 边缘情况

 **最小尺寸数组**：当`nums`只有两个元素，该算法仍然按`while`循环执行一次并返回两个数字的和。 

**所有元素相等**：如果中的每个元素`nums`是相同的，任何配对都会产生相同的总和。 该算法可以优雅地处理这个问题，因为`max_pair_sum`正确更新但永远不会改变统一总和。 

**巨大差异**：如果简单的方法将两个最大的数字配对在一起，则具有非常小和非常大数字的数组可能会导致不正确的结果。 通过对极值进行排序和配对，该算法保证大数与小数配对，有效地最小化最大和。
