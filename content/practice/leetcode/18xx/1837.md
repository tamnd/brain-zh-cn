 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 问题是要求我们转换给定的整数`n`从底数 10 到另一个底数`k`，然后计算该基数中的数字之和。 例如，如果`n`是 34 且`k`是 6，首先我们将 34 转换为以 6 为底数，得到`54`，然后将数字相加：5 + 4 = 9。 

输入受到限制，使得`1 <= n <= 100`和`2 <= k <= 10`。 这告诉我们`n`很小并且基数在简单的个位数范围内，因此性能不是主要问题。 我们保证有效的小输入，因此我们不需要处理负数、零或无效基数。 

重要的边缘情况包括`n`已经小于`k`，在这种情况下它的基数`k`表示形式是一个数字等于`n`，以及当`k`等于 10，意味着不需要转换。 

输出始终是一个整数，表示转换后以 10 为基数的数字之和。 

## 方法

 蛮力方法很简单：转换`n`表示其基数中的数字的字符串`k`，迭代每个字符，将其转换回整数，并对数字求和。 这种方法之所以有效，是因为转换为另一个基数并对数字求和是直接计算。 考虑到输入限制较小，这种方法足够快。 

更优化和优雅的方法使用数学技术而不构造字符串。 重复取剩余部分`n`除以`k`（`n % k`) 获取基数中的最低有效数字`k`，将其添加到运行总和中，然后进行整数除`n`经过`k`（`n //= k`）。 继续直到`n`变为零。 这避免了字符串转换并且内存效率更高。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(log_k n) | O(log_k n) | O(log_k n) | O(log_k n) | 转换为基数中的字符串`k`和数字总和 |
 | 最佳| O(log_k n) | O(log_k n) | O(1) | O(1) | 使用重复除法和余数直接求和 |

 ## 算法演练

 1. 初始化变量`total`到 0 以跟踪数字之和。 
2. 虽然`n`大于 0：

 a. 计算`digit = n % k`获取基数中当前最低有效数字`k`。 

b. 添加`digit`到`total`。 

c. 更新`n`使用整数除法`n //= k`删除我们刚刚处理的数字。 
3. 当循环结束时，`total`包含的数字之和`n`在基地`k`。 返回`total`。 

为什么有效：这种方法之所以有效，是因为将余数与`k`始终在基数中产生正确的最低有效数字`k`，整数除法将数字向右移动基数`k`。 重复这个过程直到`n`变为零可确保所有数字仅处理一次，并计算它们的总和。 

## Python 解决方案```python
class Solution:
    def sumBase(self, n: int, k: int) -> int:
        total = 0
        while n > 0:
            total += n % k
            n //= k
        return total
```Python 实现遵循上述最佳方法。 我们初始化`total`来累积总和。 循环的每次迭代都会提取最低有效数字`n`在基地`k`使用模运算符，将其添加到`total`，并将其从中删除`n`使用整数除法。 循环结束时`n`变为零，此时`total`包含最终总和。 

## 解决方案```go
func sumBase(n int, k int) int {
    total := 0
    for n > 0 {
        total += n % k
        n /= k
    }
    return total
}
```Go 实现反映了 Python 解决方案。 主要区别与语法相关：我们使用`for`而不是`while`， 和`/=`在 Go 中对整数执行整数除法。 不需要额外的内存结构。 

## 工作示例

 **示例1：**`n = 34, k = 6`| 步骤| n | n % k | 总计 | n // k |
 | --- | --- | --- | --- | --- |

 | 2 | 5 | 5 | 9 | 0 |

 结果：9

 | 2 | 1 | 1 | 1 | 0 |

 结果：1

 ## 边缘情况

 一种边缘情况是当`n`小于`k`。 在这种情况下，`n`本身是基数中的个位数`k`，所以数字之和就是`n`。 这是循环正确处理的，因为`n % k`回报`n`循环在一次迭代后结束。 

另一个边缘情况是当`k`等于10。不需要实际转换； 该算法仍然有效，因为`n % 10`产生每个数字`n`，整数除以 10 可以正确移动数字。 

当出现第三种边缘情况时`n`正好可以整除`k`多次，例如`n = k^m`。 该算法通过按顺序提取每个余数来正确地对所有数字求和，直到`n`变为零，确保没有遗漏任何数字。
