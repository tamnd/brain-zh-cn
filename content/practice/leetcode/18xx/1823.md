 ## 解决方案

 ## 问题理解

 该问题描述了经典约瑟夫问题的变体。 我们有`n`朋友们围成一圈，编号`1`通过`n`顺时针。 从第一个朋友开始算`k`顺时针方向的朋友（包括起始朋友）。 这位朋友在`k`-th 位置从圆中移除。 然后，从被删除的朋友的顺时针方向立即开始计数，重复该过程，直到只剩下一位朋友。 任务是确定哪个朋友是最后剩下的，即获胜者。 

输入由两个整数组成：`n`、好友数量以及`k`，步数。 输出是一个整数，即获胜朋友的号码。 约束条件（`1 <= k <= n <= 500`）告诉我们输入大小足够小，即使 O(n²) 解决方案也可以接受，尽管使用数学方法存在 O(n) 解决方案。 

关键的边缘情况包括`n = 1`其中第一个朋友无疑是获胜者，并且情况如下`k = 1`这导致顺序消除。 

## 方法

 ### 蛮力方法

 暴力法直接使用列表或队列来模拟游戏。 我们从朋友列表开始`[1, 2, ..., n]`。 使用模运算，我们计算`k`朋友们，删除`k`第一个朋友，然后重复，直到只剩下一个朋友。 这保证了正确性，因为它直接实现规则。 然而，在 Python 或 Go 中重复从列表中删除元素每次删除需要 O(n) 时间，导致总运行时间为 O(n²)。 

### 最佳方法

 最优方法利用约瑟夫问题公式。 让`f(n, k)`代表获胜者的位置`n`人和脚步`k`。 递归公式为：```
f(1, k) = 0
f(n, k) = (f(n-1, k) + k) % n  for n > 1
```此公式给出了 0 索引位置，因此我们在末尾添加 1 将其转换为 1 索引。 这种方法在线性时间 O(n) 和常数空间 O(1) 中运行，避免了显式模拟。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 使用列表或队列模拟消除过程 |
 | 最佳| O(n) | O(1) | O(1) | 迭代使用递归约瑟夫斯公式来找到获胜者 |

 ## 算法演练

 1. 初始化变量`winner`到 0。这将在我们递归计算时存储零索引的获胜者。 
2. 迭代`i`从 2 到`n`包容性。 每一步更新`winner = (winner + k) % i`。 这模拟将下一个人添加到圆圈中并调整获胜者位置。 
3. 循环完成后，`winner`持有零指数获胜者`n`朋友们。 
4. 返回`winner + 1`从从零开始的索引转换为从一开始的索引。 

**为什么有效：** Josephus 递归确保在每一步`i`,`winner`正确表示圆圈中最后剩下的人的索引`i`。 通过迭代应用该公式，我们避免了递归堆栈开销并直接计算结果`n`。 

## Python 解决方案```python
class Solution:
    def findTheWinner(self, n: int, k: int) -> int:
        winner = 0  # zero-indexed winner
        for i in range(2, n + 1):
            winner = (winner + k) % i
        return winner + 1  # convert to 1-indexed
```对于一个人的基本情况，此实现将获胜者初始化为 0。 for 循环从 2 迭代到`n`，逐步建立获胜者以增加圆圈大小。 模运算确保尊重游戏的循环性质。 最后，我们根据问题的需要加 1 将结果转换为基于 1 的索引。 

## 解决方案```go
func findTheWinner(n int, k int) int {
    winner := 0
    for i := 2; i <= n; i++ {
        winner = (winner + k) % i
    }
    return winner + 1
}
```在 Go 中，方法是相同的。 唯一的区别是语法：我们使用`:=`用于变量初始化和`for i := 2; i <= n; i++`作为循环结构。 整数运算自然地处理模计算，而不用担心由于问题限制而导致的溢出。

 ## 边缘情况

 **单身朋友：** 如果`n = 1`，只有一个朋友，所以他们是赢家。 我们的算法自然地处理这个问题，因为从 2 到 n 的循环不会执行，我们返回`winner + 1 = 1`。 

**步长为一：** 当`k = 1`，消除是连续的，总是删除圈子中的下一个朋友。 约瑟夫斯公式简化为`winner = (winner + 1) % i`，它正确地处理了这种线性消除。 

**步长等于朋友的数量：**如果`k = n`，每次消除都精确地算完整一圈。 迭代公式中的模运算可确保正确处理环绕计数，并且算法无需模拟每个步骤即可产生正确的获胜者。
