[LeetCode 问题 1807](https://leetcode.com/problems/evaluate-the-bracket-pairs-of-a-string/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串

 ## 解决方案

 ## 问题理解

 问题要求我们处理一个字符串`s`包含括号内的键，例如`(name)`或者`(age)`并将它们替换为中提供的相应值`knowledge`大批。 的每个元素`knowledge`是一个二元素数组`[key, value]`将键映射到其替换值。 如果输入一个键`s`不存在于`knowledge`，它必须替换为`"?"`。 

我们保证括号格式正确（每个`'('`有对应的`')'`)，没有嵌套括号，并且每个键在`knowledge`是独一无二的。 长度为`s`可以达到`10^5`， 和`knowledge`最多可以有`10^5`条目。 这表明任何需要重复扫描的解决方案`s`或者`knowledge`每次更换都会太慢。 该问题强调潜在大量输入的效率和正确性。 

主要观察结果是键始终非空，并且仅替换括号内的字符。 括号外的字符保持不变。 边缘情况包括不存在的键`knowledge`、同一键多次出现以及连续的括号对。 

## 方法

 暴力方法会迭代字符串，每当遇到括号内的键时，就会扫描`knowledge`线性数组来查找匹配值。 虽然这可以正常工作，但效率很低，因为扫描`knowledge`每次都可能导致`O(n * m)`时间复杂度，其中`n`的长度是`s`和`m`是键的数量`knowledge`。 对于最大的输入，此方法可能需要长达`10^10`的操作，这是不可行的。 

最佳方法利用哈希图来存储`knowledge`用于恒定时间查找。 当我们迭代时`s`，我们在括号内时逐个字符地构建键。 遇到右括号时，我们将括号内的键替换为哈希映射中的值或`"?"`如果密钥不存在。 这确保了单次传递`s`每个键的查找时间为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(1) | O(1) | 扫描字符串并线性搜索`knowledge`对于每个键|
 | 最佳 | O(n + m) | O(米) | 使用哈希映射查找键的单遍 |

 ## 算法演练

 1. 转换`knowledge`二维数组转换为字典/哈希映射`key_to_value`将每个键映射到其值。 这允许恒定时间查找替换。 
2.初始化一个空列表`result`有效地构建输出字符串和空字符串`current_key`在迭代时累积键的字符。 
3. 迭代每个字符`c`在字符串中`s`。 

一个。 如果`c`是`'('`，开始将字符累积到`current_key`。 

b. 如果`c`是`')'`，它表示一个键的结束。 从中检索其值`key_to_value`或者`"?"`如果缺少，请将其附加到`result`，并重置`current_key`。 

c. 如果`c`是一个普通字符，我们不在括号内，直接将其附加到`result`。 
4. 迭代结束后，加入`result`列表成单个字符串并返回它。 

**为什么有效：** 该算法保持了以下不变式：`result`包含直到当前字符的完整评估字符串。 通过使用哈希映射进行键查找，可以正确且高效地替换每个键。 使用单次传递可确保最佳性能，而不会丢失任何字符或键。 

## Python 解决方案```python
from typing import List

class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        key_to_value = {k: v for k, v in knowledge}
        result = []
        current_key = []
        inside_bracket = False
        
        for c in s:
            if c == '(':
                inside_bracket = True
                current_key = []
            elif c == ')':
                inside_bracket = False
                key_str = ''.join(current_key)
                result.append(key_to_value.get(key_str, '?'))
            elif inside_bracket:
                current_key.append(c)
            else:
                result.append(c)
                
        return ''.join(result)
```在这个实现中，我们首先转换`knowledge`转换为 O(1) 查找的哈希映射。 我们迭代`s`一次。 当在括号内时，字符会累积到`current_key`。 遇到时`')'`，我们在哈希映射中查找键并附加值（或`"?"`） 到`result`。 括号外的字符直接附加。 使用列表`result`是高效的，因为在 Python 中重复字符串连接在最坏的情况下是 O(n^2)。 

## 解决方案```go
func evaluate(s string, knowledge [][]string) string {
    keyToValue := make(map[string]string, len(knowledge))
    for _, kv := range knowledge {
        keyToValue[kv[0]] = kv[1]
    }

    var result []byte
    var currentKey []byte
    insideBracket := false

    for i := 0; i < len(s); i++ {
        c := s[i]
        if c == '(' {
            insideBracket = true
            currentKey = currentKey[:0]
        } else if c == ')' {
            insideBracket = false
            keyStr := string(currentKey)
            if val, ok := keyToValue[keyStr]; ok {
                result = append(result, val...)
            } else {
                result = append(result, '?')
            }
        } else if insideBracket {
            currentKey = append(currentKey, c)
        } else {
            result = append(result, c)
        }
    }

    return string(result)
}
```在 Go 中，我们使用`[]byte`用于高效的字符串构建。 该逻辑反映了 Python 解决方案。`currentKey`累积括号内的字符，并且`result`构建输出。 哈希图`keyToValue`提供恒定时间的查找。 边缘情况，例如丢失钥匙，可以用`"?"`替代品。
