 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、设计、Trie

 ## 解决方案

 ## 问题理解

 这个问题要求我们实现一个**Trie**数据结构，也称为**前缀树**，它旨在以允许快速查找和前缀查询的方式高效地存储字符串。 我们需要执行以下操作：

 1.`insert(word)`：向特里树添加一个单词。 
2.`countWordsEqualTo(word)`：计算一个单词在 trie 中出现的次数。 
3.`countWordsStartingWith(prefix)`：计算 trie 中有多少个单词以给定的前缀开头。 
4.`erase(word)`：从 trie 中删除一个单词的出现。 

输入由按顺序应用的多个运算组成，输出是计数运算的结果。 约束告诉我们单词和前缀的长度最多可达 2000 个字符，并且我们最多可能会收到 30,000 个操作。 这意味着暴力字符串扫描会太慢，尤其是对于前缀计数。 我们保证任何消息都会传递给`erase`存在于 trie 中，因此我们不需要处理删除不存在的单词。 

可能导致幼稚实现失败的边缘情况包括多次插入相同的单词、删除作为其他单词前缀的单词以及对具有长前缀的单词进行计数。 

## 方法

 **暴力方法**会将所有单词存储在列表或哈希映射中。 为了`insert`，我们附加这个词。 为了`countWordsEqualTo`，我们扫描整个集合以计算完全匹配的数量。 为了`countWordsStartingWith`，我们扫描整个集合并检查前缀。 擦除单词需要扫描第一个出现的单词并将其删除。 虽然简单，但这种方法效率低下：计数操作需要 O(N * L) 时间，其中 N 是字数，L 是字长。 

**最佳方法**使用带有子字典的 trie 节点。 每个节点存储两个计数器：`countEnd`对于以此节点结尾的单词和`countPrefix`对于通过该节点的单词。 这允许所有操作（插入、计数、擦除）在 O(L) 时间内运行，其中 L 是字长。 即使对于 N 大且长的字，这也是有效的，因为操作仅取决于字长，而不取决于存储的字的总数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N * L) | O(N * L) | 扫描整个集合的计数； 对于大 N 来说太慢 |
 | 最佳 | O(L) | O(N * L) | 使用带有计数器的 trie 节点； 快速插入、删除和前缀查询|

 ## 算法演练

 1. **Trie节点结构**：每个节点包含一个将字符映射到子节点的字典，一个整数`countEnd`表示有多少个单词在此节点结束，以及一个整数`countPrefix`表示有多少个单词经过该节点。 
2. **插入操作**：从根节点开始。 对于单词中的每个字符，如果不存在则创建一个子节点，然后递增`countPrefix`。 处理完所有字符后，递增`countEnd`在最后一个节点。 
3. **计数等于的单词**：从根节点开始，根据每个字符进行遍历。 如果children中不存在某个字符，则返回0。遍历完后，返回`countEnd`在最后一个节点。 
4. **统计以**开头的单词：与精确单词计数类似，遍历前缀的字符。 如果缺少任何字符，则返回 0。否则，返回`countPrefix`在最后一个节点。 
5. **擦除操作**：像插入一样遍历trie，递减`countPrefix`在每个节点。 在最后一个节点，递减`countEnd`。 这可确保仅删除该单词的一个实例并保持正确的前缀计数。 

**为什么有效**：trie 维护了以下不变式：`countPrefix`每个节点处的单词总数等于通过该节点的单词总数，并且`countEnd`等于以该节点结尾的单词数。 这个不变量保证了计数和擦除操作正确进行。 

## Python 解决方案```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.countEnd = 0
        self.countPrefix = 0

class Trie:

    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
            node.countPrefix += 1
        node.countEnd += 1

    def countWordsEqualTo(self, word: str) -> int:
        node = self.root
        for char in word:
            if char not in node.children:
                return 0
            node = node.children[char]
        return node.countEnd

    def countWordsStartingWith(self, prefix: str) -> int:
        node = self.root
        for char in prefix:
            if char not in node.children:
                return 0
            node = node.children[char]
        return node.countPrefix

    def erase(self, word: str) -> None:
        node = self.root
        nodes_on_path = [node]
        for char in word:
            node = node.children[char]
            nodes_on_path.append(node)
        nodes_on_path[-1].countEnd -= 1
        for i, char in enumerate(word, 1):
            nodes_on_path[i].countPrefix -= 1
```**解释**：`TrieNode`类封装了子级和计数器。 这`insert`函数确保添加所有字符并更新前缀计数。 计数操作遍历 trie 并返回适当的计数器。 擦除遵循单词路径，减少计数而不完全删除节点，这避免破坏共享前缀的其他单词。 

## 解决方案```go
type TrieNode struct {
	children    map[rune]*TrieNode
	countEnd    int
	countPrefix int
}

type Trie struct {
	root *TrieNode
}

func Constructor() Trie {
	return Trie{root: &TrieNode{children: make(map[rune]*TrieNode)}}
}

func (this *Trie) Insert(word string) {
	node := this.root
	for _, char := range word {
		if node.children[char] == nil {
			node.children[char] = &TrieNode{children: make(map[rune]*TrieNode)}
		}
		node = node.children[char]
		node.countPrefix++
	}
	node.countEnd++
}

func (this *Trie) CountWordsEqualTo(word string) int {
	node := this.root
	for _, char := range word {
		if node.children[char] == nil {
			return 0
		}
		node = node.children[char]
	}
	return node.countEnd
}

func (this *Trie) CountWordsStartingWith(prefix string) int {
	node := this.root
	for _, char := range prefix {
		if node.children[char] == nil {
			return 0
		}
		node = node.children[char]
	}
	return node.countPrefix
}

func (this *Trie) Erase(word string) {
	node := this.root
	nodesOnPath := []*TrieNode{node}
	for _, char := range word {
		node = node.children[char]
		nodesOnPath = append(nodesOnPath, node)
	}
	nodesOnPath[len(nodesOnPath)-1].countEnd--
	for i, char := range word {
		nodesOnPath[i+1].countPrefix--
	}
}
```**说明**：Go 实现镜像了 Python 版本，其中`map[rune]*TrieNode`对于儿童。 片`nodesOnPath`跟踪节点以获得正确的前缀递减。 初始化需要显式`make(map[rune]*TrieNode)`以避免零映射分配。
