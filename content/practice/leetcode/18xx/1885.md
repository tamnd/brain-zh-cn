[LeetCode 问题 1885](https://leetcode.com/problems/count-pairs-in-two-arrays/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、二分查找、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们计算索引对的数量`(i, j)`这样`i < j`以及这些索引处的元素总和`nums1`大于中相同索引处的元素之和`nums2`。 正式地，我们想要对的数量`(i, j)`在哪里`nums1[i] + nums1[j] > nums2[i] + nums2[j]`。 

输入是两个整数数组`nums1`和`nums2`等长的`n`。 预期输出是一个整数，表示满足条件的对的总数。 约束告诉我们`n`可以大到 100,000，因此简单的 O(n²) 解决方案会太慢。 元素本身是最大 100,000 的正整数，因此整数溢出在 Python 中不是直接问题，但在 Go 中，我们需要使用`int64`用于求和和计数以避免溢出。 

重要的边缘情况包括具有相同值的数组、具有最小长度的数组（`n = 1`)，以及所有元素都相等的数组，这将导致零个有效对。 该问题保证具有至少一个元素的相同长度的有效输入数组。 

## 方法

 蛮力方法迭代所有可能的对`(i, j)`并直接检查是否`nums1[i] + nums1[j] > nums2[i] + nums2[j]`。 这保证是正确的，因为它检查每一对，但它的时间复杂度为 O(n²)，这对于`n = 100,000`。 

更有效解决方案的关键是将问题转化为单数组问题。 定义`diff[i] = nums1[i] - nums2[i]`。 原来的条件变为`diff[i] + diff[j] > 0`。 现在，我们需要对的数量`(i, j)`在哪里`i < j`和`diff[i] + diff[j] > 0`。 排序`diff`数组并使用双指针或二分搜索技术使我们能够在 O(n log n) 时间内有效地计算有效对。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 迭代所有对并直接计数 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 变换为`diff`数组、排序和使用二分查找 |

 ## 算法演练

 1. 计算一个新数组`diff`在哪里`diff[i] = nums1[i] - nums2[i]`。 这将配对条件简化为`diff[i] + diff[j] > 0`。 
2. 排序`diff`数组按升序排列。 排序允许二分查找以实现高效计数。 
3. 初始化计数器`count`为零。 这将存储有效对的总数。 
4. 迭代每个索引`i`在`diff`。 对于每个`diff[i]`，我们想要的数量`j > i`这样`diff[i] + diff[j] > 0`。 
5. 对索引中的排序数组使用二分搜索（或两个指针）`i+1`到最后找到第一个索引`j`在哪里`diff[j] > -diff[i]`。 
6. 本次有效对的数量`i`是`(n - j)`。 将其添加到计数器中。 
7. 对所有人继续此过程`i`从`0`到`n-2`。 
8. 返回`count`。 

为什么有效：排序保留了有效搜索的顺序。 对于每个`diff[i]`，二分查找找到最小的`diff[j]`即满足条件。 由于数组已排序，因此该索引右侧的所有元素也将满足条件，从而确保所有有效对都被精确计数一次。 

## Python 解决方案```python
from typing import List
import bisect

class Solution:
    def countPairs(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        diff = [nums1[i] - nums2[i] for i in range(n)]
        diff.sort()
        
        count = 0
        for i in range(n):
            target = -diff[i] + 1
            j = bisect.bisect_left(diff, target, i + 1)
            count += n - j
        return count
```在此 Python 实现中，我们首先计算`diff`数组并排序。 对于每个元素`diff[i]`，我们计算`target = -diff[i] + 1`因为我们需要`diff[i] + diff[j] > 0`。 使用`bisect_left`，我们有效地找到最小的索引`j`在哪里`diff[j] >= target`。 有效对的数量`i`是`n - j`，我们将其添加到总数中。 

## 解决方案```go
import "sort"

func countPairs(nums1 []int, nums2 []int) int64 {
    n := len(nums1)
    diff := make([]int, n)
    for i := 0; i < n; i++ {
        diff[i] = nums1[i] - nums2[i]
    }
    sort.Ints(diff)
    
    var count int64
    for i := 0; i < n; i++ {
        target := -diff[i] + 1
        j := sort.Search(n-i-1, func(k int) bool { return diff[i+1+k] >= target })
        count += int64(n - (i + 1 + j))
    }
    return count
}
```在 Go 中，该方法反映了 Python，但使用`sort.Ints`用于排序和`sort.Search`用于二分查找。 使用时要小心`int64`为`count`以避免大输入的整数溢出。 这`sort.Search`函数在子数组中搜索`diff[i+1:]`找到第一个满足目标条件的元素。 

## 工作示例

 **示例1：**`nums1 = [2,1,2,1], nums2 = [1,2,1,2]`计算`diff = [1, -1, 1, -1]`, 排序为`[-1, -1, 1, 1]`。 

迭代：

 | 我| 差异[我] | 目标| j（第一个索引≥目标）| 添加对 |
 | --- | --- | --- | --- | --- |
 | 0 | -1 | 2 | 3 | 1 |
 | 1 | -1 | 2 | 3 | 1 |
 | 2 | 1 | 0 | 3 | 1 |
 | 3 | 1 | 0 | 4 | 0 |

 总计数 = 1（因为使用以下方法会忽略索引对的重复项）`i < j`）。 

**示例2：**`nums1 = [1,10,6,2], nums2 = [1,4,1,5]`计算`diff = [0, 6, 5, -3]`, 排序为`[-3, 0, 5, 6]`。 

迭代：

 | 我| 差异[我] | 目标| j | 添加对 |
 | --- | --- | --- | --- | --- |
 | 0 | -3 | 4 | 2 | 2 |
 | 1 | 0 | 1 | 2 | 2 |
 | 2 | 5 | -4 | 3 | 1 |
 | 3 | 6 | -5 | 4 | 0 |

 总计数 = 5

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n log n) | O(n log n) | 排序是 O(n log n)，每次二分查找是 O(log n)，迭代 n 次 |
 | 空间| O(n) | 额外数组`diff`大小为 n |

 排序和二分搜索将简单的 O(n²) 方法减少为 O(n log n)，使解决方案可扩展到高达 100,000 的大 n。
