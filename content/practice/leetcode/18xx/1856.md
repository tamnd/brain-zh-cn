[LeetCode 问题 1856](https://leetcode.com/problems/maximum-subarray-min-product/)

 **难度：** 🟡 中等
 **主题：** 数组、堆栈、单调堆栈、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定整数数组的任何连续子数组的**最大最小乘积**`nums`。 子数组的 **min-product** 定义为该子数组中的**最小值乘以该子数组中所有元素的总和**。 我们被要求返回这个最大值模`10^9 + 7`。 

简单来说，给定`nums`，我们需要考虑**每个可能的连续子数组**，计算其总和，确定其最小值，将这两个数字相乘，并跟踪最大结果。 模运算仅适用于最终的最大值。 

输入`nums`最多可以有`10^5`元素，每个元素的大小为`10^7`。 这意味着任何检查所有子数组的**强力方法**都会太慢。 由于约束保证结果适合 64 位整数，因此如果使用 64 位整数，我们无需担心 Python 或 Go 中的中间溢出。 

重要的边缘情况包括：

 1. 长度为1的数组，其中子数组是数组本身。 
2. 所有元素都相等的数组，其中每个子数组具有相同的最小值。 
3. 具有严格递增或递减序列的数组，这会影响连续子数组中最小值可以延伸的距离。 

## 方法

 ### 蛮力

 暴力方法很简单：迭代所有可能的子数组，计算每个子数组的总和和最小值，计算最小乘积，然后更新最大值。 这是正确的，但效率低下。 计算所有子数组会得到 O(n^2) 个子数组，而计算每个子数组的最小值和总和则需要 O(n) 的简单方式。 这会导致最坏情况下的时间复杂度为 O(n^3)，这对于`n = 10^5`。 

### 最佳方法

 关键的见解是认识到该问题类似于**直方图中的最大矩形**问题。 我们不是最大化面积，而是最大化`min * sum`。 我们可以使用**单调递增堆栈**来确定每个元素的**该元素为最小值的子数组范围**。 一旦找到每个元素的左右边界，我们就可以使用**前缀和**有效地计算子数组和。 

这将问题简化为：

 1. 计算前缀和`nums`。 
2. 使用单调堆栈查找每个索引的**左侧第一个较小元素**和**右侧第一个较小元素**。 
3. 对于每个索引`i`,计算子数组的和`[left[i]+1, right[i]-1]`使用前缀和，乘以`nums[i]`，并更新最大值。 

此方法适用于 **O(n)** 时间和 **O(n)** 空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 显式检查每个子数组 |
 | 最佳| O(n) | O(n) | 单调栈+前缀和|

 ## 算法演练

 1. **计算前缀和**`nums`允许 O(1) 子数组求和查询。 这是这样做的`prefix[i] = prefix[i-1] + nums[i]`。 
2. **初始化单调递增堆栈**。 堆栈按元素值的递增顺序存储元素的索引。 
3. **迭代`nums`**：

 - 当当前元素小于栈顶元素时，弹出栈。 
- 弹出的索引对应于子数组的最小元素。 
- 左边界是新的堆栈顶部或`-1`如果堆栈为空。 
- 右边界是当前索引。 
- 使用前缀和计算这些边界之间的子数组的总和。 
- 更新最大最小乘积，如果`nums[popped] * subarray_sum`更大。 
4. **处理迭代后堆栈中的剩余元素**。 对于这些，右边界是数组的末尾。 
5. **返回模 10^9 + 7 的最大最小乘积**。 

**为什么有效**：每个元素都被视为子数组中的最小值，尽可能向左和向右延伸，而不会遇到更小的元素。 这保证了我们探索最大的子数组，其中每个数字恰好是最小值一次，从而产生正确的最大最小乘积。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxSumMinProduct(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        
        # Compute prefix sums
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + nums[i]
        
        stack = []
        max_product = 0
        
        for i in range(n):
            while stack and nums[stack[-1]] > nums[i]:
                idx = stack.pop()
                left = stack[-1] if stack else -1
                sub_sum = prefix[i] - prefix[left+1]
                max_product = max(max_product, nums[idx] * sub_sum)
            stack.append(i)
        
        while stack:
            idx = stack.pop()
            left = stack[-1] if stack else -1
            sub_sum = prefix[n] - prefix[left+1]
            max_product = max(max_product, nums[idx] * sub_sum)
        
        return max_product % MOD
```**说明**：前缀和数组允许 O(1) 子数组和查询。 堆栈确保我们有效地找到每个最小值的左边界和右边界。 每当弹出一个元素时，我们都会计算最小乘积，以保证每个元素都被视为可能的最大子数组的最小值。 

## 解决方案```go
func maxSumMinProduct(nums []int) int {
    const MOD int = 1e9 + 7
    n := len(nums)
    
    prefix := make([]int64, n+1)
    for i := 0; i < n; i++ {
        prefix[i+1] = prefix[i] + int64(nums[i])
    }
    
    stack := []int{}
    var maxProduct int64 = 0
    
    for i := 0; i < n; i++ {
        for len(stack) > 0 && nums[stack[len(stack)-1]] > nums[i] {
            idx := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            left := -1
            if len(stack) > 0 {
                left = stack[len(stack)-1]
            }
            subSum := prefix[i] - prefix[left+1]
            product := int64(nums[idx]) * subSum
            if product > maxProduct {
                maxProduct = product
            }
        }
        stack = append(stack, i)
    }
    
    for len(stack) > 0 {
        idx := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        left := -1
        if len(stack) > 0 {
            left = stack[len(stack)-1]
        }
        subSum := prefix[n] - prefix[left+1]
        product := int64(nums[idx]) * subSum
        if product > maxProduct {
            maxProduct = product
        }
    }
    
    return int(maxProduct % int64(MOD))
}
```**说明**：Go 版本镜像了 Python 逻辑，但使用`int64`用于中间计算以防止溢出。 切片及其长度取代了堆栈操作。 

## 工作示例

 **示例：nums = [1,2,3,2]**

 前缀和：`[0,1,3,6,8]`堆栈迭代：

 - i=0: 堆栈=[0]
 - i=1: 堆栈=[0,1]
 - i=2: 堆栈=[0,1,2]
 - i=3: nums[2]=3 > 2 → 弹出 2: left=1, sum=prefix[3]-prefix[2]=6-3=3 → Product=3_3=9

 nums[1]=2 ≤ 2 → 弹出 1: left=0, sum=prefix[3]-prefix[1]=6-1=5 → Product=2_5=10

 堆栈=[0,3]
 - 结束：pop 3：left=0，sum=prefix[4]-prefix[1]=8-1=7→product=2*7=14（最大）
 - 弹出0：左=-1，总和=前缀[4]-前缀[0]=8-0=8→乘积=1*8=8

 最大最小乘积 = 14

 类似的逐步执行适用于其他示例。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个元素最多被压入栈中和从栈中弹出一次。 前缀和计算为 O(n)。 |
 | 空间| O(n) | 栈最多可以容纳n个元素。 大小为 n+1 的前缀和数组。 |

 线性时间的产生是因为单调堆栈确保每个元素仅在弹出时才被考虑。 前缀和允许对子数组进行 O(1) 求和查询。
