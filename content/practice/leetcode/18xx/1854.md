[LeetCode 1854 题](https://leetcode.com/problems/maximum-population-year/)

 **难度：** 🟢简单
 **主题：** 数组、计数、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们根据出生年份和死亡年份列表确定人口最多的年份。 输入中的每个元素`logs`是一对`[birthi, deathi]`代表着包容性的生命起点`birthi`和独家结束于`deathi`。 换句话说，一个人从出生年份到死亡前一年都被认为是活着的。 输入规模适中，最多 100 人，年份范围从 1950 年到 2050 年，最大跨度为 101 年。 产出应该是人口达到最大的最早年份。 

需要注意的重要一点是，出生年份严格小于死亡年份，并且不可能超出 1950-2050 年范围。 边缘情况包括所有人都在同一年出生、人口在多年内达到峰值或出生和死亡连续时。 

## 方法

 **暴力方法**会模拟从 1950 年到 2050 年的每一年，通过迭代来计算当年有多少人活着。`logs`。 这保证了正确性，但涉及对每个人的所有年份进行迭代，导致时间复杂度为 O(101 * n)，由于限制较小，这里可以接受，但并不优雅。 

**更好的方法**使用前缀和或差数组技术。 我们可以记录人口的变化：每个出生年份增加，每个死亡年份减少。 然后，多年来的累计总和很快就能揭示出每年的人口数量。 此方法利用了年份范围较小的事实，允许 O(n + Y) 时间，其中 Y 是年数 (101)。 这种方法高效且易于实施。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 101) | O(1) | O(1) | 每年统计活着的人数|
 | 最优（前缀和）| O(n + 101) | 奥(101) | 跟踪人口变化并计算累计总和 |

 ## 算法演练

 1.初始化一个数组`population`大小 101（1950-2050 年）到零。 各指标`i`对应年份`1950 + i`。 
2. 迭代每个人的日志`[birth, death]`。 增量`population[birth - 1950]`加1表示新生和减量`population[death - 1950]`加 1 表示死亡（不包括）。 
3.初始化变量`max_population`到 0 和`earliest_year`到 1950 年。这些记录追踪当前的最高人口数量及其发生年份。 
4. 计算前缀和`population`。 对于每年，加上上一年的人口即可得到累计人口。 如果当前人口超过`max_population`， 更新`max_population`和`earliest_year`。 
5. 返回`earliest_year`结果。 

**为什么有效：** 通过记录人口增量和减量并计算累计总和，我们可以正确跟踪每年的存活人数。 达到最大人口的第一年自然是通过从 1950 年开始迭代来捕获的。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumPopulation(self, logs: List[List[int]]) -> int:
        population = [0] * 101  # Index 0 -> 1950, Index 100 -> 2050
        
        for birth, death in logs:
            population[birth - 1950] += 1
            population[death - 1950] -= 1
        
        max_population = 0
        earliest_year = 1950
        current_population = 0
        
        for i in range(101):
            current_population += population[i]
            if current_population > max_population:
                max_population = current_population
                earliest_year = 1950 + i
        
        return earliest_year
```该实现首先通过减去 1950 将年份转换为数组索引。它累积了`population`大批。 然后，通过从1950年开始扫描，计算累计人口并更新人口最多的最早年份。 

## 解决方案```go
func maximumPopulation(logs [][]int) int {
    population := make([]int, 101) // 1950-2050

    for _, log := range logs {
        birth, death := log[0], log[1]
        population[birth-1950]++
        population[death-1950]--
    }

    maxPop := 0
    earliestYear := 1950
    currentPop := 0

    for i := 0; i < 101; i++ {
        currentPop += population[i]
        if currentPop > maxPop {
            maxPop = currentPop
            earliestYear = 1950 + i
        }
    }

    return earliestYear
}
```在Go中，切片用于存储种群变化。 该实现与 Python 非常相似。 Go 需要显式切片初始化`make`，整数算术在这里是安全的，因为总体在合理的范围内。

 | 1970 | 2 |

 ## 边缘情况

 第一个边缘情况是所有人连续几年出生和死亡。 一个简单的算法可能会错误地将结束年份算作包含在内，但是使用`death - 1950`确保排他性。 第二种边缘情况是多年间具有相同的最大人口数； 该算法必须选择最早的，这是通过从 1950 年开始迭代来处理的。 第三种边缘情况是最小的可能输入，即单个人，基于数组的方法无需特殊条件即可自然处理。
