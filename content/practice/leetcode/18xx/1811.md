[LeetCode 1811 题](https://leetcode.com/problems/find-interview-candidates/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 问题是要求我们根据 LeetCode 竞赛中的表现来确定哪些用户有资格成为**面试候选人**。 我们提供了两张表：`Contests`和`Users`。 这`Contests`表列出了比赛 ID 以及每场比赛的金牌、银牌和铜牌获得者的用户 ID。 这`Users`表包含用户信息，包括`user_id`,`name`， 和`mail`。 

如果满足以下两个条件之一，则用户就有资格成为**面试候选人**：

 1. 用户在**连续三场或以上比赛**中赢得**任何奖牌**（金、银或铜牌）。 
2. 用户在**三项或以上不同的比赛**中赢得**金牌**（比赛不必是连续的）。 

任务是返回`name`和`mail`所有此类用户。 该问题保证竞赛 ID 是连续整数并且不会跳过任何 ID。 这使得使用 ID 上的算术来检测连续竞争变得更加简单。 边缘情况包括在非连续比赛中赢得奖牌的用户或在重叠的比赛中赢得多枚奖牌的用户。 

输出可以按任何顺序。 

## 方法

 **暴力方法**将迭代每个用户并检查每个可能的三元组竞赛，看看它们是否满足任一条件。 对于连续的比赛，我们需要跟踪每场比赛的奖牌获胜情况并检查长度为三的比赛，而对于金牌，我们将计算赢得的不同比赛的总数。 这种方法在逻辑上可行，但效率低下，因为它需要迭代每个用户的每种可能的竞赛组合，这对于大型数据集来说可能非常慢。 

**最佳方法**利用 SQL 功能更有效地处理这些情况：

 - 要检测**三场或更多比赛中的金牌**，我们可以按`user_id`并统计金牌数量。 
- 要检测**连续三场比赛中的任何奖牌**，我们可以“逆透视”`Contests`表中，每场比赛的每块奖牌都被表示为单独的一行。 然后我们可以分配一个行号，分区为`user_id`并排序`contest_id`，并使用窗口函数检查是否有任何三场比赛形成连续序列。 

这种方法减少了对嵌套循环的需求，并利用了 SQL 基于集合的操作和窗口函数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(u * c^3) | O(u * c^3) | O(c) | 为每个用户迭代所有三元组的比赛； 很慢|
 | 最佳 | O(c) | O(u * c) | 使用分组和窗口函数有效地检查条件 |

 ## 算法演练

 1. **Unpivot 奖牌**：改变`Contests`表转换为包含列的规范化形式`user_id`,`contest_id`， 和`medal_type`，因此每次比赛的每种奖牌类型都会成为单独的一行。 
2. **识别连续的奖牌**：使用窗口函数分配按以下划分的行号`user_id`并按以下顺序订购`contest_id`。 计算之间的差异`contest_id`以及检测连续序列的行号。 如果用户至少有三行差异相同，则意味着他在连续三场比赛中获得了奖牌。 
3. **确定金牌获得者**：分组`Contests`表格依据`gold_medal`并计算不同的比赛。 如果计数为 3 或更多，则用户符合此条件。 
4. **合并结果**：取步骤 2 和 3 中找到的两组用户的并集。 
5. **加入`Users`表**：检索`name`和`mail`对于所有符合资格的`user_id`s。 
6. **返回结果**：输出结果表`name`和`mail`列。 

**为什么有效**：该算法通过使用 SQL 窗口函数和聚合来正确识别满足任一条件的用户。 使用之间的差异来检测连续的比赛`contest_id`和行号，它形成连续序列的常数值。 金牌获得者通过简单的汇总来确定。 Union 确保我们捕获满足至少一个条件的所有用户。 

## Python 解决方案```python
import sqlite3

def find_interview_candidates():
    query = """
    WITH Medalists AS (
        SELECT contest_id, gold_medal AS user_id FROM Contests
        UNION ALL
        SELECT contest_id, silver_medal AS user_id FROM Contests
        UNION ALL
        SELECT contest_id, bronze_medal AS user_id FROM Contests
    ),
    Consecutive AS (
        SELECT user_id
        FROM (
            SELECT user_id, contest_id, contest_id - ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY contest_id) AS grp
            FROM Medalists
        ) t
        GROUP BY user_id, grp
        HAVING COUNT(*) >= 3
    ),
    GoldWinners AS (
        SELECT gold_medal AS user_id
        FROM Contests
        GROUP BY gold_medal
        HAVING COUNT(*) >= 3
    ),
    Candidates AS (
        SELECT user_id FROM Consecutive
        UNION
        SELECT user_id FROM GoldWinners
    )
    SELECT u.name, u.mail
    FROM Users u
    JOIN Candidates c ON u.user_id = c.user_id;
    """
    return query
```**说明**：首先，`Medalists`CTE 使`Contests`表，因此每枚奖牌都是单独的一行。`Consecutive`使用以下方法检测连续获得三枚或三枚以上奖牌的用户`ROW_NUMBER()`和差异技巧。`GoldWinners`查找至少拥有三枚金牌的用户。 这`Candidates`CTE 结合了这些用户。 最后，我们加入`Users`获取所需的详细信息。
