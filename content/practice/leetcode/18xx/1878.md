 **难度：** 🟡 中等
 **主题：** 数组、数学、排序、堆（优先级队列）、矩阵、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定中最大的三个不同的**菱形和**`m x n`整数网格。 在这种情况下，菱形是旋转 45 度的正方形，其角与网格单元对齐。 **菱形总和**仅包括该形状的边界单元，而不包括内部。 菱形的“大小”可以为 0，这意味着它由单个单元格组成，这是有效的。 

输入是一个二维整数列表，`grid`， 在哪里`grid[i][j]`代表行的值`i`和列`j`。 输出是最多三个整数的列表，代表最大的**不同**菱形和，按降序排列。 

约束表明网格大小适中（`1 <= m, n <= 50`）并且每个单元格值为正（`1 <= grid[i][j] <= 10^5`）。 这使得暴力枚举对于小菱形尺寸是可行的，但我们需要一种有效的方法来处理网格边界附近的较大菱形形状。 边缘情况包括对于大菱形来说太小的网格、所有值都相同的网格以及只有一行或一列的网格。 

## 方法

 **暴力方法：**

 最简单的方法是考虑每个可能的中心单元`(i, j)`以及适合网格边界的每个可能的菱形尺寸。 对于每个菱形，我们通过沿着四个边行走手动对边界单元求和。 然后，我们将维护一组菱形和以确保不同的值。 这种方法工作正常，但效率低下，因为菱形的数量大致增长为`O(m * n * min(m, n))`，并对每个菱形边界求和需要`O(size)`运营。 对于一个`50x50`网格，这可能会变得昂贵。 

**最佳方法：**

 我们可以通过注意到菱形边框可以总结为**四个线性段**（右上、左上、左下、右下）来进行优化。 我们迭代所有有效的中心`(i, j)`以及所有适合的尺寸。 对于每个菱形，我们通过直接沿着这四个边行走来计算总和，这减少了冗余计算。 集合跟踪不同的总和，我们最终通过按降序排序提取前三个总和。 该方法利用小网格尺寸和直接计算来提高效率。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n * 分钟(m, n)^2) | O(m * n) | 枚举所有菱形中心和大小，手动对每个边界求和 |
 | 最佳| O(m * n * 分钟(m, n)) | O(m * n) | 使用沿四个边的线性遍历对菱形边界求和，存储在集合中，提取前三个 |

 ## 算法演练

 1.初始化一个空集`sums`存储不同的菱形和。 
2. 循环每个单元格`(i, j)`在网格中。 将此单元格视为潜在菱形的中心。 
3. 添加单格菱形和 (`grid[i][j]`) 到集合。 
4. 确定从该中心开始不超过网格边界的最大可能菱形尺寸。 
5. 对于每个有效尺寸`k > 0`，通过沿四个边迭代计算菱形边界和：右上、左上、左下、右下。 
6. 将计算出的菱形和添加到不同和的集合中。 
7. 处理完所有单元格和大小后，将集合转换为列表，按降序排序，并返回前三个值。 

**为什么有效：**

 该算法系统地枚举所有可能的菱形，没有冗余。 通过仅对边界求和，它尊重问题的定义。 使用集合可确保总和不同，排序可确保降序排列。 该算法涵盖所有​​有效的菱形尺寸，包括单细胞（尺寸 0）的情况。 

## Python 解决方案```python
from typing import List

class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        sums = set()
        
        for i in range(m):
            for j in range(n):
                # Single cell rhombus
                sums.add(grid[i][j])
                
                # Maximum possible rhombus size
                max_k = min(i, m-1-i, j, n-1-j)
                
                for k in range(1, max_k+1):
                    rhombus_sum = 0
                    # Top-right edge
                    for t in range(k):
                        rhombus_sum += grid[i-t][j+t]
                    # Bottom-right edge
                    for t in range(k):
                        rhombus_sum += grid[i-t+k][j+t+k]
                    # Bottom-left edge
                    for t in range(k):
                        rhombus_sum += grid[i+k-t][j+k+t]
                    # Top-left edge
                    for t in range(k):
                        rhombus_sum += grid[i+k-t][j-t]
                    
                    # Remove double-counted corners
                    rhombus_sum -= grid[i][j]
                    rhombus_sum -= grid[i-k][j+k]
                    rhombus_sum -= grid[i+k][j+k]
                    rhombus_sum -= grid[i+k][j-k]
                    
                    sums.add(rhombus_sum)
        
        return sorted(sums, reverse=True)[:3]
```**实施注意事项：**

 该代码首先将所有单格菱形和相加。 对于每个尺寸`k`，它沿着四个边行走，对值求和。 在边缘求和中，角点被访问两次，因此将它们减去一次以校正总数。 最后，集合确保总和不同，排序给出所需的降序。 

## 解决方案```go
func getBiggestThree(grid [][]int) []int {
    m, n := len(grid), len(grid[0])
    sums := map[int]struct{}{}
    
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            sums[grid[i][j]] = struct{}{}
            maxK := min(min(i, m-1-i), min(j, n-1-j))
            for k := 1; k <= maxK; k++ {
                rhombusSum := 0
                for t := 0; t < k; t++ {
                    rhombusSum += grid[i-t][j+t]
                }
                for t := 0; t < k; t++ {
                    rhombusSum += grid[i-t+k][j+t+k]
                }
                for t := 0; t < k; t++ {
                    rhombusSum += grid[i+k-t][j+k+t]
                }
                for t := 0; t < k; t++ {
                    rhombusSum += grid[i+k-t][j-t]
                }
                // Remove double-counted corners
                rhombusSum -= grid[i][j]
                rhombusSum -= grid[i-k][j+k]
                rhombusSum -= grid[i+k][j+k]
                rhombusSum -= grid[i+k][j-k]
                
                sums[rhombusSum] = struct{}{}
            }
        }
    }
    
    distinct := []int{}
    for val := range sums {
        distinct = append(distinct, val)
    }
    sort.Sort(sort.Reverse(sort.IntSlice(distinct)))
    if len(distinct) > 3 {
        return distinct[:3]
    }
    return distinct
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```**Go 特定注释：**

 Go 使用映射作为集合，使用切片作为排序列表。 算法逻辑镜像Python版本。 通过计算注意避免索引越界`maxK`。 通过减去重复计算的值来校正角点。
