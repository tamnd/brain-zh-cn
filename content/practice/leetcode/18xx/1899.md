[LeetCode 问题 1899](https://leetcode.com/problems/merge-triplets-to-form-target-triplet/)

 **难度：** 🟡 中等
 **主题：** 数组、贪心

 ## 解决方案

 ## 问题理解

 问题询问是否可以创建特定的**目标三元组**`[x, y, z]`通过使用**组件方式最大操作**重复合并三元组对，作为给定的**三元组**列表的元素。 每个三元组是三个整数的列表，表示沿三个维度的值。 该操作允许我们选择任意两个三元组`i`和`j`并更新`triplets[j]`到`[max(ai, aj), max(bi, bj), max(ci, cj)]`。 

输入由二维整数数组组成`triplets`尺寸可达`10^5`和一个`target`三号的三联体。 输出是一个布尔值：`true`如果目标可以在任意次数的操作之后显示为元素，并且`false`否则。 

要点包括：

 - 三元组中的每个数字都在 1 到 1000 之间，因此我们不需要担心负数或零。 
- 三元组可以多次更新，但仅通过采用 **max** 组件方式才允许更新。 
- 对于一个数字`target`要出现在最终结果中，必须至少存在一个三元组`triplets`其中相应的分量**小于或等于**目标分量（没有三元组可以“减少”分量）。 

重要的边缘情况：

 - 如果有任何组件`target`小于所有可用的相应组件`triplets`，无法获得目标。 
- 如果`triplets`已经包含目标，函数应该立即返回`true`。 
- 如果所有三元组至少有一个分量在错误的维度上超过目标，则合并无法减少该值，因此目标是不可能的。 

## 方法

 ### 蛮力

 一种简单的方法是模拟三元组对之间所有可能的合并操作。 在每一步中，我们都会尝试两个三元组的每一种组合，并根据组件的最大值更新一个组合。 我们将继续，直到没有发生进一步的变化，然后检查目标是否存在于`triplets`。 

这种方法是正确的，因为它探索了所有可能的结果，但对于大量输入来说**太慢**。 高达`10^5`三元组，模拟每一对都需要`O(n^2)`每个合并步骤的操作，这是不可行的。 

### 最佳洞察力

 关键的观察是**我们只关心实现组件方面的目标**。 任何一个分量超过相应目标分量的三元组对于在该维度形成目标都是无用的，因为`max`永远不会减少值。 因此，我们只需要找到**有效候选**的三元组（所有组件≤目标），并检查对于每个维度，合并时是否存在一个**与目标完全匹配**的三元组。 

通过跟踪目标的哪些组件可以被有效三元组“覆盖”，我们可以确定是否最终可以形成所有三个组件，而无需模拟所有合并操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每个合并步骤 O(n^2) | O(n) | 模拟每个可能的合并操作，直到收敛。 对于 n = 10^5 来说太慢了。 |
 | 最佳| O(n) | O(1) | O(1) | 跟踪仅使用有效三元组即可到达目标的组件。 简单的线性扫描就足够了。 |

 ## 算法演练

 1.初始化布尔数组`found = [False, False, False]`跟踪是否可以获得目标的每个组件。`found[0]`对应于`target[0]`， 等等。 
2. 迭代中的每个三元组`triplets`。 
3. 对于每个三元组，检查它是否**有效**。 如果 ** 所有组件都 ≤ 中的相应组件，则三元组是有效的`target`**。 如果任何组件超过目标，请忽略此三元组，因为它无法帮助形成目标。 
4. 对于有效的三元组，请检查每个组件。 如果某个组件与目标匹配，则标记相应的`found`条目为`True`。 
5. 扫描完所有三元组后，检查是否所有条目都在`found`是`True`。 如果是，则返回`True`; 否则，返回`False`。 

**为什么有效：**

 目标的每个分量可以通过合并有效且该分量等于目标的三元组来形成。 因为合并操作取最大值，所以一旦我们有了一个具有正确组件的三元组，我们就可以通过合并将其传播以形成完整的目标三元组。 有效的三元组在任何维度上都不会超过目标，因此合并它们不会使目标组件无效。 

## Python 解决方案```python
from typing import List

class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        found = [False, False, False]
        
        for triplet in triplets:
            if all(triplet[i] <= target[i] for i in range(3)):
                for i in range(3):
                    if triplet[i] == target[i]:
                        found[i] = True
                        
        return all(found)
```**说明：**

 该代码初始化一个`found`数组来跟踪哪些目标组件是可实现的。 它迭代每个三元组，检查它是否有效。 对于有效的三元组，任何等于目标的分量都会被标记`True`。 最后，如果找到所有组件，则可以形成目标。 

## 解决方案```go
func mergeTriplets(triplets [][]int, target []int) bool {
    found := [3]bool{}

    for _, triplet := range triplets {
        valid := true
        for i := 0; i < 3; i++ {
            if triplet[i] > target[i] {
                valid = false
                break
            }
        }
        if valid {
            for i := 0; i < 3; i++ {
                if triplet[i] == target[i] {
                    found[i] = true
                }
            }
        }
    }

    return found[0] && found[1] && found[2]
}
```**Go 特定注释：**

 为了简单起见，我们使用固定大小的布尔数组而不是切片。 这`valid`flag 确保我们跳过超过目标的三元组。 逻辑与 Python 版本完全一致。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 全部迭代一次`n`三元组，每个检查三个组件。 |
 | 空间| O(1) | O(1) | 恒定的额外空间`found`数组和临时变量。 |

 线性时间复杂度是最佳的，因为我们必须至少查看每个三元组一次。 空间是恒定的，因为我们不需要额外的结构来扩展`n`。
