[LeetCode 问题 1876](https://leetcode.com/problems/substrings-of-size- Three-with-distinct-characters/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、滑动窗口、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们计算有多少个长度恰好为 3 的子串仅包含不同的字符。 子字符串是字符串的连续部分，因此对于字符串中的每个位置，我们可以检查接下来的三个连续字符并确定这三个字符是否不同。 

例如，在字符串中`"xyzzaz"`，长度为 3 的可能子串为：

 -`"xyz"`-`"yzz"`-`"zza"`-`"zaz"`仅有的`"xyz"`包含三个独特的字符，所以答案是`1`。 

输入是单个字符串`s`仅由小写英文字母组成。 字符串的长度介于`1`和`100`，这是非常小的。 即使相对低效的方法在限制范围内也能顺利工作。 然而，该问题旨在测试对子串遍历和简单滑动窗口技术的理解。 

预期的输出是一个整数，表示有多少个大小为“好”的子字符串，这意味着子字符串中不会出现重复的字符。 

尽早识别一些边缘情况很重要：

 - 如果字符串长度小于`3`，不存在大小为 3 的有效子串，因此答案必须是`0`。 
- 像这样的子字符串`"aaa"`不好，因为所有字符都重复。 
- 像这样的子字符串`"aba"`也无效，因为该字符`'a'`appears twice.
 - Multiple identical good substrings should all be counted separately. 例如，`"abcabc"`包含`"abc"`两次，并且两次出现都算在内。 

## 方法

 ### 蛮力方法

 蛮力方法单独检查每个长度为 3 的子串。 对于每个起始索引`i`，我们提取子串`s[i:i+3]`并检查其字符是否全部不同。 

验证独特性的一种直接方法是将三个字符放入一个集合中。 由于集合会自动删除重复项，因此如果集合大小等于，则子字符串是好的`3`。 

这种方法是正确的，因为长度为 3 的每个可能的子串都被检查一次，并且每个子串都是独立评估的。 

尽管该解决方案对于给定的约束已经足够有效，但它仍然重复创建临时子串和集合。 对于较大的窗口尺寸或较大的输入，这种重复的工作可能会变得效率较低。 

### 最优滑动窗口方法

 关键的观察结果是，我们关心的每个子字符串的固定大小恰好为 3。 我们可以直接比较当前窗口中的三个字符，而不是创建许多临时子字符串。 

如果满足以下条件，则长度为 3 的子串是合适的：

 -`s[i] != s[i+1]`-`s[i] != s[i+2]`-`s[i+1] != s[i+2]`这避免了创建额外的数据结构，并使解决方案保持极其轻量级。 

这被认为是一种滑动窗口方法，因为从概念上讲，我们在字符串上一次移动一个长度为 3 的固定大小窗口一个位置。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 使用临时集检查每个长度为 3 的子字符串 |
 | 最佳| O(n) | O(1) | O(1) | 在固定滑动窗口内使用直接字符比较 |

 ## 算法演练

 1.初始化一个计数器变量`good_count`到`0`。 该变量存储我们找到了多少个有效子字符串。 
2.从index开始遍历字符串`0`到`len(s) - 3`。 每个索引代表长度为三的子字符串的起始位置。 
3. 对于每个位置`i`，检查三个字符：

 -`s[i]`-`s[i + 1]`-`s[i + 2]`4. 通过执行成对比较来检查所有三个字符是否不同：

 -`s[i] != s[i + 1]`-`s[i] != s[i + 2]`-`s[i + 1] != s[i + 2]`5. 如果所有三个条件都为真，则递增`good_count`经过`1`。 
6. 继续将窗口向右滑动一位，直到检查完所有可能的大小为 3 的子串。 
7. Return`good_count`循环结束后。 

### 为什么它有效

 该算法之所以有效，是因为当窗口在字符串上滑动时，长度为 3 的每个子字符串都恰好出现一次。 成对比较保证窗口内没有两个字符是相等的。 由于长度为三的子字符串恰好包含三个位置，因此确认所有成对不等式足以证明所有字符都是不同的。 

## Python 解决方案```python
class Solution:
    def countGoodSubstrings(self, s: str) -> int:
        good_count = 0

        for i in range(len(s) - 2):
            if (
                s[i] != s[i + 1]
                and s[i] != s[i + 2]
                and s[i + 1] != s[i + 2]
            ):
                good_count += 1

        return good_count
```实现从初始化开始`good_count`，它跟踪有效子字符串的数量。 

循环从`0`到`len(s) - 3`，包含在内。 使用`range(len(s) - 2)`确保索引`i + 1`和`i + 2`始终保持有效。 

在循环内部，代码直接比较当前窗口中的三个字符。 如果所有比较都指示不同的字符，则该子字符串是好的，因此计数器加一。 

最后，该方法在处理完所有窗口后返回总计数。 

## 解决方案```go
func countGoodSubstrings(s string) int {
    goodCount := 0

    for i := 0; i < len(s)-2; i++ {
        if s[i] != s[i+1] &&
            s[i] != s[i+2] &&
            s[i+1] != s[i+2] {
            goodCount++
        }
    }

    return goodCount
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 由于Go中的字符串可以直接按字节索引，并且问题保证小写英文字母，因此字符访问直接且安全。 

不需要额外的数组、切片或映射。 该解决方案使用恒定的额外空间并且仅执行简单的字符比较。

 ## 边缘情况

 当输入字符串长度小于三时，会出现一种重要的边缘情况。 由于该问题需要大小正好为三的子字符串，因此不能存在有效的子字符串。 粗心的实现可能会尝试无效的索引操作。 循环条件`range(len(s) - 2)`在这种情况下自然会防止迭代，因此该方法正确返回`0`。 

另一个重要的情况是所有字符都相同，例如`"aaaaaa"`。 每个窗口都包含重复的字符，因此答案应保持为零。 成对比较检查正确地拒绝每个子字符串，因为至少有一个相等条件失败。 

更微妙的边缘情况涉及重叠的子字符串。 例如，`"abcdef"`包含`"abc"`,`"bcd"`,`"cde"`， 和`"def"`，所有这些都是有效的。 该实现一次正确地将窗口滑动一个位置，确保重叠窗口独立评估并单独计数。 

最后的边缘情况涉及重复的有效子字符串，例如`"abcabc"`。 虽然`"abc"`出现两次，问题表明必须对每次出现进行计数。 由于该算法按位置而不是按唯一子字符串值处理窗口，因此两次出现都正确包含在最终计数中。
