 **难度：** 🔴难
 **主题：** 数组、数学、二分查找、计数、枚举、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们计算整数除法结果的和，`floor(nums[i] / nums[j])`，对于每对元素`(i, j)`在给定数组中`nums`。 这里，`floor()`表示小于或等于除法结果的最大整数。 数组`nums`最多可以有`10^5`元素，每个元素也可以大到`10^5`。 由于对的总数是`n^2`，一个简单的计算可​​能会导致`10^10`的操作，这是不可行的。 

输入`nums`只是一个正整数列表。 预期输出是每对的所有下限除法的总和，模`10^9 + 7`。 此模数确保可以处理极大的总和而不会出现整数溢出。 

重要的边缘情况包括所有数字都相同的数组、只有一个元素的数组以及元素大小不同（可能会产生除法结果为零）的数组。 这些约束保证输入非空并且仅包含正整数，这简化了除以零的处理。 

## 方法

 蛮力方法很简单：迭代每一对`(i, j)`, 计算`floor(nums[i] / nums[j])`，并对结果求和。 这是正确的，因为它直接遵循问题定义，但对于输入限制来说太慢了，因为它需要`O(n^2)`运营。 

最佳方法利用了这样的观察：如果我们知道有多少元素落入特定范围，我们就可以计算`nums[i]`是分批合计而不是单独合计。 具体来说，对于固定的`nums[j] = x`，值`floor(nums[i] / x)`仅以倍数变化`x`。 如果我们预先计算每个数字的频率，我们可以有效地对范围内的贡献求和`nums[i]`而不是针对每个单独的元素。 

我们还可以使用前缀和或计数数组来快速计算有多少个数字落在给定的倍数范围内，这大大降低了时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 直接迭代所有对 |
 | 最佳| O(n * 最大数量) | O(最大数量) | 使用计数和前缀总和来批量贡献 |

 ## 算法演练

 1. 确定最大数量`maxNum`在`nums`定义计数频率的范围。 
2. 创建频率数组`count`尺寸的`maxNum + 1`， 在哪里`count[x]`存储多少次`x`出现在`nums`。 
3.构建前缀和数组`prefix`从频率数组，其中`prefix[i]`代表元素的数量`nums`小于或等于`i`。 
4. 初始化`result = 0`来累积总和。 
5. 对于每个`x`在`nums`，计算贡献`x`对于所有的倍数`x`最多`maxNum`。 对于给定的倍数`k*x`, 元素数量`nums[i]`在范围内`[k*x, (k+1)*x - 1]`贡献`k`到总和。 使用前缀数组可以快速计算有多少元素属于该范围。 
6. 将计算出的贡献添加到`result`，取模`10^9 + 7`。 
7. 返回`result`。 

**为什么有效：** 通过迭代每个数字的倍数并使用前缀和来有效地计算元素，该算法确保每对`(i, j)`没有多余的计算就被考虑在内。 每个数字的贡献由整数除法结果正确加权。 

## Python 解决方案```python
from typing import List

class Solution:
    def sumOfFlooredPairs(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        max_num = max(nums)
        count = [0] * (max_num + 1)
        
        for num in nums:
            count[num] += 1
        
        prefix = [0] * (max_num + 2)
        for i in range(1, max_num + 1):
            prefix[i] = prefix[i - 1] + count[i]
        
        result = 0
        for x in nums:
            k = 1
            while k * x <= max_num:
                left = k * x
                right = min(max_num, (k + 1) * x - 1)
                contribution = k * (prefix[right] - prefix[left - 1])
                result = (result + contribution) % MOD
                k += 1
        
        return result
```Python 实现首先计算每个数字的频率，然后构建前缀和。 对于每个元素，它对由该元素的倍数定义的范围内的贡献求和。 在每一步应用模数以防止溢出。 

## 解决方案```go
func sumOfFlooredPairs(nums []int) int {
    const MOD = 1_000_000_007
    maxNum := 0
    for _, num := range nums {
        if num > maxNum {
            maxNum = num
        }
    }

    count := make([]int, maxNum+1)
    for _, num := range nums {
        count[num]++
    }

    prefix := make([]int, maxNum+2)
    for i := 1; i <= maxNum; i++ {
        prefix[i] = prefix[i-1] + count[i]
    }

    result := 0
    for _, x := range nums {
        k := 1
        for k*x <= maxNum {
            left := k * x
            right := (k+1)*x - 1
            if right > maxNum {
                right = maxNum
            }
            contribution := k * (prefix[right] - prefix[left-1])
            result = (result + contribution) % MOD
            k++
        }
    }

    return result
}
```Go 实现反映了 Python 方法。 数组被初始化用于计数和前缀和。 请注意确保数组边界正确，并使用模来避免整数溢出。 

## 工作示例

 **示例 1：** nums = [2,5,9]

 1. 最大数量 = 9
 2. 计数 = [0,0,1,0,0,1,0,0,0,1]
 3. 前缀 = [0,0,1,1,1,2,2,2,2,3,3]
 4. 对于 x = 2：

 - k = 1: 范围 [2,3] → 贡献 = 1*(前缀[3]-前缀[1]) = 1*(1-0)=1
 - k = 2: 范围 [4,5] → 贡献 = 2*(前缀[5]-前缀[3]) = 2*(2-1)=2
 - k = 3: 范围 [6,7] → 贡献 = 3*(前缀[7]-前缀[5]) = 3*(2-2)=0
 - k = 4: 范围 [8,9] → 贡献 = 4*(前缀[9]-前缀[7]) = 4*(3-2)=4
 5. 对 x = 5 和 x = 9 重复，贡献总和 = 10

 **示例 2：** nums = [7,7,7,7,7,7,7]

 - 每个元素贡献 7 对，楼层划分为 1。总和 = 7*7 = 49

 ## 边缘情况

 **单元素数组：** 唯一的元素将自身分开，产生 1。这确保代码正确处理下限。 

**所有元素相等：** 每次除法都会得到 1，这很简单，但测试了重复值的求和。 

**最大值元素：**当元素位于`10^5`，代码必须处理大数而不超出数组边界或整数限制。 前缀和和模防止溢出
