[LeetCode 第 1818 题](https://leetcode.com/problems/minimum-absolute-sum-difference/)

 **难度：** 🟡 中等
 **主题：** 数组、二分搜索、排序、有序集

 ## 解决方案

 ## 问题理解

 该问题给出两个正整数数组，`nums1`和`nums2`，两者长度相等`n`。 目标是计算这些数组之间的**绝对差和**，即每个索引处的绝对差之和：`|nums1[i] - nums2[i]|`。 您可以替换**至多一个元素**`nums1`与任何其他元素`nums1`最小化这个总和。 结果必须按模返回`10^9 + 7`。 

简而言之，我们试图通过更改最多一个元素来使两个数组尽可能“接近”`nums1`，选择最优替换以减少绝对差异之和。 

约束表明`n`可以达到`10^5`和数组中的值最多`10^5`。 这意味着尝试每个索引的所有可能替换的简单解决方案将太慢，因为时间复杂度大约为 O(n²)。 

要考虑的重要边缘情况包括已经相等的数组、替换任何元素都不能显着减少总和的数组以及具有最大可能值的数组。 

## 方法

 ### 蛮力

 一个幼稚的方法是考虑替换中的每个元素`nums1`与中的所有其他元素`nums1`并计算所得的绝对和差。 您将跟踪所有替换中观察到的最小总和。 虽然正确，但这种方法的时间复杂度为 O(n²)，这对于`n = 10^5`。 它还使用 O(1) 额外空间，但时间成本占主导地位。 

### 最佳方法

 关键的观察结果是，对于每个`nums2[i]`, 中的最佳候选替换`nums1`是最接近的元素`nums2[i]`因为它最大限度地减少了`|nums1[j] - nums2[i]|`。 为了有效地找到它，我们可以对副本进行排序`nums1`并使用二分查找来找到最接近的元素`nums2[i]`。 对于每个指数，如果我们替换当前的指数，我们计算绝对差异的潜在改进`nums1[i]`与这个最接近的元素。 然后，我们取所有指数的最大改进，并将其从总和中减去。 

这种方法显着降低了复杂性，因为排序和二分搜索非常高效：排序需要 O(n log n)，对于每个索引，二分搜索需要 O(log n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 尝试每个元素的所有可能的替换 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对 nums1 进行排序并使用二分搜索来查找最接近的元素以最小化总和 |

 ## 算法演练

 1. 计算初始绝对和差，无需任何替换。 
2. 创建一个已排序的副本`nums1`促进高效的最接近值搜索。 
3. 初始化变量`max_improvement`跟踪通过更换单个元件可能实现的最大减少量。 
4. 对于每个索引`i`:

 a. 计算当前差值：`diff = |nums1[i] - nums2[i]|`。 

b. 对已排序的数据使用二分查找`nums1`找到最接近的元素`nums2[i]`。 

c. 如果用最接近的元素替换，则计算新的差异。 

d. 更新`max_improvement`如果差异比之前观察到的减少得更多。 
5. 减法`max_improvement`从初始总和得到最小可能总和。 
6. 返回模数结果`10^9 + 7`。 

**为什么有效：** 中的每个元素`nums2`独立地贡献总和，并且最多替换一个元素`nums1`意味着我们只需要找到最大化减少的单一替代品。 通过始终使用二分搜索选择最接近的候选者，我们保证了最佳的局部改进，并且检查所有索引确保找到全局最优值。 

## Python 解决方案```python
from bisect import bisect_left
from typing import List

class Solution:
    def minAbsoluteSumDiff(self, nums1: List[int], nums2: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums1)
        sorted_nums1 = sorted(nums1)
        
        total_diff = sum(abs(a - b) for a, b in zip(nums1, nums2))
        max_improvement = 0
        
        for i in range(n):
            original_diff = abs(nums1[i] - nums2[i])
            
            # Binary search for closest value to nums2[i]
            idx = bisect_left(sorted_nums1, nums2[i])
            closest_diff = original_diff
            
            if idx < n:
                closest_diff = min(closest_diff, abs(sorted_nums1[idx] - nums2[i]))
            if idx > 0:
                closest_diff = min(closest_diff, abs(sorted_nums1[idx - 1] - nums2[i]))
            
            max_improvement = max(max_improvement, original_diff - closest_diff)
        
        return (total_diff - max_improvement) % MOD
```该实现首先计算绝对差的初始总和。 然后，它对每个元素进行迭代，对排序后的副本使用二分搜索`nums1`找到可以最小化差异的最接近的替代品。`max_improvement`跟踪单次更换可能实现的最大减少量。 

## 解决方案```go
import (
    "sort"
    "math"
)

func minAbsoluteSumDiff(nums1 []int, nums2 []int) int {
    const MOD = 1_000_000_007
    n := len(nums1)
    sortedNums1 := append([]int(nil), nums1...)
    sort.Ints(sortedNums1)
    
    totalDiff := 0
    maxImprovement := 0
    
    for i := 0; i < n; i++ {
        originalDiff := int(math.Abs(float64(nums1[i] - nums2[i])))
        totalDiff += originalDiff
        
        idx := sort.SearchInts(sortedNums1, nums2[i])
        closestDiff := originalDiff
        
        if idx < n {
            d := int(math.Abs(float64(sortedNums1[idx] - nums2[i])))
            if d < closestDiff {
                closestDiff = d
            }
        }
        if idx > 0 {
            d := int(math.Abs(float64(sortedNums1[idx-1] - nums2[i])))
            if d < closestDiff {
                closestDiff = d
            }
        }
        improvement := originalDiff - closestDiff
        if improvement > maxImprovement {
            maxImprovement = improvement
        }
    }
    
    return (totalDiff - maxImprovement) % MOD
}
```Go 实现镜像了 Python 解决方案，使用内置排序和二分搜索。 我们明确地转换为`float64`使用时`math.Abs`并投射回`int`正确处理分歧。 计算逻辑`maxImprovement`并且应用模数保持不变。 

## 工作示例

 **示例1：**`nums1 = [1,7,5]`,`nums2 = [2,3,5]`初始差异：`[1,4,0]`，总和 = 5。 

对每个元素进行二分查找：

 - i = 0：最接近 2 的是 1 -> 改进 = 0
 - i = 1：最接近 3 的是 1 或 5 -> 最佳改进 = 4 - 2 = 2
 - i = 2：最接近 5 的是 5 -> 改进 = 0

 最大改进 = 2

 最小总和 = 5 - 2 = 3

 **示例2：**`nums1 = [2,4,6,8,10]`,`nums2 = [2,4,6,8,10]`初始差异：`[0,0,0,0,0]`，总和 = 0

 最大改进 = 0

 最小总和 = 0

 **示例3：**`nums1 = [1,10,4,4,2,7]`,`nums2 = [9,3,5,1,7,4]`初始差异：`[8,7,1,3,5,3]`，总和 = 27

 - i = 0：最接近 9 的是 10 -> 改进 = 8 - 1 = 7
 - i = 1：最接近 3 的是 4 -> 改进 = 7 - 1 = 6
 - i = 2：最接近 5 的是 4 -> 改进 = 1 - 1 = 0
 - ...

 最大改进 = 7

 最小总和 = 27 - 7 = 20
