[LeetCode 问题 1825](https://leetcode.com/problems/finding-mk-average/)

 **难度：** 🔴难
 **主题：**设计、队列、堆（优先级队列）、数据流、有序集

 ## 解决方案

 ## 问题理解

 该问题要求我们设计一种数据结构，该结构可以连续接收来自流的数字，并可以有效地计算称为 MKAverage 的特殊平均值。 

对于每个查询，我们只关心最新的`m`流中的元素。 来自那些`m`要素：

 1. 删除最小的`k`数字。 
2. 删除最大的`k`数字。 
3. 计算剩余平均值的下限`m - 2k`元素。 

如果少于`m`到目前为止已经插入了元素，结果一定是`-1`。 

挑战在于流是动态变化的。 每次添加新号码时，都会选择最后一个号码中最旧的号码`m`要素可能会从考虑中消失。 这意味着该结构的行为就像流上的滑动窗口。 

限制条件很大：

 -`m`可以达到`10^5`- 最多`10^5`执行操作

 一个简单的实现，重复对最后一个进行排序`m`每个查询的元素都会太慢。 

关键的困难是有效地维护三个组：

 - 最小的`k`元素
 - 中间`m - 2k`元素
 - 最大的`k`元素

 我们还需要支持：

 - 插入新元素
 - 删除旧元素
 - 快速检索中间部分总和

 重要的边缘情况包括：

 - 少于`m`插入的元素
 - 重复值
 - 发生插入/删除时元素在分区之间移动
 - 非常大的流，无法进行重复排序

 该问题保证：

 -`2k < m`，所以中间部分始终非空
 - 所有数字均为正整数
 - 如果每个操作近似对数，则操作数量是可控的

 ## 方法

 ### 蛮力方法

 最简单的方法是将所有流元素存储在队列中。 

每当`calculateMKAverage()`称为：

 1.取最后一个`m`元素。 
2. 对它们进行排序。 
3.删除第一个`k`最后`k`。 
4. 对剩余值求和。 
5. 返回楼层平均值。 

这是有效的，因为排序直接给出最小和最大元素。 

然而，时间复杂度太昂贵。 排序`m`要素成本`O(m log m)`每个查询。 由于最多可以有`10^5`操作，这变得不可行。 

### 最佳方法

 关键的观察是我们不需要从头开始重复对整个窗口进行排序。 

相反，我们维护最后一个`m`元素分为三个平衡的有序组：

 -`low`：最小的`k`元素
 -`mid`： 中间`m - 2k`元素
 -`high`：最大的`k`元素

 我们还维护：

 - 包含最后一个的队列`m`元素
 - 当前内部所有元素的总和`mid`当新元素到达时：

 1. 将其插入适当的组中。 
2. 如果窗口超出尺寸`m`，删除最旧的元素。 
3. 重新平衡组，使其大小保持有效。 

因为答案只取决于中间部分，保持`mid_sum`允许`calculateMKAverage()`跑进去`O(1)`时间。 

为了支持高效的插入/删除，同时保持排序顺序，我们使用平衡有序结构。 

在Python中，`sortedcontainers.SortedList`是理想的。 

在 Go 中，我们实现了 Treap 来支持对数运算。

 ## 算法演练

 ### 数据结构

 我们维持：

 - 存储最近的队列`m`元素
 -`low`，包含最小的有序集`k`元素
 -`mid`，包含中间元素的有序集合
 -`high`，包含最大的有序集`k`元素
 -`mid_sum`, 里面元素的总和`mid`### 分步过程

 1. 初始化数据结构。 

创建空的有序结构`low`,`mid`， 和`high`。 还初始化队列和`mid_sum`。 
2. 添加新元素。 

插入数字时：

 - 如果它属于最小值，则将其放入`low`- 否则，如果它属于最大值，则将其放入`high`- 否则将其放入`mid`每当一个元素进入或离开时`mid`， 更新`mid_sum`。 
3. 保持窗口大小。 

如果队列大小超过`m`，从当前包含它的组中删除最旧的元素。 
4. 重新平衡各组。 

插入/删除后，组大小可能会变得无效。 

我们反复重新平衡：

 - 如果`low`元素太多，将其最大元素移入`mid`- 如果`high`元素太多，将其最小元素移入`mid`- 如果`low`元素太少，移动最小的元素`mid`- 如果`high`元素太少，移动最大的元素`mid`每次传输都会更新`mid_sum`适当地。 
5. 计算MKAverage。 

如果少于`m`元素存在，返回`-1`。 

否则：$$\text{answer} = \left\lfloor \frac{\text{mid\_sum}}{m - 2k} \right\rfloor$$### 为什么它有效

 不变量是：

 -`low`总是恰好包含最小的`k`元素
 -`high`总是包含最大的`k`元素
 -`mid`包含所有剩余元素

 由于每次插入和删除后都会进行重新平衡，因此这些属性始终保持不变。 自从`mid_sum`跟踪中间部分的精确总和，除以`m - 2k`产生正确的 MKAverage。 

## Python 解决方案```python
from collections import deque
from sortedcontainers import SortedList

class MKAverage:

    def __init__(self, m: int, k: int):
        self.m = m
        self.k = k
        
        self.queue = deque()
        
        self.low = SortedList()
        self.mid = SortedList()
        self.high = SortedList()
        
        self.mid_sum = 0

    def _add_to_group(self, num: int) -> None:
        if not self.low or num <= self.low[-1]:
            self.low.add(num)
        elif not self.high or num >= self.high[0]:
            self.high.add(num)
        else:
            self.mid.add(num)
            self.mid_sum += num

    def _remove_from_group(self, num: int) -> None:
        if num in self.low:
            self.low.remove(num)
        elif num in self.high:
            self.high.remove(num)
        else:
            self.mid.remove(num)
            self.mid_sum -= num

    def _rebalance(self) -> None:
        while len(self.low) > self.k:
            value = self.low.pop(-1)
            self.mid.add(value)
            self.mid_sum += value

        while len(self.high) > self.k:
            value = self.high.pop(0)
            self.mid.add(value)
            self.mid_sum += value

        while len(self.low) < self.k and self.mid:
            value = self.mid.pop(0)
            self.mid_sum -= value
            self.low.add(value)

        while len(self.high) < self.k and self.mid:
            value = self.mid.pop(-1)
            self.mid_sum -= value
            self.high.add(value)

    def addElement(self, num: int) -> None:
        self.queue.append(num)

        self._add_to_group(num)
        self._rebalance()

        if len(self.queue) > self.m:
            old = self.queue.popleft()
            self._remove_from_group(old)
            self._rebalance()

    def calculateMKAverage(self) -> int:
        if len(self.queue) < self.m:
            return -1

        return self.mid_sum // (self.m - 2 * self.k)

# Your MKAverage object will be instantiated and called as such:
# obj = MKAverage(m, k)
# obj.addElement(num)
# param_2 = obj.calculateMKAverage()
```该实现维护三个排序分区。 

这`_add_to_group()`方法根据当前分区边界确定新插入的号码所属的位置。 

这`_remove_from_group()`方法从当前包含传出元素的分区中删除该元素。 

这`_rebalance()`方法是解决方案中最重要的部分。 它恢复了以下不变量：

 -`low`正好有`k`元素
 -`high`正好有`k`元素
 - 所有剩余元素保留在`mid`这`mid_sum`每当元素移入或移出时变量都会更新`mid`。 这允许在恒定时间内进行平均计算。 

队列确保我们始终知道哪个元素应该离开滑动窗口一次以上`m`元素已被插入。 

## 解决方案```go
package main

import (
	"container/list"
	"math/rand"
)

type Node struct {
	key      int
	priority int
	count    int
	size     int
	left     *Node
	right    *Node
}

func nodeSize(n *Node) int {
	if n == nil {
		return 0
	}
	return n.size
}

func update(n *Node) {
	if n != nil {
		n.size = n.count + nodeSize(n.left) + nodeSize(n.right)
	}
}

func rotateRight(y *Node) *Node {
	x := y.left
	y.left = x.right
	x.right = y
	update(y)
	update(x)
	return x
}

func rotateLeft(x *Node) *Node {
	y := x.right
	x.right = y.left
	y.left = x
	update(x)
	update(y)
	return y
}

func insert(root *Node, key int) *Node {
	if root == nil {
		return &Node{
			key:      key,
			priority: rand.Int(),
			count:    1,
			size:     1,
		}
	}

	if key == root.key {
		root.count++
	} else if key < root.key {
		root.left = insert(root.left, key)
		if root.left.priority > root.priority {
			root = rotateRight(root)
		}
	} else {
		root.right = insert(root.right, key)
		if root.right.priority > root.priority {
			root = rotateLeft(root)
		}
	}

	update(root)
	return root
}

func erase(root *Node, key int) *Node {
	if root == nil {
		return nil
	}

	if key < root.key {
		root.left = erase(root.left, key)
	} else if key > root.key {
		root.right = erase(root.right, key)
	} else {
		if root.count > 1 {
			root.count--
		} else {
			if root.left == nil {
				return root.right
			}
			if root.right == nil {
				return root.left
			}

			if root.left.priority > root.right.priority {
				root = rotateRight(root)
				root.right = erase(root.right, key)
			} else {
				root = rotateLeft(root)
				root.left = erase(root.left, key)
			}
		}
	}

	update(root)
	return root
}

func getMin(root *Node) int {
	for root.left != nil {
		root = root.left
	}
	return root.key
}

func getMax(root *Node) int {
	for root.right != nil {
		root = root.right
	}
	return root.key
}

func contains(root *Node, key int) bool {
	if root == nil {
		return false
	}

	if key == root.key {
		return true
	}

	if key < root.key {
		return contains(root.left, key)
	}

	return contains(root.right, key)
}

type OrderedSet struct {
	root *Node
	size int
}

func (s *OrderedSet) Add(x int) {
	s.root = insert(s.root, x)
	s.size++
}

func (s *OrderedSet) Remove(x int) {
	s.root = erase(s.root, x)
	s.size--
}

func (s *OrderedSet) Min() int {
	return getMin(s.root)
}

func (s *OrderedSet) Max() int {
	return getMax(s.root)
}

func (s *OrderedSet) Contains(x int) bool {
	return contains(s.root, x)
}

func (s *OrderedSet) Len() int {
	return s.size
}

type MKAverage struct {
	m      int
	k      int
	queue  *list.List
	low    OrderedSet
	mid    OrderedSet
	high   OrderedSet
	midSum int64
}

func Constructor(m int, k int) MKAverage {
	return MKAverage{
		m:     m,
		k:     k,
		queue: list.New(),
	}
}

func (this *MKAverage) addToGroup(num int) {
	if this.low.Len() == 0 || num <= this.low.Max() {
		this.low.Add(num)
	} else if this.high.Len() == 0 || num >= this.high.Min() {
		this.high.Add(num)
	} else {
		this.mid.Add(num)
		this.midSum += int64(num)
	}
}

func (this *MKAverage) removeFromGroup(num int) {
	if this.low.Contains(num) {
		this.low.Remove(num)
	} else if this.high.Contains(num) {
		this.high.Remove(num)
	} else {
		this.mid.Remove(num)
		this.midSum -= int64(num)
	}
}

func (this *MKAverage) rebalance() {
	for this.low.Len() > this.k {
		val := this.low.Max()
		this.low.Remove(val)
		this.mid.Add(val)
		this.midSum += int64(val)
	}

	for this.high.Len() > this.k {
		val := this.high.Min()
		this.high.Remove(val)
		this.mid.Add(val)
		this.midSum += int64(val)
	}

	for this.low.Len() < this.k && this.mid.Len() > 0 {
		val := this.mid.Min()
		this.mid.Remove(val)
		this.midSum -= int64(val)
		this.low.Add(val)
	}

	for this.high.Len() < this.k && this.mid.Len() > 0 {
		val := this.mid.Max()
		this.mid.Remove(val)
		this.midSum -= int64(val)
		this.high.Add(val)
	}
}

func (this *MKAverage) AddElement(num int) {
	this.queue.PushBack(num)

	this.addToGroup(num)
	this.rebalance()

	if this.queue.Len() > this.m {
		front := this.queue.Front()
		old := front.Value.(int)
		this.queue.Remove(front)

		this.removeFromGroup(old)
		this.rebalance()
	}
}

func (this *MKAverage) CalculateMKAverage() int {
	if this.queue.Len() < this.m {
		return -1
	}

	return int(this.midSum / int64(this.m-2*this.k))
}

 ## 边缘情况

 当少于`m`元素已被插入。 有缺陷的实现可能会尝试在存在足够的元素之前计算平均值。 该解决方案在执行任何计算并返回之前显式检查队列长度`-1`立即地。 

另一个棘手的情况涉及重复值。 由于许多元素可能具有相同的值，因此使用普通集合会失败，因为重复项会合并为一个条目。 因此，两种实现都使用多集行为。 蟒蛇的`SortedList`自然支持重复项，而 Go Treap 则存储一个`count`重复值字段。 

当滑动窗口删除属于一个分区的元素时，会发生第三种重要的边缘情况，导致分区大小变得无效。 例如，删除中唯一的元素`low`需要从中拉出替代品`mid`。 重新平衡步骤可确保每次插入或删除后，所有分区都恢复其所需的大小。 

当所有值都相同时，会出现另一种微妙的情况。 在这种情况下，分区边界是不明确的，因为每个值的比较都是相等的。 该实现正确地处理了这个问题，因为平衡仅取决于分区大小，而不取决于严格的不平等区别。
