[LeetCode 问题 1824](https://leetcode.com/problems/minimum-sideway-jumps/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、贪心

 ## 解决方案

 ## 问题理解

 该问题描述了一只**青蛙在一条长度为 3 车道的道路**中行驶`n`。 青蛙从点开始`0`在**车道 2** 并想要到达点`n`。 道路上的每个点在三个车道之一中最多可以有一个障碍物，由`obstacles`大批。 如果没有障碍物，青蛙可以在同一车道上前进；如果目标车道没有障碍物，青蛙可以在同一点进行**侧跳**以切换到不同的车道。 

输入是一个数组`obstacles`长度`n + 1`， 在哪里`obstacles[i]`指示哪条车道在该点有障碍物`i`（`0`表示没有障碍）。 输出是青蛙在终点到达任意车道所需的**最小侧跳次数**`n`从车道 2 的点 0 开始。 

要点包括：

 - 青蛙总是从第 2 道、第 0 点开始。 
- 点 0 或 n 处永远不存在障碍物。 
- 如果车道畅通，青蛙可能会向前跳跃，如果被阻挡，青蛙可能会侧跳。 
- 每点只有一个障碍，确保我们永远不必同时考虑多个冲突。 

重要的边缘情况：

 -`obstacles`除第 2 车道以外的车道外，不包含任何障碍物； 青蛙可能不需要侧跳。 
- 障碍物可能会迫使玩家在早期点立即进行侧跳。 
- 非常大`n`高达 5 * 10^5 需要高效的 O(n) 解决方案。 

## 方法

 **暴力方法**是递归地模拟所有可能的青蛙运动。 在每个点，如果没有障碍物，青蛙都可以在当前车道上前进，或者跳到没有障碍物的任何其他车道。 这种方法会尝试所有组合，递归地探索所有侧面跳转。 这是正确的，但效率极低，因为状态数量呈指数增长`n`，使其不可行`n`最多 5 * 10^5。 

更好的解决方案的**关键观察**是我们可以跟踪**在每个点到达每个车道所需的最小侧跳**。 由于只有 3 条车道，我们可以使用动态编程甚至滚动数组来跟踪车道 1、2 和 3 在每个点的当前最小侧跳。 在每一步中，青蛙要么在没有阻碍的情况下在同一条车道上向前移动，要么计算侧跳到其他车道的最小值。 

这导致使用大小为 3 的简单 DP 数组实现 **O(n) 时间和 O(1) 空间解决方案**。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归探索所有可能的动作； 对于大 n 来说太慢 |
 | 最佳| O(n) | O(1) | O(1) | 使用大小为 3 的滚动 DP 数组跟踪每个车道的最小侧跳 |

 ## 算法演练

 1.初始化一个DP数组`dp`大小为 3，用于存储当前点在车道 1、2 和 3 处所需的最小侧跳。 由于青蛙从泳道 2 开始，`dp = [1, 0, 1]`。 这是因为从第 2 道开始需要 0 次跳跃，而在第 1 道或第 3 道开始时需要一侧跳跃。 
2. 迭代每个点`i`从 1 到`n`:

 a. 对于每条车道，如果该点有障碍物`i`， 放`dp[lane]`无穷大（或非常大的数字），因为该车道无法被占用。 

b. 标记堵塞车道后，检查每条车道`l`。 如果`dp[l]`没有被阻塞，将其更新为其当前值的最小值并且`dp[other_lane] + 1`对于另外两条车道。 这模拟了执行侧跳到达车道的可能性`l`。 
3.处理完所有点后，答案是中的最小值`dp`，代表在任何车道上到达终点所需的最小侧跳。 

**工作原理：** DP 数组始终保持最小侧跳次数以到达当前点的每个车道。 通过在每一步中更新可能的侧跳中的最小值，我们确保青蛙的路径是全局最优的。 滚动数组确保空间恒定，同时正确地向前传播最小跳跃。 

## Python 解决方案```python
from typing import List

class Solution:
    def minSideJumps(self, obstacles: List[int]) -> int:
        n = len(obstacles)
        # Initialize DP array: dp[lane] = min side jumps to reach current point in that lane
        dp = [1, 0, 1]  # lanes 1,2,3 at point 0

        for i in range(1, n):
            # Set blocked lanes to infinity
            for lane in range(3):
                if obstacles[i] == lane + 1:
                    dp[lane] = float('inf')
            
            # Update dp for non-blocked lanes using side jumps
            for lane in range(3):
                if obstacles[i] != lane + 1:
                    dp[lane] = min(dp[lane], min(dp[(lane + 1) % 3], dp[(lane + 2) % 3]) + 1)
        
        return min(dp)
```**说明：**初始化`[1,0,1]`占车道 2 的起始位置。对于每个点，阻塞的车道标记为`inf`。 然后，对于未阻塞的车道，我们考虑其他两条车道的侧跳来计算最小侧跳。 最终的答案是DP数组中的最小值。 

## 解决方案```go
import "math"

func minSideJumps(obstacles []int) int {
    n := len(obstacles)
    dp := []int{1, 0, 1} // lanes 1,2,3 at point 0

    for i := 1; i < n; i++ {
        for lane := 0; lane < 3; lane++ {
            if obstacles[i] == lane+1 {
                dp[lane] = math.MaxInt32
            }
        }
        for lane := 0; lane < 3; lane++ {
            if obstacles[i] != lane+1 {
                minSide := min(dp[(lane+1)%3], dp[(lane+2)%3]) + 1
                if dp[lane] > minSide {
                    dp[lane] = minSide
                }
            }
        }
    }
    return min(dp[0], min(dp[1], dp[2]))
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```**Go特定注释：** Go没有`inf`对于整数，所以我们使用`math.MaxInt32`标记封锁的车道。 我们使用 DP 数组的切片和辅助函数`min`以简化比较。
