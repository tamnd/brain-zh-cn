[LeetCode 问题 1859](https://leetcode.com/problems/sorting-the-sentence/)

 **难度：** 🟢简单
 **主题：** 字符串、排序

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个**打乱的句子**，其中每个单词的末尾都附加了一个数字。 该数字表示单词在句子中的原始位置，使用 **1 索引排序**。 

例如，这个词`"This1"`方法`"This"`最初出现的位置`1`， 尽管`"sentence4"`方法`"sentence"`最初出现的位置`4`。 

然后，句子中的单词被任意重新排列。 我们的任务是通过以下方式重建原始句子：

 1. 使用尾随数字确定单词的正确顺序。 
2. 删除每个单词中的数字。 
3. 用空格将单词重新连接在一起。 

输入是一个字符串`s`包含由单个空格分隔的单词。 每个单词由英文字母和其间的数字组成`1`和`9`。 

预期输出是重构的句子字符串，其中：

 - 单词按其原始顺序出现。 
- 删除附加的位置编号。 
- 单词之间用一个空格分隔。 

限制很小：

 -`s.length <= 200`- 至多`9`句子中存在单词。 
- 单词位置始终位于`1`和`9`。 

这些约束告诉我们问题的规模非常小。 即使效率较低的解决方案也能表现良好。 然而，我们的目标是编写一个干净且逻辑合理的解决方案。 

一个重要的保证是每个单词都有一个有效的尾随数字代表其唯一位置。 由于仓位保证存在且有效，因此我们不需要处理格式错误的输入。 

一些可能导致简单实施失败的边缘情况包括：

 - 只包含**一个单词**的句子，其中重构是微不足道的。 
- 单词以完全随机的顺序出现，需要完全重新排序。 
- 混合大小写字母的多字符单词，这意味着我们不能假设只有小写输入。 
- 确保我们正确地将**最后一个字符数字**与实际单词内容分开。 

## 方法

 ### 蛮力方法

 一种简单的暴力方法会重复搜索与位置相对应的单词`1`，然后定位`2`， 等等。 

我们可以将句子分成单词，然后对于每个预期位置`1`到`n`，扫描所有单词以查找最后一个字符与该位置匹配的单词。 找到后，删除该数字并将清理后的单词附加到结果中。 

这是有效的，因为每个单词都包含其确切的原始索引，保证我们可以正确地重建句子。 

然而，这种方法效率低下，因为对于每个位置，我们都会再次扫描整个单词列表。 如果有`n`换句话说，这会导致 **O(n²)** 时间复杂度。 

鉴于`n <= 9`，这种低效率实际上并没有什么害处，但我们可以做得更好。 

### 最佳方法

 关键的观察是最后一个数字直接告诉我们一个单词所属的位置。 

我们可以：

 1. 将句子拆分为单词。 
2. 创建一个大小的数组`n`。 
3. 对于每个单词：

 - 读取最后一个字符以获取其位置。 
- 删除尾随数字。 
- 将清理后的单词直接放入正确的索引中。 
4. 将数组连接到最后的句子中。 

这可以有效地工作，因为每个单词都只被处理一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复扫描每个位置的所有单词 |
 | 最佳| O(n) | O(n) | 将每个单词直接放置到正确的位置 |

 ## 算法演练

 1. 使用空格将输入句子拆分为单词列表。 

我们这样做是因为每个单词都包含其内容和排序数字。 单独处理单词使提取更容易。 
2. 创建一个元素数量与单词数量相同的结果数组。 

由于职位是`1-indexed`，我们需要一个地方来直接按照正确的顺序存储单词。 数组允许恒定时间放置。 
3. 迭代每个单词。 

对于每个单词：

 - 读取最后一个字符以确定单词的位置。 
- 将数字转换为整数。 
- 减法`1`因为 Python 和 Go 数组是`0-indexed`。 
- 从单词中删除最后一个字符以获得实际的文本。 
- 将清理后的单词存储在结果数组中的适当位置。 
4. 用空格连接已排序的单词。 

正确放置每个单词后，使用以下命令将它们组合成一个句子`" ".join(...)`在 Python 中或`strings.Join(...)`在围棋中。 

### 为什么它有效

 该算法的正确性来自于保证每个单词都包含其准确的原始位置作为唯一的尾随数字。 由于每个单词都被直接放入其索引位置一次，因此重建的数组必然代表原始句子顺序。 之后删除数字即可恢复原始单词文本。 

## Python 解决方案```python
class Solution:
    def sortSentence(self, s: str) -> str:
        words = s.split()
        ordered_words = [""] * len(words)

        for word in words:
            position = int(word[-1]) - 1
            ordered_words[position] = word[:-1]

        return " ".join(ordered_words)
```实现首先将句子分割成单独的单词。 由于每个单词末尾都包含其原始位置，因此我们创建一个名为的结果数组`ordered_words`以正确的顺序存储单词。 

然后我们迭代每个单词。 最后一个角色，`word[-1]`，包含位置数字。 将其转换为整数并减去后`1`，我们获得了正确的从零开始的索引。 

实际的单词文本是使用提取的`word[:-1]`，删除尾随数字。 我们将这个清理后的单词放入结果数组中的正确位置。 

最后，我们将所有有序单词与空格连接起来以重建原始句子。 

## 解决方案```go
package main

import (
	"strconv"
	"strings"
)

func sortSentence(s string) string {
	words := strings.Split(s, " ")
	orderedWords := make([]string, len(words))

	for _, word := range words {
		position, _ := strconv.Atoi(string(word[len(word)-1]))
		orderedWords[position-1] = word[:len(word)-1]
	}

	return strings.Join(orderedWords, " ")
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于 Go 字符串是不可变的，因此我们使用切片来删除最后一个字符。 

Go 特有的一个区别是将最后一个字符转换为整数。 我们首先将字符转换为字符串，然后使用`strconv.Atoi()`。 

错误处理来自`strconv.Atoi()`在这里被安全地忽略，因为这个问题保证了有效的输入，这意味着每个单词总是以来自的数字结尾`1`到`9`。

 ## 边缘情况

 ### 单字句子

 只包含一个单词的句子，例如`"hello1"`，可能会暴露索引错误或多个单词始终存在的假设。 该实现自然地处理这个问题，因为结果数组有大小`1`，并且唯一的单词被放置在索引处`0`。 

### 已排序的输入

 打乱的句子可能已经以正确的顺序出现，例如`"This1 is2 fine3"`。 设计不当的解决方案可能会不必要地重新排列或破坏顺序。 由于我们的实现严格按照单词的位置数字放置单词，因此会自动保留正确的顺序。 

### 最大头寸价值

 该问题允许位置`1`到`9`。 输入如`"nine9 eight8 ... one1"`验证索引逻辑是否适用于允许的最高数字。 通过减去`1`从数字来看，实现正确映射`9`到数组索引`8`。 

### 混合大小写

 单词可以同时包含大写和小写字母。 容易出现错误的实现可能会无意中标准化大小写或错误地操作字符。 由于我们只删除最后一个数字，并且从不修改剩余文本，因此大小写保持不变。
