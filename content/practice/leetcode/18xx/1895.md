[LeetCode 1895 题](https://leetcode.com/problems/largest-magic-square/)

 **难度：** 🟡 中等
 **主题：** 数组、矩阵、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们在给定的范围内找到**最大的幻方**`m x n`网格。 幻方是一个`k x k`子网格，其中每行的总和、每列的总和以及两条主对角线的总和都相等。 输入是一个二维整数数组，输出是单个整数，即边长`k`最大的魔方。 

约束告诉我们网格尺寸相对较小（`1 <= m, n <= 50`），这允许在最坏情况下具有立方时间复杂度的算法。 每个元素可以很大（`1 <= grid[i][j] <= 10^6`），但我们只需要和，而不需要乘积，因此在 Python 中整数溢出不是问题，尽管在 Go 中需要小心处理整数类型。 该问题保证了每个`1 x 1`子网格本质上是一个幻方，因此最小输出始终为 1。 

重要的边缘情况包括数字全部相同的网格、非常小的网格（`1x1`或者`1xN`），以及最大幻方仅的网格`1x1`或者`2x2`。 

## 方法

 ### 蛮力

 暴力方法会检查所有可能的情况`k x k`所有可能的子网格`k`从`1`到`min(m, n)`。 对于每个子网格，我们将计算所有行总和、所有列总和以及两个对角线总和，然后验证它们是否相等。 虽然正确，但这种方法效率低下，因为它涉及所有可能的子网格和总和上的嵌套循环，这导致最坏情况的时间复杂度为$O(m n \min(m, n)^3)$。 鉴于`m`和`n`最多可以为 50，这可能会导致最多 3100 万次迭代，这太慢了。 

### 最佳方法

 优化的关键观察是**前缀和**可用于在恒定时间内计算行和列的总和。 我们可以预先计算所有行和列的累积和。 类似地，我们可以使用额外的数组有效地计算对角线和。 这使我们能够检查候选人`k x k`子网格在$O(k)$时间而不是$O(k^2)$通过比较行总和、列总和和对角线。 

有了这个，我们可以迭代子网格的所有可能的左上角并有效地测试所有尺寸，从最大的开始`k`并减少，所以一旦找到幻方我们就可以尽早停止。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n * 分钟(m, n)^3) | O(1) | O(1) | 检查所有子网格而不进行优化 |
 | 最佳| O(m * n * 分钟(m, n)^2) | O(m * n) | 对行、列和对角线和使用前缀和 |

 ## 算法演练

 1. 计算所有行的前缀和（`rowSum[i][j]`）和所有列（`colSum[i][j]`）。 这里，`rowSum[i][j]`是第一个的总和`j`行中的元素`i`，对于列也类似。 
2. 计算两条对角线的前缀和：`diag1[i][j]`主对角线从左上角到右下角，以及`diag2[i][j]`为从右上到左下的反对角线。 
3. 迭代`k`从`min(m, n)`降至 1。这确保我们首先找到最大的幻方。 
4. 对于每个左上角`(i, j)`可以适合一个`k x k`子网格，使用前缀和计算行和和列和。 检查所有行总和和列总和是否相等。 
5. 使用对角前缀数组计算两个对角线和，并检查与行/列和的相等性。 
6. 如果找到有效的幻方，则返回`k`立即地。 
7. 如果没有找到大于 1 的幻方，则返回 1。 

工作原理：前缀和允许对行、列或对角线的任何段的总和进行恒定时间计算。 通过按尺寸递减顺序检查所有潜在的子网格，我们确保找到的第一个有效方块是最大的。 

## Python 解决方案```python
from typing import List

class Solution:
    def largestMagicSquare(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        
        rowSum = [[0] * (n + 1) for _ in range(m)]
        colSum = [[0] * (n) for _ in range(m + 1)]
        
        for i in range(m):
            for j in range(n):
                rowSum[i][j+1] = rowSum[i][j] + grid[i][j]
                colSum[i+1][j] = colSum[i][j] + grid[i][j]
        
        max_k = min(m, n)
        for k in range(max_k, 0, -1):
            for i in range(m - k + 1):
                for j in range(n - k + 1):
                    target = sum(grid[i][j:j+k])
                    magic = True
                    for x in range(k):
                        if sum(grid[i+x][j:j+k]) != target:
                            magic = False
                            break
                        if sum(grid[i+r][j+x] for r in range(k)) != target:
                            magic = False
                            break
                    if not magic:
                        continue
                    if sum(grid[i+r][j+r] for r in range(k)) != target:
                        continue
                    if sum(grid[i+r][j+k-1-r] for r in range(k)) != target:
                        continue
                    return k
        return 1
```说明：代码首先计算行和列的前缀和，但为了清楚起见，它仍然使用`sum`在行和列检查的循环内（这可以通过行/列前缀和进一步优化）。 它从最大可能的迭代`k`下降到 1，检查每个候选子网格。 对角线和直接计算。 找到的第一个有效幻方会立即返回。 

## 解决方案```go
func largestMagicSquare(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    
    maxK := 1
    for k := min(m, n); k >= 1; k-- {
        found := false
        for i := 0; i <= m-k; i++ {
            for j := 0; j <= n-k; j++ {
                target := 0
                for x := 0; x < k; x++ {
                    target += grid[i][j+x]
                }
                magic := true
                for x := 0; x < k; x++ {
                    rowSum := 0
                    colSum := 0
                    for y := 0; y < k; y++ {
                        rowSum += grid[i+x][j+y]
                        colSum += grid[i+y][j+x]
                    }
                    if rowSum != target || colSum != target {
                        magic = false
                        break
                    }
                }
                if !magic {
                    continue
                }
                diag1, diag2 := 0, 0
                for x := 0; x < k; x++ {
                    diag1 += grid[i+x][j+x]
                    diag2 += grid[i+x][j+k-1-x]
                }
                if diag1 == target && diag2 == target {
                    return k
                }
            }
        }
    }
    return maxK
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go特定注释：我们手动处理`min`因为 Go 缺乏整数的通用内置函数。 切片用于行，整数和在给定的约束内是安全的。 不需要对 nil 切片进行特殊处理，因为输入保证了维度。 

## 工作示例

 ### 示例 1

 输入：`grid = [[7,1,4,5,6],[2,5,1,6,4],[1,5,4,3,2],[1,2,7,3,4]]`开始于`k=4`，没有找到幻方。 为了`k=3`在左上角`(1,1)`, 行总和 =`[5+1+6=12, 5+4+3=12, 2+7+3=12]`，列总和 =`[5+5+2=12, 1+4+7=12, 6+3+3=12]`, 对角线 =`5+4+3=12`和`6+4+2=12`。 这匹配，所以返回 3。 

### 示例 2

 输入：`grid = [[5,1,3,1],[9,3,3,1],[1,3,3,8]]`检查`k=3`失败。 为了`k=2`，子网格开始于`(1,1)`与总和形成幻方`3+3=6`对于行、列和对角线。 返回2。
