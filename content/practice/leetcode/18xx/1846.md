[LeetCode 问题 1846](https://leetcode.com/problems/maximum-element-after-decreasing-and-rearranging/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题提供了一个正整数数组，并要求我们执行操作来转换它，以满足两个条件：第一个元素必须是`1`，并且相邻元素之间的绝对差不能超过`1`。 我们可以减少元素并重新排列数组。 最终目标是最大化结果数组中的最大元素。 

输入`arr`表示任意正整数，可能非常大（最多 10^9）且长度最多 10^5。 输出是一个整数，表示根据规则重新排列和减少元素后可达到的最大元素。 

关键边缘情况包括所有元素都相同的数组以及最小元素不同的数组`1`，以及需要显着减少的数量非常大的数组。 该问题保证至少有一个元素且所有元素均为正数，因此我们不需要处理空数组或零。 

## 方法

 **强力方法**将尝试生成数组的所有排列，然后尝试迭代地减少每个元素以满足邻接条件。 虽然这最终会给出正确的答案，但这是不可行的，因为排列的数量随数组大小呈阶乘增长（`O(n!)`），这是不可能的`n`最多 10^5。 

最佳解决方案的**关键观察**是，对数组进行排序后，每个元素最多应该是`1`大于前一个元素以满足邻接条件。 我们可以从`1`并迭代排序后的数组，将每个元素更新为其当前值的最小值并比前一个元素多 1。 这确保了第一个元素是`1`，相邻差值≤1，并且在约束条件下最大元素尽可能大。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 迭代生成所有排列并减少元素 |
 | 最佳| O(n log n) | O(n log n) | O(1) 或 O(n) | 对数组进行排序并贪婪地强制执行邻接条件 |

 ## 算法演练

 1. **对数组进行排序**：排序确保我们可以按顺序分配值，同时仅在需要时减少元素。 它允许最小的数字排在前面，并确保第一个元素很容易设置为`1`。 
2. **初始化第一个元素**：设置`arr[0] = 1`。 这满足第一个元素必须是的要求`1`。 
3. **迭代数组的其余部分**：对于每个索引`i`从`1`到`n-1`， 放`arr[i] = min(arr[i], arr[i-1] + 1)`。 这保证了绝对差条件，同时局部最大化每个元素。 
4. **返回最后一个元素**：处理后，修改后的数组中的最后一个元素将是最大可能值，因为每个元素最多`1`大于前一个元素。 

**为什么有效**：排序确保我们永远不需要增加任何元素，只需要减少，这是允许的。 的贪心赋值`min(current_value, previous + 1)`确保在最大化每个元素的同时维持邻接条件。 不变量是处理后索引`i`，所有元素来自`0`到`i`同时满足邻接条件和首元素条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumElementAfterDecrementingAndRearranging(self, arr: List[int]) -> int:
        arr.sort()
        arr[0] = 1
        for i in range(1, len(arr)):
            arr[i] = min(arr[i], arr[i-1] + 1)
        return arr[-1]
```Python 实现首先对数组进行排序。 然后它显式地将第一个元素设置为`1`，并迭代数组的其余部分，确保每个元素不超过`1`比前一个元素多。 最终的最大值是数组的最后一个元素。 

## 解决方案```go
import "sort"

func maximumElementAfterDecrementingAndRearranging(arr []int) int {
    sort.Ints(arr)
    arr[0] = 1
    for i := 1; i < len(arr); i++ {
        if arr[i] > arr[i-1]+1 {
            arr[i] = arr[i-1] + 1
        }
    }
    return arr[len(arr)-1]
}
```在 Go 中，我们使用`sort.Ints`对切​​片进行排序。 第一个元素设置为`1`，如果后续元素比前一个元素多一，则对其进行调整。 这是Python贪心算法的直接翻译。

 ## 边缘情况

 一种边缘情况是单元素数组。 这里，算法正确地将第一个元素设置为`1`，这也是最大值。 

另一种极端情况是所有元素都相同。 排序后，第一个元素变成`1`，并且每个后续元素增加`1`直到达到原始值或序列完成，保证邻接规则。 

第三种边缘情况是数组的值非常大，远远超过数组长度。 排序确保最小的元素排在前面。 然后，贪婪调整可确保最大值受数组长度限制，无论初始数字有多大，从而防止溢出或无效差异。
