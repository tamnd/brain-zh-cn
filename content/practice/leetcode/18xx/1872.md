 ## 解决方案

 ## 问题理解

 该问题描述了 Alice 和 Bob 之间的两人回合制游戏，游戏中有一排石子，每个石子都有一个整数值。 关键规则是，在一个回合中，玩家从左侧移走**多于一个棋子**，将它们的值求和到得分，然后将一个新的棋子与总和值放在左侧。 游戏继续进行，直到只剩下**一颗棋子**。 

输入是一个整数数组`stones`在哪里`stones[i]`代表的值`i-th`石头从左边。 输出是一个表示**分数差异**的整数`(Alice - Bob)`如果两者都能发挥最佳效果。 最佳游戏意味着每个玩家的目标是相对于其他玩家最大化自己的分数：爱丽丝想要**最大的正差异**，鲍勃想要**最小（或负）差异**。 

约束表明`n`可以大到 100,000，值范围为`-10^4`到`10^4`。 这表明，由于移动序列的指数数量，**强力递归模拟**是不可行的。 重要的边缘情况包括长度为 2 的数组、所有正或负的棋子，以及具有可能影响总和选择的较大交替值的数组。 

## 方法

 暴力解决方案将涉及递归模拟每一个可能的选择`x`（移除的石子数量）为双方玩家计算结果得分。 虽然这会给出正确的答案，但可能的移动序列的数量会呈指数增长`n`，这对于大型数组来说不切实际（`n`最多 10^5)。 

最佳解决方案的关键观察来自于识别**前缀和结构**以及游戏具有**单调动态规划属性**。 我们可以预先计算棋子的**前缀和**，以便可以在恒定时间内计算任何移动总和。 此外，通过分析**分数差异**，我们可以使用**动态编程数组**将问题简化为**前缀和数组后缀的最大化问题**`dp[i]`代表最好的分数差异，如果第一个`i`留下石头。 由于单调性，递归减少为**简单的贪婪 DP**：`dp[i] = max(prefix[i] - dp[i-1], dp[i-1])`。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归地模拟 Alice 和 Bob 的所有可能的动作。 规模呈指数级增长，不切实际。 |
 | 最佳 | O(n) | O(n) | 使用单调属性计算前缀和并在后缀上应用 DP。 线性扫描就足够了。 |

 ## 算法演练

 1. **计算前缀和**：对于每个索引`i`，计算第一个的总和`i+1`石头。 这允许在恒定时间内查询任何移动总和。 
2. **初始化DP数组**：让`dp[i]`代表当索引中的石子出现时，Alice 可以达到的**最大分数差**`i`到最后还剩下。 从倒数第二个索引开始，因为最后一步是微不足道的。 
3. **向后迭代**：对于每个索引`i`从`n-2`下降到`1`， 更新`dp[i]`作为`max(dp[i+1], prefix[i] - dp[i+1])`。 这代表选择要么采用当前的前缀总和并减去对手的最佳前缀总和，要么跳到下一个。 
4. **返回结果**：最优得分差值存储在`dp[1]`，对应于进行第一个有效的移动（移除至少两颗棋子）。 

**为什么有效**：通过使用前缀和和后向 DP，每个`dp[i]`保持不变，即它代表**与该位置可达到的最大分数差**。 重复性确保我们能够考虑到对手的最佳反应。 

## Python 解决方案```python
from typing import List

class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        n = len(stones)
        prefix = [0] * n
        prefix[0] = stones[0]
        for i in range(1, n):
            prefix[i] = prefix[i-1] + stones[i]

        dp = [0] * n
        dp[-1] = prefix[-1]

        for i in range(n-2, 0, -1):
            dp[i] = max(dp[i+1], prefix[i] - dp[i+1])

        return dp[1]
```Python 代码首先计算前缀和。 它初始化`dp[-1]`与所有石头的总和，因为最后一块石头的移除是微不足道的。 后向 DP 循环确保在每一步中，我们都取继续下一步或当前前缀减去对手最佳策略之间的最大值，从而捕获最佳对抗策略。 最终结果存储在`dp[1]`因为第一步必须移走至少两块石头。 

## 解决方案```go
func stoneGameVIII(stones []int) int {
    n := len(stones)
    prefix := make([]int, n)
    prefix[0] = stones[0]
    for i := 1; i < n; i++ {
        prefix[i] = prefix[i-1] + stones[i]
    }

    dp := make([]int, n)
    dp[n-1] = prefix[n-1]

    for i := n-2; i > 0; i-- {
        if prefix[i]-dp[i+1] > dp[i+1] {
            dp[i] = prefix[i]-dp[i+1]
        } else {
            dp[i] = dp[i+1]
        }
    }

    return dp[1]
}
```为了清晰起见，Go 实现通过显式条件赋值反映了 Python 的逻辑。 切片初始化用于两者`prefix`和`dp`。 向后迭代确保保留单调 DP 属性。
