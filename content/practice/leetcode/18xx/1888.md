[LeetCode 问题 1888](https://leetcode.com/problems/minimum-number-of-flips-to-make-the-binary-string-alternating/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们转换一个二进制字符串`s`使用最少数量的**翻转操作**（Type-2）转换为**交替字符串**，同时可选地执行任意数量的**旋转**（Type-1）。 交替字符串是指没有两个连续字符相同的字符串，因此有效的交替字符串遵循以下模式`"010101..."`或者`"101010..."`。 

第一个操作允许旋转：删除第一个字符并将其附加到末尾。 这意味着我们必须考虑字符串的所有**循环排列**，因为任何旋转都可能最大限度地减少所需的翻转次数。 第二个操作是翻转：改变a`'0'`到`'1'`或者`'1'`到`'0'`。 我们的目标是找到所有旋转所需的最少翻转次数。 

约束条件允许`s`达到`10^5`字符，所以**暴力旋转模拟**太慢。 我们需要一种有效的方法来计算最小翻转次数，而无需每次都物理地旋转弦。 

重要的边缘情况包括已经交替的字符串、所有字符都相同的字符串以及奇数与偶数长度的字符串，因为奇数长度的字符串允许进行一些旋转来更改起始模式。 

## 方法

 **暴力方法**将生成字符串的所有旋转，并计算每次旋转所需的翻转次数以匹配两者`"0101..."`和`"1010..."`模式。 虽然正确，但这需要生成`n`轮换和检查`2*n`每次旋转翻转一次，时间复杂度为 **O(n^2)**。 这是不可行的`n = 10^5`。 

**最佳方法**使用**滑动窗口**策略。 我们可以将字符串加倍（`s + s`）来模拟所有旋转，然后滑动一个长度的窗口`n`穿过双弦。 对于每个窗口，我们计算将其转换为`"0101..."`和`"1010..."`模式。 滑动窗口允许我们使用先前的计数在每步的 **O(1)** 时间内有效地更新翻转计数，从而导致 **O(n)** 总时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 生成所有旋转并单独计数翻转 |
 | 最佳| O(n) | O(n) | 在双字符串上使用滑动窗口来有效地解释旋转 |

 ## 算法演练

 1. **为长度交替的字符串创建两个参考模式**`2n`（处理旋转）。 模式 1 开头为`'0'`并交替，pattern2 开头为`'1'`和替补。 
2. **将输入字符串加倍**以模拟所有旋转。 
3. **初始化一个长度的窗口`n`** 在双字符串的开头，计算此窗口中两种模式所需的翻转次数。 
4. **从左向右一次将窗口滑动一个字符**。 对于每个班次：

 - 通过删除离开窗口的角色的贡献并添加进入窗口的角色的贡献来更新翻转计数。 
- 跟踪迄今为止在所有窗口中看到的**最小翻转**。 
5. **检查所有长度的窗口后返回最小翻转计数**`n`。 

**为什么有效**：将字符串加倍可确保每次旋转都表示为长度连续的子字符串`n`。 与两个参考模式进行比较可以保证我们考虑到两个有效的交替模式。 滑动窗口可以有效地计算每次旋转的翻转，而无需重新计算，从而给出正确的最小翻转。 

## Python 解决方案```python
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        s_double = s + s
        pattern1 = ''.join(['0' if i % 2 == 0 else '1' for i in range(2 * n)])
        pattern2 = ''.join(['1' if i % 2 == 0 else '0' for i in range(2 * n)])
        
        flips1 = flips2 = 0
        min_flips = float('inf')
        
        for i in range(2 * n):
            if s_double[i] != pattern1[i]:
                flips1 += 1
            if s_double[i] != pattern2[i]:
                flips2 += 1
            
            if i >= n:
                if s_double[i - n] != pattern1[i - n]:
                    flips1 -= 1
                if s_double[i - n] != pattern2[i - n]:
                    flips2 -= 1
            
            if i >= n - 1:
                min_flips = min(min_flips, flips1, flips2)
        
        return min_flips
```该实现首先构造两个长度交替的模式`2n`考虑所有旋转。 通过将字符串加倍`s`，我们避免物理旋转它。 滑动窗口通过仅更新进入和离开的字符来有效地计算翻转计数，确保`O(n)`时间。 最后，返回所有窗口的最小翻转次数。 

## 解决方案```go
func minFlips(s string) int {
    n := len(s)
    sDouble := s + s
    pattern1 := make([]byte, 2*n)
    pattern2 := make([]byte, 2*n)
    
    for i := 0; i < 2*n; i++ {
        if i%2 == 0 {
            pattern1[i] = '0'
            pattern2[i] = '1'
        } else {
            pattern1[i] = '1'
            pattern2[i] = '0'
        }
    }
    
    flips1, flips2 := 0, 0
    minFlips := n + 1
    
    for i := 0; i < 2*n; i++ {
        if sDouble[i] != pattern1[i] {
            flips1++
        }
        if sDouble[i] != pattern2[i] {
            flips2++
        }
        if i >= n {
            if sDouble[i-n] != pattern1[i-n] {
                flips1--
            }
            if sDouble[i-n] != pattern2[i-n] {
                flips2--
            }
        }
        if i >= n-1 {
            if flips1 < minFlips {
                minFlips = flips1
            }
            if flips2 < minFlips {
                minFlips = flips2
            }
        }
    }
    
    return minFlips
}
```Go 实现反映了 Python 逻辑，使用字节片进行模式表示并通过滑动窗口维护翻转计数。 由于约束保证，空字符串没有特别的问题`1 <= n`。 整数溢出不是问题，因为翻转计数受以下限制`n`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们对双倍字符串进行一次迭代，并使用滑动窗口每一步以 O(1) 的速度更新翻转。 |
 | 空间| O(n) | 存储双倍字符串和两个模式数组需要线性空间。 |

 滑动窗口方法避免了每次旋转都重新计算翻转，从而将潜在的 O(n^2) 算法减少到线性时间。

 ## 边缘情况

 **单字符字符串**：由于长度为 1 的字符串是简单交替的，因此不需要翻转。 实现会自动处理这个问题。 

**所有相同的字符**：需要大约一半的字符才能翻转。 滑动窗口正确计数
