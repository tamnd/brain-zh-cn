[LeetCode 1891 题](https://leetcode.com/problems/cutting-ribbons/)

 **难度：** 🟡 中等
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 该问题需要确定最大可能长度`x`的丝带，以便在切割或保留阵列中给定的丝带后`ribbons`，你至少可以获得`k`长度的丝带`x`。 每条丝带都可以被切成**正整数**长度的较小片段或保持原样，任何不符合目标长度的剩余片段都可以被丢弃。 输入由表示丝带长度的正整数数组和目标丝带数量组成`k`。 预期输出是一个整数，它是最大长度`x`对此至少可以得到`k`丝带。 如果没有正整数长度允许产生至少`k`丝带，输出应为 0。 

这些约束表明输入数组可以很大（最多 100,000 个元素），并且各个色带长度也可以很大（最多 100,000 个）。 所需色带数量`k`可以高达十亿。 这排除了会迭代每个可能的色带长度的天真的方法，因为它们对于最大的输入来说太慢了。 

重要的边缘情况包括以下情况`k`相对于色带的总和来说非常大，或者阵列包含无法相遇的非常短的色带`k`即使全部被切成最小的碎片。 该问题保证所有输入长度和`k`是正整数，因此负数和零不是问题。 

## 方法

 **强力方法**将尝试数组中从 1 到最大色带长度的每个可能的色带长度，通过将每个色带长度除以候选长度的整数相加来计算可以获得该长度的色带数量。 此方法之所以有效，是因为它明确地测试了所有可能的长度，但它太慢了，因为它需要为 100,000 个带中的每一个迭代潜在的 100,000 个可能的长度，导致最坏情况的时间复杂度达到 100 亿次操作，这是不切实际的。 

实现有效解决方案的**关键观察**是，可获得的色带数量是色带长度的单调递减函数。 也就是说，随着候选长度的增加，能够获得的色带总数并不能增加。 此属性允许在可能的长度范围内使用**二分搜索**来有效地找到最大有效长度。 我们不是测试每个长度，而是检查中点，确定它是否至少产生`k`功能区，并相应地调整搜索间隔。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * max(色带)) | O(1) | O(1) | 尝试从 1 到最大色带长度的所有可能长度，计算色带 |
 | 最佳| O(n * log(max(色带))) | O(1) | O(1) | 对长度进行二分搜索，检查色带计数 |

 ## 算法演练

 1. 初始化二分查找间隔`left = 1`（最小可能的色带长度）和`right = max(ribbons)`（最大色带长度）。 
2. 虽然`left <= right`，计算中点`mid = left + (right - left) // 2`。 这代表候选色带长度。 
3. 计算将每条丝带切成一定长度后可获得的丝带总数`mid`。 对于长度的丝带`r`，件数为`r // mid`。 
4. 如果色带总数至少为`k`，这意味着可以实现`k`长度的丝带`mid`或更长时间。 记录`mid`作为潜在的答案并将搜索间隔移至更长的长度：`left = mid + 1`。 
5. 如果色带总数小于`k`, 是不可能实现的`k`这个长度的丝带。 将搜索间隔调整为更短的长度：`right = mid - 1`。 
6. 重复步骤2-5，直到间隔用完。 最后记录有效`mid`是最大可能的色带长度。 如果未找到有效长度，则返回 0。 

**为什么有效**：二分查找依赖于单调性：随着色带长度的增加，色带的数量减少。 通过检查每次迭代的中点，我们有效地缩小了仍然满足至少要求的最大可能长度`k`丝带。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxLength(self, ribbons: List[int], k: int) -> int:
        left, right = 1, max(ribbons)
        result = 0
        
        while left <= right:
            mid = left + (right - left) // 2
            total_ribbons = sum(ribbon // mid for ribbon in ribbons)
            
            if total_ribbons >= k:
                result = mid
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```Python 实现首先确定搜索范围。 主循环使用二分搜索来查找最大可行长度。`total_ribbons`使用生成器表达式计算，该表达式将每个色带长度除以候选长度`mid`。 如果`total_ribbons`达到或超过`k`，我们更新`result`并搜索上半部分； 否则，我们搜索下半部分。 

## 解决方案```go
func maxLength(ribbons []int, k int) int {
    left, right := 1, 0
    for _, r := range ribbons {
        if r > right {
            right = r
        }
    }
    
    result := 0
    for left <= right {
        mid := left + (right - left) / 2
        total := 0
        for _, r := range ribbons {
            total += r / mid
        }
        
        if total >= k {
            result = mid
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    
    return result
}
```Go 的实现与 Python 版本非常相似。 我们计算最大色带长度来设置上限。 for 循环替换生成器表达式来计算色带总数。 Go 中天然地使用整数除法，并根据结果调整搜索间隔。
