[LeetCode 1816 题](https://leetcode.com/problems/truncate-sentence/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 问题给了我们一个句子`s`和一个整数`k`。 一个句子保证包含由一个空格分隔的单词，开头或结尾没有多余的空格。 我们的任务是返回一个仅包含第一个的新句子`k`原句中的单词。 

换句话说，我们需要在`k`th 单词并忽略其后的所有内容。 

例如，如果输入的句子是：```
"Hello how are you Contestant"
```和`k = 4`，那么前四个词是：```
"Hello", "how", "are", "you"
```所以正确的输出变成：```
"Hello how are you"
```输入尺寸非常小。 字符串的最大长度仅为 500 个字符，这意味着几乎任何简单的字符串处理解决方案都足够快。 因此，问题的焦点是正确性和干净的实现，而不是高级优化。 

这些约束还保证了几个重要的属性：

 - 单词之间恰好间隔一个空格。 
- 没有前导或尾随空格。 
-`k`总是有效的，这意味着至少有`k`句子中的单词。 
- 单词仅包含英文字母。 

这些保证显着简化了实现，因为我们不需要处理格式错误的输入、多个连续空格或丢失的单词。 

还有一些边缘情况值得考虑：

 - 当`k`等于总字数，答案应保持原句不变。 
- 什么时候`k = 1`，结果应仅包含第一个单词。 
- 非常短的句子应该仍然可以正常工作。 
- 如果手动错误地构建结果字符串，幼稚的实现可能会意外地留下尾随空格。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是使用空格作为分隔符将句子拆分为单词数组。 一旦我们有了单词列表，我们就取第一个`k`单词并用空格将它们重新连接在一起。 

这种方法很容易理解，因为它直接反映了问题陈述：

 1. 将句子分解为单词。 
2. 只保留第一个`k`。 
3. 重构被截断的句子。 

例如：```
s = "What is the solution to this problem"
```分割后：```
["What", "is", "the", "solution", "to", "this", "problem"]
```取前四个词得出：```
["What", "is", "the", "solution"]
```将它们重新组合在一起会产生：```
"What is the solution"
```对于给定的约束，这种方法是完全可以接受的。 然而，它为所有单词分配额外的内存，即使我们只需要第一个`k`。 

### 最佳方法

 更有效的方法是逐字符扫描字符串并计算空格数。 由于每个空格分隔单词，因此`k`第一个单词可以通过定位来确定`k`th 分隔符。 

关键的观察是，遇到之后`k`换句话说，我们已经确切地知道被截断的句子应该在哪里结束。 无需将整个字符串拆分为数组。 

我们迭代一下这句话：

 - 每当我们遇到空格时，我们就知道一个单词已经结束。 
- 一旦我们看到`k`换句话说，我们返回到该位置的子字符串。 

这避免了不必要的分割和额外的存储。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将整个句子拆分为单词 |

 ## 算法演练

 ### 最优算法

 1. 初始化一个计数器来跟踪已处理的单词数。 
2. 使用索引逐字符遍历字符串。 
3. 每次遇到空格字符时，都会增加字计数器，因为已到达字边界。 
4. 增加计数器后，检查我们是否已经找到`k`字。 

- 如果是，则返回从字符串开头到当前索引的子字符串。 
- 该子字符串恰好包含第一个`k`字。 
5. 如果循环结束后没有提前返回，则意味着该句子已经包含了`k`单词，因此返回原始字符串。 

### 为什么它有效

 该算法依赖于单词之间恰好由一个空格分隔这一事实。 每个空格都标志着一个单词的结束。 所以，遇到之后`k - 1`空间，我们知道第一个`k`单词占据下一个分隔符之前的子字符串。 通过返回正确边界处的子字符串，我们保证第一个`k`单词都包含在内。 

## Python 解决方案```python
class Solution:
    def truncateSentence(self, s: str, k: int) -> str:
        word_count = 0

        for index, char in enumerate(s):
            if char == " ":
                word_count += 1

                if word_count == k:
                    return s[:index]

        return s
```该实现使用单次传递字符串。 

变量`word_count`跟踪遇到了多少个完整的单词。 由于空格分隔单词，因此每个空格都会增加计数。 

遍历过程中，当计数达到`k`，当前索引表示紧接在`k`第一个词。 返回`s[:index]`给出所需的截断句子。 

如果循环完成而没有返回，则该句子恰好包含`k`单词，因此原始字符串原样返回。 

这种实现简洁、高效，并且直接遵循前面描述的最优算法。 

## 解决方案```go
func truncateSentence(s string, k int) string {
    wordCount := 0

    for i, char := range s {
        if char == ' ' {
            wordCount++

            if wordCount == k {
                return s[:i]
            }
        }
    }

    return s
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 特有的一个重要细节是字符串是不可变的字节切片。 返回`s[:i]`无需手动复制字符即可高效创建子字符串。 

循环使用`range`同时迭代字符和索引。 由于输入仅包含英文字母和空格，因此字节索引在这里是完全安全的。 

不用担心整数溢出，因为字符串长度非常小。

 ## 边缘情况

 ### 案例 1,`k`等于单词总数

 一个常见的错误是意外地过早截断或在实际不需要截断时返回不完整的句子。 

例如：```
s = "a b c"
k = 3
```该实现正确地处理了这个问题，因为循环仅在遇到 后面的空格时返回`k`第一个词。 由于没有这样的空间，循环自然结束并返回原始字符串。 

### 情况2，句子仅包含一个单词

 单字输入是一个重要的边界条件，因为根本没有空格。 

例子：```
s = "Hello"
k = 1
```该算法永远不会进入截断条件，因为不存在空格。 它只是返回原始字符串，这是正确的行为。 

### 情况 3，截断为一个单词

 当`k = 1`，算法必须停在第一个空格处。 

例子：```
s = "one two three"
k = 1
```第一个遇到的空格标志着第一个单词的结尾。 该算法立即返回该空格之前的子字符串，产生`"one"`正确。 

### 情况4，保留间距格式

 简单的手动字符串构建解决方案可能会意外地在末尾添加额外的空格。 

例如，不正确的方法可能会产生：```
"Hello how are you "
```带有尾随空格。 

此实现完全避免了该问题，因为它直接从原始句子返回子字符串，保留输入所保证的精确格式。
