[LeetCode 1858 题](https://leetcode.com/problems/longest-word-with-all-prefixes/)

 **难度：** 🟡 中等
 **主题：** 数组、字符串、深度优先搜索、Trie

 ## 解决方案

 ## 问题理解

 该问题给了我们一个小写字符串数组，称为`words`。 我们需要找到最长的单词，使得该单词的每个前缀也存在于数组中。 

前缀是指从单词开头取出字符形成的字符串。 例如，对于`"apple"`:

 - 长度1前缀：`"a"`- 长度2前缀：`"ap"`- 长度3前缀：`"app"`- 长度4前缀：`"appl"`- 长度5前缀：`"apple"`为了`"apple"`为了符合资格，所有较短的前缀也必须出现在输入数组中。 如果缺少一个前缀，该词就是无效的。 

输出应该是：

 - 最长的有效单词
 - 如果多个有效单词的最大长度相同，则选择字典顺序最小的一个
 - 如果不存在有效单词，则返回空字符串

 约束条件很重要：

 - 最多`10^5`话
 - 所有单词的总长度最多为`10^5`这个总长度约束告诉我们与字符总数成比例的解决方案是可以接受的。 然而，对所有字符串的二次方法或重复昂贵的子字符串搜索可能会变得太慢。 

有几个重要的边缘情况：

 - 一个单词可能没有较小的前缀而存在。 例如，`"banana"`单独无效，因为`"b"`,`"ba"`，等等都缺失了。 
- 多个单词可以具有相同的最大长度，需要字典顺序比较。 
- 单字符单词自动有效，因为它没有较短的非空前缀。 
- 可能根本没有有效的链，在这种情况下我们返回`""`。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是独立检查每个单词。 

对于每个单词：

 1.生成所有长度的前缀`1`通过`len(word) - 1`2. 检查输入数组中是否存在每个前缀
 3. 如果所有前缀都存在，则该单词有效
 4. 根据以下条件跟踪最佳答案：

 - 首先较长的长度
 - 如果长度相同则字典序较小

 为了使前缀查找高效，我们将所有单词存储在哈希集中。 

这种方法是正确的，因为它明确验证了每个候选单词所需的属性。 然而，它会为每个单词重复构建前缀，这可能会产生不必要的开销。 

即使总字符数受以下限制`10^5`，我们仍然可以改进解决方案结构，让逻辑更清晰。 

### 关键见解

 当且仅当其直接较短的前缀有效时，单词才有效。 

例如：

-`"appl"`仅当以下情况下才有效`"app"`有效
 -`"app"`仅当以下情况下才有效`"ap"`有效
 -`"ap"`仅当以下情况下才有效`"a"`有效

 这创建了一个自然的增量构建过程。 

如果我们按长度排序处理单词，我们可以构建一组已经验证的单词。 然后：

 - 单字词自动有效
 - 较长的单词如果有前缀则有效`word[:-1]`已经有效

 这避免了从头开始重复检查每个较小的前缀。

 ## 算法演练

 ### 最优算法

 1. 将所有单词存储在可排序列表中，并按字典顺序对它们进行排序。 

字典排序很重要，因为当两个有效单词具有相同长度时，我们想要较小的一个。 首先排序可确保较早的单词自然满足平局打破规则。 
2. 按长度升序对单词进行排序，然后按字典顺序排序。 

这保证了在处理单词之前，所有较短的候选前缀都已被处理。 
3. 创建一个名为的哈希集`valid_words`。 

该集合将仅包含前缀全部有效的单词。 
4.初始化一个空字符串`best_answer`。 

该变量跟踪迄今为止找到的最长的有效单词。 
5. 迭代每个单词。 

对于每个单词：

 - 如果它的长度是`1`,自动生效
 - 否则，检查是否`word[:-1]`存在于`valid_words`6. 如果该词有效：

 - 添加到`valid_words`- 比较一下`best_answer`- 如果出现以下情况，请更新答案：

 - 这个词更长，或者
 - 长度相等并且单词按字典顺序更小
 7. 返回`best_answer`处理完所有单词后。 

### 为什么它有效

 该算法保持不变式`valid_words`准确包含前缀全部存在于数组中的单词。 

当处理一个单词时，我们只需要检查它的直接较短的前缀，因为该前缀本身只能输入`valid_words`如果所有_its_前缀都有效。 这创建了一个归纳正确性链。 

由于单词是从较短长度到较长长度进行处理的，因此每个必要的前缀都已在当前单词之前进行了评估。 

## Python 解决方案```python
from typing import List

class Solution:
    def longestWord(self, words: List[str]) -> str:
        words.sort(key=lambda word: (len(word), word))

        valid_words = set()
        best_answer = ""

        for word in words:
            if len(word) == 1 or word[:-1] in valid_words:
                valid_words.add(word)

                if (
                    len(word) > len(best_answer)
                    or (
                        len(word) == len(best_answer)
                        and word < best_answer
                    )
                ):
                    best_answer = word

        return best_answer
```实现首先根据两个标准对单词进行排序：

 - 首先是较短的单词
 - 同等长度中字典顺序较小的单词优先

 这种排序保证了所有可能的前缀在其较长的扩展之前得到处理。 

这`valid_words`set 仅存储满足前缀条件的单词。 一个词在两种情况下有效：

 - 它有长度`1`- 它的直接前缀已经属于`valid_words`表达式`word[:-1]`删除最后一个字符并给出所需的较短前缀。 

每当找到有效单词时，算法就会将其与当前最佳答案进行比较。 比较逻辑完全遵循问题规则：

 - 喜欢较长的单词
 - 如果长度相同，则更喜欢字典顺序上较小的单词

 最后，该方法返回遍历过程中发现的最佳有效单词。 

## 解决方案```go
package main

import (
	"sort"
)

func longestWord(words []string) string {
	sort.Slice(words, func(i, j int) bool {
		if len(words[i]) == len(words[j]) {
			return words[i] < words[j]
		}
		return len(words[i]) < len(words[j])
	})

	validWords := make(map[string]bool)
	bestAnswer := ""

	for _, word := range words {
		if len(word) == 1 || validWords[word[:len(word)-1]] {
			validWords[word] = true

			if len(word) > len(bestAnswer) ||
				(len(word) == len(bestAnswer) && word < bestAnswer) {
				bestAnswer = word
			}
		}
	}

	return bestAnswer
}
```Go 解决方案遵循与 Python 实现相同的逻辑。 

自定义比较器用于`sort.Slice`首先按长度排序，然后按字典顺序排序。 

Go 没有内置的集合类型，因此`map[string]bool`被用来代替。 地图中的存在表明单词是有效的。 

子串提取使用切片语法：```go
word[:len(word)-1]
```这会产生验证所需的直接前缀。 

与 Python 不同，Go 区分 nil 映射和初始化映射，因此`make(map[string]bool)`插入前需要。

 ## 边缘情况

 ### 不存在有效单词

 当没有单词具有所有必需的前缀时，就会出现一个重要的边缘情况。 例如：```
["abc", "abcd", "xyz"]
```这些单词都没有较短的前缀。 有缺陷的实现可能会错误地返回最长的单词。 该解决方案避免了该问题，因为仅输入一个单词`valid_words`如果它的直接前缀已经存在。 

### 多个最长的单词

 该问题需要按字典顺序打破平局。 考虑：```
["a", "ap", "app", "appl", "apple", "apply"]
```两个都`"apple"`和`"apply"`有效且长度相同。 粗心的实现可能只是返回输入中最先出现的那个。 当长度匹配时，该解决方案显式比较字典顺序。 

### 缺少中间前缀

 一个单词可能有一些前缀，但不是全部。 例如：```
["a", "app"]
```这个词`"app"`无效，因为`"ap"`失踪了。 该算法可以正确处理这个问题，因为`"app"`需要`"ap"`已经存在于`valid_words`，但事实并非如此。 

### 单字符单词

 任何单字母单词都会自动有效，因为没有更小的非空前缀需要检查。 实现明确地处理这个问题：```
if len(word) == 1
```如果没有这个条件，任何链条都无法开始。
