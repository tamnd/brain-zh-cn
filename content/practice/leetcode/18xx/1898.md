[LeetCode 问题 1898](https://leetcode.com/problems/maximum-number-of-removable-characters/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、字符串、二分查找

 ## 解决方案

 ## 问题理解

 这个问题给了我们两个字符串，`s`和`p`，以及索引列表`removable`。 字符串`p`保证是一个子序列`s`，表示中的所有字符`p`出现在`s`以相同的顺序，但不一定是连续的。 数组`removable`代表位置`s`我们可以按顺序删除。 我们的任务是找到最大的数`k`这样如果我们删除第一个`k`字符来自`s`指定为`removable`,`p`仍然是修改后的子序列`s`。 

换句话说，我们正在寻找可以删除的最大可删除字符数。`s`在不破坏顺序的情况下`p`。 这些约束告诉我们，字符串可能会很长（最多 100,000 个字符），因此任何解决方案都必须高效且理想情况下比`O(n * m)`进行重复检查，其中`n`和`m`的长度是`s`和`p`。 

重要的边缘情况包括删除单个字符会破坏子序列的情况，其中`removable`为空，并且其中的所有字符`removable`可以安全地移除。 

## 方法

 暴力方法会尝试所有可能的值`k`从 0 到 的长度`removable`。 对于每个`k`，它将删除第一个`k`指数来自`s`并检查是否`p`仍然是一个子序列。 虽然正确，但这种方法效率低下，因为对于每个`k`它可能会扫描字符串`s`完全是为了检查子序列。 这导致最坏情况的复杂性`O(n * r)`在哪里`r`的长度是`removable`。 

最佳解决方案的关键观察是属性“p 是删除前 k 个索引后 s 的子序列”是单调的。 如果`p`是删除后的子序列`k`字符，它也将是任何较小数量的删除的子序列。 相反，如果`p`不是删除后的子序列`k`字符，对于任何更大的字符都会失败`k`。 这种单调性使我们能够应用**二分搜索**`k`。 对于每位候选人`k`，我们检查是否`p`使用布尔数组来标记删除的字符和两指针扫描，有效地保留子序列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * r) | O(n) | 尝试每一个可能的 k 并检查子序列 |
 | 最佳| O(n * log r) | O(n) | 对 k 进行二分查找并进行高效的子序列检查 |

 ## 算法演练

 1. 初始化二分查找范围`left = 0`和`right = len(removable)`。 我们正在寻找最大的`k`在这个范围内。 
2. 对于每位候选人`mid = (left + right) // 2`，标记第一个`mid`指数在`removable`使用长度的布尔数组删除`len(s)`。 
3. 使用两指针方法检查是否`p`仍然是`s`在这些删除之后。 指针`i`扫描`s`while 指针`j`扫描`p`。 什么时候`s[i]`比赛`p[j]`和`i`不删除，增加`j`。 
4.如果`j`达到`len(p)`,`p`仍然是一个子序列。 更新`left = mid + 1`尝试更多的删除。 
5.如果`j`没有达到`len(p)`,`p`不再是子序列。 更新`right = mid - 1`。 
6. 重复直到`left > right`。 最大有效`k`是`right`。 

为什么有效：二分搜索利用了删除方面的子序列有效性的单调特性。 两指针检查确保每个子序列验证都是线性的`s`，使该方法高效。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumRemovals(self, s: str, p: str, removable: List[int]) -> int:
        def is_subsequence(k: int) -> bool:
            removed = [False] * len(s)
            for i in range(k):
                removed[removable[i]] = True
            
            j = 0
            for i in range(len(s)):
                if not removed[i] and s[i] == p[j]:
                    j += 1
                    if j == len(p):
                        return True
            return j == len(p)
        
        left, right = 0, len(removable)
        max_k = 0
        while left <= right:
            mid = (left + right) // 2
            if is_subsequence(mid):
                max_k = mid
                left = mid + 1
            else:
                right = mid - 1
        return max_k
```这个实现定义了一个助手`is_subsequence(k)`检查是否`p`删除第一个后仍保留子序列`k`指数。 二分查找调整`left`和`right`基于此检查，确保我们找到最大有效值`k`。 

## 解决方案```go
func maximumRemovals(s string, p string, removable []int) int {
    isSubsequence := func(k int) bool {
        removed := make([]bool, len(s))
        for i := 0; i < k; i++ {
            removed[removable[i]] = true
        }
        j := 0
        for i := 0; i < len(s); i++ {
            if !removed[i] && s[i] == p[j] {
                j++
                if j == len(p) {
                    return true
                }
            }
        }
        return j == len(p)
    }
    
    left, right := 0, len(removable)
    maxK := 0
    for left <= right {
        mid := (left + right) / 2
        if isSubsequence(mid) {
            maxK = mid
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    return maxK
}
```Go 实现反映了 Python 逻辑。 主要区别在于显式创建切片`removed`和整数除法进行计算`mid`。
