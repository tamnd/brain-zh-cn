[LeetCode 1890 题](https://leetcode.com/problems/the-latest-login-in-2020/)

 **难度：** 🟢简单
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 问题提供了一个数据库表`Logins`记录用户登录事件，带有列`user_id`和`time_stamp`。 每个组合`(user_id, time_stamp)`是唯一的，确保每一行对应一个不同的登录。 任务是为 2020 年期间至少登录一次的每个用户确定**当年的最新登录时间戳**。 2020 年期间未登录的用户应从输出中排除。 

本质上，输入是一组跨多年的登录事件，预期输出是一个包含两列的表：`user_id`和`last_stamp`， 在哪里`last_stamp`是该用户在 2020 年最近一次登录。重要的一点包括按 2020 年进行过滤并正确识别每个用户的最大时间戳。 边缘情况包括 2020 年多次登录的用户、2020 年没有登录的用户以及 2020 年边界的时间戳（例如`2020-01-01 00:00:00`或者`2020-12-31 23:59:59`）。 

## 方法

 最简单的方法是蛮力。 人们可以迭代所有登录，过滤掉 2020 年以外的行，然后对于每个用户，跟踪迄今为止看到的最新时间戳。 虽然这在概念上是正确的，但它需要多次迭代或在 SQL 中执行联接/聚合而不利用内置函数，这对于大型数据集可能效率低下。 

最佳方法是利用 SQL 聚合。 通过过滤仅 2020 年的登录信息，然后按`user_id`，我们可以直接应用`MAX()`功能于`time_stamp`查找每个用户的最新登录信息。 这利用了 SQL 基于集合的操作并避免了手动迭代。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(u) | 迭代所有登录，将每个用户的最新登录信息存储在内存中（u = 用户数量）|
 | 最佳| O(n) | O(u) | 在 SQL 中过滤 2020 年，按 user_id 分组，计算每组的 MAX |

 ## 算法演练

 1. 过滤`Logins`表只保留其中的行`time_stamp`落在 2020 年。这可以确保我们排除其他年份的登录。 
2. 对筛选后的行进行分组`user_id`。 此步骤将每个用户在 2020 年的所有登录时间戳收集到一个逻辑组中。 
3.应用聚合函数`MAX(time_stamp)`每个组以确定该用户的最新登录时间戳。 
4. 返回一个表`user_id`和`last_stamp`列，其中`last_stamp`是计算出的每个用户的最大时间戳。 行的顺序无关紧要。 

**为什么有效：** SQL`GROUP BY`和`MAX()`保证为每个用户选择最大时间戳，并且过滤确保仅考虑 2020 年以内的登录。 这确保了正确性，不会丢失任何用户或包括无效年份。 

## Python 解决方案

 虽然这是一个数据库问题，但我们可以在Python中使用字典来表示组来模拟它。```python
from typing import List, Dict
from datetime import datetime

def latest_login(logins: List[Dict[str, str]]) -> List[Dict[str, str]]:
    latest_per_user = {}
    
    for row in logins:
        user_id = row['user_id']
        timestamp = datetime.strptime(row['time_stamp'], '%Y-%m-%d %H:%M:%S')
        
        if timestamp.year == 2020:
            if user_id not in latest_per_user or timestamp > latest_per_user[user_id]:
                latest_per_user[user_id] = timestamp
    
    result = [{'user_id': uid, 'last_stamp': latest_per_user[uid].strftime('%Y-%m-%d %H:%M:%S')} 
              for uid in latest_per_user]
    
    return result
```Python 实现迭代所有登录行，过滤 2020 年，并维护一个由`user_id`存储最新的时间戳。 最后，字典被转换为预期的输出格式。 

## 解决方案```go
package main

import (
    "time"
)

type Login struct {
    UserID    int
    TimeStamp string
}

type Result struct {
    UserID    int
    LastStamp string
}

func LatestLogin(logins []Login) []Result {
    latestPerUser := make(map[int]time.Time)
    
    for _, login := range logins {
        t, _ := time.Parse("2006-01-02 15:04:05", login.TimeStamp)
        if t.Year() == 2020 {
            if existing, ok := latestPerUser[login.UserID]; !ok || t.After(existing) {
                latestPerUser[login.UserID] = t
            }
        }
    }
    
    results := []Result{}
    for uid, ts := range latestPerUser {
        results = append(results, Result{UserID: uid, LastStamp: ts.Format("2006-01-02 15:04:05")})
    }
    
    return results
}
```在围棋中，`map[int]time.Time`用于存储每个用户的最新时间戳。 解析和格式化时间戳遵循 Go 约定。 该逻辑反映了 Python 实现。

 | 用户 ID | 时间戳 |

 | 6 | 2020-06-30 15:06:07 |
 | 6 | 2021-04-21 14:06:06 |
 | 6 | 2019-03-07 00:18:15 |
 | 8 | 2020-02-01 05:10:53 |
 | 8 | 2020-12-30 00:46:50 |

 | 2 | 2019-08-25 07:59:08 |
 | 14 | 14 2019-07-14 09:00:00 |
 | 14 | 14 2021-01-06 11:59:59 |

 在 Python 中一步一步：

 - 初始化`latest_per_user = {}`。 
- 处理每一行：

 - 用户 6: 2020-06-30 -> 最新[6] = 2020-06-30
 - 用户 8: 2020-02-01 -> 最新[8] = 2020-02-01
 - 用户8: 2020-12-30 -> 更新最新[8] = 2020-12-30
 - 用户2：2020-01-16 -> 最新[2] = 2020-01-16
 - 用户 6、8、2 保留，14 被排除。 
- 输出表：

 | 用户 ID | 最后的邮票 |
 | --- | --- |
 | 6 | 2020-06-30 15:06:07 |
 | 8 | 2020-12-30 00:46:50 |
 | 2 | 2020-01-16 02:49:50 |

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单次遍历所有登录记录以过滤和比较时间戳。 |
 | 空间| O(u) | 存储 2020 年期间登录的每个用户的最新时间戳。 

时间复杂度与登录记录数成线性关系。 空间复杂度取决于 2020 年登录的唯一用户数量。
