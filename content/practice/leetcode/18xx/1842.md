[LeetCode 1842 题](https://leetcode.com/problems/next-palindrome-using-same-digits/)

 **难度：** 🔴难
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 输入是一个数字字符串`num`这保证已经是回文了。 任务是重新排列其数字以创建另一个严格大于原始数字的回文数，同时也是此类回文数中最小的可能。 

回文具有镜像对称性。 例如：

-`"1221"`是回文，因为从左到右和从右到左读起来都是一样的。 
-`"45544554"`也是一个回文。 

重要的观察是，一旦回文的左半部分被固定，右半部分就会自动确定。 例如：

 - 左半边`"12"`产生回文`"1221"`- 左半边`"54"`产生回文`"5445"`对于奇数长度回文，中间的数字保持固定，而两半彼此镜像：

 - 左半边`"32"`有中间数字的`"1"`产生`"32123"`问题本质上是在问：

 > 找到回文前半部分的下一个字典顺序较大的排列，然后对其进行镜像以形成最小的较大回文。 

约束条件极其重要：

 -`num.length`可以达到`10^5`- 这排除了生成排列
 - 任何阶乘或指数方法都是不可能的
 - 即使二次解也可能太慢

 这意味着我们需要线性或近线性算法。 

一些边缘情况很重要：

 - 回文可能已经使用了其左半部分的最大可能排列，这意味着不存在更大的回文
 - 个位数输入不能产生另一个回文
 - 重复的数字会使下一个排列逻辑变得复杂
 - 由于中心数字的原因，奇数和偶数长度回文的行为略有不同

 例如：

 -`"32123"`已经剩下一半`"32"`，这已经是最高排列，所以答案是`""`-`"9"`也返回`""`-`"1221"`变成`"2112"`因为下一个排列`"12"`是`"21"`## 方法

 ### 蛮力方法

 强力解决方案将生成数字的每个排列，过滤形成有效回文的排列，对它们进行排序，然后找到下一个更大的回文。 

这种方法是正确的，因为它明确地检查所有可能的重新排列并选择大于原始数字的最小有效回文。 

然而，这是完全不切实际的。 

如果字符串的长度是`n`, 最多可以有`n!`排列。 即使进行了修剪和重复消除，可能的排列数量也会变得非常大`n = 10^5`。 

因此，暴力方法是不可用的。 

### 最佳方法

 关键的见解是回文完全由其前半部分决定。 

假设回文长度为`n`。 

- 左半部分由第一个部分组成`n // 2`数字
 - 右半部分与左半部分正好相反
 - 如果`n`为奇数，中间数字不变

 因此，我们不需要在所有回文中搜索，而只需要找到左半部分的下一个字典排列。 

一旦我们获得左半部分的下一个更大的排列：

 - 镜像它
 - 如有必要，重新连接中间数字
 - 构造新的回文

 这是有效的，因为左半部分的字典顺序直接决定了完整回文的字典顺序。 

因此，该问题简化为经典的“下一个排列”问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成所有排列和过滤回文 |
 | 最佳| O(n) | O(n) | 找到左半部分的下一个排列并镜像它 |

 ## 算法演练

 1.确定字符串的长度并提取左半部分。 

如果`n = len(num)`，那么：

 - 左半部分是`num[:n // 2]`- 中间数字仅存在于`n`很奇怪

 示例：

 -`"1221"`→ 左半边`"12"`-`"32123"`→ 左半边`"32"`, 中间数字`"1"`2. 将左半部分转换为可变数组。 

字符串在 Python 和 Go 中都是不可变的，因此我们使用数组或字符切片来进行就地交换和反转。 
3. 找到下一个排列的枢轴。 

从末尾开始，找到第一个索引`i`这样：```
arr[i] < arr[i + 1]
```该索引右侧的所有内容均按降序排列。 

如果不存在这样的索引，则左半部分已经是最大可能的排列，因此不存在更大的回文。 
4. 找到比主元大的最小数字。 

重新从末尾开始，找到第一个索引`j`这样：```
arr[j] > arr[i]
```交换`arr[i]`和`arr[j]`。 
5. 反转枢轴后的后缀。 

后缀以前是按降序排列的。 

将其反转即可将其转换为升序，从而给出字典顺序上最小的较大排列。 
6. 构造回文。 

- 将修改后的左半部分转换回字符串
 - 翻转它以形成镜像的右半部分
 - 如果长度是奇数，则插入中间数字
 7. 返回构造好的回文。 

### 为什么它有效

 下一个排列算法保证左半部分按字典顺序排列的最小排列。 

由于回文数由其左半部分和可选的中间数字唯一确定，因此所得的镜像回文数也是严格大于原始数的最小回文数。 

如果不存在下一个排列，则无法从数字中形成更大的回文。 

## Python 解决方案```python
class Solution:
    def nextPalindrome(self, num: str) -> str:
        n = len(num)

        if n == 1:
            return ""

        half_length = n // 2
        left_half = list(num[:half_length])

        # Step 1: Find pivot
        pivot = half_length - 2
        while pivot >= 0 and left_half[pivot] >= left_half[pivot + 1]:
            pivot -= 1

        # No next permutation exists
        if pivot < 0:
            return ""

        # Step 2: Find next larger element
        swap_index = half_length - 1
        while left_half[swap_index] <= left_half[pivot]:
            swap_index -= 1

        # Step 3: Swap
        left_half[pivot], left_half[swap_index] = (
            left_half[swap_index],
            left_half[pivot],
        )

        # Step 4: Reverse suffix
        left_half[pivot + 1:] = reversed(left_half[pivot + 1:])

        left = "".join(left_half)
        right = left[::-1]

        if n % 2 == 1:
            middle = num[half_length]
            return left + middle + right

        return left + right
```该实现遵循仅应用于回文左半部分的标准下一个排列算法。 

第一部分提取左半部分并处理单位数边缘情况。 单个数字不能使用相同的数字产生更大的回文。 

接下来，算法向后搜索主元索引。 这标识了序列停止不增加的位置。 

如果不存在主元，则左半部分已经是最大排列，意味着无法形成更大的回文。 

找到枢轴后，代码会找到右侧最小的较大数字并交换它们。 这确保了增量最小。 

后缀反转会在主元之后产生尽可能小的排序，从而保证下一个词典排列，而不仅仅是任何更大的排列。 

最后，代码镜像更新的左半部分，并在必要时插入中间数字。 

## 解决方案```go
package main

func nextPalindrome(num string) string {
	n := len(num)

	if n == 1 {
		return ""
	}

	halfLen := n / 2
	left := []byte(num[:halfLen])

	// Step 1: Find pivot
	pivot := halfLen - 2
	for pivot >= 0 && left[pivot] >= left[pivot+1] {
		pivot--
	}

	// No next permutation
	if pivot < 0 {
		return ""
	}

	// Step 2: Find next larger element
	swapIndex := halfLen - 1
	for left[swapIndex] <= left[pivot] {
		swapIndex--
	}

	// Step 3: Swap
	left[pivot], left[swapIndex] = left[swapIndex], left[pivot]

	// Step 4: Reverse suffix
	reverse(left[pivot+1:])

	leftStr := string(left)

	// Build reversed half
	right := reverseString(leftStr)

	if n%2 == 1 {
		middle := string(num[halfLen])
		return leftStr + middle + right
	}

	return leftStr + right
}

func reverse(arr []byte) {
	i, j := 0, len(arr)-1

	for i < j {
		arr[i], arr[j] = arr[j], arr[i]
		i++
		j--
	}
}

func reverseString(s string) string {
	bytes := []byte(s)

	i, j := 0, len(bytes)-1

	for i < j {
		bytes[i], bytes[j] = bytes[j], bytes[i]
		i++
		j--
	}

	return string(bytes)
}
```Go 实现密切反映了 Python 逻辑。 

因为 Go 字符串是不可变的，所以左半部分被转换为`[]byte`切片以进行有效的就地修改。 

后缀反转是通过直接在切片上操作的辅助函数来实现的。 另一个助手反转最后的字符串以构造镜像的一半。 

与 Python 切片不同，Go 需要显式辅助函数来进行反转操作。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个字符被访问的次数是固定的 |
 | 空间| O(n) | 字符数组和结果构造需要线性空间 |

 下一个排列算法本身是线性的，因为每次扫描最多遍历半串一次。 

由于字符串的创建和反转，构造最终的回文还需要线性时间和空间。 

由于只有一半的回文是直接处理的，所以实际操作量大约与`n / 2`，但渐进地这仍然是`O(n)`。

 ## 边缘情况

 ### 边缘情况 1，单个数字输入

 单个数字已经是使用该数字的唯一可能的回文。 没有更大的重组。 

例如：```
"7"
```执行立即返回`""`什么时候`n == 1`。 

### 边缘情况 2，左半部分已经最大

 如果左半部分已经按降序排列，则不存在下一个排列。 

例如：```
num = "32123"
left half = "32"
```自从`"32"`是这些数字的最大排列，没有更大的回文。 

枢轴搜索失败并返回`-1`，导致算法返回`""`。 

### 边缘情况 3，重复数字

 重复的数字很容易在下一个排列实现中引入错误。 

例如：```
"45544554"
```该算法必须仔细选择比主元大的最右边的数字并正确反转后缀。 

即使有重复，使用标准的下一个排列过程也能保证正确性。 

### 边缘情况 4，奇数长度回文

 奇数长度回文包含不参与排列的中间数字。 

例如：```
"12321"
```只有左半边`"12"`变化。 中间的数字`"3"`保持固定。 

该实现准确地保留了中间数字，同时镜像更新的左半部分。
