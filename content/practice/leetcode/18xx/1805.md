[LeetCode 问题 1805](https://leetcode.com/problems/number-of- Different-integers-in-a-string/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 该问题需要我们处理一个字符串`word`包含小写英文字母和数字。 我们被要求将所有数字序列提取为整数，忽略任何非数字字符。 提取这些序列后，我们需要计算存在多少个**唯一整数**，考虑到带有前导零的整数相当于它们的非零对应项。 例如，`"001"`和`"1"`被认为是相同的整数。 

输入`word`长度在 1 到 1000 个字符之间，因此我们不需要针对非常大的字符串进行优化。 关键的挑战是正确处理由字母分隔的数字序列，将它们转换为整数表示形式，并有效地消除重复项。 

重要的边缘情况包括具有多个前导零的字符串、仅包含字母（无整数）的字符串以及具有由字母分隔的连续数字的字符串。 该问题保证输入中至少有一个字符，因此我们不需要处理空输入字符串。 

## 方法

 强力方法是逐个字符地迭代字符串，为每个数字序列构建子字符串。 一旦找到非数字字符或到达字符串末尾，我们就将子字符串转换为整数（删除前导零）并将其存储在列表中。 处理整个字符串后，我们可以使用循环来计算唯一整数。 这种方法工作正常，但效率低下，因为我们可能会反复搜索列表以检查重复项。 

最佳方法利用**哈希集**来自动处理唯一性。 我们迭代字符串，累积数字序列的字符，并将每个完整序列转换为不带前导零的整数字符串。 然后我们将这个清理过的整数字符串插入到集合中。 使用集合可确保每个整数仅计算一次，并且我们可以避免重复搜索重复项。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 构建所有整数的列表并搜索重复项 |
 | 最佳 | O(n) | O(n) | 使用哈希集有效存储唯一整数字符串 |

 ## 算法演练

 1.初始化一个空字符串`current_number`累积数字和空集`unique_numbers`存储唯一的整数。 
2. 迭代每个字符`ch`在字符串中`word`。 
3.如果`ch`是一个数字，将其附加到`current_number`。 
4.如果`ch`是一个字母并且`current_number`不为空，去掉前导零`current_number`（如果数字是，请确保至少保留一个零`"0"`），并将其添加到`unique_numbers`。 然后重置`current_number`到一个空字符串。 
5. 循环结束后，检查是否`current_number`包含一个数字。 如果是这样，则去掉前导零并将其添加到`unique_numbers`。 
6.返回尺寸`unique_numbers`，表示字符串中不同整数的数量。 

**为什么有效**：每个数字序列仅处理一次，前导零被标准化，并且哈希集自动删除重复项。 这样就保证了正确性。 

## Python 解决方案```python
class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        unique_numbers = set()
        current_number = ""
        
        for ch in word:
            if ch.isdigit():
                current_number += ch
            else:
                if current_number:
                    # Remove leading zeros and ensure "0" remains if empty
                    cleaned_number = current_number.lstrip('0') or '0'
                    unique_numbers.add(cleaned_number)
                    current_number = ""
        
        if current_number:
            cleaned_number = current_number.lstrip('0') or '0'
            unique_numbers.add(cleaned_number)
        
        return len(unique_numbers)
```该实现迭代每个字符并构造数字序列`current_number`。 当遇到非数字时，累积的数字将被清除前导零并添加到集合中，以确保唯一性。 最终设置的大小作为结果返回。 

## 解决方案```go
import (
    "strings"
)

func numDifferentIntegers(word string) int {
    uniqueNumbers := make(map[string]struct{})
    currentNumber := ""
    
    for _, ch := range word {
        if ch >= '0' && ch <= '9' {
            currentNumber += string(ch)
        } else {
            if currentNumber != "" {
                cleanedNumber := strings.TrimLeft(currentNumber, "0")
                if cleanedNumber == "" {
                    cleanedNumber = "0"
                }
                uniqueNumbers[cleanedNumber] = struct{}{}
                currentNumber = ""
            }
        }
    }
    
    if currentNumber != "" {
        cleanedNumber := strings.TrimLeft(currentNumber, "0")
        if cleanedNumber == "" {
            cleanedNumber = "0"
        }
        uniqueNumbers[cleanedNumber] = struct{}{}
    }
    
    return len(uniqueNumbers)
}
```Go 解决方案在逻辑上与 Python 版本几乎相同。 我们使用映射作为集合，将数字序列转换为干净的字符串。 Go 要求在修剪前导零后显式处理空字符串。

 ## 边缘情况

 1. **前导零**：像这样的数字`"01"`,`"001"`和`"1"`应被视为相同的整数。 如果直接比较字符串，这可能会使幼稚的实现出错。 该解决方案通过去除前导零来处理这个问题。 
2. **Only Letters**：如果输入不包含数字，结果应该是`0`。 该解决方案正确返回空集的长度。 
3. **连续零**：输入如下`"0000"`应该算作一个唯一的整数`"0"`。 该解决方案确保如果所有数字均为零，则归一化数为`"0"`并添加一次到集合中。 
4. **末尾数字**：如果字符串的最后一个字符形成数字，则必须在循环结束后处理。 两种实现都在主循环之外处理最终检查。 
5. **大数字**：即使一个数字非常大（例如，10位数字），Python也会自然地处理它，并且在Go中我们将其存储为字符串以避免整数溢出。 

该解决方案可以稳健地处理所有边缘情况，同时保持最佳效率。
