[LeetCode 问题 1822](https://leetcode.com/problems/sign-of-the-product-of-an-array/)

 **难度：** 🟢简单
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 该问题要求我们确定整数数组中所有数字的乘积的符号，而不必计算实际的乘积本身。 

辅助函数`signFunc(x)`定义为：

 - 返回`1`如果`x > 0`- 返回`-1`如果`x < 0`- 返回`0`如果`x == 0`我们得到一个数组`nums`，我们从概念上将其所有元素相乘以形成一个称为`product`。 我们的任务是归还该产品的标志。 

例如：

 - 如果数组包含偶数个负值且没有零，则最终乘积为正，因此答案为`1`。 
- 如果数组包含奇数个负值且没有零，则最终乘积为负数，因此答案为`-1`。 
- 如果有任何值`0`，整个产品就变成了`0`，所以答案是`0`。 

限制很小：

 -`1 <= nums.length <= 1000`-`-100 <= nums[i] <= 100`尽管值本身并不大，但在其他语言或场景中重复将数字相乘仍然可以创建非常大的乘积。 更重要的是，问题只要求标志，而不要求实际的产品价值。 这一观察结果直接导致了更高效、更清洁的解决方案。 

一些重要的边缘情况包括：

 - 包含零的数组，因为答案立即变为`0`- 仅有一个负数的数组
 - 具有许多负数的数组，其中奇偶校验很重要
 - 长度数组`1`- 仅包含正值的数组

 该问题保证数组非空，因此我们永远不需要处理空输入。 

## 方法

 ### 蛮力方法

 最直接的方法是计算数组中所有数字的实际乘积，然后确定其末尾的符号。 

我们初始化一个变量`product = 1`并将每个元素相乘。 处理数组后：

 - 如果`product > 0`， 返回`1`- 如果`product < 0`， 返回`-1`- 否则返回`0`这是有效的，因为乘法保留了正确的数学结果。 

然而，这种方法并不理想。 尽管这个问题的约束足够小，足以避免 Python 中的溢出，但其他语言在将许多整数相乘时可能会溢出。 更重要的是，计算整个乘积是不必要的，因为只有符号才重要。 

### 最佳方法

 关键的观察是我们永远不需要实际的产品价值。 

产品的标志仅取决于两件事：

 - 任何数字是否为零
 - 负数的个数是奇数还是偶数

 规则是：

 - 如果有任何元素`0`，答案立即`0`- 每个负数都会翻转符号
 - 偶数个负值产生正结果
 - 奇数个负值会产生负结果

 我们可以简单地跟踪当前符号，而不是计算乘积。 

我们初始化`sign = 1`。 

对于每个数字：

 - 如果号码是`0`， 返回`0`- 如果数字为负数，则相乘`sign`经过`-1`- 否则什么都不做

 最后返回`sign`。 

这避免了不必要的乘法并使逻辑极其简单。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 直接计算完整的乘积 |
 | 最佳| O(n) | O(1) | O(1) | 使用负计数奇偶校验仅跟踪符号 |

 ## 算法演练

 1. 初始化变量`sign = 1`。 

该变量代表目前为止看到的产品的符号。 我们从正数开始，因为乘以`1`不会改变任何东西。 
2. 迭代数组中的每个数字。 

我们一次处理每个元素，以确定它如何影响最终的符号。 
3. 如果当前号码是`0`，立即返回`0`。 

任何包含零的乘积都会变为零，因此我们可以提前停止而不处理剩余元素。 
4. 如果当前数字为负数，则翻转符号。 

负数会将正乘积变为负乘积，反之亦然。 我们可以通过乘法来实现`sign`经过`-1`。 
5. 如果当前数字为正数，则不执行任何操作。 

正数不会改变乘积的符号。 
6.处理完所有元素后，返回`sign`。 

在此刻，`sign`正确表示总乘积是正还是负。 

### 为什么它有效

 该算法之所以有效，是因为乘法符号遵循简单的数学规则：

 - 乘以正数保留当前符号
 - 乘以负数翻转符号
 - 乘以零使整个乘积为零

 通过仅跟踪这些符号变化，我们获得与计算完整乘积完全相同的结果，同时避免不必要的算术。 

## Python 解决方案```python
from typing import List

class Solution:
    def arraySign(self, nums: List[int]) -> int:
        sign = 1

        for num in nums:
            if num == 0:
                return 0

            if num < 0:
                sign *= -1

        return sign
```实现从初始化开始`sign`到`1`，代表正积。 

然后我们迭代每个值`nums`。 

如果一个值是`0`，我们立即返回`0`因为无论剩余元素如何，最终的乘积都必须为零。 

如果一个值为负数，我们乘以`sign`经过`-1`。 每次遇到负数时，都会翻转符号。 

正数被忽略，因为它们不影响符号。 

循环结束后，`sign`包含正确答案并返回。 

## 解决方案```go
func arraySign(nums []int) int {
	sign := 1

	for _, num := range nums {
		if num == 0 {
			return 0
		}

		if num < 0 {
			sign *= -1
		}
	}

	return sign
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

一个显着的区别是 Go 使用`range`循环遍历切片。 由于我们从不计算实际的乘积，因此整数溢出不是问题。 

该问题保证输入切片至少包含一个元素，因此不需要对空切片进行特殊处理。

 ## 边缘情况

 一个非常重要的边缘情况是数组包含零。 继续不必要地相乘值的简单实现可能仍然有效，但尽早识别零可以让算法立即终止。 在这个实现中，时刻`0`遇到，函数返回`0`。 

另一个重要的情况是奇数个负值。 由于每个负数都会翻转符号，因此忘记正确跟踪奇偶校验可能会产生错误的结果。 该实现通过乘以`sign`变量由`-1`每次出现负值时。 

长度为 1 的数组也很重要。 该数组可以包含单个正数、单个负数或零。 由于该算法独立处理每个元素并直接应用符号规则，因此可以自然地处理这些最小的可能输入，无需任何特殊情况逻辑。
