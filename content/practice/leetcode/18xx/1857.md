 **难度：** 🔴难
 **主题：** 哈希表、字符串、动态规划、图论、拓扑排序、记忆、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们在有向图中找到**沿任何路径**的最大颜色值`n`节点，其中每个节点都有一个由小写英文字母表示的颜色。 该图可能包含循环，在这种情况下该函数应返回`-1`。 

输入由一个字符串组成`colors`在哪里`colors[i]`是节点的颜色`i`，和一个二维数组`edges`其中每个元素`[a, b]`表示从节点开始的有向边`a`到节点`b`。 输出是一个整数，表示路径中共享该路径上**最常出现的颜色**的节点的最大数量。 

约束表明`n`和`m`每个都可以达到`10^5`，因此任何明确探索所有路径的强力方法都会太慢。 该图不能保证是非循环的，因此循环检测至关重要。 边缘情况包括单节点图、自循环和断开的组件。 

## 方法

 暴力方法将涉及枚举图中的**所有可能的路径**，计算每条路径上每种颜色的频率，并跟踪最大频率。 虽然正确，但这是**不可行的**，因为由于循环和分支，路径数量会随着节点数量呈指数增长。 

最佳解决方案的关键观察是，这个问题可以被视为**动态规划的拓扑排序问题**。 如果我们可以按拓扑顺序遍历图，我们就可以沿着路径**传播颜色频率**。 每个节点维护一个大小为 26 的频率数组，表示沿以该节点结束的所有路径上每种颜色的最大出现次数。 通过从父级到子级更新频率数组，我们可以有效地计算最大颜色值。 为了检测循环，我们可以跟踪入度并使用卡恩算法风格的拓扑排序。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 枚举所有路径，对于 n ~ 10^5 不可行 |
 | 最佳| O(n + m) | O(n * 26) | 拓扑排序+色频传播动态规划|

 ## 算法演练

 1. **图表示**：从边构建邻接表。 对于每个节点，维护其传出邻居的列表。 另外，计算每个节点的入度。 
2. **拓扑排序初始化**：初始化一个队列，所有节点的入度都为零。 这些节点没有依赖关系，可以先处理。 
3. **动态规划表**：对于每个节点，维护一个`count`大小为 26 的数组，表示沿以该节点结束的任何路径上每种颜色的最大频率。 初始化`count[i][color_index] = 1`对于每个节点。 
4. **处理节点**：当队列不为空时，弹出一个节点`u`。 对于每个邻居`v`的`u`， 更新`v`的`count`数组使得对于每种颜色`c`,`count[v][c] = max(count[v][c], count[u][c] + (colors[v] == c))`。 减少入度`v`。 如果入度变为零，则入队`v`。 
5. **循环检测**：保留已处理的节点计数器。 如果在BFS结束时，处理的节点数小于`n`,存在环路，返回`-1`。 
6. **结果计算**：在传播过程中，保持全局最大值`count[u][c]`跨所有节点和颜色。 返回该最大值作为最大颜色值。 

**为什么有效**：通过使用拓扑顺序，我们保证在处理节点时，所有通向该节点的路径都已被考虑。 DP 阵列确保每个节点的颜色贡献沿着路径正确传播。 循环检测可确保非 DAG 图中的正确性。 

## Python 解决方案```python
from collections import deque, defaultdict
from typing import List

class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        graph = defaultdict(list)
        indegree = [0] * n
        
        # Build graph
        for u, v in edges:
            graph[u].append(v)
            indegree[v] += 1
        
        # DP table for each node: count of each color along path ending at node
        dp = [[0] * 26 for _ in range(n)]
        for i in range(n):
            dp[i][ord(colors[i]) - ord('a')] = 1
        
        # Topological sort
        queue = deque([i for i in range(n) if indegree[i] == 0])
        processed = 0
        max_color_value = 0
        
        while queue:
            u = queue.popleft()
            processed += 1
            for v in graph[u]:
                for c in range(26):
                    increment = 1 if c == ord(colors[v]) - ord('a') else 0
                    dp[v][c] = max(dp[v][c], dp[u][c] + increment)
                indegree[v] -= 1
                if indegree[v] == 0:
                    queue.append(v)
            max_color_value = max(max_color_value, max(dp[u]))
        
        return max_color_value if processed == n else -1
```Python 实现构建图表，初始化颜色计数的 DP 表，并按拓扑顺序处理节点。 对于每个节点，通过考虑所有父节点并在节点颜色匹配时增加计数来更新 DP 数组。 循环检测是通过比较已处理节点的数量来实现的`n`。 

## 解决方案```go
package main

func largestPathValue(colors string, edges [][]int) int {
    n := len(colors)
    graph := make([][]int, n)
    indegree := make([]int, n)
    
    for _, edge := range edges {
        u, v := edge[0], edge[1]
        graph[u] = append(graph[u], v)
        indegree[v]++
    }
    
    dp := make([][26]int, n)
    for i := 0; i < n; i++ {
        dp[i][colors[i]-'a'] = 1
    }
    
    queue := []int{}
    for i := 0; i < n; i++ {
        if indegree[i] == 0 {
            queue = append(queue, i)
        }
    }
    
    processed := 0
    maxColor := 0
    
    for len(queue) > 0 {
        u := queue[0]
        queue = queue[1:]
        processed++
        for _, v := range graph[u] {
            for c := 0; c < 26; c++ {
                increment := 0
                if byte(c+'a') == colors[v] {
                    increment = 1
                }
                if dp[u][c]+increment > dp[v][c] {
                    dp[v][c] = dp[u][c] + increment
                }
            }
            indegree[v]--
            if indegree[v] == 0 {
                queue = append(queue, v)
            }
        }
        for c := 0; c < 26; c++ {
            if dp[u][c] > maxColor {
                maxColor = dp[u][c]
            }
        }
    }
    
    if processed < n {
        return -1
    }
    return maxColor
}
```Go 版本反映了 Python 方法，使用切片和数组而不是 Python 列表和字典。 主要区别是队列的显式切片管理和颜色的字节到整数转换的仔细处理。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + m) | 每个节点处理一次，每条边遍历一次，26色DP数组更新恒定 |

 该算法相对于节点和边的数量是线性的，这对于问题约束是有效的。
