[LeetCode 问题 1850](https://leetcode.com/problems/minimum-adjacent-swaps-to-reach-the-kth-smallest-number/)

 **难度：** 🟡 中等
 **主题：** 两个指针、字符串、贪婪

 ## 解决方案

 ## 问题理解

 该问题要求我们计算转换给定数字所需的**相邻交换**的最小数量`num`变成 **第 k 个最小的奇妙整数**。 一个美妙的整数是任意排列`num`**严格大于**的数字`num`。 在所有这些排列中，我们只关心`kth`最小的一个。 

输入由一个字符串组成`num`，表示一个可能非常大的整数，以及一个整数`k`，表示目标排列在所有奇数的升序中的位置。 输出是一个整数，表示转换原始数据的**相邻数字**交换的最小次数`num`进入这个目标排列。 

限制条件是：

 -`num`长度在 2 到 1000 之间，因此解决方案需要有效地处理中等大小的字符串。 
-`k`最多为 1000，这意味着我们无法显式生成所有排列，但我们只需要执行最多`k`下一个排列逻辑的迭代。 
- 输入仅由数字组成，因此无需处理非数字字符。 

要考虑的边缘情况包括具有重复数字的数字、具有前导零的数字以及以下情况`k = 1`（第一个下一个排列）。 该问题保证了第k个最小的奇妙整数存在，因此我们不需要处理少于的情况`k`排列。 

## 方法

 蛮力方法将涉及生成所有排列`num`大于`num`，对它们进行排序，然后选择`kth`最小的一个。 然后，我们将计算要转换的相邻交换的最小数量`num`通过模拟冒泡排序样式交换进入目标排列。 虽然正确，但这种方法是不可行的，因为排列的数量随着长度的增加呈阶乘增长`num`。 

最佳方法的关键见解有两个：首先，我们可以迭代地计算**下一个排列**`k`次获得`kth`无需生成所有排列的最小奇妙数。 其次，一旦我们有了目标排列，我们就可以通过**贪婪地将原始数字中的每个数字移动到目标数字中的位置**，计算每个相邻交换来计算最小相邻交换。 

这将问题从阶乘复杂度降低到`O(k * n + n^2)`复杂度，其中`n`的长度是`num`和`k`是我们需要的下一个排列的数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n) | O(n! * n) | O(n!) | 生成所有排列、排序和计数交换 |
 | 最佳| O(k * n + n^2) | O(k * n + n^2) | O(n) | 使用 k 个下一个排列步骤和贪婪的相邻交换 |

 ## 算法演练

 1. 转换`num`到一个字符列表中以实现可变性。 
2. 应用**下一个排列**算法`k`次。 该算法的工作原理是从列表末尾开始扫描，找到第一个递减的元素，将其与下一个较大的元素交换，然后反转后缀。 后`k`迭代，我们有`kth`最小的奇妙数。 
3. 初始化计数器`swaps`到 0。这将跟踪所需的相邻交换数量。 
4. 迭代每个索引`i`的原始数量。 对于每个索引：

 - 如果索引处的数字`i`与目标中的数字匹配，继续。 
- 否则，找到位置`j`在目标数字所在的原始列表中。 
- 将数字移动到位置`j`定位`i`通过执行`j - i`相邻交换，递增`swaps`相应地，并更新列表。 
5.处理完所有数字后，返回`swaps`作为相邻交换的最小数量。 

**为什么有效：** 下一个排列算法确保我们获得精确的第 k 个最小排列。 贪婪相邻交换方法保证了最少的交换次数，因为每次交换都会使目标数字更接近其最终位置，而不会产生不必要的移动。 

## Python 解决方案```python
class Solution:
    def getMinSwaps(self, num: str, k: int) -> int:
        # Step 1: Convert to list for mutability
        num_list = list(num)
        target_list = list(num)
        
        # Step 2: Compute kth next permutation
        for _ in range(k):
            i = len(target_list) - 2
            while i >= 0 and target_list[i] >= target_list[i + 1]:
                i -= 1
            if i >= 0:
                j = len(target_list) - 1
                while target_list[j] <= target_list[i]:
                    j -= 1
                target_list[i], target_list[j] = target_list[j], target_list[i]
            target_list[i+1:] = reversed(target_list[i+1:])
        
        # Step 3: Count minimum adjacent swaps
        swaps = 0
        num_list_copy = num_list.copy()
        for i in range(len(num_list)):
            if num_list_copy[i] != target_list[i]:
                j = i
                while num_list_copy[j] != target_list[i]:
                    j += 1
                while j > i:
                    num_list_copy[j], num_list_copy[j-1] = num_list_copy[j-1], num_list_copy[j]
                    swaps += 1
                    j -= 1
        return swaps
```**解释：** 我们首先使用下一个排列技术生成第 k 个最小的奇妙数。 然后，我们迭代原始数字并通过计算最小相邻交换来贪婪地移动每个数字以匹配目标。 每个内循环最多执行`n`每个数字的交换，导致`O(n^2)`掉期计算的复杂性。 

## 解决方案```go
func getMinSwaps(num string, k int) int {
    numList := []byte(num)
    targetList := []byte(num)

    // Compute kth next permutation
    for t := 0; t < k; t++ {
        i := len(targetList) - 2
        for i >= 0 && targetList[i] >= targetList[i+1] {
            i--
        }
        if i >= 0 {
            j := len(targetList) - 1
            for targetList[j] <= targetList[i] {
                j--
            }
            targetList[i], targetList[j] = targetList[j], targetList[i]
        }
        left, right := i+1, len(targetList)-1
        for left < right {
            targetList[left], targetList[right] = targetList[right], targetList[left]
            left++
            right--
        }
    }

    // Count minimum adjacent swaps
    swaps := 0
    numCopy := append([]byte{}, numList...)
    for i := 0; i < len(numList); i++ {
        if numCopy[i] != targetList[i] {
            j := i
            for numCopy[j] != targetList[i] {
                j++
            }
            for j > i {
                numCopy[j], numCopy[j-1] = numCopy[j-1], numCopy[j]
                swaps++
                j--
            }
        }
    }
    return swaps
}
```**说明：** Go 解决方案镜像了 Python 解决方案。 我们使用`[]byte`用于可变性的切片和用于计算相邻交换的类似嵌套循环结构。 Go 需要仔细的切片处理，这是使用`append`复制原始切片。
