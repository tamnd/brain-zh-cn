[LeetCode 1813 题](https://leetcode.com/problems/sentence-similarity-iii/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、字符串

 ## 解决方案

 ## 问题理解

 问题是要求我们确定是否可以通过将连续的单词序列（可能是空的）插入到其中一个句子中来使两个句子**相同**。 每个句子都是一串由单个空格分隔的单词。 重要的是，插入必须发生在单词之间，而不是通过改变任何现有的单词。 

输入由两个字符串组成，`sentence1`和`sentence2`。 预期输出是一个布尔值：`true`如果可以通过在其中一个句子中插入一个句子来使句子相同，并且`false`否则。 

需要注意的是，两个句子都只包含英文字母和空格，单词之间用单个空格分隔，每个句子的长度上限为 100 个字符。 这意味着我们可以使用与字数成线性的方法，而不必担心性能问题。 

重要的边缘情况包括：

 - 一个句子完全包含在另一个句子的开头或结尾（例如，`"Eating"`与`"Eating right now"`）。 
- 句子没有匹配的前缀或后缀。 
- 只有一个词的句子。 
- 中间有一个单词不同的句子。 

## 方法

 暴力方法将尝试将一个句子中的每一种可能的连续子串插入到另一个句子中，并比较结果句子以查看其是否匹配。 这将需要 O(n² * m) 时间，其中 n 和 m 是句子中的单词数，这是不必要且低效的。 

最佳解决方案的关键观察是**句子必须共享公共前缀和/或后缀**。 如果我们从开头和结尾删除匹配的单词，则较长句子中剩下的任何内容都可以被视为“插入的句子”。 如果较短句子的剩余中间为空，则句子相似。 这可以使用双指针方法有效地实现：一个指针从两个单词列表的开头开始并在单词匹配时前进，另一个指针从末尾开始并在单词匹配时向后移动。

 ## 算法演练

 1. 将两个句子分成单词列表。 让`words1`和`words2`代表两个句子。 这使得索引和比较变得容易。 
2.初始化两个指针，`i`从 0 开始进行前缀比较，以及`j`从两个列表的最后一个索引开始进行后缀比较。 
3. 移动指针`i`向前只要`words1[i] == words2[i]`并且两个指针都没有到达末尾。 这标识了公共前缀。 
4. 移动指针`j`向后只要`words1[end1 - j] == words2[end2 - j]`其余单词不与前缀指针重叠。 这标识了公共后缀。 
5. 两个指针都前进后，检查前缀和后缀是否完全覆盖较短的句子。 如果是，则句子相似； 否则，他们就不是。 

**为什么有效**：该算法保证所有可以匹配的开头和结尾的单词都被匹配。 如果整个较短的句子通过前缀和后缀进行匹配，则较长句子中剩余的单词代表可能插入的句子。 没有其他插入可以使它们相等。 

## Python 解决方案```python
class Solution:
    def areSentencesSimilar(self, sentence1: str, sentence2: str) -> bool:
        words1 = sentence1.split()
        words2 = sentence2.split()
        
        # Ensure words1 is the shorter sentence
        if len(words1) > len(words2):
            words1, words2 = words2, words1
        
        i = 0
        while i < len(words1) and words1[i] == words2[i]:
            i += 1
        
        j = 0
        while j < len(words1) - i and words1[len(words1) - 1 - j] == words2[len(words2) - 1 - j]:
            j += 1
        
        return i + j == len(words1)
```该实现首先将句子分割成单词列表。 为了简化处理，我们始终将`words1`作为较短的句子。 前缀指针`i`当单词匹配时向前移动。 后缀指针`j`向后移动，确保它不与前缀重叠。 最后，我们检查较短句子中的所有单词是否都已匹配； 如果是这样，连续插入可以使句子相等。 

## 解决方案```go
func areSentencesSimilar(sentence1 string, sentence2 string) bool {
    words1 := strings.Fields(sentence1)
    words2 := strings.Fields(sentence2)
    
    if len(words1) > len(words2) {
        words1, words2 = words2, words1
    }
    
    i := 0
    for i < len(words1) && words1[i] == words2[i] {
        i++
    }
    
    j := 0
    for j < len(words1) - i && words1[len(words1)-1-j] == words2[len(words2)-1-j] {
        j++
    }
    
    return i + j == len(words1)
}
```Go 实现镜像了 Python 版本，使用`strings.Fields`将句子拆分成单词。 Go 需要小心切片索引，尤其是后缀比较。 其他方面的逻辑保持相同。
