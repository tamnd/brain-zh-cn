[LeetCode 问题 1897](https://leetcode.com/problems/redistribute-characters-to-make-all-strings-equal/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串、计数

 ## 解决方案

 ## 问题理解

 问题问是否可以将输入数组中的所有字符串`words`通过在它们之间重新分配字符来实现相等。 具体来说，在一个操作中，您可以从一个字符串中选取任何字符并将其移动到另一个字符串的任意位置。 目标是确定在可能进行多次此类操作之后，每个字符串是否可以变得相同。 

输入是一个字符串数组`words`，其中每个字符串仅包含小写英文字母。 输出是一个布尔值：`true`如果所有字符串都可以相等，并且`false`否则。 约束表明字符串的数量和每个字符串的长度适中（最多 100 个），因此我们可以使用简单的计数技术来处理整个字符集，而不必担心性能瓶颈。 

主要观察结果包括所有字符串中每个字符的总数必须能被字符串数量整除。 如果不是，就不可能均匀地分配该字符，答案一定是`false`。 

可能会导致幼稚实现失败的边缘情况包括仅包含一个字符串的数组、已经相等的字符串、包含无法均匀分布的字符的字符串以及包含一个字符串唯一的字符的字符串。 

## 方法

 暴力方法会尝试模拟字符串之间的字符移动，直到它们全部相等。 这将涉及反复选择角色并尝试所有组合，这是组合爆炸性的。 即使对于很小的输入，这也会非常缓慢且不必要。 

关键的见解是我们不需要模拟运动。 重要的是每个字符在所有字符串中的总频率。 如果每个字符的频率可以被字符串的数量整除，那么就可以均匀地重新分配它们。 否则的话，那是不可能的。 这将问题简化为简单的计数和整除性检查。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n * n!) | O(k^n * n!) | O(n) | 模拟字符串之间的字符移动，这对于较大的输入是不可行的 |
 | 最佳| O(n * m + 26) ≈ O(n * m) | O(26) ≈ O(1) | O(26) ≈ O(1) | 计算字符数并检查字符串数量的整除性，简单高效 |

 这里，`n`是字符串的数量，`m`是字符串的平均长度。 这`26`来自小写字母的数量。 

## 算法演练

 1.初始化一个数组`count`大小为 26 来存储每个小写字母的频率。 
2. 遍历每个字符串`words`。 
3. 对于字符串中的每个字符，增加相应的频率`count`大批。 
4. 统计完所有字符后，迭代`count`大批。 
5. 对于每个字符频率，检查它是否能被整除`len(words)`。 如果任何频率不可整除，则返回`false`。 
6. 如果所有字符频率都可以被整除`len(words)`， 返回`true`。 

为什么它有效：不变的是重新分配字符只会改变包含字符的字符串，而不改变总数。 如果每个字符可以均匀地分布在所有字符串中，那么就保证我们可以执行所需的操作以使每个字符串都相同。 

## Python 解决方案```python
from typing import List

class Solution:
    def makeEqual(self, words: List[str]) -> bool:
        count = [0] * 26  # Frequency of each lowercase letter
        
        for word in words:
            for char in word:
                count[ord(char) - ord('a')] += 1
        
        for freq in count:
            if freq % len(words) != 0:
                return False
        
        return True
```在这个实现中，我们首先为小写英文字母初始化一个大小为 26 的频率数组。 我们迭代每个单词和单词中的每个字符，更新相应的频率。 然后我们检查每个频率是否可以均匀分布在所有单词中。 如果有任何不能，我们返回`false`。 否则，我们返回`true`。 

## 解决方案```go
func makeEqual(words []string) bool {
    count := [26]int{}
    
    for _, word := range words {
        for _, char := range word {
            count[char-'a']++
        }
    }
    
    n := len(words)
    for _, freq := range count {
        if freq % n != 0 {
            return false
        }
    }
    
    return true
}
```Go 实现镜像了 Python 版本。 我们使用长度为 26 的固定大小数组来进行字符计数。 我们迭代每个单词和每个字符，更新计数。 然后，我们检查所有频率的整除性。 Go 通过符文处理字符串迭代，符文与 ASCII 小写字母自然对齐。

 ## 边缘情况

 第一个边缘情况是单字数组，例如，`["a"]`。 由于只有一个单词，因此它与自身相等，并且该函数应该返回`true`。 我们的实现可以处理这个问题，因为所有字符计数模 1 等于 0。 

第二种边缘情况是当字符串包含出现在不能被字符串数量整除的数字中的字母时，例如，`["a","b"]`。 该实现正确地识别出“a”和“b”无法均匀地重新分配并返回`false`。 

第三种边缘情况是当字符串已经相等但包含多个字符时，例如，`["aa","aa","aa"]`。 频率检查确认所有计数均可被单词数整除，因此算法返回`true`而不执行不必要的操作。 这样可以避免冗余计算并保证正确性。
