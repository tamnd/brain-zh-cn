[LeetCode 问题 1844](https://leetcode.com/problems/replace-all-digits-with-characters/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 In this problem, we are given a string`s`其中偶数索引处的字符始终为小写英文字母，奇数索引处的字符始终为数字。 

目标是将每个数字替换为根据其前面的字符计算出的新字符。 该操作称为`shift(c, x)`，这意味着：

 - 从角色开始`c`- 前进`x`字母表中的位置
 - 返回结果字符

 例如：

 -`shift('a', 1)`变成`'b'`-`shift('c', 2)`变成`'e'`-`shift('x', 0)`停留`'x'`输入字符串以可预测的方式在字母和数字之间交替：

 - 甚至位置也包含字母
 - 奇数位置包含数字

 对于每个奇数索引`i`，我们必须：

 1. 读取前一个字符`s[i - 1]`2. 转换数字`s[i]`化为整数
 3. 将前一个字符向前移动相应的量
 4. 用结果字符替换数字

 最后，我们返回完全转换后的字符串。 

限制非常小：

 -`1 <= s.length <= 100`这意味着效率不是主要问题，但我们仍然应该编写干净且优化的代码。 

一个重要的保证是：

 -`shift(s[i-1], s[i]) <= 'z'`这意味着我们永远不需要担心字母表的环绕。 每个移位的字符将仍然是有效的小写英文字母。 

一些重要的边缘情况包括：

 - 一个长度的字符串`1`，其中不存在数字
 - 数字等于`0`，角色保持不变
 - 多个交替的字母数字对
 - 确保正确处理字符算术

 ## 方法

 ### 蛮力方法

 暴力式解决方案将逐个字符地显式模拟移位操作。 

对于每个数字：

 1. 取前一个字母
 2. 在字母表中一次向前移动一步
 3. 重复直到数字数完
 4. 将数字替换为结果字母

 例如，转移`'a'`经过`3`将涉及：

 -`'a' -> 'b'`-`'b' -> 'c'`-`'c' -> 'd'`这种方法可以正确工作，因为它直接遵循移位运算的定义。 然而，一次重复移动一个角色是不必要的。 

尽管限制很小，但我们可以使用字符算术做得更好。 

### 最佳方法

 关键的观察结果是字符在内部存储为 ASCII 或 Unicode 整数值。 

例如：

-`'a'`有价值`97`-`'b'`有价值`98`-`'c'`有价值`99`所以通过改变一个字符`x`位置相当于：```
new_character = chr(ord(character) + x)
```这使我们能够在恒定时间内计算移位的字符。 

算法变得简单：

 1. 将字符串转换为可变数组
 2. 迭代奇数索引
 3.直接计算移位后的字符
 4. 替换数字
 5. 将数组重新连接成字符串

 这是高效、简单且易于实施的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * d) | O(n) | 模拟一次移动一步 |
 | 最佳| O(n) | O(n) | 使用直接字符算术 |

 这里，`n`是字符串长度，`d`是最大数字值，最多`9`。 

## 算法演练

 1. 将输入字符串转换为字符列表或数组。 

字符串在 Python 中是不可变的，因此转换为列表允许就地修改。 在 Go 中，字节片已经支持变异。 
2. 迭代所有奇数索引。 

由于该问题保证奇数索引包含数字，因此我们只需要处理位置`1, 3, 5, ...`。 
3. 对于每个奇数索引，读取前一个字符。 

字符位于`i - 1`保证是小写字母。 
4. 将数字字符转换为整数。 

例如，`'3'`变成`3`。 
5. 计算移位后的字符。 

使用字符算术：```
shifted = chr(ord(previous_char) + digit)
```6. 将数字替换为移位后的字符。 

这会就地转换字符串。 
7. 处理完所有奇数索引后，将字符连接回字符串并返回。 

### 为什么它有效

 该算法之所以有效，是因为奇数索引处的每个数字准确地代表了从前一个字符向前移动的位置。 字符算术直接对该操作进行建模。 

由于该问题保证移位结果永远不会超过`'z'`，将数字值添加到字符代码中始终会生成有效的小写字母。 

每个数字都是独立处理的，因此替换一位数字不会影响未来的计算。 

## Python 解决方案```python
class Solution:
    def replaceDigits(self, s: str) -> str:
        characters = list(s)

        for i in range(1, len(characters), 2):
            previous_char = characters[i - 1]
            digit = int(characters[i])

            shifted_char = chr(ord(previous_char) + digit)

            characters[i] = shifted_char

        return "".join(characters)
```实现首先将字符串转换为名为的列表`characters`。 这是必要的，因为 Python 字符串不能直接修改。 

循环从索引处开始`1`并增加`2`，确保仅处理奇数索引。 在每个奇数索引处：

 -`characters[i - 1]`给出前一个字母
 -`int(characters[i])`将数字字符转换为整数
 -`ord()`将字母转换为其 ASCII 数字值
 - 添加数字执行移位
 -`chr()`将数值转换回字符

 最后，`"".join(characters)`重建转换后的字符串。 

## 解决方案```go
func replaceDigits(s string) string {
    characters := []byte(s)

    for i := 1; i < len(characters); i += 2 {
        previousChar := characters[i-1]
        digit := characters[i] - '0'

        characters[i] = previousChar + digit
    }

    return string(characters)
}
```Go 实现使用字节切片，因为 Go 中的字符串是不可变的。 将字符串转换为`[]byte`允许就地更新。 

而不是`ord()`和`chr()`，Go可以直接操作ASCII字节值。 数字转换是使用以下方法完成的：```go
digit := characters[i] - '0'
```这会转换一个字符，例如`'3'`转化为数值`3`。 

移位后的字符直接用字节算术计算。

 ## 边缘情况

 一个重要的边缘情况是一串长度`1`。 在这种情况下，字符串仅包含字母，不包含数字。 有缺陷的实现可能会错误地假设每个字符串至少有一位数字。 该解决方案可以自然地处理这种情况，因为奇数索引上的循环永远不会执行。 

另一个重要的边缘情况是数字值`0`。 当移位为零时，结果字符应保持不变。 例如，`"a0"`变成`"aa"`。 该实现可以正确处理这个问题，因为添加`0`到字符代码使字符保持不变。 

第三个重要的边缘情况涉及字母表末尾附近的字母，例如`'x'`,`'y'`， 或者`'z'`。 不正确的实现可能会意外超出有效字符范围。 该问题保证了移位的字符永远不会超出`'z'`，因此直接字符算术总是安全的。 

最后一个微妙的边缘情况是确保替换不会干扰未来的计算。 由于每个数字仅取决于其前面的字符，甚至索引也不会被修改，因此在整个算法中从左到右的处理保持正确。
