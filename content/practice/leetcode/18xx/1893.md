[LeetCode 问题 1893](https://leetcode.com/problems/check-if-all-the-integers-in-a-range-are-covered/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们确定是否每个整数都在给定的包含范围内`[left, right]`至少被其中指定的间隔之一覆盖`ranges`大批。 的每个元素`ranges`本身就是一个数组`[starti, endi]`表示一个包含区间，表示整数`starti`和`endi`是区间的一部分。 输入最多包含 50 个间隔以及间隔端点和目标范围范围从 1 到 50 的数字。 这保证了非常小的输入大小，这使我们能够考虑可能无法扩展到更大范围的解决方案。 

输出是一个布尔值：`true`如果之间的每个整数`left`和`right`包含在至少一个区间中，并且`false`如果所有间隔中缺少任何整数。 要考虑的边缘情况包括：`left`和`right`是相同的数字、重叠的区间以及部分覆盖外部范围的区间`[left, right]`。 

重要的边缘情况包括`ranges`正好覆盖`[left, right]`、在一侧或两侧超出的范围，以及内部不相交或跳过数字的范围`[left, right]`。 

## 方法

 蛮力方法涉及迭代每个整数`left`到`right`并检查它是否出现在任何间隔中。 这保证是正确的，但需要针对最多 50 个范围检查最多 50 个数字，最坏情况的复杂度为 O(50*50)，这对于约束来说是可以接受的，但不是最优雅的解决方案。 

最佳方法利用布尔数组来标记涵盖 1 到 50 之间的整数。 对于每个间隔`[starti, endi]`，我们将该区间内的所有整数标记为已覆盖。 处理完所有区间后，我们迭代`[left, right]`并检查是否所有这些数字都被标记。 这种方法简单、高效，并且利用了较小的输入域。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(1) | O(1) | 检查每个数字`[left, right]`针对所有间隔 |
 | 最佳| O(n + m) | O(50) | 使用布尔数组标记整数 1 到 50 的覆盖范围 |

 这里，`n`是间隔数`ranges`， 和`m`是目标范围的大小`right - left + 1`。 

## 算法演练

 1.初始化布尔数组`covered`大小为 51（包括 1-50），所有值设置为`False`。 每个索引代表该整数是否被覆盖。 
2. 迭代每个区间`[starti, endi]`在`ranges`。 对于每个区间，迭代`starti`到`endi`包括在内，标记每个数字`covered`数组为`True`。 
3. 处理完所有区间后，迭代来自的整数`left`到`right`。 对于每个整数，检查它是否被标记`True`在`covered`大批。 
4. 如果所有整数都在`[left, right]`已覆盖，返回`True`。 否则，返回`False`。 

这是有效的，因为布尔数组可确保每个整数只检查一次以进行覆盖。 不变量是处理完所有区间后，`covered[i]`是`True`当且仅当整数`i`包含在至少一个区间内。 

## Python 解决方案```python
from typing import List

class Solution:
    def isCovered(self, ranges: List[List[int]], left: int, right: int) -> bool:
        covered = [False] * 51  # 1-based indexing for numbers 1 to 50
        for start, end in ranges:
            for i in range(start, end + 1):
                covered[i] = True
        for num in range(left, right + 1):
            if not covered[num]:
                return False
        return True
```Python 实现初始化一个布尔数组来标记覆盖的数字。 它迭代每个范围并将该范围内的所有数字标记为`True`。 最后，它检查每个数字`[left, right]`并返回`False`如果发现任何号码，请立即。 如果全部被覆盖，则返回`True`。 

## 解决方案```go
func isCovered(ranges [][]int, left int, right int) bool {
    covered := [51]bool{}  // 1-based indexing for numbers 1 to 50
    for _, r := range ranges {
        for i := r[0]; i <= r[1]; i++ {
            covered[i] = true
        }
    }
    for i := left; i <= right; i++ {
        if !covered[i] {
            return false
        }
    }
    return true
}
```在 Go 中，我们使用 51 个布尔值的固定大小数组。 我们迭代每个区间并将数字标记为已覆盖。 检查`[left, right]`对于未覆盖的数字，其工作方式与 Python 相同。 Go 可以高效地处理数组和切片，并且由于固定的输入约束而无需动态分配。

 ## 边缘情况

 一个重要的边缘情况是当`left`等于`right`。 这代表一个数字。 该算法可以正确处理它，因为它仍然在最终循环中检查该数字。 

第二种边缘情况是间隔重叠时，例如`[1,10]`和`[5,15]`。 布尔标记确保重叠覆盖不会导致任何重复计算或遗漏数字。 每个号码至少被标记为已覆盖一次。 

第三种边缘情况是范围超出范围时`[left, right]`， 例如`[1,2]`和`left = 3`。 该算法正确地忽略了这些，因为最终检查仅评估`[left, right]`，因此此范围之外的数字不会影响结果。
