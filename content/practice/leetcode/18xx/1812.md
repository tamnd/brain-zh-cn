 # LeetCode 1812 - 确定棋盘正方形的颜色

 ## 问题理解

 该问题要求我们根据给定的棋盘方格的坐标确定其是白色还是黑色。 输入是长度为 2 的字符串，其中第一个字符是来自的小写字母`'a'`到`'h'`，代表列，第二个字符是来自的数字`'1'`到`'8'`，代表行。 

标准棋盘会在相邻方块之间交替颜色。 如果一个方块是黑色的，那么每个水平或垂直相邻的方块都是白色的。 根据问题陈述，正方形`"a1"`是黑色，颜色从那里开始交替。 

任务是返回：

 -`true`如果给定的方块是白色的
 -`false`如果给定的方块是黑色的

 例如：

 -`"a1"`是黑色的
 -`"h3"`是白色的
 -`"c7"`是黑色的

 限制非常小。 输入始终恰好包含两个字符，并且保证坐标有效。 这意味着我们不需要担心格式错误的输入、无效字母或无效数字。 

重要的观察结果是棋盘颜色遵循重复的奇偶校验模式。 方块根据其行位置和列位置的总和交替颜色。 

一些可能导致混乱的边缘情况包括：

 - 起始广场`"a1"`是黑色而不是白色
 - 正确地将字母转换为数字位置
 - 确保奇偶校验逻辑在所有行和列中一致应用

 因为保证输入有效，所以我们不需要额外的验证逻辑。 

## 方法

 ### 蛮力方法

 暴力解决方案将显式地对整个棋盘进行建模。 我们可以创建一个 8×8 网格，并通过交替黑白来手动为每个方块分配颜色。 

例如，我们可以：

 1.创建二维数组
 2. 用交替的布尔值填充它
 3. 将坐标转换为行索引和列索引
 4.返回存储的值

 这种方法之所以有效，是因为棋盘具有固定且已知的结构。 一旦电路板构建正确，每次坐标查找都会给出正确的答案。 

然而，对于这样一个小问题，这种方法不必要地复杂。 当可以通过数学观察直接计算颜色时，构建完整的板需要额外的内存并增加实现的复杂性。 

### 最佳方法

 关键的见解是棋盘颜色完全取决于奇偶性。 

如果我们转换：

 -`'a'`到`1`-`'b'`到`2`- 等等

 那么：

 - 总和为偶数的平方`(column + row)`是黑色的
 - 总和为奇数的方格是白色的

 例如：

 | 坐标| 列值| 行值 | 总和| 颜色 |
 | --- | --- | --- | --- | --- |
 | a1 | 1 | 1 | 2 | 黑色|
 | a2 | 1 | 2 | 3 | 白色|
 | b1 | 2 | 1 | 3 | 白色|
 | b2 | 2 | 2 | 4 | 黑色|

 这使我们能够在常数时间内直接计算答案。

 ## 算法演练

 1. 从输入字符串中提取列字母和行数字。 
2. 将列字母转换为数字位置。 由于字符是使用 ASCII 值存储的，因此我们可以计算：

 -`'a'`→ 1
 -`'b'`→ 2
 - ...
 -`'h'`→ 8

 这是通过减去来完成的`'a'`从字符中加 1。 
3. 将行字符转换为整数。 
4. 将列值和行值相加。 
5. 判断总和是奇数还是偶数。 

- 奇数和 → 白色方块
 - 偶数和 → 黑色方块
 6. 返回`true`如果总和为奇数，否则返回`false`。 

### 为什么它有效

 棋盘的颜色会随着水平或垂直方向的每次移动而交替变化。 开始于`"a1"`作为黑色，每个相邻的方块都会改变颜色。 这将创建一个奇偶校验模式，其中具有相同奇偶校验的所有方块共享相同的颜色。 

因为`"a1"`有坐标`(1,1)`和总和`2`，所有偶数都是黑色的。 因此，所有奇数和必须是白色的。 该算法直接检查这个不变量。 

## Python 解决方案```python
class Solution:
    def squareIsWhite(self, coordinates: str) -> bool:
        column = ord(coordinates[0]) - ord('a') + 1
        row = int(coordinates[1])

        return (column + row) % 2 == 1
```该实现首先使用以下方法将列字母转换为数字索引`ord()`功能。 表达式：```python
ord(coordinates[0]) - ord('a') + 1
```地图`'a'`到`1`,`'b'`到`2`， 等等。 

接下来，使用以下命令将行字符转换为整数`int()`。 

然后，该算法将两个值相加并检查总和是否为奇数。 如果总和为奇数，则正方形为白色，因此该方法返回`True`。 否则，它返回`False`。 

实现很紧凑，因为数学关系完全决定了答案。 

## 解决方案```go
func squareIsWhite(coordinates string) bool {
    column := int(coordinates[0]-'a') + 1
    row := int(coordinates[1] - '0')

    return (column+row)%2 == 1
}
```Go 实现遵循与 Python 版本相同的逻辑。 字符被视为字节值，因此减去`'a'`将列转换为从零开始的索引。 添加`1`将其转换为所需的范围`1`到`8`。 

通过减法将行数字转换为整数`'0'`。 

不用担心整数溢出，因为所有值都非常小。 由于输入长度保证正好是两个字符，因此不需要额外的边界检查。

 ## 边缘情况

 一个重要的边缘情况是起始方块`"a1"`。 许多人凭直觉认为棋盘左下角的方块是白色的，但在这个问题中它明显是黑色的。 如果奇偶校验规则意外颠倒，则每个结果都会变得不正确。 该实现可以正确处理此问题，因为它将偶数和视为黑色。 

另一个重要的情况涉及列之间的转换。 例如，`"a2"`和`"b1"`尽管行和列不同，但它们都是白色的。 仅检查一个坐标的简单实现可能会在这里失败。 该解决方案正确地组合了两个坐标并检查它们的奇偶性。 

第三个重要的边缘情况是处理最大坐标`"h8"`。 这个方格位于棋盘的对角，并且有总和`16`，这是偶数。 该实现正确地将其识别为黑色。 这证实奇偶校验逻辑在整个板上一致地工作。
