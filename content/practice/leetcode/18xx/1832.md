[LeetCode 1832 题](https://leetcode.com/problems/check-if-the-sentence-is-pangram/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定给定的字符串是否是全语法。 pangram 是一个包含每个小写英文字母的句子，来自`'a'`通过`'z'`，至少一次。 

输入是一个名为`sentence`。 该问题保证字符串只包含小写英文字母，这简化了实现，因为我们不需要担心大写转换、空格、标点符号或特殊字符。 

预期输出是一个布尔值：

 - 返回`true`如果每个英文字母至少出现一次。 
- 返回`false`即使有一个字母缺失。 

约束告诉我们字符串长度介于`1`和`1000`。 这是一个非常小的输入大小，因此即使效率相对较低的解决方案仍然可以快速运行。 然而，目标仍然是设计一个干净高效的算法。 

一个重要的观察是英语字母表恰好包含 26 个字母。 因此，如果字符串长度小于26，则该句子不可能是全语法。 这为我们提供了有用的早期优化。 

需要考虑一些重要的边缘情况：

 - 短于 26 个字符的字符串永远不可能是全语法。 
- 字符串可能包含许多重复的字符而缺少其他字符。 
- 字符串在到达末尾之前可能已经包含所有字母，从而允许在某些实现中提前返回。 
- 该问题仅保证小写英文字母，因此我们不需要字符规范化或过滤。 

## 方法

 ### 蛮力方法

 暴力解决方案检查来自的每一个字母`'a'`到`'z'`单独并搜索句子以查看该字符是否存在。 

例如，我们可以迭代所有 26 个字母并使用成员资格测试，例如：```
if char not in sentence:
```如果缺少任何字母，我们将返回`false`。 如果找到所有字母，我们返回`true`。 

这种方法是正确的，因为它直接验证了全语法的定义。 每个必需的字符必须至少出现一次。 

但是，此方法会重复扫描字符串。 对于这 26 个字母中的每一个，我们可能需要遍历整个句子。 虽然约束足够小，仍然可以很好地执行，但它的效率低于必要的水平。 

### 最佳方法

 关键的见解是我们只关心每个字母是否至少出现过一次。 我们不关心频率。 

哈希集非常适合这种情况，因为集自动仅存储唯一值。 

我们迭代该句子一次并将每个字符插入到一个集合中。 最后：

 - 如果该集合恰好包含 26 个唯一字母，则该句子是全字母组合。 
- 否则，至少会丢失一个字母。 

这可以有效地工作，因为插入哈希集大约是`O(1)`平均而言。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(26 × n)，简化为 O(n) | O(1) | O(1) | 重复扫描句子中的每个字母 |
 | 最佳| O(n) | O(1) | O(1) | 使用哈希集来跟踪唯一字母 |

 尽管由于 26 是常数，两者都简化为线性时间，但哈希集方法更干净并且避免了重复扫描。 

## 算法演练

 1.首先检查句子长度是否小于26，如果小于，则立即返回`false`因为一个全字母组合需要全部 26 个字母。 
2. 创建一个空的哈希集。 该集合将存储句子中遇到的每个不同字符。 
3. 遍历句子中的每个字符。 
4. 将当前字符插入字符集中。 由于集合仅保留唯一值，因此重复字母不会增加集合大小。 
5. 每次插入后，可选检查设置的大小是否已达到26。如果已达到，则返回`true`立即，因为所有字母都已被看到。 
6. 如果循环结束并且设置的大小仍然小于26，则返回`false`。 

选择哈希集是因为它提供了高效的成员资格和插入操作，同时自然地消除了重复项。 

### 为什么它有效

 该算法保持了一个不变式，即该集合恰好包含句子中迄今为止看到的唯一字母。 

如果集合大小变为26，则每个小写英文字母必须至少出现一次，这满足全语法的定义。 

如果处理整个句子后存在的唯一字母少于 26 个，则至少缺少一个字母，因此该句子不是全字母组合。 

## Python 解决方案```python
class Solution:
    def checkIfPangram(self, sentence: str) -> bool:
        if len(sentence) < 26:
            return False

        unique_letters = set()

        for char in sentence:
            unique_letters.add(char)

            if len(unique_letters) == 26:
                return True

        return False
```实现从快速长度检查开始。 由于全语法必须包含全部 26 个字母，因此任何较短的字符串都可以立即返回`False`。 

接下来，该解决方案创建一个名为`unique_letters`。 当算法迭代句子时，每个字符都会插入到集合中。 重复的字母并不重要，因为集合自动仅存储唯一元素。 

每次插入后，实现都会检查集合大小是否已达到 26。如果是，则算法返回`True`早，因为所有字母都已经出现了。 

如果循环结束时未达到 26 个唯一字母，则函数返回`False`。 

## 解决方案```go
func checkIfPangram(sentence string) bool {
    if len(sentence) < 26 {
        return false
    }

    uniqueLetters := make(map[rune]bool)

    for _, char := range sentence {
        uniqueLetters[char] = true

        if len(uniqueLetters) == 26 {
            return true
        }
    }

    return false
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于 Go 没有内置的集合类型，因此使用映射来代替。 映射键代表唯一字符，布尔值只是占位符。 

该循环使用以下方式迭代字符串`range`，产生符文。 虽然问题只包含小写英文字母，但使用 runes 仍然是 Go 惯用的字符串迭代方法。 

不需要对整数溢出或 nil 值进行特殊处理，因为输入大小非常小并且数据结构是显式初始化的。

 ## 边缘情况

 一个重要的边缘情况是字符串短于 26 个字符。 由于有 26 个不同的小写英文字母，因此从数学上来说，这样的字符串不可能是全语法。 如果没有这种观察，解决方案可能会浪费时间处理永远不会成功的输入。 该实现会立即处理此问题并提前返回。 

另一个重要的情况是重复字符。 例如，仅包含重复的字符串`'a'`如果解决方案只是计算字符而不是跟踪唯一性，则字符可能会错误地显示为有效。 使用集合可以保证重复的字母仅存储一次，从而防止出现此错误。 

第三种边缘情况涉及很早就包含所有 26 个字母的字符串。 某些实现可能会在已经确认该句子是全语法之后继续进行不必要的扫描。 所提供的解决方案包括一旦集合大小达到 26 就提前返回，从而在保持正确性的同时提高效率。
