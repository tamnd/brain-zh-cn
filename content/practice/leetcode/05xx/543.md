[LeetCode 543 题](https://leetcode.com/problems/diameter-of-binary-tree/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们计算二叉树的**直径**。 直径定义为**任意两个节点之间最长路径的长度**，以边数来测量。 重要的是，这条路径不需要经过树的根部。 换句话说，路径可以完全位于左子树、右子树内或跨越根。 

输入是`root`二叉树的结构，最多可包含 10,000 个节点，节点值的范围为 -100 到 100。输出是表示树直径的单个整数。 这些约束表明我们必须仔细考虑性能，因为重复遍历子树的简单解决方案对于大型树来说可能太慢。 

重要的边缘情况包括直径为 0 的单个节点的树，以及最长路径不经过根的不平衡树。 

## 方法

 **暴力方法**将涉及检查每个节点的最长路径。 对于每个节点，我们可以计算其左子树和右子树的高度，然后将它们相加以获得通过该节点的最长路径。 对所有节点重复此操作会导致大量冗余计算，因为子树高度被重新计算多次。 对于倾斜树来说，在最坏的情况下，这会导致时间复杂度为 O(n^2)。 

**最佳方法**利用单个**后序深度优先搜索（DFS）**遍历来同时计算子树的高度和最大直径。 关键的见解是，穿过节点的最长路径是其左子节点和右子节点的高度之和。 通过在递归过程中更新全局最大直径，我们只需要一次遍历就可以得到正确的结果，将时间复杂度降低到 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 多次计算每个节点的高度； 对于大树来说速度较慢|
 | 最佳 | O(n) | O(h) | 单次DFS遍历，更新全局最大值； h 是树高 |

 ## 算法演练

 1.定义全局变量`max_diameter`初始化为0。该变量将存储遍历过程中找到的最大直径。 
2. 实现一个递归 DFS 函数，计算以给定节点为根的子树的高度。 高度定义为从节点到叶子的最长路径中的边数。 
3. 对于DFS中的每个节点：

 1. 递归计算左子树高度。 
2. 递归计算右子树高度。 
3. 更新`max_diameter`作为其当前值与左右高度之和的最大值。 这表示通过当前节点的最长路径。 
4. 返回当前节点的高度为1加上左右高度的最大值。 
4. 从根开始调用DFS。 
5. 返回`max_diameter`遍历完成后。 

**为什么它起作用**：在每个节点，我们考虑通过它的最长路径。 因为 DFS 遍历确保所有子树在其父树之前得到处理，所以我们始终有正确的高度可用于计算局部直径。 这保证了找到整棵树的最大直径。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.max_diameter = 0
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            left_height = dfs(node.left)
            right_height = dfs(node.right)
            self.max_diameter = max(self.max_diameter, left_height + right_height)
            return 1 + max(left_height, right_height)
        
        dfs(root)
        return self.max_diameter
```**实施演练**：`dfs`函数返回节点的高度，同时更新`self.max_diameter`在该节点找到的最长路径。 对于空节点，基本情况返回 0。 对于每个节点，我们计算左右高度，更新直径，然后向上传播高度。 这确保单次遍历就足够了。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func diameterOfBinaryTree(root *TreeNode) int {
    maxDiameter := 0

    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil {
            return 0
        }
        leftHeight := dfs(node.Left)
        rightHeight := dfs(node.Right)
        if leftHeight+rightHeight > maxDiameter {
            maxDiameter = leftHeight + rightHeight
        }
        return 1 + max(leftHeight, rightHeight)
    }

    dfs(root)
    return maxDiameter
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```**Go 特定注释**：Go 需要处理`nil`显式指针，并且整数在这种情况下不会溢出。 一个帮手`max`使用函数代替Python的内置函数`max`。 

## 工作示例

 **示例 1：根 = [1,2,3,4,5]**

 | 节点| 左高度 | 正确的高度| 最大直径|
 | --- | --- | --- | --- |
 | 4 | 0 | 0 | 0 |
 | 5 | 0 | 0 | 0 |
 | 2 | 1 | 1 | 2 |
 | 3 | 0 | 0 | 2 |
 | 1 | 2 | 1 | 3 |

 最终输出：3

 **示例 2：根 = [1,2]**

 | 节点| 左高度| 正确的高度| 最大直径|
 | --- | --- | --- | --- |
 | 2 | 0 | 0 | 0 |
 | 1 | 1 | 0 | 1 |

 最终输出：1

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 在 DFS 中每个节点只被访问一次 |

 ## 边缘情况

 第一个边缘情况是**单节点树**，其中直径必须为 0。算法通过在左右高度均为 0 时返回 0 来正确处理此问题。 

第二种边缘情况是**偏斜树**，其中所有节点仅位于一侧（如链表）。 在这种情况下，直径等于节点数减 1。该算法仍然有效，因为 DFS 沿链正确计算高度。 

第三种边缘情况是**树，其中最长路径不经过根**。 例如，具有不共享根节点的深左子树和深右子树的树。 全球`max_diameter`确保考虑所有可能的节点对，因此无论是否通过根，都可以正确捕获最大路径。
