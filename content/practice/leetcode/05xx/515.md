[LeetCode 问题 515](https://leetcode.com/problems/find-largest-value-in-each-tree-row/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到二叉树每一行中的最大值，其中一行定义为同一深度的所有节点。 输入是二叉树的根，二叉树最多可以包含 10,000 个节点，每个节点的值是一个带符号的 32 位整数。 输出应该是一个整数列表，其中第一个元素对应于根级别（深度 0）中的最大值，第二个元素对应于第一级别（深度 1）中的最大值，依此类推。 

该问题保证树是结构良好的并且可能是空的。 重要的边缘情况包括一棵空树、一棵只有一个节点的树以及一棵所有值都为负或相同的树。 如果不明确处理，这些场景很容易破坏简单的实现。 

主要挑战是逐级遍历树，跟踪每个级别的最大值，同时尊重大型树的时间和空间效率。 

## 方法

 暴力方法是多次遍历树，每个级别一次，并计算该级别的最大值。 这保证了正确性，因为它显式地检查每个深度的所有节点。 然而，这是低效的，因为每次遍历都会重复之前级别中已经完成的工作，导致不平衡树在最坏情况下需要 O(n^2) 时间。 

最佳方法使用广度优先搜索 (BFS) 或深度优先搜索 (DFS) 来访问每个节点一次，同时保持当前深度的最大值。 BFS 在这里很自然，因为它逐级处理节点。 我们使用队列来迭代当前级别中的节点，跟踪最大值，并将其附加到结果中。 DFS 也可以通过在递归调用中传递当前深度并更新每个级别的最大值来实现。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 每层多次遍历，对于大树来说效率非常低 |
 | 最优（BFS/DFS）| O(n) | O(w) | 单次遍历所有节点，空间取决于树的最大宽度 |

 ## 算法演练

 1.检查root是否为`None`。 如果是这样，则返回一个空列表，因为树没有节点。 
2.初始化一个空列表`result`存储每行的最大值。 
3. 初始化队列并添加根节点。 该队列将逐级跟踪要处理的节点。 
4. 当队列不为空时，通过测量队列长度来确定当前级别的节点数。 这确保我们只处理当前行中的节点。 
5. 初始化变量`level_max`到负无穷大。 这将跟踪当前行中的最大值。 
6. 迭代当前级别中的所有节点。 对于每个节点，更新`level_max`如果节点的值更大。 
7. 如果该节点有左子节点，则将其入队。 如果该节点有右子节点，则将其入队。 这可确保为下一个级别的处理做好准备。 
8.处理完当前层的所有节点后，追加`level_max`到`result`。 
9. 重复步骤 4-8，直到处理完所有级别。 
10. 返回`result`。 

工作原理：每个节点都被访问一次，并且在移动到下一行之前计算每行的最大值。 BFS 保证节点被逐级处理，保留最大值的正确顺序`result`。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import List, Optional
from collections import deque

class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        result = []
        queue = deque([root])
        
        while queue:
            level_size = len(queue)
            level_max = float('-inf')
            
            for _ in range(level_size):
                node = queue.popleft()
                level_max = max(level_max, node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            result.append(level_max)
        
        return result
```这个 Python 实现准确地反映了算法步骤。 我们检查空树，初始化结果列表和队列，并逐层处理树。 这`level_max`变量跟踪每行的最大值，并且 BFS 确保正确的行排序。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func largestValues(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }
    
    result := []int{}
    queue := []*TreeNode{root}
    
    for len(queue) > 0 {
        levelSize := len(queue)
        levelMax := -1 << 31 // equivalent to negative infinity for 32-bit int
        
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            if node.Val > levelMax {
                levelMax = node.Val
            }
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        result = append(result, levelMax)
    }
    
    return result
}
```在 Go 中，我们处理`nil`显式节点并使用切片作为队列。 这`levelMax`变量被初始化为最小 32 位整数值，镜像 Python`float('-inf')`。 切片操作可以有效地模拟 BFS 的队列行为。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点仅被访问一次，其中 n 是节点总数 |

 ## 边缘情况

 一个重要的边缘情况是一棵空树。 幼稚的实现可能会尝试访问`root.val`不检查`None`，这会导致运行时错误。 我们在开始时通过返回一个空列表来显式处理这种情况。 

第二个边缘情况是一棵树的值全部为负。 使用天真的`level_max = 0`初始化会错误地生成 0 作为最大值。 我们通过初始化来避免这种情况`level_max`到负无穷大（`float('-inf')`在Python中，`-1 << 31`在 Go 中），确保正确比较所有负值。 

第三种边缘情况是不平衡树，其中某些级别的节点比其他级别少得多。
