 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、并查找、图论

 ## 解决方案

 ## 问题理解

 问题是要求我们确定城市网络中**省**的数量。 每个城市都可以直接与其他城市连接，也可以通过连接链间接连接。 一个省被定义为一组直接或间接连接的城市，并且与该组之外的城市没有连接。 

输入是一个`n x n`邻接矩阵`isConnected`， 在哪里`isConnected[i][j]`是`1`如果城市`i`和城市`j`直接连接，并且`0`否则。 每个城市总是与其自身相连，因此矩阵的对角线总是`1`。 输出是一个表示省份总数的整数。 

约束表明`n`可以达到`200`，所以有一个解决方案`O(n^3)`复杂性可能在可接受的范围内，但是`O(n^2)`或更好是优选的。 该矩阵是对称的，并且城市始终相互连接，这简化了遍历并确保我们不需要检查无效索引。 

重要的边缘情况包括完全连接的城市（1个省）、完全断开的城市（每个城市都是自己的省）以及单个城市（1个省）的最小情况。 

## 方法

 **暴力方法**将考虑每个城市并尝试递归或迭代地遍历到其他城市的所有路径，记录已访问过哪些城市。 对于每个未访问过的城市，我们将开始遍历以标记其所在省份的所有城市。 这是有效的，因为每个省对应于图中的一个连接组件。 然而，幼稚的实现可能会重复检查连接，从而导致`O(n^3)`如果递归多次探索所有路径，则时间复杂度。 

**最佳方法**使用深度优先搜索 (DFS)、广度优先搜索 (BFS) 或并查找。 这些方法有效地识别连接的组件：

 - **DFS/BFS：** 对于每个未访问过的城市，执行 DFS 或 BFS 将所有可到达的城市标记为访问过。 每次遍历都准确地识别一个省份。 时间复杂度为`O(n^2)`因为每个矩阵单元最多只能被访问一次。 
- **并查找：** 将每个城市视为不相交集森林中的一个节点。 联盟连接的城市。 最后不相交的集合的数量就是省份的数量。 联合查找与路径压缩在实践中实现了接近线性的时间，`O(n^2 * α(n))`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 从每个城市遍历并重复访问会导致更高的时间复杂度 |
 | DFS / BFS | O(n^2) | O(n^2) | O(n) | 每个城市和边缘访问一次 |
 | 联查| O(n^2 * α(n)) | O(n^2 * α(n)) | O(n) | 使用不相交集运算，对于重复并集有效 |

 ## 算法演练

 我们将详细描述DFS方法：

 1. 初始化一个`visited`长度列表`n`跟踪哪些城市已被探索。 
2. 初始化一个`province_count`至 0。 
3. 迭代每个城市`i`从`0`到`n-1`。 
4.如果城市`i`尚未访问过：

 1. 增量`province_count`减 1，因为在这里启动 DFS 意味着一个新的省份。 
2. 从城市开始执行DFS`i`：

 - 将城市标记为已访问。 
- 每个城市`j`， 如果`isConnected[i][j] == 1`和`j`未访问过，递归访问城市`j`。 
5.迭代完所有城市后，返回`province_count`。 

**为什么有效：** 每次 DFS 遍历都会充分探索图的连接组件。 由于每个省对应一个连接的组件，因此在未访问过的城市上开始计算 DFS 时，所有省份都只计数一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        visited = [False] * n

        def dfs(city: int):
            visited[city] = True
            for neighbor in range(n):
                if isConnected[city][neighbor] == 1 and not visited[neighbor]:
                    dfs(neighbor)

        province_count = 0
        for i in range(n):
            if not visited[i]:
                province_count += 1
                dfs(i)

        return province_count
```该实现首先创建一个`visited`数组来跟踪探索过的城市。 这`dfs`函数将当前城市标记为已访问，并递归访问所有直接相连、未访问的城市。 主循环递增`province_count`每当它发现一个未访问过的城市时，确保每个连接的组件都被计数一次。 

## 解决方案```go
func findCircleNum(isConnected [][]int) int {
    n := len(isConnected)
    visited := make([]bool, n)

    var dfs func(int)
    dfs = func(city int) {
        visited[city] = true
        for neighbor := 0; neighbor < n; neighbor++ {
            if isConnected[city][neighbor] == 1 && !visited[neighbor] {
                dfs(neighbor)
            }
        }
    }

    provinceCount := 0
    for i := 0; i < n; i++ {
        if !visited[i] {
            provinceCount++
            dfs(i)
        }
    }

    return provinceCount
}
```Go 版本镜像了 Python 实现，使用切片`visited`和一个递归的`dfs`函数定义为闭包以允许递归。

 ## 边缘情况

 **单一城市：** 何时`n=1`，该算法正确返回 1，因为 DFS 被调用一次并立即终止。 

**完全断开图：** 当除自连接外所有城市都断开时，每个城市形成自己的省份。 DFS确保每个城市都是单独计数的，并且递归不会超出单个城市。 

**全连接图：** 当所有城市都相互连接时，DFS 从第一个城市开始访问每个城市。 随后的迭代会跳过访问过的城市，确保省份计数恰好为 1。这验证了该实现不会过度计数。
