[LeetCode 583 题](https://leetcode.com/problems/delete-operation-for-two-strings/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们确定使两个字符串相同所需的**删除步骤**的最小数量。 我们有两个输入字符串，`word1`和`word2`，并且在每一步中，我们都可以从任一字符串中删除一个字符。 目标是使用尽可能少的删除来转换两个字符串，以便它们的最终形式相同。 

例如，给定`word1 = "sea"`和`word2 = "eat"`，一个最佳序列是删除`'s'`从`word1`要得到`"ea"`并删除`'t'`从`word2`也得到`"ea"`。 这总共需要删除2次。 

约束告诉我们两个字符串的长度都在 1 到 500 之间，并且只包含小写英文字母。 这意味着时间上的二次解是可以接受的，但指数解会太慢。 

重要的边缘情况包括没有公共字符的字符串（必须从两个字符串中删除所有字母）、已经相同的字符串（不需要删除）以及长度为 1 的字符串（琐碎但必须处理）。 

## 方法

 **暴力方法**会考虑两个字符串中所有可能的删除序列，并选择总删除最少的一个。 从概念上讲，这可以建模为递归尝试每个选项：删除第一个字符`word1`, 删除第一个字符`word2`，或者如果两者匹配则保留两者。 虽然这种方法是正确的，但其复杂性是指数级的，$O(2^{m+n})$，并且对于长度不超过 500 的字符串不可行。 

**最佳方法**依赖于一个关键的观察：最小删除数量由两个字符串的**最长公共子序列（LCS）**的长度决定。 一旦我们知道了 LCS 长度，就说`lcs_len`，所需的最少删除是`(len(word1) - lcs_len) + (len(word2) - lcs_len)`。 直觉是两个字符串中都保留了 LCS 中的字符，因此只有 LCS 之外的字符需要删除。 我们可以使用动态规划有效地计算 LCS。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(m+n) 递归堆栈 | 递归探索所有删除序列 |
 | 最优（使用 LCS 的 DP）| O(m*n) | O(m*n) | 使用 2D DP 阵列计算 LCS，然后计算删除 |

 ## 算法演练

 1. 初始化一个2D数组`dp`尺寸的`(m+1) x (n+1)`， 在哪里`m`和`n`的长度是`word1`和`word2`。`dp[i][j]`表示第一个LCS的长度`i`的字符`word1`和第一个`j`的字符`word2`。 
2. 将第一行第一列的所有值设置为 0，因为任何包含空字符串的字符串的 LCS 都是 0。 
3. 遍历 的字符`word1`和`word2`。 对于每个`i`和`j`：

- 如果`word1[i-1] == word2[j-1]`， 然后`dp[i][j] = dp[i-1][j-1] + 1`因为匹配字符扩展了 LCS。 
- 否则，`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`因为我们必须从任一字符串中跳过一个字符才能最大化 LCS 长度。 
4. 填写DP表后，`dp[m][n]`给出 LCS 的长度.
 5. 计算最小删除量为`(m - dp[m][n]) + (n - dp[m][n])`。 

**为什么有效：** 该算法通过以自下而上的方式构建较小的子问题来正确计算 LCS 长度。 由于必须删除不在 LCS 中的字符才能使字符串相等，因此从每个字符串的长度中减去 LCS 长度即可得出所需的确切删除次数。 

## Python 解决方案```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        
        lcs_len = dp[m][n]
        return (m - lcs_len) + (n - lcs_len)
```Python代码创建一个DP表`dp`存储所有子问题的 LCS 长度。 根据当前字符是否匹配来填充每个条目。 最终答案是通过从每个字符串长度中减去 LCS 长度并对结果求和来计算的。 

## 解决方案```go
func minDistance(word1 string, word2 string) int {
    m, n := len(word1), len(word2)
    dp := make([][]int, m+1)
    for i := 0; i <= m; i++ {
        dp[i] = make([]int, n+1)
    }

    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
            } else {
                if dp[i-1][j] > dp[i][j-1] {
                    dp[i][j] = dp[i-1][j]
                } else {
                    dp[i][j] = dp[i][j-1]
                }
            }
        }
    }

    lcsLen := dp[m][n]
    return (m - lcsLen) + (n - lcsLen)
}
```Go 解决方案反映了 Python 实现。 差异包括 2D 切片的显式分配以及对`max`手动操作，因为 Go 缺乏内置的`max`对于整数。 

## 工作示例

 **示例1：**`word1 = "sea"`,`word2 = "eat"`| 我| j | dp[i][j] 值 | 说明|
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 's'！= 'e' |
 | 1 | 2 | 0 | 's' != 'a' | 's' != 'a' |
 | 1 | 3 | 0 | 's' != 't' | 's' != 't' |
 | 2 | 1 | 0 | 'e' == 'e'，扩展 LCS |
 | 2 | 2 | 1 | 'e'！= 'a' |
 | 3 | 2 | 1 | 'a' == 'a'，LCS 变为 2 |

 最终的`dp[3][3] = 2`，所以删除=`(3-2) + (3-2) = 2`。 

**示例2：**`word1 = "leetcode"`,`word2 = "etco"`DP计算后，LCS =`"etco"`长度 4. 删除 =`(8-4) + (4-4) = 4`。

 | 测量 | 复杂性 | 说明|
