[LeetCode 第 549 题](https://leetcode.com/problems/binary-tree-longest-consecutive-sequence-ii/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到二叉树中最长连续序列路径的长度。 与该问题的更简单版本不同，该问题的序列必须严格从父级向下移动到子级，该版本也允许路径沿子-父-子方向移动。 

连续路径意味着相邻节点完全不同`1`。 该序列可以是递增的，也可以是递减的。 

例如：

-`1 -> 2 -> 3 -> 4`有效，因为每个值增加`1`-`4 -> 3 -> 2 -> 1`也是有效的，因为每个值都会减少`1`-`1 -> 2 -> 4 -> 3`无效，因为`2`和`4`不同之处在于`2`重要的细节是路径不需要仅沿着向下的边缘。 有效路径可以经过父节点并继续进入另一个子树。 例如：```
    2
   / \
  1   3
```这里最长的有效路径是：```
1 -> 2 -> 3
```这条路径在根部改变方向。 

输入是二叉树的根节点。 每个节点包含：

 - 整数值
 - 左子指针
 - 右子指针

 输出是一个整数，表示任何有效连续路径的最大长度。 

约束条件很重要：

 - 最多`3 * 10^4`节点
 - 节点值范围为`-3 * 10^4`到`3 * 10^4`由于树可以包含数万个节点，因此任何比线性时间更差的解决方案都可能变得太慢。 这强烈表明我们应该只处理每个节点一次。 

一些边缘情况很重要：

 - 一棵只有一个节点的树，答案应该是`1`- 完全增加连锁
 - 完全减少链条
 - 通过父级切换方向的路径
 - 具有重复值的树
 - 不存在连续关系的树
 - 深度接近的倾斜树木`3 * 10^4`幼稚的实现可能会错过通过当前节点组合左子树和右子树的路径。 

## 方法

 ### 蛮力方法

 暴力策略会尝试将每个节点作为起点，并探索从该节点开始的所有可能的连续路径。 

对于每个节点，我们可以递归搜索：

 - 增加序列
 - 递减序列
 - 贯穿祖先和后代的路径

 这很快就会变得复杂，因为有效路径可能在父节点处弯曲。 为了充分探索所有可能性，我们将重复遍历树的重叠部分。 

蛮力方法是正确的，因为它显式枚举所有候选路径并检查连续条件是否成立。 然而，它执行过多的重复工作。 

在最坏的情况下，对于每个节点，我们可能会再次遍历树的很大一部分，从而导致二次复杂度。 

### 最优 DFS 动态规划方法

 关键的见解是每个节点只需要从其子节点了解两件事：

 - 从该节点开始的最长递增连续路径
 - 从该节点开始的最长递减连续路径

 如果子值是：

 -`node.val + 1`，那么孩子可以扩展一个递增序列
 -`node.val - 1`，那么孩子可以扩展一个递减序列

 一旦我们知道两个子节点的最佳递增和递减长度，我们就可以通过当前节点将它们组合起来。 

例如：```
1 <- 2 -> 3
```在节点处`2`：

 - 从左开始递减路径=`2 -> 1`- 从右开始增加路径 =`2 -> 3`这些组合成：```
1 -> 2 -> 3
```总长度：```
decreasing + increasing - 1
```我们减去`1`因为当前节点被计数了两次。 

这自然会导致后序 DFS，其中每个节点使用已计算的子信息来计算其贡献。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(h) | 反复探索重叠路径 |
 | 最佳 | O(n) | O(h) | 动态规划单次DFS遍历|

 这里，`n`是节点数，`h`是树的高度。 

## 算法演练

 1. 从根开始深度优先遍历。 
2. 对于每个节点，在处理当前节点之前，递归计算左右子节点的结果。 这是后序遍历，因为当前节点依赖于子节点信息。 
3. 在每个节点，维护两个值：

 -`increasing`，从该节点开始的最长递增连续路径
 -`decreasing`，从该节点开始的最长递减连续路径

 最初，两个值都是`1`因为节点本身形成了一条长度有效的路径`1`。 
4. 处理左孩子：

 - 如果`left.val == node.val + 1`，那么当前节点可以通过左子节点扩展递增序列。 
- 如果`left.val == node.val - 1`，那么当前节点可以通过左子节点扩展递减序列。 
5.同样处理右孩子。 
6. 更新递增长度和递减长度后，计算通过当前节点的最佳路径：```
increasing + decreasing - 1
```这会将两个方向组合成一条有效的连续路径。 
7. 如果该组合长度大于当前最佳答案，则更新全局最大答案。 
8. 返回`(increasing, decreasing)`到父节点，以便更高的节点可以继续扩展这些序列。 

### 为什么它有效

 对于每个节点，该算法计算从该节点开始的最长的递增和递减路径。 由于每个有效的连续路径必须经过方向可能​​改变的某个最高节点，因此在每个节点处组合增加和减少的长度可以保证所有有效路径都被恰好考虑一次。 DFS 确保在父母依赖子信息之前完全计算子信息。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional, Tuple

class Solution:
    def longestConsecutive(self, root: Optional[TreeNode]) -> int:
        self.answer = 0

        def dfs(node: Optional[TreeNode]) -> Tuple[int, int]:
            if not node:
                return (0, 0)

            increasing = 1
            decreasing = 1

            left_inc, left_dec = dfs(node.left)
            right_inc, right_dec = dfs(node.right)

            if node.left:
                if node.left.val == node.val + 1:
                    increasing = max(increasing, 1 + left_inc)
                elif node.left.val == node.val - 1:
                    decreasing = max(decreasing, 1 + left_dec)

            if node.right:
                if node.right.val == node.val + 1:
                    increasing = max(increasing, 1 + right_inc)
                elif node.right.val == node.val - 1:
                    decreasing = max(decreasing, 1 + right_dec)

            self.answer = max(
                self.answer,
                increasing + decreasing - 1
            )

            return (increasing, decreasing)

        dfs(root)
        return self.answer
```该实现使用递归辅助函数`dfs`为每个节点返回两个整数。 

第一个整数表示从当前节点开始的最长递增路径。 第二个整数表示从当前节点开始的最长递减路径。 

递归首先处理子级，因为父级依赖子级信息来正确扩展序列。 

每个节点开始于：```python
increasing = 1
decreasing = 1
```因为节点本身就形成了有效的长度序列`1`。 

检查儿童时：

 - 如果孩子确实是`+1`，我们扩展递增序列。 
- 如果孩子确实是`-1`，我们扩展递减序列。 

处理完两个子项后，算法将两个方向结合起来：```python
increasing + decreasing - 1
```这表示可以从一个子树穿过当前节点进入另一子树的路径。 

全局变量`self.answer`存储在树中任何位置找到的最大路径长度。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func longestConsecutive(root *TreeNode) int {
    answer := 0

    var dfs func(node *TreeNode) (int, int)

    dfs = func(node *TreeNode) (int, int) {
        if node == nil {
            return 0, 0
        }

        increasing := 1
        decreasing := 1

        leftInc, leftDec := dfs(node.Left)
        rightInc, rightDec := dfs(node.Right)

        if node.Left != nil {
            if node.Left.Val == node.Val+1 {
                if 1+leftInc > increasing {
                    increasing = 1 + leftInc
                }
            } else if node.Left.Val == node.Val-1 {
                if 1+leftDec > decreasing {
                    decreasing = 1 + leftDec
                }
            }
        }

        if node.Right != nil {
            if node.Right.Val == node.Val+1 {
                if 1+rightInc > increasing {
                    increasing = 1 + rightInc
                }
            } else if node.Right.Val == node.Val-1 {
                if 1+rightDec > decreasing {
                    decreasing = 1 + rightDec
                }
            }
        }

        current := increasing + decreasing - 1
        if current > answer {
            answer = current
        }

        return increasing, decreasing
    }

    dfs(root)

    return answer
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于Go不支持直接返回元组值，因此递归函数返回两个整数。 

Go 使用`nil`检查而不是Python的`None`。 

全局答案是通过递归函数捕获的闭包变量来维护的。 

整数溢出不是问题，因为最大路径长度受节点数量限制，最多为`3 * 10^4`。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点只处理一次 |
 | 空间| O(h) | 递归调用堆栈高度|

 该算法执行单次 DFS 遍历。 每个节点都使用来自其子节点的信息计算常量工作，因此总运行时间与节点数量呈线性关系。 

辅助空间来自递归深度。 在平衡树中这是`O(log n)`，而在倾斜树的最坏情况下，它会变成`O(n)`。

 ## 边缘情况

 ### 单节点树

 仅包含一个节点的树是最小的有效输入。 有错误的实现可能会错误地返回`0`because there are no edges. 正确答案是`1`因为单个节点本身就形成了一条有效的连续路径。 该实现通过初始化增加和减少的长度来处理这个问题`1`。 

### 重复值

 具有相等值的节点不连续，因为连续的数字必须完全不同`1`。 例如：```
2
|
2
```不应扩展任何序列。 该实现仅显式检查：```
child.val == node.val + 1
```或者```
child.val == node.val - 1
```所以重复项会被自动忽略。 

### 改变方向的路径

 最重要的边缘情况是最长路径经过父节点并组合两个子树时：```
1 -> 2 -> 3
```简单的自上而下的 DFS 可能只独立地跟踪递增或递减的序列，而错过了这种组合。 该实现通过在每个节点保持递增和递减的长度并将它们与以下组合来解决这个问题：```
increasing + decreasing - 1
```这保证了转弯路径的计算正确。 

### 倾斜的树

 完全倾斜的树的行为类似于链表，并且可能达到深度`3 * 10^4`。 递归解决方案可以接近 Python 中的递归深度限制。 从算法上来说，该解决方案仍然可以正常工作，因为每个节点都被处理一次。 空间复杂度变为`O(n)`在这种最坏的情况下，由于递归堆栈的使用。
