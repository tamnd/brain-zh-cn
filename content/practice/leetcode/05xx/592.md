 ## 问题理解

 该问题需要使用加法和减法运算符计算包含分数的数学表达式的结果。 输入是单个字符串，`expression`，由正分数或负分数组成，格式为`numerator/denominator`。 输出必须是不可约分数，以相同格式表示为字符串。 如果结果是整数，则应表示为`integer/1`。 

关键约束是输入中的每个分数都是不可约的，分子和分母在 1 到 10 之间，并且分数总数很小，在 1 到 10 之间。这些约束意味着解决方案不需要担心极大数量的分数或极大的分子/分母，但正确的算术和简化至关重要。 

可能导致简单实现失败的边缘情况包括负分数、连续加法和减法序列以及减少到零或整数的结果。 例如，处理`-1/2+1/2`必须返回`0/1`， 不是`0`或不正确的分数。 输入保证有效分数，因此解析可以假设格式正确，但最后必须执行简化。 

## 方法

 一种强力方法是解析每个分数，将其转换为浮点数，对它们进行求和，然后尝试将总和转换回分数。 虽然这适用于小输入，但浮点运算会引入精度误差，并且转换回不可约分数可能会很棘手。 这种方法不可靠，因为输出必须精确且不可约。 

最佳方法通过分别维护分子和分母来使用精确算术。 对于每个分数，我们计算一个公分母并使用整数算术执行加法或减法。 处理完所有分数后，我们使用最大公约数（GCD）简化结果，以确保分数是不可约的。 该方法保证了约束内任何输入的精度和正确性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 转换为浮点数并返回； 可能会产生精度误差|
 | 最佳 | O(n) | O(1) | O(1) | 使用 GCD 整数运算来维护精确分数 |

 ## 算法演练

 1. 初始化分子`num`和分母`den`表示运行总和，从`0/1`。 
2. 解析输入字符串以提取分数，注意显式处理正号和负号。 
3. 对于每个分数，提取其分子和分母。 
4. 使用公式计算运行总和的新分子`num * frac_den + frac_num * den`， 在哪里`frac_num`和`frac_den`是当前分数的分子和分母。 
5. 将分母更新为`den * frac_den`保持共同点。 
6. 处理完所有分数后，将所得分子和分母减去其最大公约数 (GCD)。 
7. 以字符串形式返回结果`numerator/denominator`。 

**为什么有效：** 该算法保持了一个不变量，即运行总和始终表示为单个分数。 每次加法或减法都是使用精确的整数算术执行的，因此不会丢失精度。 最后的简化保证了结果是不可约的，满足问题约束。 

## Python 解决方案```python
from math import gcd

class Solution:
    def fractionAddition(self, expression: str) -> str:
        import re
        # Initialize running numerator and denominator
        num, den = 0, 1
        
        # Extract all fractions with their signs
        fractions = re.findall(r'[+-]?\d+/\d+', expression)
        
        for frac in fractions:
            n, d = map(int, frac.split('/'))
            # Compute the new numerator with common denominator
            num = num * d + n * den
            den *= d
            # Reduce fraction at each step to avoid overflow
            g = gcd(abs(num), den)
            num //= g
            den //= g
        
        return f"{num}/{den}"
```Python 解决方案使用正则表达式可靠地提取每个分数，包括其符号。 对于每个分数，我们使用整数算术更新运行的分子和分母。 我们在每一步中应用 GCD 来保持数字较小并简化结果。 最后，分数被格式化为字符串。 

## 解决方案```go
package main

import (
    "fmt"
    "strconv"
    "strings"
)

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func fractionAddition(expression string) string {
    num, den := 0, 1
    i := 0
    for i < len(expression) {
        sign := 1
        if expression[i] == '+' || expression[i] == '-' {
            if expression[i] == '-' {
                sign = -1
            }
            i++
        }
        j := i
        for j < len(expression) && expression[j] != '+' && expression[j] != '-' {
            j++
        }
        frac := expression[i:j]
        parts := strings.Split(frac, "/")
        n, _ := strconv.Atoi(parts[0])
        d, _ := strconv.Atoi(parts[1])
        n *= sign
        num = num*d + n*den
        den *= d
        g := gcd(abs(num), den)
        num /= g
        den /= g
        i = j
    }
    return fmt.Sprintf("%d/%d", num, den)
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```在 Go 中，解析需要手动迭代字符串，因为 Go 没有像 Python 那样简洁的正则表达式。 更新分子、分母和应用 GCD 的逻辑保持不变。 我们明确地处理符号，并且分数的格式使用`fmt.Sprintf`。
