[LeetCode 第 589 题](https://leetcode.com/problems/n-ary-tree-preorder-traversal/)

 **难度：** 🟢简单
 **主题：** 堆栈、树、深度优先搜索

 ## 解决方案

 ## 问题理解

 该问题要求对 n 叉树进行**前序遍历**。 在前序遍历中，访问节点的顺序是：首先访问根节点，然后从左到右递归所有子节点。 输入给出为`root`n 叉树的节点，其中每个节点都有一个值和一个子节点列表。 输出应该是一个简单的整数列表，表示按前序访问的节点的值。 

树最多可以有 10,000 个节点**，其高度可以是 **最多 1000**。 每个节点的值介于`0`和`10,000`。 这意味着该解决方案必须有效地处理可能又大又深的树。 边缘情况包括**空树**（`root = None`），只有一个**单个节点**的树，或**没有子节点**的节点。 

该问题明确提到了**迭代解决方案**的后续工作，这意味着基于堆栈的方法有望避免深层树中的递归堆栈溢出。 

## 方法

 强力方法是使用**递归前序遍历**。 这涉及定义一个递归辅助函数，该函数首先将当前节点的值添加到结果列表中，然后按顺序递归遍历每个子节点。 这种方法简单，直接符合前序遍历的定义。 它对于所有输入都是正确的，但是对于接近最大高度 1000 的非常深的树，可能会超出 Python 的递归限制，并且迭代遍历更安全。 

**最佳方法**是使用**堆栈**的迭代解决方案。 通过将节点压入堆栈并以后进先出的方式处理它们，我们可以模仿递归遍历。 将子项添加到堆栈时，必须以**相反的顺序**压入它们，以便首先处理最左边的子项。 这避免了递归并且对于深树来说更安全。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 递归蛮力 | O(N) | O(H) | 使用调用堆栈，对于深树可能会溢出（H = 高度） |
 | 迭代堆栈| O(N) | O(H) | 对于深树来说是安全的，明确使用堆栈来跟踪节点 |

 ## 算法演练

 1. **检查空树**：如果`root`是`None`，立即返回一个空列表。 
2. **初始化堆栈和结果**：创建一个以根节点初始化的堆栈。 创建一个空列表`result`存储遍历输出。 
3. **处理栈直到空**：当栈不为空时，从栈顶弹出一个节点。 
4. **添加节点值**：将弹出的节点值追加到`result`。 
5. **以相反的顺序推入子节点**：对于弹出节点的每个子节点，将它们以相反的顺序推入堆栈。 这确保了最左边的子项首先被处理，从而保留了前序。 
6. **重复**：继续弹出并处理节点，直到堆栈为空。 
7. **返回结果**：栈为空后，返回`result`列表，现在包含前序遍历。 

**为什么起作用：** 堆栈通过首先处理根节点并按相反顺序推送子节点，确保按预序访问节点。 不变的是，每次迭代时，栈顶都是按先序访问的下一个节点，保证了正确的遍历。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: Optional[int] = None, children: Optional[List['Node']] = None):
        self.val = val
        self.children = children
"""

from typing import List, Optional

class Solution:
    def preorder(self, root: 'Node') -> List[int]:
        if not root:
            return []
        
        stack = [root]
        result = []
        
        while stack:
            node = stack.pop()
            result.append(node.val)
            if node.children:
                stack.extend(reversed(node.children))
        
        return result
```实现首先检查空树。 堆栈使用根节点进行初始化，并且我们迭代地处理节点。 每个节点值都附加到结果中，并且其子节点以相反的顺序推入堆栈，以保持正确的前序遍历。 当所有节点都被访问时，算法停止。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */

func preorder(root *Node) []int {
    if root == nil {
        return []int{}
    }
    
    stack := []*Node{root}
    result := []int{}
    
    for len(stack) > 0 {
        n := len(stack) - 1
        node := stack[n]
        stack = stack[:n]
        result = append(result, node.Val)
        
        for i := len(node.Children) - 1; i >= 0; i-- {
            stack = append(stack, node.Children[i])
        }
    }
    
    return result
}
```在 Go 中，我们处理`nil`明确地为空树。 切片用作堆栈，子级按相反顺序压入。 与 Python 不同，Go 需要手动切片操作来弹出最后一个元素。

 ## 边缘情况

 **空树**：树没有节点。 无需处理`root = None`，该算法在尝试访问属性时会抛出错误。 对于这种情况，Python 和 Go 解决方案都返回一个空列表。 

**单节点树**：仅具有根节点的树测试算法是否可以处理最小非空输入。 算法正确地添加根值并终止。 

**高度接近 1000 的深树**：由于 Python 的递归限制，递归解决方案可能会失败，但迭代堆栈方法可以安全地处理此问题。 堆栈的增长永远不会超出树的高度，从而确保内存效率。
