[LeetCode 545 题](https://leetcode.com/problems/boundary-of-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们以非常特定的顺序计算二叉树的边界遍历。 边界由四个部分组合而成：

 1.根节点
 2. 左边界，不包括叶子
 3.从左到右的所有叶子节点
 4. 右边界逆序排列，不包括叶子

 挑战不仅仅是遍历树，而是在保留所需顺序的同时小心避免重复。 

输入是二叉树的根。 每个节点都包含一个整数值以及对左子节点和右子节点的引用。 输出应该是一个整数列表，表示从根开始按顺时针顺序排列的树边界。 

约束允许最多`10^4`节点，这意味着期望进行有效的线性遍历。 任何重复扫描树的大部分的解决方案都可能变得低效。 由于树也可能高度不平衡，因此递归深度可以接近`O(n)`在最坏的情况下。 

定义中的几个细节很重要：

 - 叶节点是没有子节点的任何节点。 
- 在叶子收集阶段，根本身不被视为叶子。 
- 左边界不包括最左边的叶子。 
- 右边界不包括最右边的叶子。 
- 叶节点应该在最终答案中恰好出现一次。 

这些规则造成了一些棘手的边缘情况。 

例如：

 - 只有一个节点的树应该只返回该节点。 
- 只有左子树的树不应该复制叶子。 
- 只有右子节点的树仍应正确反转右边界。 
- 倾斜的树可能会导致左或右边界逻辑回退到交替的子方向。 
- 一个节点可以同时属于边界路径和叶集，因此防止重复很重要。 

核心困难是仔细分离三个遍历职责：

 - 收集左边界，
 - 收集树叶，
 - 以相反的顺序收集右边界。 

## 方法

 ### 蛮力方法

 强力策略是使用多次完整遍历和额外的簿记结构来显式模拟边界定义。 

一种可能的暴力方法是：

 - 遍历树以识别每条从根到叶的路径。 
- 确定最左边和最右边的路径。 
- 使用集合或映射来跟踪哪些节点属于哪个类别。 
- 仔细合并结果，同时删除重复项。 

这种方法之所以有效，是因为边界定义基于树中的结构位置。 通过计算所有相关路径和节点分类，我们可以重建正确的排序。 

然而，该方法不必要地复杂且低效。 它可能需要：

 - 存储许多路径，
 - 多次重新访问节点，
 - 使用额外的内存进行重复处理。 

对于大树来说，这会造成浪费。 

### 最佳方法

 关键的观察是边界自然地分为三个独立的遍历：

 1.左边界遍历
 2.叶子遍历
 3、右边界遍历

 每次遍历都可以在线性时间内执行，同时避免重复。 

最佳解决方案的工作原理如下：

 - 首先添加根。 
- 沿着左边的边界走，总是优先选择左边的孩子而不是右边的孩子，并在离开之前停下来。 
- 执行 DFS 从左到右收集所有叶子。 
- 沿着右边界走，始终优先选择右子节点而不是左子节点，临时存储节点，然后在追加之前反转它们。 

这是有效的，因为每个边界节点都属于以下结构类别之一：

 - 左边缘，
 - 叶子，
 - 右边缘，
 - 或根。 

通过从两次边界遍历中排除叶子，我们确保每个节点仅出现一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 多次遍历和路径存储 |
 | 最佳 | O(n) | O(h) | 使用 DFS 进行单遍式遍历 |

 这里，`n`是节点数，`h`是树的高度。 

## 算法演练

 1. 首先处理空树的情况。 

如果根是`None`，立即返回一个空列表。 
2. 创建一个辅助函数来确定节点是否是叶子。 

如果两个节点都满足，则节点是叶子`left`和`right`是`None`。 

这个助手简化了整个算法的重复预防。 
3. 使用根值初始化结果列表。 

根始终是边界的一部分。 

但是，如果树只包含根节点，我们应该立即返回，因为根以后不应该被视为叶子。 
4. 穿过左边界。 

开始于`root.left`。 

每一步：

 - 如果当前节点不是叶子，则将其添加到结果中。 
- 更喜欢移动到左边的孩子。 
- 如果不存在左孩子，则移动到右孩子。 

这遵循问题陈述中的精确左边界定义。 
5. 使用DFS收集所有叶节点。 

对整棵树执行深度优先遍历。 

对于每个节点：

 - 如果是叶子，则将其添加到结果中。 
- 否则首先递归地探索左子树，然后探索右子树。 

左优先 DFS 保证从左到右收集叶子。 
6. 穿过右边界。 

开始于`root.right`。 

每一步：

 - If the node is not a leaf, store it in a temporary list.
 - 更喜欢转移到正确的孩子身上。 
- If no right child exists, move to the left child.

 After traversal completes, reverse the temporary list and append it to the result.

 Reversal is necessary because the boundary definition requires bottom-up ordering on the right side.
 7. 返回最终结果列表。 

### 为什么它有效

 The algorithm works because every boundary node belongs to exactly one logical section:

 - 根在开始时添加一次。 
- Left boundary nodes are collected top-down without leaves.
 - Leaves are collected separately in left-to-right order.
 - Right boundary nodes are collected bottom-up without leaves.

 Since leaves are excluded from both boundary traversals, no node is duplicated. Since DFS visits leaves left-first, the required ordering is preserved.

 ## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import List, Optional

class Solution:
    def boundaryOfBinaryTree(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        def is_leaf(node: TreeNode) -> bool:
            return not node.left and not node.right

        # Single node tree
        if is_leaf(root):
            return [root.val]

        boundary = [root.val]

        # Add left boundary
        current = root.left

        while current:
            if not is_leaf(current):
                boundary.append(current.val)

            if current.left:
                current = current.left
            else:
                current = current.right

        # Add leaves
        def add_leaves(node: Optional[TreeNode]) -> None:
            if not node:
                return

            if is_leaf(node):
                boundary.append(node.val)
                return

            add_leaves(node.left)
            add_leaves(node.right)

        add_leaves(root)

        # Add right boundary
        current = root.right
        right_boundary = []

        while current:
            if not is_leaf(current):
                right_boundary.append(current.val)

            if current.right:
                current = current.right
            else:
                current = current.left

        boundary.extend(reversed(right_boundary))

        return boundary
```该实现从空树和单节点树的边缘情况处理开始。 这可以防止在叶子遍历期间重复包含根。 

这`is_leaf`助手集中叶子检测逻辑。 由于该问题明确排除了左边界遍历和右边界遍历中的叶子节点，因此在整个解决方案中重复使用该辅助函数。 

左边界遍历向下迭代，同时始终优先考虑左孩子。 如果左孩子不存在，则遍历返回到右孩子。 这完全符合问题的定义。 

叶子收集阶段使用DFS。 递归遍历自然地按从左到右的顺序访问叶子，因为左子树在右子树之前被处理。 

右边界遍历镜像左边界遍历。 但是，节点存储在临时列表中，因为最终边界需要在右侧进行反向排序。 

最后，将反转的右边界附加到结果中。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func boundaryOfBinaryTree(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }

    isLeaf := func(node *TreeNode) bool {
        return node.Left == nil && node.Right == nil
    }

    if isLeaf(root) {
        return []int{root.Val}
    }

    boundary := []int{root.Val}

    // Add left boundary
    current := root.Left

    for current != nil {
        if !isLeaf(current) {
            boundary = append(boundary, current.Val)
        }

        if current.Left != nil {
            current = current.Left
        } else {
            current = current.Right
        }
    }

    // Add leaves
    var addLeaves func(node *TreeNode)

    addLeaves = func(node *TreeNode) {
        if node == nil {
            return
        }

        if isLeaf(node) {
            boundary = append(boundary, node.Val)
            return
        }

        addLeaves(node.Left)
        addLeaves(node.Right)
    }

    addLeaves(root)

    // Add right boundary
    current = root.Right
    rightBoundary := []int{}

    for current != nil {
        if !isLeaf(current) {
            rightBoundary = append(rightBoundary, current.Val)
        }

        if current.Right != nil {
            current = current.Right
        } else {
            current = current.Left
        }
    }

    // Reverse append
    for i := len(rightBoundary) - 1; i >= 0; i-- {
        boundary = append(boundary, rightBoundary[i])
    }

    return boundary
}
```Go 实现遵循与 Python 解决方案相同的结构。 主要差异来自语言机制。 

Go 使用显式`nil`检查而不是 Python 的真实性。 切片用于动态数组，并且使用反向循环而不是 Python 来手动处理反转`reversed()`帮手。 

递归 DFS 是使用函数变量声明来实现的，因为 Go 要求在赋值之前声明递归匿名函数。

 ## 边缘情况

 ### 单节点树

 仅包含根的树是最重要的边缘情况之一。 幼稚的实现可能会将根添加一次作为根，然后在叶遍历期间再次添加，从而产生重复项。 

该实现通过在开始正常算法之前显式检查根是否是叶子来避免这种情况。 如果是，则立即返回`[root.val]`。 

### 倾斜的树

 完全左偏或右偏的树可能会暴露边界遍历逻辑中的缺陷。 在这些情况下，几乎每个节点都属于边界。 

例如，在一棵右偏树中，右边界必须以相反的顺序出现，而叶子应该只出现一次。 

该实现在边界遍历期间正确排除叶子，并在 DFS 期间单独附加它们，从而防止重复。 

### 缺少首选孩子

 问题定义指出，如果左边界节点没有左子节点，则应继续遍历右子节点。 同样的规则对称地适用于右侧。 

这很容易被忽视。 

例如：```
    1
   /
  2
   \
    3
```节点`3`在结构上仍然是树左侧的一部分。 

该实现通过以下方式处理此问题：

 - 更喜欢`left`首先在左遍历期间，
 - 否则回到`right`。 

正确的边界遍历相反地反映了这种行为。
