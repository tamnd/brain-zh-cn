[LeetCode 557 题](https://leetcode.com/problems/reverse-words-in-a-string-iii/)

 **难度：** 🟢简单
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 该问题需要反转字符串中每个单词的字符，同时保持单词的原始顺序和单词之间的间距。 换句话说，句子结构保持不变，但每个单词都镜像到位。 例如，这个词`"Let's"`变成`"s'teL"`， 和`"LeetCode"`变成`"edoCteeL"`。 

输入`s`是一个仅包含可打印 ASCII 字符的字符串，并且保证没有前导或尾随空格。 所有单词均由一个空格分隔。 字符串长度最多可达 50,000 个字符，因此解决方案必须有效地处理相对较大的字符串。 

重要的边缘情况包括具有单个单词的字符串、具有很长单词的字符串或单词包含标点符号的字符串。 该问题保证至少有一个单词，因此空输入不需要处理。 

## 方法

 暴力方法是使用空格作为分隔符将字符串拆分为单词，单独反转每个单词，然后将它们连接回单个字符串。 这种方法可以正确工作，因为它独立处理每个单词并保持原始单词顺序。 但是，它可能会创建不必要的中间字符串列表，并且如果字符串很长，则在内存方面可能不是最佳的。 

最佳方法利用两指针技术在每个单词中就地反转字符。 通过迭代字符串一次并使用索引来标记单词边界，我们可以反转每个单词中的字符，而无需为中间列表分配额外的内存。 这减少了额外的内存开销，并且可以稍微提高非常大的输入的性能。

 ## 算法演练

 1. 转换输入字符串`s`到一个可变的字符列表中。 这是必要的，因为大多数语言（包括 Python）中的字符串都是不可变的。 
2. 初始化一个指针`start`0 处标记当前单词的开头。 
3. 使用索引迭代字符串的字符`end`。 当遇到空格或到达字符串末尾时，将其视为当前单词的末尾。 
4. 反转之间的字符`start`和`end - 1`。 此步骤使用标准的两指针交换来镜像单词。 
5. 移动`start`指向`end + 1`开始下一个单词。 
6. 迭代所有字符并反转所有单词后，将字符列表转换回字符串并返回。 

工作原理：该算法保持了单词顺序不变的不变性，并且每个单词都单独反转。 通过在每个单词边界内使用两指针反转，该算法可确保单词中的所有字符恰好反转一次。 

## Python 解决方案```python
class Solution:
    def reverseWords(self, s: str) -> str:
        chars = list(s)
        start = 0
        n = len(chars)
        
        for end in range(n + 1):
            if end == n or chars[end] == ' ':
                left, right = start, end - 1
                while left < right:
                    chars[left], chars[right] = chars[right], chars[left]
                    left += 1
                    right -= 1
                start = end + 1
        
        return ''.join(chars)
```Python 实现首先将字符串转换为字符列表，以便它可以修改单个字符。 它迭代列表的索引并使用两个指针反转每个单词`left`和`right`。 处理完所有单词后，它将字符列表重新连接成字符串并返回。 

## 解决方案```go
func reverseWords(s string) string {
    chars := []rune(s)
    start := 0
    n := len(chars)
    
    for end := 0; end <= n; end++ {
        if end == n || chars[end] == ' ' {
            left, right := start, end-1
            for left < right {
                chars[left], chars[right] = chars[right], chars[left]
                left++
                right--
            }
            start = end + 1
        }
    }
    
    return string(chars)
}
```Go 实现与 Python 类似，但使用了一部分`rune`而不是用字符串来处理可变字符。 两指针反转也以同样的方式应用。 最后转换回字符串可确保函数返回正确的结果。

 ## 边缘情况

 一个重要的边缘情况是单字字符串。 需要空格的幼稚实现可能无法反转唯一的单词。 我们的算法可以正确处理这个问题，因为它检查字符串的末尾作为单词边界。 

另一个边缘情况是包含标点符号或数字的单词。 由于反转逻辑仅对字符位置进行操作，并不过滤内容，因此标点符号和数字会与字母一起反转，从而保持正确性。 

第三种边缘情况是非常长的字符串，尤其是接近最大长度 50,000 个字符。 重复创建新字符串的解决方案效率很低。 就地字符数组方法可确保解决方案在时间上保持线性，并且不会创建多个中间字符串，从而有效地处理大型输入。
