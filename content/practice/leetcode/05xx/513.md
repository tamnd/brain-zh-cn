[LeetCode 513 题](https://leetcode.com/problems/find-bottom-left-tree-value/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到二叉树最后一行中最左边的值。 二叉树是一种分层数据结构，其中每个节点最多有两个子节点：左子节点和右子节点。 问题的输入是树的根节点，它允许通过跟随子指针遍历到任何其他节点。 预期输出是一个整数值，表示树中最深级别的最左边的节点。 

主要观察结果包括理解“最后一行”对应于树的最大深度。 该行中的“最左边”节点只是在该深度从左向右遍历时遇到的第一个节点。 这些约束表明树最多可以包含 10,000 个节点，节点值在有符号 32 位整数范围内。 这个大小足够小，可以允许标准深度优先搜索 (DFS) 或广度优先搜索 (BFS) 遍历，而不会达到 Python 或 Go 中的内存或递归限制。 

重要的边缘情况包括只有一个节点的树、倾斜的树（全部为左子节点或全部为右子节点）以及最深层存在多个节点的树。 该问题保证至少有一个节点存在，因此不需要处理空树。 

## 方法

 暴力方法涉及遍历整个树，同时跟踪每个深度级别的所有节点，并将它们存储在列表或数组中。 遍历完成后，我们从最后一层中选择第一个元素。 这可以正常工作，但需要 O(n) 额外空间来存储所有级别，这可能会造成浪费。 

最佳方法利用 BFS 或 DFS 来查找最后一行中最左边的值，而不存储所有节点。 BFS 自然适合，因为它逐级处理节点。 通过从左到右遍历每个级别并跟踪每个级别的第一个节点，BFS 完成后最后记录的最左边的节点将是正确答案。 DFS 还可以通过将左子节点优先于右子节点并跟踪遇到的最大深度来使用； 每当达到新的最大深度时，我们都会使用当前节点值更新结果。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 在选择最后一行最左边的节点之前存储所有级别的所有节点 |
 | BFS / DFS 最优 | O(n) | BFS 为 O(w)，DFS 为 O(h) | BFS 使用当前层宽度为 w 的队列，DFS 使用递归堆栈直至树高为 h |

 ## 算法演练

 我们来描述一下BFS最优算法：

 1. 以根节点初始化队列。 这个队列会逐级维护待处理的节点。 
2. 当队列不为空时，迭代队列中当前的所有节点（代表一级）。 将级别中第一个节点的值存储为最左边值的候选值。 
3. 对于当前级别中的每个节点，将其左子节点入队，然后将其右子节点入队（如果存在）。 这确保了从左到右处理下一个级别。 
4. 处理完当前层的所有节点后，对下一层重复该过程。 最后处理的级别的最左边的节点存储在结果中。 
5. 一旦队列为空，返回存储的最左边的值。 

工作原理：BFS 确保节点从左到右逐级处理。 通过在每个级别开始时更新最左边的值，最后存储的值对应于最深级别的最左边的节点。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        queue = deque([root])
        leftmost = root.val
        
        while queue:
            level_size = len(queue)
            for i in range(level_size):
                node = queue.popleft()
                if i == 0:
                    leftmost = node.val
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        
        return leftmost
```Python实现以根节点初始化一个双端队列，并逐层处理树。 在每个级别开始时，第一个节点的值记录在最左边。 子级按从左到右的顺序添加到队列中，以保留 BFS 属性。 队列为空后，返回最后一层最左边的值。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func findBottomLeftValue(root *TreeNode) int {
    queue := []*TreeNode{root}
    leftmost := root.Val
    
    for len(queue) > 0 {
        levelSize := len(queue)
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            if i == 0 {
                leftmost = node.Val
            }
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
    }
    
    return leftmost
}
```Go 实现反映了 Python BFS 方法。 它使用切片作为队列，切掉已处理的元素。 零检查确保我们只将有效的子项放入队列。 最左边的变量在每个级别开始时更新以保持正确的值。 

## 工作示例

 **示例 1：根 = [2,1,3]**

 1 级：`[2]`→ 最左边 = 2

 2 级：`[1,3]`→ 最左边 = 1

 结果：1

 **示例 2: root = [1,2,3,4,null,5,6,null,null,7]**

 1 级：`[1]`→ 最左边 = 1

 2 级：`[2,3]`→ 最左边 = 2

 3级：`[4,5,6]`→ 最左边 = 4

 4 级：`[7]`→ 最左边 = 7

 结果：7

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 在 BFS 中每个节点都被访问一次
 | 空间| O(w) | 队列最多存储任意层树的最大宽度w |

 时间复杂度是线性的，因为每个节点只被处理一次。 空间复杂度与任何级别的最大节点数（即树的宽度）成正比。

 ## 边缘情况

 一个重要的边缘情况是一棵只有一个节点的树。 由于树没有子节点，因此最左边的底部值就是根本身。 另一种是左偏树，其中每个节点只有一个左子节点。 逐层遍历可确保算法正确识别最深最左边的节点。 第三种边缘情况是右偏树，该算法仍然有效，因为它跟踪每个级别中的第一个节点； 即使某个级别只有右子节点，该级别中的第一个节点也会被视为最左边的节点。 所有这些情况都可以通过 BFS 在每个级别开始时更新最左边的值来正确处理。
