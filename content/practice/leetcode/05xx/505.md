 ## 解决方案

 ## 问题理解

 该问题提出了一个表示为大小为 2D 网格的迷宫`m x n`其中每个单元格要么是一个空白区域（`0`）或墙（`1`）。 球从给定位置开始，可以**向上、向下、向左或向右**。 至关重要的是，球将**继续沿选定的方向滚动，直到撞到墙壁**，因此它无法在空旷的空间中途停止。 任务是计算球必须行进的**最短距离**才能准确地停在`destination`。 距离测量为球穿过的空白空间的数量，**不包括起始单元格并包括目标单元格**。 如果球无法到达目的地或无法停在那里，该函数应该返回`-1`。 

输入保证在以下约束范围内：`1 <= m, n <= 100`，确保网格对于图遍历技术而言相当小。 保证起点和终点都是空的并且不重合。 迷宫以墙壁为界，因此我们永远不需要明确检查网格边缘之外的出界位置。 

重要的边缘情况包括目的地位于走廊上但无法作为停止点到达的情况、存在多个滚动路径的迷宫以及​​起点与限制初始移动的墙壁相邻的情况。 

## 方法

 最直接的方法是尝试**强力 DFS**。 在这种方法中，我们递归地探索从起点到目的地的每条可能的滚动路径。 对于每个单元格，我们考虑在所有四个方向上滚动，直到撞到墙上，然后继续递归。 虽然这保证了所有路径都被探索并且可以找到正确的最小距离，但它的计算成本很高，因为它可能会以不同的路径长度多次重新访问相同的位置，从而在最坏的情况下导致指数时间复杂度。 

最佳解决方案的关键见解是，这个问题相当于寻找**加权图中的最短路径**，其中每个节点都是停止位置，边代表滚动距离。 由于距离始终为非负，**Dijkstra 算法** 是理想的。 我们维护一个优先队列，其中球接下来探索最近的未访问过的停止点，仅在找到更短的路径时更新距离。 这确保我们有效地计算最小距离，而无需多余的探索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力DFS | O(4^(m*n)) | O(4^(m*n)) | O(m*n) | 递归探索所有路径； 由于重新访问节点，速度非常慢。 |
 | 最优 Dijkstra | O(m_n_log(m*n)) | O(m_n_log(m*n)) | O(m*n) | 首先使用最小堆来探索最短路径； 避免不必要的重访。 |

 ## 算法演练

 1. 初始化一个`distance`大小矩阵`m x n`其中每个条目代表到达该单元格的最短已知距离。 将除开始之外的所有值设置为无穷大，即`0`。 
2. 使用最小堆优先级队列按当前最短距离的顺序探索位置。 推动起始位置和距离`0`进入队列。 
3. 当队列不为空时，弹出当前距离最小的单元格。 这确保我们始终首先探索最有希望的路径。 
4. 对于四个方向（上、下、左、右）中的每一个，模拟滚动球直到撞到墙壁。 计算本次滚动期间经过的单元格数量。 
5. 球停止后，计算到停止单元的新的暂定距离。 如果这个距离小于之前记录的距离，则更新距离矩阵，并将具有新距离的单元推入队列。 
6. 重复步骤 3-5，直到队列为空或目的地距离已最终确定。 
7. 返回到达目的地的最短距离。 如果该值仍然无穷大，则返回`-1`因为这意味着目的地无法到达。 

**为什么有效：** Dijkstra 算法保证了具有非负边权重的图中的最短路径。 每个停止位置对应一个图节点，每个滚动段代表一条加权边。 通过始终首先探索最小距离并仅在找到较短路径时进行更新，我们避免了冗余计算并正确计算到目的地的最短距离。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def shortestDistance(self, maze: List[List[int]], start: List[int], destination: List[int]) -> int:
        m, n = len(maze), len(maze[0])
        distance = [[float('inf')] * n for _ in range(m)]
        distance[start[0]][start[1]] = 0
        
        heap = [(0, start[0], start[1])]  # (distance, row, col)
        directions = [(0,1), (1,0), (0,-1), (-1,0)]
        
        while heap:
            dist, x, y = heapq.heappop(heap)
            if [x, y] == destination:
                return dist
            if dist > distance[x][y]:
                continue
            for dx, dy in directions:
                nx, ny, steps = x, y, 0
                while 0 <= nx + dx < m and 0 <= ny + dy < n and maze[nx+dx][ny+dy] == 0:
                    nx += dx
                    ny += dy
                    steps += 1
                if dist + steps < distance[nx][ny]:
                    distance[nx][ny] = dist + steps
                    heapq.heappush(heap, (distance[nx][ny], nx, ny))
        
        return -1
```Python 代码初始化距离矩阵和最小堆。 这`while`循环确保接下来处理最近的未访问位置。 对于每个方向，球滚动直到遇到墙壁，如果新的距离比之前记录的距离有所改善，则会更新。 这确保了 Dijkstra 算法的正确应用。 

## 解决方案```go
import (
    "container/heap"
    "math"
)

type Item struct {
    x, y, dist int
}

type PriorityQueue []Item

func (pq PriorityQueue) Len() int { return len(pq) }
func (pq PriorityQueue) Less(i, j int) bool { return pq[i].dist < pq[j].dist }
func (pq PriorityQueue) Swap(i, j int) { pq[i], pq[j] = pq[j], pq[i] }
func (pq *PriorityQueue) Push(v any) { *pq = append(*pq, v.(Item)) }
func (pq *PriorityQueue) Pop() any {
    old := *pq
    n := len(old)
    item := old[n-1]
    *pq = old[:n-1]
    return item
}

func shortestDistance(maze [][]int, start []int, destination []int) int {
    m, n := len(maze), len(maze[0])
    distance := make([][]int, m)
    for i := range distance {
        distance[i] = make([]int, n)
        for j := range distance[i] {
            distance[i][j] = math.MaxInt32
        }
    }
    distance[start[0]][start[1]] = 0
    
    pq := &PriorityQueue{}
    heap.Init(pq)
    heap.Push(pq, Item{start[0], start[1], 0})
    
    dirs := [][]int{{0,1},{1,0},{0,-1},{-1,0}}
    
    for pq.Len() > 0 {
        item := heap.Pop(pq).(Item)
        x, y, dist := item.x, item.y, item.dist
        if x == destination[0] && y == destination[1] {
            return dist
        }
        if dist > distance[x][y] {
            continue
        }
        for _, d := range dirs {
            nx, ny, steps := x, y, 0
            for nx+d[0] >= 0 && nx+d[0] < m && ny+d[1] >= 0 && ny+d[1] < n && maze[nx+d[0]][ny+d[1]] == 0 {
                nx += d[0]
                ny += d[1]
                steps++
            }
            if dist+steps < distance[nx][ny] {
                distance[nx][ny] = dist + steps
                heap.Push(pq, Item{nx, ny, distance[nx][ny]})
            }
        }
    }
    return -1
}
```在 Go 中，优先级队列是使用`container/heap`界面。 使用 2D 切片跟踪每个单元格的距离。 逻辑反映了 Python 版本，特别注意堆操作和整数处理。
