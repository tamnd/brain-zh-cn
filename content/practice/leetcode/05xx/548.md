[LeetCode 第 548 题](https://leetcode.com/problems/split-array-with-equal-sum/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们判断一个整数数组是否`nums`通过选择三个索引可以将其分为四个总和相等的非空子数组`i`,`j`， 和`k`满足严格的排序约束：`0 < i`,`i + 1 < j`,`j + 1 < k < n - 1`。 这些索引定义了四个连续子数组的边界：第一个来自索引`0`到`i-1`，第二个来自`i+1`到`j-1`，第三个来自`j+1`到`k-1`，第四个来自`k+1`到`n-1`。 

输入是单个整数数组`nums`最多 2000 个元素，每个元素的范围可能是`-10^6`到`10^6`。 输出是一个布尔值，指示是否存在此类拆分。 

重要的边缘情况包括无法分割的非常小的数组、可能存在多个分割的所有元素相等的数组，以及可能破坏简单求和比较的负值数组。 该问题保证数组至少有一个元素，但严格的索引约束意味着数组的长度必须至少为 7 才能允许有效`(i, j, k)`三联体。 

## 方法

 暴力解决方案将涉及迭代所有可能的三元组`(i, j, k)`满足约束并检查四个子数组的总和是否相等。 这保证了正确性，因为它会评估每个有效的组合。 然而，在没有预先计算的情况下重复计算子数组和将需要 O(n^3) 时间，并且对于`n = 2000`。 

优化的关键见解是使用前缀和在恒定时间内计算子数组和，并使用哈希集来存储潜在的和匹配。 通过固定中间索引`j`通过前缀和检查左右分区，我们可以显着减少操作次数。 具体来说，对于每个`j`，我们检查所有有效的`i`向左和`k`到右侧，并跟踪使用集合看到的总和。 这将复杂度从 O(n^3) 降低到大约 O(n^2)，同时为前缀和使用额外的空间。

 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 检查所有可能的情况`(i, j, k)`带有嵌套循环的三元组，重复计算总和 |
 | 最佳 | O(n^2) | O(n^2) | O(n) | 使用前缀和进行恒定时间总和计算，并使用哈希集来跟踪有效的分割 |

 ## 算法演练

 1. 计算前缀和数组`prefix`这样`prefix[x]`等于所有元素的总和`nums[0]`到`nums[x]`。 这允许通过 O(1) 计算任何子数组和`prefix[r] - prefix[l-1]`如果`l > 0`， 否则`prefix[r]`。 
2. 迭代所有可能的中间索引`j`从 3 到`n-4`。 这确保了双方都有足够的空间来选择有效的`i`和`k`。 
3. 对于每个`j`，维护一个哈希集`seen_sums`潜在左分区的总和。 迭代一遍`i`从 1 到`j-2`并检查总和是否来自`0`到`i-1`等于总和`i+1`到`j-1`。 如果是，则将该总和添加到`seen_sums`。 
4. 迭代潜力`k`从`j+2`到`n-2`。 计算正确分区的总和`j+1`到`k-1`和`k+1`到`n-1`。 如果这些总和与中的总和匹配`seen_sums`，则存在有效的分割并返回`true`。 
5. 如果无效`(i, j, k)`检查完所有三元组后满足条件`j`， 返回`false`。 

为什么有效：通过修复`j`并检查所有`i`向左和`k`向右使用前缀和，我们可以有效地检查左右子数组的每个有效组合，而无需重复求和。 哈希集确保我们只考虑两边都可以匹配的和，从而保持正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def splitArray(self, nums: List[int]) -> bool:
        n = len(nums)
        if n < 7:
            return False
        
        prefix = [0] * n
        prefix[0] = nums[0]
        for i in range(1, n):
            prefix[i] = prefix[i - 1] + nums[i]
        
        for j in range(3, n - 3):
            seen_sums = set()
            for i in range(1, j - 1):
                if prefix[i - 1] == prefix[j - 1] - prefix[i]:
                    seen_sums.add(prefix[i - 1])
            
            for k in range(j + 2, n - 1):
                right_sum = prefix[n - 1] - prefix[k]
                middle_right_sum = prefix[k - 1] - prefix[j]
                if middle_right_sum == right_sum and middle_right_sum in seen_sums:
                    return True
        
        return False
```该实现首先计算前缀和数组以允许 O(1) 子数组和查询。 然后迭代可能的中间索引`j`，将左侧的总和收集到一个集合中并检查右侧的匹配总和。 通过使用前缀和数组和集合，我们减少了重复计算并有效地确定是否存在有效的分割。 

## 解决方案```go
func splitArray(nums []int) bool {
    n := len(nums)
    if n < 7 {
        return false
    }
    
    prefix := make([]int, n)
    prefix[0] = nums[0]
    for i := 1; i < n; i++ {
        prefix[i] = prefix[i-1] + nums[i]
    }
    
    for j := 3; j < n-3; j++ {
        seenSums := make(map[int]struct{})
        for i := 1; i < j-1; i++ {
            if prefix[i-1] == prefix[j-1]-prefix[i] {
                seenSums[prefix[i-1]] = struct{}{}
            }
        }
        
        for k := j + 2; k < n-1; k++ {
            rightSum := prefix[n-1] - prefix[k]
            middleRightSum := prefix[k-1] - prefix[j]
            if middleRightSum == rightSum {
                if _, ok := seenSums[middleRightSum]; ok {
                    return true
                }
            }
        }
    }
    
    return false
}
```在 Go 中，我们使用具有空结构值的映射来有效跟踪看到的总和。 逻辑反映了Python版本：计算前缀和，迭代`j`，跟踪一组中的左和，并检查匹配的右和。
