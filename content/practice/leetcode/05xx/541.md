[LeetCode 541 题](https://leetcode.com/problems/reverse-string-ii/)

 **难度：** 🟢简单
 **主题：** 两个指针，字符串

 ## 解决方案

 ## 问题理解

 该问题需要我们操作一个字符串`s`以结构化的方式。 具体来说，我们需要反转第一个`k`每个连续块的字符`2k`字符串中的字符。 如果一个块的数量少于`k`字符，我们将它们全部反转。 如果一个块之间有`k`和`2k`字符，我们反转第一个`k`并将其余字符保留原样。 

输入是一个字符串`s`仅包含小写英文字母和整数`k`。 输出是执行指定反转后转换后的字符串。 

约束告诉我们字符串长度可达`10^4`和`k`也可以达到`10^4`。 这表明我们需要一个相对于字符串长度在时间上呈线性的解决方案，并且我们应该小心额外的空间使用。 

重要的边缘情况包括短于的字符串`k`，字符串长度不是其倍数`2k`，以及当`k`等于字符串的长度。 这些边缘情况可能会破坏不仔细检查边界的幼稚实现。 

## 方法

 蛮力方法是以块的形式迭代字符串`2k`，显式反转第一个`k`每个块的字符，并将结果连接起来形成最终的字符串。 这种方法是正确的，但涉及不必要的切片和字符串连接，这对于大字符串可能效率低下。 

最佳方法基于我们可以将字符串转换为可变字符列表并使用两个指针反转部分的观察。 通过以以下步骤迭代字符串`2k`，我们只反转第一个`k`每个段的字符。 这避免了重复的字符串连接并减少了构造中间字符串的开销。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*k) | O(n) | 迭代块、反转​​每个切片、连接字符串 |
 | 最佳| O(n) | O(n) | 转换为列表，使用两个指针就地反转 |

 ## 算法演练

 1. 转换字符串`s`到字符列表中，因为字符串在 Python 中是不可变的，我们需要就地修改。 
2. 以步长大小迭代字符串`2k`，从索引开始`0`。 
3. 对于每次迭代，确定要反转的段的起点和终点。 该段从当前索引开始`i`并结束于`i + k - 1`，但不得超过字符串长度。 
4. 使用两个指针将段反转：一个指针在开头，一个在结尾，交换字符，同时将指针移向彼此。 
5. 继续，直到到达字符串末尾。 
6. 将字符列表转换回字符串并返回。 

**为什么有效：** 通过仅反转第一个`k`每个的字符`2k`块到位后，算法满足每个分段的问题要求。 两指针反转可保证每个段内的字符有效反转，而不影响其他段。 

## Python 解决方案```python
class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        chars = list(s)
        n = len(chars)
        
        for i in range(0, n, 2*k):
            left = i
            right = min(i + k - 1, n - 1)
            
            while left < right:
                chars[left], chars[right] = chars[right], chars[left]
                left += 1
                right -= 1
        
        return ''.join(chars)
```该实现首先将字符串转换为列表以允许就地交换。 循环增量为`2k`因为我们处理块`2k`一次字符，仅反转第一个字符`k`。 这`min`函数确保我们不会超过字符串长度。 最后，列表被连接回字符串。 

## 解决方案```go
func reverseStr(s string, k int) string {
    chars := []rune(s)
    n := len(chars)
    
    for i := 0; i < n; i += 2 * k {
        left := i
        right := i + k - 1
        if right >= n {
            right = n - 1
        }
        
        for left < right {
            chars[left], chars[right] = chars[right], chars[left]
            left++
            right--
        }
    }
    
    return string(chars)
}
```在 Go 中，我们将字符串转换为`[]rune`安全地处理 Unicode，尽管对于小写英文字母`[]byte`也足够了。 其逻辑与 Python 类似，使用两个指针来反转段。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 一种重要的边缘情况是当字符串长度小于`k`。 在这种情况下，必须反转整个字符串。 该实现通过以下方式处理此问题`min`右指针的函数，确保没有越界访问。 

当字符串长度介于`k`和`2k`。 这里只讲第一个`k`字符反转，其余不变。 迭代的步骤为`2k`自然地确保了这种行为。 

最后，当`k`等于字符串长度，整个字符串恰好反转一次。 两指针逻辑正确识别该段并将其反转，而不会超出字符串边界。 这确保了问题陈述所规定的所有场景都得到有效处理。
