[LeetCode 527 题](https://leetcode.com/problems/word-abbreviation/)

 **难度：** 🔴难
 **主题：** 数组、字符串、贪婪、Trie、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们计算一组不同字符串的**最小唯一缩写**。 缩写用计数替换单词的中间字符，保留第一个和最后一个字符。 例如，`"internal"`变成`"i6l"`因为中间有六个字母`i`和`l`。 

当多个单词共享相同的缩写时，就会出现挑战。 在这种情况下，我们必须**增加前缀长度**（计数之前包含的起始字符数），直到所有缩写都是唯一的。 例如，`"abcdef"`和`"abndef"`最初缩写为`"a4f"`。 增加前缀给出`"ab3f"`进而`"abc2f"`/`"abn2f"`直到实现唯一性。 

输入是**唯一字符串**的数组，每个长度为 2 到 400，最多 400 个字符串。 输出是一个缩写数组，每个缩写都是最小的、唯一的，并且比原始单词短（否则我们保留原始单词）。 

要注意的边缘情况包括非常短的单词（例如`"aa"`)、仅最后一个字符不同的单词以及缩写不会减少其长度的单词。 

## 方法

 ### 暴力方法

 一种简单的方法是从每个单词的标准缩写开始。 然后，重复检查所有单词对是否有冲突。 每当两个单词共享缩写时，增加冲突单词的前缀并重新计算缩写。 继续下去，直到所有缩写都是唯一的。 

这种方法之所以有效，是因为它直接遵循问题规则，但效率较低。 检查所有对并重复更新缩写可能需要 **O(n² * L)** 时间，其中`n`是单词数，`L`是最大字长，这对于`n`最多 400 个并且`L`最多 400 个。 

### 最佳方法

 关键的观察是单词可以**按长度和当前缩写**进行分组，然后我们可以解决**每个组内的冲突**，而不是全局检查所有对。 使用**类似trie的前缀解析**或**冲突的哈希图**，我们可以有效地确定每个单词所需的最小前缀长度以确保唯一性。 

对于最初共享相同缩写的每组单词，我们只增加它们的前缀长度以消除歧义。 这样可以避免不必要的重复工作，并确保每个单词都有最少的缩写。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² * L) | O(n) | 比较所有对，迭代增加前缀 |
 | 最佳| O(n * L) | O(n * L) | 对单词进行分组，智能地增加前缀，直到解决冲突 |

 ## 算法演练

 1. **初始缩写：** 对于每个单词，使用以下公式生成第一个缩写：第一个字母 + 中间字母的数量 + 最后一个字母。 
2. **分组：** 单词分组依据`(length, last character)`和当前的缩写。 这确保我们只检查实际上可能发生冲突的单词之间的冲突。 
3. **前缀解析：** 对于每个存在冲突的组，确定使缩写词唯一的每个单词的最小前缀长度。 迭代地增加前缀，但仅限于冲突集中。 
4. **缩写最终确定：** 对于每个单词，使用其解析的前缀长度计算最终缩写。 如果缩写不短于原​​文，则保留原文。 
5. **返回：** 按照与输入相同的顺序组装缩写列表。 

**为什么有效：** 通过关注冲突组并仅根据需要增加前缀，我们保证了最小性和唯一性。 由于冲突是在群体内局部解决的，因此我们避免了不必要的比较。 不变的是，处理后，没有两个单词共享相同的缩写。 

## Python 解决方案```python
from typing import List, Dict, Tuple
from collections import defaultdict

class Solution:
    def wordsAbbreviation(self, words: List[str]) -> List[str]:
        n = len(words)
        prefix_lengths = [1] * n
        
        def abbreviate(word: str, prefix_len: int) -> str:
            if prefix_len >= len(word) - 2:
                return word
            return word[:prefix_len] + str(len(word) - prefix_len - 1) + word[-1]
        
        # Initialize abbreviations
        abbr_map: Dict[str, List[int]] = defaultdict(list)
        for i, word in enumerate(words):
            abbr = abbreviate(word, 1)
            abbr_map[abbr].append(i)
        
        # Resolve conflicts
        while True:
            new_map = defaultdict(list)
            resolved = True
            for abbr, indices in abbr_map.items():
                if len(indices) == 1:
                    new_map[abbr].append(indices[0])
                else:
                    resolved = False
                    for idx in indices:
                        prefix_lengths[idx] += 1
                        new_abbr = abbreviate(words[idx], prefix_lengths[idx])
                        new_map[new_abbr].append(idx)
            abbr_map = new_map
            if resolved:
                break
        
        # Build final abbreviations
        result = []
        for i, word in enumerate(words):
            abbr = abbreviate(word, prefix_lengths[i])
            result.append(abbr)
        return result
```**实施演练：**

 我们首先将每个单词的前缀长度初始化为 1。`abbreviate`函数根据给定的前缀长度生成缩写。 然后，我们将缩写映射到其相应的单词索引。 在冲突解决循环中，我们检测多个单词使用的任何缩写并增加它们的前缀长度，直到所有缩写都是唯一的。 最后，我们计算并返回最终的缩写。 

## 解决方案```go
package main

func wordsAbbreviation(words []string) []string {
    n := len(words)
    prefixLens := make([]int, n)
    for i := 0; i < n; i++ {
        prefixLens[i] = 1
    }
    
    abbreviate := func(word string, prefixLen int) string {
        if prefixLen >= len(word)-2 {
            return word
        }
        return word[:prefixLen] + string(rune(len(word)-prefixLen-1+'0')) + word[len(word)-1:]
    }
    
    abbrMap := map[string][]int{}
    for i, word := range words {
        abbr := abbreviate(word, 1)
        abbrMap[abbr] = append(abbrMap[abbr], i)
    }
    
    for {
        newMap := map[string][]int{}
        resolved := true
        for abbr, indices := range abbrMap {
            if len(indices) == 1 {
                newMap[abbr] = append(newMap[abbr], indices[0])
            } else {
                resolved = false
                for _, idx := range indices {
                    prefixLens[idx]++
                    newAbbr := abbreviate(words[idx], prefixLens[idx])
                    newMap[newAbbr] = append(newMap[newAbbr], idx)
                }
            }
        }
        abbrMap = newMap
        if resolved {
            break
        }
    }
    
    result := make([]string, n)
    for i, word := range words {
        result[i] = abbreviate(word, prefixLens[i])
    }
    return result
}

 主要区别包括使用切片和映射、处理字符串切片以及将整数计数转换为字符串。 逻辑镜像 Python，但使用 Go 语法和数据结构。 如果缩写不会缩短单词，则可以通过返回原始单词来处理诸如非常短的单词之类的边缘情况。
