 # LeetCode 572 - 另一棵树的子树

 ## 问题理解

 该问题要求我们确定一棵二叉树是否作为另一棵二叉树内的精确子树出现。 

给定两个二叉树：

 -`root`, 主树
 -`subRoot`，候选子树

 我们必须回来`true`如果里面存在某个节点`root`这样以该节点为根的整个树在结构上与`subRoot`。 结构同一性意味着：

 - 每个对应的节点都有相同的值
 - 左子树完全匹配
 - 正确的子树完全匹配
 - 失踪儿童也必须匹配

 子树不仅仅是值的部分匹配。 整个造型和每一个后代都必须完美匹配。 

例如：```
root:
        3
       / \
      4   5
     / \
    1   2

subRoot:
      4
     / \
    1   2
```以节点为根的子树`4`里面`root`比赛`subRoot`，所以答案是`true`。 

限制相对较小：

 -`root`最多有 2000 个节点
 -`subRoot`最多有 1000 个节点

 这些限制允许递归深度优先搜索解决方案，而不需要高级优化技术。 

有几个重要的边缘情况需要考虑：

 - 子树可能出现在主树的深处
 - 树可能包含重复值，因此仅匹配根值是不够的
 - 部分结构匹配仍必须返回`false`- 节点值匹配并不能保证子树相等
 - 一个额外的或缺失的子节点会使子树匹配无效

 该问题保证两棵树都至少包含一个节点。 

## 方法

 ### 蛮力方法

 暴力解决方案检查每个节点`root`作为子树的可能起点。 

对于每个节点`root`：

 1. 比较以该节点为根的子树`subRoot`2. 如果相同，则返回`true`3. 否则继续搜索

 为了比较两棵树，我们递归地验证：

 - 当前节点值匹配
 - 左子树匹配
 - 右子树匹配

 这种方法是正确的，因为每个可能的子树根都会被检查。 

然而，它可能效率低下，因为对于每个节点`root`，我们可以执行完整的子树比较`subRoot`。 

如果：

-`N`= 中的节点数`root`-`M`= 中的节点数`subRoot`那么在最坏的情况下我们可能会执行`M`为每个人工作`N`节点。 

这给出了最坏情况的时间复杂度`O(N × M)`。 

### 最佳 DFS 匹配方法

 标准最优解决方案仍然使用 DFS，但仔细构建递归以最大程度地减少不必要的工作并保持实现的优雅。 

关键的见解是子树匹配自然地分解为两个递归操作：

 1. 搜索`root`潜在的起始位置
 2. 检查两棵树是否相同

 该算法之所以有效，是因为子树相等本身是递归定义的。 

在每个节点`root`：

 - 如果当前树完全匹配，则返回`true`- 否则递归搜索左子树
 - 然后递归搜索右子树

 这种深度优先遍历确保每个可能的子树位置都被检查一次。 

尽管理论上最坏的情况仍然存在`O(N × M)`，该解决方案对于给定的约束足够有效，并且是标准接受的方法。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N × M) | O(H) | 比较`subRoot`手动针对每个节点|
 | 最优 DFS | O(N × M) | O(H) | 具有更清晰的 DFS 结构的递归子树匹配 |

 这里：

-`N`是节点数`root`-`M`是节点数`subRoot`-`H`是树的递归深度

 ## 算法演练

 ### 第 1 步：创建一个辅助函数来比较两棵树

 我们定义一个函数`isSameTree(node1, node2)`。 

该函数判断两棵树是否完全相同。 

规则是：

 1. 如果两个节点都是`None`，树木在这个分支上匹配
 2. 如果只有一个节点`None`，树不同
 3.如果节点值不同，则树不同
 4. 否则递归比较：

 - 留守儿童
 - 右边的孩子

 这个辅助函数为我们提供了精确的子树相等性检查。 

### 步骤2：遍历主树

 我们递归地遍历每个节点`root`。 

每个节点都被视为可能的子树根。 

### 步骤 3：尝试子树匹配

 在每个节点：

 1. 打电话`isSameTree(currentNode, subRoot)`2.如果返回`true`，我们找到了匹配的子树
 3.立即返回`true`### 步骤 4：继续 DFS 搜索

 如果当前节点不匹配：

 1. 搜索左子树
 2. 搜索右子树

 如果任何一方返回`true`，将结果向上传播。 

### 步骤 5：如果不存在匹配则返回 false

 如果 DFS 完成后没有找到匹配的子树，则返回`false`。 

### 为什么它有效

 该算法之所以有效，是因为其中的每个节点`root`被视为潜在的子树根。 对于每个候选节点，`isSameTree`通过递归比较保证结构和值相等。 由于每个可能的子树位置都被检查一次，因此该算法不会错过有效的子树。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def isSubtree(
        self,
        root: Optional[TreeNode],
        subRoot: Optional[TreeNode]
    ) -> bool:

        def isSameTree(
            node1: Optional[TreeNode],
            node2: Optional[TreeNode]
        ) -> bool:

            if not node1 and not node2:
                return True

            if not node1 or not node2:
                return False

            if node1.val != node2.val:
                return False

            return (
                isSameTree(node1.left, node2.left)
                and
                isSameTree(node1.right, node2.right)
            )

        if not root:
            return False

        if isSameTree(root, subRoot):
            return True

        return (
            self.isSubtree(root.left, subRoot)
            or
            self.isSubtree(root.right, subRoot)
        )
```实现分为两个递归职责。 

辅助函数`isSameTree`执行精确的树相等性检查。 它首先处理涉及的基本情况`None`节点。 如果两个节点都丢失，则该分支匹配成功。 如果仅存在一个节点，则结构会有所不同。 然后该函数比较节点值并递归检查两个子树。 

主要`isSubtree`函数在主树上执行DFS遍历。 在每个节点，它首先尝试使用完整的子树比较`isSameTree`。 如果找到匹配，则立即返回`True`。 

如果当前节点不匹配，则递归继续到左子节点和右子节点。 这保证了检查每个可能的子树位置。 

递归结构使实现保持简洁，并直接与子树相等的数学定义保持一致。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func isSubtree(root *TreeNode, subRoot *TreeNode) bool {

    var isSameTree func(node1 *TreeNode, node2 *TreeNode) bool

    isSameTree = func(node1 *TreeNode, node2 *TreeNode) bool {

        if node1 == nil && node2 == nil {
            return true
        }

        if node1 == nil || node2 == nil {
            return false
        }

        if node1.Val != node2.Val {
            return false
        }

        return isSameTree(node1.Left, node2.Left) &&
            isSameTree(node1.Right, node2.Right)
    }

    if root == nil {
        return false
    }

    if isSameTree(root, subRoot) {
        return true
    }

    return isSubtree(root.Left, subRoot) ||
        isSubtree(root.Right, subRoot)
}
```Go 实现遵循与 Python 解决方案相同的递归结构。 

主要区别在于处理方式`nil`显式地代替 Python 的指针`None`。 Go 还要求在赋值之前使用变量声明来定义递归辅助函数，以便闭包可以递归地引用自身。 

不存在整数溢出问题，因为节点值保持在较小的约束范围内。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N × M) | 中的每个节点`root`可以与所有节点进行比较`subRoot`|
 | 空间| O(H) | 递归调用堆栈深度取决于树高 |

 这里：

-`N`是节点数`root`-`M`是节点数`subRoot`-`H`是最大树高

 在最坏的情况下，每个节点`root`触发完整子树比较。 每次比较可能会访问中的所有节点`subRoot`，生产`O(N × M)`时间复杂度。 

递归空间复杂度取决于树的高度，因为递归 DFS 调用存储在调用堆栈上。 在倾斜的树中，高度可能达到`O(N)`。

    def __init__(self, val=0, left=None, right=None):
        self.val = val

    if not values:
        return None

    nodes = [
        TreeNode(v) if v is not None else None
        for v in values
    ]

    root = kids.pop()

    for node in nodes:
        if node:
            if kids:
                node.left = kids.pop()
            if kids:
                node.right = kids.pop()

    return root

 ## 边缘情况

 ### 多个位置重复值

 一个常见的错误是假设匹配节点值意味着子树相等。 考虑一棵包含许多具有相同值的节点的树。 该算法仍然必须验证完全的结构相等性。 辅助函数`isSameTree`递归地比较结构和值，防止误报。 

### 主树中的额外后代

 子树候选最初可能看起来匹配，但在树的更深处包含额外的后代。 这正是示例 2 中发生的情况。算法正确地检测到了这一点，因为`None`孩子在`subRoot`与真实节点不匹配`root`。 

### 高度不平衡的树

 倾斜的树可以创建深度递归链。 幼稚的迭代实现可能会错误地处理遍历顺序或子树边界。 递归 DFS 自然地正确处理左偏和右偏树，因为每个递归调用独立地验证子树结构。 

### 整棵树相等

 该问题指出，一棵树被视为其自身的子树。 某些实现错误地仅搜索子节点，而忘记直接比较当前根。 该解决方案首先检查`isSameTree(root, subRoot)`在递归到子级之前，确保返回相同的完整树`true`。
