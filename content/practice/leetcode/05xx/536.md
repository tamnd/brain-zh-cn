 **难度：** 🟡 中等
 **主题：** 字符串、堆栈、树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们从特殊格式的字符串表示形式重建二叉树。 

输入字符串包含整数值和括号。 每个整数代表一个树节点，括号代表子树。 该结构遵循递归模式：

 - 首先出现一个节点值。 
- 如果节点有子节点，则将它们括在括号中。 
- 第一个带括号的子树始终是左子树。 
- 第二个带括号的子树（如果存在）是右子树。 

例如：```
"4(2(3)(1))(6(5))"
```代表这棵树：```
        4
      /   \
     2     6
    / \   /
   3   1 5
```输出应该是构造的二叉树的根节点。 

这些约束告诉我们一些重要的事情：

 - 字符串长度可以大到`3 * 10^4`，因此低效的重复解析或子字符串创建可能会变得昂贵。 
- 该字符串仅包含：

 - 数字
 -`-`-`(`-`)`- 允许负值。 
- 输入保证有效。 

空字符串代表一棵空树，所以我们应该返回`None`在 Python 中或`nil`在围棋中。 

有几种边缘情况很容易导致错误：

 - 空输入字符串。 
- 负数，例如`"-4"`。 
- 只有左子节点的节点。 
- 深度嵌套的树。 
- 多位数字值，例如`"123"`。 
- 在遍历嵌套括号时正确地将子级与父级关联起来。 

简单的解析器很容易失去对当前活动节点的跟踪，尤其是当递归子树边界重叠时。 

## 方法

 ### 蛮力方法

 强力解决方案递归地搜索匹配的括号并重复对子字符串进行切片以构造左子树和右子树。 

总体思路是：

 1.解析当前节点值。 
2. 通过定位匹配的括号来找到左子树对应的子串。 
3. 递归解析该子字符串。 
4. 对右子树重复此操作。 

这种方法之所以有效，是因为树结构是在括号中显式编码的。 如果我们正确识别子树边界，递归自然会重建原始树。 

然而，重复的子串操作是昂贵的。 每次递归调用都可能创建新的子字符串，并且匹配括号一次又一次地重复扫描字符串的各个部分。 

在最坏的情况下，例如高度倾斜的树：```
1(2(3(4(5))))
```重复扫描导致二次复杂度。 

### 最佳方法

 关键的见解是该字符串已经代表了带有结构标记的前序遍历。 

我们可以在一次从左到右的传递中解析字符串，同时保持当前的解析位置。 

我们不是重复创建子字符串，而是：

 - 读取一个节点值。 
- 如果下一个字符是，则递归构建其左子树`(`。 
- 如果有另一个子树，则递归构建其右子树`(`出现。 
- 子树完成后返回。 

这避免了冗余扫描，并且对每个字符只处理一次。 

递归解析器自然地反映了树本身的递归结构。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复子字符串创建和重新扫描 |
 | 最佳 | O(n) | O(n) | 单遍递归解析 |

 ## 算法演练

 ### 最优递归解析算法

 1. 从指向字符串开头的全局索引开始。 

该索引跟踪我们当前的解析位置。 由于递归按顺序处理子树，因此共享索引允许所有递归调用正确协调。 
2. 解析当前节点值。 

节点值可以：

 - 消极
 - 包含多个数字

 首先检查当前字符是否为`'-'`。 然后继续读取数字，直到出现非数字字符。 
3. 创建一个新的树节点。 

解析整数值后，创建一个`TreeNode`为其对象。 
4. 检查左子树是否存在。 

如果当前字符是`'('`，那么字符串的下一部分代表左孩子。 

跳过左括号并递归构建子树。 
5. 递归调用结束后，跳过结束部分`')'`。 

递归调用消耗整个子树内容，因此当前索引现在应该指向匹配的右括号。 
6. 检查右子树是否存在。 

如果另一个`'('`之后立即出现，使用相同的逻辑递归解析右子树。 
7. 返回完成的节点。 

当两个可选子树解析完成时，以当前节点为根的整个子树已被重建。 

### 为什么它有效

 该算法之所以有效，是因为字符串格式的递归定义方式与树结构本身完全相同。 

每个递归调用只负责解析一个子树。 共享索引始终指向下一个未处理的字符。 由于每个节点都消耗自己的值并按前序递归地消耗其子节点，因此解析器永远不会失去与字符串结构的同步。 

每个左括号对应于进入一个子树，每个右括号对应于从该子树返回。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def str2tree(self, s: str) -> Optional[TreeNode]:
        if not s:
            return None

        index = 0

        def build_tree() -> Optional[TreeNode]:
            nonlocal index

            # Parse sign
            sign = 1
            if s[index] == '-':
                sign = -1
                index += 1

            # Parse number
            value = 0
            while index < len(s) and s[index].isdigit():
                value = value * 10 + int(s[index])
                index += 1

            node = TreeNode(sign * value)

            # Parse left child
            if index < len(s) and s[index] == '(':
                index += 1  # skip '('
                node.left = build_tree()
                index += 1  # skip ')'

            # Parse right child
            if index < len(s) and s[index] == '(':
                index += 1  # skip '('
                node.right = build_tree()
                index += 1  # skip ')'

            return node

        return build_tree()
```其实现紧密遵循递归解析算法。 

这`index`变量在所有递归调用之间共享`nonlocal`。 这避免了传递子字符串并允许解析器一次性处理字符串。 

解析器首先处理可选的负号。 之后，它使用标准整数构造逻辑将数字累积到节点值中。 

创建节点后，代码将检查下一个字符是否是`'('`。 如果是，则存在子树。 解析器跳过左括号，递归构造子树，然后跳过匹配的右括号。 

对右孩子重复相同的逻辑。 

由于递归按前序遍历顺序消耗字符串，因此无需额外的数据结构即可正确重建树。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func str2tree(s string) *TreeNode {
    if len(s) == 0 {
        return nil
    }

    index := 0

    var buildTree func() *TreeNode

    buildTree = func() *TreeNode {
        sign := 1

        // Parse sign
        if s[index] == '-' {
            sign = -1
            index++
        }

        // Parse number
        value := 0
        for index < len(s) && s[index] >= '0' && s[index] <= '9' {
            value = value*10 + int(s[index]-'0')
            index++
        }

        node := &TreeNode{
            Val: sign * value,
        }

        // Parse left child
        if index < len(s) && s[index] == '(' {
            index++ // skip '('
            node.Left = buildTree()
            index++ // skip ')'
        }

        // Parse right child
        if index < len(s) && s[index] == '(' {
            index++ // skip '('
            node.Right = buildTree()
            index++ // skip ')'
        }

        return node
    }

    return buildTree()
}
```Go 实现遵循与 Python 版本相同的解析策略。 

一个显着的区别是 Go 不支持嵌套函数`nonlocal`变量的处理方式与 Python 相同。 相反，递归闭包捕获了`index`来自周围范围的变量。 

Go 还使用显式字符比较：```go
s[index] >= '0' && s[index] <= '9'
```而不是Python的`.isdigit()`帮手。 

树节点使用以下指针进行分配：```go
&TreeNode{}
```和空树用表示`nil`。

 ## 边缘情况

 ### 空字符串

 空字符串代表一棵空树。 这很容易处理不当，因为递归解析假设至少存在一个字符。 

实现立即处理这个问题：```
if not s:
    return None
```这可以防止在解析开始之前进行无效的索引访问。 

### 负数

 该字符串可能以以下内容开头`'-'`，并且子节点也可能包含负值。 

仅假设数字的解析器将错误地构造值或在遇到`'-'`。 

该实现在解析数字之前显式检查负号：```
if s[index] == '-':
    sign = -1
```最终值变为：```
sign * value
```它可以正确处理正整数和负整数。 

### 深度嵌套树

 高度倾斜的树，例如：```
"1(2(3(4(5))))"
```创建深度递归。 

基于子字符串的简单方法变得非常低效，因为它们重复扫描字符串的重叠部分。 

最佳解决方案通过使用单个共享索引并处理每个字符一次来避免这种情况。 即使在深度嵌套的树中，总工作仍然是线性的。 

### 多位数字值

 价值观如`"123"`或者`"6789"`需要读取多个连续的数字。 

有缺陷的实现可能会意外地将每个数字视为单独的节点。 

该解决方案使用以下方法正确累积数字：```
value = value * 10 + int(s[index])
```它在创建节点之前重建整个整数。
