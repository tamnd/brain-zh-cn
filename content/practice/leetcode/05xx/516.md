[LeetCode 第 516 题](https://leetcode.com/problems/longest-palindromic-subsequence/)

 **难度：** 🟡 中等
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定字符串中**最长回文子序列**的长度`s`。 回文子序列是向前和向后读取相同的字符序列，可以通过从原始字符串中删除零个或多个字符而不改变剩余字符的顺序来获得。 

例如，在字符串中`"bbbab"`，最长的回文子序列是`"bbbb"`，其长度为 4。同样，在`"cbbd"`，最长的回文子序列是`"bb"`长度为2。 

输入是一个字符串`s`仅包含小写英文字母，长度在 1 到 1000 之间。这个约束很重要，因为它表明由于指数时间复杂度，生成所有子序列的暴力方法在计算上是不可行的。 

关键边缘情况包括已经是回文的字符串、所有字符都不同的字符串或长度为 1 的字符串。该问题保证输入始终有效，因此没有空字符串或无效字符需要处理。 

## 方法

 **暴力方法**将涉及生成所有可能的子序列`s`并检查每个是否是回文。 然后将返回找到的最长回文。 这种方法是正确的，因为它详尽地考虑了所有可能性，但效率极低。 生成所有子序列的时间复杂度为 O(2^n)，对于 n 高达 1000 的情况来说这是不切实际的。 

**最佳方法**利用**动态编程**。 关键的见解是该问题具有**重叠的子问题和最优子结构**。 如果我们定义`dp[i][j]`作为子串中最长回文子序列的长度`s[i:j+1]`，我们可以用较小的子串构建较大的子串的解决方案。 具体来说，如果`s[i] == s[j]`，端点贡献回文长度，我们将 2 添加到子序列的长度`s[i+1:j]`。 否则，结果是排除任一端所获得的子序列之间的最大值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成所有子序列并检查回文 |
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 使用二维表存储中间结果的动态规划 |

 ## 算法演练

 1. 初始化一个2D数组`dp`大小为 n x n，其中`n`的长度是`s`。 每个条目`dp[i][j]`将存储子字符串中最长回文子序列的长度`s[i:j+1]`。 
2. 设置所有对角线条目`dp[i][i]`为 1，因为单个字符是长度为 1 的回文。 
3. 迭代从 2 到 n 的所有可能的子字符串长度。 对于每个长度，迭代起始索引`i`并计算结束索引`j = i + length - 1`。 
4. 如果`s[i] == s[j]`， 放`dp[i][j] = dp[i+1][j-1] + 2`因为两个匹配字符扩展了内部回文。 
5. 如果`s[i] != s[j]`， 放`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`因为必须排除端点之一。 
6. 返回`dp[0][n-1]`，它表示整个字符串的最长回文子序列的长度。 

**为什么有效：** 该算法保持了以下不变式：`dp[i][j]`始终表示子串的最长回文子序列的长度`s[i:j+1]`。 通过将表从较短的子字符串填充到较长的子字符串，每次计算仅依赖于已经计算的值，从而确保正确性。 

## Python 解决方案```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        
        for i in range(n):
            dp[i][i] = 1
        
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i+1][j-1] + 2
                else:
                    dp[i][j] = max(dp[i+1][j], dp[i][j-1])
        
        return dp[0][n-1]
```该代码首先初始化一个用于动态规划的二维表。 单字符子字符串设置为长度 1。对于所有其他子字符串，它检查端点是否匹配。 如果这样做，它将内部回文扩展 2； 否则，它通过排除任一端点来选择最大子序列长度。 最后，它返回整个字符串的值。 

## 解决方案```go
func longestPalindromeSubseq(s string) int {
    n := len(s)
    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][i] = 1
    }
    
    for length := 2; length <= n; length++ {
        for i := 0; i <= n - length; i++ {
            j := i + length - 1
            if s[i] == s[j] {
                if length == 2 {
                    dp[i][j] = 2
                } else {
                    dp[i][j] = dp[i+1][j-1] + 2
                }
            } else {
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])
            }
        }
    }
    
    return dp[0][n-1]
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```在 Go 中，切片用于创建 2D 动态规划表。 对长度为 2 的子字符串添加特殊处理以防止索引错误。 该算法的其余部分反映了 Python 解决方案，迭代计算最长的回文子序列。

 ## 边缘情况

 **单字符字符串：** 该函数正确返回 1，因为单个字符始终是回文。 

**所有不同的字符：** 当没有两个字符相同时，最长的回文子序列为 1。DP 解决方案通过取之间的最大值来自然地处理这个问题`dp[i+1][j]`和`dp[i][j-1]`。 

**中间有重复回文的字符串：**像这样的字符串`"abacdfgdcaba"`要求算法考虑多个重叠的回文子序列。 DP 方法正确地累积内部回文的长度，确保计算出全局最大值。
