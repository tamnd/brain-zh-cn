 **难度：** 🔴难
 **主题：** 数组、数学、几何

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到 2D 平面上一组点的 **凸包**。 输入`trees`是一个坐标列表，其中每个坐标`[xi, yi]`代表花园中一棵树的位置。 我们的目标是使用最小周长用栅栏围住所有树木，这意味着我们要识别**恰好位于凸包边界**上的所有树木。 输出应该是表示该边界上的树木的坐标列表。 

该问题保证坐标是唯一的并且范围从`0`到`100`，树的总数最多可达 3000 棵。这个大小足够大，以至于朴素的暴力方法效率低下，因此我们需要一种可扩展性更好的算法。 关键边缘情况包括形成直线的树（所有树都在边界上）、某些点严格位于凸包内部的簇以及凸包同一边缘上的多个点。 

需要理解的重要一点是，船体内部的任何树都不会成为输出的一部分，并且与船体边缘共线的点应包含在栅栏上。 

## 方法

 **强力方法**会考虑每一对点，并确定所有其他点是否位于该对所形成的线的同一侧。 如果是，则线段的两个端点都是船体的一部分。 虽然这种方法是正确的，但它非常慢，因为它需要检查所有对和所有点，从而导致 O(n3) 复杂度。 对于 n 高达 3000 的情况，这将慢得令人无法接受。 

更好的解决方案的**关键见解**是，这是一个经典的**计算几何问题**，特别是计算点集的凸包。 我们可以使用 **Jarvis March（礼品包装）** 算法，经过修改以包括沿边缘的共线点。 这是有效的，因为我们可以按照极角增加的顺序“环绕”这组点，并且与当前船体边缘共线的任何点都保证位于边界上。 这将复杂度降低到 O(nh)，其中 h 是船体点的数量，并且对于 n ≤ 3000 是实用的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 检查每对点，看看它们是否形成船体边缘 |
 | 最佳 | O(nh) | O(n) | Jarvis March 与凸包共线点包含 |

 ## 算法演练

 1. **找到最左边的点**：从具有最小 x 坐标的点开始（打破与最小 y 坐标的关系）。 这保证在船体上。 
2. **初始化凸包集合**：创建一个集合来存储凸包上的所有点。 
3. **迭代点**：对于当前的船体点，找到下一个点，使得所有其他点都位于所形成的线的同一侧。 这是通过使用叉积来确定方向来完成的。 
4. **处理共线点**：如果其他点与当前线段共线，则将它们包含在船体集中。 这确保了不会遗漏沿边缘的点。 
5. **移动到下一个点**：继续环绕点集，直到返回起点。 这样就完成了凸包。 
6. **返回船体点**：将船体点集合转换为列表并返回。 

**为什么起作用**：Jarvis March 保证每个选定的点形成凸包的边缘，因为叉积确保所有其他点位于右侧或共线。 包含共线点可确保输出满足将树木精确包含在栅栏上的问题要求。 

## Python 解决方案```python
from typing import List

class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[List[int]]:
        if len(trees) <= 3:
            return trees
        
        # Cross product of OA x OB
        def cross(o, a, b):
            return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
        
        # Find the leftmost point
        start = min(trees, key=lambda x: (x[0], x[1]))
        hull = set()
        point_on_hull = start
        
        while True:
            hull.add(tuple(point_on_hull))
            next_point = trees[0]
            for candidate in trees:
                if candidate == point_on_hull:
                    continue
                orientation = cross(point_on_hull, next_point, candidate)
                if orientation < 0 or (orientation == 0 and 
                    (candidate[0]-point_on_hull[0])**2 + (candidate[1]-point_on_hull[1])**2 >
                    (next_point[0]-point_on_hull[0])**2 + (next_point[1]-point_on_hull[1])**2):
                    next_point = candidate
            point_on_hull = next_point
            if tuple(point_on_hull) == tuple(start):
                break
        
        return [list(p) for p in hull]
```此 Python 解决方案首先找到最左边的点，然后使用叉积迭代地将点添加到船体中。 当叉积为零时，它通过比较距离来确保包括沿边缘的共线点。 最后，它将所有船体点作为列表返回。 

## 解决方案```go
package main

func outerTrees(trees [][]int) [][]int {
    if len(trees) <= 3 {
        return trees
    }

    cross := func(o, a, b []int) int {
        return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
    }

    start := trees[0]
    for _, t := range trees {
        if t[0] < start[0] || (t[0] == start[0] && t[1] < start[1]) {
            start = t
        }
    }

    hullMap := make(map[[2]int]bool)
    pointOnHull := start

    for {
        hullMap[[2]int{pointOnHull[0], pointOnHull[1]}] = true
        nextPoint := trees[0]
        for _, candidate := range trees {
            if candidate[0] == pointOnHull[0] && candidate[1] == pointOnHull[1] {
                continue
            }
            orientation := cross(pointOnHull, nextPoint, candidate)
            if orientation < 0 || (orientation == 0 &&
                (candidate[0]-pointOnHull[0])*(candidate[0]-pointOnHull[0])+(candidate[1]-pointOnHull[1])*(candidate[1]-pointOnHull[1]) >
                (nextPoint[0]-pointOnHull[0])*(nextPoint[0]-pointOnHull[0])+(nextPoint[1]-pointOnHull[1])*(nextPoint[1]-pointOnHull[1])) {
                nextPoint = candidate
            }
        }
        pointOnHull = nextPoint
        if pointOnHull[0] == start[0] && pointOnHull[1] == start[1] {
            break
        }
    }

    result := make([][]int, 0, len(hullMap))
    for k := range hullMap {
        result = append(result, []int{k[0], k[1]})
    }
    return result
}
```Go 实现反映了 Python 逻辑，但使用地图来存储船体上的点。 它小心地处理切片和整数算术，避免 nil 与空的陷阱。 

## 工作示例

 **示例1**：`trees = [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]`从最左边开始`[1,1]`。 

使用叉积逐步遍历点：

 -`[1,1] -> [2,0]`边缘确认。 
- 共线检查确保`[2,0]`包括。 
- 继续包裹：`[2,4]`,`[3,3]`,`[4,2]`额外。 

最终船体设置：`{[1,1],[2,0],[4,2],[3,3],[2,4]}`**示例2**：`trees = [[1,2],[2,2],[4,2]]`所有点都是共线的。 开始`[1,2]`。
