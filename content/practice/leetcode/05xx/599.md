[LeetCode 第 599 题](https://leetcode.com/problems/minimum-index-sum-of-two-lists/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到两个字符串列表之间的公共元素，但不仅仅是任何公共元素。 我们想要两个列表中索引之和最小的那些。 换句话说，如果一个字符串出现在索引处`i`在`list1`和索引`j`在`list2`，我们计算`i + j`。 在所有常见字符串中，我们需要最小的字符串`i + j`和。 

输入由两个字符串数组组成，`list1`和`list2`，其中每个字符串在其自己的列表中都是唯一的。 输出应该是一个字符串列表，其中包含具有最小索引和的所有公共字符串。 约束相对较小（`1 <= length <= 1000`），因此我们可以使用哈希来寻求有效的解决方案。 

重要的边缘情况包括：具有相同最小索引和的多个公共字符串的列表、所有字符串都是公共的列表、或者公共字符串出现在两个列表的最后一个索引处的列表。 该问题保证至少有一个公共字符串，因此我们不需要处理空输出。 

## 方法

 ### 蛮力

 天真的暴力方法是比较每个元素`list1`中的每个元素`list2`，如果匹配则计算它们的索引总和，并跟踪最小的总和。 虽然正确，但这种方法需要`O(n * m)`比较，其中`n`和`m`的长度是`list1`和`list2`。 鉴于限制，这可能会进行多达 1,000,000 次比较，这是低效的。 

### 最佳方法

 更好的解决方案的关键是使用哈希映射来存储一个列表的索引。 通过存储`list1`在一个以字符串为键、索引为值的映射中，我们可以迭代`list2`，检查当前字符串是否存在于map中，并计算索引和。 我们维护一个变量来跟踪最小总和，并维护一个列表来收集满足该总和的所有字符串。 这将时间复杂度降低到 O(n + m) 并使解决方案变得高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(1) | O(1) | 比较两个列表之间的所有字符串对 |
 | 最佳| O(n + m) | O(n) | 使用哈希图进行快速查找并跟踪最小索引和 |

 ## 算法演练

 1. 创建一个空的哈希映射来存储字符串的索引`list1`。 
2. 迭代`list1`带索引`i`并将每个字符串及其索引存储在哈希映射中。 
3. 初始化`min_sum`到无穷大和一个空列表`result`存储索引和最小的公共字符串。 
4. Iterate over`list2`带索引`j`。 
5. 对于中的每个字符串`list2`，检查哈希映射中是否存在。 
6.如果存在，计算索引和`i + j`。 
7. 如果索引总和小于`min_sum`， 更新`min_sum`并重置`result`用这个字符串。 
8. 如果索引总和等于`min_sum`，将此字符串附加到`result`。 
9.处理完所有字符串后，返回`result`。 

**为什么有效**：哈希映射允许恒定时间查找字符串`list1`。 通过跟踪最小索引和并相应地更新结果列表，我们保证只返回具有最小索引和的字符串。 该算法自然地处理具有相同最小和的多个字符串。 

## Python 解决方案```python
from typing import List

class Solution:
    def findRestaurant(self, list1: List[str], list2: List[str]) -> List[str]:
        index_map = {restaurant: i for i, restaurant in enumerate(list1)}
        min_sum = float('inf')
        result = []

        for j, restaurant in enumerate(list2):
            if restaurant in index_map:
                total_index = index_map[restaurant] + j
                if total_index < min_sum:
                    min_sum = total_index
                    result = [restaurant]
                elif total_index == min_sum:
                    result.append(restaurant)
        
        return result
```此 Python 实现使用字典理解将字符串映射到索引。 然后我们迭代`list2`，计算公共字符串的索引和，并更新`result`仅当我们找到较小或相等的索引和时才列出。 

## 解决方案```go
func findRestaurant(list1 []string, list2 []string) []string {
    indexMap := make(map[string]int)
    for i, restaurant := range list1 {
        indexMap[restaurant] = i
    }

    result := []string{}
    minSum := 1<<31 - 1 // max int value

    for j, restaurant := range list2 {
        if i, exists := indexMap[restaurant]; exists {
            total := i + j
            if total < minSum {
                minSum = total
                result = []string{restaurant}
            } else if total == minSum {
                result = append(result, restaurant)
            }
        }
    }
    return result
}
```在 Go 中，我们使用映射进行索引查找和整数`minSum`初始化为最大可能的整数。 我们根据当前索引总和追加或重置结果切片，类似于 Python 实现。 Go 需要仔细处理切片和整数初始化，这与 Python 的灵活性不同`float('inf')`。
