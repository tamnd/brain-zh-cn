[LeetCode 第 524 题](https://leetcode.com/problems/longest-word-in-dictionary-through-deleting/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、字符串、排序

 ## 解决方案

 ## 问题理解

 问题给了我们一个源字符串`s`和一个候选词列表`dictionary`。 我们必须确定哪个字典单词可以通过删除其中的字符而形成`s`而不改变其余字符的相对顺序。 

这意味着我们正在寻找子序列关系。 如果我们能扫过的话，一个词就是有效的`s`从左到右并按顺序匹配单词的所有字符。 字符不需要是连续的，但它们的顺序必须保持相同。 

例如，如果`s = "abpcplea"`候选词是`"apple"`，我们可以通过选择字符来形成它：

 -`a`-`p`-`p`-`l`-`e`从原始字符串中删除，同时跳过不相关的字符。 

这个问题不只是要求任何有效的词。 它根据两个规则询问最好的单词：

 1. 优先选择最长的有效单词。 
2. 如果多个有效单词的长度相同，则选择字典顺序最小的一个。 

词典顺序是标准词典顺序。 例如，`"apple"`小于`"apply"`因为第一个不同的字符是`'e'`，出现在之前`'y'`。 

限制相对较小：

 -`s.length <= 1000`-`dictionary.length <= 1000`- 每个词典单词长度<= 1000`

 这些限制强烈表明单独检查每个词典单词是可行的。 一个解决方案大致为`O(dictionary_size × string_length)`复杂性是可以接受的。 

一些边缘情况很重要：

 - 无法形成字典单词，在这种情况下我们返回`""`。 
- 多个有效单词的最大长度相同，需要进行字典序比较。 
- 非常短的字符串，包括单字符输入。 
- 字典单词长于`s`，它永远不可能是有效的子序列。 
- 重复或高度相似的单词可能会暴露打破平局的错误。 

## 方法

 ### 蛮力方法

 蛮力的想法是生成每个可能的子序列`s`并检查每个子序列是否存在于字典中。 

一个长度的字符串`n`有`2^n`可能的子序列，因为每个字符都可以包含或排除。 生成所有子序列后，我们可以将它们与字典进行比较，并根据问题规则选择最佳有效答案。 

这种方法是正确的，因为它详尽地探索了所有可能的删除`s`。 任何有效的字典单词必须出现在生成的子序列中。 

然而，即使对于中等大小的输入，这种方法也变得完全不切实际。 自从`s.length`最多可达 1000，生成`2^1000`子序列是不可能的。 

### 最佳方法

 关键的观察是我们不需要生成`s`。 相反，我们可以反转该过程并测试每个字典单词是否是`s`。 

为了检查一个单词是否是子序列，我们使用两个指针技术：

 - 一键扫描`s`- 一键扫描候选词

 每当字符匹配时，我们都会将两个指针前移。 否则，我们只将指针推进`s`。 

如果我们成功地消耗了候选单词中的所有字符，那么它就是一个有效的子序列。 

在检查每个词典单词时，我们保留当前的最佳答案。 我们会在以下时间更新：

 - 新单词更长，或者
 - 长度相等并且新单词按字典顺序更小

 该解决方案非常高效，因为每个子序列检查都以相对于所涉及字符串的长度的线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 生成的所有子序列`s`|
 | 最佳| O(d × (n + m)) | O(1) | O(1) | 使用两个指针检查每个字典单词 |

 这里：

-`n = len(s)`-`d = len(dictionary)`-`m = average dictionary word length`## 算法演练

 1. 初始化一个空字符串，名为`bestWord`。 

该变量存储迄今为止找到的最有效的字典单词。 
2. 遍历其中的每个单词`dictionary`。 

我们必须检查每个候选者，因为任何单词都可能是最长的有效子序列。 
3. 对于每个单词，检查它是否是以下序列的子序列`s`。 

使用两个指针：

 -`i`指向中的字符`s`-`j`指向候选词中的字符

 遍历`s`从左到右。 
4. 每当`s[i] == word[j]`，使两个指针都前进。 

这意味着我们成功匹配了候选词的又一个字符。 
5. 否则，只前进指针`s`。 

我们正在有效地从考虑中删除该角色。 
6. 扫描完成后，检查是否`j == len(word)`。 

如果为 true，则候选单词中的每个字符都按顺序匹配，因此该单词是有效的子序列。 
7. 将有效词与`bestWord`。 

更新`bestWord`如果：

 - 当前单词较长，或者
 - 长度相等并且当前单词按字典顺序较小
 8.处理完所有字典单词后，返回`bestWord`。 

### 为什么它有效

 该算法之所以有效，是因为两个指针子序列检查精确地模拟了允许的删除过程。 通过扫描`s`一次并按顺序匹配字符，我们验证是否可以在不重新排列字符的情况下形成字典单词。 

由于每个字典单词都是独立检查的，因此不会错过任何有效的候选单词。 更新规则保证存储的答案始终是最长的有效单词，并使用字典顺序作为决胜局。 

## Python 解决方案```python
from typing import List

class Solution:
    def findLongestWord(self, s: str, dictionary: List[str]) -> str:
        
        def is_subsequence(word: str, source: str) -> bool:
            word_index = 0
            source_index = 0

            while word_index < len(word) and source_index < len(source):
                if word[word_index] == source[source_index]:
                    word_index += 1

                source_index += 1

            return word_index == len(word)

        best_word = ""

        for word in dictionary:
            if is_subsequence(word, s):
                if len(word) > len(best_word):
                    best_word = word
                elif len(word) == len(best_word) and word < best_word:
                    best_word = word

        return best_word
```实现从一个名为的辅助函数开始`is_subsequence`。 该函数在候选词和源字符串之间执行两个指针扫描`s`。 

变量`word_index`跟踪字典单词的进度，同时`source_index`扫描通过`s`。 

每当字符匹配时，我们就会前进`word_index`，意味着候选人的又一个性格已经成功形成。 

在扫描结束时，如果`word_index`达到候选词的全长，然后按顺序匹配每个字符。 

主循环一次处理每个字典单词。 每当找到有效的子序列时，代码就会将其与当前的最佳答案进行比较。 

更新条件完全满足问题要求：

 - 喜欢较长的单词
 - 对关系使用字典顺序

 最终值`best_word`检查完所有候选人后返回。 

## 解决方案```go
func findLongestWord(s string, dictionary []string) string {

	isSubsequence := func(word string, source string) bool {
		wordIndex := 0
		sourceIndex := 0

		for wordIndex < len(word) && sourceIndex < len(source) {
			if word[wordIndex] == source[sourceIndex] {
				wordIndex++
			}

			sourceIndex++
		}

		return wordIndex == len(word)
	}

	bestWord := ""

	for _, word := range dictionary {
		if isSubsequence(word, s) {

			if len(word) > len(bestWord) {
				bestWord = word
			} else if len(word) == len(bestWord) && word < bestWord {
				bestWord = word
			}
		}
	}

	return bestWord
}
```Go 实现遵循与 Python 版本相同的逻辑。 本地辅助函数使用两个指针检查子序列的有效性。 

一个区别是 Go 字符串被索引为字节切片。 由于该问题仅保证小写英文字母，因此直接字节索引是完全安全的。 

空字符串`""`自然地处理不存在有效字典单词的情况。 

不需要额外的内存分配或复杂的数据结构，因此实现仍然高效且简单。

 ## 边缘情况

 ### 没有有效的词典单词

 一个常见的错误是忘记处理无法形成字典单词的情况`s`。 在这种情况下，正确的答案是空字符串。 

该实现自然地处理了这个问题，因为`best_word`开始为`""`并且仅在找到有效子序列时更新。 

### 多个相同长度的单词

 打破平局很容易被错误地实施。 假设两者`"ab"`和`"ba"`是长度相等的有效子序列。 该问题需要返回字典顺序较小的单词。 

实现明确检查：```
elif len(word) == len(best_word) and word < best_word:
```这保证了正确的字典排序行为。 

### 字典单词长于`s`比源字符串长的字典单词永远不可能是子序列。 某些实现会尝试不必要的处理或产生索引错误。 

两个指针逻辑可以安全地处理这个问题。 自从扫描结束`s`在候选词中的所有字符都匹配之前完成，函数正确返回`False`。 

### 重复字符

 具有重复字符的字符串可能会暴露微妙的指针错误。 例如：```
s = "aaaaa"
word = "aaaa"
```该实现仅在字符匹配时才推进候选指针，确保重复的字符一次以正确的顺序匹配一个。
