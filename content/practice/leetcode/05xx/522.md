[LeetCode 522 题](https://leetcode.com/problems/longest-uncommon-subsequence-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、两个指针、字符串、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们找到数组中最长字符串的长度，该字符串不是同一数组中任何其他字符串的子序列。 

子序列是通过从字符串中删除零个或多个字符而不改变剩余字符的顺序而形成的。 例如，`"abc"`是一个子序列`"axbyc"`因为我们可以删除多余的字符并保持顺序不变。 

关键细节是我们不是在搜索子字符串。 字符不需要是连续的。 只有相对顺序才重要。 

输入是一个字符串数组，`strs`。 我们必须确定每个字符串是否可以作为数组中另一个字符串内的子序列出现。 如果一个字符串在这个意义上是唯一的，这意味着它不是任何其他字符串的子序列，那么它被认为是不常见的子序列。 

预期输出是最长的此类字符串的长度。 如果每个字符串都是另一个字符串的子序列，那么我们返回`-1`。 

限制相对较小：

 - 字符串数量最多为`50`- 每个字符串的长度最多为`10`这些约束非常重要，因为它们允许我们在字符串之间使用成对比较，而无需担心性能问题。 即使具有立方行为的算法在这种规模下也是可以接受的。 

一些边缘情况很重要：

 - 重复的字符串立即取消其自身资格，因为每个副本都是另一个副本的子序列。 
- 一个非常短的字符串可能是许多较长字符串的子序列。 
- 字符串始终是其自身的子序列，因此在比较字符串时，我们必须小心避免将单个出现视为无效，除非存在另一个相同的字符串。 
- 如果所有字符串都是其他字符串的重复项或子序列，则答案变为`-1`。 

## 方法

 ### 蛮力方法

 蛮力的想法是生成每个字符串的每个可能的子序列，然后确定哪些子序列唯一出现。 

对于一个长度的字符串`n`， 有`2^n`可能的子序列。 由于字符串长度最多为`10`，一个字符串最多可以生成`1024`子序列。 我们可以将所有子序列存储在哈希映射中，并计算有多少个字符串包含它们。 

生成所有子序列后，我们将查找恰好出现在一个字符串中的最长子序列。 

这种方法是正确的，因为它显式地检查每个可能的子序列并直接检查唯一性。 

然而，它不必要地昂贵且复杂。 尽管约束足够小，在技术上允许，但生成所有子序列会产生额外的工作并增加实现复杂性。 

### 最佳方法

 重要的观察是答案本身必须是原始字符串之一。 

假设一些子序列`x`并不常见。 然后`x`来自一些原始字符串`s`。 自从`x`是一个子序列`s`， 和`s`至少只要`x`， 如果`s`本身不是任何其他字符串的子序列，那么`s`是一个更好的候选人`x`。 

这意味着我们根本不需要生成子序列。 我们只需要确定每个原始字符串是否是任何其他字符串的子序列。 

算法变为：

 1. 对于每个字符串`strs[i]`2. 将其与其他所有字符串进行比较`strs[j]`3. 检查是否`strs[i]`是一个子序列`strs[j]`4. 如果它不是另一个字符串的子序列，则更新答案

 因为约束很小，所以成对子序列检查是完全可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n × 2^m × m) | O(n × 2^m × m) | O(2^m) | O(2^m) | 显式生成所有子序列 |
 | 最佳 | O(n² × m) | O(1) | O(1) | 直接对照所有其他字符串检查每个字符串 |

 这里：

-`n`是字符串的数量
 -`m`是最大字符串长度

 自从`m <= 10`，最优方法在实践中非常有效。 

## 算法演练

 1. 初始化变量`longest_length`到`-1`。 

该变量存储迄今为止找到的最佳不常见子序列长度。 如果不存在有效字符串，则保留该字符串`-1`。 
2. 迭代数组中的每个字符串。 

对于每个字符串`current_string`，我们将确定它是否是任何其他字符串的子序列。 
3. 假设当前字符串不常见。 

创建一个布尔标志，例如`is_uncommon = True`。 
4. 将当前字符串与所有其他字符串进行比较。 

对于每个比较：

 - 跳过将字符串与同一索引处的自身进行比较
 - 检查是否`current_string`是一个子序列`other_string`5. 使用两指针子序列检查。 

维护两个指针：

 - 候选子序列的一个指针
 - 一个指向目标字符串的指针

 逐个字符地移动目标字符串。 

每当字符匹配时，就将子序列指针前进。 

如果子序列指针到达末尾，则候选者是子序列。 
6. 如果当前字符串是另一个字符串的子序列，则将其标记为无效。 

放`is_uncommon = False`并停止检查更多字符串。 
7. 如果在所有比较后该字符串仍然不常见，请更新答案。 

因为我们想要最大长度：```
longest_length = max(longest_length, len(current_string))
```8.处理完所有字符串后，返回`longest_length`。 

### 为什么它有效

 该算法之所以有效，是因为不常见的子序列必须源自原始字符串之一。 如果原始字符串不是任何其他字符串的子序列，那么它本身就是有效的罕见子序列。 

通过对照所有其他字符串检查每个字符串，我们可以正确确定它在子序列意义上是否是唯一的。 由于我们跟踪最大有效长度，因此最终答案保证是最长的不常见子序列。 

## Python 解决方案```python
from typing import List

class Solution:
    def findLUSlength(self, strs: List[str]) -> int:
        def is_subsequence(subsequence: str, target: str) -> bool:
            sub_index = 0
            target_index = 0

            while sub_index < len(subsequence) and target_index < len(target):
                if subsequence[sub_index] == target[target_index]:
                    sub_index += 1
                target_index += 1

            return sub_index == len(subsequence)

        longest_length = -1

        for i, current_string in enumerate(strs):
            is_uncommon = True

            for j, other_string in enumerate(strs):
                if i == j:
                    continue

                if is_subsequence(current_string, other_string):
                    is_uncommon = False
                    break

            if is_uncommon:
                longest_length = max(longest_length, len(current_string))

        return longest_length
```实现首先定义一个名为的辅助函数`is_subsequence`。 该函数使用标准的两指针技术。 

第一个指针遍历候选子序列，第二个指针遍历目标字符串。 只要找到匹配的字符，子序列指针就会前进。 如果我们成功消耗整个子序列，则子序列关系成立。 

外循环将数组中的每个字符串作为潜在的候选答案进行处理。 

对于每个候选字符串，内部循环将其与所有其他字符串进行比较。 如果发现候选字符串是另一个字符串的子序列，则立即拒绝该候选字符串。 

如果该字符串在所有比较中都幸存下来，则它是一个有效的罕见子序列，我们会更新最大长度。 

该算法完全避免了生成子序列，从而保持了实现的简洁和高效。 

## 解决方案```go
func findLUSlength(strs []string) int {
	isSubsequence := func(subsequence string, target string) bool {
		subIndex := 0
		targetIndex := 0

		for subIndex < len(subsequence) && targetIndex < len(target) {
			if subsequence[subIndex] == target[targetIndex] {
				subIndex++
			}
			targetIndex++
		}

		return subIndex == len(subsequence)
	}

	longestLength := -1

	for i, currentString := range strs {
		isUncommon := true

		for j, otherString := range strs {
			if i == j {
				continue
			}

			if isSubsequence(currentString, otherString) {
				isUncommon = false
				break
			}
		}

		if isUncommon && len(currentString) > longestLength {
			longestLength = len(currentString)
		}
	}

	return longestLength
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

一个区别是 Go 字符串被索引为字节切片。 由于该问题仅保证小写英文字母，因此字节索引是完全安全的。 

为了清楚起见，子序列辅助函数被实现为内联闭包。 该解决方案的其余部分使用与 Python 版本完全相同的嵌套循环。 

Go 在这里不需要对整数溢出进行特殊处理，因为字符串长度非常小。

 ## 边缘情况

 ### 重复字符串

 重复的字符串始终是另一个相同字符串的子序列。 这是最常见的错误来源之一，因为开发人员有时会忘记匹配另一个副本会使候选者无效。 

例如：```
["abc", "abc"]
```两个字符串都会失败，因为每个字符串都是另一个字符串的子序列。 该实现通过比较索引而不是单独的值来正确处理这个问题。 

### 非常短的字符串

 单字符字符串很容易成为较长字符串的子序列。 

例如：```
["a", "abc"]
```字符串`"a"`是一个子序列`"abc"`，所以这种情况并不罕见。 两指针子序列检查自然可以处理这种情况。 

### 所有字符串嵌套

 有时，每个较短的字符串都包含在较长的字符串内。 

例如：```
["abcd", "abc", "ab", "a"]
```仅有的`"abcd"`符合条件是因为其他的在后续意义上都不是唯一的。 该算法通过独立检查每一对来正确识别最长的有效候选者。
