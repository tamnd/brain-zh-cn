[LeetCode 第 588 题](https://leetcode.com/problems/design-in-memory-file-system/)

 **难度：** 🔴难
 **主题：** 哈希表、字符串、设计、Trie、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个内存中的文件系统，它可以模拟基本的文件系统操作，而无需与真实的文件系统交互。 我们需要实施一个`FileSystem`支持创建目录、添加和读取文件内容以及列出给定路径中的文件或目录的类。 

输入由绝对路径组成（从`/`) 并且仅包含小写字母。 每个操作都会影响或查询虚拟文件系统结构。 预期输出因操作而异：`ls`返回文件或目录名称的列表，`mkdir`和`addContentToFile`修改系统且不返回，并且`readContentFromFile`以字符串形式返回文件内容。 

约束表明路径有效、长度合理、最多有 300 个操作。 这表明我们的解决方案应该注重清晰度和正确性，而不是极端优化。 边缘情况包括查询根`/`、向现有文件添加内容以及涉及嵌套目录的路径。 

关键的挑战是维护文件系统的高效且易于遍历的表示，支持快速查找、插入和内容存储。 

## 方法

 强力方法是使用平面列表或数组来存储每个路径和文件内容。 每一个`ls`,`mkdir`， 或者`addContentToFile`操作将涉及扫描整个列表以查找匹配的目录或文件。 虽然这在功能上可行，但对于嵌套路径或频繁操作来说会很慢，每个操作的复杂度为 O(n)。 

最佳方法是使用类似 trie 的树结构，其中每个节点代表一个目录或文件。 每个目录节点都存储一个将名称映射到子节点的字典。 文件节点将其内容存储为字符串。 这允许 O(k) 操作，其中 k 是路径中的组件数量，用于创建、查找或内容读取。 字典顺序为`ls`返回结果时可以通过对字典的键进行排序来处理。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每次操作 O(n) | O(n) | 将路径存储在列表中； 需要线性扫描进行查找|
 | 最佳 | ls 为 O(k log k)，其他操作为 O(k) | O(总节点+总内容) | 使用trie/树结构； k 是路径分量的数量 |

 ## 算法演练

 1. 定义一个`Node`表示目录或文件的类。 目录节点有一个子字典，文件节点有一个内容字符串。 
2. 将文件系统的根初始化为空目录节点。 
3. 实施`mkdir(path)`通过将路径拆分为多个组件并遍历 trie，沿路径创建任何丢失的目录。 
4. 实施`addContentToFile(filePath, content)`通过遍历文件路径，如果不存在则创建一个新的文件节点，并追加内容。 
5. 实施`readContentFromFile(filePath)`通过遍历到文件节点并返回其内容。 
6. 实施`ls(path)`通过遍历给定的路径。 如果它是一个文件，则在列表中返回其名称。 如果它是目录，则返回子名称的排序列表。 

工作原理：trie 结构保留了文件系统的分层性质。 每个操作都遵循从根节点到目标节点的路径组件。 沿路径创建目录或文件可保证结构保持一致。 不变的是 trie 总是准确地表示文件系统。 

## Python 解决方案```python
from typing import List, Dict

class Node:
    def __init__(self):
        self.children: Dict[str, Node] = {}
        self.content: str = ""
        self.is_file: bool = False

class FileSystem:

    def __init__(self):
        self.root = Node()

    def ls(self, path: str) -> List[str]:
        node = self.root
        if path != "/":
            parts = path.split("/")[1:]
            for part in parts:
                node = node.children[part]
            if node.is_file:
                return [parts[-1]]
        return sorted(node.children.keys())

    def mkdir(self, path: str) -> None:
        node = self.root
        parts = path.split("/")[1:]
        for part in parts:
            if part not in node.children:
                node.children[part] = Node()
            node = node.children[part]

    def addContentToFile(self, filePath: str, content: str) -> None:
        node = self.root
        parts = filePath.split("/")[1:]
        for part in parts[:-1]:
            node = node.children[part]
        if parts[-1] not in node.children:
            node.children[parts[-1]] = Node()
            node.children[parts[-1]].is_file = True
        node.children[parts[-1]].content += content

    def readContentFromFile(self, filePath: str) -> str:
        node = self.root
        parts = filePath.split("/")[1:]
        for part in parts[:-1]:
            node = node.children[part]
        return node.children[parts[-1]].content
```Python 实现定义了一个`Node`目录和文件的类。`ls`处理根目录、文件和字典顺序。`mkdir`和`addContentToFile`遍历路径，如果丢失则创建中间节点。`readContentFromFile`只需遵循文件的路径并返回内容即可。 

## 解决方案```go
package main

import (
    "sort"
    "strings"
)

type Node struct {
    children map[string]*Node
    content  string
    isFile   bool
}

type FileSystem struct {
    root *Node
}

func Constructor() FileSystem {
    return FileSystem{root: &Node{children: make(map[string]*Node)}}
}

func (this *FileSystem) Ls(path string) []string {
    node := this.root
    if path != "/" {
        parts := strings.Split(path, "/")[1:]
        for _, part := range parts {
            node = node.children[part]
        }
        if node.isFile {
            return []string{parts[len(parts)-1]}
        }
    }
    res := make([]string, 0, len(node.children))
    for name := range node.children {
        res = append(res, name)
    }
    sort.Strings(res)
    return res
}

func (this *FileSystem) Mkdir(path string) {
    node := this.root
    parts := strings.Split(path, "/")[1:]
    for _, part := range parts {
        if _, ok := node.children[part]; !ok {
            node.children[part] = &Node{children: make(map[string]*Node)}
        }
        node = node.children[part]
    }
}

func (this *FileSystem) AddContentToFile(filePath string, content string) {
    node := this.root
    parts := strings.Split(filePath, "/")[1:]
    for _, part := range parts[:len(parts)-1] {
        node = node.children[part]
    }
    if _, ok := node.children[parts[len(parts)-1]]; !ok {
        node.children[parts[len(parts)-1]] = &Node{children: make(map[string]*Node), isFile: true}
    }
    node.children[parts[len(parts)-1]].content += content
}

func (this *FileSystem) ReadContentFromFile(filePath string) string {
    node := this.root
    parts := strings.Split(filePath, "/")[1:]
    for _, part := range parts[:len(parts)-1] {
        node = node.children[part]
    }
    return node.children[parts[len(parts)-1]].content
}
```Go 实现镜像 Python，但使用显式映射初始化和类型声明。 排序是使用标准完成的`sort`包裹。 Go 需要仔细处理切片和映射，尤其是在创建新节点时。 

## 工作示例

 示例1：```
Operations: ["FileSystem", "ls", "mkdir", "addContentToFile", "ls", "readContentFromFile"]
Arguments:  [[], ["/"], ["/a/b/c"], ["/a/b/c/d", "hello"], ["/"], ["/a/b/c/d"]]
```一步一步：

 1. 初始化文件系统。 根节点是空目录。 
2.`ls("/")`→ 根没有孩子 → 返回`[]`。 
3.`mkdir("/a/b/c")`→ 为 a → b → c 创建节点。 
4.`addContentToFile("/a/b/c/d", "hello")`→ 创建文件`d`在`c`并设定内容。 
5.`ls("/")`→ 根有孩子`a`→ 返回`["a"]`。 
6.`readContentFromFile("/a/b/c/d")`→ 返回`"hello"`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | ls 为 O(k log k)，其他为 O(k) | k 是路径分量的数量 |
 | 空间| O(总节点+总内容) | 每个目录和文件使用一个节点 |

 主要成本是遍历路径组件。 排序`ls`需要 O(k log k)，其中 k 是目录中的条目数。
