[LeetCode 第 590 题](https://leetcode.com/problems/n-ary-tree-postorder-traversal/)

 **难度：** 🟢简单
 **主题：** 堆栈、树、深度优先搜索

 ## 解决方案

 ## 问题理解

 这个问题要求我们对n叉树进行后序遍历。 

在二叉树中，每个节点最多有两个子节点。 在 n 叉树中，每个节点可以有任意数量的子节点。 每个节点都包含一个值和一个子节点列表。 

后序遍历意味着：

 1. 首先探望所有孩子
 2.然后访问当前节点本身

 对于 n 叉树，这意味着我们从左到右递归地处理每个子节点，并且只有在处理完所有子节点之后，我们才会将当前节点的值添加到结果中。 

例如，考虑这棵树：```
        1
     /  |  \
    3   2   4
   / \
  5   6
```后序遍历为：```
5, 6, 3, 2, 4, 1
```因为我们完全处理节点`3`及其访问前的子树`3`本身，然后处理`2`， 然后`4`，最后`1`。 

输入作为树的根节点提供。 在内部，每个节点包含：

 - 一个值
 - 子节点列表

 这些约束告诉我们一些重要的事情：

 - 该树最多可以包含`10^4`节点，因此解决方案必须是有效的。 
- 树的高度可以大到`1000`，这意味着递归解决方案在许多语言中都是可以接受的，但递归深度在某些环境中可能会变得有风险。 
- 我们应该以线性时间复杂度为目标，因为每个节点必须至少被访问一次。 

重要的边缘情况包括：

 - 一棵空树`root == None`- 一棵只有一个节点的树
 - 树深，孩子长链
 - 具有空子列表的节点
 - 高度不平衡的树木

 该问题还包括后续要求迭代解决方案，这意味着我们应该了解如何使用显式堆栈来模拟递归深度优先遍历。 

## 方法

 ### 蛮力方法

 最直接的解决方案是递归深度优先遍历。 

对于每个节点：

 1.递归遍历所有children
 2. 之后追加当前节点的值

 这直接符合后序遍历的定义，因此很容易正确推理和实现。 

递归方法只访问每个节点一次，使其对于给定的约束足够有效。 然而，递归依赖于调用堆栈。 在极深的树中，这可能会成为问题，因为递归深度在某些编程环境中受到限制。 

虽然这种方法在时间复杂度上已经是最优的，但是后续的问题特别询问我们是否可以迭代地解决它。 

### 最佳方法

 迭代解决方案使用堆栈来模拟递归。 

关键的见解是后序遍历在处理父母之前处理孩子。 一个有用的技巧是：

 - 执行修改后的前序遍历
 - 以根优先的顺序处理节点
 - 反转最终结果

 对于n叉树：

 - 正常预购是：```
root -> children left to right
```- 如果我们处理：```
root -> children right to left
```然后将结果反转，得到：```
children left to right -> root
```这正是后序遍历。 

这是有效的，因为反转遍历自然会延迟父级处理，直到处理完所有后代。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(h) | 使用调用堆栈的递归 DFS |
 | 最佳 | O(n) | O(n) | 使用显式堆栈进行迭代遍历 |

 这里：

-`n`是节点数
 -`h`是树的高度

 ## 算法演练

 ### 迭代后序遍历

 1. 初始化一个空的结果列表。 

该列表将以修改后的预序顺序临时存储节点。 
2. 处理空树箱。 

如果根是`None`，立即返回一个空列表，因为没有要遍历的节点。 
3. 创建一个堆栈并将根节点压入其中。 

该堆栈模拟递归 DFS 调用堆栈。 
4. 当堆栈不为空时，继续处理。 

这个循环确保每个节点都被访问一次。 
5. 从堆栈中弹出顶部节点。 

这成为当前正在处理的节点。 
6. 将当前节点的值追加到结果列表中。 

在这个阶段，订单还不是真正的后序。 
7. 将所有子项推入堆栈。 

由于堆栈是 LIFO 结构，因此从左向右推送子级会导致最右边的子级首先被处理。 

这会产生类似于以下的遍历顺序：```
root -> right -> left
```8、处理完所有节点后，反转结果列表。 

反转将遍历转换为正确的后序：```
left -> right -> root
```9. 返回反转后的结果。 

### 为什么它有效

 该算法以修改后的前序顺序处理节点，其中先访问父节点，然后再访问子节点。 由于遍历顺序随后实际上是相反的，因此在最终输出中，每个父节点都出现在其所有后代节点之后。 这完全符合后序遍历的定义。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: Optional[int] = None, children: Optional[List['Node']] = None):
        self.val = val
        self.children = children
"""

from typing import List, Optional

class Solution:
    def postorder(self, root: 'Node') -> List[int]:
        if not root:
            return []

        result = []
        stack = [root]

        while stack:
            node = stack.pop()

            result.append(node.val)

            for child in node.children:
                stack.append(child)

        return result[::-1]
```实现首先处理空树的情况。 如果根是`None`，我们立即返回一个空列表。 

然后我们初始化两个结构：

 -`result`，存储遍历值
 -`stack`，它控制DFS遍历顺序

 主循环继续进行，直到堆栈变空。 在每次迭代期间：

 - 一个节点从堆栈中删除
 - 其值附加到`result`- 所有孩子都被推入堆栈

 由于堆栈首先处理最近添加的元素，因此会按照与插入相反的顺序探索子元素。 这将创建一个相反的后序序列。 

最后，`result[::-1]`反转遍历并产生正确的后序顺序。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */

func postorder(root *Node) []int {
    if root == nil {
        return []int{}
    }

    result := []int{}
    stack := []*Node{root}

    for len(stack) > 0 {
        lastIndex := len(stack) - 1
        node := stack[lastIndex]
        stack = stack[:lastIndex]

        result = append(result, node.Val)

        for _, child := range node.Children {
            stack = append(stack, child)
        }
    }

    left := 0
    right := len(result) - 1

    for left < right {
        result[left], result[right] = result[right], result[left]
        left++
        right--
    }

    return result
}
```Go 实现遵循与 Python 版本相同的算法思想。 

一些特定于 Go 的细节很重要：

 -`nil`被用来代替`None`- 切片用于堆栈和结果列表
 - 由于Go不提供内置的切片反转，我们使用两个指针手动反转结果
 - 堆栈操作是使用切片追加和切片来实现的

 该解决方案可以安全地处理空树和任意 n 元结构。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(n) | 堆栈和结果列表可以存储所有节点|

 遍历处理每个节点一次，因此总运行时间与节点数量呈线性关系。 

空间复杂度也是线性的，因为：

 - 堆栈可以同时包含许多节点
 - 结果列表存储所有节点值

 即使递归只能使用`O(h)`在辅助空间中，迭代方法使用堆栈显式管理遍历状态。

 ## 边缘情况

 ### 空树

 该树可能包含零个节点，这意味着`root`是`None`。 这是错误的常见来源，因为尝试访问`root.children`会引发错误。 该实现通过立即返回一个空列表来避免这种情况`root`是假的。 

### 单节点树

 一棵只有一个节点的树没有子节点。 某些实现会意外地跳过处理叶节点或错误处理空子列表。 在这里，算法正确地将根推入堆栈，处理它，然后返回`[root.val]`。 

### 深度嵌套树

 树高可达`1000`，创建非常深的递归调用链。 递归解决方案在某些语言或环境中存在堆栈溢出的风险。 迭代解决方案完全避免了这个问题，因为它使用在堆上分配的显式堆栈，而不是依赖于递归函数调用。 

### 具有空子列表的节点

 叶子节点有空`children`数组。 某些实现假设每个节点都有子节点，并且可能会错误地迭代`None`。 提供的解决方案可以安全地处理空子列表，因为迭代空列表自然不会执行任何操作。 

### 高度不平衡的树

 n 叉树可能会极度倾斜，其中一个分支比其他分支深得多。 该算法仍然可以正常工作，因为 DFS 遍历自然地适应任意树形状，而不依赖于平衡假设。
