[LeetCode 530 题](https://leetcode.com/problems/minimum-absolute-difference-in-bst/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、广度优先搜索、二叉搜索树、二叉树

 ## 解决方案

 ## 问题理解

 该问题为我们提供了二叉搜索树（缩写为 BST）的根节点，并要求我们找到树中任意两个不同节点的值之间的最小绝对差。 

二叉搜索树有一个非常重要的属性：

 - 左子树中的每个值都小于当前节点
 - 右子树中的每个值都大于当前节点

 输入是树结构，而不是数组。 每个节点都包含一个整数值以及指向其左子节点和右子节点的指针。 

输出应该是一个整数，表示树中任何一对节点值之间的最小绝对差。 

例如，在树中：```
    4
   / \
  2   6
 / \
1   3
```节点值为`{1, 2, 3, 4, 6}`。 任意两个值之间的最小差异是`1`， 因为：

-`2 - 1 = 1`-`3 - 2 = 1`-`4 - 3 = 1`约束条件很重要：

 - 树包含之间`2`和`10^4`节点
 - 节点值介于`0`和`10^5`由于树最多可以包含一万个节点，因此低效的成对比较解决方案可能会变得太慢。 我们需要比检查每对可能的节点更好的东西。 

还有几个重要的边缘情况：

 - 父节点和子节点之间可能出现的最小差异
 - 不同子树中的节点之间可能出现最小差异
 - BST 可能高度不平衡，本质上表现得像一个链表
 - 值可以非常接近，例如连续整数
 - 最小的树大小只有两个节点

 该问题保证至少有两个节点，因此始终存在有效的最小差异。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是：

 1.遍历整棵树，将所有节点值收集到一个数组中
 2. 比较每对值
 3. 计算每对的绝对差
 4. 返回找到的最小差异

 这是有效的，因为它显式地检查每对可能的节点，保证发现最小的差异。 

但是，如果树包含`n`节点，大约有`n²`成对进行比较。 高达`10^4`节点，这变得太昂贵了。 

蛮力方法完全忽略了 BST 结构，这浪费了有用的排序信息。 

### 最佳解决方案的关键见解

 关键的观察结果是 BST 的中序遍历会产生按排序顺序的值。 

例如，这个 BST：```
    4
   / \
  2   6
 / \
1   3
```按顺序访问给出：```
1, 2, 3, 4, 6
```一旦对值进行排序，两个相邻值之间必须出现最小绝对差。 

为什么？ 

假设我们已经排序了值：```
a < b < c
```然后：```
c - a > b - a
```和```
c - a > c - b
```因此，不相邻的值永远无法产生最小差异。 

这意味着我们只需要在中序遍历时将每个值与前一个值进行比较。 

这将问题简化为线性时间。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 收集所有值并比较每对 |
 | 最佳| O(n) | O(h) | BST的中序遍历，比较相邻值|

 这里，`h`是树的高度。 

## 算法演练

 ### 使用中序遍历的最优算法

 1. 初始化变量`previous_value`在中序遍历期间跟踪先前访问过的节点。 

由于中序遍历按排序顺序访问节点，因此前一个节点始终是最接近的较小值。 
2. 初始化变量`minimum_difference`到正无穷大。 

该变量存储迄今为止找到的最佳答案。 
3. 对 BST 进行中序遍历。 

中序遍历遵循以下顺序：

 - 遍历左子树
 - 访问当前节点
 - 遍历右子树
 4. 访问节点时，将其值与`previous_value`。 

由于值是按升序访问的，因此差异：```
current_value - previous_value
```是涉及当前节点和任何较早节点的最小可能差异。 
5. 更新`minimum_difference`如果当前差异较小。 
6. 更新`previous_value`为当前节点的值。 

这为下一次有序访问做好准备。 
7. 继续遍历，直到所有节点都处理完毕。 
8. 返回`minimum_difference`。 

### 为什么它有效

 正确性取决于 BST 的中序性质。 

BST 的中序遍历会产生严格递增排序顺序的值。 在排序序列中，任何两个数字之间的最小差异必须出现在相邻元素之间。 

因此，通过在中序遍历期间仅将每个节点与先前访问的节点进行比较，我们检查所有候选最小差异，而不需要比较每一对。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        self.previous_value = None
        self.minimum_difference = float("inf")

        def inorder(node: Optional[TreeNode]) -> None:
            if not node:
                return

            inorder(node.left)

            if self.previous_value is not None:
                difference = node.val - self.previous_value
                self.minimum_difference = min(
                    self.minimum_difference,
                    difference
                )

            self.previous_value = node.val

            inorder(node.right)

        inorder(root)

        return self.minimum_difference
```该实现使用递归中序遍历来按排序顺序处理 BST。 

变量`self.previous_value`存储先前访问过的节点值。 最初是`None`因为还没有访问过任何节点。 

变量`self.minimum_difference`存储迄今为止遇到的最小差异。 它以无穷大开始，因此第一个有效差异将始终取代它。 

里面的`inorder`功能：

 - 首先处理左子树
 - 当前节点被访问
 - 右子树最后处理

 当访问当前节点时，代码将其值与`self.previous_value`。 Because inorder traversal produces sorted values, this comparison checks adjacent elements in sorted order.

 计算差异后，当前节点成为新的前一个节点。 

The traversal eventually visits every node exactly once and returns the minimum difference found.

 ## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func getMinimumDifference(root *TreeNode) int {
    minDiff := int(^uint(0) >> 1)

    var prev *TreeNode

    var inorder func(node *TreeNode)

    inorder = func(node *TreeNode) {
        if node == nil {
            return
        }

        inorder(node.Left)

        if prev != nil {
            diff := node.Val - prev.Val

            if diff < minDiff {
                minDiff = diff
            }
        }

        prev = node

        inorder(node.Right)
    }

    inorder(root)

    return minDiff
}
```Go 解决方案遵循与 Python 版本相同的逻辑。 

一个指针`prev`在中序遍历期间跟踪先前访问过的节点。 由于Go不支持`None`，我们使用`nil`来表示不存在前一个节点。 

表达式：```go
int(^uint(0) >> 1)
```创建最大可能的整数值，作为初始最小差值。 

递归闭包`inorder`执行遍历和更新`minDiff`当节点被访问时。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 递归调用栈使用树高空间 |

 遍历过程中每个节点都会处理一次，因此运行时间与节点数量成线性关系。 

额外的空间来自递归。 在平衡 BST 中，高度为`O(log n)`。 在最坏的情况下，当树完全倾斜时，高度变为`O(n)`。

 ## 边缘情况

 ### 二节点树

 最小的有效输入恰好包含两个节点。 这种情况很重要，因为只有一对可能的值。 

有缺陷的实现可能会假设在遍历期间发生多次比较。 我们的实现正确处理了这个问题，因为第一个有效的比较立即更新`minimum_difference`。 

### 高度倾斜的树

 BST 可能会变得完全不平衡，表现得像链表：```
1
 \
  2
   \
    3
```这测试当高度变为时递归和遍历逻辑是否仍然正常工作`O(n)`。 

该实现仍然按排序顺序处理节点并正确计算相邻差异。 

### 子树深处的最小差异

 最接近的值对可能根本不涉及根。 

例子：```
      50
     /
    30
   /  \
 20   31
```最小差异为`30`和`31`，都在左子树内。 

仅比较父子关系的幼稚实现可能会错过这种情况。 中序遍历避免了这个问题，因为它会在整个树上全局比较所有相邻的排序值。
