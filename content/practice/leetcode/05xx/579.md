[LeetCode 问题 579](https://leetcode.com/problems/find-cumulative-salary-of-an-employee/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们根据每个员工 2020 年的月薪计算**累计薪资汇总**。输入是一个表格`Employee`每行包含一名员工`id`， 这`month`（1 到 12），以及`salary`那个月。 每个`(id, month)`组合是独一无二的。 

**累计工资汇总**按 3 个月滚动总和计算：对于给定月份`m`, 本月工资总和`m`,`m-1`， 和`m-2`。 如果员工在前几个月没有工作，则该月份被视为有工资`0`。 重要的是，摘要**不包括每位员工最近工作的月份**，也不包括员工未工作的月份。 输出必须按以下顺序排序`id`上升，并且在平局的情况下，通过`month`下降。 

边缘情况包括员工只有一个月的数据、有差距的月份以及员工在一年中较晚开始工作的月份（因此之前的月份实际上为零）。 输入保证月份是 1 到 12 之间的整数，并且`(id, month)`是唯一的，简化了索引。 

## 方法

 蛮力方法会迭代每个员工和每个月，将当月和前两个月的工资相加。 对于每个员工来说，这需要检查长达 12 个月，每次回溯长达 2 个月，导致重复计算。 虽然这种方法是正确的，但效率低下，尤其是对于大量员工和几个月来说，因为它会反复扫描工资记录。 

最佳方法利用 SQL 中的**窗口函数**或代码中的累积计算。 我们的见解是，对于每个员工来说，按月排序可以保持过去三个月的滚动总和。 我们可以有效地计算 3 个月的总和，而无需重复扫描，并通过首先识别每个员工来排除最近一个月。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(E * M^2) | O(E * M) | 为每位员工每个月重复计算最近 3 个月的总和 |
 | 最佳 | O(E * M) | O(E * M) | 按员工和月份排序，使用窗口/数组计算滚动总和，排除上个月 |

 这里，`E`是员工人数，`M`是每个员工的最大月数（最多 12 个）。 

## 算法演练

 1. 检索所有工资记录`Employee`按员工对它们进行表格和分组`id`。 在每个员工组中，按月份升序对记录进行排序。 
2. 对于每个员工，初始化一个大小为 3 的滚动总和数组，用于存储最近三个月的工资。 另外，确定该员工最近的月份。 
3. 迭代该员工的每个月。 对于当前月份，通过将当前月份的工资与滚动数组中存储的前两个月的工资相加来计算 3 个月的累计总和。 这可确保缺失的月份被视为零。 
4. 根据指定跳过最近一个月的计算。 
5. 存储结果`(id, month, 3-month sum)`在结果列表中。 
6. 处理完所有员工后，对最终结果进行排序`id`上升和`month`下降。 
7. 返回结果。 

**为什么有效：** 按月份排序可确保对于每个员工，滚动总和捕获连续月份。 使用长度为 3 的滚动数组可保证高效计算，同时自动将缺失月份视为零。 排除处理后的最近一个月可确保问题限制的正确性。 

## Python 解决方案```python
from typing import List
import pandas as pd

def findCumulativeSalary(employee: pd.DataFrame) -> pd.DataFrame:
    # Sort by employee id and month ascending
    employee = employee.sort_values(['id', 'month'])
    
    result = []
    
    for emp_id, group in employee.groupby('id'):
        months = group['month'].tolist()
        salaries = group['salary'].tolist()
        last_month = max(months)
        
        # Rolling sums for previous two months
        rolling = [0, 0]  # previous two months
        for i, month in enumerate(months):
            if month == last_month:
                continue  # skip the most recent month
            # Calculate 3-month sum
            sum_last_3 = salaries[i] + rolling[-1] + rolling[-2] if len(rolling) >= 2 else salaries[i]
            result.append((emp_id, month, sum_last_3))
            # Update rolling
            rolling.append(salaries[i])
            if len(rolling) > 2:
                rolling.pop(0)
    
    # Convert to DataFrame and sort
    result_df = pd.DataFrame(result, columns=['id', 'month', 'Salary'])
    result_df = result_df.sort_values(['id', 'month'], ascending=[True, False])
    return result_df
```在此 Python 解决方案中，我们使用`pandas`有效地对数据进行分组和排序。 滚动总和数组存储最近两个月的工资，添加当月工资即可计算 3 个月的总和。 我们跳过最近一个月，最后根据需要对 DataFrame 进行排序。 

## 解决方案```go
package main

import (
    "sort"
)

type Employee struct {
    Id     int
    Month  int
    Salary int
}

type Result struct {
    Id     int
    Month  int
    Salary int
}

func FindCumulativeSalary(employees []Employee) []Result {
    // Group by employee id
    empMap := make(map[int][]Employee)
    for _, e := range employees {
        empMap[e.Id] = append(empMap[e.Id], e)
    }

    var results []Result

    for id, records := range empMap {
        // Sort records by month ascending
        sort.Slice(records, func(i, j int) bool { return records[i].Month < records[j].Month })
        lastMonth := records[len(records)-1].Month
        rolling := []int{0, 0}
        
        for _, r := range records {
            if r.Month == lastMonth {
                continue
            }
            sum := r.Salary
            if len(rolling) >= 2 {
                sum += rolling[0] + rolling[1]
            }
            results = append(results, Result{Id: id, Month: r.Month, Salary: sum})
            rolling = append(rolling, r.Salary)
            if len(rolling) > 2 {
                rolling = rolling[1:]
            }
        }
    }

    // Sort results by id ascending, month descending
    sort.Slice(results, func(i, j int) bool {
        if results[i].Id == results[j].Id {
            return results[i].Month > results[j].Month
        }
        return results[i].Id < results[j].Id
    })

    return results
}
```在 Go 中，我们使用映射手动处理分组并对切片进行排序。 滚动数组逻辑与 Python 相同。 Go 需要显式的切片管理来模拟滚动窗口。 

## 工作示例

 对于员工`1`月份 [1,2,3,4,7,8] 和工资 [20,30,40,60,90,90]：

 | 月 | 滚动最后 2 | 3 个月总和 | 笔记|
 | --- | --- | --- | --- |
 | 1 | [0,0]| 20 | 只有当月工资，没有上个月 |
 | 2 | [0,20]| 50 | 50 30+20+0 |
 | 3 | [20,30]| 90 | 90 40+30+20 |
 | 4 | [30,40]| 130 | 130 60+40+30 |
 | 7 | [40,60] | 90 | 90 90+0+0（缺少 5,6 个月）|
 | 8 | 跳过| - | 最近一个月 |

 结果按每个员工的月份降序排列，产生预期的输出。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(E * M) | 对每个员工进行排序并在数月内进行迭代，并使用恒定时间滚动总和 |
 | 空间| O(E * M) | 分组员工和滚动阵列的存储 |

 时间复杂度与排序后的工资记录数量成线性关系。 空间与输入大小成正比，因为我们维护所有记录和每个员工的小型滚动数组。
