 ## 解决方案

 ## 问题理解

 该问题要求我们找到整数数组中**最长和谐子序列**的长度。 和谐数组被定义为最大值和最小值之差**恰好为 1** 的数组。 简单来说，给定一个数组`nums`，我们正在搜索最长的元素集合，其中最大元素恰好比最小元素大一，并且所有其他元素要么是该子序列的最大值或最小值。 子序列不需要是连续的，因此元素可以分散在数组中。 

输入是长度在 1 到 20,000 之间的整数列表，整数值的范围可以是`-10^9`到`10^9`。 输出是一个整数，表示最长和谐子序列的长度。 如果不存在和谐子序列（即，没有两个数字恰好相差 1），则输出应为 0。 

重要的边缘情况包括所有元素都相同的数组（没有和谐的子序列）、仅包含两个相差超过 1 的不同数字的数组，以及存在多个候选子序列的重复数字的数组。 

## 方法

 暴力方法会生成数组的所有可能的子序列，检查每个子序列的最大值和最小值，如果形成和谐的子序列，则记录长度。 这保证了正确性，但效率极低，因为子序列的数量随着数组大小呈指数增长，这使得它对于大输入不可行。 

最佳解决方案的关键见解是认识到我们只关心每个数字及其直接邻居的频率（数字±1）。 如果我们计算每个数字出现的次数，我们可以迭代唯一的数字并检查是否`number + 1`存在。 如果是，则计数的总和`number`和`number + 1`给出候选和谐子序列的长度. 这种方法将问题简化为计算频率和扫描按键，即使对于大型阵列也很有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 生成所有子序列并检查最大最小差异，对于大输入来说不切实际 |
 | 最佳| O(n) | O(n) | 使用哈希图计算频率，然后将每个数字与其邻居进行检查 |

 ## 算法演练

 1. 初始化一个空的哈希图（`count`) 来存储数组中每个整数的频率。 
2. 遍历数组`nums`并填充`count`映射，以便每个键映射到它出现的次数。 
3. 初始化变量`max_length`为 0 以跟踪找到的最长和谐子序列的长度。 
4. 迭代每个唯一的数字`num`在`count`地图。 
5. 对于每个`num`，检查是否`num + 1`存在于地图中。 
6.如果存在，计算组合长度`count[num] + count[num + 1]`。 
7. 更新`max_length`如果这个组合长度大于当前的长度`max_length`。 
8.检查完所有数字后，返回`max_length`。 

**为什么有效：** 该算法之所以有效，是因为和谐子序列必须恰好由两个相邻的整数值组成。 通过计算频率并仅检查`num`和`num + 1`，我们确保只考虑每个潜在的和谐子序列一次，并对这两个值的所有出现进行求和以获得最长的可能长度。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def findLHS(self, nums: List[int]) -> int:
        count = Counter(nums)
        max_length = 0
        
        for num in count:
            if num + 1 in count:
                max_length = max(max_length, count[num] + count[num + 1])
        
        return max_length
```在这个实现中，我们使用`Counter`来自Python的`collections`模块快速计算频率。 然后我们迭代计数器的键，检查连续数字是否存在，并更新找到的最大长度。 这是算法演练的直接实现。 

## 解决方案```go
func findLHS(nums []int) int {
    count := make(map[int]int)
    for _, num := range nums {
        count[num]++
    }
    
    maxLength := 0
    for num, freq := range count {
        if freqNext, exists := count[num+1]; exists {
            if freq+freqNext > maxLength {
                maxLength = freq + freqNext
            }
        }
    }
    
    return maxLength
}
```在 Go 中，我们使用`map[int]int`计算每个数字出现的频率。 其余逻辑与 Python 版本类似。 我们检查是否`num + 1`存在于映射中，对计数求和，并更新最大长度。 Go 没有内置计数器，因此我们手动递增映射值。
