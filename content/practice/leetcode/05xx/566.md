[LeetCode 566 题](https://leetcode.com/problems/reshape-the-matrix/)

 **难度：** 🟢简单
 **主题：** 数组、矩阵、模拟

 ## 解决方案

 ## 问题理解

 问题是要求我们采用现有的`m x n`矩阵并将其“重塑”为一个新矩阵`r`行和`c`列。 重塑意味着按照**行主顺序**（从左到右，从上到下）重新排列矩阵中的元素，而不改变元素本身的顺序。 如果原始矩阵中的元素数量 (`m * n`) 与目标矩阵 (`r * c`），重塑操作无效，我们必须返回原始矩阵不变。 

输入是一个 2D 列表（或 Go 中的切片）`mat`表示原始矩阵和整数`r`和`c`代表目标尺寸。 输出是一个 2D 整数列表（或 Go 中的 2D 切片），表示重塑后的矩阵或原始矩阵（如果无法重塑）。 

约束告诉我们，矩阵最多可以有 100 行和 100 列，值范围从 -1000 到 1000。目标维度可以大到 300，这意味着我们必须仔细检查元素总数，以避免无效的重塑。 边缘情况包括以下情况`r`或者`c`大于元素总数，或者其中`r * c`等于`m * n`但其中一个维度是 1（展平为单行或单列）。 

## 方法

 最直接的方法是暴力法。 在这种方法中，我们将原始矩阵展平为单个列表，然后使用大小的切片逐行重建新矩阵`c`。 这保证了正确性，因为它保留了行遍历顺序，但它使用与元素总数成比例的额外空间。 

更优化的解决方案可以避免创建单独的扁平列表。 通过使用整数除法和模运算，我们可以直接根据原始矩阵中的索引计算重构矩阵中的位置。 关键的见解是元素索引`i`在原始矩阵的展平视图中，它在新矩阵中的位置是`(i // c, i % c)`。 这消除了展平所需的额外空间，并在一次通过中产生结果。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(m * n) | 将矩阵展平为列表，然后重建新矩阵。 |
 | 最佳 | O(m * n) | O(1) 额外 | 将每个元素的索引直接从原始矩阵映射到重构矩阵，不需要额外的列表。 |

 ## 算法演练

 1.确定尺寸`m`和`n`通过检查原始矩阵的长度和第一行的长度来计算原始矩阵。 
2.如果产品`m * n`不等于`r * c`，返回原始矩阵，因为重塑是不可能的。 
3.初始化一个空矩阵`reshaped`和`r`行和`c`列。 
4. 使用嵌套循环或单个计数器迭代原始矩阵的所有元素`i`。 
5. 对于每个元素，计算其在重构矩阵中的位置：该行是`i // c`该列是`i % c`。 
6. 将元素放置在重构矩阵中的计算位置处。 
7. 放置完所有元素后，返回重构后的矩阵。 

**为什么有效**：该算法之所以有效，是因为原始矩阵的展平顺序与行遍历顺序相匹配。 通过使用除法和模运算，从线性索引到二维重构索引的映射保留了该顺序，而无需任何额外的存储。 

## Python 解决方案```python
from typing import List

class Solution:
    def matrixReshape(self, mat: List[List[int]], r: int, c: int) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        if m * n != r * c:
            return mat
        
        reshaped = [[0] * c for _ in range(r)]
        for i in range(m * n):
            reshaped[i // c][i % c] = mat[i // n][i % n]
        
        return reshaped
```该代码首先计算原始矩阵维度。 如果无法进行整形，则返回原始矩阵。 然后，它构造重构矩阵并对所有元素使用单个循环，使用整数除法和模算术将展平视图中的每个索引映射到原始矩阵和重构矩阵中的正确位置。 

## 解决方案```go
func matrixReshape(mat [][]int, r int, c int) [][]int {
    m, n := len(mat), len(mat[0])
    if m*n != r*c {
        return mat
    }
    
    reshaped := make([][]int, r)
    for i := range reshaped {
        reshaped[i] = make([]int, c)
    }
    
    for i := 0; i < m*n; i++ {
        reshaped[i/c][i%c] = mat[i/n][i%n]
    }
    
    return reshaped
}
```在 Go 中，我们显式初始化重塑切片的每一行。 映射索引的逻辑与 Python 相同，通过整数除法和模处理位置映射。 区别在于切片分配和类型声明。

 输入：`mat = [[1,2],[3,4]]`,`r = 2`,`c = 4`自从`2*2 != 2*4`，重塑是不可能的。 输出：`[[1,2],[3,4]]`## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 每个元素都会被访问一次，以将其放入重构后的矩阵中。 |

 ## 边缘情况

 **单元素矩阵**：无论目标维度如何，都应正确处理仅包含一个元素的矩阵。 自从`m * n`等于 1，重塑为`1x1`有效，但其他任何东西都应该返回原始矩阵。 

**重塑为单行或单列**：将矩阵展平为单行或单列可以揭示索引计算中的差一错误。 使用整数除法和取模可确保两者`i // c`和`i % c`正确映射。 

**不可能的重塑**：当`r * c`不等于`m * n`，很容易忘记检查此条件并尝试构建无效矩阵。 立即返回原始矩阵可以避免不必要的计算和错误。
