[LeetCode 问题 1026](https://leetcode.com/problems/maximum-difference- Between-node-and-ancestor/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们在一个重要条件下找到二叉树中两个节点值之间的最大绝对差：一个节点必须是另一个节点的祖先。 

在二叉树中，节点的祖先是出现在从根到该节点的路径上的任何节点。 父母是祖先，祖父母也是祖先，等等。 

对于树中的每个节点，我们希望将其值与它下面的所有后代的值进行比较。 在所有此类祖先-后代对中，我们返回最大绝对差值。 

输入是二叉树的根。 每个节点包含：

 - 整数值
 - 左子指针
 - 右子指针

 输出是一个表示最大可能值的整数：$$|a.val - b.val|$$在哪里`a`是的祖先`b`。 

约束条件很重要：

 - 树包含 2 到 5000 个节点
 - 节点值范围从0到100000

 具有 5000 个节点的树足够大，重复遍历每个节点的子树可能会变得太慢。 这强烈表明我们需要一种有效的遍历策略来一次性处理树。 

有几个重要的边缘情况需要考虑：

 - 一棵完全倾斜的树，其中每个节点只有一个子节点。 这实际上成为一个链表并创建最大可能的递归深度。 
- 所有节点值都相同的树。 答案应该正确地变为 0。 
- 最大差异发生在深度相距较远的节点之间的树，而不仅仅是直接的父子对。 
- 最小值和最大值出现在同一根到叶路径上的树。 这通常是最大差异出现的地方。 

该问题保证至少有两个节点，因此总会有至少一对祖先-后代对进行评估。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是将每个节点视为潜在的祖先，并将其与其子树中的每个后代进行比较。 

对于每个节点：

 1. 遍历其下面的所有后代。 
2. 计算祖先和每个后代之间的绝对差异。 
3. 跟踪发现的最大差异。 

这种方法是正确的，因为它明确地评估每个有效的祖先-后代对。 

然而，它的效率很低。 在最坏的情况下，每个节点可能会遍历几乎整个剩余的树。 对于一棵树来说`n`节点，这可能会导致大约：$$O(n^2)$$时间复杂度。 

对于多达 5000 个节点，二次行为的成本不必要地高。 

### 最佳解决方案的关键见解

 重要的观察是，对于任何节点，涉及该节点的最大差异仅取决于：

 - 其祖先中的最小值
 - 其祖先中的最大值

 假设我们当前正在访问一个有值的节点`x`。 

如果路径上的祖先包含的值范围为`minVal`到`maxVal`，那么最大可能的祖先差异涉及`x`必须是：$$\max(|x - minVal|,\ |x - maxVal|)$$我们不需要单独记住每一个祖先。 我们只需要沿着当前根到节点路径迄今为止看到的最小和最大值。 

这允许我们在携带以下内容时执行单个深度优先搜索遍历：

 - 当前最小祖先值
 - 当前最大祖先值

 在每个节点：

 - 使用当前最小值/最大值更新答案
 - 更新儿童的最小/最大
 - 继续递归

 这将解决方案缩短为线性时间。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(h) | 对于每个节点，遍历所有后代 |
 | 具有最小/最大跟踪的最佳 DFS | O(n) | O(h) | 追踪祖先范围时的单次遍历 |

 这里，`h`代表树的高度。 

## 算法演练

 ### 具有最小/最大跟踪的最佳 DFS

 1. 从根节点开始深度优先搜索。 

由于根没有祖先，因此将最小和最大祖先值初始化为根的值。 
2. 在每个节点，计算与当前祖先范围的差异。 

当前路径已经包含该节点的所有祖先。 涉及该节点的最大差异必须来自以下任一：

 - 最小祖先值
 - 最大祖先值

 计算：$$\max(|node.val - minVal|,\ |node.val - maxVal|)$$如果该值较大，则更新全局答案。 
3. 更新路径最小值和最大值。 

由于当前节点成为其下所有后代的祖先，因此更新：

 -`minVal = min(minVal, node.val)`-`maxVal = max(maxVal, node.val)`4. 递归处理左子树。 

向下传递更新的最小值和最大值。 
5. 递归处理右子树。 

再次传递更新后的范围。 
6. 当到达空节点时停止递归。 

空节点意味着路径已经结束，因此只需返回即可。 

### 为什么它有效

 该算法在 DFS 期间保持不变：

 -`minVal`是当前路径上所有祖先中的最小值
 -`maxVal`是当前路径上所有祖先中的最大值

 对于每个节点，最大可能的祖先差异必须涉及最小或最大祖先值。 由于每个根到节点的路径都被探索一次，因此隐式地考虑了每个有效的祖先-后代对。 

因此，该算法正确地计算了整棵树的最大差异。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def maxAncestorDiff(self, root: Optional[TreeNode]) -> int:
        self.answer = 0

        def dfs(node: Optional[TreeNode], current_min: int, current_max: int) -> None:
            if not node:
                return

            current_difference = max(
                abs(node.val - current_min),
                abs(node.val - current_max)
            )

            self.answer = max(self.answer, current_difference)

            updated_min = min(current_min, node.val)
            updated_max = max(current_max, node.val)

            dfs(node.left, updated_min, updated_max)
            dfs(node.right, updated_min, updated_max)

        dfs(root, root.val, root.val)

        return self.answer
```该实现使用递归 DFS 只遍历树一次。 

变量`self.answer`存储在所有路径上全局找到的最佳结果。 

辅助函数`dfs`收到三条信息：

 - 当前节点
 - 当前路径上的最小祖先值
 - 当前路径上的最大祖先值

 在每个节点，代码计算节点值与当前祖先范围之间的最大差异。 

然后更新路径范围，以便当前节点成为祖先集的一部分，以进行更深层次的递归调用。 

递归自然地探索每条根到节点的路径，这保证了所有祖先-后代关系都被考虑。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func maxAncestorDiff(root *TreeNode) int {
    answer := 0

    var dfs func(node *TreeNode, currentMin int, currentMax int)

    dfs = func(node *TreeNode, currentMin int, currentMax int) {
        if node == nil {
            return
        }

        diff1 := abs(node.Val - currentMin)
        diff2 := abs(node.Val - currentMax)

        currentDifference := max(diff1, diff2)

        if currentDifference > answer {
            answer = currentDifference
        }

        updatedMin := min(currentMin, node.Val)
        updatedMax := max(currentMax, node.Val)

        dfs(node.Left, updatedMin, updatedMax)
        dfs(node.Right, updatedMin, updatedMax)
    }

    dfs(root, root.Val, root.Val)

    return answer
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}

func max(a int, b int) int {
    if a > b {
        return a
    }
    return b
}

func min(a int, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 

Go 不使用类成员变量，而是使用局部变量`answer`由递归闭包捕获。 

Go 不提供内置的`min`,`max`， 或者`abs`整数函数，因此辅助函数是手动实现的。 

Nil 指针通过以下方式显式处理：```go
if node == nil {
    return
}
```由于节点值最多为`100000`，整数溢出不是 Go 标准整数类型的问题。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(h) | 递归调用堆栈最多存储一条从根到叶的路径 |

 DFS 遍历一次处理每个节点，每次访问仅执行恒定的工作。 

空间复杂度取决于递归深度。 在平衡树中，高度约为`O(log n)`。 在完全倾斜的树的最坏情况下，高度变为`O(n)`。

 ## 边缘情况

 ### 完全倾斜的树

 每个节点只有一个子节点的树的行为类似于链表。 这很重要，因为递归深度等于节点数。 

有缺陷的实现可能会意外地低效地重新计算值，或者错误地处理长路径上的祖先跟踪。 

此实现可以正确处理倾斜树，因为它仅维护两个整数，即当前最小和最大祖先值，而不管树深度如何。 

### 所有节点值相等

 如果每个节点具有相同的值，则每个祖先-后代差异为零。 

某些实现在使用减法逻辑时意外地错误地初始化了答案或无法处理这种情况。 

该解决方案可以正常工作，因为每个计算出的差异都变为：```
abs(x - x) = 0
```并且全局最大值仍然为零。 

### 树深处的最大差异

 最大的差异可能不直接涉及根节点。 它可以完全发生在子树内。 

例如：```
      50
     /
    20
   /
  5
```这里的最大差异是`45`， 之间`50`和`5`。 

仅比较父子对的简单实现将会失败。 

该算法之所以成功，是因为它沿着递归路径携带整个祖先范围，而不仅仅是直接父值。
