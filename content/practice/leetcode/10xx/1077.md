[LeetCode 问题 1077](https://leetcode.com/problems/project-employees-iii/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们从两个数据库表中找到每个项目中最有经验的员工，`Project`和`Employee`。 这`Project`表包含一个映射`employee_id`到`project_id`s，指示哪些员工从事哪些项目。 这`Employee`表提供了每位员工的其他详细信息，包括`name`和`experience_years`。 

目标是为每个项目返回具有最大`experience_years`。 如果多名员工在同一项目中拥有最高经验，则必须将所有人都包括在内。 结果不需要按任何特定顺序。 

关于输入的要点：每个`employee_id`在`Project`表存在于`Employee`桌子。 中没有重复的行`Project`，并且每个员工的经验都是非负的。 重要的边缘情况包括只有一名员工的项目、具有相同经验值的员工以及具有相同最大经验的多名员工的项目。 

## 方法

 **暴力方法**首先需要加入`Project`表与`Employee`表以获得每个项目中每个员工的经验。 然后，对于每个项目，我们扫描其所有员工以找到最大体验，然后再进行一次选择与此最大体验匹配的所有员工。 虽然正确，但这种方法对于大型数据集来说效率较低，尤其是在使用多次扫描或嵌套循环的 SQL 中实现时，因为它需要多次扫描每个项目的员工列表。 

**最佳方法**利用单个连接和窗口函数。 通过加入`Project`和`Employee`在`employee_id`，我们有一个表包含`project_id`,`employee_id`， 和`experience_years`。 然后我们就可以使用SQL`MAX()`窗函数划分为`project_id`计算每个项目的最大经验。 最后，我们过滤员工经验与该最大值匹配的行。 这种方法非常高效，因为它避免了重复扫描并利用了 SQL 的分析功能。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(P * E) | O(P * E) | 加入每个项目，然后迭代两次：首先查找最大值，然后选择员工。 |
 | 最佳 | O(P * E) | O(P * E) | 使用窗口函数进行单连接，一次性计算每个项目的最大值并进行过滤。 |

 ## 算法演练

 1. 在之间执行内连接`Project`和`Employee`在`employee_id`得到一个组合表`project_id`,`employee_id`， 和`experience_years`。 
2. 对于每个`project_id`，计算最大值`experience_years`使用窗口函数。 这会附加一个新列`max_experience`到组合表的每一行。 
3. 过滤表以仅保留其中的行`experience_years`等于`max_experience`。 这些行对应于每个项目中最有经验的员工。 
4. 选择最终列`project_id`和`employee_id`来形成结果。 

**为什么有效：** 窗口函数确保对于每个项目，每一行都知道该项目中的最大经验。 按平等筛选可确保仅包含经验最高的员工。 无论有多少员工共享最大经验，这个不变量都成立。 

## Python 解决方案```python
import sqlite3
from typing import List, Tuple

def most_experienced_employees(conn: sqlite3.Connection) -> List[Tuple[int, int]]:
    query = """
    WITH ProjectExperience AS (
        SELECT 
            p.project_id,
            p.employee_id,
            e.experience_years,
            MAX(e.experience_years) OVER (PARTITION BY p.project_id) AS max_experience
        FROM Project p
        JOIN Employee e ON p.employee_id = e.employee_id
    )
    SELECT project_id, employee_id
    FROM ProjectExperience
    WHERE experience_years = max_experience
    """
    cursor = conn.cursor()
    cursor.execute(query)
    return cursor.fetchall()
```Python 实现使用`sqlite3`连接来执行 SQL 查询。 首先，它加入了`Project`和`Employee`表来获取经验信息。 窗口函数`MAX(...) OVER (PARTITION BY project_id)`有效计算每个项目的最大经验。 最后，它过滤员工经验与最大值匹配的行，并返回包含的元组的结果列表`project_id`和`employee_id`。 

## 解决方案```go
package main

import (
    "database/sql"
    _ "github.com/mattn/go-sqlite3"
)

func MostExperiencedEmployees(db *sql.DB) ([][2]int, error) {
    query := `
    WITH ProjectExperience AS (
        SELECT 
            p.project_id,
            p.employee_id,
            e.experience_years,
            MAX(e.experience_years) OVER (PARTITION BY p.project_id) AS max_experience
        FROM Project p
        JOIN Employee e ON p.employee_id = e.employee_id
    )
    SELECT project_id, employee_id
    FROM ProjectExperience
    WHERE experience_years = max_experience;
    `
    rows, err := db.Query(query)
    if err != nil {
        return nil, err
    }
    defer rows.Close()

    var results [][2]int
    for rows.Next() {
        var projectID, employeeID int
        if err := rows.Scan(&projectID, &employeeID); err != nil {
            return nil, err
        }
        results = append(results, [2]int{projectID, employeeID})
    }
    return results, nil
}
```Go 解决方案在结构上与 Python 解决方案类似。 它执行相同的 SQL 查询并将每一行扫描到固定大小的数组中`[2]int`代表`(project_id, employee_id)`。 主要区别在于显式处理错误以及使用切片动态收集结果。
