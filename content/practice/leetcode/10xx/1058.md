 **难度：** 🟡 中等

 ## 解决方案

 ## 问题理解

 该问题要求我们将十进制价格数组舍入为整数，以使舍入数字的总和等于给定目标，同时最小化总舍入误差。 每个价格都可以向下舍入（`Floor`) 或向上 (`Ceil`）。 每个价格的舍入误差定义为原始价格与其舍入值之间的绝对差，总舍入误差是这些单独误差的总和。 如果无法对数字进行舍入以精确满足目标，则该函数应返回“-1”。 

输入由一个字符串列表组成，每个字符串表示一个具有三位小数的十进制数和一个整数目标。 输出是一个表示最小可能舍入误差的字符串，格式为小数点后三位。 

约束告诉我们，价格数量相对较小（最多 500 个），而目标可能相当大（最多 1,000,000 个）。 这些限制表明，探索地板和天花板的所有组合的强力方法是不可行的，因为组合的数量呈指数级增长。 

重要的边缘情况包括已经是整数的价格、即使全部向上或向下舍入其总和也无法匹配目标的价格以及超出可能总和范围的目标。 

## 方法

 暴力方法将涉及生成每个价格的下限或上限的所有可能组合，并检查总和是否与目标匹配。 对于每个有效组合，我们将计算总舍入误差并返回最小值。 这种方法是正确的，但在计算上不可行，因为它需要评估`2^n`组合为`n`价格，对于`n = 500`。 

实现最佳解决方案的关键观察是每个价格只能贡献其下限或上限。 如果我们将所有楼层和所有天花板相加，则楼层之和给出可能的最小总和，而天花板之和给出可能的最大总和。 如果目标在这个范围之外，就不可能达到目标，我们可以立即返回“-1”。 否则，我们可以根据价格的小数部分对价格进行排序，并选择对具有最大小数部分的价格进行四舍五入，以达到目标，同时最小化舍入误差。 这是一种经典的贪婪方法，其中将最大小数部分向上舍入可以最大限度地减少总误差。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成所有地板/天花板组合； 对于 n=500 不可​​行 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 按小数部分贪婪舍入以满足目标 |

 ## 算法演练

 1. 将每个价格字符串转换为浮点数以供计算，并将其分为整数下限部分和小数部分。 小数部分表示该数字与其下限之间的差值。 
2. 计算所有楼层的总和，即可实现的最小总和。 
3. 计算所有上限的总和，这代表可实现的最大总和。 
4.检查目标是否可以实现。 如果`target < sum_floors`或者`target > sum_ceilings`，立即返回“-1”。 
5. 计算有多少个价格需要向上取整（`ceil_count`）准确地达到目标。 这是`target - sum_floors`。 
6. 按小数部分降序对价格进行排序，小数部分最大的数字首先向上舍入。 这可以最大限度地减少总舍入误差。 
7. 通过对差值求和来计算总舍入误差。 对于每一个第一个`ceil_count`按排序顺序的价格添加上限误差（`1 - fractional_part`）。 对于其余价格，添加下限误差 (`fractional_part`）。 
8. 返回格式为小数点后三位的总舍入误差。 

这种方法之所以有效，是因为将最大的小数部分向上舍入会引入最小的增量误差，而将最小的小数部分向下舍入则会增加最小的可能误差。 将最大小数部分向上舍入的贪婪选择保证了在满足目标的同时总舍入误差最小。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimizeError(self, prices: List[str], target: int) -> str:
        floors = []
        fractional_parts = []
        sum_floors = 0
        
        for price in prices:
            value = float(price)
            floor_val = int(value)
            frac = value - floor_val
            floors.append(floor_val)
            fractional_parts.append(frac)
            sum_floors += floor_val
        
        ceil_count = target - sum_floors
        if ceil_count < 0 or ceil_count > len(prices):
            return "-1"
        
        fractional_parts.sort(reverse=True)
        
        error = 0.0
        for i, frac in enumerate(fractional_parts):
            if i < ceil_count:
                error += 1 - frac if frac > 0 else 0
            else:
                error += frac
        
        return f"{error:.3f}"
```该代码首先将价格字符串转换为浮点数，计算每个浮点数的下限，并记录小数部分。 它使用楼层总和检查是否可以实现目标。 然后，它计算必须向上舍入的价格数量，并对小数部分进行排序，以贪婪地最小化错误。 最后，它根据价格是向上舍入还是向下舍入来汇总舍入误差。 

## 解决方案```go
import (
    "fmt"
    "sort"
    "strconv"
)

func minimizeError(prices []string, target int) string {
    n := len(prices)
    floors := make([]int, n)
    fractions := make([]float64, n)
    sumFloors := 0
    
    for i, p := range prices {
        value, _ := strconv.ParseFloat(p, 64)
        floorVal := int(value)
        frac := value - float64(floorVal)
        floors[i] = floorVal
        fractions[i] = frac
        sumFloors += floorVal
    }
    
    ceilCount := target - sumFloors
    if ceilCount < 0 || ceilCount > n {
        return "-1"
    }
    
    sort.Slice(fractions, func(i, j int) bool {
        return fractions[i] > fractions[j]
    })
    
    error := 0.0
    for i, frac := range fractions {
        if i < ceilCount {
            if frac > 0 {
                error += 1 - frac
            }
        } else {
            error += frac
        }
    }
    
    return fmt.Sprintf("%.3f", error)
}
```在 Go 中，该方法类似于 Python：将字符串解析为浮点数，计算下限和分数，检查目标是否可实现，并对小数部分进行排序。 Go 需要使用显式浮点解析和格式化`strconv`和`fmt.Sprintf`。 

## 工作示例

 **示例1：**`prices = ["0.700","2.800","4.900"], target = 8`| 价格| 楼层| 分数| 圆形|
 | ---| ---| ---| ---|
 | 0.700 | 0 | 0.7 | 0.7 天花板 → 1 |
 | 2.800 | 2.800 2 | 0.8 | 0.8 天花板 → 3 |
 | 4.900 | 4.900 4 | 0.9 | 0.9 楼层 → 4 |

 楼层总和 = 0+2+4=6

 目标 = 8 → ceil_count = 8-6 = 2

 按降序排列分数：0.9、0.8、0.7

 圆顶 2 个分数向上：0.9→Ceil、0.8→Ceil、0.7→Floor

 舍入误差：(1-0.7) + (3-2.8) + (4-4.9) = 0.3 + 0.2 + 0.9 = 1.0

 返回`"1.000"`**示例2：**`prices = ["1.500","2.500","3.500"], target = 10`楼层总和 = 1+2+3=6，天花板总和 = 2+3+4=9

 目标 = 10 → 不可能

 返回`"-1"`**示例3：**`prices = ["1.500","2.500","3.500"], target = 9`楼层总数 = 6

 目标 = 9 → ceil_count = 3

 按降序排列分数：0.5、0.5、0.5

 前 3 个分数向上舍入 → 全部向上舍入

 舍入误差 = (2-1.5) + (3-2.5) + (4-3.5) = 0.5 + 0.5 + 0.5 = 1.5

 返回`"1.500"`## 复杂度分析
