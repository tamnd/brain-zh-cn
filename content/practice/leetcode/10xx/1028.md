[LeetCode 问题 1028](https://leetcode.com/problems/recover-a-tree-from-preorder-traversal/)

 **难度：** 🔴难
 **主题：** 字符串、树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 问题提供了一个字符串`traversal`表示二叉树的前序深度优先遍历，其中每个节点由其前面的值表示`D`破折号，与`D`是树中节点的深度。 根节点有深度`0`并且前面没有任何破折号。 如果一个节点只有一个子节点，则保证它是左子节点。 我们的任务是通过这次遍历重建原始二叉树并返回根。 

输入字符串通过破折号和值隐式对树结构进行编码。 例如，`"1-2--3--4-5--6--7"`代表一棵树，其中`1`是根，`2`是它的左孩子，`5`是它的右子节点，依此类推，更深的节点由越来越多的破折号表示。 约束告诉我们最多可以有 1000 个节点，节点值最多为`10^9`。 这确保了将值解析为整数是可行的，并且我们需要一种有效的算法来处理最多 1000 个节点而不超过时间限制。 

重要的边缘情况包括节点仅具有左子节点的字符串、具有大整数的字符串或在不同深度连续出现而没有右子节点的节点。 该问题保证了遍历字符串按照规则是有效的，因此我们不需要处理格式错误的输入。 

## 方法

 暴力方法涉及解析字符串，提取每个节点的深度和值，然后通过将当前深度与子节点的预期深度进行比较，将每个节点递归地插入到树中。 这可以正常工作，但可能涉及重复扫描或回溯以找到每个节点的正确父节点，从而导致时间复杂度不理想。 

最佳方法利用**堆栈**来维护从根到当前节点的路径。 在迭代遍历字符串时，我们确定每个节点的深度和值。 如果当前节点的深度大于堆栈大小，则它是堆栈顶部节点的左子节点。 如果深度小于或等于，我们弹出节点直到堆栈大小等于当前深度，然​​后将该节点附加为右子节点。 这保证了我们始终在线性时间内保持正确的父子关系。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 按深度递归插入每个节点； 可能需要反复扫描祖先|
 | 最佳 | O(n) | O(n) | 使用堆栈来追踪祖先； 根据堆栈深度将节点附加为左/右子节点 |

 ## 算法演练

 1. 初始化一个空堆栈，该堆栈将保存与从根到当前节点的当前路径对应的节点。 
2. 使用索引指针迭代遍历字符串。 
3. 对于每个节点，首先计算连续破折号的数量以确定其深度。 
4. 然后解析破折号后面的整数值。 
5. 当堆栈长度大于当前深度时，从堆栈中弹出节点。 这确保了堆栈顶部始终是新节点的父节点。 
6. 创建一个新的`TreeNode`与解析的值。 
7. 如果堆栈不为空，则检查堆栈顶部的父级。 如果父节点没有左子节点，则将新节点附加为左子节点； 否则，将其附加为右子节点。 
8. 将新节点压入堆栈。 
9. 重复步骤3-8，直到解析整个字符串。 
10. 树的根是第一个压入堆栈的节点。 

**为什么起作用：** 堆栈不变式确保在任何时候，堆栈都包含从根到当前深度的节点链。 通过维护这个属性，我们可以正确地将新节点附加为左子节点或右子节点，而无需回溯。 每个节点只处理一次，保证正确性和效率。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def recoverFromPreorder(self, traversal: str) -> Optional[TreeNode]:
        stack = []
        i = 0
        n = len(traversal)
        while i < n:
            depth = 0
            while i < n and traversal[i] == '-':
                depth += 1
                i += 1
            val_start = i
            while i < n and traversal[i].isdigit():
                i += 1
            val = int(traversal[val_start:i])
            node = TreeNode(val)
            while len(stack) > depth:
                stack.pop()
            if stack:
                parent = stack[-1]
                if not parent.left:
                    parent.left = node
                else:
                    parent.right = node
            stack.append(node)
        return stack[0] if stack else None
```在这个实现中，我们使用了一个指针`i`迭代遍历字符串。 我们首先计算破折号以确定深度，然后解析数字。 通过维护祖先堆栈，我们确保正确的父子关系，当当前深度表明我们需要回溯时弹出节点。 每个节点都被压入堆栈一次。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func recoverFromPreorder(traversal string) *TreeNode {
    stack := []*TreeNode{}
    n := len(traversal)
    i := 0
    for i < n {
        depth := 0
        for i < n && traversal[i] == '-' {
            depth++
            i++
        }
        valStart := i
        for i < n && traversal[i] >= '0' && traversal[i] <= '9' {
            i++
        }
        val := 0
        for j := valStart; j < i; j++ {
            val = val*10 + int(traversal[j]-'0')
        }
        node := &TreeNode{Val: val}
        for len(stack) > depth {
            stack = stack[:len(stack)-1]
        }
        if len(stack) > 0 {
            parent := stack[len(stack)-1]
            if parent.Left == nil {
                parent.Left = node
            } else {
                parent.Right = node
            }
        }
        stack = append(stack, node)
    }
    if len(stack) > 0 {
        return stack[0]
    }
    return nil
}
```Go 版本反映了 Python 逻辑。 而不是使用`int()`为了进行解析，我们手动将字符转换为整数。 切片用于堆栈，并且`nil`检查取代Python的`None`。 该算法保持相同的堆栈不变性和基于深度的逻辑。
