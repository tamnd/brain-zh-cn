 ## 解决方案

 ## 问题理解

 该问题提出了沿着一维 X 轴放置在不同位置的三块石头，用整数表示`a`,`b`， 和`c`。 移动包括从端点之一（最左边或最右边的石头）取出一颗棋子，并将其严格放置在端点之间的空闲位置。 目标是确定两个数字：使棋子占据三个连续位置所需的最小移动次数，以及相同规则下可能的最大移动次数。 

输入保证三个位置不同并且范围在 1 到 100 之间，这使得暴力破解原则上可行，但该问题旨在测试洞察力而不是模拟。 输出始终是两个整数的列表`[min_moves, max_moves]`。 

重要的边缘情况包括已经连续的棋子、仅间隔一个空位置的棋子或间隔很远的棋子。 这些情况对最小和最大移动的影响不同，因此需要仔细分析。 

## 方法

 暴力方法将递归地模拟所有可能的移动，将端点移动到它们之间的所有有效位置，直到棋子是连续的。 虽然这保证了正确性，但对于这个问题来说这是不必要的，因为位置仅限于三颗棋子。 模拟将涉及检查所有组合，这有点过分了。 

关键的见解是，只有三块石头，它们之间的间隙直接决定了答案。 让`x < y < z`是排序后的位置。 定义`gap1 = y - x - 1`和`gap2 = z - y - 1`。 最小移动次数通过检查间隙是否为 1 或 0 来确定：如果一颗棋子距离连续移动仅一步之遥，则最小值为 1； 如果两个间隙都大于 1，则最小值为 2。 最大移动次数就是一次移动一步来填补间隙，即移动石子的总和`gap1 + gap2`。

 ## 算法演练

 1. **对位置进行排序**：通过排序找出最左边、中间、最右边的石头`a`,`b`， 和`c`。 让`x = min(a,b,c)`,`z = max(a,b,c)`， 和`y`剩余的中间值。 排序简化了间隙计算。 
2. **计算间隙**：计算`gap1 = y - x - 1`和`gap2 = z - y - 1`。 这些代表棋子之间空位置的数量。 
3. **确定最少移动**：如果有的话`gap1`或者`gap2`如果是零（棋子是连续的）或一（一格是空的），则只需要移动一步就可以使棋子连续。 否则，如果两个间隙都大于 1，则需要两次移动，从端点移动棋子以填充间隙。 
4. **确定最大移动次数**：一次移动一颗棋子占据中间位置时出现的最大移动次数。 这只是总和`gap1 + gap2`。 
5. **返回结果**：返回一个列表`[min_moves, max_moves]`。 

**为什么有效**：排序顺序确保`x`和`z`始终是端点，间隙恰好代表要填充的空位置。 游戏规则限制移动到端点，因此最小和最大移动完全由间隙决定。 这保证了无需模拟的正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def numMovesStones(self, a: int, b: int, c: int) -> List[int]:
        x, y, z = sorted([a, b, c])
        gap1 = y - x - 1
        gap2 = z - y - 1
        
        if gap1 == 0 and gap2 == 0:
            min_moves = 0
        elif gap1 <= 1 or gap2 <= 1:
            min_moves = 1
        else:
            min_moves = 2
        
        max_moves = gap1 + gap2
        return [min_moves, max_moves]
```**说明**：代码首先对棋子位置进行排序，以简化间隙计算。 然后它计算连续棋子之间的空位置数。 最小移动量是通过检查间隙是零还是一来确定的； 最大移动量是间隙的总和。 该函数以列表形式返回结果，满足问题要求。 

## 解决方案```go
func numMovesStones(a int, b int, c int) []int {
    // sort a, b, c
    x, y, z := a, b, c
    if x > y { x, y = y, x }
    if y > z { y, z = z, y }
    if x > y { x, y = y, x }
    
    gap1 := y - x - 1
    gap2 := z - y - 1
    
    minMoves := 0
    if gap1 == 0 && gap2 == 0 {
        minMoves = 0
    } else if gap1 <= 1 || gap2 <= 1 {
        minMoves = 1
    } else {
        minMoves = 2
    }
    
    maxMoves := gap1 + gap2
    return []int{minMoves, maxMoves}
}
```**说明**：Go 版本使用成对交换手动对三个整数进行排序。 间隙计算以及最小和最大移动的逻辑反映了 Python 版本。 结果以整数切片的形式返回。
