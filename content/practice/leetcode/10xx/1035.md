[LeetCode 1035 题](https://leetcode.com/problems/uncrossed-lines/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 该问题给了我们两个整数数组，`nums1`和`nums2`。 我们可以在两个数组中的匹配值之间画线，但有一个重要的限制：线不能相互交叉。 

一条线只能连接`nums1[i]`和`nums2[j]`当值相等时。 号码一旦在连接中使用，就不能再次使用。 目标是最大化有效、非交叉连接的总数。 

关键的观察结果是，当两个数组之间所选元素的相对顺序不同时，就会发生交叉。 假设我们连接：

 -`nums1[i]`到`nums2[j]`-`nums1[k]`到`nums2[l]`如果`i < k`，那么我们还必须有`j < l`以避免交叉路口。 这意味着匹配的元素必须以相同的相对顺序出现在两个数组中。 

这正是最长公共子序列问题的定义。 子序列保留顺序，同时允许跳过元素。 因此，最大不交叉线数相当于求两个数组之间的最长公共子序列的长度。 

输入约束很重要：

 - 每个数组长度最多为`500`- 值范围为`1`到`2000`由于数组相对较小，`O(m * n)`动态规划解决方案是实用的，其中`m`和`n`是数组的长度。 然而，指数暴力解决方案会太慢。 

有几种边缘情况值得考虑：

 - 没有匹配值的数组应该返回`0`- 每个值都匹配的数组应返回较小数组的完整长度
 - 重复的值会产生多种匹配可能性，因此贪婪匹配是不安全的
 - 长度非常小的数组`1`仍必须正常工作
 - 顺序很重要，即使数组包含相同的数字

 ## 方法

 ### 蛮力方法

 强力解决方案将尝试一切可能的方式来匹配两个数组之间的元素，同时确保线不交叉。 

对于中的每个元素`nums1`，我们可以：

 - 跳过它
 - 将其与中的一些有效出现相匹配`nums2`这将创建一个递归决策树。 在每一步中，我们都会探索多种可能性并跟踪有效连接的最大数量。 

蛮力方法是正确的，因为它最终会探索每一种可能的有效匹配安排。 然而，组合的数量呈指数增长。 数组长度可达`500`，这变得完全不切实际。 

主要问题是子问题重叠。 重复重新计算相同后缀对的数组。 

### 最优动态规划方法

 关键的见解是该问题与最长公共子序列问题相同。 

如果两个匹配对交叉，则它们在数组之间的顺序会有所不同。 因此，任何有效的未交叉线集都必须保留两个数组中的相对顺序。 这正是公共子序列的作用。 

我们定义：

 -`dp[i][j]`作为未交叉线的最大数量，使用：

 - 首先`i`的元素`nums1`- 第一的`j`的元素`nums2`过渡是：

 - 如果`nums1[i - 1] == nums2[j - 1]`- 我们可以连接它们
 -`dp[i][j] = dp[i - 1][j - 1] + 1`- 否则：

 - 从任一数组中跳过一个元素
 -`dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`这避免了重新计算并有效地自下而上地构建答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(m+n)) | O(2^(m+n)) | O(m+n) | 递归探索所有匹配的可能性 |
 | 最佳| O(m * n) | O(m * n) | 基于最长公共子序列的动态规划|

 ## 算法演练

 1. 创建一个二维动态规划表，名为`dp`。 

桌子有尺寸`(len(nums1) + 1) x (len(nums2) + 1)`。 额外的填充简化了边界处理，因为行`0`和列`0`代表空前缀。 
2. 解释`dp[i][j]`。`dp[i][j]`存储可以使用以下方式形成的最大未交叉线数：

 - 第一个`i`的元素`nums1`- 第一个`j`的元素`nums2`3. 迭代两个数组。 

使用嵌套循环：

 - 外循环结束`nums1`- 内循环结束`nums2`在每对位置，决定是否应连接当前元素。 
4. 处理匹配值。 

如果`nums1[i - 1] == nums2[j - 1]`，那么这两个数可以构成一条有效的线。 

由于添加此行可以保留顺序，因此我们从较小的前缀扩展了最佳解决方案：$dp[i][j] = dp[i-1][j-1] + 1$5. 处理不匹配的值。 

If the numbers differ, we cannot connect them directly.

 相反，我们选择以下更好的一个：

 - 跳过当前元素`nums1`- 跳过当前元素`nums2`

$dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$6. 继续逐行填充表格。 

每个单元仅取决于先前计算的单元，因此该表自然会朝着最终解决方案构建。 
7. 返回右下角的值。`dp[len(nums1)][len(nums2)]`包含整个数组的最大未交叉线数。 

### 为什么它有效

 动态规划公式之所以有效，是因为每个有效的非交叉匹配都必须保留相对顺序。 当两个元素匹配时，我们可以安全地扩展较小的最佳解决方案，而无需创建交叉。 当它们不匹配时，必须从最优解中至少排除一个元素。 由于递归考虑了所有此类可能性并存储最优子问题结果，因此保证最终答案是最优的。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxUncrossedLines(self, nums1: List[int], nums2: List[int]) -> int:
        rows = len(nums1)
        cols = len(nums2)

        dp = [[0] * (cols + 1) for _ in range(rows + 1)]

        for i in range(1, rows + 1):
            for j in range(1, cols + 1):
                if nums1[i - 1] == nums2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[rows][cols]
```实现首先确定两个数组的大小。 然后我们分配一个用零初始化的二维动态规划表。 

额外的行和列简化了空前缀的处理。 例如，`dp[0][j]`表示一个数组为空，因此无法绘制任何线条。 

嵌套循环处理每对位置：

 - 如果当前值匹配，我们将前一个对角线结果加一。 
- 否则，我们将继承以下任一者的最佳答案：

 - 排除当前元素`nums1`- 排除当前元素`nums2`最后，右下角的单元格包含完整数组的最佳答案。 

## 解决方案```go
func maxUncrossedLines(nums1 []int, nums2 []int) int {
	rows := len(nums1)
	cols := len(nums2)

	dp := make([][]int, rows+1)
	for i := range dp {
		dp[i] = make([]int, cols+1)
	}

	for i := 1; i <= rows; i++ {
		for j := 1; j <= cols; j++ {
			if nums1[i-1] == nums2[j-1] {
				dp[i][j] = dp[i-1][j-1] + 1
			} else {
				if dp[i-1][j] > dp[i][j-1] {
					dp[i][j] = dp[i-1][j]
				} else {
					dp[i][j] = dp[i][j-1]
				}
			}
		}
	}

	return dp[rows][cols]
}
```Go 实现遵循与 Python 解决方案相同的动态编程逻辑。 

由于 Go 不提供像 Python 列表推导式那样的内置 2D 数组初始化快捷方式，因此我们使用显式分配每一行`make`。 

Go 切片自然会正确处理空数组，因此不需要特殊的边缘情况处理。 整数溢出不是问题，因为最大可能的答案只是`500`。

 ## 边缘情况

 ### 没有匹配元素的数组

 如果两个数组没有共同值，则正确答案是`0`。 这种情况可能会暴露算法错误地增加匹配或错误处理初始化的错误。 

例如：```
nums1 = [1,2,3]
nums2 = [4,5,6]
```每个 DP 转换都会落入非匹配分支，因此所有单元都保留`0`。 该实现通过递归关系自然地处理这个问题。 

### 具有许多重复值的数组

 重复值对于贪婪方法来说是危险的，因为匹配第一个可用的出现并不总是最佳的。 

例如：```
nums1 = [1,1,1]
nums2 = [1,1]
```最优答案是`2`， 不是`1`。 

DP解决方案正确地探索所有前缀组合并自动选择最佳排列。 

### 逆序数组

 包含相同值但顺序相反的数组很重要，因为它们说明了顺序为何如此重要。 

例子：```
nums1 = [1,2,3]
nums2 = [3,2,1]
```即使两个数组中都存在所有值，也只能绘制一条不交叉的线。 任何连接更多的尝试都会造成交叉。 

动态规划方法通过其子序列结构正确地强制执行顺序保留。
