## 问题理解

 该问题要求我们从给定的**前序遍历**数组构造一个**二叉搜索树（BST）**。 前序遍历被定义为首先访问根节点，然后递归地访问左子树，然后是右子树。 在 BST 中，对于每个节点，左子树中的值严格小于该节点的值，而右子树中的值严格大于该节点的值。 

输入`preorder`是表示 BST 的前序遍历的唯一整数列表。 我们的任务是重建 BST 并返回其根节点。 例如，给定`[8,5,1,7,10,12]`，第一个值`8`成为根，那么`5`被放置在左子树中，`10`在右子树中，依此类推。 

约束表明`preorder`最多有 100 个值从 1 到 1000 的元素。所有值都是唯一的，这简化了处理重复项。 

重要的边缘情况包括非常小的数组（长度为 1 或 2）、严格递增或递减序列（创建倾斜树）以及可能导致节点只有一个子节点的数组。 该问题保证任何输入数组都存在有效的 BST。 

## 方法

 ### 蛮力

 一个简单的方法是递归地插入每个元素`preorder`进入 BST。 从第一个元素开始作为根。 对于每个后续值，从根开始遍历树，比较值，直到找到正确的插入点。 这是可行的，因为按预序将值插入 BST 自然会保留 BST 属性。 

然而，这种方法效率低下，因为如果树倾斜，每次插入可能会花费 O(n) 时间，导致最坏情况下的时间复杂度为 O(n²)。 对于较大的输入来说，这是不必要的开销。 

### 最佳方法

 关键的观察是，前序遍历本质上为左子树和右子树提供了**单调属性**。 第一个元素是根。 所有小于根的后续元素都属于左子树，第一个大于根的元素标记右子树的开始。 利用这个属性，我们可以使用有界递归或基于堆栈的单调方法有效地构建树。 

**基于堆栈的方法**可以在 O(n) 时间内有效地构建 BST。 我们迭代`preorder`，维护祖先堆栈。 对于每个新值，我们通过从堆栈中弹出来找到其父节点，直到顶部的值大于当前节点。 这确保了 BST 中的正确放置。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 将每个节点按顺序插入 BST，对于倾斜树来说效率低下 |
 | 最佳| O(n) | O(n) | 基于堆栈的构造或有界递归，线性扫描确保正确放置 |

 ## 算法演练

 1. 初始化一个空栈来跟踪从根到当前节点的路径。 
2. 取第一个元素`preorder`作为根节点并将其压入堆栈。 
3. 迭代剩余元素`preorder`。 
4. 对于每个元素，创建一个新节点。 
5. 如果该元素小于栈顶，则它成为栈顶节点的左子节点。 将其推入堆栈。 
6. 如果该元素大于栈顶，则从栈中弹出节点，直到栈顶节点的值大于该元素。 最后弹出的节点成为父节点，新节点是其右子节点。 将新节点压入堆栈。 
7. 继续，直到处理完所有元素。 返回根。 

**为什么有效：** 堆栈维护从根到当前插入点的路径。 通过弹出节点直到找到合适的父节点，我们确保保留 BST 属性，并且每个节点都正确放置在其左子树或右子树中。 这保证了从前序遍历中正确重建 BST。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def bstFromPreorder(self, preorder: list[int]) -> 'Optional[TreeNode]':
        if not preorder:
            return None
        
        root = TreeNode(preorder[0])
        stack = [root]
        
        for value in preorder[1:]:
            node = TreeNode(value)
            if value < stack[-1].val:
                stack[-1].left = node
            else:
                parent = None
                while stack and stack[-1].val < value:
                    parent = stack.pop()
                parent.right = node
            stack.append(node)
        
        return root
```Python 实现初始化根和堆栈，然后迭代预序列表。 对于每个值，它根据堆栈的状态确定是否将该节点附加为左子节点或右子节点。 从堆栈中弹出可确保为正确的子级找到正确的父级，从而保留 BST 属性。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func bstFromPreorder(preorder []int) *TreeNode {
    if len(preorder) == 0 {
        return nil
    }
    
    root := &TreeNode{Val: preorder[0]}
    stack := []*TreeNode{root}
    
    for _, val := range preorder[1:] {
        node := &TreeNode{Val: val}
        if val < stack[len(stack)-1].Val {
            stack[len(stack)-1].Left = node
        } else {
            var parent *TreeNode
            for len(stack) > 0 && stack[len(stack)-1].Val < val {
                parent = stack[len(stack)-1]
                stack = stack[:len(stack)-1]
            }
            parent.Right = node
        }
        stack = append(stack, node)
    }
    
    return root
}
```Go 的实现与 Python 非常相似。 切片操作用于堆栈，nil 表示空子指针。 查找父节点的逻辑是一样的，保持正确性。

 | 4 | [8,5,7] | 7 > 1 → pop 1, 7 > 5 → pop 5 → 7 成为 5 的右孩子 |
 | 5 | [8,10] | 10 > 7 → pop 7, 10 > 8 → pop 8 → 10 成为 8 的右孩子 |
 | 6 | [10,12]| 12 > 10 → 10 的右子 |

 ### 示例 2：`[1,3]`| 步骤| 堆栈| 行动|

 | 1 | [1] | 根 1 |
 | 2 | [1,3]| 3 > 1 → pop 1 → 3 成为 1 的右孩子 |

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都从堆栈中压入和弹出一次 |
 | 空间| O(n) | 最坏情况下栈最多可以存储n个节点（完全倾斜的树） |

 线性时间复杂度的产生是因为每个节点只处理一次并且最多涉及恒定数量的堆栈操作。 空间以堆栈为主。
