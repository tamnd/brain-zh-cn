[LeetCode 问题 1047](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/)

 **难度：** 🟢简单
 **主题：** 字符串、堆栈

 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅包含小写英文字母。 我们反复查找两个相等的相邻字符，将它们都删除，并继续此过程，直到不存在这样的相邻重复对。 

重要的细节是，删除可以创建以前不相邻的新的相邻重复项。 例如，在字符串中`"abbaca"`，去除`"bb"`产生`"aaca"`，然后包含`"aa"`作为新的相邻重复对。 移除后`"aa"`，最终结果变为`"ca"`。 

任务是在完成所有可能的重复删除后返回最终字符串。 该问题保证最终答案是唯一的，无论执行删除的顺序如何。 

输入大小可以大到`10^5`人物。 这个约束立即告诉我们，低效的重复字符串重建方法可能会变得太慢。 由于字符串在 Python 中是不可变的，并且在许多语言中重复修改的成本很高，因此我们需要一种在可能的情况下在单次传递中有效处理字符串的方法。 

尽早识别一些边缘情况很重要：

 - 没有相邻重复项的字符串应保持不变。 
- 每个字符最终消失的字符串应返回空字符串。 
- 删除一对可能会创建另一对可删除的。 
- 长时间重复的字符，例如`"aaaa"`，需要重复的折叠行为。 
- 最小的有效输入有长度`1`，它永远不能包含重复项。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是重复扫描字符串以查找相邻的重复字符。 每当我们找到这样的一对时，我们就会将其删除并从头开始扫描。 

例如：

-`"abbaca"`- 消除`"bb"`→`"aaca"`- 消除`"aa"`→`"ca"`这种方法之所以有效，是因为最终所有可移除的对都被消除了。 然而，每次删除都会创建一个全新的字符串，我们可能会重复地重新扫描大部分输入。 

在最坏的情况下，每次移除操作的成本`O(n)`时间，因为必须重建字符串，并且我们可能会执行最多`O(n)`搬迁。 这导致了二次复杂度。 

和`n`最多`100000`， 一个`O(n^2)`解决办法太慢了。 

### 最优方法，堆栈模拟

 关键的观察结果是该问题的行为与堆栈取消完全相同。 

当我们从左到右处理字符时：

 - 如果当前字符与堆栈顶部匹配，我们将删除顶部元素而不是添加当前字符。 
- 否则，我们将当前字符压入堆栈。 

这是有效的，因为相邻的重复项总是与最近保留的角色在本地交互。 

例如：

 - 堆栈：`['a']`- 读`'b'`→ 推
 - 堆栈：`['a', 'b']`- 读`'b'`→ 匹配上衣、流行音乐
 - 堆栈：`['a']`处理完到目前为止看到的字符后，堆栈始终表示当前有效的字符串。 

由于每个字符最多被压入和弹出一次，因此该算法以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 反复扫描并重建字符串 |
 | 最佳 | O(n) | O(n) | 使用堆栈处理每个字符一次 |

 ## 算法演练

 ### 最优堆栈算法

 1. 初始化一个空堆栈。 

堆栈将存储到目前为止处理重复删除后剩余的字符。 
2. 迭代输入字符串中的每个字符。 

我们从左到右处理字符串，因为相邻关系仅取决于附近的字符。 
3. 对于每个字符，检查堆栈顶部。 

如果堆栈不为空并且顶部字符等于当前字符，那么我们就找到了相邻的重复对。 
4. 删除重复的对。 

不添加当前字符，而是从堆栈中弹出顶部字符。 这模拟删除两个相邻的重复字符。 
5. 否则，将当前字符压入堆栈。 

如果当前字符与栈顶不匹配，则此时无法形成可移动的相邻对。 
6. 继续，直到处理完所有字符。 

堆栈现在包含所有删除后的最终有效字符串。 
7. 将堆栈转换回字符串。 

连接堆栈中的所有字符并返回结果。 

### 为什么它有效

 堆栈始终存储到目前为止检查的字符串前缀的完全处理结果。 每当一个新字符与堆栈顶部匹配时，这两个字符将成为最终字符串中的相邻重复字符，因此立即删除它们是正确的。 由于每次取消都会在可能的情况下进行准确处理，因此堆栈状态始终与正确的中间字符串匹配。 遍历结束时，不会留下任何相邻的重复项。 

## Python 解决方案```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack: list[str] = []

        for char in s:
            if stack and stack[-1] == char:
                stack.pop()
            else:
                stack.append(char)

        return "".join(stack)
```该实现使用列表作为堆栈，因为 Python 列表在末尾支持高效的追加和弹出操作。 

变量`stack`存储迄今为止处理重复删除后剩余的字符。 

迭代期间：

 -`stack[-1]`访问顶部元素。 
- 如果当前字符与顶部匹配，我们使用删除顶部`pop()`。 
- 否则，我们使用添加字符`append()`。 

最后，堆栈按顺序包含最后剩余的字符，因此`"".join(stack)`将其转换回所需的字符串。 

该实现直接遵循前面描述的算法并保证线性时间复杂度。 

## 解决方案```go
func removeDuplicates(s string) string {
    stack := make([]byte, 0)

    for i := 0; i < len(s); i++ {
        current := s[i]

        if len(stack) > 0 && stack[len(stack)-1] == current {
            stack = stack[:len(stack)-1]
        } else {
            stack = append(stack, current)
        }
    }

    return string(stack)
}
```Go 实现使用字节片作为堆栈，因为输入仅包含小写英文字母。 

与 Python 列表不同，Go 切片需要显式切片来删除最后一个元素：```go
stack = stack[:len(stack)-1]
```附加使用内置`append`功能。 

最终的字节片使用以下命令转换回字符串：```go
string(stack)
```由于输入仅包含 ASCII 小写字母，因此使用字节既正确又高效。

 ## 边缘情况

 ### 单字符输入

 长度为 1 的字符串永远不能包含相邻的重复项。 假设存在对的简单实现可能会意外访问无效索引或执行不必要的操作。 

基于堆栈的解决方案可以自然地处理这个问题。 单个字符被推送一次并原封不动地返回。 

### 整个字符串消失

 输入如`"aa"`或者`"abba"`最终删除每个字符。 一些实现错误地返回`None`或者将空结构转换回字符串时失败。 

此实现正确返回空字符串，因为加入空堆栈会产生`""`。 

### 级联重复创建

 最重要的边缘情况是移除一对会创建另一对可移除的情况。 例如：```
"abccba"
```去除`"cc"`创造`"abba"`，然后创建`"aa"`删除后`"bb"`。 

没有回溯的简单单遍方法在这里会失败。 堆栈自动解决了这个问题，因为在弹出操作之后，新的顶部元素立即可用于与未来的字符进行比较。
