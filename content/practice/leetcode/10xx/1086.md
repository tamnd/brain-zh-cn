[LeetCode 第 1086 题](https://leetcode.com/problems/high- Five/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定列表中每个学生的前五名平均分`[ID, score]`对。 每个`ID`代表一个独特的学生，并且`score`代表他们收到的单个分数。 目标是返回一个列表`[ID, topFiveAverage]`对，其中`topFiveAverage`计算方法是将学生的 5 个最高分相加，并进行**整数除****5。最终输出必须按学生 ID 升序排序。 

输入约束是相当容易管理的：最多有 1000 个分数条目，学生 ID 范围在 1 到 1000 之间。每个学生至少有 5 个分数，因此我们不需要处理少于 5 个分数的情况。 关键的边缘情况包括学生只有五个分数、学生有多个相同的最高分以及分数任意顺序。 

该问题保证应用整数除法，这意味着小数平均值被截断。 此细节对于获得正确的输出至关重要。 另一个微妙之处是分数可能以任何顺序添加，因此有必要对最高分数进行排序或维护优先级队列。 

## 方法

 ### 蛮力方法

 最简单的方法是按学生 ID 对所有分数进行分组，按降序对每个组进行排序，选择前 5 个分数，将它们相加，然后除以 5。 这是有效的，因为排序可以确保我们始终选择五个最大的分数。 然而，这需要对每个学生进行排序，当我们只关心前五名的分数时，这是不必要的。 为了`n`总分，这会导致时间复杂度`O(n log n)`在最坏的情况下每个学生。 

### 最佳方法

 关键的观察是我们不需要对每个学生的所有分数进行排序。 我们只需要前五名的分数。 每个学生大小为 5 的 **最小堆（优先级队列）** 就足够了。 对于学生的每个分数，我们将其推入堆中。 如果堆大小超过 5，我们会弹出最小的元素。 这可确保堆始终包含前五个分数。 处理完所有分数后，我们将堆求和并执行整数除以 5 以获得前 5 个分数的平均值。 

这种方法避免了不必要的排序，并保持时间复杂度与分数数量呈线性关系，同时为每个学生维护固定大小的堆。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 将所有分数分组，对每个组进行排序，取前五名 |
 | 最佳 | O(n log 5) ≈ O(n) | O(n log 5) ≈ O(n) | O(s) | 维护每个学生的最小堆大小为 5，s = 唯一学生的数量 |

 ## 算法演练

 1.初始化一个字典（哈希图）`student_scores`为每个学生 ID 存储一个最小堆。 
2. 迭代每个`[ID, score]`输入中的对`items`。 
3. 对于每个`ID`，将分数推入`student_scores[ID]`。 如果堆大小超过 5，则弹出最小分数以确保仅保留前 5 个分数。 
4.处理完所有分数后，初始化一个空列表`result`。 
5. 对于按顺序排列的每个学生 ID：

 1. 获取该学生的分数。 
2. 对堆中的所有元素求和并使用整数除法除以 5。 
3. 追加`[ID, topFiveAverage]`到`result`。 
6. 返回`result`。 

为什么有效：通过维护大小为 5 的最小堆，我们保证只为每个学生保留五个最大的分数。 最后对键进行排序可确保输出按 ID 升序排列。 一致地应用整数除法以满足问题规范。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def highFive(self, items: List[List[int]]) -> List[List[int]]:
        student_scores = {}
        
        for ID, score in items:
            if ID not in student_scores:
                student_scores[ID] = []
            heapq.heappush(student_scores[ID], score)
            if len(student_scores[ID]) > 5:
                heapq.heappop(student_scores[ID])
        
        result = []
        for ID in sorted(student_scores):
            top_five_avg = sum(student_scores[ID]) // 5
            result.append([ID, top_five_avg])
        
        return result
```该代码首先创建一个字典，其中每个学生 ID 映射到分数的最小堆。 对于每个分数，它仅保留前五名。 对 ID 进行排序可确保正确的输出顺序。 计算平均值时应用整数除法。 

## 解决方案```go
package main

import (
    "container/heap"
    "sort"
)

type MinHeap []int

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeap) Push(x interface{}) {
    *h = append(*h, x.(int))
}

func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

func highFive(items [][]int) [][]int {
    studentScores := make(map[int]*MinHeap)
    
    for _, item := range items {
        ID, score := item[0], item[1]
        if _, exists := studentScores[ID]; !exists {
            h := &MinHeap{}
            heap.Init(h)
            studentScores[ID] = h
        }
        heap.Push(studentScores[ID], score)
        if studentScores[ID].Len() > 5 {
            heap.Pop(studentScores[ID])
        }
    }
    
    ids := make([]int, 0, len(studentScores))
    for id := range studentScores {
        ids = append(ids, id)
    }
    sort.Ints(ids)
    
    result := make([][]int, 0, len(ids))
    for _, id := range ids {
        sum := 0
        for _, score := range *studentScores[id] {
            sum += score
        }
        result = append(result, []int{id, sum / 5})
    }
    
    return result
}
```Go 使用以下方式处理堆`container/heap`包裹。 该方法与 Python 类似，使用每个学生的最小堆来跟踪前 5 名分数，并在最后对它们进行求和。 排序是通过`sort.Ints`。 

## 工作示例

 ### 示例 1

 输入：`[[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]`**逐步堆状态：**

 | 身份证 | 每次插入后的堆状态 |
 | ---| ---|
 | 1 | [91] → [91,92] → [91,92,60] → [91,92,60,65] → [91,92,60,65,87] → [92,87,91,65,100] |
 | 2 | [93] → [93,97] → [93,97,77] → [93,97,77,100] → [93,97,77,100,76] |

 前五名金额：`1: 100+92+91+87+65=435`,`2: 100+97+93+77+76=443`。 

整数除以 5：`1: 87`,`2: 88`。 

输出：`[[1,87],[2,88]]`### 示例 2

 输入：`[[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100]]`每个学生只有 5 个分数，都是 100。平均分是`100`。 

输出：`[[1,100],[7,100]]`## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个分数都被压入/弹出最大大小为 5 的堆中，每次操作 O(log 5) ≈ O(1)。 对唯一 ID 进行排序的成本为 O(s log s)，s ≤ n |

 该算法非常高效，因为我们从不对每个学生排序超过 5 个分数，并且只维护固定大小的堆。
