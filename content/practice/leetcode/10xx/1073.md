[LeetCode 问题 1073](https://leetcode.com/problems/adding-two-negabinary-numbers/)

 **难度：** 🟡 中等
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 该问题要求我们将两个以**负二进制**表示的数字相加，即基数**-2**。 与标准二进制（以 2 为基数）不同，负二进制中的每一位贡献的值乘以 -2 的幂。 例如，数组`[1,1,0,1]`代表：```
1 * (-2)^3 + 1 * (-2)^2 + 0 * (-2)^1 + 1 * (-2)^0
= -8 + 4 + 0 + 1
= -3
```输入由两个数组组成`arr1`和`arr2`，每个仅包含`0`或者`1`值，表示没有前导零的数字（除了`[0]`）。 输出还必须采用相同的负二进制数组格式，且不带前导零。 

这些约束表明数组的长度可达 1000，因此任何将数组转换为标准整数类型然后相加的方法都可能因潜在的溢出而失败，特别是在具有固定宽度整数的语言中。 因此，我们必须设计一种直接以负二进制形式处理算术的解决方案。 

要考虑的边缘情况包括添加`[0]`和`[0]`，添加`[0]`具有非零数字和不同长度的数组。 负数加法规则与标准二进制不同，特别是因为进位可以为负并且传播方式不同。 

## 方法

 ### 蛮力

 一种简单的方法是将两个负二进制数组都转换为十进制整数，执行标准加法，然后将结果转换回负二进制。 这是正确的，因为负二进制的数学定义允许转换为十进制并返回。 但是，对于长度为 1000 的数组，十进制值可能会变得非常大，可能会超出标准整数限制并产生大量计算开销。 

### 最佳方法

 最佳方法执行**直接负二进制加法**而不转换为十进制。 关键的观察是，在基数 -2 中，进位规则与标准二进制不同。 我们从最低有效端添加相应的位并使用以下公式管理进位：```
total = bit1 + bit2 + carry
new_bit = total & 1        # bit value is modulo 2
carry = -(total >> 1)      # carry is negative half of total
```此方法自动处理正进位和负进位。 通过从最低有效位到最高有效位进行处理，我们可以有效地构建结果。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n + m) 转换 + O(log N) 加法 | O(n + m) | 转换为十进制，相加，再转换回来； 可能会溢出|
 | 最佳 | O(最大(n, m)) | O(最大(n, m)) | 使用进位传播进行直接负二进制加法 |

 ## 算法演练

 1. 反转两个输入数组，以便我们可以从最低有效位到最高有效位进行处理。 
2. 初始化结果列表并设置`carry = 0`。 
3. 迭代索引直至两个数组的最大长度。 
4. 对于每个索引，将两个数组中的相应位加上进位相加。 
5. 将新位计算为`total % 2`并附加到结果中。 
6. 更新进位为`-(total // 2)`。 由于基数为 -2，因此可以正确处理负进位。 
7. 完成所有位后，如果有则继续处理`carry`不为零，遵循相同的规则。 
8. 反转结果列表以首先恢复最高有效位。 
9. 删除所有前导零，除非结果是`[0]`。 

**为什么有效：** 该算法保持了不变性，即在每一步中，处理后的位加上进位的总和代表负二进制的正确总数。 特殊的进位公式可确保负贡献正确传播，从而产生正确的最终结果。 

## Python 解决方案```python
from typing import List

class Solution:
    def addNegabinary(self, arr1: List[int], arr2: List[int]) -> List[int]:
        i, j = len(arr1) - 1, len(arr2) - 1
        carry = 0
        result = []
        
        while i >= 0 or j >= 0 or carry != 0:
            total = carry
            if i >= 0:
                total += arr1[i]
                i -= 1
            if j >= 0:
                total += arr2[j]
                j -= 1
            
            # Compute new bit and carry
            result.append(total & 1)
            carry = -(total >> 1)
        
        # Remove leading zeros
        while len(result) > 1 and result[-1] == 0:
            result.pop()
        
        return result[::-1]
```**实现说明：** 我们从最低有效位到最高有效位进行迭代，对相应位和进位求和。 按位运算`&1`和`>>1`有效地计算新的位和进位。 计算后会删除前导零，并反转结果以获得正确的 MSB 到 LSB 排序。 

## 解决方案```go
func addNegabinary(arr1 []int, arr2 []int) []int {
    i, j := len(arr1)-1, len(arr2)-1
    carry := 0
    result := []int{}
    
    for i >= 0 || j >= 0 || carry != 0 {
        total := carry
        if i >= 0 {
            total += arr1[i]
            i--
        }
        if j >= 0 {
            total += arr2[j]
            j--
        }
        
        result = append(result, total & 1)
        carry = -(total >> 1)
    }
    
    // Remove leading zeros
    for len(result) > 1 && result[len(result)-1] == 0 {
        result = result[:len(result)-1]
    }
    
    // Reverse the result
    for k, n := 0, len(result); k < n/2; k++ {
        result[k], result[n-1-k] = result[n-1-k], result[k]
    }
    
    return result
}
```**Go实现注意事项：** Go没有内置反转，所以我们手动反转切片。 进位和位计算反映了 Python 实现。 切片附加用于动态构建结果。
