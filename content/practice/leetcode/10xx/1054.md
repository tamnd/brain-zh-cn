[LeetCode 1054 题](https://leetcode.com/problems/distant-barcodes/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、贪婪、排序、堆（优先级队列）、计数

 ## 解决方案

 ## 问题理解

 问题是要求我们重新排列条形码列表，以便没有两个相邻的条形码是相同的。 输入是一个数组`barcodes`整数，其中每个整数代表一种条形码。 输出应该是满足邻接约束的重新排列的数组。 约束指定数组长度最多为 10,000，并且条形码值是最多 10,000 的正整数。 

这告诉我们输入大小适中，我们需要一个高效的算法，最好是 O(n log n) 或 O(n)。 问题保证了解决方案的存在，因此我们不需要处理不可能的情况。 重要的边缘情况包括除一个之外所有条形码都相同的数组，或多个条形码具有相同最大频率的数组。 如果他们试图在不检查的情况下连续放置相同的条形码，那么这些解决方案可能会失败。 

## 方法

 一种强力方法将生成数组的所有可能的排列，并检查每个排列的邻接约束。 这可以保证找到正确的解决方案，因为我们正在检查每个排列，但时间复杂度是输入大小的阶乘 (O(n!))，这对于长度高达 10,000 的数组来说是不可行的。 

最佳解决方案的关键观察是，如果我们始终将最常见的剩余条形码放置在与相同条形码距离最大的位置，我们可以避免邻接冲突。 具体来说，使用最大堆（优先级队列）始终挑选剩余计数最高的条形码，确保没有两个相同的条形码相邻。 如果我们将条形码放置在最常见的项目首先占据交替位置的模式中，则可以在 O(n log k) 时间内有效地解决问题，其中 k 是不同条形码的数量。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 生成所有排列并检查邻接性 |
 | 最佳 | O(n log k) | O(n log k) | O(k) | 使用最大堆将最常见的条形码放在前面 |

 ## 算法演练

 1. 使用哈希图计算每个条形码的频率。 这使我们能够知道哪个条形码出现最多以及我们需要放置它多少次。 
2. 将每个条形码及其负频率推入最大堆（优先级队列）。 使用负频率可确保堆充当最大堆，因为大多数语言默认提供最小堆。 
3. 为结果初始化一个空列表。 
4. 当堆中有多个元素时，弹出两个最常见的条形码。 这保证了我们永远不会连续放置相同的条形码。 
5. 将两个条形码按顺序附加到结果列表中。 减少它们的计数，如果仍有剩余频率，则将它们推回到堆中。 
6. 如果循环后堆中还剩下一个条形码，则将其附加到结果中。 
7. 返回结果数组。 

工作原理：该算法始终将最常见的可用条形码放置在防止与相同条形码相邻的位置。 通过始终从堆中取出顶部的两个条形码，我们确保没有相同的条形码相邻。 该属性保证了有效的解决方案。 

## Python 解决方案```python
from typing import List
from collections import Counter
import heapq

class Solution:
    def rearrangeBarcodes(self, barcodes: List[int]) -> List[int]:
        # Step 1: Count frequencies
        freq = Counter(barcodes)
        
        # Step 2: Build max-heap with negative counts
        max_heap = [(-count, barcode) for barcode, count in freq.items()]
        heapq.heapify(max_heap)
        
        result = []
        
        # Step 4-5: Pop two most frequent barcodes at a time
        while len(max_heap) > 1:
            count1, barcode1 = heapq.heappop(max_heap)
            count2, barcode2 = heapq.heappop(max_heap)
            
            result.append(barcode1)
            result.append(barcode2)
            
            if count1 + 1 < 0:
                heapq.heappush(max_heap, (count1 + 1, barcode1))
            if count2 + 1 < 0:
                heapq.heappush(max_heap, (count2 + 1, barcode2))
        
        # Step 6: Handle the last barcode if any
        if max_heap:
            result.append(max_heap[0][1])
        
        return result
```该实现首先计算条形码频率并将其存储在堆中，以便有效检索最常见的条形码。 主循环提取两个最常见的条形码并将它们附加到结果中，同时减少它们的计数。 剩余的条形码被推回到堆中。 最后，如果剩余一个条形码，则将其附加到末尾。 这直接反映了算法步骤，并确保没有两个相同的条形码相邻。 

## 解决方案```go
package main

import (
    "container/heap"
)

type Item struct {
    val   int
    count int
}

type MaxHeap []Item

func (h MaxHeap) Len() int            { return len(h) }
func (h MaxHeap) Less(i, j int) bool  { return h[i].count > h[j].count }
func (h MaxHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x any)         { *h = append(*h, x.(Item)) }
func (h *MaxHeap) Pop() any {
    old := *h
    n := len(old)
    item := old[n-1]
    *h = old[0 : n-1]
    return item
}

func rearrangeBarcodes(barcodes []int) []int {
    freq := make(map[int]int)
    for _, b := range barcodes {
        freq[b]++
    }

    h := &MaxHeap{}
    heap.Init(h)
    for val, count := range freq {
        heap.Push(h, Item{val, count})
    }

    result := make([]int, 0, len(barcodes))
    for h.Len() > 1 {
        first := heap.Pop(h).(Item)
        second := heap.Pop(h).(Item)

        result = append(result, first.val, second.val)
        first.count--
        second.count--
        if first.count > 0 {
            heap.Push(h, first)
        }
        if second.count > 0 {
            heap.Push(h, second)
        }
    }

    if h.Len() > 0 {
        result = append(result, heap.Pop(h).(Item).val)
    }

    return result
}
```Go 版本镜像了 Python 解决方案，但使用了`container/heap`包来实现最大堆。 结构体用于存储条形码值和计数。 堆操作可以有效地处理推入和弹出操作。 与 Python 不同，Go 需要对堆元素进行显式结构处理。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log k) | O(n log k) | 计数需要 O(n)，堆操作每个元素需要 O(log k)，总共 n 个元素 |
 | 空间| O(k) | 频率图和堆存储多达 k 个唯一条形码 |

 复杂性推理基于以下事实：每个元素最多从堆中压入和弹出一次，k 是不同条形码的数量，最多为 n。
