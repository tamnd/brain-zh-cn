[LeetCode 问题 1018](https://leetcode.com/problems/binary-prefix-divisible-by-5/)

 **难度：** 🟢简单
 **主题：** 数组、位操作

 ## 解决方案

 ## 问题理解

 问题提出了一个二进制数组`nums`，其中每个元素是`0`或者`1`。 我们被要求计算通过解释子数组形成的数字序列`nums[0..i]`作为二进制数，表示为`xi`。 任务是返回一个布尔数组，指示对于每个`i`， 无论`xi`能被5整除。 

简单来说，从数组的第一个元素开始，我们将增长的前缀视为二进制数，将其转换为十进制，并检查是否能被 5 整除。例如，给定`nums = [1,0,1]`，前缀是`[1]`,`[1,0]`,`[1,0,1]`，对应于十进制值`1`,`2`， 和`5`。 然后输出将指示每个十进制值是否能被 5 整除：`[False, False, True]`。 

输入约束告诉我们数组可以非常大，最多可达`10^5`元素。 这排除了任何使用简单方法重复将前缀转换为十进制的解决方案，因为数字可能变得非常大并且处理效率低下。 我们还知道每个元素不是 0 就是 1，这简化了我们的二进制计算。 

重要的边缘情况包括仅包含 0 的数组、长度为 1 的数组以及 1 和 0 的交替序列。 该问题保证非空输入，因此我们不需要处理空数组。 

## 方法

 蛮力方法很简单。 对于每个索引`i`，我们可以计算对应的十进制数`nums[0..i]`然后检查是否能被 5 整除。这可以正常工作，因为它直接评估所需的属性。 然而，它的效率很低，因为在最坏的情况下，重复将大型二进制前缀转换为十进制将花费 O(n^2) 时间，而且数字本身可能非常大。 

更优化方法的关键见解是认识到我们不需要存储整个十进制数来检查能否被 5 整除。模运算允许我们在处理每个位时跟踪二进制数模 5 的余数。 如果`current`是前缀模 5 的十进制值，然后添加一个新位`b`最后相当于计算`(current * 2 + b) % 5`。 这确保了`current`永远不会变得太大，从而提供 O(n) 时间和 O(1) 额外空间解决方案。

 | 蛮力 | O(n^2) | O(n^2) | O(n) | 将每个前缀转换为十进制并检查整除性 |
 | 最佳 | O(n) | O(n) | 使用模 5 算术有效地维持余数 |

 ## 算法演练

 1.初始化一个空列表`result`存储布尔值。 
2. 初始化变量`current`为 0，表示当前前缀模 5 的十进制值。 
3. 迭代每一位`b`在`nums`。 
4. 更新`current`使用公式`current = (current * 2 + b) % 5`。 这实际上将当前值左移一位并添加新位，使结果保持模 5。 
5. 追加`True`到`result`如果`current`是 0（意味着可以被 5 整除）并且`False`否则。 
6. 返回`result`大批。 

为什么它有效：在每一步，`current`正确表示前缀模 5 的十进制值。因为模算术保留了整除性，`current == 0`当且仅当前缀数字可以被 5 整除时。这个不变量保证了正确性，而无需存储或计算大的十进制数。 

## Python 解决方案```python
from typing import List

class Solution:
    def prefixesDivBy5(self, nums: List[int]) -> List[bool]:
        result: List[bool] = []
        current: int = 0
        
        for b in nums:
            current = (current * 2 + b) % 5
            result.append(current == 0)
        
        return result
```在这个实现中，我们初始化`result`存储答案并`current`跟踪前缀值模 5。对于每一位，我们更新`current`使用模运算并附加一个表示能被5整除的布尔值。代码直接遵循算法步骤，避免大量运算。 

## 解决方案```go
func prefixesDivBy5(nums []int) []bool {
    result := make([]bool, 0, len(nums))
    current := 0
    
    for _, b := range nums {
        current = (current*2 + b) % 5
        result = append(result, current == 0)
    }
    
    return result
}
```在 Go 中，我们预先分配`result`容量等于的切片`len(nums)`以提高性能。 变量`current`与 Python 中一样跟踪模 5 值。 我们迭代每个元素，更新模数，并附加一个布尔值。 Go 在此范围内安全地处理整数运算，并且我们避免了由于模运算而导致的任何溢出问题。

 ## 边缘情况

 一种重要的边缘情况是数组仅包含零。 任何前缀的十进制值始终为零，可被 5 整除。该实现正确地将所有零标识为`True`因为`(0*2 + 0) % 5 == 0`。 

第二种边缘情况是数组仅包含 1 时。 在这种情况下，二进制数快速增长，但模运算确保我们永远不会直接计算大十进制值。 该算法正确跟踪被 5 整除而不会溢出，从而生成正确的布尔序列。 

第三种边缘情况是 1 和 0 的交替模式。 此类序列可能会产生以 5 为模进行不可预测波动的十进制值。 该算法的逐步模计算正确地处理了这个问题，保持了以下不变式：`current`始终表示前缀值模 5。这可以防止在尝试重复将完整二进制字符串转换为十进制时可能发生的错误。
