[LeetCode 问题 1063](https://leetcode.com/problems/number-of-valid-subarrays/)

 **难度：** 🔴难
 **主题：** 数组、堆栈、单调堆栈

 ## 解决方案

 ## 问题理解

 问题是要求我们计算给定整数数组中**有效子数组**的数量`nums`。 如果子数组最左边的元素不大于子数组中的任何其他元素，则子数组有效。 换句话说，对于从索引开始的子数组`i`并以索引结束`j`，条件`nums[i] <= nums[k]`必须对每一个都成立`k`之间`i`和`j`包容性。 

输入是单个数组`nums`整数。 输出是一个整数，表示满足此条件的非空子数组的总数。 数组长度可达`5 * 10^4`和值高达`10^5`，因此显式检查所有子数组的简单暴力方法会太慢。 

重要的边缘情况包括严格递减的数组（例如`[3,2,1]`)，严格递增，或所有元素相等。 这些可以测试算法是否正确地对子数组进行计数，而不会出现过度计数或丢失情况的情况。 该问题保证数组非空，因此我们不必处理空输入。 

## 方法

 **暴力方法**是枚举所有可能的子数组，检查每个子数组最左边的元素是否小于或等于所有其他元素，并计算满足条件的子数组。 这是正确的，但效率很低，因为有 O(n²) 个子数组，在最坏的情况下检查每个子数组需要 O(n) 时间，总复杂度为 O(n³)，这对于 n 高达 50,000 来说是不可行的。 

**最佳方法**利用**单调堆栈**来有效地计算从每个元素开始的有效子数组。 关键的见解是，对于每个元素，有效子数组从该元素向右延伸，直到遇到小于它的元素。 通过从数组末尾开始迭代并使用堆栈以非递减顺序跟踪元素，我们可以在 O(n) 时间内计算出有效子数组的数量。

 ## 算法演练

 1.初始化一个空栈和一个变量`count`累加有效子数组的总数。 
2. 从末尾到开头迭代数组。 这确保了在处理元素时，其右侧的所有元素都已被考虑。 
3. 对于每个元素`nums[i]`,初始化一个变量`length`到 1 表示由元素本身组成的子数组。 
4. 当栈不为空且栈顶元素大于等于`nums[i]`，弹出它并将其计数添加到`length`。 此步骤扩展当前子数组以包含大于或等于的连续元素`nums[i]`。 
5. 将当前元素及其`length`到堆栈上。 这将堆栈维护为按值递减的序列。 
6. 添加`length`到`count`。 这表示从当前元素开始的所有有效子数组。 
7. 继续处理下一个元素，直到到达数组的开头。 
8. 返回`count`作为有效子数组的总数。 

**为什么有效：** 堆栈跟踪形成向右延伸的有效子数组的元素。 每个元素准确地贡献从其开始并满足条件的子数组的数量，确保所有有效子数组都被计算一次。 不变的是堆栈包含成对的（元素值、从此处开始的有效子数组的计数），从而有效地保持正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def validSubarrays(self, nums: List[int]) -> int:
        stack = []  # stack of pairs (num, count of valid subarrays starting here)
        count = 0
        for i in range(len(nums) - 1, -1, -1):
            length = 1
            while stack and stack[-1][0] >= nums[i]:
                length += stack.pop()[1]
            stack.append((nums[i], length))
            count += length
        return count
```Python实现使用堆栈来有效地合并满足非递减要求的连续元素。 通过从右向左迭代，它利用存储在堆栈中的预先计算的子数组计数，避免重复检查右侧的元素。 

## 解决方案```go
func validSubarrays(nums []int) int {
    type pair struct {
        val int
        count int
    }
    stack := []pair{}
    total := 0
    for i := len(nums) - 1; i >= 0; i-- {
        length := 1
        for len(stack) > 0 && stack[len(stack)-1].val >= nums[i] {
            length += stack[len(stack)-1].count
            stack = stack[:len(stack)-1]
        }
        stack = append(stack, pair{nums[i], length})
        total += length
    }
    return total
}
```在Go中，我们定义了一个小结构体`pair`存储元素以及从该元素开始的有效子数组的数量。 切片操作取代了堆栈操作，并且整数算术很简单，因为约束完全在`int`限制。

 ## 边缘情况

 第一个边缘情况是单元素数组。 该算法必须正确返回 1，并且堆栈逻辑自然会处理此问题而无需额外检查，因为循环仍会执行一次并将计数加一。 

第二个边缘情况是一个元素全部相等的数组。 在这里，每个元素都可以扩展到所有连续的相等元素，因此算法必须正确合并堆栈中的计数。 我们的实现对弹出元素的计数进行求和，确保子数组的总数是正确的。
