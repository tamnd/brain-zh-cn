 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、位操作、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定的二进制字符串是否`s`包含整数的**所有二进制表示**`1`到`n`作为**子字符串**。 换句话说，对于每个整数`i`这样`1 <= i <= n`，如果你转换`i`对于其二进制形式，该二进制字符串必须连续出现在`s`。 

输入`s`是一个长度最大为1000的二进制字符串，仅包含`'0'`和`'1'`。 输入`n`最大可达 10 亿（`10^9`），这很重要，因为这意味着我们无法天真地生成所有数字并搜索它们的二进制形式； 这对于大型计算来说是不可行的`n`。 

重要的边缘情况包括小`n`值（如`1`)、以零开头的二进制字符串，以及`n`超过子字符串最大长度的值`s`（因为非常大的数字的二进制表示可能比`s`）。 该问题保证了`s`仅包含有效的二进制字符，因此我们不需要验证输入。 

## 方法

 ### 蛮力方法

 蛮力方法将涉及迭代每个整数`1`到`n`，将其转换为二进制字符串，并检查它是否作为子字符串存在`s`。 这种方法简单正确，但是对于大的情况来说太慢了`n`因为检查的数量与`n`，在最坏的情况下，每个子串搜索的时间复杂度为 O(L)，其中 L 是`s`。 自从`n`可以达到`10^9`，这种方法不可行。 

### 最佳方法

 关键的见解是我们不需要检查每个数字`n`如果二进制表示长度超过`s`。 二进制长度为`n`是`len(bin(n)) - 2`，这是我们需要考虑的最大位数。 因此，我们可以使用 **滑动窗口** 来代替单独检查所有数字`s`提取长度可达的所有可能的二进制子串`len(bin(n)) - 2`，将它们转换为整数，并将它们标记为可见。 如果所有整数来自`1`到`n`在此过程中观察到，我们返回`true`。 

这种方法大大降低了复杂性，因为我们处理字符串`s`一次并有效地考虑子字符串，而不是生成直到`n`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * len(s)) | O(n * len(s)) | O(1) | O(1) | 检查每个数字最多`n`在`s`，对于大的来说太慢`n`|
 | 最佳 | O(len(s) * log n) | O(len(s) * log n) | O(n) | 使用滑动窗口捕获所有可能的二进制子串，即使对于大型子串也是可行的`n`|

 ## 算法演练

 1. 计算二进制长度`n`使用`len(bin(n)) - 2`。 这给出了我们需要考虑的最大子串长度`s`。 
2. 初始化一个**集合**来存储在二进制子串中看到的整数`s`。 
3. 迭代每个起始索引`i`的`s`并且对于每个索引，迭代可能的子字符串长度`1`到二进制长度`n`。 使用基数 2 将每个子字符串转换为整数。 
4. 如果整数介于`1`和`n`，将其添加到已见数字集合中。 
5.处理完所有子串后，检查集合的大小是否等于`n`。 如果是，则返回`true`，否则返回`false`。 

**为什么它起作用**：该算法保证所有感兴趣的子字符串（与来自的可能数字相对应的长度）`1`到`n`）被考虑。 通过将它们收集在一个集合中，我们确保重复项不会影响计数，并且最终检查确认是否存在所有必需的整数。 

## Python 解决方案```python
class Solution:
    def queryString(self, s: str, n: int) -> bool:
        max_len = len(bin(n)) - 2
        seen = set()
        
        for i in range(len(s)):
            num = 0
            for j in range(i, min(i + max_len, len(s))):
                num = (num << 1) | int(s[j])
                if 1 <= num <= n:
                    seen.add(num)
            if len(seen) == n:
                return True
        return len(seen) == n
```Python 实现使用嵌套循环，其中外循环迭代子字符串的起始索引，内循环使用按位左移和 OR 有效构造整数。 如果找到所有数字，我们会提前停止，从而优化运行时间。 套装`seen`跟踪迄今为止看到的所有唯一整数。 

## 解决方案```go
func queryString(s string, n int) bool {
    maxLen := len(fmt.Sprintf("%b", n))
    seen := make(map[int]struct{})
    
    for i := 0; i < len(s); i++ {
        num := 0
        for j := i; j < len(s) && j < i+maxLen; j++ {
            num = (num << 1) | int(s[j]-'0')
            if num >= 1 && num <= n {
                seen[num] = struct{}{}
            }
        }
        if len(seen) == n {
            return true
        }
    }
    return len(seen) == n
}
```在 Go 中，我们使用映射而不是集合，并使用空结构作为值来最小化内存。 按位运算按照 Python 中的方式构建数字，并应用提前终止。

 ## 边缘情况

 一个重要的边缘情况是当`s`很短并且`n`大于可以用长度表示的可能数字`s`。 例如，`s = "1"`和`n = 2`。 我们的解决方案通过仅添加内的数字来处理这个问题`1`到`n`并检查最终的设定尺寸。 

另一个边缘情况是当`s`包含很多重复的数字，例如`"111111"`。 该算法仍然通过在每个起始索引上滑动窗口来正确识别所有可能的数字，确保不会遗漏任何数字。
