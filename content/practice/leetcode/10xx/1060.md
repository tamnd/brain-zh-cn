[LeetCode Problem 1060](https://leetcode.com/problems/missing-element-in-sorted-array/)

 **难度：** 🟡 中等
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 The problem asks us to find the k-th missing number in a **sorted, strictly increasing array** of unique integers. 给定`nums`和一个整数`k`，我们需要识别从开始的连续整数形成的序列中缺少的数字`nums[0]`。 

输入`nums`表示排序序列中的已知元素，但之间有一些整数`nums[0]`和`nums[-1]`（以及可能超出的范围）缺失。 整数`k`指定要返回哪个缺失的数字，从第一个缺失的数字按顺序开始计数。 

输出是一个整数，即第 k 个缺失的数字。 约束保证数组可以相当大（`up to 5 * 10^4`） 和`k`也可以非常大（`up to 10^8`）。 This implies that naive linear solutions that check each number sequentially will be too slow for large input ranges.

 主要观察结果包括数组严格递增，因此两个连续元素之间缺失元素的数量可以计算为`nums[i+1] - nums[i] - 1`。 边缘情况包括缺失数字位于第一个数组元素之前、最后一个数组元素之后或正好位于两个元素之间的情况。 

## 方法

 **暴力方法**迭代从开始的每个整数`nums[0]`，计算缺失的数字，直到达到第 k 个缺失的数字。 这种方法保证有效，但效率低下。 如果`nums[-1]`非常大并且`k`也很大，可能需要检查数百万个数字，导致时间复杂度为 O(N + k)，这对于上限约束边界是不可行的。 

**最佳方法**利用了数组已排序的事实。 我们可以计算任意索引处缺失元素的数量`i`使用`nums[i] - nums[0] - i`。 这为我们提供了一个代表累积缺失计数的严格递增函数。 由于它是单调的，我们可以执行二分搜索来有效地找到第一个索引，其中缺失数字的累积数量至少为`k`。 一旦找到合适的区间，就可以直接计算第 k 个缺失数。 这将时间复杂度降低到 O(log N) 并使用 O(1) 额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k + n) | O(1) | O(1) | 迭代顺序计算缺失的数字 |
 | 最佳 | O(log n) | O(1) | O(1) | 使用累积缺失数公式进行二分查找 |

 ## 算法演练

 1. **计算索引 i 处缺失的数字**：定义一个辅助函数`missing(i)`计算缺失数字的总数`nums[0]`到`nums[i]`使用公式`nums[i] - nums[0] - i`。 
2. **检查第k个缺失数是否超出最后一个元素**：如果`k > missing(n-1)`，那么第 k 个缺失的数字是在`nums[-1]`并可计算为`nums[-1] + (k - missing(n-1))`。 
3. **执行二分查找**：初始化`left`作为 0 和`right`作为`n - 1`。 执行标准二分搜索以查找第一个索引`idx`这样`missing(idx) >= k`。 在每次迭代中，计算`mid = (left + right) // 2`。 如果`missing(mid) < k`， 移动`left`到`mid + 1`; 否则，移动`right`到`mid`。 
4. **计算第k个缺失数**：二分查找后，`left`指向累积缺失数大于或等于的第一个索引`k`。 第 k 个缺失数可以计算为`nums[left - 1] + (k - missing(left - 1))`。 

**为什么有效**：累积缺失数严格递增，因此二分查找保证我们找到第 k 个缺失数所在的正确区间。 使用公式`nums[i] - nums[0] - i`确保缺失数的计算准确且单调。 

## Python 解决方案```python
from typing import List

class Solution:
    def missingElement(self, nums: List[int], k: int) -> int:
        n = len(nums)
        
        # Helper function to compute missing numbers until index i
        def missing(index: int) -> int:
            return nums[index] - nums[0] - index
        
        # If k-th missing is beyond the last element
        if k > missing(n - 1):
            return nums[-1] + (k - missing(n - 1))
        
        left, right = 0, n - 1
        while left < right:
            mid = (left + right) // 2
            if missing(mid) < k:
                left = mid + 1
            else:
                right = mid
        
        # k-th missing number is between nums[left - 1] and nums[left]
        return nums[left - 1] + (k - missing(left - 1))
```此实现首先检查第 k 个缺失数字是否位于最后一个元素之外。 如果不是，则对累积缺失数字执行二分查找。 辅助函数可确保清晰、正确地计算缺失计数。 最终的计算从先前的已知元素调整到第 k 个缺失的数字。 

## 解决方案```go
func missingElement(nums []int, k int) int {
    n := len(nums)
    
    // Helper function to calculate missing numbers until index i
    missing := func(index int) int {
        return nums[index] - nums[0] - index
    }
    
    // If k-th missing is beyond the last element
    if k > missing(n - 1) {
        return nums[n - 1] + (k - missing(n - 1))
    }
    
    left, right := 0, n - 1
    for left < right {
        mid := (left + right) / 2
        if missing(mid) < k {
            left = mid + 1
        } else {
            right = mid
        }
    }
    
    return nums[left - 1] + (k - missing(left - 1))
}
```Go 实现反映了 Python 逻辑。 差异包括使用内联函数进行缺失的计算和整数除法`/`。 切片自然地处理动态长度。 在问题约束下，溢出不是问题。
