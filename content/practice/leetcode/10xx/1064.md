[LeetCode 1064 题](https://leetcode.com/problems/fixed-point/)

 **难度：** 🟢简单
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 问题是要求我们在**不同整数**的排序数组中找到一个“不动点”。 不动点是一个索引`i`使得该索引处的值等于索引本身，即`arr[i] == i`。 输入是一个数组`arr`按**升序**排序的整数，我们需要返回此属性所在的**最小索引**。 如果不存在这样的索引，我们返回`-1`。 

约束告诉我们数组长度最多可以有 10,000 个元素，每个元素的范围可以是`-10^9`到`10^9`。 由于数组已排序且值不同，因此我们可以利用此属性来优化我们的解决方案，而不是线性扫描。 

重要的边缘情况包括固定点出现在开头的数组（`arr[0] == 0`）或最后（`arr[n-1] == n-1`)、所有元素均为负数或正数的数组（不存在固定点）以及长度为 1 的数组。 

## 方法

 **暴力方法**很简单：从头到尾迭代数组并检查每个索引`i`看看是否`arr[i] == i`。 这可以正常工作，因为它直接检查每个元素的条件，但它运行的时间为 **O(n)** ，这对于小型数组来说是可以接受的，但可以使用排序属性对较大的数组进行改进。 

**最佳方法**使用**二分搜索**。 由于数组已排序并且元素是不同的，如果`arr[mid] < mid`，所有固定点必须位于右侧，并且如果`arr[mid] > mid`，所有固定点必须位于左侧。 这是因为比索引更小的值意味着我们需要更大的值（可能与索引匹配），而比索引更大的值意味着更早的索引可能匹配。 通过使用二分查找，我们可以将时间复杂度降低到**O(log n)**。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 遍历数组检查每个索引 |
 | 最佳| O(log n) | O(1) | O(1) | 使用二分搜索利用排序的不同属性 |

 ## 算法演练

 1.初始化两个指针，`left = 0`和`right = len(arr) - 1`。 这些代表索引的搜索空间。 
2. 虽然`left <= right`，计算中间索引`mid = (left + right) // 2`。 
3.比较`arr[mid]`和`mid`。 

- 如果`arr[mid] == mid`，我们已经找到了一个固定点，但是我们继续向左搜索以找到**最小索引**，所以设置`right = mid - 1`。 
- 如果`arr[mid] < mid`，固定点（如果存在）必须位于**右侧**`mid`，所以设`left = mid + 1`。 
- 如果`arr[mid] > mid`，固定点（如果存在）必须位于 **左侧**`mid`，所以设`right = mid - 1`。 
4. 跟踪搜索过程中找到的最小固定点。 
5. 如果搜索后没有找到不动点，则返回`-1`。 否则，返回记录的最小索引。 

**为什么有效：** 二分搜索保持任何固定点必须位于搜索范围内的不变量。 通过始终根据比较将搜索空间减半`arr[mid]`和`mid`，我们保证能够有效地找到最小的不动点。 

## Python 解决方案```python
from typing import List

class Solution:
    def fixedPoint(self, arr: List[int]) -> int:
        left, right = 0, len(arr) - 1
        result = -1
        
        while left <= right:
            mid = (left + right) // 2
            if arr[mid] == mid:
                result = mid
                right = mid - 1  # search left side for smaller index
            elif arr[mid] < mid:
                left = mid + 1
            else:
                right = mid - 1
        
        return result
```该实现使用二分搜索方法。 我们维护两个用于高效搜索的指针和一个`result`变量来存储找到的最小固定点。 通过调整`left`和`right`根据比较，我们确保不会错过左侧任何潜在的较小固定点`mid`。 

## 解决方案```go
func fixedPoint(arr []int) int {
    left, right := 0, len(arr)-1
    result := -1
    
    for left <= right {
        mid := (left + right) / 2
        if arr[mid] == mid {
            result = mid
            right = mid - 1
        } else if arr[mid] < mid {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    
    return result
}
```Go 实现镜像了 Python 版本。 主要区别在于使用`:=`对于变量声明和缺少`List[int]`类型。 空数组自然会被处理，并且整数溢出不是 Go 中 mid 计算的问题，因为约束在 32 位 int 范围内。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(log n) | 二分搜索每次迭代将搜索空间减半，给出对数时间 |
 | 空间| O(1) | O(1) | 除了几个变量之外，没有使用额外的空间 |

 二分搜索非常高效，因为数组已排序并且包含不同的整数，使我们能够在每一步中消除数组的一半，而不会丢失任何潜在的固定点。

 ## 边缘情况

 1. **长度为1的数组**：如果数组只有一个元素，它可能是也可能不是不动点。 一个简单的循环仍然可以工作，但是二分搜索可以通过评估来自然地处理它`mid = 0`并相应地返回。
