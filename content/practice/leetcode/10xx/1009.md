[LeetCode 第 1009 题](https://leetcode.com/problems/complement-of-base-10-integer/)

 **难度：** 🟢简单
 **主题：** 位操作

 ## 解决方案

 ## 问题理解

 这个问题要求我们通过翻转二进制表示中的每一位来计算以 10 为基数的整数的**补码**。 例如，如果输入`n`是5，它的二进制形式是`101`。 翻转每个`0`到`1`和每个`1`到`0`产生`010`，等于`2`以十进制表示。 输入保证是小于的非负整数`10^9`。 输出也应该是一个非负整数，表示二进制补码的十进制值。 

该问题在概念上很简单，但需要仔细处理二元运算。 要考虑的边缘情况包括`n = 0`，其中二进制文件是`0`它的补集应该是`1`，以及全部的数字`1`二进制形式的 s，例如`7`（`111`)，其补码为`0`。 

主要观察结果包括我们只需要将位翻转到**最高有效位`1`位**，忽略前导零。 

## 方法

 暴力方法涉及将数字转换为其二进制字符串，手动翻转每一位，然后转换回十进制。 这可以正常工作，但涉及字符串操作和额外的空间，这对于这个问题来说是不必要的。 

最佳方法依赖于**位操作**。 洞察力是翻转所有的位`n`，我们可以异或`n`具有相同长度的掩码，所有位都设置为`1`。 例如，对于`n = 5`（`101`），掩码为`111`二进制（或十进制 7）。 异或运算`5 ^ 7`产生`2`，这是补集。

 | 蛮力 | O(log n) | O(log n) | 转换为二进制字符串、翻转字符、转换回来 |

## 算法演练

 1. 检查是否`n`为零。 如果是，则返回`1`因为 的补集`0`是`1`。 
2. 初始化变量`mask`到`0`。 这将保存一个序列`1`与二进制表示的长度相同`n`。 
3. 初始化副本`n`在一个变量中`temp`。 
4. 虽然`temp`大于`0`， 转移`mask`留一并添加`1`。 同时，移`temp`正好一。 这构建了所有的面具`1`s 的位数与`n`。 
5. 异或`n`和`mask`。 这会翻转所有的位`n`。 
6. 返回异或运算的结果。 

**为什么有效**：XOR 运算会翻转掩码所在的位`1`s 并将位保留为`0`不变。 通过构造一个具有`1`仅在原始数字位的位置中，我们精确翻转有效位，忽略前导零。 这样就保证了正确性。 

## Python 解决方案```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        if n == 0:
            return 1
        
        mask = 0
        temp = n
        while temp > 0:
            mask = (mask << 1) | 1
            temp >>= 1
        
        return n ^ mask
```Python解决方案首先处理特殊情况`n = 0`。 然后，它通过重复左移和添加来构造掩码`1`直到所有位都输入`n`均已核算。 最后，它使用 XOR 翻转位并返回结果。 

## 解决方案```go
func bitwiseComplement(n int) int {
    if n == 0 {
        return 1
    }
    
    mask := 0
    temp := n
    for temp > 0 {
        mask = (mask << 1) | 1
        temp >>= 1
    }
    
    return n ^ mask
}
```Go 实现密切反映了 Python 逻辑。 Go 中的按位运算的行为与 Python 类似。 唯一的区别是类型声明，但因为`n`保证在`int`范围内，不存在溢出问题。

 ## 边缘情况

 1. **n = 0**：二进制是单个`0`。 翻转零位的简单实现可能会返回零，但补码应该是`1`。 我们的解决方案明确处理这种情况。 
2. **n 是二减一的幂**：像这样的数字`1`,`3`,`7`,`15`都是二进制的。 翻转他们的位会产生`0`。 这测试了掩码结构是否正确地解释了二进制表示中没有零的数字。 
3. **大数字**：接近的数字`10^9`测试该解决方案是否可以有效地处理许多位，并且不依赖于字符串转换或递归，这可能很慢或占用大量内存。 按位方法可以很好地处理这个问题。
