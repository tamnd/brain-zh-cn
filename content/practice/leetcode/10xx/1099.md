 ## 解决方案

 ## 问题理解

 该问题要求我们找到整数数组中任意两个不同数字的最大和`nums`使得它们的总和严格小于给定的整数`k`。 换句话说，我们正在寻找两个索引`i`和`j`和`i < j`在哪里`nums[i] + nums[j]`小于`k`，并且在所有这些有效对中，总和是最大可能的。 如果不存在满足此条件的对，我们应该返回`-1`。 

输入数组`nums`包含之间的整数`1`和`1000`，其长度介于`1`和`100`。 整数`k`保证在之间`1`和`2000`。 这些约束告诉我们输入尺寸很小，因此算法的时间复杂度可达`O(n^2)`可以工作，但我们可以进一步优化。 

重要的边缘情况包括所有总和大于或等于的数组`k`、仅包含一个元素的数组，或多个对总和为相同最大有效值的数组。 该问题保证数字是正整数，因此我们不需要显式处理负数或零。 

## 方法

 **暴力方法**涉及检查所有可能的对`(i, j)`在数组中并计算它们的总和。 对于每一对，我们检查总和是否小于`k`并跟踪找到的最大总和。 这种方法是正确的，因为它评估每一对，但它具有时间复杂度`O(n^2)`，对于较大的数组来说可能会很慢，但考虑到限制仍然可行。 

**最佳方法**使用排序和两指针技术。 通过首先对数组进行排序，我们可以使用两个指针有效地搜索对，一个从头开始（`left`）和最后一个（`right`）。 如果总和`nums[left] + nums[right]`小于`k`，我们更新最大总和并移动`left`向右尝试更大的金额。 如果总和大于或等于`k`，我们移动`right`向左移动以减少总和。 这种方法之所以有效，是因为数组已排序，因此增加`left`增加总和并减少`right`减少它，使我们能够有效地探索所有可能的有效总和，而无需检查每一对。

 ## 算法演练

 1. 对数组进行排序`nums`按升序排列。 这使我们能够有效地使用两个指针来探索总和。 
2.初始化两个指针：`left`在`0`（数组的开头）和`right`在`len(nums) - 1`（数组末尾）。 同时初始化`max_sum`到`-1`。 
3. 输入一个运行 while 的循环`left < right`。 
4. 计算总和`current_sum = nums[left] + nums[right]`。 
5. 如果`current_sum < k`， 更新`max_sum`至最大`max_sum`和`current_sum`。 移动`left`向右迈出一步，尝试更大的金额。 
6. 如果`current_sum >= k`， 移动`right`向左移动一步以减少总和。 
7. 继续直到`left`不再小于`right`。 
8. 返回`max_sum`，这将是`-1`如果没有找到有效的金额。 

**为什么有效**：排序后的数组可确保移动`left`指针增加总和并移动`right`指针减小它。 该属性保证所有潜在金额小于`k`有效地探索，并捕获满足条件的最大总和。 

## Python 解决方案```python
from typing import List

class Solution:
    def twoSumLessThanK(self, nums: List[int], k: int) -> int:
        nums.sort()
        left, right = 0, len(nums) - 1
        max_sum = -1
        
        while left < right:
            current_sum = nums[left] + nums[right]
            if current_sum < k:
                max_sum = max(max_sum, current_sum)
                left += 1
            else:
                right -= 1
                
        return max_sum
```该实现首先对数组进行排序。 两指针循环有效地从最小和最大数字向内探索总和。 如果金额有效，`max_sum`已更新。 如果总和超过`k`，右指针向左移动以减少总和。 考虑所有可能的对后返回结果。 

## 解决方案```go
import "sort"

func twoSumLessThanK(nums []int, k int) int {
    sort.Ints(nums)
    left, right := 0, len(nums) - 1
    maxSum := -1
    
    for left < right {
        currentSum := nums[left] + nums[right]
        if currentSum < k {
            if currentSum > maxSum {
                maxSum = currentSum
            }
            left++
        } else {
            right--
        }
    }
    
    return maxSum
}
```Go 实现反映了 Python 解决方案。`sort.Ints`对数组进行排序，并且两指针方法是通过`for`环形。 边缘情况自然会被处理，因为`maxSum`开始于`-1`并且只有有效的总和才会更新它。
