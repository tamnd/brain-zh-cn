[LeetCode 问题 1093](https://leetcode.com/problems/statistics-from-a-large-sample/)

 **难度：** 🟡 中等
 **主题：** 数组、数学、概率和统计

 ## 解决方案

 ## 问题理解

 这个问题要求我们从 0 到 255 范围内的**非常大的整数样本**计算几个描述性统计数据 - 最小值、最大值、平均值、中位数和众数。关键的挑战是样本大小最多可达 10 亿个元素，因此显式生成完整数组是不可行的。 相反，我们提供了一个`count`长度为 256 的数组，其中`count[k]`表示整数的次数`k`出现在样本中。 

预期输出是代表这五个统计数据的浮点数列表。 该问题保证了**模式是唯一的**，这简化了计算。 由于数据的潜在大小以及需要避免显式构造整个数组，平均值和中位数需要仔细处理。 

约束告诉我们`count`正好有 256 个元素，全部为非负数，并且总样本中至少有一个元素。 这确保了**最小值和最大值始终被定义**，并且在计算平均值时我们不会遇到被零除的情况。 需要观察的边缘情况包括：仅存在一个值的样本、非常偏态的分布以及影响中位数的偶数与奇数总计数。 

## 方法

 一种蛮力方法是**扩展`count`通过重复每个值将数组转换为完整的元素列表**`k`确切地`count[k]`次，然后对结果数组进行排序。 排序后，计算最小值、最大值、平均值、中位数和众数就很简单了。 这种方法原则上可以正确工作，但**对于大量计数**是完全不可行的**，因为样本可能达到 10^9 个元素。 

最佳方法利用了以下事实：**值限制在 0 到 255** 之间，并且`count`已经代表了每个值的频率。 我们可以通过迭代直接计算最小值、最大值、平均值和众数`count`。 对于中位数，我们使用**计数前缀和**来定位中间元素，而不构建完整数组。 这种方法的大小是**线性的`count`(256)** 而不是样本的大小。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(N log N)，其中 N = sum(count) | O(N) | 展开整个数组并对其进行排序； 对于大N | 不可行
 | 最佳 | O(256) = O(1) | O(256) = O(1) | O(1) | O(1) | 迭代 count 数组； 使用频率和前缀和计算统计数据 |

 ## 算法演练

 1. 初始化变量`minimum`,`maximum`,`sum`,`total_count`,`mode`， 和`max_count`。`minimum`和`maximum`最初是未定义的。`sum`和`total_count`跟踪运行总和和元素数量。`max_count`跟踪该模式的最高频率。 
2. 迭代`count`带索引`i`从 0 到 255。如果`count[i] > 0`， 更新：

-`minimum`如果尚未设置
 -`maximum`作为`i`（因为我们按递增顺序迭代）
 -`sum`通过添加`i * count[i]`-`total_count`通过添加`count[i]`-`mode`如果`count[i] > max_count`3. 计算`mean`作为`sum / total_count`。 
4. 计算`median`，首先确定中间元素的位置：

 - 如果`total_count`为奇数，中位数位于位置`(total_count + 1) // 2`- 如果`total_count`是偶数，中位数是该位置元素的平均值`total_count // 2`和`(total_count // 2) + 1`5. 使用前缀和方法来查找中位数：

 - 迭代`count`数组，保持运行总计`running_count`。 什么时候`running_count`穿过中位位置，记录相应的`i`价值观。 
6.返回统计数据`[minimum, maximum, mean, median, mode]`作为浮点数。 

**为什么有效：** 通过迭代频率数组而不是扩展样本，我们可以确保正确的统计数据，同时有效地处理极大的样本。 前缀和使我们能够在不构建完整数组的情况下识别中位位置。 

## Python 解决方案```python
from typing import List

class Solution:
    def sampleStats(self, count: List[int]) -> List[float]:
        minimum = None
        maximum = None
        total_sum = 0
        total_count = 0
        mode = 0
        max_count = 0

        for i in range(256):
            if count[i] > 0:
                if minimum is None:
                    minimum = i
                maximum = i
                total_sum += i * count[i]
                total_count += count[i]
                if count[i] > max_count:
                    max_count = count[i]
                    mode = i

        mean = total_sum / total_count

        # Median calculation
        mid1 = None
        mid2 = None
        running_count = 0
        if total_count % 2 == 1:
            median_pos = total_count // 2 + 1
        else:
            median_pos = total_count // 2

        i = 0
        current_count = 0
        med1 = med2 = None
        for i in range(256):
            current_count += count[i]
            if med1 is None and current_count >= (total_count + 1) // 2:
                med1 = i
            if med2 is None and current_count >= (total_count // 2 + 1):
                med2 = i
            if med1 is not None and med2 is not None:
                break

        median = (med1 + med2) / 2

        return [float(minimum), float(maximum), float(mean), float(median), float(mode)]
```Python 代码紧密遵循该算法：它在 count 数组上迭代一次以进行计算`minimum`,`maximum`,`sum`,`mode`， 和`total_count`。 然后，它使用第二遍通过前缀和来定位中位数。 除法确保平均值和中位数是浮点数。 

## 解决方案```go
func sampleStats(count []int) []float64 {
    var minimum, maximum, mode int
    totalSum := 0
    totalCount := 0
    maxCount := 0
    minSet := false

    for i := 0; i < 256; i++ {
        if count[i] > 0 {
            if !minSet {
                minimum = i
                minSet = true
            }
            maximum = i
            totalSum += i * count[i]
            totalCount += count[i]
            if count[i] > maxCount {
                maxCount = count[i]
                mode = i
            }
        }
    }

    mean := float64(totalSum) / float64(totalCount)

    runningCount := 0
    med1, med2 := -1, -1
    for i := 0; i < 256; i++ {
        runningCount += count[i]
        if med1 == -1 && runningCount >= (totalCount+1)/2 {
            med1 = i
        }
        if med2 == -1 && runningCount >= (totalCount/2 + 1) {
            med2 = i
        }
        if med1 != -1 && med2 != -1 {
            break
        }
    }

    median := float64(med1+med2) / 2.0

    return []float64{float64(minimum), float64(maximum), mean, median, float64(mode)}
}
```Go 解决方案反映了 Python 逻辑，使用整数进行计数和求和，仅在返回统计信息时才转换为 float64。 Go 特定的考虑因素包括变量的显式初始化和中间位置的仔细整数除法。
