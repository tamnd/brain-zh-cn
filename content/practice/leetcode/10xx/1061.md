## 问题理解

 该问题要求我们找到可以从给定的字典中获得的最小字符串`baseStr`使用由两个字符串定义的等效字符，`s1`和`s2`。 各位置`i`在`s1`和`s2`表示之间的等价关系`s1[i]`和`s2[i]`。 这些等价遵循自反性、对称性和传递性规则，这意味着如果字符通过其他等价间接连接，则它们被认为是等价的。 

输入字符串`s1`和`s2`具有相同的长度，并且所有字符串仅包含小写英文字母。 这些约束允许每个字符串最多包含 1000 个字符，因此任何解决方案都必须有效处理最多 26 个字母之间的并集运算。 输出是转换后的版本`baseStr`其中每个字符都被其等价组中字典顺序最小的字符替换。 

关键的边缘情况包括以下情况`s1`和`s2`定义重叠的等价类，`baseStr`包含不存在于的字符`s1`或者`s2`，或等价组将多个字符折叠为单个代表。 

## 方法

 蛮力方法将涉及生成所有可能的等效字符串`baseStr`通过彻底应用等价，然后选择字典顺序最小的字符串。 这是不切实际的，因为等效字符串的数量随着等效项的数量呈指数增长，导致不可接受的时间复杂度。 

最佳方法利用并查（不相交集并集）数据结构来有效管理等价类。 通过为每个字符维护一个父指针，我们可以合并等效字符集，并始终确保每个集的代表是字典顺序上最小的字符。 然后，改造`baseStr`只需将每个字符替换为其等价类中的最小代表即可。 这种方法非常高效，因为它使用路径压缩和逐级并集启发法，为并集和查找产生几乎恒定的时间操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 生成所有等效字符串，对于 n 高达 1000 来说不切实际 |
 | 最佳 | O(n + m * α(26)) ≈ O(n + m) | O(n + m * α(26)) ≈ O(n + m) | O(26) | 使用 Union-Find 高效维护等价类 |`n`的长度是`baseStr`， 和`m`的长度是`s1`/`s2`。`α`是阿克曼反函数，对于小字母表来说它实际上是常数。 

## 算法演练

 1. 初始化26个小写英文字母的并查结构。 每个字母最初都是它自己的父字母。 
2. 遍历对`(s1[i], s2[i])`。 对于每一对，执行并集运算。 合并时，始终确保字典顺序较小的字符成为父字符。 这保证了每个等价类的代表是最小的字符。 
3. 处理完所有等价项后，迭代每个字符`c`在`baseStr`。 使用`find`检索其等价类的代表的操作。 
4. 通过替换中的每个字符来构造一个新字符串`baseStr`及其最小的代表。 
5. 返回结果字符串。 

**工作原理：** 并查结构维护不相交的等效字符集，并确保每个集都有最小的字符作为其代表。 通过改造`baseStr`使用这些代表，我们可以获得字典顺序最小的等效字符串，而不必生成所有可能的排列。 

## Python 解决方案```python
class Solution:
    def smallestEquivalentString(self, s1: str, s2: str, baseStr: str) -> str:
        parent = {chr(i): chr(i) for i in range(ord('a'), ord('z') + 1)}
        
        def find(c):
            if parent[c] != c:
                parent[c] = find(parent[c])
            return parent[c]
        
        def union(c1, c2):
            p1, p2 = find(c1), find(c2)
            if p1 == p2:
                return
            if p1 < p2:
                parent[p2] = p1
            else:
                parent[p1] = p2
        
        for a, b in zip(s1, s2):
            union(a, b)
        
        return ''.join(find(c) for c in baseStr)
```**说明：** 我们首先将每个字母初始化为其自己的父字母。 这`find`函数使用路径压缩来提高效率。 这`union`函数确保当两个等价类合并时最小的字符仍然是父字符。 Finally, we transform`baseStr`通过用其代表替换每个字符。 

## 解决方案```go
func smallestEquivalentString(s1 string, s2 string, baseStr string) string {
    parent := make([]byte, 26)
    for i := 0; i < 26; i++ {
        parent[i] = byte(i) + 'a'
    }

    var find func(byte) byte
    find = func(c byte) byte {
        if parent[c-'a'] != c {
            parent[c-'a'] = find(parent[c-'a'])
        }
        return parent[c-'a']
    }

    union := func(a, b byte) {
        pa, pb := find(a), find(b)
        if pa == pb {
            return
        }
        if pa < pb {
            parent[pb-'a'] = pa
        } else {
            parent[pa-'a'] = pb
        }
    }

    for i := 0; i < len(s1); i++ {
        union(s1[i], s2[i])
    }

    res := make([]byte, len(baseStr))
    for i := 0; i < len(baseStr); i++ {
        res[i] = find(baseStr[i])
    }
    return string(res)
}
```**Go 特定说明：** 我们使用 26 个字母的固定大小数组而不是地图。 切片索引是从零开始的。 路径压缩和联合逻辑与Python类似。 之间的转换`byte`和数组索引使用减法`'a'`。
