[LeetCode 问题 1079](https://leetcode.com/problems/letter-tile-possibilities/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、回溯、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们计算由一组字母图块组成的所有可能的非空序列，其中每个图块都有一个大写字母。 输入是一个字符串`tiles`代表图块上可用的字母。 输出是一个整数，表示可以通过以任意顺序使用一个或多个图块来制作的不同序列的总数。 

每个序列最多可以使用每个图块一次，但具有相同字母的多个图块只能通过计数来区分。 例如，在`"AAB"`, 两个`'A'`瓷砖允许像这样的序列`"AA"`和`"AAB"`，但是顺序`'A'`瓷砖不会产生超出字母排序已经创建的新序列。 

限制很小：`1 <= tiles.length <= 7`，这表明暴力生成序列是可行的，但可以通过使用计数策略避免重复来进行优化。 重要的边缘情况包括所有字母都相同、单个字母以及具有多个重复字母的图块。 这些案例测试重复的处理和正确计数。 

## 方法

 强力方法将使用长度为 1 到 n 的排列生成所有可能的序列。 这保证了正确性，因为它探索了每个可能的序列。 然而，由于生成许多重复序列，特别是当图块包含重复字母时，它的效率很低。 这需要使用集合来过滤重复项，这会增加开销。 序列数量的阶乘增长（最多`7! = 5040`对于长度 7) 使其不是最佳的。 

最佳方法利用每个字母的**回溯频率计数**。 我们不是盲目地生成所有序列，而是跟踪每个字母剩余的块数。 在每一步中，我们选择一个字母，减少其计数，递归以构建更长的序列，然后通过恢复计数来回溯。 这确保了不会计算重复序列，并且较小的输入大小可确保算法高效运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成所有排列，过滤重复项 |
 | 最佳 | O(Σ_{k=1}^n n!/(c1!c2!...ck!)) | O(n) | 使用频率计数进行回溯可有效避免重复 |

 ## 算法演练

 1. **计算字母频率**：构建哈希映射（或 A-Z 数组）来存储每个字母有多少个可用块。 这简化了每个步骤的决策过程。 
2. **定义递归回溯函数**：该函数获取当前频率图并尝试将每个字母的一个图块添加到当前序列。 
3. **迭代字母**：对于每个字母，如果其计数大于0，则递减计数，计算该字母相加形成的序列，并递归探索进一步的序列。 
4. **回溯**：递归后，增加当前字母的计数，以恢复其他选择的状态。 
5. **聚合结果**：将递归调用返回的计数相加，得到序列总数。 

工作原理：由于频率计数机制，该算法确保每个可能的序列都被恰好探索一次。 回溯保证不会过度使用字母，而递归则探索所有有效长度。 

## Python 解决方案```python
class Solution:
    def numTilePossibilities(self, tiles: str) -> int:
        from collections import Counter

        def backtrack(counter: Counter) -> int:
            total = 0
            for letter in counter:
                if counter[letter] > 0:
                    counter[letter] -= 1
                    total += 1 + backtrack(counter)
                    counter[letter] += 1
            return total

        tile_count = Counter(tiles)
        return backtrack(tile_count)
```Python 解决方案首先使用以下方法计算每个字母存在的数量`Counter`。 这`backtrack`函数递归地尝试仍具有剩余图块的每个字母，为形成的序列添加一个并递归以计算更长的序列。 每次递归后，字母计数都会恢复以允许探索其他序列。 这种方法确保所有序列都被精确计数一次，而不会生成重复项。 

## 解决方案```go
func numTilePossibilities(tiles string) int {
    freq := make(map[rune]int)
    for _, c := range tiles {
        freq[c]++
    }

    var backtrack func(map[rune]int) int
    backtrack = func(counter map[rune]int) int {
        total := 0
        for c := range counter {
            if counter[c] > 0 {
                counter[c]--
                total += 1 + backtrack(counter)
                counter[c]++
            }
        }
        return total
    }

    return backtrack(freq)
}
```Go 解决方案反映了 Python 方法。 我们使用符文地图来计算字母频率。 递归`backtrack`函数处理每个字母和剩余的图块，添加到总序列中并递归地计算更长的序列。 回溯可以恢复计数，确保所有序列都被考虑，没有重复。

 ## 边缘情况

 **所有字母相同：** 如果瓷砖是`"AAAA"`，序列只能在长度上有所不同。 该算法使用回溯正确计算长度从 1 到 n 的序列，确保不重复。 

**单个字母输入：**`"V"`只允许一个序列，即字母本身。 递归正确返回 1，无需进一步分支。 

**带有独特字母的最大瓷砖长度：**`"ABCDEFG"`测试算法在不超过时间限制的情况下探索所有阶乘长度序列的能力。 回溯有效地生成每个唯一序列一次，正确处理阶乘增长。
