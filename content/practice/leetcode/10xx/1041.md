 **主题：** 数学、字符串、模拟

 ## 解决方案

 ## 问题理解

 这个问题要求我们确定在无限二维平面上移动的机器人如果永远重复一系列指令，是否会保持在某个有界区域内。 

机器人从坐标处开始`(0, 0)`面向北。 输入是一个名为`instructions`，其中每个字符代表一个动作：

 -`'G'`表示在当前方向上前进一个单位。 
-`'L'`意思是向左旋转90度。 
-`'R'`意思是向右旋转90度。 

机器人执行整个指令串，然后从头开始，无限次重复相同的指令。 

目标是回归`true`如果机器人的运动永远停留在某个圆圈内。 否则，返回`false`。 

关键细节是机器人在通过指令串后不会停止。 我们必须在无数次重复之后推理其长期行为。 

限制很小：

 -`1 <= instructions.length <= 100`- 每个角色都是其中之一`'G'`,`'L'`， 或者`'R'`由于输入大小很小，因此性能并不是主要挑战。 真正的挑战是识别机器人运动背后的数学模式。 

一些边缘情况很重要：

 - 机器人可能会在一个周期后返回原点。 
- 机器人可能不会返回原点，但最终可能会面向不同的方向。 
- 机器人可能会继续沿直线永远移动。 
- 指令字符串可能只包含转动而没有移动。 
- 指令字符串可能只包含向前移动。 

一个幼稚的实现可能会尝试模拟无限多次重复，这显然是不可能的。 解决方案取决于识别运动何时变为循环。 

## 方法

 ### 蛮力方法

 一种简单的方法是重复模拟机器人许多周期并跟踪其位置。 如果机器人最终重新访问之前的状态，我们可以得出结论，它的运动是循环的，因此是有界的。 

状态由以下部分组成：

 - 机器人的x坐标
 - 机器人的 y 坐标
 - 机器人当前方向

 如果同样的状态再次出现，未来的运动模式将永远重复。 

这种方法是正确的，因为机器人的运动是确定性的。 一旦某个状态重复，机器人就会进入循环。 

然而，这种方法效率低下且不必要。 在最坏的情况下，我们可能需要模拟多次重复才能发现运动是否有界。 更重要的是，有一种更简单的观察，可以在仅执行一次指令字符串后完全表征答案。 

### 关键见解

 关键的观察是：

 执行一次指令串后，如果出现以下任一情况，机器人就会受到限制：

 1. 机器人回原点。 
2. 机器人不再面向北方。 

为什么第二个条件有效？ 

如果机器人在一个周期后改变方向，则重复指令会旋转其轨迹。 由于只有四个可能的方向，机器人最终将返回原点并保持在有界区域内。 

另一方面，如果机器人在原点以外的某个地方结束并且仍然面向北，则下一次重复会再次产生完全相同的位移。 机器人永远以直线方式漂移得更远，因此它是无界的。 

这意味着我们只需要模拟指令字符串一次。

 ## 算法演练

 ### 最优算法

 1. 初始化机器人的位置和方向。 

从以下开始：

 -`x = 0`-`y = 0`- 朝北

 我们将方向编码为整数：

 -`0 = north`-`1 = east`-`2 = south`-`3 = west`这种表示形式使得使用模算术可以轻松进行旋转。 
2. 创建方向运动表。 

我们将每个方向映射到它的`(dx, dy)`运动：

 - 北 →`(0, 1)`- 东 →`(1, 0)`- 南 →`(0, -1)`- 西 →`(-1, 0)`3. 逐条处理每条指令。 

对于每一个角色`instructions`:

 - 如果指令是`'G'`，使用当前方向向量移动一步。 
- 如果指令是`'L'`，通过减去一个方向索引模 4 来向左旋转。 
- 如果指令是`'R'`，通过添加一个方向索引模 4 来向右旋转。 
4. 检查一个完整循环后的最终状态。 

处理完完整的指令字符串后：

 - 如果机器人返回`(0, 0)`， 返回`True`。 
- 否则，如果机器人不是面向北，则返回`True`。 
- 否则，返回`False`。 

### 为什么它有效

 重要的不变量是，面向不同方向重复相同的指令序列也会导致位移矢量旋转。 

如果机器人在一个周期后再次面向北且不在原点，则位移会永远重复，导致机器人漂移到无限远的地方。 

如果机器人面向不同的方向，则每个周期位移都会旋转。 最多重复四次后，方向变化就会抵消，迫使机器人进入有界循环。 

## Python 解决方案```python
class Solution:
    def isRobotBounded(self, instructions: str) -> bool:
        # Directions:
        # 0 = north
        # 1 = east
        # 2 = south
        # 3 = west
        
        directions = [
            (0, 1),   # north
            (1, 0),   # east
            (0, -1),  # south
            (-1, 0)   # west
        ]
        
        x, y = 0, 0
        direction = 0
        
        for instruction in instructions:
            if instruction == 'G':
                dx, dy = directions[direction]
                x += dx
                y += dy
            elif instruction == 'L':
                direction = (direction - 1) % 4
            else:  # instruction == 'R'
                direction = (direction + 1) % 4
        
        return (x == 0 and y == 0) or direction != 0
```该实现紧密遵循前面描述的算法。 

这`directions`数组存储每个方向的运动向量。 而不是使用字符串比较，例如`"north"`或者`"east"`，我们使用整数索引，因为左转或右转变成简单的模运算。 

变量`x`和`y`跟踪机器人的当前位置。 变量`direction`存储当前方向。 

当处理一个`'G'`指令，代码检索与当前方向对应的运动矢量并更新坐标。 

对于旋转：

 - 向左转减去一个方向索引。 
- 右转增加一个方向索引。 

使用模 4 可确保方向在 0 和 3 之间正确换行。 

在处理完所有指令一次后，最终的返回语句实现了关键的数学观察：

 - 返回原点意味着路径是循环的。 
- 以不同的方向结束意味着未来的重复会旋转运动并保持机器人受到限制。 

## 解决方案```go
func isRobotBounded(instructions string) bool {
    directions := [][]int{
        {0, 1},   // north
        {1, 0},   // east
        {0, -1},  // south
        {-1, 0},  // west
    }

    x, y := 0, 0
    direction := 0

    for _, instruction := range instructions {
        if instruction == 'G' {
            x += directions[direction][0]
            y += directions[direction][1]
        } else if instruction == 'L' {
            direction = (direction + 3) % 4
        } else {
            direction = (direction + 1) % 4
        }
    }

    return (x == 0 && y == 0) || direction != 0
}
```Go 实现与 Python 版本几乎相同。 

一个小的区别是左旋转的处理方式。 我们不使用负模算术（在 Go 中表现不同），而是加上 3 模 4。这在数学上相当于减去 1 模 4。 

方向向量存储为整数切片的切片。 由于坐标仍然很小，因此不必担心整数溢出。

 ## 边缘情况

 ### 边缘情况 1：机器人仅转动

 像这样的指令字符串`"LLLL"`或者`"RR"`导致机器人旋转而不移动。 有缺陷的实现可能会错误地认为没有移动就意味着不需要循环检测。 

我们的实现自然地处理了这个问题，因为机器人保持在`(0, 0)`。 最终条件立即返回`True`。 

### 边缘情况 2：机器人移动但改变方向

 像这样的序列`"GL"`一个周期后机器人不返回原点。 简单的解决方案可能会错误地得出机器人不受限制的结论，因为它的位置发生了变化。 

然而，最终的方向是向西而不是向北。 重复指令会旋转轨迹，最终形成一个循环。 我们的实现正确地检查了方向和位置。 

### 边缘情况 3：机器人保持面朝北

 像这样的指令字符串`"GG"`是临界无界情况。 机器人离开原点，经过一个周期后仍然面朝北。 

这意味着未来的每次重复都会一次又一次地添加相同的位移矢量。 机器人漂移到无限远的地方。 

我们的实现检测到这一点是因为：

 -`(x, y)`不是`(0, 0)`-`direction == 0`意思是北

 因此函数正确返回`False`。
