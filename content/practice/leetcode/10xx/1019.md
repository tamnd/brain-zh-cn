[LeetCode 问题 1019](https://leetcode.com/problems/next-greater-node-in-linked-list/)

 **难度：** 🟡 中等
 **主题：** 数组、链表、堆栈、单调堆栈

 ## 解决方案

 ## 问题理解

 该问题要求我们处理一个单链表，并为每个节点确定具有严格更大值的下一个节点的值。 具体来说，如果列表是`[2,1,5]`，对于第一个节点`2`，下一个较大的节点是`5`; 对于第二个节点`1`，下一个较大的节点也是`5`; 对于最后一个节点`5`，它后面没有更大的节点，所以答案是`0`。 输出是一个整数数组，其中每个元素对应于原始链表中的一个节点，其顺序与节点出现的顺序相同。 

输入`head`是链表的起始节点`n`节点，其中`1 <= n <= 10^4`每个节点的值都介于`1`和`10^9`。 这些约束意味着解决方案必须在时间和空间上都有效； 对于 10,000 个节点的上限来说，针对每个后续节点检查每个节点的简单嵌套循环方法会太慢。 

关键边缘情况包括只有一个节点的列表、所有节点严格递减的列表或所有节点具有相同值的列表。 该问题保证列表中至少有一个节点，因此我们不需要处理空列表。 

## 方法

 暴力方法迭代链表中的每个节点，并且对于每个节点，扫描所有后续节点以找到具有较大值的第一个节点。 这种方法是正确的，因为它显式地检查可以满足“下一个更大节点”条件的每个节点。 然而，它需要 O(n^2) 时间，这对于大输入（最多 10,000 个节点）来说是禁止的。 

最佳方法利用**单调堆栈**的概念，这是一个按值递减顺序跟踪节点的堆栈。 当我们迭代链表时，我们可以维护一个尚未找到下一个更大节点的索引堆栈。 当我们遇到一个值大于堆栈顶部值的节点时，我们知道我们已经找到了该索引的下一个更大的节点，我们将其从堆栈中弹出并更新答案数组。 这确保每个节点最多被压入和弹出一次，实现 O(n) 时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 迭代每个节点并检查所有后续节点 |
 | 最佳 | O(n) | O(n) | 使用单调堆栈有效跟踪节点，无需下一个更大的值 |

 ## 算法演练

 1.初始化一个空列表`values`并遍历链表`head`，将每个节点的值附加到`values`。 这会将链表转换为数组，以方便基于索引的访问。 
2. 创建数组`answer`与相同长度`values`，用零初始化。 这将保留最终结果。 
3.初始化一个空栈`stack`保留索引`values`尚未找到下一个更大的节点。 
4. 迭代`values`带索引`i`和价值`val`。 对于每个`val`，将其与顶部索引对应的值进行比较`stack`。 
5. 当堆栈不为空且`val`大于`values[stack[-1]]`，从堆栈中弹出索引并设置`answer[index] = val`。 这抓住了这样一个事实：`val`是弹出索引的下一个更大的节点。 
6.处理完栈后，压入当前索引`i`到`stack`。 
7. 迭代完成后，剩下的所有索引`stack`后面没有更大的节点，以及它们对应的`answer`价值观依然存在`0`。 
8. 返回`answer`。 

**为什么起作用：** 堆栈不变式是堆栈中的索引始终对应于尚未找到下一个更大节点的值，并且它们对应的值按递减顺序排列。 每个值都在堆栈操作的恒定时间内处理，保证解在时间上是线性的。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
from typing import List, Optional

class Solution:
    def nextLargerNodes(self, head: Optional[ListNode]) -> List[int]:
        values = []
        current = head
        while current:
            values.append(current.val)
            current = current.next
        
        answer = [0] * len(values)
        stack = []
        
        for i, val in enumerate(values):
            while stack and val > values[stack[-1]]:
                index = stack.pop()
                answer[index] = val
            stack.append(i)
        
        return answer
```Python 实现首先将链表转换为简单数组，以便于索引操作。 这`stack`存储尚未找到下一个更大节点的值的索引。 对于每个值，当当前值更大时，我们会从堆栈中弹出索引，以确保我们正确分配下一个更大的值。 堆栈中的剩余索引对应于没有下一个更大节点的节点，这就是为什么`answer`被初始化为零。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func nextLargerNodes(head *ListNode) []int {
    var values []int
    for current := head; current != nil; current = current.Next {
        values = append(values, current.Val)
    }

    answer := make([]int, len(values))
    var stack []int // store indices

    for i, val := range values {
        for len(stack) > 0 && val > values[stack[len(stack)-1]] {
            index := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            answer[index] = val
        }
        stack = append(stack, i)
    }

    return answer
}
```Go 实现镜像了 Python 版本。 由于 Go 没有同样的动态数组，因此我们使用切片`values`和`stack`。 循环不需要进行 Nil 检查，因为链表保证至少有一个节点。 由于限制，整数溢出不是问题，切片操作可以有效地处理堆栈操作。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点最多在堆栈上压入和弹出一次； 遍历链表是 O(n) |
 | 空间| O(n) | 将节点值存储在数组和索引堆栈中，每个索引最多 n 个元素 |

 该算法是线性的，因为在最坏的情况下每个节点都会被处理两次（一次在压入时，一次在弹出时）。
