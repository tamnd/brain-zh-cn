[LeetCode 第 1071 题](https://leetcode.com/problems/greatest-common-divisor-of-strings/)

 **难度：** 🟢简单
 **主题：** 数学、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们找到两个字符串的最大公约数（GCD）。 在这种情况下，一个字符串`t`分割另一个字符串`s`如果`s`可以通过连接形成`t`多次。 目标是找到**最大的字符串**`x`这将两者分开`str1`和`str2`。 

输入由两个非空字符串组成，`str1`和`str2`，每个仅包含大写英文字母。 预期输出是字符串`x`这是两个字符串的最长公约数，如果不存在这样的字符串，则为空字符串。 

约束告诉我们输入字符串的长度可达 1000。这意味着尝试每个子字符串组合的强力方法可能效率低下，因此我们需要一种能够根据字符串长度很好地扩展的方法。 

重要的边缘情况包括：

 1. 根本没有公约数的字符串，例如，`"LEET"`和`"CODE"`。 
2. 一个字符串是另一个字符串的重复，例如，`"ABABAB"`和`"ABAB"`。 
3. 模式相似但略有不同的字符串，例如，`"AAAAAB"`和`"AAA"`。 

我们必须正确地处理这些情况，并返回正确的最长公约数字符串或空字符串。 

## 方法

 ### 蛮力

 暴力方法将涉及生成较短字符串的所有可能的前缀，并检查每个前缀是否可以划分两个字符串。 对于每个候选前缀，我们将通过重复连接来检查它是否形成原始字符串。 这是正确的，因为字符串的 GCD 必须是两个字符串的前缀，但它太慢了，因为我们可能要检查`min(len(str1), len(str2))`多次使用前缀和连接字符串，结果是`O(n * m)`每项检查的操作。 

### 最佳方法

 关键的见解是该问题反映了**数值 GCD** 问题。 如果我们能找到的长度`str1`和`str2`允许公共重复子字符串，GCD字符串的长度是数字GCD`len(str1)`和`len(str2)`。 

我们首先检查是否`str1 + str2 == str2 + str1`。 如果此条件失败，则不存在公共重复字符串。 如果通过，则最大公约数字符串的长度`gcd(len(str1), len(str2))`，我们可以从任一字符串返回该长度的前缀。 这是有效的，因为只有当字符串重复共享一个公共的基本字符串时，它们才是可交换的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n + m) | 通过串联检查所有前缀 |
 | 最佳| O(n + m) | O(1) | O(1) | 使用字符串连接检查和数字 GCD |

 ## 算法演练

 1. 按两个顺序连接字符串：`str1 + str2`和`str2 + str1`。 
2. 检查串联结果是否相等。 如果不是，则返回空字符串，因为不存在公约数。 
3. 计算数值 GCD`len(str1)`和`len(str2)`使用欧几里得算法。 
4. 返回前缀`str1`长度等于数字 GCD。 

工作原理：串联检查可确保字符串是公共基数的倍数。 数字 GCD 给出了可以均匀划分两个字符串长度的最大长度。 取该长度的前缀可确保我们获得最大可能的字符串除数。 

## Python 解决方案```python
from math import gcd

class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        # Check if there exists a common divisor by concatenation commutativity
        if str1 + str2 != str2 + str1:
            return ""
        # Compute the length of the greatest common divisor
        length_gcd = gcd(len(str1), len(str2))
        # Return the prefix of str1 with length equal to length_gcd
        return str1[:length_gcd]
```该代码首先使用串联属性验证是否存在公共字符串除数。 然后它使用内置的`gcd`Python 数学库中的函数用于计算字符串长度的数值 GCD。 最后，返回正确的前缀作为最大公约数字符串。 

## 解决方案```go
import "math"

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func gcdOfStrings(str1 string, str2 string) string {
    if str1+str2 != str2+str1 {
        return ""
    }
    lengthGCD := gcd(len(str1), len(str2))
    return str1[:lengthGCD]
}
```在 Go 中，我们实现了一个自定义数字 GCD 函数，因为标准库没有提供整数函数。 我们使用一个`for`循环和模运算符来找到 GCD，然后返回前缀切片`str1`。

 ## 边缘情况

 1. **根本没有公约数**：当字符串不共享重复模式时，例如，`"LEET"`和`"CODE"`。 该算法通过检查来处理这个问题`str1 + str2 != str2 + str1`并返回一个空字符串，防止不必要的计算。 
2. **单字符串**：长度为1的字符串，如`"A"`和`"A"`，都被正确处理，因为串联检查仍然适用，并且 1 和 1 的 GCD 为 1，返回单个字符。 
3. **一个字符串是另一个字符串的倍数**：像这样的情况`"XYZ"`和`"XYZXYZXYZ"`需要检查较长的字符串是否是较短的字符串的重复。 连接属性确保只有真正共享基本模式的字符串才能通过，并且长度的 GCD 给出正确的除数长度。
