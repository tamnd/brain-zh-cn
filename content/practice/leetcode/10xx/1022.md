[LeetCode 问题 1022](https://leetcode.com/problems/sum-of-root-to-leaf-binary-numbers/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题给了我们二叉树的根，其中每个节点都包含`0`或者`1`。 从根节点到叶节点的每条路径都代表一个二进制数，其中根贡献最高有效位，每个子节点在右侧添加另一个位。 

例如，考虑一条路径：`1 -> 0 -> 1`这表示二进制数`101`，等于`5`以十进制表示。 

任务是计算树中每个根到叶路径形成的所有此类二进制数的总和。 

叶节点是没有子节点的节点。 这意味着我们只评估完整的根到叶路径，而不是停止于内部节点的部分路径。 

输入是由根节点表示的二叉树。 由于每个节点只包含`0`或者`1`，我们可以自然地将遍历路径解释为二进制序列。 预期输出是一个整数，表示根到叶路径生成的所有二进制值的总和。 

这些约束告诉我们一些重要的事情：

 - 树包含之间`1`和`1000`节点。 
- 每个节点值保证是`0`或者`1`。 
- 最终答案适合 32 位整数。 

由于树的尺寸相对较小，`O(n)`解决方案绰绰有余。 路径的二进制值可以在遍历过程中增量更新，而不是重复重建二进制字符串。 

一些边缘情况值得预先识别。 一棵只有一个节点的树意味着根本身也是一片叶子，因此它的值单独形成结果。 严重倾斜的树（意味着每个节点只有一个子节点）的行为实际上类似于链表并测试递归深度行为。 另一个重要的情况是当所有节点值都是`0`，因为每个根到叶的二进制数都变为零。 

## 方法

 ### 蛮力方法

 一种简单的方法是将每个根到叶的二进制数显式构造为字符串。 

我们可以执行深度优先遍历并维护一个表示当前路径的字符串。 在每个节点上，附加节点的值 (`"0"`或者`"1"`）。 当到达叶节点时，使用基数 2 转换将累积的二进制字符串转换为整数，并将其添加到结果中。 

这种方法是正确的，因为每个根到叶路径都被访问一次，并且每个生成的二进制字符串精确对应于预期的二进制数。 

然而，这种方法效率低下，因为字符串连接和重复的二进制转换会增加开销。 每个叶子都需要解析一个二进制字符串，并且中间字符串的创建会不必要地增加内存使用量。 

### 最佳方法

 关键的观察是我们不需要将二进制路径存储为字符串。 相反，我们可以在遍历树时逐步构建数字。 

二进制数遵循一个有用的属性：

 如果当前的二进制数是`x`，附加一个新位`b`产生：`new_value = (x << 1) | b`左移一位将当前数字乘以`2`，为下一点腾出空间。 然后我们使用按位或插入新的节点值。 

例如：

 当前号码：`101`（十进制`5`）

 追加`1`:`101 -> 1011`数学上：`(5 << 1) | 1 = 10 | 1 = 11`利用这个观察结果，我们可以执行 DFS 遍历，同时保持当前累积的二进制数。 一旦到达叶子，我们只需将计算值添加到最终总和中即可。 

这完全避免了字符串构造，并且只处理每个节点一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × h) | O(h) | 构建二进制字符串并在叶子处转换它们 |
 | 最佳 | O(n) | O(h) | 具有增量二进制计算的 DFS |

 这里，`n`是节点数，`h`是树的高度。 

## 算法演练

 ### 最优DFS算法

 1、从根节点开始深度优先遍历，将当前的二进制值初始化为`0`。 
2. 在每个节点上，使用以下命令更新当前数量：`current = (current << 1) | node.val`这会将累积的位左移并附加当前节点的值。 
3. 检查该节点是否为叶子节点。 如果两个节点都满足，则节点是叶子`left`和`right`是`None`。 
4. 如果节点是叶子，请将计算出的二进制值添加到运行总计中，因为这代表一个完整的根到叶子数。 
5. 否则，递归地继续遍历左子树和右子树，同时传递更新后的二进制值。 
6. 遍历完成后返回总和。 

### 为什么它有效

 该算法保持一个不变量：在每个节点，`current`表示从根到该节点的路径形成的二进制数的十进制值。 

由于二进制数是通过左移和附加位来构造的，因此每个递归调用都会正确更新路径值。 由于 DFS 只访问每条从根到叶的路径一次，并且只有叶节点对总和有贡献，因此保证最终结果是正确的。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode], current_value: int) -> int:
            if not node:
                return 0

            current_value = (current_value << 1) | node.val

            if not node.left and not node.right:
                return current_value

            left_sum = dfs(node.left, current_value)
            right_sum = dfs(node.right, current_value)

            return left_sum + right_sum

        return dfs(root, 0)
```该实现使用辅助 DFS 函数，该函数接受两个参数：当前节点和迄今为止累积的二进制值。 

底壳手柄`None`通过返回节点`0`，这简化了递归求和。 

在每个节点，我们使用以下方法更新二进制数：```python
current_value = (current_value << 1) | node.val
```这有效地附加了节点的二进制数字。 

如果我们到达叶节点，我们会立即返回计算值，因为该路径是完整的。 否则，我们递归地计算左右子树的贡献并对它们的结果求和。 

最后，main函数从根开始DFS，初始值为`0`。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func sumRootToLeaf(root *TreeNode) int {
	var dfs func(node *TreeNode, currentValue int) int

	dfs = func(node *TreeNode, currentValue int) int {
		if node == nil {
			return 0
		}

		currentValue = (currentValue << 1) | node.Val

		if node.Left == nil && node.Right == nil {
			return currentValue
		}

		leftSum := dfs(node.Left, currentValue)
		rightSum := dfs(node.Right, currentValue)

		return leftSum + rightSum
	}

	return dfs(root, 0)
}
```Go 实现遵循与 Python 解决方案完全相同的逻辑。 

我们不像Python那样自动支持嵌套函数，而是显式声明一个递归函数变量：```go
var dfs func(node *TreeNode, currentValue int) int
```Go 使用`nil`而不是`None`对于缺失的节点。 叶子检测的处理方式类似，检查两个孩子是否都在`nil`。 

由于该问题保证结果适合 32 位整数，所以标准 Go`int`算术就足够了。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点都被访问一次 |

 ## 边缘情况

 ### 单节点树

 仅包含一个节点的树是一种重要的边缘情况，因为根也是叶子。 有缺陷的实现可能会错误地假设遍历必须继续深入。 我们的解决方案正确识别两个子指针都不存在并立即返回根值。 

例如：```
1
```这会产生二进制数`1`，产生输出`1`。 

### 倾斜树

 每个节点只有一个子节点的树的行为类似于链表。 如果不仔细检查子项是否存在，这可能会暴露递归遍历逻辑中的错误。 

例子：```
1
 \
  0
   \
    1
```这代表二进制`101`，等于`5`。 由于我们的 DFS 通过返回来递归地处理失踪的孩子`0`，倾斜的树自然起作用。 

### 全零值

 如果每个节点都包含`0`，每个根到叶路径的计算结果均为二进制零。 错误处理前导零或字符串转换的幼稚实现可能会产生不正确的值。 

例子：```
    0
   / \
  0   0
```每条路径的计算结果为`0`，所以总和仍然是`0`。 由于我们的实现通过位移位以数字方式计算值，因此可以自动正确地处理前导零。 

### 树深叶多

 包含许多叶节点的树测试所有路径是否正确累积。 一些不正确的解决方案会覆盖结果而不是对它们求和。 

因为此实现递归地返回子树总和并将它们与以下组合：```
left_sum + right_sum
```每个叶子的贡献都被保存一次。
