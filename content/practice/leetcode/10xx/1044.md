## 问题理解

 该问题要求我们找到给定字符串中最长的重复子串`s`。 重复的子字符串是连续的字符序列，在字符串中至少出现两次`s`。 事件可能会重叠。 例如，在字符串中`"banana"`,`"ana"`出现两次并且是最长的此类子串。 如果不存在重复的子字符串，我们返回一个空字符串`""`。 

输入是一个字符串`s`长度在 2 到 30,000 之间，仅由小写英文字母组成。 输出是单个字符串，它是最长的重复子字符串之一。 该问题不需要所有可能的重复项，只需要一个最长的重复项。 

这些约束表明输入可能很大，因此检查所有子串对的简单解决方案效率不高。 边缘情况包括具有所有唯一字符的字符串、最长重复项出现在开头或结尾的字符串以及重复项重叠的字符串。 

## 方法

 暴力方法是生成所有可能的子串`s`，将它们的出现存储在哈希映射中，并跟踪至少出现两次的最长子字符串。 这种方法是正确的，但效率极低：对于一个长度的字符串`n`，有 O(n²) 个子字符串，检查每个子字符串是否重复需要 O(n) 次比较，导致 O(n³) 时间复杂度。 这对于`n`最多 30,000 个。 

更有效的方法将**二分搜索**与**滚动哈希（Rabin-Karp）**相结合。 关键的见解是可以使用二分搜索找到最长重复子串的长度。 对于给定的候选长度`L`，我们可以有效地检查长度是否重复`L`存在使用滚动哈希在 O(n) 时间内计算子字符串哈希。 通过调整`L`使用二分查找，我们可以有效地找到重复项的最大长度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n²) | 生成所有子字符串并检查重复项 |
 | 二分查找+滚动哈希 | O(n log n) 平均 | O(n) | 使用长度二分搜索和滚动哈希来检查重复项

 ## 算法演练

 1. **初始化搜索范围：**设置`low = 1`和`high = len(s)`。 这些表示重复子字符串的可能长度。 
2. **二分查找：** 而`low < high`,检查中间长度`mid = (low + high) // 2`。 使用辅助函数确定是否存在重复的子字符串`mid`存在。 
3. **滚动哈希：** 转换长度的每个子串`mid`使用基数（例如 26）和模数（大素数以避免冲突）转换为数字哈希。 使用滑动窗口在 O(1) 时间内根据前一个哈希值计算下一个哈希值。 
4. **检查重复项：** 将每个哈希存储在一个集合中。 如果集合中已存在新的哈希值，则存在重复项。 如果找到重复项，则更新结果子字符串并将二分查找移至右半部分（`low = mid + 1`）尝试更长的长度。 否则，移至左半部分（`high = mid`）。 
5. **返回结果：** 二分查找结束后，返回找到的最长子串。 

**为什么有效：** 二分查找可确保我们有效地搜索最大长度。 滚动哈希保证子字符串比较的平均复杂度为 O(1)，并且哈希集可以有效地检测重复项。 使用模数可以减少哈希冲突，并且在实践中该算法可靠地找到最长的重复子串。 

## Python 解决方案```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        def search(length: int) -> str:
            base = 26
            mod = 2**63 - 1
            n = len(s)
            h = 0
            for i in range(length):
                h = (h * base + ord(s[i]) - ord('a')) % mod
            seen = {h}
            baseL = pow(base, length, mod)
            for start in range(1, n - length + 1):
                h = (h * base - (ord(s[start - 1]) - ord('a')) * baseL + (ord(s[start + length - 1]) - ord('a'))) % mod
                if h in seen:
                    return s[start:start + length]
                seen.add(h)
            return ""
        
        low, high = 1, len(s)
        result = ""
        while low <= high:
            mid = (low + high) // 2
            dup = search(mid)
            if dup:
                result = dup
                low = mid + 1
            else:
                high = mid - 1
        return result
```Python 实现使用嵌套函数`search(length)`使用滚动哈希查找给定长度的任何重复子字符串。 二分查找确定重复项存在的最大长度。`ord(s[i]) - ord('a')`将字符转换为整数以进行哈希处理。`baseL`用于有效地从滚动哈希中删除最左边的字符。 

## 解决方案```go
func longestDupSubstring(s string) string {
    n := len(s)
    base := int64(26)
    mod := int64(1<<63 - 1)
    
    search := func(length int) string {
        var h int64 = 0
        for i := 0; i < length; i++ {
            h = (h*base + int64(s[i]-'a')) % mod
        }
        seen := map[int64]bool{h: true}
        baseL := int64(1)
        for i := 0; i < length; i++ {
            baseL = (baseL * base) % mod
        }
        for start := 1; start <= n-length; start++ {
            h = (h*base - int64(s[start-1]-'a')*baseL + int64(s[start+length-1]-'a')) % mod
            if h < 0 {
                h += mod
            }
            if seen[h] {
                return s[start : start+length]
            }
            seen[h] = true
        }
        return ""
    }
    
    low, high := 1, n
    result := ""
    for low <= high {
        mid := (low + high) / 2
        dup := search(mid)
        if dup != "" {
            result = dup
            low = mid + 1
        } else {
            high = mid - 1
        }
    }
    return result
}
```Go 实现反映了 Python 方法。 主要区别包括使用`int64`防止整数溢出并由于 Go 的取模行为而显式调整负哈希值。 映射用于哈希集。
