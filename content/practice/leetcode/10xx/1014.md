[LeetCode 第 1014 题](https://leetcode.com/problems/best-sightseeing-pair/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划

 ## 解决方案

 ## 问题理解

 问题提出了一个整数数组`values`，其中每个元素代表一个旅游景点的吸引力或价值。 任务是找到一对点`(i, j)`和`i < j`这样**分数**`values[i] + values[j] + i - j`被最大化。 换句话说，分数是两个点值之和减去它们之间的距离。 

输入数组可以长达 50,000 个元素，每个元素的范围从 1 到 1000。这意味着任何尝试检查所有可能对（这将花费 O(n²) 时间）的解决方案都太慢。 该问题保证数组中至少有两个元素，因此我们不必处理空数组或长度为1的数组。 

需要注意的要点包括负距离会降低分数，因此选择相距较远的点会降低分数，除非值非常高。 边缘情况可能包括所有元素都相等、严格递增、严格递减的数组或具有最大允许长度的数组。 

## 方法

 **暴力方法**涉及迭代所有可能的对`(i, j)`和`i < j`, 计算`values[i] + values[j] + i - j`对于每一对，并记录找到的最大分数。 虽然这保证了正确性，因为它检查了所有可能性，但时间复杂度为 O(n²)，并且对于大型数组（最多 50,000 个元素）来说变得不可行。 

**最佳方法**依赖于关键观察。 分数公式可以改写为：```
values[i] + values[j] + i - j = (values[i] + i) + (values[j] - j)
```这表明分数是两个组成部分的总和：`values[i] + i`（取决于第一个索引）和`values[j] - j`（取决于第二个索引）。 因此，对于每个`j`，我们只需要最大值`values[i] + i`对于所有以前的`i < j`。 我们可以在迭代数组一次时保持这个最大值，从而实现 O(n) 时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 迭代所有对`(i, j)`|
 | 最佳 | O(n) | O(1) | O(1) | 跟踪运行最大值`values[i] + i`|

 ## 算法演练

 1. 初始化变量`max_score`到一个非常小的数字，例如负无穷大，以存储找到的最大分数。 
2. 初始化`max_i_value`作为`values[0] + 0`因为第一个元素是起始候选元素`i`。 
3. 从以下位置开始迭代数组`j = 1`到最后。 
4. 对于每个`j`，计算潜在得分为`max_i_value + values[j] - j`。 这代表配对`j`与之前最好的`i`。 
5. 更新`max_score`如果这个潜在分数高于当前分数`max_score`。 
6. 更新`max_i_value`如果`values[j] + j`大于当前`max_i_value`。 这确保了最佳候选人`i`始终会考虑用于下一次迭代。 
7.循环完成后，返回`max_score`。 

**为什么有效**：通过保持不变性`max_i_value = max(values[i] + i)`为所有人`i < j`，我们保证每个`j`与最好的先前配对`i`。 这确保了在不检查所有对的情况下找到全局最高分数。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxScoreSightseeingPair(self, values: List[int]) -> int:
        max_score = float('-inf')
        max_i_value = values[0] + 0
        
        for j in range(1, len(values)):
            max_score = max(max_score, max_i_value + values[j] - j)
            max_i_value = max(max_i_value, values[j] + j)
        
        return max_score
```此实现将最大分数初始化为负无穷大，并且`max_i_value`与第一个元素的贡献。 对于每个后续元素，它使用先前的最佳元素计算分数`i`，如果需要则更新最大值，并更新最佳值`i`以供将来计算。 这避免了嵌套循环并实现了线性时间复杂度。 

## 解决方案```go
func maxScoreSightseeingPair(values []int) int {
    maxScore := -1 << 31
    maxIValue := values[0]
    
    for j := 1; j < len(values); j++ {
        maxScore = max(maxScore, maxIValue + values[j] - j)
        maxIValue = max(maxIValue, values[j] + j)
    }
    
    return maxScore
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```在 Go 中，我们初始化`maxScore`一个非常小的整数值并且`maxIValue`与第一个元素。 循环计算每个人的潜在分数`j`并更新最高分数和`maxIValue`。 辅助函数`max`用于简化比较。

 | ---| ---| ---| ---| ---|
 | 1 | 8 | 1 | 8 + 1 - 1 = 8 | 8 |
 | 2 | 8 | 5 | 8 + 5 - 2 = 11 | 8 + 5 - 2 = 11 | 11 | 11
 | 3 | 8 | 2 | 8 + 2 - 3 = 7 | 11 | 11
 | 4 | 8 | 6 | 8 + 6 - 4 = 10 | 8 + 6 - 4 = 10 | 11 | 11

 最终的`max_score = 11`。 

**示例2：**`values = [1,2]`| j | 最大i值| 值[j] | 分数 = max_i_value + 值[j] - j | 最大分数 |
 | ---| ---| ---| ---| ---|
 | 1 | 1 | 2 | 1 + 2 - 1 = 2 | 2 |

 最终的`max_score = 2`。

 ## 边缘情况

 **最小长度数组**：长度为 2 的数组是允许的最小长度。 该实现通过在索引 1 处启动循环并初始化来正确处理此问题`max_i_value`索引为 0。 

**大值数组**：在具有固定大小整数的语言中，具有最大长度和大值的数组可能会导致整数溢出。 Python 本地处理这个问题，而在 Go 中，标准的 32 位整数在给定的约束下就足够了，但初始化使用安全的最小值。 

**严格递增/递减数组**：如果数组严格递增或递减，则最佳对可能涉及第一个元素和最后一个元素。 该算法正确地维持了运行最大值`i`并有效地考虑所有对。 

这确保了各种输入模式的稳健性。
