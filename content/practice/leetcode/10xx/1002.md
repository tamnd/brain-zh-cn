[LeetCode 问题 1002](https://leetcode.com/problems/find-common-characters/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串

 ## 解决方案

 ## 问题理解

 该问题给了我们一个小写字符串数组，称为`words`。 我们必须返回数组中每个字符串中出现的所有字符，包括重复出现的字符。 

重要的细节是重复的物质。 如果一个字符在每个单词中出现多次，那么它也必须在答案中出现多次。 

例如，考虑：```
["bella","label","roller"]
```人物`'l'`出现：

 - 2次`"bella"`- 2次`"label"`- 2次`"roller"`因为每个单词至少包含两个`'l'`字符，答案必须包括`"l"`两次。 

然而，角色`'b'`没有出现在`"roller"`，所以不能包含在内。 

输入约束很小：

 - 最多 100 个字
 - 每个单词长度最多100
 - 仅限小写英文字母

 由于只有 26 个可能的小写字母，频率计数成为一种非常自然且有效的方法。 

一些重要的观察结果和边缘情况立即出现：

 - 一个字符可能在一个单词中出现多次，但在另一个单词中只能出现一次。 我们只能在所有单词中包含它的最少次数。 
- 有些单词可能根本不包含共享字符。 
- 数组可能只包含一个单词，在这种情况下，该单词中的每个字符都属于结果。 
- 由于仅使用小写英文字母，因此长度为 26 的固定大小频率数组就足够了。 

## 方法

 ### 蛮力方法

 暴力解决方案可以尝试第一个单词中的每个字符，并检查它是否存在于其他每个单词中。 为了正确处理重复项，我们还需要跟踪每个字符串中每个字符已被使用的次数。 

一种可能的实现将重复：

 1. 从第一个单词中选择一个字符。 
2. 在每个其他单词中搜索该字符。 
3. 如果找到的话，删除或标记每个单词中出现的一个。 
4. 将字符添加到答案中。 

这是有效的，因为只有当每个单词都可以贡献一个未使用的字符时，该字符才能属于结果。 

然而，这种方法变得效率低下，因为重复搜索和删除操作的成本很高。 字符串操作可能会退化为二次行为，尤其是在重复扫描单词时。 

### 最佳方法

 关键的见解是，一个字符在最终答案中出现的次数是由它在所有单词中的最小频率决定的。 

例如：```
words = ["bella", "label", "roller"]
```字符数：

 | 人物 | 贝拉 | 标签| 滚筒| 最低 |
 | ---| ---| ---| ---| ---|
 | 电子| 1 | 1 | 1 | 1 |
 | 我| 2 | 2 | 2 | 2 |
 | 一个 | 1 | 1 | 0 | 0 |

 只有最小频率大于零的字符才属于结果。 

由于只有 26 个小写字母，我们可以：

 1. 计算第一个单词的频率。 
2. 对于每个剩余的单词：

 - 再次计算频率。 
- 使用每个字母的最小计数更新全局频率。 
3. 使用剩余的频率构建最终答案。 

这是高效的，因为每个单词都被处理一次，并且每次频率比较只涉及 26 个字母。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × 平方米) | O(米) | 重复查找删除操作|
 | 最佳| O(n × m) | O(1) | O(1) | 使用超过 26 个字母的频率计数 |

 这里：

-`n`= 字数
 -`m`= 平均字长

 ## 算法演练

 1. 使用第一个字创建大小为 26 的频率数组。 

该数组表示在所有已处理单词中看到的每个字符的当前最小频率。 最初，第一个词定义了这些频率。 
2. 逐个处理剩余的每个单词。 

对于每个单词，创建另一个大小为 26 的频率数组，以计算每个字符在该特定单词中出现的次数。 
3.更新全局最低频率。 

对于每个字符`'a'`到`'z'`， 拿：```
global_frequency[i] = min(global_frequency[i], current_frequency[i])
```这可确保数组始终存储迄今为止处理的所有单词的最小出现次数。 
4. 构建结果数组。 

迭代最终的频率数组。 如果一个字符有频率`k`, 追加该字符`k`次给答案。 
5. 返回结果。 

### 为什么它有效

 该算法保持一个不变量：

 > 处理每个单词后，全局频率数组存储每个字符在所有已处理单词中出现的最小次数。 

一个字符在最终答案中出现的次数只能等于所有单词中最小计数的次数。 通过重复采用最小频率，我们保证最终结果准确包含每个字符串共有的字符，包括重复的字符。 

## Python 解决方案```python
from typing import List

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        # Initialize frequency array using the first word
        min_frequency = [0] * 26

        for char in words[0]:
            min_frequency[ord(char) - ord('a')] += 1

        # Process remaining words
        for word in words[1:]:
            current_frequency = [0] * 26

            for char in word:
                current_frequency[ord(char) - ord('a')] += 1

            # Keep minimum frequencies
            for i in range(26):
                min_frequency[i] = min(
                    min_frequency[i],
                    current_frequency[i]
                )

        # Build result
        result = []

        for i in range(26):
            result.extend(
                [chr(i + ord('a'))] * min_frequency[i]
            )

        return result
```该实现首先为第一个单词创建一个频率数组。 该数组充当所有单词的字符计数的运行交集。 

对于每个附加单词，都会构建另一个频率数组。 然后，该算法通过取每个字符的最小值来更新全局频率。 此步骤是解决方案的核心，因为它保证只有普遍共享的事件才能生存。 

最后，根据每个字符的剩余频率扩展每个字符，构建结果列表。 如果频率为`'l'`是 2，那么`"l"`添加两次。 

该实现使用固定大小的数组而不是哈希图，因为该问题只能保证小写英文字母。 这提高了简单性和效率。 

## 解决方案```go
func commonChars(words []string) []string {
    minFrequency := make([]int, 26)

    // Initialize using first word
    for _, ch := range words[0] {
        minFrequency[ch-'a']++
    }

    // Process remaining words
    for i := 1; i < len(words); i++ {
        currentFrequency := make([]int, 26)

        for _, ch := range words[i] {
            currentFrequency[ch-'a']++
        }

        // Keep minimum frequencies
        for j := 0; j < 26; j++ {
            if currentFrequency[j] < minFrequency[j] {
                minFrequency[j] = currentFrequency[j]
            }
        }
    }

    // Build result
    result := []string{}

    for i := 0; i < 26; i++ {
        for j := 0; j < minFrequency[i]; j++ {
            result = append(result, string(rune(i+'a')))
        }
    }

    return result
}
```Go 实现遵循与 Python 解决方案相同的逻辑。 固定大小的整数切片用于频率计数。 

Go 特有的一个细节是将字符转换回字符串：```go
string(rune(i + 'a'))
```这会将整数偏移量转换为正确的字符，然后将其附加到结果切片。 

由于输入约束很小，因此不必担心整数溢出。

 ## 边缘情况

 ### 单字输入

 如果输入仅包含一个单词，则该单词中的每个字符都应出现在结果中。 有缺陷的实现可能会错误地认为需要进行多次比较。 

该解决方案可以自然地处理这种情况，因为初始频率数组是从第一个单词构建的，并且不会发生进一步的更新。 

### 没有常见字符

 输入如：```
["abc", "def", "ghi"]
```不包含共享字母。 某些实现可能会意外地保留较早单词的陈旧频率。 

该实现通过连续采用最小频率来避免该问题。 单词中缺少的任何字符都会立即变为零并且永远不会重新出现。 

### 重复字符计数不同

 考虑：```
["aaa", "aa", "aaaa"]
```正确答案是：```
["a", "a"]
```一个常见的错误是只检查一个字符是否存在，而不是跟踪它存在的次数。 

此实现正确存储准确的频率，并始终保持所有单词的最小计数，从而准确地保留重复行为。
