[LeetCode 问题 1080](https://leetcode.com/problems/insufficient-nodes-in-root-to-leaf-paths/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们通过删除**不足的节点**来修剪二叉树。 如果**每条经过它的根到叶路径**的总和严格小于给定值，则该节点是不够的`limit`。 输入是`root`二叉树和整数的`limit`。 输出应该是修剪树的根，其中所有不足的节点都已被删除。 

该树是用标准定义的`TreeNode`对象，其中每个节点都有一个`val`, 一个`left`孩子，和一个`right`孩子。 叶节点是没有任何子节点的节点。 约束表明树最多可以有 5000 个节点，并且节点值和`limit`可以是负数，这意味着我们不能假设所有正和或基于正阈值的简单剪枝。 

重要的边缘情况包括具有单个节点的树、所有路径都不足的树、具有负值的树以及修剪向上级联的树（删除叶子可能会导致其父节点不足）。 该问题保证至少有一个节点存在，因此我们不需要一开始就处理一棵空树。 

## 方法

 暴力方法将递归计算**所有根到叶路径总和**，记录哪些节点属于总和低于限制的路径，然后删除这些节点。 这种方法是正确的，但效率低下，因为它多次重新计算重叠子树的路径和，导致高冗余计算。 

最佳方法利用**后序深度优先搜索 (DFS)**。 关键的见解是，我们可以通过递归检查其子节点来确定节点是否不足。 对于叶子来说，路径和就是它的值。 对于内部节点，如果在递归后**两个子节点都被删除**，那么如果到该节点的路径总和低于限制，则该节点本身就会变得不足。 这允许在单次遍历中进行**自下而上**的修剪，避免冗余计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 分别计算所有根到叶的总和，然后修剪节点 |
 | 最佳 | O(n) | O(h) | 单次后序DFS遍历；`h`是树高 |

 ## 算法演练

 1. 从根开始，执行**后序 DFS**：访问左子节点，然后访问右子节点，然后访问当前节点。 这确保了在考虑父级之前就做出了修剪子级的决定。 
2. 对于每个节点，使用更新后的值递归调用左右子节点的函数`remaining_limit`（从限制中减去节点的值）。 这表示沿着这条路径达到极限所需的剩余金额。 
3. 探望完孩子后，检查左边或右边的孩子是否已成为`None`。 如果是这样，这个孩子是不够的，可以通过将其设置为来修剪`None`。 
4. 如果两个孩子都是`None`并且该节点是叶子（或者通过它的所有路径都不足），检查该节点的值是否小于剩余限制。 如果是，则返回`None`修剪这个节点。 
5. 如果足够（至少有一个子节点或者其值满足路径要求），则返回该节点。 

**为什么有效：** 后序遍历可确保子级在父级之前得到处理，从而允许自下而上的修剪。 通过减少`limit`沿着每条路径，我们直接计算包含当前节点的路径是否满足要求，而无需重新计算总和。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sufficientSubset(self, root: Optional[TreeNode], limit: int) -> Optional[TreeNode]:
        def dfs(node: Optional[TreeNode], remaining: int) -> Optional[TreeNode]:
            if not node:
                return None
            # Leaf node
            if not node.left and not node.right:
                return node if node.val >= remaining else None
            # Recur for left and right with reduced remaining sum
            node.left = dfs(node.left, remaining - node.val)
            node.right = dfs(node.right, remaining - node.val)
            # If both children are pruned, check this node
            if not node.left and not node.right:
                return None
            return node
        
        return dfs(root, limit)
```该实现使用了一个助手`dfs`携带所需剩余金额的函数。 直接检查叶节点，内部节点根据递归结果更新其子节点引用。 后序遍历确保了自下而上的正确剪枝。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func sufficientSubset(root *TreeNode, limit int) *TreeNode {
    var dfs func(node *TreeNode, remaining int) *TreeNode
    dfs = func(node *TreeNode, remaining int) *TreeNode {
        if node == nil {
            return nil
        }
        if node.Left == nil && node.Right == nil {
            if node.Val >= remaining {
                return node
            }
            return nil
        }
        node.Left = dfs(node.Left, remaining - node.Val)
        node.Right = dfs(node.Right, remaining - node.Val)
        if node.Left == nil && node.Right == nil {
            return nil
        }
        return node
    }
    return dfs(root, limit)
}
```Go 的实现几乎与 Python 相同。 我们处理`nil`对于空节点，递归传递剩余的总和，并在递归调用后更新节点的子节点。 Go 需要显式的`nil`检查并分配给孩子们。
