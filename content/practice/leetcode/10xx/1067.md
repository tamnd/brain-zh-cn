[LeetCode 1067 题](https://leetcode.com/problems/digit-count-in-range/)

 **难度：** 🔴难
 **主题：** 数学、动态规划

 ## 解决方案

 ## 问题理解

 这个问题要求我们计算给定数字出现了多少次`d`出现在某个范围内的每个整数中`[low, high]`。 例如，如果`d = 1`范围是`[1, 13]`，我们计算该数字的所有出现次数`1`在数字 1 到 13 中。像 11 这样的数字出现了两次，而像 10 和 12 这样的数字各出现了一次。 

输入是一位整数`d`和两个整数`low`和`high`代表包含范围。 输出是一个整数，表示数字的总数`d`涵盖该范围内的所有数字。 

约束表明`d`介于 0 到 9 之间，范围`[low, high]`最高可达2亿。 这表明迭代每个数字并计算数字的强力方法会太慢，因为它可能需要检查多达 2 亿个数字。 重要的边缘情况包括`d = 0`（因为前导零不算在内），非常小的范围，例如`[1, 1]`，接近上限的范围非常大，并且情况`low`和`high`是一样的。 

## 方法

 蛮力方法很简单：迭代每个数字`low`到`high`，转成字符串，统计出现了多少次`d`发生。 这种方法保证是正确的，因为它确实会计算每次出现的次数，但对于大范围来说，它太慢了，特别是因为范围可以达到 2 * 10^8。 

最佳方法利用数字动态规划（数字 DP）。 关键的见解是将数字视为数字序列并计算出现的次数`d`逐个位置。 我们定义一个递归函数来计算出现次数`d`在所有小于或等于给定数字的数字中`x`。 通过计算`count(high)`并减去`count(low - 1)`，我们得到总出现次数`[low, high]`。 这种方法避免了单独迭代每个数字，并减少了处理数字数字的问题，数字大小是对数的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * log(n)) | O(n * log(n)) | O(1) | O(1) | 迭代每个数字并计算数字 |
 | 最佳（数字 DP）| O(log(高)^2) | O(log(高)) | 使用数字位置递归计算出现次数 |

 ## 算法演练

 1. 转换数字`x`到一个字符串来单独处理它的数字。 
2. 定义递归辅助函数`countDigits(pos, tight, countSoFar)`在哪里`pos`代表当前数字位置，`tight`指示我们是否受到当前数字的限制`x`， 和`countSoFar`跟踪出现的情况`d`。 
3. 在每个位置，迭代可能出现在该位置的所有可能的数字。 如果`tight`为 true 时，该数字不能超过中对应的数字`x`。 
4. 对于每个可能的数字，递归计算出现的次数`d`发生在其余位置。 增量`countSoFar`如果当前数字等于`d`。 
5. 记住递归函数的结果以避免重复计算相同的状态。 
6. 最后，计算`count(high) - count(low - 1)`得到出现的次数`d`在包含范围内`[low, high]`。 

为什么有效：通过逐位分解问题并仔细考虑严格约束，这种方法可确保所有数字都被精确计算一次，并且数字出现次数能够正确累积。 记忆化确保重复的子问题仅计算一次，从而提高效率。 

## Python 解决方案```python
class Solution:
    def digitsCount(self, d: int, low: int, high: int) -> int:
        def countUpTo(x: int) -> int:
            s = str(x)
            n = len(s)
            
            from functools import lru_cache
            
            @lru_cache(None)
            def dfs(pos: int, tight: bool, countSoFar: int) -> int:
                if pos == n:
                    return countSoFar
                limit = int(s[pos]) if tight else 9
                total = 0
                for digit in range(0, limit + 1):
                    newTight = tight and (digit == limit)
                    total += dfs(pos + 1, newTight, countSoFar + (digit == d))
                return total
            
            return dfs(0, True, 0)
        
        return countUpTo(high) - countUpTo(low - 1)
```该实现定义了一个辅助函数`countUpTo`它计算了总出现次数`d`从 0 到给定数字。 在内部，我们使用具有记忆功能的递归 DFS 来遍历每个数字位置，同时遵守“严格”约束。 递归计算每个位置的出现次数，并且记忆确保我们不会重新计算状态。 最后减去即可得到答案`count(low-1)`从`count(high)`得到包含范围的结果`[low, high]`。 

## 解决方案```go
func digitsCount(d int, low int, high int) int {
    var countUpTo func(x int) int
    countUpTo = func(x int) int {
        s := fmt.Sprintf("%d", x)
        n := len(s)
        memo := make([][]map[int]int, n)
        for i := range memo {
            memo[i] = make([]map[int]int, 2)
            memo[i][0] = make(map[int]int)
            memo[i][1] = make(map[int]int)
        }
        
        var dfs func(pos int, tight int, countSoFar int) int
        dfs = func(pos int, tight int, countSoFar int) int {
            if pos == n {
                return countSoFar
            }
            if val, ok := memo[pos][tight][countSoFar]; ok {
                return val
            }
            limit := 9
            if tight == 1 {
                limit = int(s[pos] - '0')
            }
            total := 0
            for digit := 0; digit <= limit; digit++ {
                newTight := 0
                if tight == 1 && digit == limit {
                    newTight = 1
                }
                add := 0
                if digit == d {
                    add = 1
                }
                total += dfs(pos+1, newTight, countSoFar+add)
            }
            memo[pos][tight][countSoFar] = total
            return total
        }
        
        return dfs(0, 1, 0)
    }
    
    return countUpTo(high) - countUpTo(low-1)
}
```Go中的递归函数`dfs`与Python类似，但记忆化是通过嵌套映射来实现的，以处理状态元组`(pos, tight, countSoFar)`。 字符串用于访问数字，整数算术跟踪严格约束和计数`d`。 整体逻辑与 Python 版本密切相关。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(log(高)^2) | 每个数字位置 (log(high)) 都会通过可能的数字 (0-9) 进行递归处理，从而产生大约 log(high)^2 次调用。 |
 | 空间| O(log(高)) | 递归深度是位数，记忆存储每个状态组合的结果，也与位数成正比。 |

 复杂性比暴力破解要好得多，因为我们避免了单独迭代每个数字。 对数依赖性来自于处理数字而不是数字本身。
