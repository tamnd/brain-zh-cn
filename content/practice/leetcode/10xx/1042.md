 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、图论

 ## 解决方案

 ## 问题理解

 问题呈现`n`花园，标记为`1`到`n`，以及连接成对花园的双向路径列表。 每个花园必须种植四种花卉中的一种（1 到 4）。 限制是通过路径连接的两个花园不能有相同类型的花。 任务是返回所有花园的**任何有效的花卉类型分配**。 

输入由一个整数组成`n`代表花园和数组的数量`paths`代表花园的联系。 中的每个元素`paths`是一对`[xi, yi]`表示双向路径。 输出应该是一个数组`answer`长度`n`， 在哪里`answer[i]`代表花园中种植的花卉类型`i+1`。 

约束提供了重要的保证：每个花园**最多有3条路径**。 这意味着有 4 种可用的花卉类型，**始终可以选择邻近花园未使用的花卉类型**，从而保证存在解决方案。 输入大小可以大到`n = 10^4`直至`2 * 10^4`路径，这意味着对所有花分配进行简单的暴力枚举会太慢。 

重要的边缘情况包括：

 - 没有路径的花园，可以安全地种植任何花朵。 
- 花园最多与 3 个邻居相连，需要仔细选择。 
- 完全连接的花园子集（三角形），由于有四种花卉类型，这些子集仍然是可解的。 

## 方法

 ### 蛮力

 一种简单的暴力方法会尝试将花递归地分配给每个花园，每当邻居拥有相同的花时就回溯。 虽然正确，但该方法的时间复杂度呈指数级（`O(4^n)`），因为每个花园都有 4 个选择，并且搜索空间组合增长。 这对于`n`最多`10^4`。 

### 最佳方法

 关键的观察结果是，**每个花园最多有 3 个邻居，并且有 4 种花类型**，这保证了每个花园至少有一种可用的花。 我们可以采用贪心的方法：

 1. 将花园和小路表示为邻接表。 
2. 按顺序遍历每个花园。 
3. 检查分配给其邻居的花类型。 
4. 分配邻居未使用的编号最小的花。 

这种方法确保单遍中的有效分配，并利用解决方案始终存在的问题约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(4^n) | O(4^n) | O(n) | 递归地尝试每个组合； 不切实际|
 | 贪婪分配（最优）| O(n + e) | O(n + e) | 使用邻接表并一次性分配花 |

 ## 算法演练

 1. 初始化邻接表`graph`将每个花园映射到其邻近花园的列表。 
2. 对于每条路径`[u, v]`在`paths`， 添加`v`到`graph[u]`和`u`到`graph[v]`。 
3.初始化一个数组`answer`长度`n`带零，代表未分配的花。 
4. 迭代每个花园`1`到`n`。 
5. 对于当前花园，创建一组已被其邻居使用的花卉类型。 
6. 指定最小的花型`1`到`4`那不属于邻居的花束。 
7. 继续，直到所有花园都有指定的花。 
8. 返回`answer`。 

**为什么有效：** 由于每个花园最多有 3 个邻居，并且有 4 种花型，因此总有至少一种花型未被邻居使用。 通过贪婪地将最小的可用花朵分配给每个花园，该算法确保满足所有约束。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def gardenNoAdj(self, n: int, paths: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        for u, v in paths:
            graph[u].append(v)
            graph[v].append(u)
        
        answer = [0] * n
        
        for garden in range(1, n + 1):
            used = {answer[neighbor - 1] for neighbor in graph[garden] if answer[neighbor - 1] != 0}
            for flower in range(1, 5):
                if flower not in used:
                    answer[garden - 1] = flower
                    break
        
        return answer
```**说明：** 我们首先使用`defaultdict`来存储邻居。 然后，对于每个花园，我们跟踪一组中邻居已经使用的花卉类型。 迭代花类型`1`到`4`，我们将第一朵可用的花分配给花园。 这确保了没有两个相邻的花园共用一朵花。 

## 解决方案```go
func gardenNoAdj(n int, paths [][]int) []int {
    graph := make([][]int, n+1)
    for _, path := range paths {
        u, v := path[0], path[1]
        graph[u] = append(graph[u], v)
        graph[v] = append(graph[v], u)
    }
    
    answer := make([]int, n)
    
    for garden := 1; garden <= n; garden++ {
        used := make(map[int]bool)
        for _, neighbor := range graph[garden] {
            if answer[neighbor-1] != 0 {
                used[answer[neighbor-1]] = true
            }
        }
        for flower := 1; flower <= 4; flower++ {
            if !used[flower] {
                answer[garden-1] = flower
                break
            }
        }
    }
    
    return answer
}
```**Go 特定说明：** 我们使用切片作为邻接列表，并使用地图来跟踪使用的花类型。 数组的索引为 0，而花园标签的索引为 1，因此我们适当调整索引。 逻辑与 Python 版本非常相似。
