[LeetCode 第 90 题](https://leetcode.com/problems/subsets-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、回溯、位操作

 ## 解决方案

 ## 问题理解

 该问题要求我们生成给定整数数组的每个可能的子集。 子集是从数组中选择的任何元素，包括空子集和包含所有元素的子集。 

与经典的子集问题不同，此版本引入了一个重要的复杂性：输入数组可能包含重复值。 因此，多个不同的选择路径可能会产生相同的子集。 最终结果必须仅包含唯一的子集。 

例如，如果输入是`[1,2,2]`，子集`[2]`可以使用第一个形成`2`或第二个`2`。 尽管它们来自不同的索引，但它们代表相同的子集，并且应该在输出中只出现一次。 

输入数组长度最多为`10`，相对较小。 由于每个元素都可以被包含或排除，因此可能的子集总数本质上是指数的。 事实上，即使没有重复项，长度的数组`n`有`2^n`子集。 由于约束很小，指数算法是可以接受的，但我们仍然需要一种避免重复生成重复子集的策略。 

重要的挑战不是生成子集，而是唯一地生成它们。 

一些边缘情况尤其重要：

 - 包含许多重复项的数组，例如`[2,2,2]`，如果不仔细处理重复项，很容易产生重复的子集。 
- 只有一个元素的数组，例如`[0]`，仍应正确生成空子集和单例子集。 
- 负数数组的工作方式必须与正数完全相同，因为子集生成仅取决于位置和相等性。 
- 必须始终包含空子集。 
- 由于问题保证至少有一个元素，因此我们不需要处理空输入数组，尽管算法自然会支持它。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是使用二进制掩码或递归包含/排除来生成每个可能的子集。 

对于长度的数组`n`， 有`2^n`可能的组合。 我们可以生成所有子集并将它们存储在集合结构中，以便随后删除重复项。 

例如，与`[1,2,2]`，我们可以生成：

 -`[]`-`[1]`-`[2]`-`[2]`-`[1,2]`-`[1,2]`-`[2,2]`-`[1,2,2]`然后我们可以将每个子集转换为一个元组并将其插入到哈希集中以消除重复项。 

这是有效的，因为集合会自动强制执行唯一性。 然而，它的效率很低，因为重复的子集在被删除之前仍然会生成和处理。 

### 最佳解决方案的关键见解

 关键的观察结果是，仅当在同一递归级别中独立处理重复的数字时，才会出现重复的子集。 

如果我们先对数组进行排序，重复的值就会变得相邻。 然后在回溯过程中，每当我们在相同的递归深度遇到重复值时，我们就会跳过它。 

例如排序后`[1,2,2]`：

 - 在一个递归级别，我们选择第一个`2`- 当我们到达第二个时`2`在同一级别，我们跳过它，因为它会生成相同的子集

 这首先避免了创建重复项，这比生成所有内容并随后进行重复数据删除更高效、更干净。 

因此，该算法结合了：

 - 排序
 - 回溯
 - 重复跳过

## 算法演练

 1. 对输入数组进行排序。 

排序将重复值分组在一起。 这是至关重要的，因为它使我们能够在递归过程中轻松检测重复项。 

例子：```
[2,1,2] -> [1,2,2]
```2. 初始化结果列表。 

我们将把每个独特的子集存储在这个列表中。 
3. 启动回溯功能。 

递归函数需要：

 - 当前起始索引
 - 当前正在构建的子集
 4. 将当前子集添加到结果中。 

每个递归状态代表一个有效的子集。 即使空子集也是有效的。 
5. 从当前索引开始迭代剩余元素。 

对于每个位置：

 - 选择当前号码
 - 将其添加到子集中
 - 向前递归
 - 之后将其删除以回溯
 6. 跳过相同递归深度的重复元素。 

这是最重要的一步。 

在迭代过程中，如果：```
i > start and nums[i] == nums[i - 1]
```然后跳过当前元素。 

条件`i > start`确保我们仅在同一递归级别内跳过重复项，而不是跨越更深的递归分支。 
7. 继续递归，直到探索完所有可能性。 

由于每个递归调用都会推进起始索引，因此每个子集只生成一次。 

### 为什么它有效

 排序可确保重复项相邻。 在递归期间，重复跳过条件阻止算法探索将生成相同子集的等效分支。 

每个递归级别代表为子集选择下一个元素。 通过在给定级别仅允许重复值第一次出现，每个唯一子集都会生成一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        
        result = []
        subset = []

        def backtrack(start: int) -> None:
            result.append(subset[:])

            for i in range(start, len(nums)):
                if i > start and nums[i] == nums[i - 1]:
                    continue

                subset.append(nums[i])
                backtrack(i + 1)
                subset.pop()

        backtrack(0)

        return result
```该实现首先对输入数组进行排序，使重复值变得相邻。 这使得重复跳过逻辑能够正常工作。 

这`result`list 存储所有有效子集，而`subset`跟踪递归期间正在构造的当前子集。 

这`backtrack`函数代表递归探索过程。 在每次调用开始时，当前子集都会被复制到结果列表中，因为每个递归状态都对应一个有效子集。 

该循环从以下位置开始迭代候选元素`start`。 在处理元素之前，算法会检查它是否与相同递归深度的前一个值重复。 如果是这样，它会跳过该元素以避免重复的子集。 

当选择一个元素时，它会被附加到`subset`，递归继续下一个索引，然后使用删除该元素`pop()`恢复之前的状态。 

递归探索系统地构建所有有效的唯一子集。 

## 解决方案```go
package main

import "sort"

func subsetsWithDup(nums []int) [][]int {
	sort.Ints(nums)

	result := [][]int{}
	subset := []int{}

	var backtrack func(start int)

	backtrack = func(start int) {
		current := make([]int, len(subset))
		copy(current, subset)

		result = append(result, current)

		for i := start; i < len(nums); i++ {
			if i > start && nums[i] == nums[i-1] {
				continue
			}

			subset = append(subset, nums[i])

			backtrack(i + 1)

			subset = subset[:len(subset)-1]
		}
	}

	backtrack(0)

	return result
}
```Go 实现遵循与 Python 解决方案相同的递归逻辑。 

Go 特有的一个重要细节是在将切片附加到结果之前复制切片。 切片引用共享底层数组，因此直接追加`subset`会导致以后的修改影响之前存储的子集。 为了避免这种情况，该实现会创建一个新切片并在存储之前将当前子集复制到其中。 

回溯是通过调整切片大小来处理的：```go
subset = subset[:len(subset)-1]
```这可以有效地删除最后一个元素。 

不需要对 nil 和空切片进行特殊处理，因为算法自然会生成空子集作为第一个结果。

 ## 边缘情况

 ### 仅包含重复项的数组

 像这样的输入`[2,2,2]`是错误的常见来源，因为简单的递归算法可能会多次生成相同的子集。 

如果没有重复的跳过，子集如`[2]`和`[2,2]`会反复出现。 该实现通过在同一递归级别跳过重复值来防止这种情况。 

结果，算法正确地产生：```
[]
[2]
[2,2]
[2,2,2]
```没有重复项。 

### 没有重复项的数组

 当所有元素都是唯一的时，例如`[1,2,3]`，问题就简化为标准子集问题。 

重复跳过条件永远不会触发，因为排序后相邻元素不同。 因此，该算法通常会探索每种可能的包含/排除组合。 

这验证了重复处理不会干扰标准子集生成。 

### 单元素数组

 输入如`[0]`测试最小的有效问题大小。 

该算法仍必须包括空子集和包含元素本身的子集。 

因为递归函数在探索进一步的选择之前立即记录当前子集，所以空子集自然被包括在内。 然后递归正确生成`[0]`。 

这证实了该算法可以干净地处理最少的输入，而不需要特殊情况的逻辑。
