 # 从排序数组中删除重复项

 ## 问题理解

 该问题给了我们一个排序的整数数组`nums`按非递减顺序。 由于数组已经排序，任何重复的值将始终相邻出现。 我们的任务是就地删除重复值，以便每个不同的数字在数组开头恰好出现一次。 

“就地”这个词很重要。 我们不应该分配另一个数组并返回它。 相反，我们必须直接修改现有数组。 修改后，首先`k`的元素`nums`应包含按排序顺序排列的所有唯一值，其中`k`是不同元素的数量。 

该函数应该返回`k`，而不是修改后的数组本身。 索引后的值`k - 1`没关系，因为法官只检查第一个`k`职位。 

例如，如果输入是：```
[0,0,1,1,1,2,2,3,3,4]
```然后处理后，数组应以：```
[0,1,2,3,4]
```并且该函数应该返回`5`。 

这些约束告诉我们一些有用的信息：

 - 数组长度可以大到`3 * 10^4`- 保证数组是有序的
 - 值范围为`-100`到`100`最重要的保证是数组是有序的。 如果不进行排序，有效地识别重复项将需要额外的数据结构，例如哈希集。 因为重复项是相邻的，所以我们可以使用两个指针和恒定的额外空间来解决问题。 

一些边缘情况很重要：

 - 只有一个元素的数组，例如`[5]`- 所有元素都相同的数组，例如`[2,2,2,2]`- 没有重复项的数组，例如`[1,2,3,4]`- 包含负数的数组
 - 重复项连续出现多次的数组

 幼稚的实现很容易犯索引错误，尤其是在就地更新元素时。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是创建一个仅存储唯一值的单独数组。 我们迭代原始数组，并在与之前的数字不同时追加一个数字。 

收集所有唯一值后，我们将它们复制回原始数组并返回计数。 

这种方法是正确的，因为排序顺序保证了重复项是相邻的。 通过将每个元素与前一个元素进行比较，我们可以确定它是否是新的唯一值。 

主要缺点是额外的内存使用。 该问题明确要求就地解决方案，因此分配另一个数组违反了要求的精神。 

### 最佳方法

 关键的观察是，由于数组是排序的，因此重复项总是连续出现。 这意味着我们只需要跟踪下一个唯一值应该写入的位置。 

我们使用两个指针：

 - 读指针扫描数组
 - 写入指针跟踪下一个唯一元素应放置的位置

 每当遇到新的唯一值时，我们将其写入写指针位置，并将写指针向前移动。 

这可以有效地工作，因为每个唯一元素最多被复制一次，并且自然会跳过重复项。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 使用额外的数组来存储唯一值 |
 | 最佳 | O(n) | O(1) | O(1) | 使用两个指针并就地修改数组 |

 ## 算法演练

 1. 从处理最简单的情况开始。 如果数组只有一个元素，则答案是立即`1`因为不能有重复的。 
2. 在索引处初始化写指针`1`。 第一个元素始终是唯一的，因此我们将其保留在适当的位置。 
3. 从索引开始迭代数组`1`使用读指针。 
4. 对于每个元素，将其与前一个元素进行比较：

 - 如果当前值不同，则为新的唯一编号。 
- 将此值写入写指针指示的位置。 
- 增加写指针。 
5. 如果当前值与前一个值相同，则为重复，因此跳过。 
6. 循环结束后，写入指针表示唯一元素的总数。 
7. 返回写指针值。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 - 来自索引的子数组`0`到`write_pointer - 1`始终仅包含按排序顺序的唯一元素。 

由于数组已排序，因此重复项会连续出现。 将每个元素与前一个元素进行比较就足以确定它是否是唯一的。 每次我们找到一个新的唯一值时，我们都会将其立即放置在已存储的最后一个唯一值之后。 

到遍历结束时，所有唯一值都已被压缩到数组的前部。 

## Python 解决方案```python
from typing import List

class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if len(nums) == 1:
            return 1

        write_index = 1

        for read_index in range(1, len(nums)):
            if nums[read_index] != nums[read_index - 1]:
                nums[write_index] = nums[read_index]
                write_index += 1

        return write_index
```实现首先检查数组是否只包含一个元素。 在这种情况下，结果立即`1`。 

变量`write_index`跟踪下一个唯一值应写入的位置。 由于第一个元素始终是唯一的，因此它从索引开始`1`。 

循环使用`read_index`从左到右扫描数组。 在每个步骤中，当前元素都会与前一个元素进行比较。 

如果值不同，我们就发现了一个新的唯一编号。 该值被复制到由`write_index`， 进而`write_index`是递增的。 

如果值相等，则该元素是重复的并被忽略。 

最后，函数返回`write_index`，它等于存储在数组开头的唯一元素的数量。 

## 解决方案```go
func removeDuplicates(nums []int) int {
    if len(nums) == 1 {
        return 1
    }

    writeIndex := 1

    for readIndex := 1; readIndex < len(nums); readIndex++ {
        if nums[readIndex] != nums[readIndex-1] {
            nums[writeIndex] = nums[readIndex]
            writeIndex++
        }
    }

    return writeIndex
}
```Go 实现遵循与 Python 版本相同的逻辑。 Go 中的切片是可变的，因此修改`nums`直接更新原数组。 

与某些语言不同，Go 并不像 Python 处理列表那样区分数组和切片。 切片通过类似引用的行为传递，因此就地修改自然有效。 

这里不存在整数溢出问题，因为索引保持在数组大小限制的范围内。

 ## 边缘情况

 ### 单元素数组

 仅包含一个元素的数组是最小的有效输入。 粗心的实现可能会错误地初始化指针或尝试访问超出范围的索引。 

例如：```
[5]
```该实现通过返回立即处理这个问题`1`在进入循环之前。 

### 所有元素相同

 当每个值都相同时，算法应该只保留一份副本。 

例子：```
[2,2,2,2]
```有错误的实现可能会继续不必要地覆盖值或返回错误的计数。 当前的解决方案正确地跳过每个重复项并返回`1`。 

### 没有重复项

 如果数组已包含唯一值，则算法应保持数组不变。 

例子：```
[1,2,3,4]
```每次比较都会标识一个新的唯一值，因此每个元素都会复制到自己的位置。 返回值等于原始数组长度。 

### 负数

 该问题允许负整数，因此无论符号如何，比较都必须正确进行。 

例子：```
[-5,-5,-2,-1]
```由于该算法仅依赖于相等比较和排序顺序，因此可以自然地处理负值，无需任何特殊逻辑。
