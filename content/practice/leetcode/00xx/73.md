 # LeetCode 73，设置矩阵零

 ## 问题理解

 该问题给了我们一个二维整数矩阵`m`行和`n`列。 我们必须就地修改矩阵，以便每当单元格包含`0`，该单元格的整行整列中的每个元素也变成`0`。 

重要的细节是，从原始矩阵状态的角度来看，操作必须同时发生。 如果我们在扫描矩阵时立即开始将零写入矩阵，我们可能会意外地创建新的零，从而错误地影响其他行和列。 

例如，假设我们在位置看到一个零`(1, 1)`并立即将行清零`1`和列`1`。 后来，在扫描矩阵时，我们遇到了新写入的零之一，并错误地认为它存在于原始输入中。 这会使零分布得比预期的更远。 

“就地”一词意味着我们应该避免分配另一个相同大小的矩阵。 后续部分将我们推向一个恒定的额外空间解决方案。 

限制相对较小，最多`200 x 200`，所以即使是一个`O(mn)`或者`O(m + n)`辅助结构可以轻松地适应记忆。 尽管如此，最佳解决方案在保持线性遍历时间的同时实现了恒定的额外空间。 

一些边缘情况很重要：

 - 零可能出现在第一行或第一列中，这变得很棘手，因为最佳解决方案使用这些区域作为标记。 
- 矩阵可能已经包含全零。 
- 矩阵可能根本不包含零。 
- 单行或单列矩阵可能会暴露索引错误。 
- 多个零可能会在受影响的行和列中重叠。 

了解如何在修改矩阵的同时保留原始的零信息是核心挑战。 

## 方法

 ### 蛮力方法

 最直接的想法是创建另一个矩阵或维护哪些单元格应为零的单独记录。 

我们首先扫描整个矩阵并记录包含零的每个行索引和列索引。 之后，我们再次遍历矩阵。 如果单元格属于标记行或标记列，我们将其设置为零。 

这种方法是正确的，因为第一遍捕获了发生任何修改之前的所有原始零位置。 然后，第二遍一致地应用转换。 

简单的暴力变体甚至可以复制整个矩阵并根据副本执行更新。 这可行，但浪费了`O(mn)`额外的空间。 

更好的改进是使用两个集合或布尔数组：

 - 一种结构存储必须变为零的行。 
- 另一个结构存储必须变为零的列。 

这减少了额外的内存`O(m + n)`。 

### 最佳方法

 关键的观察是矩阵本身可以存储标记信息。 

我们可以使用以下方法，而不是分配单独的行和列数组：

 - 每行的第一个单元格指示该行是否应变为零。 
- 每列的第一个单元格指示该列是否应变为零。 

例如：

-`matrix[i][0] == 0`表示行`i`应归零。 
-`matrix[0][j] == 0`表示列`j`应归零。 

这巧妙地重用了现有空间。 

复杂的是，第一行和第一列现在有两个用途：

 - 它们包含实际的矩阵值。 
- 它们还充当标记存储。 

为了避免丢失信息，我们单独跟踪：

 - 第一行最初是否包含零。 
- 第一列最初是否包含零。 

放置所有标记后，我们使用它们将适当的单元格归零，然后最终分别处理第一行和第一列。

 | --- | --- | --- | --- |
 | 蛮力 | O(百万) | O(m + n) | 对包含零的行和列使用单独的存储 |
 | 最佳 | O(百万) | O(1) | O(1) | 使用第一行和第一列作为就地标记 |

 ## 算法演练

 1. 判断第一行原来是否包含零。 

我们扫描行中的每一列`0`。 如果任何值为零，我们将此信息存储在布尔变量中，例如`first_row_zero`。 

此步骤是必要的，因为稍后我们将用标记值覆盖第一行中的单元格。 
2. 判断第一列原来是否包含零。 

我们扫描列中的每一行`0`。 如果任何值为零，我们将此信息存储在另一个布尔变量中，例如`first_col_zero`。 

这会保留第一列在成为标记存储之前的原始状态。 
3. 使用第一行和第一列作为标记。 

从细胞开始`(1, 1)`，我们扫描矩阵的其余部分。 

每当我们遇到零时`(i, j)`：

- 放`matrix[i][0] = 0`- 放`matrix[0][j] = 0`这记录了该行`i`和列`j`最终一定会变为零。 
4. 根据行标记将行清零。 

对于每一行`i`从`1`到`m - 1`：

- 如果`matrix[i][0] == 0`，将该行中的每个单元格设置为零。 

我们跳过行`0`因为它仍然包含标记信息。 
5. 根据列标记将列清零。 

对于每一列`j`从`1`到`n - 1`：

- 如果`matrix[0][j] == 0`，将该列中的每个单元格设置为零。 

再次，我们跳过专栏`0`因为它仍然存储标记信息。 
6. 处理第一行。 

如果`first_row_zero`为 true，设置行中的每个单元格`0`为零。 
7. 处理第一列。 

如果`first_col_zero`为 true，设置列中的每个单元格`0`为零。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 - 在任何行或列归零之前，第一行和第一列准确存储哪些行和列必须归零。 

由于标记阶段发生在任何大规模修改之前，因此不会丢失任何信息。 单独的布尔变量保留第一行和第一列的原始状态，防止标记存储和实际转换逻辑之间的冲突。 

最初包含零的每一行和每一列都被标记一次，并且每个标记的行或列最终都被归零。 

## Python 解决方案```python
from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        rows = len(matrix)
        cols = len(matrix[0])

        first_row_zero = False
        first_col_zero = False

        # Check whether first row contains a zero
        for col in range(cols):
            if matrix[0][col] == 0:
                first_row_zero = True
                break

        # Check whether first column contains a zero
        for row in range(rows):
            if matrix[row][0] == 0:
                first_col_zero = True
                break

        # Use first row and first column as markers
        for row in range(1, rows):
            for col in range(1, cols):
                if matrix[row][col] == 0:
                    matrix[row][0] = 0
                    matrix[0][col] = 0

        # Zero out marked rows
        for row in range(1, rows):
            if matrix[row][0] == 0:
                for col in range(1, cols):
                    matrix[row][col] = 0

        # Zero out marked columns
        for col in range(1, cols):
            if matrix[0][col] == 0:
                for row in range(1, rows):
                    matrix[row][col] = 0

        # Zero out first row if needed
        if first_row_zero:
            for col in range(cols):
                matrix[0][col] = 0

        # Zero out first column if needed
        if first_col_zero:
            for row in range(rows):
                matrix[row][0] = 0
```实现完全遵循算法。 

第一部分计算矩阵维度并初始化两个布尔标志。 这些标志保留第一行或第一列最初是否包含零。 

接下来的两个循环分别扫描第一行和第一列。 这必须在标记放置之前发生，否则我们无法区分原始零和标记零。 

标记阶段从索引开始`1`对于行和列。 每当找到零时，相应的行标记和列标记就会写入矩阵本身。 

建立所有标记后，算法分两遍执行转换：

 - 一次根据第一列标记将行归零。 
- 另一次根据第一行标记将列归零。 

最后，该算法使用布尔标志应用保存的第一行和第一列信息。 

由于所有修改都直接发生在原始矩阵内部，因此该解决方案满足就地要求。 

## 解决方案```go
func setZeroes(matrix [][]int) {
	rows := len(matrix)
	cols := len(matrix[0])

	firstRowZero := false
	firstColZero := false

	// Check first row
	for col := 0; col < cols; col++ {
		if matrix[0][col] == 0 {
			firstRowZero = true
			break
		}
	}

	// Check first column
	for row := 0; row < rows; row++ {
		if matrix[row][0] == 0 {
			firstColZero = true
			break
		}
	}

	// Use first row and column as markers
	for row := 1; row < rows; row++ {
		for col := 1; col < cols; col++ {
			if matrix[row][col] == 0 {
				matrix[row][0] = 0
				matrix[0][col] = 0
			}
		}
	}

	// Zero marked rows
	for row := 1; row < rows; row++ {
		if matrix[row][0] == 0 {
			for col := 1; col < cols; col++ {
				matrix[row][col] = 0
			}
		}
	}

	// Zero marked columns
	for col := 1; col < cols; col++ {
		if matrix[0][col] == 0 {
			for row := 1; row < rows; row++ {
				matrix[row][col] = 0
			}
		}
	}

	// Zero first row
	if firstRowZero {
		for col := 0; col < cols; col++ {
			matrix[0][col] = 0
		}
	}

	// Zero first column
	if firstColZero {
		for row := 0; row < rows; row++ {
			matrix[row][0] = 0
		}
	}
}
```Go 实现在结构上与 Python 版本相同。 由于 Go 切片的行为已经类似于对底层数组的引用，因此修改`matrix`直接就地更新原来的结构。 

与 Python 不同，Go 不需要显式类型提示或列表导入。 整数溢出在这里不是问题，因为该算法仅比较和分配值。 

保证矩阵至少包含一行和一列，因此访问`matrix[0]`在问题约束下是安全的。

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows = len(matrix)
        cols = len(matrix[0])

        first_row_zero = False
        first_col_zero = False

        for col in range(cols):
            if matrix[0][col] == 0:
                first_row_zero = True
                break

        for row in range(rows):
            if matrix[row][0] == 0:

        if first_row_zero:
            for col in range(cols):

        if first_col_zero:

 ## 边缘情况

 ### 第一行为零

 第一行用作最优解中的列标记存储。 如果第一行最初包含零，则我们无法区分第一行中的零是原始值还是仅仅是一个标记，除非我们单独存储该信息。 

该实现通过以下方式处理此问题`first_row_zero`布尔变量，在标记放置开始之前计算。 

### 第一列为零

 第一列也存在同样的问题，因为它存储行标记。 如果第一列最初包含零，则算法必须独立记住这一点。 

这`first_col_zero`变量保留该信息，以便第一列可以在最后正确归零。 

### 单行或单列矩阵

 矩阵如`[[1,0,3]]`或者`[[1],[0],[3]]`可以暴露索引错误，因为内部遍历来自`(1,1)`可能永远不会执行。 

该实现可以安全地处理这些情况，因为所有循环都动态使用矩阵维度，并且第一行和第一列逻辑仍然正确应用转换。 

### 多个重叠的零

 当多个零影响重叠的行和列时，粗心的实现可能会重复覆盖标记或意外传播新写入的零。 

该算法避免了该问题，因为所有标记放置都发生在任何行或列完全归零之前。 原始零信息在整个标记阶段保持不变。
