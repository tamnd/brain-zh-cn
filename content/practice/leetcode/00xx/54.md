 ## 解决方案

 ## 问题理解

 该问题给出了一个`m x n`矩阵并要求我们按螺旋顺序返回所有元素。 

螺旋顺序意味着我们从左上角开始并以顺时针螺旋模式移动：

 1.从左到右遍历顶行
 2.从上到下遍历右列
 3.从右向左遍历底行
 4.从下到上遍历左列
 5. 对内部子矩阵重复相同的过程

 例如，在此矩阵中：```
1 2 3
4 5 6
7 8 9
```我们按以下顺序访问数字：```
1 → 2 → 3
            ↓
4    5    6
↑           ↓
7 ← 8 ← 9
```其产生：```
[1,2,3,6,9,8,7,4,5]
```保证输入是有效的矩形矩阵。 每行都有相同数量的列。 约束很小，`1 <= m, n <= 10`，所以性能并不难，但实现时必须小心避免重访元素或出界。 

一些边缘情况可能会在简单的实现中导致错误：

 - 只有一行的矩阵
 - 只有一列的矩阵
 - 奇数大小的矩阵，其中一个中心元素保留在末尾
 - 行和列大小不同的矩形矩阵
 - 像这样的小矩阵`1 x 1`或者`1 x n`主要挑战是正确处理边界，同时逐层缩小遍历区域。 

## 方法

 ### 蛮力方法

 一种简单的方法是在跟踪访问的单元格的同时模拟通过矩阵的移动。 

我们可以维护：

 - 当前位置
 - 当前方向
 - 访问矩阵
 - 右、下、左、上方向向量

 每一步：

 - 将当前元素添加到结果中
 - 将单元格标记为已访问
 - 尝试前进
 - 如果下一个位置无效或已经访问过，则旋转方向

 这种方法之所以有效，是因为它完全按照描述明确地模拟了螺旋运动。 

缺点是访问矩阵需要额外的空间。 尽管约束很小，但我们可以做得更好，因为遍历自然会形成缩小的边界。 

### 最佳方法

 关键的观察结果是，螺旋遍历始终在矩阵的当前外部矩形上进行操作。 

我们不跟踪访问过的单元格，而是维护四个边界：

 -`top`-`bottom`-`left`-`right`每次遍历都会消耗当前矩形的一侧：

 - 遍历顶行，然后递增`top`- 遍历右列，然后递减`right`- 遍历底行，然后递减`bottom`- 遍历左列，然后递增`left`随着边界向内缩小，我们最终处理整个矩阵。 

这避免了对额外访问存储的需要，并保持实现的干净和高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m × n) | O(m × n) | 使用访问矩阵和方向模拟 |
 | 最佳 | O(m × n) | O(1) | O(1) | 使用缩小边界|

 ## 算法演练

 ### 最佳边界模拟

 1.初始化四个边界指针：

 -`top = 0`-`bottom = rows - 1`-`left = 0`-`right = cols - 1`这些定义了仍需要处理的当前矩形。 
2. 创建一个空结果列表。 

这将以螺旋顺序存储元素。 
3. 从左向右遍历顶行。 

迭代自`left`到`right`并附加：```
matrix[top][col]
```完成后，增加`top`因为该行已被完全处理。 
4. 从上到下遍历右列。 

迭代自`top`到`bottom`并附加：```
matrix[row][right]
```完成后，递减`right`。 
5. 检查是否仍有行。 

有时矩阵只剩下一行。 如果没有这个检查，我们可能会重复元素。 

如果`top <= bottom`，从右向左遍历底行。 
6. 从右向左遍历底行。 

迭代自`right`下降到`left`并附加：```
matrix[bottom][col]
```完成后，递减`bottom`。 
7. 检查柱子是否仍然存在。 

有时只剩下一列。 如果不进行此检查，元素可能会重复。 

如果`left <= right`，从下到上遍历左列。 
8. 从下到上遍历左列。 

迭代自`bottom`下降到`top`并附加：```
matrix[row][left]
```完成后，增加`left`。 
9. 重复此操作，直至跨越边界。 

循环继续，同时：```
top <= bottom and left <= right
```### 为什么它有效

 在每次迭代中，算法仅处理剩余子矩阵的一个外层。 遍历一条边后，其边界向内移动，保证没有元素被访问两次。 一旦边界交叉，循环就会停止，这意味着每个有效单元格都被处理了一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        rows = len(matrix)
        cols = len(matrix[0])

        top = 0
        bottom = rows - 1
        left = 0
        right = cols - 1

        result = []

        while top <= bottom and left <= right:
            # Traverse top row
            for col in range(left, right + 1):
                result.append(matrix[top][col])
            top += 1

            # Traverse right column
            for row in range(top, bottom + 1):
                result.append(matrix[row][right])
            right -= 1

            # Traverse bottom row
            if top <= bottom:
                for col in range(right, left - 1, -1):
                    result.append(matrix[bottom][col])
                bottom -= 1

            # Traverse left column
            if left <= right:
                for row in range(bottom, top - 1, -1):
                    result.append(matrix[row][left])
                left += 1

        return result
```实现直接遵循基于边界的算法。 

变量`top`,`bottom`,`left`， 和`right`定义剩余的矩形。 每次循环迭代都会处理该矩形的一层。 

第一个循环遍历顶行。 处理完之后，`top`向下移动，因为该行已完成。 

第二个循环遍历右列。 处理完之后，`right`向左移动。 

第三次遍历由以下人员守护`if top <= bottom`。 这可以防止在没有剩余行时进行重复处理。 

第四次遍历由以下人员守护`if left <= right`。 这可以防止在没有剩余列时进行重复处理。 

一旦所有层都被消耗掉，循环就会终止。 

## 解决方案```go
func spiralOrder(matrix [][]int) []int {
    rows := len(matrix)
    cols := len(matrix[0])

    top := 0
    bottom := rows - 1
    left := 0
    right := cols - 1

    result := []int{}

    for top <= bottom && left <= right {
        // Traverse top row
        for col := left; col <= right; col++ {
            result = append(result, matrix[top][col])
        }
        top++

        // Traverse right column
        for row := top; row <= bottom; row++ {
            result = append(result, matrix[row][right])
        }
        right--

        // Traverse bottom row
        if top <= bottom {
            for col := right; col >= left; col-- {
                result = append(result, matrix[bottom][col])
            }
            bottom--
        }

        // Traverse left column
        if left <= right {
            for row := bottom; row >= top; row-- {
                result = append(result, matrix[row][left])
            }
            left++
        }
    }

    return result
}
```Go 的实现与 Python 解决方案非常相似。 

切片用于结果容器，并且`append`随着元素的添加，切片会动态增长。 

由于矩阵值很小，因此不需要对整数溢出进行特殊处理。 该问题还保证矩阵非空，因此访问`matrix[0]`是安全的。

        bottom = rows - 1
        left = 0
        right = cols - 1

 ## 边缘情况

 ### 单行矩阵

 一个矩阵如：```
[[1,2,3,4]]
```如果算法盲目地分别处理顶行和底行，可能会导致重复遍历错误。 

遍历顶行后，`top`变得大于`bottom`。 条件：```
if top <= bottom:
```防止再次执行底部行遍历。 

### 单列矩阵

 一个矩阵如：```
[
 [1],
 [2],
 [3]
]
```左右列遍历也会产生类似的问题。 

遍历完右列后，`right`变得小于`left`。 支票：```
if left <= right:
```防止重复遍历同一列。 

### 具有中心元素的奇数矩阵

 一个矩阵如：```
[
 [1,2,3],
 [4,5,6],
 [7,8,9]
]
```最终缩小为单个中心细胞。 

那时：```
top == bottom
left == right
```循环仍然正确执行，在边界交叉之前精确处理最后一个元素。 

这保证了中心元素被包含一次且仅一次。
