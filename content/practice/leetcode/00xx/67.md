 # LeetCode 67，添加二进制

 ## 问题陈述

 给你两个字符串，`a`和`b`，其中每个字符串代表一个二进制数。 二进制数仅包含字符`'0'`和`'1'`。 任务是将这两个二进制数相加并将结果作为另一个二进制字符串返回。 

与普通的十进制加法不同，二进制加法遵循以 2 为底的规则。 每个数字只能是`0`或者`1`，并且当两位数之和超过`1`，为下一个位置产生进位。 

例如：

-`1 + 1 = 10`以二进制表示，这意味着当前数字变为`0`进位变成`1`-`1 + 1 + 1 = 11`，这意味着当前数字变为`1`并且进位仍然存在`1`输入字符串的长度可以是`10^4`字符，这意味着解决方案必须有效地处理大型二进制数。 由于在许多编程语言中字符串可能超过标准整数类型的大小，因此直接将它们转换为整数并不总是安全或可移植的。 相反，预期的解决方案是手动模拟二进制加法，就像小学从右到左的加法一样。 

该问题保证：

 - 两个字符串都只包含`'0'`和`'1'`- 两个字符串都不包含前导零，除非值本身是`"0"`- 两个字符串至少有长度`1`需要考虑一些重要的边缘情况：

 - 一根绳子可能比另一根绳子长得多
 - 加法可能会在末尾产生额外的进位，例如`"1" + "1" = "10"`- 两个字符串只能包含零
 - 非常大的输入需要高效的线性时间解决方案

 ## 方法

 ### 蛮力方法

 一个简单的想法是将两个二进制字符串都转换为整数，将它们相加，然后将结果转换回二进制字符串。 

在 Python 中，这可以使用内置函数来完成，例如`int(a, 2)`和`bin(sum)[2:]`。 虽然这种方法很简洁，但它严重依赖于对任意大整数的语言支持。 

在某些语言中，尤其是那些具有固定宽度整数类型的语言，非常大的二进制字符串可能会溢出标准整数存储。 由于输入长度可以达到`10^4`，二进制值可能远远大于 64 位整数限制。 

尽管 Python 在技术上可以处理任意大的整数，但这种方法避免了预期的二进制加法逻辑，并且不能跨语言普遍移植。 

### 最佳方法

 更好的解决方案是手动模拟二进制加法。 

关键的观察是二进制加法的行为与十进制加法完全相同，除了每个数字是`0`或者`1`。 我们从右到左处理字符串，因为最低有效位位于字符串的末尾。 

在每个位置：

 1. 添加两个字符串中的当前位
 2. 添加上一步的进位
 3. 使用模计算结果位`2`4. 使用整数除以计算新进位`2`这种方法可以在线性时间内高效工作，并避免任何溢出问题。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将二进制字符串转换为整数并返回 |
 | 最佳 | O(n) | O(n) | 直接从右到左模拟二进制加法 |

 ## 算法演练

 1. 初始化两个指针，一个在字符串末尾`a`以及字符串末尾的一个`b`。 这些指针代表当前正在处理的二进制数字。 
2. 初始化一个名为`carry`有价值`0`。 这存储了先前加法步骤的溢出。 
3. 创建一个空列表来存储生成的二进制数字。 使用列表是因为附加字符效率很高，而重复的字符串连接成本很高。 
4. 继续处理，同时：

 - 还剩下数字`a`, 或
 - 还剩下数字`b`, 或
 - 还有剩余的进位
 5. 对于每次迭代：

 - 从当前开始`carry`- 如果指针位于`a`有效，添加该位的数值
 - 如果指针位于`b`有效，添加该位的数值
 6. 计算生成的二进制数字：

 -`total % 2`给出当前位
 -`total // 2`给出新的进位
 7. 将结果位添加到结果列表中。 
8. 将两个指针向左移动一步。 
9. 处理完所有数字后，反转结果列表，因为数字是从最低有效位到最高有效位收集的。 
10. 将字符连接成最终字符串并返回。 

### 为什么它有效

 在每一步中，算法都会正确计算相应的二进制数字与传入进位的总和。 进位传播遵循二进制算术的精确规则。 由于每个数字位置都被处理一次，并且进位始终被正确保存，因此最终结果保证是正确的二进制和。 

## Python 解决方案```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        pointer_a = len(a) - 1
        pointer_b = len(b) - 1

        carry = 0
        result = []

        while pointer_a >= 0 or pointer_b >= 0 or carry:
            total = carry

            if pointer_a >= 0:
                total += int(a[pointer_a])
                pointer_a -= 1

            if pointer_b >= 0:
                total += int(b[pointer_b])
                pointer_b -= 1

            result.append(str(total % 2))
            carry = total // 2

        return "".join(reversed(result))
```该实现紧密遵循前面描述的算法。 

两个指针从字符串的末尾开始，因为二进制加法是从最低有效数字到最高有效数字进行的。 这`carry`变量存储迭代之间的溢出。 

在每次循环迭代期间，算法通过组合以下方式计算当前位置的总和：

 - 当前位来自`a`- 当前位来自`b`- 之前的进位

 所得的二进制数字由使用确定`total % 2`，而新的进位是使用计算的`total // 2`。 

这些数字以相反的顺序附加到结果列表中，因为处理是从字符串的最右侧开始的。 最后，列表被反转并连接到最终的二进制字符串中。 

## 解决方案```go
func addBinary(a string, b string) string {
    pointerA := len(a) - 1
    pointerB := len(b) - 1

    carry := 0
    result := make([]byte, 0)

    for pointerA >= 0 || pointerB >= 0 || carry > 0 {
        total := carry

        if pointerA >= 0 {
            total += int(a[pointerA] - '0')
            pointerA--
        }

        if pointerB >= 0 {
            total += int(b[pointerB] - '0')
            pointerB--
        }

        result = append(result, byte(total%2)+'0')
        carry = total / 2
    }

    left := 0
    right := len(result) - 1

    for left < right {
        result[left], result[right] = result[right], result[left]
        left++
        right--
    }

    return string(result)
}
```Go 实现遵循与 Python 版本相同的逻辑，但有一些特定于语言的细节。 

Go 字符串是不可变的，所以`[]byte`切片用于有效地构建结果。 使用减法将字符转换为整数`'0'`。 

由于数字是以相反的顺序附加的，因此在将字节切片转换回字符串之前必须手动反转字节切片。 

不存在整数溢出问题，因为该算法仅存储介于`0`和`3`在每个添加步骤中。

 ## 边缘情况

 ### 处理完所有数字后最后进位

 最常见的错误来源之一是在完全遍历两个字符串后忘记处理最后的进位。 

例如：```
a = "1"
b = "1"
```总和产生`"10"`，这需要超出原始长度的额外数字。 该实现正确处理了这个问题，因为循环继续 while`carry`是非零的。 

### 不同长度的字符串

 当字符串具有不同长度时，会出现另一个重要的边缘情况。 

例如：```
a = "101"
b = "1"
```一旦较短的字符串用完，算法必须继续处理较长字符串的剩余数字。 该实现独立地检查每个指针，因此它可以安全地处理不均匀的长度。 

### 长进位传播

 输入包含许多连续的`1`位可以产生长进位链。 

例如：```
a = "111111"
b = "1"
```每个位置都会产生另一个进位。 有缺陷的实现可能会过早停止或错误地处理重复的进位。 该解决方案将进位正确地传播到每个数字，直到没有进位剩余。 

### 两个输入都为零

 最小的有效输入是：```
a = "0"
b = "0"
```如果某些实现依赖非零进位来产生输出，则会意外返回空字符串。 此实现正确处理个位数并返回`"0"`。
