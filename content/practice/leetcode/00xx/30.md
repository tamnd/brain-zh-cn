[LeetCode 第 30 题](https://leetcode.com/problems/substring-with-concatenation-of-all-words/)

 **难度：** 🔴难
 **主题：** 哈希表、字符串、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们找到字符串中的所有起始索引`s`其中存在一个子字符串，该子字符串是数组中所有单词的串联`words`恰好一次，没有任何中间字符。 这些单词可以以任何顺序出现，并且所有单词都在`words`具有相同的长度。 

输入`s`是要在其中搜索的字符串，并且`words`是一个非空小写字符串数组。 预期输出是代表索引的整数列表`s`这样的连接子字符串开始的地方。 

这些约束告诉我们几个重要的点。 长度为`s`最多可达 10,000，同时`words`最多可包含 5,000 个元素，每个元素最多 30 个字符长。 这使得尝试每种单词排列的简单解决方案变得不可行，因为阶乘增长将是巨大的。 重要的边缘情况包括不存在连接子串的情况、单词以棘手的方式重叠或重复的单词出现在`words`。 

## 方法

 蛮力方法将尝试生成所有排列`words`并检查每个排列是否作为子串存在`s`。 这保证了正确性，但在计算上是不切实际的，因为生成`words`具有时间复杂度`O(m!)`， 在哪里`m`是单词数。 检查字符串中的每个排列会增加另一个因素`O(n)`， 在哪里`n`的长度是`s`。 

更好的解决方案的关键在于使用**滑动窗口与哈希映射**。 由于所有单词都具有相同的长度，因此我们可以检查固定长度的段`s`并维护所见单词的频率计数。 通过滑过`s`以等于字长的步长并根据目标图检查频率图`words`，我们可以有效地确定是否存在有效的串联，而无需生成所有排列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m! * n) | O(米) | 生成所有排列`words`并检查每个`s`|
 | 最佳| O(n * word_len) | O(n * word_len) | O(米) | 使用哈希图的滑动窗口跟踪词频 |

 ## 算法演练

 1. 计算每个单词的长度（`word_len`) 以及所有单词组合的总长度 (`concat_len`）。 
2. 创建哈希图`word_count`将每个单词映射到它的频率`words`。 
3. 迭代`s`和`word_len`可能的起始偏移量，以确保覆盖所有对齐方式。 
4.对于每个偏移量，使用两个指针`left`和`right`定义一个滑动窗口和`current_count`哈希映射来跟踪当前窗口中看到的单词。 
5. 移动`right`的步骤`word_len`。 如果这个词在`right`是在`word_count`，增加其计数`current_count`。 如果计数超过所需的频率，则缩小窗口`left`直至计数有效。 
6. 窗口大小是否匹配`concat_len`， 记录`left`作为起始索引。 
7. 如果单词位于`right`不在`word_count`， 重置`current_count`并移动`left`到`right + word_len`。 
8. 重复此操作，直到处理完整个字符串。 

**为什么起作用**：滑动窗口确保适当长度的每个子串都被检查一次，并且频率图保证只有有效的排列`words`被考虑。 窗口不变量确保所有单词`words`在当前窗口中出现的次数完全正确。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def findSubstring(self, s: str, words: List[str]) -> List[int]:
        if not s or not words:
            return []
        
        word_len = len(words[0])
        word_count = defaultdict(int)
        for word in words:
            word_count[word] += 1
        
        total_len = word_len * len(words)
        n = len(s)
        result = []
        
        for i in range(word_len):
            left = i
            current_count = defaultdict(int)
            count = 0
            for right in range(i, n - word_len + 1, word_len):
                word = s[right:right + word_len]
                if word in word_count:
                    current_count[word] += 1
                    count += 1
                    while current_count[word] > word_count[word]:
                        left_word = s[left:left + word_len]
                        current_count[left_word] -= 1
                        count -= 1
                        left += word_len
                    if count == len(words):
                        result.append(left)
                else:
                    current_count.clear()
                    count = 0
                    left = right + word_len
        return result
```Python 实现使用`defaultdict`有效地处理计数。 外循环迭代`word_len`处理不同对齐的起始位置。 内循环移动`right`指针的步长为`word_len`并使用调整窗口`left`必要时指针。 如果某个词不在`words`遇到时，窗口将重置。 

## 解决方案```go
func findSubstring(s string, words []string) []int {
    if len(s) == 0 || len(words) == 0 {
        return []int{}
    }

    wordLen := len(words[0])
    totalLen := wordLen * len(words)
    wordCount := make(map[string]int)
    for _, word := range words {
        wordCount[word]++
    }

    result := []int{}
    n := len(s)

    for i := 0; i < wordLen; i++ {
        left := i
        currentCount := make(map[string]int)
        count := 0
        for right := i; right+wordLen <= n; right += wordLen {
            word := s[right:right+wordLen]
            if _, ok := wordCount[word]; ok {
                currentCount[word]++
                count++
                for currentCount[word] > wordCount[word] {
                    leftWord := s[left:left+wordLen]
                    currentCount[leftWord]--
                    count--
                    left += wordLen
                }
                if count == len(words) {
                    result = append(result, left)
                }
            } else {
                currentCount = make(map[string]int)
                count = 0
                left = right + wordLen
            }
        }
    }
    return result
}
```在 Go 中，我们使用原生映射进行字数统计，使用切片操作进行子字符串提取。 逻辑反映了 Python 版本，但注意了映射初始化和切片边界。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * word_len) | O(n * word_len) | 外循环运行`word_len`次，内循环以以下步骤扫描字符串`word_len`|
 | 空间| O(米) | 地图商店的计数为`words`，最大尺寸为`words`|

 对于输入约束来说，这种复杂性足够有效。`n`可以是 10,000 并且`word_len`最多 30 个，每次字符串扫描大约提供 300,000 次操作。
