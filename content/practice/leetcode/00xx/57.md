[LeetCode 第 57 题](https://leetcode.com/problems/insert-interval/)

 **难度：** 🟡 中等
 **主题：** 数组

 ## 解决方案

 ## 问题理解

 该问题为我们提供了一个间隔列表，这些间隔已按起始值排序并保证不重叠。 每个区间代表一个连续范围，写为`[start, end]`。 

我们还获得了一个额外的间隔，`newInterval`，必须将其插入到现有列表中，同时保留两个属性：

 1. 间隔仍然按起始值排序。 
2.插入后间隔无重叠。 

如果新区间与一个或多个现有区间重叠，我们必须将它们合并为一个更大的区间。 

例如，假设我们已经有：```
[[1,3],[6,9]]
```我们插入：```
[2,5]
```间隔`[2,5]`重叠于`[1,3]`因为它们的范围相交。 合并后，结果变成：```
[[1,5],[6,9]]
```重要的细节是原始间隔已经排序并且不重叠。 这个属性使问题比任意区间合并问题容易得多，因为我们可以在一次传递中从左到右处理区间。 

约束相对较小，最多可达`10^4`间隔，但它们仍然强烈建议我们应该以线性解决方案为目标。 一个`O(n)`遍历是理想的，而重复插入和重排序会产生不必要的昂贵成本。 

一些边缘情况尤其重要：

 - 输入间隔列表可能为空。 
- 新间隔可以完全属于所有现有间隔之前。 
- 新间隔可以完全属于所有现有间隔之后。 
- 新的间隔可以按顺序重叠多个间隔。 
- 新的间隔可能已经适合而无需合并任何内容。 
- 新间隔可以完全包含现有间隔。 

因为间隔已经排序并且不重叠，所以一旦我们通过重叠区域，我们就不需要重新访问较早的间隔。 

## 方法

 ### 蛮力方法

 一个简单的方法是插入`newInterval`放入数组中，再次按起始位置对整个列表进行排序，然后运行标准区间合并算法。 

该过程如下所示：

 1. 追加`newInterval`到`intervals`。 
2. 按起始值对所有间隔进行排序。 
3、遍历排序好的区间，合并重叠的区间。 

这是可行的，因为排序后的区间合并是一种众所周知的技术。 每当当前间隔与前一个合并间隔重叠时，我们就会扩展合并范围。 

缺点是排序在运行时占主导地位。 尽管原始间隔已经排序，但此方法会忽略该结构并执行不必要的工作。 

### 最佳方法

 关键的观察结果是现有间隔已经排序并且不重叠。 

这意味着每个间隔都属于相对于以下三个类别之一`newInterval`：

 1.完全之前`newInterval`2. 重叠`newInterval`3.完全之后`newInterval`由于间隔已排序，因此在从左到右遍历期间这些类别按顺序出现。 

因此，我们可以一次性处理该数组：

 - 首先，添加之前结束的所有间隔`newInterval`开始。 
- 然后将所有重叠的区间合并为`newInterval`。 
- 最后，附加剩余的间隔。 

这完全避免了排序并实现了线性时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 插入、排序然后合并间隔 |
 | 最佳 | O(n) | O(n) | 使用间隔排序属性的单遍 |

 ## 算法演练

 1. 初始化一个空的结果列表。 

该列表将按排序顺序存储最终合并的间隔。 
2. 遍历之前完全出现的所有区间`newInterval`。 

一个区间完全在之前`newInterval`如果：$interval[1] < newInterval[0]$由于这些间隔不重叠，我们可以安全地将它们直接附加到结果中。 
3. 合并所有重叠的区间。 

当出现以下情况时，两个区间重叠：$interval[0] \le newInterval[1]$在重叠期间，我们扩展`newInterval`吸收当前间隔：

 - 新的开始成为最小开始。 
- 新的末端成为最大末端。 

从概念上讲：$newStart = \min(newStart, intervalStart),\quad newEnd = \max(newEnd, intervalEnd)$这逐渐构建了完全合并的区间。 
4.追加合并后的内容`newInterval`。 

处理完所有重叠后，`newInterval`现在代表完整的合并范围。 
5. 附加所有剩余的间隔。 

由于间隔已排序且不重叠，因此剩余的所有内容都必须位于合并间隔之后，并且可以直接附加。 

### 为什么它有效

 该算法依赖于输入间隔已经排序且不重叠的不变量。 

由于这个顺序：

 - 重叠区域之前的所有间隔都可以原样复制。 
- 所有重叠间隔连续出现。 
- 一旦重叠结束，以后的间隔就不能再次重叠。 

这保证了单次从左到右的遍历正确构造最终的合并区间列表。 

## Python 解决方案```python
from typing import List

class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        result = []
        index = 0
        n = len(intervals)

        # Add intervals completely before newInterval
        while index < n and intervals[index][1] < newInterval[0]:
            result.append(intervals[index])
            index += 1

        # Merge overlapping intervals
        while index < n and intervals[index][0] <= newInterval[1]:
            newInterval[0] = min(newInterval[0], intervals[index][0])
            newInterval[1] = max(newInterval[1], intervals[index][1])
            index += 1

        # Add the merged interval
        result.append(newInterval)

        # Add remaining intervals
        while index < n:
            result.append(intervals[index])
            index += 1

        return result
```该实现遵循算法演练的确切结构。 

第一个循环复制在新间隔开始之前结束的所有间隔。 这些间隔不能重叠，因此它们会按原样添加。 

第二个循环处理合并。 只要当前间隔与`newInterval`，我们扩大了边界`newInterval`使用`min`和`max`。 

合并完成后，更新`newInterval`表示完全组合的区间并附加到结果中。 

最后，直接复制所有剩余间隔，因为它们出现在合并区域之后。 

该算法仅对输入数组执行一次线性遍历。 

## 解决方案```go
func insert(intervals [][]int, newInterval []int) [][]int {
    result := [][]int{}
    index := 0
    n := len(intervals)

    // Add intervals completely before newInterval
    for index < n && intervals[index][1] < newInterval[0] {
        result = append(result, intervals[index])
        index++
    }

    // Merge overlapping intervals
    for index < n && intervals[index][0] <= newInterval[1] {
        if intervals[index][0] < newInterval[0] {
            newInterval[0] = intervals[index][0]
        }

        if intervals[index][1] > newInterval[1] {
            newInterval[1] = intervals[index][1]
        }

        index++
    }

    // Add merged interval
    result = append(result, newInterval)

    // Add remaining intervals
    for index < n {
        result = append(result, intervals[index])
        index++
    }

    return result
}
```Go 的实现与 Python 版本非常相似。 

一个区别是 Go 不提供内置的`min`和`max`整数函数，因此代码使用显式比较。 

Go 中的切片自然地通过以下方式处理动态调整大小`append`，使它们非常适合增量构建结果。 

不存在整数溢出问题，因为间隔值的边界为`10^5`。

 ## 边缘情况

 ### 空区间列表

 如果`intervals`是空的，没有什么可以合并的。 有缺陷的实现可能假设至少存在一个间隔，并因索引错误而失败。 

该实现自然地处理了这个问题，因为所有循环都被跳过并且`newInterval`直接附加到结果中。 

### 一切之前或之后的新间隔

 当新区间完全超出现有范围时，不应发生合并。 

例如：```
intervals = [[3,5],[7,9]]
newInterval = [1,2]
```或者：```
intervals = [[1,2],[3,5]]
newInterval = [6,8]
```一个常见的错误是将间隔插入到错误的位置或无法保留排序顺序。 该算法通过显式处理三个有序阶段的间隔来避免这种情况：之前、重叠和之后。 

### Merging Multiple Consecutive Intervals

 新间隔可以按顺序与多个间隔重叠。 

例子：```
intervals = [[1,2],[3,5],[6,7],[8,10]]
newInterval = [4,8]
```幼稚的实现可能只合并第一个重叠部分并过早停止。 

只要存在重叠，该算法就会正确地继续合并，不断扩展区间边界，直到吸收所有重叠区间。 

### 触及边界的区间

 间隔如`[1,2]`和`[2,5]`被认为是重叠的，因为它们共享边界值`2`。 

如果重叠条件使用，则会出现一个微妙的错误`<`而不是`<=`。 

实现正确使用：$interval[0] \le newInterval[1]$这可确保触摸间隔合并为单个连续间隔。
