 # LeetCode 14，最长公共前缀

 ## 问题理解

 该问题给出一个字符串数组，并要求我们找到数组中每个字符串共享的最长前缀。 

前缀是出现在字符串开头的字符序列。 例如，`"fl"`是一个前缀`"flower"`和`"flow"`因为两个字符串都以这些字符开头。 

任务是检查所有字符串并确定每个字符串共有的最长起始字符序列。 如果字符串甚至不共享一个起始字符，则答案应该是空字符串`""`。 

输入是一个字符串数组：```
strs = ["flower", "flow", "flight"]
```预期输出是：```
"fl"
```因为所有三个字符串都以`"fl"`。 

限制很小：

 - 最多可以有 200 个字符串
 - 每个字符串的长度最多可达 200

 这意味着即使相对简单的解决方案也足够快。 我们不需要高级优化，但我们仍然想要一个干净高效的实施。 

一些边缘情况很重要：

 - 数组只能包含一个字符串。 在这种情况下，整个字符串就是答案。 
- 某些字符串可能为空。 如果任何字符串为空，则最长公共前缀也必须为空。 
- 字符串可能根本不共享公共字符。 
- 一个字符串可能完全包含在另一个字符串中，例如`["car", "cart", "carbon"]`。 最短的匹配字符串限制了最大可能的前缀长度。 

一旦出现不匹配，正确的解决方案就必须停止。 

## 方法

 ### 蛮力方法

 强力解决方案将从其中一个字符串生成所有可能的前缀，然后检查所有其他字符串是否包含该前缀。 

例如，如果第一个字符串是`"flower"`，我们可以测试：```
"flower"
"flowe"
"flow"
"flo"
"fl"
"f"
""
```对于每个前缀，我们将其与其他每个字符串进行比较。 匹配所有字符串的第一个前缀就是答案。 

这种方法是正确的，因为最长公共前缀必须是第一个字符串的前缀。 通过从最长到最短检查前缀，找到的第一个有效前缀必定是答案。 

然而，这会重复创建子字符串并重复扫描字符串，从而引入了不必要的开销。 

### 最佳方法

 更好的方法是逐列比较字符。 

关键的观察是，公共前缀意味着：```
All strings have the same character at the same index.
```我们可以使用第一个字符串作为引用并逐个迭代其字符。 

在每个字符位置：

 - 将当前字符与每个其他字符串中的相应字符进行比较。 
- 如果任何字符串太短或具有不同的字符，请立即停止。 
- 该位置之前的所有内容都是最长的公共前缀。 

这工作效率很高，因为一旦出现不匹配我们就会停止，并且每个字符最多检查一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N × M²) | O(1) 不包括子字符串创建 | 反复尝试许多前缀 |
 | 最佳| O(N × M) | O(1) | O(1) | 直接比较字符 |

 这里：

-`N`是字符串的数量
 -`M`是最短字符串的长度

 ## 算法演练

 1. 首先将第一个字符串作为参考字符串。 

任何公共前缀都必须来自该字符串的开头，因此它提供了我们将测试的字符。 
2. 迭代第一个字符串中的每个字符索引。 

例如，如果第一个字符串是`"flower"`，我们检查：```
index 0 -> 'f'
index 1 -> 'l'
index 2 -> 'o'
...
```3. 对于每个索引，将该字符与所有其他字符串中相同索引处的字符进行比较。 

需要进行两项检查：

 - 如果另一个字符串比当前索引短，则前缀无法继续。 
- 如果另一个字符串具有不同的字符，则前缀也会结束。 
4. 一旦发生不匹配，就返回从开头到当前索引的子字符串。 

该子字符串包含迄今为止发现的所有匹配字符。 
5. 如果循环完成且没有不匹配，则返回整个第一个字符串。 

这意味着所有字符串中的每个字符都匹配。 

### 为什么它有效

 该算法保持当前索引之前的所有字符在每个字符串中都相同的不变性。 

一旦发生不匹配，就不再存在前缀，因为前缀要求每个字符位置都匹配。 因此，返回不匹配之前的所有字符可以保证结果是最长的有效公共前缀。 

## Python 解决方案```python
from typing import List

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        first_string = strs[0]

        for index in range(len(first_string)):
            current_char = first_string[index]

            for string in strs[1:]:
                if index >= len(string) or string[index] != current_char:
                    return first_string[:index]

        return first_string
```实现首先将第一个字符串存储在`first_string`。 该字符串充当所有比较的参考。 

外循环迭代引用字符串中的每个字符位置。 在每个索引处，当前字符存储在`current_char`。 

内部循环将该字符与每个其他字符串中相同位置的字符进行比较。 

条件：```python
index >= len(string)
```处理另一个字符串比当前前缀长度短的情况。 

条件：```python
string[index] != current_char
```检测字符不匹配。 

如果任一条件成立，算法立即返回到目前为止累积的前缀：```python
first_string[:index]
```如果循环成功完成，则整个第一个字符串在所有字符串中都是通用的，因此直接返回。 

## 解决方案```go
func longestCommonPrefix(strs []string) string {
    firstString := strs[0]

    for index := 0; index < len(firstString); index++ {
        currentChar := firstString[index]

        for i := 1; i < len(strs); i++ {
            currentString := strs[i]

            if index >= len(currentString) || currentString[index] != currentChar {
                return firstString[:index]
            }
        }
    }

    return firstString
}
```Go 实现遵循与 Python 版本相同的逻辑。 

一个显着的区别是 Go 字符串以字节为索引。 由于该问题仅保证小写英文字母，因此字节索引是完全安全的。 

Go 切片使子串提取变得高效：```go
firstString[:index]
```这将创建一个子字符串视图，无需手动复制。 

输入约束保证至少存在一个字符串，因此访问`strs[0]`是安全的。

 ## 边缘情况

 当字符串之一为空时，会出现一种重要的边缘情况。 例如：```
["", "abc"]
```空字符串不能为公共前缀提供任何字符，因此正确答案是立即`""`。 该实现自然地处理了这个问题，因为如果第一个字符串为空，则第一个字符串上的外部循环永远不会执行。 

另一个重要的情况是所有字符串都相同时：```
["test", "test", "test"]
```有缺陷的实现可能会过早停止或错误地修剪结果。 在此解决方案中，每个字符比较都会成功，因此算法在循环完成后返回整个第一个字符串。 

当一个字符串是另一个字符串的完整前缀时，会发生第三种重要的边缘情况：```
["car", "cartoon", "carpet"]
```正确答案是`"car"`。 该算法可以正确处理此问题，因为它仅迭代第一个字符串的字符。 一旦所有字符都进入`"car"`验证通过后，循环结束并返回整个字符串。 

另一个微妙的情况是当第一个字符发生不匹配时：```
["abc", "xyz"]
```该算法立即检测到索引处的不匹配`0`并返回：```
first_string[:0]
```它正确地产生空字符串。
