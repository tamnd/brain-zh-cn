[LeetCode 第 40 题](https://leetcode.com/problems/combination-sum-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、回溯

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到所有唯一的数字组合`candidates`数组，使得所选数字的总和等于`target`。 

与原始的组合和问题不同，每个数字只能使用一次。 即使一个数字在输入数组中出现多次，每次出现都会被视为一个单独的元素，但最终答案中不允许出现重复的组合。 

例如，如果输入是：```
candidates = [1,1,2]
target = 3
```然后`[1,2]`是一个有效的组合，但即使有两个，它也只能在输出中出现一次`1`s 在数组中。 

输入包括：

 -`candidates`，正整数数组
 -`target`, 一个正整数，表示所需的总和

 输出是唯一组合的列表，其中：

 - 每个组合的总和为`target`- 每个候选索引最多使用一次
 - 删除重复的组合

 这些约束提供了几个重要的观察结果：

 -`candidates.length <= 100`，它足够大，以至于暴力子集生成可能会变得昂贵
 -`target <= 30`，相对较小，有助于修剪
 -`candidates[i] <= 50`，表示数字为正数

 所有数字均为正数这一事实极其重要。 一旦运行总和超过目标，我们知道继续继续下去是无济于事的。 这允许在回溯期间进行积极的修剪。 

一些边缘情况很重要：

 - 输入中重复的数字，例如`[1,1,1,2]`- 多种方式形成相同的组合
 - 不存在有效的组合
 - 单元素数组
 - 候选者大于目标
 - 重复的值可能会意外产生重复的答案

 简单的实现常常会失败，因为它以不同的方式多次生成相同的组合。 

## 方法

 ### 蛮力方法

 暴力解决方案生成每个可能的子集`candidates`数组并检查子集之和是否为`target`。 

由于每个元素都可以包含或排除，因此有`2^n`可能的子集。 对于每个子集：

 1. 计算其总和
 2. 如果总和等于`target`，将其添加到答案中
 3.使用排序或集合去除重复项

 这种方法是正确的，因为它探索了每个可能的子集，因此不会错过任何有效的组合。 

然而，它的效率很低，因为：

 - 子集的数量呈指数增长
 - 重复生成重复的组合
 - 需要额外的工作来删除重复的结果

 对于`n = 100`，完整子集搜索是不可行的。 

### 最佳方法，回溯排序和重复跳过

 关键的见解是，我们可以首先避免生成重复项，而不是事后删除它们。 

我们首先对数组进行排序。 排序将重复的值分组在一起，使我们能够在同一递归级别中跳过重复的数字。 

该算法使用回溯：

 - 逐步构建组合
 - 追踪剩余目标
 - 一旦剩余目标变为负值，就停止探索
 - 在相同的递归深度上跳过重复的数字

 重复跳过规则是最重要的优化：```
if i > start and candidates[i] == candidates[i - 1]:
    continue
```这意味着：

 - 在给定的递归级别，仅使用第一次出现的重复值
 - 防止以不同顺序生成等价组合

 由于数字是正数且已排序，因此当候选者超过剩余目标时，我们也可以提前停止。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 生成每个子集并随后删除重复项 |
 | 最佳 | 最坏情况下的 O(2^n) | O(n) 递归深度 | 使用排序、修剪和重复跳过 |

 ## 算法演练

 1. 排序`candidates`大批。 

排序至关重要，因为重复的值会变得相邻。 这使我们能够有效地检测和跳过重复的组合。 
2. 创建递归回溯函数。 

该函数跟踪：

 - 当前起始索引
 - 剩余目标
 - 当前正在构建的组合
 3. 如果剩余目标变为零，则存储当前组合。 

这意味着我们找到了一个有效的组合，其总和等于目标。 
4. 从当前索引开始迭代候选者。 

我们只在数组中向前移动，以便每个数字最多使用一次。 
5. 跳过相同递归深度的重复项。 

如果当前数字与前一个数字相同，并且两者在同一递归级别上被考虑，则跳过它。 

这可以防止重复组合。 
6. 如果当前数量超过剩余目标，请提前停止。 

由于数组已排序并且所有数字都是正数，因此后面的每个数字也会太大。 
7. 将当前数字包含在组合中。 

将其添加到当前路径并递归搜索剩余的总和。 
8. 递归后回溯。 

删除最后添加的数字，以便下一次迭代可以探索不同的选择。 

### 为什么它有效

 该算法系统地探索每个有效组合，同时强制执行两个重要的不变量：

 - 元素仅从后面的索引中选择，确保每个索引被使用一次
 - 相同递归深度的重复值将被跳过，确保唯一性

 排序保证相同的值连续出现，从而使重复检测可靠。 

## Python 解决方案```python
from typing import List

class Solution:
    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        
        results = []
        current_combination = []
        
        def backtrack(start: int, remaining: int) -> None:
            if remaining == 0:
                results.append(current_combination[:])
                return
            
            for i in range(start, len(candidates)):
                # Skip duplicates at the same recursion level
                if i > start and candidates[i] == candidates[i - 1]:
                    continue
                
                # Early pruning
                if candidates[i] > remaining:
                    break
                
                current_combination.append(candidates[i])
                
                # Move to next index because each number can only be used once
                backtrack(i + 1, remaining - candidates[i])
                
                # Backtrack
                current_combination.pop()
        
        backtrack(0, target)
        
        return results
```实现首先对输入数组进行排序。 这使得重复跳过和早期修剪成为可能。 

这`results`列表存储所有有效的组合，而`current_combination`代表当前正在探索的路径。 

递归`backtrack`函数接收：

 -`start`，可以从中选择新元素的索引
 -`remaining`，达到目标所需的剩余金额

 如果`remaining == 0`，当前组合有效并复制到结果列表中。 

循环迭代自`start`以便每个元素最多使用一次。 重复跳过条件确保同一递归级别的相同数字不会被多次处理。 

修剪条件：```python
if candidates[i] > remaining:
    break
```有效，因为数组已排序。 一旦某个数字超过剩余目标，后面的所有数字也将超过该目标。 

通过删除最近添加的元素，在递归之后发生回溯。 

## 解决方案```go
package main

import "sort"

func combinationSum2(candidates []int, target int) [][]int {
	sort.Ints(candidates)

	var results [][]int
	var current []int

	var backtrack func(start int, remaining int)

	backtrack = func(start int, remaining int) {
		if remaining == 0 {
			combination := make([]int, len(current))
			copy(combination, current)
			results = append(results, combination)
			return
		}

		for i := start; i < len(candidates); i++ {
			// Skip duplicates at the same recursion level
			if i > start && candidates[i] == candidates[i-1] {
				continue
			}

			// Early pruning
			if candidates[i] > remaining {
				break
			}

			current = append(current, candidates[i])

			// Move to next index
			backtrack(i+1, remaining-candidates[i])

			// Backtrack
			current = current[:len(current)-1]
		}
	}

	backtrack(0, target)

	return results
}
```Go 实现遵循与 Python 版本相同的逻辑。 

一个重要的区别是切片处理。 在 Go 中，切片是对底层数组的引用，因此在存储有效组合时，我们必须创建一个副本：```go
combination := make([]int, len(current))
copy(combination, current)
```如果没有此副本，回溯期间的未来修改将改变先前存储的结果。 

Go 切片在回溯期间也会使用以下方法调整大小：```go
current = current[:len(current)-1]
```由于约束很小，因此不存在整数溢出问题。

 ## 边缘情况

 当输入包含许多重复值时，就会出现一种重要的边缘情况。 例如：```
[1,1,1,1]
```有目标`2`。 

一个简单的回溯解决方案可能会生成`[1,1]`来自不同指数的多次。 该实现使用以下方式正确处理此问题：```
if i > start and candidates[i] == candidates[i - 1]:
    continue
```这确保仅在相同的递归深度处跳过重复项。 

当不存在有效组合时，会出现另一个重要的边缘情况。 例如：```
candidates = [5,6,7]
target = 3
```由于所有数字都超过了目标，算法在排序后立即修剪递归。 结果仍然是空的。 

当候选者完全等于剩余目标时，就会出现第三种边缘情况。 例如：```
candidates = [1,2,5]
target = 5
```算法正确识别`[5]`作为一个完整的解决方案，因为基本案例检查：```
if remaining == 0:
```减法后立即。 

最后一个微妙的边缘情况涉及确保元素不被重用。 在这个问题中，每个候选只能使用一次。 该实现通过调用递归来保证这一点：```
backtrack(i + 1, ...)
```而不是：```
backtrack(i, ...)
```这会迫使未来的递归调用在数组中向前移动，从而防止重复使用同一索引。
