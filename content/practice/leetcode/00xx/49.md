[LeetCode 第 49 题](https://leetcode.com/problems/group-anagrams/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们将所有互为字谜的字符串组合在一起。 

如果两个字符串包含完全相同的字符且频率相同，但顺序可能不同，则这两个字符串被视为字谜词。 例如，`"eat"`,`"tea"`， 和`"ate"`都是字谜词，因为每个字符串包含一个`'a'`， 一`'e'`，和一个`'t'`。 

输入是一个字符串数组，称为`strs`。 每个字符串仅由小写英文字母组成。 我们的任务是返回一组组的列表，其中每个组都包含彼此不同的字符串。 

组的顺序并不重要，每个组内字符串的顺序也并不重要。 这意味着只要分组正确，多个有效输出都是可接受的。 

约束条件很重要：

 - 最多可以有`10^4`字符串
 - 每个字符串的长度可达`100`这些限制告诉我们，低效的成对比较方法可能会太慢。 我们需要一个能够有效识别两个字符串是否属于同一个字谜组的解决方案。 

一些重要的边缘情况立即脱颖而出：

 - 空字符串，例如`[""]`- 单字符串
 - 多个相同的字符串
 - 长度相同但字符频率不同的字符串
 - 具有许多重复模式的大量输入

 该问题保证所有字符串仅包含小写英文字母，这允许我们在需要时使用固定大小的字符频率数组。 

## 方法

 ### 蛮力方法

 一种简单的方法是将每个字符串与每个现有组进行比较。 

对于每个字符串，我们可以检查它是否是一组中代表性字符串的变位词。 为了确定两个字符串是否是字谜词，我们可以对两个字符串进行排序并比较结果，或者计算字符频率。 

该算法的工作原理如下：

 1. 维护组列表。 
2. 对于每个字符串：

 - 将其与每个现有组中的一个代表性字符串进行比较。 
- 如果它是一个字谜词，请将其放入该组中。 
- 否则，创建一个新组。 

这种方法是正确的，因为每个字符串都根据先前形成的组进行显式检查。 然而，随着字符串数量的增加，它的效率会变得很低。 

如果有`n`字符串并且每次比较都需要对长度的字符串进行排序`k`，总复杂度变得非常大，尤其是在存在许多组的最坏情况下。 

### 最佳方法

 关键的见解是所有字谜词都共享相同的规范表示。 

如果我们对字符串的字符进行排序，每个字谜都会产生相同的排序结果：

 -`"eat"`→`"aet"`-`"tea"`→`"aet"`-`"ate"`→`"aet"`这个排序的字符串可以充当识别字谜组的唯一键。 

我们可以使用哈希映射，其中：

 - 键是字符串的排序版本
 - 该值是属于该字谜组的字符串列表

 当我们迭代输入时：

 1.对当前字符串进行排序
 2. 使用排序后的字符串作为哈希映射键
 3. 将原始字符串附加到该组

 这极大地提高了效率，因为哈希图查找大约是`O(1)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² × k log k) | O(n² × k log k) | O(n × k) | O(n × k) | 反复比较字符串与现有组 |
 | 最佳 | O(n × k log k) | O(n × k log k) | O(n × k) | O(n × k) | 使用排序字符串作为哈希映射键 |

 这里：

-`n`是字符串的数量
 -`k`是最大字符串长度

 ## 算法演练

 1. 创建一个哈希映射，其中：

 - 密钥代表字谜组的规范形式
 - 该值是属于该组的字符串列表
 2. 迭代输入数组中的每个字符串。 
3. 对于当前字符串，按字母顺序对其字符进行排序。 

- 这将创建一个标准化的表示。 
- 所有字谜词都产生相同的标准化形式。 
- 例如：

-`"tan"`变成`"ant"`-`"nat"`也变成`"ant"`4. 使用排序后的字符串作为哈希映射中的键。 

- 如果该键尚不存在，则创建一个新的空列表。 
- 将原始字符串附加到与该键关联的列表中。 
5. 继续，直到处理完所有字符串。 
6. 返回哈希映射中的所有值。 

- 每个值都是一个字谜组。 

哈希映射在这里表现良好的原因是它提供了快速的分组行为。 一旦计算出规范表示，我们就可以在接近恒定的时间内立即找到正确的组。 

### 为什么它有效

 该算法之所以有效，是因为排序将每个字谜变换为相同的规范表示。 

如果两个字符串是字谜词，则它们包含具有相同频率的完全相同的字符。 对这些字符进行排序会产生相同的排序字符串。 因此，所有字谜都映射到相同的哈希映射键并最终位于同一组中。 

相反，非字谜词会产生不同的排序字符串，因此它们会被放入不同的组中。 

## Python 解决方案```python
from collections import defaultdict
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagram_groups = defaultdict(list)

        for word in strs:
            sorted_word = "".join(sorted(word))
            anagram_groups[sorted_word].append(word)

        return list(anagram_groups.values())
```实施首先创建一个`defaultdict(list)`。 每当遇到新键时，都会自动初始化一个空列表，从而简化了逻辑。 

对于输入数组中的每个单词，代码使用以下方式对字符进行排序`sorted(word)`。 自从`sorted()`返回字符列表，`"".join()`将其转换回字符串。 

这个排序的字符串成为字谜组的规范标识符。 

然后将原始单词附加到与散列映射中的该键相关联的列表中。 

最后，该函数将所有分组值作为列表的列表返回。 

实现直接遵循前面描述的算法：

 - 标准化每个字符串
 - 使用归一化作为分组键
 - 将相关字符串存储在一起

 ## 解决方案```go
package main

import (
	"sort"
)

func groupAnagrams(strs []string) [][]string {
	anagramGroups := make(map[string][]string)

	for _, word := range strs {
		chars := []rune(word)

		sort.Slice(chars, func(i, j int) bool {
			return chars[i] < chars[j]
		})

		sortedWord := string(chars)

		anagramGroups[sortedWord] = append(anagramGroups[sortedWord], word)
	}

	result := make([][]string, 0, len(anagramGroups))

	for _, group := range anagramGroups {
		result = append(result, group)
	}

	return result
}
```Go 实现遵循与 Python 版本相同的总体策略。 

一个显着的区别是 Go 字符串是不可变的，因此我们在排序之前将字符串转换为符文切片。 

这`sort.Slice`函数用于按升序对符文切片进行排序。 

Go 映射不会像 Python 那样自动初始化切片`defaultdict`， 但`append`即使在 nil 切片上也能正常工作，因此我们可以直接追加而无需先检查是否存在。 

最终结果是通过迭代映射值并将它们附加到结果切片中来构造的。

 ## 边缘情况

 一种重要的边缘情况是空字符串。 对空字符串进行排序仍然会产生一个空字符串，因此所有空字符串自然会映射到相同的键。 该实现无需任何特殊的条件逻辑即可处理此问题。 

另一个重要的情况涉及重复的字符，例如`"aab"`和`"aba"`。 仅检查唯一字符存在的简单实现可能会错误地将字符串分组在一起。 排序保留字符身份和频率，确保这些字符串正确映射到相同的规范表示。 

当根本没有字谜时，就会出现第三种边缘情况。 例如，`["abc", "def", "ghi"]`应该产生三个独立的组。 哈希映射自然地处理这个问题，因为每个排序的键都是不同的，导致每个字符串创建自己的组。 

最后一个微妙的边缘情况是重复的字符串。 如果输入包含同一字符串的多个副本，则所有副本都应出现在输出中。 由于该算法独立地附加每个出现的情况，因此重复项会被正确保留，而不是被覆盖或删除。
