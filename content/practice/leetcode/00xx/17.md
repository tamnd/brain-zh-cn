[LeetCode 第 17 题](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、回溯

 ## 解决方案

 ## 问题理解

 该问题给出一串数字，其中每个数字之间`2`和`9`。 每个数字对应于传统电话键盘上的一组字母：

 -`2 -> "abc"`-`3 -> "def"`-`4 -> "ghi"`-`5 -> "jkl"`-`6 -> "mno"`-`7 -> "pqrs"`-`8 -> "tuv"`-`9 -> "wxyz"`我们必须生成每一种可能的字母组合，这些组合可以通过为输入字符串中的每个数字选择一个字母来形成。 

例如，如果输入是`"23"`， 然后：

-`2`可以生产`a`,`b`， 或者`c`-`3`可以生产`d`,`e`， 或者`f`我们将第一个数字中的每个选项与第二个数字中的每个选项结合起来：

 -`ad`,`ae`,`af`-`bd`,`be`,`bf`-`cd`,`ce`,`cf`输出可以按任何顺序返回。 

限制很小：

 -`1 <= digits.length <= 4`- 每个字符之间`'2'`和`'9'`由于最大长度仅为 4，因此组合总数是可控的。 最大的分支因子出现在数字上`7`和`9`，每个映射到 4 个字母。 在最坏的情况下，我们生成`4^4 = 256`组合。 

一种重要的边缘情况是空输入字符串。 尽管官方限制规定长度至少为 1，但许多实现仍然会防御性地处理空字符串，因为 LeetCode 有时会在内部对其进行测试。 空输入的正确输出是空列表。 

另一个重要的细节是数字`0`和`1`永远不会出现。 这意味着每个数字始终具有有效的字母映射。 

## 方法

 ### 蛮力方法

 强力解决方案将通过每个数字位置的嵌套循环来手动生成所有可能的组合。 

例如：

 - 第一个数字一个循环
 - 第二个数字的另一个循环
 - 第三个数字的另一个循环
 - 第四个数字的另一个循环

 这是可行的，因为输入长度最多为 4。但是，这种方法不可扩展或不可维护。 循环次数取决于输入长度，因此代码变得笨拙且重复。 

如果问题约束发生变化，它也不会自然地概括。 

### 关键见解

 这个问题从根本上讲是关于通过决策树生成所有可能的路径。 

每个数字：

 - 我们选择一个可能的字母
 - 然后递归处理下一个数字

 这正是回溯的设计目的。 

回溯效果很好，因为：

 - 我们逐步构建组合
 - 每一步我们都知道当前的部分组合
 - 一旦组合达到与输入数字相同的长度，则组合完成
 - 递归自然地探索每一个有效的可能性

 我们使用递归来动态处理任何输入长度，而不是硬编码嵌套循环。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(4^n) | O(4^n) | O(4^n) | O(4^n) | 需要手动嵌套循环，不可扩展 |
 | 最佳| O(4^n) | O(4^n) | O(4^n) | O(4^n) | 使用回溯系统地生成组合 |

 这里，`n`是位数。 

## 算法演练

 1. 创建从数字到字母的映射。 

我们将电话键盘关系存储在哈希图中。 这允许恒定时间查找与每个数字对应的字母。 
2. 处理空输入框。 

如果输入字符串为空，则立即返回一个空列表。 没有要处理的数字，因此没有组合。 
3. 初始化结果列表。 

该列表将存储每个完成的组合。 
4. 定义递归回溯函数。 

该函数跟踪：

 - 数字字符串中的当前索引
 - 当前正在构建的部分组合
 5. 检查组合是否完整。 

如果当前组合长度等于位数，那么我们为每个数字选择一个字母。 

此时：

 - 将完成的字符串添加到结果列表中
 - 返回探索其他可能性
 6. 查找当前数字的字母。 

使用当前的数字索引，从键盘映射中检索所有可能的字母。 
7. 尝试每一个可能的字母。 

对于每个字母：

 - 将其添加到当前组合中
 - 递归处理下一个数字
 - 之后删除该字母，以便可以探索其他选择

 这种“选择、探索、取消选择”的结构是回溯的核心。 
8. 继续，直到探索完所有路径。 

递归只对每个有效组合进行一次探索。 

### 为什么它有效

 该算法保持当前部分字符串始终表示某个最终答案的有效前缀的不变量。 

在每个递归步骤中，我们都会附加一个与当前数字相对应的有效字母。 由于我们探索了每个数字位置的所有字母，因此生成了每种可能的组合。 

只有当组合长度与数字字符串长度匹配时，递归才会停止，保证每个返回的字符串都是完整且有效的。 

## Python 解决方案```python
from typing import List

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []

        digit_to_letters = {
            "2": "abc",
            "3": "def",
            "4": "ghi",
            "5": "jkl",
            "6": "mno",
            "7": "pqrs",
            "8": "tuv",
            "9": "wxyz",
        }

        result = []

        def backtrack(index: int, current_combination: str) -> None:
            if index == len(digits):
                result.append(current_combination)
                return

            current_digit = digits[index]
            possible_letters = digit_to_letters[current_digit]

            for letter in possible_letters:
                backtrack(index + 1, current_combination + letter)

        backtrack(0, "")

        return result
```实现首先处理空输入情况。 立即返回可以避免不必要的递归并符合预期的行为。 

这`digit_to_letters`字典存储电话键盘映射。 字典是理想的选择，因为它提供从数字到相关字母的直接查找。 

这`result`列表收集所有已完成的组合。 

递归`backtrack`函数有两个参数：

 -`index`, 当前正在处理的数字位置
 -`current_combination`，到目前为止构建的字符串

 当`index`达到`len(digits)`，组合完成。 该函数将其附加到结果列表中并停止更深入的探索。 

否则，该函数将检索当前数字的所有可能的字母。 它迭代这些字母并递归地构建更长的组合。 

递归调用前进到下一个数字，同时用所选字母扩展当前组合。 

最后，算法开始递归：```python
backtrack(0, "")
```这意味着：

 - 从数字索引 0 开始
 - 从一个空的组合开始

 ## 解决方案```go
func letterCombinations(digits string) []string {
	if len(digits) == 0 {
		return []string{}
	}

	digitToLetters := map[byte]string{
		'2': "abc",
		'3': "def",
		'4': "ghi",
		'5': "jkl",
		'6': "mno",
		'7': "pqrs",
		'8': "tuv",
		'9': "wxyz",
	}

	result := []string{}

	var backtrack func(index int, currentCombination string)

	backtrack = func(index int, currentCombination string) {
		if index == len(digits) {
			result = append(result, currentCombination)
			return
		}

		currentDigit := digits[index]
		possibleLetters := digitToLetters[currentDigit]

		for _, letter := range possibleLetters {
			backtrack(index+1, currentCombination+string(letter))
		}
	}

	backtrack(0, "")

	return result
}
```Go 实现遵循与 Python 版本相同的递归结构。 

一个区别是 Go 字符串是不可变的字节序列，因此可以使用以下方式访问数字`digits[index]`，它返回一个`byte`。 

因此键盘映射使用`map[byte]string`而不是带有字符串键的映射。 

另一个区别是 Go 在分配递归匿名函数之前需要显式函数变量声明：```go
var backtrack func(index int, currentCombination string)
```结果切片被初始化为空切片而不是`nil`，确保返回值一致。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(4^n) | O(4^n) | 每个数字最多可以贡献 4 个选择 |

 递归树在每一层最多分支 4 次，因为数字`7`和`9`每个映射到 4 个字母。 

如果输入长度为`n`，生成的组合总数最多为`4^n`。 

每个有效的组合都必须被构造和存储，因此时间和输出空间复杂度都与生成的组合的数量成正比。 

递归栈本身只使用`O(n)`空间，但输出列表主导整体内存使用。

 ## 边缘情况

 ### 空输入字符串

 空字符串是一种常见的边缘情况，如果处理不仔细，很容易产生错误的输出。 一个简单的递归实现可能会返回`[""]`而不是`[]`。 

实现明确检查：```
if not digits:
    return []
```这保证了正确的行为。 

### 四个字母的数字

 数字`7`和`9`映射到四个字母而不是三个：

 -`7 -> "pqrs"`-`9 -> "wxyz"`不正确的实现可能会假设每个数字恰好只有三个字母，从而导致丢失组合。 

该解决方案通过动态迭代每个数字的映射字符串而不是假设固定大小来避免此问题。 

### 最大输入长度

 最长的有效输入长度为 4。虽然这个值很小，但它仍然会生成许多组合：```
4^4 = 256
```实施不当的解决方案可能会重复复制大型中间结构或使用低效的字符串操作。 

递归回溯方法一次有效地构建组合，并且只存储完成的结果。
