 # LeetCode 59 - 螺旋矩阵 II

 ## 问题理解

 该问题要求我们生成一个`n x n`矩阵并用来自的数字填充它`1`到`n^2`以螺旋顺序。 

螺旋顺序遍历意味着我们从左上角开始并按顺时针方向移动：

 1. 从左向右移动穿过顶行
 2. 将右列从上到下移动
 3. 从右向左移动穿过底行
 4. 将左栏从下移至上

 完成一个外层后，我们对内层继续相同的过程，直到每个单元都被填充。 

例如，当`n = 3`，矩阵应变为：```
1 2 3
8 9 4
7 6 5
```每当我们到达边界时，数字会依次增加，而方向会发生变化。 

输入是单个正整数`n`。 输出是一个二维方阵，恰好包含来自`1`通过`n^2`。 

约束条件`1 <= n <= 20`告诉我们矩阵相当小。 甚至一个`O(n^2)`解决方案是完全可以接受的，因为矩阵本身包含`n^2`元素，并且每个有效的解决方案必须至少对每个单元格写入一次。 

一些边缘情况很重要：

 -`n = 1`，其中矩阵仅包含单个元素
 - 小型偶数矩阵，例如`n = 2`，其中没有单个中心单元
 - 奇数大小的矩阵，例如`n = 3`或者`n = 5`，螺旋最终到达一个中心细胞
 - 在每次定向遍历后正确更新边界，因为逐一错误在矩阵模拟问题中很常见

 ## 方法

 ### 暴力方法

 强力解决方案可以一次模拟移动一步，同时维护方向数组并检查下一个位置是否有效。 每一步，我们都尝试继续朝着当前的方向前进。 如果下一个位置在矩阵之外或已经填充，我们旋转到下一个方向。 

这种方法之所以有效，是因为它直接遵循螺旋运动规则。 我们总是将下一个数字放入当前位置，并仔细决定何时转动。 

虽然这种方法是有效的，但它需要在每次移动时重复进行边界检查和访问小区检查。 实现变得稍微复杂一些，因为我们需要：

 - 访问过的矩阵，或者
 - 特殊标记值指示已填充的单元格

 时间复杂度仍然可以接受，但逻辑不如基于边界的方法优雅。 

### 最佳方法

 最佳方法使用四个边界：

 -`top`-`bottom`-`left`-`right`这些边界描述了矩阵内当前未填充的矩形。 

我们不是一次无限地移动一步，而是一次填充当前层的一整面：

 - 填充顶行
 - 填写右栏
 - 填充底行
 - 填写左栏

 完成每一边后，我们将相应的边界向内收缩。 

这种方法效果特别好，因为螺旋遍历自然地逐层处理矩阵。 每次迭代都会在向内移动之前完成一个外环。 

该方法很干净，避免了不必要的访问跟踪，并保证每个单元格只写入一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n²) | 使用访问跟踪或方向模拟 |
 | 最佳 | O(n²) | O(1) 辅助空间 | 使用收缩边界进行逐层填充 |

 ## 算法演练

 1. 创建一个`n x n`用零初始化的矩阵。 这个矩阵最终将保存来自`1`到`n^2`。 
2. 初始化四个边界变量：

 -`top = 0`-`bottom = n - 1`-`left = 0`-`right = n - 1`这些边界定义了仍需要填充的当前矩形。 
3. 初始化变量`current = 1`。 这会跟踪要插入矩阵中的下一个数字。 
4. 从左到右填充顶行。 

迭代自`left`到`right`并放置`current`进入每个细胞。 增量`current`每次安置后。 
5. 移动`top`边界向下一。 

顶行现已完全处理，不应重新访问。 
6. 从上到下填写右栏。 

迭代自`top`到`bottom`并将数字放入最右边的列中。 
7. 移动`right`边界向左移一。 

右栏现已完成。 
8. 在继续之前，检查边界是否仍然有效。 

这很重要，因为奇数大小的矩阵可以折叠成单行或单列。 
9. 从右到左填充底行。 

向后迭代从`right`到`left`。 
10. 移动`bottom`边界向上一。 
11. 从下到上填充左栏。 

向后迭代从`bottom`到`top`。 
12. 移动`left`边界向右移一。 
13. 重复该过程`left <= right`和`top <= bottom`。 
14. 处理完所有层后，返回矩阵。 

### 为什么它有效

 该算法保持不变，即当前边界之外的所有单元格都已正确填充，而边界内部的所有单元格保持未填充。 

每次迭代完全填充螺旋的一个外层，而不重叠先前填充的单元。 处理完一条边后，相应的边界向内收缩，将剩余的问题减少到更小的子矩阵。 

因为每个单元都属于一层并且只被写入一次，所以最终的矩阵包含来自`1`到`n^2`以所需的螺旋顺序。 

## Python 解决方案```python
from typing import List

class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        matrix = [[0] * n for _ in range(n)]

        top = 0
        bottom = n - 1
        left = 0
        right = n - 1

        current = 1

        while left <= right and top <= bottom:
            # Fill top row
            for col in range(left, right + 1):
                matrix[top][col] = current
                current += 1

            top += 1

            # Fill right column
            for row in range(top, bottom + 1):
                matrix[row][right] = current
                current += 1

            right -= 1

            # Fill bottom row
            if top <= bottom:
                for col in range(right, left - 1, -1):
                    matrix[bottom][col] = current
                    current += 1

                bottom -= 1

            # Fill left column
            if left <= right:
                for row in range(bottom, top - 1, -1):
                    matrix[row][left] = current
                    current += 1

                left += 1

        return matrix
```实现首先创建用零填充的结果矩阵。 这提供了占位符值，这些值稍后将在螺旋遍历期间被替换。 

四个边界变量定义了矩阵的当前活动区域。 最初，它们覆盖整个矩阵。 

这`while`只要仍有未填充的区域，循环就会继续。 在循环内部，算法通过四个方向处理矩阵：

 - 从左到右穿过顶部
 - 从上到下右下
 - 从右到左穿过底部
 - 从左下到上

 每次定向遍历后，相应的边界都会向内调整，因为该行或列现已完成。 

填充底行和左列之前的条件检查很重要。 如果没有它们，小矩阵或奇数大小的中心层可能会导致重复写入或无效索引。 

最后返回完整的矩阵。 

## 解决方案```go
func generateMatrix(n int) [][]int {
	matrix := make([][]int, n)

	for i := 0; i < n; i++ {
		matrix[i] = make([]int, n)
	}

	top := 0
	bottom := n - 1
	left := 0
	right := n - 1

	current := 1

	for left <= right && top <= bottom {
		// Fill top row
		for col := left; col <= right; col++ {
			matrix[top][col] = current
			current++
		}

		top++

		// Fill right column
		for row := top; row <= bottom; row++ {
			matrix[row][right] = current
			current++
		}

		right--

		// Fill bottom row
		if top <= bottom {
			for col := right; col >= left; col-- {
				matrix[bottom][col] = current
				current++
			}

			bottom--
		}

		// Fill left column
		if left <= right {
			for row := bottom; row >= top; row-- {
				matrix[row][left] = current
				current++
			}

			left++
		}
	}

	return matrix
}
```Go 实现遵循与 Python 解决方案完全相同的逻辑。 

主要区别在于矩阵初始化。 在 Go 中，我们使用显式分配每一行`make([]int, n)`。 

使用 Go 切片代替 Python 列表，但从概念上讲，它们对于此问题的行为类似。 

整数溢出不是问题，因为写入的最大值是`20^2 = 400`，它很容易符合 Go 的标准整数类型。

 ## 边缘情况

 ### 单细胞矩阵

 当`n = 1`，矩阵仅包含一个单元格。 这种情况可能会暴露边界更新错误，因为算法会立即到达中心。 

该实现可以正确处理此问题，因为顶行遍历填充了单个单元格，之后边界自然失效并安全终止循环。 

### 奇数大小的矩阵

 奇数大小的矩阵最终会缩减为单个中心单元。 如果缺少边界检查，算法可能会覆盖单元格或在中心已被填充后尝试无效遍历。 

条件：```
if top <= bottom:
```和```
if left <= right:
```防止螺旋向内塌陷时重复加工。 

### 偶数大小的矩阵

 偶数大小的矩阵没有单个中心单元。 相反，螺旋在处理完最终的结果后结束`2 x 2`地区。 

如果边界以错误的顺序更新，这可能会导致相差一的错误。 该实现在完成每一边后立即更新边界，这保证了下一次遍历仅触及未填充的单元格。
