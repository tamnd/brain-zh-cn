[LeetCode 第 47 题](https://leetcode.com/problems/permutations-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、回溯、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们生成给定数组的每种可能的排列`nums`，同时确保最终结果中不包含重复的排列。 

排列是所有元素按特定顺序的排列。 例如，排列`[1,2,3]`是这三个数字的所有六种可能的排序。 

此问题的复杂之处在于输入数组可能包含重复值。 如果我们天真地生成排列，重复的数字可能会导致重复的排列。 例如，与`nums = [1,1,2]`，交换两者`1`s 不会创建新的独特排列，即使强力排列生成器会将它们视为不同的位置。 

输入是一个整数数组`nums`，输出应该是一个包含每个唯一排列的列表。 返回排列的顺序并不重要。 

限制相对较小：

 -`1 <= nums.length <= 8`-`-10 <= nums[i] <= 10`最大数组大小 8 很重要，因为排列按阶乘增长。 Even with no duplicates, there can be`8! = 40320`排列，虽然很大，但仍然可以通过有效的回溯解决方案进行管理。 

一些边缘情况很重要：

 - 包含所有重复值的数组，例如`[1,1,1]`- 不包含重复项的数组，例如`[1,2,3]`- 包含负数的数组
 - 重复出现多次的数组，例如`[1,1,2,2]`简单的实现很容易重复生成重复的排列，这会浪费时间和内存。 关键的挑战是在生成过程中有效地避免重复，而不是在之后过滤它们。 

## 方法

 ### 蛮力方法

 一种简单的方法是生成数组的每种可能的排列，即使产生重复。 生成所有排列后，我们可以将每个排列插入到一个集合中以删除重复项。 

这是有效的，因为集合只保留唯一的条目。 然而，这种方法效率低下，因为当存在重复时它仍然会产生许多冗余排列。 

例如，如果输入是`[1,1,2]`，暴力算法对待这两个`1`s 作为不同的位置并生成：

 -`[1,1,2]`-`[1,2,1]`-`[1,1,2]`-`[1,2,1]`-`[2,1,1]`-`[2,1,1]`一半的工作是多余的。 

排列的阶乘增长已经使问题变得昂贵。 生成不必要的重复项会增加运行时间和内存使用量。 

### 最佳方法

 更好的解决方案使用带有排序和重复跳过的回溯。 

关键的见解是，重复值只会在同一决策位置多次使用时才会导致重复排列。 

通过首先对数组进行排序，重复的值会变得相邻。 在回溯过程中，如果当前递归分支中没有使用前一个相同的数字，我们可以跳过选择重复的数字。 

这可以防止生成递归树的等效分支。 

例如排序后`[1,1,2]`，当考虑第二个`1`，我们只允许它如果第一个`1`已在当前排列路径中使用。 这保证了以一致的顺序选择相同的数字，从而完全消除重复的排列。 

这种方法避免了多余的工作，而不是事后清理重复项。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! × n) | O(n! × n) | O(n! × n) | O(n! × n) | 生成包括重复项在内的所有排列，然后使用 set | 删除重复项
 | 最佳 | O(n! × n) | O(n! × n) | O(n) 不包括输出 | 使用回溯、排序和重复修剪来避免冗余排列 |

 ## 算法演练

 1. 对输入数组进行排序。 

排序将重复的值放在一起。 这是至关重要的，因为它允许我们在回溯期间检测重复项。 

例如：```
[1,1,2]
```重复的`1`s 是相邻的，使得重复检查变得容易。 
2. 创建一个`used`大批。 

这`used`array 跟踪哪些索引已包含在当前排列中。 

例子：```
used = [False, False, False]
```如果`used[i]`是`True`， 然后`nums[i]`已经是当前排列路径的一部分。 
3. 从空的当前排列开始回溯。 

我们每次递归构建一个元素的排列。 

在每个递归级别，我们都会尝试每个未使用的数字。 
4. 跳过已经使用过的元素。 

如果`used[i]`是`True`，我们跳过该元素，因为每个元素只能在单个排列中出现一次。 
5. 智能跳过重复选择。 

这是最重要的一步。 

加工时`nums[i]`， 如果：```
nums[i] == nums[i - 1]
```并且之前的相同元素尚未被使用：```
not used[i - 1]
```然后我们跳过当前元素。 

这可以防止生成重复的递归分支。 

逻辑意思是：

 “如果已在此分支中选择了第一个副本，则仅使用第二个副本。”
 6. 选择一个元素。 

将当前数字添加到排列路径并将其标记为已使用。 
7. 更深层次地递归。 

继续构建排列，直到其长度等于`len(nums)`。 
8. 记录完整的排列。 

一旦排列包含所有元素，请将副本附加到结果列表中。 
9.原路返回。 

从路径中删除最后一个元素并将其标记为未使用，以便其他分支可以探索不同的可能性。 

### 为什么它有效

 该算法保证了唯一性，因为在递归期间仅允许按固定顺序出现重复项。 排序可确保相同的数字相邻，并且重复跳过规则可防止多次探索相同的递归分支。 每个有效的唯一排列仅生成一次。 

## Python 解决方案```python
from typing import List

class Solution:
    def permuteUnique(self, nums: List[int]) -> List[List[int]]:
        nums.sort()

        result = []
        current_permutation = []
        used = [False] * len(nums)

        def backtrack():
            if len(current_permutation) == len(nums):
                result.append(current_permutation[:])
                return

            for i in range(len(nums)):
                if used[i]:
                    continue

                if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                    continue

                used[i] = True
                current_permutation.append(nums[i])

                backtrack()

                current_permutation.pop()
                used[i] = False

        backtrack()
        return result
```实现首先对数组进行排序，使重复值相邻。 这会在算法中启用重复跳过条件。 

这`result`list 存储所有已完成的排列。 这`current_permutation`list 跟踪当前正在构建的排列。 这`used`数组记录了哪些索引已经被选择。 

这`backtrack()`函数执行递归搜索。 

当当前排列长度等于输入长度时，出现基本情况。 此时，排列的副本将附加到结果列表中。 

在循环内部，算法首先跳过已使用的元素。 然后它应用重复跳过规则：```python
if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
```此条件可确保以一致的顺序选择重复的值，从而防止重复排列。 

选择一个数字后，算法将其标记为已使用，将其附加到当前路径，并递归地探索更深层次的排列。 

递归完成后，算法通过删除数字并重置其使用状态来回溯。 

## 解决方案```go
func permuteUnique(nums []int) [][]int {
	result := [][]int{}

	sort.Ints(nums)

	used := make([]bool, len(nums))
	current := []int{}

	var backtrack func()

	backtrack = func() {
		if len(current) == len(nums) {
			permutation := make([]int, len(current))
			copy(permutation, current)
			result = append(result, permutation)
			return
		}

		for i := 0; i < len(nums); i++ {
			if used[i] {
				continue
			}

			if i > 0 && nums[i] == nums[i-1] && !used[i-1] {
				continue
			}

			used[i] = true
			current = append(current, nums[i])

			backtrack()

			current = current[:len(current)-1]
			used[i] = false
		}
	}

	backtrack()

	return result
}
```Go 实现遵循与 Python 版本相同的算法结构。 

一个重要的区别是 Go 中的切片是对底层数组的引用。 因此，在存储完整的排列时，我们必须使用以下命令创建一个副本`copy()`在将其附加到之前`result`。 否则，回溯期间的未来修改将影响之前存储的排列。 

这`used`slice 的行为与 Python 布尔列表类似。 

Go 在这里不需要对整数溢出进行特殊处理，因为问题约束非常小。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n! × n) | O(n! × n) | 最多可以有 n! 唯一的排列，复制每个排列的成本为 O(n) |
 | 空间| O(n) 不包括输出 | 递归堆栈、当前排列和使用的数组都需要 O(n) 空间 |

 阶乘复杂度来自可能排列的数量。 在所有数字都不同的最坏情况下，有`n!`排列。 

每个完成的排列都需要复制`n`元素到结果列表中，导致额外的乘法因子`n`。 

辅助空间是线性的，因为递归深度永远不会超过`n`，并且两个`used`最多数组和当前排列存储`n`元素。

 ## 边缘情况

 ### 所有元素都相同

 输入例如：```
[1,1,1]
```在简单的实现中很容易导致重复排列，因为交换相同的元素会重复产生相同的排列。 

重复跳过条件可以防止此问题。 在每个递归级别只允许第一个未使用的重复项，因此该算法恰好生成一个排列：```
[[1,1,1]]
```### 不存在重复项

 输入例如：```
[1,2,3]
```仅包含不同的值。 在这种情况下，重复跳过条件永远不会激活，因为相邻值永远不会相等。 

该算法自然地简化为标准排列回溯并生成所有`n!`排列正确。 

### 多个重复组

 输入如：```
[1,1,2,2]
```特别容易出错，因为重复处理必须跨多个值组独立工作。 

不正确的实现仍然可能会生成重复的排列或意外地跳过有效的排列。 

结合条件的排序数组策略：```
nums[i] == nums[i - 1] and not used[i - 1]
```确保对每个值组一致地处理重复项，从而保证每个唯一排列仅出现一次。
