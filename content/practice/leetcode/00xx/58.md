 # LeetCode 58，最后一个单词的长度

 ## 问题理解

 问题给了我们一个字符串`s`包含英文字母和空格。 在这个字符串中，单词之间用空格分隔，并且字符串的开头或结尾也可能有额外的空格。 

我们的任务是返回字符串中最后一个单词的长度。 

单词被定义为非空格字符的最大序列。 简单来说，单词是一个连续的字母块，内部没有空格。 

例如：

-`"Hello World"`包含两个词：`"Hello"`和`"World"`。 最后一句话是`"World"`，所以答案是`5`。 
-`"   fly me   to   the moon  "`在开头、单词之间和结尾处包含额外的空格。 最后一句话依然是`"moon"`，所以答案是`4`。 

限制很小：

 -`1 <= s.length <= 10^4`- 字符串仅包含英文字母和空格。 
- 保证输入至少包含一个单词。 

这些约束告诉我们，性能并不是极其重要，但我们仍然应该以干净的线性时间解决方案为目标。 

一些边缘情况很重要：

 - 最后一个单词后的尾随空格
 - 单词之间有多个空格
 - 只包含一个单词的字符串
 - 非常短的字符串，例如`"a"`- 最后一个单词有长度的字符串`1`如果假设最后一个字符始终是最后一个单词的一部分，那么幼稚的实现很容易失败。 例如，`"hello   "`以空格而不是字母结尾。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是使用空格将字符串拆分为单词。 

例如：```
s.split()
```这会自动删除多余的空格并仅返回有效的单词。 

对于输入：```
"   fly me   to   the moon  "
```结果变成：```
["fly", "me", "to", "the", "moon"]
```然后我们只需取出最后一个单词并返回它的长度。 

这种方法是正确的，因为拆分按顺序隔离了每个有效单词。 结果数组中的最后一个元素是字符串中的最后一个单词。 

缺点是`split()`创建一个包含所有单词的附加列表。 尽管限制很小，但这会使用不必要的额外内存。 

### 最佳方法

 更有效的解决方案是从右向左扫描字符串。 

关键的观察是我们只关心最终的结果。 我们不需要处理或存储字符串中的所有单词。 

该算法分两个阶段工作：

 1. 跳过字符串末尾的所有尾随空格。 
2. 计算字符数，直到遇到另一个空格或到达开头。 

这可以避免创建额外的数组或子字符串。 

由于每个字符最多被访问一次，因此该解决方案以线性时间运行，并具有恒定的额外空间。

 ## 算法演练

 1. 从字符串的最后一个索引开始。 

我们初始化一个指针`len(s) - 1`因为最后一个单词必须出现在字符串末尾附近。 
2. 跳过尾随空格。 

当当前字符是空格时，将指针向左移动。 这可以处理诸如以下的输入`"hello   "`最后一个单词后面出现空格。 
3. 计算最后一个单词的字符数。 

一旦我们到达一个字母，就开始计算字符数。 继续向左移动，直到我们：

 - 到达字符串的开头，或者
 - 遇到一个空间
 4. 返回计数。 

计数器现在包含最终单词的准确长度。 

### 为什么它有效

 该算法保持一个简单的不变量：

 - 跳过尾随空格后，指针始终指向最后一个单词的最后一个字符。 
- 计数时，每个访问过的字符都属于最后一个单词。 
- 当单词结束时循环停止。 

由于该算法永远不会跳过最终单词内的字母，并在单词边界后立即停止，因此保证结果计数是正确的。 

## Python 解决方案```python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        index = len(s) - 1

        # Skip trailing spaces
        while index >= 0 and s[index] == ' ':
            index -= 1

        length = 0

        # Count characters in the last word
        while index >= 0 and s[index] != ' ':
            length += 1
            index -= 1

        return length
```实施开始于放置`index`在字符串的最终位置。 

第一个`while`循环通过向左移动删除尾随空格，直到找到非空格字符。 这保证了指针落在最终单词的最后一个字符上。 

变量`length`存储最后一个单词的大小。 当字符不是空格时，第二个循环继续向左移动，增加遇到的每个字符的计数器。 

一旦到达空格或字符串的开头，就已计算完整单词，因此函数返回`length`。 

## 解决方案```go
func lengthOfLastWord(s string) int {
    index := len(s) - 1

    // Skip trailing spaces
    for index >= 0 && s[index] == ' ' {
        index--
    }

    length := 0

    // Count characters in the last word
    for index >= 0 && s[index] != ' ' {
        length++
        index--
    }

    return length
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 中的字符串可以直接使用索引`s[index]`，它返回一个字节。 由于该问题仅保证英文字母和空格，因此字节索引在这里是完全安全的。 

不需要对空字符串进行特殊处理，因为约束保证至少存在一个单词。

 ## 边缘情况

 ### 最后一个单词后的尾随空格

 输入例如：```
"hello   "
```可以破坏立即从最后一个字符开始计数的简单实现。 最后一个字符是一个空格，而不是最后一个单词的一部分。 

该实现通过第一个循环正确处理了这个问题，该循环在计数开始之前跳过所有尾随空格。 

### 不带空格的单个单词

 输入例如：```
"leetcode"
```仅包含一个单词。 一些实现错误地假设最后一个单词之前总是有一个分隔空格。 

此解决方案安全地继续计数，直到索引变为负数，这会正确返回整个字符串长度。 

### 单词之间有多个连续空格

 输入例如：```
"one     two"
```单词之间包含多个空格。 

写得不好的解析器可能会意外地计算空格或错误地停止。 此实现仅在第二次循环期间计算非空格字符，因此内部空格不会影响正确性。
