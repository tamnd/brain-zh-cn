 # 二叉树中序遍历

 ## 问题理解

 该问题要求我们对二叉树进行中序遍历，并以正确的顺序返回访问过的节点的值。 

二叉树是一种分层数据结构，其中每个节点最多可以有两个子节点，一个左子节点和一个右子节点。 输入`root`代表该树的根节点。 如果树是空的，`root`将`None`在 Python 中或`nil`在围棋中。 

中序遍历遵循非常特定的访问顺序：

 1. 访问左子树
 2.访问当前节点
 3. 访问右子树

 这种顺序很重要，因为它决定了最终的输出顺序。 

例如，考虑这棵树：```
    1
     \
      2
     /
    3
```中序遍历的工作原理如下：

 - 从节点开始`1`- 访问其左子树，该子树为空
 - 访问节点`1`- 移动到节点`2`- 访问节点`2`的左子树
 - 访问节点`3`- 返回节点`2`- 访问节点`2`最终结果：```
[1, 3, 2]
```约束条件告诉我们：

 - 树可以包含`0`和`100`节点
 - 节点值范围为`-100`到`100`由于树比较小，所以性能要求不是很高，但我们还是应该以最优的遍历方案为目标。 

一些重要的边缘情况包括：

 - 一棵空树
 - 一棵只有一个节点的树
 - 完全左偏的树
 - 完全右偏的树
 - 一些孩子失踪的树木

 如果处理不当，幼稚的实现很容易失败`None`或者`nil`子指针。 

## 方法

 ### 蛮力方法

 最直接的解决方案是递归深度优先遍历。 

递归算法直接反映了中序遍历的定义：

 - 递归遍历左子树
 - 记录当前节点的值
 - 递归遍历右子树

 这是有效的，因为递归自然地跟踪我们来自树中的位置。 每个递归调用都会暂停执行，直到其子树被完全处理。 

尽管此解决方案对于问题约束来说已经足够有效，但递归隐式地使用了调用堆栈。 后续问题是我们是否可以迭代地解决问题，这意味着我们应该自己显式管理遍历状态。 

### 最佳方法

 最优迭代解决方案使用显式堆栈来模拟递归。 

关键的见解是，中序遍历要求我们在访问节点之前完全处理所有左后代。 堆栈非常适合这种情况，因为它允许我们在继续探索左子节点时记住返回树的路径。 

算法反复：

 - 向左移动时推动节点
 - 一旦不再存在左子节点，就处理顶部节点
 - 之后移动到右子树

 这保证了节点按照精确的有序顺序被访问。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力递归 DFS | O(n) | O(h) | 使用递归调用堆栈 |
 | 最优迭代堆栈| O(n) | O(h) | 使用显式堆栈，避免递归 |

 这里：

-`n`是节点数
 -`h`是树的高度

 ## 算法演练

 ### 使用堆栈进行迭代中序遍历

 1. 初始化一个空堆栈和一个空结果列表。 

堆栈将帮助我们模拟递归。 结果列表按顺序存储节点。 
2. 设置一个名为`current`到根节点。 

该指针跟踪我们当前正在探索的节点。 
3. 继续循环，同时：

 -`current`不是`None`, 或
 - 堆栈不为空。 

这确保我们继续处理，直到每个节点都被访问过。 
4. 尽可能向左移动。 

尽管`current`不是`None`：

- 推`current`到堆栈上
 - 移动`current`到`current.left`我们这样做是因为中序遍历必须首先完全处理左后代。 
5. 一旦不再有留下的孩子：

 - 从堆栈中弹出顶部节点
 - 将其值添加到结果列表中

 现在该节点已准备好被访问，因为它的整个左子树已被处理。 
6. 移动到弹出节点的右子节点。 

放：```
current = current.right
```这开始遍历右子树。 
7. 重复该过程，直到堆栈为空并且`current`是`None`。 
8. 返回结果列表。 

### 为什么它有效

 堆栈始终存储其左子树已被探索但其值尚未添加到结果中的祖先。 当一个节点被弹出时，我们知道其左子树中的每个节点都已被处理，因此在移动到右子树之前访问该节点本身是安全的。 这完全符合中序遍历的定义。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []
        stack = []
        current = root

        while current or stack:
            while current:
                stack.append(current)
                current = current.left

            current = stack.pop()
            result.append(current.val)

            current = current.right

        return result
```实现首先创建两个数据结构：

 -`result`，存储遍历顺序
 -`stack`，模拟递归调用

 变量`current`从根节点开始。 

外层`while`只要还有节点需要处理（通过当前指针或存储在堆栈中的节点），循环就会继续。 

内部循环重复向左移动，同时将节点推入堆栈。 这保留了返回父节点的路径。 

一旦不再存在左子节点，算法就会从堆栈中弹出最新的节点。 由于其左子树是完整的，因此其值将附加到结果中。 

最后，遍历转移到该节点的右子树。 

这个过程一直持续到每个节点都被访问过一次。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func inorderTraversal(root *TreeNode) []int {
    result := []int{}
    stack := []*TreeNode{}
    current := root

    for current != nil || len(stack) > 0 {
        for current != nil {
            stack = append(stack, current)
            current = current.Left
        }

        current = stack[len(stack)-1]
        stack = stack[:len(stack)-1]

        result = append(result, current.Val)

        current = current.Right
    }

    return result
}
```Go 实现遵循与 Python 版本完全相同的算法结构。 

一些特定于 Go 的细节包括：

 -`nil`被用来代替`None`- 切片用于实现堆栈
 - 从堆栈中弹出需要手动调整切片大小
 - 结果切片动态增长`append`由于节点值很小并且遍历仅读取数据，因此这里不考虑整数溢出。

 ## 边缘情况

 ### 空树

 一棵空树表示为`root = None`在 Python 中或`nil`在围棋中。 如果算法在进入循环之前假设存在有效节点，则这种情况很容易处理错误。 

该实现正确处理了这个问题，因为外循环条件：```
while current or stack
```当两者都为空时立即失败，返回一个空列表。 

### 完全左偏树

 每个节点只有左子节点的树可能会暴露堆栈处理或递归深度假设的问题。 

例如：```
    4
   /
  3
 /
2
/
1
```迭代解决方案在向左降序的同时正确地推送所有节点，然后以与从堆栈中弹出的相反顺序处理它们。 

### 失踪孩子的节点

 二叉树通常是稀疏的，这意味着某些节点可能只有一个子节点。 

例子：```
    1
   /
  2
   \
    4
```不正确的实现有时假设两个子级都存在或尝试无效访问。 

该解决方案安全地检查是否`current`是`None`在访问子指针之前，确保稀疏树正确工作而不会出现运行时错误。
