 # LeetCode 78，子集

 ## 问题理解

 这个问题要求我们生成给定唯一整数数组的每个可能的子集。 子集是从数组中选择的任何元素，包括空子集和包含每个元素的子集。 

如果输入数组有`n`元素，那么正好有`2^n`可能的子集。 这是因为每个元素都有两种选择：要么包含在子集中，要么不包含。 

例如，如果输入是：```
nums = [1,2,3]
```那么：

 - 我们什么也不能选择：`[]`- 我们可以选择一个元素：`[1]`,`[2]`,`[3]`- 我们可以选择两个元素：`[1,2]`,`[1,3]`,`[2,3]`- 我们可以选择所有元素：`[1,2,3]`这些共同构成了完整的电源组。 

输入包括：

 - 整数数组`nums`- 每个元素都是独一无二的
 - 数组长度介于`1`和`10`输出必须包含按任意顺序的所有子集。 

唯一性保证很重要，因为这意味着我们不需要特殊的重复处理逻辑。 像“子集 II”这样的问题需要排序和重复跳过，但这个不需要。 

限制相对较小。 自从`nums.length <= 10`，子集的最大数量为：```
2^10 = 1024
```这告诉我们生成所有子集是可行的。 事实上，任何正确的解决方案都必须输出所有子集，因此指数时间复杂度是不可避免的。 

重要的边缘情况包括：

 - 单元素数组，例如`[0]`- 负数
 - 正确生成空子集
 - 确保在回溯期间正确复制子集，否则突变可能会破坏结果
 - 确保每个组合只生成一次

 ## 方法

 ### 蛮力方法

 暴力破解的想法是通过检查所有包含和排除的可能性来手动生成每种可能的组合。 

一种方法是：

 - 对于每个可能的子集大小`0`到`n`- 生成该大小的所有组合
 - 将它们添加到结果中

 另一种强力解释是迭代每个二进制掩码`0`到`2^n - 1`。 

例如：```
nums = [1,2,3]

000 -> []
001 -> [3]
010 -> [2]
011 -> [2,3]
100 -> [1]
101 -> [1,3]
110 -> [1,2]
111 -> [1,2,3]
```每一位确定是否包含一个元素。 

这种方法是正确的，因为每个子集都对应于一个二进制表示。 

然而，它仍然需要生成所有`2^n`子集，每个子​​集最多可以包含`n`元素。 因此，总复杂度是指数级的。 

### 最佳方法

 最佳方法是使用回溯。 

关键的见解是每个元素都会创建一个分支决策：

 - 包含当前元素
 - 排除当前元素

 通过递归地探索这两种选择，我们自然地构建了完整的幂集。 

回溯是一个自然的选择，因为：

 - 我们逐步构建子集
 - 我们可以有效地添加和删除元素
 - 递归树直接代表所有可能的决策

 在每次递归调用时：

 1. 将当前子集添加到结果中
 2. 尝试添加每个剩余元素
 3. 更深层次的递归
 4.删除元素恢复状态

 这会生成所有子集，没有重复项，也没有不必要的工作。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n × 2^n) | O(n × 2^n) | O(n × 2^n) | O(n × 2^n) | 枚举所有二进制掩码或组合 |
 | 最佳| O(n × 2^n) | O(n × 2^n) | O(n × 2^n) | O(n × 2^n) | 回溯增量构建子集 |

 尽管两种方法具有相同的渐近复杂性，但回溯更清晰、更灵活，并且更容易扩展到相关问题。 

## 算法演练

 ### 回溯算法

 1. 创建一个空结果列表来存储所有子集。 
2. 创建一个名为的辅助函数`backtrack(start, current_subset)`。 

-`start`告诉我们在哪里继续搜索。 
-`current_subset`存储当前正在构建的子集。 
3. 在每次递归调用的开始处，附加一份`current_subset`到结果。 

这是有效的，因为每个中间子集本身就是一个有效的答案。 
4. 迭代索引`start`到数组的末尾。 

对于每个索引：

 - 将当前号码添加到`current_subset`- 从下一个索引开始递归地继续搜索
 - 之后删除号码
 5、移除步骤是“回溯”操作。 

它将子集恢复到之前的状态，以便下一个递归分支干净地开始。 
6. 继续，直到探索完所有递归路径。 
7. 返回结果列表。 

### 为什么它有效

 该算法之所以有效，是因为每个递归级别都代表一个关于是否包含未来元素的决策点。 通过对每个有效延续进行一次探索，递归树覆盖了所有可能的子集。 

这`start`索引确保仅按正向顺序考虑元素，从而防止重复的子集，例如两者`[1,2]`和`[2,1]`。 

## Python 解决方案```python
from typing import List

class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        result = []

        def backtrack(start: int, current_subset: List[int]) -> None:
            result.append(current_subset[:])

            for index in range(start, len(nums)):
                current_subset.append(nums[index])
                backtrack(index + 1, current_subset)
                current_subset.pop()

        backtrack(0, [])
        return result
```实施首先创建`result`将存储所有子集的列表。 

嵌套的`backtrack`函数处理递归探索。 这`start`参数确保我们只考虑当前位置之后的元素，防止重复并保持顺序。 

在每次递归调用开始时，我们将当前子集复制到结果中。 副本很重要，因为 Python 中的列表是可变的。 如果不进行复制，以后的修改将影响之前存储的子集。 

在循环内部，我们添加一个元素，更深层次地递归，然后删除该元素。 这允许在递归调用中有效地重用相同的列表对象。 

最后，递归以空子集和起始索引开始`0`。 

## 解决方案```go
func subsets(nums []int) [][]int {
    result := [][]int{}
    currentSubset := []int{}

    var backtrack func(start int)

    backtrack = func(start int) {
        subsetCopy := make([]int, len(currentSubset))
        copy(subsetCopy, currentSubset)

        result = append(result, subsetCopy)

        for i := start; i < len(nums); i++ {
            currentSubset = append(currentSubset, nums[i])

            backtrack(i + 1)

            currentSubset = currentSubset[:len(currentSubset)-1]
        }
    }

    backtrack(0)

    return result
}
```Go 实现遵循与 Python 版本相同的递归结构。 

一个重要的区别是 Go 中的切片共享底层内存。 因此，我们必须显式创建一个副本`currentSubset`在将其附加到之前`result`。 如果我们直接附加切片，以后的修改将影响之前存储的子集。 

回溯步骤使用切片截断删除最后一个元素：```go
currentSubset = currentSubset[:len(currentSubset)-1]
```Go 在这里不需要对整数溢出进行特殊处理，因为约束非常小。

 ## 边缘情况

 ### 单元素数组

 单元素输入，例如`[0]`是最小的有效情况。 该算法仍必须生成空子集和包含元素本身的子集。 

一个常见的错误是忘记包含空子集。 此实现通过在每个递归调用开始时附加当前子集（包括初始空状态）来避免这种情况。 

### 负数

 该问题允许值介于`-10`和`10`，包括负数。 一些不正确的实现意外地只假设正整数。 

该算法从不对值本身执行算术运算。 它仅存储和删除元素，因此负数的行为与正数相同。 

### 正确的回溯状态恢复

 递归子集生成中最常见的错误之一是无法在递归后恢复状态。 

例如：```
current_subset.append(nums[index])
backtrack(index + 1, current_subset)
```没有配套的情况下`pop()`，未来的递归调用将继续使用损坏的状态。 

此实现在递归完成后正确删除最后一个元素，确保每个分支都以正确的子集配置开始。 

### 复制可变列表

 另一个微妙的问题是存储参考而不是副本。 

如果我们写：```
result.append(current_subset)
```然后每个条目`result`将引用相同的列表对象。 

通过使用：```
result.append(current_subset[:])
```该实现存储当前子集当时的独立快照。
