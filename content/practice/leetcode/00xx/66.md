[LeetCode 第 66 题](https://leetcode.com/problems/plus-one/)

 **难度：** 🟢简单
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个非空的数字数组，它们一起代表一个大整数。 数组中的每个元素都是一个十进制数字，并且这些数字按从左到右的顺序从最高有效数字到最低有效数字存储。 

例如：

-`[1,2,3]`代表数字`123`-`[4,3,2,1]`代表数字`4321`-`[9]`代表数字`9`我们的任务是给这个整数加一，并将结果数字作为新的数组表示形式返回。 

重要的细节是整数可能非常大。 该问题有意将数字表示为数组而不是标准整数类型。 在某些语言中，直接将数组转换为整数可能会溢出极大值的数值限制。 尽管这里的限制最多只有 100 位数字，但预期的解决方案是直接操作数字，而不是依赖内置的大整数转换。 

这些约束告诉我们一些有用的信息：

 -`1 <= digits.length <= 100`- 数组始终非空。 
- 该数字最多可以包含 100 位数字，这比许多标准整数类型可以安全存储的数字还要大。 
-`0 <= digits[i] <= 9`- 每个元素都保证是有效的十进制数字。 
- 没有前导零

 - 输入如`[0,1,2]`永远不会出现。 
- 表示始终有效且标准化。 

有几种重要的边缘情况可能会导致简单实现中的错误。 

当最后一位数字不是时，就会出现第一个主要边缘情况`9`。 在这种情况下，我们可以简单地增加最后一位数字并立即停止。 例如，`[1,2,3]`变成`[1,2,4]`。 

当数字以一个或多个结尾时，会出现第二个重要的边缘情况`9`s。 加一会导致进位传播。 例如：

-`[1,2,9]`变成`[1,3,0]`-`[1,9,9]`变成`[2,0,0]`最重要的边缘情况是每个数字都是`9`。 在这种情况下，数字的长度会增加：

 -`[9]`变成`[1,0]`-`[9,9,9]`变成`[1,0,0,0]`正确的解决方案必须正确处理跨多个数字的进位传播，并在必要时创建新的前导数字。 

## 方法

 ### 蛮力方法

 一种简单的方法是将数字数组转换为整数，加一，然后将结果转换回数字数组。 

例如：

 1. 转换`[1,2,3]`化为整数`123`2. 计算`123 + 1 = 124`3. 转换`124`回到`[1,2,4]`这种方法在概念上很简单，并且可以产生正确的答案，因为它直接模拟算术运算。 

然而，这种方法有重要的缺点。 所表示的数字可能变得非常大，可能超出许多编程语言中的标准整数限制。 Python 支持任意精度整数，但像 Go 这样的语言本身不支持 100 位整数，除非有特殊的库。 

此外，表示之间的转换会带来不必要的开销。 该问题是专门为鼓励直接数字操作而设计的。 

### 最佳方法

 更好的解决方案是直接在数字数组上模拟小学加法。 

当数字加一时：

 - 从最低有效数字开始，最右边的数字
 - 如果数字小于`9`，增加它并停止
 - 如果数字是`9`，就变成`0`并产生一个进位到下一个数字
 - 继续向左传播进位，直到没有进位剩余
 - 如果所有数字都是`9`，创建一个新数组，前导为`1`关键的见解是只有尾随的后缀`9`s 在添加过程中发生变化。 一旦进位停止，左边的数字保持不变。 

例如：

-`[1,2,3]`- 最后一位数字变为`4`- 立即完成
 -`[1,2,9]`-`9`变成`0`- 携带增量`2`到`3`-`[9,9,9]`- 每个数字都变成`0`- 需要新的领先`1`该解决方案完全避免了整数转换，并且可以有效地处理任意大的输入。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将数字转换为整数并返回 |
 | 最佳 | O(n) | O(1) 或 O(n) | 通过进位传播进行直接数字操作 |

 ## 算法演练

 1. 从数组的最后一个索引开始迭代。 

我们从最低有效数字开始，因为加法是从右向左进行的。 这反映了手工算术的工作原理。 
2. 检查当前位数是否小于`9`。 

如果数字不是`9`，我们可以安全地将其加一而不产生进位。 

例子：

-`[1,2,3]`- 最后一位数字`3`变成`4`- 结果是`[1,2,4]`至此，操作完成，所以我们立即返回数组。 
3. 如果当前数字是`9`，将其设置为`0`。 

加一到`9`产生`10`，这意味着：

 - 当前位置变为`0`- 进位移动到左边的下一个数字

 示例：

 -`[1,2,9]`-`9`变成`0`- 继续向左进位
 4. 继续向左移动，同时保持剩余。 

每个尾随`9`变成`0`直到我们遇到小于的数字`9`。 

例子：

-`[1,9,9]`- 最右边`9`变成`0`- 下一个`9`变成`0`-`1`变成`2`- 最终结果是`[2,0,0]`5. 处理好所有的事情`9`的情况。 

如果循环结束没有返回，那么每个数字都是原来的`9`。 

例子：

-`[9,9,9]`- 所有数字都变成`0`- 我们需要一个额外的前导数字

 返回：

 -`[1,0,0,0]`### 为什么它有效

 该算法之所以有效，是因为小数加法仅影响进位传播中涉及的数字。 当一个数字小于`9`递增后，进位立即停止，所有更有效的数字保持不变。 如果一个数字是`9`，加一迫使它变成`0`并向左传播进位。 通过从右到左处理数字，该算法精确地模拟了标准的以 10 为底的加法，保证了正确的结果。 

## Python 解决方案```python
from typing import List

class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        # Traverse from right to left
        for index in range(len(digits) - 1, -1, -1):
            # If digit is less than 9, increment and return
            if digits[index] < 9:
                digits[index] += 1
                return digits

            # Otherwise, set current digit to 0 and continue carry
            digits[index] = 0

        # If all digits were 9, add leading 1
        return [1] + digits
```该实现遵循算法演练中描述的确切逻辑。 

循环从最后一个索引开始，并在数组中向后移动。 这个方向很重要，因为最低有效数字是加法发生的第一个位置。 

在循环内部，代码检查当前数字是否小于`9`。 如果是，我们增加该数字并立即返回更新后的数组，因为不需要进一步的进位传播。 

如果数字等于`9`，该数字变为`0`，并且进位继续到左边的下一个位置。 

如果循环完成而没有返回，则每个数字最初都是`9`。 在这种情况下，数字的长度会增加，因此我们在前面添加一个`1`到修改后的数组。 

例如：

-`[9]`变成`[0]`加工过程中
 - 最终回报变为`[1,0]`该实现简洁、高效，并且直接对算术进位行为进行建模。 

## 解决方案```go
func plusOne(digits []int) []int {
	for i := len(digits) - 1; i >= 0; i-- {
		// If digit is less than 9, increment and return
		if digits[i] < 9 {
			digits[i]++
			return digits
		}

		// Otherwise set current digit to 0
		digits[i] = 0
	}

	// All digits were 9
	result := make([]int, len(digits)+1)
	result[0] = 1

	return result
}
```Go 实现使用与 Python 版本相同的进位传播逻辑。 

一个显着的区别是所有的处理`9`的情况。 在Python中，我们可以简单地返回`[1] + digits`。 In Go, slices cannot be concatenated that way, so we allocate a new slice with length`len(digits) + 1`。 

新切片会自动用零初始化，因此设置`result[0] = 1`产生所需的输出。 例如：

 - 原文：`[9,9,9]`- 新切片：`[1,0,0,0]`Go 整数很容易就足够了，因为我们从不将整个数字转换为单个整数值。 我们只处理单个数字。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 在最坏的情况下，每个数字都会被处理一次 |
 | 空间| O(1) 或 O(n) | 通常就地，但全 9 的情况需要一个新数组 |

 该算法最多从右向左遍历数组一次。 因此，运行时间与位数成线性关系。 

大多数情况下直接修改输入数组并使用恒定的额外空间。 然而，当每个数字都是`9`，我们必须分配一个带有一位附加数字的新数组。 因此，最坏情况的辅助空间复杂度在技术上是`O(n)`。

 ## 边缘情况

 当最后一位数字不是时，就会出现一个重要的边缘情况`9`。 在这种情况下，算法应在增加最后一位数字后立即停止。 有错误的实现可能会继续不必要的处理或意外地修改较早的数字。 当前的实现通过在增加一个小于的数字后立即返回来正确处理这个问题`9`。 

当数字以多个连续的结尾时，会出现另一个关键的边缘情况`9`s。 加一会导致跨多个位置的进位传播。 例如，`[1,9,9]`必须成为`[2,0,0]`。 仅处理单个进位的实现在这里会失败。 基于循环的进位传播正确处理每个尾随`9`。 

最重要的边缘情况是当所有数字都是`9`。 在这种情况下，结果数字包含一位额外的数字。 例如，`[9,9,9]`变成`[1,0,0,0]`。 许多错误的解决方案忘记在所有进位传播后扩展数组长度。 当循环完成但没有返回时，此实现会检测到这种情况，并创建一个带有前导的新数组`1`。 

另一个微妙的边缘情况是单元素数组，例如`[9]`或者`[0]`。 小数组经常会暴露索引错误或相差一错误。 因为该算法从右到左仔细处理索引并处理所有 -`9`单独的情况下，这些输入工作正常。
