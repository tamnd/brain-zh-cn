 # LeetCode 74 - 搜索二维矩阵

 ## 问题理解

 这个问题为我们提供了一个具有两个非常重要的排序属性的二维矩阵：

 1. 每行从左到右按非降序排序。 
2. 每行的第一个元素都大于前一行的最后一个元素。 

这两个保证一起意味着整个矩阵的行为就像一个全局排序的列表。 

例如，这个矩阵：```
[
  [1, 3, 5, 7],
  [10, 11, 16, 20],
  [23, 30, 34, 60]
]
```可以看作：```
[1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]
```该问题要求我们确定给定的`target`值存在于矩阵中的某个位置。 

关键要求是算法必须运行在`O(log(m * n))`时间复杂度，其中：

 -`m`是行数
 -`n`是列数

 这立即表明基于二分搜索的解决方案是值得期待的，因为二分搜索自然会在排序数据上以对数时间运行。 

限制相对较小：

 -`1 <= m, n <= 100`- 矩阵值范围为`-10^4`到`10^4`尽管矩阵大小足够小，足以在实践中通过暴力破解，但问题明确需要对数复杂度，因此我们必须有效地使用矩阵排序。 

需要记住的一些重要的边缘情况包括：

 - 仅包含一个元素的矩阵
 - 小于最小元素的目标
 - 大于最大元素的目标
 - 位于第一个或最后一个位置的目标
 - 只有一行的矩阵
 - 只有一列的矩阵

 该问题保证每一行都存在并且至少包含一个元素，因此我们不需要处理锯齿状或畸形矩阵。 

## 方法

 ### 蛮力方法

 最直接的解决方案是逐一扫描矩阵中的每个元素。 

我们迭代每一行，然后迭代该行内的每个值。 如果找到目标，我们就返回`True`。 如果我们扫描完整个矩阵而没有找到它，我们返回`False`。 

这种方法是正确的，因为它会检查目标可能出现的每个可能位置。 

但其时间复杂度为`O(m * n)`因为可能需要访问每个元素。 这不满足要求`O(log(m * n))`复杂。 

### 最佳方法，虚拟排序数组上的二分搜索

 关键的观察结果是，当逐行查看时，矩阵是全局排序的。 

因为：

 - 每行都已排序，并且
 - 每行的第一个元素大于前一行的最后一个元素，

 矩阵可以被视为单个排序的一维数组。 

我们可以用数学方式模拟这种映射，而不是在物理上压平矩阵。 

如果矩阵有`n`列：

 - 行索引变为`mid // n`- 列索引变为`mid % n`这让我们可以直接在矩阵上执行二分搜索，而无需额外的空间。 

由于二分搜索将每次迭代的搜索范围减半，因此运行时间变为`O(log(m * n))`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(1) | O(1) | 按顺序检查每个元素 |
 | 最佳 | O(log(m * n)) | O(log(m * n)) | O(1) | O(1) | 在虚拟排序数组上使用二分搜索 |

 ## 算法演练

 1. 确定矩阵维度。 

我们存储：

 -`rows = len(matrix)`-`cols = len(matrix[0])`虚拟一维数组和实际矩阵坐标之间的索引转换需要这些值。 
2. 初始化二分查找边界。 

由于矩阵的行为就像大小的排序数组`rows * cols`，有效索引为：

 -`left = 0`-`right = rows * cols - 1`3. 计算中间位置。 

在每次迭代期间：```
mid = (left + right) // 2
```这表示虚拟扁平数组内的索引。 
4. 将虚拟索引转换为矩阵坐标。 

我们将一维索引映射回二维坐标：```
row = mid // cols
col = mid % cols
```这是有效的，因为每一行都包含精确的`cols`元素。 
5. 将矩阵值与目标值进行比较。 

取回：```
value = matrix[row][col]
```然后比较：

 - 如果`value == target`， 返回`True`- 如果`value < target`, 搜索右半部分
 - 如果`value > target`, 搜索左半部分
 6. 继续，直到搜索空间耗尽。 

如果`left`变得大于`right`，目标在矩阵中不存在，所以返回`False`。 

### 为什么它有效

 该算法之所以有效，是因为矩阵排序保证了逐行读取元素会产生完全排序的序列。 

二分搜索依赖于一个不变量：剩余的搜索范围始终是排序的。 由于我们的虚拟展平数组已排序，因此每次比较都允许我们安全地丢弃一半的剩余元素。 

索引转换公式将虚拟索引正确映射回矩阵位置，因此每个二分搜索步骤都会访问正确的矩阵元素。 

## Python 解决方案```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        rows = len(matrix)
        cols = len(matrix[0])

        left = 0
        right = rows * cols - 1

        while left <= right:
            mid = (left + right) // 2

            row = mid // cols
            col = mid % cols

            value = matrix[row][col]

            if value == target:
                return True

            if value < target:
                left = mid + 1
            else:
                right = mid - 1

        return False
```实现首先计算矩阵维度。 由于保证矩阵至少包含一行和一列，因此访问`matrix[0]`是安全的。 

变量`left`和`right`定义虚拟展平数组的搜索范围。 该代码不是构建实际的一维列表，而是动态转换索引。 

在循环内部，通常为二分查找计算中点。 公式：```python
row = mid // cols
col = mid % cols
```将展平索引转换为实际的矩阵坐标。 

该位置的值与目标值进行比较。 根据比较结果，算法会丢弃剩余搜索范围的一半。 

如果找到目标，函数立即返回`True`。 否则，当搜索区间变空时，函数返回`False`。 

## 解决方案```go
func searchMatrix(matrix [][]int, target int) bool {
    rows := len(matrix)
    cols := len(matrix[0])

    left := 0
    right := rows*cols - 1

    for left <= right {
        mid := (left + right) / 2

        row := mid / cols
        col := mid % cols

        value := matrix[row][col]

        if value == target {
            return true
        }

        if value < target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }

    return false
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

Go 自动对整数操作数使用整数除法，因此：```go
row := mid / cols
```正确计算行索引。 

Go 中的切片自然地代表矩阵行，因此访问`matrix[row][col]`工作原理与 Python 列表类似。 

该问题保证至少一行和一列，因此不需要额外的 nil 或空检查。

 ## 边缘情况

 ### 单元素矩阵

 只包含一个值的矩阵是最小的可能有效输入。 由于不正确的循环条件或边界更新，二分搜索实现有时会在很小的范围内失败。 

例如：```
[[5]]
```如果目标是`5`，算法立即检查索引`0`并返回`True`。 如果目标不同，则搜索范围在一次迭代后失效并正确返回`False`。 

### 目标小于最小值或大于最大值

 当目标位于矩阵范围之外时，算法应干净地终止，而不会出现无效索引。 

例如：```
matrix = [[1, 3, 5]]
target = -1
```或者：```
target = 100
```二分搜索自然地通过缩小搜索间隔来处理这些情况，直到`left > right`。 

### 单行或单列

 一些实现意外地假设两个维度都大于一维。 

例如：```
[[1, 2, 3, 4]]
```或者：```
[[1],
 [3],
 [5]]
```索引映射公式仍然可以正常工作，因为：```
row = mid // cols
col = mid % cols
```即使当`cols == 1`或者`rows == 1`。 

### 目标位于矩阵边界

 位于矩阵最开头或最末尾的目标可能会在二分搜索实现中暴露一个错误。 

示例包括：```
target = matrix[0][0]
```和：```
target = matrix[rows - 1][cols - 1]
```该算法可以正确处理这些问题，因为初始搜索范围包括来自`0`通过`rows * cols - 1`。
