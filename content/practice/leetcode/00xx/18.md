 # LeetCode 18 - 4Sum

 ## 问题陈述

 我们给定一个整数数组`nums`和一个整数`target`。 目标是找到数组中每个唯一的四元组，其总和等于目标值。 

四元组由四个元素组成：```
nums[a], nums[b], nums[c], nums[d]
```其中所有四个索引都是不同的。 输出应仅包含唯一的四元组，这意味着产生相同四个值的不同索引组合应仅出现一次。 

最终答案中四元组的顺序并不重要，只要避免重复，每个四元组内元素的顺序也并不重要。 

输入大小比较适中，`nums.length <= 200`。 这个值足够大，以至于简单的暴力解决方案变得不切实际，因为随着数组大小的增加，检查每个可能的四元组的数量增长得非常快。 

数组内的值和目标的范围可以是`-10^9`到`10^9`。 这意味着：

 - 允许负数
 - 允许正数
 - 大整数和是可能的
 - 我们必须小心重复处理

 一些边缘情况很重要：

 - 少于四个元素的数组不能产生任何四元组
 - 具有许多重复值的数组可以轻松创建重复的答案
 - 如果适用，仅包含相同数字的数组仍应仅返回一个有效的四元组
 - 在某些语言中，较大的正值和负值可能会产生溢出问题
 - 可能存在多个有效的四联体

 该问题仅保证输入是有效的整数数组和目标值。 它不保证输入中的唯一性、排序或任何特殊结构。 

## 问题理解

 该问题要求我们搜索数组并识别每组唯一的四个数字，其总和等于目标值。 

例如，给定：```
nums = [1,0,-1,0,-2,2]
target = 0
```我们需要找到所有总和为零的四个数字组。 

一个有效的组是：```
[-2, -1, 1, 2]
```因为：```
-2 + -1 + 1 + 2 = 0
```另一个有效组是：```
[-2, 0, 0, 2]
```关键的挑战是避免重复。 由于数组可能包含重复的值，因此不同的索引组合可以生成相同的四元组值。 我们必须仅返回每个唯一的四元组一次。 

该问题是经典 2Sum 和 3Sum 问题的扩展。 自然的进展是：

 - 2Sum 使用散列或两个指针
 - 3Sum 修复一个数字并解决 2Sum
 - 4Sum 修复两个数字并解决 2Sum

 最佳解决方案利用排序和两指针技术来显着降低复杂性。 

## 方法

 ### 蛮力方法

 暴力解决方案检查每个可能的四元组。 

我们可以使用四个嵌套循环：

 - 第一个循环选择第一个元素
 - 第二次循环选择第二个元素
 - 第三次循环选择第三个元素
 - 第四次循环选择第四个元素

 对于每个四元组，我们计算总和并将其与目标进行比较。 

如果总和与目标匹配，我们将四元组添加到结果集中。 为了避免重复，我们需要一个额外的机制，例如包含排序元组的哈希集。 

这种方法是正确的，因为它详尽地检查了四个索引的每种可能的组合。 然而，它的速度非常慢。 

和`n = 200`，组合数变为：```
O(n^4)
```这太贵了。 

### 最佳解决方案的关键见解

 关键的观察是，一旦数组排序完毕，我们就可以使用两指针技术降低问题的复杂性。 

而不是独立尝试所有四个元素：

 - 修复第一个数字
 - 修正第二个数字
 - 使用两个指针找到剩余的两个数字

 排序后：

 - 如果当前总和太小，则将左指针向右移动
 - 如果当前总和太大，则将右指针向左移动
 - 如果总和与目标匹配，则记录四元组并跳过重复项

 排序可以有效地消除重复，并允许两指针搜索正常工作。 

这降低了复杂性`O(n^4)`到`O(n^3)`。

 ## 算法演练

 ### 最优算法

 1. 对数组进行排序。 

排序至关重要，因为它使我们能够：

 - 使用两指针技术
 - 有效地跳过重复项
 - 根据总和比较做出指针移动决策
 2. 使用索引迭代数组`i`。 

这将选择四元组的第一个数字。 

跳过重复值`i`以避免产生重复的四胞胎。 
3. 对于每个`i`, 用索引迭代`j`。 

这将选择四元组的第二个数字。 

再次，跳过重复值`j`。 
4. 初始化两个指针。 

放：

-`left = j + 1`-`right = len(nums) - 1`这些指针搜索剩余的两个数字。 
5. 计算当前总和。 

当前的四元组总和为：```
nums[i] + nums[j] + nums[left] + nums[right]
```6. 将总和与目标进行比较。 

- 如果总和小于目标，则移动`left`向前增加总和
 - 如果总和大于目标，则移动`right`向后减少总和
 - If the sum equals the target, record the quadruplet
 7. Skip duplicates after finding a valid quadruplet.

 Move the pointers past repeated values so the same quadruplet is not added again.
 8. 继续直到`left >= right`。 

一旦指针交叉，当前的所有有效对`(i, j)`的组合进行了探索。 

### 为什么它有效

 该算法之所以有效，是因为排序创建了单调结构。 

对于固定指数`i`和`j`:

 - 搬家`left`向右总是增加或保留总和
 - 搬家`right`向左总是减少或保留总和

 这保证了每个有效对都被恰好发现一次。 

重复跳过可确保唯一性，因为重复值在每个迭代级别首次出现后将被忽略。 

## Python 解决方案```python
from typing import List

class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        result = []

        n = len(nums)

        for i in range(n - 3):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            for j in range(i + 1, n - 2):
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue

                left = j + 1
                right = n - 1

                while left < right:
                    current_sum = (
                        nums[i]
                        + nums[j]
                        + nums[left]
                        + nums[right]
                    )

                    if current_sum < target:
                        left += 1

                    elif current_sum > target:
                        right -= 1

                    else:
                        result.append([
                            nums[i],
                            nums[j],
                            nums[left],
                            nums[right]
                        ])

                        left += 1
                        right -= 1

                        while (
                            left < right
                            and nums[left] == nums[left - 1]
                        ):
                            left += 1

                        while (
                            left < right
                            and nums[right] == nums[right + 1]
                        ):
                            right -= 1

        return result
```实现首先对数组进行排序。 这是两指针策略和重复处理的基础。 

外循环选择四元组的第一个元素。 在处理之前，代码检查当前值是否与先前值相同。 如果是这样，它会跳过迭代以避免重复的四元组。 

第二个循环使用相同的重复跳过逻辑选择第二个元素。 

固定前两个元素后，使用两个指针找到剩余的两个元素。 

这`left`指针立即开始`j`，而`right`指针从数组末尾开始。 

该算法计算四数和：```python
current_sum = nums[i] + nums[j] + nums[left] + nums[right]
```如果总和太小，则左指针向右移动。 如果总和太大，则右指针向左移动。 

当总和与目标匹配时，四元组将添加到结果列表中。 然后两个指针都向内移动，并跳过重复的值以防止重复答案。 

最后返回结果列表。 

## 解决方案```go
package main

import "sort"

func fourSum(nums []int, target int) [][]int {
	sort.Ints(nums)

	result := [][]int{}
	n := len(nums)

	for i := 0; i < n-3; i++ {
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}

		for j := i + 1; j < n-2; j++ {
			if j > i+1 && nums[j] == nums[j-1] {
				continue
			}

			left := j + 1
			right := n - 1

			for left < right {
				currentSum := nums[i] +
					nums[j] +
					nums[left] +
					nums[right]

				if currentSum < target {
					left++

				} else if currentSum > target {
					right--

				} else {
					result = append(result, []int{
						nums[i],
						nums[j],
						nums[left],
						nums[right],
					})

					left++
					right--

					for left < right &&
						nums[left] == nums[left-1] {
						left++
					}

					for left < right &&
						nums[right] == nums[right+1] {
						right--
					}
				}
			}
		}
	}

	return result
}
```Go 实现遵循与 Python 版本相同的逻辑。 

Go 中的一个重要考虑因素是整数溢出。 Since the constraints allow values up to`10^9`，在某些系统上，对四个整数求和可能会超出 32 位整数范围。 去的`int`现代平台上的类型通常是 64 位，这在这里就足够了，但是使用`int64`在具有严格可移植性要求的生产系统中会更安全。 

结果存储为整数切片的切片：```go
[][]int
```Go 不区分`nil`对于 LeetCode 提交来说，空切片的方式存在问题，因此返回空切片是可以接受的。

 ## 边缘情况

 ### 具有许多重复值的数组

 重复处理是此问题中最常见的错误来源。 

考虑：```
[2,2,2,2,2]
```如果不小心地跳过重复项，该算法可能会多次生成相同的四元组。 

该实现通过以下方式避免了这种情况：

 - 重复跳过`i`价值观
 - 重复跳过`j`价值观
 - 重复跳过`left`和`right`比赛后的值

 这保证了唯一性。 

### 小于四个元素的数组

 如果数组包含的数字少于四个，则不能存在四元组。 

例如：```
[1,2,3]
```循环自然会处理这个问题，因为：```
range(n - 3)
```变为空时`n < 4`。 

因此，该算法可以安全地返回一个空列表，而不需要特殊情况的代码。 

### 大整数值

 约束允许的值高达：```
10^9
```对四个此类值求和可能会超过 32 位整数限制。 

Python 自动处理大整数，因此溢出不是问题。 

在 Go 中，标准`int`type 通常在现代系统上就足够了，但开发人员应该意识到具有严格 32 位整数的语言中的溢出风险。 

### 多个有效四胞胎共享号码

 不同的有效四元组可以在不同的位置重复使用相同的值。 

例如：```
[-2, -1, 0, 0, 1, 2]
```包含几个重叠的解决方案。 

该算法正确地探索了每一个有效的`(i, j)`pair 并使用两个指针来穷尽所有剩余的可能性，确保不会错过任何有效的四元组。
