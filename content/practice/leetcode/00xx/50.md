 ## 解决方案

 ## 问题理解

 该问题要求我们手动实现求幂，具体计算：$$x^n$$在哪里`x`是一个浮点数并且`n`是一个整数指数。 

输入由两个值组成：

 -`x`, 基数
 -`n`, 指数

 输出应该是提高的结果`x`权力`n`。 

几个例子阐明了这种行为：

 -`2^10 = 1024`-`2.1^3 = 9.261`-`2^-2 = 1 / (2^2) = 1/4 = 0.25`这些约束很重要，因为它们立即排除了大指数的朴素解决方案。 

指数范围为：$$-2^{31} \le n \le 2^{31}-1$$这意味着`n`可能非常大，约为 20 亿数量级。 倍增的解决方案`x`就其本身而言`|n|`在最坏的情况下，时间会太慢。 

该问题还包括负指数。 数学上：$$x^{-n} = \frac{1}{x^n}$$因此，如果指数为负数，我们必须反转底数并使用正指数。 

另一个微妙的问题是某些语言中的整数溢出。 尤其，`-(-2^31)`在 Java 或 C++ 等语言中溢出 32 位有符号整数。 Python 会自动处理大整数，但 Go 在转换负指数时仍然需要小心处理。 

该问题保证：

 - 要么`x != 0`- 或者`n > 0`这可以防止未定义的情况，例如`0^-1`。 

重要的边缘情况包括：

 -`n = 0`，因为任何非零数的零次方都等于`1`- 负指数
 - 非常大的指数
 - 负碱基
 - 分数基数
 - 最小整数指数，`-2^31`如果不小心处理，这些情况很容易破坏幼稚的实现。 

## 方法

 ### 蛮力方法

 最简单的想法就是乘法`x`反复。 

如果`n`是积极的：$$x^n = x \times x \times x \times \dots$$执行的`n`次。 

如果`n`为负数，我们计算：$$x^{-n}$$然后取倒数。 

这种方法简单且正确，因为求幂实际上就是重复乘法。 

然而，时间复杂度与指数大小成线性关系：$$O(|n|)$$和`n`可能大约20亿，这是完全不切实际的。 

### 最佳方法，二进制求幂

 关键的观察是求幂具有递归结构。 

考虑：$$x^{10}$$而不是乘以`x`十次，我们可以写：$$x^{10} = (x^5)^2$$和：$$x^5 = x \times (x^2)^2$$每一步都会将指数大约减半。 

这种技术称为二元求幂、平方求幂或快速幂。 

中心思想是：

 - 如果`n`是偶数：$$x^n = (x^{n/2})^2$$- 如果`n`是奇数：$$x^n = x \times x^{n-1}$$通过反复将指数减半，算法以对数时间而不是线性时间运行。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O( | n | ) |
 | 最佳 | O(log | n | ) |

 ## 算法演练

 我们将使用二进制求幂的迭代版本，因为它避免了递归开销并使用恒定的额外空间。 

1. 处理负指数。 

如果`n`为负数，我们使用数学恒等式：$$x^{-n} = \frac{1}{x^n}$$所以我们替换：

 -`x`和`1/x`-`n`和`-n`经过这个变换，我们只需要解决正指数的情况。 
2. 初始化结果。 

从以下开始：```
result = 1
```这是有效的，因为乘以`1`不改变该值。 
3. 逐位处理指数。 

指数被视为二进制数。 

例如：$$13_{10} = 1101_2$$这意味着：$$x^{13} = x^8 \times x^4 \times x^1$$每个二进制数字告诉我们幂是否对最终答案有贡献。 
4. 如果当前指数位为奇数，则将结果相乘。 

什么时候`n % 2 == 1`，当前功率为`x`应包含在答案中。 

所以我们这样做：```
result *= x
```5. 将底座摆正。 

处理完当前位后，我们转向下一个幂：```
x *= x
```这会生成：$$x, x^2, x^4, x^8, x^{16}, \dots$$6. 将指数减半。 

移至下一个二进制数字：```
n //= 2
```7. 重复直到指数变为零。 

处理完所有二进制数字后，`result`包含最终答案。 

### 为什么它有效

 二进制求幂之所以有效，是因为每个整数都可以表示为 2 的幂之和。 

例如：$$13 = 8 + 4 + 1$$所以：$$x^{13} = x^8 \times x^4 \times x^1$$该算法通过重复平方来系统地生成这些幂，并仅乘以与指数中的设置位相对应的幂。 由于每次迭代指数减半，因此运算次数是对数。 

## Python 解决方案```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        # Handle negative exponents
        if n < 0:
            x = 1 / x
            n = -n

        result = 1.0

        while n > 0:
            # If current bit is set
            if n % 2 == 1:
                result *= x

            # Square the base
            x *= x

            # Move to next bit
            n //= 2

        return result
```实现首先检查指数是否为负数。 如果是，则将底数反转并将指数转换为正数。 这将问题转化为标准的正指数计算。 

变量`result`开始于`1.0`，充当乘法恒等式。 

这`while`循环一次处理一位二进制数字的指数。 每当当前指数为奇数时，当前的幂`x`有助于最终答案，因此它被乘以`result`。 

每次迭代都会对基数进行平方，因为每一步都会移动到下一个 2 的幂：$$x \rightarrow x^2 \rightarrow x^4 \rightarrow x^8$$最后，使用整数除法将指数减半。 这会丢弃已经处理过的二进制数字。 

当指数达到零时，所有位均已处理完毕，结果完成。 

## 解决方案```go
func myPow(x float64, n int) float64 {
    exponent := int64(n)

    // Handle negative exponents
    if exponent < 0 {
        x = 1 / x
        exponent = -exponent
    }

    result := 1.0

    for exponent > 0 {
        // If current bit is set
        if exponent%2 == 1 {
            result *= x
        }

        // Square the base
        x *= x

        // Move to next bit
        exponent /= 2
    }

    return result
}
```Go 解决方案遵循与 Python 实现相同的算法结构。 

Go 的一个重要细节是转换`n`到`int64`。 这可以防止处理最小整数值时溢出：$$-2^{31}$$直接在 32 位有符号整数类型中对该值取负将会溢出。 使用`int64`安全地适应转换。 

与 Python 不同，Go 使用显式浮点类型，例如`float64`，因此所有算术都使用该类型执行。

 ## 边缘情况

 ### 负指数

 负指数是最常见的错误来源之一。 幼稚的实现可能会尝试直接与负循环界限重复乘法，这没有数学意义。 

正确的变换是：$$x^{-n} = \frac{1}{x^n}$$该实现通过在进入主循环之前反转基数并将指数转换为正数来立即处理此问题。 

### 最小整数指数

 价值：$$-2^{31}$$在固定宽度整数系统中是有问题的，因为它的正对应项不能在相同的有符号范围内表示。 

在 Go 中，直接使用 32 位整数取反该值可能会溢出。 该解决方案通过将指数转换为来避免这种情况`int64`否定之前。 

Python 整数会自动扩展，因此 Python 实现不会遇到此问题。 

### 零指数

 数学上：$$x^0 = 1$$对于所有非零`x`。 

一些实现意外返回`0`或跳过处理这种情况。 在这个算法中，`result`开始于`1`，并且循环永远不会执行`n == 0`，所以自然会返回正确的值。 

### 负碱基

 负底需要小心处理，因为符号取决于指数是偶数还是奇数。 

示例：$$(-2)^3 = -8$$

$$(-2)^4 = 16$$二进制求幂会自动保留此行为，因为它在整个计算过程中使用普通的乘法规则。
