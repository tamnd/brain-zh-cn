[LeetCode 问题 2605](https://leetcode.com/problems/form-smallest-number-from-two-digit-arrays/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、枚举

 ## 解决方案

 ## 问题理解

 问题给了我们两个数组，`nums1`和`nums2`，其中每个数组包含来自的唯一数字`1`到`9`。 我们需要构造尽可能小的数字，使得该数字至少包含每个数组中的一位数字。 

短语“每个数组至少包含一位数字”是关键要求。 有效答案可以是：

 1. 单个数字（如果两个数组中都存在该数字）。 
2. 如果没有共同数字，则为两位数。 

如果一个数字同时出现在两个数组中，则该数字本身就已经满足条件，因为它同时属于两个数组。 由于任何一位数字总是小于任何两位数字，因此最小的公共数字立即成为最佳答案。 

如果没有公共数字，那么我们必须使用其中的一位数字构建一个两位数字`nums1`和一位数字`nums2`。 为了最大限度地减少数量，我们希望：

 - 最小可能的十位数字。 
- 然后是最小的可能数字。 

例如：

-`nums1 = [4,1,3]`-`nums2 = [5,7]`没有共同的数字。 中最小的数字`nums1`是`1`，以及中的最小数字`nums2`是`5`。 两种可能的顺序是：

 -`15`-`51`清楚地，`15`较小。 

限制非常小：

 - 每个数组长度最多为`9`- 数字范围从`1`到`9`- 每个数组内的数字都是唯一的

 这些限制告诉我们，即使是低效的方法也能顺利工作。 然而，目标仍然是设计一个干净且逻辑上最佳的解决方案。 

有几个重要的边缘情况：

 - 数组可能已经共享一个数字。 
- 最小的公共数字可能不是任一数组中的第一个元素。 
- 数组可能有完全不相交的数字。 
- 最小的有效两位数可能需要颠倒所选数字的顺序。 

该问题保证：

 - 每个值都是有效数字`1`到`9`- 数组非空
 - 同一数组中的数字是唯一的

 由于这些保证，我们不需要处理重复项或空输入数组。 

## 方法

 ### 蛮力方法

 暴力解决方案会尝试所有可能的有效数字。 

首先，我们可以检查所有个位数的可能性`1`通过`9`查看该数字是否出现在两个数组中。 如果存在，我们返回最小的数字。 

如果不存在公共数字，我们将使用以下方法生成每个可能的两位数字：

 - 一位数字来自`nums1`- 一位数字来自`nums2`对于每对`(a, b)`，我们形成：

 -`10 * a + b`-`10 * b + a`然后我们记录最小有效数量。 

这种方法之所以有效，是因为它明确地检查每个候选人的答案。 由于输入大小很小，因此组合的总数非常少。 

然而，强力方法会执行不必​​要的工作，因为一旦我们认识到问题的数学结构，我们实际上并不需要生成所有组合。 

### 最佳方法

 关键的见解是一位数的答案总是比两位数的答案更好。 

因此：

 - 首先，搜索数组之间的公共数字。 
- 如果存在，则立即返回最小的公共数字。 
- 否则，从每个数组中取出最小的数字，并以尽可能小的顺序组合它们。 

认为：

-`min1 = min(nums1)`-`min2 = min(nums2)`答案一定是：

 -`min(min1 * 10 + min2, min2 * 10 + min1)`这是有效的，因为：

 - 十位中任何更大的数字都会产生更大的数字。 
- 个位中任何较大的数字也会增加该值。 

约束很小，因此使用哈希集进行快速成员资格检查使实现简单而高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × m) | O(1) | O(1) | 生成所有可能的组合 |
 | 最佳| O(n + m) | O(n) | 使用集合有效地检测常见数字 |

 ## 算法演练

 1. 转换`nums1`到一个哈希集中。 

我们使用集合是因为​​成员资格检查非常快。 这使我们能够快速确定一个数字是否来自`nums2`也存在于`nums1`。 
2. 搜索常见数字。 

遍历中的每个数字`nums2`。 如果该数字存在于创建的集合中`nums1`，那么它是两个数组共享的公共数字。 
3. 追踪最小的公共数字。 

由于可能存在多个公共数字，因此我们保留最少的一个。 一位数总是小于任何两位数，因此，如果我们找到任何公共数字，则最小的自动为最终答案。 
4. 如果存在公共数字，则立即返回。 

至此，我们已经知道没有两位数可以击败一位数。 
5. 否则，计算每个数组中的最小数字。 

让：

-`smallest1 = min(nums1)`-`smallest2 = min(nums2)`6. 组成两个可能的两位数。 

有效数字是：

 -`smallest1 * 10 + smallest2`-`smallest2 * 10 + smallest1`7. 返回两者中较小的一个。 

这保证了最小可能的两位数答案。 

### 为什么它有效

 该算法依赖于数字的简单排序属性：

 - 每个一位数字都小于每个两位数字。 
- 因此，如果存在公共数字，则最小的公共数字一定是最优的。 
- 如果不存在公共数字，则最小的两位数必须使用两个数组中最小的可用数字，并按较小的顺序排列。 

因为该算法穷尽了所有数学上最佳的可能性，所以它总是产生正确的最小数。 

## Python 解决方案```python
from typing import List

class Solution:
    def minNumber(self, nums1: List[int], nums2: List[int]) -> int:
        nums1_set = set(nums1)

        smallest_common = 10

        for digit in nums2:
            if digit in nums1_set:
                smallest_common = min(smallest_common, digit)

        if smallest_common != 10:
            return smallest_common

        smallest1 = min(nums1)
        smallest2 = min(nums2)

        return min(
            smallest1 * 10 + smallest2,
            smallest2 * 10 + smallest1
        )
```实现从转换开始`nums1`到一个集合中，以便成员资格检查变得高效。 

变量`smallest_common`被初始化为`10`，它大于任何有效数字。 迭代时`nums2`，代码检查每个数字是否也存在于`nums1_set`。 如果是，算法将更新迄今为止找到的最小公共数字。 

循环后：

 - 如果发现公共数字，算法会立即返回它。 
- 否则，它计算每个数组中的最小数字。 

最后，该代码形成两种可能的两位数字并返回较小的数字。 

实现直接遵循算法演练中建立的逻辑结构。 

## 解决方案```go
func minNumber(nums1 []int, nums2 []int) int {
    nums1Set := make(map[int]bool)

    for _, digit := range nums1 {
        nums1Set[digit] = true
    }

    smallestCommon := 10

    for _, digit := range nums2 {
        if nums1Set[digit] {
            if digit < smallestCommon {
                smallestCommon = digit
            }
        }
    }

    if smallestCommon != 10 {
        return smallestCommon
    }

    smallest1 := nums1[0]
    for _, digit := range nums1 {
        if digit < smallest1 {
            smallest1 = digit
        }
    }

    smallest2 := nums2[0]
    for _, digit := range nums2 {
        if digit < smallest2 {
            smallest2 = digit
        }
    }

    option1 := smallest1*10 + smallest2
    option2 := smallest2*10 + smallest1

    if option1 < option2 {
        return option1
    }

    return option2
}
```Go 实现遵循与 Python 版本相同的逻辑。 由于 Go 没有内置的集合类型，`map[int]bool`用于模拟哈希集。 

最小值是通过循环手动计算的，因为 Go 没有提供内置的`min`切片函数。 

不存在整数溢出问题，因为所有值都是很小的两位数。

 ## 边缘情况

 当数组共享一个数字时，会出现一个重要的边缘情况。 幼稚的实现可能仍然尝试构造两位数，但这将是不正确的，因为任何一位数都小于每两位数。 该实现通过首先检查常见数字并立即返回找到的最小数字来处理此问题。 

当根本没有重叠时，会出现另一种边缘情况。 在这种情况下，算法必须仔细构造尽可能小的两位数字。 简单地连接最小的数字`nums1`第一个并不总是最佳的。 例如：

-`nums1 = [8]`-`nums2 = [2]`正确答案是`28`， 不是`82`。 该实现正确地评估了两个排序并返回较小的一个。 

第三种边缘情况涉及最小尺寸的数组。 由于两个数组可能只包含一个元素，因此某些实现可能会错误地假设存在多个候选元素。 即使每个数组只包含一位数字，当前的解决方案也能正常工作，因为逻辑不依赖于大于 1 的数组长度。 

另一个微妙的边缘情况是迭代过程中没有首先遇到公共数字。 例如：

-`nums1 = [5, 2, 8]`-`nums2 = [9, 8, 2]`两个都`8`和`2`是常见数字，但正确答案是`2`。 该实现跟踪最小公共数字，而不是返回找到的第一个数字，以确保正确性。
