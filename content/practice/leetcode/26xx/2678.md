[LeetCode 第 2678 题](https://leetcode.com/problems/number-of-senior-citizens/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们统计一个列表中严格年龄超过 60 岁的乘客数量。每个乘客的信息被压缩为 15 个字符的固定长度字符串。 该字符串的结构如下：前十个字符代表电话号码，第十一个字符代表性别，第十二和第十三个字符代表年龄，最后两个字符代表座位号。 

输入是一个字符串数组，每个字符串正好有 15 个字符。 我们保证所有电话号码和座位号都是唯一的，并且年龄部分始终为两位数。 我们的任务是解析每个字符串的年龄，检查它是否大于 60，并返回满足该条件的数量。 

要考虑的边缘情况包括最小和最大可能的年龄值（例如“00”或“99”），并确保字符串切片正确提取年龄数字而不会出现相差一的错误。 输入大小限制为最多 100 个元素，因此性能不是主要问题。 

## 方法

 蛮力方法很简单。 对于每个乘客，我们提取与年龄对应的子字符串，将其转换为整数，并检查它是否大于 60。如果是，我们增加一个计数器。 由于我们独立处理每位乘客，因此这种方法是正确且简单的。 考虑到问题的限制，它已经足够有效了。 

不需要进一步优化，因为输入量很小并且算法的复杂度本质上是线性的。 关键的观察是我们不需要任何辅助数据结构，并且对数组的一次传递就足够了。 

| 方法| 时间复杂度| 空间复杂度| 笔记|

 | 蛮力 | O(n) | O(1) | O(1) | 迭代每位乘客，提取年龄，并计算是否 > 60 |
 | 最佳| O(n) | O(1) | O(1) | 和蛮力一样，由于约束已经是最优的 |

 ## 算法演练

 1.初始化一个计数器变量`senior_count`至 0。 
2. 迭代每个字符串`detail`在`details`大批。 
3. 提取与年龄相对应的子字符串，该子字符串位于索引 11 和 12（0 索引）处。 这可以通过以下方式完成`detail[11:13]`。 
4. 将年龄子字符串转换为整数。 
5. 检查整数值是否大于 60。如果是，则递增`senior_count`。 
6. 处理完所有乘客后返回`senior_count`。 

**为什么起作用**：该算法正确识别每个字符串的年龄部分，并仅计算 60 以上的字符串。由于每个字符串的长度都保证为 15，并且年龄始终以两位数表示，因此不存在解析歧义，确保了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def countSeniors(self, details: List[str]) -> int:
        senior_count = 0
        for detail in details:
            age = int(detail[11:13])
            if age > 60:
                senior_count += 1
        return senior_count
```在这个实现中，我们首先初始化一个计数器。 对于每个乘客字符串，我们切出年龄部分（`detail[11:13]`)，将其转换为整数，并检查它是否超过 60。每次超过 60 时，我们都会递增计数器。 最后，我们返回总数。 这直接遵循算法演练并处理问题所保证的所有边缘情况。 

## 解决方案```go
import "strconv"

func countSeniors(details []string) int {
    seniorCount := 0
    for _, detail := range details {
        ageStr := detail[11:13]
        age, _ := strconv.Atoi(ageStr)
        if age > 60 {
            seniorCount++
        }
    }
    return seniorCount
}
```在 Go 中，我们迭代切片中的每个字符串，提取年龄子字符串，使用以下命令将其转换为整数`strconv.Atoi`，如果年龄大于 60，则增加计数器。Go 需要显式错误处理`Atoi`，但在这个问题中，输入在年龄位置上保证是数字，因此忽略错误是安全的。 切片索引的工作方式与 Python 类似，因此`detail[11:13]`提取正确的两字符子字符串。

 ## 边缘情况

 一个重要的边缘情况是年龄正好是 60 岁。该问题指定“严格超过 60 岁”，因此不应计算 60 岁。 切片和整数比较可以正确处理这个问题。 

另一个边缘情况是年龄子字符串以零开头，例如“06”或“09”。 将字符串解析为整数可以正确地将它们解释为 6 和 9，从而避免相差一或字符串比较错误。 

第三种边缘情况是允许的最大输入长度。 对于 100 名乘客，算法必须有效地处理整个数组。 由于它的运行时间为O(n)，空间为O(1)，所以很容易满足这个要求。 此外，固定长度字符串保证可以防止在切片年龄部分时出现索引错误。
