 ## 解决方案

 ## 问题理解

 该问题要求我们确定在边长等边三角形中将初始三角形涂成红色的最小集合`n`，这样通过重复应用传播规则，所有三角形最终都会变成红色。 传播规则很简单：任何具有**至少两个红色邻居**的白色三角形都会自动变成红色。 

输入`n`指定三角形的大小，其中`n`行。 每行`i`有`2i - 1`三角形索引自`1`到`2i - 1`。 输出应该是表示初始红色三角形的坐标的二维列表，选择该列表使得初始红色三角形的数量`k`是最小的。 

要点：

 - 如果三角形有一条边，则它们就有邻居。 边和角三角形的邻居较少。 
- 需要最小的红色三角形集来触发连锁反应，最终为所有三角形着色。 
- 限制：`1 <= n <= 1000`，这意味着该算法必须有效地扩展到大约 1,000,000 个单位三角形。 暴力模拟是不可行的。 

重要的边缘情况包括`n = 1`（单个三角形），`n = 2`（易于追踪传播的小三角形），以及`n`非常大（测试效率）。 该问题保证任何问题都存在解`n >= 1`。 

## 方法

 ### 蛮力方法

 暴力解决方案将尝试尝试最初红色三角形的所有可能组合并模拟传播。 这涉及检查三角形的每个子集，对它们进行着色是否最初会导致完全传播。 这在原则上是正确的，但在计算上是不可行的：`O(n^2)`三角形，子集的数量是指数的（`2^(n^2)`），这是不可能的`n = 1000`。 

### 关键见解和最佳方法

 关键的见解是，红色的传播方式存在一种模式**。 通过观察较小的示例，我们可以看到最小的初始红色三角形沿着 **所有边缘定位，步长为 2**。 本质上，以棋盘图案对边界三角形进行着色可确保每个内部三角形最终都会有至少两个红色邻居并变成红色。 

最佳方法是**基于模式的选择**：

 1.给第一个三角形上色`(1,1)`然后从左侧开始沿每行每隔一个三角形。 
2. 这涵盖了将红色传播到三角形网格中的每个三角形所需的所有位置。 
3. 该模式保证了初始红色三角形的数量最少。 

关键是识别**传播模式**，而不是模拟每一步。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n^2)) | O(2^(n^2)) | O(n^2) | O(n^2) | 检查所有子集，模拟传播 |
 | 最佳 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 使用行步进的基于模式的初始红色三角形 |

 ## 算法演练

 1.初始化一个空列表`res`保存最初红色三角形的坐标。 
2. 迭代每一行`i`从`1`到`n`。 
3. 在每一行中，迭代列`j`从`1`到`2i - 1`，从奇数行中的第一个三角形开始选择**每隔一个三角形**。 这确保了传播的覆盖范围。 
4. 附加每个选定的三角形`(i, j)`到`res`。 
5. 返回`res`作为最初红色三角形的最终列表。 

**为什么有效：** 沿行对每个其他三角形进行着色可确保三角形内的每个白色三角形最终至少有两个红色邻居，从而满足传播规则。 这保证了所有三角形都变成红色，同时最小化初始红色三角形的数量。 

## Python 解决方案```python
from typing import List

class Solution:
    def colorRed(self, n: int) -> List[List[int]]:
        res = []
        for i in range(1, n + 1):
            # Choose triangles in odd positions in the row for propagation
            for j in range(1, 2 * i, 2):
                res.append([i, j])
        return res
```**说明：** 我们迭代每一行`i`。 对于每一行，我们选择列`j`从 1 开始，步骤 2。这捕获了最小初始红色三角形所需的“棋盘”图案，以保证完全传播。 

## 解决方案```go
func colorRed(n int) [][]int {
    res := [][]int{}
    for i := 1; i <= n; i++ {
        for j := 1; j < 2*i; j += 2 {
            res = append(res, []int{i, j})
        }
    }
    return res
}
```**说明：** Go 版本镜像 Python 逻辑。 我们将切片用于动态数组。`append`用于收集初始红色三角形。 步骤 2 确保相同的模式。 空切片初始化相当于Python列表。

 初始红色三角形：`[[1,1],[2,1],[2,3]]`。 

传播：

 | 步骤| 新的红色三角形| 说明|
 | ---| ---| ---|

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^2) | O(n^2) | 我们对每行和行中的每个三角形迭代一次。 |
 | 空间| O(n^2) | O(n^2) | 输出列表大约包含三角形总数的一半 (n^2/2)。 |

 推理：每一行都有`2i - 1`三角形，求和`i = 1 to n`给出`n^2`。 选择每隔一个三角形会减少计数，但渐近复杂度仍为 O(n^2)。 存储随着选定三角形的数量而扩展。

 ## 边缘情况

 **边缘情况 1：n = 1**

 三角形只有一个单位。 算法正确返回`[[1,1]]`。 不需要传播，但最小的初始红色集恰好是一个三角形。 

**边缘情况 2：偶数行长度与奇数行长度**

 具有偶数个三角形的行仍然可以正常工作，因为我们从第一个三角形开始选择所有其他三角形。 这确保内部三角形最终有两个红色邻居。 偶数长度的行不需要额外的逻辑。 

**边缘情况 3：大 n (n=1000)**

 性能至关重要。 该算法以确定性模式迭代行和列，并且不模拟传播。 内存使用量缩减一半`n^2`，在给定约束的情况下这是可以接受的。 这可以避免任何堆栈溢出或 TLE。 

这种方法可以处理所有边缘情况，同时保证最小的初始红色三角形和正确的完整传播。
