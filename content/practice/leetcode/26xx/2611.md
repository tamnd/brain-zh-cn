[LeetCode 问题 2611](https://leetcode.com/problems/mice-and-cheese/)

 **难度：** 🟡 中等
 **主题：** 数组、贪婪、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 问题给了我们两个数组，`reward1`和`reward2`，其中每个索引代表一种特定类型的奶酪。 每块奶酪必须被两只老鼠中的一只吃掉。 

如果奶酪`i`被第一只老鼠吃掉，我们得到`reward1[i]`点。 如果它被第二只老鼠吃掉，我们将获得`reward2[i]`点。 

关键的限制是第一只老鼠必须准确地吃东西`k`奶酪。 所有剩余的奶酪都会自动被第二只老鼠吃掉。 

我们的目标是最大化两只小鼠收集的总奖励的总和。 

换句话说，对于每块奶酪，我们必须决定哪只老鼠应该吃它。 由于第一只老鼠只能精确进食`k`奶酪，我们要仔细选择`k`当分配给第一只老鼠而不是第二只老鼠时，奶酪会产生最大的好处。 

输入大小可以大到`10^5`，它立即告诉我们指数或二次解是不可行的。 我们需要一个接近的算法`O(n log n)`或更好。 

一个重要的观察是，每种奶酪总会贡献一些奖励。 如果我们最初假设第二只老鼠吃掉了所有奶酪，那么总得分如下：```
sum(reward2)
```每当我们将奶酪从第二只老鼠换到第一只老鼠时，总分就会发生变化：```
reward1[i] - reward2[i]
```该值表示分配奶酪带来的额外收益或损失`i`到第一只鼠标而不是第二只鼠标。 

因此问题就变成了：

 - 从分配给鼠标 2 的所有奶酪开始
 - 准确选择`k`收益最大的奶酪
 - 将这些收益添加到总数中

 重要的边缘情况包括：

 -`k = 0`，意味着第二只老鼠吃掉了所有东西
 -`k = n`，意味着第一只老鼠吃掉所有东西
 - Equal rewards where switching mice changes nothing
 - Negative differences, where assigning a cheese to mouse 1 is actually worse, but we may still be forced to choose it because exactly`k`奶酪必须交给鼠标 1
 - 非常大的数组，需要高效的排序或堆使用

 ## 方法

 ### 蛮力方法

 暴力解决方案会尝试所有可能的选择`k`为第一只老鼠准备奶酪。 

对于每个组合：

 1.分配那些`k`奶酪给老鼠1
 2. 将所有剩余的奶酪分配给鼠标 2
 3. 计算总奖励
 4. 跟踪最大值

 这种方法保证能找到最佳答案，因为它探索了每一个有效的作业。 

然而可供选择的方式有很多`k`奶酪来自`n`是：```
C(n, k)
```对于大量输入，该值呈指数增长。 和`n`最多`100000`，暴力破解就变得完全不可能了。 

### 最优贪心法

 关键的见解是我们不需要独立考虑两只老鼠。 

相反：

 1. 假设老鼠 2 最初吃掉所有东西
 2. 计算将每种奶酪换成小鼠 1 的好处
 3. 选择`k`好处最大的奶酪

 对奶酪的好处`i`是：```
reward1[i] - reward2[i]
```如果该值较大且为正，则将奶酪分配给小鼠 1 非常有利。 

如果这个值为负数，老鼠 2 会更愿意吃它，但我们可能仍然需要分配一些负差奶酪，如果`k`很大。 

通过按降序对这些差异进行排序并选择顶部`k`，我们保证最大可能的总奖励。

 ## 算法演练

 1. 假设第二只小鼠吃掉所有奶酪，计算基线分数。```
total = sum(reward2)
```这为我们提供了一个方便的起点，因为无论如何，每种奶酪都会有所贡献。 
2. 对于每种奶酪，计算如果第一只老鼠吃掉它所获得的额外收益。```
gain = reward1[i] - reward2[i]
```正值表示小鼠 1 更适合这种奶酪。 负值表示鼠标 2 更好。 
3. 将所有增益存储在列表中。```
differences = []
```4. 按降序对增益进行排序。 

收益最大的奶酪是老鼠 1 最有价值的候选者。 
5.选择顶部`k`收益。 

因为老鼠 1 必须准确地吃东西`k`奶酪，我们选择`k`最大的差异。 
6. 将这些收益添加到基线总计中。```
total += selected_gain
```7. 返回最终总奖励。 

### 为什么它有效

 该算法之所以有效，是因为每块奶酪都有贡献`reward2[i]`在基线配置中。 将奶酪分配给鼠标 1 会精确地改变总数：```
reward1[i] - reward2[i]
```由于这些变化是相互独立的，因此最大化最终分数相当于选择`k`最大的收获。 排序保证我们为小鼠 1 选择最好的奶酪。 

## Python 解决方案```python
from typing import List

class Solution:
    def miceAndCheese(self, reward1: List[int], reward2: List[int], k: int) -> int:
        total_reward = sum(reward2)

        differences = []

        for r1, r2 in zip(reward1, reward2):
            differences.append(r1 - r2)

        differences.sort(reverse=True)

        for i in range(k):
            total_reward += differences[i]

        return total_reward
```该实现首先计算假设第二只老鼠吃掉所有奶酪的总奖励。 这简化了逻辑，因为我们只需要跟踪将奶酪切换到第一只鼠标会带来多少额外价值。 

接下来，我们计算每种奶酪的奖励差异。 这个差异代表了通过将奶酪分配给第一只小鼠而不是第二只小鼠所获得的增益。 

收集所有差异后，我们按降序对它们进行排序，以便最好的选择首先出现。 

因为第一只老鼠必须准确地吃东西`k`奶酪，我们添加顶部`k`与基线总数的差异。 

最后，我们返回可实现的最大奖励。 

## 解决方案```go
package main

import "sort"

func miceAndCheese(reward1 []int, reward2 []int, k int) int {
	totalReward := 0

	differences := make([]int, len(reward1))

	for i := 0; i < len(reward1); i++ {
		totalReward += reward2[i]
		differences[i] = reward1[i] - reward2[i]
	}

	sort.Slice(differences, func(i, j int) bool {
		return differences[i] > differences[j]
	})

	for i := 0; i < k; i++ {
		totalReward += differences[i]
	}

	return totalReward
}
```Go 实现遵循与 Python 版本相同的逻辑。 

一个显着的区别是 Go 需要显式的切片分配`differences`。 排序是使用`sort.Slice`用自定义比较器来实现降序排列。 

这里不关心整数溢出，因为最大可能的总奖励是：```go
100000 * 1000 = 10^8
```可以安全地安装在 Go 中`int`在现代系统上键入。

 ## 边缘情况

 ### 案例 1：`k = 0`什么时候`k`为零，第一只老鼠不能吃任何奶酪。 有缺陷的实现可能仍会尝试访问已排序的差异数组或错误地分配奶酪。 

此实现自然地处理这种情况，因为循环：```
for i in range(k):
```执行零次。 The algorithm simply returns:```
sum(reward2)
```这是正确的。 

### 案例 2：`k = n`什么时候`k`等于奶酪的数量，第一只老鼠必须吃掉所有东西。 

有些实现会意外地将某些奶酪分配给鼠标 2。在这里，我们将所有差异添加回基线：```
sum(reward2) + sum(reward1 - reward2)
```简化为：```
sum(reward1)
```完全按照要求。 

### 案例 3：负差异

 有些奶酪分配给鼠标 1 时可能会产生较少的分数。 

例如：```
reward1 = [1]
reward2 = [10]
```区别在于`-9`。 

即使情况更糟，如果`k`要求老鼠1吃奶酪，我们仍然必须选择它。 

该实现正确地处理了这个问题，因为它总是准确地选择`k`排序后的差异，即使有些是负数。
