[LeetCode 问题 2657](https://leetcode.com/problems/find-the-prefix-common-array-of-two-arrays/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、位操作

 ## 解决方案

 ## 问题理解

 该问题提供了两个数组，`A`和`B`，每个整数的排列`1`到`n`。 排列意味着每个数字来自`1`到`n`在数组中只出现一次。 我们被要求计算一个新的数组`C`，称为**前缀公共数组**，其中`C[i]`表示同时出现的元素个数`A`和`B`直至索引`i`。 

简单来说，对于每个位置`i`，我们看第一个`i + 1`两者的要素`A`和`B`并计算两个切片中存在多少个数字。 约束条件确保`n`最多为 50，因此二次时间复杂度的解决方案是可以接受的，但我们可以进一步优化。 

重要的边缘情况包括长度为 1 的小数组、元素完美对齐的数组或公共元素在序列中出现较晚的数组。 该问题保证了没有重复的元素和一致的长度，因此我们不需要处理无效的输入。 

## 方法

 **暴力方法**很简单。 对于每个索引`i`，我们提取第一个`i + 1`两个数组的元素并计算交集。 然后将该交集的计数存储在`C[i]`。 虽然正确，但这种方法效率低下，因为每个交集操作都会扫描`i + 1`元素，导致`O(n^2)`时间复杂度。 

**最佳方法**利用了以下事实：`A`和`B`是排列`1`到`n`。 我们可以使用频率数组（或哈希集）来跟踪任一数组中出现了哪些数字。 当我们迭代时`A`和`B`同时，我们更新每个数字的计数。 当一个数字第二次出现时（意味着它已经出现在两个数组中），我们增加运行计数`C[i]`。 这种方法实现了`O(n)`时间复杂度和`O(n)`空间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 直接计算每个前缀的交集 |
 | 最佳| O(n) | O(n) | 跟踪两个数组中出现的数字和增量计数 |

 ## 算法演练

 1.初始化一个数组`C`长度`n`存储前缀公共计数，所有值最初为零。 
2.初始化频率数组或字典`count_map`跟踪每个数字在任一数组中出现的次数。 
3. 初始化变量`common_count`到 0。这会跟踪两个数组中直到当前索引为止出现的数字。 
4. 迭代索引`i`从`0`到`n - 1`。 每一步：

 a. 增加计数`A[i]`在`count_map`。 如果其计数变为 2，则递增`common_count`。 

b. 增加计数`B[i]`在`count_map`。 如果其计数变为 2，则递增`common_count`。 

c. 分配`C[i] = common_count`。 
5.返回数组`C`。 

**为什么有效：** 通过跟踪每个数字出现的次数并仅当数字出现在两个数组中时才更新计数，该算法可以维护每个前缀的公共元素的准确运行总数。 频率数组充当持久记录，消除了前缀的重复扫描。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        n = len(A)
        C = [0] * n
        count_map = defaultdict(int)
        common_count = 0
        
        for i in range(n):
            count_map[A[i]] += 1
            if count_map[A[i]] == 2:
                common_count += 1
            
            count_map[B[i]] += 1
            if count_map[B[i]] == 2:
                common_count += 1
            
            C[i] = common_count
        
        return C
```Python 实现使用`defaultdict`自动将计数初始化为零。 我们对数组进行一次迭代，更新计数`A[i]`和`B[i]`。 每当一个数字的计数达到 2 时，它就已经出现在两个数组中，我们就更新`common_count`。 该运行总计存储在`C[i]`。 

## 解决方案```go
func findThePrefixCommonArray(A []int, B []int) []int {
    n := len(A)
    C := make([]int, n)
    countMap := make([]int, n+1)
    commonCount := 0

    for i := 0; i < n; i++ {
        countMap[A[i]]++
        if countMap[A[i]] == 2 {
            commonCount++
        }

        countMap[B[i]]++
        if countMap[B[i]] == 2 {
            commonCount++
        }

        C[i] = commonCount
    }

    return C
}
```Go版本使用切片`countMap`长度`n+1`因为数字范围从`1`到`n`，避免了对哈希图的需要。 该逻辑反映了 Python 实现。 由于切片被初始化为零值，因此不需要 nil 检查。

 ## 边缘情况

 **单元素数组：** 如果`A`和`B`长度为 1，唯一的元素可能匹配也可能不匹配。 当唯一的元素同时出现在两个数组中时，算法会正确计算匹配项。 

**反向排列：**当`A`和`B`顺序相反，共同元素出现在后面。 如果假定排序，朴素的前缀交集可能会错误计数，但基于计数的方法可以独立于顺序正确跟踪元素。 

**早期前缀中没有公共元素：**早期前缀可能没有公共数字。 算法初始化`common_count`为零，并且仅当两个数组中都出现数字时才递增，确保从第一个索引开始进行准确计数。
