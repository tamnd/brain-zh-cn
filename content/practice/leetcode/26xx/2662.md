[LeetCode 问题 2662](https://leetcode.com/problems/minimum-cost-of-a-path-with-special-roads/)

 **难度：** 🟡 中等
 **主题：** 数组、图论、堆（优先级队列）、最短路径

 ## 解决方案

 ## 问题理解

 该问题要求我们找到从起点移动的最小成本`start = [startX, startY]`到目标点`target = [targetX, targetY]`在 2D 平面中。 平面上的移动有两种选择：使用曼哈顿距离成本直接从一个点移动到另一个点`|x2 - x1| + |y2 - y1|`，或者采取以固定成本连接特定点的**特殊道路**。 每条特殊道路都是单向的，可以多次使用。 

输入由起始坐标、目标坐标和特殊道路列表组成。 预期产出是从一开始就达到目标的最低总成本。 约束表明坐标的上限为`10^5`，且专用道路数量相对较少（`≤ 200`），这表明我们可以利用基于图的算法而不会遇到性能问题。 

重要的边缘情况包括使用特殊道路不是最佳的情况、向后走的道路（从较高坐标到较低坐标）以及多条特殊道路连接重叠点的情况。 

## 方法

 **暴力方法**会尝试移动和特殊道路的每种组合来计算从起点到目标的所有可能路径。 虽然原则上是正确的，但这种方法是不可行的，因为 2D 空间非常巨大（`10^5 x 10^5`），并且枚举所有路径将导致指数数量的可能性。 

**关键观察**是，该问题可以被视为图中的最短路径问题，其中节点是所涉及的点：起点、目标和特殊道路的所有端点。 边缘要么是直接曼哈顿移动，要么是特殊道路。 通过将节点限制在这些点上，问题的规模大大减小。 然后我们可以应用 **Dijkstra 算法** 来有效地计算最小成本。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 枚举所有路径； 对于大坐标不可行 |
 | 最佳| O((N+2)^2 log(N+2)) | O((N+2)^2 log(N+2)) | O(N+2) | 构建点图并使用 Dijkstra 算法； N 是专用道路的数量 |

 ## 算法演练

 1. 识别所有相关节点：起点、目标点以及所有专用道路的起点和终点。 这将无限的二维平面简化为有限的节点集。 
2.初始化距离字典`dist`将每个节点映射到其最小已知成本。 将起始节点的成本设置为 0，将所有其他节点的成本设置为无穷大。 
3. 使用**优先级队列**来实现Dijkstra算法。 将cost为0的起始节点推入队列。 
4. 当队列不为空时，弹出当前成本最小的节点。 如果该节点是目标，则立即返回成本。 
5. 对于每个邻居节点（所有其他节点）：

 - 如果正常移动，计算曼哈顿距离作为候选边缘。 
- 检查从当前节点开始的所有特殊道路。 如果存在道路，请考虑其到道路端点的固定成本。 
6. 如果通过当前节点到邻居的总成本小于其当前节点`dist`， 更新`dist`并将其推入优先队列。 
7. 继续，直到到达目标节点，确保由于 Dijkstra 的性质，我们始终首先传播最小成本路径。 

**为什么有效**：关键的不变量是 Dijkstra 算法保证第一次从优先级队列中弹出节点时，其记录的距离是最小的。 通过仅考虑相关节点以及曼哈顿移动和特殊道路作为边缘，我们确保有效地探索所有最佳路径。 

## Python 解决方案```python
from typing import List, Tuple
import heapq

class Solution:
    def minimumCost(self, start: List[int], target: List[int], specialRoads: List[List[int]]) -> int:
        points = [tuple(start), tuple(target)]
        for x1, y1, x2, y2, _ in specialRoads:
            points.append((x1, y1))
            points.append((x2, y2))
        
        points = list(set(points))  # unique points
        dist = {point: float('inf') for point in points}
        dist[tuple(start)] = 0
        heap = [(0, tuple(start))]
        
        while heap:
            cost, node = heapq.heappop(heap)
            if node == tuple(target):
                return cost
            if cost > dist[node]:
                continue
            for next_node in points:
                if next_node == node:
                    continue
                normal_cost = abs(next_node[0] - node[0]) + abs(next_node[1] - node[1])
                if cost + normal_cost < dist[next_node]:
                    dist[next_node] = cost + normal_cost
                    heapq.heappush(heap, (dist[next_node], next_node))
            for x1, y1, x2, y2, road_cost in specialRoads:
                if (x1, y1) == node:
                    next_node = (x2, y2)
                    if cost + road_cost < dist[next_node]:
                        dist[next_node] = cost + road_cost
                        heapq.heappush(heap, (dist[next_node], next_node))
        return dist[tuple(target)]
```**解释**：我们首先收集与问题相关的所有点以形成可管理的图表。 这`dist`字典记录到达每个点的最小成本。 优先级队列确保成本较小的节点首先被处理，这与 Dijkstra 算法一致。 对于每个节点，我们将正常的曼哈顿移动和特殊道路视为潜在的边缘。 

## 解决方案```go
package main

import (
    "container/heap"
    "math"
)

type Point struct {
    x, y int
}

type Item struct {
    point Point
    cost  int
}

type PriorityQueue []Item

func (pq PriorityQueue) Len() int { return len(pq) }
func (pq PriorityQueue) Less(i, j int) bool { return pq[i].cost < pq[j].cost }
func (pq PriorityQueue) Swap(i, j int) { pq[i], pq[j] = pq[j], pq[i] }
func (pq *PriorityQueue) Push(x any) { *pq = append(*pq, x.(Item)) }
func (pq *PriorityQueue) Pop() any {
    old := *pq
    n := len(old)
    item := old[n-1]
    *pq = old[0 : n-1]
    return item
}

func minimumCost(start []int, target []int, specialRoads [][]int) int {
    pointsMap := map[Point]bool{}
    startPoint := Point{start[0], start[1]}
    targetPoint := Point{target[0], target[1]}
    pointsMap[startPoint] = true
    pointsMap[targetPoint] = true
    for _, road := range specialRoads {
        pointsMap[Point{road[0], road[1]}] = true
        pointsMap[Point{road[2], road[3]}] = true
    }

    points := make([]Point, 0, len(pointsMap))
    for p := range pointsMap { points = append(points, p) }

    dist := map[Point]int{}
    for _, p := range points { dist[p] = math.MaxInt64 }
    dist[startPoint] = 0

    pq := &PriorityQueue{}
    heap.Init(pq)
    heap.Push(pq, Item{startPoint, 0})

    for pq.Len() > 0 {
        item := heap.Pop(pq).(Item)
        node, cost := item.point, item.cost
        if node == targetPoint { return cost }
        if cost > dist[node] { continue }
        for _, next := range points {
            if next == node { continue }
            normalCost := abs(next.x-node.x) + abs(next.y-node.y)
            if cost+normalCost < dist[next] {
                dist[next] = cost + normalCost
                heap.Push(pq, Item{next, dist[next]})
            }
        }
        for _, road := range specialRoads {
            if Point{road[0], road[1]} == node {
                next := Point{road[2], road[3]}
                if cost+road[4] < dist[next] {
                    dist[next] = cost + road[4]
                    heap.Push(pq, Item{next, dist[next]})
                }
            }
        }
    }
    return dist[targetPoint]
}

func abs(a int) int {
    if a < 0 { return -a }
    return a
}
```**Go 特定注释**：Go 需要使用自定义优先级队列`container/heap`。 点被定义为结构，我们维护一个距离图。 其余逻辑反映了 Python 解决方案。
