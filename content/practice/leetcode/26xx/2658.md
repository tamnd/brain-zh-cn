[LeetCode 问题 2658](https://leetcode.com/problems/maximum-number-of-fish-in-a-grid/)

 **难度：** 🟡 中等
 **主题：** 数组、深度优先搜索、广度优先搜索、并查找、矩阵

 ## 解决方案

 ## 问题理解

 该问题提供了一个表示陆地和水单元图的二维网格。 Each cell can either be land (value`0`）或含有正数鱼的水。 目标是通过从任何水单元开始并仅移动到相邻的水单元来确定渔民可以收集的最大鱼数量。 相邻单元格定义为从当前位置直接向上、向下、向左或向右。 

输入网格尺寸很小（`1 <= m, n <= 10`）并且每个单元格包含`0 <= grid[i][j] <= 10`。 这些限制意味着暴力方法可能适用于小输入，但仍应进行优化。 输出是一个整数，即可获得的最大鱼数。 如果网格中没有水，该函数应该返回`0`。 重要的边缘情况包括包含所有土地的网格、包含孤立水单元的网格以及最佳路径需要遍历多个连接的水单元的网格。 

## 方法

 **暴力方法**将尝试从每个水单元开始，并使用回溯探索所有可能的路径，沿途总结鱼类值。 这保证了正确性，但可能效率低下，因为它会多次重新访问许多路径。 

**关键见解**是鱼只能沿着相连的水体收集。 因此，使用深度优先搜索 (DFS) 或广度优先搜索 (BFS) 来计算水的每个连接部分中的鱼类总数并跟踪最大总数就足够了。 这避免了多余的探索并确保我们有效地计算最佳解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m_n) * 4^(m_n)) | O(m*n) | 探索所有水细胞的所有路径，太慢 |
 | 最优（每个组件的 DFS/BFS）| O(m*n) | O(m*n) | 访问每个单元一次，对每个连接组件的鱼求和 |

 ## 算法演练

 1. 初始化变量`max_fish`存储所有组件中收集的最大数量的鱼。 
2. 定义一个采用当前单元格坐标的递归 DFS 函数。 如果单元格出界或为陆地，则返回`0`。 否则，通过将单元格设置为已访问来将其标记为已访问`0`，然后递归地探索所有四个相邻单元格（上、下、左、右），对收集到的鱼求和。 
3. 迭代网格中的所有单元格。 对于每个水单元格（值 > 0），从该单元格开始调用 DFS 函数来计算该连接组件中的鱼总数。 
4. 更新`max_fish`如果当前组件的鱼总数大于之前的最大值。 
5、扫描完整个网格后，返回`max_fish`。 

**工作原理：** 每个水细胞都属于一个连接的组件。 DFS 确保我们对组件中的所有鱼进行求和，同时将单元格标记为已访问以避免重复计数。 所以，`max_fish`正确捕获最大可捕获的鱼。 

## Python 解决方案```python
from typing import List

class Solution:
    def findMaxFish(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        max_fish = 0

        def dfs(r: int, c: int) -> int:
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 0:
                return 0
            fish = grid[r][c]
            grid[r][c] = 0  # mark visited
            for dr, dc in [(1,0), (-1,0), (0,1), (0,-1)]:
                fish += dfs(r + dr, c + dc)
            return fish

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] > 0:
                    max_fish = max(max_fish, dfs(r, c))

        return max_fish
```此 Python 解决方案迭代每个单元，从未访问过的水单元启动 DFS，对连接组件中的所有鱼求和，并更新最大值。 将访问过的单元格标记为`0`防止重新访问并确保正确性。 

## 解决方案```go
func findMaxFish(grid [][]int) int {
    rows, cols := len(grid), len(grid[0])
    maxFish := 0

    var dfs func(r, c int) int
    dfs = func(r, c int) int {
        if r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == 0 {
            return 0
        }
        fish := grid[r][c]
        grid[r][c] = 0 // mark visited
        directions := [][2]int{{1,0},{-1,0},{0,1},{0,-1}}
        for _, d := range directions {
            fish += dfs(r + d[0], c + d[1])
        }
        return fish
    }

    for r := 0; r < rows; r++ {
        for c := 0; c < cols; c++ {
            if grid[r][c] > 0 {
                total := dfs(r, c)
                if total > maxFish {
                    maxFish = total
                }
            }
        }
    }

    return maxFish
}
```Go 版本反映了 Python 方法，使用 DFS 的递归闭包。 差异包括显式基于数组的方向处理和更新`maxFish`通过比较而不是使用`max`。

 | 访问过的单元 | 收集的鱼 | 运行总计 |
 | --- | --- | --- |

 ## 边缘情况

 **所有土地：** 没有水的网格应该返回`0`。 这是通过检查来处理的`grid[r][c] > 0`在DFS之前。 

**单个水细胞：** 该算法必须正确处理没有邻居的单个水细胞。 DFS 会将鱼归还至该牢房。 

**断开的水组件：** 必须独立评估多个断开的水簇，以确保正确识别最大值。 DFS 将访问过的单元格标记为`0`，因此每个组件仅计算一次。 

**非矩形簇：** 该解决方案可以正确处理不规则形状，因为 DFS 递归地探索所有四个方向。 这确保了任何任意形状的水簇都被完全遍历。
