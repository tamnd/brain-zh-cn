[LeetCode 问题 2652](https://leetcode.com/problems/sum-multiples/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题需要计算从 1 到给定正整数的所有整数之和`n`可以被 3、5 或 7 整除。简单来说，我们需要考虑范围内的每个数字`[1, n]`并检查它是否是这三个数字中任何一个的倍数。 如果是，我们将其包含在运行总计中。 

输入是单个整数`n`在哪里`1 <= n <= 103`，相对较小。 输出是一个整数，表示所有合格数字的总和。 

要点包括`n`总是正数，所以我们不需要处理零或负数。 边缘情况可能涉及小值，例如`n = 1`其中没有数字可以被 3、5 或 7 整除，或者更大的数字，其中多个数字可以被 3、5 或 7 中的一个以上整除（例如 15、21、35），我们必须避免在求和逻辑中重复计算。 

## 方法

 蛮力方法很简单。 我们迭代从 1 到`n`并检查它是否能被 3、5 或 7 整除。如果是，我们将其添加到累积和中。 此方法之所以有效，是因为可以单独检查每个整数的整除性，但它涉及`n`检查，对于非常大的情况可能效率低下`n`。 然而，考虑到约束条件（`n <= 103`），这种做法是可以接受的。 

最佳方法利用组合学中的包含排除原理。 我们不是单独检查每个数字，而是分别计算 3、5 和 7 的倍数之和，然后减去两次计数的数字之和（例如 15、21 或 35 的倍数），然后添加三次计数的数字（例如 105 的倍数）。 这减少了对每个数字进行显式迭代的需要，并使用简单的算术公式对算术序列的总和给出了精确的总和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 迭代所有数字 1 到 n，检查整除性并求和 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 使用算术级数公式和包含排除直接计算总和 |

 ## 算法演练

 1. 识别三个因数：3、5 和 7。 
2. 对于每个除数，计算小于或等于的倍数`n`。 这是`floor(n / divisor)`。 
3. 使用算术级数公式计算一个数的倍数之和：`sum = divisor * k * (k + 1) / 2`在哪里`k`是倍数。 
4. 应用包含-排除：将 3、5、7 的倍数和相加，减去两个除数组合的倍数和 (3_5=15、3_7=21、5_7=35)，然后将所有三个除数的倍数和 (3_5*7=105) 相加，以纠正减法过大。 
5. 返回最终金额。 

为什么有效：此方法之所以有效，是因为倍数总和公式可以正确计算均匀分布的数字的总和。 包含-排除确保每个数字只计算一次，即使它可以被多个除数整除。 

## Python 解决方案```python
class Solution:
    def sumOfMultiples(self, n: int) -> int:
        def sum_multiples(k: int) -> int:
            count = n // k
            return k * count * (count + 1) // 2
        
        sum3 = sum_multiples(3)
        sum5 = sum_multiples(5)
        sum7 = sum_multiples(7)
        
        sum15 = sum_multiples(15)
        sum21 = sum_multiples(21)
        sum35 = sum_multiples(35)
        sum105 = sum_multiples(105)
        
        return sum3 + sum5 + sum7 - sum15 - sum21 - sum35 + sum105
```这个Python实现定义了一个辅助函数`sum_multiples`计算给定数字的倍数之和`n`。 我们计算各个除数的总和，计算成对组合的总和以减去多算的数字，最后计算三重组合的总和以调整过度减法。 最终的返回值根据包含排除原则将这些组合起来。 

## 解决方案```go
func sumOfMultiples(n int) int {
    sumMultiples := func(k int) int {
        count := n / k
        return k * count * (count + 1) / 2
    }

    sum3 := sumMultiples(3)
    sum5 := sumMultiples(5)
    sum7 := sumMultiples(7)

    sum15 := sumMultiples(15)
    sum21 := sumMultiples(21)
    sum35 := sumMultiples(35)
    sum105 := sumMultiples(105)

    return sum3 + sum5 + sum7 - sum15 - sum21 - sum35 + sum105
}
```Go 实现镜像了 Python 版本。 它定义了一个内部函数`sumMultiples`计算倍数之和，计算单个除数和组合除数的总和，并应用包含排除原则来生成最终总和。 Go 中使用整数除法`count`，就像Python的一样`//`操作员。
