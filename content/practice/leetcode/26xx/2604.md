[LeetCode 问题 2604](https://leetcode.com/problems/minimum-time-to-eat-all-grains/)

 **难度：** 🔴难
 **主题：** 数组、两个指针、二分查找、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定当母鸡和谷物都位于一维线上时，**所有母鸡吃完所有谷物所需的最短时间**。 每只母鸡每秒可以向左或向右移动 1 个单位，并且可以吃掉多个谷物，但仅限于占据与谷物相同的位置时。 所有母鸡**同时**且**独立**移动。 目标是找到在最佳分配母鸡的情况下吃掉所有谷物所需的最小秒数。 

输入是两个整数数组：`hens`尺寸的`n`代表母鸡的位置，以及`grains`尺寸的`m`代表颗粒的位置。 输出是一个表示所需最短时间的整数。 

约束表明`n`和`m`最多可达 20,000 个，头寸可能非常大（最多 10^9）。 这意味着**每秒运动的强力模拟是不可行的**，我们必须利用排序和优化搜索技术。 重要的边缘情况包括母鸡数量超过谷物、谷物数量超过母鸡或位置极度倾斜，例如所有谷物远离所有母鸡。 

## 方法

 **暴力方法**将尝试模拟每一秒，将每只母鸡最佳地移动到最近的未吃掉的谷物，直到所有谷物都被吃掉。 虽然这在概念上是正确的，但由于很大的约束，它太慢了，可能需要 O(m * n * maxDistance)，这是不可接受的。 

最佳方法的**关键见解**是我们只需要确定**最短时间`T`这样每一粒谷物都可以分配给一只母鸡`T`秒**。 由于母鸡可以同时且独立地移动，因此这个问题简化为沿排序线的**匹配问题**。 对两个数组进行排序并在最短的时间内使用**二分搜索`T`**结合**贪心赋值检查**，提供了一个可行的解决方案。 对于候选人时间`T`，我们尝试按顺序将谷物分配给母鸡：如果母鸡可以在`T`秒，我们在移动到下一只母鸡之前分配尽可能多的连续谷物。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(m * n * 最大距离) | O(m + n) | 模拟每一秒； 对于大输入不可行|
 | 最佳| O((n + m) log(maxPos)) | O((n + m) log(maxPos)) | O(1) | O(1) | 贪心赋值按时二分查找； 可扩展|

 ## 算法演练

 1. **对母鸡和谷物数组进行排序**。 排序确保我们可以按顺序将谷物分配给母鸡，最大限度地减少总移动并使贪婪策略达到最佳。 
2. **定义辅助函数`canEatAllIn(time)`** 检查是否所有谷物都可以在规定时间内食用`time`秒。 初始化当前grain的指针。 对于每只母鸡，为母鸡分配尽可能多的谷物，使得所需的最大运动量不超过`time`。 
3. **按时二分查找**。 放`low = 0`和`high = max(grains) - min(hens)`作为母鸡可能需要旅行的最大距离。 尽管`low < high`,检查中间值`mid`。 如果`canEatAllIn(mid)`是真的，尝试更小的时间（`high = mid`）。 否则，增加时间（`low = mid + 1`）。 
4. **返回`low`**，这是可以吃完所有谷物的最短时间。 

**为什么有效**：该算法之所以有效，是因为排序允许贪婪分配达到最佳状态：每只母鸡都会获取它可以到达的下一个连续谷物。 二分搜索确保我们有效地找到尽可能小的`T`无需模拟每一秒。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumTime(self, hens: List[int], grains: List[int]) -> int:
        hens.sort()
        grains.sort()
        
        def canEatAllIn(time: int) -> bool:
            grain_idx = 0
            for hen in hens:
                if grain_idx >= len(grains):
                    break
                left = grains[grain_idx]
                right = left
                # Assign as many grains as possible to this hen
                while grain_idx < len(grains) and abs(hens[0] - grains[grain_idx]) <= time:
                    grain_idx += 1
            return grain_idx == len(grains)
        
        # Correct greedy check
        def canEatAllIn(time: int) -> bool:
            i = 0
            j = 0
            while i < len(hens) and j < len(grains):
                hen_pos = hens[i]
                start = j
                # Find the furthest grain this hen can eat within 'time'
                while j < len(grains):
                    left = abs(hen_pos - grains[start])
                    right = abs(hen_pos - grains[j])
                    if min(left, right) + (right - left) > time:
                        break
                    j += 1
                i += 1
            return j == len(grains)
        
        left, right = 0, 10**10
        while left < right:
            mid = (left + right) // 2
            if canEatAllIn(mid):
                right = mid
            else:
                left = mid + 1
        return left
```该实施首先对母鸡和谷物进行分类。 这`canEatAllIn`函数对母鸡进行迭代，并贪婪地分配每只母鸡在候选时间内可以到达的连续谷物。 然后，二分搜索有效地找到最小可行时间。 

## 解决方案```go
import (
    "sort"
)

func minimumTime(hens []int, grains []int) int {
    sort.Ints(hens)
    sort.Ints(grains)

    canEatAllIn := func(time int) bool {
        i, j := 0, 0
        for i < len(hens) && j < len(grains) {
            hen := hens[i]
            start := j
            for j < len(grains) {
                left := abs(hen - grains[start])
                right := abs(hen - grains[j])
                if min(left, right)+right-left > time {
                    break
                }
                j++
            }
            i++
        }
        return j == len(grains)
    }

    left, right := 0, int(1e10)
    for left < right {
        mid := (left + right) / 2
        if canEatAllIn(mid) {
            right = mid
        } else {
            left = mid + 1
        }
    }
    return left
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 版本反映了带有切片操作和辅助函数的 Python 方法`abs`和`min`。 Go 不需要显式的类型提示，并且可以高效地处理数组和切片。 

## 工作示例

 **示例1**：`hens = [3,6,7], grains = [2,4,7,9]`排序：`hens = [3,6,7]`,`grains = [2,4,7,9]`。 二分查找检查候选时间。 时间2是可行的：

 | 母鸡| 指定谷物 | 所需时间|
 | ---| ---| ---|
 | 3 | 2, 4 | 2 |
 | 6 | 7 | 1 |
 | 7 | 9 | 2 |

 最长时间 = 2。输出 = 2。 

**示例2**：`hens = [4,6,109,111,213,215], grains = [5,110,214]`排序： 母鸡 =`[4,6,109,111,213,215]`, 谷物 =`[5,110,214]`。 二分查找发现时间 1 可行：

 | 母鸡| 指定谷物 | 所需时间|
 | ---| ---| ---|
 | 4 | 5 | 1 |
 | 109 | 109 110 | 110 1 |
 | 213 | 213 214 | 214 1 |

 最长时间 = 1。输出 = 1。
