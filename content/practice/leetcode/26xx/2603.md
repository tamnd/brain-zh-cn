[LeetCode 问题 2603](https://leetcode.com/problems/collect-coins-in-a-tree/)

 **难度：** 🔴难
 **主题：** 数组、树、图论、拓扑排序

 ## 解决方案

 ## 问题理解

 问题是收集位于具有最少边遍历次数的树节点上的硬币。 我们有一棵树`n`节点，由边列表和数组表示`coins`指示每个节点是否存在硬币。 我们可以进行两种操作：收集距当前节点距离 2 内的所有硬币或移动到相邻节点。 目标是确定收集所有硬币并返回起始节点所需遍历的最小边总数。 

输入由一个`coins`大小数组`n`和一个`edges`大小数组`n-1`。 约束表明`n`可以达到`3 * 10^4`，这排除了探索所有路径的强力方法，因为它们太慢了。 输入保证形成有效的树，这意味着不存在环并且图是连通的。 

重要的边缘情况包括所有硬币都位于叶子的树、没有硬币的树以及硬币聚集在中心附近的树。 这些可能会影响实际需要遍历的边数。 

## 方法

 暴力方法会尝试从每个节点开始，通过执行 BFS 或 DFS 遍历来模拟收集硬币，同时跟踪收集的距离。 虽然这会产生正确的结果，但效率很低。 由于路径的组合性质，将每个节点视为起点并模拟所有可能的移动会导致指数时间复杂度。 和`n`最多`3 * 10^4`，这是不可行的。 

最佳解决方案的关键见解是我们只需要保留到达硬币“必要”的边缘。 任何在两步内不导致硬币的叶节点或边都可以被删除。 在树上使用类似于“修剪叶子”的过程或两遍拓扑排序可以让我们将树减少到仅保留必要的边缘。 修剪后，剩余的边表示必须遍历两次（来回）的最小路径，但距离足够近以启动允许在距离 2 内进行收集的节点的边除外。 

步骤是：修剪没有硬币的叶子，修剪叶子两次以考虑distance-2收集规则，然后计算剩余边总数乘以2。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) 或更糟 | O(n) | 模拟从每个起始节点收集硬币，对于大n是不可行的 |
 | 最佳| O(n) | O(n) | 修剪不必要的叶子并计算剩余的边缘 |

 ## 算法演练

 1. 根据树表示的边列表构建邻接列表。 这允许有效地遍历邻居。 
2. 初始化一个度数数组来跟踪每个节点的邻居数量。 
3. 识别出所有叶子节点（度数为1的节点）并将其放入队列中。 如果叶子不包含硬币，则叶子是修剪的候选节点。 
4. 对叶子进行类似 BFS 的剪枝：对于每个叶子，如果它不包含硬币，则将其从树中删除，降低其邻居的度数，如果邻居成为叶子，则将其入队。 重复此操作，直到无法去除任何叶子。 
5. 修剪掉没有硬币的叶子后，执行距离 2 收集的第二次修剪：删除所有当前叶子，然后删除第一次删除创建的新叶子。 这可以在两步内收集硬币，而无需遍历额外的边缘。 
6. 计算树中剩余的边。 每个剩余的边都需要遍历两次（去和返回）。 
7. 返回遍历总数作为答案。 

**为什么有效：** 通过修剪没有硬币的叶子并应用距离 2 逻辑，我们只留下收集硬币所需的边缘。 此修剪子树外部的每次遍历都是冗余的，因此对剩余边进行两次计数即可得出最小移动次数。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        if n == 1:
            return 0

        adj = [[] for _ in range(n)]
        degree = [0] * n

        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
            degree[u] += 1
            degree[v] += 1

        leaves = deque()
        for i in range(n):
            if degree[i] == 1:
                leaves.append(i)

        removed = [False] * n

        # First prune leaves without coins
        for _ in range(n):
            new_leaves = deque()
            while leaves:
                leaf = leaves.popleft()
                if coins[leaf]:
                    continue
                removed[leaf] = True
                for neighbor in adj[leaf]:
                    if removed[neighbor]:
                        continue
                    degree[neighbor] -= 1
                    if degree[neighbor] == 1:
                        new_leaves.append(neighbor)
            if not new_leaves:
                break
            leaves = new_leaves

        # Second prune leaves for distance-2 collection
        leaves = deque([i for i in range(n) if degree[i] == 1 and not removed[i]])
        for _ in range(2):
            new_leaves = deque()
            while leaves:
                leaf = leaves.popleft()
                removed[leaf] = True
                for neighbor in adj[leaf]:
                    if removed[neighbor]:
                        continue
                    degree[neighbor] -= 1
                    if degree[neighbor] == 1:
                        new_leaves.append(neighbor)
            leaves = new_leaves

        remaining_edges = sum(degree[i] for i in range(n) if not removed[i]) // 2
        return remaining_edges * 2
```**说明：** 我们构建邻接列表和度数组来有效跟踪叶节点。 我们执行两个修剪阶段：第一个阶段删除没有硬币的叶子，第二个阶段负责距离 2 的收集。 剩余边数将被计算并加倍以进行往返。 

## 解决方案```go
package main

func collectTheCoins(coins []int, edges [][]int) int {
    n := len(coins)
    if n == 1 {
        return 0
    }

    adj := make([][]int, n)
    degree := make([]int, n)

    for _, e := range edges {
        u, v := e[0], e[1]
        adj[u] = append(adj[u], v)
        adj[v] = append(adj[v], u)
        degree[u]++
        degree[v]++
    }

    removed := make([]bool, n)
    leaves := []int{}
    for i := 0; i < n; i++ {
        if degree[i] == 1 {
            leaves = append(leaves, i)
        }
    }

    // First pruning
    for len(leaves) > 0 {
        newLeaves := []int{}
        for _, leaf := range leaves {
            if coins[leaf] == 1 {
                continue
            }
            removed[leaf] = true
            for _, neighbor := range adj[leaf] {
                if removed[neighbor] {
                    continue
                }
                degree[neighbor]--
                if degree[neighbor] == 1 {
                    newLeaves = append(newLeaves, neighbor)
                }
            }
        }
        leaves = newLeaves
    }

    // Second pruning for distance-2
    leaves = []int{}
    for i := 0; i < n; i++ {
        if degree[i] == 1 && !removed[i] {
            leaves = append(leaves, i)
        }
    }
    for i := 0; i < 2; i++ {
        newLeaves := []int{}
        for _, leaf := range leaves {
            removed[leaf] = true
            for _, neighbor := range adj[leaf] {
                if removed[neighbor] {
                    continue
                }
                degree[neighbor]--
                if degree[neighbor] == 1 {
                    newLeaves = append(newLeaves, neighbor)
                }
            }
        }
        leaves = newLeaves
    }

    remainingEdges := 0
    for i := 0; i < n; i++ {
        if !removed[i] {
            remainingEdges += degree[i]
        }
    }
    return remainingEdges
}
```**Go 特定说明：** Go 不允许像 Python 出队那样进行动态数组切片，因此我们对队列使用切片和追加。 布尔数组和整数切片的工作原理类似。 边计数是通过整数除法完成的，因为每个边在邻接列表中都会被计数两次。

edges = [[0,1],[1,2],[2,3],[3,4],[4,5]]
```初始叶节点：[0,5]

 第一次修剪：叶子0有硬币，叶子5有硬币，不去除

 距离 2 修剪：删除末端的叶子以进行 2 步收集 → 保留边缘 [1,2,3,4]
