[LeetCode 问题 2600](https://leetcode.com/problems/k-items-with-the-maximum-sum/)

 **难度：** 🟢简单
 **主题：** 数学、贪心

 ## 解决方案

 ## 问题理解

 该问题要求我们在精确挑选时确定**可能的最大总和**`k`装有贴有标签的物品的袋子中的物品`1`,`0`， 或者`-1`。 袋子的组成由三个非负整数给出：`numOnes`对于数量`1`s,`numZeros`对于数量`0`沙`numNegOnes`对于数量`-1`是。 整数`k`指定我们必须选择多少个项目。 

预期输出是一个整数，表示通过精确选择可获得的最大总和`k`项目。 正数对总和有正向贡献，零对总和没有贡献，而负数则减少总和。 

约束保证所有输入数字都是非负的，并且所有项目的总和至少为`k`，确保总是可以选择`k`项目。 边缘情况包括以下场景：`k`的数量小于`1`s，其中`k`超过总和`1`沙`0`s，或者某些计数为零的地方。 

这个问题的要求很简单，但需要仔细处理项目计数以有效地最大化总和。 

## 方法

 **暴力方法**将涉及生成所有可能的大小子集`k`从袋子中计算每个子集的总和，然后取最大值。 虽然这保证了正确的答案，但它**低效**，因为组合的数量随着项目总数的增长而组合，最多可达 150 个。计算所有子集是不可行的。 

最佳解决方案的**关键见解**是通过选择尽可能多的数量来最大化总和`1`首先尽可能的，然后`0`如果需要的话，并且只选择`-1`如果`k`超过总和`1`沙`0`s。 这有效是因为`1 > 0 > -1`，因此每一步采取最大可用数的贪婪选择保证了最大总和。 通过这种方法，我们可以使用简单的算术来计算总和，而无需迭代子集。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n, k)) | O(C(n, k)) | O(k) | 生成大小为 k 的所有子集并计算总和。 对于 n 达到 150 来说太慢。 
| 最优（贪婪）| O(1) | O(1) | O(1) | O(1) | 使用简单的算术根据价值贪婪地挑选物品。 |

 ## 算法演练

 1. 首先挑选带有标签的物品`1`。 计算一下有多少个`1`我们可以采取：`ones_taken = min(numOnes, k)`。 添加`ones_taken`到总和。 
2. 更新`k`反映剩余的要挑选的项目：`k -= ones_taken`。 
3. 接下来，选择标记的项目`0`。 我们可以取的零个数是`zeros_taken = min(numZeros, k)`。 添加零不会改变总和，因此总和保持不变。 
4. 更新`k`再次：`k -= zeros_taken`。 
5. 如果还有剩余的物品需要挑选（`k > 0`），这些必须是`-1`是。 总和减少了`k`，因为每个`-1`将总和减 1。 
6. 返回最终金额。 

**为什么有效：** 贪婪不变量是在每一步中，我们选择具有最大值的可用数字。 自从`1 > 0 > -1`，这确保了每个选择都尽可能多地贡献于总和。 该算法处理所有边缘情况，因为它始终尊重每个数字的可用计数。 

## Python 解决方案```python
class Solution:
    def kItemsWithMaximumSum(self, numOnes: int, numZeros: int, numNegOnes: int, k: int) -> int:
        ones_taken = min(numOnes, k)
        k -= ones_taken
        
        zeros_taken = min(numZeros, k)
        k -= zeros_taken
        
        # Remaining items must be -1s
        neg_ones_taken = k
        
        return ones_taken - neg_ones_taken
```这个Python实现直接遵循算法。 首先，它最大化了`1`s，然后占`0`s，最后将总和减少任意`-1`必须选择才能到达的 s`k`。 每一步都是简单的算术运算，使得解决方案简洁高效。 

## 解决方案```go
func kItemsWithMaximumSum(numOnes int, numZeros int, numNegOnes int, k int) int {
    onesTaken := min(numOnes, k)
    k -= onesTaken
    
    zerosTaken := min(numZeros, k)
    k -= zerosTaken
    
    // Remaining items are -1
    negOnesTaken := k
    
    return onesTaken - negOnesTaken
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 版本使用辅助函数镜像 Python 逻辑`min`处理最小计算。 Go 中的主要区别是显式整数运算以及需要一个小的辅助函数而不是使用内置函数`min`。

 ## 边缘情况

 第一个重要的边缘情况是`k`**零**，意味着没有物品被挑选。 算法正确返回`0`因为没有执行加法或减法。 

第二个边缘情况是当`k`**大于`1`沙`0`s**，强制选择`-1`s。 这测试了减法逻辑是否被正确应用，算法通过将总和减去减法的数量来处理这个问题。`-1`已选。 

第三种边缘情况是当一个或多个计数为零**时，例如没有`1`有或没有`0`是。 该算法使用`min`对于每种类型，确保它永远不会尝试选择超出可用的项目，因此它可以自然地处理这些场景而不会出现错误。 

这些边缘情况至关重要，因为它们可能会导致假设所有项目类型始终存在或假设所有项目类型都存在的幼稚实现失败。`k`总是小于正项的数量。
