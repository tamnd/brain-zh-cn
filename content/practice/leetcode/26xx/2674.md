[LeetCode 问题 2674](https://leetcode.com/problems/split-a-circular-linked-list/)

 **难度：** 🟡 中等
 **主题：** 链表、两个指针

 ## 解决方案

 ## 问题理解

 该问题要求我们采用一个正整数的**循环链表**并将其拆分为**两个单独的循环链表**。 第一个列表应包含**前半个节点**，向上舍入（`ceil(length / 2)`），第二个列表应包含其余节点。 重要的是，必须保留**节点的相对顺序**，并且两个结果列表都必须保持最后一个节点指向第一个节点的循环属性。 

输入是一个循环链表，意味着从头部遍历它最终会循环回到头部。 约束指定节点数最多可达 105 个，每个节点值最大可达 109。这告诉我们，解决方案必须在输出列表之外**时间上呈线性**且空间上**恒定**，才能有效处理大型输入。 

关键边缘情况包括 **长度为 2** 的列表，其中每个拆分将有一个节点，以及**具有奇数个节点的列表**，其中由于上限操作，第一个列表将比第二个列表多包含一个节点。 

## 方法

 **强力方法**将涉及迭代循环列表以计算其长度，然后再次迭代以通过复制节点来创建两个新的循环列表。 虽然正确，但这种方法需要**与列表长度成比例的额外内存**来存储新节点，并且迭代两次可能效率稍低。 

**最佳方法**使用**双指针技术**在单次遍历中找到分割点。 我们首先通过遍历循环链表一次来确定节点总数。 然后，我们计算前半部分的节点数（`ceil(length / 2)`）并直接**调整next指针**创建两个不重复节点的循环链表。 这种方法在**线性时间**和**恒定的附加空间**中运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 遍历两次并创建新节点 |
 | 最佳| O(n) | O(1) | O(1) | 单次遍历，通过调整指针分割|

 ## 算法演练

 1. **边缘情况检查**：如果输入列表为空或只有一个节点，则将其作为第一个列表返回并`None`作为第二个。 
2. **统计总节点数**：从以下位置开始遍历循环链表`head`直到我们回到`head`确定`length`。 
3. **确定上半部分尺寸**：计算`first_half_size = ceil(length / 2)`。 
4. **遍历到分割点**：从`head`， 移动`first_half_size - 1`到达**上半部分的最后一个节点**的步骤。 
5. **拆分列表**：

 - 让`first_tail`是上半部分的最后一个节点。 它是`next`将指向下半场的头部。 
- 让`second_head`是`first_tail.next`。 
- 更新`first_tail.next`到`head`保持第一个列表的循环属性。 
6. **完成第二个列表**：遍历自`second_head`到原来的尾节点（返回头之前的最后一个节点）并设置其`next`到`second_head`。 
7. **返回结果**：返回`[head, second_head]`作为两个循环链表。 

**为什么有效**：通过计算节点数和调整指针而不是复制，我们保留了循环性质和原始顺序。 天花板操作确保第一个列表在长度为奇数时获得一个额外的节点，这符合问题要求。 

## Python 解决方案```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
from typing import Optional, List
import math

class Solution:
    def splitCircularLinkedList(self, head: Optional[ListNode]) -> List[Optional[ListNode]]:
        if not head or head.next == head:
            return [head, None]

        # Step 1: Count the total number of nodes
        length = 1
        current = head.next
        while current != head:
            length += 1
            current = current.next

        # Step 2: Determine size of the first half
        first_half_size = math.ceil(length / 2)

        # Step 3: Traverse to the last node of the first half
        first_tail = head
        for _ in range(first_half_size - 1):
            first_tail = first_tail.next

        # Step 4: Split the list
        second_head = first_tail.next
        first_tail.next = head

        # Step 5: Complete the second circular list
        current = second_head
        while current.next != head:
            current = current.next
        current.next = second_head

        return [head, second_head]
```**实现说明**：我们首先处理列表为空或只有一个节点的简单边缘情况。 计算节点数可以让我们准确地确定分割点。 调整`next`尾节点的指针保留了循环结构。 这避免了额外的内存分配并保留原始节点顺序。 

## 解决方案```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func splitCircularLinkedList(head *ListNode) []*ListNode {
    if head == nil || head.Next == head {
        return []*ListNode{head, nil}
    }

    // Step 1: Count total nodes
    length := 1
    current := head.Next
    for current != head {
        length++
        current = current.Next
    }

    // Step 2: Determine first half size
    firstHalfSize := (length + 1) / 2

    // Step 3: Traverse to last node of first half
    firstTail := head
    for i := 0; i < firstHalfSize-1; i++ {
        firstTail = firstTail.Next
    }

    // Step 4: Split the list
    secondHead := firstTail.Next
    firstTail.Next = head

    // Step 5: Complete second circular list
    current = secondHead
    for current.Next != head {
        current = current.Next
    }
    current.Next = secondHead

    return []*ListNode{head, secondHead}
}
```**Go 特定注释**：Go 需要显式的 nil 检查和整数除法。 我们使用`(length + 1) / 2`无需使用数学库即可计算上限除法。 这`*ListNode`type 直接处理指针，因此我们就地修改节点。 

## 工作示例

 **示例 1：nums = [1,5,7]**

 1. 节点数：3
 2. 前半部分大小：ceil(3 / 2) = 2
 3.从head(1)→first_tail = 5遍历1步
 4. 第二个头=7
 5.更新指针：first_tail.next = 1，最后一个节点(7).next = 7
 6. 结果：[[1,5],[7]]

 **示例 2：nums = [2,6,1,5]**

 1. 节点数：4
 2. 前半部分大小：ceil(4 / 2) = 2
 3.从head(2)→first_tail = 6遍历1步
 4.第二个头=1
 5.更新指针：first_tail.next = 2，最后一个节点(5).next = 1
 6. 结果：[[2,6],[1,5]]

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 我们遍历列表两次：一次用于计数，一次用于拆分。 每个节点被访问的次数是固定的。 |
 | 空间| O(1) | O(1) | 我们只存储指向节点的指针； 没有使用与 n 成比例的额外数据结构。 |

 线性时间复杂度是最佳的，因为每个节点必须至少被访问一次，并且恒定空间是理想的，因为我们可以就地修改指针。
