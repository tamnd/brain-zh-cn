[LeetCode 问题 2639](https://leetcode.com/problems/find-the-width-of-columns-of-a-grid/)

 **难度：** 🟢简单
 **主题：** 数组、矩阵

 ## 解决方案

 ## 问题理解

 该问题给了我们一个二维整数矩阵，称为`grid`和`m`行和`n`列。 我们的任务是独立计算每列的宽度。 

列的宽度定义为该列中出现的所有整数中的最大字符串长度。 长度计算遵循标准整数字符串格式规则：

 - 正数直接使用位数。 
- 零有长度`1`。 
- 负数在其长度中包含减号。 

例如：

-`123`有长度`3`-`0`有长度`1`-`-45`有长度`3`因为减号算作一个字符

 输出应该是一个数组`ans`尺寸的`n`， 在哪里：

-`ans[i]`表示列的最大宽度`i`限制相对较小：

 -`1 <= m, n <= 100`- 每个值都介于`-10^9`和`10^9`由于矩阵维度最多为`100 x 100`，元素总数最多为`10,000`。 这意味着即使是简单的遍历方法也是完全可行的。 

一些重要的边缘情况立即脱颖而出：

 - 包含负值的列，因为减号会增加宽度。 
- 仅包含一位数字的列。 
- 价值观如`0`，仍然有长度`1`。 
- 非常小和非常大的整数的混合。 
- 只有一行或一列的网格。 

该问题保证矩阵非空，因此我们永远不需要处理空输入。 

## 方法

 ### 蛮力方法

 最直接的解决方案是独立处理每一列。 对于每一列：

 1. 迭代所有行。 
2. 将每个整数转换为字符串。 
3. 测量绳子长度。 
4. 记录找到的最大长度。 

处理完一列的所有行后，将最大宽度存储在答案数组中。 

这种方法之所以有效，是因为宽度定义仅取决于每列中的最大格式化长度。 通过检查列中的每个值，我们保证找到最大值。 

尽管这被称为强力方法，但对于给定的约束，它已经足够有效，因为矩阵很小。 

### 最佳方法

 最佳方法本质上是相同的遍历，因为每个元素都必须至少检查一次。 没有任何捷径可以让我们在不查看列值的情况下确定列的最大宽度。 

关键的观察结果是问题简化为：

 - 将每个数字转换为其字符串表示形式。 
- 测量表示长度。 
- 跟踪每列的最大值。 

由于每个单元对其列宽都有独立的影响，因此一次通过矩阵就足够了。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|

 ## 算法演练

 1. 确定网格中的列数。 

由于输出需要每列一个宽度，我们首先计算`n = len(grid[0])`。 
2. 创建结果数组。 

初始化一个数组`answer`尺寸的`n`充满零。 每个位置将存储迄今为止为该列找到的最大宽度。 
3. 迭代每一列。 

对于每个列索引`col`，我们将检查该列中的所有行。 
4. 迭代当前列中的每一行。 

访问值`grid[row][col]`。 
5. 将整数转换为字符串。 

计算显示宽度最简单、最安全的方法是使用`str(value)`。 

示例：

 -`str(123)`变成`"123"`-`str(-45)`变成`"-45"`6. 计算字符串长度。 

使用`len(str(value))`确定整数占用多少个字符。 
7. 更新列的最大宽度。 

将当前宽度与存储的最大值进行比较并保留较大的值。 
8. 存储结果。 

处理完一列的所有行后，最大宽度最终确定为`answer[col]`。 
9. 返回完整的答案数组。 

### 为什么它有效

 该算法之所以有效，是因为列中的每个值都被检查一次，并且存储遇到的最大字符串长度。 由于列宽的定义恰好是该列中的最大整数长度，因此保持这个运行最大值可以保证正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def findColumnWidth(self, grid: List[List[int]]) -> List[int]:
        rows = len(grid)
        cols = len(grid[0])

        answer = [0] * cols

        for col in range(cols):
            max_width = 0

            for row in range(rows):
                current_width = len(str(grid[row][col]))
                max_width = max(max_width, current_width)

            answer[col] = max_width

        return answer
```实现首先确定矩阵中的行数和列数。 然后我们用零初始化结果数组，因为尚未计算宽度。 

外循环遍历每一列。 对于每一列，我们维护一个名为`max_width`，它跟踪迄今为止遇到的最大整数长度。 

在内部循环中，列中的每个值都使用以下命令转换为字符串`str()`。 这会自动正确处理负号。 该字符串的长度给出了整数的显示宽度。 

最大宽度不断更新使用`max()`。 处理完一列中的所有行后，最终的宽度将存储在答案数组的相应位置。 

最后返回完整的答案数组。 

## 解决方案```go
package main

import "strconv"

func findColumnWidth(grid [][]int) []int {
	rows := len(grid)
	cols := len(grid[0])

	answer := make([]int, cols)

	for col := 0; col < cols; col++ {
		maxWidth := 0

		for row := 0; row < rows; row++ {
			currentWidth := len(strconv.Itoa(grid[row][col]))

			if currentWidth > maxWidth {
				maxWidth = currentWidth
			}
		}

		answer[col] = maxWidth
	}

	return answer
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 主要区别在于 Go 不提供隐式整数到字符串的转换，因此我们使用`strconv.Itoa()`在测量整数长度之前将整数转换为字符串。 

答案存储在使用以下命令创建的切片中`make([]int, cols)`。 由于 Go 切片会自动使用零值进行初始化，因此不需要额外的设置。 

不存在溢出问题，因为约束安全地符合 Go 的标准整数范围。

 ## 边缘情况

 一种重要的边缘情况是负数。 幼稚的实现可能只计算数字而忘记减号。 例如，`-15`应该有宽度`3`， 不是`2`。 使用`str(value)`自动包含减号，因此实现可以正确处理此问题。 

另一个边缘情况是值`0`。 一些基于重复除法的数字计数方法可能会错误地产生长度`0`为零。 字符串转换完全避免了这种情况，因为`str(0)`正确地变成`"0"`与长度`1`。 

第三个重要的边缘情况是只有一行或一列的网格。 某些矩阵算法假设存在多个行和列，这可能会导致索引错误。 此实现使用通用循环`rows`和`cols`，因此无论网格尺寸是否为，它都能正常工作`1 x n`,`m x 1`，或更大。 

最后的边缘情况涉及非常大的整数，例如`-999999999`。 该算法仍然可以正常工作，因为字符串转换自然可以处理问题约束内的任意大的有效整数值。
