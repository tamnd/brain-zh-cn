[LeetCode 问题 2670](https://leetcode.com/problems/find-the-distinct-difference-array/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定整数数组的**不同差异数组**`nums`。 对于每个索引`i`在数组中，我们计算前缀中**不同元素的数量之间的差异`nums[0, ..., i]`以及**后缀中不同元素的数量**`nums[i + 1, ..., n - 1]`。 结果存储在新数组中`diff`与相同长度`nums`。 

例如，如果数组是`[3,2,3,4,2]`，在索引处`0`，前缀是`[3]`（1 个不同的元素），后缀是`[2,3,4,2]`（3个不同的元素），所以`diff[0] = 1 - 3 = -2`。 我们对每个索引重复此计算。 

输入数组的长度在 1 到 50 之间，每个元素在 1 到 50 之间。这个小约束允许我们使用额外的空间或效率稍低的算法，而不必担心性能下降。 重要的边缘情况包括具有所有相同元素的数组、具有所有唯一元素的数组以及最小数组大小为 1。该问题保证至少有一个元素，因此我们不需要处理空数组。 

## 方法

 蛮力方法很简单：对于每个索引`i`，分别计算前缀和后缀中不同元素的数量。 我们可以使用集合来跟踪不同的元素。 尽管这种方法是正确的，但它会重复地重新计算重叠子数组的不同元素，效率很低。 

最佳解决方案的关键观察是，我们可以在迭代数组时使用集合**增量地构建前缀和后缀**的不同元素计数。 首先，我们通过从末尾迭代到开头来计算所有索引的后缀不同计数。 然后，我们从头开始迭代以计算前缀不同计数，同时计算差异。 这避免了多次重新计算不同计数并减少了不必要的操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 使用集合 | 重新计算每个前缀和后缀的不同元素
 | 最佳| O(n) | O(n) | 使用集增量跟踪前缀和后缀不同计数 |

 ## 算法演练

 1.初始化一个数组`suffixDistinct`长度`n`存储后缀中从每个索引开始的不同元素的数量。 
2.初始化一个空集`seen`在计算时跟踪元素`suffixDistinct`。 
3. 向后迭代`nums`从最后一个索引到第一个索引。 在每个索引处`i`， 添加`nums[i]`到`seen`并设置`suffixDistinct[i] = len(seen)`。 这捕获了后缀中从以下位置开始的不同元素的数量`i`。 
4.初始化一个空集`prefixSeen`跟踪前缀中的元素。 
5. 初始化结果数组`diff`长度`n`。 
6. 向前迭代`nums`来自索引`0`到`n - 1`。 在每个索引处`i`， 添加`nums[i]`到`prefixSeen`，然后计算`diff[i] = len(prefixSeen) - (suffixDistinct[i+1] if i < n - 1 else 0)`。 这确保了后缀计数使用`0`对于最后一个元素。 
7. 返回`diff`大批。 

**为什么有效**：通过预先计算后缀中的不同计数并逐步构建前缀不同计数，我们确保每个`diff[i]`计算正确，没有多余的计算。 这保证了正确性并在线性时间内高效运行。 

## Python 解决方案```python
from typing import List

class Solution:
    def distinctDifferenceArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        suffixDistinct = [0] * n
        seen = set()
        
        # Compute suffix distinct counts
        for i in range(n - 1, -1, -1):
            seen.add(nums[i])
            suffixDistinct[i] = len(seen)
        
        prefixSeen = set()
        diff = [0] * n
        
        # Compute prefix distinct counts and differences
        for i in range(n):
            prefixSeen.add(nums[i])
            suffixCount = suffixDistinct[i + 1] if i < n - 1 else 0
            diff[i] = len(prefixSeen) - suffixCount
        
        return diff
```Python 实现使用两次遍历数组：向后传递以构建`suffixDistinct`以及在维护前缀集的同时计算差异的前向传播。 使用集合可确保正确跟踪不同的元素。 有条件的`if i < n - 1 else 0`处理后缀为空的最后一个元素的边缘情况。 

## 解决方案```go
func distinctDifferenceArray(nums []int) []int {
    n := len(nums)
    suffixDistinct := make([]int, n)
    seen := make(map[int]struct{})

    // Compute suffix distinct counts
    for i := n - 1; i >= 0; i-- {
        seen[nums[i]] = struct{}{}
        suffixDistinct[i] = len(seen)
    }

    prefixSeen := make(map[int]struct{})
    diff := make([]int, n)

    // Compute prefix distinct counts and differences
    for i := 0; i < n; i++ {
        prefixSeen[nums[i]] = struct{}{}
        suffixCount := 0
        if i < n-1 {
            suffixCount = suffixDistinct[i+1]
        }
        diff[i] = len(prefixSeen) - suffixCount
    }

    return diff
}
```在 Go 中，集合是使用`map[int]struct{}`。 该逻辑反映了 Python 解决方案，使用两个通道和映射来跟踪不同的元素。 我们通过检查 if 来显式处理后缀边缘情况`i < n-1`。 

## 工作示例

 **示例：nums = [3,2,3,4,2]**

 | 我| 前缀已见 | 后缀Distinct[i+1] | 差异[我] |
 | ---| ---| ---| ---|
 | 0 | {3} | 3 | 1 - 3 = -2 | 1 - 3 = -2 |
 | 1 | {2,3} | 3 | 2 - 3 = -1 | 2 - 3 = -1
 | 2 | {2,3} | 2 | 2 - 2 = 0 | 2 - 2 = 0
 | 3 | {2,3,4} | 1 | 3 - 1 = 2 |
 | 4 | {2,3,4} | 0 | 3 - 0 = 3 | 3 - 0 = 3 |

 结果数组是`[-2, -1, 0, 2, 3]`。

 ## 边缘情况

 一种重要的边缘情况是**单元素数组**。 这里，前缀包含元素而后缀为空，因此差异始终是前缀的长度减零。 该实现通过检查后缀索引并在以下情况时默认为 0 来处理此问题：`i`是最后一个索引。 

另一个边缘情况是具有**所有相同元素**的数组。 每个前缀和后缀仅计算一个不同的元素，但最后一个元素除外，其中后缀为空。 该代码使用集合的长度正确计算差异。 

第三种边缘情况是**交替重复**。 例如，`[1,2,1,2]`测试当元素不连续重复时，实现是否正确跟踪前缀和后缀中的不同计数。 使用前缀和后缀集可确保重复项不会增加计数。
