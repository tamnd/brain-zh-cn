 **难度：** 🟢简单
 **主题：** 数组、模拟

 ## 解决方案

 ## 问题理解

 该问题描述了两个玩家之间的保龄球比赛的简化评分系统。 每个玩家都有一个数组，代表每回合击中的瓶数，并且正好有`n`轮流。 每个回合通常根据击中的瓶数进行计分，但适用**奖励规则**：如果玩家在前两个回合中的任一回合中击中瓶数（10 个瓶），则当前回合的分数将加倍。 任务是根据这些规则计算两个玩家的总得分，并确定获胜者：玩家 1、玩家 2，如果分数相等则平局。 

输入数组保证具有相同的长度，最多 1000 个元素，每个元素介于 0 到 10 之间。这些约束确保输入足够小，可以直接模拟评分规则，而无需担心性能问题。 关键的边缘情况包括短数组（长度为 1 或 2）、连续罢工序列或平局。 

## 方法

 暴力方法将完全按照描述模拟游戏。 对于每一回合，您检查前两回合的罢工情况并相应地计算分数。 这对于给定的约束是可行的，因为`n`最多为 1000。不需要更复杂的优化，因为每个回合都可以独立评估，只有前两个结果影响分数。 

关键的见解是，你只需要记住前两回合的分数即可决定当前回合是否加倍。 这允许每个玩家使用简单的单遍算法，使用恒定的额外空间来总结总分。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力/模拟| O(n) | O(1) | O(1) | 迭代每个回合并根据前两回合应用奖励规则。 对于这个问题大小来说是最佳的。 |

 ## 算法演练

 1. 初始化`score1`和`score2`为 0。这些将存储玩家 1 和玩家 2 的累积分数。 
2. 循环每个回合索引`i`从 0 到`n-1`。 
3. 对于每个玩家，检查前两轮。 如果其中任何一个是好球（10 个瓶），则将当前回合的瓶数加倍； 否则，使用正常的引脚数。 
4. 将结果值添加到相应玩家的累积分数中。 
5.处理完所有回合后，进行比较`score1`和`score2`。 如果返回 1`score1`更大，2 如果`score2`更大，如果相等则为 0。 

**为什么有效**：该算法保持了以下不变式：`score`根据加倍规则，始终包含正确的回合值总和。 通过仅检查最后两回合，它可以正确应用奖金规则，而不会存储不必要的数据。 

## Python 解决方案```python
from typing import List

class Solution:
    def isWinner(self, player1: List[int], player2: List[int]) -> int:
        def total_score(player: List[int]) -> int:
            score = 0
            for i in range(len(player)):
                if (i >= 1 and player[i-1] == 10) or (i >= 2 and player[i-2] == 10):
                    score += 2 * player[i]
                else:
                    score += player[i]
            return score

        score1 = total_score(player1)
        score2 = total_score(player2)

        if score1 > score2:
            return 1
        elif score2 > score1:
            return 2
        else:
            return 0
```这个Python实现定义了一个辅助函数`total_score`使用单次通过计算玩家的总得分。 条件检查确保基于前两轮正确应用加倍规则。 

## 解决方案```go
func isWinner(player1 []int, player2 []int) int {
    totalScore := func(player []int) int {
        score := 0
        for i := 0; i < len(player); i++ {
            if (i >= 1 && player[i-1] == 10) || (i >= 2 && player[i-2] == 10) {
                score += 2 * player[i]
            } else {
                score += player[i]
            }
        }
        return score
    }

    score1 := totalScore(player1)
    score2 := totalScore(player2)

    if score1 > score2 {
        return 1
    } else if score2 > score1 {
        return 2
    } else {
        return 0
    }
}
```Go 实现密切反映了 Python 逻辑。 辅助函数`totalScore`用于计算每个玩家的总得分。 Go 原生处理整数运算，并使用切片代替列表。

 ## 边缘情况

 1. **单回合游戏**：只有一个元素，因此不适用加倍条件，因为没有之前的回合。 该实现仅通过检查索引 1 和 2 来正确处理此问题。 
2. **连续打击**：如果连续有多个10，则后续每回合可能会因前两次打击而翻倍多次。 该算法正确检查 i-1 和 i-2 以确保应用所有适用的加倍。 
3. **平局**：即使击球顺序和常规击球顺序不同，双方也可以获得相同的总得分。 最终比较确保抽签返回 0，从而防止错误的获胜者分配。
