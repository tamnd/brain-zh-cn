 ## 解决方案

 ## 问题理解

 这个问题要求我们创建一个函数的**记忆版本**。 记忆化是一种技术，您可以存储昂贵的函数调用的结果，并在相同的输入再次发生时返回缓存的结果。 这里，输入是一个函数`fn`那可能是`sum`,`fib`， 或者`factorial`。 

需要理解的要点是：

 1.`sum(a, b)`接受两个整数并返回它们的和。 参数的顺序很重要，所以`sum(2, 3)`不同于`sum(3, 2)`。 
2.`fib(n)`使用递归定义返回第 n 个斐波那契数。 例如，`fib(5) = fib(4) + fib(3)`。 
3.`factorial(n)`递归返回 n 的阶乘。 例如，`factorial(3) = 3 * factorial(2)`。 

我们需要跟踪对原始函数发生了多少次**实际调用**，忽略缓存的结果。 输入动作是`"call"`带参数，或`"getCallCount"`返回未缓存调用的数量。 

约束告诉我们输入规模：

 - 论据`sum`最多可以达到 105，同时`fib`和`factorial`最多只能到10个，所以缓存是可行的。 
- 操作长度可能很大（最多 10^5），因此每次调用我们需要高效的 O(1) 缓存。 

要考虑的边缘情况包括使用相同参数的重复调用、使用最小输入（如 0 或 1）调用函数以及使用不同顺序的参数进行调用`sum`。 

## 方法

 **暴力方法**是每次都调用原始函数而不进行缓存。 这是正确的但效率低下，特别是对于`fib`和`factorial`，因为冗余递归调用使其呈指数增长`fib`。 

**最佳方法**是使用哈希映射（Python 中的字典，Go 中的映射）来缓存结果。 为了`sum`，我们使用一个元组`(a, b)`作为钥匙； 为了`fib`和`factorial`，整数参数本身就是关键。 我们还维护一个实际函数调用次数的计数器。 

这种方法保证了对缓存结果的 O(1) 访问，避免了冗余计算并满足大输入约束。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | Fib 为 O(2^n)，阶乘为 O(n) | O(n) 递归堆栈 | 每次都调用原始函数，对于 fib 和阶乘来说是多余的 |
 | 最佳| 每次调用缓存 O(1) | 缓存的 O(n) | 使用哈希图存储结果，跟踪调用计数 |

 ## 算法演练

 1.定义一个字典`cache`存储先前计算的结果。 键是函数参数，值是结果。 
2. 定义一个整数`call_count`跟踪实际的函数调用。 
3. 定义包装函数`memoized_fn`那：

 - 将其参数转换为元组以用作缓存键。 
- 检查密钥是否存在于`cache`。 
- 如果是，则返回缓存的值。 
- 如果没有，则增加`call_count`，调用原始函数，将结果存储在`cache`，并返回它。 
4. 实现一个方法`getCallCount`简单地返回`call_count`。 
5. 返回记忆的函数和`getCallCount`作为方法或属性。 

**为什么有效：** 该算法确保每个唯一的参数集最多计算一次。 不变的是`cache`始终包含每个唯一输入的第一次计算的结果。 调用计数器仅在新计算时递增，这满足了要求。 

## Python 解决方案```python
from typing import Callable, Any

def memoize(fn: Callable) -> Any:
    cache = {}
    call_count = 0

    def memoized_fn(*args):
        nonlocal call_count
        key = tuple(args)
        if key in cache:
            return cache[key]
        result = fn(*args)
        cache[key] = result
        call_count += 1
        return result

    memoized_fn.getCallCount = lambda: call_count
    return memoized_fn
```这`memoized_fn`函数将参数转换为元组以用作字典中的键。 这`nonlocal`关键字允许修改`call_count`在嵌套函数内部。 这`getCallCount`方法作为属性添加，以允许在不暴露内部详细信息的情况下进行查询。 

## 解决方案```go
package main

type MemoizedFunc struct {
    fn        func(...int) int
    cache     map[string]int
    callCount int
}

func NewMemoizedFunc(fn func(...int) int) *MemoizedFunc {
    return &MemoizedFunc{
        fn:    fn,
        cache: make(map[string]int),
    }
}

func (m *MemoizedFunc) Call(args ...int) int {
    key := ""
    for _, v := range args {
        key += string(rune(v)) + ","
    }
    if val, exists := m.cache[key]; exists {
        return val
    }
    result := m.fn(args...)
    m.cache[key] = result
    m.callCount++
    return result
}

func (m *MemoizedFunc) GetCallCount() int {
    return m.callCount
}
```在 Go 中，我们将记忆函数表示为一个包含原始函数、缓存映射和调用计数的结构体。 键从参数序列化为字符串。 方法`Call`和`GetCallCount`封装行为。

sum_fn = lambda a, b: a + b
memoSum = memoize(sum_fn)

fib_fn = lambda n: 1 if n <= 1 else fib_fn(n - 1) + fib_fn(n - 2)
