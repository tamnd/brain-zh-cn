 # LeetCode 2656 - 恰好 K 个元素的最大和

 ## 问题理解

 问题给了我们一个整数数组`nums`和一个整数`k`。 我们必须准确地执行`k`运营。 在每次操作期间，我们从数组中选择一个元素，将其值添加到我们的分数中，将其从数组中删除，然后插入一个等于所选值加一的新元素。 

目标是在准确之后使总分最大化`k`运营。 

重要的细节是选择号码后`m`，数组获得一个新的数字`m + 1`。 这意味着，如果我们重复选择当前最大值，则每次操作后最大值都会增加1。 

例如，如果最大的数是`5`：

 - 第一选择给出`5`- 数组现在包含`6`- 第二顺位给出`6`- 数组现在包含`7`- 第三顺位给出`7`这就形成了一个连续递增的序列。 

输入包括：

 -`nums`，正整数数组
 -`k`，我们必须执行的确切操作数

 输出是一个整数，表示可能的最大分数。 

限制非常小：

 -`nums.length <= 100`-`nums[i] <= 100`-`k <= 100`这些限制意味着即使是简单的模拟也可以在时间限制内顺利进行。 然而，这个问题的目的是测试我们是否认识贪婪模式和算术级数。 

有几个重要的边缘情况需要考虑：

 - 所有元素都相等的数组
 - 仅包含一个元素的数组
 -`k = 1`，我们只返回最大元素
 - 重复选择相同的递增最大值
 - 小阵列与大阵列`k`该问题保证所有数字都是正整数，因此我们永远不需要处理空数组或负值。 

## 方法

 ### 蛮力方法

 蛮力解决方案直接模拟所描述的过程。 

对于每个`k`操作：

 1. 查找数组中当前的最大值。 
2. 将其添加到分数中。 
3. 删除该值。 
4. 将值加一插回到数组中。 

这是有效的，因为它从字面上遵循问题陈述。 由于选择最大的可用值总是会给出最大的直接贡献，因此强力模拟将产生最佳结果。 

然而，重复搜索最大元素可能效率很低。 每个操作都需要扫描数组来找到最大值，时间复杂度为`O(n * k)`。 

尽管约束足够小，可以通过，但我们可以通过识别数学模式做得更好。 

### 最优贪心法

 关键的观察是我们应该始终选择当前的最大数量。 

假设最大值为`nums`是`max_num`。 

选择一次后：

 - 我们收获`max_num`- 阵列增益`max_num + 1`现在新的最大值变为`max_num + 1`。 

第二次操作后：

 - 我们收获`max_num + 1`- 阵列增益`max_num + 2`这持续了整整`k`运营。 

因此，所选数字的顺序为：```
max_num, max_num + 1, max_num + 2, ..., max_num + (k - 1)
```这是一个算术级数。 

该序列的总和可以直接计算：```
k * max_num + (0 + 1 + 2 + ... + (k - 1))
```使用算术级数公式：```
0 + 1 + 2 + ... + (k - 1) = (k - 1) * k / 2
```所以最终的答案就变成了：```
k * max_num + (k * (k - 1)) / 2
```这完全避免了模拟。

 ## 算法演练

 ### 最优算法

 1. 找到数组中的最大元素。 

我们首先确定其中的最大值`nums`因为选择最大的可用数字总是可以使每一步的得分最大化。 
2. 认识递增序列。 

选择一次最大值后，该值会变大并重新进入数组。 这意味着下一个最佳选择要大一。 

所选值形成以下序列：```
max_num
max_num + 1
max_num + 2
...
max_num + (k - 1)
```3. 计算等差数列的和。 

我们不模拟该过程，而是直接计算：```
k * max_num + (0 + 1 + ... + (k - 1))
```4. 使用算术级数公式。 

来自的整数之和`0`到`k - 1`是：$0+1+2+\cdots+(k-1)=\frac{k(k-1)}{2}$5. 返回最终结果。 

最高分数为：$\text{answer}=k\cdot \max(nums)+\frac{k(k-1)}{2}$### 为什么它有效

 贪心策略之所以有效，是因为选择当前最大值后`m`，重置价值变为`m + 1`，它仍然至少与数组中的所有其他数字一样大。 因此，重复选择不断发展的最大值总是会在每一步产生最大可能的分数。 由于所选值形成连续递增序列，因此算术级数公式给出了精确的最佳总数。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximizeSum(self, nums: List[int], k: int) -> int:
        max_num = max(nums)
        
        return k * max_num + (k * (k - 1)) // 2
```实现首先使用 Python 的内置函数查找数组中最大的元素`max()`功能。 

一旦我们知道了最大值，我们就可以直接使用等差数列公式。 第一部分，`k * max_num`，考虑添加起始最大值`k`次。 第二部分，`(k * (k - 1)) // 2`，添加每次操作后发生的增量。 

整数除法`//`使用该公式是因为该公式始终产生整数结果。 

该实现很简洁，因为数学观察消除了对模拟或附加数据结构的需要。 

## 解决方案```go
func maximizeSum(nums []int, k int) int {
    maxNum := nums[0]

    for _, num := range nums {
        if num > maxNum {
            maxNum = num
        }
    }

    return k*maxNum + (k*(k-1))/2
}
```Go 解决方案遵循与 Python 版本相同的逻辑。 

由于 Go 没有提供内置的`max()`对于切片函数，我们手动迭代数组以找到最大值。 

所有计算均使用内置`int`类型。 考虑到问题的限制，整数溢出不是问题，因为最大可能的答案很小。 

不需要额外的切片或数据结构，因此该解决方案保持恒定的空间复杂度。

 ## 边缘情况

 ### 单元素数组

 如果数组仅包含一个元素，则该元素将始终被重复选择，因为它是唯一可用的选择。 每次操作后，插入的值都会变大一。 有缺陷的实现可能会错误地假设需要多个元素，但该公式自然可以处理这种情况。 

例如：```
nums = [10], k = 3
```序列变为：```
10, 11, 12
```该实现直接根据算术级数公式正确计算结果。 

### 所有元素都相等

 当每个元素具有相同的值时，第一个选择可以是任何索引，因为它们是相同的。 第一次操作后，新插入的值变得比所有剩余元素都大，应该继续被选择。 

例如：```
nums = [5,5,5], k = 2
```幼稚的实现可能会重复选择任意相等的元素，而不是正确跟踪不断变化的最大值。 我们的数学方法完全避免了这个问题。 

### 大 k 值

 当`k`相对于数组大小来说很大，重复选择和重新插入变得尤为重要。 基于模拟的解决方案可能会变得不必要的重复。 

例如：```
nums = [100], k = 100
```所选择的序列范围为`100`通过`199`。 

该实现不是模拟 100 个单独的操作，而是使用算术级数公式立即计算结果，保证了正确性和效率。
