[LeetCode 问题 2617](https://leetcode.com/problems/minimum-number-of-visited-cells-in-a-grid/)

 **难度：** 🔴难
 **主题：** 数组、动态规划、堆栈、广度优先搜索、联合查找、堆（优先级队列）、矩阵、单调堆栈

 ## 解决方案

 ## 问题理解

 该问题要求我们确定需要访问的最小单元格数量才能到达给定区域的右下角`m x n`网格。 每个细胞`(i, j)`包含一个数字`grid[i][j]`代表我们可以从该单元格**向右**或**向下**移动的最大步数。 具体来说，从`(i, j)`我们可以移动到任何单元格`(i, k)`在哪里`j < k <= j + grid[i][j]`或任何细胞`(k, j)`在哪里`i < k <= i + grid[i][j]`。 目标是根据访问的单元格数量找到最短路径，而不是步数或距离。 如果不可能到达右下角，我们返回`-1`。 

输入保证`1 <= m, n <= 10^5`和`1 <= m * n <= 10^5`，这意味着虽然单个维度可能非常大，但单元格总数仅限于`10^5`。 这确保了我们可以在需要时将网格处理为平面结构。 每个单元格中的值小于`m * n`右下角的单元格始终是`0`，这意味着我们无法离开该单元格。 

重要的边缘情况包括只有一行或一列的网格、具有`0`阻止进一步的移动，以及路径被提前阻止的网格。 

## 方法

 **暴力方法**是从左上角的单元格执行标准的广度优先搜索（BFS）。 对于每个单元格`(i, j)`，我们将根据以下条件将所有可能的向右和向下的单元格排队`grid[i][j]`。 这保证了正确性，因为 BFS 在未加权图中找到最短路径。 然而，它太慢了，因为每个单元可能会排队最多`O(m + n)`细胞，导致总时间复杂度为`O((m * n) * (m + n))`。 对于约束条件 (`m * n <= 10^5`），这是不可行的。 

最佳解决方案的**关键见解**是我们不需要对每个单独的可到达单元进行排队。 我们可以跟踪**每行和每列中最远可到达的单元格**。 使用 BFS，我们只需要移动到每个方向上新的最远点。 通过维护两个数组`maxRight[i]`和`maxDown[j]`代表行中最远的未访问单元格`i`和列`j`，我们避免不必要地重新访问单元并减少冗余操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 暴力 BFS | O((m * n) * (m + n)) | O((m * n) * (m + n)) | O(m * n) | 将每个单元格中所有可能的移动入队，速度太慢 |
 | 最远跟踪的最优 BFS | O(m * n) | O(m + n) | BFS 但仅移动到行和列中新的最远可到达单元格 |

 ## 算法演练

 1. 初始化一个BFS队列，从`(0, 0)`有距离`1`因为访问第一个单元格很重要。 
2.维护两个数组：`maxRight[i]`对于行中到达的最远列`i`， 和`maxDown[j]`对于列中到达的最远行`j`。 
3. 当队列不为空时，将当前单元出队`(r, c)`及其当前距离`d`。 
4. 对于**向右移动**，计算可到达的最远列：`endCol = min(n - 1, c + grid[r][c])`。 迭代自`maxRight[r] + 1`到`endCol`，将每个单元格排队`(r, newCol)`有距离`d + 1`，并更新`maxRight[r]`到`endCol`。 
5. 对于**向下移动**，计算可到达的最远行：`endRow = min(m - 1, r + grid[r][c])`。 迭代自`maxDown[c] + 1`到`endRow`，将每个单元格排队`(newRow, c)`有距离`d + 1`，并更新`maxDown[c]`到`endRow`。 
6. 如果我们达到`(m - 1, n - 1)`，返回当前距离。 
7. 如果队列清空而没有达到目标，则返回`-1`。 

**工作原理：** BFS 保证我们第一次到达某个单元时会经过最少数量的已访问单元，因为 BFS 会逐层探索所有单元。 追踪`maxRight`和`maxDown`确保我们不会将同一个单元放入队列两次，从而在提高效率的同时保持正确性。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def minimumVisitedCells(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if m == 1 and n == 1:
            return 1

        maxRight = [-1] * m
        maxDown = [-1] * n
        queue = deque([(0, 0, 1)])  # (row, col, distance)

        while queue:
            r, c, dist = queue.popleft()

            # Move right
            endCol = min(n - 1, c + grid[r][c])
            for newC in range(maxRight[r] + 1, endCol + 1):
                if newC == n - 1 and r == m - 1:
                    return dist + 1
                queue.append((r, newC, dist + 1))
            maxRight[r] = max(maxRight[r], endCol)

            # Move down
            endRow = min(m - 1, r + grid[r][c])
            for newR in range(maxDown[c] + 1, endRow + 1):
                if newR == m - 1 and c == n - 1:
                    return dist + 1
                queue.append((newR, c, dist + 1))
            maxDown[c] = max(maxDown[c], endRow)

        return -1
```BFS 的实现从`(0, 0)`并跟踪每行和每列中最远到达的索引。 这`for`循环仅将尚未访问过的单元入队，确保每个单元最多被处理一次。 支票为`(m - 1, n - 1)`允许提前返回。 

## 解决方案```go
package main

import "container/list"

func minimumVisitedCells(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    if m == 1 && n == 1 {
        return 1
    }

    maxRight := make([]int, m)
    maxDown := make([]int, n)
    for i := 0; i < m; i++ { maxRight[i] = -1 }
    for j := 0; j < n; j++ { maxDown[j] = -1 }

    type Cell struct {
        r, c, dist int
    }

    queue := list.New()
    queue.PushBack(Cell{0, 0, 1})

    for queue.Len() > 0 {
        front := queue.Remove(queue.Front()).(Cell)
        r, c, dist := front.r, front.c, front.dist

        // Move right
        endCol := c + grid[r][c]
        if endCol >= n {
            endCol = n - 1
        }
        for newC := maxRight[r] + 1; newC <= endCol; newC++ {
            if newC == n-1 && r == m-1 {
                return dist + 1
            }
            queue.PushBack(Cell{r, newC, dist + 1})
        }
        if endCol > maxRight[r] {
            maxRight[r] = endCol
        }

        // Move down
        endRow := r + grid[r][c]
        if endRow >= m {
            endRow = m - 1
        }
        for newR := maxDown[c] + 1; newR <= endRow; newR++ {
            if newR == m-1 && c == n-1 {
                return dist + 1
            }
            queue.PushBack(Cell{newR, c, dist + 1})
        }
        if endRow > maxDown[c] {
            maxDown[c] = endRow
        }
    }

    return -1
}
```在 Go 中，我们使用`container/list`实施BFS。 我们定义一个结构体`Cell`存储行、列和距离。 其逻辑与 Python 相似，但注重 Go 的零初始化和显式队列管理。 

## 工作示例

 **示例1：**`grid = [[3,4,2,1],[4,2,3,1],[2,1,0,0],[2,4,0,0]]`开始于`(0,0)`,`grid[0][0] = 3`。 正确的动作：`(0,1),(0,2),(0,3)`。 向下移动：`(1,0),(2,0),(3,0)`。 BFS将逐层探索并达到`(3,3)`分 4 步。 

**示例2：**`grid = [[3,4,2,1],[4,2,1,1],[2,1,1,0],[3,4,1,0]]`最优路径：`(0,0) -> (0,1) -> (1,1) -> (3,1)`总计 3
