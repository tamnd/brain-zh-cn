 ## 解决方案

 ## 问题理解

 问题要求我们找到一对**漂亮的**索引`(i, j)`在两个整数数组中`nums1`和`nums2`长度相等。 一对`(i, j)`如果它最小化相应元素之间的绝对差之和，那么它是美丽的：```
|nums1[i] - nums1[j]| + |nums2[i] - nums2[j]|
```在所有可能的对中，其中`i < j`。 如果有多对具有相同的最小值，则返回**字典顺序最小**对。 字典顺序意味着我们首先比较`i`，如果它们相等，我们比较`j`。 

输入数组最多有`10^5`元素，它足够大，使得所有对的暴力枚举不可行，因为这需要`O(n^2)`运营。 的价值观`nums1[i]`和`nums2[i]`是受数组长度限制的非负整数。 

重要的边缘情况包括最小差异出现在第一个或最后一个索引的数组、具有重复值的数组以及所有元素都相同的数组。 该问题保证至少有两个元素，因此我们不需要处理空数组。 

## 方法

 **暴力方法**很简单：迭代所有对`(i, j)`和`i < j`，计算值`|nums1[i] - nums1[j]| + |nums2[i] - nums2[j]|`对于每一对，并跟踪具有最小值的对。 这可以正常工作，但需要`O(n^2)`时间，这是不可行的`n`最多`10^5`。 

最佳解决方案的**关键见解**来自于观察曼哈顿距离公式可以使用坐标的和与差来重写。 对于任意两点`(nums1[i], nums2[i])`和`(nums1[j], nums2[j])`，曼哈顿距离为：```
|nums1[i] - nums1[j]| + |nums2[i] - nums2[j]|
```当我们考虑**沿排序变换坐标**相邻的对时，该距离最小化。 具体来说，通过考虑诸如`nums1[i] + nums2[i]`和`nums1[i] - nums2[i]`，并按这些值对索引进行排序，我们只需要检查每个排序顺序中的相邻元素。 这大大减少了候选对的数量`O(n^2)`到`O(n)`排序后。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 计算所有对的绝对差值之和 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 对变换后的坐标进行排序并仅检查相邻对 |

 ## 算法演练

 1. **变换坐标**：对于每个索引`i`，计算四个变换值：`nums1[i] + nums2[i]`,`nums1[i] - nums2[i]`,`-nums1[i] + nums2[i]`,`-nums1[i] - nums2[i]`。 这些变换捕获曼哈顿距离公式中的所有符号组合。 
2. **对索引进行排序**：对于每个转换，根据转换后的值对索引进行排序。 
3. **检查相邻对**：对于每个排序的索引列表，迭代连续的对`(i, j)`。 计算原始曼哈顿距离`|nums1[i] - nums1[j]| + |nums2[i] - nums2[j]|`并更新最小距离和字典顺序最小的对。 
4. **返回结果**：考虑所有四个变换和相邻对后，返回距离最小的对。 如果多个对具有相同的距离，则返回字典顺序最小的一个。 

**为什么有效**：按变换后的坐标排序可确保至少在一次变换中相邻点之间必须出现最小的曼哈顿距离。 这是曼哈顿距离沿轴分解的结果。 通过考虑所有四种变换，我们保证不会错过真正的最小值。 

## Python 解决方案```python
from typing import List

class Solution:
    def beautifulPair(self, nums1: List[int], nums2: List[int]) -> List[int]:
        n = len(nums1)
        min_dist = float('inf')
        result = [0, 1]

        transformations = [
            lambda i: nums1[i] + nums2[i],
            lambda i: nums1[i] - nums2[i],
            lambda i: -nums1[i] + nums2[i],
            lambda i: -nums1[i] - nums2[i]
        ]

        for transform in transformations:
            indices = list(range(n))
            indices.sort(key=transform)
            for k in range(n - 1):
                i, j = indices[k], indices[k + 1]
                dist = abs(nums1[i] - nums1[j]) + abs(nums2[i] - nums2[j])
                if dist < min_dist or (dist == min_dist and [i, j] < result):
                    min_dist = dist
                    result = [i, j]
        return result
```**解释**：我们迭代这四个转换中的每一个。 按每个转换对索引进行排序可确保连续索引之间的距离最小。 我们计算每个相邻对的曼哈顿距离，更新最小距离并保持字典顺序。 最后，我们返回找到的最好的一对。 

## 解决方案```go
package main

import (
	"math"
	"sort"
)

func beautifulPair(nums1 []int, nums2 []int) []int {
	n := len(nums1)
	minDist := math.MaxInt64
	result := []int{0, 1}

	transformations := []func(int) int{
		func(i int) int { return nums1[i] + nums2[i] },
		func(i int) int { return nums1[i] - nums2[i] },
		func(i int) int { return -nums1[i] + nums2[i] },
		func(i int) int { return -nums1[i] - nums2[i] },
	}

	for _, transform := range transformations {
		indices := make([]int, n)
		for i := 0; i < n; i++ {
			indices[i] = i
		}
		sort.Slice(indices, func(i, j int) bool {
			return transform(indices[i]) < transform(indices[j])
		})
		for k := 0; k < n-1; k++ {
			i, j := indices[k], indices[k+1]
			dist := abs(nums1[i]-nums1[j]) + abs(nums2[i]-nums2[j])
			if dist < minDist || (dist == minDist && (i < result[0] || (i == result[0] && j < result[1]))) {
				minDist = dist
				result[0], result[1] = i, j
			}
		}
	}
	return result
}

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}
```**说明**：Go 解决方案镜像了 Python 版本。 切片初始化和`sort.Slice`用于对索引进行排序。 词典比较是明确处理的。 这`abs`由于Go缺乏内置的泛型，所以该函数是手动实现的`abs`对于整数。 

## 工作示例

 **示例1**：`nums1 = [1,2,3,2,4]`,`nums2 = [2,3,1,2,3]`转型`nums1[i] - nums2[i]`：`[ -1, -1, 2, 0, 1 ]`排序索引：`[0,1,3,4,2]`检查相邻对：`(0,1)=2`,`(1,3)=1`（新的最小值），`(3,4)=1`（按字典顺序不小于），`(4,2)=4`结果：`[1,3]`检查所有转换后。 考虑所有变换后，最终结果是`[0,3]`。 

**示例2**：`nums1 = [1,2,4,3,2,5]`,`nums2 = [1,4,2,3,5,1]`转型`nums1[i] + nums2[i]`：`[2,6,6,6,7,6]`排序索引：`[0,1,2,3,5,4]`检查相邻对：`(0,1)=5`,`(1,2)=4`,`(2,3)=2`,`(3,5)=3`,`(5,4)=7`转型`nums1[i] - nums2[i]`：`[0,-2,2,0,-3,4]`排序索引：`[4,1,0,3,2,5]`检查相邻对：`(4,1)=1`→ 新的最小值

 结果：`[1,4]`## 复杂度分析
