[LeetCode 问题 2614](https://leetcode.com/problems/prime-in-diagonal/)

 **难度：** 🟢简单
 **主题：** 数组、数学、矩阵、数论

 ## 解决方案

 ## 问题理解

 该问题给了我们一个方阵`nums`尺寸的`n x n`。 我们需要检查出现在矩阵两条对角线上的值，并返回其中最大的素数。 

方阵中有两条对角线：

 - 主对角线包含行索引和列索引相同的元素，`nums[i][i]`- 次对角线包含列索引为的元素`n - i - 1`,`nums[i][n - i - 1]`当矩阵大小为奇数并且元素位于中心时，一个数字可以属于两条对角线。 

该任务专门要求在任一对角线上找到的最大素数。 如果没有对角线元素是素数，则答案应该是`0`。 

素数是大于的整数`1`只能被整除`1`和它本身。 这意味着像这样的值`1`,`0`，负数不是素数。 

矩阵大小可以大到`300 x 300`，每个值可以大到`4 * 10^6`。 这些约束很重要，因为它们告诉我们：

 - 我们不需要检查矩阵中的每个元素，只需检查对角线元素
 - 最多有`2 * n`要检查的对角线值，最多是`600`- 素数检查必须仍然相当有效，因为值可能很大

 一个重要的观察是，即使矩阵包含多达`90,000`元素，只有对角线元素才重要。 这大大减少了所需的工作量。 

一些边缘情况很重要：

 - 矩阵的对角线上不能包含素数
 - 矩阵可能有大小`1 x 1`- 奇数大小的矩阵的中心元素属于两条对角线
 - 可能会出现大的合数，并且不能被错误地分类为质数
 - 最大素数可能出现多次

 因为输入保证是正方形，所以我们不需要处理格式错误的尺寸。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是扫描矩阵中的每个元素。 对于每个元素，我们首先确定它是否属于任一对角线。 如果是，我们将检查它是否是素数并更新迄今为止找到的最大素数。 

这种方法之所以有效，是因为每个矩阵元素都会被检查，因此不会遗漏任何对角线值。 然而，它执行了不必要的工作，因为大多数矩阵元素不在任一对角线上。 

对于一个`n x n`矩阵，该方法检查所有`n^2`元素，尽管只有大约`2n`元素很重要。 

### 最佳方法

 关键的观察是只有对角线元素才重要。 我们可以直接迭代索引，而不是扫描整个矩阵`0`到`n - 1`并访问：

 -`nums[i][i]`-`nums[i][n - i - 1]`对于每个值，我们检查它是否是素数。 如果是，我们更新最大答案。 

剩下的挑战是有效的素性测试。 一个数字`x`只需要测试整除性`sqrt(x)`。 如果该范围内不存在除数，则该数字是质数。 

由于最多有`600`对角线值和每个素性测试的成本最多`O(sqrt(x))`，这个解决方案很容易足够快。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n² × √m) | O(1) | O(1) | 不必要地检查每个矩阵元素 |
 | 最佳| O(n × √m) | O(n × √m) | O(1) | O(1) | 只处理对角线元素 |

 这里，`n`是矩阵维数并且`m`是最大矩阵值。 

## 算法演练

 1. 初始化变量`largest_prime`到`0`。 

该变量存储迄今为止找到的最佳答案。 如果对角线上不存在素数，则它将保留`0`。 
2. 定义辅助函数`is_prime(num)`。 

该函数确定一个数是否为素数。 

- 如果`num <= 1`， 返回`False`- 如果`num == 2`， 返回`True`- 如果`num`是偶数且大于`2`， 返回`False`- 否则，测试可除性`3`到`sqrt(num)`仅使用奇数

 仅检查最多`sqrt(num)`之所以有效，是因为如果存在较大的因子，则也必须存在较小的配对因子。 
3. 迭代所有行索引`0`到`n - 1`。 

对于每行索引`i`，访问：

 - 主对角线值：`nums[i][i]`- 次对角线值：`nums[i][n - i - 1]`4. 检查每个对角线值是否为质数。 

如果一个值是质数，则将其与`largest_prime`并保留较大的值。 
5.处理完所有对角线元素后，返回`largest_prime`。 

### 为什么它有效

 该算法之所以有效，是因为每个对角线定义的每个有效对角线元素都会被访问一次。 主对角线覆盖所有`nums[i][i]`，次对角线覆盖所有`nums[i][n - i - 1]`。 属于对角线的任何元素都必须满足这两种形式之一。 

素性测试在数学上是正确的，因为每个合数至少有一个小于或等于其平方根的除数。 因此，如果该范围内不存在除数，则该数字一定是素数。 

由于该算法检查每个相关的对角线值并保留遇到的最大素数，因此保证最终结果是正确的。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def diagonalPrime(self, nums: List[List[int]]) -> int:
        def is_prime(num: int) -> bool:
            if num <= 1:
                return False
            
            if num == 2:
                return True
            
            if num % 2 == 0:
                return False
            
            limit = int(math.sqrt(num))
            
            for divisor in range(3, limit + 1, 2):
                if num % divisor == 0:
                    return False
            
            return True
        
        n = len(nums)
        largest_prime = 0
        
        for i in range(n):
            primary = nums[i][i]
            secondary = nums[i][n - i - 1]
            
            if is_prime(primary):
                largest_prime = max(largest_prime, primary)
            
            if is_prime(secondary):
                largest_prime = max(largest_prime, secondary)
        
        return largest_prime
```实现从定义辅助函数开始`is_prime`。 该函数首先处理小的边缘情况，从而避免不必要的工作。 偶数大于`2`立即被拒绝，因为它们不能是素数。 

该循环仅检查奇数除数，因为所有偶数除数已被消除。 上限是数字的平方根，这可以保持素性检查的效率。 

主循环迭代所有对角线索引。 对于每个索引，它直接提取两个对角线值，而不是扫描整个矩阵。 每个值都会进行素数测试，到目前为止遇到的最大素数存储在`largest_prime`。 

最后，该方法返回处理完所有对角线元素后的结果。 

## 解决方案```go
package main

import "math"

func diagonalPrime(nums [][]int) int {
	isPrime := func(num int) bool {
		if num <= 1 {
			return false
		}

		if num == 2 {
			return true
		}

		if num%2 == 0 {
			return false
		}

		limit := int(math.Sqrt(float64(num)))

		for divisor := 3; divisor <= limit; divisor += 2 {
			if num%divisor == 0 {
				return false
			}
		}

		return true
	}

	n := len(nums)
	largestPrime := 0

	for i := 0; i < n; i++ {
		primary := nums[i][i]
		secondary := nums[i][n-i-1]

		if isPrime(primary) && primary > largestPrime {
			largestPrime = primary
		}

		if isPrime(secondary) && secondary > largestPrime {
			largestPrime = secondary
		}
	}

	return largestPrime
}
```Go 版本遵循与 Python 解决方案相同的算法结构。 一个显着的区别是 Go 在使用时需要显式转换`math.Sqrt`，因为它运行于`float64`。 

该解决方案使用闭包`isPrime`辅助函数，使实现保持紧凑和可读。 

Go 切片自然地用于矩阵表示，并且整数溢出不是问题，因为最大矩阵值仅`4 * 10^6`。

 ## 边缘情况

 ### 无素数矩阵

 矩阵可以仅包含合数或`1`在它的对角线上。 这很重要，因为粗心的实施可能会错误地对待`1`作为质数或返回未初始化的值。 

该实现通过初始化答案来正确处理这个问题`0`并且仅在找到有效素数时更新它。 

### 单元素矩阵

 当矩阵大小为`1 x 1`，单个值同时属于两条对角线。 有缺陷的实现可能会意外地错误处理索引或错误地重复计算值。 

该算法可以正常工作，因为两个对角表达式的计算结果相同。 即使检查两次，最大操作仍然正确。 

### 大合数

 值可以大到`4 * 10^6`，因此低效的素性测试可能会变得昂贵。 此外，不正确的除数逻辑可能会错误地将大合数分类为质数。 

该实现通过仅测试数的平方根的整除性并跳过不必要的偶数除数来避免这种情况。 这样既保证了正确性又保证了效率。 

### 具有共享中心的奇数尺寸矩阵

 在奇数大小的矩阵中，中心元素属于两条对角线。 幼稚的实现可能会尝试使用引入错误的复杂逻辑来避免重复检查。 

如果需要，此解决方案只需检查该值两次。 由于操作只是最大比较，重复处理不会影响正确性，并使代码更简单。
