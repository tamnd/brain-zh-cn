## 问题理解

 问题提出了一个二元矩阵`mat`尺寸的`m x n`，其中每个元素是`0`或者`1`。 任务是识别包含最大数量的行并返回该行的索引和其中的计数。 如果多行的最大计数相同，则应返回索引最小的行。 

输入`mat`是一个二维数组，其中`mat[i][j]`代表元素在`i`第-行和`j`第 - 列。 输出是一个二元素数组`[row_index, count_of_ones]`。 

约束条件是`1 <= m, n <= 100`，这意味着矩阵相当小并且允许`O(m * n)`没有性能问题的解决方案。 每行保证只有`0`或`1`s，简化了计数操作。 

重要的边缘情况包括多行具有相同数量 1 的矩阵、全零矩阵以及全 1 矩阵。 这些案例可确保解决方案正确处理平局决胜并正确计数。 

## 方法

 最直接的方法是暴力解决方案。 对于矩阵中的每一行，通过迭代每个元素来计算 1 的数量。 维护找到的最大计数及其出现的行索引的记录。 如果一行的计数与当前最大值相同，我们保留索引较小的行以满足问题的平局条件。 这种方法很简单并且保证了正确性，因为它检查了矩阵的每个元素。 

使用Python的内置功能可以进行小的优化`sum()`函数或 Go 的内循环求和，这使得连续计数更快，但不会改变整体时间复杂度。 考虑到问题的规模，`O(m * n)`解决方案是完全可以接受的并且有效地是最优的。

 ## 算法演练

 1.初始化两个变量，`max_count`到`-1`和`row_index`到`-1`。 这些变量将存储迄今为止找到的最大数量以及相应的行索引。 
2. 使用循环迭代矩阵中的每一行。 设当前行索引为`i`。 
3. 计算当前行中有多少个。 在Python中，这可以通过以下方式完成`sum(mat[i])`。 在 Go 中，迭代每个元素并在元素出现时增加计数器`1`。 
4. 比较当前行的个数与`max_count`。 
5. 如果当前计数大于`max_count`， 更新`max_count`使用当前计数和设置`row_index`到`i`。 
6. 如果当前计数等于`max_count`，不执行任何操作，因为索引较小的行是首选。 
7.检查完所有行后，返回`[row_index, max_count]`在 Python 中或`[]int{row_index, max_count}`在围棋中。 

**为什么有效：**

 该算法保证了正确性，因为它只检查每一行和每个元素一次，确保没有遗漏。 保持的不变量是在迭代中的任何点，`max_count`总是存储迄今为止发现的最大数量的并且`row_index`对应于最早达到此计数的行。 这满足了在出现平局时返回具有最大索引和最小索引的行的要求。 

## Python 解决方案```python
from typing import List

class Solution:
    def rowAndMaximumOnes(self, mat: List[List[int]]) -> List[int]:
        max_count = -1
        row_index = -1
        
        for i, row in enumerate(mat):
            count = sum(row)
            if count > max_count:
                max_count = count
                row_index = i
                
        return [row_index, max_count]
```**实施说明：**

 解决方案初始化`max_count`和`row_index`哨兵值。 它循环遍历矩阵`enumerate`，计算每行中的个数`sum(row)`。 每当找到新的最大值时，两个变量都会更新。 该解决方案直接以预期格式返回结果。 使用`sum()`简化计数并保持代码简洁。 

## 解决方案```go
func rowAndMaximumOnes(mat [][]int) []int {
    maxCount := -1
    rowIndex := -1
    
    for i, row := range mat {
        count := 0
        for _, val := range row {
            if val == 1 {
                count++
            }
        }
        if count > maxCount {
            maxCount = count
            rowIndex = i
        }
    }
    
    return []int{rowIndex, maxCount}
}
```**Go 特定注释：**

 在 Go 中，我们使用`range`迭代行和元素。 一个柜台`count`累积行中的个数。 与 Python 不同，Go 没有内置的`sum`对于切片，因此需要显式的内部循环。 返回带有结果的切片`[rowIndex, maxCount]`匹配所需的输出格式。 由于问题的限制，像空切片这样的边缘情况是不相关的。
