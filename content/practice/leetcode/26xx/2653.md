[LeetCode 问题 2653](https://leetcode.com/problems/sliding-subarray-beauty/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、滑动窗口

 ## 解决方案

 ## 问题理解

 该问题要求我们计算每个大小连续的子数组的 **beauty**`k`在给定的整数数组内`nums`。 子数组的美度定义为`xth`该子数组中的最小负数。 如果子数组包含的内容少于`x`负数，美丽的是`0`。 

简单来说，对于每个窗口`k`元素在数组中从左向右滑动，我们需要识别所有负数，按升序对它们进行排序，然后选择`xth`一个（如果存在）。 否则，我们返回`0`。 

输入约束如下：`1 <= n <= 10^5`意味着数组可能非常大，因此具有 O(n_k_log(k)) 复杂度的简单解决方案可能太慢。 每个元素的范围为`-50`到`50`，一个相对较小的范围，允许通过计数技术进行优化。 边缘情况包括没有底片的窗口、有的窗口`x`超过负数的个数，以及有重复负数的数组。 

重要的边缘情况包括子数组`x-1`负数、完全负数或完全非负数的数组，以及`k = 1`它将每个子数组减少为单个元素。 

## 方法

 ### 蛮力方法

 蛮力方法涉及迭代所有大小的子数组`k`。 对于每个子数组，我们收集所有负数，对它们进行排序，然后选择`xth`最小的负数。 如果少于`x`负数，我们返回`0`。 这种方法是正确的，但效率低下，因为对每个子数组进行排序的成本`O(k log k)`，并且有`n-k+1`这样的子数组，导致时间复杂度为 O(n * k log k)，这对于大型数组来说太慢了。 

### 最佳方法

 最佳方法利用小范围的数字`[-50, 50]`使用**计数数组**。 我们维护一个大小为 51 的负数频率数组。 当窗口滑动时，我们增加传入号码的计数并减少传出号码的计数。 为了找到`xth`当前窗口中的负数，我们按升序迭代负数的计数，直到达到累积计数`>= x`。 这种方法避免了排序，并将时间复杂度降低到 O(n * 50)，实际上是 O(n)，这对于大型输入非常有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k log k) | O(n * k log k) | O(k) | 对大小为 k 的每个子数组进行排序 |
 | 最佳| O(n * 50) ~ O(n) | O(51) | 对固定范围内的负数使用计数数组 |

 ## 算法演练

 1.初始化频率数组`count`大小为 51，用于存储从 -50 到 -1 的负数计数。 
2. 预处理第一个大小的窗口`k`：对于每个负数，增加其在数组中的计数。 
3. 通过迭代计数数组、对计数求和并返回来确定第一个窗口的美观度`xth`如果存在则为负； 否则返回`0`。 
4. 将窗口向右滑动一个索引：如果为负，则减少传出元素的计数；如果为负，则增加传入元素的计数。 
5. 在每张幻灯片之后，使用相同的计数方法计算当前窗口的美度。 
6. 将每个美容值附加到结果列表中。 
7. 处理完所有窗口后返回最终结果列表。 

**为什么有效：** 通过维护负数计数并仅更新窗口边缘，我们保证计数数组始终准确地表示当前窗口中的负数。 由于负数范围是固定的，计算`xth`最小的负数是有效且正确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def getSubarrayBeauty(self, nums: List[int], k: int, x: int) -> List[int]:
        count = [0] * 51  # index 0 represents -50, index 50 represents 0
        res = []
        
        def get_beauty():
            cum = 0
            for i in range(50):  # only negative numbers -50 to -1
                cum += count[i]
                if cum >= x:
                    return i - 50
            return 0
        
        # initialize first window
        for i in range(k):
            if nums[i] < 0:
                count[nums[i] + 50] += 1
        
        res.append(get_beauty())
        
        for i in range(k, len(nums)):
            out_num = nums[i - k]
            in_num = nums[i]
            if out_num < 0:
                count[out_num + 50] -= 1
            if in_num < 0:
                count[in_num + 50] += 1
            res.append(get_beauty())
        
        return res
```**说明：** 我们使用固定大小的计数数组来表示负数。`nums[i] + 50`映射 -50..-1 到 0..49。 对于每个窗口幻灯片，我们调整传出和传入元素的计数，并有效地计算美度，而无需排序。 

## 解决方案```go
func getSubarrayBeauty(nums []int, k int, x int) []int {
    count := make([]int, 51) // index 0 for -50
    res := make([]int, 0, len(nums)-k+1)

    getBeauty := func() int {
        cum := 0
        for i := 0; i < 50; i++ { // only negative numbers
            cum += count[i]
            if cum >= x {
                return i - 50
            }
        }
        return 0
    }

    for i := 0; i < k; i++ {
        if nums[i] < 0 {
            count[nums[i]+50]++
        }
    }
    res = append(res, getBeauty())

    for i := k; i < len(nums); i++ {
        outNum := nums[i-k]
        inNum := nums[i]
        if outNum < 0 {
            count[outNum+50]--
        }
        if inNum < 0 {
            count[inNum+50]++
        }
        res = append(res, getBeauty())
    }
    return res
}
```**Go 特定说明：** Go 切片用于结果数组。 计数数组大小和负映射逻辑反映了 Python 版本。 不需要额外的边缘处理，因为该函数保证具有`k <= len(nums)`。
