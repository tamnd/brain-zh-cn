[LeetCode 问题 2663](https://leetcode.com/problems/lexicographyally-smallest-beautiful-string/)

 **难度：** 🔴难
 **主题：** 字符串、贪婪

 ## 解决方案

 ## 问题理解

 该问题需要生成**按字典顺序最小的美丽字符串**，该字符串严格大于给定的美丽字符串`s`。 如果一个字符串只使用第一个字符串，那么它就是美丽的`k`英文字母表中的字母，并且不包含长度为 2 或更大的回文子串。 本质上，没有两个连续的字母可以相同，也没有三个连续的字母可以形成回文。 

输入由一个字符串组成`s`长度`n`和一个整数`k`指定允许的字母表。 输出必须是严格按字典顺序大于的最小字符串`s`并且仍然坚持美丽的弦乐约束。 如果不存在这样的字符串，则应返回空字符串。 

约束条件意味着`n`可以大到 100,000，因此任何生成所有可能字符串的简单方法都是不可行的。 自从`k`至少为 4，我们保证有足够的字母来避免在几乎所有情况下创建回文子串，除非接近词典最大值时。 

重要的边缘情况包括`s`已经是字典顺序上最大的美丽字符串，或者当 的值较小时`k`限制可能的下一个字符，从而无法构造有效的字符串。 

## 方法

 ### 蛮力

 蛮力方法会尝试增加`s`一次一个字符，检查每个候选字符串，看看它是否漂亮。 对于字符串中的每个位置，我们将尝试所有大于当前字母的字母，并递归验证其余字母。 这保证了正确性，但不可行，因为它需要探索指数数量的字符串以获得大的字符串。`n`（最多`k^n`的可能性），这在计算上是不可能的`n = 10^5`。 

### 最佳方法

 关键的见解是**从最后开始贪婪的角色替换**。 我们尝试增加最后一个字符`s`到下一个字典顺序更大的字符。 如果该字符与其前面的字符形成长度为 2 或 3 的回文，我们会跳过它并尝试下一个可能的字符。 一旦找到有效的替换，我们就会用**最小的字典顺序有效字符**填充剩余位置，以确保最小性。 如果某个位置无法放置有效字符，我们将回溯到前一个位置并尝试那里的下一个字符。 这种方法利用贪婪选择属性并确保相对于`n`因为每个位置最多被考虑`k`次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 生成所有可能大于的字符串`s`并检查美丽。 对于大型来说不可行`n`。 |
 | 最佳| O(n*k) | O(n) | 通过局部回文检查从末尾开始贪婪增量，向前填充最少的字符。 |

 ## 算法演练

 1.从字符串的最后一个字符开始`s`并尝试将其增加到下一个字典顺序更大的字符。 
2. 对于每个候选字符，检查其与前一两个字符是否违反回文约束。 
3. 如果找到有效字符，则将其放置并继续用保持美丽字符串属性的最小可能字符填充后续位置。 
4. 如果当前位置无法放置有效字符，则向左移动一个位置并重复该过程。 
5. 继续，直到形成有效字符串或第一个位置已用完。 如果无法解决，则返回空字符串。 

**为什么有效：** 该算法保持当前索引之前的所有字符都是固定且有效的不变性。 通过贪婪地在右侧第一个可用位置处选择下一个字典顺序较大的字符并最小化其余部分，我们确保生成的字符串既美观又是大于的最小可能字符串`s`。 

## Python 解决方案```python
class Solution:
    def smallestBeautifulString(self, s: str, k: int) -> str:
        n = len(s)
        s = list(s)
        
        for i in range(n - 1, -1, -1):
            for c in range(ord(s[i]) + 1, ord('a') + k):
                char = chr(c)
                if (i >= 1 and s[i-1] == char) or (i >= 2 and s[i-2] == char):
                    continue
                s[i] = char
                for j in range(i + 1, n):
                    for next_c in range(ord('a'), ord('a') + k):
                        next_char = chr(next_c)
                        if (j >= 1 and s[j-1] == next_char) or (j >= 2 and s[j-2] == next_char):
                            continue
                        s[j] = next_char
                        break
                return "".join(s)
        return ""
```Python 解决方案从字符串末尾开始迭代，递增字符并检查回文约束。 一旦进行了有效的增量，它就会贪婪地用允许的最小字符填充字符串的其余部分。 

## 解决方案```go
func smallestBeautifulString(s string, k int) string {
    n := len(s)
    arr := []byte(s)

    for i := n - 1; i >= 0; i-- {
        for c := arr[i] + 1; c < byte('a'+k); c++ {
            if (i >= 1 && arr[i-1] == c) || (i >= 2 && arr[i-2] == c) {
                continue
            }
            arr[i] = c
            for j := i + 1; j < n; j++ {
                for next := byte('a'); next < byte('a'+k); next++ {
                    if (j >= 1 && arr[j-1] == next) || (j >= 2 && arr[j-2] == next) {
                        continue
                    }
                    arr[j] = next
                    break
                }
            }
            return string(arr)
        }
    }
    return ""
}
```在 Go 中，实现使用字节数组来就地修改字符串。 逻辑类似于 Python，使用 ASCII 值进行字符操作和本地回文检查。

 ## 边缘情况

 1. **单字符串**：当`n = 1`，算法必须简单地尝试边界内的下一个字符。 该解决方案通过从最后一个字符（也是第一个字符）进行迭代来处理此问题。 
2. **最大字典序字符串**：当`s`由最大的`k`字符按顺序排列，不存在下一个字符串。 如果找不到有效的替换，该算法自然会回溯到第一个字符并返回空字符串。 
3. **小`k`值**：对于`k = 4`，可供选择的字母较少，因此回文约束可能导致无法填充后续位置。 嵌套循环确保仅使用有效字符，并且在不存在有效字符时进行回溯，从而防止无效字符串。
