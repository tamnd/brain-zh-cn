 ## 问题理解

 该问题要求我们确定两个 JSON 值是否，`o1`和`o2`，**高度相等**。 深度平等超越了简单的引用或浅层平等。 对于数字、字符串、布尔值或 null 等原始值，使用严格比较即可轻松实现相等性（`===`）。 对于数组来说，如果两个数组的长度相同，顺序相同，并且每个对应的元素深度相等，则两个数组深度相等。 对于对象，如果两个对象具有完全相同的一组键（顺序无关紧要），则两个对象深度相等，并且每个键的值递归地也深度相等。 

输入由两个有效的 JSON 值组成，可以是基元、数组或对象，并且可以嵌套的最大深度为 1000。每个 JSON 输入的总序列化长度最多可达 105 个字符，这意味着我们不能依赖多次重复遍历结构的低效解决方案。 

需要考虑的重要边缘情况包括：将 null 与其他值、空数组或对象、包含不同类型（例如数字与字符串）的数组、具有相同键但不同值类型的对象以及接近递归限制的深度嵌套结构进行比较。 

## 方法

 蛮力方法是递归地比较值而不进行任何优化。 对于原语，我们检查严格相等。 对于数组，我们迭代所有元素并递归地比较每一对。 对于对象，我们检查所有键是否匹配并递归比较每个相应的值。 这是正确的，但对于深层嵌套结构，递归深度可能是一个问题，并且在大型对象中重复键查找可能会增加运行时间。 

最佳方法利用相同的递归策略，但确保通过排序或使用哈希映射来有效比较对象键，并在一次遍历中遍历数组。 这避免了冗余操作并确保在单个递归遍历中完成比较。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n + m) | O(d) | 每个节点的递归比较，d = 最大嵌套深度|
 | 最佳| O(n + m) | O(d) | 单遍递归遍历与高效的对象键处理，正确处理嵌套数组和对象 |

 ## 算法演练

 1. 检查两个值是否都是基元（数字、字符串、布尔值、null）。 如果是，则返回严格相等的结果。 
2. 如果两个值都是数组，首先比较它们的长度。 如果长度不同，则返回 false。 
3. 递归地迭代数组，使用相同的深度相等函数比较相应的元素。 如果任何对失败，则返回 false。 
4. 如果两个值都是对象，则提取它们的键。 如果键的数量不同，则返回 false。 
5. 确保两个对象具有完全相同的一组键。 对于每个键，递归地比较与该键关联的值。 如果任何比较失败，则返回 false。 
6. 如果之前的所有检查都通过，则返回 true，因为这两个值非常相等。 

工作原理：在每次递归调用时，该函数保证比较每个相应的基元、数组元素和对象值是否完全相等。 通过预先检查数组长度和对象键，可以尽早消除误报。 递归确保嵌套结构得到正确验证。 

## Python 解决方案```python
class Solution:
    def areDeeplyEqual(self, o1: any, o2: any) -> bool:
        if type(o1) != type(o2):
            return False
        
        if isinstance(o1, (int, float, str, bool)) or o1 is None:
            return o1 == o2
        
        if isinstance(o1, list):
            if len(o1) != len(o2):
                return False
            return all(self.areDeeplyEqual(a, b) for a, b in zip(o1, o2))
        
        if isinstance(o1, dict):
            if set(o1.keys()) != set(o2.keys()):
                return False
            return all(self.areDeeplyEqual(o1[k], o2[k]) for k in o1)
        
        return False
```Python 实现首先检查类型不匹配，确保我们不会比较不兼容的类型。 直接比较原始类型。 对于列表，我们验证长度相等，然后递归比较每个元素。 对于字典，我们检查两者是否具有完全相同的键集，然后递归地比较每个相应的值。 该实现自然地通过递归处理嵌套结构。 

## 解决方案```go
func areDeeplyEqual(o1, o2 any) bool {
    switch v1 := o1.(type) {
    case nil:
        return o2 == nil
    case bool, float64, string:
        return o1 == o2
    case []any:
        v2, ok := o2.([]any)
        if !ok || len(v1) != len(v2) {
            return false
        }
        for i := range v1 {
            if !areDeeplyEqual(v1[i], v2[i]) {
                return false
            }
        }
        return true
    case map[string]any:
        v2, ok := o2.(map[string]any)
        if !ok || len(v1) != len(v2) {
            return false
        }
        for k, val1 := range v1 {
            val2, exists := v2[k]
            if !exists || !areDeeplyEqual(val1, val2) {
                return false
            }
        }
        return true
    default:
        return false
    }
}
```在 Go 中，我们使用类型断言来识别每个对象的底层类型`any`价值。 直接比较原始类型。 数组（`[]any`）和地图（`map[string]any`）逐个元素或逐个键递归比较。 Nil 检查正确处理 JSON null 值。
