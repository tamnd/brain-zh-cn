[LeetCode 问题 2606](https://leetcode.com/problems/find-the-substring-with-maximum-cost/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们找到给定字符串的子字符串`s`最大化自定义成本函数。 字符串中的每个字符都有一个值：如果它存在于字符串中`chars`，其值取自数组中相应的索引`vals`; 如果它不存在于`chars`，它的值就是它在字母表中的 1 索引位置 (`'a' = 1, 'b' = 2, ..., 'z' = 26`）。 目标是计算任意连续子串的最大可能值之和`s`。 

输入是：

 -`s`：一串小写字母，长度最大为10^5。 
-`chars`：由不同的小写字母组成的字符串，最大长度为 26。 
-`vals`：对应于的整数数组`chars`。 

输出是一个整数，即所有子串中的最大成本`s`。 值得注意的是，空子字符串的成本为 0，如果所有字符都在`s`非常消极。 

约束表明`s`可能很大，因此任何比 O(n) 或 O(n log n) 更差的解决方案都可能太慢。 关键边缘情况包括：所有字符为负，所有字符为正，`s`完全由不在其中的字符组成`chars`， 和`s`完全由以下字符组成`chars`。 

## 方法

 天真的方法是蛮力：考虑每个可能的子串`s`，通过对字符值求和来计算其成本，并跟踪最大值。 这是正确的，因为它检查所有可能的子字符串。 然而，它的复杂度是 O(n^2)，因为 n = 的长度`s`，这对于 n = 10^5 来说是不可行的。 

最佳方法利用了我们在将每个字符映射到其成本后有效地找到**最大和子数组**问题的见解。 一旦每个字符都有一个数值，问题就简化为 Kadane 算法：迭代成本数组，维护运行总和，如果变为负数，则将其重置为零。 遇到的最大运行总和就是答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 迭代所有子串，求和它们的成本，跟踪 max |
 | 最佳| O(n) | O(1) | O(1) | 使用 Kadane 算法将字符映射到成本 |

 ## 算法演练

 1.初始化一个字典`char_to_val`映射字符`chars`到他们对应的`vals`。 
2. 对于不在其中的字符`chars`，将它们的值定义为`ord(c) - ord('a') + 1`。 
3.初始化两个变量：`max_cost = 0`和`current_sum = 0`。 
4. 迭代每个字符`c`在`s`。 

- 查找其值`char_to_val`如果存在，否则使用其字母值。 
- 将值添加到`current_sum`。 
- 如果`current_sum`低于零，将其重置为零，因为继续会减少最大总和。 
- 更新`max_cost`成为最大的`max_cost`和`current_sum`。 
5.迭代完成后，返回`max_cost`。 

**为什么起作用：** Kadane 的算法保证找到连续子数组的最大和，因为它跟踪最大运行和并丢弃会降低潜在最大值的子数组。 将字符映射到其值将子字符串问题转换为数值数组问题。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumCostSubstring(self, s: str, chars: str, vals: List[int]) -> int:
        char_to_val = {chars[i]: vals[i] for i in range(len(chars))}
        max_cost = 0
        current_sum = 0
        
        for c in s:
            val = char_to_val.get(c, ord(c) - ord('a') + 1)
            current_sum += val
            if current_sum < 0:
                current_sum = 0
            max_cost = max(max_cost, current_sum)
        
        return max_cost
```Python 实现首先构建用于常量时间值检索的查找字典。 然后它应用 Kadane 算法：迭代更新运行总和和最大总和。 使用`ord(c) - ord('a') + 1`处理不在其中的字符`chars`。 像所有负成本这样的边缘情况自然可以通过重置来处理`current_sum`为零。 

## 解决方案```go
func maximumCostSubstring(s string, chars string, vals []int) int {
    charToVal := make(map[rune]int)
    for i, c := range chars {
        charToVal[c] = vals[i]
    }

    maxCost := 0
    currentSum := 0

    for _, c := range s {
        val, exists := charToVal[c]
        if !exists {
            val = int(c - 'a' + 1)
        }
        currentSum += val
        if currentSum < 0 {
            currentSum = 0
        }
        if currentSum > maxCost {
            maxCost = currentSum
        }
    }

    return maxCost
}
```Go 解决方案镜像 Python，使用`map[rune]int`对于字符值。 主要区别在于符文算术的类型转换以及使用`exists`布尔值。

 ## 边缘情况

 1. **全负值**：当每个字符的成本都是负数时，最大子串为空。 这是通过初始化来处理的`max_cost`归零并重置`current_sum`当负值时。 
2. **人物不在`chars`**：必须正确处理具有默认字母值的字符。 通过使用`ord(c) - ord('a') + 1`在Python和`int(c - 'a' + 1)`在 Go 中，我们正确地计算了它们的值。 
3. **长串**：有`s`如果长度达到 10^5，O(n^2) 的解决方案将会超时。 基于 Kadane 的线性方法确保了大输入量下的性能扩展。 
4. **单字符字符串**：只有一个字符的字符串测试最少的输入处理。 该算法正确返回字符的值，如果为负则返回零。 
5. **所有字符均为正数**：当每个字符值为正数时，最大子串为整个字符串。 该算法自然地累加总和而无需重置。
