 **难度：** 🟡 中等
 **主题：** —

 ## 解决方案

 ## 问题理解

 这个问题要求我们实现一个**生成器**，它遍历多维数组并以与**中序遍历**相同的顺序生成整数。 

输入不是普通的一维列表。 相反，它是一个递归结构，其中每个元素可以是：

 - 一个整数
 - 另一个包含更多整数或嵌套数组的多维数组

 我们的任务是返回一个生成器对象，该对象一次生成一个整数，并保留与从**左到右递归遍历该结构时遇到的顺序相同的顺序。 

例如，考虑：```
[[[6]],[1,3],[]]
```遍历过程如下：

 1. 参观`[[6]]`2. 参观`[6]`3. 产量`6`4. 参观`[1,3]`5. 产量`1`6. 产量`3`7. 参观`[]`，没有什么可产生的

 最终输出顺序变为：```
[6,1,3]
```一个关键细节是我们需要返回一个**生成器**，而不是完全扁平化的数组。 这意味着只有在请求时才应延迟生成值`next()`，而不是预先计算所有内容。 

约束条件很重要：

 -`arr.flat().length <= 10^5`-`maxNestingDepth <= 10^5`这些值表明输入可能非常大并且嵌套很深。 

简单的递归解决方案可能会失败，因为 Python 递归深度有限，并且深度嵌套的数组可能会导致堆栈溢出。 同样，创建数组的完全扁平化版本违反了后续要求并浪费了内存。 

一些边缘情况立即很重要：

 - 空输入数组`[]`，不应产生任何结果。 
- 嵌套空数组，例如`[[], [[]], []]`，其中不包含整数。 
- 非常深的嵌套`[[[[[[5]]]]]]`，这可能会破坏递归实现。 
- 混合嵌套结构，例如`[1,[2,[3]],4]`，其中整数出现在多个深度。 
- 大量输入，高达`10^5`元素，不必要的复制会变得昂贵。 

该问题保证所有叶元素都是整数，因此除了检查某个元素是列表还是整数之外，我们不需要验证输入类型。 

## 方法

 ### 蛮力方法

 最直接的解决方案是首先将整个数组展平为一个新列表，然后从该列表中生成元素。 

我们可以递归地遍历该结构，将每个整数附加到结果数组中，最后使用生成器迭代展平列表。 

这是可行的，因为递归遍历自然地保留了所需的从左到右的顺序。 在继续处理下一个同级元素之前，会先探索每个嵌套数组。 

然而，这种方法有很大的缺点。 

首先，它违反了要求我们避免创建新的数组扁平化版本的后续要求。 

其次，它需要与结构中整数的数量成比例的额外内存。 由于压平后的尺寸可能达到`10^5`，没有必要预先存储所有内容。 

第三，递归变得危险，因为嵌套深度也可以达到`10^5`，这可能会超出递归限制并崩溃。 

### 最佳方法

 关键的见解是我们**不需要先展平数组**。 由于生成器已经支持延迟求值，因此我们可以在遇到整数时立即生成整数。 

我们不使用递归，而是使用**显式堆栈**来模拟迭代遍历。 这避免了递归深度问题，并允许我们安全地处理任意深度的嵌套。 

这个想法是维护一个迭代器或位置的堆栈，表示我们当前在嵌套结构中的位置。 

每当我们遇到：

 - 一个整数，我们立即生成它。 
- 一个嵌套数组，我们将其推入堆栈并继续探索它。 

这保留了从左到右的遍历顺序，同时仅使用遍历状态所需的内存。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 在屈服之前完全展平数组 |
 | 最佳 | O(n) | O(d) | 使用堆栈迭代遍历，其中`d`是嵌套深度 |

 这里，`n`是访问的整数和嵌套数组元素的总数，而`d`是最大嵌套深度。 

## 算法演练

 我们使用堆栈的迭代深度优先遍历。 

1. 使用输入数组迭代器初始化堆栈。 

堆栈代表了我们的遍历状态。 每个条目都会跟踪我们当前正在探索的数组。 
2. 当堆栈不为空时，检查顶部迭代器。 

栈顶始终代表当前正在遍历的数组。 
3. 尝试从当前迭代器中获取下一个元素。 

如果没有剩余元素，则从堆栈中删除该迭代器，因为该数组已被完全处理。 
4. 如果下一个元素是整数，则立即产生它。 

由于生成器是惰性的，我们不会将数字存储在任何地方。 我们一遇到就退货。 
5. 如果下一个元素是另一个数组，则将其迭代器压入堆栈。 

这可确保在继续处理剩余同级数组之前处理嵌套数组，从而保留正确的从左到右的遍历顺序。 
6. 继续，直到堆栈变空。 

至此，每一个嵌套结构都已经被充​​分探索了。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 > 堆栈始终表示从根到当前位置的精确遍历路径。 

每当遇到嵌套数组时，它都会被推入堆栈并在返回父数组之前完全探索。 这完全模仿了递归深度优先遍历，确保以相同的从左到右有序序列生成整数。 

因为每个元素都被访问一次，所以遍历既正确又高效。 

## Python 解决方案```python
from typing import List, Generator, Union

class Solution:
    def inorderTraversal(
        self, arr: List[Union[int, list]]
    ) -> Generator[int, None, None]:

        stack = [iter(arr)]

        while stack:
            try:
                value = next(stack[-1])

                if isinstance(value, int):
                    yield value
                else:
                    stack.append(iter(value))

            except StopIteration:
                stack.pop()
```该实现首先初始化一个堆栈，其中包含输入数组上的迭代器。 

我们不是递归地遍历嵌套列表，而是重复处理堆栈顶部的迭代器。 

在循环内部，我们尝试从当前迭代器中检索下一个值。 如果成功，我们将检查该值。 

如果该值是整数，我们立即生成它。 这满足了问题所需的惰性行为。 

如果该值是另一个数组，我们为该数组创建一个迭代器并将其推入堆栈。 这可确保在继续处理剩余的同级元素之前充分探索嵌套数组。 

如果一个`StopIteration`发生异常，这意味着当前数组已被完全处理，因此我们从堆栈中删除该迭代器。 

这种迭代方法完全避免了递归，使得深度嵌套的输入达到问题约束是安全的。 

## 解决方案```go
type NestedArray []interface{}

func inorderTraversal(arr NestedArray) chan int {
	result := make(chan int)

	go func() {
		defer close(result)

		stack := []struct {
			array NestedArray
			index int
		}{
			{array: arr, index: 0},
		}

		for len(stack) > 0 {
			top := &stack[len(stack)-1]

			if top.index >= len(top.array) {
				stack = stack[:len(stack)-1]
				continue
			}

			value := top.array[top.index]
			top.index++

			switch v := value.(type) {
			case int:
				result <- v
			case NestedArray:
				stack = append(stack, struct {
					array NestedArray
					index int
				}{
					array: v,
					index: 0,
				})
			case []interface{}:
				stack = append(stack, struct {
					array NestedArray
					index int
				}{
					array: NestedArray(v),
					index: 0,
				})
			}
		}
	}()

	return result
}
```Go 实现使用通道来模拟生成器行为，因为 Go 没有原生生成器。 

我们不显式存储迭代器，而是显式存储：

 - 当前数组
 - 该数组中的当前索引

 每个堆栈条目都会跟踪一个嵌套级别的遍历进度。 

当遇到整数时，它会通过通道发送。 当找到嵌套数组时，将推送一个新的堆栈帧。 

Go 特定的注意事项包括使用处理类型断言`interface{}`并显式管理索引，因为 Go 切片没有像 Python 那样的迭代器对象。 空切片自然可以工作，无需特殊处理。

 ## 边缘情况

 ### 空输入数组

 空数组，例如`[]`不包含要产生的整数。 如果假设至少存在一个元素，则幼稚的实现可能会意外失败。 

这个实现自然地处理了这种情况。 迭代器立即引发`StopIteration`，导致堆栈被弹出并结束遍历而不产生任何结果。 

### 深度嵌套数组

 输入如：```
[[[[[[5]]]]]]
```如果递归实现，很容易超出递归深度限制。 

我们基于迭代堆栈的解决方案完全避免了递归。 由于它使用堆栈显式管理遍历状态，因此它安全地支持嵌套深度高达`10^5`。 

### 嵌套空数组

 结构如：```
[[], [[]], []]
```包含许多数组但不包含整数。 

有缺陷的解决方案可能会意外地产生不正确的值，或者在下降到空数组时失败。 在这里，空迭代器会立即完成并从堆栈中删除，确保没有不必要的工作和不正确的输出。 

### 混合整数和嵌套数组

 输入如：```
[1, [2, [3]], 4]
```需要在不同的嵌套级别上保持严格的从左到右的顺序。 

堆栈保证在恢复父数组之前充分探索嵌套数组，从而保留问题所需的确切遍历顺序。
