[LeetCode 766 题](https://leetcode.com/problems/toeplitz-matrix/)

 **难度：** 🟢简单
 **主题：** 数组、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定矩阵是否满足托普利茨性质。 如果从左上角到右下角的每条对角线都包含相同的值，则矩阵被视为托普利茨矩阵。 

更正式地说，对于每个有效位置`(row, col)`在矩阵中，该位置的值必须与对角线向下和右侧的值匹配，这意味着：$matrix[row][col] = matrix[row+1][col+1]$每当`(row + 1, col + 1)`仍在矩阵范围内。 

输入是一个二维整数数组`m`行和`n`列。 任务是返回`true`如果所有对角线满足托普利茨条件，否则返回`false`。 

限制相对较小：

 -`1 <= m, n <= 20`- 矩阵值介于`0`和`99`由于矩阵维度很小，即使效率较低的方法也能轻松通过。 然而，我们的目标是设计一个干净且最佳的解决方案，该解决方案在概念上可以很好地扩展，并解决涉及有限内存访问的后续问题。 

立即识别几个边缘情况很重要：

 - 单行矩阵始终是托普利茨矩阵，因为不存在具有多个元素的对角线。 
- 单列矩阵也始终是托普利茨矩阵。 
- 非常小的矩阵，例如`1 x 1`应该返回`true`。 
- 只有一条对角线违反规则的矩阵应正确返回`false`。 
- 矩形矩阵必须正确工作，而不仅仅是方阵。 

该问题保证矩阵非空并且是正确的矩形，因此我们不需要处理格式错误的输入。 

## 方法

 ### 蛮力方法

 一种简单的暴力方法是明确地独立检查每条对角线。 

我们可以从第一行中的每个单元格和第一列中的每个单元格开始一条对角线。 对于每个起点，我们沿对角线向下移动，同时检查所有元素是否与该对角线中的第一个元素匹配。 

这种方法是正确的，因为从左上到右下的每个对角线都被访问一次，并且每个对角线中的每个元素都与预期值进行比较。 

然而，这种方法执行了多余的工作。 在穿过重叠的对角线时，许多单元会被多次重新访问。 尽管约束足够小，在实践中仍然有效，但这并不是解决问题的最干净或最优化的方法。 

### 最佳方法

 关键的观察结果是每个单元格只需要匹配它左上角的元素。 

如果矩阵是托普利茨矩阵，则：$matrix[row][col] = matrix[row-1][col-1]$对于除第一行或第一列中的单元格之外的每个单元格。 

这种见解极大地简化了问题。 我们不遍历整个对角线，而是只将每个元素与其左上角的邻居比较一次。 

如果每次这样的比较都成功，则每条对角线都必须包含相同的值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m × n × min(m, n)) | O(m × n × min(m, n)) | O(1) | O(1) | 独立遍历每条对角线 |
 | 最佳| O(m × n) | O(1) | O(1) | 将每个单元与其左上角的邻居比较一次 |

 ## 算法演练

 1. 从第二行开始迭代，因为第一行没有左上角的邻居。 
2. 对于每一行，从第二列开始迭代，因为第一列也没有左上角的邻居。 
3. 各位置`(row, col)`，将当前值与处的值进行比较`(row - 1, col - 1)`。 
4. 如果两个值不同，立即返回`False`因为托普利茨财产受到侵犯。 
5. 如果所有比较都成功，则继续扫描整个矩阵。 
6. 如果循环完成后没有发现任何不匹配，则返回`True`。 

### 为什么它有效

 核心不变量是每个元素必须等于对角线上方和左侧的元素。 如果此条件适用于每个有效单元格，则每个对角线完全由重复值组成。 

由于每条对角线都是通过反复右下移动形成的，因此确保相邻对角线元素之间的相等性可以保证整个对角线保持不变。 

## Python 解决方案```python
from typing import List

class Solution:
    def isToeplitzMatrix(self, matrix: List[List[int]]) -> bool:
        rows = len(matrix)
        cols = len(matrix[0])

        for row in range(1, rows):
            for col in range(1, cols):
                if matrix[row][col] != matrix[row - 1][col - 1]:
                    return False

        return True
```该实现首先存储行数和列数，以提高可读性和效率。 

外循环从行索引处开始`1`因为第一行中的元素没有左上角的邻居。 类似地，内部循环从列索引开始`1`。 

对于每个单元格，代码都会将当前值与对角上方和左侧的值进行比较。 如果发现不匹配，函数立即返回`False`。 

这种提前终止很重要，因为一旦任何对角线违反托普利茨性质，整个矩阵就无效。 

如果所有比较都成功，则函数返回`True`扫描整个矩阵后。 

## 解决方案```go
func isToeplitzMatrix(matrix [][]int) bool {
    rows := len(matrix)
    cols := len(matrix[0])

    for row := 1; row < rows; row++ {
        for col := 1; col < cols; col++ {
            if matrix[row][col] != matrix[row-1][col-1] {
                return false
            }
        }
    }

    return true
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

Go 切片用于表示矩阵。 由于该问题保证非空矩阵，因此访问`matrix[0]`是安全的。 

由于矩阵值非常小，因此不存在整数溢出问题。 该解决方案仅使用恒定的额外内存。

 ## 边缘情况

 单行矩阵是一种重要的边缘情况，因为没有对角线包含多个元素。 假设每个元素都有左上角的邻居的简单实现可能会意外访问无效索引。 该解决方案通过从行开始迭代来避免该问题`1`和列`1`。 

单列矩阵的行为类似。 每条对角线恰好包含一个元素，因此该矩阵自动为托普利茨矩阵。 由于内部循环从列开始`1`，不会发生无效比较。 

另一个重要的边缘情况是矩阵，其中在遍历后期只有一次比较失败。 例如：```
[
  [1, 2, 3],
  [4, 1, 2],
  [5, 4, 9]
]
```最终比较时出现不匹配。 该实现正确扫描每个所需的单元格并立即返回`False`当检测到违规行为时。 

如果实现假设行数和列数相等，则矩形矩阵也可能导致错误。 该解决方案独立跟踪行和列尺寸，因此宽矩阵和高矩阵都可以正确处理。
