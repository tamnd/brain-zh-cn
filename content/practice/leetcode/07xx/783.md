[LeetCode 783 题](https://leetcode.com/problems/minimum-distance- Between-bst-nodes/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、广度优先搜索、二叉搜索树、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到二叉搜索树（BST）中任意两个节点的值之间的最小差异。 换句话说，给定一个 BST，我们需要计算最小的绝对差`|a - b|`在哪里`a`和`b`是两个不同节点的值。 输入是`root`BST的，保证至少有两个节点，并且所有节点值都在范围内`[0, 10^5]`。 

由于输入是 BST，我们知道节点的左子节点包含较小的值，而右子节点包含较大的值。 这个属性至关重要，因为它意味着 BST 的有序遍历将产生严格递增顺序的值。 因此，此有序序列中的两个连续值之间必须出现最小差异。 

重要的边缘情况包括只有两个节点的非常小的树、所有节点都在一条直线上的树（所有左子节点或所有右子节点）以及具有重复值的树（尽管在此问题中没有明确限制重复值）。 

## 方法

 ### 暴力方法

 最简单的方法是遍历树中的所有节点对，计算每对节点的绝对差，然后返回最小差。 这保证了正确性，因为它考虑了所有可能的对，但效率很低。 为了`n`节点，有`n * (n-1) / 2`对，导致时间复杂度为 O(n²)。 如果我们将所有节点值存储在列表中，空间复杂度为 O(n)。 

### 最佳方法

 关键的见解来自 BST 属性：有序遍历会按排序顺序生成节点。 一旦我们有了节点值的排序序列，两个连续元素之间必须出现最小差异。 这将问题简化为有序序列的线性扫描，如果我们使用递归，则给出 O(n) 时间复杂度和 O(h) 空间复杂度，其中`h`是树的高度（平衡时为 O(log n)，倾斜时为 O(n)）。 我们不需要比较每一对，只需要比较连续的元素。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 比较所有节点对 |
 | 最佳| O(n) | O(h) | 中序遍历并检查连续差异 |

 ## 算法演练

 1.初始化两个变量：`prev`以中序遍历的方式存储前一个节点值`min_diff`存储当前的最小差异。 开始`prev`作为`None`和`min_diff`作为无穷大。 
2. 递归地进行中序遍历。 对于每个节点：

 1. 遍历左子树。 
2.如果`prev`不是`None`，计算当前节点值与`prev`，并更新`min_diff`如果差异更小。 
3. 更新`prev`到当前节点值。 
4. 遍历右子树。 
3、遍历完后，`min_diff`保持任意两个节点之间的最小绝对差。 

**为什么有效：** 中序遍历保证 BST 值的排序顺序。 最小差异必须出现在按排序顺序的两个连续值之间。 通过仅比较连续值，我们确保有效地找到正确的最小值。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional

class Solution:
    def minDiffInBST(self, root: Optional[TreeNode]) -> int:
        self.prev = None
        self.min_diff = float('inf')

        def inorder(node: Optional[TreeNode]):
            if not node:
                return
            inorder(node.left)
            if self.prev is not None:
                self.min_diff = min(self.min_diff, node.val - self.prev)
            self.prev = node.val
            inorder(node.right)
        
        inorder(root)
        return self.min_diff
```**说明：**我们定义一个递归`inorder`遍历树的函数。 对于每个节点，我们首先探索左子节点，然后计算差异`prev`如果存在，则更新`min_diff`，最后更新`prev`到当前节点。 遍历确保按排序顺序访问所有节点。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func minDiffInBST(root *TreeNode) int {
    var prev *int
    minDiff := 1 << 31 - 1  // Max int

    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil {
            return
        }
        inorder(node.Left)
        if prev != nil {
            diff := node.Val - *prev
            if diff < minDiff {
                minDiff = diff
            }
        }
        prev = &node.Val
        inorder(node.Right)
    }

    inorder(root)
    return minDiff
}
```**说明：** 在 Go 中，我们使用指针`prev`跟踪前一个节点值。 我们使用递归中序遍历来维护排序顺序。 该逻辑反映了 Python 实现，具有显式指针处理以适应 Go 的值语义。

 ## 边缘情况

 一种边缘情况是一棵只有两个节点的树。 由于该算法依赖于中序遍历中连续节点之间的差异，因此它通过直接计算差异来正确处理这种情况。 

另一个边缘情况是倾斜树，其中所有节点都是左子节点或右子节点。 这测试了递归处理极端高度并且不会错误地假设平衡结构。 

第三种边缘情况是具有重复的节点值。 即使问题没有明确禁止重复，但如果两个节点具有相同的值，我们的算法会正确返回 0 作为最小差异，这是数学上正确的最小值。 

此实现通过利用有序遍历并仅比较连续值来优雅地处理所有这些边缘情况。
