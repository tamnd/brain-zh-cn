[LeetCode 763 题](https://leetcode.com/problems/partition-labels/)

 **难度：** 🟡 中等
 **主题：** 哈希表、两个指针、字符串、贪婪

 ## 解决方案

 ## 问题理解

 问题是要求我们对字符串进行分区`s`分成尽可能多的连续部分，以便没有字母出现在多个部分中。 换句话说，字符串中的每个字符都应限制在单个段中。 分区后，按顺序连接所有段应该可以准确地再现原始字符串。 输入是一串小写英文字母，长度在1到500之间。输出是一个整数列表，其中每个整数代表一个分区段的长度。 

关键的挑战是确保每个角色最多出现在一个片段中。 一种简单的方法可能会尝试生成所有可能的分区并检查有效性，但对于 500 个字符的上限，这在计算上是不可行的。 

重要的边缘情况包括具有所有相同字符的字符串、没有重复字符的字符串以及除了靠近末尾的单个重复字符之外所有字符都是唯一的字符串。 

## 方法

 ### 蛮力

 暴力方法会尝试探索所有可能的分割字符串的方法，并验证每个分割是否满足每个字母仅出现在一个片段中的规则。 这需要跟踪每个段中的所有字母并将它们与剩余的字符串进行比较。 虽然它是正确的，但效率非常低，因为分割字符串的方法数量随着字符串的长度呈指数增长。 

### 最佳方法

 最佳方法依赖于使用两个指针的贪婪策略。 首先，记录哈希图中每个字符的最后一次出现。 然后迭代该字符串，维护当前分区的运行结束索引，这是迄今为止看到的任何字符的最远最后一次出现。 当当前索引到达这个运行结束时，我们知道我们可以在这里安全地分区，因为稍后该段中不会出现任何字符。 这确保了每个字符被限制在一个段中并产生最大数量的分区。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 尝试所有可能的分割并验证每个分区，这对于大 n | 是不可行的
 | 最佳| O(n) | O(26) ~ O(1) | 使用哈希图跟踪最后出现的贪婪方法，线性扫描 |

 ## 算法演练

 1. 创建一个哈希映射来存储字符串中每个字符的最后一个索引。 这使我们能够知道角色可以出现的最远点。 
2.初始化两个指针：`start`当前分区的开头和`end`跟踪当前分区中任何字符的最远最后一次出现。 
3. 逐个字符地遍历字符串。 对于每个角色，更新`end`到其当前值和该字符最​​后一次出现的最大值。 
4. 如果当前索引等于`end`，这意味着我们已经到达当前分区的末尾。 附加该分区的大小（`end - start + 1`) 到结果列表。 
5. 移动`start`到`index + 1`开始下一个分区。 
6. 继续，直到处理完整个字符串。 

**为什么有效**：贪婪方法保证每个分区包含其字符的所有出现。 不变的是`end`始终表示当前分区中看到的任何字符的最后一个索引。 一旦当前索引达到`end`，此分区中的字符随后不会出现，确保正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # Step 1: record the last occurrence of each character
        last_occurrence = {char: idx for idx, char in enumerate(s)}
        
        partitions = []
        start, end = 0, 0
        
        # Step 2: iterate over the string
        for idx, char in enumerate(s):
            # Step 3: update the end to the farthest last occurrence of any character seen
            end = max(end, last_occurrence[char])
            
            # Step 4: if current index is end, close partition
            if idx == end:
                partitions.append(end - start + 1)
                start = idx + 1
        
        return partitions
```**实现说明**：首先，一个字典`last_occurrence`将每个字符映射到其最后一个索引。 当我们迭代时，我们扩展`end`涵盖迄今为止看到的所有角色。 当当前索引达到`end`，我们最终确定分区并记录其长度。`start`然后更新以开始新的分区。 

## 解决方案```go
func partitionLabels(s string) []int {
    lastOccurrence := make(map[byte]int)
    for i := 0; i < len(s); i++ {
        lastOccurrence[s[i]] = i
    }

    var partitions []int
    start, end := 0, 0

    for i := 0; i < len(s); i++ {
        if lastOccurrence[s[i]] > end {
            end = lastOccurrence[s[i]]
        }
        if i == end {
            partitions = append(partitions, end-start+1)
            start = i + 1
        }
    }
    return partitions
}
```**Go 特定注释**：Go 使用`byte`对于字符串中的字符。 地图`lastOccurrence`保留每个字符的最后一个索引。 片`partitions`用于动态存储分区大小，类似于Python列表。
