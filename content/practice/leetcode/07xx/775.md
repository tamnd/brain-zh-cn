[LeetCode 775 题](https://leetcode.com/problems/global-and-local-inversions/)

 **难度：** 🟡 中等
 **主题：** 数组、数学

 ## 解决方案

 ## 问题理解

 问题提出了一个数组`nums`长度`n`这是整数的排列`0`到`n-1`。 **全局反转**定义为任何对`(i, j)`这样`i < j`和`nums[i] > nums[j]`，这意味着数组中任何位置前面的元素都大于后面的元素。 **局部反转**更具限制性：它只考虑连续元素`(i, i+1)`在哪里`nums[i] > nums[i+1]`。 

任务是确定全局反转总数是否等于局部反转总数。 If every global inversion in the array is also a local inversion, the array satisfies the condition and the function should return`true`; 否则，它应该返回`false`。 

约束提供了重要的背景。 The array length`n`最多可达 100,000 个，并且元素保证是唯一的并且是以下排列`[0, n-1]`。 这使我们能够考虑利用排列属性而不是任意整数的方法。 重要的边缘情况包括长度数组`1`或者`2`，其中反转是有限的，并且除了单个远距离反转之外几乎已排序的数组，这足以破坏理想的排列属性。 

## 方法

 暴力方法将直接计算全局和局部反转。 对于全局反演，这涉及检查所有对`(i, j)`和`i < j`看看是否`nums[i] > nums[j]`。 对于局部反转，我们只需检查每个连续的对。 虽然这会产生正确的答案，但它需要`O(n^2)`全局反转的时间，这对于`n`最多 100,000。 

关键观察可以得出最佳解决方案。 根据定义，每个局部反转都是全局反转。 因此，全局反转数量超过局部反转的唯一情况是存在**非局部全局反转**，即一对`(i, j)`和`j > i + 1`和`nums[i] > nums[j]`。 通过跟踪到目前为止遇到的最大值并将其与距离大于 1 的后续元素进行比较，我们可以检测线性时间内的任何非局部反转。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 计算全局反转的所有对和局部反转的所有连续对 |
 | 最佳| O(n) | O(1) | O(1) | 使用运行最大值和单次遍历数组检查非局部反转 |

 ## 算法演练

 1. 初始化变量`max_seen`到`nums[0]`。 这将跟踪迭代时迄今为止看到的最大数字。 
2. 从索引处迭代数组`1`到`n-2`。 我们停在`n-2`因为最后的局部反转不会创建非局部全局反转。 
3. 对于每个索引`i`， 更新`max_seen`至最大`max_seen`和`nums[i]`。 
4. 检查是否`max_seen > nums[i + 1]`。 如果是，则表示非局部反转，因为数组中较早的元素比不紧邻它的较晚的元素大。 返回`false`立即地。 
5. 如果迭代过程中没有发现非局部反转，则返回`true`在最后。 

**为什么有效：** 根据定义，任何局部反演都会自动计为全局反演。 因此，当且仅当不存在非局部全局反转时，数组具有相等的全局和局部反转。 该算法使用运行最大值有效地精确检查该条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def isIdealPermutation(self, nums: List[int]) -> bool:
        max_seen = nums[0]
        for i in range(1, len(nums) - 1):
            max_seen = max(max_seen, nums[i])
            if max_seen > nums[i + 1]:
                return False
        return True
```Python 实现使用简单的 for 循环和运行最大值。 在每一步中，我们都会更新`max_seen`跟踪迄今为止最大的数字，然后检查`nums[i + 1]`检测非局部反转。 循环停止于`len(nums) - 2`因为最后一个元素无法创建非局部反转。 这直接对应于算法演练。 

## 解决方案```go
func isIdealPermutation(nums []int) bool {
    if len(nums) < 2 {
        return true
    }
    maxSeen := nums[0]
    for i := 1; i < len(nums)-1; i++ {
        if nums[i] > maxSeen {
            maxSeen = nums[i]
        }
        if maxSeen > nums[i+1] {
            return false
        }
    }
    return true
}
```Go 版本反映了 Python 逻辑。 它初始化`maxSeen`使用第一个元素，迭代索引`1`到`len(nums)-2`, 更新`maxSeen`，并检查非局部反转。 Go 需要明确的索引管理和使用`len(nums)`而不是Python的`range`。 边缘情况（例如长度为 1 或 2 的数组）通过返回来处理`true`当不能发生迭代时立即执行。

 ## 边缘情况

 一个重要的边缘情况是长度为 1 的数组，例如`[0]`。 没有可比较的对，因此全局和局部反转计数均为零，并且函数正确返回`true`。 

第二个边缘情况是长度为 2 的数组，例如`[1,0]`。 在这里，单个反转既是局部的也是全局的。 该算法可以正确处理这个问题，因为循环不会迭代过去`len(nums)-2`如果数组太小，则返回`true`。 

第三种边缘情况涉及近排序数组，其中单个远距离元素创建非局部反转，例如`[0,1,3,2]`。 如果不仔细检查非局部反转，简单的算法可能会错误地返回`true`。 运行最大值确保`3 > 2`被检测为非局部反转，并且函数正确返回`false`。 

该解决方案利用任何非局部反转都会立即取消数组具有相同的全局和局部反转的属性，稳健地处理所有这些边缘情况。
