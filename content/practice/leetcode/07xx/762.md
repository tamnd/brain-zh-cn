[LeetCode 762 题](https://leetcode.com/problems/prime-number-of-set-bits-in-binary-representation/)

 **难度：** 🟢简单
 **主题：** 数学、位操作

 ## 解决方案

 ## 问题理解

 该问题需要计算给定范围内的数字`[left, right]`在其二进制表示中具有素数个设置位。 数字的 **设置位** 指的是`1`s 的二进制表示形式。 例如，数字`6`二进制是`110`，其中有`2`设置位。 如果设置的位数是质数，则应该计算该数字。 

输入`left`和`right`定义要评估的数字范围。 预期输出是一个整数，表示满足素数集位条件的数字的计数。 

约束告诉我们`left`和`right`至多是`10^6`，并且它们之间的差异最多为`10^4`。 这表明迭代该范围内的所有数字的简单解决方案是可行的，但我们可以优化素数检查，因为任何数字中的设置位数最多可达`10^6`不能超过 20 位（因为`2^20`刚刚超过一百万）。 这个小的上限允许我们预先计算素数。 

重要的边缘情况包括具有 0 或 1 位设置的数字、位于范围极端的数字 (`1`或者`10^6`)，以及仅包含单个数字的范围。 

## 方法

 ### 蛮力方法

 蛮力方法迭代范围内的每个数字`[left, right]`，将其转换为二进制，计算数量`1`s，并检查该计数是否为素数。 素数检查可以使用简单的迭代方法来完成。 这种方法是正确的，因为它直接实现了问题陈述，但对于具有相同设置位数的数字，素数检查可能会重复多次，效率稍低。 

### 优化方法

 关键的见解是数字的设置位数高达`10^6`不能超过 20。这意味着需要检查素性的唯一可能的设置位计数在范围内`[0, 20]`。 我们可以预先计算这个小范围内的所有素数并将它们存储在一个集合中以进行 O(1) 查找。 然后，对于每个数字，我们只需计算其集合位并检查素数集中的成员资格。 这避免了重复执行成本高昂的素性检查并保持算法的效率。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((右-左+1) * logN * sqrt(K)) | O(1) | O(1) | 在范围内迭代，计算设置位，通过迭代检查素性 |
 | 最佳 | O((右-左+1) * logN) | O(1) | O(1) | 预先计算小型素数集，使用内置运算对集合位进行计数，检查 O(1) | 中的素数成员资格

 ## 算法演练

 1. 预先计算范围内的所有素数`[0, 20]`。 将它们存储在一个集合中以进行 O(1) 查找。 
2. 初始化一个计数器来跟踪具有素数设置位的数字。 
3. 迭代每个数字`num`在包含范围内`[left, right]`。 
4. 计算设置位的数量`num`。 在 Python 中，这可以通过使用来完成`bin(num).count('1')`。 在 Go 中，使用`bits.OnesCount(uint(num))`。 
5. 检查计数的集合位是否在素数集合中。 如果是，则增加计数器。 
6. 处理完所有数字后返回计数器。 

**为什么有效**：之所以有效，是因为该算法对所有数字精确地迭代一次，并使用预先计算的素数来有效地确定素数。 对集合位的计数和对质数集合的检查保证了正确性。 

## Python 解决方案```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        # Precompute primes up to 20 (max set bits possible for numbers <= 10^6)
        prime_set = {2, 3, 5, 7, 11, 13, 17, 19}
        count = 0
        
        for num in range(left, right + 1):
            set_bits = bin(num).count('1')
            if set_bits in prime_set:
                count += 1
        
        return count
```Python 实现预先计算素数并迭代范围。`bin(num).count('1')`有效地计算设置的位。 会员资格`prime_set`是一个O(1)的操作，保证了效率。 

## 解决方案```go
import "math/bits"

func countPrimeSetBits(left int, right int) int {
    primeSet := map[int]bool{
        2: true, 3: true, 5: true, 7: true,
        11: true, 13: true, 17: true, 19: true,
    }
    count := 0

    for num := left; num <= right; num++ {
        setBits := bits.OnesCount(uint(num))
        if primeSet[setBits] {
            count++
        }
    }

    return count
}
```Go 解决方案使用`bits.OnesCount`从`math/bits`封装以有效地计算设置位。 映射用于存储 O(1) 查找的素数，这与 Python 的集合略有不同，但用途相同。

 ## 边缘情况

 1. **单个数字范围**：范围可以是单个数字。 这测试循环是否正确处理`left == right`。 该实现正确地计算该单个数字的设置位并检查素数。 
2. **具有 0 或 1 位设置的数字**：像这样的数字`0`（0 设置位）或`1`（1 位设置）是边缘情况，因为 0 和 1 不是素数。 预先计算的素数集可确保正确处理这些情况，而不会错误地计算它们。 
3. **最大范围大小**：给定约束`right - left <= 10^4`，范围可能很大，但计算集合位并检查素数集仍然有效。 这确保了大输入间隔的性能是可以接受的。 

这种方法对于所有指定的约束和边缘情况都具有鲁棒性，同时保持简单和高效。
