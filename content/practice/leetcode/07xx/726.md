 **难度：** 🔴难
 **主题：** 哈希表、字符串、堆栈、排序

 ## 解决方案

 ## 问题理解

 这个问题要求我们解析一个以字符串表示的化学公式，并返回一个规范字符串，该字符串计算公式中每个原子的数量。 每个原子都以大写字母开头，后面可能有小写字母。 原子后面的数字表示该原子的数量，按照惯例，没有数字意味着计数为 1。括号用于对原子进行分组，右括号后面的数字乘以括号内所有原子的计数。 

例如，`"Mg(OH)2"`是指1个镁原子、2个氧原子和2个氢原子。 嵌套括号是可能的，如`"K4(ON(SO3)2)2"`，这需要正确应用多层括号中的乘数。 

输入始终有效，并且仅包含字母、数字和括号。 它的长度最多可达 1000 个字符，因此任何解决方案都必须有效地处理中等大小的字符串。 边缘情况包括没有数字的公式、深层嵌套的括号或没有分隔符的多个串联公式。 输出必须按原子名称排序，如果计数为 1，则省略计数。 

## 方法

 一种简单的暴力方法会尝试在每个原子和括号处拆分公式，递归地计算原子数，并手动乘以计数。 这种方法很容易出错，尤其是使用嵌套括号时，并且需要复杂的簿记。 它可能需要重复扫描字符串并为每个嵌套组构建新的映射，这可能效率低下。 

最佳解决方案的关键是使用**基于堆栈的方法**。 通过从左到右扫描公式，我们可以在遇到左括号时将新计数器压入堆栈，并在遇到右括号时将其弹出。 当遇到右括号时立即应用乘数。 使用堆栈可确保正确处理嵌套结构，并且组合来自不同嵌套级别的计数变得简单。 累积所有计数后，对输出进行排序和格式化就很简单。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 字典的递归解析和重复合并； 嵌套公式效率低下。 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 基于堆栈的单通道； 最后的排序会贡献 log n 因子。 |

 ## 算法演练

 1. 初始化一个堆栈，用于存储`Counter`用于跟踪每个嵌套级别的原子计数的对象。 推一个空`Counter`为基础水平。 
2. 使用索引逐字符迭代公式字符串`i`。 
3. 当遇到大写字母时，通过在其后面附加任何小写字母来读取完整的原子名称。 
4. 紧接着原子之后，读取代表计数的任何数字。 如果不存在数字，则计数为 1。 
5.更新顶部`Counter`与原子及其计数一起在堆栈上。 
6. 当左括号`'('`遇到了，push一个新的空`Counter`到堆栈上以启动新的嵌套范围。 
7. 当右括号时`')'`遇到时，读取其后面的数字以确定乘数（如果缺少，则默认为 1）。 弹出顶部`Counter`，将其所有计数乘以乘数，并将其合并到前一个`Counter`在堆栈上。 
8. 处理完整个公式后，剩下的`Counter`堆栈上包含每个原子的总计数。 
9. 按字母顺序对原子进行排序并构造输出字符串。 仅当计数大于 1 时才追加计数。 

**为什么有效：** 堆栈确保每个嵌套级别都单独计数，并且当括号关闭时，计数会正确相乘。 堆栈的顶部始终代表当前的活动范围，因此原子会在正确的上下文中累积。 这保证了最终合并的计数器是正确的。 

## Python 解决方案```python
from collections import Counter

class Solution:
    def countOfAtoms(self, formula: str) -> str:
        stack = [Counter()]
        i, n = 0, len(formula)

        while i < n:
            if formula[i] == '(':
                stack.append(Counter())
                i += 1
            elif formula[i] == ')':
                i += 1
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                multiplier = int(formula[start:i] or 1)
                top = stack.pop()
                for atom in top:
                    stack[-1][atom] += top[atom] * multiplier
            elif formula[i].isupper():
                start = i
                i += 1
                while i < n and formula[i].islower():
                    i += 1
                atom = formula[start:i]
                start_count = i
                while i < n and formula[i].isdigit():
                    i += 1
                count = int(formula[start_count:i] or 1)
                stack[-1][atom] += count
            else:
                i += 1

        result = []
        for atom in sorted(stack[-1]):
            cnt = stack[-1][atom]
            result.append(f"{atom}{cnt if cnt > 1 else ''}")
        return ''.join(result)
```该代码使用基数初始化堆栈`Counter`并逐个字符地处理公式。 括号压入和弹出新计数器，应用乘数。 原子及其计数将添加到当前顶部计数器中。 最后，原子被排序并连接成输出字符串。 

## 解决方案```go
import (
    "strconv"
    "strings"
    "unicode"
)

func countOfAtoms(formula string) string {
    type Counter map[string]int
    stack := []Counter{{}}
    n := len(formula)
    i := 0

    for i < n {
        c := formula[i]
        if c == '(' {
            stack = append(stack, Counter{})
            i++
        } else if c == ')' {
            i++
            start := i
            for i < n && unicode.IsDigit(rune(formula[i])) {
                i++
            }
            multiplier := 1
            if start != i {
                multiplier, _ = strconv.Atoi(formula[start:i])
            }
            top := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            for atom, cnt := range top {
                stack[len(stack)-1][atom] += cnt * multiplier
            }
        } else if unicode.IsUpper(rune(c)) {
            start := i
            i++
            for i < n && unicode.IsLower(rune(formula[i])) {
                i++
            }
            atom := formula[start:i]
            startCount := i
            for i < n && unicode.IsDigit(rune(formula[i])) {
                i++
            }
            count := 1
            if startCount != i {
                count, _ = strconv.Atoi(formula[startCount:i])
            }
            stack[len(stack)-1][atom] += count
        } else {
            i++
        }
    }

    atoms := make([]string, 0, len(stack[0]))
    for atom := range stack[0] {
        atoms = append(atoms, atom)
    }
    sort.Strings(atoms)
    var sb strings.Builder
    for _, atom := range atoms {
        sb.WriteString(atom)
        if stack[0][atom] > 1 {
            sb.WriteString(strconv.Itoa(stack[0][atom]))
        }
    }
    return sb.String()
}
```Go 解决方案反映了 Python 解决方案，具有 Go 特定的堆栈切片处理方式，`map[string]int`对于计数器，以及`strconv`用于转换数字。 排序和字符串连接使用 Go 习惯用法。
