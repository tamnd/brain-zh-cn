## 问题理解

 该问题要求我们将一个值插入到**已排序的循环链表**中，以使列表保持排序状态。 循环链表是最后一个节点指向第一个节点的链表，从而创建一个循环。 列表按非降序排序，但给定的参考节点**不保证是最小的**。 

输入是对循环列表中任何节点的引用（或`null`如果列表为空）和一个整数`insertVal`。 输出应该是相同的引用节点（如果列表为空，则为新节点），并正确插入新值。 

约束和重要考虑因素：列表可能为空，可能只有一个节点，也可能有多个节点。 节点值可以是负值或正值。 由于循环和重复值，可能存在多个有效插入点。 该解决方案必须正确处理所有这些情况。 

重要的边缘情况包括：插入空列表、插入小于所有现有节点的值、插入大于所有现有节点的值以及插入所有节点值相等的列表。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是逐个节点遍历循环列表并检查**每对连续节点**以找到新值应该去的位置。 该值应插入到`curr`和`curr.next`如果它**在它们的值之间**。 

在循环列表中，如果列表从最大回绕到最小值，如果**大于 max 或小于 min **，我们可以插入新值，即当`curr.val > curr.next.val`。 

这种方法可行，但需要在最坏的情况下遍历整个列表才能找到正确的插入点。 虽然功能强大，但它可以在可读性和优雅处理边缘情况方面进行优化。 

### 最佳方法

 关键的观察是，在已排序的循环列表中，插入只有两个主要条件：

 1. 新值按升序落在**两个节点**之间（`curr.val <= insertVal <= curr.next.val`）。 
2. 新值要么**大于当前最大值，要么小于当前最小值**（过渡点，其中`curr.val > curr.next.val`）。 

通过在遍历时检测这些条件，我们可以在**一次**中找到正确的插入点，即使列表是循环的或包含重复项。 如果在一个完整的循环后没有条件匹配，则所有节点都是相等的，我们可以在**任何地方**插入，例如在起始节点之后。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 遍历整个链表查找插入； 有效但冗长 |
 | 最佳 | O(n) | O(1) | O(1) | 使用两个条件的单遍插入； 处理所有边缘情况 |

 ## 算法演练

 1.如果输入节点`head`是`None`，创建一个新节点`insertVal`并将其指向自身。 返回该节点。 
2. 初始化一个指针`curr`到`head`。 
3.无限循环，检查连续的节点`curr`和`curr.next`。 插入条件有3种：

 a. 如果`curr.val <= insertVal <= curr.next.val`，插入此处。 

b. 如果`curr.val > curr.next.val`（从最大到最小的过渡）和`(insertVal >= curr.val or insertVal <= curr.next.val)`，插入此处。 

c. 如果我们返回起始节点而没有找到合适的位置（所有值都相等），则插入到后面`curr`。 
4. 要插入，请使用以下命令创建一个新节点`insertVal`，设置其`next`到`curr.next`，然后更新`curr.next`到新节点。 
5.归还原件`head`。 

**为什么有效：**

 该算法保持了列表是循环且已排序的不变性。 通过检查正常升序和最大到最小转换，我们保证插入保留顺序。 即使所有值都相等，后备也可确保插入。 

## Python 解决方案```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, next=None):
        self.val = val
        self.next = next
"""

class Solution:
    def insert(self, head: 'Optional[Node]', insertVal: int) -> 'Node':
        if not head:
            new_node = Node(insertVal)
            new_node.next = new_node
            return new_node
        
        curr = head
        while True:
            if curr.val <= insertVal <= curr.next.val:
                # Normal case: value fits between two nodes
                break
            if curr.val > curr.next.val:
                # Transition from max to min
                if insertVal >= curr.val or insertVal <= curr.next.val:
                    break
            curr = curr.next
            if curr == head:
                # Completed full cycle without break; insert anywhere
                break
        
        new_node = Node(insertVal, curr.next)
        curr.next = new_node
        return head
```**说明：**

 该代码首先通过创建一个自引用节点来处理空列表。 然后它遍历循环列表检查两个插入条件。 如果一个完整循环后没有条件匹配，则将新节点插入到起始节点之后。 这可以处理重复项并确保列表保持循环。 

## 解决方案```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Next *Node
 * }
 */

func insert(head *Node, insertVal int) *Node {
    if head == nil {
        newNode := &Node{Val: insertVal}
        newNode.Next = newNode
        return newNode
    }
    
    curr := head
    for {
        if curr.Val <= insertVal && insertVal <= curr.Next.Val {
            break
        }
        if curr.Val > curr.Next.Val {
            if insertVal >= curr.Val || insertVal <= curr.Next.Val {
                break
            }
        }
        curr = curr.Next
        if curr == head {
            break
        }
    }
    
    newNode := &Node{Val: insertVal, Next: curr.Next}
    curr.Next = newNode
    return head
}
```**说明：**

 Go 解决方案在结构上与 Python 版本相同。 Nil 检查对于空列表是显式的。 Go 指针自然地处理循环引用。 遍历和插入的逻辑反映了 Python，但要特别注意`curr == head`来检测一个完整的周期。 

## 工作示例

 ### 示例 1：`head = [3,4,1]`,`insertVal = 2`| 步骤| 当前值 | curr.next.val | 条件满足吗？ | 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 3 | 4 | 3 <= 2 <= 4？ 没有 | 移至下一个 |
 | 2 | 4 | 1 | 4 > 1 且 2 <= 1 或 2 >= 4？ 没有 | 移至下一个 |
 | 3 | 1 | 3 | 1 <= 2 <= 3？ 是的 | 在 1 和 3 之间插入 |

 结果：`[3,4,1,2]`### 示例 2：`head = []`,`insertVal = 1`空列表 → 创建`Node(1)`指向自己。 结果：`[1]`。 

### 示例 3：`head = [1]`,`insertVal = 0`单节点列表 → 1 > 1? 否，完整循环已完成 → 在 1 之后插入。结果：`[1,0]`。
