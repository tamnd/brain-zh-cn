## 问题理解

 问题是要求我们确定是否可以从给定的底行块构造出一个块金字塔，使得上面的所有块都遵守某些三角形堆叠规则。 每个块都有一个由单个大写字母表示的颜色`A`到`F`。 底部上方一行中的每个块必须正好位于其下方的两个相邻块上，形成一个三角形，并且每对底部块只允许特定的顶部块结果。 这些允许的模式以字符串列表的形式提供，其中每个字符串的长度为 3：前两个字母是底部块，第三个是允许的顶部块。 

输入包括：

 -`bottom`：代表金字塔基行的字符串。 
-`allowed`：定义允许的三角形图案的唯一三字符字符串列表。 

输出是一个布尔值：

 -`true`如果金字塔可以一直建造到单个顶部块，同时遵守所有允许的模式。 
-`false`否则。 

约束阐明了问题的规模：

 -`2 <= bottom.length <= 6`，所以最大高度为 6。 
-`0 <= allowed.length <= 216`因为有 6 个字母，给出`6*6*6 = 216`可能的三元组。 
- 所有信件均来自`{'A','B','C','D','E','F'}`，简化索引和存储。 

重要的边缘情况包括：

 - 底行一对相邻块不存在允许的模式。 
- 允许的模式包含单个对的多个可能的顶部块。 
- 最小和最大底行长度，即 2 和 6。 

## 方法

 ### 蛮力

 暴力方法是尝试所有可能的方法将块逐行放置在顶部。 对于每对相邻块，我们找到所有允许的顶部块，并递归地尝试所有组合来构建下一个级别。 这种方法保证了正确性，因为它探索了所有可能的金字塔，但速度很慢：组合的数量随着金字塔的高度呈指数增长。 对于底部长度`n`，每对最多可以有 6 个可能的顶部块，从而导致`O(6^(n-1 + n-2 + ... + 1)) = O(6^(n(n-1)/2))`的可能性。 

### 最佳方法

 关键的见解是，我们可以使用哈希图来有效地查找每个底部对允许的顶部块，并使用 DFS（深度优先搜索）来递归地尝试构建金字塔。 由于底部长度很小（<=6），因此带有剪枝的 DFS 是可行的。 通过记住中间级别或尽早避免不可能的路径，我们可以防止不必要的递归。 这种方法利用了小的输入约束和问题的结构（顶部块仅依赖于相邻的底部对）。

 | --- | --- | --- | --- |
 | 蛮力 | O(6^(n(n-1)/2)) | O(6^(n(n-1)/2)) | O(n) | 递归尝试所有可能的组合 |
 | 最优（DFS + 哈希图）| O(6^(n(n-1)/2)) 最坏情况，实际修剪减少了这个 | 哈希映射的 O(allowed.length) + O(n) 递归 | 允许顶块查找和修剪的 DFS |

 ## 算法演练

 1. **预处理允许的模式：** 创建哈希图`pair_to_tops`其中键是一个元组`(a, b)`两个底部块的集合，该值是允许的顶部块的集合。 这允许在递归期间进行恒定时间查找。 
2. **DFS递归函数：**定义一个函数`can_build(current_level)`返回`True`如果金字塔可以从以下开始完成`current_level`。 
3. **基本情况：** 如果`current_level`长度为1，是金字塔的顶端。 返回`True`。 
4. **生成下一级的可能性：** 对于每对相邻的块`(current_level[i], current_level[i+1])`，从中检索可能的顶部块`pair_to_tops`。 如果不存在允许的顶部，则返回`False`立即地。 
5. **回溯：** 使用每对允许的顶部块递归地尝试构建下一个级别的所有组合。 这可以通过生成代表下一个级别的所有字符串并调用来实现`can_build`在每一个上。 
6. **返回：** 如果下一层的任意组合都导致了完整的金字塔，则返回`True`。 如果没有，则返回`False`。 

**为什么有效：** 在每一步中，我们仅根据允许的模式探索有效的金字塔。 由于 DFS 会尝试所有可能的顶部块组合，因此不会遗漏任何有效配置，从而保证了正确性。 

## Python 解决方案```python
from typing import List, Dict, Set
from collections import defaultdict

class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        pair_to_tops: Dict[str, Set[str]] = defaultdict(set)
        for triple in allowed:
            pair_to_tops[triple[:2]].add(triple[2])

        def can_build(current_level: str) -> bool:
            if len(current_level) == 1:
                return True  # Reached the top successfully

            next_level_options = []

            def dfs_next_level(index: int, path: List[str]):
                if index == len(current_level) - 1:
                    next_level_options.append(''.join(path))
                    return
                pair = current_level[index:index+2]
                if pair not in pair_to_tops:
                    return  # Dead end, no allowed top
                for top in pair_to_tops[pair]:
                    path.append(top)
                    dfs_next_level(index + 1, path)
                    path.pop()

            dfs_next_level(0, [])
            for next_level in next_level_options:
                if can_build(next_level):
                    return True
            return False

        return can_build(bottom)
```**实施演练：**`pair_to_tops`字典存储每个底部对的所有允许的顶部块。`can_build`递归地尝试构建金字塔。`dfs_next_level`生成所有有效的下一级字符串。 递归确保考虑所有有效配置，并且当一对不存在允许的顶部时进行修剪。 

## 解决方案```go
func pyramidTransition(bottom string, allowed []string) bool {
	pairToTops := make(map[string][]byte)
	for _, triple := range allowed {
		pair := triple[:2]
		top := triple[2]
		pairToTops[pair] = append(pairToTops[pair], top)
	}

	var canBuild func(current string) bool
	canBuild = func(current string) bool {
		if len(current) == 1 {
			return true
		}
		var nextLevels []string

		var dfsNext func(index int, path []byte)
		dfsNext = func(index int, path []byte) {
			if index == len(current)-1 {
				nextLevels = append(nextLevels, string(path))
				return
			}
			pair := current[index : index+2]
			tops, ok := pairToTops[pair]
			if !ok {
				return
			}
			for _, top := range tops {
				dfsNext(index+1, append(path, top))
			}
		}

		dfsNext(0, []byte{})
		for _, next := range nextLevels {
			if canBuild(next) {
				return true
			}
		}
		return false
	}

	return canBuild(bottom)
}
```**Go 特定注释：** Go 使用切片而不是列表，并且字符串是不可变的，因此我们使用字节切片仔细构建下一个级别。 递归 DFS 逻辑类似于 Python，其中`map[string][]byte`作为哈希图。
