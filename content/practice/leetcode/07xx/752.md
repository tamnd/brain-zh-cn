 **难度：** 🟡 中等

 ## 解决方案

 ## 问题理解

 该问题提出了一把有四个轮子的锁，每个轮子标记为`'0'`到`'9'`，可以向前或向后旋转。 锁定开始于`'0000'`，并且我们得到了一个“死端”列表，它们是锁状态，如果达到，将导致锁冻结。 目标是确定达到指定值所需的最小车轮转数`target`状态，不经过任何死胡同。 如果由于死胡同阻塞所有路径而无法到达目标，我们必须返回`-1`。 

输入由两个主要部分组成：`deadends`和一个字符串`target`。 每个死端和目标都是代表锁轮的 4 个字符的字符串。 约束保证`target`永远不会成为死胡同，并且死胡同的数量是可控的（最多 500 个）。 该问题涉及搜索锁的状态空间，该空间最多有 10,000 个状态（`0000`到`9999`）。 

边缘情况包括从死胡同开始，目标仅一步之遥，或者完全围绕起始状态的死胡同，使其无法继续。 

## 方法

 蛮力方法将尝试探索所有可能的移动序列`'0000'`直到达到目标，同时避免死胡同。 这可以通过递归深度优先搜索来实现，探索每个轮子的每一个可能的转动。 虽然它是正确的，但复杂性随着移动次数的增加而呈指数级增长，这使得它对于这个问题来说是不切实际的，因为它可以在最坏的情况下探索几乎所有 10,000 种可能的状态。 

关键的见解是，该问题可以建模为未加权图中的最短路径搜索，其中节点是锁定状态，边连接单轮转动不同的状态。 使用**广度优先搜索 (BFS)** 可确保我们找到到达目标的最小转弯数，因为 BFS 会探索远处的所有状态`d`在探索远距离状态之前从头开始`d+1`。 我们还需要一个`visited`设置为避免重新访问状态和`deadends`设置修剪无效路径。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(10^L * L!) | O(10^L * L!) | O(10^L) | O(10^L) | 递归 DFS 探索所有的移动序列； 指数级的且不切实际的|
 | 最佳 | O(10^L * L) | O(10^L * L) | O(10^L) | O(10^L) | 来自的 BFS`'0000'`避免死胡同； 保证最短路径|

 这里，`L`是4，轮子的数量。 

## 算法演练

 1. 转换`deadends`列表成一个`set`用于 O(1) 成员资格检查。 
2. 检查启动状态是否`'0000'`是在`deadends`。 如果是，则返回`-1`立即因为我们无法开始。 
3. 使用起始状态初始化队列`'0000'`和一个移动计数器。 
4. 初始化一个`visited`设置为跟踪已经探索过的状态。 
5. 当队列不为空时，处理BFS当前级别的所有状态：

 1. 将状态出列并检查它是否与目标匹配。 如果是，则返回到达该位置所需的移动次数。 
2. 对于每个车轮位置，通过递增或递减数字（围绕 0-9）生成两个新状态。 例如，转动`'0'`向后给出`'9'`。 
3. 如果生成的状态不是`deadends`并且尚未被访问过，将其添加到队列中并将其标记为已访问。 
6. 在处理完当前 BFS 级别的所有状态后，增加移动计数器。 
7. 如果队列变空而没有找到目标，则返回`-1`。 

**为什么有效：** BFS 保证未加权图中的最短路径，因为它探索了远处的所有状态`d`在远处的状态之前`d+1`。 使用访问集可确保我们不会重新访问状态并防止因循环轮子位置而导致的无限循环。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def openLock(self, deadends: List[str], target: str) -> int:
        dead_set = set(deadends)
        if '0000' in dead_set:
            return -1
        
        queue = deque([('0000', 0)])  # state, steps
        visited = set('0000')
        
        while queue:
            state, steps = queue.popleft()
            if state == target:
                return steps
            
            for i in range(4):
                digit = int(state[i])
                for move in (-1, 1):
                    new_digit = (digit + move) % 10
                    new_state = state[:i] + str(new_digit) + state[i+1:]
                    if new_state not in dead_set and new_state not in visited:
                        visited.add(new_state)
                        queue.append((new_state, steps + 1))
        
        return -1
```此 Python 实现将死端初始化为一组以进行高效查找，并使用队列来实现 BFS。 通过向前和向后转动每个轮子、跳过死胡同和访问过的状态来扩展每个状态。 这`steps`变量跟踪移动次数，随着 BFS 级别自然增加。 

## 解决方案```go
package main

import "container/list"

func openLock(deadends []string, target string) int {
    deadSet := make(map[string]bool)
    for _, d := range deadends {
        deadSet[d] = true
    }
    if deadSet["0000"] {
        return -1
    }

    queue := list.New()
    queue.PushBack([2]interface{}{"0000", 0})
    visited := map[string]bool{"0000": true}

    for queue.Len() > 0 {
        front := queue.Remove(queue.Front()).([2]interface{})
        state := front[0].(string)
        steps := front[1].(int)

        if state == target {
            return steps
        }

        for i := 0; i < 4; i++ {
            digit := int(state[i] - '0')
            for _, move := range []int{-1, 1} {
                newDigit := (digit + move + 10) % 10
                newState := state[:i] + string('0'+newDigit) + state[i+1:]
                if !deadSet[newState] && !visited[newState] {
                    visited[newState] = true
                    queue.PushBack([2]interface{}{newState, steps + 1})
                }
            }
        }
    }
    return -1
}
```Go 解决方案反映了 Python BFS 方法，使用`list.List`作为队列和地图来跟踪访问过的状态。 Go 在处理队列元素和字符串数字操作时需要显式类型转换。
