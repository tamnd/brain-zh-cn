 ## 问题理解

 该问题需要解析和评估包含整数、变量、加法、减法、乘法和括号的数学表达式，同时还对某些变量应用替换映射。 本质上，我们正在构建一个符号代数引擎，根据标准算术规则简化表达式。 

输入由一个字符串组成`expression`可能包含整数、变量（字母字符串）、运算符（`+`,`-`,`*`) 和括号。 另外，还有两个数组`evalvars`和`evalints`提供特定变量的值； 任何不在该映射中的变量仍然是象征性的。 

输出是标准化形式的术语列表，其中每个术语由一个系数组成，后跟零个或多个按字典顺序相乘的变量。 术语首先按递减程度（变量数量）排序，然后按变量名称的字典顺序排序。 零系数被省略。 

主要限制因素包括：

 - 表达式长度最多为 250 个字符，这是适度的。 
- 评估图中最多有 100 个变量。 
- 保证算术表达式有效。 
- 中间结果适合 32 位整数。 

可能导致简单实施失败的边缘情况包括：

 - 嵌套括号，需要递归或基于堆栈的计算。 
- 符号表达式相乘，产生交叉项。 
- 零系数，必须省略。 
- 变量和术语的顺序，这会影响输出格式。 

## 方法

 强力方法是将表达式转换为标准中缀树，然后在替换已知变量的同时递归计算所有可能的组合，从而对表达式进行求值。 这种方法是正确的，但由于重复的符号乘法和需要手动管理多个项而速度较慢。 

最佳方法利用地图（字典）来表示术语。 每个项都存储为键值对，其中键是变量的排序元组，值是系数。 加法和减法通过系数求和来合并字典，而乘法则执行项的叉积。 使用带有分词器的递归可以正确处理括号。 评估后，术语按程度和词典顺序排序以产生最终输出。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 递归扩展所有符号项而不进行聚合，嵌套表达式速度较慢 |
 | 最佳| O(N * M^2) | O(N * M^2) | O(M)| 使用字典进行术语聚合； N 是标记的数量，M 是评估过程中生成的唯一术语的数量 |

 ## 算法演练

 1. **标记化：** 将表达式拆分为以空格分隔的标记，区分整数、变量、运算符和括号。 
2. **评价图构建：**构建字典映射`evalvars[i]`到`evalints[i]`用于不断替换。 
3. **递归解析函数：**实现一个递归`parse()`从左到右计算标记并尊重括号的函数。 
4. **术语表示：** 将每个术语表示为一对`(coefficient, tuple_of_sorted_variables)`。 对于常量，元组是空的。 
5. **加法和减法：** 通过对相同变量元组的系数求和来合并两个项映射。 
6. **乘法：** 计算两个操作数项的叉积，连接并排序变量元组，然后乘以系数。 
7. **括号处理：**遇到时`'('`，递归地计算子表达式，直到匹配`')'`。 
8. **格式化输出：** 评估后，过滤掉零系数项。 首先按程度降序对术语进行排序，然后按变量的字典顺序排序。 将每个术语转换为所需的字符串格式。 
9. **返回结果：** 返回代表简化术语的字符串的最终列表。 

**为什么有效：** 这种方法在项级别正确建模代数运算，确保相似项被组合并且乘法生成正确的交叉项。 递归和标记化自然地处理运算符优先级和括号，保证正确的简化。 

## Python 解决方案```python
from typing import List
from collections import defaultdict
import re

class Solution:
    def basicCalculatorIV(self, expression: str, evalvars: List[str], evalints: List[int]) -> List[str]:
        eval_map = dict(zip(evalvars, evalints))

        def tokenize(expr: str):
            return expr.replace('(', ' ( ').replace(')', ' ) ').split()

        def add_terms(a, b):
            res = defaultdict(int, a)
            for k, v in b.items():
                res[k] += v
            return res

        def sub_terms(a, b):
            res = defaultdict(int, a)
            for k, v in b.items():
                res[k] -= v
            return res

        def mul_terms(a, b):
            res = defaultdict(int)
            for k1, v1 in a.items():
                for k2, v2 in b.items():
                    new_key = tuple(sorted(k1 + k2))
                    res[new_key] += v1 * v2
            return res

        def parse(tokens):
            stack = []
            op_stack = []
            i = 0

            def apply_op():
                if not op_stack:
                    return
                op = op_stack.pop()
                b = stack.pop()
                a = stack.pop()
                if op == '+':
                    stack.append(add_terms(a, b))
                elif op == '-':
                    stack.append(sub_terms(a, b))
                elif op == '*':
                    stack.append(mul_terms(a, b))

            while i < len(tokens):
                token = tokens[i]
                if token.isdigit():
                    stack.append({(): int(token)})
                elif token.isalpha():
                    if token in eval_map:
                        stack.append({(): eval_map[token]})
                    else:
                        stack.append({(token,): 1})
                elif token == '(':
                    j = i
                    count = 0
                    for j in range(i, len(tokens)):
                        if tokens[j] == '(':
                            count += 1
                        elif tokens[j] == ')':
                            count -= 1
                            if count == 0:
                                break
                    stack.append(parse(tokens[i+1:j]))
                    i = j
                elif token in '+-*':
                    while op_stack and precedence(op_stack[-1]) >= precedence(token):
                        apply_op()
                    op_stack.append(token)
                i += 1

            while op_stack:
                apply_op()

            return stack[0]

        def precedence(op):
            if op == '*':
                return 2
            return 1

        tokens = tokenize(expression)
        terms = parse(tokens)

        def format_term(term):
            coeff, vars_tuple = term
            if vars_tuple:
                return f"{coeff}*" + "*".join(vars_tuple)
            return str(coeff)

        result = [(v, k) for k, v in terms.items() if v != 0]
        result.sort(key=lambda x: (-len(x[1]), x[1]))
        return [format_term(t) for t in result]
