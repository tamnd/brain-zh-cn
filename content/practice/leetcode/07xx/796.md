[LeetCode 第 796 题](https://leetcode.com/problems/rotate-string/)

 **难度：** 🟢简单
 **主题：** 字符串、字符串匹配

 ## 解决方案

 ## 问题理解

 该问题要求我们确定是否可以使用重复的左旋转将一个字符串转换为另一个字符串。 

单个移位操作会删除字符串的第一个字符并将其附加到末尾。 例如：

-`"abcde"`变成`"bcdea"`一班后
 -`"bcdea"`变成`"cdeab"`又轮班后

 我们有两个字符串，`s`和`goal`，我们必须返回`true`如果一定数量的旋转`s`可以生产`goal`。 否则，我们返回`false`。 

重要的细节是旋转保留了字符的相对顺序。 旋转仅改变字符串的起点。 这意味着生成的字符串必须仍然包含完全相同的循环排列的字符序列。 

限制非常小：

 -`1 <= s.length, goal.length <= 100`由于绳子很短，即使效率较低的方法仍然可以轻松通过。 然而，我们的目标是了解最优雅和最优的解决方案。 

一些边缘情况很重要：

 - 字符串可能有不同的长度。 在这种情况下，旋转是不可能的。 
- 字符串可能已经相等。 允许零旋转，所以答案应该是`true`。 
- 重复的字符可能会使简单的匹配变得棘手。 例如，`"aaab"`和`"abaa"`即使字符重复也是有效的旋转。 
- 非常小的琴弦，尤其是长度`1`，仍然必须正常工作。 

## 方法

 ### 蛮力方法

 蛮力解决方案模拟了每一个可能的旋转`s`。 

一个长度的字符串`n`正好有`n`明显的左旋转。 我们可以一次一步地重复旋转字符串，并将结果与`goal`。 

例如：

 - 开始于`"abcde"`- 旋转一次→`"bcdea"`- 再次旋转 →`"cdeab"`如果在任何点旋转的字符串等于`goal`，我们返回`true`。 

这种方法是正确的，因为它明确地检查每个可能的有效轮换。 如果没有匹配，则不会产生旋转`goal`。 

然而，重复构造旋转字符串效率很低。 每次轮换成本`O(n)`时间，因为字符串是不可变的，并且我们执行最多`n`轮换。 这导致`O(n²)`时间复杂度。 

### 最佳方法

 关键的见解是字符串的每个可能的旋转都显示为与其自身连接的字符串的子字符串。 

考虑：```
s = "abcde"
s + s = "abcdeabcde"
```Now look at all length-5 substrings:

 -`"abcde"`-`"bcdea"`-`"cdeab"`-`"deabc"`-`"eabcd"`这些正是所有可能的旋转`s`。 

因此：

 - 如果`goal`是一个旋转`s`， 然后`goal`必须出现在里面`s + s`- 长度也必须匹配，因为旋转永远不会改变字符串长度

 这给出了一个非常简洁有效的解决方案：

 1. 检查长度是否相等
 2. 检查是否`goal`是一个子串`s + s`## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 显式模拟每次旋转 |
 | 最佳| O(n) | O(n) | 在双字符串中使用子字符串搜索 |

 ## 算法演练

 ### 最优算法

 1.首先比较长度`s`和`goal`。 

旋转永远不会改变字符串的长度。 如果长度不同，则不可能`goal`是一个旋转`s`。 
2. 通过连接创建一个新字符串`s`与它自己。 

例如：```
s = "abcde"
doubled = "abcdeabcde"
```这个双倍字符串包含了每一个可能的旋转`s`作为连续的子字符串。 
3. 检查是否`goal`出现在双字符串内。 

如果是这样，则进行一些轮换`s`比赛`goal`。 
4. 返回子串检查的结果。 

### 为什么它有效

 字符串的每次旋转都对应于在字符循环排序中选择不同的起点。 将字符串与其自身连接会将所有循环起始位置公开为普通子字符串。 

如果`goal`发现里面`s + s`， 然后`goal`与这些循环移位之一完全匹配。 如果没有找到，则没有有效的旋转可以产生它。 

## Python 解决方案```python
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        if len(s) != len(goal):
            return False

        doubled = s + s

        return goal in doubled
```实现首先检查两个字符串是否具有相同的长度。 这是必要的，因为旋转会保留字符数。 

接下来，代码创建`doubled`，这就是简单的`s + s`。 这个组合字符串包含每个可能的旋转`s`。 

最后，表达`goal in doubled`执行子字符串搜索。 如果`goal`出现在双倍字符串内的任何位置，那么它必须对应于有效的旋转。 

该解决方案很简洁，因为 Python 提供了高效的内置子字符串检查。 

## 解决方案```go
package main

import "strings"

func rotateString(s string, goal string) bool {
    if len(s) != len(goal) {
        return false
    }

    doubled := s + s

    return strings.Contains(doubled, goal)
}
```Go 解决方案遵循与 Python 版本完全相同的逻辑。 

主要区别在于 Go 使用`strings.Contains`子字符串搜索功能。 Go 字符串是不可变的，就像 Python 字符串一样，因此连接会创建一个新字符串。 

这里没有关于整数溢出或 nil 处理的特别问题，因为输入大小非常小，并且根据问题约束，字符串始终有效。

 ## 边缘情况

 ### 不同长度的字符串

 如果`s`和`goal`具有不同的长度，旋转是不可能的，因为旋转永远不会添加或删除字符。 

例如：```
s = "abc"
goal = "abcd"
```仅检查子字符串关系的简单实现可能会意外地产生不正确的结果。 显式长度检查会立即防止这种情况发生。 

### 已经相等的字符串

 该问题允许“一定数量的移位”，包括零移位。 

例如：```
s = "abc"
goal = "abc"
```这应该返回`true`因为不需要旋转。 双字符串方法自然可以处理这种情况，因为`"abc"`显然包含在`"abcabc"`。 

### 重复字符

 重复的字符可能会导致简单的匹配逻辑混乱。 

例如：```
s = "aaab"
goal = "abaa"
```即使字符串包含重复项`'a'`字符，双倍字符串仍然正确地表示每个有效的循环旋转。 子字符串搜索可以安全、准确地处理重复模式。
