## 问题理解

 问题要求我们找到从源城市出发的最便宜的航班费用`src`到目的地城市`dst`同时最多采取`k`沿途停靠。 我们被给予`n`城市和航班列表，其中每个航班表示为`[from, to, price]`。 输入实际上是一个**加权有向图**，其中节点是城市，边是具有相关成本的航班。 目标是找到最小总边权重路径`src`到`dst`最多使用`k + 1`边缘（因为`k`停止意味着`k + 1`航班）。 

这些约束提供了有关输入规模的有用提示。`n`最多100个，航班数量最多`n * (n - 1) / 2`（完整的图表，没有重复）。 价格是正整数，因此我们不必处理负周期。`k`总是小于`n`，因此路径长度是有界的。 该问题保证同一对城市之间不存在多重边，并且`src != dst`。 

重要的边缘情况包括`k = 0`（仅限直飞航班）、不存在路径的断开图以及存在多条路径但最多只有路径的情况`k`允许停靠。 

## 方法

 ### 蛮力

 一个简单的方法是执行 **DFS**`src`，探索所有路径`dst`至多`k`停止。 每个递归调用都会跟踪剩余的停靠点和累计成本。 这种方法是正确的，因为它检查所有有效路径，但速度太慢。 在最坏的情况下，递归会探索长度可达的所有可能路径`k + 1`，导致指数时间复杂度，这是不可接受的`n = 100`。 

### 最佳方法

 关键的一点是要注意，**允许的最大航班数量是`k + 1`**。 这使得**贝尔曼-福特动态规划算法**成为理想的选择。 Bellman-Ford 允许我们通过重复松弛边来计算具有有限数量边的最短路径。 每次迭代都会松弛所有边一次，从而有效地考虑具有多一条边的路径。 通过执行`k + 1`迭代，我们确保所有路径最多`k`考虑停靠点。 这避免了探索不必要的路径，并在给定的约束下有效运行。 

另一种替代方案是**带有优先级队列的修改后的 Dijkstra 算法**，跟踪成本和剩余停靠点。 这是可行的，但正确实现可能会更复杂，因为我们必须仔细跟踪停止限制以避免不必要地重新访问节点。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力DFS | O(n^(k+1)) | O(n^(k+1)) | O(n) | 以递归、指数和不可行的方式探索所有路径 |
 | 贝尔曼-福特 DP | O((k+1) * 航班) | O(n) | 以停止为界的迭代边缘松弛，高效且简单 |
 | Dijkstra 设有停靠点 | O(航班 * log(n)) | O(n) | 使用优先级队列，谨慎处理停止约束 |

 ## 算法演练

 1. 初始化一个列表`dist`尺寸的`n`跟踪到达每个城市的最低成本。 放`dist[src] = 0`和所有其他的无穷大。 
2. 执行`k + 1`迭代（每次迭代对应于允许再飞行一次）。 在每次迭代中：

 1. 复制当前`dist`到`temp`以避免可能过早使用新放宽的边缘的就地更新。 
2. 对于每个航班`[from, to, price]`，检查该航班是否从`from`提高了达到目标的成本`to`。 如果`dist[from] + price < temp[to]`， 更新`temp[to]`。 
3.本次迭代放宽所有航班后，更新`dist`和`temp`。 
4. After`k + 1`迭代，`dist[dst]`保持达到的最低成本`dst`至多`k`停止。 如果仍为无穷大，则返回`-1`。 

**为什么有效：** Bellman-Ford 保证，之后`i`迭代，`dist[j]`包含到达节点的最小成本`j`最多使用`i`边缘。 通过执行`k + 1`迭代中，我们最多考虑所有路径`k`停止。 

## Python 解决方案```python
from typing import List

class Solution:
    def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
        INF = float('inf')
        dist = [INF] * n
        dist[src] = 0

        for i in range(k + 1):
            temp = dist.copy()
            for from_city, to_city, price in flights:
                if dist[from_city] != INF and dist[from_city] + price < temp[to_city]:
                    temp[to_city] = dist[from_city] + price
            dist = temp

        return -1 if dist[dst] == INF else dist[dst]
```此代码初始化距离，迭代`k + 1`次，使用副本仔细放松所有边缘以避免过早覆盖距离，并返回最终的最小成本或`-1`如果无法访问。 

## 解决方案```go
import "math"

func findCheapestPrice(n int, flights [][]int, src int, dst int, k int) int {
    INF := math.MaxInt32
    dist := make([]int, n)
    for i := 0; i < n; i++ {
        dist[i] = INF
    }
    dist[src] = 0

    for i := 0; i <= k; i++ {
        temp := make([]int, n)
        copy(temp, dist)
        for _, flight := range flights {
            from, to, price := flight[0], flight[1], flight[2]
            if dist[from] != INF && dist[from]+price < temp[to] {
                temp[to] = dist[from] + price
            }
        }
        dist = temp
    }

    if dist[dst] == INF {
        return -1
    }
    return dist[dst]
}
```Go 实现镜像了 Python 逻辑，使用`math.MaxInt32`对于无穷大和`copy`以避免过早更新。
