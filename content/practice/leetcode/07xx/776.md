 **难度：** 🟡 中等
 **主题：** 树、二叉搜索树、递归、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们根据目标值将二叉搜索树（BST）拆分为两个单独的子树。 具体来说，第一个子树应包含值小于或等于目标的所有节点，第二个子树应包含值严格大于目标的所有节点。 重要的是，每个结果子树的结构应尽可能保留原始的父子关系。 

输入由 BST 组成`root`和一个整数`target`。 输出是两个树根的数组：值 ≤ target 的子树的根和值 > target 的子树的根。 BST 属性至关重要，因为它确保对于任何节点，其左子树中的所有值都较小，而其右子树中的所有值都较大，从而允许高效的递归分裂。 

约束表明树最多有 50 个节点，节点值范围从 0 到 1000。较小的尺寸意味着即使简单的递归解决方案也是可行的，但 BST 结构表明递归或分而治之的方法将更干净、更高效。 

重要的边缘情况包括：

 - 目标小于所有节点，因此左子树为空。 
- 目标大于所有节点，因此右子树为空。 
- 树只包含一个节点。 
- 树不包含确切的目标值。 

## 方法

 暴力方法需要执行有序遍历来收集所有节点，根据目标对它们进行分区，然后从这两个集合中重建两个 BST。 这是可行的，因为 BST 的有序遍历会生成排序数组，但从排序数组重建 BST 需要仔细处理以维护树结构，并且工作量超出必要范围。 

最佳方法递归地利用 BST 属性。 对于任意节点：

 - 如果`node.val`≤ target，该节点属于左子树。 我们递归地分割它的右子节点，将分割的左部分作为该节点的新右子节点，并将该节点作为左子树根返回。 
- 如果`node.val`> target，该节点属于右子树。 我们递归地拆分其左子节点，将拆分的右侧部分附加为节点的新左子节点，并将该节点作为右子树根返回。 

这种方法可以有效地就地分割树，无需额外的存储或遍历。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 遍历树到数组，分割数组，重建两个BST |
 | 最佳| O(n) | O(h) | 使用 BST 属性进行递归就地分割，h = 树高 |

 ## 算法演练

 1. 从根节点开始。 检查其相对于目标的值。 
2.如果`root.val`≤ 目标：

 - 该节点属于左子树。 
- 递归地分割右孩子。 
- 附加该拆分的左侧结果作为当前节点的新右子节点。 
- 返回`[current node, right result]`作为分裂。 
3.如果`root.val`> 目标：

 - 该节点属于右子树。 
- 递归地分割左孩子。 
- 将该拆分的右侧结果附加为当前节点的新左子节点。 
- 返回`[left result, current node]`作为分裂。 
4. 基本情况：如果节点为空，则返回`[None, None]`。 

为什么它有效：递归保证在每个节点上，我们根据 BST 属性和目标正确放置它。 通过递归地分割子树和更新指针，我们维护每个子树的结构，同时确保所有值都正确分区。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional, List

class Solution:
    def splitBST(self, root: Optional[TreeNode], target: int) -> List[Optional[TreeNode]]:
        if not root:
            return [None, None]
        
        if root.val <= target:
            left_subtree, right_subtree = self.splitBST(root.right, target)
            root.right = left_subtree
            return [root, right_subtree]
        else:
            left_subtree, right_subtree = self.splitBST(root.left, target)
            root.left = right_subtree
            return [left_subtree, root]
```该实现直接遵循算法。 递归处理分裂，子级的重新分配确保原始 BST 结构得以维持。 如果节点为空，则返回两棵空树，正确处理空子树的边缘情况。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func splitBST(root *TreeNode, target int) []*TreeNode {
    if root == nil {
        return []*TreeNode{nil, nil}
    }

    if root.Val <= target {
        split := splitBST(root.Right, target)
        root.Right = split[0]
        return []*TreeNode{root, split[1]}
    } else {
        split := splitBST(root.Left, target)
        root.Left = split[1]
        return []*TreeNode{split[0], root}
    }
}
```Go 版本反映了 Python 逻辑。 我们将零节点作为基本情况处理，并使用切片返回两个根。 子重新分配可确保保留原始 BST 结构。 

## 工作示例

 示例1：`root = [4,2,6,1,3,5,7], target = 2`1. 从节点 4 (4 > 2) 开始 → 在左子树上递归。 
2. 节点 2 (2 ≤ 2) → 在右子节点（节点 3）上递归。 
3. 节点 3 (3 > 2) → 递归左子节点（无）→ 返回`[None, None]`。 
4. 节点 3 将左子节点附加为`None`→ 返回`[None, 3]`。 
5. 节点 2 将右子节点附加为`None`→ 返回`[2, 3]`。 
6. 节点 4 将左子节点附加为 3 → 最终分割：左`[2,1]`， 正确的`[4,3,6,null,null,5,7]`。 

示例2：`root = [1], target = 1`1. 节点 1 (1 ≤ 1) → 右子节点递归 (None) → 返回`[None, None]`。 
2. 将右孩子附加为 None → 返回`[1, None]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个节点在递归中被访问一次。 |
 | 空间| O(h) | 递归栈，其中h是树的高度。 对于倾斜树，最坏情况 h = n。 |

 递归解决方案非常高效，因为它只访问每个节点一次，并在每个步骤中执行恒定的工作。 空间使用由递归栈主导，与树的高度成正比。

 ## 边缘情况

 **目标小于所有节点**：如果目标小于最小节点，则左子树必须为空。 我们的递归正确返回`[None, root]`。 

**目标大于所有节点**：如果目标大于最大节点，则右子树必须为空。 我们的递归返回`[root, None]`，保留左子树中的所有节点。 

**单节点树**：当树只有一个节点时，递归基本情况会干净地处理它。 如果该节点≤target，则左子树包含该节点； 如果> target，则右子树包含该节点。 这可以防止任何空指针错误。
