[LeetCode 第 786 题](https://leetcode.com/problems/k-th-smallest-prime-fraction/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、二分查找、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们找到第 k 个最小的分数，该分数可以通过划分已排序数组的一个元素而形成`arr`由数组中稍后的另一个元素。 数组`arr`严格递增，开始于`1`，第一个之后的所有元素都是素数。 对于每对`(i, j)`在哪里`0 <= i < j < arr.length`, 分数`arr[i] / arr[j]`被考虑。 我们将返回所有这些分数的排序列表中第 k 个最小分数的分子和分母。 

输入是唯一整数的排序列表，至少有两个元素，最多有 1000 个元素。 输出是一对整数`[arr[i], arr[j]]`代表分数。 主要限制是`arr[0] == 1`，第一个之后的元素是素数，并且所有数字都是唯一的。 我们保证`1 <= k <= arr.length * (arr.length - 1) / 2`，所以 k 总是有效的。 

可能导致幼稚实现失败的边缘情况包括长度为 2 的最小数组，其中唯一的分数是`1 / prime`，以及最大的数组，其中所有分数的强力枚举可能会变得太慢（最多约 500,000 个分数）。 

## 方法

 蛮力方法很简单。 我们生成所有可能的分数`arr[i]/arr[j]`为了`i < j`，将它们存储在列表中，对它们进行排序，然后返回第 k 个最小的分数。 这是正确的，因为对所有分数进行排序可以保证正确的顺序。 然而，它的速度很慢，时间复杂度为 O(n² log n²)，空间复杂度为 O(n²)，对于长度为 1000 的数组来说效率很低。 

最佳方法利用最小堆（优先级队列）或二分搜索。 我们可以将分数视为矩阵形式，其中行是分子，列是分母。 使用最小堆，我们最初只在每列中存储尽可能小的分数，然后迭代地弹出最小的分数，同时将下一个分数推入同一列中。 这确保我们不会生成所有分数，从而将时间和空间复杂度分别降低到大约 O(k log n) 和 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n² log n²) | O(n² log n²) | O(n²) | 生成所有分数并排序 |
 | 最小堆优化 | O(k log n) | O(k log n) | O(n) | 使用堆跟踪每列的下一个最小分数 |

 ## 算法演练

 1. 初始化一个最小堆。 每个元素都是一个元组`(fraction value, numerator index i, denominator index j)`。 
2. 将每行的第一个分数推入堆中。 也就是推`(arr[i]/arr[-1], i, arr.length - 1)`为了`i`从`0`到`arr.length - 2`。 这确保我们从每行中最小的分母开始。 
3. 重复k-1次：从堆中弹出最小的分数。 让弹出的分数有索引`(i, j)`。 
4.如果`j-1 > i`，从同一行推送下一个分数`(arr[i]/arr[j-1], i, j-1)`到堆中。 这将在行中向左移动到下一个较大的分数。 
5. 在弹出 k-1 次之后，堆顶部的分数是第 k 个最小的分数。 返回`[arr[i], arr[j]]`。 

为什么有效：分数矩阵中的每一行都已排序，因为分子是固定的，分母是增加的。 堆确保全局最小的部分始终位于顶部。 通过仅将下一个分数推入同一行，我们保持了堆始终包含下一个最小的未见分数的不变量。 

## Python 解决方案```python
from typing import List
import heapq

class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        min_heap = []
        
        # Initialize heap with fractions with the largest denominator
        for i in range(n - 1):
            heapq.heappush(min_heap, (arr[i] / arr[-1], i, n - 1))
        
        # Pop the smallest fraction k-1 times
        for _ in range(k - 1):
            _, i, j = heapq.heappop(min_heap)
            if j - 1 > i:
                heapq.heappush(min_heap, (arr[i] / arr[j - 1], i, j - 1))
        
        # The top of heap is the k-th smallest fraction
        _, i, j = heapq.heappop(min_heap)
        return [arr[i], arr[j]]
```在此实现中，我们使用具有最大分母的分数来初始化堆。 这确保堆最初包含最小的部分。 每次弹出都会给出下一个最小的分数，并且我们从同一分子行中推送下一个分数（如果存在）。 最后，第 k 次弹出给出了答案。 

## 解决方案```go
package main

import (
    "container/heap"
)

type Fraction struct {
    value float64
    i     int
    j     int
}

type MinHeap []Fraction

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].value < h[j].value }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeap) Push(x interface{}) {
    *h = append(*h, x.(Fraction))
}

func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

func kthSmallestPrimeFraction(arr []int, k int) []int {
    n := len(arr)
    h := &MinHeap{}
    heap.Init(h)
    
    for i := 0; i < n-1; i++ {
        heap.Push(h, Fraction{value: float64(arr[i]) / float64(arr[n-1]), i: i, j: n - 1})
    }
    
    for t := 0; t < k-1; t++ {
        f := heap.Pop(h).(Fraction)
        if f.j-1 > f.i {
            heap.Push(h, Fraction{value: float64(arr[f.i]) / float64(arr[f.j-1]), i: f.i, j: f.j - 1})
        }
    }
    
    f := heap.Pop(h).(Fraction)
    return []int{arr[f.i], arr[f.j]}
}
```Go 特定的考虑因素包括使用分数结构并实现`heap.Interface`。 Float64 用于分数比较。 

## 工作示例

 **示例 1：arr = [1,2,3,5], k = 3**

 初始堆：[(1/5,0,3),(2/5,1,3),(3/5,2,3)]

 第一次弹出：1/5（压入 1/3）：堆 = [(1/3,0,2),(2/5,1,3),(3/5,2,3)]

 第二次弹出：1/3（压入 1/2）：堆 = [(1/2,0,1),(2/5,1,3),(3/5,2,3)]

 第三次弹出：2/5（第 k 个分数）：返回 [2,5]

 **示例 2：arr = [1,7]，k = 1**

 初始堆：[(1/7,0,1)]

 第一次弹出：1/7：返回 [1,7]

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(k log n) | O(k log n) | 每个堆操作都是 O(log n)，我们执行 k 次弹出/推送 |
 | 空间| O(n) | 堆一次最多存储 n 个分数 |

 复杂性是有效的，因为我们避免枚举所有 O(n²) 分数。
