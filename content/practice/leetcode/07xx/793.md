[LeetCode 第 793 题](https://leetcode.com/problems/preimage-size-of-factorial-zeroes-function/)

 **难度：** 🔴难
 **主题：** 数学、二分查找

 ## 解决方案

 ## 问题理解

 这道题要求我们确定有多少个非负整数`x`存在使得阶乘`x`完全以`k`尾随零。 功能`f(x)`计算尾随零`x!`。 例如，`f(3) = 0`因为`3! = 6`没有尾随零，并且`f(11) = 2`因为`11! = 39916800`有两个尾随零。 

输入`k`是一个非负整数，表示我们要匹配的尾随零的确切数量。 输出也是一个整数，表示值的数量`x`为此`f(x) = k`。 约束条件告诉我们`k`可以大到`10^9`，这立即排除了尝试直接计算阶乘或迭代所有的简单方法`x`达到某个上限，因为阶乘增长极其迅速。 

重要的边缘情况包括小值，例如`k = 0`，其中应包括阶乘`0`通过`4`，和值`k`其中没有整数`x`可以精确生产`k`尾随零，例如`k = 5`。 问题保证`k >= 0`，因此不需要处理负输入。 

## 方法

 蛮力方法在概念上很简单：对于每个非负整数`x`, 计算`x!`并计算尾随零。 数数有多少个`x`满足`f(x) = k`。 这种方法是正确的，因为它显式检查属性的每个整数。 然而，这是不可行的，因为阶乘的增长速度比指数增长得快，并且计算它们的量很大`x`会很快溢出内存和处理能力。 

最佳方法依赖于数学洞察力，即阶乘中的尾随零来自于`5`（与偶数配对）。 因此，尾随零的数量`x!`可以使用以下方法有效计算：```
f(x) = x//5 + x//25 + x//125 + ...
```该公式计算 5 的因数个数`x!`。 给定这个函数，关键的观察结果是`f(x)`是单调非递减的`x`增加。 因此，我们可以使用二分查找来找到最小的`x`至少有`k`尾随零和最小的`x`超过`k`尾随零。 这两个界限的差给出了整数的数量`x`为此`f(x) = k`。 结果是`0`或者`5`因为产生相同数量尾随零的每个数字块恰好有五个连续整数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(x * log x) | O(x * log x) | O(1) | O(1) | 迭代计算每个的阶乘`x`直到`f(x) = k`，对于大的情况不可行`k`|
 | 最佳| O(log(k) * log(k)) | O(log(k) * log(k)) | O(1) | O(1) | 二分查找结束`x`使用尾随零公式，高效且可扩展|

 ## 算法演练

 1. 定义辅助函数`trailingZeroes(x)`它计算尾随零的数量`x!`使用公式`x//5 + x//25 + x//125 ...`。 其运行时间为 O(log x)。 
2.定义一个二分查找函数来找到最小的`x`这样`f(x) >= k`。 初始化`low = 0`和`high = 5 * k`因为`f(x)`每 5 的倍数大约增加 1。 
3.同时`low < high`, 计算`mid = (low + high) // 2`。 如果`trailingZeroes(mid) < k`， 放`low = mid + 1`。 否则，设置`high = mid`。 在最后，`low`将是第一个`x`和`f(x) >= k`。 
4. 找到最小的`x`和`f(x) = k`和最小的`x`和`f(x) = k + 1`。 这两个值之间的差异给出了`x`恰好与`k`尾随零。 这将是 0（如果`k`是不可能的）或 5（如果存在有效的`x`）。 

**为什么有效：** 功能`f(x)`是单调递增的，并且具有逐步行为，其中每个步骤恰好跨越五个连续整数。 通过使用二分查找，我们找到了下界`k`和`k + 1`，差异捕获了该步骤中的所有整数，这保证了正确性。 

## Python 解决方案```python
class Solution:
    def preimageSizeFZF(self, k: int) -> int:
        def trailingZeroes(x: int) -> int:
            count = 0
            while x > 0:
                x //= 5
                count += x
            return count
        
        def left_bound(target: int) -> int:
            low, high = 0, 5 * target
            while low < high:
                mid = (low + high) // 2
                if trailingZeroes(mid) < target:
                    low = mid + 1
                else:
                    high = mid
            return low
        
        return left_bound(k + 1) - left_bound(k)
```实现定义`trailingZeroes(x)`有效地计算 5 的因数。`left_bound(target)`使用二分查找来查找至少具有以下值的最小整数`target`尾随零。 之间的区别`left_bound(k + 1)`和`left_bound(k)`给出恰好符合的整数个数`k`尾随零，与算法一致。 

## 解决方案```go
func preimageSizeFZF(k int) int {
    trailingZeroes := func(x int) int {
        count := 0
        for x > 0 {
            x /= 5
            count += x
        }
        return count
    }

    leftBound := func(target int) int {
        low, high := 0, 5*target
        for low < high {
            mid := (low + high) / 2
            if trailingZeroes(mid) < target {
                low = mid + 1
            } else {
                high = mid
            }
        }
        return low
    }

    return leftBound(k+1) - leftBound(k)
}
```Go 的实现与 Python 非常相似，使用闭包`trailingZeroes`和`leftBound`。 整数除法自然地处理因子计数。 不需要对空或 nil 切片进行特殊处理，因为我们只处理整数。 

## 工作示例

 **示例 1：k = 0**`left_bound(0) = 0`,`left_bound(1) = 5`→ 差异 = 5

 **示例 2：k = 5**`left_bound(5) = 25`,`left_bound(6) = 30`→ 差异 = 5 → 实际上`f(x) = 5`不可能，检查函数：它返回 0，因为没有精确的 k 与单个步骤匹配。 

**示例 3：k = 3**`left_bound(3) = 15`,`left_bound(4) = 20`→ 差异 = 5

 状态表为`k = 3`:

 | x| f(x) | f(x) |
 | --- | --- |
 | 15 | 15 3 |
 | 16 | 16 3 |
 | 17 | 17 3 |
 | 18 | 18 3 |
 | 19 | 19 3 |
 | 20 | 4 |

 f(x) = 3 的 x 的个数为 5，与算法一致。

 | 测量 | 复杂性 | 说明|

 | 时间 | O(log k * log k) | O(log k * log k) | 二分查找需要 O(log (5k)) 次迭代； 每次迭代都以 O(log x) | 计算 TrailingZeroes
