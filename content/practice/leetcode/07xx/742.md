[LeetCode 742 题](https://leetcode.com/problems/closest-leaf-in-a-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们找到距离给定目标节点**最近的叶节点**`k`在二叉树中。 输入是`root`二叉树的每个节点都有一个**唯一的整数值**。 叶节点定义为没有子节点的任何节点。 输出是从目标节点可以到达的叶子节点的**值**`k`通过遍历最少数量的边。 

保证输入树至少有一个节点（`1 <= number of nodes <= 1000`），所有值都是唯一的（`1 <= Node.val <= 1000`) 和目标节点`k`存在于树中。 这保证了我们不需要处理空树或丢失的目标值。 

重要的边缘情况包括树仅由根节点组成，在这种情况下，根本身是叶子并且是最接近自身的叶子。 另一个棘手的情况是，最近的叶子**不在以目标节点为根的子树**中，而是在树的更高位置（需要遍历父节点）。 

## 方法

 ### 蛮力方法

 一个简单的方法是首先定位目标节点`k`，然后对其子树中的每个叶子执行广度优先搜索（BFS）或深度优先搜索（DFS）以找到最接近的叶子。 如果最近的叶子恰好位于目标节点的子树之外（即树的上方），我们将需要探索**从目标节点的每个祖先到叶子的所有路径**，这将需要额外的簿记。 这是可能的，但效率低下，特别是当树很大且不平衡时，因为我们可能会探索许多不必要的路径。 

### 最佳方法的关键见解

 如果我们**允许从一个节点遍历到它的父节点**以及它的子节点，那么问题就会变得简单得多。 如果我们将树转换为**无向图**，其中每个节点都连接到其子节点和父节点，则找到距离目标节点最近的叶子相当于**找到从目标节点到该图中的任何叶子的最短路径**。 然后我们可以从目标节点开始使用 **BFS*​​ 来保证我们以最少的步骤找到最近的叶子。 

这种方法在同一统一框架中处理目标子树中的叶子和子树外部的叶子。 

### 比较表

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 搜索从目标到叶子的所有路径； 不平衡树的效率低下 |
 | 最佳| O(n) | O(n) | 将树转换为图并从目标节点使用 BFS |

 ## 算法演练

 1. **映射父指针：** 使用 DFS 遍历树并存储从每个节点到其父节点的映射。 这允许在 BFS 期间从子级遍历到父级。 
2. **识别叶节点：** 如果一个节点没有子节点，则该节点是叶节点。 在 BFS 期间，如果一个节点没有子节点，我们立即返回它的值。 
3. **从目标节点启动 BFS：** 使用父映射，将目标节点排入队列。 使用集合来跟踪访问过的节点以防止循环。 
4. **探索邻居：** 对于从 BFS 出列的每个节点，考虑其左子节点、右子节点和父节点（如果它们存在且未被访问）。 将它们排队以进行进一步探索。 
5. **返回第一个叶子：** BFS 确保遇到的第一个叶子是最近的，因为 BFS 按照距目标距离递增的顺序探索节点。 

**为什么有效：** BFS 保证未加权图中的最短路径。 通过在遍历中包含父级，我们可以正确地考虑更接近但不在目标子树中的叶子。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def findClosestLeaf(self, root: Optional[TreeNode], k: int) -> int:
        parent = {}

        # Step 1: DFS to map parents and find target node
        def dfs(node, par=None):
            if not node:
                return None
            if par:
                parent[node] = par
            if node.val == k:
                target_node[0] = node
            dfs(node.left, node)
            dfs(node.right, node)

        target_node = [None]
        dfs(root)

        # Step 2: BFS from target node
        queue = deque([target_node[0]])
        visited = set([target_node[0]])

        while queue:
            node = queue.popleft()
            # If leaf node, return its value
            if not node.left and not node.right:
                return node.val
            for neighbor in (node.left, node.right, parent.get(node)):
                if neighbor and neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
```**实现演练：** 首先，DFS 将每个节点映射到其父节点并识别目标节点。 然后BFS逐层探索节点，必要时使用父映射向上移动。 BFS 中遇到的第一个叶子会立即返回。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func findClosestLeaf(root *TreeNode, k int) int {
    parent := make(map[*TreeNode]*TreeNode)
    var targetNode *TreeNode

    // DFS to map parents and locate target node
    var dfs func(node, par *TreeNode)
    dfs = func(node, par *TreeNode) {
        if node == nil {
            return
        }
        if par != nil {
            parent[node] = par
        }
        if node.Val == k {
            targetNode = node
        }
        dfs(node.Left, node)
        dfs(node.Right, node)
    }
    dfs(root, nil)

    queue := []*TreeNode{targetNode}
    visited := make(map[*TreeNode]bool)
    visited[targetNode] = true

    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        if node.Left == nil && node.Right == nil {
            return node.Val
        }
        neighbors := []*TreeNode{node.Left, node.Right, parent[node]}
        for _, neighbor := range neighbors {
            if neighbor != nil && !visited[neighbor] {
                visited[neighbor] = true
                queue = append(queue, neighbor)
            }
        }
    }
    return -1
}
```**Go 特定注释：** Go 使用`nil`检查而不是Python的`None`。 切片用作队列，地图跟踪访问过的节点。 逻辑反映了 Python 版本。 

## 工作示例

 **示例 1：** 根 = [1,3,2], k = 1

 DFS 映射父级：3→1、2→1。 BFS从1开始，邻居是3和2。3和2都是叶子。 BFS 返回 2（或 3），因为返回了第一个出队的叶子。 

**示例2：** root = [1]，k = 1

 DFS 没有映射父母。 BFS 从 1 开始，它本身就是一片叶子。 立即返回 1。 

**示例 3：** root = [1,2,3,4,null,null,null,5,null,6], k = 2

 DFS 映射父母。 来自 2 的 BFS：邻居是 1（父级）和 4（左子级）。 BFS 探索 4，然后是 5 和 6。BFS 接下来探索 1，然后是 3，这是一个叶子。 返回 3 作为最近的叶子。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点在 DFS 中被访问一次，在 BFS 中被访问一次，n 是节点数 |
 | 空间| O(n) | 最坏情况下父映射和 BFS 队列使用 O(n) 空间 |

 因为我们从概念上将树转换为无向图，所以 BFS 确保我们不会进行不必要的遍历，从而使算法在时间和空间上保持线性。
