[LeetCode 第 788 题](https://leetcode.com/problems/rotated-digits/)

 **难度：** 🟡 中等
 **主题：** 数学、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算给定范围内**好整数**的数量`[1, n]`。 如果一个整数的每个数字在旋转 180 度时形成另一个有效数字，并且结果数字与原始数字**不同**，则该整数被认为是好的。 数字`0`,`1`， 和`8`旋转时保持不变，而`2`和`5`交换，并且`6`和`9`交换。 任何包含数字的数字`3`,`4`， 或者`7`旋转后无效。 

输入`n`是一个整数，输出应该是好整数的总数`[1, n]`。 约束表明`1 <= n <= 10^4`，这意味着迭代所有数字的解决方案是可行的，但可能不是最有效的。 要考虑的边缘情况包括较小的值`n`（喜欢`1`或者`2`），有效但旋转后保持不变的数字（例如`1`,`8`,`10`)，以及包含无效数字的数字，例如`3`或者`7`。 

## 方法

 **暴力方法**很简单：迭代所有数字`1`到`n`，将每个数字转换为其旋转版本，并检查它是否有效且与原始数字不同。 这适用于给定的约束，因为`n`至多是`10^4`，但它不能很好地扩展，如果`n`更大。 

更优化解决方案的**关键见解**是认识到可以使用**数字动态规划**或**分类计数**来解决问题。 每个数字都可以归类为**不变**（`0`,`1`,`8`）， **好的** （`2`,`5`,`6`,`9`)，或**无效** (`3`,`4`,`7`）。 如果一个数字包含**至少一个有效数字**并且没有无效数字，则该数字是良好的。 我们可以迭代数字并应用此分类，而无需显式生成旋转数字。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * log n) | O(n * log n) | O(log n) | 将每个数字转换为字符串，检查每个数字，统计好数字 |
 | 最佳| O(n * d) | O(1) | O(1) | 迭代数字，对数字进行分类，计算是否包含至少一个好数字 |

 ## 算法演练

 1.初始化一个计数器`count`到 0。这将保存好数字的总数。 
2. 定义一组**好数字**（`2`,`5`,`6`,`9`) 和一组**有效数字** (`0`,`1`,`2`,`5`,`6`,`8`,`9`）。 
3. 迭代每个整数`num`从`1`到`n`。 对于每个数字：

 1. 转换`num`到一个字符串并检查每个数字。 
2. 如果任何数字**无效**（`3`,`4`,`7`），跳过这个数字。 
3. 跟踪号码是否包含**至少一个有效数字**。 
4. 如果是，则增加`count`。 
4. 返回`count`迭代完成后。 

**为什么有效：** 每个数字要么是无效的，要么是不变的，要么是好的。 通过迭代所有数字、检查有效性并确保至少有一个好数字，我们可以精确地计算出满足问题的好整数定义的数字。 

## Python 解决方案```python
class Solution:
    def rotatedDigits(self, n: int) -> int:
        good_digits = {'2', '5', '6', '9'}
        valid_digits = {'0', '1', '2', '5', '6', '8', '9'}
        count = 0
        
        for num in range(1, n + 1):
            num_str = str(num)
            is_good = False
            for ch in num_str:
                if ch not in valid_digits:
                    is_good = False
                    break
                if ch in good_digits:
                    is_good = True
            if is_good:
                count += 1
                
        return count
```此实现会迭代来自的每个数字`1`到`n`。 对于每个数字，它检查每个数字以查看其是否有效。 如果遇到无效数字，则会跳过该数字。 否则，它会检查是否至少有一位数字合格。 如果是这样，它就会增加计数器。 

## 解决方案```go
func rotatedDigits(n int) int {
    goodDigits := map[rune]bool{'2': true, '5': true, '6': true, '9': true}
    validDigits := map[rune]bool{'0': true, '1': true, '2': true, '5': true, '6': true, '8': true, '9': true}
    
    count := 0
    
    for num := 1; num <= n; num++ {
        numStr := []rune(fmt.Sprintf("%d", num))
        isGood := false
        valid := true
        for _, ch := range numStr {
            if !validDigits[ch] {
                valid = false
                break
            }
            if goodDigits[ch] {
                isGood = true
            }
        }
        if valid && isGood {
            count++
        }
    }
    
    return count
}
```在 Go 中，我们通过将数字转换为符文切片来迭代每个数字来处理数字。 我们使用两个映射来表示良好和有效的数字。 逻辑反映了 Python 版本。 由于 Go 没有字符串的隐式布尔短路，因此我们显式跟踪`valid`和`isGood`。

 ## 边缘情况

 1. **最小的数字（`n = 1`)**：这很重要，因为答案是 0，测试算法是否错误地包含未更改的数字。 该解决方案通过要求至少一个好数字来处理这个问题。 
2. **包含无效数字的数字（`3`,`4`,`7`)**：必须跳过这些。 当检测到无效数字时，该算法会显式中断循环，从而防止错误计数。 
3. **所有数字不变的数字（`0`,`1`,`8`)**：这些数字有效但不好。 如果至少有一位好数字，该实现仅增加计数，确保排除未更改的数字。 

这种方法保证了所有边缘场景的正确性，同时对问题约束保持高效。
