[LeetCode 757 题](https://leetcode.com/problems/set-intersection-size-at-least-two/)

 **难度：** 🔴难
 **主题：** 数组、贪婪、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们找到一组整数的最小大小，`nums`，这样每个给定的区间`[starti, endi]`包含**至少两个整数`nums`**。 每个区间都表示为一个闭区间，意味着之间的所有整数`starti`和`endi`包含属于该区间。 目标是构建`nums`这样，所有区间都满足此条件，但元素数量尽可能最少。 

输入是一个二维数组`intervals`， 在哪里`1 <= intervals.length <= 3000`并且每个区间都有`0 <= starti < endi <= 10^8`。 这些限制意味着，由于整数的潜在范围和间隔的数量很大，枚举所有可能集合的简单方法是不可行的。 边缘情况包括完全重叠的区间、几乎不接触的区间以及长度最小的区间（大小为 2，要求两个数字都在集合中）。 

输出是一个整数，表示所需的最小整数数`nums`满足“每个区间至少有两个整数”条件。 

## 方法

 **暴力方法**会尝试尝试所有间隔的并集内所有可能的整数组合，检查哪个组合满足每个间隔至少有两个整数的条件。 虽然这保证了正确性，但可能的集合数量随着间隔的大小而组合增长，使得在给定约束的情况下在计算上不可行。 

最佳解决方案的**关键见解**是使用**贪婪方法进行排序**。 对于具有相同结束点的区间，我们可以首先按其终点按升序对区间进行排序，其次按其起点按降序排列。 这确保我们从左到右处理间隔，从而最大限度地重用先前选择的数字。 如果现有数字尚未满足间隔，我们总是选择**每个间隔中的最后两个最大数字**。 通过仔细跟踪之前间隔中包含的两个最大数字，我们可以最大限度地减少额外的选择。

 ## 算法演练

 1. **对间隔进行排序**：按照间隔的末尾升序对间隔进行排序。 如果两个间隔具有相同的结束位置，则按开始位置降序排序。 这确保先处理较早结束的间隔，从而最大限度地提高先前添加的数字满足未来间隔的机会。 
2. **初始化两个跟踪器**：维护两个变量，`first`和`second`，跟踪当前包含集合中的两个最大数字。 将它们初始化为`-1`和`-1`因为还没有包含任何数字。 
3. **迭代间隔**：对于每个间隔`[start, end]`，检查当前两个最大的数中有多少落在这个区间内。 
4. **决定要添加的数字**：

 - 如果两者都`first`和`second`处于区间内，不执行任何操作。 
- 如果只是`second`是在区间内，则添加`end`到集合并更新`first`和`second`。 
- 如果两者都不在区间内，则添加`end-1`和`end`到集合并更新`first`和`second`。 
5. **返回集合大小**：保留添加到的总数的运行计数`nums`。 最后，该计数是包含集的最小可能大小。 

**为什么有效**：通过始终（贪婪地）选择间隔内的最大数字，我们可以最大化未来间隔的覆盖范围，因为间隔是按末尾排序的。 这保证了算法添加最少的必要数字，同时保持每个处理的间隔至少有两个数字的不变性。 

## Python 解决方案```python
from typing import List

class Solution:
    def intersectionSizeTwo(self, intervals: List[List[int]]) -> int:
        intervals.sort(key=lambda x: (x[1], -x[0]))
        first, second = -1, -1
        count = 0
        
        for start, end in intervals:
            if start <= first:
                continue
            elif start <= second:
                first = second
                second = end
                count += 1
            else:
                first = end - 1
                second = end
                count += 2
        
        return count
```此实现首先对间隔进行排序，并初始化添加的最后两个数字的跟踪器。 它迭代每个间隔，检查当前的覆盖范围`first`和`second`价值观。 根据重叠情况，它决定添加多少个新数字。 这确保了最少的添加，同时满足“每个间隔至少两个”条件。 

## 解决方案```go
import "sort"

func intersectionSizeTwo(intervals [][]int) int {
    sort.Slice(intervals, func(i, j int) bool {
        if intervals[i][1] == intervals[j][1] {
            return intervals[i][0] > intervals[j][0]
        }
        return intervals[i][1] < intervals[j][1]
    })
    
    first, second := -1, -1
    count := 0
    
    for _, interval := range intervals {
        start, end := interval[0], interval[1]
        if start <= first {
            continue
        } else if start <= second {
            first = second
            second = end
            count++
        } else {
            first = end - 1
            second = end
            count += 2
        }
    }
    
    return count
}
```Go 解决方案反映了 Python 实现。 排序用途`sort.Slice`带有自定义比较器。 主要区别在于 Go 语法，例如`for`循环切片和元组拆包替换。
