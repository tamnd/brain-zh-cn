 ## 问题理解

 滑动拼图问题提出了`2 x 3`包含五个编号的图块的棋盘`1`到`5`和一个空格表示为`0`。 目标是将电路板转变为已解决的配置`[[1,2,3],[4,5,0]]`使用最少的移动次数，其中移动包括交换`0`与其任何相邻的图块（上、下、左、右）。 输入`board`是表示图块当前配置的二维列表。 预期输出是一个整数，表示达到已解决状态所需的最小移动次数，或者`-1`如果不可能的话。 

问题约束表明电路板很小且尺寸固定（`2x3`）并且所有值都是唯一的，因此可能的状态数量是有限的（`6! = 720`）。 边缘情况包括已经解决的板、具有相反顺序的图块的板以及由于奇偶校验约束（例如无法解决的排列）而无法解决的板。 

了解这些约束使我们能够有效地利用图搜索技术，因为我们可以将每个板配置视为一个节点并作为边缘移动。 

## 方法

 暴力方法涉及从初始棋盘状态生成所有可能的移动序列，直到我们达到已解决的状态或耗尽所有可能性。 这可以通过递归回溯来完成。 虽然这种方法在理论上是正确的，但效率很低，因为它探索了许多冗余路径，并且可以多次重新访问以前看到的板配置，导致指数时间复杂度。 

最佳方法是将谜题建模为一个图表，其中每个节点代表一个棋盘配置，边代表有效的移动`0`。 广度优先搜索（BFS）是合适的，因为我们正在搜索最短的移动序列。 BFS 保证我们第一次达到已解决状态时，我们已经使用最少的移动次数完成了这一任务。 我们还使用哈希集来跟踪访问的状态，防止循环和冗余计算。 一个关键的见解是将 2D 板序列化为字符串或元组，以便可以轻松比较状态并将其存储在集合中。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(6!) | O(6!) | 递归地探索所有可能的移动序列，多次重新访问状态。 |
 | 最优 BFS | O(6!) | O(6!) | 状态图上的 BFS 保证最少的移动； 访问集可防止冗余探索。 |

 ## 算法演练

 1. **序列化板子**：转换`2x3`板成字符串，例如，`'123450'`，以便更轻松地跟踪访问过的状态并比较主板。 
2. **定义邻接图**：根据每个索引预先计算映射`0`在字符串中添加到它可以交换的索引。 对于一个`2x3`板，映射为：```
0 -> [1, 3]
1 -> [0, 2, 4]
2 -> [1, 5]
3 -> [0, 4]
4 -> [1, 3, 5]
5 -> [2, 4]
```3. **初始化 BFS 队列**：使用初始序列化板和移动计数开始 BFS`0`。 使用一组跟踪访问过的状态以避免再次访问。 
4. **BFS遍历**：当队列不为空时，将最前面的元素出队。 如果与目标匹配`'123450'`，返回当前的移动计数。 否则，对于每个有效交换`0`，生成新的棋盘状态，如果没有被访问过，则将其添加到队列中并标记为已访问。 
5. **如果无法解决则返回-1**：如果 BFS 完成但未达到已解决状态，则返回`-1`表明该谜题无解。 

**为什么有效：** BFS 保证最小移动次数，因为它深度探索所有状态`d`在进入深度之前`d+1`。 通过标记访问过的状态，它确保每个状态仅处理一次，避免无限循环和冗余计算。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def slidingPuzzle(self, board: List[List[int]]) -> int:
        start = ''.join(str(num) for row in board for num in row)
        target = '123450'
        neighbors = {
            0: [1, 3],
            1: [0, 2, 4],
            2: [1, 5],
            3: [0, 4],
            4: [1, 3, 5],
            5: [2, 4]
        }

        queue = deque([(start, 0)])
        visited = set([start])

        while queue:
            state, moves = queue.popleft()
            if state == target:
                return moves

            zero_index = state.index('0')
            for swap_index in neighbors[zero_index]:
                new_state = list(state)
                new_state[zero_index], new_state[swap_index] = new_state[swap_index], new_state[zero_index]
                new_state_str = ''.join(new_state)
                if new_state_str not in visited:
                    visited.add(new_state_str)
                    queue.append((new_state_str, moves + 1))

        return -1
```该实现首先将板转换为字符串以便于状态比较。 BFS 队列保存元组`(state, moves)`用于跟踪当前棋盘和所采取的步数。 对于每个出队状态，它找到的位置`0`，生成所有可能的有效移动，并将尚未访问的新状态放入队列。 BFS通过层序遍历保证最短路径。 

## 解决方案```go
package main

import (
    "container/list"
    "strconv"
)

func slidingPuzzle(board [][]int) int {
    start := ""
    for i := 0; i < 2; i++ {
        for j := 0; j < 3; j++ {
            start += strconv.Itoa(board[i][j])
        }
    }
    target := "123450"
    neighbors := [][]int{
        {1, 3},
        {0, 2, 4},
        {1, 5},
        {0, 4},
        {1, 3, 5},
        {2, 4},
    }

    visited := map[string]bool{start: true}
    queue := list.New()
    queue.PushBack([2]interface{}{start, 0})

    for queue.Len() > 0 {
        elem := queue.Front()
        queue.Remove(elem)
        state := elem.Value.([2]interface{})[0].(string)
        moves := elem.Value.([2]interface{})[1].(int)

        if state == target {
            return moves
        }

        zeroIndex := -1
        for i, ch := range state {
            if ch == '0' {
                zeroIndex = i
                break
            }
        }

        for _, swapIndex := range neighbors[zeroIndex] {
            newState := []byte(state)
            newState[zeroIndex], newState[swapIndex] = newState[swapIndex], newState[zeroIndex]
            newStateStr := string(newState)
            if !visited[newStateStr] {
                visited[newStateStr] = true
                queue.PushBack([2]interface{}{newStateStr, moves + 1})
            }
        }
    }
    return -1
}
```Go 实现镜像了 Python 版本，使用`container/list`用于 BFS 队列和访问过的状态的地图。 它会仔细地将棋盘转换为字符串并返回，因为 Go 没有 Python 的动态列表/字符串行为。 

## 工作示例

 **示例1：`[[1,2,3],[4,0,5]]`**

 | ---| ---| ---| ---|
 |`'123405'`| 0 | 4 |`'103425'`,`'123045'`,`'123450'`|
 |`'123450'`| 1 | - | 已解决 |

 输出：`1`。 

**示例2：`[[1,2,3],[5,4,0]]`**

 BFS 探索了所有 720 种可能的状态，但从未达到`'123450'`。 输出：`-1`。 

**示例3：`[[4,1,2],[5,0,3]]`**

 BFS 找到一条长度为 的路径`5`通过各州：`'412503' -> '012453' -> '412053' -> '102453' -> '120453' -> '123450'`输出：`5`。

 | 测量 | 复杂性 | 说明|
