 **难度：** 🔴难
 **主题：** 链表、堆栈、设计、双向链表、有序集

 ## 解决方案

 ## 问题理解

 问题要求我们设计一个栈数据结构，`MaxStack`，其行为类似于普通堆栈，具有用于有效访问和删除最大元素的附加操作。 具体来说，除了标准的堆栈操作之外`push`,`pop`， 和`top`，我们需要实施`peekMax`，它返回最大元素而不删除它，并且`popMax`，它删除最上面出现的最大元素。 输入是压入堆栈的整数序列，输出是各种堆栈操作的结果。 

约束表明每个整数可以介于`-10^7`和`10^7`并且最多可以有`10^5`运营。 这些保证确保`pop`,`top`,`peekMax`， 和`popMax`永远不会在空堆栈上调用，因此我们不需要处理空堆栈异常。 重要的边缘情况包括多次出现最大元素、负值和序列，其中`popMax`被反复调用。 

挑战在于如何有效地实施这些操作。 尽管`top`必须是 O(1)，`push`,`pop`,`peekMax`， 和`popMax`应尽可能接近 O(log n)。 简单的解决方案可能无法满足这些要求。 

## 方法

 暴力方法是使用标准堆栈并通过每次扫描堆栈来计算最大值`peekMax`或者`popMax`被称为。 这保证了正确性，但速度太慢：`peekMax`和`popMax`会变成 O(n)，这是不可接受的`10^5`运营。 

最佳解决方案使用**双向链表**来表示堆栈，并使用**平衡树或排序列表**来按值跟踪元素。 这允许恒定时间操作`top`和对数时间运算`push`,`pop`,`peekMax`， 和`popMax`。 关键的见解是维护排序结构中每个值对其链表中节点的引用，以便我们可以有效地删除它们。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | peekMax/popMax 为 O(n)，push/pop/top 为 O(1) | O(n) | 简单堆栈，线性扫描最大 |
 | 最佳 | Push/pop/peekMax/popMax 为 O(log n)，top | 为 O(1) O(n) | 使用双向链表+节点排序图/树进行快速访问 |

 ## 算法演练

 1. 使用**双向链表**来维护堆栈的顺序。 这允许 O(1)`push`,`pop`， 和`top`运营。 
2. 维护一个**排序映射**（Python：`SortedDict`从`sortedcontainers`）将每个值映射到包含该值的链表节点列表。 这让我们可以在 O(log n) 时间内访问最大值。 
3.为了`push(x)`，在链表尾部创建一个新节点，并将其添加到key下的有序映射中`x`。 
4. 对于`pop()`，从链表中删除尾节点，并从排序映射中删除引用。 返回节点值。 
5. 对于`top()`，只需返回尾节点的值即可。 
6. 对于`peekMax()`，查询排序映射中最大的键。 这使得 O(log n) 可以访问最大值而无需删除它。 
7. 对于`popMax()`，找到排序映射中最大的键，并从链表和映射中删除该值的**最近添加的节点**。 如果该值的节点列表变空，则从映射中删除该键。 

**为什么起作用：** 双向链表保留堆栈顺序并允许恒定时间删除任意节点。 排序后的映射有效地跟踪当前的最大值。 将这两者结合起来可以确保所有操作都满足所需的时间复杂度。 

## Python 解决方案```python
from sortedcontainers import SortedDict

class Node:
    def __init__(self, val: int):
        self.val = val
        self.prev = None
        self.next = None

class MaxStack:

    def __init__(self):
        self.head = Node(0)  # dummy head
        self.tail = Node(0)  # dummy tail
        self.head.next = self.tail
        self.tail.prev = self.head
        self.map = SortedDict()  # val -> list of nodes

    def push(self, x: int) -> None:
        node = Node(x)
        node.prev = self.tail.prev
        node.next = self.tail
        self.tail.prev.next = node
        self.tail.prev = node
        if x not in self.map:
            self.map[x] = []
        self.map[x].append(node)

    def pop(self) -> int:
        node = self.tail.prev
        self._remove(node)
        return node.val

    def top(self) -> int:
        return self.tail.prev.val

    def peekMax(self) -> int:
        return self.map.peekitem(-1)[0]

    def popMax(self) -> int:
        max_val, nodes = self.map.peekitem(-1)
        node = nodes.pop()
        if not nodes:
            del self.map[max_val]
        self._remove(node)
        return node.val

    def _remove(self, node: Node):
        node.prev.next = node.next
        node.next.prev = node.prev
```Python 解决方案使用双向链表来实现堆栈顺序和`SortedDict`有效跟踪最大值。 每个`push`附加到尾部，并且`_remove`有效地处理任意节点删除。 

## 解决方案```go
package main

import (
    "container/list"
    "sort"
)

type MaxStack struct {
    stack *list.List
    mapVal map[int][]*list.Element
    sortedKeys []int
}

func Constructor() MaxStack {
    return MaxStack{
        stack: list.New(),
        mapVal: make(map[int][]*list.Element),
        sortedKeys: []int{},
    }
}

func (this *MaxStack) Push(x int)  {
    node := this.stack.PushBack(x)
    this.mapVal[x] = append(this.mapVal[x], node)
    if len(this.mapVal[x]) == 1 {
        this.sortedKeys = append(this.sortedKeys, x)
        sort.Ints(this.sortedKeys)
    }
}

func (this *MaxStack) Pop() int {
    node := this.stack.Back()
    val := node.Value.(int)
    this.stack.Remove(node)
    nodes := this.mapVal[val]
    this.mapVal[val] = nodes[:len(nodes)-1]
    if len(this.mapVal[val]) == 0 {
        delete(this.mapVal, val)
        this.sortedKeys = this.sortedKeys[:len(this.sortedKeys)-1]
    }
    return val
}

func (this *MaxStack) Top() int {
    return this.stack.Back().Value.(int)
}

func (this *MaxStack) PeekMax() int {
    return this.sortedKeys[len(this.sortedKeys)-1]
}

func (this *MaxStack) PopMax() int {
    maxVal := this.PeekMax()
    nodes := this.mapVal[maxVal]
    node := nodes[len(nodes)-1]
    this.stack.Remove(node)
    this.mapVal[maxVal] = nodes[:len(nodes)-1]
    if len(this.mapVal[maxVal]) == 0 {
        delete(this.mapVal, maxVal)
        this.sortedKeys = this.sortedKeys[:len(this.sortedKeys)-1]
    }
    return maxVal
}
```Go 实现使用`container/list`用于双向链接列表和从值到列表元素切片的映射。 由于Go缺乏内置的平衡树，我们维护一个`sortedKeys`片。 逻辑与 Python 相似，但需要手动切片排序。
