 ## 解决方案

 ## 问题理解

 这个问题本质上是对《糖果粉碎传奇》游戏的模拟，我们需要反复粉碎网格中的糖果，直到棋盘达到稳定状态。 输入是一个`m x n`代表不同类型糖果的整数矩阵，以及`0`代表空单元格。 1 到 2000 之间的每个整数代表一种不同的糖果类型。 规则是，如果三个或更多相同类型的糖果连续排列在一行或一列中，它们就会“压碎”并消失，留下空单元格。 糖果压碎后，空单元格上方的任何糖果都会掉落，直到到达另一颗糖果或棋盘底部。 重复这个过程，直到没有更多的糖果可以被压碎。 

预期输出是经过所有可能的挤压和掉落动作后最终稳定的板。 约束表明电路板尺寸最多为 50x50，这对于简单的模拟方法来说足够小。 边缘情况包括已经稳定的棋盘、具有多次重叠挤压的棋盘以及掉落糖果后触发新挤压的情况。 

## 方法

 蛮力方法是遍历棋盘，检测所有可粉碎的序列（水平和垂直），标记它们，然后粉碎它们并让糖果掉落。 重复这个过程，直到不再有糖果被压碎为止。 虽然正确，但这种方法可能会重复扫描整个电路板，从而降低效率。 每次完整扫描可能需要`O(mn)`重复扫描可能会导致更高的整体运行时间。 

最佳方法利用系统的标记和丢弃策略。 我们不使用复杂的数据结构，而是使用负值或单独的布尔板来标记要压碎的糖果，然后一次性压碎所有标记的糖果。 对于掉落的糖果，我们使用底部的“写指针”独立处理每一列，从而有效地向下移动糖果。 我们重复这个过程，直到不再发生挤压。 这减少了不可破碎区域上不必要的重复迭代，并使解决方案简单高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((mn)^2) | O((mn)^2) | O(百万) | 反复扫描整个棋盘是否有压痕 |
 | 最佳| O((mn)^2) | O((mn)^2) | O(1) | O(1) | 标记压碎，沿列掉落糖果，重复直到稳定 |

 ## 算法演练

 1. 初始化一个标志`found`指示当前迭代中是否有任何糖果被压碎。 将其设置为`True`开始循环。 
2. 虽然`found`是`True`，执行以下操作：

 3. 设置`found`到`False`。 遍历棋盘以识别三个或更多相同糖果的水平和垂直序列。 通过使用负值或单独的布尔标记来标记这些要压碎的位置。 如果找到任何序列，则设置`found`到`True`。 

4. 标记后，再次迭代棋盘，将所有标记的糖果设置为粉碎`0`。 

5. 独立处理每一列以掉落糖果。 从每列的底部开始有一个“写入指针”。 对于从下到上遇到的每个非零糖果，将其移动到`write`位置和减量`write`。 移动完所有糖果后，填满上面剩余的位置`write`和`0`。 
3. 重复上述循环，直到没有发现新的粉碎（`found`遗迹`False`）。 

为什么有效：循环不变式是在每次迭代之后，所有可压碎的糖果都被压碎，并且所有剩余的糖果都处于尽可能低的位置。 通过重复应用这些步骤，我们确保不会留下新的可压碎序列，从而保证稳定性。 

## Python 解决方案```python
from typing import List

class Solution:
    def candyCrush(self, board: List[List[int]]) -> List[List[int]]:
        m, n = len(board), len(board[0])
        found = True
        
        while found:
            found = False
            crush = [[False]*n for _ in range(m)]
            
            # Mark horizontal crushes
            for i in range(m):
                for j in range(n-2):
                    if board[i][j] != 0 and board[i][j] == board[i][j+1] == board[i][j+2]:
                        crush[i][j] = crush[i][j+1] = crush[i][j+2] = True
                        found = True
            
            # Mark vertical crushes
            for i in range(m-2):
                for j in range(n):
                    if board[i][j] != 0 and board[i][j] == board[i+1][j] == board[i+2][j]:
                        crush[i][j] = crush[i+1][j] = crush[i+2][j] = True
                        found = True
                        
            # Crush candies
            for i in range(m):
                for j in range(n):
                    if crush[i][j]:
                        board[i][j] = 0
            
            # Drop candies
            for j in range(n):
                write = m - 1
                for i in range(m-1, -1, -1):
                    if board[i][j] != 0:
                        board[write][j] = board[i][j]
                        write -= 1
                for i in range(write, -1, -1):
                    board[i][j] = 0
                    
        return board
```Python 实现紧密遵循该算法。 水平和垂直挤压分别标记，并且`crush`矩阵避免了就地冲突。 通过每列自下而上的写入指针可以有效地处理删除。 

## 解决方案```go
func candyCrush(board [][]int) [][]int {
    m, n := len(board), len(board[0])
    found := true

    for found {
        found = false
        crush := make([][]bool, m)
        for i := range crush {
            crush[i] = make([]bool, n)
        }

        // Horizontal crush
        for i := 0; i < m; i++ {
            for j := 0; j < n-2; j++ {
                if board[i][j] != 0 && board[i][j] == board[i][j+1] && board[i][j] == board[i][j+2] {
                    crush[i][j], crush[i][j+1], crush[i][j+2] = true, true, true
                    found = true
                }
            }
        }

        // Vertical crush
        for i := 0; i < m-2; i++ {
            for j := 0; j < n; j++ {
                if board[i][j] != 0 && board[i][j] == board[i+1][j] && board[i][j] == board[i+2][j] {
                    crush[i][j], crush[i+1][j], crush[i+2][j] = true, true, true
                    found = true
                }
            }
        }

        // Crush candies
        for i := 0; i < m; i++ {
            for j := 0; j < n; j++ {
                if crush[i][j] {
                    board[i][j] = 0
                }
            }
        }

        // Drop candies
        for j := 0; j < n; j++ {
            write := m - 1
            for i := m - 1; i >= 0; i-- {
                if board[i][j] != 0 {
                    board[write][j] = board[i][j]
                    write--
                }
            }
            for i := write; i >= 0; i-- {
                board[i][j] = 0
            }
        }
    }

    return board
}
```在 Go 中，切片用于表示棋盘和挤压标记。 该方法类似于 Python，具有 2D 布尔切片的显式初始化。 同样的逻辑也适用，自然地处理边缘情况和重复粉碎。
