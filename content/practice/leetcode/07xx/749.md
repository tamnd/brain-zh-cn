[LeetCode 749 题](https://leetcode.com/problems/contain-virus/)

 **难度：** 🔴难
 **主题：** 数组、深度优先搜索、广度优先搜索、矩阵、模拟

 ## 解决方案

 ## 问题理解

 该问题模拟了病毒在二维网格上的传播。 每个细胞要么被感染（`1`）或未感染（`0`）。 病毒每天晚上从受感染的细胞沿四个基本方向传播到邻近的未受感染的细胞：上、下、左、右。 

我们被允许建造隔离墙，每天只隔离一个受感染的区域。 区域是使用 4 向连接的受感染细胞的连接组件。 一旦一个地区被隔离，病毒就无法再传播。 

重要的限制是我们必须选择在下一个传播阶段感染最多数量的当前未感染细胞的区域。 这个问题保证永远不会有平局，所以选择总是唯一的。 

任务是计算直到病毒被完全遏制或整个网格被感染为止所建造的墙的总数。 

输入是一个`m x n`矩阵其中：

 -`0`表示未感染
 -`1`表示已感染且活跃
 - 在模拟过程中，我们通常还会在内部引入第三个值，例如`-1`, 标记隔离区域

 输出是一个整数，表示整个过程中建造的墙的总数。 

限制相对较小：

 -`1 <= m, n <= 50`- 最大网格尺寸为`2500`细胞

 这使得我们能够重复扫描整个网格并执行 DFS 或 BFS 等图遍历，而不会出现性能问题。 

一些边缘情况很重要：

 - 一个区域可能已经被完全包围并且无法扩散
 - 多个感染区域可能同时存在
 - 整个网格可能已经被感染
 - 单个受感染的细胞可能需要多个壁，具体取决于邻近的未受感染的细胞
 - 一个地区被隔离后，所有剩余地区同时传播

 幼稚的实现很容易犯错误，比如允许隔离区域再次扩散、重复计算墙壁或以错误的顺序更新网格。 

## 方法

 ### 蛮力方法

 暴力方法会尝试每天模拟每一种可能的隔离选择。 对于每个受感染的区域，我们可以：

 1. 模拟隔离该区域
 2. 为所有其他人模拟病毒传播
 3. 比较结果状态
 4. 选择最佳选择

 这是有效的，因为它明确地评估每一种可能的行动，并根据问题规则选择最佳的行动。 

然而，这不必要地昂贵，因为问题已经告诉我们如何选择区域：隔离威胁最大数量未感染细胞的区域。 我们不需要独立模拟所有可能性。 

暴力解决方案重复复制网格并执行许多冗余扩展模拟，使其比必要的速度慢得多。 

### 最佳方法

 关键的观察是，对于每个连接的感染区域，我们只需要三条信息：

 1. 属于该区域的单元格
 2. 该区域接下来可能感染的一组未感染细胞
 3. 隔离该区域所需的墙壁数量

 一旦我们计算出每个区域的这些信息：

 - 我们隔离威胁最多细胞的区域
 - 我们将其墙数添加到答案中
 - 我们将该区域标记为永久封锁
 - 所有其他地区同时传播

 这自然会导致重复的 DFS 或 BFS 模拟。 

网格尺寸足够小，每轮重新扫描棋盘是完全可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((mn)^3) | O((mn)^3) | O(百万) | 模拟许多冗余的未来状态 |
 | 最佳 | O((mn)^2) | O((mn)^2) | O(百万) | 重复 DFS/BFS 与直接区域分析 |

 ## 算法演练

 1. 将总墙数初始化为零。 
2. 重复处理网格，直到没有活动区域可以进一步扩展。 
3. 在每次迭代期间，扫描网格并使用 DFS 或 BFS 识别所有连接的感染区域。 
4. 对于每个区域，维护：

 - 该地区受感染细胞的列表
 - 一组接下来可能被感染的邻近未感染细胞
 - 隔离该区域所需的墙壁数量
 5. 探索一个地区时：

 - 如果我们遇到相邻的未感染细胞，我们：

 - 将其添加到受威胁集中
 - 将墙数增加一堵
 - 如果我们遇到另一个被感染的细胞，则继续遍历
 6. 处理完所有区域后，确定哪个区域威胁最多数量的未感染细胞。 
7. 如果没有区域可以再扩展，则终止模拟并返回累积的墙数。 
8. 将所选区域的墙数添加到答案中。 
9. 使用特殊值标记隔离区域中的所有单元格，例如`-1`。 这可以防止它们在未来几轮中传播。 
10. 对于所有其他活跃区域：

 - 感染所有受威胁的邻近细胞
 - 这种传播在所有非隔离地区同时发生
 11. 重复该过程直至遏制完成。 

### 为什么它有效

 在每一步中，算法都严格遵循问题的规则。 每个连接的组件都经过独立分析，以确定它威胁了多少个单元以及需要多少个墙。 威胁最多细胞的区域被隔离，而所有其他区域同时传播。 由于隔离区域被永久标记并排除在未来的传播之外，因此模拟仍然忠实于预期过程。 重复此过程最终达到稳定状态，其中没有活性区域可以感染其他细胞。 

## Python 解决方案```python
from typing import List, Set, Tuple

class Solution:
    def containVirus(self, isInfected: List[List[int]]) -> int:
        rows = len(isInfected)
        cols = len(isInfected[0])

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        total_walls = 0

        while True:
            visited = set()

            regions = []
            frontiers = []
            walls_needed = []

            for r in range(rows):
                for c in range(cols):
                    if isInfected[r][c] == 1 and (r, c) not in visited:
                        stack = [(r, c)]

                        region = []
                        frontier = set()
                        walls = 0

                        visited.add((r, c))

                        while stack:
                            x, y = stack.pop()
                            region.append((x, y))

                            for dx, dy in directions:
                                nx = x + dx
                                ny = y + dy

                                if 0 <= nx < rows and 0 <= ny < cols:
                                    if isInfected[nx][ny] == 1 and (nx, ny) not in visited:
                                        visited.add((nx, ny))
                                        stack.append((nx, ny))

                                    elif isInfected[nx][ny] == 0:
                                        frontier.add((nx, ny))
                                        walls += 1

                        regions.append(region)
                        frontiers.append(frontier)
                        walls_needed.append(walls)

            if not frontiers:
                break

            quarantine_index = 0

            for i in range(1, len(frontiers)):
                if len(frontiers[i]) > len(frontiers[quarantine_index]):
                    quarantine_index = i

            if len(frontiers[quarantine_index]) == 0:
                break

            total_walls += walls_needed[quarantine_index]

            # Quarantine selected region
            for x, y in regions[quarantine_index]:
                isInfected[x][y] = -1

            # Spread remaining regions
            for i in range(len(regions)):
                if i == quarantine_index:
                    continue

                for x, y in frontiers[i]:
                    isInfected[x][y] = 1

        return total_walls
```该实现重复执行区域发现和模拟回合。 

这`visited`设置可防止在 DFS 期间多次处理同一受感染的细胞。 每次 DFS 遍历都会收集属于一个相连的感染区域的所有单元。 

对于每个区域，维护三个结构：

 -`region`，属于该组件的受感染细胞
 -`frontier`，下一轮可以到达未感染的细胞
 -`walls`，所需墙的确切数量

 每当 DFS 看到相邻的未感染细胞时，它就会增加细胞壁计数。 多个受感染的细胞接触同一个未受感染的细胞会形成多个墙壁，这与问题陈述相符。 

分析完所有区域后，算法选择具有最大边界的区域。 该区域通过将其单元格标记为而被隔离`-1`。 

然后所有剩余区域同时感染其前沿细胞。 

这个过程不断重复，直到没有区域可以进一步传播。 

## 解决方案```go
package main

func containVirus(isInfected [][]int) int {
	rows := len(isInfected)
	cols := len(isInfected[0])

	directions := [][]int{
		{1, 0},
		{-1, 0},
		{0, 1},
		{0, -1},
	}

	totalWalls := 0

	for {
		visited := make(map[[2]int]bool)

		var regions [][][]int
		var frontiers []map[[2]int]bool
		var wallsNeeded []int

		for r := 0; r < rows; r++ {
			for c := 0; c < cols; c++ {
				key := [2]int{r, c}

				if isInfected[r][c] == 1 && !visited[key] {
					stack := [][]int{{r, c}}

					visited[key] = true

					var region [][]int
					frontier := make(map[[2]int]bool)

					walls := 0

					for len(stack) > 0 {
						cell := stack[len(stack)-1]
						stack = stack[:len(stack)-1]

						x, y := cell[0], cell[1]

						region = append(region, []int{x, y})

						for _, d := range directions {
							nx := x + d[0]
							ny := y + d[1]

							if nx >= 0 && nx < rows && ny >= 0 && ny < cols {
								nextKey := [2]int{nx, ny}

								if isInfected[nx][ny] == 1 && !visited[nextKey] {
									visited[nextKey] = true
									stack = append(stack, []int{nx, ny})
								} else if isInfected[nx][ny] == 0 {
									frontier[nextKey] = true
									walls++
								}
							}
						}
					}

					regions = append(regions, region)
					frontiers = append(frontiers, frontier)
					wallsNeeded = append(wallsNeeded, walls)
				}
			}
		}

		if len(frontiers) == 0 {
			break
		}

		quarantineIndex := 0

		for i := 1; i < len(frontiers); i++ {
			if len(frontiers[i]) > len(frontiers[quarantineIndex]) {
				quarantineIndex = i
			}
		}

		if len(frontiers[quarantineIndex]) == 0 {
			break
		}

		totalWalls += wallsNeeded[quarantineIndex]

		for _, cell := range regions[quarantineIndex] {
			x, y := cell[0], cell[1]
			isInfected[x][y] = -1
		}

		for i := 0; i < len(regions); i++ {
			if i == quarantineIndex {
				continue
			}

			for pos := range frontiers[i] {
				x, y := pos[0], pos[1]
				isInfected[x][y] = 1
			}
		}
	}

	return totalWalls
}
```Go 实现遵循与 Python 版本相同的整体逻辑。 由于 Go 没有内置的元组类型或集合，因此具有固定大小数组键的映射用于访问跟踪和边界存储。 

切片用于 DFS 堆栈和区域存储。 整数溢出不是问题，因为网格最多包含 2500 个单元，并且墙数仍然在 Go 的范围内`int`范围。

 ## 边缘情况

 当网格已经完全被感染时，就会出现一种重要的边缘情况。 在这种情况下，没有剩余的未感染细胞，因此没有区域可以进一步传播。 有缺陷的实现可能仍然会尝试建造不必要的墙。 该解决方案正确处理了这个问题，因为每个区域的边界都变空，导致模拟循环立即终止。 

另一个棘手的情况是当多个受感染的细胞与同一个未感染的细胞相邻时。 简单的实现可能只计算一堵墙，因为边界集存储了唯一的单元格。 然而，该问题需要计算每个共享边界的墙数，而不是每个边界单元。 每次遇到受感染到未受感染的边缘时，该实现都会正确增加墙计数。 

第三个微妙的情况是同时传播。 隔离一个地区后，其余所有地区同时传播。 如果实现更新一个区域，然后使用修改后的网格顺序处理另一个区域，则结果将变得不正确。 该解决方案通过在执行任何扩展更新之前首先计算所有边界来避免这种情况。 

最后一个边缘情况涉及隔离区域。 一旦被隔离，它们就绝不能再次传播。 忘记区分被隔离的细胞和活跃的感染细胞会导致重复传播和无限循环。 将隔离单元标记为`-1`将它们与活跃的感染状态完全分开。
