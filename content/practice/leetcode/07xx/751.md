 **难度：** 🟡 中等
 **主题：** 字符串、位操作

 ## 解决方案

 ## 问题理解

 这个问题要求我们获取一个起始 IPv4 地址和一个数字`n`连续的 IP 地址，并将它们转换为精确覆盖该范围的最小 CIDR 块集。 IPv4 地址是以熟悉的点分十进制格式编写的 32 位数字（例如，`"192.168.1.1"`），其中每个段代表 8 位。 CIDR 块，例如`"192.168.1.0/24"`，通过固定第一个地址来指定地址范围`k`位并允许剩余的`32 - k`位变化。 

输入包含有效的 IPv4 字符串`ip`和一个整数`n`代表要覆盖的连续地址的数量。 输出必须是涵盖所有这些地址的 CIDR 块列表，不多也不少。 挑战在于尽可能使用最少的 CIDR 块，这通常涉及将连续地址组合成以 2 的幂对齐的最大有效块。 

约束告诉我们输入的 IP 始终有效并且`1 <= n <= 1000`。 因此，地址范围相对较小，我们不需要处理环绕`255.255.255.255`。 重要的边缘情况包括小范围（`n=1`)、不是 2 的幂的范围以及未与 2 的幂边界对齐的起始地址。 

## 方法

 **暴力方法**将生成所有`n`IP 地址并尝试以简单的方式将它们组合成 CIDR 块，检查每个地址的每个可能的块大小。 虽然这最终会产生正确的结果，但效率很低，因为它涉及迭代潜在的数千个单独地址并尝试所有块大小，从而导致不必要的计算。 

**最佳方法**依赖于位操作和二进制对齐的两个观察结果：

 1. 每个 CIDR 块必须从与其块大小对齐的地址开始。 例如，一个大小为`8`必须以以下倍数开始`8`以整数形式。 
2. 每一步的最大块大小受到当前起始 IP 的对齐和要覆盖的剩余地址数量的限制。 我们可以计算满足这两个约束的最大二次幂块。 

该算法将IP转换为32位整数，重复计算最大有效块以覆盖剩余地址，附加相应的CIDR字符串，并递增起始IP，直到覆盖所有地址。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * log n) | O(n * log n) | O(n) | 生成所有IP，然后合并成块|
 | 最佳 | O(log n) | O(log n) | 使用位操作贪婪地选择最大的块 |

 ## 算法演练

 1. **将IP转换为整数：** 将起始IP字符串转换为32位整数，以便于算术和按位运算。 
2. **初始化结果列表：** 准备一个列表来存储CIDR块字符串。 
3. **在地址保留时迭代：** While`n > 0`:

 1. 使用以下命令计算当前 IP 对齐允许的最大块大小`x & -x`，隔离最低有效设置位。 
2. 使用以下命令计算剩余地址允许的最大块大小`2^floor(log2(n))`。 
3. 取两者中的最小值来获取当前步骤的块大小。 
4. 将此块大小转换为 CIDR 前缀长度：`32 - log2(block_size)`。 
5. 将当前 IP 和前缀的 CIDR 字符串附加到结果列表中。 
6. 将 IP 整数增加块大小并减少`n`因此。 
4. **覆盖所有地址后返回结果列表**。 

**为什么有效：** 这种贪婪算法保证了最小的 CIDR 块，因为在每一步它都会选择最大可能的对齐块而不超出剩余范围。 使用二的幂可确保对齐和完全覆盖。 

## Python 解决方案```python
from typing import List
import math

class Solution:
    def ipToCIDR(self, ip: str, n: int) -> List[str]:
        def ip_to_int(ip_str: str) -> int:
            parts = list(map(int, ip_str.split('.')))
            res = 0
            for part in parts:
                res = res * 256 + part
            return res
        
        def int_to_ip(ip_int: int) -> str:
            return '.'.join(str((ip_int >> (8 * i)) % 256) for i in reversed(range(4)))
        
        res = []
        start = ip_to_int(ip)
        
        while n > 0:
            # Max block size due to IP alignment
            lsb = start & -start
            max_size = 1
            while max_size <= lsb:
                max_size <<= 1
            max_size >>= 1
            
            # Max block size due to remaining addresses
            while max_size > n:
                max_size >>= 1
            
            prefix_len = 32 - int(math.log2(max_size))
            res.append(f"{int_to_ip(start)}/{prefix_len}")
            
            start += max_size
            n -= max_size
        
        return res
```**实现说明：**`ip_to_int`和`int_to_ip`函数在字符串和整数表示之间进行转换。 这`lsb`计算用途`x & -x`找到对齐限制。 该循环确定对齐和剩余地址允许的最大块大小，计算相应的 CIDR 前缀，更新起始 IP，并递减`n`。 

## 解决方案```go
import (
    "fmt"
    "math"
    "strconv"
    "strings"
)

func ipToCIDR(ip string, n int) []string {
    ipToInt := func(ipStr string) int {
        parts := strings.Split(ipStr, ".")
        res := 0
        for _, part := range parts {
            num, _ := strconv.Atoi(part)
            res = res*256 + num
        }
        return res
    }

    intToIP := func(ipInt int) string {
        parts := make([]string, 4)
        for i := 3; i >= 0; i-- {
            parts[i] = strconv.Itoa(ipInt % 256)
            ipInt /= 256
        }
        return strings.Join(parts, ".")
    }

    res := []string{}
    start := ipToInt(ip)
    
    for n > 0 {
        lsb := start & -start
        maxSize := 1
        for maxSize <= lsb {
            maxSize <<= 1
        }
        maxSize >>= 1

        for maxSize > n {
            maxSize >>= 1
        }

        prefixLen := 32 - int(math.Log2(float64(maxSize)))
        res = append(res, fmt.Sprintf("%s/%d", intToIP(start), prefixLen))

        start += maxSize
        n -= maxSize
    }
    
    return res
}
```**Go 特定说明：** Go 不直接支持`math.log2`对于整数，所以我们转换为 float64。 切片用于动态列表。 字符串和整数之间的转换使用`strconv.Atoi`和`strconv.Itoa`。 

## 工作示例

 **示例1：**`ip = "255.0.0.7"`,`n = 10`1.将IP转换为整数：`start = 4278190095`2.第一次迭代：`lsb = 1`，最大块大小 = 1 → CIDR`"255.0.0.7/32"`, 开始 += 1, n = 9
 3.第二次迭代：`lsb = 8`，最大块大小 = 8 → CIDR`"255.0.0.8/29"`, 开始 += 8, n = 1
 4. 第三次迭代：最大块大小 = 1 → CIDR`"255.0.0.16/32"`, 完成

 **示例2：**`ip = "117.145.102.62"`,`n = 8`1.将IP转换为整数：`start = 1977140294`2. 第一次迭代：lsb = 2 → CIDR`"117.145.102.62/31"`, 开始 += 2, n = 6
 3. 第二次迭代：lsb = 4 → CIDR`"117.145.102.64/30"`, 开始 += 4, n = 2
 4. 第三次迭代：lsb = 2 → CIDR`"117.145.102.68/31"`, 完成

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(log n) | 每次迭代至少覆盖一个地址，并且通常是 2 的幂块，因此迭代与 log(n) | 成正比。 
| 空间| O(log n) | 结果列表最多存储 log(n) 个 CIDR 块 |

 原因是每个块覆盖二次方数量的地址，以指数方式减少剩余范围，并且转换是恒定时间。
