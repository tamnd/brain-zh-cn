[LeetCode 750 题](https://leetcode.com/problems/number-of-corner-rectangles/)

 **难度：** 🟡 中等
 **主题：** 数组、数学、动态规划、矩阵

 ## 解决方案

 ## 问题理解

 该问题要求我们计算二进制中**角矩形**的数量`m x n`矩阵`grid`。 角矩形定义为一组四个`1`网格中的 s 形成轴对齐矩形的角。 重要的是，只需将角`1`; 内部细胞可以是`0`。 四个`1`s 必须是不同的，因此具有重叠角的矩形不会多次计数，除非它们形成不同的四个集合`1`是。 
输入`grid`是一个二维数组，仅包含`0`沙`1`s。 输出是一个整数，表示不同角矩形的数量。 

约束提供了对问题规模的洞察。 矩阵可达`200 x 200`，这使得`O(m^2 * n^2)`算法可能不可行，而总数`1`s 限制为 6000，这允许算法依赖于`1`s 而不是总网格大小。 

边缘情况包括单行或单列的网格，它们不能形成矩形，网格充满`1`s，或者稀疏网格，很少`1`分散在许多行和列中。 

## 方法

 **暴力方法**将迭代所有行对和列对，检查所有四个角是否都已`1`。 具体来说，对于每对行`(r1, r2)`和每对列`(c1, c2)`，我们检查是否`grid[r1][c1]`,`grid[r1][c2]`,`grid[r2][c1]`， 和`grid[r2][c2]`都是`1`。 虽然正确，但这种方法具有时间复杂度`O(m^2 * n^2)`对于最大允许的网格尺寸来说变得不可行。 

**最佳方法**依赖于一个关键观察：对于任何行对，问题都简化为计算两行都具有的列对`1`s。 如果行`i`和行`j`两者都有`1`列中的 s`c1`和`c2`， 然后`(i, j, c1, c2)`形成一个角矩形。 这使我们能够迭代所有行对并维护共享的计数`1`列，添加`count * (count - 1) / 2`每个新共享的矩形`1`。 这种方法将问题简化为`O(m^2 * n)`时间和`O(n^2)`最坏情况下的空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m^2 * n^2) | O(m^2 * n^2) | O(1) | O(1) | 检查行和列对的每个组合 |
 | 最佳 | O(m^2 * n) | O(m^2 * n) | O(n^2) | O(n^2) | 共享计数`1`行对之间的 s 并组合计算矩形 |

 ## 算法演练

 1. 初始化变量`result`为零。 这将累积角矩形的总数。 
2. 迭代所有行对`(r1, r2)`使用嵌套循环。 
3. 对于每对`(r1, r2)`，迭代所有列`c`并计算有多少列`1`在两者中`r1`和`r2`。 设这个数为`shared`。 
4. 这两行和共享列组成的矩形的个数为`shared * (shared - 1) / 2`。 将此值添加到`result`。 
5. 处理完所有行对后，返回`result`。 

**为什么它有效**：不变的是对于任何两行，每对列`1`两行中的 s 唯一定义一个矩形。 对所有共享列对进行计数可确保考虑所有可能的矩形，而不会重复计算。 

## Python 解决方案```python
from typing import List

class Solution:
    def countCornerRectangles(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        result = 0
        for r1 in range(m):
            for r2 in range(r1 + 1, m):
                shared = 0
                for c in range(n):
                    if grid[r1][c] == 1 and grid[r2][c] == 1:
                        shared += 1
                result += shared * (shared - 1) // 2
        return result
```Python实现首先计算行数`m`和列`n`。 它迭代所有行对`(r1, r2)`，然后计算两行都有的列`1`s。 使用组合公式`shared * (shared - 1) // 2`，它计算由该行对形成的矩形的数量并将其添加到`result`。 最后，它返回总数。 

## 解决方案```go
func countCornerRectangles(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    result := 0
    for r1 := 0; r1 < m; r1++ {
        for r2 := r1 + 1; r2 < m; r2++ {
            shared := 0
            for c := 0; c < n; c++ {
                if grid[r1][c] == 1 && grid[r2][c] == 1 {
                    shared++
                }
            }
            result += shared * (shared - 1) / 2
        }
    }
    return result
}
```Go 版本反映了 Python 逻辑，使用整数除法进行组合计算。 Go 需要对切片进行显式类型处理，但其他方面的工作方式相同。 

## 工作示例

 **示例1**```
grid = [[1,0,0,1,0],
        [0,0,1,0,1],
        [0,0,0,1,0],
        [1,0,1,0,1]]
```对于行对`(1,3)`，共享列`1`是`[2, 4]`。 计数 = 2，矩形 = 2 * 1 / 2 = 1。结果 = 1。 

**示例2**```
grid = [[1,1,1],
        [1,1,1],
        [1,1,1]]
```对于每一行对，所有列都有`1`s。 对于行对`(0,1)`，共享 = 3，矩形 = 3 * 2 / 2 = 3。`(0,2)`= 3,`(1,2)`= 3。总计 = 9。 

**示例3**```
grid = [[1,1,1,1]]
```仅存在一行，因此没有行对。 结果 = 0。

 ## 边缘情况

 一个重要的边缘情况是只有单行或单列的网格。 无法形成矩形，因为至少需要两行和两列。 该实现自然地通过迭代行对来处理这个问题，这在单行网格中不存在。 

另一个边缘情况是完全密集的网格，其中每个元素都是`1`。 这测试了组合计数是否正确工作，并且该算法不会对矩形进行重复计数。 每个行对都会正确计算`shared * (shared - 1) / 2`为矩形的数量。 

第三种边缘情况是稀疏网格`1`s 的分散方式使得某些行对没有共享`1`s。 在这些情况下，算法会正确添加零个矩形，从而防止过度计数。 即使大部分矩阵都是这样，这也能确保正确性`0`。
