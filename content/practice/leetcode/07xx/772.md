 # LeetCode 772 - 基本计算器 III

 ## 问题理解

 该问题要求我们评估以字符串表示的数学表达式。 该表达式可能包含：

 - 非负整数
 - 加法（`+`）
 - 减法（`-`）
 - 乘法（`*`）
- 分配 （`/`）
 - 括号（`(`和`)`）

 目标是计算最终的整数结果，同时遵守正常的算术优先规则。 

重要的细节是乘法和除法的优先级高于加法和减法。 括号会覆盖优先级并强制首先计算其中的表达式。 除法必须向零截断，这与问题预期的行为相匹配。 

输入是单个字符串`s`，代表一个有效的数学表达式。 输出是一个整数，即该表达式的计算结果。 

这些约束告诉我们一些重要的事情：

 - 字符串长度可以大到`10^4`，因此解决方案必须是有效的。 
- 表达式保证有效，这意味着：

 - 括号是平衡的
 - 操作员出现在有效位置
 - 不存在格式错误的表达式
 - 中间结果适合 32 位有符号整数范围。 

一些边缘情况可能会在简单的实现中导致问题：

 - 嵌套括号，例如`"2*(3+(4*5))"`- 多位数字，例如`"123+456"`- 负值除法，其中截断为零很重要
 - 以数字结尾的表达式
 - 优先顺序很重要的连续操作，例如`"2+3*4"`正确的实现必须仔细解析字符串，同时保留运算符优先级并正确评估嵌套表达式。 

## 方法

 ### 蛮力方法

 暴力式方法将重复扫描字符串并根据优先级规则评估操作。 

一种可能的实现是：

 1. 首先解析最里面的括号。 
2. 将每个括号内的表达式替换为其计算值。 
3. 重复扫描乘法和除法。 
4. 然后扫描加减法。 

这最终会产生正确的答案，因为算术优先规则是分阶段明确执行的。 

然而，这种方法效率低下，因为每次缩减都可能需要重建或重新扫描字符串的大部分。 对于深层嵌套的表达式或长输入，重复扫描会变得昂贵。 

由于字符串突变和令牌管理变得难以正确维护，因此实现也很复杂。 

### 最佳方法

 最佳解决方案是将递归与堆栈结合使用。 

关键的观察是括号自然地形成递归子问题。 每当我们遇到`'('`，我们可以递归地计算其中的子表达式，直到达到匹配`')'`。 

在每个递归级别：

 - 我们维持当前正在建造的数量。 
- 我们追踪前任操作员。 
- 我们使用堆栈来处理优先级。 

该堆栈之所以有效，是因为：

 - 加法推动正数。 
- 减法推入负数。 
- 乘法立即与前一个堆栈值相结合。 
- 除法立即与先前的堆栈值相结合。 

这自然地保留了运算符优先级，而不需要多次传递。 

在表达式结束时或到达时`')'`，堆栈包含应该简单地求和在一起的值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复重新扫描和重建表达式 |
 | 最佳| O(n) | O(n) | 使用递归和堆栈进行单遍解析 |

 ## 算法演练

 1. 初始化一个索引指针来跟踪字符串中的当前位置。 
2. 创建一个递归辅助函数，用于计算从当前索引开始的表达式。 
3. 在辅助函数中，维护：

 - 处理值的堆栈
 - 由数字构建的当前数字
 - 最初的前任操作员`'+'`4. 逐个字符地遍历字符串。 
5. 如果当前字符是数字，则更新当前数字：```
num = num * 10 + digit
```这可以正确处理多位数字。 
6. 如果当前字符是`'('`，递归计算括号内的子表达式。 递归调用返回计算值，该值成为当前数字。 
7. 当我们遇到运算符、右括号或字符串末尾时，处理前一个运算符：

 -`'+'`推动`num`-`'-'`推动`-num`-`'*'`弹出最后一个值，将其乘以`num`，然后将结果压入
 -`'/'`弹出最后一个值，除以`num`向零截断，然后将结果推入
 8. 重置`num`到`0`并更新之前的操作符。 
9. 如果当前字符是`')'`，停止当前的递归调用并返回堆栈的和。 
10. 循环结束后，返回堆栈的总和作为该表达式级别的最终值。 

### 为什么它有效

 该算法保持了一个重要的不变量：

 - 堆栈始终包含当前表达式级别的正确处理值。 
- 加法和减法通过存储有符号值来延迟计算。 
- 立即评估乘法和除法，确保正确的优先级。 

递归正确地隔离了带括号的子表达式，允许嵌套表达式在集成到外部表达式之前独立计算。 

由于每个字符都被处理一次，因此该算法可以有效地计算出正确的结果。 

## Python 解决方案```python
class Solution:
    def calculate(self, s: str) -> int:
        index = 0

        def evaluate() -> int:
            nonlocal index

            stack = []
            num = 0
            operator = '+'

            while index < len(s):
                char = s[index]

                if char.isdigit():
                    num = num * 10 + int(char)

                elif char == '(':
                    index += 1
                    num = evaluate()

                if (
                    char in '+-*/)'
                    or index == len(s) - 1
                ):
                    if operator == '+':
                        stack.append(num)

                    elif operator == '-':
                        stack.append(-num)

                    elif operator == '*':
                        stack.append(stack.pop() * num)

                    elif operator == '/':
                        prev = stack.pop()
                        stack.append(int(prev / num))

                    operator = char
                    num = 0

                if char == ')':
                    break

                index += 1

            return sum(stack)

        return evaluate()
```该实现使用名为的递归辅助函数`evaluate`。 该函数一次处理一个表达式范围。 

这`index`变量在递归调用之间共享`nonlocal`。 这允许嵌套表达式在返回后从正确的位置继续解析。 

这`stack`存储部分评估的值。 加法和减法直接压入有符号数，而乘法和除法则立即修改最近的值。 这保证了正确的优先级处理。 

当遇到`'('`，该函数递归地计算嵌套子表达式。 返回值成为外部表达式中的当前数字。 

除法步骤使用：```python
int(prev / num)
```这很重要，因为 Python 底层划分 (`//`) 对于负数的行为有所不同。 使用`int(prev / num)`确保截断为零，这与问题规范相匹配。 

最后，函数返回`sum(stack)`，它结合了所有延迟加法和减法运算。 

## 解决方案```go
func calculate(s string) int {
	index := 0

	var evaluate func() int

	evaluate = func() int {
		stack := []int{}
		num := 0
		operator := byte('+')

		for index < len(s) {
			char := s[index]

			if char >= '0' && char <= '9' {
				num = num*10 + int(char-'0')
			} else if char == '(' {
				index++
				num = evaluate()
			}

			if char == '+' ||
				char == '-' ||
				char == '*' ||
				char == '/' ||
				char == ')' ||
				index == len(s)-1 {

				switch operator {
				case '+':
					stack = append(stack, num)

				case '-':
					stack = append(stack, -num)

				case '*':
					last := stack[len(stack)-1]
					stack = stack[:len(stack)-1]
					stack = append(stack, last*num)

				case '/':
					last := stack[len(stack)-1]
					stack = stack[:len(stack)-1]
					stack = append(stack, last/num)
				}

				operator = char
				num = 0
			}

			if char == ')' {
				break
			}

			index++
		}

		total := 0

		for _, value := range stack {
			total += value
		}

		return total
	}

	return evaluate()
}
```Go 实现与 Python 解决方案非常相似，但有几个特定于语言的细节值得注意。 

Go 切片用作堆栈。 移除顶部元素需要切片：```go
stack = stack[:len(stack)-1]
```Go 中的整数除法已经向零截断，因此标准整数除法就足够了。 

Go 不支持嵌套函数`nonlocal`像Python一样的变量，但闭包仍然允许访问共享`index`多变的。

 ## 边缘情况

 一种重要的边缘情况是多位数。 幼稚的实现可能会独立处理每个数字，从而错误地解释`"123"`作为单独的值而不是单个数字。 该解决方案通过使用以下方法不断构建当前数字来解决该问题：```
num = num * 10 + digit
```另一个关键的边缘情况是嵌套括号。 表达式例如：```
"1+(2*(3+(4*5)))"
```需要多个级别的递归评估。 如果没有递归或仔细的堆栈管理，很容易忘记哪些操作属于哪个范围。 递归辅助函数清楚地隔离了每个带括号的子表达式。 

涉及负数的除法也是错误的常见来源。 在 Python 中，向下取整除法与向零截断的行为不同：```
-3 // 2 == -2
```然而，该问题需要截断为零，这应该产生`-1`。 使用：```
int(a / b)
```确保正确的行为。 

最后的边缘情况涉及以数字结尾的表达式。 由于可能没有尾随运算符来触发处理，因此某些实现会忘记评估最后累加的数字。 该解决方案明确检查：```
index == len(s) - 1
```以确保最终值得到正确处理。
