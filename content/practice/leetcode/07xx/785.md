[LeetCode 第 785 题](https://leetcode.com/problems/is-graph-bipartite/)

 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、并查找、图论

 ## 解决方案

 ## 问题理解

 问题询问给定的无向图是否是**二分图**。 简单来说，我们得到一个表示为邻接表的图`graph`， 在哪里`graph[u]`列出与节点直接连接的所有节点`u`。 目标是确定是否可以将所有节点分成两个集合，使得同一集合内的两个节点都不会通过边连接。 

输入图最多有 100 个节点，并且可能不连接。 每个节点只列出不同的邻居，没有自环，并且图是无向的，这意味着如果`v`是一个邻居`u`， 然后`u`也是的邻居`v`。 预期输出是一个布尔值：`true`如果图是二分图，`false`否则。 

重要的边缘情况包括具有断开连接的组件的图、具有循环的图（尤其是奇数长度的循环，这使得二分性不可能）以及单节点图（通常是二分性的）。 

## 方法

 暴力方法会尝试将节点的**所有可能的分区**枚举为两个集合，并检查每条边是否连接来自不同集合的节点。 虽然这在理论上是正确的，但该方法是不切实际的，因为分区数量与节点数量呈指数关系，具体而言`2^n`，即使对于`n = 20`，更不用说`n = 100`。 

最佳方法利用**图形着色技术**。 关键的见解是，当且仅当可以用两种颜色之一为每个节点着色，使得没有两个相邻节点共享相同的颜色时，图才是二分图。 此属性允许我们使用深度优先搜索 (DFS) 或广度优先搜索 (BFS) 遍历图形，尝试交替为节点着色。 如果我们遇到一个在不违反规则的情况下无法着色的节点，则该图不是二分图。 这种方法工作效率很高，因为我们只访问每个节点和每条边一次，给出相对于节点和边的数量的线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 检查所有节点划分为两个集合并验证边 |
 | 图形着色（DFS/BFS）| O(V + E) | O(V) | 使用双色来确定二分性； 遍历每个节点和边一次 |

 ## 算法演练

 1.初始化字典或数组`color`存储每个节点的颜色。 通常使用两种颜色`0`和`1`。 最初，所有节点都是未着色的。 
2. 迭代图中的所有节点。 对于每个未着色的节点，从该节点开始执行 DFS（或 BFS），尝试对连接的组件进行着色。 
3. 在DFS/BFS期间，用一种颜色为当前节点着色，并为其所有邻居分配相反的颜色。 
4. 如果邻居已经被着色为与当前节点相同的颜色，则返回`false`立即因为违反了着色规则，表明该图不是二分图。 
5. 如果所有节点都成功着色且没有冲突，则返回`true`。 

**为什么有效：** 双色规则保证同一集合内的节点不能连接。 通过尝试递归或迭代地对图进行着色，任何违反二分性的行为都将被检测为着色冲突。 由于该算法检查所有节点，包括断开连接的组件，因此它可以正确处理未连接的图。 

## Python 解决方案```python
from typing import List

class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        color = {}

        def dfs(node: int, c: int) -> bool:
            if node in color:
                return color[node] == c
            color[node] = c
            for neighbor in graph[node]:
                if not dfs(neighbor, 1 - c):
                    return False
            return True

        for node in range(len(graph)):
            if node not in color:
                if not dfs(node, 0):
                    return False
        return True
```**说明：** 我们使用字典`color`存储每个节点分配的颜色。 这`dfs`函数尝试为节点着色，并用相反的颜色递归地为其邻居着色。 如果任何邻居已经具有相同的颜色，我们返回`false`。 外循环确保断开连接的组件也得到检查。 

## 解决方案```go
func isBipartite(graph [][]int) bool {
    n := len(graph)
    color := make([]int, n)
    for i := range color {
        color[i] = -1
    }

    var dfs func(int, int) bool
    dfs = func(node int, c int) bool {
        if color[node] != -1 {
            return color[node] == c
        }
        color[node] = c
        for _, neighbor := range graph[node] {
            if !dfs(neighbor, 1 - c) {
                return false
            }
        }
        return true
    }

    for i := 0; i < n; i++ {
        if color[i] == -1 {
            if !dfs(i, 0) {
                return false
            }
        }
    }
    return true
}
```**Go 特定注释：** 我们使用切片`color`初始化为`-1`代表未着色的节点。 递归DFS是使用函数变量实现的。 逻辑与Python版本相同。

 ## 边缘情况

 **断开连接的图：**某些节点可能无法从其他节点访问。 该算法通过迭代所有节点并对未访问的节点执行 DFS 来处理此问题，确保检查所有组件。 

**单节点图：** 具有一个节点且没有边的图是平凡二分图。 DFS 正确地为其着色，没有任何冲突。 

**奇数长度循环：** 任何奇数长度的循环都不能是二分的。 当尝试用相同的颜色给邻居着色时，DFS 会检测到这一点，并立即返回`false`。 这确保了正确处理周期。
