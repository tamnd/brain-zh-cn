[LeetCode 722 题](https://leetcode.com/problems/remove-comments/)

 **难度：** 🟡 中等
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们从表示为字符串数组的 C++ 程序中删除注释。 每个字符串代表程序的一行，由换行符分隔。 在 C++ 中，有两种类型的注释： 以以下字符开头的行注释`"//"`以及包含在之间的块注释`"/*"`和`"*/"`。 行注释在行尾终止，而块注释可以跨越多行。 

我们的任务是逐行处理输入并删除所有注释。 删除注释后，空行不应包含在输出中。 输出必须保留其余代码行的相对顺序。 

输入限制是可控的：源代码最多有 100 行，每行最多 80 个字符。 每个块注释都保证被关闭，并且输入中没有引号。 这些约束意味着我们不需要处理格式错误的注释或嵌入的字符串，这简化了解析。 关键的边缘情况包括在行中间开始和结束的注释、单行中的多个注释以及跨多行的块注释。 我们还需要正确处理由块注释引起的隐式换行符删除。 

## 方法

 一种暴力方法是将源代码转换为单个字符串，搜索所有出现的`"//"`和`"/*...*/"`，然后将其删除。 删除注释后，我们将字符串拆分回行。 这种方法可行，但很麻烦，因为手动处理多行块注释和换行符很容易出错。 此外，尽管输入大小很小，但字符串串联和重复搜索可能会降低解决方案的效率。 

最佳方法是使用带有标志的逐行扫描来跟踪我们是否位于块注释内。 对于每一行，我们在检查字符的同时迭代字符`"//"`和`"/*"`或者`"*/"`序列。 如果我们在块注释之外遇到行注释，我们会忽略该行的其余部分。 如果我们遇到块注释开始，我们进入块注释模式，跳过字符，直到找到块注释的结尾。 这种方法保留了行结构并避免了不必要的字符串操作。 

这种方法与输入中的字符总数呈线性关系，使其对于给定的约束非常有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N * M) | O(N * M) | 连接行，通过字符串替换删除所有注释，然后拆分回来 |
 | 最佳 | O(N * M) | O(N * M) | 单次传递字符、跟踪块注释、保留行 |

 这里，N是线数，M是平均线长度。 

## 算法演练

 1.初始化一个空列表`result`存储清理过的行和布尔标志`in_block_comment`设置为`False`。 
2. 迭代输入源中的每一行。 
3. 对于每一行，初始化一个空列表`new_line`累积非注释字符和指针`i`跟踪当前字符索引。 
4. 虽然`i`在线范围内：

 - 如果`in_block_comment`是`True`，检查当前字符和下一个字符是否是`"*/"`。 如果是，则退出块注释模式并前进`i`by 2。否则，跳过当前字符。 
- 如果`in_block_comment`是`False`，检查当前字符和下一个字符是否是`"//"`。 如果是，则中断循环，因为该行的其余部分是行注释。 
- 如果当前字符和下一个字符是`"/*"`，进入块注释模式并前进`i`2.
 - 否则，将当前字符附加到`new_line`并推进`i`1.
 5. 处理完该行后，如果`new_line`非空且不完全是空格，将其连接成一个字符串并附加到`result`。 
6. 返回`result`列表。 

为什么它有效：不变的是块注释之外的所有字符都会被累积，并且所有注释都会被跳过。 严格遵循行注释和块注释规则，确保只保留有效的代码。 

## Python 解决方案```python
from typing import List

class Solution:
    def removeComments(self, source: List[str]) -> List[str]:
        result = []
        in_block_comment = False
        new_line = []

        for line in source:
            i = 0
            if not in_block_comment:
                new_line = []
            while i < len(line):
                if in_block_comment:
                    if i + 1 < len(line) and line[i] == '*' and line[i+1] == '/':
                        in_block_comment = False
                        i += 2
                    else:
                        i += 1
                else:
                    if i + 1 < len(line) and line[i] == '/' and line[i+1] == '/':
                        break
                    elif i + 1 < len(line) and line[i] == '/' and line[i+1] == '*':
                        in_block_comment = True
                        i += 2
                    else:
                        new_line.append(line[i])
                        i += 1
            if not in_block_comment and new_line:
                result.append(''.join(new_line))

        return result
```这个 Python 实现直接镜像了该算法。 主循环处理线路遍历，而`in_block_comment`跟踪块评论状态。 仅当在注释之外时才附加字符，以确保正确的行结构。 

## 解决方案```go
func removeComments(source []string) []string {
    result := []string{}
    inBlock := false
    var newLine []byte

    for _, line := range source {
        i := 0
        if !inBlock {
            newLine = []byte{}
        }
        for i < len(line) {
            if inBlock {
                if i+1 < len(line) && line[i] == '*' && line[i+1] == '/' {
                    inBlock = false
                    i += 2
                } else {
                    i++
                }
            } else {
                if i+1 < len(line) && line[i] == '/' && line[i+1] == '/' {
                    break
                } else if i+1 < len(line) && line[i] == '/' && line[i+1] == '*' {
                    inBlock = true
                    i += 2
                } else {
                    newLine = append(newLine, line[i])
                    i++
                }
            }
        }
        if !inBlock && len(newLine) > 0 {
            result = append(result, string(newLine))
        }
    }
    return result
}
```Go 解决方案与 Python 几乎相同。 切片取代了 Python 列表来进行字符累积。`newLine`是一个有效构建字符串的字节切片。 主要逻辑保持不变。
