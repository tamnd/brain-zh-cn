[LeetCode 第 748 题](https://leetcode.com/problems/shortest-completing-word/)

 **难度：** 🟢简单
 **主题：** 数组、哈希表、字符串

 ## 解决方案

 ## 问题理解

 问题给了我们一个名为`licensePlate`和一组候选词称为`words`。 我们必须找到满足所有字母要求的最短单词`licensePlate`。 

关键细节是只有字母字符才重要。 应完全忽略数字和空格。 此外，大写和小写字母被视为相同字符。 这意味着我们应该在处理之前将所有字母标准化为小写。 

如果一个单词包含了所有必需的字母，则该单词被视为“完整单词”`licensePlate`，包括重复项。 例如，如果车牌包含字母`'s'`两次，那么候选词也必须至少包含两个`'s'`人物。 

输入尺寸相对较小：

 -`licensePlate.length <= 7`-`words.length <= 1000`-`words[i].length <= 15`这些限制告诉我们，我们不需要非常先进的优化技术。 直接频率计数方法很容易满足限制。 

输出应该是最短的完成词。 如果多个单词具有相同的最小长度，我们必须返回输入列表中出现的第一个单词。 这意味着迭代的顺序很重要。 

一些边缘情况很重要：

 - 车牌除一个字母外不得包含任何有用的字符。 
- 字母可能会重复多次。 
- 大写和小写字母必须同等对待。 
- 多个候选词可以具有相同的有效最短长度。 
- 答案保证存在，因此我们不需要处理失败情况。 

## 方法

 ### 蛮力方法

 强力解决方案将独立处理每个单词，并重复扫描车牌中的每个所需字符。 

一种简单的实现可以像这样工作：

 1. 提取所有字母`licensePlate`。 
2. 对于每个单词：

 - 对于每个必需的字符：

 - 计算它在单词中出现的次数。 
- 与所需频率进行比较。 
3. 跟踪最短的有效单词。 

这种方法是正确的，因为每个候选词都根据要求进行了明确检查。 然而，它对每个所需的字母重复扫描同一个单词，效率很低。 

例如，如果车牌需要多个不同的字符，则可以多次扫描同一个单词以重复计算频率。 

### 最佳方法

 关键的观察是可以有效地预先计算字符频率。 

我们可以：

 1. 构建车牌频率数组。 
2. 对于每个候选词：

 - 建立自己的频率阵列一次。 
- 比较两个数组。 
3. 选择最短的有效单词。 

由于只有 26 个小写英文字母，因此比较频率数组非常便宜并且有效地恒定时间。 

这种方法避免了冗余的计数工作，并实现了干净、高效的实施。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(宽 × 长 × 右) | O(1) | O(1) | 重复扫描单词以查找每个所需的字母 |
 | 最佳 | O(宽 × 长) | O(1) | O(1) | 使用频率计数进行有效验证 |

 在哪里：

-`W`= 字数
 -`L`= 平均字长
 -`R`= 车牌中所需字母的数量

 由于字母表大小固定为 26，因此额外的内存使用量是恒定的。 

## 算法演练

 1. 根据车牌要求创建大小为 26 的频率数组。 

每个索引代表一个小写字母`'a'`到`'z'`。 对于每个字母字符`licensePlate`，将其转换为小写并增加其相应的计数。 

该数组准确存储了每个字母需要出现的次数。 
2. 初始化一个变量来存储当前的最佳答案。 

最初，尚未选择答案。 
3. 迭代中的每个单词`words`。 

由于连接必须返回最早的单词，因此我们按单词的原始顺序处理单词。 
4. 为当前单词构建频率数组。 

计算每个字母在单词中出现的次数。 
5. 将词频与所需频率进行比较。 

对于每封来自`'a'`到`'z'`，验证：

 -`word_count[i] >= required_count[i]`如果任何必需的字母缺失或不足，则该单词无效。 
6. 如果该单词有效，则将其长度与当前最佳答案进行比较。 

如果出现以下情况，请更新答案：

 - 尚无答案，或者
 - 当前单词较短

 我们不会以相同的长度进行更新，因为较早的单词应该仍然是答案。 
7. 处理完所有单词后，返回存储的答案。 

### 为什么它有效

 该算法之所以有效，是因为每个候选词都会根据从车牌中提取的确切频率要求进行检查。 仅当一个单词包含足够多的每个必需字符时，该单词才会被接受。 由于我们按顺序处理单词，并且仅在找到严格较短的单词时才替换答案，因此最终结果保证是最早最短的完成单词。 

## Python 解决方案```python
from typing import List

class Solution:
    def shortestCompletingWord(self, licensePlate: str, words: List[str]) -> str:
        required = [0] * 26

        for char in licensePlate:
            if char.isalpha():
                index = ord(char.lower()) - ord('a')
                required[index] += 1

        answer = ""

        for word in words:
            counts = [0] * 26

            for char in word:
                counts[ord(char) - ord('a')] += 1

            is_valid = True

            for i in range(26):
                if counts[i] < required[i]:
                    is_valid = False
                    break

            if is_valid:
                if answer == "" or len(word) < len(answer):
                    answer = word

        return answer
```实现首先构建`required`来自车牌的频率阵列。 仅处理字母字符，并将每个字符转换为小写以确保不区分大小写。 

对于每个候选词，另一个频率数组称为`counts`已建成。 这允许恒定时间访问任何字母的频率。 

验证循环检查单词是否满足所有必需的计数。 如果任何字符频率不足，则该单词立即被拒绝。 

当找到有效单词时，仅当新单词严格较短时，算法才会更新答案。 这保留了关系的首次出现规则。 

最后，返回最短的有效单词。 

## 解决方案```go
func shortestCompletingWord(licensePlate string, words []string) string {
	required := make([]int, 26)

	for _, ch := range licensePlate {
		if ch >= 'a' && ch <= 'z' {
			required[ch-'a']++
		} else if ch >= 'A' && ch <= 'Z' {
			required[ch-'A']++
		}
	}

	answer := ""

	for _, word := range words {
		counts := make([]int, 26)

		for _, ch := range word {
			counts[ch-'a']++
		}

		valid := true

		for i := 0; i < 26; i++ {
			if counts[i] < required[i] {
				valid = false
				break
			}
		}

		if valid {
			if answer == "" || len(word) < len(answer) {
				answer = word
			}
		}
	}

	return answer
}
```Go 实现遵循与 Python 版本相同的逻辑。 一个小区别是 Go 不像 Python 那样方便地提供内置大小写标准化，因此在车牌处理期间会显式处理大写和小写检查。 

切片用于频率数组，并且由于字母表大小固定为 26，因此内存使用量保持不变。 

不存在整数溢出问题，因为在给定约束下所有计数都非常小。

 ## 边缘情况

 当车牌包含重复的字母时，就会出现一种重要的边缘情况。 例如，`"aA"`需要该字母出现两次`'a'`，不只是一个。 使用集合而不是频率计数的简单实现会错误地接受仅包含一个的单词`'a'`。 频率数组方法通过存储精确的计数来正确处理这个问题。 

另一个关键的边缘情况涉及大写字母。 该问题明确指出匹配应该不区分大小写。 如果没有标准化，字符就像`'S'`和`'s'`会受到不同的对待。 该实现在计数之前将所有车牌字母转换为小写，以确保一致的匹配行为。 

第三个重要的边缘情况是平局解决。 多个单词可以具有相同的最短有效长度。 该问题需要返回输入数组中最早出现的位置。 该实现通过仅在找到严格较短的单词时更新答案来保留此行为。 等长的单词不会取代当前的答案。 

最后的边缘情况涉及主要包含数字和空格的车牌。 例如，`"1 2 3 a"`只需要这封信`'a'`。 有缺陷的实现可能会意外地将数字处理为字符，或者在出现很少的字母时失败。 该算法明确检查`isalpha()`Python 中的字母范围和 Go 中的字母范围，确保只有字母字符影响要求。
