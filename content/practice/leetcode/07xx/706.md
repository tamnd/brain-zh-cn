 **难度：** 🟢简单
 **主题：** 数组、哈希表、链表、设计、哈希函数

 ## 解决方案

 ## 问题理解

 这个问题要求我们从头开始实现一个HashMap，而不使用任何内置的哈希表库。 换句话说，我们需要创建一个可以存储键值对的数据结构，允许根据键高效地插入、检索和删除值。 输入操作包括`put`,`get`， 和`remove`，并且我们必须支持最多 10,000 个键和值在该范围内的操作`[0, 10^6]`。 

预期输出为`get`是与键关联的值，或者`-1`如果密钥不存在。 这`put`操作要么插入一个新的`(key, value)`如果键已存在，则配对或更新值。 这`remove`操作将删除键及其值（如果存在）。 

关键约束和见解包括键是非负整数，最多可达一百万，这意味着一个简单的大小数组`10^6+1`可以，但可能空间效率低下。 此外，操作数量（最多`10^4`）允许每个操作接近恒定时间的解决方案。 要考虑的边缘情况包括多次插入相同的密钥、删除不存在的密钥或检索从未添加的密钥。 

## 方法

 暴力方法是使用简单的元组列表或键值对数组。 每个操作（`put`,`get`,`remove`）需要扫描列表来查找密钥，在最坏的情况下，每个操作的时间复杂度为 O(n)。 这是正确的，因为它为每个操作显式搜索和更新列表，但对于大量操作来说效率低下。 

最佳方法是使用存储桶数组并结合使用链表的单独链接来实现哈希表。 我们使用哈希函数将每个键映射到特定的存储桶索引，并通过在每个存储桶中维护一个链表来处理冲突。 这种方法允许`put`,`get`， 和`remove`假设哈希函数均匀分布键，则操作在平均情况下运行 O(1) 时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 将键值对存储在列表中； 需要线性搜索的操作|
 | 最佳 | 平均 O(1)，最坏 O(n) | O(n) | 使用桶数组和链表进行碰撞处理 |

 ## 算法演练

 1. 用固定数量的桶初始化哈希图，每个桶是一个空链表。 桶的数量通常选择素数以减少冲突。 
2. 实现一个哈希函数，使用模运算将键映射到存储桶索引：`bucket_index = key % number_of_buckets`。 
3.为了`put(key, value)`，计算桶索引。 如果桶中存在该键，则更新其值。 如果该键不存在，则附加一个新节点`(key, value)`到链接列表。 
4. 对于`get(key)`，计算桶索引并遍历该桶中的链表以查找具有给定键的节点。 如果找到则返回其值，否则返回`-1`。 
5. 对于`remove(key)`，计算桶索引并遍历链表定位带有key的节点。 如果找到，则从链表中删除该节点。 

**为什么起作用：** 哈希函数确保键分布在各个存储桶中，从而减少每个存储桶的平均元素数量。 每个存储桶中的链表处理冲突，确保所有键都可以正确存储和检索。 

## Python 解决方案```python
class ListNode:
    def __init__(self, key: int, value: int, next=None):
        self.key = key
        self.value = value
        self.next = next

class MyHashMap:

    def __init__(self):
        self.size = 1009  # prime number of buckets
        self.buckets = [None] * self.size

    def _hash(self, key: int) -> int:
        return key % self.size

    def put(self, key: int, value: int) -> None:
        index = self._hash(key)
        if not self.buckets[index]:
            self.buckets[index] = ListNode(key, value)
            return
        current = self.buckets[index]
        while True:
            if current.key == key:
                current.value = value
                return
            if not current.next:
                break
            current = current.next
        current.next = ListNode(key, value)

    def get(self, key: int) -> int:
        index = self._hash(key)
        current = self.buckets[index]
        while current:
            if current.key == key:
                return current.value
            current = current.next
        return -1

    def remove(self, key: int) -> None:
        index = self._hash(key)
        current = self.buckets[index]
        prev = None
        while current:
            if current.key == key:
                if prev:
                    prev.next = current.next
                else:
                    self.buckets[index] = current.next
                return
            prev, current = current, current.next
```在这个实现中，我们首先定义一个`ListNode`类来表示链表中的每个键值对。 这`MyHashMap`类初始化一个存储桶数组。 每种方法都使用哈希函数来定位正确的存储桶，然后迭代该存储桶中的链表以执行更新、检索或删除。 

## 解决方案```go
type ListNode struct {
    key, value int
    next       *ListNode
}

type MyHashMap struct {
    size    int
    buckets []*ListNode
}

func Constructor() MyHashMap {
    size := 1009
    buckets := make([]*ListNode, size)
    return MyHashMap{size: size, buckets: buckets}
}

func (this *MyHashMap) hash(key int) int {
    return key % this.size
}

func (this *MyHashMap) Put(key int, value int) {
    index := this.hash(key)
    if this.buckets[index] == nil {
        this.buckets[index] = &ListNode{key: key, value: value}
        return
    }
    current := this.buckets[index]
    for {
        if current.key == key {
            current.value = value
            return
        }
        if current.next == nil {
            break
        }
        current = current.next
    }
    current.next = &ListNode{key: key, value: value}
}

func (this *MyHashMap) Get(key int) int {
    index := this.hash(key)
    current := this.buckets[index]
    for current != nil {
        if current.key == key {
            return current.value
        }
        current = current.next
    }
    return -1
}

func (this *MyHashMap) Remove(key int) {
    index := this.hash(key)
    current := this.buckets[index]
    var prev *ListNode
    for current != nil {
        if current.key == key {
            if prev != nil {
                prev.next = current.next
            } else {
                this.buckets[index] = current.next
            }
            return
        }
        prev = current
        current = current.next
    }
}
```在 Go 中，我们使用指针作为链表节点。 这`Put`,`Get`， 和`Remove`方法镜像 Python 逻辑，显式处理空存储桶或头节点的 nil 指针。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 平均 O(1)，最坏 O(n) | 散列可确保平均情况下的恒定时间，如果所有键都碰撞到单个存储桶中，则会发生最坏的情况 |
 | 空间| O(n) | 每个插入的键一个节点，加上存储桶数组 |

 时间复杂度由每个桶的平均元素数量决定。 选择质数的桶有助于均匀地分配密钥。 空间复杂度与存储的密钥数量成线性关系。
