[LeetCode 第 798 题](https://leetcode.com/problems/smallest-rotation-with-highest-score/)

 **难度：** 🔴难
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们确定数组的最佳旋转`nums`以便结果数组获得尽可能高的分数，其中分数定义为旋转后小于或等于其索引的元素数量。 换句话说，在将数组旋转一些之后`k`, 位置处的元素`i`贡献 1 分，如果`nums[i] <= i`。 

输入是一个零索引的整数数组，其中每个元素位于`0`和`nums.length - 1`。 输出是一个整数`k`表示产生最大分数的最小旋转索引。 约束表明数组可以很大，最多`10^5`元素，这排除了单独计算所有可能旋转分数的暴力解决方案，因为这需要`O(n^2)`运营。 

重要的边缘情况包括已经按升序排列的数组、所有元素都相同的数组、多次旋转产生相同最大分数的数组以及长度为 1 的数组。该问题保证了边界内的有效输入，因此我们不需要处理负数或超出范围的值。 

## 方法

 蛮力方法涉及迭代所有可能的旋转`0`到`n-1`，应用旋转，然后通过根据索引检查每个元素来计算分数。 这实现起来很简单并且保证正确，但有时间复杂度`O(n^2)`因为每个`n`旋转需要检查所有`n`元素，这对于`n = 10^5`。 

最佳方法使用一个关键观察：我们可以跟踪旋转时分数的变化，而不是单独计算每次旋转的分数。 每个元素`nums[i]`为旋转贡献一分`k`在哪里`(i - k + n) % n >= nums[i]`，可以表示为模运算中的范围。 通过将这些范围的开始和结束记录为辅助数组中的“分数变化”并计算前缀和，我们可以确定给出最大分数的旋转`O(n)`时间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 旋转数组以获得所有 k 并每次计算分数 |
 | 最佳| O(n) | O(n) | 使用差异数组高效跟踪分数变化 |

 ## 算法演练

 1.初始化一个数组`change`长度`n`全为零。 该数组将跟踪分数在我们旋转时如何变化。 
2. 对于每个索引`i`在`nums`，计算旋转索引范围`[start, end)`其中分数贡献为`nums[i]`减少。 具体来说，如果`nums[i] > 0`，当旋转超过时分数会减少`(i - nums[i] + 1 + n) % n`。 
3. 更新`change`数组：增量`change[start]`并减少`change[end]`反映元素停止对分数做出贡献的范围。 
4. 迭代`change`数组，计算运行前缀和以跟踪每次旋转的总得分`k`。 
5. 记录遇到的最大分数和最小索引`k`就达到了这个目的。 
6.返回最小的`k`与最高分。 

**为什么有效**：每个元素都会在特定的旋转范围内对分数做出贡献。 通过使用差异数组和前缀和，我们可以有效地聚合所有个人贡献。 前缀和保证我们在 O(n) 时间内正确计算每次旋转的分数。 

## Python 解决方案```python
from typing import List

class Solution:
    def bestRotation(self, nums: List[int]) -> int:
        n = len(nums)
        change = [0] * n

        for i, num in enumerate(nums):
            start = (i - num + 1 + n) % n
            end = (i + 1) % n
            change[start] += 1
            change[end] -= 1
            if start >= end:
                change[0] += 1

        max_score = score = 0
        best_k = 0
        for k in range(n):
            score += change[k]
            if score > max_score:
                max_score = score
                best_k = k

        return best_k
```**说明**：我们首先创建一个`change`数组，用于跟踪旋转时每个数字对分数的影响。 对于每个数字，我们计算减少其得分贡献的旋转范围。 在调整模块化包装后，我们使用前缀和累积每次旋转的总得分，并返回给出最大得分的最小旋转。 

## 解决方案```go
func bestRotation(nums []int) int {
    n := len(nums)
    change := make([]int, n)

    for i, num := range nums {
        start := (i - num + 1 + n) % n
        end := (i + 1) % n
        change[start]++
        change[end]--
        if start >= end {
            change[0]++
        }
    }

    maxScore, score, bestK := 0, 0, 0
    for k := 0; k < n; k++ {
        score += change[k]
        if score > maxScore {
            maxScore = score
            bestK = k
        }
    }

    return bestK
}
```**Go 特定说明**：我们使用切片而不是数组进行动态分配。 模运算正确处理换行。 除了数据结构之外，不需要额外的数据结构`change`片。

 ## 边缘情况

 1. **单元素数组**：只有一个元素的数组，例如，`[0]`。 这可能会导致简单的模计算失败。 我们的实现可以处理它，因为`n = 1`确保模算术和循环正常工作。 
2. **所有元素相同**：像这样的数组`[0,0,0,0]`可能有多次旋转产生相同的最大分数。 该算法正确返回最小索引，因为我们初始化了`best_k`为 0 并仅在找到严格更高的分数时更新。 
3. **降序数组**：类似的数组`[4,3,2,1,0]`测试旋转逻辑是否正确处理负范围和模环绕。 计算中的模运算`start`确保范围正确换行，并且前缀和聚合正确识别最佳旋转。
