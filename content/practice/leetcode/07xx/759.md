[LeetCode 759 题](https://leetcode.com/problems/employee-free-time/)

 **难度：** 🔴难
 **主题：** 数组、扫描线、排序、堆（优先级队列）

 ## 解决方案

 ## 问题理解

 该问题要求我们根据一组员工的日程安排确定**共同的空闲时间间隔**。 每个员工都有一个不重叠的时间间隔列表，代表他们忙碌的时间。 我们的目标是找到**所有员工同时空闲**的时期，不包括任何零长度的间隔。 保证每位员工的排班安排有序，间隔严格在规定范围内`[0, 10^8]`。 

输入`schedule`是一个列表的列表`Interval`对象。 例如，`schedule[i]`代表员工`i`的工作时间，以及`schedule[i][j]`是一个区间`[start, end]`对于该员工。 输出是一个列表`Interval`代表**没有员工忙碌**的空闲时间的对象。 区间延伸至无穷大（例如`[-inf, start]`或者`[end, inf]`）被忽略。 

关键点包括间隔在**同一员工**内不会重叠，但**在员工之间**可以重叠。 需要注意的边缘情况包括所有员工总是忙碌而没有任何间隙的时间表、只有一名员工的时间表以及接触但不重叠的时间间隔（例如`[1,3]`和`[3,5]`）。 

## 方法

 ### 蛮力

 蛮力方法将涉及遍历所有员工从最小开始到最大结束的所有可能时间点，并检查哪些时间对所有人都是免费的。 这需要创建一个时间表并标记每个员工的忙碌时间，然后找到连续的空闲时段。 虽然正确，但效率非常低，因为时间范围可能长达`10^8`，使得线性扫描变得不切实际。 

### 最佳方法

 关键的观察是我们只关心间隔的**起点和终点**。 通过将所有员工日程安排为单个时间间隔列表并按开始时间排序，我们可以合并重叠的时间间隔以获得所有繁忙时间的并集。 合并后，这些合并间隔之间的间隙代表**共同空闲时间**。 这种方法利用了这样一个事实：员工的日程安排在内部已经不重叠，因此合并既简单又高效。 

我们还可以使用**优先级队列（最小堆）**方法，该方法按排序顺序合并多个员工之间的间隔，而无需先展平整个列表。 这两种方法都有效地将问题简化为**合并间隔**和查找间隙。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(范围) ~ O(10^8) | O（范围）| 标记各个时代的时间线，不切实际|
 | 最佳（排序和合并）| O(N log N)，N = 总间隔 | O(N) | 展平并合并间隔，然后找到间隙 |
 | 最优（堆）| O(N log k)，N = 总间隔，k = #employees | O(k) | 使用堆合并员工之间的排序间隔 |

 ## 算法演练

 1. **扁平化时间表**：迭代每个员工的间隔列表并将所有间隔收集到一个列表中。 这会将列表列表转换为单个列表，以便于处理。 
2. **排序间隔**：按照开始时间对所有间隔进行排序。 排序确保当我们合并间隔时，我们可以一次性完成。 
3. **合并重叠区间**：初始化一个变量`prev`与第一个间隔。 迭代排序列表。 如果当前间隔开始于`prev.end`，有一个自由区间`prev.end`到`current.start`。 更新`prev`如果当前间隔超出，则为当前间隔的结束`prev.end`。 
4. **收集间隙**：每次我们检测到当前间隔开始于`prev.end`，追加一个新的`Interval(prev.end, current.start)`到结果列表。 这代表了共同的空闲时间。 
5. **返回结果**：迭代完所有区间后，返回空闲区间列表。 

**为什么有效**：通过合并员工的所有繁忙时间间隔，我们获得了繁忙时段的连续时间线。 这些合并的时间间隔之间的间隙正是**没有员工工作**的时间，满足普通空闲时间的要求。 排序确保正确的顺序，合并确保重叠的繁忙间隔不会产生错误的间隙。 

## Python 解决方案```python
"""
# Definition for an Interval.
class Interval:
    def __init__(self, start: int = None, end: int = None):
        self.start = start
        self.end = end
"""

class Solution:
    def employeeFreeTime(self, schedule: '[[Interval]]') -> '[Interval]':
        # Flatten all intervals from all employees
        all_intervals = [iv for emp in schedule for iv in emp]
        
        # Sort intervals by start time
        all_intervals.sort(key=lambda x: x.start)
        
        # Merge intervals and find gaps
        free_times = []
        prev = all_intervals[0]
        
        for curr in all_intervals[1:]:
            if curr.start > prev.end:
                # Gap found
                free_times.append(Interval(prev.end, curr.start))
                prev = curr
            else:
                # Merge overlapping intervals
                prev.end = max(prev.end, curr.end)
        
        return free_times
```**解释**：首先，我们展平所有间隔以便于处理。 排序确保我们按时间顺序处理间隔。 合并步骤跟踪前一个间隔的结束并找到空闲时间的间隙。 合并重叠以避免错误间隙。 最后，我们返回所有检测到的空闲间隔。 

## 解决方案```go
/**
 * Definition for an Interval.
 * type Interval struct {
 *     Start int
 *     End   int
 * }
 */

import "sort"

func employeeFreeTime(schedule [][]*Interval) []*Interval {
    // Flatten all intervals
    allIntervals := []*Interval{}
    for _, emp := range schedule {
        allIntervals = append(allIntervals, emp...)
    }
    
    // Sort intervals by start time
    sort.Slice(allIntervals, func(i, j int) bool {
        return allIntervals[i].Start < allIntervals[j].Start
    })
    
    freeTimes := []*Interval{}
    prev := allIntervals[0]
    
    for _, curr := range allIntervals[1:] {
        if curr.Start > prev.End {
            // Gap found
            freeTimes = append(freeTimes, &Interval{Start: prev.End, End: curr.Start})
            prev = curr
        } else {
            // Merge overlapping intervals
            if curr.End > prev.End {
                prev.End = curr.End
            }
        }
    }
    
    return freeTimes
}
```**Go 特定注释**：我们处理切片`append`并排序`sort.Slice`。 合并更新`prev`就地参考。 Go 需要对时间间隔进行仔细的指针管理，这与自然处理对象引用的 Python 不同。 

## 工作示例

 ### 示例 1

 输入：`[[[1,2],[5,6]],[[1,3]],[[4,10]]]`展平间隔：`[1,2],[5,6],[1,3],[4,10]`排序间隔：`[1,2],[1,3],[4,10],[5,6]`→ 按开始-结束合并：

 - 合并`[1,2]`和`[1,3]`→`[1,3]`- 差距`[3,4]`→ 空闲时间
 - 合并`[4,10]`和`[5,6]`→`[4,10]`输出：`[[3,4]]`### 示例 2

 输入：`[[[1,3],[6,7]],[[2,4]],[[2,5],[9,12]]]`展平：`[1,3],[6,7],[2,4],[2,5],[9,12]`排序：`[1,3],[2,4],[2,5],[6,7],[9,12]`合并步骤：

 - 合并`[1,3],[2,4],[2,5]`→`[1,5]`- 差距`[5,6]`→ 空闲时间
 - 合并`[6,7]`→`[6,7]`- 差距`[7,9]`→ 空闲时间
 - 合并`[9,12]`→`[9,12]`输出：`[[5,6],[7,9]]`## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N log N) | O(N log N) | 对所有区间进行排序占主导地位，N = 总区间 |
 | 空间| O(N) | 间隔的扁平列表加上结果列表 |

 展平需要 O(N) 空间，排序需要 O(N log N)。 合并循环是O(N)，因此整体复杂度主要由排序决定。
