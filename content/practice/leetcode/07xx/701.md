[LeetCode 701 题](https://leetcode.com/problems/insert-into-a-binary-search-tree/)

 **难度：** 🟡 中等
 **主题：** 树、二叉搜索树、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们将一个新值插入到现有的二叉搜索树（缩写为 BST）中，同时保留 BST 属性。 

二叉搜索树是具有特殊排序规则的二叉树：

 - 节点左子树中的每个值都小于该节点的值。 
- 节点右子树中的每个值都大于该节点的值。 

您将得到：

 -`root`，这是 BST 的根节点
 -`val`，必须插入的整数值

 您的任务是在将新值插入到正确位置后返回更新后的 BST 的根。 

该问题保证：

 - 所有节点值都是唯一的
 -`val`树中尚不存在

 这种保证简化了逻辑，因为我们永远不需要处理重复项。 

插入过程遵循 BST 排序规则。 从根开始：

 - 如果`val`小于当前节点，移至左子节点。 
- 如果`val`大于当前节点，移动到右子节点。 
- 继续直到出现空位置（`None`或者`nil`）被发现。 
- 在那里插入新节点。 

一个重要的细节是，插入后可能存在多个有效的 BST 结构。 发生这种情况是因为某些树可以以不同的方式重新排列，同时仍然满足 BST 排序。 该问题接受任何有效的 BST。 

这些约束告诉我们一些重要的事情：

 - 树最多可以包含`10^4`节点，因此首选高效的遍历。 
- 节点值可以是大的负整数或正整数，但标准整数类型就足够了。 
- 由于树已经是 BST，我们应该利用该属性而不是扫描整个树。 

一些边缘情况很重要：

 - 树最初可能是空的。 
- 新值可能成为树深处的叶节点。 
- BST 可能高度不平衡，表现得像一个链表。 
- 插入的值可能成为最左边或最右边的节点。 

忽略 BST 排序的简单实现会浪费时间探索不必要的分支。 

## 方法

 ### 蛮力方法

 暴力策略是完全忽略 BST 属性。 我们可以遍历树中的每个节点，直到找到可以插入值的有效空位置。 

例如，我们可能会执行完整的 DFS 遍历并手动检查可能的插入位置。 

这种方法之所以有效，是因为最终每个节点都会被检查，并且可以找到正确的插入点。 然而，它的效率很低，因为 BST 结构已经提供了方向信息，告诉我们到底要去哪里。 

我们不需要探索每个节点的左子树和右子树，而是只需要遵循一条路径。 

在最坏的情况下，即使插入位置在遍历的早期就很明显，暴力解决方案也会触及每个节点。 

### 最佳方法

 关键的观察是 BST 排序完全决定了插入路径。 

在每个节点：

 - 如果`val < node.val`，新值必须属于左子树中的某个位置。 
- 如果`val > node.val`，新值必须属于右子树中的某个位置。 

这意味着我们永远不需要搜索树的两侧。 

我们只需从根向下走，直到找到应附加新节点的缺失子位置。 

这产生了一种有效的解决方案，因为仅遍历一条从根到叶的路径。 

可以递归或迭代地编写实现。 递归版本很简洁并且自然地映射到 BST 定义。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 不必要地遍历整棵树 |
 | 最佳| O(h) | O(h) 递归，O(1) 迭代 | 仅遍历一条 BST 路径，其中`h`是树高 |

 ## 算法演练

 ### 递归 BST 插入

 1. 从根节点开始。 

根是当前位置，我们决定新值属于左子树还是右子树。 
2. 检查当前节点是否为空。 

如果当前节点是`None`，这意味着我们已经到达了正确的插入位置。 创建并返回一个新节点，其中包含`val`。 
3.比较`val`与当前节点的值。 

如果`val`较小时，BST 性质保证正确的插入位置必须存在于左子树中的某个位置。 
4. 递归插入到左子树中。 

调用插入函数`root.left`，然后将返回的子树分配回`root.left`。 
5. 否则，插入到右子树中。 

由于重复是不可能的，如果`val`不是更小，一定是更大。 递归插入到`root.right`。 
6. 返回当前根。 

在树的更深处完成插入后，返回当前节点不变，以便父链接保持正确连接。 

### 为什么它有效

 该算法之所以有效，是因为它在每个节点都保留了 BST 不变量：

 - 所有左子树值仍然小于该节点。 
- 所有右子树值仍然大于节点。 

递归搜索遵循的路径与 BST 查找目标值所遵循的路径完全相同。 当找到空位置时，将节点插入那里可以保持整个树的正确顺序。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def insertIntoBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        if root is None:
            return TreeNode(val)

        if val < root.val:
            root.left = self.insertIntoBST(root.left, val)
        else:
            root.right = self.insertIntoBST(root.right, val)

        return root
```实施从基本案例开始。 如果当前节点是`None`，我们已经到达插入点，所以一个新的`TreeNode`创建并返回。 

接下来通过代码对比`val`与当前节点的值。 

如果新值较小，则继续递归到左子树。 返回的子树根被重新分配给`root.left`。 这种重新分配很重要，因为递归调用可能会创建一个全新的节点。 

如果新值更大，则以相同的方式递归到右子树。 

最后，返回当前根，以便递归调用正确重新连接，同时展开回原始根。 

代码直接反映了 BST 的性质，使其简洁且易于推理。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func insertIntoBST(root *TreeNode, val int) *TreeNode {
    if root == nil {
        return &TreeNode{Val: val}
    }

    if val < root.Val {
        root.Left = insertIntoBST(root.Left, val)
    } else {
        root.Right = insertIntoBST(root.Right, val)
    }

    return root
}
```Go 实现遵循与 Python 版本完全相同的递归结构。 

主要区别在于指针处理。 在Go中，树节点是通过指针操作的，因此使用以下命令创建新节点`&TreeNode{Val: val}`。 

这`nil`Go 中的关键字的作用与`None`在Python中。 

由于 Go 使用显式结构体字段和指针，子树更新写为：```go
root.Left = insertIntoBST(root.Left, val)
```对于右子树也是如此。 

不需要特殊的溢出处理，因为问题约束完全适合 Go 的整数范围。

 ## 边缘情况

 ### 空树

 当原始 BST 为空时，会出现一种重要的边缘情况。 在这种情况下，`root`是`None`或者`nil`。 

有缺陷的实现可能会假设根始终存在并尝试访问`root.val`，导致错误。 

该解决方案立即使用基本情况处理此问题：```
if root is None:
    return TreeNode(val)
```这正确地创建了树中的第一个节点。 

### 高度倾斜的树

 BST 可能会变得完全不平衡，表现得像链表。 

例如：```
1
 \
  2
   \
    3
```插入另一个大值会强制遍历每个节点。 

这种情况很重要，因为它产生的最坏情况时间复杂度为`O(n)`。 

该实现仍然可以正常工作，因为它只是跟随子指针，直到`None`孩子被发现了。 

### 作为最左或最右节点插入

 插入的值可能成为整个BST中的最小值或最大值。 

例如：

 - 插入`0`进入一棵树，其最小值为`1`- 插入`100`进入一棵树，其最大值为`50`有缺陷的实现可能会过早地错误地停止遍历。 

递归逻辑避免了这个问题，因为无论插入点有多深，比较都会继续，直到到达空子位置。
