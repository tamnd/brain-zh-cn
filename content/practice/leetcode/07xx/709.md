[LeetCode 第 709 题](https://leetcode.com/problems/to-lower-case/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们将字符串中的每个大写英文字母转换为其对应的小写字母。 任何已经是小写的字符，或者根本不是字母字符，都应该保持不变。 

输入是一个字符串`s`包含可打印的 ASCII 字符。 可打印 ASCII 包括大写字母、小写字母、数字、标点符号、空格和符号。 该任务特别关注来自的大写英文字母`'A'`到`'Z'`。 

预期输出是一个新字符串，其中每个大写字母都已替换为相应的小写字母。 例如，`'H'`变成`'h'`,`'L'`变成`'l'`， 等等。 

限制非常小：

 -`1 <= s.length <= 100`-`s`包含可打印的 ASCII 字符

 These constraints tell us that performance is not a major concern. Even an inefficient solution would work comfortably within the limits. However, the problem is intended to test basic string manipulation and character processing.

 Several edge cases are important to think about before implementation:

 - 字符串可能已经完全小写。 
- 字符串只能包含大写字母。 
- The string may contain digits or symbols that should remain unchanged.
 - 字符串长度可以小至 1。 
- Mixed strings with uppercase, lowercase, numbers, and punctuation should all be handled correctly.

 该问题保证输入仅包含可打印的 ASCII 字符，因此我们无需担心 Unicode 大小写规则或国际字母表。 

## 方法

 ### 蛮力方法

 A straightforward brute-force solution is to iterate through every character in the string and manually check whether it is an uppercase letter. If it is uppercase, we convert it into lowercase using ASCII arithmetic. 否则，我们保持不变。 

In ASCII encoding, uppercase and lowercase English letters are separated by a fixed distance:

 -`'A'`到`'Z'`有 ASCII 值`65`到`90`-`'a'`到`'z'`有 ASCII 值`97`到`122`对应的大写字母和小写字母之间的差异始终是`32`。 例如：

-`'A'`→`'a'`-`65 + 32 = 97`利用这个属性，我们可以手动转换大写字母。 

这种方法是正确的，因为每个字符都是独立处理的，并且 ASCII 转换规则保证每个大写字母映射到正确的小写版本。 

尽管这被称为暴力方法，但它对于问题约束来说已经足够有效了。 

### 最佳方法

 最佳解决方案是使用编程语言提供的内置小写转换功能。 

Python 和 Go 等语言已经提供了优化的字符串转换实用程序：

 - 蟒蛇：`s.lower()`- 去：`strings.ToLower(s)`这些内置方法在内部有效地处理转换并清楚地表达代码的意图。 

关键的见解是该问题不需要我们手动实现 ASCII 转换。 由于目标只是将大写字母转换为小写字母，因此标准库提供了最干净、最可维护的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 手动检查并转换大写字符 |
 | 最佳 | O(n) | O(n) | 使用内置小写转换实用程序 |

 ## 算法演练

 ### 最优算法

 1.接收输入字符串`s`。 
2. 对字符串调用语言内置的小写转换函数。 

该函数扫描字符串中的每个字符并将大写字母转换为小写字母，同时保持所有其他字符不变。 
3. 返回转换后的字符串。 

### 为什么它有效

 该算法之所以有效，是因为每个大写英文字母都有一个明确定义的小写字母。 内置的小写转换函数将此映射一致地应用于字符串中的每个字符。 由于非大写字符保留不变，因此生成的字符串完全符合问题要求。 

## Python 解决方案```python
class Solution:
    def toLowerCase(self, s: str) -> str:
        return s.lower()
```实现故意很简单，因为 Python 已经提供了可靠的内置小写转换方法。 

该方法接收输入字符串`s`并立即致电`s.lower()`。 

这`lower()`方法创建并返回一个新字符串，其中每个大写字母都已转换为小写。 已经是小写的字符以及数字和标点符号保持不变。 

这直接遵循前面描述的最优算法。 

## 解决方案```go
package main

import "strings"

func toLowerCase(s string) string {
    return strings.ToLower(s)
}
```Go 解决方案使用`strings.ToLower`标准库中的函数。 

与 Python 不同，Go 需要导入`strings`显式封装。 

该函数接受输入字符串`s`并返回小写转换后的版本。 

Go 特有的一个重要细节是字符串是不可变的，就像 Python 中一样。 这`strings.ToLower`因此，函数创建并返回一个新字符串，而不是修改原始字符串。 

在此问题中，无需担心整数溢出或 nil 处理，因为输入始终是有效字符串，并且操作纯粹基于字符。

 ## 边缘情况

 ### 字符串已经是小写

 输入字符串可能已仅包含小写字母。 有缺陷的实现可能会不必要地改变字符或产生不正确的输出。 当前的实现可以正确处理此问题，因为转换函数不会更改小写字符。 

### 包含非字母字符的字符串

 输入可能包含数字、标点符号或空格。 这些字符没有大写或小写形式，因此它们必须保持原样。 内置小写转换函数可以正确保留这些字符而不进行修改。 

### 单字符串

 最小有效输入的长度为 1。粗心的实现可能会因索引假设或循环逻辑而失败。 即使对于单字符字符串，所提供的解决方案也能正常工作，因为转换函数自然可以处理任何有效长度的字符串。
