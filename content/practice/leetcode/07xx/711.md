[LeetCode 711 题](https://leetcode.com/problems/number-of-distinct-islands-ii/)

 **难度：** 🔴难
 **主题：** 数组、哈希表、深度优先搜索、广度优先搜索、并查找、排序、矩阵、哈希函数

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出一个二元矩阵，其中每个单元格包含`0`或者`1`。 值为`1`代表土地，而`0`代表水。 岛屿是通过在四个基本方向上连接相邻的陆地单元而形成的：上、下、左、右。 

任务不仅仅是统计岛屿数量。 相反，我们必须确定网格中存在多少_不同的岛屿形状_。 

如果两个岛屿可以使用以下任意组合将一个岛转换为另一个岛，则认为两个岛是相同的：

 - 旋转 90、180 或 270 度
 - 水平或垂直轴的反射

 这意味着在原始方向上看起来不同的岛屿在变换后可能仍然呈现相同的形状。 

输入尺寸比较小，最多两个维度`50`。 由于网格最多包含`2500`对于单元格，我们可以对整个矩阵执行 DFS 或 BFS 遍历，并对岛坐标执行几何归一化。 

从约束和问题定义中可以得出一些重要的结论：

 - 岛屿只能包含一个单元格。 
- 多个岛屿可以共享相同的形状，但出现在不同的位置。 
- 平移并不重要，这意味着在网格中其他位置移动的相同形状仍然被认为是相同的。 
- 旋转和反射也必须被视为等效。 
- 网格保证仅包含有效的二进制值。 

一些边缘情况很容易破坏简单的实现：

 - 单细胞岛，因为每次转化都会产生相同的结果。 
- 对称岛，其中多个变换折叠成相同的坐标集。 
- 形状不规则的岛屿，必须仔细进行标准化。 
- DFS 期间的遍历顺序不同，如果排序不当，可能会产生不一致的坐标序列。 

因此，主要的挑战不是发现岛屿，而是生成岛屿形状的规范表示，该形状在所有有效的旋转和反射中保持相同。 

## 方法

 ### 蛮力方法

 暴力解决方案首先使用 DFS 或 BFS 提取每个岛屿。 对于每个岛屿，我们可以将其与所有先前发现的岛屿进行明确的比较。 

为了确定两个岛是否相等，我们将生成所有八种可能的变换：

 1. 原创
 2. 旋转90度
 3.旋转180度
 4.旋转270度
 5.水平反射
 6.垂直反射
 7. 反射加旋转90度
 8. 反射加旋转270度

 对于每一对岛屿，我们将检查标准化后是否有任何转换后的版本匹配。 

这种方法是正确的，因为它详尽地测试了所有法律转换。 然而，它变得昂贵，因为每个新岛屿可能需要与许多先前发现的岛屿进行比较，并且每次比较本身都涉及多个坐标转换和排序操作。 

在最坏的情况下，如果有很多岛屿，成对比较就会变得低效。 

### 最佳方法

 关键的见解是我们实际上不需要成对比较岛屿。 

相反，对于每个岛屿，我们可以计算_规范标准化形式_。 任何两个等效的岛屿都会产生完全相同的规范表示。 

该过程的工作原理如下：

 1.提取属于一个岛屿的所有坐标。 
2. 生成这些坐标的所有八个变换。 
3. 通过移动每个变换来标准化它，使最小坐标变为`(0, 0)`。 
4. 对标准化坐标进行排序。 
5. 在八种可能性中选择字典顺序最小的表示形式。 

无论平移、旋转或反射如何，这种规范表示都唯一地标识了岛的形状。 

一旦我们有了规范形式，问题就减少到计算哈希集中不同的字符串或元组。 

### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k² * s log s) | O(k² * s log s) | O(s) | 将每个岛屿与其他岛屿进行比较 |
 | 最佳 | O(m * n * log s) | O(m * n) | 使用规范标准化和散列 |

 在哪里：

-`k`是岛屿的数量
 -`s`是一个岛屿的大小
 -`m * n`是细胞总数

 ## 算法演练

 1.逐个单元格地遍历网格。 

每当我们遇到陆地细胞（`1`），我们开始 DFS 遍历来收集属于该岛的所有坐标。 
2. 在 DFS 过程中，记录相对于起始单元格的岛屿坐标。 

使用相对坐标消除了对绝对网格位置的依赖。 例如，如果第一个单元格是`(r0, c0)`，每个其他坐标存储为`(r - r0, c - c0)`。 
3. 收集岛屿的所有坐标后，生成所有八个变换。 

对于每个点`(x, y)`，变换为：

 -`( x,  y)`-`( x, -y)`-`(-x,  y)`-`(-x, -y)`-`( y,  x)`-`( y, -x)`-`(-y,  x)`-`(-y, -x)`这些共同代表所有旋转和反射。 
4. 标准化每个变换后的坐标集。 

由于平移并不重要，因此移动每个变换后的形状，使其最小坐标变为`(0, 0)`。 

这是通过从所有坐标中减去最小行值和最小列值来完成的。 
5. 对标准化坐标进行排序。 

即使形状相同，岛屿之间的 DFS 遍历顺序也可能不同。 排序保证了顺序的一致性。 
6. 将标准化坐标转换为元组表示。 

这使得形状可散列并且适合插入到集合中。 
7. 选择字典顺序最小的转换表示。 

多个变换对应同一个岛屿。 选择最小的一个可以确保所有等效的岛屿映射到相同的规范形式。 
8. 将规范表示插入集合中。 

由于集合会自动消除重复项，因此最终答案只是集合的大小。 

### 为什么它有效

 每个岛屿变换都保留相对结构。 通过生成所有合法转换并选择唯一的规范表示，我们确保任何两个等效岛屿都标准化为完全相同的形式。 

归一化期间平移差异消失，排序后遍历顺序差异消失，几何等价通过变换生成处理。 

因此，当且仅当两个岛在旋转和反射下属于同一等价类时，它们才被视为相同。 

## Python 解决方案```python
from typing import List, Tuple

class Solution:
    def numDistinctIslands2(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        cols = len(grid[0])

        visited = [[False] * cols for _ in range(rows)]

        def dfs(r: int, c: int, base_r: int, base_c: int,
                cells: List[Tuple[int, int]]) -> None:
            if (
                r < 0 or r >= rows or
                c < 0 or c >= cols or
                visited[r][c] or
                grid[r][c] == 0
            ):
                return

            visited[r][c] = True
            cells.append((r - base_r, c - base_c))

            dfs(r + 1, c, base_r, base_c, cells)
            dfs(r - 1, c, base_r, base_c, cells)
            dfs(r, c + 1, base_r, base_c, cells)
            dfs(r, c - 1, base_r, base_c, cells)

        def normalize(cells: List[Tuple[int, int]]) -> Tuple[Tuple[int, int], ...]:
            transformations = [[] for _ in range(8)]

            for x, y in cells:
                transformed = [
                    ( x,  y),
                    ( x, -y),
                    (-x,  y),
                    (-x, -y),
                    ( y,  x),
                    ( y, -x),
                    (-y,  x),
                    (-y, -x),
                ]

                for i in range(8):
                    transformations[i].append(transformed[i])

            normalized_forms = []

            for shape in transformations:
                shape.sort()

                min_x = shape[0][0]
                min_y = shape[0][1]

                normalized = []

                for x, y in shape:
                    normalized.append((x - min_x, y - min_y))

                normalized_forms.append(tuple(normalized))

            return min(normalized_forms)

        distinct_shapes = set()

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1 and not visited[r][c]:
                    cells = []
                    dfs(r, c, r, c, cells)

                    canonical = normalize(cells)
                    distinct_shapes.add(canonical)

        return len(distinct_shapes)
```实施过程首先扫描网格以查找未访问的陆地单元。 一旦发现新岛屿，DFS 就会收集属于该岛屿的所有坐标。 

坐标是相对于起始单元格存储的，这立即消除了位置依赖性。 

这`normalize`功能是解决方案的核心。 它构建了该岛的所有八个转变。 每个变换后的形状都经过排序和移位，使其最小坐标变为`(0, 0)`。 

由于每个等效岛屿最终都会产生相同的字典顺序最小标准化表示，因此将这些规范形式插入到集合中会自动删除重复项。 

最后，返回集合的大小。 

## 解决方案```go
package main

import (
	"sort"
	"strconv"
	"strings"
)

func numDistinctIslands2(grid [][]int) int {
	rows := len(grid)
	cols := len(grid[0])

	visited := make([][]bool, rows)
	for i := range visited {
		visited[i] = make([]bool, cols)
	}

	type Point struct {
		x int
		y int
	}

	var dfs func(int, int, int, int, *[]Point)

	dfs = func(r, c, baseR, baseC int, cells *[]Point) {
		if r < 0 || r >= rows || c < 0 || c >= cols {
			return
		}

		if visited[r][c] || grid[r][c] == 0 {
			return
		}

		visited[r][c] = true

		*cells = append(*cells, Point{r - baseR, c - baseC})

		dfs(r+1, c, baseR, baseC, cells)
		dfs(r-1, c, baseR, baseC, cells)
		dfs(r, c+1, baseR, baseC, cells)
		dfs(r, c-1, baseR, baseC, cells)
	}

	normalize := func(cells []Point) string {
		transformations := make([][]Point, 8)

		for _, p := range cells {
			x := p.x
			y := p.y

			transformed := []Point{
				{x, y},
				{x, -y},
				{-x, y},
				{-x, -y},
				{y, x},
				{y, -x},
				{-y, x},
				{-y, -x},
			}

			for i := 0; i < 8; i++ {
				transformations[i] = append(transformations[i], transformed[i])
			}
		}

		forms := make([]string, 0)

		for _, shape := range transformations {
			sort.Slice(shape, func(i, j int) bool {
				if shape[i].x == shape[j].x {
					return shape[i].y < shape[j].y
				}
				return shape[i].x < shape[j].x
			})

			minX := shape[0].x
			minY := shape[0].y

			var builder strings.Builder

			for _, p := range shape {
				builder.WriteString(
					strconv.Itoa(p.x-minX) +
						"," +
						strconv.Itoa(p.y-minY) +
						";",
				)
			}

			forms = append(forms, builder.String())
		}

		sort.Strings(forms)

		return forms[0]
	}

	distinct := make(map[string]bool)

	for r := 0; r < rows; r++ {
		for c := 0; c < cols; c++ {
			if grid[r][c] == 1 && !visited[r][c] {
				cells := []Point{}

				dfs(r, c, r, c, &cells)

				canonical := normalize(cells)

				distinct[canonical] = true
			}
		}
	}

	return len(distinct)
}
```Go 实现遵循与 Python 版本相同的算法结构。 由于 Go 元组本身并不存在，因此岛表示被编码为字符串。 

切片用于坐标存储，并且`sort.Slice`为转换后的坐标提供字典顺序。 

Go 没有使用 Python 的元组哈希，而是使用`map[string]bool`追踪独特的典型岛屿形态。 

由于坐标值仍然很小，因此不必担心整数溢出。

                    (-x,  y),

 ## 边缘情况

 ### 单细胞岛

 仅由一个陆地单元组成的岛屿是一种重要的极端情况，因为每次旋转和反射都会产生相同的坐标集。 有缺陷的标准化例程可能会意外地对大小为 1 的岛屿产生重复或格式错误的转换。 

此实现可以自然地处理这种情况，因为所有转换都归一化为`((0,0))`，仅在集合中插入一次。 

### 对称岛屿

 有些岛屿在一定的旋转或反射下是对称的。 例如，方形岛屿经过多次变换后仍保持不变。 

如果实现没有一致地对坐标进行排序和规范化，对称岛可能会错误地生成多个规范形式。 

该解决方案通过对每个转换后的坐标列表进行排序并始终选择字典顺序最小的表示来避免此问题。 

### 不同DFS遍历顺序的岛屿

 根据起始位置或递归访问顺序，可以以不同的顺序遍历两个相同的岛屿。 

如果在比较之前不对坐标进行排序，则相同的形状可能会出现不同，因为坐标是以不同的顺序收集的。 

该实现通过在标准化和规范化之前对每个变换后的形状进行排序来解决这个问题，从而保证确定性表示，而不管遍历顺序如何。
