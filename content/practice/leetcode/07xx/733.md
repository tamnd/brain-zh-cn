 **难度：** 🟢简单
 **主题：** 数组、深度优先搜索、广度优先搜索、矩阵

 ## 解决方案

 ## 问题理解

 问题是要求我们在表示图像的 2D 网格上模拟**洪水填充**操作。 网格中的每个单元格都包含一个表示像素颜色的整数。 给你一个起始像素`(sr, sc)`和目标颜色`color`。 目标是将起始像素和所有**相同原始颜色**的连接像素的颜色更改为新颜色。 连接被定义**仅在四个基本方向**（上、下、左、右），而不是对角线。 

输入由图像网格组成`image`, 起始行`sr`，起始列`sc`，以及新的`color`。 输出是执行洪水填充后修改后的图像。 

约束告诉我们图像最多可以是`50x50`，相对较小，并且像素值是小于216的非负整数。这意味着我们可以使用**DFS或BFS**，而不必担心大多数语言中的递归深度或内存溢出。 

重要的边缘情况包括：

 - 起始像素已经是目标颜色。 洪水填充不应**不无限循环**或不必要地覆盖像素。 
- 图像包含**未连接**的起始颜色的孤立像素； 这些应该保持不变。 
- 最小尺寸图像，例如`1x1`应该优雅地处理。 

## 方法

 ### 蛮力方法

 一种简单的方法是扫描整个图像，对于具有原始起始颜色的每个像素，递归地检查所有邻居并更新它们的颜色。 虽然这最终会填充正确的区域，但效率很低，因为它不能有效地跟踪**访问的像素**并且可能多次重新访问像素，从而导致不必要的计算。 

### 最佳方法

 最佳方法利用**深度优先搜索 (DFS)** 或 **广度优先搜索 (BFS)**。 从给定的像素开始`(sr, sc)`，我们可以递归地（DFS）或迭代地（BFS）探索相同颜色的连接像素。 关键的见解是当像素与原始颜色不匹配或超出范围时**停止递归或迭代**。 另外，如果起始像素已经有了目标颜色，我们可以立即返回图像，避免多余的操作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(m * n) | 扫描每个像素，可能会重访多次 |
 | 最优（DFS/BFS）| O(m * n) | O(m * n) | 仅访问相同颜色的连接像素一次 |

 ## 算法演练

 1. 检索起始像素处的原始颜色`(sr, sc)`。 如果已经等于目标`color`，立即返回图像。 
2. 定义辅助函数`dfs(r, c)`这将执行递归 DFS。 该函数将：

 - 检查是否`(r, c)`超出范围。 如果是这样，请返回。 
- 检查像素是否位于`(r, c)`是原来的颜色。 如果没有，请返回。 
- 更新像素`(r, c)`到新颜色。 
- 递归调用`dfs`对于四个邻居中的每一个：向上`(r-1, c)`， 向下`(r+1, c)`， 左边`(r, c-1)`， 正确的`(r, c+1)`。 
3.通过调用启动DFS`dfs(sr, sc)`。 
4. 返回修改后的图像。 

**工作原理：** DFS 确保通过相同原始颜色连接到起始像素的每个像素都被访问一次并更新。 不变的是，在访问一个像素之后，该像素的原始颜色的所有可到达的像素最终也将被访问和更新。 

## Python 解决方案```python
from typing import List

class Solution:
    def floodFill(self, image: List[List[int]], sr: int, sc: int, color: int) -> List[List[int]]:
        original_color = image[sr][sc]
        if original_color == color:
            return image
        
        def dfs(r: int, c: int):
            if r < 0 or r >= len(image) or c < 0 or c >= len(image[0]):
                return
            if image[r][c] != original_color:
                return
            
            image[r][c] = color
            dfs(r-1, c)
            dfs(r+1, c)
            dfs(r, c-1)
            dfs(r, c+1)
        
        dfs(sr, sc)
        return image
```**实现演练：** 我们首先检查起始像素是否已经是目标颜色。 这`dfs`函数在更新像素和递归访问邻居之前处理边界和颜色检查。 这确保了仅更新相同原始颜色的连接像素。 递归完成后，返回修改后的图像。 

## 解决方案```go
func floodFill(image [][]int, sr int, sc int, color int) [][]int {
    originalColor := image[sr][sc]
    if originalColor == color {
        return image
    }
    
    var dfs func(r, c int)
    dfs = func(r, c int) {
        if r < 0 || r >= len(image) || c < 0 || c >= len(image[0]) {
            return
        }
        if image[r][c] != originalColor {
            return
        }
        
        image[r][c] = color
        dfs(r-1, c)
        dfs(r+1, c)
        dfs(r, c-1)
        dfs(r, c+1)
    }
    
    dfs(sr, sc)
    return image
}
```**Go 特定注释：** Go 使用函数变量进行递归（`var dfs func(...)`）。 边界和颜色检查与 Python 相同。 切片索引自然地处理矩阵。 The main difference is explicit declaration of function type and the syntax for recursion.
