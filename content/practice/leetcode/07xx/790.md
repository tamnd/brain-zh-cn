 **主题：** 动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们计算完全平铺一个的方法的数量`2 x n`使用两种类型的瓷砖的棋盘：多米诺骨牌（`2 x 1`）和特罗米诺形状。 多米诺骨牌恰好覆盖垂直或水平方向的两个相邻单元，而多米诺骨牌则覆盖 L 形的三个相连的单元。 瓷砖可以根据需要旋转。 

输入是单个整数`n`代表板的宽度。 输出应该是不同平铺配置的总数模`10^9 + 7`。 如果至少一对相邻的方块被不同地覆盖，则认为两个平铺是不同的。 

约束表明`1 <= n <= 1000`，这意味着该解决方案必须有效地处理相对较大的板宽度。 递归地尝试所有放置的朴素暴力方法是不可行的，因为可能性的数量呈指数增长`n`。 需要注意的边缘情况包括非常小的板（`n = 1`或者`n = 2`），其中只有少数几个位置是可能的。 

## 方法

 暴力方法会尝试在棋盘上递归地放置瓷砖，探索多米诺骨牌和多米诺骨牌的每种有效组合。 虽然正确，但该方法是指数级的`n`并且对于`n`最多 1000 个。 

最佳解决方案的关键观察是该问题表现出重叠的子问题和最佳子结构，使其成为动态规划的理想选择。 我们定义`dp[i]`作为平铺 a 的方式数量`2 x i`木板。 我们必须考虑两种情况：完全填充的列和部分填充的列（由于多米诺骨牌在最后一列中留下了一个方块未被覆盖）。 这导致了涉及的递归关系`dp[i-1]`,`dp[i-2]`，以及用于部分平铺的辅助数组。 这将问题从指数时间转变为线性时间。

 | 蛮力 | O(2^n) | O(2^n) | O(n) | 递归尝试多米诺骨牌和特罗米诺骨牌的所有放置 |

 ## 算法演练

 1. 初始化一个`dp`大小数组`n+1`存储完全平铺的方式数量`2 x i`板和另一个阵列`dp2`存储部分平铺的方式数量`2 x i`留下一个方块悬挂。 
2. 设置基本案例：`dp[0] = 1`（空板上有一块简单的瓷砖），`dp[1] = 1`（一张垂直多米诺骨牌），`dp[2] = 2`（两个垂直多米诺骨牌或两个水平多米诺骨牌）。 
3. 循环自`i = 3`到`n`。 对于每个`i`，计算完整平铺的数量：

 - 使用递归`dp[i] = dp[i-1] + dp[i-2] + 2 * dp2[i-1]`考虑放置一个垂直多米诺骨牌、两个水平多米诺骨牌，或在部分配置中添加多米诺骨牌。 
- 更新部分平铺：`dp2[i] = dp2[i-1] + dp[i-2]`。 
4. 返回`dp[n] % (10^9 + 7)`处理大量数据。 

为什么有效：递归通过考虑将较小的平铺扩展到较大的板的所有有效方法来正确计算所有配置。 部分平铺阵列可确保 tromino 正确合并。 

## Python 解决方案```python
class Solution:
    def numTilings(self, n: int) -> int:
        MOD = 10**9 + 7
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        dp = [0] * (n + 1)
        dp2 = [0] * (n + 1)
        
        dp[0], dp[1], dp[2] = 1, 1, 2
        dp2[2] = 1
        
        for i in range(3, n + 1):
            dp[i] = (dp[i-1] + dp[i-2] + 2 * dp2[i-1]) % MOD
            dp2[i] = (dp2[i-1] + dp[i-2]) % MOD
        
        return dp[n]
```该实现使用基本情况初始化动态编程数组。 主循环填充`dp`和`dp2`根据复发情况。 我们在每一步都使用模运算来防止溢出。 

## 解决方案```go
func numTilings(n int) int {
    const MOD = 1000000007
    if n == 1 {
        return 1
    }
    if n == 2 {
        return 2
    }

    dp := make([]int, n+1)
    dp2 := make([]int, n+1)

    dp[0], dp[1], dp[2] = 1, 1, 2
    dp2[2] = 1

    for i := 3; i <= n; i++ {
        dp[i] = (dp[i-1] + dp[i-2] + 2*dp2[i-1]) % MOD
        dp2[i] = (dp2[i-1] + dp[i-2]) % MOD
    }

    return dp[n]
}
```在 Go 中，我们使用切片进行动态编程数组，并定义模运算常量。 该逻辑反映了 Python 实现。

 ## 边缘情况

 第一个重要的边缘情况是`n = 1`。 木板太小，无法容纳多米诺骨牌，只能容纳一个垂直的多米诺骨牌。 实现通过条件检查显式处理此问题。 

第二个边缘情况是`n = 2`。 多米诺骨牌和部分放置都必须正确考虑。 我们显式初始化`dp[2] = 2`和`dp2[2] = 1`来捕捉这个场景。 

第三个边缘情况很大`n = 1000`。 在这里，可能会发生整数溢出，并且简单的递归方法会失败。 该解决方案使用模数`10^9 + 7`和动态规划，确保在约束范围内得到正确的结果。 

这些边缘情况在实现中得到正确处理，并确保在整个输入范围内的鲁棒性。
