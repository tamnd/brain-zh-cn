[LeetCode 问题 2147](https://leetcode.com/problems/number-of-ways-to-divide-a-long-corridor/)

 **难度：** 🔴难
 **主题：** 数学、字符串、动态规划

 ## 解决方案

 ## 问题理解

 问题提出了一条用字符串表示的**长走廊**，其中`'S'`表示一个座位并且`'P'`表示植物。 目标是将这条走廊分成**部分**，以便每个部分包含**恰好两个座位**和任意数量的植物。 已经有两个分隔符：一个在第一个字符之前，一个在最后一个字符之后。 可以在任意两个相邻位置之间放置额外的分隔器，但每个位置最多可以有一个分隔器**。 

**输入**是一个字符串`corridor`长度`n`在哪里`1 <= n <= 10^5`，并且它仅由`'S'`和`'P'`。 **输出**是将走廊划分为有效部分的方法数量，模数`10^9 + 7`。 如果不存在有效的除法，则返回`0`。 

主要限制和观察包括：

 1. 区域**必须正好有两个座位**。 这意味着座位总数必须**偶数**，否则无法划分走廊。 
2、植物不影响节的有效性； 它们仅充当座位之间的填充物。 
3. 走廊长度可达`10^5`，这排除了检查每个可能的分区的简单递归或组合方法。 

重要的边缘情况包括：

 - 少于2个座位：不可能形成一个区域。 
- 座位数为奇数：不可能分成两个部分。 
- 连续的座位之间没有植物：必须小心地放置隔板。 
- 座位对之间有许多植物的走廊：多个有效的分隔物放置会增加总数。 

## 方法

 ### 蛮力方法

 暴力方法将涉及生成所有可能的方法来在角色之间放置分隔线，并检查每个结果部分是否恰好包含两个座位。 对于长度较长的走廊`n`, 最多有`2^(n-1)`可能的分隔线放置，这是指数级的且不可行`n = 10^5`。 虽然这种方法原则上是正确的，但它太慢并且无法在任何合理的时间限制内完成。 

### 最佳方法

 关键的见解是有效部分完全由**座位对**决定。 一旦确定了座椅对，放置隔板的方式数量取决于这些座椅对之间的植物数量。 

步骤如下：

 1. 统计座位总数。 如果是**奇数**，则返回`0`。 
2. 识别所有成对的连续座位。 
3. 对于一对座位的末端和下一座位对的开始之间的每个**间隙**，计算植物的数量。 每个间隙都为分隔线的放置提供了多种选择。 具体来说，如果有`k`两部分之间有植物`k + 1`放置分隔线的方法。 
4. 将所有这些计数相乘即可得到路的总数。 

这种方法避免了显式枚举每个分区，并且在**线性时间内**工作。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 枚举所有可能的分隔线位置并检查部分 |
 | 最佳 | O(n) | O(1) | O(1) | 计算两对座位之间的植物数量并计算选择的乘积 |

 ## 算法演练

 1. 初始化座位计数器并将结果变量设置为`1`。 
2. 遍历走廊线。 计算座位总数。 
3. 若座位总数小于2或**奇数**，则返回`0`因为不可能形成恰好两个座位的部分。 
4. 行驶时跟踪座位位置。 每当找到两个座位时，标记当前部分的结尾。 
5. 计算当前部分结束点和下一部分开始点之间的植物数量。 
6. 对于每个这样的间隙，将结果乘以`(number of plants + 1)`模数`10^9 + 7`。 
7. 处理完所有座位对后，返回结果。 

**为什么有效：** 每个有效部分必须恰好有两个座位。 通过仅考虑成对的座椅和中间的植物，我们将问题简化为计算在区域之间放置隔断的位置的选择。 乘法反映了每个间隙的独立选择。 

## Python 解决方案```python
class Solution:
    def numberOfWays(self, corridor: str) -> int:
        MOD = 10**9 + 7
        seats = 0
        n = len(corridor)
        for ch in corridor:
            if ch == 'S':
                seats += 1
        
        if seats == 0 or seats % 2 != 0:
            return 0
        
        result = 1
        current_seat = 0
        i = 0
        
        while i < n:
            if corridor[i] == 'S':
                current_seat += 1
                if current_seat % 2 == 0:
                    # Count plants until next 'S'
                    plants = 0
                    i += 1
                    while i < n and corridor[i] == 'P':
                        plants += 1
                        i += 1
                    if i < n:
                        result = (result * (plants + 1)) % MOD
                    continue
            i += 1
        
        return result
```**实施演练：**

 该代码首先计算总座位数。 如果数字为奇数或零，则立即返回`0`。 然后它穿过走廊，计算每对连续座位之间的植物数量。 每个间隙都会乘以总结果，并应用模数以防止溢出。 

## 解决方案```go
func numberOfWays(corridor string) int {
    const MOD int = 1e9 + 7
    seats := 0
    n := len(corridor)
    
    for i := 0; i < n; i++ {
        if corridor[i] == 'S' {
            seats++
        }
    }
    
    if seats == 0 || seats % 2 != 0 {
        return 0
    }
    
    result := 1
    currentSeat := 0
    i := 0
    
    for i < n {
        if corridor[i] == 'S' {
            currentSeat++
            if currentSeat % 2 == 0 {
                plants := 0
                i++
                for i < n && corridor[i] == 'P' {
                    plants++
                    i++
                }
                if i < n {
                    result = result * (plants + 1) % MOD
                }
                continue
            }
        }
        i++
    }
    
    return result
}
```**Go 特定说明：** 逻辑镜像 Python，但我们显式声明常量并使用带模的整数运算来防止溢出。 切片和索引用于遍历字符串。
