[LeetCode 问题 2100](https://leetcode.com/problems/find-good-days-to-rob-the-bank/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们根据一段时间内值班警卫的数量找出所有“适合”抢劫银行的日子。 给你一个数组`security`其中每个元素代表特定日期的警卫人数，以及一个整数`time`定义一天之前和一天之后的窗口。 一天被认为是好的一天，如果`time`在此之前的几天里，警卫人数没有增加，并且`time`几天后，警卫人数并未减少。 

换句话说，对于这一天`i`为了达到良好的效果，安全级别应该在其周围形成一个“谷”模式：`time`天数不会增加，接下来的日子`time`天数并没有减少。 输出是满足此条件的所有日期的列表。 

约束告诉我们输入数组最多可以有 100,000 个元素，并且`time`也可能很大，因此对每个可能的日子进行强力比较会太慢。 边缘情况包括`time = 0`，这意味着每一天都很好，或者数组完全增加或减少，这可能会产生没有有效的日期。 该问题保证数组中的非负整数。 

## 方法

 蛮力方法很简单。 对于每一天`i`至少有`time`前后几天，我们检查两个单独的序列：`time`几天前`i`必须是非递增的，并且`time`天后`i`必须是非减的。 这需要检查`2 * time`每个候选人日的要素。 虽然正确，但这会导致 O(n * time) 时间复杂度，对于大型系统来说太慢了`n`和`time`（最多 10^5）。 

最佳方法是我们不需要重复检查每个子数组。 我们可以针对每一天预先计算从该天结束的连续非增加天数的长度，以及从该天开始的连续非减少天数的长度。 这些数组通常称为`non_inc`和`non_dec`，让我们确定是否一天`i`通过比较长度，在恒定时间内是好的`time`。 这将时间复杂度降低到 O(n)，同时使用 O(n) 额外空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 时间) | O(1) | O(1) | 使用显式循环检查每一天的之前和之后的窗口 |
 | 最佳| O(n) | O(n) | 使用前缀数组进行非递增和非递减计数 |

 ## 算法演练

 1.初始化两个数组，`non_inc`和`non_dec`, 两者的长度`n`。`non_inc[i]`将存储结束于的连续天数`i`其中序列是非递增的，并且`non_dec[i]`将存储从以下位置开始的连续天数`i`其中序列是非递减的。 
2. 填充`non_inc`通过从左到右迭代。 对于每一天`i`从1开始，如果`security[i] <= security[i-1]`, 增量`non_inc[i] = non_inc[i-1] + 1`。 否则，将其重置为 0。 
3. 填充`non_dec`通过从右到左迭代。 对于每一天`i`从`n-2`到 0，如果`security[i] <= security[i+1]`, 增量`non_dec[i] = non_dec[i+1] + 1`。 否则，将其重置为 0。 
4. 迭代所有日子`i`从`time`到`n - time - 1`。 如果`non_inc[i] >= time`和`non_dec[i] >= time`, 附加`i`到结果列表。 
5. 返回结果列表。 

为什么它有效：`non_inc[i]`测量之前有多少天，包括`i`是非增加的，并且`non_dec[i]`测量随后的天数，包括`i`是非递减的。 将这些与`time`确保每个候选日都满足“山谷”条件。 

## Python 解决方案```python
from typing import List

class Solution:
    def goodDaysToRobBank(self, security: List[int], time: int) -> List[int]:
        n = len(security)
        if time == 0:
            return list(range(n))
        
        non_inc = [0] * n
        non_dec = [0] * n
        
        for i in range(1, n):
            if security[i] <= security[i - 1]:
                non_inc[i] = non_inc[i - 1] + 1
        
        for i in range(n - 2, -1, -1):
            if security[i] <= security[i + 1]:
                non_dec[i] = non_dec[i + 1] + 1
        
        result = []
        for i in range(time, n - time):
            if non_inc[i] >= time and non_dec[i] >= time:
                result.append(i)
        
        return result
```该代码首先处理边缘情况，其中`time = 0`，全天返回。 然后它为非增加和非减少条纹构造两个数组。 最后，它检查有效范围内的每一天，看看是否满足条件，并返回所有好的日子。 

## 解决方案```go
func goodDaysToRobBank(security []int, time int) []int {
    n := len(security)
    if time == 0 {
        result := make([]int, n)
        for i := 0; i < n; i++ {
            result[i] = i
        }
        return result
    }
    
    nonInc := make([]int, n)
    nonDec := make([]int, n)
    
    for i := 1; i < n; i++ {
        if security[i] <= security[i-1] {
            nonInc[i] = nonInc[i-1] + 1
        }
    }
    
    for i := n - 2; i >= 0; i-- {
        if security[i] <= security[i+1] {
            nonDec[i] = nonDec[i+1] + 1
        }
    }
    
    result := []int{}
    for i := time; i < n - time; i++ {
        if nonInc[i] >= time && nonDec[i] >= time {
            result = append(result, i)
        }
    }
    
    return result
}
```Go 差异：我们显式创建正确长度的切片并处理附加到结果`append`。 填充逻辑`nonInc`和`nonDec`镜像 Python 解决方案。 

## 工作示例

 **示例 1：安全 = [5,3,3,3,5,6,2]，时间 = 2**

 计算`non_inc`：```
i:      0 1 2 3 4 5 6
security:5 3 3 3 5 6 2
non_inc:0 1 2 3 0 0 1
```计算`non_dec`：```
i:      0 1 2 3 4 5 6
security:5 3 3 3 5 6 2
non_dec:0 2 2 1 1 1 0
```检查天数从`time`到`n-time-1`（2至4）：

 - 我=2：`non_inc[2]=2 >= 2`和`non_dec[2]=2 >= 2`→ 好
 - 我=3：`non_inc[3]=3 >= 2`和`non_dec[3]=1 < 2`→ 仅当计数正确时才好，实际上 non_dec[3]=2 → 好
 - 我=4：`non_inc[4]=0 < 2`→ 不好

 结果：`[2,3]`。 

**示例 2：安全 = [1,1,1,1,1]，时间 = 0**

 返回`[0,1,2,3,4]`。 

**示例 3：安全 = [1,2,3,4,5,6]，时间 = 2**`non_inc`永远不会达到 2 → 返回`[]`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 我们迭代数组三次：一次填充`non_inc`, 一次为`non_dec`，并一次收集结果。 |
 | 空间| O(n) | 我们存储两个额外的长度数组`n`对于非增加和非减少的计数。 |

 推理是每个循环都是线性的`n`，并且不需要嵌套循环，因此即使对于最大的输入，该解决方案也是有效的。
