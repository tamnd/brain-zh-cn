 # LeetCode 2177 - 查找三个连续整数的总和为给定数字

 ## 问题理解

 这个问题要求我们判断给定的整数是否`num`可以表示为三个连续整数之和。 如果存在这样的表示，我们必须按排序顺序返回这三个整数。 否则，我们返回一个空数组。 

三个连续的整数始终遵循以下模式：```
x, x + 1, x + 2
```他们的总和是：```
x + (x + 1) + (x + 2) = 3x + 3
```这意味着总和必须始终能被整除`3`。 

输入由单个整数组成`num`，输出为：

 - 包含三个连续整数的列表，其总和等于`num`- 如果不存在这样的整数，则为空列表

 约束条件很重要：

 -`0 <= num <= 10^15`上限非常大，因此任何迭代许多可能值的算法都是低效的。 我们需要数学观察来使我们能够在恒定的时间内解决问题。 

一些边缘情况很重要：

 - 小值，例如`0`,`1`， 或者`2`- 不能被整除的数字`3`- 附近有大量数字`10^15`- 连续整数包括的情况`0`该问题保证了`num`是非负的，所以我们不需要处理负输入。 

## 方法

 ### 蛮力方法

 一种简单的方法是尝试每个可能的起始整数`x`并检查是否：```
x + (x + 1) + (x + 2) == num
```如果等式成立，我们返回`[x, x + 1, x + 2]`。 

这种方法是正确的，因为它详尽地检查了每个可能的三个连续整数组。 然而，它的效率很低，因为搜索空间随着搜索空间的增长而增长。`num`。 自从`num`可以大到`10^15`，迭代候选者是完全不切实际的。 

### 最优数学方法

 关键的见解来自代数。 

假设三个连续整数是：```
x - 1, x, x + 1
```他们的总和是：```
(x - 1) + x + (x + 1) = 3x
```这立即告诉我们：

 - 有效解存在当且仅当`num`可以整除`3`- 中间的数字是`num // 3`一旦我们知道了中间的数字，答案就变成了：```
[num // 3 - 1, num // 3, num // 3 + 1]
```这消除了所有搜索并给出了`O(1)`解决方案。

 ## 算法演练

 1. 检查是否`num`可以整除`3`。 

三个连续的整数之和总是为以下的倍数`3`。 如果`num % 3 != 0`，不存在有效的解决方案，因此我们立即返回一个空数组。 
2. 计算中间的整数。 

如果`num`可以整除`3`， 让：```
middle = num // 3
```这三个整数必须是：```
middle - 1
middle
middle + 1
```3. 返回结果数组。 

构造并返回：```
[middle - 1, middle, middle + 1]
```### 为什么它有效

 正确性直接来自连续整数的结构。 任何三个连续的整数总是可以写成：```
x - 1, x, x + 1
```他们的总和简化为：```
3x
```因此，当`num`可以整除`3`。 当它可分时，`x = num / 3`，它唯一地确定了三个整数。 

## Python 解决方案```python
from typing import List

class Solution:
    def sumOfThree(self, num: int) -> List[int]:
        if num % 3 != 0:
            return []

        middle = num // 3

        return [middle - 1, middle, middle + 1]
```实现首先检查整除性`3`。 如果余数不为零，则该函数立即返回一个空列表，因为不存在有效的三元组。 

如果该数字可以被`3`，代码使用整数除法计算中间整数。 然后通过减法和加法生成周围的连续整数`1`。 

解决方案很简洁，因为数学关系完全决定了答案。 

## 解决方案```go
func sumOfThree(num int64) []int64 {
    if num%3 != 0 {
        return []int64{}
    }

    middle := num / 3

    return []int64{middle - 1, middle, middle + 1}
}
```Go 实现遵循与 Python 解决方案相同的数学推理。 

Go 特有的一个重要细节是使用`int64`，因为约束允许值达到`10^15`。 使用常规`int`可能会导致某些系统溢出。 当不存在解时，该函数返回一个空切片。

 ## 边缘情况

 ### 输入等于零

 当`num = 0`，某些实现可能会错误地假设所有返回的整数必须为正数。 然而，该问题只需要连续整数，而不需要正整数。 

正确的顺序是：```
[-1, 0, 1]
```该实现自然地处理了这个问题，因为整数除法仍然可以正确工作。 

### 不能被三整除的数字

 一个常见的错误是尝试构建一个序列，即使`num`不能被整除`3`。 例如：```
num = 4
```三个连续的整数之和不能等于`4`。 

该实现通过立即检查来避免此问题：```
if num % 3 != 0:
    return []
```### 非常大的数字

 自从`num`可以大到`10^15`，迭代方法变得不可行。 强力解决方案可能需要数万亿次操作。 

该数学解决方案仅执行恒定时间算术运算，因此即使对于最大约束，它也可以完美扩展。 Go 解决方案还使用`int64`安全地存储大值而不会溢出。
