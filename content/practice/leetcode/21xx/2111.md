[LeetCode 问题 2111](https://leetcode.com/problems/minimum-operations-to-make-the-array-k-increasing/)

 **难度：** 🔴难
 **主题：** 数组、二分查找

 ## 解决方案

 ## 问题理解

 The problem asks us to transform a given array`arr`使用最少的操作次数将其转换为 **K 递增数组**。 定义一个 K 递增数组，使得对于每个索引`i`在哪里`i >= k`，条件`arr[i-k] <= arr[i]`成立。 每个操作都允许我们选择任何索引`i`并改变`arr[i]`为任何正整数。 目标是尽量减少此类操作的数量。 

简单来说，数组可以看作`k`由索引处的元素形成的独立子序列`i, i+k, i+2k, ...`。 每个子序列必须是非递减的才能满足 K 递增条件。 因此，问题简化为计算每个子序列中必须修改多少个元素才能使该子序列不减，并对所有子序列中的这些计数求和`k`子序列。 

输入数组可能非常大（`n`最多`10^5`），这意味着任何简单的 O(n²) 解决方案都会太慢。 每个数组元素都是一个正整数，并且`k`至少为 1 但最多`n`。 

重要的边缘情况包括已经 K 递增的数组（需要 0 次操作）、具有单个元素的数组（始终有效）以及`k`值等于 1 或`n`，这将问题简化为熟悉的形式：使数组不减或检查单个子序列。 

## 方法

 ### 蛮力

 暴力解决方案将尝试检查每个可能的操作序列以强制执行`arr[i-k] <= arr[i]`。 对于每个索引`i >= k`， 如果`arr[i] < arr[i-k]`，我们可以改变`arr[i]`到`arr[i-k]`。 虽然这看起来很简单，但它没有考虑到改变`arr[i]`可能会向前传播问题，并且枚举所有可能性将导致指数时间复杂度。 

这种方法原则上是正确的，但由于组合爆炸而对于大型阵列来说不可行。 

### 最佳方法

 关键的洞察力是注意到问题可以分解为`k`独立子序列：`[arr[i], arr[i+k], arr[i+2k], ...]`为了`i = 0..k-1`。 对于每个子序列，使其不减所需的最小更改次数等于子序列长度减去其**最长非减子序列（LNDS）**的长度。 这是经典的最长递增子序列问题的变体，适用于允许相等的元素。 使用二分搜索方法，可以在 O(m log m) 时间内找到长度子序列的 LNDS`m`。 

计算完所有所需的更改数量后`k`子序列，将它们相加得到最终答案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 检查所有可能的操作； 不可行 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 分解为 k 个子序列并使用 LNDS 进行二分查找 |

 ## 算法演练

 1. 初始化变量`res`到 0，这将累积所需操作的总数。 
2. 对于每个`i`从 0 到`k-1`,构造子序列`sub`包含元素`arr[i], arr[i+k], arr[i+2k], ...`。 
3. 对于这个子序列`sub`，使用二分查找方法计算其最长非递减子序列 (LNDS) 的长度：

 - 初始化一个空列表`ln`代表当前的 LNDS。 
- 迭代每个元素`num`在`sub`。 使用二分查找查找第一个索引`ln`在哪里`num`小于该索引处的值。 如果找到则替换该元素，否则追加`num`到`ln`。 
4. 该子序列所需的操作次数为`len(sub) - len(ln)`。 
5.将此号码添加到`res`。 
6. 返回`res`作为要进行的最小操作数`arr`K-增加。 

**为什么有效：** 通过将数组分解为`k`独立的子序列，我们确保 K 增属性在所有指数中都成立。 计算每个子序列的 LNDS 可以保证修改最小数量的元素以实现非降序，这直接转化为最小化操作。 

## Python 解决方案```python
from typing import List
import bisect

class Solution:
    def kIncreasing(self, arr: List[int], k: int) -> int:
        res = 0
        for i in range(k):
            sub = arr[i::k]
            ln = []
            for num in sub:
                idx = bisect.bisect_right(ln, num)
                if idx == len(ln):
                    ln.append(num)
                else:
                    ln[idx] = num
            res += len(sub) - len(ln)
        return res
```**实现演练：** 对于使用 提取的每个子序列`arr[i::k]`，我们维护一个列表`ln`表示当前的最长非递减子序列。`bisect_right`确保我们允许相等的元素，因为问题允许非降序。 子序列长度和 LNDS 长度之间的差异给出了所需的最少更改数量。 

## 解决方案```go
import "sort"

func kIncreasing(arr []int, k int) int {
    res := 0
    for i := 0; i < k; i++ {
        var sub []int
        for j := i; j < len(arr); j += k {
            sub = append(sub, arr[j])
        }
        ln := []int{}
        for _, num := range sub {
            idx := sort.Search(len(ln), func(j int) bool { return ln[j] > num })
            if idx == len(ln) {
                ln = append(ln, num)
            } else {
                ln[idx] = num
            }
        }
        res += len(sub) - len(ln)
    }
    return res
}
```**Go 特定说明：** Go 没有内置的`bisect_right`， 所以`sort.Search`用于查找第一个大于的元素的插入索引`num`。 切片操作有效地维护 LNDS。 整数溢出不是问题，因为元素是约束内的正整数。 

## 工作示例

 ### 示例 1：`arr = [5,4,3,2,1], k = 1`子序列：`[5,4,3,2,1]`的 LNDS`[5,4,3,2,1]`是`[5]`（长度1）

 操作：`5 - 1 = 4`答案：4

 ### 示例 2：`arr = [4,1,5,2,6,2], k = 2`子序列0：`[4,5,6]`, LNDS =`[4,5,6]`→ 0 处变更

 后续1：`[1,2,2]`, LNDS =`[1,2,2]`→ 0 处变更

 总操作 = 0

 答案：0

 ### 示例 3：`arr = [4,1,5,2,6,2], k = 3`子序列0：`[4,2]`, LNDS =`[2]`→ 1 次变更

 后续1：`[1,6]`, LNDS =`[1,6]`→ 0 处变更

 后续2：`[5,2]`, LNDS =`[2]`→ 1 次变更

 总操作 = 1 + 0 + 1 = 2

 答案：2

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n log n) | O(n log n) | 每个`k`子序列最多有`n/k`元素。 找到每个的 LNDS 需要 O((n/k) log(n/k))，求和`k`给出 O(n log n) |
 | 空间| O(n) | 存储子序列和 LNDS 列表 |

 二分搜索方法确保即使对于大型数组，我们也不会超过 O(n log n)。
