[LeetCode 问题 2145](https://leetcode.com/problems/count-the-hidden-sequences/)

 **难度：** 🟡 中等
 **主题：** 数组、前缀和

 ## 解决方案

 ## 问题理解

 该问题要求我们确定存在多少个可能的整数序列，它们与给定的连续元素之间的差异数组相匹配，同时保持在指定的包含范围内。 具体来说，给你一个数组`differences`长度`n`其中每个元素表示长度隐藏序列的连续元素之间的差异`n + 1`。 您还获得了整数`lower`和`upper`定义此隐藏序列中每个元素的有效边界。 

目标是计算差异匹配且所有元素都在范围内的所有有效序列`[lower, upper]`。 重要的是，没有给出顺序； 只是差异而已。 序列的第一个元素是灵活的，只要应用差异后整个序列保持在界限内即可。 

约束表明`n`可以大到`10^5`，这排除了所有可能序列的简单枚举。 差异可以是正的，也可以是负的，也可以涵盖整个范围`-10^5`到`10^5`。 界限`lower`和`upper`也跨越相同的范围，包括负数。 这意味着我们需要处理潜在的大数字和边缘情况，其中序列可能立即超出限制。 边缘情况包括差异大幅波动的序列、具有单个元素的序列，或者`lower == upper`。 

## 方法

 暴力方法会迭代每个可能的起始数字`x`之内`[lower, upper]`，然后使用差异数组重建序列。 对于每个起始数字，我们检查所有后续数字是否仍在范围内。 这是正确的，但太慢了，因为可能最多有`10^5`差异和高达`2 * 10^5 + 1`可能的起始数字。 其复杂度大致为`O(n * (upper - lower + 1))`，这对于大范围是不可行的。 

最佳解决方案的关键见解是，有效序列仅取决于**差异的最小和最大前缀和**。 让`prefix[i]`是第一个的总和`i`差异。 那么序列元素可以表示为`hidden[0] + prefix[i]`。 留在里面`[lower, upper]`，我们要求：```
lower <= hidden[0] + min_prefix <= hidden[i] <= hidden[0] + max_prefix <= upper
```这将问题简化为简单的范围检查：计算最小和最大前缀和，然后确定有多少个起始数字`hidden[0]`满足`lower - min_prefix <= hidden[0] <= upper - max_prefix`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * (上 - 下 + 1)) | O(n) | 尝试每个可能的起始值并验证序列 |
 | 最佳 | O(n) | O(1) | O(1) | 计算前缀最小/最大并确定有效的起始范围 |

 ## 算法演练

 1. 初始化`min_prefix`和`max_prefix`到 0。这些将跟踪差异运行总和的最小值和最大值。 
2. 初始化变量`current_sum`到 0，表示迭代时的前缀和。 
3. 迭代`differences`大批。 对于每个`diff`， 更新`current_sum += diff`。 更新`min_prefix = min(min_prefix, current_sum)`和`max_prefix = max(max_prefix, current_sum)`。 
4. 处理完所有差异后，计算第一个元素的有效范围`hidden[0]`作为`[lower - min_prefix, upper - max_prefix]`。 
5、有效序列的个数就是这个范围内的整数个数，即`max(0, (upper - max_prefix) - (lower - min_prefix) + 1)`。 

**为什么有效：** 该算法之所以有效，是因为元素之间的相对偏移量由下式固定：`differences`。 一旦我们知道了最小和最大偏移量，控制有效性的唯一因素就是起始元素。 通过约束`hidden[0]`将所有元素保留在其中`[lower, upper]`，我们确保所有序列都是有效的。 没有其他因素需要检查。 

## Python 解决方案```python
from typing import List

class Solution:
    def numberOfArrays(self, differences: List[int], lower: int, upper: int) -> int:
        min_prefix = 0
        max_prefix = 0
        current_sum = 0
        
        for diff in differences:
            current_sum += diff
            min_prefix = min(min_prefix, current_sum)
            max_prefix = max(max_prefix, current_sum)
        
        # Calculate the valid range for hidden[0]
        valid_start_min = lower - min_prefix
        valid_start_max = upper - max_prefix
        
        return max(0, valid_start_max - valid_start_min + 1)
```该实现计算运行前缀总和并跟踪观察到的最小和最大总和。 然后直接计算有效起始数字的范围。 这`max(0, ...)`确保如果范围无效（空），则返回 0。 

## 解决方案```go
func numberOfArrays(differences []int, lower int, upper int) int {
    minPrefix, maxPrefix := 0, 0
    currentSum := 0

    for _, diff := range differences {
        currentSum += diff
        if currentSum < minPrefix {
            minPrefix = currentSum
        }
        if currentSum > maxPrefix {
            maxPrefix = currentSum
        }
    }

    validStartMin := lower - minPrefix
    validStartMax := upper - maxPrefix
    result := validStartMax - validStartMin + 1
    if result < 0 {
        return 0
    }
    return result
}
```Go 解决方案反映了 Python 逻辑。 Go 使用显式条件进行最小/最大更新，最终计算确保非负返回。
