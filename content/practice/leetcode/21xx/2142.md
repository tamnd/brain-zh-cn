 ## 解决方案

 ## 问题理解

 该问题涉及模拟乘客到达公交车站并在到达时登上公交车。 我们有两张表：`Buses`和`Passengers`。 每辆巴士都有独特的`bus_id`和一个`arrival_time`，并且每位乘客都有一个独特的`passenger_id`和一个`arrival_time`。 乘客搭乘到达时间后第一趟到达的巴士，每位乘客只能搭乘一辆巴士。 我们的目标是计算登上每辆公交车的乘客数量并返回按以下顺序排序的结果`bus_id`按升序排列。 

输入表示公交车和乘客的到达时间，输出是每辆公交车的乘客数量。 限制包括没有两辆公交车同时到达，而且公交车和乘客的数量可能足够大，以至于简单的方法可能效率低下。 边缘情况包括公交车先于任何乘客、在所有乘客之后到达的情况，或者多名乘客与公交车同时到达的情况。 

## 方法

 蛮力方法很简单：对于每辆公交车，迭代所有乘客，并计算在公交车到达时间或之前到达且尚未登上前一辆公交车的乘客。 虽然这是正确的，但效率低下，需要嵌套循环并导致时间复杂度为$O(B \times P)$， 在哪里$B$是公交车的数量，$P$是乘客数量。 

更优化的方法依赖于按到达时间对公共汽车和乘客进行排序，并使用运行指针来跟踪哪些乘客已登机。 对于每辆公交车，我们按顺序迭代乘客，让所有到达时间小于或等于当前公交车到达时间的乘客登机。 这种方法无需重复扫描每辆公交车的乘客，从而降低了时间复杂度$O(B \log B + P \log P + B + P)$，由排序步骤主导。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(B * P) | O(1) | O(1) | 公共汽车和乘客的嵌套循环； 正确但低效|
 | 最佳| O(B log B + P log P) | O(B log B + P log P) | O(P)| 对两个表进行排序并使用指针有效地分配乘客 |

 ## 算法演练

 1. 排序`Buses`表格依据`arrival_time`同时跟踪`bus_id`。 
2. 排序`Passengers`表格依据`arrival_time`。 
3. 初始化一个结果列表来存储`bus_id`和`passengers_cnt`。 
4. 初始化指针`p`到0，代表下一个没有上车的乘客的索引。 
5. 按到达时间顺序迭代每辆公交车：

 1.初始化一个计数器`cnt`该总线为 0。 
2. 虽然`p`小于乘客总数和索引处的乘客`p`有`arrival_time`≤ 当前公交车到达时间：

 1. 增量`cnt`1.
 2. 增量`p`将乘客标记为已登机。 
3.追加元组`(bus_id, cnt)`到结果列表。 
6. 最后对结果列表进行排序`bus_id`以满足输出要求。 

**为什么有效**：该算法之所以有效，是因为通过按时间对公共汽车和乘客进行排序，我们保持了每个乘客都被分配到最早的公共汽车的不变性。 指针确保不会对乘客进行两次计数，排序则保证公交车按时间顺序处理。 

## Python 解决方案```python
import pandas as pd

class Solution:
    def numberOfPassengers(self, Buses: pd.DataFrame, Passengers: pd.DataFrame) -> pd.DataFrame:
        # Sort buses and passengers by arrival_time
        buses_sorted = Buses.sort_values(by='arrival_time').reset_index(drop=True)
        passengers_sorted = Passengers.sort_values(by='arrival_time').reset_index(drop=True)

        result = []
        p = 0
        num_passengers = len(passengers_sorted)

        # Iterate over buses in chronological order
        for _, bus in buses_sorted.iterrows():
            cnt = 0
            while p < num_passengers and passengers_sorted.at[p, 'arrival_time'] <= bus['arrival_time']:
                cnt += 1
                p += 1
            result.append({'bus_id': bus['bus_id'], 'passengers_cnt': cnt})

        # Return the result sorted by bus_id
        return pd.DataFrame(result).sort_values(by='bus_id').reset_index(drop=True)
```Python 实现首先对公交车和乘客进行排序`arrival_time`以便我们可以按时间顺序处理它们。 指针`p`确保每个乘客仅被分配一次，并且结果是增量构建的。 最后，排序依据`bus_id`确保输出符合问题要求。 

## 解决方案```go
package main

import (
    "sort"
)

type Bus struct {
    BusID       int
    ArrivalTime int
}

type Passenger struct {
    PassengerID int
    ArrivalTime int
}

type BusCount struct {
    BusID         int
    PassengersCnt int
}

func NumberOfPassengers(buses []Bus, passengers []Passenger) []BusCount {
    sort.Slice(buses, func(i, j int) bool { return buses[i].ArrivalTime < buses[j].ArrivalTime })
    sort.Slice(passengers, func(i, j int) bool { return passengers[i].ArrivalTime < passengers[j].ArrivalTime })

    result := make([]BusCount, 0, len(buses))
    p := 0
    for _, bus := range buses {
        cnt := 0
        for p < len(passengers) && passengers[p].ArrivalTime <= bus.ArrivalTime {
            cnt++
            p++
        }
        result = append(result, BusCount{BusID: bus.BusID, PassengersCnt: cnt})
    }

    sort.Slice(result, func(i, j int) bool { return result[i].BusID < result[j].BusID })
    return result
}
```Go 实现镜像了 Python 解决方案，使用切片和排序函数。 主要区别在于表的显式切片分配和结构类型，因为 Go 没有内置的 DataFrame 类型。 

## 工作示例

 对于提供的示例：

 - 巴士按到达时间排序：[(1,2), (2,4), (3,7)]
 - 乘客按到达时间排序：[(11,1), (12,5), (13,6), (14,7)]

 迭代：

 | 巴士 ID | 到达时间 | 客运指数 乘客登机 | 计数|
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 0 | 11 | 11 1 |
 | 2 | 4 | 1 | 无 | 0 |
 | 3 | 7 | 1 | 12、13、14 | 3 |

 最终结果按bus_id排序：[(1,1),(2,0),(3,3)]

 | 空间| O(P)| 存储结果并使用乘客指针 |
