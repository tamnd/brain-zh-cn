[LeetCode 问题 2134](https://leetcode.com/problems/minimum-swaps-to-group-all-1s-together-ii/)

 **难度：** 🟡 中等
 **主题：** 数组、滑动窗口

 ## 解决方案

 ## 问题理解

 问题是要求我们找到将所有组分组所需的最小交换次数`1`s 在任何连续段一起位于**二进制圆形数组**中。 该数组是循环的，这意味着数组的末尾环绕到开头。 每次交换只能交换数组中两个不同位置的值。 输入是一个二进制数组，这意味着每个元素都是`0`或者`1`。 预期输出是一个整数，表示所需的最小交换次数。 

约束告诉我们数组可以很大，最多`10^5`元素，这使得检查每个可能的分组的简单方法变得不可行。 我们还知道数组可能已经拥有所有`1`s 分组或可能需要循环属性来最小化交换。 重要的边缘情况包括所有元素都在的数组`1`或`0`s，交替排列的数组`0`沙`1`s 和数组，其中最小分组发生在最后一个元素和第一个元素之间的边界上。 

## 方法

 ### 蛮力

 暴力方法会考虑每个可能的连续子数组，其长度等于数组的总数。`1`s 在数组中并计算有多少`0`s 位于该段中。 每个`0`代表需要交换来带来`1`进入该段。 因为数组是循环的，所以我们需要考虑从末尾到开头环绕的段。 这种方法工作正常但效率低下，因为对于长度的数组`n`和`k`那些，我们会检查`n`子数组和计数`0`中的每个子数组中的 s`O(k)`时间，导致`O(n*k)`时间复杂度，对于大型数组来说太慢了。 

### 最佳方法

 关键的见解是最小交换次数等于**最小交换次数`0`s 在长度等于总数的任何连续子数组中`1`s**。 为了有效地处理循环属性，我们可以**复制数组**（将其连接到自身）并应用长度等于数组数量的**滑动窗口**`1`s。 这样，每个圆弧段都被表示为双倍数组中的标准线性段。 使用滑动窗口，我们可以维护一个运行计数`0`s 并有效地确定所有窗口的最小计数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*k) | O(1) | O(1) | 检查所有长度的子数组`k`并数数`0`s |
 | 最佳| O(n) | O(n) | 复制数组并使用滑动窗口跟踪`0`s |

 ## 算法演练

 1. 统计总数量`1`s 到数组中并将其存储为`numOnes`。 
2.如果`numOnes`是`0`或者等于数组长度，返回`0`立即，因为不需要交换。 
3. 通过将数组连接到自身来复制数组，创建`numsExtended`。 
4.初始化一个长度的滑动窗口`numOnes`并计算数量`0`在第一个窗口中。 将此计数存储为`minZeros`。 
5. 将窗口滑过`numsExtended`来自索引`1`到`len(nums)`。 对于每一步，删除元素离开窗口的效果并添加元素进入窗口的效果：

 - 如果传出元素是`0`，减少零计数。 
- 如果传入的元素是`0`，增加零计数。 
- 更新`minZeros`如果当前零计数较小。 
6. 滑过所有可能的窗口后，`minZeros`将代表所需的最小交换次数。 
7. 返回`minZeros`。 

**为什么有效：** 该算法依赖于最小数量的不变式`0`任何大小等于总数的窗口中的 s`1`s 恰好对应于所需的最小交换量。 复制数组允许我们将圆形子数组处理为线性子数组，而无需特殊情况。 

## Python 解决方案```python
from typing import List

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        numOnes = sum(nums)
        if numOnes <= 1:
            return 0
        
        n = len(nums)
        numsExtended = nums + nums
        currentZeros = numsExtended[:numOnes].count(0)
        minZeros = currentZeros
        
        for i in range(1, n):
            if numsExtended[i - 1] == 0:
                currentZeros -= 1
            if numsExtended[i + numOnes - 1] == 0:
                currentZeros += 1
            minZeros = min(minZeros, currentZeros)
        
        return minZeros
```实现首先计算所有`1`s 确定窗口大小。 通过扩展数组，我们可以应用滑动窗口，而无需特殊的循环逻辑。 每个窗口中的零计数直接映射到对所有窗口进行分组所需的交换`1`s，并且我们跟踪所有可能窗口中的最小值。 

## 解决方案```go
func minSwaps(nums []int) int {
    numOnes := 0
    for _, v := range nums {
        if v == 1 {
            numOnes++
        }
    }
    if numOnes <= 1 {
        return 0
    }
    
    n := len(nums)
    numsExtended := append(nums, nums...)
    
    currentZeros := 0
    for i := 0; i < numOnes; i++ {
        if numsExtended[i] == 0 {
            currentZeros++
        }
    }
    minZeros := currentZeros
    
    for i := 1; i < n; i++ {
        if numsExtended[i-1] == 0 {
            currentZeros--
        }
        if numsExtended[i+numOnes-1] == 0 {
            currentZeros++
        }
        if currentZeros < minZeros {
            minZeros = currentZeros
        }
    }
    
    return minZeros
}
```Go 解决方案遵循相同的逻辑。 Go 需要显式处理切片并且没有内置的`count`函数，所以我们手动计算零。 滑动窗口逻辑保持不变。
