[LeetCode 问题 2112](https://leetcode.com/problems/the-airport-with-the-most-traffic/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 此问题要求我们使用航班表找到**交通量最大**的机场。 的每一行`Flights`表代表直接连接`departure_airport`到`arrival_airport`以及航班数量`flights_count`对于那条路线。 机场的交通量定义为**出发或到达该机场**的航班总数。 如果多个机场的客流量并列，我们必须按任意顺序返回所有机场。 

输入是一个包含三列的关系表：`departure_airport`,`arrival_airport`， 和`flights_count`。 输出是一个具有单列的表`airport_id`包含客流量最大的机场。 这些约束意味着该表非空并且`(departure_airport, arrival_airport)`对是唯一的，因此我们可以安全地对`flights_count`按每个机场分组。 边缘情况包括多个机场并列最大交通量或仅作为出发或到达出现的机场。 

## 方法

 蛮力方法是迭代数据集中的所有机场，分别计算每个机场出发和到达的航班总数，然后选择最大值。 这需要对表进行多次扫描，这对于大型数据集来说效率很低。 

最佳方法利用**单通道聚合**。 我们可以通过扫描`Flights`一次表，逐步更新出发机场和到达机场的流量计数器。 聚合后，我们可以找到最大流量并选择具有该值的所有机场。 该方法避免了多次扫描，使解决方案简单高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n) | 对于每个机场，分别对到达和出发航班进行汇总。 多表扫描。 |
 | 最佳| O(n) | O(n) | 使用哈希映射或 SQL 的单遍聚合`GROUP BY`和`SUM`。 |

 ## 算法演练

 1. 初始化一个地图或临时表来存储每个机场的总流量。 
2. 迭代每一行`Flights`桌子。 对于每一行，提取`departure_airport`,`arrival_airport`， 和`flights_count`。 
3. 对于`departure_airport`， 添加`flights_count`其在地图上的总流量。 对`arrival_airport`。 
4. 处理完所有行后，确定地图中所有机场的最大流量值。 
5. 选择所有客流量等于最大值的机场并将其作为结果返回。 

**为什么有效：** 该方法保证了正确性，因为每个航班对出发机场的流量和到达机场的流量只贡献一次。 在单次遍历中对这些进行求和可确保不会错过任何机场并避免冗余计算。 

## Python 解决方案```python
import pandas as pd

# For LeetCode SQL, we would use a query; for Python simulation:

def mostTrafficAirports(flights: pd.DataFrame) -> pd.DataFrame:
    traffic = {}
    for _, row in flights.iterrows():
        dep, arr, count = row['departure_airport'], row['arrival_airport'], row['flights_count']
        traffic[dep] = traffic.get(dep, 0) + count
        traffic[arr] = traffic.get(arr, 0) + count
    
    max_traffic = max(traffic.values())
    result = pd.DataFrame({'airport_id': [airport for airport, t in traffic.items() if t == max_traffic]})
    return result
```该代码使用字典来累积流量计数。 每行都对出发和到达计数有所贡献。 处理完所有行后，我们确定最大值并提取与其匹配的所有机场。 

## 解决方案```go
package main

type Flight struct {
	DepartureAirport int
	ArrivalAirport   int
	FlightsCount     int
}

func mostTrafficAirports(flights []Flight) []int {
	traffic := make(map[int]int)
	for _, f := range flights {
		traffic[f.DepartureAirport] += f.FlightsCount
		traffic[f.ArrivalAirport] += f.FlightsCount
	}
	
	maxTraffic := 0
	for _, t := range traffic {
		if t > maxTraffic {
			maxTraffic = t
		}
	}
	
	var result []int
	for airport, t := range traffic {
		if t == maxTraffic {
			result = append(result, airport)
		}
	}
	return result
}
```在 Go 中，我们使用地图来累积流量计数。 我们迭代一次来计算总数，然后迭代地图来识别客流量最大的机场。

 最大值为 9，因此返回机场 1、2、3、4。

 ## 边缘情况

 1. **单一航班：** 当只有一个航班时，其所连接的两个机场均应被视为具有最大流量。 该算法正确地将航班计数添加到出发和到达。 
2. **绑定机场：** 如果多个机场具有相同的最大流量，则解决方案必须包括所有机场。 使用最终过滤器`traffic == max_traffic`确保了这一点。 
3. **机场仅出现一次：** 某些机场可能仅显示为出发地或仅显示为到达地。 该算法自然地处理这个问题，因为它使用以下命令将计数初始化为零`get`或者`+=`在地图中。 

该解决方案非常全面，可以处理所有边缘情况，并提供干净的基于 O(n) 聚合的计算。
