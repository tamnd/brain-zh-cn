[LeetCode 问题 2135](https://leetcode.com/problems/count-words-obtained-after-adding-a-letter/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、位操作、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们确定有多少个字符串`targetWords`可以由以下字符串组成`startWords`通过具体的改造。 该转换涉及两个操作：附加字符串中尚未存在的单个字母，然后任意重新排列所有字母。 本质上，我们正在检查是否可以通过添加一个新字符并排列结果来从某个起始单词生成目标单词。 

输入由两个字符串数组组成：`startWords`和`targetWords`，每个仅包含小写英文字母，字符串中没有重复项。 输出是一个整数，表示可以从任何起始单词获得的目标单词的数量。 

约束很重要：每个数组中最多可以有 50,000 个单词，每个字符串最多有 26 个字母。 这表明由于组合爆炸，检查每个排列的强力解决方案是不可行的。 此外，唯一字母保证简化了问题，因为我们在执行操作时不需要考虑重复的字母。 

关键的边缘情况包括空字符串（尽管约束保证长度≥1）、单字母字符串以及由于字母重叠而无法进行转换的情况。 

## 方法

 暴力方法将尝试模拟每个操作`startWord`通过添加一个新字母并排列结果来生成所有可能的字符串，然后检查是否有任何匹配a`targetWord`。 这种方法是正确的，但效率很低，因为生成字符串的所有排列都是长度的阶乘，这对于长度高达 26 的字符串和大小为 50,000 的数组来说成本高昂。 

最佳方法利用每个字符串包含唯一字母的事实，并使用**位掩码**来有效地表示字母集。 每个字符串都可以编码为 26 位整数，其中每个位代表一个字母的存在。 为了`startWords`，我们将所有位掩码存储在一个集合中。 对于每个`targetWord`，我们通过一次删除一个字母来生成位掩码（因为该操作涉及添加一个字母来获取目标），然后检查生成的掩码是否存在于起始集中。 这是高效的，因为检查集合中的成员资格的时间复杂度为 O(1)，并且每个目标单词生成最多 26 个掩码是可行的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(S * T * 26！) | O(S * 26!) | 添加字母后生成所有可能的排列 |
 | 最佳| O(S + 26 * T) | O(S)| 使用位掩码表示进行高效检查 |

 ## 算法演练

 1.初始化一个空集`start_masks`存储所有的位掩码表示`startWords`。 
2. 对于其中的每个单词`startWords`，将其转换为位掩码，其中每个位代表一个字母的存在。 将此掩码添加到`start_masks`。 
3. 初始化计数器`count`为零。 这将跟踪数量`targetWords`可以得到。 
4. 对于其中的每个单词`targetWords`，将其转换为位掩码表示形式。 
5. 对于每一个字母`targetWord`，通过**删除**该字母（即从目标掩码中减去与该字母对应的位）来生成新掩码。 这代表了一种可能的`startWord`可以生成目标。 
6. 如果任何这些生成的掩码存在于`start_masks`, 增量`count`并中断到下一个目标单词。 
7.处理完所有目标词后，返回`count`。 

**为什么有效：** 每个目标单词只能通过在起始单词上添加一个字母来获得。 通过反转操作（删除一个字母），我们使用位掩码有效地检查所有可能的候选起始词。 由于映射是唯一的并且检查是 O(1)，这保证了正确性。 

## Python 解决方案```python
from typing import List

class Solution:
    def wordCount(self, startWords: List[str], targetWords: List[str]) -> int:
        def word_to_mask(word: str) -> int:
            mask = 0
            for ch in word:
                mask |= 1 << (ord(ch) - ord('a'))
            return mask

        start_masks = {word_to_mask(word) for word in startWords}
        count = 0

        for word in targetWords:
            target_mask = word_to_mask(word)
            for ch in word:
                possible_start = target_mask & ~(1 << (ord(ch) - ord('a')))
                if possible_start in start_masks:
                    count += 1
                    break

        return count
```功能`word_to_mask`将单词转换为位掩码，有效地对所有字母进行编码。`start_masks`存储所有起始词掩码以便快速查找。 对于每个目标单词，删除每个字母并检查成员资格可确保我们只计算有效的转换，从而避免不必要的计算。 

## 解决方案```go
func wordCount(startWords []string, targetWords []string) int {
    wordToMask := func(word string) int {
        mask := 0
        for i := 0; i < len(word); i++ {
            mask |= 1 << (word[i] - 'a')
        }
        return mask
    }

    startMasks := make(map[int]struct{})
    for _, word := range startWords {
        startMasks[wordToMask(word)] = struct{}{}
    }

    count := 0
    for _, word := range targetWords {
        targetMask := wordToMask(word)
        for i := 0; i < len(word); i++ {
            possibleStart := targetMask & ^(1 << (word[i] - 'a'))
            if _, exists := startMasks[possibleStart]; exists {
                count++
                break
            }
        }
    }

    return count
}
```在 Go 中，位掩码转换和映射使用在语法上略有不同。 我们使用空结构作为映射值以最小化内存。 逻辑与 Python 版本保持相同。 

## 工作示例

 **示例1：**`startWords = ["ant","act","tack"]`,`targetWords = ["tack","act","acti"]`1. 转换`startWords`到面具：`ant -> 0b111001`,`act -> 0b1011`,`tack -> 0b11101`2. 目标“大头钉”掩码：0b11101。 删除字母：

 - 删除 't' -> 0b101 -> 不在开始位置
 - 删除 'a' -> 0b1101 -> 不在启动中
 - 删除 'c' -> 0b10101 -> 不在启动中
 - 删除 'k' -> 0b1011 -> 匹配“act”→ count += 1
 3.目标“act”掩码：无法删除字母以匹配任何开头→跳过
 4. 目标“acti”掩码：0b11011。 删除字母：

 - 删除 'i' -> 0b1011 → 匹配“act” → count += 1

 结果 = 2

 ## 边缘情况

 **单字母开头和目标：**何时`startWords`或者`targetWords`只有一个字母，添加任何字母都是微不足道的，但我们必须确保我们不会尝试“添加”相同的字母，这是被禁止的。 该实现正确地使用了位掩码并避免了这种情况。 

**目标与开始相同：**如果目标单词已在`startWords`，不能算，因为运算需要加一个字母。 该算法通过生成删除一个字母的掩码来处理这一问题； 由于删除不存在的字母不会创建相同的掩码，因此目标会被正确跳过。 

**最大输入大小：** 对于 50,000 个单词和最多 26 个字母，暴力排列方法会失败。 位掩码方法仍然高效，因为它将字符串比较减少为整数比较，并将每个目标的迭代次数限制为 26 次。 这确保了可扩展性。 

该解决方案稳健、高效，并且可以处理问题约束所规定的所有边缘情况。
