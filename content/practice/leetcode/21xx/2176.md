 # LeetCode 2176，计算数组中相等且可整除的对

 ## 问题理解

 该问题给了我们一个 0 索引的整数数组`nums`和一个整数`k`。 我们需要计算有多少对索引`(i, j)`满足以下所有条件：

 1.`0 <= i < j < n`2.`nums[i] == nums[j]`3.`(i * j) % k == 0`换句话说，我们正在数组中寻找值相等的位置对，并且两个索引的乘积可整除`k`。 

输入数组表示整数序列。 输出是一个表示有效索引对数量的整数。 

限制很小：

 -`1 <= nums.length <= 100`-`1 <= nums[i], k <= 100`这些限制告诉我们一些重要的事情。 由于数组长度最多为 100，即使是`O(n^2)`解决方案是完全可以接受的。 二次解最多可以执行大约 10,000 对检查，这对于现代计算机来说是微不足道的。 

该问题还保证所有值都是正整数，因此我们不需要担心数组本身中的负数或零值。 但是，索引仍然可以为零，因为数组是 0 索引的。 这很重要，因为涉及零的索引乘法总是产生零，并且零可以被每个正整数整除。 

需要考虑一些重要的边缘情况：

 - 应返回没有重复值的数组`0`。 
- 每个值都相同的数组可能会生成许多候选对。 
- 仅有一个索引的情况`0`很特别，因为`0 * j = 0`，它总是可以被整除`k`。 
- 非常小的数组，例如长度`1`，无法形成任何有效的对。 
- 情况`k = 1`使整除条件始终为真，将问题简化为计算等值对。 

## 方法

 ### 蛮力方法

 最直接的解决方案是检查每一个可能的索引对`(i, j)`在哪里`i < j`。 

对于每对：

 1. 检查是否`nums[i] == nums[j]`。 
2. 如果相等，则计算`i * j`。 
3. 检查是否`(i * j) % k == 0`。 
4. 如果两个条件都满足，则增加答案。 

这种方法保证是正确的，因为它根据问题条件明确检查每个可能的对。 

尽管对于大量输入而言，暴力破解通常太慢，但这里的限制非常小。 和`n <= 100`，总对数最多为：$$\frac{100 \times 99}{2} = 4950$$这很容易管理。 

### 关键见解

 关键的观察结果是，约束足够小，二次解在实践中已经是最佳的。 

我们不需要高级优化，例如按值对索引进行分组或使用数论技巧，因为直接的配对检查方法足够简单、可读且高效。 

唯一真正的优化是在执行整除性计算之前首先检查值是否相等，以避免不必要的工作。

 ## 算法演练

 ### 逐步算法

 1. 初始化变量`count`到`0`。 

该变量将存储有效对的数量。 
2. 迭代所有可能的第一个索引`i`。 

循环运行自`0`到`n - 1`。 
3. 对于每个`i`，迭代所有有效的第二个索引`j`。 

由于问题需要`i < j`，第二个循环开始于`i + 1`。 
4. 检查值是否相等。 

如果`nums[i] != nums[j]`，该对不可能是有效的，所以我们立即跳过它。 
5. 如果值相等，则计算指数乘积整除条件。 

检查是否：$$(i \times j) \bmod k = 0$$6. 如果两个条件都满足，则增加`count`。 
7. 处理完所有对后，返回`count`。 

### 为什么它有效

 该算法对每个可能的索引对仅检查一次。 对于每一对，它直接验证问题陈述中的两个必需条件：

 - 同等价值
 - 指数产品的可分割性

 由于每个有效对都会被计数，并且不会对无效对进行计数，因此该算法始终会产生正确的结果。 

## Python 解决方案```python
from typing import List

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = 0

        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] == nums[j] and (i * j) % k == 0:
                    count += 1

        return count
```实现首先将数组长度存储在`n`并初始化答案变量`count`。 

外循环选择第一个索引`i`，而内部循环选择第二个索引`j`。 内循环开始于`i + 1`保证每对都满足`i < j`并防止重复检查。 

在嵌套循环内，代码首先检查数组值是否相等。 仅当此条件为真时，才会评估整除条件。 这使得逻辑简洁高效。 

只要两个条件都满足，答案计数器就会递增。 检查完所有对后，返回最终计数。 

## 解决方案```go
func countPairs(nums []int, k int) int {
    n := len(nums)
    count := 0

    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            if nums[i] == nums[j] && (i*j)%k == 0 {
                count++
            }
        }
    }

    return count
}
```Go 实现遵循与 Python 版本完全相同的逻辑。 

Go 使用显式整数类型和标准`for`循环而不是Python的`range`。 由于约束非常小，因此不必担心整数溢出，因为最大可能的乘积为`99 * 99 = 9801`。 

Go 中的切片自然地处理动态数组访问，因此对于空或小输入不需要额外的处理。

 ## 边缘情况

 ### 单元素数组

 如果数组仅包含一个元素，则不存在可能的对，因为一对需要两个不同的索引。 无法正确处理循环边界的幼稚实现可能会意外尝试无效访问。 该实现自然地避免了这种情况，因为内部循环开始于`i + 1`，它立即变得超出范围。 

### 无重复值

 具有所有唯一值的数组应始终返回`0`， 不管`k`。 有缺陷的实现可能会仅基于整除性来错误地计算对，而不首先验证相等性。 该解决方案明确检查`nums[i] == nums[j]`在增加答案之前。 

### 指数零参与

 因为数组是从 0 索引的，所以任何涉及索引的对`0`生产的产品`0`。 自从`0`可以被每个正整数整除，如果值相等，这些对总是有效的。 这是一个容易被忽视的细节。 该实现可以正确处理它，因为它直接使用数学条件：```
(i * j) % k == 0
```什么时候`i`是`0`，表达式变为`0 % k`，它正确地评估为`0`。 

### 大量重复值

 如果许多元素相同，则候选对的数量会快速增长。 某些实现可能会意外地重复计数对或包含无效的`(j, i)`订单。 该解决方案通过强制执行来防止这种情况发生`j > i`，确保每对都被精确计数一次。
