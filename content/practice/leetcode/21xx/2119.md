[LeetCode 2119 题](https://leetcode.com/problems/a-number-after-a-double-reversal/)

 **难度：** 🟢简单
 **主题：** 数学

 ## 解决方案

 ## 问题理解

 该问题要求我们判断一个数字在执行两位数反转后是否保持不变。 

数字反转是指从右向左读取数字的数字。 但是，反转后出现的任何前导零都会自动删除，因为整数不存储前导零。 

例如：

 - 倒车`526`给出`625`- 倒车`1800`给出`81`，因为相反的形式是`0081`，并且前导零被丢弃
 - 倒车`0`仍然给`0`问题描述的流程是：

 1、将原来的数字反转`num`2.再次反转结果
 3. 检查最终值是否等于原始数

 输入是单个整数`num`，输出是一个布尔值：

 - 返回`true`如果双重反转产生原始数字
 - 返回`false`否则

 限制很小：

 -`0 <= num <= 10^6`这告诉我们，性能并不是主要问题，即使是简单的解决方案也可以轻松工作。 然而，问题实际上是测试数学观察而不是实现复杂性。 

最重要的边缘情况涉及尾随零。 任何以一个或多个零结尾的数字都会在第一次反转期间丢失这些零。 一旦消失，第二次逆转就无法恢复它们。 

例如：

-`1200`- 第一次逆转 →`21`- 第二次逆转 →`12`- 最终结果与原始结果不同

 另一个重要的边缘情况是`0`。 虽然`0`技术上以零结尾，反转它仍然会产生`0`，所以两次反转后保持不变。 

该问题保证输入是非负数，因此我们不需要处理负数。 

## 方法

 ### 蛮力方法

 最直接的解决办法就是逐字模拟问题中描述的过程。 

我们可以编写一个辅助函数来逐位反转数字：

 1. 使用模提取最后一位数字
 2. 将其附加到新的反转数字上
 3. 使用整数除法删除最后一位数字
 4. 重复直到数字变为零

 实现反转功能后：

 - 反向`num`一次
 - 再次反转结果
 - 将最终值与原始值进行比较

 这种方法是正确的，因为它完全遵循问题陈述。 

尽管该解决方案对于给定的约束已经很有效，但它执行了不必要的计算，因为该问题具有简单的数学属性，可以让我们完全避免实际的逆转。 

### 最佳观察

 关键的见解是只有尾随零的数字在双重反转后才会失败。 

为什么会出现这种情况？ 

当反转数字时，尾随零变为前导零。 由于整数不保留前导零，因此它们会永久消失。 

例如：

-`3400`- 反转一次 →`43`- 再次反转 →`34`原来的零将永远丢失。 

另一方面，如果数字不以零结尾，则在反转过程中会保留每个数字，并且反转两次会恢复原始数字。 

唯一的例外是`0`本身：

 - 反向`0`→`0`- 再次反转 →`0`那么条件就变得极其简单：

 - 返回`true`如果`num == 0`- 否则返回是否`num % 10 != 0`### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(d) | O(1) | O(1) | 显式执行两次反转，其中 d 是位数 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 使用尾随零观察 |

 ## 算法演练

 1. 检查数字是否为零。 

这个特殊情况很重要，因为`0`逆转依然是`0`。 即使它以零数字结尾，它也应该返回`true`。 
2. 如果数字不为零，请使用以下命令检查其最后一位数字`num % 10`。 

模运算给出数字的最后一位。 
3. 如果最后一位数字为零，则返回`false`。 

尾随零在第一次反转期间消失，因此第二次反转无法重建原始数字。 
4.否则返回`true`。 

没有尾随零的数字通过两次反转保留所有数字。 

### 为什么它有效

 仅当第一次反转期间没有丢失信息时，双重反转才会恢复数字的原始顺序。 唯一可能消失的信息是由原始尾随零创建的前导零。 因此，每个以零结尾的非零数字都会失败，而所有其他数字都会成功。 

## Python 解决方案```python
class Solution:
    def isSameAfterReversals(self, num: int) -> bool:
        return num == 0 or num % 10 != 0
```该实现直接对数学观察结果进行编码。 

表达式`num == 0`处理输入本身为零的特殊情况。 

条件`num % 10 != 0`检查数字是否以非零数字结尾。 如果最后一位数字非零，则反转两次可以准确保留该数字。 

由于该解决方案完全避免了构造相反的数字，因此实现极其简洁和高效。 

## 解决方案```go
func isSameAfterReversals(num int) bool {
    return num == 0 || num%10 != 0
}
```Go 实现与 Python 版本几乎相同。 

Go 使用`||`用于逻辑 OR 而不是 Python 的`or`。 整数模的工作方式相同，因此检查`num%10 != 0`正确确定数字是否有尾随零。 

由于输入范围非常小，因此不用担心整数溢出。

 ## 边缘情况

 一个重要的边缘情况是数字`0`。 纯粹基于检查数字是否以零结尾的简单实现可能会错误地返回`false`为了`0`。 然而，反转零仍然会产生零，所以正确答案是`true`。 该实现显式处理这种情况`num == 0`。 

另一个关键的边缘情况是带有尾随零的数字，例如`10`,`100`， 或者`1800`。 这些数字在第一次反转期间会丢失信息，因为前导零被丢弃。 该实现使用以下方法正确检测到这种情况`num % 10 == 0`。 

第三个重要的边缘情况是内部包含零但末尾不包含零的数字，例如`101`或者`909`。 反转后内部零仍然是数字的一部分，因此双重反转可以正确恢复原始值。 由于该算法仅检查尾随零，因此可以正确处理这些情况。
