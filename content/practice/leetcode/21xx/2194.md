[LeetCode 问题 2194](https://leetcode.com/problems/cells-in-a-range-on-an-excel-sheet/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 这个问题要求我们在以字符串格式给出的矩形范围内生成所有 Excel 样式的单元格引用。 例如，每个单元格由列字母和行号标识`"A1"`或者`"K2"`。 输入字符串的格式为`"<col1><row1>:<col2><row2>"`， 在哪里`<col1>`和`<col2>`是表示起始列和结束列的大写字母，并且`<row1>`和`<row2>`是指示起始行和结束行的数字。 约束条件确保`r1 <= r2`和`c1 <= c2`，因此范围始终有效且非空。 

输出必须是表示该矩形内所有单元格的字符串列表，首先按列排序，然后按行排序。 这种排序很重要，因为首先对行进行简单迭代可能会产生不正确的序列。 该问题保证了固定的小输入大小（`s.length == 5`），所以性能不是问题，重要的是正确性和顺序。 

边缘情况包括单行、单列或单个单元格的范围。 例如，`"A1:A1"`或者`"B2:B2"`必须返回一个单元素列表。 由于列是字母，因此一个常见的错误可能是在不从 ASCII 转换的情况下以数字方式处理它们。 

## 方法

 蛮力方法很简单：迭代所有可能的列`col1`到`col2`以及所有可能的行`row1`到`row2`，为每个组合构建单元格字符串。 由于约束非常小，这种暴力方法足够高效，但可以通过利用 Python 或 Go 的范围和字符运算来提高清晰度和简单性。 

最佳方法本质上与暴力破解相同，但使用列的 ASCII 算术和行的整数算术进行干净迭代。 这确保了单元格自然地按所需的排序顺序添加，无需任何额外的排序步骤。 因为输入总是保证有`col1 <= col2`和`row1 <= row2`，这个做法简单、直接、正确。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((c2-c1+1)*(r2-r1+1)) | O((c2-c1+1)*(r2-r1+1)) | 迭代所有列和行，构建字符串 |
 | 最佳| O((c2-c1+1)*(r2-r1+1)) | O((c2-c1+1)*(r2-r1+1)) | 使用 ASCII 算术按列优先顺序迭代 |

 ## 算法演练

 1. 提取起始列（`col1`）和行（`row1`) 从字符串的第一部分开始。 
2. 提取结束列（`col2`）和行（`row2`) 来自字符串的第二部分。 
3. 初始化一个空列表来存储结果单元格。 
4. 循环从以下位置开始的列`col1`到`col2`。 将字母转换为 ASCII 整数以使迭代变得容易。 
5. 在列循环内，迭代来自`row1`到`row2`。 
6. 对于每个列-行组合，将列字母与行号连接起来形成单元格字符串。 
7. 将每个构建的单元格字符串附加到结果列表中。 
8. 两个循环完成后，返回结果列表。 

**为什么有效：** 通过首先迭代列，然后迭代行，我们保证了所需的排序顺序。 ASCII 算术确保列字母正确递增，整数迭代处理行号。 由于循环覆盖了包含范围内的所有值，因此不会跳过任何单元格。 

## Python 解决方案```python
from typing import List

class Solution:
    def cellsInRange(self, s: str) -> List[str]:
        col1, row1 = s[0], s[1]
        col2, row2 = s[3], s[4]
        
        result = []
        for c in range(ord(col1), ord(col2) + 1):
            for r in range(int(row1), int(row2) + 1):
                result.append(chr(c) + str(r))
        return result
```**说明：** 代码首先从输入字符串中提取起始和结束列字母以及行数字。`ord()`将字母转换为 ASCII 代码以方便迭代。 嵌套循环迭代列和行，通过将列 ASCII 转换回字符并连接行来构造每个单元格字符串。 结果列表自然遵循列优先的顺序。 

## 解决方案```go
func cellsInRange(s string) []string {
    col1, row1 := s[0], s[1]
    col2, row2 := s[3], s[4]
    
    var result []string
    for c := col1; c <= col2; c++ {
        for r := row1; r <= row2; r++ {
            result = append(result, string(c)+string(r))
        }
    }
    return result
}
```**Go 特定说明：** Go 允许对字节进行迭代，这是有效的，因为输入使用 ASCII 字母和数字。`string(c)`将字节转换为字符串。 与 Python 不同，Go 字符串是不可变的，因此每次连接都会创建一个新字符串。 结果切片动态增长`append`。

 ## 边缘情况

 第一个边缘情况是由单个单元格组成的范围，例如`"C3:C3"`。 幼稚的实现可能会尝试循环超出起始值，但正确的处理是准确包含该单元格。 该解决方案可以正确处理它，因为循环边界是包容性的。 

第二个边缘情况是具有多行的单列，例如`"B2:B5"`。 在这里，重要的是列不会增加，只有行会增加。 该实现通过将列循环固定在单个值上并正常迭代内部行循环来确保这一点。 

第三种边缘情况是单行多列，例如`"D4:G4"`。 在这种情况下，重要的是行保持不变，而列增加。 迭代外循环中的列和内循环中的行的嵌套循环结构保证了正确处理。 这三种情况涵盖了差一错误、错误排序和边界处理的潜在陷阱。
