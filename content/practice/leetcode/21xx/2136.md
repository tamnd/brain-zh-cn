 ## 解决方案

 ## 问题理解

 这个问题提出了一个场景，我们有`n`花种子，每种花种子都需要两个阶段才能开花：种植阶段和生长期。 每粒种子`i`需要`plantTime[i]`全天种植，可以分散在非连续的日子里。 播种后，种子需要`growTime[i]`整整几天的生长时间，只有在这段时间之后花朵才会开花。 目标是确定所有花朵最早开放的日期。 

输入由两个等长数组组成：`plantTime`和`growTime`。 输出是一个整数，表示每朵花完全盛开的最早日期。 约束表明`n`最多可达 100,000 个，个别时间最多可达 10,000 个，因此探索种植顺序的所有排列的简单方法将会太慢。 重要的是，该问题保证种植时间和生长时间均为正整数，因此我们不需要处理零或负值。 

要考虑的关键边缘情况包括只有一个种子时、所有种子时`growTime`值相同，或者当种植时间大于生长时间时，反之亦然。 这些边缘情况可能会挑战简单的调度策略。 

## 方法

 ### 蛮力方法

 强力方法将尝试尝试种子种植顺序的每种可能的排列，计算每个序列的开花日，并返回所有排列中的最小开花日。 对于每个排列，种子的开花日是该种子的累积种植时间加上其生长时间。 虽然正确，但这种方法对于大型计算来说是不可行的`n`因为排列的数量是`n!`，它呈阶乘增长。 

### 最佳方法

 关键的见解是种植顺序会影响最后一颗种子开花的时间。 为了最大限度地减少总开花日，我们应该优先种植需要较长时间才能较早生长的种子。 原因是生长时间长的种子会成为瓶颈。 尽早种植它们可以使它们的生长与其他种子的种植同时进行。 这本质上是一种贪婪策略：按降序对种子进行排序`growTime`并按顺序种植它们。 然后，跟踪累积种植天数并计算每个种子的开花日：`current_plant_day + growTime[i]`。 这些开花天数的最大值给出了所有种子开花的最早日期。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 生成所有排列并计算开花日 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 按生长时间降序排序并贪婪地计算开花天数 |

 ## 算法演练

 1. 将每个种子配对`plantTime`和`growTime`一起跟踪两个值以进行排序。 
2. 对种子进行排序`growTime`按降序排列，确保先种植生长期较长的种子。 
3.初始化两个变量：`current_day`跟踪累计种植天数和`earliest_full_bloom`追踪最近的开花日。 
4. 迭代排序后的种子：

 1. 增量`current_day`由种子的`plantTime`，代表种植这颗种子（包括这颗种子）所花费的天数。 
2. 计算种子的开花日：`current_day + growTime`。 
3. 更新`earliest_full_bloom`作为其当前值和该种子的开花日的最大值。 
5.处理完所有种子后，`earliest_full_bloom`包含所有种子开花的最早一天。 

**为什么有效**：通过首先种植生长时间较长的种子，我们可以让它们的生长与生长较短的种子的种植重叠，从而最大限度地减少最长开花日。 这种贪心策略保证了最早的一天，而不需要考虑所有排列。 

## Python 解决方案```python
from typing import List

class Solution:
    def earliestFullBloom(self, plantTime: List[int], growTime: List[int]) -> int:
        seeds = list(zip(plantTime, growTime))
        seeds.sort(key=lambda x: -x[1])  # Sort by growTime descending

        current_day = 0
        earliest_full_bloom = 0

        for plant, grow in seeds:
            current_day += plant
            earliest_full_bloom = max(earliest_full_bloom, current_day + grow)

        return earliest_full_bloom
```Python 实现将每个种子的种植时间和生长时间配对，按生长时间降序对种子进行排序，然后迭代累积种植天数，同时跟踪最近的开花日期。 这与算法演练完全对应。 

## 解决方案```go
import "sort"

func earliestFullBloom(plantTime []int, growTime []int) int {
    n := len(plantTime)
    seeds := make([][2]int, n)
    for i := 0; i < n; i++ {
        seeds[i] = [2]int{plantTime[i], growTime[i]}
    }

    sort.Slice(seeds, func(i, j int) bool {
        return seeds[i][1] > seeds[j][1] // Descending growTime
    })

    currentDay := 0
    earliestFullBloom := 0

    for _, seed := range seeds {
        currentDay += seed[0]
        if currentDay+seed[1] > earliestFullBloom {
            earliestFullBloom = currentDay + seed[1]
        }
    }

    return earliestFullBloom
}
```Go 的实现与 Python 类似，使用切片来存储种子元组。 排序是使用处理的`sort.Slice`。 整数加法和比较可确保正确跟踪累积种植天数和最大开花天数。

 ## 边缘情况

 一种重要的边缘情况是只有一颗种子时。 该算法正确地处理了它，因为对单个元素进行排序不会改变顺序，而花期只是`plantTime[0] + growTime[0]`。 

另一个边缘情况是多个种子具有相同的生长时间。 该排序保持确定性顺序，并且正确跟踪累积种植天数，确保开花日不会出现误算。
