[LeetCode 问题 2103](https://leetcode.com/problems/rings-and-rods/)

 **难度：** 🟢简单
 **主题：** 哈希表、字符串

 ## 解决方案

 ## 问题理解

 问题是要求我们确定有多少根标记为 0 到 9 的棒上放置有**所有三种颜色的环**。 每个环由两个字符的字符串描述：第一个字符是颜色 (`'R'`对于红色，`'G'`对于绿色，`'B'`蓝色），第二个字符是杆索引（`'0'`到`'9'`）。 输入`rings`是一个长度的字符串`2n`代表`n`戒指。 

实际上，我们需要扫描输入并跟踪每根杆上出现的颜色。 最后，我们计算有多少根杆具有**所有三种颜色**。 

限制是适度的：`1 <= n <= 100`而且只有**10根杆**，所以我们不需要进行大量的优化。 然而，我们应该确保我们的解决方案是干净的，并正确处理同一杆上的重复颜色、仅具有某些颜色的杆以及像单个环这样的最小输入。 

重要的边缘情况包括：

 - 只给出一个环，所以没有一根棒可以拥有所有三种颜色。 
- 同一根杆上有多个环，具有一些重复的颜色。 
- 最大输入长度（`2n = 200`），确保性能仍然可以接受。 
- 从未收到戒指的棒。 

## 方法

 **暴力方法**将涉及迭代`rings`字符串并为每根棒维护已出现的颜色的列表。 最后，对于每根棒，检查它是否包含所有三种颜色。 这适用于问题大小，但需要检查每个杆的列表并与集合进行比较`{'R','G','B'}`。 

**更优化的方法**使用哈希映射（字典），其中键是杆索引（`0`到`9`）并且值是颜色集。 我们迭代字符串，对于每个颜色棒对，我们将颜色添加到与该棒相对应的集合中。 最后，数 3 组的棒直接给出答案。 这种方法简单、直接、高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 维护每根杆的颜色列表，检查每根杆的所有三种颜色 |
 | 最佳| O(n) | O(1) | O(1) | 对棒使用集合的哈希映射； 只有 10 根杆，因此空间是恒定的 |

 ## 算法演练

 1.初始化一个字典`rod_colors`其中键是杆索引（`0`到`9`）和值是空集，用于存储每根杆上看到的颜色。 
2. 迭代`rings`步骤 2 中的字符串：

 - 提取物`color`作为索引处的字符`i`。 
- 提炼`rod`作为索引处的字符`i+1`。 
- 添加`color`到`rod_colors[rod]`。 
3. 初始化计数器`count`至 0。 
4. 迭代中的集合`rod_colors`:

 - 如果该集合包含所有三种颜色（`len(set) == 3`), 增量`count`。 
5. 返回`count`作为具有所有三种颜色的棒的数量。 

**工作原理：** 每组杆只包含唯一的颜色，因此计算尺寸为 3 组的杆可以保证杆有红色、绿色和蓝色。 该算法直接捕获颜色的分布，无需多余的检查。 

## Python 解决方案```python
class Solution:
    def countPoints(self, rings: str) -> int:
        rod_colors = {str(i): set() for i in range(10)}
        
        for i in range(0, len(rings), 2):
            color = rings[i]
            rod = rings[i+1]
            rod_colors[rod].add(color)
        
        count = 0
        for colors in rod_colors.values():
            if len(colors) == 3:
                count += 1
        
        return count
```**说明：** 字典理解为每个杆初始化一个集合。 以 2 为步进行迭代可确保我们正确读取色杆对。 添加到集合会自动处理重复项。 最后，检查设定长度以确定杆是否具有所有三种颜色。 

## 解决方案```go
func countPoints(rings string) int {
    rodColors := make(map[byte]map[byte]bool)
    for i := byte('0'); i <= '9'; i++ {
        rodColors[i] = make(map[byte]bool)
    }

    for i := 0; i < len(rings); i += 2 {
        color := rings[i]
        rod := rings[i+1]
        rodColors[rod][color] = true
    }

    count := 0
    for _, colors := range rodColors {
        if len(colors) == 3 {
            count++
        }
    }

    return count
}
```**Go 特定说明：** 我们使用地图来表示颜色集。 外部映射键是棒字节，内部映射充当集合（`map[byte]bool`）。 与 Python 集不同，Go 需要显式初始化映射。

 ## 边缘情况

 第一个边缘情况是输入字符串仅包含一个环时。 在这种情况下，没有一根棒可以具有全部三种颜色。 实现通过最后检查集合大小来正确处理这个问题。 

第二种边缘情况是当多个相同颜色的环放置在同一根杆上时
