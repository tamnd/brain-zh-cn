[LeetCode 问题 2109](https://leetcode.com/problems/adding-spaces-to-a-string/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、字符串、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们在给定的字符串中插入空格`s`在数组描述的特定位置`spaces`。 中的每个元素`spaces`表示字符串中的索引**之前**应插入一个空格。 例如，如果`spaces = [2]`和`s = "hello"`，输出将是`"he llo"`。 

输入字符串`s`最长可达 300,000 个字符，并且`spaces`数组还可以包含最多 300,000 个索引。 所有指数位于`spaces`严格递增，这意味着我们永远不会有重复的位置，我们可以遍历`spaces`在迭代字符串时一次性完成。 

重要的边缘情况包括在第一个字符之前插入空格、连续插入空格以及`spaces`覆盖字符串的所有字符。 该问题保证严格增加索引，因此我们不需要处理重复或无序索引。 

预期的输出是一个字符串，其中空格已准确插入到由`spaces`大批。 

## 方法

 蛮力方法是迭代`spaces`数组并使用切片操作重复将空格插入到字符串中。 每次插入都会创建一个新字符串，因为字符串是不可变的。 虽然这是正确的，但效率很低，因为重复插入字符串的每次插入成本为 **O(n)** 。 和`m`空格和长度的字符串`n`，总时间复杂度可以达到 **O(n * m)**，这对于约束（最多 300,000 个字符和索引）来说太慢了。 

最佳方法利用了字符串不可变但列表不可变这一事实。 我们可以遍历字符串一次，将每个字符附加到列表中。 使用指针`spaces`数组中，只要当前索引与数组中的下一个元素匹配，我们就插入一个空格`spaces`。 这确保了 **O(n + m)** 时间复杂度和 **O(n + m)** 额外空间来构造最终字符串。 此方法使用单遍并避免重复的字符串连接。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n) | 使用字符串切片的方式一一插入空格； 大输入效率低下 |
 | 最佳| O(n + m) | O(n + m) | 使用指针遍历字符串一次`spaces`有效插入空格|

 ## 算法演练

 1. 初始化一个列表`result`保存最终字符串的字符和空格。 使用列表是因为附加到列表的平均时间复杂度为 O(1)，这与字符串连接不同。 
2. 初始化一个指针`space_index`在 0 处跟踪我们当前的位置`spaces`大批。 
3. 遍历字符串`s`使用索引`i`。 
4. 在每个索引处`i`，检查是否`space_index`在界限内并且如果`spaces[space_index] == i`。 如果是这样，请在后面添加一个空格`result`并增加`space_index`。 
5. 追加字符`s[i]`到`result`。 
6. 继续，直到处理完所有字符。 
7. 加入列表`result`成一个字符串并返回它。 

**为什么有效**：指针通过`spaces`确保我们只在指定的索引处添加空格。 因为`spaces`是严格递增的，我们永远不会在同一位置插入两次空格。 不变的是`result`对于所有索引，始终包含正确间隔的字符`i`。 

## Python 解决方案```python
from typing import List

class Solution:
    def addSpaces(self, s: str, spaces: List[int]) -> str:
        result = []
        space_index = 0
        for i, char in enumerate(s):
            if space_index < len(spaces) and spaces[space_index] == i:
                result.append(' ')
                space_index += 1
            result.append(char)
        return ''.join(result)
```该代码创建一个列表`result`有效地构建最终的字符串。 指针`space_index`确保我们只检查下一个相关空间。 每个字符都会处理一次，并且仅在需要时添加空格，从而产生 O(n + m) 解决方案。 

## 解决方案```go
func addSpaces(s string, spaces []int) string {
    result := make([]byte, 0, len(s)+len(spaces))
    spaceIndex := 0
    for i := 0; i < len(s); i++ {
        if spaceIndex < len(spaces) && spaces[spaceIndex] == i {
            result = append(result, ' ')
            spaceIndex++
        }
        result = append(result, s[i])
    }
    return string(result)
}
```Go 版本反映了 Python 解决方案。 我们预先分配切片容量以避免多次调整大小。 迭代逻辑是相同的：使用指针跟踪下一个空格，将字符附加到切片，并在最后转换为字符串。

 ## 边缘情况

 一个重要的边缘情况是在字符串的第一个字符之前插入空格。 一个天真的解决方案可能假设第一个字符前面不应该有空格。 该算法通过检查当前索引来正确处理这个问题`spaces`。 

另一个边缘情况是当`spaces`包含连续索引。 例如，`spaces = [0,1,2]`和`s = "abc"`应该输出`" a b c"`。 使用单个指针可确保每个空格在正确位置精确插入一次。 

第三种边缘情况是最后一个字符前面有空格。 例如，`spaces = [n-1]`。 当索引等于最后一个元素时，解决方案正确地附加一个空格`spaces`，确保在最后一个字符之前添加空格。 

这种方法涵盖了问题约束所保证的所有边缘情况，包括严格增加空间索引和最大输入大小。
