[LeetCode 问题 2153](https://leetcode.com/problems/the-number-of-passengers-in-each-bus-ii/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题描述了乘客到达公交车站和公交车到达接他们的模拟。 每辆巴士都有唯一的 ID、到达时间和容量限制。 每位乘客都有一个唯一的 ID 和到达时间。 已到达巴士或在巴士到达之前到达且尚未登上之前巴士的乘客将尝试登上巴士。 如果等待的乘客数量超过巴士的载客量，则只提供最先的乘客`capacity`乘客按到达时间顺序登机。 

输入由两个表组成：`Buses`和`Passengers`。 这`Buses`表提供公交车 ID、到达时间和容量。 这`Passengers`表提供乘客 ID 和到达时间。 输出应该是一个列出每个的表格`bus_id`成功登机的乘客人数，按升序排列`bus_id`。 

需要注意的要点：所有公交车 ID 和乘客 ID 都是唯一的，公交车到站时间是唯一的，载客量为正整数，并且没有两辆公交车同时到达。 重要的边缘情况包括等待乘客为零的公交车、所有公交车发车后到达的乘客以及公交车容量小于等待乘客数量的公交车。 

## 方法

 暴力方法将直接模拟该场景。 对于每辆巴士，我们将迭代所有乘客并选择那些在巴士到达时间到达但尚未登上巴士的乘客。 选择乘客后，我们会根据巴士的载客量限制上车。 这种方法可行，但效率很低，尤其是在有数千名乘客和公交车的情况下，因为对于每辆公交车，我们都会遍历所有乘客，从而导致潜在的 O(n*m) 复杂度，其中 n 是公交车的数量，m 是乘客的数量。 

更优化的解决方案依赖于按到达时间对公共汽车和乘客进行排序。 通过使用两个指针，一个用于公共汽车，一个用于乘客，我们可以按时间顺序迭代乘客并有效地将他们与公共汽车匹配。 这确保了每位乘客都被考虑一次，并且每辆公交车仅处理相关的乘客子集，从而减少了不必要的比较。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n) | 迭代每辆公交车并过滤在其之前到达的所有乘客 |
 | 最佳| O(n log n + m log m) | O(n log n + m log m) | O(n + m) | 对公交车和乘客进行排序，然后使用两个指针来模拟登机 |

 ## 算法演练

 1. 排序`Buses`表格依据`arrival_time`和`Passengers`表格依据`arrival_time`。 
2. 初始化一个指针`p`迭代乘客和空结果列表。 
3. 对于每辆公交车（按时间顺序）：

 1.初始化一个计数器`boarded`至 0。 
2. 虽然`p`指向当前巴士到达或之前到达的乘客，并且`boarded`小于总线容量：

 1. 增量`boarded`1.
 2. 移动乘客指针`p`给下一位乘客。 
3. 记录`bus_id`和`boarded`计入结果列表。 
4.处理完所有总线后，对结果列表进行排序`bus_id`产生最终的输出。 

工作原理：该算法保证乘客尽可能最早登上公交车，因为我们按时间顺序处理公交车，并且只向前移动乘客指针。 每辆巴士均遵守载客量限制，每位乘客最多搭乘一辆巴士。 

## Python 解决方案```python
import pandas as pd

class Solution:
    def numberOfPassengers(self, Buses: pd.DataFrame, Passengers: pd.DataFrame) -> pd.DataFrame:
        # Sort buses and passengers by arrival time
        buses_sorted = Buses.sort_values('arrival_time').reset_index(drop=True)
        passengers_sorted = Passengers.sort_values('arrival_time').reset_index(drop=True)
        
        p = 0
        total_passengers = len(passengers_sorted)
        result = []

        for _, bus in buses_sorted.iterrows():
            capacity = bus['capacity']
            boarded = 0
            # Board passengers until capacity is filled or no eligible passengers left
            while p < total_passengers and passengers_sorted.at[p, 'arrival_time'] <= bus['arrival_time'] and boarded < capacity:
                boarded += 1
                p += 1
            result.append({'bus_id': bus['bus_id'], 'passengers_cnt': boarded})

        # Return result sorted by bus_id
        return pd.DataFrame(result).sort_values('bus_id').reset_index(drop=True)
```此实现首先按到达时间对两个表进行排序，以使按时间顺序登机变得简单。 我们使用指针`p`跟踪下一位要考虑的乘客，并在乘客登上公交车时增加该乘客的数量。 对于每辆巴士，我们会计算在不超过其容量的情况下上车的乘客人数。 最终结果排序为`bus_id`根据需要。 

## 解决方案```go
package main

import (
    "sort"
)

type Bus struct {
    BusID       int
    ArrivalTime int
    Capacity    int
}

type Passenger struct {
    PassengerID int
    ArrivalTime int
}

type BusResult struct {
    BusID          int
    PassengersCnt  int
}

func NumberOfPassengers(buses []Bus, passengers []Passenger) []BusResult {
    sort.Slice(buses, func(i, j int) bool { return buses[i].ArrivalTime < buses[j].ArrivalTime })
    sort.Slice(passengers, func(i, j int) bool { return passengers[i].ArrivalTime < passengers[j].ArrivalTime })

    result := []BusResult{}
    p := 0
    totalPassengers := len(passengers)

    for _, bus := range buses {
        boarded := 0
        for p < totalPassengers && passengers[p].ArrivalTime <= bus.ArrivalTime && boarded < bus.Capacity {
            boarded++
            p++
        }
        result = append(result, BusResult{BusID: bus.BusID, PassengersCnt: boarded})
    }

    // Sort by BusID to match the required output order
    sort.Slice(result, func(i, j int) bool { return result[i].BusID < result[j].BusID })
    return result
}
```Go 实现镜像了 Python 版本。 我们按到达时间对公交车和乘客进行排序，使用乘客指针进行迭代，并对每辆公交车的登机乘客进行计数。 为了清晰和类型安全，Go 需要显式的切片操作和结构定义。 

## 工作示例

 使用问题陈述中的示例：

 | 巴士到达时间 | 巴士运力 | 旅客到达时间 | 登上 |
 | --- | --- | --- | --- |
 | 2 | 1 | 1 | 1 |
 | 4 | 10 | 10 1, 12 | 1 |
 | 7 | 2 | 5、6、7 | 2 |

 逐步：

 1. 公交车排序：[2, 4, 7]，乘客排序：[1, 1, 5, 6, 7]。 
2.公交车2：载客量1，上车乘客11→上车=1，p=1。 
3. 公交车 4：载客量 10，上车乘客 12 → 上车=1，p=2。 
4. 公交车 7：载客量 2，登上乘客 13 和 14 → 登上=2，p=4。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n log n + m log m) | O(n log n + m log m) | 对公共汽车和乘客进行分类在时间复杂度上占主导地位
 | 空间| O(n + m) | 我们存储排序的副本和结果 |

 排序是主要成本，而两指针迭代的运行时间为 O(n + m)，与公交车和乘客的总数呈线性关系。
