[LeetCode 问题 2108](https://leetcode.com/problems/find-first-palindromic-string-in-the-array/)

 **难度：** 🟢简单
 **主题：** 数组、两个指针、字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们检查字符串数组，`words`，并识别第一个回文字符串。 回文是向前和向后读相同的字符串。 换句话说，第一个字符与最后一个字符匹配，第二个字符与倒数第二个字符匹配，依此类推。 如果数组中没有字符串是回文，则该函数应返回空字符串`""`。 

输入由一个字符串数组组成，其中每个字符串至少有一个字符，最多 100 个字符，并且该数组包含 1 到 100 个字符串。 每个字符串仅包含小写英文字母。 这些约束确保输入大小是可管理的，并且字符串比较是直接的，而不必担心大写/小写或非字母字符。 

重要的边缘情况包括没有字符串是回文的数组、第一个字符串本身是回文的数组以及回文出现在最后的数组。 该问题保证数组中至少有一个字符串，因此我们不需要处理空数组输入。 

## 方法

 ### 蛮力方法

 暴力方法很简单：迭代数组中的每个字符串并检查它是否是回文。 要检查字符串，请从开头和结尾向中心比较其字符。 如果所有相应的字符都匹配，则该字符串是回文字符串。 一旦找到第一个回文字符串，我们就将其返回。 如果没有字符串匹配，我们返回一个空字符串。 这种方法很简单并且工作正常，因为它彻底检查每个字符串，但是对于较长的字符串，重复的字符比较可能成本高昂，尽管在问题限制内这是可以接受的。 

### 最佳方法

 在这种情况下，最佳方法本质上与蛮力相同，因为输入大小很小。 关键的见解是，顺序检查每个字符串是有效的，一旦找到回文，我们就可以立即返回。 不需要额外的数据结构或预处理，因为操作在字符串数量和每个字符串的长度方面已经是线性的。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(1) | O(1) | 迭代每个字符串并通过比较字符来检查回文 |
 | 最佳| O(n * m) | O(1) | O(1) | 与暴力破解相同，但一旦发现回文就提前退出 |

 _n = 字符串数量，m = 最大字符串长度_

 ## 算法演练

 1. 迭代每个字符串`word`在输入数组中`words`。 
2. 对于每个`word`，检查是否是回文。 初始化两个指针，`left`在开始时和`right`在字符串的末尾。 
3. 比较字符`left`和`right`。 如果匹配，则移动`left`向前和`right`落后。 
4. 如果有任何字符不匹配，则该字符串不是回文。 继续下一个字符串。 
5. 如果所有字符比较都匹配（即`left >= right`)，立即返回该字符串。 
6. 如果检查所有字符串后没有找到回文，则返回空字符串`""`。 

为什么有效：通过从两端向中心对称地比较字符，我们可以保证正确识别回文。 在第一次成功检查后立即返回可确保我们获得数组中的第一个回文字符串。 

## Python 解决方案```python
from typing import List

class Solution:
    def firstPalindrome(self, words: List[str]) -> str:
        for word in words:
            left, right = 0, len(word) - 1
            is_palindrome = True
            while left < right:
                if word[left] != word[right]:
                    is_palindrome = False
                    break
                left += 1
                right -= 1
            if is_palindrome:
                return word
        return ""
```Python 实现迭代中的每个字符串`words`并使用两个指针来检查回文。 如果发生不匹配，循环就会提前中断。 一旦找到回文，就将其返回。 如果整个数组中没有找到回文，则返回空字符串。 

## 解决方案```go
func firstPalindrome(words []string) string {
    for _, word := range words {
        left, right := 0, len(word)-1
        isPalindrome := true
        for left < right {
            if word[left] != word[right] {
                isPalindrome = false
                break
            }
            left++
            right--
        }
        if isPalindrome {
            return word
        }
    }
    return ""
}
```Go 解决方案遵循与 Python 相同的逻辑。 我们使用一个`for`在切片上进行范围迭代的循环。 回文检查使用两个向中心移动的索引。 如果不匹配，则会提前退出，并且立即返回找到的第一个回文。 如果没有找到，则返回空字符串。
