[LeetCode 问题 2151](https://leetcode.com/problems/maximum-good-people-based-on-statements/)

 **难度：** 🔴难
 **主题：** 数组、回溯、位操作、枚举

 ## 解决方案

 ## 问题理解

 该问题要求我们在给定一组关于彼此的陈述的情况下确定一个群体中“好人的最大数量”。 每个人都可以是**好**（总是说实话）或**坏**（可能撒谎或说实话）。 输入是一个二维方形数组`statements`尺寸的`n x n`， 在哪里`statements[i][j]`代表人`i`关于人的陈述`j`。 这些值的含义如下：`0`意思是“坏”，`1`意思是“好”，并且`2`意思是“没有声明”。 此外，每个人都不会发表关于自己的声明，即`statements[i][i] = 2`。 

目标是找到好人和坏人的分配，**最大化好人的数量**，同时与好人的陈述保持一致。 好人的陈述必须**完全真实**，而坏人的陈述可能前后矛盾。 

约束条件告诉我们`n`最多 15。这个值足够小，可以使用位操作枚举好人和坏人的所有可能组合，因为`2^15 = 32,768`，这在计算上是可行的。 重要的边缘情况包括每个人都不好、每个人都好或陈述相互矛盾且不能全部满足的情况。 

## 方法

 ### 蛮力

 一种天真的暴力方法是尝试每一种可能的好人或坏人的组合，并检查它是否有效。 我们生成所有`2^n`好的/坏的作业的组合，并且对于每个作业，验证好人所做的所有陈述是否一致。 如果是的话，我们就会计算好人的数量并跟踪最多的人。 这种方法是正确的，但可能会很慢`n=15`如果没有有效实施。 

### 最佳方法

 关键的见解是我们可以将每个分配编码为长度的**位掩码**`n`，其中一个`1`代表着一个好人和一个`0`代表坏人。 使用这种编码，我们可以有效地迭代所有组合并使用简单的按位运算或循环来验证每个分配。 与生成人员集合或数组相比，这减少了开销。 验证仅检查那些标记为良好的语句，忽略来自坏人的语句，这简化了一致性检查。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 明确检查所有组合 |
 | 位掩码枚举 | O(2^n * n^2) | O(2^n * n^2) | O(1) | O(1) | 用于赋值表示的高效位掩码 |

 ## 算法演练

 1. 将好人和坏人的每种可能的分配表示为`n`位整数，其中`i`第 位是`1`如果人`i`很好，否则`0`。 
2. 初始化变量`max_good`跟踪在有效任务中找到的好人的最大数量。 
3. 迭代所有可能的位掩码`0`到`2^n - 1`。 
4. 对于每个位掩码，假设它代表好人/坏人的当前分配。 
5. 通过迭代每个人来检查此作业的有效性。 如果此人被标记为优秀，则他们的陈述必须与作业一致。 对于每个陈述，如果它与另一个人的假定角色相矛盾，则将分配标记为无效。 
6. 如果分配有效，则计算位掩码中好人的数量并更新`max_good`如果这个数字更高。 
7. 检查完所有作业后，返回`max_good`。 

为什么有效：通过枚举所有可能的好/坏分配并仅根据好人的陈述检查一致性，我们确保考虑任何有效的配置。 由于我们明确地计算好人并最大化，因此结果保证是尽可能大的数量。 

## Python 解决方案```python
from typing import List

class Solution:
    def maximumGood(self, statements: List[List[int]]) -> int:
        n = len(statements)
        max_good = 0
        
        # Iterate over all possible assignments of good/bad people
        for mask in range(1 << n):
            valid = True
            for i in range(n):
                if (mask >> i) & 1:  # person i is good
                    for j in range(n):
                        if statements[i][j] == 2:
                            continue
                        if statements[i][j] != ((mask >> j) & 1):
                            valid = False
                            break
                    if not valid:
                        break
            if valid:
                max_good = max(max_good, bin(mask).count('1'))
        
        return max_good
```在此实现中，我们使用位掩码来表示好人和坏人的当前分配。 我们只检查标记为良好的人员的陈述，确保他们的主张与作业相符。 如果一致，我们会计算好人并更新最大值。 

## 解决方案```go
func maximumGood(statements [][]int) int {
    n := len(statements)
    maxGood := 0
    
    for mask := 0; mask < (1 << n); mask++ {
        valid := true
        for i := 0; i < n; i++ {
            if (mask>>i)&1 == 1 { // person i is good
                for j := 0; j < n; j++ {
                    if statements[i][j] == 2 {
                        continue
                    }
                    if statements[i][j] != ((mask>>j)&1) {
                        valid = false
                        break
                    }
                }
                if !valid {
                    break
                }
            }
        }
        if valid {
            count := 0
            for i := 0; i < n; i++ {
                if (mask>>i)&1 == 1 {
                    count++
                }
            }
            if count > maxGood {
                maxGood = count
            }
        }
    }
    
    return maxGood
}
```Go 特定的考虑因素包括用于位掩码的显式整数操作和设置位的手动计数，而不是使用`bin(mask).count('1')`就像在Python中一样。
