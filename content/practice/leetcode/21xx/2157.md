 **难度：** 🔴难
 **主题：** 数组、哈希表、字符串、位操作、并查找

 ## 解决方案

 ## 问题理解

 该问题要求我们根据特殊的连接概念对一组唯一的小写字符串进行分组。 每个字符串都可以表示为**一组字母**，并且如果一个字符串可以通过**精确的一个操作**转换为另一个字符串，则两个字符串**连接**：添加一个字母、删除一个字母或替换一个字母（包括用其本身替换它）。 

输入是字符串列表`words`其中每个字符串包含不同的字母，输出应该是一个数组`[number_of_groups, largest_group_size]`。 组的数量表示可以形成多少个不同的连接簇，最大的组大小是任何单个组中的最大字符串数。 

关键约束包括数组的长度（`1 <= words.length <= 2 * 10^4`) 并且每个字符串最多有 26 个字母。 这些限制表明，简单的成对比较方法会太慢（`O(n^2)`），并且使用位操作或联合查找的优化表示是必要的。 

重要的边缘情况是单字符字符串、完全不相交的字符串（例如`"a"`和`"xyz"`)，以及作为其他字符串子集的字符串 (`"ab"`和`"abc"`）。 该问题保证存在唯一的分组，从而确保没有模糊的重叠。 

## 方法

 **暴力方法**会比较每对字符串，并根据这三个操作检查它们是否连接。 这涉及将字符串转换为集合并检查差异。 虽然正确，但时间复杂度为`O(n^2 * m)`在哪里`m`是平均字符串长度，这对于`n = 2 * 10^4`。 

**最佳方法**利用**位操作**和**联合查找**。 每个字符串都可以表示为一个 26 位整数，其中每个位表示一个字母的存在。 然后连接操作简化为位级操作：

 - **添加一个字母**：将一个 0 位翻转为 1。 
- **删除一个字母**：将一个 1 位翻转为 0。 
- **替换字母**：删除一个 1 位并添加一个 0 位（也可以包括用自身替换）。 

我们使用并查找（不相交集）结构来合并有效连接的字符串。 我们迭代所有掩码，生成通过一项操作可到达的所有掩码，并将它们合并。 这大大减少了检查次数并利用了快速的按位运算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * m) | O(n^2 * m) | O(n) | 使用集合运算比较每一对； 对于大 n 来说太慢 |
 | 最佳| O(n * 26^2) | O(n * 26^2) | O(n + 2^26) | O(n + 2^26) | 使用位掩码来表示字符串并使用联合查找来实现连接； 快速针对问题约束|

 ## 算法演练

 1. **将字符串转换为位掩码**：每个字符串都转换为 26 位整数，其中`1 << (ord(c) - ord('a'))`标志着性格的存在`c`。 
2. **初始化并查找**：为所有唯一掩码创建并查找结构。 
3. **联合连接掩码**：对于每个掩码，尝试所有单字母操作：

 a. **删除一个字母**：翻转每个为 1 的位，并与结果掩码（如果存在）合并。 

b. **添加一个字母**：翻转每一位为 0 的位，并与结果掩码（如果存在）合并。 

c. **替换字母**：在嵌套循环中组合删除和添加，并与所有存在的结果掩码联合。 
4. **计数组和最大组大小**：遍历所有掩码，在 union-find 中找到它们的根，并计算组的唯一根的数量。 跟踪每个根集的大小以找到最大的组。 

**为什么有效**：位掩码表示确保每个字符串的编码都是唯一的。 Union-find 将所有连接的字符串合并到同一根下，捕获问题定义的传递连接。 计算根然后直接给出组的数量，最大集合大小给出最大的组。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class UnionFind:
    def __init__(self):
        self.parent = {}
        self.size = {}

    def find(self, x):
        if x not in self.parent:
            self.parent[x] = x
            self.size[x] = 1
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return
        if self.size[px] < self.size[py]:
            px, py = py, px
        self.parent[py] = px
        self.size[px] += self.size[py]

class Solution:
    def groupStrings(self, words: List[str]) -> List[int]:
        def word_to_mask(word):
            mask = 0
            for c in word:
                mask |= 1 << (ord(c) - ord('a'))
            return mask

        masks = [word_to_mask(word) for word in words]
        uf = UnionFind()
        mask_set = set(masks)

        for mask in masks:
            uf.find(mask)

        for mask in masks:
            # Remove one letter
            for i in range(26):
                if mask & (1 << i):
                    uf.union(mask, mask ^ (1 << i))
            # Add one letter
            for i in range(26):
                if not mask & (1 << i):
                    new_mask = mask | (1 << i)
                    if new_mask in mask_set:
                        uf.union(mask, new_mask)
            # Replace one letter
            for i in range(26):
                if mask & (1 << i):
                    for j in range(26):
                        if not mask & (1 << j):
                            new_mask = mask ^ (1 << i) | (1 << j)
                            if new_mask in mask_set:
                                uf.union(mask, new_mask)

        group_count = defaultdict(int)
        for mask in masks:
            root = uf.find(mask)
            group_count[root] += 1

        return [len(group_count), max(group_count.values())]
```**说明**：我们首先将每个字符串转换为位掩码，并为每个掩码初始化 union-find。 对于每个掩码，我们模拟所有可能的单字母操作，联合集合中存在的掩码。 最后，我们通过唯一根对组进行计数并确定最大组大小。 

## 解决方案```go
package main

func groupStrings(words []string) []int {
    type UnionFind struct {
        parent map[int]int
        size   map[int]int
    }

    uf := &UnionFind{
        parent: make(map[int]int),
        size:   make(map[int]int),
    }

    var find func(x int) int
    find = func(x int) int {
        if _, ok := uf.parent[x]; !ok {
            uf.parent[x] = x
            uf.size[x] = 1
        }
        if uf.parent[x] != x {
            uf.parent[x] = find(uf.parent[x])
        }
        return uf.parent[x]
    }

    union := func(x, y int) {
        px, py := find(x), find(y)
        if px == py {
            return
        }
        if uf.size[px] < uf.size[py] {
            px, py = py, px
        }
        uf.parent[py] = px
        uf.size[px] += uf.size[py]
    }

    wordToMask := func(word string) int {
        mask := 0
        for _, c := range word {
            mask |= 1 << (c - 'a')
        }
        return mask
    }

    masks := make([]int, len(words))
    maskSet := make(map[int]bool)
    for i, word := range words {
        masks[i] = wordToMask(word)
        maskSet[masks[i]] = true
        find(masks[i])
    }

    for _, mask := range masks {
        // Remove one letter
        for i := 0; i < 26; i++ {
            if mask&(1<<i) != 0 {
                union(mask, mask^(1<<i))
            }
        }
        // Add one letter
        for i := 0; i < 26; i++ {
            if mask&(1<<i) == 0 {
                newMask := mask | (1 << i)
                if maskSet[newMask] {
                    union(mask, newMask)
                }
            }
        }
        // Replace one letter
        for i := 0; i < 26; i++ {
            if mask&(1<<i) != 0 {
                for j := 0; j < 26; j++ {
                    if mask&(1<<j) == 0 {
                        newMask := mask^(1<<i) | (1 << j)
                        if maskSet[newMask] {
                            union(mask, newMask)
                        }
                    }
                }
            }
        }
    }

    groupCount := make(map[int]int)
    maxSize := 0
    for _, mask := range masks {
        root := find(mask)
        groupCount[root]++
        if groupCount[root] > maxSize {
            maxSize = groupCount[root]
        }
    }

    return []int{len(groupCount), maxSize}
}
