[LeetCode 问题 2196](https://leetcode.com/problems/create-binary-tree-from-descriptions/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、树、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们从关系列表构建二叉树，其中每个关系给出为`[parent, child, isLeft]`。 这里，`parent`是节点的值，`child`是其直系后代的值，并且`isLeft`表示是否`child`是左孩子（`1`) 或右孩子 (`0`）。 所有节点值都是唯一的，因此每个值恰好对应一个树节点。 

输入是大小最大为 10,000 的二维数组，值可以大到 100,000。 这告诉我们，解决方案需要在时间和空间上都高效，因为寻找父母或孩子的简单 O(n²) 搜索可能太慢。 

输出是树的根节点，它被定义为在任何描述中都不作为子节点出现的节点。 该问题保证二叉树是有效的，这意味着没有循环，并且每个子树只有一个父树。 

重要的边缘情况包括树本质上是一个链表（所有节点要么左要么右），或者只有一对父子对的最小可能输入。 

## 方法

 强力方法将根据需要创建树节点，并且对于每个描述，搜索现有节点以将子节点附加到正确的父节点。 这种方法是正确的，但效率低下，因为重复搜索节点可能会导致 O(n²) 复杂度。 

最佳方法利用哈希图来有效地存储和检索节点并确定根。 我们可以使用以下方法一次性创建所有节点`value → TreeNode`地图和另一套用于跟踪儿童的信息。 永远不会作为子节点出现的节点是根节点。 这避免了重复搜索，并允许我们在每个描述的 O(1) 时间内附加子项。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 在不断增长的节点列表中反复搜索父节点 |
 | 最佳| O(n) | O(n) | 使用哈希图有效地跟踪节点和子节点 |

 ## 算法演练

 1.初始化一个空字典`nodes`将值映射到`TreeNode`对象。 这允许按值即时检索或创建节点。 
2.初始化一个空集`children`跟踪作为子节点出现的所有节点值。 这将有助于我们稍后识别根。 
3. 迭代每个描述`[parent, child, isLeft]`。 对于每个值，检查它是否存在于`nodes`。 如果没有，则创建一个新的`TreeNode`并将其添加到`nodes`。 
4. 更新`children`通过添加来设置`child`。 
5. 附上`child`节点到`parent`节点作为左子节点如果`isLeft == 1`或者作为右孩子，如果`isLeft == 0`。 
6. 处理完所有描述后，根就是值为 in 的节点`nodes`但不在`children`。 检索并返回该节点。 

**为什么有效：** 每个节点都只创建一次并根据描述进行附加。 由于该问题保证一棵有效的树，因此将恰好有一个不是子节点，从而确保唯一的根。 使用哈希映射可确保节点检索的时间复杂度为 O(1)，从而提供整体线性解决方案。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def createBinaryTree(self, descriptions: list[list[int]]) -> TreeNode:
        nodes = {}
        children = set()
        
        for parent_val, child_val, is_left in descriptions:
            if parent_val not in nodes:
                nodes[parent_val] = TreeNode(parent_val)
            if child_val not in nodes:
                nodes[child_val] = TreeNode(child_val)
            
            children.add(child_val)
            
            if is_left:
                nodes[parent_val].left = nodes[child_val]
            else:
                nodes[parent_val].right = nodes[child_val]
        
        for val in nodes:
            if val not in children:
                return nodes[val]
```Python 实现使用字典来存储节点和集合来跟踪子节点。 每个描述都会处理一次，根据需要创建节点并根据描述将它们链接起来`isLeft`旗帜。 最后，我们迭代节点值以找到不在列表中的节点值。`children`集，即根。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func createBinaryTree(descriptions [][]int) *TreeNode {
    nodes := make(map[int]*TreeNode)
    children := make(map[int]bool)
    
    for _, desc := range descriptions {
        parentVal, childVal, isLeft := desc[0], desc[1], desc[2]
        
        if _, ok := nodes[parentVal]; !ok {
            nodes[parentVal] = &TreeNode{Val: parentVal}
        }
        if _, ok := nodes[childVal]; !ok {
            nodes[childVal] = &TreeNode{Val: childVal}
        }
        
        children[childVal] = true
        
        if isLeft == 1 {
            nodes[parentVal].Left = nodes[childVal]
        } else {
            nodes[parentVal].Right = nodes[childVal]
        }
    }
    
    for val, node := range nodes {
        if !children[val] {
            return node
        }
    }
    return nil
}
```Go 实现镜像了 Python 解决方案，但使用了`map[int]*TreeNode`对于节点和`map[int]bool`用于追踪儿童。 附加子项和识别根的逻辑是相同的，如果未找到则返回根时隐含 nil 处理。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 我们对每个描述进行一次迭代，并使用哈希映射对每个描述执行 O(1) 操作 |
 | 空间| O(n) | 我们将所有节点存储在映射中并跟踪集合中的所有子节点，大小均为 O(n) |

 该算法是线性的，因为每个描述都只处理一次，并且哈希映射查找和插入的时间复杂度为 O(1)。
