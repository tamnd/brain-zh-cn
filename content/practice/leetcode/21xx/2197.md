[LeetCode 问题 2197](https://leetcode.com/problems/replace-non-coprime-numbers-in-array/)

 **难度：** 🔴难
 **主题：** 数组、数学、堆栈、数论

 ## 解决方案

 ## 问题理解

 该问题要求我们用**最小公倍数（LCM）**重复替换数组中相邻的**非互质**数字，直到不再存在相邻的非互质对。 如果两个数字的**最大公约数 (GCD)** 大于 1，则这两个数字互质。在所有可能的替换之后，应返回最终数组。 

换句话说，给定一个整数数组，我们必须迭代地组合共享大于 1 的任何公因数的数字。一旦两个数字被组合到它们的 LCM 中，它可能会与相邻数字创建新的非互质对，因此该过程将继续，直到无法进行进一步的组合为止。 数组长度最大可达 100,000，每个整数最大可达 100,000，但最终数组值保证小于或等于 108。 

关键边缘情况包括所有数字互质的数组、长度为 1 的数组、具有重复数字的数组或可能发生重复替换的数组，需要仔细的迭代方法。 

## 方法

 一种强力方法是从左到右迭代数组，计算每个相邻对的 GCD，并用它们的 LCM 替换非互质对。 每次替换后，迭代将从先前的索引重新开始，以检查新形成的非互质对。 虽然这适用于小型数组，但对于大型数组来说效率极低，因为重复重新计算同一对的 GCD 可能会导致 **O(n^2)** 时间复杂度。 

最佳解决方案利用**堆栈**来维护连续的数字列表。 对于每个新数字，我们反复将其与**堆栈顶部**进行比较。 如果它们不互质，我们用两者的 LCM 替换顶部元素，并继续检查，直到新的堆栈顶部与当前数字互质。 如果互质，我们将数字压入堆栈。 这种方法避免了重新开始迭代，并保证了平均的**线性时间复杂度**，因为每个元素都被处理一次，偶尔会重复 LCM 计算。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 重复迭代数组，每次替换后重新计算相邻元素的 GCD。 |
 | 最优（堆栈）| O(n log max(num)) | O(n log max(num)) | O(n) | 使用堆栈有效地组合相邻的非互质数。 LCM/GCD 计算主导对数因子。 |

 ## 算法演练

 1. 初始化一个空堆栈来保存到目前为止已处理过的数字。 
2. 迭代输入数组中的每个数字。 
3. 当栈不为空且**栈顶**与当前数**非互质**（GCD > 1）时，将栈顶替换为栈顶元素和当前数的LCM。 使用此 LCM 更新当前数字，因为组合值可能与前一个堆栈元素形成新的非互质对。 
4. 一旦栈顶与当前数字互质或者堆栈为空，则将当前数字压入堆栈。 
5. 处理完所有数字后，堆栈包含所有相邻非互质数组合而成的最终数组。 

**为什么起作用：** 堆栈确保每个新数字始终与其左邻居进行比较，从而保留邻接检查。 重复的 LCM 替换在堆栈中传播，直到解析出所有非互质对。 由于该问题保证最终值小于108，因此重复LCM计算不会溢出。 

## Python 解决方案```python
from math import gcd
from typing import List

class Solution:
    def replaceNonCoprimes(self, nums: List[int]) -> List[int]:
        stack = []
        
        for num in nums:
            while stack:
                top = stack[-1]
                g = gcd(top, num)
                if g == 1:
                    break
                # Replace top with LCM(top, num)
                num = top * num // g
                stack.pop()
            stack.append(num)
        
        return stack
```该代码初始化一个空堆栈并迭代每个数字。 它使用堆栈顶部元素计算 GCD，如果它们不互质，则用它们的 LCM 替换顶部元素。 这一直持续到顶部元素与当前数字互质或堆栈为空，确保有效解析所有非互质对。 

## 解决方案```go
package main

func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a % b
    }
    return a
}

func replaceNonCoprimes(nums []int) []int {
    stack := []int{}
    
    for _, num := range nums {
        for len(stack) > 0 {
            top := stack[len(stack)-1]
            g := gcd(top, num)
            if g == 1 {
                break
            }
            num = top * num / g
            stack = stack[:len(stack)-1]
        }
        stack = append(stack, num)
    }
    
    return stack
}
```在Go中，切片用于实现堆栈。 这`gcd`函数使用欧几里得算法。 与 Python 不同，Go 需要显式的切片操作来弹出元素，但逻辑保持不变。
