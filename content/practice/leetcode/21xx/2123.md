[LeetCode 问题 2123](https://leetcode.com/problems/minimum-operations-to-remove-adjacent-ones-in-matrix/)

 **难度：** 🔴难
 **主题：** 数组、图论、矩阵

 ## 解决方案

 ## 问题理解

 问题提出了一个**二元矩阵**，其中每个元素是`0`或者`1`。 目标是将这个矩阵转换成**良好隔离的**配置，这意味着没有`1`4 向连接到任何其他`1`。 四向连接是指上、下、左、右方向的邻接，不包括对角线。 

输入，`grid`, 是一个`m x n`矩阵其中`1 <= m, n <= 300`，每个单元格要么是`0`或者`1`。 输出是使网格良好隔离所需的**最小操作数**。 一个操作包括翻转`1`变成一个`0`。 

从约束条件来看，我们看到矩阵可能非常大，最多可达 90,000 个单元格，因此检查所有翻转组合的简单方法是不可行的。 该问题保证网格有效并且仅包含 0 和 1。 重要的边缘情况包括全零的网格（已经很好地隔离）、具有隔离的 1 的网格（不需要翻转）以及具有大型连接的 1 块的网格，其中仔细选择要翻转的 1 可以最大限度地减少操作。 

挑战在于有效地识别**要删除的最小 1 组**，使得没有两个 1 保持相邻，而无需多余地翻转额外的 1。 

## 方法

 ### 蛮力

 一个简单的解决方案会尝试考虑 **1 的所有子集** 并检查哪个子集会产生良好隔离的网格。 对于每种配置，我们都会计算翻转次数并跟踪最小值。 虽然这种方法保证了正确性，但对于大小的矩阵来说在计算上是不可行的`300 x 300`因为 1 的数量最多可达 90,000 个，导致`2^k`组合。 对于大量投入来说，这种指数增长是不可接受的。 

### 最佳方法

 关键的见解是将问题视为在**图中**找到最大独立集**，其中节点为 1，边连接 4 个方向相邻的 1**。 删除 1 对应于“删除一个节点”，我们希望最小化删除，相当于最大化我们保留的 1 集合，使得没有两个节点相邻。 

由于1s的邻接图是**二分图**（任何二维网格图都可以用棋盘图案着色），我们可以利用**柯尼希定理**，该定理指出，在二分图中，最大独立集的大小等于总节点减去最大匹配的大小。 因此，我们可以：

 1. 构建一个 1 的二分图，根据棋盘图案着色为黑白。 
2. 连接相邻 1 之间的边。 
3. 使用二分匹配算法（如 Hopcroft-Karp）计算最大匹配。 
4、最小翻转次数等于1的数量减去最大独立集大小，即`maximum matching`在这个两方设置中。 

这种方法可以有效地解决问题的限制。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^k) | O(2^k) | O(k) | 检查 1 的所有子集； 对于大矩阵来说不切实际
 | 最佳| O(k * sqrt(k)) | O(k * sqrt(k)) | O(k) | 通过 Hopcroft-Karp 使用二分图匹配； 可扩展 |

 这里，`k`是网格中 1 的总数。 

## 算法演练

 1. 迭代矩阵以识别 1 的所有位置，并使用棋盘图案为它们分配颜色（黑色或白色）：`(i + j) % 2`。 
2.构建二部图：对于每个黑色节点，将其连接到所有相邻的同样为1的白色节点。 
3. 应用**最大二分匹配算法** (Hopcroft-Karp) 来查找每个黑色节点与白色节点匹配的最大边集。 
4. 计算最小翻转次数为**1 的总数减去最大独立集大小**，其中最大独立集大小等于`total_1s - matching_size`。 
5. 返回该最小操作数。 

**为什么起作用：** 棋盘着色确保 1 的邻接图是二分的，因此每对连接的 1 都将位于黑色和白色节点之间。 通过找到最大匹配，我们确定了必须删除的最小 1 集，以消除所有 4 向连接。 这保证了正确性和最小性。 

## Python 解决方案```python
from typing import List
from collections import deque

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        total_ones = sum(row.count(1) for row in grid)
        
        # Mapping positions of 1s to indices
        pos_to_index = {}
        index = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    pos_to_index[(i,j)] = index
                    index += 1
        
        black_nodes = set()
        adj = [[] for _ in range(total_ones)]
        
        # Build bipartite graph
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    idx = pos_to_index[(i,j)]
                    if (i + j) % 2 == 0:
                        black_nodes.add(idx)
                        for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                            ni, nj = i + dx, j + dy
                            if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                                adj[idx].append(pos_to_index[(ni,nj)])
        
        # Hopcroft-Karp for maximum bipartite matching
        match_to = [-1] * total_ones
        
        def bpm(u, visited):
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    if match_to[v] == -1 or bpm(match_to[v], visited):
                        match_to[v] = u
                        return True
            return False
        
        matching = 0
        for u in black_nodes:
            visited = [False] * total_ones
            if bpm(u, visited):
                matching += 1
        
        return matching
```该实现构建了一个二部图，其中黑色节点代表位置`(i+j)%2==0`值为 1。为每个黑色节点构造邻接表。 这`bpm`函数执行深度优先搜索来查找匹配的增广路径。 决赛`matching`count 表示所需的最少翻转次数。 

## 解决方案```go
func minimumOperations(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    posToIndex := make(map[[2]int]int)
    index := 0
    totalOnes := 0

    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == 1 {
                posToIndex[[2]int{i,j}] = index
                index++
                totalOnes++
            }
        }
    }

    adj := make([][]int, totalOnes)
    blackNodes := []int{}
    
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == 1 {
                idx := posToIndex[[2]int{i,j}]
                if (i+j)%2 == 0 {
                    blackNodes = append(blackNodes, idx)
                    directions := [][2]int{{-1,0},{1,0},{0,-1},{0,1}}
                    for _, d := range directions {
                        ni, nj := i+d[0], j+d[1]
                        if ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1 {
                            adj[idx] = append(adj[idx], posToIndex[[2]int{ni,nj}])
                        }
                    }
                }
            }
        }
    }

    matchTo := make([]int, totalOnes)
    for i := range matchTo { matchTo[i] = -1 }

    var bpm func(int, []bool) bool
    bpm = func(u int, visited []bool) bool {
        for _, v := range adj[u] {
            if !visited[v] {
                visited[v] = true
                if matchTo[v] == -1 || bpm(matchTo[v], visited) {
                    matchTo[v] = u
                    return true
                }
            }
        }
        return false
    }

    matching := 0
    for _, u := range blackNodes {
        visited := make([]bool, totalOnes)
        if bpm(u, visited) {
            matching++
        }
    }

    return matching
}
```在 Go 中，切片和映射取代了 Python 的列表和字典。 基于DFS的二分匹配函数被实现为访问闭包`matchTo`和`adj`方便。
