[LeetCode 问题 2182](https://leetcode.com/problems/construct-string-with-repeat-limit/)

 **难度：** 🟡 中等
 **主题：** 哈希表、字符串、贪婪、堆（优先级队列）、计数

 ## 解决方案

 ## 问题理解

 该问题要求我们根据给定字符串的字符构造一个字符串`s`在特定约束下：任何字符不能出现超过`repeatLimit`连续多次。 我们的目标不仅仅是创建任何有效的字符串，而是生成**按字典顺序最大的**字符串。 字典顺序与字典顺序类似：如果第一个不同的字符在字母表中靠后，则字符串较大。 

输入`s`是一串小写英文字母，并且`repeatLimit`是 1 到长度之间的整数`s`。 这些限制表明输入大小最多可达 100,000 个字符，因此需要有效的解决方案。 可能会导致幼稚实现失败的边缘情况包括一个字符占主导地位的字符串`s`,`repeatLimit`等于 1，或者当字典顺序最大的字符由于达到重复限制而无法连续使用时。 

该问题保证了`s`至少有一个字符，因此我们不需要处理空字符串。 

## 方法

 蛮力方法将尝试生成所有排列`s`，过滤掉那些违反规定的`repeatLimit`，然后选择字典顺序最大的。 虽然理论上是正确的，但由于阶乘时间复杂度，这种方法在计算上不可行（`O(n!)`）即使对于中等大小的输入也是如此。 

最佳解决方案利用带有最大堆的**贪婪策略**。 关键的观察是，为了实现按字典顺序排列的最大字符串，我们总是希望在遵守重复限制的同时放置最大的可用字符。 如果最大字符达到其连续重复限制，我们会暂时插入下一个最大字符来“破坏”序列，然后恢复使用最大字符。 通过维护每个字符的计数，我们可以有效地选择下一个要附加的字符以及附加次数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n!) | 生成所有排列，按重复限制过滤，选择最大 |
 | 最佳| O(n log k) | O(n log k) | O(k) | 使用最大堆和字符计数； 对于小写字母，k ≤ 26 |

 ## 算法演练

 1.统计每个字符出现的频率`s`使用哈希图。 
2. 将所有非零频率的字符推入最大堆（优先级队列），按字符值排序，使最大的字符位于顶部。 
3. 初始化一个空结果字符串。 
4. 当堆不为空时，弹出具有最高值的字符（`currChar`）并确定可以连续添加多少次而不超过`repeatLimit`。 
5. 追加`min(count[currChar], repeatLimit)`的实例`currChar`到结果字符串。 
6. 如果还有剩余实例`currChar`，我们必须插入下一个最大的字符来打破重复。 如果此时堆为空，我们就无法追加更多内容`currChar`。 
7. 推回剩余计数`currChar`进入堆（如果有的话）。 
8. 继续，直到堆为空。 

**为什么有效：** 该算法保持了不变性，即每一步的结果字符串始终按字典顺序尽可能大。 通过使用最大的可用字符直到达到重复限制，然后临时插入较小的字符，我们在尊重重复限制的同时最大化字典顺序。 

## Python 解决方案```python
import heapq
from collections import Counter

class Solution:
    def repeatLimitedString(self, s: str, repeatLimit: int) -> str:
        count = Counter(s)
        # Use negative ASCII for max-heap
        max_heap = [(-ord(c), freq) for c, freq in count.items()]
        heapq.heapify(max_heap)
        
        result = []
        
        while max_heap:
            curr_char_ord, freq = heapq.heappop(max_heap)
            curr_char = chr(-curr_char_ord)
            use = min(freq, repeatLimit)
            
            result.extend([curr_char] * use)
            freq -= use
            
            if freq > 0:
                if not max_heap:
                    break  # cannot place any other char to break sequence
                next_char_ord, next_freq = heapq.heappop(max_heap)
                next_char = chr(-next_char_ord)
                result.append(next_char)
                next_freq -= 1
                if next_freq > 0:
                    heapq.heappush(max_heap, (next_char_ord, next_freq))
                heapq.heappush(max_heap, (curr_char_ord, freq))
        
        return ''.join(result)
```在此 Python 实现中，堆将字符存储为负 ASCII 值，以使用 Python 的最小堆模拟最大堆。 计数器跟踪剩余频率。 关键逻辑是附加字符直至重复限制，并在必要时用下一个最大字符中断序列。 

## 解决方案```go
package main

import (
    "container/heap"
)

type CharFreq struct {
    char rune
    freq int
}

type MaxHeap []CharFreq

func (h MaxHeap) Len() int { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i].char > h[j].char }
func (h MaxHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x interface{}) { *h = append(*h, x.(CharFreq)) }
func (h *MaxHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}

func repeatLimitedString(s string, repeatLimit int) string {
    freq := make(map[rune]int)
    for _, c := range s {
        freq[c]++
    }
    
    h := &MaxHeap{}
    heap.Init(h)
    for c, f := range freq {
        heap.Push(h, CharFreq{c, f})
    }
    
    result := []rune{}
    
    for h.Len() > 0 {
        curr := heap.Pop(h).(CharFreq)
        use := min(curr.freq, repeatLimit)
        for i := 0; i < use; i++ {
            result = append(result, curr.char)
        }
        curr.freq -= use
        
        if curr.freq > 0 {
            if h.Len() == 0 {
                break
            }
            next := heap.Pop(h).(CharFreq)
            result = append(result, next.char)
            next.freq--
            if next.freq > 0 {
                heap.Push(h, next)
            }
            heap.Push(h, curr)
        }
    }
    
    return string(result)
}

func min(a, b int) int {
    if a < b { return a }
    return b
}
```在 Go 中，我们使用自定义最大堆实现`container/heap`因为 Go 只提供了一个最小堆接口。 每个字符及其频率都包装在一个用于堆存储的结构中。 逻辑反映了 Python 版本，确保遵守重复限制。
