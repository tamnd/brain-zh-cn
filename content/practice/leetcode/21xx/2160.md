 **主题：** 数学、贪心、排序

 ## 解决方案

 ## 问题理解

 问题要求我们取一个**四位整数**`num`并将其数字分成**两个新整数**，以使这两个整数的总和最小化。 我们可以使用所有数字一次，并且新整数可以有**前导零**。 例如，如果数字是`2932`，数字是`[2, 9, 3, 2]`，我们可以形成这样的数字`29`和`23`， 或者`22`和`93`。 目标是找到产生**最小总和**的组合。 

输入保证是一个**正四位数字**（`1000 <= num <= 9999`）。 此约束确保**恰好有四位数字**，因此我们不必处理数字更少或更多的情况。 新数字中允许使用前导零，这在最小化总和时至关重要。 

重要的边缘情况包括具有重复数字的数字（例如`1122`）和带零的数字（例如`4009`）。 如果我们不仔细考虑数字排序，这些可能会导致幼稚的实现失败。 

## 方法

 **暴力方法**将涉及生成四位数字的所有排列，将它们分成所有可能的数字对，并计算每对数字的总和。 虽然这保证了正确性，但这里没有必要，因为位数固定为四。 生成所有排列将导致`4! = 24`排列，并以所有可能的方式分割每个排列会产生额外的组合。 尽管可行，但它有点矫枉过正，并且不能很好地概括。 

最佳解决方案的**关键见解**是为了最小化总和，我们希望两个数字的**最小数字位于最高位值**。 通过按升序对数字进行排序，并将最小的与第二小的、第三小的与最大的配对，我们可以构造两个总和最小的数字。 具体来说，如果排序后的数字是`[a, b, c, d]`，通过形成获得最小总和`10*a + c`和`10*b + d`。

 ## 算法演练

 1. 转换整数`num`放入其四位数字的列表中。 
2. 按升序对数字列表进行排序。 排序可确保首先考虑最小的数字。 
3. 将数字配对形成两个新整数。 将最小的数字作为第一个数字的十位，第二小的数字作为第二个数字的十位，第三小的数字作为第一个数字的个位，最大的数字作为第二个数字的个位。 
4. 计算两个数字的总和。 
5. 返回总和作为结果。 

**为什么有效：** 排序可确保较小的数字尽可能占据较高的权重位置，从而最大限度地减少结果数字。 通过将两个数字中最小的与下一个最小的数字配对，我们保证总和最小，因为任何其他配对都会增加一个数字，而不是减少另一个数字。 

## Python 解决方案```python
class Solution:
    def minimumSum(self, num: int) -> int:
        digits = [int(d) for d in str(num)]
        digits.sort()
        new1 = digits[0] * 10 + digits[2]
        new2 = digits[1] * 10 + digits[3]
        return new1 + new2
```该实现首先将数字转换为其数字列表并对它们进行排序。 根据最优配对逻辑，使用排序后的数字构造两个新整数，并返回它们的和。 

## 解决方案```go
import "sort"

func minimumSum(num int) int {
    digits := make([]int, 4)
    for i := 3; i >= 0; i-- {
        digits[i] = num % 10
        num /= 10
    }
    sort.Ints(digits)
    new1 := digits[0]*10 + digits[2]
    new2 := digits[1]*10 + digits[3]
    return new1 + new2
}
```在 Go 中，使用模除法和整数除法将数字分成数字。 排序是使用`sort.Ints`功能。 新数字的形成使用与 Python 相同的逻辑。 由于排序不需要对零进行特殊处理。

 ## 边缘情况

 第一个边缘情况是当**出现零**时，例如`4009`。 排序可确保零位于低权重位置，因此前导零不会使总和增大。 第二个边缘情况是**重复数字**，例如`1122`。 该算法仍然正确地形成最小和，因为排序顺序确保了正确的配对。 第三种边缘情况是当**所有数字都相同**时，例如`9999`。 该算法自然地处理这个问题，产生具有正确的最小总和的相等数字。 测试套件涵盖了这些案例，并确认解决方案在所有有效输入上都是稳健的。
