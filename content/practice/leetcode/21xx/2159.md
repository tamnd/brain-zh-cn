[LeetCode 问题 2159](https://leetcode.com/problems/order-two-columns-independently/)

 **难度：** 🟡 中等
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 问题提供了一个名为`Data`有两个整数列：`first_col`和`second_col`。 每行代表一对数字，并且允许重复行。 任务是返回一个新表，其中每列中的数字都独立排序：`first_col`按升序排列并且`second_col`按降序排列。 重要的是，一列的排序不会影响另一列。 这意味着最小值`first_col`不必与最大值对齐`second_col`在原始数据中。 

输入表示可能具有重复整数值的数据集。 输出必须保留原始表形状，但具有独立重新排序的列。 约束没有明确说明，但由于问题出在 SQL 中并且通常在中等大小的表上运行，因此我们可以假设可能有数千行。 

重要的边缘情况包括具有重复值的表、单行或已排序的列。 幼稚的实现可能会错误地将行排序在一起，这是不正确的，因为排序是独立的。 

## 方法

 暴力方法很简单：获取所有值`first_col`和`second_col`，根据需要的顺序对每个列表进行排序，然后将排序后的结果按索引进行配对。 这保证了正确性，因为独立排序会产生所需的独立排序。 这种方法的局限性在于，如果表非常大，则在非数据库上下文中它会占用大量内存，但对于大多数 SQL 查询来说，数据库引擎可以有效地处理这种情况。 

更优化的 SQL 解决方案的关键在于，数据库允许我们对每一列进行独立排序，并分配行号以将排序后的值映射回表形式。 使用窗口函数，我们可以为每个排序列分配一个顺序索引，然后连接这些索引上的列。 这种方法非常高效，并且利用了 SQL 的内置优化。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 获取列、独立排序、重建表 |
 | SQL 窗口函数 | O(n log n) | O(n log n) | O(n) | 将行号分配给已排序的列并加入 |

 ## 算法演练

 1. 提取物`first_col`从`Data`表并按升序排序。 使用以下命令为每个元素分配连续的行号`ROW_NUMBER()`。 该行号将充当稍后重新组装列的关键。 
2.同样，提取`second_col`从`Data`表并按降序排序。 使用以下命令为每个元素分配连续的行号`ROW_NUMBER()`。 
3. 使用行号对两组数据执行内连接。 连接确保了最小值`first_col`具有最大值的对`second_col`，然后是第二小的和第二大的，依此类推。 
4. 按照最终输出顺序选择连接的列：`first_col`其次是`second_col`。 

工作原理：行号分配保证了排序后位置的一对一映射，而连接则确保了每个位置`first_col`与中的相应位置配对`second_col`独立排序后。 这保留了独立订购要求。 

## Python 解决方案```python
# Python solution for reference, simulating SQL behavior
from typing import List
import pandas as pd

class Solution:
    def orderColumnsIndependently(self, Data: pd.DataFrame) -> pd.DataFrame:
        # Sort first_col ascending and reset index
        first_sorted = Data[['first_col']].sort_values(by='first_col', ascending=True).reset_index(drop=True)
        # Sort second_col descending and reset index
        second_sorted = Data[['second_col']].sort_values(by='second_col', ascending=False).reset_index(drop=True)
        # Concatenate columns side by side
        result = pd.concat([first_sorted, second_sorted], axis=1)
        return result
```在这个实现中，我们使用`pandas`模拟独立列排序。 我们首先排序`first_col`按升序排列并且`second_col`按降序排列，重置索引以创建干净的位置映射。 最后，`concat`按列合并两个 DataFrame，模仿 SQL 窗口函数 join。 

## 解决方案```go
package main

import (
    "sort"
)

type DataRow struct {
    FirstCol  int
    SecondCol int
}

func orderColumnsIndependently(data []DataRow) []DataRow {
    n := len(data)
    firstCol := make([]int, n)
    secondCol := make([]int, n)
    
    for i, row := range data {
        firstCol[i] = row.FirstCol
        secondCol[i] = row.SecondCol
    }
    
    sort.Ints(firstCol)
    sort.Slice(secondCol, func(i, j int) bool {
        return secondCol[i] > secondCol[j]
    })
    
    result := make([]DataRow, n)
    for i := 0; i < n; i++ {
        result[i] = DataRow{FirstCol: firstCol[i], SecondCol: secondCol[i]}
    }
    return result
}
```在 Go 中，切片用于单独保存每一列。`sort.Ints`排序`first_col`按升序排列，并且`sort.Slice`使用自定义比较器排序`second_col`按降序排列。 最后，我们通过配对排序值来重建结果切片。 

## 工作示例

 输入示例：```
first_col: [4, 2, 3, 1]
second_col: [2, 3, 1, 4]
```第 1 步：排序`first_col`上升→`[1, 2, 3, 4]`第 2 步：排序`second_col`下降→`[4, 3, 2, 1]`步骤3：按索引配对→结果表：```
first_col | second_col
1         | 4
2         | 3
3         | 2
4         | 1
```## 复杂度分析

 ## 边缘情况

 一种重要的边缘情况是表只有一行。 以任一顺序对单个值进行排序都应返回同一行，我们的实现可以正确处理该行，因为对长度为 1 的列表进行排序是无操作。 

另一种边缘情况是多行具有相同的值。 这可能会导致尝试对整行而不是列进行排序的算法出错。 我们的方法独立处理列，不依赖行排序，确保结果正确。 

最后，当两列都已按所需顺序排序时，错误地重新组合列的简单实现可能会打乱值。 我们的算法显式地对每列进行独立排序并按索引配对，从而保留现有的正确排序。
