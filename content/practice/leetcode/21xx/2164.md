[LeetCode 问题 2164](https://leetcode.com/problems/sort-even-and-odd-indices-independently/)

 **难度：** 🟢简单
 **主题：** 数组、排序

 ## 解决方案

 ## 问题理解

 该问题要求我们采用一个整数数组`nums`and sort its elements based on their indices in two separate ways: the elements at **even indices** should be sorted in **non-decreasing** order, and the elements at **odd indices** should be sorted in **non-increasing** order. 该数组是 **0 索引**，因此索引`0`被认为是偶数，索引`1`为奇数，索引`2`是偶数，依此类推。 

输入`nums`表示需要根据基于索引的排序规则重新排列的整数列表。 输出是执行两次单独排序后的数组，同时将元素保留在各自的索引奇偶校验位置。 

约束很小：数组长度最多为 100，每个元素的范围在 1 到 100 之间。这确保了即使是简单的基于排序的解决方案也是高效的。 

重要的边缘情况包括长度为 1 或 2 的数组、所有奇数或所有偶数索引都包含相同值的数组，以及已根据一种或两种规则排序的数组。 该问题保证数组非空并且仅包含正整数。 

## 方法

 ### 蛮力

 一种简单的方法是迭代数组，将偶数索引元素和奇数索引元素分成两个单独的数组，根据所需的顺序对每个数组进行排序，然后将它们合并回原来的位置。 

这种方法之所以有效，是因为对两个组进行独立排序可以保证最终的数组满足所需的条件。 对于小型阵列，这是完全可以接受的。 

### 最佳洞察力

 考虑到约束条件（`nums.length <= 100`），强力解决方案实际上是最优的，因为对两个大小相同的小数组进行粗略排序`n/2`速度很快。 除了使用内置排序功能之外，无需进一步优化。

 ## 算法演练

 1. 初始化两个空列表：一个用于偶数索引元素（`even_nums`) 和一个用于奇数索引元素 (`odd_nums`）。 
2. 迭代原始数组`nums`。 如果索引`i`是偶数，附加`nums[i]`到`even_nums`; 否则，将其附加到`odd_nums`。 
3. 排序`even_nums`按非递减顺序。 这确保偶数索引的位置将按升序排序。 
4. 排序`odd_nums`按非递增顺序。 这确保奇数索引位置将按降序排序。 
5.初始化一个新数组或者复用原来的数组`nums`。 
6. 迭代`nums`再次，对于每个索引`i`，放置元素`even_nums`如果`i`是偶数，并且从`odd_nums`如果`i`是奇数，保持排序顺序。 
7. 返回修改后的数组。 

**为什么有效：** 对每个奇偶校验组进行独立排序可确保偶数和奇数索引内的相对顺序遵循指定的排序规则。 通过将排序后的值映射回其原始奇偶校验位置，我们维护了索引约束。 

## Python 解决方案```python
from typing import List

class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:
        even_nums = [nums[i] for i in range(0, len(nums), 2)]
        odd_nums = [nums[i] for i in range(1, len(nums), 2)]
        
        even_nums.sort()
        odd_nums.sort(reverse=True)
        
        result = []
        even_idx, odd_idx = 0, 0
        for i in range(len(nums)):
            if i % 2 == 0:
                result.append(even_nums[even_idx])
                even_idx += 1
            else:
                result.append(odd_nums[odd_idx])
                odd_idx += 1
        
        return result
```**实现说明：** 我们首先提取偶数和奇数索引元素，根据需要对它们进行排序，然后通过为偶数和奇数数组维护两个单独的指针来将它们合并回来。 这确保每个元素在遵循排序规则的同时到达正确的索引。 

## 解决方案```go
import "sort"

func sortEvenOdd(nums []int) []int {
    evenNums := []int{}
    oddNums := []int{}
    
    for i, val := range nums {
        if i%2 == 0 {
            evenNums = append(evenNums, val)
        } else {
            oddNums = append(oddNums, val)
        }
    }
    
    sort.Ints(evenNums)
    sort.Sort(sort.Reverse(sort.IntSlice(oddNums)))
    
    result := make([]int, len(nums))
    evenIdx, oddIdx := 0, 0
    
    for i := range nums {
        if i%2 == 0 {
            result[i] = evenNums[evenIdx]
            evenIdx++
        } else {
            result[i] = oddNums[oddIdx]
            oddIdx++
        }
    }
    
    return result
}
```**Go 特定注释：** 我们使用`sort.Ints`用于升序排序和`sort.Sort(sort.Reverse(...))`用于降序排序。 Go 中的切片可以轻松动态构建偶数和奇数数组，并且我们分配固定大小的结果切片以避免多次追加。 

## 工作示例

 ## 边缘情况

 **单元素：** 只有一个元素的数组不需要排序。 该算法通过提取单元素数组并将它们原样合并回来来处理此问题。 

**所有元素相同：** 如果所有元素都相等，排序仍然会发生，但会产生相同的数组。 这测试了实现不会无意中错误地重新排序相同的元素。 

**奇数长度数组：** 具有奇数个元素的数组确保最后一个索引可以是偶数或奇数。 我们的方法通过使用基于索引的迭代和单独的指针来处理这个问题，确保不会跳过任何索引。 

**已排序：** 如果数组已根据规则排序，则算法仍应生成相同的数组。 这验证了排序操作和合并逻辑不会破坏已经排序的奇偶校验组。
