[LeetCode 问题 2158](https://leetcode.com/problems/amount-of-new-area-painted-each-day/)

 **难度：** 🔴难
 **主题：** 数组、线段树、有序集

 ## 解决方案

 ## 问题理解

 该问题描述了用一维数轴表示的绘画场景。 输入数组中的每个元素`paint[i] = [starti, endi]`代表需要绘制的部分`i`那天。 目标是计算每天有多少**新区域**被绘制，即前几天未绘制的部分部分。 应避免在同一区域多次涂漆。 

输入是带有约束的间隔列表，确保`0 <= starti < endi <= 50,000`最多 100,000 天。 输出是一个列表`worklog`其中每个条目对应于当天绘制的新区域。 

重要的考虑因素包括重叠段、嵌套段和不相交段。 边缘情况涉及完全重叠的间隔、大小为 1 的最小间隔以及接触边界的间隔（starti = 前一个 endi）。 

挑战在于如何有效地跟踪绘画的哪些部分已经被覆盖，而不需要每天迭代整个范围，因为考虑到限制，简单的方法会太慢。 

## 方法

 ### 蛮力

 暴力解决方案很简单：维护一个布尔数组，表示数轴上每个单位位置的绘制状态。 对于每天的间隔`[start, end)`，迭代每个单元位置，如果之前没有被绘制过，则将其标记为已绘制。 计算工作日志中新绘制的单元。 

虽然这种方法是正确的，但其复杂性却令人望而却步。 对于最大输入大小`paint.length = 10^5`和`endi`最多 50,000 个，每天迭代每个单位头寸将导致 O(n * m) 次操作，其中 m 是数轴中的头寸数量。 对于大输入来说这太慢了。 

### 最佳方法

 关键的观察是，一旦绘制了一个片段，下一个绘制操作就可以**跳过已经绘制的部分**。 我们可以使用**地图或数组来跟踪每个起点的下一个未绘制位置**，从而有效地允许我们跳过绘制的间隔。 这是应用于区间的**并集查找或不相交集优化**的一种形式。 

使用这种技术，对于每个间隔`[start, end)`，我们检查当前的起始位置。 如果它已被绘制，我们跳到下一个未绘制的位置并继续，直到到达终点。 这确保每个单元仅被访问一次，从而实现相对于总间隔长度的线性时间，而不是简单的嵌套迭代。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(米) | 单独标记每个单元，对于大 m 来说太慢 |
 | 最佳| O(n + 总绘制单元) | O(米) | 使用地图或数组跳过绘制的段以实现快速跳跃 |

 ## 算法演练

 1.初始化一个数组`next_unpainted`大小略大于最大端点，以跟踪每个索引的下一个未绘制位置。 最初，每个索引都指向自身。 
2. 定义辅助函数`find_next(x)`递归地找到下一个未绘制的位置，从`x`使用路径压缩。 
3. 对于每天的间隔`[start, end)`, 初始化`current = start`。 
4. 虽然`current < end`， 寻找`next_pos = find_next(current)`。 
5. 如果`next_pos >= end`，打破循环。 
6. 将当天的新油漆数量增加`1`并设置`next_unpainted[next_pos] = next_pos + 1`来标记它已涂漆。 
7. 移动`current = next_pos + 1`。 
8. 将当天绘制的新单元数添加到`worklog`。 
9. 返回`worklog`经过一整天的处理。 

**为什么它有效：** 不变的是`next_unpainted[x]`始终指向该位置或该位置之后的第一个未绘制的单元`x`。 通过在绘制后更新它，我们确保没有位置被计算两次。 路径压缩保证了后续间隔的快速查找。 

## Python 解决方案```python
from typing import List

class Solution:
    def amountPainted(self, paint: List[List[int]]) -> List[int]:
        max_pos = 50001
        next_unpainted = list(range(max_pos))
        worklog = []
        
        def find_next(x: int) -> int:
            if next_unpainted[x] != x:
                next_unpainted[x] = find_next(next_unpainted[x])
            return next_unpainted[x]
        
        for start, end in paint:
            new_area = 0
            current = start
            while current < end:
                current = find_next(current)
                if current >= end:
                    break
                new_area += 1
                next_unpainted[current] = current + 1
                current += 1
            worklog.append(new_area)
        
        return worklog
```**说明：** 我们维持`next_unpainted`有效地跳过涂漆区域。 这`find_next`函数使用路径压缩来展平结构，以便将来更快地查找。 对于每个间隔，我们跳转到下一个未绘制的单元，并仅增加新绘制位置的计数。 

## 解决方案```go
func amountPainted(paint [][]int) []int {
    maxPos := 50001
    nextUnpainted := make([]int, maxPos)
    for i := range nextUnpainted {
        nextUnpainted[i] = i
    }

    findNext := func(x int) int {
        if nextUnpainted[x] != x {
            nextUnpainted[x] = findNext(nextUnpainted[x])
        }
        return nextUnpainted[x]
    }

    worklog := make([]int, 0, len(paint))
    
    for _, p := range paint {
        start, end := p[0], p[1]
        newArea := 0
        current := start
        for current < end {
            current = findNext(current)
            if current >= end {
                break
            }
            newArea++
            nextUnpainted[current] = current + 1
            current++
        }
        worklog = append(worklog, newArea)
    }
    
    return worklog
}
```**Go 特定注释：** 初始化使用`make`分配数组。 递归闭包`findNext`允许路径压缩。 切片附加用于有效地构建结果数组。 

## 工作示例

 **示例 1：油漆 = [[1,4],[4,7],[5,8]]**

 | 日 | 间隔 | 新漆 | next_unpainted 更新 |
 | --- | --- | --- | --- |
 | 0 | [1,4]| 3 | 1→2、2→3、3→4 |
 | 1 | [4,7]| 3 | 4→5, 5→6, 6→7 |
 | 2 | [5,8]| 1 | 7→8 |

 输出：`[3,3,1]`**示例 2：油漆 = [[1,5],[2,4]]**

 | 日 | 间隔 | 新漆 | next_unpainted 更新 |
 | --- | --- | --- | --- |
 | 0 | [1,5]| 4 | 1→2、2→3、3→4、4→5 |
 | 1 | [2,4]| 0 | 无 |

 输出：`[4,0]`## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + 总绘制单元) | 由于路径压缩，每个单元最多被访问一次 |
