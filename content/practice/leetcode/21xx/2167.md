[LeetCode 问题 2167](https://leetcode.com/problems/minimum-time-to-remove-all-cars-containing-illegal-goods/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 问题呈现一个二进制字符串`s`代表一系列火车车厢。 每个角色`'0'`或者`'1'`表示火车车厢是否含有非法物品（`'1'`） 或不 （`'0'`）。 目标是结合使用三种可能的操作来移除所有含有非法物品的汽车：从左端移除、从右端移除或从序列中的任何位置移除。 从末端移除的成本为 1 个单位时间，从中间移除的成本为 2 个单位时间。 

我们被要求计算移除所有含有非法物品的汽车的**最短总时间**。 输入可以长达 200,000 个字符，这意味着评估所有可能的删除序列的强力解决方案会太慢。 约束确保字符串非空，并且每个字符是`'0'`或者`'1'`。 

重要的边缘情况包括具有所有特征的字符串`'0'`（无需删除），所有字符串`'1'`（从任一端删除所有内容是最佳选择），并且带有单个的字符串`'1'`中间，直接删除可能会更便宜。 

面临的挑战是如何有效地结合左、右和中间的拆除，以最大限度地降低总成本。 

## 方法

 ### 蛮力

 暴力方法会考虑从左侧、右侧和中间移除汽车的所有可能组合。 对于移除的每个汽车子集，它将检查是否所有非法汽车都被移除并计算总成本。 虽然正确，但对于给定的输入约束（`2^n`的可能性）。 因此，对于长度达到 200,000 的字符串来说是不切实际的。 

### 最佳方法

 关键的见解是，任何删除序列都可以表示为**从左侧删除前缀**和**从右侧删除后缀**，以及从剩余中间部分删除。 我们可以预先计算每个前缀和后缀移除非法商品的成本，然后考虑所有可能的分割以找到最小的总成本。 

我们定义`left[i]`作为删除所有内容的最短时间`'1'`子串中的 s`s[0:i]`和`right[i]`作为删除所有内容的最短时间`'1'`是从`s[i:]`。 通过迭代所有可能的分割，我们结合左右成本并计算最短时间。 这种方法避免了显式的组合枚举，并且在**线性时间**中运行。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 评估所有移除组合，对于大 n | 来说是不可行的
 | 最佳| O(n) | O(n) | 使用前缀和后缀数组进行线性计算的动态规划 |

 ## 算法演练

 1.初始化两个数组，`left`和`right`，每个长度`n+1`存储移除的累计最小成本`'1'`s 来自前缀和后缀。 
2. 计算`left[i]`迭代地：对于每个索引`i`，或者取之前的`left[i-1]`成本加 1 如果`s[i-1] == '1'`用于末端去除，或 2 用于中间去除。 选择最小值。 
3. 计算`right[i]`类似地，从末尾到开头迭代。 
4. 初始化`min_time`至少从左侧删除所有内容或从右侧删除所有内容（`left[n]`或者`right[0]`）。 
5. 迭代所有可能的分割点`i`从 0 到`n`, 计算`left[i] + right[i]`并更新`min_time`如果更小。 
6. 返回`min_time`作为最终答案。 

**为什么有效：** 该算法保持了以下不变式：`left[i]`和`right[i]`存储从各个部分移除所有非法商品的最低成本。 通过考虑所有分割点，我们考虑了左、右和中间移除的所有有效组合。 线性扫描保证找到全局最小总时间。 

## Python 解决方案```python
class Solution:
    def minimumTime(self, s: str) -> int:
        n = len(s)
        left = [0] * (n + 1)
        for i in range(1, n + 1):
            left[i] = left[i - 1] + 1 if s[i - 1] == '1' else left[i - 1]
            left[i] = min(left[i], i * 2)
        
        right = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            right[i] = right[i + 1] + 1 if s[i] == '1' else right[i + 1]
            right[i] = min(right[i], (n - i) * 2)
        
        min_time = min(right[0], left[n])
        for i in range(1, n):
            min_time = min(min_time, left[i] + right[i])
        return min_time
```此 Python 实现使用动态编程来维护前缀和后缀成本。 这`left`数组跟踪删除所有的最小成本`'1'`s 从开始到索引`i`，以及`right`数组从末尾向后执行相同的操作。 最后的循环找到结合左右移除的最佳分割点。 

## 解决方案```go
func minimumTime(s string) int {
    n := len(s)
    left := make([]int, n+1)
    for i := 1; i <= n; i++ {
        left[i] = left[i-1]
        if s[i-1] == '1' {
            left[i] += 1
        }
        if 2*i < left[i] {
            left[i] = 2 * i
        }
    }

    right := make([]int, n+1)
    for i := n - 1; i >= 0; i-- {
        right[i] = right[i+1]
        if s[i] == '1' {
            right[i] += 1
        }
        if 2*(n-i) < right[i] {
            right[i] = 2 * (n - i)
        }
    }

    minTime := left[n]
    if right[0] < minTime {
        minTime = right[0]
    }
    for i := 1; i < n; i++ {
        if left[i]+right[i] < minTime {
            minTime = left[i] + right[i]
        }
    }
    return minTime
}
```Go 解决方案反映了 Python 逻辑。 数组`left`和`right`预先分配有`make`。 中间删除使用的条件更新`2*i`或者`2*(n-i)`。 最后的循环计算最小组合成本。
