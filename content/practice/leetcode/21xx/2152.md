 **难度：** 🟡 中等
 **主题：** 数组、哈希表、数学、动态规划、回溯、位操作、几何、位掩码

 ## 解决方案

 ## 问题理解

 此问题要求我们确定覆盖 X-Y 平面上给定点集所需的**最小直线数**。 每个点都由其定义`(x, y)`坐标，直线可以经过任意多个点，只要它们共线。 输入是唯一点的数组，输出是一个整数，表示覆盖所有点所需的最小行数。 

考虑到约束条件，最多有`10`点，因此我们在非常小的输入空间中进行操作。 这很重要，因为它使我们能够考虑对于较大输入大小可能不可行的方法，例如位掩码动态编程或穷举搜索。 需要注意的边缘情况包括所有点共线的可能性（最小线 = 1）、排列的点不存在三个共线（n 点的最大线 = n-1）或具有相同 x 或 y 值的点（垂直或水平线）。 

## 方法

 ### 蛮力

 蛮力方法涉及检查可以覆盖点的所有可能的线组合。 对于共线的每个点子集，我们可以尝试递归地覆盖其余点。 这保证了正确的解决方案，因为它详尽地考虑了所有可能性。 然而，子集的数量随着点的数量呈指数增长，使得这种方法对于较大的输入来说不切实际。 具体来说，需要检查`2^n`子集，验证每个子集的共线性会增加额外的计算。 

### 最佳方法

 最佳解决方案的关键见解是，因为`n <= 10`，我们可以使用**位掩码**表示点集，并使用**动态编程**来找到最小行数。 DP 中的每个状态代表一组已经涵盖的点。 对于每对点，我们可以预先计算与该对点共线的所有点的集合。 然后，使用 DP，迭代点的所有子集，并尝试用穿过点对的线覆盖剩余的点。 这减少了冗余计算，同时保证了最少的行数。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^3) | O(2^n * n^3) | O(n) | 检查所有子集的共线性，非常慢 |
 | 最佳（位掩码 DP）| O(3^n) | O(3^n) | O(2^n) | O(2^n) | 使用位掩码 DP 有效覆盖点 |

 ## 算法演练

 1. **预计算共线集**：对于每对点`(i, j)`，计算表示与该对共线的所有点的位掩码。 使用斜率公式`(y2-y1)*(x-x1) == (y-y1)*(x2-x1)`以避免浮点问题。 
2. **初始化DP阵列**：创建DP阵列`dp[mask]`在哪里`mask`是表示覆盖点的位掩码。 初始化`dp[0] = 0`因为覆盖任何点都需要零线。 
3. **迭代所有掩码**：对于每个掩码，迭代所有点对`(i, j)`找到可以用一条线覆盖的新点。 
4. **更新 DP 状态**：对于每个掩码和线集，通过将当前掩码与预先计算的共线掩码进行或运算来计算新掩码。 更新`dp[new_mask] = min(dp[new_mask], dp[mask] + 1)`跟踪所需的最少线路。 
5. **返回结果**：答案存储在`dp[(1 << n) - 1]`，表示所有点都被覆盖的掩模。 

**为什么有效**：DP 探索覆盖点子集的所有可能的线序列，确保考虑每种组合。 通过始终取最小值，可以保证最佳的行数。 

## Python 解决方案```python
from typing import List
from itertools import combinations

class Solution:
    def minimumLines(self, points: List[List[int]]) -> int:
        n = len(points)
        if n <= 1:
            return n
        
        # Precompute collinear masks
        collinear = [[0]*n for _ in range(n)]
        for i, j in combinations(range(n), 2):
            mask = 0
            x1, y1 = points[i]
            x2, y2 = points[j]
            for k, (x, y) in enumerate(points):
                if (y2 - y1) * (x - x1) == (y - y1) * (x2 - x1):
                    mask |= 1 << k
            collinear[i][j] = mask
            collinear[j][i] = mask
        
        dp = [float('inf')] * (1 << n)
        dp[0] = 0
        
        for mask in range(1 << n):
            if dp[mask] == float('inf'):
                continue
            first_uncovered = 0
            while first_uncovered < n and (mask >> first_uncovered) & 1:
                first_uncovered += 1
            if first_uncovered == n:
                continue
            for j in range(n):
                if j != first_uncovered:
                    new_mask = mask | collinear[first_uncovered][j]
                    dp[new_mask] = min(dp[new_mask], dp[mask] + 1)
        
        return dp[(1 << n) - 1]
```该实现首先预先计算每对的所有共线点集。 然后，它迭代所有位掩码状态，尝试用每个其他点覆盖第一个未覆盖的点以最大化覆盖范围。 DP 确保计算出最少的行数。 

## 解决方案```go
func minimumLines(points [][]int) int {
    n := len(points)
    if n <= 1 {
        return n
    }

    collinear := make([][]int, n)
    for i := range collinear {
        collinear[i] = make([]int, n)
    }

    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            mask := 0
            x1, y1 := points[i][0], points[i][1]
            x2, y2 := points[j][0], points[j][1]
            for k := 0; k < n; k++ {
                x, y := points[k][0], points[k][1]
                if (y2-y1)*(x-x1) == (y-y1)*(x2-x1) {
                    mask |= 1 << k
                }
            }
            collinear[i][j] = mask
            collinear[j][i] = mask
        }
    }

    dp := make([]int, 1<<n)
    for i := range dp {
        dp[i] = 1 << 30
    }
    dp[0] = 0

    for mask := 0; mask < (1 << n); mask++ {
        if dp[mask] == 1<<30 {
            continue
        }
        firstUncovered := 0
        for firstUncovered < n && (mask&(1<<firstUncovered)) != 0 {
            firstUncovered++
        }
        if firstUncovered == n {
            continue
        }
        for j := 0; j < n; j++ {
            if j != firstUncovered {
                newMask := mask | collinear[firstUncovered][j]
                if dp[newMask] > dp[mask]+1 {
                    dp[newMask] = dp[mask] + 1
                }
            }
        }
    }

    return dp[(1<<n)-1]
}
```在 Go 中，我们处理切片和位掩码操作的方式与 Python 类似。 我们初始化一个大数字来表示无穷大并迭代所有位掩码状态。 逻辑与Python版本相同。 

## 工作示例

 | 0000 | 0000 0 | (0,1)| 0111| 1 |
 | 0111| 3 | (3, 任意) | 1111 | 1111 2 |

 最终答案：2

 ### 示例 2：`points = [[0,2],[-2,-2],[1,4]]`所有点都通过 (-2,-2) 和 (1,4) 共线，因此 DP 直接覆盖一条直线上的所有点。 

最终答案：1
