 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、贪婪、计数

 ## 解决方案

 ## 问题理解

 这个问题要求我们使用两个字母的单词列表构造**最长的回文**。 每个单词最多可以使用一次，并且可以自由选择连接顺序。 回文从前到后读起来都是一样的，这意味着要使一对单词围绕中心对称出现，一个单词必须与另一个单词相反。 此外，**本身已经是回文**的单词（例如“gg”或“cc”）可以出现在中间或作为镜像对出现在两侧。 

输入是一个字符串数组`words`，其中每个字符串恰好是两个小写字母。 输出是所形成的回文的总长度，即所使用的单词的长度之和。 约束表明该列表最多可以包含 100,000 个单词，这排除了诸如生成所有排列之类的天真的暴力尝试。 

重要的边缘情况包括：

 1. 已经是回文的单词（如“aa”）可以用在回文的中间。 
2. 列表中没有反向对应词的单词不能对称使用。 
3. 多个相同的回文词（例如[“cc”，“cc”，“cc”]）可能只允许中间一个，但可以将其他的在两侧配对。 

了解这些约束和属性使我们能够使用哈希图设计有效的解决方案。 

## 方法

 **暴力方法**将涉及生成单词的所有排列并检查每个连接的回文有效性。 这是正确的但不可行，因为对于`n = 10^5`换句话说，排列的数量是天文数字，无法在合理的时间内进行计算。 

**关键见解**是可以通过将单词与其相反的对应项配对来构造回文。 我们只需要统计每个单词出现的次数，并检查其逆序是否存在。 对于本身就是回文的单词，我们可以使用偶数个单词来形成镜像对，如果不存在其他中间单词，则可以在中间放置一个单词。 

这将问题简化为**哈希表计数**，这使我们能够在线性时间内计算相对于单词数量的最长回文。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 生成所有排列并检查每个排列是否为回文，这对于大 n | 来说是不可行的
 | 最佳| O(n) | O(n) | 使用哈希映射来计算单词数并将每个单词与其相反的单词有效地配对 |

 ## 算法演练

 1. 初始化哈希图`count`存储每个单词的频率`words`。 
2. 初始化变量`length`跟踪总回文长度。 
3. 初始化布尔标志`used_middle`指示是否使用了中心回文词。 
4. 迭代每个唯一的单词`w`在哈希映射中。 
5. 检查是否`w`本身就是一个回文（即`w[0] == w[1]`）。 如果是这样：

 - 添加`2 * (count[w] // 2) * 2`到`length`对于镜像对（每个单词贡献 2 个字母）。 
- 如果有奇数个`w`和`used_middle`是`False`，加 2 到`length`对于中心词和集合`used_middle`到`True`。 
6. 如果`w`不是回文，计算其逆序`rev`。 

- 如果`rev`存在于哈希映射中，添加`2 * 2 * min(count[w], count[rev])`到`length`（每对贡献 4 个字母）。 
- 标记两者`w`和`rev`通过将其计数设置为零以避免重复计算来进行处理。 
7.迭代完所有单词后，返回`length`。 

**为什么有效：** 每个有效对都只计算一次，并且单个回文单词可以作为中心。 这确保了生成的字符串是最长的回文字符串。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def longestPalindrome(self, words: List[str]) -> int:
        count = Counter(words)
        length = 0
        used_middle = False
        
        for word in list(count.keys()):
            if count[word] == 0:
                continue
            rev = word[::-1]
            if word == rev:
                pairs = count[word] // 2
                length += pairs * 4
                if count[word] % 2 == 1 and not used_middle:
                    length += 2
                    used_middle = True
                count[word] = 0
            elif rev in count:
                pairs = min(count[word], count[rev])
                length += pairs * 4
                count[word] -= pairs
                count[rev] -= pairs
        
        return length
```该代码首先计算每个单词的频率，然后迭代每个单词以查找中心的镜像对或回文单词。 每个单词只处理一次，确保正确性和效率。 

## 解决方案```go
func longestPalindrome(words []string) int {
    count := make(map[string]int)
    for _, word := range words {
        count[word]++
    }

    length := 0
    usedMiddle := false

    for word, c := range count {
        if c == 0 {
            continue
        }
        rev := string([]byte{word[1], word[0]})
        if word[0] == word[1] {
            pairs := c / 2
            length += pairs * 4
            if c%2 == 1 && !usedMiddle {
                length += 2
                usedMiddle = true
            }
            count[word] = 0
        } else if count[rev] > 0 {
            pairs := min(c, count[rev])
            length += pairs * 4
            count[word] -= pairs
            count[rev] -= pairs
        }
    }
    
    return length
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 解决方案镜像了 Python 逻辑，但存在细微的语言差异，包括用于反转两个字符字符串的显式字节切片和一个帮助程序`min`功能。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们遍历列表一次来计算单词数，并遍历一次唯一单词来将它们配对。 |
 | 空间| O(n) | 哈希映射存储每个唯一单词的计数，最多 26*26 = 676 个条目，这是有界但渐近的 O(n)。 |

 该算法随输入大小线性缩放，并使用与唯一单词数量成比例的额外空间。
