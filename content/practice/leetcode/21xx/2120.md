[LeetCode 问题 2120](https://leetcode.com/problems/execution-of-all-suffix-instructions-staying-in-a-grid/)

 **难度：** 🟡 中等
 **主题：** 字符串、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们模拟一个机器人在`n x n`网格，从指定位置开始`startPos = [startrow, startcol]`。 我们以字符串形式给出一系列移动指令`s`，其中每个字符代表一个方向：`'L'`对于左，`'R'`对于权利，`'U'`对于向上，并且`'D'`对于下来。 机器人可以从**任何索引**开始执行指令`i`字符串的`s`并按顺序继续，直到下一个移动将其从网格中取出或到达指令字符串的末尾。 

输出是一个数组`answer`长度`m`（长度为`s`） 在哪里`answer[i]`记录机器人在启动时可以执行的指令数`i`第一条指令。 例如，如果机器人按照指令开始`i`并立即尝试脱离电网，`answer[i]`应该是`0`。 

约束表明网格和指令串相对较小（`n, m <= 500`），这允许`O(m^2)`模拟方法，但可能无法有效地扩展。 重要的边缘情况包括机器人从边界开始或网格最小的情况（`n = 1`），在这种情况下任何移动都是无效的。 

## 方法

 ### 蛮力

 一种简单的方法是从每条指令开始进行模拟`i`。 对于每个`i`，初始化机器人的位置`startPos`并模拟逐步移动，直到机器人退出网格或指令结束。 计算执行的移动次数并将其存储在`answer[i]`。 这是正确的，因为它直接遵循问题的规则，但效率很低，因为对于每个起始索引，它可能会模拟最多`m`移动。 在最坏的情况下，这给出`O(m^2)`时间复杂度。 

### 优化方法

 优化的主要见解是我们可以在跟踪机器人位置的同时顺序模拟**所有后缀指令**。 对于每个后缀，我们可以迭代，直到机器人脱离网格。 由于网格尺寸很小（`n <= 500`）并且指令也有限（`m <= 500`），我们仍然可以安全地实现这种直接模拟。 由于限制，不需要更先进的方法，例如使用动态规划或线段树预先计算每个方向的有效移动。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(m^2) | O(米) | 单独模拟每个后缀 |
 | 优化 | O(m^2) | O(米) | 由于约束限制，与此处的蛮力相同，如果机器人脱离电网，可以提前停止模拟 |

 ## 算法演练

 1.初始化一个数组`answer`长度`m`带零。 
2. 迭代每个索引`i`从`0`到`m - 1`。 这代表起始指令。 
3. 对于每个`i`，初始化机器人的位置`startrow, startcol`。 
4. 初始化计数器`steps`到`0`。 
5. 从索引迭代`j = i`到`m - 1`：

 - 检查说明`s[j]`。 
- 根据指令更新机器人的位置：减少行`'U'`，增加行`'D'`，减少列`'L'`，增加列`'R'`。 
- 如果机器人移出网格（行或列 < 0 或 ≥ n），则断开循环。 
- 否则，增加`steps`。 
6. 商店`steps`在`answer[i]`。 
7. 处理完所有起始索引后，返回`answer`。 

**为什么有效：** 该算法直接遵循问题的规则，迭代每个指令后缀并计算有效移动，直到机器人退出网格。 由于所有动作都是正确且独立地模拟的，因此每个起始指数的结果都是准确的。 

## Python 解决方案```python
from typing import List

class Solution:
    def executeInstructions(self, n: int, startPos: List[int], s: str) -> List[int]:
        answer = [0] * len(s)
        directions = {'U': (-1, 0), 'D': (1, 0), 'L': (0, -1), 'R': (0, 1)}
        
        for i in range(len(s)):
            x, y = startPos
            steps = 0
            for j in range(i, len(s)):
                dx, dy = directions[s[j]]
                x_new, y_new = x + dx, y + dy
                if 0 <= x_new < n and 0 <= y_new < n:
                    x, y = x_new, y_new
                    steps += 1
                else:
                    break
            answer[i] = steps
        
        return answer
```此实现初始化一个字典以将方向映射到坐标变化。 对于每个起始索引，它都会模拟移动，直到机器人脱离网格，从而增加计数器。 循环在到达边界后立即中断，确保效率。 

## 解决方案```go
func executeInstructions(n int, startPos []int, s string) []int {
    m := len(s)
    answer := make([]int, m)
    directions := map[byte][2]int{
        'U': {-1, 0},
        'D': {1, 0},
        'L': {0, -1},
        'R': {0, 1},
    }

    for i := 0; i < m; i++ {
        x, y := startPos[0], startPos[1]
        steps := 0
        for j := i; j < m; j++ {
            dx, dy := directions[s[j]][0], directions[s[j]][1]
            xNew, yNew := x+dx, y+dy
            if xNew >= 0 && xNew < n && yNew >= 0 && yNew < n {
                x, y = xNew, yNew
                steps++
            } else {
                break
            }
        }
        answer[i] = steps
    }

    return answer
}
```Go 的实现在逻辑上几乎是相同的。 主要区别在于类型处理：Go 使用`byte`用于字符串索引和数组用于方向映射。 切片处理动态数组，并且没有显式内存分配`answer`超越初始化。
