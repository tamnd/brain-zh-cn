 ## 解决方案

 ## 问题理解

 问题要求我们追加`k`现有数组的唯一正整数`nums`这样我们添加的整数都不存在于`nums`，并且我们附加的数字的总和被最小化。 换句话说，我们要选择最小的`k`缺少的正整数`nums`。 输入`nums`是一个最多 10^9 的正整数数组，并且`k`可以大到 10^8，这意味着按顺序检查每个整数的简单解决方案将太慢。 输出是`k`我们附加的整数。 边缘情况包括：`nums`已经包含从 1 开始的连续数字，或者当`nums`数字之间的差距非常大。 

## 方法

 一种强力方法是迭代从 1 开始的所有正整数，跳过已经存在的数字`nums`，直到我们附加了`k`数字。 原则上这是可行的，但是当`nums`最多有 10^5 个元素并且`k`最多为 10^8，因为迭代和检查成员资格的成本非常高。 

最优方法依赖于排序`nums`并使用贪心方法。 我们排序`nums`并迭代这些数字，跟踪每个数字之前缺失的最小正整数。 对于排序数组中连续数字之间的每个间隙，我们可以计算间隙中缺少多少个数字，并使用算术和公式有效地将它们相加。 如果处理完中的所有元素后仍有数字需要追加`nums`，我们将最小的缺失数字附加在最大数字之后`nums`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(max(n, k) * n) | O(n) | 从 1 开始迭代整数，检查 nums | 中的成员资格
 | 最佳| O(n log n) | O(n log n) | O(n) | 对 nums 进行排序并使用算术求和公式贪婪地添加缺失的数字 |

 ## 算法演练

 1. 排序`nums`并删除重复项以简化处理，因为重复项不会对最小缺失数产生额外的约束。 
2. 初始化变量`prev`为 0 以跟踪最后考虑的数字，以及`total_sum`到 0 来累加附加数字的总和。 
3. 迭代每个数字`num`在已排序的`nums`。 
4. 对于每个数字，计算之间缺失的数字数`prev + 1`和`num - 1`。 设这个数为`gap_count`。 
5. 如果`gap_count`小于或等于剩余的`k`，使用算术级数公式将间隙中的所有数字添加到总和中。 减去`gap_count`从`k`。 
6.如果`gap_count`超过剩余的`k`，仅附加第一个`k`使用算术级数公式计算间隙中的数字，然后中断，如我们所附加的`k`数字。 
7. 迭代完所有元素后，如果`k`仍然为正，追加下一个`k`从最后一个元素开始的连续数字加一，再次使用算术级数公式。 
8. 返回附加数字的总和。 

工作原理：该算法保证最小总和，因为在每一步它都会附加可用的最小缺失数字，首先填充现有数字之间的间隙，然后在最大数字之后按顺序继续。 使用算术总和可确保我们有效地计算总和，而无需显式迭代所有数字。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimalKSum(self, nums: List[int], k: int) -> int:
        nums = sorted(set(nums))
        total_sum = 0
        prev = 0
        
        for num in nums:
            gap_count = num - prev - 1
            if gap_count > 0:
                if gap_count <= k:
                    total_sum += (prev + 1 + num - 1) * gap_count // 2
                    k -= gap_count
                else:
                    total_sum += (prev + 1 + prev + k) * k // 2
                    k = 0
                    break
            prev = num
        
        if k > 0:
            total_sum += (prev + 1 + prev + k) * k // 2
        
        return total_sum
```Python 实现首先删除重复项并对数组进行排序。 它跟踪连续元素之间的缺失数字，使用算术求和公式有效计算缺失数字的总和。 它更新了`k`作为附加数字。 任何剩余的`k`numbers are appended after the largest element.

 ## 解决方案```go
import "sort"

func minimalKSum(nums []int, k int) int64 {
    numMap := make(map[int]struct{})
    for _, num := range nums {
        numMap[num] = struct{}{}
    }
    
    uniqueNums := make([]int, 0, len(numMap))
    for num := range numMap {
        uniqueNums = append(uniqueNums, num)
    }
    
    sort.Ints(uniqueNums)
    
    var totalSum int64 = 0
    prev := 0
    
    for _, num := range uniqueNums {
        gapCount := num - prev - 1
        if gapCount > 0 {
            if gapCount <= k {
                totalSum += int64(prev+1+num-1) * int64(gapCount) / 2
                k -= gapCount
            } else {
                totalSum += int64(prev+1+prev+k) * int64(k) / 2
                k = 0
                break
            }
        }
        prev = num
    }
    
    if k > 0 {
        totalSum += int64(prev+1+prev+k) * int64(k) / 2
    }
    
    return totalSum
}
```在 Go 中，我们使用映射显式处理重复项并对唯一数字进行排序。 我们使用`int64`为了`totalSum`以避免整数溢出，因为总和可能很大。 逻辑反映了 Python 版本，迭代排序的数字并使用算术和。

 ## 边缘情况
