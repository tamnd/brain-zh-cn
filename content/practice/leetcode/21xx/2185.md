[LeetCode 问题 2185](https://leetcode.com/problems/counting-words-with-a-given-prefix/)

 **难度：** 🟢简单
 **主题：** 数组、字符串、字符串匹配

 ## 解决方案

 ## 问题理解

 这个问题给了我们两个输入：

 - 名为的字符串数组`words`- 一个名为`pref`我们必须数一下里面有多少个字符串`words`从字符串开始`pref`。 

前缀表示字符串的开始部分。 例如：

-`"at"`是一个前缀`"attention"`-`"pay"`是一个前缀`"pay"`-`"code"`不是以下的前缀`"leetcode"`因为`"leetcode"`不开始于`"code"`因此，任务很简单：

 1. 检查数组中的每个单词。 
2. 检查单词是否以`pref`。 
3. 统计有多少个单词满足这个条件。 
4. 返回最终计数。 

限制很小：

 - 最多100字
 - 每个单词长度最多100
 - 前缀长度最多为100

 这些限制告诉我们，性能并不是主要问题。 即使直接逐个字符比较也是完全可以接受的，因为数据总量很小。 

一个重要的细节是前缀必须出现在单词的开头。 子字符串出现在中间的某个位置是不够的。 

例如：

-`"attend"`开始于`"at"`， 有效的
-`"practice"`包含`"at"`中间，无效

 该问题还保证：

 - 所有字符串均为小写英文字母
 - 每个字符串的长度至少为 1
 - 前缀非空

 这些保证简化了实现，因为我们不需要处理空字符串或无效输入。 

一些重要的边缘情况包括：

 - 没有单词与前缀匹配
 - 每个单词都匹配前缀
 - 前缀比某些单词长
 - 一个单词完全等于前缀
 - 数组仅包含一个单词

 正确的解决方案必须一致地处理所有这些情况。 

## 方法

 ### 蛮力方法

 暴力方法将前缀与每个单词逐个字符进行比较。 

对于每个单词：

 1. 首先检查单词是否足够长以包含前缀。 
2. 将前缀的每个字符与单词中相应的字符进行比较。 
3. 如果所有字符都匹配，则增加答案。 

这是有效的，因为当每个前缀字符与单词开头的相应字符匹配时，字符串就以前缀开头。 

虽然这种方法是完全正确的，但它需要手动迭代字符。 该实现比必要的更加冗长，并且现代编程语言已经提供了优化的前缀检查功能。 

最坏情况的复杂性仍然是可以接受的，因为约束很小，但我们可以编写一个更清晰、更易读的解决方案。 

### 最佳方法

 关键的观察是大多数语言已经包含用于检查前缀的内置方法。 

在Python中，我们可以使用：```
word.startswith(pref)
```在 Go 中，我们可以使用：```
strings.HasPrefix(word, pref)
```这些函数直接表达问题的意图，并在内部有效地执行必要的比较。 

算法变为：

 1. 迭代每个单词。 
2. 检查是否以`pref`。 
3. 计算匹配数。 

这既简单又高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × m) | O(1) | O(1) | 手动比较每个单词的字符 |
 | 最佳| O(n × m) | O(1) | O(1) | 使用内置前缀检查功能 |

 这里：

-`n`是单词数
 -`m`是前缀的长度

 ## 算法演练

 1. 初始化一个名为`count`到`0`。 

该变量跟踪有多少个单词以给定前缀开头。 
2. 遍历列表中的每个单词`words`大批。 

我们必须检查每个单词，因为它们中的任何一个都可以匹配前缀。 
3. 对于当前单词，检查它是否以`pref`。 

在 Python 中，这是通过使用完成的`word.startswith(pref)`。 

在 Go 中，这是通过使用完成的`strings.HasPrefix(word, pref)`。 

这些函数将单词的开头与前缀进行比较。 
4. 如果单词以前缀开头，则递增`count`。 

每场成功的比赛都会为最终答案贡献一分。 
5.处理完所有单词后，返回`count`。 

此时，计数器代表匹配单词的总数。 

### 为什么它有效

 该算法对每个单词只检查一次，并检查前缀是否与该单词的开头匹配。 由于每个有效的匹配单词都会使计数器递增一次，并且每个不匹配的单词不会产生任何贡献，因此最终计数恰好是包含以下内容的单词数：`pref`作为前缀。 

## Python 解决方案```python
from typing import List

class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:
        count = 0

        for word in words:
            if word.startswith(pref):
                count += 1

        return count
```实现从初始化开始`count`为零。 该变量存储匹配单词的数量。 

接下来，代码循环遍历列表中的每个单词`words`大批。 对于每个单词，它使用Python的内置`startswith()`判断单词是否开头的方法`pref`。 

如果条件为真，则计数器递增。 

最后，在检查完所有单词后，该函数返回累计计数。 

该实现直接遵循前面描述的算法，并使用Python的内置字符串功能来保持解决方案的简洁性和可读性。 

## 解决方案```go
package main

import "strings"

func prefixCount(words []string, pref string) int {
    count := 0

    for _, word := range words {
        if strings.HasPrefix(word, pref) {
            count++
        }
    }

    return count
}
```Go 解决方案遵循与 Python 版本相同的逻辑。 主要区别在于 Go 需要导入`strings`使用的包`strings.HasPrefix`。 

该循环使用 Go 的方法迭代切片`range`句法。 由于约束非常小，因此不必担心整数溢出。 该解决方案使用恒定的额外空间并自然地处理所有边缘情况。

 ## 边缘情况

 ### 比单词长的前缀

 错误的常见来源是尝试比较较短单词末尾之外的字符。 例如：```
word = "ab"
pref = "abcd"
```该单词不可能以前缀开头，因为它更短。 内置前缀函数会自动安全、正确地处理此返回`False`。 

### 完全等于前缀的单词

 一些不正确的实现仅计算严格长于前缀的单词。 但是，字符串始终被认为是以其自身开头。 

例如：```
word = "app"
pref = "app"
```这应该算作有效的匹配。 两种实现都正确地将相等视为成功的前缀匹配。 

### 没有匹配的词

 当没有任何单词以前缀开头时，会发生另一个重要情况。 该算法仍然必须正确返回`0`而不是未初始化的值或不正确的计数。 

例如：```
words = ["dog", "cat"]
pref = "z"
```由于没有单词满足条件，因此计数器永远不会递增，并且最终返回值保持不变`0`。
