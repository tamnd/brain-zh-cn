 **难度：** 🔴难
 **主题：** 数组、哈希表、两个指针、排序、枚举

 ## 解决方案

 ## 问题理解

 该问题提出了一个场景，其中 Alice 有一个原始数组`arr`长度`n`由正整数组成。 她选择一个正整数`k`并生成两个新数组：`lower`和`higher`。 数组`lower`通过减去形成`k`从每个元素`arr`， 尽管`higher`通过添加形成`k`到每个元素。 然后将数组合并为一个数组`nums`长度`2n`，其中区别`lower`和`higher`丢失了。 我们的任务是恢复原始数组`arr`。 

输入是一个列表`2n`表示并集的整数`lower`和`higher`数组。 预期输出是任何有效数组`arr`长度`n`本来可以产生`nums`通过一些正整数`k`。 约束保证`1 <= n <= 1000`和`1 <= nums[i] <= 10^9`，确保解决方案必须有效地处理中等规模的阵列。 该问题保证至少存在一个有效的解决方案，这简化了对不可能性或空输出的考虑。 

重要的边缘情况包括小数组（`n = 1`）、所有数字都相等的数组、间隙非常大的数组（需要很大的`k`），以及具有重复项的数组，这可能会误导天真的配对逻辑。 

## 方法

 暴力方法会尝试所有可能的数字对`nums`计算潜在价值`k`然后验证是否划分`nums`进入`lower`和`higher`基于此的数组`k`重建一个有效的`arr`。 虽然这对于小输入有效，但对于`n = 1000`因为有`O(n^2)`可能的对，并检查每一个是`O(n)`， 导致`O(n^3)`复杂。 

最佳方法依赖于两个关键的观察结果。 首先，排序后`nums`，任何较小的数字和较大的数字之间的差异`nums`是`2k`如果它们对应于相同的原始元素。 其次，一旦我们猜出一个有效的`k`从排序后的数组中，我们可以尝试通过贪婪地配对数字来重建原始数组：始终将最小的未使用数字与一个数字配对`2k`在多重集中更大。 这确保我们正确恢复`arr`无需尝试所有排列。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 测试所有对的 k 并验证重建 |
 | 最佳| O(n^2) | O(n^2) | O(n) | 对数组进行排序并尝试从配对差异中获得有效的 k，使用多重集进行配对 |

 ## 算法演练

 1. 排序`nums`按升序排列。 排序确保我们可以首先考虑最小的数字，并尝试根据以下条件将它们与潜在的合作伙伴配对`2k`。 
2. 初始化一个多重集（Python 中的计数器）来跟踪其中每个数字的计数`nums`。 
3. 迭代所有潜在候选元素中的最小元素`higher`减去中的最小元素`nums`。 具体来说，对于每个`nums[i] > nums[0]`, 计算`2k = nums[i] - nums[0]`。 忽略零或负差异。 
4.如果`2k`是偶数，计算`k = (nums[i] - nums[0]) // 2`。 
5.尝试重建`arr`使用计算出的`k`：

 - 复制多组数字。 
- 对于排序中的每个数字`nums`，如果它存在于多重集中，则将其视为`lower[i] = x - k`并将其与`higher[i] = x + k`。 检查多重集中是否存在配对号码。 如果是，则减少多重集中的计数并添加`lower[i] + k`到原始数组。 
6. 如果所有数字都配对成功，则返回重构后的数组`arr`。 
7. 如果候选者不存在有效配对`k`，继续下一个候选。 

**为什么有效：** 关键的不变量是每个原始数字`arr[i]`恰好对应于中的两个数字`nums`：`arr[i] - k`和`arr[i] + k`。 通过迭代潜力`k`值源自最小元素的差异，我们确保有效测试所有有效的可能性。 使用多重集可确保我们正确处理重复项。 

## Python 解决方案```python
from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums) // 2
        
        for i in range(1, len(nums)):
            diff = nums[i] - nums[0]
            if diff % 2 != 0 or diff == 0:
                continue
            k = diff // 2
            counter = Counter(nums)
            res = []
            valid = True
            
            for num in nums:
                if counter[num] == 0:
                    continue
                if counter[num + 2 * k] == 0:
                    valid = False
                    break
                counter[num] -= 1
                counter[num + 2 * k] -= 1
                res.append(num + k)
            
            if valid and len(res) == n:
                return res
        
        return []
```在这个实现中，`nums`首先排序。 我们用最小的元素迭代潜在的差异以确定可能的`k`价值观。 一个`Counter`跟踪剩余的配对号码。 对于每个有效的配对，我们附加`num + k`到`res`和递减计数。 一旦长度有效的数组`n`构造完毕，返回。 

## 解决方案```go
package main

import (
    "sort"
)

func recoverArray(nums []int) []int {
    sort.Ints(nums)
    n := len(nums) / 2

    for i := 1; i < len(nums); i++ {
        diff := nums[i] - nums[0]
        if diff == 0 || diff%2 != 0 {
            continue
        }
        k := diff / 2
        counter := make(map[int]int)
        for _, num := range nums {
            counter[num]++
        }
        res := make([]int, 0, n)
        valid := true

        for _, num := range nums {
            if counter[num] == 0 {
                continue
            }
            if counter[num + 2*k] == 0 {
                valid = false
                break
            }
            counter[num]--
            counter[num + 2*k]--
            res = append(res, num + k)
        }

        if valid && len(res) == n {
            return res
        }
    }

    return []int{}
}
```在Go中，地图用于模拟多重集。 排序和差异计算与Python版本相同。 该解决方案确保正确处理重复项并保持 O(n^2) 复杂性。 

## 工作示例

 - k = 1 产生对：(2,4), (6,8), (10,12)
 - 原始数组：`[3, 7, 11]`示例2：`nums = [1,1,3,3]`- 种类：`[1,1,3,3]`- 最小数量：1
 - 与1的区别：0,2,2
 - k = 1 产生对：(1,3), (1,3)
 - 原始数组：`[2,2]`示例3：`nums = [5,435]`- 种类：`[5,435]`- 最小数量：5
 - 与 5 的差异：430
 - k = 215
 - 原始数组：`[220]`## 复杂度分析
