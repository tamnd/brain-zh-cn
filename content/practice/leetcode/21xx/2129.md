[LeetCode 问题 2129](https://leetcode.com/problems/capitalize-the-title/)

 **难度：** 🟢简单
 **主题：** 字符串

 ## 解决方案

 ## 问题理解

 该问题要求我们根据基于单词长度的特定规则来转换给定标题字符串中每个单词的大小写。 

我们得到一个名为的字符串`title`，其中包含一个或多个由单个空格分隔的单词。 每个单词仅包含英文字母字符，并且没有前导或尾随空格。 我们的任务是独立处理每个单词并应用两个大写规则之一：

 - 如果字长是`1`或者`2`，整个单词必须变为小写。 
- 如果字长是`3`或更大，第一个字符必须变为大写，所有其余字符必须变为小写。 

最终结果应该是一个新格式化的字符串，其中所有转换后的单词都使用空格连接在一起。 

例如，这个词`"tHe"`有长度`3`，所以就变成了`"The"`。 这个词`"OF"`有长度`2`，所以就变成了`"of"`。 

限制非常小：

 -`1 <= title.length <= 100`这告诉我们性能并不是主要问题。 即使效率较低的解决方案仍然可以快速运行，因为输入大小很小。 然而，问题主要是测试仔细的字符串操作和大小写规则的正确处理。 

有几个重要的边缘情况需要考虑：

 - 单字词，例如`"I"`必须变成小写。 
- 两个字符的单词，例如`"OF"`也必须完全小写。 
- 单词的格式可能已经正确，所以我们不应该意外地过度修改它们。 
- 单词可以包含任意大小写组合，例如`"cApiTalIZe"`。 
- 由于该问题保证单词由单个空格分隔并且没有前导或尾随空格，因此我们不需要处理格式错误的空格。 

## 方法

 ### 蛮力方法

 一个简单的暴力解决方案是手动处理每个单词的每个字符。 

我们可以将标题分成单词，然后对于每个单词：

 1. 检查长度。 
2.如果长度是`1`或者`2`，迭代所有字符并手动将它们转换为小写。 
3. 否则，手动将第一个字符大写并小写所有剩余字符。 
4. 将所有已处理的单词重新连接在一起。 

这种方法是正确的，因为它明确地将所需的大写规则应用于每个字符。 然而，它不必要地冗长且容易出错，因为大多数编程语言已经提供了内置的字符串大写实用程序。 

尽管对于给定的约束，这种方法实际上并不算太慢，但它比必要的更复杂，并且增加了实现的复杂性。 

### 最佳方法

 关键的观察是每个单词都可以使用内置字符串方法独立处理。 

我们可以：

 1. 将字符串拆分为单词。 
2. 对于每个单词：

 - 如果长度小于或等于，则将整个单词转换为小写`2`。 
- 否则，将第一个字母大写，其余字母小写。 
3. 将处理后的单词重新连接成单个字符串。 

这很有效，因为大小写规则仅取决于当前单词，而不取决于相邻单词。 内置方法如`.lower()`和`.capitalize()`Python 显着简化了实现。

 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 手动处理每个字符 |
 | 最佳| O(n) | O(n) | 使用内置字符串操作来实现更清晰的逻辑 |

 ## 算法演练

 1. 使用空格将输入字符串拆分为单个单词。 

这使我们能够独立处理每个单词。 由于该问题保证单词之间恰好有一个空格，因此拆分操作简单且可靠。 
2. 创建一个结果列表来存储转换后的单词。 

使用列表非常高效，因为在许多语言中重复连接字符串可能会比较慢。 
3. 迭代每个单词。 

对于每个单词，确定其长度，因为大写规则完全取决于单词的大小。 
4. 如果字长为`1`或者`2`，将整个单词转换为小写。 

根据问题规则，小单词不应包含任何大写字符。 
5. 否则，请正确地将单词大写。 

将第一个字母转换为大写，其余字母转换为小写。 在Python中，`.capitalize()`方便地执行此转换。 
6. 将转换后的单词添加到结果列表中。 

这保留了原始词序。 
7. 用空格连接所有已处理的单词。 

最终输出必须保持原始的间距结构。 

### 为什么它有效

 该算法之所以有效，是因为每个单词都是根据问题陈述中指定的确切规则独立转换的。 每个可能的单词都恰好属于以下两类之一：

 - 长度`1`或者`2`- 长度`3`或更大

 该算法对每个类别应用正确的转换，确保最终标题满足所有大写要求。 

## Python 解决方案```python
class Solution:
    def capitalizeTitle(self, title: str) -> str:
        words = title.split()
        result = []

        for word in words:
            if len(word) <= 2:
                result.append(word.lower())
            else:
                result.append(word.capitalize())

        return " ".join(result)
```实现首先将输入字符串拆分为单独的单词。 这给了我们一个列表，其中每个元素都可以独立处理。 

接下来，我们迭代每个单词并检查其长度。 如果单词包含一两个字符，我们使用以下命令将整个单词转换为小写`.lower()`。 

对于较长的单词，我们使用`.capitalize()`，它自动将第一个字符转换为大写，其余字符转换为小写。 这与所需的格式完全匹配。 

最后，我们使用空格将所有转换后的单词重新连接在一起并返回结果字符串。 

## 解决方案```go
package main

import (
	"strings"
	"unicode"
)

func capitalizeTitle(title string) string {
	words := strings.Split(title, " ")

	for i, word := range words {
		word = strings.ToLower(word)

		if len(word) > 2 {
			runes := []rune(word)
			runes[0] = unicode.ToUpper(runes[0])
			word = string(runes)
		}

		words[i] = word
	}

	return strings.Join(words, " ")
}
```Go 解决方案遵循与 Python 实现相同的逻辑。 一个区别是 Go 没有提供与 Python 直接等效的功能`.capitalize()`方法，因此我们在将整个单词转换为小写后手动将第一个字符大写。 

我们使用`[]rune`当修改第一个字符时，因为 Go 字符串是不可变的。 转换为符文也使 Unicode 处理的实现更加安全，即使这个问题只包含英文字母。

 ## 边缘情况

 一种重要的边缘情况是单字符单词，例如`"I"`或者`"A"`。 这些单词必须完全小写，即使它们最初包含大写字母。 将每个单词大写的幼稚实现会错误地产生`"I"`而不是`"i"`。 我们的实现显式检查字长并正确地将所有单字符单词小写。 

另一个重要的边缘情况是两个字符的单词，例如`"OF"`或者`"Is"`。 这些单词也需要完全小写转换。 这很容易被忽视，因为许多标题格式约定都将单词大写，例如`"Is"`或者`"Of"`。 然而，这个问题有它自己的自定义大小写规则，我们的解决方案完全遵循它们。 

第三种边缘情况涉及具有不寻常大写模式的单词，例如`"cApItALiZe"`。 仅仅将第一个字母大写是不够的，因为其余字母也必须变为小写。 我们的实现通过使用来解决这个问题`.capitalize()`在 Python 中或在 Go 中将第一个字符大写之前显式地小写整个单词。
