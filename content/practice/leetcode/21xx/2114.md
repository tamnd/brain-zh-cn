[LeetCode 问题 2114](https://leetcode.com/problems/maximum-number-of-words-found-in-sentences/)

 **难度：** 🟢简单
 **主题：** 数组、字符串

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出了一个字符串数组，称为`sentences`。 每个字符串代表一个由小写英文单词组成的句子，单词之间恰好有一个空格分隔。 该问题要求我们确定任何单个句子中出现的最大单词数。 

一个关键细节是如何分隔单词。 该问题保证：

 - 没有前导或尾随空格。 
- 单词之间恰好间隔一个空格。 
- 每个句子至少包含一个单词。 

由于这些保证，计算字数变得非常简单。 在格式正确的句子中，单词数始终等于空格数加一。 例如：

-`"hello world"`包含 1 个空格，因此有 2 个单词。 
-`"this is easy"`包含 2 个空格，因此有 3 个单词。 

输入大小非常小：

 - 最多 100 句话。 
- 每个句子长度最多 100 个字符。 

这些限制告诉我们，效率并不是主要问题。 即使是相对简单的解决方案也很容易满足限制。 

一个重要的观察是，我们不需要实际提取或存储单词本身。 我们只需要计数。 这使我们能够通过扫描字符和计算空格来有效地解决问题。 

有一些边缘情况值得考虑：

 - 只有一个单词的句子，例如`"hello"`, 不包含空格，但仍算作一个单词。 
- 多个句子可能具有相同的最大字数。 
- 尽可能短的输入包含单个单词的单个句子。 

该问题保证了有效的格式，因此我们不需要处理格式错误的输入，例如双空格或空字符串。 

## 方法

 ### 蛮力方法

 一种简单的方法是使用空格字符将每个句子分成单词，然后计算产生了多少个单词。 

对于每个句子：

 1. 打电话`split(" ")`。 
2. 计算结果的单词数。 
3. 跟踪迄今为止看到的最大计数。 

这是有效的，因为该问题保证单词由单个空格分隔，没有前导或尾随空格。 因此，按空格分割总是会产生正确的单词列表。 

尽管此解决方案对于给定的约束是完全可以接受的，但它执行了不必要的工作，因为它为拆分字数组分配了额外的内存。 

### 最佳方法

 关键的观察结果是有效句子中的单词数等于空格数加一。 

我们可以简单地：

 1. 数一下句子中出现了多少个空格。 
2. 加一即可得到字数。 
3. 跟踪所有句子的最大值。 

这可以避免创建中间数组并减少额外的内存使用。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × m) | O(米) | 将每个句子拆分为单词 |
 | 最佳| O(n × m) | O(1) | O(1) | 直接计算空间，无需额外存储 |

 这里：

-`n`是句子的数量。 
-`m`是平均句子长度。 

## 算法演练

 1. 初始化一个名为`max_words`到`0`。 该变量将存储迄今为止找到的最大字数。 
2. 遍历语句中的每个句子`sentences`大批。 
3. 对于当前句子，计算它包含多少个空格。 由于每个空格分隔两个单词，因此单词数为：```
number_of_spaces + 1
```4. 将此字数与`max_words`。 如果当前计数较大，则更新`max_words`。 
5. 继续处理所有句子，直到循环结束。 
6. 返回`max_words`作为最终答案。 

### 为什么它有效

 该算法之所以有效，是因为该问题保证每个句子的格式正确，单词之间只有一个空格，并且开头或结尾没有多余的空格。 在这些条件下，每个空格恰好代表单词之间的一个分隔。 因此，计算空格并加一总是可以给出句子中准确的单词数。 

通过检查每个句子并维护最大计数，该算法可以正确返回在任何句子中找到的最大单词数。 

## Python 解决方案```python
from typing import List

class Solution:
    def mostWordsFound(self, sentences: List[str]) -> int:
        max_words = 0

        for sentence in sentences:
            word_count = sentence.count(" ") + 1
            max_words = max(max_words, word_count)

        return max_words
```实现直接遵循算法。 

变量`max_words`存储迄今为止找到的最佳答案。 我们逐句迭代每个句子。 

对于每个句子，表达式：```python
sentence.count(" ") + 1
```计算空格数并将其转换为单词数。 由于保证输入格式有效，因此该计算始终是正确的。 

然后，我们使用 Python 将当前句子的字数与现有的最大值进行比较`max()`功能。 

最后，处理完所有句子后，我们返回最大值。 

## 解决方案```go
import "strings"

func mostWordsFound(sentences []string) int {
    maxWords := 0

    for _, sentence := range sentences {
        wordCount := strings.Count(sentence, " ") + 1

        if wordCount > maxWords {
            maxWords = wordCount
        }
    }

    return maxWords
}
```Go 解决方案与 Python 版本非常相似。 主要区别在于 Go 使用`strings.Count()`标准库中的函数用于计算空格。 

Go 没有内置 Python`max()`整数函数，因此我们使用手动更新最大值`if`陈述。 

不用担心整数溢出，因为最大句子长度非常小。

 ## 边缘情况

 ### 只有一个词的句子

 像这样的一句话`"hello"`不包含空格。 仅计算空格的幼稚实现可能会错误地返回`0`。 我们的实现通过始终添加来避免此问题`1`计算空格后，产生正确的结果`1`。 

### 多个句子共享最大值

 几个句子可能包含相同的最多单词数。 例如：```
["a b c", "d e f"]
```两者都包含三个单词。 该算法正确地处理了这个问题，因为它只跟踪最大值本身，而不是哪个句子产生它。 

### 非常小的输入大小

 最小的有效输入是包含一个单词的单个句子：```
["a"]
```这种情况可能会暴露与初始化或空处理相关的错误。 我们的实现初始化`max_words`到`0`，处理单个句子，计算`0 + 1`，并正确返回`1`。
