 ## 解决方案

 ## 问题理解

 问题给了我们一个字符串`s`仅由数字组成`'0'`到`'9'`。 我们必须计算有多少不同的子串满足特殊条件：

 子字符串中出现的每个数字必须出现相同的次数。 

子字符串是字符串的连续部分。 子字符串可以包含一位数字或几个不同的数字。 重要的要求是该子字符串中出现的所有数字必须具有相同的频率。 

例如，考虑子字符串`"1212"`:

 -`'1'`出现2次
 -`'2'`出现2次

 由于两个数字出现的频率相同，因此子字符串有效。 

现在考虑`"122"`:

 -`'1'`出现1次
 -`'2'`出现2次

 频率不相等，因此该子串无效。 

另一个重要的细节是独特性。 即使相同的有效子串在字符串中出现多次，也只应计算一次。 

例如，在`"1212"`:

 -`"12"`出现两次
 - 只计算一次

 限制相对较小：

 -`1 <= s.length <= 1000`-`s`仅包含数字

 由于字符串长度最多为 1000，因此`O(n^2)`解决方案通常是可以接受的，同时`O(n^3)`可能会变得太慢。 事实上，只有 10 个可能的数字非常重要，并且可以实现有效的频率检查。 

一些边缘情况很重要：

 - 单字符子串始终有效，因为只出现一位数字。 
- 重复的子串只能计算一次。 
- 具有许多重复数字的子字符串可能会产生重复的有效模式。 
- 包含所有相同数字的字符串必须仍然正常工作。 
- 具有许多不同数字的字符串需要仔细的频率比较。 

## 方法

 ### 蛮力方法

 暴力解决方案生成每个可能的子字符串并检查所有出现的数字是否具有相同的频率。 

对于每个子串：

 1. 统计每个数字出现的次数。 
2. 提取非零频率。 
3. 验证所有非零频率是否相等。 
4. 如果有效，则将子字符串存储在集合中。 

有`O(n^2)`子串。 天真地检查每个子串需要再次扫描子串以计算频率，这会花费`O(n)`时间。 

这导致整体复杂性`O(n^3)`。 

虽然`n = 1000`并不巨大，`O(n^3)`可能会变得太慢，因为大约有一百万个子字符串，每个子字符串可能需要再次扫描。 

### 最佳方法

 关键的观察结果是只有 10 个可能的数字。 

我们可以逐步扩展子串，而不是从头开始重新计算每个子串的频率。 

对于每个起始索引：

 1. 维护一个大小为 10 的频率数组。 
2. 一次将子字符串扩展一个字符。 
3. 更新新增数字的频率。 
4. 检查所有非零频率是否相等。 

由于检查 10 位数字的时间是恒定的，因此可以有效地验证每个子字符串。 

为了避免多次计算重复项，我们将有效的子字符串存储在哈希集中。 

我们不直接存储实际的子字符串内容，而是使用滚动哈希。 这样就避免了重复创建子字符串对象，提高了效率。 

## 方法比较

 | 方法| 时间复杂度| 空间复杂度| 笔记|

 ## 算法演练

 ### 步骤 1：初始化唯一有效子字符串的集合

 我们使用哈希集来确保重复的子字符串仅计算一次。 

我们不存储原始子字符串，而是存储滚动哈希值。 

### 第 2 步：迭代每个起始位置

 对于每个索引`start`:

 - 创建一个大小为 10 的新频率数组
 - 初始化滚动哈希变量

 这允许我们逐步构建子字符串。 

### 步骤 3：逐字符扩展子字符串

 对于每个结束索引`end`开始于`start`:

 - 将数字字符转换为整数
 - 增加其频率
 - 更新滚动哈希

 滚动哈希使我们能够有效地唯一地表示子字符串。 

### 步骤4：检查频率是否相等

 我们扫描频率数组：

 - 忽略零频率
 - 记录第一个非零频率
 - 确保所有其他非零频率与其匹配

 如果是，则子字符串有效。 

### 步骤 5：将有效子字符串添加到集合中

 当子串满足条件时：

 - 将其滚动哈希插入集合中

 由于集合会自动删除重复项，因此重复的子字符串仅计算一次。 

###第6步：返回设置的大小

 最终答案只是集合中存储的唯一有效子字符串的数量。 

### 为什么它有效

 该算法对每个可能的子串只检查一次。 对于每个子字符串，它会增量地维护精确的数字频率，因此相等性检查始终准确。 

仅当所有非零数字计数相等时才会添加子字符串。 由于该集合存储子字符串的唯一表示形式，因此重复项将被自动删除。 

因此，每个有效的唯一子字符串只计算一次。 

## Python 解决方案```python
class Solution:
    def equalDigitFrequency(self, s: str) -> int:
        unique_hashes = set()

        base = 11
        mod = 10**9 + 7

        n = len(s)

        for start in range(n):
            freq = [0] * 10
            rolling_hash = 0

            for end in range(start, n):
                digit = int(s[end])

                freq[digit] += 1

                rolling_hash = (
                    rolling_hash * base + digit + 1
                ) % mod

                target = 0
                valid = True

                for count in freq:
                    if count == 0:
                        continue

                    if target == 0:
                        target = count
                    elif count != target:
                        valid = False
                        break

                if valid:
                    unique_hashes.add(rolling_hash)

        return len(unique_hashes)
```该实现使用两个嵌套循环来枚举所有子字符串。 

外环固定起始位置。 对于每个起始索引，我们初始化：

 - 数字的频率数组
 - 滚动哈希值

 内部循环每次逐步将子字符串扩展一个字符。 这种增量构造很重要，因为它避免了从头开始重新计算频率。 

每次添加新数字时：```python
freq[digit] += 1
```滚动哈希使用多项式哈希进行更新：```python
rolling_hash = (
    rolling_hash * base + digit + 1
) % mod
```添加`1`避免涉及前导零的歧义。 

接下来，代码检查所有非零频率是否相同。 第一个非零计数成为参考频率。 所有其他非零计数必须与其匹配。 

如果子字符串有效，则将其哈希值插入到集合中。 由于集合仅保留唯一值，因此重复的子字符串会自动去重。 

最后，返回唯一有效子串的数量。 

## 解决方案```go
package main

func equalDigitFrequency(s string) int {
    uniqueHashes := make(map[int]bool)

    const base = 11
    const mod = 1000000007

    n := len(s)

    for start := 0; start < n; start++ {
        freq := make([]int, 10)
        rollingHash := 0

        for end := start; end < n; end++ {
            digit := int(s[end] - '0')

            freq[digit]++

            rollingHash = (rollingHash*base + digit + 1) % mod

            target := 0
            valid := true

            for _, count := range freq {
                if count == 0 {
                    continue
                }

                if target == 0 {
                    target = count
                } else if count != target {
                    valid = false
                    break
                }
            }

            if valid {
                uniqueHashes[rollingHash] = true
            }
        }
    }

    return len(uniqueHashes)
}
```Go 实现遵循与 Python 版本相同的算法结构。 

一个`map[int]bool`使用而不是 Python 集。 频率计数使用长度为 10 的切片。 

Go 字符串是字节索引的，因此数字转换是通过以下方式执行的：```go
digit := int(s[end] - '0')
```整数溢出不是问题，因为所有哈希计算都是模数执行的`1e9+7`。

 ## 边缘情况

 一个重要的边缘情况是仅包含一个唯一数字的字符串，例如`"111111"`。 每个子字符串都完全由相同的数字组成，因此每个子字符串都是有效的。 然而，许多子字符串是重复的。 有缺陷的实现可能会单独计算每次出现的次数，而不是强制执行唯一性。 哈希集可以防止此问题，因为相同的子字符串会产生相同的存储表示。 

另一个重要的情况涉及子串，其中频率在最初匹配后变得不相等。 例如，`"121"`开始有效时间为`"1"`和`"12"`，但一旦第二次就失效`'1'`出现。 增量频率跟踪可以正确处理此问题，因为在每次扩展子字符串后都会执行验证。 

第三种边缘情况是正确处理零。 由于数字范围从`'0'`到`'9'`，实现必须像对待任何其他数字一样对待零。 滚动哈希使用`digit + 1`而不是`digit`直接避免哈希构造中涉及前导零的歧义。 这确保了像这样的子字符串`"0"`和`"00"`都得到了鲜明的体现。 

另一个微妙的情况是重复的有效子字符串出现在不同的位置。 在`"1212"`, 子串`"12"`出现两次。 如果没有重复数据删除，算法会错误地计算两次。 该集合保证每个有效子字符串仅对最终答案贡献一次。
