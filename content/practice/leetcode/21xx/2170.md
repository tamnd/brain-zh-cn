[LeetCode 问题 2170](https://leetcode.com/problems/minimum-operations-to-make-the-array-alternating/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、贪心、计数

 ## 解决方案

 ## 问题理解

 该问题需要转换给定的整数数组`nums`进入具有最少操作次数的**交替数组**。 如果偶数索引处的元素每两步重复一次，则数组是交替的（`nums[i] == nums[i-2]`为了`i >= 2`) 且奇数索引处的元素与其前一个元素不同 (`nums[i] != nums[i-1]`）。 实际上，这意味着理想情况下所有偶数索引位置应包含一个重复数字，所有奇数索引位置应包含另一个数字，并且这两个数字应该不同。 

输入是正整数列表，输出是单个整数，表示满足交替属性所需的最小更改数。 约束表明数组可以非常大（`n`最多 100,000），并且值也可以很大（`nums[i]`最多 100,000），因此任何解决方案都必须在时间和空间上有效扩展。 

重要的边缘情况包括长度为 1 的数组（默认情况下已交替）、所有元素都相同的数组、具有两个不同重复数字的数组以及多个数字在偶数和奇数位置竞争多数的数组。 尝试每种组合的幼稚方法会太慢。 

## 方法

 **暴力方法**将涉及尝试尝试每对可能的偶数和奇数位置的数字，计算每对所需的更改数量，并取最小值。 虽然正确，但这种方法的时间复杂度为$O(k^2 n)$， 在哪里$k$是唯一值的数量`nums`。 对于最坏的情况，即所有数字都是唯一的，这种方法太慢了。 

**最佳方法**利用了一个关键观察结果：偶数和奇数位置的最佳选择通常是这些位置上的**最频繁的数字**。 通过分别计算偶数和奇数索引的频率，我们可以重点关注每个索引的前一个或两个最常见的数字。 如果偶数和奇数位置出现次数最多的数字不同，我们可以直接使用它们。 如果它们相同，我们选择在其中一个位置使用第二频繁的数字来最小化总操作的组合。 这种方法是贪婪的并且有效，因为最大化已经具有期望值的位置数量可以最小化变化。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(k²n) | O(k²n) | O(k) | 尝试所有数字对的偶数和奇数位置 |
 | 最佳| O(n) | O(k) | 计算偶数和奇数位置的频率并选择前 1-2 个候选者 |

 ## 算法演练

 1.初始化两个字典，`even_count`和`odd_count`，分别存储偶数和奇数索引处数字的频率计数。 
2. 迭代数组。 对于索引处的每个元素`i`，增加计数`even_count`如果`i`是偶数，或者在`odd_count`如果`i`很奇怪。 
3. 提取偶数索引和奇数索引的前两个最频繁的数字。 如果只有一个唯一的数字，则第二个频率可以被视为带有占位符数字的 0。 
4. 如果偶数和奇数位置的最频繁的数字不同，则最少的运算是元素的数量减去这些最高频率的总和。 
5. 如果出现次数最多的数字相同，请考虑两种选择：使用顶部数字表示偶数，使用第二个数字表示奇数，或者使用顶部数字表示奇数，使用第二个数字表示偶数。 答案是最小化总操作的选项。 
6. 返回计算出的最小操作数。 

**为什么有效：** 通过最大化已包含偶数和奇数索引所选数字的位置数量，我们可以最小化所需的更改总数。 这种贪心选择是有效的，因为没有其他数字选择可以进一步减少运算次数。 

## Python 解决方案```python
from collections import Counter
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        if len(nums) == 1:
            return 0
        
        even_count = Counter(nums[i] for i in range(0, len(nums), 2))
        odd_count = Counter(nums[i] for i in range(1, len(nums), 2))
        
        # Get the most common numbers and their counts
        even_common = even_count.most_common(2)
        odd_common = odd_count.most_common(2)
        
        even1, even1_count = even_common[0] if even_common else (0, 0)
        even2, even2_count = even_common[1] if len(even_common) > 1 else (0, 0)
        odd1, odd1_count = odd_common[0] if odd_common else (0, 0)
        odd2, odd2_count = odd_common[1] if len(odd_common) > 1 else (0, 0)
        
        if even1 != odd1:
            return len(nums) - (even1_count + odd1_count)
        else:
            option1 = len(nums) - (even1_count + odd2_count)
            option2 = len(nums) - (even2_count + odd1_count)
            return min(option1, option2)
```该实现分别计算偶数和奇数位置上数字的频率，识别最重要的候选者，然后确定最少的操作。 特殊处理可确保如果顶级候选发生冲突，我们会评估次佳频率以找到最少的更改数量。 

## 解决方案```go
package main

func minimumOperations(nums []int) int {
    n := len(nums)
    if n == 1 {
        return 0
    }

    evenCount := map[int]int{}
    oddCount := map[int]int{}

    for i, num := range nums {
        if i%2 == 0 {
            evenCount[num]++
        } else {
            oddCount[num]++
        }
    }

    type pair struct {
        val, cnt int
    }
    getTopTwo := func(countMap map[int]int) [2]pair {
        top := [2]pair{{0, 0}, {0, 0}}
        for num, cnt := range countMap {
            if cnt > top[0].cnt {
                top[1] = top[0]
                top[0] = pair{num, cnt}
            } else if cnt > top[1].cnt {
                top[1] = pair{num, cnt}
            }
        }
        return top
    }

    evenTop := getTopTwo(evenCount)
    oddTop := getTopTwo(oddCount)

    if evenTop[0].val != oddTop[0].val {
        return n - (evenTop[0].cnt + oddTop[0].cnt)
    }

    option1 := n - (evenTop[0].cnt + oddTop[1].cnt)
    option2 := n - (evenTop[1].cnt + oddTop[0].cnt)
    return min(option1, option2)
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 版本遵循相同的逻辑，但使用映射而不是计数器，并手动提取偶数和奇数位置的前两个元素。 它还处理单元素数组的边缘情况。 

## 工作示例

 **示例1：**`nums = [3,1,3,2,4,3]`- 偶数指数：`[3,3,4]`→ 最常见：3（2次），其次：4（1次）
 - 奇数索引：`[1,2,3]`→ 最常见：1、2 还是 3？ 1 (1), 2 (1), 3 (1) → 选择 1，第二个：2

 由于顶部偶数和奇数不同 (3 != 1)，因此最少运算 =`6 - (2 + 1) = 3`。 

**示例2：**`nums = [1,2,2,2,2]`- 偶数指数：`[1,2,2]`→ 2 出现 2 次，1 出现 1 次
 - 奇数索引：`[2,2]`→ 2 出现 2 次，第二多 0

 上面的偶数和奇数都是2→冲突。 

选项1：偶数上(2) + 奇数下(0) → 5 - (2 + 0) = 3

 选项2：偶数第二（1）+奇数顶部（2）→5-（1+2）=2→最小值=2

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 计算一次中的频率并在 O(k) 中找到前两个频率，其中 k ≤ n |
 | 空间| O(k) | 存储偶数和奇数索引的频率计数 |

 计数和比较操作非常高效，因为唯一元素的数量`k`以 n 为界。
