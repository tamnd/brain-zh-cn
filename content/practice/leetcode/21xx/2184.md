[LeetCode 问题 2184](https://leetcode.com/problems/number-of-ways-to-build-sturdy-brick-wall/)

 **难度：** 🟡 中等
 **主题：** 数组、动态规划、位操作、位掩码

 ## 解决方案

 ## 问题理解

 该问题要求我们计算建造给定墙的方法数量`height`和`width`使用指定宽度的砖，使墙**坚固**。 如果没有两相邻行的砖块在水平方向上的同一位置相交（墙的末端除外），则墙是**坚固的**。 

输入是：

 -`height`- 墙的行数。 
-`width`- 每行的总水平长度。 
-`bricks`- 唯一整数数组，每个整数代表砖块宽度。 砖块的高度为 1，不能旋转，并且无限供应。 

输出是建造坚固墙的不同方法的总数，模$10^9 + 7$。 

约束表明最大`width`较小（≤10），砖块类型数量较小（≤10），高度可达 100。这提出了一种解决方案，可以预先计算可能的行并有效地将它们组合起来，而不是暴力破解所有墙配置。 

重要的边缘情况包括：

 -`width`小于所有砖类型 - 无法形成行。 
- 单排墙 - 无坚固性限制。 
- 完全适合宽度的砖块与不适合宽度的砖块。 

## 方法

 **暴力方法**将生成所有可能的长度行`width`使用可用的砖块，然后递归地堆叠行，同时检查每一步的坚固性条件。 这种方法是正确的，但速度呈指数级缓慢，特别是当`height`增加，因为每一行都可以与多个先前行递归地组合。 

**最佳方法**使用**位掩码和动态编程**。 关键的观察是，一排砖块之间**裂缝**的位置决定了两排砖是否可以牢固地堆放。 通过将裂纹编码为每个行配置的位掩码，我们可以预先计算哪些行是兼容的。 然后，我们在墙的高度上使用动态编程来有效地计算有效组合。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O((#row_configs)^高度) | O(#row_configs * 高度) | 递归堆叠所有行，每次检查坚固性 |
 | 最佳| O(#row_configs^2 * 高度) | O(#row_configs^2 + 高度) | 预计算行掩码和DP表，相乘兼容行|

 ## 算法演练

 1. **生成所有有效行**：递归创建总和为的所有砖块序列`width`。 对于每一行，记录**裂缝的位置**（砖块相交的位置，不包括末端）。 每个裂纹组都可以编码为位掩码以进行快速比较。 
2. **预先计算兼容性**：对于每对行，检查裂缝是否不重叠（末端除外）。 将兼容的行存储在字典或邻接列表中。 
3. **动态编程初始化**：创建DP数组`dp[r]`代表建造一堵高墙的方法数量`h`以行配置结束`r`。 初始化为`dp[row] = 1`对于所有行（第一行）。 
4. **逐行建造墙**：每行从 2 到`height`，通过对每个当前行的所有兼容的先前行求和来更新新的 DP 数组。 
5. **对结果求和**：到达顶行后，对所有行配置的计数求和。 返回模数$10^9 + 7$。 

**为什么起作用**：该算法保证了正确性，因为它枚举了所有可能的行序列并使用 DP 传播有效组合，仅在满足坚固性约束时才堆叠行。 

## Python 解决方案```python
from typing import List

class Solution:
    MOD = 10**9 + 7
    
    def buildWall(self, height: int, width: int, bricks: List[int]) -> int:
        # Step 1: Generate all valid row configurations as crack bitmasks
        row_masks = []

        def dfs(pos, mask):
            if pos == width:
                row_masks.append(mask)
                return
            for b in bricks:
                if pos + b <= width:
                    new_mask = mask
                    if pos + b < width:  # add crack if not at the end
                        new_mask |= 1 << (pos + b - 1)
                    dfs(pos + b, new_mask)
        
        dfs(0, 0)
        
        # Step 2: Precompute compatible rows
        compatible = {mask: [] for mask in row_masks}
        for mask1 in row_masks:
            for mask2 in row_masks:
                if mask1 & mask2 == 0:  # no overlapping cracks
                    compatible[mask1].append(mask2)
        
        # Step 3: Dynamic programming across height
        dp = {mask: 1 for mask in row_masks}  # first row
        for _ in range(1, height):
            new_dp = {mask: 0 for mask in row_masks}
            for mask in row_masks:
                for prev in compatible[mask]:
                    new_dp[mask] = (new_dp[mask] + dp[prev]) % self.MOD
            dp = new_dp
        
        # Step 4: Sum all configurations
        return sum(dp.values()) % self.MOD
```该代码首先递归枚举所有有效的行配置。 每行的裂纹都编码在位掩码中，这允许使用按位 AND 进行恒定时间兼容性检查。 然后，动态规划逐行聚合建造墙的方法数量。 在每一步应用模数以防止溢出。 

## 解决方案```go
func buildWall(height int, width int, bricks []int) int {
    const MOD = 1_000_000_007
    type void struct{}
    var masks []int

    var dfs func(pos int, mask int)
    dfs = func(pos int, mask int) {
        if pos == width {
            masks = append(masks, mask)
            return
        }
        for _, b := range bricks {
            if pos+b <= width {
                newMask := mask
                if pos+b < width {
                    newMask |= 1 << (pos + b - 1)
                }
                dfs(pos+b, newMask)
            }
        }
    }
    dfs(0, 0)

    // Precompute compatibility
    compatible := make(map[int][]int)
    for _, m1 := range masks {
        compatible[m1] = []int{}
        for _, m2 := range masks {
            if m1&m2 == 0 {
                compatible[m1] = append(compatible[m1], m2)
            }
        }
    }

    // DP
    dp := make(map[int]int)
    for _, m := range masks {
        dp[m] = 1
    }

    for h := 1; h < height; h++ {
        newDP := make(map[int]int)
        for _, m := range masks {
            sum := 0
            for _, prev := range compatible[m] {
                sum = (sum + dp[prev]) % MOD
            }
            newDP[m] = sum
        }
        dp = newDP
    }

    res := 0
    for _, val := range dp {
        res = (res + val) % MOD
    }
    return res
}
```Go 处理映射和按位运算的方式与 Python 类似。 DFS 使用递归来生成行掩码。 兼容性存储在映射中，DP 被实现为聚合行计数的映射。 聚合期间应用模数。 

## 工作示例

 **示例1：**`height = 2, width = 3, bricks = [1,2]`- 可能的行：`[1,1,1]`,`[1,2]`,`[2,1]`- 相应的裂纹掩模：`0b011 (3)`,`0b01 (1)`,`0b10 (2)`- 兼容的堆叠行：

 -`0b01`兼容于`0b10`-`0b10`兼容于`0b01`-`0b11`不兼容
 - DP 步骤 1：`{1:1, 2:1, 3:1}`- DP 步骤 2：使用兼容更新：`{1:1, 2:1, 3:0}`- 总和 = 2

 **示例2：**`height = 1, width = 1, bricks = [5]`- 无法形成行 → 0 种方式

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(H * R^2) | O(H * R^2) | H = 高度，R = 有效行掩码的数量。 预计算兼容行和 DP 乘法 |
 | 空间| O(R^2 + R) | O(R^2 + R) | 存储兼容行 (O(R^2)) 和 DP 数组 (O(R)) |

 由于宽度≤10且砖块≤10，行配置R的数量较小。 这样就保证了可行性。
