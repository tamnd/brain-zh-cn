[LeetCode 2118 题](https://leetcode.com/problems/build-the-equation/)

 **难度：** 🔴难
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 该问题要求我们从名为的数据库表构造一个多项式方程`Terms`。 表中的每一行代表方程中的一个项，其中`power`是的指数`X`和`factor`是系数。 目标是输出表示方程的单个字符串，其中所有项按其幂的降序连接，并且右侧始终为零。 

输出格式非常严格：每个术语必须以符号 (`+`或者`-`)，然后是因子的绝对值，然后`X`如果幂大于 1，则求幂。如果幂为 1，则仅`X`出现时不带指数。 如果幂为0，则只显示数字，不显示`X`。 这需要仔细处理字符串格式和排序。 

输入保证`factor`是非零并且`power`是唯一的，这简化了问题。 重要的边缘情况包括负系数、0 或 1 的幂以及只有一项的表格。 

后续，哪里`power`可能不是唯一的，需要在构造方程串之前首先对相同幂的系数求和。 

## 方法

 暴力方法很简单：从表中读取所有术语，按降序对它们进行排序，然后通过迭代每一行来手动构建字符串。 每个术语都需要根据其功能进行条件格式设置。 这是可行的，因为数据集很小（`power`≤ 100），但如果需要额外的操作（例如对重复幂求和），它就不能很好地扩展。 蛮力方法是正确的，但机械重复。 

最佳方法利用 SQL 的字符串函数以及`ORDER BY`子句按降序对权力进行排序。 对于每个术语，我们根据使用的功率有条件地格式化字符串`CASE`声明。 这避免了应用程序代码中的后处理，并确保直接在数据库查询中构建字符串。 它更优雅，并且随着术语数量的增加而更好地扩展。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 在应用程序中进行排序并手动设置每个术语的格式 |
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 在 SQL 中排序并使用聚合和构建字符串`CASE`|

 ## 算法演练

 1. 首先读取所有行`Terms`桌子。 
2. 按降序对行进行排序`power`。 
3. 对于每个术语，根据以下内容确定字符串表示形式`power`：

- 如果`power = 0`, 附加`+factor`或者`-factor`。 
- 如果`power = 1`, 附加`+factorX`或者`-factorX`。 
- 否则，附加`+factorX^power`或者`-factorX^power`。 
4. 写项时使用因子的绝对值，但在原始因子的基础上加上符号。 
5. 将所有格式化术语连接成一个字符串。 
6. 追加`=0`最后完成方程。 
7. 将结果字符串作为名为的单列返回`equation`。 

**为什么有效**：通过按降序对幂进行排序并正确格式化每一项，我们可以保持多项式的正确顺序和数学表示。 使用带有符号的因子的绝对值可确保正确表示正项和负项。 

## Python 解决方案```python
import sqlite3
from typing import List, Tuple

def buildEquation(terms: List[Tuple[int, int]]) -> str:
    # Sort terms in descending order of power
    terms.sort(key=lambda x: -x[0])
    
    equation_parts = []
    for power, factor in terms:
        sign = '+' if factor > 0 else '-'
        abs_factor = abs(factor)
        
        if power == 0:
            term_str = f"{sign}{abs_factor}"
        elif power == 1:
            term_str = f"{sign}{abs_factor}X"
        else:
            term_str = f"{sign}{abs_factor}X^{power}"
        
        equation_parts.append(term_str)
    
    return ''.join(equation_parts) + '=0'
```该代码首先按幂的降序对元组列表进行排序。 然后，对于每一项，它根据幂构建字符串。 符号由因子确定，并且在字符串中使用绝对值。 最后，将所有字符串连接起来`=0`附加以形成完整的方程。 

## 解决方案```go
package main

import (
    "fmt"
    "sort"
    "strconv"
)

type Term struct {
    Power  int
    Factor int
}

func buildEquation(terms []Term) string {
    sort.Slice(terms, func(i, j int) bool {
        return terms[i].Power > terms[j].Power
    })
    
    equation := ""
    for _, term := range terms {
        sign := "+"
        if term.Factor < 0 {
            sign = "-"
        }
        absFactor := term.Factor
        if absFactor < 0 {
            absFactor = -absFactor
        }
        
        var part string
        if term.Power == 0 {
            part = fmt.Sprintf("%s%d", sign, absFactor)
        } else if term.Power == 1 {
            part = fmt.Sprintf("%s%dX", sign, absFactor)
        } else {
            part = fmt.Sprintf("%s%dX^%d", sign, absFactor, term.Power)
        }
        equation += part
    }
    equation += "=0"
    return equation
}
```Go 实现镜像 Python。 我们按降幂对项切片进行排序，确定符号和绝对值，然后使用`fmt.Sprintf`。 最后，我们连接所有部分并附加`=0`。

 ## 边缘情况

 一种边缘情况是多项式只有一项。 该算法正确地添加了符号和`=0`无论该术语的力量如何。 另一个边缘情况是当幂为 0 或 1 时，这需要条件格式化以避免添加`X`或者`^1`错误地。 第三种边缘情况是负系数，必须预先考虑`-`并使用术语字符串中的绝对值。 该算法通过检查符号并使用来一致地处理这个问题`abs()`或等效逻辑。
