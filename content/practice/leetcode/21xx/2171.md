 ## 解决方案

 ## 问题理解

 该问题要求我们从袋子中取出豆子，使所有非空袋子中的豆子数量相同，同时最大限度地减少取出的豆子总数。 输入数组中的每个元素`beans`代表一个装有正数豆子的袋子。 我们可以从袋子中取出任意数量的豆子，包括所有豆子，但一旦取出豆子，就不能将其添加到另一个袋子中。 

目标是返回移除的豆子的最小总数，以便所有剩余的非空袋子具有相同数量的豆子。 限制因素`1 <= beans.length <= 10^5`和`1 <= beans[i] <= 10^5`表明我们需要一个线性或更好的解决方案，因为简单的方法会太慢。 

重要的边缘情况包括所有元素都相同的数组、只有一袋的数组、包含许多小元素和一个大元素的数组，或者已经按升序或降序排序的数组。 该问题保证所有数字都是正数，因此我们最初不必处理零。 

## 方法

 蛮力方法是尝试使每个不同的豆子计数为所有非空袋的目标数量。 对于每个目标值`x`，我们计算要移除的豆子总数，以使所有非空袋等于`x`。 这可以工作，但效率很低，因为对于每个目标，我们必须迭代整个数组，如果所有 bean 都不同，则在最坏的情况下会导致 O(n^2)。 

最佳解决方案的关键观察是，在对数组进行排序后，如果我们在位置选择一个包`i`在排序后的数组中作为所有非空包的目标，我们只需要删除之前包中的所有bean`i`并减少所有行李`i`继续匹配`beans[i]`。 使用前缀和或运行总计使我们能够有效地计算总移除量，从而将排序的复杂性降低到 O(n log n)。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 尝试每个可能的目标值并计算总去除量 |
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 对数组进行排序并使用运行和计算移除 |

 ## 算法演练

 1. 对输入数组进行排序`beans`按升序排列。 排序确保较小的值排在前面，这使得我们可以轻松计算需要从较小的袋子中取出的豆子。 
2. 计算所有bean 的总和。 这将有助于在选择目标袋值时计算移除的豆子数量。 
3. 初始化变量`min_removal`到无穷大。 这将存储在所有可能的目标中删除的最小数量的 Bean。 
4. 迭代每个索引`i`在已排序的数组中。 考虑`beans[i]`作为所有非空袋子的目标值。 
5. 对于每个目标`beans[i]`，使用以下公式计算要移除的豆子总数：`total_sum - (beans[i] * (n - i))`。 这里，`(n - i)`是保持非空的袋子数量，我们之前从袋子中取出所有豆子`i`。 
6. 更新`min_removal`如果当前移除计数较小。 
7. 返回`min_removal`检查完所有可能的目标后。 

**为什么有效：** 排序确保我们首先考虑移除最小的袋子，并且使用总和使我们能够有效地计算必须从所有其他袋子中移除多少豆才能匹配给定的目标。 这保证了我们找到最小的移除量。 

## Python 解决方案```python
from typing import List

class Solution:
    def minimumRemoval(self, beans: List[int]) -> int:
        beans.sort()
        total_sum = sum(beans)
        n = len(beans)
        min_removal = float('inf')
        
        for i, b in enumerate(beans):
            # Total removal = sum of beans removed from smaller bags + beans removed to match target in bigger bags
            removal = total_sum - b * (n - i)
            min_removal = min(min_removal, removal)
        
        return min_removal
```Python 实现首先对数组进行排序，计算总和，然后迭代每个潜在目标。 对于每个目标，它计算如果所有剩余的非空袋减少到该目标值，将删除多少豆子。 返回所有目标的最小值。 

## 解决方案```go
import "sort"

func minimumRemoval(beans []int) int64 {
    sort.Ints(beans)
    var total int64
    for _, b := range beans {
        total += int64(b)
    }

    var minRemoval int64 = total
    n := len(beans)
    for i, b := range beans {
        removal := total - int64(b)*(int64(n-i))
        if removal < minRemoval {
            minRemoval = removal
        }
    }
    return minRemoval
}
```Go 解决方案镜像了 Python 版本。 我们使用`int64`防止因大数相加而导致溢出。 排序是通过内置的`sort.Ints`。 总和计算如下`int64`，最小去除量也以类似方式更新。 

## 工作示例

 **示例1：**`beans = [4,1,6,5]`种类：`[1,4,5,6]`，总和 = 16

 | 我| 豆类[i] | 剩余行李 | 移除 = 总计 - beans[i]*(n-i) |
 | --- | --- | --- | --- |
 | 0 | 1 | [1,4,5,6] | 16 - 1*4 = 12 | 16 - 1*4 = 12 |
 | 1 | 4 | [4,5,6]| 16 - 4*3 = 4 |
 | 2 | 5 | [5,6]| 16 - 5*2 = 6 | 16 - 5*2 = 6
 | 3 | 6 | [6] | 16 - 6*1 = 10 | 16 - 6*1 = 10 |

 最小去除量 = 4

 **示例2：**`beans = [2,10,3,2]`种类：`[2,2,3,10]`，总和 = 17

 | 我| 豆类[i] | 剩余行李 | 移除 = 总计 - beans[i]*(n-i) |
 | --- | --- | --- | --- |
 | 0 | 2 | [2,2,3,10] | 17 - 2*4 = 9 | 17 - 2*4 = 9
 | 1 | 2 | [2,3,10] | 17 - 2*3 = 11 | 17 - 2*3 = 11 |
 | 2 | 3 | [3,10]| 17 - 3*2 = 11 | 17 - 3*2 = 11 |
 | 3 | 10 | 10 [10]| 17 - 10*1 = 7 | 17 - 10*1 = 7 |

 最小去除量 = 7

 ## 边缘情况

 一个重要的边缘情况是长度为 1 的数组。该解决方案必须正确处理此问题并返回 0，因为不需要删除。 另一个边缘情况是所有元素都相等； 再次强调，去除量必须为零。 具有一个非常大的元素和许多小元素的数组很棘手，因为最小删除可能涉及删除所有较小的元素，而不是减少大的元素。 按所述排序和计算移除量可确保正确处理所有这些情况。
