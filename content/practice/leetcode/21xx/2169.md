[LeetCode 第 2169 题](https://leetcode.com/problems/count-operations-to-obtain-zero/)

 **难度：** 🟢简单
 **主题：** 数学、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们计算减少两个非负整数中的任何一个所需的操作数`num1`或者`num2`为零。 **运算**被定义为从较大的数字中减去较小的数字（或者如果它们相等则减去其中一个）。 我们继续执行操作，直到至少有一个数字变为零。 

输入由两个整数组成，均限制在 0 到 105 之间（含 0 和 105）。 输出是一个整数，表示所需操作的总数。 

重要的观察包括处理其中一个数字最初为零的情况，这意味着需要零次操作，以及当数字相等时，这将在单个操作中立即将一减少到零。 

要考虑的边缘情况是任一数字为零的输入、数字相等的输入以及一个数字远大于另一个数字的输入。 

## 方法

 最直接的方法是**暴力模拟**。 在这里，我们反复比较`num1`和`num2`，按照规则进行减法运算，并递增计数器，直到任一数字变为零。 这种方法简单且正确，但如果数字很大，则可能会很慢，因为每次减法仅将一个数字减少少量，可能需要多次迭代。 

**最佳方法**利用了这样的观察结果：反复从较大的数字中减去较小的数字相当于执行整数除法。 具体来说，对于两个数字`a`和`b`在哪里`a >= b`，需要减少的减法次数`a`以下`b`是`a // b`。 完成这一步后，我们只需要继续`a % b`和`b`。 重复此操作模仿了用于计算最大公约数 (GCD) 的欧几里得算法。 这显着减少了迭代次数，因为每一步都会将较大的数字减少较小数字的倍数。

 | --- | --- | --- | --- |
 | 蛮力 | O(最大(num1, num2)) | O(1) | O(1) | 一一模拟操作 |
 | 最佳| O(log(max(num1, num2))) | O(log(max(num1, num2))) | O(1) | O(1) | 像欧几里德算法一样使用除法和取模 |

 ## 算法演练

 1.初始化一个计数器`operations`为零。 这将跟踪执行的操作数量。 
2. 循环 while 两者`num1`和`num2`均非零。 
3. 在每次迭代中，识别较大和较小的数字。 
4. 将较大的数除以较小的数所得的商相加 (`num1 // num2`或者`num2 // num1`） 到`operations`。 这计算了一次可以发生多少次减法。 
5. 将较大的数更新为其除法后的余数（`num1 % num2`或者`num2 % num1`），它模仿在一个步骤中执行多个减法运算。 
6. 继续，直到任一数字变为零。 
7. 返回`operations`。 

**为什么有效：** 该算法之所以有效，是因为反复从较大的数字中减去较小的数字相当于执行除法并取余数。 所需减法的次数正是商，余数在后续迭代中成为新的较大数。 与暴力方法相比，这成倍减少了步骤数，同时保持了正确性。 

## Python 解决方案```python
class Solution:
    def countOperations(self, num1: int, num2: int) -> int:
        operations = 0
        while num1 != 0 and num2 != 0:
            if num1 >= num2:
                operations += num1 // num2
                num1 %= num2
            else:
                operations += num2 // num1
                num2 %= num1
        return operations
```在这个 Python 实现中，我们维护了一个运行的操作总数。 我们使用一个`while`循环继续处理，直到一个数字达到零。 在循环中，我们总是从较大的数字中减去较小的数字，使用整数除法一次计算多个减法。 模运算可以有效地更新较大的数字。 这种方法可以处理边缘情况，例如一个数字为零或两个数字相等。 

## 解决方案```go
func countOperations(num1 int, num2 int) int {
    operations := 0
    for num1 != 0 && num2 != 0 {
        if num1 >= num2 {
            operations += num1 / num2
            num1 %= num2
        } else {
            operations += num2 / num1
            num2 %= num1
        }
    }
    return operations
}
```Go 实现反映了 Python 方法。 整数除法`/`和模`%`用于一次计算多个操作并更新较大的数字。 边缘情况（例如零和相等的数字）的处理方式相同。

 ## 边缘情况

 第一个边缘情况是当`num1`或者`num2`最初为零。 该算法处理这个问题是因为循环条件`num1 != 0 and num2 != 0`立即失败，按预期返回零操作。 

第二种边缘情况发生在`num1`和`num2`是平等的。 在这种情况下，只需要一次操作，因为`num1 - num2`或者`num2 - num1`立即将一个数减为零。 我们基于划分的方法正确地添加了`1`到操作计数并终止。 

第三种边缘情况是一个数字明显大于另一个数字。 简单的实现可能会一次减去较小的数字一，从而需要多次迭代。 最优算法通过使用整数除法一步计算多个减法来有效地处理这一问题，即使在上限的情况下也能确保性能`105`。
