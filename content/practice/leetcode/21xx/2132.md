[LeetCode 问题 2132](https://leetcode.com/problems/stamping-the-grid/)

 **难度：** 🔴难
 **主题：** 数组、贪婪、矩阵、前缀和

 ## 解决方案

 ## 问题理解

 在这个问题中，我们给出一个二元矩阵，称为`grid`。 每个单元格包含：

 -`0`，表示单元格为空
 -`1`，表示单元格被阻塞或被占用

 我们还得到了一个矩形印章，其尺寸为：

 -`stampHeight`-`stampWidth`目标是确定是否可以将任意数量的这些图章放置到网格上，以便每个空单元格都被至少一个图章覆盖。 

放置规则非常重要：

 - 印章只能覆盖空单元格
 - 印记不能与任何占用的单元格重叠
 - 邮票可能会相互重叠
 - 邮票无法旋转
 - 每个印章必须完全留在网格内

 问题只问是否存在有效的安排。 我们不需要退回邮票的实际位置。 

主要挑战来自于限制：

 -`m * n <= 2 * 10^5`这告诉我们网格在一维上可能很大，因此任何比单元数量大致线性或近线性更差的算法都可能会超时。 

反复检查每个空单元格的每个可能的标记的简单方法将变得过于昂贵。 

一些边缘情况很重要：

 - 网格可能已经被完全占用，在这种情况下，答案会自动进行`true`- 印章可能大于网格尺寸
 - 一些空单元格可能会被隔离，这样任何邮票都无法覆盖它们
 - 允许重叠的邮票，这显着改变了策略
 - 我们只需要覆盖范围，而不是最少数量的邮票

 关键的观察是我们不需要贪婪地模拟邮票放置。 相反，我们只需要确定每个空单元格是否属于至少一个有效的图章矩形。 

## 方法

 ### 蛮力方法

 一种简单的方法是尝试每个可能的左上角位置作为图章。 

对于每个位置：

 1. 检查整个图章矩形是否位于网格内
 2. 验证每个被覆盖的单元格都是空的
 3. 如果有效，则将该矩形中的所有单元格标记为已覆盖

 处理完所有放置后，我们再次扫描网格并验证是否每个空单元格都被覆盖。 

这种方法是正确的，因为它明确地测试了所有合法的印章放置。 

然而，性能太慢了。 

假设：

 - 有`m * n`可能的职位
 - 每个印章验证检查`stampHeight * stampWidth`细胞

 复杂度变为：$$O(m \times n \times stampHeight \times stampWidth)$$这对于约束来说太大了。 

### 关键见解

 强力方法的昂贵部分是重复检查矩形是否包含任何已占用的单元格。 

这立即建议使用二维前缀和。 

通过前缀和矩阵，我们可以在恒定时间内确定矩形是否包含任何被占用的单元格。 

那么我们还面临另一个问题：

 - 一个空单元格可能被许多可能的邮票覆盖
 - 明确标记每个印章的所有覆盖单元仍然可能很昂贵

 为了有效地解决这个问题，我们使用第二种技术：

 - 二维差分数组

 我们不是单独更新邮票矩形内的每个单元格，而是以恒定的时间记录矩形更新。 随后，我们使用前缀和恢复最终的覆盖率计数。 

这种组合提供了有效的近线性解决方案。 

## 方法比较

 | --- | --- | --- | --- |
 | 蛮力 | O(m × n × 印章高度 × 印章宽度) | O(m × n) | 逐个单元地明确检查每个印章区域 |
 | 最佳| O(m × n) | O(m × n) | 使用前缀和和二维差分数组 |

 ## 算法演练

 ### 第 1 步：为占用的单元构建 2D 前缀和

 我们创建一个前缀和矩阵，其中：$$prefix[r][c]$$存储矩形中占用的单元格数量`(0,0)`到`(r-1,c-1)`。 

这使我们能够在恒定时间内查询任何矩形总和。 

如果矩形和为零，则整个区域是空的并且可以将印记放置在那里。 

矩形查询公式为：$$sum = prefix[r2][c2] - prefix[r1][c2] - prefix[r2][c1] + prefix[r1][c1]$$### 第 2 步：枚举所有有效的图章放置位置

 我们迭代每个可能的左上角`(r,c)`。 

右下角变成：$$(r + stampHeight - 1,\ c + stampWidth - 1)$$如果该矩形位于网格内且不包含已占用的单元格，则图章放置有效。 

### 步骤 3：使用差异数组记录覆盖范围

 我们使用二维差分矩阵，而不是直接标记每个被覆盖的单元。 

对于有效的矩形：

 - 添加`+1`at the top-left
 - 减去`1`在矩形边界之外

 This lets us apply rectangle updates in constant time.

 具体来说：```
diff[r1][c1] += 1
diff[r2+1][c1] -= 1
diff[r1][c2+1] -= 1
diff[r2+1][c2+1] += 1
```### 步骤 4：恢复最终覆盖计数

 我们计算差分矩阵的前缀和。 

每个单元格的结果值告诉我们有多少邮票覆盖了该位置。 

### Step 5: Verify Every Empty Cell is Covered

 最后，我们扫描网格：

 - If a cell is occupied, ignore it
 - 如果单元格为空但覆盖计数为零，则返回`false`如果每个空单元格都被覆盖，则返回`true`。 

## 为什么它有效

 该算法之所以有效，是因为它考虑了所有可能的有效印章放置。 

任何可以被至少一个合法标记覆盖的空单元将在差异阵列重建中得到正覆盖。 

如果一个空单元格最终未被覆盖，那么任何合法的邮票放置都无法覆盖它，所以答案一定是`false`。 

前缀和保证恒定时间矩形验证，而差异数组保证恒定时间矩形更新。 它们共同将问题简化为线性复杂度。 

## Python 解决方案```python
from typing import List

class Solution:
    def possibleToStamp(
        self,
        grid: List[List[int]],
        stampHeight: int,
        stampWidth: int
    ) -> bool:

        rows = len(grid)
        cols = len(grid[0])

        # Build prefix sum of occupied cells
        prefix = [[0] * (cols + 1) for _ in range(rows + 1)]

        for r in range(rows):
            row_sum = 0
            for c in range(cols):
                row_sum += grid[r][c]
                prefix[r + 1][c + 1] = prefix[r][c + 1] + row_sum

        def rectangle_sum(r1: int, c1: int, r2: int, c2: int) -> int:
            return (
                prefix[r2 + 1][c2 + 1]
                - prefix[r1][c2 + 1]
                - prefix[r2 + 1][c1]
                + prefix[r1][c1]
            )

        # Difference array for coverage
        diff = [[0] * (cols + 1) for _ in range(rows + 1)]

        # Try every possible stamp placement
        for r in range(rows - stampHeight + 1):
            for c in range(cols - stampWidth + 1):

                r2 = r + stampHeight - 1
                c2 = c + stampWidth - 1

                # Entire rectangle must be empty
                if rectangle_sum(r, c, r2, c2) == 0:
                    diff[r][c] += 1
                    diff[r2 + 1][c] -= 1
                    diff[r][c2 + 1] -= 1
                    diff[r2 + 1][c2 + 1] += 1

        # Recover coverage counts
        coverage = [[0] * cols for _ in range(rows)]

        for r in range(rows):
            for c in range(cols):

                top = coverage[r - 1][c] if r > 0 else 0
                left = coverage[r][c - 1] if c > 0 else 0
                diagonal = coverage[r - 1][c - 1] if r > 0 and c > 0 else 0

                coverage[r][c] = (
                    diff[r][c]
                    + top
                    + left
                    - diagonal
                )

                # Empty cell must be covered
                if grid[r][c] == 0 and coverage[r][c] <= 0:
                    return False

        return True
```实现首先构建一个二维前缀和矩阵。 这允许辅助函数`rectangle_sum()`在恒定时间内确定邮票矩形是否包含任何被占用的单元格。 

接下来，算法迭代每个可能的标记位置。 每当找到一个完全空的矩形时，该矩形就会被添加到差异数组中。 

差异数组紧凑地存储矩形更新。 我们没有单独标记每个被覆盖的单元，而是只修改四个边界位置。 

处理完所有有效标记后，代码使用差异数组上的前缀和来重建最终的覆盖矩阵。 

在重建期间，立即检查每个空单元。 如果任何空单元格的覆盖范围为零，则算法返回`False`。 

否则，每个空单元格都可以被至少一个有效的印章位置覆盖，所以答案是`True`。 

## 解决方案```go
package main

func possibleToStamp(grid [][]int, stampHeight int, stampWidth int) bool {
	rows := len(grid)
	cols := len(grid[0])

	// Prefix sum of occupied cells
	prefix := make([][]int, rows+1)
	for i := range prefix {
		prefix[i] = make([]int, cols+1)
	}

	for r := 0; r < rows; r++ {
		rowSum := 0
		for c := 0; c < cols; c++ {
			rowSum += grid[r][c]
			prefix[r+1][c+1] = prefix[r][c+1] + rowSum
		}
	}

	rectSum := func(r1, c1, r2, c2 int) int {
		return prefix[r2+1][c2+1] -
			prefix[r1][c2+1] -
			prefix[r2+1][c1] +
			prefix[r1][c1]
	}

	// Difference array
	diff := make([][]int, rows+1)
	for i := range diff {
		diff[i] = make([]int, cols+1)
	}

	// Find valid stamp placements
	for r := 0; r <= rows-stampHeight; r++ {
		for c := 0; c <= cols-stampWidth; c++ {

			r2 := r + stampHeight - 1
			c2 := c + stampWidth - 1

			if rectSum(r, c, r2, c2) == 0 {
				diff[r][c]++
				diff[r2+1][c]--
				diff[r][c2+1]--
				diff[r2+1][c2+1]++
			}
		}
	}

	// Recover coverage counts
	coverage := make([][]int, rows)
	for i := range coverage {
		coverage[i] = make([]int, cols)
	}

	for r := 0; r < rows; r++ {
		for c := 0; c < cols; c++ {

			top := 0
			left := 0
			diag := 0

			if r > 0 {
				top = coverage[r-1][c]
			}

			if c > 0 {
				left = coverage[r][c-1]
			}

			if r > 0 && c > 0 {
				diag = coverage[r-1][c-1]
			}

			coverage[r][c] = diff[r][c] + top + left - diag

			if grid[r][c] == 0 && coverage[r][c] <= 0 {
				return false
			}
		}
	}

	return true
}

主要区别是：

 - Go 要求显式分配所有 2D 切片

 - 边界条件是手动处理的，因为 Go 不支持负索引
 - 整数溢出不是问题，因为最大更新次数受以下限制`m * n`## 工作示例

 ## 边缘情况

 ### 邮票比网格大

 如果其中之一`stampHeight > rows`或者`stampWidth > cols`，那么就无法放置任何印记。 

这很容易处理不当，因为放置循环可能永远不会执行。 实现自然地处理了这个问题。 如果不存在有效的展示位置，则覆盖矩阵在任何地方都保持为零。 任何空单元格都会立即导致算法返回`False`。 

### 完全占用的网格

 一个网格仅包含`1`s 根本不需要邮票。 

一些不正确的实现尝试强制至少放置一个标记。 我们的实现在验证过程中正确地忽略了占用的单元格。 由于没有空单元格可供检查，算法返回`True`。 

### 隔离的空单元格

 空单元格可能存在，但仍然无法覆盖，因为每个潜在的标记矩形与占用的单元格相交或超出网格边界。 

这是问题中最重要的逻辑边缘情况。 该算法通过在处理所有有效的邮票放置后检查实际覆盖率计数来处理它。 如果空单元格从未收到正面覆盖，则答案是正确的`False`。 

### 重叠的邮票覆盖范围

 多个邮票可能会严重重叠。 

试图避免重叠的贪婪策略可能会错误地失败。 我们的方法并不尝试建设性的安置。 相反，它只是记录每个有效的图章矩形。 由于允许重叠，这保证了不会错过任何有效的覆盖机会。
