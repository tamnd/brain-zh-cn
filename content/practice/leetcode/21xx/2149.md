[LeetCode 问题 2149](https://leetcode.com/problems/rearrange-array-elements-by-sign/)

 **难度：** 🟡 中等
 **主题：** 数组、两个指针、模拟

 ## 解决方案

 ## 问题理解

 该问题要求我们重新排列给定的整数数组`nums`使得正数和负数交替，从正数开始。 该数组具有**偶数长度**并包含**相同数量**的正整数和负整数。 除了符号交替外，正数之间和负数之间的**相对顺序**必须保持与原始数组中相同。 

输入`nums`表示初始整数序列，可以以任何顺序交织或聚集。 输出是满足所有条件的重新排列的数组：它交替符号，保留相对顺序，并以正整数开头。 

约束告诉我们数组可以相当大，最多$2 \times 10^5$元素，但保证相等的正数和负数以及甚至长度简化了处理边缘情况。 我们不需要就地重新排列，因此允许额外的空间。 

重要的边缘情况包括已经满足条件的数组、所有正数都聚集在开头的数组或负数聚集的数组以及最小长度（2 个元素）的数组。 

## 方法

 **暴力方法**会尝试从数组中一个接一个地挑选元素以形成交替序列，在每一步检查符号并扫描剩余的数组。 虽然正确，但由于重复扫描下一个正元素或负元素，效率会很低。 其时间复杂度为$O(n^2)$。 

**最佳方法**利用相同数量的正数和负数。 我们可以**将数组**分成两个列表：一个用于正数，一个用于负数。 然后，我们通过**交替这两个列表中的元素**来构造结果数组，从正数开始。 这保留了相对顺序并保证单次传递中符号交替。 这种方法运行在$O(n)$时间和用途$O(n)$额外的空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复扫描下一个正/负元素 |
 | 最佳 | O(n) | O(n) | 将数组拆分为正数/负数，然后交替 |

 ## 算法演练

 1.初始化两个空列表：`positives`和`negatives`。 
2. 迭代`nums`。 对于每个数字，将其附加到`positives`如果它是积极的，或者`negatives`如果是负数。 此步骤保留每个符号组内的相对顺序。 
3.初始化一个空列表`result`和指数`p_idx = 0`和`n_idx = 0`跟踪位置`positives`和`negatives`。 
4. 迭代输出数组的索引：

 1. 如果当前索引是偶数，则附加下一个正数`positives[p_idx]`和增量`p_idx`。 
2. 如果当前索引为奇数，则附加下一个负数`negatives[n_idx]`和增量`n_idx`。 
5. 返回`result`填充所有位置后的数组。 

**为什么有效：** 该算法按设计交替元素，从正数开始。 拆分保留原始相对顺序。 因为数组具有相同数量的正数和负数，所以在填充结果数组时我们总是会精确地耗尽两个列表。 

## Python 解决方案```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        positives = []
        negatives = []

        for num in nums:
            if num > 0:
                positives.append(num)
            else:
                negatives.append(num)
        
        result = []
        p_idx = 0
        n_idx = 0

        for i in range(len(nums)):
            if i % 2 == 0:
                result.append(positives[p_idx])
                p_idx += 1
            else:
                result.append(negatives[n_idx])
                n_idx += 1

        return result
```该代码首先将输入数组分为正列表和负列表，同时保留它们的顺序。 然后，它通过交替元素构造结果数组，从正数开始。 使用索引指针避免了重复扫描，使得时间和空间呈线性。 

## 解决方案```go
func rearrangeArray(nums []int) []int {
    positives := make([]int, 0, len(nums)/2)
    negatives := make([]int, 0, len(nums)/2)

    for _, num := range nums {
        if num > 0 {
            positives = append(positives, num)
        } else {
            negatives = append(negatives, num)
        }
    }

    result := make([]int, len(nums))
    pIdx, nIdx := 0, 0

    for i := 0; i < len(nums); i++ {
        if i%2 == 0 {
            result[i] = positives[pIdx]
            pIdx++
        } else {
            result[i] = negatives[nIdx]
            nIdx++
        }
    }

    return result
}
```在Go中，切片用于存储正数和负数。 容量是预先分配的以避免重复调整大小。 交替结构反映了 Python 方法。 

## 工作示例

 **示例1：**`nums = [3,1,-2,-5,2,-4]`1. 分成`positives = [3,1,2]`,`negatives = [-2,-5,-4]`。 
2. 交替构建结果：

 - 索引 0：正 → 3
 - 索引 1：负 → -2
 - 索引 2：正 → 1
 - 指数 3：负 → -5
 - 指数 4：正 → 2
 - 索引 5：负 → -4
 3、结果：`[3,-2,1,-5,2,-4]`。 

**示例2：**`nums = [-1,1]`1.`positives = [1]`,`negatives = [-1]`2. 交替：`[1,-1]`## 复杂度分析

 | --- | --- | --- |
 | 时间 | O(n) | 单遍分割数组和单遍合并 |

 线性时间得到保证，因为每个元素仅被触摸两次。 空间是线性的，因为我们将一半的元素存储在两个单独的列表中。

 ## 边缘情况

 **最小数组：** 只有两个元素，算法必须在需要时简单地交换。 我们的方法可以正确处理这个问题，因为它从索引 0 开始交替并假设第一个正值存在。 

**数组已经交替：** 该算法仍然有效，因为拆分保留了相对顺序，并且重建数组正确地交替了元素。 

**聚集的阳性和阴性：**当阳性和阴性不交错时，简单的扫描方法可能会失败。 通过拆分和使用索引指针，无论初始聚类如何，我们都保证正确的交替排列。 

该解决方案对于满足问题约束的所有输入都是稳健的。
