[LeetCode 问题 2192](https://leetcode.com/problems/all-ancestors-of-a-node-in-a-directed-acycling-graph/)

 **难度：** 🟡 中等
 **主题：** 深度优先搜索、广度优先搜索、图论、拓扑排序

 ## 解决方案

 ## 问题理解

 这个问题给了我们一个**有向无环图（DAG）**`n`节点标记为`0`到`n - 1`，以及有向边列表。 每条边`[u, v]`意味着有来自节点的单向连接`u`到节点`v`。 

目标是为每个节点进行计算`i`，它的所有**祖先**。 

节点的祖先`v`是任意节点`u`最终可以达到`v`通过一个或多个有向边。 包括直接父关系，但也包括通过中间节点的间接关系。 

例如，如果：```
0 -> 1 -> 2
```然后：

-`0`是的祖先`1`-`1`是的祖先`2`-`0`也是`2`，因为存在一条路径`0 -> 1 -> 2`所需的输出是一个列表`answer`在哪里：```
answer[i]
```包含节点的每个祖先`i`，按升序排列。 

重要的细节是，该图保证是一个**DAG**，这意味着**没有循环**。 这种保证很重要，因为它允许我们以**拓扑顺序**处理节点，确保当我们处理一个节点时，它的所有前任节点都已被处理。 

### 了解限制

 限制条件是：

 -`1 <= n <= 1000`-`edges.length <= 2000`这些限制是适度的。 自从`n`至多是`1000`， 一个`O(n²)`甚至`O(n³)`在某些情况下解决方案可能仍然可行，但我们应该寻求更有效的方法。 

从每个节点进行简单的图遍历是可行的，因为图相对较小，但我们可以通过利用 DAG 属性做得更好。 

非循环图尤其重要，因为它意味着依赖关系仅沿一个方向流动，这使得**拓扑排序**适用。 

### 重要的边缘案例

 一种重要的边缘情况是**根本没有边缘**。 在这种情况下，每个节点都没有祖先，因此答案只是一个空数组列表。 

另一个边缘情况是**线性链**：```
0 -> 1 -> 2 -> 3
```在这种情况下，祖先列表逐渐变大：```
[[], [0], [0,1], [0,1,2]]
```第三种边缘情况是具有**多个传入路径**的图。 如果一个节点可以通过不同的路由到达，我们必须避免重复的祖先。 

例如：```
0 -> 2
1 -> 2
0 -> 1
```节点`2`应包含`[0,1]`，不重复`0`。 

该问题还保证：

 - 没有重复的边缘
 - 无自循环
 - 无循环

 这些保证简化了实现，因为我们不需要循环检测或重复边缘过滤。 

## 方法

 ### 蛮力方法

 蛮力的想法很简单：对于每个节点`u`，运行图形遍历，例如 **DFS** 或 **BFS*​​ 来确定可到达的所有节点`u`。 

每当节点`u`到达节点`v`，我们添加`u`到`v`的祖先名单。 

换句话说：

 1. 从每个节点启动DFS/BFS。 
2. 访问所有可达的后代。 
3. 添加源节点作为每个访问节点的祖先。 

这是有效的，因为如果`u`可以达到`v`，那么根据定义`u`是的祖先`v`。 

然而，这种方法变得低效，因为我们可能会重复遍历图的重叠部分。 

例如，如果许多节点共享后代，则会多次探索相同的路径。 

由于我们对所有的进行遍历`n`节点，最坏情况复杂度变为：```
O(n × (n + e))
```在哪里：

-`n`= 节点数
 -`e`= 边数

 虽然这可以通过`n = 1000`，有更干净的DAG特定优化。 

### 最优方法，拓扑排序+祖先传播

 关键的见解是该图是一个 **DAG**。 

在 DAG 中，我们可以按**拓扑顺序**处理节点，这意味着每个节点都出现在其所有先决条件之后。 

假设我们知道节点的所有祖先`u`。 

如果有一条边：```
u -> v
```那么每一个祖先`u`自动成为祖先`v`。 

此外，`u`本身成为祖先`v`。 

因此我们可以向前传播祖先信息：```
ancestors[v] =
ancestors[v] ∪ ancestors[u] ∪ {u}
```我们使用 **卡恩算法** 处理节点进行拓扑排序。 

这保证了在处理节点之前，所有传入的依赖项都已经贡献了它们的祖先信息。 

使用集合有助于自动避免重复。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | ---| ---| ---| ---|
 | 蛮力 | O(n × (n + e)) | O(n × (n + e)) | O(n + e) | 从每个节点运行 DFS/BFS |
 | 最佳| O(n² + e) | O(n² + e) | 具有祖先传播的拓扑排序 |

 ## 算法演练

 ### 第 1 步：构建图表

 从边列表创建邻接列表。 

对于每条边：```
u -> v
```店铺`v`里面`graph[u]`。 

我们还计算每个节点的**入度**，它计算它有多少个传入边。 

拓扑排序需要此信息。 

### 步骤 2：初始化祖先存储

 创建集合列表：```
ancestors[i]
```每个集合最终将包含节点的所有祖先`i`。 

我们使用集合是因为：

 - 必须避免重复
 - 插入效率高
 - 工会运作简单

 ### 第三步：开始拓扑排序

 添加所有具有入度的节点`0`到一个队列。 

这些节点没有传入边，这意味着它们不能有祖先。 

它们充当起点。 

### 步骤 4：按拓扑顺序处理节点

 当队列不为空时：

 1.移除当前节点`u`2.拜访每个邻居`v`3.添加`u`进入`ancestors[v]`4. 合并所有祖先`u`进入`ancestors[v]`5. 降低度数`v`6. 如果入度变为`0`， 推`v`进入队列

 传播步骤是最重要的：```
ancestors[v].add(u)
ancestors[v].update(ancestors[u])
```这会将所有已知的祖先信息向前传输。 

### 步骤 5：将集合转换为排序列表

 该问题需要祖先按升序排列。 

由于集合是无序的，因此将每个集合转换为排序列表。 

返回最终结果。 

### 为什么它有效

 正确性来自**拓扑排序**。 

仅在处理了节点的所有传入依赖项后才处理节点。 因此，在处理边缘时：```
u -> v
```集合`ancestors[u]`已经完成了。 

添加：```
ancestors[u] + {u}
```到`v`保证所有有效的祖先都只传播一次。 

因为每条边都经过处理并且重复项被按组删除，所以最终的祖先列表是完整且正确的。 

## Python 解决方案```python
from collections import deque
from typing import List

class Solution:
    def getAncestors(self, n: int, edges: List[List[int]]) -> List[List[int]]:
        graph = [[] for _ in range(n)]
        indegree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            indegree[v] += 1

        ancestors = [set() for _ in range(n)]

        queue = deque()

        for node in range(n):
            if indegree[node] == 0:
                queue.append(node)

        while queue:
            current = queue.popleft()

            for neighbor in graph[current]:
                ancestors[neighbor].add(current)
                ancestors[neighbor].update(ancestors[current])

                indegree[neighbor] -= 1

                if indegree[neighbor] == 0:
                    queue.append(neighbor)

        return [sorted(list(ancestor_set)) for ancestor_set in ancestors]
```### 实现说明

 该解决方案首先构建图和入度数组。 邻接列表表示出边，而入度数组则跟踪每个节点有多少个先决条件。 

然后我们初始化一个集合数组，称为`ancestors`。 每个索引存储特定节点的所有祖先。 

队列由入度为零的节点初始化。 由于这些节点没有传入边，因此它们没有祖先，可以立即处理。 

在 BFS 遍历期间，每个节点都会将其祖先信息传播给邻居。 

对于每个邻居：```
ancestors[neighbor].add(current)
```添加直接父级。 

然后：```
ancestors[neighbor].update(ancestors[current])
```添加所有间接祖先。 

处理完一条边后，入度会减小。 一旦节点达到入度零，所有父节点信息都已被处理，因此它可以安全地进入队列。 

最后，在返回之前对每个集合进行排序，因为问题需要升序。 

## 解决方案```go
func getAncestors(n int, edges [][]int) [][]int {
	graph := make([][]int, n)
	indegree := make([]int, n)

	for _, edge := range edges {
		u, v := edge[0], edge[1]
		graph[u] = append(graph[u], v)
		indegree[v]++
	}

	ancestors := make([]map[int]bool, n)

	for i := 0; i < n; i++ {
		ancestors[i] = make(map[int]bool)
	}

	queue := []int{}

	for i := 0; i < n; i++ {
		if indegree[i] == 0 {
			queue = append(queue, i)
		}
	}

	for len(queue) > 0 {
		current := queue[0]
		queue = queue[1:]

		for _, neighbor := range graph[current] {
			ancestors[neighbor][current] = true

			for ancestor := range ancestors[current] {
				ancestors[neighbor][ancestor] = true
			}

			indegree[neighbor]--

			if indegree[neighbor] == 0 {
				queue = append(queue, neighbor)
			}
		}
	}

	result := make([][]int, n)

	for i := 0; i < n; i++ {
		for ancestor := range ancestors[i] {
			result[i] = append(result[i], ancestor)
		}

		// sort ascending
		for j := 0; j < len(result[i]); j++ {
			for k := j + 1; k < len(result[i]); k++ {
				if result[i][j] > result[i][k] {
					result[i][j], result[i][k] =
						result[i][k], result[i][j]
				}
			}
		}
	}

	return result
}
```### Go 具体注释

 Go 没有内置的集合类型，因此我们使用以下方法模拟一个集合类型：```
map[int]bool
```这允许恒定时间插入和自动重复消除。 

与 Python 不同，Go 切片不支持`popleft()`，因此队列操作是通过切片来处理的：```
queue = queue[1:]
```Python版本使用`sorted()`，而 Go 需要显式排序。 在生产代码中，`sort.Ints(result[i])`对于可读性和性能来说是首选。 

Nil 处理很简单，因为每个祖先映射在使用前都已初始化。

class Solution:
    def getAncestors(self, n, edges):
        from collections import deque

        graph = [[] for _ in range(n)]
        indegree = [0] * n

        for u, v in edges:
            graph[u].append(v)
            indegree[v] += 1

        ancestors = [set() for _ in range(n)]
        queue = deque(
            [i for i in range(n) if indegree[i] == 0]
        )

        while queue:
            current = queue.popleft()

            for neighbor in graph[current]:
                ancestors[neighbor].add(current)
                ancestors[neighbor].update(
                    ancestors[current]
                )

                indegree[neighbor] -= 1

                if indegree[neighbor] == 0:
                    queue.append(neighbor)

        return [sorted(a) for a in ancestors]

 ## 边缘情况

 ### 图中没有边

 当图不包含边时，每个节点都是孤立的。 

例如：```
n = 4
edges = []
```每个节点的入度为零并立即进入队列。 由于没有传出边，因此不会形成祖先关系。 

实现正确返回：```
[[], [], [], []]
```### 到同一节点的多个路径

 一个节点可以通过多条路由到达。 

例子：```
0 -> 1 -> 3
0 -> 2 -> 3
```如果不小心处理，祖先`0`可能会添加两次。 

该实现通过将祖先存储在**集合**中来避免此错误，自动确保唯一性。 

### 长依赖链

 在这样的链中：```
0 -> 1 -> 2 -> 3 -> 4
```每个节点都会累积所有先前的节点作为祖先。 

这强调传递传播，因为每一步都会继承越来越大的祖先集。 

该实现通过以下方式自然地处理这个问题：```
update(ancestors[current])
```它有效地传播所有间接祖先。 

### 断开的组件

 该图可以包含独立的子图。 

例子：```
0 -> 1

2 -> 3
```祖先计算应该在每个组件内保持隔离。 

由于拓扑处理同时从所有入度为零的节点开始，因此无需任何特殊逻辑即可正确处理断开的组件。
