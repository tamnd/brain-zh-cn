 ## 解决方案

 ## 问题理解

 这个问题是询问一个字符串是否包含以下字符`'('`,`')'`， 和`'*'`可以被视为有效的括号字符串。 本质上，`'('`必须匹配一个`')'`以正确的顺序，并且`'*'`可以充当灵活的占位符，其行为如下`'('`,`')'`，或空字符串。 输入`s`是一个长度在1到100之间的字符串，因此它相对较小，这使得方法选择具有一定的灵活性。 预期输出是一个布尔值，`true`是否可以通过解释使字符串有效`'*'`适当地，并且`false`否则。 

关键边缘情况包括完全由以下内容组成的字符串`'*'`, 开头的字符串`')'`或结束于`'('`，以及多个组合`'*'`角色可能会解决或打破平衡，具体取决于他们的解释。 约束保证输入仅包括`'('`,`')'`， 或者`'*'`，所以我们不需要验证输入字符。 

## 方法

 暴力方法是生成所有可能的替代品`'*'`和`'('`,`')'`，或空字符串，然后检查每个结果字符串是否有效。 这是有效的，因为它详尽地测试了所有解释，但效率极低。 对于一个长度的字符串`n`和`k` `'*'`字符，有`3^k`可能要检查的字符串，即使对于中等程度的人来说也变得难以管理`n`。 

更好的解决方案的关键在于我们不需要生成所有组合。 相反，我们可以在遍历字符串时跟踪**可能的左括号的范围**。 我们维持一个`low`和`high`柜台：`low`表示不匹配的最小可能数量`'('`（治疗`'*'`作为`')'`）， 和`high`表示不匹配的最大可能数量`'('`（治疗`'*'`作为`'('`）。 如果`high`任何时候都低于 0，数量太多`')'`字符且字符串无效。 如果`low`达到 0 时，它被钳位在 0，因为负的打开计数是不可能的。 最后，如果`low`为0时，字符串有效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(3^k * n) | O(3^k * n) | O(n) | 通过替换生成所有可能的字符串`'*'`并检查每个的有效性|
 | 最优（贪婪）| O(n) | O(1) | O(1) | 无与伦比的航迹范围`'('`使用`low`和`high`计数器，单程|

 ## 算法演练

 1.初始化两个计数器，`low`和`high`, 到 0。这些代表不匹配的最小和最大数量`'('`分别。 
2. 迭代每个字符`c`在字符串中`s`。 
3.如果`c`是`'('`, 两者都增加`low`和`high`加 1，因为它增加了不匹配的左括号的数量。 
4. 如果`c`是`')'`, 两者都减少`low`和`high`加 1，因为它关闭了括号。 夹钳`low`为 0 因为我们不能有负数不匹配`'('`。 
5. 如果`c`是`'*'`，将其视为`'('`,`')'`，或为空。 增量`high`乘以 1（考虑`'*'`作为`'('`) 并递减`low`乘以 1（考虑`'*'`作为`')'`) 并夹紧`low`至 0。 
6. 如果在任何时候`high`变为负数，返回`false`立即，因为它表明有太多不匹配的`')'`。 
7.处理完所有字符后，返回`true`如果`low`为0，表示存在所有括号都匹配的解释； 否则，返回`false`。 

为什么它有效：`low`和`high`计数器保持一个无与伦比的可行范围`'('`在每一步。 如果这个范围变得无效（`high < 0`），不存在有效的解释。 如果下界`low`当最后达到 0 时，有一个有效的解释可以平衡所有括号。 

## Python 解决方案```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        low = 0
        high = 0
        
        for c in s:
            if c == '(':
                low += 1
                high += 1
            elif c == ')':
                low = max(low - 1, 0)
                high -= 1
            else:  # c == '*'
                low = max(low - 1, 0)
                high += 1
                
            if high < 0:
                return False
        
        return low == 0
```代码使用`low`和`high`计数器跟踪不匹配的最小和最大数量`'('`在每个字符处。`'('`两者都增加，`')'`两者都减少`low`钳位至 0，并且`'*'`调整范围以考虑其三种可能的解释。 如果`high`低于 0，函数立即返回`False`，否则返回`True`如果`low`末尾是0。 

## 解决方案```go
func checkValidString(s string) bool {
    low, high := 0, 0
    
    for _, c := range s {
        switch c {
        case '(':
            low++
            high++
        case ')':
            if low > 0 {
                low--
            }
            high--
        case '*':
            if low > 0 {
                low--
            }
            high++
        }
        if high < 0 {
            return false
        }
    }
    
    return low == 0
}
```在Go中，我们使用整数变量`low`和`high`出于同样的目的。 这`switch`为了清楚起见，使用了声明。`low`被夹紧使用`if low > 0 { low-- }`。 其余逻辑反映了 Python 实现。 不需要动态内存结构，这使得它在空间和时间上都很高效。

 ## 边缘情况

 一个重要的边缘情况是以以下开头的字符串`')'`。 幼稚的实现可能不会及早检测到字符串无效。 贪心方法正确设置`high`到-1，立即返回`False`。 

第二个边缘情况是一个字符串，只有`'*'`。 该算法必须处理这个问题而不假设任何固定的解释。 夹紧`low`到 0 确保范围保持有效，无论如何
