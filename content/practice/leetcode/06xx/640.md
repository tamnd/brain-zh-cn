 ## 解决方案

 ## 问题理解

 问题是要求我们求解包含单个变量的线性方程`'x'`和整数系数，表示为字符串。 该方程可以包括加法`'+'`, 减法`'-'`，以及相等运算符`'='`。 我们需要解析这个字符串，组合相似的项，并求解`'x'`。 结果应返回为`"x=#value"`是否存在唯一的整数解。 如果不存在解则返回`"No solution"`，如果有无穷多个解，则返回`"Infinite solutions"`。 

输入字符串有几个限制：它始终只包含一个`'='`，以及系数`'x'`是范围内的整数`[0, 100]`没有前导零。 字符串的最大长度为 1000 个字符，因此我们需要一个能够高效处理字符串的解决方案，而无需以指数方式迭代可能性。 

重要的边缘情况包括方程，其中`'x'`项相互抵消、系数为零的方程以及一侧仅包含常数的方程。 例如，`"x=x"`应该返回`"Infinite solutions"`和`"2x=x"`应该返回`"x=0"`。 拆分术语时正确处理符号至关重要。 

## 方法

 蛮力方法将尝试评估方程的每个可能的整数值`'x'`。 虽然如果我们在足够大的范围内搜索，这可以保证正确性，但它的效率非常低，因为范围可能很大，并且重复解析和评估表达式会很慢。 

最佳方法使用代数运算。 我们可以将方程视为两侧由`'='`。 通过解析每一边，我们可以提取出总系数`'x'`和总常数项。 一旦我们有`ax + b = cx + d`，我们可以解出`'x'`使用`x = (d - b) / (a - c)`。 这是有效的，因为它将问题简化为基本算术和字符串解析，使其与输入的长度呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(R * N) | O(1) | O(1) | 评估 x 在某个范围内的所有可能的整数值，对于大系数来说效率较低。 |
 | 最佳| O(N) | O(1) | O(1) | 解析每个项一次，计算系数和常数，使用代数求解。 |

 ## 算法演练

 1. 将输入字符串分割为`'='`分为左侧 (LHS) 和右侧 (RHS)。 这允许单独处理方程两边。 
2. 将每一方解析为术语。 术语由以下条件分隔`'+'`或者`'-'`，并且项可以是常数或`'x'`带有可选系数的项。 
3. 对于每一项，累加总系数`'x'`和总常数。 例如，在`"2x+3-x"`，总系数`'x'`是`1`总常数为`3`。 
4.处理完两边后，计算网络`'x'`系数为`lhs_x_coeff - rhs_x_coeff`净常数为`rhs_const - lhs_const`。 
5. 处理边缘情况。 如果网`'x'`系数为零，则如果净常数非零，则无解；如果净常数为零，则有无限解。 
6. 否则，计算整数解`'x'`作为`net_constant / net_x_coeff`并以格式返回`"x=#value"`。 

**为什么有效：** 通过组合两边相似的项并将方程简化为标准线性形式，我们确保解在数学上是正确的。 解析每一项可确保正确处理符号和系数。 

## Python 解决方案```python
class Solution:
    def solveEquation(self, equation: str) -> str:
        def parse(expr: str) -> tuple[int, int]:
            i, n = 0, len(expr)
            x_coeff, const = 0, 0
            while i < n:
                sign = 1
                if expr[i] in '+-':
                    sign = 1 if expr[i] == '+' else -1
                    i += 1
                num = 0
                has_num = False
                while i < n and expr[i].isdigit():
                    num = num * 10 + int(expr[i])
                    i += 1
                    has_num = True
                if i < n and expr[i] == 'x':
                    x_coeff += sign * (num if has_num else 1)
                    i += 1
                else:
                    const += sign * num
            return x_coeff, const

        lhs, rhs = equation.split('=')
        lhs_x, lhs_const = parse(lhs)
        rhs_x, rhs_const = parse(rhs)

        net_x = lhs_x - rhs_x
        net_const = rhs_const - lhs_const

        if net_x == 0:
            if net_const == 0:
                return "Infinite solutions"
            else:
                return "No solution"
        return f"x={net_const // net_x}"
```**实施演练：**`parse`函数迭代表达式的每个字符，正确处理`'+'`和`'-'`符号、可选系数和常数。 解析两边后，我们减去系数和常数来简化方程。 最后，我们检查零系数的特殊情况并计算解决方案。 

## 解决方案```go
import "strconv"

func solveEquation(equation string) string {
    parse := func(expr string) (int, int) {
        xCoeff, constSum := 0, 0
        n := len(expr)
        i := 0
        for i < n {
            sign := 1
            if expr[i] == '+' || expr[i] == '-' {
                if expr[i] == '-' {
                    sign = -1
                }
                i++
            }
            num := 0
            hasNum := false
            for i < n && expr[i] >= '0' && expr[i] <= '9' {
                num = num*10 + int(expr[i]-'0')
                i++
                hasNum = true
            }
            if i < n && expr[i] == 'x' {
                if !hasNum {
                    num = 1
                }
                xCoeff += sign * num
                i++
            } else {
                constSum += sign * num
            }
        }
        return xCoeff, constSum
    }

    parts := []string{}
    for _, c := range equation {
        if c == '=' {
            parts = append(parts, "")
        } else {
            if len(parts) == 0 {
                parts = append(parts, "")
            }
            parts[len(parts)-1] += string(c)
        }
    }

    lhsX, lhsC := parse(parts[0])
    rhsX, rhsC := parse(parts[1])

    netX := lhsX - rhsX
    netC := rhsC - lhsC

    if netX == 0 {
        if netC == 0 {
            return "Infinite solutions"
        }
        return "No solution"
    }
    return "x=" + strconv.Itoa(netC/netX)
}
```**Go 特定说明：** 我们显式地将字符转换为整数并处理两侧的字符串构建。 Go 缺乏像 Python 一样的元组返回类型解构，但返回两个值的工作方式类似。 我们还使用处理整数转换和字符串格式化`strconv`。
