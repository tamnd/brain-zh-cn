[LeetCode 第 648 题](https://leetcode.com/problems/replace-words/)

 **难度：** 🟡 中等
 **主题：** 数组、哈希表、字符串、Trie

 ## 解决方案

 ## 问题理解

 该问题要求我们使用一组预定义的**根词**替换句子中的单词。 词根是一个较短的单词，可以作为较长的衍生单词的前缀。 每当句子中的单词以字典中的词根之一开头时，我们就会用匹配的词根替换该单词。 

有一个重要的规则：如果多个词根可以匹配一个单词，我们必须始终选择**最短的词根**。 例如，如果字典同时包含`"cat"`和`"cattle"`，并且该句子包含`"cattleman"`，正确的替换是`"cat"`因为它是最短的有效前缀。 

输入由两部分组成：

 -`dictionary`，词根列表。 
-`sentence`，包含空格分隔单词的字符串。 

预期的输出是一个修改后的句子，其中每个派生词都被其最短的匹配根替换，而与任何根不匹配的单词保持不变。 

例如：```
dictionary = ["cat","bat","rat"]
sentence = "the cattle was rattled by the battery"
```这个词`"cattle"`开始于`"cat"`，所以就变成了`"cat"`。`"rattled"`开始于`"rat"`，所以就变成了`"rat"`。`"battery"`开始于`"bat"`，所以就变成了`"bat"`。 

约束很重要，因为它们影响算法的选择。 字典最多可以包含`1000`根，每个长度`100`。 一个句子可以长至`10^6`个字符，每个单词也可能很大。 当句子和字典都很大时，重复扫描每个单词的每个词根的简单解决方案可能会变得低效。 

一些边缘情况值得预先识别。 一个单词可能根本不匹配任何词根，在这种情况下它应该保持不变。 同一个词可能有多个词根匹配，我们必须选择最短的一个。 有些词根本身可能是其他词根的前缀，例如`"a"`和`"ab"`，这使得最短前缀选择尤为重要。 该问题保证输入仅包含小写字母和空格，单词之间只有一个空格，从而简化了解析。 

## 方法

 ### 蛮力方法

 一个简单的解决方案是根据字典中的每个词根检查句子中的每个单词。 

对于每个单词，我们迭代所有字典条目并确定根是否是当前单词的前缀。 如果多个根匹配，我们会跟踪最短的一个。 如果没有匹配的词根，我们就保持该词不变。 

这种方法是正确的，因为它显式检查所有可能的根并选择最短的有效前缀。 然而，当字典很大时，它会变得低效。 对于每个单词，我们可能会扫描所有词根，而前缀检查本身可能会花费与词根长度成正比的额外时间。 

如果：

-`n`= 字数
 -`d`= 字典根的数量
 -`k`= 平均根长

 那么时间复杂度大约变为`O(n × d × k)`，这可能会不必要地昂贵。 

### 最佳解决方案的关键见解

 主要观察结果是我们重复执行**前缀查找**。 这正是 **Trie（前缀树）** 旨在有效解决的问题。 

Trie 逐个字符地存储单词。 我们不是独立检查每个根，而是将所有字典根插入到 Trie 中。 然后，对于每个句子单词，我们逐个字符地遍历 Trie。 

当我们遇到标记为根结尾的节点时，我们立即停止，因为我们遇到的第一个根自动是最短的前缀。 如果由于 Trie 中不存在字符而导致遍历失败，则不存在替换。 

这避免了重复扫描整个字典，并使前缀匹配速度更快。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n × d × k) | O(n × d × k) | O(d × k) | 检查每个词的每个词根 |
 | 最优（特里树）| O(D + S) | O(D) | 使用 Trie 进行高效前缀查找 |

 这里：

-`D`是所有字典单词的字符总数。 
-`S`是所有句子单词的字符总数。 

## 算法演练

 ### 使用 Trie 的最优算法

 1. **从字典根构建一个 Trie**

 创建一个 Trie，其中每个节点存储子字符和一个指示根是否在那里结束的标记。 一次将每个根插入 Trie 一个字符。 

这个预处理步骤使我们能够有效地执行前缀查找，而不是重复扫描字典。 
2. **将句子拆分成单词**

 由于该句子包含由空格分隔的单词，因此我们将其拆分为单词数组。 

这使我们能够独立处理每个单词。 
3. **搜索最短匹配根**

 对于每个单词：

 - 从根节点开始遍历Trie。 
- 在单词中逐个字符移动。 
- 如果 Trie 中不存在某个字符，则停止，因为没有根匹配。 
- 如果我们遇到一个标记为根结尾的 Trie 节点，则立即返回到该位置的子字符串。 

我们在第一个有效的根处停止，因为 Trie 遍历自然会在较长的前缀之前找到较短的前缀。 
4. **如果需要请替换该词**

 如果找到匹配的根，则将该根追加到结果列表中。 否则，附加原始单词不变。 
5. **重构句子**

 使用空格将所有已处理的单词重新连接在一起。 

### 为什么它有效

 关键的不变量是 Trie 遍历按照长度递增的顺序遵循前缀。 一旦我们遇到一个标记为完整根的节点，我们就知道它是最短的有效根，因为任何更长的根都会延伸到这一点之外。 因此，替换第一个有效词根处的单词总是可以满足问题要求。 

## Python 解决方案```python
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Solution:
    def replaceWords(self, dictionary: List[str], sentence: str) -> str:
        root = TrieNode()

        # Build Trie
        for word in dictionary:
            node = root
            for char in word:
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
            node.is_end = True

        def find_root(word: str) -> str:
            node = root
            prefix = []

            for char in word:
                if char not in node.children:
                    return word

                node = node.children[char]
                prefix.append(char)

                if node.is_end:
                    return "".join(prefix)

            return word

        words = sentence.split()
        replaced_words = [find_root(word) for word in words]

        return " ".join(replaced_words)
```实现首先定义一个`TrieNode`班级。 每个节点包含一个子节点字典和一个指示根词是否以该节点结束的布尔标志。 

Trie 是通过迭代每个字典根并一一插入字符来构建的。 如果字符路径不存在，则创建一个新节点。 一旦插入整个单词，结束节点就被标记为有效的根。 

辅助函数`find_root`执行前缀搜索。 它逐个字符地遍历 Trie，同时构建前缀。 如果遍历失败，则返回原始单词，因为不存在根。 如果遇到结束节点，则立即返回最短的有效根。 

最后，将句子拆分为单词，使用辅助函数进行转换，并使用空格进行重构。 

## 解决方案```go
package main

import "strings"

type TrieNode struct {
	children map[byte]*TrieNode
	isEnd    bool
}

func newTrieNode() *TrieNode {
	return &TrieNode{
		children: make(map[byte]*TrieNode),
	}
}

func replaceWords(dictionary []string, sentence string) string {
	root := newTrieNode()

	// Build Trie
	for _, word := range dictionary {
		node := root

		for i := 0; i < len(word); i++ {
			char := word[i]

			if _, exists := node.children[char]; !exists {
				node.children[char] = newTrieNode()
			}

			node = node.children[char]
		}

		node.isEnd = true
	}

	findRoot := func(word string) string {
		node := root

		for i := 0; i < len(word); i++ {
			char := word[i]

			nextNode, exists := node.children[char]
			if !exists {
				return word
			}

			node = nextNode

			if node.isEnd {
				return word[:i+1]
			}
		}

		return word
	}

	words := strings.Split(sentence, " ")

	for i := 0; i < len(words); i++ {
		words[i] = findRoot(words[i])
	}

	return strings.Join(words, " ")
}
```Go 实现遵循与 Python 版本相同的整体结构，但使用`map[byte]*TrieNode`表示 Trie 中的子边。 由于问题保证小写英文字母，`byte`索引是充分且有效的。 

Go 没有使用返回字符列表的嵌套辅助函数，而是简单地使用以下命令对原始字符串进行切片`word[:i+1]`一旦找到有效的根。 句子被分割使用`strings.Split`，最后的句子用`strings.Join`。 

无需特殊处理`nil`是必需的，因为约束保证非空输入，尽管实现对于空切片仍然可以正确运行。

 ## 边缘情况

 ### 多个词根匹配同一个单词

 一个单词可以同时匹配多个词根。 例如，如果字典包含`["a", "ab", "abc"]`这个词是`"abcdef"`，所有三个根都是技术上有效的前缀。 

这是错误的常见来源，因为实现可能会意外返回最长的匹配项。 基于 Trie 的解决方案通过在**第一个结束节点**停止来自然地避免了这种情况，这保证了最短的根。 

### 没有根匹配

 有些单词可能不以任何字典词根开头。 例如：```
dictionary = ["cat"]
sentence = "dog"
```幼稚的实现可能会错误地返回空字符串或部分匹配的前缀。 在此实现中，当第一个字符丢失时，Trie 遍历立即失败，并且原始单词不变地返回。 

### 词根是整个单词

 有时一个单词已经完全等于一个词根，例如：```
dictionary = ["cat"]
sentence = "cat cattle"
```该实现正确地处理了这个问题，因为 Trie 遍历将最终节点标记为`is_end`。 一旦到达，该词将被替换为`"cat"`，即使它已经完美匹配。 这保证了精确匹配和导数的行为一致。
