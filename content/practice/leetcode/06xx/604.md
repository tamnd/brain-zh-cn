 ## 解决方案

 ## 问题理解

 这个问题要求我们实现一个**压缩字符串迭代器**。 我们得到一个字符串，其中每个字符后面紧跟着一个数字，表示该字符在未压缩版本中连续出现的次数。 例如，`"a3b2"`代表`"aaabb"`。 

我们需要实现一个类`StringIterator`有两种方法：

 -`next()`，它返回未压缩字符串中的下一个字符，如果没有剩余字符，则返回 **空格**。 
-`hasNext()`，返回`True`是否还有剩余字符需要迭代，否则`False`。 

输入保证压缩字符串格式良好：字母与数字交替，数字为正整数，每个数字可以大到$10^9$。 字符串长度上限为 1000，但由于重复计数可能非常大，**完全解压缩字符串对于空间和时间效率来说是不可行的**。 

重要的边缘情况包括：

 - 重复次数较多的字符，无法在内存中展开为完整字符串。 
- 查询`next()`当所有角色都被消耗完之后。 
- 具有单字符重复的字符串（例如`"a1"`）。 

该问题本质上需要一个**惰性迭代器**来动态解压缩字符。 

## 方法

 **暴力方法**很简单：将字符串完全解压缩为字符列表，然后迭代该列表。 这是正确的但不切实际，因为单个字符最多可以重复$10^9$次，这将超出内存限制。 

**最佳方法**是维护**指针和计数器**，而不是存储完整的字符串。 我们将压缩后的字符串解析为`(char, count)`对，然后使用索引来跟踪当前位置，并使用计数器来跟踪当前字符已发出的次数。 每个`next()`call 只是递减计数器，当它达到零时，我们移动到下一个字符计数对。`hasNext()`只需检查计数器或剩余字符是否指示要返回更多字符。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N + 总数) | O(总计数) | 解压缩整个字符串，然后迭代。 对于大量重复来说不切实际。 |
 | 最佳| 解析 O(N)，每个 next/hasNext | O(1) O(N) | 仅存储字符计数对并维护指针，延迟解压缩。 |

 ## 算法演练

 1. **初始化**：将压缩字符串解析为列表`(char, count)`对。 使用指针`index`跟踪当前字符对并`current_count`跟踪该角色的剩余重复次数。 
2. **next()**：检查是否`current_count > 0`。 如果是，则递减`current_count`并返回`current_char`。 如果`current_count == 0`， 进步`index`到下一对并设置`current_count`返回字符之前先到相应的计数。 
3. **hasNext()**：返回`True`如果其中之一`current_count > 0`或者`index`在对列表的范围内。 
4. **边缘处理**：如果`next()`被调用并且没有剩余字符，返回一个空格。 

**为什么它有效**：迭代器维护以下不变式：`current_count`总是反映出多少次`current_char`仍需归还。 这保证了正确的序列生成，而无需解压缩整个字符串。 

## Python 解决方案```python
class StringIterator:

    def __init__(self, compressedString: str):
        self.pairs = []
        i = 0
        n = len(compressedString)
        while i < n:
            char = compressedString[i]
            i += 1
            count = 0
            while i < n and compressedString[i].isdigit():
                count = count * 10 + int(compressedString[i])
                i += 1
            self.pairs.append([char, count])
        self.index = 0
        self.current_count = self.pairs[0][1] if self.pairs else 0

    def next(self) -> str:
        if not self.hasNext():
            return " "
        char, count = self.pairs[self.index]
        self.current_count -= 1
        if self.current_count == 0:
            self.index += 1
            if self.index < len(self.pairs):
                self.current_count = self.pairs[self.index][1]
        return char

    def hasNext(self) -> bool:
        return self.index < len(self.pairs)
```构造函数将字符串解析为`(char, count)`对，处理多位数字。`next()`用途`current_count`延迟发出字符，并且`hasNext()`确保我们只报告剩余的字符。 

## 解决方案```go
type StringIterator struct {
	pairs        [][2]int
	chars        []byte
	index        int
	currentCount int
}

func Constructor(compressedString string) StringIterator {
	it := StringIterator{}
	n := len(compressedString)
	for i := 0; i < n; {
		char := compressedString[i]
		i++
		count := 0
		for i < n && compressedString[i] >= '0' && compressedString[i] <= '9' {
			count = count*10 + int(compressedString[i]-'0')
			i++
		}
		it.pairs = append(it.pairs, [2]int{int(char), count})
	}
	if len(it.pairs) > 0 {
		it.currentCount = it.pairs[0][1]
	}
	return it
}

func (this *StringIterator) Next() byte {
	if !this.HasNext() {
		return ' '
	}
	char := byte(this.pairs[this.index][0])
	this.currentCount--
	if this.currentCount == 0 {
		this.index++
		if this.index < len(this.pairs) {
			this.currentCount = this.pairs[this.index][1]
		}
	}
	return char
}

func (this *StringIterator) HasNext() bool {
	return this.index < len(this.pairs)
}
```在 Go 中，我们存储`(char, count)`使用切片进行配对`[2]int`数组。 我们以类似的方式处理多位数字。`Next()`和`HasNext()`行为与 Python 相同。 去的`byte`type 用于字符表示。
