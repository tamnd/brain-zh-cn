[LeetCode 第 664 题](https://leetcode.com/problems/strange-printer/)

 **难度：** 🔴难
 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题描述了一种“奇怪的打印机”，它可以一轮打印**相同字符**的序列。 打印机可以覆盖字符串中的任何现有字符。 给定一个输入字符串`s`，目标是确定打印整个字符串所需的**最小打印操作数**。 

换句话说，我们想要找到使用该打印机重现字符串所需的最少数量的连续字符序列。 输入是一串小写英文字母，长度在 1 到 100 之间。这些约束意味着暴力解决方案对于非常小的字符串可能是可行的，但对于长度接近 100 的字符串，我们需要更优化的方法。 

边缘情况包括：

 1. 具有全部相同字符的字符串，例如，`"aaaa"`。 只需要一圈。 
2. 具有交替字符的字符串，例如，`"abab"`。 每个不同的角色可能需要仔细的重叠规划。 
3. 长度为1的字符串，例如，`"a"`。 只需要一圈。 

该问题保证非空字符串，因此我们不需要处理空输入。 

## 方法

 **暴力方法：**

 一种简单的暴力方法会考虑以每种可能的顺序打印每个可能的子字符串。 在每一步中，算法都可以尝试打印相同字符的子字符串，并递归计算剩余字符串所需的最小圈数。 虽然这种方法原则上是正确的，但它的速度呈指数级缓慢，因为分割字符串的方法数量随着长度的增长而增长得非常快。 它无法处理长度最多为 100 的字符串。 

**优化方法：**

 关键的见解是**动态编程**可以通过利用重叠的子问题来降低复杂性。 让`dp[i][j]`是打印子字符串所需的最小圈数`s[i..j]`。 

如果`s[i] == s[j]`, 最后一个字符`s[j]`可以在同一轮中打印`s[i]`，减少所需的匝数。 Otherwise, we consider splitting the substring at every possible index`k`之间`i`和`j`并取最小总和`dp[i][k] + dp[k+1][j]`。 这样可以避免冗余计算，保证最优解。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n^2) | O(n^2) | 尝试所有分区和打印命令，对于 n=100 来说太慢 |
 | 最佳 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 使用DP存储子问题结果并高效分割子串 |

 ## 算法演练

 1.初始化一个2D DP数组`dp`尺寸的`n x n`， 在哪里`n`是字符串的长度。`dp[i][j]`将存储打印子字符串所需的最小圈数`s[i..j]`。 
2. 对于长度为 1 的子串（即`i == j`）， 放`dp[i][i] = 1`因为单个角色只需要一回合。 
3. 迭代子字符串长度从 2 到`n`。 
4. 对于每个子串长度，迭代所有起始索引`i`计算结束索引`j = i + length - 1`。 
5. 初始化`dp[i][j]`到`dp[i][j-1] + 1`，代表打印`s[j]`打印后新一轮`s[i..j-1]`。 
6. 迭代所有`k`从`i`到`j-1`。 如果`s[k] == s[j]`，考虑合并回合：更新`dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j-1])`。 
7. 返回`dp[0][n-1]`作为打印整个字符串的最小圈数。 

**为什么有效：**

 该算法之所以有效，是因为 DP 表正确地表示了每个子串所需的最小匝数。 通过在所有可能的点拆分子字符串并在字符匹配时合并轮次，确保不会错过最佳解决方案。 

## Python 解决方案```python
class Solution:
    def strangePrinter(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0
        
        dp = [[0] * n for _ in range(n)]
        
        for i in range(n):
            dp[i][i] = 1
        
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i][j] = dp[i][j-1] + 1
                for k in range(i, j):
                    if s[k] == s[j]:
                        dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j-1])
        
        return dp[0][n-1]
```DP数组被初始化为存储每个子串的最小圈数。 单个角色需要一回合。 对于较长的子字符串，我们考虑单独打印最后一个字符或与前面的字符（如果匹配）合并。 该解决方案迭代地构建 DP 表，确保考虑所有子串。 

## 解决方案```go
func strangePrinter(s string) int {
    n := len(s)
    if n == 0 {
        return 0
    }
    
    dp := make([][]int, n)
    for i := 0; i < n; i++ {
        dp[i] = make([]int, n)
        dp[i][i] = 1
    }
    
    for length := 2; length <= n; length++ {
        for i := 0; i <= n - length; i++ {
            j := i + length - 1
            dp[i][j] = dp[i][j-1] + 1
            for k := i; k < j; k++ {
                if s[k] == s[j] {
                    if k+1 <= j-1 {
                        dp[i][j] = min(dp[i][j], dp[i][k]+dp[k+1][j-1])
                    } else {
                        dp[i][j] = min(dp[i][j], dp[i][k])
                    }
                }
            }
        }
    }
    
    return dp[0][n-1]
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```Go 需要对 2D 数组进行显式切片初始化。 主要逻辑与Python相同，但在处理索引边界时要小心`k+1 > j-1`。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n^3) | O(n^3) | 三个嵌套循环：长度、起始索引、分割索引 |

 立方时间是通过考虑所有子串长度和所有分割点而产生的。 需要二次空间来存储每个子串的结果。
