 ## 解决方案

 ## 问题理解

 该问题要求我们找到数组的最短连续子数组`nums`与原始数组具有相同的**度**。 数组的**度**定义为该数组中任何元素的最大频率。 换句话说，如果出现次数最多的元素出现`k`次，那么`k`是学位。 

输入`nums`是非负整数的非空列表，输出是一个整数，表示最小连续子数组的长度，该子数组包含对数组度数有贡献的元素之一的所有出现。 

约束告诉我们，数组可以相当大，最多 50,000 个元素，每个元素值也可以很大，最多 49,999 个。 这意味着我们需要一个至少在时间上是线性的解决方案，因为用蛮力方法检查所有可能的子数组会太慢。 重要的边缘情况包括元素全部相同的数组、多个元素具有相同最大频率的数组，以及每个元素都是唯一的 1 度数组。 

## 方法

 一种强力方法是计算数组的度数，然后对于出现次数与度数一样多的每个元素，检查包含该元素所有出现次数的所有子数组并跟踪最小长度。 这种方法是正确的，但速度非常慢，因为生成所有子数组将花费 O(n²) 时间，并且对于 n 高达 50,000 的情况不可行。 

最佳解决方案的关键是跟踪每个数字的第一次和最后一次出现，同时计算它们的频率。 一旦我们知道每个数字的第一次和最后一次出现，我们就可以通过简单地计算具有最大频率的元素的最小连续子数组长度`last_index - first_index + 1`。 这将问题简化为一次数组遍历和每个唯一元素的常数时间计算，从而产生 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 检查所有子数组中每个对度数有贡献的元素 |
 | 最佳| O(n) | O(n) | 跟踪频率、第一个索引、最后一个索引，然后计算最小子数组长度 |

 ## 算法演练

 1.初始化三个字典：`freq`存储每个数字的频率，`first_index`存储第一次出现的索引，以及`last_index`存储最后出现的索引。 
2. 使用索引迭代数组`i`。 对于每个元素`num`:

 - 增量`freq[num]`1.
 - 如果`num`不在`first_index`， 放`first_index[num] = i`。 
- 始终更新`last_index[num] = i`。 
3. 计算数组的度作为最大值`freq`。 
4. 初始化变量`min_length`到无穷大。 迭代中的每个数字`freq`：

- 如果`freq[num]`等于度数，计算包含所有出现次数的子数组的长度`last_index[num] - first_index[num] + 1`。 
- 更新`min_length`如果这个长度小于当前的`min_length`。 
5. 返回`min_length`。 

该算法之所以有效，是因为捕获对次数有贡献的数字的所有出现的子数组必须从其第一次出现开始并在其最后一次出现结束。 通过仅考虑这些索引，我们确保子数组包含该数字的所有实例并且是最小的。 

## Python 解决方案```python
from typing import List

class Solution:
    def findShortestSubArray(self, nums: List[int]) -> int:
        freq = {}
        first_index = {}
        last_index = {}
        
        for i, num in enumerate(nums):
            if num not in first_index:
                first_index[num] = i
            last_index[num] = i
            freq[num] = freq.get(num, 0) + 1
        
        degree = max(freq.values())
        min_length = float('inf')
        
        for num in freq:
            if freq[num] == degree:
                min_length = min(min_length, last_index[num] - first_index[num] + 1)
        
        return min_length
```Python 实现直接遵循该算法。 我们在一次遍历数组中跟踪第一次和最后一次出现的次数和频率。 计算次数后，我们迭代频率字典以找到具有最大频率的元素的最小子数组长度。 

## 解决方案```go
func findShortestSubArray(nums []int) int {
    freq := make(map[int]int)
    firstIndex := make(map[int]int)
    lastIndex := make(map[int]int)
    
    for i, num := range nums {
        if _, exists := firstIndex[num]; !exists {
            firstIndex[num] = i
        }
        lastIndex[num] = i
        freq[num]++
    }
    
    degree := 0
    for _, count := range freq {
        if count > degree {
            degree = count
        }
    }
    
    minLength := len(nums)
    for num, count := range freq {
        if count == degree {
            length := lastIndex[num] - firstIndex[num] + 1
            if length < minLength {
                minLength = length
            }
        }
    }
    
    return minLength
}
```在 Go 中，映射的使用方式与 Python 字典类似。 关键的区别在于，我们在设置第一次出现之前显式检查键是否存在，并且我们初始化`minLength`数组长度而不是无穷大，这在 Go 中更惯用。
