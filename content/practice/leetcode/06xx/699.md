[LeetCode 第 699 题](https://leetcode.com/problems/falling-squares/)

 **难度：** 🔴难
 **主题：** 数组、线段树、有序集

 ## 解决方案

 ## 问题理解

 该问题描述了落在 X 轴上的正方形的模拟。 每个方块由两个值表示：

 -`lefti`, 正方形左边缘的 X 坐标
 -`sideLengthi`，正方形的边长

 一个正方形占据区间：$$[lefti,\ lefti + sideLengthi)$$当一个正方形落下时，它会继续向下，直到发生以下两种情况之一：

 1.到达地面，即高度的X轴`0`2.它落在另一个水平重叠的正方形的顶部

 关键细节是接触边缘不算重叠。 仅当两个间隔共享正宽度时，它们才会重叠。 例如：

-`[1, 3)`和`[3, 5)`不要重叠
 -`[1, 4)`和`[2, 5)`重叠

 对于每个新方块：

 - 我们确定所有先前放置的水平重叠方块的最大高度
 - 新的广场落在那个高度的顶部
 - 其顶部高度变为：$$\text{base height} + \text{side length}$$放置每个方块后，我们记录迄今为止所看到的最高高度。 

输出数组应包含这些运行的最大高度。 

约束条件很重要：

 - 最多`1000`正方形
 - 坐标可以大到`10^8`大的坐标范围意味着我们无法构建由 X 坐标索引的巨大网格或高度数组。 然而，方格的数量相对较少，这表明直接比较区间是可行的。 

一个重要的观察结果是，每个方块仅与先前放置的水平重叠的方块相互作用。 不重叠的正方形是完全独立的。 

一些边缘情况可能会导致幼稚的实现失败：

 - 只接触边缘的方块不应该堆叠
 - 多个重叠的方块可能会形成高塔
 - 大坐标值会妨碍逐坐标模拟
 - 嵌套重叠可以产生级联高度增加
 - 不相交的区域必须保持不同的高度

 该问题保证了有效的正坐标和边长，因此我们永远不需要处理空方块或无效间隔。 

## 方法

 ### 蛮力方法

 最直接的方法是通过与所有先前放置的方块进行比较来模拟每个下落的方块。 

对于每个新方块：

 1. 计算其区间`[left, right)`2. 检查每个较早的方块
 3. 如果区间重叠，则确定其中的最大高度
 4. 将当前方块放置在最大高度之上
 5.记录更新后的全局最大值

 为了支持这一点，我们存储：

 - 左边界
 - 右边界
 - 顶部高度

 对于每个先前放置的方块。 

这种方法是正确的，因为每个方块的静止高度仅取决于先前放置的重叠方块。 由于正方形的数量只有`1000`，检查所有较早的方块在计算上是可以接受的。 

然而，对于较大的输入，这种方法变得低效，因为每个方块都可以与每个较早的方块进行比较。 

### 更好的洞察力

 重要的见解是我们并不独立关心每个 X 坐标。 我们只关心间隔和它们的最大高度。 

下降过程完全取决于区间重叠。 如果两个方块水平重叠，则后一个方块可能会堆叠在前一个方块的上面。 

我们可以将其视为区间最大值问题，而不是连续模拟几何：

 - 查询重叠区间的最大高度
 - 插入具有更新高度的新间隔

 具有坐标压缩的线段树是一种更具可扩展性的解决方案。 坐标压缩将大坐标映射到紧凑的索引范围，同时保留间隔关系。 

线段树允许：

 - 范围最大查询
 - 范围更新

 两者都是对数时间。 

虽然`O(n^2)`通过限制，线段树解决方案展示了解决这个难题的先进技术。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 将每个方块与之前的所有方块进行比较 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 与线段树协调压缩|

 ## 算法演练

 ### 坐标压缩

 坐标可以大到`10^8`，所以我们将它们压缩到更小的索引空间中。 

对于每个正方形：

 - 添加`left`- 添加`left + sideLength`到一组坐标。 

对这些坐标进行排序后，每个唯一坐标都会获得一个压缩索引。 

这保留了重叠关系，同时使线段树紧凑。 

### 线段树的目的

 线段树存储压缩区间的最大高度。 

它有效地支持两种操作：

 1.查询某个范围内的最大高度
 2. 将范围更新到新的高度

 ### 逐步算法

 1. 收集所有区间边界。 

对于每个正方形`[left, size]`，计算：$$right = left + size$$两者都添加`left`和`right`到一个坐标集。 
2. 对坐标进行排序并构建压缩图。 

每个唯一坐标接收一个整数索引。 
3. 初始化线段树。 

该树存储压缩间隔的最大高度。 
4. 一张一张地处理方块。 

对于每个正方形：

 - 计算压缩区间索引
 - 查询该区间内当前最大高度
 - 新高度变为：$$\text{base height} + \text{size}$$5.更新线段树。 

将整个间隔设置为新高度，因为正方形现在占据该水平范围。 
6. 跟踪全局最大高度。 

每次插入后，将当前最高高度附加到答案数组中。 

### 为什么它有效

 不变的是线段树总是存储每个压缩区间的正确的最大占用高度。 

当一个新的方块掉落时，它必须落在其下方最高的重叠结构上。 查询间隔最大值即可准确给出支撑高度。 之后更新间隔可确保未来的方块看到正确的地形。 

由于每个方块都是按时间顺序处理的，并且每次更新都会反映该方块的最终静止高度，因此该算法始终会生成正确的堆叠高度。 

## Python 解决方案```python
from typing import List

class SegmentTree:
    def __init__(self, size: int):
        self.size = size
        self.tree = [0] * (4 * size)
        self.lazy = [0] * (4 * size)

    def push(self, node: int):
        if self.lazy[node]:
            value = self.lazy[node]

            self.tree[node * 2] = max(self.tree[node * 2], value)
            self.tree[node * 2 + 1] = max(self.tree[node * 2 + 1], value)

            self.lazy[node * 2] = max(self.lazy[node * 2], value)
            self.lazy[node * 2 + 1] = max(self.lazy[node * 2 + 1], value)

            self.lazy[node] = 0

    def update(
        self,
        node: int,
        left: int,
        right: int,
        query_left: int,
        query_right: int,
        value: int,
    ) -> None:
        if query_left > right or query_right < left:
            return

        if query_left <= left and right <= query_right:
            self.tree[node] = max(self.tree[node], value)
            self.lazy[node] = max(self.lazy[node], value)
            return

        self.push(node)

        mid = (left + right) // 2

        self.update(
            node * 2,
            left,
            mid,
            query_left,
            query_right,
            value,
        )

        self.update(
            node * 2 + 1,
            mid + 1,
            right,
            query_left,
            query_right,
            value,
        )

        self.tree[node] = max(
            self.tree[node * 2],
            self.tree[node * 2 + 1],
        )

    def query(
        self,
        node: int,
        left: int,
        right: int,
        query_left: int,
        query_right: int,
    ) -> int:
        if query_left > right or query_right < left:
            return 0

        if query_left <= left and right <= query_right:
            return self.tree[node]

        self.push(node)

        mid = (left + right) // 2

        return max(
            self.query(
                node * 2,
                left,
                mid,
                query_left,
                query_right,
            ),
            self.query(
                node * 2 + 1,
                mid + 1,
                right,
                query_left,
                query_right,
            ),
        )

class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        coordinates = set()

        for left, size in positions:
            coordinates.add(left)
            coordinates.add(left + size)

        sorted_coords = sorted(coordinates)

        coordinate_index = {
            coordinate: index
            for index, coordinate in enumerate(sorted_coords)
        }

        segment_tree = SegmentTree(len(sorted_coords))

        result = []
        tallest = 0

        for left, size in positions:
            right = left + size

            left_index = coordinate_index[left]
            right_index = coordinate_index[right] - 1

            base_height = segment_tree.query(
                1,
                0,
                len(sorted_coords) - 1,
                left_index,
                right_index,
            )

            new_height = base_height + size

            segment_tree.update(
                1,
                0,
                len(sorted_coords) - 1,
                left_index,
                right_index,
                new_height,
            )

            tallest = max(tallest, new_height)
            result.append(tallest)

        return result
```实现从坐标压缩开始。 由于坐标可能非常大，因此压缩会将稀疏坐标值转换为密集索引。 

这`SegmentTree`类管理间隔高度。 这`query`方法检索范围内的最大高度，而`update`方法在一个区间上分配一个新的高度。 

使用延迟传播以便范围更新保持高效。 更新被推迟到必要时，而不是单独更新每个叶子。 

对于每个正方形：

 1.我们确定其压缩区间
 2、查询其下方当前最大高度
 3. 计算新的顶部高度
 4.更新占用区间
 5.记录运行最大值

 这直接反映了问题中描述的物理坠落过程。 

## 解决方案```go
package main

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

type SegmentTree struct {
	tree []int
	lazy []int
	size int
}

func NewSegmentTree(size int) *SegmentTree {
	return &SegmentTree{
		tree: make([]int, 4*size),
		lazy: make([]int, 4*size),
		size: size,
	}
}

func (st *SegmentTree) push(node int) {
	if st.lazy[node] != 0 {
		value := st.lazy[node]

		st.tree[node*2] = max(st.tree[node*2], value)
		st.tree[node*2+1] = max(st.tree[node*2+1], value)

		st.lazy[node*2] = max(st.lazy[node*2], value)
		st.lazy[node*2+1] = max(st.lazy[node*2+1], value)

		st.lazy[node] = 0
	}
}

func (st *SegmentTree) update(
	node, left, right,
	queryLeft, queryRight,
	value int,
) {
	if queryLeft > right || queryRight < left {
		return
	}

	if queryLeft <= left && right <= queryRight {
		st.tree[node] = max(st.tree[node], value)
		st.lazy[node] = max(st.lazy[node], value)
		return
	}

	st.push(node)

	mid := (left + right) / 2

	st.update(
		node*2,
		left,
		mid,
		queryLeft,
		queryRight,
		value,
	)

	st.update(
		node*2+1,
		mid+1,
		right,
		queryLeft,
		queryRight,
		value,
	)

	st.tree[node] = max(
		st.tree[node*2],
		st.tree[node*2+1],
	)
}

func (st *SegmentTree) query(
	node, left, right,
	queryLeft, queryRight int,
) int {
	if queryLeft > right || queryRight < left {
		return 0
	}

	if queryLeft <= left && right <= queryRight {
		return st.tree[node]
	}

	st.push(node)

	mid := (left + right) / 2

	return max(
		st.query(
			node*2,
			left,
			mid,
			queryLeft,
			queryRight,
		),
		st.query(
			node*2+1,
			mid+1,
			right,
			queryLeft,
			queryRight,
		),
	)
}

func fallingSquares(positions [][]int) []int {
	coordinates := map[int]bool{}

	for _, position := range positions {
		left := position[0]
		size := position[1]

		coordinates[left] = true
		coordinates[left+size] = true
	}

	sortedCoords := make([]int, 0, len(coordinates))

	for coordinate := range coordinates {
		sortedCoords = append(sortedCoords, coordinate)
	}

	for i := 0; i < len(sortedCoords); i++ {
		for j := i + 1; j < len(sortedCoords); j++ {
			if sortedCoords[j] < sortedCoords[i] {
				sortedCoords[i], sortedCoords[j] =
					sortedCoords[j], sortedCoords[i]
			}
		}
	}

	coordinateIndex := map[int]int{}

	for index, coordinate := range sortedCoords {
		coordinateIndex[coordinate] = index
	}

	segmentTree := NewSegmentTree(len(sortedCoords))

	result := []int{}
	tallest := 0

	for _, position := range positions {
		left := position[0]
		size := position[1]
		right := left + size

		leftIndex := coordinateIndex[left]
		rightIndex := coordinateIndex[right] - 1

		baseHeight := segmentTree.query(
			1,
			0,
			len(sortedCoords)-1,
			leftIndex,
			rightIndex,
		)

		newHeight := baseHeight + size

		segmentTree.update(
			1,
			0,
			len(sortedCoords)-1,
			leftIndex,
			rightIndex,
			newHeight,
		)

		tallest = max(tallest, newHeight)
		result = append(result, tallest)
	}

	return result
}
```Go 实现遵循与 Python 版本相同的结构，但一些特定于语言的差异值得注意。 

Go没有提供内置的线段树结构，因此树和惰性数组是手动管理的。 使用切片而不是 Python 列表。 

因为 Go 缺乏内置的`max`对于整数函数，定义了一个辅助函数。 

地图用于坐标压缩，排序是手动实现的，以保持解决方案的独立性。 在生产代码中，`sort.Ints`通常会更好。 

所有算术都可以安全地适合 Go 的范围`int`给定约束下的类型。

from typing import List

class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        intervals = []
        result = []
        tallest = 0

        for left, size in positions:
            right = left + size

            base_height = 0

            for prev_left, prev_right, prev_height in intervals:
                if left < prev_right and right > prev_left:
                    base_height = max(base_height, prev_height)

            new_height = base_height + size

            intervals.append((left, right, new_height))

            tallest = max(tallest, new_height)
            result.append(tallest)

        return result

 ## 边缘情况

 ### 仅在边缘接触的正方形

 一个非常常见的错误是将触摸间隔视为重叠。 

例如：```
[1,3) and [3,5)
```共享一个端点，但没有正宽度重叠。 

该实现使用以下方法正确检查重叠：```
left < prev_right and right > prev_left
```这可确保边缘接触的方块不会堆叠。 

### 完全嵌套的方块

 较小的正方形可能完全落在较大正方形的水平跨度内。 

例子：```
[[1,5],[2,2]]
```第二个正方形与第一个正方形完全重叠，并且必须堆叠在其顶部。 

该算法自然地处理这个问题，因为无论包含关系如何，范围最大查询都会返回最高的重叠高度。 

### 大稀疏坐标

 坐标可以非常大，例如`10^8`。 

一个简单的逐坐标高度数组不可能有效地分配。 

坐标压缩通过仅存储重要的边界点来解决这个问题，将问题的大小从潜在的数亿个坐标减少到最多`2n`独特的端点。
