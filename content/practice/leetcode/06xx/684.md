 ## 解决方案

 ## 问题理解

 问题是要求我们识别以树开始的图中的冗余边。 树是一个连通图`n`节点并且准确地`n-1`边缘，意味着它没有循环。 输入图有`n`节点和`n`边，因此根据定义，它恰好包含一个循环。 额外的边缘是创建此循环的边缘，我们的任务是识别它。 

输入是边数组，其中每条边表示为一对`[ai, bi]`连接的节点。 预期输出是该数组中的一条边，特别是如果删除该边，则会恢复树属性（连通且非循环）的边。 如果可以删除多个边，则应返回输入数组中最后出现的边。 

约束条件澄清了`n`最多 1000，这排除了效率极低的暴力方法。 每个节点都被标记为从 1 到`n`，边是唯一的，图总是连通的。 这些保证简化了问题：我们不需要检查断开的组件或重复的边。 

需要注意的边缘情况包括具有 3 个节点的最小树（尽可能小的循环）、连接具有高索引的节点的边，以及涉及多个节点的循环，其中必须返回输入中的最后一条边。 如果不注意“最后一个边缘”的要求，这些可能会导致简单的 DFS 实现失败。 

## 方法

 暴力方法会尝试依次删除每条边并检查剩余的图是否是树。 这可以通过在移除每条边后执行 DFS 或 BFS 检查连接性和循环来完成。 虽然正确，但此方法很慢：对于`n`边，通过 DFS 检查连通性是`O(n)`每次移除都会导致`O(n^2)`总体时间复杂度。 给定上限`n = 1000`，这可能效率低下。 

关键的见解是，当同一连接组件中的两个节点连接时，就会形成循环。 Union-Find（不相交集并集）是一种数据结构，旨在有效跟踪连接的组件并检测循环。 当我们迭代边时，如果一条边的两个节点已经连接，添​​加这条边将形成一个循环，使其成为冗余连接。 这种方法利用了图的非循环性质并且非常高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 删除每条边，然后使用 DFS/BFS 检查连通性 |
 | 并查（最优）| O(n α(n)) | O(n α(n)) | O(n) | 有效跟踪连通分量，α(n) 是阿克曼反函数 |

 ## 算法演练

 1. 为所有初始化一个并查（不相交集并集）结构`n`节点。 每个节点都作为其自己的父节点开始，代表一个单独的组件。 
2. 迭代每条边`[u, v]`在输入数组中。 
3. 对于每条边，使用并查`find`确定两个节点的根（代表）的操作`u`和`v`。 
4. 如果根相同，则节点已经连接。 添加这条边会形成环路，因此是冗余连接。 返回`[u, v]`。 
5. 如果根不同，则使用并查集将两个分量合并`union`操作，连接它们的组件而不形成循环。 
6. 继续，直到处理完所有边缘。 根据问题保证，恰好一个边沿会引起循环，并且会被检测到。 

**为什么起作用：** Union-Find 保持了同一组件中的节点共享相同根的不变式。 当一条边连接具有相同根的两个节点时，可以精确地检测到循环，从而确保我们根据需要返回导致循环的最后一条边。 

## Python 解决方案```python
from typing import List

class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        parent = list(range(len(edges) + 1))
        
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x: int, y: int) -> bool:
            root_x, root_y = find(x), find(y)
            if root_x == root_y:
                return False
            parent[root_y] = root_x
            return True
        
        for u, v in edges:
            if not union(u, v):
                return [u, v]
```该实现初始化一个`parent`代表每个节点的根的数组。 这`find`函数执行路径压缩以提高效率。 这`union`函数连接两个组件并返回`False`如果它们已经连接，则发出循环信号。 主循环迭代边缘并立即返回导致循环的第一个边缘，该边缘对应于创建循环的输入中的最后一个边缘。 

## 解决方案```go
func findRedundantConnection(edges [][]int) []int {
    parent := make([]int, len(edges)+1)
    for i := range parent {
        parent[i] = i
    }

    var find func(int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }

    union := func(x, y int) bool {
        rootX, rootY := find(x), find(y)
        if rootX == rootY {
            return false
        }
        parent[rootY] = rootX
        return true
    }

    for _, edge := range edges {
        if !union(edge[0], edge[1]) {
            return edge
        }
    }
    return nil
}
```在 Go 中，我们同样维护一个`parent`用于并查找的切片。 这`find`函数递归压缩路径，并且`union`合并组件或在检测到循环时返回 false。 该解决方案直接反映了 Python 逻辑，以惯用的方式处理切片索引和函数闭包。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n α(n)) | O(n α(n)) | 每个`find`由于路径压缩，接近 O(1)； 迭代边是 O(n) |
 | 空间| O(n) | 父数组存储组件代表`n`节点 |

 具有路径压缩的并查找结构可确保几乎恒定时间的并和查找操作。 空间随节点数量线性扩展，在给定约束的情况下，节点数量足够小。
