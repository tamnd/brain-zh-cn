[LeetCode 第 623 题](https://leetcode.com/problems/add-one-row-to-tree/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、广度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题要求我们通过添加具有给定值的新节点行来修改二叉树`val`在指定深度`depth`。 输入由二叉树的根、整数值组成`val`插入，以及目标深度`depth`。 Depth is defined such that the root of the tree is at depth`1`。 

如果`depth`是`1`，我们没有“深度为1”的父节点来附加新节点，因此新节点成为新的根，原始树成为其左子树。 否则，对于深度处的每个节点`depth - 1`，我们插入两个新节点作为其子节点，原始子节点成为这些新节点的子节点。 树结构保留在插入的行下方。 

约束表明树最多可以有`10^4`节点和深度可达`10^4`。 节点值的范围为`-100`到`100`，而新的行值可以是`-10^5`到`10^5`。 由于默认的递归限制，这确保了 Python 中可以考虑递归深度。 

重要的边缘情况包括在根添加（`depth == 1`）、只有左子节点或只有右子节点的树，以及深度等于最大深度加一的树。 

## 方法

 暴力方法将完全遍历树，访问每个节点，并检查位于`depth - 1`。 对于每个符合条件的节点，我们将创建具有值的新左子节点和右子节点`val`并相应地附加原始子项。 这可以正确工作，但在概念上并不是最佳的遍历方式； 简单的递归 DFS 效果很好，但 BFS 对于基于级别的插入可能更直观。 

关键的见解是我们不需要遍历整个树来查找下面的节点`depth - 1`。 层序遍历 (BFS) 允许精确停止于`depth - 1`并有效地插入新节点。 DFS 也可以工作，一旦达到目标深度就停止递归。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 暴力DFS | O(N) | O(H) | 递归访问每个节点，深度插入新节点`depth`。 H为树高。 |
 | BFS / 最优 | O(N) | O(W) | 层序遍历在深度1处停止，使用队列。 W 是树的最大宽度。 |

 ## 算法演练

 1. 处理边缘情况`depth == 1`首先：创建一个具有值的新节点`val`，将其左子节点设置为原始根，并将这个新节点作为新根返回。 
2. 初始化一个队列，根节点和当前深度为`1`。 
3. 进行层序遍历，直到到达节点`depth - 1`。 
4. 对于每个节点`depth - 1`，创建一个新的左节点和一个新的右节点，其值为`val`。 
5. 将当前节点原来的左子节点设置为新左节点的左子节点。 
6. 将当前节点原来的右子节点设置为新右节点的右子节点。 
7. 将新节点附加到当前节点。 
8. 继续直到所有节点位于`depth - 1`被处理。 
9. 返回修改后的树。 

为什么它起作用：该算法保持了深度小于的任何节点的不变量`depth - 1`未受影响，并且新节点正确连接到指定深度。 通过停止遍历`depth - 1`，不会对更深的节点进行不必要的修改。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def addOneRow(self, root: Optional[TreeNode], val: int, depth: int) -> Optional[TreeNode]:
        if depth == 1:
            new_root = TreeNode(val)
            new_root.left = root
            return new_root
        
        queue = deque([(root, 1)])
        
        while queue:
            node, curr_depth = queue.popleft()
            
            if curr_depth == depth - 1:
                old_left, old_right = node.left, node.right
                node.left = TreeNode(val)
                node.right = TreeNode(val)
                node.left.left = old_left
                node.right.right = old_right
            else:
                if node.left:
                    queue.append((node.left, curr_depth + 1))
                if node.right:
                    queue.append((node.right, curr_depth + 1))
        
        return root
```该实现首先处理新行成为根的特殊情况。 否则，它使用队列进行级别顺序遍历。 当到达节点时`depth - 1`，它用新节点替换它们的子节点，同时保留现有的子树。 所有其他节点只是排队等待将来处理。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func addOneRow(root *TreeNode, val int, depth int) *TreeNode {
    if depth == 1 {
        return &TreeNode{Val: val, Left: root}
    }
    
    queue := []*TreeNode{root}
    currDepth := 1
    
    for len(queue) > 0 {
        size := len(queue)
        if currDepth == depth-1 {
            for i := 0; i < size; i++ {
                node := queue[i]
                oldLeft := node.Left
                oldRight := node.Right
                node.Left = &TreeNode{Val: val, Left: oldLeft}
                node.Right = &TreeNode{Val: val, Right: oldRight}
            }
            break
        } else {
            for i := 0; i < size; i++ {
                node := queue[0]
                queue = queue[1:]
                if node.Left != nil {
                    queue = append(queue, node.Left)
                }
                if node.Right != nil {
                    queue = append(queue, node.Right)
                }
            }
            currDepth++
        }
    }
    
    return root
}
```Go 版本密切反映了 Python 逻辑。 差异包括队列的显式切片处理和直接结构初始化。 不需要类型提示系统，并且`nil`代表失踪儿童。 

## 工作示例

 **示例 1：** root = [4,2,6,3,1,5]，val = 1，深度 = 2

 | 步骤| 队列| 行动|
 | --- | --- | --- |
 | 1 | [(4,1)] | 深度！= 1，继续|
 | 2 | 流行 (4,1) | curr_深度 = 1 == 深度-1 → 向左/右插入新节点 1，附加旧的子节点 |
 | 3 | 队列空 | 返回修改后的树 |

 结果：[4,1,1,2,空,空,6,3,1,5]

 **示例 2：** root = [4,2,null,3,1]，val = 1，深度 = 3

 | 步骤| 队列| 行动|
 | --- | --- | --- |
 | 1 | [(4,1)] | curr_深度 < 深度-1 → 队列子级 (2) |
 | 2 | 流行 (2,2) | curr_深度 = 2 == 深度-1 → 将新节点 1 作为左/右插入，附加旧子节点 3 和 1 |
 | 3 | 队列空 | 返回修改后的树 |

 结果：[4,2,空,1,1,3,空,空,1]

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N) | 每个节点都会被访问一次以检查深度或附加新节点。 |
 | 空间| O(W) | 队列最多存储树的宽度。 DFS 递归将使用 O(H)。 |

 该算法的效率来自于一旦我们修改了节点就停止遍历`depth - 1`，避免不必要的更深层次的递归。
