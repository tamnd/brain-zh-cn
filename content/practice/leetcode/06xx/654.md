 ## 解决方案

 ## 问题理解

 该问题要求我们从给定的整数数组构造一个**最大二叉树**`nums`具有独特的元素。 最大二叉树是一棵二叉树，其中每个节点都是它所代表的子数组的**最大元素**。 具体来说，树的根是整个数组中最大的元素。 根的左子树是该最大值**左边**的所有元素的最大二叉树，右子树是该最大值**右边**的所有元素的最大二叉树。 

输入是一个整数数组`nums`约束条件是所有元素都是唯一的，数组长度范围为 1 到 1000。输出是二叉树的根，表示根据上述规则构建的最大二叉树。 每个树节点都有一个值、一个左子节点和一个右子节点，其中任一子节点都可以是`None`如果没有对应的子树。 

重要的边缘情况包括长度为 1 的数组（树只是一个节点）、严格递增或严格递减数组（树分别向右或向左倾斜）以及最大值出现在边缘的数组。 

唯一性保证简化了问题，因为我们不需要处理重复项，否则会使子树决策变得复杂。 

## 方法

 **暴力方法**是递归地找到当前子数组中的最大元素，用该值创建一个节点，然后从子数组到最大值的左右递归构建左子树和右子树。 这种方法之所以有效，是因为它直接实现了问题的递归定义，但效率较低，因为每次查找最大值都需要扫描子数组。 对于长度的数组`n`，第一次扫描是`O(n)`，接下来的左右扫描较小，但仍然总结为`O(n^2)`在最坏的情况下，尤其是对于排序数组。 

更**优化的方法**使用**单调堆栈**。 我们的见解是，我们可以通过以**降序**维护一堆节点来迭代地构造树。 对于每个元素，我们从堆栈中弹出小于当前元素的元素，并将它们分配为当前节点的左子节点。 如果此后堆栈不为空，则当前节点成为堆栈顶部的右子节点。 这确保每个节点在**线性时间内**找到其正确的父节点，因为每个元素最多被推送和弹出一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 递归查找子数组中的最大值； 对于排序数组来说很慢|
 | 最佳| O(n) | O(n) | 单调堆栈确保每个元素都被处理一次 |

 ## 算法演练

 1. 初始化一个空栈来保存节点。 
2. 迭代每个元素`num`在`nums`。 
3.创建新的树节点`node`为了`num`。 
4. 当栈不为空且栈顶节点的值小于`num`，弹出它并将其指定为`node.left`。 这确保较小的元素成为下一个较大元素的左子元素。 
5.如果出栈后栈不为空，则将顶节点的右子节点设置为`node`。 这确保了`node`正确附加到其父级。 
6. 推`node`到堆栈上。 
7. 处理完所有元素后，树的根是堆栈中的第一个元素（最底部的元素）。 

**为什么起作用：** 堆栈维护节点的递减顺序，确保当新的最大值到达时，所有较小的节点都作为左子节点附加到它，从而保留最大二叉树属性。 最终堆栈包含与最大二叉树定义一致的父子关系的层次结构。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        stack = []
        for num in nums:
            node = TreeNode(num)
            while stack and stack[-1].val < num:
                node.left = stack.pop()
            if stack:
                stack[-1].right = node
            stack.append(node)
        return stack[0] if stack else None
```该实现迭代数组，维护一个堆栈来跟踪尚未确定父级的节点。 较小的节点将被弹出并指定为当前节点的左子节点，而堆栈顶部的剩余节点（如果有）将成为当前节点的父节点。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func constructMaximumBinaryTree(nums []int) *TreeNode {
    stack := []*TreeNode{}
    for _, num := range nums {
        node := &TreeNode{Val: num}
        for len(stack) > 0 && stack[len(stack)-1].Val < num {
            node.Left = stack[len(stack)-1]
            stack = stack[:len(stack)-1]
        }
        if len(stack) > 0 {
            stack[len(stack)-1].Right = node
        }
        stack = append(stack, node)
    }
    if len(stack) == 0 {
        return nil
    }
    return stack[0]
}
```在 Go 中，我们处理切片而不是 Python 列表，并且`nil`表示不存在子节点。 该逻辑完全反映了 Python 解决方案，通过对堆栈进行重新切片来实现弹出。

 ## 边缘情况

 第一个边缘情况是具有**单个元素**的数组。 这是差一错误的潜在来源，因为没有子数组。 我们的解决方案正确返回没有任何子节点的单个节点。 

第二种边缘情况是**严格递增数组**，它会生成左偏树。 简单的递归解决方案可能会低效地重复扫描每个子数组，但基于堆栈的方法可以线性处理此问题，因为每个元素都会成为下一个较大元素的左子元素。 

第三种边缘情况是一个**严格递减数组**，它会生成右偏树。 单调堆栈确保不分配左子节点，并且每个节点都作为其前任节点的右子节点连接，避免不必要的递归调用或不正确的树结构
