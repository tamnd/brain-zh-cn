[LeetCode 第 687 题](https://leetcode.com/problems/longest-univalue-path/)

 **难度：** 🟡 中等
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们找到**二叉树中的最长路径，其中路径上的每个节点都具有相同的值**。 关键细节是路径长度是以**边**而不是节点来测量的。 此外，路径*​​不需要经过根**，这意味着最长的有效路径可以完全存在于子树内部。 

输入是`root`的二叉树。 每个节点包含一个整数值和指向左子节点和右子节点的指针。 我们的任务是返回一个整数，表示所有连接节点共享相同值的任何路径中的最大边数。 

二叉树中的路径不必仅向下移动。 它可以从一个孩子，一直到父母，然后再到另一个孩子。 例如，有效路径可以通过公共父节点将左子树的节点连接到右子树，只要该路径上的每个节点都具有相同的值即可。 

这些约束为解决方案设计提供了重要指导：

 - 树最多包含`10^4`节点，它足够大，以至于重复遍历子树可能会太慢。 
- 树的深度不超过`1000`，这表明递归在大多数环境中是安全的，尽管它接近 Python 的递归限制。 
- 节点值范围为`-1000`到`1000`，但实际值并不是特别重要，因为我们只比较相等性。 

预先识别一些边缘情况很重要。 

一棵空树（`root = None`）应该返回`0`，因为没有节点，因此也没有边。 

一棵只有一个节点的树也应该返回`0`，因为单个节点不包含边。 

应该返回所有值都不同的树`0`，因为没有两个相邻节点可以形成单值路径。 

最长路径完全存在于子树内部而不是通过根的树可以很容易地破坏仅考虑涉及根的路径的幼稚实现。 

最后，因为路径可以通过父级组合左分支和右分支，所以我们必须仔细区分：

 1.向上传递到父级的最佳路径。 
2. 在树中任意位置找到的最佳路径。 

这些并不总是相同的值。 

## 方法

 ### 蛮力方法

 强力解决方案会将每个节点视为单值路径的潜在中心，并尝试计算从该节点到其后代的最大同值扩展。 

对于每个节点，我们可以递归地探索左子节点和右子节点，以确定同值链延伸多远。 然后，我们将结合这些长度来计算通过当前节点的最长路径。 

问题是冗余。 同一子树会从不同的祖先处重复重新计算。 例如，如果子树以节点为根`x`被评估多次，我们重复计算相同的向下路径长度。 

由于每个节点都可能触发对树的大部分的遍历，因此在倾斜树中，整体复杂性可能会降级为 **O(N²)**。 

这种方法是正确的，因为它最终会检查每个可能的单值路径，但对于输入大小而言效率较低。 

### 最佳解决方案的关键见解

 关键的观察结果是，该问题具有重叠的子问题结构，该结构自然地适合**后序深度优先搜索（DFS）**。 

在每个节点，我们想知道：

 > “从该节点开始且所有值都相同的最长向下路径是什么？”

 该信息可以从其子项计算得出。 

对于给定节点：

 - 首先，递归计算左子节点的最长同值扩展。 
- 然后对右孩子进行相同的计算。 
- 如果子节点与当前节点具有相同的值，则扩展该路径。 
- 否则，该孩子的贡献为零。 

重要的认识是：

 - 向上返回给父级的值必须代表**仅一个方向**，要么左要么右，因为向上传递的路径不能分支。 
- 但是节点处的全局答案可能会结合**左右贡献**，从而创建通过当前节点的更长路径。 

这使我们能够一次性处理每个节点。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N²) | O(H) | 反复重新计算子树信息 |
 | 最优 DFS | O(N) | O(H) | 单后序遍历，增量计算答案 |

 这里，`N`是节点数，`H`是树的高度。 

## 算法演练

 1. 初始化变量`longest_path`到`0`。 这存储在树中任何位置找到的最大单值路径长度。 
2. 定义递归 DFS 辅助函数。 该函数的目的是返回**从当前节点开始的最长向下同值路径**。 
3. 如果当前节点是`None`， 返回`0`。 空节点不贡献任何路径。 
4. 递归计算左右子节点的最长同值路径。 
5.初始化两个变量，`left_path`和`right_path`， 到`0`。 
6. 如果左子节点存在并且与当前节点具有相同的值，则通过以下方式扩展左贡献：`left_path = left_length + 1`这`+1`表示连接当前节点和子节点的边。 
7. 对右孩子应用相同的逻辑。 
8、此时经过当前节点的最长路径为：`left_path + right_path`这是有效的，因为有效路径可以从左子树开始，通过当前节点，进入右子树。 
9. 更新全局最大值：`longest_path = max(longest_path, left_path + right_path)`10. 返回两个方向中较长的一个：`max(left_path, right_path)`这是必要的，因为父母只能继续一条向上的道路。 

### 为什么它有效

 该算法之所以有效，是因为每个 DFS 调用都会计算一个精确的不变量：

 > 辅助函数始终返回从当前节点开始的最长的向下单值链。 

由于每个节点将来自其子节点的信息恰好组合一次，因此会考虑每个可能的单值路径。 全局最大值确保保留完全在子树内的路径，同时仅向上返回较长的分支，以防止父路径中的无效分支。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def longestUnivaluePath(self, root: Optional[TreeNode]) -> int:
        longest_path = 0

        def dfs(node: Optional[TreeNode]) -> int:
            nonlocal longest_path

            if node is None:
                return 0

            left_length = dfs(node.left)
            right_length = dfs(node.right)

            left_path = 0
            right_path = 0

            if node.left and node.left.val == node.val:
                left_path = left_length + 1

            if node.right and node.right.val == node.val:
                right_path = right_length + 1

            longest_path = max(
                longest_path,
                left_path + right_path
            )

            return max(left_path, right_path)

        dfs(root)
        return longest_path
```该实现遵循前面描述的后序 DFS 策略。 

变量`longest_path`全局存储最佳答案。 由于递归助手仅返回向上的单向路径，因此我们需要一个单独的变量来保留通过中间节点分支的路径。 

这`dfs`函数首先递归处理左子节点和右子节点。 这种排序很重要，因为在计算当前节点的贡献之前，我们必须已经知道最佳的向下同值路径。 

在收到孩子们的结果后，我们决定是否可以延长这些路径。 如果子节点的值与当前节点的值匹配，我们将添加一条边以继续该路径。 否则，贡献重置为零。 

全局答案使用更新`left_path + right_path`，因为通过当前节点的最佳路径可能会结合两个方向。 

最后，该函数返回两个分支中较大的一个，因为只有一个方向可以继续向上到达父级。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func longestUnivaluePath(root *TreeNode) int {
    longestPath := 0

    var dfs func(node *TreeNode) int

    dfs = func(node *TreeNode) int {
        if node == nil {
            return 0
        }

        leftLength := dfs(node.Left)
        rightLength := dfs(node.Right)

        leftPath := 0
        rightPath := 0

        if node.Left != nil && node.Left.Val == node.Val {
            leftPath = leftLength + 1
        }

        if node.Right != nil && node.Right.Val == node.Val {
            rightPath = rightLength + 1
        }

        if leftPath+rightPath > longestPath {
            longestPath = leftPath + rightPath
        }

        if leftPath > rightPath {
            return leftPath
        }

        return rightPath
    }

    dfs(root)

    return longestPath
}
```Go 实现密切反映了 Python 逻辑。 由于Go不支持`nonlocal`，变量`longestPath`自然地被闭包捕获。`nil`被用来代替`None`，并且在访问子值之前需要显式的指针检查。 

不存在整数溢出问题，因为最大边数受节点数限制，最多`10^4`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N) | 每个节点都被访问一次 |
 | 空间| O(H) | 递归栈取决于树的高度 |

 该算法对树执行一次 DFS 遍历。 每个节点在访问其子节点后仅执行常量工作，从而使运行时间与节点数量成线性关系。 

辅助空间来自递归栈。 在平衡树中这是`O(log N)`，而在完全倾斜的树的最坏情况下，它变成`O(N)`。

 ## 边缘情况

 ### 空树

 空树不包含节点，因此也不包含边。 有缺陷的实现可能会尝试递归而不检查`None`，导致运行时错误。 此实现可以安全地处理它，因为 DFS 基本情况立即返回`0`对于空节点。 

### 单节点树

 一棵只有一个节点的树看起来应该返回`1`，但问题衡量的是**边缘**，而不是节点。 由于没有边，所以正确答案是`0`。 该实现自然会处理这个问题，因为叶节点返回零长度路径。 

### 最长路径不包括根

 一个常见的错误是假设最佳路径必须涉及根节点。 实际上，最优路径可能完全存在于子树内。 全球`longest_path`变量通过更新每个节点（而不仅仅是根节点）的答案来防止此问题。 

### 通过节点的分支路径

 当左子节点和右子节点都匹配当前节点值时，会发生另一种微妙的情况。 该路径可以在两个方向上延伸通过父级。 然而，只有一根分支可以向上延续到祖先。 该实现通过使用两侧更新全局最大值来正确处理这种区别，同时仅返回向上的最大单个分支。
