## 问题理解

 该问题要求我们使用从无限量的给定贴纸中剪切下来的字母来构造一个目标字符串，其中每个贴纸都是一个小写单词。 您可以多次重复使用贴纸并自由重新排列字母。 目标是找到形成目标所需的**最小贴纸数量**。 如果不可能，我们就必须返回`-1`。 

输入由一个列表组成`stickers`（每个单词都有小写字母）和一个字符串`target`。 限制是最多有 50 个贴纸，每个贴纸最多有 10 个字符，目标最多有 15 个字符。 这些限制表明，对贴纸的所有排列进行天真的详尽搜索可能会太慢，我们应该利用**记忆化**或**位掩码**等优化。 

需要考虑的关键边缘情况包括：

 - 目标包含任何贴纸中不存在的字母，应该返回`-1`。 
- 目标或贴纸包含重复字母，可能需要多次使用同一张贴纸。 
- 目标本身是空的，应该返回`0`因为不需要贴纸。 

## 方法

 ### 蛮力

 简单的暴力解决方案会递归地尝试所有可能的贴纸组合。 对于每个递归步骤，您从当前目标中减去所选贴纸的字母并继续，直到目标为空。 虽然这保证了正确性，但速度非常慢，因为可能的贴纸组合数量随着目标长度和贴纸数量呈指数增长。 如果贴纸数量最多为 50 个，目标长度为 15，则递归树将非常大。 

### 最佳方法

 关键的见解是，可以使用**带有频率计数器的记忆**有效地解决该问题。 我们不是跟踪字符串中的单个字母，而是将目标转换为字母的频率计数。 每个贴纸也表示为频率图。 然后，我们递归地尝试使用贴纸来减少剩余目标，同时记住先前计算的子问题。 

另一种优化是仅考虑对当前目标有贡献的贴纸（即目标中至少包含一个字母）。 这减少了不必要的计算。 

通过将中间结果存储在以剩余字母（作为字符串或计数元组）为键的哈希图中，我们可以避免重新计算，从而将解决方案从指数复杂度降低到可管理的时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^m) | O(n^m) | O(米) | 递归尝试所有贴纸组合，以目标长度 m 为指数 |
 | 最佳| O(2^m * n * 26) | O(2^m * n * 26) | O(2^m) | O(2^m) | 使用带有频率计数器的记忆，仅计算目标的每个子集一次 |

 ## 算法演练

 1. 将每个贴纸转换为大小为 26 的频率数组，表示“a”到“z”的计数。 这允许恒定时间减法并与目标频率进行比较。 
2. 定义递归函数`dp(remaining)`在哪里`remaining`是字符串形式的当前目标。 如果`remaining`为空，返回0。 
3. 检查是否`remaining`已在备忘录字典中计算。 如果是，则返回存储的结果。 
4. 初始化`min_stickers`到无穷大。 对于每个贴纸，检查它是否包含第一个字符`remaining`。 如果没有，请跳过它。 
5. 减去贴纸上的字母`remaining`来形成一个新的`next_remaining`细绳。 递归调用`dp(next_remaining)`并为当前贴纸添加 1。 更新`min_stickers`与最小值。 
6. 存储计算结果`min_stickers`在备忘录字典中键入`remaining`。 
7. 返回`-1`如果`min_stickers`是无穷大（即无解），否则返回`min_stickers`。 

**为什么它有效**：

 记忆确保每个唯一的字母子集仅计算一次，避免指数重新计算。 通过始终减去贴纸字母并仅考虑贡献贴纸，递归有效地将可能的解决方案缩小到最小贴纸数量。 

## Python 解决方案```python
from collections import Counter
from typing import List

class Solution:
    def minStickers(self, stickers: List[str], target: str) -> int:
        n = len(stickers)
        sticker_counts = [Counter(sticker) for sticker in stickers]
        memo = {}

        def dp(remaining: str) -> int:
            if not remaining:
                return 0
            if remaining in memo:
                return memo[remaining]

            target_count = Counter(remaining)
            min_stickers = float('inf')

            for sticker in sticker_counts:
                if sticker[remaining[0]] == 0:
                    continue

                new_remaining = ''
                for ch in target_count:
                    if target_count[ch] > sticker[ch]:
                        new_remaining += ch * (target_count[ch] - sticker[ch])

                res = dp(new_remaining)
                if res != -1:
                    min_stickers = min(min_stickers, 1 + res)

            memo[remaining] = -1 if min_stickers == float('inf') else min_stickers
            return memo[remaining]

        return dp(target)
```**说明**：

 我们首先将贴纸转换为频率计数器，以进行 O(1) 的字母查找。 递归`dp`函数计算给定的最小贴纸`remaining`细绳。 仅考虑对第一个角色有贡献的贴纸。 贴上贴纸后，我们形成一个新的`remaining`字符串并递归地解决它。 记忆化确保每个唯一的字符串都被计算一次。 

## 解决方案```go
package main

func minStickers(stickers []string, target string) int {
    n := len(stickers)
    stickerCounts := make([][26]int, n)
    for i, s := range stickers {
        for _, ch := range s {
            stickerCounts[i][ch-'a']++
        }
    }

    memo := map[string]int{}

    var dp func(string) int
    dp = func(remaining string) int {
        if remaining == "" {
            return 0
        }
        if val, ok := memo[remaining]; ok {
            return val
        }

        targetCount := [26]int{}
        for _, ch := range remaining {
            targetCount[ch-'a']++
        }

        minStickers := 1 << 30
        for _, sticker := range stickerCounts {
            if sticker[remaining[0]-'a'] == 0 {
                continue
            }

            newRemaining := ""
            for i := 0; i < 26; i++ {
                if targetCount[i] > sticker[i] {
                    newRemaining += string(rune('a' + i)) * (targetCount[i] - sticker[i])
                }
            }

            res := dp(newRemaining)
            if res != -1 && 1+res < minStickers {
                minStickers = 1 + res
            }
        }

        if minStickers == 1<<30 {
            memo[remaining] = -1
        } else {
            memo[remaining] = minStickers
        }
        return memo[remaining]
    }

    return dp(target)
}
```**Go 特定注释**：

 我们使用长度为 26 的数组代替`Counter`为了效率。 使用循环或串联来模拟字符串乘法。 地图`memo`缓存结果。 处理`minStickers`和`1 << 30`因为无穷大在 Go 中是典型的。
