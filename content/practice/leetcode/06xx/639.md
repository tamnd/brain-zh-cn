 **主题：** 字符串、动态规划

 ## 解决方案

 ## 问题理解

 该问题要求我们确定将编码字符串解码为字母的方式数，其中`'A'`映射到`"1"`,`'B'`映射到`"2"`, 直至`'Z'`映射到`"26"`。 输入字符串`s`包含数字`'0'-'9'`以及可能的通配符`'*'`，它代表任意数字`'1'`到`'9'`。 输出是有效解码总数模$10^9 + 7$。 

关键的挑战是处理`'*'`通配符并确保正确计算一位数和两位数的组合，而不会重复计算或包含无效序列，例如`"06"`。 该字符串最多可达$10^5$个字符长，这排除了由于组合数量呈指数增长而导致的强力递归。 

重要的边缘情况包括完全由以下内容组成的字符串`'*'`，序列包含`'0'`（这只能是一部分`'10'`或者`'20'`)，以及混合数字和的字符串`'*'`以一种创造多种有效解释的方式。 

## 方法

 暴力方法是递归地将字符串中的每个字符视为一位数解码，或者如果可能的话，视为两位数解码。 为了`'*'`，我们将迭代该位置的所有 9 个可能的数字。 这在理论上是正确的，但由于指数时间复杂度而不可行，$O(9^n)$， 在哪里$n$是字符串的长度。 

最佳方法使用动态规划。 让`dp[i]`表示子串的解码方式数`s[0:i]`。 该转换考虑一个字符和两个字符的组合。 对于一个字符，如果`s[i-1]`是`'*'`，贡献了9倍`dp[i-1]`; 否则贡献1`'0'`。 对于两个字符的组合，我们考虑形成 10 到 26 之间数字的有效范围，并仔细计算以下情况的可能性：`'*'`出现在任一位置。 空间可以优化为`O(1)`通过仅存储最后两个 DP 值，因为每个`dp[i]`仅取决于`dp[i-1]`和`dp[i-2]`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(9^n) | O(9^n) | O(n) | 递归地探索所有的解释`*`和数字 |
 | 最佳DP | O(n) | O(1) | O(1) | 使用 DP 进行模运算和句柄`*`仔细|

 ## 算法演练

 1. 初始化`MOD = 10^9 + 7`处理大量数据。 
2.创建两个变量，`dp1`和`dp2`，代表`dp[i-1]`和`dp[i-2]`。 最初，`dp2 = 1`（空字符串有 1 次解码），并且`dp1`取决于第一个字符：9（如果是）`'*'`, 如果非零数字则为 1，如果为 0`'0'`。 
3. 迭代从索引 1 到 n-1 的字符串：

 1. 计算`single`用于解码`s[i]`作为单个字符： 9 if`'*'`, 1 如果是数字`'1'-'9'`, 0 如果`'0'`。 
2. 计算`double`用于解码`s[i-1]`和`s[i]`作为两位数。 处理所有组合`'*'`仔细：

 - 如果`s[i-1]`是`'*'`和`s[i]`是`'*'`，有效的两位数是`11-19`和`21-26`→ 共有 15 种组合。 
- 如果只有一个`'*'`，根据其他数字计算有效选项。 
- 如果都是数字，检查它们是否构成 10 到 26 之间的数字。 
3. 计算`dp = (dp1 * single + dp2 * double) % MOD`。 
4. 更新`dp2 = dp1`,`dp1 = dp`用于下一次迭代。 
4. 返回`dp1`作为解码字符串的方法总数。 

工作原理：该 DP 正确计算单位数和双位数解码的所有组合，处理`'*'`高效。 模数确保我们不会溢出。 通过仅存储最后两个 DP 值，我们在不损失正确性的情况下降低了空间复杂度，因为每个`dp[i]`仅取决于`dp[i-1]`和`dp[i-2]`。 

## Python 解决方案```python
class Solution:
    def numDecodings(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        if not s:
            return 0
        
        dp2 = 1
        dp1 = 9 if s[0] == '*' else 0 if s[0] == '0' else 1
        
        for i in range(1, n):
            single = 0
            double = 0
            
            if s[i] == '*':
                single = 9
            elif s[i] != '0':
                single = 1
            
            if s[i-1] == '*' and s[i] == '*':
                double = 15  # 11-19 + 21-26
            elif s[i-1] == '*':
                double = 2 if '0' <= s[i] <= '6' else 1
            elif s[i] == '*':
                if s[i-1] == '1':
                    double = 9
                elif s[i-1] == '2':
                    double = 6
            else:
                if s[i-1] != '0' and 10 <= int(s[i-1:i+1]) <= 26:
                    double = 1
            
            dp = (dp1 * single + dp2 * double) % MOD
            dp2, dp1 = dp1, dp
        
        return dp1
```该代码初始化基本情况`dp[0]`和`dp[1]`并迭代字符串，计算单字符和双字符解码的方式数。 它处理`'*'`通过明确计算形成有效字母的所有可能的数字值。 

## 解决方案```go
func numDecodings(s string) int {
    const MOD = 1_000_000_007
    n := len(s)
    if n == 0 {
        return 0
    }
    
    dp2, dp1 := 1, 0
    if s[0] == '*' {
        dp1 = 9
    } else if s[0] != '0' {
        dp1 = 1
    }
    
    for i := 1; i < n; i++ {
        single, double := 0, 0
        
        if s[i] == '*' {
            single = 9
        } else if s[i] != '0' {
            single = 1
        }
        
        if s[i-1] == '*' && s[i] == '*' {
            double = 15
        } else if s[i-1] == '*' {
            if s[i] >= '0' && s[i] <= '6' {
                double = 2
            } else {
                double = 1
            }
        } else if s[i] == '*' {
            if s[i-1] == '1' {
                double = 9
            } else if s[i-1] == '2' {
                double = 6
            }
        } else {
            if s[i-1] != '0' {
                twoDigit := (int(s[i-1]-'0')*10 + int(s[i]-'0'))
                if twoDigit >= 10 && twoDigit <= 26 {
                    double = 1
                }
            }
        }
        
        dp := (dp1*single + dp2*double) % MOD
        dp2, dp1 = dp1, dp
    }
    
    return dp1
}
```Go 解决方案反映了 Python 实现，但整数转换和模运算的语法有所不同。 我们使用显式转换来计算两位数，并仅维护最后两个 DP 值以减少内存使用量。
