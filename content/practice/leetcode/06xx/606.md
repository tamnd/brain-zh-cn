[LeetCode 606 题](https://leetcode.com/problems/construct-string-from-binary-tree/)

 **难度：** 🟡 中等
 **主题：** 字符串、树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 这个问题要求我们使用非常特定的前序遍历格式将二叉树转换为字符串。 我们必须按照**根→左子树→右子树**的顺序访问节点，并使用括号表示树的结构。 

每个节点将其整数值贡献给最终字符串。 如果节点有子节点，则这些子节点将紧跟在节点值后面的括号中。 左孩子总是出现在右孩子之前。 

微妙的挑战来自于如何处理空虚的孩子。 在大多数情况下，应省略空括号以保持字符串紧凑。 然而，有一个重要的例外：当一个节点有**右子节点但没有左子节点**时，我们必须显式包含`()`为了失踪的左孩子。 如果没有这个占位符，树的结构就会变得不明确。 

例如，考虑这棵树：```
    1
   / \
  2   3
 /
4
```包含每对可能的括号的完整表示如下：```
1(2(4)())(3()())
```然而，不必要的空括号被删除，产生：```
1(2(4))(3)
```现在考虑这棵树：```
    1
   / \
  2   3
   \
    4
```节点`2`有右孩子但没有左孩子。 我们必须显式地保留这个缺失的左孩子：```
1(2()(4))(3)
```输入是二叉树的根节点。 输出是一个字符串，它唯一地表示该树，同时遵循省略规则。 

约束告诉我们树最多可以包含`10^4`节点。 这个值足够大，我们应该避免低效地重复连接不可变字符串，因为这可能会导致二次行为。 优选线性遍历。 节点值的范围为`-1000`到`1000`，但由于我们只是将整数转换为字符串，因此值的大小不是主要问题。 

一些边缘情况很重要：

 - 只有一个节点的树应该只返回不带括号的节点值。 
- 仅具有左子节点的节点应仅包含左子树括号。 
- 只有右子节点的节点必须包含一个空的`()`在右子树之前。 
- 深树可能会强调递归深度和字符串构建效率。 

## 方法

 ### 蛮力方法

 一个简单的暴力解决方案是使用重复的字符串连接来递归地构建字符串。 

在每个节点，我们递归地计算左子树字符串和右子树字符串。 然后我们根据问题规则将它们组合成正确的格式。 由于 Python 字符串和 Go 字符串是不可变的，因此每次连接都会创建一个新字符串。 如果树非常大，重复的串联可能会变得昂贵，因为之前构建的字符串部分会被一次又一次复制。 

这种方法在逻辑上是正确的，因为前序遍历自然匹配所需的输出格式。 我们首先处理当前节点，然后附加左子树表示，然后附加右子树表示。 根据子项是否存在来应用省略规则。 

然而，幼稚的字符串连接可能会降低性能，特别是对于倾斜的树，其中连接重复复制越来越大的字符串。 

### 最佳方法

 关键的观察结果是，问题自然映射到**深度优先遍历**，特别是先序遍历。 我们可以使用列表（Python）或增量方式构建结果，而不是重复连接不可变的字符串`strings.Builder`（去）。 

这个想法是递归地遍历树并将结果的片段直接附加到可变缓冲区中：

 - 添加节点值。 
- 如果节点有子节点，则处理括号内的左子树。 
- 如果节点有右子节点但没有左子节点，则显式追加`()`。 
- 处理括号内的右子树（如果存在）。 

这避免了重复复制并确保每个节点对最终字符串的贡献恰好一次。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 重复不可变字符串连接的递归遍历 |
 | 最佳| O(n) | O(n) | 通过高效的可变字符串构建进行 DFS 遍历 |

 这里，`n`是树中的节点数。 

## 算法演练

 1. **创建递归 DFS 辅助函数**

 我们使用前序遍历，因为该问题明确要求当前节点出现在其子节点之前。 辅助函数一次处理一个节点。 
2. **追加当前节点值**

 当访问一个节点时，立即将其整数值添加到结果中。 

例如：```
Node = 1
Result = "1"
```3. **处理左边的孩子**

 如果该节点有左子节点，则将其递归结果括在括号内。 

例子：```
Node = 2
Left child = 4

Result becomes:
"2(4)"
```4. **处理特殊的留守儿童失踪案件**

 如果该节点没有左子节点但有右子节点，则追加：```
()
```这保留了字符串和树结构之间的一对一映射。 
5. **照顾正确的孩子**

 如果该节点有右子节点，则在括号内递归处理它。 
6. **继续递归**

 递归自然地按先序处理整个树。 
7. **加入累积的碎片**

 在Python中，我们将字符串片段存储在列表中并调用`"".join()`在最后。 在 Go 中，我们使用`strings.Builder`有效积累人物。 

### 为什么它有效

 该算法之所以有效，是因为它准确地反映了问题的先序遍历要求。 以正确的顺序访问每个节点，并且根据子节点的存在一致地应用括号规则。 丢失左子树的特殊情况保留了结构的唯一性，确保生成的字符串始终可以明确地重建原始树。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional

class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        parts = []

        def dfs(node: Optional[TreeNode]) -> None:
            if not node:
                return

            parts.append(str(node.val))

            if node.left or node.right:
                parts.append("(")

                if node.left:
                    dfs(node.left)

                parts.append(")")

            if node.right:
                parts.append("(")
                dfs(node.right)
                parts.append(")")

        dfs(root)
        return "".join(parts)
```该实现使用一个`parts`list 来有效地积累字符串片段。 不是重复连接字符串，而是将每个片段附加到列表中并在最后组合一次。 

递归`dfs()`函数执行前序遍历。 首先，它附加当前节点值。 然后检查左孩子是否需要括号。 请注意，条件：```python
if node.left or node.right:
```是必不可少的。 即使左孩子缺失，如果右孩子存在，我们仍然会打开和关闭括号。 这正确地产生了`()`对于缺失的左子树。 

最后，如果存在右子节点，则在其自己的括号内递归处理该右子节点。 

## 解决方案```go
import (
	"strconv"
	"strings"
)

/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func tree2str(root *TreeNode) string {
	var builder strings.Builder

	var dfs func(node *TreeNode)

	dfs = func(node *TreeNode) {
		if node == nil {
			return
		}

		builder.WriteString(strconv.Itoa(node.Val))

		if node.Left != nil || node.Right != nil {
			builder.WriteByte('(')

			if node.Left != nil {
				dfs(node.Left)
			}

			builder.WriteByte(')')
		}

		if node.Right != nil {
			builder.WriteByte('(')
			dfs(node.Right)
			builder.WriteByte(')')
		}
	}

	dfs(root)

	return builder.String()
}
```Go 实现遵循与 Python 版本相同的逻辑，但使用`strings.Builder`用于高效的字符串构建。 由于 Go 字符串是不可变的，因此重复连接`+`对于大树来说效率很低。 

Go 使用`nil`而不是`None`为失踪儿童，以及`strconv.Itoa()`将整数转换为字符串。 使用添加括号`WriteByte()`为了效率。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点都被访问一次 |
 | 空间| O(n) | 递归调用堆栈和输出存储|

 时间复杂度为`O(n)`因为每个节点都将其值和括号贡献给输出一次。 不会重新访问任何节点，并且由于可变缓冲，字符串组装非常高效。 

空间复杂度为`O(n)`因为在最坏的情况下递归栈可能会增长到树的高度，而且输出字符串本身也需要线性空间。

 ## 边缘情况

 仅包含单个节点的树是一个重要的边界情况。 幼稚的实现可能会意外地将节点包裹在不必要的括号中，例如`"1()"`。 正确的输出就是节点值。 此实现可以自然地处理这种情况，因为仅当子项存在时才添加括号。 

只有右子节点的节点是问题中最容易出错的场景。 如果我们省略空的左括号，结构就会变得不明确。 例如，`"1(2)"`可能意味着左孩子或右孩子。 实现明确检查：```
if node.left or node.right:
```这保证了`()`每当存在右子节点而没有左子节点时插入。 

深度倾斜的树木是另一个潜在的问题来源。 由于树可能包含最多`10^4`节点，低效的字符串连接可能会变得非常慢。 在 Python 中使用字符串片段列表`strings.Builder`Go 中确保线性性能，避免重复复制大型中间字符串。
