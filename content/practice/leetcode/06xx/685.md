 ## 解决方案

 ## 问题理解

 该问题要求我们识别起源于有根树的**有向图中**的冗余边。 一棵有根树有一个根，所有其他节点只有一个父节点。 给出的图最初是一棵树`n`标记的节点`1`到`n`，恰好添加了一个额外的有向边。 这个额外的边可能会创建一个环，一个具有两个父节点的节点，或两者。 

输入`edges`是一个对的列表`[ui, vi]`， 在哪里`ui`是的父级`vi`。 我们需要返回**一条要删除的边**，以便生成的图再次成为有效的有根树。 如果可以删除多条边，我们必须返回输入中**最后**出现的一条边。 

约束告诉我们`3 <= n <= 1000`，因此时间复杂度为 O(n²) 的算法可能有效，但对于大型`n`。 每个节点标签都是唯一且正的，不存在自环。 该问题恰好保证了**一条额外的边**，这简化了我们需要考虑的情况。 

关键的边缘情况包括：

 1. 有两个父节点的节点。 我们必须选择删除哪条边来恢复树的属性。 
2. 图中的一个循环。 移除闭合循环的边可恢复非循环属性。 
3. 两者的组合：一个节点有两个父节点，其中一条边创建一个环。 

## 方法

 ### 蛮力方法

 一种简单的方法是迭代每条边并暂时删除它，然后检查生成的图是否是有根树。 要检查图是否是一棵有根树，我们可以使用 DFS 或 BFS 来确保不存在循环并且每个节点只有一个父节点。 虽然这种方法是正确的，但它需要检查每条边的树属性，导致时间复杂度为 O(n²)。 对于 n = 1000 的上限来说，这是低效的。 

### 最佳方法

 最佳方法利用**Union-Find（不相交集并集）与父跟踪**相结合。 关键的见解是冗余边缘只能属于以下三类之一：

 1. 有两个父节点的节点，无循环。 
2. 有两个父节点的节点，存在循环。 
3. 循环，没有两个父节点的节点。 

首先，我们扫描边缘以确定节点是否有两个父节点。 如果是，我们暂时忽略第二条边并使用并查找检查循环。 如果存在环，则冗余边为第一条父边； 否则，它是第二条边。 如果没有节点有两个父节点，我们只需使用并查找来检测循环并返回完成它的边。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 删除每条边并检查图是否是有效的树 |
 | 最佳| O(n) | O(n) | 使用父数组和并查高效检测两个父项和循环 |

 ## 算法演练

 1. 初始化一个`parent`大小数组`n+1`跟踪每个节点的父节点。 
2.初始化两个变量`cand1`和`cand2`存储具有两个父节点的节点的候选边。 
3. 迭代每条边`[u, v]`。 如果`v`已经有父母、商店`[existing_parent, v]`作为`cand1`和`[u, v]`作为`cand2`，然后暂时忽略`cand2`。 
4. 使用并查（Union-Find）迭代边：

 a. 跳过`cand2`如果存在的话。 

b. 对于每条边`[u, v]`, 联盟`u`和`v`。 

c. 如果`u`和`v`已连接，检测到循环。 
5. 确定要删除的边：

 a. 如果不存在双父节点，则返回创建环的边。 

b. 如果存在双父节点并且检测到环路，则返回`cand1`。 

c. 如果存在双父节点但不存在循环，则返回`cand2`。 

**为什么有效：** 通过同时跟踪父级关系和检测循环，我们可以处理额外边缘的所有场景：具有两个父级、循环或两者兼而有之的节点。 这确保返回的边正是导致违反根树属性的边。 

## Python 解决方案```python
from typing import List

class Solution:
    def findRedundantDirectedConnection(self, edges: List[List[int]]) -> List[int]:
        n = len(edges)
        parent = [0] * (n + 1)
        cand1 = cand2 = None
        
        # Step 1: Check for a node with two parents
        for u, v in edges:
            if parent[v] == 0:
                parent[v] = u
            else:
                cand1 = [parent[v], v]
                cand2 = [u, v]
                # Temporarily remove the second edge
                break
        
        # Union-Find setup
        def find(x):
            if uf[x] != x:
                uf[x] = find(uf[x])
            return uf[x]
        
        uf = list(range(n + 1))
        
        # Step 2: Detect cycle
        for u, v in edges:
            if [u, v] == cand2:
                continue
            pu, pv = find(u), find(v)
            if pu == pv:
                if cand1:
                    return cand1
                else:
                    return [u, v]
            uf[pv] = pu
        
        # Step 3: If no cycle, remove the second parent edge
        return cand2
```**说明：** 第一个循环标识一个具有两个父节点的节点。 然后，联合查找逻辑会有效地检测循环，并在必要时跳过第二个候选者。 根据循环和双父节点的存在，我们返回正确的边。 

## 解决方案```go
func findRedundantDirectedConnection(edges [][]int) []int {
    n := len(edges)
    parent := make([]int, n+1)
    var cand1, cand2 []int
    
    for _, e := range edges {
        u, v := e[0], e[1]
        if parent[v] == 0 {
            parent[v] = u
        } else {
            cand1 = []int{parent[v], v}
            cand2 = []int{u, v}
            break
        }
    }
    
    uf := make([]int, n+1)
    for i := 0; i <= n; i++ {
        uf[i] = i
    }
    
    var find func(int) int
    find = func(x int) int {
        if uf[x] != x {
            uf[x] = find(uf[x])
        }
        return uf[x]
    }
    
    for _, e := range edges {
        if cand2 != nil && e[0] == cand2[0] && e[1] == cand2[1] {
            continue
        }
        u, v := e[0], e[1]
        pu, pv := find(u), find(v)
        if pu == pv {
            if cand1 != nil {
                return cand1
            }
            return e
        }
        uf[pv] = pu
    }
    
    return cand2
}
```**Go 特定说明：** 我们使用切片而不是列表，对候选者进行 nil 检查，并且函数是处理递归的闭包`find`。 

## 工作示例

 ### 示例 1：`[[1,2],[1,3],[2,3]]`1. 节点 3 有两个父节点：cand1 = [1,3]、cand2 = [2,3]。 
2.并查：

 - [1,2]：联合成功
 - [1,3]：联合成功
 - 跳过 cand2 ([2,3])
 3. 未检测到循环。 删除 cand2 = [2,3]。 

### 示例 2：`[[1,2],[2,3],[3,4],[4,1],[1,5]]`1. 没有具有两个父节点的节点。 
2.并查：

 - [1,2]、[2,3]、[3,4]：联合成功
 - [4,1]：检测到循环。 返回[4,1]

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单遍检测两个父级 + 带路径压缩的并查找 |
 | 空间| O(n) | 父数组和大小为 n+1 的并查数组 |

 由于路径压缩，并查找操作的时间接近恒定，从而确保总体时间是线性的。
