 ## 解决方案

 ## 问题理解

 这个问题要求我们将每个部门的平均工资与公司每个月的整体平均工资进行比较。 我们有两张表：`Salary`和`Employee`。 这`Salary`表记录了每个员工的月工资以及日期，而`Employee`表将员工映射到他们的部门。 

目标是生成一个表，其中每行显示一个月（`pay_month`）、一个部门（`department_id`），和一个`comparison`表示部门当月平均工资与公司当月平均工资是否“较高”、“较低”或“相同”的值。 

重要的一点包括：

 -`pay_date`是一个完整的日期，但我们只关心聚合的月份部分。 
- 应计算该月所有工资的平均值。 
- 边缘情况包括部门只有一名员工的月份、所有工资相同的月份或某些员工可能有多个工资条目（例如每月奖金或多个工资条目）的月份。 
- 输出可以按任何顺序。 

该问题保证每个员工都属于一个部门，并且表格格式良好。 

预先考虑的边缘情况：

 1. 一个部门一个月只有一名员工。 
2、所有员工一个月工资相同。 
3、同月多次记入的工资。 
4. 给定月份内没有员工的部门不应出现在结果中。 

## 方法

 ### 蛮力

 暴力的方法是迭代每个月，计算该月公司的平均工资，然后每个部门计算该月的平均工资，最后进行比较。 虽然正确，但这需要多个嵌套聚合，并且可能会变得昂贵，因为它有效地扫描整个`Salary`多次表，这对于大型数据集来说效率低下。 

### 最佳

 最佳方法利用 SQL 执行连接和聚合的能力。 首先我们加入`Salary`和`Employee`将每个工资与其部门相关联。 然后，我们从中提取月份`pay_date`并计算按月份和部门分组的平均工资。 同样，我们计算按月分组的公司整体平均值。 最后，我们将当月的这两个聚合结合起来，并使用`CASE`产生“更高”、“更低”或“相同”的语句。 这种方法需要一次通过数据进行聚合和一次连接进行比较，从而使其更加高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * d) | O(n) | 每个月和部门的嵌套迭代； 对于大桌子来说效率低下|
 | 最佳| O(n) | O(n) | 通过 join 对工资进行单一聚合； 速度更快并利用 SQL 优化 |

 ## 算法演练

 1. 加入`Salary`表与`Employee`在`employee_id`将工资与其部门联系起来。 
2. 提取`pay_month`从`pay_date`使用 SQL 日期函数。 
3、按分组计算每月部门平均工资`pay_month`和`department_id`。 
4. 仅按分组计算公司月平均工资`pay_month`。 
5、将部门平均数与公司平均数结合起来`pay_month`。 
6. 使用`CASE`比较表达式`dept_avg`和`company_avg`并输出“更高”、“更低”或“相同”。 
7. 返回`pay_month`,`department_id`，以及比较。 

**为什么有效：** 通过先聚合后加入，我们确保每个部门的月平均值与相应公司的月平均值进行准确比较。 这`CASE`确保正确的文本比较。 

## Python 解决方案```python
# This problem is SQL-specific, but for reference, a Python pandas implementation could look like this
import pandas as pd

def department_vs_company_comparison(salary: pd.DataFrame, employee: pd.DataFrame) -> pd.DataFrame:
    salary['pay_month'] = pd.to_datetime(salary['pay_date']).dt.to_period('M').astype(str)
    merged = salary.merge(employee, on='employee_id')
    
    dept_avg = merged.groupby(['pay_month', 'department_id'])['amount'].mean().reset_index(name='dept_avg')
    company_avg = merged.groupby('pay_month')['amount'].mean().reset_index(name='company_avg')
    
    result = dept_avg.merge(company_avg, on='pay_month')
    
    def compare(row):
        if row['dept_avg'] > row['company_avg']:
            return 'higher'
        elif row['dept_avg'] < row['company_avg']:
            return 'lower'
        else:
            return 'same'
    
    result['comparison'] = result.apply(compare, axis=1)
    return result[['pay_month', 'department_id', 'comparison']]
```**说明：** 代码转换`pay_date`到一个`YYYY-MM`字符串、连接`Salary`和`Employee`，使用 groupby 计算部门和公司平均值，将它们合并，然后确定与 lambda 函数的比较。
