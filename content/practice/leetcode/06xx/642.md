[LeetCode 642 题](https://leetcode.com/problems/design-search-autocomplete-system/)

 **难度：** 🔴难
 **主题：** 字符串、深度优先搜索、设计、Trie、排序、堆（优先级队列）、数据流

 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个自动完成系统，其行为类似于搜索引擎建议功能。 该系统首先收集历史句子以及每个句子之前被输入的次数。 当用户一一输入字符时，系统必须返回最多三个以当前输入前缀开头的匹配句子。 

排名规则非常重要：

 - 频率较高的句子应首先出现。 
- 如果两个句子具有相同的频率，则 ASCII 顺序较小的句子应该排在前面。 
- 仅返回前三个结果。 

特殊字符`'#'`表示当前句子的结束。 发生这种情况时，当前输入字符串将成为历史数据的一部分，并且其频率增加 1。 然后系统重置并开始接受新句子。 

输入包括：

 -`sentences`，历史搜索字符串列表
 -`times`， 在哪里`times[i]`是的频率`sentences[i]`- 通过重复调用的一系列字符输入`input(c)`每个字符输入的输出为：

 - 最多三个自动完成建议的列表，如果`c != '#'`- 空列表，如果`c == '#'`这些约束揭示了有关预期解决方案设计的几个重要细节。 

首句数量比较少，最多`100`，但每个句子可能相当长。 更重要的是，`input()`函数最多可调用`5000`次。 这意味着每次击键时重复扫描每个句子可能会变得低效。 问题本质上是关于有效的前缀查找与排名相结合。 

一些边缘情况很重要：

 - 多个句子可能共享相同的频率，需要 ASCII 排序。 
- 用户可以输入当前不存在的全新句子。 
- 前缀可能返回少于三个匹配项。 
- 空格是有效字符，必须正确处理。 
- 系统必须在每个完成的句子后动态更新自身。 

幼稚的实现很容易在排序、前缀处理或更新频率后犯错误。`'#'`。 

## 方法

 ### 蛮力方法

 最简单的方法是将所有句子存储在哈希映射中，其中键是句子，值是其频率。 

对于每个字符输入：

 1. 将字符附加到当前前缀。 
2. 扫描每个存储的句子。 
3. 检查句子是否以当前前缀开头。 
4.收集匹配的句子。 
5. 按以下方式排序：

 - 频率下降
 - 字典顺序升序
 6.返回前三名。 

什么时候`'#'`遇到：

 1. 将完成的句子添加到频率图中。 
2. 重置当前输入缓冲区。 

这种方法是正确的，因为它直接评估每个可能的候选人并完全按照规定应用排名规则。 

然而，它变得低效，因为每次击键都需要扫描所有存储的句子。 随着数据集的增长，重复的前缀匹配和排序变得昂贵。 

### 最优方法，频率图特里法

 关键的观察是这个问题本质上是一个前缀搜索问题。 前缀问题自然适合 Trie。 

Trie 允许我们：

 - 一个接一个地遍历字符
 - 快速找到共享前缀的所有句子
 - 避免扫描不相关的句子

 每个 Trie 节点代表一个前缀。 我们存储：

 - 子指针
 - 句子到该前缀频率的映射

 当插入句子时，路径上的每个节点都会更新其频率图。 

当用户输入一个字符时：

 1. 遍历Trie到代表当前前缀的节点。 
2. 检索该节点存储的所有候选句子。 
3. 根据所需的排名规则对候选人进行排序。 
4.返回前三名。 

这显着减少了不必要的扫描，因为只考虑共享前缀的句子。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(N × L + N log N) | O(N × L) | 扫描每个句子中的每个字符 |
 | 最佳| 每个查询 O(P + K log K) | O(Trie 中的总字符数) | Trie 将搜索范围缩小到匹配的前缀 |

 在哪里：

-`N`= 句子数
 -`L`= 平均句子长度
 -`P`= 前缀长度
 -`K`= 匹配候选人的数量

 ## 算法演练

 ### 基于 Trie 的最优算法

 1. 创建一个 Trie 数据结构，其中每个节点包含：

 - 子节点的字典
 - 将句子映射到频率的字典

 子字典允许逐字符遍历。 频率图允许快速检索任何前缀的候选句子。 
2.将每个历史句子插入Trie中。 

对于句子中的每个字符：

 - 移动到相应的子节点，必要时创建它。 
- 用句子的计数更新节点的句子频率图。 

这确保每个前缀节点都知道哪些句子属于该前缀。 
3.维护两块运行时状态：

 - 当前输入字符串
 - 指向当前 Trie 节点的指针

 这些允许在用户键入时进行高效的增量遍历。 
4. 什么时候`input(c)`用普通字符调用：

 - 将字符追加到当前输入缓冲区。 
- 移动到Trie中相应的子节点。 
- 如果路径不存在，则返回空列表，因为没有句子与此前缀匹配。 
- 否则，检索节点中存储的所有候选句子。 
5. 使用以下方法对候选句子进行排序：

 - 频率优先
 - 当频率相等时，首先按词典顺序排列较小的句子

 在 Python 中，这是通过以下方式实现的：```
sorted(candidates, key=lambda x: (-freq[x], x))
```6.返回排序后的前三个句子。 
7. 什么时候`input('#')`称为：

 - 将完整的句子插入 Trie 中，频率增加 1。 
- 重置当前输入缓冲区。 
- 重置Trie遍历状态。 
- 返回一个空列表。 

### 为什么它有效

 核心不变量是每个 Trie 节点存储共享该节点前缀的所有句子。 因此，一旦遍历到达表示当前输入前缀的节点，每个有效的自动完成候选者在该节点立即可用。 根据问题规则对这些候选者进行排序可以保证正确的前三个建议。 

## Python 解决方案```python
from typing import List
from collections import defaultdict

class TrieNode:
    def __init__(self):
        self.children = {}
        self.sentences = defaultdict(int)

class AutocompleteSystem:

    def __init__(self, sentences: List[str], times: List[int]):
        self.root = TrieNode()
        self.current_input = ""
        self.current_node = self.root

        for sentence, time in zip(sentences, times):
            self._insert(sentence, time)

    def _insert(self, sentence: str, frequency: int) -> None:
        node = self.root

        for char in sentence:
            if char not in node.children:
                node.children[char] = TrieNode()

            node = node.children[char]
            node.sentences[sentence] += frequency

    def input(self, c: str) -> List[str]:
        if c == '#':
            self._insert(self.current_input, 1)

            self.current_input = ""
            self.current_node = self.root

            return []

        self.current_input += c

        if self.current_node and c in self.current_node.children:
            self.current_node = self.current_node.children[c]

            candidates = list(self.current_node.sentences.keys())

            candidates.sort(
                key=lambda sentence: (
                    -self.current_node.sentences[sentence],
                    sentence
                )
            )

            return candidates[:3]

        self.current_node = None
        return []
```实施开始于`TrieNode`班级。 每个节点存储：

 -`children`，表示传出字符边缘
 -`sentences`，它跟踪节点前缀的句子频率

 构造函数初始化 Trie 并插入所有历史数据。 

这`_insert()`辅助方法遍历句子中的每个字符。 当它遍历 Trie 时，它​​会更新路径上每个节点的句子频率。 这保证了每个前缀节点包含所有匹配的句子。 

这`input()`方法处理两种情况。 

当用户输入`'#'`，当前句子被最终确定并插入到 Trie 中，频率增加 1。 随后系统状态被重置。 

对于普通字符，该方法通过 Trie 前进。 如果前缀存在，则从当前节点检索候选句子，使用排序规则对它们进行排序，并返回前三名。 

如果由于不存在匹配的前缀而导致遍历失败，则当前节点变为`None`，并且未来的字符继续返回空列表，直到`'#'`重置系统。 

## 解决方案```go
package main

import (
	"sort"
)

type TrieNode struct {
	children  map[byte]*TrieNode
	sentences map[string]int
}

func NewTrieNode() *TrieNode {
	return &TrieNode{
		children:  make(map[byte]*TrieNode),
		sentences: make(map[string]int),
	}
}

type AutocompleteSystem struct {
	root         *TrieNode
	currentNode  *TrieNode
	currentInput string
}

func Constructor(sentences []string, times []int) AutocompleteSystem {
	system := AutocompleteSystem{
		root: NewTrieNode(),
	}

	system.currentNode = system.root

	for i := 0; i < len(sentences); i++ {
		system.insert(sentences[i], times[i])
	}

	return system
}

func (this *AutocompleteSystem) insert(sentence string, frequency int) {
	node := this.root

	for i := 0; i < len(sentence); i++ {
		ch := sentence[i]

		if _, exists := node.children[ch]; !exists {
			node.children[ch] = NewTrieNode()
		}

		node = node.children[ch]
		node.sentences[sentence] += frequency
	}
}

func (this *AutocompleteSystem) Input(c byte) []string {
	if c == '#' {
		this.insert(this.currentInput, 1)

		this.currentInput = ""
		this.currentNode = this.root

		return []string{}
	}

	this.currentInput += string(c)

	if this.currentNode != nil {
		if nextNode, exists := this.currentNode.children[c]; exists {
			this.currentNode = nextNode

			candidates := make([]string, 0)

			for sentence := range this.currentNode.sentences {
				candidates = append(candidates, sentence)
			}

			sort.Slice(candidates, func(i, j int) bool {
				freqI := this.currentNode.sentences[candidates[i]]
				freqJ := this.currentNode.sentences[candidates[j]]

				if freqI == freqJ {
					return candidates[i] < candidates[j]
				}

				return freqI > freqJ
			})

			if len(candidates) > 3 {
				return candidates[:3]
			}

			return candidates
		}
	}

	this.currentNode = nil
	return []string{}
}
```Go 实现遵循相同的整体设计，但在一些特定于语言的细节上有所不同。 

Go 没有内置的默认字典，因此映射必须显式初始化。 

排序是使用实现的`sort.Slice()`带有自定义比较器。 

Trie 使用`byte`键，因为问题只包含小写字母、空格和`'#'`。 

与 Python 不同，Go 区分`nil`切片和空切片。 返回`[]string{}`确保正确的空结果格式。

 ## 边缘情况

 ### 前缀不存在

 当遍历到达 Trie 中不存在的字符路径时，会出现一个非常常见的错误。 幼稚的实现可能会继续搜索或意外因空引用而崩溃。 

此实现通过设置来处理这种情况`current_node`到`None`在 Python 中或`nil`在围棋中。 一旦发生这种情况，当前句子的所有未来输入都会立即返回空结果，直到`'#'`重置系统。 

### 句子之间的频率关系

 两个句子可能具有相同的频率。 该问题需要 ASCII 排序作为决定因素，这一点很容易被忽视。 

例如：```
"i love leetcode"
"iroman"
```两者都可能有频率`2`，但空格字符的 ASCII 值小于`'r'`， 所以`"i love leetcode"`必须是第一位的。 

该实现使用基于元组的排序来处理这个问题：```
(-frequency, sentence)
```这保证了正确的排序。 

### 添加全新的句子

 用户可能会键入以前从未存在过的句子。 有缺陷的实现可能无法正确插入它，因为缺少中间 Trie 节点。 

这`_insert()`方法在遍历字符时动态创建丢失的节点。 这确保了用户输入后可以立即搜索新句子`'#'`。 

### 少于三个匹配的前缀

 该问题需要返回尽可能多的结果，而不是恰好三个。 

该实现安全地使用切片：```
candidates[:3]
```如果存在的候选数少于三个，Python 会自动返回可用的子集，不会出现错误。 Go 版本类似地在截断之前检查切片长度。
