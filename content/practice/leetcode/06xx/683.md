 ## 解决方案

 让我们按照格式说明查看 **LeetCode 683 - K 空槽** 的完整、详细的技术解决方案指南。 

## 问题理解

 问题要求我们找出最早的一天，当**恰好存在时`k`两个打开的灯泡之间的灯泡关闭**。 给你一个数组`bulbs`在哪里`bulbs[i]`告诉您当天哪个灯泡（1 索引）打开`i+1`。 

重申一下，想象一排灯泡最初全部关闭。 每天，您根据表中的顺序打开一个灯泡`bulbs`大批。 您的任务是找到**最小天数**，使得灯泡上存在**两个**且**准确无误`k`关闭中间的灯泡**。 如果这种情况从未发生，请返回`-1`。 

输入数组`bulbs`是数字的排列`1`到`n`。 这保证了没有重复并且每个灯泡最终都会打开。 数组大小`n`可以达到`2 * 10^4`，对于每天检查每对灯泡的简单暴力模拟来说太大了。 

重要的边缘情况包括：

 -`k = 0`，我们需要打开相邻的灯泡。 
- 灯泡按升序或降序打开，这可能永远不会产生有效的间隙。 
- 允许的最大输入大小（`n = 2 * 10^4`）这需要一个有效的解决方案。 

## 方法

 ### 蛮力

 最简单的方法是每天模拟灯泡阵列。 每天，打开当前灯泡后，检查每对可能打开的灯泡，看看它们之间关闭的灯泡数量是否正好`k`。 这将涉及一个嵌套循环：每天扫描阵列以查找打开的灯泡并计算间隙。 

虽然正确，但这太慢了，因为`n`灯泡，每天可能需要`O(n)`检查所有对。 总复杂度可能达到`O(n^2)`或者更糟，这是不可接受的`n = 2 * 10^4`。 

### 最佳方法

 关键的见解是我们**不需要每天检查所有对**。 相反，我们可以使用数组来转换问题`days`在哪里`days[i]`是哪一天`i-th`灯泡（1 索引）打开。 

然后，在灯泡上找到两个完全相同的`k`它们之间的灯泡关闭成为**窗户问题**。 对于每个尺寸的窗口`k+2`（开始于`left`和`right = left + k + 1`），窗户内的灯泡必须在左右灯泡**之后**全部打开。 

我们可以使用 **滑动窗口** 有效地实现这一点：

 1. 转型`bulbs`进入一个`days`大批。 
2. 迭代所有可能的情况`left`定位并维护大小的滑动窗口`k+2`。 
3. 如果窗口内的所有灯泡都**晚于边缘**打开，则更新最短日期。 

这减少了问题`O(n^2)`到`O(n)`时间与`O(n)`空间。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 每天进行模拟，检查所有成对的灯泡 |
 | 滑动窗口（最佳）| O(n) | O(n) | 转换为days数组，高效检查k+2大小的窗口 |

 ## 算法演练

 1. 创建一个`days`长度数组`n`在哪里`days[i]`代表那一天`i+1-th`灯泡亮起。 迭代一遍`bulbs`填充它：`days[bulb-1] = day_index + 1`。 
2. 初始化`res = infinity`存储满足条件的最早一天。 
3. 设置`left = 0`和`right = k + 1`。 这些是差距潜在“边缘”的指数。 
4. 滑动一个窗口`left`到最后`days`数组：

 1. 对于窗户内的每个灯泡（`left+1`到`right-1`），检查它是否在**之前**任一边缘（`days[left]`或者`days[right]`）。 如果是，请移动`left`到这个灯泡并重置`right = left + k + 1`。 
2. 如果窗口有效（所有内部灯泡晚于边缘打开），则更新`res`和`max(days[left], days[right])`。 
3. 移动`left`减 1 并更新`right = left + k + 1`。 
5. 如果`res`仍然是`infinity`循环结束后，返回`-1`。 否则，返回`res`。 

**为什么有效：**`days`数组对每个灯泡打开的确切日期进行编码。 通过检查窗口的大小`k+2`，我们直接强制执行以下条件：`k`灯泡在两个灯泡之间关闭。 稍后打开内部灯泡可确保当天间隙是空的。 

## Python 解决方案```python
from typing import List

class Solution:
    def kEmptySlots(self, bulbs: List[int], k: int) -> int:
        n = len(bulbs)
        days = [0] * n
        for day, bulb in enumerate(bulbs):
            days[bulb - 1] = day + 1

        res = float('inf')
        left, right = 0, k + 1

        while right < n:
            valid = True
            for i in range(left + 1, right):
                if days[i] < days[left] or days[i] < days[right]:
                    left = i
                    right = left + k + 1
                    valid = False
                    break
            if valid:
                res = min(res, max(days[left], days[right]))
                left = right
                right = left + k + 1

        return -1 if res == float('inf') else res
```该实现首先创建`days`数组，它可以让我们将问题从动态的日常模拟转换为静态窗口检查。 滑动窗口循环确保我们有效地仅检查有效的候选窗口。 移动`left`到违规的灯泡确保我们永远不会重新访问无效的窗口。 

## 解决方案```go
func kEmptySlots(bulbs []int, k int) int {
    n := len(bulbs)
    days := make([]int, n)
    for day, bulb := range bulbs {
        days[bulb-1] = day + 1
    }

    res := n + 1
    left, right := 0, k+1

    for right < n {
        valid := true
        for i := left + 1; i < right; i++ {
            if days[i] < days[left] || days[i] < days[right] {
                left = i
                right = left + k + 1
                valid = false
                break
            }
        }
        if valid {
            if days[left] > days[right] {
                if days[left] < res {
                    res = days[left]
                }
            } else {
                if days[right] < res {
                    res = days[right]
                }
            }
            left = right
            right = left + k + 1
        }
    }

    if res == n+1 {
        return -1
    }
    return res
}
```在 Go 中，切片和索引的行为与 Python 列表类似。 主要区别在于初始化`res`到`n+1`而不是`infinity`。 循环和比较在其他方面是相同的。 

## 工作示例

 **示例1：**`bulbs = [1,3,2], k = 1`逐步：

 1.`days = [1, 3, 2]`2. 启动窗口`left=0`,`right=2`3. 检查左右之间的内灯泡（`i=1`）：`days[1]=3`,`days[left]=1`,`days[right]=2`。`days[i] > days[left]`和`days[i] > days[right]`？ 不，`3 > 1 and 3 > 2`有效的。 
4. 更新`res = max(days[left], days[right]) = max(1, 2) = 2`返回`2`。 

**示例2：**`bulbs = [1,2,3], k = 1`1.`days = [1, 2, 3]`2. 窗户`left=0`,`right=2`3. 内灯泡`i=1`,`days[i]=2`<`days[right]=3`？ 是 → 窗口无效。 移动`left=1`,`right=3`（出界）

 返回`-1`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们滑动一扇窗户`days`每个内灯泡最多检查一次 |
 | 空间| O(n) | 额外的`days`大小数组`n`|

 该算法是线性的，因为每个灯泡最多被视为窗口边缘一次。 滑动窗口确保没有嵌套的完整扫描。
