 **难度：** 🟡 中等

 ## 解决方案

 ## 问题理解

 问题是要求我们找到二维二进制矩阵中最大的陆地连通面积。 矩阵中的每个单元代表水（`0`）或土地（`1`）。 一群`1`s 形成一个岛，如果`1`**4 个方向**（上、下、左或右）连接。 对角线连接不算数。 任务是遍历整个网格，识别所有岛屿，计算它们的面积，并返回找到的最大面积。 如果网格中不存在土地，我们返回`0`。 

输入是一个二维列表`grid`有尺寸`m x n`， 在哪里`1 <= m, n <= 50`。 这个约束告诉我们网格相对较小，因此时间复杂度高达`O(m * n)`是可以接受的。 网格值保证为`0`或者`1`，所以我们不需要验证输入值。 

边缘情况包括根本没有陆地的网格、单行或单列的网格或多个大小相等的小岛。 该问题保证所有网格边缘都被水包围，从而简化了边界检查。 

## 方法

 暴力方法将迭代网格中的每个单元。 每当一个`1`如果发现，我们可以使用 DFS 或 BFS 递归或迭代地探索所有连接的陆地单元，计算该岛的大小。 每个访问过的单元格都需要标记以避免重复计数。 这种方法是正确的，因为它系统地探索每个岛，但它可能会在效率较低的实现中多次重新访问单元格，从而使其速度变慢。 对于给定的约束，这仍然是可行的，但我们可以通过立即标记访问过的单元来优化它。 

最佳解决方案的关键见解是使用**DFS 或 BFS 并标记已访问的单元**。 通过将每个访问过的陆地单元转换为`0`（水），我们避免重新审视它。 这允许对每个陆地单元进行一次遍历，从而减少不必要的重复工作。 由于简单性和基于堆栈的递归，DFS 通常是首选，而 BFS 则通过队列进行迭代。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O((m * n) * k) | O(m * n) | 探索每个陆地单元，但可能会多次重新访问部分岛屿 |
 | 最优（DFS/BFS）| O(m * n) | O(m * n) | 每个陆地单元仅被访问一次，标记单元可防止重新访问 |

 ## 算法演练

 1. 初始化变量`max_area`到`0`追踪发现的最大岛屿。 
2. 迭代每个单元格`(i, j)`在网格中。 
3. 当单元格有值时`1`找到后，从该单元格启动 DFS 或 BFS 来探索整个岛屿。 
4. 在探索过程中，对于访问过的每个陆地单元，将其标记为`0`来表明它已经被计算在内。 这可以防止重复计算。 
5. 计算本次探索期间访问的单元格总数。 这给出了当前岛屿的面积。 
6. 更新`max_area`如果当前岛屿的面积大于先前的最大值。 
7. 继续迭代网格，直到处理完所有单元格。 
8. 返回`max_area`结果。 

为什么它有效：不变的是每个陆地单元都被访问一次。 通过将访问过的单元标记为水，该算法保证每个岛都被精确计数一次。 由于我们递归或迭代地探索所有方向，因此不会错过任何连接的土地，并且始终跟踪最大面积。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        def dfs(i: int, j: int) -> int:
            if i < 0 or i >= len(grid) or j < 0 or j >= len(grid[0]) or grid[i][j] == 0:
                return 0
            grid[i][j] = 0  # mark visited
            area = 1
            area += dfs(i + 1, j)
            area += dfs(i - 1, j)
            area += dfs(i, j + 1)
            area += dfs(i, j - 1)
            return area
        
        max_area = 0
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if grid[i][j] == 1:
                    max_area = max(max_area, dfs(i, j))
        return max_area
```Python 实现使用辅助 DFS 函数来递归地探索岛屿。 每个递归调用都会检查边界条件以及单元是否是水。 DFS 函数对所有连接的陆地单元的面积进行求和。 在主迭代期间，我们更新`max_area`每当计算新的岛屿面积时。 

## 解决方案```go
func maxAreaOfIsland(grid [][]int) int {
    var dfs func(i, j int) int
    dfs = func(i, j int) int {
        if i < 0 || i >= len(grid) || j < 0 || j >= len(grid[0]) || grid[i][j] == 0 {
            return 0
        }
        grid[i][j] = 0
        area := 1
        area += dfs(i+1, j)
        area += dfs(i-1, j)
        area += dfs(i, j+1)
        area += dfs(i, j-1)
        return area
    }

    maxArea := 0
    for i := 0; i < len(grid); i++ {
        for j := 0; j < len(grid[0]); j++ {
            if grid[i][j] == 1 {
                maxArea = max(maxArea, dfs(i, j))
            }
        }
    }
    return maxArea
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```Go 实现镜像了 Python 版本。 递归 DFS 是使用内部函数闭包定义的。 Go 需要明确的`max`helper 因为标准库不提供通用函数。 切片索引和边界检查与 Python 类似，但 Go 需要明确地处理整数。 

## 工作示例

 **示例1**：

 第一次 DFS 调用期间的网格状态`(0, 2)`:

 | 步骤| DFS 位置 | 细胞标记| 当前区域 | 最大面积 |
 | --- | --- | --- | --- | --- |
 | 1 | (0,2) | (0,2) | 1 | 1 |
 | 2 | (1,2) | (1,2) | 2 | 2 |
 | 3 | (2,2) | (2,2) | 3 | 3 |
 | 4 | (2,1) | (2,1) | 4 | 4 |
 | 5 | (3,1) | (3,1) | 5 | 5 |
 | 6 | (4,1) | (4,1) | 6 | 6 |

 完成DFS后，max_area更新为6。其他岛屿较小，所以最终输出为`6`。 

**示例2**：

 网格全为零。 不进行 DFS 调用。 剩余最大面积`0`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n) | 每个单元格都被访问一次。 DFS 不会重新访问标记的单元格。 |
 | 空间| O(m * n) | 最坏情况下递归的堆栈空间是跨越整个网格的大岛。 |

 该算法对于给定的约束是有效的，因为最大网格尺寸为`50x50 = 2500`细胞。 即使在最坏的情况下，递归深度也仅限于陆地单元的数量。
