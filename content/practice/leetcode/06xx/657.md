[LeetCode 第 657 题](https://leetcode.com/problems/robot-return-to-origin/)

 **难度：** 🟢简单
 **主题：** 字符串、模拟

 ## 解决方案

 ## 问题理解

 这个问题要求我们判断一个机器人是否从原点开始`(0, 0)`在 2D 平面上，执行一系列移动后返回原点。 每个动作都由字符串中的一个字符表示：`'R'`向右移动，`'L'`向左移动，`'U'`向上移动，并且`'D'`向下移动。 机器人每步总是精确移动一个单位，并且它“面向”的方向并不重要。 

输入是单个字符串`moves`长度可达20,000。 输出是一个布尔值：`true`如果机器人结束于`(0, 0)`在所有的动作之后，`false`否则。 由于移动仅限于这四个字符并且字符串长度适中，因此线性时间算法是可行的。 

边缘情况包括机器人仅进行垂直移动而没有水平补偿，或仅进行水平移动而没有垂直补偿。 该问题保证字符串非空并且仅包含有效的移动，因此我们不需要处理无效的输入字符。 

## 方法

 **暴力方法**很简单：我们一步步模拟机器人的位置。 初始化坐标`(x, y)`在`(0, 0)`并迭代每个动作。 为了`'R'`增量`x`， 为了`'L'`递减`x`， 为了`'U'`增量`y`，并且对于`'D'`递减`y`。 处理完所有动作后，检查是否`(x, y)`等于`(0, 0)`。 这是有效的，因为机器人返回原点必须抵消相反移动的总和。 

**最佳方法的关键见解**是我们只需要计算相反移动的发生次数。 机器人返回原点当且仅当`'L'`移动次数等于`'R'`动作和次数`'U'`移动次数等于`'D'`移动。 这允许使用简单的计数方法而无需跟踪精确坐标，但实际上，两种方法具有相同的时间复杂度。 计数方法的记账量可能会稍微少一些。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 逐步模拟坐标。 |
 | 计数| O(n) | O(1) | O(1) | 计算每种移动类型的出现次数并比较相反的情况。 |

 ## 算法演练

 1.初始化两个变量`x`和`y`为 0，代表机器人的水平和垂直位置。 
2. 遍历字符串中的每个字符`moves`。 
3. 如果角色是`'R'`, 增量`x`。 如果是的话`'L'`, 递减`x`。 
4.如果角色是`'U'`, 增量`y`。 如果是的话`'D'`, 递减`y`。 
5. 处理完所有动作后，检查两者是否`x`和`y`是 0。 
6. 返回`true`如果`(x, y)`等于`(0, 0)`，否则返回`false`。 

**为什么有效：** 每次移动都会以一致的方式直接更新机器人的坐标。 相反的移动会相互抵消，因此只有当水平和垂直位移之和为零时，机器人才会返回原点。 这个不变量保证了正确性。 

## Python 解决方案```python
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        x = 0
        y = 0
        for move in moves:
            if move == 'R':
                x += 1
            elif move == 'L':
                x -= 1
            elif move == 'U':
                y += 1
            elif move == 'D':
                y -= 1
        return x == 0 and y == 0
```在这个实现中，我们初始化坐标`(x, y)`在原点并迭代每个动作。 每次移动都会更新相应的坐标。 最后，我们返回两个坐标是否都归零，这与算法演练完全匹配。 

## 解决方案```go
func judgeCircle(moves string) bool {
    x, y := 0, 0
    for _, move := range moves {
        switch move {
        case 'R':
            x++
        case 'L':
            x--
        case 'U':
            y++
        case 'D':
            y--
        }
    }
    return x == 0 && y == 0
}
```Go 解决方案反映了 Python 解决方案。 我们使用 a 迭代字符串中的每个符文`switch`更新声明`x`或者`y`。 不用担心 nil 值，因为输入字符串保证有效且非空。

 ## 边缘情况

 一个重要的边缘情况是单步移动。 由于机器人移动了一个单位，无法返回原点，函数正确返回`false`。 

另一个边缘情况是完美平衡的序列，无论顺序如何，移动都会相互抵消。 我们的坐标更新方法保证最终的坐标是`(0, 0)`如果移动取消。 

第三种边缘情况是长的不平衡序列。 即使在一个方向上有很多移动，该函数也将正确计算净位移而不会溢出，因为 Python 整数是任意精度的，而 Go 整数在问题约束内是安全的。 

此方法还处理仅垂直或仅水平移动的序列，返回`false`必要时。
