 ## 解决方案

 ## 问题理解

 该问题要求我们实现一个循环队列，一个固定大小的队列，其中末尾回绕到开头以有效地重用空白空间。 在用数组实现的普通队列中，一旦数组填满，即使元素从前面出队，如果不移动数组，新元素也无法入队。 循环队列通过将数组视为循环来解决这个问题，因此最后一个索引之后的下一个插入可以发生在索引处`0`如果有空间的话。 

输入由对队列对象的方法调用组成：`enQueue`添加元素，`deQueue`删除元素，`Front`和`Rear`从正面和背面读取元素，并且`isEmpty`/`isFull`检查队列状态。 输出是这些调用的返回值。 约束表示队列大小`k`至多是`1000`并且至多`3000`执行操作。 这使得基于阵列的解决方案变得可行，而无需担心性能限制。 

边缘情况包括尝试入队到满队列、从空队列出队以及读取`Front`或者`Rear`当队列为空时。 正确处理环绕是至关重要的； 幼稚的实现通常会在索引方面出现相差一的错误。 

## 方法

 强力方法可以使用动态数组或列表，并在每个出队上移动元素以维持索引处的前端`0`。 这是正确的但效率低下，因为每次出队时移动元素都会导致`O(n)`每次出队操作的时间，这是不必要的。 

最佳方法使用带有两个指针的固定大小数组，`front`和`rear`，和一个`count`的元素。`enQueue`插入于`rear`并将其向前移动模数`k`。`deQueue`动作`front`正向模数`k`。`isEmpty`检查是否`count`为零，并且`isFull`检查是否`count`等于`k`。 这种方法维持了`O(1)`所有操作都需要时间，并且不需要移动任何元素。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每个 deQueue | O(n) O(k) | 出列时移动元素 |
 | 最佳| 每次操作 O(1) | O(k) | 使用带有 front、rear、count 的数组； 换行索引模 k |

 ## 算法演练

 1.用size的固定大小数组初始化队列`k`。 放`front`和`rear`到`0`和`count`到`0`。 
2. 至`enQueue(value)`，首先检查队列是否已满（`count == k`）。 如果满则返回`False`。 否则，插入`value`在`rear`, 增量`rear`模数`k`，并增加`count`。 返回`True`。 
3. 到`deQueue()`，首先检查队列是否为空（`count == 0`）。 如果为空则返回`False`。 否则，增加`front`模数`k`并减少`count`。 返回`True`。 
4.`Front()`回报`-1`如果队列为空。 否则，返回值`front`。 
5.`Rear()`回报`-1`如果队列为空。 否则，返回值`(rear - 1 + k) % k`因为`rear`指向下一个插入索引。 
6.`isEmpty()`回报`True`如果`count == 0`， 别的`False`。 
7.`isFull()`回报`True`如果`count == k`， 别的`False`。 

该算法之所以有效，是因为结合了`front`,`rear`， 和`count`始终保持正确的元素数量并确保所有操作遵循 FIFO 顺序。 使用模运算保证了循环行为。 

## Python 解决方案```python
class MyCircularQueue:

    def __init__(self, k: int):
        self.queue = [0] * k
        self.k = k
        self.front = 0
        self.rear = 0
        self.count = 0

    def enQueue(self, value: int) -> bool:
        if self.isFull():
            return False
        self.queue[self.rear] = value
        self.rear = (self.rear + 1) % self.k
        self.count += 1
        return True

    def deQueue(self) -> bool:
        if self.isEmpty():
            return False
        self.front = (self.front + 1) % self.k
        self.count -= 1
        return True

    def Front(self) -> int:
        if self.isEmpty():
            return -1
        return self.queue[self.front]

    def Rear(self) -> int:
        if self.isEmpty():
            return -1
        return self.queue[(self.rear - 1 + self.k) % self.k]

    def isEmpty(self) -> bool:
        return self.count == 0

    def isFull(self) -> bool:
        return self.count == self.k
```Python实现使用固定数组`queue`存储元素并维护`front`,`rear`， 和`count`。 所有运算都使用模算术来处理循环行为。 这保证了`O(1)`每个操作和正确的环绕。 

## 解决方案```go
type MyCircularQueue struct {
	queue       []int
	front, rear int
	count, k    int
}

func Constructor(k int) MyCircularQueue {
	return MyCircularQueue{
		queue: make([]int, k),
		k:     k,
	}
}

func (this *MyCircularQueue) EnQueue(value int) bool {
	if this.IsFull() {
		return false
	}
	this.queue[this.rear] = value
	this.rear = (this.rear + 1) % this.k
	this.count++
	return true
}

func (this *MyCircularQueue) DeQueue() bool {
	if this.IsEmpty() {
		return false
	}
	this.front = (this.front + 1) % this.k
	this.count--
	return true
}

func (this *MyCircularQueue) Front() int {
	if this.IsEmpty() {
		return -1
	}
	return this.queue[this.front]
}

func (this *MyCircularQueue) Rear() int {
	if this.IsEmpty() {
		return -1
	}
	return this.queue[(this.rear-1+this.k)%this.k]
}

func (this *MyCircularQueue) IsEmpty() bool {
	return this.count == 0
}

func (this *MyCircularQueue) IsFull() bool {
	return this.count == this.k
}
```Go 解决方案与 Python 类似，但使用固定长度和整数字段的切片来跟踪状态。 使用模运算以相同方式处理环绕。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 每次操作 O(1) | 所有操作都涉及简单的指针更新或检查 |
 | 空间| O(k) | 固定大小数组最多可存储 k 个元素 |

 因为我们从不移动元素并且只更新索引模`k`，该算法实现每次操作的恒定时间。
