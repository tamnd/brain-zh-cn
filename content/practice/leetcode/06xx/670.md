[LeetCode 第 670 题](https://leetcode.com/problems/maximum-swap/)

 **难度：** 🟡 中等
 **主题：** 数学、贪心

 ## 解决方案

 ## 问题理解

 该问题要求我们取一个整数`num`并找到通过交换**最多两位数字**可以创建的最大数字。 换句话说，我们可以选择数字中的两个位置，交换它们的数字，并且我们希望得到的数字尽可能大。 如果没有交换会增加数字，我们只需返回原始数字。 

输入`num`保证是一个非负整数，最多`10^8`。 这意味着该号码最多可以有 9 位数字。 预期输出是一个整数，表示可从`num`最多一次交换。 

重要的边缘情况包括已经按降序排列的数字、具有重复数字的数字以及潜在交换后带有前导零的数字（尽管交换不能引入实际的前导零，因为`num >= 0`）。 

## 方法

 ### 蛮力方法

 暴力方法会考虑每对可能的数字位置，交换它们，并跟踪获得的最大数字。 对于一个数字`n`数字，这需要检查所有对`(i, j)`和`0 <= i < j < n`。 每次交换后，必须计算整数值以查看它是否大于当前最大值。 这种方法是正确的，因为它详尽地检查了每种可能性，但效率很低：对于 9 位数字，我们将执行 36 次交换，而对于更大的数字，这可能会显着增长。 时间复杂度为`O(n^2)`掉期乘以`O(n)`从数字中重建数字，使其`O(n^3)`总共。 

### 最佳方法

 最佳解决方案的关键观察是**最大可能的数字是通过将第一个较小的数字（从左起）与其后面出现的最大数字交换来获得的**。 要实现这一点：

 1. 将数字转换为数字列表。 
2. 跟踪每个数字 (0-9) 的 **最后一次出现**。 
3. 从左到右遍历数字，对于每个数字，检查该数字后面是否有更大的数字（从 9 开始一直到当前数字 + 1）。 
4. 交换第一个这样的对并返回结果。 

这种方法在**线性时间内起作用**`O(n)`和用途`O(1)`额外空间（最后位置的常量 10 元素数组）。 原因是，通过将最左边的较小数字与其右侧最大的可能数字交换，我们可以尽早最大化数字中的值。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 检查所有可能的交换，每次重建整数 |
 | 最佳 | O(n) | O(1) | O(1) | 使用最后出现映射和贪婪的从左到右交换 |

 ## 算法演练

 1. 转换整数`num`到数字列表，以便我们可以轻松访问和交换它们。 
2. 创建一个`last`数组或字典来存储每个数字（0-9）的**最后一次出现的索引**。 这有助于我们快速识别最大数字出现在数字后面的位置。 
3. 从左到右遍历数字列表。 对于每个数字`d`在索引处`i`，检查数字`9`下降到`d + 1`。 
4. 如果数字更大`d_larger`存在及其最后一次出现`j`是在之后`i`， 交换`digits[i]`和`digits[j]`。 这保证了我们通过进行第一次显着的向左交换来最大限度地增加数量。 
5. 将数字列表转换回整数并返回。 如果没有找到交换，则返回原始号码。 

**为什么起作用**：该算法确保可增加的最左边的数字与其右侧最大的可用数字交换。 任何稍后的交换都不会产生那么大的影响，因为左边的数字在确定数字的值方面更重要。 这保证了最多一次交换的全局最大值。 

## Python 解决方案```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        digits = list(str(num))
        last = {int(d): i for i, d in enumerate(digits)}
        
        for i, d in enumerate(digits):
            for larger in range(9, int(d), -1):
                if last.get(larger, -1) > i:
                    digits[i], digits[last[larger]] = digits[last[larger]], digits[i]
                    return int("".join(digits))
        return num
```Python 解决方案首先将数字转换为其数字列表，然后创建每个数字到其最后位置的映射。 它按降序检查可能的较大数字的交换，确保第一次交换使价值最大化。 如果不存在这样的交换，则返回原始数字。 

## 解决方案```go
func maximumSwap(num int) int {
    digits := []byte(fmt.Sprintf("%d", num))
    last := [10]int{}
    for i, d := range digits {
        last[d-'0'] = i
    }

    for i := 0; i < len(digits); i++ {
        for d := 9; d > int(digits[i]-'0'); d-- {
            if last[d] > i {
                digits[i], digits[last[d]] = digits[last[d]], digits[i]
                res, _ := strconv.Atoi(string(digits))
                return res
            }
        }
    }
    return num
}
```Go 实现遵循与 Python 相同的逻辑。 一个`byte`切片代表数字，数组跟踪每个数字的最后一次出现。`strconv.Atoi`将切片转换回整数。 由于边缘情况不需要特殊处理`num`保证非负。

 ## 边缘情况

 一个重要的边缘情况是**个位数**，例如`0`或者`7`。 由于没有其他数字可以交换，因此该函数必须返回数字本身。 该实现处理了这个问题，因为循环永远找不到更大的数字来交换。 

另一个边缘情况是**具有重复数字的数字**，例如`9973`。 同一数字多次出现可能会混淆那些选择第一次出现而不是最后一次出现的简单算法。 通过跟踪每个数字的最后一次出现，该解决方案保证选择最大的交换。 

最后，**已经按降序排列的数字**，例如`54321`，必须返回原始号码。 任何交换都会减少该值，因此该函数应该正确检测到不存在有益的交换并返回原始整数。 该算法自然地通过仅在稍后找到更大的数字时进行交换来处理此问题。
