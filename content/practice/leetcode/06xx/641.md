 ## 解决方案

 ## 问题理解

 该问题要求我们设计一个循环双端队列，也称为双端队列。 双端队列是一种允许从前面和后面插入和删除的数据结构。 与普通队列仅支持后端入队和前端出队不同，双端队列可以高效地支持两端操作。 

“循环”一词是这个问题的关键部分。 当结构到达数组末尾时，索引不会移动元素，而是回绕到开头。 这使得所有操作都可以保持高效，而无需重新分配或移动元素。 

我们必须实现一个具有以下功能的类：

 - 插入前面
 - 插入后部
 - 从前面删除
 - 从后面删除
 - 检索前面的值
 - 检索后面的值
 - 检查双端队列是否为空
 - 检查双端队列是否已满

 双端队列有固定容量`k`，这意味着它不能动态增长。 如果双端队列已满，则插入操作必须失败并返回`false`。 同样，如果双端队列为空，则删除操作必须失败并返回`false`。 

限制很小：

 -`1 <= k <= 1000`- 至多`2000`运营

 尽管约束并不大，但问题本质上是一个数据结构设计问题。 目标不仅仅是通过约束，而是高效地实施所有操作。 

简单的实现可能会在从前面插入或删除时重复移动数组内的元素。 这在功能上是可行的，但它会使一些操作线性时间。 预期的解决方案实现了每次操作的恒定时间。 

一些边缘情况很重要：

 - 插入完整双端队列
 - 从空双端队列中删除
 - 当索引移过数组的任一端时正确包装索引
 - 处理双端队列仅包含一个元素的情况
 - 在多次绕行后保持正确的前后位置

 该问题保证所有方法调用都遵循所需的签名，并且值始终在允许的范围内。 

## 方法

 ### 蛮力方法

 最直接的解决方案是使用动态列表或数组并手动模拟双端队列行为。 

例如：

-`insertFront`可以使用`list.insert(0, value)`-`insertLast`可以使用`append`-`deleteFront`可以使用`pop(0)`-`deleteLast`可以使用`pop()`这种方法很容易实现并产生正确的结果，因为列表始终保持元素的正确顺序。 

然而，基于标准数组的列表前面的操作成本很高。 在索引处插入或删除`0`需要将每个剩余元素移动一个位置。 这使得这些操作`O(n)`。 

尽管约束相对较小，但这并不能满足高效双端队列操作的预期设计要求。 

### 最佳方法

 最佳解决方案是使用固定大小的圆形阵列。 

关键的见解是，在从任一端插入或删除时，我们不需要物理移动元素。 相反，我们坚持：

 - A`front`指针
 - A`rear`指针
 - A`size`柜台

 该阵列就像一个环。 当索引移过数组末尾时，它会使用模算术回绕到开头。 

例如：```
(index + 1) % capacity
```这种循环行为允许每个操作在恒定时间内完成。 

最重要的观察是双端队列的逻辑顺序不需要与内存中的物理布局匹配。 我们只需要正确的指针管理。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | 每个前端操作的 O(n) | O(k) | 使用列表移位进行前面的插入和删除 |
 | 最佳| 每次操作 O(1) | O(k) | 使用带有模运算的循环数组 |

 ## 算法演练

 1.初始化一个长度固定的数组`k`。 

该数组存储所有双端队列元素。 由于最大尺寸是固定的，我们永远不需要调整它的大小。 
2. 维持`front`指数。 

这`front`index 始终指向双端队列的当前前端元素。 
3. 保持`rear`指数。 

这`rear`index 始终指向下一次后插入发生的位置。 
4. 保持`size`多变的。 

这跟踪当前双端队列中的元素数量。 它允许我们确定双端队列是空还是满。 
5. 对于`insertFront`，首先检查双端队列是否已满。 

如果满则返回`False`。 

否则：

 - 移动`front`使用循环算术向后移动一位。 
- 将值存储在新的前面位置。 
- 增量`size`。 
6. 对于`insertLast`，首先检查双端队列是否已满。 

如果满则返回`False`。 

否则：

 - 存储当前值`rear`位置。 
- 移动`rear`使用循环算术向前推进。 
- 增量`size`。 
7. 对于`deleteFront`，首先检查双端队列是否为空。 

如果为空则返回`False`。 

否则：

 - 移动`front`前进一位。 
- 递减`size`。 
8.为了`deleteLast`，首先检查双端队列是否为空。 

如果为空则返回`False`。 

否则：

 - 移动`rear`向后退一位。 
- 递减`size`。 
9. 为了`getFront`，返回位于`front`如果双端队列不为空，则索引。 
10. 对于`getRear`，返回紧邻之前的元素`rear`指针。 

自从`rear`指向下一个插入位置，实际后部元素位于：```
(rear - 1 + capacity) % capacity
```1.`isEmpty`返回是否`size == 0`。 
2.`isFull`返回是否`size == capacity`。 

### 为什么它有效

 正确性来自于保持一致的不变量：

 -`front`始终指向第一个有效元素
 -`rear`总是指向后面的下一个插入位置
 -`size`始终等于存储元素的数量

 模算术保证索引始终保持在数组范围内，同时仍然表现得像循环结构。 由于元素永远不会移动，因此所有操作都保持恒定时间。 

## Python 解决方案```python
class MyCircularDeque:

    def __init__(self, k: int):
        self.capacity = k
        self.deque = [0] * k
        self.front = 0
        self.rear = 0
        self.size = 0

    def insertFront(self, value: int) -> bool:
        if self.isFull():
            return False

        self.front = (self.front - 1 + self.capacity) % self.capacity
        self.deque[self.front] = value
        self.size += 1

        return True

    def insertLast(self, value: int) -> bool:
        if self.isFull():
            return False

        self.deque[self.rear] = value
        self.rear = (self.rear + 1) % self.capacity
        self.size += 1

        return True

    def deleteFront(self) -> bool:
        if self.isEmpty():
            return False

        self.front = (self.front + 1) % self.capacity
        self.size -= 1

        return True

    def deleteLast(self) -> bool:
        if self.isEmpty():
            return False

        self.rear = (self.rear - 1 + self.capacity) % self.capacity
        self.size -= 1

        return True

    def getFront(self) -> int:
        if self.isEmpty():
            return -1

        return self.deque[self.front]

    def getRear(self) -> int:
        if self.isEmpty():
            return -1

        rear_index = (self.rear - 1 + self.capacity) % self.capacity
        return self.deque[rear_index]

    def isEmpty(self) -> bool:
        return self.size == 0

    def isFull(self) -> bool:
        return self.size == self.capacity
```实现首先分配一个固定大小的数组并初始化跟踪变量。 这`front`和`rear`指针都从索引开始`0`， 尽管`size`开始于`0`。 

插入方法首先验证空间是否存在。`insertFront`移动`front`在存储新值之前向后指针，而`insertLast`先存储值，然后前进`rear`指针。 

删除方法只是移动指针并减少大小计数器。 不会发生元素移位，这就是操作保持恒定时间的原因。 

检索方法依赖于指针不变量。`getFront`直接访问`front`索引，同时`getRear`计算之前的索引`rear`。 

模运算在整个实现过程中至关重要，因为它可以确保索引正确环绕。

 ## 边缘情况

 插入完整双端队列时会出现一种重要的边缘情况。 如果没有适当的大小检查，新的插入可能会覆盖现有元素并破坏结构。 该实现通过检查来防止这种情况发生`isFull()`在每次插入操作之前。 

另一个关键的边缘情况是从空双端队列中删除。 在不存在元素时尝试移动指针很容易产生无效状态或不正确的检索结果。 该实现通过立即返回来安全地处理这个问题`False`不修改任何内部状态。 

一个特别微妙的情况涉及圆形环绕。 例如，经过多次插入和删除后，`front`指针可能会变得比`rear`指针。 简单的实现可能会假设元素始终连续存储，这在循环缓冲区中是不正确的。 使用模算术可以保证索引保持有效且逻辑连接，无论它们绕回多少次。 

当双端队列只包含一个元素时，就会出现最后一种边缘情况。 在这种情况下，前端和后端操作都与相同的逻辑位置交互。 不正确的指针更新可能会意外地跳过或重复元素。 该实现通过依赖于`size`变量作为存在多少有效元素的权威来源。
