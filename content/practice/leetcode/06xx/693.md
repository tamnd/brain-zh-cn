[LeetCode 第 693 题](https://leetcode.com/problems/binary-number-with-alternating-bits/)

 **难度：** 🟢简单
 **主题：** 位操作

 ## 解决方案

 ## 问题理解

 该问题要求我们确定给定正整数的二进制表示是否`n`有交替位。 换句话说，对于二进制数字`n`，任何两个连续位都不应该是相同的。 例如，`101`是交替的，同时`111`不是因为它包含连续的。 

输入`n`保证是范围内的正整数`1 <= n <= 2^31 - 1`，对应于 32 位有符号整数范围。 该约束确保`n`可以使用 Python 或 Go 中的标准整数类型安全地处理而不会溢出。 

预期输出是一个布尔值：`true`如果`n`有交替位和`false`否则。 

重要的边缘情况包括尽可能小的输入`n = 1`，它通常具有交替的位、全为 1 的数字（例如，`7`)，以及以交替位结尾的数字`0`或者`1`。 

## 方法

 蛮力方法很简单。 我们可以重复提取数字的最低有效位并将其与前一位进行比较。 如果任意两个连续位相同，我们返回`false`。 否则，我们继续直到检查完所有位。 这种方法是正确的，因为它直接验证交替位的定义，但它可能对 32 位整数执行最多 32 次比较，这是可以接受的，但不是最佳的。 

更优化的解决方案是使用位操作。 考虑到对于具有交替位的数字，将数字右移一位并与原始数字进行异或应该会产生一个所有位设置为的二进制数`1`。 这是因为 XOR 返回`1`对于不同的位和`0`对于相等的位。 一旦我们得到这个 XOR 结果，我们就可以检查它是否具有以下形式`2^k - 1`通过验证`x & (x + 1) == 0`。 这个属性来自于对数字的观察`1`,`11`,`111`等，以二进制形式满足此恒等式。

 | 蛮力 | O(log n) | O(1) | O(1) | 迭代地将每个位与前一个位进行比较 |

 ## 算法演练

 1.从输入数字开始`n`。 
2. 计算`shifted = n >> 1`。 这会移动所有位`n`向右一个位置。 
3. 计算`xor_result = n ^ shifted`。 该 XOR 运算将产生一个数字，其中每一位都是`1`如果原始位不同，这正是交替位产生的结果。 
4. 检查是否`xor_result`是所有的序列`1`s，使用表达式`xor_result & (xor_result + 1)`。 如果结果是`0`， 然后`xor_result`是这样的形式`2^k - 1`， 意义`n`有交替位。 
5. 返回`true`如果检查通过，否则`false`。 

工作原理：该算法依赖于交替序列中连续位的 XOR 产生全 1 的特性，并且二进制中的所有 1 都满足恒等式`x & (x + 1) == 0`。 这个不变量保证了所有有效输入数字的正确性。 

## Python 解决方案```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        shifted = n >> 1
        xor_result = n ^ shifted
        return (xor_result & (xor_result + 1)) == 0
```在这个实现中，第一步发生了变化`n`加一以对齐连续位以进行比较。 XOR 运算检测位的不同之处，最后的检查确保所有位都在`xor_result`被设置，表示交替位。 此方法避免了单独迭代每个位。 

## 解决方案```go
func hasAlternatingBits(n int) bool {
    shifted := n >> 1
    xorResult := n ^ shifted
    return (xorResult & (xorResult + 1)) == 0
}
```Go 的实现反映了 Python 的方法。 位运算直接用于整数。 在问题约束的 32 位范围内，不存在整数溢出的问题，并且 Go 处理按位运算`int`有效地类型。

 ## 边缘情况

 一个重要的边缘情况是`n = 1`。 由于它只有一位，因此应该返回 true。 如果不能正确处理单位数字，比较连续位的简单实现可能会失败。 我们的按位方法可以自然地处理它，因为`n`和`n >> 1`产生`1`，以及最终检查`(1 & 2) == 0`成立。 

另一个边缘情况是数字的二进制表示形式全部为 1，例如`n = 7`或者`n = 127`。 这些数字没有交替位，并且 XOR 方法可以正确检测模式，并返回 false，因为 XOR 结果并非全为 1。 

第三种边缘情况是交替模式以以下结尾的数字`0`， 例如`n = 10`（二进制 1010）。 一些迭代解决方案可能假设交替序列必须以`1`。 我们的解决方案没有这种偏差，因为异或和位检查正确处理这两种情况。
