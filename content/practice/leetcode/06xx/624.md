 **难度：** 🟡 中等
 **主题：** 数组、贪心

 ## 解决方案

 ## 问题理解

 问题提出了一个列表`m`数组，每个数组都按升序单独排序。 系统会要求您从两个不同的数组中选择一个元素并计算这两个元素之间的绝对差（定义为距离）。 目标是找到任何此类对之间的**最大可能距离**。 

输入表示多个整数数组。 每个数组都已经排序，这是一个关键属性。 预期输出是一个整数，是通过从一个数组中选择一个元素并从另一个数组中选择另一个元素可获得的最大绝对差。 

约束表明所有数组中的整数总数不会超过`10^5`，并且数组单独可以非常小（小至长度 1）。 数组可以包含负数和大正数，最多可达`10^4`。 该问题保证每个数组至少包含一个整数，但不保证所有数组的长度相等。 

重要的边缘情况包括具有单个元素的数组、包含相同数字的数组或跨越负数和正数的数组。 由于上限，考虑数组中所有元素对的简单解决方案可能会非常慢`10^5`整数，因此需要一种优化方法。 

## 方法

 **暴力方法**很简单：迭代所有数组对，然后迭代这些数组中的所有元素以计算每个可能的绝对差。 这保证了正确性，但在计算上是不可行的，因为时间复杂度为`O(N^2)`在最坏的情况下，其中`N`是整数的总数。 

最佳解决方案的**关键观察**是，由于每个数组都是排序的，因此每个数组的**最小和最大元素**足以计算与其他数组的最大距离。 具体来说，对于每个数组，可以通过将其最小元素与先前见过的数组的最大值配对或者将其最大元素与先前见过的数组的最小值配对来实现最大可能距离。 这一观察允许我们在迭代数组时仅跟踪两个值：到目前为止看到的**全局最小值**和**全局最大值**，从而相应地更新最大距离。 这将时间复杂度降低到`O(m)`。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(N^2) | O(N^2) | O(1) | O(1) | 比较数组中的所有元素对 |
 | 最佳| O(米) | O(1) | O(1) | 跟踪先前数组的最小值和最大值以计算最大距离 |

 ## 算法演练

 1.初始化两个变量：`min_val`作为第一个数组的第一个元素并且`max_val`作为第一个数组的最后一个元素。 这些代表当前的全球最小值和最大值。 
2. 初始化变量`max_distance`为零以存储找到的最大距离。 
3. 从第二个数组开始迭代剩余的数组。 
4. 对于当前数组，计算其第一个元素与当前数组之间的距离`max_val`，以及它的最后一个元素与当前元素之间的距离`min_val`。 
5. 更新`max_distance`与最大电流`max_distance`以及步骤 4 中计算的两个距离。 
6. 更新`min_val`是当前的较小者`min_val`以及当前数组的第一个元素。 
7. 更新`max_val`是当前的较大者`max_val`以及当前数组的最后一个元素。 
8. 继续此过程，直到处理完所有数组。 
9. 返回`max_distance`。 

**为什么有效：** 该算法之所以有效，是因为最大距离必须涉及一个数组的最小元素和另一个数组的最大元素。 通过维护迄今为止看到的全局最小值和最大值，我们确保考虑所有潜在的最大距离，而无需冗余地比较每个元素对。 

## Python 解决方案```python
from typing import List

class Solution:
    def maxDistance(self, arrays: List[List[int]]) -> int:
        min_val = arrays[0][0]
        max_val = arrays[0][-1]
        max_distance = 0
        
        for arr in arrays[1:]:
            max_distance = max(max_distance, abs(arr[-1] - min_val), abs(max_val - arr[0]))
            min_val = min(min_val, arr[0])
            max_val = max(max_val, arr[-1])
        
        return max_distance
```**实现说明：**我们从初始化开始`min_val`和`max_val`第一个数组的最小值和最大值。 对于每个后续数组，我们使用第一个和最后一个元素计算两个可能的最大距离，并更新全局`max_distance`因此。 最后我们更新一下`min_val`和`max_val`包括当前数组。 这确保了我们在下一次迭代中始终拥有正确的全局最小值和最大值。 

## 解决方案```go
func maxDistance(arrays [][]int) int {
    minVal := arrays[0][0]
    maxVal := arrays[0][len(arrays[0])-1]
    maxDistance := 0
    
    for i := 1; i < len(arrays); i++ {
        arr := arrays[i]
        maxDistance = max(maxDistance, abs(arr[len(arr)-1]-minVal), abs(maxVal-arr[0]))
        minVal = min(minVal, arr[0])
        maxVal = max(maxVal, arr[len(arr)-1])
    }
    
    return maxDistance
}

func max(a, b, c int) int {
    if a >= b && a >= c {
        return a
    } else if b >= a && b >= c {
        return b
    }
    return c
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```**Go 实现说明：** Go 实现反映了 Python 方法。 辅助函数`max`,`min`， 和`abs`处理多重比较和绝对值计算。 使用 Go 切片而不是列表。 不需要对 nil 切片进行特殊处理，因为该问题保证每个数组至少包含一个元素。
