[LeetCode 第 686 题](https://leetcode.com/problems/repeated-string-match/)

 **难度：** 🟡 中等
 **主题：** 字符串、字符串匹配

 ## 解决方案

 ## 问题理解

 该问题要求我们确定一个字符串出现的最小次数`a`必须重复，以便另一个字符串`b`成为重复版本的子串`a`。 子字符串是字符串中的连续字符序列。 输入由两个字符串组成，`a`和`b`，长度都在 1 到 10,000 个字符之间。 输出是一个整数，表示最小重复次数，或者`-1`如果没有重复次数`b`重复的子串`a`。 

本质上，我们是在重复连接`a`与自身并检查是否`b`出现在结果字符串中的任何位置。 这个问题需要效率，因为对于长字符串来说，生成每个可能的重复的简单方法可能会非常慢。 

重要的边缘情况包括以下场景：`b`长于`a`， 在哪里`b`跨越两次重复之间的边界重叠`a`，以及情况`b`包含不存在于的字符`a`根本不。 约束保证`a`和`b`非空且由小写英文字母组成，但不保证`b`会重复出现`a`。 

## 方法

 暴力方法很简单：从空字符串开始，继续连接`a`，并在每次串联后检查是否`b`是一个子串。 这种方法保证找到正确的答案，因为我们正在详尽地检查所有可能的重复。 然而，它的时间复杂度很高，因为对于大输入大小，字符串连接和子字符串检查可能会变得昂贵，特别是当`b`很长。 

更优化解决方案的关键见解是`b`只能开始重叠`a`最多一次跨越重复边界。 因此，我们不需要检查无限次数的重复。 在实践中，重复`a`足够多的时间来超过长度`b`再加上一次额外的重复就足以确定是否`b`可以是一个子串。 这是因为`b`可以在一个重复的末尾附近开始并延伸到下一个重复，但它不能超出其长度超过两次重复。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m * k) | O(n * m * k) | O(n * k) | 连接`a`重复并检查子字符串，对于大字符串来说很慢 |
 | 最佳| O(n + m) | O(n + m) | 重复`a`至少要超过`b`长度和检查子字符串，利用 Python/Go 子字符串搜索 |

 ## 算法演练

 1. 计算所需的最小重复次数，使得重复字符串的长度至少与`b`。 计算如下：`ceil(len(b) / len(a))`。 
2. 重复`a`多次以形成初始候选字符串。 
3. 检查是否`b`是候选的子串。 如果是，则返回当前的重复次数。 
4.如果`b`未找到，再追加一个重复项`a`处理以下情况`b`重叠最后一个重复和新重复之间的边界。 
5. 再次检查是否`b`现在是一个子字符串。 如果是，则返回更新后的重复计数。 
6.如果`b`还是没有找到，返回`-1`因为没有重复将包含`b`。 

**为什么有效：** 该算法之所以有效是因为`b`只能跨越两次连续的重复`a`。 通过重复`a`刚好足以覆盖`b`再重复一次，我们确保所有可能的位置`b`无需进行不必要的串联即可进行检查，从而使算法高效。 

## Python 解决方案```python
class Solution:
    def repeatedStringMatch(self, a: str, b: str) -> int:
        from math import ceil
        
        # Calculate minimum repetitions needed
        min_repeats = ceil(len(b) / len(a))
        repeated_a = a * min_repeats
        
        # Check if b is a substring
        if b in repeated_a:
            return min_repeats
        
        # Check one more repetition for overlap
        repeated_a += a
        if b in repeated_a:
            return min_repeats + 1
        
        return -1
```Python 解决方案首先计算覆盖所需的最小重复次数`b`。 它首先检查是否`b`这些重复之后已经是一个子字符串。 如果没有，它会再追加一次重复来处理重叠的情况并再次检查。 如果`b`仍然缺席，它返回`-1`。 

## 解决方案```go
func repeatedStringMatch(a string, b string) int {
    minRepeats := (len(b) + len(a) - 1) / len(a) // ceil(len(b)/len(a))
    repeatedA := ""
    for i := 0; i < minRepeats; i++ {
        repeatedA += a
    }
    
    if strings.Contains(repeatedA, b) {
        return minRepeats
    }
    
    repeatedA += a
    if strings.Contains(repeatedA, b) {
        return minRepeats + 1
    }
    
    return -1
}
```Go 的实现与 Python 非常相似。 主要区别在于整数上限计算使用`(len(b) + len(a) - 1) / len(a)`， 和`strings.Contains`用于子字符串检查。 Go 将字符串处理为不可变的字节序列，因此重复连接在这里是安全的。 

## 工作示例

 **示例1：**`a = "abcd"`,`b = "cdabcdab"`1.`min_repeats = ceil(8 / 4) = 2`2.`repeated_a = "abcd" * 2 = "abcdabcd"`3. 检查子串：`"cdabcdab" not in "abcdabcd"`4. 再添加一个重复项：`"abcdabcdabcd"`5. 检查子串：`"cdabcdab" in "abcdabcdabcd"`→ 返回 3

 **示例2：**`a = "a"`,`b = "aa"`1.`min_repeats = ceil(2 / 1) = 2`2.`repeated_a = "aa"`3. 检查子串：`"aa" in "aa"`→ 返回 2

 ## 边缘情况

 **案例1：`b`不存在于`a`完全没有。** 如果`b`包含不在其中的字符`a`，任何重复都会失败。 我们的实现通过返回来自然地处理这个问题`-1`检查重复的字符串后。 

**案例2：`b`与重复的边界重叠。** 例如，`a = "ab"`和`b = "bab"`。 天真的方法可能会在两次重复后停止，错过重叠部分。 通过附加一次额外的重复，我们的解决方案可以正确检测`b`。 

**情况 3：最少的字符串。** 当`a`和`b`都是单个字符，算法仍然正常工作，返回`1`如果它们匹配或`-1`如果不。 该解决方案不假设字符串长度超过 1 个字符，并处理尽可能小的输入大小。
