[LeetCode 620 题](https://leetcode.com/problems/not-boring-movies/)

 **难度：** 🟢简单
 **主题：** 数据库

 ## 解决方案

 ## 问题理解

 问题是要求我们查询一个名为`Cinema`并根据两个条件返回一组经过过滤的电影：电影 ID 必须是奇数，并且其描述不能是奇数`"boring"`。 然后结果必须按电影的降序排序`rating`。 

换句话说，对于数组中的每一行`Cinema`表，我们检查是否`id`使用模运算是奇数（`id % 2 = 1`）并且如果`description`不等于字符串`"boring"`。 仅满足这两个条件的行才会包含在输出中。 输出预计保留所有列（`id`,`movie`,`description`,`rating`）但必须进行排序，以便评分较高的电影首先出现。 

主要限制和澄清包括：`id`是独一无二的，`rating`是 0 到 10 范围内的浮点数，有 2 位小数，并且模式中没有提到空值。 重要的边缘情况可能包括具有奇怪 ID 的电影，但是`"boring"`描述、所有 ID 均为偶数、或多部具有相同评级的电影（未指定决胜局，因此默认 SQL 排序就足够了）。 

## 方法

 暴力方法很简单：扫描整个`Cinema`表逐行过滤满足两个条件的行（`odd id`和`description != "boring"`），将结果存储在临时结构中，最后按评分降序排序。 这种方法是正确的，但依赖于全表扫描，如果表很大，则效率可能会很低。 

最佳方法是直接利用 SQL 过滤和排序。 使用`WHERE`子句，我们可以通过以下方式过滤行`id % 2 = 1`和`description != 'boring'`，然后对结果进行排序`ORDER BY rating DESC`。 SQL 引擎可以使用索引（如果可用）有效地处理过滤和排序，因此既简洁又高效。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 扫描所有行，手动过滤，在应用程序代码中排序 |
 | 最佳| O(n log n) | O(n log n) | O(1) | O(1) | 使用SQL`WHERE`+`ORDER BY`将过滤和排序推送到数据库|

 ## 算法演练

 1. 首先写一个`SELECT`语句来检索所有列`Cinema`桌子。 我们想要保存`id`,`movie`,`description`， 和`rating`。 
2.添加一个`WHERE`子句来过滤行。 使用`id % 2 = 1`仅选择具有奇数 ID 的行。 
3. 延长`WHERE`排除电影的子句`"boring"`在描述中。 与第一个条件结合使用`AND`。 
4. 添加一个`ORDER BY rating DESC`子句对结果进行排序`rating`列按降序排列，以便评分较高的电影首先出现。 
5. 执行SQL 查询。 数据库引擎将有效地应用过滤和排序，仅返回满足这两个条件的行，并根据需要进行排序。 

**为什么有效**：过滤`WHERE`确保仅包含相关行，同时`ORDER BY`保证所需的排序顺序。 这些子句的组合可在单个查询中产生正确的输出，而无需进行后处理。 

## Python 解决方案```python
# Python solution is not directly applicable since this is a SQL problem
# If required for execution via Python DB API:
import sqlite3
from typing import List, Tuple

def not_boring_movies(conn: sqlite3.Connection) -> List[Tuple[int, str, str, float]]:
    query = """
    SELECT id, movie, description, rating
    FROM Cinema
    WHERE id % 2 = 1 AND description != 'boring'
    ORDER BY rating DESC
    """
    cursor = conn.cursor()
    cursor.execute(query)
    return cursor.fetchall()
```Python 实现使用数据库连接来执行 SQL 查询。 该查询选择具有奇数 ID 和非无聊描述的行，并按评级对它们进行排序。 这`fetchall()`调用将所有行作为元组列表返回。 

## 解决方案```go
// Go solution using database/sql package
package main

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

type Movie struct {
    ID          int
    Movie       string
    Description string
    Rating      float64
}

func NotBoringMovies(db *sql.DB) ([]Movie, error) {
    query := `
    SELECT id, movie, description, rating
    FROM Cinema
    WHERE id % 2 = 1 AND description != 'boring'
    ORDER BY rating DESC
    `
    rows, err := db.Query(query)
    if err != nil {
        return nil, err
    }
    defer rows.Close()

    var result []Movie
    for rows.Next() {
        var m Movie
        if err := rows.Scan(&m.ID, &m.Movie, &m.Description, &m.Rating); err != nil {
            return nil, err
        }
        result = append(result, m)
    }
    return result, nil
}
```在 Go 中，解决方案定义了一个`Movie`使用结构体和查询数据库`db.Query`。 过滤和排序由 SQL 处理。 行被扫描到结构切片中，然后返回给调用者。

 结果：```
+----+------------+-------------+--------+

+----+------------+-------------+--------+
| 5  | House card | Interesting | 9.1    |

 ## 边缘情况

 一种重要的边缘情况是所有电影 ID 均为偶数。 在这种情况下，过滤`id % 2 = 1`将导致零行。 SQL 查询通过返回空结果集来正确处理此问题。 

当所有描述都已完成时，会出现另一种边缘情况`"boring"`。 即使某些 ID 是奇数，它们也不应该出现在输出中。 这`description != 'boring'`条件确保排除这些行。 

第三种边缘情况是多部电影具有相同的评级。 由于该问题没有指定超出评级的平局打破，因此具有相同评级的任何顺序都是可以接受的。 这`ORDER BY rating DESC`子句正确处理降序排序，将同等电影的相对顺序留给 SQL 引擎，这对于此问题是可以接受的。
