[LeetCode 第 671 题](https://leetcode.com/problems/second-minimum-node-in-a-binary-tree/)

 **难度：** 🟢简单
 **主题：** 树、深度优先搜索、二叉树

 ## 解决方案

 ## 问题理解

 该问题提供了一个**特殊的二叉树**，其中每个节点有零个或两个子节点，并且每个内部节点的值等于其两个子节点中较小的值。 此属性保证**根包含树中的最小值**，因为根始终是其直接子级中最小的，并且通过递归，是整个树中最小的。 

任务是找到所有节点中的**第二最小值**。 如果所有节点共享相同的值，则不存在第二最小值，并且该函数应返回`-1`。 

输入是一棵有 1 到 25 个节点的二叉树，节点值范围从 1 到$2^{31}-1$。 树属性确保最小值始终位于根，这简化了对第二最小值的搜索。 

关键边缘情况包括所有节点都相等的树、只有一个分支包含较大值的树以及恰好有两层的树。 

## 方法

 **暴力方法**是遍历所有节点，收集集合中的所有值以删除重复项，对它们进行排序，然后选择第二小的值。 这保证了正确性，但由于特殊的树属性，这是不必要的。 由于排序，其时间复杂度为 O(n log n)，存储所有唯一值的空间复杂度为 O(n)。 

**最佳方法**利用了根包含最小值的事实。 任何第二个最小值必须**严格大于根**。 我们可以递归地遍历树并忽略等于根的节点，除非它们包含子节点。 每当一个节点的值大于根时，我们就将其记录为第二个最小值的候选者。 这避免了不必要的存储或排序并降低了复杂性。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n) | 收集所有值，排序，选择第二个最小值 |
 | 最佳 | O(n) | O(h) | DFS遍历，只跟踪大于root的候选，h为树高|

 ## 算法演练

 1. 初始化变量`root_val`来存储根的值。 这是树中的最小值。 
2. 定义一个遍历树的递归辅助函数：

 - 如果节点是`None`， 返回`-1`。 
- 如果节点的值大于`root_val`，返回该值作为候选值。 
- 否则，递归调用左右子节点的助手。 
3. 合并左右结果：

 - 如果两者都是`-1`， 返回`-1`。 
- 如果有一个是`-1`，返回另一个。 
- 如果两者都不是`-1`，返回较小的那个。 
4. 调用根上的助手并返回其结果。 

**为什么有效：** 因为在根处保证最小值，所以该算法仅考虑严格大于根的值。 递归比较确保返回最小的候选者。 树属性保证较大的值不会出现在较小的值之上，从而保持正确性。 

## Python 解决方案```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int:
        if not root:
            return -1
        
        root_val = root.val
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return -1
            if node.val > root_val:
                return node.val
            
            left = dfs(node.left)
            right = dfs(node.right)
            
            if left == -1:
                return right
            if right == -1:
                return left
            return min(left, right)
        
        return dfs(root)
```这`dfs`函数递归地检查每个节点。 如果节点值大于根，则它成为候选节点。 如果一个节点等于根，我们继续搜索它的子节点。 这`min`最后的比较确保选择大于根的最小候选者。 

## 解决方案```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func findSecondMinimumValue(root *TreeNode) int {
    if root == nil {
        return -1
    }
    
    rootVal := root.Val
    
    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil {
            return -1
        }
        if node.Val > rootVal {
            return node.Val
        }
        
        left := dfs(node.Left)
        right := dfs(node.Right)
        
        if left == -1 {
            return right
        }
        if right == -1 {
            return left
        }
        if left < right {
            return left
        }
        return right
    }
    
    return dfs(root)
}
```在围棋中，`nil`代表失踪儿童。 递归结构反映了 Python 版本。 比较逻辑显式返回较小的非`-1`价值。

 ## 边缘情况

 **单节点树：** 应返回只有一个节点的树`-1`因为不存在第二个值。 该算法处理这个问题是因为 DFS 立即返回`-1`为了失踪的孩子。 

**所有节点相等：** 每个节点具有相同值的树应该返回`-1`。 由于DFS只考虑大于根的值，因此它不会找到任何候选者，正确返回`-1`。 

**树中第二个最小值：**在某些树中，第二个最小值可能不是根的直接子代。 例如，在`[2,2,5,null,null,5,7]`，DFS 确保正确比较像 5 和 7 这样的更深的候选，以找到比根大的最小的一个。 这表明需要遍历整棵树，而不是停在第一个较大的子树上。
