 ## 解决方案

 ## 问题理解

 此问题要求我们在给定单独价格和可选特价的情况下找到购买一组商品的最低成本。 我们得到三个主要输入：一个数组`price`指定每个商品的单价，一个数组`needs`指定我们要购买的每件商品的确切数量，以及一个二维数组`special`代表特别优惠。 每个报价在`special`包含所含商品的数量以及该报价的总价。 

输出是满足的最低可能成本`needs`完全正确，无需购买额外的物品。 这意味着我们不能超越任何`needs[i]`即使这会降低整体价格。 

关键约束提供了有关问题规模的重要提示。 物品数量`n`最多 6 个，每个需求最多 10 个。特价商品数量最多可达 100 个。因为`n`很小，我们可以考虑涉及探索报价组合的解决方案，但可能状态的总数呈指数增长`n`和`needs`。 该问题保证每个特价商品至少包含一件商品，因此没有一个商品是空的。 

重要的边缘情况包括`needs`当特别优惠比单独购买商品更贵时，或者当优惠在不超过需要的情况下无法使用时，全部为零（成本为零）。 解决方案必须正确处理这些情况。 

## 方法

 强力方法是递归地尝试特价优惠和个人购买的所有组合。 对于当前需求定义的每个状态，我们可以购买单独的物品或应用不超过剩余需求的任何特殊优惠。 这保证了正确性，因为它探索了每种可能性，但速度非常慢。 状态数为`(needs[0]+1) * (needs[1]+1) * ... * (needs[n-1]+1)`，这取决于`11^6 ≈ 1.7 million`州。 如果没有记忆，重复的计算会使这变得不可行。 

最佳解决方案的关键观察是问题表现出重叠的子问题。 对于任何给定的剩余需求集，最小成本仅取决于该状态，因此我们可以使用记忆来存储结果并避免重新计算。 通过治疗`needs`数组作为哈希映射中的元组键，我们可以有效地缓存每个状态的结果并通过剪枝执行递归搜索。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(选择^(n*max_need)) | O(n*max_need) | O(n*max_need) | 无需缓存即可递归探索所有优惠组合 |
 | 最佳| O(11^n * m) | O(11^n * m) | O(11^n) | O(11^n) | 带记忆的递归回溯，`n`项目，`m`优惠，每份需要≤10 |

 ## 算法演练

 1. 定义辅助函数`dfs(needs)`计算当前需求的最低成本。 该函数将被递归调用。 
2. 基本情况：如果所有需求为零，则成本为零。 
3. 初始化`min_cost`作为以单独价格购买所有剩余物品的成本。 
4. 迭代每项特别优惠。 检查是否可以在不超出当前需求的情况下应用。 如果是，则计算一个新的`needs`数组减去报价中的数量。 
5. 递归调用`dfs`关于更新的`needs`数组并添加当前报价的价格。 
6. 更新`min_cost`如果使用此优惠可以降低总成本。 
7. 存储计算结果`min_cost`对于当前的`needs`存储在记忆字典中以避免重复计算。 
8. 返回`min_cost`。 

为什么有效：在每个州，我们都会探索优惠和个人购买的每一种有效组合。 记忆化保证每个唯一状态仅计算一次，从而确保效率。 因为我们考虑了所有有效选项并选择最小值，所以保证解决方案是正确的。 

## Python 解决方案```python
from typing import List, Tuple

class Solution:
    def shoppingOffers(self, price: List[int], special: List[List[int]], needs: List[int]) -> int:
        memo = {}
        
        def dfs(current_needs: Tuple[int, ...]) -> int:
            if current_needs in memo:
                return memo[current_needs]
            
            # Cost without any special offer
            min_cost = sum(current_needs[i] * price[i] for i in range(len(price)))
            
            # Try each special offer
            for offer in special:
                new_needs = []
                for i in range(len(price)):
                    if offer[i] > current_needs[i]:
                        break
                    new_needs.append(current_needs[i] - offer[i])
                else:
                    # Offer is valid, recurse
                    min_cost = min(min_cost, dfs(tuple(new_needs)) + offer[-1])
            
            memo[current_needs] = min_cost
            return min_cost
        
        return dfs(tuple(needs))
```Python 实现定义了一个记忆递归函数`dfs`探索所有有效的特别优惠组合。 对于每个递归调用，它首先计算单独购买剩余商品的成本，然后尝试不超出当前需求的每个特价商品。 有效的报价更新需求，并且递归继续。 备忘录字典存储每个的结果`needs`元组，避免冗余计算。 

## 解决方案```go
func shoppingOffers(price []int, special [][]int, needs []int) int {
    memo := make(map[string]int)
    
    var dfs func([]int) int
    dfs = func(currentNeeds []int) int {
        key := fmt.Sprint(currentNeeds)
        if val, ok := memo[key]; ok {
            return val
        }
        
        minCost := 0
        for i, n := range currentNeeds {
            minCost += n * price[i]
        }
        
        for _, offer := range special {
            newNeeds := make([]int, len(currentNeeds))
            valid := true
            for i := range price {
                if offer[i] > currentNeeds[i] {
                    valid = false
                    break
                }
                newNeeds[i] = currentNeeds[i] - offer[i]
            }
            if valid {
                cost := dfs(newNeeds) + offer[len(offer)-1]
                if cost < minCost {
                    minCost = cost
                }
            }
        }
        
        memo[key] = minCost
        return minCost
    }
    
    return dfs(needs)
}
```在 Go 中，我们使用带有字符串键的映射来记忆状态，因为切片不能直接用作映射键。 每个状态都会转换为字符串表示形式。 该逻辑反映了 Python 解决方案：计算基本成本、迭代有效报价、递归更新的需求以及记住最低成本。 

## 工作示例

 **示例1：**`price = [2,5]`,`special = [[3,0,5],[1,2,10]]`,`needs = [3,2]`| 步骤| 当前需求| 基本成本| 已申请优惠 | 新需求 | 总成本|
 | --- | --- | --- | --- | --- | --- |
 | 1 | [3,2]| 3_2 + 2_5 = 16 | 3_2 + 2_5 = 16 | 报价 1 (3,0,5) | [0,2]| 5 + dfs([0,2]) = 5 + 10 = 15 |
 | 2 | [3,2]| 16 | 16 报价2 (1,2,10) | [2,0]| 10 + dfs([2,0]) = 10 + 4 = 14 |
 | 3 | [3,2]| 分钟(16, 15, 14) | - | - | 14 | 14

 最终答案：14

 **示例2：**`price = [2,3,4]`,`special = [[1,1,0,4],[2,2,1,9]]`,`needs = [1,2,1]`| 步骤| 当前需求| 基本成本| 已申请优惠 | 新需求 | 总成本|
 | --- | --- | --- | --- | --- | --- |
 | 1 | [1,2,1]| 2+6+4=12 | 报价1 | [0,1,1]| 4 + dfs([0,1,1]) = 4 + 7 = 11 |
 | 2 | [1,2,1]| 12 | 12 报价2 | 无效（需求 < 报价）| - |

 最终答案：11
