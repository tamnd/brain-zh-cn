 **难度：** 🟢简单
 **主题：** 数组、矩阵

 ## 解决方案

 ## 问题理解

 问题是要求我们实现一个**图像平滑器**，一个过滤器，它根据自身及其周围细胞的平均值来修改 2D 灰度图像中的每个细胞。`3 x 3`窗户。 关键要求是我们只考虑存在的相邻小区； 对于边缘或角单元，邻居的数量将少于八个。 输出是一个与输入大小相同的矩阵，其中每个单元都被其邻居和自身的平均值的下限替换。 

输入，`img`, 是一个`m x n`矩阵，其中每个元素都是 0 到 255 之间的整数，表示灰度强度。 输出也必须是`m x n`整数矩阵。 约束表明矩阵可以相对较小（`1 <= m, n <= 200`），因此我们可以提供一种算法来迭代每个单元及其邻居，而不会遇到性能问题。 重要的边缘情况包括最小的图像（`1x1`,`1xN`,`Mx1`）以及矩阵边缘或角落上的单元，其中存在较少的邻居。 

## 方法

 **暴力方法**很简单：对于每个单元格，手动迭代以该单元格为中心的 3x3 窗口，对所有有效邻居值求和，计算有多少个有效邻居，并计算总和除以计数的整数除法（下限）。 这种方法可以正常工作，因为它直接遵循问题陈述，但它需要在矩阵和 3x3 窗口上进行嵌套循环，从而导致潜在的冗余计算。 

**最佳方法**对此进行了改进，它认识到尽管我们仍然需要访问每个单元格的邻居，但考虑到问题约束，计算复杂度已经可以接受（`O(m * n)`）和问题大小（`200x200`）很小。 因此，通过仔细的边界检查进行简单的暴力迭代对于解决此问题已经足够有效。 对于这种规模，不需要额外的优化，例如预先计算前缀和。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(m * n) | O(m * n) | 迭代每个单元格及其邻居，计算平均值 |
 | 最佳| O(m * n) | O(m * n) | 与暴力破解一样，边界检查确保正确性 |

 ## 算法演练

 1. 初始化结果矩阵`res`与输入矩阵具有相同的维度`img`。 
2. 迭代每一行`i`和列`j`的`img`。 
3. 对于每个单元格`(i, j)`, 初始化`total_sum`到 0 和`count`为 0。这些将跟踪有效邻居值及其计数的总和。 
4. 迭代相对邻居位置`dx`和`dy`在`[-1, 0, 1]`。 
5. 对于每个邻居，计算`ni = i + dx`和`nj = j + dy`。 检查是否`(ni, nj)`位于矩阵边界内。 如果有效，请添加`img[ni][nj]`到`total_sum`并增加`count`。 
6. 处理完所有邻居后，计算下限平均值：`floor(total_sum / count)`并将其分配给`res[i][j]`。 
7. 继续，直到所有单元格均已处理完毕。 
8. 返回`res`。 

**为什么有效：** 每个单元格都会准确考虑存在的邻居，通过对这些邻居进行求和和计数，我们可以正确计算下限平均值。 该方法保证了正确性，因为它直接遵循问题规范，包括边缘和拐角的边界处理。 

## Python 解决方案```python
from typing import List

class Solution:
    def imageSmoother(self, img: List[List[int]]) -> List[List[int]]:
        m, n = len(img), len(img[0])
        res = [[0] * n for _ in range(m)]
        
        for i in range(m):
            for j in range(n):
                total_sum = 0
                count = 0
                for dx in [-1, 0, 1]:
                    for dy in [-1, 0, 1]:
                        ni, nj = i + dx, j + dy
                        if 0 <= ni < m and 0 <= nj < n:
                            total_sum += img[ni][nj]
                            count += 1
                res[i][j] = total_sum // count
        
        return res
```Python 实现首先用零初始化结果矩阵。 然后，它循环遍历每个单元格，对有效邻居求和，对它们进行计数，并将整数除法存储到结果矩阵中。 边界检查确保边缘和角单元正确平均，没有索引错误。 

## 解决方案```go
func imageSmoother(img [][]int) [][]int {
    m, n := len(img), len(img[0])
    res := make([][]int, m)
    for i := 0; i < m; i++ {
        res[i] = make([]int, n)
    }

    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            totalSum := 0
            count := 0
            for dx := -1; dx <= 1; dx++ {
                for dy := -1; dy <= 1; dy++ {
                    ni, nj := i + dx, j + dy
                    if ni >= 0 && ni < m && nj >= 0 && nj < n {
                        totalSum += img[ni][nj]
                        count++
                    }
                }
            }
            res[i][j] = totalSum / count
        }
    }

    return res
}
```在 Go 中，切片使用以下方式初始化`make`，并应用相同的嵌套循环逻辑。 整数除法会自动将结果取整。 边界检查确保不会发生超出范围的访问。
