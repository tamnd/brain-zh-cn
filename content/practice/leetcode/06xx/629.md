 **难度：** 🔴难
 **主题：** 动态规划

 ## 解决方案

 以下是遵循 LeetCode 629 格式规则的完整技术解决方案指南：

 ## 问题理解

 该问题要求我们确定长度的数组的数量`n`包含来自的数字`1`到`n`使得恰好有`k`逆对。 **逆对**`[i, j]`发生在`i < j`和`nums[i] > nums[j]`。 换句话说，它计算相对于排序数组而言无序的元素数量。 

输入由两个整数组成，`n`和`k`。`n`定义排列的大小和数组中可以出现的最大数量，而`k`指定我们要计算的逆对的确切数量。 输出是一个整数，表示有效数组的模数`10^9 + 7`。 

约束告诉我们`n`和`k`可以达到 1000。这意味着朴素的暴力解决方案，例如生成所有`n!`由于阶乘增长，排列和计算它们的逆对是完全不可行的。 

重要的边缘情况包括`k = 0`（只有排序后的数组才有效），`k`等于最大逆对数`n`（完全反转的数组），以及情况`k`大于最大可能的逆对（`n*(n-1)/2`），应该返回`0`。 

## 方法

 蛮力方法将生成来自的所有数字排列`1`到`n`并计算每个排列的逆对的数量。 虽然正确，但速度非常慢，因为排列的数量是`n!`，它呈阶乘增长并且在计算上变得不可行`n > 10`。 

最佳解决方案的关键洞察是**动态规划**。 让`dp[i][j]`是长度数组的数量`i`恰好与`j`逆对。 当我们添加下一个数字时`i`到长度数组`i-1`，将其放置在不同位置会生成不同数量的新逆对。 通过认识到放置`i`在索引处`p`从最后添加`p`新的逆对，我们可以导出一个递归关系，从而可以有效地填充 DP 表。 此外，使用前缀和或累积和可以减少重复计算，以实现 O(n*k) 的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 笔记|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 生成所有排列并计算逆对。 对于 n > 10 不可行。 
| 最佳| O(n*k) | O(k) | 使用前缀和进行动态规划以提高效率。 处理大的 n 和 k。 |

 ## 算法演练

 1.初始化一个大小为1D的DP数组`k+1`代表`dp[j]`对于数组的数量`j`逆对。 
2. 设置`dp[0] = 1`，因为正好有一个长度为 1 且有 0 个逆对的数组。 
3. 迭代`i`从 2 到`n`。 对于每个`i`，计算一个新的DP数组`new_dp`:

 a. 使用累积和数组有效地计算可以贡献的有效先前状态的总和`j`逆对。 

b. 为了`j`从 0 到`k`，通过相加计算数组的数量`i`相对于长度数组的不同位置`i-1`。 
4. 使用模数`10^9 + 7`每次添加时防止溢出。 
5. 处理完所有数字后`n`,`dp[k]`包含所需的数组数量。 

**为什么有效**：每个 DP 条目`dp[i][j]`正确计算长度数组的数量`i`和`j`逆对，因为该算法考虑了插入新数字的所有方式`i`并累积更新计数，保持所有计数数组都是具有确切数量的逆对的不同排列的不变性。 

## Python 解决方案```python
class Solution:
    def kInversePairs(self, n: int, k: int) -> int:
        MOD = 10**9 + 7
        dp = [0] * (k + 1)
        dp[0] = 1

        for i in range(1, n + 1):
            new_dp = [0] * (k + 1)
            cum_sum = 0
            for j in range(k + 1):
                cum_sum += dp[j]
                if j >= i:
                    cum_sum -= dp[j - i]
                new_dp[j] = cum_sum % MOD
            dp = new_dp
        
        return dp[k]
```在此 Python 实现中，`dp`跟踪每个可能的逆对计数的数组数量。 对于每个新号码`i`，使用累积和技术来有效计算所有可能的新逆对，无需嵌套循环，确保 O(n*k) 解决方案。 

## 解决方案```go
func kInversePairs(n int, k int) int {
    const MOD = 1e9 + 7
    dp := make([]int, k+1)
    dp[0] = 1

    for i := 1; i <= n; i++ {
        newDp := make([]int, k+1)
        cumSum := 0
        for j := 0; j <= k; j++ {
            cumSum += dp[j]
            if j >= i {
                cumSum -= dp[j-i]
            }
            newDp[j] = (cumSum % MOD + MOD) % MOD
        }
        dp = newDp
    }

    return dp[k]
}
```在Go中，使用切片而不是数组进行动态分配。 使用模运算显式处理整数溢出。 逻辑与 Python 类似，但要注意确保模结果非负，这在 Go 中很常见。

 ## 边缘情况

 **情况 1：零逆对**

 当`k = 0`，只有排序后的数组`[1,2,...,n]`是有效的。 该实现正确地处理了这个问题，因为`dp[0]`初始化为 1，累加和逻辑不会生成负对。 

**情况 2：最大逆对**

 对于`k = n*(n-1)/2`，只有完全反转的数组才有效。 累积和技术正确地对在最大逆位置插入数字的贡献求和，因此该算法精确地计算出一个数组。
