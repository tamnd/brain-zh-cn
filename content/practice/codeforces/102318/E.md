 ## 解决方案
 ## 问题理解

 我们有一个以原点为中心的飞镖靶。 该板径向分为`w`相同的楔子，并且具有三个同心得分区域。 最内圈的半径`b`是靶心，总是给出 50 分。 半径之间`b`和`d`是双精度区域，其中楔形值乘以 2。在半径之间`d`和`s`是使用楔形的普通值的单个区域。 半径外的省道`s`得分 0。 

紧邻 x 正轴逆时针方向的楔形值为 1。通过楔形逆时针移动会将值增加 1，因此紧邻 x 正轴顺时针方向的楔形值为 1`w`。 对于每个测试用例，我们都会得到棋盘尺寸以及所有飞镖的坐标，并且我们需要它们的分数之和。 最初的竞赛声明给出了`2 <= w <= 20`,`0 < b < d < s < 100`，每个测试用例最多 100 个飞镖。 飞镖坐标位于`-100`和`100`，且内无飞镖`10^-5`楔形边界或圆形边界。 

这些界限使问题比许多几何问题简单得多。 甚至一个`O(tw)`解决方案最多执行`100 * 20 = 2000`楔形检查在一个测试用例中，因此一种简单的解决方案已经足够快了。 尽管如此，我们仍然可以处理每个飞镖`O(1)`通过将其角度直接转换为楔数，给出`O(t)`时间。 

最相关的边缘情况是由几何形状而不是大输入尺寸引起的。 例如，在正中心的省道```
1
2 1 2 3
1
0.000 0.000
```得分为 50，而不是 0 或楔值。 首先计算角度并将中心视为普通楔子的解决方案仍然可以产生一个值，但该值没有意义，因为牛眼优先于角度得分。 

即使飞镖的角度指向高值楔形，飞镖在棋盘外的得分也必须为零。 例如，```
1
2 1 2 3
1
0.000 4.000
```得分为 0，因为它距原点的距离大于外半径。 

双环省道必须使用两倍的楔值。 和```
1
2 1 5 8
1
0.000 3.000
```飞镖位于双环内且位于上楔形处，其值为 1，因此正确的输出为`2`。 忘记乘数会产生`1`。 

负角的情况也很容易处理不当。 和```
1
4 1 5 8
1
1.000 -1.000
```角度是`-45`度。 这属于第四个楔形，而不是第一个楔形，因此省道获得第四个楔形的值。 如果粗心地简单地将负角度除以楔形宽度，则会得到负索引。 

2017 年存档的声明的第一个样本也存在历史不一致。 它给出了`4 7 13 10`，尽管有规定的关系`b < d < s`。 预期的答案对待`13`作为双区域的外边界，因此下面的实现完全遵循所写的变量并重现原始样本输出。 后面的样本和评分规则都与这个解释一致。 

## 方法

 最直接的做法就是对每个省份进行独立处理。 首先计算其距原点的平方距离。 如果该值小于`b²`，省份的值为 50。否则，确定哪个楔形包含省份，然后根据径向区域将该楔形的值乘以 2、1 或 0。 

对于暴力实现，一旦知道了飞镖的角度，我们就可以针对每个飞镖来测试该角度`w`楔形间隔，直到找到匹配的楔形。 这是正确的，因为楔子分割了整个圆。 由于最多有 20 个楔子和 100 个飞镖，因此最坏的情况是每个测试用例恰好有 2000 个楔子检查。 这还远远不足以威胁一秒的限制，因此这个版本已经被接受。 

更清晰的观察结果是楔子的大小相同。 我们根本不需要搜索它们。 一整周有角度`2π`，所以每个楔形占据一个角度`2π / w`。 

如果省道具有标准化角度`θ`在`[0, 2π)`，它的从零开始的楔形索引就是`floor(θ / (2π / w))`。 

加一会将该索引转换为飞镖靶的分数（从 1 到`w`。 这减少了角度功`O(w)`到`O(1)`。 

蛮力方法之所以有效，是因为每个飞镖都可以独立分类，但它会花费不必要的工作来寻找可以直接计算的楔子。 相等的角宽度正是使直接公式成为可能的原因。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(tw) | O(1) | O(1) | 已接受 |
 | 最佳| O(t) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 每个测试用例都描述一个独立的飞镖靶及其投掷，因此总得分可以在每个用例开始时重置为零。 
2. 阅读`w`,`b`,`d`， 和`s`，然后读取数字`t`的飞镖。 将半径平方存储为`b²`,`d²`， 和`s²`。 比较平方距离可以避免不必要的平方根并保留径向区域的准确顺序。 
3. 对于每一个飞镖`(x, y)`, 计算`r² = x² + y²`。 如果`r² < b²`，立即加50分。 靶心有固定的分数，所以它的角度并不重要。 
4. 如果飞镖不在靶心内，则用以下方法确定其角位置：`atan2(y, x)`。 该函数给出了所有四个象限的正确角度，与`atan(y / x)`，这会丢失象限信息。 
5. 如果角度为负，则加上`2π`所以它位于`[0, 2π)`。 这会将圆坐标转换为可分为相等楔形宽度的正常非负区间。 
6. 计算`wedge = int(angle / (2π / w)) + 1`。 除法确定省道角度之前出现多少个完整的楔形间隔，以及`+1`将从零开始的索引转换为棋盘的分数编号。 
7. 从径向位置确定乘数。 飞镖与`r² < d²`位于双倍区域并获得乘数 2。 飞镖`r² < s²`位于单一区域并获得乘数 1。超出范围的飞镖`s`得到乘数 0。 
8. 添加`wedge * multiplier`到测试用例的总数并在处理所有省份后打印总数。 

### 为什么它有效

 对于每个飞镖，平方距离唯一地确定哪个同心得分区域包含它，而`atan2`唯一决定了它的方向。 由于所有楔块都具有相同的角宽度，因此将归一化角度除以`2π/w`准确给出包含省道的楔形的索引. 然后，径向乘数对该区域应用评分规则。 唯一的特殊情况是牛眼，它首先被检查，因为它的固定分数覆盖了楔形分数。 由于该问题保证省份不会靠近边界，因此浮点舍入无法在相邻区域之间进行有效的省份切换。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    tc = int(input())
    out = []

    for _ in range(tc):
        w, b, d, s = map(int, input().split())
        t = int(input())

        b2 = b * b
        d2 = d * d
        s2 = s * s

        wedge_angle = 2.0 * math.pi / w
        total = 0

        for _ in range(t):
            x, y = map(float, input().split())
            r2 = x * x + y * y

            if r2 < b2:
                total += 50
                continue

            angle = math.atan2(y, x)
            if angle < 0:
                angle += 2.0 * math.pi

            wedge = int(angle / wedge_angle) + 1

            if r2 < d2:
                total += 2 * wedge
            elif r2 < s2:
                total += wedge

        out.append(str(total))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```前三个平方半径变量在每个测试用例中计算一次，因为飞镖之间的棋盘不会发生变化。 比较`r2`使用这些值可以避免`sqrt`，因此每个径向分类仅使用算术比较。 

靶心检查发生在角度计算之前。 除了稍微便宜一点之外，这还直接反映了评分等级：无论方向如何，飞镖射中靶心总是得分 50。`atan2(y, x)`被用来代替`atan(y / x)`因为`atan`无法区分，例如`(1, -1)`从`(-1, 1)`。`atan2`正确处理整个圆。 阴性结果偏移`2π`，产生范围内的角度`[0, 2π)`。 

表达式`int(angle / wedge_angle) + 1`是关键的几何计算。 由于保证省道不会靠近楔形边界，因此无需进行 epsilon 调整。 相同的边界保证让我们可以使用严格的`<`半径的比较。 

Python 整数具有任意精度，因此不存在整数溢出问题。 浮点值仅用于坐标和角度，而所有最终得分仍然是整数。

 ## 边缘情况

 在进行任何角度计算之前必须检查靶心。 为了```
1
2 1 2 3
1
0.000 0.000
```我们得到`r² = 0`，小于`b² = 1`。 该算法立即加 50 并跳过`atan2`，生产`50`。 这避免了将任意楔形分配给中心点。 

棋盘外的飞镖遵循与普通飞镖相同的角度计算，但其乘数保持为零。 为了```
1
2 1 2 3
1
0.000 4.000
```距离的平方为 16，大于`s² = 9`，因此不添加分数。 结果是`0`。 

双环先于单环处理，因为径向区域是嵌套的。 为了```
1
2 1 5 8
1
0.000 3.000
```距离的平方为 9，介于`1²`和`5²`。 该点位于楔形 1 中，因此其基值为 1，双倍乘数给出`2`。 

单环的工作原理类似。 为了```
1
2 1 5 8
1
0.000 6.000
```距离的平方为 36，介于`5²`和`8²`。 该点仍在楔形 1 中，但乘数现在为 1，给出`1`。 

在找到楔子之前必须对负角进行归一化。 为了```
1
4 1 5 8
1
1.000 -1.000
```

`atan2(-1, 1)`回报`-π/4`。 添加`2π`产生`7π/4`，属于四个 90 度楔形中的第四个。 基础分数为 4，且该点位于双环内，因此结果为`8`。 

最后，竞赛样本包含`4 7 13 10`值得特别照顾。 书面限制说`b < d < s`，但该特定历史样本反转了最后两个半径。 通过将飞镖处理为`(6,-4)`位于双区域内，因为其距离约为 7.21，如下`d = 13`。 该代码故意不对这三个半径进行排序或重新解释。 它按照输入顺序进行评分比较，再现官方样本，同时在满足条件的有效案例上也表现正常`b < d < s`。
