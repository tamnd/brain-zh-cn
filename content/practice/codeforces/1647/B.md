 ## 解决方案
 ## 问题理解

 我们得到了一个二进制网格。 黑色子矩形是任何轴对齐的矩形，完全由`1`s。 

在所有黑色矩形中，如果一个矩形不能扩展到包含它的更大的黑色矩形，则该矩形被称为好矩形。 换句话说，它的包容性是最大的。 

当没有两个漂亮的矩形共享任何单元格时，网格被称为优雅的。 

乍一看，这个定义听起来很复杂，因为它讨论了所有可能的情况——`1`矩形及其包含关系。 挑战在于确定这种重叠的最大矩形是否存在。 

网格尺寸最多为`100 × 100`，并且测试用例中所有行计数和列计数的总和受下式限制`777`。 这是一个非常小的输入大小。 甚至一个`O(nm(n+m))`解决方案很容易被接受。 不可接受的是枚举所有可能的矩形，因为`100 × 100`网格大致包含`25 million`矩形，检查每个矩形的成本太高了。 

主要的困难是认识到优雅的定义在其形成的形状方面的真正含义。`1`s。 

一些边缘情况很容易被误解。 

考虑```
11
11
```正确答案是`YES`。 

所有四个单元格形成一个最大的黑色矩形。 一种简单的方法，仅检查是否相邻`1`s 存在会错误地拒绝它。 

考虑```
10
01
```正确答案是`YES`。 

两人`1`仅对角接触。 它们属于单独的最大矩形并且不相交。 

考虑```
11
10
```正确答案是`NO`。 

三个`1`s 形成L 形。 一个最大矩形是顶行，另一个最大矩形是左列。 它们在左上角的单元格处重叠，因此网格并不优雅。 

仅计算连接组件的粗心实现将错误地接受这种情况，因为所有`1`s 属于单个组件。 

另一个重要的例子是```
111
101
111
```正确答案是`NO`。 

中心的孔阻止整个形状成为矩形。 多个最大的黑色矩形在拐角处重叠，形成相交的漂亮矩形。 

解决方案来自于准确理解哪些形状`1`是允许的。 

## 方法

 暴力解释直接遵循定义。 

我们可以枚举每个轴对齐的矩形，检查它是否完全由`1`s，确定是否最大，收集所有好的矩形，然后测试每对矩形的交集。 

尺寸网格`100 × 100`大约包含$$\frac{100\cdot101}{2}\cdot\frac{100\cdot101}{2} \approx 25\,000\,000$$矩形。 

即使在检查其内容之前，这也已经远远超出了期限内可以处理的范围。 

关键的观察是实际的定义分解为一个非常简单的几何属性。 

取任意连接的组件`1`使用四方向邻接。 

如果该组件本身形成一个填充矩形，则其内部恰好有一个最大的黑色矩形，即整个组件。 不存在重叠问题。 

如果组件未形成填充矩形，则其边界框内必须至少缺少一个单元格。 这种形状必然包含一个 L 形转弯，即水平运行的拐角`1`s 和垂直运行`1`见面了。 这两次运行生成共享角单元的不同最大黑色矩形。 因此两个漂亮的矩形相交。 

这意味着：

 网格是优雅的当且仅当每个连接的组件`1`s 构成一个完整的矩形。 

一旦我们发现了这个性质，问题就变得很小了。 对于每个连接的组件，计算其边界框。 如果组件恰好包含该边界框的每个单元格，则该组件是矩形的。 否则立即得到答案`NO`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 非常大的、大约 O(n²m²) 的矩形加上验证 | 大| 太慢了 |
 | 最佳| O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 迭代网格的所有单元格。 
2. 每当一个未访问的单元格包含`1`找到后，启动 BFS 或 DFS 来发现其整个连接组件。 
3. 遍历组件时，记录：

 - 最小行索引。 
- 最大行索引。 
- 最小列索引。 
- 最大列索引。 
- 组件中的单元格数量。 
4. 遍历完成后，计算组件外接矩形的面积。```
area = (max_row - min_row + 1) × (max_col - min_col + 1)
```5. 将元件尺寸与边界矩形区域进行比较。 

如果它们不同，则边界矩形内的某些单元格丢失。 该组件不是一个填充的矩形，因此网格无法优雅。 输出`NO`。 
6. 继续处理所有组件。 
7. 如果每个组件都通过检查，则输出`YES`。 

为什么比较面积就足够了？ 因为组件的每个单元格都位于边界框内。 如果组件单元格的数量等于盒子面积，则盒子内的每个位置都必须属于该组件。 该组件实际上是一个矩形。 

### 为什么它有效

 关键的属性是`1`当 s 是填充矩形时，它是安全的。 

如果一个组件是一个填充矩形，那么整个组件就是一个最大的黑色矩形。 任何较小的黑色矩形都包含在其中，这并不好。 没有一对漂亮的矩形可以相交。 

如果组件不是填充矩形，则其边界框至少包含一个缺失的单元格。 这样的形状不能用单个最大矩形来表示。 至少需要两个最大的黑色矩形，并且它们在组件内部的某处重叠。 那些重叠的最大矩形是漂亮的矩形，违反了优雅。 

因此，每个连接的组件都必须是矩形的，检查该条件既是必要的也是充分的。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    vis = [[False] * m for _ in range(n)]
    ok = True

    for r in range(n):
        for c in range(m):
            if g[r][c] != '1' or vis[r][c]:
                continue

            q = deque([(r, c)])
            vis[r][c] = True

            min_r = max_r = r
            min_c = max_c = c
            cnt = 0

            while q:
                x, y = q.popleft()
                cnt += 1

                min_r = min(min_r, x)
                max_r = max(max_r, x)
                min_c = min(min_c, y)
                max_c = max(max_c, y)

                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx = x + dx
                    ny = y + dy

                    if (
                        0 <= nx < n
                        and 0 <= ny < m
                        and not vis[nx][ny]
                        and g[nx][ny] == '1'
                    ):
                        vis[nx][ny] = True
                        q.append((nx, ny))

            area = (max_r - min_r + 1) * (max_c - min_c + 1)

            if area != cnt:
                ok = False
                break

        if not ok:
            break

    print("YES" if ok else "NO")
```外层循环搜索未访问过的`1`细胞。 每个这样的单元都会启动一个新的连接组件。 

BFS 同时服务于两个目的。 它标记属于该组件的所有单元格，并计算组件的边界框。 跟踪最小和最大行索引和列索引可以避免任何额外的网格遍历。 

变量`cnt`存储组件中的单元格数量。 BFS结束后，由边界框确定的矩形就已知了。 如果组件是完美的矩形，则其大小必须等于矩形的面积。 任何孔、凹痕或 L 形都会减小元件尺寸，同时使边界框保持不变，从而导致比较失败。 

该实现使用四向邻接，因为这是网格组件连接的自然概念。 对角邻居被故意忽略。 

对于单个单元格、单个行或单个列不需要特殊处理。 在所有这些情况下，面积公式都可以正确工作。

 考虑 L 形：```

11
10
```BFS 发现一个组件包含三个单元。 它的边界框跨越两行和两列，给出面积`4`。 自从`3 != 4`，该组件不是矩形，算法输出`NO`。
