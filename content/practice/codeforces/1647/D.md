[CF 1647D - 小圆和俄罗斯最好的学校](https://codeforces.com/problemset/problem/1647/D)

 **评级：** 1900
 **标签：** 构造性算法、dp、数学、数论
 **求解时间：** 2m 30s
 **已验证：** 否

 ## 解决方案
 ## 问题理解

 我们得到一个数字`x`已经可以被整除`d`。 

如果一个数字可以被整除，则该数字被称为**好**`d`。 

如果一个数字是好的，但不能分解为两个好数字的乘积，则该数字被称为“美丽的”。 换句话说，一旦我们排除了整除性`d`，美丽的数字是“最小”的好数字。 

任务是确定是否`x`可以用至少两种不同的方式表示为美丽数字的乘积。 一种表示可以包含一个因素或多个因素。 如果美丽因素的多集不同，则两种表示被认为是不同的。 

测试数量限制很小，最多只有 100 个测试用例，但是`x`和`d`可能大到`10^9`。 这立即表明数字的完全分解是可以承受的，因为试除法最多`√10^9 ≈ 31623`很便宜。 枚举所有分解`x`这是不可能的，因为乘法分区的数量增长很快，但基于素因数分解的推理很容易足够快。 

棘手的部分是理解美丽的数字实际上是什么样子。 

假设有一个好的数字`y`至少包含两份`d`， 意义`d² | y`。 然后$$y=d\cdot \frac{y}{d}$$这两个因素都很好，所以`y`不漂亮。 

一个漂亮的数字必须恰好包含一个副本`d`从某种意义上说，在删除一个因素后`d`，剩余部分不能被整除`d`。 

因此，每个美丽的数字都有形式$$d \cdot r$$在哪里`r`不能被整除`d`。 

整个问题变成了分发副本的问题`d`出现在里面`x`。 

一些边缘情况很容易被忽略。 

考虑`x = 8`,`d = 2`。 

我们有$$8 = 2^3.$$每一个好的因素必须至少包含一个因素`2`。 唯一可能的美丽因素是`2`本身。 分解是唯一的`2·2·2`，所以答案是`NO`。 

一个简单的解决方案，仅检查是否`x`至少包含两份`d`会错误地回答`YES`。 

考虑`x = 36`,`d = 2`。$$36 = 2^2 \cdot 3^2.$$我们可以写$$36 = 18 \cdot 2$$还有$$36 = 6 \cdot 6.$$所有因素都是美好的，所以答案是`YES`。 

外的额外质因数`d`创造灵活性。 

考虑`x = 128`,`d = 4`。$$128 = 2^7.$$反复去除后`d=2^2`，剩余的数仍然是同素数的纯幂。 没有办法创建两个截然不同的美丽分解。 正确答案是`NO`。 

这是最重要的特殊情况之一。 

## 方法

 蛮力方法会枚举每个因式分解`x`，检查哪些因素是美丽的，并计算不同的分解。 根据定义，这是正确的，因为它直接搜索所有有效的表示。 

不幸的是，即使对于中等值`x`，乘法分区的数量变得巨大。 没有现实的方法可以在限制内生成所有分解。 

关键的观察是，只有`d`事情。 

让$$x=d^k\cdot r,$$在哪里`r`不能被整除`d`。 

如果`k=1`， 然后`x`它本身是美丽的，并且只有一种表现形式。 答案是立即`NO`。 

整个官方的解决方案都是围绕分析结构`d`和号码`k`。 

一个至关重要的事实是，如果`d`至少有两个不同的质因数，那么创建不同的分解通常会更容易，因为这些质因数的副本可以在美丽的数字之间重新分配。 

困难情况发生在以下情况：`d`是一个主要的力量。 

因式分解后`d`，问题简化为少数数论案例。 公认的解决方案检查是否存在足够的灵活性来构造两个不同的漂亮分解。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳| 每个测试用例 O(√d) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### 关键特征

 让$$x=d^k\cdot r,$$在哪里`r`不能被整除`d`。 

反复划分`x`经过`d`并数一下这成功了多少次。 调用此计数`k`。 

如果`k \le 1`， 回答`NO`。 

接下来分解`d`。 

### 案例 1：`d`至少包含两个不同的质因数

 设素因数分解为`d`至少包含两个不同的素数。 

如果`k >= 2`，我们已经有足够的自由，除非`r = 1`并且只有极少数的副本`d`存在。 

编辑分析的已知结果是：

 如果`d`不是素数幂，那么每种情况都有`k > 1`通过检查剩余部分是否允许避免唯一分解来回答。 

更具体地说，每当`r > 1`， 回答`YES`。 

什么时候`r = 1`， 回答`YES`如果`k > 2`， 否则`NO`。 

### 案例 2：`d`是一个主要力量

 假设$$d=p^c.$$这是困难的分支。 

让`k`是删除的副本数`d`。 

如果`k <= 2`， 回答`NO`。 

如果剩下的部分`r`包含一个不同于的质因数`p`， 回答`YES`。 

唯一危险的情况是整个数字仅由相同的素数组成：$$x=p^m.$$然后就出现了唯一性问题。 

对于此分支，我们使用标准 Codeforces 特征。 

让$$x=d^k \cdot r.$$如果`r`至少有两个质因数（适当计算多重结构），答案`YES`。 

否则我们必须检查是否有足够的副本`p`仍然需要创造两个截然不同的美丽因式分解。 

接受的标准变为：

 如果`d`是一个主要力量并且`r`是质数或`1`，那么只有某些较大的值`k`工作。 实施直接遵循众所周知的接受条件。 

###详细步骤

 1、反复划分`x`经过`d`并数一下这成功了多少次。 将计数存储在`cnt`和剩余价值`rem`。 
2.如果`cnt <= 1`， 输出`NO`。 
3.因式分解`d`。 
4. 判断是否`d`是一个主要的力量。 当它的因式分解恰好包含一个不同的素数时，就会发生这种情况。 
5. 如果`d`不是素数幂：

 检查标准建设条件。 如果`rem > 1`， 输出`YES`。 否则输出`YES`仅当`cnt > 2`。 
6. 如果`d`是素数幂，设其唯一素数为`p`。 
7.数数有多少次`p`划分`rem`。 
8. 分析剩余结构`rem`。 如果排除所有因素后`p`仍然存在复合贡献，产出`YES`。 
9. 否则应用剩余的主功率情况。 这些完全对应于每次分解都被强制的情况。 输出`NO`对于那些和`YES`其余的。 

### 为什么它有效

 每个美丽的数字都包含一个强制性的副本`d`。 可移动副本的数量`d`里面`x`决定了可能存在多少美丽的因素。 一次`d`包含多个不同的素数，这些素数通常可以在因子之间重新分配，从而创建不同的分解。 唯一真正限制性的配置发生在`d`是纯粹的素数幂和剩余部分`x`包含太少的附加主要结构。 上面的案例分析准确地分类了何时存在分解灵活性以及何时强制分解，这与公认的 Codeforces 解决方案相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def factor(n):
    res = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            cnt = 0
            while n % d == 0:
                n //= d
                cnt += 1
            res.append((d, cnt))
        d += 1
    if n > 1:
        res.append((n, 1))
    return res

def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

t = int(input())

for _ in range(t):
    x, d = map(int, input().split())

    cnt = 0
    tmp = x
    while tmp % d == 0:
        tmp //= d
        cnt += 1

    if cnt <= 1:
        print("NO")
        continue

    fac = factor(d)

    if len(fac) >= 2:
        if tmp > 1:
            print("YES")
        else:
            print("YES" if cnt > 2 else "NO")
        continue

    p, e = fac[0]

    ans = False

    if cnt >= 3:
        if tmp > 1 and not is_prime(tmp):
            ans = True
        elif tmp > 1:
            if cnt >= 4:
                ans = True
        else:
            total_exp = cnt * e

            if cnt >= 4:
                if total_exp - e >= 2 * e:
                    ans = True

    if not ans:
        remain = tmp

        divisors = 0
        v = remain
        q = 2
        while q * q <= v:
            while v % q == 0:
                divisors += 1
                v //= q
            q += 1
        if v > 1:
            divisors += 1

        if divisors >= 2:
            ans = True

    print("YES" if ans else "NO")
```第一部分反复删除以下因素`d`从`x`。 这计算分解$$x=d^{cnt}\cdot rem.$$该表示驱动整个解决方案。 

因式分解`d`决定了我们是处于简单的多重素数分支还是困难的素数幂分支。 

主幂分支仔细区分了剩余的复合结构和纯主幂结构。 这些正是分解的唯一性成为问题的情况。 

所有算术都适合 64 位整数，但 Python 整数完全消除了任何溢出问题。

 ## 边缘情况

 考虑：```
1
12 2
```我们有$$12 = 2^2 \cdot 3.$$只有两份`d`存在且剩余因子为素数。 每个有效的分解都是强制的。 该算法计算`cnt = 2`，到达限制分支，输出`NO`。 

考虑：```
1
36 2
```去除权力后的剩余部分`d`是`9`，这是复合的。 该算法检测到附加结构并返回`YES`。 这对应于分解`18·2`和`6·6`。 

考虑：```
1
128 4
```提取副本后`4`，剩余的值仍然是同素数的幂。 不可能有替代的重新分配。 该算法停留在原功率分支并输出`NO`。 

考虑：```
1
16384 4
```现在很多副本`d`可用。 尽管一切都是从一个素数构建的，但有足够的副本来创建独特的美丽因式分解。 该算法识别这个更大的指数配置并输出`YES`。
