 ## 解决方案
 ## 问题理解

 唐纳德以以下格式将时间输入微波炉`MM:SS`，期望它表示分钟和秒。 不幸的是，微波炉解释的数字与`HH:MM`，表示小时和分钟。 

例如，如果唐纳德输入`02:15`，他预计微波炉将运行 2 分 15 秒。 相反，微波炉运行 2 小时 15 分钟。 

我们必须计算一下由于这种误解而导致的额外烹饪时间。 答案必须打印为`HH:MM:SS`。 

输入由单个字符串组成`MM:SS`。 两个部分都在 0 到 59 之间，并且至少其中之一不为零。 输出是以下之间的差异：

 1. 实际输入的时间，解释为小时和分钟。 
2. 唐纳德想要的时间，解释为分钟和秒。 

由于输入仅包含一个时间戳且范围很小，因此效率在这里无关紧要。 任何恒定时间算术解决方案都很容易足够快。 真正的挑战是在不同时间单位之间正确转换并格式化结果。 

一个常见的错误是单独减去字段。 考虑：```
00:10
```唐纳德预计需要 10 秒。 

微波炉将其解释为 10 分钟。 

区别在于：```
600 - 10 = 590 seconds
```等于：```
00:09:50
```如果我们分别减去分钟和秒而不首先将所有内容都转换为秒，我们很容易错误地处理所需的借用。 

当秒非零时，会出现另一个容易出现的陷阱。 

输入：```
05:00
```预计时间：```
5 minutes = 300 seconds
```实际时间：```
5 hours = 18000 seconds
```不同之处：```
17700 seconds = 04:55:00
```仅比较显示数字的解决方案可能会忽略小时和分钟对应于完全不同的单位刻度。 

## 方法

 最直接的方法是将两种解释都转换为秒。 

假设输入是`MM:SS`。 

唐纳德的预期持续时间是：```
MM minutes + SS seconds
```等于：```
MM * 60 + SS
```秒。 

微波的实际持续时间为：```
MM hours + SS minutes
```等于：```
MM * 3600 + SS * 60
```秒。 

所需的答案只是这两个值之间的差异。 

更麻烦的方法是使用借用的小时、分钟和秒来手动执行时间减法。 这是可行的，但它引入了不必要的复杂性，并在借用操作期间产生了相差一错误的机会。 

关键的观察是，一旦一切都以单个单元表示，时间算术就变得微不足道。 计算出以秒为单位的差异后，我们使用除法和模运算将其转换回小时、分钟和秒。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 借用手动时间减法 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 转换为秒并减去 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取输入字符串并在冒号处将其拆分。 
2. 将两个值解析为整数`m`和`s`。 
3. 计算 Donald 预期的持续时间：```
intended = m * 60 + s
```4. 计算微波炉实际使用的持续时间：```
actual = m * 3600 + s * 60
```5. 计算额外时间：```
diff = actual - intended
```6. 转换`diff`回到小时、分钟和秒。```
hours = diff // 3600
diff %= 3600

minutes = diff // 60
seconds = diff % 60
```7. 每个字段使用两位数字打印结果。 

### 为什么它有效

 两种解释都描述同一对数字，但为它们分配不同的单位。 

预期的持续时间以分钟和秒为单位进行测量，而微波炉将其视为小时和分钟。 将两个持续时间转换为总秒数可以消除所有歧义并允许直接减法。 

由于每个持续时间都以秒为单位精确表示，因此计算出的差异在数学上与额外的烹饪时间相同。 将该差异转换回小时、分钟和秒只是将总秒数分解为标准时间单位。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

m, s = map(int, input().strip().split(':'))

intended = m * 60 + s
actual = m * 3600 + s * 60

diff = actual - intended

hours = diff // 3600
diff %= 3600

minutes = diff // 60
seconds = diff % 60

print(f"{hours:02d}:{minutes:02d}:{seconds:02d}")
```第一步解析输入的两个组成部分。 

然后，该解决方案计算两个独立的持续时间。 一对应于唐纳德想要的，以分钟和秒来衡量。 另一个对应于微波炉如何解释相同的数字，以小时和分钟为单位。 

减去持续时间后，剩余值为秒数。 转换回`HH:MM:SS`遵循标准流程：首先提取小时，然后从剩余时间中提取分钟，然后从之后剩余的时间中提取秒。 

格式化字符串`:02d`很重要，因为该问题需要每个字段恰好有两位数字。 没有它，诸如此类的值`4:5:0`将被打印而不是`04:05:00`。

# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    m, s = map(int, input().strip().split(':'))

    intended = m * 60 + s
    actual = m * 3600 + s * 60

    diff = actual - intended

    h = diff // 3600
    diff %= 3600

    ss = diff % 60

    return f"{h:02d}:{mm:02d}:{ss:02d}"
