 ## 解决方案
 ## 问题理解

 给定一个由小写英文字母组成的字符串，并询问是否可以将其拆分为正好 k 个连续的非空片段，使得每个片段包含相同数量的辅音字母。 这里的辅音是指除a、e、i、o、u、y之外的任何字母。 

关键的限制是分割必须通过将字符串切割成连续的段来实现，因此我们不会重新排列字符。 我们只选择 k 个剪切位置，并且得到的 k 个子串必须具有相等的辅音数量。 

输入大小可能高达 200,000 个字符，因此任何尝试所有可能的分区或检查所有剪切组合的解决方案都是立即不可行的。 对分割位置或段选择的二次或指数方法将大大超出时间限制，因此解必须在 n 中是线性或接近线性的。 

当 k 大于 n 时，会出现第一个微妙的边缘情况。 即使字符串包含许多元音，每个段也必须非空，因此段数不能多于字符数。 例如，无论字符串如何，n = 3, k = 4 总是失败。 

另一个重要的边缘情况是辅音总数不能被 k 整除。 由于每个片段必须具有相同数量的辅音，如果辅音总数为 C，则每个部分必须恰好具有 C / k 辅音。 如果 C 不能被 k 整除，则任何划分都不起作用。 例如，如果字符串有 5 个辅音且 k = 2，则我们无法将 5 均分为两个整数部分。 

最后，即使可分性成立，我们也必须确保分割可以连续的方式进行。 这要求当我们从左到右扫描并累积辅音时，我们可以精确地将剪切位置设置为目标每段辅音计数的倍数。 

## 方法

 暴力策略会尝试在 n-1 个可能的位置中进行 k-1 次切割，并验证每个分区。 对于每个候选分区，我们将重新计算每个片段中的辅音计数。 即使使用前缀和，剪切组合的数量也是从n中选择k个位置的顺序，当n为200,000且k达到200,000时，组合变得很大。 这种做法是完全不可行的。 

关键的观察是，只有辅音才重要，而不是精确的字母组成。 一旦我们知道辅音 C 的总数，每个有效分区必须将 C 分成 k 个相等的整数部分，每个部分等于 C / k。 这将问题转化为单个线性扫描：我们计算辅音，然后贪婪地将它们按顺序分配给片段。 每当我们精确地积累 C / k 辅音时，我们就结束一个片段并开始下一个片段。 

贪婪的性质之所以有效，是因为字符串顺序是固定的。 一旦达到片段所需的配额，延迟剪切或提前移动它没有任何好处，因为辅音计数只会随着我们向右移动而增加。

 ## 算法演练

1. 通过扫描每个字符一次来统计字符串中辅音的总数。 如果计数为零，我们将其视为特殊情况，因为所有片段仍必须具有相等的计数，这迫使每个片段具有零个辅音。 
2. 如果 k 大于 n，则立即返回“No”，因为我们无法形成 k 个非空段。 
3. 如果辅音总数 C 为零，则每个段都必须有零个辅音，只要我们可以将字符串拆分为 k 个非空部分，这总是可能的。 由于任何剪切都不影响辅音相等，因此当 k ≤ n 时答案为“是”。 
4. 如果 C 不能被 k 整除，则返回“No”，因为整数计数的平均分配是不可能的。 
5. 计算target = C / k，即每个段所需的辅音数量。 
6. 从左到右遍历字符串，保持当前段中辅音的连续计数器。 
7. 每次遇到辅音时，递增运行计数器。 
8. 每当运行计数器达到目标时，我们将其重置为零，并从概念上完成一段。 我们还会计算已完成的部分数量。 
9. 处理完整个字符串后，检查我们是否恰好形成了 k 个片段并均匀地消耗了所有辅音。 如果是，则返回“是”，否则返回“否”。 

### 为什么它有效

 正确性取决于问题的单调结构。 当我们扫描字符串时，辅音计数只会增加，因此段边界是强制的：段必须在达到其所需配额时准确结束。 任何较早的削减都会为该段留下足够的辅音，任何较晚的削减都会超出配额。 因此，如果存在有效分区，它必须与这种贪婪构造一致。 可分性条件保证了配额全局一致，扫描保证了每一步的局部可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_vowel(c):
    return c in "aeiouy"

def solve():
    n, k = map(int, input().split())
    s = input().strip()

    consonants = 0
    for ch in s:
        if not is_vowel(ch):
            consonants += 1

    if k > n:
        print("No")
        return

    if consonants == 0:
        print("Yes")
        return

    if consonants % k != 0:
        print("No")
        return

    target = consonants // k

    cnt = 0
    segments = 0

    for ch in s:
        if not is_vowel(ch):
            cnt += 1
        if cnt == target:
            segments += 1
            cnt = 0

    print("Yes" if segments == k and cnt == 0 else "No")

if __name__ == "__main__":
    solve()
```该实现直接反映了贪婪构造。 为了清楚起见，元音检查被隔离。 唯一微妙的条件是最终验证：我们确保恰好形成了 k 个完整片段，并且没有剩余辅音，这表明最终片段不完整。
