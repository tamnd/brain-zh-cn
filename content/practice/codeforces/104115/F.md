 ## 解决方案
 ## 问题理解

 有一行$n$箱子编号从 1 到$n$。 正好一个胸$k$蕴含宝藏，其他皆空。 海盗开始打开宝箱，但尚未发现宝藏所在。 

在开始之前，他会采取两种固定策略之一：要么从左到右打开箱子，从 1 开始向上移动，要么从右到左打开，从 1 开始$n$并向下移动。 当他打开装有宝藏的箱子时，他立即停了下来。 

我们被要求计算在最坏的情况下他会打开多少个箱子，假设宝藏实际上在这个位置$k$，但海盗提前选择两个方向中较好的一个，以最小化所需的最大开口数。 

约束条件$n \le 10^9$排除跨阵列的任何模拟或迭代扫描。 任何解决方案都必须是恒定时间，因为即使是线性扫描$n$是不可能的。 

当宝藏接近一端时，就会发生一种微妙的边缘情况。 例如，如果$n = 5, k = 4$，则从左侧扫描需要 4 个开口，而从右侧扫描需要 2 个开口（5 → 4）。 总是假设从左到右的幼稚方法会在不比较两个方向的情况下错误地返回 4。 正确答案取决于与最近端点的距离。 

另一个边缘情况是当$k = 1$或者$k = n$。 在这两种情况下，一个方向立即在 1 步中找到宝藏，而另一个方向则需要$n$步骤。 任何平均或组合距离而不是取最小值的解决方案在这里都会失败。 

## 方法

 直接模拟将尝试从字面上遵循海盗的过程。 如果我们确定一个方向，我们就会计算有多少个箱子被打开，直到到达$k$。 从左边看，这正是$k$。 从右边看，这是$n - k + 1$。 这种方法是正确的，因为它精确地反映了流程定义，但在较大的约束下，它变得无关紧要，因为输入大小很大，但每次测试的计算量却很小。 

关键的观察是，只有两种可能的单调遍历，并且每种遍历都会产生纯粹基于位置的确定性成本$k$。 该问题简化为选择两个线性距离中较小的一个：距左边界的距离和距右边界的距离。 中间结构并不重要，因为搜索过程中没有分支或随机性。 

因此，最佳解决方案就是简单地计算成本并取最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n) | O(1) | O(1) | 太慢了|
 | 直接配方| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算如果海盗从左边开始，会打开多少个箱子。 这正是$k$，因为他打开 1, 2, ...，直到$k$。 
2. 计算如果海盗从右边开始，会打开多少个箱子。 这是$n - k + 1$，自从他打开$n, n-1, ..., k$。 
3. 比较这两个值并选择较小的一个，因为海盗会选择一种策略，以最大限度地减少最坏情况下的空缺数量$k$。 

### 为什么它有效

 每个策略都是确定性的单调遍历，没有跳过。 成本仅取决于到达索引所需的步骤数$k$从一个固定的端点。 由于两次遍历都是线性且独立的，因此最优选择始终是它们各自距离的最小值。 步骤之间没有交互，因此没有自适应策略可以改进这两个固定选项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    left = k
    right = n - k + 1
    print(min(left, right))

if __name__ == "__main__":
    solve()
```该代码读取两个整数并直接计算两个可能的搜索成本。 左边的成本对应于从 1 到$k$，而正确的成本对应于从$n$。 最终的答案是两者中的最小值。 

唯一的微妙之处是记住右侧距离包括位置本身，因此$+1$。 如果没有它，无论何时计数都会减一$k$正好在一个端点。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    return str(min(left, right))

 ## 边缘情况

 当$k = 1$，左边的策略一步就能找到宝藏，而右边的策略则需要$n$步骤。 该算法计算$left = 1$,$right = n$，并正确返回 1。 

当$k = n$，就会出现对称的情况。 计算结果$left = n$,$right = 1$，并且最小值再次为 1。 

当$k$正好在中间，两个方向的行为类似，但由于奇偶校验最多相差一。 例如，$n = 6, k = 3$给出$left = 3$,$right = 4$。 算法选择 3，符合左侧遍历首先到达的事实。 

这些案例证实该解决方案正确地减少了过程到端点的距离，并且没有遗漏边界效应。
