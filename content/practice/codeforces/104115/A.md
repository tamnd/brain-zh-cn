 ## 解决方案
 ## 问题理解

 我们得到一组代表电视节目的时间间隔。 每个节目都有开始时间、结束时间和三种类型之一。 Petya 喜欢类型 1 程序，Masha 喜欢类型 2，两人同时喜欢类型 3。 

在任何时刻，电视最多只能播放一个节目，但我们可以在节目之间自由切换，甚至只能观看其中的片段。 如果我们选择在某个时间段观看一个节目，当节目类型为 1 或 3 时，Petya 每分钟获得一个单位的幸福感，而当节目类型为 2 或 3 时，玛莎每分钟获得一个单位的幸福感。类型 3 的节目同时对两者做出贡献，因此在这一分钟内，总贡献度为 2。 

任务是在每个时刻选择观看哪些可用的节目，以便最大化两个朋友累积的总幸福感。 

输入约束允许最多十万个间隔，坐标最多为十亿。 这立即排除了任何试图逐分钟处理时间的解决方案。 随着时间的推移进行直接模拟可能需要迭代数十亿个单位，这在时间限制内是不可能的。 任何正确的解决方案都必须根据活动间隔集发生变化的事件边界进行推理。 

当多个间隔以复杂的方式重叠时，就会出现微妙的边缘情况。 例如，如果在某个时间有多个类型1和类型2程序重叠，但没有类型3程序，则很容易错误地认为我们可以获得每分钟两个的综合效益。 这是不正确的，因为一次只能观看一个节目。 在这种情况下，正确的增益仍然是每分钟 1。 

当类型 3 区间与许多其他区间重叠时，就会出现另一种极端情况。 即使有多个类型 1 和类型 2 程序可用，单个类型 3 程序的存在也占主导地位，因为它产生每分钟两个程序的最大可能组合效益。 

## 方法

 一种幼稚的策略是将时间线视为一系列微小的片段，并且对于每个时刻，确定哪些间隔是活动的并选择最佳的间隔。 从概念上讲，这是可行的，因为每个时刻的决策都独立于过去。 然而，如果我们明确地模拟时间，坐标范围可以扩展到十亿，因此迭代每个单位时间步会导致操作数量不可行。 

我们可以通过观察答案仅在间隔端点发生变化来改进这一点。 在两个连续端点之间，活动间隔集保持不变，因此最佳选择也保持不变。 这将问题转化为关键事件间隔数最多两倍的问题。 

在连续事件时间之间的每个段，我们只需要知道是否存在至少一个类型 3 的活动间隔，否则是否存在至少一个类型 1 或 2 的活动间隔。这减少了在扫描排序端点时按类型维护活动间隔计数的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力时间模拟 | O(最大坐标范围) | O(1) | O(1) | 太慢了|
 | 具有活动计数的扫描线 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们将所有间隔端点作为事件处理，并按升序扫描时间。

1. 我们将每个间隔转换为两个事件，一个标记其开始，一个标记其结束。 每个事件都带有时间和类型，我们还跟踪它是插入还是删除。 这使我们能够随时维护当前活跃的影片集。 
2. 我们按时间对所有事件进行排序。 当多个事件同时发生时，我们会先处理所有事件，然后再评估当时开始的分段的任何贡献。 这确保了每个时间间隔的活动集始终是正确的。 
3. 我们为活动间隔维护三个计数器：当前活动的类型 1、类型 2 和类型 3 的数量。 这些计数器使我们能够在恒定的时间内确定最佳的胶片选择。 
4. 在两个连续的事件时间之间，例如从时间 t 到 t_next，活动集不会改变。 我们计算该细分市场每分钟可实现的最佳幸福感。 如果至少有一个类型 3 间隔处于活动状态，则每分钟的最佳值为 2。否则，如果至少有一个类型 1 或类型 2 间隔处于活动状态，则最佳值为 1。如果没有活动，则为 0。 
5. 我们将此最佳值乘以线段 t_next 减去 t 的长度，并将其添加到答案中。 
6. 我们根据 t_next 发生的所有事件更新活动计数器并继续。 

关键思想是，我们永远不需要决定观看哪部特定的电影，只需决定每个时间段可实现的最大价值即可。 

### 为什么它有效

 在任何固定时刻，选择都独立于未来的决定，因为电影之间的切换没有成本。 因此，最优策略在每个时刻都是局部最优的。 由于活动集仅在事件边界发生变化，因此最优值在事件之间的每个间隔内是恒定的。 扫描线确保我们准确评估那些最大线段，而不会遗漏任何变化点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    events = []

    for _ in range(n):
        l, r, t = map(int, input().split())
        events.append((l, t, 1))
        events.append((r, t, -1))

    events.sort()

    cnt1 = cnt2 = cnt3 = 0
    ans = 0

    def value():
        if cnt3 > 0:
            return 2
        if cnt1 > 0 or cnt2 > 0:
            return 1
        return 0

    i = 0
    while i < len(events):
        j = i
        time = events[i][0]

        while j < len(events) and events[j][0] == time:
            j += 1

        if i > 0:
            prev_time = events[i - 1][0]
            ans += value() * (time - prev_time)

        for k in range(i, j):
            _, t, delta = events[k]
            if t == 1:
                cnt1 += delta
            elif t == 2:
                cnt2 += delta
            else:
                cnt3 += delta

        i = j

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案构建一个事件列表，其中每个间隔贡献两个端点。 对这些事件进行排序可确保我们按时间顺序处理所有更改。 计数器 cnt1、cnt2 和 cnt3 跟踪当前存在的每种类型的活动间隔数量。 

一个关键的实现细节是将具有相同时间戳的事件分组。 我们只计算不同时间点之间的贡献，而不是相同时间戳内的贡献。 函数 value() 对决策规则进行编码：类型 3 支配一切，否则任何类型 1 或 2 都会给出单位贡献。 

答案以段长度乘以该段中可实现的最佳值的形式累积。

 ## 边缘情况

 关键的边缘情况是多个事件在同一时间戳发生。 如果这些没有正确分组，算法可能会使用过时的计数错误地计算段。 正确的处理可确保在评估下一个段之前应用给定时间的所有插入和删除。 

另一种情况是一个间隔正好在另一个间隔结束时开始。 由于问题定义了半开间隔，因此端点处理必须确保不会计算额外的重叠。 扫描线在向前移动之前处理同一坐标处的事件，因此相邻间隔不会人为重叠。 

最后一种情况是分段没有活动间隔。 值函数正确返回零，确保空时间范围不会对答案产生影响。
