 ## 问题理解

 我们给出一个带有整数系数的二次方程$a, b, c$，全部非零。 我们可以用新的非零整数替换这三个系数的任何子集。 修改后，方程必须成为具有重复实根的二次方程，这意味着其判别式必须恰好为零。 

重实根的判别条件是$b^2 - 4ac = 0$，这相当于$b^2 = 4ac$。 任务是最小化我们从原始三元组更改的系数。 

输出是任何有效的三元组$(a', b', c')$在给定的范围内，使得所有都是非零整数并且二次方具有双根，同时最小化变化的数量。 

约束的大小很小，每个系数的边界为$10^4$，但输出可以达到$10^9$。 这强烈表明我们可以自由构造新系数，而不是在大范围内搜索。 条件的结构$b^2 = 4ac$是代数和离散的，因此解决方案取决于案例分析而不是大范围的优化。 

一个微妙的问题是可能存在多个最小答案。 该问题不需要唯一性，只需要正确性和最小的修改。 

当某些系数已经满足判别条件时，就会出现边缘情况。 例如，如果$a, b, c$已经满足了$b^2 = 4ac$，我们必须输出相同的三元组并且不修改任何内容。 另一种边缘情况是，仅改变一个系数就足够了，但粗心的构造可能会引入零系数或违反整数约束。 

## 方法

 强力解释将尝试所有改变系数子集的方法。 对于每个子集，我们将尝试边界内所有可能的整数替换，并检查是否$b^2 = 4ac$。 即使我们将替换限制在合理的范围内，搜索空间原则上也是无界的，甚至限制为$[-10^9, 10^9]$使得这不可行。 尝试对两个系数进行所有替换已经导致在大域上进行二次或更糟糕的搜索。 

关键的观察是我们只关心有多少系数是固定的还是被替换的。 由于只有三个系数，所以答案只能是 0、1、2 或 3 次变化。 我们可以明确地检查是否可以在每种情况下实现判别条件。 

如果零变化已经满足$b^2 = 4ac$，我们完成了。 

如果一项改变就足够了，那么我们会尝试精确调整一个系数，同时保持其他两个固定。 每种情况都简化为求解一个简单的丢番图方程：

 - 修复$a, c$， 调整$b$:$b' = \pm 2\sqrt{ac}$- 使固定$a, b$， 调整$c$:$c' = b^2 / (4a)$如果可整除且非零
 - 修复$b, c$， 调整$a$:$a' = b^2 / (4c)$如果可整除且非零

 如果这些都不起作用，我们将进行两项更改。 替换两个系数后，我们只需要保证存在满足的整数$b'^2 = 4a'c'$。 我们可以自由构造这样的三元组，例如通过设置$a' = 1$,$c' = 1$,$b' = \pm 2$。 这始终满足条件并遵守非零约束。 

这种结构将问题分解为少量恒定数量的代数检查。

 ## 算法演练

 1、检查原系数是否已经满足$b^2 = 4ac$。 如果是，则原样输出。 这对应于零修改，这是最佳的。 
2.仅尝试修改$a$同时保持$b$和$c$固定的。 计算$a' = b^2 / (4c)$。 这仅适用于$b^2$可以整除$4c$，结果非零，并且遵守所有约束。 如果有效，则输出这个三元组。 
3.仅尝试修改$c$同时保持$a$和$b$固定的。 计算$c' = b^2 / (4a)$在相同的整除性和非零检查下。 
4.仅尝试修改$b$同时保持$a$和$c$固定的。 我们需要$b'^2 = 4ac$， 所以$4ac$一定是一个完美的正方形。 如果是这样，设置$b' = \pm \sqrt{4ac}$。 选择任一符号，通常为正数。 
5. 如果单一更改选项均不起作用，请构造一个包含两次更改的有效二次方程。 规范的结构是$a' = 1$,$b' = 2$,$c' = 1$，满足$b'^2 = 4a'c'$确切地。 

它之所以有效，是因为每个有效答案都必须满足判别条件，并且固定系数的数量严格限制了方程的形式。 至多有一个系数自由时，方程就变成线性整除约束或平方条件。 如果甚至失败，释放两个系数可以保证对方程的完全控制，并且始终存在固定的规范解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

def ok(a, b, c):
    return b * b == 4 * a * c

if ok(a, b, c):
    print(a, b, c)
    sys.exit()

# try change a
if (b * b) % (4 * c) == 0:
    a2 = (b * b) // (4 * c)
    if a2 != 0:
        print(a2, b, c)
        sys.exit()

# try change c
if (b * b) % (4 * a) == 0:
    c2 = (b * b) // (4 * a)
    if c2 != 0:
        print(a, b, c2)
        sys.exit()

# try change b
val = 4 * a * c
if val > 0:
    import math
    r = int(math.isqrt(val))
    if r * r == val:
        print(a, r, c)
        sys.exit()

# fallback: change two coefficients
print(1, 2, 1)
```代码首先直接检查判别条件是否已经成立，对应于零变化。 每个后续块通过代数求解缺失变量来尝试进行一次修改。 可整除性检查确保我们只产生整数系数，因为小数值是无效的。 

平方根步长为$b$是唯一不平凡的计算，我们确保$4ac$赋值前是完全平方数$b$。 后备是一个保证有效的双根二次方程。 

一个微妙的点是确保没有系数变为零。 在计算新值时会显式检查这一点，因为即使输入非零，理论上除法也可能产生零。

 ## 边缘情况

 当判别式已经为零时会出现一种边缘情况，例如输入$(-3, 6, -3)$。 该算法立即检测到$b^2 = 4ac$并返回相同的三元组，避免不必要的修改。 

另一种边缘情况是只可能更改一个系数但需要仔细的整数处理。 例如，修复时$a$和$b$, 计算$c' = b^2 / (4a)$可能会产生非整数结果。 可除性检查可防止无效分配并强制算法尝试其他情况。 

进一步的边缘情况是当$4ac$是正数，但不是完全平方数。 在这种情况下，只需调整$b$不可能，因为不存在整数平方根。 该算法正确地跳过该分支并依赖于两次更改后备。 

最后，后备构造$a' = 1, b' = 2, c' = 1$始终避免零系数并始终满足判别条件，即使所有单次更改尝试都失败也能确保完整性。
