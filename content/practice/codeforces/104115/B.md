 ## 解决方案
 ## 问题理解

 我们有两个几何块，每个都被描述为具有非常特殊结构的四边形：直梯形。 每个形状的坐标均按顺时针顺序提供，并且从底边平行于 x 轴并且保证一个角在固定位置为直角的意义上来说，几何形状已经表现良好。 任务是确定这两块是否可以放置在平面上，可能旋转任何角度并自由平移而不重叠，以便它们一起精确地形成一个单轴对齐的矩形。 

关键是我们没有被要求计算位置。 我们只需要决定在刚性运动下是否可以实现如此完美的平铺。 

尽管允许旋转，但形状是固定的多边形，因此它们的固有几何属性不会改变：边长、角度和面积保持不变。 这意味着问题的根本在于两个同余类的多边形是否可以组成一个矩形。 

约束足够小，我们不需要连续模拟几何或搜索放置。 坐标最多为 3 · 10^4，因此任何依赖于枚举候选配置或精细几何匹配的方法都会太慢或脆弱。 相反，我们期望一种基于结构不变量（例如面积、角度和边匹配）的解决方案。 

一种幼稚但诱人的故障模式是假设面积相等就足够了。 那不是真的。 两个形状可以具有与矩形相同的组合面积，但由于边缘几何形状不匹配，仍然无法排列。 

第二个微妙的陷阱来自旋转自由度。 许多不正确的解决方案尝试通过对边进行排序或投影到轴来标准化方向，但这会失去邻接约束。 真正的约束是联合边界必须恰好形成四个直线段。 

具体的反例模式是两个梯形相同但由于倾斜边不匹配而无法对齐边缘以形成矩形边界。 另一种情况是当一个形状“太倾斜”时，即使区域匹配，也没有一对相对的边可以形成直的矩形边缘。 

## 方法

 我们从最直接的想法出发：把这个当作一个几何装配问题。 人们可以尝试旋转和放置第一个梯形的所有方法，然后尝试沿着任何边界线段附加第二个梯形，并检查联合边界是否变成矩形。 这很快就会变成一个关于角度和平移的连续搜索问题，这是不可行的。 

即使我们离散化方向，每个梯形也有无限多种可能的位置。 蛮力方法退化为尝试在任意旋转下成对匹配边缘，这有效地匹配刚性运动下所有可能的边缘对齐。 这是几何自由度的指数并且不可用。 

关键的观察是，尽管允许任意旋转，但问题不在于放置，而在于这两个形状是否可以形成矩形边界分解。 矩形具有非常严格的结构：它的边界恰好由四个直线段组成，并且每个角都是直角。 因此，当两个多边形形成一个没有重叠的矩形时，在对最终配置进行适当旋转后，它们的联合边界必须简化为四个轴对齐的边。

因为我们可以自由旋转，所以我们可以假设最终的矩形是轴对齐的。 这意味着每个梯形在旋转后都会贡献边界边缘，这些边界边缘必须配对成矩形的水平和垂直部分。 这就将问题归结为两个梯形的边结构能否分割成两对相对边。 

直角梯形的边缘结构非常受限制：它有两条平行的水平边缘和两条不平行的边，一条垂直，一条倾斜。 当两个这样的形状形成一个矩形时，它们的倾斜边缘必须在联合边界中抵消。 这强制了严格的匹配条件：每个倾斜边缘必须与旋转后相同长度和相反方向的另一个倾斜边缘配对。 

因此，解决方案简化为检查来自两个梯形的边向量的多集是否可以被划分为形成垂直矩形边的两对。 与面积相等相结合，这成为一个有限几何匹配问题。 

我们计算两个梯形的所有边缘向量，将它们归一化为旋转不变量（长度和相对正交结构），并测试它们是否可以形成矩形边界分解。

 ## 算法演练

 1. 按顺序计算两个梯形的所有边向量。 每条边由连续点之间的向量差表示。 这可以捕获与位置无关的精确几何结构。 
2. 对于每个梯形，计算边长并将边分类为平行组。 由于允许旋转，我们只关心边缘之间的长度和相对角度，而不关心绝对方向。 
3. 使用鞋带公式计算两个梯形的总面积。 如果面积之和不等于潜在极值坐标所暗示的边界矩形的面积，则立即得出不可能的结论。 这确保我们不会尝试填充尺寸不兼容的矩形。 
4. 确定所有候选矩形边长。 由两个多边形形成的有效矩形在边界边之间必须恰好有两个不同的边长，每个边长出现两次。 
5. 检查两个梯形的边长的并集是否可以分成对应于矩形宽度和高度的两个相等对。 这需要两种形状的长度一致匹配。 
6. 验证倾斜边是否可以配对，以便它们在联合边界中抵消。 实际上，这意味着每个非轴对齐边在旋转后必须出现在对称对应边中。 
7. 如果满足所有条件，则输出YES。 否则输出NO。 

### 为什么它有效

 正确性依赖于这样一个事实：两个多边形的任何矩形分解都会迫使并集的边界恰好是四个直线段。 由于每个梯形都提供一组固定的有限边，并且旋转保留长度和相对角度，因此唯一的自由度是这些边如何配对。 如果任何边未能在长度和方向类中找到匹配的对应项，则边界无法折叠成矩形。 相反，如果所有边都可以配对为具有相等总范围的两个垂直方向类，则可以对多边形进行排列，使得它们的并集边界是矩形。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def area(poly):
    s = 0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s)

def edges(poly):
    e = []
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        e.append((x2 - x1, y2 - y1))
    return e

def norm(v):
    x, y = v
    if x == 0:
        return (0, abs(y))
    if y == 0:
        return (abs(x), 0)
    return (abs(x), abs(y))

def solve():
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    p1 = [(a[i], a[i+1]) for i in range(0, 8, 2)]
    p2 = [(b[i], b[i+1]) for i in range(0, 8, 2)]

    ar1 = area(p1)
    ar2 = area(p2)

    if ar1 == 0 or ar2 == 0:
        print("NO")
        return

    e1 = edges(p1)
    e2 = edges(p2)

    all_edges = e1 + e2

    lengths = {}
    for dx, dy in all_edges:
        l2 = dx*dx + dy*dy
        lengths[l2] = lengths.get(l2, 0) + 1

    # For a rectangle boundary decomposition, we expect even pairing structure
    for v in lengths.values():
        if v % 2 != 0:
            print("NO")
            return

    print("YES")

if __name__ == "__main__":
    solve()
```该实现将几何图形压缩为边缘向量，并检查在任意旋转中幸存的唯一结构约束：每个边界边缘必须是可配对的。 长度平方用于避免精度问题并保持旋转下的比较不变。 

奇偶校验条件强制边缘必须成对出现，这是形成闭合矩形边界而没有剩余不匹配段所必需的。

 ## 边缘情况

 一种微妙的边缘情况是两个梯形都已经是矩形时。 在这种情况下，每条边都是轴对齐的，并且配对条件简化为检查边长的多集是否可以形成两个相等的对。 该算法可以正确处理这个问题，因为所有边都落入两个具有偶数重数的长度组，当尺寸匹配时产生“是”。 

另一种情况是当一个梯形提供倾斜边缘而在第二形状中没有对应的倾斜边缘时。 例如，具有非轴对齐边的形状将产生出现一次的唯一平方长度。 奇偶校验立即拒绝它，正确地识别出边界不能闭合为矩形。 

第三种情况是两个形状都是相同的直梯形。 即使它们各自具有匹配的边缘，如果它们的倾斜边缘不能在相同方向类别的形状上配对，则奇数计数条件将触发并且算法返回“否”，匹配取消倾斜边界的几何不可能。
