 ## 解决方案
 ## 问题理解

 该问题提出了一个具有固定攻击力和生命值的英雄面对一组怪物，每个怪物都有自己的攻击力和生命值。 战斗是不轮流但同时进行的：当英雄攻击怪物时，怪物也会将其攻击伤害返还给英雄。 当怪物的生命值降至零或更低时，怪物就会被击败，而英雄的生命值降至零或更低时，就会被击败。 目标是确定英雄是否可以杀死所有怪物，即使他在此过程中死亡，只要没有怪物幸存即可。 

输入由多个测试用例组成。 每个测试用例提供英雄的攻击、英雄的生命值、怪物数量、怪物攻击列表和怪物生命值列表。 每个测试用例的输出都是简单的“是”或“否”。 

这些约束允许所有测试用例中最多有 10^5 个怪物，怪物的生命值和攻击力最多为 10^6。 在最坏的情况下，任何迭代地减去每次攻击的生命值直到怪物死亡的幼稚模拟都太慢了。 例如，如果怪物的生命值是 10^6，英雄的攻击力是 1，则模拟每个怪物的每次攻击可能需要 10^6 次迭代，远远超出了可行的限制。 

当怪物造成巨大伤害但生命值较低时，就会出现微妙的边缘情况。 粗心的贪婪算法可能会以任意顺序攻击怪物，让英雄过早死亡。 例如，生命值 999 且攻击力 1000 的单个怪物对生命值 999 的英雄立即致命。 正确的答案是否定的，但如果忽略了所需的总伤害而只计算攻击次数，则可能会错误地回答是。 

## 方法

 暴力方法明确地模拟每次攻击：重复选择一个活的怪物，从其生命值中减去英雄的攻击力，从英雄的生命值中减去怪物的攻击力，然后重复，直到所有怪物或英雄都死了。 这是正确的，但每个测试用例可能需要数百万次操作，考虑到限制，这太慢了。 

最佳方法利用了这样的观察结果：每个怪物造成的总伤害与杀死它所需的攻击次数成正比。 对于每个怪物，所需的英雄攻击次数为 ceil(monster_health / Hero_attack)。 每次攻击造成的英雄伤害等于怪物的攻击力。 如果英雄单独与每个怪物战斗，将所有怪物的总伤害得出英雄将承受的总伤害。 如果英雄的生命值超过或等于该总和减去最大的单一怪物攻击力，则英雄生存。 这是有效的，因为即使英雄在那次攻击中死亡，最后一个怪物也可以被消灭，但所有其他怪物都必须完全生存。 排序是不必要的； 只需要最大的怪物攻击力和所有怪物的总“有效伤害”即可。 

蛮力推理很简单，但时间复杂度为 O(n * max(b_i/A))，而最佳方法对于每个测试用例都是线性的，即 O(n)，它完全符合约束条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 最大值(b_i / A)) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取英雄的攻击`A`, 英雄的健康`B`，以及怪物数量`n`。 
2.读取怪物攻击数组`a`和怪物生命值阵列`b`。 
3. 对于每个怪物，计算杀死它所需的攻击次数。 这是`(b_i + A - 1) // A`。 将此值乘以怪物的攻击力即可得出该怪物在死亡前造成的总伤害。 将所有怪物的这些值相加。 
4. 识别最大的单体怪物攻击`max_attack`。 这代表了英雄对最终怪物所能承受的伤害，因为他在杀死它后可能会死亡。 
5. 如果英雄健康`B`大于或等于所有造成的伤害之和减去`max_attack`，输出YES。 否则输出NO。 

为什么有效：关键的不变量是每个怪物的总伤害是根据杀死它所需的最少攻击次数来计算的。 减去最大怪物攻击力可以模拟英雄消灭最后一个怪物同时可能同时死亡的场景。 这确保了英雄可以杀死所有怪物而不留任何活物，符合问题的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        A, B, n = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        total_damage = 0
        max_attack = 0
        
        for ai, bi in zip(a, b):
            attacks_needed = (bi + A - 1) // A
            total_damage += attacks_needed * ai
            max_attack = max(max_attack, ai)
        
        if B >= total_damage - max_attack:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```解决方案的每个部分都直接对应于算法演练。 这`attacks_needed`计算使用上限除法来精确确定需要多少次攻击。`total_damage`总结每个怪物的潜在伤害。`max_attack`用于让英雄在最后一次攻击中死亡。 边缘情况，例如英雄生命值恰好等于所受伤害的单个怪物，将由最终比较处理`B >= total_damage - max_attack`。
