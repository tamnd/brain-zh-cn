 ## 解决方案
 ## 问题理解

 我们有一个固定点 (O)，代表工厂，以及平面上的 (n) 个收集点。 我们需要选择四个收集点并将它们分成两对。 连接每对点的线段必须经过 (O)，并且这四个点必须位于一个圆上。 

因为通过 (O) 的每条线最多包含两个收集点，所以一旦我们选择了有效的对，这两个点必须位于 (O) 的相对侧。 因此，每个有用的对对应于一条穿过 (O) 的线，其中恰好包含两个收集点。 

(O)和所有采集点的坐标都是绝对值最大为(10^4)的整数，而(n)最大为(2000)。 (O(n^2)) 解决方案已经执行了大约四百万次迭代，这在 Python 中是很方便的。 在一秒的限制下， (O(n^3)) 或 (O(n^4)) 解决方案是不现实的。 因此，主要目标是将搜索减少到基本上一次遍历点。 

有几个几何细节可能会导致看似正确的实现失败。 来自 (O) 的同一射线上的一对点不会形成包含 (O) 的线段。 例如，```
0 0
4
1 0
2 0
0 1
0 -2
```在正 (x) 射线上有两个点，因此前两个点不能是有效的点对。 唯一有效的对是 ((0,1),(0,-2))，这不足以形成所需的四个点，所以答案是`NO`。 仅通过无向斜率对点进行分组并忘记它们占据 (O) 的哪一侧的实现可能会错误地将前两个点视为一对。 

与(O)重合的点也必须单独处理。 例如，```
0 0
3
0 0
1 0
-1 0
```只有一对非简并的，所以答案是`NO`。 (O) 处的点与 (O) 的距离为零，并且它不能参与有用的四点配置中所需的两点线段之一。 

重复的坐标是不假设每个标准化方向自动表示有效对的另一个原因。 例如，```
0 0
2
1 1
1 1
```在同一位置包含两个收集点。 它们并不位于 (O) 的相对两侧，因此它们无法通过 (O) 形成所需的线段。 答案是`NO`。 

最后，精确的算术很重要。 相关的几何量是平方距离的乘积，使用浮点值可能会引入不必要的等式误差。 所有坐标都是整数，因此整个计算可以用整数来执行。 

## 方法

 直接的做法是枚举每组四个集合点，尝试所有三种方法将四个点分成两对，检查对应的线段是否通过（O），然后检查四个点是否同循环。 这是正确的，因为每个可能的答案都经过明确检查。 然而，对于 (n=2000)，仅仅枚举四点子集就需要

 [
 \binom{2000}{4}=664,668,499,500
 ]

 最坏情况下的迭代。 这远远超出了可用时间。 

有用的几何观察结果是，所选的两个线段是穿过 (O) 的同一个圆的割线。 对于一条这样的线上的任何点对 (A,B)，定义

 [
 P(A,B)=OA\cdot OB。 
]

 对于通过圆的同一点 (O) 的任意两条割线，点幂定理给出

 [
 OA\cdot OB=OC\cdot OD。 
]

 因此，我们可以检查包含一对点的 (O) 的每条线并计算其距离乘积，而不是一次检查四个点。 当两个不同的有效行的乘积相等时，它们准确地给出所需的答案。 

无需使用实际距离。 如果

 [
 r_A^2=OA^2,\qquad r_B^2=OB^2,
 ]

 那么距离乘积相等等于

 [
 r_A^2r_B^2=r_C^2r_D^2。 
]

 所有这些值都是整数。 

剩下的任务是识别同一条线上的相对点。 对于点 (P)，将其平移 (O)，将向量减少其坐标的 gcd，并保留其符号。 例如，((6,4)) 变为 ((3,2))，而其相反射线为 ((-3,-2))。 当两个归一化向量都出现时，一对就存在。 

输入保证通过 (O) 的任何直线上最多有两个点，因此每条射线最多可以包含一个相关点。 我们可以为每个归一化有向向量存储一个点，然后查找其负值。 

暴力方法之所以有效，是因为它显式检查每个可能的四点配置，但在 (n=2000) 时失败。 观察到每个有效配置都是由两个相反的射线对确定的，并且圆使它们的距离乘积相等，这让我们可以将问题简化为对每条有效线散列一个整数值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n^4)) | (O(1)) | (O(1)) | 太慢了 |
 | 最佳| (O(n\log C)) | (O(n\log C)) | (O(n)) | (O(n)) | 已接受 |

 这里 (C) 是最大绝对平移坐标。 由于 (C\le 2\cdot10^4)，gcd 计算实际上是这些约束的恒定时间。 

## 算法演练

 1. 通过减去 (O) 的坐标来平移每个收集点。 具有平移坐标 ((0,0)) 的点将被忽略，因为它无法与 (O) 上的另一个点形成非简并对。 
2. 标准化每个剩余点的方向。 如果其平移向量为 ((x,y))，则将两个坐标除以 (\gcd(|x|,|y|))。 保持符号不变，因此相反的光线产生相反的键。 
3. 为每个归一化有向向量存储点索引及其平方距离
 [
 r^2=x^2+y^2。 
]
 每条线上至多两个点的条件保证一条射线不能包含两个不同的集合点。 
4. 对于每个方向 (v=(x,y))，寻找相反的方向 (-v)。 如果不存在，则这些点不能通过 (O) 形成线段。 
5. 每条无向线仅处理一次。 一种简单的方法是仅处理字典元组顺序中满足 (v< -v) 的方向。 对于该线上的两点 (A,B)，计算
 [
 值=OA^2\cdot OB^2。 
]
 6. 存储为每个找到的第一对`value`。 如果另一条不同的线产生相同的值，则输出两个存储的端点，然后输出当前线的两个端点。 它们的两个线段都包含 (O)，且等积条件保证所有四个点都位于一个圆上。 
7、如果没有重复的产品，则输出`NO`。 

### 为什么它有效

 考虑任何包含 (A,B) 和 (C,D) 对的有效答案。 由于两条线段都经过 (O)，因此 (A,B) 位于一条直线的相对射线上，而 (C,D) 位于另一条直线的相对射线上。 由于这四个点位于一个圆上，因此 (O) 相对于该圆的幂给出

 [
 OA\cdot OB=OC\cdot OD。 
]

 两边平方正好给出了算法检查的相等性。 

相反，假设穿过 (O) 的两条不同的直线具有具有相等乘积的相反光线对 (A,B) 和 (C,D)。 将圆穿过 (A,B,C)。 它在 (O) 处的功率由第一个割线确定，等于 (OA\cdot OB)。 第二条线与该圆相交于 (C) 和距 (O) 距离必须相等的另一点。 由于 (OC\cdot OD) 等于该值，因此 (D) 正是第二个交点。 因此所有四个点都位于同一个圆上。 

不变量是每条已处理的有效线都由一个整数表示，即该整数对相对于 (O) 的幂值的平方。 相等的整数恰好对应于属于同一个圆的两条割线。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    ox, oy = map(int, input().split())
    n = int(input())

    rays = {}

    for idx in range(1, n + 1):
        x, y = map(int, input().split())
        x -= ox
        y -= oy

        if x == 0 and y == 0:
            continue

        g = math.gcd(abs(x), abs(y))
        x //= g
        y //= g

        rays[(x, y)] = (idx, x * x + y * y)

    seen_value = {}

    for direction, data in rays.items():
        x, y = direction
        opposite = (-x, -y)

        if opposite not in rays:
            continue

        # Process each undirected line only once.
        if direction > opposite:
            continue

        idx1, r1 = data
        idx2, r2 = rays[opposite]

        value = r1 * r2

        if value in seen_value:
            a, b = seen_value[value]
            print("YES")
            print(a, b, idx1, idx2)
            return

        seen_value[value] = (idx1, idx2)

    print("NO")

if __name__ == "__main__":
    solve()
```代码的第一部分翻译每个点，使工厂成为原点。 这使得方向测试和距离计算都独立于 (O) 的原始位置。 

gcd 归一化将同一射线上的向量转换为相同的字典键。 例如，((10,6)) 和 ((5,3)) 都变为 ((5,3))。 它们的相反射线用((-5,-3))表示。 我们故意保留符号，因为仅一条无向线不足以判断两点之间的线段是否包含 (O)。 

平方距离是在代码中标准化后计算的。 这是有效的，因为归一化向量仍然指向相同的方向，但这里有一个微妙的点：存储的平方距离必须是原始点的实际平方距离，而不是归一化方向的平方长度。 因此，上面写的代码是不正确的。 

正确的实现必须保留用于距离计算的原始翻译坐标，同时仅使用归一化向量作为字典键。 这是更正后的完整解决方案。```python
import sys
import math

input = sys.stdin.readline

def solve():
    ox, oy = map(int, input().split())
    n = int(input())

    rays = {}

    for idx in range(1, n + 1):
        x, y = map(int, input().split())
        x -= ox
        y -= oy

        if x == 0 and y == 0:
            continue

        dist2 = x * x + y * y

        g = math.gcd(abs(x), abs(y))
        dx = x // g
        dy = y // g

        rays[(dx, dy)] = (idx, dist2)

    seen_value = {}

    for direction, (idx1, r1) in rays.items():
        dx, dy = direction
        opposite = (-dx, -dy)

        if opposite not in rays:
            continue

        if direction > opposite:
            continue

        idx2, r2 = rays[opposite]
        value = r1 * r2

        if value in seen_value:
            a, b = seen_value[value]
            print("YES")
            print(a, b, idx1, idx2)
            return

        seen_value[value] = (idx1, idx2)

    print("NO")

if __name__ == "__main__":
    solve()
```第二个版本是要提交的版本。 归一化方向和原始向量之间的区别至关重要。 归一化会删除距离信息，因此使用归一化向量来计算 (OA^2) 会使同一射线上的不相关点看起来具有相同的距离。 

Python 整数具有任意精度，因此乘积不会导致溢出。 原始坐标差以(2\cdot10^4)为界，每个平方距离最多为(8\cdot10^8)，乘积大致低于(6.4\cdot10^{17})。 

词典比较`direction > opposite`防止处理同一行两次。 它不会影响几何形状，只是避免在功率图中存储相同的对两次。 

最后四个指数的顺序也是经过深思熟虑的。 前两个索引来自一对相反光线对，而后两个索引来自另一对。 因此，第一段和第二段都通过 (O)，完全按照输出格式的要求。
