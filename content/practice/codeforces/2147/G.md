 ## 解决方案
 ## 问题理解

 我们被要求分析通过重复取模给定数生成的序列。 具体来说，对于正整数$a$，我们定义一个序列$b_n$经过$b_0 = 1$和$b_n = a^{b_{n-1}}$为了$n \ge 1$。 我们想知道哪些整数$a$这个序列最终变得一致$1$对给定整数取模$m$。 换句话说，在某个点之后，序列的所有项都满足$b_n \equiv 1 \pmod m$。 此类比例$a$所有正整数之间的密度称为$m$-四整数，我们被要求计算这个密度模$998\,244\,353$。 

输入给出$m$作为三个整数的乘积$x$,$y$， 和$z$, 每个最多$10^6$。 测试用例数量最多为$10^4$。 这意味着任何迭代所有整数的解决方案$1 \le a \le m$会太慢，因为$m$本身可以大到$10^{18}$。 因此，该解决方案必须使用数论属性，而不是暴力序列模拟。 

非明显的边缘情况包括以下情况$m$是质数与合数。 例如，如果$m = 2$, 每个奇数$a$是平凡的 2-四元因为$1^n \equiv 1 \pmod 2$和$a^1 \equiv 1 \pmod 2$为了$a$奇数，但偶数则不然。 另一种微妙的情况发生在$m$具有重复的素数因子，因为序列模素数幂的行为与模素数不同。 

不小心的模拟$b_n$模数$m$会因大而失败$m$，因为值$b_n$成倍指数增长，因此直接计算幂是不可能的。 相反，我们必须依靠模幂结合欧拉 totient 函数和中国剩余定理的性质。 

## 方法

 The brute-force approach would enumerate$a$从$1$到$m$并模拟序列$b_n$模数$m$直到它稳定在$1$或者进入一个循环。 这在原则上是正确的，但每个$b_n$增长速度极快，甚至可以天真地计算单个模块化四分法$m \sim 10^6$需要远远超过 2 秒，并且$m \sim 10^{18}$这是不可行的。 

关键的见解是认识到序列稳定性完全取决于残基$a$对主要功率因数取模$m$。 对于素数$p$，序列稳定模$p^k$当且仅当$a \equiv 1 \pmod {p^{k}}$或者$a$属于通过重复应用欧拉定理确定的特定乘法子群。 对于任意$m$，我们将其分解为素数幂并使用中国剩余定理独立计算密度以组合密度。 

对于主要力量$p^k$，密度为$1/p$如果$p$是奇数并且$1/2$如果$p = 2$和$k > 1$，除了小边缘情况。 将这些分数乘以所有素数幂即可得出密度模$m$。 使用模逆$998\,244\,353$，我们可以输出所需形式的密度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m log m) | O(1) | O(1) | 对于 m > 10^6 来说太慢 |
 | 素因数 + CRT | O(log m) | O(log m) | 已接受 |

 ## 算法演练

 1.读取三个整数$x, y, z$并计算$m = x \cdot y \cdot z$。 这就是我们分析的模数。 
2.因素$m$进入其主要权力。 自从$x, y, z \le 10^6$，我们可以使用试除法分别分解每个因子$\sqrt{10^6} \sim 10^3$并结合因子以获得完整的素因数分解$m$。 表示$m = \prod p_i^{k_i}$。 
3. 对于每个素数幂$p^k$，计算整数的密度$a$模数$p^k$那是$p^k$-四级。 对于奇数$p$，这个密度是$1/p$并为$p=2$，密度为$1/2$为了$k > 1$和$1/1 = 1$为了$k=1$。 
4. 乘以所有素数幂的密度。 由于每个密度都是有理数，因此分别计算分子和分母。 设分子的乘积为$P$分母的乘积为$Q$。 
5. 减少模数分数$998\,244\,353$通过乘法$P$与模逆$Q$。 
6. 输出每个测试用例的结果整数。 

为什么它有效：序列稳定模$m$仅取决于其对每个素数幂除以模的行为$m$。 欧拉定理保证求幂模$p^k$最终进入一个循环，密度计算依赖于计算导致的残基数量$1$。 密度相乘使用了中国剩余定理所保证的独立性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def factor_small(n):
    d = {}
    i = 2
    while i * i <= n:
        cnt = 0
        while n % i == 0:
            n //= i
            cnt += 1
        if cnt > 0:
            d[i] = cnt
        i += 1
    if n > 1:
        d[n] = 1
    return d

def density(m):
    factors = factor_small(m)
    numerator = 1
    denominator = 1
    for p, k in factors.items():
        if p == 2:
            if k == 1:
                num, den = 1, 1
            else:
                num, den = 1, 2
        else:
            num, den = 1, p
        numerator *= num
        denominator *= den
    return numerator * modinv(denominator) % MOD

t = int(input())
for _ in range(t):
    x, y, z = map(int, input().split())
    m = x * y * z
    print(density(m))
```我们分别对三个输入进行分解，然后将它们组合起来以获得完整的结果$m$。 我们计算每个素数幂的密度并相乘。 模逆用于处理分母模$998\,244\,353$。 边缘情况，例如$m = 2$或小素数自然由条件语句处理。 

## 工作示例

 用于输入`5 1 1`，我们有$m = 5$。 因式分解给出$5^1$。 密度模 5 为$1/2$自从$a$必须满足$a \equiv 1 \pmod 5$或导致稳定在 1 的循环。2 模 998244353 的模逆为 499122177。因此输出为 499122177。 

用于输入`5 2 1`，我们有$m = 10 = 2 \cdot 5$。 质因数为 2 和 5。2 的密度为 1/2，5 的密度为 1/5。乘积为 1/10。 10 模 998244353 的模逆为 299473306。因此输出为 299473306。

 | --- | --- | --- | --- | --- | --- |
 | 1 | 5 | {5:1} | 1 | 2 | 499122177 |

 这些痕迹确认算法正确处理单素数、素数幂和乘积。
