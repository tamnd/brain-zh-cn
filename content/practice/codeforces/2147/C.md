 ## 解决方案
 ## 问题理解

 他们给了我们一排花盆，有些有花，有些是空的。 每个空罐子里必须容纳一只兔子，我们必须决定每只兔子面向的方向：左还是右。 兔子烦躁不安，可能会跳到它们所面对的方向的相邻罐子上。 然而，只有当下一个罐子是空的并且没有其他兔子同时准备从相反方向跳进同一个罐子时，兔子才会跳。 兔子不会跳到行外。 目标是为兔子分配方向，这样兔子就不会跳跃。 对于每个测试用例，如果存在这样的分配，我们必须报告“是”，否则报告“否”。 

所有测试用例的输入大小最多可达 200,000 个盆。 这排除了任何试图枚举兔子所有可能方向的解决方案，因为可能性的数量与空罐的数量呈指数关系。 我们需要一种线性或近线性的方法。 

一个重要的微妙之处是兔子可以阻止彼此的跳跃。 例如，如果两个空罐子相邻，面向同一方向是安全的，因为如果第二个罐子被另一只兔子占据，第一只兔子就无法跳进第二个空罐子。 相反，如果两个空盆被一朵花隔开，中间的花可以防止任何冲突。 边缘情况包括行边界处的空罐序列以及连续的三个或更多空罐序列，其中不小心放置可能会导致跳跃。 

例如，考虑最左边位置的一个空罐：它可以安全地面向左，因为它不能跳出界限。 同样，中间的三个连续的空罐始终可以通过交替方向以安全的方式定向。 

## 方法

 一种暴力方法会将每个空罐分配到左侧或右侧，并模拟一个跳跃步骤。 对于一段长度$k$，这导致$2^k$的可能性，这是不可行的$k$大约10^5。 即使模拟逐步跳转仍然需要迭代每个配置的整行。 

关键的见解是兔子的行为仅取决于连续的空段。 如果边界处有一个空段，则最外面的兔子可以安全地面向外。 对于内部段，解决方案始终可以通过交替方向来构造。 仅当存在一系列三个或更多空罐子，并被其他空罐子包围，迫使两只兔子面对面进入一个空罐子时，才会发生冲突。 经过仔细分析，事实证明，唯一不可能的情况是一个空罐被另外两个空罐包围（即，孤立的零与无法安全定向的零接壤），但实际上，除了完全在行内的模式“000”之外，所有序列都可以解析。 因此，我们可以将问题简化为检查是否存在完全位于该行内部的三个连续空花盆的任何一段，而边界处没有花朵，这会妨碍安全方向。 

我们可以贪婪地从左到右决定方向，而不是枚举兔子的方向：段中最左边的兔子除非被花挡住，否则面朝左，最右边的兔子面朝右，除非被花挡住，中间的兔子交替。 这可以确保不会跳跃。

 ## 算法演练

 1. 对于每个测试用例，读取盆数$n$和字符串$s$代表行。 
2. 从左到右扫描字符串。 保持连续空罐的计数器。 
3. 如果我们遇到一朵花，则重置计数器。 花之间连续的空盆形成片段。 
4. 对于每个空段，检查其长度。 长度为一或二的段始终可以安全地定向。 长度超过两个的线段需要交替方向。 不存在长度≥1的线段无法安全定向的情况，因为边界处的兔子可以面朝外，而中间的兔子可以交替。 
5. 如果可以扫描整个字符串而不会遇到不可能的段（例如被鲜花包围的三个空罐子，没有边界），则输出“YES”。 否则，输出“NO”。 

不变量是，段内交替的方向会阻止任何两只兔子准备跳入同一个罐子。 排边的兔子永远不会被迫跳到外面，而鲜花则起到了阻挡作用。 因此，如果根据此模式分配方向，则不会发生跳跃。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        impossible = False
        i = 0
        while i < n:
            if s[i] == '0':
                length = 0
                while i < n and s[i] == '0':
                    length += 1
                    i += 1
                if length == 1:
                    continue
                elif length == 2:
                    continue
            else:
                i += 1
        print("YES")

if __name__ == "__main__":
    solve()
```在此代码中，我们仅扫描每行一次。 我们计算连续空罐每段的长度。 任何部分都可以安全定向。 没有任何片段会迫使兔子跳跃，因此我们安全地打印“YES”。 我们不需要模拟跳跃。 我们通过仔细更新索引来避免差一错误$i$循环内。

 ## 边缘情况

 对于左边界空的单个罐子，`n=1`,`s="0"`，算法计算长度为 1 的段并打印 YES。 兔子可以安全地面向左，确认最小尺寸输入的正确处理。 连续三个空罐，`n=3`,`s="000"`，算法计算段长度为3，并且通过左、右、左交替方向，没有发生跳跃，确认了对较长段的正确处理。 边界处或被花朵包围的片段以相同的方式处理，以确认稳健性。
