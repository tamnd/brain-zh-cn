 ## 解决方案
 ## 问题理解

 我们得到了由模算术规则生成的一系列平台高度。 第 x 个平台位于高处`(a · x) mod p`， 在哪里`a`和`p`是互质的，我们只考虑第一个`n`这样的职位。 角色从高度 0 开始，可以在任意两个位置之间向上移动，只要单次跳跃不超过固定限制`h`。 任务是确定是否有可能到达这些平台中最高的平台`n`点，假设角色可以选择访问可到达平台的任何顺序。 

这不是一个简单的“我们能否直接达到最大值”的问题。 在任何两个已经到达的平台之间跳转的能力意味着平台形成一个图，其中每对节点都连接，如果它们的高度差最多为`h`。 问题是询问高度最大的节点是否位于该规则下包含 0 的连通域中。 

测试用例的数量限制非常严格，最多 10⁴，而`n`和`p`可以大到 10⁹。 这立即排除了任何显式构建所有平台高度或每个测试用例天真地模拟连接的方法。 即使每个测试用例的 O(n) 总体来说也太大了。 

关键的微妙之处在于顺序`(a · x mod p)`其行为就像对残基进行类似排列的行走，因为`a`和`p`是互质的。 然而，我们并没有遍历整个循环，只是遍历第一个循环`n`点按顺序。 这破坏了最直接的结构，并且关于单调性或简单间隙的天真推理失败了。 

一个典型的错误是假设由于高度是模数分散的`p`，可达区域仅取决于索引顺序中的本地邻居。 例如，如果高度是`7, 2, 9, 4`和`h = 2`，人们可能会错误地认为按索引顺序访问会提供可达性信息。 但正确的转换仅取决于排序高度，而不取决于索引顺序。 

另一种故障模式是忽略可达性相当于图中的连接性，其中边缘完全取决于绝对高度差。 对指数进行天真的 BFS 会错过恰好具有接近高度的非相邻指数之间的有效跳跃。 

## 方法

 暴力解释构建了完整的图表`n`节点，其中每个节点是平台高度。 如果两个节点的绝对高度差最大，则它们是连接的`h`。 然后我们从地面（0）运行 BFS 或 DFS 并检查最大高度节点是否可达。 这是正确的，但是构造所有成对边的成本为 O(n²)，即使对于中等程度的情况也是不可能的`n`。 

我们可以通过观察在由绝对差阈值定义的图中来减少这种情况，边缘仅在按排序顺序接近的点之间起作用。 一旦高度排序，每个节点只需要连接到距离内的直接邻居`h`，因为任何较长范围的连接都可以通过中间排序点进行分解（如果它们在阈值内）。 

这将问题简化为排序后线图中的连通性，我们可以贪婪地扩展可达区间。 剩下的困难是我们仍然必须生成`n`有效地价值观。 关键的观察是，尽管`n`跨测试用例很大，每个测试只需要对生成的残基进行线性扫描，并生成每个`a·x mod p`是 O(1)。 真正的瓶颈是每个测试的排序，这是可以接受的，因为所有测试的总输入大小以 10⁴ 为界。 

因此，解决方案变为：生成所有高度，对它们进行排序，然后根据大于的间隙扫描合并可达组件`h`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解图| O(n²) | O(n²) | 太慢了 |
 | 排序 + 贪婪连接 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 使用生成所有平台高度`h[i] = (a · i) mod p`为了`1 ≤ i ≤ n`。 这显式地构造了可达节点的状态空间。 
2. 对高度数组进行排序。 排序至关重要，因为可达性仅取决于数值接近度，而不取决于索引顺序。 
3. 初始化变量`reachable_max`作为最小高度，因为地面为 0，我们考虑向上的连通性。 
4. 从最小到最大扫描排序后的高度。 如果连续高度之间的差距最多为`h`，通过扩展将它们合并到同一个可达集群中`reachable_max`。 
5. 如果在任何一点差距超过`h`，我们检查目标最大高度是否已经包含在当前簇中。 如果不是，并且我们无法弥合差距，则剩余的较大值将无法从 0 到达。 
6. 处理完成后，检查最大高度是否与 0 在同一个连通段中（相当于第一个包含 0 的簇是否达到最大值且没有大于 0 的断点）`h`）。 

关键思想是排序顺序将问题转化为检查从最小可达值的范围是否可以连续扩展到最大值而不会遇到禁止间隙。 

### 为什么它有效

 排序后，仅当两个高度在距离内时才可能在两个高度之间跳跃`h`。 如果两个连续的排序值相差超过`h`，那么它们之间不存在中间值链，因为任何中间值都必须在数字上位于它们之间，因此会在它们之间排序。 因此，间隙大于`h`形成一个硬屏障，将图分隔成互不相连的组件。 从 0 开始的可达分量恰好是从最小高度开始的第一段，其中所有相邻差异最多`h`。 如果最大值在该段内，则可达； 否则，它会被禁止的间隙分开。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        a, n, p, h = map(int, input().split())
        
        vals = [(a * i) % p for i in range(1, n + 1)]
        vals.sort()
        
        # start from the smallest height cluster
        ok = True
        for i in range(1, n):
            if vals[i] - vals[i - 1] > h:
                # if max is beyond this point, it is unreachable
                if vals[n - 1] > vals[i - 1]:
                    ok = False
                break
        
        out.append("YES" if ok else "NO")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```生成步骤直接构造全套平台高度。 排序确保我们可以纯粹地推理值空间中的邻接关系。 扫描检测到第一个“阻塞间隙”大于`h`。 一旦找到这样的间隙，右侧的所有内容都会与左侧的所有内容断开连接。 

检查最大值是否超出间隙的条件是关键的正确性门：如果最大值已经在可达前缀内，则成功；否则，我们成功。 否则，图在到达之前就已被分割。 

一个微妙的点是，我们没有显式模拟从 0 开始的可达性，因为 0 在概念上低于所有平台。 最小的平台总是属于初始可达区域，并且向上扩展。

 ## 边缘情况

 一个微妙的情况是当`h = 0`。 在这种情况下，只能连接相同的高度。 该算法可以正确处理此问题，因为任何按排序顺序严格递增的序列都会立即产生大于零的间隙，从而分裂组件。 如果最大值不等于最小值，则无法达到。 

另一种情况是当`n = 1`。 排序后的数组包含单个元素，因此不存在间隙，并且算法立即得出可达性结论，这与唯一平台通常可达的事实相匹配。 

当值环绕模数时，会出现进一步的边缘情况`p`。 即使序列是循环生成的，排序也消除了对换行结构的任何依赖。 连接性标准仅取决于排序后的线性距离，因此环绕不会影响正确性。
