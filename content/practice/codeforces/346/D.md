 ## 解决方案
 ## 问题理解

 我们得到一个有向图，表示机器人可以遍历的地图。 机器人从顶点 _s_ 开始，必须到达目标顶点 _t_。 它遵循三个定律：如果它重新访问顶点，它会自毁；如果它到达没有传出边的顶点，它会自毁；如果存在多个传出边，它会随机移动，除非明确告知要采用哪条边。 mzry1992可以在具有多个出边的顶点处提供特殊指令，以防止机器人随机移动。 

输入由顶点和边的数量、边列表以及起始顶点和目标顶点组成。 输出是必须沿机器人路径发出的最小指令数，以保证在最坏的情况下安全到达_t_，如果不存在路径则为 -1。 

约束最多允许 10^6 个顶点和边。 这排除了时间复杂度高于 O(n + m) 的算法。 显式探索每条路径的朴素 DFS 会太慢，因为在最坏的情况下它会尝试指数路径，尤其是在具有许多循环或分支点的图中。 

当具有多个出边的顶点位于循环上时，会出现微妙的边缘情况。 如果我们不能在那里给出指令，机器人可能会无限循环，永远无法到达目标。 例如，像 1 → 2 → 1 这样的循环，只有通过顶点 2 才能到达目标 3，需要顶点 1 处的指令以避免随机循环。 粗心的 DFS 只计算一条路径上的分支点可能会低估指令的数量，从而产生不正确的输出。 

另一种边缘情况是当目标顶点具有出边时。 机器人停在目标处，因此我们永远不需要在那里发出指令，即使它有多个传出边缘。 同样，不在任何到达目标的路径上的死胡同顶点也是无关紧要的； 我们必须只关注可到达目标的顶点。 

## 方法

 暴力方法是模拟机器人可能采取的每一条可能的路径，在机器人到达分支顶点时计算指令。 这是可行的，因为每个分支顶点可能需要一条指令，但模拟必须考虑循环并避免无限递归。 即使使用记忆化，具有 10^6 个节点的图中的路径数量也可能是指数级的，使得这种方法不可行。 

关键的见解是我们不需要详细模拟路径。 相反，我们可以将问题视为图上的动态规划问题。 我们定义一个值`dp[v]`作为从顶点安全到达目标所需的最少指令数`v`。 如果一个顶点没有出边并且不是目标，则不可能到达目标，所以`dp[v] = inf`。 对于只有一个出边的顶点，我们只需从该边传播值而不添加指令。 对于具有多个出边的顶点，我们必须考虑最坏的情况，即机器人可以采用任何出边。 因此，这样一个顶点的值是 1（对于指令）加上最大值`dp`其邻居的价值观。 

这将问题简化为计算`dp[v]`对于从目标可到达的所有顶点，使用反向图的后序遍历。 未连接到目标的循环中的顶点将被忽略，并且从目标可到达的循环中的顶点将通过沿反转图边缘传播最大值来正确处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(分支^路径) | O(n + m) | 太慢了 |
 | 图上的 DP / 反向拓扑 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 构造图的邻接表以及从目标开始遍历的逆邻接表。 我们将从目标开始向后计算最小指令。 
2. 初始化一个`dp`大小数组`n + 1`， 环境`dp[t] = 0`因为机器人已经到达目标，所以不需要任何指令。 将其他顶点设置为未计算值的占位符，例如 -1。 
3. 定义递归函数`solve(v)`计算`dp[v]`如果它是未计算的。 该函数首先检查顶点是否`v`没有传出边缘。 如果是这样并且`v`不是目标，标记`dp[v] = inf`因为机器人无法从这里到达目标。 
4.如果顶点`v`有一个出边`u`， 然后`dp[v] = solve(u)`。 不需要指令，因为机器人别无选择`v`。 
5.如果顶点`v`有多个出边，递归计算`dp[u]`为所有邻居`u`并设置`dp[v] = 1 + max(dp[u])`。 这`1`说明防止随机移动所需的指令`v`，以及`max`确保我们处理最坏情况的分支。 
6. 通过在递归期间将顶点标记为“当前处理”来安全地处理循环。 如果我们在当前递归中重新访问一个顶点，我们就检测到了一个循环，并且我们不需要做任何特殊的事情，因为在计算出目标的所有可到达节点后，最大传播最终将解决。 
7. 最后，计算`solve(s)`。 如果结果是`inf`，打印-1，因为机器人无法到达目标。 否则，打印计算值。 

不变量是计算后`dp[v]`，它表示到达目标所需的最少指令数`v`在最坏的情况下，假设所有后续分支顶点都有最优指令。 传播最大值可确保我们考虑最坏情况的随机运动，而无需显式模拟每条路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)

s, t = map(int, input().split())

dp = [-1] * (n + 1)
processing = [False] * (n + 1)

INF = n + 1

def solve(v):
    if dp[v] != -1:
        return dp[v]
    if processing[v]:
        return INF
    processing[v] = True
    if v == t:
        dp[v] = 0
    elif not adj[v]:
        dp[v] = INF
    elif len(adj[v]) == 1:
        dp[v] = solve(adj[v][0])
    else:
        dp[v] = 1 + max(solve(u) for u in adj[v])
    processing[v] = False
    return dp[v]

res = solve(s)
print(-1 if res >= INF else res)
```邻接表存储用于快速邻居迭代的边。 这`processing`数组检测循环以防止无限递归。`INF`代表不可达节点。 递归`solve`函数完全按照概述实现 DP。 在不添加指令的情况下处理单边缘节点至关重要。 多边缘节点添加一条指令并传播邻居的最大 DP，覆盖最坏情况的分支场景。
