 ## 解决方案
 ## 问题理解

 我们有一个无向图。 每个顶点必须被分配`0`或者`1`。 

对于每条边，我们写下其两个端点上的值之和。 由于端点是二进制的，因此每条边都会接收三个可能值之一：

 -`0`如果两个端点都是`0`-`1`如果端点不同
 -`2`如果两个端点都是`1`我们必须计算有多少顶点分配同时产生所有三个边值。 换句话说，在所有边中必须至少存在一条标记为`0`，至少一条边被标记为`1`，并且至少一条边标记为`2`。 

该图最多包含 40 个顶点。 与许多图形问题相比，这个数字很小，但对于枚举所有作业来说却太大了。 有`2^40 ≈ 10^12`可能的二进制标签，这是完全不可行的。 

该图也可以断开连接。 事实证明，这是关键困难之一，因为当存在多个组件时，某些在连通图中不可能的分配变得可能。 

一些边缘情况很容易被忽略。 

考虑一个没有边的图：```
3 0
```没有边缘可以接收标签`0`,`1`， 或者`2`，所以答案是`0`。 

考虑单边：```
2 1
1 2
```可能的边缘标签是`0`,`1`， 或者`2`，但绝不会同时三个。 答案又是`0`。 

另一个微妙的情况是断开连接的图：```
4 2
1 2
3 4
```一项作业可能会使一个组件完全`0`另一个完全`1`。 此类分配包含边缘标签`0`和`2`但没有标记边缘`1`。 仅对边缘进行局部推理的计数方法很容易对这些配置进行过度计数。 

最重要的特殊结构是二分性。 在连接的二分组件中，每个分配仅产生边缘标签`1`必须与两种二分颜色之一完全对应。 这一事实推动了很大一部分计数。 

## 方法

 暴力解决方案会尝试每个顶点分配。 对于每个`2^n`分配时我们检查所有边并检查边标签是否`0`,`1`， 和`2`全部出现。 

这是正确的，因为每个作业都经过显式测试。 

不幸的是，当`n = 40`，我们大约需要$$2^{40} \approx 1.1 \times 10^{12}$$作业。 即使忽略边缘处理，这也是无望的。 

关键的观察结果是，直接计算有效分配是很困难的，但计算无效分配的结构却令人惊讶。 

让$$T = 2^n$$是作业总数。 

如果至少有一个边缘标签，则分配无效`{0,1,2}`失踪了。 

这自然意味着包含-排除。 

定义：

-`A0`：没有边缘标记的作业`0`-`A1`：没有边缘标记的作业`1`-`A2`：没有边缘标记的作业`2`那么答案就是$$T-|A_0\cup A_1\cup A_2|.$$挑战在于计算所有包含-排除项。 

图形结构使这些计数易于管理。 

如果没有边缘标记`0`，则没有边可以连接指定的两个顶点`0`。 因此，零值顶点集必须是独立集。 

同样，没有边缘标记的作业`2`完全对应于选择分配的独立顶点集`1`。 

因此两者`|A0|`和`|A2|`等于图的独立组数。 

为了`n ≤ 40`，可以通过中间相遇来计算独立集。 这是主要的算法组件。 

其余的包含-排除项要容易得多，可以使用连接组件和二分组件来表达。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n·m) | O(2^n·m) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(2^(n/2) · n) | O(2^(n/2) · n) | O(2^(n/2)) | O(2^(n/2)) | 已接受 |

 ## 算法演练

 ### 包含-排除设置

 让：

 -`I`= 独立组数
 -`cc`= 连接组件的数量
 -`bip`= 连接的二分组件的数量

 我们从所有作业开始：$$2^n.$$我们减去至少缺少一个边缘标签的分配，然后根据包含-排除添加回交集。 

### 计数`A0`和`A2`

`A0`由没有标记边缘的作业组成`0`。 

每个顶点都分配了`0`必须形成一个独立的集合。 

选择零顶点完全决定了分配。 

因此$$|A_0| = I.$$根据对称性，$$|A_2| = I.$$### 计数`A1`一条边接收标签`1`正是当它的端点不同时。 

如果没有边缘标记`1`，每条边连接相等的值。 

在每个连接的组件内，所有顶点必须具有相同的值。 

每个连接组件独立选择`0`或者`1`。 

所以$$|A_1| = 2^{cc}.$$### 计数`A0 ∩ A1`没有边缘可以有标签`0`或者`1`。 

因此，每条边都必须有标签`2`。 

在每个连接的组件内，所有顶点都必须是`1`。 

每个孤立的顶点仍然可以自由选择。 

这个计数等于$$2^{iso},$$在哪里`iso`是孤立顶点的数量。 

出现相同的值`A1 ∩ A2`。 

### 计数`A0 ∩ A2`没有边缘可以有标签`0`或者`2`。 

每条边都必须有标签`1`。 

每条边的端点必须具有相反的值。 

因此，每个连接的组件必须是二分的。 

连接的二分组件恰好有两种有效的颜色。 

非二分组件的贡献为零。 

如果任何非隔离组件不是二分组件，则计数为零。 

否则，$$|A_0 \cap A_2| = 2^{bip}.$$### 计数`A0 ∩ A1 ∩ A2`任何边都不能有任何标签。 

仅当图没有边时这才有可能。 

对于包含-排除来说，很简单$$2^{iso}.$$### 独立集合计数

 剩下的困难部分是计算`I`。 

将顶点分成两半：$$L,\ R$$尺寸最多为 20。 

对于左半部分的每个子集，检查它是否是独立的。 

存储一个位掩码，描述仍可以选择哪些右半顶点。 

对于右半部分的每个独立子集，计算存在多少个兼容的左子集。 

这是标准的中间相遇独立集计数技术。 

兼容性计数是通过右半掩码上的子集 zeta 变换来累积的。 

### 算法演练

 1. 读取图形并构建邻接位掩码。 
2. 计算连通分量、孤立顶点以及每个分量是否是二分的。 
3. 使用中间相遇计算所有独立集。 
4.让`ans = 2^n`。 
5. 减法`|A0|`和`|A2|`, 给予`ans -= 2 * I`。 
6. 减法`|A1| = 2^cc`。 
7.添加回来`|A0 ∩ A1|`和`|A1 ∩ A2|`，每一个都等于`2^iso`。 
8. 添加`|A0 ∩ A2|`。 如果每个非隔离组件都是二分的，则这等于`2^bip`; 否则为零。 
9. 减去三重交集`2^iso`。 
10. 输出结果值。 

为什么它有效：

 包含-排除公式是精确的，因为每个无效赋值至少属于以下之一：`A0`,`A1`， 或者`A2`。 公式中的每一项都是根据缺失边标签所施加的结构约束进行计数的。 中间相遇过程精确计算独立集的数量，所有剩余数量都来自组件级图属性。 由于每个包含-排除项都是正确的，因此最终计数是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    adj = [0] * n
    g = [[] for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1

        adj[u] |= 1 << v
        adj[v] |= 1 << u

        g[u].append(v)
        g[v].append(u)

    vis = [False] * n
    cc = 0
    iso = 0
    bip = 0
    all_bip = True

    from collections import deque

    for s in range(n):
        if vis[s]:
            continue

        cc += 1

        if not g[s]:
            iso += 1
            bip += 1
            vis[s] = True
            continue

        q = deque([s])
        vis[s] = True
        color = {s: 0}
        ok = True

        while q:
            v = q.popleft()

            for to in g[v]:
                if to not in color:
                    color[to] = color[v] ^ 1
                    vis[to] = True
                    q.append(to)
                elif color[to] == color[v]:
                    ok = False

        if ok:
            bip += 1
        else:
            all_bip = False

    n1 = n // 2
    n2 = n - n1

    left_adj = [0] * n1
    right_adj = [0] * n2
    cross = [0] * n1

    for i in range(n1):
        mask_l = 0
        mask_r = 0

        for j in range(n1):
            if adj[i] >> j & 1:
                mask_l |= 1 << j

        for j in range(n2):
            if adj[i] >> (n1 + j) & 1:
                mask_r |= 1 << j

        left_adj[i] = mask_l
        cross[i] = mask_r

    for i in range(n2):
        mask = 0
        v = n1 + i

        for j in range(n2):
            if adj[v] >> (n1 + j) & 1:
                mask |= 1 << j

        right_adj[i] = mask

    size_r = 1 << n2

    indep_r = [0] * size_r
    indep_r[0] = 1

    for mask in range(1, size_r):
        b = mask & -mask
        v = b.bit_length() - 1
        prev = mask ^ b

        if indep_r[prev] and (right_adj[v] & prev) == 0:
            indep_r[mask] = 1

    f = [0] * size_r

    for mask in range(1 << n1):
        ok = True
        allowed = (1 << n2) - 1

        cur = mask
        while cur:
            b = cur & -cur
            v = b.bit_length() - 1

            if left_adj[v] & (mask ^ b):
                ok = False
                break

            allowed &= ~cross[v]
            cur ^= b

        if ok:
            f[allowed] += 1

    for bit in range(n2):
        for mask in range(size_r):
            if mask & (1 << bit):
                f[mask] += f[mask ^ (1 << bit)]

    independent_sets = 0

    for mask in range(size_r):
        if indep_r[mask]:
            independent_sets += f[mask]

    ans = 1 << n

    ans -= independent_sets
    ans -= independent_sets
    ans -= 1 << cc

    ans += 1 << iso
    ans += 1 << iso

    if all_bip:
        ans += 1 << bip

    ans -= 1 << iso

    print(ans)

solve()
```将图分成两半后，代码独立枚举所有左半子集和所有右半子集。 由于每一半最多包含 20 个顶点，因此最大的子集空间约为 100 万个状态，这是可以管理的。 

数组`f`存储有多少个独立的左子集允许一组特定的右顶点。 子集 zeta 变换将此信息转换为每个独立右子集的兼容性计数。 

一个常见的错误是错误地处理包含-排除项中的孤立顶点。 孤立的顶点永远不会创建边标签，因此它们的行为与普通的二分组件不同。 该公式使用`iso`正是出于这个原因分开。 

另一个容易的错误是忘记了`A0 ∩ A2`要求每条边都有标签`1`。 包含非二分连通分量的图向该交集贡献零分配。

 ## 边缘情况

 考虑：```
3 0
```每个顶点都是孤立的。 该算法计算`cc = iso = bip = 3`。 独立集计数为`2^3 = 8`。 包含-排除取消一切并产生`0`。 由于不存在边缘，因此获取标签`0`,`1`， 和`2`是不可能的。 

考虑：```
2 1
1 2
```有四项任务。 只能标记单边`0`,`1`， 或者`2`取决于任务。 没有作业可以同时创建所有三个标签。 包含-排除公式正确地计算为零。 

考虑：```
3 3
1 2
2 3
1 3
```该图是一个三角形。 BFS着色时，会出现奇偶校验冲突，所以`all_bip = False`。 结果，`A0 ∩ A2`贡献变为零。 这是正确的，因为使每条边都等于`1`需要适当的二元着色，而三角形则没有。 

考虑：```
4 2
1 2
3 4
```该图有两个不相连的组件。`A1`被算作`2^cc = 4`因为每个组件独立地选择一个统一的值。 将图视为已连接的图会错误地仅计算两个此类分配。 基于组件的计数避免了这种错误。
