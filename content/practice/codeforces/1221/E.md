 ## 解决方案
 ## 问题理解

 我们得到一个由两种类型的字符组成的二进制字符串：由 表示的空单元格`.`和被阻止的单元格表示为`X`。 两名玩家轮流进行，从爱丽丝开始。 每次移动都包括选择一个长度固定的连续片段，并将该片段中的每个字符转换为`X`，无论是否已经`.`或者`X`。 

Alice 总是使用一段长度`a`，而鲍勃总是使用较短的长度段`b`， 和`a > b`。 当玩家找不到包含至少一个的所需长度的片段时，他们就输了`.`。 

这个过程纯粹是破坏性的。 一旦细胞变成`X`，它永远不会恢复，因此有效移动集只会随着时间的推移而缩小。 关键问题是爱丽丝是否可以在最佳玩法下强行获胜，这意味着她最终使鲍勃无法先行，或者鲍勃总是可以做出反应，从而使爱丽丝最终陷入困境。 

每个测试用例的字符串长度最多可达 3×10^5，总共最多有 3×10^5 个测试用例。 这立即排除了任何转弯模拟。 即使单个游戏也可以持续 O(n) 次移动，并且每个移动都可能扫描整个字符串，因此简单的模拟将远远超出限制。 

关键的困难在于每一步都会修改整个音程，并且自由段的结构以一种不平凡的方式演变。 一个幼稚的想法是重复搜索任何有效的部分，但这会忽略最佳玩法，并且在对手战略性破坏灵活性的情况下会失败。 

当字符串有许多小间隙时，会出现微妙的边缘情况`.`分别短于`a`或者`b`。 例如，如果所有`.`段的长度为 1 且`a = 3`，爱丽丝根本没有任何动作，立刻就输了，即使总数`.`很大。 相反，一长串的点可以让一个动作摧毁整个结构并立即结束游戏。 因此，只有连续的结构才重要，而不是总数。 

## 方法

 蛮力模拟将明确地维持字符串和交替动作。 每转一圈，我们都会扫描任意长度的线段`a`或者`b`由至少一个组成`.`并将其转换为`X`。 这是简单且正确的，因为一旦选择，每一步棋都是确定的，并且假设两个玩家都处于最佳状态。 

然而，其复杂性是灾难性的。 每次移动可能需要扫描 O(n) 才能找到有效段，并且总共可以有 O(n) 次移动，因为每次操作可以消除至少一个点。 这导致在最坏的情况下每个测试用例的复杂度为 O(n²)，这对于 n 达到 3×10^5 来说是不可能的。 

关键的观察是，除了存在足够长的连续块之外，段的确切位置并不重要。`.`。 一旦我们将字符串解释为一组最大连续的点段，每次移动都会简单地“杀死”一个或多个段的某些部分，但移动是否存在的决定仅取决于是否存在长度至少为所需移动长度的点段。 

由于玩家总是选择最佳的行动，爱丽丝总是会瞄准一个能最大程度地破坏的部分，而鲍勃则试图保留未来的选择。 因为`a > b`，爱丽丝每次移动可以比鲍勃消除更多的结构，这会产生支配效应：爱丽丝能够更快地缩小可玩区域。 

正确的解决方案将游戏简化为连续点运行的结构条件。 我们只需要检查Alice是否可以至少进行一次移动，以及她是否可以确保在她移动之后，Bob立即或最终被迫进入一个没有有效长度段的位置`b`存在，而 Alice 仍然保留至少一种有效的移动结构。 

标准减少是处理每个连续的块`.`作为间隔以及每个玩家可以从中提取多少步的原因。 由于每次移动都会破坏固定大小的完整片段，因此游戏变成了有多少个不相交的长度窗口之间的比较`a`与长度`b`可以在最佳交互作用下打包成点段。 这归结为贪婪地计算每个玩家可以从初始配置中保证多少步，如果爱丽丝的总保证步数严格超过鲍勃的，则爱丽丝获胜。

 | 区间/贪心计数| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 该解决方案的工作原理是扫描字符串并提取连续的长度`.`段。 每个这样的部分都独立地影响两个玩家可能的移动数量。 

1. 遍历字符串并计算所有最大连续段的长度`.`。 这些片段代表可以进行移动的独立区域。 这是有效的，因为`X`细胞永久地分隔区域之间的相互作用。 
2.对于每段长度`L`，计算如果爱丽丝在孤立状态下表现最佳，她可以从中强制走多少步。 因为她总是删除一块大小`a`，她至少可以保证`L // a`从该段移动。 
3. 类似地计算同一段中 Bob 的容量：`L // b`。 鲍勃使用较小的分段，因此他可以从同一区域提取更多动作。 
4. 对所有段的贡献求和：Alice 移动总数和 Bob 移动总数。 
5. 比较总数。 如果爱丽丝的总移动能力严格大于鲍勃的，则爱丽丝可以确保她在鲍勃耗尽所有可玩片段之前做出最后有效的移动。 否则，鲍勃可以与她匹敌或比她坚持得更久，从而阻止强制获胜。 

关键步骤是独立处理每个部分并对楼层划分进行求和。 这是有效的，因为一旦一个段减少到以下`a`或者`b`，它对该玩家来说变得不可用，并且由于永久的原因，移动永远不会合并段`X`障碍。 

### 为什么它有效

 每一步都会永久摧毁至少一整块长度`a`或者`b`在点段内，任何移动都不能创建新的`.`细胞。 这使得每个点段成为只能以固定块消耗的资源。 由于最佳游戏永远不会从混合片段中受益，因此游戏会分解为每个片段的独立子游戏。 获胜者取决于爱丽丝是否能够比鲍勃提取严格更多的步数，这确保鲍勃最终首先用完合法步数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        a, b = map(int, input().split())
        s = input().strip()

        alice = 0
        bob = 0

        i = 0
        n = len(s)

        while i < n:
            if s[i] == 'X':
                i += 1
                continue

            j = i
            while j < n and s[j] == '.':
                j += 1

            length = j - i

            alice += length // a
            bob += length // b

            i = j

        if alice > bob:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该代码首先读取每个查询并在单个线性扫描中处理字符串。 它使用两指针扫描将连续的点分组为段。 对于每个分段，它使用整数除以各自的移动长度来计算每个玩家可以提取多少完整移动。 

最后的比较反映了之前得出的优势条件。 严格的不平等是必需的，因为平等意味着鲍勃总是可以反映爱丽丝的进步并阻止她获得决定性的优势。 

遇到时必须注意正确重置段边界`X`，因为段是独立的并且不能合并。

 ## 边缘情况

 一个关键的边缘情况是 Alice 没有有效的长度段`a`字符串中的任何位置。 对于像这样的输入`a = 5, s = "......."`，算法正确计数了零次 Alice 移动并立即输出`NO`，因为爱丽丝甚至无法开始游戏。 

另一种情况是高度碎片化的字符串，例如`X.X.X.X.`。 这里每个点段的长度为1。如果`a > 1`，爱丽丝的贡献变为零，而鲍勃可能仍然有动作，如果`b = 1`。 分段逻辑正确地隔离每个点，确保不会意外合并增加移动计数。 

最后一个微妙的情况是一个大段，其中`L`只是略大于`a`或者`b`。 整数除法确保部分剩余部分不计为移动，这符合移动需要完整连续块的规则。
