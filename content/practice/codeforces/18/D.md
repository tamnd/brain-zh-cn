 ## 解决方案
 ## 问题理解

 鲍勃每天经历一件事。 一天要么是奖励日，要么是客户日。 

在颁奖日，鲍勃收到了一个大小的记忆棒$2^x$。 他可以保留它，也可以立即放弃它。 他从来不被允许同时存放超过一根棍子。 

在客户日，有人想买一根尺寸的棍子$2^x$。 如果鲍勃当前拥有那根棍子，他会卖掉它并赚取收入$2^x$贝拉尔斯。 否则客户就会离开，机会就永远消失了。 

输入只是这些事件的序列。 对于每个有奖活动，我们必须决定鲍勃是保留棍子还是丢弃它，以便使总收入最大化。 

约束条件$n \le 5000$对于二次动态规划足够小，但对于指数搜索来说太大。 尝试所有选择的蛮力需要考虑最多$2^{5000}$状态，这是不可能的。 三次解是有风险的，因为$5000^3 = 1.25 \times 10^{11}$操作已经远远超出了极限。 二次解很舒服，大约$2.5 \times 10^7$最坏情况下的操作。 

棘手的是鲍勃只能拿着一根棍子。 一个对当地有吸引力的决定可能会破坏未来更有利可图的销售。 

考虑这个例子：```
4
win 1
win 10
sell 1
sell 10
```总是保留最新棍子的贪婪策略最终会带来利润$2^{10} = 1024$，因为 1 号棒在顾客到达之前就被丢弃了。 

最佳玩法不同：

 保留 1 号，出售，然后保留 10 号，也出售，总计$2 + 1024 = 1026$。 

另一个微妙的情况是当匹配的客户已经通过后奖品才到达。```
3
sell 5
win 5
sell 5
```只有第二个顾客才能满意。 粗心的预处理步骤将每次获胜与相同规模的每次销售相匹配，这会导致计算过多。 

重叠区间之间也存在重要的相互作用。```
6
win 1
win 2
sell 1
sell 2
win 1
sell 1
```第一个 1 号棒和第 2 号棒不能同时保留，因为它们的活动间隔重叠。 该算法必须明确地模拟这种冲突。 

## 方法

 最直接的蛮力就是一天一天地处理，并尝试每一个可能的决定。`win`事件。 每当鲍勃收到一根棍子时，我们就会分为两种可能性：保留它或丢弃它。 如果他已经拥有另一根棍子，我们也可能决定更换当前的棍子。 

这种搜索是正确的，因为它探索了每一个合法的行动序列。 问题在于州的数量。 在最坏的情况下，有 5000 个有奖活动，大约产生$2^{5000}$的可能性。 即使积极的修剪也无法挽救这种方法。 

关键的观察是，有利可图的销售行为就像一个区间。 

假设有一根大小为$x$当天获胜$l$，当天出现相应的客户$r$。 如果鲍勃想从这根棍子上赚钱，那么从一天开始$l$直到有一天$r$他必须为这根棍子保留唯一的存储空间。 在整个间歇期间，他无法保留任何其他棍子。 

这将问题转化为间隔调度问题。 

每个盈利机会变成：

 间隔一段时间$[l, r]$有价值$2^x$。 

如果两个区间不重叠，则它们是兼容的。 目标是选择一组不重叠间隔的最大值。 

现在结构变得简单多了。 对于每一个`sell x`，最多有一个顾客。 我们可以向后扫描并将该客户与之前的每个客户配对`win x`。 每对这样的对形成一个区间候选。 

一旦我们有了所有间隔，问题就变成了加权间隔调度，一个经典的动态规划问题。 

我们按结束日期对间隔进行排序。 对于每个间隔，我们都会找到在该间隔开始之前完成的最后一个间隔。 然后：$$dp[i] = \max(dp[i-1], dp[p(i)] + value_i)$$这将问题从指数搜索简化为二次预处理加线性DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 将所有事件读入数组。 

对于每一天，存储是否`win`或者`sell`，以及相关的指数$x$。 
2. 对于每一个`sell x`一天，向后扫描并找到所有更早的`win x`天。 

每对这样的组合都构成一个有效的机会：

 如果鲍勃从获胜日一直持有棍子到卖出日，他就会赚到$2^x$。 

间隔为：$$[win\_day, sell\_day]$$有利润：$$2^x$$3. 将所有间隔存储在列表中。 

每个区间包含：

 开始日，

 结束日，

 利润。 
4. 按结束日期对间隔进行排序。 

加权间隔调度依赖于递增完成顺序的处理间隔。 
5. 对于每个间隔$i$, 计算$p(i)$。$p(i)$是一个区间的最大索引，其结束日严格在区间之前$i$的开始日。 

这些正是可以与区间共存的区间$i$。 
6. 运行动态规划。 

让`dp[i]`是使用第一个的最大利润`i`按排序顺序排列的间隔。 

过渡：

 要么跳过间隔$i$,

 或将其与最佳兼容解决方案一起使用。 

正式：$$dp[i] = \max(dp[i-1], dp[p(i)] + value_i)$$7. 输出最终的DP值。 

这是可实现的最大利润。 

### 为什么它有效

 每个有利可图的操作都对应于在连续时间间隔内保留 Bob 的单个存储槽。 当两个有利可图的行动的时间间隔不重叠时，它们同时可能发生。 

变换是精确的：

 每个有效的策略都会产生一组不重叠的区间，

 每组不重叠的区间都描述了一个有效的策略。 

动态规划是加权区间调度的标准最优子结构。 当考虑间隔时$i$，任何最优解要么排除它，要么包含它。 如果包含区间$i$，所有剩余的选定间隔必须来自以结尾的兼容前缀$p(i)$。 由于这是仅有的两种可能性，递归总是计算出真正的最优值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    typ = []
    val = []

    for _ in range(n):
        t, x = input().split()
        typ.append(t)
        val.append(int(x))

    intervals = []

    for r in range(n):
        if typ[r] == "sell":
            x = val[r]

            for l in range(r):
                if typ[l] == "win" and val[l] == x:
                    intervals.append((l, r, 1 << x))

    intervals.sort(key=lambda item: item[1])

    m = len(intervals)

    ends = [0] * m
    starts = [0] * m
    profits = [0] * m

    for i in range(m):
        starts[i] = intervals[i][0]
        ends[i] = intervals[i][1]
        profits[i] = intervals[i][2]

    p = [-1] * m

    for i in range(m):
        best = -1

        for j in range(i - 1, -1, -1):
            if ends[j] < starts[i]:
                best = j
                break

        p[i] = best

    dp = [0] * (m + 1)

    for i in range(1, m + 1):
        skip = dp[i - 1]

        take = profits[i - 1]
        if p[i - 1] != -1:
            take += dp[p[i - 1] + 1]

        dp[i] = max(skip, take)

    print(dp[m])

solve()
```第一阶段构建所有可能的盈利区间。 如果一个`win x`发生在`sell x`，鲍勃有可能在整个间歇期保留那根棍子并完成销售。 

区间列表是核心建模步骤。 一旦完成这种转变，关于记忆棒的原始故事就会消失，只有间隔兼容性才重要。 

排序顺序很重要。 DP 假定所有兼容的较早间隔出现在当前间隔之前。 按结束时间排序可以保证此属性。 

的计算`p[i]`向后搜索最新的兼容间隔。 由于区间数最多为$O(n^2)$，二次预处理通道足够快。 

为了方便起见，DP 数组使用从 1 开始的索引。 间隔`i - 1`对应DP状态`i`。 这可以避免访问空前缀时出现负索引。 

严格比较：```
ends[j] < starts[i]
```是必不可少的。 如果一个间隔在另一个间隔开始的同一天结束，它们仍然重叠，因为鲍勃不能在同一天的序列中既出售一根棍子又拥有另一根棍子。 

利润用途：```
1 << x
```因为已售出的棍子的价值是$2^x$。 

Python 整数安全地处理自以来的最大值$2^{2000}$很容易适合任意精度的整数。
