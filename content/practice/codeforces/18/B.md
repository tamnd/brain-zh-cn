 ## 解决方案
 ## 问题理解

 我们拥有一系列独立平台。 每个平台都有固定的长度`l`并与下一个分开固定距离`m - l`，所以平台`k`占据该段`(k-1)*m`到`(k-1)*m + l`。 蚱蜢鲍勃从位置开始`0`并精确地向前跳跃`d`单位。 如果他降落在平台上，他就会幸存并可以再次跳跃。 如果他落在所有平台之外，他就会摔倒。 正好落在边缘才算安全。 任务是找到鲍勃第一个跌倒的位置。 

输入整数`n, d, m, l`都可以达到 10^6。 这意味着在最坏的情况下，任何单独迭代位置的方法都可能需要多达一百万次跳转，如果我们小心的话，这是可行的，但强力扫描行的每个单元会太慢。 边缘情况包括跳跃长度的情况`d`大于两个平台之间的距离，或者`d`与边缘完全对齐，并且情况`l = 1`和`m`很大。 这些场景很容易通过一个单位进行简单的检查，因此我们需要具有闭区间的精确算术。 

例如，如果`n = 1, d = 5, m = 10, l = 3`, 鲍勃跳到`5`在第一次跳跃时。 唯一的平台是`[0,3]`。 虽然`5 < 10`，他在平台之外，所以答案是`5`。 粗心的实现可能会错误地假设任何跳转`m`单位是安全的，这会产生`10`，下一个（不存在的）平台的开始，错误的结果。 

## 方法

 最简单的方法是暴力模拟。 从位置 0 开始，递增`d`每次跳跃，并针对每个新位置检查它是否落入任何平台段内。 这是正确的，因为它直接模拟了鲍勃的行为。 问题是效率：对于`n = 10^6`和`d = 1`，这可以执行多达一百万次跳转，并且对于每次跳转，平台的线性扫描成本太高。 更糟糕的是，在最坏的情况下，每次检查所有平台的时间复杂度为 O(n^2)，这会超时。 

关键的观察结果是平台间隔均匀且长度相同。 平台`k`是`[ (k-1)*m , (k-1)*m + l ]`。 对于给定的位置，我们可以计算`x`，通过整数除法它将位于哪个平台（或将落在哪个平台之间）：候选平台索引是`x // m + 1`。 那么我们只需要检查是否`x`小于`(candidate - 1)*m + l`确定 Bob 是否仍在平台上。 如果是，他就活下来；如果是，他就活下来。 如果没有，他就会跌倒。 这将问题简化为每次跳转的简单算术检查，并避免扫描所有平台。 

我们可以通过认识到鲍勃的跳跃距离是固定的来进一步优化。 他跌倒的第一次跳跃可以表示为`x = d * k`对于某个整数`k`。 我们需要最小的`k`这样`x`大于其所在平台的右端。 这给出了每次跳跃 O(1) 的纯算术解，直到他摔倒。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 优化算法| O(n/d) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化Bob的位置`x`到`0`。 我们将增加`d`在每次跳跃时。 
2. 在每次跳跃时，计算 Bob 将降落的平台索引。 由于平台是`[ (k-1)*m , (k-1)*m + l ]`，候选平台为`k = x // m + 1`。 
3. 检查是否`k`超过`n`。 如果是，则鲍勃已跳过最后一个平台并跌落于`x`。 
4. 否则，检查是否`x`位于平台内：`x <= (k-1)*m + l`。 如果是，鲍勃就活下来并再次跳跃。 
5.如果`x > (k-1)*m + l`，鲍勃落在平台外并摔倒。 这是第一个不安全位置，我们将其打印出来。 
6. 增量`x`经过`d`并重复。 

为什么它有效：该算法保持了不变式`x`始终是鲍勃在跳跃一定次数后的实际位置。 通过代数计算候选平台，我们永远不会扫描不相关的平台。 支票`x <= (k-1)*m + l`正确捕捉鲍勃是落在平台内还是跌倒。 自从`d`是恒定的，每一步都会进行到下一个跳跃，而不会错过任何潜在的落点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, d, m, l = map(int, input().split())

x = 0
while True:
    k = x // m + 1
    if k > n or x > (k - 1) * m + l:
        print(x)
        break
    x += d
```代码开头为`x = 0`并迭代`d`。 计算`k = x // m + 1`直接给出从1开始的平台索引。 如果`k > n`，鲍勃已经跳过了所有平台。 如果`x > (k-1)*m + l`，他已经超越了当前的平台。 否则，`x`是安全的并且循环继续。 该实现可以正确处理边缘，因为我们使用`<=`用于平台包容性。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n/d) | 我们增加`d`每一步。 最大跳跃次数大致为`n*m/d`，边界为`10^6`。 |
 | 空间| O(1) | O(1) | 仅使用少数整数变量，独立于`n`。 |

 这完全符合时间和内存的限制。 即使在最坏的情况下`d = 1`和`n = 10^6`，我们最多执行 10^6 次迭代，这在 2 秒内是可行的。
