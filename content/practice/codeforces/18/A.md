 ## 解决方案
 ## 问题理解

 我们在平面上给出了三个具有整数坐标的点。 这三个点已经形成一个有效的三角形，这意味着它们不共线。 

任务是将三角形分为三个类别之一。 

三角形是`RIGHT`如果其中一个角恰好是 90 度。 

三角形是`ALMOST`如果它当前不是直角，但在四个基本方向之一上精确移动一个顶点一个单位就会使其成为直角。 移动的点仍必须具有整数坐标。 

如果两个条件都不成立，我们打印`NEITHER`。 

坐标很小，仅在`-100`和`100`。 这完全改变了问题的性质。 我们不需要高级几何、浮点运算或优化技巧。 即使尝试许多候选配置也是很便宜的，因为可能性的总数很小。 

几何问题中最大的危险是精度。 粗心的实现可能会使用三角函数计算角度并将浮点值与`90`。 这是脆弱的，因为浮点舍入可以将精确的直角变成类似的东西`89.999999`。 

例如：```
0 0 3 0 0 4
```这显然是一个直角三角形，但使用余弦公式进行浮点比较可能会引入微小的错误。 

安全的方法是完全使用平方距离和整数算术。 

检查时出现另一个微妙的情况`ALMOST`健康）状况。 我们只能精确地移动一个点的距离`1`沿着网格。 不允许对角移动。 

例如：```
0 0 1 2 2 1
```对角移动一个点可以创建一个直角三角形，但对角移动具有欧几里德距离`sqrt(2)`， 不是`1`。 这里的正确答案不是基于对角线移动。 

另一个实现错误是在搜索之前忘记拒绝原始三角形`ALMOST`。 

例子：```
0 0 2 0 0 1
```这已经是直角了。 即使移动点也可能产生另一个直角三角形，正确的输出仍然必须是`RIGHT`。 

## 方法

 解决问题最直接的方法就是检查当前三角形是否是直角。 如果不是，我们会尝试每一个允许的动作并再次检查。 

如果三角形的边长满足毕达哥拉斯定理，则三角形是直角三角形。 由于坐标是整数，因此平方距离也是整数。 假设边长的平方是`a`,`b`， 和`c`。 对它们进行排序后，在以下情况下，三角形是直角：```
a + b = c
```这种蛮力策略已经足够快了。 每个点有四种可能的移动：```
(x+1,y), (x-1,y), (x,y+1), (x,y-1)
```共有三点，所以只`3 × 4 = 12`修改三角形进行测试。 

每个测试计算三个平方距离并执行恒定的工作。 即使时间限制大幅减少，这仍然会立即运行。 

关键的观察是，当我们避免实际距离时，具有整数坐标的几何图形通常会变得更简单。 平方距离保留了毕达哥拉斯定理所需的所有比较，同时完全消除了平方根。 

更简单的几何方法可能会计算向量和点积，甚至用三角函数计算角度。 这些方法在数学上是有效的，但它们在这里不必要地复杂。 问题结构足够小，详尽的检查与整数运算相结合可以提供更干净、更安全的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 浮点几何的暴力破解 | O(1) | O(1) | O(1) | O(1) | 已接受但容易出错 |
 | 整数平方距离检查 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读懂三点。 
2. 编写一个辅助函数来确定三个点是否形成直角三角形。 
3. 在该函数内，计算所有三边的平方长度。 

如果点是`A`,`B`， 和`C`，计算：```
AB², AC², BC²
```使用平方距离可以完全避免浮点运算。 

1. 对三个长度的平方进行排序。 

最大的边一定是直角三角形的斜边，所以排序后我们只需要检查是否：```
smallest + middle = largest
```1、首先检查原来的三角形。 

如果它已经满足毕达哥拉斯条件，则打印`RIGHT`。 

1. 否则，尝试在四个允许的方向上移动每个点。 

对于每个点，生成这些候选点：```
(x+1,y)
(x-1,y)
(x,y+1)
(x,y-1)
```暂时替换原来的点并测试新的三角形。 

1. 如果任何修改后的三角形变成直角，则打印`ALMOST`。 

一旦我们找到有效的举动，我们就可以停止搜索。 

1. 如果十二个动作都不起作用，则打印`NEITHER`。 

### 为什么它有效

 该算法检查语句允许的每个配置。 

当三角形的边长满足毕达哥拉斯定理时，它就是直角三角形。 平方距离完美地保留了此属性，因为：```
a² + b² = c²
```仅包含整数运算。 

对于`ALMOST`条件下，该语句只允许水平或垂直移动一个单位。 该算法显式枚举每个顶点的所有此类移动，因此不会错过任何有效的候选者。 

由于每个允许的修改都经过测试，并且每个测试在数学上都是精确的，因此该算法不会对三角形进行错误分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def dist2(x1, y1, x2, y2):
    return (x1 - x2) ** 2 + (y1 - y2) ** 2

def is_right(points):
    x1, y1 = points[0]
    x2, y2 = points[1]
    x3, y3 = points[2]

    sides = [
        dist2(x1, y1, x2, y2),
        dist2(x1, y1, x3, y3),
        dist2(x2, y2, x3, y3)
    ]

    sides.sort()

    return sides[0] > 0 and sides[0] + sides[1] == sides[2]

def solve():
    nums = list(map(int, input().split()))

    points = [
        [nums[0], nums[1]],
        [nums[2], nums[3]],
        [nums[4], nums[5]]
    ]

    if is_right(points):
        print("RIGHT")
        return

    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    for i in range(3):
        original_x, original_y = points[i]

        for dx, dy in directions:
            points[i] = [original_x + dx, original_y + dy]

            if is_right(points):
                print("ALMOST")
                return

        points[i] = [original_x, original_y]

    print("NEITHER")

solve()
```这`dist2`函数计算欧氏距离平方。 使用平方距离可以避免平方根并保持每次计算的准确性。 

这`is_right`功能是核心几何检查。 它计算三个平方边长，对它们进行排序，并验证毕达哥拉斯条件。 额外检查`sides[0] > 0`尽管保证原始输入是非退化的，但可以防止退化边缘。 

主要逻辑首先检查原始三角形。 这种顺序很重要，因为必须打印已经是直角的三角形`RIGHT`，即使移动一个点也可以创建另一个直角三角形。 

寻找`ALMOST`迭代所有十二个合法动作。 测试一个动作后，该点会在尝试下一个动作之前恢复。 忘记这个恢复步骤是错误的常见来源，因为后续迭代将从已经修改的坐标开始。 

一切都以整数运算运行，因此不存在精度问题。

 ## 边缘情况

 考虑三角形已经是直角的情况：```
0 0 2 0 0 1
```该算法首先调用`is_right`在原来的点上。 

平方边长为：```
1, 4, 5
```自从：```
1 + 4 = 5
```算法立即打印`RIGHT`并停止。 它永远不会进入`ALMOST`搜索。 这种排序是必要的，因为该语句优先考虑`RIGHT`超过`ALMOST`。 

现在考虑一种情况，对角线移动会有所帮助，但合法移动不会：```
0 0 1 2 2 1
```该算法检查原始三角形并发现没有毕达哥拉斯关系。 

然后它精确测试这十二个动作：```
(+1,0), (-1,0), (0,+1), (0,-1)
```对于每个顶点。 

没有经过测试的配置变成直角，因此算法打印`NEITHER`。 

这证实了仅考虑基本方向的移动，与问题定义完全匹配。 

最后，考虑负坐标：```
-1 -1 1 -1 -1 2
```平方边长变为：```
4, 9, 13
```排序后：```
4, 9, 13
```自从：```
4 + 9 = 13
```算法正确输出`RIGHT`。 

计算仅使用减法和平方，因此负坐标不需要特殊处理。
