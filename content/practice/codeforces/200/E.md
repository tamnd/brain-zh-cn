 ## 问题理解

 我们被要求根据学生的考试成绩向他们分配固定的奖学金预算。 每个学生的分数为3、4或5，分数相同的学生必须获得相同的奖学金。 令 _c3_、_c4_、_c5_ 为 3、4、5 年级学生的数量，并令 _k3_、_k4_、_k5_ 为各自的奖学金。 约束条件是奖学金是整数，非递减（_k3 ≤ k4 ≤ k5_），并且花费的总金额等于预算_s_。 此外，“最优”分配最大限度地减少了奖学金的特定功能，这归结为平衡奖学金之间的差异。 

输入给出学生人数 _n_ (3 ≤ n ≤ 300)、总预算 _s_ (1 ≤ s ≤ 3·10^5) 以及每个学生的分数。 输出应提供满足约束条件的任何奖学金分配，如果不存在此类分配，则为 -1。 

这个问题很微妙，因为小整数舍入可能会妨碍总预算的精确相等。 尝试分配比例份额的幼稚方法可能会默默地违反整数要求。 例如，如果 _c3 = 2_、_c4 = 1_、_c5 = 2_ 和 _s = 7_，简单地按比例划分预算可能会产生 2.8 卢布等无效分数。 探索整数解时必须小心。 

## 方法

 暴力方法将迭代满足 0 ≤ k3 ≤ k4 ≤ k5 的所有可能值 _k3_、_k4_、_k5_ 并检查总预算是否匹配。 由于每项奖学金最高可达 _s_，因此大约有 O(s^3) 种可能性。 对于 s 达到 3·10^5 来说，这太大了。 

关键的观察是，我们可以通过注意到一旦我们修复 _k3_ 和 _k5_，_k4_ 由总预算确定来减少搜索空间：```
k4 = (s - c3*k3 - c5*k5) / c4
```这必须是一个整数，满足 k3 ≤ k4 ≤ k5，并且完全满足预算。 这将问题简化为可能的 k3 和 k5 上的双循环，这是可行的，因为 n ≤ 300 且 s ≤ 3·10^5。 k3 和 k5 的范围可以进一步分别由下限（s / c3）和下限（s / c5）限制，以保持循环紧密。 

最后，对于每个候选者 (k3, k5)，我们检查以这种方式计算的 k4 是否有效。 当奖学金之间的差异尽可能小时，“最佳”函数就会最小化，因此从 0 向上迭代 k3 并从最小可行值开始迭代 k5 往往会产生最小的差异。

 | --- | --- | --- | --- |
 | 蛮力 | O(s³) | O(1) | O(1) | 太慢了 |
 | 双环（最佳）| O((s/c3)*(s/c5)) | O(1) | O(1) | 已接受 |
