 ## 解决方案
 ## 问题理解

 我们得到了几种饮料，每种饮料都含有一定比例的橙汁。 Vasya 将等量的每种饮料混合成一杯鸡尾酒。 

问题很简单：将它们混合后，最终鸡尾酒中橙汁的比例是多少？ 

输入包含饮料数量和每种饮料的橙汁百分比。 输出是混合物中橙汁的百分比。 

限制非常小。 最多有 100 种饮料，因此任何处理每个百分比一次的算法都会立即完成。 即使是不必要的复杂模拟仍然可以轻松地满足限制。 这意味着挑战不在于算法效率，而在于正确理解混合等量如何影响百分比。 

一个常见的错误是考虑实际体积并模拟它们。 这个问题并没有告诉我们每杯饮料喝了多少毫升。 幸运的是，这个值并不重要，因为从每杯饮料中提取的量都是相同的。 最终的百分比只是各个百分比的平均值。 

当某些饮料根本不含橙汁时，就会发生另一种微妙的情况。 

输入：```
2
0 100
```输出：```
50
```忽略零值或除以错误数量的粗心实现可能会产生不正确的结果。 该混合物含有等量的纯橙汁饮料和不含橙汁的饮料，因此平均值恰好为 50%。 

另一个边缘情况是每种饮料都含有 0% 的橙汁。 

输入：```
3
0 0 0
```输出：```
0
```答案仍然有效，因为对零进行平均仍然给出零。 

同样，如果每种饮料都含有 100% 橙汁：

 输入：```
4
100 100 100 100
```输出：```
100
```混合物仍然是纯橙汁。 

## 方法

 直接的蛮力解释是假设 Vasya 从每次饮料中抽取一定量（例如 100 毫升）。 我们可以计算每杯饮料中有多少毫升橙汁，将这些量相加，计算鸡尾酒的总体积，最后除以。 

一杯有百分比的饮料`p`，服用100毫升贡献`p`毫升橙汁。 处理完所有饮料后，橙汁百分比为$$\frac{\text{total orange juice}}{\text{total volume}} \times 100.$$这种方法是正确的，因为它完全遵循物理混合过程。 其时间复杂度为$O(n)$，因为每种饮料都经过一次处理。 

仔细观察这个公式会发现一些更简单的东西。 如果从每杯饮料中取出相同的量，则该量会同时出现在分子和分母中并相互抵消。 剩下的只是所有百分比的算术平均值：$$\frac{p_1 + p_2 + \cdots + p_n}{n}.$$这个问题立即变成了一个求平均的任务。 我们只需要所有百分比的总和，然后除以饮料的数量。 

对于给定的约束，蛮力模拟已经运行得足够快，但平均观察消除了不必要的计算并直接表达了基础数学。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取整数`n`，饮料的数量。 
2. 阅读`n`百分比值。 
3. 计算所有百分比的总和。 
4. 将总和除以`n`以获得平均百分比。 
5. 将结果打印为浮点数。 

唯一的数学观察是从每杯饮料中取出等份。 由于每种饮料的体积相同，因此最终浓度等于原始浓度的平均值。 

### 为什么它有效

 假设瓦夏采取`x`每杯饮料的毫升数。 

喝`i`贡献$$x \cdot \frac{p_i}{100}$$毫升纯橙汁。 

橙汁总量为$$x \cdot \frac{p_1+p_2+\cdots+p_n}{100}.$$鸡尾酒的总体积为$$nx.$$最终的百分比是$$\frac{x \cdot \frac{p_1+p_2+\cdots+p_n}{100}}{nx}\times100 = \frac{p_1+p_2+\cdots+p_n}{n}.$$该算法精确计算这个数量，因此它总是返回正确的橙汁百分比。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
p = list(map(int, input().split()))

answer = sum(p) / n
print(answer)
```第一行读取饮料的数量。 第二行将所有百分比读取到列表中。 

表达式`sum(p)`计算所有饮料的总贡献百分比。 除以`n`给出算术平均值，即最终鸡尾酒中橙汁的浓度。 

Python使用时自动执行浮点除法`/`，因此结果以足够的精度打印，以满足所需的误差容限。 

不存在棘手的边界条件。 值的范围可以是 0 到 100，最大总和仅为 10,000，远低于任何数字限制。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    print(sum(p) / n)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert abs(float(run("3\n50 50 100\n")) - 66.666666666667) < 1e-6

# minimum size
assert abs(float(run("1\n0\n")) - 0.0) < 1e-6

# all equal values
assert abs(float(run("4\n25 25 25 25\n")) - 25.0) < 1e-6

# all maximum values
assert abs(float(run("5\n100 100 100 100 100\n")) - 100.0) < 1e-6

# mixture of extremes
assert abs(float(run("2\n0 100\n")) - 50.0) < 1e-6

# maximum n
assert abs(float(run("100\n" + " ".join(["100"] * 100) + "\n")) - 100.0) < 1e-6
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`1 / 0`|`0`| 最小输入尺寸 |

 |`5 / 100 100 100 100 100`|`100`| 百分比上限 |
 |`2 / 0 100`|`50`| 混合极端|
