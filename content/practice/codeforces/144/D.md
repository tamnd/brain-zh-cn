 ## 解决方案
 ## 问题理解

 我们得到一个代表城市和道路的连接加权无向图。 城市`s`是首都。 导弹发射井可能正好位于城市上或道路的某个内部点。 如果一个头寸到首都的最短路径距离恰好是`l`。 

任务是计算有多少不同的位置满足这个条件。 

关键细节是我们不是在计算路径，而是在计算图中的几何位置。 一条道路可能包含零个、一个或两个有效点，具体取决于距两个端点的最短距离的表现。 

该图最多有`10^5`城市和道路。 这立即排除了任何二次方。 甚至一个`O(nm)`解决方案将执行大约`10^10`最坏情况下的操作，在2秒的限制下是不可能的。 由于所有边权重均为正，因此 Dijkstra 可以高效运行`O((n + m) log n)`，它很适合约束条件。 

棘手的部分不是计算到城市的最短距离。 困难的部分是在不重复计算的情况下计算边缘内的点或计算实际上不在最短距离的点`l`。 

考虑这个图：```
1 --(10)-- 2
```和`s = 1`和`l = 5`。 

远处没有城市`5`，但边缘内恰好有一个点。 仅检查城市的解决方案将错误地返回`0`。 

另一个微妙的情况是来自两端的两个候选点重合。```
1 --(10)-- 2
```认为`dist[1] = 0`,`dist[2] = 4`， 和`l = 7`。 

从城市出发`1`，候选点是`7`沿边缘的单位。 

从城市出发`2`，候选点是`3`沿边缘的单位。 

这些是相同的物理点，因为`7 + 3 = 10`。 我们必须数一次，而不是两次。 

当可以从远处的一个端点到达某一点时，会出现一种更危险的情况`l`，但存在通过另一个端点的另一条更短的路线。 

认为：```
dist[u] = 2
dist[v] = 3
edge length = 10
l = 8
```从`u`，重点在于`6`单位进入边缘。 但从`v`，同一点仅`4 + 3 = 7`远离源，所以它的最短距离实际上是`7`， 不是`8`。 简单的几何检查会计算出无效点。 

该解决方案必须仔细验证最短路径条件。 

## 方法

 强力解释会将每条道路视为连续的路段，并尝试找到最短距离等于的所有点`l`。 人们可以推导出每条边的方程并比较通过两个端点的距离。 

这在理论上是可能的，但处理所有重叠和最短路径条件直接变得混乱。 更糟糕的是，重新计算许多候选位置的最短路径是完全不可行的。 即使针对每个城市检查每个边缘也已经超出了实际限制。 

一旦我们观察到到达边内点的每条最短路径都必须通过边端点之一进入，问题的结构就会发生变化。 

假设一条边连接`u`和`v`与长度`w`。 如果一个点说谎`x`单位来自`u`，那么它到源的距离通过`u`是：```
dist[u] + x
```并通过`v`是：```
dist[v] + (w - x)
```到该点的实际最短距离是这两个值中的最小值。 

这一观察结果完全将连续问题简化为边缘端点的算术问题。 一旦我们使用 Dijkstra 计算从源到每个城市的最短距离，就可以独立分析每条边。 

对于一个点来说，精确地具有最短距离`l`，至少一侧必须满足：```
dist[u] + x = l
```或者```
dist[v] + (w - x) = l
```找到这样的候选位置后，我们必须验证相反的方向并没有给出严格更小的路径。 

这会导致在一次 Dijkstra 运行后对所有边缘进行干净的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 太大，连续持仓可能呈指数增长 | 大| 太慢了 |
 | 最佳|`O((n + m) log n)`|`O(n + m)`| 已接受 |

 ## 算法演练

 1. 构建图的邻接表。 

由于图稀疏且庞大，因此邻接列表比邻接矩阵更有效。 
2. 从首都运行Dijkstra`s`。 

这计算`dist[i]`，从首都到各个城市的最短距离。 
3. 统计所有最短距离等于的城市`l`。 

每一个这样的城市本身就是一个有效的导弹发射井位置。 
4. 独立处理每条边。 

假设边缘是`(u, v, w)`。 
5. 计算端点生成的候选点`u`。 

如果`dist[u] < l`，然后是距离上的一个点```
x = l - dist[u]
```从`u`位于边缘的某个地方如果`x < w`。 
6. 验证该点实际上距离最短`l`。 

通过的距离`v`将是：```
dist[v] + (w - x)
```仅当该值至少为`l`。 

如果它更小，那么该点的真实最短距离将不等于`l`。 
7. 对称地重复终点`v`。 
8. 处理重复计算。 

如果两个端点生成相同的内点，则：```
x + y = w
```在这种情况下，两项检查都涉及一个物理位置，因此请从该边缘的计数中减一。 
9. 将所有有效的城市和边缘位置相加。 

### 为什么它有效

 迪杰斯特拉之后，`dist[u]`是从源到每个端点的确切最短路径距离。 

到边缘内点的任何最短路径`(u, v)`必须通过任一方式进入`u`或者`v`，因为图是无向的并且点仅位于该边上。 因此，到内点的最短距离恰好是：```
min(dist[u] + x, dist[v] + (w - x))
```该算法枚举这些表达式之一等于的每个可能点`l`。 验证步骤保证其他表达式不小于`l`，所以真正的最短距离正是`l`。 

每个有效点都是从至少一个端点发现的，并且当两个端点结构引用同一位置时，重叠校正消除了唯一可能的重复情况。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

n, m, s = map(int, input().split())
s -= 1

adj = [[] for _ in range(n)]
edges = []

for _ in range(m):
    u, v, w = map(int, input().split())
    u -= 1
    v -= 1

    adj[u].append((v, w))
    adj[v].append((u, w))

    edges.append((u, v, w))

l = int(input())

dist = [INF] * n
dist[s] = 0

pq = [(0, s)]

while pq:
    d, u = heapq.heappop(pq)

    if d != dist[u]:
        continue

    for v, w in adj[u]:
        nd = d + w

        if nd < dist[v]:
            dist[v] = nd
            heapq.heappush(pq, (nd, v))

answer = 0

for d in dist:
    if d == l:
        answer += 1

for u, v, w in edges:
    cnt = 0

    # candidate generated from u
    if dist[u] < l:
        x = l - dist[u]

        if x < w and dist[v] + (w - x) >= l:
            cnt += 1

    # candidate generated from v
    if dist[v] < l:
        y = l - dist[v]

        if y < w and dist[u] + (w - y) >= l:
            cnt += 1

    # same physical point counted twice
    if cnt == 2 and (l - dist[u]) + (l - dist[v]) == w:
        cnt = 1

    answer += cnt

print(answer)
```第一部分构建图并分别存储边。 我们需要 Dijkstra 的邻接列表和用于后续边缘分析的平坦边缘列表。 

Dijkstra 实现是标准的。 由于边权重为正，因此我们第一次确定节点时，其距离是最佳的。 这`if d != dist[u]`检查会跳过陈旧的堆条目。 

知道最短距离后，即可立即计算城市。 

边缘处理部分包含真正的逻辑。 从端点`u`，我们计算我们必须沿着边缘走多远才能到达距离`l`。 条件`x < w`保证点严格位于边缘内，而不是正好落在边缘上`v`。 端点城市已经单独统计。 

不等式：```
dist[v] + (w - x) >= l
```是必不可少的。 如果没有它，我们可能会计算一个实际最短距离小于的点`l`。 

重叠条件：```
(l - dist[u]) + (l - dist[v]) == w
```意味着两个结构在同一点相遇。 这是唯一可能发生重复计算的情况。 

所有算术都安全地适合 64 位整数，因为距离可以增长到大约`10^8`。

 ## 边缘情况

 考虑中点重复的情况：```
2 1 1
1 2 10
5
```最短距离是：```
dist[1] = 0
dist[2] = 10
```从节点`1`，候选点位于`5`沿边缘的单位。 

从节点`2`，候选点也在于`5`沿边缘的单位。 

如果没有重叠校正，算法将计算两个点。 平等：```
(5 - 0) + (5 - 10) = 10
```检测到两个结构都引用同一位置，因此计数变为`1`。 

现在考虑一个错误的候选人：```
3 2 1
1 2 2
2 3 10
8
```距离：```
dist[1] = 0
dist[2] = 2
dist[3] = 12
```从节点`2`，我们可以移动`6`单位进入边缘`(2,3)`并且似乎达到了距离`8`。 

但从节点`3`，同一点只是：```
12 + (10 - 6) = 16
```这很好，所以这个观点是有效的。 

现在从概念上修改距离：```
dist[2] = 2
dist[3] = 3
w = 10
l = 8
```该候选人来自`2`会撒谎`6`单位进入边缘。 通过节点`3`，距离变为：```
3 + 4 = 7
```验证条件拒绝该点，因为它的真实最短距离是`7`， 不是`8`。 

最后，考虑准确着陆在端点上：```
2 1 1
1 2 5
5
```城市`2`已经被算作一个城市了。 边缘处理时：```
x = 5
```自从`x < w`为 false，算法不会再次将端点计为内部点。
