 ## 解决方案
 ## 问题理解

 给定一个方阵的三角形区域，称为 n 度楼梯。 在这个楼梯中，除了次对角线上方的区域（从右上角到左下角）之外，每个单元格都是可访问的。 在这个楼梯上，有_m_个运动员被放置在不同的位置。 每个运动员必须沿着最短路径移动到达次对角线。 它们只能移动到侧面相邻的单元格，并且到对角线的距离被测量为此类移动的最小次数。 

挑战是选择最大数量的运动员，以便每个人都可以选择到达次对角线的最短路径，而不会与另一个运动员同时占据同一单元格。 两名运动员可以依次穿过同一个牢房，但没有两个人可以同时占据该牢房。 

输入是运动员的坐标列表，全部位于有效的楼梯区域内。 输出是可以参加的运动员的最大数量以及相应的一组指数。 

约束允许 _n_ 和 _m_ 最多为 100,000，这意味着有效的解决方案必须在大致线性或接近线性的时间内运行。 尝试所有路径排列的简单方法将是 _m_ 的阶乘，并且是完全不可行的。 当多名运动员与次对角线等距或位于同一条线上时，就会出现边缘情况，除非仔细选择路径，否则可能会导致不可避免的碰撞。 例如，如果两名运动员从同一行但不同列开始，他们瞄准的对角线步可能会重合，如果顺序不正确，就会导致碰撞。 粗心的方法可能会错过这一点并过多计算可行集。 

## 方法

 暴力方法将尝试模拟运动员沿着所有最短路径移动的每一种排列。 对于每种配置，它都会检查是否有任何两个同时占据同一个方块。 虽然原则上是正确的，但这种方法完全不切实际：有 _m!_ 种排列，并且可能需要 _O(n)_ 时间来模拟每条路径。 当 _m_ 达到 100,000 时，这是不可行的。 

关键的见解来自观察楼梯中最短路径的结构。 位于 _(r, c)_ 位置的每个运动员到次对角线的最小距离由 _(r + c - n - 1)_ 给出。 所有最短路径都具有相同的长度，并且对角单元格可以按其列进行索引。 最短路径实际上涉及从左下角向对角线移动，并且没有运动员可以在同一条对角线上超越另一个运动员。 因此，问题归结为调度问题：为每个运动员分配一个“时隙”，以在不发生碰撞的情况下到达目标对角线单元。 这个问题可以贪心解决。 

我们可以根据运动员与对角线的距离对他们进行排序，并使用优先级队列或计数策略将他们分配到对角线单元格中。 对于给定的对角单元格，运动员按距离递增的顺序分配，确保最早到达的运动员首先获得位置，避免碰撞。 通过将每个运动员映射到次对角线上的潜在目标并模拟最早到达的目标，我们保证了无碰撞分配。 如果使用排序，该解决方案的工作时间为 _O(m log m)_ 时间，这对于给定的约束是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m! * n) | O(m * n) | 太慢了 |
 | 按距离贪婪分配 | O(m log m) | O(米) | 已接受 |

 ## 算法演练

 1. 使用以下公式计算每个运动员到次对角线的最短路径距离`distance = r + c - n - 1`。 这捕获了所需的最少移动次数。 
2. 按照运动员能够到达的目标对角线单元对运动员进行分组。 位置处的每个辅助对角线单元格`(i, j)`最多可容纳一名运动员，因此这些是可分配的有限资源。 
3. 根据运动员到对角线的距离对运动员进行排序。 排序确保距离较近的运动员首先被分配，从而防止与后来到达的运动员发生碰撞。 
4. 迭代排序的运动员，并贪婪地将每个运动员分配到与其路径相对应的可用对角单元格。 跟踪占用的对角线单元格，以确保没有两个运动员被分配到相同的目标。 如果单元格已被占用，请暂时跳过运动员。 
5. 收集所有指定的运动员并输出他们的人数和指数。 

为什么有效：按距离排序可以保证不会有两名运动员在他们的路径上发生碰撞。 每个对角单元格的分配都是按照最早到达的顺序进行的，这确保了运动员永远不会移动到另一个运动员同时占用的单元格中。 这个不变量保证了选择最多数量的不碰撞运动员。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
sportsmen = []

for i in range(m):
    r, c = map(int, input().split())
    # distance to secondary diagonal
    dist = r + c - n - 1
    sportsmen.append((dist, r, c, i + 1))  # store index 1-based

# sort by distance
sportsmen.sort()

occupied_diagonal = set()
selected = []

for dist, r, c, idx in sportsmen:
    target_diag = c  # each diagonal cell can be indexed by its column
    if target_diag not in occupied_diagonal:
        occupied_diagonal.add(target_diag)
        selected.append(idx)

print(len(selected))
print(" ".join(map(str, selected)))
```该解决方案首先计算每个运动员的距离，然后对他们进行排序，以确保首先考虑那些最早到达的运动员。 每个辅助对角柱都用作关键，以确保没有两个运动员瞄准同一个单元格，从而防止碰撞。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    sportsmen = []
    for i in range(m):
        r, c = map(int, input().split())
        dist = r + c - n - 1
        sportsmen.append((dist, r, c, i + 1))
    sportsmen.sort()
    occupied_diagonal = set()
    selected = []
    for dist, r, c, idx in sportsmen:
        target_diag = c
        if target_diag not in occupied_diagonal:
            occupied_diagonal.add(target_diag)
            selected.append(idx)
    return f"{len(selected)}\n{' '.join(map(str, selected))}"
