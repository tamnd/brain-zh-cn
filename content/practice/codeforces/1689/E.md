 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组。 每个数组元素对应于图中的一个顶点。 当两个顶点的值按位与为正时，它们就通过边连接。 

不保证该图是连通的。 我们可以重复地将单个数组元素增加或减少 1，其中仅允许对正值进行递减。 每一次增量或减量都会花费一次操作。 

我们的任务是找到使图连接起来所需的最少可能操作数，并输出一个达到该最小值的结果数组。 

最重要的观察是图结构完全由共享集位决定。 如果两个数字至少有一个公共位等于 1，则它们是相邻的。因此，连通性是位如何在数组中分布的属性，而不是数值本身的属性。 

限制小得惊人。 全部的总和$n$整个输入最多为 2000。这意味着$O(n^2)$甚至$O(n^2 \log A)$解决方案是完全可以接受的。 由于值低于$2^{30}$，只有 30 个相关位位置。 

一些边缘情况很容易被错误处理。 

考虑：```
2
0 0
```对应于值 0 的顶点没有设置位，因此它与所有事物隔离。 任何连通图都不能包含零。 仅检查非零顶点之间的连通性的解决方案会错误地声称成功。 

另一个棘手的情况是：```
2
3 12
```该图已断开连接，因为：```
3  = 0011
12 = 1100
```他们的 AND 为零。 单个减量给出：```
3  = 0011
11 = 1011
```现在 AND 为正。 最小答案是 1。 

最后一个微妙的情况是：```
4
8 8 1 1
```删除零后，图形仍然断开。 一些建设性的想法将其连接到两个操作中，但不一定连接到一个操作中。 该解决方案必须正确区分答案 1 和 2。 

## 方法

 一种强力方法是搜索所有可能的修改序列并在每次更改后测试连接性。 

这在原则上显然是正确的，但完全不可行。 即使将我们限制为每个元素的一些增量和减量也已经创建了指数搜索空间。 

关键的突破在于答案总是非常小。 

首先，必须更改每个零。 零不贡献任何位，并且永远不能与任何东西共享边缘。 将每个零变成一始终是最佳选择，因为它只花费每个零一次操作并产生有用的值。 

所有零变为一后，我们检查结果图。 

如果已经连接，我们就完成了。 

否则，编辑的观察是值得注意的：在删除零之后，剩余的最小额外成本永远不会超过两个。 我们可以首先通过尝试每个可能的单个增量和每个可能的单个减量来测试一个额外的操作是否足够。 自从$n \le 2000$，这种暴力检查很便宜。 

如果这些尝试都不起作用，那么答案一定是两个。 

最后一步是以建设性的方式实现这两项操作。 让```
lowbit(x) = x & (-x)
```并考虑所有低位为最大值的元素。 

如果只有一个这样的元素，则将其减一。 

如果有多个这样的元素，则递减其中一个并递增另一个。 

这种特殊的修改总是连接图形。 证明来自连接测试中使用的位组件结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力搜索操作 | 指数| 指数| 太慢了 |
 | 连接测试 + 尝试所有一步更改 + 建设性两步修复 |$O(n^2 \cdot 30)$|$O(30)$| 已接受 |

 ## 算法演练

 ### 连接检查

 顶点上的图可能很大，但只有 30 位位置。 

不是直接构建顶点图，而是在位上构建图。 

对于每个数字，连接该数字内出现的所有设置位。 如果一个数字包含位 1、4 和 7，那么这些位属于同一组件，因为该数字将它们链接在一起。 

处理完所有数字后，出现在任何地方的所有位位置都应该属于单个连通分量。 如果不是，则原始顶点图无法连接。 

### 步骤

 1. 计算数组中所有零的数量。 
2. 将每个零替换为 1，并将替换次数添加到答案中。 
3. 检查图形是否连通。 
4. 如果已连接，则输出当前数组。 
5. 否则，尝试每个索引。 

对于每个索引，如果值为正，则暂时将其减一并测试连通性。 

如果实现连接，则输出该数组。 
6. 恢复该值并暂时加一。 
7. 再次测试连接。 
8. 如果实现连接，则输出该数组。 
9. 如果单个修改不起作用，则找到最大值`lowbit(a[i])`。 
10.收集具有该最大低位的所有索引。 
11. 如果恰好存在一个这样的索引，则将该元素减一。 
12. 否则，将其中一个元素减少 1，并将另一个元素增加 1。 
13. 将答案加 2 并输出结果数组。 

### 为什么它有效

 将每个零替换为一是强制性的。 零不包含任何设置位，因此它始终是隔离的。 任何连接的最终图必须消除所有零。 

删除零后，我们首先测试仅需要一次额外操作的所有可能性。 由于每个合法的单操作解决方案必须是一个元素的单个增量或单个减量，因此详尽的检查就足够了。 

剩下的主张是，如果不存在单操作解决方案，则总是存在两操作解决方案。 官方社论的低位结构保证了这一点。 具有最大低位的元素位于所有数字中的最高“位级别”。 将其中一两个调整一位会更改其最低设置位并合并断开的位组件。 因此，每个剩余的情况都可以通过两次额外的操作来解决。 

由于我们已经排除了答案 0 和 1，因此最小可能答案必须是 2。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def connected(a):
    parent = list(range(30))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra = find(a)
        rb = find(b)
        if ra != rb:
            parent[ra] = rb

    used = []

    for x in a:
        bits = []
        for b in range(30):
            if (x >> b) & 1:
                bits.append(b)

        if bits:
            used.extend(bits)
            root = bits[0]
            for b in bits[1:]:
                union(root, b)

    used = list(set(used))

    if not used:
        return False

    r = find(used[0])
    for b in used:
        if find(b) != r:
            return False

    return True

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        ops = 0

        for i in range(n):
            if a[i] == 0:
                a[i] = 1
                ops += 1

        if connected(a):
            print(ops)
            print(*a)
            continue

        found = False

        for i in range(n):
            if a[i] > 0:
                a[i] -= 1
                if connected(a):
                    print(ops + 1)
                    print(*a)
                    found = True
                    break
                a[i] += 1

            a[i] += 1
            if connected(a):
                print(ops + 1)
                print(*a)
                found = True
                break
            a[i] -= 1

        if found:
            continue

        best = max(x & -x for x in a)

        idx = [i for i in range(n) if (a[i] & -a[i]) == best]

        if len(idx) == 1:
            a[idx[0]] -= 1
        else:
            a[idx[0]] -= 1
            a[idx[1]] += 1

        print(ops + 2)
        print(*a)

solve()
```实施围绕`connected()`功能。 

它不是在数组位置上构造图，而是在 30 位位置上构造 DSU。 每个数字将其所有设置位合并到单个 DSU 组件中。 最后，所有使用的位必须属于一个 DSU 组件才能连接图。 这正是官方解决方案中使用的标准。 

单操作搜索必须在每次临时修改后仔细恢复值。 忘记恢复元素是错误答案的常见原因。 

低位计算使用：```
x & -x
```它隔离了最低设置位。 在所有元素中，我们找到具有最大低位的元素并应用建设性的两次操作修复。

 ## 边缘情况

 考虑：```
2
0 2
```与零对应的顶点没有边。 该算法立即将零转换为一。 之后它会检查连接性`[1,2]`。 如果仍然断开连接，则稍后的阶段会处理它。 重要的是，没有任何连接的解决方案可以保持零。 

考虑：```
2
3 12
```零处理后没有任何变化。 该图已断开连接。 一次操作搜索测试每个增量和减量。 改变`3`到`4`产量：```
4 & 12 = 4
```因此图已连通并且算法正确返回答案 1。 

考虑：```
4
8 8 1 1
```没有一次操作修改成功。 算法达到建设性阶段。 最大低位为 8，通过 8 的两个副本实现。一个减少，另一个增加，仅在两次附加操作中产生有保证的连接配置。 由于所有一次性操作的可能性已经用尽，因此这个答案是最佳的。
