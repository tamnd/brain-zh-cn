 ## 解决方案
 ## 问题理解

 给定一个一维长度的条带$n$。 每个单元格最终必须被着色为黑色或白色。 我们不能自由选择颜色，而必须准确地形成$k$连续的黑色段，其长度固定为$b_1, b_2, \dots, b_k$，按此顺序。 连续的黑色段之间必须至少有一个白色单元，而两端允许有任意数量的白色单元。 

除了通常的非图规则之外，一些单元格已经受到 Bob 的约束。 一部分位置被迫为白色，而其余位置尚未确定。 该任务首先确定是否存在满足段约束和 Bob 强制白色的有效着色。 如果至少存在一种有效配置，我们必须对所有有效解决方案中的每个单元格进行分类：如果单元格在每个有效解决方案中都是黑色，则将其标记为黑色，如果在每个有效解决方案中都是白色，则将单元格标记为白色，否则将不明确。 

输入大小很大：所有测试用例的总长度可以达到$2 \cdot 10^6$，因此任何解决方案对于每个测试用例都必须基本上是线性的。 这排除了任何尝试枚举块的放置或独立地重新计算每个单元的可行性的方法。 

当根本没有块时，就会出现微妙的边缘情况，即$k = 0$。 在这种情况下，整个条带必须是白色的，唯一的问题是这是否与鲍勃的约束相矛盾。 另一种边缘情况是当强制白细胞阻挡所需片段的所有可能放置时。 例如，如果必须放置长度为 3 的块，但每个长度为 3 的间隔与强制零相交，则该实例立即不可能。 

## 方法

 暴力解释是尝试所有可能的位置$k$沿着条带进行块，同时尊重顺序和间距，并检查与强制白细胞的一致性。 即使在最简单的情况下，每个块都可以移动$O(n)$位置，因此配置数量呈指数增长$k$。 即使对于中等程度的人来说，这也很快变得不可行$n$。 

关键的观察是，尽管可能有许多有效的布局，但可行布局的结构是单调的。 一旦我们固定了块的顺序，每个块都有一个连续范围的有效起始位置。 这使我们能够为每个块计算与所有约束一致的最早和最晚可能的开始位置。 这些范围完全涵盖了所有有效的解决方案。 

一旦知道了这些范围，问题的第二部分就变成了覆盖推理任务：每个块在滑动间隔内贡献黑色单元，并且我们必须确定单元是否被全部、部分或没有有效布局覆盖。 这完全避免了枚举解决方案，并将问题简化为区间分析。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力展示位置 | 指数| O(n) | 太慢了|
 | 区间界限+覆盖推理| 每次测试 O(n + k) | O(n) | 已接受 |

 ## 算法演练

 我们将解决方案分为两个阶段：计算块的有效放置范围，然后使用这些范围对单元进行分类。 

### 步骤1：验证每个区块间隔的可行性

 我们首先计算每个块$i$最早可能的起始位置$L_i$以及最新可能的起始位置$R_i$，考虑排序限制和强制白细胞。 

为了有效地检查可行性，我们预先计算字符串的前缀和，以便我们可以在 O(1) 时间内测试某个段是否包含任何强制白色。 如果一段长度$b_i$包含强制白色，该放置无效。 

我们计算$L_i$贪婪地从左到右。 每个块必须在前一个块结束后开始，加上至少一个分离单元。 我们向前滑动起始点，直到找到一个适合该块且不会接触强制白球的位置。 如果不存在这样的位置，则整个测试用例是不可能的。 

### 步骤 2：计算最新有效仓位

 我们计算$R_i$从右到左对称。 我们将方块放置在尽可能靠右的位置，同时保留间距并避免强制出现白色。 这再次使用了贪婪移位和有效性检查。 

此步骤之后，每个有效配置对应于选择每个块开始$s_i \in [L_i, R_i]$，排序约束已经编码在我们计算范围的方式中。 

### 步骤 3：确定在某些解决方案中哪些单元格可以是黑色的

 一个细胞$x$如果存在某个块，则至少在一种有效解决方案中可以为黑色$i$和一些安置$s_i \in [L_i, R_i]$这样$x \in [s_i, s_i + b_i - 1]$。 

重写这个条件，这样的位置存在当且仅当：$$x \in [L_i, R_i + b_i - 1]$$因此，我们可以在单元格上维护一个差异数组并标记每个间隔$[L_i, R_i + b_i - 1]$。 在所有有效解决方案中，任何此类间隔未覆盖的任何单元格都将强制为白色。 

### 步骤 4：确定哪些单元格始终为黑色

 一个细胞$x$如果存在块，则始终为黑色$i$这样该块的每个有效位置都覆盖$x$。 这意味着：$$L_i \le x - b_i + 1 \quad \text{and} \quad R_i \ge x$$如果两者都成立，那么无论我们如何选择有效的配置，都会阻止$i$总是跨越$x$， 制作$x$永久黑色。 

我们通过扫描每个块并标记其保证覆盖区间来计算这一点$[L_i + b_i - 1, R_i]$。 

### 步骤 5：最终分类

 对于每个单元格：

 - 如果它没有被任何配置中的任何块覆盖，则它始终为白色。 
- 否则，如果保证在每种配置中至少被一个块覆盖，则它始终为黑色。 
——否则的话，就是有歧义的。 

### 为什么它有效

 关键的不变量是每个有效的解决方案完全对应于固定独立区间内的块起始位置的选择$[L_i, R_i]$。 这些间隔捕获由排序和禁止单元引起的所有全局约束。 一旦这种分解成立，每个块在覆盖贡献方面都会独立表现，并且每个单元的状态都会简化为对这些独立选择的区间并集进行推理。 除了排序之外，没有任何全局耦合存在，排序已经被吸收到区间的构造中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    s = input().strip()
    b = list(map(int, input().split())) if k else []

    # prefix sum of forced zeros
    pref = [0] * (n + 1)
    for i, ch in enumerate(s):
        pref[i+1] = pref[i] + (ch == '0')

    def has_zero(l, r):
        if l > r:
            return False
        return pref[r+1] - pref[l] > 0

    if k == 0:
        # must all be white unless forced contradiction (already white forced allowed)
        # output all '0'
        print("Yes")
        print("0" * n)
        return

    L = [0] * k
    R = [0] * k

    # compute L
    pos = 0
    for i in range(k):
        if i > 0:
            pos += 1
        while pos + b[i] <= n and has_zero(pos, pos + b[i] - 1):
            pos += 1
        if pos + b[i] > n:
            print("No")
            return
        L[i] = pos
        pos += b[i]

    # compute R
    pos = n - 1
    for i in range(k-1, -1, -1):
        if i < k - 1:
            pos -= 1
        while pos - b[i] + 1 >= 0 and has_zero(pos - b[i] + 1, pos):
            pos -= 1
        if pos - b[i] + 1 < 0:
            print("No")
            return
        R[i] = pos - b[i] + 1
        pos = R[i]

    diff = [0] * (n + 2)
    always_black = [0] * n

    for i in range(k):
        diff[L[i]] += 1
        diff[R[i] + b[i] - 1 + 1] -= 1

        left = L[i] + b[i] - 1
        right = R[i]
        if left <= right:
            always_black[left] += 1
            if right + 1 < n:
                always_black[right + 1] -= 1

    cover = 0
    for i in range(n):
        cover += diff[i]
        always_black[i] += always_black[i-1] if i > 0 else 0

    res = []
    for i in range(n):
        if s[i] == '0':
            res.append('0')
            continue

        can_black = cover > 0
        must_black = always_black[i] > 0

        if must_black:
            res.append('1')
        elif can_black:
            res.append('?')
        else:
            res.append('0')

    print("Yes")
    print("".join(res))

t = int(input())
for _ in range(t):
    solve()
```该实现首先在强制零上构建前缀和，以便任何段有效性检查都成为恒定时间。 前向传递通过贪婪地向右推动每个块直到它适合来构造最早的放置。 向后传递反映了这一点以计算最新的位置。 这两次传递定义了每个块的完整可行范围。 

差值数组`diff`捕获某个单元格是否可以被某个块的至少一个位置覆盖。 第二阵列跟踪始终被至少一个固定块覆盖的单元，无论放置如何。 最后，强制白细胞立即凌驾于其他一切之上。 

## 工作示例

 考虑一个小例子$n = 6$，一个长度为3的块，并且没有强制限制。 该块可以从位置 0 到 3 的任何位置开始。可能的覆盖联合是从 0 到 5 的滑动窗口，因此每个单元格都可能是黑色的，但根据重叠结构，只有中间区域始终是黑色的。 

| 块| 左 | 右 | 乙| 覆盖间隔|
 | --- | --- | --- | --- | --- |
 | 1 | 0 | 3 | 3 | [0, 5] |

 这展示了即使起始点受到限制，覆盖范围也可以扩展到连续范围。 

现在考虑两个块，例如$b = [2, 1]$，中间强制为零。 强制约束分割了可行的布局，缩小了两者$L$和$R$。 有些单元变得完全无法到达，而其他单元则始终被第一个块覆盖，无论移动如何。 

| 块| 左 | 右 | 乙|
 | --- | --- | --- | --- |
 | 1 | 0 | 2 | 2 |
 | 2 | 4 | 5 | 1 |

 这显示了强制约束如何分割可行区间并直接影响覆盖分类。 

这些例子证实所有推理都正确地简化为区间边界。

 ## 边缘情况

 一个关键的边缘情况是强制清零将所需块完全碎片化。 例如，条带上长度为 3 的块，其中每个长度为 3 的段都包含强制零，将不会产生有效的结果$L_1$。 在正向构造过程中，指针前进，直到找到有效段； 如果不存在，算法会立即拒绝该实例，以匹配正确的行为。 

当块的可行范围折叠到单个位置时，会出现另一种边缘情况。 在那种情况下$L_i = R_i$，这意味着该块在所有解决方案中都是固定的。 分类逻辑正确地将其跨度中的所有单元标记为始终黑色，因为没有替代放置。 

最后的边缘情况是$k = 0$，其中条带必须完全不包含黑色单元。 该算法绕过所有DP，直接输出全白条带，符合不存在黑色块的约束。
