 ## 解决方案
 ## 问题理解

 我们有一条固定长度的圆形跑道。 喀布尔沿着这一环路以恒定的速度运行，并在固定的时间内保持向一个方向移动。 其他步行者也沿着同一个循环移动，每个步行者都以恒定的符号速度移动，因此它们要么与喀布尔一起移动，要么与他对抗。 

对于每个步行者，我们都会被告知喀布尔第一次见到该步行者的时间。 第一次相遇后，两人继续在同一条圆形轨道上移动，因此在时间耗尽之前他们可能会多次相遇。 任务是确定对于每个步行者，从开始时间到最终时间 T 的时间间隔内总共发生了多少次会议，包括初始会议和恰好在 T 发生的任何会议。 

其关键结构是每个步行者以匀速圆周运动，因此相对运动是均匀的，并且会议周期性地重复。 每个测试用例总共可以包含最多 200,000 个步行者，时间最多可以达到 10^7，因此任何模拟随时间移动或每秒处理的解决方案都是不可能的。 甚至 O(NT) 或任何依赖于 T 的东西都会被立即排除。 即使 O(N sqrt T) 也是不安全的。 

一个微妙的点是我们没有被要求计算第一次会议的时间。 这已经是给定的了。 输入修复了喀布尔和每个步行者之间的参考对齐。 这消除了几何模糊性，并将问题转化为计算周期性事件在有限时间间隔内发生的次数。 

通常打破朴素推理的边缘情况来自模块化环绕和方向变化。 

一个简单的失败案例是步行者以非常接近喀布尔的速度沿同一方向移动。 他们可能很少会面，但也会多次见面，而且周期会变长。 

另一种边缘情况是当会议恰好在时间 T 发生时。由于 T 包含在内，因此未能计算边界命中会导致差一错误。 

最后，方向仅通过相对速度起作用。 在没有带符号速度的情况下统一处理所有步行者会导致周期计算不正确。 

## 方法

 暴力解释将模拟喀布尔和每个步行者随时间变化的位置。 我们可以以较小的增量提前时间，并跟踪位置何时与模 L 匹配。对于每个步行者，检测到时间 T 的会议将需要逐步遍历所有未来的碰撞事件。 

问题在于会议在时间上形成了算术级数。 喀布尔和步行者之间的相对位置随时间线性变化，并且在圆周上，位置相等会在每个完整的相对圈中重复。 这将会议时间序列变成从给定的第一次会议时间 ti 开始的算术级数，固定周期仅取决于相对速度。 

如果我们让有效相对速度为 v0 - vi，那么在绕圆的每个完整周期之后，都会重复相同的对准。 因此，一旦我们在 ti 召开一次会议，下一次会议就恰好在等于 L 除以绝对相对速度的恒定时间间隔之后发生。 

这将每个步行者简化为一个简单的计数问题：给定第一次出现时间和一个周期，计算算术级数中有多少项位于 [0, T] 内。 

蛮力方法之所以有效，是因为它直接跟踪运动，但失败是因为它需要逐步遍历每个步行者可能的 O(T) 或 O(T / period) 事件。 观察到运动在圆上是周期性的，将问题简化为算术级数计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟 | O(N·T) | O(N·T) | O(1) | O(1) | 太慢了|
 | 算术级数计数| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立对待每个步行者，因为相互作用不会互相影响。 

### 1. 计算相对运动

对于每个步行者，计算喀布尔和步行者之间的相对速度。 由于喀布尔以 v0 移动，步行者以 vi 移动，因此接近速度为带符号形式的 v0 - vi。 只有幅度对周期长度很重要。 

原因是会议只取决于解决圆圈距离的速度，而不是方向约定。 

### 2. 推导会议时间

 每次喀布尔超过或再次遇到步行者时，相对位移正好增加一个完整的循环长度 L。因此，连续相遇之间的时间为 L / |v0 - vi|。 

这是会议时间的算术级数的周期。 

### 3. 模拟会议时间

 所有的会议时间可以写为：

 ti, ti + 周期, ti + 2·周期, ...

 第一项已经给出，因此我们不需要对其进行几何计算。 

### 4. 计算时间窗口内的有效术语

 我们需要级数中位于 [0, T] 中的项数。 由于ti保证在[0, T]范围内，所以我们只需要统计有多少项不超过T即可。 

因此我们计算最大的 k：

 ti + k · 周期 ≤ T

 这给出：

 k ≤ (T - ti) / 周期

 因此会议次数为：

 k+1

 ### 5. 安全地处理整数算术

 因为L和速度都是整数，所以在实际算术中周期可能不是整数。 然而，所有输入都保证一致的对齐，因此我们通过缩放进行理性算术：我们避免浮点并使用乘法进行计算。 

我们重写条件：

 ti + k·L / d ≤ T，其中 d = |v0 - vi|

 乘以：

 ti·d + k·L ≤ T·d

 所以：

 k ≤ (T·d - ti·d) / L

 我们使用整数除法。 

### 为什么它有效

 喀布尔和圆周上任何步行者的运动都简化为时间模 L 的线性函数。位置相等对应于求解时间上的线性同余。 一旦给出一个解 ti，所有其他解就会形成一个由 L / |v0 - vi| 精确间隔的格子。 由于不存在其他力或相互作用，会议时间的集合完全由该算术级数决定。 因此，计算有效会议相当于计算级数的有界区间内的整数点，这由导出的不等式精确捕获。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    K = int(input())
    out = []
    for _ in range(K):
        L, v0, T, N = map(int, input().split())
        res = []
        for _ in range(N):
            ti, vi = map(int, input().split())

            d = abs(v0 - vi)

            # number of additional full cycles possible
            # k such that ti + k*(L/d) <= T
            # => ti*d + k*L <= T*d
            # => k <= (T*d - ti*d) // L
            if ti > T:
                res.append(0)
                continue

            numerator = (T - ti) * d
            if L == 0 or numerator < 0:
                res.append(0)
                continue

            k = numerator // L
            res.append(k + 1)

        out.append(" ".join(map(str, res)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案在恒定时间内独立处理每个步行者。 关键部分是避免期间的浮点除法。 相反，我们将不等式乘以相对速度，以保持所有内容都是整数。 即使 T 和 L 值很大，这也可以防止精度问题并保持正确性。 

一个微妙的细节是将 ti 精确地处理为 T 或超出 T。由于 ti 保证在语句中的范围内，因此此检查主要是防御性的，但它可以防止算术边缘情况。

 ## 边缘情况

 一个重要的边缘情况是第一次会议正好发生在时间 T。在这种情况下，算术级数仅包含初始项。 该公式仍然有效，因为 (T - ti) 变为零，产生 k = 0，因此答案为 1。 

另一种情况是当相对速度很大时，使得周期很小。 这增加了会议的数量，但整数除法仍然正确捕获所有有效倍数，因为每个步骤都是从精确的不等式变换而不是浮动近似导出的。 

当vi接近v0时，分母变小，因此表达式(T - ti) * d / L可以变大。 使用 64 位整数对于避免中间乘法溢出是必要的。
