 ## 问题理解

 任务是排列数字`1`到`n`成排列。 排列的质量是通过查看每个位置并将其值与其旁边的值进行比较来衡量的。 对于每个元素，我们关心它与相邻元素之间的最大绝对差异。 排列的美妙之处在于所有位置上这些值的最小值。 目标是构造一个具有最大可能美感的排列。 

输入仅包含排列的大小。 输出必须是所有数字的一个排序`1`到`n`从而达到最佳的美感。 

的约束条件为`n`意味着算法应该接近线性。 即使`n`很大，我们只需要打印`n`数字，因此任何解决方案在每个元素上执行的工作量超过少量恒定工作量都有可能太慢。 排序、搜索或尝试许多候选排列是不必要的，因为答案具有直接构造。 

困难的情况不在于性能，而在于保持每个元素所需的最小差异。 

为了`n = 1`，假设每个元素都有两个邻居的解决方案将会失败。 正确的输出是：```
Input:
1

Output:
1
```只有一种可能的排列，这就是答案。 

为了`n = 2`，粗心的实现可能会尝试将最大的元素放在构造的中间。 没有中间位置，因此构造仍然必须产生两个数字：```
Input:
2

Output:
2 1
```对于奇数值，例如`n = 5`，使用偶数构造公式而不进行调整会产生重复值或缺失值。 正确的排列是：```
Input:
5

Output:
3 1 4 2 5
```中间值必须单独处理，因为排列的一侧多了一个元素。 

## 方法

 直接的蛮力方法将生成所有可能的排列并计算其美丽度。 一种排列的计算是线性的，因为每个元素只需要对照其邻居进行检查。 然而，有`n!`可能的排列，因此总工作变为`O(n * n!)`。 即使对于较小的值`n`，这增长得太快了。 

关键的观察是我们不需要搜索排列。 美丽取决于迫使每个元素至少有一个远离它的邻居。 大值应该放在小值旁边，因为它们的差异就是我们正在最大化的资源。 

最大可能的美丽不能超过一半`n`在偶数情况下。 考虑中间值`n / 2`。 它可以配对的最大值是`n`，给出精确的差异`n / 2`。 没有任何元素可以实现更大的保证差异，因为最接近的可能排列仍然使该中间元素成为限制因素。 

这个界限表明构造应该将数字的前半部分与后半部分配对。 这种安排在较大的未使用值和较小的未使用值之间交替，从而在各处产生较大的差异。 

对于甚至`n`，顺序为：```
n/2 + 1, 1, n/2 + 2, 2, ..., n, n/2
```对于奇数`n`，中间值略有不同，因此构造变为：```
(n+1)/2, 1, (n+1)/2 + 1, 2, ..., n
```蛮力方法之所以有效，是因为它探索了所有可能的位置。 构建之所以有效，是因为目标的结构准确地告诉我们哪些值应该是邻居。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * n!) | O(n) | 太慢了|
 | 最佳| O(n) | 除了输出存储之外，O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`，所需排列的大小。 
2. 手柄`n = 1`分别通过输出`1`。 一般构造依赖于具有小值和大值对，这对于单个元素来说是不存在的。 
3.如果`n`是偶数，从`n/2 + 1`和`1`。 添加一个大数，然后添加相应的小数，每对后两边都增加。 这会产生绝对差异较大的对。 
4. 如果`n`是奇数，从`(n+1)/2`和`1`。 继续添加一个大值，然后添加一个小值，直到使用完所有数字。 多余的中间值自然放在开头。 
5. 打印构建的排列。 

结构在两半之间交替的原因是每个数字都可以从另一半访问相邻的数字。 下半部分的值与上半部分的值相差很大，这使得最小邻居差异尽可能大。 

为什么它有效：

 该结构保证除了端点之外的每个元素都具有来自数字范围另一半的相邻值。 端点还有一个邻居，该邻居具有由布置创建的最大可能间隔。 由于范围的中间元素限制了任何可能的答案，达到该值证明该结构是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 1:
        print(1)
        return

    ans = []

    if n % 2 == 0:
        low = 1
        high = n // 2 + 1

        while high <= n:
            ans.append(high)
            ans.append(low)
            high += 1
            low += 1
    else:
        low = 1
        high = (n + 1) // 2

        while high <= n:
            ans.append(high)
            if low < high:
                ans.append(low)
            high += 1
            low += 1

    print(*ans)

if __name__ == "__main__":
    solve()
```该代码保留两个代表排列中未使用部分的指针。`low`走过较小的一半并且`high`走过较大的一半。 交替附加它们会产生所需的大间隙。 

偶数情况更简单，因为两半的大小相同。 奇怪的情况有一个额外的大侧元素，因此循环在附加它之前检查小侧值是否仍然存在。 

边界条件`n == 1`防止循环逻辑创建无效的空配对。 由于值是直接从范围生成的，因此不存在重复值，也不存在丢失的数字。

import sys
import io

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())

    if n == 1:
        return "1\n"

    ans = []

    if n % 2 == 0:
        low = 1
        high = n // 2 + 1
        while high <= n:
            ans.append(high)
            ans.append(low)
            high += 1
            low += 1
    else:
        low = 1
        high = (n + 1) // 2
        while high <= n:
            ans.append(high)
            if low < high:
                ans.append(low)
            high += 1
            low += 1

    return " ".join(map(str, ans)) + "\n"

assert solution("1\n") == "1\n", "minimum size"
assert solution("2\n") == "2 1\n", "two elements"
assert solution("5\n") == "3 1 4 2 5\n", "odd size"
assert solution("6\n") == "4 1 5 2 6 3\n", "even size"
assert solution("8\n") == "5 1 6 2 7 3 8 4\n", "larger even size"

 ## 边缘情况

 对于`n = 1`，算法立即返回`1`。 没有尝试创建对，因此它避免访问不存在的相邻元素。 

为了`n = 2`，偶数构造开始于`n/2 + 1 = 2`，产生唯一可能的顺序，值较大的首先：```
2 1
```两个元素之间的差异是最大可能值。 

为了`n = 5`，算法采用奇数公式：```
3 1 4 2 5
```价值`3`是范围的中间，因此不能将其视为任一半的正常元素。 先放置它，然后交替放置剩余的数字，可以保持最小相邻差值最优。 

为了`n = 8`，生成的序列为：```
5 1 6 2 7 3 8 4
```该算法从不排序、交换或搜索。 它只是并行消耗下半部分和上半部分，因此每个值都恰好出现一次，并且每个相邻关系都遵循预期的模式。
