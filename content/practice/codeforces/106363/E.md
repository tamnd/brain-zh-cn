 ## 解决方案
 ## 问题理解

 我们得到了一系列票价，并要求解决一个两级选择任务。 首先，在所有票价之间的两两差异中，我们需要确定第k个最小的差异值。 确定了目标差异后，我们想要找到一对价格差异恰好等于该值的门票，同时根据问题的平局规则优化对的选择，即在该约束下选择最佳的可能对。 

自然的解释是我们正在使用代表价格的整数数组。 从这个数组中，我们隐式地形成所有对 i < j 并考虑它们的绝对差异。 第一阶段是针对这些差异的全球排名问题。 第二阶段是对满足差异相等条件的对进行约束搜索。 

这些约束意味着票的数量可能足够大，以至于不可能枚举所有对。 如果n达到2×10^5，则对的数量约为2×10^10，这远远超出了任何可行的计算。 这立即排除了两个阶段中的任何二次方法。 任何解决方案都必须避免显式对生成，而是依赖排序结构和计数技术。 

当多对共享相同的差异时，就会出现一个微妙的问题。 幼稚的方法可能会错误地假设唯一性，或者在重建最终对时可能会错误地处理平局打破。 另一个常见的陷阱是忘记差异是根据排序值计算的，因此绝对差异仅在排序后才变成简单的减法。 

作为具体的边缘情况，请考虑 k = 1 时的价格 [1, 10, 20]。与 (1, 10) 的最小差异为 9。 仅检查原始数组中相邻差异的天真错误方法可能会完全错过对 (1, 10)。 另一种情况是 [1, 2, 3, 100]，其中连续元素之间存在许多小的差异，但第 k 个最小的可能来自取决于 k 的非相邻结构。 这表明原始顺序中的邻接关系是无关紧要的； 必须强制执行命令。 

## 方法

 直接强力解决方案枚举每对索引 i < j，计算 |a[j] - a[i]|，存储这些值，对它们进行排序，然后选择第 k 个最小的值。 这是正确的，因为它显式地构造了完整的差异多重集。 然而，它需要 O(n^2) 时间和 O(n^2) 内存，即使 n 约为 10^5，这也是不可能的，因为对的数量呈二次方增长。 

关键的结构观察是，一旦数组排序，问题在差异阈值上就变得单调。 如果我们固定一个值 d 并计算有多少对最多有 d 差异，则可以使用两指针扫描在线性时间内计算该计数。 随着 d 的增加，该计数只会增加。 这种单调性允许我们对 d 进行二分搜索以找到最小值，使得至少 k 对的差异 ≤ d，这正是第 k 个最小的差异。 

一旦知道这个阈值差异，第二阶段就变成了约束计数问题。 我们再次在排序数组上使用两指针方法来识别差值等于目标值的对，并根据所需的排序条件选择最佳对。 这避免了枚举所有对，同时仍然恢复有效的最佳解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 log n^2) | O(n^2 log n^2) | O(n^2) | O(n^2) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(1) 或 O(n) | 已接受 |

 ## 算法演练

 我们首先对票价数组进行排序，以便可以通过简单的减法来处理元素之间的差异。

1. 对数组进行非降序排序。 排序可确保对于任何 i < j，差值 a[j] - a[i] 在 j 中是非负且单调的。 
2. 定义函数 count(d)，返回满足 a[j] - a[i] ≤ d 的 (i, j) 对的数量。 这是使用两个指针计算的。 对于每个 i，我们在保持约束的同时尽可能地推进 j。 从 i 开始的有效对的数量为 (j - i - 1)。 这是有效的，因为一旦 j 违反了条件，所有其他索引也将违反它。 
3. 对 d 在 0 到 max(a) - min(a) 范围内进行二分查找。 对于每个中点，计算 count(mid)。 如果 count(mid) ≥ k，我们知道第 k 个最小差值 ≤ mid，因此我们将上限向下移动。 否则我们将下限上移。 这收敛到最小 d，使得至少 k 对满足条件。 
4. 获得精确阈值d后，我们需要隔离差值恰好为d的对。 我们运行类似的两指针扫描：对于每个 i，我们找到 j 使得 a[j] - a[i] ≤ d，并分别跟踪那些相等的对。 
5. 在扫描时，我们根据所需的排序规则维护最佳对，通常是字典顺序最小或最大的索引，具体取决于语句的抢七条件。 我们仅在差异与 d 完全匹配时更新候选项。 
6. 输出所选对。 

### 为什么它有效

 正确性依赖于谓词“a[j] - a[i] ≤ d”的单调性。 随着 d 的增加，有效对的集合只会扩大。 这使得计数函数不减，从而保证二分查找找到唯一的阈值，其中有效对的累积数量穿过 k。 每对都对这种差异排序贡献一次，因此第 k 个最小的差异必须位于该阈值处。 然后，第二遍将注意力限制在具有完全相同差异的对的等价类上，确保我们不会混合来自较小或较大差异类的对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_pairs(a, d):
    n = len(a)
    j = 0
    total = 0
    for i in range(n):
        if j < i + 1:
            j = i + 1
        while j < n and a[j] - a[i] <= d:
            j += 1
        total += (j - i - 1)
    return total

def find_pair_with_diff(a, d):
    n = len(a)
    j = 0
    best = None

    for i in range(n):
        if j < i + 1:
            j = i + 1
        while j < n and a[j] - a[i] <= d:
            if a[j] - a[i] == d:
                if best is None or (a[i], a[j]) < best:
                    best = (a[i], a[j])
            j += 1

        # j may have stepped one too far; fix for next i implicitly

    return best

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    lo, hi = 0, a[-1] - a[0]

    while lo < hi:
        mid = (lo + hi) // 2
        if count_pairs(a, mid) >= k:
            hi = mid
        else:
            lo = mid + 1

    d = lo
    ans = find_pair_with_diff(a, d)
    print(ans[0], ans[1])

if __name__ == "__main__":
    solve()
```排序步骤至关重要，因为计数和重构都依赖于右指针的单调移动。 计数函数确保每个左端点恰好扩展一个有效窗口一次，从而使每次检查的复杂性保持线性。 二分查找调用该函数 O(log(maxA)) 次。 

在重建步骤中，我们只接受差值等于最终阈值的对。 这可以避免意外选择满足 ≤ d 但严格较小的对，这将违反我们精确匹配第 k 类的要求。 

## 工作示例

 考虑输入数组 [1, 3, 4, 8]，k = 3。排序顺序中的两两差异为 2, 3, 4, 5, 7, 3。对它们进行排序会得到 2, 3, 3, 4, 5, 7，因此第 k 个最小差异是 3。 

我们追踪 d = 3 时的计数函数：

 | 我| j 运动 | 从 i | 开始对数
 | --- | --- | --- |
 | 0 | j 扩展到 2 (1→3→4) | 2 |
 | 1 | j 扩展到 3 (3→4) | 1 |
 | 2 | j 扩展到 3（4→8 立即停止）| 0 |
 | 3 | 没有对 | 0 |

 总数 = 3 对，匹配 k 个阈值。 

这证实二分查找正确地识别出 d = 3。 

现在考虑在 d = 3 的同一数组上进行重建。 

| 我| j | 差异| 行动|
 | --- | --- | --- | --- |
 | 0 | 1 | 2 | 跳过|
 | 0 | 2 | 3 | 候选人 |
 | 1 | 2 | 1 | 跳过|
 | 1 | 3 | 5 | 跳过|
 | 2 | 3 | 4 | 跳过|

 唯一有效的对是 (1, 4)，它被选中。 

这表明重建仅隔离精确差异对，而不是阈值下的所有对。

 ## 边缘情况

 一种重要的边缘情况是所有元素都相等。 对于输入 [7, 7, 7, 7]，每对的差值为 0。二分搜索立即收敛到 d = 0，因为 count(0) 等于 n(n−1)/2，并且重建必须正确返回任何有效的对。 该算法可以处理此问题，因为相等性检查显式捕获所有零差异对。 

另一种情况是当k对应于最大差值对时。 对于 [1, 100, 200]，与 (1, 200) 的最大差异为 199。 二分搜索自然扩展，直到 hi 达到 199，并且重建选择唯一实现该差异的对。 

最后一个微妙的情况是，当许多对具有相同的差异时，这可能会混淆平局决胜局。 由于重建显式地比较候选对并且仅更新精确匹配，因此即使存在多个有效答案，选择仍然是确定性的。
