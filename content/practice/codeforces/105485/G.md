 ## 解决方案
 ## 问题理解

 我们被要求计算一年内发生了多少奥运会比赛项目。 关键细节是有两个独立的赛事序列：夏季奥运会和冬季奥运会。 每一个都遵循严格的周期性模式。 

夏季奥运会有一个已知的最近参考年，2024 年，然后每四年重复一次。 冬季奥运会同样以 2022 年为基准年，并且每四年举办一次。 每一次发生，无论夏季还是冬季，都算作一个事件。 

给定从 L 到 R（含）的年份间隔，任务是计算有多少个夏季和冬季奥运会年份落在该范围内，并输出赛事总数。 

从竞争性编程的角度来看，约束非常小，因为 L 和 R 最多为 9999。这立即排除了跨大范围或复杂数据结构进行模拟的任何需要。 即使是 O(R − L) 扫描在技术上也会通过，因为间隔长度约为一万，但周期结构表明在恒定时间内有直接算术解决方案。 

一个天真的陷阱是逐年迭代并检查每年是否与任一序列匹配。 这在这里是安全的，但隐藏了预期的数学结构。 

一个更微妙的问题来自计算模块对齐时错误处理负偏移量。 由于我们正在对齐算术级数，因此不正确的楼层划分逻辑可以轻松跳过范围内的第一个有效事件。 例如，如果我们不小心计算第一年≥L，我们可能会错误地跳到下一个周期。 

考虑这样的情况：L = 2023，R = 2025。冬季奥运会将于附近的 2022 年和 2026 年举行。 区间内的正确答案只有2026？ 实际上 2026 年在外面，所以冬天贡献 0，夏天贡献 2024，所以答案是 1。有缺陷的实现可能会错误地将第一个冬季计算为 2026，然后错误处理包含，或更糟糕的是计算 2022 并意外地将其包含在内，即使它在 L 之前。 

正确的解决方案必须精确地计算等差数列与闭区间的交点。 

## 方法

 蛮力的想法很简单。 我们从 L 迭代到 R，并且每年我们检查它是否与两个级数中的任何一个匹配。 如果年份等于 2024 加 4 的倍数，或 2022 加 4 的倍数，则该年份有效。这是有效的，因为序列稀疏且易于使用模算术进行测试。 

此方法最多执行 10,000 次迭代，每次迭代进行 O(1) 检查，因此总共大约 20,000 次操作。 这在限制下是微不足道的，但它在概念上无法扩展并且模糊了周期结构。 

关键的观察是两个序列都是算术级数。 通过找到第一个不小于 L 的有效项和最后一个不大于 R 的有效项，然后将索引转换为计数，可以在恒定时间内计算算术级数中有多少项位于某个范围内。 

这将问题简化为两个独立的间隔计数，每个级数一个，然后将它们相加。

 | 蛮力 | O(R − L) | O(R − L) | O(1) | O(1) | 已接受 |
 | 最优算术计数 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理夏季和冬季序列，因为它们在残基类模 4 中不重叠。

1. 对于从 a 年开始执行步骤 4 的给定序列，计算 [L, R] 中有多少个有效项。 该序列为 a、a+4、a+8 等，因此每一项都由索引 k 确定，其中年份 = a + 4k。 
2. 计算最小索引 k，使得 a + 4k ≥ L。这需要求解 4k ≥ L − a。 我们将其转换为 k ≥ (L − a) / 4，然后取上限。 我们使用 k_low = (L − a + 3) // 4 的整数算术来代替浮点数学。+3 移位可确保正差和负差的正确上限行为。 
3. 计算最大索引 k，使得 a + 4k ≤ R。使用整数下限除法得出 k_high = (R − a) // 4。 
4. 如果 k_high ≥ k_low，则有效项的数量为 k_high − k_low + 1。否则，区间内没有有效项。 
5. 对 a = 2024（夏季）和 a = 2022（冬季）应用相同的计算，然后将两个结果相加。 

除法技巧起作用的原因是两个序列都是完美对齐的算术级数，没有间隙或不规则之处。 索引转换将问题从多年来的推理转换为对序列中整数位置的推理。 

### 为什么它有效

 每个奥林匹克序列都可以一对一映射到整数索引 k ≥ 0。转换年份 = a + 4k 保留顺序和间距。 任何区间[L，R]都对应于一个索引区间[k_low，k_high]，并且原始范围内的每个有效年份恰好对应于该索引区间中的一个整数。 由于没有两个不同的 k 映射到同一年份，因此计算索引相当于计算年份，这保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count(a, L, R):
    k_low = (L - a + 3) // 4
    k_high = (R - a) // 4
    if k_high < k_low:
        return 0
    return k_high - k_low + 1

L, R = map(int, input().split())

ans = count(2024, L, R) + count(2022, L, R)
print(ans)
```实现的核心是将模运算条件转换为直接索引范围的辅助函数。 唯一微妙的一点是公式`(L - a + 3) // 4`，它充当正值和负值的上限划分。 这可以避免在尝试“手动调整”第一个有效项时经常出现的相差一错误。 

该解决方案完全避免了循环，因此它可以在恒定时间内运行，并且即使输入范围大得多，也很稳健。

 ## 边缘情况

 常见的边缘情况是 L 刚好在有效事件年份之后。 例如，L = 2025，R = 2027。夏季事件将在接下来的 2028 年发生，冬季事件已在 2026 年发生。正确答案是 1。 

对于夏季，k_low = (2025 − 2024 + 3) // 4 = 1，k_high = (2027 − 2024) // 4 = 0，因此该函数正确返回 0，因为 k_high < k_low。 对于冬季，k_low = (2025 − 2022 + 3) // 4 = 1，k_high = (2027 − 2022) // 4 = 1，恰好给出 2026 年的一个事件。 

当 L 远早于基准年时，会出现另一个微妙的情况。 例如，L = 2000，R = 2005。公式仍然可以正确运行，因为负差可以通过楼层划分自然处理。 对于夏季，k_low 变为 0，这意味着 2024 年是第一个候选，但由于 R 较小，因此不计算夏季事件。 冬天同样没有贡献任何东西。 该算法避免了对“开始年份之前”情况的任何条件修正。 

这些案例证实，基于索引的公式可以统一处理负偏移和正偏移，这是该解决方案可靠的主要原因。
