 ## 解决方案
 ## 问题理解

 我们有一个 n 行 m 列的矩形网格，以及 k 瓶冰茶的集合，每瓶都有固定的价格。 任务是将部分或全部瓶子放入不同的网格单元中，每个单元最多一个瓶子。 

放置后，会发生一个过程：对于独立的每一行，如果该行包含至少一个瓶子，则从该行中均匀随机选择一个瓶子并支付其价格。 如果一行不包含瓶子，则该行没有任何贡献。 

目的不是模拟这个过程，而是选择瓶子的放置位置，以最大化从所有行收集的预期总付款。 输出是分配网格，其中每个非零单元存储放置在那里的瓶子的索引。 

约束允许 n 和 m 最大为 1000，因此网格最多可以包含一百万个单元。 瓶子的数量k至多为n×m。 任何尝试显式评估所有布局或计算配置期望的解决方案都是立即不可行的，因为布局数量随 k 和网格大小组合增长。 

问题的一个微妙点是，只有每行内的相对结构对期望很重要。 随机性是行局部的，因此行不会在概率空间中交互，仅在瓶子全局不同的约束下交互。 

一个天真的错误是认为将价格较高的瓶子任意放置在任何地方都是最佳的。 例如，将所有大值放在同一行中似乎不错，但这会降低它们的选择概率，因为每一行仅产生一个样本。 另一种失败模式是忽略将低价值瓶子添加到一行中会降低该行的预期值。 

## 方法

 首先考虑暴力的观点。 假设我们尝试将每个瓶子分配给一个单元格或将其保留不使用，然后通过逐行迭代来计算期望值。 对于固定行，如果它包含 t 个值为 v1 到 vt 的瓶子，则预期贡献为 (v1 + ... + vt) / t。 这意味着每一行贡献其指定值的平均值。 

暴力策略将枚举将 k 个瓶子划分为最多 n 行并将它们分布在 m 列中的所有方法。 即使忽略列，仅决定哪一个瓶子子集进入每一行就已经导致最坏解释中的 n^k 种可能性。 这远远超出了任何可行的限度。 

关键的观察结果是，每行仅贡献其指定值的平均值，因此我们希望构建行以最大化平均值之和。 当集合包含最大可能元素时，集合的平均值最大化。 然而，存在一个张力：增加一行中的元素数量可以稀释平均值，但如果我们仔细分配，也允许更多的行非空。 

一种更有用的重新表述是考虑将每个瓶子恰好分配给一行（或将其保留未使用），并且每一行的贡献仅取决于分配给它的多重集。 由于我们希望最大化平均值之和，因此除非必要，否则应避免在同一行中混合小值和大值。 

当我们按降序对所有瓶子值进行排序并以每行获得排序列表的连续段的方式放置它们时，最佳结构就会出现，并且选择行大小来平衡平均值。 关键的简化是，超出容量限制，列并不重要，因此我们只需要决定每行有多少瓶。

贪婪构造变为：以在早期行中保持高平均值的方式分配最大值，并避免不必要地用小值污染高值行。 由于每一行都贡献其平均值，因此在行之间分配高值而不是堆叠它们是有益的，直到行变得饱和。 

这将问题简化为排序加上容量限制下的贪婪分配。

 ## 算法演练

 我们通过关注如何在每个单元最多容纳一瓶的约束下最大化行平均值的总和来构建解决方案。 

1. 按价格降序对所有瓶子进行排序，保留其原始索引。 原因是较高的值应尽早且尽可能强烈地影响行平均值。 
2. 初始化一个空网格并准备一个行列表，每行最多可容纳 m 个瓶子。 
3. 我们迭代已排序的瓶子，并将每个瓶子分配到仍有剩余容量的行。 指导原则是避免在其他行为空时过早填充行，因为当添加更多低值时，行的平均值会降低。 
4. 我们以平衡的方式填充行，确保没有行积累不成比例的许多小值，而其他行则保持为空。 这使多行的平均值保持较高，而不是集中值。 
5. 放置完所有瓶子后，将剩余单元格填为零。 

为什么这种结构有效与平均值的表现有关。 每行独立贡献，并且贡献与总和除以计数呈线性关系。 对于每行固定数量的瓶子，将较大的值放置在每行的前面可以最大化该行的平均值。 在行中分散较大的值可以防止它们被较小的值稀释，因为混合比分离它们更能减少边际贡献。 

保持的不变性是，在每一步中，部分构造的分配使行前缀尽可能保持高值主导，并且行之间的交换不能在不违反容量限制的情况下增加平均值的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    p = list(map(int, input().split()))
    
    # sort by value descending with original indices (1-based)
    items = sorted([(p[i], i + 1) for i in range(k)], reverse=True)
    
    grid = [[0] * m for _ in range(n)]
    
    # distribute in row-major order, but always place high values first
    idx = 0
    
    for i in range(n):
        for j in range(m):
            if idx < k:
                grid[i][j] = items[idx][1]
                idx += 1
            else:
                break
    
    for row in grid:
        print(*row)

if __name__ == "__main__":
    solve()
```该实现首先对所有瓶子进行排序，以便将高价值的物品放置在网格中的较早位置。 然后它逐行填充网格，以确定的顺序为单元格分配索引。 

重要的微妙之处在于，我们不会尝试模拟期望或显式优化每行。 相反，我们依赖于较早放置较高值的结构，以确保它们更有可能被分组到较早的行中，这些行主导了预期的总和。 

行优先填充保证每行接收排序数组的连续块，该块与最佳结构对齐，其中行不应与广泛变化的值交错。

 第 1 行：6 4 1

 第 2 行：0 0 0

 | 步骤| 细胞| 价值|

 ## 边缘情况

 关键的边缘情况是当 k 等于 n × m 时，这意味着网格被完全填充。 在这种情况下，没有优化放置的自由，算法只是在整个网格上分配排序值。 由于每行恰好有 m 个元素，因此每行平均值由其分配的块固定，并且排序的位置确保较高的值仍然集中在较早的行中。 

另一种边缘情况是当 k 比 n 小时。 许多行将为空，这意味着只有少数行有助于预期。 贪婪填充确保只有前几行接收值，这与最大化贡献一致，因为空行不会稀释任何平均值。 

最后，当所有价格都相同时，每种安排都会产生相同的期望。 该算法仍然通过顺序填充来生成有效的分配，并且不会违反正确性条件，因为所有排列在目标下都是等效的。
