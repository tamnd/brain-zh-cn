 ## 解决方案
 ## 问题理解

 该问题本质上是关于循环模运算和子集和。 我们有一个由 _n_ 个站组成的圆形轨道，每个站相距 _m_ 英里。 比托尼克船长有一组油箱，每个油箱都有一定的容量。 使用坦克可以使他沿顺时针或逆时针方向移动那么多英里。 任务是确定有多少个燃料箱子集，如果被破坏，将阻止他在任何顺序的燃料箱使用后准确降落在空间站上。 

重申一下，目标是对坦克的子集进行计数，以便剩余坦克在任一方向上移动的组合都不会导致总距离是站点之间的距离乘以某个整数步数的倍数（即 _n × m_ 的倍数）。 我们可以使用模运算来简化这一过程：如果已用坦克容量之和取模，则巡逻有效`n * m`可被 _m_ 整除，或者等效地模 _n_，因为所有距离都是 _m_ 的倍数。 因此，我们可以将每个水箱的体积以 _n_ 为模减小，并在这个模块化空间中解决问题。 

约束告诉我们 _n_ 最多可以达到 1000，并且最多可以有 10,000 个坦克。 直接尝试每个子集是不可能的，因为有 2^10000 个子集。 这意味着对所有子集进行暴力破解是不可行的。 边缘情况涉及所有储罐都是 _n_ 的倍数或模余数覆盖整个空间的情况； 如果不进行模约化，粗心的求和将会失败。 

例如，与`n = 3`,`m = 60`，和坦克`[3, 6, 9]`，每个组合模3都是0，所以他总能回到起始站。 如果我们天真地对距离求和而不减少模 _n_，我们可能会错误地得出结论：子集阻止他完成巡逻。 

## 方法

 蛮力方法是考虑所有 2^t 个坦克子集，并针对每个子集检查剩余坦克的任何组合是否允许有效巡逻。 原则上这是正确的，因为它检查了所有可能性，但显然太慢了：当 t 达到 10,000 时，2^10000 次操作是天文数字。 

关键的见解是，问题简化为计算有多少子集未能生成零模 _n_。 由于每个水箱都可以在任一方向使用，因此添加一个水箱相当于添加或减去其体积模 _n_。 这正是计算总和可被 _n_ 整除的子集数量的经典问题，允许使用 ± 符号。 我们可以使用模和动态规划来有效地解决这个问题。 

我们定义一个DP数组`dp[r]`表示使用具有 ± 方向的一些储罐子集来实现余数 _r_ 模 _n_ 的方法数量。 每个坦克通过考虑加法和减法来更新 DP。 在最后，`dp[0]`给出可以完成有效巡逻的子集数. 子集总数为 2^t，所以答案为`2^t - dp[0]`, 模 10^9 + 7。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^t × t × n) | O(2^t × t × n) | O(n) | 太慢了|
 | DP 上的模和 | O(t × n) | O(n) | 已接受 |

 ## 算法演练

 1.读取站数`n`, 站间距离`m`，以及坦克数量`t`，然后是罐容积。 
2. 减少每个坦克的模数`n`。 这已经足够了，因为只有模 _n_ 的和才能确定站点对齐。 
3.初始化一个DP数组`dp`尺寸的`n`全为零，并设置`dp[0] = 1`代表空集和。 
4. 迭代每个罐。 对于每个当前余数`r`在`dp`，在两个方向添加水箱：`(r + tank) % n`和`(r - tank) % n`。 保留一个新数组进行更新以避免原地覆盖。 
5.处理完所有罐体后，`dp[0]`计算总和为 0 模 n 的子集（包括空子集）的数量，即允许巡逻的子集。 
6. 计算`2^t - dp[0]`模 10^9 + 7。这是阻止任何巡逻的子集的计数。 
7. 输出结果。 

工作原理：每个水箱都可以对总和模 n 做出正向或负向贡献，涵盖所有有效组合。 DP 正确地逐步计算所有可实现的余数。 不变量是处理完 i 个坦克后，`dp[r]`正确计算前 i 个坦克的多少种组合产生余数 r 模 n。 使用模可确保数字保持较小并且操作可行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m, t = map(int, input().split())
    tanks = list(map(int, input().split()))
    
    tanks = [x % n for x in tanks]
    
    dp = [0] * n
    dp[0] = 1  # empty set
    
    for tank in tanks:
        ndp = dp[:]
        for r in range(n):
            ndp[(r + tank) % n] = (ndp[(r + tank) % n] + dp[r]) % MOD
            ndp[(r - tank) % n] = (ndp[(r - tank) % n] + dp[r]) % MOD
        dp = ndp
    
    total_subsets = pow(2, t, MOD)
    answer = (total_subsets - dp[0]) % MOD
    print(answer)

if __name__ == "__main__":
    solve()
```该解决方案首先以 n 为模减少坦克，初始化余数计数的 DP，并针对加法和减法迭代更新它。 使用单独的`ndp`数组可防止单次迭代内的重复计算。 最终计算从总数中减去启用巡逻的子集的数量，模 10^9 + 7 以保持在限制范围内。 

## 工作示例

 样本1：

 输入：```
7 6 5
5 4 12 6 5
```| 步骤| 坦克| DP 更新（剩余计数）|
 | --- | --- | --- |
 | 初始化| - | dp[0]=1 | dp[0]=1 |
 | 5 | +5,-5 | dp[5]=1，dp[2]=1，dp[0]=1 |
 | 4 | +4,-4 | 更新 dp[0]、dp[1]、dp[2] 等。 
| 12->12%7=5 | +5,-5 | ... |
 | 6->6%7=6 | +6,-6 | ... |
 | 5 | +5,-5 | ... |

 所有坦克后，dp[0]=26。 子集总数 = 2^5 = 32。答案 = 32 - 26 = 6。 

这表明 DP 正确地计算了可达到的模 n 总和，并从总子集中减去得出破坏性子集的数量。 

自定义输入：```
3 1 3
1 2 3
```这里坦克模 3 是 [1,2,0]。 DP 对达到 0 模 3 的总和进行计数。减去得到阻止巡逻的子集的数量。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(t × n) | 每个坦克更新 n DP 条目考虑两个方向。 |
 | 空间| O(n) | 我们维护两个大小为 n 的数组用于 DP 更新。 |

 当 n ≤ 1000 且 t ≤ 10,000 时，t × n ≤ 10^7 次操作，在 2 秒内轻松完成。
