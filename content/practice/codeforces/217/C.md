 ## 解决方案
 ## 问题理解

 该公式描述了由常量构建的布尔函数`0`和`1`, 占位符`?`，以及运算符 AND、OR 和 XOR。 

每个`?`对应于植物的一片叶子。 在实验过程中，我们选择将哪个菌落放置在每片叶子上。 如果殖民地`i`具有物种价值`x_i ∈ {0,1}`，然后根据这些值计算公式并返回`0`或者`1`。 

科学家们可以进行任意数量的实验。 关于未知菌落类型的唯一承诺是，并非所有菌落都具有相同的物种。 

问题是给定的公式是否强大到足以确定每个有效物种分配的每个群体的确切物种。 

输入大小立即排除了任何构建真值表的方法。 公式长度可以达到一百万个字符，所以即使是一个`O(length × log length)`解决方案不必要地昂贵。 我们需要对表达式进行线性扫描，并且每个符号只需进行恒定量的工作。 

问题的微妙之处在于公式可能包含许多不同的内容`?`叶子，但科学家可以在每片叶子上放置相同的菌落。 事实证明，这一观察结果完全表征了何时可以恢复。 

考虑公式`(?^?)`。 

如果我们在两片叶子上放置相同的菌落，结果总是`0`。 该实验没有提供有关该群体物种的信息。 事实上，这两个任务```
colony A = 0, colony B = 1
```和```
colony A = 1, colony B = 0
```产生完全相同的信息，因此无法唯一确定物种。 正确答案是`NO`。 

现在考虑```
(?|0)
```放置菌落`i`每片叶子上的值都准确地计算出该菌落的值。 每个群体的一次实验立即揭示了所有物种，所以正确的答案是`YES`。 

另一个容易犯的错误是分析完整的多变量函数。 真正的问题不在于该公式是否区分不同的叶子分配。 科学家们自己控制叶子分配模式。 关键的实验是在各处放置相同的菌落，这将整个公式简化为单个变量的函数。 

## 方法

 暴力的观点是将公式视为其所有叶子的布尔函数。 人们可以尝试描述每一种可能的实验，并确定所得到的函数族是否唯一地识别所有菌落分配。 

这很快就变得不可能了。 该公式可能包含数十万个叶子，因此即使存储真值表也无济于事。 可能的叶分配数量是指数级的。 

关键的观察结果是，科学家们可能会在每片叶子上放置相同的菌落。 

假设每个`?`公式中得到相同的值`x`。 整个表达式折叠成一个单变量布尔函数```
g(x)
```由于一个变量的布尔函数只有四种可能性，因此简化公式必须是以下之一```
0
1
x
!x
```如果`g(x) = x`或者`g(x) = !x`，然后对菌落进行一次实验`i`放置在每片叶子上揭示了菌落的种类`i`。 对所有菌落重复此操作可恢复整个分配。 

如果`g(x)`是恒定的，那么无论物种如何，在任何地方使用相同的菌落总是给出相同的答案。 该公式从未提供区分 sp 的绝对参考
