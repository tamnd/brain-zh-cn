 ## 解决方案
 ## 问题理解

 我们正在研究与足球表现相关的简化财务模型。 有$P$教师，每个月都有固定工资$R$。 内马尔进球$G$一个月内的目标，每个目标都有固定的金额$X$应该从每个老师的工资中扣除并转给内马尔。 

关键的限制是教师的工资不能为负数。 如果重复扣除会使教师的工资减少到零以下，则扣除额将受到限制，以便工资停止为零。 

任务是计算内马尔收到的总金额$G$目标，汇总到所有教师身上。 

从约束条件来看，$P$可以大到$10^8$， 尽管$R$至多是$3000$,$G$最多$40$， 和$X$最多$2000$。 这立即表明任何迭代教师的方法都是不可能的，因为$P$独自使$O(P)$操作不可行。 

重要的结构是每个老师的行为都是相同的。 每个人都独立贡献，所以答案是$P$是单个老师的贡献的几倍。 

当我们忽略零上限时，就会犯天真的错误。 例如，如果$R = 10$,$G = 5$， 和$X = 3$，然后朴素乘法给出$15$按教师人数扣除，但工资只允许$10$被采取。 因此，正确的每位教师贡献是$10$， 不是$15$。 

当每个目标不正确地应用上限时，就会发生另一个微妙的失败。 例如，与$R = 10$,$G = 2$,$X = 7$，一个天真的方法可能会减去$7$总共两次$14$，然后上限为$10$，这在这里很好，但从概念上讲，正确的推理是总扣除额是$G \cdot X = 14$，然后上限为$R$。 

## 方法

 强力解释将模拟每位教师的每个目标，逐步减少工资，并在工资达到零时停止。 这在概念上很简单，因为它直接遵循具有下限的重复演绎规则。 然而，这需要迭代所有$P$老师和大家$G$目标，导致$P \cdot G$运营。 在最坏的情况下这是$10^8 \cdot 40 = 4 \cdot 10^9$更新，这远远超出了可行的限度。 

关键的观察是所有教师都是相同且独立的。 我们可以以封闭形式计算每位教师的总扣除额，而不是进行模拟。 每个老师都输了$X$每个目标，就这样结束了$G$目标 预期总数是$G \cdot X$。 然而，最大可能损失的界限为$R$，因为工资不能低于零。 因此，每个老师的贡献是准确的$\min(R, G \cdot X)$。 乘以$P$给出了最终答案。 

这将问题简化为常数时间算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(P·G)| O(1) | O(1) | 太慢了 |
 | 直接配方| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取数值$P$,$R$,$G$， 和$X$。 这些定义了相同贡献者的数量、他们的工资上限、事件数量以及每个事件的扣除额。 
2. 将每位教师的预期扣除总额计算为$G \cdot X$。 这代表了如果没有工资限制会发生什么。 
3. 将此值与$R$，因为没有老师可以贡献超过他们的全额工资。 拿$\min(R, G \cdot X)$。 
4. 将每位教师的贡献乘以$P$以获得内马尔收到的总金额。 
5. 输出结果。 

核心推理是每个教师的行为都是独立且相同的，因此一旦知道每个教师的贡献，扩展到整个群体就是线性且精确的。 

### 为什么它有效

 每个老师的工资演变只取决于自己的扣除，从不与其他人互动。 超过$G$相同的操作，尝试的总扣除是相加的。 唯一的约束是硬上限$R$，它截断了每位教师的总贡献。 这使得每个教师的贡献完全由单个分钟操作决定，并且对所有教师进行求和可以保持正确性，因为不存在交叉依赖性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    P = int(input())
    R = int(input())
    G = int(input())
    X = int(input())

    per_teacher = min(R, G * X)
    print(P * per_teacher)

if __name__ == "__main__":
    solve()
```直接按照推导公式实现。 唯一微妙的一点是确保乘法$G \cdot X$发生在分钟之前，因为上限适用于累计扣除总额，而不是每个进球。 Python 对大整数的支持使得溢出不再是问题，即使在$P$很大。 

## 工作示例

 考虑一个输入，其中$P = 3$,$R = 10$,$G = 2$,$X = 3$。 每位教师的预期扣除额为$G \cdot X = 6$，低于工资上限。 

| 步骤| 价值|
 | ---| ---|
 | 普 | 3 |
 | 右 | 10 | 10
 | G·X| 6 |
 | 每个老师| 分钟(10, 6) = 6 |
 | 总计 | 18 | 18

 这显示了没有触发工资上限的不受限制的情况。 

现在考虑$P = 2$,$R = 8$,$G = 3$,$X = 5$。 每位教师的预期扣除总额为$15$，但工资限制了它。 

| 步骤| 价值|
 | ---| ---|
 | 普 | 2 |
 | 右 | 8 |
 | G·X| 15 | 15
 | 每个老师| 分钟(8, 15) = 8 |
 | 总计 | 16 | 16

 这表明了工资上限具有约束力时的饱和行为。

 ## 边缘情况

 一个重要的边缘情况是预期扣除额小于工资。 例如，与$P = 5$,$R = 100$,$G = 2$,$X = 10$，每位教师的总数为$20$。 该算法计算$\min(100, 20) = 20$，乘以得到$100$。 不触发上限，所有教师均全额贡献计算出的金额。 

另一个极端情况是预期扣除额大幅超过工资。 例如，$P = 4$,$R = 7$,$G = 3$,$X = 10$给出$G \cdot X = 30$，但每个老师的上限是$7$。 结果变成$28$。 该算法正确地将重复的溢出合并为单个上限操作。 

最后一个边缘情况是$P$是非常大的，比如$10^8$。 由于最小运算后计算减少为单个乘法，因此没有教师迭代，并且结果保持准确和高效。
