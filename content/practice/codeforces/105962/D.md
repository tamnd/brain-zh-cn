 ## 解决方案
 ## 问题理解

 我们在平面上按固定顺序给出四个点：A、B、C、D。任务是确定按该顺序连接它们（包括从 D 回到 A 的边）是否形成一个几何正方形。 

这不是一个我们可以任意重新排序的“四点集”问题。 顺序很重要，因为边明确是 AB、BC、CD 和 DA。 所以我们正在检查这个精确的循环是否描述了一个正方形。 

每个点的整数坐标都在一个适度的范围内，因此所有几何计算都可以使用整数安全地完成。 由于坐标的大小高达 10^4，平方距离可以轻松地适合 64 位整数，而且我们永远不需要浮点运算。 

一个幼稚的错误是将这四个点视为无序集，并尝试通过对距离或角度进行排序来猜测正方形。 这会失败，因为有效的平方取决于循环顺序。 例如，如果排序正确，相同的四个点可以形成正方形，但如果排列正确，则变成自相交形状或非正方形四边形。 

另一个常见的陷阱是依赖浮点几何，尤其是角度比较。 由于精度误差，这是不必要且有风险的。 一切都可以使用点积和平方长度来精确表达。 

一个微妙的边缘情况是当这些点形成菱形而不是正方形时。 所有边都可以相等，但角度不是 90 度。 另一种是不是正方形的矩形，其中相对边相等但相邻边不同。 两者都必须被拒绝。 

## 方法

 蛮力的想法是考虑四个点的所有排列，将它们解释为一个循环，并测试是否有任何排序形成一个正方形。 对于每个排列，我们将计算所有四个边长和角度。 因为有4个！ = 24 种排列，这是每个测试用例的持续工作，并且仍然可行。 

然而，这种方法在概念上是浪费的，因为问题已经确定了顺序。 我们不允许重新安排积分； 我们必须直接验证给定的周期。 

关键的观察结果是，当且仅当满足两个条件时，四边形才是正方形：所有四个边都相等，并且至少一个角是直角。 用向量术语来说，如果 AB、BC、CD、DA 是边，那么我们要求相邻边之间的平方长度相等且正交。 

这将整个问题简化为计算四个向量、四个平方长度和一些点积。

 ## 算法演练

 我们直接使用由连续点形成的向量。 

1. 构造四个边向量AB、BC、CD 和DA。 每个向量都是通过减去坐标来计算的，例如 AB = B − A。这以适合整数算术的形式对方向和长度进行编码。 
2. 计算所有四个边的长度平方。 平方长度避免了平方根并保持一切精确，因为比较长度只需要相等。 
3. 验证所有四个平方长度是否相等。 如果任何边不同，则该形状不能是正方形，因为正方形有四个全等的边。 
4. 选取一个顶点，例如点 B，并计算相邻边 AB 和 BC 的点积。 点积为零相当于 B 处的角度为 90 度。 
5. 检查AB 和BC 是否垂直。 如果不是，即使所有边都相等，该图形也不是正方形，因为它只是菱形。 
6. 如果两个条件都成立，则输出“SIM”，否则输出“NAO”。 

仅检查一个角度背后的原因是，在所有边相等的四边形中，有一个直角会迫使所有角度都是直角，这充分体现了正方形的特征。 

### 为什么它有效

该算法强制所有边全等，从而将形状限制为菱形。 在菱形中，所有顶点在旋转 180 度的情况下对称，并且所有角度成对相等。 如果一个角是90度，则所有角都必须是90度，将菱形变成正方形。 因此，相等的边长加上单个正交邻接条件足以保证完整的正方形结构，并且固定顺序确保我们验证正确的循环而不是搜索循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def sq_len(ax, ay, bx, by):
    dx = bx - ax
    dy = by - ay
    return dx * dx + dy * dy

def dot(ax, ay, bx, by, cx, cy):
    # AB · BC where A->B->C
    return (bx - ax) * (cx - bx) + (by - ay) * (cy - by)

def solve():
    pts = [tuple(map(int, input().split())) for _ in range(4)]
    A, B, C, D = pts

    ax, ay = A
    bx, by = B
    cx, cy = C
    dx, dy = D

    d1 = sq_len(ax, ay, bx, by)
    d2 = sq_len(bx, by, cx, cy)
    d3 = sq_len(cx, cy, dx, dy)
    d4 = sq_len(dx, dy, ax, ay)

    if not (d1 == d2 == d3 == d4):
        print("NAO")
        return

    if dot(ax, ay, bx, by, cx, cy) != 0:
        print("NAO")
        return

    print("SIM")

if __name__ == "__main__":
    solve()
```该实现首先加载四个点并按给定顺序计算每个连续边的平方距离。 相等性检查确保我们正在处理菱形候选者。 顶点 B 处的点积测试强制 AB 和 BC 之间形成直角。 我们不需要显式检查其他角度或对角线属性，因为这些属性是由闭环中的等边和一个正交角的组合所隐含的。 

所有计算都是整数，完全避免了精度问题。

 ## 边缘情况

 一种重要的边缘情况是正方形旋转时。 对于 (1,0)、(2,1)、(1,2)、(0,1) 等输入，该算法仍然计算第二个点的等平方长度和零点积，因此它正确返回“SIM”。 这证实了该方法是旋转不变的。 

另一种情况是当点形成一个不是正方形的矩形时，例如(0,0)、(1,0)、(2,1)、(1,1)。 这里边长立即不同，因此算法会拒绝它而不需要角度检查。 

看起来退化的情况是共线或接近共线的排序，如 (0,0)、(1,1)、(2,2)、(3,3)。 即使距离可能显示部分对称，但至少一侧比较失败或点积非零，从而确保拒绝。
