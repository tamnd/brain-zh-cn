 ## 解决方案
 ## 问题理解

 我们在房间的角落里立着一个长方形的柜子。 它沿墙的两个尺寸是`a`和`b`。 一扇长度的门`d`安装在一定距离处`l`从角落里。 当门打开时，我们需要确定它是否可以到达两个房间墙壁之一而不接触柜子。 

几何形状是从上面考虑的。 柜子占据了靠近角落的一个矩形，而门则绕其铰链旋转。 只有当门最终停在墙上并且在任何一点都不接触柜子时，门才是成功的。 恰好碰触柜子的角落也算失败。 输入由四个正整数组成`a`,`b`,`d`， 和`l`，最多包含所有值`30000`和`a <= l`。 所需的输出是`Yes`是否存在至少一种到达墙壁的安全方法，以及`No`否则。 

界限很小，但这并不意味着我们应该搜索位置或角度。 没有离散的可能的门角度集，因此模拟必须近似连续的几何过程。 预期的解决方案将整个问题简化为恒定数量的算术运算。 输入中只有四个数字，`O(1)`解决方案很容易足够快，而真正关心的是获得几何不等式及其严格性。 

有两种不明显的边界情况。 

首先，禁止触摸柜子。 例如，```
1
1
1
2
```给出```
No
```在这里，门可以准确地到达最近的墙壁`a + d = l`。 它的端点恰好位于相关的柜子边界，因此门接触柜子。 粗心的实现使用`a + d <= l`会错误打印`Yes`。 官方示例明确使用了这种情况。 

其次，如果相应的轨迹穿过柜子，则仅有足够的长度到达墙壁是不够的。 例如，```
4
3
10
8
```给出```
No
```尽管门的长度足以到达墙壁，但极限轨迹穿过柜子，因此门在到达墙壁之前就接触到了柜子。 这是第二个官方样本。 

当`a = l`。 在这种情况下，数量`l - a`变为零。 穿过远角的轨迹在相关边界处变得垂直，因此远墙公式不能除以`l - a`。 自从`a + d < l`也是不可能的，答案一定是`No`。 

## 方法

 字面几何模拟将尝试旋转门并确定它何时第一次接触墙壁或橱柜。 这不是一个有用的计算模型，因为门角度是连续的。 采样角度可能会错过精确的切线位置，尤其是在仅触摸柜子就改变答案的情况下。 增加采样密度只会使程序变慢，而不会将近似解转化为精确解。 

更直接的暴力解释是分别考虑两个可能的墙。 如果门避开了柜子，则它的第一次成功接触必须是与靠近门的墙壁或对面的墙壁。 只有两种几何可能性，因此没有大的搜索空间可供枚举。 真正的优化不是减少案例数量，而是为每个案例导出精确的不等式并避免浮点计算。 

对于较近的墙，几何形状特别简单。 门有长度`d`，而内阁占据`a`沿相关方向的门和拐角之间的单元。 要越过柜子并到达较近的墙壁而不接触它，可用距离`l`必须严格大于它们的总长度。 因此条件是`a + d < l`。 

严格的不等式直接由碰撞规则得出。 相等是指门端点准确到达柜体边界。 

较远的墙壁需要关键的几何观察。 让`x = l - a`。 

在限制配置中，门必须穿过机柜的远角。 从门的起点到柜角的水平位移为`x`垂直位移为`b`。 根据毕达哥拉斯定理，该线段有长度`sqrt(x² + b²)`。 

同一条线继续下去，直到到达对面的墙壁。 由于其水平分量从`x`到`l`，从门铰链到那堵墙的整个段都有长度`l * sqrt(x² + b²) / x`。 

只有当门的长度严格大于该值时，门才能安全地到达更远的墙壁。 严格的不平等再次很重要，因为平等意味着门恰好到达橱柜角，因此会刮伤它。 这是官方比赛分析中使用的几何推导。 

我们可以使用浮点平方根来评估这种情况，但没有理由将数值精度引入精确整数问题。 开始于`d > l * sqrt(x² + b²) / x`并使用`x > 0`，我们可以将正两边平方并乘以`x²`。 条件变为`d² * x² > l² * (x² + b²)`。 

所有数量都是非负的，因此平方不会改变不等式的真实性。 Python 整数也具有任意精度，因此溢出不是问题。 

这两个案例是独立的。 如果近壁条件或远壁条件成功，则答案为`Yes`。 否则答案是`No`。

 ## 算法演练

 1. 读取四个维度`a`,`b`,`d`， 和`l`。 这些描述了柜子、门以及从门到房间角落的距离。 
2. 检查是否`a + d < l`。 如果这是真的，则门可以在其端点到达柜子之前到达较近的墙壁，因此答案立即`Yes`。 平等被刻意拒绝，因为碰柜子就被认为是碰撞。 
3. 计算`x = l - a`。 这是从门铰链到柜子远角的水平距离。 
4. 如果`x = 0`，由于限制线的水平分量为零，因此无法评估较远的墙结构。 近壁条件已经失效，所以答案是`No`。 
5. 比较`d² * x² > l² * (x² + b²)`。 

这是条件的平方版本，即门严格长于从铰链到穿过柜角的较远墙壁的线。 
6. 如果比较为真，则打印`Yes`。 否则打印`No`。 

原理：门在不撞到柜子的情况下完成打开的唯一安全方法是到达较近的墙壁或到达较远的墙壁。 第一种可能性的特点是`a + d < l`。 对于第二种可能性，在柜子安全的一侧能够到达较远墙壁的最短门长度是穿过柜子远角的线，其长度为`l * sqrt((l-a)²+b²)/(l-a)`。 严格较长的门到达墙壁时不会接触到那个角落，而相同或更短的门则无法安全地到达墙壁。 由于精确检查了两种几何可能性，算法返回`Yes`正是在存在安全开口的时候。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())
    d = int(input())
    l = int(input())

    # The door can pass to the nearer wall.
    if a + d < l:
        print("Yes")
        return

    x = l - a

    # No room remains for the far-wall trajectory.
    if x == 0:
        print("No")
        return

    # Compare:
    # d > l * sqrt(x^2 + b^2) / x
    #
    # All quantities are positive, so we can square safely:
    # d^2 * x^2 > l^2 * (x^2 + b^2)
    left = d * d * x * x
    right = l * l * (x * x + b * b)

    print("Yes" if left > right else "No")

if __name__ == "__main__":
    solve()
```第一个比较直接实现了近壁情况。 不涉及平方根，并且严格`<`这是至关重要的，因为平等意味着门接触柜子。 

变量`x`代表`l - a`，从门铰链到远柜角的水平距离。 什么时候`x`为零，除以它无效。 更重要的是，此配置中没有有效的远墙逃逸，因此返回`No`是正确的几何行为。 

最终的比较是故意仅使用整数乘法来编写的。 原始几何条件包含平方根和除法，但两者都可以消除，因为涉及的每个量都是非负的。 严格的`>`必须保持严格。 替换为`>=`会错误地接受精确到达橱柜角的门。 

最大的乘积约为`30000^4`， 大约`8.1 * 10^17`，适合有符号 64 位整数。 无论如何，Python 整数都是无界的，因此即使无需手动推理机器溢出，实现也是安全的。

 ## 边缘情况

 第一个重要的边缘情况是较近的墙相等。 和```
1
1
1
2
```我们有`a + d = 2`和`l = 2`。 测试`a + d < l`失败。 门无法在不接触橱柜边界的情况下穿过它，因此算法打印`No`。 使用`<=`会悄无声息地将碰撞变成成功的开局。 

第二个边缘情况是一扇足够长的门，只需接触柜子即可到达较远的墙壁。 考虑```
4
3
10
8
```这里`x = 4`。 两个数量的平方都是`1600`，所以远墙比较`left > right`失败。 等式表示门正好穿过柜角。 由于禁止接触，`No`是正确的。 

远墙公式的一个有用的精确相等情况是```
2
3
10
4
```这里`x = l-a = 2`， 尽管`b = 3`， 所以`sqrt(x²+b²) = 5`。 极限长度为`l * 5 / x = 4 * 5 / 2 = 10`。 

门有精确的长度`10`，因此它到达橱柜角并接触它。 整数比较两边相等并打印`No`。 

如果我们将门的长度增加一倍，```
2
3
11
4
```极限长度仍然是`10`，但现在`d = 11`。 不等式是严格的，所以门可以到达更远的墙壁而不接触柜子，答案就变成了`Yes`。 

最后，考虑边界`a = l`， 例如```
1
1
1
1
```近壁条件是不可能的，因为`a + d < l`变成`2 < 1`。 同时，`x = l-a = 0`，因此远墙公式中没有有效的除法。 该算法在执行平方比较并返回之前显式处理这种情况`No`。 该分支对于数学正确性和安全实现都是必要的。
