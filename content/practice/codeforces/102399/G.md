 ## 解决方案
 ## 问题理解

 我们有两个直线族。 第一个族包含 (y=x+p) 形式的线，第二个族包含 (y=-x+q) 形式的线。 值 (p) 是不同的整数，值 (q) 也是如此。 

第一个族的每条线都与第二个族的每条线相交，因为它们的斜率为 (1) 和 (-1)。 对于每个这样的对，我们必须确定它们的交点是否具有整数坐标。 答案是满足这个条件的对的数量。 

对于一条线 (y=x+p) 和一条线 (y=-x+q)，将两个表达式相等可得出

 [
 x+p=-x+q,
 ]

 所以

 [
 x=\frac{q-p}{2}.
 ]

 将其代入任一行给出

 [
 y=\frac{p+q}{2}.
 ]

 因此，当 (q-p) 为偶数时，两个坐标都是整数。 当两个整数具有相同的奇偶校验时，两个整数的差甚至是精确的。 因此，整个几何问题简化为计算 (p) 和 (q) 均为偶数或均为奇数的对。 

重要的限制是每个族最多可以包含 (100000) 行。 检查每一对的方法将执行最多 (100000\cdot100000=10^{10}) 个检查。 这远远超出了 2 秒竞技编程限制所能支持的范围。 我们需要一个解决方案，其工作本质上与输入值的数量成正比。 

有一些边界情况很容易处理不当。 如果两个值都是奇数，则它们的差值仍然是偶数。 例如，与```
1
1
1
3
```两条线是 (y=x+1) 和 (y=-x+3)。 它们的交集是((1,2))，所以正确答案是`1`。 仅检查两个数字是否为偶数的解决方案将错误地返回零。 

零值也是偶数，必须正常处理。 例如，```
1
0
1
1
```给出 (x=\frac{1-0}{2})，它不是整数，所以正确的输出是`0`。 将零与其他偶数分开处理的粗心实现可能会出错。 

(p) 和 (q) 相等并不是一个特殊问题。 例如，```
1
5
1
5
```产生交集 ((0,5))，所以答案是`1`。 两条线不同，因为它们具有不同的斜率，即使它们的参数相同。 

最后，最大答案可能非常大。 如果两个系列中的所有 (100000) 个值都具有相同的奇偶性，则每对都有效，给出 (10^{10}) 个有效对。 因此，答案必须存储在至少能够容纳 (10^{10}) 的整数类型中。 Python 整数在这里不存在溢出问题。 

## 方法

 直接的方法是取出每一行（y=x+p_i），将其与每一行（y=-x+q_j）配对，计算（q_j-p_i），并检查结果是否为偶数。 这是正确的，因为每个可能的对都被检查一次，并且导出的交集公式给出了整数坐标的精确标准。 

问题是对的数量。 对于 (n=m=100000)，暴力破解会执行 (10^{10}) 次奇偶校验。 尽管每次检查在数学上都很简单，但一百亿次迭代对于时间限制来说太多了。 

关键的观察是我们实际上并不需要差异的值。 我们只需要他们的平等。 只有两种可能的奇偶校验：偶数和奇数。 当一个对的两个参数属于同一奇偶校验类时，该对就起作用。 

假设第一族参数中有(E_p)个偶数值和(O_p)个奇数值。 类似地，令 (E_q) 和 (O_q) 为第二个族的相应计数。 每个偶数 (p) 都可以与每个偶数 (q) 配对，生成 (E_pE_q) 个有效对。 同样，每个奇数 (p) 都可以与每个奇数 (q) 配对，产生 (O_pO_q) 个有效对。 

因此答案是

 [
 E_pE_q+O_pO_q。 
]

 我们只需要扫描每个输入数组一次并计算其偶数和奇数元素。 在奇偶性已知后，参数的实际位置和大小就无关紧要了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(nm)) | (O(1)) | (O(1)) | 太慢了|
 | 最佳 | (O(n+m)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1.读取(y=x+p)形式的行数(n)，然后读取所有(p)个值。 数一下有多少个是偶数，有多少个是奇数。 只有这两个计数很重要，因为交集标准仅取决于奇偶性。 
2.读取(y=-x+q)形式的行数(m)，然后读取所有(q)值。 再次计算偶数和奇数。 
3. 将偶数 (p) 的数量乘以偶数 (q) 的数量。 每一个这样的对都有 (q-p) 偶数，因此它们中的每一个都对答案有贡献。 
4. 将奇数 (p) 的数量乘以奇数 (q) 的数量。 它们的差异也是均匀的，因此这些对也做出了贡献。 
5. 将两个产品相加并打印结果。 一对相反的奇偶校验被排除，因为它们的差异是奇数，使得两个交点坐标都是半整数。 

### 为什么它有效

 对于任意一对直线，它们的交点是

 [
 \left(\frac{q-p}{2},\frac{p+q}{2}\right)。 
]

 如果(p)和(q)具有相同的奇偶性，则(q-p)和(p+q)都是偶数，因此两个坐标都是整数。 如果它们的奇偶性不同，则两个表达式都是奇数，因此两个坐标都是非整数。 因此，有效对是完全相同的奇偶校验对。 对偶偶和奇奇对进行计数时，每个有效对都只计数一次，并排除每个无效对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    m = int(input())
    q = list(map(int, input().split()))

    even_p = sum(x % 2 == 0 for x in p)
    odd_p = n - even_p

    even_q = sum(x % 2 == 0 for x in q)
    odd_q = m - even_q

    answer = even_p * even_q + odd_p * odd_q
    print(answer)

if __name__ == "__main__":
    solve()
```前两个输入读取获得两个参数系列。 该问题保证每个族都在一行中给出，因此将整行转换为列表就足够了。 

第一族的两个奇偶校验计数器是通过对偶数值进行计数并从(n)中减去以获得奇数值的数量来获得的。 第二个家庭也是如此。 

最终表达式直接实现数学结果（E_pE_q+O_pO_q）。 不需要对数组进行排序、构造线或显式计算任何交集。 

模运算`% 2`对于所有允许的非负参数值都是安全的。 Python 的任意精度整数还可以处理最大可能的答案 (10^{10})，无需任何特殊处理。 

最初的 Gym 版本只包含一个测试用例，而后来的 Codeforces 版本将相同的想法打包到多个测试用例中。

第二个例子是```
2

1 3 5
```两个 (p) 值都是偶数，而所有三个 (q) 值都是奇数。 

| 参数组 | 甚至| 奇数|

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(n+m)) | 每个参数都会检查一次以确定其奇偶性。 |
 | 空间| (O(n+m)) | 该实现存储两个输入数组。 |

 这些约束允许每个族中最多 (10^5) 个值，因此最佳算法仅执行大约 (2\cdot10^5) 个奇偶校验。 这完全在 2 秒的时间限制内。 与 512 MB 限制相比，内存使用量也很小。 

甚至可以在不存储数组的情况下处理数组，从而将辅助空间减少到 (O(1))，但保留它们使实现变得简单，并且完全在限制范围内。

## 边缘情况

 第一个奇偶边缘情况是两个奇数参数。 考虑```
1
1
1
3
```该算法计算一个奇数 (p) 和一个奇数 (q)，得出 (1\cdot1=1)。 交集为 ((1,2))，因此输出为`1`。 这捕获了错误地假设只有偶数对才能工作的实现。 

第二种边缘情况涉及零：```
1
0
1
1
```这里 (p=0) 是偶数，(q=1) 是奇数。 该算法产生 (1\cdot0+0\cdot1=0)。 交集为((1/2,1/2))，确认输出`0`。 奇偶校验测试自然会处理零。 

平等的情况是```
1
5
1
5
```两个参数都是奇数，因此算法返回`1`。 交集是((0,5))。 参数值相等并不意味着两条线重合，因为它们的斜率不同。 

最后，考虑有效对的最大可能数量。 让两个族都包含 (100000) 个不同的偶数值。 那么每一对 (100000^2=10^{10}) 都有一个整数交集。 该公式直接将其计算为 (100000\cdot100000)，而不枚举任何对。 这正是将 (O(nm)) 蛮力法与 (O(n+m)) 解决方案区分开来的情况。
