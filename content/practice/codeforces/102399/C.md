 ## 解决方案
 ## 问题理解

 我们有一个（n × m）矩形网格，其单元格有两种颜色。 当两个单元共用一侧时，它们就是邻居。 如果每个单元格最多有一个具有相同颜色的邻居，则着色是有效的。 

任务是计算网格的所有有效颜色并打印模 (10^9+7) 的结果。 每个网格的维度可以达到（100,000），因此单元格的数量可以达到（10^{10}）。 任何显式处理每种可能的着色的方法都是没有希望的，甚至状态指数依赖于较小维度的方法也无法处理（10^5 \times 10^5）网格。 我们需要将问题减少到每个维度的工作量恒定。 

有两个小案例暴露了推理中的错误。 对于 (1\times1) 网格，两种颜色都有效，因此答案是 (2)。 假设每个细胞都有四个邻居的方法，或者盲目地应用从 (n=2) 开始的递归的方法，可能会出错。 对于 (1\times3) 网格，有效字符串都是二进制字符串，没有三个相等的连续单元格，给出 (6) 颜色。 仅禁止相邻相等单元格的粗心方法将仅计算两个交替的字符串并错过诸如 (001) 之类的颜色。 

对于 (2\times2) 网格，答案是 (6)。 四个单元格不能全部具有相同的颜色，并且具有一种颜色和另一种颜色的三个单元格的着色也是无效的，因为大多数颜色单元格之一具有两个相同的邻居。 这是一项有用的检查，因为它将实际条件（最多一个相等的邻居）与更强且不正确的条件（所有邻居必须具有相反的颜色）区分开来。 

## 方法

 直接的方法是枚举每一种 (2^{nm}) 颜色。 对于每种颜色，我们可以检查每个细胞并计算其同色侧邻居的数量。 这是正确的，因为每种可能的颜色都会根据所需的条件进行考虑和检查。 它的最坏情况工作是 (O(nm,2^{nm}))。 对于 (n=m=100,000)，有 (10^{10}) 个单元格和 (2^{10^{10}}) 个可能的颜色，因此即使写下搜索空间也是不可能的。 

有用的观察是停止直接考虑颜色，而是标记每对具有相同颜色的相邻单元格。 因为一个单元格最多可以有一个相同颜色的邻居，所以这些标记的边缘形成匹配：两个标记的边缘永远不能共享一个单元格。 

现在考虑这样一条边的方向。 假设两个水平相邻的单元格具有相同的颜色。 每个端点都已经使用了其唯一允许的相同颜色的邻居，因此紧邻其上方的单元格（当它们存在时）必须具有相反的颜色。 相同的参数将水平同色对传播到每一行。 因此，单个水平等色边缘迫使整个着色仅具有水平等色边缘。 垂直等色边缘不能出现在这种着色中的任何地方，因为垂直边缘会沿垂直方向传播并最终与强制水平结构发生冲突。 同样的论点也适用于水平和垂直交换。 这种结构观察是整个解决方案的关键。 

因此，每种有效的颜色至少属于两个家族中的一个。 在第一个族中，没有垂直的同色边缘，因此每列垂直交替。 在第二个系列中，没有水平同色边缘，因此每行水平交替。 属于这两个家族的唯一颜色是两种棋盘颜色。

考虑第一家庭。 由于每一列垂直交替，整个网格由其第一行确定。 第一行可以是任何二进制字符串，其中三个连续单元格永远不相等。 一旦选择了第一行，所有剩余的行都将强制垂直交替。 如果第一个单元格的颜色是固定的，则令 (f_k) 为长度为 (k) 的有效字符串的数量。 前两个值是 (f_1=1) 和 (f_2=2)。 对于 (k\ge3)，固定第一个单元格后，最后一个块可以将前一个字符串扩展一个单元格或两个相等的单元格，给出

 [
 f_k=f_{k-1}+f_{k-2}。 
]

 第一个单元本身有两种可能的颜色，因此该族包含 (2f_m) 个网格。 

根据对称性，没有水平同色边的族包含 (2f_n) 个网格。 它们的交点恰好由两个棋盘组成。 包含-排除给出

 2(f_n+f_m-1)。 
]

 这是用于解决该问题的标准特征。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(nm,2^{nm})) | (O(nm)) | 太慢了|
 | 斐波那契递推 | (O(\max(n,m))) | (O(\max(n,m))) | 已接受 |

 ## 算法演练

 1. 读取(n)和(m)，并令(L=\max(n,m))。 我们只需要更大维度的斐波那契式值。 
2. 定义(f_1=1)和(f_2=2)。 对于从 (3) 到 (L) 的每个 (i)，计算
 [
 f_i=f_{i-1}+f_{i-2}\pmod{10^9+7}。 
]
 这对长度为 (i) 的二进制字符串进行计数，该二进制字符串具有固定的第一个颜色并且没有三个连续的相同颜色。 
3. 没有垂直等色边缘的颜色按(2f_m)计数。 因子 (2) 选择第一个单元格的颜色，之后垂直交替确定每列的其余部分。 
4. 通过将参数旋转 (90^\circ)，没有水平等色边缘的颜色将按 (2f_n) 进行计数。 
5. 这两个系列的两种棋盘颜色完全重叠。 将这两个重复的颜色相减一次，得到
 [
 2f_n+2f_m-2。 
]
 6. 打印
 [
 2(f_n+f_m-1)\pmod{10^9+7}。 
]

 计数背后的不变性是，具有相同颜色的相邻对的每个有效着色对于此类对来说只有一个可能的方向。 一旦选择了该方向，垂直方向必须交替，并且剩余的自由度恰好是一个一维二进制串，没有三个相等的连续颜色。 除了两个棋盘之外，两个可能的方向是不相交的，因此包含-排除公式对每个有效颜色仅计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    limit = max(n, m)

    if limit == 1:
        f1 = 1
    else:
        f1, f2 = 1, 2

        for _ in range(3, limit + 1):
            f1, f2 = f2, (f1 + f2) % MOD

    if n == 1:
        fn = 1
    elif n == 2:
        fn = 2
    else:
        a, b = 1, 2
        for _ in range(3, n + 1):
            a, b = b, (a + b) % MOD
        fn = b

    if m == 1:
        fm = 1
    elif m == 2:
        fm = 2
    else:
        a, b = 1, 2
        for _ in range(3, m + 1):
            a, b = b, (a + b) % MOD
        fm = b

    print((2 * (fn + fm - 1)) % MOD)

if __name__ == "__main__":
    solve()
```递归只能计算一次直到 (\max(n,m))，这更简单并且避免执行两个单独的循环。 上面的实现使边界情况保持明确，但基于紧凑数组的实现也是可能的。 

值 (f_1=1) 和 (f_2=2) 不是通常的斐波那契初始化 (1,1)。 它们在这里有直接的组合意义。 对于固定的第一种颜色，有一个长度为一的字符串，而有两个长度为二的字符串：第二个单元格可以具有任一颜色。 

Python 整数不会溢出，但无论如何，每个循环值都会以模 (10^9+7) 形式减少。 (1) 的减法发生在最终的乘法之前，并且在 Python 中不需要添加模数，因为最终的结果是`% MOD`正确处理负中间值。 

更高效的实现可以将所有值存储在数组中并直接读取 (f_n) 和 (f_m)。 滚动版本仅使用恒定的辅助内存，并且在单独处理两个维度时就足够了。 

## 工作示例

 对于提供的样本 (n=2,m=3)，递归给出 (f_1=1)、(f_2=2) 和 (f_3=3)。

 | 复发 | 3 | 1 | 2 | 3 |

 这两个系列包含 (2f_2=4) 和 (2f_3=6) 颜色。 两者都包含两个棋盘，因此并集有 (4+6-2=8) 种颜色。 

对于第二个示例，取 (n=1,m=3)。 重复值再次为 (f_1=1,f_2=2,f_3=3)。 

| 步骤| 尺寸| (f_{i-2}) | (f_{i-2}) (f_{i-1}) | (f_i) | (f_i) |
 | ---| ---| ---| ---| ---|
 | 初始| 1 | | 1 | |
 | 初始| 2 | 1 | 2 | |
 | 复发 | 3 | 1 | 2 | 3 |

 公式给出

 [
 2(f_1+f_3-1)=2(1+3-1)=6。 
]

 这六个字符串正是除(000)和(111)之外长度为3的二进制字符串。 这证实了二维参数也可以正确处理退化的单行网格。

 ## 边缘情况

 对于`1 1`，递归只有 (f_1=1)。 公式给出

 [
 2(1+1-1)=2。 
]

 只有一个单元格，因此两种颜色中的任何一种都会产生有效的着色。 没有邻居的情况可以通过公式自然地处理。 

为了`1 3`，网格只是一个二进制字符串。 有效字符串不能包含三个相等的连续单元格，因为中间的单元格将有两个相等的邻居。 这6个有效字符串正是(2f_3=6)计数的字符串。 该公式给出相同的结果：

 [
 2(f_1+f_3-1)=2(1+3-1)=6。 
]

为了`2 2`，（f_2=2），所以

 [
 2(f_2+f_2-1)=2(2+2-1)=6。 
]

 六种有效着色包括两个棋盘和具有一对相等相邻单元的四种着色。 这种情况证实了两个方向族必须恰好重叠两种颜色，而不是简单地相加。 

为了`2 3`，递推给出 (f_2=2) 和 (f_3=3)。 水平边缘族贡献（2f_2=4），垂直边缘族贡献（2f_3=6），并且两个棋盘出现在两个族中。 最终计数为（4+6-2=8），与样本相符。 

为了`100000 100000`，不需要特殊的数学案例。 递推式在每一步都以模 (10^9+7) 进行评估，因此值仍然很小，并且答案是从两个相同的值 (f_{100000}) 中获得的。 运行时间在 (100,000) 内保持线性，而不是在网格的 (10^{10}) 个单元内保持线性。
