 ## 问题理解

 问题提出了一条圆形项链，其中包含$n$珍珠，其中每颗珍珠都通过绳子与其相邻珍珠连接，最后一颗珍珠又连接回第一颗珍珠。 每根琴弦的切割成本都需要几分钟。 丹增想要将项链分成连续的片段，这样任何片段都不会包含超过$k$珍珠。 目标是确定进行此类削减所需的最短总时间。 

输入由多个测试用例组成。 每个测试用例提供珍珠数量$n$, 最大线段长度$k$，以及一个列表$n$整数$a_1$通过$a_n$代表每根弦的切割时间。 每个测试用例的输出是满足段尺寸约束的最小总切削时间。 

给定$n$可以达到$5 \cdot 10^5$跨越所有测试用例，时间限制为 2 秒，任何复杂度低于$O(n)$每个测试用例可能会超时。 考虑所有切割子集的简单方法是不可行的，因为可能的组合数量呈指数增长。 忽视项链的圆形性质或总是假设相等切割的粗心实施可能会产生不正确的结果。 例如，如果$n = 5$,$k = 2$，并且切割时间都是不同的，纯粹按顺序选择切割而不考虑最小组合可能会导致比所需的总数更高。 

## 方法

 强力解决方案将枚举所有可能的切割组，并计算满足段长度约束的每个组合的总时间。 这种方法是正确的，但不切实际，因为切割子集的数量呈指数增长$n$，这将是大约$2^n$最坏情况下的操作。 即使对于小$n$，这很快就超出了可行的运行时间。 

关键的见解是对于固定的最大段长度$k$，由于项链的圆形性质，该问题具有周期性结构。 任何有效的划分都可以通过选择一个起始珍珠然后贪婪地获取最多长度的片段来表示$k$。 最佳切割策略是选择最小成本串来切割尺寸大于的每个段$k$。 这将问题简化为对所有可能的起始位置进行线性扫描，跟踪最多长度段的最小累积切割成本$k$。 

对于每个起始位置$s$，我们迭代珍珠并考虑在每次之后进行切割$k$-th 珍珠，总结这些位置的最低可用切割成本。 由于项链是圆形的，因此我们通过复制一次来扩展切割时间数组，从而允许对窗口段进行线性扫描，而无需进行模运算。 

问题简化为考虑所有$k$第一个内可能的起始偏移量$k$珍珠并计算进行该偏移时的最小切割总和。 最后，我们选择这些起始偏移量中的最小总数。 这种方法是线性的$n$每个测试用例，在给定的约束下这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 带偏移的线性贪婪 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$k$，以及切削时间列表$a$。 延长$a$通过将其连接到自身来处理循环性质，而无需模运算。 
2. 初始化变量`res`到一个大值来存储最小总切削时间。 
3. 迭代所有可能的起始偏移量`start`从 0 到$k-1$。 每个偏移量代表选择第一个内的第一个剪切位置$k$珍珠。 
4. 对于每个偏移量，初始化一个和`cur_sum`为0。这将累积当前策略的削减成本。 
5. 从以下位置开始迭代珍珠`start`与步骤`k`，在长度段内选择最小切割成本$k$。 将这个最小成本添加到`cur_sum`。 
6. 扫描所有珍珠的起始偏移量后，更新`res`如果`cur_sum`小于当前的`res`。 
7.检查所有起始偏移后，输出`res`作为测试用例的最小总切削时间。 

为什么它有效：通过迭代大小的第一段内的所有起始偏移量$k$，我们保证考虑每个有效的切割配置。 每个段内最小成本的贪心选择确保没有段超过$k$珍珠，同时保持最小的累积成本。 扩展数组可以无缝地处理循环环绕。 不变量是每个段永远不会超过$k$珍珠并检查所有可能的起始配置，确保最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a_extended = a + a  # handle circular necklace
        res = float('inf')
        for start in range(k):
            cur_sum = 0
            for i in range(start, start + n, k):
                cur_sum += a_extended[i]
            res = min(res, cur_sum)
        print(res)

if __name__ == "__main__":
    solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`。 连接数组简化了循环结构的处理，无需模运算。 迭代偏移量可确保考虑每个可能的段对齐。 这`cur_sum`累积给定偏移量的最小切割并更新总体最小值`res`。

 ## 边缘情况
