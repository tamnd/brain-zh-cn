 ## 解决方案
 ## 问题理解

 我们有$n$独立的随机变量，每个变量从区间中均匀选择$[0,1]$。 在变量对之间，我们给出以下形式的约束$$x_i+x_j\le 1$$或者$$x_i+x_j\ge 1.$$任务是计算所有约束同时成立的概率。 

最重要的观察是变量是连续的。 等式如$x_i+x_j=1$有概率发生$0$，因此只要严格的不等式简化了论证，我们就可以自由地进行推理。 

约束条件$n\le 20$立即表明指数算法$n$是可能的。 大小的状态空间$2^n$大约一百万，这是可行的。 任何涉及变量所有排列的事情都需要$20!$可能性并且是无望的。 

一个微妙的点是约束不比较单个变量。 他们比较相对于的总和$1$。 尝试离散化变量的值或直接积分$[0,1]^n$很快就会变得棘手。 

另一个容易犯的错误是自循环处理不当。 

例如：```
1 1
1 1 1
```约束条件是$2x_1\ge 1$，这意味着$x_1\ge \tfrac12$。 答案是$\tfrac12$， 不是$1$。 

相似地：```
1 1
0 1 1
```需要$x_1\le \tfrac12$，再次概率$\tfrac12$。 

另一个陷阱是间接产生的矛盾结构。```
4 4
0 1 2
0 3 4
1 1 3
1 2 4
```这是第四个样本。 约束迫使一个无法满足的符号要求循环，所以答案是$0$。 对每个边缘进行本地检查是不够的。 

## 方法

 蛮力观点是将概率视为单位立方体内部区域的体积$[0,1]^n$。 每个约束都通过超平面切割立方体。 准确计算结果体积需要对复杂的多面体进行积分。 即使是为了$n=20$，这是完全不现实的。 

关键的观察来自于重写中点附近的变量$1/2$。 

定义$$y_i=x_i-\frac12.$$每个$y_i$均匀分布在$\left[-\frac12,\frac12\right]$。 

现在每个约束都变成$$y_i+y_j\le 0$$或者$$y_i+y_j\ge 0.$$认为$|y_i|<|y_j|$。 

如果$y_i+y_j\le 0$，和的符号由较大的幅度项确定$y_j$。 自从$|y_j|$占主导地位，不等式相当于要求$y_j<0$。 

同样，如果$y_i+y_j\ge 0$，相当于要求$y_j>0$。 

这就是突破。 对于每条边，只有绝对值较大的端点才重要。 

因此，我们不需要使用实际值，而只需要：

 1. 绝对值的排序$|y_i|$。 
2. 各标志$y_i$。 

一旦这些被修复，每个约束要么得到满足，要么被违反。 

绝对值是独立的统一变量。 它们的大小的每个排序都有概率发生$1/n!$。 每个变量的符号独立为正或负的概率$1/2$。 

于是问题就变成了：

 计算有效对的数量$$(\text{ordering of }|y|,\ \text{sign assignment})$$并除以$$2^n n!.$$计数本身可以通过幅度排序上的子集 DP 来完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力几何积分 | 连续维度上的指数 | 巨大 | 太慢了 |
 | 数量级上的位掩码 DP |$O(n2^n)$|$O(2^n)$| 已接受 |

 ## 算法演练

 ### 步骤 1

 变换每个变量：$$y_i=x_i-\frac12.$$约束条件变为$y_i+y_j\le 0$和$y_i+y_j\ge 0$。 

### 步骤 2

 对于每个变量，存储两个位掩码。`LE[i]`包含连接到的所有顶点$i$通过约束$y_i+y_j\le 0$。`GE[i]`包含连接到的所有顶点$i$通过约束$y_i+y_j\ge 0$。 

自然地包括自循环。 

### 步骤 3

 过程变量按升序排列$|y|$。 

让$S$是已经放置的顶点集。 中的每个顶点$S$比外面的每个顶点的绝对值都小$S$。 

假设我们要放置顶点$i$下一个。 

然后$i$成为其中最大的量级$S\cup\{i\}$。 

### 步骤 4

 计算有多少种可能的符号选择$i$。 

如果$i$是正数，则类型的每个约束$\ge 0$发生于$i$必须指向一个尚未放置的顶点。 否则$i$将是较大幅度的端点，并且将被该边缘强制为正。 

所以允许正数当且仅当$$GE[i]\cap(S\cup\{i\})=\varnothing.$$如果成立，请添加一个转换。 

同样，允许负数当且仅当$$LE[i]\cap(S\cup\{i\})=\varnothing.$$如果成立，请添加另一个过渡。 

每个允许的符号仅以一种方式做出贡献。 

### 步骤 5

 运行标准子集 DP。 

让$$dp[S]$$是 中顶点的排序和符号的有效构造数$S$。 

初始化$$dp[\varnothing]=1.$$对于尚未选择的每个状态和每个顶点，应用上面的两项检查并更新$dp[S\cup\{i\}]$。 

### 步骤 6

 完成后，$dp[(1<<n)-1]$等于有效对的数量$$(\text{ordering},\text{sign assignment}).$$每个符号分配都有概率$1/2^n$。 

绝对值的每个排序都有概率$1/n!$。 

因此答案是$$\frac{dp[(1<<n)-1]}{2^n n!}.$$所有算术都是模数完成的$998244353$。 

### 为什么它有效

 对于任何约束，只有绝对值较大的端点才能确定总和是正数还是负数。 一旦绝对值的顺序固定，每条边都会对一个端点（即该顺序中的后一个端点）施加符号要求。 

DP 构建从小到大的顺序。 当顶点$i$插入后，所有顶点都在$S$具有较小的幅度。 之间的任意边$i$和一个顶点$S$已经确定了哪个标志$i$必须有。 两个位掩码测试精确检查是否仍然可能是正数或负数。 

每个有效的排序和符号分配都只计算一次，并且每个计算的配置都满足所有约束。 由于符号和幅度排序是均匀分布的，除以$2^n n!$将计数转换为所需的概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, m = map(int, input().split())

    LE = [0] * n
    GE = [0] * n

    for _ in range(m):
        t, i, j = map(int, input().split())
        i -= 1
        j -= 1

        if t == 0:
            LE[i] |= 1 << j
            LE[j] |= 1 << i
        else:
            GE[i] |= 1 << j
            GE[j] |= 1 << i

    N = 1 << n
    dp = [0] * N
    dp[0] = 1

    for S in range(N):
        cur = dp[S]
        if cur == 0:
            continue

        for i in range(n):
            if (S >> i) & 1:
                continue

            T = S | (1 << i)

            if (GE[i] & T) == 0:
                dp[T] = (dp[T] + cur) % MOD

            if (LE[i] & T) == 0:
                dp[T] = (dp[T] + cur) % MOD

    ans = dp[N - 1]

    inv2 = pow(2, MOD - 2, MOD)
    for k in range(1, n + 1):
        ans = ans * pow(k, MOD - 2, MOD) % MOD
        ans = ans * inv2 % MOD

    print(ans)

if __name__ == "__main__":
    main()
```两个面具`LE`和`GE`对整个约束图进行编码。 自循环会自动将顶点放置在其自己的蒙版内，这正是我们想要的。 例如，一个约束$x_i+x_i\ge 1$成为一个自我位`GE[i]`，使得负转变不可能。 

DP状态仅存储已处理顶点的子集。 不需要额外的信息，因为排序是根据插入顶点的顺序重建的。 

表达式`GE[i] & T`检查是否有禁止的`>=`边缘已经指向较小量级的顶点。 如果是这样，选择正号将违反约束。 

最后，我们乘以模逆$2$和$1,2,\dots,n$除以$2^n n!$。 

## 工作示例

 ### 示例 1

 输入：```
3 2
0 1 2
1 3 3
```这些面具是：

 | 顶点| LE | 通用电气|
 | --- | --- | --- |
 | 1 | {2} | {} |
 | 2 | {1} | {} |
 | 3 | {} | {3} |

 DP 转换：

 | 状态| 添加顶点 | 允许的标志 |
 | --- | --- | --- |
 | {} | 1 | + 和 - |
 | {} | 2 | + 和 - |
 | {} | 3 | 仅+ |
 | ... | ... | ... |

 最终计数为$6$。 

有$3!\cdot 2^3 = 48$同样可能的订单/符号对。 因此$$\frac{6}{48}=\frac14.$$模数$998244353$， 这是`748683265`。 

此示例显示自循环如何限制单个变量的符号而不影响排序逻辑。 

### 示例 2

 输入：```
3 3
0 1 2
0 1 3
0 2 3
```每条边都有类型$\le 0$。 

无论我们检查哪一对，较大的端点都必须为负。 

因此，总体上最大量级变量必须为负。 其余两个变量可以具有任一符号。 

| 最大量值顶点 | 必填标志 |
 | --- | --- |
 | 1 | 负|
 | 2 | 负|
 | 3 | 负|

 DP 计算所有有效订单/符号对并再次生成概率$1/4$。 

这个例子说明了中心原则：只有较大的端点才重要。

 ## 边缘情况

 考虑：```
1 1
1 1 1
```自循环存储在里面`GE[1]`。 当 DP 尝试将顶点放置为负号时，条件$$GE[1]\cap\{1\}\neq\varnothing$$阻止这种转变。 只剩下积极的信号了。 DP 计数变为$1$，并除以$2$产生概率$1/2$。 

现在考虑：```
1 1
0 1 1
```同样的推理适用于`LE`。 只允许使用负号，再次产生概率$1/2$。 

最后，考虑：```
4 4
0 1 2
0 3 4
1 1 3
1 2 4
```其中任意一个顶点$\{1,3\}$较大的幅度一定是正值。 其中任意一个顶点$\{1,2\}$较大的幅度必定为负值。 围绕图表追逐这些要求会产生矛盾。 在 DP 期间，每个部分构造最终都会卡住，因此最终计数为零，算法输出$0$。 这表明 DP 自动检测全局不一致，而不是依赖于本地检查。
