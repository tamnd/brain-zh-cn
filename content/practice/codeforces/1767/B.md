 ## 解决方案
 ## 问题理解

 我们有几个塔，每个塔都包含一定数量的块。 目标是通过从比其他塔具有更多块的塔中移动块来最大化第一个塔上的块数量。 仅当我们从具有更多方块的塔中取出一个方块并将其放置到具有较少方块的塔上时才允许移动。 每次移动都会使一座塔减少一格，并使另一座塔增加一格。 

输入由多个测试用例组成。 每个测试用例都提供塔的数量以及所有塔的块计数列表。 对于每个测试用例，输出应该是执行任何有效移动序列后第一个塔上的最大可能块数。 

限制是巨大的：塔的数量$n$可以达到$2 \cdot 10^5$，以及总和$n$所有测试用例不超过$2 \cdot 10^5$。 这排除了任何逐一模拟移动的解决方案，因为在最坏的情况下，单独移动块将需要最多$10^9$单塔十亿块的操作，远远超出了时间限制。 块本身可能非常大，因此解决方案必须使用算术，而不是强力模拟。 

非明显的边缘情况包括其中一座塔具有大量块而其余塔很少的情况，或者所有塔都以相同数量的块开始。 例如，如果输入是`[1, 1000000000]`，迭代检查每个可能的移动的简单算法将非常慢。 另一个边缘情况是所有塔都相等时，例如`[5, 5, 5]`。 这里不可能移动，一号塔的最大值只是它的起始值。 

## 方法

 暴力方法很简单：重复扫描所有塔，找到比第一个塔具有更多块的塔，然后将一个块从它移动到第一个塔。 重复直到不可能进行此类移动。 这个方法是正确的，因为每一步都是合法的，只有当一号塔无法进一步增加时我们才会停止。 问题在于性能：在最坏的情况下，我们可以向上移动到塔之间的差异之和，这可能达到$10^9$每个测试用例的操作。 这超出了任何可行的限制。 

最佳方法来自于观察移动的顺序并不重要。 我们只需要知道街区总数以及有多少可以合法到达一号塔。 一号塔可以接收来自所有其他塔的方块，但当我们移动方块时，任何塔都不能低于一号塔的当前计数。 因此，一号塔上的最大块数是所有块向上舍入的整数平均值。 形式上，所有块的总和除以塔的数量给出了在最佳地重新分配块时任何塔可以达到的公平最大值。 这是因为任何具有比平均值更少的块的塔都不能给出比其计数与平均值之间的差更多的值。 所以公式就变成了`max_possible = ceil(total_blocks / n)`，可以使用整数算术安全地计算为`(total + n - 1) // n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(总和(a_i)) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取塔的数量`n`和块计数列表`a`。 
3. 计算所有塔上的块总数：`total = sum(a)`。 
4. 计算第一塔可以达到的最大方块数。 由于一号塔永远不会超过区块平均数的上限，因此计算`(total + n - 1) // n`。 
5. 打印每个测试用例的计算最大值。 

该方法的正确性依赖于这样的不变性：在不违反移动规则的情况下，任何塔都不能接收超过其公平份额的块。 通过取平均值的上限，我们确保一号塔接收尽可能多的方块，同时尊重其他塔的相对高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    total = sum(a)
    max_blocks = (total + n - 1) // n
    print(max_blocks)
```该解决方案可以有效地读取输入`sys.stdin.readline`，处理多个测试用例，对块求和，并应用整数算术来计算上限，而无需浮点运算。 使用`(total + n - 1) // n`避免舍入错误并处理高达$2 \cdot 10^{14}$安全地使用Python。

 ## 边缘情况

 如果所有塔的块数相同，则总和除以`n`是一个整数，上限不会改变该值。 例如，`[5, 5, 5]`产量`(15 + 3 - 1) // 3 = 17 // 3 = 5`。 该算法输出第一塔的起始数字，这是正确的，因为没有任何移动可以增加它。 

如果一座塔与其他塔相比具有大量的块，例如`[1, 1000000000]`，总和是`1000000001`，塔的数量 = 2，给出`(1000000001 + 2 - 1) // 2 = 1000000002 // 2 = 500000001`。 该算法有效地捕获最大可能的分布，避免迭代移动。
