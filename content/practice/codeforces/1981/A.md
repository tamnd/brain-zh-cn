 ## 解决方案
 ## 问题理解

 我们给定一个整数范围$[l, r]$。 海龟选择一个数字$x$从这个范围。 之后，小猪反复分裂$x$除以大于或等于的除数之一$2$，每划分一分，直到数字变为$1$。 

两位选手都希望最终的比分尽可能大。 我们需要确定可能的最大分数。 

关键的观察是每个操作都替换$x$经过$x / p$， 在哪里$p \ge 2$。 自从$p$至少是$2$，每次操作都会使当前值至少减少一个因子$2$。 分数只是达到之前的除法步数$1$。 

从算法的角度来看，约束非常小。 最多有$10^4$测试用例和值最多为$10^9$。 迭代整个区间的任何解决方案$[l,r]$这是不可能的，因为间隔长度可以接近$10^9$。 每个测试用例我们需要一个直接的数学公式。 

一个微妙的错误是认为质因数分解本身就决定了答案。 例如，对于$x=12$，质因数分解为$2^2 \cdot 3$，给出三个素因数。 分数确实是$3$，但这是因为 Piggy 总是可以选择素因数，并且一次只能删除一个素因数。 最大分数等于重数计数的质因数总数。 

另一个容易犯的错误是寻找区间中的最佳数字。 考虑$l=114514$,$r=1919810$。 暴力破解数百万个值是不必要的。 最佳数字始终是适合该区间的最大的二的幂。 

## 方法

 暴力解决方案将检查每个数字$x$在$[l,r]$，将其因式分解，统计质因数的总数，并保留最大值。 这是正确的，因为固定数字的最大分数等于具有重数的质因数的数量。 不幸的是，间隔长度可能接近$10^9$，使得这样的搜索完全不可行。 

关键的观察是每个操作至少将当前值除以$2$。 开始于$x$， 后$s$我们必须有的操作$$x \ge 2^s.$$这立即给出$$s \le \lfloor \log_2 x \rfloor.$$无论何时，这个界限都是可以实现的$x$本身就是二的幂。 例如，$2^{10}$可以除以$2$正好十次。 

由于海龟可以选择任意数字$[l,r]$，通过选择不超过的两个最大幂来获得最大可能的分数$r$。 让$$2^k \le r < 2^{k+1}.$$然后$k=\lfloor \log_2 r \rfloor$。 

因为该声明保证$2l \le r$，该区间始终至少包含 2 的一次方。 如果$2^k$是两个不超过的最大幂$r$， 然后$2^k > r/2 \ge l$。 因此$2^k$位于区间内，可以选择。 

答案很简单$\lfloor \log_2 r \rfloor$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O((r-l+1)\sqrt r)$|$O(1)$| 太慢了 |
 | 最佳 |$O(1)$每个测试用例|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读$l$和$r$。 
2. 计算最大整数$k$这样$2^k \le r$。 
3、输出$k$。 

Python 中最简单的方法是使用位长度$r$。 对于任意正整数，$$\lfloor \log_2 r \rfloor = r.\text{bit\_length()} - 1.$$### 为什么它有效

 每个除法删除一个因子至少等于$2$，所以之后$s$原始操作数必须至少为$2^s$。 没有数量不超过$r$可以生产超过$\lfloor \log_2 r \rfloor$运营。 

该区间始终包含两个不超过的最大幂$r$。 选择该值即可准确实现$\lfloor \log_2 r \rfloor$重复除以的运算$2$。 由于上限和匹配结构都存在，所以答案正是$\lfloor \log_2 r \rfloor$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        l, r = map(int, input().split())
        ans.append(str(r.bit_length() - 1))

    sys.stdout.write("\n".join(ans))

solve()
```该解决方案从不使用$l$读完后。 乍一看这可能令人惊讶，但保证$2l \le r$正是这样确保了两个的必要幂总是位于区间之内。 

表达式`r.bit_length() - 1`计算$\lfloor \log_2 r \rfloor$无需浮点运算，避免精度问题。 自从$r \le 10^9$，整数溢出从来都不是问题。

 ## 边缘情况

 考虑最小可能的间隔：```
1
1 2
```唯一可用的两个幂是$2$。 我们有$$2 \to 1$$所以分数是$1$。 公式给出$\lfloor \log_2 2 \rfloor = 1$。 

考虑一个区间，其中上端点本身就是 2 的幂：```
1
8 16
```答案是$4$因为$16 = 2^4$。 反复除以$2$实现四个操作。 公式返回`16.bit_length() - 1 = 4`。 

考虑一个范围，其中最佳数不是最大数：```
1
6 22
```最大值为$22$，其素因数分解为$2 \cdot 11$，仅给出两个操作。 区间还包含$16$，给出四种运算。 该算法从不超过的两个最大幂中正确找到答案$22$，生产$4$。
