 ## 解决方案
 ## 问题理解

 我们在数轴上得到一组线段。 每个段也带有一个值$a_i$。 如果两个片段的间隔至少在一个点重叠（包括端点处接触），则认为它们是相关的。 每当两个段重叠时，我们就想象它们之间有一条边，其权重是它们关联值的绝对差。 

这定义了一个无向加权图，其中顶点是线段，边仅存在于重叠线段之间。 任务是计算该图的最小生成树的总权，或者确定由于图不连通而不存在生成树。 

这些限制使得结构变得非常庞大。 最多可以有$5 \cdot 10^5$所有测试用例的分段，端点可以大到$10^9$。 这立即排除了任何尝试显式构建相交对之间的所有边的解决方案，因为在最坏的情况下，所有线段重叠并且图形变得完整，给出$O(n^2)$边缘。 

简单的 Kruskal 方法需要枚举所有重叠对，这在规模上是不可能的。 即使成对检查重叠也会导致二次行为。 

当片段形成多个不相连的重叠簇时，就会出现关键的边缘情况。 例如，如果一组线段位于$[1,2]$另一个在$[100,200]$，组之间没有重叠，答案必须是$-1$即使两个群体都有内部联系。 在按左端点排序后假设连接的简单实现可能会错过这一点。 

另一个微妙的情况是当重叠仅被链接时。 线段 A 与 B 重叠，B 与 C 重叠，但 A 不与 C 重叠。该图仍然是连接的，但任何仅连接“按排序顺序相邻”而不维护活动重叠结构的解决方案都可能会错过正确性所需的有效边。 

## 方法

 如果我们忽略结构，问题就会简化为构建一个图，其中每个重叠对都连接起来，然后运行最小生成树算法。 这种强力解释表明生成所有对$(i, j)$使得线段相交，然后运行 ​​Kruskal 或 Prim。 

该方法的正确性是立竿见影的，因为它准确地构建了图形。 问题在于尺寸。 在最坏的情况下，如果所有段重叠，则边的数量为$\binom{n}{2}$，这大约是$10^{11}$什么时候$n = 5 \cdot 10^5$。 即使检测重叠也需要对所有对进行二次扫描或间隔查询。 

结构上的突破在于重新解释图表。 两个节点之间的权重仅取决于$|a_i - a_j|$，独立于几何形状，而边缘仅在间隔重叠时才存在。 这种组合表明我们希望以一种最小化差异的方式连接每个连接的重叠组件$a$，不枚举所有边。 

关键的观察是，在以连接方式相互重叠的任何一组段内，绝对差异的 MST 表现得像一个经典结果：如果我们按以下方式对节点进行排序：$a_i$，然后按顺序连接它们在带有权重的完整图上生成最小生成树$|a_i - a_j|$。 唯一的复杂之处在于并非所有对都被允许，仅允许在同一重叠连接组件内的对。 

因此，真正的任务变成识别“区间交集图”中的连接组件，并在每个组件内按$a_i$并对相邻差异求和。 

剩下的困难是在不显式构建边缘的情况下有效地计算连接的组件。 这是通过使用类似 DSU 的结构或基于区间合并的联合策略来扫描区间并维护活动重叠组来处理的。 

我们维护按当前右端点排序的活动段，并统一按左端点扫描时重叠的段。 一旦我们拥有了所有组件，我们就会独立处理每个组件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 显式图上的强力 MST |$O(n^2 \log n)$|$O(n^2)$| 太慢了 |
 | 扫描 + DSU 组件 + 每个组件排序的 MST |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将问题转化为在区间交集下构建连通组件，然后使用排序计算每个组件内的 MST 成本$a_i$。 

1. 按左端点对所有线段进行排序。 

这确保我们按照间隔开始的递增顺序处理间隔，从而使我们能够使用滚动活动结构来跟踪重叠。 
2. 维护一个跟踪每个组件当前活动合并间隔的数据结构。 

对于每个新段，我们将其与最大右端点仍然≥当前左端点的有源组件进行比较。 
3. 如果某个段与活动组件重叠，我们将使用 DSU 将其合并到该组件中。 

这样做的原因是重叠是通过链传递的，因此任何交叉路径都定义了一个连接的组件。 
4. 在扫描时，我们维护按其正确端点排序的组件的当前“边界”。 当组件的右端点完全位于当前左端点后面时，它将被关闭。 
5. 识别出所有组件后，收集每个组件的节点。 
6. 对于每个组件，对其节点进行排序$a_i$。 
7. 计算组件内的 MST 成本，作为按排序顺序的相邻差异之和$a_i$。 

这是有效的，因为组件内部产生的图形在绝对差度量下的行为类似于完整的图形。 
8. 如果存在多个组件，则返回$-1$。 否则返回总和。 

### 为什么它有效

 区间交集关系定义的连通分量正是区间图的连通分量。 同一组件中的任何两个节点都可以通过重叠链连接。 这保证了重叠活动间隔上基于 DSU 的合并正确捕获所有连接。 

在一个组件内部，诱导边权重在绝对差下形成一个度量空间$a_i$。 对于此类图，MST 始终由排序点和连接连续元素形成，因为任何较长的边都由中间边的总和支配。 这是在线度量上 MST 的经典属性。 

因此，我们将原始图简化为独立的线度量 MST 问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1]*n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        seg = []
        for i in range(n):
            l, r, a = map(int, input().split())
            seg.append((l, r, a, i))

        seg.sort()

        dsu = DSU(n)

        active = []  # (r, i)
        import heapq

        for l, r, a, i in seg:
            new_active = []
            for rr, j in active:
                if rr >= l:
                    new_active.append((rr, j))
                else:
                    pass
            active = new_active

            for rr, j in active:
                dsu.union(i, j)

            active.append((r, i))

        comp = {}
        for i in range(n):
            root = dsu.find(i)
            comp.setdefault(root, []).append(i)

        if len(comp) > 1:
            print(-1)
            continue

        nodes = list(range(n))
        nodes.sort(key=lambda x: seg[x][2])

        ans = 0
        for i in range(1, n):
            ans += abs(seg[nodes[i]][2] - seg[nodes[i-1]][2])

        print(ans)

if __name__ == "__main__":
    solve()
```该实现首先按段的左端点对段进行排序，以启用扫描式处理。 DSU 结构保持由重叠引起的连接性。 

这`active`列出其右端点仍与重叠相关的轨道段。 对于每个新段，我们删除过期的间隔并将当前段与其重叠的所有活动段合并。 这是构建连接组件的机制。 

DSU 构建完成后，我们按根对索引进行分组。 如果存在多个组，我们立即返回$-1$，因为不存在生成树。 

最后，对于单组件情况，我们使用排序方式计算 MST 成本：$a_i$诡计。 关键的微妙之处在于，此步骤完全忽略几何图形，因为连接性已由 DSU 强制执行。

 ## 边缘情况

 一个关键的边缘情况是间隔几乎没有接触。 例如，段$[1,2]$和$[2,3]$必须被视为已连接。 由于条件原因，扫描将它们视为重叠$\max(l_1,l_2) \le \min(r_1,r_2)$，所以平等就足够了。 DSU 联合步骤正确地将它们合并为一个组件，确保不会人为分离。 

另一种情况是重叠是间接的。 如果$[1,5]$,$[4,6]$， 和$[6,10]$出现，即使第一个和最后一个不直接相交，所有三个都必须在一个组件中。 主动扫描确保在处理第三个间隔时，它仍然与当前活动的代表相交，从而传递性地保留连接性。 

最后，如果所有段重叠，则该算法绝不会产生多个分量，并且最终答案会简化为所有段的简单排序差值和。$a_i$，匹配绝对差下完整图的 MST。
