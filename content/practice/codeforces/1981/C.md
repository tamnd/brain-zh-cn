 ## 解决方案
 ## 问题理解

 我们得到一个正整数序列，其中一些元素丢失并表示为`-1`。 原始序列有一个特殊的属性：对于每对连续的数字，要么第一个数字是第二个数字的一​​半，要么第二个数字是第一个数字的一​​半。 任务是重建任何有效的序列，尊重缺失的数字并维持此属性，同时保持所有数字为正值并以$10^9$。 如果不存在这样的序列，我们报告`-1`。 

输入允许多个测试用例，每个测试用例最多$2 \cdot 10^5$元素，并且所有测试的元素总和不超过$2 \cdot 10^5$。 这意味着一个$O(n^2)$解决方案将太慢，因为它可能涉及最多$4 \cdot 10^{10}$最坏情况下的操作。 我们需要一种在每个测试用例的线性时间内工作或略高于线性时间的方法，理想情况下$O(n \log U)$在哪里$U$是数字的上限，以适应 3 秒的时间限制。 

棘手的情况是缺失的数字与已知的数字相互作用，从而可能违反减半特性。 例如，一个序列`-1 5 -1 6`可能没有任何有效的重建，因为填充空白以满足双方的减半/下限属性是不可能的。 同样，已知值不兼容的小序列，例如`2 -1 -1 3`，必须被检测为无效。 没有约束的从左到右的简单填充可能会默默地产生无效序列。 

## 方法

 蛮力方法是尝试 1 到 1 之间所有可能的整数$10^9$对于每一个`-1`位置，然后检查每个连续对的减半条件。 由于序列的范围和长度很大，这显然是不切实际的。 即使尝试所有数字直到$10^8$在最坏的情况下需要$10^{13}$运营。 

关键的观察是，对于序列中的每个已知数字，其邻居的可能值受到限制。 如果`b[i]`已知，那么`b[i-1]`只能在范围内`[b[i]*2, b[i]*2+1]`反过来，或者`[b[i]//2, b[i]]`向前方向，取决于我们解释减半关系的方向。 通过左右传播这些约束，我们可以计算每个未知元素的可行区间。 如果在任何一步可行区间变空，则该序列是不可能的。 

这将问题简化为维护每个位置的可行范围，从左到右和从右到左传播约束，然后选择两个范围交集内的任何值。 由于每个位置都是在恒定时间内处理的，因此整体复杂度与序列长度呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(10^9 * n) | O(10^9 * n) | O(n) | 太慢了 |
 | 区间传播 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组，`lo`和`hi`，表示每个位置的可行值范围。 最初，设置`lo[i] = 1`和`hi[i] = 10^9`对于所有未知元素，以及`lo[i] = hi[i] = a'[i]`对于已知元素。 这设置了输入的初始约束。 
2. 从左到右传播约束。 对于每个位置`i`从 1 到 n-1，调整`lo[i+1]`和`hi[i+1]`根据当前减半性质`lo[i]`和`hi[i]`。 具体来说，`b[i+1]`必须满足`b[i+1] // 2 = b[i]`或者`b[i+1] = b[i] // 2`。 更新`lo[i+1]`作为两种可能性隐含的最大下界和`hi[i+1]`作为最小上限。 如果`lo[i+1] > hi[i+1]`，该序列是不可能的。 
3. 使用相同的逻辑从右向左重复传播。 这确保了来自另一方的约束被考虑。 再说一次，如果在任何位置`lo[i] > hi[i]`， 输出`-1`。 
4. 计算出所有位置的可行范围后，在每个位置中选择任意值`[lo[i], hi[i]]`间隔。 为了简单起见，选择`lo[i]`有效，因为区间中的任何值都满足由于先前传播而导致的减半条件。 
5. 打印当前测试用例的序列。 如果任何步骤失败，则打印`-1`。 

为什么它有效：该算法保持一个不变量，即每个`b[i]`必须位于`[lo[i], hi[i]]`满足与其邻居的减半条件。 从两个方向传播约束可以保证我们捕获已知数字施加的所有限制。 如果可行区间变空，则不可能满足序列，否则区间内选择的任何值都会产生有效序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        lo = [1] * n
        hi = [10**9] * n
        for i in range(n):
            if a[i] != -1:
                lo[i] = hi[i] = a[i]
        # left to right propagation
        for i in range(n-1):
            new_lo = max(lo[i] * 2, (lo[i]+1)//2)
            new_hi = min(hi[i] * 2 + 1, hi[i]*2+1)
            lo[i+1] = max(lo[i+1], new_lo)
            hi[i+1] = min(hi[i+1], new_hi)
            if lo[i+1] > hi[i+1]:
                break
        else:
            # right to left propagation
            for i in range(n-1, 0, -1):
                new_lo = max(lo[i]//2, lo[i])
                new_hi = min(hi[i]*2+1, hi[i])
                lo[i-1] = max(lo[i-1], new_lo)
                hi[i-1] = min(hi[i-1], new_hi)
                if lo[i-1] > hi[i-1]:
                    break
            else:
                print(" ".join(map(str, lo)))
                continue
        print(-1)

if __name__ == "__main__":
    solve()
```该代码初始化所有位置的可行范围，向前和向后传播约束，最后输出每个区间的有效选择。 传播仔细地使用整数运算以确保正确应用边界。
