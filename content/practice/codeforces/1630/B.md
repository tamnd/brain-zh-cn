 ## 解决方案
 ## 问题理解

 给定一个整数数组，任务是找到一个数值范围`[x, y]`并将数组精确地分割成`k`连续子数组，以便在每个子数组中，超过一半的元素落在所选范围内。 目标是最小化范围的宽度，`y - x`。 从概念上讲，我们试图用以下内容“覆盖”数组`k`每个子数组的大部分位于一个小数字窗口内的子数组。 

约束很严格：`n`可以达到`2·10^5`每个测试用例，以及总和`n`在所有测试用例中也是`2·10^5`。 这排除了检查所有可能范围或所有可能子数组的强力方法，因为简单的解决方案将是 O(n^2) 或 O(n^3)，这是不可行的。 每个测试用例我们需要一个大约 O(n log n) 或 O(n) 的算法。 

当数组有许多重复元素时，或者当`k`等于`1`或者`n`。 例如，如果所有元素都相等，则范围`[x, y]`是微不足道的，但粗心的方法可能会尝试错误地分割子数组。 如果`k = n`，每个子数组包含一个元素，因此范围必须包含每个元素。 当最佳范围包含数组中不连续的元素时，会出现另一种微妙的情况，从而强制进行仔细的分区。 

## 方法

 蛮力方法将检查所有可能的`[x, y]`范围，计算数组中有多少元素落在所有可能子数组的范围内和范围外，并检查是否有效分割为`k`子数组存在。 原则上这是正确的，但它是 O(n^3)，因为有 O(n^2) 个范围，每个子数组检查的成本为 O(n)。 它很快就变得不可行`n = 2·10^5`。 

关键的见解是我们不需要单独考虑每个子数组来选择范围。 相反，我们可以分析数字的频率。 让`freq[v]`是值的次数`v`出现在数组中。 为了满足多数条件，范围内的元素总数必须至少为`(n + k) // 2`。 这是因为，如果每个子数组内部的元素多于外部的元素，则对所有子数组求和将为我们提供该范围内元素的全局下界。 

有了这种洞察力，我们可以有效地选择最小宽度范围`[x, y]`通过对数组值的频率计数使用前缀和。 一次`[x, y]`是固定的，构造子数组很简单，只需一次贪婪的操作即可：我们保持一种平衡，即范围内的元素递增，范围外的元素递减。 每当余额为正且我们尚未创建时`k-1`子数组，我们剪切当前子数组。 最后的子数组位于数组的末尾。 这保证了每个子数组在范围内的元素多于范围外的元素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n + n log n) | O(n + n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 统计数组中每个数字出现的频率。 我们需要知道每个潜在数字出现的次数，才能有效评估候选范围。 
2. 计算这些频率的前缀和。 让`pref[v]`数组中元素的数量小于或等于`v`。 那么对于任意范围`[x, y]`，该范围内的元素总数为`pref[y] - pref[x-1]`。 
3. 确定范围内满足所有多数条件所需的最小元素数`k`子数组。 这是`(n + k) // 2`。 这个公式来自于要求每个子数组的内部元素多于外部元素。 如果我们将所有人的最低多数相加`k`子数组，内部元素总数必须至少为`(n + k) // 2`。 
4. 滑动窗口`[x, y]`使用前缀和来遍历可能的数字。 开始于`x = 1`并移动`y`到最小值，使得里面的总元素`[x, y]`至少是`(n + k) // 2`。 记录宽度`y - x`。 移动`x`向前并重复以找到最小宽度。 
5.一旦达到最佳状态`[x, y]`找到后，贪婪地构造子数组。 迭代数组并保持运行平衡。 对于每个元素，如果在里面则加1`[x, y]`如果在外面则减1。 当余额变为正值且小于`k-1`创建子数组，剪切当前子数组并重置余额。 最后一个子数组在数组的末尾结束。 

为什么它有效：通过选择至少具有的最小范围`(n + k) // 2`元素，我们确保有足够的元素来形成`k`多数条件成立的子数组。 贪婪平衡方法保证每个子数组单独满足内部>外部要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        count = [0] * (n + 2)
        for num in a:
            count[num] += 1
        
        pref = [0] * (n + 2)
        for i in range(1, n + 2):
            pref[i] = pref[i-1] + count[i]
        
        needed = (n + k) // 2
        x, y = 1, n
        best_width = n + 1
        left = 1
        for right in range(1, n + 1):
            while pref[right] - pref[left - 1] >= needed:
                if right - left < best_width:
                    best_width = right - left
                    x, y = left, right
                left += 1
        
        print(x, y)
        segments = []
        balance = 0
        last = 0
        cuts = 0
        for i in range(n):
            if x <= a[i] <= y:
                balance += 1
            else:
                balance -= 1
            if balance > 0 and cuts < k - 1:
                segments.append((last + 1, i + 1))
                last = i + 1
                balance = 0
                cuts += 1
        segments.append((last + 1, n))
        for l, r in segments:
            print(l, r)

if __name__ == "__main__":
    solve()
```第一部分计算频率和前缀和以有效找到最小宽度范围`[x, y]`其中至少包含`(n + k) // 2`元素。 第二部分构建`k`子数组使用运行平衡来确保每个子数组具有范围内的大多数元素。 边界处理至关重要：我们在以下位置停止切割`k-1`子数组，以便最后一个子数组延伸到数组的末尾。
