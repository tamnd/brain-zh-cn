 ## 解决方案
 ## 问题理解

 我们给定一个整数$n$并且必须将其分成三个数字，其总和恰好为$n$。 

这三个数必须同时满足三个条件。 它们必须都是正数，它们必须是不同的，并且它们都不能被整除$3$。 

对于每个测试用例，我们只需要找到一个有效的构造。 如果不存在这样的结构，我们打印`NO`。 

从算法的角度来看，约束非常小。 虽然$n$可以大到$10^9$, 最多只有$10^4$测试用例。 每个测试用例执行恒定工作量的任何解决方案实际上都是瞬时的。 对可能的三元组进行强力搜索是不可能的，因为搜索空间的增长大致为$O(n^2)$或者更糟，对于接近的值来说这是完全不可行的$10^9$。 

棘手的部分不是效率而是建设。 

一种边缘情况是当$n$非常小。 例如：```
n = 4
```唯一正的不同三元组总和为$4$需要使用类似的数字$(1,1,2)$或者它的排列，它们并不明显。 正确答案是`NO`。 

另一个重要的情况是当剩下的第三个数字可以被整除时$3$。 

假设我们总是选择$1$和$2$作为前两个数字。 然后：```
n = 9
```会产生```
1 + 2 + 6 = 9
```但$6$可以整除$3$，所以这个构造是无效的。 一个解决方案仅使用$(1,2)$将在所有倍数上失败$3$。 

最后一个微妙的情况是第三个数字与所选数字之一相冲突。 

例如：```
n = 6
```使用$(1,2)$给出```
z = 3
```它可以被整除$3$。 

使用$(1,4)$给出```
z = 1
```这是不明确的。 

正确答案是`NO`。 

## 方法

 暴力解决方案会尝试所有三元组$(x,y,z)$和$$x+y+z=n,$$检查所有数字是否为正数、不同且不能被整除$3$，然后在找到有效的三元组时停止。 

这种方法是正确的，因为它明确地检查了每种可能性。 问题在于搜索空间的大小。 均匀固定$z=n-x-y$, 大致有$O(n^2)$候选对$(x,y)$。 为了$n=10^9$，这是完全不可能的。 

关键的观察是我们不需要搜索。 我们只需要一种有效的构造。 

涉及整除性的限制$3$建议使用余数为模的小数$3$是已知的。 

考虑两种情况。 

如果$n$不能被整除$3$， 选择$$x=1,\qquad y=2.$$两个数都不能被整除$3$，并且它们是不同的。 第三个数字是$$z=n-3.$$自从$n \not\equiv 0 \pmod 3$,$$z \equiv n \pmod 3,$$所以$z$也不能被整除$3$。 

如果$n$可以整除$3$，之前的构建失败是因为$z=n-3$也可以被整除$3$。 我们需要一对不同的。 选择$$x=1,\qquad y=4.$$然后$$z=n-5.$$因为$n \equiv 0 \pmod 3$,$$z \equiv -5 \equiv 1 \pmod 3,$$所以$z$不能被整除$3$。 

唯一剩下的任务是检查$z$保持正值并且与所选数字不同。 这只对小值失败，例如$n=6$和$n=9$，没有有效答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 最佳 |$O(1)$每个测试用例|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读$n$。 
2.如果$n \le 6$， 打印`NO`。 

任何三个不同的正整数具有最小可能的和$$1+2+3=6.$$为了$n<6$解决方案是不可能的，并且对于$n=6$唯一不同的三元组是$(1,2,3)$其中包含多个$3$。 
3.如果$n \bmod 3 \ne 0$， 选择$$x=1,\quad y=2,\quad z=n-3.$$4. 检查是否$$z>2.$$这保证了积极性和独特性。 
5. 打印`YES`和三重。 
6. 如果$n \bmod 3 = 0$， 选择$$x=1,\quad y=4,\quad z=n-5.$$7. 如果$$z\le4,$$打印`NO`。 

唯一有问题的倍数$3$大于$6$是$n=9$，这给出了$z=4$并违反了明确性。 
8. 否则打印`YES`和三重。 

### 为什么它有效

 对于$n \not\equiv 0 \pmod 3$, 施工$(1,2,n-3)$使用全部非零模数$3$。 自从$n-3 \equiv n \pmod 3$，第三个数字也不能被$3$。 

为了$n \equiv 0 \pmod 3$, 施工$(1,4,n-5)$有效是因为$n-5 \equiv 1 \pmod 3$。 同样，没有一个数字可以被整除$3$。 

唯一的失败发生在第三个数字变为非正数或等于所选值之一时。 这些情况正是已经被拒绝的小值。 每个较大的有效案例都会得到正确的构造。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())

    if n <= 6:
        print("NO")
        continue

    if n % 3 != 0:
        print("YES")
        print(1, 2, n - 3)
    else:
        z = n - 5

        if z == 1 or z == 4:
            print("NO")
        else:
            print("YES")
            print(1, 4, z)
```第一个分支处理不能被三整除的数字。 这对$(1,2)$是固定的，并且剩余值自动避免被三整除。 

第二个分支处理三的倍数。 这对$(1,4)$避免模​​数$3$破坏第一个结构的问题。 

唯一的特殊失败是$n=9$，其中第三个值变为$4$，使数字不明确。 条件`z == 1 or z == 4`捕获所有有问题的案例。 在实践中，经过前面的`n <= 6`检查，仅`z == 4`可能会发生。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())

        if n <= 6:
            out.append("NO")
            continue

        if n % 3 != 0:
            out.append("YES")
            out.append(f"1 2 {n - 3}")
        else:
            z = n - 5
            if z == 1 or z == 4:
                out.append("NO")
            else:
                out.append("YES")
                out.append(f"1 4 {z}")

    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

# provided sample
assert run("4\n10\n4\n15\n9\n") == (
    "YES\n1 2 7\n"
    "NO\n"
    "YES\n1 4 10\n"
    "NO"
)

# minimum value
assert run("1\n1\n") == "NO"

# smallest valid non-multiple of 3
assert run("1\n7\n") == "YES\n1 2 4"

# smallest valid multiple of 3 after failure at 9
assert run("1\n12\n") == "YES\n1 4 7"

# maximum input
assert run("1\n1000000000\n") == "YES\n1 2 999999997"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`1`|`NO`| 尽可能少的输入 |
 |`7`|`YES 1 2 4`| 最小有效结构|
 |`12`|`YES 1 4 7`| 使用第二种模式的 3 的倍数 |
 |`1000000000`| 有效三重| 最大允许值|

 ## 边缘情况

 考虑：```
n = 6
```该算法立即拒绝它，因为`n <= 6`。 唯一不同的正三重求和$6$是$(1,2,3)$， 和$3$可以整除$3$。 正确答案是`NO`。 

考虑：```
n = 9
```算法进入三的倍数分支。$$z = 9 - 5 = 4.$$三重将是$(1,4,4)$，这并不明显。 算法打印`NO`，这是正确的。 

考虑：```
n = 8
```该算法使用第一种结构。$$(1,2,5).$$所有数字都是正数、不同的且不能被整除$3$。 该算法打印一个有效的答案。 

考虑：```
n = 999999999.
```自从$n$可以整除$3$，算法构造$$(1,4,999999994).$$第三个值是正值、独特且一致$1 \pmod 3$。 所有要求均得到满足，这表明即使是最大规模的建设也能进行。
