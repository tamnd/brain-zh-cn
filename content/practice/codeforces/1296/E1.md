 **求解时间：** 2m 3s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们有一串小写字母。 每个位置必须分配两种颜色之一：0 或 1。 

选择颜色后，只有当相邻字符的颜色不同时，我们才可以交换它们。 我们可以根据需要多次执行此类交换。 目标是确定某种颜色是否允许将字符串重新排列为非递减字母顺序。 

输出不是交换序列。 我们只需要打印有效的颜色（如果存在）。 

关键限制隐藏在交换规则内。 两个相邻的相同颜色的字符永远不能直接交换。 更重要的是，它们的相对顺序永远不会改变。 每次交换都会交换不同颜色的字符，因此属于同一颜色类别的字符始终保留其原始顺序。 

长度最多为 200。这足够小，即使是$O(n^2)$或者$O(n^3)$解决方案是完全安全的。 这个小约束暗示我们可以显式地构建和分析持仓图表。 

一个常见的错误是只考虑角色本身而忽略位置。 颜色分配给索引，而不是字母值。 两个相同的字母可能会呈现不同的颜色。 

考虑字符串：```
ba
```排序后的字符串是`"ab"`。 这两个字符必须改变顺序。 由于相同颜色的字符无法改变其相对顺序，因此它们必须接收不同的颜色。 一个有效的答案是：```
YES
01
```另一个微妙的情况是：```
cba
```排序后的字符串是`"abc"`。 每对位置都是颠倒的。 位置 1 与位置 2、3 冲突，位置 2 与位置 3 冲突。这就形成了一个冲突三角形，不能只用两种颜色来着色。 正确答案是：```
NO
```仅基于字符值的粗心贪婪着色可能会错误地声称存在解决方案。 

另一种边缘情况是许多字母相等：```
aaaa
```该字符串已经排序。 完全没有任何限制，因此每种颜色都有效。 输出可以是：```
YES
0000
```将相同的字母视为倒置会错误地引入不必要的限制。 

## 方法

 蛮力方法是尝试所有可能的颜色。 由于每个位置都有两个选择，因此有$2^n$着色。 对于每种颜色，我们可以检查排序后的字符串是否可达。 即使是为了$n=200$,$2^{200}$这是一个天文数字，所以这是不可能的。 

为了找到更好的东西，我们需要了解交换操作实际上允许什么。 

假设有两个位置$i<j$有相同的颜色。 它们的相对顺序永远不会改变，因为每次允许的交换都发生在不同颜色之间。 因此，在每个颜色类中，字符的子序列必须永远保持其原始顺序。 

现在看一个反转：位置$i<j$和$s_i>s_j$。 

在最终排序的字符串中，这两个字符必须以相反的顺序出现。 由于相同颜色的位置永远无法反转其相对顺序，因此每次反转的端点必须接收不同的颜色。 

这一观察完全说明了问题的特征。 创建一个图，其顶点是字符串位置。 如果两个位置形成反转，则连接它们。 每条边都要求其端点具有不同的颜色。 

问题变成：反演图可以用两种颜色着色吗？ 

这正是二部图的定义。 

如果图是二分图，则二分图给出有效的着色。 如果不是二分的，则某些奇怪的循环会迫使颜色要求相互矛盾，并且不存在解决方案。 

简单版本的设计使得构建整个反演图的成本低廉。 只有$200$位置，因此检查所有对需要$O(n^2)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 创建一个图，每个字符串位置有一个顶点。 
2. 对于每对索引$i<j$，检查是否$s_i>s_j$。 
3. 如果存在反转，则在之间添加无向边$i$和$j$。 

该边缘意味着两个位置必须接收不同的颜色，否则它们的顺序将永远无法纠正。 
4. 使用 DFS 或 BFS 运行标准二分检查。 
5. 每当我们遍历一条边时，为相邻顶点指定相反的颜色。 
6. 如果我们遇到一条边，其端点已经具有相同的颜色，则该图不是二分图。 打印`"NO"`。 
7. 如果所有连接的组件都成功着色，则打印`"YES"`并将分配的颜色作为二进制字符串输出。 

### 为什么它有效

 每个反转都必须按最终排序顺序解决。 共享一种颜色的两个位置永远保留其相对顺序，因此每次反转的端点必须具有不同的颜色。 反演图准确地记录了这些要求。 

如果图是二分图，则根据二分图分配颜色满足每个反转约束。 然后，每个颜色类形成一个保持内部有序的子序列。 由于每个反转对都位于两个颜色类中，因此可以通过允许的交换对所有有问题的对进行重新排序，并且可以将字符串转换为排序顺序。 

如果图不是二分图，则某些反转约束集要求位置同时为两种颜色。 不存在有效的着色。 因此算法返回`"YES"`恰好当解决方案存在时。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()

g = [[] for _ in range(n)]

for i in range(n):
    for j in range(i + 1, n):
        if s[i] > s[j]:
            g[i].append(j)
            g[j].append(i)

color = [-1] * n

def dfs(v, c):
    color[v] = c

    for to in g[v]:
        if color[to] == -1:
            if not dfs(to, c ^ 1):
                return False
        elif color[to] == c:
            return False

    return True

for i in range(n):
    if color[i] == -1:
        if not dfs(i, 0):
            print("NO")
            sys.exit()

print("YES")
print("".join(map(str, color)))
```第一个嵌套循环构造反转图。 每对位置都被检查一次。 每当左侧字符大于右侧字符时，我们就会创建一条边缘，因为这些位置必须接收相反的颜色。 

这`color`数组存储二分着色。 值为`-1`表示该顶点尚未被访问过。 

DFS 沿着图的边缘分配交替的颜色。 如果已经着色的邻居与当前顶点具有相同的颜色，我们就发现了矛盾。 此时图就不是二分图了，答案是`"NO"`。 

该图可能有多个连接的组件，因此只要找到未访问的顶点，外循环就会启动新的 DFS。 

一个微妙的细节是使用`c ^ 1`。 因为颜色只是`0`和`1`, XOR 可以干净地在它们之间翻转。 

另一个细节是相同的字母不会产生边缘。 只有严格的反转才重要。 包含相同字符的位置可能会在排序字符串中保持其相对顺序，因此不需要任何约束。

import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n = int(input())
    s = input().strip()

    g = [[] for _ in range(n)]

    for i in range(n):
        for j in range(i + 1, n):
            if s[i] > s[j]:
                g[i].append(j)
                g[j].append(i)

    color = [-1] * n

    def dfs(v, c):
        color[v] = c
        for to in g[v]:
            if color[to] == -1:
                if not dfs(to, c ^ 1):
                    return False
            elif color[to] == c:
                return False
        return True

    for i in range(n):
        if color[i] == -1:
            if not dfs(i, 0):
                return "NO\n"

    return "YES\n" + "".join(map(str, color)) + "\n"

# provided sample
out = run("9\nabacbecfd\n")
assert out.startswith("YES\n")

# minimum size
assert run("1\na\n") == "YES\n0\n", "single character"

# already sorted
assert run("4\naaaa\n") == "YES\n0000\n", "all equal"

s = "".join(chr(ord('z') - (i % 26)) for i in range(200))

 ## 边缘情况

 ### 单个字符

 输入：```
1
a
```不存在一对位置，因此反演图有一个孤立的顶点。 

DFS 将其着色为`0`。 

输出：```
YES
0
```该算法自然地处理孤立的顶点，因为每个连接的组件都是独立处理的。 

### 所有字符都相等

 输入：```
4
aaaa
```每次比较都不满足条件`s[i] > s[j]`，所以没有添加边。 

该图由四个孤立的顶点组成。 

该算法输出：```
YES
0000
```相同的字母不会产生倒置，这正是我们想要的。 

### 严格递减字符串

 输入：```
3
cba
```每对都是一个反转。 

图形变成三角形：```
0-1
|/
2
```三角形不是二分三角形。 在 DFS 过程中，顶点 1 和 2 接收相同的颜色，但它们之间存在一条边。 立即检测到冲突。 

输出：```
NO
```这是不可能满足反演约束的最小示例。 

### 具有实际倒装的重复字母

 输入：```
4
baab
```反转边为：```
(0,1), (0,2)
```该图是一条以顶点 0 为中心的简单路径。 

有效的着色是：```
0110
```重复的`'a'`字符之间没有边缘，因为相同的字母不是倒置。 该算法可以正确区分相等值和真正的排序冲突。
