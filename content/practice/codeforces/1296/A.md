 ## 解决方案
 ## 问题理解

 我们有一个整数数组。 操作允许我们选择两个不同的位置并将值从一个位置复制到另一个位置。 由于我们可以多次重复此操作，因此可以在整个数组中重复值。 

对于每个测试用例，我们需要确定是否可以转换数组以使所有元素的最终总和为奇数。 

限制非常小。 所有测试用例的元素总数最多为 2000 个，因此即使是相对低效的解决方案也能轻松适应。 真正的挑战是了解操作可以改变什么、不能改变什么。 

关键的观察是复制值不会创建新的数字。 对于总和的奇偶性唯一重要的是元素是奇数还是偶数。 每个操作都会将一个元素替换为另一个现有元素，因此数组始终只包含最初出现的值。 

要获得奇数和，最终数组必须包含奇数个奇数元素。 由于和的奇偶性恰好是奇数计数的奇偶性，因此问题变成了奇数和偶数的问题，而不是实际大小的问题。 

一些边缘情况很容易被忽略。 

考虑：```
1
4
2 2 8 8
```答案是`NO`。 每个值都是偶数，复制偶数值永远不会创建奇数值。 仅检查操作是否可用的粗心解决方案会错误地回答`YES`。 

考虑：```
1
4
5 5 5 5
```答案是`NO`。 所有值都是奇数，并且有四个，因此总和是偶数。 由于数组中没有偶数值，因此在任何操作序列之后每个位置将始终保持奇数。 奇数元素的数量保持等于`n`，所以总和永远不会变成奇数。 

考虑：```
1
2
2 3
```答案是`YES`。 原来的和已经是奇数了，所以不需要进行任何操作。 任何假设必须执行至少一项操作的解决方案都会在这里失败。 

## 方法

 蛮力思维从直接思考操作开始。 我们可以尝试生成可达数组并检查其中是否有一个奇数和。 由于每个操作选择两个索引并且可以无限重复，因此状态空间很快就会爆炸。 即使对于适度的值`n`，可能的数组数量变得巨大。 这种做法原则上是正确的，因为它探索了所有的可能性，但它是完全不切实际的。 

蛮力思想之所以让人感觉困难，是因为它关注的是精确的值。 该操作实际上保留的信息比看起来要少得多。 与最终答案相关的唯一因素是奇偶性。 

当奇数元素的数量为奇数时，恰好出现奇数和。 

假设当前总和已经是奇数。 然后我们可以简单地进行零运算并回答`YES`。 

现在假设当前的总和是偶数。 我们可以改变它的奇偶性吗？ 

如果数组同时包含奇数和偶数，那么我们可以将一个奇偶校验复制到另一个奇偶校验的位置。 这允许我们更改奇数元素的计数。 特别是，我们总是可以使奇数的个数变为奇数，从而使总和为奇数。 

如果所有数字都是偶数，则可能出现的每个值都是偶数，因此总和始终保持偶数。 

如果所有数字都是奇数，则每个位置始终包含奇数。 奇数元素的数量永久等于`n`。 仅当以下情况时，总和才是奇数`n`很奇怪。 由于我们目前正在考虑总和为偶数的情况，这意味着`n`是偶数，答案是`NO`。 

这导致了一个非常简单的标准：

 如果当前总和是奇数，则回答`YES`。 

否则请回答`YES`仅当数组包含至少一个奇数和至少一个偶数时。

 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算所有元素的总和。 
2. 如果总和是奇数，则打印`"YES"`。 

不需要任何操作，因为目标条件已经满足。 
3. 统计数组中是否至少包含一个奇数元素。 
4. 统计数组中是否至少包含一个偶数元素。 
5. 如果双方都存在，则打印`"YES"`。 

拥有两个奇偶校验意味着我们可以通过复制操作修改奇数元素的数量，从而可以实现奇数总和。 
6. 否则，打印`"NO"`。 

当所有值都具有相同的奇偶性时，每个未来值也具有该奇偶性，因此偶数和不能变成奇数。 

### 为什么它有效

 和的奇偶性仅取决于奇数元素数量的奇偶性。 如果初始总和已经是奇数，则目标立即实现。 

当奇数和偶数都存在时，复制允许我们将元素从一个奇偶校验类转换为另一奇偶校验类，从而更改奇数元素的数量。 这使得可以获得奇数的奇数个，从而获得奇数和。 

当所有值都是偶数时，每个可达数组完全由偶数组成。 当所有值都是奇数时，每个可达数组完全由奇数组成。 无论哪种情况，奇偶校验结构都不能改变，因此偶数总和永远保持偶数。 这些正是答案所在的情况`NO`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    if sum(a) % 2 == 1:
        print("YES")
        continue

    has_odd = any(x % 2 for x in a)
    has_even = any(x % 2 == 0 for x in a)

    if has_odd and has_even:
        print("YES")
    else:
        print("NO")
```第一个检查处理最简单的情况。 如果总和已经是奇数，我们根本不需要推理运算。 

变量`has_odd`和`has_even`记录每个奇偶校验是否出现在数组中。 他们的实际计数是不必要的。 只有双方的存在才重要。 

最终条件直接来自证明。 仅当数组中某处奇数和偶数都可用时，偶数和才能更改为奇数。 

不存在溢出问题，因为最大可能的总和仅为`2000 × 2000 = 4,000,000`，它很容易适合 Python 整数。

 输入：```

由于只有一个值，并且每个操作都会复制一个现有值，因此数组永远不能包含奇数。

 输入：```

算法打印`NO`。 

在任何分配序列之后，每个位置都将始终包含一个奇数。 奇数元素的数量仍然存在`4`，所以总和永远保持偶数。
