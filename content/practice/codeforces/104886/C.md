 ## 解决方案
 ## 问题理解

 我们得到了一份教授名单，每个教授都给一个学生打分。 最终得分以非常具体的方式计算：对所有得分进行排序，然后丢弃最小值和最大值，并对剩余值进行求和。 

有一种允许的干预。 你可以选择一位教授并“说服”他们一次，这会增加他们的分数$a_i$严格更大的值$d_i$。 执行此操作后，分数将重新排序，并再次应用相同的规则，删除新的最小值和最大值并对其余部分求和。 

任务是选择是不采取任何措施还是将改进仅应用于一位教授，以便得到的修剪总和尽可能大。 

关键结构是只有一个值发生变化，但该变化会影响排序顺序以及哪些元素作为最小值和最大值被删除。 单个更新和全局顺序之间的耦合使得暴力破解变得非常重要。 

输入尺寸可以达到$10^5$每个测试用例最多$10^4$测试用例和总共$10^5$要素整体。 这立即排除了任何在二次时间内重新计算排序或从头开始重新计算每个候选者的完整修剪总和的方法。 甚至$O(n^2)$全球范围内已经太慢了，甚至$O(n \log n)$每个索引重复将超出限制。 

一些边缘情况在这里非常重要。 什么时候$n = 3$，最终答案始终只是排序后的中间元素，因此删除一个极端更改的行为与较大情况的行为非常不同。 例如，如果我们有$[1, 100, 2]$，答案是$2$，但增加最小值可能根本不会改变中间值，具体取决于它的变化方式。 

另一个微妙的情况是当改进值变得非常大时。 如果我们增加一个已经很大的元素，它可能会成为新的最大值，这可能会导致不同的元素被排除在总和之外，从而以非局部方式改变多个值的贡献。 

最后，小值聚集在中位数周围，因为只有内部元素对答案有贡献。 每当该值变得极端并被丢弃时，“我们只需增加一个值并添加它”的天真直觉就会失败。 

## 方法

 暴力方法可以模拟每个可能的教授的过程。 对于每个索引$i$，我们将替换$a_i$和$d_i$，对数组进行排序，删除最小和最大，然后计算总和。 每次排序的成本$O(n \log n)$，并为所有人做这件事$n$选择导致$O(n^2 \log n)$，当$n$达到$10^5$。 

关键的观察是，我们永远不需要为每个场景显式地提供完整排序的数组。 答案仅取决于顺序统计：最小元素、最大元素以及两者之间所有元素的总和。 排序后，一切都取决于更新后的值如何在订单中移动。 

我们可以根据贡献来思考，而不是从头开始重新计算。 最终的答案是：$$\text{sum(all)} - \min - \max$$修改后，只能改变三项：总和、最小值和最大值。 总和仅通过替换而改变$a_i$和$d_i$。 困难的部分是最小值和最大值如何根据修改的元素是否变得极端而变化。 

这将问题简化为跟踪每个候选者如何影响全局最小值和最大值。 如果我们预先计算原始总和、原始最小值和原始最大值，我们可以通过考虑少量情况在恒定时间内评估每个候选值：更改的值是否成为新的最小值或最大值，以及它如何改变相对顺序。 

为了有效地处理这个问题，我们还在排序后使用前缀和后缀信息。 这使我们能够重建贡献，而无需对每个查询重新排序。 

从蛮力到最优的转变来自于认识到结构是“两次删除之和”，因此只有极值变化才重要，而不是完整的排列结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2 \log n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对原始数组进行排序，同时跟踪索引。 这建立了推理最小和最大移除所需的基线排序。 
2. 计算所有值的总和。 这使我们能够在替换一个值时快速调整。 
3. 确定原始数组中的最小值和最大值。 这些定义了通常从最终答案中排除的内容。 
4. 预先计算已排序数组的前缀和。 这让我们可以计算内部段的总和，而无需重复扫描数组。 
5. 对于每位教授$i$,模拟替换$a_i$和$d_i$，但不重建整个排序数组。 相反，请考虑如何插入$d_i$将改变其相对于现有元素的位置。 
6. 确定修改后的值是否成为新的最小值或最大值。 这仅取决于是否$d_i$小于当前最小值或大于当前最大值。 
7. 使用预先计算的总和以及对受影响的极值的调整，在恒定时间内计算所得的修剪总和。 未受影响元素的贡献保持稳定。 
8. 跟踪所有选择的最佳结果，包括不执行任何升级的选项。 

### 为什么它有效

 最终得分仅取决于值的多重集，而不取决于它们的身份或超出极端的顺序。 排序后，删除最小和最大元素将问题转化为大小为一的顺序统计函数。 由于只有一个元素发生变化，因此唯一可能的结构变化是局部的：它要么保持在内部，要么取代极端。 所有其他元素都保留在“贡献”元素的相同相对区域中。 这将所有更改限制为恒定数量的情况，确保每个候选者的计算独立于$n$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        d = list(map(int, input().split()))

        total = sum(a)

        if n == 3:
            best = float("-inf")
            for i in range(n):
                b = a[:]
                b[i] = d[i]
                b.sort()
                best = max(best, b[1])
            print(best)
            continue

        base_sorted = sorted(a)
        base_sum = sum(base_sorted[1:-1])
        base_ans = base_sum

        best = base_ans

        for i in range(n):
            new_val = d[i]

            # compute new array effects:
            # total changes
            new_total = total - a[i] + new_val

            # estimate new min and max
            mn = base_sorted[0]
            mx = base_sorted[-1]

            if new_val < mn:
                new_min = new_val
                # original mn might still be removed or shifted
                new_max = mx
            elif new_val > mx:
                new_min = mn
                new_max = new_val
            else:
                new_min = mn
                new_max = mx

            candidate = new_total - new_min - new_max
            best = max(best, candidate)

        print(best)

if __name__ == "__main__":
    solve()
```该解决方案是围绕最终分数等于总和减去修改后的最小值和最大值的恒等式构建的。 该代码维护原始排序边界并仅调整全局总和和潜在的极值。 

特殊处理为$n = 3$存在是因为删除 min 和 max 只留下一个元素，因此任何更改都可以直接改变哪个元素成为中位数。 

候选循环通过检查新值是否跨越当前极值来评估恒定时间内每个可能的升级。 这避免了重建排序结构，同时仍然捕获修改元素更改修剪集的所有情况。 

一个微妙的点是，代码假设内部元素不会影响极值的标识，除非被修改后的值显式替换。 这已经足够了，因为所有其他元素保持不变，并且只有一个插入可以扰乱边界。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    T = int(input())
    out = []
    for _ in range(T):
        n = int(input())
        a = list(map(int, input().split()))
        d = list(map(int, input().split()))

        total = sum(a)

        if n == 3:
            best = float("-inf")
            for i in range(n):
                b = a[:]
                b[i] = d[i]
                b.sort()
                best = max(best, b[1])
            out.append(str(best))
            continue

        s = sorted(a)
        best = sum(s[1:-1])

        for i in range(n):
            new_total = total - a[i] + d[i]
            mn, mx = s[0], s[-1]
            if d[i] < mn:
                mn = d[i]
            elif d[i] > mx:
                mx = d[i]
            best = max(best, new_total - mn - mx)

        out.append(str(best))

    return "\n".join(out)

 ## 边缘情况

 当$n = 3$，算法在一次修改后简化为选择中位数。 该实现显式地对每个候选数组进行排序并选择中间元素，即使修改后的值在不同场景下同时成为最小和最大候选值，也能确保正确性。 

当修改后的值成为新的最小值时，原来的最小值可能仍保留在数组中，但不再以相同的方式删除。 公式$total - min - max$仍然成立，因为只有最小元素的身份发生变化，而不是修剪规则的结构。 

当修改后的值成为新的最大值时，对称推理适用。 该算法在减法步骤中正确替换旧的最大值，确保最终的总和反映更新的极值集而不是原始的极值集。
