 ## 解决方案
 ## 问题理解

 任务是通过检查是否可以同时满足所有要求的时间间隔来确定给定的时间表是否可行。 每个测试用例描述了几个时间约束，每个约束代表了某个条件必须成立的一段时间。 目标是找出是否存在满足所有约束的非空重叠，或者等效地，所有区间的交集是否非空。 

输入可以解释为数轴上间隔的集合。 每个间隔将有效计划限制在一个连续的范围内。 最终答案完全取决于应用所有约束后这些范围是否至少有一个共同点。 

从复杂性的角度来看，问题的设计使得直接模拟就足够了。 约束足够小，可以接受重复相交的间隔，甚至检查有界范围内的每个可能的时间单位。 如果最大坐标值很大但每个测试用例仍然可以管理，则 O(n × maxR) 扫描仍然可行。 如果 n 很大但间隔已经标准化和排序，则线性扫描就足够了。 

当间隔没有按顺序正确交叉时，就会出现微妙的失败情况。 例如，如果我们独立处理间隔而不维护正在运行的交集，我们可能会错误地得出可行性结论。 

考虑：

 输入：```
3
1 5
4 8
6 10
```正确答案取决于所有三个区间的重叠是否非空。 朴素的并集检查可能会说“是”，因为所有间隔在某个点都成对重叠，但完整的交集是空的，因为没有单个点位于所有三个点中。 

另一种边缘情况是当区间在端点处接触时。 例如：```
2
1 3
3 5
```如果端点包含在内，则此方法有效，否则无效。 正确的解决方案必须一致地对待边界。 

## 方法

 蛮力的想法很简单。 我们从完整可能的时间范围开始，并反复将其与每个间隔相交。 处理完每个约束后，我们将有效区域缩小到当前有效段与下一个区间之间的重叠部分。 如果路口在任何时候变得空了，我们可以立即停车。 

这是可行的，因为每个约束独立地限制解空间，并且最终的可行区域恰好是所有约束的交集。 正确性直接来自同时满足的定义。 

更简单的版本会模拟全局范围内的每个可能的时间单位，并检查它是否满足所有间隔。 当坐标范围很大时，这种方法会变得太慢，因为它可能需要迭代每个间隔的每个单元。 

关键的观察是我们永远不需要检查各个时间点。 每个区间仅影响当前可行性的下限和上限。 因此，维护表示当前交集的两个变量就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举| O(n × R) | O(1) | O(1) | 太慢了|
 | 间隔交叉点扫描 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们维持当前可行的区间，最初设置为尽可能宽的范围。 然后我们逐步限制它。 

1. 将当前可行区间初始化为 [L, R]，通常根据公式设置为第一个区间或无限范围。 这表示应用约束之前所有可能的有效计划。 
2. 对于每个传入的区间 [l, r]，将可行区间更新为 [max(L, l), min(R, r)]。 此步骤强制任何有效的解决方案必须同时满足先前的约束和新的约束。 
3. 更新后，检查区间是否失效，即max(L, l) > min(R, r)。 如果发生这种情况，则没有时间点满足所有约束，因此答案立即为假。 
4. 继续按顺序处理所有区间，始终缩小可行区域。 
5、处理完所有区间后，如果该区间仍然有效，则输出true； 否则输出 false。 

### 为什么它有效

 在每一步中，维护的间隔恰好是迄今为止处理的所有间隔的交集。 这个不变量成立是因为区间交集是结合律和交换律的。 一旦交叉点变空，未来的间隔就无法恢复可行性，因为交叉点只能缩小或保持不变。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    L, R = map(int, input().split())
    
    for _ in range(n - 1):
        l, r = map(int, input().split())
        L = max(L, l)
        R = min(R, r)
        if L > R:
            print("NO")
            return
    
    print("YES")

if __name__ == "__main__":
    solve()
```该解决方案将第一个区间读取为初始可行范围，并迭代地将其与每个后续区间相交。 关键的实现细节是提前终止：一旦间隔变得无效，就不需要进一步处理，因为不可能恢复。 

比较`L > R`是唯一需要的正确性检查。 它必须是严格的，因为当端点包含在内时，相等仍然是有效的单点重叠。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个间隔都以恒定时间更新处理一次 |

 ## 边缘情况

 一种边缘情况是间隔折叠成一个点。 例如：```
3
1 10
5 5
5 7
```该算法首先将 [1, 10] 约简为 [5, 5]，然后与 [5, 7] 相交并保留 [5, 5]。 由于允许相等，因此输出仍然有效。 

另一个边缘情况是第二个间隔处的立即不相交：```
2
1 3
10 20
```第一次更新后，[1, 3] 与 [10, 20] 相交，产生一个无效区间，其中 L > R。算法正确地提前停止。 

最后一个微妙的情况是大范围，天真的枚举会失败，但交集方法每步保持恒定时间，确保正确性而不依赖于坐标限制。
