 ## 解决方案
 ## 问题理解

 任务是将给定的整数 _n_ 分解为其素数因子，并以非递减顺序打印它们，每个素数根据其重数重复。 本质上，如果一个数字是素数的乘积，例如$n = 2^2 \cdot 3^1 \cdot 5^2$，输出应该是`2 2 3 5 5`。 输入是 2 到 250 之间的单个整数，该整数足够小，因此我们不需要像 Pollard's rho 或针对非常大的数字优化的筛子等高级分解算法。 

因为上限只有 250，所以我们可以执行与$n$或者$\sqrt{n}$在 2 秒的时间限制内轻松地完成任务。 当 _n_ 本身是素数（例如 2, 3, 197）时，会出现主要的边缘情况，在这种情况下，因式分解就是`n`，或者当 _n_ 是素数的完全平方时（例如，49 = 7*7），它测试算法是否正确处理重复因子。 一种简单的方法，除以 _n_ 之前的每个数字，在这里会起作用，因为$n \le 250$，但我们可以做得稍微好一点，只考虑潜在的除数$\sqrt{n}$。 

另一个微妙之处是顺序：因子必须以非递减顺序打印，并且多重性必须完全展开，而不是总结为幂。 例如，8 = 2^3 必须打印为`2 2 2`， 不是`2^3`。 

## 方法

 暴力方法迭代从 2 到 _n_ 的所有整数，测试整除性。 每次除数 _d_ 除 _n_ 时，都会打印它，并且 _n_ 除以 _d_ 直到它不再整除。 这是可行的，因为任何大于 1 的整数要么是素数，要么可以因式分解为素数。 对于小_n_，除法尝试的次数大致为$n$，这是可以接受的$n \le 250$。 

允许优化的观察结果是没有因素大于$\sqrt{n}$（可能_n_本身除外）需要在重复试验中考虑。 一旦我们删除了所有较小的因子，任何剩余的数字都必须是素数。 这让我们只循环到$\sqrt{n}$并单独处理最后剩下的号码。 这稍微减少了不必要的检查数量，同时保持算法简单和可读。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 接受 n ≤ 250 |
 | 最佳 | O(√n) | O(√n) | O(1) | O(1) | 接受并清洁|

 ## 算法演练

 1. 从输入中读取整数_n_。 初始化一个变量`num`当我们提取因子时存储剩余的数字。 
2. 迭代所有整数`i`从 2 开始到$\sqrt{n}$。 对于每个`i`, 测试是否可以整除`num`。 
3.同时`i`划分`num`， 打印`i`并划分`num`经过`i`。 继续这个循环直到`i`不再分裂`num`。 这可以确保重复的质因数被打印正确的次数。 
4. 循环结束后$\sqrt{n}$， 如果`num`仍然大于 1，它本身一定是素因数，所以打印`num`。 
5. 用空格分隔所有打印的数字。 

原理：每个大于 1 的整数都可以唯一分解为素数。 通过迭代至$\sqrt{n}$并删除所有因子，剩下的任何数字都必须是素数，因此算法会准确地打印每个素数因子的正确次数。 不变量是在每次迭代中，`num`等于所有剩余未因式分解的主要成分的乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
num = n
i = 2
factors = []

while i * i <= num:
    while num % i == 0:
        factors.append(i)
        num //= i
    i += 1

if num > 1:
    factors.append(num)

print(' '.join(map(str, factors)))
```解决方案首先读取整数并初始化`num`跟踪要分解的剩余部分。 外循环运行的潜在因数最多为$\sqrt{num}$，内部循环删除所有出现的当前除数。 我们将所有找到的因素附加到列表中以维持顺序。 最终检查为`num > 1`处理剩余数为素数且大于的情况$\sqrt{n}$。 将这些因素连接到单个字符串中可确保正确的输出格式。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    while i * i <= num:
        while num % i == 0:
            factors.append(i)
            num //= i

    if num > 1:

 ## 边缘情况

 最小的输入，`n = 2`，产生单个因子`2`。 算法初始化`num = 2`，进入循环，看到 2*2 > 2 所以跳过内部循环，然后检查`num > 1`和打印`2`。 为了`n = 49`，循环正确地删除了 7 两次，表明超过 √n 的重复因子已完全扩展。 对于大于 √n 的素数，例如`n = 13`，最后的检查确保输出唯一的素因数。 这种方法可以处理所有不明显的场景，无需特殊分支。
