 ## 解决方案
 ## 问题理解

 我们得到一个最多包含 100 个整数的数组。 每个值都在 1 到 60 之间。任务只是以非降序打印数组。 

乍一看，这看起来像一个标准的排序问题，但异常小的值范围完全改变了问题的结构。 我们可以考虑计算每个值出现的次数，而不是考虑重新排列任意数字。 

数组长度很小。 甚至一个$O(n^2)$诸如冒泡排序或插入排序之类的排序算法可以轻松地满足限制，因为$100^2 = 10{,}000$操作可以忽略不计。 值范围甚至小于数组大小，只有 60 个不同的可能值。 这为基于计数的解决方案打开了大门，该解决方案以相对于输入大小的线性时间运行。 

主要的边缘情况来自重复值和出现在允许范围边界的值。 

考虑这个输入：```
5
7
7
7
7
7
```正确的输出是：```
7 7 7 7 7
```将值存储在一组中的粗心实现会删除重复项并仅打印一个`7`。 

另一个容易犯的错误是忘记正确处理最小值或最大值。```
4
1
60
1
60
```正确的输出是：```
1 1 60 60
```如果创建的计数数组大小为 60 而不是 61，则访问索引`60`根据语言的不同，会失败或默默地产生错误的输出。 

最小输入大小也很重要：```
1
42
```输出必须是：```
42
```当只有一个元素存在时，某些实现会意外地打印额外的空格或忘记打印任何内容。 

## 方法

 蛮力方法是使用标准比较排序。 我们反复比较元素并将较小的值移到前面。 冒泡排序、插入排序或选择排序都可以工作，因为通过比较排序可以保证最终的数组顺序是正确的。 

为了$n = 100$， 甚至$O(n^2)$复杂性很好。 Bubble sort performs at most about$100 \times 100 = 10{,}000$比较，这对于 2 秒的限制来说是微不足道的。 

这个问题有趣的部分是有界值范围。 每个数字都在 1 到 60 之间，这意味着无论输入大小如何，都只有 60 个可能的不同值。 我们可以计算每个值出现的次数，而不是直接对元素进行排序。 

观察结果是，如果我们知道价值`x`出现`k`次，那么排序后的数组必须恰好包含`k`的副本`x`，并且所有这些都必须出现在任何更大的值之前。 

这将问题转化为计算频率并按升序重建排序序列。 算法变为：

 1. 计算每个数字出现的次数。 
2. 从 1 迭代到 60。 
3. 按每个数字出现的次数打印该数字。 

这是专门针对非常小的范围的计数排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n + 60) | O(60) | 已接受 |

 ## 算法演练

 1.读取整数`n`，数组中元素的数量。 
2. Create a frequency array`cnt`大小为 61，用零初始化。 

指数`i`将存储多少次值`i`出现。 我们使用尺寸 61 所以索引`1`通过`60`都是可以直接使用的。 
3.读取每个数组元素`x`。 
4. 增量`cnt[x]`。 

处理完所有数字后，`cnt[v]`等于值的频率`v`在输入数组中。 
5. Create an empty answer list.
 6. Iterate through values from`1`到`60`。 
7. 对于每个值`v`，将其准确附加到答案列表中`cnt[v]`次。 

Since we process values in increasing order, the reconstructed sequence is automatically sorted.
 8. Print the answer list as space-separated integers.

 ### 为什么它有效

 The algorithm maintains the invariant that after processing value`v`，答案列表包含每个小于或等于的输入元素`v`，按排序顺序，具有完全正确的重数。 

由于值的每次出现都会被精确计数一次，并且随后会被精确再现一次，因此不会丢失或重复任何元素。 由于值是按递增顺序附加的，因此较大的数字不能出现在较小的数字之前。 这保证了最终的序列是排序后的数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

cnt = [0] * 61

for _ in range(n):
    x = int(input())
    cnt[x] += 1

ans = []

for value in range(1, 61):
    ans.extend([value] * cnt[value])

print(*ans)
```第一部分读取输入并构建频率数组。 由于值的范围从 1 到 60（含），因此大小为 61 的列表就足够了。 索引 0 未使用，这使索引保持简单并避免从每个值中减去 1。 

重建阶段按升序迭代值。 对于每个值，我们附加它的次数与输入中出现的次数完全相同。 表达式：```
[value] * cnt[value]
```创建一个包含当前值的重复副本的列表。 

使用`extend`而不是重复`append`调用使实现保持简洁。 

决赛`print(*ans)`自动打印以空格分隔的元素，这与所需的输出格式匹配。 这也避免了尾随空格问题。

 ## 边缘情况

 考虑所有元素都相同的情况：```
5
7
7
7
7
7
```频率数组结束于`cnt[7] = 5`。 在重建过程中，算法附加值`7`正好五次。 由于没有其他频率非零，因此最终输出变为：```
7 7 7 7 7
```这证实了重复项被保留而不是折叠。 

现在考虑边界值：```
4
1
60
1
60
```读取输入后，我们有：```
cnt[1] = 2
cnt[60] = 2
```重建循环扫描从 1 到 60（含）。 当它达到`1`，它附加两个副本。 当它达到`60`，它会再附加两个副本。 最终结果是：```
1 1 60 60
```使用大小为 61 的频率数组来生成索引`60`有效的。 

最后，考虑最小的可能输入：```
1
42
```算法增量`cnt[42]`一次。 重建附加一份副本`42`。 输出是：```
42
```单元素数组不需要特殊处理，因为计数方法自然适用于每个有效的输入大小。
