 ## 解决方案
 ## 问题理解

 我们需要计算$n$-th 六边形数。 该序列由以下公式定义$$h_n = 2n^2 - n$$输入包含单个整数$n$，输出就是这个公式产生的值。 

例如，当$n = 2$,$$h_2 = 2 \cdot 2^2 - 2 = 8 - 2 = 6$$所以答案是`6`。 

限制非常小。 的最大可能值$n$只是$100$，所以即使是非常慢的算法也会立即运行。 我们可以计算的最大六边形数是$$2 \cdot 100^2 - 100 = 19900$$它很容易适合标准整数类型。 

这个问题的主要风险不是性能，而是错误地执行公式。 一些常见的错误很容易犯。 

一种可能的错误是忘记运算符优先级。 考虑输入```
2
```正确的计算是$$2 \cdot 2^2 - 2 = 6$$粗心的实施就像`2*n*n-n`很好，但是写一些诸如`2*n^(2-n)`或令人困惑`^`在 Python 中求幂会产生错误的结果，因为 Python 使用`**`为了权力。 

另一个常见错误是使用错误的公式。 一些数字公式看起来很相似。 用于输入```
1
```正确的输出是```
1
```因为$$2 \cdot 1^2 - 1 = 1$$如果有人错误地使用$n^2$或者$3n^2-n$，序列立即变得不正确。 

## 方法

 一种蛮力方法是逐层构建六边形图案。 第一个图包含$1$单元格，下一个在它周围添加更多单元格，依此类推，直到到达$n$第-层。 自从$n \le 100$，即使直接模拟构造也足够快了。 

例如，我们可以重复添加每个新层贡献的单元格数量并维护运行总数。 这是有效的，因为每一步都反映了六边形数的几何定义。 

该方法的缺点是它执行了不必要的工作。 我们已经知道答案的确切数学公式：$$h_n = 2n^2 - n$$一旦我们认识到序列是明确给出的，就没有理由模拟任何东西。 我们可以在常数时间内直接计算出答案。 

最优解简单地写为$n$，计算公式并打印结果。

 | ---| ---| ---| ---|
 | 蛮力 |$O(n)$|$O(1)$| 已接受 |
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取整数$n$来自输入。 
2. 计算值$$2n^2 - n$$这直接符合$n$- 问题中给出的第一个六边形数。 

1. 打印计算出的值。 

### 为什么它有效

 该问题通过公式明确定义了序列$$h_n = 2n^2 - n$$该算法精确计算所提供的该表达式$n$。 由于不涉及近似、迭代或变换，因此生成的值正是所需的六边形数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

answer = 2 * n * n - n

print(answer)
```程序首先读取整数$n$。 由于只有一个值，因此不需要循环或额外的解析。 

表达式```
2 * n * n - n
```计算$2n^2 - n$。 以这种方式编写可以避免对指数运算符的任何混淆，并使算术保持简单。 

Python 整数会自动处理比该问题所需大得多的值，因此这里不可能发生溢出。 

最后直接打印结果。
