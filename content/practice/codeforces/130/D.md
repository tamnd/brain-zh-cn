 ## 解决方案
 ## 问题理解

 我们需要计算余数$a^b$除以$c$。 输入给出三个整数，每行一个。 第一个值是底数，第二个值是指数，第三个值是模数。 

直接解释很简单。 如果输入是：```
2
5
40
```然后我们计算$2^5 = 32$，然后计算$32 \bmod 40 = 32$。 

限制很小。 每个值都在 1 到 100 之间。即使最大可能的指数也只有 100，这意味着原始值$100^{100}$在数学上是巨大的，但 Python 可以自动处理任意大的整数。 在限制范围内，将数字乘以 100 次的简单循环是完全安全的。 

因为指数最多为 100，即使是$O(b)$解决方案在实践中是微不足道的。 直接实施不存在超时风险。 尽管如此，这个问题仍然是讨论模幂的好机会，因为同样的想法可以扩展到指数$10^{18}$。 

主要的边缘情况是忘记在正确的时间应用模数。 考虑：```
10
2
7
```正确答案是：```
2
```因为$10^2 = 100$， 和$100 \bmod 7 = 2$。 

具有固定大小整数的语言中的粗心实现可能会在取模之前发生溢出。 Python 避免了溢出，但模块化方法仍然是数学上正确的技术。 

另一个微妙的情况是当模数为 1 时：```
5
7
1
```正确答案是：```
0
```每个整数模 1 都等于 0。忘记此属性可能会导致对结果保持正值的错误假设。 

## 方法

 蛮力方法计算$a^b$直接乘以$a$就其本身而言$b$次，然后对余数取模$c$。 

对于这些限制，该解决方案是完全可以接受的。 指数最多为 100，因此循环最多执行 100 次乘法。 甚至使用直接求幂`a ** b`在 Python 中工作起来很舒服。 

当指数变得非常大时，蛮力法的弱点就会显现出来。 如果$b$是$10^9$，在时间限制内执行十亿次乘法的循环是不可能的。 

关键的观察是模运算允许我们立即减少中间值：$$(x \cdot y) \bmod c = ((x \bmod c) \cdot (y \bmod c)) \bmod c$$这意味着我们永远不需要存储$a^b$。 我们可以使每个中间结果小于$c$。 

从那时起，二进制求幂就变得自然了。 而不是乘以$a$确切地$b$有时，我们会重复计算底数的平方并一点一点地处理指数。 每一步都会将指数减半，从而降低复杂度$O(b)$到$O(\log b)$。 

尽管约束不需要这种优化，但它是标准且可扩展的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(b)$|$O(1)$| 已接受 |
 | 最佳 |$O(\log b)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取整数`a`,`b`， 和`c`。 
2. 初始化`result = 1`。 

该变量存储求幂模的累加值`c`。 
3. 立即减少碱基`a %= c`。 

任何更大的倍数`c`在模运算下的行为相同，因此保持基数较小可以避免不必要的增长。 
4. 虽然`b > 0`，一次一位地处理指数。 
5. 如果`b`是奇数，将当前结果乘以当前基数：$$result = (result \cdot a) \bmod c$$奇数指数意味着当前功率对最终答案有贡献。 
6. 将底座摆正：$$a = (a \cdot a) \bmod c$$幂的移动，例如$a^1$到$a^2$， 然后$a^4$,$a^8$， 等等。 
7. 使用整数除法将指数除以 2。 

这会删除刚刚处理过的位。 
8.循环结束后，打印`result`。 

### 为什么它有效

 在每次迭代中，算法都会保持以下不变式：$$result \cdot a^b \equiv \text{original } a^{\text{original } b} \pmod c$$当指数为奇数时，当前基数的一份副本必须对最终答案有贡献，因此我们将其乘以`result`。 然后我们将底数平方并将指数减半，这以压缩形式保留了相同的数学值。 

由于指数每次迭代都会丢失一位二进制数字，因此循环最终会达到零。 至此，所有必要的权力都已纳入`result`，所以它等于正确的值$a^b \bmod c$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = int(input())
b = int(input())
c = int(input())

result = 1
a %= c

while b > 0:
    if b % 2 == 1:
        result = (result * a) % c

    a = (a * a) % c
    b //= 2

print(result)
```该程序首先从标准输入读取三个整数。 

变量`result`从 1 开始，因为乘法恒等式从 1 开始。该行`a %= c`立即将基础减少到有效的模块化范围内。 这使得中间值很小并且符合模乘法的数学特性。 

该循环以二进制形式处理指数。 什么时候`b`为奇数，最低二进制位为1，表示当前的功率`a`must be included in the answer. 之后，对底数进行平方以移动到下一个 2 的幂。 

线路`b //= 2`将指数右移一位。 这是二进制求幂的核心。 

操作顺序很重要。 我们必须检查是否`b`在减半之前是奇数，否则我们将丢失有关当前位的信息。 

Python 整数永远不会溢出，但将模数保留在循环内仍然是正确的实现策略，并且对于具有固定大小整数类型的语言至关重要。

 ## 边缘情况

 考虑模数为 1 的情况：```
5
7
1
```该算法开始于：```
a %= c
```所以`a`变成`0`。 

之后的每个乘法都保留`0`模数`1`。 循环最终产生：```
0
```这在数学上是正确的，因为每个整数除以 1 时余数为 0。 

现在考虑底数已经可以被模数整除的情况：```
7
7
7
```线路`a %= c`再次将底座变成`0`。 

当算法第一次遇到奇数指数位时，它会计算：$$result = (1 \cdot 0) \bmod 7 = 0$$之后，结果就永远不会改变。 最终的答案是：```
0
```这说明了为什么在进入循环之前减少基数既正确又有效。 

最后，考虑：```
10
2
7
```一个幼稚的实现可能首先计算`10 * 10 = 100`然后才应用模数。 我们的算法立即减少：$$10 \bmod 7 = 3$$然后它完全适用于小值：$$3^2 \bmod 7 = 2$$输出是：```
2
```这个不变量仍然有效，因为模乘法在每一步都保持了等价性。
