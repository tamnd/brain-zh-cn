 ## 解决方案
 ## 问题理解

 我们被要求确定一串圆括号是否平衡。 平衡序列是每个左括号“(”都有一个相应的右括号“)”，并且括号正确嵌套。 换句话说，如果要从左到右遍历字符串，则右括号的数量在任何时候都不应多于左括号，并且到最后，左括号和右括号的数量必须完全匹配。 

输入是长度在 1 到 100 个字符之间的单个字符串，仅由 «(» 和 «)» 组成。 输出是一个简单的是/否答案，具体取决于序列是否平衡。 

这些限制意味着我们不需要高度优化的算法。 即使是 O(n²) 方法也可能在 2 秒限制内运行，因为 n ≤ 100。不过，线性方法更可取，因为它可以干净地扩展并避免不必要的计算。 

当序列以右括号开始或以左括号结束时，会出现边缘情况。 例如，“)(”是不平衡的，因为第一个字符无法匹配。另一个微妙的情况是像“((()))”这样的序列，它是完美嵌套的，但需要仔细跟踪括号的深度。单字符序列“(”或“)”是不平衡的，因为它们没有匹配的对应项。

 ## 方法

 暴力方法会通过添加元素来模拟生成所有可能的有效表达式，但这是不必要的。 一种更简单的方法是检查字符串的每个前缀，看看它包含的右括号是否多于左括号。 如果确实如此，序列就会立即不平衡。 然后最后检查左括号和右括号的总数是否匹配。 这是正确的，但无需显式前缀数组即可有效实现。 

最佳方法是利用运行计数器。 将计数器初始化为零。 从左到右遍历字符串。 当遇到左括号时，增加计数器。 当遇到右括号时，减少计数器。 如果在任何时候计数器变为负数，则表明右括号比左括号多，这意味着序列不平衡。 处理完整个字符串后，计数器为零确认平衡序列； 任何其他值表示不匹配的括号。 我们的见解是，正确的嵌套可确保计数器永远不会低于零，而末尾的相等性可确保每个左括号都有相应的右括号。

 ## 算法演练

 1.初始化一个计数器变量`balance`为 0。此计数器将跟踪不匹配的左括号的净数量。 
2、顺序遍历字符串的每个字符。 
3. 如果字符是左括号«(»，则递增`balance`1.
 4. 如果字符是右括号 «)»，则递减`balance`1.
 5. 递减后，立即检查是否`balance`是负数。 如果是，输出“NO”并停止。 负余额表示不匹配的结束括号。 
6、遍历完成后，检查是否`balance`等于零。 如果是，则输出“YES”，因为所有左括号都有匹配的右括号。 如果不是，则输出“NO”，因为存在不匹配的左括号。 

为什么它有效：不变的是在每一步，`balance`表示当前未匹配的左括号的数量。 负平衡表示右括号没有对应的左括号，这违反了平衡条件。 结尾为`balance`零确保每个左括号都是配对的。 这种方法直接镜像平衡括号序列的逻辑定义，并且不会产生不正确的输出，因为它显式跟踪必要的嵌套属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
balance = 0
for ch in s:
    if ch == '(':
        balance += 1
    else:  # ch == ')'
        balance -= 1
    if balance < 0:
        print("NO")
        sys.exit(0)
print("YES" if balance == 0 else "NO")
```该代码读取输入字符串并删除所有尾随换行符。 我们维持一个`balance`变量来跟踪不匹配的左括号。 每个左括号都会增加余额，每个右括号都会减少余额。 立即检查负余额可确保提前终止以不匹配的右括号开头的序列。 最后，检查零余额可确保所有空缺都匹配。 此实现避免了差一错误并正确处理长度为 1 的序列。

 ## 边缘情况

 对于输入 «)»，余额从 0 开始，第一个字符将其递减到 -1，立即返回 «NO»。 对于“((())”，平衡通过字符串递增和递减，以 1 结尾，结果为“NO”。这些情况证实算法正确处理以不匹配的右括号开头的序列、以不匹配的左括号结尾的序列以及嵌套结构，始终产生正确的输出。
