 ## 解决方案
 ## 问题理解

 我们得到一棵树，它是一个非循环连通图，其中$n$顶点。 任务是选择两个顶点，$a$和$b$，并删除它们之间唯一路径上的所有顶点，包括$a$和$b$他们自己。 删除之后，树分裂成一个或多个连接的组件。 目标是最大限度地增加所创建的连接组件的数量。 

输入由多个测试用例组成。 每个测试用例指定节点数$n$和$n-1$定义树的边。 对于每个测试用例，我们必须输出通过选择要删除的最佳路径可以获得的最大数量的连接组件。 

限制因素很重要：$n$可以达到$2 \cdot 10^5$，以及总和$n$所有测试用例的边界也受$2 \cdot 10^5$。 这意味着任何$O(n^2)$考虑所有顶点对的方法是不可行的。 我们需要更接近的东西$O(n)$或者$O(n \log n)$每个测试用例。 

需要注意的边缘情况包括非常小的树木。 例如，一棵树$n=2$只有两个顶点，因此删除任何顶点都会留下零个或一个连通分量。 另一种边缘情况是“星”树，其中一个中心顶点连接到所有其他顶点。 在这里，删除中心顶点可以最大限度地分割树。 天真地迭代所有路径会很慢，并且可能会错过最佳路径通常包含度数最高的顶点的结构洞察。 

## 方法

 蛮力方法是考虑每对顶点$(a, b)$，找到它们之间的路径，删除这些顶点，并计算所得的连通分量。 在最坏的情况下，有$O(n^2)$成对，每条路径都可以采取$O(n)$识别、给予$O(n^3)$总操作。 这显然太慢了$n = 2 \cdot 10^5$。 

关键的见解是关注树的结构。 删除单个顶点会将树拆分为多个与其度数相等的连接组件。 删除长度大于 1 的路径可以视为按顺序删除多个顶点。 当我们删除的路径包含高度顶点及其邻居（如果有利的话）时，将实现组件的最大数量。 

事实证明，最优策略是选择经过度数最高的顶点的路径。 如果路径的长度为一（即我们仅删除一个顶点），则连接组件的数量等于其度数。 如果路径长度为 2，则两个移除顶点的邻居对组件有贡献，但共享邻居应仅计数一次。 因此，我们可以通过考虑每个顶点的度数以及可能的相邻顶点的度数总和减 1（以考虑它们的共享边）来计算组件的最大数量。 

这种结构观察将问题从强力路径去除简化为顶点度数的简单分析。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 太慢了|
 | 最佳（基于学位）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取顶点数$n$和$n-1$边缘。 构造一个邻接表来表示树。 
3. 初始化顶点度数列表。 迭代所有边并增加每个端点的度数。 
4. 跟踪遇到的最大度数，因为删除度数最高的顶点会最大化初始碎片。 
5. 考虑连接顶点的每条边$u$和$v$。 删除两者$u$和$v$沿着它们之间的边导致连通分量等于$\text{deg}[u] + \text{deg}[v] - 1$。 跟踪所有边上该总和的最大值。 
6. 测试用例的最终答案是最大度（单个顶点去除）和所有边上的最大总和（两个顶点去除）中的最大值。 
7. 输出所有测试用例的结果。 

工作原理：该算法依赖于这样一个不变量：通过删除树中的顶点而形成的组件数量仅取决于删除的顶点的度数。 由于树是非循环的，因此没有两个不相邻的顶点共享路径之外的邻居，因此我们可以将问题简化为局部度和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    results = []
    for _ in range(t):
        n = int(input())
        deg = [0] * (n + 1)
        edges = []
        for _ in range(n - 1):
            u, v = map(int, input().split())
            deg[u] += 1
            deg[v] += 1
            edges.append((u, v))
        max_single = max(deg)
        max_pair = 0
        for u, v in edges:
            max_pair = max(max_pair, deg[u] + deg[v] - 1)
        results.append(str(max(max_single, max_pair)))
    print("\n".join(results))

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 度数存储在从 1 开始的列表中，边用于计算每个相邻对的总和。 我们取所有可能的单顶点移除和两顶点路径移除的最大值。

 ## 边缘情况

 对于只有两个顶点的树，例如：```
2
1 2
```度数组=[0,1,1]，最大单=1，最大对=1+1-1=1。 该算法正确输出 1。删除任一顶点或由两个顶点组成的路径会产生单个组件，这符合预期。 

对于一棵具有一个高度中心顶点的星形树，移除中心会将树分成多个叶子作为单独的组件。 该算法通过考虑以下因素来捕获这一点：
