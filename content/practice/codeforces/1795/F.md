 ## 解决方案
 ## 问题理解

 我们得到一棵树，它是一个连通的无环图，其中`n`顶点。 其中一些顶点最初包含碎片，每个碎片位于不同的顶点上。 每个包含芯片的顶点都是黑色的，其余的都是白色的。 游戏按轮进行，在每一轮中，我们将一个筹码移动到相邻的白色顶点，并将该顶点涂成黑色。 切屑以固定的循环顺序移动：切屑 1 首先移动，然后切屑 2，以此类推，在切屑之后环绕`k`。 如果没有相邻的白色顶点可供移动，游戏就会停止。 目标是确定可能的最大移动次数，直到没有筹码可以移动。 

输入由多个测试用例组成。 每个测试用例指定顶点数`n`，形成树的边，芯片数`k`，以及最初包含芯片的顶点。 每个测试用例的输出是一个整数：可能的最大移动次数。 

约束允许最多`2 * 10^5`跨所有测试用例的顶点，这意味着任何以简单的方式对每个测试用例的所有顶点或边进行多次迭代的解决方案都可能会超出时间限制。 按顺序移动芯片的强力模拟每次移动可能需要 O(n * k) 次操作，这太慢了。 

不明显的边缘情况包括当所有芯片都放置在叶子或相邻顶点上时。 例如，如果树是一条路径`1-2-3-4-5`我们在顶点上有芯片`1`和`5`，如果不考虑下一步应该移动哪个芯片以最大化覆盖范围的最佳顺序，则简单的模拟可能会低估移动。 另一个棘手的情况是当`k = n`，其中每个顶点已经包含一个芯片，这意味着不可能进行任何移动； 一个幼稚的解决方案可能会尝试不必要的动作。 

## 方法

 蛮力方法将按顺序模拟每个动作。 对于每次移动，它都会检查哪个芯片可以移动到相邻的白色顶点，然后更新棋盘状态。 这适用于小树，因为它忠实地代表了游戏。 然而，每个芯片的移动次数可能是 O(n)，导致每个测试用例的操作次数为 O(n*k)。 和`n`最多`2*10^5`，这显然是不切实际的。 

实现更快解决方案的关键观察是，该游戏本质上是树上的多源扩展。 每个碎片像波浪一样传播，将未访问的顶点涂成黑色。 由于切屑循环移动，因此每个切屑只能到达在“切屑转弯距离”方面比任何其他切屑更靠近它的顶点。 在树上，顶点之间的距离是唯一的，因此我们可以使用同时从所有芯片开始的广度优先搜索来确定哪个芯片首先到达哪个顶点。 每个顶点将由按 BFS 顺序最先到达它的芯片着色。 最大移动次数就是最终变成黑色的白色顶点总数减去初始移动次数`k`筹码。 

这将问题从顺序模拟移动转变为基于 BFS 的着色问题，其中距离按筹码数量缩放。 它利用树结构，其中最短路径是唯一的，多源 BFS 保证每个顶点都被最近的芯片访问。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n*k) | O(n) | 对于 n=2*10^5 | 太慢
 | 多源BFS | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 使用给定的边构建树的邻接表。 这使我们能够有效地遍历任何顶点的邻居。 
2. 初始化一个包含所有筹码位置的队列，并用距离零标记这些顶点。 这代表了BFS的起始点，距离将计算相应芯片所走了的圈数。 
3. 同时从所有芯片执行 BFS。 对于从队列中弹出的每个顶点，考虑所有未访问的邻居。 为每个邻居分配一个距离，等于当前顶点的距离加上`k`（移动的周期长度），并将其入队。 这模拟了芯片每次只能移动一次的效果`k`轮流。 
4. 计算本次 BFS 中到达的顶点数（不包括初始筹码位置）。 该计数代表最大移动次数。 
5. 返回每个测试用例的计数。 

工作原理：在 BFS 中，首先到达顶点的芯片会访问该顶点。 因为图是一棵树，所以到每个顶点都有唯一的路径，不会发生冲突。 添加`k`每次移动都确保遵守切屑轮次的循环顺序。 根据移动规则可以涂成黑色的每个顶点都将被访问一次。 

## Python 解决方案```python
import sys
from collections import deque
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u - 1].append(v - 1)
            adj[v - 1].append(u - 1)
        k = int(input())
        chips = list(map(lambda x: int(x) - 1, input().split()))
        
        dist = [-1] * n
        q = deque()
        for c in chips:
            dist[c] = 0
            q.append(c)
        
        while q:
            u = q.popleft()
            for v in adj[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + k
                    q.append(v)
        
        moves = sum(1 for d in dist if d > 0)
        print(moves)

if __name__ == "__main__":
    solve()
```邻接表有效地表示了树。 使用双端队列允许 BFS 执行 O(1) 的弹出和追加操作。 我们将 Python 列表的顶点索引调整为从零开始。 BFS 确保规则下每个可到达的顶点都被精确计数一次。 计算大于零的距离可确保我们排除初始筹码位置。
