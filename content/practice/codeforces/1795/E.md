 ## 解决方案
 ## 问题理解

 我们有一排怪物，每个怪物都有一定的生命值，以及两种类型的攻击：一种基本法术，可以使任何怪物的生命值减少 1 点 MP，以及一次性“爆炸”，可以针对一个具有任意力量的怪物。 如果目标生命值小于或等于法术威力，爆炸会杀死目标，并触发相邻怪物的连锁爆炸，每次二次爆炸的威力为被杀死怪物的生命值减一。 任务是最小化消耗的MP总量，即基本法术施放和爆炸威力的总和，以便爆炸最终杀死所有怪物。 

输入提供多个测试用例。 每个测试用例给出了怪物的数量$n$以及他们的一系列健康状况。 输出是每种情况所需的最小总MP。 

约束告诉我们，所有测试用例中的怪物总数最多可达$3 \cdot 10^5$。 这立即排除了尝试用所有可能的基本法术分布来模拟所有可能的爆炸目标的幼稚方法，因为这可能会导致$O(n^2)$或者更糟糕的时间复杂度。 理想情况下，任何解决方案都应该与每个测试用例的怪物数量大致呈线性关系$O(n)$，或者也许$O(n \log n)$如果使用二分搜索或堆。 

一个不明显的边缘情况是所有怪物都具有相同的生命值，尤其是当它们很小时。 例如，如果所有怪物都是1，则最佳策略是施展基本法术零次，并选择最后一个怪物作为爆炸目标。 粗心贪婪的做法可能会不必要地减少生命值并超支 MP。 另一个棘手的场景是中间的峰值：[1,10,1]，其中最佳爆炸目标是中间的怪物； 错误地识别先击中哪个怪物可能会使 MP 成本增加一倍。 

## 方法

 暴力方法是尝试对每个怪物组合施放基本法术，然后模拟每个可能的爆炸目标并计算由此产生的 MP。 虽然原则上是正确的，但选项的数量呈指数增长$n$，使其在约束条件下完全不可行。 例如，即使是对所有爆炸的简单线性模拟$n$怪物会是$O(n^2)$在最坏的情况下，如果每次爆炸都会在所有邻居之间线性传播。 

解锁更快解决方案的关键观察是，对于每个怪物，对总 MP 的唯一相关贡献是其生命值与其两个邻居中较小者之间的差异。 更准确地说，如果你将爆炸视为左右传播的波，那么爆炸最多只能“减去”相邻怪物生命值中较小的那个减去一。 这导致了一个贪婪的策略：对于每个怪物，计算减少它所需的MP，以便它的爆炸杀死它并触发最大链。 形式上，总MP可以表示为每个怪物“吸收”上一次爆炸伤害后贡献的总和，相当于计算每个怪物的max(0, h[i] - min(h[i-1], h[i+1]))之和（在边缘进行特殊处理）。 

最佳解决方案避免了任何模拟，并将问题简化为在线性时间内计算这些差异。 它之所以有效，是因为爆炸传播是确定性的：唯一的决定是瞄准哪个怪物，一旦波开始，它就不能被重定向或停止，所以我们只需要考虑尚未被相邻爆炸覆盖的生命值。

 ## 算法演练

 1. 对于每个测试用例，读取怪物的数量$n$以及他们的健康状况$h$。 
2. 初始化变量`total_mp`为零。 这将积累所需的MP。 
3.对于每个怪物$i$从 0 到$n-1$，计算爆炸前它必须从基本法术中承受的有效伤害，以便链条能够到达它。 有效伤害为`max(0, h[i] - min(h[i-1], h[i+1]))`。 对于第一个和最后一个怪物，只有一个邻居存在，因此仅使用该邻居的生命值。 将此值添加到`total_mp`。 
4.处理完所有怪物后，`total_mp`现在代表所需的最低 MP：在任何地方设置一次爆炸所需的所有基本法术的总和。 输出当前测试用例的该值。 

为什么它有效：不变的是，对于任何怪物，相邻怪物的爆炸可以覆盖最多`neighbor_health - 1`损害。 通过降低怪物的生命值来考虑它从邻居那里承受的最大爆炸，我们确保每个怪物要么因主爆炸要么因传播爆炸而死亡，而不会在不必要的基本法术上浪费 MP。 这保证了最低的总 MP，同时确保所有怪物死亡。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        total_mp = 0
        for i in range(n):
            left = h[i - 1] if i > 0 else 0
            right = h[i + 1] if i < n - 1 else 0
            needed = max(0, h[i] - max(left, right))
            total_mp += needed
        print(total_mp)

solve()
