 ## 问题理解

 我们在 2D 平面上最多有 50 个点。 每个点都有整数坐标，有些点可能重合。 任务是找到任意一对点之间的最大欧氏距离。 

对于两点$(x_1, y_1)$和$(x_2, y_2)$，欧氏距离为：$d=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$拖动点以更新两点之间的距离。-10-8-6-4-2246810-10-5510A(6.0, 6.0)B(-6.0, -6.0)d = 16.97Delta x = 12Delta y = 12

 输入格式有点不寻常，因为每个坐标都在自己的行上给出。 读完后`n`，我们读到`2n`更多行： 1`x`， 一`y`，对每个点重复。 

限制非常小。 只有 50 分，总对数最多为：$\frac{50\cdot49}{2}=1225$对于 2 秒的限制来说，这个时间太小了。 甚至一个$O(n^2)$算法只执行几千次距离计算，这是微不足道的。 

主要的危险不是性能，而是正确性和精度。 

一个容易犯的错误是忘记欧几里得距离使用平方根。 粗心的实现可能会最大化平方距离并直接打印它。 

例子：```
2
0
0
3
4
```正确答案是：```
5
```因为：$\sqrt{3^2+4^2}=5$印刷`25`相反会是错误的。 

另一个微妙的情况是重复点。```
3
1
1
1
1
4
5
```两点相同，因此它们的距离为零。 正确的最大距离介于`(1,1)`和`(4,5)`。 

假设所有点都不同的错误实现可能会意外地跳过有效比较或错误处理索引。 

浮点输出格式是另一个常见的问题来源。 判断器接受较小的误差容限，因此以标准浮点精度打印就足够了，但整数除法或截断会失败。 

## 方法

 最直接的解决办法就是暴力破解。 我们检查每对点，计算它们之间的欧几里德距离，并保留迄今为止看到的最大值。 

这是有效的，因为答案实际上被定义为所有对的最大值。 如果我们对每一对都检查一次，我们就不会错过最佳的一对。 

暴力算法执行：$O(n^2)$距离计算。 和`n = 50`，这意味着最多 1225 对，可以忽略不计。 

对于较大的约束，这种方法会出现问题。 如果`n`是$10^5$，成对检查大约需要$10^{10}$限期内不可能进行的操作。 在这些设置中，计算几何技术（例如凸包和旋转卡尺）变得必要，因为最远的一对必须位于凸包上。 

这个问题不需要那些优化。 约束条件故意设置得足够小，使得简单的成对解决方案在实践中已经是最佳的。 关键的观察是，尝试构建更先进的几何算法只会增加复杂性，而没有任何好处。

 ## 算法演练

 1.读取整数`n`。 
2. 将所有点读入列表中`(x, y)`对。 
3. 初始化变量`best = 0.0`。 
4. 迭代每对索引`(i, j)`和`i < j`。 
5. 对于每一对，计算坐标差：$dx=x_i-x_j$

$dy=y_i-y_j$6. 计算欧氏距离：$d=\sqrt{dx^2+dy^2}$7. 更新`best`如果这个距离更大。 
8. 处理完所有对后，打印`best`。 

### 为什么它有效

 该算法明确评估每个可能的点对的距离。 由于答案的定义是所有对之间的最大距离，因此保证在迭代过程中出现最佳对。 每当发现更大的距离时，`best`已更新。 循环结束后，`best`等于整组对的最大距离，这正是所需的答案。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

# solution
def solve():
    n = int(input())
    
    points = []
    for _ in range(n):
        x = int(input())
        y = int(input())
        points.append((x, y))
    
    best = 0.0
    
    for i in range(n):
        x1, y1 = points[i]
        
        for j in range(i + 1, n):
            x2, y2 = points[j]
            
            dx = x1 - x2
            dy = y1 - y2
            
            dist = math.sqrt(dx * dx + dy * dy)
            best = max(best, dist)
    
    print(best)

if __name__ == "__main__":
    solve()
```第一部分将所有点读入列表中。 由于坐标被分成不同的行，因此我们读取每个点的两个整数并将它们存储在一起作为一个元组。 

嵌套循环将每个无序对恰好枚举一次。 使用`j`从`i + 1`避免重复比较，例如`(A,B)`和`(B,A)`，并且还跳过将点与其自身进行比较。 

距离计算在求平方根之前使用平方差。 坐标足够小，在 Python 中不可能溢出，但直接使用平方项仍然可以避免不必要的浮点运算，直到最后一步。 

答案变量开始于`0.0`因为距离是非负的。 每个计算出的距离都会与当前最大值进行比较。 

最终的打印语句使用Python的默认浮点格式，它已经为法官的容差要求提供了足够的精度。
