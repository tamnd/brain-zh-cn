 ## 解决方案
 ## 问题理解

 我们得到一个正整数，并且必须以 2 为基数打印它的表示形式。换句话说，我们希望将数字表示为 2 的幂并输出相应的位序列。 

例如，十进制数 13 等于：$13 = 1\cdot2^3 + 1\cdot2^2 + 0\cdot2^1 + 1\cdot2^0$所以它的二进制表示法是`1101`。 

限制非常小。 的价值`n`最多一百万，这意味着它的二进制表示最多包含 20 位，因为：$2^{20}=1048576$任何合理的算法都可以轻松满足时间限制。 即使重复将数字除以二的方法也仅执行大约 20 次迭代。 

棘手的部分不是性能，而是格式的正确性。 

一种常见的错误是以相反的顺序打印位。 当我们重复除以二时，我们获得从最低有效位到最高有效位的位。 如果我们立即打印它们，答案就会相反。 

例如：

 输入：```
5
```余数按以下顺序出现：

 | 当前 n | n % 2 |

 |---|---|---|

 | 5 | 1 |

 | 2 | 0 |

 | 1 | 1 |

 如果我们直接打印它们，我们会得到`101`从下到上，而不是从上到下。 

另一个错误是产生前导零。 二进制符号应从最高设置位开始。 

例如：

 输入：```
1
```正确输出：```
1
```粗心的固定宽度实现可能会打印类似的内容`00000001`，这是不允许的。 

第三种边缘情况是正确处理最小的数字。 如果循环条件写得不正确，程序可能会产生一个空字符串`n = 1`。 

输入：```
1
```正确输出：```
1
```该算法必须保证至少打印一位。 

## 方法

 最直接的想法就是模拟二进制记数法的定义。 每个二进制数字都表明 2 的某个幂是否参与该数字的分解。 

蛮力方法从大到小检查两个人的权力。 对于每个位置，我们确定该功率是否适合剩余值。 如果是，我们输出`1`并减去它。 否则，我们输出`0`。 

例如，对于`13`:$13 = 8 + 4 + 0 + 1$所以这些位变成`1101`。 

这个方法是正确的，因为二进制记数法正是分解为2的幂。 问题是我们首先需要确定最大的相关权力。 如果通过重复求幂或扫描许多不必要的位置来简单地实现，那么对于这样一个简单的任务，代码就会变得笨拙。 

更清晰的观察来自二进制数的形成方式。 最低有效位等于除以二时的余数。$n = 2q + r,\quad r\in\{0,1\}$剩下的`r`正是当前的二进制数字。 提取后，我们将数字除以二并继续求商。 

例如，从`13`:

 | n | n % 2 | n // 2 |
 | --- | --- | --- |
 | 13 | 1 | 6 |
 | 6 | 0 | 3 |
 | 3 | 1 | 1 |
 | 1 | 1 | 0 |

 这些位以相反的顺序出现：`1011`。 反转它们给出`1101`。 

这种方法是最佳的，因为每次迭代都会删除一个二进制数字。 由于一百万以内的数字只有大约 20 位，因此算法几乎立即完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(log n) | O(1) | O(1) | 已接受 |
 | 最佳| O(log n) | O(log n) | 已接受 |

 ## 算法演练

 1.读取整数`n`。 
2. 创建一个空列表`bits`来存储二进制数字。 
3.同时`n > 0`，执行以下操作：

 1. 计算`n % 2`。 
2. 将此余数附加到`bits`。 
3. 更换`n`和`n // 2`。 

余数给出当前最低有效的二进制数字。 整数除法会删除该数字并将该数字右移一位。 
4. 反转列表`bits`。 

数字是从最低有效位到最高有效位生成的，因此反转可以恢复正确的顺序。 
5. 将数字连接成字符串并打印结果。 

### 为什么它有效

 在每次迭代中，该算法都保持不变式，即可以根据收集的余数和当前值重建原始数`n`。 

假设当前值为`n`。 我们写：$n = 2\left\lfloor\frac{n}{2}\right\rfloor + (n\bmod 2)$余数始终是`0`或者`1`，它与二进制数字完全匹配。 记录完这个数字后，我们继续求商。 重复此过程将从右到左提取每个二进制数字。 反转收集的数字可恢复标准的从左到右的二进制表示法。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

bits = []

while n > 0:
    bits.append(str(n % 2))
    n //= 2

bits.reverse()

print("".join(bits))
```该程序首先从标准输入读取整数。 

名单`bits`将二进制数字存储为字符串。 将它们立即存储为字符串可以避免输出构造期间的额外转换步骤。 

在循环内部，`n % 2`提取当前最低有效位。 然后`n //= 2`从数字中删除该位。 循环继续，直到数字变为零。 

操作顺序很重要。 我们必须在除法之前记录余数。 反转这两行将丢失当前位。 

循环结束后，数字会反转，因为它们是从右向左收集的。 最后，`"".join(bits)`有效地构造输出。 

条件`while n > 0`工作正常，因为问题保证`n ≥ 1`。 如果允许零，我们将需要特殊处理，因为循环永远不会执行。

def solve():

 考虑尽可能最小的输入：

 输入：```

```执行轨迹：

 | 当前 n | n % 2 | 位|

 | 1 | 1 | [1] |
