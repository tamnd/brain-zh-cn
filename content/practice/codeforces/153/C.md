 ## 解决方案
 ## 问题理解

 我们被要求对大写拉丁字母的输入字符串实现凯撒密码。 从概念上讲，这意味着每个字母在字母表中向前移动固定数量的位置，用 _k_ 表示。 如果移位超过“Z”，则会环绕到“A”。 例如，移位 3 后，“X”变为“A”，“Y”变为“B”，“Z”变为“C”。 

输入由长度在 1 到 10 个字符之间的字符串组成，因此我们保证数据集非常小。 第二行是 0 到 25 之间的整数 _k_，这意味着移位永远不需要字母表的多个循环。 输出应该是将凯撒密码应用于每个字符后转换后的字符串。 

当字母接近字母表末尾且 _k_ 将其推过“Z”时，会出现一种微妙的边缘情况。 例如，使用输入`"XYZ"`和`k = 5`，预期输出是`"CDE"`。 简单地将 _k_ 添加到每个字符的 ASCII 值而不换行的简单方法将给出“Z”之外的无效字母。 另一个边缘情况是`k = 0`，其中字符串应保持不变。 

## 方法

 暴力方法很简单：迭代每个字符，将其转换为对应于其在字母表中位置的 0 到 25 之间的数字，添加 _k_，然后使用模 26 进行环绕。这是可行的，因为字母表具有固定大小，我们可以使用 ASCII 算术轻松将字母映射到整数。 对于长度为 _n_ 的字符串，此方法恰好需要 _n_ 次操作，在我们的例子中最多为 10 次。不存在性能问题； 考虑到限制，“蛮力”本质上是最优的。 

简化一切的观察是模运算本质上处理环绕。 具体来说，如果我们将 'A' 映射到 0，'B' 映射到 1，...，'Z' 映射到 25，那么`(index + k) % 26`产生正确的移位索引。 这种模运算是唯一必要的关键见解。 一旦您考虑数字索引而不是字母，问题就会简化为简单的数组转换。

 | --- | --- | --- | --- |
 | 蛮力/最优| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取输入字符串和整数移位_k_。 该字符串将被视为字符序列，并且 _k_ 保证在 0 到 25 之间。 
2. 初始化一个空列表来保存结果字符。 使用列表而不是增量构建字符串可以避免字符串不可变的语言中的二次时间复杂度。 
3. 迭代输入字符串中的每个字符。 通过减去“A”的 ASCII 值，将字符转换为从 0 到 25 的索引。 这给出了适合算术的数字表示。 
4. 通过添加 _k_ 并取模 26 来计算移位后的新索引。模数确保移位正确地从“Z”回绕到“A”。 
5. 通过添加 'A' 的 ASCII 值将新索引转换回字符并将其附加到结果列表中。 
6. 将字符列表连接成单个字符串并打印它。 

工作原理：该算法维护从字符到数字索引的一致映射，在封闭数字系统中应用模 26 的移位，然后映射回字符。 不变的是每个字符的索引始终在 0 到 25 之间，因此模运算保证了小移位和边界移位的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
k = int(input())

result = []

for char in s:
    index = ord(char) - ord('A')
    new_index = (index + k) % 26
    result.append(chr(new_index + ord('A')))

print(''.join(result))
```该代码首先读取字符串和移位，去除任何额外的换行符。 然后我们迭代每个字符，将其转换为从零开始的索引。 添加 _k_ 并取模 26 可确保正确处理环绕。 最后，我们将每个移位索引转换回字符并组装输出字符串。 使用`ord`和`chr`字符索引映射是标准的，并且操作顺序经过仔细安排以避免差一错误。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = sys.stdin.readline().strip()
    k = int(sys.stdin.readline())
    result = [chr((ord(c) - ord('A') + k) % 26 + ord('A')) for c in s]
    return ''.join(result)

# Provided samples
assert run("CODEFORCES\n5\n") == "HTIJKTWHJX", "sample 1"

# Minimum-size input
assert run("A\n0\n") == "A", "min size, no shift"

# Maximum-size input
assert run("ABCDEFGHIJ\n25\n") == "ZABCDEFGHI", "max size, wrap-around"

# All-equal letters
assert run("ZZZZZ\n1\n") == "AAAAA", "all Zs wrap to A"

# Boundary shift
assert run("XYZ\n5\n") == "CDE", "wrap-around near end"

 ## 边缘情况

 对于输入`"XYZ"`和`k = 5`，数字索引为 23, 24, 25。加 5 得到 28, 29, 30，模 26 得到 2, 3, 4。将这些映射回字符会产生`"CDE"`。 该算法可以正确处理字母表末尾附近的字母，无需特殊分支或条件，从而确认模运算完全管理边缘环绕。
