 ## 解决方案
 ## 问题理解

 我们被要求计划两位表演者 Lelle 和 Flamm 之间的比赛，每轮都会产生一个获胜者。 目标是最大化总分，计算公式为`l * W_L + f * W_F`， 在哪里`W_L`和`W_F`分别是 Lelle 和 Flamm 的胜利次数。 然而，表现必须满足严格的“成功”标准：每一轮结束后，获胜次数的最大公约数必须最多为 1，这意味着`gcd(W_L, W_F) <= 1`。 最后，没有人能获得超过其各自限制的胜利，我们保证简单版本`n = m`。 

输入为我们提供了多个测试用例，每个测试用例都有两个玩家允许的最大获胜次数（在这个简单版本中是相等的）和评分系数。 输出应该是这些约束下可达到的最大分数。 

限制因素很重要：`n`和`m`可以达到`2 * 10^7`，所以任何迭代所有可能的解决方案`(W_L, W_F)`对是不可行的。 这排除了任何复杂度为 O(n*m) 的简单暴力方法。 测试用例的最大数量为 1000，这也意味着我们必须高效地计算每个用例的结果。 

当一个分数系数支配另一个分数系数时，就会出现不明显的边缘情况。 例如，如果`l = 1`和`f = 10^9`，我们希望弗拉姆尽可能获胜，但是`gcd`约束阻止简单地采取`W_F = n`。 同样，像这样的小值`n = 2`和`l = f = 1`可能会产生联系并需要仔细排序以维持`gcd <= 1`。 

## 方法

 蛮力方法在概念上很简单。 我们可以枚举所有获胜序列，计算`gcd(W_L, W_F)`每轮结束后，记录最大有效分数。 这是正确的，但完全不切实际，因为即使`n = 10^5`，序列的数量呈指数增长，我们将超出时间限制。 

关键的见解来自互质数的结构。 如果我们想象一个可能的网格`(W_L, W_F)`值，我们只需要考虑互质的对，因为中间`gcd`大于 1 的值会立即使序列无效。 自从`n = m`，沿加权分数轴最大的互质对位于优化线附近`l * W_L + f * W_F`。 这相当于将“主导”系数除以另一个系数并逐步遍历连续的互质候选者。 该方法减少了迭代`W_L`或者`W_F`候选者，计算相应的其他变量以最大化线性分数，并确保它们保持互质。 可以使用简单的数论有效地限制迭代，而无需探索整个 n×m 网格。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n+m)) | O(2^(n+m)) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(sqrt(n)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 首先确定哪位球员的得分系数更高。 不失一般性，假设`l <= f`; 如果没有，请交换 Lelle 和 Flamm 的角色。 这使我们能够优先考虑更高的分数以实现高效迭代。 
2. 观察序列必须以互质对结束`(W_L, W_F)`。 对于任何`k`这样`W_L = floor(n / k) * k`和`W_F = floor(n / k) * (k-1)`或其对称对应物，我们可以生成候选者。 然而，我们可以通过迭代来简化`k`从 1 到`sqrt(n)`并考虑两者`(floor(n/k), n - floor(n/k))`作为可能的互质候选者。 
3. 对于每个候选对`(W_L, W_F)`， 核实`gcd(W_L, W_F) == 1`。 仅当它们互质并且在界限内时才计算分数`0 <= W_L <= n, 0 <= W_F <= m`。 
4. 跟踪在所有有效候选对中观察到的最高分数。 最佳配对可能包括一名球员`n`赢减去一个，另一个相应地调整以保持互质。 
5. 输出每个测试用例的最高分。 

这样做的原因是得分函数的线性`l*W_L + f*W_F`意味着在可行区域的边界处获得了最佳分数。 通过关注沿由定义的“边缘”的互质对`W_L + W_F <= n + m`并迭代至`sqrt(n)`，我们有效地探索所有相关候选者，而无需冗余计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

def max_score(n, l, f):
    ans = 0
    for k in range(1, int(n**0.5) + 2):
        W_L = n // k
        W_F = n - W_L
        if W_L <= n and W_F <= n and gcd(W_L, W_F) == 1:
            ans = max(ans, W_L * l + W_F * f)
        W_F_alt = n // k
        W_L_alt = n - W_F_alt
        if W_L_alt <= n and W_F_alt <= n and gcd(W_L_alt, W_F_alt) == 1:
            ans = max(ans, W_L_alt * l + W_F_alt * f)
    return ans

t = int(input())
for _ in range(t):
    n, m, l, f = map(int, input().split())
    # n == m guaranteed
    print(max_score(n, l, f))
```在此代码中，我们迭代所有`k`最多`sqrt(n)`生成接近最大可能获胜的互质候选者。 我们计算两者`(W_L, W_F)`及其对称对应物，以确保不会遗漏任何候选者。 这`gcd`检查保证我们只考虑在整个比赛中有效的序列。`ans`累积最高分数。
