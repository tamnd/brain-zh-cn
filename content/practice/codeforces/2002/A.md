 ## 解决方案
 ## 问题理解

 我们有一个矩形网格`n`行和`m`列。 每个单元格必须分配一种颜色，但颜色受到距离规则的限制：如果两个单元格共享相同的颜色，那么它们在切比雪夫意义上必须足够远，这意味着它们的行差和列差的最大值必须至少为`k`。 

简单来说，任何两个相同颜色的单元格不能位于一个单元格内`(k-1) × (k-1)`彼此的平方邻域。 任务是在遵守此分离规则的同时使用尽可能少的颜色。 

每个测试用例的输出只是一个数字：该网格所需的最小颜色数以及该值`k`。 

约束允许最多 1000 个测试用例，网格尺寸最大为 10^4。 这排除了任何尝试模拟着色或比较所有单元对的行为，因为即使是大小为 10^4 × 10^4 的单个网格也太大而无法显式处理。 解决方案必须仅依赖于`n`,`m`， 和`k`，而不是单个细胞的相互作用。 

一个常见的失败案例来自于局部思考而不是全局思考。 例如，人们可能会尝试逐行或逐列进行贪婪着色，但这种方法很快就会失效，因为约束不是方向性的。 一个单元可以在水平和垂直方向上与其他单元发生冲突，因此局部决策同时在两个维度上传播。 

另一个微妙的边缘情况发生在`k`与网格尺寸相比非常大。 在这种情况下，两个不同的细胞根本不可能共享同一种颜色，因为每对细胞都太接近了。 假设颜色定期重复使用的幼稚方法会错误地高估重复使用机会。 

## 方法

 蛮力的想法是实际模拟网格着色。 对于每个单元格，如果距离内没有出现冲突，我们将尝试为其分配以前使用过的颜色`k`，否则引入新颜色。 这需要检查所有先前着色的相同颜色单元的距离，导致最坏情况的复杂性约为`O(n^2 m^2)`所有情况下的总和，远远超出了限制。 

关键的观察结果是约束是纯粹几何的且平移不变的。 重要的不是绝对位置，而是以适当间距为模的相对位置。 如果我们考虑重复图案，一个自然的想法是将网格划分为重复块，使得任何两个相同的颜色被迫相距很远。 

如果我们按坐标模对单元格进行分组`k`，那么任意两个具有相同残基对的细胞`(i mod k, j mod k)`两个坐标相差的倍数`k`，保证了所需的距离条件。 这立即给出了一个有效的构造`k × k`只要网格在两个维度上都足够大，就会显示颜色。 

然而，当网格小于`k`在一个方向上，模结构不再完全塌陷。 例如，如果`n < k`，那么所有行索引在单个残差类循环中都是不同的，因此我们不能重用完整的行索引`k`垂直结构。 在这种情况下，不同行的数量成为限制因素。 

这导致了一个简单的精化视图：在每个维度中，我们只需要与维度大小和维度中较小者一样多的不同“级别”`k`。 结合两个维度给出最终答案。

 ## 算法演练

 最佳解决方案基于直接计算每个方向需要多少个独立“层”。 

1. 阅读`n`,`m`， 和`k`。 这些定义了网格和所需的最小间隔距离。 
2.观察到，沿着行，我们不能比每行更频繁地重用行模式`k`步骤。 然而，如果网格的数量少于`k`行，那么每一行本质上都是唯一的，并且不能超出网格大小本身进行分组。 所以有效行层数为`min(n, k)`。 
3. 对列应用相同的推理。 有效柱层数为`min(m, k)`。 
4. 行层和列层的每种组合都对应于最佳构造中的唯一颜色。 
5. 将两个独立计数相乘即可得到所需的颜色总数：`min(n, k) * min(m, k)`。 

这种乘法之所以有效，是因为该结构相当于为每个单元分配一对`(i mod k, j mod k)`但当网格小于时会被截断`k`在任一维度。 

### 为什么它有效

 关键的不变量是共享同一对简化坐标的两个单元格不能比`k`在任一方向上，因为相同的对迫使两个坐标相差数倍`k`。 同时，任何使用更少颜色的尝试都意味着合并两个这样的残基类别，这必然会在禁止距离内创建一对单元格。 这使得结构既足够又最小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    print(min(n, k) * min(m, k))
```解法直接应用推导公式即可。 每个测试用例都会在恒定时间内独立处理，考虑到用例数量很大，这一点很重要。 

唯一微妙的一点是正确处理`min(n, k)`和`min(m, k)`结构。 一个常见的错误是使用`k * k`无条件地，当网格小于时失败`k`在一个或两个维度上。 

## 工作示例

 ### 示例 1

 输入：```
n = 3, m = 3, k = 2
```我们计算：

 -`min(n, k) = 2`-`min(m, k) = 2`所以结果=`2 × 2 = 4`。 

这符合我们在网格的 2 周期平铺中只需要 4 个重复残基类的想法。 

### 示例 2

 输入：```
n = 5, m = 1, k = 10000
```我们计算：

 -`min(n, k) = 5`-`min(m, k) = 1`所以结果=`5 × 1 = 5`。 

这反映出，只有一列，在如此大的规模下，不可能进行水平复用。`k`，因此每一行实际上都需要自己的颜色。 

这些示例证实了该公式在以下情况下都能正确适应：`k`很小，当它比网格大得多时。

 ## 边缘情况

 当`k = 1`，每对细胞的距离至少为 1，因此所有细胞可以共享单一颜色。 公式给出`min(n,1) * min(m,1) = 1`，匹配此行为。 

什么时候`k`比两个尺寸都大得多，例如`n = m = 5, k = 100`，公式变为`5 × 5 = 25`，这正确地反映了没有两个不同的单元格可以重复使用一种颜色。 

当只有一维很大时，例如`n = 1000, m = 1, k = 10`，结果变为`10 × 1 = 10`，这意味着我们只需要沿垂直轴分离，水平重用是无关紧要的。
