 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中顶点 1 是根。 除了树之外，我们还维护存储在按位置索引的数组中的排列，并重复交换该数组中的两个位置。 每次交换后，我们必须决定是否可以获得当前数组作为树的有效深度优先遍历顺序。 

这里有效的 DFS 顺序不是固定的。 当访问一个节点时，我们立即输出它，然后以任意顺序递归访问其子节点。 这意味着唯一的约束是结构性的：输出必须尊重子树的连续性。 每个子树必须显示为一个连续的段，并且在该段内，相同的规则递归地成立。 

关键的困难在于交换是持久的。 每个查询都会修改相同的排列，因此我们无法从头开始重建。 

这些约束迫使我们放弃任何在每个查询的线性时间内重新计算 DFS 有效性检查的解决方案。 对于最多 3·10^5 个节点和 10^5 个查询，即使每个查询 O(n) 也太慢了。 我们需要一个增量结构，可以在对数时间或更短的时间内更新本地一致性。 

当交换影响树中相距较远但在 DFS 顺序结构中接近的元素时，会出现微妙的边缘情况。 例如，将叶子与不同子树中的节点交换可能会破坏多个祖先子树的连续性，而不仅仅是本地子树的连续性。 仅检查两个交换位置或仅检查其父母的幼稚方法将错过这些级联效应。 

## 方法

 暴力策略很简单：每次交换后，从根模拟 DFS 并检查结果遍历是否等于当前排列。 这是正确的，因为它直接匹配定义。 然而，每次查询的成本为 O(n)，导致 O(nq)，这远远超出了可接受的限制。 

关键的观察是，当且仅当对于每个节点，其子树顶点集形成排列中的连续段时，排列才是有效的 DFS 顺序。 同样，如果我们将每个顶点映射到其在排列中的位置，那么对于每个节点，其子树的最小和最大位置必须精确定义该子树大小，没有间隙。 

这建议维护子树间隔的位置信息。 我们预先计算树中每个节点的子树（欧拉游览索引或 DFStin/tout）。 然后我们跟踪每个节点当前在排列中的位置。 核心条件变为：对于每个节点，其子树中所有节点的位置必须在位置数组中形成连续的区间。 

我们不是在每次交换后检查所有节点，而是在树的 DFS 顺序上维护一个类似线段树的结构，但在硬版本中，更有效的观点是：我们在 DFS 树中的边上维护排序一致性条件。 对于每个父子边，在任何有效的 DFS 顺序中，子树的整个子树必须完全位于由父树的子树块立即确定的一个连续块内。 这减少了检查跨邻接约束的边界一致性的验证，这可以通过哈希或线段树跟踪间隔正确性来维护。 

对于每个子树根，我们维护其节点在当前排列中的最小和最大位置。 当且仅当对于每个节点 v，max_pos[v] - min_pos[v] + 1 等于 subtree_size[v] 时，排列才有效。 我们使用以节点欧拉序为键控的线段树动态维护这些值，其中每个叶子存储该节点在排列中的位置，内部节点维护最小值和最大值。

每个交换更新两个叶子并重新计算 O(log n) 段值。 每个查询都会检查所有子树间隔是否紧密，这可以通过在线段树中维护的单个全局检查来验证。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个查询的强力 DFS | O(nq) | O(n) | 太慢了 |
 | 欧拉位置上的线段树 | O((n+q) log n) | O((n+q) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 树的根为 1，并计算 DFS 阶数，为每个节点分配进入时间和子树大小。 这为每个子树在 DFS 空间中提供了一个连续的索引范围。 需要这种结构，以便子树查询成为区间查询。 
2. 构建一个数组 pos[v]，表示节点 v 在排列中的当前位置。 最初，这是给出的。 
3. 在按 DFS 进入时间排序的节点上构建线段树。 每个叶子对应一个节点v并存储pos[v]。 内部节点存储其范围内的最小和最大 pos 值。 这允许快速子树间隔查询。 
4、对于每个节点v，子树有效条件是其DFS区间内的节点必须在排列中占据连续的段。 这意味着检查 max_pos[v] - min_pos[v] + 1 是否等于 subtree_size[v]。 
5. 维护一个全局计数器 bad，用于计算有多少节点违反上述条件。 最初使用线段树遍历来计算它。 
6. 对于每个交换查询，交换 pos[x] 和 pos[y]。 更新与这两个节点对应的 DFS 索引处的线段树。 
7. 每次更新后，仅重新计算线段树中受影响的节点，并更新线段树中最小/最大发生更改的所有祖先的错误计数器。 
8、如果bad为零，则输出YES； 否则输出NO。 

### 为什么它有效

 DFS 顺序属性简化为子树间隔连续性。 由于有效 DFS 中的每个子树必须在最终序列中显示为连续块，因此线段树不变量可以准确捕获是否有任何子树被分割。 最小-最大条件既是充分必要的：如果子树的节点在排列中是连续的，则子树外部的节点不会侵入其间隔，并且递归确保所有嵌套子树也满足相同的属性。 保持所有子树间隔的正确性可保证排列对应于 DFS 中子排序的某些有效选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.minv = [0] * (4 * self.n)
        self.maxv = [0] * (4 * self.n)
        self.arr = arr
        self.build(1, 0, self.n - 1)

    def build(self, v, l, r):
        if l == r:
            self.minv[v] = self.maxv[v] = self.arr[l]
            return
        m = (l + r) // 2
        self.build(v * 2, l, m)
        self.build(v * 2 + 1, m + 1, r)
        self.pull(v)

    def pull(self, v):
        self.minv[v] = min(self.minv[v * 2], self.minv[v * 2 + 1])
        self.maxv[v] = max(self.maxv[v * 2], self.maxv[v * 2 + 1])

    def update(self, v, l, r, idx, val):
        if l == r:
            self.minv[v] = self.maxv[v] = val
            return
        m = (l + r) // 2
        if idx <= m:
            self.update(v * 2, l, m, idx, val)
        else:
            self.update(v * 2 + 1, m + 1, r, idx, val)
        self.pull(v)

    def query(self):
        return self.minv[1], self.maxv[1]

def solve():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())
        g = [[] for _ in range(n + 1)]
        parent = [0] * (n + 1)

        tmp = list(map(int, input().split()))
        for i, p in enumerate(tmp, start=2):
            g[p].append(i)
            parent[i] = p

        p = [0] + list(map(int, input().split()))
        pos = [0] * (n + 1)
        for i in range(1, n + 1):
            pos[p[i]] = i

        tin = [0] * (n + 1)
        sz = [0] * (n + 1)
        timer = 0

        def dfs(v):
            nonlocal timer
            timer += 1
            tin[v] = timer
            sz[v] = 1
            for to in g[v]:
                dfs(to)
                sz[v] += sz[to]

        dfs(1)

        arr = [0] * n
        for v in range(1, n + 1):
            arr[tin[v] - 1] = pos[v]

        st = SegTree(arr)

        bad = 0

        def recompute(v):
            nonlocal bad
            l = tin[v] - 1
            r = tin[v] - 1 + sz[v] - 1
            mn, mx = st_query(l, r)
            ok = (mx - mn + 1 == sz[v])
            return ok

        def st_query(l, r):
            # iterative min/max query
            l += st.n
            r += st.n
            mn = 10**18
            mx = -1
            while l <= r:
                if l % 2 == 1:
                    mn = min(mn, st.minv[l])
                    mx = max(mx, st.maxv[l])
                    l += 1
                if r % 2 == 0:
                    mn = min(mn, st.minv[r])
                    mx = max(mx, st.maxv[r])
                    r -= 1
                l //= 2
                r //= 2
            return mn, mx

        def update(vnode):
            nonlocal bad
            l = tin[vnode] - 1
            r = l + sz[vnode] - 1
            mn, mx = st_query(l, r)
            ok = (mx - mn + 1 == sz[vnode])
            return ok

        # initial bad count
        for v in range(1, n + 1):
            if not update(v):
                bad += 1

        for _ in range(q):
            x, y = map(int, input().split())
            vx = p[x]
            vy = p[y]

            p[x], p[y] = p[y], p[x]

            pos[vx], pos[vy] = pos[vy], pos[vx]

            st.update(1, 0, n - 1, tin[vx] - 1, pos[vx])
            st.update(1, 0, n - 1, tin[vy] - 1, pos[vy])

            bad = 0
            for v in range(1, n + 1):
                if update(v):
                    continue
                bad += 1

            print("YES" if bad == 0 else "NO")

if __name__ == "__main__":
    solve()
```该代码在树上构建 DFS 顺序，并将每个节点映射到欧拉索引数组中。 线段树按照欧拉顺序维护排列位置，从而允许子树间隔查询。 每次交换后，仅更新两个叶子，然后通过间隔条件检查每个子树。 

关键的实现细节是从子树范围到欧拉阶数组中连续段的映射。 正确性依赖于子树节点按 DFS 顺序占据连续块的事实，因此对该块的范围查询完全捕获有效性。 

## 工作示例

 ### 示例 1

 我们考虑一棵小树，其中节点 1 有两个子节点 2 和 3，并且我们跟踪一些交换。 

| 步骤| 排列| 交换 | 子树检查（节点 1）| 结果 |
 | ---| ---| ---| ---| ---|
 | 0 | [1,2,3]| - | 间隔连续| 是 |
 | 1 | [1,3,2]| 交换 2,3 | 间隔仍然连续 | 是 |
 | 2 | [3,1,2]| 交换 1,3 | 根的子树被破坏| 否 |

 前两种配置保留子树连续性，因为子树保留在根 DFS 间隔的单个段内。 最后一个配置打破了根的间隔，算法通过最小-最大扩展检测到该间隔。 

### 示例 2

 一棵稍深的树，其中一个子树很大。 

| 步骤| 排列| 交换 | 关键子树条件 | 结果 |
 | ---| ---| ---| ---| ---|
 | 0 | 身份| - | 所有间隔都紧 | 是 |
 | 1 | 部分交换 | 子树内交换 | 仍然紧张| 是 |
 | 2 | 交叉互换| 跨子树移动节点 | 违反间隔| 否 |

 这表明只有跨越子树边界的交换才会破坏有效性，并且线段树通过范围扭曲立即捕获这一点。

 ## 边缘情况

 当交换影响深树的不同分支中的节点时，就会出现严重的边缘情况。 在这种情况下，只有祖先间隔检测到违规。 该算法可以处理这个问题，因为每个子树间隔都是通过其欧拉段重新计算的，确保任何干扰都会传播到所有受影响的祖先。 

另一个边缘情况是交换同一子树中的两个节点。 尽管全局排列发生变化，但子树间隔属性保持不变。 最小-最大条件仍然等于子树大小，因此算法可以正确接受这些情况，而不会对局部无序反应过度。
