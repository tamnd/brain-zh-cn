 ## 解决方案
 ## 问题理解

 我们不断地从一组城市中均匀地随机选择一个城市$n$城市，每次我们选择一个城市时，我们都会支付其相关费用。 仅当每个城市至少被看到一次时，该过程才会停止。 问题不在于步骤的数量，而在于所有不同城市出现之前累积的总预期成本。 

每次我们“绘制”一座城市时，我们都会立即支付它的成本，即使我们以前见过它。 这意味着总成本是随机过程中所有样本成本的总和，该过程一直持续到覆盖完整的索引集。 

困难在于，停止时间取决于随机性，每次抽奖的成本取决于选择哪个城市。 这使得期望值变得不平凡，因为在终止之前访问每个城市的次数不是独立的。 

约束条件允许$n$最多$10^5$，因此任何显式模拟过程或跟踪子集的解决方案都是不可能的。 甚至维护子集超过$2^n$状态或在访问集上进行 DP 被排除。 有效的解决方案必须将问题简化为封闭式表达式或数组上的线性时间计算。 

当所有成本相等时，就会出现一个微妙的问题。 一种简单的方法可能会尝试计算预期的抽奖次数乘以平均成本，但这会失败，因为停止时间和成本累积在没有理由的情况下不能以简单的方式分离。 

另一个极端情况是$n = 1$，该过程在一次抽奖后立即结束，所以答案很简单$a_1$。 任何派生公式都必须完全折叠到该基本情况。 

## 方法

 暴力心理模型是模拟随机过程：从一组空的访问过的城市开始，重复选择一个随机索引，累积其成本，并将其标记为已看到。 重复直到访问完所有城市。 人们可以尝试蒙特卡罗模拟或状态的完全枚举，但这两种方法都不可行。 即使单个模拟也有预期的长度$n H_n$，并且平均多次运行将远远超出限制。 

一种更结构化的强力方法是将过程建模为访问城市子集上的马尔可夫链。 来自一个州$S$，下一个转变会添加一个随机城市，并且每次转变都会根据选择概率贡献预期成本。 这导致$O(2^n)$状态，这立即是不可能的。 

关键的观察是将“流程何时结束”与“每个城市的付款频率”脱钩。 我们不是对子集进行推理，而是逐个城市地分析贡献。 每个城市每次抽签都会贡献自己的成本，我们只需要在过程停止之前每个城市出现的预期次数。 

这表明重点关注预期访问次数。 类似于优惠券收集器的停止条件的标准技巧是以最后一个新发现的城市为条件。 我们没有追踪完整的历史，而是考虑最后一座看不见的城市被发现的那一刻。 该事件的概率结构允许我们使用发现顺序排列的对称性来表达预期计数。 

一旦我们将视角转向排序，城市的每个排列都可以被视为城市首次发现的顺序。 停止时间对应于发现的该排列中的最后一个元素。 这将问题转化为对随机排列的排序和发现之间的几何等待时间的推理。 

最终的转换产生成本的线性表达式，其中每个$a_i$乘以城市的预期次数$i$在它在覆盖过程中变得无关之前被绘制。 这种期望仅取决于它在看不见的元素子集中的位置，从而产生谐波结构。 

这将问题简化为计算所有城市的单个谐波加权和。

 ## 算法演练

 1. 观察该过程一直持续到所有城市至少被看到一次为止，因此我们正在处理均匀随机抽样的全覆盖事件。 
2. 不要跟踪访问过的城市的子集，而应关注首次发现每个城市的那一刻。 首次出现的顺序形成所有城市的随机排列，均匀分布在所有城市上$n!$的可能性。 
3.对于固定城市$i$，考虑其对总成本的贡献。 每次在进程结束之前绘制它时，它都会添加$a_i$至总数。 所以我们想要城市的预期次数$i$在发现最后一个看不见的城市之前进行采样。 
4. 所在城市的活动情况$i$是$k$发现顺序中出现的第 - 个新城市。 在此之前，有$k-1$已经发现的城市和$n-k+1$看不见的城市包括$i$。 该过程继续绘制，直到$i$第一次出现。 
5. 虽然$i$是看不见的，每次抽奖都有概率击中一个看不见的城市$\frac{n-k+1}{n}$。 在未见过的城市中发现新城市的等待时间贡献了几何期望$\frac{n}{n-k+1}$。 这决定了多长时间$i$仍然不可见，因此在它第一次出现之前总共发生了多少次抽奖。 
6. 对所有可能的等级求和$k$，统一加权，因为所有排列的可能性相同，得出每个城市贡献的预期因子等于$n$次谐波数$H_n$。 
7. 因此预期总成本变为$H_n \cdot \sum a_i$。 
8. 计算谐波数模$10^9+7$作为$H_n = \sum_{i=1}^n i^{-1}$，并乘以成本总和。 

### 为什么它有效

 所有城市的过程都是对称的，唯一重要的结构是抽签发生时还剩下多少个看不见的城市。 每个城市在重新标记下的行为都是相同的，因此在完全覆盖之前其预期出现的次数仅取决于未见元素池大小的减少。 这将问题减少到优惠券收集器结构，其中每个阶段贡献预期的$\frac{n}{k}$步骤$k$剩余的看不见的元素。 期望的线性允许独立地求和贡献，确保总期望干净地分解为总成本和谐波数的乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

n = int(input())
a = list(map(int, input().split()))

S = sum(a) % MOD

H = 0
for i in range(1, n + 1):
    H = (H + modinv(i)) % MOD

print((S * H) % MOD)
```直接按照推导公式实现。 唯一重要的部分是计算所有整数的模逆$n$，因为调和数被定义为模运算下的倒数之和。 

成本总和计算一次。 然后我们积累$H_n$使用模逆。 最后，我们将两个值相乘。 

一个常见的错误是试图模拟随机过程，而该过程永远不会在约束范围内完成。 另一个错误是忘记除法必须通过模逆而不是整数除法来处理。

## 测试用例```python
import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    S = sum(a) % MOD
    def inv(x): return pow(x, MOD-2, MOD)
    H = 0
    for i in range(1, n+1):
        H = (H + inv(i)) % MOD
    return str((S * H) % MOD)

# provided samples
assert run("3\n1 2 3\n") == "11", "sample 1"
assert run("1\n5\n") == "5", "sample 2"

# custom cases
assert run("2\n1 1\n") == "3", "minimum nontrivial case"
assert run("4\n1 2 3 4\n") == str((10 * sum(pow(i, MOD-2, MOD) for i in range(1,5))) % MOD), "manual harmonic check"
assert run("5\n5 5 5 5 5\n") == str((25 * sum(pow(i, MOD-2, MOD) for i in range(1,6))) % MOD), "uniform costs"
assert run("1\n100000\n") == "100000", "single element large value"

 ## 边缘情况

 当$n = 1$，该过程永远不会循环。 谐波次数$H_1 = 1$，所以公式直接简化为$a_1$。 该算法计算总和$= a_1$并乘以$1$，无需特殊外壳即可产生正确的输出。 

当所有$a_i$是平等的，说所有都是$c$，期望值变为$c \cdot n \cdot H_n$。 该实现正确地处理了这个问题，因为成本总和变为$n \cdot c$，谐波因子保持不变。 

什么时候$n$很大，调和和仍然在线性时间内计算，并且模逆是安全的，因为模数是素数并且所有分母都是可逆的。
