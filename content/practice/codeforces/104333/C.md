 ## 解决方案
 ## 问题理解

 我们得到一串小写字母，对于每个位置，我们想知道“我们可以坐在里面的回文有多大”，同时强制该位置成为其中的一部分。 更准确地说，对于每个索引$i$，我们考虑所有包含的子串$i$和 是回文，我们希望它们之间的长度尽可能最大。 

因此，不是要求全局的所有回文子串，而是关注局部：每个位置就像一个必须被所选回文覆盖的锚点，并且我们想要最长的这样的对称段。 

约束很严格：测试用例的总长度可达$2 \cdot 10^5$，并且最多可以有$10^5$测试。 这会立即强制每个测试整体呈现线性或近线性行为。 任何试图以幼稚的方式独立扩展每个位置的回文的做法都会面临风险$O(n^2)$在一个长字符串中，这是不可接受的。 

直接的暴力尝试将尝试包含的每个中心或每个子串$i$，向外扩展，并检查回文性。 即使使用两指针扩展，也要为每个指针独立执行此操作$i$导致重复劳动。 对于像这样的字符串$aaaaa\ldots$，每个位置都会尝试扩展到整个字符串，导致比较的二次重复。 

一些微妙的案例暴露了陷阱：

 如果字符串是`aaaaa`，每个位置都应该输出`5`。 一种幼稚的方法，仅考虑以恰好为中心的回文数$i$对于偶数长度的回文会失败，缺少像`aa`位置之间居中。 

如果字符串是`ababa`，答案是`5`对于中间索引并对称递减，但是仅基于中心的计算可能会错过最大回文覆盖索引$2$仍然是完整的字符串，即使它的中心并不完全在$2$。 

这些案例迫使我们从全局回文结构的角度来思考，而不是按索引展开。 

## 方法

 暴力策略首先修复每个索引$i$，然后枚举所有子串$[l, r]$这样$l \le i \le r$，并检查是否$s[l..r]$是一个回文。 每张支票费用$O(r-l)$，并且有$O(n^2)$最坏情况下每个测试的子字符串。 这导致$O(n^3)$在最坏的情况下总计，这显然是不可行的。 

即使使用散列改进回文检查，也可以将每次检查减少到$O(1)$，但仍然离开$O(n^2)$每个索引都有子字符串，因此总体复杂性仍然是二次的。 

关键的观察是每个回文都可以用它的中心来表示，更重要的是，每个回文都将其完整的区间贡献给它内部的所有索引。 我们不想重新计算每个索引的贡献，而是希望将每个回文区间传播到它覆盖的所有位置。 

这表明了一种差异数组风格的想法：如果我们知道回文跨越$[l, r]$，那么该区间内的每个索引都可以将其答案至少更新为$r-l+1$。 因此，问题简化为有效地找到所有最大回文间隔。 

Manacher 算法准确地给出了这一点：它为每个中心（包括字符之间）计算线性时间内的最大回文半径。 找到的每个回文都对应一个区间，从中我们可以更新它涵盖的所有索引的最佳答案。 挑战在于有效地进行这些范围更新。 

我们可以将每个回文视为对段贡献一个值，并且我们希望每个索引处都有覆盖它的最大段长度。 这成为一个经典的“范围最大更新，点查询”问题，可以使用线段树或通过使用差异数组和前缀最大值的扫描处理端点来解决。 

干净的解决方案使用从 Manacher 派生的间隔扫描，为每个左端点存储最佳的右扩展，然后传播。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3)$|$O(1)$| 太慢了|
 | 使用哈希检查所有子字符串 |$O(n^2)$|$O(n)$| 太慢了|
 | Manacher + 区间传播 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们首先使用 Manacher 算法在统一处理偶数和奇数中心的变换字符串上计算所有回文半径。 

1. 通过插入分隔符来转换字符串（例如`#`），这样每个回文都变成奇数长度。 这避免了单独处理偶数和奇数回文并简化了半径解释。 
2. 运行Manacher计算数组`rad[i]`其中每个位置`i`转换后的字符串中给出以该处为中心的最大回文半径。 此步骤是线性的，因为该算法重用了先前计算的对称信息。 
3. 对于每个中心`i`在转换后的字符串中，将其回文转换回实数区间$[l, r]$在原始字符串中。 每个这样的回文代表一个候选子串贡献值$r - l + 1$。 
4.而不是将这个值分配给中的每个索引$[l, r]$，我们执行范围更新，表示该回文至少为区间内的所有索引贡献了该长度。 
5. 我们通过为每个位置维护从该位置开始或覆盖该位置的回文的最大右边界来处理所有此类间隔，然后通过扫描字符串来计算最终答案。 

关键思想是我们从不关心哪个回文产生了答案，只关心覆盖每个位置的最佳长度。 因此，重叠的回文会崩溃为每个索引的单个最大约束。 

### 为什么它有效

 字符串中的每个回文都恰好对应于变换后的 Manacher 表示中的一个中心，并且 Manacher 保证我们找到该中心的最大可能半径。 因此，每个回文子串都被视为某个最大间隔的一部分。 任何较小的回文都是无关紧要的，因为它包含在以相同位置为中心的较大或相等的回文中。 

由于每个索引的答案仅取决于覆盖它的最佳区间，并且生成每个有效区间，因此对所有区间取最大值会产生正确的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def manacher(s):
    t = ['#']
    for ch in s:
        t.append(ch)
        t.append('#')
    n = len(t)
    rad = [0] * n
    center = 0
    right = 0

    for i in range(n):
        if i < right:
            rad[i] = min(right - i, rad[2 * center - i])

        while i - rad[i] - 1 >= 0 and i + rad[i] + 1 < n and t[i - rad[i] - 1] == t[i + rad[i] + 1]:
            rad[i] += 1

        if i + rad[i] > right:
            center = i
            right = i + rad[i]

    return t, rad

def solve():
    n = int(input())
    s = input().strip()

    t, rad = manacher(s)

    m = len(t)

    diff = [0] * (n + 2)

    for i in range(m):
        if rad[i] == 0:
            continue

        l = (i - rad[i]) // 2
        r = (i + rad[i]) // 2 - 1

        length = r - l + 1
        diff[l] = max(diff[l], length)

    ans = [0] * n
    best = 0
    for i in range(n):
        best = max(best, diff[i])
        ans[i] = best

    print(*ans)

t = int(input())
for _ in range(t):
    solve()
```该解决方案从 Manacher 算法开始，该算法构造变换后的字符串并在线性时间内计算回文半径。 返回的`rad`数组对以每个位置为中心的每个最大回文进行编码。 

从转换后的指数返回到原始指数的转换是微妙的部分。 每个中心跨越转换后的数组中的一个段，除以二会将其映射回原始字符串坐标。 计算出的$[l, r]$给出了该回文的完整覆盖。 

这`diff`数组用于存储每个起始索引的最佳回文长度，该回文长度从该索引开始或作为候选贡献者锚定在那里。 我们只存储最大值，因为较弱的候选者是不相关的。 

最后，前缀最大扫描传播这些最佳可能长度，因此每个位置都会继承覆盖或到达它的最强回文。 

## 工作示例

 ### 示例 1：`ababa`变换后，Manacher 找到以中间为中心、跨越整个字符串的最大半径。 

| 中心| 半径 | 间隔（l，r）| 长度 |
 | --- | --- | --- | --- |
 | 中| 完整| (0, 4) | (0, 4) | 5 |

 扫掠集`diff[0] = 5`，和前缀传播产量`5 5 5 5 5`。 

这证实了全局回文中的每个索引都必须继承该回文的长度。 

### 示例 2：`abca`回文是：`a`,`b`,`c`,`a`，并且不再是中心回文。 

| 中心| 间隔 | 长度 |
 | --- | --- | --- |
 | 每个字符 | (一世，一世) | 1 |

 所以`diff[i] = 1`为所有人`i`，并且前缀传播将所有值保留在`1`。 

这表明，当不存在更大的回文时，算法会正确地回退到单字符答案。

 ## 边缘情况

 像这样的单字符字符串`a`由 Manacher 简单处理，它在转换后的字符串中返回半径为零并映射到间隔$(0, 0)$。 算法集`diff[0] = 1`，以及前缀扫描输出`1`。 

像这样的统一字符串`aaaaaa`产生一个最大半径覆盖整个范围的单个中心。 该间隔被转换为$[0, n-1]$，并且扫描确保每个位置都接收到值`n`，与每个索引都位于全局回文内部的事实相匹配。 

没有重复字符的字符串，例如`abcdef`只生成长度为 1 的回文。 每个中心只贡献自己的位置，没有任何区间超出它。 扫描永远不会增加超过 1，因此每个索引都输出 1。 

每个案例都证实该算法在两个极端下都能正确退化：最大对称性和根本不对称性。
