 ## 解决方案
 ## 问题理解

 我们有两个长度相等的数组。 一个数组表示附加到我们可以排列的索引的值，另一个数组表示固定的“槽”。 对于第一个数组的任何重新排列，我们将置换数组的每个元素与第二个数组中的位置进行匹配，并计算等于配对元素按位异或之和的分数。 

任务不是找到最佳排列，而是计算更大的东西：所有可能排列的总分。 由于有$n!$排列，每个配对之间$a_i$和一个$b_j$在所有排列中出现多次，目标是有效地聚合它们的贡献。 

约束条件$n \le 10^5$立即排除任何迭代排列甚至天真地处理对的方法$O(n^2)$。 甚至$O(n \log n)$或者$O(n)$方法是可以接受的，但任何涉及组合枚举的内容都必须替换为计数参数。 

这里常见的失败模式是尝试推理每个排列或模拟交换效果。 例如，与$n=3$，人们可能会尝试显式计算所有 6 种排列的分数。 这适用于微小的情况，但会按比例缩放，即使在$n=15$。 

另一个微妙的问题是重复计数逻辑：由于 XOR 在排列上并不是线性的，错误的方法可能会尝试配对排序数组或贪婪地匹配值。 这完全失去了组合结构。 

关键的困难是认识到每一对$(a_i, b_j)$在排列之间对称地贡献，我们只需要计算有多少排列$a_i$在位置$j$。 

## 方法

 蛮力解决方案迭代每个排列$p$，通过求和计算其分数$a_{p_i} \oplus b_i$，并对结果进行累加。 这是正确的，因为它直接遵循定义。 然而，它需要生成$n!$排列，以及每个排列的成本$O(n)$进行评估，导致$O(n \cdot n!)$，即使对于$n=12$。 

结构洞察力来自对称性。 修复一个元素$a_k$。 在所有排列中，该元素被放置在每个位置$j$完全相同的次数。 具体来说，如果我们修复$a_k$在位置$j$， 其余$n-1$元素可以任意排列，给出$(n-1)!$排列。 这意味着每对$(a_k, b_j)$准确贡献$(n-1)!$次到最后的总和。 

因此，我们不再考虑排列，而是将问题简化为对所有对的贡献进行求和，每个对的权重相等$(n-1)!$。 答案变成：$$(n-1)! \cdot \sum_{i=1}^{n} \sum_{j=1}^{n} (a_i \oplus b_j)$$现在问题已简化为有效计算双异或和。 XOR可以逐位分解，每个位独立贡献。 对于固定位$t$，我们只需要数一下有多少个$a_i$已设置该位以及有多少个$b_j$设置了该位。 比特的贡献$t$到$a_i \oplus b_j$当位不同时恰好为 1，这给出了标准组合表达式。 

让$c_a$是数字的计数$a$带位$t$设置，并且$c_b$同样对于$b$。 那么具有不同位的对的数量是$c_a (n - c_b) + (n - c_a)c_b$。 每对这样的贡献$2^t$。 

我们对最多 17 位的所有位求和（因为值最多为$10^5$），乘以$(n-1)!$，我们就完成了。

 ## 算法演练

 我们将问题重构为计算每比特的贡献并通过排列对称性进行缩放。 

1. 计算阶乘$(n-1)!$模数$10^9+7$。 这表示有多少排列将所选元素固定在固定位置。 关键思想是每个这样的分配都使得剩余元素可以自由排列。 
2. 对于每个位位置$t$从0到17，计算其中有多少个元素$a$设置了这个位，以及有多少个元素$b$设置它。 这将 XOR 行为隔离为独立的二进制维度。 
3. 对于位$t$，计算有多少有序对在该位的 XOR 中产生 1。 当一侧设置了位而另一侧没有设置位时，就会发生这种情况，因此我们计算两组之间的交叉组合。 
4. 将不同位对的数量乘以$2^t$，因为每个这样的对都会将该值贡献给 XOR。 
5. 累积所有位的贡献以获得所有位的总成对 XOR 和$a_i, b_j$。 
6. 将最终的两两总和乘以$(n-1)!$考虑所有排列，因为每一对都出现在那么多排列位置中。 

### 为什么它有效

 正确性取决于元素在排列位置上的均匀分布。 任意固定元素$a_i$出现在位置上$j$正好在$(n-1)!$排列，独立于$i$和$j$。 这种对称性将排列和简化为所有对上完整二分和的统一缩放。 一旦简化为成对结构，每位的异或线性度就可以保证对设置位不匹配的计数完全表征总贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    # factorial (n-1)!
    fact = 1
    for i in range(1, n):
        fact = fact * i % MOD
    
    max_bit = 17
    cnt_a = [0] * (max_bit + 1)
    cnt_b = [0] * (max_bit + 1)
    
    for x in a:
        for t in range(max_bit + 1):
            if x >> t & 1:
                cnt_a[t] += 1
    
    for x in b:
        for t in range(max_bit + 1):
            if x >> t & 1:
                cnt_b[t] += 1
    
    pair_sum = 0
    for t in range(max_bit + 1):
        ca = cnt_a[t]
        cb = cnt_b[t]
        diff_pairs = ca * (n - cb) + (n - ca) * cb
        pair_sum = (pair_sum + diff_pairs * (1 << t)) % MOD
    
    ans = pair_sum * fact % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```解决方案从计算开始$(n-1)!$，它编码将固定元素分配给固定位置的排列数。 在计算所有元素对的总贡献后，最后应用该因子。 

下一步将 XOR 结构压缩为位数。 我们不是直接计算 XOR，而是计算每个数组中有多少个数字设置了每个位。 这避免了二次对迭代。 

对于每一位，我们计算有多少交叉对在该位产生 1。 表达式$c_a (n - c_b) + (n - c_a)c_b$直接来自位不同的分割情况。 

最后，我们将总的成对异或和乘以排列多重因子。 

一个微妙的点是确保我们永远不会尝试显式地构造排列。 整个组合爆炸被吸收到阶乘乘数中。 

## 工作示例

 ### 示例 1

 输入：```
3
1 2 3
1 2 3
```我们计算$(n-1)! = 2$。 

我们计算比特贡献。 为简单起见，考虑实际的 XOR 对：

 | 配对类型| 计数 | 异或贡献总和|
 | --- | --- | --- |
 | 全部$a_i, b_j$成对| 9 | 12 | 12

 因此两两求和为 12，乘以 2 得到 24。 

这表明每对在排列中的贡献相同，并且阶乘缩放足以重建完整的答案。 

### 示例 2

 输入：```
3
2 2 2
3 4 4
```这里全部$a_i$相同，因此对称性更强。 

我们计算$(n-1)! = 2$。 现在评估成对异或：

 对于$2 \oplus 3 = 1$， 和$2 \oplus 4 = 6$。 

对数：

 - (2,3) 出现 3 次
 - (2,4) 出现 6 次

 两两总和：$3 \cdot 1 + 6 \cdot 6 = 39$乘以 2 得出$78$。 

这证实了即使值大量重复，重数也能得到正确处理。

 ## 边缘情况

 当$n=1$，只有一个排列，阶乘因子变为$(n-1)! = 1$。 该算法简化为单个 XOR 计算，因此它可以自然地处理简并组合结构，而无需特殊的外壳。 

当所有值都在$a$相同，位计数方法仍然有效，因为它不依赖于唯一性。 每个位的贡献仅由频率决定，并且该公式正确地将所有对差异折叠为统一计数。 

当两个数组相同时，每个 XOR 都为零，因此所有位不匹配计数都会消失。 该算法产生零，因为对于每一位，$c_a = c_b$，使得两个交叉项完全抵消，这证实了按位分解的正确性。
