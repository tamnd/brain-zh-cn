 ## 解决方案
 ## 问题理解

 我们正在使用一个整数数组，我们可以选择任何子序列，这意味着我们可以自由选择索引的子集并保持它们的值按顺序排列，但顺序本身不会影响计算，因为只有总和才重要。 

对于任何选定的子序列，我们计算其总和$x$。 我们分别考虑从整个数组导出的两个固定量：最小可能的子序列和$p$，以及最大可能的子序列和$q$。 任务是选择一个子序列，其总和$x$使价值$|2x - (p+q)|$尽可能小。 

关键是$p$和$q$仅取决于原始数组，而不取决于所选的子序列。 一旦它们被修复，问题就变成了对所有子序列和的搜索。 

限制条件$n \le 500$和$a_i \in [-500, 500]$立即表明指数子集太大而无法直接枚举。 完整子集空间具有大小$2^{500}$，这远远超出了任何可行的计算。 然而，这些值足够小，因此对可能的总和进行动态规划是合理的，因为总和范围最多为$[-250000, 250000]$。 

当所有数字均为正数或全部为负数时，会出现微妙的边缘情况。 在这些情况下，可实现的子序列和集会崩溃到单调极端，并且最佳答案通常来自空子序列或完整子序列。 假设我们必须至少选择一个元素或子序列和连续表现的天真的方法将失败。 

## 方法

 如果我们尝试暴力破解，我们将枚举每个子序列，计算其总和，然后计算表达式$|2x - (p+q)|$。 这是正确的，但需要迭代$2^n$子集。 和$n=500$，这是不可能的。 

表达式的结构表明围绕$(p+q)/2$。 我们试图选择一个子序列，其总和$x$尽可能接近这个中点。 因此，我们不考虑任意子序列，而只关心哪些和是可以实现的。 

这将问题转换为经典的子集和可达性问题。 我们使用动态规划计算所有可能的子序列和。 一旦我们知道了一组可实现的总和，我们就会扫描它们并选择最小化到目标中点的距离的总和。 

唯一的额外工作是计算$p$和$q$。 对于子序列，$p$是通过取所有负数获得的，因为包含负数总是会减少总和，并且跳过非负元素永远不会损害最小化。 相似地，$q$是通过取所有正数得到的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n \cdot n)$|$O(1)$| 太慢了|
 | DP 超过总和 |$O(n \cdot S)$,$S \le 5 \cdot 10^5$|$O(S)$| 已接受 |

 ## 算法演练

 ### 1. 计算固定参考值$p$和$q$我们扫描一次数组。 我们将所有负值添加到$p$，因为每个负元素都会严格减少一个子序列和。 我们将所有正值添加到$q$，因为每个正元素都会严格增加一个子序列和。 零不会影响任一极端。 

这是有效的，因为子序列选择对于每个元素都是独立的：每个元素要么贡献，要么不贡献，没有任何限制。 

### 2.定义目标值

 我们计算$target = p + q$，我们想要$x$附近$target / 2$。 我们不使用分数，而是使用绝对差进行比较$|2x - target|$，这使一切保持完整。 

### 3. 计算所有可达子序列和

 我们对可能的和使用布尔 DP。 由于值范围从 -500 到 500 并且$n \le 500$，总和范围的界限为$[-250000, 250000]$。 

我们将索引移动一个偏移量，以便负和映射到有效的数组索引。 对于每个元素$a_i$，我们更新 DP，以便任何先前可达到的总和$s$现在也可以达到$s + a_i$。 

我们必须以相反的顺序小心地迭代求和，以避免多次重复使用同一元素。 

### 4. 追踪最佳答案

 在填充 DP 时或之后，我们迭代所有可达的总和$x$。 对于每个，我们计算$|2x - target|$并保持最小值。 

### 为什么它有效

 DP 准确地表示所有可能的子序列和的集合。 每个转换对应于每个元素的二元决策，并且反向迭代确保每个元素在每个子集状态中最多使用一次。 由于每个有效子序列恰好对应于一个 DP 可达和，反之亦然，因此最小化 DP 状态相当于最小化所有子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    p = 0
    q = 0
    for v in a:
        if v < 0:
            p += v
        elif v > 0:
            q += v

    target = p + q

    offset = 250000
    size = 500001
    dp = [False] * size
    dp[offset] = True

    for v in a:
        if v == 0:
            continue
        if v > 0:
            rng = range(size - v - 1, -1, -1)
        else:
            rng = range(-v, size)

        for i in rng:
            if dp[i]:
                dp[i + v] = True

    ans = 10**18
    for i, ok in enumerate(dp):
        if ok:
            x = i - offset
            val = abs(2 * x - target)
            if val < ans:
                ans = val

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先隔离了计算$p$和$q$，这避免了对子集枚举的任何依赖。 DP 数组使用偏移量居中，因此负和不需要单独处理。 转换循环按以下符号分割$v$以在反向迭代时保持正确性。 

最终扫描在 DP 阵列上呈线性，并直接评估每个可实现总和的目标函数。

 ## 边缘情况

 像这样的案例`[-1, -2, -3]`使$p = -6$和$q = 0$。 所有可达到的总和都是非正数，因此最佳中点匹配被限制在该范围内。 DP 仍然正确枚举和 0、-1、-2、-3、-3、-4、-5、-6，并统一计算距离。 

具有所有积极因素的案例，例如`[5, 5, 5]`产量$p = 0$,$q = 15$。 中点是 7.5，但所有可达的和都是 0 到 15 的整数。DP 确保我们通过离散和隐式考虑 7 和 8，并选择最接近的一个。 

混合交替的情况，例如`[1, -1, 1, -1]`创建许多重复的和，但 DP 不会重复计算状态。 每个可达总和被记录一次，并且最终扫描正确地发现 0 是最佳的，因为$target = 0$。
