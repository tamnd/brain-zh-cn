 ## 解决方案
 ## 问题理解

 我们在 2D 平面上得到了几组独立的点。 对于每个集合，我们必须将所有点包含在一个轴对齐的正方形内，这意味着正方形的边平行于坐标轴。 在所有完全包含每个点的正方形中，我们想要具有最小可能面积的正方形。 

对于固定的测试用例，几何意义很简单：我们可以在任何地方放置一个正方形，但它的边长必须足够大，以覆盖 x 和 y 方向上的点的整个分布。 一旦我们知道了边长，面积就是它的平方。 

这些约束促使我们采用每次测试常数或对数解。 所有测试用例的总点数最多为 200,000，因此任何处理每个点恒定次数的解决方案都是可以接受的。 每个测试用例的任何二次方都会立即失败，因为即使是适度的输入分割也会超出时间限制。 

坐标范围产生了一个微妙的问题。 坐标可以大到 ±10^9，因此任何依赖于枚举候选正方形位置或平面上强力几何的方法都是不可行的。 

主要的边缘情况来自退化点集。 如果所有点都相同，则包围的正方形的边长应为 0，从而产生面积 0。如果只有一个点，则适用相同的逻辑。 另一种情况是，当点水平或垂直排列在一条线上时，只有一个维度决定答案。 一个天真的错误是将面积计算为`(max_x - min_x) * (max_y - min_y)`不强制执行正方形约束，当一维较大时，该约束会低估所需的正方形边长。 

例如，点`(0,0)`和`(10,1)`宽度为 10，高度为 1。矩形面积为 10，但正方形的边长必须为 10，面积为 100。 

## 方法

 蛮力的想法是考虑每一个可能的正方形放置。 人们可以想象选择一个左下角和一个边长，然后检查所有点是否都适合。 对于每个候选者，我们扫描所有点，从而进行 O(n) 验证。 如果我们使用点坐标离散化候选位置，我们仍然有 O(n^2) 或更差的中心或角的可能性，因为任何点都可能定义边界。 超过 n 大约几千之后，这很快就变得不可能了。 

关键的观察结果是，包围所有点的轴对齐正方形完全由极值坐标确定。 包含所有点的最小矩形的宽度`max_x - min_x`和身高`max_y - min_y`。 任何正方形的边长必须至少是这两个值中的较大者，因为缩小任一维度都会排除至少一个极值点。 

一旦我们接受边长是由这些极值固定的，最佳正方形就是边长为的最小正方形`max(max_x - min_x, max_y - min_y)`。 除了确保正方形可以放置在任何地方之外，我们不需要考虑位置选择； 移动正方形不会改变所需的边长。 

因此，每个测试用例都简化为线性扫描，计算 x 和 y 的最小值和最大值。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) 或更糟 | O(1) | O(1) | 太慢了|
 | 最佳| 每次测试 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取所有点并跟踪四个值：最小 x、最大 x、最小 y、最大 y。 这四个值捕获集合的整个几何分布，而不存储中间结构。 
2. 计算水平跨度为`dx = max_x - min_x`。 这表示包含所有点的任何轴对齐矩形的最小可能宽度。 
3. 计算垂直跨度为`dy = max_y - min_y`。 这代表任何此类矩形的最小可能高度。 
4. 确定所需正方形边长为`side = max(dx, dy)`。 此步骤通过确保两个尺寸都适合单个等长边来强制执行方形约束。 
5. 计算面积为`side * side`并将其输出用于测试用例。 

步骤 4 正确的关键原因是任何方块必须同时覆盖水平和垂直范围。 如果边小于 dx 或 dy，则至少一对极值点将位于该维度的正方形之外。 

### 为什么它有效

 这组点定义了与轴对齐的最小边界矩形。 任何包含所有点的轴对齐正方形必须完全包含该矩形。 因此，它的边长不能小于矩形的较大边。 相反，正方形的边长`max(dx, dy)`始终可以定位为覆盖边界矩形，因为我们不受固定原点的限制。 这使得计算端既必要又充分，从而保证了最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        min_x = 10**18
        max_x = -10**18
        min_y = 10**18
        max_y = -10**18

        for _ in range(n):
            x, y = map(int, input().split())
            if x < min_x:
                min_x = x
            if x > max_x:
                max_x = x
            if y < min_y:
                min_y = y
            if y > max_y:
                max_y = y

        dx = max_x - min_x
        dy = max_y - min_y
        side = max(dx, dy)
        out.append(str(side * side))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现在读取输入时直接维护 x 和 y 的运行极值，避免存储点列表。 这很重要，因为所有测试用例的总点数可能达到 200,000。 

唯一的微妙之处是最小值和最大值的初始化。 使用大的哨兵值也可以确保负坐标的正确性。 最终的平方边计算仅使用整数算术，这是安全的，因为差异在 64 位范围内。

 ## 边缘情况

 对于像这样的单点`(5, 5)`，算法将所有极值设置为相等，产生`dx = dy = 0`因此面积`0`。 这与零边的正方形仍然包含该点的事实相符。 

对于水平对齐的点，例如`(0,0), (5,0), (10,0)`，垂直跨度为零，水平跨度为 10。算法计算`side = 10`，生成面积 100。如果处理不当，任何使用矩形面积的尝试都会错误地输出高度贡献 0 或面积 0。 

对于垂直对齐的点，例如`(2,1), (2,5), (2,9)`，水平跨度为零，垂直跨度为 8。算法返回边 8 和区域 64，即使不存在水平扩展，也能正确水平扩展。 

对于混合负坐标，例如`(-3,-3)`和`(1,2)`，极值处理确保正确的差异，无论符号如何。 计算出的跨度是`dx = 4`,`dy = 5`，给出边 5 和区域 25。这证实了初始化和最小/最大更新正确处理整个整数范围。
