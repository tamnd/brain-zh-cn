 ## 解决方案
 ## 问题理解

 我们得到一个固定的字母表，由前 18 个小写字母组成，从`a`到`r`。 对于每个测试用例，我们都会收到一个字符串`s`和一个数字`n`。 我们被要求计算有多少个字符串`t`长度`n`，其中的所有字符`t`是不同的，满足涉及字符如何的特殊条件`t`彼此之间以及他们在里面的存在都有联系`s`。 

该条件有两种限定字符串的替代方法`t`为有效。 要么我们选择一个起始角色`t1`出现在某处`s`，然后通过为剩余位置选择严格递增的字母来扩展它，或者我们选择一个字符串`t`每个字符都出现在某个地方`s`不需要相邻字符之间的任何排序条件。 由于字母表很小并且`n ≤ 18`，两种解释都强烈表明答案仅取决于出现在中的字母`s`，而不是他们的立场。 

关键约束是总输入大小`s`所有测试用例的数量最多为 2 × 10^5，这迫使任何解决方案都要处理`s`最多 O(1) 或 O(log 18) 次。 由于字母表只有 18 个字母，任何对 18 的指数依赖都是可以接受的，但必须避免涉及大子集排列或每个测试用例重新计算的任何情况。 

出现微妙的边缘情况时`s`包含很少的独特字符。 例如，如果`s = "a"`和`n = 2`，如果规则允许超出存在约束的扩展，则仍然仅存在第一种类型的有效构造，但任何完全忽略排序的解释都会过度计算由不存在的字母组成的字符串。 同样，如果`s = "ar"`和`n = 2`，都增加对像`ab`,`ac`，以及类似反向的结构，例如`ra`变得相关，这表明问题是将单调结构与纯粹基于子集的条件混合在一起。 

重要的认识是，唯一的信息来自`s`是 18 个字母中至少出现一次的字母。 

## 方法

 我们首先考虑直接的暴力解释。 我们枚举所有可能的字符串`t`长度`n`具有 18 个字母的不同字符。 最多有 P(18, n) 种可能性，这已经很大了：对于 n = 18，这是 18！ 大约是 6.4 × 10^15。 对于每个候选字符串，我们通过扫描它并检查成员资格来检查它是否满足两个给定条件之一`s`。 即使使用布尔数组进行成员资格检查的时间复杂度为 O(1)，枚举本身也远远不可行。 

条件的结构表明，唯一真正的约束是所选字母集是否包含在`s`，或者是否可以从出现在中的字母开始按升序扩展`s`。 由于超过 18 个字母的“严格递增”意味着一旦我们选择了字母的子集，它们就恰好存在一个递增排列，因此第一个条件有效地描述了由出现在 中的字母组成的所有递增子序列。`s`。 

第二个条件只需要所有字符`t`出现在`s`，但由于字符是不同的并且顺序不受限制，因此大小的有效子集的每个排列`n`是允许的。 这将答案分为字母表子集上的两个独立的计数机制。 

因此，我们将问题简化为计算出现在的字母集中包含的字母子集`s`，然后计算每个子集贡献了多少有效排列或递增排列。 

让`k`是出现在的不同字母的数量`s`。 我们只关心这些`k`字母。 对于大小的每个子集`n`，正好有一个递增字符串，并且有`n!`有助于第二个条件的排列。 然而，第一个条件仅贡献增加的序列，每个子集已经包含一次。 所以对于大小的每个子集`n`，我们添加`n!`来自排列，并且增加的情况不会添加超出该设置解释的额外的不同字符串。 因此，问题归结为选择大小的任何子集`n`从`k`可用的字母并计算它的所有排列。 

于是答案就变成了：

 C(k, n) × n!。 

我们预先计算最多 18 的阶乘并计算不同的字母`s`每个测试用例。

 | 计算不同字母+组合 | O( | s | + n) |

 ## 算法演练

 1.读取字符串`s`和整数`n`。 计算有多少个不同的字母出现在`s`。 这个值是`k`，并且它完全总结了字符串中的所有相关信息，因为只有存在才重要，而不是频率或顺序。 
2.如果`k < n`，立即输出0。我们无法形成任何长度-`n`如果少于则具有不同字符的字符串`n`字母总共存在。 
3. 预先计算一次最多 18 的阶乘。 这些代表排列任何选定的大小子集的方法数量`n`。 
4. 计算选择的方式数量`n`来信`k`，即 C(k, n)。 乘以`n!`。 
5. 输出结果。 

### 为什么它有效

 每个有效字符串`t`准确地使用`n`与出现在的字母集中不同的字母`s`。 一旦大小的子集`n`是固定的，它的每个排列都会为第二个条件生成一个有效的字符串，并且第一个条件恰好贡献同一子集的唯一递增排序。 由于递增排序已经是排列之一，因此每个子集的有效字符串总数恰好是`n!`。 因此，问题归结为计算大小的子集`n`从可用的字母表中`s`，并乘以每个子集的排列数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXA = 18

fact = [1] * (MAXA + 1)
for i in range(1, MAXA + 1):
    fact[i] = fact[i - 1] * i

def solve():
    s, n = input().split()
    n = int(n)

    used = [0] * 26
    k = 0
    for ch in s:
        if not used[ord(ch) - 97]:
            used[ord(ch) - 97] = 1
            k += 1

    if k < n:
        print(0)
        return

    # C(k, n)
    comb = 1
    for i in range(n):
        comb *= (k - i)
        comb //= (i + 1)

    print(comb * fact[n])

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```该解决方案首先将输入字符串压缩为包含 26 个字母的布尔存在数组，但只有前 18 个字母是相关的。 计数`k`跟踪存在多少个不同的可用字母。 

二项式系数是迭代计算的，以避免预先计算帕斯卡三角形并保持内存恒定。 自从`n ≤ 18`，整数增长在 Python 中是安全的并且永远不会变得昂贵。 

乘以`fact[n]`考虑每个选定子集的所有排列。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import factorial

    MAXA = 18
    fact = [1] * (MAXA + 1)
    for i in range(1, MAXA + 1):
        fact[i] = fact[i - 1] * i

    t = int(sys.stdin.readline())
    out = []
    for _ in range(t):
        s, n = sys.stdin.readline().split()
        n = int(n)

        used = [0] * 26
        k = 0
        for ch in s:
            if not used[ord(ch) - 97]:
                used[ord(ch) - 97] = 1
                k += 1

        if k < n:
            out.append("0")
            continue

        comb = 1
        for i in range(n):
            comb *= (k - i)
            comb //= (i + 1)

        out.append(str(comb * fact[n]))

    return "\n".join(out)

 ## 边缘情况

 当`s`恰好包含`n`不同的字母，计算减少到单个子集。 算法正确输出`n!`，因为 C(n, n) = 1 并且所有排列都被计算在内。 

什么时候`s`包含许多重复项但很少有不同的字符，该实现正确地完全忽略了频率。 例如，`s = "aaaaabbbb"`行为完全像`s = "ab"`，因为只有存在才重要。 

什么时候`n = 1`，每个独特的字符`s`形成一个有效的字符串，公式返回C(k, 1) × 1 = k，与直接枚举匹配。 

什么时候`k < n`，提前退出确保不执行不必要的组合计算，避免无效状态上的除法步骤。
