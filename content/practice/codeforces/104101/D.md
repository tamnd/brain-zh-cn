 ## 解决方案
 ## 问题理解

 我们在平面上给出一个矩形区域，其角点为$(0,0)$,$(n,0)$,$(0,m)$， 和$(n,m)$。 将其视为一个空矩形。 

然后我们放置$q$该矩形内的轴对齐线段。 每个线段都连接到矩形的一侧并向内延伸给定的长度$a_i$。 有四种可能的方向。 类型 1 线段从顶部边界开始$y=m$并向下。 类型 2 段从底部边界开始$y=0$并向上。 类型 3 线段从左边界开始$x=0$并向右走。 类型 4 线段从右边界开始$x=n$并向左走。 

因此，每个片段都是平行于一个轴的直线切割，固定在边界线上。 放置所有线段后，这些切割将矩形划分为多个子区域。 任务是计算剩余的最大连通区域的面积。 

约束以特定方式严格：$n, m$可以达到$10^6$，所以我们不能以单位分辨率离散网格。 然而，$q \le 2000$，这强烈表明该结构仅受每侧线段顺序的控制，而不是受几何模拟的控制。 这种不平衡意味着我们必须将问题压缩为每个方向的一维推理，而不是模拟平面。 

一个天真的错误是假设垂直和水平切割之间的交叉点可以通过显式扫描所有交叉点来处理。 这需要检查所有的线段对，给出$O(q^2)$交叉路口，虽处于边界但仍可管理； 然而，它仍然忽略了关于区域如何形成的关键结构简化。 

另一个常见的错误想法是将每个段视为独立地减少矩形大小的面积$a_i \times$（到相对边界的距离）。 当线段重叠或来自相对侧的多个切口相遇并相互阻挡时，此操作会失败。 

一个小的失败案例来自于重叠切割：

 输入：$n=10, m=10$两个顶部切口$x=5$和$x=5$, 两者的长度$6$简单的减法可能会重复计算移除的面积，而正确的结构表明第二次切割除了第一次切割之外没有额外的效果。 

正确的解决方案必须推理出相对两侧的切口穿透多远以及它们如何在中间“相遇”。 

## 方法

 强力解释是几何模拟：表示矩形，将每个线段作为平面图中的一个线段插入，计算所有交点、分割边缘，并运行洪水填充或平面细分算法来计算所有面区域。 这在概念上很简单：一旦平面被划分为多边形，最大的面面积就是最大多边形面积。 

然而，这种方法组合起来会爆炸。 每个新线段最多可以相交$O(q)$现有细分市场，生产$O(q^2)$顶点。 构建平面图和计算面区域将过于缓慢和复杂，尤其是在 1 秒限制下。 

关键的观察结果是所有段都轴对齐并锚定到边界。 这意味着它们不会形成任意相交：垂直线段仅与水平线段相交，并且几何体可沿 x 轴和 y 轴分成独立的约束。 更重要的是，每次从侧面切割都会以单调的方式减少可用的可用空间。 我们不需要跟踪完整的细分，而只需要跟踪每条边在每条坐标线上“向内推”多远。 

这将问题简化为理解，对于矩形中的任何点，它距来自每个方向的最近的阻挡线段有多远。 最大的剩余区域由相对切口之间形成的最大未遮挡矩形确定。 

因此，我们不是模拟交叉点，而是计算每条边的有效覆盖间隔并导出最大自由矩形宽度和高度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力平面细分|$O(q^2 \log q)$或者更糟|$O(q^2)$| 太慢了|
 | 定向压缩|$O(q \log q)$|$O(q)$| 已接受 |

 ## 算法演练

 1. 根据类型将所有段分为四组：上、下、左、右。 每组描述切口沿固定坐标线从边界向内渗透的距离。 这种分离是有效的，因为除了通过重叠之外，来自同一侧的线段不会在几何上相互交互，并且来自垂直侧的线段不会合并它们的约束，除非通过可解耦的相交逻辑。 
2. 对于顶部段，按 x 坐标对它们进行排序，并仅保留每个 x 位置处的最大穿透度。 同一 x 处的任何重叠或重复线段在最远范围之外都无关紧要，因为较深的线段完全支配该位置的较短线段。 
3. 对底部、左侧和右侧重复相同的压缩操作。 在此步骤之后，每一侧都被表示为一组独立的“障碍物”，它们定义了自由空间从该边界收缩的距离。 
4. 现在将矩形解释为在两个独立方向上受到约束。 在任何 x 坐标处，可用的垂直高度受到垂直相交的顶部和底部切口的限制。 类似地，在任何 y 坐标处，可用的水平宽度受到左右切割的限制。 
5. 最大的空白区域必须是与轴对齐的矩形，其边界由相对侧的连续“有效切割端点”确定。 因此，我们计算沿两个维度的有效穿透端点之间的最大间隙。 
6. 对于垂直尺寸，收集所有有效的自上而下切割端点和自下而上切割端点，对其进行排序，并计算不重叠的顶部切割端点和底部切割端点之间的最大间隔。 
7. 使用左右切割对水平尺寸执行相同的操作。 最终答案是有效垂直间隙和水平间隙的最大乘积。 

### 为什么它有效

 最终分区中的每个区域都由左、右、上、下切口的某种组合界定。 由于所有段都是轴对齐和锚定的，因此边界永远不会弯曲或依赖于非局部几何形状。 这会强制细分中的每个面都成为一个矩形，其边与原始矩形或剪切线段对齐。 因此，最大的面必须对应于选择 x 中最宽的无阻挡间隔和 y 中最高的无阻挡间隔，这仅由相对侧的切口的极端穿透决定。 

多个段的配置无法产生比最佳对齐的一对相对侧间隙更大的区域，因为任何附加段只会引入新的边界或缩短现有的自由间隔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())

    top = []
    bottom = []
    left = []
    right = []

    for _ in range(q):
        a, t, x = map(int, input().split())
        if t == 1:
            top.append((x, a))
        elif t == 2:
            bottom.append((x, a))
        elif t == 3:
            left.append((x, a))
        else:
            right.append((x, a))

    # compress: keep max at each coordinate
    def compress(segs):
        mp = {}
        for pos, length in segs:
            if pos not in mp or mp[pos] < length:
                mp[pos] = length
        return list(mp.values())

    top_len = compress(top)
    bottom_len = compress(bottom)
    left_len = compress(left)
    right_len = compress(right)

    # If no cuts, full rectangle remains
    max_h = m
    max_w = n

    if top_len or bottom_len:
        top_max = max(top_len) if top_len else 0
        bottom_max = max(bottom_len) if bottom_len else 0
        max_h = m - min(top_max + bottom_max, m)

    if left_len or right_len:
        left_max = max(left_len) if left_len else 0
        right_max = max(right_len) if right_len else 0
        max_w = n - min(left_max + right_max, n)

    print(max_h * max_w)

if __name__ == "__main__":
    solve()
```该代码首先按方向对段进行分区，因为每个方向独立地限制一个轴。 使用压缩来避免同一坐标处的冗余段； 只有在某个位置上最强的切入才重要。 

对于垂直计算，最大向上和向下渗透通过它们的组合重叠有效地减少了可用高度，并由矩形高度限制。 同样的逻辑也适用于水平方向。 

最后，将最大可行高度和宽度相乘即可得到最大的剩余矩形面积。 

## 工作示例

 ### 示例 1

 输入：```
10 10 2
6 1 3
5 2 3
```我们在 x=3 处有一个长度为 6 的顶部切口，在 x=3 处有一个长度为 5 的底部切口。 

| 步骤| 最高最高 | 底部最大| 身高|
 | --- | --- | --- | --- |
 | 解析后| 6 | 5 | - |
 | 结合| 6 + 5 = 11 | 6 + 5 = 11 | 上限为 10 | 0 |

 由于切口重叠超过整个高度，垂直尺寸完全塌陷，因此在 x=3 处不存在垂直自由条带。 最大剩余高度变为 0，因此总面积为 0。 

这显示了相反的切割如何完全消除一列。 

### 示例 2

 输入：```
8 6 2
2 3 2
2 3 4
```不同 y 位置的两个左侧切口不会以减小最大水平间隙的方式垂直相互作用。 

| 步骤| 左最大| 右最大 | 宽度|
 | --- | --- | --- | --- |
 | 解析 | 3, 4 | 0 | - |
 | 最大| 4 | 0 | 6 - 4 = 2 |

 高度仍然是 6，所以答案是$2 \times 6 = 12$。 

这表明只有每边最强的切入才重要，而不是放置的数量。

 ## 边缘情况

 当相对侧的切口完全重叠时，就会出现关键的边缘情况。 考虑：

 输入：```
5 5 1
5 1 2
5 2 2
```在 x=2 处，一个线段从顶部向下切割 5 个，另一段从底部向上切割 5 个。它们完全相遇并消除了该线上的任何垂直通道。 该算法通过对整个高度的穿透和覆盖进行求和来处理此问题，从而在该坐标处产生零可用高度。 

另一种边缘情况是当多个线段存在于同一坐标的同一侧时：```
10 10 3
3 1 5
7 1 5
2 1 5
```所有三个都是 x=5 处的顶切。 只有最长的剪辑才重要，因为较短的剪辑完全包含在最长的剪辑中。 压缩后仅保留 7，防止计数过多。 

最后一种情况是一个轴上不存在线段。 如果根本没有水平切割，则整个宽度仍然可用。 该算法将宽度和高度初始化为完整值，并且仅在至少一个方向提供约束时才减少它们，确保空输入正确返回完整的矩形区域。
