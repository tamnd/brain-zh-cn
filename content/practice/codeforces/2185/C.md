 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，其中可能包含负数。 该任务允许我们选择一个整数移位`x`并将其添加到数组的每个元素中。 执行此转换后，我们希望最大化数组的 MEX。 数组的 MEX 定义为数组中不存在的最小非负整数。 

实际上，问题是问：通过统一移动所有元素，我们可以创建的从零开始的最大“间隙”是数组中缺失的？ 例如，一个数组`[2, 4, 1, 0, -1]`可以进行移位，使元素从零开始，使连续的非负整数尽可能长地出现，从而进一步推动第一个缺失的数字。 

限制是中等的：所有测试用例中最多有 3000 个数组元素。 这意味着`O(n^2)`解决方案可以工作，但我们应该更喜欢`O(n log n)`或者`O(n)`如果可能的话，在 2 秒的时间限制内保持舒适。 负数必须小心处理，因为假设非负数的天真的方法可能会失败。 

当所有数字都相同或最小数字已经为零时，就会出现边缘情况。 例如，`[1, 1]`只能通过移动`-1`制作数组`[0, 0]`，给出 MEX`1`。 另一种边缘情况是当数组已经包含来自的连续数字时`0`到`k`; 最佳 MEX 仅比移位后的最大元素多 1，可能为零移位。 

## 方法

 蛮力方法很简单：尝试所有可能的转变`x`从`-max(a)`到`-min(a)`以便移位后的数组触及零并在每次移位后检查 MEX。 这是可行的，因为添加一个大的正数或负数可以将元素推得很远，但潜在的移位数量是巨大的（最多 2*10^9），因此迭代所有移位是不可行的。 

关键的见解是最佳移位将数组中的最小数字与零对齐。 一旦最小元素变为零，MEX 将由排序数组中最小的缺失整数确定。 由于我们只需要考虑最小数和零之间的差异，因此单个操作就足够了：将所有元素移动`-min(a)`。 此后，数组变为非负并从零开始。 MEX 只是连续非负序列被破坏的第一个索引。 

对移位后的数组进行排序允许我们计算从零开始出现的连续数字的数量。 第一个缺口表示 MEX。 这将问题简化为每个测试用例一次排序加上线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（尝试所有 x）| O(范围(a) * n) | O(n) | 太慢了|
 | 最优（按 -min(a) 移位、排序、查找 MEX）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`长度`n`。 
2. 计算数组中的最小值，`min_a`。 该值确定将最小元素归零所需的移位。 
3. 将数组移动`x = -min_a`。 这保证了最小元素为零并且所有元素都是非负的。 
4. 对移位后的数组进行排序。 排序简化了查找第一个缺失整数的过程，因为我们现在可以从零向上扫描。 
5. 初始化变量`mex`为零。 迭代排序后的数组，跳过重复项。 对于每个元素，如果它等于`mex`, 增量`mex`by 1. 第一个元素大于`mex`打破了连续的序列，所以`mex`此时就是数组的 MEX。 
6. 输出`mex`作为班次后可能的最大 MEX。 

**为什么有效：** 最佳移位必须使某些元素为零，因为 MEX 是非负整数。 移动任何低于零的元素永远不会将 MEX 增加到超出第一个缺失的非负整数。 排序和扫描可确保我们正确地考虑重复序列和连续序列，从而保证检测到第一个间隙。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_mex(a):
    min_a = min(a)
    shifted = [x - min_a for x in a]
    shifted.sort()
    mex = 0
    for val in shifted:
        if val == mex:
            mex += 1
    return mex

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max_mex(a))
```**说明：**

 我们首先计算数组的最小值来确定移位。 减法`min_a`从每个元素确保数组从零开始。 对数组进行排序可以让我们通过检查轻松找到第一个缺失的非负整数`mex`针对每个值。 最终循环仅通过递增正确地跳过重复项`mex`当当前值等于`mex`。

 ## 边缘情况

 对于数组`[1,1]`，最小值为 1。移位`-1`产量`[0,0]`。 排序给出`[0,0]`。 MEX 扫描从 0 开始； 第一个元素 0 将 MEX 递增到 1，第二个元素 0 被跳过。 正确的 MEX 是 1。这证实了重复项不会人为地夸大 MEX。 

为了`[ -1, 1, 2, 3, 5, 6 ]`，最小值为-1。 移动依据`1`给出`[0,2,3,4,6,7]`。 排序：`[0,2,3,4,6,7]`。 扫描墨西哥
