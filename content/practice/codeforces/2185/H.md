 ## 解决方案
 ## 问题理解

 一旦我们不再考虑个人比赛，锦标赛的结构就会出人意料地简单。 

每当一头牛在一场比赛中获胜时，它的新技能就成为两个参与者的总和。 连续几次获胜后，幸存的牛的技能简直就是它吸收的所有牛的总和。 

假设我们专注于一头具有初始技能的特定奶牛`v`。 我们将其从原来的位置移除并插入到其他地方。 问题是，如果这头牛最多可以用力的话，多少个插入位置可以让这头牛成为最后的幸存者`k`损失变为胜利。 

关键的观察结果是，当我们的牛到达队列中的某个位置时，其左侧的所有内容都已合并为一头牛，其力量等于这些值的总和。 唯一重要的是，我们的牛目前的力量是否至少达到这个累计值。 如果没有，则需要进行一次作弊。 

所有测试用例中的奶牛总数最多为`2 · 10^5`。 任何明确模拟每个位置的每头牛的方法都会立即变得二次，这太大了。 我们周围需要一些东西`O(n log n)`每个测试用例，或者`O(n log^2 n)`在最坏的情况下。 

当一头牛插入最前面时，会出现微妙的边缘情况。 

例如：```
n = 3, k = 0
a = [1, 2, 3]
```如果牛`3`被移动到位置`1`，它永远不必与组合前缀作斗争`[1,2]`。 将每个位置都视为总是有左侧合并会超出所需的作弊次数。 

另一个容易犯的错误是假设一头牛在向右移动时可能需要很多作弊。 每次作弊胜利后，其强度至少会增加一倍，因此不同作弊事件的数量在数值范围内只是对数。 这一事实使解决方案变得可行。 

## 方法

 暴力解决方案很简单。 

选择一头牛。 全部尝试`n`插入位置。 模拟整个比赛并计算奶牛需要作弊多少次。 如果计数不超过`k`，这个位置很好。 

单次模拟成本`O(n)`。 有`n`每个的位置`n`牛, 给予`O(n³)`在最坏的情况下工作。 即使进行了优化，任何接近的东西`O(n²)`每个测试用例已经太慢了`n = 2 · 10^5`。 

突破来自于通过前缀和来查看锦标赛。 

让```
pref[i] = a1 + a2 + ... + ai
```当一头牛的力量`v`站在最前面，开始从左到右吸收牛，正好在哪个位置就需要作弊```
a[i] > pref[i-1]
```因为目前在遇到牛之前所积累的实力`i`等于`pref[i-1]`。 这些“危险”位置与大多数插入选择无关。 而且，每次这样的姿势强行作弊，牛的实力至少会增加一倍，所以危险姿势的总数只有`O(log A)`。 

对于每头牛，我们可以构建一组危险位置，这些位置在移除该牛后仍然相关。 从这个集合我们可以确定：

 1、每个位置是否自动获胜。 
2. 插入位置最多需要哪个后缀`k`作弊。 
3. 牛恰好需要时的特殊边界情况`k`作弊和左侧合并可能会消失。 

这将问题简化为对前缀和和危险位置的有序列表进行二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(1) | O(1) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算前缀和`pref`。 
2. 建立清单```
pos = { i | a[i] > pref[i-1] }
```这些正是从前面出发的牛需要作弊的位置。 
3. 处理每头牛`i`独立。 
4. 构建过滤列表`g`。 

对于每一个危险的位置`x ≠ i`，确定移除牛后是否仍然存在危险`i`。 

如果`x < i`, 前面的前缀`x`是不变的。 

如果`x > i`，移除的值`a[i]`从前缀中消失，所以条件变为```
a[x] > pref[x-1] + a[i]
```与已接受的解决方案完全相同。 
5.让`m = len(g)`。 

如果`m < k`，即使是最差的插入位置也使用少于`k`作弊，所以每个位置都很好。 
6. 如果`k > 0`，找到对应的位置`k`从最后开始的第-次危险事件。 

这决定了在作弊预算内仍然可以赢得的插入位置的最大后缀。 
7. 特殊情况发生时`m == k`。 

这里的答案还包括左侧合并完全消失的位置。 

使用前缀和和二分搜索来查找奶牛可以插入到左边多远，同时避免额外的作弊。 
8. 输出每头牛的累计数量。 

### 为什么它有效

 关键的不变量是，当一头牛吸收了一组牛后，它的力量等于它们力量的总和。 胜利的确切顺序并不重要。 

只有当下一个对手超过当前累积的实力时才需要作弊。 这些事件正是前缀和条件所识别的危险位置。 

删除一头牛只会更改其右侧的前缀，这就是为什么可以通过调整危险位置集来处理每头牛，而不是重新计算整个锦标赛。 

后缀计数步骤之所以有效，是因为插入位置相对于遇到的危险事件的数量变得单调。 一旦某个职位需要超过`k`作弊，同一地区的每个早期位置也会失败。 这种单调性允许二分搜索。 

## Python 解决方案```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, k = map(int, input().split())
        a = [0] + list(map(int, input().split()))

        pref = [0] * (n + 1)
        for i in range(1, n + 1):
            pref[i] = pref[i - 1] + a[i]

        pos = []
        for i in range(1, n + 1):
            if a[i] > pref[i - 1]:
                pos.append(i)

        ans = [0] * (n + 1)

        for i in range(1, n + 1):
            g = []

            for x in pos:
                if x == i:
                    continue

                if a[x] > pref[x - 1] + (a[i] if x < i else 0):
                    g.append(x)

            if len(g) < k:
                ans[i] = n
                continue

            cur = 0

            if k > 0:
                p = g[-k]
                cur += n - p + 1 - (1 if p < i else 0)

            if len(g) == k:
                if pref[i - 1] >= a[i]:
                    cur += bisect_left(pref, a[i], 1) - 1
                else:
                    cur += bisect_left(pref, 2 * a[i], 1) - 2

            ans[i] = cur

        print(*ans[1:])

solve()
```此实现遵循竞赛分析社区公认的想法。 前缀和数组是中心结构，因为每个锦标赛状态都由先前吸收的奶牛的总和表示。 

过滤后的列表`g`是最微妙的部分。 去除牛`i`更改其右侧的每个前缀，因此必须调整危险条件。 如果方向错误，就会导致许多隐藏测试的失败。 

表达式```
g[-k]
```选择`k`从最后开始的第 - 个危险位置。 这仅在以下情况下有效`k > 0`，这就是代码单独处理这种情况的原因。 

所有算术都使用Python整数，因此即使前缀和可能达到约，也不存在溢出风险`2 · 10^14`。 

## 工作示例

 ### 示例 1```
n = 2
k = 0
a = [2, 1]
```| 我| 危险岗位| 长度(g) | 好职位|
 | ---| ---| ---| ---|
 | 1 | ∅ | 0 | 2 |
 | 2 | {1} | 1 | 0 |

 奶牛`1`已经主宰了一切可能的安排。 奶牛`2`不作弊，永远无法战胜更强大的牛。 

### 示例 2```
n = 3
k = 1
a = [1, 1, 3]
```| 我| 拆除后的危险位置| 长度(g) | 回答 |
 | ---| ---| ---| ---|
 | 1 | {3} | 1 | 2 |
 | 2 | {3} | 1 | 2 |
 | 3 | ∅ | 0 | 3 |

 大牛可以从每个插入位置获胜。 只有当单个可用的作弊得到最佳使用时，较小的奶牛才能获胜。 

这些痕迹说明了主要的不变量：只有危险的位置才重要，而不是完整的锦标赛模拟。

 ## 边缘情况

 考虑```
n = 2
k = 0
a = [1, 1]
```第一头牛获胜。 如果我们忽略平局规则并在各处使用严格的比较，我们就会错误地得出两头牛都赢不了的结论。 基于前缀的公式保留了原始锦标赛规则，因为危险位置是使用`>`而不是`>=`。 

考虑```
n = 3
k = 0
a = [1, 2, 3]
```将最后一头牛移到前面会删除整个左侧合并。 该算法通过特殊的方法来处理这个问题`len(g) == k`分支，它明确计算潜在作弊消失的位置。 

考虑```
n = 5
k = 4
a = [1, 1, 1, 1, 100]
```一个简单的模拟可能会出现很多作弊行为。 事实上，有意义的危险位置的数量很少，因为每次成功的作弊都会使奶牛的有效力量加倍。 该算法利用了这种对数结构，并且不需要逐一模拟匹配。
