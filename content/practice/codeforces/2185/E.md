 ## 解决方案
 ## 问题理解

 每个机器人都接受完全相同的动作序列。 在第一条指令之后，所有机器人都移动相同的位移。 在第二条指令之后，所有机器人都移动另一个公共位移，依此类推。 

让$p_i$是第一个之后的累积位移$i$指示。 机器人从指定位置开始$a$将在位置$a + p_i$步骤后$i$。 

机器人第一次落在尖刺上就会死亡。 对于每个指令前缀，我们必须输出有多少个机器人还活着。 

第一个观察结果是机器人从不相互交互。 机器人能否生存仅取决于其自身的起始位置和尖峰位置。 这让我们可以计算每个机器人的独立死亡时间。 

限制才是真正的挑战。 在所有测试用例中，总和$n$,$m$， 和$k$每个最多$2 \cdot 10^5$。 任何模拟每个机器人执行每条指令的解决方案都需要$O(nk)$工作，可以达到$4 \cdot 10^{10}$操作，是完全不可行的。 我们需要一些接近的东西$O((n+m+k)\log k)$。 

当机器人从未到达任何尖峰时，就会出现微妙的边缘情况。 例如：```
1
1 1 3
10
100
LRL
```当尖峰位于 100 时，机器人仅在位置 10 附近移动。正确答案是：```
1 1 1
```仅查看最终位置的解决方案会错误地得出结论：发生了一些较早的碰撞。 

另一个容易犯的错误是忘记在任何中间时间触摸尖刺都会立即杀死机器人。 考虑：```
1
1 1 2
1
2
RL
```机器人移动了$1 \to 2 \to 1$。 它在第一次移动后就死了，所以答案是：```
0 0
```仅检查所有指令后的位置会错过这次碰撞。 

最后一个不明显的情况是机器人可能会因为两侧的尖刺而死亡。 例如：```
robot = 10
spikes = {7, 20}
moves = LLL
```机器人在第三步达到 7 时死亡。 只查看右侧最近的尖峰是不正确的。 

## 方法

 蛮力的想法很简单。 对于每个机器人，逐步模拟指令序列，更新其位置，并检查其是否站在尖峰上。 发生这种情况的第一步是它的死亡时间。 

这是正确的，因为它完全遵循声明中描述的过程。 不幸的是，它执行$O(nk)$更新。 两个值都接近$2 \cdot 10^5$，运行时间变得太大。 

关键的观察结果是所有机器人都共享相同的位移序列。 

让$$p_i$$是之后的累积位移$i$指示。 

对于从位置开始的机器人$a$，其在步骤之后的位置$i$是$$a+p_i.$$如果某个尖峰位置位于它访问过的所有位置中，则机器人就会死亡。 

假设我们知道第一个过程中达到的最小和最大累积位移$i$指示：$$L_i=\min_{1\le j\le i} p_j, \qquad R_i=\max_{1\le j\le i} p_j.$$由于每次移动都会精确地改变一个单位的位置，因此行走会访问其最小位移和最大位移之间的每个整数点。 因此，在第一次期间$i$指令，机器人从$a$正好访问间隔$$[a+L_i,\; a+R_i].$$所以机器人在之后还活着$i$当且仅当没有尖峰位于该区间内时才进行步进。 唯一重要的尖峰是机器人起始位置左侧最近的尖峰和右侧最近的尖峰。 

对于每个机器人，我们可以二分搜索最大的前缀长度，其间隔仍然避免两个相邻的尖峰。 这给出了机器人还活着的最后一步。 在计算每个机器人的这个值后，我们只需要计算每个前缀长度有多少个机器人存活下来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(nk)$|$O(m)$| 太慢了|
 | 最佳|$O((m+k)\log m + n(\log m+\log k))$|$O(m+k+n)$| 已接受 |

 ## 算法演练

 ### 1. 计算累积位移极值

 处理指令串一次。 

维持当前位移$p$。 

对于每个前缀$i$， 店铺：$$L_i=\min(L_{i-1},p),$$和$$R_i=\max(R_{i-1},p).$$这些值描述了在第一个过程中达到的最左边和最右边的位移$i$指示。 

### 2. 对尖峰位置进行排序

 对所有尖峰坐标进行排序。 

对于每个机器人位置$a$，找到：

 - 最近的尖峰严格位于左侧，
 - 最近的尖峰严格位于右侧。 

这是通过在排序的尖峰数组中进行二分搜索来完成的。 

### 3.二分查找每个机器人的生存长度

 对于固定位置的机器人$a$， 让：

-$left$是它最近的左边尖峰，
 -$right$是其最近的右侧尖峰。 

对于前缀长度$mid$，机器人在以下时间仍然存活$$left < a+L_{mid}$$和$$a+R_{mid} < right.$$第一个不等式意味着探索的区间尚未到达左侧尖峰。 第二个意味着它还没有到达正确的峰值。 

这些条件是单调的。 机器人一旦死亡，就永远无法再复活。 因此，我们二分查找满足两个不等式的最大前缀长度。 

调用这个值$c$。 机器人走完步就活了$1,2,\dots,c$然后就死了。 

### 4. 每一步计算幸存者数量

 存储所有值$c$。 

对它们进行排序。 

对于每条指令计数$i$，我们需要机器人的数量$$c \ge i.$$对排序数组进行两指针扫描可以在线性时间内给出所有答案。 

### 为什么它有效

 对于任何指令前缀，每个机器人都会遵循相同的位移行走。 该行走期间访问的位移集恰好是迄今为止达到的最小位移和最大位移之间的间隔。 

机器人从指定位置开始$a$因此正好访问间隔$[a+L_i,a+R_i]$。 当且仅当该区间内没有尖峰时，机器人才能生存。 

最近的左右尖峰完全决定了该区间是否包含尖峰。 如果它们之间的间隔严格保持，则所有其他尖峰距离更远，无法到达。 如果任何一个相邻的尖峰进入该间隔，机器人就会立即死亡。 

生存条件相对于前缀长度是单调的，因此二分查找可以正确找到最后一个生存前缀。 计算生存长度至少为$i$产生之后存活的数字$i$指示。 

## Python 解决方案```python
import sys
from bisect import bisect_left, bisect_right

input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, m, k = map(int, input().split())
        robots = list(map(int, input().split()))
        spikes = sorted(map(int, input().split()))
        s = input().strip()

        min_disp = [0] * (k + 1)
        max_disp = [0] * (k + 1)

        cur = 0
        for i, ch in enumerate(s, 1):
            if ch == 'L':
                cur -= 1
            else:
                cur += 1

            min_disp[i] = min(min_disp[i - 1], cur)
            max_disp[i] = max(max_disp[i - 1], cur)

        NEG_INF = -10**18
        POS_INF = 10**18

        survive = []

        for a in robots:
            pos = bisect_left(spikes, a)

            left_spike = spikes[pos - 1] if pos > 0 else NEG_INF
            right_spike = spikes[pos] if pos < m else POS_INF

            lo, hi = 1, k
            best = 0

            while lo <= hi:
                mid = (lo + hi) // 2

                alive = (
                    left_spike < a + min_disp[mid]
                    and a + max_disp[mid] < right_spike
                )

                if alive:
                    best = mid
                    lo = mid + 1
                else:
                    hi = mid - 1

            survive.append(best)

        survive.sort()

        ans = []
        ptr = 0

        for step in range(1, k + 1):
            while ptr < n and survive[ptr] < step:
                ptr += 1
            ans.append(str(n - ptr))

        print(*ans)

solve()
```第一部分计算累积位移极值。`min_disp[i]`和`max_disp[i]`描述运动序列探索的整个范围，直到步骤`i`。 

对于每个机器人，我们在排序的尖峰数组上使用二分搜索来定位邻近的尖峰。 当一侧不存在尖峰时，将使用无限哨兵。 这避免了以后的特殊情况逻辑。 

对指令前缀的二分查找依赖于单调性。 如果一个机器人在较长的前缀中幸存下来，它也会在每个较短的前缀中幸存下来。 相反，一旦峰值进入探索区间，每个较大的前缀仍然无效。 

最后的计数阶段很容易出错。`survive[i]`存储机器人仍然存活的最大步数索引。 机器人帮忙回答`step`恰好在什么时候`survive[i] >= step`。 对这些值进行排序允许单指针扫描。
