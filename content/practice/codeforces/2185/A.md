 ## 解决方案
 ## 问题理解

 我们被要求为每个测试用例生成一系列不同的“完美根”。 完美的根只是一个整数$x$这样$x^2$也是一个整数，对于所有正整数来说都是如此。 换句话说，每个正整数都有资格作为完全根，因为它的平方也是整数。 

输入由许多测试用例组成$t$，每个指定一个整数$n$。 对于每个测试用例，我们必须输出$n$不同的正整数，每个最多$10^9$。 除了每个测试用例不同且在指定范围内之外，完美根的值没有任何限制。 

关键的见解是，问题更多的是生成任何一组不同的正整数，而不是执行任何复杂的数学计算。 鉴于$n$很小（最多 20）并且值的限制很高（$10^9$），我们不需要担心性能或大规模数字生成。 边缘情况可能涉及$n = 1$或者$n = 20$，但任何从 1 到 的连续整数的简单序列$n$足够且安全。 例如，粗心的实现可能会在单个测试用例中意外重复数字或超过$10^9$限制。 

## 方法

 一种简单的方法是随机挑选数字并检查它们是否不同。 这适用于小型$n$，但是检查唯一性的开销是不必要的。 此外，随机性可能会带来冲突的风险，需要重试。 

最佳方法是确定性的：生成第一个$n$直接正整数。 这保证了所有数字都是不同的，根据定义，每个数字都是完美的根，并且没有一个超过$10^9$。 由于最大$n$是 20，这个解决方案非常快速且简单。 不需要优化技巧或高级数据结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 具有唯一性检查的随机生成 | 最坏情况下的 O(n²) | O(n) | 不必要的复杂性 |
 | 确定性连续整数 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取整数$t$对于测试用例的数量。 这设置了一个循环来独立处理每个测试用例。 
2. 对于每个测试用例，读取整数$n$它指定要输出多少个完全根。 
3. 生成从 1 到 的整数列表$n$。 每个整数本质上都是完美根，因为它的平方是有效整数。 
4. 在一行上以空格分隔值的形式输出整数列表。 
5. 对所有测试用例重复此操作。 

工作原理：该算法保留了每个输出列表中的所有数字都是不同且正数的不变式，并且每个数字$x$满足$x^2$是一个整数。 因为$n \leq 20$，范围 1 到$n$完全在限制范围之内$10^9$，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # generate perfect roots 1, 2, ..., n
    result = [str(i) for i in range(1, n + 1)]
    print(" ".join(result))
```该解决方案读取测试用例的数量并按顺序处理每个测试用例。 对于每个$n$，它构造一个从 1 到$n$。 将整数转换为字符串允许使用`" ".join()`产生所需的空格分隔的输出。 这种方法可以避免差一错误并确保所有数字都是不同的。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()

    for _ in range(t):
        n = int(input())
        result = [str(i) for i in range(1, n + 1)]

 ## 边缘情况

 当$n = 1$，算法产生`[1]`这是有效的。 为了$n = 20$，输出`[1, 2, ..., 20]`仍保持在$10^9$限制，确认没有发生溢出。 如果连续的整数被替换为不连续但仍然不同的值，则解决方案将仍然有效，但顺序选择可确保简单性和正确性，而不会出现重复的风险。
