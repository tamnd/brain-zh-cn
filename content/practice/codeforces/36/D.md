 ## 解决方案
 ## 问题理解

 我们被要求分析一个两人游戏$n \times m$长方形板。 玩家从左上角开始轮流移动一个棋子。 在每一回合中，玩家可以将棋子向右移动一个格、向下一个格或对角线移动一个格$k$单元格右下。 无法做出合法动作的玩家就输了。 目标是针对多个棋盘预测第一个玩家是否有获胜策略。 

输入给出$t$测试用例和单个整数$k$。 每个测试用例都提供尺寸$n$和$m$。 输出是一个序列$t$符号，如果第一个玩家可以强制获胜，则为“+”，否则为“-”。 

限制条件很高：$n$和$m$可以达到$10^9$， 和$k$最多$10^9$。 这排除了任何在板单元上迭代或在所有位置上使用标准动态编程的解决方案。 暴力模拟最多需要$10^{18}$的操作，这是不可行的。 我们需要一个可以运行的解决方案$O(1)$每个测试用例或值中的对数。 

当电路板相对于电路板非常小时，就会出现不明显的边缘情况。$k$。 例如，一个$1 \times 1$棋盘没有任何动作； 第一个玩家输了。 一个$1 \times 2$棋盘只允许一次向右移动，因此第一个玩家获胜。 板子在哪里$n$或者$m$正是$k+1$很棘手，因为对角线跳跃可能会落在棋盘之外。 粗心的基于模的方法可能无法检测到这些边界位置。 

## 方法

 一种自然的暴力方法是使用标准组合博弈论为每个单元分配一个游戏状态：如果至少一个可到达的单元正在失败，则该单元获胜，否则它就失败。 对于每个细胞$(i,j)$，我们将检查$(i+1,j)$,$(i,j+1)$， 和$(i+k,j+k)$。 这在原则上是正确的，但对于大的情况来说是不可行的$n$和$m$因为它需要填写一张尺寸表$n \times m$。 

关键的洞察力来自于观察亏损头寸的模式。 如果我们忽略对角线移动，游戏就会简化为矩形上的标准 Wythoff 类游戏，其中失败的位置恰好是其中的单元格$(i+j) \mod (k+1) = 0$。 对角线移动将棋盘分成不同大小的块$k+1$。 左上角的任何单元格$k+1$块（即$(i,j)$这样$\lfloor i/(k+1) \rfloor = \lfloor j/(k+1) \rfloor$）正在失去。 第一个玩家只有能够将棋子强行放入对手处于失败位置的方块中才能获胜。 

观察到丢失的细胞会周期性重复$k+1$模式允许我们将问题简化为简单的算术：对于每个板，计算$(n \mod (k+1), m \mod (k+1))$。 如果两者相等，则第一个玩家处于失败的格子中； 否则，第一个玩家可以移动到这个位置并获胜。

 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n*m) | 太慢了 |
 | 最优（模模式）| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取电路板尺寸$n$和$m$。 
2. 计算$n \mod (k+1)$和$m \mod (k+1)$。 余数确定单元格在其内部的位置$k+1$堵塞。 
3. 比较余数。 如果它们相等，则第一个玩家的单元格失败，输出“-”。 
4. 否则，输出“+”，表示第一个玩家可以移动到对手失败的位置。 

工作原理：模运算将棋盘缩小为重复的大小块$k+1$。 在每个块内，获胜和失败单元格的模式是不变的：只有沿块主对角线的位置正在失败。 这保证了任何的正确性$n$和$m$无需模拟所有动作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t, k = map(int, input().split())

for _ in range(t):
    n, m = map(int, input().split())
    if n % (k + 1) == m % (k + 1):
        print('-', end='\n')
    else:
        print('+', end='\n')
```代码首先读取$t$和$k$。 每块板都是独立加工的。 使用模运算，我们检查位置是否落在失败的对角线上。 印刷用途`end='\n'`确保每个输出都在自己的行上，避免细微的逐一格式错误。 这个处理非常大$n$和$m$高效，因为取模和比较都是 O(1)。

 ## 边缘情况

 对于最小的电路板$1 \times 1$与任何$k$,$n \mod (k+1) = m \mod (k+1) = 1$，因此算法输出“-”，正确指示第一个玩家没有移动。 

对于一块板子$n = 2$,$m = 3$和$k = 2$, 模计算结果$2 \mod 3 = 2$和$3 \mod 3 = 0$。 由于值不同，第一个玩家获胜。 不能使用对角线跳跃，因为它会超出电路板，但模逻辑会隐式处理此问题。 

对于最大尺寸的板，该算法避免了任何数组分配或迭代，只需减少模数$k+1$。 这证实了该方法可以扩展到$n, m \sim 10^9$。
