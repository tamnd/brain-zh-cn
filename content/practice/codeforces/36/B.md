 ## 解决方案
 ## 问题理解

 我们从一个`n × n`由黑色单元组成的图案（`*`）和白细胞（`.`）。 该模式就像一个模板。 

分形是递归构建的。 在第一层，整个画布分为`n × n`块，并且模板中对应于黑色单元格的每个块都变为全黑。 白色模板单元目前尚未决定。 

在下一个级别，每个仍然白色的块再次分为`n × n`较小的块，并且在其内部应用相同的模板。 黑色细胞永远停止扩张，而白色细胞则继续递归。 

准确执行此过程后`k`有时，我们必须打印最终的图片。 它的大小是`n^k × n^k`。 

数值上的限制非常小，但最终输出本身可能会变得很大。 自从`n ≤ 3`和`k ≤ 5`，最大可能的网格有大小`3^5 = 243`，因此输出最多包含大约六万个单元。 这意味着即使算法多次接触每个最终单元也是完全安全的。 

真正的挑战是理解递归如何确定特定单元格最终是黑色还是白色。 

一个常见的错误是认为每个级别都会覆盖以前的颜色。 这个过程不是这样的。 一旦某个区域变黑，递归就会永久停止。 

考虑这个输入：```
2 2
*.
..
```在第一级，左上象限变成全黑。 里面没有任何东西被再次细分。 粗心的实现可能会继续递归到该象限，并错误地在应保持全黑的区域内创建白色单元格。 

当模板仅包含一个白色单元格时，会出现另一种微妙的情况。```
2 3
**
*.
```只有右下角的分支继续细分。 所有其他区域立即变黑。 如果实现每一步都盲目地扩展所有单元，则会浪费工作，并且可能会意外覆盖固定的黑色区域。 

最小可能的情况也值得检查：```
2 1
..
.*
```这里的答案正是原始模板。 不会发生递归扩展，因为我们只执行一级。 

## 方法

 最直接的模拟从字面上反映了该陈述。 

我们从一个白色方块开始。 在每一步中，当前的每个白色方块都会被替换为`n × n`模板的副本。 黑色方块永远保持纯黑色。 

实现这一点的一种方法是递归细分。 每个区域要么立即变成全黑，要么再次细分。 由于最终图像最多包含`243 × 243`细胞，这种方法已经足够快了。 

问题是显式管理递归区域变得很尴尬。 我们需要坐标、大小、停止条件以及对已经黑色区域的仔细处理。 

关键的观察结果是每个最终细胞都可以独立分析。 

取一个细胞`(x, y)`在最后的网格中。 在每个递归级别，模板都会决定该位置是属于黑色子单元还是白色子单元。 每个级别的坐标都是简单的数字`x`和`y`在基地`n`。 

假设我们在某种程度上检查：```
template[x % n][y % n]
```如果这个位置是黑色的，那么整个祖先区域在该递归深度处都变成黑色，所以最终的单元格也必须是黑色的。 我们可以立即停止。 

如果是白色，则继续向上递归：```
x //= n
y //= n
```我们向所有人重复这一点`k`水平。 如果没有关卡落在黑色模板单元格上，则最终单元格保持白色。 

这将问题从递归区域构造转变为简单的每单元数字检查问题。 

强力递归构造之所以有效，是因为输出大小很小，但基于坐标的解释更清晰且更容易推理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力递归构造 | O(n^(2k) * k) | O(n^(2k) * k) | O(n^(2k)) | O(n^(2k)) | 已接受 |
 | 最佳坐标检测| O(n^(2k) * k) | O(n^(2k) * k) | O(1) 额外 | 已接受 |

 渐近复杂度看起来是一样的，因为输出本身已经有`n^(2k)`细胞。 这种改进来自于简单性和较低的常数因子。 

## 算法演练

 1.读取模板网格并计算最终尺寸`size = n^k`。 
2. 迭代每个最终单元格`(i, j)`在`size × size`输出网格。 
3. 对于当前单元格，将其坐标复制到临时变量中：```
x = i
y = j
```4. 准确重复`k`次。 

在每个步骤中，检查：```
template[x % n][y % n]
```这些余数告诉我们哪个模板单元控制当前的递归级别。 
5. 如果该模板单元格是黑色的（`*`），立即将最后一个单元格标记为黑色并停止检查更深层次。 

这是有效的，因为黑色区域永远不会进一步细分。 
6. 否则划分坐标：```
x //= n
y //= n
```这将移动到父递归级别。 
7.如果全部`k`水平保持白色，最终的单元格是白色的。 
8. 打印构建的行。 

### 为什么它有效

 最终图像中的每个坐标对应于通过递归细分树的路径。 

最不重要的碱基 -`n`数字确定最深的细分级别，接下来的数字确定父级别，依此类推。 

如果该路径的任何级别落在黑色模板位置上，则单元格将变为黑色。 一旦发生这种情况，递归就会停止，整个后代区域永远保持黑色。 

如果每个级别都落在白色模板单元上，则递归将在所有级别中幸存`k`步，单元格保持白色。 

该算法精确检查这些条件，因此每个输出单元格都会收到正确的颜色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
pattern = [input().strip() for _ in range(n)]

size = n ** k
answer = []

for i in range(size):
    row = []

    for j in range(size):
        x = i
        y = j
        black = False

        for _ in range(k):
            if pattern[x % n][y % n] == '*':
                black = True
                break

            x //= n
            y //= n

        row.append('*' if black else '.')

    answer.append(''.join(row))

sys.stdout.write('\n'.join(answer))
```外部两个循环生成最终图像中的每个位置。 

对于每个单元格，变量`x`和`y`使用整数除法重复减少。 这有效地向上遍历递归级别。 

表达式：```
pattern[x % n][y % n]
```提取当前基数`n`数字对。 这些数字标识哪个模板块控制当前级别。 

早期的`break`很重要。 一旦出现黑色模板单元，更深的层次就不再重要，因为递归会永久停止在那里。 

一个微妙的实现细节是操作的顺序。 除以之前我们必须检查当前的余数`n`。 反转顺序将跳过最深的递归级别并产生移位的模式。 

另一个细节是精确迭代`k`次。 即使`x`和`y`提前变为零，更高的递归级别仍然对应于模板位置`(0, 0)`。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^(2k) * k) | O(n^(2k) * k) | 我们检查每个输出单元并最多检查`k`递归级别 |
 | 空间| O(n^(2k)) | O(n^(2k)) | 输出网格本身主导内存使用 |

 最大的网格包含`243 × 243 = 59049`细胞。 对于每个单元格，我们最多执行五次检查。 这完全在限度之内。

 ## 边缘情况

 考虑递归仅通过一条路径生存的情况：```
2 3
**
*.
```在每个级别，三个象限立即变成永久黑色。 只有右下象限继续细分。 

取细胞`(7,7)`。 

在每个级别：```
(7 % 2, 7 % 2) = (1,1) -> white
(3 % 2, 3 % 2) = (1,1) -> white
(1 % 2, 1 % 2) = (1,1) -> white
```没有黑色电平出现，因此单元保持白色。 

现在采取`(6,7)`：```
(0,1) -> black
```该算法立即停止并将单元格标记为黑色。 

这证实了单一黑人祖先统治所有更深层次的规则。 

现在考虑最小递归深度：```
2 1
..
.*
```该算法精确地检查每个单元格的一个级别。 

为了`(1,1)`：```
(1 % 2, 1 % 2) = (1,1) -> black
```为了`(0,1)`：```
(0,1) -> white
```输出与模板完全匹配，确认实现处理`k = 1`正确，无需额外细分。 

最后，考虑一个全白模板：```
2 2
..
..
```每个级别检查总是落在白色模板单元格上。 由于没有递归级别产生黑色，因此整个最终图像保持白色。 

这捕获了意外将单元格初始化为黑色或无法在迭代之间重置状态的实现。
