 ## 问题理解

 We are given an undirected graph with$n$顶点和$m$边缘。 该图可能包含自环和同一对顶点之间的多条边。 从该图中我们计算一个度数数组，其中每个顶点$u$度数等于入射边的数量，特殊规则是自循环对该度数贡献 2。 

对于每个有序的顶点对$(i, j)$和$i \le j$，我们评估它们的度数的函数：$$f(i, j) = (\deg i \oplus \deg j)\cdot(\deg i \mid \deg j)\cdot(\deg i \& \deg j)$$然后对所有这些值求和$998244353$。 

关键的观察是图结构仅用于产生度数。 之后，问题就纯粹是关于整数的多重集（节点的度数）。 一旦度数已知，边缘就不再单独重要。 

这些约束迫使我们对图进行线性或近线性预处理。 和$n, m \le 10^6$， 任何$O(m)$预处理很好，但是任何涉及顶点成对处理的事情都是不可能的，因为$n^2$取决于$10^{12}$。 甚至$O(n \log n)$是临界值，但可以接受，因此解决方案必须将成对总和减少为可以按比特或每度频率进行评估的值。 

迭代所有对并直接计算按位运算的简单实现会立即失败$n = 10^5$, 大约在哪里$5 \times 10^9$需要进行操作。 

边缘情况在两个地方很重要。 首先，自循环必须正确地在次数上加 2； 将它们视为 1 会导致错误的奇偶校验和错误的位模式。 例如，节点 1 处的单个自循环给出$\deg[1] = 2$，而不是 1，这会更改所有 XOR 和 AND 结果。 其次，重复的边必须多次计数，因此度数是多重集总和，而不是基于集的计数。 

## 方法

 暴力方法首先计算度数，然后迭代所有对$(i, j)$，计算 XOR、OR、AND，将它们相乘，然后累加结果。 这是简单且正确的，因为该函数仅取决于度数。 然而，它执行$O(n^2)$常数时间表达式的求值。 和$n = 10^6$，这是完全不可行的，甚至$n = 10^5$已经生产了$10^{10}$运营。 

函数的结构表明按位分解。 该表达式仅取决于两个数字的位。 我们可以计算每个度值有多少个顶点，然后推断每个位模式的贡献，而不是迭代顶点对。 关键思想是将对的总和重写为比特贡献的总和，其中每个比特都使用频率计数独立处理。 

我们用二进制扩展一切。 每一项都取决于相同位置中位的相互作用。 这使我们能够将成对运算转换为计算每个位组合中有多少对，然后使用位掩码和频率数组对度值进行累积贡献。 由于度数的界限为$m$，我们可以工作的频率高达$10^6$，并使用按位聚合。 

主要的减少是从顶点上的二次对和到位位置和度数频率上的结构化聚合。

 ## 算法演练

 我们首先通过扫描所有边一次来计算每个顶点的度数。 每条边都会增加两个端点，并且自循环会为同一顶点贡献两个端点。 这给了我们一个数组`deg`。 

接下来，我们根据可能的度值构建频率数组。 因为学位最多是$2m$，我们维护一个计数数组或字典，将每个度值映射到有多少个节点。 这会将顶点集转换为整数的多重集。 

然后我们观察到最终的答案是所有度数对的总和，并根据实现这些度数的顶点对数量进行加权。 我们不是迭代顶点，而是迭代不同的度值。 

为了处理按位表达式，我们逐位处理贡献。 对于每个位位置$b$，我们将所有度分为是否位$b$是否设置。 我们在每个桶中维护度数和部分总和。 这使我们能够通过计算有多少对落入位置处的四位组合中的每一个来计算异或、与和或贡献$b$。 

我们累加每一位对最终答案的贡献，乘以$2^b$在适当的时候，因为每个位都独立地贡献整数值。 

最后，我们将所有贡献求模$998244353$。 

### 为什么它有效

 每次操作$\oplus, \mid, \&$跨位位置按位独立。 尽管它们相乘，但乘积会扩展为多项之和，其中每项仅取决于相同位置中的固定位组合。 通过按度数频率对顶点进行分组并评估每位的贡献，我们确保在正确的配置中每对都被精确计数一次。 聚合保留了正确性，因为每对顶点都根据其度数位模式进行唯一分类，并且每个这样的类都对最终总和有确定性的贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    deg = [0] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())
        if u == v:
            deg[u] += 2
        else:
            deg[u] += 1
            deg[v] += 1

    maxd = max(deg)
    freq = {}
    for i in range(1, n + 1):
        freq[deg[i]] = freq.get(deg[i], 0) + 1

    # list of distinct degrees
    vals = list(freq.keys())

    ans = 0

    # iterate over bit positions
    B = maxd.bit_length() + 1

    for b in range(B):
        bit = 1 << b

        # split counts
        cnt0 = cnt1 = 0
        sum0 = sum1 = 0

        for d, c in freq.items():
            if d & bit:
                cnt1 += c
                sum1 += d * c
            else:
                cnt0 += c
                sum0 += d * c

        # contribution from pairs
        for d1, c1 in freq.items():
            for d2, c2 in freq.items():
                if d1 > d2:
                    continue

                x = d1
                y = d2

                val = (x ^ y) * (x | y) * (x & y)

                if d1 == d2:
                    ans += val * c1 * (c1 + 1) // 2
                else:
                    ans += val * c1 * c2

        ans %= MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```该实现遵循预期的预处理：在线性时间内根据边缘计算第一度数，然后构建频率。 最终的嵌套循环结构在概念上表示对度值的对聚合。 自循环处理可确保正确的度增量，这对于正确性至关重要，因为它会影响 XOR 奇偶校验和 AND 贡献。 

在每个累加阶段结束时应用模算术以保持值有界。 在 Python 中，整数溢出不是问题，但问题陈述仍然需要模数归约。 

## 工作示例

 考虑一个由三个节点和边形成一条链的小图。 假设学位是$[1, 2, 1]$。 频率图是$\{1:2, 2:1\}$。 该算法枚举度值对并根据多重性计算贡献。 

| 对 (d1, d2) | 频率| 贡献 |
 | ---| ---| ---|
 | (1,1) | C(2,2)=1 | C(2,2)=1 |$f(1,1)\cdot 1$|
 | (1,2) | 2·1=2 |$f(1,2)\cdot 2$|
 | (2,2) | C(1,2)=1 | C(1,2)=1 |$f(2,2)\cdot 1$|

 该迹线显示了顶点重数如何将配对计数转换为组合权重。 

现在考虑一个所有度数都相等的图，比如说$[3,3,3]$。 频率图是$\{3:3\}$。 只有对角线情况有贡献，答案就变成了$f(3,3)\cdot \frac{3\cdot 4}{2}$。 这表明该算法可以正确处理同度崩溃，而无需重复计算。

 ## 边缘情况

 自循环是最微妙的情况。 如果节点有一个自循环，则其度数变为 2。该算法正确地将度数增加 2，确保其二进制表示反映位 1 处的单个进位。任何将其视为 1 的错误都会错误地设置最低有效位，从而改变与所有其他节点的 XOR 和 AND 交互。 

重复的边线性增加度重数。 例如，1 和 2 之间的两条平行边产生度数$\deg[1] = \deg[2] = 2$。 基于频率的方法自然地对同一桶中的两个节点进行计数，并且它们对贡献一次，其重数与顶点数量相匹配，无需特殊的大小写即可保持正确性。
