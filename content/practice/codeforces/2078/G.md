 ## 解决方案
 ## 问题理解

 我们得到了一个代表纸条暗度级别的整数数组，我们有一个特殊的操作：我们可以将纸条折叠任意多次，在一个位置滴上黑色染料，然后展开。 染料沿着其穿过褶皱层的路径增加黑暗度。 功能$f(b)$对于一个序列$b$计算精确达到黑暗级别所需的此类操作的最少次数$b$。 

问题要求我们取一个数组$a$和总和$f$的所有连续子数组$a$。 这相当于询问：对于每个间隔$[l, r]$在$a$，我们需要多少次操作才能实现黑暗模式$a_l, \dots, a_r$？ 

限制很严格。 和$n$最多$2 \cdot 10^5$和多个测试用例，任何计算方法$f(b)$为所有人从头开始$\mathcal{O}(n^2)$子数组是不可行的。 我们需要一个线性或近线性的解$n$每个测试用例。 一个简单的算法需要检查每个子阵列，并为每个子阵列模拟折叠和染料滴，这很容易超过$10^{10}$运营。 

需要注意的边缘情况包括所有元素都相等的子数组、长度为一的子数组以及值在高低之间交替的情况。 例如，单元素子数组总是具有$f(b) = b_1$如果我们可以去掉染料$b_1$次。 具有重复峰的阵列可以通过对称折叠而不是独立处理每个单元来优化。 

## 方法

 蛮力方法计算$f(b)$独立地为每个子数组。 对于长度为的子数组$m$，可以递归地找到区间中的最小值，通过从所有元素中减去最小值来缩小区间，然后求和$1 + f(\text{left}) + f(\text{right})$。 这是有效的，因为每个染料滴都可以在折叠后应用以一次覆盖多个细胞。 虽然正确，但计算得出$\mathcal{O}(n^2)$间隔太慢，特别是因为计算$f(b)$本身就是$\mathcal{O}(m)$。 

关键的见解是该操作的行为类似于分段贪婪归约。 任何间隔中的最小值定义了“基础染料滴”，我们可以将其应用于整个间隔，同时减少所有值。 然后我们可以对值超过该最小值的部分进行递归求解。 这自然会导致分而治之的方法。 由于重复是单调的并且基础滴是可加的，因此我们可以使用堆栈来计算单次从左到右扫描中所有子阵列的贡献，以跟踪新染料滴开始的高度。 本质上，我们维护以每个位置结束的子数组的操作总数。 

我们可以将具有相同“当前最小值减去基数”的连续段压缩为单个条目，从而减少冗余计算。 这减少了总时间$O(n^3)$或者$O(n^2)$粗略地$O(n)$通过利用单调性和增量聚合来每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了|
 | 使用堆栈进行分而治之 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个变量来累加当前测试用例的总和。 
2. 从左到右迭代数组。 对于每个位置，维护一个堆栈，其中每个元素都是一对`(height, count)`，表示具有统一最小高度的线段。 
3. 对于当前元素，减去前一个基数以计算其超出最后一个最小值的部分。 从堆栈中弹出，直到顶部的高度小于当前多余的高度。 每次弹出都代表完成一个部分并将其贡献添加到总数中。 
4. 如果当前超出的值大于零，则将其与表示其启动的子数组数量的计数一起推入堆栈。 使用计数和高度更新累积和。 
5. 处理完所有元素后，添加堆栈中任何剩余段的贡献。 
6. 对每个测试用例重复此操作并输出模数之和$998\,244\,353$。 

不变的是，堆栈始终维护高度递减的段，每次弹出一个段时，我们都正确地计算了以当前位置结束并受该段高度限制的所有子数组。 每个子数组的$f(b)$因此，作为在每个段级别应用的基本减少的总和，仅计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

for _ in range(int(input())):
    n = int(input())
    a = list(map(int, input().split()))
    stack = []
    total = 0
    for val in a:
        count = 1
        while stack and stack[-1][0] >= val:
            h, c = stack.pop()
            total -= h * c
            count += c
        stack.append((val, count))
        total += val * count
    print(total % MOD)
```我们使用以下方法有效地读取输入`sys.stdin.readline`。 对于每个测试用例，堆栈跟踪递减的高度以及从每个高度开始的子数组的计数。 当新元素到达时，我们弹出所有大于或等于它的高度，并相应地调整总和。 然后我们将当前值与更新后的计数一起推送。 总和累加以当前元素结尾的所有子数组的贡献。 模运算可确保结果符合要求的限制。 

## 工作示例
