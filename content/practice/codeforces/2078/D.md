 ## 解决方案
 ## 问题理解

 我们有两条车道。 每条车道一开始只有一个人。 

该级别包括`n`回合。 每轮都有一个左门和一个右门。 登机口要么增加固定数量的人员，要么增加当前通道中的人员数量。 

关键的细节是，大门不会直接改变车道人口。 相反，每个大门都会产生一定数量的新人。 

如果有一个门`+ a`，它准确地创建了`a`新人。 

如果有一个门`x a`，并且该车道当前包含`k`人，它创造`(a - 1) * k`新人。 

当该轮的两个门都产生了新的人后，所有新创建的人都会聚集在一起。 我们可以按照我们喜欢的方式将这些新人分配在两条车道之间。 现有人员无法移动，只有新生成的人员可以分配。 

任务是在所有回合后最大化两条车道上的人数。 

轮数最多只有30轮，数量很少。 挑战不在于规模大小`n`，但是在车道之间分配新创建的人员的可能方法有很多。 对所有分配的直接搜索将导致组合爆炸。 

一个微妙的点是，乘法门仅取决于回合开始前已经出现在自己车道上的人数。 同一轮中产生的人无法增加倍增效果。 任何以错误顺序处理分配和乘法的解决方案都将导致计数过多。 

考虑：```
1
1
x 3 x 3
```最初，两条车道均载有一个人。 

两个门生成`2 + 2 = 4`新人。 我们可以随意分配这四个人，但最终的总数始终是`2 + 4 = 6`。 

粗心的做法可能会认为将生成的人放到一条车道上可以立即帮助同一轮中的其他乘法，产生更大的价值。 这是不允许的。 

另一个容易犯的错误是假设平衡车道总是最佳的。 

考虑：```
1
2
+ 100 + 0
x 3 + 0
```所有生成的 100 个人都应放置在左侧车道中，因为该车道稍后会成倍增加。 平均分配它们会失去价值。 未来几轮决定当前收益应该投资在哪里。 

核心困难是考虑到所有未来的乘法，决定每轮新创建的人应该去哪里。 

## 方法

 暴力视图对于理解结构很有用。 

假设我们知道当前的人口`(l, r)`。 一轮产生一些数字`g`新人。 我们可以选择任何分割：```
x people to the left
g - x people to the right
```对于每个整数`0 ≤ x ≤ g`。 

递归地探索所有此类选择是正确的，因为它会检查每种可能的分配策略。 问题是`g`多次相乘后会变得巨大。 即使我们以某种方式限制了每轮的选择数量，分支因子仍然会呈指数增长`n`。 

关键的观察结果是游戏是完全线性的。 

想象一下我们站在某个回合之前`i`。 假设从该点开始可实现的最大最终答案可以写为```
A * l + B * r + C
```在哪里`l`和`r`是当前车道人口。 

在游戏的最后，这显然是正确的：```
final = l + r
```所以最初```
A = 1
B = 1
C = 0
```现在考虑前一轮。 

让`g`是该轮新创建人员的总数。 如果我们发送`x`他们中的一些人到了左边的车道，未来的价值变成```
A(l + x) + B(r + g - x) + C
```这简化为```
Al + Br + C + Bg + (A - B)x
```唯一的变量是`x`。 

如果`A > B`，每多一个人在左车道上都更有价值，所以所有新生成的人都应该向左走。 

如果`B > A`，所有新生成的人都应该走右边。 

如果它们相等，则任何分割都是最佳的。 

这就是突破。 我们永远不需要考虑部分分布。 每轮生成的人员都会全部投入到未来系数较大的车道上。 

一旦知道这一点，我们就可以向后处理并更新系数`(A, B, C)`。 

由于乘法门贡献与当前通道数量成比例的值，而加法门贡献一个常数，因此在整个向后扫描过程中保持线性形式。

 ## 算法演练

 1. 定义轮数后缀的价值函数为：```
F(l, r) = A * l + B * r + C
```在哪里`(A, B, C)`描述最优的未来收益。 
2、从上一轮结束后的状态开始。 

那时：```
F(l, r) = l + r
```所以初始化：```
A = 1
B = 1
C = 0
```3. 从右向左处理回合。 
4.设：```
m = max(A, B)
```任何新生成的人都应该完全分配到具有系数的车道`m`，因为这会产生最大的未来贡献。 
5. 将每个门表示为线性贡献。 

对于一个门`+ a`：```
gain = a
```对应于：```
0 * lane + a
```对于一个门`x a`：```
gain = (a - 1) * lane
```对应于：```
(a - 1) * lane + 0
```6.让左门做出贡献```
cL * l + dL
```右门贡献```
cR * r + dR
```总共产生的人数为```
g = cL * l + cR * r + dL + dR
```7. 因为每一个生成的人都是有价值的`m`将来添加`m * g`到当前值函数。 

这会产生：```
A' = A + m * cL
B' = B + m * cR
C' = C + m * (dL + dR)
```8. 更换`(A, B, C)`经过`(A', B', C')`并继续。 
9. 处理完所有轮次后，初始状态为`(1, 1)`。 

答案是：```
A + B + C
```### 为什么它有效

 不变的是，处理完一轮后缀后，从该点开始的最佳最终答案总是可以表示为线性函数```
A * l + B * r + C.
```基本情况是正确的，因为最终分数很简单`l + r`。 

假设回合中不变量成立`i + 1`。 回合期间`i`，唯一的决定就是如何分配新产生的人。 由于未来价值是线性的，因此每个额外的人都会做出贡献`A`或者`B`取决于接收它的车道。 将一个人送到系数较大的车道总是至少与任何其他选择一样好。 因此每一个生成的人都有价值`max(A, B)`。 

将此值添加到当前线性函数会产生另一个线性函数，从而保留不变量。 通过归纳，该不变量适用于每一轮，包括游戏开始。 结果值在`(1, 1)`是最优答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        gates = []

        for _ in range(n):
            op1, a1, op2, a2 = input().split()
            gates.append((op1, int(a1), op2, int(a2)))

        A = 1
        B = 1
        C = 0

        for op1, a1, op2, a2 in reversed(gates):
            m = max(A, B)

            if op1 == '+':
                cL, dL = 0, a1
            else:
                cL, dL = a1 - 1, 0

            if op2 == '+':
                cR, dR = 0, a2
            else:
                cR, dR = a2 - 1, 0

            A = A + m * cL
            B = B + m * cR
            C = C + m * (dL + dR)

        print(A + B + C)

solve()
```变量`A`,`B`， 和`C`存储已处理后缀的最优值函数的系数。 

对于每一轮我们首先计算`m = max(A, B)`。 这代表了一个新产生的人的未来价值，因为所有产生的人都应该投资于更有利可图的领域。 

每个门都转换成以下形式：```
c * lane + d
```这使得更新代数变得简单。 

更新必须使用旧值`m`。 重新计算`m`更新后`A`或者`B`是不正确的，因为分配决策属于当前一轮，而不是未来一轮。 

Python 的整数会自动增长到任意大小，这是必要的，因为重复的乘法可能会使结果远大于 64 位限制。

 ## 边缘情况

 考虑尽可能最小的级别：```
1
1
+ 1 + 1
```向后初始化给出：```
A = 1
B = 1
C = 0
```本轮贡献了两个不变的人。 自从`m = 1`：```
C = 2
```答案变成：```
1 + 1 + 2 = 4
```这与直接模拟相匹配。 

现在考虑一个纯乘法轮：```
1
1
x 3 x 3
```两个门生成：```
2 * l + 2 * r
```和`A = B = 1`，我们有`m = 1`， 所以：```
A = 3
B = 3
C = 0
```答案是：```
3 + 3 = 6
```这证实了新产生的人不允许影响同一轮内的乘法。 

最后，考虑一种情况，其中一条车道变得更有价值：```
1
2
+ 100 + 0
x 3 + 0
```后向处理产量：```
After second round: A = 3, B = 1
```自从`A > B`，第一轮产生的每个人都应该被放置到左车道。 该算法通过以下方式自动捕获这一点```
m = max(A, B) = 3.
```总是平衡车道的策略会错过这个机会并产生较小的答案。 基于系数的决策正确地识别了未来乘法在哪些方面使投资最有利可图。
