 ## 解决方案
 ## 问题理解

 我们得到一个偶数长度的数组，代表系统的内部变量。 每个变量都有一个初始正整数值。 目标是使用两种类型的操作将每个元素更改为其否定：一种可以将后面的元素的值添加到前面的元素，或者从后面的元素中减去前面的元素。 这些操作必须遵守顺序约束，这意味着第一个索引严格小于第二个索引。 每次操作必须保持以下元素的绝对值$10^{18}$，并且操作总数不得超过 5000。对于每个测试用例，我们需要提供将数组转换为其否定的有效操作序列。 

约束表明数组的长度最多可达 1000 个元素，并且我们有多个测试用例。 由于最大操作数为 5000，因此如果导致超出此限制的二次爆炸，我们无法承受天真地任意操纵每一对的解决方案。 我们还需要避免整数溢出； 然而，操作是线性的，并且从值开始直到$10^9$，所以我们在到达之前有一个安全的缓冲区$10^{18}$。 

当元素已经相等或者当数字对以可能产生大的中间值的方式交互时，如果我们不注意运算顺序，就会出现微妙的边缘情况。 例如，一个简单的顺序应用程序可能会创建超过$10^{18}$如果我们重复添加大量数字。 此外，由于元素数量是偶数，因此仔细配对元素对于系统方法至关重要。 

## 方法

 暴力方法会尝试通过对每个其他元素重复应用操作来单独翻转每个元素。 人们可以想象加或减直到符号翻转。 虽然这在原则上是可行的，但它很快就变得不切实际，因为单个元素可能需要数百次操作，并且与所有其他元素交互会导致$O(n^2)$步骤，对于大型数组可能超过 5000 次操作。 

关键的见解是，这些操作类似于线性系统操作，其中每一对都可以独立转换。 通过按顺序对元素进行配对，我们可以使用每对六个操作的固定序列来系统地否定两者。 考虑一对$(x, y)$。 操作顺序为：

 1. 设置$y = y - x$2. 设置$x = x + y$3. 设置$y = y - x$4.再次按相同顺序重复以上三个步骤

 这个序列变换$(x, y)$进入$(-x, -y)$而不影响其他元素。 线性组合属性确保每个步骤保持中间值有界（大致乘以 2 或 3）并维持顺序约束$i < j$。 因为我们每对执行六次操作，并且有$n/2$对，总操作次数为$3n$，安全低于 5000$n \le 1000$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢/不安全|
 | 成对否定| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 以两步迭代数组，创建连续的对$(a_1, a_2), (a_3, a_4), \dots$。 均匀的长度确保没有剩余元素。 
2. 对于每对$(x, y)$，依次执行以下操作：设置$y = y - x$， 然后$x = x + y$， 然后$y = y - x$。 这个序列部分地走向否定。 
3. 对同一对重复以上三个操作。 经过六次手术后，$x$和$y$被否定。 
4. 以所需格式将每个运算附加到输出：类型（1 表示加法，2 表示减法），后跟元素的索引。 
5. 继续处理下一对，直到数组末尾。 
6. 输出每个测试用例的操作总数和顺序。 

其原理：每一对都独立变换，六个运算的序列在代数上保证了$(x, y)$变成$(-x, -y)$。 由于对不相互作用，因此该过程在整个阵列中是一致的。 这些操作经过仔细排序，以避免超过绝对值限制并遵守索引约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ops = []
        for i in range(0, n, 2):
            x, y = i+1, i+2  # 1-based indices
            # Sequence of six operations to negate both
            ops.append((2, x, y))
            ops.append((1, x, y))
            ops.append((2, x, y))
            ops.append((2, x, y))
            ops.append((1, x, y))
            ops.append((2, x, y))
        print(len(ops))
        for op in ops:
            print(op[0], op[1], op[2])

if __name__ == "__main__":
    solve()
```该解决方案仔细处理基于 1 的操作索引，每对执行 6 次操作，并以 2 步迭代，确保每对都独立处理。 每个操作类型都对应于问题的定义，并且该序列重复两次以实现否定。 这种模式使总操作保持线性$n$并安全地低于限制。

 ## 边缘情况

 对于最小输入 [1,1]，算法对单个对执行六次操作，得到 [-1,-1]。 对于最大 n，假设 n=1000，算法正好生成 3000 次操作，安全地低于 5000。中间值永远不会超过最大初始元素的三倍，保持在低于$10^{18}$。 具有所有相等值或具有较大变化的数组可以被正确处理，因为每一对都是独立且连续地转换的，确保没有交互导致不正确的否定。
