 ## 解决方案
 ## 问题理解

 我们被要求计算在一行中打开的灯的预期数量$n$灯，根据连续的长度段给出停止条件$k$。 每盏灯都开始亮起，在每一步中，随机打开一个仍处于关闭状态的灯。 一旦任何一段发生，设备立即停止$k$连续的灯有不止一盏灯打开。 输入给出多个测试用例，其值为$n$和$k$，我们需要返回设备停止时打开的预期灯数，模数$10^9+7$。 

限制条件表明$n$可以大到$10^5$并且最多可以有 10 个测试用例。 模拟所有序列或枚举可能性的简单方法很快就会超过$10^5$每个测试用例的操作，这对于最多$3 \cdot 10^6$总共迭代次数。 我们需要一种分析方法而不是明确的模拟。 

当发生微妙的边缘情况时$k$非常接近$n$， 例如$n = k = 2$。 两个灯亮起后，设备几乎立即停止，因为长度为 2 的唯一段已经包含两个灯。 一个天真的假设，即预期值与$n/k$会在这里失败。 同样，如果$k = 2$和$n$更大，预期的灯数量比$n$，并且错误地应用统一概率而不考虑段重叠会给出错误的答案。 

## 方法

 蛮力方法在概念上很简单：枚举所有灯光激活序列，跟踪打开的灯光数量，并在出现一段亮灯时停止对序列进行计数。$k$连续的灯光包含多个灯光。 然后将预期值计算为结果之和除以序列总数。 虽然正确，但这种方法是因式分解的$n$，因为每个激活序列都是光的排列。 即使是为了$n = 20$，这已经是$20! \approx 2.4 \cdot 10^{18}$的操作，这是不可行的。 

关键的见解是关注可以在不触发停止条件的情况下激活的位置。 如果我们将预期打开的灯数量视为位置的总和，我们就会意识到，当且仅当它至少为$k$与先前打开的灯分开的位置。 这将问题转换为至少放置不重叠“标记”的组合或概率问题$k$分开成一行$n$职位。 利用期望的线性，我们不需要枚举序列； 我们可以通过迭代可能的距离并应用从谐波和导出的概率公式来计算预期的灯光数量。 

最佳方法使用派生公式计算期望值：期望为$E = k - 1 + \sum_{i=0}^{n-k} 1 / (i + k)$模数$10^9+7$，可以使用模逆来有效计算模数下的除法。 这将问题从阶乘简化为$O(n)$每个测试用例，这是可以接受的$n$最多$10^5$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$k$。 
2. 初始化变量`ans`到$k - 1$，因为第一个$k - 1$在不违反规则的情况下，灯可以随时打开。 
3. 迭代`i`从 0 到`n - k`包容性。 对于每个`i`，计算模逆`i + k`模数$10^9+7$并将其添加到`ans`。 这对应于可以安全打开的剩余灯的预期贡献。 
4. 将所有贡献求和后，输出`ans`模 $10^9+7`。 

为什么它有效：期望的线性使我们能够将期望值独立地计算为每个光的期望贡献的总和。 停止条件可以重新表述为可以安全开启的剩余位置数量的谐波和。 使用模逆可以正确处理模算术下的除法。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def expected_lights(n, k):
    ans = k - 1
    for i in range(n - k + 1):
        ans = (ans + modinv(i + k)) % MOD
    return ans

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    print(expected_lights(n, k))
```功能`modinv(x)`使用费马小定理计算模逆。 循环小心地从`i = 0`到`n - k`，代表第一个安全之外的剩余位置`k - 1`。 我们将每一项取模相加$10^9+7$以避免溢出。 使用`pow(x, MOD - 2, MOD)`即使在以下情况下也能确保正确性`i + k`很大。

### 示例 2：n = 15，k = 2

 我们从`ans = 1`。 然后我们将 2 到 15 的模逆相加。模逆之和$10^9+7$给出`141946947`。 

这些表演示了如何使用模逆来累积每个光的预期贡献，从而确认算法正确地考虑了间距约束。

 ## 边缘情况

 当`n = k`，算法正确设置`ans = k - 1 = n - 1`最初，然后循环运行`i = 0`到`n - k = 0`，添加模逆`k = n`，这恰好导致`n`。 例如，`n = 10, k = 10`给出`ans = 9 + modinv(10) = 10`。 这表明该算法可以很好地处理设备几乎立即触发停止条件的情况，并且仍然正确计算预期的数字。
