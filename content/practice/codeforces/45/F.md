 ## 解决方案
 ## 问题理解

 我们有经典的河流穿越设置，但有一个精确的安全规则，改变了过渡的工作方式。 

最初，有`m`山羊和`m`狼在左岸。 目标是使用最多可承载的船只将所有动物移至右岸`n`动物一次。 每次穿越时，船必须始终携带至少一只动物。 

每时每刻，在动物存在的每一个地方，狼的数量都不能严格超过山羊，除非那里根本没有山羊。 这个条件分别适用于左岸、右岸，甚至渡河时的船本身。 

还有另一个微妙的细节。 当船到达岸边时，所有乘客首先同时下船。 只有在那之后，下一位乘客才能登机。 所以卸载后的中间状态也必须是安全的。 

任务是计算安全运送每个人所需的最少过境次数，或确定无法完成。 

制约因素很大。 两个都`m`和`n`可以达到`10^5`，因此对动物的所有分布进行任何状态空间搜索都是不可能的。 对状态进行简单的 BFS 大约有`(m+1)^2`状态，因为状态取决于一方有多少山羊和狼。 和`m = 10^5`，这变成了大约`10^10`甚至在考虑转换之前就进行状态。 甚至存储图表也是不可能的。 

该问题必须具有直接的数学特征。 我们需要一个`O(1)`或者`O(log m)`解决方案。 

一些边缘情况很容易被忽略。 

考虑：```
1 1
```这艘船只能运载一只动物。 如果我们先移动山羊，狼就会独自一人，这是安全的，但山羊无法返回，因为船必须携带动物。 如果我们先移动狼，山羊就会立即被吃掉。 正确答案是`-1`。 

另一个危险的情况是：```
2 2
```乍一看它很像经典的拼图，但容量`2`其实就够了。 存在 5 个交叉的最佳序列。 如果粗心地假设“容量小于 3 是不可能的”，那么这里就会失败。 

现在考虑：```
100000 100000
```这艘船可以承载所有人一次。 答案是`1`。 任何模拟重复传输而不是立即检测到这一点的解决方案都会带来不必要的复杂性。 

当船的容量为奇数时，就会发生最微妙的情况。 例如：```
5 3
```许多贪婪的转移策略都会失败，因为卸货后，银行中的狼暂时多于山羊。 解决方案取决于了解哪些船舶配置从根本上来说是安全且高效的。 

## 方法

 强力方法将每个有效配置建模为图形状态。 

一个状态可以用三个值来表示：左岸的山羊、左岸的狼和船边。 从一个州开始，我们尝试每一种可能的船载量，其中包含`1`和`n`动物，检查船本身是否安全，模拟穿越，并验证卸货后两岸是否安全。 

这适用于小值，因为约束是局部的并且易于验证。 然后 BFS 会自动产生最少的交叉数。 

问题在于州的数量。 每个银行可能包含来自`0`到`m`山羊和狼，所以状态计数大致为：$(m+1)^2 \cdot 2$为了`m = 10^5`，这是一个天文数字。 即使生成所有转换也是不可行的。 

关键的观察是每个安全状态都有一个刚性结构。 

在任何有山羊的银行上，狼的数量必须等于山羊的数量。 由于全球总数相等，任何不平衡都会立即造成狼数量多于山羊的局面。 

这意味着每个安全银行配置如下所示：$(k,k)$对于某些人来说`k`。 

同样的逻辑也适用于船。 如果船上载有山羊和狼，那么计数也必须相等。 否则船内的山羊会在旅途中被吃掉。 

因此，每次有用的前行旅行都会运送相同数量的山羊和狼。 

假设一次向前旅行移动`x`山羊和`x`狼。 然后：$2x \le n$因为船的容量是`n`。 

为了最大化进度，我们应该选择尽可能最大的有效值`x`：$x = \left\lfloor \frac{n}{2} \right\rfloor$在这样的旅行之后，船必须携带至少一只动物返回。 返回一只山羊和一只狼是最佳选择，因为它可以保证安全，同时最大限度地减少进度损失。 

所以每个完整的周期都会准确地获得：$x-1$目的地端配对。 

这将难题转化为简单的算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力 BFS | O(m²·过渡) | O(平方米) | 太慢了|
 | 数学贪心| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1、处理琐碎的全贴合案例。 如果船的容量至少为`2m`，我们可以在一次穿越中运输所有动物，所以答案是`1`。 
2. 计算一次安全旅行中可运输的最大山羊-狼对数量：$x = \left\lfloor \frac{n}{2} \right\rfloor$每一次前行都安全承载着`x`山羊和`x`狼。 
3.如果`x = 0`，运输是不可能的。 

这意味着`n = 1`，所以船不能同时运载一只山羊和一只狼。 任何举动都会立即造成不安全的银行或不安全的船。 
4. 观察一个完整周期的净进度。 

前方交叉口运输`x`配对到右岸。 要继续，船必须返回至少携带一对。 所以经过两次穿越后，永久增益为：$x-1$对。 
5.如果`x = 1`和`m > 1`，运输是不可能的。 

容量`2`允许一次只移动一对，但随后同一对必须返回。 净进度变为零。 
6.否则反复增益`x-1`直到剩余的对数最多为`x`。 
7. 携带所有剩余对进行最后一次向前交叉。 
8. 仔细计算交叉点。 

每个完整周期贡献两次交叉，最终传输贡献一次额外的交叉。 

### 为什么它有效

 不变的是，每个安全配置在每个被占领的位置上都有相同数量的山羊和狼。 

假设某个银行的狼数量多于山羊，但仍然有山羊。 然后山羊就会立即被吃掉。 由于山羊和狼的总数在全球范围内是相等的，任何一侧偏离平等的情况都会迫使其他地方出现相反的不平衡。 

由于这个不变量，每个有效的运输操作都必须将相同数量的山羊和狼一起移动。 最大的此类负载可以最大限度地提高每次前进行程的进度。 返回少于一对是不可能的，因为返回时船必须被占用，而返回超过一对只会减少进度。 

因此，最优策略是被迫的：总是向前传输最大可能的相等组，返回恰好一对，并重复直到最后一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    m, n = map(int, input().split())

    if n >= 2 * m:
        print(1)
        return

    x = n // 2

    if x == 0:
        print(-1)
        return

    if x == 1:
        print(-1)
        return

    full_cycles = (m - x + (x - 2)) // (x - 1)

    answer = full_cycles * 2 + 1

    print(answer)

solve()
```实现直接遵循数学推导。 

第一个条件处理船立即运载所有动物的情况。 缺少此案例会导致错误答案`m = 1`和`n = 2`，因为通用公式会错误地声称不可能。 

变量`x`代表一次安全前进行程中可运输的最大山羊-狼对数量。 由于每对占用两个船位，我们计算`n // 2`。 

什么时候`x == 0`，船的容量为`1`，这显然无法传输安全的一对。 

什么时候`x == 1`，船一次只能运载一对。 每次回程都必须带回该对，因此除非之前的任务已经解决了整个任务，否则不可能取得永久进展`n >= 2m`健康）状况。 

完整周期的数量需要仔细划分上限。 每个周期后我们永久放置`x - 1`对在右岸。 我们继续下去，直到剩余的对数最多为`x`，因为这些可以在最后的单程旅行中移动。 

从数学上来说，我们需要最小的整数`k`这样：$m - k(x-1) \le x$重新排列给出：$k \ge \frac{m-x}{x-1}$该代码实现了该值的上限。 

最后，每个周期需要两次穿越，最终运输需要一次。

 ## 边缘情况

 考虑：```
1 1
```船只能容纳一只动物。 运走山羊先让狼独自一人，但船却无法安全返回。 首先运送狼时，一只狼带着一只山羊留在原来的河岸上，这仍然是安全的，但最终山羊必须独自旅行并变得脆弱。 该算法立即检测到这一点，因为：$x = \left\lfloor \frac{1}{2} \right\rfloor = 0$并返回`-1`。 

现在考虑：```
2 2
```这里：$x = 1$一对可以前进，但同一对必须返回，这样船才能继续运行。 净转移对永远保持为零。 算法正确返回`-1`。 

最后考虑：```
3 6
```这艘船可以同时运载所有六只动物。 由于卸货同时进行，因此两家银行始终保持安全。 该算法通过以下条件捕捉到这一点：$n \ge 2m$和输出`1`。
