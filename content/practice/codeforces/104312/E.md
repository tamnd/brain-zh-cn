 ## 解决方案
 ## 问题理解

 我们得到了三面独立的墙，每面都被描述为一系列截面高度。 每个数组包含$n$整数，其中每个整数代表该墙中一段的高度。 目标不是匹配墙壁上的位置，而只是找到出现在所有三个数组中的高度值。 在所有这些共享高度中，我们必须返回最大的高度。 如果所有三堵墙都不共享高度，则答案是$-1$。 

关键细节是我们比较的是数值，而不是指数。 如果某个高度在 Wall Maria 中至少出现一次、在 Wall Rose 中至少出现一次、在 Wall Sina 中至少出现一次，则该高度有效。 

约束条件$n \le 10^5$意味着每面墙最多可以包含十万个值，并且有三个这样的数组。 跨数组的直接二次或三次比较将导致粗略的结果$10^{10}$最坏情况下的操作，远远超出了2秒的限制所能处理的。 这立即排除了三个数组的所有元素之间的成对扫描。 

值本身的边界是$10^5$，这是一个重要的结构提示。 这表明在固定域上进行频率计数或存在标记可能是可行的。 

一些边缘情况在实践中很重要。 如果所有数组中的所有值都不同，则不存在重叠，并且输出必须是$-1$。 如果所有数组都包含相同的值，则答案就是存在的最大值。 当数组中存在重复项时，会出现另一种微妙的情况； 重复不应该影响正确性，因为我们只关心存在性，而不关心频率。 

## 方法

 蛮力的想法很简单。 对于第一面墙中的每个值，我们检查它是否出现在第二面墙和第三面墙中。 这可以使用嵌套循环或线性搜索来实现。 

如果我们天真地这样做，对于每个$n$第一个数组中的元素，我们可以扫描到$n$第二个和另一个中的元素$n$在第三个。 这导致$O(n^3)$在最坏的情况下，如果使用原始循环实现，或者$O(n^2)$如果我们使用列表和线性扫描来预先检查成员资格。 甚至$O(n^2)$翻译为$10^{10}$操作，这是不可行的。 

关键的观察是我们不需要成对比较元素。 我们只需要知道每个数组中是否存在某个值即可。 这将问题转化为集合交集问题。 一旦每个数组都转换为成员结构，检查某个值是否出现在所有三个数组中就变成常数时间。 

由于值的边界为$10^5$，我们还可以使用布尔频率数组或哈希集。 在标记每面墙的存在性后，我们扫描可能的值范围并选择所有三面墙中存在的最大值。 

这将问题从重复搜索减少到对值域进行单次线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$到$O(n^3)$|$O(1)$| 太慢了|
 | 存在数组/集合 |$O(n + V)$|$O(V)$| 已接受 |

 这里$V = 10^5$，最大可能值。 

## 算法演练

 1. 创建三个布尔数组（或集合），表示每面墙中出现哪些值。 此步骤将原始列表转换为快速成员资格结构，以便我们可以在恒定时间内回答存在查询。 
2. 对于 Wall Maria 中的每个高度，将其标记为存在于第一个结构中。 重复的价值观并不重要，因为我们只关心存在。 
3. 对 Wall Rose 和 Wall Sina 重复相同的标记过程，分别填充第二个和第三个结构。 
4. 迭代所有可能的高度$1$到$10^5$，检查某个值是否被标记为存在于所有三个结构中。 这是有效的，因为所有有效高度必须位于给定的范围内。 
5. 跟踪满足所有三个数组中存在的最大值。 由于我们按升序扫描，因此只要找到有效值，我们就可以简单地覆盖答案。 
6.扫描结束后，如果没有找到值，则返回$-1$，否则返回记录的最大值。 

### 为什么它有效

 该算法依赖于这样一个事实：每面墙的成员资格是独立且无序的。 通过将每面墙转换为一组当前值，我们准确地保留了问题所需的信息，并丢弃了所有不相关的信息，例如排序和重复项。 最终扫描根据所有三堵墙中存在的正确表示来检查每个候选高度，确保每个报告的值真正出现在所有阵列中。 由于我们评估允许范围内的所有可能高度，因此不会错过任何有效答案，并且选择其中的最大值可以保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    m = list(map(int, input().split()))
    r = list(map(int, input().split()))
    s = list(map(int, input().split()))
    
    MAXV = 100000
    
    in_m = [False] * (MAXV + 1)
    in_r = [False] * (MAXV + 1)
    in_s = [False] * (MAXV + 1)
    
    for x in m:
        in_m[x] = True
    for x in r:
        in_r[x] = True
    for x in s:
        in_s[x] = True
    
    ans = -1
    for v in range(1, MAXV + 1):
        if in_m[v] and in_r[v] and in_s[v]:
            ans = v
    
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先构建三个出席表，每面墙一个。 每个表记录该墙是否存在高度。 这避免了重复扫描并确保持续时间的成员资格检查。 

最后的循环按升序扫描所有可能的高度。 每次在所有三个数组中找到高度时，它都会更新答案。 因为我们向上扫描，所以最后记录的值是最大有效高度。 

一个微妙的点是固定范围$1 \le h \le 10^5$。 这使我们能够安全地分配大小的数组$100001$不用担心动态边界。

 ## 边缘情况

 所有数组都包含不相交值的情况演示了算法对缺失的正确处理。 例如：```
Maria = [1,2], Rose = [3,4], Sina = [5,6]
```扫描过程中没有索引$v$满足所有三个布尔检查，所以`ans`遗迹$-1$，已正确返回。 

第二种情况是重复占主导地位时：```
Maria = [7,7,7], Rose = [7,7], Sina = [7]
```尽管计数不同，但存在数组仅标记存在。 在$v = 7$，所有三个标志都为 true，因此答案被正确识别为 7。
