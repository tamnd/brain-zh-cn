 ## 解决方案
 ## 问题理解

 我们收到一组短文本消息，每条消息彼此独立。 对于每条消息，我们都需要确定它是代表一场“战斗”还是只是随意的对话。 

如果一条消息包含至少三个全部为字母“a”的连续字符序列，则该消息被视为一场战斗，并且大小写无关紧要。 这意味着我们将字母的大写和小写版本视为相同，因此只要文本中至少存在三个连续的类似“a”的字母，“aaa”、“Aaa”或“aAAAa”等序列都符合资格。 

每行输入都会被单独检查，并根据是否存在这样的子串来输出固定短语。 

约束很小：每条消息的长度最多为 100 个字符，即使消息数量很大，每条消息的总工作量也是有界的。 这立即排除了任何比每个字符串线性扫描更重的东西，甚至每个字符串的二次行为也是可以接受的，但没有必要。 每条消息一次传递就足够了。 

主要的微妙之处在于在不区分大小写的情况下正确定义“连续的 a”，并确保每当出现非“a”字符时我们都能正确重置计数。 

一个常见的错误来自于仅检查精确的小写“a”而不进行标准化。 例如，“AAA”应该是一场战斗，但区分大小写的检查会错误地拒绝它。 

另一个微妙的边缘情况是忘记重置跨空格或标点符号的条纹。 例如，“aa a aaaa”在末尾包含四个连续 a 的有效运行，但如果程序员错误地错误地重置每个空格或合并不连续的段，他们可能会错误计数。 

## 方法

 暴力破解的想法很简单：对于字符串中的每个位置，尝试扩展一个窗口并检查我们是否可以找到至少三个连续字符，这些字符在规范化大小写后全部为“a”。 对于每个起始索引，向前扫描以检测运行需要 O(n)，并且对每个索引执行此操作将为每条消息提供 O(n²)。 对于最多 100 个字符，这仍然可以舒适地工作，但这是不必要的矫枉过正。 

关键的观察结果是我们不需要从每个位置重新开始扫描。 我们只关心同一字符类别的连续运行。 如果我们在从左到右扫描时保持连续“a”类型字符的运行计数，我们可以一次性决定是否有任何运行达到长度三。 这将问题转化为简单的流检查：累积条纹、中断时重置，并跟踪最大条纹长度。 

该问题的结构基本上是基于游程长度的，因此将字符串折叠成连续的段是最佳的。 每个字符只被处理一次，并且状态是恒定的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每条消息 O(n²) | O(1) | O(1) | 已接受但没有必要 |
 | 最佳| 每条消息 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将整个消息转换为小写，以便大小写差异不影响比较。 这确保了在扫描期间对“A”和“a”的统一处理，无需额外的条件逻辑。 
2. 初始化计数器`streak = 0`跟踪当前连续“a”字符的数量。 
3. 从左到右扫描字符串，一次处理一个字符。 每个角色都有助于延续或打破连胜。 
4. 如果当前字符是‘a’，则递增`streak`一个。 这扩展了当前连续的有效字符段。 
5. 如果当前字符不是‘a’，则重置`streak`为零，因为连续性要求被破坏。 
6.更新后`streak`，检查是否达到3个以上。 如果有，我们可以立即将该消息归类为战斗并提前停止扫描。 
7. 如果我们完成扫描但未达到连续 3 条，则将该消息归类为非战斗。 

提前停止是可选的，但与以下事实相符：一旦找到有效段，进一步的处理就无法改变答案。 

### 为什么它有效

 在字符串的任意位置，`streak`准确表示以该位置结尾的连续“a”字符的当前后缀的长度。 因为当出现非“a”字符时我们会立即重置它，所以它总是编码以当前索引结尾的有效连续段。 任何长度至少为 3 的有效子字符串必须以某个索引结尾，其中`streak >= 3`，因此检测这种状态既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    for _ in range(n):
        s = input().rstrip("\n").lower()
        
        streak = 0
        found = False
        
        for ch in s:
            if ch == 'a':
                streak += 1
                if streak >= 3:
                    found = True
                    break
            else:
                streak = 0
        
        if found:
            print("Love is war!")
        else:
            print("Just friends <3")

if __name__ == "__main__":
    solve()
```该解决方案读取每条消息，并使用`.lower()`，并维护一个整数计数器。 这`found`一旦发现有效的运行，标志允许提前终止。 重置`streak`任何非“a”字符都保持连续性，这是核心要求。 

一个微妙的实现细节是仅剥离换行符。 我们避免删除空格，因为空格是有意义的字符，会中断运行。 另一个重要的点是执行`.lower()`每个字符串而不是每个字符一次，这使得每个字符的循环最小且高效。

 ## 边缘情况

 一个重要的边缘情况是字符串包含混合大小写字母，仅在标准化后才形成有效的运行。 例如，输入“AaAaA”在降低后变为“aaaaa”，产生 5 的有效条纹。该算法处理此问题是因为归一化发生在扫描之前，因此条纹计数是根据统一表示计算的。 

另一种情况是有效字符由空格或标点符号分隔。 例如，“aa aaaa”应该是一场战斗，因为后面有四个“a”。 扫描期间，空间将条纹重置为零，最后一段正确重建条纹，达到 4 并触发条件。 

第三种情况是根本没有“a”的字符串，例如“hello world”。 连胜始终保持为零，并且不会发生提前终止，从而正确地产生非战斗分类。
