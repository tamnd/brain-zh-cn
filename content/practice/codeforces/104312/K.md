 ## 解决方案
 ## 问题理解

 我们有一排怪物，每个怪物都有一个正值或负值的力量值。 埼玉可以选择这些怪物的任何连续部分并击败该组。 所选分段的强度是其内部所有值的总和，任务是找到所有连续分段的最大可能分段总和。 

输入是长度最大为 100,000 的单个数组，每个值可以小至负十亿，大至十亿。 输出是一个整数，是任何连续子数组的最佳可能总和。 

对 n 的约束立即排除了任何显式尝试所有子数组的解决方案。 在最坏的情况下，所有 (i, j) 对上的双循环已经导致大约 10^10 次操作，这远远超出了一秒内可以通过的操作。 这推动我们寻求线性或近线性的解决方案。 

当所有数字均为负数时，会出现微妙的边缘情况。 例如，对于输入`[-5, -2, -8]`，正确答案是`-2`，来自选择单个元素。 将答案初始化为零或假设我们可以“跳过所有内容”的幼稚实现将错误地返回零，即使零不是有效的子数组总和，除非空子数组明确允许，而该问题不允许这样做。 

另一个边缘情况是单元素数组，其中答案必须是该元素本身，即使是否定的。 这强调正确的初始化。 

## 方法

 蛮力方法很简单：考虑每个可能的子数组，计算其总和，并跟踪最大值。 对于每个起始索引 i，我们扩展到每个 j ≥ i 并增量累加总和。 这是正确的，因为它直接评估每个有效的连续段。 然而，段的数量是 n(n+1)/2，如果我们重用前缀累积，每次总和更新是 O(1)，仍然给出 O(n^2) 总工作量。 当 n 达到 10^5 时，这变得不可行。 

关键的观察是，当从左到右扫描时，在每个位置，我们只关心扩展前一个片段是否有益，或者从当前位置重新开始是否更好。 如果运行总和变为负数，保留它只会减少任何未来扩展的贡献，因此最好从当前元素重新启动。 这将全局优化问题转化为每个索引处的局部决策，这正是允许线性扫描的原因。 

这减少了维护在每个位置结束的运行最佳前缀并跟踪这些值的全局最大值的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最优（Kadane 算法）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们从左到右处理数组，同时维护两个值：以当前位置结束的最佳子数组总和，以及迄今为止看到的最佳整体答案。 

1. 将运行总和初始化为数组的第一个元素。 这确保我们正确处理所有数字均为负数的情况，因为我们被迫至少选择一个元素。 
2. 将全局最佳答案初始化为相同的值，因为开头的最佳子数组只能是该单个元素。 
3. 从第二个元素开始迭代数组。 
4. 在每个元素 p[i] 处，决定是扩展前一个子数组还是从 i 处重新开始。 扩展意味着将 p[i] 添加到运行和中，而重新启动意味着丢弃它并将运行和设置为 p[i]。 
5. 通过将 p[i] 与 running_sum + p[i] 进行比较来做出决定。 如果之前的和为负数，则重新启动更好； 否则，延长是有益的。 
6. 更新运行总和后，如果运行总和较大，则更新全局答案。 
7. 迭代完成后，全局答案是最大子数组和。 

为什么它有效：在每个索引 i 处，该算法都会维护必须以 i 结尾的最佳可能子数组。 任何以 i 结尾的子数组要么来自扩展以 i−1 结尾的有效子数组，要么从 i 本身开始。 如果先前的贡献为负，它只能减少未来的总和，因此丢弃它不会使任何最优的未来选择变得更糟。 这种局部最优性保证了所有端点之间都遇到全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    current = arr[0]
    best = arr[0]
    
    for i in range(1, n):
        current = max(arr[i], current + arr[i])
        best = max(best, current)
    
    print(best)

if __name__ == "__main__":
    solve()
```该解决方案读取一次数组并维护两个运行变量。 关键是过渡线`current = max(arr[i], current + arr[i])`，它编码重新启动或扩展的决定。 变量`best`跟踪迄今为止看到的最佳子数组总和，无论它在哪里结束。 

初始化时必须小心。 两者都设置`current`和`best`即使所有数字都是负数，第一个元素也能确保正确性，避免意外初始化为零。

 ## 边缘情况

 对于像这样的单元素输入`[-7]`，算法初始化`current`和`best`到`-7`，所以直接输出`-7`而不进入循环。 这避免了任何可以选择空子数组的错误假设。 

对于像这样的全负数组`[-5, -2, -8, -1]`，算法在每个位置重复重新启动，因为扩展总是使总和恶化。 运行中的最佳更新`-2`在索引 1 处并且此后不再下降，从而产生正确的最小负元素作为答案。
