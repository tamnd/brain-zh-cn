 ## 解决方案
 ## 问题理解

 我们有两个普通的墙壁插座和一组电源分配器。 每个分离器都有一个插头，消耗一个可用插座和三个自己的插座，因此连接一个分离器会使空闲插座总数恰好增加两个。 分离器可以直接连接到墙壁或另一个分离器的插座，因此分离器可以形成任意的连接树。 

输入包含`n`、必须通电的笔记本电脑数量，以及`k`，已可用的分配器数量。 我们需要购买最少数量的附加分路器，以便至少`n`笔记本电脑的插座仍然可用。 

约束条件允许两者`n`和`k`一样大`10^9`。 这排除了对每台笔记本电脑或每个分离器执行一次迭代的任何模拟。 即使是线性算法，在最坏的情况下也可能需要大约 5 亿次迭代，这远远超出了一秒限制所能支持的范围。 预期的解决方案必须将问题简化为常数时间算术。 

有几种小的边界情况很容易导致差一错误。 如果`n = 1`，两个原来的墙壁插座已经足够了，所以`k = 0`答案是`0`， 不是`1`。 如果`n = 2`，两个原来的socket都可以直接使用，所以答案又是`0`。 例如，`2 0`必须产生`0`。 

当笔记本电脑的数量为奇数时，会出现另一种边界情况。 为了`n = 3`和`k = 0`，一个分路器就足够了：将其连接到一个墙上插座并使用其三个插座用于笔记本电脑，而另一个墙上插座保持不使用。 答案是`1`。 使用普通整数除法的粗心公式`(n - 2) / 2`如果不向上舍入，将错误地获得`0`。 

只有在确定实际需要的数量后，才必须减去现有的分离器。 为了`n = 6`和`k = 3`，只需要两个分离器，所以答案是`0`。 盲目计算正购买计数而不将其限制为零的公式可能会产生否定答案。 

## 方法

 直接模拟可以从两个可用插座开始，然后重复添加一个分路器。 每个新的分离器都会消耗一个现有的套接字并贡献三个新的套接字，因此空闲套接字的数量增加了两个。 我们继续直到至少有`n`空闲套接字，然后减去`k`已经拥有的分离器。 这是正确的，因为每个分离器对可用笔记本电脑连接的数量具有完全相同的影响。 

这种方法的问题在于迭代次数。 和`n = 10^9`和`k = 0`，我们需要`499,999,999`分离器。 模拟将执行大约 5 亿次迭代，这对于给定的时间限制来说太慢了。 

关键观察是使用后的空闲套接字数量`t`分离器立即可知。 我们从两个插座开始，每个分路器又增加两个，所以容量是`2 + 2t`。 

我们需要这个数量至少`n`。 求解不等式给出`2 + 2t >= n`。 

因此`t >= (n - 2) / 2`,

 自从`t`必须是整数，我们需要该值的上限。 对于正整数`n`，这个天花板有一个特别简单的形式：`ceil((n - 2) / 2) = (n - 1) // 2`。 

这也处理`n = 1`正确地，因为`(1 - 1) // 2 = 0`。 

让`required = (n - 1) // 2`是所需分离器的总数。 自从`k`其中已经可用，必须购买的数量是`required - k`，但不能为负数。 因此最终的答案是`max(0, required - k)`。 

蛮力方法和最优方法可以进行如下比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`、笔记本电脑的数量，以及`k`，已拥有的分离器数量。 只有这两个值会影响答案，因为每个分离器的行为都是相同的。 
2. 如果没有可用的分离器，请计算所需的分离器总数：`required = (n - 1) // 2`。 

这是因为最初有两个墙壁插座可用，每个分配器都会将空闲插座的数量增加两个。 
3.减去已经拥有的`k`分离器来自`required`。 如果结果为负，则将其替换为零，因为我们永远不需要购买现有的分离器。 
4. 打印结果数字。 

### 为什么它有效

 准确连接后`t`分离器，电气设置有`2 + 2t`笔记本电脑的免费插座。 无论分离器如何连接，情况都是如此，因为每个分离器仅消耗一个现有插座并创建三个新插座，从而产生 2 的净增益。 因此，一个配置可以为所有`n`笔记本电脑究竟什么时候`2 + 2t >= n`。 最小整数`t`满足这个不等式是`(n - 1) // 2`。 如果`k`最多已拥有分离器`k`不需要购买这些所需的分路器，从而`max(0, required - k)`。 由于这是总分配器的最小可能数量，并且每个分配器都贡献相同的容量增加，因此计算出的购买数量是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    required = (n - 1) // 2
    answer = max(0, required - k)

    print(answer)

if __name__ == "__main__":
    solve()
```第一行`solve`读取两个整数。 只有一个测试用例，因此不需要循环测试用例。 

表达式`(n - 1) // 2`直接计算分配器的最小总数。 使用这种形式可以避免浮点运算并处理偶数和奇数`n`正确。 例如，它给出`1`为了`n = 3`,`1`为了`n = 4`， 和`2`为了`n = 5`和`n = 6`。 

这`max`操作处理现有集合已包含足够拆分器的情况。 Python 整数具有任意精度，因此值可达`10^9`不需要特殊的溢出处理。 

操作顺序在概念上很重要。 首先确定完整安装需要多少个分离器，然后考虑已拥有的分离器。 这使得边界情况`k > required`自然就变成了零购买。

 ## 边缘情况

 对于`n = 1`和`k = 0`，公式给出`required = (1 - 1) // 2 = 0`，所以答案是`0`。 两个墙壁插座已经提供了足够的容量。 

为了`n = 2`和`k = 0`，公式给出`required = (2 - 1) // 2 = 0`。 两台笔记本电脑都可以直接连接到两个原始插座，因此不需要分线器。 这是一个有用的边界检查，因为基于的公式`ceil((n - 2) / 2)`此时还必须正确定义。 

为了`n = 3`和`k = 0`，公式给出`required = 2 // 2 = 1`。 将一个分路器连接到任一墙上插座会在该分路器上创建三个可用插座，因此所有三台笔记本电脑都可以供电。 输出是`1`，它捕获意外舍入的实现`(n - 2) / 2`向下。 

为了`n = 6`和`k = 3`，总要求为`required = 5 // 2 = 2`。 由于三个分离器已经可用，`max(0, 2 - 3)`给出`0`。 盈余不得变成负购买数。 

为最大值`n = 10^9`和`k = 0`，计算为`required = 999,999,999 // 2 = 499,999,999`。 两个墙壁插座加上每个分配器获得的两个插座恰好提供了足够的容量，并且无需模拟数亿个分配器添加即可立即获得答案。
