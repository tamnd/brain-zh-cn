 ## 解决方案
 ## 问题理解

 这道菜包含两种蔬菜。 第一个贡献`X`每克的情绪单位，并且有`A`克它。 第二个贡献`Y`每克情绪单位，并且有`B`克。 总的情绪变化只是两种蔬菜贡献的总和：`A * X + B * Y`。 

第一输入行给出金额`A`和`B`，而第二个给出每克情绪变化`X`和`Y`。 要求的输出是一个整数，即吃完整道菜后心情的总变化。 否定答案意味着情绪下降，而肯定答案意味着情绪上升。 

数量`A`和`B`至多是`30000`， 和`X`和`Y`位于之间`-30000`和`30000`。 即使是一种蔬菜的最大绝对贡献也是`30000 * 30000 = 900000000`，所以总的绝对结果最多为`1800000000`。 这适合有符号的 32 位整数，尽管 Python 整数无论如何都没有溢出问题。 更重要的是，约束不需要任何迭代、搜索、动态规划或图算法。 恒定数量的算术运算就足够了。 

主要的边缘情况来自有符号值而不是输入的大小。 例如，与```
2 3
2 -1
```答案是`2 * 2 + 3 * (-1) = 1`。 粗心的实施会导致`Y = -1`因为正值会产生`7`，失去了第二种蔬菜会降低情绪的事实。 

第二种情况是两种情绪变化都是负面的：```
1 1
-30000 -30000
```正确答案是`-60000`。 乘法必须保留以下符号`X`和`Y`; 在计算之前取绝对值会得到错误的结果。 

零也是一种有效的情绪变化。 为了```
30000 30000
0 30000
```正确答案是`900000000`。 第一种蔬菜没有任何贡献，尽管其数量不为零。 任何假设每种蔬菜都会改变情绪的实现都会错误地处理这种情况。 

最后，最大值可以产生接近整数边界的结果：```
30000 30000
30000 30000
```正确答案是`1800000000`。 必须使用能够表示完整结果的整数类型来执行计算。 

## 方法

 直接的强力解释将单独处理每一克。 我们可以添加`X`到答案`A`次，然后添加`Y`到它`B`次。 这是正确的，因为每一克都是独立贡献的，因此在处理所有克之后，累加器准确地包含总的情绪变化。 

问题是这执行`A + B`补充。 两个金额等于`30000`， 那是`60000`迭代。 在这个特定的问题中，60000 个操作仍然足够小，可以在一秒的限制内轻松运行，因此这个强力版本实际上会被接受。 然而，这是不必要的工作，并且模糊了问题的简单数学结构。 

关键的观察是所有`A`第一种蔬菜的克数具有完全相同的贡献，`X`。 而不是添加`X`反复地，我们可以将这些相同的贡献组合到产品中`A * X`。 同样的推理给出`B * Y`第二种蔬菜。 由于这道菜只包含这两种蔬菜，因此添加两种产品即可给出完整的答案。 

这将整个计算变成两次乘法和一次加法。 蛮力之所以有效，是因为它明确地对每个单独的贡献求和，但未能利用许多连续贡献相同的事实。 认识到重复可以让我们用乘法代替重复的加法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(A + B) | O(1) | O(1) | 已接受，但没有必要 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`A`和`B`，两种蔬菜的量。 这些值决定了每种类型有多少克对最终情绪变化有贡献。 
2. 阅读`X`和`Y`，每种蔬菜一克所引起的情绪变化。 它们可能是正数、零或负数，因此必须保留它们的符号。 
3. 计算`A * X`。 这将第一种蔬菜的所有克数的相同贡献结合到一次乘法中。 
4. 计算`B * Y`出于同样的原因，对于第二种蔬菜。 
5. 将两个产品相加并打印结果。 这两种产品占菜肴中的每一克，因此它们的总和正是情绪变化的总和。 

### 为什么它有效

 第一种蔬菜的贡献是`X`重复`A`次，这正是`A * X`。 同样，第二种蔬菜的贡献是`B * Y`。 每克都属于这两组中的一组，因此总贡献恰好是`A * X + B * Y`。 该算法直接计算该表达式，这意味着它不能省略一克或对一进行两次计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A, B = map(int, input().split())
    X, Y = map(int, input().split())

    print(A * X + B * Y)

if __name__ == "__main__":
    solve()
```第一个输入操作读取两个量，第二个输入操作读取两个每克情绪变化。`map(int, ...)`就足够了，因为所有四个值都是整数，包括负值。 

表达式`A * X + B * Y`是完整的数学解。 没有循环、数组、递归或特殊情况，因为普通的有符号整数算术已经正确处理正、负和零贡献。 

操作顺序也很简单。 在将两个独立的贡献相加之前，将每个量乘以相应的每克效应。 Python 的任意精度整数使得这些约束不可能发生溢出，尽管最大结果已经小到足以容纳有符号的 32 位整数。

 ## 边缘情况

 当一种蔬菜降低情绪时，它的贡献一定是负面的。 为了```
2 3
2 -1
```第一个产品是`4`第二个是`-3`，所以结果是`1`。 该算法从不取绝对值或以其他方式改变符号，因此负面影响是自然处理的。 

当两种效应均为负时，相同的公式仍然适用。 为了```
1 1
-30000 -30000
```产品是`-30000`和`-30000`，生产`-60000`。 对于负值没有单独的分支，因为整数乘法已经应用了正确的符号。 

零效应是另一种不需要特殊分支的情况。 和```
30000 30000
0 30000
```第一个产品是`0`，第二个是`900000000`。 结果是`900000000`。 该算法正确地将第一种蔬菜视为对情绪没有影响。 

在最大正边界处，```
30000 30000
30000 30000
```产品都是`900000000`, 给予`1800000000`。 该计算使用完整的输入值，没有任何差一调整，因为`A`克准确贡献`A`的副本`X`。 

相同的边界适用于负极端：```
30000 30000
-30000 -30000
```两种产品都是`-900000000`，所以答案是`-1800000000`。 这证实了该实现保留了符号并处理了完整允许的数字范围。
