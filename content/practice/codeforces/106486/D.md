 ## 解决方案
 ## 问题理解

 我们从一个正整数开始$x$。 在每一步中，我们都应用经典的 Collat​​z 变换。 

如果当前值为奇数，则变为$3x+1$。 

如果当前值是偶数，则变为$x/2$。 

任务不是永远模拟。 我们只需要求出需要进行多少次操作才能使该值第一次恰好变为1。该语句保证对于所有测试数据，序列最终达到1，并且答案小于1000。 

输入包含单个整数$x$，输出是一个整数，表示达到 1 所需的最少操作数。 

从算法的角度来看，约束非常小。 初始值最多为$2^{31}-1$，并且该声明还保证每个中间值也保持在该范围内。 由于答案保证小于 1000，因此直接模拟执行的迭代次数少于 1000 次。 甚至一个$O(\text{answer})$解决方案实际上是恒定时间。 

最重要的边缘情况是输入已经为 1 时。 

例如：```
Input:
1
```正确的输出是：```
0
```不需要任何操作，因为该值已经等于 1。如果粗心的实现总是在检查之前执行一次转换，则会错误地输出 1。 

另一种微妙的情况是在一次操作后立即达到 1 的序列。 

例如：```
Input:
2
```顺序是：```
2 -> 1
```答案是1。如果我们在值变为1时停止但忘记计算最后的操作，我们将错误地输出0。 

第三种情况涉及奇数。 

例如：```
Input:
3
```顺序是：```
3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1
```答案是7。错误计算的实现$3x-1$或者错误地执行整数除法会产生完全不同的轨迹。 

## 方法

 最直接的想法就是完全按照描述来模拟过程。 从给定值开始，根据奇偶校验重复应用相应的规则，并统计执行了多少次操作。 一旦该值变为 1，就停止并输出计数。 

这种暴力方法已经足够了。 序列长度保证低于1000，因此最多执行999次转换。 每个转换都包含奇偶校验和简单的算术运算。 总的工作量很小。 

许多涉及重复状态转换的问题需要循环检测、记忆、图形技术或数学捷径。 这里这些都不是必需的，因为该语句明确保证序列达到 1，并且在很少的步骤内完成。 约束的结构告诉我们，简单的模拟正是预期的解决方案。 

因此，最佳解决方案是相同的模拟。 我们重复变换当前值，直到它变成1，并计算变换次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(t) | O(1) | O(1) | 已接受 |
 | 最佳| O(t) | O(1) | O(1) | 已接受 |

 这里$t$表示达到 1 之前的操作次数，该语句保证$t < 1000$。 

## 算法演练

 1.读取初始值$x$。 
2. 初始化计数器`ans = 0`。 
3.同时`x != 1`，执行一项 Collat​​z 操作。 

如果`x`是奇怪的，将其替换为`3 * x + 1`。 

否则，将其替换为`x // 2`。 
4.应用操作后，增加`ans`减 1，因为恰好执行了一次转换。 
5. 什么时候`x`变为1，停止循环。 
6. 输出`ans`。 

### 为什么它有效

 该循环准确地再现了问题中定义的过程。 每次迭代对应一个合法操作并将计数器加一。 当前值`x`后$k$iterations 正是应用变换后获得的值$k$距离初始状态的时间。 

循环在第一时刻终止`x`等于 1。由于计数器记录了迄今为止执行的操作数，因此其终止时的值恰好是达到 1 所需的最小操作数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x = int(input())

ans = 0

while x != 1:
    if x % 2:
        x = 3 * x + 1
    else:
        x //= 2
    ans += 1

print(ans)
```程序首先读取初始值。 

变量`ans`存储已应用的转换次数。 循环继续，直到当前值变为 1。 

在循环内部，奇偶校验决定使用哪个规则。 对于奇数，我们计算`3 * x + 1`。 对于偶数，我们使用整数除以二。 执行转换后，我们将计数器递增，因为一项操作已完成。 

顺序很重要。 我们首先应用操作，然后递增计数器。 这正确地计算了产生新值的转换。 循环条件`x != 1`还可以正确处理输入已经为 1 的特殊情况，生成答案 0。 

该语句保证中间值保持在 32 位范围内，但 Python 整数无论如何都可以处理更大的值，因此溢出永远不是问题。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    x = int(input())
    ans = 0

    while x != 1:
        if x % 2:
            x = 3 * x + 1
        else:
            x //= 2
        ans += 1

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

 ## 边缘情况

 ### 输入已经等于 1

 输入：```
1
```算法初始化`ans = 0`。 条件`x != 1`立即为 false，因此循环永远不会运行。 输出是：```
0
```这是正确的，因为不需要任何操作。 

### 单次操作达到 1

 输入：```
2
```执行轨迹：```
x = 2, ans = 0
2 is even -> x = 1
ans = 1
```循环停止并输出：```
1
```产生 1 的运算被正确计数。 

### 从奇数开始

 输入：```
3
```执行轨迹：```
3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1
```该算法执行七次转换并输出：```
7
```这证实奇数跃迁使用所需的公式$3x+1$并且每个操作都只计算一次。
