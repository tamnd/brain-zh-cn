 ## 解决方案
 ## 问题理解

 我们被要求精确地计算有根有序树$n$分支结构约束下的节点。 每个节点都有一定数量的子节点，并且该数量必须属于给定的允许集合$A$。 该套装始终包括$0$，因此叶子总是被允许的，并且每个节点的子节点都是有序的，这意味着即使子树相同，交换两个子树也会产生不同的树。 

输入给出了多个测试用例。 每个测试用例提供$n$、树中的节点数和一个小集合$A$of allowed child counts. 任务是计算模数$998244353$，有多少种不同的有序有根树$n$节点满足每个节点的子节点数位于$A$。 

这些约束已经暗示了解决方案的结构。 全部的总和$n$测试用例最多为 3000 个，因此即使每个测试用例采用二次或稍三次动态编程也是可以接受的。 然而，$k \le 10$并且每个测试允许的度数有所不同，这会阻止所有情况下的预计算。 因此，主要的计算压力不是在单个测试中渐近的，而是在有效处理许多小卷积中。 

一个微妙的点是尺寸的含义。 树的大小计算的是节点，而不是边，因此单节点树对应于$n=1$。 这导致基本情况很重要：即使$0 \in A$，最小的有效树仍然是单个根节点。 

如果有人将“子节点数量”约束与图论意义上的度数序列相混淆，并试图将其建模为任意树，就会出现天真的错误。 例如，如果$A = \{0,2\}$和$n=3$，有效的结构受到严格限制，任何忽略排序或将子树视为无序的方法都会低估。 

另一个常见的失败案例是“儿童计数”之间的索引不一致$d$” 并且分配在子级之间的总节点数是$n-1$。 忘记这一点会导致相差一的结构错误，即使递归在其他方面是正确的。 

## 方法

 直接的暴力方法将尝试生成每个可能的有根有序树$n$节点并检查每个节点是否具有允许的度。 这在概念上很简单：通过为每个节点选择多个子节点来递归地构建树，然后递归地构建每个子树并计算总节点数匹配的配置$n$。 这是正确的，但组合起来会爆炸。 即使对于中等$n$，有序树的数量呈指数级增长，生成后的过滤效果更差。 

关键的观察是这个问题完全由子树大小组成决定。 一旦根有了$d$孩子们，问题归结为分裂$n-1$节点进入$d$有序组，每个组本身都是一棵有效的树。 这正是按大小排列的树计数序列的卷积结构。 

让$f[n]$是有效树的数量$n$节点。 对于固定根度$d$，我们需要分配剩余的$n-1$节点进入$d$有序子树。 这相当于采取$d$- 序列的折叠卷积$f$与自身并提取系数$n-1$。 自从$k \le 10$，每个测试用例最多只需要 10 个这样的卷积。 

这通过小序列的重复卷积将问题从指数枚举简化为多项式 DP。 因为总共$n$所有测试都很小，很简单$O(k n^2)$每次测试的 DP 足够并且顺利通过。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| 指数| 指数| 太慢了|
 | 具有有序卷积的 DP |$O(k n^2)$每次测试 |$O(n)$| 已接受 |

 ## 算法演练

 我们定义$f[i]$作为有效有序树的数量$i$节点。 我们使用子树大小的动态规划独立地为每个测试用例计算此值。 

### 步骤

 1.初始化一个DP数组$f$长度$n+1$全为零，并设置$f[1] = 1$。 

这表示单节点树，它始终有效，因为根有零个子节点。 
2. 适合各种尺寸$i$从$2$到$n$, 计算$f[i]$通过考虑所有可能的根度$d \in A$。 

根使用一个节点，因此剩余的$i-1$节点分布在其之间$d$孩子们。 
3.对于固定的$d$，计算分割方式的数量$i-1$进入$d$有序部分，其中每个部分对应于一个子树大小。 

每个部分贡献一个因素$f[\cdot]$，所以这变成了系数$x^{i-1}$在$F(x)^d$， 在哪里$F(x) = \sum f[i] x^i$。 
4. 直接使用卷积来计算，而不是符号幂级数。 维护一个表示当前功率的辅助数组$g_d$， 在哪里$g_d[s]$是形成总尺寸的方式数$s$使用$d$有序子树。 
5. 构建$g_d$迭代地：

 开始于$g_0[0] = 1$，并且对于每个乘法$F$，通过卷积更新：$$g_{t+1}[s] = \sum_{x=1}^{s} g_t[x] \cdot f[s-x]$$6. 计算后$g_d$， 添加$g_d[i-1]$进入$f[i]$对于每一个允许的$d \in A$。 

### 为什么它有效

 中心不变量是$g_d[s]$总是精确地计算有序森林的数量$d$有根树的总大小为$s$，其中每个组件树已经根据$f$。 这确保了当我们计算时$f[i]$，我们不是猜测结构，而是系统地组合已经正确的子结构。 由于每个有效树都具有按根度和有序子树大小进行的唯一分解，因此每个配置都只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        A = list(map(int, input().split()))

        # dp[i] = number of trees with i nodes
        dp = [0] * (n + 1)
        dp[1] = 1

        # precompute convolution powers up to max degree needed
        # we will build dp incrementally
        for i in range(2, n + 1):
            total = 0

            for d in A:
                if d == 0:
                    continue
                # g[0] = 1, then convolve f (dp) with itself d times
                # we compute iteratively
                g = [0] * i
                g[0] = 1

                for _ in range(d):
                    ng = [0] * i
                    for s in range(i):
                        if g[s] == 0:
                            continue
                        for x in range(1, i - s):
                            if dp[x]:
                                ng[s + x] = (ng[s + x] + g[s] * dp[x]) % MOD
                    g = ng

                total = (total + g[i - 1]) % MOD

            dp[i] = total

        print(dp[n] % MOD)

if __name__ == "__main__":
    solve()
```从字面上看，实现遵循递归。 外循环增量构建树大小，确保在计算较大大小时已知所有子树计数。 对于每个允许的度，内部结构计算组装有序子树的方式数量，并与剩余节点相加。 

一个微妙的实现细节是排除$x=0$卷积循环内的子树大小。 这是必要的，因为每个子树必须包含至少一个节点。 允许零会错误地计算空树并夸大结果。 

## 工作示例

 ### 示例 1

 考虑$n=4$,$A = \{0,1\}$。 

我们计算$dp[1]=1$。 为了$dp[2]$，只有度 1 起作用，因此我们附加一个大小为 1 的子树。因此$dp[2]=1$。 

为了$dp[3]$，同样只有链是可能的，给出 1 结构。 为了$dp[4]$，仍然只有一条路径存在。 

| 我| d 选择 | i-1 的 g 结果 | dp[i] | dp[i] |
 | --- | --- | --- | --- |
 | 1 | - | - | 1 |
 | 2 | 1 | [1 种方式] | 1 |
 | 3 | 1 | [1 种方式] | 1 |
 | 4 | 1 | [1 种方式] | 1 |

 这证实了限制单子节点会强制形成链结构。 

### 示例 2

 让$n=4$,$A=\{0,2\}$。 

为了$dp[2]$，度 2 是不可能的，因此值为 0。 

对于$dp[3]$，有 2 个子节点的根需要将 2 个节点分成两个有序的非空部分，只有 (1,1)，所以$dp[3]=1$。 

为了$dp[4]$，我们将 3 个节点分成两个有序部分：(1,2) 和 (2,1)，所以$dp[4]=2$。 

| 我| i-1 的有效分割 | dp[i] | dp[i] |
 | --- | --- | --- |
 | 2 | 无 | 0 |
 | 3 | (1,1) | 1 |
 | 4 | (1,2), (2,1) | (1,2), (2,1) | 2 |

 这演示了子项的排序如何直接使对称子树配置加倍。

 ## 边缘情况

 一个关键的边缘情况是当$A = \{0\}$。 唯一有效的结构是单个节点，因为每个节点必须有零个子节点。 该算法正确地处理了这个问题，因为所有$d \neq 0$不存在，所以没有增长超出$dp[1]$发生。 

另一种情况是当$n$很小但很大程度存在于$A$。 例如，$n=3$,$A=\{0,2,5\}$。 5 度选项实际上是无关紧要的，因为卷积$i-1=2$无法分配足够的节点。 由于没有有效的分割，循环自然会产生零贡献，因此不需要特殊的过滤。 

最后，考虑$n=2$,$A=\{0,1,2\}$。 2 度似乎适用，但将一个节点拆分为两棵非空子树是不可能的。 在这种情况下，卷积正确地产生了零，这表明可行性是通过结构而不是手动来强制执行的。
