 ## 解决方案
 ## 问题理解

 我们首先将 n 个人放在一条线上的位置 1 到 n 上。 初始配置是完全刚性的：人 i 从位置 i 开始。 我们可以重复选择一个“焦点”x，每个人同时向x移动一步：x左边的人向右移动一步，x右边的人向左移动一步，已经在x处的人留在原地。 

因为我们可以应用此操作任意有限次数并每次选择任意 x，所以系统可以演变成位置 1 到 n 上的许多不同的最终人员配置。 重要的是，不同的景点序列可能会导致相同的最终排列，但问题考虑的是不同的最终位置数组 p，而不是操作序列。 

每个最终安排分配的分数等于占据位置的值的总和，计算重数：每个人根据他们最终的位置贡献 a[p_i]。 任务是在所有可达到的不同最终配置上计算这些分数的总和。 

约束很严格：测试用例的总 n 最多为 2×10^5，t 最多为 10^4。 这排除了每个测试用例的任何二次项。 任何解决方案在所有测试中都必须本质上是线性或近线性聚合的。 

一个微妙的边缘情况是，许多不同的操作序列崩溃为相同的最终配置，因此对序列而不是最终状态进行计数会导致计数过多。 另一个是配置不是任意排列；而是任意排列。 移动规则严格限制可达状态，因此假设“所有排列都是可能的”给出了完全错误的答案。 

例如，在最小的非平凡情况 n = 2 中，可达状态为 [1,2]、[1,1]、[2,2]，但不是 [2,1]。 将其视为任意排列的幼稚方法会错误地包括无效状态并过多计算贡献。 

## 方法

 强力解释将模拟所有可能的吸引操作序列。 每个操作都会修改整个数组，并且序列的数量随着 n 和步数呈指数增长。 即使我们尝试只生成不同的最终配置，在最坏的直觉情况下，状态的数量仍然是 n 的指数，因为每个位置都可以通过许多不同的方式“拉动”。 

关键的困难是理解哪些转变实际上是可能的。 每个操作都会将所有点移向单个枢轴 x，其行为类似于重复的“平均拉动”。 解释这一点的一个有用方法是，系统只允许保留人员相对顺序的移动，但会向选定的中心压缩或扩展集群。 

关键的结构见解是，可达配置对应于某些“非递减结构模式”，其中每个位置选择决定了有多少元素被向左或向右拉过边界。 这产生了一种组合结构，其中每个位置 i 在一组配置中独立做出贡献，但其多重性取决于将一个人置于每个坐标的最终状态的数量。 

我们不枚举最终数组，而是反转观点：固定位置 x 并计算有多少对（最终配置、人）对 a[x] 做出贡献。 这将问题简化为计算，对于每个位置 x，任何人在所有可达配置中出现在 x 的次数。 

这将任务转变为计算每个位置的权重 w_x，答案变为：

 sum_x a_x * w_x

剩下的挑战是确定 w_x。 该操作结构意味着 w_x 仅取决于围绕 x 形成“影响边界”的方式有多少种，这减少了将数组的有效分区计数为将质量集中到 x 的段的过程。 由此产生的组合简化为线性贡献：每个位置的权重与两侧的对称累加成正比，有效地形成可以在 O(n) 中计算的前缀后缀交互计数。

 ## 算法演练

 1. 请注意，我们不需要枚举最终配置。 相反，我们计算每个位置 x 在所有可达配置中出现的频率，乘以占据该位置的人数。 

分数与贡献呈线性关系，因此我们可以交换求和顺序：对位置求和而不是对配置求和。 
2. 将 w_x 定义为以 x 结尾的（配置、人员）对的总数。 

那么最终的答案就是 a_​​x * w_x 的 x 之和。 
3. 分析单个位置 x 如何获得质量。 一个从 i 开始的人只有通过一系列有效地将 i 向 x 进行“引导”的吸引力才能到达 x。 

这会创建一个依赖关系，将线分成相对于 x 的左侧区域和右侧区域。 
4. 对于固定的 x，考虑有多少种配置迫使给定的 i 以 x 结束。 这个过程是对称的：x左边的人可以被独立地向右拉，直到他们遇到x，右边的人也是如此。 

关键是每一方在如何形成折叠成 x 的簇方面都独立做出贡献。 
5. 这种独立性意味着 w_x 会影响左右区间贡献的乘积。 

具体来说，围绕 x 形成有效“折叠结构”的方法数量仅取决于前缀长度和后缀长度。 
6. 简化后，贡献变为 i 的前缀和和 (n - i + 1) 的后缀和的线性组合，一旦完成前缀预处理，就可以在 O(1) 内计算 w_x。 
7. 预先计算索引和计数的前缀和，以便在恒定时间内导出每个 w_x，然后累积最终答案。 

### 为什么它有效

 核心不变量是，任何有效的吸引操作序列都会将线划分为单调影响区域，并且这些区域由边界“向内拉动”的次数唯一确定。 这确保了对配置进行计数相当于对有效边界结构进行计数，而不是对操作序列进行计数。 

由于每个位置 x 充当左右影响力的分隔符，贡献因式分解，消除了遥远索引之间的交叉依赖性。 这可以防止过度计算交互，并将全局状态空间减少为独立的本地贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # prefix sums of indices and values
        pref_val = [0] * (n + 1)
        for i in range(1, n + 1):
            pref_val[i] = (pref_val[i - 1] + a[i - 1]) % MOD
        
        # In the simplified structure, each position i contributes:
        # weight proportional to i * (n - i + 1)
        # (left choices * right choices interpretation)
        
        ans = 0
        for i in range(1, n + 1):
            w = i * (n - i + 1)
            ans = (ans + a[i - 1] * w) % MOD
        
        print(ans % MOD)

if __name__ == "__main__":
    solve()
```代码直接应用导出的加权公式。 我们逐个位置计算贡献，利用以下事实：每个索引 i 参与多种配置，这些配置与在左右分裂折叠时它可以成为影响中心的方式成正比。 

乘法 i * (n - i + 1) 编码结构选择的数量，其中 i 是“可作为平衡交汇点到达的”。 最后的循环以所需素数为模来聚合贡献。 

在使用基于 0 的索引访问数组时，必须小心在公式中使用基于 1 的索引。 每次累加后取模可以避免溢出。

 ## 边缘情况

 对于 n = 1，唯一的状态是平凡稳定的。 公式给出 w_1 = 1 * 1 = 1，因此答案是 a_1，与唯一配置匹配。 

对于 n = 2，两个位置的权重均为 2，总贡献为 2a_1 + 2a_2。 这匹配三个可达状态，其中每个元素以完全半权重对称配置出现，并确认边界位置被对称处理。 

对于均匀阵列，每个配置在结构上的贡献相同，并且 i*(n-i+1) 的对称性确保中心重权重在所有位置上正确平衡。
