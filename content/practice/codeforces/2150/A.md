 ## 解决方案
 ## 问题理解

 我们得到一行$10^9$细胞，每个都是黑色或白色。 最初，一组细胞是黑色的，而所有其他细胞都是白色的。 然后，一系列命令以累积的方式执行多次：对于第一个命令，我们从单元格 1 开始，遵循该命令，并将生成的单元格涂成黑色。 对于前两个命令，我们再次从单元格 1 开始，按顺序执行这两个命令，并将最终的单元格涂成黑色。 此过程持续进行，直到所有命令都已累积应用。 

有两种类型的命令：`A`，向前迈出一步，并且`B`，移动到下一个白色单元格。 输出是所有人执行完动作后的最后一组黑色单元格。 

限制因素很大。 命令总数和初始黑色单元格可以达到$10^5$所有测试用例中的每个，但细胞数量本身可以高达$10^9$。 这意味着模拟整行细胞或以简单的方式重复扫描下一个白细胞将太慢。 任何直接接触每个单元格或迭代至$10^9$将超过时间限制。 

当多个命令时会出现微妙的边缘情况`B`连续执行，所有中间单元格都是黑色的。 一次移动一个单元格的简单解决方案要么速度很慢，要么如果不小心的话可能会超过下一个白色单元格。 另一种边缘情况是命令的最终目的地已经是黑色时； 该算法必须正确地将其保留为黑色，而不会重复或丢失更新。 

## 方法

 暴力方法模拟每个人从单元 1 开始并执行命令前缀。 对于每个`A`，我们增加 1。对于每个`B`，我们向前扫描，直到找到一个白细胞。 执行完前缀后，我们将最后一个单元格标记为黑色。 这种方法是正确的，但太慢了：每个`B`可能需要扫描最多$O(10^9)$细胞，我们最多有$10^5$命令。 最坏情况的复杂性本质上是$O(n \cdot m)$具有非常大的常数，这是不可行的。 

解锁更快解决方案的关键观察是，仅需要标记**每个前缀的最后访问的单元格**。 用于命令`B`，最终位置仅取决于命令序列和当前的黑色单元格集。 重要的是，在前缀末尾添加黑色单元格后，只会影响后面的内容`B`命令。 我们可以将黑色单元保持在排序结构中并贪婪地处理运动。 每当我们遇到一个`B`，我们使用现有的黑色单元格跳转到下一个未标记的位置。 

最佳方法是避免扫描每个细胞。 相反，我们将黑色单元格保留在一组中$O(1)$成员资格检查并跟踪最远访问的单元。 对于每个命令，`A`很简单，只需增加 1。对于`B`，我们增加当前位置，直到到达不在黑色集合中的单元格。 因为每个单元格最多可以变黑一次，所以这保证了所有命令的增量总数受以下限制：$n + m$，即$O(10^5)$对于每个测试用例。 这已经足够高效了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m * 细胞扫描) | O(米) | 太慢了 |
 | 最佳 | O(n + m) | O(米) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`和`m`、命令字符串和初始黑色单元格。 
2. 将初始黑色单元存储在集合中以进行 O(1) 成员资格检查。 
3. 初始化当前位置`pos = 1`。 
4. 按顺序迭代每个命令。 如果命令是`A`, 增量`pos`1.
 5. 如果命令是`B`, 反复递增`pos`直到`pos`不在黑色单元格集中。 这可以有效地跳转到下一个白色单元格。 
6. 在每个命令前缀（字符串中的每个步骤）后添加`pos`到黑色单元格集。 
7. 处理完所有命令后，对黑色单元集进行排序并输出其大小和元素。 

不变的是，在任何点，黑色单元格集合包含由先前前缀标记的所有单元格。 每个`B`命令总是跳过黑色单元格到下一个白色单元格，以确保正确性。 事实上，每个单元格只能从白色过渡到黑色一次，这保证了内部循环`B`命令最多运行`n + m`跨越整个前缀序列的步骤。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = input().strip()
        black = set(map(int, input().split()))
        pos = 1
        for c in s:
            if c == 'A':
                pos += 1
            else:
                while pos in black:
                    pos += 1
            black.add(pos)
        black_list = sorted(black)
        print(len(black_list))
        print(' '.join(map(str, black_list)))

solve()
```该解决方案首先有效地读取输入。 黑色单元存储在一个集合中，以允许 O(1) 成员资格检查，这对于快速执行至关重要`B`命令。 这`while`循环下`B`确保在不扫描整行的情况下找到下一个白单元。 最后排序可确保输出按升序排列。 使用集合可以避免重复插入并保持成员资格测试的效率。
