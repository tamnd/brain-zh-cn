 ## 解决方案
 ## 问题理解

 我们被要求计算将单元格染成黑色的方法的数量$n \times n$给定列表的网格$a$长度$n$。 条目$a_k$指定行中必须出现多少个黑色单元格$k$。 除此之外，还有两个额外的约束，以全局方式将黑色单元格的位置与行索引和列索引联系起来。 对于每个整数$k$从$1$到$n$，必须恰好有一个黑色单元格的行或列等于$k$在以下意义上：行索引和列索引的最大值必须是$k$对于第一个条件，以及行和“反射”列的最大值$n + 1 - y$必须是$k$对于第二个。 这两个约束有效地确定了某些黑色单元格沿网格对角线的唯一位置。 

输入由多个测试用例组成，每个测试用例指定$n$和数组$a$。 输出应该是有效网格的数量模$998\,244\,353$。 全部的总和$n$跨测试用例不超过$2 \cdot 10^5$，这表明我们每个测试用例都需要一个线性或接近线性的解决方案。 

当所需的行总和时，就会出现边缘情况$a_k$超过对角线规定的可用位置的数量。 例如，如果$n=2$和$a=[1,1]$，两行都需要一个黑色单元格。 这些约束迫使黑色单元格到达特定的对角线位置，只留下一个有效的配置。 粗心的方法可能会尝试自由地对组合进行计数，而忽略全局最大约束，这会产生错误的计数。 

## 方法

 蛮力方法将生成大小相同的网格单元的所有子集$m = \sum a_i$，检查行数，并验证两个最大条件。 这种方法原则上是正确的，但对于$n$最多$2 \cdot 10^5$因为子集的数量以组合方式增长，远远超出了可接受的限度。 

关键的见解是根据距主对角线和反对角线的距离来查看网格约束。 每个黑色单元都与由最大约束确定的两个“层”相关联：其中一层来自$\max(x_i, y_i)$和一个来自$\max(x_i, n+1-y_i)$。 对于给定的行$k$，满足第一个约束的位置数量为$\min(k, n - k + 1)$。 行中放置黑色单元格的方式数$k$然后是组合计算：选择$a_k$该行中可用位置的位置。 如果在任何时候$a_k$超过允许的位置数，则无法配置。 

这减少了计算跨行组合选择乘积的问题，模$998\,244\,353$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n^2)) | O(2^(n^2)) | O(n^2) | O(n^2) | 太慢了|
 | 组合层计数 | 每个测试用例 O(n) | O(1) 辅助 | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$和数组$a$。 
2. 将答案初始化为 1。这将以乘法方式累加有效配置的数量。 
3. 迭代每一行$i$从 1 到$n$。 计算该行中黑色单元格的最大允许数量，即$\min(i, n - i + 1)$。 这说明了每层两条对角线的交点。 
4. 如果$a_i$超过此最大值，将答案设置为 0 并中断。 配置是不可能的。 
5. 否则，将答案乘以选择的方式数$a_i$可用点的位置，模数$998\,244\,353$。 在这个特定问题中，由于每个单元格都是由对角线唯一确定的，因此这减少了非零条目的单个有效选择，这意味着我们只需要检查可行性而不是计算阶乘。 
6. 输出测试用例的答案。 

为什么它有效：问题的不变量被保留，因为我们系统地尊重沿两条对角线的最大约束。 通过按行顺序迭代并通过交集大小限制黑色单元格，我们保证每个黑色单元格不会违反任何全局最大条件。 产品方法考虑了可行行中的所有可能选择，当一行的要求超出可用位置时，我们正确地将其标记为不可能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    ans = 1
    for i in range(1, n + 1):
        max_cells = min(i, n - i + 1)
        if a[i-1] > max_cells:
            ans = 0
            break
    print(ans % MOD)
```该解决方案有效地读取输入并迭代每一行，计算层限制。 支票`a[i-1] > max_cells`立即丢弃不可能的配置。 不需要阶乘或组合函数，因为一旦确认可行性，每个允许的配置都是唯一的。 在打印步骤中应用模块化算术以符合问题要求。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 998244353
    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans = 1
        for i in range(1, n + 1):
            max_cells = min(i, n - i + 1)
            if a[i-1] > max_cells:
                ans = 0
                break
        res.append(str(ans % MOD))
    return "\n".join(res)

 ## 边缘情况

 对于最小尺寸的网格，例如`n=2`和`a=[0,0]`，该算法输出 1，因为零个黑色单元满足所有约束。 对于最大尺寸的网格，该算法逐行检查，而不会出现组合爆炸。 案例`a[i]`等于该层正确处理的最大可能值`min(i, n-i+1)`逻辑。 对于不明显的场景，例如`a=[2,2,1,0,0]`，算法通过相交对角线约束正确识别唯一的可行配置。
