 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度为的二进制字符串$n$，恰好包含$k$一个，具有涉及长度为三的子序列的附加结构约束。 在所有指数三元组中$i < j < k$，我们计算有多少个形成模式“101”和有多少个形成“010”。 目标是生成一个字符串，其中这两个计数相等。 

这里的子序列意味着我们可以自由地跳过字符，所以重要的不是相邻性而是相对顺序。 这使得条件对零和一的全局放置而不是局部模式敏感。 

限制很小：$n \le 100$和$t \le 500$。 这立即告诉我们，我们不需要任何渐近紧密的东西$O(n^2)$每个测试用例，甚至立方推理也是可以理解的。 然而，构造问题表明贪婪或结构模式而不是明确计数。 

边缘情况出现时$k = 0$,$k = n$，或者当$k = 1$或者$k = n-1$。 在这些情况下，其中一种模式是不可能的，因为“101”或“010”至少之一要求两个符号在交替位置出现两次。 例如，如果所有字符都相同，则两个计数都为零，因此任何统一字符串都是有效的。 粗心的方法可能会尝试通过过于激进地交替来“平衡”子序列，但这是不必要的，并且可能会违反所需的子序列数量。 

另一个微妙的边缘情况是当它们非常稀疏或非常密集时。 例如，如果$k = 1$，任何具有单个 1 的字符串两种模式的出现次数为零，因此任何放置都有效。 同样对于$k = n-1$。 

## 方法

 一个蛮力的想法是生成所有长度的二进制字符串$n$恰好与$k$一个，并通过迭代所有索引三元组来计算“101”和“010”子序列的数量。 直接计算子序列需要$O(n^3)$，并且有$\binom{n}{k}$候选字符串。 即使是为了$n = 100$，这是一个天文数字，使得暴力破解完全不可行。 

关键的观察结果是，该问题实际上并不需要控制两个计数之间的精确差异。 我们只需要它们相等。 一个强大的结构简化是我们可以强制两个计数为零。 如果我们完全消除长度为三的所有交替模式，就会发生这种情况。 

当且仅当二进制字符串从不按顺序在 0 和 1 之间交替两次时，它才没有“101”或“010”子序列。 如果字符串在块中是单调的，则可以保证这一点：全零后跟全一，或者全一后跟全零。 在这样的字符串中，任何三元组要么只包含一种符号类型，要么最多有一个转换，因此两种模式都不会出现。 

这将任务简化为纯粹的构造问题：放置$k$那些和$n-k$单个连续块结构中的零。 “000…111…”和“111…000…”都有效，并且都满足所需的相等性，因为两个子序列计数都为零。 

这是关键的减少：我们不是平衡两个组合计数，而是同时避免两者。

 ## 算法演练

 1. 阅读$n$和$k$。 这些定义了最终字符串中必须出现的数量及其总长度。 
2. 构造一个由以下内容组成的字符串$k$连续的“1”字符。 这确保了计数约束立即得到满足，无需稍后修正。 
3. 追加$n-k$连续的“0”字符。 这在符号之间创建了单个转换边界。 
4. 输出结果字符串。 

将所有人放在第一位的选择是任意的。 将所有零放在前面同样有效，因为条件仅取决于交替形式的子序列，而不取决于绝对顺序。 

### 为什么它有效

 构造的字符串在符号之间最多有一次转换。 任何在 0 和 1 之间交替的长度为 3 的子序列都需要至少按顺序进行两次转换，即 0→1→0 或 1→0→1。 由于整个字符串中只存在一个转换，因此两种模式都无法形成。 因此，两个计数都为零，并且它们相等。 

该结构还强制执行了确切的数量，因为我们明确地放置了它们而没有重新排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    # place all 1s first, then 0s
    print("1" * k + "0" * (n - k))
```代码直接实现了单调块构造。 唯一微妙的一点是确保计数完全匹配：字符串长度是固定的，所以一旦$k$已放置，其余位置必须为零。 

不需要进一步的验证或计算，因为该结构自动保证子序列条件。

 ## 边缘情况

 当$k = 0$，算法输出$n$零。 没有，所以“101”和“010”子序列都是不可能的。 该构造产生一个空的一块，后跟零，这仍然满足最多一次转换的不变量。 

什么时候$k = n$，输出是$n$那些。 同样，不存在零，因此两个子序列计数都为零。 该结构退化为没有转换的单个块。 

什么时候$k = 1$，字符串是“1000…0”。 任何长度为 3 的子序列都不能交替，因为 1 只出现一次，因此两种模式都不存在。 同样的推理对称地适用于$k = n-1$。
