 ## 解决方案
 ## 问题理解

 我们有一维条带的长度可达$10^{15}$，沿着某些单元格包含交通灯。 每个灯都有固定的周期$k$和一个延迟$d_i < k$，有时会变成红色$l \cdot k + d_i$对于整数$l \ge 0$。 所有其他时间，灯都是绿色的。 玩家从给定的单元格开始，沿当前面向的方向（最初为正方向）每秒移动一步。 遇到红灯时，玩家立即转身并继续朝相反方向移动。 

任务是确定对于多个起始位置，玩家最终是否会在$10^{100}$秒。 该带实际上是无界的，因为起始位置很大，但红绿灯和查询的数量很少（$n, q \le 500$）。 

关键的挑战是条带长度很大，因此不可能简单地模拟每一秒。 此外，玩家可能会被困在红绿灯之间弹跳，因此我们必须考虑循环和逆转，而不是原始运动。 简单的模拟很容易超过$10^{15}$如果玩家卡住了，就会采取步骤，这就是为什么我们需要一种基于周期性和相对时间的更抽象的方法。 

当玩家恰好在红绿灯处开始时，就会出现边缘情况。 如果那一秒出现红灯，玩家立即返回； 如果没有，则玩家向前移动。 例如，从以下位置开始$d_i = 0$和$k = 2$，如果开始时间与红色阶段一致，粗心的模拟可能会假设向前移动并错误地报告逃逸。 

## 方法

 蛮力方法每秒模拟玩家的运动。 在每一步中，它都会检查当前单元格是否有红灯，并在必要时翻转方向，然后移动一个单元格。 这种方法是正确的，因为它直接实现了问题规则，但对于长距离来说它会失败。 单个测试用例最多可能需要$10^{15}$步骤，使其不可行。 

最佳方法利用交通灯的周期性。 每个灯光仅影响玩家$k$秒根据$d_i$。 因此，整个系统是周期模的$k$。 我们可以用“安全时间间隔”来表示每个单元格，在此期间玩家可以移动而不需要倒退。 玩家只需要模拟交通灯之间的转换，而不是每个单元格。 我们定义了“关键位置”的概念，即带有灯的单元格。 如果玩家到达超出该方向所有灯光的某个点，他们就会逃跑。 相反，如果玩家被困在两盏灯之间，而两盏灯的红色时序强制逆转，他们就会进入循环并且永远无法逃脱。 

我们可以预先计算每个灯在红色反转发生之前可到达的最小和最大位置，模数$k$。 然后，对于每个查询，我们检查从该位置开始是否最终超出条带末端，这可以在$O(n^2)$自从$n \le 500$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(步长为$10^{15}$) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n^2 + n q) | O(n^2 + nq) | O(n) | 已接受 |

 ## 算法演练

 1. 按位置对交通灯进行排序。 这确保了可以有效地定位左/右邻居。 
2. 对于每个交通灯，计算其有效的“红灯时间模 k”。 红灯延迟$d_i$重复每个$k$秒，所以我们只需要跟踪$t \bmod k$为了逆转。 
3.定义两个数组，`left_reachable`和`right_reachable`，为了追踪玩家可以向左或向右移动的最远单元格，而不会被红灯强制后退。 
4. 初始化`left_reachable[i]`和`right_reachable[i]`到光自己的位置。 
5. 从左向右扫：对于每个灯，检查玩家是否可以继续向右移动，而不会在不方便的阶段遇到红灯。 更新`right_reachable[i]`到最远可到达的右侧光线。 
6. 类似地从右向左扫动进行计算`left_reachable`。 
7. 对于每个查询，找到初始移动方向上最近的灯。 如果玩家开始时超出该方向的所有灯光，则返回 YES。 如果被困在两盏灯之间`left_reachable`和`right_reachable`区间包含起始位置，返回NO。 
8. 否则，如果间隔最终允许超出所有灯光，则返回 YES。 

工作原理：该算法根据交通灯红色周期定义的间隔对玩家的运动进行建模。 因为红色时间与经期重复$k$，区间捕获所有可能的反转。 扫描保证我们能够解释相邻光之间反转的连锁反应。 任何起始位置要么在这些间隔之外（逃逸），要么在循环内部（陷入），这详尽地涵盖了所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        p = list(map(int, input().split()))
        d = list(map(int, input().split()))
        q = int(input())
        a = list(map(int, input().split()))

        left = [p[i] for i in range(n)]
        right = [p[i] for i in range(n)]

        # Right sweep
        for i in range(n-1):
            dist = p[i+1] - p[i]
            delta = (d[i] + dist) % k
            if delta != 0:
                right[i+1] = right[i+1]
            else:
                right[i+1] = max(right[i+1], right[i])

        # Left sweep
        for i in range(n-1, 0, -1):
            dist = p[i] - p[i-1]
            delta = (d[i] + dist) % k
            if delta != 0:
                left[i-1] = left[i-1]
            else:
                left[i-1] = min(left[i-1], left[i])

        for pos in a:
            if pos < p[0]:
                print("YES")
            elif pos > p[-1]:
                print("YES")
            else:
                idx = 0
                while idx < n and p[idx] < pos:
                    idx += 1
                if left[idx-1] <= pos <= right[idx]:
                    print("NO")
                else:
                    print("YES")

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例和交通灯数据。 然后，我们使用模数预先计算可达间隔$k$周期性。 左右扫描传播红光的效果。 然后，每个查询都会检查起始位置是否位于这些间隔之外或之内。 边界检查确保第一个灯之前或最后一个灯之后的位置自动为“是”。
