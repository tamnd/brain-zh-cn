 ## 解决方案
 ## 问题理解

 我们被问到是否有一个整数数组，`a`，可以转化为另一个数组，`b`，使用两种类型的操作。 第一个操作是循环左移，它将每个元素向左移动一个位置并将第一个元素绕到末尾。 第二个操作是相邻元素之间的交换，如果它们的数值差至少为 2。两个数组都包含从 1 到`m`至少一次，所以没有丢失任何数字。 数组可能长于`m`，意味着某些数字可以重复。 

任务是确定每个测试用例是否可以达到`b`从`a`使用这些操作。 和`n`由于所有测试用例中的元素多达 500,000 个且总共 500,000 个元素，因此任何考虑所有可能的交换或移位序列的解决方案都是不可行的。 模拟每种可能的交换的朴素暴力将花费阶乘或指数时间，这远远超出了允许的限制。 

当涉及重复数字时，会出现不明显的边缘情况。 例如，考虑`a = [1,1,2]`和`b = [1,2,1]`。 粗心的方法可能会尝试检查每对的相对顺序，而不考虑重复的数字会阻止某些交换。 在这里，算法必须仔细处理重复的数字及其位置。 当数字仅相差 1 时，会出现另一个微妙的问题：禁止交换，因此即使多重集中的所有数字都匹配，也无法达到某些排列。 像这样的小数组`a = [1,2]`,`b = [2,1]`和`m = 2`还暴露掉期无法弥合 1 的差异。 

## 方法

 蛮力方法是模拟每个可能的操作序列。 对于每次移位，我们可以旋转数组，对于每次可能的交换，尝试在允许的情况下交换相邻元素。 这种方法之所以有效，是因为允许的操作可以生成一些排列，但一旦出现以下情况，它就会失败`n`超过屈指可数。 和`n = 500,000`，即使考虑每个元素的单个交换也是`O(n)`每次操作，探索所有序列都变得天文数字。 

关键的见解是交换只允许相差 2 或更多的元素交换位置。 因此，相差 1 的元素不能相互移动。 这意味着相同“值模邻接”的数字的相对顺序被保留。 具体来说，我们可以将数字分为几类，其中同一类的元素可以在彼此之间自由交换或具有较大差异，但相差 1 的元素会相互阻塞。 实际上，当前剩余数组中最小的数字必须出现在`b`位于可以通过允许的交换和轮班到达的位置。 使用每个数字的频率图和单调堆栈或队列来跟踪哪些数字位于“前面”`a`使这变得高效。 此外，循环移位允许我们旋转数组，以便开头的任何数字最终都可以成为第一个元素，从而为我们提供了交换的灵活性。 

这一观察将问题简化为按从小到大的顺序处理数字，确保对于`b`, 中存在对应的数`a`可以在不违反交换限制的情况下移动到其位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`和`b`和不同元素的数量`m`。 维护每个数字的频率计数`a`。 
2. 为从 1 到 的每个数字创建一个队列或列表`m`包含该数字出现的索引`a`。 这将使我们能够有效地找到下一个所需的数字在哪里。 
3. 初始化变量`cur_min`跟踪当前可移动以匹配的最小数字`b`。 这很关键，因为相差 1 的数字无法交换，因此我们必须始终将最小的可用数字向前移动到较大的数字之前。 
4. 迭代`b`从左到右。 对于每个`b[i]`，检查该数字的位置队列`a`。 如果前面的索引对应于当前位置`a`或者可以在不交叉数字小于的情况下向前推进`b[i]`，我们将其从队列中删除并降低频率。 
5. 如果在任何时候下一个`b[i]`无法移动到其位置，因为所需的数字被尚未放置的较小数字阻挡，对此测试用例输出“NO”。 
6. 如果所有元素在`b`使用位置和允许的交换成功匹配，输出“YES”。 

这样做的原因是交换受到数字差异的限制。 通过始终首先移动最小的可用数字，我们确保不会发生阻塞移动。 循环移位由索引队列隐式处理，因为每个数字最终都会到达前面。 

## Python 解决方案```python
import sys
from collections import deque, defaultdict
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    pos = defaultdict(deque)
    for idx, val in enumerate(a):
        pos[val].append(idx)
    
    import heapq
    available = []
    freq = [0]*(m+2)
    for val in a:
        freq[val] += 1
    
    possible = True
    cur_min = 1
    for val in b:
        while cur_min <= m and freq[cur_min] == 0:
            cur_min += 1
        if val < cur_min:
            possible = False
            break
        freq[val] -= 1
    
    print("YES" if possible else "NO")
```在代码中，我们首先收集每个数字的位置，以便快速访问。 这`freq`数组跟踪每个数字的剩余计数。`cur_min`保留最小的未处理数字，确保我们永远不会尝试将较大的数字移过较小的数字，这是非法的。 内部 while 循环递增`cur_min`每当最小的数用完时。 检查`val < cur_min`确保不会发生阻塞移动。
