 ## 问题理解

 对于每个查询，我们都会得到一个素数$p$。 我们查看来自的所有整数$1$到$p-1$，并且对于每个这样的整数$a$，我们计算它的乘法逆模$p$。 这意味着我们找到了一个数字$b$在范围内$[1, p-1]$这样$a \cdot b \equiv 1 \pmod p$。 因为$p$是素数，每个非零留数都有一个这样的逆元。 

任务是计算所有这些逆的总和：$$\sum_{i=1}^{p-1} i^{-1} \bmod p$$对于每个查询。 

输入由多个独立素数组成，对于每个素数，我们输出这个总和。 

约束条件$T \le 9592$意味着我们无法承受任何每个查询循环$p$， 自从$p$可以很大。 每个查询的模逆的直接计算需要$O(p)$每个测试用例，总体来说太慢了。 

可能陷入幼稚推理的一个微妙之处是思维逆行为的独立性。 例如，计算一些逆并尝试快速推断模式会导致错误的结论，除非使用群结构。 

另一个边缘情况是$p = 2$。 在这种情况下，范围$1$到$p-1$仅包含$1$，它的倒数是它本身，所以总和是$1$。 许多一般的模块化参数隐含地假设$p > 2$，所以这需要单独注意。 

## 方法

 强力方法将通过费马定理使用快速求幂来计算每个模逆$a^{-1} \equiv a^{p-2} \pmod p$，然后对它们求和。 这是正确的，因为每个项都是独立且正确地模计算的$p$。 然而，它执行$p-1$每个测试用例的求幂以及每个求幂成本$O(\log p)$，导致$O(p \log p)$每个查询。 对于多达近万个查询，一旦素数相当大，这就变得不可行。 

关键的结构观察是映射$a \mapsto a^{-1} \bmod p$是集合的排列$\{1, 2, \dots, p-1\}$。 这是有限域中的每个非零元素都有唯一的逆元素这一事实的直接结果，并且应用逆元素两次会返回原始元素。 

因为逆是同一集合上的双射，所以对所有逆求和相当于以不同顺序对所有原始数求和。 这意味着逆的多重集与多重集完全相同$\{1, 2, \dots, p-1\}$。 因此，倒数之和等于：$$1 + 2 + \dots + (p-1) = \frac{(p-1)p}{2}$$因为我们输出这个值模$p$，该表达式立即简化，因为它包含一个因子$p$，使其可除以$p$。 因此结果是$0$模数$p$对于所有奇素数。 唯一的例外是$p = 2$，其中公式退化。 

因此，整个计算减少为每个查询的恒定时间检查。

 ## 算法演练

 我们完全依赖于这样一个事实：反转对非零余数系统以素数取模进行置换。 

1. 读取每个素数$p$来自输入。 每个查询都是独立的，因此不需要预处理。 
2.如果$p = 2$,直接输出$1$。 这是因为唯一的元素是$1$， 和$1^{-1} = 1$。 
3.如果$p > 2$， 输出$0$。 这是因为逆集合只是以下的重新排列$1$到$p-1$，以及完整残差系统模的总和$p$排除零总是折叠为$0 \bmod p$。 

### 为什么它有效

 功能$f(a) = a^{-1} \bmod p$是一个双射$\{1, \dots, p-1\}$。 双射保留多重集，因此它保留模和$p$。 所以：$$\sum_{a=1}^{p-1} a^{-1} \equiv \sum_{a=1}^{p-1} a \pmod p$$右边等于$\frac{p(p-1)}{2}$，可除以$p$，因此符合$0$模数$p$。 这个不变量对于每个素数都成立$p > 2$，保证常数时间解的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        p = int(input())
        if p == 2:
            out.append("1")
        else:
            out.append("0")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实现直接遵循派生的特征。 每个查询都在恒定时间内处理。 唯一的分支条件是特殊情况$p = 2$，必须将其分开，以避免当集合仅包含一个元素时错误地应用模块化取消参数。

 ## 边缘情况

 对于$p = 2$，反转集折叠为单个元素。 该算法在应用一般规则之前显式检查这种情况。 

为了$p > 2$，每个元素在同一范围内都有不同的逆元，因此其和只是排列和。 例如与$p = 3$，我们有逆$1 \leftrightarrow 1$和$2 \leftrightarrow 2$, 给出总和$3 \equiv 0 \pmod 3$。 算法正确输出$0$。 

对于较大的素数，例如$p = 11$，即使各个逆看起来不规则，排列属性保证总和保持固定，并且该算法避免直接计算它们中的任何一个，同时仍然返回正确的结果。
