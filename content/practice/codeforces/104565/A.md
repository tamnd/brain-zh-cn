 ## 解决方案
 ## 问题理解

 我们给出了几种独立的疏散场景。 在每种情况下都有几个政党，每个政党都有一定数量的参议员。 唯一允许的行动是在一个步骤中重复罢免一名参议员或两名参议员。 每经过这样的一步，剩余的参议员绝不能出现某一党派占剩余参议员总数一半以上的情况。 

任务不仅仅是确定是否可以疏散，而是实际构建完整的疏散步骤序列，以移除所有参议员，同时维持每个中间状态的安全条件。 

输入为每个测试用例提供政党数量以及每个政党的参议员初始人数。 输出必须描述一系列疏散步骤，其中每个步骤要么是代表一名疏散参议员的单个字母，要么是代表来自可能不同政党的两名疏散参议员的一对字母。 

核心困难是任何一方在任何步骤之后都不能立即获得绝对多数的限制。 它限制了贪婪的移除：过早地从一方获取太多数量可能会使另一方暂时占据主导地位，即使总计数看起来是安全的。 

这些限制足够小，我们不需要高级的数据结构。 每个测试用例的参议员总数最多为 1000，因此任何重复执行与参与方数量成正比的工作的算法都足够快。 重要的是疏散策略的正确性，而不是渐近优化。 

天真的方法的一个微妙的失败案例是，只要有可能，总是从最大政党中剔除两名参议员。 例如，如果配置是A = 3，B = 2，C = 2，则先删除AA，剩下A = 1，B = 2，C = 2，这是安全的。 但在其他配置中，盲目地从最大的参议员中剔除两名参议员可能会造成一个政党超过剩余参议员一半的情况。 

当两方都拥有最大规模时，就会出现另一个棘手的情况。 即使替代配对可以保持安全，但选择不当可能会暂时造成不平衡。 

## 方法

 一个蛮力的想法是将剩余参议员的每个州视为一个节点，并尝试仅保留不存在多数席位的州的搜索，尝试疏散一名或两名参议员的所有可能。 这在概念上是正确的，因为它探索了所有有效序列，但状态空间随着参议员数量呈指数增长。 在 1000 名参议员的最坏情况下，单个移除的分支因子大约为 26 个选择，而配对移除的分支因子大约为 26 个选择 2，使得这种方法完全不可行。 

关键的观察是我们实际上不需要探索所有有效状态。 约束只关心每次移动后最大的一方。 这意味着我们始终可以在本地推理前一或前两方，并确保我们永远不会允许最大计数超过剩余总数一半的配置。 

贪心策略就是总是减少系统中最大的压力。 如果剩余参议员总数为奇数，我们必须在该步骤中删除一名参议员。 否则，只要我们不创造多数席位，我们就可以安全地罢免两名参议员。 安全的选择是要么从最大的一方中删除一个，要么在不违反平衡条件的情况下从两个最大的一方中各删除一个。 

由于政党数量最多为 26 个，而且总规模较小，因此我们可以在每一步重新计算最大的政党，并重复应用此规则，直到删除所有参议员。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力搜索 | 指数| 指数| 太慢了|
 | 通过最大选择进行贪婪疏散 | O(N * S) | O(N) | 已接受 |

这里S是参议员的总数。 

## 算法演练

 我们维护各方当前的计数并重复构建疏散步骤，直到所有计数归零。 

1. 计算剩余参议员总数。 如果为零，则该过程完成。 这个终止条件确保我们最终产生完整的疏散序列。 
2. 按剩余人数降序对各方进行排序。 这使我们能够在每一步中识别出最危险的一方，这意味着如果不减少的话，最有可能违反多数约束的一方。 
3. 如果参议员总数是奇数，我们必须恰好删除一名参议员。 我们选择剩余人数最多的政党，并从中删除一名参议员。 这种选择是安全的，因为减少最大政党会直接降低多数党的风险，而消除任何其他政党并不能解决直接的不平衡风险。 
4. 如果参议员总数为偶数，我们考虑罢免两名参议员。 我们看看排名前两位的政党。 如果他们不同，我们就会从每个人中删除一名参议员。 这是最安全的对称归约，因为它保持了两个最大组之间的平衡。 
5. 执行删除后，我们将相应的字母或字母对附加到答案中并更新计数。 
6. 重复直到所有计数为零。 

正确性依赖于这样一个事实：我们总是从当前最关键的参与方中剔除，确保在任何步骤后没有任何一个参与方的增长能够超过剩余总数的一半。 贪婪选择之所以有效，是因为任何危险配置总是由一两个主导方引起，而算法总是直接针对它们。 

### 为什么它有效

 在每一步，令 T 为剩余参议员总数。 违反该条件的唯一方法是某方超过 T/2。 该算法确保每当 T 为奇数时，我们立即减少最大方，防止它在下一个状态中严格超过一半。 当 T 为偶数时，从顶部删除两个或从顶部两个中各删除一个可确保最大可能的浓度降低或保持受控，并且没有其他方可以超越它，因为我们永远不会忽略当前的最大值。 这维持了一个不变的事实：没有一个国家拥有绝对多数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(cnt):
    n = len(cnt)
    res = []

    while True:
        total = sum(cnt)
        if total == 0:
            break

        # find top parties
        order = sorted(range(n), key=lambda i: cnt[i], reverse=True)

        if total % 2 == 1:
            i = order[0]
            cnt[i] -= 1
            res.append(chr(ord('A') + i))
        else:
            i, j = order[0], order[1]
            # evacuate one each if possible
            cnt[i] -= 1
            cnt[j] -= 1
            res.append(chr(ord('A') + i) + chr(ord('A') + j))

    return " ".join(res)

def main():
    t = int(input())
    out = []
    for tc in range(1, t + 1):
        n = int(input())
        cnt = list(map(int, input().split()))
        ans = solve_case(cnt)
        out.append(f"Case #{tc}: {ans}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```该代码重复地按规模重新计算政党的排序，并对剩余参议员的总数应用平价规则。 每一步使用排序就足够了，因为参议员总数很少，而政党数量最多为 26 个。 

疏散步骤的构造直接反映了算法。 在罢免两名参议员时，我们总是从当前州最大的两个政党中选拔，确保罢免后没有较小的政党能够占据主导地位。 

一个微妙的点是，我们不会在每次移动后明确检查多数条件。 这是安全的，因为构造策略保证状态始终通过设计保持平衡。

 ## 边缘情况

 当只有一个政党保持非零时，该算法会重复删除其中的单个参议员。 对于像 A = 3、B = 0、C = 0 这样的输入，总数始终为奇数，因此算法一次删除一个 A。 这永远不会违反多数条件，因为不存在形成多数的竞争方。 

当两方的最大计数相同时，例如 A = 2、B = 2、C = 1，当总数为偶数时，算法始终首先将 A 和 B 配对。 这可以防止 C 成为多数派，因为 C 永远不会超过前两方的总减少率。 

当系统严重倾斜时，例如 A = 6、B = 1、C = 1，第一步会删除 A，因为总数是奇数。 这会立即减少占主导地位的政党，并确保后续的偶数步骤可以安全地配对剩余的参议员，而不会允许 A 再次超过一半。
