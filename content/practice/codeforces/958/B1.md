 ## 解决方案

 ## 问题理解

 我们拥有一个由隧道连接的行星网络，形成树状结构。 这意味着每个行星都可以从其他行星到达，并且任何两个行星之间都只有一条简单的路径。 

如果一颗行星通过一条隧道与系统的其余部分相连，则该行星被称为远程行星。 用图的术语来说，这是一个度数等于 1 的顶点，即树中的一片叶子。 

任务只是计算存在多少个这样的遥远行星。 

输入大小最多为 1000 个行星。 即使具有大约 10^6 次操作的二次解也很容易在限制内运行，但问题的结构表明更简单：我们只需要有关每个节点的本地信息，而不需要任何全局遍历或路径计算。 

树中的一些边缘情况很重要：

 如果树是一条像 1 - 2 - 3 - 4 这样的线，那么遥远的行星就是两个端点。 天真的误解可能会尝试考虑“距离”或“深度”，但那是无关紧要的。 

如果树只有两个由一条边连接的节点，则两个节点的度数均为 1，因此两者都是远程的，答案为 2。这里的错误通常来自假设叶子必须“少于两个邻居”，但忘记了度数 1 即使在最小的树中也适用。 

如果树是一个以节点 1 为中心并与所有其他节点相连的星形树，则所有外部节点都是远程的，而中心不是。 

## 方法

 强力方法是将每个节点视为候选节点，并通过扫描每个节点的所有边来计算它有多少个邻居。 对于 N 个节点中的每一个，我们扫描最多 N 个边，给出 O(N^2) 操作。 当 N 达到 1000 时，这大约是 10^6 次检查，这仍然可以接受，但没有必要。 

然而，树的结构使这变得更简单。 每个节点的连接数正是其度数。 我们可以维护一个度数组，而不是重复扫描边缘。 每次我们读取一条边 (u, v) 时，我们都会增加 Degree[u] 和 Degree[v]。 处理完所有边后，我们只计算有多少个节点的度数等于 1。 

关键的见解是“远程”的定义仅取决于直接连接，而不取决于树的任何全局属性。 一旦知道度数，就可以在线性时间内获得答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（扫描每个节点的边缘）| O(N^2) | O(N^2) | O(N + E) | 已接受 |
 | 度计数 | O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 读取行星数量 N。这决定了我们将在度数数组中跟踪多少个节点。 
2. 创建一个大小为 N + 1 的数组，初始化为零。 这将存储每个行星有多少条隧道。 
3. 读取N-1 个隧道中的每一个。 对于 u 和 v 之间的每个隧道，增加 Degree[u] 和 Degree[v]。 这是可行的，因为每条隧道都向两个端点提供了一个连接。 
4. 处理完所有隧道后，从 1 到 N 迭代所有行星。 
5. 计算有多少颗行星的度数等于 1。这些正是远程行星，因为它们通过一条边连接到树。 
6. 输出计数。 

### 为什么它有效

 在树中，每条边对其每个端点的度贡献恰好为 1，并且不存在重复的边或自循环。 因此，度数组充分捕捉了局部连通性的结构。 度数为 1 的节点只有一个邻居，这意味着删除其唯一的边会将其与树的其余部分断开。 没有其他节点可以满足“仅通过一条隧道连接”的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    deg = [0] * (n + 1)

    for _ in range(n - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    ans = 0
    for i in range(1, n + 1):
        if deg[i] == 1:
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```实现完全依赖于跟踪度。 邻接结构从不显式存储，这避免了不必要的内存开销。 边缘循环仅负责更新计数，这确保我们永远不会两次重新访问相同的信息。 最终扫描是对预先计算的度数的直接分类步骤。 

一个常见的错误是尝试执行 DFS 或 BFS 并动态解释“叶数”。 在这里这是不必要的，因为树结构已经完全已知，并且仅度就足够了。

 ## 边缘情况

 二节点树是最脆弱的情况。 输入：```
2
1 2
```处理唯一的边后，deg[1] 和 deg[2] 都变为 1。该算法对两者进行计数，返回 2。这避免了一个常见错误，即解决方案假设叶子必须在“更大”的树中总体上至少有两个邻居。 

直线树测试是否正确检测到端点，无需任何特殊情况逻辑。 对于链来说，只有第一个和最后一个节点恰好积累一个连接。 中间节点总是累积两个，因此它们被正确排除。 

星形树可以确保高度中心节点不会被错误地包含在内。 中心累积 N − 1 个连接并自然被过滤掉，而所有其他连接仍保持为 1 级并被计数。
