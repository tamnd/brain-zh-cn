 ## 问题理解

 我们在平面上有两个小点集，一个代表叛军船只，另一个代表基地。 每艘船必须恰​​好分配给一个基地，并且每个基地也必须恰好接收一艘船，因此分配是两个集合之间的双射。 一旦选择了配对，我们就在匹配对之间绘制直线段，并且我们要求这些线段中没有两条在任何地方相交，除了可能在端点处。 

任务是确定是否存在这种不相交的完美匹配。 

关键的约束是两个集合的大小最多为 10。这立即排除了诸如几何流或重组合之类的任何内容，并强烈表明对排列的指数搜索是可行的。 点为 10 时，双射数为 10！ 大约是360万，检查每个候选匹配的时间复杂度为O(n²)或O(n log n)，这仍然是可行的。 

几何约束引入了微妙的边缘情况。 由于没有三个点共线，因此我们可以避免相交测试变得不明确的简并性，但我们仍然必须处理线段共享端点或在其内部交叉的情况。 

一个天真的但诱人的错误是假设按 x 或 y 坐标排序并贪婪地匹配可以保留平面性。 当本地选择迫使稍后穿越时，这种方法就会失败。 另一个错误的想法是匹配最近的邻居，即使在非常小的配置中也可以轻松地创建交叉。 

例如，考虑形成凸四边形的四个点，在船舶和基地之间交替。 即使沿着边界存在非交叉匹配，按最近距离进行的贪婪配对也可能会产生交叉的对角线。 

## 方法

 蛮力的想法是尝试将船只分配给基地的所有可能的方法。 对于分配给船舶的每个碱基排列，我们构造线段集并检查任何两个线段是否相交。 如果我们找到一项有效的作业，我们就会返回 Yes。 

这是正确的，因为每个有效的解决方案都是基数的排列，因此穷举搜索涵盖了所有可能性。 瓶颈是阶乘增长：对于 R = B = 10，我们测试最多 10！ 分配，并且每个分配都需要 O(n²) 交集检查，导致大约 360 万次 100 次检查，这是临界值，但只有在使用剪枝的情况下，在优化的 Python 中才可以接受。 

然而，我们可以通过注意到该结构是纯粹的组合并且几何形状仅用于验证交叉来做得更好。 由于图尺寸很小，关键的改进是增量地集成相交约束。 我们不是检查完整的排列，而是一次建造匹配的一艘船，并在创建交叉时立即拒绝部分分配。 这将强力排列枚举转换为带有修剪的回溯。 

使修剪有效的观察结果是可以在本地检测到交叉：当我们添加新段时，只需要根据已选择的段进行检查。

 ## 算法演练

1. 将船舶视为按顺序固定，并通过排列生成分配基地，但增量地构造分配，而不是预先枚举完整的排列。 这样可以尽早拒绝。 
2. 维护已使用的基地和迄今为止形成的段的列表。 每个部分将一艘船连接到其指定的基地。 
3. 当尝试为下一艘船分配基地时，请检查新线段是否与任何先前创建的线段相交。 
4. 当且仅当方向满足标准线段相交条件时，两条线段 (a, b) 和 (c, d) 相交。 由于没有三个点共线，因此严格的方向测试就足够了，无需处理共线重叠情况。 
5. 如果新线段不与任何现有线段相交，则递归地继续到下一艘船。 
6. 如果所有舰艇都分配成功，则立即返回成功。 
7. 如果没有赋值导致完全有效匹配，则返回失败。 

### 为什么它有效

 在递归的任何阶段，部分匹配表示一组不相交的线段。 如果新线段与任何现有线段相交，则此部分赋值的任何扩展都无法修复该交叉，因为线段是固定的几何对象。 因此，修剪此类状态并不能消除有效的解决方案。 相反，任何有效的完全匹配都可以逐步构建，而无需创建交集，因此它将在所有修剪步骤中幸存下来。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def orient(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def intersect(a, b, c, d):
    ax, ay = a
    bx, by = b
    cx, cy = c
    dx, dy = d

    o1 = orient(ax, ay, bx, by, cx, cy)
    o2 = orient(ax, ay, bx, by, dx, dy)
    o3 = orient(cx, cy, dx, dy, ax, ay)
    o4 = orient(cx, cy, dx, dy, bx, by)

    return (o1 * o2 < 0) and (o3 * o4 < 0)

def solve():
    R, B = map(int, input().split())
    ships = [tuple(map(int, input().split())) for _ in range(R)]
    bases = [tuple(map(int, input().split())) for _ in range(B)]

    if R != B:
        print("No")
        return

    n = R
    used = [False] * n
    match = [-1] * n

    sys.setrecursionlimit(1000000)

    def dfs(i, segs):
        if i == n:
            return True

        sx, sy = ships[i]

        for j in range(n):
            if used[j]:
                continue

            ok = True
            for (a, b) in segs:
                if intersect(ships[a], bases[b], (sx, sy), bases[j]):
                    ok = False
                    break

            if not ok:
                continue

            used[j] = True
            segs.append((i, j))

            if dfs(i + 1, segs):
                return True

            segs.pop()
            used[j] = False

        return False

    print("Yes" if dfs(0, []) else "No")

if __name__ == "__main__":
    solve()
```该解决方案的核心是船舶索引上的 DFS，为每艘船分配一个唯一的基础。 这`used`数组确保我们保持双射。 

这`intersect`函数使用方向（叉积符号）对标准线段相交测试进行编码。 因为输入不能保证三个共线点，所以我们只需要严格的符号比较。 

递归探索按字典顺序对基数进行赋值。 每次我们分配一个碱基时，我们都会针对所有先前选择的片段进行验证，以确保不会引入交叉。 这种增量验证使得实践中的搜索量保持较小。 

一个微妙的点是，段存储为索引对而不是坐标，这避免了重复的坐标复制，并使交集检查与当前部分匹配保持一致。
