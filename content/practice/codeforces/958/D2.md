 ## 解决方案

 ## 问题理解

 每艘船在最多五维的空间中提供一小部分向量。 从这些向量中，我们考虑所有线性组合，因此每艘船都定义了一个子空间：通过组合其给定的生成器可以达到的所有向量的集合。 

任务是为船舶分配标签，以便两艘船舶在生成的子空间相同时准确地接收相同的标签。 由于不同的输入集可以生成相同的子空间，因此我们必须将每个生成集标准化为其跨越的子空间的规范表示，然后将相同的生成集分组。 

第二个要求不仅仅是分组，而是产生字典顺序上最小的有效标签。 这意味着当我们遇到新的子空间时，我们会分配与早期分配一致的最小可能标签。 

关键的困难在于子空间不能直接与它们的原始生成器进行比较。 两组不同的向量可能看起来无关，但实际上跨越同一空间。 一个天真的尝试是通过求解每对船之间的线性系统来比较跨度，但这变得太慢了，因为船可能多达 30,000 艘。 

维度最多为五是关键的约束。 它允许我们在每艘船的恒定时间内使用高斯消去法计算每个子空间的稳定规范基础。 

当船舶提供冗余向量或向量是其他向量的线性组合时，就会出现微妙的边缘情况。 例如，在第二维中，集合`{(1,0), (2,0)}`和`{(1,0)}`定义相同的子空间。 任何正确的解决方案都必须彻底消除冗余； 否则，散列原始输入将错误地将等效子空间视为不同的。 

另一个问题是排序：两个规范基必须逐字节（或逐坐标）相同才能进行散列。 即使同一子空间的不同基础选择也会破坏分组，因此表示必须是确定性的。 

## 方法

 直接方法通过检查每对船的跨度是否相等来比较它们。 为了测试两个子空间的相等性，我们将检查一个子空间的每个生成器是否位于另一个子空间的范围内，这需要求解大小最多为 5 的线性系统。 该测试的时间是恒定的，但有 O(m²) 对，在最坏的情况下会导致大约 4.5 亿次比较，这太慢了。 

更好的观点是将每组向量转换为其子空间的规范表示。 由于维数很小，我们可以对每个集合独立地进行高斯消元来提取基。 一旦每个子空间都由唯一的简化基表示，相等性就简化为这些基的相等性。 

关键的观察结果是固定维度中的高斯消除产生确定性的简化行梯形形式。 如果我们对向量进行一致排序或处理，则无论输入冗余或顺序如何，每个子空间都会折叠成相同的规范基。 

标准化后，我们可以对每个基础进行哈希处理（例如，将其转换为元组的元组），并使用字典按首次出现的字典顺序分配组 id。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力成对跨度检查 | O(m²·d³) | O(1) | O(1) | 太慢了|
 | 高斯消去+哈希| O(m·d³) | O(米) | 已接受 |

 ## 算法演练

 我们在最多五维的向量空间中工作，因此所有线性代数运算都是恒定大小的。 

1. 对于每艘船，读取其 k 个向量并将它们存储为工作列表。 目标是将这个列表转换为其跨度的基础。 
2. 对这些向量执行高斯消元法，逐步构建缩减基。 我们维护一个列表`basis`最初是空的。 
3. 对于船舶输入中的每个向量，尝试将其插入到基础中。 我们使用现有的基向量来减少向量，消除沿着先前选择的枢轴的分量。 如果它变为非零，它将贡献一个新的独立方向并作为新的基向量添加。 
4. 处理完所有向量后，我们对所得基础进行归一化，使其具有确定性形式。 标准选择是确保枢轴位置一致并且向量相对于彼此减少。 这保证了相同的子空间总是产生相同的基数。 
5. 将基础转换为可散列结构，例如整数元组的元组，保留主元发现的顺序。 
6. 使用字典将此规范表示映射到组 ID。 如果之前已经见过这个基础，则重用它的id； 否则按升序分配一个新的。 
7. 按照输入顺序输出分配的id。 

这种排序策略确保字典最小性的原因是我们总是在第一次遇到时分配最小的可用标签，并且永远不会重新标记较早的船只。 

### 为什么它有效

 正确性取决于高斯消去法在固定的确定性规则下执行时为每个子空间产生规范基础的事实。 添加的每个向量要么增加跨度，要么是冗余的，并且冗余向量被完全消除。 因此，当且仅当两组向量的约化基完全重合时，它们才会生成相同的子空间。 由于基础构造仅取决于跨度而不取决于输入顺序，因此它在同一子空间的不同表示下是不变的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def normalize(vectors, d):
    basis = []
    for v in vectors:
        v = v[:]  # copy
        for b in basis:
            # eliminate component along b
            # find pivot position
            for i in range(d):
                if b[i] != 0:
                    piv = i
                    break
            if v[piv] != 0:
                factor = v[piv] / b[piv]
                # avoid floats: integer elimination
                # scale subtraction
                for i in range(d):
                    v[i] = v[i] * b[piv] - b[i] * v[piv]
        if any(x != 0 for x in v):
            # normalize v
            # find pivot
            for i in range(d):
                if v[i] != 0:
                    piv = i
                    break
            # make pivot positive
            if v[piv] < 0:
                for i in range(d):
                    v[i] = -v[i]
            basis.append(v)
    # final cleanup: sort by pivot for determinism
    basis.sort(key=lambda x: next(i for i, val in enumerate(x) if val != 0))
    return tuple(tuple(row) for row in basis)

def solve():
    m, d = map(int, input().split())
    mp = {}
    res = []
    next_id = 1

    for _ in range(m):
        k = int(input())
        vecs = [list(map(int, input().split())) for _ in range(k)]
        key = normalize(vecs, d)
        if key not in mp:
            mp[key] = next_id
            next_id += 1
        res.append(mp[key])

    print(*res)

if __name__ == "__main__":
    solve()
```该代码独立处理每艘船。 这`normalize`函数通过增量插入向量并消除相关方向来构建基础。 整数运算通过在消除过程中进行缩放而不是除法来避免浮点不稳定。 

主元选择确保每个基向量都有一个明确定义的前导非零坐标。 最后的排序保证了基本向量的一致排序，这对于散列是必要的。 

字典将规范表示映射到 id，自动保留首次出现的顺序，这在字典顺序上提供了最小的标签。

 ## 边缘情况

 一个典型的失败案例是向量仅因缩放而不同。 例如`(1,0)`和`(2,0)`标准化后必须相同。 消除步骤确保了这一点，因为`(2,0)`减少到标量倍数`(1,0)`当插入基础时变得多余。 

当向量以不明显的方式线性相关时，就会出现另一个问题。 在第三维中，`(1,0,0)`,`(0,1,0)`,`(1,1,0)`全部与前两个向量跨越同一平面。 该算法消除了第三个向量，因为它在投影到现有基础上后变为零，因此最终表示保持稳定。 

第三个微妙的情况是输入向量的顺序不一致。 由于高斯消元法增量构建基础，然后按枢轴位置排序，因此同一生成集的任何排列都会产生相同的最终规范基础，从而确保不同输入之间的分组一致。
