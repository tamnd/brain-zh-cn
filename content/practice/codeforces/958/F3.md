 ## 解决方案

 ## 问题理解

 我们得到了多组光剑，其中每把剑都属于其中一个`m`颜色。 相同的颜色意味着相同的物体，所以我们只关心每种颜色选择了多少把军刀，而不是具体的绝地武士提供了它们。 

任务是计算通过精确选择可以形成多少种不同的“颜色计数配置”`k`给定的军刀`n`，其中每个配置都是一个长度向量`m`描述每种颜色选择了多少把军刀。 如果每种颜色在两个选择中出现相同的次数，则认为两个选择是相同的。 

同样，对于每种颜色`i`，如果出现`cnt[i]`在输入中，我们选择一个整数`x_i`这样`0 ≤ x_i ≤ cnt[i]`和`sum x_i = k`。 答案是此类有界整数解的数量。 

限制条件很大：`n`最多可达 200,000，这会立即排除任何枚举子集或对颜色和计数使用嵌套循环的方法。 甚至`O(nk)`在最坏的情况下太慢，因为两者都可能很大。 

一个微妙的问题是，相同的颜色会产生难以区分的贡献。 元素上的朴素子集 DP 会过度计算相同颜色的排列，除非仔细压缩为频率。 

当许多绝地武士拥有相同的颜色时，就会出现另一种极端情况。 例如，如果所有`n`军刀的颜色为 1，那么答案就是 1，如果`k ≤ n`，否则为 0。任何独立处理元素的方法都会错误地将相同项目的组合视为不同的。 

## 方法

 一个直接的表述是根据生成函数来思考。 每种颜色`i`贡献一个多项式：```
P_i(x) = 1 + x + x^2 + ... + x^{cnt[i]}
```选择一个有效的集合对应于从每个多项式中选取一项并将它们相乘，以及`x`所得结果是所选军刀的总数。 因此答案是系数`x^k`在：```
P_1(x) * P_2(x) * ... * P_m(x)
```蛮力方法会将这些多项式一一相乘，其中将两个大小的多项式相乘`a`和`b`成本`O(ab)`。 在最坏的情况下，如果许多颜色有很大的计数，这会退化为大致`O(n^2)`操作，这太慢了。 

关键的观察是每个多项式都是一个连续的块。 这使得卷积结构高度规则：我们重复乘以“全一”段，这可以使用基于 FFT 的卷积来有效处理。 

我们不是以简单的方式顺序相乘，而是执行分而治之的卷积树。 在每个合并步骤中，我们使用 FFT 卷积来组合两个中间多项式。 这将总工作量减少到`O(k log k log m)`或类似，具体取决于实现细节，因为多项式次数的界限为`k`。 

FFT 之所以有效，是因为卷积恰好对应于组合不同颜色的独立选择。 每个合并步骤都保留多项式编码有效部分选择的不变量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nk) 或更差 | O(k) | 太慢了 |
 | 分而治之 FFT | O(k log k log m) | O(k log k log m) | O(k) | 已接受 |

 ## 算法演练

 我们将输入压缩为频率计数`cnt[color]`。 

我们将每种颜色解释为多项式`P_i(x)`长度`cnt[i] + 1`，所有系数都等于 1。 

### 步骤

 1. 计算每种颜色出现的次数。 这将输入转换为`m`频率值。 此步骤消除了对排序的依赖，并将问题简化为独立的组合块。 
2. 构建一个多项式列表，每种颜色一个，其中每个多项式表示为长度为 1 的数组`cnt[i] + 1`。 这对在 0 和 0 之间进行选择的所有可能方式进行编码`cnt[i]`那种颜色的军刀。 
3. 使用分治法递归合并多项式。 在每个递归节点，将列表分成两半，计算它们的组合多项式，并对它们进行卷积。 这种结构保证了FFT使用的平衡并避免了重复的重新计算。 
4. 使用 FFT 模 1009 执行卷积。由于模数很小且不适合 FFT，因此我们使用数论变换风格改编或采用舍入后进行模数缩减的复杂 FFT。 
5.全部合并后，提取系数`x^k`。 该值是有效选择的数量。 

分治法很重要的原因是，在链中重复相乘多项式会重复地将大型中间结果与不断增长的成本进行卷积。 平衡合并可控制多项式大小。 

### 为什么它有效

 在每个合并步骤中，为一段颜色存储的多项式准确地表示从该段中选择给定军刀总数的方法数。 当两个片段组合在一起时，卷积正确地计算出分割总数的所有方式`k`分为左右部分的贡献。 这保持了一个不变量，即 次数的多项式系数`t`等于有效选择的数量总和`t`对于该部分。 当整个树被合并时，这个不变量直接给出所有组合颜色的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1009

def fft_convolve(a, b, mod=MOD):
    n, m = len(a), len(b)
    res = [0] * (n + m - 1)
    for i in range(n):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(m):
            res[i + j] = (res[i + j] + ai * b[j]) % mod
    return res

def merge(polys):
    if len(polys) == 1:
        return polys[0]
    mid = len(polys) // 2
    left = merge(polys[:mid])
    right = merge(polys[mid:])
    return fft_convolve(left, right)

def solve():
    n, m, k = map(int, input().split())
    arr = list(map(int, input().split()))

    cnt = [0] * (m + 1)
    for x in arr:
        cnt[x] += 1

    polys = []
    for i in range(1, m + 1):
        if cnt[i] > 0:
            polys.append([1] * (cnt[i] + 1))

    if not polys:
        print(1 if k == 0 else 0)
        return

    res = merge(polys)
    if k < len(res):
        print(res[k] % MOD)
    else:
        print(0)

if __name__ == "__main__":
    solve()
```该实现首先将输入压缩为频率计数，删除绝地武士的身份并仅保留颜色多样性。 每种颜色都贡献一个全多项式，代表该颜色的所有有效选择。 

这`merge`函数构建平衡递归树，以便尽可能控制多项式大小。 每个卷积将两个部分分布组合成总计数的新分布。 

为了清楚起见，卷积本身以简单的嵌套循环形式编写。 在完全优化的解决方案中，这将被 FFT 或 NTT 取代，以在时间限制下有效处理大量输入。 

最终的答案就是索引处的系数`k`，只要它存在。 

## 工作示例

 ### 示例 1

 输入：```
4 3 2
1 2 3 2
```频率：`cnt = [0, 1, 2, 1]`多项式：`P1 = [1, x]`

`P2 = [1, x, x^2]`

`P3 = [1, x]`我们跟踪卷积：

 | 步骤| 多项式状态 |
 | --- | --- |
 | P1 | [1, 1] |
 | P2 | [1, 1, 1] |
 | P1*P2 | [1,2,2,1]|
 | 决赛（*P3）| [1, 3, 4, 3, 1] |

 我们需要系数`x^2`，即`4`。 

这表明存在选择两把军刀的多个分布：要么来自不同的颜色，要么都来自相同的颜色，并且卷积正确地聚合了所有情况。 

### 示例 2

 输入：```
3 2 3
1 1 2
```频率：`cnt = [0, 2, 1]`多项式：`[1, x, x^2]`和`[1, x]`| 步骤| 多项式状态 |
 | --- | --- |
 | P1 | [1, 1, 1] |
 | P2 | [1, 1] |
 | 决赛| [1,2,2,1]|

 系数`x^3`是`1`，对应选择所有军刀。 

这证实了仅存在一个完整选择的严格边界情况下的正确性。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 朴素卷积中的 O(nk)，优化后的 O(k log k log m) | 每次合并最多组合 k 度的多项式分布 |
 | 空间| O(k) | 仅存储 k 次以下的 DP 多项式 |

 ## 边缘情况

 当所有军刀共享单一颜色时，就会出现严重的边缘情况。 例如，如果输入是`n = 5`,`m = 1`， 和`k = 3`，唯一有效的配置是从该单个池中恰好选择 3 个。 该算法构建一个多项式`[1,1,1,1,1,1]`，直接读取索引3处的系数，为1，与期望相符。 

另一个边缘情况是当`k = 0`。 无论颜色分布如何，都存在一种不选择任何内容的方法，对应于从每个多项式中选择零。 卷积通过在整个合并过程中始终保持常数项 1 来保留这一点。 

第三种边缘情况是当`k`超过可用军刀总数。 在这种情况下，所有多项式的最大次数都小于`k`，因此系数查找落在结果数组之外并正确返回 0。
