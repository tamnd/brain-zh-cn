 ## 解决方案
 ## 问题理解

 我们得到一个整数序列并要求将其精确地切割成$k$连续的非空段。 每个元素必须恰好属于一个段，并且元素的顺序被保留。 

对于任何段，我们取其元素的总和，然后以模数减少该总和$p$。 分区的总分是这些每段模值的总和。 任务是选择$k-1$削减位置，使总分最大化。 

问题的关键在于段和仅通过其余数模相互作用$p$，而剪切本身必须尊重连续性。 这种组合建议采用前缀和段数的动态编程结构。 

这些约束足够强大，足以排除任何指数或二次 k×n×n 方法。 和$N \le 20000$和$k \le 50$，大约有一个解$O(N^2 k)$已经太慢了，因为它会达到$2\times 10^{10}$运营。 This pushes us toward an$O(N k)$或者$O(N k p)$优化过渡的风格重复。 

当段总和超过时，就会出现一个微妙的问题$p$。 幼稚的实现可能会重复重新计算段总和，或者忘记只需要前缀总和来计算任何段总和$O(1)$。 

另一个陷阱是误解民主党的方向。 由于段是连续的，我们必须确保当我们决定最后一个段结束于位置$i$，我们正确地考虑了所有可能的先前切割位置。 

粗心推理失败的一个小例子是$k = 1$。 答案很简单$\sum A \bmod p$，但天真的 DP 可能会错误地强制至少进行一次削减和少算。 

## 方法

 暴力方法会尝试所有方法来放置$k-1$之间切入$N-1$可能的差距。 然后，每个分区将计算段总和并应用模数$p$。 分区数为$\binom{N-1}{k-1}$，即使对于中等强度来说，这也是一个天文数字$N$，并计算每个分数的成本$O(N)$，导致运行时不可行。 

一旦我们观察到段的值仅取决于其模数之和，问题的结构就变得易于管理$p$，并且可以使用前缀和快速计算段和。 这表明我们使用一个 DP 来跟踪具有固定数量段的数组前缀的最佳可实现分数。 

让$dp[j][i]$使用第一个表示最大分数$i$元素分裂成$j$段。 计算$dp[j][i]$，我们尝试所有可能的先前切点$t < i$, 治疗$[t+1, i]$作为最后一段。 分部贡献为$(prefix[i] - prefix[t]) \bmod p$。 

这将问题简化为经典的分区 DP。 然而，天真的转变是$O(N^2 k)$，这太慢了。 关键的优化是修复$j$和处理$i$从左到右，保持最佳可能值$dp[j-1][t] - prefix[t] \bmod p$-调整结构，但由于模数很小（$p \le 100$），我们可以通过跟踪残基类别的最佳值来优化转换。 

我们重写转换：$$dp[j][i] = \max_{t < i} \left( dp[j-1][t] + (prefix[i] - prefix[t]) \bmod p \right)$$扩展模项依赖于$prefix[i] \bmod p$和$prefix[t] \bmod p$。 自从$p$很小，我们为每个残基保持最佳值$prefix[t] \bmod p$，允许每个状态进行恒定时间转换。 

这会将每个 DP 层折叠为$O(Np)$，给出总复杂度$O(Nkp)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\binom{N}{k} \cdot N)$|$O(N)$| 太慢了|
 | 天真的DP |$O(N^2 k)$|$O(Nk)$| 太慢了|
 | 优化 DP（mod 类）|$O(N k p)$|$O(Nk)$| 已接受 |

 ## 算法演练

 1. 计算前缀和$pref[i]$， 在哪里$pref[i]$是第一个的总和$i$元素。 这允许恒定时间段总和查询。 
2.定义一个DP表，其中$dp[j][i]$表示使用第一个可达到的最高分数$i$元素分裂成$j$段。 
3. 初始化$dp[1][i] = pref[i] \bmod p$。 这对应于不进行切割并且整个前缀是一个段的情况。 
4. 对于每个段数$j$从 2 到$k$，计算所有值$i$。 
5.对于固定的$j$，维护一个辅助数组$best[r]$对于残留物$r \in [0, p-1]$。 该数组存储了最好的值$dp[j-1][t] - pref[t] + r\cdot p$- 隐式调整贡献结构，但在操作上我们只需要跟踪：$$dp[j-1][t] - pref[t] + pref[t] \bmod p$$分组依据$pref[t] \bmod p$。 
6. 当我们扫地时$i$从左到右，更新$best[pref[i] \bmod p]$使用$dp[j-1][i] - pref[i]$。 
7. 计算：$$dp[j][i] = pref[i] \bmod p + \max_{r}(best[r] + r)$$在哪里$r$对应于$pref[t] \bmod p$。 
8.全部处理完毕后$i$，继续进行下一个段计数。 

### 为什么它有效

 DP 不变量是对于每个$j$和$i$，我们已经考虑了所有可能的最后切割位置$t < i$。 段的贡献仅取决于前缀和的差异，并且模运算减少了对剩余类的完整前缀值的依赖。 通过维护每个残基的最佳可能的先前状态，我们隐式评估所有有效的切割位置而不枚举它们。 这确保了每个有效分区在最大化时仅被表示一次。
