 ## 解决方案

 ## 问题理解

 我们有两个大小相同的正方形网格$N \times N$，其中每个单元格要么是星星，要么是空白区域。 任务是确定如果允许我们使用正方形的刚性对称性来变换其中一个网格，则这两个网格是否可以表示相同的图案。 

允许的变换对应于将网格物理旋转 90、180 或 270 度，或者水平或垂直翻转。 在应用这些操作的任何序列之后，如果一个网格可以逐个单元地与另一个网格相同，则它们被认为是相同的配置。 

从计算的角度来看，每张地图只是一个字符矩阵。 问题是两个矩阵在一组有限的几何变换下是否等价。 

约束条件$N \le 10$非常小。 即使是三次操作或涉及显式尝试所有转换的操作在这种规模下也是微不足道的。 这立即告诉我们，我们不需要散列技巧、搜索修剪或渐近最优匹配技术。 直接模拟所有候选变换就足够了。 

一个微妙的点是转换是离散的但可以重叠。 例如，水平翻转后垂直翻转相当于 180 度旋转。 如果在不了解闭包的情况下尝试仅实现转换的子集，则很容易错过有效的匹配。 

一些边缘情况值得牢记。 如果两个网格已经相同，则不需要转换，答案应该是“是”。 如果模式具有高度对称性，例如所有单元格都相同，则每个转换都会保留相等性，这可能会错误地掩盖实际上未正确应用转换的实现中的错误。 另一个失败案例是尝试仅比较旋转而不比较翻转； 例如，图案及其镜像并不仅通过旋转而相关。 

## 方法

 蛮力的想法很简单：枚举第一个网格上允许的每个转换，应用它，并将结果与第二个网格进行比较。 由于网格最多$10 \times 10$，每次比较的成本$O(N^2)$，可以忽略不计。 唯一的问题是必须检查多少个转换。 

一个幼稚的错误是尝试任意的翻转和旋转序列，这可能会生成无限的搜索空间。 然而，正方形的对称结构是封闭且有限的。 任何允许的旋转和翻转序列都会简化为八种不同变换之一：四种旋转（0、90、180、270 度）及其镜像对应项。 这是正方形的二面群。 

关键的观察是，我们可以直接构建这八个结果网格中的每一个并比较它们，而不是探索序列。 这将组合搜索变成了常数因子枚举。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有转换序列）| O(∞ 概念上，实际上无界) | O(N^2) | O(N^2) | 太慢/不明确|
 | 明确尝试所有 8 种对称性 | O(8·N^2) | O(8·N^2) | O(N^2) | O(N^2) | 已接受 |

 ## 算法演练

 我们显式生成第一个网格的所有不同的转换版本，并检查是否有任何与第二个网格匹配。 

1. 读取两个网格并将它们存储为字符串列表。 
2.定义一个通过映射单元格顺时针旋转网格90度的函数$(i, j)$到$(j, N-1-i)$。 这是基本的构建块，因为所有旋转都可以从重复应用中导出。 
3. 构建网格的四个旋转：0 度（原始）、90 度、180 度和270 度。 每个旋转都是使用相同的映射规则从前一个旋转获得的。 
4. 对于每个旋转的网格，还构建其水平反射。 水平翻转会反转每一行。 
5. 每次旋转及其翻转版本总共给出 8 个候选网格。 
6. 将每个候选网格与目标网格进行比较。 如果任何匹配项逐个单元格相同，则立即输出 Yes。 
7. 如果检查完所有 8 种可能性后没有转换匹配，则输出 No。 

我们不混合任意序列的原因是允许的操作的任何组合总是会折叠成这八种规范形式之一。 直接枚举它们可以避免冗余并保证完整性。 

### 为什么它有效

 正方形的变换形成一个大小为 8 的闭群。每个允许的操作都是该群的一个元素，并且组合永远不会在该群之外产生任何内容。 通过为每个组元素生成一个代表，我们确保第一个网格的每个可能的变换版本都被恰好考虑一次。 这保证了如果在任何允许的操作序列下存在等价项，它将出现在我们的枚举中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def rotate(grid):
    n = len(grid)
    return ["".join(grid[n - 1 - r][c] for r in range(n)) for c in range(n)]

def flip_h(grid):
    return grid[::-1]

def solve():
    n = int(input())
    a = [input().strip() for _ in range(n)]
    b = [input().strip() for _ in range(n)]

    variants = []

    cur = a
    for _ in range(4):
        variants.append(cur)
        variants.append(flip_h(cur))
        cur = rotate(cur)

    for v in variants:
        if v == b:
            print("Yes")
            return

    print("No")

if __name__ == "__main__":
    solve()
```该解决方案依赖于两个原始转换。 旋转函数通过从下到上读取原始网格的列来构建新的网格，这相当于顺时针旋转 90 度。 翻转函数反转行顺序，产生垂直反射； 根据解释，这已经足够了，因为旋转与此翻转相结合会生成所有镜像情况。 

我们迭代地生成旋转，以便每个新网格都是从前一个网格派生出来的，避免了对原始网格的重复重新计算。 这使实现变得简单并减少了索引错误的机会。 

比较是通过行列表的直接字符串相等来完成的，这是安全的，因为每行都完全编码网格结构。

 ## 边缘情况

 最小的$1 \times 1$grid always matches itself regardless of transformation. 该算法自然地处理这个问题，因为旋转和翻转操作返回相同的单单元格网格，因此如果字符匹配，唯一的变体等于目标。 

Highly symmetric grids, such as those filled entirely with 'X', produce identical variants under all transformations. In such cases, every generated candidate equals the target, so the first comparison succeeds immediately. This does not affect correctness because the algorithm does not assume uniqueness of transformations, only existence.

 Another subtle case is when the correct transformation is a combination like flip followed by rotation. 枚举仍然捕获它，因为组合变换显示为旋转翻转循环期间生成的八个规范变体之一。
