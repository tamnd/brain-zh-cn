 ## 解决方案
 ## 问题理解

 我们有一棵树$N$节点，意味着每一对节点都由一条简单路径连接。 我们可以选择$K$节点作为“活动站”。 一旦被选择，一个节点就会受到控制，并且位于任意两个选定节点之间的简单路径上的任何节点也将受到控制。 

因此，最终的受控集不仅仅是所选节点本身，而是连接它们的最小子树内的所有内容。 用树语言来说，这正是由所选节点导出的 Steiner 树。 

对于每一个$K$从$1$到$N$，我们必须确定该导出子树的最大可能大小。 

关键的困难在于所选节点的结构比它们各自的位置更重要。 两个相距较远的节点可能控制许多中间节点，而集群节点的贡献很小。 

约束很严格：$N \le 10^5$。 任何尝试所有子集的方法都是不可能的，因为即使选择$K$节点已经给出$\binom{N}{K}$的可能性。 甚至二次或$O(N^2)$施工不会通过。 这迫使解决方案在大致线性或接近线性的时间内构建全局结构信息。 

当树是一条线时，会出现微妙的边缘情况。 在这种情况下，选择端点可以最大化覆盖范围，并且每个端点的答案$K$成为连续段长度。 任何假设局部扩张而不考虑全局直径结构的不正确的贪婪在这里都会失败。 

另一个边缘情况是星形树。 选择任何叶子都会立即扩大中心的覆盖范围，因此与路径相比，最佳集的行为非常不同。 这表明没有像“选择最高度节点”这样的单一局部启发式方法能够一致地工作。 

## 方法

 直接的暴力方法会尝试所有的选择$K$节点，计算每个选择的斯坦纳树大小，并取最大值。 计算固定集的 Steiner 树可以通过标记节点并运行虚拟树构建或 DFS 剪枝来完成，即$O(N)$每个子集。 然而，子集的数量已经是指数级的，即使对于$N = 30$，更不用说$10^5$。 

问题的结构提出了不同的观点。 受控集仅取决于通过在两侧选择节点来“激活”哪些边。 当且仅当所选节点不完全包含在该边的一侧时，每条边才会对答案做出贡献。 

这将问题从选择节点转变为最大化所选集合“切割”的边数。 挑战在于边在全局范围内交互：放置一个节点会同时影响许多边。 

关键的见解是通过树的层次分解来重新解释节点的贡献。 如果我们构建质心分解，每个节点都会参与对数个质心分量。 每次从质心考虑一个节点时，它都会贡献一个等于其到该质心的距离的值。 这些距离捕获节点距树的不同结构分区的“距离”。 

一个关键事实是，最佳控制尺寸$K$节点可以表示为选择$K-1$这些贡献可以最大化一个节点基础上的总增益。 直观上，我们从单个根节点开始，每个附加的选定节点在质心层次结构中贡献其最佳“传播值”。 对这些贡献进行排序可以提供计算所有答案的直接方法。 

这将问题简化为收集所有质心距离贡献、对它们进行排序并获取前缀和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 节点集上的暴力破解 | 指数| O(N) | 太慢了|
 | 质心分解+排序贡献|$O(N \log N)$| O(N \log N) | O(N \log N) | 已接受 |

 ## 算法演练

 ### 1.构建树的质心分解

 我们递归地找到子树的质心。 每个节点都与质心祖先链相关联。 这种分解确保树的每条边都以对数数量的级别表示。 

我们使用质心分解的原因是它将树分成平衡的部分，使我们能够以结构化的多尺度方式测量距离。 

### 2. 计算每个节点的质心距离贡献

 对于每个质心$c$，我们计算距离$c$到其组件中的所有节点。 对于每个节点$u$，我们记录该值$\text{dist}(u, c)$。 

因此，每个节点积累多个值，每个质心祖先一个。 

这些值表示当与分解的不同部分中选择的其他节点结合时，节点提供了多少“新范围”。 

### 3. 将所有贡献收集到全局列表中

 我们将所有记录的质心距离收集到一个数组中。 这个数组有大小$O(N \log N)$，因为每个节点最多出现在对数个质心层中。 

每个值代表选择树中分离良好的节点时的潜在增量增益。 

### 4. 按降序对贡献进行排序

 我们对列表进行排序，以便将大的结构性贡献放在第一位。 选择与大距离相对应的节点可以最大化斯坦纳树扩展的速度。 

这一步将结构优化问题转化为贪婪累积问题。 

### 5. 使用前缀和构建答案

 我们解读选择$K$节点作为根贡献加上最好的$K-1$额外的收益。 所以：$$\text{answer}[K] = 1 + \sum_{i=1}^{K-1} \text{top gains}[i]$$我们计算排序数组的前缀和并输出所有值。 

### 为什么它有效

 每个质心级别捕获节点如何有助于将树分成独立的区域。 选择一个节点所带来的好处与其帮助连接的质心分区数量成正比。 分解保证了树中的每个结构增益在每个分离级别都准确地表示一次。 排序确保我们始终首先采取最有影响力的分离，这与最大化诱导斯坦纳树中边数的组合结构相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    size = [0] * n
    dead = [False] * n
    contrib = []

    def dfs_size(u, p):
        size[u] = 1
        for v in g[u]:
            if v != p and not dead[v]:
                dfs_size(v, u)
                size[u] += size[v]

    def dfs_centroid(u, p, tot):
        for v in g[u]:
            if v != p and not dead[v]:
                if size[v] > tot // 2:
                    return dfs_centroid(v, u, tot)
        return u

    def dfs_collect(u, p, c, d):
        contrib.append(d)
        for v in g[u]:
            if v != p and not dead[v]:
                dfs_collect(v, u, c, d + 1)

    def build(croot):
        dfs_size(croot, -1)
        c = dfs_centroid(croot, -1, size[croot])
        dead[c] = True

        dfs_collect(c, -1, c, 0)

        for v in g[c]:
            if not dead[v]:
                build(v)

    build(0)

    contrib.sort(reverse=True)

    pref = [0]
    for x in contrib:
        pref.append(pref[-1] + x)

    ans = []
    for k in range(1, n + 1):
        if k - 1 <= len(contrib):
            ans.append(1 + pref[k - 1])
        else:
            ans.append(1 + pref[-1])

    print(*ans)

if __name__ == "__main__":
    solve()
```该实现构建了质心分解，收集每个质心级别的距离贡献，然后在全局范围内聚合它们。 质心DFS确保每个节点只被处理$O(\log N)$次，这将总工作量控制在限制范围内。 

排序步骤是唯一的超线性操作，并且在复杂性中占主导地位。 前缀和然后直接回答所有值$K$。 

必须注意在每个质心步骤重置子树大小，并避免遍历已删除的组件，否则分解会中断并且节点会被重复计算。

 ## 边缘情况

 单节点树很简单：质心分解立即返回一个没有边的节点，并且贡献列表为空。 算法输出$1$，匹配唯一可能的受控集。 

路径形树展示了长距离结构的重要性。 质心分解收集从端点到中心不断增加的距离贡献。 排序可确保选择更多节点以正确的顺序沿链扩展覆盖范围，从而产生增大的斯坦纳树大小。 

星形树则表现出相反的极端。 所有叶子与中心的距离为 1，因此贡献是均匀的。 当选择每个新叶子时，排序的数组会导致受控大小的线性增长，这与每个新叶子强制包含中心并每次将诱导子树增加一个边缘的事实相匹配。
