 ## 解决方案
 ## 问题理解

 我们得到一个由变量 a 到 h 以及具有标准优先级规则的运算符 not、and、and or 构建的布尔公式。 该公式定义了哪些变量子集被视为有效。 每个变量对应于可能在场或不在场的乐队成员。 

任务不是直接评估公式。 相反，我们必须在网格内构建物理布线系统。 网格在左上角和右上角的单元格处有两个特殊端点，其思想是这两个端点最初通过连续的导线路径连接。 然而，这条路径可能会被锁中断。 乐队成员携带一把钥匙，可以打开所有标有其字母的锁。 如果存在一组成员，他们会集体打开与其变量对应的所有锁，并且两个端点之间的连接可能会根据打开的锁而被阻塞或解除阻塞。 最终条件是当且仅当布尔公式在所选分配下计算结果为 true 时，才应连接两个端点。 

网格被限制为最多 50 x 50，并且必须使用一组非常有限的图块来构建，这些图块的行为类似于电线和交叉点。 公式中出现的每个字母都可能作为锁组件出现在网格中。 

关键的困难在于这不是一个标准的可满足性检查或评估问题。 这是一个构造问题：我们必须将任意布尔公式编码到具有受控连接的平面布线小工具系统中。 

网格很小的限制迫使我们建立公式的组合表示，而不是直接模拟它。 尝试显式表示所有分配或所有路径的简单方法是不可能的，因为即使只有 8 个变量，也有 256 个分配，并且网格的结构必须同时对所有这些分配进行编码。 

不可构造的公式会产生微妙的边缘情况。 例如，在该系统中无法实现独占或行为，因为连接模型对于以无法强制执行奇偶校验约束的方式打开锁而言是单调的。 像 xor b 这样的公式会失败，因为打开两条路径可能会以意想不到的方式恢复连接，并且系统无法可靠地强制执行“恰好一个”语义。 这体现在声明暗示有些公式是不可能的。 

## 方法

 一种直接的方法是将接线网格模拟为图形，并尝试为每个子公式分配一个其连通性与其真值表相匹配的子图。 对于每个操作员，我们都会尝试设计一个小工具。 例如，对于 和 ，我们希望两个子电路都需要连接，而对于 或 ，我们希望其中一个子电路就足够了。 

如果我们尝试强力构建，我们将为每个子公式递归构建一个完整的网格，并尝试在所有组件之间布线。 问题是，这会导致大小爆炸，因为每个子公式可能需要大型子网格的新副本，并且共享结构变得困难。 更糟糕的是，确保所有分配的正确性需要对所有路径进行全局推理，这在 50 x 50 约束内是不可行的。 

关键的观察结果是，这从根本上来说是一个具有几何嵌入约束的单调电路构造问题。 网格的行为就像一个图表，其中线是边，锁根据变量分配充当条件边删除。 这符合一个标准的想法：我们想要构建一个电路，其中两个端子之间的连接代表公式值。

我们可以为每个子公式递归地构建一个具有两个端子的电路。 每个子公式对应一个具有输入端子和输出端子的小工具。 对于变量，我们放置单个锁控制连接。 对于 not、and、and or，我们使用网格中的串行和并行组合来组合这些小工具。 

关键的见解是 和 对应于串行连接，或者对应于并行连接，而不对应于可以通过使用固定结构交换连接路径来模拟的锁反转小工具。 然而，只有当公式在结构意义上单调时，该构造才有效，并且无法嵌入某些非单调模式（例如类似异或的行为）。 这导致不可能输出的可能性。

 ## 算法演练

 我们首先使用标准优先规则将布尔公式解析为抽象语法树。 树中的每个节点代表一个子公式，我们必须将其转换为具有单个入口端子和单个出口端子的矩形接线小工具。 

接下来，我们定义一个递归构造。 

1. 如果节点是变量 x，我们构造一个由标有 x 的单个水平线段组成的最小小工具。 该段充当锁控通道。 入口是左端点，出口是右端点。 这样做的原因是连通性直接取决于 x 是否“开放”。 
2. 如果节点不是 A，我们为 A 构造 gadget，然后将其包装在反转连通性的结构中。 这是通过强制一条仅在 A 关闭时可用的绕行路径来实现的。 该设计确保每当 A 阻塞连接时，就会有替代路线可用，从而有效地翻转事实。 
3. 如果节点是A和B，我们将A的gadget放在B的gadget上方，并将它们串联。 A 的出口成为 B 的入口。这强制两个子小工具都必须允许完整路径存在。 
4. 如果节点是 A 或 B，我们将 A 和 B 的小工具并行放置，将它们的两个入口点连接到共享的起点，并将两个出口连接到共享的终点。 这可确保至少一条有效路径足以实现连接。 
5. 在构建过程中，我们为每个小工具维护边界框，并小心地将它们嵌入到全局网格中，始终将宽度和高度保持在 50 以下。我们通过根据合成类型垂直或水平对齐子小工具来重复使用空间。 
6. 构建根 gadget 后，我​​们输出网格，网格的起点位于左上角，终点位于右上角。 

这种构造有效的原因是每个小工具都强制子公式真值和终端连接之间完全等效。 归纳起来，如果每个子小工具行为正确，那么使用串联和并联组合将它们组合起来可以保持正确性。 不变的是，每个子公式都由一个两端网络表示，当子公式在任何锁分配下为真时，该网络的连通性恰好为真。

 ## 边缘情况

 一种边缘情况是计算矛盾的公式，例如 a 和 not a。 该构造试图同时构建直接路径和串联的反向路径。 该不变量确保两个块之一始终阻止连接，因此最终网格中不存在有效路径。 

另一个边缘情况是仅涉及单个变量的公式。 在这种情况下，整个网格会折叠成一个小工具，并且不需要组合。 入口点和出口点是同一水平段，因此连通性完全取决于锁是否打开。 

第三种边缘情况是深度嵌套的交替运算符，例如 a 或 (b 和 (c 或 d))。 递归结构通过反复分裂成并行和串行组合来处理这个问题。 边界框保持受控状态，因为每种组合都会增加恒定的开销，并且不会发生指数重复。
