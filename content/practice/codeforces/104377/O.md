 ## 解决方案
 ## 问题理解

 我们在平面上得到一组点，每个点都带有正值或负值。 渔民站在原点，可以非常灵活地撒网。 该网始终对应于一个边界通过原点的圆，并且该圆内部或该圆上的所有内容都被收集。 总增益是所有收集点的值的总和。 

关键的几何自由度是我们不固定圆心或半径。 我们可以选择任何通过原点的圆，这包括圆变得任意大的退化情况，这有效地将边界变成通过原点的直线，留下半平面作为收集区域。 

因此，任务是选择一个由这样一个圆定义的几何区域，以最大化其中所有点的值的总和。 

约束足够小，O(n^2) 几何扫描是可行的。 当 n 达到 1000 时，即使将每个点视为参考方向并处理与其相关的所有其他点的解决方案也会在时间限制内轻松通过。 

一个微妙的点是，最佳区域不一定是“围绕一组正点的小圆圈”。 因为我们可以扩大圆，同时仍然迫使它​​通过原点，所以我们可以有效地近似通过原点的任何半平面。 这使得许多中等正值点位于一条线的一侧的配置比紧密聚集的高值点更重要。 

一个天真的错误是只考虑距离，假设我们应该选择一个以某处为中心的半径来捕获附近的正点。 这忽略了圆必须通过原点的约束，这从根本上将每个有效区域与锚定在原点的方向联系起来。 

另一个常见的陷阱是将问题视为选择凸包或边界圆问题。 例如，人们可能会尝试选择正点的最小外接圆，但该圆不需要通过原点，因此它不是有效的候选者。 

## 方法

 暴力解释是枚举通过原点的每个可能的圆，然后测试其中的所有点并计算总和。 平面中的圆具有三个自由度，但它通过原点的约束将其减少到其中心的两个自由度。 即使我们离散中心位置或尝试对由点对定义的候选圆进行组合枚举，我们很快就会面临可能性的爆炸。 检查每个候选点的所有 n 个点的成员资格会产生三次或更差的复杂性，考虑到几何结构，这是不必要的。 

关键的观察结果是，每个经过原点的圆都会引起平面的分割，其中“远边界行为”相当于半平面。 随着圆的半径增大，其边界在原点周围局部变平，并且该区域接近边界线通过原点的半平面。 

更具体地说，任何最佳配置都可以表示为选择一条穿过原点的有向线，并将所有点保持在该线的一侧。 一旦我们确定了方向，我们就有效地确定了一个半平面，并且每个有效的圆都可以被拉伸，以便它恰好包含位于通过原点的某条线一侧的那些点。 

这将问题简化为：找到一条穿过原点的线，使得线一侧的点值之和最大化。

这是一个经典的角度扫描问题。 每个点都有一个围绕原点的极角。 任何半平面都对应于长度严格小于 π 的角度区间。 因此，我们按角度对点进行排序，并在圆角空间上使用宽度为 π 的滑动窗口，维护窗口内的值之和。

 | 蛮力圈| 指数或最多 O(n^3) | O(n) | 太慢了 |

 ## 算法演练

 我们将几何问题转换为角坐标，然后搜索加权点的最佳半圆覆盖。 

1. 计算每个点相对于原点的极角。 这将每个点映射到 [0, 2π) 范围内的角度。 
2. 通过向每个角度添加 2π 并将其附加到数组来复制点列表。 这使我们能够使用线性扫描来模拟圆形环绕。 
3. 按角度对所有点进行排序。 需要进行排序，以便连续的角度间隔对应于数组中的连续段。 
4.使用两指针滑动窗口。 对于每个左端点，我们尽可能地向前推进右端点，同时保持角跨度小于 π。 
5. 对于每个有效窗口，计算其内部点值的总和并跟踪所有窗口的最大值。 

窗口大小为 π 的原因是通过原点的半平面精确对应于任何长度为 π 的区间内的所有方向。 任何更大的间隔都必然包括通过原点的某条线两侧的点，这违反了半平面结构。 

### 为什么它有效

 每个可行的解决方案都对应于选择一条通过原点的有向线，该线定义了一个半平面。 该半平面对应于单位圆上宽度为 π 的连续角区间。 相反，任何这样的间隔都定义了有效的半平面。 滑动窗口枚举所有此类间隔，因此每个有效的几何配置仅被考虑一次。 因此，最佳窗口总和等于最佳的基于循环的选择。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    n = int(input())
    v = list(map(int, input().split()))
    
    pts = []
    for i in range(n):
        x, y = map(int, input().split())
        ang = math.atan2(y, x)
        pts.append((ang, v[i]))
    
    pts.sort()
    
    extended = pts + [(ang + 2 * math.pi, val) for ang, val in pts]
    
    m = len(extended)
    
    ans = -10**18
    current_sum = 0
    r = 0
    
    for l in range(n):
        if r < l:
            r = l
            current_sum = 0
        
        while r < m and extended[r][0] - extended[l][0] < math.pi - 1e-12:
            current_sum += extended[r][1]
            r += 1
        
        ans = max(ans, current_sum)
        current_sum -= extended[l][1]
    
    print(ans)

if __name__ == "__main__":
    solve()
```实现首先将每个点转换为极角形式。 使用`atan2`确保正确处理所有象限，包括负坐标。 

排序后，我们显式复制数组，角度偏移 2π。 这使得滑动窗口可以将圆角空间视为线性区间，而无需特殊的模运算。 

两指针扫描维护当前角度窗口内的值的运行总和。 条件`< π`强制半平面约束。 移动左指针时的减法步骤可确保窗口总和保持一致。 

一个常见的实现错误是在比较角度差异时忘记浮点精度问题。 当点恰好位于 π 阈值上时，小 epsilon 可防止边界不稳定。

 ## 边缘情况

 关键的边缘情况是当点恰好位于所选半平面的边界线上时。 在角度方面，这对应于恰好等于 π 的差值。 该算法将窗口视为严格小于 π，这确保每个边界一致地仅分配给一侧。 例如，角度为 0 和 π 的点永远不会一起包含在同一窗口中，这符合通过原点的线将点放置在相对侧的几何解释。 

当所有值都为负时，会出现另一种微妙的情况。 最优策略仍然是选择负数最小的半平面，而不是空集。 滑动窗口自然地处理这个问题，因为每个窗口总和都会被计算，包括那些具有最小幅度负总数的窗口总和，确保仍然正确捕获最大值。
