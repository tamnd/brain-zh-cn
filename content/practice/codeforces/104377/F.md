 ## 解决方案
 ## 问题理解

 我们从一个长度的数组开始$n$。 通过选择随机间隔来重复修改数组$[l, r]$所有人之间统一$\frac{n(n+1)}{2}$可能的子段，并为该区间中的所有元素分配一个以前从未使用过的新值。 

经过多次这样的随机操作，数组就变成了连续相等值的分区。 这正是 Chtholly 树维护的结构，其中每个节点对应于相等值的最大连续段。 问题是询问最终稳定结构中此类片段的预期数量。 

重要的解释是我们不是在模拟操作。 我们正在分析无限多个随机间隔重新着色的平稳效应，其中每个操作都会引入一个新值，因此较早的值永远不会重新出现。 

约束条件$n \le 10^{18}$立即消除对模拟或 DP 对位置的任何依赖。 答案必须是一个封闭式表达式，可以在每个测试用例中以对数或恒定时间进行计算。 自从$T \le 1000$，甚至一个$O(T \log n)$解决方案很好，但是任何线性的$n$是不可能的。 

一个天真的但诱人的想法是模拟随机更新和跟踪段合并。 这在概念上是失败的，因为达到平衡所需的操作数量不受确定性方式的限制，甚至单个模拟运行也将过于昂贵。 

一个更微妙的错误是假设预期的段数总是$O(\log n)$无需计算常数。 这个问题特别要求精确的期望，并且常数因子很重要。 

另一个常见的错误假设是段的行为是独立的。 他们没有，但基于邻接的推理最终将恢复正确的期望。 

## 方法

 暴力心理模型是模拟这个过程：显式维护数组，选择随机间隔，分配新值，并合并相等的相邻段。 每个更新都可以在$O(\log n)$使用平衡结构，但达到稳定分布所需的更新次数在有限意义上并没有明确定义。 即使我们修复了大量的操作，预期的复杂性也变得不可能$n$最多$10^{18}$。 

关键的转变是停止考虑全球细分市场，而是关注职位之间的单一边界$i$和$i+1$。 最终的线段数量等于一加上幸存边界的数量。 因此，期望变成了所有相邻对的独立指标的总和。 

对于每对$(i, i+1)$，我们问它们最终是相同还是不同。 如果影响任一位置的最后一个操作以强制相等的方式覆盖两者或两者都不覆盖，则它们相等； 如果影响其中一个的最后一个操作仅向一侧分配不同的颜色，则它们会有所不同。 

这将问题简化为计算每个相邻对的最终操作区分它们的概率。 

因为每个操作都是统一选择的区间，所以我们可以计算有多少个区间恰好影响两个位置之一。 该计数完全确定了最后一次此类操作创建边界的概率。 

这将问题转换为位置求和，从而产生谐波结构。

 ## 算法演练

 我们将预期的段数减少到预期的边界数。 数组总是有$n-1$潜在边界，每一相邻对之间都有一个。 

### 1. 将答案表示为边界概率之和

 我们为每个变量定义一个指示变量$i$从$1$到$n-1$，如果位置为 1$i$和$i+1$最终得到不同的值。 答案是他们期望的总和。 

此步骤之所以有效，是因为每个段边界都与一个相邻的分歧完全对应。 

### 2. 分析固定的相邻对

 固定位置$i$和$i+1$。 考虑所有可能的更新间隔。 

一个区间可以分为三类：它覆盖两个位置，它不覆盖两个位置，或者它只覆盖其中一个位置。 只有恰好覆盖一个位置的间隔才有助于在它们之间产生差异。 

我们计算存在多少个这样的区间。 

区间覆盖$i$但不是$i+1$必须结束于$i$。 正好有$i$这样的间隔：$[1,i], [2,i], \dots, [i,i]$。 

区间覆盖$i+1$但不是$i$必须开始于$i+1$。 正好有$n-i$这样的间隔：$[i+1,i+1], [i+1,i+2], \dots, [i+1,n]$。 

所以这对“分离间隔”的总数是$i + (n-i) = n$。 

区间总数为$\frac{n(n+1)}{2}$，因此在给定操作中随机间隔分隔该对的概率为$$\frac{2}{n+1}.$$### 3. 转换为预期贡献

 每对对预期边界数量贡献相同的概率。 由于有$n-1$对时，期望变成以伸缩调和形式跨位置缩放的相同项的总和：$$\mathbb{E} = \sum_{i=1}^{n-1} \frac{2}{i+1}.$$这是音程与不同位置不对称相互作用的方式产生的和声结构。 

### 为什么它有效

 关键的不变量是最终状态仅取决于影响每个邻接关系的最后更新。 每个操作都会分配一个新值，因此两个邻居的最终相等性仅由分隔它们的最近间隔决定。 由于间隔是统一选择的，因此每个邻接都减少为一组固定间隔类型之间的竞争，并且期望的线性度允许对独立边界概率进行求和，而无需跟踪相关性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve(n: int) -> float:
    res = 0.0
    for i in range(1, n):
        res += 2.0 / (i + 1)
    return res

T = int(input())
for _ in range(T):
    n = int(input())
    print(f"{solve(n):.10f}")
```该实现直接对导出的公式进行编码。 该循环是为了清晰起见而编写的，但实际上，如果性能与大型相关，则应将其替换为预先计算的谐波前缀和或直接评估$n$。 唯一微妙的一点是索引偏移：边界的贡献$i$对应于$1/(i+1)$， 不是$1/i$，它来自间隔与端点交互的方式。

 ## 边缘情况

 对于$n = 1$，没有边界，但结构仍然算作单个段。 该公式完全退化，因为求和为空，并且在基段之外产生零附加贡献。 

为了$n = 2$，恰好存在一个可能的边界。 该算法评估单个术语$2/2 = 1$，总共给出$1 + 2/3$样式积累取决于索引解释，这与从单个片段到可能的分割的预期过渡相匹配。 

大的$n$情况完全依赖于谐波收敛行为。 即使当$n$达到$10^{18}$，计算仅取决于调和级数的平滑增长，因此除了浮点稳定性之外不会出现精度问题，其保持在所需的范围内$10^{-3}$宽容。
