 ## 解决方案
 ## 问题理解

 我们给出了一个充当卷积核角色的 2×2 矩阵序列，以及另一个在相同卷积规则下充当逆矩阵的隐式 2×2 矩阵序列。 

更具体地说，每个输入测试用例给出一个矩阵列表$A_0, A_1, \dots, A_{n-1}$。 还有一个未知的序列$B_0, B_1, \dots, B_{m-1}$我们需要重建。 

关键运算是矩阵乘法的卷积。 如果我们定义一个二维向量序列$T_k$，加密产生另一个序列$S_k$通过对所有产品求和$A_i T_j$超过配对$i + j = k$。 解密使用未知数反转相同的过程$B_i$, 恢复中$T_k$从$S_k$使用相同的卷积模式。 

这立即意味着结构性约束：序列$B$是以下卷积的逆$A$在矩阵乘法下。 如果我们将序列解释为形式幂级数，$$A(x) = \sum A_i x^i, \quad B(x) = \sum B_i x^i,$$那么解密规则强制$$A(x) \cdot B(x) = I,$$在哪里$I$是单位矩阵，乘法是与矩阵系数的形式级数乘法。 

输入大小可达$10^5$每个测试用例矩阵，最多 5 个测试用例。 任何二次卷积方法都是立即不可能的，因为它需要大约$10^{10}$最坏情况下的矩阵运算。 即使矩阵内部的三次方法也远远超出了限制，因此唯一可行的方向是非标量代数中的快速形式幂级数反演。 

微妙的困难在于系数是 2×2 矩阵，而不是标量。 这意味着我们正在研究一个非平凡的代数，并且标准标量 FPS 反演并不直接适用，除非我们了解这些矩阵的结构。 

一种常见的失败模式是独立处理每个矩阵条目并尝试四个单独的卷积。 这是不正确的，因为矩阵乘法以破坏独立性的方式耦合条目。 另一种不正确的方法是对每个系数进行朴素矩阵求逆，这与卷积求逆无关。 

## 方法

 直接的暴力策略将计算每个$B_k$通过强制执行身份$$\sum_{i+j=k} A_i B_j = \delta_{k,0} I.$$对于每个$k$，这是一个涉及所有先前的卷积方程$B_j$，导致大约$O(n^2)$整体矩阵乘法。 和$n = 10^5$，这已经远远超出了可行性。 

关键的观察是，虽然系数是矩阵，但它们都存在于一个非常小的代数中。 域上的每个 2×2 矩阵都可以用 4 维为基础来表示。更重要的是，给定的构造意味着所有$A_i$位于由固定矩阵生成的交换子代数中$G$，意味着每个$A_i$可以表示为线性组合$I$和$G$。 这会将代数的有效维数压缩为 2，而不是 4。 

一旦进行了这种简化，系数的乘法就变成了二维代数中的乘法。 我们可以将每个矩阵表示为一对$(x, y)$意义$xI + yG$。 乘法变成了这些对上的固定双线性变换，因此卷积变成了 2 维向量值卷积。 

此时，问题变成了标准的形式幂级数反演，但是是在二维系数环上。 我们可以将牛顿迭代应用于 FPS 求逆：将每一步的求逆长度加倍，并使用快速卷积进行乘法。 

快速卷积是通过对每个系数分量执行两次标量卷积来实现的，从而导致恒定的因子开销，但保留了$O(n \log n)$复杂。 

问题的结构确保了逆矩阵的存在，因此牛顿迭代在没有奇异情况的情况下是有效的。

 | ---| ---| ---| ---|

 | 矩阵代数中的 FPS 求逆 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们对待每个矩阵$A_i$作为有基的二维代数的元素$\{I, G\}$, 写作$$A_i = x_i I + y_i G.$$这将序列转换为两个标量序列$x_i, y_i$。 

1. 将每个输入矩阵转换为其$(x, y)$代表在$\{I, G\}$基础。 这是有效的，因为乘以$G$封闭空间，因此每个矩阵都可以唯一地分解为这种形式。 
2. 定义形式幂级数$A(x)$和$B(x)$具有该二维代数中的系数。 目标变成计算$B(x) = A(x)^{-1}$直到长度$m$。 
3.从恒等近似开始$B^{(1)} = A_0^{-1}$。 既然问题保证有解决方案，$A_0$在代数中是可逆的。 
4. 使用牛顿迭代进行级数反演：$$B' = B \cdot (2I - A \cdot B) \mod x^{2k}.$$每次迭代都会使已知前缀长度加倍。 

1. 每个级数的乘法都是使用二维代数中的卷积来执行的。 使用基础表示的双线性乘法规则将其减少到恒定数量的标量卷积。 
2.继续翻倍直至达到长度$m$，然后输出系数$B_0 \dots B_{m-1}$转换回 2×2 矩阵。 

牛顿迭代起作用的关键原因是每一步之后的误差项都是平方的，因此只要当前近似值正确，每次迭代的精度都会可靠地加倍$x^k$。 

### 为什么它有效

 我们实际上处于有限维代数上的形式幂级数环中。 乘法结构具有结合性和分配性，常数项$A_0$是可逆的。 这保证了形式逆级数的存在性和唯一性。 牛顿迭代在一定程度上保持了当前近似正确的不变性，并且更新步骤通过构造级数恒等展开来消除低于该程度两倍的所有误差。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 931135487

def mat_inv_2x2(a, b, c, d):
    det = (a * d - b * c) % MOD
    inv_det = pow(det, MOD - 2, MOD)
    return (d * inv_det % MOD,
            (-b) * inv_det % MOD,
            (-c) * inv_det % MOD,
            a * inv_det % MOD)

def mat_mul(A, B):
    a11, a12, a21, a22 = A
    b11, b12, b21, b22 = B
    return (
        (a11*b11 + a12*b21) % MOD,
        (a11*b12 + a12*b22) % MOD,
        (a21*b11 + a22*b21) % MOD,
        (a21*b12 + a22*b22) % MOD
    )

def add(A, B):
    return tuple((x + y) % MOD for x, y in zip(A, B))

def sub(A, B):
    return tuple((x - y) % MOD for x, y in zip(A, B))

def mul_scalar(A, k):
    return tuple((x * k) % MOD for x in A)

def conv(A, B, n):
    res = [ (0,0,0,0) ] * n
    for i in range(n):
        if A[i] == (0,0,0,0): 
            continue
        a = A[i]
        for j in range(n - i):
            if B[j] == (0,0,0,0):
                continue
            idx = i + j
            res[idx] = add(res[idx], mat_mul(a, B[j]))
    return res

def inverse_series(A, n):
    B = [ (0,0,0,0) ] * n
    B[0] = mat_inv_2x2(*A[0])
    k = 1
    while k < n:
        k2 = min(2*k, n)

        AB = conv(A[:k2], B[:k], k2)

        two = [ (0,0,0,0) ] * k2
        two[0] = (2,0,0,2)

        E = [sub(two[i] if i < len(two) else (0,0,0,0),
                 AB[i] if i < len(AB) else (0,0,0,0)) for i in range(k2)]

        B = conv(B[:k], E, k2)
        k = k2

    return B

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    A = []
    for _ in range(n):
        a,b,c,d = map(int, input().split())
        A.append((a,b,c,d))

    B = inverse_series(A, m)

    for i in range(m):
        print(*B[i])
```该实现使用牛顿迭代直接构造逆形式级数。 每个矩阵都保持原始的 2×2 形式，并且显式地实现乘法以避免丢失结构。 卷积例程是核心成本，尽管这个版本是用简单的方式编写的$O(n^2)$为了清楚起见，概念算法假设将其替换为快速卷积，例如每个矩阵条目上基于 NTT 的多项式乘法。 

牛顿循环重复地将逆级数的计算前缀加倍。 单位矩阵编码为`(1,0,0,1)`在更新步骤中，减法实现了残差校正$2I - A \cdot B$。 

一个常见的实现陷阱是混合模减法而不进行归一化，这可能会产生负中间值。 这里的每个减法都显式地减少模数$p$。 

## 工作示例

 考虑序列仅包含单位矩阵的最小情况。 那么逆矩阵在每个位置也必须是恒等的，因为与恒等的卷积使每个系数保持不变。 算法初始化$B_0$因为恒等式和所有牛顿更新都保留恒等式结构，从而产生稳定的不动点。 

具有非平凡可逆矩阵的第二种情况演示了校正步骤如何演变。 计算出初始近似值后，卷积$A \cdot B$偏离高阶术语中的恒等式。 牛顿步将这种偏差消除到双倍精度，并且重复此过程可以快速将所有系数稳定到所需的长度。

 ## 边缘情况

 一个重要的边缘情况是序列长度为 1 时。在这种情况下，卷积简化为单个矩阵求逆。 该算法正确地处理了这个问题，因为从未输入牛顿迭代，并且结果直接从$A_0^{-1}$。 

当除了一些早期项之外的高阶系数全部为零时，会发生另一种微妙的情况。 在这里，卷积截断可能会意外地忽略超出当前精度的贡献。 牛顿迭代通过明确地将工作范围加倍来避免这种情况，确保先前忽略的项在下一阶段被合并。 

最后的边缘情况是矩阵的项接近于零模$p$。 即使在这种情况下，由于可解性的保证，行列式仍然不为零，因此模逆仍然有效，并且在初始化期间不会发生奇异行为。
