 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，并要求选择该列表中满足特定结构属性的最大值：该值的每个素因数也必须出现在列表中的某个位置。 

更具体地说，想象每个数字都有一组素数来划分它。 如果一个数因式分解中出现的所有素数都被数组中至少一个可被该素数整除的元素“覆盖”，则该数是有效的。 我们被要求找到所有有效数字中的最大值，或者报告不存在这样的数字。 

输入大小最多可达 100,000 个数字，每个数字最多 1,000,000 个。 这立即排除了在不进行预处理的情况下使用重复除法为每个查询天真地重新计算素数分解的情况。 如果使用筛子或最小素因数表仔细完成，每个元素的直接因式分解仍然是可行的，因为$10^6$足够小，可以在线性或近线性时间内预处理 SPF，然后每个因式分解的值都变为对数。 

关键的隐藏约束不仅是因式分解效率，还在于数字之间的依赖性。 幼稚的解释可能会独立处理每个数字，但有效性取决于全局信息：每个素除数是否在数组中的某个位置表示。 这种耦合是强制对整个数据集进行预处理的原因。 

一些边缘案例暴露了常见的错误。 

如果所有数字都相同并且是合数，例如`[6, 6, 6]`，然后素数`{2, 3}`必须都作为某些元素的因子出现，这是正确的，因此最大有效数是`6`。 如果简单的解决方案仅检查素数本身是否作为数组中的原始值而不是作为因子出现，则它可能会错误地拒绝此操作。 

如果数组是`[4, 9]`，那么 4 有素因数`{2}`和 9 有`{3}`。 两个素数都作为因子出现在数组中，因此两者都是有效的，答案是`9`。 仅检查素数作为元素的直接存在的错误方法在这里会失败。 

如果数组是`[8, 9]`，同样的逻辑适用，但如果我们有`[8]`，然后素数`2`被覆盖，所以`8`是有效的。 

微妙的失败模式混淆了“素数作为一个元素出现”和“素数作为某个元素的约数出现”。 

## 方法

 暴力策略首先对每个数字进行独立因式分解，然后针对每个数字检查其因式分解中的所有素数是否以某种可用的方式出现在数组中。 实现此目的的一种方法是首先构建所有数字的频率图，然后将每个候选数字因式分解为素数，并验证每个素数是否至少能整除数组中的一个元素。 

瓶颈是重复因式分解与重复的素性/整除性检查相结合。 在最坏的情况下，每个数字最多$10^6$可能会被处理$O(\sqrt{a_i})$审判分庭，导致约$10^5 \cdot 10^3 = 10^8$操作，当包含常量时，这在 Python 中是边缘性的，甚至更糟。 更重要的是，重复分解相同的值会造成浪费。 

关键的观察是我们只需要知道哪些素数作为因子出现在数组中的任何位置。 一旦知道了该集合，每个数字的验证就变成了对其质因数分解的简单隶属度检查。 这表明在整个范围内使用最小素因子筛进行预处理$10^6$，允许快速分解每个元素。 然后我们计算任何因式分解中出现的所有素数的集合。 最后，我们使用相同的因式分解重新评估每个数字，以确保其所有素数都属于该全局集合。 

这将问题简化为线性预处理加上线性遍历和有效的因子提取。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n \sqrt{A})$|$O(n)$| 太慢了 |
 | 最佳 |$O(A \log \log A + n \log A)$|$O(A)$| 已接受 |

 这里$A = 10^6$。 

## 算法演练

 1.构建最小素因数数组`spf`对于所有整数$10^6$。 这允许通过重复除以任何数字的最小质因数，在对数时间内对任何数字进行因式分解。 
2. 对于数组中的每个数字，使用以下方法将其分解`spf`。 提取素数时，将任何因式分解中出现的每个不同素数记录到全局布尔数组中`present_prime`。 此步骤捕获数据集中“可用”的所有素数。 
3. 再次遍历数组。 对于每个数字，使用以下方法再次将其分解`spf`，并检查该数字的每个不同素因数是否被标记为存在于`present_prime`。 
4. 如果一个号码通过了这项检查，那么它就是一个有效的候选者。 跟踪所有有效候选人中的最大值。 
5. 如果没有有效候选，则输出`-1`。 

步骤 2 的正确性依赖于将素数视为全局资源。 我们不计算重数，只计算素数是否作为输入中某处的因子至少出现一次。 

### 为什么它有效

 有效性的条件仅取决于除法的每个素数是否存在于从数组派生的全局素数因子支持集中。 由于每个数字都是针对由所有因式分解构建的相同全局集进行测试，因此每个元素的决策都是一致且独立的。 筛子保证正确的素数分解，全局存储素数确保数字之间不丢失依赖关系。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 10**6

# smallest prime factor sieve
spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXV + 1, step):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    primes = set()
    while x > 1:
        p = spf[x]
        primes.add(p)
        while x % p == 0:
            x //= p
    return primes

n = int(input())
a = list(map(int, input().split()))

present_prime = [False] * (MAXV + 1)

fact_cache = []
for x in a:
    ps = factorize(x)
    fact_cache.append(ps)
    for p in ps:
        present_prime[p] = True

ans = -1
for i, x in enumerate(a):
    ok = True
    for p in fact_cache[i]:
        if not present_prime[p]:
            ok = False
            break
    if ok:
        ans = max(ans, x)

print(ans)
```筛子一次性建成，可以快速分解。 在此实现中，每个数字都被分解两次：一次用于构建全局素数集，一次用于验证候选数。 一个小的优化是缓存因子集以避免重新计算。 

这`present_prime`数组充当出现在任何地方的所有素数的全局注册表。 每个候选者仅根据其自己的素数集进行检查。

 7 使用 {7} 存在 → 有效

 最大值为 15。 

该跟踪表明，一旦全局收集了所有素数，验证就变得独立于每个数字。 

现在考虑：```
3
8 9 5
```因式分解：

 8 → {2}

 9 → {3}

 5 → {5}

 所有素数都是全局出现的，所以所有数字都有效，答案是 9。 

这证实了该算法不需要素数作为独立元素出现，仅作为数据集中某处的因子出现。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    MAXV = 10**6
    spf = list(range(MAXV + 1))
    for i in range(2, int(MAXV ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factorize(x):
        primes = set()
        while x > 1:
            p = spf[x]
            primes.add(p)
            while x % p == 0:
                x //= p
        return primes

    n = int(input())
    a = list(map(int, input().split()))

    present = [False] * (MAXV + 1)
    facts = []

    for x in a:
        ps = factorize(x)
        facts.append(ps)
        for p in ps:
            present[p] = True

    ans = -1
    for i, x in enumerate(a):
        ok = True
        for p in facts[i]:
            if not present[p]:
                ok = False
                break
        if ok:
            ans = max(ans, x)

    return str(ans)

 ## 边缘情况

 一种极端情况是数字本身是质数。 用于输入`[2, 3, 5]`，每个数字都有一个等于其自身的质因数。 由于所有这些素数都作为其自身元素的因子出现在数组中，因此所有数字都是有效的，答案是最大元素。 

另一个边缘情况是重复的复合结构，例如`[4, 9, 25]`。 每个数字都取决于一个素数因子，但有效性要求每个素数都出现在数组中的某个位置。 算法正确收集`{2,3,5}`全局并成功验证所有元素。 

更微妙的情况是混合依赖，例如`[6, 25]`。 这里需要6个`{2,3}`25 需要`{5}`。 由于所有素数都出现在现有元素的因式分解中，因此两者都是有效的，并且输出为 25。该算法通过不要求同一数字内素数的交叉共享，只要求全局存在来确保这一点。
