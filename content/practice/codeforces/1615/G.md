 ## 解决方案
 ## 问题理解

 我们得到一个数组，其中包含一些固定整数和一些标记为零的位置。 每个零必须替换为 1 到 n 之间的任意整数，并且可以独立填充不同的零位置，甚至可以使用相同的值。 

填充数组后，我们查看每个整数值 k 并提出一个非常具体的问题：k 是否在最终数组中的某处作为一对相等的相邻元素至少出现一次？ 如果是，则 k 为得分贡献 1，无论它形成多少个这样的相邻对。 目标是选择零的替换，以便尽可能多的不同值 k 实现至少一个相邻的重复对。 

重要的结构是，我们不是在计算对，而是计算有多少个不同的值设法创建至少一个 k, k 形式的邻接关系。 

约束条件很大，n 高达 3⋅10^5。 这立即排除了任何尝试所有零分配或独立模拟每个值选择的解决方案。 n 中的任何二次方都太慢，甚至 O(n√n) 也会很紧。 该解决方案必须以基本上线性的时间处理数组，并利用如何形成邻接的结构。 

一个关键的微妙之处是零可以用作现有值之间的“粘合剂”。 某个值当前可能没有相邻的重复项，但可以填充其出现次数之间的零以强制将它们放在一起。 另一个微妙的情况是，零还可以创建从未出现在输入中的全新值。 

一个天真的错误是假设每个值都可以独立处理。 例如，人们可能会尝试通过在每个值周围填充零来贪婪地“修复”每个值。 这会失败，因为相同的零位置不能重复用于多个值，因此决策会在全局范围内交互。 

另一个错误是只计算现有的相邻相等对并假设零并不重要。 例如，在`[1, 0, 1]`，忽略零表明值 1 没有邻接，但将零填充为 1 会创建一个有效的对。 

最后，为每个值单独处理每个零块是错误的，因为为一个值填充一个块会破坏其为其他块服务的能力。 

## 方法

 蛮力的观点是尝试以各种可能的方式将值赋给零并计算分数。 即使每个零只有 n 个选择，这也会导致 n^(#zeros)，这是不可能的。 

一个稍微好一点的想法是单独处理每个值，并尝试决定是否可以为其强制使用相邻对。 对于固定值 k，我们将检查其所有出现的情况，并尝试使用零作为中间位置连接至少其中两个。 这自然会导致一种连通性视图：位置 i 和 i+1 可以被遍历，如果它们至少其中之一为零或者两者都已经是 k 兼容的。 然而，如果我们尝试对每个值独立地执行此操作，我们就会以不兼容的方式重复消耗零。 

关键的观察结果是，邻接的形成从根本上讲是关于通过零连接的间隔。 如果我们考虑一张图表，只要至少一个端点为零或两个端点都相等非零，相邻索引就会连接起来，那么每个连接的组件的行为就像一个“资源区域”，我们可以使用零自由地重塑值，但有一个全局限制：每个组件最多可以有效地用于创建一个在其他地方尚未成功的新的成功值。 

这将问题从按值推理减少到按组件推理。 原始数组中已经具有相邻对的值已经成功，并且不需要任何组件资源。 然后，包含零的组件可以通过为其中的某些位置分配一致的值来“激活”附加值。

 | ---| ---| ---| ---|
 | 暴力作业 | 指数| O(n) | 太慢了 |
 | 组件+贪心赋值| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 在索引上构建一个图，其中位置 i 连接到 i+1（如果其中至少一个为零，或者如果它们已包含相同的非零值）。 这会将位置分组到连接的组件中，其中零允许值的自由传播。 
2. 对于每个值 k，检查其在原始数组中是否已经有至少一对相邻的值（忽略零）。 这标识了已经计算且没有任何修改的值。 
3. 使用 DSU 或邻接规则上的线性扫描来计算索引的连通分量。 对于每个组件，记录它是否包含任何零并收集其中出现的一组值。 
4. 标记由于现有邻接而已经“良好”的所有值。 这些立即有助于答案，不需要再次考虑。 
5. 对于至少包含一个零的每个分量，确定它是否包含至少一个尚未良好的值。 如果确实如此，则该组件可用于创造以前无法实现的一项额外的良好价值。 
6. 计算有多少组件有资格创造这样的新价值。 令其为 g，令 r 为尚未良好的值的数量。 附加增益的数量是min(g,r)。 
7. 通过为每个限定组件分配一个不同的未使用值来构造最终数组，并用该所选值填充该组件中的所有零。 

第 6 步背后的关键约束是每个新值只能“激活”一次。 如果我们在多个组件中重用相同的值，它仍然只计算一次，因此我们必须将选择分散到不同的值中。 

### 为什么它有效

在零桥接下形成的每个连接组件的行为就像一个区域，其中零可以在整个组件上自由传播选定的值。 然而，一旦为组件选择了一个值，该组件就无法在不破坏邻接一致性的情况下独立支持另一个不同的新值。 这造成了一对一的限制：每个有用的组件最多只能贡献一个先前不活动的值。 

已经具有相邻对的值独立于该过程，因为无论零放置如何，它们的贡献都已经得到保证。 该算法将这两种状态分开，并确保每个附加增益对应于不同的分量和不同的值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # DSU
    parent = list(range(n))
    
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    
    def union(x, y):
        x = find(x)
        y = find(y)
        if x != y:
            parent[y] = x
    
    # connect components
    for i in range(n - 1):
        if a[i] == 0 or a[i + 1] == 0 or a[i] == a[i + 1]:
            union(i, i + 1)
    
    # gather components
    comp_vals = {}
    comp_has_zero = {}
    comp_has_adj = {}
    
    good = set()
    
    # detect already-good values (adjacent equal non-zero)
    for i in range(n - 1):
        if a[i] != 0 and a[i] == a[i + 1]:
            good.add(a[i])
    
    for i in range(n):
        r = find(i)
        if r not in comp_vals:
            comp_vals[r] = set()
            comp_has_zero[r] = False
        if a[i] == 0:
            comp_has_zero[r] = True
        else:
            comp_vals[r].add(a[i])
    
    comps = []
    for r in comp_vals:
        comps.append((r, comp_has_zero[r], comp_vals[r]))
    
    # available values for new activation
    used = set(good)
    available = []
    for x in range(1, n + 1):
        if x not in used:
            available.append(x)
    
    ptr = 0
    assign = {}
    
    # choose components that can gain a new value
    for r, has_zero, vals in comps:
        if not has_zero:
            continue
        if ptr >= len(available):
            break
        
        # check if component can contribute something new
        ok = False
        for v in vals:
            if v not in good:
                ok = True
                break
        
        if ok or len(vals) == 0:
            assign[r] = available[ptr]
            ptr += 1
    
    # build result
    res = a[:]
    
    for i in range(n):
        r = find(i)
        if a[i] == 0:
            if r in assign:
                res[i] = assign[r]
            else:
                res[i] = next(iter(comp_vals[r])) if comp_vals[r] else 1
    
    print(*res)

if __name__ == "__main__":
    solve()
```该实现首先使用并查找结构基于邻接是否可以通过零或已经相等的值“桥接”来构建索引之间的连接。 此后，每个组件都成为一个独立的区域。 

这`good`set 捕获在任何修改之前已经具有相邻相等对的值。 这些是锁定的贡献，不依赖于如何填充零。 

然后检查每个组件以查看它是否包含零，因为只有这样的组件才能用于引入最初不存在的新邻接关系。 维护未使用值的池，以便每个选定的组件接收不同的新值。 

最后，每个选定组件内的零都用指定的值一致地填充，确保组件为该值生成至少一个相邻的相等对。

```最初没有值具有相邻对。 

有一个涵盖所有索引的大组件，包含零和值 {2,3}。 

| 组件| 价值观 | 有零 | 良好的价值观| 已分配 |

 ## 边缘情况

 关键的边缘情况是组件仅包含零。 在这种情况下，它内部不存在任何值，但它仍然可以用来引入一个全新的值。 该算法通过允许空值组件仍然从未使用的值池中接收分配来处理此问题，确保它们贡献一个新的好值（如果可用）。 

另一个边缘情况是组件内的所有值都已经全局良好。 即使该分量包含零，使用它也不会增加不同的好值的数量，因此该算法故意避免为其分配新值。 

最后一个微妙的情况是，多个组件都符合条件，但未使用值的数量小于组件的数量。 贪婪分配确保每个值最多使用一次，因此只有前几个组件有贡献，这与只有不同值对最终分数很重要这一事实相匹配。
