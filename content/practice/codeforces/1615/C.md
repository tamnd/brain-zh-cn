 ## 解决方案
 ## 问题理解

 光明节烛台上有一排蜡烛，每根蜡烛要么点燃，要么不点燃。 当前状态以二进制字符串形式给出`a`， 在哪里`1`表示点燃的蜡烛并且`0`表示不亮。 我们被要求达到目标配置`b`使用特殊操作。 在一次操作中，我们选择当前点燃的任何蜡烛； 所选蜡烛保持点亮状态，而所有其他蜡烛则翻转其状态。 我们的目标是确定是否可以转型`a`进入`b`，如果是，求所需的最少操作数。 

约束条件放弃`10^5`单个测试用例中的蜡烛，最多`10^4`测试用例，并且测试用例中所有蜡烛的总和上限为`10^5`。 这意味着任何解决方案都必须最多处理每根蜡烛恒定的次数才能保持在时间限制内。 对所有可能的操作序列进行简单模拟是不切实际的，因为每个操作都会影响所有蜡烛并且序列数量呈指数增长。 

当所有蜡烛都未点燃时，会出现微妙的边缘情况`a`，因为我们不能选择任何蜡烛进行操作。 例如，如果`a = "000"`和`b = "101"`，无法更改任何蜡烛，因为我们没有点燃的蜡烛可供选择。 另一种棘手的情况发生在`a`已经等于`b`。 我们必须认识到这一点并返回`0`立即行动。 

## 方法

 蛮力方法是模拟每个操作序列。 每个操作都可以应用于任何点燃的蜡烛，我们将检查所有序列以查看是否`b`是可达的。 这是正确的，因为它精确地模拟了操作，但其时间复杂度是指数级的，最坏情况下为 O(2^n)，因为该操作会翻转多根蜡烛并且序列数量会迅速爆炸。 

关键的观察结果是该操作具有非常具体的效果：选择一根点燃的蜡烛会翻转所有其他蜡烛。 这可以用计数来重新表述`1`沙`0`s。 如果我们在位置选择一根蜡烛`i`:

 - 选定的蜡烛保持不变`1`。 
- 所有其他蜡烛都会翻转。 

此操作要么保留蜡烛，要么翻转它，这意味着对字符串中 1 数量的影响是可预测的。 我们可以分析两种策略：

 1. 应用操作来尝试匹配位置`a[i] = b[i]`。 
2. 应用操作尝试反转所有位，然后进行匹配。 

通过仔细计算位置`a[i]`不同于`b[i]`以及它们相同的位置，我们可以计算最少的操作次数，而无需模拟每次翻转。 具体来说：

 - 如果`a`已经等于`b`，需要零运算。 
- 否则，最小操作数是以下位置的位置数：`a[i] = b[i]`或在哪里`a[i] ≠ b[i]`，取决于是否`a`至少包含一个`1`。 
- 如果没有`1`进入`a`但`a ≠ b`，变换不可能，返回`-1`。 

这种见解将问题从指数时间缩短为线性时间，每个测试用例为 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`,`a`， 和`b`。 
2. 检查是否`a`已经等于`b`。 如果是这样，则打印`0`并继续。 
3. 数一下数量`1`进入`a`和`b`。 如果`a`不包含`1`s，无法执行任何操作。 在这种情况下，打印`-1`。 
4. 计算有多少个位置`a[i]`等于`b[i]`（`same`）以及它们的不同之处（`diff`）。 
5. 如果`a`至少包含一个`1`，所需的最少操作是较小的`same`和`diff`。 这是有效的，因为：

 - 选择一根点燃的蜡烛并翻转其余的蜡烛可以修复已经正确的位置或翻转不正确的位置。 
- 不变的是，每次操作后，我们选择的蜡烛保持点亮，因此我们可以控制后续操作中哪些仓位受到影响。 
6. 打印最少操作次数。 

工作原理：操作仅取决于选择的蜡烛，单根点燃的蜡烛可以多次重复使用。 通过关注相等和不同位置的计数，我们可以保证使用最少的翻转达到目标配置。 该解决方案可以正确处理零亮情况和已经匹配的字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def menorah():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()

        if a == b:
            print(0)
            continue

        ones_a = a.count('1')
        if ones_a == 0:
            print(-1)
            continue

        same = sum(1 for i in range(n) if a[i] == b[i])
        diff = n - same
        print(min(same, diff))

if __name__ == "__main__":
    menorah()
```该解决方案可以快速读取输入`sys.stdin.readline`。 这`same`和`diff`计数使我们能够避免模拟翻转。 我们首先处理已经相等的情况并检查是否`a`至少有一个`1`在计算最少操作之前。 这些检查可以避免边缘情况错误。

 ## 边缘情况

 对于`a`全部为零并且`b`不同，算法打印`-1`立即地。 对于已经匹配的字符串，它会打印`0`。 这`same`和`diff`计数保证最少的操作`a`至少包含一个`1`。 例如，`a = "01", b = "11"`计算`same=1, diff=1`， 所以`min(1,1)=1`，正是所需的操作计数。 该代码处理边界长度`n=1`和最大`n`无缝地，因为所有循环都精确地迭代字符串长度。
