 ## 解决方案
 ## 问题理解

 我们有一个矩形棋盘，最多有$10^9$行和列。 两名玩家各控制一个棋子，要么是车，要么是象。 棋子按照通常的国际象棋移动规则移动：车沿行或列移动，而象沿对角线移动。 一旦玩家的棋子吃掉了对手的棋子，玩家就获胜。 两位棋手都知道自己的位置，并且总是选择能够最大化自己结果的棋步。 

输入包含几个独立的游戏。 对于每个游戏，我们都知道棋盘尺寸、毛伊棋子的起始方格和类型，以及莫阿娜棋子的起始方格和类型。 毛伊岛首先行动。 我们需要确定毛伊岛是否可以强行获胜，莫阿纳是否可以强行获胜，或者最佳发挥是否会导致无休止的平局。 

棋盘尺寸非常大，因此不可能模拟棋盘上的动作。 一块尺寸的板子$10^9 \times 10^9$有太多的细胞甚至一次都无法检查。 对于多达 5000 个测试用例，该解决方案只能使用坐标算术，而不能依赖于电路板面积。 

关键的边缘情况来自不同运动类型的相互作用。 例如，单行上有两个车：```
1
1 10
1 5 R
1 7 R
```正确答案是`WIN`。 仅检查当前棋子是否可以立即捕获的粗心方法在这里仍然有效，但在玩家可以移动到获胜方格而不立即捕获的位置上，它会失败。 

另一个重要的情况是两个主教的颜色相同：```
1
4 4
4 4 R
1 1 B
```正确答案是`DRAW`。 车可以移动到主教的对角线上并最终捕获，但双方都可以永远避免给对手安全的捕获机会。 仅检查棋子是否互相攻击会错过这种类型的位置。 

最后一个常见错误是忽略了板边界。 例如：```
1
2 2
1 2 R
2 1 B
```正确答案是`WIN`。 车可以移动到主教无法立即做出反应的唯一方格。 生成无限的棋线而不是检查交点是否留在棋盘内可能会产生无效的移动。 

## 方法

 一个简单的想法是模拟博弈树。 从每个位置生成所有可能的移动，递归地评估结果位置，并在有人捕获时停止。 这是正确的，因为如果有人最终获胜，游戏就是有限的，而极小极大描述了最佳游戏。 然而，车几乎可以有$2 \cdot 10^9$在一个巨大的棋盘上可能的走法，因此即使生成一次走法也是不可能的。 最坏的情况与电路板尺寸成正比，无法满足约束条件。 

有用的观察是，玩家只需要知道他们是否可以移动到可以创造有保证的捕获机会的方格。 假设一名玩家移动到一个方格并从中攻击对手。 对手有一个回合做出反应。 如果对手能够立即吃掉攻击棋子，则计划失败。 否则，第一个玩家将在下一步中占领。 这意味着唯一相关的问题是是否存在一个可到达的方格可以攻击对手但不被对手攻击。 

可能获胜的方格不会分布在整个棋盘上。 它们是运动线之间的交叉点。 车贡献行和列，而主教贡献对角线。 将这些小集合相交最多给出四个候选方格。 我们可以使用坐标公式直接检查每个候选者。 

在计算当前玩家是否有此获胜动作后，我们将相同的逻辑应用于对手。 如果两个玩家都在自己的回合中强制获胜，则第一个玩家获胜，因为他们先移动。 如果只有对手有这样的举动，则第一个玩家就输了。 如果双方都没有，那么双方都可以避免永远失败，所以结果是平局。

 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 实现一个函数来检查一个棋子是否攻击另一个棋子。 对于车来说，这意味着共享行或列。 对于主教来说，这意味着具有相同的值$x-y$或者$x+y$。 
2. 实现一个判断玩家是否有必胜棋步的函数。 如果当前棋子已经攻击对手，玩家可以立即吃掉并获胜。 
3. 如果没有立即吃子，则构建当前棋子和对手方格的移动线。 每个可能让当前玩家攻击对手的方格都必须位于这些线的交点之一上。 
4. 生成这些线的所有交点。 由于每个棋子最多有两个运动线族，因此只有恒定数量的可能交叉点。 
5. 对于每个候选方格，检查三个条件。 该方格必须在棋盘内，当前棋子必须可以到达，并且对手不能攻击该方格。 如果存在这样的格子，则当前玩家强制获胜。 
6. 评估毛伊岛的强取胜能力。 如果 Maui 无法强行获胜，则评​​估 Moana 是否可以在回合改变后从相同位置强行获胜。 如果莫阿娜可以的话，答案是`Lose`; 否则答案是`Draw`。 

为什么它有效：不变量是每一个获胜的动作都必须经过一个方格，移动的玩家从该方格攻击对手并且不能立即被捕获。 如果存在这样的方格，则玩家最多在两回合内获胜。 如果不存在这样的方格，则每次制造直接威胁的尝试都可以被对手回应，因此不再有顺序可以创造强制胜利。 由于两名玩家都遵循相同的规则，因此三种可能的结果完全是通过检查两名玩家的获胜能力来确定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def attacks(piece, a, b):
    x1, y1, _ = a
    x2, y2, _ = b
    if piece == 'R':
        return x1 == x2 or y1 == y2
    return x1 - y1 == x2 - y2 or x1 + y1 == x2 + y2

def lines(piece, x, y):
    if piece == 'R':
        return [('v', x), ('h', y)]
    return [('d1', x - y), ('d2', x + y)]

def intersect(l1, l2):
    t1, a = l1
    t2, b = l2

    if t1 == t2:
        return None

    if t1 > t2:
        t1, a, t2, b = t2, b, t1, a

    if t1 == 'h' and t2 == 'v':
        return a, b
    if t1 == 'v' and t2 == 'd1':
        return a, a - b
    if t1 == 'v' and t2 == 'd2':
        return a, b - a
    if t1 == 'h' and t2 == 'd1':
        return b + a, a
    if t1 == 'h' and t2 == 'd2':
        return b - a, a
    if t1 == 'd1' and t2 == 'd2':
        if (a + b) % 2 != 0:
            return None
        return (a + b) // 2, (b - a) // 2

def inside(x, y, n, m):
    return 1 <= x <= n and 1 <= y <= m

def can_win(n, m, cur, opp):
    x, y, c = cur

    if attacks(c, cur, opp):
        return True

    for a in lines(c, x, y):
        for b in lines(opp[2], opp[0], opp[1]):
            p = intersect(a, b)
            if p is None:
                continue
            nx, ny = p
            if not inside(nx, ny, n, m):
                continue
            if (nx, ny) == (opp[0], opp[1]):
                continue
            if not attacks(c, cur, (nx, ny, c)):
                continue
            if not attacks(opp[2], opp, (nx, ny, opp[2])):
                return True
    return False

def solve():
    t = int(input())
    ans = []
    for _ in range(t):
        n, m = map(int, input().split())
        x1, y1, c1 = input().split()
        x2, y2, c2 = input().split()
        p1 = (int(x1), int(y1), c1)
        p2 = (int(x2), int(y2), c2)

        if can_win(n, m, p1, p2):
            ans.append("Win")
        elif can_win(n, m, p2, p1):
            ans.append("Lose")
        else:
            ans.append("Draw")
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```这`attacks`函数将国际象棋规则隔离到一处，从而避免重复车和象逻辑。 对角线检查使用标准不变量$x-y$和$x+y$，所以即使坐标大到$10^9$。 

这`intersect`函数处理每对可能的运动线。 行、列或对角线上没有循环，因为几何图形仅给出恒定数量的可能获胜方格。 

主例程首先检查毛伊岛，因为回合顺序很重要。 如果毛伊岛有制胜之举，莫阿娜永远没有机会使用自己的制胜策略。 否则，检查莫阿娜决定`Lose`和`Draw`。

 ## 边缘情况

 对于共享一行的两个车，该算法立即返回胜利，因为`attacks`在寻找中间方块之前找到捕获线。 巨大的棋盘尺寸并不重要，因为只比较坐标。 

对于小棋盘上的车和象的位置，该算法生成车线和象对角线的可能交点。 它拒绝棋盘外的交叉点，只接受对手无法立即占领的方格。 这可以防止非法的“无限棋盘”移动。 

对于两个玩家都没有安全获胜方格的位置，算法会检查两个方向。 如果双方都无法强行占领，则每个玩家都可以继续移动而不放弃失败的位置，因此正确的结果是`Draw`。
