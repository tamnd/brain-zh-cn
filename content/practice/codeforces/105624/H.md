 ## 解决方案
 ## 问题理解

 任务是将最小数量的整数添加到现有数组中，以便最终排序数组的中位数恰好变为`x`。 中位数定义是排序后左边中间的元素，这意味着对于长度为`m`，中位数是位置处的元素`(m + 1) // 2`使用基于一的索引。 这与原始问题所使用的下中值约定相同。 

输入给出当前值的数量、所需的中值和数组本身。 我们只能插入新值，而不能修改现有值。 输出是所需插入值的最小数量。 

数组长度最多为 500，这意味着甚至是左右的解`O(n^2)`可以适合。 然而，问题的结构允许更简单的`O(n log n)`排序后的方法。 重要的观察是，只有小于的值的数量`x`，等于`x`，并且大于`x`影响答案。 我们不需要模拟实际的插入。 

粗心的解决方案通常会在以下情况下失败：`x`不存在或当前中位数接近但不完全一致`x`。 例如：```
3 10
10 20 30
```答案是`1`。 只计算现有的解决方案`x`值会失败，因为`x`已经存在，但当前中位数是`20`。 

另一个例子：```
3 4
1 2 3
```答案是`4`。 只添加一个`4`给出`[1,2,3,4]`，其中位数为`2`， 不是`4`。 最终数组必须包含足够的值大于或等于`4`使中间位置达到插入的值。 

第三个常见错误是错误处理已经正确的中位数：```
5 3
1 2 3 4 5
```答案是`0`。 任何总是插入的解决方案`x`当它出现时会产生错误的肯定答案。 

## 方法

 一种直接的蛮力想法是尝试将值逐一相加，并检查中位数是否变为`x`。 由于长度变化时中位位置也会变化，所以这需要对数组进行重复排序或计数。 如果我们尝试许多可能的插入计数，检查次数很快就会变成不必要的工作。 由于相关变体的输入大小较大，重复重建排序数组成为瓶颈。 

关键的观察是实际插入的值是灵活的。 我们可以插入小于以下的值`x`，等于`x`，或大于`x`，这三组都很重要。 

让`less`是现有值的数量小于`x`， 和`equal`现有值的数量等于`x`。 排序后，中位位置必须位于所有小于的值之后`x`，但毕竟值不等于`x`。 

如果`x`缺失，我们首先插入一个副本`x`。 之后，我们只需要围绕中位位置重新平衡计数即可。 如果`x`已经存在了，我们可以直接将中位位置移动到`x`通过在必要的一侧添加值来获取值。 

可以通过考虑插入后中位数的位置来贪心地实现`x`如有必要，则仅添加移动中值边界所需的最少数量的值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(答案 × n log n) | O(n) | 总体来说太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对数组进行排序，找到包含的第一个和最后一个位置`x`。 对所有小于的值进行排序`x`，等于`x`，并且大于`x`分成不同的范围，这让我们只能对计数进行推理。 
2.如果`x`不存在，插入一份`x`从概念上讲，并将答案加一。 中位数必须是现有值，因此如果不进行此插入，目标值就无法成为中位数。 
3. 使用从零开始的索引计算当前数组的中值位置：`(n - 1) // 2`。 
4. 如果该位置已经落入等于的值块内`x`，不再需要插入。 
5. 如果中间位置在第一个之前`x`，有太多小于的值`x`。 添加大于或等于的值`x`直到中间位置移动到`x`堵塞。 
6.如果中间位置在最后一个之后`x`，有太多值大于`x`。 添加小于或等于的值`x`直到中间位置达到`x`。 

为什么它有效：排序后的数组分为三个区域。 中位数失败的唯一方法是中位数索引位于由`x`。 在对面添加数字会移动边界，而不会破坏现有的`x`堵塞。 由于每次插入都会以尽可能小的量改变中值位置，因此贪婪的添加是最小的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))

    ans = 0

    if x not in a:
        a.append(x)
        n += 1
        ans += 1

    a.sort()

    left = 0
    while left < n and a[left] < x:
        left += 1

    right = left
    while right < n and a[right] == x:
        right += 1

    median = (n - 1) // 2

    if left <= median < right:
        print(ans)
        return

    if median < left:
        need = 2 * left - n + 1
        ans += need
    else:
        need = n - 2 * right
        ans += need

    print(ans)

if __name__ == "__main__":
    solve()
```第一部分处理特殊情况，其中`x`缺席。 添加`x`是强制性的，因为中位数必须是最终排序数组的元素。 

排序后，`left`指向第一次出现的`x`， 和`right`最后一次出现之后的点`x`。 间隔`[left, right)`正是中位数指数必须落地的安全区。 

当中位数索引太小时，数组包含太多以下值`x`。 添加较大的值会增加数组长度并将中间位置向右推。 当中值索引太大时，添加较小的值会使中值位置向左移动。 该公式计算所需的最少班次。 

表达式仅使用整数算术。 Python 整数不会溢出，但在具有固定宽度整数的语言中的相同公式仍应仔细检查。

 ## 边缘情况

 当`x`不存在，算法首先插入它。 对于输入：```
1 7
1
```数组变成`[1,7]`。 中位指数为`0`，所以中间下层的元素是`1`。 该算法检测到中位数在`x`块并添加一个更大的值，产生答案`1`。 

当所有值已经相等时`x`，中值块覆盖整个数组。 为了：```
5 5
5 5 5 5 5
```第一个和最后一个位置`x`包围中值索引，因此算法返回`0`。 

当下面的值太多时`x`，算法将中位数向右移动。 为了：```
3 10
1 2 3
```缺失值案例插入`10`，那么需要额外的值，因为中间位置仍然被小数字占据。 最终答案仅由中位位置到`x`块，而不是插入的实际值。
