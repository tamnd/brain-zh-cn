 ## 解决方案
 ## 问题理解

 我们得到了建立在直线基线上的几何配置。 三个点按 B、C、D 的顺序位于一条直线上，从 B 到 C 的线段与从 C 到 D 的线段的长度相同。第四个点 A 放置在该线上方，形成共享 A 点的两个三角形：三角形 ABC 和三角形 ACD。 

已知两个角度。 第一个是线段 BA 和 BD 之间在 B 处形成的角度，第二个是线段 CA 和 CD 之间在 C 处形成的角度。 仅根据这两个角度约束以及 BC 等于 CD 的事实，任务是确定 DA 和 DC 之间的三角形 ACD 内形成的 D 处的角度。 

输入由两个实值角度 α 和 β 组成，每个角度严格介于 1 到 90 度之间。 输出是表示高精度 ∠ADC 的单个实数。 

限制非常小，所以不用担心性能。 真正的挑战是将严格的几何配置转变为稳定的代数表达式。 这类问题对坐标设置和角度解释很敏感。 一种常见的故障模式是误解每个角度的测量方向，特别是因为 ABD 和 ACD 是沿同一基线在不同顶点定义的。 

第二个微妙的问题是 A 不能保证位于 BD 中点的正上方。 根据 α 和 β，该点可能会水平移动到线段 BC 之外，因此任何假设图形对称的推理都会默默地失败。 

## 方法

 强力方法会尝试将问题视为一般几何构造：选择满足所有约束的 A、B、C 和 D 坐标，然后对 A 进行数值调整，直到两个角度条件匹配。 这自然会导致具有三角约束的非线性方程组。 人们可以尝试迭代求解器或数值优化，反复调整坐标，直到两个角度都符合所需的值。 

原则上这是可行的，因为该配置完全由两个独立的角度约束和一个固定的长度比决定。 然而，搜索空间是连续的，约束是非线性的。 朴素采样或基于梯度的方法将需要每个测试用例进行多次迭代，并且在 A 几乎与基线共线的简并配置附近会出现数值不稳定。 

关键的观察结果是，一旦我们固定与基线对齐的坐标系，几何图形就会变得完全刚性。 我们可以直接使用三角方向对约束进行编码，而不是搜索。 B 处的角度固定了线 BA 的方向，C 处的角度固定了线 CA 的方向。 使这两条射线相交明确给出 A。 一旦 A 的坐标已知，D 处的剩余角度就是直接矢量角度计算。 

这减少了从连续搜索到封闭形式构造的问题。

 ## 算法演练

 我们首先对几何体进行标准化以消除缩放自由度。 由于 BC 等于 CD，我们将三个共线点放置在 x 轴上，B 为 0，C 为 1，D 为 2。这保留了所有比率和角度，因为配置在均匀缩放下保持不变。 

然后我们将点 A 表示为由给定角度确定的两条射线的交点。

1. 将 B 放置在 (0, 0) 处，将 C 放置在 (1, 0) 处，将 D 放置在 (2, 0) 处。 这将等段约束直接编码为坐标。 
2. 解释 B 处的角度，即 BA 和 BD 之间的角度。 由于 BD 沿着正 x 轴，因此射线 BA 与水平面形成角度 α。 对于某些 t > 0，给出 A = t(cos α, sin α)。 
3. 解释 C 处的角度，即 CA 和 CD 之间的角度。 由于 CD 也沿着正 x 轴，因此射线 CA 与水平面形成角度 β。 对于某些 s > 0，给出 A = (1, 0) + s(cos β, sin β)。 
4. 通过使坐标相等来求解两条参数线的交点。 这会在 t 和 s 中产生一个线性系统，从而产生 A 的封闭式表达式。 
5. 一旦 A 已知，形成向量 DA = A − D 和 DC = C − D。所需角度 ∠ADC 是这两个向量之间的角度。 
6. 使用点积公式计算该角度：cos θ = (DA · DC) / (|DA||DC|)。 将 θ 转换回度数。 

关键思想是所有几何约束都分解为两条射线，其交点唯一地定义了配置。 

### 为什么它有效

 该构造通过将 B、C 和 D 固定在一条线上并使用给定角度为 BA 和 CA 指定方向来强制消耗平面中的所有自由度。 这两条射线相交于一点，因为该问题保证了有效的配置。 一旦 A 被唯一确定，所有剩余的角度都是欧几里得几何的固定结果。 不需要近似或迭代调整，因此数值稳定性仅取决于三角函数的标准浮点计算。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    alpha, beta = map(float, input().split())

    a = math.radians(alpha)
    b = math.radians(beta)

    B = (0.0, 0.0)
    C = (1.0, 0.0)
    D = (2.0, 0.0)

    sin_a, cos_a = math.sin(a), math.cos(a)
    sin_b, cos_b = math.sin(b), math.cos(b)

    denom = cos_a - sin_a * (cos_b / sin_b)
    t = 1.0 / denom

    Ax = t * cos_a
    Ay = t * sin_a

    Dx, Dy = D
    Cx, Cy = C

    dax = Ax - Dx
    day = Ay - Dy

    dcx = Cx - Dx
    dcy = Cy - Dy

    dot = dax * dcx + day * dcy
    da_len = math.hypot(dax, day)
    dc_len = math.hypot(dcx, dcy)

    cos_theta = dot / (da_len * dc_len)
    cos_theta = max(-1.0, min(1.0, cos_theta))

    theta = math.degrees(math.acos(cos_theta))
    print(theta)

if __name__ == "__main__":
    solve()
```实现首先将角度转换为弧度，因为 Python 中的所有三角函数都以弧度进行运算。 通过为 B、C 和 D 指定显式坐标来固定基线。 

两个角度约束被转换为方向向量。 从 B 到 A 的直线表示为方向由 α 确定的射线，从 C 到 A 的直线同样由 β 确定。 它们的交集是通过代数求解单个标量方程来计算的。 

一旦计算出 A，D 处的角度就可以纯粹使用点积从向量几何中获得。 将余弦限制在有效区间 [-1, 1] 中可以防止浮点漂移对 acos 产生无效输入，这是几何问题中运行时 NaN 的常见来源。

 ## 边缘情况

 一种微妙的情况是当 α 和 β 非常接近 90 度时。 在这种情况下，来自 B 和 C 的光线变得几乎垂直且几乎平行，这可能会使相交计算在数值上不稳定。 该实现避免了失败，因为它从未使用除以 x 坐标的微小差异来显式求解几乎平行线的系统。 相反，它将一切简化为从三角恒等式导出的单个代数表达式，只要 sin(β) 不为零，该代数表达式就保持稳定，这是由约束保证的。 

另一种情况是两个角度都非常小时。 这里两条射线几乎是水平的，并且 A 远离线段 BC。 坐标系仍然成立，因为缩放比例是固定的，并且交集公式保持良好条件，因为两个方向的斜率略有不同。 

最后的隐式边缘情况是 A 位于线段 BC 投影之外很远的情况。 该算法不假设 A 的任何有界位置，因此无论 A 位于线段的左侧还是右侧，D 处基于矢量的角度计算仍然有效。
