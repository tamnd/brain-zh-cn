 ## 解决方案
 ## 问题理解

 我们被要求构建从 1 到 n 的整数排列。 对于此排列的每个子数组，我们计算一个值，该值取决于其中数字的分布情况。 具体来说，对于一段 p[i..j]，我们取该段中的最大值，减去最小值，然后减去该段的长度。 当值紧密排列且段较短时，这会产生较小的成本；而当段较长或具有较大的值差距时，该成本会变大。 

排列的总分是所有可能子数组的成本之和。 任务是找到使总分最小化的排列。 在所有达到最低分数的排列中，我们必须输出字典顺序最大的排列。 

约束允许 n 最大为 200,000，因此任何尝试显式评估所有子数组的解决方案都是立即不可能的。 子数组的数量是二次的，甚至计算每个子数组的最小值和最大值也会导致三次行为。 

一个微妙的点是，目标仅取决于值的相对顺序，而不是它们的绝对同一性，因为排列始终是 1 到 n。 另一个重要的观察结果是，每个子数组都贡献了一个涉及最大值和最小值的项，这表明在许多段中变得极端的元素对成本有很大的影响。 

一种简单的方法可能会尝试在跟踪所有子数组的贡献的同时进行局部推理或贪婪地选择元素，但这种方法通常会失败，因为插入一个值会以高度非局部的方式影响穿过其位置的所有段。 

一个小例子凸显了敏感性。 对于 n = 3，排列 1 2 3 和 3 2 1 的行为不同，因为中间元素决定有多少段具有小范围。 总是在没有全局模式的情况下将小值或大值放在末端的贪婪算法很容易错过真正的最优结构。 

## 方法

 暴力方法将生成所有排列并计算每个排列的总成本。 即使我们有一种有效的方法来计算 O(n^2) 中单个排列的成本，排列的数量也是 n!，这是完全不可行的。 即使仅限于评估一种排列，仍然需要迭代所有 O(n^2) 子数组，并且计算 min 和 max 会给每个子数组带来 O(n) 复杂度，从而导致总工作量为 O(n^3) 。 

我们需要了解什么排列结构会减少总贡献。 段的成本由最大值和最小值驱动。 如果一个段在排列中具有连续的整数，则其范围较小并且成本降低。 这表明我们希望避免连续段内的大跳跃，而是希望对值进行排列，以便以受控的方式分离极端值。 

一个关键的转换是根据每对元素在子数组上成为最大值或最小值的频率来重写问题。 表达式 max 减去 min 可以解释为对的贡献，其中一个元素成为段中的最大值，另一个元素成为最小值。 负长度项推动较短的段，总体上贡献较少的惩罚。 

出现的结构是，通过将最大的元素放在前面或最后，然后以保持排列尽可能“居中”的方式向外递归填充来构建最佳排列。 然而，因为我们还需要在最佳解决方案中按字典顺序排列最大值，所以只要对称性允许，我们更喜欢将较大的元素放在较早的位置。

这导致了一种建设性的模式：我们从两端向内构建排列，总是选择最大的剩余数字并将其放置在保持最佳平衡的位置，并偏向较早的位置以满足字典序最大化。 

在贡献对称性下进行分析时，最佳配置结果是一个简单的递减序列，因为将较小数字放在较大数字之前的任何偏差都倾向于创建额外的子数组，其中 max-min 变大，同时无法通过长度减小进行充分补偿。 

因此，解决方案简化为按顺序排列从 n 到 1 的数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!·n²) | O(n!·n²) | O(n) | 太慢了|
 | 优化施工| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们直接构造排列。 

1. 初始化一个大小为 n 的空列表 p。 这将存储最终的排列。 
2. 从最大值n开始，向下移动到1。 
3. 对于从 n 到 1 的每个值 x，将 x 附加到 p。 

这会将较大的值放在排列的前面，这对于最大化最佳解决方案之间的字典顺序是必要的。 
4. 输出构造好的列表。 

这种简单构造就足够的原因是，任何替代安排都会引入一对索引，其中较小的值在较大的值之前，从而增加了范围不必要地扩展的子数组的数量。 降序排列可以最大限度地减少两个极端相距很远的段的创建，因为大值集中在前面，而逐渐变小的值只会缩小可能的范围。 

### 为什么它有效

 关键的不变量是，将排列的前 k 个元素设置为 n, n−1, …, n−k+1 后，在此前缀内开始的每个子数组的最大值都已立即由该子数组的第一个元素确定。 这可以稳定许多段中 max 的贡献，并防止在数组中较小的元素出现在较大元素之前时出现的额外变化。 

i < j 但 p[i] < p[j] 形式的任何反转都会创建额外的子数组，其中最大值不是在左边界局部确定的，从而增加了许多段之间 max-min 的可变性。 降序排列完全消除了这种倒置，使所有基于前缀的最大值单调并最小化总体扩展贡献。 

由于该结构在最佳配置中在对称性方面也是唯一的，因此它在所有最佳解决方案中按字典顺序是最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    res = list(range(n, 0, -1))
    print(*res)

if __name__ == "__main__":
    solve()
```该实现直接以相反的顺序构造排列。 唯一重要的细节是确保正确的空格格式，并通过使用 Python 的范围和步骤 -1 来避免任何差一错误。 

立即打印而不是构建增量结构的决定避免了不必要的开销。 由于排列是确定性的，因此不需要额外的数据结构。 

## 工作示例

 ### 示例 1：n = 3

 我们一步步构建序列。 

| 步骤| 当前 x | 排列|

 | 2 | 2 | 3 2 |
 | 3 | 1 | 3 2 1 | 3 2 1

 最终输出是 3 2 1。这证实了该构造始终首先附加最大的剩余元素。 

此示例演示了排列如何构建严格递减的结构而不会产生歧义，从而确保候选者之间的字典顺序最大排序。

该跟踪强调不需要重新排序决策，这与构造中不存在局部权衡是一致的。

 ## 边缘情况

 主要的边缘情况是 n = 1。该算法产生单元素排列 [1]，它通常不具有长度大于 1 的子数组，因此所有成本项都为零。 这与最优性是一致的。 

对于 n = 2，该算法生成 2 1。唯一的子数组是 [2]、[1] 和 [2,1]。 降序确保唯一长度为 2 的段的 max-min 等于 1，并且没有替代排列可以在不增加结构不平衡的情况下改善字典顺序。 

一个稍微不那么简单的情况是 n = 3。该算法生成 3 2 1。无反转结构确保每个前缀都有稳定的最大值，并且没有替代排列可以在不引入更大字典序惩罚的情况下减少贡献，即使在最小的非对称多元素情况下也能确认正确性。
