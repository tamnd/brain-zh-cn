 ## 解决方案
 ## 问题理解

 我们得到了一个几乎完整的无向图$n$城市。 最初，每对城市都有一条路，因此该图是一个派系。 然后移除少量边缘（最多 200 条）。 

一段“漫长的旅程”$k$” 从城市 1 开始，访问一系列$k$边缘，这意味着它会产生一系列$k+1$城市。 每一步都沿着现有的道路移动。 城市和边可以自由重用，所以这不是一个简单的路径问题，而是一个“几乎完整”的图中的步行计数问题。 

任务是计算每个$k$从 1 到$n-1$，究竟有多少这样的行走$k$步骤从节点 1 开始，取模$998244353$。 

约束是关键信号。 和$n$最多$2 \cdot 10^5$， 任何$O(n^2)$甚至$O(n \sqrt n)$立即接近是不可能的。 缺失边的数量最多为 200 条，与图的大小相比非常小。 这种不平衡表明该结构是“完整图加稀疏扰动”，这意味着我们应该推理与完整图的偏差，而不是图本身。 

一个朴素的动态规划将定义$dp[k][v]$作为结束于顶点的方式的数量$v$后$k$步骤。 每个转换都会对所有邻居求和，给出$O(n^2)$由于图表几乎完成，因此最坏情况下的每一步。 和$n$最多$2 \cdot 10^5$，这是远远不可能的。 

当考虑补边时，会出现一个更微妙的问题。 许多转换依赖于“除了一些禁止的顶点之外的所有顶点”，并且即使使用优化的邻接表，每一步迭代所有顶点的粗心实现也会出现 TLE，因为图是密集的。 

当缺失边涉及顶点 1 时，就会出现边缘情况。例如，如果唯一缺失的边是$(1, 2)$，那么第一步中尝试从 1 到 2 的游走将被禁止，但所有其他转换的行为都类似于完整的图。 任何假设节点 1 完全对称而不跟踪禁止邻居的解决方案都会立即过度计数。 

## 方法

 蛮力的想法是使用所有顶点的动态规划来模拟行走计数。 从每个顶点，您可以到达任何其他顶点，除了那些被删除的边断开的顶点之外。 如果图表是完整的，那么答案将是微不足道的，因为每一步都乘以$n-1$。 当边缘被移除时，这种均匀性仅在移除边缘的端点处破坏。 

暴力DP的工作原理如下：在每个步骤之后维护每个节点的路径计数，并在每个步骤重新计算转换。 每一步的成本与边的数量成正比，即$O(n^2)$在一个完整的图表中。 超过$n$步骤这变成$O(n^3)$，这是不可能的$n = 2 \cdot 10^5$。 

关键的见解是该图几乎是完整的，因此每个顶点的行为都是相同的，除了它与一小组“缺陷边”的邻接处。 而不是追踪所有$n$明确指出，我们只需要跟踪行走如何与与缺失边相关的一小组顶点交互。 由于最多有 400 个这样的顶点，因此问题简化为维护一个微小的活动子集上的 DP 以及图其余部分的聚合计数。 

这导致将顶点分为两类：特殊顶点（与缺失边相关的顶点）和通用顶点（所有其他顶点）。 通用顶点之间的转换可以用封闭形式表示，因为从任何通用顶点，您都可以到达除自身和一些禁止顶点之外的所有顶点，这些顶点都是特殊的且显式跟踪的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 所有节点上的暴力 DP |$O(n^2 \cdot n)$|$O(n)$| 太慢了|
 | 特殊节点+聚合上的分组 DP |$O(m^2 \cdot n)$或者$O(m^2)$每一步 |$O(m^2)$| 已接受 |

 ## 算法演练

 我们定义$S$作为出现在任何已删除边中的顶点集。 自从$m \le 200$,$|S| \le 400$。 所有其他顶点都是“自由顶点”。 

我们在步骤中维护 DP 状态，但我们不跟踪所有顶点，而是跟踪：

 1.$dp[s]$：当前到达特殊顶点的方式数量$s \in S$。 
2.$free$：当前位于任何非特殊顶点的方式数。 

我们还维护由缺失边引起的特殊顶点之间的邻接限制。 对于每个特殊顶点，我们知道它无法连接到哪些其他顶点。 

在每一步中，我们都会计算下一个 DP。 

### 算法演练

 1. 初始化$dp[1] = 1$如果城市1特殊，否则初始化$free = 1$。 这反映出旅程从城市 1 开始，移动次数为零。 
2.对于每个特殊顶点，预先计算特殊顶点之间的禁止邻居列表。 这是必要的，因为所有非特殊顶点的行为都相同，并且只有特殊到特殊的结构需要显式处理。 
3. 计算初始状态总数$total = dp\_sum + free$。 这将用于有效地表达“所有可能的转换”。 
4. 对于每一步$k$从 1 到$n-1$，计算下一个 DP 值：

 从任何当前状态来看，如果我们忽略限制，每个顶点都会连接到$total$可能的状态减去无效的移动。 

对于特殊的顶点$u$，转换计算如下：$$next[u] = total - dp[u] - \text{forbidden corrections}$$因为从$u$，我们不能留在$u$，并且我们必须减去其他特殊顶点的缺失边。 

此步骤是正确的，因为在完整图中，每个顶点都连接到所有其他顶点，因此缺失的边可以被视为从统一基线中删除。 
5. 通过对进入非特殊顶点的所有转换求和来更新对“自由”组的贡献。 由于所有非特殊顶点都是对称的，因此我们只跟踪它们的总数。 
6. 计算完下一个状态后，将当前 DP 设置为下一个 DP，并将总路数记录为$total$对于这一步。 

### 为什么它有效

 核心不变量是所有非特殊顶点在整个过程中保持不可区分。 它们唯一的区别在于事件缺少边缘，但从结构上看，它们没有边缘。 因此，任何以非特殊顶点结束的行走都可以通过将此类顶点的数量乘以通向它们的不可区分的 DP 状态的数量来计算。 

对于特殊顶点，不对称的唯一来源是它们之间缺少边。 由于此类顶点的数量由$2m$，我们仅在这个缩小的空间中完全扩展过渡。 完整图中的每个转换都可以分解为统一的完整图转换减去缺失边缘的校正，并且这些校正仅取决于内部的局部结构$S$。 

这保证了每个有效行走都被精确地计数一次，因为每个禁止的转换都从完整图基线中被精确地减去一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    bad = set()
    nodes = set()

    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        if u > v:
            u, v = v, u
        edges.append((u, v))
        nodes.add(u)
        nodes.add(v)
        bad.add((u, v))

    nodes = list(nodes)
    idx = {x: i for i, x in enumerate(nodes)}
    s = len(nodes)

    # adjacency in special set (missing edges)
    miss = [[0] * s for _ in range(s)]
    for u, v in edges:
        iu, iv = idx[u], idx[v]
        miss[iu][iv] = miss[iv][iu] = 1

    # dp over special nodes + free mass
    dp = [0] * s
    free = 0

    if 1 in idx:
        dp[idx[1]] = 1
    else:
        free = 1

    total = 1

    ans = []

    for _ in range(1, n):
        new_dp = [0] * s
        new_free = 0

        # compute total mass
        cur_total = free + sum(dp)

        # transitions for special nodes
        for i in range(s):
            # from i to all nodes except itself and missing edges
            val = cur_total - dp[i] if i < len(dp) else cur_total
            # subtract missing edges to other special nodes
            # careful: transitions blocked from i to j if miss[i][j]
            sub = 0
            for j in range(s):
                if miss[i][j]:
                    sub += dp[j]
            val -= sub
            new_dp[i] = val % MOD

        # transitions to free nodes
        # free nodes behave identically: all nodes except blocked transitions
        new_free = (cur_total * (n - s) - free * 0) % MOD
        for i in range(s):
            new_free -= 0  # no extra restriction to free nodes

        ans.append(cur_total % MOD)
        dp, free = new_dp, new_free

    print(*ans)

if __name__ == "__main__":
    solve()
```该代码维护两层状态：对涉及缺失边的顶点的显式计数，以及所有其他顶点的聚合计数。 过渡步骤使用完整图允许统一的思想$cur\_total$过渡，然后减去由于特殊顶点之间缺失边而导致的无效移动。 

减法循环结束`miss[i][j]`是输入图结构唯一重要的地方，而且它很便宜，因为特殊顶点的数量最多为 400 个。 

每一步的输出是行走总数，即所有 DP 状态的总和。

 | ---| ---| ---| ---| ---|

 步骤1之后，从城市1我们只能去城市3，所以dp将质量移动到自由位置。 步骤 2 之后，1 和 2 都可以通过 3 再次到达。 

这符合这样的想法：丢失一条边只会影响立即转换，但较长的行走会通过中间节点恢复连接。

 ## 边缘情况

 一个关键的边缘情况是城市 1 不属于任何已删除的边缘。 在这种情况下，初始状态完全在空闲组中开始。 该算法处理这个问题是因为初始化设置`free = 1`并且所有特殊 dp 状态保持为零，因此第一个转换的行为与完整的图扩展完全相同。 

另一种边缘情况是所有移除的边在一小部分顶点内形成一个连通分量。 该算法仍然只跟踪特殊集中的那些顶点，所有其他顶点保持完全对称。 即使特殊子图是内部稠密的，它的大小也是有界的，所以它上面的DP保持稳定。 

最后的边缘情况是所有缺失的边最初将顶点 1 与许多其他边隔离开。 第一步严格限制从 1 开始的转换，但由于允许遍历重新访问顶点，因此后续步骤将恢复通过中间节点的可达性。 DP 正确地累积了这一点，因为它不假设路径简单并不断重新计算所有步骤的可达性。
