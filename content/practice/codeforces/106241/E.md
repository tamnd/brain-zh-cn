 ## 问题理解

 我们有一排多米诺骨牌，每张都有高度和成本。 启动任何动作的唯一方法是手动推动选定的多米诺骨牌，并支付各自的成本。 一旦多米诺骨牌倒下，它可能会引发确定性的向右连锁反应：位置 j 处倒下的多米诺骨牌将撞击 j+1，但前提是它严格高于其右邻居。 如果这种情况成立，下降会继续向前，可能会通过长时间的高度下降而级联。 

目标是选择一个多米诺骨牌子集来手动推动，以便每个多米诺骨牌最终倒下，同时最小化所选启动推动的总成本。 

关键的结构细节是，链式反应只能向右移动，并且只能沿着严格降低的相邻高度成功。 任何非递减边界都会阻止传播，除非我们明确地在其之外或内部开始新的推送。 

这些约束促使我们为每个测试用例提供线性或近线性解决方案。 所有测试用例的总 n 高达 2·10^5，每个测试用例的 O(n²) 甚至 O(n log n) 方法将太慢。 这强烈建议采用贪婪或单调堆栈式解决方案，其中每个多米诺骨牌被处理一次或恒定次数。 

当思考“推动每个局部最大值”或“推动所有增加的断点”时，就会出现微妙的失败案例。 例如，考虑高度`[3, 1, 2]`。 如果我们只推送索引 1，它会下降到 2，因为 3 > 1，但随后会停止，因为 1 < 2 会中断传播。 我们仍然需要推送索引 3。仅基于本地比较的幼稚策略会忽略成本权衡：有时根据链实际传播的距离，提前或推迟推送会更便宜。 

另一个棘手的场景是单调增加的数组，例如`[1, 2, 3, 4]`。 没有多米诺骨牌可以向右传播，因此必须单独推动每张多米诺骨牌。 任何假设在增加的段中至少部分传播的解决方案都会低估答案。 

最后，在严格递减数组中，例如`[5, 4, 3, 2]`，在第一个位置按一次就足够了，其他所有位置都免费落下。 这是极端相反的行为，也是分段贪婪合并变得至关重要的地方。 

## 方法

 强力解释是选择索引的任何子集来推动，模拟产生的级联，并检查是否所有多米诺骨牌都倒下。 这是正确的，但不可行。 有 2^n 个子集，每次模拟都需要 O(n)，导致指数时间。 

更结构化的观点是询问推送实际上“涵盖”了什么。 在位置 i 处按下会激活右侧的最大连续段，其中高度从段的开头严格减小。 一旦这种递减的属性被破坏，级联就会停止，除非单独激活，否则超出该点的所有内容都不会受到影响。 

所以每次推送有效地覆盖了一个区间`[i, r]`其中 r 是最远可达索引。 如果我们可以计算这些间隔，问题就变成选择一组最小成本的间隔启动器，以便每个索引都被至少一个达到它的间隔覆盖。 

重要的观察是间隔不是独立的。 在 i 处开始推送不仅覆盖其自然递减运行，而且还可能与先前覆盖的区域交互。 如果较晚的位置已经通过一些较早的推送达到了，我们不需要再次支付费用。 

这导致了一个从左到右的动态过程：通过已选择的推送维持当前可到达的最远点，并在每个索引处决定是否需要付费以扩展其之外的覆盖范围。 

关键思想是传播结构仅取决于相邻高度之间的比较，这使我们能够在贪婪扫描中计算可达性，而无需重新计算完整的模拟。

 ## 算法演练

 我们从左到右处理多米诺骨牌，同时跟踪哪个后缀由于早期的推动而已经保证会倒下。 中心对象是我们目前可以通过已选择的推送以零额外成本达到的最远索引。 

### 步骤

 1.我们维护一个变量`reach`，表示已经保证下跌的最远指数。 
2. 我们还维护一个结构，告诉我们如果位置 i 的推送是影响该区域的第一个推送，它会传播多远。 这可以通过在高度严格减小时向右扫描来计算。 
3. 我们将 i 从 1 迭代到 n。 如果我已经在里面`reach`，我们跳过它，因为它会由于之前的决定而自动下降。 
4.如果我在外面`reach`，我们被迫对 i 开始新的推动，因为否则多米诺骨牌 i 永远不会倒下。 我们支付 ci。 
5. 在 i 处付款后，我们计算该推送传播的距离。 从 i 开始，我们扩展 j 只要 h[j] > h[j+1]，并设置`reach`至最大值（当前到达范围，j）。 
6. 我们继续扫描。 每一次新的强制推动都会延伸得更远，可能会跳过大的部分。 

### 为什么它有效

 该算法依赖于这样一个事实：一旦头寸位于先前触发的有效递减链内，其行为就与未来的决策无关。 当前范围内的任何多米诺骨牌都无法贡献新的信息或成本，因为无论我们是否手动推动它，它都已经倒下。 

每次我们选择在 i 处推送时，我们这样做只是因为没有更早的推送可以到达 i。 这使得在任何有效的解决方案中 i 处的决定都不可避免。 在必须覆盖 i 的所有解决方案中，从 i 开始是最佳的，因为任何较早的开始都已被考虑并且无法达到 i。 

因此，每个选择的推送都对应一个必要的“覆盖断点”，并且贪婪过程永远不会引入冗余推送。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        c = list(map(int, input().split()))

        reach = -1
        ans = 0

        i = 0
        while i < n:
            if i <= reach:
                i += 1
                continue

            ans += c[i]

            j = i
            while j + 1 < n and h[j] > h[j + 1]:
                j += 1

            reach = j
            i += 1

        print(ans)

if __name__ == "__main__":
    solve()
```该实现是扫掠思想的直接转化。 这`reach`变量代表已经保证会下降的最右边位置。 每当我们遇到超出这个范围的指数时，我们就被迫付出其代价。 

内部循环计算从所选推动位置开始的最大递减段。 这是安全的，因为传播仅取决于相邻高度之间的严格比较，并且一旦启动新的推送，就独立于先前的选择。 

循环结构确保每个索引最多被访问两次：一次在外部扫描中，一次在最多一次内部传播中，从而保持解的线性。

 ## 边缘情况

 单个多米诺骨牌情况会立即处理，因为外循环看到`reach = -1`，强制一推，该段就是它本身。 不存在越界传播，因此答案就是它的成本。 

严格增加的序列展示了最坏情况下的推送次数。 每个索引在每一步都超出当前范围，强制执行 n 个独立的激活。 该算法正确地支付了所有成本，因为没有传播循环延伸范围。 

严格递减序列形成单个最大段。 第一次强制推送将范围扩展到数组末尾，导致跳过所有后续索引。 这显示了贪婪的“第一个未覆盖索引定义段”行为的正确性。
