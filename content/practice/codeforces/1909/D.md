 ## 解决方案
 ## 问题理解

 给定一个正整数和一个数字的多重集$k$。 我们可以重复选择任意数字$x$黑板上的，擦掉，换成两个正整数$y$和$z$这样$y + z = x + k$。 目标是确定是否可以使所有数字相等，如果可以，则找到此类操作的最少数量。 每个操作都会使数字总和增加$k$， 因为$y + z = x + k$准确地添加$k$超过原来的数量$x$。 

输入可能很大：$n$最多$2 \cdot 10^5$和数字高达$10^{12}$。 简单的模拟分割的方法是行不通的，因为操作的数量可能会以组合方式爆炸，而且我们必须有效地处理多个测试用例。 这暗示解决方案必须依赖算术推理而不是强力模拟。 

一个微妙的边缘情况是$k = 0$。 然后每次操作都会保留总和，并且我们只能将数字拆分为总和与原始值完全一致的数字。 如果数字最初不相等，则不可能使它们全部相等，因为拆分不允许减少总和。 另一种边缘情况是当所有数字已经相等时，需要零运算。 不允许使用负数，因此分割必须始终产生严格的正整数。 

## 方法

 蛮力的想法是模拟每一个可能的分裂，尝试所有序列直到数字相等。 对于每个数字，我们可以尝试所有$y, z$令人满意的组合$y + z = x + k$。 这很快就变得不可行，因为操作数量随着分割数量呈指数增长，特别是考虑到$n$最多$2 \cdot 10^5$。 即使只考虑重复分裂最大的数量，状态的数量仍然是巨大的。 

关键的观察是从最大数开始向后推算。 如果所有数字最终必须等于某个目标$M$，然后每个数字$a_i$必须可转换为一份或多份副本$M$使用拆分。 每个分割恰好相加$k$到总和，所以我们可以将每个数字建模为产生$x$的副本$M$总和增加$k$每次操作。 从代数上来说，我们需要$a_i + t_i \cdot k = c_i \cdot M$对于一些正整数$t_i, c_i$。 这减少了检查是否$(M - a_i) \% k = 0$，将分割数给出为$(M - a_i) / k$。 最优的$M$是数组中的最大数量，因为进一步增加它只会增加所需操作的数量。 

因此，问题简化为检查所有数字是否满足$(M - a_i) \% k = 0$并求和$(M - a_i) / k$为所有人$i$以获得最少的操作次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 算术归约| 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$和$k$，后跟数组$a$。 
2. 计算最大数$M$在数组中。 这是所有元素应转换为的目标数字。 选择任何小于的数字$M$需要负分割，这是无效的，并且任何大于$M$增加不必要的操作。 
3. 初始化操作总数计数器。 
4. 迭代每个数字$a_i$在数组中：

 - 计算差异$diff = M - a_i$。 
- 如果$diff \% k \neq 0$, 不可能达到$M$从$a_i$，所以输出$-1$对于这个测试用例。 
- 否则，计算所需的操作数$a_i$作为$ops_i = diff // k$并添加到总计数器中。 
5. 处理完所有数字后，输出操作总数。 

这样做的原因是每次操作都会增加一个数字$k$总的来说。 通过以最大数量为目标，每个数字可以重复分割，最终达到与以下相同的总贡献：$M$。 不变的是，每次分割后，总和增加$k$每个操作，我们选择的分割恰好达到$M$。 任何偏差都会破坏模条件，表明不可能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        M = max(a)
        total_ops = 0
        possible = True
        for num in a:
            diff = M - num
            if diff % k != 0:
                possible = False
                break
            total_ops += diff // k
        print(total_ops if possible else -1)

if __name__ == "__main__":
    solve()
```代码首先将最大数字识别为目标。 对于每个数字，它检查是否可以通过大小的整数分割达到最大值$k$。 这`diff % k`检查可防止尝试将数字拆分为小数部分。 整数除法的最终总和给出了最少的运算次数，因为每次增量$k$需要一次拆分操作。 该循环可以有效地处理多个测试用例，而无需存储额外的状态。
