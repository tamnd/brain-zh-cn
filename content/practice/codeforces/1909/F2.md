 ## 解决方案
 ## 问题理解

 对于每个职位$i$,看前缀$p_1,\dots,p_i$的一个排列。 

定义$$f(i)=\#\{j\le i \mid p_j\le i\}.$$某些位置包含规定值$a_i$， 意义$f(i)$必须完全是$a_i$。 职位与$a_i=-1$不施加任何限制。 

我们必须计算有多少排列满足所有指定的约束。 

所有测试用例的总长度最多为$2\cdot 10^5$，所以任何二次方都被立即排除。 甚至$O(n\sqrt n)$会不舒服。 我们需要本质上是线性的，或者线性乘以一个小常数。 

困难的部分是仅在选定的位置给出约束。 朴素的解释试图直接构造排列，但条件同时取决于位置和值，这使得局部推理非常困难。 

一个特别危险的边缘情况是最终位置。 

为了$i=n$,$$f(n)=n$$对于每个排列，因为每个值至多$n$。 

如果$a_n$被指定并且$a_n\neq n$，答案立即$0$。 

例子：```
n = 3
a = [-1, -1, 2]
```正确答案是$0$。 忽略最后一个位置的特殊角色的解决方案将会计算无效配置。 

另一个微妙的情况是减少指定值。 

例子：```
n = 4
a = [1, -1, 0, 4]
```自从$f(i)$是非递减的，后面的指定值不可能小于前面的指定值。 答案是$0$。 

当有很长的一段时间时，就会出现第三个陷阱。$-1$。 缺失的位置不是独立的。 单独处理每个未知位置会大大增加计算量，因为约束仅在下一个指定的检查点起作用。 

## 方法

 蛮力方法生成所有$n!$排列并检查每个约束。 

对于固定排列，我们可以计算所有值$f(i)$在$O(n)$或者$O(n\log n)$，但这并不重要。 即使是为了$n=12$,$12!\approx 4.8\cdot 10^8$，已经绝望了。 

关键的观察是，该条件可以转换为车放置问题$n\times n$木板。 

将车放置在$(i,p_i)$。 因为$p$是一个排列，每一行每一列都恰好包含一个车。 

现在考虑$$f(i)=\#\{(r,c): r\le i,\ c\le i\}.$$换句话说，$f(i)$正是左上角内车的数量$i\times i$正方形。 

这种几何解释将问题转化为对某些嵌套正方形内具有规定数量的车的排列矩阵进行计数。 

认为$j$和$i$是连续位置，其中$a\neq -1$。 

在它们之间，董事会从$j\times j$平方到一个$i\times i$正方形。 

让$$t=a_i-a_j.$$那些$t$新的车必须位于扩大正方形时添加的L形区域内。 

重写维度后，计数问题变为：

 数数放置方式$t$L 形板上的非攻击车由$y\times y$通过删除一个正方形$x\times x$square from the lower-left corner.

 Different specified intervals are independent, so their counts multiply.

 The remaining task is counting rook placements in that L-shape.

 使用包含-排除。 

让$F(n,m)$是放置方式的数量$m$非攻击车$n\times n$木板。 

选择行，然后将它们与列匹配：$$F(n,m)=\binom{n}{m}\frac{n!}{(n-m)!}.$$对于禁止的$x\times x$块，包含-排除强制进入该块的车数量给出$$\sum_{k=0}^{t} (-1)^k F(x,k)\, F(y-k,t-k).$$这会产生一个$O(t)$一个段的计算。 由于所有段的总和增加$t$整个测试用例最多$n$，总复杂度是线性的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n!\cdot n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$每个测试用例总计 |$O(n)$| 已接受 |

 ## 算法演练

 1. 预先计算阶乘和逆阶乘$2\cdot10^5$。 
2. 定义$$A(n,m)=\frac{n!}{(n-m)!}, \qquad C(n,m)=\binom{n}{m}.$$1. 定义$$F(n,m)=C(n,m)\cdot A(n,m).$$这是放置方式的数量$m$非攻击车$n\times n$木板。 

1.如果$a_n$被指定并且$a_n\neq n$， 输出$0$。 
2. 更换$a_n$经过$n$。 最后的正方形总是包含所有$n$乌鸦，所以治疗$n$作为强制检查点简化了逻辑。 
3.让$j$最初是先前指定的位置$0$和$a_0=0$。 
4. 对于每个指定位置$i$:

 1. 计算$$t=a_i-a_j, \qquad x=j-a_j, \qquad y=i-a_j.$$2.如果$t<0$， 输出$0$。 
3. 计算$$\text{ways} = \sum_{k=0}^{\min(x,t)} (-1)^k F(x,k) F(y-k,t-k).$$4. 将答案乘以该值。 
5. 设置$j=i$。 
5. 输出累加乘积模$998244353$。 

### 为什么它有效

 对于每个指定的检查点，值$a_i-a_j$告诉我们在两个嵌套方块之间添加的 L 形区域中到底出现了多少个新车。 

不同检查点区间对应的区域是不相交的，因此在一个区间中做出的选择不会影响另一个区间。 他们的人数成倍增加。 

段内唯一的禁止区域是被删除的$x\times x$正方形。 Inclusion-exclusion counts placements in the full board and subtracts those using forbidden cells. 期限$F(x,k)$选择$k$禁止车，同时$F(y-k,t-k)$放置剩余的车，使其不发生冲突的行或列。 

每个有效排列恰好对应于一个车放置配置，并且每个计数的车放置恰好对应于一个排列矩阵。 因此，算法产生的计数正是良好排列的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 200000

fac = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fac[i] = fac[i - 1] * i % MOD

ifac = [1] * (MAXN + 1)
ifac[MAXN] = pow(fac[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    ifac[i - 1] = ifac[i] * i % MOD

def C(n, r):
    if r < 0 or r > n or n < 0:
        return 0
    return fac[n] * ifac[r] % MOD * ifac[n - r] % MOD

def A(n, r):
    if r < 0 or r > n or n < 0:
        return 0
    return fac[n] * ifac[n - r] % MOD

def F(n, m):
    return C(n, m) * A(n, m) % MOD

t = int(input())

for _ in range(t):
    n = int(input())
    a = [0] + list(map(int, input().split()))

    if a[n] != -1 and a[n] != n:
        print(0)
        continue

    a[n] = n

    ans = 1
    prev = 0

    ok = True

    for i in range(1, n + 1):
        if a[i] == -1:
            continue

        t_inc = a[i] - a[prev]

        if t_inc < 0:
            ok = False
            break

        x = prev - a[prev]
        y = i - a[prev]

        ways = 0

        lim = min(x, t_inc)
        for k in range(lim + 1):
            cur = F(x, k) * F(y - k, t_inc - k) % MOD
            if k & 1:
                ways -= cur
            else:
                ways += cur

        ways %= MOD
        ans = ans * ways % MOD
        prev = i

    print(ans if ok else 0)
```阶乘和反阶乘表允许在恒定时间内评估每个二项式系数和排列计数。`F(n, m)`直接实现车计数公式。 主循环仅处理指定的检查点。 对于每个分段，它计算包含排除总和并将其乘以全局答案。 

一个微妙的细节却很逼人`a[n] = n`。 这不是额外的限制。 每个排列都已经满足它。 该更改仅保证最终段得到统一处理。 

另一个容易犯的错误是忘记了中间术语，例如`y - k`可能会变成负值。 对于无效参数，辅助函数会自动返回零，这与组合含义相匹配。

 ## 边缘情况

 考虑：```
1
3
-1 -1 2
```因为每个排列都满足$f(3)=3$，要求$a_3=2$是不可能的。 该算法在任何计数之前都会检查这一点并立即返回$0$。 

考虑：```
1
4
1 -1 0 4
```指定的值来自$1$下降到$0$。 当处理第二个检查点时，算法计算$$t = a_i-a_j < 0.$$新添加的车数量不可能为负数，所以答案变为$0$。 

考虑：```
1
5
-1 -1 -1 -1 -1
```只有人工检查站$a_5=5$存在。 整个电路板作为一个单独的部分进行处理并产生$$F(5,5)=5!=120.$$每个排列都只计算一次。
