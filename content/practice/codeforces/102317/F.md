 ## 解决方案
 ## 问题理解

 任务是几何的。 每个测试用例给出平面上的一组不同的点，我们必须计算有多少个不同的四个点组可以排列为大写`T`。 

为四分`A`,`M`,`B`， 和`C`，水平部分`T`是段`AB`， 和`M`正好在它的中点。 剩下的一点`C`是茎的端点。 茎的长度必须与`AB`，并且它必须垂直于`AB`在`M`。 等价地，如果`A`和`B`是已知的，那么`M`是被迫的，并且只有两个可能的位置`C`。 

输入最多包含 100 个测试用例。 每组包含 4 到 50 个不同的点，每个坐标都位于`-1000`和`1000`。 官方规定时间限制为1秒，内存限制为256MB。 

当存在 100 个测试用例时，50 个点的小界限足以排除直接的四点枚举。 枚举四个不同点的每个有序选择需要`50 * 49 * 48 * 47 = 5,527,200`一个最大尺寸的测试用例的选择，或 100 个此类用例的多达 552,720,000 个选择。 接近三次方时间的解比较舒服，而二次解则更好。 

浮点比较是主要的数值问题。 该语句将两个值定义为相等，当它们的差值最大时`10^-6`。 比较坐标`==`因此可以拒绝一个有效点，因为诸如`(x1 + x2) / 2`可能无法准确表示。 

例如这四点```
(0, 0)
(2, 0)
(1, 0)
(1, 2)
```形成一个`T`，所以答案是`1`。 计算中点并将浮点坐标与精确相等进行比较的实现依赖于问题无法保证的属性。 

第二个边缘情况是相同的`T`可以描述为`A`和`B`交换了。 为了```
(0, 0)
(2, 0)
(1, 0)
(1, 2)
```对`(A,B)`和`(B,A)`描述相同的横杆。 计算有序对会产生`2`而不是正确答案`1`。 

当候选交叉开关仅存在两个可能的主干端点之一时，会出现第三种边缘情况。 为了```
(0, 0)
(2, 0)
(1, 0)
(1, 2)
(5, 5)
```仍然有一个`T`。 我们必须检查两个垂直方向，但只计算实际存在的点。 

UCF官方声明给出了相同的几何定义，并且`10^-6`平等宽容。 

## 方法

 直接的方法是选择四个不同的点并测试这些点的每种可能的分配`A`,`M`,`B`， 和`C`。 测试直接遵循定义：验证`M`是的中点`AB`， 那`CM`长度与`AB`，并且两个部分在`M`是垂直的。 

这种方法是正确的，因为每个有效的`T`由四点组成，因此检查每一个可能的分配最终会检查其正确的角色。 问题在于选择的数量。 对于 50 分，即使枚举有序四元组，每个测试用例也需要 5,527,200 个选择，并且在执行几何检查之前，100 个最大尺寸的用例可以达到 552,720,000 个选择。 

几何结构为我们提供了更好的组织搜索的方法。 不选择四个点，而是选择两个端点`A`和`B`横杆的。 一旦这两个点固定了，其他两个位置就没有自由了。 

中点是`M = ((Ax + Bx) / 2, (Ay + By) / 2)`。 

设向量由`A`到`B`是`(dx, dy)`。 相同长度的垂直向量是`(-dy, dx)`或者`(dy, -dx)`。 因此，唯一可能的茎端点是`C1 = M + (-dy, dx)`和`C2 = M + (dy, -dx)`。 

因此，每个无序点对最多生成两个候选第四点。 我们只需要检查这些候选坐标是否出现在输入中。 

最多 50 个点，即使是扫描所有点来定位每个候选点的简单实现也只需要`O(p^3)`时间。 有`O(p^2)`的选择`A,B`，两个候选位置，以及一个`O(p)`扫描每位候选人。 对于给定的边界来说，这很容易足够小。 

蛮力方法之所以有效，是因为会检查每个可能的角色分配，但会失败，因为它探索的是可以立即确定几何形状的组合。 观察到交叉开关端点唯一地确定中点和两个可能的主干，从而消除了搜索的整个维度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(p^4) | O(p^4) | O(1) | O(1) | 在最坏的情况下太慢|
 | 最佳| O(p^3) | O(p^3) | O(p) | 已接受 |

 ## 算法演练

 1. 阅读`p`当前测试用例的点并存储它们的坐标。 
2. 枚举每对无序点`A`和`B`。 仅使用与`i < j`这是至关重要的，因为交换交叉开关的端点不会创建不同的`T`。 
3. 计算中点`M`的`A`和`B`。 中点是由定义的第一个条件强制确定的，因此不需要选择其他输入点`M`独立。 
4. 计算`dx = Bx - Ax`和`dy = By - Ay`。 向量`(dx, dy)`描述了横梁。 
5. 构建两个可能的茎端点。 垂直于的向量`(dx, dy)`长度完全相同的是`(-dy, dx)`，其相反的是`(dy, -dx)`。 将任一向量添加到`M`给出一个可能的位置`C`。 
6. 对于每位候选人`C`，扫描输入点并检查其坐标是否在范围内`10^-6`的候选坐标。 如果点匹配，则增加答案。 
7. 处理每一对和两个垂直方向，然后在所需的位置打印结果计数`Set #k: answer`格式后跟一个空行。 

数值比较独立地应用于两个坐标。 当两个坐标差最多时，认为存在一个点`10^-6`，匹配语句中的相等规则。 

### 为什么它有效

 对于每个有效的`T`，它的两个交叉端点是一些无序对`A,B`在输入中。 当算法到达该对时，其中点计算恰好产生所需的点`M`。 向量`AB`精确确定两个具有相同长度的垂直向量`AB`，因此生成的两个候选恰好是 的两个几何可能位置`C`。 

因此有效的`C`的`T`必须通过扫描才能找到。 相反，每当生成的候选点与输入点匹配时，中点条件、等长条件和垂直条件都通过构造成立，因此这四个点形成有效的点`T`。 

使用`i < j`意味着每个交叉开关被考虑一次。 对于固定交叉开关，每个可能的主干端点都会被考虑一次，因此不会对任何有效组进行多次计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

EPS = 1e-6

def same_point(x1, y1, x2, y2):
    return abs(x1 - x2) <= EPS and abs(y1 - y2) <= EPS

def solve_case(points):
    n = len(points)
    ans = 0

    for i in range(n):
        ax, ay = points[i]

        for j in range(i + 1, n):
            bx, by = points[j]

            dx = bx - ax
            dy = by - ay

            mx = (ax + bx) / 2.0
            my = (ay + by) / 2.0

            # Two perpendicular vectors having the same length as AB.
            candidates = (
                (mx - dy, my + dx),
                (mx + dy, my - dx),
            )

            for cx, cy in candidates:
                for px, py in points:
                    if same_point(cx, cy, px, py):
                        ans += 1
                        break

    return ans

def main():
    t = int(input())

    out = []

    for case_no in range(1, t + 1):
        p = int(input())
        points = [tuple(map(float, input().split())) for _ in range(p)]

        ans = solve_case(points)

        out.append(f"Set #{case_no}: {ans}")
        out.append("")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```这`solve_case`函数实现演练中的基于对的搜索。 外面两个循环选择`A`和`B`和`i < j`，所以横杆永远不会重复。 

中点使用除以`2.0`因为坐标是实数。 然后直接通过垂直变换获得两个候选点。 如果`(dx, dy)`是交叉向量，`(-dy, dx)`将其旋转 90 度而不改变其长度。 

内部扫描故意使用 epsilon 比较，而不是由原始浮点坐标键入的字典。 基于精确浮点值的字典将使结果依赖于表示细节。 只需 50 个点，扫描就足够简单、快速。 

这`break`找到匹配点之后也是必要的。 输入点保证是不同的，因此一个候选点最多可以对应一个输入点。 如果没有`break`，即使语句排除了重复项，未来的重复坐标也会错误地增加计数。 

Python整数不会溢出，答案最多是`2 * C(50, 2) = 2450`，因此不需要特殊的整数处理。 

每个答案后所需的空行是通过在每个案例后附加一个空字符串来生成的。 官方声明指定了这种输出格式。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(p^3) | O(p^3) | O(p²) 无序交叉开关对，每对两个候选，以及 O(p) 点扫描 |
 | 空间| O(p) | 输入点集存储在内存中 |

 和`p <= 50`，最坏的情况仅约为`50² * 50 = 125,000`每个测试用例的点比较达到恒定因子，或者超过 100 个最大大小的用例大约 1250 万次比较。 这比暴力破解所考虑的数亿个四点作业要小得多。 官方的界限足够小，以至于直接的浮点扫描比引入更复杂的空间查找结构更可取。

## 边缘情况

 第一个边缘情况是交换中的重复计数`A`和`B`。 为了```
1
4
0 0
2 0
1 0
1 2
```这对`(0,0),(2,0)`产生`(1,2)`作为有效的茎端点。 当循环稍后考虑时`(2,0),(0,0)`，他们不处理它，因为算法需要`i < j`。 答案依然存在`1`，而不是成为`2`。 

第二个边缘情况是浮点相等。 为了```
1
4
0.1 0.1
2.1 0.1
1.1 0.1
1.1 2.1
```前两点的中点是`(1.1, 0.1)`。 候选词干是`(1.1, 2.1)`，存在。 该比较使用绝对容差`10^-6`在两个坐标上，因此小的表示误差不会改变结果。 输出是`Set #1: 1`。 

第三种边缘情况是横杆可以有两个有效的主干。 为了```
1
5
0 0
2 0
1 0
1 2
1 -2
```中点是`(1,0)`，而两个垂直向量是`(0,2)`和`(0,-2)`。 两个生成点都存在，因此算法将答案增加两次并输出`Set #1: 2`。 

第四种边缘情况是对角线横杆。 考虑```
1
7
0 0
2 2
1 1
-1 3
3 -1
10 10
-5 -4
```交叉向量是`(2,2)`，它的中点是`(1,1)`，两个等长的垂直向量是`(-2,2)`和`(2,-2)`。 相应的茎端点是`(-1,3)`和`(3,-1)`，两者都存在于输入中。 答案是`2`。 该计算使用矢量旋转而不是关于水平或垂直坐标的假设，因此相同的推理可以处理任意方向。
