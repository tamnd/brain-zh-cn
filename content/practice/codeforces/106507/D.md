 ## 解决方案
 ## 问题理解

 该任务是几何的，而不是通常意义上的组合。 您将获得平面上不同点的集合，并且其中没有三个点位于一条直线上。 从这个集合中，您想要确定如果允许您选择点的子集并使用它们作为顶点形成多边形，则配置可以变得多么“凸”。 

这里的有效多边形意味着对选定的点进行排序，以便它们形成一个没有自相交的简单闭合形状。 在您可以形成的所有此类多边形中，目标是最大化顶点数量，同时仍保持多边形凸面。 换句话说，我们正在寻找可以作为凸多边形顶点出现的点的最大子集。 

输出不是多边形本身，而是最大子集的大小。 

此类 Codeforces 问题中的约束机制通常允许大约$10^5$点或具有较大总输入大小的多个测试用例。 这立即排除了任何检查所有子集甚至所有三元组的东西，因为它们增长得太快了。 任何尝试显式枚举多边形或检查许多候选子集的凸性的解决方案都会失败，因为单独的凸性检查在子集大小中已经是线性的，并且子集的数量是指数的。 

当所有点都位于其凸包的边界上时，就会出现微妙的边缘情况。 在这种情况下，每个点都构成一个凸多边形，答案就是点的总数。 一种天真的方法错误地假设只有“极端”点在更严格的意义上才重要，在这里可能会低估。 

另一种极端情况是当点以近凸形状排列但一个或多个点严格位于船体内部时。 例如，具有一个内点的凸四边形：内点不能成为使用所有点的任何凸多边形的一部分，因此天真的“获取一切”方法会失败。 正确答案仅取决于船体结构，而不取决于内部分布。 

## 方法

 暴力策略将尝试选择点的每个子集，测试它是否形成凸多边形，并跟踪最大尺寸。 即使忽略子集选择中的组合爆炸，验证多边形的凸性也需要检查所有连续的转弯是否具有相同的方向，这与子集大小呈线性关系。 和$n$点，这导致了一些关于$O(2^n \cdot n)$，即使对于$n = 30$。 

关键的结构见解是，由点子集形成的任何凸多边形都必须位于该子集的凸包上。 如果您想象逐渐扩展凸多边形，则成为顶点的任何点最终都必须位于整个所选集合的凸包的边界上。 这意味着您可以从这组点形成的最大凸多边形正是整组点的凸包。 

因此，问题不是对子集进行推理，而是计算整个点集的凸包并计算其上有多少点。 没有三个点共线的限制简化了实现，因为我们不需要处理船体边界上的退化共线链。 

一旦问题被识别为凸包计算，就会应用标准的单调堆栈结构，例如安德鲁算法。 船体可以内置$O(n \log n)$由于排序，然后是线性时间扫描。 构建完下船体和上船体后，船体中独特点的数量就是答案。

 | 蛮力 |$O(2^n \cdot n)$|$O(n)$| 太慢了|
 | 凸包（安德鲁/单调堆栈）|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将任务简化为找到平面点集的凸包并计算其顶点。 

1. 按 x 坐标对所有点进行排序，按 y 坐标打破平局。 排序是必要的，因为凸包算法依赖于确定性从左到右的顺序处理点。 
2. 通过从左到右扫描点并维护一堆候选船体顶点来构建下船体。 对于每个新点，我们检查堆栈中的最后两个点是否与新点一起进行非左转。 如果这样做，则中点不能成为下边界的一部分并被删除。 
3. 以相同的方式构建上船体，但从右向左扫描。 使用相同的转弯条件来保持上边界的凸性。 
4. 连接下体和上体，删除重复的端点，因为每个体的第一个点和最后一个点重叠。 
5. 剩下的唯一点的数量就是凸包的大小，这就是答案。 

步骤2和3中的关键操作是使用叉积进行定向测试。 给定三分$A, B, C$，我们计算$(B - A) \times (C - B)$。 负值或零值（取决于约定）表示右转或共线性，这意味着中点破坏了凸性，必须将其删除。 

### 为什么它有效

 在扫描期间的任何时刻，堆栈表示已处理的点前缀的凸包。 当一个新点与堆栈中的最后两个点违反凸性时，该中间点不能出现在最终的外壳上，因为它位于由其邻居形成的三角形内部或创建一个凹转弯。 删除它可以保留堆栈边界始终是凸的不变量。 由于每个点都只处理一次并可能删除一次，因此不会永久丢弃有效的外壳顶点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    hull = convex_hull(pts)
    print(len(hull))

if __name__ == "__main__":
    solve()
```该实现遵循标准的单调堆栈结构。 这`cross`函数对方向进行编码，并且是唯一需要的几何图元。 严格的移除条件`<= 0`在问题的“无三个共线点”约束下是安全的，并且它保证在堆栈中仅保留严格的凸转弯。 

最终的串联删除了重复的端点，因为两个船体通道共享最左边和最右边的点。

 ## 边缘情况

 一种边缘情况是所有点共线。 在这种情况下，每个三元组都会产生零叉积，因此船体结构会不断弹出点，直到只剩下两个端点。 该算法自然地将结果减少到线段的端点，这是构造下允许的唯一有效的凸多边形简并性。 

另一种情况是当点已经处于凸位置时。 由于每个转弯都是严格左转的，因此在堆栈构建期间不会发生任何删除，并且两次船体传递都会返回完整的点集。 因此，该算法无需任何特殊处理即可保留最大值。 

最后一个微妙的情况是最小输入大小。 通过三个点，该算法构造相同的上壳和下壳，并且合并步骤正确地删除重复项，返回恰好三个顶点，匹配唯一可能的凸多边形。
