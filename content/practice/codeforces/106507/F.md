 ## 解决方案
 ## 问题理解

 我们有一个 2 行的矩形网格，$n$列，以及多组$2n$代表单元格值的数字。 我们可以在网格中任意排列这些值。 

“乌龟”从左上角的单元格开始，仅向右或向下移动，直到到达右下角的单元格。 沿着它的路径，它收集访问过的单元格值的总和。 然而，乌龟是对抗性的，因为它总是选择一条在所有单调路径中最大化该总和的路径。 

我们的任务是重新排列网格中的数字，使乌龟选择的这条最佳路径的总和尽可能小。 

所以交互是：我们首先选择排列，然后乌龟选择一条最大化其收集总和的路径，而我们希望最小化结果值。 

约束足够小，可以解决$O(n \log n)$预计。 任何试图探索所有排列甚至所有网格配置的事情都是立即不可行的，因为排列的数量是$(2n)!$，即使对于适度的情况，其增长也远远超出任何可计算的极限$n$。 即使模拟每个排列的所有路径也会增加另一个因素$O(n)$，这使得暴力破解完全不可能。 

一个微妙的点是，海龟的最佳路径结构在很大程度上取决于它从顶行切换到底行的位置。 任何有效路径要么完全停留在顶行直到某一列然后下降一次，要么对称地先停留在底行然后切换。 这种结构就是在问题中产生组合压力的原因。 

当值“局部优化”但全局错误时，就会出现常见的失败情况。 例如，将较大的值放在一行中似乎很安全，但海龟可以在大部分路径中穿过该行。 另一个失败情况是交替大值和小值而不考虑前缀和，这允许海龟选择捕获最大值的切换点。 

## 方法

 蛮力的想法很简单：生成$2n$值，将它们放入网格中，然后计算海龟可以达到的最大路径总和。 对于固定网格，我们可以计算最佳路径$O(n)$通过尝试将每一列作为行之间可能的切换点。 这给出了总复杂度$O((2n)! \cdot n)$，即使对于$n = 10$，因为阶乘增长主导一切。 

关键的观察结果是路径结构受到极大限制。 任何最佳路径都由其切换行的一列决定。 如果我们固定网格，则最佳路径值是所有分割点上的最大值$k$两个表达式：在第 1 行中向右移动，直到$k$然后将第 2 行排到最后，或者相反的方向。 这减少了评估前缀和后缀和的路径问题。 

一旦明确了这一点，剩下的问题就是如何放置值，以便没有分割点产生过大的组合总和。 海龟总是会为我们的安排选择最糟糕的分割，因此我们希望“平滑”所有潜在的前缀后缀组合。 

关键的结构洞察力是，重要的不是局部邻接性，而是价值的全局排序。 对值进行排序使我们能够控制前缀中累积的元素大小。 最佳构造最终是单调分离：小值应该主导海龟可以强制在一行中的所有前缀，而应该放置大值，以便它们以防止任何单个路径收集太多前缀的方式跨行分割。 

这导致了我们对所有内容进行排序的结构$2n$值并以“平衡的相反顺序”分布它们：顶行按升序填充，而底行按降序填充。 这确保顶行中的任何前缀与底行中相对较大的后缀值配对，反之亦然，从而防止任何路径在两个段上一致地收集大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((2n)! \cdot n)$|$O(n)$| 太慢了|
 | 排序+建设性安排|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1.收集全部$2n$将两个输入行的值放入单个数组中。 这消除了对初始布局的任何依赖，因为我们可以完全重新排序网格。 
2. 按非降序对数组进行排序。 目的是强行进行全球排名，以便我们可以推断出哪些值是“危险的”（大），哪些是安全的（小）。 
3. 使用最小的从左到右填充第一行$n$值按递增顺序排列。 这确保了顶行中的任何前缀逐渐增长，并且不包含海龟在切换行之前可以利用的大尖峰。 
4. 使用最大的从左到右填充第二行$n$值，但按降序排列。 这种反转很重要，因为它可以防止底行的单个前缀在连续段中集中过多的大值，否则会创建主导路径。 
5. 输出结果网格。 

这种放置背后的原因是，每个有效路径都将网格分割为一行上的前缀段和另一行上的后缀段。 通过将小值和大值分成相反的单调方向，我们确保任何此类分割都会混合低值和高值，而不是允许路径累积大的连续块。 

### 为什么它有效

 关键不变量是对于任何列$k$，路径可以通过切换收集的值的总和$k$由一个排序序列的前缀和另一个相反排序序列的后缀的组合界定。 由于一行在增加，另一行在减少，因此每个前缀后缀配对本质上都会平衡大值和小值。 这可以防止路径的两个部分同时包含许多大元素的分割点的存在。 

由于海龟总是选择所有此类分割中的最大值，因此我们的构造确保所有候选分割值尽可能保持均匀，从而最小化可实现的最大路径和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    vals = a + b
    vals.sort()
    
    top = vals[:n]
    bottom = vals[n:]
    
    # top increasing
    row1 = top
    
    # bottom decreasing
    row2 = bottom[::-1]
    
    print(*row1)
    print(*row2)

if __name__ == "__main__":
    solve()
```实施直接遵循建设性想法。 唯一的微妙之处是确保排序后正确的分割：最小的$n$元素进入顶行，最大的$n$以相反的顺序到最后一行。 逆转是必要的； 如果没有它，大值将聚集并在第二行中创建一个强大的前缀和，海龟可以通过后期切换来利用它。

 ## 边缘情况

 一种重要的边缘情况是所有值都相等。 在这种情况下，每种安排都是等价的，乌龟的路径选择变得无关紧要。 该算法保留了此属性，因为排序不会更改多重集结构，并且两行的分布保持相同。 

另一种边缘情况是当许多小值中有一个非常大的值时。 一个幼稚的放置可以将大值放在一行的开头，让海龟在每条路径上都采用它。 在构造的解决方案中，由于反转，最大值被放置在底行的末尾，确保只有当海龟承诺牺牲其他收益的特定分割时才捕获它。 

最后一个微妙的情况是当值高度聚集时，例如许多相等的中间范围值和一些极端值。 排序分割仍然保证极值在行之间分离，防止任何单个前缀后缀组合同时累积分布的两端。
