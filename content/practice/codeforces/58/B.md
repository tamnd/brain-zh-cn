 ## 解决方案
 ## 问题理解

 我们得到最大面额硬币的价值，`n`。 我们必须建立一系列不同的硬币值，使得每个较大的硬币都可以被每个较小的硬币整除。 在所有有效序列中，我们想要包含最大可能数量的硬币的序列。 

输出必须列出从最大到最小的面额。 

可分性条件创建了链结构。 如果硬币是：```
a1 > a2 > a3 > ...
```那么每个较早的值必须能被每个较晚的值整除。 尤其：```
a1 % a2 == 0
a2 % a3 == 0
a1 % a3 == 0
```等等。 

极限只是`10^6`，它足够小，可以进行试除和重复因子运算。 甚至一个`O(sqrt(n))`算法很容易在 2 秒内足够快。 另一方面，生成和检查所有子集或所有除数链将导致组合爆炸，并且是不必要的。 

棘手的部分是理解“最大硬币数量”的真正含义。 粗心的解决方案可能会尝试直接从`n`到`1`，但这浪费了插入中间除数的机会。 

例如：

 输入：```
12
```有效的序列是：```
12 1
```但它不是最大的。 我们可以插入更多值：```
12 6 3 1
```另一个常见的错误是除以任意除数而不是最小的可能质因数。 假设我们从`60`。 

如果我们激进地分裂：```
60 -> 10 -> 1
```我们只得到三枚硬币。 

如果我们一次删除一个因素：```
60 -> 30 -> 15 -> 5 -> 1
```链条变得更长。 

边缘情况`n = 1`也容易误操作。 没有更小的正因数可以相加，所以答案很简单：```
1
```## 方法

 蛮力方法会尝试生成所有因数`n`，然后寻找其中最长的可分链。 由于链中的每一对都必须正确划分，因此我们可以对除数进行排序并运行类似于最长递增子序列的动态编程。 

这是有效的，因为整除关系形成了偏序。 如果`a`划分`b`， 然后`a`可以出现在之后`b`在序列中。 

问题是这种方法解决的问题比必要的要困难得多。 虽然`n ≤ 10^6`保持除数计数易于管理，构建所有链和转换仍然是不必要的工作。 

关键的观察是，最大化硬币数量意味着我们应该尽可能缓慢地减少数量。 

假设当前的硬币是`x`。 下一个硬币必须是`x`。 为了最大化剩余的步数，我们希望下一个值尽可能大，同时仍然小于`x`。 

最好的做法是除以最小素因数`x`。 

例如：```
60 -> 30
```优于：```
60 -> 20
```因为仅删除一个素因数可以保留以后更多的整除步骤。 

每一次运算都会从数字的因式分解中恰好删除一个素因数。 由于一个数经过因式分解```
n = p1^a1 * p2^a2 * ...
```恰好包含`a1 + a2 + ...`质因数计算多重性，最长的链一次将它们删除一个，直到达到`1`。 

所以算法就变得简单了：

 开始于`n`。 重复除以其最小素因数并打印每个中间值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(d²) 其中 d 是除数 | O(d) | 不必要的复杂 |
 | 最佳| O(sqrt(n)) | O(1) 不包括输出 | 已接受 |

 ## 算法演练

 1.读取整数`n`。 
2. 打印当前值`n`因为序列必须从最大面额开始。 
3.同时`n`大于`1`，找到最小除数`n`大于`1`。 

我们搜索从`2`向上，直到找到除数。 找到的第一个除数始终是最小的素因数。 
4. 划分`n`通过这个最小的素因数。 

这从数字中恰好删除了一个素因数，从而给出了尽可能最慢的减少并最大化了剩余的链长度。 
5. 打印新值`n`。 
6. 重复直到`n`变成`1`。 

在每一步中，新值都会除以先前的值，因为它是通过除以整数因子获得的。 由于整除性是可传递的，因此每个较大的硬币仍然可以被序列中后面的每个较小的硬币整除。 

### 为什么它有效

 最长的链是通过一次删除一个质因数来获得的。 

假设我们有一个当前号码`x`。 任何下一个值必须是：```
x / d
```在哪里`d`是一个大于的除数`1`。 

如果`d`是复合的，然后删除它会同时丢弃多个素因数。 这缩短了可能的链，因为剩下的中间除数更少。 

除以最小的素因数会恰好删除一个素因数，并保持下一个数字尽可能大。 重复这个过程可以保证每个质因数都为序列贡献一枚额外的硬币，这是可实现的最大长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

ans = []

while True:
    ans.append(str(n))

    if n == 1:
        break

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            n //= d
            break
    else:
        n = 1

print(" ".join(ans))
```该解决方案维持当前面额`n`并重复将其附加到答案序列中。 

循环仅在打印后停止`1`， 自从`1`也必须作为最终硬币出现。 

内循环从以下位置开始搜索最小除数`2`。 找到的第一个除数自动成为最小的素因数。 除以它会从因式分解中恰好删除一个素因数。 

这`else`附于`for`循环很重要。 仅当未找到除数时才运行。 这意味着当前`n`是素数。 素数只有一个真因数，即`1`，所以下一步必须变成`1`。 

一个常见的错误是忘记在开始除法之前打印初始值。 另一个简单的错误是立即停止`n`成为素数，这将跳过最后的`1`。 

平方根界限保持除数搜索的效率。 自从`n`每一步都会缩小，总的运行时间仍然很小。

 ## 边缘情况

 考虑最小的输入：```
1
```该算法立即附加`1`到答案并停止。 由于不存在更小的正除数，因此不会进行除数搜索。 输出正确：```
1
```现在考虑一个素数：```
13
```除数搜索检查所有整数`2`到`sqrt(13)`但什么也没找到。 这`for-else`分支触发器，将下一个值设置为`1`。 

序列变为：```
13 1
```这是最优的，因为素数除了除数之外没有其他约数`1`。 

最后，考虑一个具有许多重复因子的数字：```
16
```执行过程如下：```
16 -> 8 -> 4 -> 2 -> 1
```每一步除以`2`，一次仅删除一个素因数。 粗心的解决方案除以较大的因子可能会产生：```
16 -> 4 -> 1
```这是有效的但不是最大值。 贪心策略正确地保留了最长的可能链。
