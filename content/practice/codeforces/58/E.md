 ## 解决方案
 ## 问题理解

 我们得到一个表示以下形式的简单算术表达式的字符串`a+b=c`， 在哪里`a`,`b`， 和`c`是整数。 瓦斯亚声称他可能忘记写下一些数字，这意味着左侧和右侧的数字可能是实数的子序列。 我们的目标是重建“真实”的数字`x`,`y`， 和`z`以便`x+y=z`，同时确保`a`,`b`， 和`c`出现为`x`,`y`， 和`z`， 分别。 我们还想要数字的总数`x+y=z`最小化。 

问题界限的绝对值很小（`1 ≤ a, b, c ≤ 10^6`），这意味着任何迭代数百万个可能整数的解决方案都是可行的，但具有更高指数复杂度的解决方案将会失败。 这也暗示主要的挑战不是计算速度，而是对数字放置和子序列的仔细处理。 

非明显的边缘情况包括最小长度解决方案必须在最高有效位扩展数字的情况。 例如，如果输入是`2+4=5`，最小解`21+4=25`之所以有效，是因为将数字添加到`a`和`c`左边给出了正确的总和，而不会不必要地增加总长度。 简单地匹配现有数字或仅填充零的天真的方法可能会失败，因为它会产生`2+4=5`，这在算术上是无效的。 

另一个棘手的边缘情况是进位跨数字传播。 例如，`1+9=1`可以成为`11+9=20`，表明数字有时必须在意想不到的位置增长才能满足总和。 

## 方法

 暴力方法会尝试尝试所有可能的方法将数字插入到`a`,`b`， 和`c`形成有效的数字`x`,`y`， 和`z`然后检查是否`x+y=z`。 如果我们将每个可能的数字插入表示为长度序列`L`最多`10^6`，候选者的数量呈组合爆炸式增长。 即使我们只尝试 10^7 以内的数字，也会迭代每个组合`x`和`y`最多需要 10^14 次检查，这显然是不可行的。 

关键的见解是，该问题可以简化为动态规划问题，模拟将两个数字从最低有效位到最高有效位逐位相加，同时确保每个数字序列包含相应的原始数字作为子序列。 通过反向考虑数字，我们可以自然地传播进位并跟踪位置`a`,`b`， 和`c`必须匹配。 DP状态表示三个原始数字和进位中的位置，并且转换对应于选择下一个数字`x`和`y`与成型一致`z`和匹配子序列。 这极大地减少了搜索空间并保证了最小的总长度，因为我们仅在必要时扩展数字。

 ## 算法演练

 1. 将输入解析为字符串`a`,`b`， 和`c`。 反转它们以简化从最低有效位到最高有效位的逐位加法。 
2. 初始化一个DP表，其中`dp[i][j][k][carry]`是`True`是否有可能达到职位`i`在`a`,`j`在`b`， 和`k`在`c`具有给定的进位。 DP 还将存储所选的数字以重建解决方案。 
3. 迭代每个状态`(i, j, k, carry)`这是可以到达的。 对于每个数字，尝试所有可能的下一个数字`d1`和`d2`为了`x`和`y`。 计算`d1 + d2 + carry = dsum`。 下一个数字为`z`是`dsum % 10`，下一个进位是`dsum // 10`。 
4. 检查是否`i < len(a)`然后`d1`比赛`a[i]`（或跳过匹配以允许额外的数字），类似地`b`和`c`。 只有有效的转换才会添加到 DP 表中。 
5. 填表后，找到一个消耗掉所有数字的可达状态`a`,`b`， 和`c`带有进位零。 使用存储的数字选择进行回溯以重建`x`,`y`， 和`z`。 
6. 反转重构的字符串以获得最终解，确保它们除了零本身之外没有前导零。 

工作原理：在每一步中，DP 都会强制任何选定的数字序列将原始数字扩展为子序列并满足加法属性。 通过从最低有效位开始模拟加法并跟踪进位，该算法可确保最终数字的总和正确。 保证了最小长度，因为 DP 仅在必要时扩展数字以匹配子序列或进位传播。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, rest = input().strip().split('+')
b, c = rest.split('=')
a = a[::-1]
b = b[::-1]
c = c[::-1]

from functools import lru_cache

@lru_cache(None)
def dfs(i, j, k, carry):
    if i == len(a) and j == len(b) and k == len(c) and carry == 0:
        return "", "", ""
    for d1 in range(10):
        if i < len(a) and int(a[i]) != d1:
            continue
        for d2 in range(10):
            if j < len(b) and int(b[j]) != d2:
                continue
            s = d1 + d2 + carry
            d3 = s % 10
            nc = s // 10
            if k < len(c) and int(c[k]) != d3:
                continue
            res = dfs(i + (d1 == int(a[i]) if i < len(a) else 0),
                      j + (d2 == int(b[j]) if j < len(b) else 0),
                      k + (d3 == int(c[k]) if k < len(c) else 0),
                      nc)
            if res is not None:
                x, y, z = res
                return str(d1) + x, str(d2) + y, str(d3) + z
    return None

x, y, z = dfs(0, 0, 0, 0)
print(x[::-1] + '+' + y[::-1] + '=' + z[::-1])
```该解决方案使用递归记忆来探索有效的数字位置。 我们对每个数字迭代从 0 到 9 的所有数字，同时考虑子序列约束和进位传播。 微妙的选择包括仅当位置在界限内时检查数字匹配以及小心地推进位置`a`,`b`,`c`仅当数字与原始子序列匹配时。
