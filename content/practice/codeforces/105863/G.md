 ## 解决方案
 ## 问题理解

 我们给出了固定数量的位置和一系列值，并且我们从概念上将该范围中的值分配给每个位置。 对于每个完整的作业，我们感兴趣的是识别从左到右扫描时该位置的值第一次出现新最小值的位置。 换句话说，在位置 i 处，如果该值不大于其之前的所有值，则该值将成为前缀最小值。 

任务不是评估单个分配，而是在统一计数模型下汇总所有可能分配的条件。 每个位置都可以独立取固定范围内的任意值，因此配置空间是指数级的。 输出是所有配置的总贡献，其中每个位置以所描述的方式充当前缀最小值。 

编辑暗示的约束暗示位置数量和值范围都可能足够大，以至于不可能迭代所有分配。 如果以三嵌套循环方式天真地完成，即使迭代所有位置和值对也太慢。 任何在没有代数压缩的情况下显式枚举分配甚至成对贡献的解决方案都将超出典型限制。 

当独立推理前缀最小值条件时，会出现微妙的边缘情况。 例如，如果只有一个位置，则无论值如何，该位置始终是前缀最小值。 错误地从数组两侧强制执行条件的天真的解释在这里将失败。 另一种边缘情况是当值范围的大小为一时，这意味着每个分配都是常量。 在这种情况下，每个位置都是一个前缀最小值，并且假设值之间存在可变性的公式可能会错误地除以零或假设退化的几何比率。 

## 方法

 蛮力视角从定义开始。 我们想象迭代每个位置的值分配。 对于每个分配，我们从左到右扫描并标记值小于或等于所有先前值的每个位置。 然后，我们为每次出现此类情况的答案加一。 这是正确的，但从根本上来说是不可行的，因为分配的数量是 k^n，甚至 n 达到几十也使得这是不可能的。 

我们需要重新组织计数，以便我们永远不会枚举完整的作业。 关键的转变是视角的转变。 我们不是询问有多少个赋值产生给定的全局结构，而是询问每对 (i, j)，有多少个赋值使位置 i 等于值 j 并同时使其成为前缀最小值。 

为了使位置 i 成为值为 j 的前缀最小值，每个较早的位置必须具有至少 j 的值。 这给出了一个干净的独立结构：i之前的位置被限制在范围[j, k]内，i的位置被固定为j，i之后的位置不受限制。 这将计数分离为独立选择的乘积。 

因此，固定对 (i, j) 的贡献对于前缀变为 (k − j + 1)^(i−1)，对于后缀乘以 k^(n−i)。 对所有 i 和 j 求和得到一个双和，看起来仍然很大，但现在有了结构。 

关键的观察是，对于固定的 j，随着 i 的增加，项 (k − j + 1)^(i−1) 形成几何级数。 这允许我们用封闭形式的几何级数替换 i 上的内部和。 完成此操作后，j 上的剩余总和在 k 中变为线性，并且可以使用模幂和模逆在恒定时间内评估每一项。 这将复杂度从 O(nk) 或更糟压缩为 O(k log MOD)。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解分配| O(k^n · n) | O(k^n · n) | O(n) | 太慢了|
 | 配对计数与几何求和 | O(k log MOD) | O(k log MOD) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们围绕固定出现在前缀最小位置的值 j 重构计算。 

1. 将值 j 从 1 固定为 k。 我们将其解释为在某个位置 i 分配的值，该位​​置成为前缀最小值。 
2. 对于固定位置 i，强制位置 i 具有值 j。 i 之前的每个位置必须至少为 j，因此每个位置都有 (k − j + 1) 个选择。 这贡献了 (k − j + 1)^(i−1)。 
3. i 之后的位置不受限制，因此它们每个都贡献 k 个选择，给出 k^(n−i)。 
4. 将这些组合成固定 (i, j) 的贡献，即 (k − j + 1)^(i−1) · k^(n−i)。 
5. 现在对固定 j 的所有位置 i 求和。 重写总和，使 (k − j + 1) 的幂在 i 中形成几何级数。 分解出 k^(n−1) 来分离比率 (k − j + 1) / k。 
6. 应用几何级数公式计算每个 j 在恒定时间内 i 的总和。 这消除了显式迭代所有位置的需要。 
7. 对从 1 到 k 的所有值 j 的结果求和，以 MOD 为模累加最终答案。 

为什么它有效

 通过选择每个前缀最小出现次数的位置和值，对每个有效配置进行唯一计数。 条件“i 处的前缀最小值，值为 j”仅取决于对早期位置的约束，这些位置在各个索引之间是独立的。 这种独立性允许因式分解为幂。 几何结构的出现是因为位置之间唯一变化的部分是相同基数 (k − j + 1) 上的指数，确保对 i 和 j 求和时不会重叠或重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def modinv(a):
    return modpow(a, MOD - 2)

def solve():
    n, k = map(int, input().split())

    inv_k = modinv(k)
    ans = 0

    for j in range(1, k + 1):
        base = k - j + 1

        # geometric ratio r = base / k
        r = base * inv_k % MOD

        # sum_{i=1..n} base^(i-1) * k^(n-i)
        # = k^(n-1) * sum_{t=0..n-1} r^t
        if r == 1:
            geom = n % MOD
        else:
            geom = (modpow(r, n) - 1) * modinv(r - 1) % MOD

        ans = (ans + modpow(k, n - 1) * geom) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先实现模幂和模逆，因为所有表达式都涉及素数模数下的幂和除法。 在主循环内，每个值 j 定义了前缀位置的基本约束。 比率 r 捕获移动前缀边界时贡献如何变化。 

几何和是使用标准闭合形式计算的，特殊情况是 r 等于 1，这种情况发生在 j = 1 并且所有前缀值不受限制时。 提取因子 k^(n−1) 以稳定表达式并减少重复求幂。 

这里的一个常见陷阱是混合指数偏移。 前缀使用 i−1，后缀使用 n−i，因此提取 k^(n−1) 对于避免几何比率中的差一误差至关重要。 

## 工作示例

 ### 示例 1

 考虑 n = 3，k = 2。 

我们计算 j = 1 和 j = 2 时的贡献。 

| j | 基= k − j + 1 | 比率 r | 几何总和| 贡献 |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 1 | 3 | k^(2)·3 | k^(2)·3
 | 2 | 1 | 1/2 | 1/2 1 + 1/2 + 1/4 | 1 + 1/2 + 1/4 | k^(2) · 总和 |

 对于 j = 1，每个前缀约束都消失，因此每个分配在各个位置上的贡献是一致的。 对于 j = 2，前缀位置必须全部为 2，这会快速限制有效配置。 

该迹线显示了几何比率如何随着 j 的增加而缩小，反映了更严格的前缀约束。 

### 示例 2

 考虑 n = 2，k = 3。 

我们评估每个 j：

 | j | 基地| r | 吉姆总和 |
 | --- | --- | --- | --- |
 | 1 | 3 | 1 | 2 |
 | 2 | 2 | 2/3 | 1 + 2/3 | 1 + 2/3 |
 | 3 | 1 | 1/3 | 1/3 1 + 1/3 |

 这证实了更严格的约束（更大的 j）减少了基数，从而减少了贡献，并且该公式正确地处理了几何级数快速崩溃的短数组。

 ## 边缘情况

 k = 1 的情况会破坏所有随机性。 每个位置都强制值为 1，因此每个位置都是前缀最小值。 该公式简化为对相同的贡献进行求和，并且实现可以正确处理此问题，因为 r 变为 1 并且几何求和分支返回 n。 

对于 n = 1，问题简化为对所有可能值 j 求和，其中单个位置始终是前缀最小值。 该代码评估相同结构的 k 个项，每个项贡献 k^0 = 1 乘以长度 1 的几何和，产生预期的 k。 

当 j = 1 时，比率 r 恰好变为 1。 这是几何公式在通用形式中除以零的唯一点。 显式分支干净地处理这种情况，产生线性和而不是几何和。
