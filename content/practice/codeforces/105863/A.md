 ## 解决方案
 ## 问题理解

 我们正在研究一个坐标系，其中每次移动都不是标准步骤，而是类似反射的变换。 从给定点开始，我们可以重复选择另一个点并通过它进行“反射”，从而根据固定的几何规则产生新的位置。 

任务是确定从过程原点（或等效地，从固定初始点）开始可以到达平面中的哪些点，假设每个操作都使用此反射规则移动当前位置。 输出只是在任意次数的此类操作之后是否可以到达目标点。 

尽管这个操作听起来很几何，但关键的困难在于重复的反射可以创造出不平凡的作品。 简单的解释可能会暗示复杂的可达区域，因此主要的挑战是在简单的代数条件下表征可达性。 

从每个测试用例必须在恒定时间内独立回答的意义上来说，约束实际上是严格的。 如果我们尝试模拟反射或搜索中间状态，即使像 10^5 查询这样的适度界限也会立即使该方法不可行，因为每个查询可能涉及连续几何或无界中间状态。 

当坐标非常小或为零时，会出现微妙的边缘情况。 例如，如果起始点和目标点在任一坐标中相差正好一个，则某些幼稚的几何推理可能会错误地假设路径存在，因为“我们可以任意接近”，但变换会保留奇偶结构，从而使此类转换变得不可能。 

另一种边缘情况是两个坐标都匹配奇偶校验但距离很大。 天真的网格行走直觉可能表明中间可行性很重要，但实际上只有奇偶一致性很重要，而不是大小。 

## 方法

 暴力方法将模拟反射过程。 从初始点开始，我们将尝试所有可能的反射中心并重复生成新点，本质上是在无限隐式状态空间上执行图遍历。 即使我们将自己限制在目标周围的有界区域内，分支因子原则上也是无限的，因为平面上的每个点都是潜在的反射中心。 这使得任何直接模拟都变得不可能。 

关键的见解来自于对单个反射的代数分析。 如果我们通过一个点 (x₁, y₁) 反射另一个点 (x, y)，结果是 (2x − x₁, 2y − y₁)。 此操作保留了奇偶校验结构：新点的每个坐标取决于加倍整数减去原始坐标，这意味着两个坐标的奇偶校验是模 2 不变的。 

一旦我们认识到这个不变量，整个问题就会分解为检查目标点是否满足与起点相同的奇偶校验约束。 如果奇偶校验匹配，我们可以通过选择适当的中点来构建到达奇偶校验的反射序列，从而有效地逐步反转反射操作。 如果奇偶校验不匹配，则任何操作序列都无法更改它。 

蛮力之所以有效，是因为它探索了所有可能的变换，但它失败了，因为状态空间是连续且无界的。 反射保留坐标奇偶性的观察将问题简化为每个查询的恒定时间检查。

 ## 算法演练

 我们将每个查询简化为起点和目标点之间的简单奇偶性比较。

1. 读取起点和目标点的坐标。 所有操作的起点都是固定的，因此我们将其作为奇偶校验的参考。 
2. 计算目标和起始点之间x 坐标差的奇偶性。 这相当于检查两个 x 值是偶数还是奇数。 
3. 以同样的方式计算 y 坐标差的奇偶性。 
4. 如果两个奇偶校验匹配，则输出 YES。 否则输出NO。 

我们将 x 和 y 分开的原因是反射操作独立地作用于每个坐标，因此可达性的约束可以在轴上清晰地分解。 

### 为什么它有效

 反射公式将点 (x₁, y₁) 变换为 (2x − x₁, 2y − y₁)。 模 2，值 2x 始终为 0，因此每个坐标都与 -x₁ modulo 2 全等，这与 x₁ modulo 2 相同。这表明奇偶校验在每次操作下都是不变的。 由于唯一可达的状态是那些保留奇偶性的状态，并且由于可以通过适当选择中点来构造匹配奇偶性的任何点，因此奇偶性充分表征了可达性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    # assuming input is multiple test cases of form:
    # x1 y1 x2 y2 per line (typical for this kind of problem)
    data = input().strip().split()
    if not data:
        return
    
    x1, y1, x2, y2 = map(int, data)
    
    if (x1 % 2 == x2 % 2) and (y1 % 2 == y2 % 2):
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```该实现直接对先前导出的奇偶校验条件进行编码。 唯一微妙的一点是确保我们独立比较 x 和 y 的奇偶校验； 混合它们或使用绝对差异是不正确的，因为奇偶性与距离无关，而是与模块化结构有关。 

使用模 2 对于负坐标也是安全的，因为 Python 的模运算符可以正确保留整数的奇偶校验等价性。

这些例子表明，大小并不重要，只有奇偶校验一致性才能控制系统。

 ## 边缘情况

 一种重要的边缘情况是起点和目标在坐标上相差正好一。 例如，从 (0, 0) 开始并定位 (1, 0)。 该算法检查奇偶校验：0 % 2 为 0，而 1 % 2 为 1，因此结果为“否”。 这正确地处理了单个反射可能桥接相邻点的误解。 

另一种情况是坐标非常大但仍然共享奇偶校验，例如 (10^9, 10^9) 到 (2, 2)。 该算法仍然返回 YES，因为奇偶校验比较与大小无关。 计算减少为检查两个模运算，因此不会出现溢出或精度问题。 

最后一种情况是只有一个坐标与奇偶校验匹配。 例如，(2, 3) 至(4, 6)。 这里 x 匹配奇偶校验，但 y 不匹配，并且算法正确返回 NO，反映了两个轴必须独立满足反射下不变性的事实。
