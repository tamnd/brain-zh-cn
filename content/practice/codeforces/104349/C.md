 ## 解决方案
 ## 问题理解

 我们得到一个小整数序列，每个小整数彼此独立。 对于每个数字，我们检查它在三种不同数字系统中的外观：以 10 为基数（通常的十进制形式）、以 2 为基数（二进制形式）和以 16 为基数（十六进制形式）。 在每个基数中，我们将数字写为一串数字，并询问该字符串向前和向后读起来是否相同。 

如果这三个表示中至少有两个是回文，则该数字被认为是“超级”。 对于每个测试用例，我们根据条件是否满足输出两个固定字符串之一。 

这些限制的幅度极其严格。 每个数字最多1000个，测试用例最多1000个。 将数字转换为基数 2 或基数 16 会分别生成长度最多约为 10 和 3 的字符串，因此回文检查实际上是恒定时间的。 这立即排除了任何试图在大范围内进行大量预计算或任何组合搜索的方法。 直接按数字评估就足够了。 

主要的边缘情况来自回文在不同基数中的行为方式。 像 1 这样的数字在每个底数中都是回文，所以它总是符合条件。 像 10 这样的数字不是十进制的回文，但根据表示形式可能是也可能不是二进制或十六进制，因此必须独立检查每个基数。 一个常见的错误是在代码中转换时忘记去除“0b”或“0x”等前缀，这会破坏回文检查。 

## 方法

 最直接的策略是独立处理每个数字并显式计算其以 2、10 和 16 为基数的表示，然后测试每个字符串的对称性。 

对于单个数字，使用重复除法或内置格式转换为二进制或十六进制很简单。 一旦我们有了字符串，回文检查就是简单的两指针比较或字符串反转比较。 

这种暴力方法在这里已经是最佳的。 每个测试用例只需要恒定的工作量：三个转换和三个回文检查。 即使在 1000 个测试用例的最坏情况下，总工作量仍然可以忽略不计。 

关键的观察结果是问题结构不包含数字之间的任何相互依赖性。 没有共享状态，没有前缀计算，也没有通过预处理进行优化的机会。 每个数字的界限都很小，因此直接模拟是预期的解决方案。

 ## 算法演练

 我们独立处理每个数字并评估其三种表示形式。 

1. 读取当前测试用例的整数n。 该值足够小，因此所有转换的成本都是微不足道的。 
2. 将 n 转换为十进制字符串形式，通过比较两端的对称字符来检查是否为回文。 这给出了第一个属性。 
3. 将 n 转换为不带前导前缀的二进制表示形式，并以相同的方式检查回文对称性。 这给出了第二个属性。 
4. 将n 转换为大小写一致的十六进制表示，然后检查向前和向后读取是否相同。 这给出了第三个属性。 
5. 计算这三项检查中有多少是正确的。 如果计数至少为二，则输出“ghavi”，否则输出“fanni khordim”。 

独立检查所有三个的原因是每个碱基对数字进行不同的编码，并且回文结构不会跨碱基保留。 

### 为什么它有效

每个表示形式都是同一整数的确定性字符串编码，但回文有效性完全取决于字符序列。 由于我们独立评估所有三个并且只需要两个阈值，因此该决策纯粹基于计算布尔属性。 碱基之间不存在相互作用，因此任何隐藏案例都无法逃脱这种分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_pal(s: str) -> bool:
    return s == s[::-1]

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())

        dec = str(n)
        bin_s = bin(n)[2:]
        hex_s = hex(n)[2:]

        cnt = 0
        if is_pal(dec):
            cnt += 1
        if is_pal(bin_s):
            cnt += 1
        if is_pal(hex_s):
            cnt += 1

        if cnt >= 2:
            print("ghavi")
        else:
            print("fanni khordim")

if __name__ == "__main__":
    solve()
```该实现依赖于Python内置的基数转换函数。 切片`[2:]`至关重要，因为两者`bin()`和`hex()`包含否则会破坏回文比较的前缀。 辅助函数避免了重复的反转逻辑并保持每次检查的统一。

 ## 边缘情况

 对于最小的输入值1，算法将其转换为`"1"`在所有三个基地中。 每个回文检查都会比较一个单字符字符串，因此所有三个属性的计算结果均为 true，并且计数器变为 3。 因此，输出为“ghavi”，符合要求。 

对于像 2 这样的数字，十进制表示为`"2"`，二进制是`"10"`，十六进制是`"2"`。 只有十进制和十六进制字符串是回文，但由于二进制失败，总计数正好是一。 该算法正确输出“fanni khordim”，因为它需要至少两个满足的属性。
