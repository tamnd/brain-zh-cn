 ## 解决方案
 ## 问题理解

 我们有一排奶牛，每头奶牛都有独特的 Cowdeforces 评级，它们参加连续的锦标赛。 比赛从前两头奶牛开始，随后的每场比赛都在上一场比赛的获胜者和排队的下一头奶牛之间进行。 评级较高的牛总是获胜。 您拥有一头牛，可以与任何其他牛交换一次，或将其保留在原处。 目标是最大化你的奶牛赢得的比赛数量。 

输入由多个测试用例组成。 每个测试用例都会给出奶牛的数量、奶牛从 1 开始的索引以及所有奶牛在初始位置的评分。 每个测试用例的输出是一个数字，代表您的奶牛在最佳交换策略下可实现的最大胜利。 

这些约束允许所有测试用例中总共最多有 100,000 头奶牛。 这意味着任何时间复杂度低于每个测试用例 O(n) 的解决方案都可能太慢。 具体来说，所有可能交换的嵌套模拟将导致 O(n^2) 行为，这是不可接受的。 

当你的奶牛已经是其所在群体中最强或最弱的时候，就会出现微妙的边缘情况。 例如，如果您的牛已经是第一并且比接下来的几头牛更强，那么天真的方法可能会尝试不必要的交换并减少总胜利。 另一个棘手的情况是，最好的策略是将你的牛向前移动到较弱的序列，而不是从头开始。 例如，考虑等级 [2, 1, 5]，而你的奶牛等级为 2。交换到位置 2 会带来一场胜利，但交换到位置 3 会带来零场胜利。 处理这些需要仔细考虑局部最大值和较弱奶牛的顺序。 

## 方法

 蛮力方法很简单。 您可以模拟您的牛与另一头牛的每次可能的交换的锦标赛，然后计算每个场景的胜利并选择最大值。 这是正确的，因为锦标赛规则是确定性的。 然而，这需要每个测试用例进行 O(n^2) 次操作：对于 n 头奶牛，我们会考虑 n 个可能的交换位置，并且每个模拟最多可以执行 n 个步骤。 当n达到10^5时，在最坏的情况下这会导致10^10次操作，这是不可行的。 

关键的观察是，在连续锦标赛中，只有比你的牛弱的牛才重要。 如果你的牛比队列中的下一头牛更强，它将继续获胜，直到遇到比自己更强的牛。 因此，为了最大化胜利，我们只需要找到一个位置，使你的奶牛遇到比自己弱的奶牛的最长连续序列。 这意味着最佳策略是要么将你的奶牛保持在原位，要么将其移动到“峰值”奶牛（比你的奶牛更强的奶牛）之前，以最大化连续胜利。 

我们可以通过从左到右扫描来在 O(n) 时间内实现这一点。 我们保留了一个计数器，计算您的牛从任何给定位置开始可以击败多少只较弱的牛。 我们在所有有效的起始位置上保持最大值（包括将奶牛保持在适当的位置）。 该问题简化为比较评级的简单线性扫描，避免了每次交换的完全模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取奶牛的数量 n、你的奶牛的索引 k 和评级数组 a。 将基于 1 的索引 k 转换为基于 0 的索引，以便于数组处理。 
2.初始化两个变量：`max_wins`追踪最佳获胜次数，以及`current_wins`计算当前位置的连续获胜次数。 
3. 从左到右迭代数组。 如果当前牛是你的牛，则重置`current_wins`为零，因为它从这里开始计算胜利。 
4. 对于任何其他牛，检查如果您的牛处于此位置，它是否会获胜。 如果您的牛的评级高于当前比赛中牛的评级，则情况如此。 如果是，则增加`current_wins`。 
5. 更新`max_wins`每当`current_wins`超过它。 这确保我们始终跟踪您的奶牛从某个位置开始可能获得的最长连胜。 
6. 扫描阵列后，`max_wins`代表你的牛可以通过留在原地或通过单个最佳交换赢得的连续比赛的最大数量。 

为什么有效：不变的是，一头牛只能依次击败比自己弱的牛。 通过线性扫描并计算连续较弱的奶牛，我们会自动考虑放置奶牛的最佳位置，包括将其保持在原始位置。 这避免了显式模拟每个匹配但给出相同的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_wins_for_cow(n, k, a):
    cow_rating = a[k-1]
    max_wins = 0
    current_wins = 0
    for rating in a:
        if rating == cow_rating:
            current_wins = 0
            continue
        if rating < cow_rating:
            current_wins += 1
            max_wins = max(max_wins, current_wins)
        else:
            current_wins = 0
    return max_wins

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print(max_wins_for_cow(n, k, a))
```该解决方案首先隔离您的奶牛的评级。 然后，它迭代所有奶牛，计算任何段中存在多少连续较弱的奶牛，如果出现更强的奶牛，则重置计数器。 使用`current_wins`确保我们跟踪连续记录，并且`max_wins`保持最好的结果。 将 k 转换为基于 0 的索引可以避免差一错误。

 如果我们以最佳方式交换，则最大胜利为 1，因为序列在满足 14 时中断。该表表明，计算连续较弱的奶牛可以正确处理当出现较强的奶牛时的连续重置。

 | 测量| 复杂性 | 说明|
