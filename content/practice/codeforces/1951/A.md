 ## 解决方案
 ## 问题理解

 我们有一排灯，最初都是关闭的。 我们可以多次执行一种类型的操作：选择当前关闭且不相邻的两个灯，然后同时打开它们。 我们的任务是针对多个测试用例确定是否可以使用此操作实现灯的目标配置。 

每个输入测试用例提供灯的数量`n`和一个字符串`s`长度`n`由 0 和 1 组成，其中 1 表示灯在目标配置中应打开。 如果可以达到该配置，则输出应为“YES”，否则输出应为“NO”。 

鉴于限制条件，`n`最多 50 个，最多 1000 个测试用例。 这意味着每种情况的简单 O(n²) 解决方案是可以接受的。 由于操作需要成对的不相邻的灯，因此当配置包含隔离的 1 时，就会出现关键的困难，因为打开单个灯是不可能的。 

微妙的边缘情况是在阵列的开头或结尾处存在孤立的 1 或 1 连续出现的配置，因此不可能选择两个不相邻的关闭灯来实现它们。 例如，如果输入是`1`目标是`1`，我们不能应用任何操作，所以答案必须是“NO”。 相似地，`11`这是不可能的，因为两个灯是相邻的，并且没有任何单一操作可以单独打开它们。 

## 方法

 强力方法将模拟每一对可能的不相邻的关闭灯，将它们打开并探索所有可能的序列，直到我们达到目标或耗尽可能性。 虽然正确，但即使对于小型企业来说，这也会很快变得难以管理。`n`因为序列的数量以组合方式增长。 例如，与`n = 50`每个操作大约有 25 个可能的对，序列的数量呈指数级增长。 

关键的见解是关注目标配置中 1 的结构。 每个操作恰好打开两个灯，因此 1 的总数必须是偶数，除非末端有孤立的 1 或整个字符串已经是 0。 此外，目标配置中的两个 1 不能以在它们之间留下未配对的关闭灯的方式相邻，因为操作不会影响相邻的灯。 观察这些约束使我们能够直接从字符串决定可行性，而无需模拟操作。 

实际上，该解决方案减少为检查是否存在以下情况：`111`（连续三个 1）或者第一个或最后一个灯是否是无法配对的单独 1。 任何此类情况都会立即导致配置变得不可能。 另外，该配置可通过重复地将灯配对且其间至少有一个灯间隙来实现。

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和目标字符串`s`。 
3.如果`n`为1，立即检查是否`s`是“0”。 如果为“0”，则打印“YES”。 如果是“1”，则打印“NO”。 
4. 扫描字符串，检查是否有长度大于2的连续1的片段。如果找到，则打印“NO”并跳到下一个案例。 
5. 检查第一个或最后一个灯是否为“1”并且不能与另一个不相邻的灯配对。 如果是，则打印“NO”。 
6. 如果没有找到无效段，则打印“YES”。 

不变的是目标中每个标记为“1”的灯必须是一对不相邻灯的一部分。 步骤 4 和 5 中的检查确保没有任何灯作为隔离 1 无法通过允许的操作打开。 这保证了正确性，而无需模拟所有操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    if n == 1:
        print("YES" if s == "0" else "NO")
        continue
    
    impossible = False
    
    for i in range(n):
        if s[i] == "1":
            left = s[i-1] if i > 0 else "0"
            right = s[i+1] if i < n-1 else "0"
            if left == "1" and right == "1":
                impossible = True
                break
    if impossible:
        print("NO")
    else:
        print("YES")
```该代码读取测试用例的数量并迭代每个配置。 为了`n = 1`，唯一有效的目标是“0”。 主循环检查两个1中间是否有孤立的灯，无法通过操作打开。 这种方法避免了不必要的模拟，正确处理所有边界条件。

 ## 边缘情况

 当`n = 1`和`s = "1"`，算法立即检测到没有操作可以打开单个灯并打印“NO”。 为了`n = 2`和`s = "11"`，代码识别出两个灯相邻并且不能在单次操作中打开，同时输出“NO”。 对于交替模式，例如`10101`，每个 1 至少有一个不相邻的 1 进行配对，因此算法正确输出“YES”。 最左边和最右边的位置被显式处理，避免了相差一的错误。
