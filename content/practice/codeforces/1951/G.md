 ## 解决方案
 ## 问题理解

 我们有一圈篮子，编号从 1 到$m$， 和$n$球最初放置在不同的篮子中。 爱丽丝重复随机均匀地选择其中一个球，并将其顺时针移动到下一个篮子。 如果该篮子已经装有球，则现有的球将被扔掉。 这一过程一直持续到只剩下一个球为止。 任务是计算此过程所需的预期秒数。 

从输入角度来看，每个测试用例提供了球的数量$n$, 篮子数量$m$，以及球的初始位置数组。 输出必须是预期时间（以秒为单位），减少模数$10^9 + 7$作为分数$p/q$， 在哪里$q$是可逆模数$10^9 + 7$。 

限制因素很大。$n$可以达到$3 \cdot 10^5$每个测试用例和$m$最多$10^9$。 总和为$n$所有测试用例不超过$3 \cdot 10^5$。 一步步移动每个球的简单模拟是不可行的，因为它可能需要最多$O(m \cdot n)$每个测试用例的操作，这远远超出了可接受的范围$m \sim 10^9$。 我们需要一个大致运行的解决方案$O(n \log n)$或者$O(n)$每个测试用例。 

边缘情况包括以下场景：$n = 1$，在这种情况下不需要时间，或者当球连续或以相反顺序放置时，这可能会创建以可预测方式相互作用的簇。 粗心的方法可能会尝试模拟每一秒，从而导致时间复杂度爆炸或对重叠运动的错误处理。 

## 方法

 暴力方法会模拟爱丽丝动作的每一秒。 我们将维护一个代表篮子的数组，随机挑选一个球，移动它，检查碰撞，然后重复，直到只剩下一个球。 这种方法原则上是正确的，但速度非常慢，因为操作数量随着步数的增加而增加，直到只剩下一个球，可能高达$O(n \cdot m)$。 为了$n = 3 \cdot 10^5$和$m = 10^9$，这是行不通的。 

关键的见解是对问题进行概率建模，而不是通过模拟。 每个球与顺时针方向的下一个球都有一个“碰撞距离”。 一旦我们知道了这些距离，消除球所需的预期移动次数就与按选择概率缩放的距离成正比。 更正式地说，如果一个球有$d$在击中下一个球之前的空篮，在造成碰撞之前预期的移动次数为$n \cdot d$。 我们将除最后一个球以外的所有球的贡献相加。 按球的初始位置对球进行排序使我们能够有效地计算顺时针距离。 需要模逆，因为期望值是一个分数，我们必须在模下减少它$10^9 + 7$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n + m) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$,$m$，以及位置数组$a$。 
3.如果$n = 1$，答案立即为 0，因为只有一个球存在。 
4. 对位置数组进行排序$a$轻松计算连续球之间的顺时针间隙。 
5. 使用以下公式计算连续球之间的顺时针距离$(a_{i+1} - a_i - 1 + m) \% m$。 这给出了碰撞发生之前空篮子的数量。 
6. 将这些距离相加，得到“自由移动”的总数，直到除掉一个球之外的所有球为止。 这个总和代表了预期时间的分子。 
7. 将该总和乘以$n$因为每次移动都有概率发生$1/n$，以有理形式给出预期的总秒数。 
8. 对结果求模$10^9 + 7$使用模逆$1$（或者如果需要的话直接计算分数），确保结果是整数模$10^9 + 7$。 

该算法之所以有效，是因为按排序顺序排列的球之间的距离唯一地确定了每个球必须移动多少次才能消除下一个球。 每个球对总预期时间都有独立的贡献，并且均匀随机选择通过以下方式缩放该贡献：$n$。 排序可确保在圆形数组上正确计算距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        if n == 1:
            print(0)
            continue
        a.sort()
        total_dist = 0
        for i in range(n):
            nxt = a[(i + 1) % n]
            dist = (nxt - a[i] - 1 + m) % m
            total_dist += dist
        expected_time = (total_dist * n) % MOD
        print(expected_time)

solve()
```该代码首先读取输入并定义模常数。 这`modinv`function 是在需要时计算模逆的实用程序。 对于每个测试用例，如果只存在一个球，则答案为零。 否则，对球进行排序以计算顺时针距离。 每个距离都通过模算术调整圆度。 预计时间乘以距离总和$n$因为每个球都有一个$1/n$每秒移动的机会。 结果以模数形式打印$10^9 + 7$。

 对于第一个样本：```

 ## 边缘情况

 当$n = 1$，算法立即返回 0。 对于连续篮子中的球，距离计算正确地围绕模数进行计算$m$。 对于间距较大的球，模数调整可确保正确计算圆形距离。 乘以$n$正确地解释了均匀随机选择。 在所有情况下，模运算都会将数字保持在 32 位整数范围内并避免溢出。
