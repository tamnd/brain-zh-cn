 ## 解决方案
 ## 问题理解

 我们得到一个长度为 n 的数组，它描述了一系列维护禁令。 每一秒 i 都禁止使用一个频率 ai。 有 n + 1 个可能的频率，标记为从 0 到 n，其中较小的标记更理想。 

我们将时间线分成 k 个连续的片段。 在一个段内，我们查看该段中出现的所有禁止值，并计算从未出现在那里的最小非负频率。 该值是该段选择的频率，因此每个段纯粹根据其范围内缺少的频率生成一个数字。 

固定分割后，我们获得 k 个这样的值。 另外，我们必须选择一个紧急频率y。 这个 y 可以是出现在原始数组中某处的任何值，但它不能等于 k ​​段值中的任何一个。 我们希望 y 尽可能小，因此我们尝试强制将较小的数字放入分段结果中，以“阻止”它们被选为 y。 

关键的张力在于分区控制出现哪些 mex 值，而这些 mex 值会删除 y 的候选值。 我们希望设计 k 个段，以便尽可能多的小值成为段 mex 结果，尤其是那些实际出现在数组中的小值。 

约束允许 n 最多为 100 万，这排除了任何分段策略或所有分区的简单模拟。 任何从头开始重新计算每个段的 mex 或尝试所有剪切位置的操作都会立即变得太慢。 我们需要一个带有仔细贪婪推理的线性或近线性构造。 

一个微妙的边缘情况来自这样一个事实：y 必须来自数组中出现的值。 即使我们设法使某些数字不出现在段 mex 值中，只有该数字存在于输入中才重要。 另一个极端情况是当 k 很大时：我们可能没有足够的“有用”mex 值来实际强制执行，因此剩余的段变得无关紧要。 

## 方法

 暴力策略会尝试所有可能的方法将数组分成 k 段，计算每个段的 mex，收集结果集，然后确定最小的有效 y。 即使忽略分区的数量，重复计算 mex 也已经很昂贵了。 对于单个分区，在线性时间内重新计算每个段的 mex 给出每次分割的 O(n)，并且分割的数量以 n 为指数，使得这完全不可行。 

关键的观察是，段的 mex 仅取决于它是否包含从 0 向上的所有值。 要强制段 mex 为 x，该段必须至少包含一次从 0 到 x − 1 的每个数字，并且必须完全丢失 x。 这将每个 mex 值转变为对我们放置段边界的位置的结构约束。 

我们不再考虑全局分区，而是翻转视角。 我们询问哪些值 x 可能会出现为某个段的 mex。 一旦我们知道了这一点，我们就可以决定我们能够在最多 k 个段上“花费”哪些值，因为每个选定的 mex 都会消耗一个段。 

如果我们可以选择所有数字 0 到 x − 1 的出现，使得它们位于避免所有 x 出现的区域中，则值 x 作为线段 mex 是可行的。 这创建了一个基于间隙的条件：x 的出现将数组划分为区间，并且我们必须在不接触 x 的单个区间内至少容纳每个较小数字的出现一次。 

识别出所有可行的 mex 值后，最佳策略是选取数组中实际出现的最小可行值中的 k 个。 这些成为分部结果。 那么答案 y 就是这 k 个选项中未被选中的最小数组值。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解分区 | 指数| O(n) | 太慢了 |
 | 可行性+ mex 值的贪婪选择 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们分两个阶段构建解决方案。 首先我们确定哪些值可以显示为段 mex。 然后我们最多选择 k 个，以最大化被阻止的小数组值的数量。 

1. 对于每个值 v，计算 v 在数组中出现的位置列表。 这让我们可以推断出 v 造成的间隙。 
2.对于固定的候选x，查看x在数组中的位置。 这些位置将时间线分成几个不包含 x 的最大间隔。 mex 等于 x 的任何线段必须完全位于这些区间之一内。 
3. 在一个这样的区间内，我们检查是否可以收集从 0 到 x − 1 的每个数字至少出现一次。如果存在一个可能的区间，则 x 是一个可行的 mex 值。 
4. 我们对数组中出现的所有值重复此可行性检查。 这为我们提供了可以作为分段结果实现的所有 mex 值的集合。 
5. 对数组中也出现的可行值进行排序。 从这个排序列表中，获取最小的 k 值。 这些是我们分配给 k 段的 mex 值。 
6. 紧急值 y 是出现在数组中但不在这些选定的 mex 值中的最小数字。 

一个关键的结构属性是值 x 的可行性并不取决于我们如何在其他地方分割数组。 每个段都可以独立验证，因为 mex 约束是该段的本地约束。 唯一的全局耦合来自于我们总共只能使用 k 个段，因此我们只能选择 k 个可行的 mex 值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    pos = [[] for _ in range(n + 1)]
    present = [False] * (n + 1)

    for i, v in enumerate(a):
        pos[v].append(i)
        present[v] = True

    def can_make_mex(x):
        if x == 0:
            return True
        if not present[x]:
            return True

        # we try each gap between occurrences of x
        occ = pos[x]
        # build boundaries of x-free segments
        segments = []

        prev = -1
        for p in occ:
            segments.append((prev + 1, p - 1))
            prev = p
        segments.append((prev + 1, n - 1))

        need = set(range(x))
        need_list = list(need)

        for l, r in segments:
            if l > r:
                continue
            seen = set()
            for i in range(l, r + 1):
                if a[i] < x:
                    seen.add(a[i])
            if all(v in seen for v in need_list):
                return True

        return False

    feasible = []
    for x in range(n + 1):
        if present[x] and can_make_mex(x):
            feasible.append(x)

    feasible.sort()

    chosen = set(feasible[:k])

    for v in range(n + 1):
        if present[v] and v not in chosen:
            print(v)
            return

    print(n)

if __name__ == "__main__":
    solve()
```代码首先构建位置列表，以便我们可以推断每个值出现的位置。 功能`can_make_mex(x)`通过扫描无 x 区间并验证所有所需的较小值是否出现在至少一个这样的区间内，检查是否存在可以实现 mex x 的段。 

收集所有可行的 mex 值后，我们对它们进行排序并取最小的 k，因为这些对于阻止 y 的小候选值最有价值。 最后，我们向上扫描以找到未用作所选 mex 的最小数组值。 

一个微妙的细节是处理 x = 0。当且仅当一个段不包含 0 时，它才具有 mex 0，因此任何不包含 0 的区间都会立即满足该条件。 

## 工作示例

 考虑输入`n = 3, k = 2`带数组`[1, 3, 0]`。 

我们首先确定可行的 mex 值。 对于 x = 0，如果可能的话，我们总是可以选择一个避免 0 的段。 对于x = 1，我们需要一个包含0但不包含1的段； 这在 0 单独出现的区间内是可能的。 对于 x = 2 和 x = 3，类似的检查表明可行性取决于我们是否可以在不包含 x 的情况下隔离所需的较小值。 

可行性之后，假设我们得到可行列表`[0, 1, 3]`。 我们取 k = 2 最小，所以选择的 mex 值是`{0, 1}`。 剩余的数组值是`{0, 1, 3}`，不在所选集合中的最小者是`2`如果出现，否则我们继续向上。 

此跟踪显示了 mex 可行性如何转化为最终答案的阻塞低整数。 

现在考虑`n = 2, k = 2`带数组`[0, 2]`。 

对于 x = 0，如果我们隔离第二个元素，我们总是可以形成一个没有 0 的线段。 对于x = 2，可行性取决于我们是否可以在没有2的段中收集0和1，这是不可能的，因为1永远不会出现。 因此可行的 mex 值是有限的。 当 k = 2 时，我们选择所有可行值，留下 y 作为未覆盖的最小数组值。 

这演示了缺失中间值如何减少 mex 构造的可能性。

 ## 边缘情况

 关键的边缘情况是值 0 从未出现在数组中。 在这种情况下，每个段自动具有 mex 0，因此无论分段如何，mex 0 始终可行。 该算法立即正确地将 0 标记为可行，并允许在选择步骤中使用它。 

另一种情况是当 k 与可行 mex 值的数量相比较大时。 即使我们只能构造几个不同的 mex 值，该算法仍然有效，因为它最多选择其中 k 个，并且不会尝试强制添加额外的不可能的段。 

第三种情况是当值以高度聚集的形式出现时，会创建许多无 x 区间。 可行性检查仍然有效，因为它只需要为每个 x 找到一个有效区间，而忽略其余的。
