 ## 解决方案
 ## 问题理解

 我们正在研究一个随机财富过程$n$人们。 每个人都从一个单位的货币开始。 此后，会发生许多额外的单位转移。 每次转账都是通过选择接收者的概率与其当前财富成正比来产生的，因此越富有的人更有可能变得更富有。 所有转让完成后，我们将财富常态化为股份$p_i = \frac{s_i}{\sum s_i}$，因此份额总和为 1。 

最终状态是概率单纯形上的随机点，但不以任意方式统一：它来自优先附着过程。 这是具有相同初始权重的经典 Pólya urn，这意味着最终的归一化向量具有与所有参数等于 1 的对称狄利克雷分布相同的分布。 

我们没有观察完整的配置。 相反，我们被告知只有所有人中最小的份额，称之为$p_{(1)} = a$。 在这种情况下，我们被要求计算最大份额的期望值$p_{(n)}$。 

关键的困难在于，对对称狄利克雷分布的阶统计量进行调节会以一种非常重要的方式改变可行区域的几何形状。 一种简单的方法会尝试模拟该过程或显式集成所有配置，但状态空间是连续且高维的，因此即使对于中等水平的人来说，这也会很快变得棘手$n$。 

限制条件$n \le 2000$排除任何涉及子集枚举或单纯形离散化的内容。 价值$a \le \frac{1}{n}$与可行性一致：如果最小份额为$a$，那么至少$n a \le 1$必须持有，因为股份总数为 1。 

一个微妙的问题是事件“最小值恰好等于$a$” 隐式意味着一个坐标恰好是$a$和所有其他的都严格更大。 在连续分布中，关系的概率为零，因此这种解释是安全的，但它对于我们如何分解结构很重要。 

## 方法

 暴力思维模型是考虑单纯形上所有可能的最终财富向量，过滤那些最小坐标等于的向量$a$，然后对最大坐标进行平均。 即使忽略计算，几何形状也很复杂：我们正在使用由阶统计量定义的边界约束对单纯形的切片区域进行积分。 直接集成需要处理$n$由最小坐标确定的维分段区域，这在组合上变得混乱。 

结构性突破来自于将分布识别为对称狄利克雷分布$(1,1,\dots,1)$，在单纯形上是均匀的。 以最小值为条件$a$迫使一个坐标位于边界处，在去除该最小值所贡献的固定质量后，其余坐标的行为就像一个低维均匀单纯形。 

这减少了问题$n$维序统计问题$(n-1)$统一单纯形上的维期望，加上确定性偏移$a$。 

其余成分是均匀狄利克雷向量的预期最大坐标的已知封闭形式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过有序单纯形直接积分 | 指数为$n$| 大象征| 太慢了 |
 | 狄利克雷约简+已知阶统计公式|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 认识到最终的归一化财富向量遵循参数全部等于 1 的对称狄利克雷分布。这意味着向量在概率单纯形上均匀分布。 
2. 解读“最低份额等于”事件$a$” 因为恰好存在一个坐标等于$a$，其他所有的都严格更大。 这是合理的，因为分布是连续的，因此出现平局的概率为零。 
3. 从所有坐标中减去最小贡献。 让$p_i = a + x_i$。 对于最小坐标，$x = 0$，而所有其他人都满足$x_i > 0$。 
4. 转换总和约束。 自从$\sum p_i = 1$，我们得到$\sum x_i = 1 - n a$。 这将问题简化为总质量的单纯形$1 - n a$超过$n$1 固定为零的变量。 
5、去掉零坐标，重点关注剩下的$n-1$积极的变量。 归一化后$1 - n a$，剩余向量再次均匀分布在维度单纯形上$n-1$。 
6. 表达最大份额。 最大原始份额为$a + \max(x_i)$，并且自从$x_i = (1 - n a) y_i$， 在哪里$y$是统一的$(n-1)$-单纯形，我们得到$$p_{(n)} = a + (1 - n a)\cdot \max(y).$$7. 线性地取期望：$$\mathbb{E}[p_{(n)} \mid p_{(1)} = a] = a + (1 - n a)\,\mathbb{E}[\max(y)].$$8. 使用已知的闭合形式来求维度上均匀狄利克雷向量的期望最大值$k$:$$\mathbb{E}[\max] = \frac{H_k}{k},$$在哪里$H_k$是谐波数。 这里$k = n-1$。 

### 为什么它有效

 关键的不变量是，在去除固定坐标并重新归一化之后，对称狄利克雷分布中的边界阶统计量的条件保持了简化单纯形的均匀性。 在这种类型的边缘条件下，狄利克雷分布是可交换的且稳定的，这可以防止剩余坐标超出线性缩放范围的失真。 这使得期望能够干净地分解为确定性转变加上缩放的已知期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, a = input().split()
    n = int(n)
    a = float(a)

    if n == 1:
        print(1.0)
        return

    k = n - 1

    # harmonic number H_k
    H = 0.0
    for i in range(1, k + 1):
        H += 1.0 / i

    expected_max_simplex = H / k

    ans = a + (1.0 - n * a) * expected_max_simplex
    print(f"{ans:.12f}")

if __name__ == "__main__":
    solve()
```该实现直接应用派生的分解。 唯一重要的计算是谐波数，在线性时间内计算$n$，这很容易足够快$n \le 2000$。 最终表达式仔细地将确定性贡献与剩余单纯形的最小值和缩放期望分开。 

一个常见的陷阱是忘记比例因子$1 - n a$。 如果没有它，结果会错误地假定剩余质量为 1，而不是固定最小坐标后减少的单纯形体积。

 ## 边缘情况

 当$a = \frac{1}{n}$，所有质量已经集中在最小约束水平。 在这种情况下$1 - n a = 0$，所以剩余的单纯形消失并且每个坐标必须等于$a$。 该算法干净地处理了这个问题，因为缩放项取消了预期的最大贡献。 

什么时候$a$非常小，单纯形与完全狄利克雷分布几乎没有变化。 然后结果接近维数均匀单纯形的无条件期望最大值$n$，即$\frac{H_n}{n}$。 公式在这种情况下平滑地减少，因为$1 - n a \approx 1$。 

什么时候$n = 2$，“剩余单纯形”的维数为 1，并且最大值确定性为 1。调和表达式正确计算为$H_1/1 = 1$，因此公式可折叠为$1 - a$，匹配两个互补股的几何形状。
