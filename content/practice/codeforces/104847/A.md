 ## 解决方案
 ## 问题理解

 我们正在比较两种方法来彻底测试所有长度的二进制字符串$n$。 有$2^n$可能的秘密。 经典机器每次只测试一个候选人$a$秒，所以它的总时间与$a \cdot 2^n$。 

量子机器的行为有所不同。 和$q$量子位，它可以处理多达$2^q$一批候选字符串，每一批需要$b$秒。 由于有$2^n$量子机器需要的候选者总数$2^{n-q}$批次，所以它的总时间是$b \cdot 2^{n-q}$。 

任务是找到最小的非负整数$q$使得量子时间严格小于经典时间，或者确定不存在这样的$q$存在。 

输入大小可达$10^{18}$，所以直接计算幂，例如$2^n$是不可能的。 任何解决方案都必须避免显式构造指数值，而是依赖于不等式的代数运算。 

当量子机器永远不会更快时，就会出现一个关键的边缘情况，无论$q$。 例如，如果$a \le b$，那么即使具有无限批处理优势，量子方面也不具有竞争力，因为每个批次并不比经典的单一测试便宜。 

另一个微妙的情况是当$n$很小并且$a$很大。 例如，如果$n = 1, a = 100, b = 1$，那么即使是一个很小的$q$使量子立即变得优越。 假设单调行为而不正确解决不等式的天真的方法可能会高估$q$。 

## 方法

 直接模拟会尝试每一个$q$，计算经典和量子运行时间，并比较它们。 经典时间是固定的$n, a$，但是量子时间取决于有多少批次的大小$2^q$需要。 即使我们避免模拟字符串，我们仍然面临指数量，例如$2^n$，使得暴力破解变得不可行。 

蛮力推理原则上是有效的，因为量子运行时间呈指数减少$q$增加。 然而，检查每个$q$需要评估涉及的表达式$2^n$，当$n$很大。 这在运行时甚至成为问题之前就破坏了该方法。 

关键的观察是两个运行时都可以写成闭指数形式：$$T_{\text{classical}} = a \cdot 2^n$$

$$T_{\text{quantum}} = b \cdot 2^{n-q}$$我们比较它们：$$b \cdot 2^{n-q} < a \cdot 2^n$$取消$2^n$:$$b \cdot 2^{-q} < a$$重新排列：$$\frac{b}{2^q} < a \quad \Rightarrow \quad b < a \cdot 2^q$$现在问题变成了寻找最小的$q$这样：$$2^q > \frac{b}{a}$$如果$a \ge b$，那么甚至$q = 0$满足$b < a$，所以量子在零量子位时已经更快了。 

否则，我们计算最小整数$q$这样$2^q > b/a$，这相当于$q = \lfloor \log_2(b/a) \rfloor + 1$。 由于我们只处理整数和大值，因此我们通过重复加倍或位长逻辑来计算它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解结束$q$具有指数值 | 不可能（溢出）| O(1) | O(1) | 太慢了 |
 | 使用不等式进行对数比较 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将条件转换为之间的比较$a$,$b$，以及二的幂。 

1. 比较$a$和$b$。 如果$a \ge b$，那么即使有$q = 0$，量子已经严格来说更好，因为它处理所有字符串$b$秒与$a$传统上每个字符串的秒数，使总体比较立即变得有利。 输出0。 
2.否则，我们需要增加$q$直到批处理优势补偿了较慢的每批时间$b$。 我们寻找最小的$q$这样$a \cdot 2^q > b$。 
3. 开始于$q = 0$和一个值$2^q = 1$。 重复加倍，直到不等式成立。 每次加倍对应于增加$q$1.
 4. 停止时$a \cdot 2^q > b$。 目前的$q$是最小的，因为我们增加了$q$从零开始单调。 

### 为什么它有效

 该不等式将原始指数比较简化为单调函数$q$。 左侧$a \cdot 2^q$严格增加为$q$增加，所以有一个独特的阈值，它首先超过$b$。 从零开始并递增确保我们恰好达到该阈值一次，并在第一次成功时停止保证最小化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, a, b = map(int, input().split())

# Compare directly first condition
if a >= b:
    print(0)
    sys.exit()

q = 0
power = 1  # represents 2^q

while a * power <= b:
    power *= 2
    q += 1

print(q)
```第一个分支处理量子无需任何量子位即可立即竞争的情况。 第二部分保持了明确的表示$2^q$使用重复加倍，避免任何大的指数或对数。 

循环条件直接强制不等式$a \cdot 2^q \le b$，所以第一个$q$这正是答案。 每一步使用乘法 2 可以防止求幂公式的溢出问题，并将所有内容保留在整数算术中。 

## 工作示例

 ### 示例 1

 输入：```

```| 问 | 2^q| a·2^q | a·2^q | 条件 a·2^q ≤ b |

 循环立即停止，因为$a \cdot 1 = 1 \le 1$仍然不是严格意义上的更大，但是因为$a \ge b$是假的，我们小心地继续逻辑：量子在 q=0 时并不更好，但增加 q 只会增加左侧，所以我们仍然需要确保严格的不等式。 第一个$q$在哪里$a \cdot 2^q > 1$是$q = 1$。 输出为1。 

这显示了阈值行为：即使量子位的最小增加也会产生第一个严格优势。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, a, b = map(int, input().split())

    if a >= b:
        return "0"

    q = 0
    power = 1
    while a * power <= b:
        power *= 2
        q += 1
    return str(q)

# provided sample-like cases
assert run("1 1 1") == "0"
assert run("10 100 1") == "0"

# custom cases
assert run("1 1 2") == "1", "small threshold case"
assert run("5 3 20") == "3", "growth crossing case"
assert run("60 1 10") == "4", "larger gap case"
assert run("100 5 4") == "0", "a >= b immediate win"

 ## 边缘情况

 当$a \ge b$，算法立即返回0。例如，输入`100 5 4`触发该分支并避免不必要的计算。 

当之间的差距$b$和$a$很大，比如`60 1 10`，循环执行重复加倍：1,2,4,8,16，四步后到达第一个大于 10 的值，给出$q = 4$。 

当边界处的值相等时，例如`1 1 1`，严格的不平等迫使一个增量，产生$q = 1$， 自从$1 \cdot 2^0 = 1$并不严格大于1。 

所有情况都依赖于单调增加$a \cdot 2^q$，所以第一个交叉点始终是最小有效答案。
