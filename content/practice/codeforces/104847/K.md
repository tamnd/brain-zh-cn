 ## 解决方案
 ## 问题理解

 我们得到了一系列整数，表示净流量随时间的变化。 每个值可以是正数或负数，并且我们可以丢弃任何我们想要的元素，保留剩余元素之间的顺序。 

对于任何选定的子序列，我们通过查看该子序列内的相邻对来定义分数。 对于每个相邻对，我们取两个值中的最大值，并将整个子序列的这些最大值相加。 长度为 1 的子序列贡献为零，空子序列也贡献零。 

任务是选择原始数组的一个子序列来最大化该分数。 

输入大小可以达到 500000 个元素，因此任何尝试所有子序列甚至所有子序列对的解决方案都是立即不可行的。 二次方法已经太大了，任何指数方法都是不可能的。 该解决方案必须在接近线性的时间内有效地运行，或者在最坏的情况下是线性的，因为在编译语言中，两秒内只有大约一千万次操作是安全的，而在 Python 中则要少得多。 

当所有数字均为负数时，会出现微妙的边缘情况。 例如，如果数组为[-5,-4,-3]，则取较长的子序列会增加对贡献的数量，但每个贡献仍然为负，因此最佳策略可能是取单个元素甚至空子序列。 这表明解决方案必须仔细平衡获得更多对与累积负面贡献。 

当较大的正值被许多较小或负值分隔时，会出现另一种边缘情况。 总是选择局部最大值或相邻有益对的天真的贪婪策略可能会失败，因为选择中间元素可能会释放双方的巨大贡献。 

## 方法

 蛮力方法是枚举每个子序列，计算其弱估计，并取最大值。 对于长度为 k 的子序列，计算其分数的成本为 O(k)，并且有 2^n 个子序列，因此总复杂度是指数级的，即使 n = 40 也完全无法使用。 

一个稍微不那么幼稚的想法是仅考虑作为连续片段的子序列。 这将问题简化为 O(n^2) 段，如果直接计算，每个段仍然需要 O(n) 工作，给出 O(n^3)，这仍然太大。 即使使用前缀优化，目标的结构也不能完全分解，因为分数取决于相邻的最大值，而不是简单的总和。 

关键的观察是子序列结构允许我们选择哪些元素变得相邻。 每个选定的元素仅与下一个选定的元素交互，并且对于每个邻接，我们支付 max(a[i], a[j]) ，其中 i < j 并且它们之间没有选定的元素。 这表明从链接元素的角度进行思考。 

现在考虑如果我们修复子序列中最后选择的元素会发生什么。 假设我们在位置 i 结束一条链。 先前选择的元素 j 贡献 max(a[j], a[i])。 如果我们将其重写为 a[i] + max(0, a[j] - a[i])，我们会看到贡献自然地分为基线加上可选的奖金，具体取决于先前的值是否更大。 

这种结构允许动态编程解释：我们维护在每个位置结束的最佳可能链。 延长一条链仅取决于我们是否通过提前或推迟放置更大的元素来获得额外的价值。 最佳结构最终相当于按价值降序对元素进行排序并按该顺序连接它们，因为较早配对较大的值可以最大化未来的贡献并避免浪费潜在收益。 

将问题转化为这种排序见解后，解决方案简化为聚合单调结构中的贡献，可以使用贪婪扫描在线性时间内计算。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将每个选定的子序列解释为一个链，其中每个相邻对贡献两个值中的最大值。 目标是建立一条最大化总贡献的链条。 
2. 将一对 (x, y) 的贡献重写为 max(x, y)，并观察到每对中较大的元素占主导地位。 这表明将较大的元素安排在链的早期通常是有益的。 
3. 按价值降序对元素进行排序或概念性处理，因为较大的元素是唯一可以有意义地增加贡献而不被支配的元素。 
4. 从最大到最小扫描值，维护代表迄今为止形成的最佳链的运行最佳结构。 每个新元素要么启动一个新链，要么附加到现有的最佳端点。 
5. 当附加一个新元素时，计算它作为新邻接的贡献量。 由于它将与先前选择的元素配对，因此其贡献由较大的端点值决定，该端点值已在当前结构中固定。 
6. 贪婪地积累贡献，始终确保我们以保留最大对贡献的方式扩展链条。 

### 为什么它有效

 关键的不变量是，在递减扫描中的任何一点，构造的子序列都对应于一个链，其中每个新添加的元素都是下一个最佳可能的候选者，以最大化未来最大对贡献。 由于 max(x, y) 由较大端点主导，因此按降序放置元素可确保每个元素要么作为主导端点贡献其全部价值，要么在不损失潜在贡献的情况下被吸收。 任何与此顺序的偏差都会迫使更大的元素稍后出现，这会减少较早对的贡献，而这在链中后期无法得到补偿。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    a.sort(reverse=True)
    
    total = 0
    for i in range(1, n):
        if a[i] > 0:
            total += a[i-1]
        else:
            total += max(a[i-1], a[i])
            break
    
    print(max(0, total))

if __name__ == "__main__":
    solve()
```该实现首先按降序对数组进行排序，这对应于构建一个最佳链，其中较大的值放在前面。 然后，循环按此排序顺序累积相邻元素之间的贡献。 正值的处理方式是始终贡献前一个（较大的）元素，因为与较小或相等的值配对仍然保留该最大值。 一旦出现非正值，该结构就不再保证从延伸链中获得收益，因此该过程在考虑到最终可能的对后停止。 

最终答案被限制为零，因为始终允许不选择任何元素并产生零分，这比任何负面构造都要好。

 ## 边缘情况

 For a single-element input like`[5]`，算法排序为`[5]`并且不执行配对形成，产生 0。这与定义匹配，因为长度为 1 的子序列中不存在邻接。 

对于像这样的全负输入`[-3, -2, -1]`, 排序产量`[-1, -2, -3]`。 第一对贡献`-1`，第二个贡献`-2`，运行总和变为负数，之后取零更好。 最终钳位确保输出为 0。 

对于混合输入，例如`[10, -5, 7]`，排序给出`[10, 7, -5]`。 第一对贡献 10，第二对贡献 7，结果是 17。这显示了主导元素如何控制结构，以及一旦排序固定，负面元素如何没有机会降低早期收益。
