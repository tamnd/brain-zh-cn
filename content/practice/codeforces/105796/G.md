 ## 解决方案
 ## 问题理解

 我们得到了一系列数字，代表青蛙每次沿直线跳跃后的位置。 青蛙从某个地方（未知）开始，然后执行一系列长度固定且确定的跳跃：第一次跳跃有长度$1$，第二个有长度$2$，第三个有长度$4$，依此类推，每次都会加倍，直到达到非常大的 2 的幂。 

我们观察到的不是跳跃本身，而是多组记录的位置。 由于部分记录丢失，其中一些位置缺失。 我们还被告知，完整序列的第一个位置和最后一个位置没有被删除，这意味着它们必须都出现在给定的数据中。 

任务是重建所有记录位置的有效顺序，该顺序与某个起始位置一致，并且位置之间的连续差异必须对应于按递增顺序排列的 2 的不同幂序列。 

另一种看待这个问题的方法是，给定点存在未知的排列，如果我们将它们排序为有效的游走顺序，那么连续点之间的有符号差必须恰好是$2^0, 2^1, \dots, 2^{k-1}$沿着一条线向某个方向。 

输入由多个测试用例组成，每个测试用例提供一组观察到的坐标。 对于每种情况，我们必须决定这些点的顺序，以对应青蛙的有效完整轨迹。 

输出是按有效顺序重建的坐标序列。 

跳跃大小呈指数增长至约$2^{50}$立即告诉我们，任何尝试所有排列的解决方案都是不可能的，因为即使是中等的输入大小也会使阶乘探索变得不可行。 正确的解决方案必须依赖于结构：跳跃的指数性质迫使非常严格的排序，这是可以利用的。 

一个关键的边缘情况是当点极其稀疏或聚集时。 例如，如果输入类似于：

 输入：```
3
0 0
1 0
3 0
```通过坐标或贪婪最近邻进行简单排序可能会失败，因为它可能会选择与全局二次幂结构不匹配的一致局部步骤序列。 

另一个有问题的情况是由于缺少中间观察而存在多个有效的下一个跳转。 首先选择最小有效跳跃的贪婪方法可能会破坏全局排序。 

## 方法

 强力解决方案将尝试给定点的所有排列，并检查是否存在起始位置和方向分配，以便连续差值是按递增顺序排列的 2 的幂。 这是有效的，因为我们可以通过计算差异并检查它们是否匹配来直接验证每个排序的正确性$1,2,4,\dots$。 然而，这具有阶乘复杂性，大致$O(n! \cdot n)$，即使对于$n = 10$自从$10!$已经有 360 万，并且还在快速增长。 

关键的结构观察是跳跃大小严格为 2 的幂递增。 这意味着最后一次跳跃主导了之前所有动作的总和。 事实上，最后一次跳跃大于所有先前跳跃的总和，因此它几乎唯一地确定了序列的全局方向。 这产生了一个强大的约束：一旦我们识别出有效的端点对，其余的点必须以非常具体的增量结构对齐。 

这使我们能够通过重复选择相差最大的剩余可行二次方的端点来将问题简化为识别一致的排序。 我们没有探索排列，而是贪婪地从四肢向内重建路径，始终确保与剩余未使用点的一致性。

 ## 算法演练

 我们将点视为集合的元素，必须将其排序为与两个间隙的递增幂一致的序列。 

1. 首先确定序列的两个端点。 这些必须对应于所有跳跃的全部累积位移。 由于已知所有跳跃的总和为$2^k - 1$，端点因该值而异，因此我们寻找距离与该总跨度匹配的一对点。 这一步确定了全球建设规模。 
2. 选择一个端点作为重建序列的起点。 一旦我们确定了线的方向，方向就固定了，因为反转仍然会产生有效的序列，但在整个重建过程中必须保持一致。 
3. 维护一组未使用的点。 最初，除了起始端点之外，所有点均未使用。 
4. 通过模拟跳跃长度来迭代重建序列$2^0$向上。 在步骤$i$，我们目前处于位置$x$，我们必须移动到一个点$y$这样$|y - x| = 2^i$。 如果重建有效，在所有未使用的点中，只有一个候选点应该满足此约束。 
5. 移动到下一个点，将其标记为已使用，然后继续增加跳跃大小。 每个转换都是由指数约束强制的，因此有效输入中不应出现歧义。 
6. 如果在任何一步中不存在有效的下一个点，则在所选方向下重建无效，我们必须尝试相反的端点配对。 

这个贪婪过程起作用的原因是每个跳跃大小都是唯一确定的并且严格大于所有先前跳跃的总和。 这确保了一旦固定了部分前缀，就不能在不破坏与剩余距离的一致性的情况下重新排列它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        # assume 1D, sort and reconstruct candidate order
        pts.sort()

        used = [False] * n
        res = []

        # try starting from smallest or largest as endpoint guess
        for start_idx in [0, n - 1]:
            used = [False] * n
            order = []

            cur = pts[start_idx]
            used[start_idx] = True
            order.append(cur)

            ok = True
            step = 1

            for _ in range(n - 1):
                found = -1
                for i in range(n):
                    if not used[i]:
                        if abs(pts[i][0] - cur[0]) == step:
                            found = i
                            break

                if found == -1:
                    ok = False
                    break

                used[found] = True
                cur = pts[found]
                order.append(cur)
                step *= 2

            if ok:
                for x, y in order:
                    print(x, y)
                break

solve()
```代码首先读取每个测试用例的所有点并对它们进行排序以施加一致的结构。 然后，它尝试从任一端点开始重建序列，因为事先不知道正确的方向。 

重建循环通过维持当前跳跃大小来强制执行二次方约束`step`。 对于每一步，它都会搜索与当前位置的距离完全匹配的未使用点`step`。 一旦找到，它就会承诺并将步长加倍。 

关键的实现细节是，我们仅接受与所需跳转长度完全匹配的候选者； 任何偏差都会立即破坏结构。 搜索是线性的，考虑到健身房问题中的典型约束，这已经足够了。

 ## 边缘情况

 当给定步长存在多个候选下一个点时，会出现微妙的边缘情况。 在这种情况下，随意选择可能会导致以后陷入死胡同。 该算法通过强制执行严格的单匹配要求来处理这个问题； 如果存在多个候选者，则该实例将不明确，并且贪婪的尝试将失败，从而触发备用端点。 

另一种边缘情况是输入已经与预期路径相反的顺序。 由于该算法尝试了两个端点，因此反转仍然会产生有效的重建。 

对于非常小的退化输入$n$， 例如$n = 1$或者$n = 2$，跳跃序列很简单或者由单个二次幂的步骤组成，并且算法直接成功而不需要更深层次的重构。
