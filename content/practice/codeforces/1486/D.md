 ## 解决方案
 ## 问题理解

 我们被要求找到长度至少为给定数组的所有连续子数组中最大可能的中位数$k$。 换句话说，从输入数组$a$长度$n$，我们必须考虑每一段长度$k$或更长时间，计算该段的中位数，并返回这些中位数的最大值。 大小数组的中位数$m$是位置上的元素$\lfloor (m + 1) / 2 \rfloor$如果数组已排序。 

约束表明$n$可以大到$2 \cdot 10^5$。 显式检查所有子数组的简单解决方案大约需要$O(n^2)$操作，这将取决于$4 \cdot 10^{10}$最坏情况下的操作。 这远远超出了 2 秒的时间限制，因此我们需要一种大致线性或$O(n \log n)$最多。 数组元素的边界为$1$到$n$，这暗示了基于值的处理的可能性，而不是重复对子数组进行完全排序。 

非明显的边缘情况包括多个元素相等的子数组，或者子数组中出现的最大中位数长于$k$。 例如，对于$n = 5$,$k = 3$， 和$a = [1, 2, 2, 2, 1]$，子数组$[2, 2, 2]$中位数为 2，以及更长的子数组，例如$[1, 2, 2, 2]$也有中位数 2。粗心的方法只是从第一个 k 长度子数组中选取中位数，可能会错过真正的最大值。 

当所有元素都相等时，会发生另一种微妙的情况。 任何子数组都将具有相同的中位数，因此最大中位数通常就是该元素。 

## 方法

 蛮力方法是迭代所有长度至少为$k$，对每个子数组进行排序，并取中位数。 这种方法是正确的，因为它确实计算了所有子数组的中位数，但最坏情况的复杂度是$O(n^3 \log n)$如果我们考虑所有子数组大小和排序，这对于$n$最多$2 \cdot 10^5$。 

有效解决方案的关键见解是认识到我们不需要精确的排序顺序来知道候选中值是否$m$是可能的。 对于长度为的子数组$l \ge k$至少有中位数$m$，其一半以上的元素必须是$\ge m$。 这相当于将元素标记为+1，如果$\ge m$否则-1，然后检查是否存在至少长度的子数组$k$其累计和为正。 这将问题转化为最大子数组和问题的变体。 

通过这种转换，我们可以对候选中位数执行二分搜索。 由于元素的边界在 1 和$n$, 最多有$n$不同的候选人。 对于每个候选中位数，我们使用前缀和和滑动窗口来有效检查长度是否至少为$k$存在足够大的元素以使中位数至少为该候选者。 这给出了总体$O(n \log n)$解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3 \log n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对 1 到 1 之间的候选中值初始化二分搜索$n$。 每位候选人$m$代表我们正在测试的中位数。 
2. 对于给定的候选人$m$，变换数组$a$到一个数组中$b$在哪里$b[i] = 1$如果$a[i] \ge m$， 和$-1$否则。 这使我们能够跟踪子数组是否有足够大的元素。 
3. 计算前缀和$s[i] = b[0] + b[1] + \dots + b[i-1]$。 前缀和差$s[r] - s[l]$给出子数组中大元素减去小元素的净计数$a[l..r-1]$。 
4. 检查子数组的长度是否至少为$k$至少存在中位数$m$, 迭代$r = k$到$n$并维持最小前缀和$min\_prefix = \min(s[0..r-k])$。 如果$s[r] - min\_prefix > 0$，那么子数组结束于$r-1$+1 的数量多于 -1 的数量，因此中位数至少为$m$。 
5、如果存在这样的子数组，则候选中位数可行； 否则就不是。 相应地调整二分搜索范围，直到找到最大的可行中位数。 

为什么它有效：保持的不变量是任何具有超过一半元素的子数组$\ge m$对应于变换后的前缀和的正差。 二分查找确保最大$m$找到，并且前缀和检查保证至少长度的子数组的正确性$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_median(n, k, a):
    low, high = 1, n
    ans = 1
    while low <= high:
        mid = (low + high) // 2
        b = [1 if x >= mid else -1 for x in a]
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i+1] = prefix[i] + b[i]
        min_prefix = 0
        found = False
        for r in range(k, n+1):
            min_prefix = min(min_prefix, prefix[r-k])
            if prefix[r] - min_prefix > 0:
                found = True
                break
        if found:
            ans = mid
            low = mid + 1
        else:
            high = mid - 1
    return ans

if __name__ == "__main__":
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print(max_median(n, k, a))
```该代码首先对可能的中值执行二分搜索。 对于每个候选者，它将数组转换为 +1/-1 值并计算前缀和。 至少尺寸的滑动窗口$k$确保我们有效地检查是否存在有效的子数组。 更新中`min_prefix`是微妙的； 它必须始终表示从开始到`r-k`至少捕获所有长度的子数组$k$。
