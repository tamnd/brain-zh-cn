 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中，二维网格上都有一组点，代表房屋。 目标是为新建筑选择一个整数坐标，使得从该点到所有房屋的曼哈顿距离之和尽可能小。 我们需要的不是位置本身，而是达到这个最小可能总距离的不同整数网格点的数量。 

距离模型清楚地分为水平和垂直部分。 从候选点开始的总成本$(x, y)$是所有房屋沿 x 方向的绝对差值之和加上沿 y 方向的绝对差值之和。 这种可分离性是关键的结构属性：x 中的最优选择不依赖于 y，反之亦然。 

总的限制条件很小，$n$所有测试用例最多 1000 个。这立即告诉我们，即使$O(n^2)$或者$O(n \log n)$每个测试用例都很好。 然而，隐藏的挑战不是性能而是推理：答案不是单个点而是所有最优点的计数，这需要理解 L1 距离和的全套最小化器。 

一种天真的误解是认为只有一个最佳位置，通常是某个“中心”。 在坐标聚集或数量偶数的情况下，这种方法会失败，产生最优解的区间而不是单个点。 

例如，如果所有房屋都位于$(0,0)$，每个点都会增加距离，所以只有$(0,0)$是有效的。 但如果房屋位于网格矩形上，则许多内部点共享相同的最小总和。 

另一个常见的陷阱是试图独立对待 x 和 y，但却忘记了最终答案是有效 x 选择和有效 y 选择的乘积。 混合它们或联合重新计算会导致多算或少算。 

## 方法

 暴力方法会尝试包含所有房屋的边界框中的每个整数点。 对于每位候选人$(x, y)$，我们计算到所有点的总曼哈顿距离并跟踪最小值。 最后，我们计算有多少点达到了该最小值。 

这是正确的，因为它直接评估定义。 问题是比例：坐标达到$10^9$，因此边界框可能很大。 即使我们限制房屋之间的最小/最大 x 和 y，我们仍然有最多$10^9 \times 10^9$最坏情况下的候选点。 这在计算上是不可能的。 

关键的观察结果是曼哈顿距离分解为独立的一维问题。 总成本变为：$$\sum |x - x_i| + \sum |y - y_i|$$所以最小化超过$(x, y)$相当于分别最小化 x 和 y。 任何最佳解决方案都必须使用最小化的 x 坐标$\sum |x - x_i|$，对于 y 也是如此。 

在一维中，绝对偏差最小化器的结构是众所周知的。 如果我们对值进行排序，则最小值会出现在中位数处。 更准确地说，对于偶数个点，两个中间元素之间的间隔中的每个值都是最优的。 对于奇数，只有中间的元素是最优的。 由于我们只关心整数坐标，因此我们计算有多少个整数位于该最佳区间内。 

因此，问题简化为求出 x 坐标中值区间中整数 x 值的数量，乘以 y 坐标中值区间中整数 y 值的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解网格 |$O(R^2 \cdot n)$|$O(1)$| 太慢了|
 | 排序+中值区间 |$O(n \log n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 将所有x坐标提取到一个数组中并排序。 需要排序以暴露绝对偏差的中值结构。 
2. 将所有 y 坐标提取到另一个数组中，并以相同的理由对其进行排序。 
3. 对于 x 坐标，确定最佳间隔：

 - 如果n是奇数，则最优x固定在中间元素。 
- 如果 n 为偶数，则两个中间元素（含）之间的任何 x 都是最佳的。 
4. 计算此区间内整数 x 值的数量。 这只是上中值边界和下中值边界之差加一。 
5. 对 y 坐标重复相同的计算。 
6. 将有效 x 位置的数量乘以有效 y 位置的数量以获得最终答案。 

### 为什么它有效

 曼哈顿距离目标分为两个独立的凸一维问题。 每个一维绝对偏差之和恰好在中值区间上最小化。 由于 x 和 y 之间不存在交互项，因此每个最优解都是通过独立选择任意最优 x 和任意最优 y 形成的。 这会创建最佳集合的笛卡尔积，并且将它们干净地进行因式分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_1d_opt(vals):
    vals.sort()
    n = len(vals)
    if n % 2 == 1:
        return 1
    left = vals[n // 2 - 1]
    right = vals[n // 2]
    return right - left + 1

t = int(input())
for _ in range(t):
    n = int(input())
    xs = []
    ys = []
    for _ in range(n):
        x, y = map(int, input().split())
        xs.append(x)
        ys.append(y)
    print(count_1d_opt(xs) * count_1d_opt(ys))
```实现的核心是`count_1d_opt`功能。 它编码了这样一个事实：一维中的一组最佳点要么是单个中值，要么是两个中间值之间的完整整数段。 

直接访问中值结构需要排序。 偶数情况公式`right - left + 1`计算有效区间内的整数格点，而不仅仅是端点。 

最终的乘法反映了轴的独立性，这是核心的结构简化。

 ## 边缘情况

 一种极端情况是所有房屋都重合在同一点。 在这种情况下，两个坐标数组都是恒定的。 排序会产生相同的中间元素，并且偶数情况公式会折叠为单个有效坐标。 该算法正确返回 1，因为相同的中间值之间的差为零。 

当 n 为偶数且中值间隔不平凡时，会出现另一种边缘情况。 例如，x 值 [0, 10] 生成从 0 到 10（含）的有效范围。 该算法通过计算捕获这一点`right - left + 1`，它正确计算间隔中的所有整数位置，而不仅仅是端点。
