 ## 解决方案
 ## 问题理解

 我们有两组敌舰，全部位于两条垂直线上：一组固定在$x=-100$，另一个在$x=100$。 每艘船都有一个整数$y$-坐标，多艘船可以共享同一个$y$。 

我们可以在垂直线上的任何地方放置两艘友方船只$x=0$，选择他们的$y$- 自由坐标（不一定是整数）。 每艘敌方舰艇同时发射两束激光：一束射向第一艘友军舰艇，一束射向第二艘。 每束激光射线都是一条笔直的无限半线，从敌方船只开始，穿过选定的友方位置，继续超越它。 

如果任何激光射线穿过船只的位置，船只就会被摧毁。 任务是选择两个位置$x=0$从而使被摧毁的敌舰总数最大化。 

限制很小，每方最多 60 艘船。 这立即排除了诸如扫除所有几何配置或尝试持续优化之类的任何事情。 如果不利用结构，任何试图模拟任意位置的光线相交的解决方案都会很快变得过于复杂。 

一个关键的微妙之处在于，破坏并不局限于某一方。 左侧的船只可以通过与选定点的共线间接摧毁右侧的船只，反之亦然。 两侧之间的这种耦合是天真的计数往往会被打破的地方。 

一些边缘案例暴露了典型的错误。 

如果一侧的所有船只共享相同的$y$，我们将两艘友军船放在同一位置$y$，则每条射线都是水平的，从而最大化覆盖范围。 独立处理每一侧的简单解决方案可能会忽略两个选定点通过同一组射线相互作用的情况。 

当对称配置创建重叠线时，会发生另一种失败情况。 如果两艘不同的左船产生的射线击中同一艘右船，则该右船仍必须仅计数一次。 除非仔细处理联合逻辑，否则任何每艘船的贪婪计数都会高估结果。 

最后，如果两艘友方舰船位于同一位置$y$，问题退化为单点配置。 假设两个位置不同的解决方案将错过这种最佳情况。 

## 方法

 暴力解释首先尝试两艘船的所有可能位置$x=0$。 自从$y$是真实的，这是连续的，但几何形状将有意义的事件限制为特殊值：仅当三个点共线时，右船才会被左船的射线击中，这会强制选择$y$满足以下形式的线性方程的值$$y = \frac{y_i + y_j}{2}.$$这表明只有有限多个候选位置很重要，但即使在离散化候选位置之后，尝试所有位置对并从头开始重新计算几何交集也会导致$O(C^2 \cdot n \cdot m)$方法，只有经过大量优化才可以接受。 

关键的结构观察是，每个选定的位置独立地确定_对面的一组被摧毁的船只_。 对于固定位置$a$，每艘左船在$(-100, y_i)$要么不执行任何操作，要么定义一条恰好击中右侧的唯一线$y$-坐标，即$y_j = 2a - y_i$。 这意味着每个候选位置都会产生对面被毁船只的确定性子集，独立于其他船只。 

这减少了选择两名候选人的问题$a$和$b$，其中每个人都贡献一组对方被摧毁的船只，我们采取联合。 同样的推理对称地适用。 

一旦每个候选位置减少为两个位掩码（从左到右和从右到左效果），通过检查所有对并通过位运算取并来获得最终答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力连续几何 | 无限/未定义 | O(1) | O(1) | 无法使用 |
 | 通过重新计算离散化所有对 | O(C²·n·m) | O(1) | O(1) | 太慢了 |
 | 每个候选者预先计算的位掩码 | O(C²·(n + m)) | O(C²·(n + m)) | O(C·(n + m)) | O(C·(n + m)) | 已接受 |

 ## 算法演练

 我们将问题压缩为有限的候选集$y$- 友军船只的坐标。 这些包括所有输入$y$- 值和所有中点$(y_i + y_j)/2$这可能是由共线性条件引起的。 

一旦确定了候选人，我们就会预先计算每个候选人的行为方式。 

1. 建立候选人职位列表。 这些包括所有原创$y$- 两侧的坐标和所有值$(y_i + y_j)/2$可以显示为有效的几何对齐。 这确保了在搜索空间中呈现任何最佳放置。 
2. 对于每位候选人$c$，使用左侧船只计算其对右侧的影响。 对于每艘左船$y_i$，计算隐含的右侧击球位置$y_j = 2c - y_i$。 如果该值存在于右侧船舶中，则在候选者的位掩码中将其标记为已损坏$c$。 这将多对一映射压缩为单个联合结构。 
3. 同样，计算每个候选者$c$它在左侧使用右侧船舶的效果，再次构建位掩码。 
4. 现在考虑每对有序的候选者$(a, b)$。 通过取对应于的两个位掩码的并集来获得被摧毁的右侧船只的总数$a$和$b$。 左侧也进行同样的操作。 
5. 最终答案是所有候选对中被摧毁的左侧和右侧船只之和的最大值。 

### 为什么它有效

 每个候选位置都会产生确定性的几何约束：每个选定点左船最多可以击中一艘右船，并且该关系完全由方程捕获$y_j = 2c - y_i$。 这意味着候选者的所有影响都会分解为离散的敌人坐标集上的集合成员资格问题。 

因为破坏被定义为存在至少一条穿过船的射线，所以组合两个位置恰好对应于取这些集合的并集。 除了最终位掩码中的成员身份之外，不需要跟踪各个左船之间的交互，这可以保留正确性而不会丢失信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    L = list(map(int, input().split()))
    R = list(map(int, input().split()))

    # compress right/left y-values into indices
    R_idx = {y: i for i, y in enumerate(R)}
    L_idx = {y: i for i, y in enumerate(L)}

    # candidate set: all original y-values + midpoints
    cand = set(L + R)
    for y1 in L:
        for y2 in L:
            cand.add((y1 + y2) / 2)
    for y1 in R:
        for y2 in R:
            cand.add((y1 + y2) / 2)

    cand = list(cand)

    # bitmasks
    RL = [0] * len(cand)  # left -> right
    LR = [0] * len(cand)  # right -> left

    # precompute effects
    for ci, c in enumerate(cand):
        # left to right
        for y in L:
            y_r = 2 * c - y
            if y_r in R_idx:
                RL[ci] |= 1 << R_idx[y_r]

        # right to left
        for y in R:
            y_l = 2 * c - y
            if y_l in L_idx:
                LR[ci] |= 1 << L_idx[y_l]

    best = 0
    C = len(cand)

    for i in range(C):
        for j in range(i, C):
            right_mask = RL[i] | RL[j]
            left_mask = LR[i] | LR[j]
            best = max(best, right_mask.bit_count() + left_mask.bit_count())

    print(best)

if __name__ == "__main__":
    solve()
```该实现首先将几何交互压缩为位掩码，以便每个候选位置的行为就像预先计算的“破坏轮廓”。 候选者上的嵌套循环是可以接受的，因为候选者数量在约束下仍然很小。 

最微妙的部分是中点结构。 如果没有它，一些最佳位置将永远不会被测试，因为最佳对齐通常恰好在满足从左到右或从右到左反射条件时发生。 

使用位掩码并集而不是重新计算交集，因为破坏纯粹是基于设置的：无论有多少光线穿过船，船要么被击中，要么未被击中。

 如果我们选择 2 处的两个候选者，则两个掩码相同，因此 union 不会添加新元素。

 ## 边缘情况

 当所有船只都位于同一位置时，就会发生退化情况$y$。 在这种情况下，每个候选者都会产生相同的掩模，并且任何对选择都会产生相同的结果。 该算法自然地处理这个问题，因为按位或不会引入人工重复。 

当最佳对齐需要输入中不存在的中点时，会出现另一种情况。 例如，如果左船位于 0 和 10，右船位于 5，则有效候选者为$y=2.5$。 中点生成步骤确保包含该值，从而检测到相应的共线性。 

最后一个微妙的情况是两艘选择的船都是相同的。 该算法不强制唯一性，pair 循环自然包括$i=j$，它正确地模拟了仅使用一个有效位置的情况。
