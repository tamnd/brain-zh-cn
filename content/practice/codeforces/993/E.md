 ## 解决方案
 ## 问题理解

 我们给定一个数组和一个阈值`x`。 对于每个可能的整数`k`从`0`到`n`，我们需要计算有多少个子数组恰好有`k`元素严格小于`x`。 每个子数组恰好贡献一个`k`，取决于有多少元素低于阈值。 

思考任务的另一种方法是我们滑过所有可能的部分`[l, r]`，对于每个段，我们计算一个值：该段中小于的元素数`x`。 输出是该值在所有子数组上的频率分布。 

约束条件`n ≤ 2 · 10^5`立即排除任何显式枚举所有子数组的解决方案。 有大约`n(n+1)/2`子数组，其顺序为`2 · 10^10`在最坏的情况下。 即使计算每个子阵列一个计数器也将远远超出 2 秒的限制。 

问题的结构表明我们实际上并不关心大于或等于的元素的值`x`，除了它们如何分区或移位计数。 这是一个强烈的暗示，数组可以被压缩成一个二进制序列，其中每个元素都变成`1`如果`a[i] < x`和`0`否则。 然后问题就简化为按总和对子数组进行计数。 

当所有元素都大于或等于时，会出现微妙的边缘情况`x`。 在这种情况下，每个子数组都有`k = 0`，所以答案应该是`n(n+1)/2`为了`k = 0`否则为零。 一种简单的实现，假设至少一个元素小于`x`在构建频率结构时可能会错误地跳过这种统一情况。 

另一个边缘情况是当所有元素都小于`x`。 那么每个子数组都有贡献`k = length of subarray`，所以分布是三角形的：恰好`n - k + 1`每个子数组`k`。 

## 方法

 暴力方法会枚举每个子数组`[l, r]`，计算有多少个元素小于`x`通过扫描该段，并增加该值的计数器`k`。 这是正确的，因为它直接遵循定义。 然而，每个子阵列的成本`O(n)`最坏情况下的时间，导致`O(n^3)`如果简单地实现的话，总的复杂性，或者`O(n^2)`即使使用前缀和进行计数，因为我们仍然枚举所有子数组。 

关键的观察是，将数组转换为二进制数组后，其中`b[i] = 1`如果`a[i] < x`和`0`否则，每个子数组的值只是一个段上的总和。 因此，任务就变成了计算有多少个子数组具有每个可能的和。 

这是一个经典的卷积问题。 如果我们定义一个数组`f`在哪里`f[i] = 1`对于每个前缀总和值，则具有总和的子数组的数量`k`是前缀和对的数量`(i, j)`这样`pref[j] - pref[i] = k`。 这可以重写为前缀和的频率数组与其自身的反转版本的卷积。 

一旦表示为卷积，我们就可以使用基于 FFT 的多项式乘法同时计算所有频率`O(n log n)`时间。 前缀和的大小是`n+1`，所以我们大致构建一个长度的数组`2n`以安全地容纳卷积结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(1) | O(1) | 太慢了 |
 | 前缀枚举| O(n²) | O(n) | 太慢了 |
 | FFT 卷积 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将输入数组转换为二进制数组，其中每个元素是`1`如果它严格小于`x`， 否则`0`。 这种转换准确地保留了我们关心的每个子数组的数量。 
2. 在此二进制数组上构建前缀和。 每个前缀和代表小于多少个元素`x`存在到该索引。 
3.构建频率数组`cnt`在哪里`cnt[v]`是前缀和值的次数`v`发生。 前缀和的范围为`0`到`n`。 
4. 将问题解释为计算前缀和对`(i, j)`这样`pref[j] - pref[i] = k`。 每个这样的对对应于一个子数组，其恰好`k`元素小于`x`。 
5. 将这个计数重新表述为卷积：如果我们反转一个副本`cnt`并将其与原始数组进行卷积，得到的数组给出了前缀和之间所有差异的计数。 
6. 使用基于 FFT 的多项式乘法来有效地计算该卷积`O(n log n)`时间。 
7. 提取所有结果`k`从`0`到`n`，它直接对应于子数组计数`k`元素小于`x`。 

### 为什么它有效

 每个子数组`[l, r]`唯一对应于一对前缀索引`(l-1, r)`。 元素个数小于`x`在该子数组中是`pref[r] - pref[l-1]`。 因此，每个有效子数组恰好贡献一对有序的前缀和，其差等于其值`k`，并且每一对都定义一个子数组。 这种一对一的对应关系确保了计算前缀和差异等同于计算子数组。 

卷积步骤只不过是同时聚合所有前缀和上的所有此类成对差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import numpy as np

def fft_convolve(a, b):
    fa = np.fft.rfft(a)
    fb = np.fft.rfft(b)
    fc = fa * fb
    res = np.fft.irfft(fc)
    return np.rint(res).astype(np.int64)

def solve():
    n, x = map(int, input().split())
    arr = list(map(int, input().split()))

    b = [1 if v < x else 0 for v in arr]

    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + b[i]

    cnt = [0] * (n + 1)
    for v in pref:
        cnt[v] += 1

    rev = cnt[::-1]

    conv = fft_convolve(cnt, rev)

    # conv index shift: we want differences pref[j] - pref[i]
    # reverse convolution gives centered differences at offset n
    offset = n
    ans = [0] * (n + 1)

    for k in range(n + 1):
        ans[k] = int(conv[offset + k])

    print(*ans)

if __name__ == "__main__":
    solve()
```### 代码解释

 二元变换隔离了每个元素的唯一相关特征。 然后，前缀和将所有子数组计数编码为两个前缀状态之间的差异。 

频率阵列`cnt`计算每个前缀和出现的频率，这很重要，因为多个索引可以共享相同的前缀和值。 反转该数组允许卷积自然地计算前缀值之间的所有差异。 

FFT 卷积计算所有成对乘积的总和，索引移位对齐卷积输出，以便索引`n + k`对应差异`k`。 

解释浮点 FFT 输出时必须小心。 舍入到最接近的整数是必要的，因为数值误差会在卷积结果中累积。

 ## 边缘情况

 当所有元素都大于或等于`x`，二进制数组变为全零。 前缀和恒定为零，因此`cnt[0] = n+1`。 然后卷积产生一个非零值`k = 0`，等于子数组的数量`n(n+1)/2`，符合预期结果。 

当所有元素都小于`x`，二进制数组变为全一。 前缀和形成严格递增的序列，并且卷积将计数均匀地分布在所有可能的差异上，产生三角形结构。 每个`k`准确接收`n-k+1`贡献，与产生该总和的长度子数组的数量一致。
