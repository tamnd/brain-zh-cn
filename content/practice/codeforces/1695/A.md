 ## 解决方案
 ## 问题理解

 我们得到一个包含不同整数的网格。 迈克尔选择尺寸`h × w`，然后 Joe 秘密选择任意大小完全相同的子矩形。 在查看选择了哪个矩形之前，Michael 必须说出 Joe 选择的矩形内的最大值。 

由于所有值都是不同的，因此整个板具有唯一的全局最大值。 迈克尔只有在一切可能的情况下才能保证胜利`h × w`子矩形包含相同的单元格。 在这种情况下，无论 Joe 如何选择，所选矩形内的最大值始终是整个棋盘的全局最大值。 

任务是找到尽可能小的区域`h · w`为此，这种保证是可能的。 

尺寸满足`n, m ≤ 40`，很小。 即使是尝试所有可能的矩形尺寸的算法也很容易负担得起。 只有`40 × 40 = 1600`可能的`(h, w)`每个测试用例成对，因此直接的数学解决方案就足够了。 

一个微妙的点是迈克尔不需要知道乔选择了哪个子矩形。 他只需要一个保证在每一个可能的选择中都是最大的数字。 因为所有值都是不同的，所以唯一的候选者是整个董事会的全局最大值。 

考虑这个网格：```
1 2
3 4
```最大值`4`位于右下角。 选择`h = 1, w = 1`失败，因为 Joe 可以选择包含以下内容的单元格`1`，其最大值不是`4`。 

正确答案是`4`，通过选择整个板获得。 只检查某个矩形是否包含最大值的粗心方法会错误地返回`1`。 

另一个容易犯的错误是忘记最大值可能位于边缘。```
5 1 2
3 4 0
```最大值位于位置`(1,1)`。 答案不是由到中心的距离决定的。 矩形尺寸必须足够大，以便每个可能的位置都包含左上角。 

## 方法

 蛮力观点首先识别包含全局最大值的单元格。 假设单元格位于行`r`和列`c`使用从 1 开始的索引。 

对于每对`(h, w)`，我们可以枚举所有可能的`h × w`子矩形并检查每个子矩形是否包含`(r, c)`。 如果是的话，迈克尔会以这个选择获胜。 然后我们保留最小面积。 

这是正确的，因为当每个合法矩形包含全局最大单元格时，迈克尔就获胜。 问题是对于每种尺寸，我们都会检查许多矩形位置。 尽管约束足够小，仍然可以通过，但它隐藏了问题的真实结构。 

关键的观察是我们根本不需要枚举矩形。 

对于固定高度`h`，矩形的起始行可以是以下任意值`1`到`n - h + 1`。 

对于每个包含行的此类矩形`r`，两个条件必须同时成立：```
start_row ≤ r
start_row + h - 1 ≥ r
```限制性最强的起始行是可能的最小行和可能的最大行。 

最小的开始是`1`，这需要：```
1 + h - 1 ≥ r
h ≥ r
```最大的开始是`n - h + 1`，这需要：```
n - h + 1 ≤ r
h ≥ n - r + 1
```将它们结合起来可以得到：```
h ≥ max(r, n - r + 1)
```对于列的推理完全相同：```
w ≥ max(c, m - c + 1)
```为了最小化面积，我们选择最小的有效高度和宽度：```
h = max(r, n - r + 1)
w = max(c, m - c + 1)
```答案很简单`h · w`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²m²) | O(1) | O(1) | 概念上太慢，没有必要 |
 | 最佳 | O(纳米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 扫描网格并找到包含全局最大值的单元格。 
2. 设其位置为`(r, c)`在基于 1 的索引中。 
3. 计算强制每个有效矩形包含行的最小高度`r`：```
h = max(r, n - r + 1)
```这是最顶部和最底部放置都不能避免行的最小高度`r`。 
4. 计算强制每个有效矩形包含列的最小宽度`c`：```
w = max(c, m - c + 1)
```5、输出：```
h × w
```### 为什么它有效

 每个`h × w`矩形包含最大单元格当且仅当每个合法行间隔的长度`h`包含行`r`以及每个长度的合法列间隔`w`包含列`c`。 

满足该性质的最小高度是`max(r, n-r+1)`。 任何较小的高度都允许顶部放置或跳过行的底部放置`r`。 同样的论点也适用于宽度。 

由于高度和宽度是独立的，因此为每个尺寸选择最小有效值可以最小化面积。 每个生成的矩形都包含全局最大单元格，因此其最大值始终相同。 迈克尔总是能正确回答。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    mx = -10**18
    r = c = 0

    for i in range(1, n + 1):
        row = list(map(int, input().split()))
        for j in range(1, m + 1):
            if row[j - 1] > mx:
                mx = row[j - 1]
                r, c = i, j

    h = max(r, n - r + 1)
    w = max(c, m - c + 1)

    print(h * w)
```第一个循环读取网格，同时定位全局最大值。 由于所有值都是不同的，因此最大单元格是唯一的。 

找到自己的位置后`(r, c)`，所需高度和宽度的公式直接来自上面开发的几何参数。 

使用从 1 开始的索引可以简化公式。 数量`n - r + 1`和`m - c + 1`表示到相对边界的距离（包括在内）。 取最大值选择较远的一侧，这决定了矩形必须有多大才变得不可避免。 

除了读取每一行之外，不需要额外的数组。

 ## 边缘情况

 考虑一个最大值位于角落的棋盘：```
1
2 2
10 1
2 3
```最大值位于`(1,1)`。 

该算法计算：```
h = max(1, 2) = 2
w = max(1, 2) = 2
answer = 4
```任何较小的尺寸都将允许矩形完全避开拐角。 需要整个板。 

现在考虑中心最大值：```
1
3 3
1 2 3
4 9 5
6 7 8
```最大值位于`(2,2)`。 

该算法计算：```
h = max(2, 2) = 2
w = max(2, 2) = 2
answer = 4
```每一个`2 × 2`的矩形a`3 × 3`板包含中心单元。 一个常见的错误是假设答案一定是`3 × 3 = 9`，但中心已经成为不可避免的面积`4`。 

最后，考虑单行：```
1
1 5
1 2 10 3 4
```最大值位于列处`3`。 

该算法给出：```
h = 1
w = max(3, 3) = 3
answer = 3
```长度为 5 的行中长度为 3 的每个连续段都包含中间位置。 该公式自然可以处理一维板，没有任何特殊情况。
