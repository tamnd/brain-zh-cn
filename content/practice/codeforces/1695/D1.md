 ## 解决方案
 ## 问题理解

 我们被要求确定唯一标识树中隐藏顶点所需的最小距离查询数。 输入为我们提供了一系列树，每棵树都由其顶点和边定义。 对于每棵树，都有一个隐藏顶点，查询返回从查询顶点到隐藏顶点的最短路径距离。 任务是找到最小的顶点集，以便知道从这些顶点到隐藏顶点的距离始终可以识别它，无论隐藏哪个顶点。 

约束是适度的：每棵树最多有 2000 个顶点，并且所有测试用例的顶点总数不超过 2000。这意味着我们可以负担得起$O(n^2)$算法，但是$O(n^3)$可能会开始变慢。 边缘情况包括具有单个顶点的树（需要零查询）或本质上是直线的树。 在三个节点的直线中，查询中间顶点有时可以通过单个查询唯一地标识隐藏顶点，而查询末端则可能不能。 

## 方法

 简单的方法是将所有可能的顶点子集视为查询候选，模拟所有可能的隐藏顶点，并查看查询子集是否唯一标识隐藏顶点。 这是有效的，因为如果距离顶点子集的距离对于每个可能的隐藏顶点都是唯一的，则该子集就足够了。 然而，这种方法是组合的。 对于 2000 个顶点，迭代所有子集显然是不可能的。 

解锁更简单的解决方案的关键观察来自于树结构。 考虑极端情况：叶节点及其邻居。 如果我们查询一片叶子，任何靠近树中心的顶点都会为某些隐藏顶点生成较短距离的签名。 如果我们选择查询使得树中的每对顶点具有到查询的不同距离向量，则隐藏顶点是唯一可识别的。 在树中，这个问题简化为计算叶子的数量，因为查询叶子可以提供最大的区分能力。 

对于单顶点树，不需要查询。 对于具有中心的树（一个顶点连接到所有其他顶点，如一颗星），在中心进行单个查询就足够了。 对于长于一条边的路径，查询两个端点可确保唯一性。 因此，对于单个顶点，最佳查询数量为 0；如果树具有星形结构，则最佳查询数量为 1；对于更一般的树，最佳查询数量为 2。

 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n \cdot n^2)$|$O(n^2)$| 太慢了|
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，将树结构读入邻接表。 
2. 统计顶点数$n$。 如果$n = 1$，最小查询次数为0，因为只有一个顶点需要识别。 
3. 检查树是否是星形：连接到所有其他顶点的顶点。 如果是这样，则该中心顶点处的一个查询唯一地标识任何隐藏顶点。 
4. 否则，树不是单个顶点或星形，因此两次查询就足够了。 查询树的相反极端处的两个顶点（例如，具有最大距离的两个叶子）可确保到任何隐藏顶点的距离向量是唯一的。 
5. 输出每个测试用例的最小查询数。 

工作原理：在树中，每对顶点都有唯一的路径。 查询两个叶子最大化所有顶点之间的距离差，确保到隐藏顶点的距离向量是唯一的。 没有两个顶点到两个查询的距离相同，因为它们到叶子的路径不同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u - 1].append(v - 1)
            adj[v - 1].append(u - 1)

        if n == 1:
            print(0)
            continue

        max_deg = max(len(neigh) for neigh in adj)
        if max_deg == n - 1:
            print(1)
        else:
            print(2)

if __name__ == "__main__":
    solve()
```我们将每棵树读入邻接表以检查度数。 如果只有一个顶点，则需要零次查询。 如果一个顶点连接到所有其他顶点，则该顶点处的单个查询就足够了。 否则，需要两次查询，因为选择最大距离的两个顶点可确保唯一标识。

 ## 边缘情况

 该算法通过检查来处理单顶点树`n == 1`并打印0。通过计算最大度来检测星形树。 非星形树默认为 2，覆盖路径和一般结构。 这可确保使用最少数量的查询正确分类每个场景。
