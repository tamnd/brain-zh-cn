 ## 解决方案
 ## 问题理解

 我们有一棵以节点 1 为根的树，其中每条边都有一个权重。 对于每个节点，我们可以通过对从节点 1 到该节点的唯一路径上的边权重求和来计算距根的距离。 然后将该距离按模减小$10^5$。 

经过这个预处理后，我们考虑选择任意两个节点$u$和$v$。 对于每一对，我们获取两个根距离，计算它们的按位异或，并记录结果。 任务是确定通过这种方式可以生成多少个不同的 XOR 值，并按排序顺序输出所有这些值。 

因此，一旦知道距根的距离，问题的结构就不再真正与树有关了。 树的存在只是为了生成一组值，每个节点一个，其中每个值都位于范围内$[0, 99999]$。 答案仅取决于这些值的所有成对异或，包括其中的对$u = v$，其贡献始终为 0。 

约束条件$N \le 10^5$意味着我们不能明确地考虑所有对，因为那将是$O(N^2)$，远远超出了可行的限度。 一般来说，即使存储所有成对结果也是不可能的。 然而，这些值严格限制在一个固定的小范围内，这强烈建议采用基于频率或按位变换的方法。 

一个微妙的边缘情况是多个节点共享相同的根距离。 例如，如果两个节点具有相同的距离值$x$，然后选择它们会产生$x \oplus x = 0$，并且在最终的不同集合中只能计算一次。 另一个边缘情况是我们不能假设节点对是有序的或无序的； XOR 是对称的，因此两种解释都会得出同一组结果。 

## 方法

 简单的方法首先使用树的 DFS 或 BFS 遍历来计算每个节点的根距离。 一旦我们有了一个数组$a$尺寸的$N$，其中每个$a[i]$是根距离模数$10^5$，我们迭代所有对$(i, j)$并计算$a[i] \oplus a[j]$，将结果插入到集合中。 这是正确的，因为它直接遵循问题的定义。 

瓶颈是双重循环$N$节点。 这会产生$O(N^2)$配对评估，大约是$10^{10}$在最坏的情况下，操作在一秒钟内就太大了。 

关键的观察是我们不关心哪些节点产生结果，只关心结果是否存在。 这意味着我们正在处理一个集合卷积问题：给定一个频率数组$[0, 2^{17})$，我们想要该集合中两个元素的所有异或组合。 

这正是布尔数组或频率数组上的异或卷积。 正确的工具是快速 Walsh-Hadamard 变换 (FWHT)，它计算 XOR 卷积$O(M \log M)$， 在哪里$M$是值范围之上的下一个 2 的幂。 这里$M = 131072$，这很容易足够快。 

我们构建一个频率数组$f[x]$，表示是否值$x$出现在根距离之中。 然后我们计算异或卷积$g = f * f$， 在哪里$g[z]$告诉我们是否存在一对$(x, y)$这样$x \oplus y = z$。 最终的答案就是所有的指数$z$在哪里$g[z]$是非零的。

 | --- | --- | --- | --- |
 | 暴力配对 |$O(N^2)$|$O(N)$| 太慢了 |
 | FWHT 异或卷积 |$O(M \log M)$|$O(M)$| 已接受 |

 ## 算法演练

 ### 1. 计算根距离

 我们从节点 1 开始遍历树，并通过累积边权重来计算到每个节点的距离。 计算完每个距离后，我们将其模数减少$10^5$因为问题明确定义了该简化形式的值。 

此步骤将树结构转换为简单的值数组，这是与 XOR 过程相关的唯一信息。 

### 2.构建频率数组

 我们分配一个数组$f$尺寸的$2^{17}$（因为值小于$10^5$），并标记$f[a[i]] = 1$对于每个节点值。 

我们只关心存在性，而不关心多重性，因为即使是一次出现也足以形成有效的对。 

### 3. 应用快速 Walsh-Hadamard 变换

 我们将频率数组变换到 FWHT 域。 然后我们逐点平方，这对应于原始域中的异或卷积，最后应用逆变换。 

经过这个过程后，各个索引$z$结果数组中告诉我们是否存在至少一对 XOR 等于的值$z$。 

### 4. 收集结果

 我们迭代所有可能的值并收集卷积结果为正的那些索引。 这些索引是问题所需的不同 XOR 结果。 

### 为什么它有效

 该算法依赖于指标数组上的异或卷积对集合中元素的所有可能的成对异或组合进行计数的事实。 由于每个根距离在计算后都是独立的，因此预处理后树结构不再重要。 FWHT 准确地保留了成对 XOR 存在所需的信息，并且不会引入虚假值。 每个可达的异或对应一对实际的节点，每对节点恰好贡献一个异或值，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def fwht_xor(a, invert=False):
    n = len(a)
    step = 1
    while step < n:
        jump = step * 2
        for i in range(0, n, jump):
            for j in range(step):
                u = a[i + j]
                v = a[i + j + step]
                a[i + j] = u + v
                a[i + j + step] = u - v
        step = jump

    if invert:
        for i in range(n):
            a[i] //= n

def solve():
    n = int(input())
    g = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))

    sys.setrecursionlimit(10**7)

    dist = [0] * (n + 1)
    stack = [1]
    parent = [-1] * (n + 1)

    while stack:
        u = stack.pop()
        for v, w in g[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            dist[v] = (dist[u] + w) % 100000
            stack.append(v)

    M = 1
    while M < 131072:
        M <<= 1

    f = [0] * M
    for i in range(1, n + 1):
        f[dist[i]] = 1

    fwht_xor(f, invert=False)

    for i in range(M):
        f[i] *= f[i]

    fwht_xor(f, invert=True)

    res = [i for i in range(M) if f[i] > 0]
    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```DFS 是迭代实现的，以避免链形树上的递归深度问题。 在遍历期间应用模运算，因此距离立即保持在界限内。 

FWHT 部分执行标准 XOR 变换，对变换后的数组进行平方以计算成对组合，然后应用逆变换。 变换域中的平方是取代变换域的关键步骤$O(N^2)$对枚举。 

最后，我们过滤所有具有正计数的索引以产生不同的 XOR 值。

 ## 边缘情况

 链形树是最重要的结构边缘情况，因为它强调递归深度和累积权重传播。 迭代 DFS 避免了堆栈溢出，同时仍然按顺序正确累积距离。 

第二种边缘情况是当所有节点具有相同的根距离时，这仅产生单个 XOR 结果 0。频率数组正确地将重复项折叠为单个存在，并且卷积仅产生索引 0 作为非零。 

第三种情况是当值分布在整个模数范围内时，它测试 FWHT 数组是否足够大以包含所有可能的 XOR 输出而无需截断。
