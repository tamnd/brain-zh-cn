 ## 解决方案
 ## 问题理解

 我们有一个长方形的公告板和两张固定方向的长方形海报。 亚历克斯总是把他的海报放在第一位。 问题不仅仅是两张海报是否合适，因为根据鲍勃的海报，亚历克斯有两个不同的目标。 

对于第一个计划，Alex 希望以某种方式放置他的海报，从而留下一些位置，让 Bob 可以在不重叠的情况下放置他的海报。 对于第二个计划，Alex 希望放置他的海报，以便 Bob 的每个可能的位置都与其重叠，从而使 Bob 无法放置他的海报。 

输入给出了板的高度和宽度，然后是 Alex 的海报和 Bob 的海报的尺寸。 输出包含两个答案，每个答案对应一个计划。 

尺寸最多为 150，看起来很小，但几何体是连续的，因此不需要直接模拟每个可能的位置。 重要的部分是找到两个轴对齐矩形的结构属性。 在最坏的情况下，尝试每个放置对的解决方案将执行大约 20,000 × 20,000 次检查，这是不必要的。 我们需要恒定时间的几何观察。 

有少数情况很容易处理不当。 如果亚历克斯的海报本身不合适，那么这两个计划都行不通。 例如：```
20 30
21 10
20 30
```输出是：```
No
No
```即使鲍勃的海报适合，亚历克斯也无法启动该过程。 

另一个陷阱是假设两张海报单独适合意味着它们可以共存。 例如：```
50 100
30 20
30 20
```第一个答案是`Yes`因为两张海报可以垂直或水平并排放置。 第二个答案是`No`因为当板子周围有足够的剩余空间时，亚历克斯无法完全阻止鲍勃。 

接触边缘也很重要。 矩形可以共享边界，因此恰好为零的间隙并不是障碍。 

## 方法

 暴力方法会枚举 Alex 海报的每个可能位置，然后检查 Bob 海报的每个可能位置。 由于每个海报的最大位置数约为 20,000 个，因此这会产生约 4 亿次比较。 该方法是正确的，因为它直接对问题进行建模，但忽略了矩形结构。 

对于计划 A，关键的观察结果是两个不重叠的轴对齐矩形之间始终有一条分隔的水平或垂直线。 如果分隔是水平的，则两张海报独立地消耗它们的高度，并且它们的宽度必须配合在一起。 如果分离是垂直的，则情况相反。 这将问题简化为两个简单的检查。 

对于 B 计划，Alex 希望尽量减少海报周围最大的空白区域。 最佳位置是板的中心，因为将海报移向边缘只会增加另一侧的可用空间。 一旦 Alex 居中，Bob 只能适应 Alex 的上方/下方或 Alex 的左侧/右侧。 我们只需要检查剩余的条带是否足够大。 

蛮力之所以有效，是因为它探索了每一个可能的位置，但失败了，因为它重复了相同的几何推理数千次。 对分隔线和最佳居中放置的观察将一切简化为常数时间算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((HW)^2) | O((HW)^2) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 检查 Alex 的海报是否适合公告板。 如果其高度或宽度超过相应的板尺寸，则两个答案都是`No`，因为 Alex 无法放置他的海报。 
2. 对于方案A，测试海报是否可以水平分离。 这要求两张海报在垂直方向上适合，并且在彼此相邻放置时宽度也适合：`ha <= H`,`hb <= H`， 和`wa + wb <= W`。 

还测试垂直分离情况：`wa <= W`,`wb <= W`， 和`ha + hb <= H`。 

如果这两种情况都有效，鲍勃就可以有一席之地。 
3. 对于 B 计划，想象 Alex 将他的海报放在黑板中间。 剩余高度为`H - ha`，剩余宽度为`W - wa`。 最大可能的顶部或底部间隙是剩余高度的一半，最大的左侧或右侧间隙是剩余宽度的一半。 
4. 检查 Bob 是否可以放入剩余的条带之一中。 如果满足以下任一条件，鲍勃就能成功：`hb <= (H - ha) / 2`和`wb <= W`或者：`wb <= (W - wa) / 2`和`hb <= H`。 

如果两者都不可能，亚历克斯就会成功​​阻止鲍勃。 

这样做的原因是任何避开 Alex 矩形的矩形都必须完全位于它的一侧。 它不能同时水平和垂直穿过Alex。 使亚历克斯居中同时最小化所有四个侧面间隙，因此如果鲍勃不能容纳在那里，则没有其他位置可以使间隙更小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    H, W = map(int, input().split())
    ha, wa = map(int, input().split())
    hb, wb = map(int, input().split())

    if ha > H or wa > W:
        print("No")
        print("No")
        return

    plan_a = False

    if ha <= H and hb <= H and wa + wb <= W:
        plan_a = True

    if wa <= W and wb <= W and ha + hb <= H:
        plan_a = True

    plan_b = True

    if hb <= (H - ha) / 2 and wb <= W:
        plan_b = False

    if wb <= (W - wa) / 2 and hb <= H:
        plan_b = False

    print("Yes" if plan_a else "No")
    print("Yes" if plan_b else "No")

if __name__ == "__main__":
    solve()
```第一部分立即拒绝不可能的情况，因为这两个计划都要求亚历克斯放置自己的海报。 Plan A 计算直接遵循分隔线参数。 这两个方向涵盖了两个不重叠的矩形的所有可能的排列。 

对于 B 计划，有意使用浮点除法。 使用整数除法会错误地舍入诸如`(H - ha) / 2`向下。 比较仅针对整数海报大小，因此普通 Python 浮点精度对于这些小值来说绰绰有余。

 ## 边缘情况

 当亚历克斯的海报与黑板完全匹配时，剩余空间为零。 为了：```
10 10
10 10
10 10
```计划A条件成功，因为只有在有另一种安排的情况下，两个海报才能接触，但这里没有鲍勃的空间，所以第二个答案是`No`。 该算法可以处理此问题，因为剩余的间隙均为零。 

当 Bob 的海报完全适合剩余的条带之一时，Alex 就无法执行 B 计划。例如，如果剩余的垂直间隙恰好足够大，则比较将使用`<=`，因为触摸 Alex 的海报是允许的。 

当看板有足够的空间但海报无法按要求的方向并排排列时，A 计划仍必须返回`No`。 分隔线检查涵盖了两种可能的方向，因此不会意外地接受无效的对角线排列。
