 ## 解决方案
 ## 问题理解

 面条从长度开始`0`。 在接下来的每一次`T`秒，其长度变化`+1`或者`-1`。 每个选择序列都会产生长度的随机游走`T`。 

对于每个测试用例，我们必须计算在整个时间间隔内有多少次行走具有最高值，包括当时的初始位置`0`，正好等于`M`。 由于答案可能非常大，因此每个结果都取模`10^9 + 7`。 

的最大值`T`只是`2000`，但可以有多达`10^5`测试用例。 为每个查询独立计算动态程序大约需要`10^5 × 2000²`的操作，这是完全不可行的。 小上限为`T`建议对每个可能的值进行一次预处理，然后在恒定时间内回答每个查询。 

一个微妙的情况是当`M > T`。 步行每秒仅改变一个单位，因此之后`T`它永远无法达到的高度大于`T`。 例如，```
1
2 3
```有答案`0`。 

另一个容易犯的错误是忘记了计算最大值时初始位置也很重要。 例如，```
1
1 0
```会有答案`1`，因为步行`(0, -1)`永远不会超越`0`。 这个问题保证`M ≥ 1`，所以这种情况永远不会出现在输入中，但它解释了为什么每次都取最大值，包括`t = 0`。 

当步行达到`M`几次。 例如，```
1
4 2
```包含步行```
0 → 1 → 2 → 1 → 2
```它的最大值仍然是`2`。 只计算第一次访问的解决方案`M`会错误地拒绝这个有效的步行。 

## 方法

 最直接的解决办法就是枚举所有`2^T`可能的序列`+1`和`-1`移动。 每个序列都很容易模拟，同时跟踪其最大值。 这显然是正确的，因为每次步行都被检查一次。 不幸的是，当`T = 2000`，搜索空间大约为`2^2000`，这远远超出了任何实际限制。 

指数级的爆炸来自于独立对待每一次步行。 重要的观察是，只有当前位置以及我们是否已经越过禁界才重要。 

假设我们计算最大值从未超过某个限制的步行`K`。 每个状态仅取决于当前时间和当前位置，因为所有先前的信息都是通过我们从未超出的事实来总结的`K`。 

让```
f[K][T]
```表示长度的步行数`T`其最大值最多为`K`。 

那么想要的答案是```
f[M][T] - f[M - 1][T].
```每次行走都精确地达到最大值`M`按第一个数量计算一次，并按第二个数量排除。 

由于每个查询都满足`T ≤ 2000`，我们可以预处理所有的值`f`对于每一个`K`从`0`到`2000`。 状态空间仅约为`2001 × 4001`，因为位置总是介于`-T`和`T`。 此预处理成本约为`O(MAXT²)`每个边界，导致整体复杂性`O(MAXT³)`，这大约是`8 × 10^9`过渡，但仍然太大。 

第二次观察消除了另一个因素。 当增加边界时`K`到`K + 1`，转移图仅在局部发生变化。 通过减法移动坐标`K`将每个问题转化为永远不会变成正数的计数行走。 反射原理给出了封闭形式$$f(K,T)=\sum_x
\left(
\binom{T}{\frac{T+x}{2}}
-
\binom{T}{\frac{T+x}{2}+K+1}
\right),$$其中总和跨越可到达的端点。 在预计算阶乘和逆阶乘之后，每个值都在恒定时间内计算。 现在填写每个答案表只需`O(MAXT²)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(2^T · T)`|`O(1)`| 太慢了|
 | 最佳|`O(MAXT² + N)`|`O(MAXT²)`| 已接受 |

 ## 算法演练

 1. 预计算阶乘和逆阶乘模`10^9 + 7`最多`2000`。 这允许在恒定时间内评估每个二项式系数。 
2. 对于每一个`T`从`0`到`2000`，迭代每个可能的最大值`M`。 
3、利用反射原理公式来统计最大值不超过的行走次数`M`。 
4. 计算边界的相同量`M - 1`。 
5. 将两个值相减`10^9 + 7`。 结果正是最大值等于的行走次数`M`。 
6. 将每个答案存储在一个查找表中，索引为`(T, M)`。 
7. 对于每个测试用例，打印预先计算的值。 

### 为什么它有效

 反射原理在跨越禁止边界的行走和在移动位置结束的反射行走之间建立了双射。 每个无效步行都与恰好一个反射步行配对，并且每个反射步行都恰好来自一个无效步行。 从不受限制的计数中减去这些反射路径，就精确地留下了最大值从未超过边界的路径。 取连续边界之间的差值来隔离其最大值恰好为的游走`M`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7
MAXT = 2000

fac = [1] * (MAXT + 1)
for i in range(1, MAXT + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (MAXT + 1)
invfac[MAXT] = pow(fac[MAXT], MOD - 2, MOD)
for i in range(MAXT, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def C(n, k):
    if k < 0 or k > n:
        return 0
    return fac[n] * invfac[k] % MOD * invfac[n - k] % MOD

ans = [[0] * (MAXT + 1) for _ in range(MAXT + 1)]

for T in range(MAXT + 1):
    at_most = [0] * (MAXT + 1)
    for M in range(MAXT + 1):
        s = 0
        for x in range(-T, T + 1, 2):
            k = (T + x) // 2
            s += C(T, k)
            s -= C(T, k + M + 1)
        at_most[M] = s % MOD

    for M in range(1, MAXT + 1):
        ans[T][M] = (at_most[M] - at_most[M - 1]) % MOD

n = int(input())
for _ in range(n):
    T, M = map(int, input().split())
    if M > T:
        print(0)
    else:
        print(ans[T][M])
```预处理使用阶乘和模逆在恒定时间内计算每个二项式系数。 对每对评估反射原理公式`(T, M)`，之后减去连续值以隔离其最大值恰好为的游走`M`。 

减法必须始终以模进行`10^9 + 7`，因为中间值可能变为负值。 另一个细节是隐藏在端点迭代中的奇偶校验。 可到达的端点始终具有相同的奇偶校验`T`，因此循环前进 2。

 ## 边缘情况

 考虑```
1
2 3
```由于步行每秒最多可以增加 1 次，达到高度`3`分两步是不可能的。 该算法立即检测到`M > T`并返回`0`。 

考虑```
1
4 2
```步行```
0 → 1 → 2 → 1 → 2
```达到高度`2`两次。 它属于具有最多最大值的游走集合`2`，但不至于最大的集合`1`。 他们的差异正确地计算了一次。 

最后，考虑```
1
3 1
```步行```
0 → 1 → 0 → 1
```多次触及最大值但不超过它。 反射原理将其计入以下边界的行走中`1`，而减法仅删除以`0`，因此这次步行对最终答案仅贡献一次。
