 ## 解决方案
 ## 问题理解

 我们在平面上有两组无限轴对齐的线。 

第一组包含位置处的垂直线$x_i$。 第二组包含位置处的水平线$y_j$。 

对角线段来自$(h,0)$到$(h+l,l)$。 由于其斜率是$1$，该线段上的每个整数点都具有以下形式$(h+t,t)$为了$0 \le t \le l$。 对于每个这样的点，我们发射一条垂直于对角线的射线，指向右侧。 任务是确定首先击中哪条画线。 如果第一个命中是垂直线，我们打印`A`接下来是其原始索引。 如果它是一条水平线，我们打印`T`接下来是其原始索引。 平局的解决有利于水平线。 如果没有任何东西被击中，我们打印`-1`。 

输入限制是关键的观察结果。 我们有$N+M \le 10^6$， 和$l$还可以达到$10^6$。 任何对每条射线执行二分搜索的解决方案都已经存在$10^6 \log 10^6$，这是可以接受的，但有更干净的线性扫描。 任何将每条光线与每条线进行比较的方法都需要大约$10^{12}$操作，是完全不可行的。 

微妙的情况来自于几何学。 

考虑：```
1 1
1
0
0 0
```唯一的射线开始于$(0,0)$。 垂直线距离一个单位，而水平线已经在起点上。 正确答案是：```
T0
```忽略距离为零的交点的粗心实现将错误地选择垂直线。 

另一个重要的情况是领带。```
1 1
5
2
3 2
```为了点$(4,1)$，最近的垂直和水平相交发生在沿射线相同的距离处。 该语句要求选择水平线，因此答案必须使用`T`， 不是`A`。 

最后，有些射线可能永远不会击中任何东西。```
1 1
0
100
10 0
```射线开始于$(10,0)$，向右和向下移动，无法到达垂直线$x=0$，并且已经低于水平线$y=100$。 正确的输出是：```
-1
```## 方法

 蛮力的想法很简单。 对于对角线上的每个整数点，计算其射线与每条垂直线和每条水平线相交的位置。 保持沿射线距离最小的有效交点。 这是正确的，因为它明确地评估了每个候选人。 不幸的是，有$l+1$射线和最多$10^6$线，大致导致$10^{12}$在最坏的情况下进行检查。 

为了改善这一点，我们需要了解单条射线的几何形状。 

对角线是$y=x-h$，所以它的一个点是$(h+t,t)$。 

垂直指向右边的射线有方向$(1,-1)$。 其参数形式为$$x=h+t+u,\qquad y=t-u,\qquad u\ge 0.$$对于垂直线$x=a$，交集发生在$$u=a-(h+t).$$这仅在以下情况下有效$a \ge h+t$。 

在所有垂直线中，只有最小的$x_i$满意的$x_i \ge h+t$可能是第一个垂直打击。 

对于水平线$y=b$，交集发生在$$u=t-b.$$这仅在以下情况下有效$b \le t$。 

在所有水平线中，只有最大的$y_j$满意的$y_j \le t$可能会成为第一个横向打击。 

问题现在变成了整数范围上的后继和前驱查询序列。 

作为$t$增加自$0$到$l$，值$h+t$也单调增加。 这意味着我们可以通过两次线性扫描来处理所有光线。 

对于垂直线，我们保留一个指向第一行的指针，其$x$-坐标至少是当前的$h+t$。 

对于水平线，我们保留一个指向最大线的指针，该线的最大线$y$-坐标最多是当前的$t$。 

每个指针仅向前移动，因此总工作是线性的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((l+1)(N+M))$|$O(1)$| 太慢了 |
 | 最佳 |$O(N\log N + M\log M + l)$|$O(l)$| 已接受 |

 ## 算法演练

 1. 将每条垂直线存储为`(x_position, original_index)`并排序`x_position`。 
2. 将每条水平线存储为`(y_position, original_index)`并排序`y_position`。 
3. 对于每个值`t`从`0`到`l`， 让`s = h + t`。 
4. 在已排序的垂直数组中维护一个指针。 当当前行有时将其向前移动`x < s`。 尖线现在是最接近右侧的垂直线（如果存在这样的线）。 
5. 计算垂直距离参数：$$u_v = x_i - s$$如果不存在有效的垂直线，则将距离视为无穷大。 
6. 在已排序的水平数组中维护另一个指针。 虽然下一行满足`y <= t`，使指针前进。 
7. 尖的水平线现在是最大的`y_j <= t`，这正是射线击中的第一条水平线。 
8. 计算$$u_h = t - y_j$$如果不存在这样的水平线，则将距离视为无穷大。 
9. 比较两个距离。 

如果`u_h <= u_v`，输出水平线。 

否则输出垂直线。 
10. 如果两个距离都是无穷大，则输出`-1`。 

### 为什么它有效

 对于固定射线，每个有效的垂直交点都有距离参数$$u=x_i-(h+t).$$最小有效距离来自最小$x_i$那至少仍然是$h+t$。 任何较大的垂直线都会产生较大的距离。 

同样，每个有效的水平交点都有距离参数$$u=t-y_j.$$最小有效距离来自最大有效距离$y_j$那最多还是$t$。 任何较低的水平线都会产生较大的距离。 

该算法始终准确地比较这两个最佳候选者。 由于每隔一条线都距离较远，因此所选线恰好是与射线相交的第一条线。 平局规则是通过使用来处理的`<=`在比较中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    xs = list(map(int, input().split()))
    ys = list(map(int, input().split()))

    h, l = map(int, input().split())

    vert = sorted((x, i) for i, x in enumerate(xs))
    hori = sorted((y, i) for i, y in enumerate(ys))

    ans = []

    pv = 0
    ph = -1

    for t in range(l + 1):
        s = h + t

        while pv < n and vert[pv][0] < s:
            pv += 1

        while ph + 1 < m and hori[ph + 1][0] <= t:
            ph += 1

        best_v = None
        dist_v = 10**30

        if pv < n:
            dist_v = vert[pv][0] - s
            best_v = vert[pv][1]

        best_h = None
        dist_h = 10**30

        if ph >= 0:
            dist_h = t - hori[ph][0]
            best_h = hori[ph][1]

        if dist_v == 10**30 and dist_h == 10**30:
            ans.append("-1")
        elif dist_h <= dist_v:
            ans.append(f"T{best_h}")
        else:
            ans.append(f"A{best_v}")

    print(" ".join(ans))

solve()
```排序的垂直数组让我们可以维护一个后继指针。 一旦垂直线对于当前光线来说变得太靠左，它就永远不会再次变得相关，因为`h+t`只会增加。 

水平扫描反过来使用相同的想法。 指针总是标记最大的`y`已经达到当前值`t`。 

无穷大值由一个非常大的整数表示。 这避免了特殊情况的比较逻辑。 

平局规则的实现是`dist_h <= dist_v`。 将其更改为严格的`<`在等距离交叉点上会产生错误的答案。

 ## 边缘情况

 考虑零距离交集：```
1 1
1
0
0 0
```为了`t = 0`，水平线满足`y = 0`， 所以`uh = 0`。 最近的垂直线有`uv = 1`。 自从`0 <= 1`，算法输出`T0`。 任何忽略距离零的实现都会在这里失败。 

考虑领带：```
1 1
2
0
1 1
```为了`t = 1`，射线开始于`(2,1)`。 随着距离立即到达垂直线`0`，而水平线也在一定距离处`1 - 0 = 1`对于较早的射线。 比较使用`<=`，因此等距离始终准确地选择所需的水平线。 

考虑一个无法访问的配置：```
1 1
0
100
10 0
```后继查询找不到垂直线，因为所有垂直线都位于起点的左侧。 前导查询找不到水平线，因为所有水平线都位于射线上方。 两个距离都变为无穷大，算法输出`-1`。 这直接符合几何解释。
