 ## 解决方案
 ## 问题理解

 我们得到一小组轴对齐的矩形海报，放置在代表墙的固定 20 x 20 网格上。 每张海报覆盖其矩形内的每个单元格，并且多张海报可能重叠。 如果网格中的每个单元格都被至少一张海报覆盖，则认为墙被成功“覆盖”。 

我们可以精确地挑选一张海报并将其重新定位到任何其他相同尺寸的轴对齐矩形位置。 所有其他海报保持固定。 问题是是否可以选择一张海报并对其进行新的放置，以便在移动后，整个 20 x 20 墙被完全覆盖。 

关键约束很小。 对于最多 10 个矩形和仅包含 400 个单元格的网格，任何明确推理单个单元格或尝试所有子集的解决方案都已经可行。 这立即排除了对大量优化技术的需要。 即使是从头开始重新计算每个候选海报的覆盖范围的解决方案也是可以接受的，因为常数因子很小。 

仅推理总面积时会出现微妙的失败案例。 例如，假设未覆盖的单元格与海报区域具有相同的计数，但被分成两个不相连的区域。 在这种情况下，移动单个矩形无法解决这种情况，因为矩形只能填充单个连续块。 同样，即使未覆盖的区域是连续的，它也可能不会形成完美的矩形，这又使得无法精确填充。 

具体的边缘情况是指未覆盖的单元看起来像 L 形。 该区域可能与海报匹配，但没有单个轴对齐的矩形可以覆盖它。 单纯的基于区域的检查会错误地接受此类情况。 

## 方法

 暴力的观点是尝试所选海报的所有可能的目标位置，模拟最终配置，并验证完全覆盖。 然而，网格有 400 个单元，并且矩形可以放置在大约 400 个可能的左上角位置和方向（由其固定大小确定）。 尝试对最多 10 张海报中的每张海报进行所有放置会导致大约 10 × 400 × N 矩形更新，这变得不必要且重复。 

关键的观察是，我们实际上并不关心移动的海报最终会去哪里。 我们只关心最终条件：从原始位置移除一张海报后，剩余的未覆盖区域必须可以由与移除的海报尺寸相同的矩形完全填充。 这消除了显式模拟放置的需要。 

所以问题归结为结构检查。 对于每张海报，暂时从网格中删除其贡献并查看未覆盖的单元格。 如果我们能够发现未被覆盖的单元恰好形成一个轴对齐的矩形，其面积等于移除的海报的面积，那么我们就可以将移动的海报放在那里并实现完全覆盖。 否则，那张海报就不可能被移动。 

这将任务减少为最多检查 10 个候选者，每个候选者位于 20 x 20 的网格上。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力放置模拟| O(N·400·400) | 奥（400）| 可以接受但没有必要 |
 | 移除一张海报 + 验证孔形状 | O(N·400) | 奥（400）| 已接受 |

 ## 算法演练

 我们直接在 20 x 20 网格上工作，并将每张海报视为一组覆盖的单元格。

1. 构建一个 20 x 20 的覆盖网格，其中每个单元格计算覆盖它的海报数量。 这给出了墙的完整描述。 
2. 对于每个海报 i，从网格中减去其贡献。 这模拟了将其从墙上移除并揭示了剩余海报引起的未覆盖结构。 
3. 收集移除后未覆盖的所有细胞。 这些代表了移动海报 i 必须填充的确切区域。 
4. 通过跟踪最小和最大 x 和 y 坐标来计算这些未覆盖单元格的边界矩形。 这给出了包含所有未覆盖单元格的最小轴对齐矩形。 
5. 检查该边界矩形内的每个单元格是否都未被覆盖。 如果里面的一个单元格已经被覆盖，那么未被覆盖的区域就不是一个完整的矩形，因此这张海报无法使用。 
6. 检查该边界矩形的面积是否等于海报 i 的面积。 这可以确保移动的海报有足够的单元格来填充孔。 
7. 如果任何海报都满足这两个条件，请返回“是”。 否则，返回“否”。 

我们只检查边界矩形的原因是任何有效的放置本身都必须是矩形，因此未覆盖的区域必须与该形状完全匹配。 

### 为什么它有效

 移除一张海报后网格的状态是固定的。 如果剩余的未覆盖单元格不能形成单个完美的矩形，则没有单个轴对齐的矩形可以完全覆盖它们。 如果它们确实形成一个矩形，但其面积与移除的海报不同，那么即使完美放置的移动海报也无法匹配所需的覆盖范围。 因此，该算法检查可行性的确切必要和充分条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    rects = []
    for _ in range(N):
        x1, y1, x2, y2 = map(int, input().split())
        rects.append((x1, y1, x2, y2))
    
    def build_coverage(exclude):
        grid = [[0] * 21 for _ in range(21)]
        for i, (x1, y1, x2, y2) in enumerate(rects):
            if i == exclude:
                continue
            for x in range(x1, x2 + 1):
                for y in range(y1, y2 + 1):
                    grid[x][y] = 1
        return grid

    for i in range(N):
        grid = build_coverage(i)
        
        cells = []
        for x in range(1, 21):
            for y in range(1, 21):
                if grid[x][y] == 0:
                    cells.append((x, y))
        
        if not cells:
            continue
        
        minx = min(x for x, y in cells)
        maxx = max(x for x, y in cells)
        miny = min(y for x, y in cells)
        maxy = max(y for x, y in cells)
        
        ok = True
        area = 0
        
        for x in range(minx, maxx + 1):
            for y in range(miny, maxy + 1):
                if grid[x][y] == 0:
                    area += 1
                else:
                    ok = False
        
        if not ok:
            continue
        
        target_area = (rects[i][2] - rects[i][0] + 1) * (rects[i][3] - rects[i][1] + 1)
        if area == target_area:
            print("Yes")
            return
    
    print("No")

if __name__ == "__main__":
    solve()
```该解决方案迭代每个可能的海报以移动并重建没有它的墙壁覆盖范围。 网格足够小，每次重新计算覆盖范围都是简单且安全的。 

关键的实施细节是未覆盖区域的验证。 我们不会仅仅因为边界框存在就假设它是矩形。 我们明确验证边界框内的每个单元格都未被覆盖。 这可以防止未覆盖的细胞形成多个断开区域的误报。 

另一个微妙之处是我们仅在确认形状正确性后才比较区域。 颠倒此顺序可能会冒接受面积匹配但几何形状不匹配的情况的风险。

 假设移除一张海报后，未覆盖的单元格形成一个完美的 2 x 3 矩形。

### 示例 2

 现在考虑一个未覆盖的单元格被分割的情况：

 | 步骤| 敏克斯 | 最大 | 米妮 | 马克西 | 盒子里面没有盖子|

 | 移除后 | 1 | 3 | 1 | 3 | 含有孔 |

 尽管边界框是 3 x 3，但其中的一些单元格已经被覆盖。 该算法立即拒绝，因为没有一个矩形可以填充非实体区域。 

这说明了为什么仅边界框推理是不够的，以及为什么需要对内部进行全面验证。

 ## 边缘情况

 当移除海报时，会出现一种边缘情况，根本不会留下未覆盖的单元格。 在这种情况下，算法会正确地跳过检查，因为没有任何内容可填充，并且移动海报是不必要的，但也是无关紧要的，因为完全覆盖已经存在。 

另一种情况发生在未覆盖区域是单个细胞时。 即使这是一个矩形，算法也会正确地将面积与删除的海报进行比较并拒绝，除非海报完全是 1 x 1。 

一个更微妙的情况是当未覆盖的单元格形成多个不相交的矩形时。 边界框仍然存在，但内部检查将失败，因为框内的某些单元格仍然被覆盖。 这确保了碎片孔永远不会被错误地接受。
