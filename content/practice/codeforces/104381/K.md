 ## 解决方案
 ## 问题理解

 我们有两行平行的编号图块，每行包含$n$职位。 在每个索引处$i$，左行有一个值$a_i$右行有一个值$b_i$。 玩家开始时，左脚站在左行的第一块棋子上，右脚站在右行的第一块棋子上。 然后，他们每次重复移动一只脚到同一排的下一个位置，从而向前移动，永远不会向后移动。 

每当一只脚踩在一块瓷砖上时，该瓷砖的值就会添加到分数中。 这个过程一直持续到双脚到达位置$n$。 目标是最大化收集的总金额。 约束限制了两脚允许的距离：如果左脚处于位置$i$右脚处于位置$j$， 然后$|i - j| \le K$必须始终持有。 

关键在于，运动是沿着两条耦合路径连续进行的。 每个状态不仅由位置定义，而且由两只脚的相对位置定义，因为向前迈出一侧会改变这种差异。 

约束很小，有$n \le 300$，这立即表明二次或三次动态规划方法是可以接受的。 一个立方体$O(n^3)$解决方案可能勉强通过，但设计良好$O(n^2)$DP 在一定范围内。 

一种简单的方法是尝试模拟所有可能的动作序列。 每一步，左脚或右脚向前移动，同时遵守距离限制。 此类序列的数量呈指数增长，大致类似于长度的二项式路径$2n$，即使对于$n = 30$。 

当一只脚“等待”而另一只脚前进几步时，就会出现一个更微妙的问题。 如果我们不仔细编码状态，很容易错误地假设双脚同步前进，这将错过最佳解决方案，其中一侧暂时前进得更快以收集更高的值。 

当存在负值时会出现另一种边缘情况。 总是向前移动或总是平衡脚的贪婪方法可能会严重失败，因为有时值得暂时踩到负值以解锁对更大正段的访问，同时尊重距离约束。 

## 方法

 蛮力的想法是将其视为对状态的类似最短路径的搜索$(i, j)$， 在哪里$i$是左脚位置，$j$是右脚的位置。 从每个州，我们可以移动$i \to i+1$或者$j \to j+1$，只要指数保持在界限内并且$|i-j| \le K$。 每一步都会增加所踩到的瓷砖的价值。 

这是正确的，因为它探索了所有有效的动作序列。 然而，州的数量是$O(n^2)$，并且从每个状态我们分支成两个转换，因此简单的递归探索指数数量的路径。 即使在没有仔​​细排序的情况下进行记忆，也可能面临重新计算或大量开销的风险。 

关键的观察结果是，这是状态网格上的经典动态规划问题。 每个状态仅取决于之前的两个状态：$(i-1, j)$和$(i, j-1)$，假设有约束$|i-j| \le K$受到尊重。 这将问题转化为在有限对角线带上计算 DP$n \times n$网格。 

我们定义$dp[i][j]$为左脚踩地时的最高分$i$右脚位于$j$。 转换很简单，因为最后一步必须是向左前进或向右前进。 

约束条件$|i-j| \le K$只是修剪无效状态，将 DP 区域缩小到对角线周围的区域。 自从$n \le 300$，迭代所有有效对是有效的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数$O(2^{2n})$| O(n) 递归深度 | 太慢了|
 | 最佳DP |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们将该过程建模为两个同步指针沿着各自的行独立移动，同时遵守距离约束。 

1. 定义一个 DP 表，其中每个状态代表双脚的有效配置。 我们使用$dp[i][j]$为左脚在位时的最佳成绩$i$右脚处于位置$j$。 这直接编码有关游戏状态的所有必要信息。 
2.初始化启动状态$dp[1][1]$与第一块瓷砖的总和$a_1 + b_1$。 这反映了任何移动发生之前的初始分数。 
3. 迭代所有对$(i, j)$按递增顺序。 对于每一对，我们仅在以下情况下处理它：$|i-j| \le K$，因为所有无效状态都被禁止并且不能促成转换。 
4. 从每个有效状态，考虑将左脚推进到$i+1$。 新的状态变成$(i+1, j)$，我们添加$a_{i+1}$到分数。 我们更新$dp[i+1][j]$如果这提高了价值。 这表示在保持右脚固定的情况下在左行上迈出一步。 
5. 同样，考虑将右脚推进$j+1$，过渡到$(i, j+1)$并添加$b_{j+1}$。 我们更新$dp[i][j+1]$因此。 这反映了对称动作。 
6. 在传播转换时，确保我们只更新满足约束的状态$|i-j| \le K$。 任何违反此规定的转换都会被立即丢弃，因为它代表无效的物理配置。 
7. 答案是存储在中的值$dp[n][n]$，因为双脚必须结束于最后一个位置。 

DP 按递增的索引顺序进行处理，以便当我们计算状态时，所有可能的前驱状态都已被评估。 

### 为什么它有效

 每个有效的移动序列恰好对应于通过 DP 网格的一条路径$(1,1)$到$(n,n)$。 每次转换都会准确地添加新踩到的图块的值，并且不会重复计算或跳过任何图块。 约束条件$|i-j| \le K$每一步都强制执行，确保所有 DP 状态都对应于有效的物理配置。 由于所有路径都是通过 DP 松弛来探索的，并且每个状态都保持所有到达它的方式中的最大分数，因此最终状态$dp[n][n]$必须包含最优答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, K = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

INF = -10**18
dp = [[INF] * (n + 1) for _ in range(n + 1)]

dp[1][1] = a[0] + b[0]

for i in range(1, n + 1):
    for j in range(1, n + 1):
        if abs(i - j) > K:
            continue
        if dp[i][j] == INF:
            continue

        if i + 1 <= n and abs((i + 1) - j) <= K:
            dp[i + 1][j] = max(dp[i + 1][j], dp[i][j] + a[i])

        if j + 1 <= n and abs(i - (j + 1)) <= K:
            dp[i][j + 1] = max(dp[i][j + 1], dp[i][j] + b[j])

print(dp[n][n])
```其实现直接反映了 DP 的表述。 DP表被初始化为一个大的负数来表示不可达状态。 初始状态包括两个起始位置。 每个转换在更新之前都会仔细检查数组边界和距离约束。 

DP 中的索引是从 1 开始的，但数组中是从 0 开始的，因此访问`a[i]`对应于将左脚从$i$到$i+1$。 这种转变在整个转变过程中都是一致的。 

循环顺序确保在处理状态时，已考虑所有较早可达的状态，因此不需要额外的排序逻辑。

 ## 边缘情况

 一个微妙的边缘情况是$K$大，意味着脚可以自由分开。 例如，如果$K = n$，约束消失，问题变成网格上的纯路径DP。 该算法自然会处理这个问题，因为所有$(i,j)$状态仍然有效，因此 DP 探索整个格并可以独立地最大化两行。 

另一种情况是当$K = 1$，这迫使两个指数几乎保持同步。 在这样的情况下$a = [0, 100, 0]$,$b = [0, 0, 100]$，最优策略需要仔细交替。 民主党通过绝不允许像这样的国家来确保可行性$(1,3)$，这将违反约束，从而强制正确的交错。 

负重输入测试 DP 是否正确地偏好未来收益而不是眼前损失。 例如，可能仍然需要踩到负图块才能解锁对后续高价值区域的访问。 DP 保留了这种转换，因为它总是将最大可达分数传播到每个状态，而不是根据局部需求进行修剪。
