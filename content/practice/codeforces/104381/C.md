 ## 解决方案
 ## 问题理解

 我们给定了一个整数集合，我们想要基于整除性来计算索引之间的有序关系。 对于每对位置$i$和$j$，我们检查值是否为$i$可以被以下值整除$j$，同时保证两个索引不同。 每个有效对都为最终答案贡献一个。 

输入大小使得对所有对进行暴力破解是不可能的。 高达$2 \cdot 10^5$数字，对所有对的二次扫描将涉及大约$4 \cdot 10^{10}$检查，这远远超出了一秒钟可以运行的范围。 即使是尝试跳过某些情况的稍微优化的嵌套循环，在这种规模下仍然会崩溃。 

值本身的边界是$5 \cdot 10^5$，这是关键的结构性约束。 这意味着我们可以将思维从每个元素的比较转变为值频率推理，因为可能值的范围远小于元素的数量。 

当存在重复时，天真的方法也往往会以微妙的方式失败。 如果许多元素共享相同的值，则在嵌套循环内独立处理每个出现的元素会导致重复的冗余工作并增加运行时间，而不会提高正确性。 

例如，如果数组全为 1，则除自对之外的每个有序对都是有效的。 强力方法仍然单独检查每一对，而基于频率的方法立即将计算压缩为简单的公式。 

## 方法

 强力解决方案迭代所有有序对并直接检查整除性。 这在概念上很简单：对于每个$i$，我们扫描所有$j \neq i$并测试是否$a_i \bmod a_j = 0$。 这是有效的，因为它完全遵循定义，但它对每个有序对执行整除性检查，从而导致$O(n^2)$运营。 和$n = 2 \cdot 10^5$，这是不可行的。 

关键的观察结果是，可分性仅取决于值，而不取决于位置。 如果我们知道每个值出现的次数，我们可以用聚合计数代替重复检查。 我们不是迭代元素，而是迭代可能的值并推理它们的倍数。 

对于固定值$x$, 每个有效的合作伙伴$y$必须满足$y$划分$x$。 所以问题就变成了：对于每个值$x$，将所有除数的频率相加$y$，同时尊重排序约束。 

这将计算转变为类似筛子的累积过程。 我们预先计算频率，然后迭代值，将贡献传播到倍数。 每个数字都会贡献其自身的所有倍数，这自然地编码了整除关系，而无需显式的对枚举。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 频率筛|$O(V \log V)$或者$O(V \log V)$类似|$O(V)$| 已接受 |

 这里$V = 5 \cdot 10^5$。 

## 算法演练

 我们首先将输入压缩到频率数组中，其中`freq[x]`存储多少倍的值`x`出现。 

然后，我们使用倍数筛选来计算贡献。 

1. 针对输入中的所有值构建频率数组。 这让我们可以将相同的值视为一组，而不是单独处理每个出现的值。 这是至关重要的，因为所有交互仅取决于值，而不取决于指数。 
2. 对于每个值$x$，我们将其视为潜在除数。 每个倍数$k \cdot x$代表一个可以配对的值$x$在可分性条件下。 
3. 对于每个这样的倍数，我们添加以下形式的贡献`freq[x] * freq[kx]`。 这对有序对进行计数，其中第二个元素可被第一个元素整除。 
4. 我们还必须确保排序约束不会错误地重复计算。 由于条件是有方向的（i、j 有序），因此当按升序迭代除数时，每个有效对自然会被精确计数一次。 
5. 将所有贡献汇总为一个全局答案。 

关键在于，迭代多个可确保每个有效的整除关系仅捕获一次，而无需扫描不相关的对。 

### 为什么它有效

 每对订购的$(i, j)$这样$a_i$是的倍数$a_j$唯一对应于一对值$(x, y)$在哪里$x = a_i$,$y = a_j$， 和$x$是的倍数$y$。 当我们修好$y$并迭代所有倍数$x$，我们精确地枚举了这些对。 频率乘积对所有索引组合进行计数，因此不会遗漏配对，也不会重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    MAXV = 500000
    freq = [0] * (MAXV + 1)
    
    for x in a:
        freq[x] += 1

    ans = 0

    for y in range(1, MAXV + 1):
        if freq[y] == 0:
            continue
        for x in range(y * 2, MAXV + 1, y):
            if freq[x]:
                ans += freq[x] * freq[y]

    print(ans)

if __name__ == "__main__":
    solve()
```读取输入后，我们构建一个频率表，以便聚合所有相同的值。 然后，双循环遍历除数-倍数关系。 对于每个基值`y`，我们迭代所有倍数`x`，并累积`freq[y] * freq[x]`它表示所有有序对，其中较大的值可以被较小的值整除。 

内循环从`2*y`因为`y`分裂自身将对应于自对，这些自对被问题陈述明确排除。 

## 工作示例

 ### 示例 1

 输入：```
1 2 3 4 5
```频率均为 1。我们列举贡献：

 | y | x 的倍数 | 贡献|
 | --- | --- | --- |
 | 1 | 2,3,4,5 | 4 |
 | 2 | 4 | 1 |
 | 3 | - | 0 |
 | 4 | - | 0 |
 | 5 | - | 0 |

 总计 = 5

 这与示例相符，因为所有数字都可以被 1 整除，并且 4 可以被 2 整除。 

### 示例 2

 输入：```
2 2 2 4
```频率：

 - 2 → 3
 - 4 → 1

 | y | x| 贡献 |
 | --- | --- | --- |
 | 2 | 4 | 3 * 1 = 3 | 3 * 1 = 3 |

 答案 = 3

 这显示了重复如何通过频率倍增来放大贡献。

 ## 边缘情况

 一个关键的边缘情况是当数组包含像 1 这样的小数字的许多重复项时。在这种情况下，每隔一个数字都会贡献 1，并且答案会呈二次方增长。 基于频率的方法可以自然地处理这个问题，因为`freq[1]`乘以所有其他频率，而简单的方法仍然会进行冗余的成对检查。 

另一种边缘情况是当值在上限附近稀疏时。 筛子仍然可以正确迭代，因为它会跳过空频率并仅处理现有除数，从而防止不必要的工作。
