 ## 解决方案
 ## 问题理解

 我们正在跟踪每周不断演变的随机密码系统。 有一个固定的列表$n+1$不同的密码。 在第一周开始时，系统使用列表中的第一个密码。 

每周，密码要么保持不变，要么发生变化。 有概率$1/m$，没有任何反应并且密码保持不变。 有概率$(m-1)/m$，发生变化，从其他密码中统一选择一个新密码$n$密码，不包括当前密码。 

运行此过程后$T$几周以来，我们观察当前使用的密码。 然后，用户尝试通过按列表顺序尝试密码来解锁系统，最多允许尝试解锁系统$k$尝试。 问题是当前密码在一周的概率$T$是第一批之一$k$列表中的条目。 

因此，真正的任务不是模拟尝试，而是计算密码在之后当前处于活动状态的概率分布。$T$随机转换，然后对大小前缀上的概率求和$k$。 

关键的难点在于$n$和$m$可以大到$10^9$，因此我们无法维护每个密码的概率或直接模拟马尔可夫过程。 仅有的$T$足够小，可以随着时间的推移进行迭代。 

从复杂性的角度来看，任何跟踪大小向量的解决方案$n$每一步都是立即不可能的，因为它会花费$O(nT)$，最多可达$10^{14}$。 甚至$O(n)$每步太大。 我们必须大幅减少状态空间。 

出现微妙的边缘情况时$k = n+1$。 在这种情况下，无论什么情况，答案始终为 1$T$，因为所有可能的密码都在允许的尝试范围内。 幼稚的实现可能仍然会执行不必​​要的概率计算并冒模块化错误的风险。 

另一个极端情况是当$m = 1$。 然后$(m-1)/m = 0$，因此密码在初始化后永远不会改变。 答案仅取决于初始密码是否位于第一个$k$位置，这是确定性的。 

最后，当$n = 1$，只有一种可能的替代密码。 该系统变成了一个简单的二态过程，具有简并的转换结构，并且许多天真的“统一于其他”实现由于被零或空采样集除法而在这里破裂。 

## 方法

 强力解释将维持所有概率分布$n+1$密码。 最初，概率 1 位于密码 1 上。每周，我们都会更新概率：每个状态要么保留因子$1/m$，或者将其输出概率质量均匀地分布在所有其他$n$州。 

这是一个具有密集转移矩阵的马尔可夫链。 直接模拟成本$O(T \cdot n)$，因为每一步都会在所有状态之间重新分配概率质量。 和$n, T$很大，这太慢了。 

关键的观察是对称性。 除第一个密码外，所有密码都无法区分。 在任何时候，只有两种状态：当前密码和任何其他状态$n$密码。 更重要的是，在第一步之后，所有非初始密码将永远保持对称。 这会折叠状态空间$n+1$值为两个聚合概率：密码 1 的概率和任何其他特定密码的概率。 

这种简化将过程变成了一个具有非常简单的递归的二态马尔可夫链，其中每一步仅取决于初始状态下的当前质量以及它如何传播到其他状态。 

一旦我们可以计算出每个密码当前处于活动状态的概率，我们就再次利用对称性：所有非初始密码都具有相同的概率。 因此，当前密码位于第一个的概率$k$位置仅取决于是否包含索引 1 以及剩余的数量$k-1$包括对称状态。 

这将问题转化为计算两个量的闭合形式演化$T$步骤，可以在$O(T)$，然后将它们进行算术组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(Tn)$|$O(n)$| 太慢了|
 | 最佳|$O(T)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 初始化概率$p$作为之后我们仍然使用原始密码的概率$t$步骤。 最初$p = 1$。 我们还跟踪所有其他密码均等地共享剩余概率质量，因此每个密码都有概率$(1-p)/n$。 这种对称性由转移规则保留。 
2. 每周处理从 1 到$T$。 在每个步骤中，计算概率如何从当前状态流动。 有概率$1/m$，系统保持相同的密码，因此每个状态的质量乘以$1/m$。 有概率$(m-1)/m$，发生转换，并且质量在所有其他密码中均匀地重新分配。 
3.利用以下事实来更新处于原始密码的概率：可以通过留在原地或从另一个状态转换然后通过统一选择返回来达到原始密码。 递推简化为线性变换$p$，所以我们更新$p = a \cdot p + b$，其中常数$a$和$b$仅依赖于$n$和$m$。 
4.之后$T$步骤，计算每个非初始密码的概率为$(1-p)/n$。 这直接遵循对称性：所有非初始状态在该过程下仍然是可交换的。 
5. 计算最终答案。 如果密码 1 在第一个密码内$k$， 添加$p$。 然后添加剩余的贡献$\min(k-1, n)$对称密码，每个密码都有贡献$(1-p)/n$。 
6. 使用模逆将得到的有理表达式转换为模形式。 由于所有分数都是涉及项的线性组合$m$和$n$，我们计算模下的所有内容$10^9+7$使用模幂求逆。 

### 为什么它有效

 正确性来自对称不变量：在每一步中，除原始密码外的所有密码都保持可交换。 转换规则从不区分它们，因为每个“更改”步骤都会在所有其他密码中统一选择。 这确保了概率分布始终具有两个自由度：原始密码的质量和所有其他密码共享的相等质量。 这两个量的演化完全决定了系统，因此状态空间的崩溃不会丢失信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m, k, T = map(int, input().split())

    if k >= n + 1:
        print(1)
        return

    # probabilities:
    # p = prob we are still at password 1
    # recurrence derived from symmetry:
    # p' = (1/m)*p + (m-1)/m * (1/n)
    invm = modinv(m)
    one_minus = (m - 1) * invm % MOD
    stay = invm

    invn = modinv(n)

    p = 1

    for _ in range(T):
        p = (stay * p + one_minus * invn) % MOD

    # total answer
    ans = 0
    if k >= 1:
        ans = (ans + p) % MOD

    if k > 1:
        ans = (ans + (k - 1) * ((1 - p) % MOD) % MOD * invn) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```代码直接实现了二态递归。 变量`p`跟踪保留初始密码的概率。 期限`stay = 1/m`对应于不改变，而`one_minus/n`表示变化后通过随机选择返回到初始状态的概率质量。 

最终答案分为两部分：第一个密码是否在允许的范围内，以及剩余密码的对称组中有多少概率质量位于第一个密码中$k-1$职位。 

一个常见的实现错误是忘记更改后的重新分配排除了当前密码，这就是循环混合保留采样项和均匀采样项的原因。

 ## 边缘情况

 当$m = 1$，变化的转移概率为零。 复发率降低至$p_{t+1} = p_t$， 所以$p$全部保持为 1$T$。 最终的答案纯粹是索引 1 是否位于第一个索引内$k$，实现立即处理。 

什么时候$k \ge n+1$，所有密码都是可接受的。 该算法短路返回1，不进行任何模运算，避免了不必要的运算，防止溢出累加。 

什么时候$T = 0$，这个过程根本没有进化。 系统以 1 的概率保留第一个密码，因此如果$k \ge 1$，否则为 0。递归循环自然会跳过更新并保留正确性。
