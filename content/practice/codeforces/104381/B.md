 ## 解决方案
 ## 问题理解

 我们在无限网格上给出了具有整数坐标的两个点。 一块从第一个点开始，需要到达第二个点。 在一个动作中，这件作品可以有两种不同的表现方式。 它可以像骑士一样移动，这意味着它可以以八种标准 L 形模式之一跳跃，偏移量为 (2,1)、(1,2) 及其符号变化。 或者，它可以像主教一样移动，这意味着它可以在单个对角线方向上移动任意步数，或者沿着线 y = x 或 y = -x。 

每个动作都是自由选择的，因此在每一步我们都可以决定是使用骑士跳还是任意长度的对角滑行。 目标是最小化从起始坐标到目标坐标所需的移动次数。 

坐标的大小可以大到 10^9，因此任何尝试逐步探索网格或模拟路径的解决方案都是立即不可行的。 即使是对位置的 BFS 也是不可能的，因为图是无限的并且分支因子是不平凡的。 答案必须仅取决于两点的几何特性。 

一个关键的微妙之处在于象移动非常强大：它允许沿着任意长度的对角线即时移动。 这意味着如果起点和终点位于同一对角线上，则答案很简单 1。当马单独移动就足够时，就会出现第二种微妙的情况，因为一次移动中马的可达性取决于一组固定的相对偏移量。 最后，在某些情况下，马或主教的移动都不够，但两种移动的组合就足够了。 

一个天真的错误是假设组合两种移动类型总是减少到 1 或 2 个移动而不仔细检查对齐条件。 例如，距离一马的点不一定位于对角线上，并且对角线上的点可能在曼哈顿距离中仍然相距很远，但在主教的一步移动中仍然可以到达。 

## 方法

 强力解释将尝试将每个位置视为图中的一个节点并运行最短路径搜索。 从任何节点，都有八个马边和无限多个主教边，因为主教可以跳到其对角线上的任何点。 即使我们离散化问题，状态空间也是无界的，并且转换也是不可管理的。 主教单独移动的分支因素使得这成为不可能，因为每个节点都连接到无限多个其他节点。 

关键的观察结果是，最佳路径只需要少量的移动。 每次移动要么保留对角线不变量（主教），要么在固定的有界偏移集内移动（骑士）。 因此，任何最短路径都必须属于以下三类之一：如果点重合则为零步，如果点通过马步或象步直接连接则为一步，否则两步总是足够的。 

两次移动就足够的原因来自于网格的几何形状。 马的移动可以以有界的方式改变奇偶结构和相对位置，主教的移动可以任意重新排列对角线。 如果直接的马移动和直接的主教移动都不起作用，我们总是可以首先使用一个移动将自己置于一个由主教移动完成旅程的配置中，反之亦然。 由于两种移动类型在不同的维度上都极具表现力，因此它们的组合涵盖了所有剩余的情况。 

因此，问题简化为检查一些恒定时间的几何条件。

 ## 算法演练

我们将起点表示为 (x1, y1)，将目标表示为 (x2, y2)。 我们完全使用相对位移 dx = |x2 - x1| dy = |y2 - y1|。 

1. 首先检查起点和目标是否重合。 如果 dx = 0 且 dy = 0，则不需要移动。 这是唯一答案为零的情况，因为任何移动都会改变位置。 
2. 接下来，检查单个主教移动是否可以到达目标。 主教的移动可以到达位于同一对角线上的任何点，这意味着 dx = dy。 这是有效的，因为沿着对角线移动可以保留坐标之间的绝对差。 
3. 然后检查单次骑士移动是否可以到达目标。 马的移动恰好有八种可能的位移模式，因此我们验证对 (dx, dy) 是否与 (1,2)、(2,1)、(2,0)、(0,2) 中的任何一个匹配在标准马的移动中实际上无效，因此只有 (1,2) 和 (2,1) 很重要，因为符号对称性是通过绝对值处理的。 
4. 如果以上条件均不成立，则答案为 2。原因是，任何位置总是最多需要两步才能到达，因为我们可以首先使用马移动到对角线对齐的位置，或者通过主教移动直接匹配目标。 

### 为什么它有效

 整个解决方案依赖于以下事实：两种移动类型都定义了非常大的可达性集。 象的移动一步覆盖了整个对角线，而马的移动可以打破奇偶约束并在象无法到达的坐标类之间移动。 因为这两个变换是互补的，所以任何一对点要么直接由其中一个点连接，要么可以使用一个中间位置桥接。 没有任何配置需要两次以上的移动，因为一次局部有界跳跃和一次全局对角线扫描的组合跨越了整个整数格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_knight(dx, dy):
    return (dx, dy) in {(1, 2), (2, 1)}

def solve():
    x1, y1, x2, y2 = map(int, input().split())
    dx = abs(x1 - x2)
    dy = abs(y1 - y2)

    if dx == 0 and dy == 0:
        print(0)
        return

    if dx == dy:
        print(1)
        return

    if is_knight(dx, dy):
        print(1)
        return

    print(2)

if __name__ == "__main__":
    solve()
```实现首先读取坐标并使用绝对差将问题转换为纯粹的相对形式。 这消除了方向性，使我们只能推理幅度。 

第一个条件处理不需要移动的退化情况。 第二个条件检查对角线对齐，这与主教一步可达性完全一致。 第三个条件测试骑士偏移的有限集。 其他一切都属于两步运动类别，这是由组合运动结构保证的。

 ## 边缘情况

 相同的开始和结束情况是移动计数为零的唯一情况。 该算法在任何几何检查之前显式处理它，因此对于 (7, -3) 到 (7, -3) 等输入，它正确输出 0。 

马邻接情况取决于精确的偏移量。 例如，接受 (0,0) 到 (2,1)，因为它与取绝对值后的有效马位移相匹配。 该算法根据固定集进行检查，因此不会意外包含无效偏移量。 

对角线情况处理任意大的距离，例如 (10^9, 10^9)，正确地将它们折叠成单个主教移动。 由于直接检查绝对差的相等性，因此不会出现溢出或近似问题。 

其余情况自动分为两步。 例如，(0,0) 到 (3,4) 不是马步，也不是对角线，因此它可以正确分类，不需要显式的路径构造。
