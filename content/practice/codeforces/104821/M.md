 ## 解决方案
 ## 问题理解

 我们得到一个高度数组，表示垂直条的天际线。 每次操作后，一个条就会增加，我们必须计算如果雨水填满山谷，这些条之间会滞留多少水。 

对于每个位置，水位由其左侧的最高条和右侧的最高条确定。 位置 i 上方的水位是这两个最大值减去当前高度中的较小者，但绝不会为负值。 任务是在每次点增量更新后维护这个总数。 

限制很大：每次测试总计最多 200,000 个位置和更新，总输入大小最多为 100 万个。 这排除了每次更新后从头开始重新计算前缀和后缀最大值的情况，因为这会花费每个查询的线性时间，并在最坏的情况下导致大约 10^11 次操作。 

单纯的方法除了速度之外还会以更微妙的方式失败。 例如，假设我们维护前缀和后缀最大值数组，并且仅在更改的索引周围进行本地更新。 这种情况会被破坏，因为每当创建新的主峰时，单次增加就可以将变化传播到右侧或左侧很远的地方。 

一个小例子说明了这一点：

 输入：```
5
1 2 3 2 1
update (3, +3)
```更新后，第三个元素变为6，将中间条变成全局峰值。 其右侧所有位置的前缀最大值发生变化，其左侧所有位置的后缀最大值发生变化。 任何仅假设局部调整的方法都会低估影响并产生不正确的截留水值。 

## 方法

 蛮力思想为每次更新重新计算前缀最大值和后缀最大值，然后对每个索引的水贡献求和。 这是正确的，因为它直接遵循定义：每个位置仅取决于其当前的左右最大值。 问题是每次重新计算的成本为 O(n)，并且随着 q 次更新，成本变为 O(nq)，这对于给定的约束来说太大了。 

关键的观察是前缀最大值和后缀最大值是单调结构。 当我们从左到右扫描时，前缀最大值仅在遇到新纪录高点时才会改变。 对于后缀最大值，这同样适用于从右侧对称的情况。 这意味着数组可以被视为被划分为多个段，其中控制最大值是恒定的。 

当单个位置增加时，它可能会创造新的记录或加强现有的记录。 这仅影响该位置附近的记录最大值的结构。 我们不重新计算整个前缀或后缀数组，而是维护当前的记录结构，只修复因更新而无效的部分。 每次修复要么插入一条新记录，要么删除一系列受控制的记录，并且在所有更新中，每条记录只能插入和删除有限次数。 

我们维护两种单调结构，一种用于前缀最大值，一种用于后缀最大值。 由此，我们可以恢复每个索引的 f[i] 和 g[i]。 然后通过对 min(f[i], g[i]) - a[i] 求和来计算总水量，并且我们通过仅跟踪 f 或 g 值发生变化的指数来增量地维护这个总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(nq) | O(n) | 太慢了 |
 | 前缀和后缀最大值的单调修复| O((n + q) log n) 摊销 | O(n) | 已接受 |

 ## 算法演练

 我们维护三个数组：当前高度a[i]、前缀最大数组f[i]和后缀最大数组g[i]。 我们还将总答案保持为 min(f[i], g[i]) - a[i] 之和。 

核心思想是更新只增加单个位置，因此前缀和后缀最大值只能增加，不能减少。 这种单调性使我们能够修复受影响的区域，而不是重建一切。 

1. 使用单次从左到右和从右到左的遍历构建初始 f[i] 和 g[i]。 根据公式计算初始答案。 
2. 对于每次更新(x, v)，将a[x]增加v并获得其新高度。 
3. 仅在受此增加影响的区域重新计算 f 和 g。 对于f，我们从x开始向右走，更新f[i] = max(f[i], a[x])，直到没有变化发生。 对于 g，我们从 x 向左走，更新 g[i] = max(g[i], a[x]) 直到达到稳定。 

这种情况很快停止的原因是，一旦 f[i] 已经大于或等于 a[x]，右侧的其他位置也将不受影响。 

1.在更新f[i]或g[i]的同时，我们还更新索引i在全局答案中的贡献。 对于每个 f 或 g 发生变化的 i，我们减去其旧的贡献并添加其新的贡献。 
2. 处理每次更新后输出维护的总数。 

### 为什么它有效

 位置 i 处的前缀最大值仅取决于值 a[1..i]，类似地，后缀最大值仅取决于值 a[i..n]。 由于更新仅增加单个位置，因此前缀最大结构通过增加从该位置开始的连续区域直到达到更强的现有最大值而演变。 较早的前缀值不会受到影响，因为左侧的元素不会发生变化。 相同的对称性适用于后缀最大值。

这保证了只有更新索引周围的连续区域可以改变，并且每次改变都是单调递增的。 每个索引的 f[i] 和 g[i] 只能增加有限次数，因为它们受到最终全局最大结构的限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    q = int(input())

    f = [0] * n
    g = [0] * n

    # prefix max
    cur = 0
    for i in range(n):
        cur = max(cur, a[i])
        f[i] = cur

    # suffix max
    cur = 0
    for i in range(n - 1, -1, -1):
        cur = max(cur, a[i])
        g[i] = cur

    ans = 0
    for i in range(n):
        ans += min(f[i], g[i]) - a[i]

    for _ in range(q):
        x, v = map(int, input().split())
        x -= 1

        a[x] += v

        old = min(f[x], g[x]) - (a[x] - v)
        new = min(f[x], g[x]) - a[x]
        ans += new - old

        # repair prefix to the right
        cur = f[x]
        for i in range(x, n):
            if f[i] >= cur:
                break
            oldv = min(f[i], g[i]) - a[i]
            f[i] = cur
            ans -= oldv
            ans += min(f[i], g[i]) - a[i]

        # repair suffix to the left
        cur = g[x]
        for i in range(x, -1, -1):
            if g[i] >= cur:
                break
            oldv = min(f[i], g[i]) - a[i]
            g[i] = cur
            ans -= oldv
            ans += min(f[i], g[i]) - a[i]

        print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该代码维护前缀和后缀最大值数组，并仅更新受每个增量影响的区域。 通过仅在任一边界发生变化时重新计算贡献来增量跟踪答案。 

两个修复循环中的早期中断条件是关键的优化。 一旦现有的前缀最大值已经主导了传播值，其他索引将保持不变并且可以安全地跳过。 

更新贡献时必须小心：在修改 f[i] 或 g[i] 之前必须减去旧值，否则两个最大值之间的重叠会导致错误的计算。 

## 工作示例

 考虑一个小直方图：

 输入：```
5
1 2 1 3 2
```初始前缀和后缀最大值：

 | 我| 一个[我] | f[i] | f[i] 克[我] | 水 |
 | ---| ---| ---| ---| ---|
 | 1 | 1 | 1 | 3 | 0 |
 | 2 | 2 | 2 | 3 | 0 |
 | 3 | 1 | 2 | 3 | 1 |
 | 4 | 3 | 3 | 3 | 0 |
 | 5 | 2 | 3 | 2 | 0 |

 现在在位置 3 应用 +3 更新，因此 a 变为 1 2 4 3 2。 

| 步骤| x| 一个[x] | 受影响的 f | 受影响的 g | 总变化|
 | ---| ---| ---| ---| ---| ---|
 | 初始化| - | - | 计算| 计算| 基地|
 | 更新1 | 3 | 4 | 向右传播| 向左传播 | 重新计算本地|

 更新后，位置 3 成为强峰值，向右增加前缀最大值，直到达到至少 4，并且类似地向左增加后缀最大值。 唯一受影响的区域以更新的索引为中心。 

该迹线表明，只需要从更新点开始的单调传播，并且一旦最大值稳定，就不需要进一步的校正。

 ## 边缘情况

 单元素数组是最简单的应力情况。 没有左边界或右边界，因此前缀和后缀最大值都等于元素本身。 任何更新都会简单地增加两者，并且水保持为零，因为 min(f[i], g[i]) 始终等于 a[i]。 

严格递增数组测试后缀最大值在各处占主导地位的情况。 由于每个前缀最大值已经是当前元素，因此不会捕获任何水。 中间的更新不会产生山谷，因为它们只提高局部值并且不会引入任何有界区域。 

像 1 2 5 2 1 这样的对称峰结构测试传播。 增加中心会增强前缀和后缀最大值，但只有峰值附近的区域会改变贡献，而外部区域保持稳定。 这证实了传播不会错误地超出必要的边界。
