 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，对于每个元素，我们可以重复地增加它的最后一位数字。 例如，如果元素为 27，则应用该运算得到 27 + 7 = 34，再次应用该运算得到 34 + 4 = 38。任务是确定通过对任何元素子集应用此运算任意次数，我们是否可以使所有数组元素相等。 

输入由多个测试用例组成，每个测试用例最多包含 200,000 个元素，所有测试用例的所有元素之和以 200,000 为界。 这意味着算法在所有测试用例的元素总数中必须是最坏的线性，因为任何二次或更高的都会超出时间限制。 

出现不明显的边缘情况是因为操作根据最后一位数字的不同而表现不同。 以 0 结尾的元素永远不会改变，以 5 结尾的元素一步收敛到 10 的倍数，以 1-9 结尾的元素（5 除外）在几个步骤后遵循以 20 为模的循环。 模拟每个数字的每个操作的简单方法很容易超时。 另一个微妙之处是具有不同最后一位数字的元素可能永远不会相遇，例如仅使用此操作无法将 1 和 2 转换为公共值。 

## 方法

 暴力方法是模拟每个元素上的操作，直到它重复先前看到的值或超出某个界限。 这是可行的，因为该操作单调增加值，但当数字很大（最多 10^9）或序列很长时，它会失败，因为模拟所有步骤总共可以达到数亿次操作。 特别是，以 1-9 结尾（除 5 之外）的数字可以在重复模式之前生成 20 个步骤的序列，因此如果我们对每个元素都尝试这样做，暴力破解可能会很慢。 

关键的见解是，数字根据最后一位数字分为两类。 如果一个数字以 0 或 5 结尾，最多经过一次操作，它会达到 10 的倍数。以其他数字结尾的数字最终会进入严格递增的模 20 循环，并且不会与 10 的倍数重叠。因此，只有当所有数字都是 10 的倍数或者可以在其 20 步模循环内对齐时，才能使数组相等。 更具体地说，任何以0或5结尾的数字经过变换后都必须是10的倍数。 对于以 1-9 结尾的数字（5 除外），变换后的数字模 20 必须相等，否则它们永远不可能重合。 

这一观察结果使我们能够快速对数字进行分类，而无需模拟每一步。

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，读取数组长度`n`和数组元素`a`。 
2. 将数组分成两组：以 0 或 5 结尾的数字，以及以 1-9 除 5 以外的数字结尾的数字。这是因为这两组在运算下具有根本不同的行为。 
3. 对于以0或5结尾的数字，最多执行一次运算。 如果任何一个数字以5结尾，经过一次运算就变成10的倍数。 然后检查该组中的所有数字是否都等于 10 的倍数。如果不是，则返回 NO。 
4. 对于除 5 之外的以 1-9 结尾的数字，观察经过重复运算后，所有数字最终都达到 2 mod 20 的全等值。对每个这样的数字进行变换，直到达到最后一位数字 2 的数字。然后检查所有变换后的数字是否相等。 如果是，则返回 YES； 否则，返回NO。 
5. 如果数组包含两个组的混合（0/5 组和 1-9 除 5 组外），则它们永远不能相等。 返回编号

 为什么有效：该操作是单调的，仅取决于最后一位数字。 以 0 或 5 结尾的数字收敛为 10 的倍数，以 1-9 结尾的数字遵循模 20 循环，最后一位数字为 2。由于这个性质，我们可以将数字分类为互斥的类别，这些类别从不相交，并且只有在同一类别内才可能相等。 这个不变量保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_equalize(arr):
    group0 = []
    group1 = []
    for x in arr:
        last = x % 10
        if last == 0 or last == 5:
            if last == 5:
                x += 5
            group0.append(x)
        else:
            while x % 10 != 2:
                x += x % 10
            group1.append(x)
    if group0 and group1:
        return "No"
    if group0:
        return "Yes" if all(x == group0[0] for x in group0) else "No"
    return "Yes" if all(x == group1[0] for x in group1) else "No"

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(can_equalize(a))
```该代码读取每个测试用例并按最后一位数字分隔数字。 以 0 或 5 结尾的数字被标准化为 10 的倍数，以 1-9 结尾的数字被转换，直到最后一位数字变为 2。相等性检查在每个组内执行。 如果两个组都存在于同一测试用例中，则该函数立即返回 NO。
