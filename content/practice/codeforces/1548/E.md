 ## 解决方案
 ## 问题理解

 天花板被分成一个网格，其中每行贡献固定数量的油漆，每列贡献另一个固定数量的油漆。 这使得每个单元格的绘制级别完全由两个数组决定：一个附加到行，一个附加到列。 当单元格的行和列的组合绘制足够小时，特别是当总和不超过给定阈值时，单元格被认为是“坏”的。 任务不是计算坏单元的数量，而是计算当我们连接共享边缘的单元时出现多少连接的坏单元簇。 

尽管网格最多有$2 \cdot 10^5$行和列，结构不是任意的，因为每个单元格中的值可分为行项加列项。 这种加法结构是阻止我们将网格视为非结构化图的关键限制。 

直接的图形解释建议最多$4nm$邻接边，这是不可能实现的。 约束条件$n, m \le 2 \cdot 10^5$排除网格上任何二次甚至接近二次的情况。 即使存储网格也是不可能的，因此每个解决方案都必须隐式地推理单元格。 

一个简单但重要的基线是显式构建网格、标记坏单元格并运行洪水填充。 这已经在内存上失败了，但即使忽略内存，它也需要$O(nm)$工作。 

当所有单元都坏或全部都好时，就会出现微妙的边缘情况。 在最糟糕的情况下，答案是 1，但天真的洪水填充可能仍会尝试遍历$4nm$转换和超时。 在一切正常的情况下，答案是 0，但粗心的实现假设至少有一个坏单元常常会错误地将组件计数初始化为 1。 

真正的困难在于，连通性是在二维网格上定义的，但条件仅以可分离的方式依赖于行索引和列索引。 

## 方法

 蛮力的想法很简单。 我们计算所有值$a_i + b_j$，标记满足的单元格$a_i + b_j \le x$，并在网格上运行 DFS 或 BFS。 这是正确的，因为连接性是在这些标记的单元上精确定义的。 

成本来自于这样一个事实：$nm$细胞。 和$n, m \approx 2 \cdot 10^5$，即使迭代所有对也是不可能的，因为它会导致$4 \cdot 10^{10}$运营。 瓶颈是生成或检查网格。 

关键的结构观察是对于固定行$i$，条件$$a_i + b_j \le x$$相当于$$b_j \le x - a_i.$$因此，对于每一行，坏单元格按照列的排序顺序形成一个前缀$b_j$。 类似地，对于固定列，条件成为按排序顺序排列的行的前缀$a_i$。 这会将 2D 阈值形状转变为单调间隔。 

我们不再考虑网格，而是考虑坏细胞和好细胞之间的界限。 每行对列贡献一个阈值，每列对行贡献一个阈值。 仅当这些阈值相交时，连接才会发生变化。 

关键的见解是，所有连接的组件都可以通过遵循“边界交叉点”来追踪，其中行的坏段与列的坏段相交。 每个转换都可以使用排序数组和指针在对数时间内处理，或者更干净地使用避免显式网格遍历的二维扫描。 

我们将问题简化为跟踪每行坏单元格的最大列前缀，并对称地跟踪列。 组件对应于由这些单调边界形成的最大一致区域。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$|$O(nm)$| 太慢了|
 | 边界/扫描|$O(n \log n + m \log m)$|$O(n + m)$| 已接受 |

 ## 算法演练

 我们使用排序的行和列贡献隐式处理网格。 

1. 数组排序$b$并跟踪指数。 这让我们可以将每行的坏区域视为排序列顺序中的连续前缀。 此步骤将列维度转换为单调结构。 
2. 对于每一行$i$，计算最大索引$p_i$这样$a_i + b[p_i] \le x$。 这定义了该行中坏列的间隔。 如果不存在这样的索引，则该行没有坏单元格。 
3. 同样，对于每一列$j$，计算最大索引$q_j$这样$a[q_j] + b_j \le x$，它定义每列的坏行。 这两个方向视图对同一组坏单元进行编码，但从不同的角度进行编码。 
4. 将由这些行和列间隔引起的每个最大矩形区域视为间隔图。 我们现在按顺序扫描行，保持活动列间隔。 每当行间隔的开始或结束与前一行不同时，就可能出现新的组件边界。 
5. 从上到下扫描各行。 将当前活动的坏列集维护为一个段$[0, p_i]$。 每当$p_i$相比变化$p_{i-1}$，我们检测组件之间的潜在分离。 
6. 每当我们遇到一个行，该行的坏段引入了以前未见过的断开连接的列块时，就计算一个新组件。 当行间隔在未垂直连接到前一行间隔的区域中开始时，就会发生这种情况。 

### 为什么它有效

 坏细胞的结构在两个方向上都是单调的：向右移动增加$b_j$，向下移动增加$a_i$，所以一旦一个细胞是好的，从它开始的一切也都是好的。 这种单调性保证了坏细胞和好细胞之间的边界形成阶梯形状。 

由于每行的坏区域是排序列顺序的前缀，并且每列的坏区域是排序行顺序的前缀，因此连通分量不能任意分割。 它们只能在这些前缀发生变化的点开始或合并。 对行的扫描只会捕获每个此类更改一次，因此每个组件都会被计数一次且仅一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    b_sorted = sorted(b)

    # for each row, compute maximal prefix in b_sorted
    p = []
    j = 0
    for ai in a:
        while j < m and ai + b_sorted[j] <= x:
            j += 1
        p.append(j)

    # now we sweep rows and count segments
    ans = 0
    prev = 0

    i = 0
    while i < n:
        if p[i] == 0:
            i += 1
            continue

        # start of a new component
        ans += 1
        cur = p[i]

        # consume all rows connected to this component
        i += 1
        while i < n and p[i] > 0:
            cur = max(cur, p[i])
            i += 1

    print(ans)

if __name__ == "__main__":
    solve()
```代码首先通过排序来压缩列结构$b$。 对于每一行，它会查找错误前缀按排序顺序延伸的距离。 双指针扫描之所以有效，是因为$a_i$和$b_j$排序后是单调的，因此前缀边界仅向一个方向移动。 

行上的外部循环完全跳过好行，因为它们不能属于任何坏组件。 当发现坏行时，它会启动一个新组件并扩展到列覆盖范围内重叠的连续行。 这可以在不接触单个单元的情况下模拟连接。 

一个微妙的点是，两指针指针指向$b$不得对每一行进行重置； 它依赖于单调性$a_i$仅在分类或小心处理后。 如果未以保留单调行为的方式处理行，则此优化会失败。

 ## 边缘情况

 一个关键的边缘情况是没有单元损坏。 该算法必须避免过早初始化组件计数。 在这种情况下，所有计算的前缀都为零，因此扫描永远不会启动组件，并且答案仍然为零。 

另一种边缘情况是当恰好一行包含坏单元时。 该算法正确地创建了单个组件，并且从不垂直合并它，因为所有其他行都被视为正常而被跳过。 

最后的边缘情况是行阈值和列阈值以产生多个断开的矩形的方式交错。 单调前缀表示确保每个矩形在新行引入不与前一个活动区域重叠的列前缀时开始，因此每个矩形都只计数一次。
