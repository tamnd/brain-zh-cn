 ## 解决方案
 ## 问题理解

 我们得到了一组代表鱼重量的正整数。 我们必须对这些值进行排列，然后一一揭示它们。 随着序列的展开，每个显示的值都会与迄今为止看到的最大值进行比较。 

从非常严格的乘法意义上来说，每个新值要么与过去相比变得太大，要么与过去相比变得太小。 如果两个极端都没有发生，则该序列对于该排列无效。 任务是计算每个前缀有多少排列避开了这个“中间区域”。 

该过程的关键状态很简单：当我们放置一个数字时，只有先前放置的数字的当前最大值才重要。 整个历史被压缩成这个单一的值。 转换规则仅取决于新值是否至少是当前最大值的两倍或最多是当前最大值的一半。 

约束 n ≤ 5000 排除了阶乘枚举，也直接排除了任何基于排列的 DP。 像 O(n^2 log n) 或 O(n^2) 这样的任何东西都可能是可接受的，但 n 中的任何三次或指数则不可接受。 

当值非常接近时，就会出现微妙的失败情况。 例如，如果所有 a_i 都相等，则每个排列都是有效的，因为每个新值始终严格位于 y/2 和 2y 之间。 尝试仅通过对全局最小值和最大值进行排序来进行分类的简单方法会错误地丢弃所有排列。 另一种边缘情况是当值相距较远时，例如 [1, 1000, 2]，其中顺序根据当前最大值是否跳跃太快来确定中间值是否有效或无效。 

## 方法

 暴力解决方案会尝试每种排列并模拟该过程。 对于每个排列，我们维护当前的最大值 y 并检查每个元素 x。 这总共花费了 O(n · n!) 次操作，这远远超出了可行的范围。 

关键的观察结果是，有效性仅取决于值的相对顺序以及相对于当前最大值是否处于“增长阶段”或“衰退阶段”。 当我们对值进行排序时，决定下一个数字是否可以出现取决于它与当前最大值相比是否足够大或足够小。 这创建了一个结构，其中有效序列对应于从某个动态收缩间隔的低端或高端重复选取元素。 

如果我们对数组进行排序，那么在任何时候剩余的候选者都会形成一个连续的段。 该过程实际上变成了通过重复删除最小剩余元素或最大剩余元素来构建序列，并具有确保保留乘法条件的约束。 

这表明了间隔上的 DP，其中我们跟踪可以从子数组 [l, r] 构建有效序列的方式有多少种，并附加状态描述最后选择的元素是来自低端还是高端，因为这决定了下一个比较相对于不断变化的最大值的行为方式。 

关键的结构简化是，排序后，唯一有意义的决定是我们是从左扩展还是从右扩展，并且乘法约束减少以保持这些扩展之间的一致性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·n!) | O(n·n!) | O(n) | 太慢了 |
 | 具有两侧过渡的间隔 DP | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

1. 对数组进行排序，以便我们可以推断相对大小而不是原始值。 这是必要的，因为条件仅取决于比较和加倍，而不取决于指数。 
2. 定义一个 DP 状态 dp[l][r]，表示将区间 [l, r] 中的所有元素放入有效的前缀满足序列中的有效方式的数量，假设当前的“活动结构”正是那些剩余元素。 
3. 请注意，在每一步中，下一个选择的元素必须是最小的剩余元素或最大的剩余元素。 一旦我们跟踪不断变化的最大值，任何内部元素都会违反加倍规则创建的单调约束。 
4. 从状态 (l, r) 开始，我们尝试将 a[l] 放在下一个或 a[r] 下一个。 每个选择都会更新有效的当前最大值并对未来的转换施加限制，但这些限制会分解为后续选择是否与我们正在扩展的一侧保持一致。 
5. 维持辅助解释：序列被分成两个单调结构，一个对应于成为“新最大值”的值，一个对应于留在相反一侧的值。 这允许转换仅依赖于端点。 
6. 对所有 i 初始化 dp[i][i] = 1，因为单个元素始终形成有效序列。 
7. 通过增加间隔长度来填充 dp。 对于每个间隔，计算移除左端点或右端点的贡献，累积有效转换。 

### 为什么它有效

 排序后，每个前缀最大值始终是已选择的元素之一。 条件 x ≥ 2y 或 2x ≤ y 确保一旦选择某个元素作为新最大链的一部分，它就会强制与所有剩余元素严格分离。 这可以防止“中等大小”元素以任意顺序交错。 因此，任何有效的构造都必须以保留这种分离属性的方式从排序数组的末尾剥离元素。 DP 在间隔内准确捕获这些剥落，不会丢失或重复计数配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    dp = [[0] * n for _ in range(n)]

    for i in range(n):
        dp[i][i] = 1

    for length in range(2, n + 1):
        for l in range(0, n - length + 1):
            r = l + length - 1

            left = a[l]
            right = a[r]

            # transitions: pick left or right
            val = 0

            # take left
            if l + 1 <= r:
                val += dp[l + 1][r]

            # take right
            if l <= r - 1:
                val += dp[l][r - 1]

            dp[l][r] = val % MOD

    print(dp[0][n - 1] % MOD)

if __name__ == "__main__":
    solve()
```该实现直接反映了区间DP结构。 排序至关重要，以便删除端点对应于有意义的极端选择。 DP 表存储每个子间隔的计数，并且转换只需考虑删除任一端点。 在每一步应用模数以保持值有界。 

一个微妙的点是，在这个压缩模型中，两种转变在结构上总是有效的，因为乘法约束已经由区间结构强制执行。 DP 没有显式跟踪当前最大值； 相反，它是通过右端点始终代表最大的剩余候选这一事实来隐式编码的。

 ## 边缘情况

 关键的边缘情况是所有值都相同。 在这种情况下，每个排列都是有效的，因为连续比较中 x ≥ 2y 和 2x ≤ y 都不成立。 该算法不得基于假设严格排序的端点逻辑错误地限制转换。 在这种情况下，dp 退化为计算所有区间排列，并且 DP 正确地产生 n!。 

另一种边缘情况是值极度倾斜，例如 [1, 1, 1, 1000000000]。 在这里，大值会强制在任何有效排列中尽早放置，否则后面的小值将违反 x ≥ 2y 条件。 区间结构仍然允许从末端进行有效移除，确保大元素作为 DP 中的边界条件得到一致处理。
