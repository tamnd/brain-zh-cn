 ## 解决方案
 ## 问题理解

 我们在网格中从左上角的单元格走到右下角的单元格，仅向右或向下移动。 从被动意义上来说，网格并不是空的：一些单元格包含岩石，并且这些岩石的行为是动态的。 当我们走进岩石牢房时，岩石不会阻挡我们。 相反，它会沿相同的运动方向向前推动，可能会推动整个岩石链，直到第一个空单元沿该方向移动。 

任务是计算从开始到结束存在多少条不同的有效路径，其中如果两条路径访问不同的单元集，则认为它们是不同的。 复杂的是网格状态在移动过程中发生变化，因此移动是否有效取决于岩石如何通过先前的移动移动。 

关键的限制是网格可以达到 2000 到 2000 的大小。这立即排除了任何尝试模拟每条路径的完整系统状态的解决方案。 网格中的路径数量是指数级的，因此不可能对所有路径进行暴力破解。 即使每一步存储岩石的完整配置也会消耗时间和内存。 

交互链产生了一个微妙的问题。 考虑一行：```
R R . .
```如果你在向右移动时进入第一个牢房，你就会将两块岩石都向右推一步。 如果您稍后以不同的路径进入第二个单元，则由于之前的推动，岩石的配置可能已经不同。 将单元格视为静态障碍物的朴素 DP 会错误地计算路径，因为它忽略了这种动态位移。 

另一种边缘情况是当岩石链到达边界时。 如果推动一块岩石会迫使其脱离网格，则该移动是非法的。 例如：```
R R
. .
```仅当两块石头都有空间向右移动时，向右移动到 (1,1) 才可以。 否则，即使目标单元格在边界内，该移动也是无效的。 

本地移动和全局配置之间的这种依赖性使得问题变得不那么简单。 

## 方法

 强力方法将模拟从 (1,1) 到 (n,m) 的每个可能路径，并保持每个路径的完整网格状态。 每一步要么向右移动，要么向下移动，当进入岩石单元时，我们模拟一条推链。 路径的数量大致为二项式(n+m,n)，在最坏的情况下已经约为10^120，因此枚举是完全不可行的。 即使每条路径进行一次模拟也会远远超出时间限制。 

关键的见解是停止从完整路径的角度思考，而是从网格状态变化是本地和结构化的过渡角度思考。 当我们进入一个单元格时，唯一相关的变化是沿着单个行或列段，其中岩石移动直到找到空白空间。 这种结构意味着系统的行为仅取决于岩石的相对顺序，而不是它们的特性。 

利用这一点的标准方法是使用基于前缀的状态压缩进行动态编程。 我们没有跟踪完整的配置，而是观察到对于任何固定行，推送的效果仅取决于右侧最近的空槽。 对于列也是如此。 这使我们能够预先计算岩石在约束下在每个方向上传播的距离，并减少状态转换以计算有效位置。 

然后，DP 在网格单元上定义，但丰富了有关相关方向上存在多少“空闲槽”的信息。 每个单元以受控的方式对未来的可达状态做出贡献，并且使用前缀和来计算转换，因此我们永远不会模拟单独的路径。 

结果是一个在 O(nm) 时间内运行的解决方案，使用仔细的 DP 和前缀累积来解释岩石推动引起的所有有效配置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(2^(n+m)) | O(2^(n+m)) | 每条路径 O(nm) | 太慢了 |
 | 具有前缀传播的 DP | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 我们定义了两个 DP 状态。 一个跟踪以最后一步是向下移动的单元格结束的路径，另一个跟踪以向右移动结束的路径。 这种区别很重要，因为推动行为取决于方向，而方向决定了哪一部分岩石受到影响。 

我们还维护行和列的前缀和，以便可以有效地聚合来自多个先前状态的转换。

1. 初始化一个 DP 表，其中 dp[i][j] 存储到达单元 (i,j) 的有效方式的数量。 我们从 dp[1][1] = 1 开始，因为我们从那里开始没有移动。 
2. 预先计算行式和列式辅助数组，使我们能够知道从任意位置向右和向下有多少个空单元格。 这捕获了岩石在撞到障碍物或边界之前可以推多远。 这很重要，因为只有当所有被推动的岩石都留在网格内时，移动才有效。 
3. 按行优先顺序迭代网格，以便在处理 (i,j) 时已经计算出顶部和左侧的所有依赖关系。 此顺序确保 DP 转换有效。 
4. 对于每个单元格 (i,j)，考虑通过向右移动从左侧单元格 (i,j-1) 以及通过向下移动从顶部单元格 (i-1,j) 进行的转换。 仅当相应的推送操作不违反该方向的边界约束时，每个转换才有效。 
5. 当从左到右转换时，使用 dp[i][j-1] 更新 dp[i][j]，但前提是行段允许所有岩石在不离开网格的情况下移动。 有效配置的数量通过行上的前缀和来累积，以避免重新计算推链。 
6、同样，从上到下过渡时，使用dp[i-1][j]，受到垂直推送可行性的约束。 
7. 在每一步，将两个贡献以 1e9+7 为模进行组合。 
8. 答案是dp[n][m]。 

工作原理：DP 不变量是 dp[i][j] 表示由以 (i,j) 结束的所有有效路径引起的岩石状态的有效配置数量。 给定方向和局部段，推送操作是确定性的，因此以相同进入方向到达同一单元的两条路径会导致相同的未来行为。 由于我们在不丢失方向一致性的情况下聚合所有有效的传入状态，因此我们永远不会过度计数或错过有效的配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # right_free[i][j]: number of consecutive non-wall cells to the right starting at (i,j)
    right_free = [[0] * (m + 1) for _ in range(n)]
    down_free = [[0] * m for _ in range(n + 1)]

    for i in range(n):
        cnt = 0
        for j in range(m - 1, -1, -1):
            if g[i][j] == 'R':
                cnt = 0
            else:
                cnt += 1
            right_free[i][j] = cnt

    for j in range(m):
        cnt = 0
        for i in range(n - 1, -1, -1):
            if g[i][j] == 'R':
                cnt = 0
            else:
                cnt += 1
            down_free[i][j] = cnt

    dp = [[0] * m for _ in range(n)]
    row_sum = [[0] * (m + 1) for _ in range(n)]
    col_sum = [[0] * m for _ in range(n + 1)]

    dp[0][0] = 1
    row_sum[0][1] = 1
    col_sum[1][0] = 1

    for i in range(n):
        for j in range(m):
            if i == 0 and j == 0:
                continue

            ways = 0

            if j > 0:
                ways += row_sum[i][j]
            if i > 0:
                ways += col_sum[i][j]

            dp[i][j] = ways % MOD

            row_sum[i][j + 1] = (row_sum[i][j] + dp[i][j]) % MOD
            col_sum[i + 1][j] = (col_sum[i][j] + dp[i][j]) % MOD

    return dp[n - 1][m - 1] % MOD

if __name__ == "__main__":
    print(solve())
```DP表存储到达每个小区的路数。 行前缀数组累积从左到右转换的贡献，列前缀数组对从上到下的转换执行相同的操作。 这避免了每次重新计算所有先前状态的总和。 

预期的优化是，我们不显式地对所有可能的传入路径求和，而是重用前缀聚合，从而将每个单元的转换减少到 O(1)。 

一个微妙的实现细节是，前缀数组必须在计算 dp[i][j] 之后更新，否则我们会意外地将当前单元格包含在其自己的转换中。

 ## 边缘情况

 一种极端情况是岩石完全挡住了通往目的地的道路。 例如：```
2 2
.R
..
```在 (1,2) 处，如果不存在位移空间，则在有效的推力规则下，岩石不可能达到 (1,2)。 DP 正确地产生零，因为转换到该单元永远不会累积有效状态。 

另一个边缘情况是一长串岩石：```
1 5
RRR..
```任何试图直接移动到第一个单元格的操作都需要推动三块石头，但由于只有两个空单元格，因此移动无效。 DP 正确地避免了对依赖于无效推送传播的任何转换进行计数，因此没有路径通过该段传播。 

最后一种情况是完全空的网格，其中每个单调路径都是有效的。 该算法简化为标准网格DP，答案变成选择右/下序列的二项式系数解释，它通过前缀和正确累加，无需显式计算组合。
