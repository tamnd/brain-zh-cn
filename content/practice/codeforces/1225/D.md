 ## 解决方案
 ## 问题理解

 给定一个正整数序列，并要求我们计算有多少对索引产生的乘积是完美的 k 次方。 换句话说，对于两个不同的元素$a_i$和$a_j$，我们想知道他们的产品是否可以写成$x^k$对于某个整数$x$。 

关键的困难不是检查单个对，而是在以下情况下有效地计算所有有效对：$n$很大。 直接的成对检查将涉及检查两个数字的所有组合并验证它们的乘积是否是完美的 k 次幂，当数组大小达到$10^5$。 

价值观的约束，$a_i \le 10^5$，是关键的结构提示。 它表明基于因式分解的预处理是可能的，并且我们可以以受控的方式用素数指数来表示每个数字。 

最微妙的边缘情况来自数字 1。$1 \cdot x = x$， 和$1$始终是任意的完美 k 次幂$k$，它与每一个“自我补充”结构都有微不足道的相互作用。 例如，当所有元素均为 1 时，每对都有效。 任何忽略指数标准化的解决方案通常都会错误计数或错误处理这种情况。 

## 方法

 暴力解决方案迭代所有对$(i, j)$，计算乘积$a_i a_j$，并检查它是否是完美的 k 次方。 检查完美幂需要重复求根或对乘积进行完全质因数分解。 即使检查单个数字是有效的，对的数量也是如此$\Theta(n^2)$，达到$5 \cdot 10^9$的上限操作$10^5$，远远超出了极限。 

关键的结构观察是乘积的条件可以转化为素数指数的条件。 如果我们对每个数字进行因式分解：$$a = p_1^{e_1} p_2^{e_2} \cdots$$然后是产品$a_i a_j$是完美的 k 次幂当且仅当对于每个素数，指数之和可被整除$k$。 这将乘法变成了指数向量的模运算。 

这建议用一个简化的“签名”来表示每个数字，该“签名”捕获其指数模$k$。 然而，仅仅模数归约是不够的，因为我们需要配对互补的指数向量：一个数字贡献某些残基，另一个数字必须提供缺失的残基，以便总数可以被整除$k$。 

对于每个数字，我们通过对其进行质因数分解并减少模数指数来构建规范表示$k$。 然后我们将其标准化为一种唯一表示达到完整 k 次幂所需的形式。 如果一个数字的签名恰好是另一个数字的反补码，则两个数字形成有效对。 

这将问题简化为计算签名频率并使用哈希映射将每个签名与其补码进行匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2 \cdot \sqrt{A})$|$O(1)$| 太慢了 |
 | 因式分解 + 散列 |$O(n \log A)$|$O(n)$| 已接受 |

 ## 算法演练

 我们预先计算所有数字的最小质因数$10^5$，它允许快速分解每个元素。 

然后，我们处理每个数字并根据其素数指数模构建一个简化签名$k$。 对于每个素数指数$e$，我们计算$e \bmod k$。 如果余数不为零，则它有助于签名； 否则，它不会做出任何贡献，因为它已经与第 k 个权力结构对齐。 

我们存储迄今为止看到的签名的频率图。 对于每个新数字，我们计算其补码签名，它表示前一个数字形成有效对所需的精确残基配置。 我们将该补集的当前频率添加到答案中，然后将当前签名插入到映射中。 

### 步骤

 1. 预先计算所有整数的最小素因数 (SPF)$10^5$。 这确保了每个数字都可以用对数时间而不是试除法来分解。 
2. 对于每个数字，使用 SPF 将其分解，并通过记录每个素数指数模来计算简化签名$k$。 
3. 将签名转换为规范的可哈希形式，通常是排序的元组$(prime, remainder)$对。 
4. 通过替换每个余数构建补码签名$r$和$(k - r) \bmod k$。 这确保指数和可以被整除$k$。 
5. 维护一个字典，计算每个签名出现的次数。 
6. 对于每个元素，将其补码签名的计数添加到答案中，然后更新其自身的频率。 

### 为什么它有效

 核心不变量是每个存储的签名代表所有先前处理的数字的残差结构。 当我们处理一个新数字时，我们只计算对，其中较早的数字恰好提供了完成倍数所需的缺失模指数$k$。 由于素数分解是唯一的，并且每个素数的指数加法是独立的，因此匹配补码保证了乘积中的每个素数指数都可以整除$k$。 无法计算无效对，因为即使是单个素数指数中的任何不匹配都会破坏模条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 100000

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXV + 1, step):
            if spf[j] == j:
                spf[j] = i

def factor_signature(x, k):
    sig = []
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        cnt %= k
        if cnt:
            sig.append((p, cnt))
    return tuple(sig)

n, k = map(int, input().split())
arr = list(map(int, input().split()))

freq = {}
ans = 0

for x in arr:
    sig = factor_signature(x, k)

    comp = []
    for p, r in sig:
        comp.append((p, (k - r) % k))
    comp = tuple(sorted(comp))

    ans += freq.get(comp, 0)
    freq[sig] = freq.get(sig, 0) + 1

print(ans)
```SPF 筛为快速重复分解构建了紧凑的表示形式。 每个数字都通过重复除以其最小素因数来分解，确保所有数字的总成本保持有效。 

签名构建步骤仅保留非零残基，这可以防止冗余存储并确保等效数字共享相同的表示。 

补码构造是关键的正确性步骤：对于每个素数指数余数$r$，我们计算缺少的内容以达到倍数$k$。 对对进行排序可确保元组是规范的且可散列的。 

频率字典跟踪到目前为止每个签名出现的次数，从而实现有效对的增量计数。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MAXV = 100000
    spf = list(range(MAXV + 1))
    for i in range(2, int(MAXV ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factor_signature(x, k):
        sig = []
        while x > 1:
            p = spf[x]
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            cnt %= k
            if cnt:
                sig.append((p, cnt))
        return tuple(sig)

    n, k = map(int, input().split())
    arr = list(map(int, input().split()))

    freq = {}
    ans = 0

    for x in arr:
        sig = factor_signature(x, k)
        comp = tuple(sorted((p, (k - r) % k) for p, r in sig))
        ans += freq.get(comp, 0)
        freq[sig] = freq.get(sig, 0) + 1

    return str(ans)

# provided sample
assert run("6 3\n1 3 9 8 24 1\n") == "5"

# all ones
assert run("5 4\n1 1 1 1 1\n") == "10"

# powers of two, k=2
assert run("4 2\n2 4 8 16\n") == "4"

# mixed primes
assert run("5 3\n2 3 5 7 11\n") == "0"

# single prime complement pairs

 ## 边缘情况

 全 1 的情况是最敏感的，因为签名对于每个元素都变为空。 该算法将所有的都映射到相同的签名，并通过频率累积正确地计算所有对组合。 对于 5 个，频率演变为 0、1、2、3、4、5 贡献，产生$\binom{5}{2} = 10$对。 

当所有数字都是单个素数的幂时，签名会简化为单个指数模$k$。 该算法有效地成为循环群中的模块化配对，并且补码始终是明确定义的。 

当数字包含其指数已经是倍数的素数时$k$，这些素数从签名中完全消失。 这确保了完全“干净”的数字通过空签名正确地相互匹配，而不需要特殊的大小写。
