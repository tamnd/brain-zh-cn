 ## 解决方案
 ## 问题理解

 我们收到了下一场的电视节目表`n`天。 每天只播放一个节目中的一集，用整数表示。 

订阅是按节目购买的，而不是按集购买的。 如果我们订阅节目`x`，我们可以观察每一次发生的情况`x`在日程表中。 

目标是找到所需的节目订阅的最小数量，以便至少存在一个块`d`连续几天，每个播出的剧集都属于我们订阅的节目。 

纵观一段`d`连续几天，该部分所需的订阅数量只是其中出现的不同节目的数量。 如果某个节目在该片段中出现多次，一份订阅仍可涵盖所有节目。 

这一观察将问题转化为一个简单得多的问题：

 对于每个长度连续的子数组`d`，计算它包含多少个不同的值。 答案是所有长度中最小的这样的计数 -`d`视窗。 

硬版本允许所有的总和`n`跨测试用例达到`2·10^5`。 为每个窗口从头开始重新计算不同元素的解决方案大约需要`O(n·d)`工作。 当两个值都很大时，这大约变成`4·10^10`操作，在2秒的限制内是完全不可能的。 

这些约束强烈建议每个测试用例采用线性或近线性解决方案。 

一些边缘情况很容易被错误处理。 

考虑：```
n = 5, d = 3
1 1 1 1 1
```每个窗口只包含一个不同的节目，所以答案是`1`。 计算元素而不是不同值的粗心实现将错误地返回`3`。 

考虑：```
n = 5, d = 1
1 2 3 4 5
```每个长度为 1 的窗口恰好包含一个节目，所以答案是`1`。 当窗口大小尽可能小时，滑动窗口逻辑中的相差一错误通常会出现。 

考虑：```
n = 4, d = 4
1 2 3 4
```只有一个有效窗口。 答案是整个数组中不同元素的数量，即`4`。 总是尝试至少滑动一次的实现可能会访问数组外部的元素。 

考虑：```
n = 6, d = 3
1 2 1 3 3 3
```窗口包含：```
[1,2,1] -> 2 distinct
[2,1,3] -> 3 distinct
[1,3,3] -> 2 distinct
[3,3,3] -> 1 distinct
```答案是`1`。 如果当元素离开窗口时频率没有正确减少，则非重复计数可能会永久膨胀。 

## 方法

 最直接的解决方案是检查每个长度的窗口`d`独立。 

对于每个起始位置，我们收集所有`d`值，将它们插入到集合中，并记录集合大小。 所有窗口的最小设置大小就是答案。 

这是有效的，因为集合会自动删除重复项，因此其大小等于该窗口所需的订阅数量。 

问题是效率。 大约有`n`窗口，每个窗口最多可以包含`d`元素。 复杂度变为`O(n·d)`。 和`n = 2·10^5`，这太慢了。 

关键的观察结果是连续的窗口严重重叠。 

假设当前窗口是：```
a[l], a[l+1], ..., a[r]
```当我们向右移动一个位置时，只有两件事发生变化：```
a[l] leaves
a[r+1] enters
```所有其他元素都保留在窗口内。 

我们不是从头开始重新计算不同的值，而是维护当前存在的元素的频率计数。 当一个元素进入时，我们会增加它的频率。 当一个元素离开时，我们会降低它的频率。 

仅当频率在零和一之间转变时，不同元素的数量才会发生变化。 

如果进入元素的频率从`0`到`1`，一个新的独特的节目出现了。 

如果离开元素的频率从`1`到`0`，一个明显的表演消失了。 

这让我们可以在恒定时间内更新不同的计数，同时在数组上滑动窗口。 

结果是在线性时间内运行的经典滑动窗口解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·d) | O(d) | 太慢了 |
 | 最优滑动窗口| O(n) | O(d) 到 O(n) | 已接受 |

 ## 算法演练

 1. 为当前窗口创建频率字典。 
2.插入第一个`d`元素放入字典中。 
3. 维护一个变量`distinct`代表窗口中当前出现的不同节目数量。 

每当一个值的频率从`0`到`1`, 增量`distinct`。 
4. 构建第一个窗口后，用以下命令初始化答案`distinct`。 
5. 将窗口一次滑动一个位置。 
6.让`out = a[i-d]`是离开窗口的元素。 

降低其频率。 
7. 如果频率`out`变为零，递减`distinct`。 

该节目不再出现在窗口中。 
8.让`in = a[i]`是进入窗口的元素。 
9. 如果其频率当前为零，则增加`distinct`。 

该节目将在窗口中重新呈现。 
10.增加频率`in`。 
11. 用当前值的最小值更新答案并`distinct`。 
12.处理完所有窗口后，输出答案。 

### 为什么它有效

 在每一个时刻，频率字典都准确地包含当前存在于活动长度中的元素-`d`窗户。 

变量`distinct`等于频率为正的键的数量。 这正是窗口中出现的不同节目的数量。 

每一个可能的长度-`d`窗口被检查一次。 对于每个窗口，我们准确地知道其不同显示计数，并且我们保留所有窗口中的最小值。 

由于问题的答案是任意长度中出现的不同节目的最小数量 -`d`段，算法总是返回正确的结果。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    t = int(input())
    answers = []

    for _ in range(t):
        n, k, d = map(int, input().split())
        a = list(map(int, input().split()))

        freq = defaultdict(int)
        distinct = 0

        for i in range(d):
            if freq[a[i]] == 0:
                distinct += 1
            freq[a[i]] += 1

        ans = distinct

        for i in range(d, n):
            out = a[i - d]
            freq[out] -= 1
            if freq[out] == 0:
                distinct -= 1

            inn = a[i]
            if freq[inn] == 0:
                distinct += 1
            freq[inn] += 1

            ans = min(ans, distinct)

        answers.append(str(ans))

    sys.stdout.write("\n".join(answers))

if __name__ == "__main__":
    solve()
```频率字典存储每个节目在当前窗口中出现的次数。 

第一个循环构建初始长度窗口`d`。 在插入元素时，我们检测某个节目是否是第一次出现。 这保留了`distinct`与独特节目的实际数量同步。 

滑动阶段每次移动都会删除一个元素并添加一个元素。 顺序很重要。 我们首先更新传出元素的频率并可能减少`distinct`。 然后我们处理传入的元素并可能增加`distinct`。 

条件检查使用到零的转换。 当节目的频率为正时，它就会对非重复计数做出贡献。 

不存在整数溢出问题，因为所有计数最多为`d`。 

该实现自然地处理所有边界情况。 如果`d = n`，滑动循环永远不会运行，并且第一个窗口已经代表唯一的有效段。

 ## 边缘情况

 ### 所有值相同

 输入：```
1
5 10 3
7 7 7 7 7
```第一个窗口有频率`{7:3}`和`distinct = 1`。 

每张幻灯片都会删除一个`7`并添加另一个`7`，因此频率永远不会达到零并且不同计数仍然存在`1`。 

该算法输出：```
1
```这是正确的，因为一份订阅涵盖了每一天。 

### 窗口大小等于数组大小

 输入：```
1
4 10 4
1 2 3 4
```初始窗口已经包含整个数组。 

频率图变为：```
{1:1, 2:1, 3:1, 4:1}
```所以`distinct = 4`。 

滑动循环不执行，因为没有附加窗口。 答案依然存在`4`，这是正确的。 

### 最佳窗口出现在最后

 输入：```
1
6 6 3
1 2 1 3 3 3
```窗口包含不同的计数：```
2, 3, 2, 1
```最小值出现在最后一个窗口中。 

随着算法的滑动，频率会逐渐更新。 当最后一个窗口`[3,3,3]`已达到，仅显示`3`保持正频率，所以`distinct`变成`1`。 

答案更新为`1`，确认没有跳过任何窗口。 

### 频率降至零

 输入：```
1
4 4 2
1 2 2 2
```初始窗口：```
[1,2]
distinct = 2
```滑动后：```
remove 1 -> frequency becomes 0
distinct decreases to 1

add 2 -> frequency already positive
distinct stays 1
```新窗口`[2,2]`正确地只包含一个不同的节目。 

这种情况验证了算法中最重要的转换，从活动窗口中完全删除一个值。
