 ## 解决方案
 ## 问题理解

 我们有一套$n$黑板上的正整数和一个数字$k \ge 2$。 没有一个整数可以被整除$k$。 我们可以重复选择任意两个数字$x$和$y$，擦除它们，然后写入$f(x+y)$反而。 功能$f$反复除以$k$直到结果不再能被整除$k$。 目标是执行一系列这些操作，以便只剩下一个数字，并且该数字是$1$。 

输入包括$n$16 以内且总和不超过 2000 的数字。$n$立即表明我们可以探索数组子集的指数解。 总和最多为 2000 的限制暗示我们可以有效地跟踪总和和中间数字。 功能$f$引入非线性，因为将两个数字相加并减少$k$可以产生小于总和的数字。 仅以任意顺序对对求和的粗心贪婪方法可能无法达到 1。 

边缘情况包括所有数字均为 1 的情况，或者选择的数字使得总和的组合不会减至 1 的情况。例如，$n = 2$,$k = 3$，和数字$[2, 2]$，唯一的和是 4，它会减少到 4，因为它不能被 3 整除。那么最终的数字是 4，而不是 1。天真的算法可能会错误地假设重复组合数字总是将它们减少到 1。 

## 方法

 暴力方法将尝试所有可能的组合对序列。 由于有$n-1$操作，每个操作最多有$\binom{m}{2}$选择越多，序列的数量就会呈阶乘增长。 具体来说，有$\prod_{i=2}^{n} \binom{i}{2}$可能的操作序列，即使对于$n = 16$。 这种方法原则上是正确的，但速度太慢。 

关键的观察是操作$f(x+y)$仅取决于模幂总和$k$。 我们可以预先计算$f(s)$为所有人$1 \le s \le 2000$。 自从$n \le 16$，我们可以对子集使用动态规划方法。 对于初始数字的每个子集，我们可以跟踪可以从该子集中获得的所有可能值。 每次我们组合子集中的两个数字时，我们都会考虑它们的总和并使用$f$。 这将问题简化为探索所有子集及其可实现的值。 

这种见解使用位掩码将问题转化为子集上的可管理 DP，因为$2^{16} = 65536$，这是可行的。 如果 1 是可实现的，则存储每个子集的可实现值允许我们重建操作序列。 位掩码自然也允许我们使用父指针追溯操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n! \cdot n^2)$|$O(n)$| 太慢了 |
 | 子集上的DP |$O(2^n \cdot S^2)$,$S \le 2000$|$O(2^n \cdot S)$| 已接受 |

 ## 算法演练

 1. 预计算函数$f(x)$为所有人$x \le 2000$。 对于每个数字，重复除以$k$直到它不再可分为止。 将结果存储在数组或字典中。 
2. 使用位掩码来表示初始数字的子集。 对于每个子集，维护所有可实现数字的字典。 初始化每个单例子集$\{a_i\}$与号码$a_i$。 
3. 迭代大小大于 1 的子集。对于每个子集，考虑将其拆分为两个非空不相交子集。 对于这两个部分中的每一对可实现的数字，计算$f(x+y)$并将其添加到当前子集的可实现值中。 
4. 使用父指针跟踪生成每个新值的操作。 这允许在 DP 完成后重建移动顺序。 
5. 处理完所有子集后，检查整个集合（所有数字）是否具有 1 作为可实现值​​。 如果没有，则打印“NO”。 
6. 如果 1 是可实现的，则通过从完整集合向下跟踪父指针到单例子集来重建操作序列，记录每一步组合了哪两个数字。 

工作原理：在每一步中，DP 都会正确记录每个子集的所有可能结果。 因为我们考虑了所有不相交的子子集对，所以不会错过任何可实现的值。 不变的是每个子集的 DP 字典恰好包含从该子集可获得的数字。 这保证了如果可以达到 1，算法就会找到它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def f(x, k):
    while x % k == 0:
        x //= k
    return x

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    S = sum(a)
    
    # Precompute f(x) for 1..S
    F = [0] * (S + 1)
    for i in range(1, S + 1):
        F[i] = f(i, k)
    
    dp = [defaultdict(lambda: None) for _ in range(1 << n)]
    for i in range(n):
        dp[1 << i][a[i]] = None  # singletons
    
    for mask in range(1, 1 << n):
        if bin(mask).count('1') == 1:
            continue
        sub = mask
        while sub:
            sub = (sub - 1) & mask
            other = mask ^ sub
            if sub == 0 or other == 0:
                continue
            for x in dp[sub]:
                for y in dp[other]:
                    val = F[x + y]
                    if val not in dp[mask]:
                        dp[mask][val] = (sub, x, other, y)
    
    full = (1 << n) - 1
    if 1 not in dp[full]:
        print("NO")
        return
    
    print("YES")
    ops = []
    def build(mask, val):
        parent = dp[mask][val]
        if parent is None:
            return [val]
        sub1, val1, sub2, val2 = parent
        l1 = build(sub1, val1)
        l2 = build(sub2, val2)
        ops.append((l1[-1], l2[-1]))
        return l1[:-1] + l2[:-1] + [val]
    
    build(full, 1)
    for x, y in ops:
        print(x, y)

solve()
```该解决方案预先计算$f(x)$并在所有子集上构造一个 DP 表。 这`build`函数使用存储在 DP 中的父指针重建操作。 一个微妙之处在于，对于每个子集，我们必须避免重复计算空分割，这是通过跳过来处理的`sub == 0`或者`other == 0`。 最终操作按照执行顺序打印。
