 ## 解决方案
 ## 问题理解

 任务是找出从源发送的消息多快可以到达至少一颗星星。 星星是三维空间中的点，信息以每年一个单位距离的速度沿直线传播。 由于目的地可以是给定恒星中的任何一颗，因此答案就是从起点到任何恒星的最小距离。 

每个输入点描述一个可能的目的地。 对于坐标处的恒星`(x, y, z)`，所需的旅行时间是从`(0, 0, 0)`到这一点，即`sqrt(x^2 + y^2 + z^2)`。 输出是这些距离的最小值，四舍五入到小数点后三位。 

星星的数量最多为 1000 颗。这个数量足够小，我们可以检查每颗星星一次。 具有二次行为的算法已经可以执行大约一百万次操作，这在这里是可以接受的，但问题的结构允许更简单的线性扫描。 坐标值的绝对值限制为 1000，因此平方距离很适合 Python 中的正常整数范围。 

一些实施细节可能会导致错误的答案。 一个常见的错误是在取平方根后比较距离，这是不必要的，并且会引入无益的精确工作。 另一个错误是打印的数字太少。 例如：```
1
1 1 1
```正确的输出是：```
1.732
```距离约为`1.73205`，因此需要四舍五入。 截断而不是舍入的程序将打印`1.732`对于这种情况，只有意外情况，并且在第四位小数改变答案的值上可能会失败。 

另一个边缘情况是原点处的星号：```
1
0 0 0
```正确的输出是：```
0.000
```如果实现将最小距离初始化为零而不是非常大的值，则每个正距离都将被错误地忽略。 初始值必须允许第一个星星替换它。 

重复的星星也是可能的：```
2
5 0 0
5 0 0
```答案是：```
5.000
```解决方案必须将每颗恒星视为候选者，但不需要存储任何额外信息，因为只有最小距离才重要。 

## 方法

 直接的方法是计算每颗恒星的距离并保留找到的最小值。 这是有效的，因为每颗恒星都是独立的。 目的地之间没有交互，因此检查所有候选目的地足以保证找到最好的目的地。 

更复杂的强力解释可能会比较每对恒星或构建不必要的几何结构，但这些操作都无法得出答案。 唯一相关的关系是每颗恒星和原点之间的关系。 因此，有用的计算计数恰好是每颗恒星的一次距离计算。 

关键的观察是该问题要求距离固定点最近的点。 因为原点永远不会改变，所以不需要排序或搜索。 一次通过就足够了。 我们还可以比较平方距离而不是实际距离，因为平方根函数是递增的。 如果`a < b`， 然后`sqrt(a) < sqrt(b)`，因此平方距离最小的恒星也具有最小的实际距离。 

蛮力之所以有效，是因为检查每个目的地可以保证正确性，但如果星星的数量变得更多，它就会变得浪费。 观察到答案仅取决于每个点到原点的距离，从而将解简化为线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 如果实施为扫描，则接受 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取星星的数量并准备一个包含非常大的平方距离的变量。 该值代表在检查任何恒星之前迄今为止找到的最佳答案。 
2. 对于每颗星，计算`x * x + y * y + z * z`。 这是距原点的行驶距离的平方。 比较平方值可以避免不必要的平方根计算，同时保留距离的顺序。 
3. 如果当前平方距离小于存储的最小值，则用该值替换存储的最小值。 存储的值始终代表迄今为止处理的所有恒星中最接近的恒星。 
4、处理完所有星星后，取最小平方距离的平方根，并打印出小数点后恰好三位数字。 

工作原理：处理输入的任何前缀后，存储的最小值是该前缀中所有星星之间的最小平方距离。 下一颗星星要么成为新的最接近的星星，要么保持当前答案不变。 在检查完每个星星之前，这个不变量一直保持不变，因此最终存储的值对应于整体上最近的星星。 仅在最后取平方根，将平方距离转换回所需的行程时间。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return

    n = int(n_line)
    best = float('inf')

    for _ in range(n):
        x, y, z = map(int, input().split())
        dist2 = x * x + y * y + z * z
        if dist2 < best:
            best = dist2

    print(f"{math.sqrt(best):.3f}")

if __name__ == "__main__":
    solve()
```该程序只保留一个值，`best`，因为最近的恒星的身份无关紧要。 每当出现更好的候选者时，循环就会更新它，匹配算法演练中的不变量。 

该比较使用平方距离。 这避免了重复的浮点平方根计算并保持决策过程精确，因为所有平方距离都是整数。 在找到最小值之后，平方根运算发生一次。 

输出格式使用`:.3f`，它执行所需的四舍五入到小数点后三位的操作。 无穷大初始化处理第一颗恒星具有任何可能距离（包括零）的情况。 

## 工作示例

 对于示例输入：```
3
0 1 1
2 0 0
0 -2 0
```执行是：

 | 步骤| 明星| 平方距离| 当前最小值 |
 | --- | --- | --- | --- |
 | 开始| 无 | 无 | 无穷大|
 | 1 | (0,1,1) | (0,1,1) | 2 | 2 |
 | 2 | (2,0,0) | 4 | 2 |
 | 3 | (0,-2,0) | (0,-2,0) | 4 | 2 |

 最小平方距离为 2，因此最终距离为`sqrt(2)`，四舍五入为`1.414`。 这表明该算法保留了最佳候选者并忽略了更远的恒星。 

第二个例子：```
2
0 0 0
10 10 10
```| 步骤| 明星| 平方距离| 当前最小值 |
 | --- | --- | --- | --- |
 | 开始| 无 | 无 | 无穷大|
 | 1 | (0,0,0) | (0,0,0) | 0 | 0 |
 | 2 | (10,10,10) | 300 | 300 0 |

 最近的恒星是原点本身，所以输出是`0.000`。 这证实了零距离处理正确。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每颗恒星都被访问一次，并且需要常数时间算术。 |
 | 空间| O(1) | O(1) | 仅存储当前最小值。 |

 对于最多 1000 颗星星，线性扫描很容易满足给定的限制。 该算法的扩展性也很好，因为它的内存使用量不依赖于星星的数量。 

## 测试用例```python
import sys
import io
import math

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    best = float('inf')

    for _ in range(n):
        x, y, z = map(int, input().split())
        best = min(best, x * x + y * y + z * z)

    return f"{math.sqrt(best):.3f}"

assert solution("""3
0 1 1
2 0 0
0 -2 0
""") == "1.414", "sample 1"

assert solution("""1
0 0 0
""") == "0.000", "origin case"

assert solution("""3
1000 1000 1000
-1000 -1000 -1000
1 1 1
""") == "1.732", "large coordinates and minimum selection"

assert solution("""4
5 0 0
0 5 0
0 0 5
5 0 0
""") == "5.000", "duplicate equal distances"

assert solution("""2
-1000 0 0
0 999 0
""") == "999.000", "boundary coordinate values"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 | 单星位于`(0,0,0)`|`0.000`| 最小距离可以为零 |
 | 坐标在`1000`和`-1000`|`1.732`| 大值和正确比较 |
 | 几个相同的最近距离|`5.000`| 重复候选人不影响结果 |

 ## 边缘情况

 对于零距离情况：```
1
0 0 0
```该算法从无穷大开始，计算零的平方距离，并替换存储的最小值。 最终的平方根为零，因此打印的答案是`0.000`。 

对于重复的星星：```
2
5 0 0
5 0 0
```第一个星形将最小平方距离设置为 25。第二个星形的平方距离也为 25，因此最小值保持不变。 最终的答案是`5.000`。 

对于舍入精度：```
1
1 1 1
```该算法存储平方距离`3`并计算`sqrt(3)`最后只有一次。 格式化输出将值正确舍入为`1.732`。 

对于负坐标：```
1
-1000 0 0
```距离的平方是`1000000`，与`(1000,0,0)`。 坐标的符号不会影响距离，因为在比较之前先对值进行平方。
