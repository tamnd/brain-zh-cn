 ## 解决方案
 ## 问题理解

 我们得到一个整数的集合，每个整数代表坚果的“能量”。 任务是选择两个不同的坚果，使其能量之和为奇数，并在所有此类有效对中返回最大可能的总和。 如果没有一对产生奇数和，则答案为 -1。 

输出完全取决于配对行为，而不是顺序或位置。 我们正在有效地处理多个值集，并且必须推断哪些两个元素可以组合起来以满足奇偶校验约束，同时最大化结果总和。 

约束允许最多 200,000 个值，每个值最多 200,000 个。 这立即排除了任何显式检查所有对的二次方法，因为在最坏的情况下这将需要大约 4 × 10^10 操作，远远超出 1 秒的限制。 我们需要一个能够在线性或近线性时间内处理数组的解决方案。 

当所有数字共享相同奇偶校验时，就会出现微妙的边缘情况。 如果所有值都是偶数，则每个总和都是偶数。 如果全部都是奇数，则每个和也都是偶数。 在这两种情况下，都不存在有效的对。 

例如，输入`2 4 6`不产生奇数和对，因此答案为 -1。 简单的方法可能仍然尝试计算最大对和并错误地返回 10。 

当仅存在一个奇数或一个偶数时，会出现另一种边缘情况。 例如，`1 2 4 6`只有一个奇数元素，因此即使存在很大的值，也无法形成有效的奇数和对。 

## 方法

 暴力解决方案尝试每一对 (i, j) 并检查 Ai + Aj 是否为奇数。 这很简单：对于每一对，计算总和，如果总和为奇数，则更新最佳答案。 正确性是显而易见的，因为它列举了所有可能性。 

问题在于规模。 当 N 达到 200,000 时，对的数量约为 N(N−1)/2，在最坏的情况下大约为 2 × 10^10 次操作。 这不能在时限内运行。 

关键的观察来自奇偶校验结构。 当且仅当一个数字是偶数而另一个数字是奇数时，和才是奇数。 这将问题从“所有对”减少为“仅交叉奇偶校验对”。 在所有有效对中，通过取最大偶值和最大奇值来获得最大总和。 

这将问题转化为简单的扫描：跟踪最大偶数和最大奇数元素，然后计算它们的总和（如果两者都存在）。

 ## 算法演练

 我们继续提取奇偶校验所施加的结构并将搜索空间减少到两个候选者。 

1. 扫描一次数组，同时维护两个变量：迄今为止看到的最大偶数值和迄今为止看到的最大奇数值。 我们将两者初始化为不存在，例如使用像−1这样的哨兵。 
2.对于每个数字Ai，确定其奇偶性。 如果Ai为偶数，则与当前的最佳偶数进行比较，如果Ai较大则更新。 如果 Ai 为奇数，则对奇数跟踪器执行相同操作。 这确保了我们始终在每个同等类别中保留最好的候选者。 
3. 处理完所有值后，检查是否同时存在最大偶数和最大奇数。 如果其中一个缺失，则没有有效的对可以形成奇数和，因此答案为 -1。 
4. 如果两者都存在，则计算它们的总和。 这是保证奇数的唯一结构，因为 Even + odd 是产生奇数结果的唯一方法。 

仅保留最大值的选择是合理的，因为任何有效的解决方案都必须将一个奇数和一个偶数配对，并且在每个奇偶校验组内独立地最大化总和会产生最佳的可能对。 

### 为什么它有效

 在任何时刻，该算法都会保留所见的最大偶数和所见的最大奇数。 任何有效的奇数和对必须由每个奇偶校验类别中的一个元素组成。 用相同奇偶校验的较大值替换此类对中的任一元素只能增加总和。 因此，最优对由数组中的最大偶数和最大奇数形成。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    arr = list(map(int, input().split()))
    
    max_even = -1
    max_odd = -1
    
    for x in arr:
        if x % 2 == 0:
            if x > max_even:
                max_even = x
        else:
            if x > max_odd:
                max_odd = x
    
    if max_even == -1 or max_odd == -1:
        print(-1)
    else:
        print(max_even + max_odd)

if __name__ == "__main__":
    solve()
```该实现在扫描输入一次时保持两个运行最大值。 哨兵值 -1 可以安全工作，因为所有输入都至少为 1，因此它不能与有效的数组值混淆。 

一个常见的错误是试图仅跟踪总和而不分离奇偶校验类别。 但这失败了，因为它忽略了奇数和需要相反奇偶校验的结构约束。

 ## 边缘情况

 一种边缘情况是数组仅包含偶数。 用于输入`6\n2 4 6 8 10 12`，扫描将 max_even 设置为 12，而 max_odd 始终保持为 -1。 最后，算法正确输出 -1，因为不可能进行交叉奇偶校验配对。 

另一种边缘情况是奇偶校验类中只有一个元素。 用于输入`4\n100 2 3 4`， max_even 变为 100，max_odd 变为 3。该算法仍然有效，因为只要其他类存在，就有一个奇数或偶数就足够了。 

第三种情况是最大偶数和最大奇数出现在数组的后面。 用于输入`5\n1 8 3 6 7`，运行最大值不断演化，直到最后 max_even = 8 和 max_odd = 7。 最终答案 15 证实顺序不会影响正确性，只有最大值很重要。
