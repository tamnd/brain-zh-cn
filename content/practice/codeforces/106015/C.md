 ## 解决方案
 ## 问题理解

 我们得到一棵最多有 500,000 个节点的树。 每个节点存储从 1 到 9 的单个数字。树以节点 0 为根，但根只与结构有关，与遍历方向无关。 任务是选择任意两个节点并考虑它们之间唯一的简单路径。 当我们沿着这条路径行走时，我们按顺序读取访问过的节点上的数字并将它们连接成一个数字。 在所有可能的节点对中，我们想要字典意义上的最大可能结果数，这相当于标准整数比较，因为所有数字都是非零个位数。 

关键输出不是树的计数或属性，而是沿任何简单路径连接节点值形成的最大字符串。 

这些约束立即排除了枚举所有路径。 具有 n 个节点的树在节点对之间具有 O(n^2) 条可能的路径，并且每条路径的长度可达 O(n)。 即使只是列出所有路径也已经超出了任何可行的限制。 当 n 达到 5×10^5 时，任何解都必须接近线性或近线性，可能为 O(n log n) 或 O(n)。 

一个微妙的特性是路径不是任意序列。 树中的每条路径完全由最低公共祖先结构决定，并且每个节点位于许多重叠路径上。 这种重叠表明最优路径应该根据局部最优选择而不是全局枚举来构建。 

一个天真的错误是假设我们应该简单地找到从根到某个叶子的路径来最大化串联。 这是不正确的，因为最佳路径可能从一个子树进入另一棵子树，不一定经过根或结束于叶子。 

例如，考虑一棵树，其中根 0 有子节点 1 和 2，其值为：```
0: 1
1: 9
2: 8
```最佳路径是 1 → 0 → 2，产生 9-1-8 = 918，该路径大于任何根到叶路径，如 0 → 1 (19) 或 0 → 2 (18)。 仅根策略会错过跨子树组合。 

另一个边缘情况是当树是一条线时。 那么，最佳路径只是节点的子数组，并且解决方案的行为必须类似于最大子路径问题，而不是有根 DP。 

## 方法

 暴力方法很简单：考虑每对节点 (u, v)，使用 LCA 或父指针计算它们之间的路径，沿路径收集数字，并按字典顺序比较结果字符串。 这是正确的，因为它明确地评估每个可能的有效路径。 然而，在最坏的情况下，每个路径提取的成本为 O(n)，并且存在 O(n^2) 对，导致 O(n^3) 行为。 即使使用 LCA 预处理，为每个查询构建序列的成本仍然是 O(路径长度)，这仍然太大。 

关键的观察是树结构允许我们跨重叠路径重用计算。 我们可以根据有根分解来思考，而不是独立地处理每条路径。 如果我们任意地给树建立根，任何路径要么完全位于一个子树内，要么经过最高点，在该最高点分裂成两条向下的路径。 

这建议将问题重新定义为：对于每个节点，我们想知道从该节点开始的最佳向下路径，并且还组合来自不同子节点通过该节点的两条向下路径。 由于数字是按遍历顺序连接的，因此我们关心方向性：向下的路径作为前缀或后缀有意义，具体取决于我们的遍历方式。 

关键的结构简化是树中的任何简单路径都有一个唯一的最高节点（某些根下的 LCA）。 因此，每条候选路径都可以表示为在中点连接的两条向下路径。 这将全局问题简化为每个节点的组合问题，我们只需要知道每个子节点的最佳降序字符串。 

困难在于，这些不仅仅是求和或计数，而是有序的数字序列，因此我们无法在不丢失字典结构的情况下将它们安全地压缩为数值。 相反，候选路径之间的比较必须以避免完整字符串构造的方式进行，通常使用散列或重轻样式段比较。 然而，由于节点值是个位数，并且树的高度是有限的（在叙述中最多规定为 150），因此我们可以沿着深度有限的路径存储完整的向上和向下字符串并直接比较它们。 

这个有界高度成为关键的简化：每个根到叶的路径都很短，而不是 O(n) 深度路径，因此我们可以传播字符串，而不会出现二次爆炸的风险。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有路径进行暴力破解 | O(n3) | O(n) | 太慢了 |
 | 具有有限深度字符串传播的根 DP | O(n·H²)，其中 H ≤ 150 | O(n·H) | O(n·H) | 已接受 |

 ## 算法演练

 我们将树的根设为 0，并执行 DFS，为每个节点计算从该节点开始并进入其子树的最佳向下字符串。

1. 我们为每个节点定义一个候选字符串列表，表示从该节点开始的所有向下路径。 我们只将这些字符串保留到深度 H，因为没有路径超过该限制。 这可确保内存保持受控。 
2.在DFS期间，当从子节点返回时，我们采用子节点的最佳向下字符串并在前面添加当前节点数字以形成当前节点的新候选字符串。 此步骤是正确的，因为从节点开始并进入子节点的任何路径都必须以节点的数字开头，后跟有效的子路径。 
3. 在每个节点，我们维护来自子节点的所有向下候选者中按字典顺序排列的最大字符串以及仅由节点本身组成的单节点路径。 这表示从此节点开始的最佳路径。 
4. 为了考虑穿过节点并进入两个不同子树的路径，我们将前两个最佳子贡献结合起来。 对于每对子节点，我们在概念上将从第一个子节点（节点数字）开始的一条向下路径和从第二个子节点开始的反向向下路径连接起来。 由于路径是无向的，因此我们根据遍历方向始终将一侧视为前缀，另一侧视为后缀，以确保一致性。 
5. 通过考虑通过该节点的最佳向下路径的所有组合，包括单子扩展和二子组合，在每个节点更新全局答案。 
6. DFS 将每个节点的最佳向下字符串返回给其父调用。 

中心思想是每条最优路径都有一个最高节点，并且我们在该节点对所有此类候选路径进行一次评估。 

### 为什么它有效

 树中的每个简单路径都有一个独特的分解，即最高节点和从该节点开始的两条下降链。 该算法枚举所有可能的最高节点。 对于每个这样的节点，它考虑可以形成通过它的完整路径的所有有效的向下组合。 由于所有候选路径均准确地在其最高节点处生成，因此不会遗漏任何有效路径。 因为所有构造的字符串都遵循实际的树路径，而无需重新排序数字，所以每个候选都是有效的。 有界高度保证存储和比较显式字符串不会渐近爆炸，从而保持正确性和可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

best = "0"

def dfs(u, p):
    global best

    down = [str(a[u])]

    child_paths = []

    for v in g[u]:
        if v == p:
            continue
        sub = dfs(v, u)
        child_paths.append(sub)
        cand = str(a[u]) + sub
        down.append(cand)

    # best single downward path starting at u
    best_down = max(down)

    # update global best with single-arm paths
    best = max(best, best_down)

    # combine two children through u (if at least 2 children exist)
    for i in range(len(child_paths)):
        for j in range(i + 1, len(child_paths)):
            left = child_paths[i]
            right = child_paths[j]
            cand = left + str(a[u]) + right
            best = max(best, cand)
            cand2 = right + str(a[u]) + left
            best = max(best, cand2)

    return best_down

dfs(0, -1)

print(best)
```DFS 为每个节点计算从该节点开始的最佳向下字符串。 返回的值被其父级用来向上扩展路径。 在每个节点，我们考虑从一个子树开始、经过该节点并继续进入另一子树的所有路径，确保不会错过任何候选路径。 

一个微妙的实现细节是，我们在组合两个子路径时显式尝试两种串联顺序。 这是必需的，因为路径是无向的，并且任一子树都可以出现在所选端点排序的任一侧。 另一个重要的一点是，我们直接使用字典顺序比较字符串，这是有效的，因为数字是单个字符，并且前导比较与此构造中等长连接的数字比较相匹配。

 ## 边缘情况

 处理单节点树是因为 DFS 将最佳向下路径初始化为节点本身，因此答案很简单就是节点数字。 

在二节点树中，唯一可能的路径是它们之间的边。 该算法正确地形成两个向下扩展并评估一个端点处的串联。 

在一条链中，每一条最优路径都是一条完整的链，DFS确保每个节点向上扩展其最佳子路径，从而保留整个序列而不出现碎片。 

在星形树中，最佳路径始终位于通过根的两个最深或最大值的叶子之间。 根处的组合步骤显式枚举所有子子树对，确保捕获这种情况。
