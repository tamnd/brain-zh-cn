 ## 解决方案
 ## 问题理解

 我们给出一个仅由其几何参数描述的等腰三角形：两条相等的边都有长度$L$，并且底边有长度$B$。 任务是确定这样的三角形是否存在，如果存在，则计算两个经典中心之间的距离：内心（内切圆的中心）和外心（外接圆的中心）。 

只有满足三角形不等式时，三角形才存在。 由于等边是$L$底座是$B$，唯一重要的条件是底数必须严格小于两个等边的总和，这可以简化为$B < 2L$。 如果失败，三角形就会退化或变得不可能，并且没有几何对象可供分析。 

约束条件允许边长达到$10^6$，因此任何解决方案都必须是每个测试用例的恒定时间，并避免迭代几何构造。 这立即排除了对三角形几何形状的任何坐标搜索或数值模拟。 一切都必须简化为涉及边长的封闭式公式。 

一个常见的微妙失败案例是几乎不违反或几乎满足三角不等式。 例如，$L = 5, B = 10$给出一个简并三角形. 直接将值插入几何公式的简单实现仍可能生成浮点数而不是拒绝输入。 当出现另一个问题时$B$非常接近$2L$，如果处理不当，浮点精度可能会使平方根下的表达式稍微负数。 

## 方法

 强力几何方法会尝试在坐标中构造三角形，将底边放置在 x 轴上，使用圆交点计算第三个顶点，然后根据定义显式计算内心和外心坐标。 这是可行的，因为所有这些对象都是由三角形唯一确定的，但它变得不必要的复杂和数值不稳定。 每个步骤都会引入平方根和除法，并且在求解交点时会累积小的浮点误差。 

关键的观察结果是，内心和外心都仅取决于边长，而不取决于三角形的任何嵌入。 这使我们能够完全绕过几何并使用经典的三角形不变量。 外接圆半径$R$, 半径内$r$，并且内心和外心之间的距离满足欧拉几何中的已知恒等式：$$OI^2 = R(R - 2r)$$在哪里$O$是外心并且$I$是内心。 

所以问题归结为计算$R$和$r$从边长来看。 一旦我们用以下形式表达面积$L$和$B$，两个半径都直接来自标准公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 坐标构建+直接几何 |$O(1)$|$O(1)$| 数字太脆弱|
 | 闭式三角形几何（欧拉公式）|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1.通过验证来判断三角形是否存在$B < 2L$。 如果没有，则返回$-1$。 这避免了对无效输入进行任何几何计算，否则会产生无意义的浮点值。 
2. 计算等腰三角形从顶点到底边的高度。 将三角形分成两个直角三角形，得到一个带斜边的直角三角形$L$和一条腿$B/2$，所以高度是$h = \sqrt{L^2 - (B/2)^2}$。 此步骤是无需海伦公式即可获得面积的最简洁方法。 
3. 使用底乘高计算面积：$A = \frac{B \cdot h}{2}$。 面积是中心量，因为内半径和外接半径都直接依赖于它。 
4. 计算半周长$s = \frac{2L + B}{2} = L + \frac{B}{2}$，然后使用计算内半径$r = \frac{A}{s}$。 这是从身份得出的$A = rs$，这对于每个三角形都成立。 
5. 使用以下方法计算外接圆半径$R = \frac{abc}{4A}$。 这里$a = b = L$和$c = B$， 所以$R = \frac{L^2 B}{4A}$。 这完全用边长和面积来表达外接圆。 
6. 使用欧拉关系计算中心之间的距离$d = \sqrt{R(R - 2r)}$。 这是两个中心之间最后的几何桥梁。 
7. 输出$d$具有足够的精度。 

### 为什么它有效

 正确性基于以下事实：任何非简并三角形都是由其边长唯一确定的（直到刚性运动），因此所有导出的几何量仅是以下函数的函数$L$和$B$。 使用的公式是欧几里得几何中的精确恒等式，而不是近似值。 必须明确强制执行的唯一条件是非简并性，因为所有公式都假设面积为正三角形。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    L, B = map(float, input().split())

    if B >= 2 * L:
        print(-1)
        return

    h_sq = L * L - (B * B) / 4.0
    if h_sq <= 0:
        print(-1)
        return

    h = math.sqrt(h_sq)
    A = (B * h) / 2.0

    s = L + B / 2.0
    r = A / s

    R = (L * L * B) / (4.0 * A)

    val = R * (R - 2.0 * r)
    if val < 0:
        val = 0.0

    d = math.sqrt(val)

    print(d)

if __name__ == "__main__":
    solve()
```推导后直接实现。 第一个守卫确保我们永远不会尝试无效几何表达式的平方根。 高度计算优于 Heron 公式，因为它可以避免在以下情况下减去几乎相等的数字：$B$接近于$2L$，这提高了数值稳定性。 

最后的守卫`val`防止浮点舍入引起的微小负值传播到平方根。

 ## 边缘情况

 当$B$方法$2L$，高度计算涉及减去两个几乎相等的数字$L^2 - (B/2)^2$。 例如，$L = 10^6$,$B = 2 \cdot 10^6 - 10^{-3}$会使表达式对浮点错误极其敏感。 在这种情况下，在求平方根之前限制负值可确保算法不会产生 NaN。 

如果$B = 0$，三角形退化为线段，并且有效性检查拒绝它，因为$0 < 2L$为真，但面积变为零，并且平方根步骤通过$h^2 \le 0$警卫。 

如果在退化极限上所有边都相等$B = 2L$，三角形折叠成一条线段。 该算法在初始不平等检查时捕获了这一点并返回$-1$，防止进行无效的几何推理。
