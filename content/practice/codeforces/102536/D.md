 ## 解决方案
 ## 问题理解

 任务是根据两条信息来决定一个人是否可以访问某条内容：该人的年龄和内容的评级类别。 标题本身并不影响决策，它只是输入格式的一部分。 该等级决定了最低年龄要求，但特殊的 PG 情况除外，即较年轻的人在有责任的成年人陪同下可以进入。 

输入的第一行包含一个年龄值和一个评级字符串，第二行包含内容标题。 输出描述了访问决策。 它可以是正常批准、需要成人陪同的有条件批准或拒绝。 

年龄可以大到 10^9，但决策仅取决于将该年龄与一些固定阈值进行比较。 标题长度最多为 100 个字符，因此读取和存储它很简单。 扫描标题或执行与年龄成比例的任何计算的解决方案是不必要的。 预期的算法应在解析输入后使用恒定时间。 

可能破坏粗心实施的主要情况是确切的边界年龄。 例如，年满 13 岁的人应该被允许进入 R-13 内容。```
13 R-13
Example
```正确的输出是：```
OK
```解决方案使用`age > 13`而不是`age >= 13`会错误地拒绝此案。 

另一个重要的例子是 PG 对年轻人的满足。 一岁的孩子不会立即被拒绝，因为 PG 允许在有人陪伴的情况下进入。```
1 PG
Example
```正确的输出是：```
OK IF ACCOMPANIED
```如果解决方案将所有 13 岁以下的年龄都视为禁止，则会产生错误的结果。 

G级也是一个特例，因为它没有年龄限制。```
0 G
Example
```正确的输出是：```
OK
```任何对每个评级应用最低年龄检查的实现都会在这里失败。 

## 方法

 一种直接的方法是为每个评级创建一组条件并逐一检查它们。 这已经是自然的暴力方法，因为只有五个可能的评级值。 它的工作是恒定的：它读取输入，必要时将年龄与阈值进行比较，并打印相应的结果。 

不存在涉及标题的有意义的较慢的蛮力，因为标题在决策中没有任何作用。 重复检查每个可能的年龄值的假设方法在最大情况下将执行多达 10^9 次检查，这远远超出了可用时间。 问题的结构告诉我们，只有年龄和固定截止值之间的关系才重要。 

关键的观察是每个评级都可以用一个简单的规则来表示。 G总是成功的。 PG 对于 13 岁以下的年龄有一项有条件的结果。R-13、R-16 和 R-18 都是最低年龄要求。 一旦这些规则被明确地写出来，整个问题就变成了恒定数量的比较。 

蛮力之所以有效，是因为可能的类别数量很小，但有用的见解是认识到输入大小不需要任何常规搜索或模拟。 评级系统是一个固定的决策表，这一观察结果让我们可以将解决方案简化为一些条件检查。

 | 蛮力 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取此人的年龄和要求的等级。 标题也可以从输入中消耗，但它不影响结果。 
2.如果评级为G，则立即返回OK，因为该类别没有年龄限制。 
3. 如果评级为PG，则将年龄与13岁进行比较。13岁及以上通常会获得批准，而较小的年龄会收到附带的批准消息。 
4. 如果评级为 R-13、R-16 或 R-18，请根据评级数字确定所需的最低年龄，并将其与人员的年龄进行比较。 仅当年龄至少达到要求值时才会接受此人。 
5. 打印与结果匹配的决策字符串。 

这样做的原因是评级规则形成了所有可能输入的完整划分。 每个评级只有一个规则，并且每个规则都直接匹配评级系统描述的条件。 

为什么它有效：

 对于任何输入，算法都会选择与给定评级相对应的规则。 对于 G，规则接受所有人，这与不受限制的类别匹配。 对于PG，算法将人分为满足正常年龄要求的人和需要陪伴的人。 对于受限评级，算法完全接受满足最小年龄条件的年龄。 由于每个可能的评级均由其正确的规则处理，因此生成的输出始终与所需的访问决策相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

age, rating = input().split()
age = int(age)

if rating == "G":
    print("OK")
elif rating == "PG":
    if age >= 13:
        print("OK")
    else:
        print("OK IF ACCOMPANIED")
else:
    limit = int(rating[2:])
    if age >= limit:
        print("OK")
    else:
        print("ACCESS DENIED")
```该代码首先将年龄与评级分开，并将年龄转换为整数，以便可以执行数字比较。 解析后不需要标题行，因为它不包含决策过程使用的信息。 

G分支排在第一位，因为它完全忽略了年龄。 PG 分支有两种可能的结果，使用`age >= 13`所以恰好 13 的边界情况被正确处理。 

其余评级均具有相同的格式：R 后跟连字符和数字。 提取前两个字符后的子字符串给出所需的最小年龄。 Python 整数可以处理最大年龄值，而无需担心溢出。

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline
    age, rating = input().split()
    age = int(age)

    if rating == "G":
        return "OK"
    elif rating == "PG":
        if age >= 13:
            return "OK"
        return "OK IF ACCOMPANIED"
    else:
        limit = int(rating[2:])
        if age >= limit:
            return "OK"
        return "ACCESS DENIED"

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

assert run("18 R-18\nFrozen 3\n") == "OK", "sample 1"
assert run("1 R-13\nStar Wars: The Fall of Skywalker\n") == "ACCESS DENIED", "sample 2"
assert run("13 PG\nAgent Cody Banks\n") == "OK", "sample 3"

assert run("0 G\nAnything\n") == "OK", "minimum age with unrestricted rating"
assert run("12 PG\nMovie\n") == "OK IF ACCOMPANIED", "PG boundary below 13"
assert run("16 R-16\nMovie\n") == "OK", "exact restricted boundary"
assert run("1000000000 R-18\nMovie\n") == "OK", "maximum age value"

 |`16 R-16`|`OK`| 检查受限评级边界上的相等性。 |

 ## 边缘情况

 对于正好处于最小年龄的人，算法使用大于或等于比较。```
13 R-13
Movie
```评级不是 G 或 PG，因此代码提取限制为 13 并检查`13 >= 13`。 条件成立，答案为`OK`。 

对于 13 岁以下儿童的 PG 评级，算法不会立即拒绝。```
5 PG
Movie
```代码进入PG分支，检查`5 >= 13`，并发现它是假的。 由于 PG 允许伴奏，所以正确答案是`OK IF ACCOMPANIED`。 

对于非常年轻的人的 G 评级，该算法从不执行年龄比较。```
0 G
Movie
```第一个条件匹配，答案是`OK`。 这可以避免错误地应用属于其他类别的限制。
