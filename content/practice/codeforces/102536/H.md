 ## 解决方案
 ## 问题理解

 网格是一个矩形，其中有效单元形成对角走廊。 走廊有宽度`l - w + 1`，每一行都会将走廊向右移动一个位置。 路径只能向右或向下移动，因此问题是计算永远不会离开该对角线带的单调路径。 

直接动态编程解决方案将存储到达每个单元格的方式数量。 这将需要处理大约`l * w`细胞太大了，因为`l`可以达到`5 * 10^6`和`w`可以达到`5 * 10^5`。 

有用的观察是走廊条件可以转化为一维步行。 设当前值为：```
column - row
```向右移动会将该值增加 1，向下移动会将该值减少 1。 起始值为`0`，最终值为`l - w`，并且当该值介于`0`和`l - w`。 

这将问题转化为计算有界条带中的行走次数。 

## 方法

 暴力解决方案使用网格上的动态编程。 对于每个打开的单元格，它会添加从上方单元格和左侧单元格开始的路数。 这是正确的，因为每条有效路径都从这两个方向之一到达单元格。 然而，细胞的数量可能约为`2.5 * 10^12`，所以这种方法是不可能的。 

关键的观察是一维行走有两个禁界。 反射原理让我们通过反射每条跨越边界的路径来计算无效行走。 结果是普通二项式系数的交替和。 

让：```
n = l + w - 2
d = l - w
```答案变成：```
sum over k:
C(n, l - 1 + k(d + 2)) - C(n, l + k(d + 2))
```仅介于之间的索引`0`和`n`很重要，所以当`d`很大，并且当`d`很小，步长很小，但项数仍然可以管理。 

模数`104857601`是素数，因此阶乘和逆阶乘允许在恒定时间内计算每个二项式系数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力DP | O(lw) | O(lw) | 太慢了 |
 | 反射+二项式 | O(l + w) | O(l + w) | 已接受 |

 ## 算法演练

 1. 计算`n = l + w - 2`和`step = l - w + 2`。 价值`step`是路径的连续反射副本之间的距离。 
2. 预先计算阶乘和逆阶乘`n`。 由于模数是素数，因此每个二项式系数可由下式获得：```
C(n, k) = fact[n] * invfact[k] * invfact[n-k]
```1. 添加表格的所有条款`C(n, l - 1 + k * step)`范围内的`[0, n]`。 
2. 减去表格中的所有项`C(n, l + k * step)`范围内的`[0, n]`。 
3. 对结果进行模归一化`104857601`。 

为什么它有效：每个无效路径都与一个反射路径配对。 第一个二项式系数族计算不受限制的路径，而第二个二项式系数族则删除跨越上或下禁止边界的路径。 交替总和只留下完全留在走廊内的路径。 

## Python 解决方案```python
import sys
from array import array

input = sys.stdin.readline

MOD = 104857601

def solve():
    l, w = map(int, input().split())

    n = l + w - 2
    step = l - w + 2

    fact = array('I', [1]) * (n + 1)
    for i in range(1, n + 1):
        fact[i] = (fact[i - 1] * i) % MOD

    invfact = array('I', [1]) * (n + 1)
    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = (invfact[i] * i) % MOD

    def comb(k):
        if k < 0 or k > n:
            return 0
        return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

    ans = 0

    x = l - 1
    while x >= 0:
        ans += comb(x)
        x -= step

    x = l - 1 + step
    while x <= n:
        ans += comb(x)
        x += step

    x = l
    while x >= 0:
        ans -= comb(x)
        x -= step

    x = l + step
    while x <= n:
        ans -= comb(x)
        x += step

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```阶乘数组使用`array('I')`而不是普通的 Python 列表，因为最大值`n`接近于`5.5 * 10^6`，而Python整数对象会消耗更多的内存。 

四个环路分别生成正反射项和负反射项。 从两个方向开始是必要的，因为反射路径可能对应于负值`k`以及积极的方面。 

模逆使用费马小定理，该定理是有效的，因为`104857601`是素数。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(l + w) | 阶乘准备占主导地位，而反射和包含的项要少得多 |
 | 空间| O(l + w) | 两个数组存储阶乘和逆阶乘值 |

 最大阶乘大小约为`5.5 million`，因此内存使用量远低于限制。 该解决方案避免了对原始网格中单元数量的任何依赖。 

## 工作示例

 对于`l = 7`,`w = 5`:```
n = 10
step = 4
```积极的条件是：

 | k | 索引 | 价值|
 | --- | --- | --- |
 | 0 | 6 | C(10,6) | C(10,6) |
 | -1 | 2 | C(10,2) | C(10,2) |

 否定词有：

 | k | 索引 | 价值|
 | --- | --- | --- |
 | 0 | 7 | C(10,7) | C(10,7) |
 | -1 | 3 | C(10,3) | C(10,3) |

 结果是：```
C(10,6) + C(10,2) - C(10,7) - C(10,3)
= 210 + 45 - 120 - 120
= 16
```与示例输出匹配。
