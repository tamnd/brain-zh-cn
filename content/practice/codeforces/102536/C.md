 ## 解决方案
 ## 问题理解

 前辈用几个品质来判断一个人。 每种品质都有其权重，因此提高某些品质比提高其他品质更重要。 前辈自身所要求的质量水平随时间线性变化。 对于每种质量，要求都有一个起始值和变化率。 

口海的一切个人品质都是从零开始的。 唯一的限制是改进的速度：在任何时刻，所有质量增长率的向量必须最多有长度`g`。 任务是找到口海最早能够选择最优改进策略，使个人加权得分至少达到前辈当前标准的时间。 

输入给出了品质的数量、最大生长速度、所有品质的权重以及描述前辈不断变化的标准的线性函数。 输出是可能成功的最短时间。 

约束表明所有测试用例的质量数量仅为`10^4`，因此期望对质量进行线性传递。 任何随时间的模拟、对质量的动态规划或重复执行昂贵检查的搜索都会增加不必要的工作。 答案是一个实数，因此主要的挑战是推导公式，而不是通过复杂的计算来处理数值精度。 

棘手的情况来自于重量、增长率和起始要求都可能为负的事实。 假设每个值都为正的解决方案可能会默默地失败。 

考虑口海已经超出要求的单一质量：```
1
1 10
1
0 -5
```正确的输出是`0`。 由于最初的要求是`-5`口海的初始分数是`0`，无需改进。 不检查当前状态而立即除法的粗心公式可能会产生负时间。 

另一种情况是负权重使得提高质量变得有害：```
1
1 10
-2
0 5
```不应因为权重为负而增加质量。 正确的推理是使用权重向量的总长度，让口海朝权重分数最大化的方向移动。 仅对权重进行求和而忽略其符号的解决方案将计算出错误的增长潜力。 

## 方法

 直接方法会尝试模拟可能的改进策略。 在选定的时间`t`，它可以尝试决定每个品质应该投入多少增长预算，然后检查加权分数是否达到前辈的要求。 这是正确的，因为条件仅取决于最终的质量值，但可能的持续改进功能的空间是巨大的。 即使将其减少到检查许多可能的次数也需要重复解决优化问题。 和`q = 1000`，尝试许多候选分配或使用细粒度时间模拟很快就变得不可行。 

关键的观察结果是，只有口海质量向量的最终位置才重要。 从零开始，任何有效的增长路径都可以将质量向量移动最多距离`g * t`过了一段时间`t`。 加权分数是最终质量向量和权重向量之间的点积。 通过精确地沿权重方向移动来获得具有有界长度的向量的最大可能点积。 

时间后可能的最大加权分数`t`因此是：

 g·t·∣∣W∣∣

 其中：

 ∣∣W∣∣= i Σ​ W i 2 ​​

 Senpai 的总需求也是线性的：

 i Σ ​ S i ​ (t)=t i Σ ​ F i ​ + i Σ ​ C i ​

 现在两边都是时间的简单线性函数。 通过求解一个不等式可以直接找到答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(无限搜索策略) | O(q) | 太慢了 |
 | 最佳 | O(q) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取质量的权重并计算权重向量的平方长度。 权重向量的方向决定了口海生长速度的最佳消耗方式，因此只需要它的大小即可。 
2. 添加所有Senpai生长因子`sum_f`以及所有初始要求`sum_c`。 这两个值将前辈的总标准描述为单个线性函数。 
3. 计算口海单位时间内最大可能的分数增幅为：

 g i Σ​ W i 2 ​​

 这是加权质量和的最大可能增长率，因为改进方向可以自由选择。 

1. 比较两个线性函数。 如果`sum_c <= 0`，口海在零时刻已经满足要求，所以答案是零。 
2.否则解决：

 (g∣∣W∣∣− i Σ ​ F i ​ )t≥ i Σ ​ C i ​

 分母必须为正，因为问题保证了答案的存在。 将剩余要求除以该值即可得到最短时间。 

为什么有效：经过一段时间`t`，每种可能的改进策略都会产生一个质量向量，其欧几里得长度最多为`gt`。 根据柯西-施瓦茨不等式，加权得分至多是两个向量长度的乘积，即`gt||W||`。 该上限可以通过选择与权重向量平行的改进方向来实现。 该算法正是使用这个最大可能分数，并找到第一次达到前辈要求的时间，因此没有更早的时间可以工作，并且返回的时间是可以实现的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    c = int(input())
    ans = []

    for _ in range(c):
        q, g = map(int, input().split())

        w = list(map(int, input().split()))

        sum_f = 0
        sum_c = 0
        for _ in range(q):
            f, cc = map(int, input().split())
            sum_f += f
            sum_c += cc

        w_len = math.sqrt(sum(x * x for x in w))
        growth = g * w_len

        if sum_c <= 0:
            ans.append("0.00000000000")
        else:
            t = sum_c / (growth - sum_f)
            ans.append("{:.12f}".format(t))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```代码首先将所有质量信息简化为三个值：权重向量的大小、Senpai 标准变化的总速率以及初始总标准。 个人的贡献积累后就不再需要储存了。 

每个测试用例仅计算一次平方根。 浮点精度足够了，因为所需的误差是`1e-10`，且涉及的值很小。 该公式仅在检查零时间情况后才使用除法，以避免错误的否定答案。 

Python 中不存在整数溢出问题，但在将最终表达式转换为浮点之前，通过使用原始约束的总和，实现仍然使计算保持简单。

 ## 边缘情况

 当初始要求已满足时，算法在使用线性方程之前返回零。 为了：```
1
1 10
1
0 -5
```

`sum_c = -5`，所以不需要改进。 没有此检查的基于除法的实现可能会返回无效的负时间。 

当权重包含负值时，最好的策略不是增加每个质量。 最佳移动方向遵循权重向量，这自然意味着负权重会降低质量。 例如：```
1
2 1
1 -1
0 5
0 5
```重量长度为：

 1 2 +(−1) 2 ​ = 2 ​

 口海的最大改善率为`sqrt(2)`。 要求恒定为`10`，所以答案是：

 10/ 2 ​ =7.071067811865

 该算法可以处理这个问题，因为它使用权重的平方而不是它们的总和。 

如果前辈的标准提高得很快，最终公式的分母就会变小。 该解决方案不会围绕答案进行搜索，因此避免了因二分查找狭窄范围而导致的精度损失。 它直接计算精确的线性交点。
