 ## 解决方案
 ## 问题理解

 该任务是从数字集合中提取顺序信息：给定一个序列，我们不仅要识别最大值，还要识别在忽略重复项时排序中紧邻该值的值。 

更具体地说，假设您正在查看一个整数列表并反复询问哪个数字最大。 一旦知道了这一点，您就可以从概念上删除所有出现的最大数字，并再次提出相同的问题。 第二个问题的答案就是我们所说的第二个最大值。 

输入可以解释为单个整数数组。 输出是一个整数，表示该数组中第二大的不同值。 如果每个元素都相同，或者只有一个唯一值，则没有要报告的有效第二个最大值，并且输出必须反映这种缺失。 

从约束的角度来看，此类问题的自然上限通常最多为 10^5 或更多元素。 这立即排除了任何比较所有元素对或每个查询重复对子数组进行排序的解决方案。 O(n^2) 方法在最坏的情况下已经执行了大约 10^10 次操作，并且不适合典型的时间限制。 即使通过排序的 O(n log n) 解决方案也是可以接受的，但它是矫枉过正的，因为问题的结构只需要跟踪两个值。 

当数组包含最大值的重复项但不存在第二个不同值时，会出现微妙的边缘情况。 例如，输入`[5, 5, 5]`有最大`5`，但没有第二个最大值。 简单地在排序后选择第二个元素而不删除重复项的简单实现会错误地输出`5`，这违反了独特性的要求。 

当最大值出现一次而第二个最大值重复多次时，就会出现另一种边缘情况，例如`[10, 3, 3, 3]`。 正确的解决方案必须确保它不会意外地将重复的扫描位置视为单独的候选位置； 它应该只关心值的转换，而不是频率。 

## 方法

 最直接的想法是按降序对数组进行排序，并选择第一个元素作为最大值并向前扫描，直到找到更小的不同值。 这是正确的，因为排序将相等的元素分组在一起，因此值更改的第一个位置恰好对应于第二个最大值。 缺点是排序成本为 O(n log n)，并且该问题实际上并不需要完全排序，只需要前两个不同的值。 

更有效的方法来自于观察我们在扫描一次数组时只关心两个值。 我们不建立全局顺序，而是维护两个运行变量：迄今为止看到的最大值和迄今为止看到的第二大不同值。 每个新元素只需要与这两个元素进行比较，这将问题减少到一次。 

关键的观察是，每当我们遇到大于当前最大值的值时，之前的最大值就会成为第二个最大值候选者。 当该值严格位于当前最大值和当前第二最大值之间时，它会更新第二最大值。 其他一切都可以忽略。 

这将整个问题减少到具有恒定额外空间的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 排序 | O(n log n) | O(n log n) | O(1) 或 O(n) | 已接受但没有必要 |
 | 一次性追踪 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们在一次遍历数组期间维护两个变量：`max1`作为迄今为止看到的最大值`max2`作为第二大不同值。 

1. 初始化两者`max1`和`max2`为未定义（或负无穷大，具体取决于实现）。 这代表我们还没有看到任何值。 
2. 读出每个数字`x`从数组中一一取出。 
3.如果`x`大于`max1`， 然后`x`成为新的最大值。 上一个`max1`（如果存在）向下移动以成为新的`max2`。 此步骤保留了迄今为止看到的最好的两个不同值。 
4.否则如果`x`严格介于`max1`和`max2`， 然后`x`改进第二好的候选者并替换`max2`。 我们忽略了与`max1`这里是因为重复项不会创建新的不同最大值。 
5. 否则，什么也不做。 该值要么与我们已经计算过的值重复，要么太小而无关紧要。 
6.处理完所有元素后，检查是否`max2`was ever assigned a valid value. 如果不是，则不存在第二个不同的最大值。 

这样做的原因是在扫描中的任何一点，`max1`保证是所有处理值中最大的元素，并且`max2`是严格小于的最大值`max1`在这些相同的元素中。 任何新元素只需要与这两个摘要竞争，因为所有较小的结构与确定前两个不同值无关。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    max1 = None
    max2 = None
    
    for x in arr:
        if max1 is None or x > max1:
            max2 = max1
            max1 = x
        elif x != max1:
            if max2 is None or x > max2:
                max2 = x
    
    if max2 is None:
        print("NO SECOND MAX")
    else:
        print(max2)

if __name__ == "__main__":
    solve()
```该实现直接反映了二变量不变量。 第一个分支处理提升到最大位置并正确降级之前的最大位置。 第二个分支确保只有与当前最大值严格不同的值才能影响`max2`，这增强了独特性。 最终检查区分是否具有有效的第二个最大值和是否所有值都相同。 

一个常见的陷阱是允许与`max1`更新`max2`，这会错误地将最大值的重复项视为有效的第二个最大值。

 ## 边缘情况

 关键的边缘情况是所有值都相同。 在这种情况下，算法永远不会分配`max2`，因为每次比较都匹配`max1`或者无法产生一个严格较小的候选人。 最终检查正确地检测到这一点并产生“无第二最大值”输出。 

当最大值出现在数组的较晚位置时，会出现另一种边缘情况。 例如，在`[1, 2, 3, 100, 50]`，算法必须正确更新两者`max1`并重置`max2`当遇到 100 时，确保较早的候选者不会被错误地保留为相对于新的最大值的次优。 每当找到新的最大值时，第一个分支中的降级步骤就会将先前的最大值移动到第二个位置，从而保证此行为。
