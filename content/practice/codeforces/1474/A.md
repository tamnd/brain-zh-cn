 ## 解决方案
 ## 问题理解

 我们被要求构造一个二进制数`a`给定另一个二进制数`b`相同长度的`n`以这样的方式导出数字`d`被最大化。 获取过程`d`是分两步进行的。 首先，我们计算`c`作为按数字求和`a`和`b`无需携带。 这意味着每个数字`c`简直就是`a[i] + b[i]`可以是 0、1 或 2。其次，我们删除连续的重复数字`c`要得到`d`。 例如，如果`c = 1220`，我们删除重复的连续数字得到`d = 120`。 

我们的目标是选择`a`最大化`d`作为整数。 在实践中，这意味着我们想要的数字序列`c`在最大可能值之间交替，而不会创建不必要的重复，这些重复将在`d`。 

约束表明`n`可以达到`10^5`最多可以有 1000 个测试用例，总和为`n`在所有情况下 ≤ 10^5。 这排除了任何检查所有可能的解决方案`a`值，因为有`2^n`的可能性。 我们需要一种在每个测试用例的线性时间内工作的算法。 边缘情况包括非常短的字符串（长度为 1）、完全由 0 或 1 组成的字符串以及连续的字符串`b[i]`值相等，这会影响是否`d`折叠数字。 

尝试所有长度的二进制数的简单方法`n`会立即失败。 例如，如果`b = 111`和`n = 3`，暴力破解会考虑`a`在`000`到`111`。 这是指数级的且不切实际的。 另一个微妙的情况是当`b`有交替的零和一； 选择`a`不考虑重复可能会产生更小的`d`比可能的。 

## 方法

 暴力解决方案将生成所有二进制字符串`a`长度`n`, 计算`c = a + b`（按数字），然后减少连续的重复次数以获得`d`，最后比较`d`值为整数。 复杂度为 O(2^n × n)，即使 n = 20 也显然不可行，更不用说 10^5 了。 这在理论上是正确的，但在实践中却毫无用处。 

关键的观察是`d`当数字达到最大时`c`尽可能在值之间交替。 自从`c[i] = a[i] + b[i]`和`b[i]`是固定的，`a[i]`可以是 0 或 1。我们只需要决定`a[i]`以避免连续的相同数字`c`。 具体来说，如果前一个数字`c`是一样的`b[i] + 1`，我们无法选择`a[i] = 1`因为`c[i]`会重复。 否则我们就贪婪地挑选`a[i] = 1`使`c[i]`尽可能大。 如果这种情况重复出现，我们选择`a[i] = 0`。 

这个观察结果允许一个简单的贪心算法构建`a`单次通过`b`。 贪婪的选择总是安全的，因为`c`折叠连续的重复，因此单独最大化每个数字，同时避免立即重复可以保证最大`d`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n × n) | O(2^n × n) | O(n) | 太慢了|
 | 贪婪最优 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化`prev`到-1，这将存储前一个数字`c`在构建的序列中。 开始建造`a`作为空字符串。 
2. 对于每个索引`i`从 0 到 n-1，考虑`b[i]`。 计算总和如果`a[i] = 1`（所以`c_i = b[i] + 1`）并检查它是否等于`prev`。 如果没有，请选择`a[i] = 1`， 放`c_i = b[i] + 1`，并更新`prev`到`c_i`。 
3. If setting`a[i] = 1`会重复之前的`c`数字，选择`a[i] = 0`反而。 然后`c_i = b[i] + 0 = b[i]`，并更新`prev`到`c_i`。 
4. 追加选择的内容`a[i]`到字符串`a`。 
5. 重复直到结束`b`。 输出`a`。 

为什么有效：在每一步中，我们都会选择最大的可能数字`c`不重复前面的`c`价值。 由于折叠连续的相等数字只会减少重复次数，因此没有任何选择可以改善`d`超越这个贪婪的决定。 这保持了每一步都会产生局部最大贡献的不变性`d`而不引入崩溃。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    b = input().strip()
    a = []
    prev = -1  # previous digit of c
    
    for ch in b:
        bi = int(ch)
        if bi + 1 != prev:
            a.append('1')
            prev = bi + 1
        else:
            a.append('0')
            prev = bi

    print("".join(a))
```该解决方案读取多个测试用例并迭代每个字符`b`。 关键是保持`prev`作为最后一位数字`c`。 我们尝试挑选`a[i] = 1`最大化`c[i]`。 如果这种情况重复出现，我们选择`a[i] = 0`。 这确保了线性时间执行并遵守崩溃规则。
