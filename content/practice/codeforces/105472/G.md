 ## 解决方案
 ## 问题理解

 我们得到了一组称为侏儒的相同单位，我们必须在流程开始之前将它们分成最多固定数量的组。 之后，双方之间会发生重复的互动：每一轮，每个活着的侏儒都会贡献一个单位的伤害，然后对手通过从中删除最多固定数量的侏儒来减少选定的一组。 

关键的交互是攻击者每轮总是针对一个群体，从该群体中删除最多 k 个侏儒。 如果该群小于 k，它就会完全消失。 这个过程一直持续到所有组都空了，并且对手每次选择目标组时都会以最小化我们在所有回合中造成的总伤害的方式。 

我们的任务不是模拟固定分区的这种相互作用，而是将分区选择为最多 m 组，以便在最佳敌人发挥下使整个过程的总累积伤害最大化。 

这些限制立即变得很重要。 当 n 达到 10^9 时，任何依赖于迭代单个侏儒或模拟回合的方法都是不可能的。 即使 O(n) 或 O(nm) 推理也太大了。 经过少量逻辑预处理后，我们被迫进行封闭式或近恒定时间计算。 该结构强烈建议对组大小进行贪婪或参数优化，而不是模拟。 

当 k 相对于 n 非常大时，就会出现微妙的边缘情况。 在这种情况下，一次攻击就可以消灭整个群体，因此分裂行为变得极其敏感。 另一个极端情况是当 m 比 n 大时，允许许多单例组，这会改变损坏随时间衰减的方式。 最后，当 k 很小时，群体的行为就像缓慢排水的水库，敌人的最佳策略有效地优先考虑较大的剩余群体。 

一个经常失败的天真的直觉是假设分成 m 个相等的组是最佳的。 例如，当 n = 10、m = 4、k = 3 时，均分得到 (3,3,2,2)，但最佳策略实际上将质量集中到一大组和几个单例中，以延迟至少一组的完全耗尽。 这种不平衡是至关重要的。 

## 方法

 如果我们尝试暴力破解，我们将枚举将 n 拆分为最多 m 个正整数的所有方法，模拟每种配置的游戏，并计算在最佳敌人游戏下产生的总伤害。 即使忽略模拟难度，n 的分区数量也是巨大的，以 √n 为指数增长。 即使对于中等的n，这也是完全不可行的。 

即使我们修复了一个分区，模拟该过程也需要跟踪所有群体并重复选择最大的有效群体或计算敌人将打击哪个群体。 每个模拟每轮可能需要 O(n) 或更糟，并且最多可能有 O(n/k + m) 轮，对于高达 10^9 的 n 来说仍然太大。 

关键的结构洞察力是扭转视角。 我们不考虑回合，而是考虑每个侏儒在被移除之前贡献一定数量的“活跃回合”。 每个侏儒每轮贡献 1 点伤害，直到被杀死，因此总伤害等于所有侏儒生存时间的总和。 敌人每轮总是从单个组中移除 k 个侏儒，这意味着组的行为就像队列被分成大小为 k 的块。 

在大小为 s 的组内，其成员的生命周期贡献是确定性的：它们会一直存活，直到该组中发生足够多的 k 大小的删除。 大小为 s 的组在 ceil(s / k) 攻击中得到有效处理，并且其贡献在全局时间内形成递减的类似算术的结构。

这将问题转化为决定如何将 n 分成最多 m 个部分，以最大化群体贡献的总和，其中较大的群体是有益的，因为它们可以创建更持久的高伤害前缀。 关键的单调行为是合并两个组永远不会减少每单位 k 攻击的总伤害； 它倾向于集中生存能力。 

最佳结构结果是贪婪的：我们应该创建尽可能多的单例组，因为每个单例在一次命中后立即被删除，并贡献最小的浪费重叠，而剩下的一个大组吸收其余的，最大化长尾损害。 

这个决定减少了我们能负担得起的单身人数。 如果我们创建 x 个单例组，则剩余组的大小为 n - x，组的总数为 x + 1，因此 x ≤ m - 1。权衡是平衡多个组的早期高伤害与一个大组的长期持续伤害。 

评估这种结构会产生一种封闭形式，我们在其中测试大组在重复 k 删除的情况下存活多长时间，同时考虑到每次攻击删除一个单例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将系统建模为具有一个潜在的大组和几个可选的单例组。 

1. 我们考虑选择 x 个单例组，其中 0 ≤ x ≤ min(m - 1, n)。 每个单例在被移除之前都贡献了一轮完整的边缘存在。 

原因是单身人士在被瞄准时会立即被杀死，并且由于敌人是最佳的，单身人士一旦变得相关就会被消耗掉。 
2. 剩余组的大小为 s = n - x。 该组决定了该过程的长期阶段，因为它需要消除多个 k 大小的攻击。 
3. 大群体在针对它的 ceil(s / k) 次攻击中幸存下来。 在每次此类攻击中，所有当前存活的侏儒都会在减少发生之前贡献全部伤害。 
4、有效回合总数等于单例移除次数加上大群被击中的次数。 由于敌人总是选择伤害减免效率最大化的群体，因此首先移除单体，然后将注意力转移到大群体上。 
5. 我们将总损害计算为这些阶段的贡献之和。 单态相贡献了 m - 1、m - 2、... 的递减序列，具体取决于排序，而大基团在其耗尽时贡献了三角形结构。 
6. 我们通过观察增加 x 线性增加早期伤害但超线性减少大群体的尾部贡献来评估最佳分割点。 最佳平衡发生在边界处，因此我们检查由 k 引起的临界分裂。 
7. 我们通过仅模拟过渡点来计算最佳值，其中大组相对于 k 的大小决定其维持多少个完整攻击周期，并将其与单例贡献相结合。 

### 为什么它有效

 该过程完全由每个组被选择减少多少次来决定，并且每次减少仅减少一组固定的上限k。 这使得除了敌人贪婪选择强加的调度顺序之外，每个组都是独立的。 由于每个侏儒每轮都会贡献一个单位的伤害，直到其群体减少到足以消灭它为止，因此分组只会影响这些消灭的时间。 

敌人的最佳策略是始终攻击那些减少了剩余活跃侏儒总数最快减少的群体，这与始终瞄准最大的群体是一致的。 这创建了一个单调结构，其中所有小团体首先被清除，然后大团体才占主导地位。 由于这种分离，最佳分区会分解为单参数族，从而使解决方案可简化为评估一个主要断点。

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())

    # If we can isolate all gnomes into singletons or small groups,
    # the process degenerates into repeated removal of k per group selection.
    # The key observation is that optimal structure reduces to a single large group
    # plus up to (m-1) singletons.

    # Let x be number of singletons.
    # remaining group size s = n - x

    # Each full "cycle" reduces large group by k, contributing triangular damage.

    # We evaluate best split by iterating only over possible critical points:
    # x = 0 or x = min(m-1, n) are sufficient due to monotonicity.

    x = min(m - 1, n)
    s = n - x

    # Damage from large group: sum of s + (s-k) + (s-2k) + ...
    def tri(sum_start):
        res = 0
        cur = sum_start
        while cur > 0:
            res += cur
            cur -= k
        return res

    ans = 0

    # case 1: all possible singletons
    ans = max(ans, x + tri(s))

    # case 2: no singletons
    s = n
    ans = max(ans, tri(s))

    print(ans)

if __name__ == "__main__":
    solve()
```该代码将大群体的贡献建模为以 k 步长递减的算术级数，这对应于对该群体的重复最优攻击。 辅助函数精确计算该组在其生命周期内造成的累积损害。 

然后我们比较两种边界配置：一种是我们最大化单例使用，另一种是我们不使用单例。 这些对应于两个结构极端，其中早期消除和长尾生存之间的权衡最为明显。 中间分裂不会改善结果，因为损伤函数在这些极端之间是单调的。 

这里的一个常见陷阱是尝试随着时间的推移显式模拟所有组。 在最坏的情况下，这会导致二次行为，并且是不必要的，因为损害仅取决于确定性耗尽下剩余组大小的序列。

### 示例 1

 输入：n = 10，m = 4，k = 3

 我们考虑 x = min(m-1, n) = 3 个单例，因此 s = 7。

单例贡献 3 轮额外贡献，每轮 1 轮，共 27 轮。

 | ---| --- | ---|
 | 无 | 0 | 0 |

 单例贡献 5 总伤害。 

这个大团体没有任何贡献，因为它不存在。 敌人无法有效地使用k，因为每个组都已经小于k。

 ## 边缘情况

 当 m = 1 时，整个系统崩溃为一个组。 该算法正确地简化为计算 k 的重复减法并对递减的前缀序列求和，因为单例策略是不可能的。 

当 k ≥ n 时，每次攻击都会立即删除整个组。 在这种情况下，分组成为主导，最佳解决方案是将组数最大化到 m，从而产生大部分单例行为。 该实现处理了这个问题，因为三角函数立即折叠为每组的单个项。 

当m≥n时，每个侏儒都可以被孤立。 最佳行为是微不足道的：每个侏儒在被移除之前恰好存活了一轮完整贡献，并且答案变为 n。 分割逻辑自然地通过 x = n 达到此配置。
