 ## 解决方案
 ## 问题理解

 该树描述了一个系统，其中每个节点都带有非负“流值”。 叶子代表独立的水源并且可以取任何正整数值。 每个内部节点代表一个汇合点，其值恰好是其子节点值的总和。 根只是聚合从其子树向上流动的所有内容的另一个节点。 

一些节点的流量值已经固定，而其他节点则未知。 必须选择一个未知值，以便所有求和关系在整个树中都成立。 任务是判断是否存在一个符合约束条件的所有节点值的有效赋值，如果存在，则输出。 如果有多个有效分配或根本没有，答案是“不可能”。 

约束允许最多$3 \cdot 10^5$节点，强制线性或接近线性的解决方案。 任何涉及子树上每个节点重新计算或重复流重新分配的操作都太慢。 该结构是一棵有根树，其边从父级到子级，因此每种有效的方法都必须利用单个 DFS 或 BFS 遍历。 

一个关键的微妙之处是，除非指定，否则叶子不是固定的，但内部节点会强制执行附加约束。 这意味着即使系统是一致的，它仍然可能会失败唯一性，因为不受约束的子树可以在内部重新分配质量而不影响任何已知节点。 

一种常见的失败情况是完全不受约束的子树。 例如，如果一个节点有两个子节点，并且两个子节点都不受下面任何位置的约束，那么即使父节点和是固定的，也有无限多种方法可以在两个分支之间分割该和。 任何仅检查总和的一致性而忽略唯一性的解决方案都将错误地接受此类情况。 

另一个微妙的情况是约束存在但稀疏。 考虑一个值为 10 的节点和两个子节点，一个子树包含受约束的叶子，另一个完全不受约束。 无约束子树吸收剩余部分，但如果该子树包含多个叶子，则其内部的分布仍然不固定，再次导致多个解决方案。 

最后，当固定值与其他约束隐含的子树总和不一致时，就会出现矛盾。 例如，如果一个节点固定为 5，但其子节点固定为 3，并且另一个子子树必须贡献至少 3（因为它至少包含一个叶子），则最小可能的总和超过 5，从而使配置变得不可能。 

## 方法

 一种直接的方法是将叶子值视为变量并向上传播约束。 对于每个节点，其值是其子树中所有叶子值的总和，因此每个固定节点对叶子变量施加线性方程。 人们可以尝试全局求解该系统，但这很快就变得不切实际，因为方程是按树结构嵌套的，并且解空间是高维的。 

另一个蛮力的想法是为叶子分配任意值并重复调整它们以满足每个固定节点。 这本质上是试图满足一个依赖约束的系统，但是调整会通过祖先传播，并且冲突可能会不可预测地级联。 在最坏的情况下，每次调整可能需要重新计算整个子树，从而导致二次行为。 

关键的观察是每个节点值完全由其子树中叶子的总和确定。 这将问题转化为控制子树和。 每个固定节点锚定其子树的总质量，剩下的唯一自由是如何在本身不受约束的子子树之间分配该质量。 

关键的结构是这样的：仅当一个节点具有多个完全不受任何固定节点约束的子子树时，才会出现歧义。 在这种情况下，质量可以在这些子树之间重新分配，而不影响任何约束。 相反，如果在每个分支点最多有一个子子树不受约束，则每个“自由质量”都被迫沿着唯一的路径流动，直到到达叶子，从而消除了歧义。 

这导致了两相解决方案。 首先，我们使用子树聚合检查约束的可行性。 然后我们检查该结构是否在任何地方都允许多个自由度。 如果确实如此，那么答案并不唯一。 如果没有，则可以通过向下传播固定和来确定性地重建值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力重新分配| 指数| O(n) | 太慢了|
 | 没有结构检查的子树方程 | O(n) | O(n) | 不正确（非独特情况）|
 | 具有唯一性约束的树DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将树的根设为 1 并使用子树信息。

### 第 1 步：识别受约束的节点

 我们标记每个具有固定值的节点。 这些节点充当完全确定子树总和的锚点。 

### 步骤 2：计算子树“约束覆盖率”

 我们从叶子向上执行 DFS。 对于每个节点，我们确定其子树是否包含至少一个受约束节点。 这是至关重要的，因为只有具有至少一个约束的子树才能被系统唯一地固定。 

如果子树不包含任何约束，则其内部分布是完全自由的，这已经威胁到了唯一性。 

### 步骤 3：检查分支歧义

 对于每个节点，我们检查它的子节点。 我们计算有多少子子树不包含受约束的节点。 如果该计数至少为 2，则配置立即不唯一，因为这两个子树可以交换任意数量的流，同时满足所有约束。 

该条件捕获了系统中的所有自由度。 

### 步骤 4：自下而上传播子树求和

 我们尽可能计算实际节点值。 如果一个节点有固定值，我们就采用它。 否则，如果除了一个子子树之外的所有子子树都有确定的总和，则一旦知道该总和，就强制从父总和中减去剩余的子子树。 

这种传播只能在通过唯一性检查的树中进行，因为否则就会有多个未知的分支。 

### 第 5 步：验证积极性

 每片叶子最终都必须具有正值。 由于叶子代表源，任何零或负的计算值都意味着不一致。 

### 为什么它有效

 每个节点值都等于其子树中叶子变量的总和，因此系统在具有树结构约束矩阵的叶子上基本上是线性的。 唯一性条件相当于要求无约束叶子的每个连通区域在由约束导出的商图中具有大小一。 DFS 条件确保没有节点允许两个独立的无约束子树在固定总和下共存，这正是质量唯一分解的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
p = [0] * (n + 1)
parents = list(map(int, input().split()))
for i in range(2, n + 1):
    p[i] = parents[i - 2]

a = [0] + list(map(int, input().split()))

children = [[] for _ in range(n + 1)]
for i in range(2, n + 1):
    children[p[i]].append(i)

fixed = [False] * (n + 1)
for i in range(1, n + 1):
    if a[i] != 0:
        fixed[i] = True

has_fixed = [False] * (n + 1)
bad = [False]

def dfs(u):
    hf = fixed[u]
    zero_free_children = 0

    for v in children[u]:
        cf = dfs(v)
        hf = hf or cf
        if not cf:
            zero_free_children += 1

    if zero_free_children >= 2:
        bad[0] = True

    has_fixed[u] = hf
    return hf

dfs(1)

if bad[0]:
    print("impossible")
    sys.exit()

ans = a[:]

def assign(u, forced_sum=None):
    # forced_sum is the sum required by ancestors if known
    cur = a[u] if a[u] != 0 else None

    child_unknown = []
    known_sum = 0

    for v in children[u]:
        if a[v] != 0:
            known_sum += a[v]
        else:
            child_unknown.append(v)

    if cur is not None:
        remaining = cur - known_sum
        if remaining < len(child_unknown):
            print("impossible")
            sys.exit()

        if len(child_unknown) == 1:
            a[child_unknown[0]] = remaining

        elif len(child_unknown) > 1:
            # split minimally, but uniqueness guarantees this won't happen
            for v in child_unknown[:-1]:
                a[v] = 1
            a[child_unknown[-1]] = remaining - (len(child_unknown) - 1)

    for v in children[u]:
        assign(v)

assign(1)

if any(a[i] == 0 for i in range(1, n + 1)):
    print("impossible")
else:
    print(*a[1:])
```第一个 DFS 计算每个子树是否包含固定节点，并检测两个无约束子树共存的任何分支点，这会立即破坏唯一性。 

第二阶段尝试向下传播已知和。 如果一个节点有固定值，它会对其子节点强制执行预算。 当只有一个孩子不受约束时，该孩子被迫承担整个剩余的质量，这是保留唯一性的唯一情况。 

最终检查确保没有节点保持未设置状态。 

## 工作示例

 ### 示例 1

 考虑一棵小树，其中根有两个子树，一个子树受到完全约束。 

| 节点| 固定| 已在子树 | 中修复 不受约束的孩子算|
 | --- | --- | --- | --- |
 | 根 | 是的 | 是的 | 0 |
 | 左| 没有| 是的 | 0 |
 | 对| 没有| 没有| 1 |

 DFS 检测到没有节点具有两个完全不受约束的子子树，因此该结构通过。 

然后，传播分配根和，减去已知的贡献，并强制剩余的子树值唯一。 

这证实了单个无约束分支是可接受的，因为它完全由减法确定。 

### 示例 2

 具有两个独立的无约束子树的根：

 | 节点| 固定| 已在子树 | 中修复
 | --- | --- | --- |
 | 根 | 是的 | 是的 |
 | 左孩子 | 没有| 没有|
 | 右孩子| 没有| 没有|

 在根部，两个子树都是不受约束的子树。 DFS 检测到两个这样的分支，立即将该实例标记为不可能。 这证明了关键的歧义：根和可以在两侧任意分割。

 ## 边缘情况

 一种重要的边缘情况是，一个节点恰好有两个子节点，并且其中只有一个包含任何固定节点。 在这种情况下，算法不会拒绝该配置，因为只有一棵空闲子树。 剩余的子树完全通过固定父树的减法确定，并且其中的所有叶子通过向下传播唯一确定。 

另一种情况是根本没有固定节点。 每个子树都是不受约束的，并且在每个内部节点处都可能有多个独立的分裂。 DFS 立即检测到根处的多个不受约束的分支并拒绝该实例。 

最后一个微妙的情况是一条深链，其中约束仅出现在底部。 尽管中间节点不受约束，但每个节点在每一步最多有一个不受约束的子子树，因此一旦叶子约束向上传播，结构仍然是唯一确定的。
