 ## 解决方案
 ## 问题理解

 我们有一个戏剧俱乐部`n`男孩和`m`女孩们。 性能组必须准确包含`t`人，有两个额外的限制：其中至少 4 名必须是男孩，至少 1 名必须是女孩。 

任务是计算可以形成多少个不同的有效组。 如果至少有一个选定的人不同，则两个群体被视为不同。 

限制非常小。 两个都`n`和`m`最多 30 个，因此即使相当昂贵的组合计算也是安全的。 答案也适合 64 位整数，这意味着我们可以直接计算组合而无需模运算。 

从约束中观察到的关键是我们不需要先进的优化技术。 可能的男孩计数很小，因为所选组的规模很大`t`，且男生必须贡献至少4名成员。 我们可以简单地尝试一切可行的男孩和女孩之间的划分。 

如果迭代边界不小心，有一些边缘情况很容易产生错误的答案。 

考虑这个输入：```
4 10 5
```唯一有效的组合是 4 个男孩和 1 个女孩。 正确答案是：```
40
```如果男孩从 0 而不是 4 开始的错误循环会计算出许多无效球队。 

另一个棘手的情况是，没有足够的女孩可以参加特定的分组。```
10 1 8
```唯一有效的组合是 7 个男孩和 1 个女孩。 选择 6 个男孩和 2 个女孩是不可能的，因为只有一个女孩存在。 盲目计算所有分割的组合的粗心实现可能会尝试无效值，例如`C(1, 2)`。 

当出现另一种微妙的情况时`t`接近于`n + m`。```
4 1 5
```只有一个有效的组：每个人都必须被选中。 

上限不正确的循环可能会意外地跳过选择所有男孩的情况。 

## 方法

 蛮力的想法很简单。 我们可以枚举每个人的子集并检查其大小是否准确`t`，是否至少包含 4 个男孩，是否至少包含 1 个女孩。 

这是有效的，因为每个有效的剧团都恰好对应一个子集。 问题是子集的数量。 最坏的情况下总共有 60 人，这意味着`2^60`子集。 这是一个天文数字，远远超出了 2 秒的运行速度。 

问题的结构给出了更好的方向。 我们实际上并不关心枚举时的身份，只关心有多少男孩和女孩被选中。 

假设我们确定该组恰好包含`b`男孩们。 那么女生的数量就被迫为`t - b`。 

对于这个固定分割：```
ways = C(n, b) * C(m, t - b)
```因为我们独立选择`b`男孩来自`n`和`t - b`女孩来自`m`。 

唯一剩下的任务是迭代每个有效值`b`。 

暴力方法会失败，因为它单独处理每个子集。 组合方法通过组合将大量子集组合在一起。 我们不是检查单个组，而是一次计算一个结构的所有组。 

由于最多有 30 个可能的值可供尝试，因此该解决方案足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n+m)) | O(2^(n+m)) | O(1) | O(1) | 太慢了|
 | 最佳 | O(t) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`m`， 和`t`。 
2. 迭代所选男孩的数量，称其为`boys`。 
3、男孩的最小有效数量是4，因为声明要求至少有4个男孩。 
4. 男孩的最大有效数量为`min(n, t - 1)`。 

我们不能选择更多`n`男孩，我们必须为至少一个女孩留出空间。 
5. 对于每个有效`boys`值，计算：```
girls = t - boys
```6. 数一下选择这些人的方式：```
C(n, boys) * C(m, girls)
```7. 将此值添加到答案中。 
8. 打印最终答案。 

### 为什么它有效

 每个有效的剧团都有唯一数量的被选中的男孩。 当我们迭代所有可行的男孩计数时，每个有效的剧团恰好出现在一次迭代中。 

对于固定分割`(boys, girls)`，选择是独立的。 我们首先选择哪些男孩参加，然后选择哪些女孩参加。 将两个组合计数相乘即可得出具有该组合的剧团的确切数量。 

由于循环覆盖了所有有效的作品并且没有作品与其他作品重叠，因此最终的总和只对每个有效的剧团进行一次计数。 

## Python 解决方案```python
import sys
from math import comb

input = sys.stdin.readline

n, m, t = map(int, input().split())

answer = 0

for boys in range(4, min(n, t - 1) + 1):
    girls = t - boys
    
    if 1 <= girls <= m:
        answer += comb(n, boys) * comb(m, girls)

print(answer)
```解决方案直接遵循组合推理。 

循环从 4 开始，因为违反规则的男孩较少。 上限是`min(n, t - 1)`因为我们不能选择比现有更多的男孩，并且选择所有`t`人们作为男孩会留下零个女孩。 

支票：```
if 1 <= girls <= m:
```防止无效的女孩计数。 如果没有这个条件，我们可以尝试不可能的选择，例如在只有 2 个女孩存在时选择 5 个女孩。 

蟒蛇的`math.comb`有效计算精确的二项式系数并安全地处理所需的范围。 由于答案适合 64 位整数范围，因此溢出不是问题。

# helper: run solution on input string, return output string
import sys, io
from math import comb

def solve():
    input = sys.stdin.readline
    
    n, m, t = map(int, input().split())
    
    ans = 0
    
    for boys in range(4, min(n, t - 1) + 1):
        girls = t - boys
        
        if 1 <= girls <= m:
            ans += comb(n, boys) * comb(m, girls)
    
    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out
    
    solve()
    
    sys.stdout = backup
    return out.getvalue().strip()

# provided sample
assert run("5 2 5\n") == "10", "sample 1"

# minimum valid configuration
assert run("4 1 5\n") == "1", "minimum sizes"

# only one possible girl count
assert run("10 1 8\n") == str(comb(10, 7)), "single girl available"

# multiple valid splits
assert run("6 3 7\n") == "36", "multiple compositions"

# larger boundary-style case
assert run("30 30 30\n") == str(
    sum(comb(30, b) * comb(30, 30 - b)
        for b in range(4, 30))
), "large values"

 ## 边缘情况

 考虑输入：```
4 10 5
```该算法从 4 开始迭代男孩计数。唯一有效的分割是：```
boys = 4
girls = 1
```计算变为：```
C(4,4) * C(10,1) = 1 * 10 = 10
```男孩少于 4 名的无效病例不予考虑。 

现在检查：```
10 1 8
```循环检查：

 | 男孩 | 女孩| 有效的？ |
 | ---| ---| ---|
 | 4 | 4 | 没有 |
 | 5 | 3 | 没有 |
 | 6 | 2 | 没有 |
 | 7 | 1 | 是的 |

 只有最后一行满足`girls <= m`。 答案变成：```
C(10,7) * C(1,1) = 120
```这证实了在添加组合之前验证女孩数量的重要性。 

最后，考虑：```
4 1 5
```循环范围为：```
range(4, min(4, 4) + 1)
```其中只包含一个值：```
boys = 4
girls = 1
```该算法正确地计算出了包含所有人的单个剧团。
