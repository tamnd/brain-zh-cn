 ## 解决方案
 ## 问题理解

 我们在棋盘上被赋予了皇后的位置。 皇后向八个方向攻击：左、右、上、下和四个对角线。 蚁后不会攻击某个方向上的所有蚁后，只会攻击沿该光线遇到的第一个蚁后。 

对于每个皇后，我们必须计算它直接攻击了多少个其他皇后。 该值介于 0 和 8 之间，因为只有八个可能的方向。 为每个皇后计算出这个数字后，我们构建一个数组，其中`t[i]`是攻击的皇后数量`i`其他女王。 

棋盘尺寸和皇后数量都为`10^5`。 二次解立即被排除。 检查每对皇后大约需要`10^10`最坏情况下的比较，远远超出了两秒钟的时间。 该解决方案必须保持接近`O(m log m)`或更好。 

棘手的部分是“只有这个方向的第一个女王”这句话。 一个幼稚的实现可能会计算共享相同行、列或对角线的每个皇后。 那是错误的。 

考虑这个例子：```
5 3
2 1
2 3
2 5
```皇后都在同一排。 

正确的攻击次数是：

 -`(2,1)`攻击`(2,3)`-`(2,3)`攻击两个邻居
 -`(2,5)`攻击`(2,3)`所以计数是`[1,2,1]`，输出为：```
0 2 1 0 0 0 0 0 0
```如果粗心的解决方案对同一行中的每个皇后进行计数，则会错误地给出计数`[2,2,2]`。 

对角线处理是错误的另一个常见来源。 仅当两个皇后在同一条对角线上时`r - c`或者`r + c`匹配。 

例如：```
5 2
1 5
3 3
```这些女王躺在同一个地方`/`对角线因为：```
1 + 5 = 6
3 + 3 = 6
```仅检查解决方案`r - c`会错过这次攻击。 

当几个皇后共享一条线但排序后不相邻时，会发生另一种微妙的情况。```
8 4
4 1
4 3
4 5
4 8
```只有排中相邻的皇后才会互相攻击。 列中的皇后们`1`和`5`不互动，因为`(4,3)`挡住了道路。 

## 方法

 蛮力的想法很简单。 对于每个皇后，扫描所有其他皇后并检查它们是否位于八个方向之一。 如果它们这样做，请确定是否有另一个皇后挡住了路径。 这是合乎逻辑的，因为国际象棋运动是几何的，并且很容易用坐标算术进行测试。 

问题是成本。 有`m`皇后，所以检查所有对已经需要`O(m^2)`。 和`m = 10^5`，那就变成`10^10`在考虑阻塞逻辑之前进行配对检查。 

皇后运动的结构提供了一种更好的方法。 皇后仅与共享的皇后互动：

 - 同一行
 - 同一列
 - 一样`r - c`对角线
 - 一样`r + c`对角线

 在这些行中的任何一行中，只有排序后相邻的皇后才能互相攻击。 如果两个皇后之间有另一个皇后在同一条线上，则较近的皇后会挡住较远的皇后。 

这一观察完全改变了问题。 我们不是比较每一对，而是按行对皇后进行分组：

 - 行分组依据`r`- 列分组依据`c`- 对角线分组依据`r - c`- 反对角群`r + c`在每个组内，我们沿线对位置进行排序。 然后，每对相邻的对在每个方向上都贡献一次攻击。 

例如，如果一行在列中包含皇后：```
1, 4, 7
```然后：

-`1`攻击`4`-`4`攻击两者`1`和`7`-`7`攻击`4`这对`(1,7)`从不直接互动。 

每个皇后最多参与每种线型的两个相邻关系，因此整个计算变得高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(平方米) | O(1) | O(1) | 太慢了|
 | 最佳 | O(m log m) | O(米) | 已接受 |

 ## 算法演练

 1. 读取所有皇后位置并为每个皇后分配一个索引。 

我们需要稳定的存储，因为最终的攻击计数属于每个特定的皇后。 
2. 创建四个哈希映射。 

每张地图将共享一条攻击线的皇后组合在一起：

 - 行按`r`- 列按`c`- 主对角线`r - c`- 反对角线`r + c`3. 将每个皇后插入所有四组中。 

每个存储的条目都包含足够的信息，可以沿该行对皇后进行排序并稍后恢复皇后索引。 
4. 对于每个行组，按列排序。 

排序后相邻的皇后正是水平方向看到的皇后。 
5. 对于排序行中的每个相邻对，增加两个皇后的攻击计数器。 

如果皇后`A`和`B`按排序顺序是连续的，中间没有皇后，所以它们直接互相攻击。 
6. 对列组重复相同的过程。 

这里我们按行排序，因为移动是垂直的。 
7. 重复`r - c`对角线组。 

按行排序就足够了，因为行和列沿着这条对角线一起增加。 
8. 重复`r + c`对角线组。 

同样，按行排序给出了沿线的正确顺序。 
9. 四个结构都处理完毕后，每个皇后都有其被攻击皇后的总数。 
10. 构建数组`ans[0...8]`。 

对于每个皇后的攻击计数`k`, 增量`ans[k]`。 
11. 打印频率数组。 

### 为什么它有效

 在任何行、列或对角线内，皇后只攻击每个方向上最近的邻居。 沿着一条线对皇后进行排序会将那些最近的邻居暴露为相邻元素。 

每个直接攻击关系在一个线组中作为相邻对出现一次。 不会错过任何攻击，因为每个有效攻击都位于四种线路类型之一。 不会添加额外的攻击，因为不相邻的皇后总是有另一个皇后挡住路径。 

由于我们增加了每个相邻对的两个端点，因此每个皇后都会精确地累积它攻击的皇后的数量。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def process(groups, cnt):
    for arr in groups.values():
        arr.sort()

        for i in range(len(arr) - 1):
            _, a = arr[i]
            _, b = arr[i + 1]

            cnt[a] += 1
            cnt[b] += 1

def solve():
    n, m = map(int, input().split())

    rows = defaultdict(list)
    cols = defaultdict(list)
    diag1 = defaultdict(list)   # r - c
    diag2 = defaultdict(list)   # r + c

    cnt = [0] * m

    for idx in range(m):
        r, c = map(int, input().split())

        rows[r].append((c, idx))
        cols[c].append((r, idx))
        diag1[r - c].append((r, idx))
        diag2[r + c].append((r, idx))

    process(rows, cnt)
    process(cols, cnt)
    process(diag1, cnt)
    process(diag2, cnt)

    ans = [0] * 9

    for x in cnt:
        ans[x] += 1

    print(*ans)

solve()
```解决方案围绕`process`功能。 每组包含共享一条攻击线的皇后。 元组存储为：```
(position_along_line, queen_index)
```排序后，连续的皇后成为沿着这条线的直接邻居。 对于每对相邻的一对，两个皇后都会获得一次攻击。 

相同的逻辑适用于行、列和两条对角线，因为所有皇后运动都是线性的。 唯一的区别在于团体的形成方式。 

使用`r - c`确定一个对角线方向，因为该值沿方向保持不变`\`对角线。 使用`r + c`确定另一个对角线方向，因为该值沿方向保持不变`/`对角线。 

一个微妙的实现细节是增加每个相邻对的两个端点。 皇后攻击在这里是对称的。 如果`A`看到`B`， 然后`B`还看到`A`从相反的方向。 

另一个容易犯的错误是对角线的排序不正确。 沿着固定的对角线，按行排序也会自动按列排序，因此单个坐标就足够了。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(m log m) | 每个皇后都参与四组内的排序 |
 | 空间| O(米) | 哈希图和攻击计数器在每个结构中存储所有皇后一次 |

 存储的数据总量与皇后的数量成线性关系。 排序在运行时占据主导地位。 由于所有组的大小总和是`m`，总分拣成本保持不变`O(m log m)`，这很容易满足限制`10^5`皇后。

 ## 边缘情况

 考虑在同一行上有多个皇后并阻塞：```
5 3
2 1
2 3
2 5
```行组变为：```
[(1,A), (3,B), (5,C)]
```该算法处理相邻对：

 -`A-B`-`B-C`它永远不会连接`A-C`因为排序后它们不相邻。 由此产生的攻击计数为：```
A = 1
B = 2
C = 1
```这是正确的。 

现在考虑反对角线攻击：```
5 2
1 5
3 3
```两位皇后都满足：```
r + c = 6
```所以他们输入相同的`diag2`团体。 排序后，它们相邻并且都获得一次攻击。 最终输出是：```
0 2 0 0 0 0 0 0 0
```这证实了两个对角线方向都是独立处理的。 

最后，考虑皇后共享一条对角线但被阻挡：```
6 3
1 1
3 3
5 5
```排序后的对角群为：```
[(1,A), (3,B), (5,C)]
```只有相邻对才有贡献：

 -`A-B`-`B-C`皇后们`A`和`C`永远不要互相攻击，因为`B`挡住了道路。 计数变为：```
1 2 1
```与实际的国际象棋动作完全匹配。
