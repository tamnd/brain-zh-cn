 ## 解决方案
 ## 问题理解

 我们被要求计算所有分配的数字完全相反的客户对。 每个客户端有一个-10到10之间的数字，如果一个客户端有数字，则一对有效$x$另一个有号码$-x$。 零被认为是它自己的对立面，因此两个编号为 0 的客户端形成有效对。 客户端的顺序并不重要，因此每对只应计数一次，并且客户端不能与自己配对。 

输入由客户端数量组成$n$以及他们分配的号码列表$t_1, t_2, \dots, t_n$。 输出是有效相反对的总数。 

自从$n$可以大到$10^5$，一种明确检查所有对的蛮力方法大约需要$n^2/2$操作，即$5 \cdot 10^9$在最坏的情况下。 这对于 2 秒的限制来说太慢了，所以我们需要一个线性或接近线性的解决方案。 所有数字都在一个小的固定范围内，这暗示了基于计数的方法。 边缘情况包括全零、重复的数字和负正对称。 例如，如果输入是`0 0 0`，有 3 对：`(1,2)`,`(1,3)`,`(2,3)`。 使用两个循环检查配对的简单方法可能会重复计数配对或错过零自配对。 

## 方法

 暴力方法很简单：迭代所有客户端对，检查它们的数字是否相反，然后递增计数器。 这适用于正确性但会运行$O(n^2)$，这对于$n=10^5$因为它会执行大约$5 \cdot 10^9$比较。 内存可以忽略不计，但运行时使得这种方法不可接受。 

最佳方法使用计数策略。 首先，创建列表中所有数字的频率图。 对于每个数字$x$, 与其相反的有效对的数量$-x$是计数的乘积$x$和计数$-x$。 零需要特殊处理：零之间的对数为$\binom{count_0}{2} = count_0 \cdot (count_0-1)/2$。 为了避免重复计算，在将计数与其相反数相乘时仅考虑正数（包括零）。 

由于数字很小且有界，因此可以使用长度为 21（-10 到 10）的固定大小数组或字典来跟踪计数。 这将运行时间减少到$O(n)$用于计数和$O(1)$用于使用固定数量的可能值来计算对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1)（固定数组）| 已接受 |

 ## 算法演练

 1.初始化一个计数器数组`freq`大小为 21，用于存储从 -10 到 10 的数字的频率。数字的索引$x$是`x + 10`。 
2. 迭代输入列表并递增相应的索引`freq`对于每个数字。 这在线性时间内构建了频率图。 
3. 初始化变量`pairs`为 0 来存储相反对的总数。 
4. 迭代从 1 到 10 的数字。对于每个数字`x`, 乘以`freq[x + 10]`经过`freq[-x + 10]`并将结果添加到`pairs`。 这会将所有具有相反数字的对计数一次，而不会重复计数。 
5. 单独处理零位。 如果`freq[10]`是零的数量，添加`freq[10] * (freq[10] - 1) // 2`到`pairs`考虑所有零零对。 
6. 打印值`pairs`。 

为什么它有效：该算法通过使用每个数字的不变量来正确计算所有对$x > 0$，我们将所有带负数的组合都包含一次。 零用组合公式处理，因为它与自身配对。 这可确保不会对任何配对进行两次计数，并且不会发生无效的自配对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
nums = list(map(int, input().split()))

# frequency array for numbers -10 to 10
freq = [0] * 21
for num in nums:
    freq[num + 10] += 1

pairs = 0
# count positive-negative pairs
for i in range(1, 11):
    pairs += freq[i + 10] * freq[-i + 10]

# count zero pairs
pairs += freq[10] * (freq[10] - 1) // 2

print(pairs)
```第一部分读取输入并构造频率数组。 正数循环计算带有负数的对，而不会重复计算。 零情况使用组合公式从中选择 2 个元素`freq[10]`零。 我们使用整数除法来获得精确的整数计数。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    nums = list(map(int, input().split()))
    freq = [0]*21
    for num in nums:
        freq[num+10] += 1
    pairs = 0
    for i in range(1, 11):
        pairs += freq[i+10]*freq[-i+10]
    pairs += freq[10]*(freq[10]-1)//2
    return str(pairs)

 ## 边缘情况

 对于零情况，输入`0 0 0`结果频率`freq[10] = 3`。 配对计数公式计算`3*2/2 = 3`对，正确枚举`(1,2)`,`(1,3)`,`(2,3)`。 对于所有相同的正数，例如`1 1 1`，计数数组有`freq[11] = 3`， 但`freq[-1+10] = freq[9] = 0`，因此不会添加任何对。
