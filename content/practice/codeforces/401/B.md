 ## 解决方案
 ## 问题理解

 比赛平台按开始时间对每轮进行连续编号。 一轮可以是独立的 Div2 轮，也可以是 Div2 获取标识符的一对同时轮`i`Div1 获取标识符`i + 1`。 

Sereja 只参加 Div2 轮次。 现在他正在参加一轮`x`，而在此之前他正好参加了`k`较早的 Div2 轮次。 对于每一次早期的参与，他都记得：

 - 带有标识符的独立 Div2 回合`a`- 或同时对`(a, a + 1)`在哪里`a`是 Div2 标识符

 所有记住的标识符都小于`x`。 

缺失的信息是关于他跳过的回合的所有信息。 一些未使用的标识符可能对应于独立的 Div2 回合，并且一些可能属于同时对。 我们必须计算：

 - Sereja 可能错过的 Div2 轮次最少数量
 - Sereja 可能错过的 Div2 轮数上限

 限制很小。 所有标识符都低于 4000，因此即使是`O(x^2)`解决方案会轻松通过。 这意味着挑战不是性能，而是正确建模编号规则。 

危险的部分是理解标识符的含义。 独立 Div2 回合消耗一个标识符。 一对同时消耗两个连续的标识符，其中较小的一个是 Div2 轮，较大的一个是 Div1 轮。 

粗心的实现通常会独立对待每个未使用的标识符，但这是错误的，因为两个连续的标识符实际上可能属于一对同时存在的标识符。 

考虑这个例子：```
x = 8
known rounds:
2 2
2 5
```使用的标识符是`{2, 5}`。 未使用的标识符是`{1, 3, 4, 6, 7}`。 

如果我们最大化错过的 Div2 回合，我们可以使每个未使用的标识符成为独立的 Div2 回合，从而错过 5 轮。 

如果我们尽量减少错过的 Div2 回合，我们应该尽可能将标识符组合成同时对：

 -`(3,4)`可以同时是一对
 -`(6,7)`可以是另一对同时存在的
 -`1`必须保持独立

 这样一来，Div2 就只有 3 轮缺席。 

另一个微妙的情况是当记住的同时对阻止相邻标识符时。```
x = 6
known:
1 2 3
```标识符`2`和`3`已经被一对同时占用。 我们无法另外配对`(1,2)`或者`(3,4)`，因为标识符不能属于两个不同的轮次。 

正确的处理需要跟踪哪些标识符已被使用。 

## 方法

 一个蛮力的想法是重建与记住的回合一致的每个有效比赛时间表，然后计算 Sereja 在每次重建中跳过了多少 Div2 回合。 由于每个未使用的标识符都可以是：

 - 独立的 Div2 回合
 - 同时对的一部分
 - 或同时对内的仅 Div1 标识符

 可能性的数量呈指数级增长。 

例如，如果有 2000 个未使用的标识符，尝试所有分配将是没有希望的。 

关键的观察是我们永远不需要完整的时间表。 我们只关心未使用的标识符中存在多少 Div2 轮。 

假设我们标记每个小于`x`已经出现在输入中。 剩余的每个标识符都是免费的。 

对于最大的答案，策略是显而易见的。 每个免费标识符都可以成为独立的 Div2 回合。 每一个这样的选择都会导致错过 Div2 一轮，并且没有什么可以阻止这种构造。 因此最大值等于空闲标识符的数量。 

最低限度的答案就是贪婪想法出现的地方。 

一对同时消耗两个连续的标识符，但仅贡献一轮 Div2。 因此，为了尽量减少错过 Div2 回合，我们应该在空闲标识符中创建尽可能多的同时对。 

这变成了一个简单的区间配对问题：

 - 从左到右扫描标识符
 - 当两个连续的标识符都空闲时，将它们配对在一起
 - 否则将当前标识符保留为独立的 Div2 回合

 这种贪婪的方法之所以有效，是因为将两个空闲的连续标识符配对总是会将 Div2 轮数减少一圈，并且稍后使用标识符无法创造更好的机会。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(x) | O(x) | 已接受 |

 ## 算法演练

 1. 创建布尔数组`used`对于来自的标识符`1`到`x - 1`。 
2. 阅读记住的每个回合描述。 
3. 如果描述的是独立 Div2 回合`2 a`, 标记标识符`a`如所用。 
4.如果描述的是同时对`1 a b`, 标记两者`a`和`b`如所用。 
5. 计算有多少个标识符`1`到`x - 1`未使用。 此计数是错过 Div2 回合的最大可能次数。 

每个未使用的标识符都可以独立成为一个独立的 Div2 回合。 
6. 要计算最小答案，请扫描以下标识符`1`到`x - 1`。 
7. 如果当前标识符已被使用，则跳过它。 
8. 否则，检查下一个标识符是否存在且未使用。 

如果两者都是空闲的，则从它们中同时创建一对。 将答案加 1 并跳过两个标识符。 
9. 如果无法配对，则当前标识符必须成为独立的 Div2 回合。 将答案加 1，向前移动一步。 

### 为什么它有效

 最大构造很简单，因为每个未使用的标识符都可以代表一个独立的 Div2 回合。 

对于最小结构，不变的是每次我们遇到两个连续的空闲标识符时，将它们配对总是最佳的。 一对消耗两个标识符，同时只贡献一个错过的 Div2 回合。 不配对任何一个标识符永远不会进一步减少总数。 

贪婪扫描总是创建最大可能数量的不相交的连续对。 由于每一对都会将错过 Div2 轮数的次数减少一倍，这也会使最终答案最小化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x, k = map(int, input().split())

    used = [False] * (x + 2)

    for _ in range(k):
        parts = list(map(int, input().split()))

        if parts[0] == 1:
            _, a, b = parts
            used[a] = True
            used[b] = True
        else:
            _, a = parts
            used[a] = True

    # maximum answer
    mx = 0
    for i in range(1, x):
        if not used[i]:
            mx += 1

    # minimum answer
    mn = 0
    i = 1

    while i < x:
        if used[i]:
            i += 1
            continue

        if i + 1 < x and not used[i + 1]:
            mn += 1
            i += 2
        else:
            mn += 1
            i += 1

    print(mn, mx)

solve()
```这`used`数组记录已经属于记住的回合的每个标识符。 对于同时进行的回合，我们标记两个标识符，因为两者都不能在以后重复使用。 

最大答案就是未使用标识符的数量。 他们中的每一个都可以代表一个独立的 Div2 回合。 

最小答案使用贪婪扫描。 微妙的部分是边界条件`i + 1 < x`。 标识符`x`本身属于当前轮次，不能重复使用，因此只有严格小于的标识符`x`事情。 

另一个容易犯的错误是在形成一对后忘记跳过这两个标识符。 如果我们配对`(i, i + 1)`，两个标识符都被消耗并且不得再次参与。

 ## 边缘情况

 考虑最小的有效输入：```
1 0
```没有小于以下的标识符`1`，所以扫描范围为空。 该算法正确地产生：```
0 0
```一个常见的差一错误错误地包含了标识符`x`本身并返回`1 1`。 

现在考虑：```
6 1
1 2 3
```标识符`2`和`3`已经被记住的同时对占据。 

免费标识符有`{1, 4, 5}`。 

贪婪扫描的行为如下：

 -`1`无法配对`2`，所以它变得独立
 -`4`与`5`总最小值为`2`。 

最大值为`3`因为每个免费标识符都可能变得独立。 

正确输出：```
2 3
```仅标记记忆对中的 Div2 标识符的错误实现会错误地认为标识符`3`是免费的并产生无效的配对。 

最后，考虑：```
8 3
2 1
2 3
2 5
```免费标识符有`{2, 4, 6, 7}`。 

贪心过程：

 -`2`无法配对`3`-`4`无法配对`5`-`6`与`7`最小值变为`3`， 不是`2`。 

这会捕获尝试配对非连续空闲标识符的实现。
