 ## 解决方案
 ## 问题理解

 我们在整数网格上得到了相同数量点的两种配置。 将它们视为放置在晶格点上的两张无法区分的粒子的图画。 粒子可以移动，但只能通过非常具体的集体操作。 

在一步操作中，我们选择一个粒子并选择四个基本方向之一。 该选定的粒子朝该方向移动一步，而所有其他粒子同时朝相反方向移动一步。 每次移动后，不允许两个粒子占据同一个单元。 

问题是，在一系列这样的移动之后，如果我们还允许在最后应用整个图片的整体移动，并且我们不关心哪个粒子对应于哪个标签，那么初始配置是否有可能成为目标配置。 

高达 100000 的约束 n 迫使任何解接近线性或线性算数。 任何涉及成对比较、移动模拟或点之间的图形匹配的操作都会立即变得太慢，因为 n 平方约为 10^10 运算。 

一个微妙的困难是该操作同时耦合所有点。 天真的解释可能会建议单独跟踪坐标，但每次移动都会同时改变所有点，这使得局部推理产生误导。 

第二个隐藏的问题是点的身份无关紧要。 任何尝试将第 i 个初始点与第 i 个目标点匹配的解决方案在相同结构的排列上都会失败。 

## 方法

 直接的暴力方法将模拟所有可能的移动序列。 每个状态都是 n 个点的完整配置，每个移动分为 4 个方向选择和 n 个选择“引导”移动。 这会产生一个巨大的状态图，甚至忽略分支，不同配置的数量在移动数量上呈指数级增长。 即使对于非常小的 n，这也会很快变得难以管理。 

关键的观察结果是，每个移动都有一个非常结构化的效果：一个点沿方向 v 移动，而所有其他点沿相反方向移动。 这可以重写为所有点的全局平移 -v，加上仅应用于所选点的额外 2v。 由于最终答案允许任意转换，因此在比较配置时可以忽略全局移位分量。 剩下的就是每次移动都会有效地将 ±2e_x 或 ±2e_y 形式的向量添加到单个选定点，同时保留其他所有内容直至平移。 

这立即表明只有模 2 的信息才重要。 每次更新都会将所有点的坐标更改 ±1，这意味着每个坐标奇偶校验都会同时翻转。 因此，虽然绝对位置以复杂的方式变化，但点在四个奇偶校验类别中的位置结构以非常有限的方式演变：它仅经历奇偶校验的全局异或移位。 

这将问题从几何问题简化为四个奇偶校验类别的计数问题。

 ## 算法演练

 我们将每个点转换为其奇偶校验类，这意味着我们仅存储 (x mod 2, y mod 2)。 恰好有四种可能的类别。 

然后，我们利用每个操作同时翻转奇偶校验空间中每个点的两个坐标这一事实，这对应于使用相同的固定 2 位向量对所有奇偶校验类进行异或。

1. 计算每个初始点的奇偶类别，并计算有多少个点属于四个类别中的每一个。 这给出了 4 维频率向量。 
2. 对目标配置执行相同的操作。 
3. 尝试所有四种可能的全球平价转变。 移位对应于将每个初始点的两个坐标与 {0,1}² 中的固定 (dx, dy) 进行异或。 
4. 对于每个班次，重新计算应用初始奇偶分布后的结果。 
5. 如果初始奇偶校验计数的任何移位版本与目标奇偶校验计数完全匹配，则答案是可能的。 
6. 否则，任何操作序列都无法将一种配置转换为另一种配置。 

其有效的唯一原因是该操作不能创建或破坏点之间的相对奇偶校验结构，它只能一致地翻转所有内容或保留成对奇偶校验关系。 

### 为什么它有效

 每一步都会翻转每个点的每个坐标的奇偶性。 因此，在任意次数的移动之后，所有点都已通过奇偶校验空间中的相同全局异或进行变换，可能与标签的排列相结合。 这意味着唯一不变的信息是 Z2 × Z2 中直至全局平移的多重点集。 由于最终答案中的翻译是允许的，因此只有奇偶校验类之间的相对分布很重要，并且该分布在 XOR 之前被精确保留。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    init = [tuple(map(int, input().split())) for _ in range(n)]
    targ = [tuple(map(int, input().split())) for _ in range(n)]
    
    def build(points):
        cnt = [[0, 0], [0, 0]]
        for x, y in points:
            cnt[x & 1][y & 1] += 1
        return cnt
    
    A = build(init)
    B = build(targ)
    
    for dx in (0, 1):
        for dy in (0, 1):
            ok = True
            for i in range(2):
                for j in range(2):
                    if A[i ^ dx][j ^ dy] != B[i][j]:
                        ok = False
            if ok:
                print("YES")
                return
    
    print("NO")

if __name__ == "__main__":
    solve()
```该解决方案将每个点压缩到四个奇偶校验桶之一中。 功能`build`构造这个 2x2 频率表。 然后，我们通过尝试所有四种可能性来模拟唯一重要的效果，即奇偶校验空间中的全局异或移位。 

嵌套循环结束`dx`和`dy`测试是否存在使初始奇偶校验分布与目标分布完全对齐的偏移。 由于 n 可能很大，所以其他一切都是线性的。 

一个常见的错误是尝试直接匹配排序坐标或跟踪实际位移。 这些方法忽略了这样一个事实，即该操作会在全局范围内纠缠所有点，但奇偶校验准确地隔离了在纠缠中幸存下来的内容。 

## 工作示例

 考虑一个小案例，包含三点：

 初始值：(0,0)、(0,1)、(1,0)

 目标：相同结构的移位版本

 我们计算奇偶校验计数。 

| 点集| (0,0) | (0,0) | (0,1)| (1,0)| (1,1) |
 | --- | --- | --- | --- | --- |
 | 初始| 1 | 1 | 1 | 0 |
 | 目标| 1 | 1 | 1 | 0 |

 尝试所有移位使多重集保持相同，因此算法接受。 

现在考虑不匹配：

 初始值：(0,0)、(1,1)、(2,2)

 目标：(0,0)、(0,0)、(1,1)

 奇偶校验计数根本不同。 

| 点集| (0,0) | (0,0) | (0,1)| (1,0)| (1,1) |
 | --- | --- | --- | --- | --- |
 | 初始| 3 | 0 | 0 | 0 |
 | 目标| 1 | 0 | 0 | 2 |

 没有 XOR 移位可以协调这些分布，因此算法会拒绝。 

第二种情况表明宇称质量分布是真正的不变量，而不是几何或距离。

 ## 边缘情况

 当 n 等于 1 时，每个配置都是等效的，因为任何单个点都可以通过重复移动任意平移。 该算法自然地处理这个问题，因为初始奇偶校验表和目标奇偶校验表都有一个非零条目，并且匹配的移位始终存在。 

当所有点都位于同一奇偶校验类时，该结构就会折叠成一个桶。 在相应的班次之后，任何在四个存储桶之一中保留相同计数的目标配置都会被接受，并且算法会显式检查所有四个班次。 

当分布严重倾斜时，例如一个类中有 n−1 个点，另一类有 1 个点，移位检查可确保准确保留不平衡模式。 任何通过几何“隐藏”不匹配的尝试都会失败，因为奇偶校验计数在所有允许的操作下都是不变的。
