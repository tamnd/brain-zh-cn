 ## 解决方案
 ## 问题理解

 我们被要求计算数字 _A_ 以从 2 到 _A_ - 1 的所有基数表示时的平均数字和。输入是 3 到 1000 之间的单个整数 _A_。输出应该是一个不可约分数，表示所有数字和除以所考虑的基数的总和，以基数 10 编写。 

限制很小。 当 _A_ ≤ 1000 时，从 2 到 _A_ - 1 的所有碱基迭代是可行的。 对于每个基数，我们需要计算该基数中 _A_ 的数字总和。 当 _A_ = 1000 时出现最大操作数，即 998 个碱基。 对于每个基数，该基数中_A_的位数最多大约为log2A，小于10。因此，数字和计算的总数小于10,000。 这可以在 1 秒的时间限制内轻松完成。 

不明显的边缘情况包括像 2 和 3 这样的小基数，其中位数可以更大，以及 _A_ 完全除以基数的情况。 例如，当 _A_ = 4 时，以 2 为基数计算得出 100，总和为 1，以 3 为基数计算得出 11，总和为 2。错误计算除法或取模的简单实现可能会产生错误的总和，或者忘记包含最高基数 _A_ - 1。 

## 方法

 暴力方法很简单。 对于从 2 到 _A_ - 1 的每个底数 _b_，重复将 _A_ 除以 _b_ 并对余数求和，直到商为零。 然后将这些总和除以碱基数即可得到平均值。 这是正确的，因为基数转换定义明确并且操作数量很少。 在最坏的情况下，位数计算的数量是 log₍b₎A 的所有基数的总和，即 O(A log A)。 对于 _A_ ≤ 1000，这少于 10,000 次操作，因此暴力方法已经足够了。 

最佳方法本质上是相同的，但需要注意输出格式。 我们需要总和除以碱基数量的不可约形式的分数。 为此，我们计算分子和分母的最大公约数，并在打印之前将其除以。 问题的结构不允许进一步渐近改进，因为我们必须单独检查每个碱基。

 | ---| ---| ---| ---|
 | 蛮力 | O(A 对数 A) | O(1) | O(1) | 已接受 |
 | 最佳 | O(A 对数 A) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从输入中读取整数_A_。 这是我们要转换成不同基数的数字。 
2. 初始化变量`total_sum`为零。 这将累积所有基数的数字总和。 
3. 迭代基础`b`从 2 到 _A_ - 1（含）。 对于每个基数，我们将计算数字之和。 
4. 在循环内，初始化`n`至 _A_ 和`digit_sum`为零。`n`将被重复除以当前基数。 
5. 虽然`n`大于零，添加`n % b`到`digit_sum`然后进行整数除法`n //= b`。 这会将数字转换为基数并对数字求和。 
6. 添加`digit_sum`到`total_sum`。 
7. 完成循环后，考虑的碱基数为`A - 2`。 
8. 要产生不可约分数，请计算最大公约数`g`的`total_sum`和`A - 2`。 将分子和分母同时除以`g`。 
9. 将分数打印为`X/Y`。 

为什么有效：每次迭代都使用重复除法和模数正确计算基_b_数字和。 对所有基础进行求和可确保计算所有贡献。 减少分数可确保输出为不可约形式。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

A = int(input())
total_sum = 0

for b in range(2, A):
    n = A
    digit_sum = 0
    while n > 0:
        digit_sum += n % b
        n //= b
    total_sum += digit_sum

denominator = A - 2
g = math.gcd(total_sum, denominator)
print(f"{total_sum // g}/{denominator // g}")
```代码首先读取数字_A_。 外部循环迭代从 2 到 _A_ - 1 的所有基数。在内部，我们将 _A_ 转换为当前基数，并使用模除法和整数除法计算数字之和。 我们将所有数字总和总结为`total_sum`。 循环之后，我们计算最大公约数`total_sum`和分母来减少分数并将其打印出来`X/Y`格式。

 ## 边缘情况

 对于 _A_ = 3，只需考虑一个基数，即基数 2。转换后得到 11，总和为 2。分母 = 1。分数 = 2/1，化简为 2/1。 该算法正确地处理了最小碱基数。 

对于 _A_ = 4，考虑基数 2 和 3。 基数 2：100 和 1； 底数 3：11 和 2； 总和=3； 分母 = 2； 分数 = 3/2。 该算法正确计算数字和并减少分数。 

对于 _A_ = 1000，该算法迭代超过 998 个基数，使用整数算术有效地求和数字和，并使用 gcd 减少分数。 这证实了即使是最大的输入也会在合理的时间内运行并产生正确的不可约分数。
