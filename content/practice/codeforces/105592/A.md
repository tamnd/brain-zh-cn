 ## 解决方案
 ## 问题理解

 我们给定一个正整数$n$。 我们考虑如何拆分$n$分成两个自然数，表示正整数，写成对$(a, b)$这样$a + b = n$。 这同样适用于另一对$(c, d)$和$c + d = n$。 两对都必须满足排序约束，我们对四元组感兴趣$(a, b, c, d)$这样$a + b = n$,$c + d = n$，并且这四个数字在模式中严格递增$a < c < d < b$。 

所以从几何角度来说，我们选择同一数字的两个分解$n$，并交错它们的端点，以便第一个分割比第二个分割更“左移”，同时两者的总和仍然相同。 

输入大小可达$10^9$，因此任何尝试所有可能的分解或迭代所有四元组的解决方案都是立即不可能的。 甚至迭代所有可能的情况$a$值来自$1$到$n$已经太慢了。 这强烈表明答案取决于结构计数论证而不是枚举。 

出现微妙的边缘情况时$n$很小。 例如，如果$n = 3$，只有一种有效的分解$(1,2)$，因此根本不可能选择两个不同的对，这意味着答案必须为零。 任何忘记在所有四个变量之间强制执行严格不平等的方法都可能会错误地计算某些变量重合的简并配置。 

另一个潜在的陷阱是重复计算。 自从$(a,b)$和$(b,a)$由于隐含的自然排序约束，不允许作为有效对$a < b$，我们必须确保只考虑一次有序分解。 

## 方法

 暴力方法是枚举所有对$(a,b)$这样$a+b=n$，这给出了关于$n-1$有效的分割。 然后我们会选择两个这样的对并检查所有四元组$(a,b,c,d)$验证是否$a < c < d < b$。 这导致大约$O(n^2)$候选对比较，每次检查都是恒定时间，总体复杂度约为$O(n^2)$。 为了$n = 10^9$，这是完全不可行的。 

关键的观察是，每个有效四元组都是通过选择同一线段的两个有效分割来完全确定的$1 \dots n-1$。 每一次分裂$(a,b)$对应一个分区点$a$， 自从$b = n-a$。 因此，我们不再考虑四个自变量，而是将问题简化为选择两个划分点$a$和$c$，并检查哪些约束$a < c < d < b$翻译成.

 替代$b = n-a$和$d = n-c$，不等式变为$a < c < n-c < n-a$。 

最右边的不等式$n-c < n-a$简化为$a < c$，这是多余的，因为它已经存在。 剩下的重要条件是$c < n-c$，这意味着$c < \frac{n}{2}$，还有$n-c < n-a$，这再次减少到$a < c$。 

因此该结构分解为计算整数对$a < c$与两者$a$和$c$受到中点“左侧”的约束$n$，并且另外尊重两个分割都是有效的。 

这将问题简化为计算有多少种方法可以从由下式确定的特定前缀范围中选择两个不同的整数：$n$，答案就变成了线性段上的简单组合计数。 

这将问题从二次枚举转换为直接组合公式。

 ## 算法演练

 1. 重写每个有效对$(a,b)$使用单个变量$a$， 自从$b = n-a$。 这将问题简化为处理整数$a$在范围内$1 \le a \le n-1$。 
2. 类似地表达第二对$(c, n-c)$。 现在整个四元组是通过选择两个不同的值来确定的$a$和$c$。 
3. 翻译约束$a < c < d < b$只涉及不平等$a$和$c$。 替代$d = n-c$和$b = n-a$，我们得到$a < c < n-c < n-a$。 
4. 简化不等式。 条件$n-c < n-a$减少到$a < c$，这已经是必需的。 非平凡约束变为$c < n-c$，这相当于$2c < n$。 这限制了有效范围$c$。 
5. 识别所有有效的$c$。 这些是整数$c$这样$1 \le c \le \left\lfloor \frac{n-1}{2} \right\rfloor$。 
6. 对于每个有效$c$, 统计有多少个有效$a$存在于$1 \le a < c$。 这简直就是$c-1$。 
7. 所有有效的总和$c$，产生三角和$\sum_{c=1}^{m} (c-1)$， 在哪里$m = \left\lfloor \frac{n-1}{2} \right\rfloor$。 这评估为$\frac{m(m-1)}{2}$。 

### 为什么它有效

 每个有效的四元组都唯一对应于一对有序索引$(a,c)$和$a < c$，其中两者都表示分解的有效第一分量$n$。 不等式链迫使两个点都位于有效分解范围的下半部分，并且替换后不存在其他隐藏约束。 由于每个四元组恰好映射到一个这样的有序对，反之亦然，因此对这些对进行计数会产生有效配置的准确数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    m = (n - 1) // 2
    if m <= 1:
        print(0)
        return
    
    print(m * (m - 1) // 2)

if __name__ == "__main__":
    solve()
```代码首先将问题转换为计算变量的有效位置$c$，它必须严格位于$n/2$。 这是捕捉到的$m = \lfloor (n-1)/2 \rfloor$，表示第二个分割点存在多少个有效选择。 

如果存在少于两个这样的点，则没有有序对$(a,c)$可以成立，所以答案为零。 否则，增加对的数量是标准组合计数$C(m,2)$，实施为$m(m-1)/2$。 

关键的实现细节是确保正确使用整数除法，因为 Python 的向下除法与数学推导一致。

 ## 边缘情况

 对于$n = 2$，只有一次分解$(1,1)$，但它违反了形成两个不同对的严格不平等要求。 该算法计算$m = \lfloor (2-1)/2 \rfloor = 0$，立即返回零，匹配不存在有效四元组的事实。 

为了$n = 3$，唯一的分割是$(1,2)$，因此不可能选择两个不同的有效分割。 该算法再次得出$m = 1$，并且自从$m(m-1)/2 = 0$，输出正确。 

对于大型$n$， 例如$10^9$，该算法不会尝试枚举。 它直接计算$m = 499999999$并返回单个算术表达式，避免任何时间限制问题的风险，同时仍然正确表示所有有效配置。
