 ## 问题理解

 该任务是关于象在棋盘上的移动。 我们在标准网格上有两个正方形，每个正方形都由坐标标识。 该棋子只能沿对角线移动，这意味着每次移动都会在相反方向上以相同的幅度改变行和列。 

目标是确定从起始方格到目标方格所需的象移动的最小次数，或者报告这是不可能的。 

输入由起始方格和目标方格​​的坐标组成。 输出是一个整数，表示所需的对角线移动的最小数量，或者是一个表示不可能的特殊值，具体取决于问题的表述。 

即使没有明确的约束，此类问题也是针对每个测试用例的恒定时间推理而设计的。 关键的含义是任何解决方案都必须将电路板的几何形状减少到一些算术检查。 如果坐标范围很大，任何涉及路径模拟、棋盘上的 BFS 或逐步移动的操作都会太慢，因为这至少会在网格大小中引入线性或二次行为。 

当两个方块相同时，会出现微妙的边缘情况。 在这种情况下，不需要移动，因此答案必须为零。 在国际象棋术语中，当两个方格颜色不同时，就会出现另一种边缘情况。 主教总是停留在相同颜色的方块上，因此如果坐标之间的奇偶性不同，则不可能到达目标。 例如，从(1,1)到(1,2)，答案是不可能的，因为颜色不同。 如果不考虑此奇偶校验约束，仅检查对角线距离的简单方法将错误地假设可达性。 

## 方法

 思考这个问题的强力方法是模拟从初始正方形开始的所有可能的主教路径。 从任何位置，主教都可以沿着四个对角线方向移动，可能会移动很多步。 网格上的 BFS 会正确地找到移动次数方面的最短路径。 

这是可行的，因为 BFS 以越来越多的移动次数探索所有可到达的方块，保证我们第一次到达目的地时使用了最少的移动次数。 然而，成本来自于电路板的尺寸。 如果坐标范围很大，则将网格视为显式图就变得不可行。 每个节点可以沿对角线扩展至 O(n) 个位置，从而形成巨大的状态空间。 

关键的观察是主教运动具有很强的几何结构。 当且仅当两个方格位于同一条对角线上时，主教要么一步到达一个方格，这相当于坐标的绝对差相等的条件。 如果不存在，问题就简化为检查是否存在两步移动路径。 在国际象棋几何中，任何两个相同颜色的方格都可以在最多两次主教的移动中通过跨过位于两个方格对角线交叉点上的中间方格来连接。 

这将整个问题简化为对坐标奇偶性和对角线相等性的算术检查。

 | --- | --- | --- | --- |
 | BFS 全面上线 | O(N²) 或更差 | O(N²) | 太慢了 |
 | 直接几何检查| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 读取起始方坐标和目标方坐标。 它们定义了二维整数点阵中的两个点，我们将其解释为棋盘位置。 
2. 如果起始方格与目标方格相同，则立即返回 0。 不需要移动，任何应用移动规则的尝试只会引入不必要的计算。 
3. 通过比较坐标的绝对差来检查两个正方形是否位于同一条对角线上。 如果`|x1 - x2| == |y1 - y2|`，返回1，因为单个象的移动可以直接连接它们。 
4. 检查两个方块的颜色是否相同。 这是由坐标奇偶性决定的：正方形可以被视为黑色或白色，具体取决于是否`x + y`是偶数还是奇数。 如果两个方块之间的奇偶校验不同，则根据输出格式返回 -1 或“不可能”。 
5. 如果这些方格在一次移动中无法到达，但具有相同的颜色，则返回 2。通过选择位于两个端点对角线交点上的中间方格，任何这样的一对都可以在两次主教移动中连接起来。 

正确性来自于将所有可能的配置分类为三种不相交的几何情况：相同位置、单对角线可达性和相同颜色但非对角线可达性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x1, y1, x2, y2 = map(int, input().split())

    if x1 == x2 and y1 == y2:
        print(0)
        return

    if abs(x1 - x2) == abs(y1 - y2):
        print(1)
        return

    if (x1 + y1) % 2 != (x2 + y2) % 2:
        print(-1)
        return

    print(2)

if __name__ == "__main__":
    solve()
```该实现直接反映了逻辑分类。 第一个条件处理不需要移动的退化情况。 第二个条件捕获象移动的精确几何定义，其中行和列偏移的大小必须匹配。 第三个条件编码了主教保留方形颜色的不变性，防止相反奇偶性之间的任何转换。 

只有在排除了之前的情况后，最终返回 2 才是合理的，这意味着我们可以保证正方形具有相同的颜色，但不会对角对齐。 这确保了两次移动路径始终存在，而无需显式构造它。

 ## 边缘情况

 一个关键的边缘情况是起始方块和结束方块重合。 用于输入`1 1 1 1`，算法在进行任何几何检查之前立即返回 0。 这可以防止错误地将位置分类为对角线或两步可达。 

另一种情况是直接对角线可达性，例如`3 5 6 8`。 绝对差相等，因此算法返回 1 而不检查奇偶性，因为对角线移动已经足够并且比颜色分类更具体。 

第三种情况涉及相反颜色的方块，例如`1 1 2 3`。 这里是奇偶校验`(x + y) % 2`不同，所以算法正确地停止在不可能的地方。 即使不存在主教路径，仅检查对角线距离的简单方法也会错误地尝试分配两步解决方案。 

最后，一般的同色非对角线情况，例如`2 3 5 6`通过对角线和奇偶校验过滤器，从而得出有保证的两步结论。 这证实了分类干净地划分了所有可能的输入，没有重叠或模糊。
