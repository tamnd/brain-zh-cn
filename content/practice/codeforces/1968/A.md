 ## 解决方案
 ## 问题理解

 我们得到一个数字$x$，我们需要选择一个较小的正整数$y$使得该值$$\gcd(x, y) + y$$尽可能大。 目标不是最大化$y$本身，而是一个组合$y$以及它与多少共享除数$x$。 

思考这个问题的一个有用的方法是$y$通过自身价值直接贡献，通过自身价值间接贡献$\gcd(x,y)$，这取决于其因素与$x$。 因此，我们正在平衡一个大数和一个具有相同结构的数$x$。 

输入尺寸非常小：$x \le 1000$和$t \le 1000$。 这立即告诉我们，即使是$O(x^2)$每个测试用例的暴力破解都会轻松通过，因为总工作量最多约为一百万次评估。 然而，该结构表明有一个捷径可以避免检查所有候选者。 

一个天真的错误是假设选择$y = x-1$或者$y = \lfloor x/2 \rfloor$总是好的。 例如，当$x = 10$, 采摘$y = 9$给出$\gcd(10,9)+9 = 10$， 但$y=5$给出$5 + 5 = 10$同样，其他值可以平局或超过，具体取决于可除性结构。 最佳选择不是关于接近度，而是关于与除数的对齐$x$。 

另一个微妙的失败案例来自完全忽略除数。 如果我们只尝试接近的值$x$，我们错过了这样的情况$x=21$， 在哪里$y=18$获胜是因为$\gcd(21,18)=3$, 给予$21$，比许多附近的替代方案更大。 

## 方法

 暴力解决方案很简单。 对于每个$y$从$1$到$x-1$, 计算$\gcd(x,y) + y$，跟踪最大值，并返回最好的$y$。 这是有效的，因为每个候选者都经过检查，因此保证了正确性。 

成本来自重复的 gcd 计算。 每个gcd需要$O(\log x)$，我们就这么做了$x$每个测试用例的次数，给出$O(x \log x)$。 和$x \le 1000$和$t \le 1000$，这样还是可以的，但是没有必要。 

关键的观察是值$\gcd(x,y)$总是除数$x$，如果我们固定 gcd 值$d$， 然后$y$必须是的倍数$d$。 表达式变为：$$\gcd(x,y) + y = d + y$$所以对于一个固定的$d$，我们想要最大的$y < x$可以被整除$d$，同时仍保证$\gcd(x,y)=d$。 最好的候选者自然会出现在大除数的倍数附近$x$。 

这表明我们不需要测试所有$y$，仅那些与除数结构相关的。 自从$x \le 1000$，我们可以安全地迭代所有$y$但优化gcd计算； 然而，更清晰的观察会进一步简化：最佳答案总是由一些人获得$y$这是除数的倍数$x$，并且检查所有这些值仍然很小。 

在实践中，最简单的接受方法仍然是直接扫描，但理解除数可以解释它的工作原理以及为什么更好的选择围绕结构化值聚集。

 ## 算法演练

 我们独立解决每个测试用例。 

1. 阅读$x$。 我们会尝试每一位候选人$y$从$1$到$x-1$，因为约束足够小，不需要剪枝。 
2. 对于每个$y$, 计算$\gcd(x,y)$。 这捕获了多少结构$y$与 共享$x$，直接影响目标。 
3. 计算分数$s = \gcd(x,y) + y$，并跟踪迄今为止看到的最佳值。 我们还存储了相应的$y$。 
4.检查完所有候选后，输出$y$达到了最高分。 

这样做的原因是，之间的每一种可能的相互作用$x$和$y$完全体现在搜索空间中。 自从$\gcd(x,y)$仅取决于$x$和$y$, 枚举所有$y$保证不会错过任何潜在的最佳除数对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

t = int(input())
for _ in range(t):
    x = int(input())
    
    best_y = 1
    best_val = -1
    
    for y in range(1, x):
        val = math.gcd(x, y) + y
        if val > best_val:
            best_val = val
            best_y = y
    
    print(best_y)
```该方案直接实现穷举搜索。 唯一重要的部分是使用 Python 的内置函数`math.gcd`，这对于给定的约束足够有效。 

一个常见的实施陷阱是错误地初始化最佳值。 自从$\gcd(x,1)+1$总是有效的，从像这样的哨兵开始$-1$避免遗漏小案件。

 ## 边缘情况

 对于$x=2$，唯一有效的选择是$y=1$。 算法检查$y=1$，计算$\gcd(2,1)+1 = 2$，并返回$1$。 不需要特殊处理，因为循环仍然执行一次。 

对于素数$x=7$， 每一个$y$gcd 为 1，但不允许为 7 的倍数。 最佳值变为$y + 1$，所以最大的$y$，即 6，是最优的。 循环自然会发现$y=6$最好的。 

对于合数，例如$x=21$，出现由不同除数结构绑定的多个候选。 该算法不假设唯一性，只是跟踪符合问题要求的第一个最大值。
