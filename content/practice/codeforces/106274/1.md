 ## 解决方案
 ## 问题理解

 该问题比较了两个灯泡。 普通灯泡价格便宜，但耗电较多。 节能灯泡一开始的成本较高，但每小时消耗的瓦数会减少。 我们需要找到第一个整数小时，在此之后，花在节能灯泡上的总钱不超过花在普通灯泡上的总钱。 

输入在不同的行上给出五个值：普通灯泡的购买价格、每小时的耗电量、节能灯泡的购买价格、每小时的耗电量以及每瓦时的电价（以戈比为单位）。 输出是节能灯泡支付其较高初始成本时的最小整数小时数。 

数值可以达到$10^9$，因此答案可能比 32 位整数大得多。 直接模拟小时数是不可能的，因为所需的小时数可能约为$10^{11}$或更多。 我们需要使用算术进行恒定时间计算，而不是每小时检查一次。 

边缘情况大多与零电价和精确划分有关。 如果电是免费的，那么更昂贵的灯泡就永远赶不上。 例如：```
10
100
20
50
0
```正确的输出是`-1`，因为两个灯泡都永远保持原来的购买价格。 除以节省的能源成本而不检查零的解决方案将会失败。 

另一种情况是当节省恰好在整数小时时变得足够时：```
20
90
120
20
5
```购买价格相差10000戈比。 每个小时可节省 350 戈比，因此第一个有效小时为 29。使用整数除法而不向上舍入的解决方案将错误地生成 28。 

第三种情况是第一个小时已经足够了：```
0
100
1
0
1
```输出是`1`。 节能灯泡一开始要贵一个戈比，但每小时可以节省100戈比，所以第一个小时后就更好了。 意外地允许零小时的实现将是错误的，因为灯泡尚未使用。 

## 方法

 一个简单的方法是模拟过去的时间。 我们每小时计算两个灯泡的总成本，并在节能灯泡变得不再昂贵时停止。 这种方法很容易证明是正确的，因为它准确地检查语句中的条件。 然而，它可能需要大量的迭代。 随着价格接近$10^9$，所需时间约为$10^{11}$小时，使得模拟变得不可能。 

关键的观察结果是，这两种成本都随着时间线性增长。 购买价格是固定的，每小时只增加电费。 我们可以比较它们的差异，而不是反复比较两个不断增长的值。 

节能灯泡在后面启动$b-a$卢布。 每个小时它都会获得优势$(x-y)p$科比，因为它消耗的瓦数更少。 将初始差值转换为科比给出一个简单的不等式：$$100(b-a) \leq h(x-y)p$$答案是最小的整数$h$满足它。 这只是一个天花板划分。

 | --- | --- | --- | --- |
 | 蛮力 | O（答案）| O(1) | O(1) | 太慢了|

 ## 算法演练

 1. 读取五个输入值并完全以戈比为单位进行计算。 电力计算已经使用戈比，因此转换灯泡价格可以防止浮点错误。 
2. 计算节能灯泡的初始缺点为`100 * (b - a)`。 这是它在盈利之前必须节省的金额。 
3. 计算每小时节省的费用为`(x - y) * p`。 普通灯泡消耗更多能量，因此该值是非负的。 
4. 如果每小时节省为零，节能灯泡将永远无法恢复其较高的价格。 输出`-1`。 
5. 否则，使用上限除法计算最小整数小时计数：$$\left\lceil \frac{\text{initial disadvantage}}{\text{hourly saving}} \right\rceil$$整数形式为`(need + save - 1) // save`。 

为什么有效：两个灯泡的成本之间的差异每小时减少完全相同的量。 最初，节能灯泡落后了固定的量。 每个小时都会消除该差异的固定部分。 当累计节省达到初始劣势的第一时刻，正是节能灯泡变得不再昂贵的时刻。 上限除法找到发生这种情况的第一个整数小时。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    a = int(input())
    x = int(input())
    b = int(input())
    y = int(input())
    p = int(input())

    need = 100 * (b - a)
    save = (x - y) * p

    if save == 0:
        print(-1)
    else:
        print((need + save - 1) // save)

if __name__ == "__main__":
    solve()
```该程序首先将购买价差从卢布转换为戈比。 这可以避免丢失精度并使所有计算保持为整数。 

变量`save`存储节能灯泡一小时后变得便宜多少。 由于普通灯泡耗电较多，因此该值是收回初始差价所取得的进度。 

零检查是必要的，因为上限除以零是无效的，从逻辑上讲，当电力本身没有价格时，更便宜的电力成本永远不会创造任何优势。 

最终表达式使用标准整数上限除法公式。 添加`save - 1`除法之前将任何非精确结果向上移动，同时保持精确除法不变。
