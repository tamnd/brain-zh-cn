 ## 解决方案
 ## 问题理解

 我们正在比较购买相同数量甜甜圈的两种不同方式，对于每种方式，我们想知道什么时候它会比另一种方式严格便宜。 

在第一家商店，价格是线性的：购买$x$甜甜圈的成本正好$a \cdot x$。 

在第二家商店，购买受到限制。 甜甜圈按尺寸盒出售$b$, 每盒成本$c$。 如果我们想要$x$甜甜圈，我们不能购买零碎的盒子，所以我们必须购买足够的整盒来至少覆盖$x$甜甜圈。 这意味着我们购买$\lceil x / b \rceil$箱，总成本变为$c \cdot \lceil x / b \rceil$。 

对于每个测试用例，我们需要找到一个正整数$x$其中第一家商店严格比第二家便宜，另一个（可能不同）整数$x$第二家商店比第一家便宜。 如果某个方向不存在这样的值，我们输出 -1。 

就测试数量而言，约束很小，但是$a$,$b$， 和$c$可以达到$10^9$， 和$x$还可以达到$10^9$。 这立即排除了尝试所有值$x$。 任何解决方案都必须直接从成本函数的结构中推理。 

当一家商店总是更好或总是相同时，就会出现微妙的边缘情况。 例如，如果$a \le c/b$在平均意义上，但四舍五入会改变行为，或者如果盒子大小使第二个商店分段恒定。 另一个重要的问题是不允许平等； 我们需要严格的不平等，因此必须排除成本匹配的值，即使它们看起来“最优”。 

## 方法

 一个蛮力的想法是迭代$x$从 1 到某个大的限制并比较两种成本。 对于每个$x$, 计算$a \cdot x$和$c \cdot \lceil x/b \rceil$，并记录其中一个小于另一个的值。 这是正确的，但从根本上来说太慢了：即使我们只检查$10^9$，这在典型的约束下是不可能的。 

关键的观察结果是，这两个成本函数在结构化方式上都是单调的。 第一家商店是完全线性的。 第二个商店是一个阶跃函数：它在长度间隔内保持不变$b$，然后跳过$c$。 这意味着商店之间的主导地位的变化只能发生在小的、结构化的点周围，通常是围绕多个点$b$或非常小的值$x$。 

而不是扫描全部$x$，我们只需要测试一些战略性选择的候选人。 第一个有用的想法是，如果第二家商店更便宜，那么一些小商店的价格就已经更便宜了。$x$，特别是在$x = 1$。 这是因为，当您充分利用盒子时，每个甜甜圈的成本将被有效降低； 更大$x$只会重复相同的平均模式或恶化舍入效率。 

因此，要找到第二家商店更便宜的情况，我们只需检查$x = 1$。 

为了让第一家店更便宜，我们希望：$$a \cdot x < c \cdot \lceil x/b \rceil$$右侧是每个大小块的分段常数$b$。 第一家商店获胜的第一个机会通常发生在盒子的边界，即$x = b$，因为在此之前第二家商店可能会浪费产能，但之后摊销会有所改善。 

所以我们测试$x = b$。 

这两个候选就足够了，因为任何改进或交叉都发生在阶跃函数的最小结构点：第一个甜甜圈和第一个完整的盒子。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 计算成本比较$x = 1$。 我们比较$a$和$c$， 自从$\lceil 1/b \rceil = 1$。 如果$c < a$，那么第二家商店更便宜$x = 1$，所以我们输出$x = 1$对于第二个答案。 否则，我们得出结论，没有有效的$x$对于第二家商店。 
2. 通过检查计算第一家商店何时更便宜的候选$x = b$。 此时，第一店成本$a \cdot b$，而第二家商店的成本正好是$c$因为一个完整的盒子涵盖了所有$b$甜甜圈。 如果$a \cdot b < c$，我们输出$x = b$对于第一个答案。 
3. 如果条件失败，我们对该方向输出-1。 
4. 确保输出保持在范围内，这是有保证的，因为我们只使用$1$和$b \le 10^9$。 

### 为什么它有效

 第二家商店的成本函数仅在以下情况下发生变化$x$跨越多个$b$。 在这些点之间它是恒定的，因此任何最小或主导变化都必须在段中的第一个点或第一个段边界处见证。 第一个商店是线性的，所以如果它打败了第二个商店，它会最早在这些结构断点之一处做到这一点。 这将无限搜索空间减少为两个有意义的候选者：$x = 1$和$x = b$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())

    # second shop cheaper candidate
    second_ans = -1
    if c < a:
        second_ans = 1

    # first shop cheaper candidate
    first_ans = -1
    if a * b < c:
        first_ans = b

    print(first_ans, second_ans)
```第一个块计算第二家商店中的单个甜甜圈是否更便宜。 由于购买一个甜甜圈总是迫使购买一盒，因此比较减少为$c < a$。 

第二个区块测试了盒子结构停止帮助第二家商店的关键边界。 在$x = b$，两家商店都进行了清晰的比较：一盒与一盒$b$单独的甜甜圈。 这是决定第一家商店是否可以严格便宜所需的唯一一点。 

乘法$a \cdot b$必须在 64 位范围内完成，但 Python 可以安全地处理这个问题。 

## 工作示例

 ### 示例 1

 输入：```
5 10 4
```我们评估两位候选人。 

为了$x = 1$，第一家店成本5，第二家成本4，所以第二家店更便宜。 为了$x = 10$，第一店50，第二店4，所以第二店还是便宜一些。 

| 步骤| x| 首次成本 | 第二成本| 结果 |
 | ---| ---| ---| ---| ---|
 | 第二次检查 | 1 | 5 | 4 | 第二次获胜 |
 | 首先检查| 10 | 10 50 | 50 4 | 第二次获胜 |

 这表明第一家商店永远不会变得更便宜，因此我们为其输出-1。 

### 示例 2

 输入：```
2 2 3
```为了$x = 1$，成本为 2 和 3，因此第一家商店更便宜，但这并不能保证所有人都保持这种状态$x$。 为了$x = 2$，第一家店的费用是4，第二家店的费用是3，所以第二家店更便宜。 

| 步骤| x| 首次成本 | 第二成本| 结果 |
 | ---| ---| ---| ---| ---|
 | 第二次检查 | 1 | 2 | 3 | 先胜 |
 | 首先检查| 2 | 4 | 3 | 第二次获胜 |

 我们为每个方向得到一个有效答案：$1$对于第一家商店，$2$对于第二家商店。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    t = int(input())
    out = []
    for _ in range(t):
        a, b, c = map(int, input().split())

        second_ans = -1
        if c < a:
            second_ans = 1

        first_ans = -1
        if a * b < c:
            first_ans = b

        out.append(f"{first_ans} {second_ans}")

    return "\n".join(out) + "\n"

# provided samples

-1 1
-1 -1
"""

""") == "2 1\n", "both directions possible"

""") == "3 1\n", "second shop strong"

""") == "5 1\n", "first shop wins for box size gap"

 ## 边缘情况

 当$a = c$，第二家商店不可能严格便宜于$x = 1$，因为两者的成本相同。 该算法正确输出 -1，因为严格不等式失败。 

什么时候$a \cdot b = c$，比较在$x = b$变得相等，因此第一家商店并不被认为严格更便宜。 这可以避免在两家商店打成平手的情况下错误地声称有效答案。 

什么时候$b = 2$，步骤函数有非常频繁的跳转，但结构仍然崩溃到相同的两个检查点。 该算法仍然有效，因为它不依赖于平滑度，仅依赖于第一步和第一个块边界。
