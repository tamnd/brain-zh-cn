 ## 解决方案
 ## 问题理解

 每个查询给出一个正整数$a$，我们需要构造另一个整数$k$。 约束不是为了优化$k$，但是关于塑造数字$2k$。 当你写的时候$2k$以十进制表示，数字为$a$必须以连续块的形式出现在该数字的最后 100 位数字内。 

这意味着我们可以自由选择一个非常大的数字$k$，只要加倍它就会产生一个后缀区域包含的数字$a$作为子串。 “最后 100 位数字”的上限很重要：超出此范围的任何内容对于条件都无关紧要。 

关键的限制是$a < 10^{11}$，因此每个数字最多有 11 位数字，而我们最多可以构造 50 位数字$k$。 这提出了一种建设性的方法，我们可以明确地构建$2k$，而不是试图推导$k$通过算术约束。 

一个天真的想法是尝试增加$k$并检查是否$2k$包含$a$最后 100 位数字。 这会立即失败，因为搜索空间巨大，而且条件太弱，无法引导暴力。 

如果我们尝试“附加数字”来强制匹配而不控制进位，则会出现更微妙的问题。 例如，尝试放置$a$转化为十进制表示形式$k$并不直接转化为控制$2k$，因为加倍引入了可以跨多个数字传播的进位。 

正确的构造必须通过设计一个数字来完全避免不受控制的进位，其中加倍行为在我们关心的区域中是可预测的。 

## 方法

 蛮力方法会迭代增加的值$k$, 计算$2k$，提取最后100位数字，并检查是否$a$显示为子字符串。 这是正确的，但不可行。 即使检查单个$k$速度很快，在最坏的情况下，成功之前所需的候选人数量是无限的。 

中心观察是我们不是在寻找未知数的属性，而是用受控的小数后缀构造一个数。 因为只有最后 100 位数字$2k$没关系，我们可以自由地明确设计这些数字。 

关键思想是构建$2k$首先，而不是$k$。 如果我们设计一个数字$x = 2k$这样：

 1.最后100位数字$x$包含$a$,
 2.$x$是偶数，

 然后$k = x/2$是一个有效的整数解。 

第二个条件执行起来很简单，因为均匀度仅取决于最后一位数字。 这使我们能够完全控制后缀结构：我们可以自由设计100位后缀并确保其最后一位是偶数。 

因此我们建立$x$作为串联：

 - 包含的前缀$a$,
 - 后缀区域有足够的填充来达到 100 位数字，
 - 选择最后一位数字以使数字为偶数。 

自从$a$最多有 11 位数字，它可以轻松地放入 100 位数字块中。 

我们明确放置$a$在最后 100 位数字的开头$x$，用零填充其余部分，并强制最后一位数字为偶数。 这保证了子串条件不与更高位的进位交互，因为我们构造$x$直接作为十进制字符串。 

一次$x$建成后，我们计算$k = x/2$使用大整数算术。

 ## 算法演练

 我们构造一个有效的$x = 2k$对于每个输入数字$a$，然后除以 2。 

1. 阅读$a$作为字符串，因此我们可以直接操作数字而不会出现转换问题。 

这是必要的，因为我们正在设计十进制结构，而不是对值进行算术推理。 
2. 创建一个100个字符的数组$b$，这将代表最后 100 位数字$x$。 
3. 复制数字$a$进入开始$b$。 

这确保了$a$显示为从后缀区域的位置 0 开始的子字符串。 
4. 将除最后一位数字之外的所有剩余位置填入`'0'`。 

这隔离了结构$a$因此它不会被进位效应或重叠数字所干扰。 
5. 设置最后一位数字$b$通常为偶数`'0'`。 

这保证了完整的数量$x$是偶数，因为整数的奇偶校验仅取决于它的最后一位数字。 
6. 构建$x$作为：$$x = (\text{int}(a) \cdot 10^{100}) + \text{int}(b)$$这确保了$b$正好是最后 100 位数字$x$，因为较高的块移动了 100 个零。 
7. 输出$k = x // 2$。 

### 为什么它有效

 该结构保证了最后 100 位数字$x$正是字符串$b$。 自从$b$开始于$a$，子串条件立即满足。 其余的$x$不会干扰该区域，因为它已移动到 100 位边界之外。 均匀度是通过最后一位数字独立强制执行的$b$，因此除以 2 会产生一个有效整数$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_one(s: str) -> str:
    L = len(s)
    # build 100-digit suffix b
    b = ['0'] * 100
    
    # place a at beginning of suffix
    for i, ch in enumerate(s):
        b[i] = ch
    
    # ensure last digit is even
    b[99] = '0'
    
    b_str = ''.join(b)
    
    # construct x = 2k
    A = int(s) * (10 ** 100)
    x = A + int(b_str)
    
    k = x // 2
    return str(k)

def main():
    n = int(input())
    for _ in range(n):
        s = input().strip()
        print(solve_one(s))

if __name__ == "__main__":
    main()
```代码直接实现了后缀的构造$b$。 关键的设计选择是固定最后一位数字$b$为零，这确保了$x$是偶数，与前缀无关。 乘以$10^{100}$保证$b$精确地占据最后 100 位数字，无需进位交互。

 ## 边缘情况

 出现微妙的边缘情况时$a$以与奇偶校验要求冲突的数字结尾。 因为我们从不依赖最后一位数字$a$对于奇偶校验来说，这并不重要。 奇偶校验完全由构造的后缀的最后一位数字控制，因此即使是像这样的输入`"9"`或者`"11111111111"`行为相同。 该算法将奇偶校验约束与子串嵌入隔离开来，防止它们之间发生任何交互。
