 ## 解决方案
 ## 问题理解

 该问题要求我们计算整数 _m_ 除以时的余数$2^n$，其中 _n_ 和 _m_ 是正整数。 换句话说，我们给出了二次方模数和被除数的大小，我们必须找到被除数除以该模数后剩下的值。 输入 _n_ 指定我们乘以 2 自身以获得除数的次数，而 _m_ 是要对该除数取模后减少的数字。 输出是 0 到 之间的单个整数$2^n - 1$，代表余数。 

这些限制是温和的，但具有微妙的影响。 _n_ 和 _m_ 都可以大到 10^8。 直接计算$2^n$是不切实际的，因为存储或操作的数量大致为$10^{30,000,000}$数字在记忆中是不可能的。 这排除了任何从字面上构建的方法$2^n$。 因此，该算法必须依赖于二的幂的属性，而不是显式地计算它们。 

当 _m_ 小于时，会出现边缘情况$2^n$，在这种情况下余数就是 _m_，或者当 _m_ 可以被$2^n$，产生余数为零。 例如，如果 _n_ = 5 且 _m_ = 32，$2^5 = 32$余数为 0。尝试计算的粗心实现$2^n$在这种情况下，实际上会失败或溢出。 

## 方法

 蛮力方法将尝试计算$2^n$然后执行 _m_ 模$2^n$。 原则上这是正确的，但是当 _n_ 达到 10^8 时，这个数字$2^n$是一个天文数字，无法用标准整数类型表示。 尝试直接构建它需要指数级的时间和内存，远远超出了问题的限制。 

关键的见解是$2^n$有一个非常简单的二进制表示形式：它是二进制的 1 后跟 _n_ 个零。 计算 _m_ 模$2^n$相当于取_m_的最后_n_位。 实际上，这正是按位与运算的结果$2^n - 1$实现，因为$2^n - 1$二进制是 _n_ 个。 这一观察结果将问题简化为单个快速操作，即使对于最大的约束也适用，并且避免构造大量数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 太慢了，对于大n 来说是不可能的|
 | 按位取模 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数_n_和_m_。 它们分别指定 2 的指数和要减少的数字。 
2. 计算$mask = 2^n - 1$。 这将创建一个具有 _n_ 个二进制数的数字。 原因是任何以 2 的幂为模的数字都等于其最后 _n_ 位，此掩码将其隔离。 
3. 计算余数为$result = m \& mask$。 按位 AND 运算精确保留 _m_ 的最后 _n_ 位，丢弃较高位。 这个操作直接产生$m \bmod 2^n$没有任何大数算术。 
4. 打印结果。 这样就高效地完成了计算。 

为什么它有效：不变量是对于任何整数_m_，除以的余数$2^n$仅取决于 _m_ 的最低 _n_ 位。 AND 运算与$2^n - 1$保留这些位，同时将高位位清零，这对其余位没有影响。 无论 _m_ 或 _n_ 有多大，这都保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
m = int(input())

# 2^n - 1 is a mask with n ones in binary
mask = (1 << n) - 1

# remainder of m divided by 2^n
result = m & mask

print(result)
```该代码使用快速 I/O 读取输入，使用左移计算掩码以避免显式计算大幂，然后应用按位 AND 来提取最后 _n_ 位。 使用`1 << n`在 Python 中既快速又安全，因为 Python 整数是无界的。 最终打印根据需要输出剩余部分。

import sys, io

def run(inp: str) -> str:

    mask = (1 << n) - 1

 ## 边缘情况

 当_m_小于$2^n$，算法正确返回 _m_ 本身。 例如，n = 5，m = 3 导致 mask = 31，且 3 & 31 = 3。当 _m_ 等于$2^n$，例如 n = 5，m = 32，掩码为 31，并且 32 & 31 = 0。大_n_（例如 30 和 m = 1073741825）仍然有效，因为 Python 支持任意精度整数，并且按位 AND 隔离了正确的最后 30 位。 这些案例证实了算法正确处理所有边界。
