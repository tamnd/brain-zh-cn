 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其顶点编号为 1 到 _n_。 顶点 1 始终是根。 对于每个其他顶点，输入告诉我们其父顶点，这完全定义了树结构。 

如果一个顶点没有子节点且不是根，则该顶点被视为叶子。 当每个非叶子顶点至少有三个子节点本身就是叶子时，树被称为云杉树。 

任务只是确定给定的树是否满足这个条件。 如果每个非叶顶点至少有三个叶子节点，则打印`"Yes"`。 否则打印`"No"`。 

限制非常小。 该树最多包含 1000 个顶点。 即使是检查每个顶点及其所有子顶点的算法也能在限制内轻松运行。 不需要高级的树算法、递归技巧或繁重的预处理。 

主要挑战是正确解释情况。 我们没有计算所有叶子的后代。 我们只计算叶子的直系子代。 

考虑这个例子：```
5
1
1
2
2
```这棵树是：```
1
├─2
│ ├─4
│ └─5
└─3
```顶点 1 只有一个叶子子节点，即顶点 3。顶点 4 和 5 是叶子，但它们是 1 的孙子节点，而不是子节点。 正确答案是：```
No
```计算叶子后代而不是叶子子代的粗心实现会错误地接受这棵树。 

另一个微妙的情况是当内部顶点有很多子节点，但叶子数量不够时：```
7
1
1
1
2
2
2
```这棵树是：```
1
├─2
│ ├─5
│ ├─6
│ └─7
├─3
└─4
```顶点 2 有效，因为它具有三个子叶。 顶点 1 只有两个叶子子节点，即顶点 3 和 4。正确答案是：```
No
```粗心的解决方案可能只检查根，或者可能计算总子项而不是叶子项。 

另一种边缘情况是一个顶点恰好具有三个叶子子节点：```
4
1
1
1
```根有三个叶子孩子，所以答案是：```
Yes
```条件是“至少 3”，因此必须接受正好 3。 

## 方法

 最直接的方法是检查每个非叶顶点并计算其子节点有多少个。 

暴力版本可以通过每次扫描所有顶点来确定子节点是否是叶子。 对于每个顶点、每个子节点，我们搜索整个树以查看该子节点是否有自己的子节点。 对于 _n_ 个顶点，这将导致大约 _O(n²)_ 工作。 

对于 _n = 1000_，甚至 _O(n²)_ 也是可以接受的。 大约一百万次操作完全在限制之内。 

还有一种更干净的方法。 在读取输入时，我们构建一个包含每个顶点的子节点的邻接列表。 一旦我们有了这个结构，确定一个顶点是否是叶子就变得很简单：当一个顶点的子列表为空时，它就是一个叶子。 

关键的观察结果是，云杉的状况仅取决于直系子代。 我们永远不需要遍历子树或计算深度。 对于每个内部顶点，我们只需计算有多少个子节点拥有零个子节点。 

这将解决方案简化为一次遍历所有邻接列表。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 已接受 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取顶点数。 
2. 为每个顶点建立一个子列表。 对于每个顶点`i`从 2 到`n`，读取其父级`p`并附加`i`到`children[p]`。 
3. 迭代每个顶点。 
4. 如果一个顶点没有子节点，那么它就是一个叶子。 云杉条件不适用于叶子，因此请跳过它。 
5. 对于每个非叶顶点，计算其直接子节点有多少个是叶顶点。 当子节点自己的子节点列表为空时，它就是叶子。 
6. 如果任何非叶顶点的计数小于 3，则打印`"No"`并立即停止。 
7. 如果每个非叶子顶点都通过了检查，则打印`"Yes"`。 

### 为什么它有效

 当且仅当一个顶点是内部顶点并且其直接子节点少于三个时，该顶点违反了云杉定义。 

该算法准确地检查每个内部顶点的这个条件。 每个叶子都会被忽略，因为定义对叶子没有限制。 每个内部顶点都会检查一次，并根据定义精确计算叶子子节点的数量。 

如果算法打印`"No"`，某些内部顶点不符合要求，因此该树不能是云杉。 如果算法打印`"Yes"`，每个内部顶点都满足要求，这与云杉的定义相匹配。 因此算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

children = [[] for _ in range(n + 1)]

for v in range(2, n + 1):
    p = int(input())
    children[p].append(v)

for v in range(1, n + 1):
    if not children[v]:
        continue

    leaf_children = 0

    for child in children[v]:
        if not children[child]:
            leaf_children += 1

    if leaf_children < 3:
        print("No")
        sys.exit()

print("Yes")
```第一部分将有根树构造为邻接表。 由于输入直接给出每个顶点的父级，因此构建子级列表非常简单。 

第二部分迭代所有顶点。 子列表为空的顶点是叶子，因此会被跳过。 

对于每个内部顶点，代码会计算有多少子节点本身具有空子节点列表。 这些正是定义所要求的叶子孩子。 

当一个顶点的叶子节点少于三个时，答案是`"No"`，因此程序提前终止。 如果循环结束，则每个内部顶点都满足条件，答案为`"Yes"`。 

一个常见的错误是计算所有叶子后代而不是直接叶子孩子。 该实现通过仅检查中的顶点来避免这种情况`children[v]`。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    children = [[] for _ in range(n + 1)]

    for v in range(2, n + 1):
        p = int(input())
        children[p].append(v)

    for v in range(1, n + 1):
        if not children[v]:
            continue

        cnt = 0
        for child in children[v]:
            if not children[child]:
                cnt += 1

        if cnt < 3:
            print("No")
            return

    print("Yes")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run("4\n1\n1\n1\n") == "Yes", "sample 1"

# minimum valid tree
assert run("4\n1\n1\n1\n") == "Yes", "minimum spruce"

# root has only two leaf children
assert run("3\n1\n1\n") == "No", "root needs at least three leaf children"

# internal node valid, root invalid
assert run("7\n1\n1\n1\n2\n2\n2\n") == "No", "count only immediate leaf children"

# larger valid tree
assert run("8\n1\n1\n1\n2\n2\n2\n1\n") == "Yes", "all internal vertices satisfy condition"

# chain structure
assert run("4\n1\n2\n3\n") == "No", "every internal vertex fails"

 ## 边缘情况

 考虑树：```
5
1
1
2
2
```该算法构建：```
children[1] = [2, 3]
children[2] = [4, 5]
```处理顶点 1 时，子节点 2 不是叶子，因为它有子节点。 孩子 3 是一片叶子。 计数为 1，小于 3，因此算法打印`"No"`。 

这可以正确处理叶后代存在但不是直接子代的情况。 

考虑：```
7
1
1
1
2
2
2
```顶点 2 有三个叶子子节点和通道。 顶点 1 有子节点`{2,3,4}`。 只有顶点 3 和 4 是叶子，因此其计数为 2。算法打印`"No"`。 

这验证了每个内部顶点都必须满足条件，而不仅仅是其中的一些顶点。 

考虑：```
4
1
1
1
```根的子节点都是叶子，因此计数恰好为 3。由于条件是“至少 3”，因此算法接受树并打印`"Yes"`。 

这证实了边界情况，即计数恰好是所需的最小值。
