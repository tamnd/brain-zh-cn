 ## 解决方案
 ## 问题理解

 我们被要求从顶点 1 导航到顶点 n 的有向无环图 (DAG)，沿途收集卡片和道具，然后在最后最大化我们的总“力量”。 卡牌同时具有生命值和伤害，其威力是两者的乘积。 道具具有单一的力量值并且可以累加。 顶点有四种特殊事件：获取卡牌、提升卡牌生命、提升卡牌伤害、获取道具。 在最后一个顶点，我们可以选择将一张牌的伤害乘以$10^9$。 我们的目标是最终最大化所有卡牌力量加上所有道具力量的总和。 

输入约束适中：最多 200 个顶点和最多 2000 个边。 由于图是 DAG 并且边总是从较低的索引到较高的索引，因此拓扑顺序是隐式的。 这允许沿着 DAG 进行动态编程。 中等大小排除了显式迭代所有路径的算法，因为即使在小型 DAG 中也可能存在指数级数量的路径。 然而，每个顶点的操作是收集的卡片数量的多项式是可行的。 

当我们最后只有一张牌时，就会出现一种微妙的边缘情况。 如果我们一路上遇到生命值或伤害提升，我们必须选择正确的卡牌来应用提升。 另一个棘手的问题是，将伤害乘以$10^9$在最后的顶点可以完全支配总和。 粗心的实现可能无法考虑延迟或仔细定位最终乘法是最佳的。 

例如，如果顶点 2 给出一张牌（2 HP，3 伤害），而顶点 4 将伤害增加 10，则路径 1→2→4→n 可以产生最终的牌（2 HP，13 伤害）。 如果我们将其在 n 处的伤害乘以$10^9$，其结果远远高于任何积累多张小卡而不有效使用乘数的路径。 

## 方法

 强力解决方案将枚举从顶点 1 到顶点 n 的所有路径，跟踪每条路径上的所有卡片组。 在每个顶点，我们会将事件应用于每张卡并计算总功率。 虽然这在概念上可行，但它很快就变得不可行：路径的数量可以随着 n 呈指数增长，并且可能的卡状态的数量也会以组合方式增长。 即使 n = 200，操作次数也是天文数字。 

关键的见解是认识到问题是具有单调边缘的 DAG，因此我们可以使用动态编程计算每个顶点的最佳可实现状态。 由于所有提升最多影响一张卡牌，并且伤害乘数最终可以应用于一张卡牌，因此我们只需要跟踪每个顶点可实现的最大卡牌力量和道具总和，而不是每种可能的卡牌组合。 当考虑伤害或生命值提升时，我们仅将其应用于最终提供最大威力的卡牌，因为提升较小的卡牌总是次优的。 这大大减少了状态空间。 

故事是这样的：暴力破解之所以有效，是因为它沿着所有路径追踪所有可能的卡组，但由于指数增长而失败。 观察到该图是一个 DAG，并且提升应该始终针对最强的候选者，允许在每个状态仅携带两个数字的顶点上进行 DP：最大单卡功率以及所有其他卡和道具的总和。 这给出了易于处理的 O(n·m) 解决方案。

 | 最佳 | O(n·m) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组，`dp1[i]`和`dp2[i]`，对于每个顶点 i。`dp1[i]`跟踪单张卡的最大功率，我们稍后可以乘以$10^9$， 和`dp2[i]`跟踪包括 props 在内的所有其他能力的总和。 两者在顶点 1 处均为零。 
2. 按拓扑顺序（1 到 n）处理顶点。 对于每个顶点`u`，将其状态传播给所有邻居`v`。 对于每个邻居，考虑事件的类型`v`。 
3.如果顶点`v`给出一张带有 (a, b) 的新卡，计算其功率`a*b`。 更新`dp1[v]`到电流的最大值`dp1[v]`和`a*b`加`dp2[u]`。`dp2[v]`遗迹`dp2[u]`因为还没有收集到道具。 
4.如果顶点`v`提高生命值或伤害，识别当前跟踪的卡牌`dp1[u]`应用升压。 计算新卡功率并更新`dp1[v]`因此。 保持`dp2[v] = dp2[u]`。 
5.如果顶点`v`给出 w 次方的属性，只需将 w 添加到`dp2[v]`然后离开`dp1[v]`不变。 
6. 在每次传播时，确保`dp1[v]`和`dp2[v]`取所有传入边缘的最大可实现值。 这样，我们就能始终跟踪全局最优路径。 
7.处理完所有顶点后，答案为`dp2[n] + dp1[n]*10^9`，因为在最后的顶点我们可以将最好的牌乘以$10^9$正好一次。 

为什么它有效：该算法维护两个不变量。 第一的，`dp1[i]`如果我们计划在最后将其相乘，则始终表示顶点 i 处可达到的最佳单卡功率。 第二，`dp2[i]`代表沿途的所有其他贡献。 因为我们按拓扑顺序处理顶点，所以在访问顶点之前会解决所有依赖关系，从而保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
events = []
for _ in range(n):
    line = list(map(int, input().split()))
    events.append(line)

edges = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    edges[u-1].append(v-1)

dp1 = [0]*n  # max card to multiply
dp2 = [0]*n  # sum of other powers
dp1[0] = 0
dp2[0] = 0

for u in range(n):
    for v in edges[u]:
        e = events[v]
        c1, c2 = dp1[u], dp2[u]
        if e[0] == 0:
            dp1[v] = max(dp1[v], c1)
            dp2[v] = max(dp2[v], c2)
        elif e[0] == 1:
            a, b = e[1], e[2]
            new_card = a*b
            dp1[v] = max(dp1[v], max(c1, new_card))
            dp2[v] = max(dp2[v], c2 + min(c1, new_card) if c1 else c2)
        elif e[0] == 2:
            x = e[1]
            if c1:
                dp1[v] = max(dp1[v], (c1//max(1, c1//(10**9))) + x)
                dp2[v] = max(dp2[v], c2)
        elif e[0] == 3:
            y = e[1]
            if c1:
                dp1[v] = max(dp1[v], (c1//max(1, c1//(10**9))) * y)
                dp2[v] = max(dp2[v], c2)
        elif e[0] == 4:
            w = e[1]
            dp1[v] = max(dp1[v], c1)
            dp2[v] = max(dp2[v], c2 + w)

print(dp2[n-1] + dp1[n-1]*10**9)
