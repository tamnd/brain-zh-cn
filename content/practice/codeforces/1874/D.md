 ## 解决方案
 ## 问题理解

 我们有一个简单的线性城市链，编号从 0 到 n，由 n 条道路依次连接。 每条路都有一个“美丽”值，该值决定了水母站在其端点之一时穿过该路的概率。 从城市 0 开始，Jellyfish 随机选择一条与其美丽程度成比例的相连道路并沿着它移动。 她的目标是到达城市 n，我们希望为道路分配美丽值，以便她到达之前的预期天数最小化，但美丽值总和不超过 m。 

输入由两个整数 n 和 m 组成。 输出是一个浮点数，表示到达城市 n 的最小预期天数。 约束告诉我们，n 最多可以达到 3000，这意味着任何复杂度明显低于 O(n*m) 的算法都可能变得不可行。 期望值计算涉及除法和累积概率，因此需要注意避免浮点精度误差，特别是因为该问题要求绝对或相对误差低于 1e-9。 

当 m 等于 n 时，会出现微妙的边缘情况。 在这种情况下，我们必须为每条道路分配美丽度 1，因为我们不能超过美丽度的总和。 另一个边缘情况是 n = 1，这很简单，但证实了算法处理最小的链。 任何忽视沿链美景最佳分配的幼稚方法都有可能将所有美景分配给一条路，增加其他地方的预期天数，违反最小化总预期时间的要求。 

## 方法

 一种简单的方法是尝试枚举所有可能的美丽值分配，其总和不超过 m，并计算每个分配的预期天数。 对于每个任务，我们需要求解 n+1 个状态上的马尔可夫链来计算预期步骤。 即使采用动态规划，将 m 分成 n 个部分的整数划分数量也是巨大的（大约为组合 (m, n)），这使得 n 达到 3000 时完全不可行。 

关键的观察是城市是线性连接的，形成路径图。 对于这样的结构，从城市 0 到达城市 n 的预期天数有一个简单的递归。 令 f[i] 表示从城市 i 出发到达城市 n 的预计天数。 如果城市 i 的两个邻居都有边缘美人 a[i]（朝向 i+1）和 a[i-1]（朝向 i-1），则递推式为：```
f[0] = 1 + f[1]          # only one outgoing edge
f[i] = 1 + (a[i-1]/(a[i-1]+a[i]))*f[i-1] + (a[i]/(a[i-1]+a[i]))*f[i+1]  for 0 < i < n
f[n] = 0
```由于我们想要最小化 f[0] 并且该函数在连续美女的比率上是凸的，因此我们可以对总美女总和使用动态规划来优化分配美女。 更具体地说，最优解决方案将总美丽度总和 m 分配给道路，使得连续美丽度的比率满足一个简单的属性：对于连续道路，它们的美丽度形成一个算术级数，平衡预期的前进和后退步数。 这相当于求解线性方程组中的变量 a[i]，该线性方程组是通过求和约束最小化递推而导出的。 

对于这个问题，一种方便的方法是“贪婪分配凸优化”：首先为所有道路分配 1，然后迭代增加增量最大地减少总预期天数的道路，直到达到总和 m。 通过仔细使用前缀和，可以有效地计算预期值更新。 复杂度为 O(n*m)，在给定 n、m <= 3000 的情况下可接受。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举美女| O(梳子(m,n)*n) | O(n) | 太慢了 |
 | 最优 DP / 贪婪分配 | O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1.初始化一个数组`a`大小为n，代表道路的美丽程度，全部设置为1。这确保我们满足每条道路的最小约束1。 
2. 使用路径图的递归计算从城市 0 开始的初始预期天数。 这给出了具有最小美感的基线值。 
3. 当美丽度总和小于 m 时，确定哪条路如果其美丽度增加 1，将最大程度地减少预期天数。 这涉及计算每条道路的 f[0] 的边际下降。 
4、增加边际效益最高的道路美感。 相应地更新预计天数。 
5. 重复步骤3和4，直到美数总和达到m。 选择每个增量以最大程度地减少预期天数，并且由于函数是凸函数，因此这种贪婪分配会导致全局最小预期天数。 
6. 分配完所有美女后，使用递推公式计算最终预计距离 0 号城市的天数。 

为什么有效：预期天数是线性路径中美女的凸函数。 增加道路的美观度总是会提高该路段相对于相邻路段的进度，并且贪婪分配确保每个额外的美观度单位都会对 f[0] 做出最大可能的减少。 自始至终都遵守总和约束，并且线性递归保证了正确的预期天数计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

# Initialize beauties to 1
a = [1] * n
remaining = m - n

# Precompute f for current a
def compute_expected(a):
    f = [0.0] * (n + 1)
    for i in range(n - 1, -1, -1):
        f[i] = 1 + f[i + 1] * a[i] / (a[i] + (a[i-1] if i > 0 else 0))
        if i > 0:
            f[i] += f[i-1] * a[i-1] / (a[i] + a[i-1])
    return f[0]

# Greedy allocation
while remaining > 0:
    best_gain = -1
    best_idx = -1
    for i in range(n):
        a[i] += 1
        gain = compute_expected(a)
        a[i] -= 1
        if best_gain < 0 or gain < best_gain:
            best_gain = gain
            best_idx = i
    a[best_idx] += 1
    remaining -= 1

# Final expected days
f0 = compute_expected(a)
print("%.12f" % f0)
```我们以最小的美感初始化每条道路，确保我们不会超出限制。 这`compute_expected`函数沿路径向后传递计算 f[i]，这使我们能够看到增加美感如何减少 f[0]。 每次迭代都会选择边际改进最大的道路。 这确保了收敛到最短预期天数。
