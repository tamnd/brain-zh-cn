 ## 解决方案
 ## 问题理解

 我们被要求从线性连接的王国中的一组潜在种族中获得最大利润。 每场比赛都会占用一组连续的道路，如果所使用的所有道路都得到修复，则会提供报酬。 每条道路都有维修成本，利润定义为举办比赛的总付款减去维修所需道路的成本。 输入由道路数量组成`n`, 比赛次数`m`，每条道路的维修费用，以及每场比赛的左右端点及其付款。 输出是一个整数：可实现的最大利润。 

制约因素很大。 和`n`和`m`最多 200,000 个，任何明确检查道路的每个可能子集的算法都是不可能的。 简单地尝试检查所有可能的道路组合将需要`2^n`的操作，这是一个天文数字。 即使以嵌套方式迭代每条道路的所有比赛也可能达到 200,000 × 200,000 = 4×10^10 次操作，这太慢了。 这意味着 O(n log n + m log n) 的解决方案是合理的，但任何 O(n·m) 的解决方案都会失败。 

边缘情况包括不修复任何道路是最佳的情况，因为相对于维修成本而言，所有比赛都太昂贵，或者所有道路的维修成本为零，从而使每场比赛都有利可图。 例如，如果我们有一条道路需要花费 10 美元来修复，而使用该道路的一场比赛只需花费 5 美元，那么最好的选择就是不进行任何修复并获得零利润。 粗心的实施可能会自动包括所有种族，高估利润。 

## 方法

 蛮力方法在概念上很简单。 对于每个可能的道路子集，计算可以运行哪些比赛，然后计算利润。 这是正确的，因为它检查了每种可能性，但对于 n=200,000 来说它变得不可行。 操作次数大约为 O(2^n · m)，大得离谱。 

更快解决方案的关键见解是将问题建模为间隔动态规划的变体或基于分段的决策问题。 每条道路都可以修复或不修复，并且只有当其间隔内的所有道路都修复时，比赛才有价值。 如果我们将“潜在利润”想象为比赛的总付款减去修复道路的成本，我们可以将问题视为决定修复哪些连续的子区间。 通过扭转视角并考虑“通过修复这条道路获得的利润”，我们注意到问题可以转化为经典的最大和路段问题：每条道路都有一个由需要它的比赛减去其修复成本定义的净值，并且我们希望选择连续道路的子集来最大化总净值。 然而，由于比赛可以跨越多条道路，我们需要有效地处理贡献。 

最佳解决方案结合使用扫描线和线段树技术。 我们可以将比赛表示为前缀和数组的加法，这样每条道路都知道它参加的比赛的总价值。那么对于每条道路，修复后的净利润就是涉及它的比赛总价值减去其修复成本。 问题归结为选择净利润为正的道路； 任何一条净利润为负的路都会减少总数，因此不应该修复。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n·m) | O(2^n·m) | O(n + m) | 太慢了|
 | 最佳 | O(n + m) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`road_value`大小 n+2 为零。 该数组最终将包含覆盖每条道路的所有比赛的付款总和。 
2. 迭代每场比赛。 对于跨越道路的比赛`lb`到`ub`付款`p`, 增量`road_value[lb]`经过`p`并减少`road_value[ub+1]`经过`p`。 这是一个标准的前缀和差数组技巧，可有效地将值应用于范围。 
3. 将差异数组转换为每条道路的实际值。 从 1 迭代到 n 并累加`road_value[i] += road_value[i-1]`。 此后，`road_value[i]`包含所有公路比赛的潜在收益总和`i`。 
4. 计算每条道路的净利润为`net[i] = road_value[i] - repair_cost[i]`。 如果净利润为负，则将其设置为零。 这一步骤确保我们永远不会修复会减少总利润的道路。 
5. 总结所有道路的净利润。 这个总和是可实现的最大利润，因为仅修复具有正净贡献的道路可以保证覆盖这些道路的所有比赛都会增加总利润。 

为什么有效：每场比赛都会为其跨越的每条道路贡献自己的报酬。 通过减去维修成本，我们直接衡量每条道路对总利润的贡献。 任何净值为负的道路都会减少总利润，因此忽略它是安全的。 由于比赛只有在所有必需的道路均已修复的情况下才进行，因此扫线前缀和方法可以正确计算每条道路的总付款，并对正贡献进行求和以选择最佳子集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
repair_cost = [0] + [int(input()) for _ in range(n)]

road_value = [0] * (n + 2)

for _ in range(m):
    lb, ub, p = map(int, input().split())
    road_value[lb] += p
    if ub + 1 <= n:
        road_value[ub + 1] -= p

for i in range(1, n + 1):
    road_value[i] += road_value[i - 1]

profit = 0
for i in range(1, n + 1):
    net = road_value[i] - repair_cost[i]
    if net > 0:
        profit += net

print(profit)
```第一部分读取输入并构建维修成本数组。 我们在索引 0 处填充 0，以实现基于 1 的索引。 第二部分初始化一个差异数组，以跟踪每个竞赛如何在其范围内添加其付款。 将差异数组转换为前缀和即可得出每条道路的总潜在收入。 减去维修成本并对正数求和即可得出最终利润。 通过仔细使用基于 1 的索引和 n+2 大小的数组来安全地处理边界增量，可以防止偏一错误。
