 ## 解决方案
 ## 问题理解

 我们有一个`n × m`网格。 每个单元必须包含四个角形管件之一。 每块正好连接电池的两个相邻侧面。 

四种管道类型是：

 - 类型 1 连接顶部和左侧
 - 类型 2 连接顶部和右侧
 - 类型 3 连接底部和右侧
 - 类型 4 连接底部和左侧

 有些单元格已经固定，而有些单元格是空的并标记为`.`。 我们必须计算有多少种方法可以填充空的单元格，以便整个管道系统不泄漏。 

如果满足以下任一条件，则管端有效：

 - 连接到相邻单元中的另一个管道末端，或
 - 触及网格的外边界。 

任何不匹配的内端都会造成泄漏并使配置失效。 

网格最多可包含`5 · 10^5`单元格，这会立即排除任何对分配的搜索。 每个空单元格都有四种可能性，因此蛮力会检查`4^k`国家在哪里`k`是空单元格的数量。 甚至`k = 30`已经不可能了。 

所包围的单元格总数`5 · 10^5`强烈表明预期的解决方案在网格大小上是线性的或接近线性的。 任何单元格数量的二次方都会超时。 

棘手的部分是理解“不泄漏”在全球范围内的真正含义。 粗心的实现可能会尝试独立验证相邻小区并错过边界施加的结构约束。 

考虑这个输入：```
1 1
.
```答案是：```
0
```每种管道类型都有两个末端。 在一个`1 × 1`网格，四个边都是边框。 这四个部件中没有一个两端同时朝所需方向指向外部，因此无法放置。 

另一个微妙的情况：```
1 2
13
```答案是：```
1
```类型`1`第一个单元格暴露了顶部和左侧，这两个单元格都有效，因为它们接触了边框。 类型`3`在第二个单元格中暴露底部和右侧，这也是有效的，因为它们接触边框。 两个内侧并不连接，因此这种布置实际上是泄漏的。 一个只验证本地学位的天真的检查者会错误地接受它。 

另一个重要的边缘情况：```
2 2
11
11
```答案是：```
0
```第一行中的两个单元尝试将其顶侧暴露于边界，这很好，但下侧完全缺少连接。 每个内部边缘必须从两侧连接或从两侧未使用。 

关键的实现是每个内部邻接都在两个相邻单元之间施加平等条件。 

## 方法

 暴力解决方案很简单。 对于每个空单元格，尝试所有四种管道类型。 构建完整的网格后，扫描所有相邻对并验证每个管端是否正确匹配。 这是有效的，因为有效性条件纯粹是本地的。 

问题是作业的数量。 如果网格有`k`空单元格，我们必须测试`4^k`配置。 在最坏的情况下，`k = 5 · 10^5`，这是一个天文数字。 

管件的结构赋予了更强的性能。 

每一块都可以通过是否在垂直方向上连接以及是否在水平方向上连接来描述。 

例如：

 - 类型 1 使用顶部和左侧
 - 类型 2 使用顶部和右侧
 - 类型 3 使用底部和右侧
 - 类型 4 使用底部和左侧

 观察内部边缘发生的情况。 

假设两个水平相邻的单元共享一条边。 要么两个部分都通过该边缘连接，要么两者都不连接。 查看四种片类型，此条件仅取决于单元是否属于两个奇偶校验类别之一。 

更简洁的表达方式是这样的：

 为每个单元格定义一个二进制值：

 - 类型`1`和`3`属于班级`0`- 类型`2`和`4`属于班级`1`然后，每个有效的水平邻接都要求两个相邻单元具有相反的类别。 

类似地，每个有效的垂直邻接也需要相反的类。 

这意味着整个网格被迫形成棋盘图案。 

一旦每个单元格的棋盘类被固定，每个单元格只有两种允许的管道类型：

 - 每个边框方向都有一个选择。 

然后边界约束决定这两个选择中哪一个是有效的。 

事实上，在固定棋盘奇偶校验后，每个单元格都变得唯一确定。 由于只有两种可能的棋盘颜色，因此最终答案最多是`2`。 

因此，我们只测试两个全局模式，而不是搜索指数级的许多作业。

 ## 算法演练

 1. 为每个管道类型分配一个奇偶校验值。 

让：$$p(1)=0,\quad p(2)=1,\quad p(3)=0,\quad p(4)=1$$有效系统中的相邻单元必须始终具有相反的奇偶校验。 
2. 尝试第一个棋盘图案。 

对于每个细胞`(i, j)`：$$p(i,j) = (i+j)\bmod 2$$这决定了单元必须具有哪个奇偶校验。 
3. 对于每个固定单元，验证兼容性。 

如果网格已包含其奇偶校验与所需的棋盘奇偶校验不匹配的管道类型，则此模式是不可能的。 
4. 对于每个单元格，确定是否存在混凝土管道方向。 

一旦奇偶校验确定，每个单元就有两种候选管道类型：

 - 奇偶校验`0`给出类型`1`或者`3`- 奇偶校验`1`给出类型`2`或者`4`边界决定哪一个是合法的。 

例如，顶行中的单元格不能使用仅指向下方的管道。 其顶部暴露的一侧必须与边框行为相匹配。 
5. 检查所需的边界方向是否唯一确定有效类型。 

内部边缘已经保证匹配，因为相邻奇偶校验是交替的。 

唯一剩下的问题是工件方向是否与外边框兼容。 
6. 对相反的棋盘着色重复该过程。 

第二种模式是：$$p(i,j) = 1 - ((i+j)\bmod 2)$$7. 计算两种模式中有多少是有效的。 

### 为什么它有效

 不变量是每个内部边缘都连接两个具有相反奇偶性的单元。 

对于任何管道类型，跨过边缘移动会翻转该边缘是否被使用。 由于每个有效的内部边缘必须要么被两个单元使用，要么被两个单元都不使用，所以相邻单元必须属于相反的奇偶校验类别。 

具有强制奇偶校验交替的所有邻接的连接网格恰好有两个有效的全局分配，即两个棋盘着色。 一旦单元的奇偶校验被固定，边界约束就会强制采用唯一的管道方向。 没有额外的自由了。 

由于该算法精确地测试了仅有的两种可能的全局奇偶校验结构，因此它不会错过任何有效的配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000003

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # parity:
    # 1,3 -> 0
    # 2,4 -> 1
    parity = {
        '1': 0,
        '2': 1,
        '3': 0,
        '4': 1
    }

    ans = 0

    for start in range(2):
        ok = True

        for i in range(n):
            for j in range(m):
                need = (i + j + start) & 1

                c = g[i][j]

                if c != '.':
                    if parity[c] != need:
                        ok = False
                        break

            if not ok:
                break

        if ok:
            ans += 1

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```由于数学结构消除了所有局部模拟，因此实现时间出人意料地短。 

字典`parity`对管件的两个等价类进行编码。 核心事实是相邻小区必须始终具有相反的奇偶校验。 

对于两个可能的棋盘分配中的每一个，我们计算位置所需的奇偶校验`(i, j)`作为：```
(i + j + start) & 1
```变量`start`选择左上角显示的奇偶校验。 

如果网格中已经存在固定管道，我们只需验证其奇偶校验是否与所需的奇偶校验匹配。 任何不匹配都会立即使整个模式失效。 

不需要显式的边缘检查。 奇偶校验特性已经保证了所有内部兼容性。 

一个常见的错误是尝试重建实际的管道方向。 那是不必要的。 奇偶条件是充分必要的。 

另一个容易犯的错误是假设答案可以超过`2`。 一旦选择了一个单元奇偶校验，所有其他单元奇偶校验都会受到邻接约束的强制。

import sys
import io

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    parity = {
        '1': 0,
        '2': 1,
        '3': 0,
        '4': 1
    }

    ans = 0

    for start in range(2):

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()
