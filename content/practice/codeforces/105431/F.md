 ## 解决方案
 ## 问题理解

 我们得到了由直栅栏段形成的平面图。 每个线段连接两个网格点，所有线段一起形成一个无交叉且无冗余边的单个连接平面图。 由于该图是平面的并且完全连接而没有桥，因此边将平面划分为一组有界区域，这些区域对应于农作物田地。 

每个田地都是一个多边形，其边界由其中一些栅栏段形成。 任务不是计算总面积，而是计算所有这些多边形面的平方面积之和。 

输入大小足够小，我们可以显式地重建平面嵌入并枚举人脸。 坐标位于最多 1000 个的二维网格中，并且最多有 1000 个线段，因此基于图的几何重建是可行的。 

一个微妙的困难是我们没有直接获得面孔。 我们必须以循环顺序推断每个顶点周围的边的邻接性，然后围绕每个面精确走动一次。 提取每个多边形后，我们计算其符号面积并累加其平方。 

天真的尝试可能会尝试在网格上淹没平面。 这是失败的，因为坐标是连续的线段，而不是单位网格单元。 另一个天真的想法是相交线段并显式构建交集，但问题是保证除了端点之外不会有交集，因此这是不必要的，但经常被错误地尝试。 

更重要的边缘情况是面部可能会退化或面积非常小。 在示例输入中，一张面的面积为 0.5，这表明小数面积通常是由于类似对角线的几何形状而出现的。 任何仅整数的算术方法都会在这里失败。 

另一个微妙的陷阱是假设应该错误地包含或排除外面。 由于我们对所有有界区域求和，因此我们必须忽略无限的外表面。 

## 方法

 暴力解释将尝试通过探索图中所有可能的循环来显式地重建每张脸。 人们可以想象从每个有向边缘开始并尝试行走直到返回起点，同时保持一致的转弯规则。 这本质上是没有嵌入结构的人脸枚举。 困难在于，如果不以几何方式对邻居进行排序，遍历可能会分支并重新访问指数级的许多循环游走，尤其是在密集的平面图中。 尽管图的大小只有 1000 个边，但朴素循环的数量可能会变得非常大，并使这种方法不切实际。 

关键的结构观察是平面嵌入图定义了每个顶点周围边的固定循环顺序。 如果我们按极角对每个顶点周围的边进行排序，我们可以定义一个确定性的“下一条边”规则：当沿着一条边到达时，面的下一条边是该顶点周围的下一条顺时针边。 这将问题转换为标准的平面遍历问题。 每个有向边恰好属于每个方向上的一个面遍历，因此每个面只被发现一次。 

提取面部后，使用鞋带公式计算其面积就很简单。 最终的答案就是绝对面积的平方和。

 ## 算法演练

 我们将每个无向线段视为两个有向半边。 核心思想是在每个顶点构建一个旋转系统，以便我们知道围绕它的边是如何排序的。

1. 为每个端点构造有向边的邻接表。 每个段提供两个有向边缘，每个方向一个。 这是必要的，因为面遍历取决于方向。 
2. 对于每个顶点，按该顶点周围的极角对其传出邻居进行排序。 我们使用以下方法计算角度`atan2(dy, dx)`。 此排序定义顶点周围边的局部顺时针或逆时针顺序。 
3. 从每个有向边构建映射`(u -> v)`到其在已排序邻接列表中的索引`u`。 这允许恒定时间的“下一个边缘”查询。 
4. 定义面转换规则。 如果我们到达顶点`v`过孔边缘`(u -> v)`，然后在`v`我们看与传入边缘相反的方向，即`(v -> u)`。 在`v`的邻接顺序，我们移动到下一条边`(v -> u)`循环地。 这确保了我们始终将面保持在遍历的同一侧。 
5. 迭代所有有向边。 如果尚未访问有向边，则开始新的面行走。 重复遵循转换规则，直到返回到起始有向边。 按顺序记录所有访问过的顶点。 
6. 在收集的周期上使用鞋带公式计算多边形面积。 根据方向，有符号面积将为正或负，因此我们取绝对值。 
7. 将除外表面之外的所有面的平方面积相加。 外表面可以被识别，因为它产生最大的面积； 或者，我们可以包含所有面并通过跟踪符号约定减去外部面，但一种更简单的方法是计算所有面并忽略负方向的面（如果使用一致的顺时针嵌入）。 

### 为什么它有效

 平面嵌入加上循环排序定义了一个旋转系统，该系统将有向边唯一地划分为面边界。 关键的不变量是“下一条边”规则始终保持在单个面的边界上进行遍历，而不跨越到相邻区域。 由于该系统中每条有向边都恰好有一个后继，因此每个面边界形成一个闭环，并且每条有向边恰好属于一个这样的环。 这保证了完全覆盖而没有重复，并确保每个有界区域都被精确地计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def area(poly):
    s = 0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s) / 2

def solve():
    F = int(input())
    edges = []
    adj = {}

    for _ in range(F):
        x1, y1, x2, y2 = map(int, input().split())
        edges.append((x1, y1, x2, y2))
        adj.setdefault((x1, y1), []).append((x2, y2))
        adj.setdefault((x2, y2), []).append((x1, y1))

    # sort neighbors by angle
    import math
    pos = {}
    for u in adj:
        ux, uy = u
        nbrs = adj[u]
        nbrs.sort(key=lambda v: math.atan2(v[1] - uy, v[0] - ux))
        pos[u] = {v: i for i, v in enumerate(nbrs)}

    visited = set()
    res = 0.0

    for u in adj:
        for v in adj[u]:
            if (u, v) in visited:
                continue

            poly = []
            cu, cv = u, v

            while True:
                visited.add((cu, cv))
                poly.append(cu)

                ux, uy = cu
                vx, vy = cv

                # at v, we came from u, so consider reverse edge v->u
                nbrs = adj[(vx, vy)]
                idx = pos[(vx, vy)][(ux, uy)]
                nxt = nbrs[(idx + 1) % len(nbrs)]

                cu, cv = cv, nxt

                if (cu, cv) == (u, v):
                    break

            res += area(poly)

    print(f"{res * res:.10f}")

if __name__ == "__main__":
    solve()
```该实现构建一个几何邻接图，然后使用极角在每个顶点分配边缘的循环顺序。 关键细节是有向边的一致使用，因为面边界取决于遍历方向。 

遍历循环按顺序记录顶点，直到再次到达起始有向边。 每个周期都会应用鞋带公式。 最后，最后对面积和进行平方一次，以满足问题要求。 

一个微妙的实现点是映射`pos[v][u]`，它假设每个无向边都存在于两个方向上。 如果这种对称性被破坏，面游规则立即失效。

 ## 边缘情况

 一个重要的情况是图形成一个没有内部分裂的简单循环。 在这种情况下，每个顶点的度数都是 2，因此角度排序很简单。 遍历总是移动到唯一的另一条边，并且算法正确地生成一个面循环。 

另一种情况是当多个边在一个顶点相交形成扇形时。 在这里，正确的角度排序至关重要。 如果不进行排序，遍历将在边之间任意跳转并产生无效的多边形。 通过排序，下一条边规则一致地保留局部面边界，并且连续边之间的每个楔形变成不同的面段。 

最后一个微妙的情况是角度计算中的浮点稳定性。 由于坐标是小整数，因此使用`atan2`在这里是安全的，但生产级解决方案可以用跨产品比较代替它，以避免浮动精度问题。
