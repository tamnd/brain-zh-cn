 ## 解决方案
 ## 问题理解

 我们有一个人从位置沿直线段移动`a`定位`b`以每分钟 1 个单位的恒定速度。 独立位置有一个网络基站`c`覆盖了距离内的一切`r`。 当人移动时，他们每时每刻要么在覆盖范围之内，要么在覆盖范围之外。 任务是计算他们在整个行程中在覆盖区域之外花费的总时间。 

由于速度为 1，因此时间等于行驶的距离。 因此，问题归结为测量该段有多少来自`a`到`b`位于覆盖范围之外。 

关键的几何观察是数轴上的覆盖区域本身就是一个以`c`，延伸`r`两个方向上的单位。 所以覆盖的区域就是区间`[c - r, c + r]`。 移动也是一个间隔，但可能会向左或向右移动，具体取决于是否`a < b`或者`a > b`。 

这些约束允许最多 1000 个测试用例，坐标大小最多为 10^8。 这立即表明每个测试解决方案需要 O(1)，因为任何涉及远距离扫描或模拟的事情都是不可能的。 

一种天真的解释是模拟每分钟或一个单位的运动，但坐标范围使得这是不可行的。 即使单个测试用例也最多可以跨越 2⋅10^8 个步骤。 

通常破坏不正确方法的边缘情况包括反转方向（当`a > b`），全覆盖（整个段内`[c-r, c+r]`），并且根本没有重叠（与覆盖范围完全不相交的分段）。 另一个微妙的情况是，当线段仅部分重叠覆盖区间时，需要仔细处理相交端点。 

例如，如果`a = 1, b = 10, c = 7, r = 1`，覆盖范围为`[6, 8]`。 行驶的路段仅在以下位置重叠`[6, 8]`，所以未覆盖的部分是`[1, 6]`和`[8, 10]`，给出总的未覆盖长度 7。这里的一个错误是忘记正确夹紧重叠部分或假设方向并不重要。 

## 方法

 蛮力的想法是在单位分辨率下模拟 Polycarp 的运动，检查每个整数点或每个小步是否位于内部`[c - r, c + r]`。 这在概念上是有效的，因为每个位置的覆盖范围很容易测试。 然而，每次测试的路径长度最多可达 2⋅10^8，并且如果测试多达 1000 次，这将变得完全不可行。 

问题的结构消除了模拟的需要。 移动和覆盖都是一条线上的连续间隔。 我们不需要随着时间的推移跟踪位置，而只需计算旅行段与覆盖段相交的程度。 一旦我们认识到这一点，问题就变成了纯粹的区间交集任务。 

我们计算行程间隔之间的重叠`[min(a,b), max(a,b)]`和覆盖区间`[c-r, c+r]`。 这种重叠的长度就是覆盖所花费的时间。 从总行驶距离中减去它就得出在覆盖范围之外花费的时间。

 ## 算法演练

 我们根据时间间隔重新制定一切。 

1. 将运动转换为标准化段`[l1, r1]`在哪里`l1 = min(a, b)`和`r1 = max(a, b)`。 这完全消除了方向，因此我们只处理长度。 
2. 将覆盖范围转换为`[l2, r2]`在哪里`l2 = c - r`和`r2 = c + r`。 这代表信号可用的所有点。 
3. 计算这两个线段的交集`left = max(l1, l2)`和`right = min(r1, r2)`。 
4.如果`right > left`，交点的长度为正，因此覆盖时间为`right - left`。 如果`right <= left`，没有重叠并且覆盖时间为零。 
5. 计算总行程时间为`r1 - l1`，然后减去覆盖时间即可得到未覆盖时间。 

这样做的原因是速度为 1 的运动将时间转化为几何长度。 问题被简化为测量一个区间有多少位于另一个区间之外，即总长度减去交叉点长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, r = map(int, input().split())

    l1, r1 = min(a, b), max(a, b)
    l2, r2 = c - r, c + r

    left = max(l1, l2)
    right = min(r1, r2)

    overlap = max(0, right - left)
    total = r1 - l1

    print(total - overlap)
```代码直接实现了问题的区间视图。 第一步标准化方向，这避免了任何特殊的情况`a > b`。 第二步明确构建覆盖区间。 

相交逻辑依赖于重叠线段的标准公式。 这`max(0, right - left)`确保非重叠间隔贡献为零，避免负长度。 

最后，从总数中减去重叠就可以准确地得出覆盖范围之外所花费的时间。

 ## 边缘情况

 当`a == b`，运动区间收缩为一个点。 在这种情况下`r1 - l1`为零，因此无论覆盖范围如何，答案都自动为零。 用于输入`a = 5, b = 5, c = 0, r = 0`，区间视图给出`[5,5]`和`[0,0]`, producing zero overlap and zero total length, matching the correct result.

 当根本没有重叠时，例如`a = 0, b = 10, c = 100, r = 1`，交集计算得出`min(r1,r2) < max(l1,l2)`，因此重叠变为零。 答案减少为完整的段长度，即 10。 

当覆盖范围完全包含运动片段时，例如`a = 2, b = 5, c = 3, r = 10`，交集等于整个线段，因此重叠等于总长度，结果为零。
