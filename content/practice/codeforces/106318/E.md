 ## 解决方案
 ## 问题理解

 我们得到了两块多米诺骨牌。 每个图块都有两端，每一端都带有一个从0到6的整数值。第一张多米诺骨牌由两个数字描述，第二张多米诺骨牌也由两个数字描述。 

我们可以旋转每张多米诺骨牌，这意味着我们可以交换它的两端。 我们想要决定是否可以将两个多米诺骨牌排成一排，以便第一个多米诺骨牌的一端接触第二个多米诺骨牌的一端，并且接触端的值相等。 如果这样的放置是可能的，我们必须按照它们在行中出现的顺序以选定的方向输出两个多米诺骨牌。 如果不可能，我们输出-1。 

重要的解释是，我们并不是试图匹配整个多米诺骨牌，而只是匹配一对相互接触的末端。 每个多米诺骨牌都可以独立翻转，因此每对数字可以按任意顺序出现。 

约束很小：值在 0 到 6 之间。这立即排除了对复杂数据结构或优化的任何需要。 任何检查恒定数量配置的解决方案就足够了，因为只有几种可能的方向。 

一个微妙的边缘情况是存在多个匹配时。 例如，如果两个多米诺骨牌两端都包含相同的数字，则存在许多有效输出。 该任务允许任何正确的排列，因此我们只需要找到一种有效的配置，而不是枚举所有可能性。 

另一种边缘情况是没有一对末端匹配。 例如，(1,2) 和 (3,4) 没有共同值，因此任何旋转都无济于事，答案必须为 -1。 

## 方法

 暴力的观点是尝试两个多米诺骨牌的所有可能的方向。 每个多米诺骨牌都有两种可能的状态：原始顺序或翻转顺序。 这给出了该对的总共四种配置。 对于每个配置，我们检查第一个多米诺骨牌的右端是否等于第二个多米诺骨牌的左端。 如果任何配置有效，我们都会打印它。 

这种蛮力已经非常小：每个测试用例进行四次检查。 即使有很多测试用例，这也会是瞬时的。 不存在隐藏的组合爆炸，因为每张多米诺骨牌都有恒定的自由度。 

关键的观察是我们不需要显式地模拟所有配置。 我们只需要找到两个多米诺骨牌之间的共享值即可。 一旦我们找到了一个共同的值，我们就可以调整两个多米诺骨牌的方向，使这个值位于接触的一端。 这减少了从检查配置到检查两个大小为 2 的集合的交集的问题。 

那么问题就变成了：{a,b}和{c,d}的交集是否至少包含一个值，如果是，我们如何将该值放在接触的位置。

 ## 算法演练

 1. 读取两张多米诺骨牌 (a, b) 和 (c, d)。 这些代表每个图块每一半的值。 
2. 尝试找到两个多米诺骨牌中都出现的值。 该值将用作它们之间的连接点。 我们从概念上检查 a 或 b 中的任何一个是否等于 c 或 d 中的任何一个。 
3. 如果不存在这样的值，则输出-1，因为没有旋转可以使接触端相等。 
4. 否则，选择一个匹配对并确定方向，使得匹配值成为第一张多米诺骨牌的右端和第二张多米诺骨牌的左端。 
5. 通过按所选方向打印第一张多米诺骨牌，然后按所选方向打印第二张多米诺骨牌来构建输出。

一个关键的微妙之处是方向很重要。 如果共享值出现在多米诺骨牌的错误一侧，我们必须翻转该多米诺骨牌，以便共享值移动到所需的边界位置。 这总是可能的，因为每张多米诺骨牌都有两端。 

### 为什么它有效

 该算法依赖于这样一个事实：任何有效的排列都必须使用出现在两个多米诺骨牌中的值，因为该值正是接触的值。 相反，通过适当翻转每张多米诺骨牌，任何共享值始终可以定位在边界处。 这给出了“存在有效排列”和“两对至少在一个值上相交”之间的完全等价。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())
    c, d = map(int, input().split())

    # try all match cases and construct directly
    if a == c:
        print(a, b, c, d)
        return
    if a == d:
        print(a, b, d, c)
        return
    if b == c:
        print(b, a, c, d)
        return
    if b == d:
        print(b, a, d, c)
        return

    print(-1)

if __name__ == "__main__":
    solve()
```该实现直接编码四种可能的方式来对齐匹配值。 每个条件对应于选择哪一端成为接触对。 例如，如果a等于d，我们翻转第二张多米诺骨牌，使d成为它的左端，确保邻接。 

检查的顺序并不重要，因为任何有效的配置都是可接受的。 我们只是返回第一个成功的构建。

 ## 边缘情况

 一种边缘情况是两个多米诺骨牌共享两个值。 例如，(1,2) 和(1,2)。 在这种情况下，存在多个放置位置。 该算法自然地处理这个问题，因为第一个匹配条件立即触发并产生有效的方向。 

另一个边缘情况是共享值位于两个多米诺骨牌的两端。 例如，(1,2) 和(2,1)。 正确的输出需要翻转一个多米诺骨牌，以便共享值成为接触对。 条件`a == d`或者`b == c`确保在打印之前通过交换端点来正确处理此问题。 

最后一种边缘情况是一个多米诺骨牌的两个数字相同，例如 (5,5)。 如果另一张多米诺骨牌在任何地方包含 5 个，则可以保证匹配，并且算法可以正确对齐两端而不会产生歧义，因为翻转不会在视觉上改变多米诺骨牌。
