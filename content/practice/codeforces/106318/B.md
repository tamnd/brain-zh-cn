 ## 解决方案
 ## 问题理解

 我们获得了一组建筑物的汇总统计数据，但单个建筑物的高度丢失了。 对于每个阈值$k$，我们知道有多少建筑物严格超过$k$地板。 形式上，一个数组$a$给出了其中$a_k$计算高度大于的建筑物$k$。 该阵列是非增加的，这与随着阈值增加，可以超过它的建筑物越来越少的事实相匹配。 

根据这些累积信息，我们必须重建多组建筑物高度。 作为有序结构，输出并不唯一，但我们被要求输出按非升序排序的恢复高度以及建筑物总数。 

约束条件$m \le 10^6$迫使我们避免任何二次甚至$O(m \log m)$除非精心设计，否则具有很大的常数。 预计可以通过解释连续值之间的差异来进行线性重建$a$。 

一个微妙的点是，该序列描述的是累积分布，而不是直接描述每个高度的频率。 一个天真的误解是对待$a_k$作为高度精确的建筑物数量$k$，这是不正确的。 另一个错误是试图贪婪地重建高度，而没有注意到每次减少$a$对应于一批在特定高度边界处“结束”的建筑物。 

要查看失败案例，请考虑$a = [4, 3, 1, 1]$。 天真的解释可能会直接将高度指定为每个级别的计数，从而产生诸如过多矮建筑物之类的结果。 正确的重建必须同时确保所有阈值的一致性。 

当序列在多个位置上都是平坦的时，会出现另一种边缘情况。 例如$a = [5, 5, 5]$意味着增加时建筑物不会消失$k$，因此所有建筑物的高度必须至少为 3。如果不能正确解释高原，贪婪的每层分配很容易导致计数错误。 

## 方法

 关键的观察是解释$a_k$作为高度直方图的前缀。 

让$b_k$是高度恰好为的建筑物数量$k$。 然后：

-$a_k = b_k + b_{k+1} + \dots$这是一个经典的后缀和关系。 所以：

-$b_k = a_k - a_{k+1}$为了$k < m-1$-$b_{m-1} = a_{m-1}$因此，连续值之间的每个差异都告诉我们有多少建筑物在该高度“结束”。 

一旦我们有$b_k$，我们可以通过输出高度来重构答案$k$确切地$b_k$次。 由于最终输出必须按非递增顺序，因此我们只需从高到低进行迭代。 

蛮力方法将尝试为各个建筑物分配高度并验证与所有建筑物的一致性$a_k$，这导致$O(nm)$检查或更糟。 这是不可行的$10^6$。 

差异数组解释将问题简化为单遍。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分配+验证|$O(m^2)$|$O(m)$| 太慢了|
 | 差异重建|$O(m)$|$O(m)$| 已接受 |

 ## 算法演练

 1.读取数组$a$。 将其视为未知频率上的累积后缀结构。 
2. 计算一个新数组$b$，其中每个$b_k$代表有多少建筑物有$k$地板。 对于最后一个索引，设置$b_{m-1} = a_{m-1}$。 
3. 对于所有其他索引$k$从$m-2$下降到$0$, 计算$b_k = a_k - a_{k+1}$。 这种减法隔离了有多少建筑物停止贡献超过高度$k$，这意味着它们有精确的高度$k$。 
4. 总和$b_k$获取建筑物总数$n$。 
5. 通过打印每个高度来构建输出$k$确切地$b_k$次，从高到低迭代，因此结果自动不增加。 

关键的推理步骤是减去相邻的累积计数可以分离出精确的频率。 如果没有这一步，数据的累积性质就会隐藏实际的分布。 

### 为什么它有效

 每个$a_k$计算高度严格大于的所有建筑物$k$。 当我们减去$a_{k+1}$，我们移除所有高度大于的建筑物$k+1$，留下那些高度等于$k+1$。 这将所有建筑物完美地划分为不相交的高度等级。 因为每一栋建筑都对一个建筑有贡献$b_k$，重建是无损的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    m = int(input())
    a = list(map(int, input().split()))

    b = [0] * m

    for i in range(m - 1):
        b[i] = a[i] - a[i + 1]
    b[m - 1] = a[m - 1]

    n = sum(b)

    out = []
    for h in range(m - 1, -1, -1):
        if b[h]:
            out.extend([str(h)] * b[h])

    sys.stdout.write(str(n) + "\n")
    sys.stdout.write(" ".join(out))

if __name__ == "__main__":
    main()
```重建取决于通过相邻差异计算每个高度的精确计数。 从高位到低位的循环确保了所需的排序，而无需排序。 输出结构使用直接重复； 虽然看起来很重，但印刷元素的总数正好是$n$，这是不可避免的。 

必须注意所有算术运算均以整数完成，并且访问时索引不会越界$a[i+1]$。 最后一个元素必须单独处理。

 ## 边缘情况

 一个关键的边缘情况是累积数组恒定。 对于输入：```
3
5 5 5
```该算法计算零差异，直到最后一个元素。 所有质量都累积在最终高度。 从高到低迭代可确保所有输出都来自最后一个存储桶。 

另一个边缘情况是当数组在第一个位置急剧下降时：```
3
10 0 0
```这里$b_0 = 10$，其他一切都为零。 重建生成所有高度为 0 的建筑物，这符合没有建筑物超过任何正阈值的解释。 

最终的边缘情况是最小输入大小：```
1
k
```无法做减法，答案很简单$k$高度为 0 的建筑物。算法通过最后一个元素分配直接处理此问题。
