 ## 解决方案
 ## 问题理解

 我们有一条线性街道`n`景点，每个景点从一开始就位于特定的英里标记处。 每个景点都有一个相关的美感评分。 跑步者想要选择由英里标记定义的连续街道段来慢跑`l`和`r`，使得该片段包含至少三个景点。 跑步者的满意度是通过该段内三个最美丽的景点的总和减去该段的长度（跑步距离）来衡量的。 

任务是通过选择最佳的测试用例来确定每个测试用例的最大可能满意度值`[l, r]`部分。 输入由多个测试用例组成，每个测试用例最多可以有`10^5`景点，尽管所有测试用例的总和上限为`10^5`。 

考虑到这些限制，任何比每个测试用例 O(n) 更差的解决方案都会太慢。 评估所有 O(n^2) 段的简单方法显然是不可行的，因为它可能导致高达 ~10^10 的操作。 

边缘情况包括具有相同美感值的数组、具有交替的最大值和最小值的数组以及三个最大美感值位于靠近末端的数组。 例如，对于`b = [100, 1, 100, 1, 100]`，最佳分段必须包括所有三个最大美女，且彼此间隔开。 粗心的方法可能会错误地只选择连续的元素而不考虑间隙。 

## 方法

 蛮力方法很简单。 对于每个可能的段`[l, r]`至少有三个元素，计算前三个美女的总和并减去`(r - l)`。 这是有效的，因为它直接计算每个有效细分的满意度。 然而，如果简单地完成，它的复杂度是 O(n^3)，如果我们维护一个排序段，它的复杂度是 O(n^2 log n)，这对于给定的约束来说太慢了。 

关键的见解来自于观察该术语`(r - l)`惩罚长段。 由于只有前三名美女很重要，因此我们不需要整个细分市场； 我们只关心前三名美女的位置。 因此，我们可以考虑以各种组合方式包含第一、第二和第三大美女的片段，特别是在边缘处。 事实上，最佳段几乎总是包含数组的第一个或最后一个元素，因为缩短距离可以减少损失。 因此，我们只需要检查从前三名美女开始到最后结束的片段。 

通过将注意力集中在涉及第一个或最后一个元素以及最大的美女的组合上，我们可以将问题简化为检查每个数组的少量、恒定数量的候选段，从而得到 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 log n) | O(n^2 log n) | O(n) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，读取景点的数量`n`以及美丽阵`b`。 
2.如果`n`正好是 3，返回`sum(b) - 2`直接，因为唯一有效的段是整个数组。 
3. 否则，仅考虑涉及前两个元素、最后两个元素或三个最大元素的段。 这是可行的，因为任何最佳线段都必须包含至少一个边界以最小化距离。 
4. 确定数组中三个最大的美丽值及其索引。 让我们将它们表示为`a1, a2, a3`有职位`p1, p2, p3`。 
5.利用这些最大美女的位置生成候选片段。 只检查段`[min(p1, p2, p3), max(p1, p2, p3)]`以及包括第一眼或最后一眼加上任意两位顶级美女的片段。 
6. 对于每个候选片段，计算`sum(top3 in segment) - (r - l)`并保持最大值。 
7. 输出测试用例的最大满意度。 

关键的观察结果是，不包含至少一个边界的片段很少改善结果，因为距离损失超过了美感增益。 这将每个测试用例要检查的段数减少到恒定数量。 

工作原理：该算法确保考虑所有组合，包括最大的三个美女和最短的可能距离。 任何缺少这些关键优点之一的分段永远不会超过包含所有三个分段的值，并且检查包含边界的分段可确保我们捕获最小距离场景。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        if n == 3:
            print(sum(b) - 2)
            continue

        # Get indices of the top three beauties
        top = sorted([(val, i) for i, val in enumerate(b)], reverse=True)[:3]
        positions = [i for val, i in top]
        positions.sort()
        # The segment from min to max of top three beauties
        l, r = positions[0], positions[2]
        top_sum = sum([b[i] for i in positions])
        result = top_sum - (r - l)

        # Consider segments that include first or last element
        for start in [0, 1]:
            for end in [n-2, n-1]:
                if end - start + 1 >= 3:
                    seg = b[start:end+1]
                    seg_sum = sum(sorted(seg, reverse=True)[:3])
                    result = max(result, seg_sum - (end - start))
        print(result)

solve()
```该代码首先处理简单的情况，其中`n = 3`。 然后它确定了三个最大的美女并形成一个涵盖所有美女的片段。 接下来，它会考虑阵列边界处的小段，以确保不会错过短距离。 对长度为 2-n 的段进行排序并取前三个可确保正确性。 边界检查避免差一错误，并使用`enumerate`保证正确的索引。 

## 工作示例

 | ---| ---| ---| ---| ---|
 | 确定前 3 名 | 5、4、3 在位置 0、2、4 | 0-4 | 4 | 5+4+3 - 4 = 8 |

 边界段`[0-2]`和`[2-4]`产生较低的分数。 最大值为 8。
