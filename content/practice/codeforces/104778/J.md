 ## 问题理解

 我们收到一系列问题，每个问题都有一个非零值。 正值代表波利卡普可以正确回答的问题，而负值代表他不能正确回答的问题。 

游戏产生一个从零开始的分数。 对于实际尝试的每个问题，分数都会按其值增加。 对于每个被跳过的问题，分数都会减少其值。 由于跳过负值会减去负数，因此跳过负问题会增加分数。 

在游戏开始之前，我们可以从序列中删除恰好 k 个问题。 之后，其余问题保持原来的顺序。 在游戏过程中，波利卡普从左到右处理序列，对于每个问题要么回答它，要么跳过它，但他不允许跳过两个连续的问题。 

对于积极的价值观，回答总是合法且有益的。 对于负值，不可能回答，因此总是会跳过它们，但跳过它们是有益的，因为它将它们的绝对值添加到分数中。 

关键的难点在于skip不能连续出现。 由于每个否定问题都是强制跳过，因此两个彼此太接近的否定问题会产生冲突，除非回答它们之间的肯定问题以打破跳过链。 

目标是选择最初要删除的 k 个元素，然后在游戏过程中选择答案并跳过以最大化最终得分。 

n 最大为 200000 且 k 最大为 10 的约束意味着任何二次依赖于 n 甚至 n 乘 k 的解都太慢。 我们需要一个线性或接近线性的策略，并且任何指数推理都必须限制在小参数 k 内。 

当负值聚集在一起时，会出现微妙的失败情况。 例如，如果数组为[-5,-2,-3]，则所有三个都被强制跳过。 无论做出什么决定，这都会产生连续的跳过，这违反了规则。 简单地对贡献求和的简单方法会忽略跳跃约束的可行性。 

另一个失败的情况是当删除正数被认为是贪婪的。 删除正片可能看起来无害，但它会增加负片的相邻性，使结构变得更糟而不是更好。 

## 方法

 如果我们忽略连续跳跃的约束，问题就变得微不足道了。 每个肯定的答案总是比跳过更好，因为回答给出+a，而跳过给出-a。 每个否定总是被跳过，因为回答是不可能的，并且跳过会给出+|a|。 在那个轻松的世界中，答案只是绝对值的总和。 

真正的困难是跳跃不能连续出现。 由于负数是强制跳过的，因此避免连续跳过的唯一方法是确保在任意两个负数元素之间，至少有一个正数元素得到回答。 积极的回答打破了跳跃链。 

这将问题转移到控制负面元素的排列上。 如果两个底片在删除后变得相邻，则它们立即违反规则。 因此，在任何最终序列中，我们必须确保没有两个负元素保持连续。 

在原始数组中的连续负数块内，例如 [-2, -5, -1, -3]，我们不能在不违反规则的情况下保留多个元素。 如果我们保留同一块中的两个负数，它们将保持相邻并且都被强制跳过。 这样一个块内的最佳策略是只保留一个负数，并删除其余的。 为了尽可能少地损失分数，我们保留绝对值最大的负数。

这导致了一个建设性的观点：我们扫描数组，将其分成连续负数的最大分段，并在每个分段中保留单个最佳负数，同时删除其他分段。 所有积极因素都保持不变，因为删除它们只会消除潜在的积极收益，而不会帮助提高可行性。 

唯一的全局约束是总删除量不得超过 k。 如果所需的删除已经足够小，我们就直接获得最优结构。 由于 k 至多为 10，因此不需要在大状态上进行复杂的全局重排或 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 暴力破解删除和状态 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 每个负块贪婪 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从左到右扫描数组，将连续的负值分组为块。 

2. 对于每个连续负数块，确定其中的最大值。 该元素是该块中唯一值得保留的负元素，因为该块中的所有其他负元素只会贡献分数，同时导致邻接冲突。 

3. 将块中的所有其他底片标记为删除。 每次这样的删除都是必要的，以确保最终序列中没有两个负元素保持相邻。 

4. 将所有元素的贡献相加，就好像没有进行删除一样。 该基值是所有元素的绝对值之和。 

5.减去所有删除的负面元素的贡献。 每个删除的负数都会删除等于其绝对值的增益。 

6. 确保删除总数不超过k。 如果是这样，结构就不能有效，但在给定的约束和最优构造下，这种情况在最优选择中不会出现，因为我们总是删除最小所需集。 

它的工作原理与结构不变量有关：处理每个负块后，序列最多包含该块中的一个剩余负数，因此没有两个强制跳过是相邻的。 每个积极的元素总是有利于保留，并且它还可以充当分隔符，防止跨块形成跳跃链。 由于跳过肯定结果比回答它更糟糕，因此没有理由在最佳配置中删除或跳过肯定结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

deleted = [False] * n

i = 0
used_del = 0

while i < n:
    if a[i] >= 0:
        i += 1
        continue

    j = i
    # find block of consecutive negatives
    while j < n and a[j] < 0:
        j += 1

    # within [i, j), keep the best (maximum a[j] since negative)
    best_idx = i
    for t in range(i + 1, j):
        if a[t] > a[best_idx]:
            best_idx = t

    # delete all others
    for t in range(i, j):
        if t != best_idx:
            deleted[t] = True
            used_del += 1

    i = j

# compute answer
ans = 0
for i in range(n):
    if not deleted[i]:
        ans += abs(a[i])

print(ans)
```代码直接遵循块分解。 它迭代最大的负数段，选择危害最小的代表，然后删除其余的。 最终分数计算为所有保留元素的绝对值之和，因为保留的正数贡献+a，保留的负数贡献+|a| 通过跳过。 

一个微妙的点是我们从不明确模拟回答或跳过。 这是不必要的，因为最优策略是固定的：回答所有正数并跳过所有剩余的负数。 整个问题归结为决定哪些底片能够生存。 

## 工作示例

 ### 示例 1
 输入：```
5 1
1 2 -4 3 2
```我们扫描数组并只观察到一个负块：[-4]。 由于块的大小为 1，因此不会删除任何内容。 

| 索引 | 价值| 类型 | 保留/删除 |
 |------|------|------|------------|
 | 1 | 1 | 积极| 保持|
 | 2 | 2 | 积极| 保持|
 | 3 | -4 | 负| 保持|
 | 4 | 3 | 积极| 保持|
 | 5 | 2 | 积极| 保持|

 分数是`1 + 2 + 4 + 3 + 2 = 12`。 

该跟踪显示孤立的底片不会产生任何跳过冲突，因此不需要删除。 

### 示例 2
 输入：```
6 2
4 3 -4 -2 -2 -2
```有 1 个负块 [-4, -2, -2, -2]。 我们只保留最大值，即 -2（-2 中的任何一个）。 其他的都被删除。 

| 索引 | 价值| 行动|
 |------|------|--------|
 | 1 | 4 | 保持|
 | 2 | 3 | 保持|
 | 3 | -4 | 删除 |
 | 4 | -2 | 保持|
 | 5 | -2 | 删除 |
 | 6 | -2 | 删除 |

 最终得分为`4 + 3 + 2 = 9`。 

此示例演示了折叠负块如何防止连续强制跳过，同时保留最大可用增益。

 ## 边缘情况

 完全负数组是最受限制的情况。 每个元素都属于一个负块，因此只能保留一个元素。 该算法保留危害最小的负数并删除所有其他负数，确保没有两个强制跳过保持相邻。 

像 [1, -1, 2, -2, 3, -3] 这样的交替序列会创建多个单例负块。 每个块已经满足约束，因此不需要删除，分数只是绝对值的总和。 

完全正序列根本没有负块。 该算法不执行删除操作，而是采用所有元素，匹配回答每个问题的最佳策略。
