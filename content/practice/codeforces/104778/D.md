 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度排列$n$，表示数字的排列$1$到$n$没有重复，这样就准确地$k$元素至少参与一次反转。 

反转是一对位置$i < j$值在哪里$i$大于该值$j$。 如果一个元素至少出现在一对这样的元素中，则该元素被视为“活动”，无论是左侧较大的元素还是右侧较小的元素。 

因此，任务不是控制反转的数量，而是控制有多少不同元素参与至少一种反转关系。 

限制条件$n \le 100$和$k \le n$立即建议我们不要被迫进行大量优化。 任何线性或二次的构造$n$是可以接受的，真正的困难纯粹是结构性的：决定哪些值可以“免反转”以及如何将它们与其他值隔离。 

当没有元素应该参与任何反转时，就会出现关键的边缘情况。 只有当排列完全增加时才会发生这种情况，因为任何偏差都会引入至少一个反转对。 所以$k = 0$强制排列为$1, 2, \dots, n$。 

另一种微妙的情况是当$k = n$，这意味着每个元素都必须参与反转。 这是可能的，但前提是我们避免创建一个永远不会出现在任何反转对中的全局“干净”元素。 递减排列已经满足了这一点，因为每个元素要么比其右侧的元素大，要么比其左侧的元素小。 

因此，核心挑战是决定如何构造一个排列，其中$n-k$元素完全没有反转，而其余的$k$分子被迫参与。 

## 方法

 暴力方法将枚举所有大小的排列$n$，计算每个元素是否参与任何反转，计算有多少个元素参与，并检查它是否等于$k$。 这是正确的，但立即不可行，因为有$n!$排列，甚至计算每个排列成本的反转参与$O(n^2)$，即使是中等程度的也会导致爆炸$n$。 

结构洞察力是，只有当一个元素表现得像“完美枢轴”时，它才没有倒置：其左侧的所有内容都较小，右侧的所有内容都较大。 这些元素具有极大的限制性，如果我们想要多个元素，则必须以非常受控的方式排列它们。 

我们没有尝试同时构造所有元素，而是将排列分成两部分。 我们明确选择$n-k$元素不反转，并强制剩余的$k$元素完全陷入反转。 

保证无反转元素的最简洁方法是使用最大值将它们按升序放置在排列的末尾。 这确保了它们的右侧永远不会遇到较小的元素，并且左侧的所有元素都因构造而变小。 

其余的最小值放在前面。 如果我们按降序排列它们，则该前缀中的每个元素都至少参与一次反转，因为在前缀结构中每个元素的右侧都有一个较小的元素，或者其左侧有一个较大的元素。 

这种分离干净地强制执行所需的计数。

 | 建设性分裂|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将排列分为两部分：负责所有反转参与的前缀和保证干净的后缀。 

1.如果$k = 0$，输出恒等排列$1$到$n$。 这是唯一完全没有反转的排列，因此每个元素都会自动清理。 
2. 否则，定义$m = n - k$。 这些$m$元素将是必须避免所有反转的元素。 
3. 赋值$m+1$通过$n$到 clean 后缀。 这些是最大的数字，这防止它们小于其右侧的任何元素。 
4. 将这些后缀值按升序放置在排列的末尾。 这确保了在后缀本身内不会引入反转，因为序列已排序。 
5. 用值填充前缀$1$通过$m$按降序排列。 这保证了该前缀中的每个元素至少参与前缀内的一次反转。 

反转前缀的原因是它迫使每个元素在其左侧都有一个较大的元素或在其右侧有一个较小的元素，以确保参与反转对。 

### 为什么它有效

 该结构强制执行严格的角色划分。 每个后缀元素都大于每个前缀元素，因此后缀元素不能与前缀元素形成反转。 在后缀内，顺序在增加，因此也不存在倒置，使这些元素完全干净。 

在前缀内部，降序保证对于每个元素，其右侧都存在一个较小的元素，从而产生至少一个包含该元素的反转对。 因此每个前缀元素都是活动的。 

这正好给出了$m = n-k$干净的元素和$k$活性元素，两组之间没有交叉干扰。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if k == 0:
    print(*range(1, n + 1))
else:
    m = n - k
    # prefix: 1..m in decreasing order
    prefix = list(range(m, 0, -1))
    # suffix: m+1..n in increasing order
    suffix = list(range(m + 1, n + 1))
    print(*(prefix + suffix))
```实施直接反映了构造。 唯一的分支发生在退化的情况下$k = 0$，任何反转都会违反要求，强制排序排列。 

前缀反转是必要的； 如果它增加，则没有前缀元素必然参与反转，从而破坏所需的计数。 后缀保持排序，以便它与反转行为完全隔离。

 ## 边缘情况

 案例$k = 0$是唯一禁止任何反转的情况。 该算法通过输出完全递增的排列来单独处理它，确保每个元素都满足严格的无反转条件。 

为了$k = n$，该结构产生一个完全递减的前缀，没有后缀，这保证每个元素至少出现在一个反转对中。 每个元素的左侧都有一个较大的元素，因此没有一个是干净的。 

什么时候$n - k = 1$，前缀有一个元素，它仍然参与反转，因为后缀在全局结构中其右侧包含更大的元素，确保至少存在一个反转对。 

什么时候$n - k = 0$，后缀变成整个数组，并且递增顺序保证不倒置，完全符合要求。
