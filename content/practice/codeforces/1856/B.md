 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 我们想知道是否可以构造另一个相同长度的数组，使得每个位置的值都改变，但总和保持完全相同。 

第二个数组不是任意的。 每个位置都必须与原始位置不同，但是当所有元素相加时，全局上没有任何变化。 这个问题纯粹是存在性的：我们不需要构造数组，只需决定是否存在这样的重新排列。 

测试用例数量和总数组大小方面的约束很大，因此任何解决方案对于每个测试用例都必须是线性的。 每个测试用例的二次甚至轻度超线性方法将立即失败，因为所有测试的元素总数达到$10^5$。 

主要的微妙之处在于，这与排列或重新排列无关。 新数组可以自由更改值，只要它尊重正性并保持总和不变。 这使得它成为一个全局平衡问题而不是局部匹配问题。 

一个常见的失败案例发生在以下情况：$n=1$。 在这种情况下，唯一可能具有相同总和的数组就是数组本身，因此不可能满足条件$a_1 \ne b_1$。 另一个重要的边缘情况是当所有元素都相等并且$n$很小，除非仔细检查总和约束，否则关于“移动值”的直觉通常会导致错误的结论。 

## 方法

 蛮力视角试图为每个位置分配一个与原始值不同的新值，同时跟踪剩余的总和。 人们可以想象迭代所有可能的赋值，但每个位置都有无限多个有效正整数，因此枚举在有限意义上甚至没有明确定义。 即使我们将自己限制为出现在数组中或受总和限制的值，可能性的数量也会呈指数增长$n$，使得这种方法在输入非常小的情况下不可行。 

关键的观察是我们不需要显式构造数组。 我们只需要确定是否可以同时满足总和约束和“每个索引无固定点”约束。 总和约束迫使所有头寸的总增加和减少完全抵消。 这立即表明，至少必须增加一项，至少必须减少一项，否则总和不能保持不变。 

当结构变得特别刚性时$n=1$，因为不可能进行重新分配。 什么时候$n \ge 2$，总是可以将值从一个位置移动到另一个位置：将一个元素减少$1$并增加另一个$1$，同时保持所有元素积极并确保没有位置保留其原始值。 既然所有$a_i \ge 1$，我们总是有空间减少至少一个元素。 

因此，问题崩溃为一个简单的二分法，完全基于$n$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 没有明确定义| O(n) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取数组的大小$n$。 
2.如果$n = 1$，立即输出“NO”。 对于单个元素，总约束力$b_1 = a_1$，这违反了$a_1 \ne b_1$。 
3.如果$n \ge 2$，输出“是”。 在这种情况下，我们总是可以通过减少一个元素并增加另一个元素来构造一个有效的数组，保留正数并维持总和。 
4. 对所有测试用例重复此操作。 

### 为什么它有效

 总和约束强制保留总质量。 至少有两个头寸，我们可以将一个单位从一个指数重新分配到另一个指数。 这会产生至少一个索引，其中$b_i < a_i$和一个地方$b_j > a_j$，确保不等式条件和求和保存。 任何指数都不会被迫保持不变，因为任何下降都可以在其他地方得到补偿。 为了$n=1$，这样的重新分配是不可能的，因此约束变得不相容。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    input().split()  # values not needed
    if n == 1:
        print("NO")
    else:
        print("YES")
```该解决方案故意忽略实际的数组值，因为可行性仅取决于数组的长度。 唯一有意义的决定是是否可以在至少两个指数之间进行重新分配。 

这里的一个常见错误是试图分析奇偶校验或元素结构，但这些都不重要。 除了需要至少两个自由度之外，总和约束不会限制可行性，这正是$n \ge 2$提供。 

## 工作示例

 考虑具有多种不同大小的情况的输入。 

为了$n=3$，任何数组，例如$[1,5,9]$具有足够的灵活性。 存在重新分配，因此答案是“是”。 

为了$n=1$， 例如$[1]$，除了它本身之外，不存在具有相同和的替代正整数，所以答案是“否”。 

对于另一个$n=3$类似情况$[1,2,3]$，我们总是可以构造一个新数组，例如$[2,1,3]$或任何平衡转变，所以答案再次是“是”。 

| 测试案例| n | 决定| 原因 |
 | ---| ---| --- | --- |
 | [1,5,9]| 3 | 是 | 可能重新分配|
 | [1] | 1 | 否 | sum 强制相同的数组 |
 | [1,2,3]| 3 | 是 | 可能进行类似交换的调整|

 这些痕迹证实只有数组的大小很重要，而不是值的分布。

 ## 边缘情况

 对于$n=1$，算法立即返回“NO”。 唯一可能的具有相同总和的候选数组与原始数组相同，因此不能满足不等式约束。 

为了$n=2$，算法返回“YES”。 对于像这样的输入$[10,10]$，我们可以构造$[11,9]$，它保留总和并更改两个位置。 这证实至少拥有两个职位足以重新分配价值。 

对于较大的均匀数组，例如$[1,1,1,1,1]$，算法返回“YES”，因为我们总是可以将一个单位从一个位置移动到另一个位置，同时保留正性和总和，确保没有元素保持不变。
