 ## 解决方案
 ## 问题理解

 我们有一棵有根的树`n`顶点，标记`1`通过`n`，其中顶点`1`是根。 每个非根顶点`i`有一个父母`p_i`，定义树的边缘。 我们被要求分配号码`1`通过`n`以某种顺序（排列）到顶点，以最大化特定的计数函数。 

该函数计算顶点对的数量`(u, v)`值在哪里`u`小于最低共同祖先的值`u`和`v`，这反过来又小于该值`v`。 正式地，`a[u] < a[lca(u, v)] < a[v]`。 我们想要选择排列`a`以便尽可能多的对满足这个不等式。 

问题被限制为`n ≤ 5000`。 考虑每一对的天真的方法`(u, v)`对于每个排列都是立即不可行的：有`O(n^2)`对，并且`n!`排列。 即使我们修复单个排列，天真地计算每对的所有 LCA 值也将是`O(n^3)`。 因此，暴力方法是没有希望的。 挑战在于利用 LCA 的树结构和属性来有效地计算最优值。 

边缘情况包括直线树（退化树）或星形树（所有节点都直接连接到根）。 在一条线上，远处顶点的 LCA 更接近根，因此极值可能必须靠近根才能最大化有效对。 在星形中，大多数对的根是 LCA，因此它的值变得至关重要。 

## 方法

 暴力解决方案将尝试每一种排列`1..n`，计算所有 LCA，并计算有效对。 正确性得到保证，但复杂性爆炸`O(n! * n^2)`操作 - 即使对于`n = 10`。 这建立了基线：正确但不切实际。 

优化的关键洞察是函数`f(a)`可以沿着子树递归分解。 观察到，如果我们知道每个子树可获得的最大值，我们可以通过选择相对于根而言哪个子树的节点获得较小的数字以及哪个子树的节点获得更大的数字来组合它们。 更具体地说，每个有效对`(u, v)`在哪里`lca(u, v) = x`必须涉及`x`严格介于`a[u]`和`a[v]`。 这自然是满足的，如果`x`具有中间值，其子树被划分为上方和下方的范围`a[x]`。 

有根子树上的动态编程是自然的方法。 让`dp[u][k]`是子树中的最大对数`u`如果我们分配`k`总共有多少个。 对于每个顶点，我们可以考虑分配给每个子节点的节点数来合并其子节点的 DP。 这大大降低了复杂性，因为我们避免了枚举排列并仅计算子树组合，这是可管理的`n = 5000`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n^2) | O(n! * n^2) | O(n) | 太慢了 |
 | 子树 DP | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.解析树结构。 从父数组构造邻接表，方便DFS遍历。 
2.定义DP数组`dp[u][k]`在子树中存储最大数量的有效对`u`使用`k`数字。 
3.使用DFS后序遍历树。 对于一片叶子来说，`dp[u][1] = 0`因为单个节点不形成对。 
4. 对于内部节点`u`, 开始于`dp[u][1] = 0`。 考虑每个孩子`v`并将其 DP 表与`u`的当前 DP 使用临时数组。 让`s1`是分配给的号码数量`u`到目前为止和`s2`分配给的号码`v`。 那么合并后的DP值为`dp[u][s1 + s2] = max(dp[u][s1 + s2], dp[u][s1] + dp[v][s2] + s1 * s2)`。 这`s1 * s2`term 计算通过选择一个数字形成的新对`u`的现有分配和子项的分配，其中`u`之间。 
5.处理完所有children后，`dp[1][n]`包含答案：使用所有有效对的最大数量`n`树中的数字。 
6. 返回`dp[1][n]`。 

不变的是`dp[u][k]`正确计算以 为根的子树中可实现的最大对数`u`确切的时候`k`号码已分配。 使用组合计数与子级合并可确保不同子树上的所有对都具有`u`计算 LCA 时。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def solve():
    n = int(input())
    parents = list(map(int, input().split()))
    
    tree = [[] for _ in range(n)]
    for i, p in enumerate(parents):
        tree[p-1].append(i+1)
    
    # dp[u][k] = max pairs in subtree of u using k nodes
    dp = [None] * n
    size = [0] * n
    
    def dfs(u):
        dp[u] = [0]  # 0 nodes initially
        size[u] = 1
        for v in tree[u]:
            dfs(v)
            new_dp = [0]*(size[u] + size[v] + 1)
            for s1 in range(size[u]):
                for s2 in range(1, size[v]+1):
                    new_dp[s1+s2] = max(new_dp[s1+s2], dp[u][s1] + dp[v][s2] + s1*s2)
            size[u] += size[v]
            dp[u] = new_dp[:size[u]+1]
    
    dfs(0)
    print(dp[0][n])

solve()
```DFS 自下而上构建树。 双循环将子 DP 合并到父级中，正确计算所有新对。 环境`s2`从`1`到`size[v]`避免重复计算空分配。
