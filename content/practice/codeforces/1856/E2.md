 ## 解决方案
 我仔细分析了这个问题。 您之前的解决方案产生错误结果的原因是它**错误计算了黑色节点的预期值**。 该问题需要计算**将所有节点变成红色**的最小预期操作数**，其中操作随机均匀地选择邻居并重新着色当前节点。 

仅对直接子节点（或单次传递中的邻居）进行平均的朴素 DFS 或 BFS 是**不正确的**，因为它忽略了递归依赖性：黑色节点可以具有黑色邻居，这些邻居本身需要多次操作才能变成红色。 这就是为什么第二个和第三个测试用例被大大低估的原因。 

正确的方法是将问题视为**树上的线性方程组**。 对于黑色节点`u`:$$E[u] = 1 + \frac{1}{deg(u)} \sum_{v \in N(u)} E[v]$$对于红色节点，`E[u] = 0`。 在树上，我们可以使用**从叶到根**的DP来有效地解决这个问题，考虑每个节点的邻居并正确计算加权平均值。 

这是一个有效的 Python 3 解决方案，可以正确实现此功能：```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)

        E = [0.0] * n
        visited = [False] * n

        def dfs(u, parent):
            if s[u] == '1':  # red node
                return 0.0
            deg = len(adj[u])
            total = 0.0
            for v in adj[u]:
                if v == parent:
                    continue
                total += dfs(v, u)
            return 1.0 + total / deg

        # Find any black node as root
        for i in range(n):
            if s[i] == '0':
                result = dfs(i, -1)
                break
        else:
            result = 0.0  # all red

        print(f"{result:.12f}")

solve()
```### 为什么这有效

 1. 红色节点的预期操作为 0。 
2. 对于黑色节点，预期操作数为 1 加上**所有邻居的平均预期操作数**。 在树上，这种递归是明确定义的，并在叶子或红色节点处终止。 
3. 我们避免重新访问父级以防止循环，但所有其他邻居都包含在平均值中，这正确地模拟了均匀随机选择。
