 ## 解决方案
 ## 问题理解

 我们被要求计算绘制垂直木板栅栏所需的最少笔触次数。 每块木板的宽度均为 1 米，高度各不相同。 刷子宽度正好1米，可以垂直或水平涂抹。 垂直描边一次绘制整块木板，而水平描边则在一定高度绘制所有连续的木板。 

输入包括`n`，木板的数量，后跟一个数组`a`长度`n`，代表木板的高度。 输出是一个整数：覆盖整个栅栏所需的最少笔划。 

约束条件表明`n`最大可达5000，单块木板高度可达10^9。 这意味着任何以简单方式检查所有木板对或三块木板的算法都可能执行数千万次操作并面临 TLE 风险。 我们需要一种接近 O(n^2) 或更好的方法。 

经常打破简单解决方案的边缘情况包括所有高度都相等的栅栏、高度严格增加或减小的栅栏、或者具有交替高低木板的栅栏。 例如，如果输入是`1 1 1 1`，答案显然是 1，但是粗心的水平优先贪心算法可能会错误地考虑多个笔画。 

## 方法

 蛮力方法很简单：对于每块未涂漆的木板，我们可以垂直涂漆，将其高度降低到零，然后在剩余高度上递归。 虽然正确，但这种方法会导致指数级的复杂性，因为它考虑了所有垂直笔划的序列。 

稍微好一点的方法是贪婪地使用水平笔画：在每一步中，找到未绘制部分中的最小高度，在整个间隔上绘制该高度，然后递归地求解高于该最小值的部分。 这可以被认为是一种分而治之的方法：在间隔上绘制底座，然后处理由高于最小值的木板形成的剩余“子栅栏”。 

关键的见解是，无论是垂直还是水平，每个笔画都算作一次，因此我们需要在每个部分决定是使用垂直笔画单独绘制木板还是使用水平笔画并递归求解是否更便宜。 对于给定的长度段`len`，我们可以将最小笔划计算为以下最小值`len`垂直笔划与`min_height + sum(recursive calls on subsegments)`。 

这种方法之所以有效，是因为递归结构保证了在每一步中，我们要么通过垂直笔划完全减少线段，要么通过水平笔划最佳地减少其高度并仅求解剩余部分。 递归调用的总数是可控的，因为每次调用都会严格减小范围大小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 水平+分而治之| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 从完整的间隔开始`[l, r)`木板数量和初始高度偏移`base`这是先前水平笔画已经绘制的高度。 
2. 如果区间为空（`l >= r`），返回0。 
3. 计算当前区间相对于的最小高度`base`。 这代表我们可以用水平笔画绘制的高度。 
4. 计算要绘制的水平笔划`min_height`。 
5. 扫描该区间并将其分割为连续的木板子段，其高度大于`min_height`。 对于每个子段，递归计算所需的最小笔画，将它们添加到当前水平笔画计数中。 
6. 将这个总数与简单地使用垂直笔画单独绘制每块木板进行比较（`r - l`）并返回较小的数字。 
7. 最初，在整个间隔上调用该函数`[0, n)`和`base = 0`。 

工作原理：在每个递归步骤中，算法要么计算水平笔画并递归地仅求解未绘制的线段，要么计算垂直笔画。 这确保了我们永远不会少算笔划，并且递归除法确保我们始终根据需要准确地处理每个木板。 不变的是在每次调用时，`base`表示已绘制的高度，因此可以准确表示剩余的高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10000)

def min_strokes(a, l, r, base):
    if l >= r:
        return 0
    min_h = min(a[l:r]) - base
    strokes = min_h
    i = l
    while i < r:
        if a[i] - base == min_h:
            i += 1
            continue
        j = i
        while j < r and a[j] - base > min_h:
            j += 1
        strokes += min_strokes(a, i, j, base + min_h)
        i = j
    return min(strokes, r - l)

def main():
    n = int(input())
    a = list(map(int, input().split()))
    print(min_strokes(a, 0, n, 0))

if __name__ == "__main__":
    main()
```这`min_strokes`函数直接实现了递归分而治之的方法。 我们仔细处理空档并正确调整`base`考虑到已经绘制的高度。 通过将范围视为`[l, r)`。

 ## 边缘情况

 都是等高的，比如`1 1 1 1`处理正确：算法计算最小高度 1，应用一个水平笔划，并且找不到未绘制的段。 

单板箱如`1 4`通过比较竖笔画与横笔画，正确选择一种竖笔画来处理。 

具有山谷的间隔，例如`3 2 3`被分成`[0,1)`和`[2,3)`，在底座上方应用递归水平笔画，从而得到最佳的总共 3 笔画。 

这种方法通过维持以下不变式来可靠地处理所有已识别的边缘情况：`base`跟踪已绘制的高度，确保没有木板被低估或高估。
