 ## 解决方案
 ## 问题理解

 我们得到了作用在三维空间中的物体上的几个力矢量。 每个向量具有三个分量：其沿 x 轴、y 轴和 z 轴的影响。 

仅当作用在物体上的各个方向上的总力为零时，物体才处于平衡状态。 这意味着：

 - 所有 x 分量的总和必须为 0
 - 所有 y 分量的总和必须为 0
 - 所有 z 分量的总和必须为 0

 任务只是读取所有向量，独立地添加它们的坐标，并检查所有三个总数是否为零。 如果是，则打印`"YES"`。 否则，打印`"NO"`。 

限制非常小。 最多给出 100 个向量，每个坐标都在 -100 到 100 之间。即使是低效的解决方案也很容易满足限制。 沿一个轴的最大可能绝对和仅为 100 × 100 = 10000，因此普通整数运算是完全安全的。 

主要挑战不是性能，而是将物理条件正确地转换为代码。 一个常见的错误是检查每个向量是否单独相等`(0,0,0)`。 那不是必需的。 非零向量可以相互抵消。 

例如：```
2
1 2 3
-1 -2 -3
```正确的输出是：```
YES
```总力为`(0,0,0)`即使两个向量都不为零。 

另一种微妙的情况是只有一个轴平衡时。```
3
1 0 0
-1 5 0
0 -3 0
```x 轴总和为零，但 y 轴总和为 2。正确的输出是：```
NO
```如果粗心地只检查一个坐标，那么这里的实现将会失败。 

还有最小尺寸的情况：```
1
0 0 0
```正确的输出是：```
YES
```只有一个向量时，只有当该向量本身为零时才会发生平衡。 

## 方法

 最直接的方法就是暴力破解。 我们可以尝试通过检查每个向量并将其坐标添加到运行总和中来计算总力。 处理完所有向量后，我们检查最终的和是否全为零。 

由于输入大小很小，这已经可以有效地工作。 我们对每个向量执行 3 次加法，因此即使在最坏的情况下，我们也只执行大约 300 次算术运算。 

关键的观察是，平衡仅取决于所有力的综合效应，而不取决于它们的顺序或单独的大小。 向量加法是结合和交换的，因此我们在处理向量后不需要存储向量。 我们只需要三个运行总计。 

这将问题减少到维护：```
sum_x
sum_y
sum_z
```当我们读取每个向量时`(x, y, z)`，我们更新这些总数。 最后：

 - 如果所有三个总和都为零，则身体平衡
 - 否则，会残留一些净力，因此身体会移动

 尽管暴力方法和最优方法在这里看起来很相似，但重要的优化是认识到我们只需要恒定的额外内存和单次通过输入。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取整数`n`，力矢量的数量。 
2.初始化三个变量：`sum_x = 0`,`sum_y = 0`， 和`sum_z = 0`。 

这些变量代表沿每个轴累积的总力。 
3. 重复`n`次数：

 - 读取一个向量`(x, y, z)`。 
- 添加`x`到`sum_x`。 
- 添加`y`到`sum_y`。 
- 添加`z`到`sum_z`。 

每个矢量独立地贡献沿每个轴的净力。 
4. 处理完所有向量后，检查所有三个和是否都为零。 

只有当任何方向上都没有剩余力时，物体才处于平衡状态。 
5. 打印`"YES"`如果所有总和为零。 否则打印`"NO"`。 

### 为什么它有效

 该算法保持了处理第一个之后的不变量`i`向量，变量`sum_x`,`sum_y`， 和`sum_z`等于这些贡献的总力`i`沿每个轴的向量。 

矢量加法按分量进行，因此总净力为：$$\left(\sum x_i,\ \sum y_i,\ \sum z_i\right)$$当这个结果向量等于时，物体正好处于平衡状态`(0,0,0)`。 由于算法正确计算这些总和，因此最终检查总是会产生正确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

sum_x = 0
sum_y = 0
sum_z = 0

for _ in range(n):
    x, y, z = map(int, input().split())

    sum_x += x
    sum_y += y
    sum_z += z

if sum_x == 0 and sum_y == 0 and sum_z == 0:
    print("YES")
else:
    print("NO")
```该程序首先读取向量的数量。 初始化三个累加器变量以跟踪沿每个轴的总力。 

在循环内，读取每个向量并立即将其添加到运行总计中。 向量永远不需要存储，因为只有累积和才重要。 

最终条件同时检查所有三个坐标。 这很重要，因为平衡要求整个矢量和为零，而不仅仅是一个坐标。 

整数溢出在 Python 中不是一个问题，但即使在固定宽度语言中，限制也足够小，可以轻松地适应标准整数类型。 

该实现还避免了不必要的数据结构。 使用常量记忆可以使解决方案变得简单并且直接与平衡的数学定义保持一致。

def solve():
    input = sys.stdin.readline

    n = int(input())

    sx = sy = sz = 0

    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
