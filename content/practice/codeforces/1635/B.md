 **标签：** 贪婪
 **求解时间：** 2m 2s

 ## 解决方案
 ## 问题理解

 我们必须修改一个数组，以便没有位置严格大于其两个邻居。 这样的位置称为局部最大值。 第一个和最后一个元素永远不是局部最大值，因为它们只有一个邻居。 

每个操作都允许将一个元素更改为 1 到 1 之间的任何值$10^9$。 目标是最小化修改位置的数量并输出一个有效的结果数组。 

所有测试用例的元素总数最多为$2 \cdot 10^5$。 由于有两秒的限制，线性或接近线性的解决方案是完全安全的。 二次算法大约需要$4 \cdot 10^{10}$在最坏的情况下进行操作，这太过分了。 

有几种情况很容易处理不当。 

考虑连续峰值：```
1 3 1 3 1
```位置 2 和 4 都是局部最大值。 如果我们通过降低每个峰值来独立修复它们，我们将使用两个操作。 更好的解决方案是更改中间元素：```
1 3 3 3 1
```只需要一次操作。 单独处理每个峰值会错过这种优化。 

另一个棘手的情况是被谷分开的三个连续峰：```
2 1 3 1 3 1 3
```将中间谷值更改为足够大的值会立即删除两个相邻的峰值：```
2 1 3 3 3 1 3
```之后，就只剩下最后一个高峰了。 贪婪策略必须认识到这种模式。 

边界位置也需要小心。 在```
5 1 5
```只有中间元素有两个邻居，因此位置 1 和 3 不能是局部最大值，无论它们的值如何。 不小心检查它们会产生错误的结果。 

## 方法

 蛮力视图是检测每个局部最大值并独立修复它。 一种可能性是降低每个峰值，直到它不大于其相邻峰值之一。 这种方法是正确的，因为每次操作都会破坏至少一个峰值。 

当波峰与波谷交替时，就会出现弱点：```
1 3 1 3 1
```分别修复两个峰需要两次修改，即使更改中心元素一次会删除两个峰。 由于每个峰都是独立处理的，因此忽略附近峰之间的相互作用。 

关键的观察是一种模式```
peak - valley - peak
```可以通过一次操作来处理。 如果持仓$i-1$和$i+1$是峰值，位置增加$i$到```
max(a[i-1], a[i+1])
```同时删除两个局部最大值。 

这建议从左到右扫描。 每当两个峰恰好被一个元素分开时，我们就会修改该中间元素并向前跳过。 否则，孤立的峰值将被单独固定。 

由于每个位置仅被检查固定次数，因此整个算法以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 并不总是最优的 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 扫描数组并记录哪些位置是局部最大值。 
2. 从左到右遍历数组。 
3. 每当位置`i`和`i+2`都是局部最大值，修改位置`i+1`。 
4. 设置```
a[i+1] = max(a[i], a[i+2])
```因为这使得中间元素至少与两个峰值一样大，所以两侧都不会保持局部最大值。 

1. 计算一次操作并向前跳三个位置，因为两个峰值均已处理。 
2.如果位置`i`是局部最大值但位置`i+2`不是，将其视为孤立峰。 
3. 更换```
a[i] = max(a[i-1], a[i+1])
```这会立即破坏该局部最大值。 

1. 计数一次操作并继续扫描。 
2. 打印操作次数和最终数组。 

### 为什么它有效

 一次操作可以删除两个峰的唯一方法是这些峰恰好被一个元素分开。 任何较大的距离意味着峰是独立的。 

在从左到右扫描期间，每对相邻峰值被检测一次。 修改中间元素会同时删除这两个元素，这总是比花费两次操作要好。 不属于此类峰对的峰无法与另一个峰共享操作，因此单独修复它们是最佳选择。 因此，操作总数是最少的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
ans = []

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    peak = [False] * n
    for i in range(1, n - 1):
        if a[i] > a[i - 1] and a[i] > a[i + 1]:
            peak[i] = True

    cnt = 0
    i = 1

    while i < n - 1:
        if peak[i]:
            if i + 2 < n and peak[i + 2]:
                a[i + 1] = max(a[i], a[i + 2])
                cnt += 1
                i += 3
            else:
                a[i] = max(a[i - 1], a[i + 1])
                cnt += 1
                i += 1
        else:
            i += 1

    ans.append(str(cnt))
    ans.append(" ".join(map(str, a)))

sys.stdout.write("\n".join(ans))
```第一个循环识别原始数组中的所有局部最大值。 该信息在扫描期间保持固定。 每次修改后重新计算峰值会使实施变得复杂，并且没有必要。 

主循环从左到右处理峰值。 当两个峰相距两个位置时，对中间元素的一项修改会删除这两个峰。 随后该指数上涨了三位，因为这些峰值已经结束。 

对于孤立的峰值，用较大的相邻峰值替换峰值会破坏该峰值，而不会创建新的峰值。 使用最大邻居值就足够了，因为相等不算作局部最大值。 

永远不会检查边界位置，因为循环从索引 1 开始并在索引之前停止`n-1`。

 ## 边缘情况

 考虑```
1 3 1 3 1
```初始峰值位于位置 2 和 4。算法注意到它们被一个元素分开并更改了中心值：```
1 3 3 3 1
```仅使用一种操作。 独立修复每个峰值的策略将花费两次操作。 

考虑```
2 1 3 1 3 1 3
```位置 3 和 5 处的第一对峰共享一个中间元素，因此一个操作将同时删除这两个元素：```
2 1 3 3 3 1 3
```位置 7 处的剩余峰被隔离并单独固定。 两种操作是最佳的。 

考虑```
5 1 5
```两个端点都不能是局部最大值。 该循环仅检查中心位置，该位置小于两个邻居，因此不执行任何操作并且数组保持不变。 这避免了边界处的一个错误。
