 ## 解决方案
 ## 问题理解

 我们有两个整数，但它们不是以十进制形式书写，而是通过质因数分解来描述。 一个号码，拨打即可$X$，完全由素数及其指数列表确定。 另一个号码$Y$以同样的方式描述。 

任务是计算有多少个有序对$(p, q)$的正整数存在使得最小公倍数$p$和$q$等于$X$，以及最大公约数$p$和$q$等于$Y$。 答案必须以模计算$998244353$。 

考虑约束的一个有用方法是，这两个数字都可以非常大，最多可达约$2 \times 10^6$在素数和大指数中。 不同素数的数量最多为$10^5$，因此任何解决方案都必须独立处理每个素数，并在因子列表上以基本上线性的时间工作。 素数或指数数量的任何二次方在一秒钟内都是不可能的。 

从 gcd 和 lcm 的定义中立即出现了一个关键的结构要求。 如果质数出现在$Y$，它也必须出现在$X$，因为 gcd 不能包含两个数字中都不存在的素数，并且 lcm 必须已经包含两个数字中的所有素数。 如果此条件对于任何素数不成立，则答案必定为零。 忽略此一致性检查的粗心解决方案将在以下情况下产生错误的肯定答案：$X = 2^1 \cdot 5^1$,$Y = 3^1$，其中不可能存在对。 

另一个微妙的问题是素数不存在于$Y$但存在于$X$仍然贡献选择。 许多不正确的解决方案要么忘记处理这些素数，要么用 gcd 素数对称地对待它们，这会破坏正确性。 

最后，顺序很重要：成对$(p,q)$是有序的，因此交换它们会产生不同的有效解决方案，除非$p = q$。 

## 方法

 暴力方法将尝试构造所有对$(p,q)$使它们的 gcd 和 lcm 与所需值匹配。 人们可以尝试枚举两个数字中每个素数的所有可能的指数分配。 对于给定的素数，如果它的指数为$X$是$a$，然后指数$p$和$q$必须位于 gcd 和 lcm 约束规定的某些界限之间。 然而，即使对于单个素数，枚举所有有效的指数对也可以，但是在最多$10^5$素数仍然需要仔细计数而不是显式生成。 

关键的观察结果是 gcd 和 lcm 约束在素数上完全解耦。 对于每个素数$x$，假设它的指数为$X$是$a$并在$Y$是$b$。 如果$b > a$，没有解，因为在任何质数指数中 gcd 都不能超过 lcm。 

现在修复一个素数。 让该素数的指数$p$是$i$，并在$q$是$j$。 然后 gcd 条件强制$\min(i,j) = b$，以及 lcm 条件力$\max(i,j) = a$。 这立即意味着两者$i$和$j$必须位于集合中$\{b, a\}$，但每个端点至少有一个等于。 这为每个有序对分配提供了两种可能性：$i=b, j=a$或者$i=a, j=b$，但前提是$a \ne b$。 如果$a = b$，那么两者必须相等，只给出一个选择。 

对于未出现在的素数$Y$，我们有$b = 0$。 在那种情况下，$\min(i,j)=0$至少强制其中之一$i,j$为零，同时$\max(i,j)=a$迫使对方完全一样$a$。 同样，对于每个这样的素数，我们正好得到两个有序配置，只要$a > 0$。 

整个问题简化为将独立贡献乘以所有素数$X$，但前提是所有素数都在$Y$包含在$X$。 如果素数存在于$Y$但不在$X$，答案立即为零。 

因此，每个素数有 1 种或 2 种贡献，具体取决于它的指数是否在$X$等于$Y$。

 ## 算法演练

 我们将两个素因子列表处理为两个映射之间的比较问题。 

1. 将每个素数的指数存储在$X$在哈希映射或字典中。 

这允许在检查素数时进行恒定时间查找$Y$。 
2. 将答案初始化为1。 

我们将乘以每个质数的独立贡献。 
3. 迭代每个素数$C_j$在$Y$。 

对于每一个，检查它是否存在于$X$。 如果它不存在，则 gcd 无法包含 lcm 中不存在的素数，因此答案变为 0，我们可以停止。 
4. 代入该素数的指数$X$是$a$，并在$Y$是$b$。 

如果$b > a$，我们再次立即得出不可能性的结论，因为在任何素数分量中 gcd 都不能超过 lcm。 
5. 如果$a = b$，这个素数正好贡献 1 种方式。 

两个都$p$和$q$必须包含具有相同指数的素数，因此不存在自由。 
6. 如果$a > b$，这个素数正好有两种贡献。 

一个数取指数$a$另一个取指数$b$，并且由于该对是有序的，因此两个分配都是有效的。 
7. 将贡献乘以答案模$998244353$。 

处理完所有素数后$Y$, 中的所有素数$X$那些不在$Y$隐式地表现为$b=0$，如果我们扩展相同的推理，它们已经被考虑在内：每个这样的素数也恰好有两种贡献。 然而，如果我们仔细构建计算，我们不需要单独迭代它们：我们跟踪中有多少素数$X$匹配$Y$，以及有多少不同。 

一个干净的实现直接迭代所有素数$X$，检查存在于$Y$，并相应地乘以贡献。 

### 为什么它有效

 对于每个素数，约束$\gcd(p,q)$和$\text{lcm}(p,q)$对其指数施加独立条件$p$和$q$。 由于 gcd 和 lcm 是针对每个素数独立计算的，因此对一个素数的选择不会影响另一个素数。 这创建了一个基于质数的产品结构。 每个素数贡献固定数量的有效指数分配，对的总数是这些贡献的乘积。 正确性源于素因数分解的唯一性和指数约束的独立性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))
    
    x_exp = {}
    for p, e in zip(A, B):
        x_exp[p] = e

    m = int(input())
    C = list(map(int, input().split()))
    D = list(map(int, input().split()))
    
    y_exp = {}
    for p, e in zip(C, D):
        y_exp[p] = e

    # consistency check: all primes in Y must exist in X
    for p, e in y_exp.items():
        if p not in x_exp or e > x_exp[p]:
            print(0)
            return

    ans = 1

    # process primes in X (covers both shared and extra primes)
    for p, a in x_exp.items():
        b = y_exp.get(p, 0)

        if a == b:
            ans = (ans * 1) % MOD
        else:
            ans = (ans * 2) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该实现构建了两个将素数映射到指数的字典。 第一个循环强制可行性：中的每个素数$Y$必须出现在$X$至少有同样大的指数。 第二个循环计算每个素数的乘法贡献$X$。 中缺少素数$Y$被视为指数零，这可以正确模拟 gcd 约束。 

一个常见的陷阱是仅迭代素数$Y$。 这低估了素数的贡献$X$但缺席于$Y$，其中每个仍提供因子 2。

 ## 边缘情况

 第一个边缘情况是当$Y$包含不存在于的素数$X$。 在这种情况下，gcd 需要 lcm 没有的素因数，这是不可能的。 该算法在任何乘法发生之前立即在可行性循环中捕获这一点。 

另一个边缘情况是当$X = Y$。 每个质数指数都完全匹配，因此在分配指数时没有灵活性$p$和$q$。 每个素数只贡献一种配置，最终答案是 1。算法自然地处理这个问题，因为没有素数触发加倍规则。 

当出现第三种边缘情况时$Y = 1$。 这里所有素数$X$实际上是免费的，并且每个贡献两个赋值，对应于在之间分配完整的指数$p$和$q$。 该算法简化为对每个素数乘以 2$X$，生产$2^{|X|}$，这是正确的。 

最后一种情况是当$X$有一个素数。 该算法简化为简单的二元选择，具体取决于该素数是否出现在$Y$具有相同的指数或零，确认最小的非平凡结构的正确性。
