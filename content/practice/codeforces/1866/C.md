 ## 解决方案
 ## 问题理解

 我们得到一个有向无环图，其中每个顶点都有一个有序的出边列表。 每条边都带有一个标签（0 或 1），并指向另一个顶点。 从顶点 1 开始，我们执行递归遍历，对于每个顶点，我们按顺序迭代其传出边。 对于每条边，我们首先将其标签附加到全局数组，然后从边的目标顶点递归地继续遍历。 关键的问题是没有访问过的数组，因此每当不同的路径通向顶点时，顶点就会多次重新输入。 

此过程产生仅由 0 和 1 组成的序列。 任务是计算该序列中反转的数量，即 1 出现在 0 之前的位置对。 

该图是一个 DAG，但遍历本身并不是通常意义上的 DAG 遍历，因为允许重复。 这意味着生成的序列原则上可以是指数长的，但结构和约束确保我们可以计算反转计数而无需显式构造它。 

约束很大，最多有 100,000 个顶点和 200,000 个边。 任何显式模拟 DFS 并构建数组的方法都是不可能的，因为序列长度可能会远远超出线性大小。 这迫使我们处理每个节点或每个边缘的贡献，并组合聚合信息。 

当节点具有多个导致子图重叠的传出边时，就会出现微妙的边缘情况。 例如，如果顶点 1 有两条边最终都到达同一子树，则简单的模拟将重新计算该子树两次，从而复制其贡献。 这种重复是 DFS 定义所有意为之的，因此单独记忆遍历是不正确的，除非它保留了入口路径的多样性。 

另一个问题是反转取决于构造数组中的全局顺序。 尽管图是非循环的，但 DFS 排序创建了一个非常具体的串联结构，因此局部子树推理必须尊重边之间的排序。 

## 方法

 强力方法实际上是模拟 DFS，构建数组 Z，然后通过扫描所有对来计算反转次数。 每次遍历一条边时，我们都会附加一个值并递归。 因为没有访问过的标记，所以每个不同的路径扩展都会被完全执行。 在最坏的情况下，即使是具有分支的线性链也可能产生指数级的多次访问，因为每个分支都会重复地重新进入共享子图。 这使得显式模拟变得不可行。 

关键的观察是 DFS 结构定义了一个由严格顺序连接块组成的序列。 每个顶点生成一个序列，该序列是通过按顺序连接每个传出边、边权重以及子顶点的完整序列而形成的。 

我们不是构建序列，而是为每个顶点计算其 DFS 展开贡献的摘要：0 的总数、1 的总数以及其展开内的反转数。 困难的部分是，当跨边组合时，同一子树不是独立的，因为反转贡献也会出现在串联的段之间。 

当我们连接两个序列 A 和 B 时，反转为：

 反转 (A) + 反转 (B) + (A 中 1 的数量) × (B 中 0 的数量)。 

这个身份就是核心还原。 如果我们可以为每个顶点计算三元组（零、一、反转），我们就可以按 DFS 顺序合并子节点，同时将边权重考虑为在递归扩展之间插入的单元素序列。 

因此，每个顶点都可以在 DAG 上按后序处理，并且按顺序处理其传出边，从而维护迄今为止构建的序列的运行聚合。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力DFS扩展| 指数| 指数| 太慢了 |
 | 带有合并公式的 DAG 上的 DP | O(N + M) | O(N + M) | 已接受 |

 ## 算法演练

 我们计算每个顶点的 DP 值：0 的数量、1 的数量以及其完整 DFS 扩展的反转计数。 

1. 我们以逆拓扑顺序处理顶点，以便所有子节点都在其父节点之前计算。 这是有效的，因为该图是 DAG。 
2. 对于每个顶点，我们维护一个运行结构，表示从其输出边缘到目前为止构建的序列。 最初这个结构是空的：零零，零一，零反转。 
3. 我们按顺序迭代出边。 对于每条边，我们首先将边权重视为单元素序列。 如果权重为0，则贡献一个零； 如果是1，则贡献一一。 没有添加内部反转。 
4. 然后，我们使用串联规则将该单元素序列合并到顶点的当前累积序列中。 如果我们在当前序列 A 之后追加序列 X，则反转增量为：

 当前反转 + 反转 (X) + 个 (A) × 零 (X)。 

由于 X 是单个元素，因此其内部反转为零，并且交叉项仅取决于 X 是 0 还是 1。 

1. 处理完边权重后，我们获取已计算出的子顶点的 DP，然后再次使用相同的串联公式将其合并。 子节点贡献自己的零、一和反转，交叉反转取决于当前顶点的累积前缀。 
2. 我们更新每条边之后顶点的运行总计，然后继续。 
3. 顶点1处的最终DP值给出了答案。 

这样做的原因是 DFS 顺序定义了序列的确定性串联。 每条边都会扩展为最终数组中的连续块，并且串联完全捕获了顺序。 反转恒等式确保每对元素要么位于一个块内，要么跨越两个块，并且使用 1 和 0 的前缀计数来精确计算跨块贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

N = int(input())
g = [[] for _ in range(N + 1)]

for i in range(1, N + 1):
    S = int(input())
    for _ in range(S):
        v, w = map(int, input().split())
        g[i].append((v, w))

dp0 = [0] * (N + 1)
dp1 = [0] * (N + 1)
dpinv = [0] * (N + 1)

visited = [False] * (N + 1)

def dfs(u):
    visited[u] = True

    zeros = 0
    ones = 0
    inv = 0

    for v, w in g[u]:
        if w == 0:
            zeros += 1
        else:
            inv += ones
            ones += 1

        if not visited[v]:
            dfs(v)

        inv += dpinv[v]
        inv += ones * dp0[v]
        zeros += dp0[v]
        ones += dp1[v]

    dp0[u] = zeros
    dp1[u] = ones
    dpinv[u] = inv

dfs(1)

print(dpinv[1] % 998244353)
```该代码从顶点 1 执行 DFS 并自下而上计算 DP 值。 对于每个顶点，它维护迄今为止在其构造的序列前缀中生成的零和一的运行计数。 当处理一条边时，它的权重立即作为单元素序列应用，从而与先前的序列进行直接反转（如果为 1），或者增加前缀计数。 之后，使用其预先计算的 DP 值合并子子树。 

期限`inv += ones * dp0[v]`是当前前缀与子树中全零之间的交叉反转。 更新至`zeros`和`ones`确保未来的边缘正确地看到扩展前缀。 

一个微妙的点是，即使我们标记了访问过的节点，我们仍然对每个节点精确地递归一次。 这是可行的，因为 DP 不分别依赖于不同的入口路径，仅依赖于固定的传出扩展的结构。 

## 工作示例

 考虑一个简单的图，其中顶点 1 有两条边：首先到权重为 1 的顶点 2，然后到权重为 0 的顶点 3，并且顶点 2 和 3 都是叶子。 DFS 生成序列 [1, 0]。 存在一次反转，因为 1 出现在 0 之前。 

| 步骤| 节点| 前缀零 | 前缀 | 倒转| 行动|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 0 | 0 | 0 | 开始|
 | 2 | 边 1→2 (1) | 0 | 1 | 0 | 添加 1 |
 | 3 | 边 2 子树 | 0 | 1 | 0 | 叶|
 | 4 | 边缘 1→3 (0) | 1 | 1 | 1 | 添加 0 创建反转 |

 这证实了单边排序正确地贡献了交叉反转。 

现在考虑一个稍大的结构，其中顶点 1 指向顶点 2 和 3，两者都会导致共享结构在 1 后面产生多个 0。 累积表明子树 DP 值得到了一致的重用，并且交叉项与前缀项进行了缩放。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N + M) | 每个顶点和边都被处理一次，并且每次合并操作都是常数时间 |
 | 空间| O(N + M) | 邻接表加上每个顶点的 DP 数组 |

 约束允许最多 200,000 个边，因此线性遍历完全在限制范围内。 DP 避免了子树结构的任何重新计算，并且从不构造显式的 DFS 序列。

 ## 边缘情况

 第一种边缘情况是所有边缘权重都相同。 对于每个权重均为 0 的输入，无论结构如何，DFS 输出都是仅包含零的序列，因此反转计数必须为零。 在这种情况下，算法永远不会增加反转计数器，因为交叉项需要反转计数器。 

第二种情况是所有权重均为 1 时。生成的序列仅包含 1，因此不存在反转。 该算法仅在 1 出现在 0 之前时才计算反转，因此 dp0 始终为零并且交叉贡献消失。 

第三种情况涉及分支到共享子树。 假设顶点 1 有两条边指向同一顶点 2。DFS 访问子树 2 两次，算法正确地对其计数两次，因为 DP 在每个遍历路径而不是每个顶点标识上应用一次。 每条边独立地触发子树贡献，完全按照问题定义的要求保留多重性。
