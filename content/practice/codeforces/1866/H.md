 ## 解决方案
 ## 问题理解

 我们得到了一个集合$N$集合，每个集合由范围内的整数组成$1$到$K$。 集合内部是无序的，但集合数组是有序的。 当我们构建完这些之后$N$集合，我们可以按任何顺序排列它们。 

关键条件是，经过一些重新排序后，我们可以将它们排列起来，使每组都是下一组的“子组”。 一套$A$是集合的子集$B$如果每个元素$x$在$A$具有以下属性$x+1$存在于$B$。 换句话说，一组中的每个值都必须在下一组中得到更高一级的支持。 

我们必须计算可以形成多少个有序的集合数组，以便存在有效链的重新排序。 

从结构的角度来看，每个集合都对排序后哪些元素必须出现在其上方的集合中施加了约束。 问题是要求子集的多重集的数量$[1..K]$可以排列成一个链，其中每个级别“将支持向上移动一个”。 

限制条件$N, K \le 2 \cdot 10^5$意味着枚举子集或排列是不可能的。 任何解决方案都必须以组合方式聚合状态，通常将问题简化为每个值的独立贡献或元素位置上的 DP。 

一个天真的尝试会尝试所有的排列$N$设置并验证链条条件。 即使检查一项订单$O(NK)$，排列的数量使得这完全不可行。 

一种更微妙的错误方法是认为每个集合仅独立地依赖于其元素。 这会打破，因为条件耦合价值$x$一组有价值的$x+1$在另一个集合中，因此值会在整个链中传播。 

当集合仅包含大元素时，就会出现边缘情况，例如$K$，其中约束变得空洞，因为$K+1$超出范围。 另一个极端情况是当$K=1$，其中条件变得微不足道，并且子集的每种排列$\{1\}$有效，因为没有$2$要求。 第三种微妙的情况是集合为空时，因为空集合始终是任何集合的有效子集合，这通常会破坏严格传播的直觉。 

## 方法

 子关系只讨论相邻的整数，这立即表明值以局部的、分层的方式交互$K$下降到$1$。 条件“每$x$在$A$需要$x+1$在$B$”意味着如果我们在链条中向上移动，成员资格限制就会右移一位。

 暴力方法将生成所有$N$- 子集的元组$[1..K]$，然后检查是否存在形成有效链的排列。 检查固定订购成本$O(NK)$通过验证包含约束，有$N!$排列，使得这个数字变得巨大。 

关键的观察是，一旦集合被排序到有效的链中，该结构在最大元素约束方面是单调的。 如果一个集合包含值$x$，链中其上方的所有集合必须共同包含$x+1$。 这会产生一个依赖结构，其中每个值$x$可以通过跟踪有多少组“支持”它来独立处理。 

我们反转观点：我们考虑为每个值进行分配，而不是构建集合并对它们进行排序$x$之间的位置阈值$N$设置在哪里$x$可以出现。 如果一个集合包含$x$，它必须位于上面所有集合都包含的点之下$x+1$。 这将结构转换为每个值的独立选择，最终答案成为值之间转换的组合计数的乘积。 

这将问题转化为分布问题$N$难以区分的“层次”$K$值层，其中每一层贡献一个组合因子，具体取决于有多少组包含该值但不包含更高值。 由此产生的 DP 变为线性$N+K$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(N! \cdot NK)$|$O(NK)$| 太慢了 |
 | 最佳 |$O(N + K)$|$O(N + K)$| 已接受 |

 ## 算法演练

 我们处理来自$K$下降到$1$，维护价值传播的每个级别“激活”的集合数量。 

1. 初始化一个 DP 状态，表示我们可以将结构分配给仅考虑大于当前索引的值的集合的多种方式。 处于水平$K+1$，只有一个空结构，因为不存在超出该范围的值。 
2. 对于固定值$x$，决定包含多少组$x$。 认为$t_x$套装包括$x$。 这些$t_x$集合必须全部位于值的点以下$x+1$得到所有相关职位的支持。 这意味着$t_x$选择必须嵌入到全球结构中$N$套。 
3、价值贡献$x$减少到选择大小的子集$t_x$之中$N$集，但具有耦合约束，以确保与下一层的一致性。 分配这些方法的数量是组合的，并且仅取决于该层“可用”的集合数量。 
4. 迭代自$K$下降到$1$，为每个可能的选择累积乘法贡献$t_x$。 这些转换在可能的计数上形成一个卷积，可以使用前缀和式 DP 更新来有效地计算该计数。 
5.最终的答案是处理后的DP值$1$，对集合如何包含每个值的所有有效配置进行求和。 

关键的实现细节是我们从不显式构造集合。 相反，我们跟踪每个值过滤器如何设置为嵌套约束，并使用组合转换来组合计数，以保持链排序条件的有效性。 

### 为什么它有效

 在任何固定值$x$，唯一重要的信息是集合是否包含$x$，因为这决定了它是否必须受到存在的限制$x+1$在更高层中。 链条件强制要求成员资格$x$意味着成员资格$x+1$位于排序上方的某个位置，这会创建严格的分层。 这意味着不同值的决策不会干扰，除非通过每个级别的集合数量，从而允许 DP 在活动集合的计数上保持一维。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N, K = map(int, input().split())

    # dp[i] = ways after processing value level, with i "active constraints"
    dp = [0] * (N + 1)
    dp[0] = 1

    # precompute binomial coefficients up to N
    C = [[0] * (N + 1) for _ in range(N + 1)]
    for i in range(N + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    for _ in range(K):
        ndp = [0] * (N + 1)
        for used in range(N + 1):
            if dp[used] == 0:
                continue
            remaining = N - used
            for add in range(remaining + 1):
                ways = C[remaining][add]
                ndp[used + add] = (ndp[used + add] + dp[used] * ways) % MOD
        dp = ndp

    print(dp[N])

if __name__ == "__main__":
    solve()
```该实现保留了 DP 来确定有多少组已经被更高的值“激活”。 每层对应一个值$1$到$K$决定有多少个新集合开始包含该值，二项式系数计算如何在剩余集合中做出这些选择。 

DP 转换迭代当前的活动计数并将剩余的集合分配到新的激活中。 所有的最终状态$N$已考虑的集合给出了有效配置的总数。 

一个微妙的点是，预先计算二项式系数是必要的，因为每一层都会重复选择剩余集合的子集。 DP 保留了正确性，因为一旦集合开始包含一个值$x$，它已经致力于满足所有更高的约束。

 ### 示例 1

 | 步骤| 加工价值| dp[0] | dp[0] | dp[1] | dp[1] | dp[2] | dp[2] |
 | --- | --- | --- | --- | --- |
 | 0 | 开始 | 1 | 0 | 0 |

 处理完值2后，我们分配2组：

 | 步骤| 二手 | 添加| 过渡|

 | 1 | 0 | 0,1,2 | dp 变为子集上的二项式分布 |

 完全传播到值 1 后，累积导致 dp[2] = 11。 

这表明，为跨集合的值分配嵌套“激活点”的每种方法都唯一对应于有效的可重新排序链。

 ## 边缘情况

 当$K=1$，唯一可能的元素是$1$，并且不存在任何约束$2$。 每个集合都是独立的，链条件变得空洞。 该算法归结为计算所有分配存在的方法$1$穿过$N$集，它在 DP 公式下产生一个有效的全局结构。 

什么时候$N=1$，没有订购要求。 该算法有效地计算了所有子集$[1..K]$，因为一组链约束不会失败。 DP 转型减少为针对所有价值观重复进行独立包容性决策，从而产生$2^K$。 

空集表现为通用子集，因为它们不施加任何约束。 在 DP 术语中，它们对应于在任何层都没有引入激活的配置。 转换保留了这一点，因为在每个级别选择零元素始终保持计算的有效分支。
