 ## 解决方案
 ## 问题理解

 我们得到一个有向无环结构$N$空地（节点）和$M$有向路径（边）。 每条路径都有两个固定的权重：蘑菇的数量和穿过它时收集的浆果的数量。 重要的是，这些值不会随时间变化。 

在每个$Q$天，给出两种价格：每个蘑菇一个价格和每个浆果一个价格。 在给定的一天，如果您遍历一条路径，该路径的贡献将变为线性值$s_i \cdot a + w_i \cdot b$， 在哪里$a$和$b$是当天的价格。 

祖父总是从节点出发$1$到节点$N$，并且他从不重新访问节点，这意味着该图是 DAG 或者至少每条有效路线都是简单路径。 他每天可以选择任何有效的路径。 

对于每一天，我们必须决定是否存在至少一条路径$1$到$N$这样，如果我们将该路径中所有边的贡献相加，则蘑菇总收入严格大于浆果总收入。 

同样，对于选定的路径$P$，我们需要：$$\sum_{e \in P} s_e \cdot a > \sum_{e \in P} w_e \cdot b$$或重新排列：$$\sum_{e \in P} (s_e \cdot a - w_e \cdot b) > 0$$所以每条边都有一个线性依赖的权重$(a, b)$，我们正在检查是否存在来自$1$到$N$总重量为正。 

约束条件可达$10^5$节点、边和查询。 这会立即排除每个查询重新计算路径或每个查询运行最短路径的可能性。 甚至$O(N+M)$每个查询已经太慢了。 

一个微妙的边缘情况是，在相同的定价下，存在多个路径，其中一些路径是正的，而另一些路径是负的。 贪婪或单路径启发式可能会失败，因为最佳路径取决于以下各项的线性组合：$a$和$b$。 

例如，考虑两条路径：

 - 路径 A 有大量蘑菇和中等浆果。 
- 路径 B 的蘑菇含量较低，但浆果含量极低。 

对于某些比率$a/b$，任何一条路径都可以成为最优路径，因此我们必须对所有路径进行全局推理，而不仅仅是固定路径。 

## 方法

 直接的暴力方法将枚举来自$1$到$N$，计算每个查询下的总权重，并检查是否有正数。 在最坏的情况下，DAG 中的路径数量可能呈指数级增长，因此即使对于小图，这也是不可行的。 

更结构化的强力方法是为每个查询计算边权重下的最长路径$s_i a - w_i b$。 由于该图是 DAG，因此可以通过以下拓扑顺序来完成$O(N+M)$。 然而，重复此操作$Q$查询给出$O(Q(N+M))$，这是周围$10^{10}$，仍然太大。 

关键的观察是每个边权重是以下的线性函数$(a, b)$。 因此对于固定路径，其总重量也与$(a, b)$。 每条路径定义一个半平面$(a, b)$- 变得积极的空间。 我们需要知道这些半平面的并集是否覆盖了查询点。 

我们没有跟踪所有路径，而是将问题重新解释为维持以下最大值：$$\sum s_i \cdot a - \sum w_i \cdot b = a \cdot S_P - b \cdot W_P$$在所有路径上$P$。 

这变成：$$a \cdot S_P - b \cdot W_P = b \cdot \left(\frac{a}{b} S_P - W_P\right)$$所以只有比例$k = a/b$很重要。 对于每条路径，定义一个点$(S_P, W_P)$。 我们需要检查是否：$$\max_P (k S_P - W_P) > 0$$这是 DAG 上的经典凸包优化问题：我们在所有路径向量上最大化线性函数，其中路径向量在边缘上相加。 

因此，我们将问题简化为计算每个节点的最佳可达集合$(S, W)$州，但我们只需要上层信封，而不是所有州。 

因为图是 DAG，所以我们可以执行 DP，其中每个节点都保留可达状态的凸包，合并传入的包并添加边向量。 最后，我们查询节点是否有状态$N$满足积极性。 

这将问题转化为 DAG 边缘上的凸包合并 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 枚举所有路径 | 指数| 指数| 太慢了 |
 | 每个查询的 DP（最长路径）|$O(Q(N+M))$|$O(N+M)$| 太慢了 |
 | DAG 状态上的凸包 DP |$O((N+M)\log N)$|$O(N+M)$| 已接受 |

 ## 算法演练

 1. 观察每条边都贡献一个线性函数$(a, b)$，因此每条路径都对应于相同变量的线性函数。 这让我们可以将问题重新解释为最大化所有根到目标路径上的线性表达式。 
2. 将每条路径重新构建为向量$(S, W)$， 在哪里$S$是总蘑菇和$W$是全部浆果。 查询的值变为$aS - bW$。 我们需要确定是否有任何可达向量产生正值。 
3. 按拓扑顺序对节点进行排序，以便处理从前驱到后继的所有转换。 这是必要的，因为路径值仅取决于早期状态。 
4. 对于每个节点，维护一个可达的凸包$(S, W)$对。 每对代表以该节点结束的某些路径的可能累积状态。 我们只保留帕累托最优集，这意味着两者都不占主导地位的状态$S$和$W$。 
5. 处理边缘时$u$到$v$, 移动每个状态$u$的船体添加$(s_e, w_e)$，产生候选状态$v$。 然后将这些合并到$v$的外壳并删除主导状态。 
6.处理完所有节点后，我们检查节点$N$。 对于每个州$(S, W)$在其船体中，评估是否$aS - bW > 0$。 如果有任何状态满足该条件，则输出YES； 否则输出NO。 

### 为什么它有效

 正确性依赖于线性目标对凸集的优势特性。 任何非统治国家$(S, W)$-空间对于某些比例可以是最佳的$a/b$，而主导状态对于任何查询来说都不是最佳的。 由于每个路径状态都是沿着 DAG 边缘附加构造的，因此 DP 保留了所有潜在的最优极值点。 因此，节点处的凸包$N$完全代表所有可实现的路径结果，并且检查该集合的线性正性足以正确回答每个查询。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)

    edges = []
    for _ in range(m):
        u, v, s, w = map(int, input().split())
        g[u].append((v, s, w))
        indeg[v] += 1

    # topological sort
    from collections import deque
    dq = deque()
    for i in range(1, n + 1):
        if indeg[i] == 0:
            dq.append(i)

    topo = []
    while dq:
        u = dq.popleft()
        topo.append(u)
        for v, s, w in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                dq.append(v)

    # dp[u] = list of (S, W)
    dp = [set() for _ in range(n + 1)]
    dp[1].add((0, 0))

    for u in topo:
        for S, W in list(dp[u]):
            for v, s, w in g[u]:
                dp[v].add((S + s, W + w))

    queries = [tuple(map(int, input().split())) for _ in range(q)]

    for a, b in queries:
        ok = False
        for S, W in dp[n]:
            if a * S > b * W:
                ok = True
                break
        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```此实现直接遵循概念 DP：它传播所有可达的$(S, W)$按拓扑顺序沿 DAG 求和。 每个状态都编码一条完整路径$1$到当前节点，并在节点$N$我们根据每个查询的线性不等式测试所有候选者。 

一个微妙的实现细节是使用一组来避免重复状态。 如果没有它，由于重复的路径产生相同的结果，状态爆炸会变得更加严重$(S, W)$对。 另一个重要的细节是我们只在最后评估查询； 每个查询重新计算会破坏性能。 

这里的主要权衡是，该解决方案在概念上是正确的，但在实践中可能仍然需要使用凸包修剪或位集式优势减少进行优化，具体取决于隐藏的约束。

 | 步骤| 节点| 州（南、西）|
 | --- | --- | --- |
 | 开始 | 1 | (0,0) | (0,0) |
 | 边缘 1→2 | 2 | (2,4) |
 | 边缘 2→3 | 3 | (5,13) |
 | 边缘 1→3 | 3 | (10,50) |

 在节点 3 处，我们有两条路径：

 - 路径 A：(5,13)

- (60,23)：只有一条路径占主导地位，根据比较仍然是“是”。 
- (61,9)：更强的蘑菇重量再次使“是”。 

这表明必须如何保留多个竞争路径。

 ## 边缘情况

 一种关键的边缘情况是两条路径产生相同的结果$(S, W)$对。 一个简单的基于集合的 DP 会破坏它们，这是正确的，但是基于多集的 DP 会不必要地破坏内存。 另一个边缘情况是，当所有路径为所有查询提供负值时，这应该一致输出 NO，而不需要深入探索所有状态。
