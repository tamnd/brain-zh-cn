 ## 解决方案
 ## 问题理解

 有一排城市，每个城市都包含已知数量的景点。 每个城市都安装了望远镜。 每个望远镜都有一个非负整数倍。 如果城市里有望远镜$i$有权力$p$，那么使用它的游客可以观察所有指数在距离内的城市$p$从$i$，形成一个以$i$，剪在该国的边界。 

对于任何固定的城市，通过望远镜观察产生的可见景点总数等于望远镜可见部分内所有城市的景点总数。 要求是该总数不得超过全局限制$R$。 每个城市都有自己的望远镜，我们希望为每个望远镜分配最大可能的功率，以便其中心城市仍然满足这一约束。 如果甚至零功率已经违反了某些城市的限制，则配置是不可能的。 

关键点是每个城市都是独立检查的，但约束取决于该城市周围的范围总和。 所以对于每个位置$i$，我们实际上正在寻找最大半径$p_i$使得周围对称线段的总和$i$不超过$R$。 

这些约束迫使$O(N \log N)$或者$O(N)$解决方案。 和$N \le 10^5$，任何区间的二次展开都会太慢。 由于吸引力总额可达$10^{14}$，我们还需要 64 位算术来计算前缀和。 

一些边缘情况很重要。 

如果一个城市已经有$s_i > R$，那么即使半径为零也会失败，所以该城市的答案是立即$-1$。 例如，如果$R = 3$和$s = [1, 10, 1]$，则中间城市不能被分配任何有效的望远镜功率。 

另一个微妙的情况是当半径快速扩展超过阵列的边界时。 正确的解释是间隔只是在末端进行剪辑，并且这必须在范围和计算中自然处理。 

最后，由于每个城市都是独立的，因此尝试耦合城市之间的半径将是一个错误。 该约束不会跨望远镜相互作用。 

## 方法

 最简单的想法就是独立对待每个城市。 对于固定中心$i$，我们尝试每一个可能的半径$p$，计算中的吸引力总和$[i-p, i+p]$，并检查它是否保持在$R$。 这是有效的，因为条件纯粹是该区间的局部条件。 

然而，这种蛮力方法太慢了。 在最坏的情况下，每个城市可能允许的半径可达$O(N)$，并且天真地重新计算每个半径的范围总和会导致$O(N)$每个城市的工作，或$O(N^2)$总操作。 和$10^5$城市，这已经远远超出了时间限制。 

关键的观察是可以使用前缀和在恒定时间内查询范围和。 一旦前缀和可用，检查固定半径就变成了$O(1)$。 这将问题转化为单调搜索：随着半径的增加，间隔之和永远不会减少，因此我们可以二分搜索每个城市的最大有效半径。 

这种单调性正是解决方案的关键所在。 我们不是扫描所有半径，而是搜索区间和首先超过的边界$R$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个城市的暴力扩张 |$O(N^2)$|$O(N)$| 太慢了 |
 | 每个城市的前缀和+二分搜索 |$O(N \log N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们对吸引力数组的前缀和进行预处理，以便可以在恒定时间内计算任何段的和。 

对于每个城市$i$，然后我们搜索最大半径$p_i$使得区间内景点的总和$[i-p_i, i+p_i]$不超过$R$。 如果即使$p_i = 0$失败，我们输出$-1$。 

1. 在景点上构建一个前缀和数组。 这允许在恒定时间内快速计算任何间隔总和。 
2. 对于每个城市$i$，首先检查单个城市是否已经违反约束。 如果$s_i > R$，我们立即分配$-1$。 这是必要的，因为任何扩展都无法修复局部违规。 
3. 否则，对可能的半径执行二分搜索$0$到$N$。 上限$N$是安全的，因为间隔不能超过整个数组。 
4. 对于候选半径$m$，计算间隔$[L, R] = [i-m, i+m]$，钳位到有效索引。 使用前缀和来计算该段中的总景点。 
5. 如果总和小于或等于$R$，半径是可行的，我们尝试进一步扩大； 否则，我们减小半径。 
6. 二分查找结果给出城市的最大有效半径$i$，它被存储为答案。 

步骤 4 的关键思想是夹紧自然地处理边界城市，因此不需要超出索引限制的特殊套管。 

### 为什么它有效

 对于每个固定中心$i$,定义一个函数$f(p)$作为景点的总和$[i-p, i+p]$。 作为$p$增加，间隔只会增加，所以$f(p)$是单调非减的。 这保证了一旦$f(p)$超过$R$，所有较大的半径均无效。 这种单调结构正是使二分搜索正确的原因，并确保我们找到最大可行半径而不会丢失任何中间候选。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, r = map(int, input().split())
    a = list(map(int, input().split()))
    
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]

    def range_sum(l, rr):
        if l > rr:
            return 0
        return pref[rr + 1] - pref[l]

    def can(i, rad):
        l = max(0, i - rad)
        rr = min(n - 1, i + rad)
        return range_sum(l, rr) <= r

    res = []
    for i in range(n):
        if a[i] > r:
            res.append(-1)
            continue

        lo, hi = 0, n
        best = 0

        while lo <= hi:
            mid = (lo + hi) // 2
            if can(i, mid):
                best = mid
                lo = mid + 1
            else:
                hi = mid - 1

        res.append(best)

    print("\n".join(map(str, res)))

if __name__ == "__main__":
    solve()
```前缀和数组构建一次，这样每个区间查询就变成两个值的减法。 辅助函数`can`强制边界剪裁，这在数组末端附近至关重要。 

每个城市的二分搜索独立运行。 的选择`n`因为上限是安全的，因为半径不能超过数组的整个跨度。 

这里的一个常见错误是忘记处理案件`a[i] > R`早期的。 如果没有这个，二分搜索可能会错误地返回正半径，即使中心本身已经违反了约束。 

## 工作示例

 ### 示例 1

 输入：```
3 4
1 2 1
```我们计算前缀和：`[1, 3, 4]`。 

对于城市 1（值 2），半径 0 给出 2，这是有效的，半径 1 给出 1+2+1 = 4，也是有效的，半径 2 会超出界限，但仍然等于总和 4。所以结果是 2。 

对于城市 2（值 2），对称性给出相同的结果 2。 

对于城市 3（值 1），半径 0 给出 1，半径 1 给出 2+1 = 3，半径 2 给出 4，因此结果为 2。 

输出：```
2
2
2
```该轨迹显示了扩展如何在全段总和达到极限时准确停止。 

### 示例 2

 输入：```
3 3
1 3 5
```前缀和：`[1, 4, 9]`。 

对于城市 2（值 3），半径 0 有效。 半径 1 得出 1+3+5 = 9，超过 3，因此结果为 0。 

城市 3 的值 5 已经超过 3，因此输出为 -1。 

| 城市 | 最佳半径|
 | --- | --- |
 | 1 | 0 |
 | 2 | 0 |
 | 3 | -1 |

 此示例表明，即使很小的扩展也可以立即打破约束，并且在任何搜索之前都会检测到无效中心。
