 ## 解决方案
 ## 问题理解

 我们正在处理从 1 到 n 的整数集，并且我们想要计算有多少个大小为 k 的子集具有非常严格的结构：每对选定的数字必须以素数距离分隔。 

换句话说，如果我们从子集中选取元素 a 和 b，则绝对差 |a − b| 必须始终是质数。 此条件适用于整个子集，而不仅仅是按排序顺序的邻居之间。 因此子集受到极大的约束，因为即使是不相邻的元素也必须满足相同的素数距离规则。 

对于每个测试用例，我们给出 n 和 k，并且我们必须计算 {1, 2, …, n} 中存在多少个大小恰好为 k 的有效子集。 答案以 104206969 为模。 

规模上的限制非常严格：n 可以大到 10^7，测试用例的数量可以达到 2 × 10^5。 这立即排除了任何独立处理每个查询或构建每个测试结构的解决方案。 任何甚至每次查询都为 O(n) 的方法都是不可能的。 唯一可行的方向是单个预计算直至最大 n，然后是 O(1) 查询应答。 

一个微妙的困难是，该条件涉及所有成对差异，而不仅仅是连续差异。 这使得有效集合的结构乍一看非常不明显，并且在不了解什么配置是可能的情况下，对子集的简单组合推理很快就会变得棘手。 

## 方法

 直接的暴力方法会尝试枚举 {1..n} 的所有 k 元素子集，并检查每个成对差值是否为素数。 即使我们修复一个子集，验证它也需要 O(k^2) 检查，并且有$\binom{n}{k}$子集。 即使 n 很小，也会立即爆炸，因为搜索空间呈指数增长。 

关键的简化来自于注意到条件仅取决于差异，并且当所有差异必须同时为素数时，差异的表现非常严格。 一旦我们对有效子集 a1 < a2 < ... < ak 进行排序，我们就可以用连续间隙来表达所有约束。 令 di = a(i+1) − ai。 每个di必须是素数，更重要的是，连续di的任意和也必须是素数，因为它对应于一个不相邻的差。 

这造成了严格的算术限制。 两个素数之和几乎永远不是素数。 唯一的例外是 2 + 3 = 5。这个单一的观察结果破坏了结构的复杂性：每当我们添加连续的间隙时，它们必须以只允许 2 和 3 的非常短的交替模式的方式配对。 

由此，我们发现有效的配置不能任意大。 事实上，只有大小最大为 4 的子集才能以任何非平凡的方式存在，因为较长的交替结构不可避免地会产生非素数的连续间隙之和。 这将整个问题简化为计算整数行内的一些固定几何图案。 

然后我们明确计算每个可能的结构。 大小 1 和 2 子集仅取决于素数和素数差的全局计数。 大小 3 和 4 对应于具有小偏移的固定算术级数。

 ## 算法演练

 我们通过子集大小 k 将答案分开，因为结构会随着大小的不同而完全变化。 

首先，我们使用筛子预先计算所有测试用例中最大 n 的所有素数。 除此之外，我们还计算素数的前缀和以及素数的前缀计数，因此我们可以快速计算任何范围内所有素数的和。 

现在我们按大小分析有效子集。 

1. 当 k = 1 时，每个元素都有效，因为没有任何对违反条件。 所以答案很简单：n。 
2. 当 k = 2 时，我们需要 (a, b) 对，使得 b − a 是素数。 对于固定素数 p，每个起始位置 a 且 a + p ≤ n 形成有效对。 因此每个素数 p 恰好贡献 (n − p) 对。 我们对所有素数 p ≤ n − 1 求和。 
3. 当 k = 3 时，我们将子集排序为 a < b < c。 令间隙为 x = b − a 且 y = c − b。 两者都必须是素数，并且 x + y 也必须是素数。 两个素数求和为素数的唯一方法是它们按某种顺序是 2 和 3。 这迫使 c − a = 5，并且中点可以在 a + 2 或 a + 3 处。因此，对于每个起始位置 a ≤ n − 5，我们恰好得到两个有效的三元组。 
4.当k = 4时，我们引入三个间隙x、y、z。 同样的推理迫使每对相邻的间隙为 (2, 3) 或 (3, 2)。 所有约束的一致性只留下一个有效模式：2,3,2。这对应于集合 {a, a + 2, a + 5, a + 7}。 因此，每个 a ≤ n − 7 都贡献一个有效的四元组。 
5. 当k≥5时，不存在有效配置。 任何扩展交替结构的尝试最终都会在较长线段的端点之间产生非素数总距离，这打破了所有成对差异必须保持素数的要求。 

### 为什么它有效

 核心不变量是任何有效的子集在排序时都会强制每个内部结构被编码为素数间隙序列，其每个连续的和也必须是素数。 由于两个素数之和几乎永远不是素数，因此该结构会塌陷为一组有界的交替模式。 此限制消除了所有大型配置，仅留下可直接计数的恒定大小的模板。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 104206969

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    primes = []
    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
            step = i
            if i * i <= n:
                for j in range(i * i, n + 1, i):
                    is_prime[j] = False
    return is_prime, primes

def solve():
    T = int(input())
    queries = []
    max_n = 0

    for _ in range(T):
        n, k = map(int, input().split())
        queries.append((n, k))
        max_n = max(max_n, n)

    is_prime, primes = sieve(max_n)

    # prefix sums over primes and prefix counts by value
    prime_prefix_sum = [0] * (max_n + 1)
    prime_prefix_cnt = [0] * (max_n + 1)

    ps = 0
    pc = 0
    for i in range(1, max_n + 1):
        if is_prime[i]:
            pc += 1
            ps += i
        prime_prefix_cnt[i] = pc
        prime_prefix_sum[i] = ps

    out = []

    for n, k in queries:
        if k == 1:
            out.append(str(n))
        elif k == 2:
            cnt = prime_prefix_cnt[n - 1]
            s = prime_prefix_sum[n - 1]
            ans = (cnt * n - s) % MOD
            out.append(str(ans))
        elif k == 3:
            if n < 5:
                out.append("0")
            else:
                out.append(str(2 * (n - 5) % MOD))
        elif k == 4:
            if n < 7:
                out.append("0")
            else:
                out.append(str(n - 7))
        else:
            out.append("0")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```筛子是唯一的全局繁重预处理步骤，之所以需要它，只是因为 k = 2 取决于对直到 n 的所有素数的贡献求和。 一旦素数及其前缀和已知，每个查询都会简化为常数时间算术。 

对于 k = 2，表达式 n * (#primes) − (素数之和) 直接计算每个素数间隙的所有有效有序起始 a。 对于 k = 3 和 k = 4，公式直接来自枚举有效的算术模式并将它们移过整数行。 

k ≥ 5 的分支安全地为零，因为没有任何配置能够幸免于超过大小 4 的成对素差约束。

 ## 边缘情况

 对于 k = 1，子集约束完全消失。 该算法无需依赖任何筛子结构即可正确返回 n。 

对于 n < 5 的小 n，k = 3 没有有效的配置，因为即使是最小的模式也需要跨度 5。该公式自然返回零，因为 (n − 5) 变为负值并被条件限制。 

对于 k = 4，最小有效构造跨越长度 7。当 n < 7 时，模式 {a, a+2, a+5, a+7} 不存在起始位置，因此输出正确为零。 

当 k ≥ 5 时，算法始终返回零。 这与强制交替素数间隙所产生的结构不可能性相匹配，其累积和不可避免地包含一个复合值，从而打破了全局成对约束。
