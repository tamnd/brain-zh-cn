 ## 解决方案
 ## 问题理解

 有两个相同大小的网格。 一个网格代表英雄 A 移动的现实世界，另一个网格代表克隆人试图到达目的地单元的平行世界。 两个网格都包含墙壁、空单元格、单个起始位置，并且只有克隆的网格包含单个目的地。 

每时每刻，英雄 A 都会向四个基本方向之一发出行动。 如果英雄 A 的网格中的移动被阻止，则任何地方都不会发生任何事情。 如果它在英雄 A 的网格中有效，则英雄 A 移动。 然后，克隆体尝试镜像相同的方向：如果克隆体网格中的相应单元格是空闲的，则它会移动；如果是，则它会移动。 否则它会留在原地。 这会产生一种耦合，英雄 A 的移动序列间接推动克隆人，但克隆人网格中的障碍可能会“取消”其中一些推动。 

任务是确定英雄 A 所需的最小移动次数，以便克隆体从两个初始位置开始最终到达其网格中的目标单元格。 

约束意味着每个网格最多有 1000 个单元，并且最多有 10 个测试用例。 这立即排除了网格单元上的任何指数或三次方法。 大约 10^6 状态的二次解是可以接受的，特别是如果每​​个转换都是 O(1)。 

当英雄 A 被困在自己的网格中时，就会出现一种微妙的边缘情况。 在这种情况下，任何尝试的移动都不会导致任何一个网格发生变化，因此系统可能会“陷入”某种状态。 不跟踪访问状态的简单模拟将永远循环。 

另一种重要的情况是，当克隆人被墙壁阻挡，导致其反复落后于英雄 A 时，因此英雄 A 的移动只会影响他自己很多步，然后克隆人再次开始移动。 这使得贪婪模拟不正确，因为移动的好处是依赖于状态的。 

## 方法

 一个天真的解释是模拟英雄 A 所有可能的移动序列并跟踪克隆人的最终位置。 由于每个步骤分为四个方向，因此对于 k 个移动，可能的序列数量会增长为 4^k。 即使 k 约为 40，这也完全不可行，而网格中的最短路径通常需要数百步。 

关键的观察是，一旦我们固定一对位置，系统就完全确定了：英雄 A 在网格 A 中的位置和克隆人在网格 B 中的位置。单个移动方向确定性地将这一对转换为新的对。 这将问题转化为产品图上的最短路径问题，其节点是单元对。 

暴力破解会失败，因为它在不记住中间配置的情况下探索序列。 正确的结构是，重新访问同一对位置永远不会产生更好的答案，因此我们可以在状态 (a_position, b_position) 上运行 BFS。 每个状态最多有四个转换对应于四个方向。 

这将问题简化为大小为 r_c * r_c 的未加权图中的最短路径，最多 10^6 个节点。 每个节点都有恒定的度，因此 BFS 就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力序列 | O(4^k) | O(4^k) | O(k) | 太慢了|
 | 状态对上的 BFS | O((rc)^2) | O((rc)^2) | O((rc)^2) | O((rc)^2) | 已接受 |

 ## 算法演练

 我们将每个状态视为一对，由英雄 A 在网格 A 中的位置和克隆人在网格 B 中的位置组成。然后，我们搜索将克隆体引导到目的地的最短移动序列。

1. 解析两个网格并找到网格 A 中的起始位置以及网格 B 中的起始位置和目标位置。这些定义了初始状态。 
2. 将每个单元表示为单个整数索引，以便可以将一对位置编码为单个可哈希状态。 这允许快速访问检查。 
3. 使用起始状态和距离 0 初始化 BFS 队列。将此状态标记为已访问。 
4. 重复从队列中弹出一个状态。 如果克隆位置等于目的地，则立即返回距离，因为 BFS 保证最小值。 
5. 对于四个方向中的每一个，计算英雄 A 尝试的移动。 如果移动在网格 A 中被阻止，则状态不会改变，我们会跳过为该方向生成新状态，因为它只会产生自循环。 
6. 如果英雄 A 成功移动，则计算克隆人的响应。 如果网格 B 中的下一个单元格位于边界内并且未被阻挡，则克隆会移动到那里； 否则它将保留在当前单元格中。 这准确地捕捉了“滞后”行为。 
7. 根据这两个结果位置形成新状态。 如果之前没有被访问过，则将其标记为已访问，并将其推入队列，距离加一。 

BFS 确保按照移动次数递增的顺序探索状态。 

### 为什么它有效

 关键的不变量是每个 BFS 状态代表一系列有效移动之后的精确配置，并且每次转换都准确对应英雄 A 的一个合法移动。因为所有移动都有相同的成本，所以 BFS 以非递减的步骤顺序探索配置。 一旦访问了一个状态，到达该状态的任何替代路径都必须至少具有同样大的长度，因此重新访问它无法改进答案。 这保证了克隆体第一次到达目的地时，相应的移动次数是最少的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

def solve():
    r, c = map(int, input().split())
    
    A = [input().strip() for _ in range(r)]
    B = [input().strip() for _ in range(r)]
    
    def find(grid, ch):
        for i in range(r):
            for j in range(c):
                if grid[i][j] == ch:
                    return i, j
        return None
    
    sa_x, sa_y = find(A, 'S')
    sb_x, sb_y = find(B, 'S')
    
    dx, dy = find(B, 'D')
    
    def id(x, y):
        return x * c + y
    
    start = (id(sa_x, sa_y), id(sb_x, sb_y))
    target_b = id(dx, dy)
    
    N = r * c
    vis = set()
    vis.add(start)
    q = deque([(start[0], start[1], 0)])
    
    while q:
        a, b, d = q.popleft()
        
        if b == target_b:
            print(d)
            return
        
        ax, ay = divmod(a, c)
        bx, by = divmod(b, c)
        
        for dx, dy in DIRS:
            nax, nay = ax + dx, ay + dy
            
            if not (0 <= nax < r and 0 <= nay < c):
                continue
            if A[nax][nay] == 'X':
                continue
            
            nbx, nby = bx + dx, by + dy
            
            if not (0 <= nbx < r and 0 <= nby < c) or B[nbx][nby] == 'X':
                nbx, nby = bx, by
            
            na = id(nax, nay)
            nb = id(nbx, nby)
            
            state = (na, nb)
            if state not in vis:
                vis.add(state)
                q.append((na, nb, d + 1))
    
    print(-1)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该解决方案在配对位置上构建 BFS。 唯一微妙的部分是仔细建模克隆体的“尝试移动”规则：它尝试遵循英雄 A 的方向，但独立检查自己的网格约束。 另一个重要的细节是完全忽略无效的 Hero 动作，因为这些动作不会产生状态变化，否则会在 BFS 中创建无用的自循环。 

## 工作示例

 考虑一个简单的情况，其中两个网格都打开并对齐，因此运动始终是镜像的。 BFS 的行为类似于单个网格上的标准最短路径，因为两个坐标始终一起移动。 

| 步骤| 英雄A | 克隆| 行动|
 | ---| ---| ---| ---|
 | 0 | S | S | 开始 |
 | 1 | 对| 对| 两者都移动|
 | 2 | 下| 下| 两者都移动|
 | 3 | 对| 对| 到达 D |

 这证实了当没有障碍物时，系统会减少到普通的最短路径行为。 

现在考虑克隆被提前阻止的情况。 

| 步骤| 英雄A | 克隆| 行动|
 | ---| ---| ---| ---|
 | 0 | S | S | 开始 |
 | 1 | 对| 被封锁 | 克隆留下|
 | 2 | 对| 被封锁 | 克隆仍然卡住|
 | 3 | 下| 向下移动 | 部分进展 |

 这说明了为什么天真的贪婪推理会失败：早期的动作可能对克隆没有影响，但仍然需要重新定位英雄 A，以便未来的动作变得有效。 

BFS 正确地解释了这些延迟效应，因为每个状态同时对两个位置进行编码。

 | 测量 | 复杂性 | 说明|

 由于 r*c ≤ 1000，状态总数最多为 10^6，并且每个状态的转换都是恒定的。 这完全符合典型的限制。

 ## 边缘情况

 一种边缘情况是，英雄 A 完全被困在网格 A 中，而克隆人距离目的地还很远。 在这种情况下，每一次尝试的移动都变成了空操作。 BFS 正确地处理了这个问题，因为这样的转换会返回到已经访问过的相同状态，因此队列自然会清空，如果克隆从未达到目标，答案将变为 -1。 

另一种情况是，克隆人被墙壁包围，但英雄 A 可以自由移动。 当英雄 A 改变位置时，克隆状态在许多步骤中保持不变，有效地探索“接近”克隆网格动态的不同方法。 BFS 捕捉到了这一点，因为即使克隆体是固定的，英雄 A 的位置状态也会有所不同。 

最后一个微妙的情况是两个网格相同但起始位置不同。 该解决方案不假设对称性，并且仍然独立对待它们，因此 BFS 正确地探索了英雄 A 必须如何“重新调整”运动序列才能将克隆体带入可到达的走廊。
