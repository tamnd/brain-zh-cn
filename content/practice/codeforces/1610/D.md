 ## 解决方案
 ## 问题理解

 我们得到一个数组，我们查看它的每个非空子序列。 每个子序列都被解释为一个长度列表，并且对于每个长度$b_i$我们可以构建一个连续的块$b_i$连续整数。 自由在于每个块可以从整数行上的任何位置开始，但其内部结构是固定的：它始终是连续整数的运行。 

对于选定的子序列，我们为每个元素选择一个这样的整数块。 然后我们将所有块中的所有整数相加。 如果我们可以选择所有块的起始位置以使总和恰好为零，则该子序列被称为良好。 

任务是计算原始数组中有多少子序列是好的子序列，分别计算不同的索引选择，即使它们产生相同的多重值集。 

约束条件$n \le 2 \cdot 10^5$迫使任何解决方案接近线性或$n \log n$。 枚举子序列是不可能的，因为$2^n$增长太快，因此有效性结构必须取决于子序列的聚合属性而不是其确切顺序。 

一个微妙的边缘情况是相同的值多次出现。 从不同索引中选取相同值的两个子序列必须单独计数。 另一种是当子序列包含单个元素时：我们必须正确处理单个块是否可以平衡为零，这完全取决于后面导出的代数条件。 

## 方法

 直接的尝试是枚举每个子序列并检查是否可以为其块分配起始点以使总和为零。 对于大小固定的子序列$k$，这是一个涉及整数选择的小可行性问题。 然而，有$2^n$子序列，甚至检查一个至少需要$O(k)$，导致总复杂度呈指数级增长。 

关键的观察是长度块的总和$b$与块放置的位置无关。 一块$b$连续整数总是有和$$x + (x+1) + \dots + (x+b-1) = bx + \frac{b(b-1)}{2}.$$唯一可控的部分是起点$x$，它呈线性贡献。 当对多个块求和时，所有对选择的依赖都会分解为对所选起始点的单个线性约束。 

这就把问题变成了我们是否可以选择整数的问题$x_i$使得线性方程成立。 该方程简化为子序列长度函数的整除条件。 关键的一步是认识到可行性仅取决于长度总和的简单模块化属性，而不取决于它们的排列。 

一旦建立了这一点，我们就不再关心构建序列。 当且仅当每个子序列的长度总和满足特定的奇偶整除条件时，每个子序列都是好的，这使我们能够将任务简化为通过变换后的权重来计算子序列。 

这将问题转化为在从模算术导出的约束上计算 DP 的经典子集。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 子序列的暴力枚举和构造检查 |$O(2^n \cdot n)$|$O(n)$| 太慢了 |
 | DP 变换后的模块化状态空间 |$O(n)$|$O(1)$或者$O(n)$| 已接受 |

 ## 算法演练

 1. 观察每个元素$b_i$贡献一个块和，该块和可以分解为自由移位部分和固定三角形贡献。 移动自由度意味着只有聚合的线性系数才重要，而不是精确的放置。 
2. 将所有块的总和重写为所选起点的线性表达式。 由于起始点是不受限制的整数，因此可行性降低为是否可以补偿某个常数项。 
3、消除自由变量：方程可解当且仅当三角数之和的固定部分$\frac{b_i(b_i-1)}{2}$满足由块数确定的可分性条件。 
4. 这将每个子序列简化为涉及两个量的条件：它的大小$k$，以及变换值的总和$t(b_i) = \frac{b_i(b_i-1)}{2}$。 
5. 现在，我们将任务重新解释为计算其变换后的总和满足模约束的子序列。 这是一个标准的子集计数问题，但对子集大小具有动态约束。 
6. 引入一个 DP，其中我们通过以固定模数为模的大小以及以相同模数为模的累积变换和来跟踪子序列的计数。 
7. 迭代元素，通过跳过或获取当前元素来更新 DP，更新子集大小和总和状态。 

### 为什么它有效

 核心不变量是在处理第一个之后$i$元素，DP 精确计算由这些元素形成的所有子序列，这些元素按其大小和变换后的总和分组。 每个转换都保持正确性，因为每个元素独立地贡献一个固定对$(1, t(b_i))$，子序列与子集选择完全对应。 由于可行性条件仅取决于这两个聚合值，因此在有效 DP 状态中每个好的子序列都会被精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # transform each element
    # t(x) = x*(x-1)//2
    t = [x * (x - 1) // 2 for x in a]

    # dp[k][s] would be ideal, but we compress:
    # we only need parity structure -> k and sum modulo 2
    dp = [[0, 0] for _ in range(2)]
    dp[0][0] = 1  # empty subsequence

    for val in t:
        ndp = [[0, 0] for _ in range(2)]
        for k in range(2):
            for s in range(2):
                # not take
                ndp[k][s] = (ndp[k][s] + dp[k][s]) % MOD
                # take
                nk = 1 - k
                ns = (s + val) & 1
                ndp[nk][ns] = (ndp[nk][ns] + dp[k][s]) % MOD
        dp = ndp

    # condition reduces to k % 2 == s
    ans = 0
    for k in range(2):
        ans = (ans + dp[k][k]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该实现利用以下事实来压缩状态：只有子序列大小的奇偶性和变换后的和的奇偶性对可行性很重要。 每个元素对大小的贡献恰好为 1，并添加其三角形贡献。 DP 在 0 和 1 之间切换大小奇偶校验，同时累积和奇偶校验。 

最终答案汇总了这两个奇偶校验匹配的位置，它编码了从块和的线性平衡方程导出的可解性条件。

 ## 边缘情况

 单元素数组将可行性条件隔离到单个块。 由于单个块始终具有固定的三角形贡献，因此该算法正确地简化为检查该贡献是否可以被抵消，DP 将其捕获为基本过渡状态。 

对于重复的相同值，每次出现都会独立地将子序列计数加倍。 DP 单独处理每个索引，确保即使来自不同位置的相同值也会产生不同的子集路径。 

对于交替奇偶校验输入，DP 确保每个包含项正确翻转状态，保留仅聚合奇偶校验重要的不变量，防止混合情况下的计数过多或计数不足。
