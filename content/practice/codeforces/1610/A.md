 ## 解决方案
 ## 问题理解

 我们有一个矩形网格$n$行和$m$列。 在这个网格的某个地方，对手隐藏了一个单元格$(x, y)$。 我们被允许“探测”一组固定的$k$我们选择的细胞。 对于每个选定的单元格，我们都会收到其到隐藏单元格的曼哈顿距离。 

重要的限制是在看到这些之后$k$距离，我们必须能够唯一地确定每个可能选择的隐藏单元$(x, y)$。 目标是找到保证这种唯一性所需的最少探针数量。 

问题的根本在于需要多少个参考点，以便每个网格单元都有到这些点的曼哈顿距离的唯一向量。 

限制因素$n, m \le 10^9$消除任何枚举单元格或模拟距离模式的想法。 任何正确的解决方案必须仅取决于网格的几何形状，而不取决于其明确的尺寸。 由于有多达$10^4$测试用例时，每个用例的解决方案必须是恒定的时间。 

当人们认为将探针“远离”放置总是足够时，天真的推理就会出现一种微妙的失败情况。 例如，在一个$2 \times 3$在网格中，选择对角不一定区分对称位置，因为曼哈顿距离保留了一定的对称性。 这正是问题在于结构而不是简单布局的原因。 

## 方法

 暴力方法会尝试选择$k$探测单元并检查从隐藏单元到距离向量的映射是否是单射的。 对于探针的固定选择，我们将计算所有探针的距离向量$n \cdot m$细胞并验证唯一性。 即使我们只测试一种配置，这也已经花费了$O(nm)$，这是不可能的，当$n, m$可以达到$10^9$。 

尝试所有探针组的情况甚至更糟。 搜索空间是$(nm)^k$，即使对于$k = 2$。 所以暴力破解是完全不可能的。 

关键的观察结果是曼哈顿距离具有非常严格的结构。 单个探针无法确定唯一的单元格，因为菱形轮廓上的所有点都具有相同的距离。 每个附加探针有效地与另一组此类轮廓相交。 问题是：需要多少个这样的约束才能隔离矩形中的单个格点？ 

距一个探针的单一距离沿对角线留下多个候选者。 使用两个探针，我们可以认为两个对角水平集系列相交。 然而，当网格具有多于一行和多于一列时，就会出现简并性：某些配置仍然允许歧义。 另一个探针通过打破剩余的对称性来解决这个问题。 

关键的简化在于，答案仅取决于网格是直线还是真正的二维。 如果其中之一$n = 1$或者$m = 1$，所有像元都位于一条线上，曼哈顿距离变成普通的绝对距离。 在端点处精心选择的探针可以用单个值唯一地标识每个位置，因为当锚定在端点时，沿线的距离是单射的。 

如果两个维度都至少为 2，则两个探针始终足够，而一个永远不够。 一个探针无法区分对称位置。 放置在非简并位置（例如相邻角）的两个探针打破了所有对称性。 

所以答案是：

 -$k = 1$如果$n = 1$或者$m = 1$-$k = 2$否则

 这种二分法充分说明了问题的特征。

 | 蛮力 | 指数 /$O((nm)^k)$|$O(nm)$| 太慢了 |
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取整数$n$和$m$对于每个测试用例。 这些定义了网格的几何形状，这是对答案唯一重要的事情。 
2. 检查网格是否退化为单行或单列。 这对应于$n = 1$或者$m = 1$。 在这种情况下，所有点都位于一条直线上，因此距离的行为类似于一维绝对差。 
3. 如果网格是一维的，则输出 1。放置在端点处的单个探针使得每个其他位置都具有不同的距离，因此不会留下任何歧义。 
4. 否则，两个维度都至少为 2。在这种情况下，输出 2。一个探针无法区分对称配置，但两个探针会破坏保留单个距离值的所有可能的反射和平移。 

### 为什么它有效

 正确性来自于距离信息如何约束坐标。 使用一个探针，所有细胞都满足$|x - x_0| + |y - y_0| = d$形成菱形，并且当 2D 网格中仅使用一个探针时，多个单元始终共享相同的距离模式。 这保证了当$n, m \ge 2$。 

当网格是一条线时，曼哈顿度量减少为沿一个轴的绝对差，并将探针放置在端点处会在所有单元格之间产生严格增加或减少的距离值，从而使每个位置都可以唯一识别。 在二维中两个独立的距离约束下，两个曼哈顿水平集的交集至多是一个网格单元，从而消除了歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n == 1 or m == 1:
        print(1)
    else:
        print(2)
```其实现直接体现了网格的结构分类。 唯一需要的决定是网格是否折叠成一维线。 不需要模拟或几何构造，因为答案完全取决于维度。 

关键的微妙之处在于认识到端点是一维情况下隐式的最佳探测位置，即使问题不需要显式地构造它们。 在 2D 情况下，我们也不需要构造两个探针，因为问题只要求最小计数。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 or m == 1:
            out.append("1")
        else:
            out.append("2")
    return "\n".join(out)

# provided samples
assert run("2\n2 3\n3 1\n") == "2\n1"

# minimum size grid
assert run("1\n1 1\n") == "1"

# single row
assert run("1\n1 1000000000\n") == "1"

# square grid
assert run("1\n4 4\n") == "2"

# tall grid
assert run("1\n100 1\n") == "1"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 | 1×1 | 1 | 最小网格|
 | 1×N | 1 | 一维行行为 |
 | N×1 | 1 | 一维列行为 |
 | 4×4 | 2 | 最小 2D 案例 |

 ## 边缘情况

 对于一个$1 \times 1$网格，算法检查$n = 1$或者$m = 1$并立即返回 1。没有歧义，因为只有一个单元存在，所以任何探测都足够了。 

对于一个$1 \times m$网格如$1 \times 5$，条件再次触发一维情况。 如果我们进行心理模拟，任何探测$(1, 1)$产生距离$0, 1, 2, 3, 4$跨行，全部不同，因此一个查询就足够且最佳。 

对于一个$2 \times 2$网格，两个维度都不等于 1，因此算法输出 2。只有一个探针，对角如$(1,1)$和$(2,2)$为距离模式的某些内部推理产生对称歧义。 需要两个探针来打破这些对称性，从而匹配输出。
