 ## 问题理解

 我们得到一串括号`S`已通过重复执行包装操作进行修改。 每个操作都允许您获取任何连续的子字符串`B`并用一对括号将其括起来，将其插回到字符串中的原始位置。 提供所有操作后的结果字符串，目标是重建原始字符串，如果有多个有效答案，则选择字典顺序最小的可能性。 

输入保证第一个字符是`)`，这很重要，因为它从一开始就排除了一些关于格式良好的天真的假设。 字符串的长度最多可达 300,000，这意味着任何尝试模拟所有可能的逆运算或显式检查所有可能的分割的算法都会太慢。 尝试每一种可能的切割的强力解决方案将在字符串长度上具有指数级的复杂性，这是完全不可行的。 

当字符串有许多嵌套或连续的括号时，会出现微妙的边缘情况，例如`")()()"`。 粗心的方法可能会认为从左到右平衡括号就足够了，但包装操作允许一定的灵活性，因此我们必须仔细选择将哪些括号视为原始存在或插入。 例如，`")((())))"`应该返回`")(())))"`- 删除里面的第一个额外的对会产生最小的字典字符串。 处理空子字符串`A`或者`C`正确也很重要； 如果不这样做，可能会产生错误移位的字符串。 

## 方法

 蛮力方法是尝试以各种可能的方式撤消每个包装操作，生成原始字符串的所有候选者，然后选择字典顺序最小的。 虽然这在原则上是正确的，但它会组合爆炸，因为每对括号都可以在任何子字符串周围引入，并且在不检查每种可能性的情况下，没有有效的方法来确定哪些是原始的。 操作次数很容易超过`2^n`对于长度为 300,000 的字符串，使得此方法不可用。 

关键的见解是从平衡的角度看待问题。 每一项操作增加一个空缺`(`和一个关闭`)`在特定位置。 如果我们想象剥离这些添加的对，我们希望以最小化词典顺序的方式删除这些对。 因为`(`小于`)`，按字典顺序最小的字符串放置了尽可能多的`)`尽可能接近结束并离开早期`)`在开始时完好无损（因为第一个字符保证是`)`）。 我们可以统计不匹配的数量`)`开头和数量不匹配`(`最后，然后删除中间多余的添加对。 这有效地将问题简化为线性扫描，在我们重建字符串时保持计数器平衡。

 ## 算法演练

 1.初始化一个计数器`open_count`为零和一个空列表`result`构建原始字符串。 
2.遍历字符串`S`逐个字符。 如果角色是`'('`, 增量`open_count`并将其附加到`result`。 这算不匹配的左括号。 
3. 如果角色是`')'`,检查是否有对应的不匹配`'('`通过检查`open_count`。 如果`open_count`为正数，追加`')'`到`result`并减少`open_count`。 这确保了只有有效的对才包含在重建中。 
4.如果`open_count`遇到时为零`')'`，它必须是开头处原始不匹配的右括号的一部分，因此将其直接附加到`result`。 
5.遍历完整个字符串后，`result`包含按字典顺序最小的原始字符串，因为通过操作添加的所有额外对都被有效忽略，而不匹配的原始括号被保留。 

为什么有效：在每一步，我们都保持不变式：`open_count`准确地表示了不匹配的数量`'('`尚未关闭的。 仅当存在不匹配时才匹配括号`'('`，我们防止形成原始字符串中不存在的新对。 保存无与伦比的`')'`在开始时尊重输入的初始条件并确保结果字符串按字典顺序最小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

S = input().strip()
result = []
open_count = 0

for ch in S:
    if ch == '(':
        open_count += 1
        result.append('(')
    else:  # ch == ')'
        if open_count > 0:
            open_count -= 1
            result.append(')')
        else:
            result.append(')')

print(''.join(result))
```此代码使用输入字符串的线性扫描，为不匹配的情况维护一个简单的计数器`'('`。 It directly builds the output in a list, which is efficient for string concatenation. 关键的微妙之处在于无与伦比`')'`在开始时被保留，这确保了词典编排的最小性，并且额外`')'`会创建无效对的操作将被忽略，直到匹配`'('`存在。
