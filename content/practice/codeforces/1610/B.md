 ## 解决方案
 ## 问题理解

 我们得到一个数组并允许执行一种非常特定类型的转换：我们可以选择一个值`x`并从数组中删除该值的所有出现，不一定是全部。 删除后，剩余的元素折叠在一起，我们检查结果序列是否是回文。 

任务是决定是否存在至少一种选择`x`这样这个操作就可以使数组成为回文数组。 我们不需要在最终输出中显式地构造删除，只需回答是否可能。 

这些约束允许最多 10^4 个测试用例，并且所有测试的总数组长度最多为 2 × 10^5。 这立即意味着每次测试的 O(n^2) 或任何比每次测试线性更差的东西都是不安全的。 任何解决方案都必须在线性时间内有效地处理每个测试，可能需要少量的线性扫描。 

一种天真的方法会尝试每一个可能的值`x`，删除它，并检查结果数组是否是回文。 在最坏的情况下，每次测试的时间复杂度为 O(n^2)，当值频繁重复时，这太慢了。 

当数组几乎是回文但需要删除出现在许多位置的值时，会出现更微妙的失败情况。 删除遇到的第一个不匹配值的贪婪删除尝试将失败，因为正确的选择`x`是全球性的，而不是局部性的。 

## 方法

 暴力破解的想法很简单：对于数组中的每个不同值，模拟删除该值的所有出现，然后检查生成的数组是否是回文。 每次检查的成本为 O(n)，并且可以有 O(n) 个不同的值，因此总成本变为 O(n^2)。 这立即在限制下被打破。 

关键的观察结果是，有效解决方案的结构受到原始数组中不匹配的严重限制。 我们从使用两个指针的标准回文检查开始。 如果数组已经是回文，我们就完成了。 否则，我们找到从左到右的第一个值不同的位置。 此时，任何有效的解决方案都必须删除所有出现的不匹配所涉及的左值或右值，因为这些是唯一可以消除该位置冲突的候选值。 

这将问题减少到最多测试两个候选者。 对于每个候选值，我们模拟两指针回文检查，同时在该值出现时跳过该值。 如果任一模拟成功，则该数组是回历数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 暴力破解一切x | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 两分球候选人检查 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们从数组末尾的两个指针开始。 当价值观匹配时，我们将它们向内移动。 如果我们到达中间，数组就已经是回文了。 

如果我们遇到位置不匹配`l`和`r`，唯一可能的修复是删除所有出现的`a[l]`或所有出现的`a[r]`。 我们独立测试这两个选项。 

测试候选值`x`，我们再次使用两个指针。 每当我们看到`x`，我们通过向内移动指针来跳过它。 否则，我们就正常比较。 如果在任何时候非跳过值不匹配，则该候选者失败。 

如果任一候选人成功，我们将返回 YES。 

这样做的原因是两指针扫描中的第一个不匹配识别了对称性破坏的确切区域。 任何有效的解决方案都必须删除两个冲突值之一，否则在数组的每个简化版本中都会存在不匹配问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_pal_after_removal(a, x):
    l, r = 0, len(a) - 1
    while l < r:
        while l < r and a[l] == x:
            l += 1
        while l < r and a[r] == x:
            r -= 1
        if l >= r:
            break
        if a[l] != a[r]:
            return False
        l += 1
        r -= 1
    return True

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        l, r = 0, n - 1
        
        while l < r and a[l] == a[r]:
            l += 1
            r -= 1
        
        if l >= r:
            print("YES")
            continue
        
        x, y = a[l], a[r]
        
        if is_pal_after_removal(a, x) or is_pal_after_removal(a, y):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```识别出第一个不匹配后，代码会准确隔离可能影响任何有效解决方案结构的两个值。 辅助函数在线性时间内执行过滤回文检查，完全跳过一个候选值。 这可以避免重建数组并保持内存使用量恒定。 

一个微妙的点是我们不会尝试任意删除部分出现的情况。 跳过逻辑隐式允许选择性删除，同时保留顺序，这与问题定义相匹配。 

## 工作示例

 考虑输入：```
5
1 4 4 1 4
```最初的两指针扫描比较 1 和 4，结果立即不匹配。 所以候选者是 1 和 4。 

测试删除 1 会得到 [4, 4, 4]，这是一个回文。 

测试删除 4 个会产生 [1, 1]，这也是一个回文。 

该算法正确返回 YES。 

现在考虑：```
3
1 2 3
```第一个不匹配立即发生在两端（1 和 3）。 仅删除 1 会产生 [2, 3]，而不是回文。 仅删除 3 个会产生 [1, 2]，也不是回文。 该算法正确返回 NO。

 ## 边缘情况

 一个关键的边缘情况是当数组已经是回文时。 在这种情况下，不匹配指针永远不会发散，并且算法会提前正确终止，而无需测试任何删除候选者。 这可以防止不必要的计算并避免漏报。 

另一种极端情况是所有元素都相同。 不匹配循环永远不会触发，答案立即是“是”，因为任何删除仍然会留下回文或空数组。
