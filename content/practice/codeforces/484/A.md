 ## 解决方案
 ## 问题理解

 我们被要求处理多个查询，每个查询都由下限定义`l`和一个上限`r`。 对于每个查询，我们需要找到整数`x`区间内`[l, r]`使得其二进制表示中的设置位数尽可能大。 如果多个数字达到了最大设置位数，则应选择这些数字中最小的一个。 

输入保证最多 10,000 个查询，并且限制`l`和`r`上升到$10^{18}$。 这个上限意味着一种简单的方法，检查每个数字`[l, r]`将是不可行的，因为`r - l`可能非常大，有潜力$10^{18}$。 因此，解决方案必须能够计算答案，而无需枚举区间内的所有整数。 

当发生微妙的边缘情况时`l`和`r`是连续的 2 的幂或仅相差一位。 例如，如果`l = 8`和`r = 15`，最优数为`15`因为它已设置所有低 4 位。 一个粗心的实现，只考虑了`r`或者简单的贪心方法可能会错误地选择`14`，其设置位较少。 同样，如果`l = r`，算法必须简单地返回`l`，因为这是唯一的选择。 

## 方法

 暴力方法很简单：对于每个查询，迭代之间的每个整数`l`和`r`，计算设置位的数量，并跟踪最大值。 这保证了正确性，但将设置位计数到$10^{18}$对于 10,000 个查询来说显然太慢了。 最坏情况下的操作数是$10^{18} \times 64 \approx 6.4 \times 10^{19}$操作，这超出了许多数量级的可行限制。 

关键的观察是间隔中设置位的最大数量`[l, r]`是通过尽可能接近一串连续的数字来实现的，从最高位开始，其中`l`和`r`不同。 如果我们检查二进制表示`l`和`r`，我们可以通过将第一个不同位设置为来构造候选数`1`和所有较低位`1`。 这位候选人可能会超过`r`，因此我们需要小心地将较低位翻转回零以保持在界限内，检查多个位置。 

这种洞察力使我们能够避免枚举所有数字。 相反，我们可以直接对二进制表示进行操作，每个查询最多操作 64 位，从而得到可行的解决方案。 该方法减少了构建候选人的过程`r`并贪婪地填充较低位，同时尊重间隔约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((r-l+1) * 64) | O(1) | O(1) | 太慢了|
 | 最佳 | 每个查询 O(64) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个查询，立即检查是否`l == r`。 如果是，则返回`l`。 无需进一步计算，因为只有一个候选者。 
2. 转换`l`和`r`通过用前导零填充将其转换为相同长度的二进制表示形式。 这允许直接比较每个位置的位。 
3. 初始化候选号`ans`作为`r`。 这是起点，因为`r`是间隔中最大的数字，并且已经包含许多设置位。 
4. 从最高有效位到最低有效位迭代。 确定第一个位置`l`有一个`0`和`r`有一个`1`。 这是最高的不同位。 要最大化设置位，请考虑将该位设置为`1`和所有较低位`1`。 
5. 通过设置识别的位并用以下内容填充所有较低有效位来构造一个新数字`1`s。 如果这超过`r`，从最低有效端将位恢复为零，直到它适合`[l, r]`。 
6. 将该候选者的设置位数与`r`本身。 选择设置位数较多的那个。 如果出现平局，请选择较小的数字。 
7. 返回结果数。 

为什么它的工作原理：该算法保证之间的第一个不同位`l`和`r`在候选中设置。 用 1 填充所有较低位可最大化设置位的数量，向下调整可确保其不超过`r`。 任何具有较高设置位计数的数字都必须有一个`1`处于一个位置`r`有`0`，这将在区间之外，因此不存在更好的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_bits(l, r):
    if l == r:
        return l
    ans = r
    length = max(l.bit_length(), r.bit_length())
    for i in range(length-1, -1, -1):
        mask = 1 << i
        if (l & mask) == 0 and (r & mask) != 0:
            candidate = r | (mask - 1)
            if candidate > r:
                candidate ^= candidate & (mask - 1)
            if candidate < l:
                candidate = r
            if bin(candidate).count('1') > bin(ans).count('1') or (bin(candidate).count('1') == bin(ans).count('1') and candidate < ans):
                ans = candidate
            break
    return ans

n = int(input())
for _ in range(n):
    l, r = map(int, input().split())
    print(max_bits(l, r))
```该代码仔细地操作位以在不超过间隔的情况下最大化位的数量。 掩码标识第一个不同的位，并且`mask - 1`设置所有低位。 通过 XOR 进行调整可确保我们保持在范围内。 使用Python的内置方法来计算位数`bin()`功能。 

## 工作示例

 **输入：**`1 10`二进制`l=1`->`0001`,`r=10`->`1010`。 

最高的不同位位于位置 3（LSB 从 0 开始计数）。 设置该位并用 1 填充较低位会产生`0111`->`7`。`7`具有三个设置位，比任何其他数字都多`[1, 10]`。

 这证实了用第一不同位和较低位组构建候选给出了正确的最大组位数。
