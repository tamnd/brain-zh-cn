 ## 解决方案
 ## 问题理解

 我们的任务是创造一种药水，其中含有精确的成分$k\%$魔法精华和$(100-k)\%$水。 坩埚开始是空的，我们一次只能添加任一成分一升。 目标是确定为达到精确比例而必须倒出的最小升数。 输入提供了许多测试用例$t$，每个指定所需的百分比$k$，并且输出必须给出每个的最小总升数。 

关键的观察是，药水的比例仅取决于精华和水的相对数量，而不取决于绝对体积。 因此，问题就简化为寻找最小整数$e$和$w$这样$$\frac{e}{e + w} = \frac{k}{100}.$$我们可以将其重写为$100 \cdot e = k \cdot (e + w)$，这导致$100e - k(e + w) = 0$，或等价地$e \cdot (100 - k) = w \cdot k$。 这是整数线性丢番图方程$e$和$w$。 

约束很小，$1 \le k \le 100$和$t \le 100$，所以一个$O(1)$每个测试用例的算术解决方案就足够了。 边缘情况发生时$k$将 100 整除（例如，$k = 25, 50, 100$）以及何时$k$与 100 互质（例如，$k = 3, 7$）。 测试所有卷（最多 100）的简单解决方案是可行的，但由于存在简单的数论公式，因此没有必要。 

## 方法

 蛮力方法将迭代所有可能的卷$e + w$从1开始，检查分数是否$e/(e+w)$等于$k/100$。 为了$k = 1$或者$k = 99$，这可能需要最多 100 个步骤，这是可以接受的，但不够优雅。 

最佳方法使用最大公约数推理。 如果$g = \gcd(k, 100)$， 然后$k = g \cdot k'$和$100 = g \cdot 100'$。 满足该比例的最小总升数恰好是$100/g$， 自从$$\frac{e}{e+w} = \frac{k}{100} = \frac{k'}{100'}$$该比率中的最小整数是$e = k'$和$w = 100' - k'$, 给予$e + w = k' + (100' - k') = 100' = 100/g$。 这会产生一个无需迭代的直接公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | 每个测试用例 O(100) | O(1) | O(1) | 已接受但没有必要 |
 | 最佳| 每个测试用例 O(log 100) | O(1) | O(1) | 被接受且优雅 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取百分比$k$。 
3. 计算最大公约数$g = \gcd(k, 100)$。 这确定了可以减少分子和分母的最大因素。 
4. 计算最小总升数：$100/g$。 这对应于最小的整数$e$和$w$满足比例。 
5. 打印测试用例的结果。 

为什么有效：通过减少分数$k/100$对于最低项，我们找到保持精确百分比的最小整数比率。 该约简分数的分子和分母之和给出了最小总体积。 没有更小的整数组合可以满足精确的比率，因为任何更小的和都会违反约简分数性质。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    k = int(input())
    g = math.gcd(k, 100)
    print(100 // g)
```该解决方案读取每个测试用例，计算最大公约数，并输出最小总体积。 整数除法的选择确保我们获得准确的升数。 Python 的内置`math.gcd`自动处理所有边缘情况，包括$k = 100$和$k = 1$。

 ## 边缘情况

 当$k = 100$，gcd 为 100，100/100 = 1，确认倒入一升就足够了。 什么时候$k = 1$，gcd(1,100) = 1，算法正确输出 100 升。 该公式自动处理 100 整除的百分比以及与 100 互质的百分比，保证所有边界条件下的正确性。
