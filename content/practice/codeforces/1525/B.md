 ## 解决方案
 ## 问题理解

 我们得到了以下数字的排列`1`到`n`。 在一个操作中，我们可以选择数组的任何连续段，并按照我们喜欢的方式重新排列该段内的元素。 唯一的限制是所选的段不能是整个数组。 

目标是确定将排列转换为排序顺序所需的此类操作的最少数量`[1, 2, ..., n]`。 

关键细节是重新排列选定的片段非常强大。 我们不限于掉期或逆转。 一旦选择了某个段，其内容就可以按任意顺序放置。 唯一的限制来自于该细分市场无法涵盖所有​​内容`n`职位。 

限制非常小。 数组长度永远不会超过50，最多有2000个测试用例。 即使是昂贵的计算也能轻松完成。 尽管如此，这个问题是围绕发现简单的结构观察而不是模拟操作而设计的。 

一些边缘情况很容易被忽略。 

考虑一个已经排序的排列：```
1 2 3 4
```答案是`0`， 不是`1`。 由于不需要任何工作，应用任何操作只会降低数组的排序程度。 

考虑：```
2 1 3 4
```答案是`1`。 粗心的解决方案可能会认为因为第一个元素错误，所以需要多次操作。 事实上，我们可以选择职位`[1,2]`并对它们重新排序。 

一个更微妙的情况是：```
4 2 3 1
```这里第一个元素不是`1`最后一个元素不是`n`。 答案是`3`。 许多解决方案错误地返回`2`。 原因是两端都放错了位置，属于两端的值也被困在了错误的地方。 事实证明，这是需要三次操作的独特情况。 

## 方法

 蛮力观点是考虑所有可能的片段以及这些片段的所有可能的重新排序。 由于片段可以任意重新排列，因此分支因子是巨大的。 即使是为了`n = 50`，枚举可能的状态是完全不可行的。 

这个问题有趣的部分是我们没有被要求构建操作。 我们只需要最小数量。 这表明寻找答案的特征而不是寻找答案。 

关键的观察是答案只能是`0`,`1`,`2`， 或者`3`。 

如果排列已经排序，那么答案显然是`0`。 

假设排列未排序。 如果第一个位置已经包含`1`或者最后一个位置已经包含`n`，那么一次操作就足够了。 我们可以选择数组的剩余部分并将其重新排列成正确的顺序。 

例如：```
1 4 3 2
```第一个位置已经是正确的。 我们可以选择职位`[2,4]`并对它们进行排序。 

现在考虑两端都不正确的情况。 

如果值`1`当前位于最后一个位置且值`n`目前处于第一个位置，那么答案是`3`。 这是端点可能最差的排列。 单个操作不能同时触及两端，因为整个阵列是被禁止的，并且固定一侧不会自动固定另一侧。 

在剩下的每种情况下，答案都是`2`。 两个端点都已不正确，但排列不在特殊的最坏情况配置中。 

这完全可以通过一些端点检查来确定答案。

 ## 算法演练

 1. 读出排列。 
2. 检查排列是否已排序。 

如果每个位置`i`包含`i + 1`，不需要任何操作，所以输出`0`。 
3. 检查第一个元素是否为`1`或者最后一个元素是`n`。 

如果任一条件成立，则输出`1`。 

原因是数组的其余部分形成了一个真子数组，可以自由地重新排列以完成排序。 
4. 检查第一个元素是否为`n`最后一个元素是`1`。 

如果两个条件都成立，则输出`3`。 

这是需要最大操作次数的独特配置。 
5.否则输出`2`。 

两个端点都不是正确的，但这种安排并不是最糟糕的安排，因此两次操作总是足够的。 

### 为什么它有效

 整个问题是由端点控制的。 

如果数组已经排序，则答案是`0`。 

如果一个端点已经正确，则其余位置形成有效的真子数组。 由于选定的子数组可以任意重新排列，因此一次操作就足够了。 

当两个端点都不正确时，单个操作无法对排列进行排序。 任何正确的子数组都会丢失至少一个端点，因此至少会保留一个不正确的端点。 

在这些个案中，安排`n`在开始时和`1`最后是最难的。 仅通过两次操作无法修复两个放错位置的极值，因为可能永远不会选择整个数组。 官方分析表明，这个配置正好需要三个操作。 

所有其他未排序的排列都属于剩余类别，并且可以通过两次操作来修复。 

由于这些情况是互斥的并且涵盖所有排列，因此该算法始终返回正确的最小操作数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if a == list(range(1, n + 1)):
            print(0)
        elif a[0] == 1 or a[-1] == n:
            print(1)
        elif a[0] == n and a[-1] == 1:
            print(3)
        else:
            print(2)

solve()
```第一个条件检查排列是否已经排序。 这必须在任何端点逻辑之前处理，否则排序排列，例如`[1,2,3]`会错误地匹配第二种情况并返回`1`。 

第二个条件检测一次操作就足够的情况。 我们只需要其中一个端点已经正确即可。 

第三个条件确定了唯一的最坏情况安排。 必须在前面的条件之后进行检查，因为排列`a[0] = n`和`a[n-1] = 1`无论如何都无法满足一操作条件。 

每个剩余的排列都属于二元运算范畴。 

小件无需特殊处理`n`是必须的。 该逻辑对于所有有效输入统一工作。

 ## 边缘情况

 考虑已经排序的排列：```
1
3
1 2 3
```该算法首先检查整个数组是否等于`[1,2,3]`。 确实如此，所以答案是`0`。 这可以防止数组错误地匹配一次操作的情况。 

考虑：```
1
4
1 4 3 2
```数组未排序，但第一个元素已经排序`1`。 算法返回`1`。 我们可以对子数组进行排序`[4,3,2]`直接因为它是一个真子数组。 

考虑：```
1
4
4 2 3 1
```数组未排序。 两个端点都不正确。 第一个元素等于`n`最后一个元素等于`1`，所以算法返回`3`。 这正是证明所确定的特殊的最坏情况配置。 

考虑：```
1
5
2 3 1 5 4
```数组未排序。 两个端点都不正确，但这不是最坏情况的安排。 算法到达最后一个分支并返回`2`，这是该类别的最小操作数。
