 ## 解决方案
 ## 问题理解

 我们得到了一套完整的方形拼图，排列在未知的 m × m 网格中。 每块碎片都由从 1 到 m² 的唯一数字来标识，并且对于每块碎片，我们都会获得四个指针，指示哪块碎片直接位于其北、南、西和东。 值 -1 表示在该方向上该棋子位于拼图的边界上。 

隐藏的结构是一个完美的网格：每块最多有四个与矩形平铺一致的邻居，整个配置形成一个一致的 m × m 排列。 任务是重建网格布局，即恢复每个块的位置并逐行打印最终矩阵。 

由于 m 可以大到 10³，因此约束最多允许 10⁶ 件。 任何解决方案都必须在片段数量上以线性时间运行，因为即使 O(n log n) 具有大量常量也是可以接受的，但任何类似重复图搜索或回溯放置的操作都会面临超时或内存压力的风险。 

天真的思维中的一个微妙问题是假设邻接指针可能形成循环或不一致。 他们没有。 每一块都属于一致网格中的一个单元，因此邻接结构定义了四个有向图，其行为类似于正交方向的链表。 

另一种常见的失败情况是尝试从任意节点开始重建而不保证它是角点。 如果我们选择一个非角点，我们无法确定网格原点，并且可能会错误地移动坐标。 

例如，假设我们从中间的图块 A 开始。向北走直到 -1 就可以了，但如果我们不向西对齐，我们可能会将 A 视为 (0, 0) 并产生负索引，而不会意识到真正的网格原点在其他地方。 正确的输出必须对齐，以便左上角是真正的边界单元，而不是任意起点。 

第二种边缘情况是 m = 1 的退化网格。在这种情况下，单片的所有四个方向均为 -1，并且必须直接输出而无需遍历。 

## 方法

 强力解释是将每个块视为图中的一个节点，并尝试通过重复选择未放置的节点并扩展约束直到固定所有位置来为其分配坐标。 人们可以模拟放置约束：选择一个图块，为其分配一个坐标，然后重复传播邻居约束，每次都检查一致性。 

这在概念上是有效的，因为每个邻接约束都固定相对位置。 然而，简单的实现可能会重复搜索未放置的邻居或扫描所有节点以查找匹配的邻接关系，从而导致 O(n²) 行为。 当 n 达到 10⁶ 时，这是不可行的。 

关键的观察结果是图结构已经完全有向且一致。 每个图块都直接指向其邻居，因此我们不需要搜索或匹配。 我们只需要选择一个有效的原点并执行一次遍历来分配坐标。 

关键的见解是边界结构定义了一个独特的坐标系。 任何没有北邻的瓷砖必须属于第一行，其中没有西邻的瓷砖必须属于左上角。 一旦找到这个锚点，所有其他图块都通过跟随东和南指针来唯一确定。 这将问题转化为线性遍历和坐标分配问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 通过重复搜索进行暴力传播 | O(n²) | O(n) | 太慢了|
 | 锚点+BFS/DFS坐标重建| O(n) | O(n) | 已接受 |

 ## 算法演练

我们将邻接指针视为有向网格图，其中每个节点都知道其邻居。 目标是将坐标分配给一致的整数网格中的每个节点，然后将它们标准化为基于 1 的矩阵。 

1. 扫描所有图块并找到没有北邻和西邻的唯一图块。 这是网格的左上角。 这些保证确保它存在并且是唯一的。 此步骤建立坐标原点，以便所有后续放置都一致。 
2. 创建从图块 id 到其 (x, y) 坐标的映射。 初始化一个队列并分配角块坐标(0, 0)，然后将其推入队列。 这开始了对隐式网格边缘的类似 BFS 的遍历。 
3. 当队列不为空时，弹出一个坐标为(x,y)的图块u。 对于其四个方向中的每一个，如果邻居存在（不是 -1）并且尚未分配坐标，则为其分配相对坐标：北为 (x − 1, y)，南为 (x + 1, y)，西为 (x, y − 1)，东为 (x, y + 1)。 将每个新分配的图块推入队列。 此步骤之所以有效，是因为邻接指针对精确的几何偏移进行编码。 
4. 遍历后，计算所有指定坐标的最小 x 和 y。 这允许标准化，以便最终输出空间中的左上角变为 (0, 0)。 
5. 通过减去 min_x 和 min_y 来移动所有坐标，然后将每个图块 id 放入其最终位置的大小为 m × m 的二维数组中。 
6. 逐行输出网格。 

正确性取决于每个图块都可以通过邻接指针从左上角到达，因此 BFS 只覆盖整个网格一次。 

### 为什么它有效

 邻接结构定义了连接网格图到 Z² 的一致嵌入。 每条边对应于四个方向之一的固定单位向量。 由于网格是简单连接的，并且每个节点都有一个有效的位置，因此一旦锚定一个节点，每个其他节点的位置就通过以下有向边唯一确定。 BFS 确保我们在没有冲突的情况下传播这些约束，并且唯一性保证没有图块被分配两个不同的坐标。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    m = int(input())
    n = m * m

    nxt = [None] * (n + 1)

    # store adjacency
    north = [0] * (n + 1)
    south = [0] * (n + 1)
    west = [0] * (n + 1)
    east = [0] * (n + 1)

    has_parent = [False] * (n + 1)

    for i in range(1, n + 1):
        a, b, c, d = map(int, input().split())
        north[i], south[i], west[i], east[i] = a, b, c, d
        if a != -1:
            has_parent[a] = True
        if c != -1:
            has_parent[c] = True

    start = -1
    for i in range(1, n + 1):
        if not has_parent[i] and north[i] == -1 and west[i] == -1:
            start = i
            break

    pos = {}
    pos[start] = (0, 0)
    q = deque([start])

    while q:
        u = q.popleft()
        x, y = pos[u]

        v = north[u]
        if v != -1 and v not in pos:
            pos[v] = (x - 1, y)
            q.append(v)

        v = south[u]
        if v != -1 and v not in pos:
            pos[v] = (x + 1, y)
            q.append(v)

        v = west[u]
        if v != -1 and v not in pos:
            pos[v] = (x, y - 1)
            q.append(v)

        v = east[u]
        if v != -1 and v not in pos:
            pos[v] = (x, y + 1)
            q.append(v)

    minx = min(x for x, y in pos.values())
    miny = min(y for x, y in pos.values())

    grid = [[0] * m for _ in range(m)]
    for k, (x, y) in pos.items():
        grid[x - minx][y - miny] = k

    for row in grid:
        print(*row)

if __name__ == "__main__":
    solve()
```该实现首先读取所有邻接信息并跟踪哪些节点被引用为邻居。 这允许检测候选边界，因为真正的左上角必须没有传入引用，并且必须明确没有北和西邻居。 

BFS部分是几何传播的直接编码。 每个分配都使用固定的偏移量，这可以防止歧义或需要回溯。 字典`pos`确保每个图块只分配一次。 

归一化是必要的，因为 BFS 坐标从任意原点 (0, 0) 开始，可能与最终的网格索引不对应。 移位将所有内容对齐到有效的 m × m 矩阵中。 

一个微妙的细节是，我们不仅仅依赖于“无父母”检测；而是依赖于“无父母”检测。 我们还要求北和西为-1，以确保我们选择真正的左上角而不是任何边界图块。

 ## 边缘情况

 单个图块情况立即分配坐标 (0, 0) 并输出 1×1 网格而无需遍历，因为不存在邻居。 

长的水平带确保从西向东的传播无需任何垂直移动； BFS 增量分配坐标，标准化保持排序一致。 

完整的边界丰富的网格测试起始图块的正确识别。 只有真正的左上角同时满足“无北邻”和“无西邻”，确保在其他边界单元中不会错误选择原点。
