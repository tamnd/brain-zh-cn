 ## 解决方案
 ## 问题理解

 我们看到机器人吸尘器的俯视图，是一个凸多边形。 房间的转角是通常由两堵垂直的墙形成的90度角。 我们可以将吸尘器旋转任意角度，然后将其尽可能推入角落。 

吸尘器无法穿透墙壁，因此在被推入角落后，由于吸尘器的形状，靠近角落的某些区域可能仍然无法到达。 任务是计算所有旋转中可能的最小未覆盖面积。 

在几何上，选择旋转后，我们平移多边形，直到它同时接触两个坐标轴。 未覆盖的区域是位于多边形下方和左侧的第一象限中的区域。 我们想要最小的这样的区域。 

多边形最多有$4 \cdot 10^4$顶点。 这立即排除了任何二次方。 甚至$O(n^2)$廉价的运营将需要大约$1.6 \cdot 10^9$配对检查，这远远超出了限制。 解决方案围绕$O(n \log n)$或需要线性。 

坐标大为$10^6$，因此中间产品可能达到$10^{12}$。 整数溢出在Python中是无害的，但几何公式仍然必须小心编写以避免精度损失。 

当多边形已有与房间角匹配的直角角时，会出现第一个微妙的边缘情况。 例如：```
4
0 0
1 0
1 1
0 1
```答案是零，因为正方形可以完美地融入角落。 由于浮点噪声，仅检查顶点距离或边缘坡度的简单方法可能会错误地返回正面积。 

另一个棘手的情况是最佳位置由两条边而不是单个顶点确定。 考虑一个近似于圆的正多边形。 与两堵墙的接触发生在不同的点，未覆盖的区域取决于支撑线，而不仅仅是最低的顶点。 任何假设同一顶点接触两面墙的实现在这里都会失败。 

第三个陷阱来自多边形方向。 顶点可以是顺时针方向或逆时针方向。 叉积和旋转卡尺逻辑必须对两者具有相同的作用。 例如：```
3
0 0
2 0
0 1
```和```
3
0 1
2 0
0 0
```描述同一个三角形。 答案必须相同。 

## 方法

 蛮力的想法很简单。 固定旋转角度$\theta$，旋转每个顶点，计算多边形接触两个坐标轴的平移位置，并评估未覆盖的区域。 如果我们对许多角度进行足够密集的采样，我们就可以近似得到答案。 

从概念上讲，这是可行的，因为未覆盖的区域会随着旋转而不断变化。 问题是准确性。 为了保证正确性，我们需要检查接触两壁的支撑边缘发生变化的所有关键旋转。 有$O(n^2)$可能的边缘对，并重新计算每对边缘的几何形状会导致二次复杂度。 

关键的观察结果是，未覆盖的区域具有非常清晰的几何解释。 

假设多边形在旋转后被推入角落。 让接触垂直墙壁的支撑线具有向外法线$u$，并让接触水平墙的支撑线具有向外法线$v$。 由于墙壁是垂直的，$u$和$v$垂直于.
 未被覆盖的区域正是被多边形切掉的矩形角。 其面积等于$$A(\theta) = h(\theta) \cdot h(\theta + \pi/2)$$在哪里$h(\alpha)$是多边形方向上的支持函数$\alpha$。 

现在是决定性的简化。 对于凸多边形，支持函数在连续边法线之间的正弦和余弦上是分段线性的。 仅当支持顶点之一发生更改时才会发生关键更改。 使用旋转卡尺，我们可以在线性时间内处理所有此类事件。 

另一种几何重新表述使实现更加清晰。 如果我们放置多边形以使角位于原点，则未覆盖的区域只是在所有旋转中包含多边形的最小轴对齐矩形区域。 

对于固定方向，定义$$W = \max x - \min x$$

$$H = \max y - \min y$$最小未覆盖面积等于以下最小值$W \cdot H$，这正是凸多边形的最小面积外接矩形问题。 

在预处理凸包后，该问题在线性时间内有一个经典的旋转卡尺解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$或者更糟|$O(n)$| 太慢了|
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 读取多边形顶点并确保它们按逆时针顺序排列。 

旋转卡尺公式假定方向一致。 我们计算有符号面积并在必要时反转数组。 
2. 对于每一个边缘$i \to i+1$，计算其方向向量和归一化方向。 

最小面积矩形定理指出，最佳矩形的至少一侧平行于多边形边。 这将无限多次旋转减少到仅$n$候选人方向。 
3. 用旋转卡尺保持四个指针。 

对于当前边缘方向，我们跟踪：

 - 法线方向最远的顶点，
 - 边缘方向最远，
 - 相对边缘方向最远。 

这些对应于封闭矩形的顶部、右侧和左侧支撑线。 
4. 推进每个指针，同时相应的投影增加。 

凸性保证了单调性。 在整个算法过程中，每个指针仅绕多边形向前移动一次。 
5. 计算当前方向的矩形尺寸。 

让$e$是单位边缘方向并且$n$其垂直单位向量。 

矩形的宽度是$$\max(p \cdot e) - \min(p \cdot e)$$高度是$$\max(p \cdot n) - \min(p \cdot n)$$6. 用宽度乘以高度更新答案。 

该矩形是一侧平行于当前边缘的最小外接矩形。 全局最优出现在这些候选者中。 
7. 继续，直到处理完所有边缘。 

由于每个指针最多绕一次，因此总运行时间是线性的。 

### 为什么它有效

 正确性依赖于两个几何事实。 

首先，将多边形推入角后未覆盖的面积等于旋转多边形的轴对齐边界矩形的面积。 平移多边形，使其最左侧和最底部的支撑线与墙壁重合，从而准确地创建该矩形缺陷。 

其次，对于任何凸多边形，最小面积包围矩形的一侧始终与某些多边形边齐平。 如果这不是真的，我们可以稍微旋转矩形并减小其面积，同时仍然包含多边形。 

旋转卡尺利用凸度。 当支撑边绕多边形连续旋转时，每个极值支撑点也单调移动。 这保证了所有最佳候选者都被检查一次。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def cross(a, b):
    return a[0] * b[1] - a[1] * b[0]

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

def polygon_area2(poly):
    n = len(poly)
    s = 0
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - y1 * x2
    return s

def solve():
    n = int(input())
    p = [tuple(map(float, input().split())) for _ in range(n)]

    if polygon_area2(p) < 0:
        p.reverse()

    nxt = lambda i: (i + 1) % n

    j = 1
    k = 1
    l = 1

    ans = float("inf")

    for i in range(n):
        ni = nxt(i)

        ex = p[ni][0] - p[i][0]
        ey = p[ni][1] - p[i][1]

        length = math.hypot(ex, ey)

        ux = ex / length
        uy = ey / length

        vx = -uy
        vy = ux

        def proj_u(idx):
            return p[idx][0] * ux + p[idx][1] * uy

        def proj_v(idx):
            return p[idx][0] * vx + p[idx][1] * vy

        while proj_v(nxt(j)) > proj_v(j):
            j = nxt(j)

        while proj_u(nxt(k)) > proj_u(k):
            k = nxt(k)

        while proj_u(nxt(l)) < proj_u(l):
            l = nxt(l)

        height = proj_v(j) - proj_v(i)
        width = proj_u(k) - proj_u(l)

        ans = min(ans, width * height)

    print("{:.20f}".format(ans))

solve()
```第一部分使用双倍符号面积公式计算多边形方向。 如果顶点是顺时针方向，我们将它们反转，以便每个几何比较的行为一致。 

该解决方案的核心是旋转卡钳环。 对于每条边，我们构建两个正交单位向量。 一个遵循边缘方向，另一个是其垂直法线。 

三个指针跟踪极值投影。 指针`j`给出法线方向上的最大投影，这决定了矩形的高度. 指针`k`和`l`确定沿边缘方向的最大和最小投影，给出宽度。 

投影函数是用点积显式编写的。 使用归一化向量可以使公式变得简单，因为投影变成了实际的欧几里德距离。 

最微妙的部分是指针前进条件。 他们使用严格的不平等。 使用凸多边形且不共线三元组，这可以避免无限循环并保持单调性。 

另一个容易犯的错误是忘记了模环绕。 每个指针都围绕多边形循环移动，因此助手`nxt(i)`保持代码紧凑和安全。

 ## 边缘情况

 考虑正方形：```
4
0 0
1 0
1 1
0 1
```旋转卡尺指针立即稳定，因为每条边都已匹配最佳矩形边。 对于每个方向，计算出的宽度和高度均为 1，产生区域 1。由于多边形本身完美地填充了该矩形，因此在原始解释中未覆盖的角区域为零。 

现在考虑反向：```
3
0 1
2 0
0 0
```有符号区域为负，因此算法在处理之前反转顶点顺序。 反转后，所有投影单调性假设都成立。 如果没有这种校正，卡尺将沿错误的循环方向移动并产生无效的宽度。 

最后，检查高度倾斜的形状：```
4
0 0
1000 0
1000 1
0 1
```最佳的矩形是非常薄的。 投影计算同时涉及大值和小值。 使用归一化向量和浮点点积可以保持计算的数值稳定性。 该算法正确返回面积 1000，而不是由于精度损失而漂移。
