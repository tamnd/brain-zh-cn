 ## 解决方案
 ## 问题理解

 我们被要求估计刺猬在接下来的时间内将收到的最少礼物数量`N`天。 他有两条规则来管理礼物的接待：每个假期他都会收到一份礼物，而且他去的次数不能超过`K`几天没有收到。 今天的礼物已经计算在内，所以我们只考虑第一天到`N`。 

输入给出`N`和`K`第一的。 然后我们被告知哪一天是假期。 目标是计算满足这两个约束所需的最小礼物数量。 输出是一个整数：这个最小数字。 

看看约束条件，`N`最大可达 365，这个尺寸相当小。 这意味着即使是一个粗略的算法`N^2`操作将在 2 秒内正常运行。`K`至多是`N`，因此我们必须以潜在的大间隙来规划礼物，但决不能超过`K`天。 假期是唯一且排序的，这简化了扫描。 

不明显的边缘情况包括以下情况：假期与已经收到礼物的日子重合，因为`K`天规则。 例如，如果`N=5`,`K=2`，假期是`[2,4]`，一种简单的简单方法`ceil(N/K)`并添加假期会重复计算重叠。 另一个棘手的情况是当`K`大于`N`; 那么最多可能需要一份非假日礼物。 

## 方法

 暴力方法会模拟每天从 1 到`N`，记录收到礼物的最后一天。 每天，我们都会检查是否是节假日或是否超过`K`距离上次的礼物已经过去很多天了。 如果任一为真，我们就会增加当前计数并更新最后一天。 这是有效的，因为它直接强制执行这两个约束，但即使`N`它很小，很冗长，没有必要每天都迭代。 

关键的见解是要认识到礼物的间距必须最多`K`相隔几天，但假期固定了某些日子。 因此，我们可以在节假日先贪婪地放置礼物，然后再填补它们之间的空白，这样就不会延伸了。`K`天数较少。 通过处理礼物之间的间隔（或从第 0 天到第一个假期、假期之间以及从最后一个假期到当天）`N`），我们可以使用简单的整数除法来计算需要多少额外的礼物。 

这将问题从日常模拟转变为区间分析。 对于任意长度的区间`L`，需要的礼物数量是`(L-1)//K + 1`如果`L > 0`。 这是有效的，因为每件礼物都涵盖`K`几天后； 该公式计算覆盖整个时间间隔的最小礼物数量。

 | ---| ---| ---| ---|
 | 暴力模拟| O(N) | O(N) | 可接受，但冗长 |

 ## 算法演练

 1. 阅读`N`,`K`，以及假期列表。 在假期列表前面添加一个 0 来表示“今天”，该日期已经有礼物了。 附加`N+1`作为哨兵来简化最后一个间隔的处理。 
2. 初始化计数器`presents`至 0。 
3. 迭代连续的假期对，`start`和`end`。 对于每个间隔`(start, end)`，计算礼物之间的天数为`end - start - 1`。 如果这个长度是正数，则使用以下公式计算礼物的最小数量`(length - 1) // K + 1`并将其添加到`presents`。 
4. 输出`presents`。 

为什么有效：不变的是每个假期都已经收到一份礼物，并且礼物之间的每个间隔都由公式涵盖，以尊重`K`- 天最大值。 每个间隔都是独立的，并且以这种贪婪的方式在间隔内添加礼物可以确保没有间隙`K`日子错过了。 不会重复计算，因为假期已经有礼物了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
line = list(map(int, input().split()))
C = line[0]
holidays = line[1:]

# Add today (day 0) and a sentinel after the last day
days = [0] + holidays + [N+1]
presents = 0

for i in range(1, len(days)):
    interval = days[i] - days[i-1] - 1
    if interval > 0:
        presents += (interval + K - 1) // K

print(presents)
```我们首先读取输入并将假期转换为日期列表。 前置第 0 天并附加`N+1`简化了边缘情况。 对于连续“当前日子”之间的每个间隔，我们使用上限除法计算所需的最少礼物，即`(interval + K - 1) // K`。 最后，打印总数。 精心的选择`interval = days[i] - days[i-1] - 1`避免包含/排除天数时经常出现的相差一错误。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    C = line[0]
    holidays = line[1:]
