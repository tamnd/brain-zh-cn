 ## 解决方案
 ## 问题理解

 我们被要求确定 Monocarp 杀死一组怪物所需的最少施法次数，每个怪物都有一定的生命值。 Monocarp 有两种法术：一种可以同时减少两种不同怪物的生命值，另一种可以立即杀死单个怪物。 目标是以尽可能少的施法次数杀死所有怪物的方式对这些法术进行排序。 

输入由多个测试用例组成。 对于每个测试用例，我们都会得到怪物的数量，然后是它们的健康值列表。 每个测试用例的输出是一个整数，即所需的最小咒语数量。 

限制相对较小：单个测试用例中的怪物数量最多为 100 个，所有测试用例中的怪物总数最多为 20,000 个。 这使得每个测试用例的算法可以舒适地运行大约 O(n^2)，但是任何接近 O(n^3) 的算法都可能开始变得低效。 每个怪物的生命值最多为 100，这表明依赖于排序、贪婪选择或基本算术操作的解决方案将有效运行。 

当怪物的生命值高度不平衡时，幼稚的方法可能会失败。 例如，如果我们有三个具有生命值的怪物`[1, 1, 100]`，贪婪地将两个怪物法术的前两个配对是有效的，但是在不考虑最大生命值的情况下反复尝试配对怪物可能会导致多次使用单个怪物法术，从而导致总计数不理想。 

## 方法

 暴力解决方案将尝试所有可能的法术施放序列：对于每对活着的怪物，我们可以应用双怪物法术，对于任何单个怪物，我们可以使用单怪物法术。 这将产生大量的状态，并且由于每个怪物最多可以有 100 点生命值，因此在最坏的情况下，潜在状态的数量约为 100^100。 这显然是棘手的。 

关键的见解是要认识到，当可以应用两只怪物的咒语时，它总是更有效。 每次施法都会使两个怪物的总生命值减少 2 点，而单个怪物的法术仅减少 1 点。 因此，最佳策略将始终尝试最大限度地利用两只怪物法术。 如果我们从整体健康角度思考，让`H`是所有怪物生命值的总和，让`M`是个体健康的最大化。 法术的最小数量受到两个事实的限制：每个法术最多减少 2 点生命值（对于两个怪物的法术），所以我们至少需要`ceil(H/2)`咒语； 而且，任何怪物都不能在少于`M`法术，因为在最坏的情况下，我们每次施法减少其生命值的速度不能超过 1。 因此，最少的总铸造次数为`max(ceil(H/2), M)`。 

这种见解立即导致每个测试用例的 O(n) 解决方案：计算运行状况值和最大运行状况的总和，然后取总和的一半（向上舍入）和最大运行状况的最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * H) | O(2^n * H) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 这设置了我们在多个场景中的循环。 
2. 对于每个测试用例，读取怪物的数量`n`。 
3. 阅读怪物生命值列表。 
4. 计算总和`total_health`所有健康价值观。 这代表了所需的“损害”总量。 
5. 找到最大生命值`max_health`所有怪物之中。 这确保了没有任何一个怪物的生命值超过施法次数。 
6. 计算`ceil(total_health / 2)`考虑到两个怪物的法术每次施法会减少两个生命值。 在整数运算中，这是`(total_health + 1) // 2`。 
7. 结果是`max(max_health, (total_health + 1) // 2)`。 这保证了两个约束都得到满足：我们有足够的演员来减少总生命值，并足以消除最强的怪物。 
8. 打印结果。 

为什么有效：两个约束——总健康状况和最大健康状况——抓住了系统的瓶颈。 没有任何算法可以使用比这两个限制更少的施法，因为双怪物法术减少总数的速度不能快于每次施法两点，并且如果怪物是唯一剩下的强大怪物，则任何怪物的死亡速度都不能快于每次施法 1 点生命值。 总是应用两个怪物法术直到只剩下一个的贪婪选择隐式编码在最大公式中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    h = list(map(int, input().split()))
    total_health = sum(h)
    max_health = max(h)
    result = max(max_health, (total_health + 1) // 2)
    print(result)
```该解决方案读取测试用例的数量，迭代每个测试用例，计算健康值的总和和最大值，然后计算结果。 使用`(total_health + 1) // 2`确保奇数总数的正确舍入。 该解决方案除了存储健康数组之外，还使用 ​​O(1) 的额外空间。

 ## 边缘情况

 如果只有一个怪物，答案等于它的生命值。 例如，`[100]`产生`100`。 该算法计算`max(100, ceil(100/2)) = 100`。 

如果所有怪物的生命值相同，例如`[5, 5, 5, 5, 5]`，总和为 25，`ceil(25/2) = 13`，最大值为 5，输出为 13。这正确地说明了通过两个怪物咒语有效地将怪物配对。 

如果一只怪物在总数中占主导地位，比如`[1, 100, 1]`，总和为 102，`ceil(102/2) = 51`，但最大值为 100。该算法正确输出 100，因为我们无法比 100 次施法更快地杀死最强的怪物。
