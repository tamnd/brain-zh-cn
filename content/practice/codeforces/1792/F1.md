 ## 解决方案
 ## 问题理解

 我们被要求计算给完整图的边缘着色的方法的数量$n$在非常特定的连接约束下，顶点恰好使用两种颜色：红色和蓝色。 完整的图意味着每个顶点都与其他每个顶点相连。 如果子集中的任何两个顶点通过仅由红色边组成的路径连接，则顶点子集是红色连接的，对于蓝色也是类似的。 着色必须确保大小为两个或更多的每个子集恰好以一种颜色连接，而不是两种颜色连接，并且每种颜色至少有一个边缘。 

输入是单个整数$n$，它定义了顶点的数量。 输出是有效边缘着色的总数模$998244353$。 自从$n$最多可以达到 5000，任何尝试枚举所有的算法$2^{n(n-1)/2}$边缘着色是完全不可行的。 为了$n=5000$，边数大致为$12.5 \times 10^6$， 和$2^{12.5\cdot10^6}$是一个天文数字。 这排除了暴力枚举。 

小例子揭示了微妙的限制。 为了$n=3$，有 3 个顶点和 3 个边。 每条边都可以独立着色，但我们必须避免所有三个边都是相同颜色的配置（这将使每个子集都是红色和蓝色连接的）。 忽略“恰好一种颜色连接”条件的天真计数将会过多计算解决方案。 

## 方法

 蛮力方法是考虑所有$2^{n(n-1)/2}$着色并检查大小为 2 或更大的每个子集的每种颜色的连通性。 这在原则上是正确的，因为它明确地强制执行规则，但在计算上是不可能的$n > 10$。 

关键的见解是“恰好一种颜色连接”条件极其严格。 如果任何子集以两种颜色连接，则着色无效。 这立即意味着层次结构：有效的着色对应于将顶点划分为簇，使得每个簇内的所有边都是相同的颜色，簇之间的所有边都是其他颜色。 按照这种观点，每个顶点相对于其他顶点存在三种可能性：它形成红色派系、蓝色派系或单个连接派系的一部分。 

组合简化源于有效着色数量等于的观察$2 \cdot 2^{\binom{n}{2}} - 2$，我们将所有颜色减去两种单色颜色，然后考虑对称性来选择哪种颜色是“主导”。 这是有效的，因为任何不完全单色的颜色都将满足“恰好一种颜色连接”条件。 这两种单色情况被排除，因为它们违反了至少有另一种颜色的一条边缘的规则。

 ## 算法演练

 1. 计算完整图中的边总数，即$n(n-1)/2$。 这定义了需要着色的边数。 
2. 计算$2^{\binom{n}{2}}$模数$998244353$考虑所有可能的颜色，忽略约束。 Python 的内置`pow`具有三个参数可以有效地处理模幂。 
3. 减去所有边缘均为红色或所有边缘均为蓝色的两个无效配置。 这确保了每种颜色至少有一个边缘。 
4. 返回取模结果$998244353$。 

原理：通过计算所有可能的边缘着色并减去两种单色情况，我们确保至少存在一条红色边缘和一条蓝色边缘。 在所有其他配置中都会自动满足“恰好一种颜色连接性”约束，因为如果子集未以一种颜色连接，则另一种颜色会自动提供连接性。 模运算保证了大数的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
total_edges = n * (n - 1) // 2
# total colorings minus the two monochromatic ones
answer = (pow(2, total_edges, MOD) - 2) % MOD
print(answer)
```解决方案从阅读开始$n$并计算边的总数。 使用`pow`具有三个参数的计算$2^{\binom{n}{2}}$模数$998244353$有效地避免整数溢出。 我们减去两个无效的全红和全蓝情况，并取模以确保结果非负。

 ## 边缘情况

 该算法正确处理允许的最小值$n=3$。 边的总数为 3，因此所有颜色减去两个单色边得到 6。对于最大$n=5000$，模幂可以防止溢出并有效地计算答案。 减 2 可确保遵守“每种颜色至少有一个边缘”规则，即使在`pow`由于模换行，返回一个小数。
