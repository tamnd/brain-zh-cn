 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，它只是一个包含来自的每个整数的序列$1$到$n$正好一次。 任务是使用特殊操作多次对此排列进行排序。 每个操作都允许我们选择两个数字，删除它们，然后在序列的开头插入较小的数字，在序列的末尾插入较大的数字。 目标是找到将排列转换为严格递增顺序所需的此类操作的最少数量。 

约束条件告诉我们$n$可以大到$2 \cdot 10^5$在所有测试用例中，最多$10^4$测试用例。 这排除了任何尝试模拟每个可能的操作或显式尝试每对元素的解决方案，因为即使每个测试用例采用二次方法也会太慢。 我们必须找到一个在每个测试用例的线性或接近线性时间内工作的解决方案。 

当排列已经排序、已经反转或者在末尾具有最大值或最小值时，就会出现边缘情况。 例如，如果排列已经排序为`[1,2,3]`，正确答案是`0`。 如果排列是`[3,2,1]`，该操作必须至少使用一次，将最大的元素移动到末尾，将最小的元素移动到开头。 如果粗心的解决方案不考虑第一个和最后一个元素相对于`1`和`n`。 

## 方法

 暴力方法将尝试贪婪地模拟操作。 人们可以尝试每一对可能的元素，计算结果数组，并继续递归直到排序。 虽然这种方法在理论上是正确的，但其复杂性是指数级的$n$，这对于$n$最多$2 \cdot 10^5$。 

优化的关键观察是每个操作都可以有效地将一个元素放置在开始或结束时的最终位置。 因此，我们只需要跟踪最小和最大元素的位置。 问题简化为检查末尾的元素序列：如果第一个元素是`1`或者最后一个是`n`，我们已经有了一个正确的边界。 如果第一个元素是`n`或者最后一个是`1`，它使序列变得复杂。 否则，可以通过计算第一个和最后一个元素与其排序位置的差异来推断最小操作数。 这种洞察力允许对每个测试用例进行恒定时间的评估。 

通过推理最小和最大元素的位置，我们可以将排列分为四种情况：已经排序、除了一个元素在错误的一端之外已排序、反转或完全未排序。 每种情况都有预定数量的操作：`0`,`1`,`2`， 或者`3`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和排列`p`。 
2. 检查是否`p[0]`是`1`和`p[-1]`是`n`。 如果两者都为真，则数组已经排序。 返回`0`。 
3. 检查是否`p[0]`是`n`和`p[-1]`是`1`。 如果两者都为真，则数组完全反转。 返回`3`因为我们需要通过至少两次操作来正确移动两端，再加上一次用于中间调整。 
4.如果有的话`p[0]`是`1`或者`p[-1]`是`n`， 返回`1`。 一次操作足以修复另一端。 
5.否则返回`2`。 第一个和最后一个要素并不到位，但都不是极端错误的。 两次操作足以将它们正确定位。 

保证正确性的不变量是每个操作将一个数字移动到其最终排序位置的极值。 通过仅分析第一个和最后一个位置，我们捕获了最小操作的所有场景，因为其余元素始终可以在这些计数中进行调整。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_max_sort():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        if p[0] == 1 and p[-1] == n:
            print(0)
        elif p[0] == n and p[-1] == 1:
            print(3)
        elif p[0] == 1 or p[-1] == n:
            print(1)
        elif p[0] == n or p[-1] == 1:
            print(2)
        else:
            print(2)

min_max_sort()
```该解决方案首先读取测试用例的数量并循环遍历每个测试用例。 仔细检查条件以尽量减少操作，并明确处理特殊的相反情况以避免计数不足。 所有检查都是恒定时间，并且读取排列是线性的，因此解决方案可以针对大输入进行适当扩展。

 ## 边缘情况

 当数组只有一个元素时，算法正确返回`0`因为不需要任何操作。 当数组完全反转时，比如`[n, ..., 2, 1]`，算法返回`3`，捕获重新定位两个极端所需的额外操作。 对于仅存在一个极值的数组，算法返回`1`。 所有其他情况均属于`2`- 操作类别，确保始终返回最少数量的操作。
