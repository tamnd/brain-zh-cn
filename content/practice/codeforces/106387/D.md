 ## 解决方案
 ## 问题理解

 我们正在研究一个配置问题，涉及固定数量的位置和两种类型的无法区分的对象。 有$2n$位置在一条线上，并且精确地$n$其中一些被标记为美国宝石，而其余的则被标记为美国宝石$n$是瑞典的石头。 所有有效的安排都是同样可能的。 

该问题询问第一个的概率$k$队列中的位置都是美国人。 换句话说，如果我们随机选择$n$的$2n$老虎机是美国的，我们希望这些选择中的一小部分位置$1$通过$k$保证跻身美国职位之列。 

输入由整数组成$n$和$k$，输出是表示为约简分数或有理数的概率值，具体取决于问题的输出格式要求。 从概念上讲，我们正在计算所有可能的展示位置中的有利展示位置。 

关键的组合约束是我们精确地选择$n$职位出$2n$，所以配置总数为$\binom{2n}{n}$。 困难在于前缀条件强制限制：第一个$k$职位必须包含在所选的美国职位集中。 

这引入了一个微妙的边界条件$k > n$。 如果需要的前缀位置多于可用的美国宝石，则概率恰好为零。 盲目应用二项式系数而不检查可行性的朴素组合公式将错误地产生非零值或未定义的组合。 

另一种边缘情况发生在$k = 0$。 在这种情况下，没有限制，因此概率必须恰好为 1。 任何在不处理空约束的情况下计算阶乘比率的实现都可能仍然有效，但如果不仔细构建，数字取消或除法逻辑可能会失败。 

## 方法

 暴力解释将枚举所有选择方法$n$美国的立场$2n$插槽，然后检查每个配置以查看是否有位置$1$通过$k$都被选中了。 这是正确的，因为它直接遵循概率的定义，即有利结果优于总结果。 然而，配置的数量是$\binom{2n}{n}$，呈指数增长$n$。 即使对于中等$n$，这变得不可行，因为枚举了大小的所有子集$n$从$2n$已经是数亿甚至更多的数量级了。 

关键的观察结果是，前缀约束仅影响固定第一个后剩余的美国职位数量$k$插槽。 如果第一个$k$已经被强制成为美国人了，那么我们只需要选择剩下的$n-k$其余的包括美国宝石$2n-k$职位。 这将有利计数减少为单个二项式系数$\binom{2n-k}{n-k}$。 

分母仍然是选择的方式总数$n$美国的立场$2n$，即$\binom{2n}{n}$。 因此，概率是两个组合量的简单比率。 

我们通过将问题简化为直接组合来完全避免暴力，通常使用阶乘或预先计算的二项式系数来计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举|$O(\binom{2n}{n})$|$O(1)$或者$O(\binom{2n}{n})$| 太慢了|
 | 组合公式|$O(n)$或者$O(1)$预处理后 |$O(n)$| 已接受 |

 ## 算法演练

 我们使用二项式系数及其比率来计算概率。 

1. 检查约束是否可行。 如果$k > n$，立即归零。 这是因为我们不能在前缀中强加更多的美国宝石，而不是总数。 
2. 计算有效配置总数，即$\binom{2n}{n}$。 这计算了所有精确放置的方法$n$美国石头之中$2n$职位不受限制。 
3. 计算有利配置的数量，即$\binom{2n-k}{n-k}$。 这来自修复第一个$k$作为美国人的立场并分配剩余的$n-k$其余的包括美国宝石$2n-k$插槽。 
4. 返回有利配置与总配置的比率。 如果问题需要一个不可约分数，请使用最大公约数步骤来约简。 

微妙的一点是我们从来没有明确地构建安排。 每个决策都被简化为对组合进行计数，从而避免了任何指数计数。 

### 为什么它有效

 美国宝石的每一种有效配置都对应于尺寸的一个子集$n$选自$2n$。 以第一个事件为条件$k$包含位置会从选择空间中删除这些位置，并统一减少可用槽的数量和所需选择的数量。 这保留了计数的一致性，因此概率变成了二项式系数的干净比率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

def comb(n, r):
    if r < 0 or r > n:
        return 0
    r = min(r, n - r)
    res = 1
    for i in range(1, r + 1):
        res = res * (n - r + i) // i
    return res

n, k = map(int, input().split())

if k > n:
    print(0)
else:
    total = comb(2 * n, n)
    good = comb(2 * n - k, n - k)

    g = gcd(good, total)
    good //= g
    total //= g

    print(good, total)
```该实现直接反映了组合推导。 辅助函数迭代计算二项式系数，以避免阶乘溢出和不必要的内存使用。 对称优化将环路长度减少到$\min(r, n-r)$，这使大值的计算保持稳定。 

可行性检查$k > n$防止对组合函数的无效调用，否则会产生无意义的结果。 最后的归约步骤确保分数以最简单的形式输出，这通常是概率形式输出所需要的。 

## 工作示例

 考虑$n = 3, k = 1$。 我们有$6$职位并选择$3$对于美国宝石。 配置总数为$\binom{6}{3} = 20$。 对于有利的配置，位置$1$一定是美国人，所以我们选择剩下的$2$美国上次的立场$5$, 给予$\binom{5}{2} = 10$。 

| 步骤| 价值|
 | --- | --- |
 | 全部的$\binom{2n}{n}$| 20 |
 | 有利$\binom{2n-k}{n-k}$| 10 | 10
 | 概率 | 1/2 | 1/2

 这表明固定前缀会减少有效选择空间，同时保持对称性。 

现在考虑$n = 2, k = 2$。 我们有 4 个位置，必须选择 2 个美国宝石。 如果前两个职位都必须是美国人，那么美国安置就没有剩余的选择。 

| 步骤| 价值|
 | --- | --- |
 | 全部的$\binom{4}{2}$| 6 |
 | 有利$\binom{2}{0}$| 1 |
 | 概率 | 1/6 | 1/6

 这证实了即使前缀完全确定了所有美国宝石，该公式仍然可以正常工作。

 ## 边缘情况

 对于$k > n$，比如输入$n = 3, k = 5$，该算法在任何组合之前立即返回零。 这避免了评估$\binom{2n-k}{n-k}$带有负参数，否则会产生不正确的结果。 

为了$k = 0$， 例如$n = 4, k = 0$，计算变为$\binom{8}{4} / \binom{8}{4} = 1$。 该算法自然地处理这个问题，无需超出二项式评估的特殊范围。 

为了$k = n$， 例如$n = 3, k = 3$，我们得到$\binom{3}{0} / \binom{6}{3}$，这恰好对应于一种有利的配置，其中所有美国宝石都占据前缀。
