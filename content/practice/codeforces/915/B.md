 ## 解决方案
 ## 问题理解

 我们有一个浏览器`n`编号为 1 到 1 的选项卡`n`。 鼠标当前位于选项卡上`pos`。 Luba 希望最终只得到该段中的选项卡`[l, r]`打开。 所有其他选项卡都需要关闭，目标是在最短的秒数内完成。 每一秒，Luba 都可以将光标向左或向右移动一个选项卡，或者关闭光标左侧或右侧的所有选项卡。 

输入给出四个整数：制表符总数、当前光标位置以及要保留的段的左右边界。 输出是将打开的选项卡减少到恰好该段的最短时间`[l, r]`。 

限制很小：`n`最多 100，所以即使算法`O(n)`每个操作的步骤是可以接受的。 这是一条重要的线索，因为它告诉我们可以推理每一个可能的移动或关闭，而不必担心效率。 光标开始于 1 和`n`， 和`[l, r]`是一个有效的子段。 

一个关键的微妙之处是，如果光标在内部开始`[l, r]`，我们可能不需要移动来关闭左侧或右侧选项卡。 另一个是当`[l, r]`包括第一个或最后一个选项卡； 在这种情况下，一侧不需要任何操作。 总是将光标移动到最近的边缘而不检查该侧是否确实有要关闭的选项卡的天真的方法可能会过度计算移动次数。 例如，如果`pos = 3`和`[l, r] = [1, 3]`，无需关闭左侧选项卡，因为它们已经是该段的一部分，因此向左移动是浪费的。 

## 方法

 思考这个问题的强力方法是模拟光标的每一个可能的移动和每一个可能的关闭操作。 在每个步骤中，您将检查秒数以及哪些选项卡保持打开状态。 虽然正确，但这很快就会变得很麻烦，而且即使`n`很小，没有必要每一秒都模拟。 暴力破解需要检查光标移动和关闭的多个路径，并且很容易陷入边缘情况，例如光标是否位于段的最左侧选项卡。 

关键的观察结果是，对于光标左侧或右侧的所有选项卡，关闭操作都是即时的。 因此，我们只需要考虑三件事：是否需要关闭左侧选项卡（之前的选项卡）`l`），是否需要关闭右侧选项卡（之后的选项卡`r`)，以及光标距每个边界的距离。 

如果光标已经在里面`[l, r]`，我们仅在必要时移动它以到达具有额外选项卡的一侧。 如果剩下的是`l`，我们必须向右移动到`l`关闭左侧选项卡。 如果是对的`r`，我们必须向左移动`r`关闭右侧选项卡。 总时间是光标移动加上最多两次关闭的总和：一次向左，一次向右。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢/太复杂|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`time`到 0。这将累计总秒数。 
2.如果保留最左边的选项卡，`l`，大于1，我们需要关闭左侧选项卡。 检查光标相对于的位置`l`。 如果`pos`是在左边`l`，将光标移至`l`。 该运动的秒数为`max(0, l - pos)`。 添加 1 秒以关闭左侧的所有选项卡。 更新`time`因此。 
3.同样，如果保留最右边的选项卡，`r`, 小于`n`，我们需要关闭右侧的选项卡。 如果`pos`是在右边`r`，将光标移至`r`。 移动成本为`max(0, pos - r)`。 添加 1 秒以关闭右侧的所有选项卡。 将这些秒添加到`time`。 
4. 处理双方都需要关闭的情况。 关闭侧面的顺序会影响移动成本。 最短总时间是首先移动到左边界以关闭左选项卡，然后移动到右边界以关闭右选项卡，或者反之亦然。 计算这两种情况并取最小值。 
5. 如果双方都不需要关闭（`l = 1`和`r = n`)，无需任何操作，时间保持为 0。 

为什么有效：每个选项卡都在外面`[l, r]`保证恰好关闭一次，并且光标仅移动所需的最小距离。 该算法从不计算额外的移动，因为它仅在必要时移动光标并在一秒钟内关闭整个段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, pos, l, r = map(int, input().split())

time = float('inf')

if l > 1 and r < n:
    # Both sides need closing, consider both orders
    move_left_then_right = abs(pos - l) + 1 + (r - l + 1 - (r - l + 1)) + (r - l) + 1
    move_right_then_left = abs(pos - r) + 1 + (r - l + 1 - (r - l + 1)) + (r - l) + 1
    # simpler: just compute minimal time directly
    time = min(abs(pos - l) + 1 + (r - l) + 1, abs(pos - r) + 1 + (r - l) + 1)
elif l > 1:
    time = abs(pos - l) + 1
elif r < n:
    time = abs(pos - r) + 1
else:
    time = 0

print(time)
```我们检查哪些方面实际上需要关闭。 如果双方都需要采取行动，我们会将先行动与`l`或者`r`因为顺序可以减少移动。 当只有一侧需要关闭时，我们直接移动到那里并关闭。 代码使用`abs(pos - l)`和`abs(pos - r)`以干净的方式计算移动成本。 使用`float('inf')`当需要考虑双方时可以轻松进行比较。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, pos, l, r = map(int, input().split())
    time = float('inf')
    if l > 1 and r < n:
        time = min(abs(pos - l) + 1 + (r - l) + 1, abs(pos - r) + 1 + (r - l) + 1)
    elif l > 1:
        time = abs(pos - l) + 1
    elif r < n:
        time = abs(pos - r) + 1
    else:
        time = 0
    return str(time)

# Provided samples
