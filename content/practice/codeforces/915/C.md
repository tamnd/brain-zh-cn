 ## 解决方案
 ## 问题理解

 我们有两个整数，`a`和`b`。 我们的任务是重新排列`a`产生不超过的最大可能数量`b`。 结果数字必须使用所有数字`a`恰好一次并且不能有前导零。 数字可能非常大，最多可达$10^{18}$，这意味着我们不能依赖具有固定位宽的数据类型，但 Python 本身可以处理任意长度的整数。 

关键限制是答案的位数必须与`a`，因此我们不能删除数字或添加前导零来调整其大小。 这排除了按降序对数字进行简单的贪婪排序，因为最大的排列可能超过`b`。 生成所有排列的简单实现是正确的，但效率极低，因为 18 位数字的排列数量可以达到$18! \approx 6 \times 10^{15}$。 

非明显的边缘情况包括以下情况`a`有重复的数字，其中第一个数字`b`小于第一个数字`a`，或者每一步存在多种选择，但只有一个序列产生有效数字。 例如，如果`a = 123`和`b = 213`，只需在每个位置选择最大的可用数字即可得到`321`，这是无效的。 正确答案是`213`，这需要从更高数字的失败尝试中进行回溯。 

## 方法

 蛮力方法是生成所有排列`a`并选择不超过的最大值`b`。 这是正确的，因为它显式枚举了所有有效的候选者，但复杂性是$O(n!)$， 在哪里$n$是数字的个数`a`。 对于最多18位数字，这种方法是完全不可行的。 

产生有效解决方案的关键观察是我们不需要生成每个排列。 我们可以从左到右逐位构建结果，保持两种可能性：要么我们严格低于`b`并且可以自由选择最大的剩余数字，或者我们完全匹配`b`到目前为止，必须选择不超过相应数字的数字`b`。 这自然会导致带有修剪的递归或深度优先搜索方法。 按降序对数字进行排序使我们能够在每一步快速选择剩余的最大有效数字。 

通过考虑中的每个数字`b`当一个选择导致没有有效的延续时，顺序地、仔细地回溯，我们保证我们构造的第一个有效的全长数字是最大的。 这将阶乘问题转换为可通过数字级递归管理的问题，其复杂性受数字平方数的限制，因为在每个位置我们最多尝试`n`数字和递归深度是`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 带剪枝的递归 DFS | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 两者都转换`a`和`b`到字符串`A`和`B`。 统计每个数字出现的频率`a`。 我们将逐步构建结果字符串。 
2. 如果长度为`a`小于的长度`b`，我们可以排序`a`的数字按降序排列并打印。 任何排列都会自动小于`b`。 
3. 如果长度相等，则定义一个递归函数`dfs(pos, tight)`在哪里`pos`是当前数字索引并且`tight`表示目前构建的数字是否等于前缀`b`。 我们从`pos = 0`和`tight = True`。 
4. 在每个位置，迭代从 9 到 0 的数字。如果该数字在我们的频率计数中可用并且不违反`tight`，选择它。 减少其计数并递归地前进到下一个位置。 如果递归成功，则将所选数字附加到结果中。 
5. 如果`tight`为 True，我们只允许小于或等于的数字`B[pos]`。 如果`tight`为 False，则按降序排列的任何剩余数字均有效。 
6. 如果某个位置没有数字有效，则通过恢复数字计数并尝试下一个较小的数字来回溯。 
7. 当所有位置都填满后，将所选数字连接起来并输出结果。 

工作原理：该算法保持一个不变式，即到目前为止选择的所有数字都形成一个有效的前缀，不超过相应的前缀`b`。 通过按降序探索数字并在必要时回溯，保证构造的第一个完整数字是最大有效排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A = input().strip()
    B = input().strip()
    n = len(A)
    m = len(B)

    if n < m:
        print("".join(sorted(A, reverse=True)))
        return

    from collections import Counter
    count = Counter(A)
    result = []

    def dfs(pos, tight):
        if pos == n:
            return True
        limit = int(B[pos]) if tight else 9
        for d in range(limit, -1, -1):
            if count[str(d)] > 0:
                count[str(d)] -= 1
                result.append(str(d))
                if dfs(pos + 1, tight and d == limit):
                    return True
                result.pop()
                count[str(d)] += 1
        return False

    dfs(0, True)
    print("".join(result))

if __name__ == "__main__":
    solve()
```该解决方案首先检查以下简单情况：`a`位数少于`b`。 我们使用计数器来跟踪可用数字，并按降序递归选择数字，修剪超出的任何路径`b`。 回溯确保我们可以在必要时探索替代数字。
