 ## 解决方案
 ## 问题理解

 我们有一个机器人在一个矩形房间内移动$n$行和$m$列。 机器人从某个单元开始$(r_b, c_b)$并沿对角线移动：一次向下一步，向右一步。 房间有墙壁，因此每当机器人越过边界时，它就会从边界上“反弹”，沿该轴反转其方向。 除了移动之外，机器人每秒都会清理当前行和列中的所有单元格。 目标是确定机器人清洁单个脏单元所需的时间$(r_d, c_d)$。 

输入给出了多个测试用例，每个测试用例指定房间大小、机器人的起始位置和脏单元位置。 输出是机器人首次清洁脏单元的时间（以秒为单位）。 

限制很小：$n, m \le 100$直至$10^4$测试用例。 这意味着我们可以一步一步地模拟机器人的运动，因为即使在最坏的情况下，每个测试用例在机器人重新访问之前的位置和方向之前最多将涉及200步左右。 不需要大规模的优化； 边界的正确性和谨慎处理更为重要。 

需要注意的边缘情况包括机器人在与脏单元格相同的行或列中开始的情况，这应该产生时间为零。 另一个微妙的情况是当脏单元位于角落时，如果边界处理不小心，这可能会与单个模拟步骤中的多个方向反转一致。 

## 方法

 暴力方法是模拟机器人运动的每一秒，根据当前方向更新行和列，必要时从墙壁反射，并检查当前行或列是否与脏单元格匹配。 这有效是因为$n$和$m$很小。 对于每个测试用例，机器人永远不会需要超过$2(n-1) + 2(m-1)$沿着对角线图案到达脏细胞的步骤。 因此，暴力方法在这里是可以接受的。 

一个关键的见解是，我们不需要跟踪机器人的整个路径，只需跟踪它的位置和运动方向。 每一步都是确定性的，机器人会清理当前位置的整个行和列，因此我们只需检查当前行或列是否与脏单元格匹配。 反射逻辑很简单：如果下一行超出房间限制，我们翻转垂直方向； 如果下一列超出房间限制，我们会翻转水平方向。

 | ---| ---| ---| ---|
 | 蛮力 | 每个测试用例 O(n + m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 循环每个测试用例。 
2. 对于每个测试用例，读取房间尺寸$n$和$m$, 机器人的初始位置$(r_b, c_b)$，和脏细胞$(r_d, c_d)$。 
3. 初始化机器人的运动方向为$(dr, dc) = (1, 1)$。 
4. 初始化一个定时器变量`time = 0`。 
5. 当机器人尚未清理脏单元时循环：

 1. 检查机器人当前行是否`r_b`等于`r_d`或其当前列`c_b`等于`c_d`。 如果是这样，请中断循环，因为脏电池已被清洁。 
2. 计算下一行`next_r = r_b + dr`和下一栏`next_c = c_b + dc`。 
3.如果`next_r`将超出房间边界（小于 1 或大于$n$）， 撤销`dr`并重新计算`next_r`。 
4.如果`next_c`将超出房间边界（小于 1 或大于$m$）， 撤销`dc`并重新计算`next_c`。 
5. 更新机器人的位置为`(r_b, c_b) = (next_r, next_c)`。 
6. 增量`time`一个。 
6. 输出`time`对于当前的测试用例。 

工作原理：在每一步中，机器人要么沿对角线移动，要么从墙壁反射，这保证了它最终到达与脏单元相交的行或列。 由于房间是有限的并且运动是周期性的，因此机器人无法在不清洁脏单元的情况下进入无限循环。 每一秒精确对应一个移动步骤，因此计时器会跟踪清洁之前的秒数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def robot_cleaner():
    t = int(input())
    for _ in range(t):
        n, m, r_b, c_b, r_d, c_d = map(int, input().split())
        dr, dc = 1, 1
        time = 0
        while r_b != r_d and c_b != c_d:
            if r_b + dr < 1 or r_b + dr > n:
                dr = -dr
            if c_b + dc < 1 or c_b + dc > m:
                dc = -dc
            r_b += dr
            c_b += dc
            time += 1
        print(time)

robot_cleaner()
```在解决方案中，`dr`和`dc`跟踪垂直和水平方向。 如果机器人要穿过墙壁，操作顺序可确保在移动之前翻转方向。 while 循环检查机器人在移动之前是否已经清理了脏单元。 这可以避免计算秒数时出现差一的错误。
