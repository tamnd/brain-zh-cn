 ## 解决方案
 ## 问题理解

 我们被要求构造一个从 1 到 n 的数字排列，其内部位置恰好有一个局部最大值和 b 个局部最小值。 局部最大值是比其直接邻居大的数，局部最小值是比其直接邻居小的数。 第一个和最后一个元素永远不会被视为局部极值，因为它们只有一个邻居。 

输入是 t 个测试用例，每个测试用例都有三个整数 n、a 和 b。 我们必须输出满足最大值和最小值计数的有效排列，或者如果不存在这样的排列则输出 -1。 

限制因素很重要。 n 可以大到 10^5，所有测试用例的 n 总和为 10^5，因此每个测试用例的 O(n log n) 或 O(n) 解决方案是可以接受的，但类似 ​​O(n^2) 的解决方案太慢了。 此外，给定 n 时，a 和 b 必须是可实现的。 生成所有排列的简单方法的复杂度为 O(n!)，这显然是不可行的。 

需要注意的边缘情况包括请求的波峰和波谷数量对于数组长度来说太大的情况。 例如，如果 n=4，并且我们要求 a=2 最大值和 b=1 最小值，这是不可能的，因为长度为 4 的数组中内部极值的最大数量为 2，峰谷交替。 另外，如果 a 或 b 为零，我们需要正确处理中间严格递增或递减的序列。 

## 方法

 蛮力方法是生成数字 1 到 n 的所有排列，并计算每个排列的峰和谷的数量。 虽然原则上是正确的，但复杂度为 O(n!)，并且当 n > 10 时永远不会完成。即使对于较小的 n，排列的数量也会呈阶乘增长，因此立即排除这种情况。 

关键的见解来自于对峰谷自然交替的观察。 每个内部元素可以是峰、谷或单调序列的一部分。 峰或谷的最大数量受到我们可以拥有的交替位置数量的限制，对于阵列中间的峰或谷来说，其为⌊(n-1)/2⌋。 一旦我们知道了这一点，我们就可以贪婪地构建排列：将最大的数字放在我们想要峰值的位置，将最小的数字放在我们想要山谷的位置，按顺序填充剩余的数字。 这会在线性时间内产生排列，而无需检查所有可能性。 

通过交替高数和低数，我们可以保证每个峰值都大于相邻的值，每个谷值都小于相邻的值。 我们还必须检查 a + b ≤ n - 2，因为内部位置仅限于索引 2 到 n-1。 如果请求超出此界限，则排列是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 贪婪构造| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.首先检查请求是否可行。 如果 a + b > n - 2，则没有足够的内部位置来满足这两个计数，因此立即输出 -1。 

2.初始化一个空数组`p`长度 n. 我们将其填充为三部分：峰值、谷值和剩余数字。 

3.维护两个指针：`low = 1`为最小的可用数，并且`high = n`对于最大的。 这些将用于分配数字以确保峰值和谷值。 

4. 如果 a ≥ b，我们从峰值模式开始。 将数字在高低之间交替放置，从高点表示峰，然后低点表示谷，直到放置所有 a 峰和 b 谷。 剩余元素的数量为 n - (a + b + 1)。 

5. 如果 b > a，则从山谷模式开始。 从低开始，然后是高，交替放置数字，直到放置所有的谷和峰。 

6. 根据需要按升序或降序填充剩余位置的数字，以避免产生额外的峰或谷。 

7. 输出最终数组。 这准确地保证了 a 峰和 b 谷。 该算法依赖于以下不变量：每个峰值比其相邻峰值获得更大的数字，而每个谷值比其相邻峰值获得更小的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        if a + b > n - 2 or abs(a - b) > 1:
            print(-1)
            continue

        p = [0] * n
        low, high = 1, n
        idx = 0

        # Determine starting pattern
        if a >= b:
            # start with peak
            for i in range(a + b + 1):
                if i % 2 == 0:
                    p[idx] = high
                    high -= 1
                else:
                    p[idx] = low
                    low += 1
                idx += 1
        else:
            # start with valley
            for i in range(a + b + 1):
                if i % 2 == 0:
                    p[idx] = low
                    low += 1
                else:
                    p[idx] = high
                    high -= 1
                idx += 1

        # Fill remaining numbers
        for i in range(low, high + 1):
            p[idx] = i
            idx += 1

        print(' '.join(map(str, p)))

if __name__ == "__main__":
    solve()
```第一部分检查可行性，包括峰值和谷值相差不能超过 1 的微妙约束，否则不可能交替。 下一部分构建峰和谷的交替序列。 如果峰多于谷，我们选择从峰开始，以确保正确的交替。 其余数字按递增顺序排列，以防止出现额外的极值。 该顺序保留了所有预期的峰和谷。
