 ## 解决方案
 ## 问题理解

 我们被要求确定，对于锦标赛中的每个玩家，如果锦标赛以最佳方式进行，他们是否有可能获胜。 有两张地图，每个玩家在两张地图上都有自己的优势。 当两名玩家在选定的地图上战斗时，该地图上实力较高的玩家总是获胜。 在同一张地图上没有两个玩家的实力相同，因此每场战斗都有明显的胜者。 

锦标赛包括重复选择任意两名剩余玩家并让他们在任意地图上进行战斗，淘汰失败者，直到剩下一名玩家。 对于每个玩家，我们需要决定是否存在一系列战斗可以让他们成为最终的胜利者。 输出是一个长度的字符串$n$，如果玩家可以获胜则为“1”，否则为“0”。 

约束意味着$n$可以达到$10^5$所有测试用例的总计。 这排除了任何模拟所有可能的战斗序列的方法，因为这可能是因素$n$。 相反，我们需要线性或近线性算法。 

不明显的边缘情况包括单人锦标赛，该玩家微不足道地获胜，以及玩家的优势使得没有一个玩家主宰两张地图的情况，如果多名玩家避免在自己的强地图上与更强大的对手直接对抗，那么他们就有机会。 例如，有两名玩家：地图 A 上的优势$[2,1]$和地图B$[1,2]$，双方都可以获胜，具体取决于比赛顺序，因此输出应该是“11”。 

## 方法

 暴力方法是模拟每一种可能的战斗序列。 我们会挑选每对可能的对和地图，传播获胜者，并检查玩家是否可以进入决赛。 这种方法原则上是正确的，但需要检验$O(n!)$序列为$n$玩家，这是不可能的$n$最多$10^5$。 

关键的见解是锦标赛的结果受到两张地图的统治地位的限制。 在两张地图上都比其他玩家弱的玩家永远无法获胜，因为最终他们将面对更强的玩家，无论选择什么地图都会输。 相反，任何在两张地图上都不被其他人控制的玩家都有可能被精心策划，直到最后才避开更强大的对手，从而使他们成为可能的赢家。 

为了使其具体化，请考虑二维强度$(a_i, b_i)$每个玩家的。 我们可以通过按一张地图对玩家进行排序，然后跟踪迄今为止看到的另一张地图中的最大实力来确定最小的“统治边界”。 如果两张地图上都存在更强的玩家，那么该玩家就有可能被淘汰。 任何在这个主导盘之外的玩家都可以成为胜利者。 

这将问题简化为排序和对玩家的线性扫描，时间复杂度为$O(n \log n)$每个测试用例而不是阶乘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和力量数组$a$和$b$。 将它们组合成对$(a_i, b_i, i)$保留原始索引。 
2. 按升序对对进行排序$a_i$。 如果两个玩家有相同的$a_i$, 排序依据$b_i$下降。 这确保了当我们从左到右扫描时，我们只需要跟踪当前的最大值$b$。 
3. 初始化变量$max_b$到$-\infty$。 这将跟踪最高的$b$到目前为止按排序顺序看到的值。 
4. 初始化长度为零的结果数组$n$。 
5. 迭代排序后的玩家列表。 对于每个玩家$(a, b, idx)$：

- 如果$b \ge max_b$，将result[idx]标记为1，因为在两张地图中都没有之前扫描到的玩家支配该玩家。 
- 更新$max_b$至最大$max_b$和$b$。 
6. 扫描完所有玩家后，将结果打印为字符串。 

为什么它有效：排序依据$a$并在扫描的同时跟踪最大值$b$保证我们能够识别出在两张地图上都占主导地位的玩家。 任何在这次检查中幸存下来的玩家都至少有一个维度，他们不会被任何更强大的玩家统治，这意味着存在一系列巧妙的战斗，他们可以避免被淘汰直到最后。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        players = [(a[i], b[i], i) for i in range(n)]
        players.sort()  # sort by a ascending

        res = [0] * n
        max_b = -1
        for pa, pb, idx in players:
            if pb >= max_b:
                res[idx] = 1
            max_b = max(max_b, pb)
        print("".join(map(str, res)))

if __name__ == "__main__":
    solve()
```该解决方案首先有效地读取所有输入。 玩家与其原始索引组合成元组，以按输入顺序生成输出。 排序依据$a$确保当我们检查时$b$，我们只需要保持跑动最大值就可以判断一个玩家在两张地图中是否都占主导地位。 这可以自然地处理边界和边缘情况，例如单个玩家或具有优势的玩家在两张地图中形成交叉模式。
