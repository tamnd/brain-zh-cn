 ## 解决方案
 ## 问题理解

 我们被要求为每个测试用例构造一个递增的整数序列，并对连续元素有特定的限制。 该序列必须严格递增，并且每个下一个元素都不能被前一个元素整除。 我们可以自由选择任何有效的构造，只要它尊重这两个约束并保持在最多 10 亿的范围内。 

输入大小很小，因为每个测试最多有 1000 个元素，并且测试的总数最多为 10,000 个。 这意味着我们不需要复杂的数据结构或繁重的预处理。 每个测试用例以线性时间运行的任何解决方案都足够快。 

主要的结构约束是邻居之间的可分性条件。 像连续整数这样的朴素递增序列会立即失败，因为在某些情况下，每个整数都可以被它的前一个整数整除，特别是在小心地逐步遍历倍数时。 同样，简单的算术级数也是有风险的，因为它们经常引入可预测的整除模式。 

边缘情况很少，但在概念上很重要。 当n等于1时，允许范围内的任何值都是可接受的。 当 n 较大时，构造必须避免意外引入 a_{i} = k * a_{i-1} 的对。 例如，如果我们选择 2 的幂，如 1、2、4、8，则条件完全失败，因为每个元素都可以除下一个元素。 这说明仅仅“增加”是不够的，必须积极打破乘法结构。 

## 方法

 暴力方法会尝试一次构建一个元素的序列。 对于每个候选的下一个值，我们将测试所有大于前一个值的整数，直到找到一个不能被它整除的整数。 这是正确的，因为它明确地强制执行约束，但它变得昂贵，因为在最坏的情况下，我们可能会扫描数轴的大部分来查找每个位置，从而在最坏的情况下导致二次行为。 

关键的观察是，如果我们确保连续数字以简单的结构方式互质，那么整除性就变得微不足道了。 我们可以通过构造来强制它，而不是试图动态地避免可分性。 标准技巧是以受控递增模式交替奇偶校验。 如果我们选择一个基值并在一种模式中添加小的偏移量，以确保没有元素是前一个元素的倍数，那么我们可以在不进行检查的情况下保证正确性。 

一个特别简单的构造是从一个大的恒定间隙开始，并以确保严格增加同时打破整除性的方式添加索引。 一个干净的想法是输出序列：

 a_i = 1000 * i + 1

 这保证了立即严格增加，因为连续项之间的间隙恰好是 1000。更重要的是，a_i 模 a_{i-1} 永远不会为零，因为连续项不是彼此的倍数：差值是固定的，但由于 +1 偏移，比率不是整数。 任何将 a_i 除以 a_{i-1} 的尝试都会失败，因为 a_{i-1} 不能均匀地拟合到偏移量为 1 的线性级数中。 

蛮力通过本地搜索来工作，但是观察到我们可以嵌入具有故意偏移的固定算术结构，从而消除了所有搜索需求。

 ## 算法演练

 我们直接为每个测试用例构建数组。 

1. 对于给定的 n，从 1 迭代到 n。 
2. 对于每个索引 i，计算值 a_i = 1000 * i + 1。 
3. 将每个计算值附加到输出序列。 
4. 打印序列。

选择1000的原因纯粹是为了方便。 任何大于 n 的常数都可以，但 1000 在约束下是安全的，因为 n ≤ 1000。+1 移位确保序列结构中没有元素是另一个元素的精确倍数。 

### 为什么它有效

 构造的序列是严格递增的，因为每一项都比前一项恰好增加 1000。 可整性条件不成立，因为对于任何连续的对，比率

 a_i / a_{i-1} = (1000i + 1) / (1000(i-1) + 1)

 不能是整数。 分子和分母相差 1000，但 +1 偏移量确保不会产生整数比。 因此，没有任何元素可以整除下一个元素，并且满足所有约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        res = []
        for i in range(1, n + 1):
            res.append(str(1000 * i + 1))
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于直接构建。 该循环在恒定时间内生成每个项，并且每个测试用例打印一次。 

重要的实现细节是在打印之前使用字符串累积。 循环内的打印仍然会通过给定的约束，但批处理输出可以避免不必要的开销。 

选择常数 1000 是为了确保即使对于最大 n，所有值也保持在 10^9 限制内，因为 1000 * 1000 + 1 等于 1,000,001，这是安全的。 

## 工作示例

 ### 示例 1

 输入：

 n = 1

 | 我| a_i |
 | ---| ---|
 | 1 | 1001 | 1001

 该序列仅包含一个元素，因此所有约束条件均得到满足。 不需要进行整除性检查。 

这证实了构造仍然产生有效单元素数组的边界情况。 

### 示例 2

 输入：

 n = 4

 | 我| a_i |
 | ---| ---|
 | 1 | 1001 | 1001
 | 2 | 2001 |
 | 3 | 3001 | 3001
 | 4 | 4001 | 4001

 每一步增加 1000。我们检查连续的对：

 1001 不能整除 2001，因为 2001 / 1001 不是整数。 

同样，2001 不能整除 3001，3001 不能整除 4001。由于 +1 偏移量破坏了与倍数的对齐，因此每对都无法整除。 

这表明该构造始终避免了整个序列中的意外多次出现。

 ## 边缘情况

 对于 n = 1，该算法生成单个值 1001。没有邻接约束，因此正确性仅取决于范围有效性，由于 1001 远低于 10^9，因此可以满足范围有效性。 

对于 n = 2，输出为 1001 和 2001。第二个不能被第一个整除，因为 2001 除以 1001 不是整数。 该结构保证了这一点，因为两个数字相对于 1000 的倍数共享固定偏移量 +1，从而防止对齐。 

对于较大的 n（例如 n = 1000），最后一个值为 1,000,001。 这仍然在范围内，并且每个连续的对都保留相同的结构，因此无论位置如何，邻居之间都不会出现可分关系。
