 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，我们的目标是将其分成两个非空数组，`b`和`c`，使得其中没有元素`c`将任意元素除以`b`。 每个元素必须恰好进入一个数组。 如果这是不可能的，我们返回`-1`。 

约束条件告诉我们`n`，数组的长度最多为 100，每个元素最大可以为$10^9$。 这意味着我们不能依赖于迭代每个元素的所有除数，因为如果简单地实现的话可能会太慢。 测试用例数量`t`最多可达 500，因此解决方案为$O(n^2)$每个测试用例是可以接受的，因为$500 \cdot 100^2 = 5 \cdot 10^6$操作可在 1 秒内完成。 

边缘情况包括所有元素都相同的数组。 例如，`[2, 2, 2]`无法拆分，因为其中的任何元素`c`将除以任何元素`b`。 最小元素所在的数组`1`很有趣，因为`1`划分一切，所以它必须在`b`以避免琐碎的分裂问题，否则分裂可能是不可能的。 

## 方法

 暴力方法会尝试将数组的每个分区分成两个非空集合并检查除数条件。 有$2^n - 2$非空分区，即$2^{100} - 2$在最坏的情况下，显然是不可行的。 

关键的见解是我们不需要测试每个分区。 分割数组的唯一障碍是所有数字是否相同，因为这样的每个选择`c`将所有数字除以`b`。 否则，如果至少有一个数字小于其他数字，我们可以将最小的数字分成一个数组，其余的分成另一个数组。 具体来说，我们可以对数组进行排序并将第一个元素放入`b`并将所有剩余元素放入`c`。 那么，其中没有元素`c`将把元素分为`b`如果最小的数字是唯一的。 如果最小的数字出现多次，我们仍然可以分配一份给`b`其余的到`c`不违反除数条件，因为如果我们小心地放置重复项，一个数字就不能将自己整除到另一个数组中。 

这将问题简化为简单地检查所有数字是否相同。 如果是，则输出`-1`; 否则，拆分为一个元素`b`其余的在`c`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和数组`a`。 
3. 检查所有元素是否`a`是相同的。 如果是，则打印`-1`并继续下一个测试用例。 
4. 否则，排序`a`轻松挑选最小的元素。 将第一个元素放入数组中`b`以及数组中所有剩余的元素`c`。 
5. 打印长度`b`和`c`接下来是每个数组的内容。 

为什么它有效：满足除数条件是因为`b`包含最小元素`a`。 中的任何其他元素`c`大于或等于，并且如果至少有一个不同的数，则不能将较小的数整除`b`。 排序确保我们可以直接识别最小的元素，并保证有效的分割，而无需迭代所有对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    if all(x == a[0] for x in a):
        print(-1)
        continue
    
    a.sort()
    b = [a[0]]
    c = a[1:]
    
    print(len(b), len(c))
    print(*b)
    print(*c)
```该代码首先使用以下方法有效地处理多个测试用例`sys.stdin.readline`用于快速输入。 它显式检查全相等的情况，然后对数组进行排序以进行简单的分割。 使用解包运算符`*`整齐地打印数组。 排序是安全的，因为`n`很小，可以确保我们正确处理重复项，而不需要复杂的逻辑。

 ## 边缘情况

 对于`[2, 2, 2]`，所有元素都是相同的。 支票`all(x == a[0] for x in a)`触发、返回`-1`。 为了`[1, 1000000000]`, 最小元素`1`进入`b`和大元素`c`，满足条件，因为 1000000000 不能整除 1。`[5, 10, 15, 20]`，将 5 放入`b`其余的在`c`确保没有元素`c`划分`b`错误地，因为 10、15 和 20 是 5 的倍数，但只有最小的在`b`。
