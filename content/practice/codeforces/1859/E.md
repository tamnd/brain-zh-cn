 ## 解决方案
 ## 问题理解

 我们有两个长度的数组$n$,$a$和$b$。 对于任何连续的子数组或段，由其开始定义$l$并结束$r$，我们可以使用公式计算“成本”$|b_l - a_r| + |b_r - a_l|$。 目标是选择总长度总和恰好为的非重叠段$k$，并最大化分段成本的总和。 

这个问题很微妙，因为段成本取决于段的两端和两个数组。 例如，取单个元素段$[i, i]$产量$|b_i - a_i| + |b_i - a_i| = 2|b_i - a_i|$。 选择较长的线段会引入交叉项$|b_l - a_r|$和$|b_r - a_l|$，并且优化必须平衡选择高成本段与总长度约束$k$。 

限制条件适中：$n$最多可达 3000，所有的总和$n$跨测试用例也最多 3000 个。这排除了$O(n^3)$算法，它将尝试每个可能的组合的每个分段，因为$3000^3$大约是 270 亿次操作。 一个$O(n^2)$或者$O(nk)$方案是可行的，2秒内900万次操作是可以接受的。 

当长度为 1 的段是最佳时，会出现不明显的边缘情况，因为较长的段会产生较小的交叉项贡献。 例如，如果$a = [1, 3]$和$b = [4, 2]$和$k=2$，最佳选择可能是两个长度为 1 的段，而不是一个长度为 2 的段。粗心的实现仅检查长段会错过最大值。 

另一个边缘情况是当数组$a$和$b$是平等的。 那么所有单元素成本都为零，有时所有多元素段也产生零成本，如第一个示例所示。 我们的算法必须正确处理零成本段，而不假设正成本。 

## 方法

 蛮力方法会尝试总长度为的非重叠段的每种组合$k$，计算它们的成本，并选择最大总和。 计算每个段本身的成本需要$O(1)$，但是枚举所有长度的所有段给出$O(n^2)$段，然后快速尝试所有组合就变成了$O(2^n)$，这是完全不可行的。 

关键的见解是从动态规划的角度思考。 让我们定义$dp[i][len]$作为我们可以使用第一个获得的最大成本$i$数组的元素和所选段的总长度$len$。 对于每个位置$i$，我们要么跳过它（结转$dp[i-1][len]$) 或取一个结尾为$i$有一定长度的$j \le i$并将其成本添加到$dp[i-j][len-j]$。 这种方法之所以有效，是因为分段成本仅取决于分段的开始和结束； 中间元素无关。 预先计算每个段的成本$cost[l][r]$在$O(n^2)$允许$dp$转变于$O(n^2)$，拟合整体约束。 

通过将问题转化为经典的“具有长度预算的非重叠段的最大和”动态规划问题，我们将搜索空间从指数减少到二次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 动态规划| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预先计算所有分段成本。 对于每对索引$l \le r$, 计算$cost[l][r] = |b_l - a_r| + |b_r - a_l|$。 这是可行的$O(n^2)$时间因为$n \le 3000$。 将其存储在二维数组中允许$O(1)$DP 期间的查找。 
2.初始化DP表$dp[i][len]$在哪里$dp[i][len]$表示使用第一个可实现的最大成本$i$具有总段长度的元素$len$。 所有条目都以负无穷开始，除了$dp[0][0] = 0$。 
3. 迭代位置$i$从 1 到$n$。 对于每个$i$，迭代总长度$len$从 0 到$k$。 结转之前的最大值：$dp[i][len] = dp[i-1][len]$。 
4. 对于每个可能的段长度$seg$从 1 到$\min(i, len)$，考虑使用结尾为$i$长度$seg$。 更新$dp[i][len] = \max(dp[i][len], dp[i-seg][len-seg] + cost[i-seg+1][i])$。 
5. 处理完所有位置后，$dp[n][k]$包含总长度的最大成本$k$。 

为什么它有效：DP 保持不变式$dp[i][len]$始终存储第一个的最佳总和$i$元素和总长度$len$。 考虑所有可能的最后一段长度可确保考虑到每个可行的组合。 不重叠是自然强制执行的，因为我们只考虑以$i$使用该段之前元素的 DP。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        # Precompute costs
        cost = [[0]*n for _ in range(n)]
        for l in range(n):
            for r in range(l, n):
                cost[l][r] = abs(b[l] - a[r]) + abs(b[r] - a[l])
        
        # DP initialization
        dp = [[-float('inf')] * (k+1) for _ in range(n+1)]
        dp[0][0] = 0
        
        for i in range(1, n+1):
            for length in range(k+1):
                dp[i][length] = dp[i-1][length]  # skip i-th element
                for seg in range(1, min(i, length)+1):
                    dp[i][length] = max(dp[i][length],
                                        dp[i-seg][length-seg] + cost[i-seg][i-1])
        print(dp[n][k])

if __name__ == "__main__":
    solve()
```该代码首先预先计算每个段的成本以避免重新计算。 DP表`dp[i][length]`自然地处理非重叠段，因为 DP 状态总是引用当前段之前的元素。 边缘条件（例如采用长度为 1 的段或到达第一个元素）可以安全处理，因为 Python 列表是 0 索引的，并且我们的 DP 使用`i-seg`引用段之前的状态。
