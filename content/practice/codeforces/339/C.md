 ## 解决方案
 ## 问题理解

 Xenia 可以使用 1 到 10 公斤之间的某些重量子集。 对于标记为可用的每种重量类型，她可以使用该重量任意次。 

她一次将一个重物放在天平上。 第一个重物放在左盘上，第二个重物放在右盘上，然后再次向左移动，永远交替。 每次放置后，刚刚收到新重量的平底锅必须严格比对面的平底锅重。 

该序列还必须满足另一个限制：两个连续选择的权重不能具有相同的值。 

输入描述了哪些权重值可用，并询问是否可以准确执行`m`移动。 如果可能的话，我们必须输出所选权重的一个有效序列。 

的最大值`m`是 1000。这立即表明，如果附加状态变量的数量仍然很小，则任何状态取决于移动数的解决方案都是可行的。 由于只有十个可能的权重值，因此状态空间的数量级为`1000 × 10 × something_small`是完全可以管理的。 

对所有序列进行天真的搜索是没有希望的。 即使每步只有十个选择，可能的序列数量也大致为`10^1000`在最坏的情况下。 

棘手的部分是了解在决定下一步行动时哪些信息真正重要。 

考虑每次移动后的平衡差异。 假设左盘当前比右盘多了3。如果下一步必须放在右盘上，那么选择的重量必须大于3。放置后，右盘会变得更重`weight - 3`。 

这一观察结果意味着之前放置的整个历史都是无关紧要的。 只有当前余额差异和最后选择的重量很重要。 

有几种容易被忽略的边缘情况。 

如果只有一种重量类型可用并且`m > 1`，答案是不可能的，因为连续的权重不可能相等。 

例子：```
1000000000
2
```唯一可用的权重是 1。第一次移动是可以的，但第二次移动必须再次使用 1，这是禁止的。 正确答案是`NO`。 

当存在可用权重但没有一个权重足够大以推翻当前平衡时，会发生另一种微妙的情况。 

例子：```
1100000000
3
```可用权重为 1 和 2。 

一个有效的开始是：```
1
2
```经过这些动作后，平衡差变为 1，有利于右侧平移。 第三次移动在左盘上进行，并且必须超过 1。重量 2 可以使用，但它等于之前的重量。 重量 1 太小。 不存在延续。 

只选择最大可用权重的贪婪策略也可能会失败。 本地有效的选择可能不会在以后留下任何法律延续。 自从`m`可以大到1000，我们需要一种能够系统地探索未来可能性的方法。 

## 方法

 蛮力的想法很简单。 在每一步中，尝试与前一个不同的每一个可用重量，并产生有效的较重的平底锅。 继续递归直到一个长度的序列`m`被发现或者所有可能性都失败。 

此搜索是正确的，因为它明确地检查了每个合法序列。 问题在于分支因素。 在最坏的情况下，每一步都有十个可用的权重，导致大约`10^m`州。 为了`m = 1000`，这是完全不可行的。 

关键的观察结果是秤的完整配置是不必要的。 每次移动后，只有两条信息影响未来的决策。 

首先是当前余额差异。 将其定义为当前较重的平底锅超过另一个平底锅的重量。 该值始终为正。 

第二个是前一步使用的重量，因为禁止连续使用相同的重量。 

假设当前差值是`d`，下一步移动会施加权重`w`在打火机的平底锅上。 此举在以下时间有效：`w > d`。 放置后，新的差异变为`w - d`。 

所以每一个动作都会改变：```
(d, last_weight)
    ->
(w - d, w)
```在哪里`w`可用，`w != last_weight`， 和`w > d`。 

差异永远不会超过 10，因为所有权重最多为 10，并且下一个差异始终是`w - d`。 这给出了至多 10 个可能的差异和先前权重的 11 种可能性（0 表示开始状态加上权重 1..10）。 

整个搜索空间变成：```
move_number × difference × last_weight
```最多是：```
1000 × 10 × 11 = 110000
```州。 

对此状态空间进行记忆的深度优先搜索很容易满足限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(10^m) | O(10^m) | O(米) | 太慢了 |
 | 最优 DFS + DP | O(米×10×11×10)| O(米×10×11)| 已接受 |

 ## 算法演练

 1. 读取可用性字符串并收集所有允许的权重值。 
2.定义DFS状态`(pos, diff, last)`。 

这里`pos`是已经放置的权重的数量，`diff`是当前的正余额差，并且`last`是之前选择的权重。 
3.如果`pos == m`，我们已经成功构造了一个长度的序列`m`。 返回成功。 
4. 对于每个可用的重量`w`，检查是否可以选择。 

它必须满足：

 -`w != last`-`w > diff`第一个条件强制执行连续权重限制。 第二个确保接受新重量的平底锅变得严格更重。 
5. 计算下一个差异。 

由于新的重量施加在较轻的盘上，因此较重的一侧会发生变化。 新的超额变为：```
new_diff = w - diff
```6. 递归搜索状态：```
(pos + 1, new_diff, w)
```7. 如果有任何递归调用成功，记录`w`作为答案的一部分并向上传播成功。 
8. 记住失败的状态。 如果某个状态已被证明是不可能的，则跳过重新计算。 
9. 如果初始状态`(0, 0, 0)`成功，输出构造的序列。 否则输出`NO`。 

### 为什么它有效

 不变的是`diff`始终等于当前较重的平底锅超过较轻的平底锅的量。 

处于有差异的状态`diff`，下一步必须放在较轻的盘上。 为了使平底锅变得更重，增加的重量必须超过当前的重量差。 这正是条件`w > diff`。 

放置这样的重量后，新的较重的平底锅比另一个重的平底锅多了`w - diff`，这成为下一个状态的差异。 

每个合法序列都对应于通过这些状态的一条路径，并且 DFS 生成的每个转换都对应于一个合法的移动。 搜索探索所有合法的延续，同时记忆可以防止重复工作。 如果 DFS 报告成功，则重建的序列有效。 如果它报告失败，则该状态不存在合法序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    m = int(input())

    weights = [i + 1 for i, ch in enumerate(s) if ch == '1']

    dp = {}
    answer = []

    def dfs(pos, diff, last):
        if pos == m:
            return True

        state = (pos, diff, last)
        if state in dp:
            return False

        for w in weights:
            if w == last:
                continue
            if w <= diff:
                continue

            if dfs(pos + 1, w - diff, w):
                answer.append(w)
                return True

        dp[state] = False
        return False

    if dfs(0, 0, 0):
        answer.reverse()
        print("YES")
        print(*answer)
    else:
        print("NO")

solve()
```名单`weights`包含所有可用的重量值。 由于只有 10 个可能的值，因此在每个 DFS 状态中迭代它们的成本很低。 

国家`(pos, diff, last)`准确捕获继续该过程所需的信息。 早期举措中的任何其他内容都不会影响未来的合法性。 

记忆字典仅存储失败状态。 记录所选重量后，成功状态立即返回向上。 这种重建方法避免了存储每个状态的父指针。 

一个微妙的细节是`diff`。 至少经过一次移动后，它始终为正值，并且代表较重盘当前的剩余量。 公式`w - diff`之所以有效，是因为新的重量总是放在较轻的盘上，并且必须大于现有的多余重量。 

另一个容易犯的错误是忘记反转重建的序列。 我们在从递归调用返回时附加权重，因此序列以相反的顺序收集。

 ## 边缘情况

 考虑：```
1000000000
2
```仅存在权重 1。 第一步创建状态`(1, 1, 1)`。 下一步不能使用权重 1，因为它等于前一个选择。 DFS 未发现任何转换并报告失败。 算法输出`NO`。 

现在考虑：```
1100000000
3
```DFS 可以从权重 1 开始。得到的状态是：```
(0,0,0)
→ (1,1,1)
→ (2,1,2)
```从`(2,1,2)`，权重 1 太小，权重 2 重复之前的选择。 该状态被记忆为不可能的。 其他所有分支都类似地失败，所以最终答案是`NO`。 

最后考虑：```
0000000101
3
```顺序：```
8 → 10 → 8
```产生差异：```
8 → 2 → 6
```每个选择的权重都严格大于当前差值，并且与之前的权重不同。 DFS达到长度`m`并成功重建序列。
