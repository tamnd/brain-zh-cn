 ## 解决方案
 ## 问题理解

 输入是一个表示总和的字符串，其中每个数字都是`1`,`2`， 或者`3`，数字之间用加号分隔。 例如，字符串`3+2+1+3`代表四个被加数。 

仅当数字按非递减顺序出现时，Xenia 才能计算表达式。 我们的任务不是计算总和本身。 相反，我们必须重新排列现有的数字，以便所有`1`先来，然后是所有`2`s，则所有`3`s，并以相同的方式打印结果表达式`a+b+c`格式。 

输入长度最多为 100 个字符。 由于每个数字占一个字符，每个分隔符占一个字符，因此最多有 50 个左右的数字。 如此小的限制意味着几乎任何合理的方法都足够快。 即使基于排序的解决方案也会立即运行。 

主要挑战是正确处理字符串格式。 我们需要对数字进行排序，而不是整个字符串。 对所有字符进行排序的粗心实现会将数字和加号混合在一起并产生无效的表达式。 

一种边缘情况是表达式仅包含单个数字。 

输入：```
2
```输出：```
2
```没有加号可以插入原始结构之外。 拆分和合并仍然可以正常工作。 

另一个边缘情况是所有数字都已排序。 

输入：```
1+1+2+3
```输出：```
1+1+2+3
```该算法应保持表达式不变。 

不同的情况是所有数字都相同。 

输入：```
3+3+3
```输出：```
3+3+3
```排序不应改变结果，并且必须保留重复值。 

## 方法

 暴力思维是生成所有可能的数字排序，检查该排序是否非递减，然后打印第一个有效的排序。 这是可行的，因为正确的答案只是给定被加数的排列之一。 

问题在于排列是阶乘增长的。 如果有50个数，则有`50!`可能的订单量是天文数字般巨大且完全不可行。 

问题的结构提供了更简单的观察。 唯一出现的值是`1`,`2`， 和`3`，Xenia 希望它们按非降序排列。 当所有较小的值出现在较大的值之前时，序列是非递减的。 这意味着我们根本不需要在排列之间进行搜索。 我们可以提取数字，对它们进行排序，然后重建表达式。 

由于排序直接产生唯一的非递减排列，因此该问题变成了一个简单的实现任务。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取输入字符串。 
2. 使用分割字符串`'+'`作为分隔符。 

这会将所有数字提取为单独的字符串，例如`["3", "2", "1"]`。 
3. 对结果列表进行排序。 

对所有位置进行排序`1`首先是，然后是所有`2`s，则所有`3`s，这正是所需的顺序。 
4. 使用以下命令将排序后的数字重新连接在一起`'+'`。 

这会以原始格式重建有效的表达式。 
5. 打印结果。 

### 为什么它有效

 表达式仅由数字组成`1`,`2`， 和`3`。 有效答案必须包含与输入完全相同的数字多重集，只是重新排序。 

对提取的数字进行排序会产生一个序列，其中每个元素都小于或等于下一个元素。 这正是非降序的定义。 由于排序既不会删除也不会重复任何数字，因此结果表达式完全包含原始被加数并满足 Xenia 的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()

numbers = s.split('+')
numbers.sort()

print('+'.join(numbers))
```第一步将表达式读取为字符串。 使用`strip()`删除尾随换行符。 

致电给`split('+')`是关键的解析操作。 它不处理单个字符，而是直接将数字提取为单独的元素。 

然后该列表按字典顺序排序。 由于唯一可能的值是`"1"`,`"2"`， 和`"3"`，字典顺序与数字顺序匹配。 

最后，`'+'.join(numbers)`使用所需的分隔符重建表达式。 这会自动处理单数和多数表达式，没有任何特殊情况。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    s = input().strip()
    numbers = s.split('+')
    numbers.sort()
    print('+'.join(numbers))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("3+2+1\n") == "1+2+3", "sample 1"

# minimum-size input
assert run("1\n") == "1", "single number"

# already sorted
assert run("1+1+2+3\n") == "1+1+2+3", "already sorted"

# all equal values
assert run("3+3+3\n") == "3+3+3", "all equal"

# reverse order
assert run("3+3+2+2+1+1\n") == "1+1+2+2+3+3", "full sorting"

# mixed duplicates
assert run("2+1+3+1+2\n") == "1+1+2+2+3", "duplicates preserved"

 ## 边缘情况

 考虑单个数字输入：```
2
```该算法执行：```
"2".split('+')
```其产生：```
["2"]
```排序不执行任何操作，连接返回：```
2
```输出保持正确，无需任何特殊处理。 

考虑一个已经排序的表达式：```
1+1+2+3
```分割后：```
["1", "1", "2", "3"]
```排序使列表保持不变。 最终输出与输入相同，这是期望的行为。 

考虑一个仅包含相同值的表达式：```
3+3+3
```分裂给出：```
["3", "3", "3"]
```排序会保留所有三个出现的情况。 加入重建：```
3+3+3
```这证实了该算法永远不会丢失或重复被加数，并且始终保留原始的数字多重集。
