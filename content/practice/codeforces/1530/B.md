 ## 解决方案
 ## 问题理解

 我们被要求最大化矩形桌子上的盘子数量，表示为$h \times w$网格。 板只能沿着周边放置，包括第一行、最后一行、第一列和最后一列。 此外，任何两个板都不能正交或对角相邻。 也就是说，对于任何位于$(i, j)$，周围的八个单元格必须保持为空。 目标是为每个表输出有效的板配置，以实现最大可能的板数量。 

输入提供多个测试用例，每个测试用例都有表尺寸$h$和$w$。 我们需要生产$h$长度线$w$每个测试用例，将板标记为“1”，将空单元标记为“0”。 自从$3 \le h, w \le 20$和$t \le 100$，该算法只需要处理小网格，这意味着即使是顺序检查所有周边单元的解决方案也是可行的。 

当桌子很窄或很短时，就会出现不明显的边缘情况，例如$3 \times 3$桌子。 在这里，不检查角落的简单放置可能会尝试将板沿边缘放置在相邻单元中，从而违反邻接限制。 同样，具有偶数尺寸的表格可以允许多个等效的最大放置，因此我们的解决方案在应用避免冲突的模式时应该保持一致，特别是在角落。 

## 方法

 暴力方法将尝试尝试周边单元的每个可能的子集，检查每个组合是否存在邻接冲突。 大致有$2 \cdot h + 2 \cdot (w - 2)$周长单元格，因此子集的数量与周长长度呈指数关系。 为了$h = w = 20$，这导致$2^{76}$的组合，这是不可行的。 

关键的观察结果是邻接约束沿周边局部传播。 只要我们小心处理角落，沿边缘交替放置的板就不会发生冲突。 我们可以通过按顺序遍历边缘（顶行、右列、底行、左列）来利用这一点，并在单元格及其邻居空闲时贪婪地放置一个板。 这是可行的，因为邻接约束纯粹是局部的，因此沿着周边的贪婪方法总是会产生最大配置。 唯一的微妙之处是检查拐角处的对角线邻接，如果拐角邻居已经包含板块，则可以通过跳过放置来处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(2h + 2w)) | O(2^(2h + 2w)) | O(高*宽) | 太慢了|
 | 贪婪边缘放置 | O(高*宽) | O(高*宽) | 已接受 |

 ## 算法演练

 1. 初始化一个$h \times w$网格充满零。 这代表一个空表。 
2. 沿着顶行从左到右迭代。 对于每个单元格，检查单元格本身及其八个邻居是否为空。 如果是这样，请在该单元格中放置一块板（“1”）。 
3. 沿着最右边的列，从上到下迭代。 跳过顶部单元格，因为它与已处理的右上角重叠。 在放置盘子之前应用相同的邻居检查。 
4. 沿着底行从右到左迭代。 跳过右下角，因为它可能已被右列填充。 再次，在放置之前检查邻居。 
5. 沿着最左边的列，从下到上迭代。 如果已处理，请跳过左下角和左上角。 仅当邻居空着时才放置盘子。 
6. 处理完所有边缘后，逐行打印网格。 

工作原理：只有当所有相邻单元都空闲时才会放置板，这保证了不会违反邻接关系。 按顺序处理边可确保按遍历顺序解决角冲突。 局部贪婪放置就足够了，因为每个边缘单元仅受直接邻居的影响，因此不需要全局回溯来最大化板的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def place_plates(h, w):
    grid = [['0'] * w for _ in range(h)]

    def safe(i, j):
        for di in [-1, 0, 1]:
            for dj in [-1, 0, 1]:
                ni, nj = i + di, j + dj
                if 0 <= ni < h and 0 <= nj < w:
                    if grid[ni][nj] == '1':
                        return False
        return True

    # top row
    for j in range(w):
        if safe(0, j):
            grid[0][j] = '1'

    # right column
    for i in range(1, h):
        if safe(i, w - 1):
            grid[i][w - 1] = '1'

    # bottom row
    for j in range(w - 2, -1, -1):
        if safe(h - 1, j):
            grid[h - 1][j] = '1'

    # left column
    for i in range(h - 2, 0, -1):
        if safe(i, 0):
            grid[i][0] = '1'

    return [''.join(row) for row in grid]

t = int(input())
for _ in range(t):
    h, w = map(int, input().split())
    result = place_plates(h, w)
    print('\n'.join(result))
    print()
```该解决方案定义了一个`safe`确保没有邻居包含车牌的功能。 顶行从左到右处理，右列从上到下处理，底行从右到左处理，左列从下到上处理。 角点自然会被处理，因为邻居检查可以防止重复放置。 填充后，打印网格。
