 ## 解决方案

 ## 问题理解

 我们得到了全天的时间表，货运列车已经在固定时间出发。 这一天是循环的`h`小时和`m`分钟每小时，因此每个火车时间都可以被视为长度为单个圆形时间轴上的一个点`H = h · m`分钟。 

我们想引入定期客运有轨电车系统。 电车必须均匀间隔发车：恰好每隔`m/2`分钟，从某个偏移量开始`t`在第一个小时内，即第一趟电车的时间`t`，下一个在`t + m/2`，依此类推，直到一天结束。 

每趟有轨电车的出发都会产生一个长度的“禁窗”`k`电车前几分钟。 任何严格在此区间内发车的货运列车都必须取消。 允许火车恰好位于窗口的起点或终点。 

任务是选择起始偏移量`t`从而使取消的货运列车总数最小化，并输出该最小数量和一个最佳数量`t`。 

关键结构是所有与有轨电车相关的约束在每个`m/2`分钟，因此每列货运列车都会与相同窗口的周期性模式相互作用。 

约束条件很大：最多`10^5`火车，时间值高达`10^9`。 这排除了任何检查所有可能的方法`t`天真地，自从`t`最多有`m/2`可能性和`m`可以是巨大的。 甚至检查一个`t`需要有效地计算重叠。 

一个微妙的问题是正确处理边界行为。 允许火车正好在电车时间或恰好在窗口边界处行驶，但任何严格在规定范围内的列车`k`-分钟段不是。 另一个棘手的情况是当`k`接近于`m/2`，导致连续禁止区间之间存在较大重叠，这意味着我们必须避免重复计算。 

## 方法

 蛮力的想法很简单：尝试每一个可能的开始时间`t`从`0`到`m/2 - 1`。 对于每个`t`，模拟所有有轨电车的发车情况，并根据禁止的间隔检查每列货运列车。 由于有`h`有轨电车按周期结构在全天重复运行，这会变得昂贵。 

即使我们对火车进行预先排序，对于每个`t`我们仍然需要计算有多少`n`火车属于一个联盟`2h`间隔。 直接模拟大致得出`O(m · n)`或者更糟，这是不可能的，因为`m`可以达到`10^9`。 

关键的观察是每列货运列车仅取决于其位置模`m/2`。 一旦我们将时间缩短为单个长度`m/2`，每列火车对应一个点，每辆电车创建一个固定的禁止偏移区间`t`。 而不是迭代`t`，我们反转视角：对于每列火车，我们计​​算起始偏移量的集合`t`这将迫使这列火车进入禁区。 每个这样的集合都是圆形域上的简单区间。 那么问题就变成了寻找一个点`t`这就是这些间隔的最小数量。 

这将问题变成了带有间隔加法的经典圆形线扫描，可以在通过换行处理将圆形间隔映射为线性间隔后使用差分数组来解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解所有t | O(m·n) | O(n) | 太慢了 |
 | 模线上的间隔扫描 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将每趟货运列车的时间换算为从当天开始算起的分钟数。 然后对它进行模减`p = m/2`，因为有轨电车模式重复每个`p`分钟。 这将每列火车映射到一个圆形坐标系中。 
2.对于固定时间的列车`x`，确定哪些值`t`这列火车停在一些有轨电车的禁止窗户内。 每辆电车有时发车`t + j·p`。 如果列车位于以下位置，则该列车无效`(t + j·p - k, t + j·p)`对于某些人来说`j`。 
3.重新排列，对于固定列车，这个条件就变成了区间约束`t`。 具体来说，`t`必须位于通过将火车时间平移得出的区间内`[-k, 0)`模数`p`。 
4. 因此，每列列车在圆形范围内贡献一或两个间隔`[0, p)`。 如果间隔环绕，请将其分成两段。 
5. 使用差异数组`[0, p)`计算每种可能的无效列车数量`t`。 添加`+1`在间隔开始和`-1`在间隔结束时。 
6. 扫遍一切`t`从`0`到`p-1`，维护一个前缀和来查找每个列车取消的列车数量`t`。 
7. 跟踪最小值和对应的`t`。 

这种转变有效的关键原因是每列列车独立限制了选择`t`成一个圆上的简单连续区域。 一旦所有约束都在同一坐标系中表达，全局最优值就是区间之间重叠最小的点。 

### 为什么它有效

 每列货运列车都提供一个独立于所有其他列车的约束：它有效或无效仅取决于某些电车车窗是否覆盖它。 对于任何固定列车，一组不良起始位置在可能的圆轴上形成连续的弧`t`价值观。 因此，最终答案是该圆上弧数最少的点。 通过模块化分割将圆转换为直线可以准确地保留重叠计数，因此前缀和扫描可以正确地重建每个可能的起始位置的违反约束的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def add(diff, l, r):
    diff[l] += 1
    diff[r] -= 1

def solve():
    n, h, m, k = map(int, input().split())
    p = m // 2

    trains = []
    for _ in range(n):
        hh, mm = map(int, input().split())
        x = hh * m + mm
        trains.append(x % p)

    diff = [0] * (p + 1)

    for x in trains:
        l = (x - k) % p
        r = x % p

        if l < r:
            add(diff, l, r)
        else:
            add(diff, l, p)
            add(diff, 0, r)

    best = n
    best_t = 0
    cur = 0

    for t in range(p):
        cur += diff[t]
        if cur < best:
            best = cur
            best_t = t

    print(best, best_t)

if __name__ == "__main__":
    solve()
```该解决方案首先将所有时间在几分钟内折叠成一个线性标度，然后将它们模数减少`p = m/2`利用周期性。 差异数组对每列列车如何限制有效起始位置进行编码。 这`add`函数在 O(1) 中实现范围更新，这一点至关重要，因为每列列车仅贡献一个或两个间隔。 

主扫描计算所有可能的前缀和`t`。 变量`cur`跟踪当前有多少趟列车对此无效`t`，然后我们将其最小化。 

一个微妙的点是当`l >= r`。 这意味着禁区跨越`0`，因此必须将其分为两段。 缺少这种分割是错误答案的最常见来源。

 ## 边缘情况

 一个关键的边缘情况是当`x - k`变为负数或超过零。 在这种情况下，禁区跨越了模圆的边界。 该算法将其分成两段`[l, p)`和`[0, r)`，确保前缀和正确计算两侧的覆盖范围。 

另一种边缘情况发生在`k = m/2`，其中每列火车恰好排除了一半可能的`t`价值观。 在这种情况下，每个点都会被覆盖多次，并且扫描仍然正确地找到最小值，因为所有位置都是对称的。 

最后一个微妙的情况是多列列车产生相同的区间边界。 差异数组自然地处理这个问题，因为更新会累积，并且前缀和反映了多重性，而无需额外的逻辑。
