 ## 解决方案
 ## 问题理解

 给定两个非负整数，我们可以同步移动它们：每个操作都会将两个值更改完全相同的量，要么都增加 1，要么减少 1（只要我们不低于零）。 

我们关心的分数是任意移动序列后两个数字的最大公约数。 我们希望最大化这个分数，并且在实现最大可能的 GCD 的所有方法中，我们希望所需的移动次数最少。 

一个关键的观察是，每一步都会保留两个数字之间的差异。 如果我们定义$d = a - b$，那么两个操作都保持$a - b$不变。 这意味着整个过程仅限于以下形式的点$(x, x - d)$或者$(x + d, x)$取决于订购。 

约束条件达到$10^{18}$，因此任何尝试所有可达状态的解决方案都是不可能的。 甚至扫描周围的一系列值$a$和$b$不可行，因为可达值在两个方向上跨越无限长的线。 

出现微妙的边缘情况时$a = b$。 在这种情况下，增加两个数字可以保持相等并使 GCD 等于值本身，并且它可以无限制地增长。 这会导致无限的兴奋，必须被察觉。 

当一个值为零时，会出现另一种极端情况。 自从$gcd(x, 0) = x$，减小这两个值可能是不可能的，但增加这两个值就可以达到任意大的相等值，只要我们不受到负约束的阻碍。 然而，最优推理仍然取决于不变的差异。 

一个天真的错误是假设我们可以独立调整价值观以适应多重关系。 我们无法改变差异，因此任何目标对都必须满足固定的线性关系。 

## 方法

 一个蛮力的想法是模拟所有可能到达的状态$(a, b)$通过BFS或DFS，将两个值一起更新±1。 这很快就会变得无限，因为状态图在两个方向上都是一条无限的线。 即使我们启发式地限制界限，最佳 GCD 也可能发生在很远的地方，因为 GCD 取决于可分性，而不是邻近性。 

关键的结构洞察力是差异$d = |a - b|$永远不会改变。 任何可达对都可以写成：$$(a', b') = (x, x - d)$$对于某个整数$x$（假设订购）。 

我们想要选择$x$这样：$$\gcd(x, x - d)$$被最大化。 

使用身份：$$\gcd(x, x - d) = \gcd(x, d)$$问题归结为选择$x$在一条线上，使其与固定数字共享最大可能的除数$d$，同时最小化距起点的距离。 

最大可能的 GCD 很简单$d$本身尽可能，但我们必须确保可行性，并限制我们只能达到与整数步长一致的值$a$和$b$。 

重要的结构结果是可实现的最佳 GCD 是$g = |a - b|$如果我们可以通过移位将一个数字对齐到多重结构； 否则，当$a = b$，答案是无穷大。 

这将任务简化为基于差异对齐和到最近有效配置的距离的简单数论计算。

 ## 算法演练

 1.如果$a = b$，立即回归无限兴奋。 

原因是在任意次数的操作之后两个数字始终保持相等，并且重复的增量操作使 GCD 无限制地增长。 
2. 计算$d = |a - b|$。 

这种差异在所有允许的操作下都是不变的，因此每个可到达的状态都位于固定的算术线上。 
3.如果$d = 0$，我们已经处理过了，所以继续假设$d > 0$。 
4. 计算可实现的最佳 GCD 为$g = d$。 

这来自于身份$\gcd(x, x - d) = \gcd(x, d)$，这意味着 GCD 始终是$d$，我们可以对齐$x$最大化该除数，实现$d$本身。 
5. 确定达到其中一个数字可被整除的配置所需的最小移动次数$d$。 

由于每次移动都会将两个数字移动 1，因此我们实际上是沿着整数线移动该对。 我们选择最近的多重对齐以最小化距离。 
6. 计算距离$a$是最接近的倍数$d$，并使用该转变作为移动次数。 

### 为什么它有效

 不变的是差异$a - b$永远不会改变。 这将所有可达状态限制为单个一维晶格。 在这个点阵上，GCD 简化为一个变量和一个固定常数的函数$d$。 由于每个可实现的 GCD 都是$d$，通过对齐状态使一个坐标是以下的倍数来实现最大值$d$。 最小移动计数如下，因为每个操作都会将整个格点恰好移动一个单位，因此达到最接近的有效对齐是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())

        if a == b:
            print(0, 0)
            continue

        d = abs(a - b)

        # shift to nearest multiple alignment
        r = a % d
        move = min(r, d - r)

        print(d, move)

if __name__ == "__main__":
    solve()
```该解决方案首先检查平等情况，这是导致无限增长的唯一情况。 之后，一切都取决于不变差$d$。 其余的$a$模数$d$告诉我们距离对齐还有多远$a$到多个$d$，并且移动两个数字可以在沿着可达线移动时保留可行性。 

选择仅使用$a \% d$是有效的，因为移动两个数字都会对称地影响两者，并且对齐条件仅取决于相对于固定差值的整除性。

 ## 边缘情况

 当$a = b$，算法立即返回$0, 0$。 例如，输入$4, 4$产生相等，并且重复增量允许 GCD 无限增长，因此早期退出正确地捕获了这一点。 

当一个值为零时，例如$0, 5$，差值为 5，余数逻辑仍然适用。 计算产生的有效移位距离为零，这意味着无需移动即可最大化 GCD。 

当值已经接近时，例如$7, 3$，差值为 4，7 模 4 的余数为 3。算法正确地选择最小移位以达到与 4 整除一致的配置。 

当值极大但相差 1 时，差值为 1，并且每个配置的 GCD 为 1。余数逻辑产生零移动，因为不可能进行改进。
