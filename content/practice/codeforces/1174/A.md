 ## 解决方案
 ## 问题理解

 给定一个整数多重集，其大小恰好是某个数字 n 的两倍。 任务是将这些值重新排列成新的顺序，这样如果我们将重新排序的数组分成长度为 n 的两个连续的一半，左半部分的总和与右​​半部分的总和不同。 如果不存在这样的重新安排，我们必须报告失败。 

关键点是我们没有被要求优化超出这个不平等条件的任何东西。 我们可以自由地任意排列，因此解决方案的结构完全取决于我们如何通过排序影响两个半和。 

约束 n ≤ 1000 意味着数组大小最多为 2000。这足够小，排序或线性扫描都很简单，甚至 O(n²) 构造也会通过。 重要的部分是对和结构的推理而不是计算效率。 

当所有元素都相同时，会出现微妙的边缘情况。 例如，如果数组为 [5, 5, 5, 5]，则任何分为两半的分区都会产生相等的总和，因为两半都包含相同的多重集。 在这种情况下，不存在解决方案。 

当数组变化非常小时，例如 [1, 1, 1, 2]，就会出现另一种边缘情况。 天真的直觉可能表明，一些巧妙的交织仍然可以使总和相等，但事实上，除非所有值都相同，否则我们总是可以打破相等。 

核心困难是认识到无论排列如何，对称性何时会强制相等。 

## 方法

 暴力方法会尝试排列数组并检查是否存在有效的分割。 有(2n)个！ 排列，甚至评估一个排列也是 O(n)，这使得这完全不可行。 

即使我们减少采样排列，我们仍然缺少结构。 真正的观察是，所有排列失败的唯一原因是每个元素都相同。 在这种情况下，每一半都有相同的和 n·x，因此相等是不可避免的。 

如果至少存在两个不同的值，我们可以故意构造具有不同总和的两半。 最简单的方法是对数组进行排序。 排序后，最小值集中在开头，最大值集中在末尾。 在 n 个元素之后进行拆分可保证后半部分至少包含一个比前半部分中的任何元素严格更大的元素，反之亦然，具体取决于分布。 这造成了金额上的严格不平衡。 

更具体地说，排序确保我们最大化两半之间的分离。 前半部分偏向较小的值，第二部分偏向较大的值，这会导致总和差距。 

因此，问题简化为简单的一致性检查，然后进行排序。

 ## 算法演练

 1. 读取数组并检查所有元素是否相等。 如果是，则输出 -1，因为每个排列都会产生相同的半和，从而不可能出现不等式。 
2. 按非降序对数组进行排序。 这将创建一个结构，其中小值分组在左侧，大值分组在右侧。 
3.直接输出排序后的数组。 分成大小为 n 的两半现在将比较较低重量的一半和较高重量的一半。 
4. 终止。 

### 为什么它有效

排序会创建单调排列，其中前半部分中的每个元素都小于或等于后半部分中的每个元素。 由于当数组不均匀时至少存在一个严格的不等式，因此后半部分包含严格更大的总贡献。 这保证了两半的总和不能匹配，因为用较大的元素替换前半部分中的任何元素都会严格增加后半部分相对于前半部分的总和。 

正确性取决于以下事实：所有元素相等是消除两半之间所有可能的严格排序的唯一配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if len(set(a)) == 1:
        print(-1)
        return
    
    a.sort()
    print(*a)

if __name__ == "__main__":
    solve()
```解决方案首先读取n和2n个元素。 使用集合进行均匀性检查至关重要，因为它直接捕获唯一不可能的情况。 如果没有它，单独排序仍然会输出有效的排列，但我们会在全相等的边缘情况下失败。 

排序是强制区分小值和大值的建设性步骤。 排序后按原样打印数组就足够了，因为该问题不需要显式地形成两半，只需确保这样的分割具有不相等的总和。 

一个常见的错误是尝试交错元素或构建交替模式。 这些都是不必要的，因为它们不会改善排序已经提供的保证。

 ## 边缘情况

 最重要的边缘情况是所有元素都相同。 对于这样的输入：```
3
7 7 7 7 7 7
```该算法检测到`len(set(a)) == 1`并立即输出-1。 如果我们跳过此检查并打印数组，则两半的总和将为 3 × 7 = 21，从而违反了条件。 

对于接近均匀的情况，例如：```
3
1 1 1 1 1 2
```集合大小大于1，所以我们继续排序：```
1 1 1 1 1 2
```一半的总和变为：

 前半部分 = 3，后半部分 = 4，因此条件成立。 这表明，即使是单一的均匀性偏差也足以保证排序后的有效分割。 

此行为证实构造仅在完全对称的情况下失败，否则成功。
