 ## 解决方案
 ## 问题理解

 我们得到了一个数字序列，并且允许我们对其重新排序，但交换的工作方式受到限制。 仅当我们选择两个具有相反奇偶性的头寸（即一个为奇数，另一个为偶数）时，掉期才是合法的。 如果两者都是偶数或都是奇数，我们不能直接交换它们。 

任务是使用任意数量的此类允许的交换来确定按字典顺序可到达的最小数组。 字典顺序意味着我们从左到右比较数组，并且更喜欢它们不同的第一个位置。 

该操作的关键含义是奇偶校验组的行为不同：元素只能跨奇偶校验边界自由移动，而不能在同一奇偶校验组内自由移动。 这立即表明完全任意排列是不可能的，只能进行受限重排。 

n 最多 100,000 的约束意味着我们至少需要 O(n log n) 或 O(n) 解决方案。 任何涉及重复模拟交换或 BFS 式配置探索的方法都是不可行的，因为状态空间以 n 为指数。 

当所有元素具有相同的奇偶性时，就会出现微妙但重要的边缘情况。 如果所有数字都是偶数或都是奇数，则不存在有效的交换，因为每一对的总和都是偶数。 在这种情况下，数组已经固定并且无法更改。 

另一个边缘情况是奇偶校验混合存在，但天真的贪婪尝试尝试对整个数组进行排序。 例如，输入`[3, 2, 1]`可能会诱使排序`[1, 2, 3]`，但可行性取决于奇偶相互作用，而不是纯粹的排序。 

## 方法

 暴力方法将模拟所有有效的交换并尝试达到所有可达的排列，然后按字典顺序选择最小的排列。 从状态角度来​​看，每个配置最多有 O(n²) 种可能的交换，并且有 n！ 总共的排列，使得这完全不可行。 

关键的观察是，当两个元素具有不同的奇偶性时，恰好允许交换。 这意味着任何奇数元素都可以与任何偶数元素交换，反之亦然。 在重复交换中，这意味着所有赔率都可以通过中介有效地与所有偶数进行排列，但相同奇偶性的元素永远不会直接约束彼此的排序，除非通过全局混合。 

我们可以重新解释该过程：我们可以对所有数字的多重集任意重新排序，但奇偶校验交互确保最终排列中奇偶校验组的相对顺序仅受元素交错方式的限制。 

关键的简化是我们可以将所有元素视为属于两个池：奇数池和偶数池。 在每个池中，相对排序是完全自由的，因为我们可以使用相反奇偶校验的元素作为中介来有效地模拟相同奇偶校验元素之间的交换。 这是一个标准的传递性论证：奇偶交换允许我们通过另一组“冒泡”元素。 

因此，奇数组和偶数组都可以独立排序，然后通过在每个位置放置最小的可用元素来贪婪地合并，因为我们总是可以在不违反约束的情况下从任一组中进行选择。 

然而，真正的约束更简单：因为任何奇数都可以与任何偶数交换，所以多重集是完全可置换的。 这意味着唯一的限制是我们无法在结构上区分奇偶校验类，因此最佳排列就是全局排序的数组。 

一个天真的误解是认为奇偶校验组在内部被锁定，但实际上，只要两个奇偶校验都存在，交换图就已连接。 

所以正确的逻辑分为几种情况：

 如果奇数和偶数都存在，我们就可以实现任意排列，所以我们对整个数组进行排序。 

如果仅存在一个奇偶校验，则不可能进行交换，因此我们输出原始数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力交换 | O(n!) | O(n!) | 太慢了 |
 | 奇偶校验模拟| O(n²) | O(n) | 太慢了 |
 | 使用奇偶校验排序 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 扫描数组并计算有多少个元素是奇数和多少个是偶数。 这决定了是否可以进行任何交换，因为交换需要相反的奇偶校验值。 
2. 如果奇数计数或偶数计数为零，则返回数组不变。 不存在有效的交换，因此无法重新排列。 
3. 否则，按非降序对整个数组进行排序。 理由是，当两个奇偶校验都存在时，交换图是连接的，这意味着可以构造任何排列。 
4. 将排序后的数组输出为按字典顺序排列的最小排列。 

### 为什么它有效

 允许的操作在数组位置上定义一个图，其中边连接不同奇偶校验的元素。 当两个奇偶校验都存在时，该图通过交替奇偶校验交换连接，允许任何元素通过中间交换移动到任何位置。 这意味着完全排列可达性。 由于所有排列都是可到达的，因此字典顺序上最小的可到达排列就是全局排序的顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    odd = sum(x % 2 for x in a)
    even = n - odd
    
    if odd == 0 or even == 0:
        print(*a)
    else:
        a.sort()
        print(*a)

if __name__ == "__main__":
    main()
```该代码首先读取数组并计算奇偶校验分布。 该检查至关重要，因为它确定交换是否可以真正更改配置。 如果不存在交叉奇偶校验对，则排序将无效，因为它假设不存在移动性。 

当两个奇偶校验都存在时，我们对整个数组进行排序。 这依赖于交换操作有效地使排列组完全可达这一事实。 

一个微妙的点是我们不需要显式地模拟交换或构造中间状态。 连接性参数保证存在一系列有效交换，将任何排列转换为任何其他排列。

 ## 边缘情况

 当所有元素共享相同的奇偶校验时，算法会正确检测到无法应用任何操作。 用于输入`[2, 6, 8]`，奇数计数为零，所以我们直接返回`[2, 6, 8]`。 任何在这里排序的尝试都是无效的，因为没有合法的交换来证明改变位置的合理性。 

当两个奇偶校验都存在时，即使元素严重交错，例如`[100, 1, 99, 2]`，算法排序为`[1, 2, 99, 100]`。 连接性参数确保每个所需的转置都可以分解为有效的奇偶交换，因此排序结果始终可达。
