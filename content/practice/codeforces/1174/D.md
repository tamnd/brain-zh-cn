 ## 解决方案
 ## 问题理解

 我们被要求构建一个整数序列，每个整数的范围从 1 到$2^n - 1$，对其连续段有非常具体的限制。 对于每个连续的子数组，我们计算其元素的按位异或，并且这些异或值都不允许为 0 或给定的禁止值$x$。 在满足此限制的所有序列中，我们想要一个具有最大可能长度的序列。 

重新构建问题的一个有用方法是根据前缀异或来思考。 如果我们定义$p_0 = 0$和$p_i = a_1 \oplus a_2 \oplus \dots \oplus a_i$，然后对子数组进行异或$[l, r]$是$p_r \oplus p_{l-1}$。 条件是没有子数组异或为0或$x$成为关于前缀 XOR 集中禁止的成对差异的条件：我们决不能有$p_i = p_j$（以避免 XOR 0），并且我们决不能有$p_i = p_j \oplus x$（以避免异或$x$）。 

因此构造问题变成：构建一系列不同的前缀 XOR 状态，避免任何不同的状态对$x$。 

约束条件$n \le 18$意味着所有值最多都位于一个大小的宇宙中$2^{18}$，大约有26万种可能性。 这足够小，以至于对所有状态进行基于位掩码的图形推理都是可行的。 困难不在于计算限制，而在于构造状态以便不出现禁止的 XOR 关系。 

一个幼稚的尝试是从 0 开始，通过选择任何未使用的值来贪婪地扩展序列，该值不会立即创建与先前前缀的禁止子数组 XOR。 这会失败，因为约束对于所有前缀对都是全局的，而不是最近元素的局部约束。 一个糟糕的早期选择可能会阻止几乎所有未来的扩展，即使它目前看起来是安全的。 

当尝试独立处理值时会出现另一种失败模式。 选择一大组整数而不检查前缀 XOR 关系会忽略约束基本上是关于超立方体上 XOR 图的结构，而不是关于单个元素。 

## 方法

 关键的重新表述是完全在前缀 XOR 空间中工作。 我们构建一系列不同的值$p_i$，从$p_0 = 0$，这样没有两个选定的前缀满足$p_i \oplus p_j = x$。 一旦我们有了这样的序列，我们就可以通过设置来恢复实际的数组$a_i = p_i \oplus p_{i-1}$。 

这将问题转化为在顶点全部为的图中选择最大长度路径$2^n$位掩码，其中仅当边缘不违反所选集合中禁止的 XOR 关系时才允许边缘。 然而，我们没有显式地构建边缘，而是观察到更强大的结构：每个值$v$仅与自身不相容并且与$v \oplus x$。 这意味着顶点自然形成不相交的对$(v, v \oplus x)$什么时候$x \ne 0$。 

在每一对中，我们最多可以取一个元素，否则我们将立即创建一个禁止的 XOR$x$。 唯一剩下的问题是确保前缀排序的一致性，以便构造的差异保持有效。 

这表明对从 0 到所有数字的贪婪构造$2^n - 1$。 我们迭代值并选择一个数字（如果它或其 XOR 伙伴都没有被使用）。 这确保了我们最多从每一对禁止中选择一个。 然后，我们通过将它们用作前缀状态序列来排列它们，以便前缀异或差异保持有效。 

微妙的一点是，从 0 开始，如果我们选择一组代表，其中没有两个代表有不同$x$，那么归纳数组自动满足条件，因为任何子数组 XOR 都与两个选定的不同前缀状态的 XOR 完全对应，并且这样的一对永远不可能等于 0 或$x$。 

因此，该构造简化为在连接图中构建一个最大独立集$v$和$v \oplus x$，这是通过贪婪配对实现的。

 ## 算法演练

 1. 我们初始化一个包含所有值的已访问状态数组$[0, 2^n)$。 目的是确保我们永远不会选择禁止的异或对中的两个元素。 
2.我们迭代所有整数$v$从 0 到$2^n - 1$。 如果$v$尚未使用，我们尝试将其包含在构造中。 这种顺序是任意但固定的，这保证了确定性。 
3. 当我们选择一个值时$v$，我们标记两者$v$和$v \oplus x$如所用。 这可以防止选择两个状态，从而产生禁止的 XOR 差异$x$。 
4.我们追加$v$到所选前缀 XOR 状态的列表。 这份名单代表$p_0, p_1, \dots$固定后$p_0 = 0$。 
5. 构造完前缀异或序列后，我们通过取相邻的异或差将其转换为最终数组：$a_i = p_i \oplus p_{i-1}$。 

它起作用的原因与异或差异的结构有关。 每个子数组 XOR 等于两个前缀状态的 XOR。 因为我们永远不会从同一禁止对中选择两个状态$(v, v \oplus x)$，所选前缀之间的差异不能相等$x$。 独特性确保子数组 XOR 不会变为 0。此不变量在全局范围内保持，与顺序无关。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())
    N = 1 << n

    used = [False] * N
    p = []

    for v in range(N):
        if not used[v]:
            p.append(v)
            used[v] = True
            if v ^ x < N:
                used[v ^ x] = True

    # build array from prefix xor
    a = []
    for i in range(1, len(p)):
        a.append(p[i] ^ p[i - 1])

    print(len(a))
    if a:
        print(*a)

if __name__ == "__main__":
    solve()
```实现直接遵循配对思想。 数组`used`确保我们永远不会选择异或禁止对的两个端点。 名单`p`存储前缀 XOR 状态。 转换步骤`p[i] ^ p[i-1]`重建实际的数组元素。 

一个微妙的点是处理$v \oplus x$安全：即使原则上超出界限，它也始终保持在范围内，因为异或不会将位宽增加到超出范围$n$。

 ## 边缘情况

 当出现一种边缘情况时$x = 0$。 该约束禁止任何子数组 XOR 等于 0，这对于任何非空数组都是不可能的，因为每个单个元素子数组都有等于其自身的 XOR，并且在长构造中重复的前缀冲突是不可避免的。 该算法通过将每个值与其自身配对来处理此问题，有效地只允许每个值有一个代表，从而将结构折叠为一个非常小的安全集。 

另一个边缘情况是当$x$很大但仍在范围内。 即使$v \oplus x$超过$2^n - 1$，由于固定位宽 XOR，它永远不会发生，因此配对保持有效，无需额外的边界检查。 

最后的边缘情况是贪婪扫描顺序似乎产生次优配对。 由于每个冲突对于二元素异或对来说都是严格局部的，因此任何排序仍然会从每对中精确选择一个，因此结果大小是不变的，从而确保运行之间的一致性。
