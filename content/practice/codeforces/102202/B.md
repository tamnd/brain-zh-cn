 ## 解决方案
 ## 问题理解

 比赛结果形成有向锦标赛图。 每个学生都是一个顶点，并且对于每对不同的学生来说，存在一条有向边：如果学生 (i) 击败了学生 (j)，则存在一条边 (i \to j)。 

获胜路径就是该图中的一条有向路径。 从 (x) 到 (y) 的距离是最短有向路径长度，当 (y) 不可达时，其值为特殊值 (9000)。 一个学生的弱点是该学生与任何学生之间最大的距离。 我们需要输出一个弱点尽可能小的学生，以及最小的弱点。 

输入是（N \times N）字符矩阵。 第 (i) 行描述了涉及学生 (i) 的每场比赛，其中`W`表示边缘从 (i) 到该列的学生，并且`L`意味着边缘朝相反方向移动。 由于每对都只玩一次，因此这是一场锦标赛而不是任意有向图。 

约束（N \le 3000）是中心线索。 读取整个矩阵已经花费了 (O(N^2))，最大大小约为 900 万个字符，并且是完全合理的。 然而，(O(N^3)) 算法在 (N=3000) 时执行多达 (27) 十亿次基本图操作，远远超出了一秒的时间限制所能容忍的范围。 我们需要直接从锦标赛结构中提取更多信息，而不是计算所有对的最短路径。 

有两种简单的情况，粗心的解决方案可能会处理不当。 首先，学生与自己的距离是零，而不是一。 例如，```
2
-W
L-
```学生 1 直接击败了学生 2，因此与学生 1 的距离为 (0,1)，弱点为 (1)。 正确的输出是`1 1`。 将起始顶点计算为需要一步的解决方案可能会错误地报告 (2)。 

第二种情况是没有人直接击败所有人。 考虑循环锦标赛```
3
-LW
W-L
LW-
```学生 1 输给了学生 2，但学生 1 击败了学生 3，学生 3 击败了学生 2。因此，学生 1 在两场胜利之内达到了所有学生的目标，给出了弱点 (2)。 正确的输出是`2 1`。 简单地选择直接获胜次数最多的学生并假设答案总是 (1) 在这里会失败。 

第三个微妙之处是特殊值 (9000) 永远不需要出现在答案中。 锦标赛中始终包含一个学生，该学生最多可以在两个有向边上接触到所有其他学生。 下面的解决方案直接构造这样一个学生，因此最佳弱点始终是（1）或（2）。 

## 方法

 直接的方法是将结果视为有向图，并对每个学生进行广度优先搜索。 一次 BFS 计算距一名起始学生的所有最短距离，因此在运行 (N) 次 BFS 后，我们知道每个学生的弱点，并可以选择最小的一个。 使用邻接矩阵，每个 BFS 可以检查每个 (N) 个顶点的 (N) 个可能的出边，从而为每个源提供 (O(N^2)) 工作，并且总体为 (O(N^3))。 在 (N=3000) 时，这相当于 (3000^3 = 27{,}000{,}000{,}000) 次邻接检查，这太慢了。 

暴力方法之所以有效，是因为 BFS 完全符合获胜路径距离的定义。 问题是锦标赛包含比一般有向图更强的结构。 

关键的观察结果是，具有最大出度的顶点始终能够在最多两步内到达所有其他顶点。 这里，出度只是`W`该学生行中的字符。 

取一个最大出度的学生 (v)，并考虑 (v) 输给的另一个学生 (u)。 如果（v）不能在两步内到达（u），那么就不会有学生（w）使得（v）击败（w）并且（w）击败（u）。 由于每一对都只有一个获胜者，因此每个被 (v) 击败的学生也必须被 (u) 击败。 

这就产生了矛盾。 学生（u）击败了（v），并且（u）也击败了（v）击败的每个学生。 因此，(u) 的直接获胜次数严格大于 (v)，这与 (v) 作为最大出度学生的选择相矛盾。 

因此，每个学生要么直接输给 (v)，在这种情况下，存在一条通过某个中间学生的两条边路线，要么已经直接被 (v) 击败。 因此，最大出度学生的弱点最多为 (2)。 

这将整个问题简化为计算直接胜利。 如果某个学生赢得了 (N-1) 次胜利，那么他们的弱点恰好是 (1)，因为其他所有学生都是直接到达的。 否则，没有学生的弱点可以是（1），而最大出度的学生最多有弱点（2）。 因此它的弱点正是（2）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个学生都使用 BFS 进行暴力破解 | (O(N^3)) | (O(N^2)) | 太慢了 |
 | 最大出度 | (O(N^2)) | (O(N^2)) | 已接受 |

 ## 算法演练

 1. 读取完整的结果矩阵。 我们需要考察每一个角色，因为每个学生的直接获胜次数决​​定了候选人。 
2. 计算每一行有多少个字符`W`。 这个计数就是学生的出度，即学生直接击败的对手的数量。 
3.保留出度最大的学生。 我们还不需要构建任何路径，因为最大出度属性已经保证该学生在两步内到达每个人。 
4. 如果最大出度为(N-1)，则输出弱点(1)和该学生。 其他每个学生都是直接传出邻居，因此不需要大于 1 的正距离。 
5.否则，输出弱点(2)和同一个学生。 最大出度论证证明，每一个没有被直接击败的对手都可以通过一个中级学生到达。 由于被选中的学生并没有直接击败所有人，所以它的弱点不可能是（1），所以它恰好是（2）。 

### 为什么它有效

 令 (v) 为具有最大出度的学生。 假设（v）输给了某个学生（u）。 矛盾假设 (v) 不能分两步到达 (u)。 对于 (v) 击败的每个学生 (w)，(u) 也必须击败 (w)，因为否则 (v \to w \to u) 将是有效的两步路径。 由于(u)另外击败了(v)，所以(v)的每次直接胜利也是(u)的直接胜利加上(u)对(v)的胜利。 因此 (u) 的出度严格大于 (v)，与极大性相矛盾。 

因此每个顶点与 (v) 的距离最多为 2。 如果(v)有(N-1)次直接胜利，它的弱点是(1)。 如果它更少，它的弱点至少是 (2)，上面的论点给出了上限 (2)。 因此，所选学生的弱点恰好是最小可能值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    best_player = 0
    best_wins = -1

    for i in range(n):
        row = input().strip()
        wins = row.count('W')

        if wins > best_wins:
            best_wins = wins
            best_player = i

    weakness = 1 if best_wins == n - 1 else 2

    print(weakness, best_player + 1)

if __name__ == "__main__":
    solve()
```输入循环一次读取一整行并使用`count('W')`以获得学生的出度。 对角线`-`和所有`L`字符不需要特殊处理，因为它们都不代表当前行的学生直接获胜。 

比较使用`>`而不是`>=`。 任何一个选择都是正确的，因为允许多个最大出度的学生，但是使用`>`只是保留第一个这样的学生。 

最终测试是`best_wins == n - 1`， 不是`best_wins == n`。 学生无法击败自己，因此只有 (N-1) 种可能的直接胜利。 如果该条件成立，则在一条边上每隔一个顶点都会到达。 否则，最大出度定理给出的弱点恰好是二。 

答案将从零开始的 Python 索引转换回问题所需的从一开始的学生编号。 

Python 中不存在整数溢出问题，最大计数存储在`best_wins`只有(N-1)个。 处理每一行后不需要存储矩阵本身，这使得额外的内存使用量非常小。

```学生 1 击败学生 3，但输给学生 2。学生 2 也有一场直接获胜，学生 3 也有一场直接获胜。 

| 学生| 行| 直接获胜 | 最佳后排| 弱点决定|
 | ---| ---| ---| ---| ---|

 对于学生 1，到学生 2 的路径长度为 2：(1 \to 3 \to 2)。 最大出度定理保证了这样一条路径，而不需要我们明确地搜索它。 

没有学生有两次直接获胜，因此弱点（1）是不可能的。 学生 1 在两步内到达每个人，因此最小的弱点正是 (2)。 输出`2 1`是有效的。

## 测试用例

 以下测试工具实现了与函数相同的算法，以便可以检查返回的结果。 由于当存在多个 Gosu 时，该问题允许任何 Gosu，因此验证器会检查所报告的学生是否具有所声称的弱点，而不是要求一个确切的学生索引。```python
import sys
import io

def solve_data(inp: str) -> str:
    data = inp.strip().splitlines()
    n = int(data[0])

    best_player = 0
    best_wins = -1

    for i in range(n):
        wins = data[i + 1].count('W')
        if wins > best_wins:
            best_wins = wins
            best_player = i

    weakness = 1 if best_wins == n - 1 else 2
    return f"{weakness} {best_player + 1}"

def brute_weakness(rows, start):
    n = len(rows)
    dist = [-1] * n
    dist[start] = 0
    queue = [start]

    for v in queue:
        for u in range(n):
            if rows[v][u] == 'W' and dist[u] == -1:
                dist[u] = dist[v] + 1
                queue.append(u)

    if -1 in dist:
        return 9000
    return max(dist)

def check(inp: str, out: str):
    lines = inp.strip().splitlines()
    n = int(lines[0])
    rows = lines[1:]

    weakness, player = map(int, out.split())
    assert 1 <= player <= n
    assert weakness == brute_weakness(rows, player - 1)

    all_weaknesses = [brute_weakness(rows, i) for i in range(n)]
    assert weakness == min(all_weaknesses)

def run(inp: str) -> str:
    out = solve_data(inp)
    check(inp, out)
    return out

# Provided samples
run("""2
-W
L-
""")

run("""3
-LW
W-L
LW-
""")

run("""5
-WLLW
L-LLW
WW-LL
WWW-W
LLWL-
""")

# Minimum size
run("""2
-W
L-
""")

# Three-cycle, where every student has weakness 2
run("""3
-LW
W-L
LW-
""")

# Transitive tournament, where student 1 beats everyone directly
run("""4
-WWW
L-WW
LL-W
LLL-
""")

# Maximum-size input, a transitive tournament.
# Student 1 beats everybody, so the answer must have weakness 1.
n = 3000
rows = []
for i in range(n):
    row = ['-'] * n
    for j in range(i + 1, n):
        row[j] = 'W'
        row[i] = 'L'
    rows.append(''.join(row))

large_input = str(n) + '\n' + '\n'.join(rows) + '\n'
large_output = solve_data(large_input)
assert large_output == "1 1", "maximum-size transitive tournament"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`2 / -W / L-`|`1 1`| 最小值（N），直接获胜者，对角线的正确处理 |
 |`3 / -LW / W-L / LW-`|`2 1`或另一个有效的 Gosu | 一场没有普遍直接获胜者的锦标赛 |
 |`4 / -WWW / L-WW / LL-W / LLL-`|`1 1`| 最大出度为 (N-1) 的边界情况 |
 | 传递性锦标赛 (N=3000) |`1 1`| 最大输入大小和 (O(N^2)) 可扩展性 |

 对于 (N>2) 来说，字面上的“全等值”锦标赛是不可能的，因为每对必须恰好有一个获胜者和一个失败者。 最接近的相关测试是三周期测试，其中每个学生恰好有一次直接获胜，并且直接获胜计数相等。 该算法仍必须选择有效的学生并正确返回弱点 (2)。 

## 边缘情况

 对于最小规模的锦标赛```
2
-W
L-
```第一个学生的出度是(1=N-1)，而第二个学生的出度为零。 该算法选择学生 1 并返回弱点 (1)。 自距离为零，唯一的其他距离为 1，因此结果与定义完全匹配。 

对于没有普遍获胜者的锦标赛来说，```
3
-LW
W-L
LW-
```所有三名学生均获得一级学位。 该算法保留学生 1，因为它是第一个最大值。 学生1直接到达学生3并通过学生3到达学生2，所以它的弱点是(2)。 由于没有学生 (N-1=2) 直接获胜，弱点 (1) 是不可能的。 

对于一个学生赢得每场比赛的边界情况，```
4
-WWW
L-WW
LL-W
LLL-
```学生 1 的出度为 3，等于 (N-1)。 该算法立即分配弱点 (1)。 其他所有学生的出度都较小，因此选择学生 1 显然也是最优的。 

最大的箱子可容纳 3000 名学生。 通过让学生（i）击败具有更大索引的每个学生，可以形成传递锦标赛。 然后学生 1 有 2999 场直接胜利，因此算法返回`1 1`。 该实现正好处理 3000 行并计算它们的数量`W`字符，总共约九百万个矩阵条目。 它从不执行 BFS 或构造距离矩阵，这就是二次方法在上限仍然实用的原因。
