 ## 解决方案
 ## 问题理解

 我们被要求确定波利卡普斯在电视节目的一季中没有看过哪一集。 他总共看了 _n_ 集，每集从 1 到 _n_ 连续编号。 输入为我们提供了 _n_，剧集总数，以及表示他已经看过的剧集的 _n_ - 1 个整数列表。 任务是找到丢失的剧集编号。 

鉴于 _n_ 可以大到 100,000，任何扩展性低于 O(n) 的解决方案都可能变得太慢。 例如，在最坏的情况下，重复扫描列表中从 1 到 _n_ 的每个数字将是 O(n²)，这对于 n ≈ 10⁵ 来说慢得令人无法接受。 我们需要一个执行线性传递或使用数学属性来减少工作的解决方案。 

当缺失的剧集是第一集 (1) 或最后一集 (n) 时，会出现不明显的边缘情况。 例如，如果 n = 3 并且观看的剧集为 [2, 3]，则缺失的剧集为 1。任何假设缺失剧集位于列表中间某处的解决方案都会失败。 类似地，如果 n = 3 时观看的剧集为 [1, 2]，则缺失的剧集为 3，如果数组边界处理不当，则可能会忽略该剧集。 

## 方法

 暴力方法会迭代数字 1 到 _n_，检查每个数字是否存在于监视列表中。 这是有效的，因为列表包含 1 到 _n_ 范围内的不同整数，因此任何缺失的数字都是答案。 然而，检查大小为 _n_ - 1 的列表中的成员资格的时间复杂度为 O(n)，因此这种简单的方法将执行 O(n²) 操作。 对于 n = 100,000，这大约是 10^10 次操作，这对于 1 秒的时间限制来说太慢了。 

最佳方法依赖于一个简单的数学属性。 前n个自然数的和为n*(n+1)/2。 如果我们计算这个总和并减去所有观看剧集的总和，则差值必定是缺失的剧集。 这是有效的，因为观看的剧集恰好覆盖了所有其他数字一次。 总和计算和减法都是 O(n)，因此总运行时间是线性的并且完全符合约束条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 总差| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取总集数，n。 这告诉我们有效剧集编号的范围。 
2. 读取n - 1 观看过的剧集列表。 每个数字保证是不同的并且在 1 到 n 之间。 
3. 使用公式 n*(n+1)//2 计算所有 n 个集数的总和。 这给出了如果没有丢失任何剧集的话我们将得到的总和。 
4. 计算已观看剧集的总和。 这捕获了我们看到的所有数字。 
5. 从总和中减去已观看剧集的总和。 结果是 Polycarpus 忘记观看的集数。 
6. 打印这个缺失的剧集编号。 

确保正确性的关键属性是从 1 到 n 的所有不同数字的总和减去其中任何 n - 1 的总和恰好留下一个缺失的数字。 无论缺少哪一集，包括第一集或最后一集，这都有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
watched = list(map(int, input().split()))

total_sum = n * (n + 1) // 2
watched_sum = sum(watched)

missing_episode = total_sum - watched_sum
print(missing_episode)
```该代码读取 n 和已观看剧集的列表。 它使用整数除法计算前 n 个自然数的总和，以避免浮点问题。 然后，它计算已观看剧集的总和，并将其从总和中减去。 最后，它打印丢失的剧集。 一个常见的错误是忘记整数除法或使用浮点除法，这可能会给出不正确的结果。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    watched = list(map(int, input().split()))
    total_sum = n * (n + 1) // 2
    watched_sum = sum(watched)
    return str(total_sum - watched_sum)

# provided sample

 ## 边缘情况

 如果缺失的剧集是第一集，例如 n = 3、watched = [2, 3]、total_sum = 6、watched_sum = 5，则算法返回 1，这是正确的。 如果缺失的剧集是最后一集，例如，n = 3、watched = [1, 2]、total_sum = 6、watched_sum = 3，则算法返回 3。在所有情况下，总和差值捕获准确的缺失数字，无论其在列表中的位置如何。
