 ## 解决方案
 ## 问题理解

 我们被要求重建一个二进制字符串，给出其连续对的计数，并按它们包含的数量进行分组。 输入提供三个整数：$n_0$是相邻对“00”的数量，$n_1$计算只有一个“1”（“01”或“10”）的对，并且$n_2$计数对“11”。 我们的目标是生产任何字符串$s$其连续对与这些计数相匹配。 

问题归结为决定在块中放置多少个连续的零和一以及如何交错它们以便交替对占$n_1$。 每对恰好贡献三个计数之一，因此字符串长度是隐式确定的：如果$n_0 > 0$，我们必须有$n_0 + 1$连续的零，类似地$n_2 > 0$需要$n_2 + 1$连续的。 要考虑的交替序列$n_1$可以从零或一开始，具体取决于存在哪个块。 

当以下情况之一发生时，会出现不明显的边缘情况$n_0$或者$n_2$为零。 例如，如果$n_0 = 0$，不存在“00”对，因此字符串不能以多个零开头。 盲目构建区块的粗心实现可能会产生额外的对，从而违反计数。 同样，当$n_1 = 0$，0 和 1 之间不能交替，因此字符串必须完全由连续的 0 或 1 组成。 

约束很小（$0 \le n_i \le 100$），所以一个$O(n_0 + n_1 + n_2)$建设就足够了。 我们不需要优化超出相对于计数总和的线性时间。 

## 方法

 暴力方法是枚举所有长度的字符串$n_0 + n_1 + n_2 + 1$并计算对数，接受匹配的字符串。 这是正确的，但显然不可行：对于长度为 200 的字符串，有$2^{200}$候选者，远远超出了计算极限。 

关键的观察是连续的零或一的块生成可预测的对计数：$k$零产生$k-1$“00”对，以及一个块$m$产生$m-1$“11”对。 长度交替序列$l+1$准确地生产$l$交替对。 因此，我们可以直接构造块：长度为零的块$n_0 + 1$, 一个长度的块$n_2 + 1$，以及长度的交替序列$n_1 + 1$。 我们只需要决定在哪里插入交替序列，以便它根据需要连接或分隔零和一块。 

这一观察将问题简化为连接最多三个序列，给出$O(n_0 + n_1 + n_2)$考虑到约束条件，这是可以接受的解决方案。

 ## 算法演练

 1.初始化一个空字符串`s`。 
2.如果`n_0 > 0`，附加一个长度为零的块`n_0 + 1`到`s`。 这准确地保证了`n_0`“00”对。 
3.如果`n_2 > 0`，附加一个长度为 1 的块`n_2 + 1`到`s`。 这准确地保证了`n_2`“11”对。 
4.如果`n_1 > 0`，构造长度为 0 和 1 的交替序列`n_1 + 1`。 如果`s`为空，从零开始； 否则，从最后一个字符的补码开始`s`以避免创建额外的对。 
5. 将交替序列连接成`s`。 添加的交替对的数量正好是`n_1`，因为序列中的每个相邻对都贡献一个交替对。 
6. 返回`s`。 

为什么它起作用：每种类型的对都由显式构造处理：零块精确产生`n_0`“00”对，一个区块产生`n_2`“11”对，交替序列产生`n_1`“01”/“10”对。 小心地进行连接以避免生成额外的不需要的对。 由于所需对的总数决定了块长度，因此这种构造保证产生有效的字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n0, n1, n2 = map(int, input().split())
        res = []

        if n0 > 0:
            res.append('0' * (n0 + 1))
        if n2 > 0:
            res.append('1' * (n2 + 1))

        if n1 > 0:
            alt = []
            start = '0' if not res else ('1' if res[-1][-1] == '0' else '0')
            for i in range(n1 + 1):
                alt.append(start)
                start = '1' if start == '0' else '0'
            res.append(''.join(alt))

        print(''.join(res))

solve()
```该解决方案构造零块如果`n_0`是正数并且一个块如果`n_2`是积极的。 构建交替块时要仔细注意起始字符，以防止不需要的配对。 块的串联产生满足所有三个计数的字符串。 不会发生相差一的错误，因为我们为每个块长度加 1，并且交替序列总是产生精确的结果`n_1`对。
