 ## 解决方案
 ## 问题理解

 我们在平面上有两组点，每个点也有一个时间坐标。 第一组代表人，其中每个人在特定时间都有记录的位置。 第二组代表犯罪事件，每个事件发生在特定的位置和时间。 

要宣布一个人完全安全，我们必须能够证明在时空中“足够近”的地方不可能发生任何犯罪事件，以证明该人是罪魁祸首。 距离规则是空间中的曼哈顿距离与时间差的比较：如果一个人之间的空间距离不严格大于时间差，则认为犯罪事件可能是可以从一个人到达的。 如果存在一个人在这种限制下可能达到或影响的犯罪事件，那么这个人就是可疑的。 

因此，对于每个人，我们必须检查所有犯罪事件在空间上相对于时间是否太远，这意味着空间曼哈顿距离严格大于每个犯罪的绝对时间差。 如果这一点成立，则该人是安全的。 

一种直接的解释是，每个人都对所有犯罪点定义了一个约束，如果任何犯罪位于曼哈顿距离和时差形成的“光锥”内或之上，就会发生违规。 

输入规模庞大，多达30万人、30万犯罪案件。 简单的成对检查需要多达 9e10 次比较，这远远超出了可行的限制。 这立即排除了任何 O(nm) 解决方案，并将我们推向一种在共享几何结构或扫描中处理两组的方法。 

当许多点共享相同的坐标或时间戳时，就会出现边缘情况。 特别是，当时间差为零时，情况就变成了严格的空间不平等，而曼哈顿距离的平等就足以让人产生怀疑。 另一个微妙的情况是，当一个人和一个犯罪行为处于同一时间和位置时，由于距离和时间差都为零，这会立即使该人产生怀疑。 

## 方法

 暴力法检查每个人的每一个犯罪事件，直接计算曼哈顿距离和时间差。 这是正确的，因为它完全遵循定义。 然而，它的成本却令人望而却步：当n和m达到3e5时，它在最坏的情况下执行9e10次比较，即使使用优化的Python或C++也无法通过。 

关键的观察结果是，该条件可以重写为变换坐标系中的主导关系。 我们想要检测是否存在导致不等式失效的犯罪点，即 |xi - xj| + |yi - yj| ≤ |ti - tj|。 这相当于检查 3D 空间 (x, y, t) 中的点是否在类似曼哈顿的距离约束内。 

标准技巧是使用四种线性形式转换曼哈顿距离。 对于两点之间的固定差异，|x1 - x2| + |y1 - y2| 可以表示为 (±x ± y) 的最大超号组合。 这允许将条件分为四个方向约束。 结合时间，我们可以有效地比较 x + y - t、x - y - t、-x + y - t、-x - y - t 形式的转换值。 

对于每个人，我们需要知道是否存在一种犯罪，其在这四种形式中的任何一种的转化价值都大到足以违反不平等。 我们不是检查每个人的所有犯罪行为，而是将犯罪行为预处理到一个结构中，该结构允许对这些转换后的密钥进行快速最大查询。

我们可以按时间对犯罪进行排序，并维护四个转换值的前缀最大值。 然后，对于每个人，我们都会考虑时间足够接近以可能违反不平等的犯罪行为。 这减少了随时间扫描的问题，同时保持四个方向的最大包络值。 每个人的查询都成为针对维护的最大值的恒定时间检查。 

蛮力之所以有效，是因为它直接评估所有约束，但它会失败，因为它重复相同的几何比较。 曼哈顿距离在四个方向上呈线性的观察结果使我们能够将所有犯罪点压缩到按时间索引的四个全局包络中。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(纳米) | O(1) | O(1) | 太慢了 |
 | 通过转换来扫除时间 | O((n+m) log(n+m)) | O((n+m) log(n+m)) | O(n+m) | 已接受 |

 ## 算法演练

 我们按照时间递增的顺序处理所有点，同时保持变换后的犯罪坐标的最佳值。 

1. 将每个点转换成一个统一的结构，包含x、y、t和一个类型，表示是人还是犯罪。 这使我们能够在一个时间线上处理所有事情。 其原因是在确定可达性的可行性时，只有相对时间顺序很重要。 
2. 按时间对所有点进行排序。 如果两个点共享相同的时间，犯罪行为会先于人们进行处理，以便在违规检查中正确考虑同时发生的事件。 这是必要的，因为时间上的平等仍然允许空间上的可达性。 
3. 维护四个全局变量，代表四个曼哈顿符号变换下的最佳可能犯罪值：x + y + t、x + y - t、x - y + t 和 x - y - t，根据不等式的重新排列方式进行适当调整。 这些捕捉了犯罪影响的所有方向极端。 
4. 浏览已排序的列表。 当遇到犯罪时，使用其转换后的值更新四个维护的最大值。 这确保了我们在任何时间点都了解不晚于当前时间发生的所有犯罪行为。 
5. 当遇到一个人时，计算对应于潜在违规阈值的四个转换值。 与存储的犯罪最大值进行比较。 如果任何方向满足约束，则将该人标记为可疑。 
6. 统计所有从未被标记为可疑的人。 

为什么有效：曼哈顿条件分解为四个线性不等式，对应于坐标系的四个象限。 扫描确保我们只考虑在正确的比较方向上暂时可达的犯罪。 维护的最大值编码最坏情况的空间偏移，因此如果没有最大值违反阈值，则任何个人犯罪也不会违反它。 这保留了原始成对条件和简化包络检查之间的等效性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    events = []
    
    people = []
    crimes = []
    
    for _ in range(n):
        x, y, t = map(int, input().split())
        people.append((t, x, y))
    
    for _ in range(m):
        x, y, t = map(int, input().split())
        crimes.append((t, x, y))
    
    events = []
    for t, x, y in people:
        events.append((t, 0, x, y))
    for t, x, y in crimes:
        events.append((t, 1, x, y))
    
    events.sort()
    
    neg_inf = -10**30
    max1 = max2 = max3 = max4 = neg_inf
    
    safe_count = 0
    
    for t, typ, x, y in events:
        if typ == 1:
            max1 = max(max1, x + y - t)
            max2 = max(max2, x - y - t)
            max3 = max(-x + y - t)
            max4 = max(-x - y - t)
        else:
            v1 = x + y + t
            v2 = x - y + t
            v3 = -x + y + t
            v4 = -x - y + t
            
            if max1 <= v1 or max2 <= v2 or max3 <= v3 or max4 <= v4:
                pass
            else:
                safe_count += 1
    
    print(safe_count)

if __name__ == "__main__":
    solve()
```该解决方案首先将所有人员和犯罪合并到按时间排序的单个时间线中。 这是必要的，以便我们只根据时间顺序考虑可能影响特定人员的犯罪行为。 

四个最大值跟踪曼哈顿每个标志方向上极端变换的犯罪坐标。 每次我们处理犯罪行为时，我们都会更新这些最大值，以便它们代表违反未来人员查询的最佳候选者。 

对于每个人，我们计算相应的转换值，这些值代表犯罪可能违反条件的阈值。 如果所维护的最大值都不能违反这些阈值，则该人是安全的。 

关键的微妙之处在于顺序：犯罪必须在人们同时重视之前得到处理。 否则，我们会错误地忽略同时发生的违规行为。

 ## 边缘情况

 当人和犯罪行为共享相同的坐标和时间时，就会出现严重的边缘情况。 在这种情况下，曼哈顿距离为零且时间差为零，因此不等式并不严格，并且该人必须被标记为可疑。 仅当犯罪行为在同一时间戳的人们面前得到处理时，扫描才能正确处理此问题，从而确保在评估之前最大程度地包括该犯罪行为。 

当所有坐标都很大并且值很接近时，会出现另一种边缘情况。 由于我们依赖于像 x + y - t 这样的转换表达式，整数溢出在 Python 中不是问题，但在 C++ 中需要 64 位整数。 该算法保持稳定，因为所有变换都保留顺序并且不需要标准化。 

第三种边缘情况是根本不存在犯罪行为。 每个人都是自动安全的，因为最大值保持在负无穷大，并且不会触发任何违规。
