 ## 解决方案
 ## 问题理解

 我们得到了一张代表监狱般迷宫的图表。 K 开始时有一个特殊的起始节点，一组节点称为“漏斗”，另一组节点称为“门”。 剩下的结构是连接所有节点的无向​​图。 关键约束是门节点的行为就像上锁的房间：除非已经获得了对应的钥匙，否则 K 无法进入门节点。 

钥匙的数量与门的数量完全相同，并且每把钥匙都与一扇门唯一关联。 每把钥匙都恰好放置在一个漏斗节点中。 一旦 K 到达漏斗，他就会获得那里存储的所有钥匙，并且这些钥匙将永久解锁相应的门。 

任务是计算有多少种方法将 m 个不同的密钥分配给 n 个漏斗节点，使得 K 能够从节点 1 开始，穿过图，从访问过的漏斗中收集密钥，最终到达并打开每个门节点，使整个图可遍历。 

重要的微妙之处在于可达性随着时间的推移而变化。 门节点会阻止遍历，直到找到其钥匙，并且该钥匙本身可能位于其他门后面，因此门的可访问顺序取决于图结构和钥匙的放置位置。 

约束很小：n 和 m 最多为 11，因此门子集上的状态总数最多为 2048。这强烈表明，任何涉及门子集枚举和排列动态规划的解决方案都是可行的，而任何超过 m 的指数都太大了。 特别是，直接迭代所有赋值将是 n^m，即使在 n = 11 和 m = 11 时，就概念分支而言，这也太大了，因此解决方案必须避免显式推理每个赋值，而是以组合方式聚合。 

一个常见的失败案例来自于忽略门的可达性和先前打开的门之间的依赖性。 

例如，如果一扇门位于通往包含料斗的区域的所有路径上，那么“如果图已连接，则任何分配都有效”的天真假设立即就会被打破。 在图中，节点 2 是门，节点 3 是料斗，并且 1 仅通过 2 连接才能到达 3，那么如果门 2 的钥匙尚未位于从节点 1 不经过 2 即可到达的料斗中，则该配置将无效。 忽略锁定效果的简单可达性检查会错误地计算此类分配。 

另一个陷阱是假设键之间是独立的。 即使每把钥匙都独立地放入漏斗中，钥匙是否可用取决于在需要门时是否可以到达其漏斗，这取决于之前打开的门。 这引入了不可忽视的排序约束。 

## 方法

 蛮力解释很简单。 我们尝试将 m 个不同的键分配到 n 个漏斗中的所有可能的分配方式。 对于每个分配，我们模拟 K 是否可以打开从节点 1 开始的所有门。该模拟本身需要在某些节点被锁定的图中重复计算可达性，并在找到密钥时动态解锁它们。 即使优化了可达性检查，单独的分配数量也是 n^m，在最坏的情况下是 11^11，远远超出了任何可行的限制。 

关键的观察结果是，该过程的结构仅取决于哪些门已经打开，而不取决于它们如何打开的确切历史。 一旦门的子集打开，从节点 1 可到达的节点集就被明确定义，并且可以确定性地计算。 这意味着我们可以将所有动态行为压缩为门子集上的函数。

我们不是首先考虑任务，而是扭转观点。 确定开门顺序。 对于任何这样的顺序，当我们到达打开的门的前缀时，图中的可到达区域是固定的。 门的钥匙必须放置在订单中处理门时位于可触及区域的任何料斗中。 

这将问题转化为对门的所有排列求和，其中每个排列贡献与前缀相关的可达料斗计数的乘积。 该结构适合于排列上的子集动态规划。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过模拟对作业进行暴力破解 | O(n^m · (n+m) · r) | O(n^m · (n+m) · r) | O(n+m+r) | 太慢了|
 | 具有可达性预计算的门排列子集 DP | O(2^m·(r + m·2^m)) | O(2^m·(r + m·2^m)) | O(2^m + r) | O(2^m + r) | 已接受 |

 ## 算法演练

 我们对每个门子集 S 进行编码，并预先计算当 S 中的门被认为是打开时，图的哪些部分是可到达的。 

1. 对于门的每个子集 S，使用 BFS 或 DFS 计算从节点 1 可到达的节点集。 在这个遍历过程中，我们可以自由地通过漏斗节点，并且只有当门节点包含在S中时，我们才可以通过门节点。这就产生了一个可达区域R(S)。 

这样做的原因是，一旦我们修复了哪些门打开，该图就成为标准的无向图，并删除了一些阻塞的顶点，因此可达性是明确定义的。 

1. 对于每个子集 S，计算 f(S)，即 R(S) 内的漏斗节点数。 这表示如果 S 中的门已经打开后，如果对应的门是下一个要打开的门，则存在多少种放置钥匙的有效选择。 
2. 定义一个动态规划表 dp[S]，其中 S 表示已按某种打开顺序选择的一组门。 dp[S] 存储恰好打开 S 中的门的所有排列的总贡献，其中贡献根据每一步的可达选择进行累积。 
3. 初始化 dp[empty set] = 1，因为只有一个空排序。 
4. 迭代所有子集 S。对于不在 S 中的每个门 x，计算 S2 = S union {x}。 任何以 S2 结尾的排列都可以通过选择 x 作为隔壁来扩展以 S 结尾的排列来形成。 该扩展的贡献乘以 f(S2)，因为当 x 打开时，S2 中的门已经打开。 
5. 对每个此类转换累加 dp[S2] += dp[S] * f(S2)。 
6. 最终答案是 dp[所有门]，因为每个完整排列都会贡献其可达选择的完整乘积。 

### 为什么它有效

 DP 不变量是 dp[S] 已经聚合了对 S 中的门进行排序的所有可能方式，并且每个此类排序都带有与每个前缀处的可达料斗计数相对应的正确累积乘法权重。 因为 f(S) 仅取决于一组已打开的门，而不取决于它们的顺序，所以通过新门 x 扩展 S 的任何有效顺序都会正确地附加下一个因子 f(S ∪ {x})，而不会产生歧义。 这确保了每个排列都以其正确的权重精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m, r = map(int, input().split())
    N = n + m
    
    adj = [[] for _ in range(N)]
    for _ in range(r):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    hoppers = set(range(1, n + 1))
    doors = list(range(n + 1, n + m + 1))
    door_idx = {doors[i]: i for i in range(m)}

    def reachable(mask):
        q = deque([0])
        vis = [False] * N
        vis[0] = True
        
        while q:
            u = q.popleft()
            for v in adj[u]:
                if vis[v]:
                    continue
                if v in hoppers:
                    vis[v] = True
                    q.append(v)
                else:
                    i = door_idx[v]
                    if (mask >> i) & 1:
                        vis[v] = True
                        q.append(v)
        return vis

    f = [0] * (1 << m)
    for mask in range(1 << m):
        vis = reachable(mask)
        cnt = 0
        for i in hoppers:
            if vis[i]:
                cnt += 1
        f[mask] = cnt

    dp = [0] * (1 << m)
    dp[0] = 1

    for mask in range(1 << m):
        if dp[mask] == 0:
            continue
        for i in range(m):
            if not (mask >> i) & 1:
                nmask = mask | (1 << i)
                dp[nmask] += dp[mask] * f[nmask]

    print(dp[(1 << m) - 1])

if __name__ == "__main__":
    solve()
```BFS 例程在一组固定的打开门下构建可达性。 关键的实现细节是将门视为阻塞节点，除非它们的位被设置在掩码中。 漏斗总是可遍历的，这使得它们充当图的永久部分。 

DP 转换依赖于按升序迭代子集，因此每个 dp[mask] 在使用时就已最终确定。 每个转换都乘以 f[nmask]，而不是 f[mask]，因为下一扇门的钥匙必须位于该门被视为打开后的可达区域中。

| 面膜| 开门| 可到达的料斗 |
 | --- | --- | --- |
 | 00 | 00 无 | 取决于初始连接 |
 | 01 | 门 1 | 扩大区域 |
 | 10 | 10 门 2 | 扩大区域 |
 | 11 | 11 两者 | 全面覆盖 |

 DP 累积两扇门上的排列。 从空集开始，我们分为两个选择，每个选择都根据打开门后可到达的料斗计数进行加权。 处理完两个订单后，最终的总和将两个排列及其各自的可达性约束聚合起来，产生总的有效分配。 

这表明，即使具有相同的图结构，不同的门顺序也会产生不同的可达集，这会直接改变有效钥匙放置的数量。 

### 示例 2

 输入：```
3 3
1-5-6 structure with multiple cross links
```这里的关键行为是，某些门只有在打开其他门后才能到达，因此某些排列早期贡献零或较小的权重，但稍后贡献更大的权重。 DP 会自动捕获这一点，因为一旦关键门包含在 S 中，f(S) 就会急剧增加。 

跟踪证实，无效的早期开口自然会被排除，因为当门阻挡所有料斗的访问时，f(S) 变为零或变小。

 ## 边缘情况

 当一扇门完全阻挡除其自身之外的所有料斗的通道时，就会出现一种边缘情况。 在这种情况下，如果在排列的早期没有打开该门，则该前缀的可达料斗集将变空，导致 f(S) 为零并消除所有延迟它的排列。 DP 正确地处理了这个问题，因为此类子集的权重为零并且不会进一步传播。 

另一种边缘情况是起始节点与所有料斗隔离，除非打开特定的门。 空掩码的 BFS 将产生零可到达的漏斗，使得以另一扇门开始的任何排列立即贡献为零，确保只有有效的打开订单才能生存。 

最后的边缘情况是多个门在图结构中可以互换。 DP 自然地单独计算所有排列，因为每个排序都被不同地处理，但它们共享相同的 f(S) 值，从而导致正确的乘法对称性，而不会过度计数或低估。
