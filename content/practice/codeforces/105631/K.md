 ## 解决方案
 ## 问题理解

 我们从包含从 1 到 n 的所有整数的集合中重复抽取数字，并进行替换。 每次抽签都是独立且均匀随机的，因此任何长度为 m 的序列只是一个有序的 m 元组，其中每个位置可以是从 1 到 n 的任何值。 

对于每个这样的序列，我们只关心两个值：序列中出现的最小元素和出现的最大元素。 如果我们分别称它们为 b 和 a，则该序列贡献值 (a − b)²。 

任务不是评估单个随机序列的值，而是对长度为 m 的每个可能序列求和该值。 由于存在 n^m 个序列，因此我们可以有效地按顺序聚合所有可能的多重集上的函数。 

主要困难在于该函数仅取决于序列的极值，但这些极值是由许多不同的序列引起的。 简单的枚举需要迭代所有 n^m 序列，即使对于非常小的参数也是不可能的。 

考虑结构的一个有用方法是按序列的最小值和最大值对序列进行分组。 一旦对（最小值，最大值）固定，所有具有这些极值的序列的贡献就可以组合计数。 

当序列中的所有元素都相同时，会出现微妙的边缘情况。 在这种情况下，最小值等于最大值，贡献为零。 任何正确的表述都必须确保这些情况不会引入虚假的非零贡献。 

另一个边缘情况是 m = 1 时。每个序列的 min = max，因此无论 n 如何，答案都必须始终为零。 任何意外计算小间隔内无效包含-排除项的公式都必须干净地处理这个问题。 

## 方法

 直接的强力方法将生成长度为 m 的每个序列并计算其最小值和最大值。 这需要 O(n^m · m) 时间，因为计算每个序列的最小值和最大值会花费 m 的线性时间。 一旦 n 和 m 超过小常数，即使存储或迭代 n^m 序列也是不可行的，因此这个方向立即被排除。 

关键的结构观察是序列的贡献仅取决于其最小值和最大值，而不取决于内部排列。 我们不再考虑序列，而是将视角转向表示序列可能值范围的区间 [i, j]。 对于固定对 (i, j)，我们计算有多少个长度为 m 的序列仅使用该区间内的值，同时包含至少一个 i 和至少一个 j。 每个这样的序列都贡献 (j − i)²。 

如果我们表示 k = j − i + 1，则仅使用区间内的值的序列数为 k^m。 其中，我们减去那些缺失的 i 和那些缺失的 j，然后将缺失两个端点的添加回来。 这会产生一个标准的包含-排除表达式：

 k^m − 2·(k−1)^m + (k−2)^m。 

将所有间隔相加并按距离平方加权得出最终答案。 用距离 d = j − i 重写可以简化外部总和，因为该宽度的区间恰好有 (n − d) 个选择。 

这将问题从指数枚举简化为远距离的单次线性扫描，并使用模幂来评估功效。

 ## 算法演练

 我们将问题转化为对最小值和最大值之间的可能距离求和。

1. 固定最小值和最大值之间的距离 d。 这意味着我们考虑 [1, n] 内的所有区间 [i, i + d]。 恰好有 n − d 个这样的区间，因为 i 的范围可以从 1 到 n − d。 
2. 对于每个这样的区间，计算 k = d + 1，即区间内允许的不同值的数量。 
3. 计算长度为 m 且完全位于该区间内并接触两个端点的序列。 我们从所有 k^m 序列开始。 
4. 减去从不使用下端点的序列，该序列只能使用 k − 1 个值，贡献 (k − 1)^m。 
5. 减去从不使用上端点的序列，再次贡献 (k − 1)^m。 
6. 添加回避免两个端点的序列，该序列使用 k − 2 值，贡献 (k − 2)^m。 
7. 将所得计数乘以 d2，因为每个此类序列的 (max − min)2 都等于 d2。 
8. 累加从 1 到 n − 1 的所有 d。 

唯一的计算挑战是评估大模数下许多基 x 的幂 x^m。 每次求幂都是通过二进制求幂完成的。 

它起作用的原因来自于按极值对序列进行分区。 每个序列都有一个唯一的对（最小值、最大值），对于固定对，包含排除公式会精确计算其值集跨越整个区间的序列。 没有序列在不同的时间间隔内被计数两次，因为（最小，最大）对唯一地确定其贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, e):
    res = 1
    a %= MOD
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n, m = map(int, input().split())
    
    if m == 1:
        print(0)
        return

    ans = 0

    for d in range(1, n):
        k = d + 1

        total = mod_pow(k, m)
        minus1 = mod_pow(k - 1, m) if k - 1 >= 0 else 0
        minus2 = mod_pow(k - 2, m) if k - 2 >= 0 else 0

        cnt = (total - 2 * minus1 + minus2) % MOD
        ans = (ans + cnt * (d * d % MOD) * (n - d)) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```实现直接遵循基于距离的分解。 d 上的循环表示最小值和最大值之间所有可能的差距。 对于每个间隙，我们计算对应于 k^m、(k−1)^m 和 (k−2)^m 的三个模幂。 

一个常见的陷阱是错误处理较小的 k 值。 当 k 为 1 或 2 时，(k−2)^m 或 (k−1)^m 等项涉及零或负基数。 在模算术中，当 m > 0 且等于零时，0^m 是安全的，但负基数不能按字面意思解释。 该代码通过限制无效的情况来避免这种情况。 

另一个微妙之处是，必须在计算包含-排除计数后乘以 (n − d)，因为它表示间隔的有效起始位置的数量。 

## 工作示例

 考虑一个小情况 n = 3, m = 2。 

我们迭代 d = 1 和 d = 2。 

对于 d = 1，k = 2。我们有：

 k^2 = 4

 (k−1)^2 = 1

 (k−2)^2 = 0

 因此 cnt = 4 − 2·1 + 0 = 2。有 (3 − 1) = 2 个该大小的区间，因此贡献为 2 · 1² · 2 = 4。 

对于 d = 2，k = 3。我们有：

 3^2 = 9

 2^2 = 4

 1^2 = 1

 所以 cnt = 9 − 2·4 + 1 = 2。有 (3 − 2) = 1 个区间，所以贡献为 2·4·1 = 8。 

总数为 12。

 | --- | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 2 | 4 | 1 | 0 | 2 | 2 | 4 |
 | 2 | 3 | 9 | 4 | 1 | 2 | 1 | 8 |

 这证实了分解与样本行为正确匹配。 

第二种合理情况是 n = 2，m = 1。每个序列的长度为 1，因此最小值等于最大值，并且答案必须为零。 循环仍然运行，但 cnt 对于每个 d 计算为零，确保没有意外贡献。

 ## 边缘情况

 当 m = 1 时，每个序列都包含一个值。 最小值和最大值重合，因此每个贡献都为零。 该算法通过在任何幂计算之前提前返回来处理这个问题，避免不必要的工作并防止在微小间隔大小下对包含-排除项的误解。 

当n = 1时，无论m如何，都只有一个可能的序列。 由于不存在有效的 d ≥ 1，因此不会执行距离循环，因此答案自然保持为零。 

当 d = 1 时，区间大小为 k = 2，(k−2)^m 项变为 0^m。 由于 m ≥ 1，它安全地为零，这与单元素字母表上不存在使用两个端点的序列这一事实相匹配。
