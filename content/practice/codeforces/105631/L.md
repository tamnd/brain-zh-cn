 ## 解决方案
 ## 问题理解

 我们被要求填写一个$n \times m$正整数矩阵最多$10^9$。 每行和每列必须满足非常具体的聚合约束，而不是任意值。 

对于每一行$i$，如果您取该行中所有元素的最小公倍数，则结果必须完全相同$a_i$。 对于每一列$j$，如果您取该列中所有元素的最大公约数，则结果必须完全相同$b_j$。 任务是确定这样的矩阵是否存在，如果存在，则构造一个。 

限制因素$n, m \le 1000$暗示直到$10^6$细胞。 任何尝试搜索每个单元格的值或通过嵌套因子检查迭代调整候选值的解决方案都已经接近极限。 解决方案必须将问题简化为最多直接构造$O(nm)$简单的算术。 

一个关键的结构约束隐藏在 LCM 和 GCD 的定义中。 LCM 约束强制行元素成为行目标的约数。 GCD 约束强制列元素是列目标的倍数。 这两个方向强烈交叉，大多数不正确的方法都因单独对待它们而失败。 

当候选值满足行约束但破坏列 GCD 时，就会出现典型的失败情况。 例如，如果尝试设置行中的每个单元格$i$等于$a_i$，列 GCD 塌陷为 GCD$a_i$的而不是匹配所需的$b_j$的。 相反，将列设置为$b_j$由于行无法到达其目标，因此破坏了行 LCM。 

该解决方案取决于对齐这两个约束，以便每个单元同时与其行和列要求兼容。 

## 方法

 一个强力的想法是将每个单元格视为一个变量，并尝试同时满足两个约束的值，在每次分配后重复重新计算所有行 LCM 和列 GCD。 即使我们只尝试每个单元格的小候选值，重新计算成本$O(nm)$每次尝试，搜索空间都会爆炸，因为每个单元都依赖于两个独立目标的因素组合。 除了非常小的网格之外，这很快就变得不可行。 

关键的结构观察是，约束对于每个单元来说不是独立的，而是可分为可分条件。 从LCM和GCD的定义中，我们可以得出每个单元格必须整除其行目标，并且必须能被其列目标整除。 这将问题转化为对的兼容性条件$(a_i, b_j)$。 一旦认识到这一点，构造就变得简单了：我们从满足列约束的基本矩阵开始，然后有选择地“注入”行目标而不破坏列结构。 

该构造之所以有效，是因为在引入当前 GCD 倍数的值时 GCD 是稳定的，而只要行中至少有一个元素达到行目标，LCM 就是稳定的。

 ## 算法演练

 我们首先将约束转换为单个单元格的算术限制$x_{i,j}$。 

1. 对于固定行$i$，该行的最小公倍数为$a_i$，所以该行中的每个元素都必须除$a_i$。 如果单元格包含的数字不存在于$a_i$，LCM 将超过$a_i$。 因此每一个$x_{i,j}$必须划分$a_i$。 
2.对于固定立柱$j$，最大公约数是$b_j$，所以该列中的每个元素都必须是$b_j$。 如果任何条目不能被整除$b_j$，GCD 将降至以下$b_j$。 因此每一个$x_{i,j}$必须能整除$b_j$。 
3. 结合这两个条件，每个细胞必须满足$$b_j \mid x_{i,j} \mid a_i.$$这立即暗示了一个可行性条件：如果$b_j$不分开$a_i$，该位置不能存在有效值，因此整个矩阵是不可能的。 
4. 一旦所有对都成立，我们就通过将每个单元格设置为其列要求来构造一个基本矩阵$b_j$。 这会自动确保所有列 GCD 至少都是正确的候选者。 
5. 修复每行的行 LCM$i$，我们选择单列$p_i$并用以下内容覆盖该单元格$a_i$。 这保证了该行$i$包含一个等于$a_i$，迫使该行的 LCM 精确地变为$a_i$。 
6. 我们必须检查此覆盖不会破坏列 GCD。 栏内$p_i$，我们现在大部分有$b_{p_i}$价值观和一个价值观$a_i$。 自从$b_{p_i} \mid a_i$，该列的 GCD 保持不变$b_{p_i}$。 
7. 最后，我们输出矩阵。 

### 为什么它有效

 该结构保持两个不变量。 每个单元格始终是其列目标的倍数，因此列 GCD 永远不会低于$b_j$，并且每一列仍然包含至少一个等于$b_j$，所以GCD无法增加。 对于行，每行至少包含一个等于$a_i$，和所有其他元素除$a_i$，所以 LCM 不能超过$a_i$并且不能低于它。 这两个约束将行 LCM 和列 GCD 固定为精确值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    # feasibility check: b[j] must divide every a[i]
    for i in range(n):
        for j in range(m):
            if a[i] % b[j] != 0:
                print("No")
                return

    # start with base matrix filled with column requirements
    mat = [[b[j] for j in range(m)] for _ in range(n)]

    # assign each row one column to place its row LCM target
    for i in range(n):
        mat[i][i % m] = a[i]

    print("Yes")
    for row in mat:
        print(*row)

if __name__ == "__main__":
    solve()
```可行性检查直接强制执行导出条件$b_j \mid a_i$。 如果它在任何地方失败，则无法进行构造，因为该单元将同时违反两个可分性约束。 

矩阵已初始化，以便每一列都已具有正确的 GCD 候选值。 然后，每一行都会收到一个覆盖放置$a_i$，确保行 LCM 变得精确而不破坏列结构。 使用$i \bmod m$分发这些覆盖，因此每列仍然包含多个$b_j$值，防止意外的 GCD 通货膨胀。 

## 工作示例

 ### 示例 1

 输入：```
2 3
2 6
1 2 2
```我们从可行性开始：每个$b_j$划分每个$a_i$，因为 1 和 2 都能整除 2 和 6。 

我们建造：

 | 步骤| 第 1 行 | 第 2 行 |
 | --- | --- | --- |
 | 初始化| 1 2 2 | 1 2 2 1 2 2 | 1 2 2
 | 地点 a_i | 2 2 2 | 2 2 2 1 6 2 | 1 6 2

 第 1 行 LCM 为 2，因为它包含 2 并且所有值都除以 2。第 2 行 LCM 为 6，因为放置了 6。每列的 GCD 保持其原来的值$b_j$因为所有值都是$b_j$，并且每一列仍然包含至少一个纯$b_j$条目或仅保留 GCD 的倍数。 

### 示例 2

 输入：```
3 3
1 1 4
5 1 4
```可行性立即失败，因为$5$不分开$1$或者$4$。 任何单元格中都不存在可以同时为以下倍数的值$5$和除数$1$或者$4$。 施工甚至无法开始，所以正确的输出是`No`。

 ## 边缘情况

 一个微妙的情况是当所有$a_i = 1$。 然后每个单元格必须除 1，强制所有条目都为 1。该结构仍然有效，因为每个$b_j$也必须为 1，否则可行性立即失败。 该算法正确地拒绝不一致的情况，否则输出行 LCM 和列 GCD 保持为 1 的均匀矩阵。 

另一种情况是当所有$b_j = 1$。 这几乎完全消除了列约束，但行约束仍然强制每个约束至少出现一次$a_i$。 用 1 填充的基础矩阵确保列 GCD 保持为 1，并且注入$a_i$每行一个位置可以保持正确性，因为 GCD(1, a_i) 始终为 1。 

第三种情况是当$n$或者$m$等于 1。构造退化为单个行或列，但相同的整除逻辑仍然适用。 该算法仍然正确地检查兼容性并分配单个所需的结构而不进行修改。
