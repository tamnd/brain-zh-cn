 ## 解决方案
 ## 问题理解

 我们得到了球的三角形排列，其中第 1 行有 1 个球，第 2 行有 2 个球，依此类推，直到第 n 行。 球从上到下逐行连续编号，每行内从左到右连续编号。 这意味着每个球在概念三角形中都有一个固定位置，但我们通过其线性索引 x 来寻址。 

当母球击中球 x 时，该球变为活动状态。 如果它不在最后一行，它将把运动分成位于下一行正下方的两个球。 然后，每个球都以相同的方式运行，在其下方分裂成两个球，形成向下的二元传播，直到到达最后一行。 这个过程是确定性的：每个激活的球都会激活下一行中的两个子球（如果存在）。 

任务是计算 n 行三角形内从 x 开始有多少个不同的球被激活。 

约束条件非常大：n 最多可达 10^9，x 最多可达 10^18，并且测试用例最多可达 1000 个。 这立即排除了任何传播模拟，因为在最坏的情况下，即使是单个起始位置也可能激活 O(n^2) 个节点，这远远超出了可行的限制。 即使每次测试都是 O(n) 也是不可能的，因为 n 本身可以是十亿。 

一个微妙但重要的边缘情况是 x 位于最后一行。 在这种情况下，根本不会发生传播，答案恰好是 1。另一种边缘情况是当 x 接近三角形顶部时，传播扩展最大，触及每个可到达的级别。 

## 方法

 直接模拟会将结构视为以 x 为根的树，逐级扩展。 每个节点在下面的行中最多生成两个子节点。 这原则上是正确的，因为该问题明确定义了确定性分支过程。 然而，激活节点的数量随着深度呈指数增长：在深度 d 处，最多有 2^d 个节点。 如果 x 接近顶部，则深度为 n，这使得该方法爆炸性远远超过任何时间限制。 

关键的观察是我们实际上不需要跟踪单个球。 我们只需要了解激活区域在每行中水平延伸多远。 

我们不再考虑单个节点，而是从几何角度重新解释结构。 每行包含一个连续的索引区间。 当 r 行中位置 j 的球被激活时，它会激活 r+1 行中的位置 j 和 j+1。 因此每一行中的活动集始终是一个连续的段。 这是至关重要的压缩：指数分支崩溃为区间扩展。 

所以这个过程变成了一系列间隔。 从行 r0 中的单个索引开始，我们在每行中维护活动仓位的左边界和右边界。 每个步骤将间隔 [L, R] 转换为下一行中的 [L, R+1]，并按行宽度进行裁剪。 当我们到达第 n 行时我们停下来。 答案只是所有受影响行的间隔长度之和。 

这将问题从跟踪指数级数量的节点减少为仅跟踪区间边界，区间边界在最多 n 个步骤内线性演化。 然而，n 仍然太大而无法直接迭代，因此我们通过观察间隔增长是单调的并且针对行边界快速饱和来进一步压缩该过程。 一旦间隔覆盖整行，所有较低的行就会保持满。 

这使我们能够在恒定时间内跳过长范围的完全覆盖的行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 节点上的强力 BFS | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了|
 | 带跳跃的区间模拟 | 最差 O(n)，典型 O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 将线性索引 x 转换为其在三角形编号系统中的行 r 和列 c。 我们找到最大的 r 使得 r(r+1)/2 < x，然后计算行内的偏移量。 这是必要的，因为传播取决于行结构，而不是全局索引。 
2.将r行中的活动区间初始化为[c,c]，表示单次击中位置。 该间隔代表当前行中所有当前活动的球。 
3. 维护一个变量 ans 来累计活动球的总数。 
4. 对于从 r 到 n 的每一行，处理当前区间 [L, R]。 将 (R - L + 1) 添加到 ans 中，因为所有这些球都在这一行中被激活。 
5. 如果我们已经位于第 n 行，则停止，因为没有要传播到的下一行。 
6. 将下一行的间隔计算为 [L, R+1]，因为每个位置都会扩展到两个子位置并合并到一个连续的段中，最多向右移动一位。 
7. 将此区间剪裁到下一行的有效范围，该行的长度为 row_index + 1。如果该区间变得无效或为空，则停止。 
8. 如果在任何时候间隔变为 [1, row_length]，我们可以直接跳到底部，因为所有剩余行都被完全覆盖，从而提供了可预测的算术和。 

关键的决策点是识别活动间隔何时使行饱和。 一旦激活整行，所有后续行也将完全激活，并且不需要进一步的结构跟踪。 

### 为什么它有效

 不变量是，处理完第 i 行后，该行中的活动节点集始终形成单个连续间隔，并且第 i 行中的每个活动节点将其两个子节点准确贡献给第 i+1 行（如果存在）。 由于相邻节点的子节点在其目标索引中重叠，因此某个区间的所有子节点的并集仍然是最多移动一个边界扩展的连续区间。 这保证了我们永远不需要两个以上的端点来描述整个状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def row_of(x):
    lo, hi = 1, 2 * 10**9
    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * (mid + 1) // 2 >= x:
            hi = mid - 1
        else:
            lo = mid + 1
    return lo

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())

        r = row_of(x)
        prev_total = r * (r - 1) // 2
        c = x - prev_total

        L = R = c
        ans = 0

        cur_row = r
        width = r

        while cur_row <= n:
            ans += (R - L + 1)

            if cur_row == n:
                break

            next_width = width + 1

            L2 = L
            R2 = R + 1

            if L2 < 1:
                L2 = 1
            if R2 > next_width:
                R2 = next_width

            L, R = L2, R2
            cur_row += 1
            width = next_width

            if L == 1 and R == width:
                ans += (n - cur_row + 1) * width
                break

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将线性索引转换为三角坐标系，这对于理解传播开始的位置是必要的。 二分查找在`row_of`在 O(log n) 时间内找到正确的行。 

然后，我们使用两个整数 L 和 R 仅跟踪每行的活动间隔。每次迭代都会计算当前行的活动球，并根据每个位置扩展到下面两个位置的规则扩展间隔。 

饱和度检查`if L == 1 and R == width`是当活动区域已经扩展到覆盖整行时防止迭代所有剩余行的优化。 此时，下面的每一行都会贡献其全部宽度，因此我们一步添加剩余的三角和。 

## 工作示例

 考虑一个小三角形，其中 n = 4，x 是第三个球。 

我们首先在三角形中定位x。 它位于第 2 行、位置 2。 

| 行| 间隔[L，R] | 宽度| 贡献 |
 | --- | --- | --- | --- |
 | 2 | [2, 2] | 2 | 1 |
 | 3 | [2, 3] | 3 | 2 |
 | 4 | [2, 4] | 4 | 3 |

 总数为 1 + 2 + 3 = 6。 

此跟踪显示单个激活如何扩展为不断增长的区间，而不是分支到单独的节点。 活动集保持连续的不变量在每一行都是可见的。 

现在考虑 n = 3 且 x 位于最顶部，第 1 行位置 1。 

| 行| 间隔[L，R] | 宽度| 贡献 |
 | --- | --- | --- | --- |
 | 1 | [1, 1] | 1 | 1 |
 | 2 | [1, 2] | 2 | 2 |
 | 3 | [1, 3] | 3 | 3 |

 结果是 6，这意味着每个球都变得活跃。 这演示了饱和行为，其中间隔最终填充整行并保持满。

 ## 边缘情况

 当 x 位于最后一行时，传播永远不会扩展。 例如，如果 n = 4 并且 x 是第 4 行中的任何索引，则间隔在单行处开始和结束，并且不会发生扩展。 该算法立即每行累加一个，并在第一次迭代时停止，正确生成 1。 

当 x 是金字塔中的第一个球时，区间扩大到最大并很快变满。 在这种情况下，经过几个步骤后，条件 L == 1 和 R == width 会触发，并且剩余的行将作为完整的算术延续添加。 该执行不会单独触及每一行，但仍然对每个球进行一次精确计算。 

当 x 接近行的右边界时，第一个扩展步骤会产生一个可能暂时超过行宽度的间隔。 裁剪步骤确保间隔保持有效，防止在三角形之外进行过度计数。
