 ## 解决方案
 ## 问题理解

 描述一栋高层建筑，其中公寓从一楼开始从 1 开始连续编号，并且每层包含相同数量的公寓。 如果一个楼层有`k`公寓，则 1 楼包含公寓`1`通过`k`, 2楼包含`k+1`通过`2k`， 等等。 

每个测试用例我们都会得到两个数字：`f`，特定公寓所在的楼层，以及`r`，公寓号码。 任务是确定哪些值`k`（每层公寓数）使这成为可能，并在所有这些有效值中找到最小和最大的可能值`k`。 如果没有这样的`k`存在，两个答案都是`-1`。 

约束条件`r ≤ 10^9`意味着任何有效的解决方案都必须避免迭代所有可能的`k`价值观。 线性扫描可达`r`在最坏的情况下会太慢，因为可能有多达 1000 个测试用例，每个测试用例可能需要多达 10^9 次检查。 

一个关键的结构观察是对于固定的`k`, 公寓楼层`r`由整数除法确定：`(r - 1) // k + 1`。 这将问题转化为对不等式的推理而不是模拟。 

当出现微妙的边缘情况时`f`大于任何有效的最大可能楼层索引`k`。 例如，如果`f = 5`和`r = 3`，那么在任何统一分区下，3号公寓不可能位于5楼。 任何只检查整除性而不考虑楼层索引的方法都将在这里失败。 

当尝试推断边界而不仔细处理不等式的严格性时，会出现另一种失败模式，因为下限边界取决于包含的整数范围。 

## 方法

 如果我们确定每层公寓的候选数量`k`，我们可以直接计算出公寓的楼层`r`使用`(r - 1) // k + 1`并检查它是否等于`f`。 这种蛮力方法尝试了所有`k`从 1 到`r`，这保证了正确性，因为它会检查每个可能的配置。 然而，这导致`O(r)`每个测试用例的工作量太大，当`r`可以达到`10^9`。 

下限函数的结构提供了更清晰的表征。 该公寓的条件`r`躺在地板上`f`相当于要求大小的累积范围`k`地方`r`里面的`f`第-段。 这转化为一对不等式，限制了`k`为连续区间而不是分散的离散值。 

具体来说，楼层边界意味着：```
(f - 1) * k < r ≤ f * k
```由此，我们可以得出边界`k`：```
k ≥ ceil(r / f)
k ≤ floor((r - 1) / (f - 1))   (when f > 1)
```因此，我们不进行搜索，而是计算有效区间`k`直接地。 如果区间为空，则不存在解。 否则，最小和最大有效`k`只是这个区间的端点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次测试 O(r) | O(1) | O(1) | 太慢了|
 | 区间推导| 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.特殊情况处理`f = 1`。 在这种情况下，公寓`r`位于一楼，即所有从 1 到`k`包括`r`。 这迫使`k ≥ r`，因为第一层必须至少覆盖`r`。 在这种情况下没有上限限制，因此最大值是无界的，表示为`-1`。 
2. 对于`f > 1`，将楼层条件转化为描述其中的不等式`r`必须落在大小块内`k`。 
3. 重写条件`(f - 1)k < r ≤ fk`进入约束条件`k`。 上限来自确保`f`不是之后的楼`r`，下界确保`r`不会落入较早的楼层。 
4. 使用整数上限除法计算下界：`k_min = (r + f - 1) // f`。 这确保了`f * k`至少是`r`。 
5. 计算上限为`k_max = (r - 1) // (f - 1)`。 这确保了`(f - 1) * k < r`。 
6. 如果`k_min > k_max`，不存在有效分区，因此输出`-1 -1`。 否则输出区间端点。 

它之所以有效，是因为将公寓编号视为将数轴划分为等长的段。 每个`k`定义将整数平铺到块中，而楼层数只是包含块的索引`r`。 不等式精确地捕捉了阻碍的条件`f`包含`r`，并且因为两个约束都是单调的`k`，它们定义一个连续的区间。 任何`k`在此区间之外要么移动`r`到较高楼层或较低楼层，因此不会遗漏或添加有效的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    f, r = map(int, input().split())

    if f == 1:
        # r must be on first floor, so k >= r
        print(r, -1)
        continue

    # lower bound: fk >= r
    k_min = (r + f - 1) // f

    # upper bound: (f-1)k < r  => k <= (r-1)/(f-1)
    k_max = (r - 1) // (f - 1)

    if k_min > k_max:
        print(-1, -1)
    else:
        print(k_min, k_max)
```特殊情况`f = 1`避免在上限公式中被零除，并捕捉到第一层始终从公寓 1 开始并无限延伸的事实，具体取决于`k`。 吊顶划分`(r + f - 1) // f`强制执行最低限度`k`这样`r`没有被推到地板之外`f`。 楼层划分`(r - 1) // (f - 1)`确保`r`按大小分段时尚未包含在较低楼层中`k`。 

条件比较直接检查导出的可行区间是否为空。 

## 工作示例

 考虑输入`f = 3, r = 11`。 

我们一步步计算边界。 

| 步骤| 表达 | 价值|
 | --- | --- | --- |
 | f | 输入楼层 | 3 |
 | r | 公寓 | 11 | 11
 | k_min | 天花板(11 / 3) | 4 |
 | k_最大| (11 - 1) // (3 - 1) | 5 |

 结果是`4 5`。 

这表明两者`k = 4`和`k = 5`将公寓 11 放置在 3 楼，因为两种配置中的楼层范围都正确对齐。 

现在考虑`f = 1, r = 9`。 

| 步骤| 表达 | 价值|
 | --- | --- | --- |
 | f | 输入楼层 | 1 |

 | k_min | r | 9 |

 输出变为`9 -1`。 

这证实了对于一楼，任何配置每层必须至少有 9 间公寓，但没有有意义的上限，因为更大`k`价值仍然保留在 1 楼的 9 号公寓。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        f, r = map(int, input().split())
        if f == 1:
            out.append(f"{r} -1")
            continue
        k_min = (r + f - 1) // f
        k_max = (r - 1) // (f - 1)
        if k_min > k_max:
            out.append("-1 -1")
        else:
            out.append(f"{k_min} {k_max}")
    return "\n".join(out)

 ## 边缘情况

 当`f = 1`，算法直接输出`k_min = r`。 用于输入`f = 1, r = 1`，结果是`1 -1`，因为公寓 1 始终位于一楼，无论`k ≥ 1`。 该计算通过完全绕过一般公式来避免被零除。 

什么时候`k_min > k_max`， 例如`f = 5, r = 3`，我们得到`k_min = 1`和`k_max = 0`，生产`-1 -1`。 这反映出，在任何统一的分区中，公寓3都不能被推到5楼，因为即使是尽可能最小的楼层分组也不能充分延迟其楼层索引。 

对于以下情况`r`正好可以整除`(f - 1)`，上限变紧，解区间缩小到单个有效值`k`。 这捕获了只有一种配置对齐公寓的情况`r`正好位于楼层的起始边界`f`。
