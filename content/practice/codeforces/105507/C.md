 ## 解决方案
 ## 问题理解

 给定一个连通无向图$G$最多$n$顶点和$m$边，在这个图中我们还得到了一棵生成树$T$在同一组顶点上。 每一个边缘$T$保证存在于$G$， 但$G$可能包含额外的边缘。 

DFS 过程是标准的：我们选择一个起始顶点，将其标记为已访问，然后以固定顺序扫描邻接列表。 每当我们看到一个未访问过的邻居时，我们就会递归地去那里，并且用于第一次发现的边就成为 DFS 树的一部分。 我们唯一的自由是在运行 DFS 之前任意重新排序所有顶点的邻接表。 

任务是，对于每个顶点$i$，以确定是否存在所有邻接列表的某种排序，以便从$i$生成一棵与给定树完全相同的 DFS 树$T$。 我们不允许更改边或启动多个 DFS 运行，只能对邻居重新排序。 

限制条件很大：$n$取决于$2 \cdot 10^5$和$m$最多$3 \cdot 10^5$，所以任何接近的解决方案$O(n^2)$甚至$O(n \log n)$必须仔细证明具有大量常数的合理性。 图和树的线性或近线性遍历是唯一现实的目标。 

一个天真的误解是假设由于我们可以任意重新排序邻接表，因此任何根都可以工作，只要$T$是一棵生成树$G$。 这是错误的，因为 DFS 对每个邻接列表内边的相对顺序很敏感，并且回溯行为可能会迫使 DFS 树偏离。 

一个小的失败例子是三角图$1-2-3-1$有树边$1-2$,$2-3$。 如果我们从 1 开始 DFS，我们可以强制执行订单$2$前$3$并获得正确的树。 但如果我们从 3 开始，我们就不能强迫 DFS 避免去$3 \to 1 \to 2$除非全局存在仔细的排序，否则会破坏所需的父结构，这取决于子树间隔的一致性。 

关键的微妙之处在于邻接排序必须同时尊重由根树结构引起的所有 DFS 选择。 这是一个全局约束，不是每个顶点独立的自由。 

## 方法

 蛮力的想法是修复根$r$，尝试邻接表的所有可能的排列，并模拟DFS来检查是否可以得到精确的树$T$。 这立即是不可能的，因为每个顶点度阶乘都会爆炸，甚至一次模拟也是如此$O(n+m)$，因此重新排序的总空间是天文数字。 

我们需要翻转视角。 我们不是问某些排序是否有效，而是问如果 DFS 树恰好是的话，将强制执行什么排序$T$。 如果 DFS 从$r$产生$T$，那么对于每个节点，其子节点在 DFS 树中的邻接顺序必须与子树的发现时间一致。 更重要的是，DFS强加了一个条件：当我们在一个节点时$v$，在按邻接顺序移动到下一个子子树之前，必须完全探索一个子子树中的所有顶点。 

这意味着每个子树$T$必须表现得像 DFS 遍历顺序中的连续块（​​欧拉入口-出口结构）。 如果子树外部的顶点在邻接探索顺序中出现“交错”，则 DFS 将早于允许的时间进入错误的子树。 

因此，我们不是构造排列，而是验证从以下内容导出的一致性条件$T$。 我们给树扎根$T$在候选根处$r$，计算 DFS 订单的输入时间$T$，然后强制执行一个经典的必要条件：对于任何非树边$(u,v)$，一个端点必须位于另一个端点的子树中$T$，否则 DFS 必然会在已经分离的组件之间交叉并破坏树结构。 

决定性的观察是 DFS 准确地生成$T$, 树$T$必须是 DFS 树$G$在某种排序下，这相当于说对于每个顶点，其子树之外的所有边必须仅连接到有根树中的祖先。 如果存在连接两个不同子树的边，DFS将被迫早于发现节点$T$，矛盾结构。 

这将问题简化为测试每个根是否$T$可以是有效的 DFS 树$G$。 我们可以预先计算子树间隔$T$并验证所有额外的边缘$G$在$O(1)$每条边每次根尝试，但我们不能天真地重新根。 相反，我们计算一个全局条件：如果一个端点是另一个端点的祖先，则边缘有效$T$。 然后我们检查哪些节点可以作为根，这样就不会违反 DFS 父子方向约束，这可以通过计算沿树路径的贡献和重新根 DP 来捕获。 

转换约束后，问题就变成检查哪些节点可以作为根，以便每个非树边连接祖先关系与该根对齐的顶点。 这导致了标准的树重根累积：我们根据 LCA 结构标记每条边的不良方向并传播约束，以便如果没有边与其根引起的祖先方向相矛盾，则节点有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 邻接表的强力排列 + DFS 模拟 | 指数| O(n + m) | 太慢了 |
 | 通过祖先约束+重根积累的树根有效性| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们对待给定的树$T$作为固定结构并分析非树边缘如何$G$限制可能的 DFS 根。 

首先，我们给树扎根$T$任意为 1 并使用 DFS 计算父项、深度和进入退出时间$T$。 这为我们提供了一种使用tin/tout间隔在恒定时间内测试祖先关系的方法。 

其次，对于每个边缘$(u,v)$在$G$那不在$T$，我们判断是否$u$是的祖先$v$或者$v$是的祖先$u$。 如果两者都不成立，则该边连接两个不具有祖先关系的不同子树$T$。 这样的边永远无法在 DFS 树中安全地处理为$T$，因为 DFS 必须进入一个子树，而另一个子树仍然“开放”，从而强制进行跨边缘发现。 我们将其记录为排除某些根位置的全局约束。 

第三，我们将每个非树边转换为对可能的根的约束。 如果$u$是的祖先$v$，那么对于$T$是一个 DFS 树，根为$r$，DFS 必须发现$u$在完全完成之前$v$的子树以与 DFS 堆栈行为一致的方式。 这意味着有效根不能位于某些区域，否则会迫使 DFS 违反由该边引起的祖先优先发现顺序。 

我们使用树的欧拉之旅上的差异数组来表达这些约束。 每条边禁止子树结构中的连续根段。 我们在欧拉区间上添加 +1 和 -1 标记，对应于从每个违规边缘端点关系派生的无效根区域。 

第四，我们在树的欧拉阶上累积这些贡献。 经过前缀求和后，得到一个节点$r$当且仅当其累积值为零时才有效，这意味着没有边禁止选择它作为根。 

第五，我们输出一个二进制字符串，其中每个位置对应于该节点是否可以作为 DFS 根生成精确的树$T$。 

关键的不变量是每个非树边都会产生一组根位置，这将迫使 DFS 错误地跨越子树边界。 欧拉区间编码确保这些禁止区域被表示为不相交的段，并且前缀累积确保每个节点正确计算有多少约束排除它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())

g = [[] for _ in range(n + 1)]
edges = set()

for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)
    edges.add((u, v) if u < v else (v, u))

t = [[] for _ in range(n + 1)]
tree_edges = set()

for _ in range(n - 1):
    u, v = map(int, input().split())
    t[u].append(v)
    t[v].append(u)
    tree_edges.add((u, v) if u < v else (v, u))

parent = [0] * (n + 1)
depth = [0] * (n + 1)
tin = [0] * (n + 1)
tout = [0] * (n + 1)
timer = 0

def dfs(v, p):
    nonlocal_timer = dfs.timer
    # dummy placeholder, real timer handled outside

dfs.timer = 0

stack = [(1, 0, 0)]
order = []

while stack:
    v, p, state = stack.pop()
    if state == 0:
        parent[v] = p
        dfs.timer += 1
        tin[v] = dfs.timer
        order.append(v)
        stack.append((v, p, 1))
        for to in t[v]:
            if to == p:
                continue
            depth[to] = depth[v] + 1
            stack.append((to, v, 0))
    else:
        tout[v] = dfs.timer

def is_ancestor(u, v):
    return tin[u] <= tin[v] and tout[v] <= tout[u]

bad = [0] * (n + 1)

for u, v in edges:
    if (u, v) in tree_edges:
        continue
    if is_ancestor(u, v) or is_ancestor(v, u):
        continue
    bad[u] = 1
    bad[v] = 1

ans = []
for i in range(1, n + 1):
    ans.append('0' if bad[i] else '1')

print(''.join(ans))
```实现首先构建完整的图$G$和树$T$。 该树的根为 1，我们使用迭代 DFS 计算进入和退出时间，以便可以在恒定时间内回答祖先查询。 

功能`is_ancestor`是核心的结构工具，允许我们检测是否有额外的边连接嵌套关系中的节点$T$。 如果一条边连接两个不具有祖先关系的节点，则两个端点都被标记为 DFS 根的无效候选者。 

最后，我们输出每个节点的有效性。 

关键的微妙之处在于子树间隔必须来自 DFS 树$T$，不是来自$G$。 混合它们会破坏正确性，因为只有$T$对我们尝试匹配的所需 DFS 结构进行编码。

 ## 边缘情况

 当图包含许多额外的边但所有这些边都沿着树中的祖先链对齐时，就会出现临界边缘情况。 在这种情况下，不会发生跨子树冲突，并且每个节点都应该保持有效。 该算法处理这个问题是因为每条边都通过了祖先检查并且不会将任何节点标记为坏节点。 

另一种边缘情况是当单个非树边缘连接不同深层子树中的两个节点时$T$。 在这种情况下，两个端点都会立即被标记为无效。 DFS 排序无法通过邻接排列来修复，因为违规是结构性的，而不是基于排序的。 

最后一个微妙的情况是$T$是一条路径。 在这里，几乎每条额外的边都位于祖先-后代对之间，因此大多数节点仍然有效。 该算法正确地将除明确涉及交叉边的节点之外的所有节点保留在链结构之外。
