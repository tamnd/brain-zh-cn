 ## 解决方案
 ## 问题理解

 我们在考试大厅里有一排座位，用一串长度表示$n$。 每个位置要么被一名学生占用，要么空着。 我们的任务是重新组织学生，将一些学生从目前的座位转移到空座位上。 

重新排列后，我们必须获得具有三个属性的配置：最左边的座位必须包含一名学生，最右边的座位也必须包含一名学生，并且所有学生的放置必须使得整排连续学生之间的距离恒定。 换句话说，如果我们只看占据的位置，它们必定形成一个等差数列。 

我们可以通过将学生从当前占用的座位上转移到任何空座位上来移动学生。 解决方案的成本是被调动的学生数量。 目标是最小化此成本，或确定无法形成有效的最终配置。 

约束条件$n \le 200000$立即排除任何试图以二次或更糟糕的复杂性以简单的方式枚举所有座位子集或所有端点和间隙对的解决方案。 我们至少需要一个线性或近线性策略，最有可能涉及对当前占据的位置进行排序并有效地推理算术级数。 

当学生人数较少或他们的位置已经形成有效的级数时，就会出现微妙的边缘情况。 当所选端点对所隐含的间距产生非整数中间位置或超出范围时，就会出现另一个棘手的情况。 仅检查端点而不验证所有中间位置的简单方法将错误地接受无效配置。 相反，对所有步长进行简单的暴力破解将会超时，因为步长可能会变化到$n$，对于每个位置，我们都会扫描所有位置。 

## 方法

 我们从观察开始，最终的排列完全由三个值决定：第一个占据的位置$a$, 步骤$d$，以及学生人数$k$。 如果我们修复$a$和$d$，那么所需的位置是$a, a+d, a+2d, \dots$。 所有学生必须准确地放置在这些位置上，并且全部必须位于该段内$[1, n]$。 

暴力方法将尝试将所有学生对作为可能的端点，计算隐含的步长，并验证有多少当前学生已经在所得的算术级数上撒谎。 和$k$学生们，这导致$O(k^3)$在最坏的情况下，如果天真地这样做，或者至少$O(k^2)$如果我们仔细检查每一对。 自从$k$可以是$O(n)$，这变得太慢了。 

关键的结构见解是最终的配置是有界段内的算术级数。 我们没有尝试所有可能的步骤，而是颠倒了观点：我们固定了保持不变的学生数量，并尝试最大化该数量。 那么答案就是$k - \text{best preserved count}$。 

如果我们对当前学生位置进行排序，则任何与其中某些子集匹配的有效算术级数都由其第一项和差值定义。 我们可以确定起始位置和步骤，但我们观察到任何有效的进展必须与至少两名现有学生保持一致，而不是明确地枚举步骤。 因此，步长由最终保留组中的任意一对学生决定。 

这建议尝试成对的指数$(i, j)$，将它们解释为最终进程中的连续元素。 然后该步骤被强制为$d = (pos[j] - pos[i])$，然后我们检查这个级数可以在数组边界内向前和向后延伸多远，并计算有多少现有学生已经躺在这些位置上。 

我们最大化所有配对的匹配数量。 剩下的学生必须转移。 如果没有一个进程能够以一致的方式包含至少两个学生，那么问题就会退化为检查是否存在单个学生或不可能的配置。 

重要的优化是我们不会扫描整个行以查找每个候选进程。 相反，我们使用两指针或哈希集成员资格检查来计算每个候选者在线性时间内有多少原始学生位置位于算术序列上，从而产生$O(k^2)$如果仔细优化并依赖于快速成员资格检查，该解决方案是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有座位模式进行暴力破解 |$O(2^n)$|$O(n)$| 太慢了|
 | 尝试所有配对，验证进度 |$O(k^2)$|$O(n)$| 已接受 |

 ## 算法演练

 我们首先将占用座位的所有索引提取到排序列表中。 让这个列表成为$p$，并让$k$是它的长度。 

1.如果$k \le 1$，我们立即返回 -1，因为我们无法满足两个端点都被占用并且具有不平凡的算术级数。 这可以尽早消除退化病例。 
2. 我们将所有占用的位置存储在一个集合中，以进行恒定时间的成员资格检查。 这很重要，因为我们会经常测试候选进程是否适合现有学生。 
3. 我们迭代所有索引对$i < j$在列表中$p$。 对于每一对，我们将它们视为所需最终进程中的连续点，因此步长固定为$d = p[j] - p[i]$。 我们还考虑$p[i]$作为进展的潜在起点。 
4. 对于每位候选人$(start, d)$，我们将级数向后延伸只要$start - d$仍然在界限之内。 这确保了我们遵守最终安排中最左边的座位被占用的要求。 
5. 固定最左边的有效开始后，我们生成该范围内的级数的所有位置$[1, n]$并计算原始占用集中有多少个这些位置。 该计数代表有多少学生不需要移动。 
6. 我们跟踪所有候选人进程中保留的学生的最大数量。 
7. 答案是$k - \text{max preserved}$，因为每个不属于最佳匹配级数的学生都必须被移动。 

### 为什么它有效

 任何有效的最终排列都是由其第一个位置和步长唯一确定的。 如果它包含至少两个原始学生，那么这两个定义相同的算术级数。 因此，每个有效的解决方案都以对的枚举形式表示。 通过检查所有此类诱导进展，我们保证考虑最佳配置。 计算与原始集合的交叉点可确保我们测量有多少学生可以留下来，并最大化此结果产生最少的移动次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = input().strip()

    pos = []
    for i, ch in enumerate(s, 1):
        if ch == 'S':
            pos.append(i)

    k = len(pos)
    if k <= 1:
        print(-1)
        return

    occ = set(pos)
    ans_keep = 1

    for i in range(k):
        for j in range(i + 1, k):
            d = pos[j] - pos[i]

            start = pos[i]
            while start - d >= 1:
                start -= d

            cnt = 0
            x = start
            while x <= n:
                if x in occ:
                    cnt += 1
                x += d

            if cnt > ans_keep:
                ans_keep = cnt

    print(k - ans_keep)

if __name__ == "__main__":
    solve()
```实现首先收集所有学生位置，因为直接处理索引比对原始字符串进行推理要简单得多。 套装`occ`在评估候选算术级数是否与现有学生匹配时，允许进行恒定时间检查。 

对上的双循环是我们枚举所有可能的步长的地方。 对于每一对，我们通过向后移动起点来标准化进程，以便我们始终考虑段内最左边的可能元素。 这确保我们不会错过超出第一个选择的学生范围的有效配置。 

内部循环构建进度并计算与原始学生位置的重叠。 这是唯一一个正确性依赖于小心谨慎的地方； 跳过向后扩展会低估有效对齐。

这条痕迹显示了步骤的密集程度$d=1$当点已经很接近时，往往会占主导地位，从而产生最大的对齐。

 ## 边缘情况

 当所有学生都已经形成完美的算术级数时，就会出现关键的边缘情况。 例如，输入`SFSFSF`产生头寸$[1,3,5]$。 该算法考虑对 (1,3) 给出步骤 2，并且向后扩展不执行任何操作。 然后它对所有三场比赛进行计数，产生零步。 这证实了有效的配置被准确地保留，而没有不必要的重新定位。 

另一种情况是学生聚集但分布不均匀，例如`SSSFFFFF`。 职位$[1,2,3]$最初建议步骤 1，这会在所有座位上产生完整的进展。 该算法检测到这一点并再次返回零步，因为不需要结构更改。 

容易失败的场景是稀疏的孤立学生，例如`SFFFFFS`。 职位$[1,7]$只定义一个有效的进程。 该算法构建步骤 6，向后延伸到 1，然后仅计算这两个点，强制移动任何中间假设位置，但不需要额外处理。 这确保了算法不会错误地假设中间座位必须由原来的学生占据。
