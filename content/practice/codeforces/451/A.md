 ## 解决方案
 ## 问题理解

 游戏在由以下组成的网格上进行`n`水平棒和`m`垂直的棍子。 每根水平棒与每根垂直棒相交，形成`n * m`交叉点。 

在一轮中，玩家选择一个剩余的交点。 选择该点将删除水平棒和穿过该点的垂直棒。 一旦这两根棍子被移除，涉及这两根棍子的每个交叉点也会消失。 

仅当至少剩余一个交点时才可能进行移动。 第一个玩家是 Akshat，第二个玩家是 Malvika。 两者都发挥最佳，我们必须确定谁获胜。 

输入仅包含两个整数，`n`和`m`。 输出是在最佳玩法下获胜的玩家的名字。 

约束非常小，两个维度都最多为 100。即使是模拟也能轻松地满足限制。 真正的挑战是认识游戏结构并将其简化为简单的观察。 

一个不明显的一点是，选择的确切交叉点并不重要。 例如，在一个`3 x 5`在网格中，选择任何交叉点总是会恰好删除一根水平棒和一根垂直棒。 剩余的游戏状态仅取决于剩下多少水平和垂直的棍子，而不取决于剩下哪些具体的棍子。 

考虑输入：```
1 5
```只有一根横棍。 第一次移动后，该棍子被移除，因此不再有交叉点。 阿克沙特立即获胜。 专注于交叉点坐标而不是剩余行和列的模拟很容易使这种情况变得过于复杂。 

另一个有用的例子是：```
2 2
```第一步删除一行和一列，留下`1 x 1`网格。 第二步删除最后一行和最后一列。 没有剩余棋步，因此阿克沙特输了，马尔维卡赢了。 

第三个例子是：```
3 4
```总共可以进行三种移动。 第三次移动后，所有行或所有列都已耗尽。 由于 3 是奇数，所以第一个玩家走完最后一步并获胜。 

## 方法

 强力解决方案将对整个网格进行建模并递归地探索所有可能的移动。 来自一个州`r`剩余行和`c`剩余的列，每一步都会删除一行和一列，产生一个状态`(r - 1, c - 1)`。 由于每一步都存在许多选择，因此即使约束很小，朴素博弈树也会快速增长。 

关键的观察结果是，每次移动总是恰好移除一根水平棍子和一根垂直棍子。 别的都无所谓。 移动一圈后，剩余行数减一，剩余列数减一。 

假设我们从`n`行和`m`列。 只有当两个计数均为正数时，游戏才能继续。 每次移动后，两个计数都会减一。 因此，总移动次数恰好是：```
min(n, m)
```做出最后一步的玩家获胜。 由于阿克沙特先行动，所以当行动次数为奇数时他获胜。 当步数为偶数时，马尔维卡获胜。 

整个游戏简化为检查奇偶性`min(n, m)`。

 ## 算法演练

 1. 阅读`n`和`m`。 
2. 计算`moves = min(n, m)`。 

每次移动恰好消耗一行和一列。 一旦行或列达到零，则不再有交点，游戏结束。 
3. 检查是否`moves`是奇数还是偶数。 

如果总步数为奇数，则第一个玩家走最后一步。 

如果总步数是偶数，则第二个玩家进行最后一步。 
4. 打印`"Akshat"`什么时候`moves`是奇数，否则打印`"Malvika"`。 

### 为什么它有效

 每次移动后，恰好一行和一列消失。 游戏状态完全由剩余行数和列数决定。 开始于`(n, m)`， 后`k`移动状态变为`(n - k, m - k)`。 当其中一个达到零时，游戏就会停止，这恰好发生在`min(n, m)`移动。 由于玩家轮流轮流，获胜者仅取决于该数字是奇数还是偶数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if min(n, m) % 2 == 1:
    print("Akshat")
else:
    print("Malvika")
```实现直接遵循数学观察。 首先，它计算游戏必须包含多少步。 该值是`min(n, m)`因为每一步都会删除一行和一列。 

这个值的奇偶性决定了谁采取最后的行动。 奇数步意味着第一个玩家最后一步，而偶数意味着第二个玩家最后一步。 

不存在棘手的边界条件，因为两个维度都至少为一，并且答案仅取决于单个奇偶校验。

 ## 边缘情况

 考虑输入：```
1 1
```恰好有一个交叉点。 阿克沙特在第一回合将其移除，使马尔维卡无法移动。 该算法计算`min(1, 1) = 1`，这是奇数，并且正确返回`Akshat`。 

考虑输入：```
1 5
```一个常见的错误是认为有五种可能的移动，因为有五个交叉点。 实际上，第一步会移除唯一的水平棍子，立即消除每个交叉点。 该算法计算`min(1, 5) = 1`并正确返回`Akshat`。 

考虑输入：```
100 100
```基于仿真的解决方案可能不必要对整个电路板进行建模。 数学观察显示正好有 100 步。 由于 100 是偶数，马尔维卡采取了最后一步。 算法返回`Malvika`在恒定的时间内。 

考虑输入：```
2 3
```游戏持续两步。 第一步之后，一行一列消失。 第二次移动后，没有行剩余。 该算法计算`min(2, 3) = 2`，检测偶校验，并正确返回`Malvika`。 这种情况证实，一旦知道较小的尺寸，较大的尺寸就不会影响获胜者。
