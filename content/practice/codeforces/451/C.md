 ## 解决方案
 ## 问题理解

 我们有一个由三支球队参加的足球锦标赛。 每场比赛都会产生一名获胜者，因此每场比赛都会为其中一支球队贡献一场胜利。 

后`k`比赛已经打完，我们不知道三队的具体胜场数。 我们只知道两个绝对差异：

 - 球队 1 和球队 2 的胜利差异为`d1`。 
- 第 2 队和第 3 队的胜利之间的差异是`d2`。 

比赛最终将包含`n`游戏总数。 我们想知道是否有可能完成比赛，这样，毕竟`n`比赛结束后，每支球队的胜场数完全相同。 

由于每场比赛贡献一场胜利，因此所有球队最终的胜利场数正好是`n`。 如果所有三队必须均分，则每队必须以`n / 3`获胜。 这立即意味着`n`必须能被 3 整除。 

约束是需要数学解决方案的第一个线索。 测试用例数量达到`10^5`， 和`n`可以大到`10^12`。 任何模拟游戏或搜索获胜分布的方法都是不可能的。 即使做的工作与`k`会失败的。 我们需要对每个测试用例进行恒定时间检查。 

棘手的部分是差异是绝对值。 会心`|a - b| = d1`和`|b - c| = d2`不能唯一确定当前的获胜计数。 多种标志配置是可能的。 

一个常见的错误是假设单一顺序，例如`a ≥ b ≥ c`。 考虑：```
n = 6
k = 4
d1 = 1
d2 = 0
```一种有效的分布是`(2,1,1)`，这将导致有效的决赛。 如果我们只检查订单`a ≥ b ≥ c`，我们会找到它，但在其他情况下，唯一有效的排列可能会使用不同的顺序。 

另一个微妙的情况发生在当前最强的球队已经取得了太多胜利的情况下。 例如：```
n = 6
k = 3
d1 = 3
d2 = 0
```唯一可能的分布是`(3,0,0)`。 由于每个团队必须完成`2`获胜，1 队已经超额完成最终目标。 答案是`"no"`。 

第三个边缘情况是可分性。 考虑：```
n = 4
k = 0
d1 = 0
d2 = 0
```尽管目前的状态完美平衡，但四场胜利的总成绩也无法平分给三支球队。 答案一定是`"no"`。 

## 方法

 蛮力方法将尝试在第一场比赛后重建三支球队的获胜次数`k`匹配。 让这些计数成为`(a,b,c)`。 

他们必须满足：```
a + b + c = k
|a - b| = d1
|b - c| = d2
```人们可以列举出可能的值`a`,`b`， 和`c`，检查约束条件，然后验证剩余的是否`n-k`比赛可以平衡所有球队。 

这在概念上是可行的，因为每个有效的当前状态都可以直接测试。 问题在于规模。 自从`k`可以大到`10^12`，即使迭代一个变量的可能值也是完全不可行的。 

关键的观察结果是，只有四种不同的方法可以为两个绝对差值分配符号。 

让第 2 队的胜利具有一定的价值`x`。 

那么团队 1 必须是`x+d1`或者`x-d1`。 

同样，团队 3 必须是`x+d2`或者`x-d2`。 

这仅创建了四种候选模式：```
(x+d1, x, x+d2)
(x+d1, x, x-d2)
(x-d1, x, x+d2)
(x-d1, x, x-d2)
```对于每个模式，方程```
a + b + c = k
```决定`x`独一无二。 

获得后`(a,b,c)`，我们只需要验证是否：

 1. 所有计数均为非负整数。 
2. 没有任何团队超过最终目标`n/3`。 
3. 剩下的比赛足以让所有球队晋级`n/3`。 

第三个条件相当于检查所需的额外胜利总数是否恰好等于剩余比赛的数量。 

由于只有四种配置，因此每个测试用例都可以在恒定时间内解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k) 或更差 | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 检查是否`n`能被3整除。如果不能，最终分数不可能相等，所以返回`"no"`。 
2. 设每队最终获胜目标为：```
target = n / 3
```3. 枚举四种标志配置：```
(+d1, +d2)
(+d1, -d2)
(-d1, +d2)
(-d1, -d2)
```4. 对于选定的配置，请写入：```
a = x + s1*d1
b = x
c = x + s2*d2
```在哪里`s1`和`s2`是`+1`或者`-1`。 
5.使用条件`a+b+c=k`计算`x`。```
3x + s1*d1 + s2*d2 = k
```因此```
x = (k - s1*d1 - s2*d2) / 3
```6. 如果分子不能被3整除，则此配置不能代表有效的获胜计数。 跳过它。 
7. 构建`(a,b,c)`并验证所有值均为非负数。 
8.让```
mx = max(a,b,c)
```如果`mx > target`，那么某支球队的胜场数已经超过了其最终允许的总胜场数。 跳过此配置。 
9. 计算每个团队需要多少场胜利才能达到目标：```
need = (target-a) + (target-b) + (target-c)
```10.如果`need == n-k`，那么剩下的游戏正好可以提供这些胜利，所以返回`"yes"`。 
11.如果四种配置都不起作用，则返回`"no"`。 

### 为什么它有效

 目前积分榜唯一的不确定性来自于两人绝对差值的走向。 每个有效的三元组`(a,b,c)`必须对应于四个符号分配之一。 

对于固定分配，方程`a+b+c=k`唯一决定排名。 没有遗漏任何有效的分发。 

如果团队已经超出最终目标`n/3`，后面没办法去掉wins，所以配置不了。 如果所有球队至多都是目标，那么达到目标所需的确切胜利场数`(target,target,target)`是```
(target-a)+(target-b)+(target-c).
```因为未来的每一场比赛都会贡献一场额外的胜利，所以当所需的总数等于剩余比赛的数量时，该配置是可行的`n-k`。 

由于每个可能的符号分配都会被检查，并且每个符号分配都会根据锦标赛约束进行精确检查，因此该算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def possible(n, k, d1, d2):
    if n % 3 != 0:
        return False

    target = n // 3

    for s1 in (1, -1):
        for s2 in (1, -1):
            rem = k - s1 * d1 - s2 * d2

            if rem % 3 != 0:
                continue

            x = rem // 3

            a = x + s1 * d1
            b = x
            c = x + s2 * d2

            if min(a, b, c) < 0:
                continue

            if max(a, b, c) > target:
                continue

            need = (target - a) + (target - b) + (target - c)

            if need == n - k:
                return True

    return False

def main():
    t = int(input())

    ans = []
    for _ in range(t):
        n, k, d1, d2 = map(int, input().split())
        ans.append("yes" if possible(n, k, d1, d2) else "no")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    main()
```第一个检查处理不可避免的可分性要求。 如果`n`不是三的倍数，最终分数不可能相等。 

嵌套循环枚举了绝对差异的四种可能的解释。 对于每一个，总和约束确定中间值`x`。 如果结果值不是整数，则该配置无法对应于实际获胜计数。 

非负性检查消除了不可能的排名。 最大值检查非常重要，因为以后无法从团队中夺走胜利。 

最终平等```
need == n - k
```捕捉剩余比赛是否足以让所有团队达到共同目标。 

所有算术都使用整数，因此即使在`n`达到`10^12`，因为 Python 整数是无界的。

 ## 边缘情况

 考虑：```
1
4 0 0 0
```该算法立即检查`n % 3`。 自从`4 % 3 = 1`，最终得分相等是不可能的。 输出是`"no"`。 仅考虑当前排名的解决方案将错误地接受这种情况。 

考虑：```
1
6 3 3 0
```使用有效的符号分配给出：```
(a,b,c) = (3,0,0)
```目标是`2`。 自从`max(a,b,c)=3`，一支球队的胜场数已经超过了最终平衡状态下允许的胜场数。 该算法拒绝配置并输出`"no"`。 

考虑：```
1
3 3 3 2
```检查所有四个符号分配。 有些会产生负获胜计数，而另一些则不符合整除要求。 当前胜利的有效分配根本不存在。 算法正确输出`"no"`因为所报告的差异不可能在三场比赛之后出现。 

考虑：```
1
6 4 1 0
```一种配置产生：```
(a,b,c) = (2,1,1)
```没有团队超出目标`2`，并且正好有两场胜利有待分配。 所需的额外胜利也是`2`，所以算法输出`"yes"`。 这证实了只要领导者尚未超过最终目标，拥有当前领导者是可以接受的。
