 ## 解决方案
 ## 问题理解

 我们有`n`花箱。 从盒子里`i`，我们可以在之间取任意数量的花`0`和`f[i]`，包含在内。 颜色不同，因此选择完全取决于我们从每个盒子中取出的花朵数量。 

任务是计算整数向量的数量$$x_1+x_2+\cdots+x_n=s$$这样$$0 \le x_i \le f_i$$对于每个盒子。 答案必须以模数形式报告$10^9+7$。 

首先引人注目的是数字的大小。 盒子数量最多为$20$，这是非常小的。 另一方面，两者$s$并且盒子的容量可以是巨大的，达到$10^{14}$和$10^{12}$分别。 

这些约束立即排除了对总和的动态规划。 任何其复杂性取决于的解决方案$s$是无望的。 甚至$O(ns)$需要处理最多$10^{14}$州。 

的小值$n$才是真正的线索。 每当$n \le 20$，涉及子集的技术通常变得可行，因为$2^{20}\approx 10^6$，这是可以管理的。 

有几种容易被忽略的边缘情况。 

考虑```
1 0
0
```唯一有效的选择是拿零朵花。 答案是`1`。 不小心将零视为特殊无效情况的公式将在此处失败。 

考虑```
1 5
3
```不存在有效的选择，因为盒子只包含三朵花。 答案是`0`。 任何不受限制的计数公式都会错误地计算一种解决方案。 

考虑```
2 1
0 0
```答案又是`0`。 上限完全消除了每个候选解。 

另一个微妙的情况出现在包含-排除过程中。 一些子集贡献对应于计算解决方案$$x_1+\cdots+x_n = T$$和$T<0$。 这些项的贡献必须为零。 忘记此检查会导致无效的二项式系数进入计算。 

## 方法

 强力解决方案是尝试从每个盒子中选择所有可能的鲜花。 

对于每个盒子$i$， 有$f_i+1$的可能性。 总搜索空间为$$\prod_{i=1}^{n}(f_i+1).$$自从$f_i$可能达到$10^{12}$，这是一个天文数字。 即使值很小，例如$f_i=100$，搜索空间变为$101^{20}$，这已经是不可能的了。 

问题的自然无限制版本要容易得多。 如果我们忽略上限并且只需要$$x_1+\cdots+x_n=s,\qquad x_i\ge 0,$$那么经典的星条公式给出$$\binom{s+n-1}{n-1}.$$唯一的障碍是上限$x_i\le f_i$。 

每当我们有简单的下界和上限时，包含-排除就成为一个强有力的候选者。 不受限制的计数很容易。 可以系统地对违反一个或多个上限的解决方案进行计数。 

假设有一个特定的盒子$i$违反了它的极限。 然后$$x_i\ge f_i+1.$$让$$y_i=x_i-(f_i+1).$$经过这次转变后，$y_i\ge 0$，总和减少$f_i+1$。 

如果一个子集$S$的盒子被迫违反其限制，然后将每个变量移入$S$,$$\sum x_i=s$$变成$$\sum y_i=s-\sum_{i\in S}(f_i+1).$$非负解的数量又是星条数。 

自从$n\le 20$，我们可以枚举所有子集$S$。 只有$2^n$其中。 

剩下的挑战是计算二项式系数，其中最高值可能与$10^{14}$。 幸运的是，底值总是至多$$n-1\le 19.$$这个微小的值允许直接乘法计算模$10^9+7$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O\!\left(\prod (f_i+1)\right)$|$O(n)$| 太慢了|
 | 最佳包含-排除 |$O(n2^n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读`n`,`s`，以及容量`f[i]`。 
2. 使用位掩码枚举框的每个子集`0`到`(1<<n)-1`。 
3. 对于当前子集`mask`, 计算$$T=s-\sum_{i\in S}(f_i+1),$$在哪里$S$是选定位的集合。 

这相当于强制每个框进入$S$超过其极限。 

1.如果$T<0$，移位后没有非负解，因此该子集贡献为零。 
2. 否则计算以下的无限制解$$y_1+\cdots+y_n=T.$$星条给出$$\binom{T+n-1}{n-1}.$$1. 如果子集大小是偶数，则将此数量添加到答案中。 
2. 如果子集大小为奇数，则从答案中减去该数量。 

这正是包含排除原则。 
3. 处理完所有子集后，对答案进行模归一化$10^9+7$。 

### 为什么它有效

 对于每个子集$S$，包含-排除计数解决方案，其中所有变量$S$违反他们的上限。 将每个违规变量替换为$$y_i=x_i-(f_i+1)$$在此类解与减和方程的非负解之间创建双射。 星条准确地计算了这些解决方案。 

包含-排除保证每个有效的解决方案都被计算一次，而每个无效的解决方案都被取消。 由于每个子集都被处理，最终的总和等于同时满足所有上限的解的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def modinv(x):
    return pow(x, MOD - 2, MOD)

def comb_large_n_small_k(n, k):
    if n < 0 or k < 0 or k > n:
        return 0

    res = 1
    for i in range(1, k + 1):
        res = res * ((n - k + i) % MOD) % MOD
        res = res * modinv(i) % MOD
    return res

def solve():
    n, s = map(int, input().split())
    f = list(map(int, input().split()))

    ans = 0

    for mask in range(1 << n):
        t = s
        bits = 0

        for i in range(n):
            if mask & (1 << i):
                t -= f[i] + 1
                bits += 1

        if t < 0:
            continue

        ways = comb_large_n_small_k(t + n - 1, n - 1)

        if bits & 1:
            ans -= ways
        else:
            ans += ways

    print(ans % MOD)

solve()
```中心程序是`comb_large_n_small_k`。 上面的参数可能大到$10^{14}$，但较低的参数最多是$19$。 我们计算$$\binom{N}{K} = \prod_{i=1}^{K} \frac{N-K+i}{i} \pmod{MOD}$$直接地。 

因为$K<MOD$，每个分母都有一个模逆元。 

子集循环精确地实现了包含-排除。 对于每个选定的框，我们减去`f[i] + 1`，这相当于强制该框超出其限制。 如果结果和变为负数，则没有解，并且子集没有任何贡献。 

子集大小的奇偶性决定了贡献是增加还是减少。

 ## 边缘情况

 考虑```
1 0
0
```空子集给出$$\binom{0}{0}=1.$$违规子集产生负的约简和并且贡献为零。 最终的答案是`1`，代表不取花的独特选择。 

考虑```
1 5
3
```空子集贡献$$\binom{5}{0}=1.$$违规子集贡献$$\binom{1}{0}=1.$$包含-排除收益率$$1-1=0.$$每个无限制的解决方案都会违反上限，因此取消已完成。 

考虑```
2 1
0 0
```空子集贡献$$\binom{2}{1}=2.$$每个单框违规子集都会贡献$1$，双盒子集贡献$0$。 结果是$$2-1-1=0.$$不存在有效的选择，因为两个盒子都不包含任何花。 

负和情况会自动处理。 每当$$s-\sum_{i\in S}(f_i+1)<0,$$变量平移后不可能有任何非负解，因此贡献为零。 这可以防止无效的二项式计算并保持包含-排除在数学上的正确性。
