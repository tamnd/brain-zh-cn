 ## 解决方案
 # 问题理解

 我们在一个长度的圆上有两个多点集`m`。 

第一组包含办公地点。 办公室`i`位于城市`a[i]`。 

第二组包含候选人。 候选人`j`住在城市`b[j]`。 

每个办公室必须接收一名候选人，并且必须将每位候选人分配到一个办公室。 将候选人分配到办公室的成本是其城市之间的最短圆距离。 我们必须最小化总成本并输出一个最优分配。 

该圆包含最多`10^9`城市，但仅`n ≤ 200000`办公室和候选人。 城市数量巨大，因此任何取决于圆圈大小的算法都是不可能的。 我们唯一能处理的对象是`n`自己的立场。 

的价值`n`立即排除二次算法。 一个`O(n²)`解决方案大约需要`4 × 10^10`在最坏的情况下进行操作，这是完全不可行的。 目标复杂度必须约为`O(n log n)`。 

棘手的部分是这些城市位于一个圆上而不是一条线上。 

考虑：```
m = 10
offices    : 1 9
candidates : 2 10
```线性解释将使用距离`1`和`1`，但是在圆城上`10`毗邻城市`1`，因此几何图形环绕。 

另一个容易犯的错误是对两个数组进行排序并逐个位置进行匹配。```
m = 10
offices    : 1 4 8
candidates : 3 6 8
```排序后，匹配相等的排名给出成本```
|1-3| + |4-6| + |8-8| = 4
```但在圆上我们可以旋转一个排序顺序。 匹配```
1 <- 3
4 <- 6
8 <- 8
```实际上是产生最佳值的转变。 关键的观察是，最佳匹配始终是排序顺序的循环移位，而不一定是零移位。 

重复会造成另一个微妙的情况。```
m = 20
offices    : 5 5 5
candidates : 5 5 5
```有许多最佳分配。 解决方案仍必须输出候选索引的有效排列。 

## 方法

 暴力解决方案会尝试所有可能的完美匹配。 有`n!`匹配，这几乎立即变得不可能。 

更合理的蛮力从结构观察开始。 如果我们围绕圆圈对办公室职位进行排序，并围绕圆圈对候选职位进行排序，则任何最佳匹配都不会出现交叉对。 如果两条匹配的路径交叉，交换它们的端点永远不会增加总距离，而且常常会减少总距离。 反复删除交叉点会将任何最优值转化为非交叉最优值。 

一旦禁止交叉，匹配就完全由循环移位决定。 对两组进行排序后，选择一些班次`k`，然后匹配```
A[i] <-> B[i+k]
```与循环采用的指数。 

这减少了搜索空间`n!`只匹配到`n`轮班。 

不幸的是，独立评估每个班次仍然需要成本`O(n²)`。 

剩下的观察结果是，对于固定办公室职位`a`，其随平移变化的贡献是平移范围内的分段常数函数。 圆周距离```
dist(a, b) = min(|a-b|, m-|a-b|)
```仅当以下情况时才改变形式`b`跨越几个关键位置之一`a`。 

对坐标进行排序后，可以通过二分查找来定位这些关键转变。 每个办公室和每个候选人在连续的轮班范围内贡献一个恒定的值。 我们可以使用移位域上的差分数组来累积所有贡献。 

结果是`O(n log n)`算法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解所有班次 | O(n²) | O(n) | 太慢了 |
 | 移位差分数组| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按城市位置对办事处进行排序，记住其原始索引。 
2. 按城市位置对候选者进行排序，同时记住其原始索引。 
3、利用非交叉性。 任何最佳分配都必须将已排序的办公室序列与已排序的候选序列的循环移位相匹配。 
4.让转变`k`意思是排序办公室`i`与已排序的候选者匹配`(i+k) mod n`。 
5. 构建数组`cost[k]`, 总的轮班成本`k`。 
6. 处理每个办公室职位，而不是单独评估每个班次`a[i]`。 

对于固定办公室，表达式`dist(a[i], b[j])`仅当以下情况时才改变形式`b[j]`穿过圆圈周围的四个关键区域之一。 对排序后的候选坐标进行二分搜索，确定范围`j`属于各个地区。 
7. 将每个这样的区域转换为移位变量的范围更新`k = j - i`。 

差异数组允许将相同的值添加到整个移位间隔`O(1)`时间。 
8. 对每个候选位置重复对称过程`b[j]`。 

两次传递后，每个班次的累积值等于该班次的总匹配成本。 
9. 对差异数组进行前缀求和以恢复每个`cost[k]`。 
10. 选择成本最小的班次。 
11. 重构作业。 如果最好的转变是`k`，然后排序办公室`i`接收排序的候选者`(i+k) mod n`。 
12. 将作业转换回原始索引并打印结果。 

### 为什么它有效

 对圆周围的点进行排序后，任何交叉匹配都可以取消交叉，而不会增加目标值。 重复此过程会产生最佳的非交叉匹配。 

两个循环有序集合之间的非交叉完美匹配完全由一对起始对决定。 一旦选择了第一对，其余对必须遵循循环顺序。 这意味着每个最佳解决方案都对应于已排序候选序列的某种循环移位。 

差分数组结构同时计算每个班次的准确总成本。 每个办公室候选人对都对该对匹配的轮班做出了贡献，并且分段分解涵盖了所有可能性。 因此，移位的恢复值`k`正是由该转变定义的匹配的总成本。 选择其中的最小值即可得到全局最优值。 

## Python 解决方案```python
import sys
from bisect import bisect_right

input = sys.stdin.readline

def solve():
    m, n = map(int, input().split())

    A = [(x, i) for i, x in enumerate(map(int, input().split()), start=1)]
    B = [(x, i) for i, x in enumerate(map(int, input().split()), start=1)]

    A.sort()
    B.sort()

    a = [x for x, _ in A]
    b = [x for x, _ in B]

    aa = [2 * x for x in a]
    bb = [2 * x for x in b]

    diff = [0] * (n + 1)

    def add_range(l, r, v):
        if l > r:
            return

        l %= n
        r %= n

        if l <= r:
            diff[l] += v
            if r + 1 < n:
                diff[r + 1] -= v
        else:
            diff[0] += v
            if r + 1 < n:
                diff[r + 1] -= v
            diff[l] += v

    for i in range(n):
        x = a[i]

        r = bisect_right(bb, 2 * x - m - 1) - 1
        add_range(-i, r - i, -x)

        l = r + 1
        r = bisect_right(bb, 2 * x - 1) - 1
        add_range(l - i, r - i, x)

        l = r + 1
        r = bisect_right(bb, 2 * x + m) - 1
        add_range(l - i, r - i, -x)

        l = r + 1
        r = n - 1
        add_range(l - i, r - i, x + m)

    for i in range(n):
        x = b[i]

        r = bisect_right(aa, 2 * x - m - 1) - 1
        add_range(i - r, i, -x)

        l = r + 1
        r = bisect_right(aa, 2 * x) - 1
        add_range(i - r, i - l, x)

        l = r + 1
        r = bisect_right(aa, 2 * x + m) - 1
        add_range(i - r, i - l, -x)

        l = r + 1
        r = n - 1
        add_range(i - r, i - l, x + m)

    cur = 0
    best_shift = 0
    best_cost = None

    for k in range(n):
        cur += diff[k]
        if best_cost is None or cur < best_cost:
            best_cost = cur
            best_shift = k

    ans = [0] * n

    for i in range(n):
        j = (i + best_shift) % n
        office_idx = A[i][1]
        candidate_idx = B[j][1]
        ans[office_idx - 1] = candidate_idx

    print(best_cost)
    print(*ans)

solve()
```第一部分对办公室和候选人进行排序，同时保留原始索引，以便可以重建最终的分配。 

实现的核心是移域差分阵列。 每个二分搜索不是单独计算每个班次的成本，而是识别接收相同贡献的整个班次间隔。 帮手`add_range`执行循环范围更新，因为移位是取模的`n`。 

四个二分搜索范围对应于圆距离的四种不同代数形式。 它们的推导来自于比较直接弧和包裹弧。 

应用所有更新后，前缀总和会重建每个班次的总成本。 最小偏移决定最佳匹配。 

一个容易犯错误的地方是模间隔更新。 间隔可能会环绕移位数组的末尾，因此必须将它们分成两个普通范围。 错误的另一个常见来源是使用`bisect_right(...)-1`，它有意查找属于某个区域的最后一个索引。

 ## 边缘情况

 考虑：```
10 2
1 9
10 2
```圆的距离是`1`和`1`，给出总成本`2`。 线性距离解会错误地计算`1 + 7 = 8`。 该算法可以处理此问题，因为距离分解明确使用圆形度量并将环绕路径视为第一类候选路径。 

现在考虑重复的位置：```
20 3
5 5 5
5 5 5
```每次转变都有成本`0`。 差分数组构造在各处分配零贡献，所有移位平局，并且算法输出一种有效排列。 无需特殊处理。 

最后，考虑最佳匹配与原始顺序不明显的情况：```
10 3
1 4 8
8 3 6
```排序揭示了循环排序。 非交叉属性将搜索空间减少为循环移位，最小成本移位以总成本重现最优分配`4`。 该算法从不依赖于原始输入顺序，只依赖于圆周围的几何顺序。
