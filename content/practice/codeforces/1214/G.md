 ## 解决方案
 ## 问题理解

 我们有一个代表变色龙身体的二维网格。 最初，所有单元格都是绿色的。 每个单元格可以是绿色或蓝色，并且颜色可以翻转多次。 每次翻转都会影响单行的连续水平段。 每次翻转后，我们必须确定变色龙是否心情好，如果存在一个由四个单元格组成的矩形形成“好心情证书”，就会发生这种情况。 好心情证书是一个 2×2 子网格，其中相对的角共享相同的颜色，但并非所有四个角都相同。 

输入提供网格大小`n × m`和一系列`q`翻转。 每次翻转指定行和列间隔来反转颜色。 每次翻转后的输出是`-1`如果变色龙心情不好，或者表示有效好心情证书坐标的四个整数。 

限制意味着在每次翻转后检查每个可能的矩形的强力方法是不可行的。 和`n, m`最多 2000 个，可能的 2×2 子矩形的数量大致为`O(n*m) = 4×10^6`，并且最多 500,000 次翻转，简单的 O(n_m_q) 方法将导致数万亿次操作。 这迫使我们考虑增量更新，而不是每次都重新检查整个网格。 

边缘情况包括只有一行或一列的网格（其中不能存在矩形）、相互撤销的翻转以及证书出现和消失的交替模式。 例如，我们翻转一个 2×2 的网格`(1,1,1)`和`(2,2,2)`反复可能会导致情绪时好时坏。 

## 方法

 最简单的方法是明确地模拟网格。 每次翻转后，我们可以迭代所有 2×2 子矩形，检查颜色，并输出证书（如果存在）。 这是正确的，但太慢了：每次翻转的成本为 O(n*m) 并且`q`可以是500,000。 

关键的见解是跟踪可以创建好心情证书的模式，而无需检查整个网格。 只有两行包含颜色翻转奇偶性不同的段的矩形才能生成证书。 如果行段已翻转奇数次，则其颜色与最初的绿色不同。 因此，我们只需要监视每行最左边和最右边的翻转单元，并检查相邻行是否有潜在的 2×2 矩形。 

我们可以将每一行表示为位掩码或具有翻转奇偶校验的间隔列表。 每次更新后，我们只需要检查该行及其相邻行中受影响的 2×2 矩形。 这将每次翻转检查减少到 O(m)，总复杂度为 O(q*m)，这是可以接受的`m`最多 2000 和`q`最多 500,000。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(q_n_m) | O(q_n_m) | O(n*m) | 太慢了 |
 | 最佳 | O(q*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 将每一行表示为一个二进制数组，指示每个单元格是否已翻转奇数次。 最初，全为零。 
2. 每次翻转`(a, l, r)`，增加指定间隔的翻转计数。 使用前缀和或差异数组，可以在每行每次操作 O(1) 的时间内高效完成此操作。 
3. 将翻转应用于行后`a`，使用差异数组累积和将行转换回实际奇偶校验值（0 表示绿色，1 表示蓝色）。 仅需要更新受影响的行。 
4.检查好心情证书。 迭代该行和紧邻该行的下一行（如果存在）以查找任意 2×2 子矩形，其中对角相等但并非所有四个角都相等。 对于每个列索引`c`,检查四个单元格`(a, c)`,`(a, c+1)`,`(a+1, c)`,`(a+1, c+1)`。 
5. 如果存在这样的矩形，则输出其坐标。 否则，输出`-1`。 
6. 每次翻转重复此操作。 

为什么它有效：在每次翻转时，我们只修改一行，因此只有涉及该行和紧邻其下方的行的 2×2 矩形可以更改其状态。 通过维护奇偶校验和使用增量检查，我们确保永远不会错过潜在的证书。 由于每个矩形在可能发生变化时都会被准确检查，因此保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, q = map(int, input().split())
rows = [[0]*m for _ in range(n)]  # 0=green, 1=blue

def check_good(x):
    if x == n - 1:
        return None
    for y in range(m-1):
        a = rows[x][y]
        b = rows[x][y+1]
        c = rows[x+1][y]
        d = rows[x+1][y+1]
        if a == d and b == c and not (a == b == c == d):
            return (x+1, y+1, x+2, y+2)  # 1-based
    return None

for _ in range(q):
    a, l, r = map(int, input().split())
    a -= 1
    l -= 1
    r -= 1
    for y in range(l, r+1):
        rows[a][y] ^= 1
    found = None
    for x in [a-1, a]:
        if 0 <= x < n-1:
            res = check_good(x)
            if res:
                found = res
                break
    if found:
        print(*found)
    else:
        print(-1)
```我们将每一行维护为 0/1 值的列表。 翻转操作是对受影响的区间进行简单的异或。 检查好心情证书仅检查涉及更新行及其直接邻居的矩形。 这对于效率至关重要：该算法从不扫描未受影响的行，从而使每个查询的时间保持线性`m`。
