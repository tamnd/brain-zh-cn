 ## 解决方案
 ## 问题理解

 我们给出了三个整数来描述一个小的组合设置。 男孩和女孩的总数是固定的，并且恰好$n$参与者将参加一项活动，但我们不知道其中有多少是男孩或女孩。 参加活动的实际男孩人数可以从 0 到$n$，只要不超过可用的男孩人数，同样女孩的数量由余数决定。 

对于每一个可能的分裂$n$参与者分为男孩和女孩，我们需要能够正确分配徽章。 每个可能的分割都需要特定类型的徽章牌组：如果有$i$孩子们，我们需要一套包含以下内容的套牌：$i$蓝色徽章和$n-i$红色徽章。 

我们被赋予了一切$n+1$可能的套牌，但我们不需要拿走所有套牌。 任务是选择这些牌组的最小子集，使得对于每个可行值$i$考虑到男孩和女孩总数的限制，这种情况实际上可能会发生，至少有一套选定的牌组与之匹配。 

输入大小很小，以 300 为界。这消除了高级数据结构或优化的任何压力； 直接算术或贪心推理就足够了。 二次甚至线性扫描是完全可以接受的。 

当某些值时，会出现微妙的边缘情况$i$由于缺少男孩或女孩而不可能。 例如，如果只有 2 个男孩，那么任何需要 3 个或更多蓝色徽章的套牌即使存在，也是无关紧要的。 一种总是假设一切的幼稚方法$0 \ldots n$值可能会超出所需的牌组数量。 

## 方法

 蛮力观点是考虑所有可能的男孩数量$i$在比赛中，从 0 到$n$，并检查该配置是否可行。 仅当配置可行时$i \le b$和$n-i \le g$。 对于每一个可行的$i$，我们必须包含相应的牌组。 

这立即建议进行简单扫描：标记所有有效$i$，然后对它们进行计数。 这已经正确解决了问题，因为每个有效的$i$对应于不同的所需牌组，并且没有牌组可以提供两个不同的值$i$因为每副牌都编码固定数量的蓝色徽章。 

对蛮力的“优化”主要是概念性的。 我们不需要推理子集或重叠，因为结构是线性的：每个$i$正好映射到一副牌。 唯一真正的任务是确定有效范围$i$。 

由不等式可知：$i \le b$和$n-i \le g \Rightarrow i \ge n-g$。 

如此有效$i$位于交叉路口：$$\max(0, n-g) \le i \le \min(n, b)$$答案就是这个区间的大小（如果它非空的话）。

 ## 算法演练

 1. 计算锦标赛中可能的最少男孩人数：$L = \max(0, n - g)$。 这确保了我们在组建剩余参与者时不会超过可用的女孩人数。 
2. 计算男孩的最大可能数量：$R = \min(n, b)$，因为我们不能超过参与者总数或可用男孩数。 
3.如果$L > R$，不存在有效的配置，这意味着实际上不需要任何牌组来满足可行的场景，因此答案为 0。 
4. 否则，所有整数值$i$在范围内$[L, R]$对应于可行的场景，每个场景都需要不同的牌组。 
5. 因此所需的甲板数量为$R - L + 1$。 

### 为什么它有效

 每个可行的锦标赛配置均由男孩数量唯一标识$i$。 约束限制$i$到一个连续的区间。 该区间中的每个整数都对应于不同的所需徽章组合，并且每个组合都由一副牌表示。 由于牌组定义之间不存在重叠，因此覆盖所有可行的情况可以精确地简化为覆盖该区间中的每个整数。 没有额外的选择策略可以在不丢失有效的情况下减少计数$i$。

 ## 边缘情况

 当女孩充足而男孩是限制因素时，下限$L = \max(0, n-g)$变为 0 并且区间向上扩展，直到$b$。 该算法正确地包括了所有可行的$i$从 0 到$b$。 

当男孩较多而女孩稀缺时，上限为$R = n$但下限向上移动到$n-g$，消除不可能的小值$i$。 计算出的间隔仍然保持连续且大小正确。 

当两者$b$和$g$太小而无法形成任何有效的分割，条件$L > R$触发，产生 0，这符合没有参与者分配是可行的事实。
