 ## 解决方案
 ## 问题理解

 我们有一辆巴士`n`单排座位，编号从 1 到`n`。 乘客逐一登机，每个人都根据一个简单的规则选择座位：第一位乘客可以坐在任何地方，但任何后续乘客都必须坐在已占用座位的旁边。 我们得到了选择座位的时间顺序`n`乘客，并且必须确定每位乘客是否遵循了此建议。 

输入由多个测试用例组成。 每个测试用例提供`n`以及座位号数组。 如果该测试用例中的每个乘客都遵守邻接规则，则输出为“YES”，否则输出为“NO”。 

约束条件允许`n`每个测试用例达到 2·10^5，最多有 10^4 个测试用例，尽管所有测试用例的总和`n`所有测试用例最多为 2·10^5。 这意味着我们无法承受 O(n^2) 方法，因为在最坏的情况下它会执行大约 4·10^10 次操作。 我们需要一个具有整体线性或近线性复杂度的解决方案。 

当前几名乘客占据公共汽车的两端时，就会出现边缘情况。 例如，如果`n = 5`顺序是`[5, 4, 2, 1, 3]`，第三位乘客选择座位`2`，这是无效的，因为两个邻居都没有被占用。 仅检查到目前为止序列中是否存在座位号的简单方法会错过这一点，因为此时占用的座位不是连续的。 

另一种微妙的情况发生在乘客从一端严格按照递增或递减顺序占用座位时，这是有效的，因为每个新座位都与当前占用的部分相邻。 检测连续的占用座位段至关重要。 

## 方法

 蛮力方法很简单：对于第一位乘客之后的每位乘客，检查紧邻左侧和右侧的座位，并验证是否有一个座位被占用。 这在逻辑上是有效的，但每次检查都需要扫描占用的座位列表，从而导致每个测试用例的复杂度为 O(n^2)。 这对于大型企业来说是不可行的`n`。 

关键的观察结果是，在任何时间点，有效座位集形成了连续的占用座位块。 每位新乘客必须直接坐在其最左边或最右边已占用座位的旁边来扩展此区域。 因此，我们只需要跟踪当前最左边和最右边的占用座位即可。 对于第一位乘客，我们将两端设置在该座位上。 随后的每位乘客必须坐在当前左端的左侧或当前右端的右侧。 如果乘客选择这两个选项之外的座位，则违反规则。 

此观察允许对序列进行 O(n) 扫描，同时维护两个变量，`left`和`right`，代表当前占用的段。 不需要复杂的数据结构。 该解决方案简单高效，非常适合给定的约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（扫描所有占用的座位）| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 段跟踪（两个指针）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化两个指针，`left`和`right`， 到`-1`。 这些将跟踪当前连续的占用座位块。 
2. 迭代乘客的座位选择顺序。 
3. 对于第一位乘客，设置两者`left`和`right`到他们的座位号。 这建立了初始段。 
4. 对于每位后续乘客，检查他们的座位是否紧邻左侧（`seat == left - 1`）或立即向右（`seat == right + 1`) 当前段的。 
5. 如果座椅向左端延伸，则更新`left`到这个新座位。 如果它延伸到右端，则更新`right`。 如果它没有延伸到任一端，则为此测试用例返回“NO”。 
6. 如果所有乘客都满足邻接条件，则返回“YES”。 

为什么有效：通过维护最左边和最右边的占用座位，我们保证占用的座位形成一个连续的段。 由于乘客只能坐在该路段附近，因此任何违规行为都会立即表明违反规则。 每个步骤后都会维护这个不变量，以确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def seating_in_bus():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        left = right = -1
        valid = True
        
        for seat in a:
            if left == -1:
                left = right = seat
            elif seat == left - 1:
                left = seat
            elif seat == right + 1:
                right = seat
            else:
                valid = False
                break
        
        print("YES" if valid else "NO")

if __name__ == "__main__":
    seating_in_bus()
```代码初始化`left`和`right`到`-1`指示空巴士。 对于每位乘客，我们检查他们是否坐在当前占用的航段旁边。 更新段边界可确保后续检查保持有效。 支票`seat == left - 1`和`seat == right + 1`有效地处理两端。 在第一次违规时尽早中断可以避免不必要的计算。

 ## 边缘情况

 如果第一位乘客坐在中间，例如，`n = 5`， 顺序`[3, 2, 4, 1, 5]`，算法初始化`left=right=3`。 乘客2坐在`2`（`left-1`），更新`left=2`。 乘客3坐在`4`（`right+1`），更新`right=4`。 乘客 4 坐在`1`（`left-1`），更新`left=1`。 乘客5坐在`5`（`right+1`），更新`right=5`。 每个步骤都保持连续段的不变性。 该算法正确输出“YES”。 这证实了对两个方向的重要段增长的正确处理。
