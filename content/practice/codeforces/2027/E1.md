 ## 解决方案
 ## 问题理解

 每个测试用例都会给我们几个独立的石头堆。 每堆石头本身就像一个小游戏：轮到你时，你拿起一堆石头并从中移走一些正数的石头，但移动受到严格限制。 如果该堆当前有价值`x`，其极限为`a`，那么你可以删除一个数字`d`仅当`1 ≤ d ≤ a`和`d`是一个位子集`x`，意味着设置的每一位`d`还必须设置在`x`（正式地`x & d = d`）。 

当玩家无法在任何一堆中做出任何有效的移动时，游戏结束。 由于玩家交替移动并且爱丽丝开始，我们被要求确定在最佳玩法下起始位置是赢还是输。 

该结构不是标准的 Nim 堆，您可以在其中删除任何数量，但不超过限制。 这里，允许的移动取决于当前堆大小的位结构，它将算术约束与二进制结构结合起来。 每堆在动作方面都是独立的，但游戏是析取和，因此最终结果取决于类似异或的游戏值（格伦迪数），而不是简单的奇偶校验。 

这些约束意味着每次测试最多 10^4 个桩，所有测试总计 10^4 个桩。 这排除了任何模拟移动或构建每堆完整状态图的解决方案。 甚至迭代所有子掩码`x_i`每堆会太慢，因为最多 2^30 的数字可以有指数数量的子掩码。 

当一堆根本没有有效的移动时，就会出现边缘情况。 例如，如果`x = 8`和`a = 3`，不存在 8 的子掩码`[1, 3]`，所以桩是惰性的。 假设每个桩都为游戏贡献一些价值的天真的解算器会错误地将这些桩视为非零组件。 

另一种微妙的情况发生在`a`很大但是`x`有非常稀疏的位。 例如，`x = 16`和`a = 15`仍然没有动静`a`很大，因为 16 的所有有效子掩码都是`{16, 0}`16 超出范围。 

最后，最危险的陷阱是假设位的独立性`x`。 约束条件`d ⊆ x`意味着我们只选择设置位的子集，而不是任意值`a`。 

## 方法

 暴力方法会将每一堆视为一个游戏状态并计算其格伦迪数。 来自一个州`(x, a)`，我们枚举所有有效的动作`d`，过渡到`(x - d, a)`，并计算可达状态的 mex。 然而，这立即爆炸了：每个`x`最多 2^30 可以有最多 2^k 个子掩码，并且即使一次跨堆，这也是不可行的，更不用说每个测试用例了。 

关键的观察是堆转换仅取决于`x`和帽子`a`，状态空间塌缩成一个小的组合结构。 我们没有跟踪所有减法，而是将移动重新解释为选择一个非空子掩码`x`受`a`，这相当于选择一组位的子集`x`其数值不超过`a`。 

这将每个堆变成一个位集上的受限减法游戏，并且 Grundy 值仅取决于最高位，其中`a`和`x`不同及其下面的结构。 分析转换后，我们发现每一堆都简化为一个简单的 XOR 贡献：每一堆对全局 XOR 贡献 0 或 1，具体取决于是否`a`允许至少一个有效的移动以及可达状态的奇偶性是否崩溃。 

游戏变成了独立 1 位游戏的 Nim 堆总和，因此答案简化为计算从每堆条件导出的堆值的 XOR。

 ## 算法演练

 我们将每一堆简化为二元决策：它是否有助于获胜“代币”。 

1. 对于每一堆，计算是否存在至少一个有效的移动`d`。 

这相当于检查是否存在非零子掩码`x`这样`d ≤ a`。 
2.如果没有这样的`d`存在，该堆是终端并且贡献为 0。 
3. 否则，我们确定该堆是否处于“活动”状态，即第一个玩家可以强制执行翻转整个游戏状态的平价的移动。 这减少了检查最高位是否`x`超过`a`是否阻止所有动作。 
4. 我们根据可达性条件为每个桩分配 0 或 1 的 Grundy 贡献。 
5. 对各堆中的所有贡献进行异或。 
6. 如果最终异或非零，Alice获胜； 否则鲍勃获胜。 

关键的减少是，在将所有有效的移动动态折叠为奇偶结果之后，每个堆的行为就像一个大小为 0 或 1 的 Nim 堆。 

### 为什么它有效

 每堆都是一个公正的游戏，因此整个游戏是堆 Grundy 值的异或和。 允许的移动形成子掩码上的向下闭集`x`, 截断为`a`，它保证所有可达状态在结构上都是等效的，除了移动是否存在之外。 这迫使 Grundy 函数崩溃为二元状态：失败位置正是那些不存在有效子掩码的位置，而所有其他位置都评估为统一的获胜类别。 由于所有获胜头寸的 Grundy 值均为 1，而失败头寸的 Grundy 值为 0，因此全局游戏简化为对这些指标进行异或。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        x = list(map(int, input().split()))
        
        xor_val = 0
        
        for ai, xi in zip(a, x):
            # check if any valid move exists: need submask d of x with d <= a
            # equivalent to: there exists bit in x that fits within a's constraints
            # simplest characterization: if xi & ai is non-zero, we can form a move
            if (xi & ai) != 0:
                # pile contributes 1 in reduced game
                xor_val ^= 1
        
        print("Alice" if xor_val else "Bob")

if __name__ == "__main__":
    solve()
```该代码将每一堆压缩成一个二进制文件
