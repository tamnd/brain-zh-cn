 ## 解决方案
 ## 问题理解

 我们被赋予了一条笔直的道路$n$站编号为$1$到$n$。 车站之间$i$和$i+1$，有一段路段长度为$v_i$。 在每个车站$i$，燃油可以买，但是每个站都有自己的固定价格$a_i$每升。 

汽车在车站启动$1$油箱已空且必须到达车站$n$。 油箱没有容量限制，但油耗是量化的：一升油可以让汽车准确行驶$d$公里，因此行驶一段长度$v_i$需要$\lceil v_i / d \rceil$升。 

任务是选择每个站点购买多少燃料，使汽车能够穿越所有路段，并使总成本最小化。 

约束允许最多$10^5$站和段长度可达$10^5$。 这强烈表明$O(n)$或者$O(n \log n)$解决方案。 Any approach that tries to simulate all possible refueling decisions or dynamic programming over fuel states would be too slow because the state space would explode with both position and fuel quantity.

 燃料消耗的整数舍入产生了一个微妙的问题。 即使一个段仅比多个段稍长$d$，它仍然需要额外的满升。 例如，如果$d = 4$和$v_i = 5$，那么我们需要$2$升，不$1.25$。 

另一个不明显的问题是燃料从哪里购买。 由于燃料不受油箱尺寸的限制，因此购买决策纯粹取决于价格，而不是可行性。 一种天真的方法可能会尝试在每个加油站本地决定是否只为下一段购买燃料，但当后面的加油站更便宜并且可以更早使用时，这种方法就会失败。 

## 方法

 蛮力策略将考虑在每个加油站购买多少燃料，然后模拟加油站之间所有可能的燃料购买分布。 即使限制自己“准确购买下一个或更多细分市场所需的东西”，仍然会导致指数级的选择，因为燃料可以无限期地结转，而且决策会在许多细分市场之间相互作用。 

针对站点和剩余燃料的动态规划公式也变得不切实际。 燃料数量是无界的，将其离散化会导致与总可能燃料需求成比例的非常大的状态空间。 

关键的观察结果是燃料是完全可转移的并且没有降解成本，因此唯一有意义的因素是迄今为止最便宜的价格。 一旦我们到达价格较低的车站，它就会在未来的购买中优先于所有之前的车站。 

因此，对于每个路段，最优策略是以最低价格从以下站点购买该路段所需的所有燃料：$1$直到当前电台。 我们只需维持最低燃油价格并将其乘以每个细分市场的燃油需求即可。

 ## 算法演练

 让我们从左到右处理道路，同时跟踪迄今为止遇到的最便宜的燃油价格。 

1. 初始化变量`best_price`与 1 号站的价格相同，因为这是第一个可用的选项。 这代表了我们目前可以使用的每升的最低成本。 
2. 初始化`answer = 0`，这将累积总成本。 
3. 对于从车站出发的每个航段$i$到$i+1$，计算所需的升数：$$\text{liters} = \frac{v_i + d - 1}{d}$$这是其覆盖范围的最小整数升$d \cdot \text{liters}$至少是$v_i$。 
4.添加答案：$$\text{answer} += \text{liters} \times \text{best\_price}$$这反映出以迄今为止最便宜的价格购买该细分市场的所有燃料。 
5. 在进入下一个部分之前，更新：$$\text{best\_price} = \min(\text{best\_price}, a_{i+1})$$这确保了未来的细分市场可以从前面任何更便宜的车站中受益。 
6.处理完所有段后，输出`answer`。 

### 为什么它有效

 在道路上的任何地点，之前购买的任何燃料都可以在以后使用而不会造成损失。 因此，如果我们遇到价格较低的加油站，就没有理由提前以较高的价格购买燃料以供将来使用。 最好的策略始终是将迄今为止最便宜的价格视为满足所有剩余需求的有效燃料成本。 这创建了一个前缀最小结构，其中每个段都根据迄今为止最便宜的可达车站独立分配成本，并且购买的任何重新安排都不能进一步降低总成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, d = map(int, input().split())
    v = list(map(int, input().split()))
    a = list(map(int, input().split()))

    best_price = a[0]
    ans = 0

    for i in range(n - 1):
        liters = (v[i] + d - 1) // d
        ans += liters * best_price
        if i + 1 < n:
            best_price = min(best_price, a[i + 1])

    print(ans)

if __name__ == "__main__":
    solve()
```代码直接遵循贪婪结构。 该循环处理每个路段一次，使用整数上限除法计算所需的升数。 变量`best_price`维持燃油价格的最低前缀，确保每个航段都以迄今为止最便宜的可用费率收费。 

一个常见的实施陷阱是在错误的时间更新最低价格。 使用当前段的价格决策逻辑后必须更新； 否则，算法将错误地允许站点$i+1$用于段$i$，这是不可能的，因为在到达车站之前就已经到达该路段$i+1$。

 ## 边缘情况

 当稍后出现更便宜的电台时，就会出现一个关键的边缘情况。 假设第一站很贵，最后一站非常便宜。 该算法正确地避免了为未来的路段购买任何较早的燃料，因为它仅在经过每个加油站后才不断更新最低价格。 

另一个边缘情况是当$v_i$不能被整除$d$。 例如，如果$d = 4$和$v_i = 5$，算法计算$(5 + 3) // 4 = 2$升。 错误的楼层划分会错误地仅分配 1 升并低估成本，从而使解决方案无效。 

最后一个微妙的情况是所有价格都相同。 在这种情况下，该算法有效地减少了对所有分段燃料需求乘以恒定价格的求和，表明贪婪结构干净地退化为直接累加，而不需要任何优化决策。
