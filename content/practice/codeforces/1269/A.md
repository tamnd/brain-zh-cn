 ## 解决方案

 ## 问题理解

 我们被要求构造两个复合整数，称它们为$a$和$b$，这样它们的差值恰好是给定的数字$n$。 两个数字都必须至少为 2，并且都必须是合数，这意味着每个数字都至少有一个非平凡的除数。 

输出不是唯一的，因此只要满足算术约束，任何有效对都是可以接受的$a - b = n$以及两个数字的复合性约束。 

约束条件$n \le 10^7$看起来足够大，我们应该避免任何依赖于因式分解或反复检查素性的构造$n$。 然而，输出范围要大得多，最多$10^9$，这使我们能够灵活地使用小型固定复合模式来构建数字。 

一个天真的方法是尝试$b$从 2 向上并设置$a = b + n$，然后检查两者是否复合。 这原则上是可行的，但在最坏的情况下，我们可能会扫描许多候选者并反复测试素性。 即使进行快速素性检查，这也是不必要的，因为问题的结构保证了恒定时间构造的存在。 

边缘情况主要是关于较小的值$n$。 例如，当$n = 1$，我们必须确保两个数字都是合数，所以像这样的对$9$和$8$工作，但成双成对喜欢$3$和$2$失败，因为两者都是素数。 相似地，$n = 2$或者$n = 3$需要小心，因为如果我们不系统化，小的偏移很容易落在素数上。 

关键的挑战是找不到大型解决方案$n$，但确保始终产生合数的统一结构，无论奇偶校验或大小如何。 

## 方法

 蛮力策略从修复开始$b$并检查两者是否$b$和$b + n$是复合的。 自从$n$可以达到$10^7$，并且有效$a, b$可以达到$10^9$，原则上我们可以尝试许多值$b$。 对于每个候选者，我们大致执行素性检查$O(\sqrt{x})$时间。 即使我们只测试几千个值，考虑到常量构造的存在，这也已经是不必要的开销。 

效率低下是因为将其视为搜索问题。 结构更简单：我们不尝试优化任何内容或搜索稀疏解空间，我们只需要满足线性关系和弱数论属性的任何对。 

关键的观察结果是，合数在大整数中极其密集，我们可以故意使用小的固定复合构建块来构造它们。 例如，$8 = 2 \cdot 2 \cdot 2$,$9 = 3 \cdot 3$， 和$10 = 2 \cdot 5$。 一旦我们有了一个小的固定复合锚栓，我们就可以安全地移动它。 

标准结构是选择固定的复合材料$b$，然后设置$a = b + n$，并确保$a$也是通过嵌入因式分解模式来复合的。 干净的技巧是使用像这样的数字$8$和$9$，因为它们是复合的并且相差 1。从那里开始，将两者都移动$n$保留差异性的同时保持复合性。 

一种稳健的模式是：

 选择$b = 8$,$a = 8 + n$。 如果$a$是复合的，我们就完成了。 如果没有，我们使用稍大的基数进行调整，例如$b = 9$， 自从$9 + n$对于有效的约束几乎总是复合的，并且在最坏的情况下小的调整保证了有效性。 

编辑解决方案中使用的更具确定性的结构是：

 设置$b = 8$,$a = n + 8$，但如果需要通过使用进行调整$b = 9$,$a = n + 9$。 由于复合整数的密度以及我们只需要避免有限多个素数例外的事实，这些对中至少一对总是会产生两个复合数。 

因此，问题简化为常数时间构造。

 ## 算法演练

 我们直接构造一个有效的对，无需搜索。 

1.固定一个小的复合基值，通常$b = 8$。 这确保了$b$在所有输入上都是复合且稳定的。 
2. 设置$a = b + n$。 这保证了所需的差异$a - b = n$。 
3. 检查是否$a$是复合的。 如果是，我们可以输出$a, b$立即地。 
4.如果$a$是素数，通过选择另一个固定复合底座来调整结构，例如$b = 9$，并设置$a = 9 + n$。 
5. 输出结果对。 

关键的想法是我们只需要避免罕见的情况$b + n$落在一个素数上。 由于我们至少有两个固定的复合锚点，并且素数是稀疏的，因此这些锚点之一总是会产生一个复合锚点$a$在限制范围内。 

### 为什么它有效

 正确性基于两个事实。 首先，所选择的基值保证是复合的。 其次，对于任意$n \ge 1$，至少其中之一$n + 8$或者$n + 9$是复合的。 这是因为连续整数不能同时为素数，除了$2$和$3$，这里两个候选人至少$9$或更大，消除唯一特殊的小区域。 因此，至少有一种结构可以避免两端的素数，从而确保有效的对始终存在。
