 ## 解决方案
 ## 问题理解

 给定一棵以节点 1 为根的树，其中每个节点都带有正整数权重。 相对于选定的根，树的成本是节点权重与其距该根的距离的乘积的所有节点的总和。 对于被视为新子树根的每个节点，我们需要计算在可选地执行单个操作后可实现的最大可能成本：将子树内的一个节点（不是根本身）移动到同一子树内的新父节点。 

这意味着对于每个节点，我们希望通过稍微重新排列子树来最大化从该节点到其子树中所有节点的距离的加权和。 输入提供多个测试用例，每个测试用例都有一棵树和一个节点权重列表。 输出应该是树中每个节点的最大成本列表，每个测试用例一个列表。 

约束告诉我们所有测试用例的节点总数最多为 200,000 个。 这消除了任何从头开始重新计算每个可能的节点或每个可能的移动操作的距离的幼稚解决方案，因为暴力方法可能涉及$O(n^2)$每个测试用例的操作次数最多$10^9$总体计算。 边缘情况包括子树中只有自己的节点，其中不可能移动，或者节点具有多个子节点且权重差异较大，其中最佳移动可能不会立即明显。 例如，如果节点 3 的子树具有权重为 1、2 和 10 的节点，则算法应选择移动最重的节点以在可能的情况下最大化深度。 粗心的实现可能总是选择最深的节点或最重的节点，而不考虑它们与距离的乘积，从而产生次优成本。 

## 方法

 暴力方法将每个节点作为根，计算其子树的初始成本，然后尝试该子树中每个节点到子树中每个其他可能的父节点的每个有效移动，每次都重新计算子树成本。 这在逻辑上是正确的，但是对于具有$k$节点，这可能涉及$O(k^3)$操作，因为对于每个节点移动，我们需要重新计算到所有后代的距离。 对树中的所有节点求和，这很容易超出允许的操作。 

优化的关键观察是，最佳可能的移动始终是使具有最大权重的节点尽可能远离当前子树根，从而增加其距离贡献。 一旦子树的根位于$r$，节点的最大可实现距离增加受子树高度的限制。 因此，我们可以首先使用标准深度优先搜索计算每个子树的总成本，而无需任何移动。 然后，我们可以找到每个子树中权重最大的节点，并将其虚拟地“附加”到距根最远的叶子上，从而给出该节点的最大可能深度。 这将问题简化为树DP，其中每个节点存储其后代及其子树中最大权重节点的权重总和，使我们能够计算每棵树的线性时间的最佳成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从输入边构建树并读取节点权重。 这给出了标准的邻接列表表示。 
2. 对于每个节点，执行深度优先搜索来计算两个量：子树的初始成本（如果以该节点为根），以及其子树中的权重总和。 对于一个节点$u$，初始子树成本为$\sum_{v \in \text{subtree}(u)} a_v \cdot d(u,v)$。 这是通过将子级的成本加上其权重之和（因为每个权重为父级提供额外的距离 1）来递归地完成的。 
3. 在 DFS 期间，还跟踪每个子树中的最大权重节点。 对于每个节点$u$, 存储最大重量$m_u$在其子树中找到，以及实现它的节点相对于的深度$u$。 
4. 对于以 为根的子树，计算至多一次移动后的最大成本$u$，考虑将最大权重节点移动到距离最远的叶子$u$。 潜在收益是$m_u \cdot (\text{height} - d_{\text{current}})$。 将此增益添加到初始子树成本中以获得子树的最大可实现成本$u$。 
5. DFS 完成后，输出每个节点在步骤 4 中计算出的最大成本。由于树具有$n$节点，并且每个 DFS 调用只处理每个节点一次，每棵树的总体复杂度为$O(n)$。 

保证正确性的不变量是，移动任何其他节点或任何移动组合都不会比将最重的节点移动到其子树的最深位置产生更大的增益。 这是因为成本与重量和距离的乘积呈线性关系，因此最大化最大重量的距离会产生单个允许移动的全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)
        
        # initialize arrays
        subtree_sum = [0]*n
        initial_cost = [0]*n
        max_weight = [0]*n
        max_depth = [0]*n

        def dfs(u, parent):
            subtree_sum[u] = a[u]
            max_weight[u] = a[u]
            max_depth[u] = 0
            total = 0
            for v in adj[u]:
                if v == parent:
                    continue
                dfs(v, u)
                subtree_sum[u] += subtree_sum[v]
                total += initial_cost[v] + subtree_sum[v]
                # update max weight
                if max_weight[v] > max_weight[u] or (max_weight[v]==max_weight[u] and max_depth[v]+1>max_depth[u]):
                    max_weight[u] = max_weight[v]
                    max_depth[u] = max_depth[v]+1
            initial_cost[u] = total

        dfs(0, -1)

        ans = [0]*n

        def dfs2(u, parent):
            # initial cost
            cost = initial_cost[u]
            if u != 0:
                # gain: move heaviest node to deepest leaf
                cost += max_weight[u]*max_depth[u]
            ans[u] = cost
            for v in adj[u]:
                if v == parent:
                    continue
                dfs2(v, u)

        dfs2(0, -1)
        print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```第一个 DFS 计算每个子树的初始成本并跟踪最大权重节点及其深度。 第二个 DFS 计算可能将最大权重节点移动到最深点后每个节点可实现的最大成本。 我们将 DFS 分为两遍，以清楚地区分计算子树属性和评估移动。 

微妙之处包括确保根节点本身永远不会移动，在比较最大权重节点时正确处理深度更新，以及准确地传播权重总和以计算初始成本。 增加递归深度以防止大型链上的堆栈溢出。
