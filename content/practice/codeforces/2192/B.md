 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，它是一个序列`0`沙`1`s，我们可以执行一项非常具体的操作：选择一个索引`i`，并翻转字符串中除索引处的位之外的所有位`i`。 翻转意味着改变`0`到`1`和`1`到`0`。 我们可以多次执行此操作，但每个索引只能使用一次。 目标是使字符串中的所有位都等于`0`。 如果这是不可能的，我们必须报告`-1`。 

字符串长度`n`最多可达 200,000，并且一次运行中所有测试用例的总长度也不超过 200,000。 这立即排除了尝试所有操作序列的任何强力解决方案，因为组合的数量呈指数增长`n`。 相反，我们需要一种方法来检查字符串结构并决定在单次传递或对字符串进行几次传递中选择索引。 

一些不明显的边缘情况是由已经全为零的字符串或其中的数量的字符串引起的。`1`在某些方面，s 恰好是字符串长度的一半。 例如，像这样的字符串`1010`不能变成全零，因为每个操作几乎翻转整个字符串，并且会出现奇偶校验冲突。 另一个微妙之处是，如果字符串恰好有一个`1`，选择该索引作为操作会将所有其他零翻转为一，这是不可取的。 一个幼稚的解决方案可能会错误地尝试对索引进行操作，而不考虑奇偶性`1`字符串中的 s。 

## 方法

 暴力方法将递归或迭代地模拟每个可能的索引上的操作，直到字符串变为全零或无法进行进一步的移动。 这适用于非常小的字符串，但序列的数量是`O(n!)`在最坏的情况下，这对于`n`最多200,000。 

最佳解决方案的关键洞察来自于观察单个操作的效果。 选择索引`i`翻转所有位，除了`s[i]`。 如果我们考虑总数`1`字符串中的 s 表示为`count1`，然后对索引进行一次操作后`i`，数量`1`s 变为`n - count1 - (s[i] == '1') + (s[i] == '0')`，这简化为`n - count1 - 1 + 1`如果`s[i] == '1'`或者`n - count1`如果`s[i] == '0'`。 这告诉我们，只有在以下情况下该操作才能工作：`1`s 匹配某些奇偶校验条件。 实际中，可以通过计数来确定解`1`s。 如果全部都已为零，则无需进行任何操作。 否则，如果`count1`等于`n`或者是奇数，总是可以选择的索引`0`或`1`s 分别达到全零。 否则，如果`count1`等于`n/2`甚至，这是不可能的，因为每个操作都会翻转偶数位，从而保留奇偶校验不匹配。 

有了这种洞察力，我们只需要根据多数位（或者是`1`或`0`s)，并且可以通过字符串的单次传递来构建解决方案。

 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取字符串并统计其个数`1`s，我们称之为`count1`。 让`n`是字符串的长度。 
2.如果`count1`是`0`，字符串已经全为零。 输出`0`操作和空索引列表。 
3.如果`count1`是`n`，不可能将所有位翻转为零，因为每个操作都会翻转除一位之外的所有位。 输出`-1`。 
4. 如果`count1`是奇数，我们可以选择该位所在的所有索引`1`。 对这些索引执行操作将翻转其他位并最终产生全零。 
5.如果`count1`是偶数但不等于`0`或者`n`，选择该位所在的所有索引`0`。 翻转这些索引会将字符串转换为全零。 
6. 输出所选索引的数量和索引列表。 只要每个索引最多使用一次，任何索引顺序都可以。 

为什么有效：每个操作都会翻转除选定的一位之外的每一位。 通过根据平价选择指数`1`s，如果每个位开始为，我们确保每个位都被翻转奇数次`1`，将其转换为`0`，如果它开始为偶数次`0`，保持不变。 这个不变量保证在所有操作之后，字符串变为全零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        count1 = s.count('1')
        
        if count1 == 0:
            print(0)
            continue
        if count1 == n:
            print(-1)
            continue
        
        if count1 % 2 == 1:
            indices = [i+1 for i, ch in enumerate(s) if ch == '1']
        else:
            indices = [i+1 for i, ch in enumerate(s) if ch == '0']
        
        print(len(indices))
        print(' '.join(map(str, indices)))

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量，然后独立处理每个字符串。 计数`1`s 是用内置的`count`功能。 首先处理已经全零或全一的字符串的边缘情况。 主要决定基于奇偶性`count1`，并且索引是使用基于 1 的索引的列表理解生成的。 一旦构建了索引列表，打印就变得很简单。

 ## 边缘情况

 对于一位字符串`1`，count1 为 1，为奇数。 选择索引 1 将翻转所有其他索引（无）并保持索引 1 不变，产生`0`。 为了`0`，无需任何操作。 对于交替位`1010`，count1 = 2（偶数），所以我们选择的索引`0`s → 位置 2 和 4。翻转它们会将所有内容转换为`0`s。 该算法处理精确的奇偶校验要求，并确保没有索引被多次使用。
