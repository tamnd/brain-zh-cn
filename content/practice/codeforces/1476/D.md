 ## 解决方案
 ## 问题理解

 我们给出了一系列编号从 0 到$n$，线性连接$n$道路。 每条路都有一个方向，要么向左（从城市$i$到$i-1$）或右（从$i-1$到$i$）。 旅行者希望从某个城市出发，游览尽可能多的不同城市。 The traveler can move along a road only in its current direction, and after each move, every road flips its direction. The task is to compute, for each city, the maximum number of distinct cities the traveler can reach if they start there.

 输入由多个测试用例组成。 对于每种情况，我们都会得到长度$n$和一个长度的字符串$n$代表道路的初始方向。 我们必须输出$n+1$整数，每个城市一个，表示从该城市出发可到达的不同城市的最大数量。 

约束条件很强：$n$可以达到$3 \cdot 10^5$，以及总和$n$所有测试用例不超过$3 \cdot 10^5$。 这意味着任何明确迭代每个城市所有可能旅程的解决方案都是不可行的，因为暴力模拟需要$O(n^2)$每个测试用例或更多操作。 我们需要一个$O(n)$每个测试用例的解决方案。 

一个微妙的边缘情况是交替的道路字符串，例如`LRL`。 从城市 1 开始，旅行者可以直接前往城市 2，然后方向翻转，允许返回城市 1。粗心的实施可能会忘记翻转允许“来回”移动并低估可到达的城市。 

另一个边界是最小的情况，$n = 1$。 如果单路指向正确`R`，从城市 0 开始，您可以移动到城市 1，但从城市 1 开始，您无法移动。 正确的输出是`[2,1]`。 如果索引关闭，处理链的开头或结尾的边缘很容易出错。 

## 方法

 蛮力方法是模拟从每个城市出发的每个旅程。 在每一步中，我们都会检查当前城市的邻居并沿着有效的边缘移动，然后翻转所有方向。 这是正确的，但需要$O(n^2)$最坏情况下的操作。 和$n = 3 \cdot 10^5$，这大约导致$10^{10}$操作，太慢了。 

关键的见解来自于观察到一次移动后，道路方向会反转，因此一系列连续的移动`R`或`L`s 允许以可预测的模式移动。 我们可以预先计算一个人在不受干扰的情况下可以在每个方向上走多远，而不是进行模拟。 我们定义两个数组，`left`和`right`。`left[i]`是从城市开始向左连续移动的次数`i`在交替翻转下。 相似地，`right[i]`是向右连续移动的次数。 

这将问题简化为从左到右扫描一次字符串，从右到左扫描一次字符串，计算连续的可达城市。 每个城市的最大行程为`left[i] + 1 + right[i]`。 这给出了线性$O(n)$解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 预计算左/右| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组`left`和`right`大小的`n+1`带零。 这些将存储每个城市左侧和右侧可到达的最大连续城市。 
2. 计算`right`从左到右扫描排列。 对于每个索引$i$从 0 到$n-1$，如果$i$第 条路指向右侧`R`， 放`right[i+1] = right[i] + 1`。 否则，重置`right[i+1] = 0`。 这说明了从城市搬来的情况$i$到$i+1$。 
3. 计算`left`从右向左扫描排列。 对于每个索引$i$从$n$降至 1，如果$i-1$还剩下第 - 个路点`L`， 放`left[i-1] = left[i] + 1`。 否则，重置`left[i-1] = 0`。 这捕捉到了城市的移动$i$到$i-1$。 
4. 对于每个城市$i$从 0 到$n$，可到达的不同城市的最大数量为`left[i] + 1 + right[i]`。 这`+1`占起始城市本身。 
5. 打印每个测试用例的计算值。 

为什么它有效：`left`和`right`数组捕获每个方向上的最大连续序列。 由于道路在每次移动后都会翻转，因此交替模式保证了连续的相同移动，因此计算不间断的序列可以给出可到达的不同城市的确切数量。 求和`left`,`right`，起始城市确保每个访问过的城市都被精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        left = [0] * (n+1)
        right = [0] * (n+1)

        for i in range(n):
            if s[i] == 'R':
                right[i+1] = right[i] + 1
            else:
                right[i+1] = 0

        for i in range(n-1, -1, -1):
            if s[i] == 'L':
                left[i] = left[i+1] + 1
            else:
                left[i] = 0

        result = [str(left[i] + 1 + right[i]) for i in range(n+1)]
        print(" ".join(result))

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量。 对于每种情况，它都会初始化数组以预先计算最大左右范围。 使用适当的索引仔细地进行扫描，以避免差一错误。 最后，结果被格式化为字符串并打印。 使用快速 I/O 可确保解决方案在大输入的时间限制内运行。
