 ## 解决方案
 ## 问题理解

 爱丽丝和鲍勃玩一个交替选择的游戏`n`轮流。 在每一回合中，爱丽丝都会选择一个介于`0`和`k`。 然后，鲍勃决定是否从总分中添加或减去该数字，但限制条件是他必须至少添加`m`整个游戏的次数。 最终得分是鲍勃签名贡献的总和。 Alice 想要最大化最终得分，Bob 想要最小化最终得分，并且两者都发挥最佳效果。 

输入给出`t`独立的测试用例。 每个案例由三个整数组成：`n`，总匝数；`m`，Bob 必须进行的最少添加次数； 和`k`，Alice 可以选择的最大数量。 输出是最终分数模`10^9 + 7`当双方球员都打出最佳状态后。 

约束条件允许`n`最多`10^6`和`t`最多`10^5`，但总和`n`跨测试用例不超过`10^6`。 这意味着任何解决方案都必须在每个测试用例的大致线性时间或更好的时间内运行，因为嵌套循环`n`会太慢。 需要进行模运算，因为分数可能会变得非常大。 

边缘情况出现时`m = n`或者`k = 0`。 什么时候`m = n`，Bob 没有做减法的灵活性，所以 Alice 可以安全地每轮挑选最大的数字。 什么时候`k = 0`，爱丽丝选择的每个数字都是零，因此无论鲍勃如何选择，分数都为零。 粗心的实现可能无法正确处理这些边界，或者可能错误地计算模数分数`10^9 + 7`。 

## 方法

 天真的方法是模拟每个回合，跟踪鲍勃的剩余义务并尝试爱丽丝可以选择的所有可能的数字。 理论上，Alice 会考虑 0 到 0 之间的所有实数`k`，鲍勃会考虑加法或减法，确保至少`m`补充。 分行数量呈指数级增长`n`，即使对于小数据，暴力破解也是不可能的`n`。 

关键的见解是认识最佳游戏的结构。 Alice总是会选择尽可能大的数字，`k`，因为鲍勃不能否定所有这些，如果`m > 0`。 鲍勃的最佳策略取决于所需添加量与总匝数的比率。 如果他必须添加大多数回合（`m`附近`n`），他无法减去足够的量来显着降低分数。 最佳最终得分可以从组合模式中得出，其中鲍勃均匀地分散他的减法，而爱丽丝则在不可避免的加法回合中最大化她的收益。 

从数学上讲，该解决方案简化为计算代表最佳策略下预期最终得分的分数。 使用模运算，该分数可以表示为`p * q^{-1} mod 10^9 + 7`。 该公式涉及 2 的幂，因为每个可选的减法实际上将该回合的剩余影响减半。

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`n`,`m`,`k`。 
3. 计算`free_turns = n - m`，代表鲍勃可以自由选择减去的圈数。 
4.如果`free_turns == 0`，鲍勃必须每回合添加。 最后的成绩简直就是`n * k % MOD`。 
5. 否则，最佳分数由以下公式得出：`score = k * (2^free_turns - 1) / 2^free_turns * n / free_turns`。 

推导认为每个自由回合递归地将影响减半。 
6. 执行模运算以避免精度问题：

 - 计算`2^free_turns mod MOD`。 
- 计算发生除法的模逆。 
7. 打印最终得分模数`10^9 + 7`。 

为什么它有效：爱丽丝在每一回合都最大化她的选择，而鲍勃在允许的情况下最佳地减去。 剩下的强制加法为爱丽丝提供了总分的保证部分。 递归减半解释了鲍勃的策略减法。 模逆可以正确处理模算术下的分数结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a, mod):
    return pow(a, mod - 2, mod)

t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    free = n - m
    if free == 0:
        print(n * k % MOD)
    else:
        pow2 = pow(2, free, MOD)
        num = (pow2 - 1) % MOD
        score = k * num % MOD
        score = score * modinv(pow2, MOD) % MOD
        score = (score + 1) * m % MOD
        print(score)
```该解决方案首先处理鲍勃没有自由的小情况。 对于非平凡的情况，它计算`2^free_turns`对 Bob 的可选减法的效果进行建模。 减一并除以`2^free_turns`捕获 Alice 可以保证的预期最大影响力。 乘以`m`解释强制加法轮次。 使用`modinv`确保模数下的除法是正确的。
