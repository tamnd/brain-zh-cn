 ## 解决方案
 ## 问题理解

 我们在平面上有几个圆圈。 每个圆都有固定的圆心和半径，我们可以通过一个非负因子缩放所有半径$k$。 缩放后，每个圆都变成同心同半径的圆盘$k \cdot r_i$。 

然后我们询问是否存在一条与每个圆盘相交的直线。 这里的交集意味着直线要么穿过圆盘，要么与圆盘相切。 如果$k = 0$，所有圆都变成点，因此直线必须经过每个中心。 

任务是找到最小的$k$使得至少一条线可以同时与所有缩放的圆盘相交。 

关键的几何约束是，当且仅当从圆盘中心到直线的垂直距离至多为其半径时，直线与圆盘相交。 因此，对于固定线，每个圆对其中心距线的允许距离施加上限。 

和$n$直到大约 2000 年，如果仔细完成，对由圆对或三重圆确定的所有直线进行简单检查已经处于可行性边缘，但对任意直线进行直接几何搜索是不可能的。 约束的结构迫使我们将问题转化为仅依赖于成对关系的问题。 

当所有中心都相同时，会出现微妙的边缘情况。 在这种情况下，任何线路都适用$k = 0$，因为每个圆都会折叠到同一位置的一点。 假设成对几何的粗心解决方案可能仍然有效，但是除以表达式之类的实现$r_i + r_j$必须避免下游步骤中的零行为或退化行为。 

另一种边缘情况是所有半径都相等。 答案不一定为零，因为即使具有相同的缩放比例，一条线仍然必须在所有中心的固定距离内通过，这成为点集的纯宽度问题。 

## 方法

 蛮力视角从定义开始。 我们尝试猜测一条线，然后计算最小值$k$该行所需的，然后最小化所有行。 对于固定线路$L$, 每个圆$i$贡献了一个约束$k \ge \frac{d_i}{r_i}$， 在哪里$d_i$是从中心到线的距离。 所以最好的$k$因为该线是这些比率的最大值。 困难在于行的空间是连续的，甚至限制到具有组合意义的候选者留下$O(n^2)$或者更多的可能性。 

关键的观察是我们可以通过其法线方向参数化一条线。 固定单位方向$n$，并将所有点投影到该轴上。 然后通过沿该方向的移动来确定该线，并且可行性降低为区间相交条件。 这会将几何形状转换为每个方向的一维优化问题。 

对于固定方向$n$, 每个点$p_i$投影为标量$t_i = p_i \cdot n$。 一条正交线$n$对应于选择班次$c$，可行性成为一组形式的约束$|t_i + c| \le k r_i$。 每个点贡献一个有效区间$c$，并且所有区间必须相交。 

这将问题转化为对成对差异的约束：$$|t_i - t_j| \le k (r_i + r_j)$$所以对于固定方向，$$k(n) = \max_{i,j} \frac{|(p_i - p_j)\cdot n|}{r_i + r_j}.$$现在定义向量$$u_{ij} = \frac{p_i - p_j}{r_i + r_j}.$$那么表达式就变成了$$k(n) = \max_{i,j} |u_{ij} \cdot n|.$$因此，我们现在不再推理圆，而是推理一组点$u_{ij}$在飞机上。 我们要选择一个方向$n$最小化该集合的最大投影。 从几何角度来说，这正是旋转下点集的最小宽度。 

剩下的问题是$u_{ij}$有$O(n^2)$元素，但是$n$足够小，构造所有对都是可以接受的。 一旦建立了集合，问题就变成了经典的凸包宽度问题，可以用旋转卡尺解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解线路| 指数/无穷 | O(1) | O(1) | 太慢了|
 | 成对减速+凸包+旋转卡尺| O(n^2 log n) | O(n^2 log n) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 构造所有成对向量$u_{ij} = \frac{(x_i - x_j, y_i - y_j)}{r_i + r_j}$为所有人$i < j$，并且还隐式或显式地包括对称负数。 此步骤将圆约束转换为单个几何点集。 
2. 对待所有$u_{ij}$作为平面上的点。 目标是找到一个最小化该集合上的最大绝对点积的方向。 
3. 计算所有这些点的凸包。 严格位于船体内部的点永远不会影响极值投影，因此可以将它们丢弃而不改变答案。 
4. 在凸包上使用旋转卡尺来计算其在所有方向上的最小宽度。 对于船体的每条边，将其方向视为候选法线方向并计算支撑线之间的距离。 
5. 获得的最小宽度是投影的最小可能范围。 由于该集合是对称的（因为交换$i$和$j$求反向量），最大绝对投影等于该宽度的一半。 
6. 返回$k = \frac{\text{minimum width}}{2}$。 

这种方法起作用的核心原因是，任何固定方向的最坏约束总是由​​一对点实现，并且一旦通过$r_i + r_j$，这些成对约束的行为类似于有限平面点集的线性投影。 最佳方向必须与该组凸包的支撑方向对齐，因此没有任何内部配置可以比凸包边缘定义更好的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

def width(points):
    n = len(points)
    if n <= 1:
        return 0.0

    j = 1
    best = float("inf")

    for i in range(n):
        ni = (points[(i + 1) % n][0] - points[i][0],
              points[(i + 1) % n][1] - points[i][1])

        while True:
            k1 = abs(ni[0] * (points[(j + 1) % n][0] - points[i][0]) +
                     ni[1] * (points[(j + 1) % n][1] - points[i][1]))
            k2 = abs(ni[0] * (points[j][0] - points[i][0]) +
                     ni[1] * (points[j][1] - points[i][1]))
            if k1 > k2:
                j = (j + 1) % n
            else:
                break

        cur = abs(ni[0] * (points[j][0] - points[i][0]) +
                  ni[1] * (points[j][1] - points[i][1])) / (ni[0]**2 + ni[1]**2)
        best = min(best, cur)

    return best * 2

n = int(input())
circles = [tuple(map(int, input().split())) for _ in range(n)]

pts = []
for i in range(n):
    x1, y1, r1 = circles[i]
    for j in range(i + 1, n):
        x2, y2, r2 = circles[j]
        denom = r1 + r2
        dx = (x1 - x2) / denom
        dy = (y1 - y2) / denom
        pts.append((dx, dy))

hull = convex_hull(pts)
ans = width(hull)
print(ans)
```构建阶段构建所有归一化差异向量。 凸包消除了所有非极端对相互作用，只留下可以定义最大投影的候选对。 然后，旋转卡尺步骤找到该船体在所有方向上的最小可能宽度。 

最终的乘法和除法逻辑直接来自对称性论证：由于每个向量差都以其负数出现，因此宽度等于最大绝对投影的两倍。

 ### 示例 1

 考虑三个具有小整数坐标的圆，以便容易看到成对向量。 假设两个点在特定方向上产生主导归一化差异。 该算法首先构建所有成对向量，然后通过凸包丢弃内部向量。 

| 步骤| 状态|
 | --- | --- |
 | 向量对| 所有标准化差异$u_{ij}$|
 | 凸包| 只剩下极端的方向向量 |
 | 卡尺| 测试每个船体边缘方向 |
 | 回答 | 最小半角 |

 这表明内部对关系永远不会影响最终约束，即使它们存在于原始公式中。 

### 示例 2

 如果所有圆的半径相同但分散在一条线上，则成对归一化会减少为缩放坐标差，并且船体会变成类似一维的细长形状。 

| 步骤| 状态|
 | --- | --- |
 | 向量对| 共线集 |
 | 凸包| 两个端点占主导地位 |
 | 卡尺| 沿垂直方向计算的宽度 |
 | 回答 | 受极端分离控制|

 这表明当几何退化时，解决方案自然会减少到经典的宽度最小化。

 ## 边缘情况

 一种重要的边缘情况是所有半径都相同且所有中心位于一条直线上。 在这种情况下，每个归一化向量都位于变换空间中的一条线上，并且凸包退化为一个线段。 旋转卡尺仍然有效，但只有两个相反的方向重要，答案纯粹来自极端的一对。 

当多个圆共享相同的中心但不同的半径时，会出现另一种边缘情况。 然后许多成对向量变为零，并且它们不会影响船体。 正确的实现必须避免除法问题并确保零向量不会扭曲外壳计算。 

最后一种情况是，一个圆以非常大的半径支配所有其他圆。 然后，涉及该圆的所有归一化差异都变得非常小，并且船体相应地缩小。 该算法自然地处理这个问题，因为缩放已经融入到成对标准化步骤中。
