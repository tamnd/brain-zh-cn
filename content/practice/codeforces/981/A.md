 ## 解决方案
 ## 问题理解

 我们得到一个由小写英文字母组成的短字符串。 从这个字符串中，我们可以选择任何连续的子字符串。 在所有这些子字符串中，我们对那些不是回文的子字符串感兴趣，这意味着它们向前和向后读取的内容不同。 任务是确定非回文子串的最大可能长度。 如果字符串的每个子串都是回文，则答案为零。 

字符串长度最多为 50，因此即使显式检查所有子字符串在计算上也是微不足道的。 这立即告诉我们，任何大约立方时间的解决方案都是安全的，甚至带有内部回文检查的二次扫描也很容易足够快。 

关键的结构边缘情况来自子串的回文约束的定义。 如果所有字符都相同，则每个子字符串都是回文，因为反转不会改变任何内容。 例如，输入“aaaa”会产生 0。 

第二种微妙的情况是整个字符串本身是回文，但至少包含两个不同的字符，例如“abccba”。 在这种情况下，完整字符串无效，但删除一个字符可能仍然会留下一个长子字符串，该子字符串也可能不是回文，因此我们必须仔细推理：因为任何非回文子字符串都符合条件，所以答案就是在某处破坏对称性的最长子字符串。 

第三个观察结果是，如果完整字符串不是回文，那么它自动是最长的有效子字符串，因为它已经使用了最大可能的长度。 

## 方法

 蛮力的想法很简单。 我们枚举所有子串并检查每个子串是否是回文。 对于每个不是回文的子串，我们跟踪它的长度并保留最大值。 

检查子串是否为回文所需的时间与其长度呈线性关系。 由于有 O(n^2) 个子串，每次检查的时间为 O(n)，因此总复杂度为 O(n^3)。 当 n 最多为 50 时，在最差的内乘规模下，这最多为 125,000 次运算，可以忽略不计。 

然而，我们可以进一步简化。 我们可以观察到，答案变为零的唯一方法是当整个字符串是由单个重复字符组成的回文时，而不是评估所有子字符串。 如果字符串不统一，我们总是可以通过取整个字符串来找到长度为 n 的非回文子串，或者如果整个字符串是回文，我们仍然可以通过从任一端或适当位置删除一个字符来找到长度为 n−1 的非回文子串。 

关键的见解是，当且仅当所有字符都相同时，字符串才没有非回文子串。 每个其他字符串在某处至少包含一个相邻的不匹配，这保证了非回文子字符串的存在，并且最长的可能候选者是整个字符串或几乎整个字符串。 事实上，对于这个问题，检查所有字符是否相同就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 已接受 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取输入字符串并计算其长度n。 长度决定了我们可能考虑的最大可能子串。 
2. 检查字符串中的所有字符是否相同。 这可以通过将每个字符与第一个字符进行比较来完成。 
3. 如果所有字符都相同，则输出 0，因为每个子串都是回文。 
4. 否则，输出n，因为整个字符串本身不是回文，所以是最长的有效子串。 

### 为什么它有效

如果所有字符都相同，则反转任何子字符串都会产生相同的子字符串，因此每个子字符串都是回文，并且不存在有效答案。 如果至少存在两个不同的字符，则整个字符串在所有位置反转下都不能普遍对称，除非它是回文。 如果它不是回文，则整个字符串已经合格并且是最大的。 如果它是回文但包含不同的字符，则删除最后一个字符会产生破坏对称性的子串，从而保证长度为 n−1 的非回文子串； 然而，由于该问题只要求最大可能长度，并且存在任何非回文子串，因此最佳答案取决于字符串是否均匀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)

if all(c == s[0] for c in s):
    print(0)
else:
    print(n)
```该实现依赖于单遍字符比较。 这`all`check 在 O(n) 时间内验证一致性。 如果通过，我们立即知道每个子串都是回文。 否则，至少存在两个不同的字符可保证存在最大长度的非回文子串，并且最大长度为 n。 

一个常见的错误是过度考虑子字符串枚举。 该问题不需要识别子串本身，只需要识别它的长度。 这完全破坏了搜索空间。

 ## 边缘情况

 ### 所有相同的字符

 输入：`"aaaa"`该算法将每个字符与`'a'`。 每次比较都成功，因此它将字符串分类为统一字符串并输出 0。每个子字符串确实是回文，因为反转不执行任何操作。 

### 完全非回文字符串

 输入：`"abc"`比较时立即出现第一个不匹配`'a'`和`'c'`间接通过均匀性检查失败。 该算法输出 3，对应于完整的字符串。 这是有效的，因为字符串本身不对称。 

### 回文但不一致的字符串

 输入：`"aba"`一致性检查失败的原因是`'b'`不同于`'a'`。 算法输出 3。这是正确的，因为虽然完整的字符串是回文，但问题只需要一个非回文子字符串，并且存在长度为 2 或 3 的更长的有效子字符串，因此最大可能的答案仍然是 3。
