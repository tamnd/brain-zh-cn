 ## 解决方案
 ## 问题理解

 我们得到了固定数量的糖果，学校分为两组学生：男孩和女孩。 校长必须为每个男孩选择正整数数量的糖果，为每个女孩选择不同的正整数数量的糖果。 每个男孩收到的糖果数量完全相同，每个女孩收到的糖果数量也完全相同，但每个女孩的数量必须严格大于每个男孩的数量。 

因此，分发的糖果总数完全由两个整数决定，例如$x$对于男孩和$y$对于女孩来说，有限制$x \ge 1$,$y \ge 1$， 和$x < y$。 总共使用的是$a \cdot x + b \cdot y$。 我们想选择这样的$x, y$最大化分发糖果的数量而不超过$n$。 输出是未使用的糖果数量，即$n - \max(a x + b y)$。 

限制很小：$n \le 1000$,$a, b \le 100$。 这立即排除了小二次甚至三次搜索之外的任何内容，但也暗示了一个更强的属性：最优的搜索空间$x, y$如果结构正确的话，它足够小，可以用暴力破解。 

一个关键的边缘情况是当约束$x < y$变得紧张。 例如，如果$x = y$，即使使用很多糖果，配置也无效。 另一个微妙的点是，至少保证可行性$x = 1$和$y = 2$，因此总是至少有一个有效的分配。 

## 方法

 解决问题的直接方法是尝试所有可能的值$x$和$y$。 由于两者都是正整数并且必须满足$x < y$，我们可以迭代所有$x$从 1 到$n$，并且对于每个$x$, 迭代所有$y$从$x+1$到$n$。 对于每一对，我们计算$a x + b y$并跟踪最大不超过$n$。 

这种暴力破解是正确的，因为每个有效的配置都被显式检查。 然而，它可能会做最多$O(n^2)$检查，在最坏的情况下大约需要一百万次操作。 虽然有点边界，但对于 Python 来说仍然可以接受，但考虑到结构，这是不必要的。 

关键的简化是对于任何固定的$x$，最优的$y$只是大于的最大整数$x$这样$a x + b y \le n$。 自从增加$y$总是会增加糖果总量，一旦满足可行性，就没有理由考虑较小的值。 因此，无需扫描所有$y$，我们可以直接用算术计算它，将搜索减少到单个循环$x$。 这将问题从二次型转化为线性型。

 ## 算法演练

 ## 算法演练

 1.修复了一些糖果的数量$x$分配给每个男孩，从 1 开始向上。 每个这样的选择都定义了一个线性约束，即可以为女孩保留多少糖果。 我们必须确保至少一个有效的$y > x$存在。 
2.对于固定的$x$，计算给男孩糖果后剩余的预算：$rem = n - a \cdot x$。 如果$rem \le 0$，那么女孩和更大的人就没有剩余的糖果了$x$只会让情况变得更糟，所以我们可以尽早停止。 
3. 给定剩余的糖果，我们想要尽可能大的糖果$y$这样$b \cdot y \le rem$和$y > x$。 最好的候选人是$y = \left\lfloor \frac{rem}{b} \right\rfloor$，但仍必须满足严格的不平等约束。 
4. 如果$\left\lfloor \frac{rem}{b} \right\rfloor \le x$，那么这个$x$无法产生有效的分配，因为任何有效的$y$必须严格大于$x$。 我们跳过这个案例。 
5. 否则，我们采取$y = \left\lfloor \frac{rem}{b} \right\rfloor$并计算已使用的糖果总量$used = a \cdot x + b \cdot y$。 我们跟踪最大值$used$总体而言有效$x$。 
6. 迭代完所有之后$x$，答案是$n - \max(used)$。 

### 为什么它有效

 对于任何固定的$x$，女孩的贡献是单调的$y$，所以最好的选择总是在最大可行的范围内$y$。 唯一的非单调约束是$y > x$，这为每个创建一个阈值$x$。 由于除此排序条件外，这两个约束都是线性且独立的，因此最优解必须位于这些边界点之一。 这确保枚举所有$x$并贪婪地最大化$y$对于每个$x$探索可以出现最佳结果的所有候选者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())

    best = 0

    for x in range(1, n + 1):
        rem = n - a * x
        if rem <= 0:
            break

        y = rem // b
        if y <= x:
            continue

        used = a * x + b * y
        if used > best:
            best = used

    print(n - best)

if __name__ == "__main__":
    solve()
```代码直接实现了先固定男生分配，然后尽可能提高女生分配的想法。 当男孩单独超出预算时，循环会提前停止，从而防止不必要的迭代。 整数除法`rem // b`是将内部搜索转变为关键的一步$y$进入常数时间。 条件`y <= x`强制执行严格的不平等约束，如果过于机械地翻译数学，这一点很容易被忽视。

 ## 边缘情况

 一个重要的边缘情况是当$y = \lfloor rem / b \rfloor$存在但不严格大于$x$。 例如，如果$x$增长速度快于剩余预算允许的速度$y$，即使两个部分单独看起来可行，配置也会变得无效。 条件`y <= x`明确地过滤掉这一点，防止非法对贡献最大。 

另一种边缘情况发生在$x$足够大$n - a x$变为非正值。 在这种情况下，没有有效的$y$对于任何更大的都存在$x$，所以早断是正确的。 循环终止是安全的，因为剩余预算随着$x$，确保未来的迭代无法恢复可行性。
