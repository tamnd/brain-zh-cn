 ## 解决方案
 ## 问题理解

 我们得到了一系列椰子堆，其中每堆都有一些整数大小。 我们可以选择一个正整数基值$x$，然后我们只从那些尺寸恰好为正幂的椰子堆中收集椰子$x$，表示形式的值$x^1, x^2, x^3, \dots$。 每个符合条件的堆都将其全部价值贡献给我们的总价值，而所有其他堆都将被忽略。 目标是选择$x$使收集的椰子总量最大化。 

所以任务不是任意选择子集，而是选择一个结构：一个基础$x$，然后取出数组中位于该底生成的几何序列中的所有数字。 

输入大小最多为 200000 个元素，每个值最多为 10^9。 这立即排除了尝试所有可能基础的任何解决方案$x$并天真地检查所有权力。 对每个候选库进行直接检查会太慢，特别是因为每次检查都涉及对整个数组进行重复求幂或散列成员资格查询。 

当值重复或许多数字为 1 时，就会出现一个关键的微妙之处。$1 = x^k$仅当$x = 1$，数字 1 的行为与其他值不同。 另一个边缘情况是当$x$本身很大：大的底座产生非常短的动力链，通常长度为 1 或 2，这仍然必须考虑。 

一个天真的错误是假设选择$x$等于数组值之一总是会产生一个好的答案。 这会失败，因为最好的碱基甚至可能不会出现在数组中。 例如，如果数组包含 2、4、8、16 等数字，则最佳选择是$x = 2$，存在，但在其他情况下，如 3、9、27、40，最好$x$根据结构，可能是 3 或 40，并且 40 不属于任何链。 

## 方法

 蛮力方法是尝试每个可能的整数$x$从 1 到数组中的最大值。 对于每个$x$，我们会反复计算$x, x^2, x^3, \dots$当该值在范围内时，如果这些值存在于数组的频率图中，则对贡献求和。 每个链的大小都是对数的，因为价值增长很快，但候选者的数量$x$在最坏情况范围内仍然是 10^9 的数量级，这是不可能的。 

即使将候选值限制为数组中出现的值也不能完全解决问题，因为最佳基数可能是一个本身不存在但其幂与许多数组元素一致的数字。 然而，我们可以改进这个想法：每个有效的链都必须由某个起始基数决定$x$，并且数组中的每个数字最多属于每个选定的一个指数链$x$。 权力结构建议扭转观点：而不是尝试所有$x$，我们可以尝试识别潜在的$x$通过观察数字之间的关系。 

关键的观察是，如果一个数字$a$等于$x^k$，那么它的质因数分解必须与完美幂一致。 这意味着可以出现在有效链中的所有数字共享一个共同的基本结构：它们都是同一整数的幂。 因此，问题简化为通过最小根表示对数字进行分组。 对于每个数字$a$，我们可以计算它的最小底数$b$这样$a = b^k$，然后同一链中的所有数字对应于该相同的幂$b$。 最佳答案是通过对每个此类重建链上的值求和来获得的。 

主要困难是正确识别每个数字的规范基数。 对于每个$a$，我们将其分解为整数幂并提取其最小根。 然后我们沿着这些基地产生的链汇总贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解 x | O(N·最大A) | O(1) | O(1) | 太慢了 |
 | 因式分解 + 按根基分组 | O(N √A) | O(N √A) | O(N) | 已接受 |

 ## 算法演练

 我们将每个数字转换为其规范表示，然后将属于同一动力链的值分组。 

1. 对于每个数字$a_i$，计算其最小根底$b_i$。 这意味着找到最小的整数$b$这样$a_i = b^k$对于某个整数$k \ge 1$。 此步骤确保所有完美幂都归一化为相同的底层生成器。 
2. 如果一个数不是任何较小整数的完美幂，那么它的基数就是它本身，因此它形成长度为 1 的平凡链。这可以处理不是完美幂的素数和一般合数。 
3. 维护基地地图$b$所有原始值的总和$a_i$属于其链。 我们累积实际的椰子，而不仅仅是计数，因为每个有效的椰子堆都贡献了其全部大小。 
4. 迭代所有值并更新此映射。 每个数字都恰好构成一条链，因为最小根表示是唯一的。 
5. 处理完所有值后，答案是所有链和中的最大值。 这对应于选择最佳基地$x$，因为每个组代表该形式的所有值$x^k$。 

为什么它有效：每个有效的选择都对应于某个基础$x$。 包含的任何数字都必须是$x$，所以它的最小根也必须等于$x$。 因此，在这个规范的基本映射下，所有选定的数字都会折叠成一个组。 由于每个数字恰好映射到一个碱基，因此我们不会错过任何有效的分组，并且最大化组涵盖了所有选择$x$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def get_base(x):
    # find minimal base b such that x = b^k
    # try all powers up to log2(x)
    best = x
    # try exponent from 2 upward
    for k in range(2, 32):
        b = int(round(x ** (1.0 / k)))
        if b <= 1:
            continue
        # verify exact power
        p = 1
        for _ in range(k):
            p *= b
            if p > x:
                break
        if p == x:
            best = min(best, b)
    return best

n = int(input())
a = list(map(int, input().split()))

from collections import defaultdict
mp = defaultdict(int)

for v in a:
    b = get_base(v)
    mp[b] += v

print(max(mp.values()))
```功能`get_base`计算其重复求幂产生给定数字的最小整数基数。 由于值的范围是 10^9，因此我们迭代最多 30 个可能的指数，因此任何有意义的幂分解都必须具有较小的指数。 

对于每个候选指数，我们使用整数根提取来近似基数，然后通过直接乘法进行验证以避免浮动精度误差。 一旦确定了基数，我们就将原始值累积到其组中。 

字典`mp`收集每个基地的椰子总数，最终答案是最大的总和。

 ## 边缘情况

 一个微妙的情况是数字为 1 时。对于输入：```
4
1 1 1 1
```每个值都映射到基数 1，因为$1 = 1^k$对于任何$k$。 该算法将它们全部分组到一个桶中并返回 4，这与选择匹配$x = 1$。 

另一种情况是完美幂和非幂的混合：```
3
8 9 10
```这里 8 映射到基数 2，9 映射到基数 3，10 映射到 10。每个都形成自己的组，最大单个值是 10。该算法正确地避免了尝试强制它们进入共享结构，因为不存在公共基数。
