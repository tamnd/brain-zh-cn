 ## 解决方案
 ## 问题理解

 我们得到三堆球，每堆都有不同的颜色。 在一步操作中，我们选择两个不同颜色的球，将两个球移除，然后用第三种颜色的单个球替换它们。 此操作改变了组成，但使总结构受到非常具体的交换规则的约束。 

目标是达到所有三种颜色的球数完全相同的配置。 我们可以执行任意数量的操作，包括零个操作，并且我们想知道这样的配置是否可以访问。 如果可以达到，我们还必须最大限度地减少所需的操作数量。 

输入由三个非负整数组成，描述三种颜色的初始计数。 输出要么是达到相等计数所需的最小操作数，要么是 -1（如果没有操作序列可以实现该状态）。 

约束达到 10^9，这会立即排除任何操作模拟。 每次移动都会改变状态，但由于球的总数可能非常大，即使是线性或贪婪的逐步过程也会太慢。 该解决方案必须仅依赖于系统的少量不变量。 

第一个微妙的问题是该操作不会保留球的总数。 每一步都会移除两个球并添加一个，因此总数正好减少一个。 这意味着最终状态与执行的移动次数紧密相关。 

另一个重要的边缘情况是初始配置已经平衡。 这种情况下，不需要进行任何运算，但答案仍必须与推导公式一致，而不是作为特殊情况单独处理。 

最后，有些配置即使数量很大，在结构上也是不可能实现平衡的。 例如，如果三个计数的奇偶校验未对齐，则任何操作序列都无法将它们同步为相等的值。 

## 方法

 暴力方法将模拟所有可能的操作。 从任何状态（a、b、c），我们可以尝试三种可能的合并和递归或 BFS 状态。 这正确地探索了所有可到达的配置，因为每个操作在状态图意义上都是可逆的。 然而，州的数量增长极其迅速。 由于每次移动都会使总和减一，因此搜索深度可以是 O(a + b + c)，最高可达 10^9，这使得这完全不可行。 

关键的观察是我们实际上不需要跟踪中间状态。 该系统具有很强的不变量，完全决定了可行性和最优性。 最重要的一个来自奇偶行为。 每个操作都会从两个计数中减去一，并将第三个计数加一，从而同时翻转所有三个值的奇偶校验。 这意味着平价的相对平等或不平等永远不会改变； 要么所有三个最初都是相同的奇偶校验，要么不是，并且这个条件是不可变的。 

一旦确定了可行性，第二个观察结果是每次操作都会将球的总数恰好减少一个。 如果我们最终处于所有计数都等于 x 的状态，则 3x 必须等于最终总数。 由于最终总数是初始总和减去操作数，因此操作数完全由所选的最终 x 决定。 

事实证明，如果奇偶性条件成立，则总数每次减一仍然与维持均衡的可能性一致，唯一剩下的约束是在最终状态下能被三整除。 这导致了最小运算的直接公式。

## 算法演练

 ### 1.检查奇偶校验一致性

 我们首先检查所有三个计数的奇偶性。 如果它们不全是偶数或全奇数，我们立即得出结论，不可能达到相等。 这是因为每次操作都会同时翻转所有三个奇偶校验，因此它们之间的关系永远不会改变。 

### 2. 计算球的总数

 我们计算 S = a + b + c。 该值跟踪在任何操作之前存在多少个球。 由于每个操作都会将 S 恰好减少 1，因此它完全决定了系统如何总体演化。 

### 3. 使用不变量确定可行性

 如果奇偶校验不对齐，我们返回 -1。 否则，我们继续前进，知道系统不会受到奇偶校验约束的阻碍，并且有可能达到对称配置。 

### 4. 推导最终的操作次数

 在最终状态下，所有三个计数必须相等，例如 x。 那么总数是3x。 由于每次操作总数都会减少 1，因此如果执行 k 次操作，我们有：

 S - k = 3x。 

重写得到 k = S - 3x。 

我们想要最小化 k，这相当于最大化 x。 在操作规则和奇偶校验约束下，最大可实现的对称状态对应于取x=floor(S/3)。 替换它给出最少的操作数。 

### 5.输出结果

 我们返回 k = S - 3 * Floor(S / 3)，简化为 S mod 3。 

### 为什么它有效

 该系统通过在坐标之间重新分配质量同时稳步减少总量来发展。 奇偶校验条件是三个坐标是否可以相同的唯一结构限制，因为每个操作都会保留所有三个坐标的奇偶校验是否相等。 一旦满足该约束，唯一剩下的自由度就是执行了多少总归约，这直接决定了最终的相等值。 由于没有中间配置比奇偶校验施加更严格的约束，因此最佳值仅取决于总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

# parity check
if (a & 1) != (b & 1) or (b & 1) != (c & 1):
    print(-1)
else:
    print((a + b + c) % 3)
```实现直接反映了这两个不变量。 第一个条件强制所有奇偶校验都匹配，否则任何操作序列都无法对齐三个计数。 第二行计算总数并将其模三减少，一旦保证可行性，它就会编码所需操作的最小数量。 

一个常见的陷阱是试图模拟或贪婪地平衡桩。 这是不必要的，因为系统的可达集完全由奇偶校验和总归约确定。

 ## 边缘情况

 一种重要的边缘情况是所有三个值都已经相等。 例如，输入 (5, 5, 5) 具有匹配的奇偶校验，因此算法继续进行。 总和为 15，15 mod 3 为 0，正确地表明不需要进行任何操作。 

另一种情况是奇偶校验略有不同，例如 (2, 2, 3)。 该算法立即拒绝这一点，因为一个值具有不同的奇偶校验。 任何模拟操作的尝试都证实，每一步都保留“全部相同或不全部相同”的奇偶校验结构，因此不可能达到相等。 

第三种微妙的情况是大型对称输入，例如 (10^9, 10^9, 10^9)。 尽管数量级很大，但该算法仅依赖于奇偶校验和模运算，因此它可以处理这种情况，而不会出现溢出或性能问题。
