 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们首先计算其平均值，即总和除以元素数量。 该平均值不一定是整数，而是由全数组确定的固定有理值。 

任务是恰好删除两个不同的元素，以便当我们重新计算剩余元素的平均值时，它与原始平均值完全相同。 我们被要求计算有多少对指数产生了这个属性。 

关键限制是数组大小，最多可达 200,000。 任何直接检查所有对的解决方案都会考虑$\frac{n(n-1)}{2}$删除量，在最坏的情况下约为 200 亿次操作。 这远远超出了 Python 或 C++ 中两秒的时间。 这立即排除了任何二次方法。 

当所有元素都相同时，会出现一种微妙的边缘情况。 在这种情况下，删除任意两个元素可以轻松保留平均值，因为每个子集都具有相同的平均值。 如果尝试直接将平均值重新计算为浮点数，幼稚的实现可能仍然会遇到不必要的算术或风险精度问题。 

另一个重要的情况是平均值非整数。 粗心的解决方案可能会尝试在删除后比较浮点平均值。 这是不安全的，因为即使代数条件完全成立，精度错误也可能导致不正确的等式检查。 

## 方法

 暴力解决方案将迭代所有对$(i, j)$，删除这两个元素，重新计算剩余数组的总和，并检查平均值是否与原始数组匹配。 使用前缀和可以将剩余总和的计算优化为 O(1)，但我们仍然有 O(n^2) 对要测试，这导致大约$10^{10}$在最坏的情况下进行检查。 即使每次检查都使用恒定时间算术，这也太慢了。 

关键的观察结果来自于用代数重写条件。 设数组的总和为$S$，并令原始均值为$k = S / n$。 删除两个元素后$a_i$和$a_j$，新的总和变为$S - a_i - a_j$，新的元素数量为$n - 2$。 我们要求：$$\frac{S - a_i - a_j}{n - 2} = \frac{S}{n}$$交叉相乘完全避免了分数并揭示了对的线性约束。 这将问题从检查平均值转变为计算具有固定总和条件的对。 简化后，每个有效对必须满足：$$a_i + a_j = \frac{2S}{n}$$因此，整个任务简化为计算有多少对总和达到恒定目标值。 这是一个经典的频率计数问题，可以使用哈希图在线性时间内解决。 

我们计算每个值的频率，然后对于每个不同的值$x$，我们寻找它的补集$T - x$， 在哪里$T = 2S / n$。 必须小心避免重复计算并处理以下情况：$x = T - x$。

 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 频率哈希 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算总和$S$数组并导出目标总和$T = 2S / n$。 该值表示在平均条件的代数变换之后每个有效对必须相加的值。 
2.如果$2S$不能被整除$n$，立即停止并返回 0。在这种情况下，目标和不是整数，但所有数组元素都是整数，因此没有对可以完全满足条件。 
3. 构建所有数组值的频率图。 这使我们能够计算每个候选元素出现的次数，这对于有效计算有效对是必要的。 
4. 迭代每个不同的值$x$在频率图中。 对于每个这样的值，计算其补码$y = T - x$。 
5. 如果$x < y$，计算通过选择一次出现而形成的所有对$x$并且出现一次$y$。 这样的对的数量是$freq[x] \cdot freq[y]$。 排序约束避免了重复计算。 
6.如果$x = y$，计数完全在同一值组内形成的对。 这样的对的数量是$freq[x] \cdot (freq[x] - 1) / 2$。 
7. 将所有贡献相加并输出结果。 

### 为什么它有效

 从平均约束到固定和约束的转换是精确且可逆的。 每个有效的删除都必须保留平均值，代数表明这相当于要求删除的对具有精确的总和$T = 2S/n$。 基于频率的计数通过不同的补集或在单个值类中对每个无序对精确地枚举一次。 没有遗漏有效对，因为每对索引都由频率图中的一个值组合表示，并且没有包含无效对，因为所有计数的对都满足导出的等式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    s = sum(a)
    if (2 * s) % n != 0:
        print(0)
        return
    
    target = (2 * s) // n
    
    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1
    
    ans = 0
    for x in freq:
        y = target - x
        if y not in freq:
            continue
        if x < y:
            ans += freq[x] * freq[y]
        elif x == y:
            c = freq[x]
            ans += c * (c - 1) // 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先计算总和并检查整除性，以确保导出的目标对和是整数。 这完全避免了浮点比较。 频率字典跟踪每个值的出现次数，以便对计数变成组合计数而不是迭代计数。 

键上的循环仔细地强制执行排序`x < y`，这可以防止重复计算 (x, y) 和 (y, x) 这样的对。 相等情况使用标准组合公式从一组相同值中选择两个索引。

 ## 边缘情况

 对于全平等的情况，说$n = 6$数组是`[5, 5, 5, 5, 5, 5]`。 总和为 30，因此目标对和为 10。每对 5 都是有效的。 该算法构建频率`freq[5] = 6`并进入平等分支。 它计算$6 \cdot 5 / 2 = 15$，它与选择任意两个位置的方法数量相匹配。 

对于不存在整数目标的情况，例如`[1, 2, 3]`，总和为 6，所以$2S/n = 4$。 这是有效的，但没有对的总和等于 4。频率图检查对并没有找到任何对，结果为 0。如果总和产生了小数目标，则早期的整除性检查将正确返回 0，而无需扫描对。 

对于混合数组，例如`[1, 4, 7, 3, 5]`，该算法严格按照补码结构对值进行配对。 由于排序限制，每个有效对仅出现一次，从而防止过度计数，同时仍捕获所有有效删除。
