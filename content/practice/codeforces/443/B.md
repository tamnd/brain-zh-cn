 ## 解决方案
 ## 问题理解

 我们得到了 Kolya 最初拥有的一串小写英文字母，他可以在末尾附加最多 _k_ 个附加字符。 任务是确定结果字符串中串联重复的最大可能长度。 长度为 _2·n_ 的串联重复是一个连续的子串，其中前半部分恰好等于后半部分。 例如，在字符串“aabaab”中，子字符串“aabaab”是长度为6的串联重复，因为“aab”等于“aab”。 

输入约束很小：原始字符串的长度最多为 200，而我们可以附加的字符数最多为 200。这意味着最终字符串的最大长度可以达到 400。在这样的限制下，时间复杂度为 O(n²) 的解决方案是可行的，但 O(n³) 会有风险。 

当最佳串联重复延伸到我们可以自由附加的字符串部分时，就会出现不明显的边缘情况。 例如，如果初始字符串是“a”并且我们可以添加 2 个字符，则最佳串联重复可能是长度为 2 的“aaa”，即使最初只存在一个字符。 仅在原始字符串内部搜索的简单方法会错过这一点。 类似地，当字符串已经包含重复模式时，最佳串联重复可以部分重用原始字符串中的字符，部分依赖添加的字符，从而最大化重复长度。 

## 方法

 强力方法考虑原始字符串中每个可能的起始位置 _i_ 和每个可能的串联重复长度 _2·len_。 对于每个候选者，我们检查需要多少个额外字符才能完成重复。 如果需要的字符不超过_k_，我们记录总长度。 这是可行的，因为对于小字符串，我们实际上可以尝试每种可能性，但在最坏的情况下，大约有 200 个位置和 200 个潜在长度，导致 40,000 次迭代，每次可能扫描最多 200 个字符。 这给出了 O(n³) 操作，这可能会通过但并不优雅。 

关键的见解是我们不需要明确考虑每个附加字符。 只要原始字符串与自身匹配，串联重复就可以扩展，或者我们可以用添加的字符进行补充。 我们可以通过在字符串上滑动长度为 _len_ 的窗口并计算两半之间的不匹配来模拟这一点。 每个不匹配都可以通过附加一个字符来“修复”。 一旦所需的附加字符数超过_k_，我们就停止扩展该重复。 通过有效地迭代可能的长度和起始位置，我们减少了冗余检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 可以接受，但在上限可能会很慢 |
 | 优化滑动检查 | O(n²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`ans`为零，这将存储找到的最大串联重复长度。 
2. 迭代每个可能的起始索引`i`在原始字符串中。 这代表串联重复前半部分的开始。 
3. 对于每个`i`，迭代可能的长度`len`串联重复的前半部分。 最大`len`受到原始字符串长度加上我们可以添加的字符数的限制。 
4. 将前半部分的字符与后半部分的相应字符进行比较。 计算不匹配的数量，因为每个不匹配都需要一个附加字符。 
5. 当所需附加字符数超过时停止比较`k`。 记录总串联重复长度`2 * len`加上可以附加的任何额外匹配项。 
6. 更新`ans`如果此总长度大于当前最大值。 
7. 迭代完所有位置和长度后，`ans`保持可能的最大串联重复长度。 

正确性依赖于这样一个事实：对于每个起始位置和前半部分长度，我们将串联重复延伸到可用附加字符数量允许的范围内。 由于我们检查了所有可行的起始位置和长度，因此我们不能错过更长的重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
k = int(input())

n = len(s)
ans = 0

for i in range(n):
    for l in range(1, n + k + 1):
        mismatches = 0
        for j in range(l):
            if i + j >= n or i + j + l >= n:
                break
            if s[i + j] != s[i + j + l]:
                mismatches += 1
            if mismatches > k:
                break
        if mismatches <= k:
            total_len = min(2 * l, n - i + k)
            ans = max(ans, total_len)

print(ans)
```外循环枚举起始位置和前半部分长度。 内部循环对当前候选重复的不匹配进行计数。 条件`i + j >= n or i + j + l >= n`确保我们的索引不会超出原始字符串。 然后，我们计算可实现的总串联重复长度，其中可能包括原始字符串之外的附加附加字符。 更新中`ans`保证我们跟踪最大值。

    k = int(input())

                if i + j >= n or i + j + l >= n:

                ans = max(ans, total_len)
    return str(ans)

 ## 边缘情况

 对于 k=2 的单字符字符串“a”，算法考虑从索引 0 开始，l=1。 前半部分是“a”，后半部分是现有字符或附加字符。 两个附加字符允许形成长度为 3 的“aaa”。如果不匹配超过 k，则内部循环会正确中断。 对于具有重复字母的最大尺寸输入，该算法计算完整的可能扩展，产生等于原始加 k 的串联重复长度，从而确认边界和扩展逻辑的正确处理。
