 ## 问题理解

 任务是计算坐标平面上两点之间的直线距离。 输入描述两个点的坐标，每个点由其 x 坐标和 y 坐标表示。 输出是连接这两点的线段的长度。 

对于积分`(x1, y1)`和`(x2, y2)`，水平差为`x2 - x1`垂直差为`y2 - y1`。 这两个差形成直角三角形的边，因此所需的距离是斜边：$$\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$$约束很小，但它们仍然决定了正确的实现细节。 不需要任何搜索、排序或几何数据结构，因为答案是通过恒定数量的算术运算获得的。 主要关注的是数值精度，因为结果通常不是整数。 

边缘情况很简单，但如果公式实施不正确，很容易处理错误。 

对于两个相同的点：```
0 0
0 0
```答案是：```
0.0
```仅计算一个坐标差的解决方案也可以通过许多测试，但在一般输入上可能会失败。 

对于位于垂直线上的点：```
5 1
5 6
```答案是：```
5.0
```x 差值为零，但距离仍由 y 差值决定。 

对于对角线的点：```
0 0
3 4
```答案是：```
5.0
```粗心的实现会添加坐标差而不是使用欧几里德公式，从而输出`7`，这是曼哈顿距离而不是请求的距离。 

## 方法

 蛮力方法通常意味着尝试寻找某种模式或枚举可能性。 对于这个问题，这种本能是不必要的，因为两个给定点之间只有一个可能的距离。 任何枚举都只会重复几何公式已经直接求解的工作。 

数学观察是坐标差给出了直角三角形的边。 毕达哥拉斯定理将这两个独立的运动转换为对角线段的长度。 该问题从几何任务简化为评估固定公式。 

暴力的想法在这里没有意义，因为即使是单个不必要的循环也会增加复杂性，而不会提供新信息。 直接计算是常数时间，是预期的解决方案。

 ## 算法演练

 1.读取两点的坐标。 我们存储四个值，因为答案取决于相应坐标之间的差异。 
2. 使用以下公式计算水平位移`x2 - x1`和垂直位移使用`y2 - y1`。 符号并不重要，因为两个值都会平方。 
3. 将两个差值平方并相加。 这给出了线段长度的平方。 
4. 求总和的平方根。 结果值是点之间的欧几里德距离。 

原理：坐标差创建一个直角三角形，其中点之间的线段是斜边。 毕达哥拉斯定理指出，斜边的平方等于两条边的平方和。 由于两条腿正好是 x 和 y 差，因此计算值始终是所需的距离。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    x1, y1 = map(float, input().split())
    x2, y2 = map(float, input().split())

    dx = x2 - x1
    dy = y2 - y1

    ans = math.sqrt(dx * dx + dy * dy)

    print(ans)

if __name__ == "__main__":
    solve()
```程序首先读取两个点。 坐标存储为浮点值，因为最终距离可能包含小数部分。 

变量`dx`和`dy`表示由点组成的直角三角形的两条边。 对它们进行平方会消除任何负号，因此两点的顺序不会影响答案。 

表达式`math.sqrt(dx * dx + dy * dy)`直接遵循数学公式。 Python 浮点数足以满足此问题所需的精度。

 ## 边缘情况

 对于相同的点：```
0 0
0 0
```该算法计算`dx = 0`和`dy = 0`。 公式变为`sqrt(0 + 0)`，生产`0.0`。 不需要特殊处理，因为通用公式已经涵盖了这种情况。 

对于垂直线段：```
5 1
5 6
```该算法计算`dx = 0`和`dy = 5`。 距离的平方为`25`，所以答案是`sqrt(25) = 5.0`。 除以一个坐标差或假设两个坐标都发生变化的解决方案在这里将失败。 

对于对角线段：```
0 0
3 4
```该算法计算`dx = 3`和`dy = 4`。 距离的平方为`9 + 16 = 25`，给出答案`5.0`。 这证实了该解决方案使用欧几里德距离而不是简单地添加坐标变化。
