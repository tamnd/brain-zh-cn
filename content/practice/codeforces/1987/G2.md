 ## 解决方案
 ## 问题理解

 我们给出了从 1 到$n$和一串长度的指令$n$，其中每条指令是 L、R 或 ?。 排列中的每个位置都可以连接到其最接近的左侧 (L) 或右侧 (R) 的较大数字，并且 ? 允许我们选择任一方向。 目标是按照这些规则构造一个无向连通图，并找到该图的最大可能直径，如果无法形成连通图，则输出 -1。 

关键的挑战在于如何通过排列和指令确定边缘，以及如何选择？ 位置影响连通性。 一种幼稚的方法，尝试所有可能的选择？ 是不可行的，因为$n$可以达到 400,000 个，使组合数量呈指数级增长。 此外，总和$n$所有测试用例也可以达到 400,000 个，因此任何算法都必须接近线性$n$以适应 7 秒的时间限制。 

需要仔细处理的边缘情况包括创建断开组件的完全固定方向、最大数量位于端点的序列以及长的 ? 存在多种配置的字符。 例如，对于$p=[1,2]$和$s='LR'$，无法连接两个节点，因为 L 指向左侧，R 指向右侧，从而使它们处于孤立状态。 正确的输出是-1。 

## 方法

 蛮力方法为 ? 的每个选择组合构建图表。 对于每种配置，我们将通过从每个顶点执行 BFS 或对树使用两遍 BFS 来计算图的直径。 这是可行的，因为图始终是一棵树（每个节点恰好添加一条边），但它会失败，因为配置数量为$2^k$在哪里$k$是多少？ 字符，可以高达$n$。 评估所有配置需要按以下顺序进行操作$O(2^n \cdot n)$，这显然太慢了$n\sim 4 \cdot 10^5$。 

关键的见解是，排列定义的边创建了一个**单调链森林**，其中每个节点都连接到最近的较大邻居。 每个节点都指向由 L 或 R 定义的父节点。这些边的结构对应于基于排列构建的**笛卡尔树**：最大的元素成为根，递归地将相同的规则应用于左右子数组。 笛卡尔树使我们能够有效地推断连通性和距离：最大可能直径是根的左右子树的高度之和，可能通过 处的选择进行调整？ 职位。 

为了处理 ?，我们可以将其视为“我们可以选择最大化树深度的边”。 这将问题简化为笛卡尔树上的“分而治之”，其中在每个子树上，我们计算当边缘可以自由向左或向右移动时可获得的最大高度。 如果树完全构建，则可以保证连接性，但如果指令以某些节点无法附加到任何更高节点的方式强制边缘，则会出现断开的组件。 检测此类情况需要检查在给定固定 L 和 R 方向的情况下是否有任何子树保持隔离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 笛卡尔树 + DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 预计算每个索引$i$左边最近的较大邻居$l_i$和对的$r_i$使用单调堆栈。 此步骤以线性时间运行，因为每个元素最多被压入和弹出一次。 
2. 将L视为强制连接$l_i$和 R 作为强制连接$r_i$。 对于 ?，允许两种选择，有效地使孩子依附于提供更高深度的父母。 
3. 从排列构建笛卡尔树：当前子数组中最大的元素为根，递归构建左右子树。 这给出了任何有效图的底层连接性。 
4.定义DP函数`dfs(node)`返回以`node`以及该子树中可实现的最大直径。 对于叶子，高度为 1，直径为 0。 
5. 在DP中，对于带有?的节点，取左右子树之间的最大高度来计算潜在直径。 局部直径是该节点下两个最高子树的总和加 1（对于节点本身）。 向上传播最大直径。 
6. 如果任何子树无法根据固定的 L/R 边连接，则立即返回 -1。 否则，在根部完成 DP 后，返回计算出的直径。 

工作原理：笛卡尔树可确保每个节点正确连接到其最近的较大邻居。 通过递归地选择 ? 的高度最大化边，我们模拟了最大化树直径的配置。 由于每个节点仅贡献一条边，并且所有节点都包含在树中，因此连接不变量适用于有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        s = input().strip()

        # nearest greater to left
        l = [i for i in range(n)]
        stack = []
        for i in range(n):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            l[i] = stack[-1] if stack else i
            stack.append(i)

        # nearest greater to right
        r = [i for i in range(n)]
        stack = []
        for i in range(n-1, -1, -1):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            r[i] = stack[-1] if stack else i
            stack.append(i)

        children = [[] for _ in range(n)]
        root_candidates = set(range(n))
        parent = [-1]*n
        ok = True

        for i in range(n):
            if s[i] == 'L':
                if l[i] == i:
                    ok = False
                    break
                parent[i] = l[i]
            elif s[i] == 'R':
                if r[i] == i:
                    ok = False
                    break
                parent[i] = r[i]

        if not ok:
            print(-1)
            continue

        for i in range(n):
            if parent[i] != -1:
                children[parent[i]].append(i)
                root_candidates.discard(i)

        # attach remaining ? nodes optimally
        for i in range(n):
            if s[i] == '?':
                if l[i] != i and r[i] != i:
                    if len(children[l[i]]) < len(children[r[i]]):
                        parent[i] = r[i]
                    else:
                        parent[i] = l[i]
                    children[parent[i]].append(i)
                    root_candidates.discard(i)
                elif l[i] != i:
                    parent[i] = l[i]
                    children[parent[i]].append(i)
                    root_candidates.discard(i)
                elif r[i] != i:
                    parent[i] = r[i]
                    children[parent[i]].append(i)
                    root_candidates.discard(i)
                else:
                    ok = False
                    break

        if not ok or len(root_candidates) != 1:
            print(-1)
            continue

        root = root_candidates.pop()

        def dfs(u):
            h1 = h2 = 0
            diameter = 0
            for v in children[u]:
                d, h = dfs(v)
                diameter = max(diameter, d)
                if h > h1:
                    h2 = h1
                    h1 = h
                elif h > h2:
                    h2 = h
            return max(diameter, h1 + h2), h1 + 1

        ans, _ = dfs(root)
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先使用单调堆栈计算最近的较大邻居。 然后，它根据固定的 L 和 R 边构造一个临时父列表，立即拒绝不可能的配置。 其余的 ？ 节点贪婪地连接以最大化高度。 DFS 在单次后序遍历中有效地计算最大直径。
