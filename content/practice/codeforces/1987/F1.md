 ## 解决方案
 ## 问题理解

 我们得到一个长度为整数的数组$n$。 在每一步中，我们可以选择一个索引$i$在哪里$a_i = i$和$i < n$，并删除两者$a_i$和$a_{i+1}$。 目标是最大化执行此操作的次数，直到不再存在有效索引为止。 每个测试用例都是独立的，所有测试用例的总和$n$所有测试用例不超过 100 个，这个数量很小，可以让我们轻松地考虑具有三次甚至二次行为的解决方案。 

从概念上讲，这是一个关于在数组中查找与其从 1 开始的索引相匹配的子序列并有效删除它们的问题。 一种幼稚的方法可能会考虑重复检查每个位置，在有效时删除两个元素，然后继续。 但是，在边缘情况下必须小心：如果数组严格递增但跳过索引，或者数组非常短（长度为 1 或 2），则操作可能无法进行。 例如，如果$a = [1]$或者$a = [2, 2]$，不会发生任何操作，输出应为 0。 

当连续操作可以重叠时，就会出现另一个微妙之处。 考虑$a = [1, 2, 2, 3]$。 选择索引 1 会删除元素 [1,2]，留下 [2,3]。 现在，下一个有效操作发生在新索引 1（原始索引 3）处，需要仔细计算以确保算法不会跳过可能的操作。 

## 方法

 暴力方法迭代数组，搜索有效索引$i$在哪里$a_i = i$和$i < n$。 一旦找到，就会删除$a_i$和$a_{i+1}$，将剩余元素左移，并重复直到没有有效索引剩余。 这适用于小型数组，但其最坏情况的复杂性是$O(n^2)$，因为每次移除都需要移动元件并反复检查每个位置。 为了$n$最多 100 个，这种方法可以工作，但高效实施很麻烦，特别是如果我们想推广到更大的约束。 

最佳方法的关键观察是，可以将数组建模为一系列连续的段，每个段代表相对于操作条件“不合适”的元素数量。 如果我们跟踪每个段内可以发生多少个操作，我们就可以使用动态规划来解决该问题。 具体来说，我们可以维护一个 DP 数组，其中`dp[i]`是以索引结尾的前缀可能的最大操作数`i`。 在每一步中，我们都会检查当前索引是否$i$满足$a_i = i$，然后与之前的解决方案结合起来以解决连续删除问题。 这将复杂性降低到$O(n^2)$无需在每一步中进行实际的阵列突变。 

故事是这样的：蛮力之所以有效，是因为它直接模拟了过程，但在清晰度和泛化方面失败了。 通过将问题视为前缀上的 DP 来观察，我们可以在不移动数组的情况下计算最大操作数，从而使解决方案简洁且易于推理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 适用于小 n，但很乏味 |
 | 动态规划| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个长度为DP的数组$n+1$带零。 这里`dp[i]`将表示对以索引结尾的数组的前缀可能进行的最大操作数`i`。 
2. 从左到右迭代数组。 对于每个索引`i`（基于 1），考虑所有先前的指数`j < i`并检查子数组是否`a[j..i]`可以形成有效的操作序列。 子数组有效，如果`a[k] <= k-j+1`为所有人`k`在`j..i`。 如果有效，更新`dp[i] = max(dp[i], dp[j-1] + 1)`。 
3.处理完所有索引后，整个数组的最大操作次数为`dp[n]`。 
4. 对所有测试用例重复该过程。 

为什么它有效：DP 数组保持不变式`dp[i]`始终表示前缀上可实现的最佳操作数`[1..i]`。 当有效操作可能结束于`i`，在保证正确性之前，对前缀的最优解添加一个操作。 因为我们从不跳过任何有效的子数组，并且总是最大化，这保证了全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        dp = [0] * (n + 1)
        for i in range(n):
            cnt = 0
            for j in range(i, -1, -1):
                cnt += 1
                if a[j] == cnt:
                    dp[i+1] = max(dp[i+1], dp[j] + 1)
        print(dp[n])

solve()
```外循环读取测试用例的数量。 在每个测试用例中，我们初始化一个 DP 数组并迭代数组索引。 内部循环向后计算当前段长度，检查元素是否与“距段起点的距离”匹配，该距离对应于`a_i = i`调整到段时的情况。 更新中`dp[i+1]`确保我们为每个前缀累积最大可能的操作数。
