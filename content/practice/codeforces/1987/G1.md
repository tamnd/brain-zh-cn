 ## 解决方案
 ## 问题理解

 我们给出了一个排列`p`长度`n`和一个字符串`s`相同长度仅由`?`。 各位置`i`在排列中定义了两个特殊索引：`l_i`是之前的最后一个索引`i`其中排列值较大，并且`r_i`是之后的第一个索引`i`其中值较大。 如果不存在这样的索引，我们默认为`i`本身。 

任务是构造一个无向图`n`顶点。 每个顶点`i`可以连接到`l_i`或者`r_i`因为所有的角色都是`?`。 目标是选择这些边，以便生成的图是连接的并具有最大可能的直径，定义为任意两个顶点之间的最大距离。 如果无法形成连通图，则输出`-1`。 

约束条件意味着`n`所有测试用例的总数最多可达 400,000 个。 尝试所有方法的天真方法`2^n`选择边缘的方法是不可能的。 我们必须利用结构`l_i`和`r_i`在线性或近线性时间内有效地计算直径。 

当排列严格增加或减少时，会出现微妙的边缘情况。 在这种情况下，`l_i`或者`r_i`可以默认为`i`本身，创建不扩展图的自循环。 例如，`p = [1,2,3]`导致`l_2 = 2`,`r_2 = 3`，并且选择错误的边可能会减少连通性或直径。 

## 方法

 蛮力方法会尝试所有边缘的每种组合`?`人物。 对于每种组合，我们构建图表，使用 DFS 或 BFS 检查连通性，然后使用双 BFS 计算直径。 每个组合都是`O(2^n)`构建和检查图表是`O(n)`，使其完全不可行`n`高达 400,000。 

关键的见解是由以下定义的图`l_i`和`r_i`如果边缘选择一致朝向较大的邻居，则它是一个有根树的森林。 每个顶点都有一个到更大元素的唯一“向上”边缘，形成一棵以排列的全局最大值为根的树。 因为所有`?`可以向左或向右指向更大的邻居，最大直径是通过以之字形方式选择边缘来实现的，如果可能的话，在左右之间交替。 更系统地，可以通过对隐式树进行动态规划来获得直径：计算每个节点的最长向下路径，并将每个节点处的两条最大路径组合起来形成候选直径。 全局最大值给出了答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算`l_i`和`r_i`为所有人`i`有效地使用单调堆栈。 从左到右迭代`l_i`，保持递减的堆栈。 对于每个元素，弹出较小的元素，直到顶部更大，这给出`l_i`。 从右向左重复`r_i`。 
2. 将图隐式表示为数组`parent[i]`。 对于最大直径，我们总是连接每个`i`到较大的`l_i`或者`r_i`最大化到叶子的距离。 
3. 使用深度优先搜索（DFS）计算每个子树的高度。 从递归返回时，跟踪子节点中的两个最大高度，并计算该节点处的候选直径作为两个最大高度之和加上 2（对于连接边）。 
4.保留全局变量`diameter`并在发现更大的候选直径时更新它。 
5. DFS 完成后，以全局最大值为根的树`p`，输出计算出的`diameter`。 

工作原理：通过始终连接到下一个较大的邻居，我们确保树以全局最大值为根，从而最大化距离。 结合每个节点处的两个最大高度可确保我们考虑通过内部节点的路径。 这种贪婪的选择是有效的，因为问题允许选择`l_i`或者`r_i`自由地选择更大的邻居会扩大深度而不是压缩深度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        s = input().strip()

        l = [0] * n
        r = [0] * n

        stack = []
        for i in range(n):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            l[i] = stack[-1] if stack else i
            stack.append(i)

        stack = []
        for i in range(n-1, -1, -1):
            while stack and p[stack[-1]] < p[i]:
                stack.pop()
            r[i] = stack[-1] if stack else i
            stack.append(i)

        children = [[] for _ in range(n)]
        root = p.index(max(p))
        for i in range(n):
            if i == root:
                continue
            # choose the neighbor further from root for max diameter
            if abs(i - l[i]) > abs(i - r[i]):
                children[l[i]].append(i)
            else:
                children[r[i]].append(i)

        diameter = 0
        def dfs(u):
            nonlocal diameter
            heights = []
            for v in children[u]:
                h = dfs(v)
                heights.append(h)
            if not heights:
                return 0
            heights.sort(reverse=True)
            if len(heights) >= 2:
                diameter = max(diameter, heights[0] + heights[1] + 2)
            diameter = max(diameter, heights[0] + 1)
            return heights[0] + 1

        dfs(root)
        print(diameter)

if __name__ == "__main__":
    solve()
```前两个循环计算`l_i`和`r_i`使用单调堆栈在线性时间内。 这`children`array 通过为每个节点选择增加深度的邻居来表示树结构。 DFS 递归计算高度并更新全局`diameter`使用前两个孩子的高度。 排序高度是可以接受的，因为实际上每个节点最多有两个子节点，从而保持整体操作的线性。
