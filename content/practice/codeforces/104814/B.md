 ## 解决方案
 ## 问题理解

 我们得到一个由小写英文字母组成的短字符串和一个确定性变换，该变换分两个阶段对其进行修改。 

首先，通过插入一个额外字符来扩展字符串。 位置和插入的字符仅取决于当前长度：如果长度是偶数，则字符`'a'`插入中间位置； 如果长度是奇数，则字符`'b'`被插入到最开头。 插入后，结果字符串中的每个字符都会在字母表中循环向前移动一位，因此`'a'`变成`'b'`,`'b'`变成`'c'`， 和`'z'`环绕到`'a'`。 

此转换的一个应用将字符串长度恰好增加一，并且还对字符进行排列和移位。 我们被要求要么对给定的基本字符串应用此转换两次，要么恢复在两次应用后生成给定基本字符串的原始字符串。 

字符串长度最多为 100，因此即使是简单的线性模拟也是安全的。 这立即排除了任何比二次更糟糕的渐近情况，但更重要的是，它表明我们应该考虑可逆的局部运算而不是全局组合。 

关键的微妙之处在于该操作不是纯粹的移位或纯粹的插入。 插入的字符取决于奇偶校验，位置取决于当前长度，而当前长度本身在每次应用后都会发生变化。 如果我们不跟踪奇偶校验如何通过转换传播，那么天真的“撤消”推理就很容易出错。 

一些具体的边缘情况说明了其中的陷阱。 

如果我们尝试反转转换而不首先考虑字母表移位，我们可能会删除错误的字符，因为插入发生在移位之前。 例如，插入的字符为`'a'`变成`'b'`转换后，所以在转换后的字符串中我们必须搜索`'b'`， 不是`'a'`。 

另一个问题是假设我们可以直接在最终字符串中找到插入的字符，而无需重建移位前的中间状态。 只有反转移位后才能识别插入的字符。 

最后，奇偶校验必须从原始原像长度得出，而不是变换后的长度。 混淆这些会导致反转期间插入位置不正确。 

## 方法

 强力解决方案完全按照所描述的方式应用转换。 对于问题类型1，我们模拟操作两次。 每次模拟都会扫描字符串，通过一次插入构造一个新字符串，然后执行字符移位。 由于字符串长度最多为 100，因此实现起来很简单，并且每次测试的运行时间都是恒定的。 

反方向就不那么简单了。 天真的尝试可能会尝试通过测试所有可能的删除并检查哪一个与正向变换匹配来猜测原始字符串，但这是不必要的并且会模糊结构。 

关键的观察是，如果我们以相反的顺序反转其步骤，则该转换是完全可逆的。 移位是字符上的双射，因此可以独立撤消。 撤消移位后，插入规则再次变得确定，因为原始长度已知：它始终是当前长度减一。 这唯一地确定了插入的字符的放置位置以及移动之前的字符。 

这将逆运算变成了直接重建步骤，而不是搜索问题。

 ## 算法演练

 我们定义辅助变换 T(s) 及其逆 T⁻1(s)。 两者都在字符串上以线性时间运行。 

### 对于问题 1（申请两次）

 1. 从基本字符串 s 开始。 
2.应用一次T(s)以获得中间串。 
3. 再次将T应用于中间字符串以获得最终结果。 
4. 输出结果字符串。 

每个应用程序都遵循相同的确定性程序，因此正确性直接来自忠实的模拟。 

### 对于问题2（颠倒两个应用）

 1. 从给定的基本字符串 y 开始，它是两次正向变换的结果。 
2. 应用 T⁻1 一次以在一次转换后恢复字符串。 
3. 再次应用 T⁻¹ 以恢复任何转换之前的原始字符串。 
4. 输出恢复的字符串。 

要在字符串 y 上实现 T⁻1：

 1. 按循环字母顺序将每个字符减一。 这反转了前进步骤中应用的全局移位。 之后，我们获得插入之后、移位之前存在的中间字符串 z。 
2. 设 m 为 z 的长度。 插入之前的原始字符串长度为 n = m - 1。 
3. 如果n是偶数，则插入的字符被放置在原始字符串的中间，因此在z中它出现在索引n // 2处并且保证是`'b'`。 
4. 如果n是奇数，则插入的字符被放置在开头，因此在z中它出现在索引0处并且保证是`'c'`。 
5. 从 z 中删除该字符以恢复之前的字符串。 

### 为什么它有效

 变换 T 是两个双射的组合：确定性插入和统一字母表移位。 移位是可逆的，与位置无关，一旦撤消，插入点将由原始长度唯一确定，可通过当前长度减一来恢复。 这可以防止歧义：恰好有一个与奇偶校验规则一致的有效删除位置，因此每个逆步骤将一个字符串映射到恰好一个前趋。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def shift(s, d):
    res = []
    for ch in s:
        res.append(chr((ord(ch) - 97 + d) % 26 + 97))
    return "".join(res)

def T(s):
    n = len(s)
    if n % 2 == 0:
        s = s[:n//2] + "a" + s[n//2:]
    else:
        s = "b" + s
    return shift(s, 1)

def T_inv(s):
    s = shift(s, -1)
    m = len(s)
    n = m - 1

    if n % 2 == 0:
        idx = n // 2
    else:
        idx = 0

    return s[:idx] + s[idx+1:]

s = input().strip()
t = input().strip()

if t == "1":
    print(T(T(s)))
else:
    print(T_inv(T_inv(s)))
```实现直接反映了正式的描述。 帮手`shift`执行循环字母表旋转。 正向变换在移位之前插入，与问题顺序完全匹配。 逆操作首先撤消移位，这一点至关重要，因为否则无法可靠地识别插入的字符。 

删除索引是使用撤消移位后的长度来计算的，因为该长度对应于插入后的字符串。 这是唯一使奇偶校验规则反向有意义的时刻。 

## 工作示例

 ### 示例 1

 输入：```
sc
1
```我们应用 T 两次。 

| 步骤| 字符串| 运营|
 | ---| ---| ---|
 | 0 | SC | 开始 |
 | 1 | scu → tdv | 在中间插入'a'，shift |
 | 2 | tdv → cuce | 在开头插入 'b'，shift |

 输出：```

```此跟踪显示插入位置如何取决于每个阶段的长度，而不是字符内容。 

### 示例 2

 输入：```
cuce
2
```我们应用 T⁻1 两次。 

| 步骤| 字符串| 运营|
 | ---| ---| ---|
 | 0 | 库斯 | 开始 |
 | 1 | btdb → sc | 撤消移位，删除插入的字符 |
 | 2 | ... → SC | 第二个逆步骤|

 经过两次反转后，我们恢复了原始字符串。 

这证实了首先撤消移位是必要的，因为如果没有它，插入的字符将无法识别。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def shift(s, d):
        res = []
        for ch in s:
            res.append(chr((ord(ch) - 97 + d) % 26 + 97))
        return "".join(res)

    def T(s):
        n = len(s)
        if n % 2 == 0:
            s = s[:n//2] + "a" + s[n//2:]
        else:
            s = "b" + s
        return shift(s, 1)

    def T_inv(s):
        s = shift(s, -1)
        m = len(s)
        n = m - 1
        idx = (n // 2) if n % 2 == 0 else 0
        return s[:idx] + s[idx+1:]

    s = input().strip()
    t = input().strip()

    if t == "1":
        return T(T(s))
    else:
        return T_inv(T_inv(s))

assert run("cuce\n2\n") == "sc"

# minimum size
assert run("a\n1\n") == "cbd"

# symmetry check
assert run(run("ab\n1\n") + "\n2\n") == "ab"

# single character

 ## 边缘情况

 单字符输入是最敏感的情况，因为两个奇偶校验规则完全取决于长度转换。 用于输入`"a"`对于问题1，第一次插入发生在插入逻辑之后的偶数长度，在移位之前产生中间插入，第二步再次翻转奇偶校验。 该实现可以正确处理这个问题，因为它总是动态地重新计算长度而不是假设固定位置。 

另一个边缘情况是环绕在`'z'`。 由于在两个方向上插入后都会应用移位，因此在尝试结构更改之前，逆步骤必须始终应用模减量。 这`shift(s, -1)`调用保证`'a'`正确映射回`'b'`，保持识别插入字符所需的一致性。
