 ## 解决方案
 ## 问题理解

 我们给定一个固定的整数$x$，它表示直角三角形的一条边的长度。 任务是计算存在多少个具有整数边长的不同直角三角形，使得其中一条腿恰好是$x$。 如果两个三角形在旋转、反射或平移后边长匹配，则认为它们是相同的，这实际上意味着我们只关心它们的边长三倍，而不关心方向。 

边长为整数的直角三角形完全由毕达哥拉斯三元组确定$(a, b, c)$令人满意$a^2 + b^2 = c^2$。 在我们的例子中，其中一条腿被固定在$x$，所以我们计算任一的整数解$x^2 + y^2 = z^2$或者$y^2 + x^2 = z^2$。 由于两条腿是对称的，我们可以不失一般性地假设第二条腿是$y$，我们搜索整数对$(y, z)$这样$$x^2 + y^2 = z^2, \quad x, y, z > 0.$$限制才是真正的挑战：$x \le 10^9$并且最多有5个测试用例。 任何枚举候选者的解决方案$y$或者$z$最多$x$立即是不可行的。 二次或偶数$O(x)$扫描远远超出了可接受的限度，因此解决方案必须依赖于毕达哥拉斯三元组的结构特性。 

一个微妙的边缘情况是多个不同的三元组可以共享同一个固定腿$x$，如示例所示，其中$x = 15$产生四个不同的三角形。 另一个重要的细节是缩放很重要：三元组就像$(8, 15, 17)$,$(15, 20, 25)$,$(15, 36, 39)$， 和$(15, 112, 113)$证明原始三元组和非原始三元组都必须被计算。 

## 方法

 暴力方法将尝试第二条腿的所有可能值$y$, 计算$z = \sqrt{x^2 + y^2}$，并检查是否$z$是一个整数。 从概念上讲，这是可行的，因为每个有效的三角形都必须出现在该枚举中，并且该条件很容易验证。 然而，$y$原则上可以达到任意大的值，甚至限制为$y \le x$仍然会导致$O(x)$每个测试用例的迭代次数，这对于$x \le 10^9$。 

关键的观察是毕达哥拉斯三元组具有完整的参数化。 每个整数直角三角形都对应于整数$m > n$具有相反的奇偶性，使得$$a = k(m^2 - n^2), \quad b = k(2mn), \quad c = k(m^2 + n^2).$$我们的固定腿$x$必须匹配$k(m^2 - n^2)$或者$k(2mn)$。 这将问题简化为计算因式分解$x$适合这两种代数形式。 

我们不是迭代几何值，而是迭代除数$x$并使用数论约束。 的结构$2mn$和$m^2 - n^2$强制强整除条件，这意味着每个有效的三元组都对应于受控因式分解$x$。 这将问题转化为除数枚举问题，这是可行的，因为除数的数量$x \le 10^9$最坏的情况最多也就几千左右。

 ## 算法演练

 核心思想是重写条件$x^2 + y^2 = z^2$作为分解约束$(z-y)(z+y)$。 展开给出$$z^2 - y^2 = x^2 \Rightarrow (z-y)(z+y) = x^2.$$这将几何问题转化为寻找因子对$x^2$。 

### 步骤

 1.修复$x$并计算$x^2$。 我们想要所有对$(u, v)$这样$u \cdot v = x^2$， 在哪里$u = z-y$和$v = z+y$。 这种替换之所以有效，是因为两个表达式都是整数并保留正性约束。 
2. 枚举所有除数$u$的$x^2$最多$\sqrt{x^2} = x$。 对于每个除数$u$， 定义$v = x^2 / u$。 这保证了所有因素对都被考虑一次。 
3. 对于每对$(u, v)$,重建$$z = \frac{u + v}{2}, \quad y = \frac{v - u}{2}.$$这些必须是整数，所以我们需要$u \equiv v \pmod{2}$。 如果奇偶校验不同，则该对无效并被跳过。 
4. 确保积极性：$y > 0$。 如果$u < v$，所以我们只考虑$u < v$以避免退化情况和重复计算。 
5. 将每个有效的重建算作一个三角形。 

### 为什么它有效

 每个整数直角三角形唯一对应于因式分解$x^2$通过身份$(z-y)(z+y) = x^2$。 相反，满足奇偶性的每个有效因子对都会产生一个有效整数$y$和$z$。 在这些约束下，有效三角形和有效因子对之间的映射是双射的，因此对这些对进行计数可以精确地对三角形进行计数，而不会重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_triangles(x):
    n = x * x
    ans = 0

    i = 1
    while i * i <= n:
        if n % i == 0:
            j = n // i

            # pair (i, j)
            if i < j and ((i + j) % 2 == 0):
                ans += 1

            # pair (j, i) is same, so no need to process separately
        i += 1

    return ans

t = int(input())
for _ in range(t):
    x = int(input())
    print(count_triangles(x))
```该实现直接应用因子对重构。 我们迭代直到$x$自从$\sqrt{x^2} = x$，确保我们涵盖了所有除数$x^2$。 条件$i < j$防止对称对的重复计算。 奇偶校验确保重构$y$是一个整数，因为两者$z-y$和$z+y$必须具有相同的奇偶性。

 ## 边缘情况

 对于$x = 1$，我们得到$x^2 = 1$。 唯一的因子对是$(1, 1)$，但它不会产生有效的三角形，因为它会导致$y = 0$。 该算法正确地丢弃了这一点，因为$u = v$被排除在外。 

为了$x = 2$，我们得到$x^2 = 4$与对$(1, 4)$和$(2, 2)$。 仅有的$(1, 4)$产生一个有效的$y = \frac{3}{2}$尝试，但奇偶校验失败，因此结果为零。 这符合以下事实：整数直角三角形的边长度不能为 2。 

对于$x = 15$, 多个因子对$225$满足奇偶校验并产生有效的整数中点。 每个这样的对对应于一个不同的三角形，并且由于严格的$i < j$健康）状况。
