 ## 解决方案
 ## 问题理解

 我们有一个聚会场景，其中 Petya 邀请了 _n_ 个朋友，每个人都给了另一个朋友一份礼物。 输入按顺序列出了每个朋友赠送礼物的朋友。 我们的任务是反转这个映射：对于每个朋友，我们想知道谁给了他们礼物。 

形式上，输入由一个整数 _n_ 和一个数组组成`p`长度为 _n_，其中`p[i]`是收到好友礼物的好友号码`i + 1`。 输出是一个数组`q`长度 _n_ 其中`q[i]`是给朋友送礼物的朋友`i + 1`。 

约束条件`1 ≤ n ≤ 100`很小，这意味着即使是 O(n²) 解决方案也足够快。 然而，正确性比效率更微妙。 每个朋友都送出和收到一份礼物，所以数组`p`表示数字 1 到 _n_ 的排列。 这保证了逆映射的存在。 

一个常见的边缘情况是朋友给自己送礼物。 例如，如果`n = 3`和`p = [1, 2, 3]`，然后每个朋友都会收到自己的礼物。 正确的输出还应该反映出每个朋友给自己送了一份礼物：`q = [1, 2, 3]`。 假设没有自我赠予的天真的方法可能会产生不正确的映射或无法正确处理索引。 

## 方法

 暴力方法会迭代每个接收者的所有朋友。 给朋友`i`，我们搜索通过`p`找到索引`j`在哪里`p[j] = i`。 这是有效的，因为每个值`p`是独一无二的，保证匹配。 时间复杂度为O(n²)，可以接受`n ≤ 100`。 此方法在概念上很简单，但对于较大的数组来说效率较低。 

优化的关键见解来自于认识到`p`是一个排列。 排列可以直接反转：如果朋友`i`给朋友送礼物`p[i]`，然后朋友`p[i]`收到朋友的礼物`i`。 我们可以创建一个数组`q`大小 _n_ 并分配`q[p[i] - 1] = i + 1`为所有人`i`。 这种方法的复杂度为 O(n)，并且只需要对数组进行一次遍历，从而消除了不必要的嵌套循环。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 对于此问题已接受，对于较大的 n | 效率较低
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取好友数量`n`和数组`p`代表每个朋友送礼物给谁。 
2.初始化一个数组`q`长度`n`存储逆映射。 
3. 迭代所有好友`i`从 0 到 n-1。 
4. 对于每一位朋友`i`， 分配`q[p[i] - 1] = i + 1`。 这一步让给予者`i + 1`在与接收者对应的索引处`p[i] - 1`。 
5. 填充后`q`，将其打印为空格分隔的整数。 

该算法之所以有效，是因为每个朋友都给出了一份礼物并收到了一份礼物。 作业`q[p[i] - 1] = i + 1`确保每个位置`q`填写一次并正确地将接收者映射到其给予者。 排列的唯一性保证不会发生覆盖。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
p = list(map(int, input().split()))

q = [0] * n
for i in range(n):
    q[p[i] - 1] = i + 1

print(*q)
```我们使用快速 I/O 读取朋友的数量和排列数组。 数组`q`用零初始化以存储逆映射。 该循环使用基于 1 的索引为每个接收者分配正确的提供者。 最后，我们通过解包打印结果以匹配所需的输出格式。 

## 工作示例

 对于输入：```
4
2 3 4 1
```我们初始化`q = [0, 0, 0, 0]`。 

| 我| p[i] | p[i] q 分配后 |
 | ---| ---| ---|
 | 0 | 2 | [0, 1, 0, 0] |
 | 1 | 3 | [0, 1, 2, 0] |
 | 2 | 4 | [0, 1, 2, 3] |
 | 3 | 1 | [4,1,2,3]|

 输出是`4 1 2 3`。 索引处的每个值`i`正确指示谁给朋友送了礼物`i + 1`。 

另一个输入：```
3
1 3 2
```| 我| p[i] | p[i] q 分配后 |
 | ---| ---| ---|
 | 0 | 1 | [1, 0, 0] |
 | 1 | 3 | [1, 0, 2] |
 | 2 | 2 | [1,3,2]|

 输出：`1 3 2`，正确地将给予者映射到接受者。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    p = list(map(int, input().split()))
    q = [0] * n
    for i in range(n):
        q[p[i] - 1] = i + 1
    return ' '.join(map(str, q))

# Provided samples
assert run("4\n2 3 4 1\n") == "4 1 2 3", "sample 1"
assert run("3\n1 3 2\n") == "1 3 2", "sample 2"

# Custom cases

 ## 边缘情况

 对于单身朋友，输入`1\n1`，算法初始化`q = [0]`并分配`q[0] = 1`，产生输出`1`。 该算法正确地处理了最小边界。 

如需送礼，请输入`5\n1 2 3 4 5`， 每个`q[i]`已分配`i + 1`，生成与输出相同的数组。 不会发生相差一的错误，因为我们仔细调整了 Python 中基于 0 的索引与基于 1 的好友编号。 

对于反转或交换排列，直接赋值`q[p[i] - 1] = i + 1`无需搜索即可可靠地将给予者映射到接收者，从而确认所有排列的正确性。
