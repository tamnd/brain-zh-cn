 ## 解决方案
 ## 问题理解

 我们给出了一个排列$p$尺寸的$n$，这意味着它包含来自的每个整数$1$到$n$正好一次。 我们必须构建另一个排列$q$大小相同，也是重新排列$1$到$n$，具有连接相邻位置的结构约束。 

对于每对相邻的索引$i$和$i+1$，我们形成两个和：$p_i + q_i$和$p_{i+1} + q_{i+1}$。 要求是这两个和的最大公约数至少为 3。换句话说，连续位置产生的和必须始终共享大小至少为 3 的非平凡公约数。 

输出不是单个值而是完整的排列$q$，并且任何有效的构造都被接受。 

约束允许最多$2 \cdot 10^5$所有测试用例的总元素，这立即排除了任何考虑位置对或尝试搜索排列的方法。 每个测试用例超出线性或接近线性时间的任何事情都将失败。 

一个微妙的一点是，条件完全是局部的：只有相邻位置才重要。 然而，每个位置都会影响两个约束，因此不能在不确保一致性的情况下孤立地贪婪地做出决策。 

一个天真的错误是认为选择$q_i$独立匹配$p_i$对某个数字取模可能无需协调即可工作。 例如，如果有人尝试$q_i = n+1 - p_i$，它可能会意外地满足某些邻接条件，但会在其他邻接条件下失败，因为 gcd 条件取决于总和，而不是单个残差。 

当尝试随机排列时会出现另一种故障模式$q$。 尽管许多随机构造将满足一些局部 gcd 约束，但满足所有条件的概率$n-1$对于大的约束同时变得可以忽略不计$n$，这样的解决方案并不可靠。 

## 方法

 蛮力的观点是尝试构建$q$逐渐地。 在每个位置$i$，我们选择一个剩余值$q_i$并检查条件是否与$i-1$很满意。 这会导致大小排列的回溯$n$，具有阶乘复杂度。 即使进行剪枝，邻接 gcd 约束也不会尽早限制空间以避免指数爆炸。 

关键的见解是停止考虑单个位置，而是对总和强制执行全局算术结构$p_i + q_i$。 条件$\gcd(x, y) \ge 3$如果两个数有 3 的公倍数，即都是 3 的倍数，则保证成立。 

这减少了问题，以确保所有相邻的和都位于相同的模 3 的残差类中，特别是都可以被 3 整除。如果每个$p_i + q_i$是 3 的倍数，则每个相邻的 gcd 自动至少为 3。 

所以问题就变成了构造一个排列$q$这样每个总和$p_i + q_i$能被 3 整除。这相当于强制$$q_i \equiv -p_i \pmod 3.$$现在我们必须构建一个尊重这些残差约束的排列，同时使用每个数字一次。 由于残基 mod 3 将数字分为三个平衡组，因此我们可以将每个组配对$p_i$与兼容的$q_i$从相应的残基类别中提取。 该构造成为残基类之间的匹配问题，但由于两侧都是同一集合的排列，因此残基组内的简单循环移位就足够了。 

这将问题转化为按残基类别对索引进行排序并在每个类别内轮换分配。

 | --- | --- | --- | --- |
 | 暴力回溯|$O(n!)$|$O(n)$| 太慢了|
 | 残渣基施工|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 分区索引$1$到$n$根据分为三个桶$p_i \bmod 3$。 这是必要的，因为每个$p_i$规定了所需的残留类别$q_i$。 
2.同样，对值进行分区$1$到$n$根据其模 3 值分为三个桶。 这些代表每个残基类别的可用候选者$q$。 
3. 对于每个残留类别$r \in \{0,1,2\}$，将索引配对$p$-bucket 中的值$q$- 桶按顺序排列。 这项任务确保每个$q_i$遵守所需的残留条件。 
4. 分配$q_i$根据这些配对，填补所有位置。 
5. 输出排列结果。 

步骤 3 和 4 的关键思想是，我们正在解决三个独立的匹配问题，而不是一个全局排列问题，因为模 3 完全解耦了 gcd 约束。 

### 为什么它有效

 该结构保证对于每个索引$i$, 总和$p_i + q_i$能被 3 整除，因为$q_i \equiv -p_i \pmod 3$。 因此，每个这样的和至少是 3 的倍数，因此每对相邻的和都有一个至少为 3 的公约数。这个不变量在全局范围内成立，因为它在每个位置独立强制执行，因此任何邻接都不能违反它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        
        buckets_p = {0: [], 1: [], 2: []}
        buckets_q = {0: [], 1: [], 2: []}
        
        for i, x in enumerate(p):
            buckets_p[x % 3].append(i)
        
        for v in range(1, n + 1):
            buckets_q[v % 3].append(v)
        
        q = [0] * n
        
        for r in range(3):
            for i, v in zip(buckets_p[r], buckets_q[r]):
                q[i] = v
        
        print(*q)

if __name__ == "__main__":
    solve()
```实现直接遵循残差分区策略。 我们首先按值对位置进行分类$p_i \bmod 3$，然后将可用数字按其自己的模 3 类别进行分类。 然后我们以一对一的方式匹配它们。 

一个微妙的点是索引是通过位置来完成的$p$，不是按值，因为$q$必须与位置对齐。 另一个重要的细节是该结构假设桶大小相等，这是因为$p$和$1..n$每个残基类中包含相同数量的元素。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        b0, b1, b2 = [], [], []
        for i, x in enumerate(p):
            (b0 if x % 3 == 0 else b1 if x % 3 == 1 else b2).append(i)

        c0, c1, c2 = [], [], []
        for v in range(1, n + 1):
            (c0 if v % 3 == 0 else c1 if v % 3 == 1 else c2).append(v)

        q = [0] * n
        for a, b in [(b0, c0), (b1, c1), (b2, c2)]:
            for i, v in zip(a, b):
                q[i] = v

        out.append(" ".join(map(str, q)))
    return "\n".join(out)

 ## 边缘情况

 对于$n=2$，除了一对之外没有邻接约束，因此任何有效的残基一致分配都有效。 即使某些存储桶可能是空的，该算法仍然可以正确分区。 

对于小$n$， 例如$n=3$，残渣类别可能不均匀，但构造仍然有效，因为两者$p$和$1..n$在模 3 类中均匀分布，确保完美匹配。 

对于已经结构化的排列，例如$p = [1,2,3,\dots,n]$，该算法简单地将每个残基类映射到其自身上，产生一个有效的$q$没有冲突。
