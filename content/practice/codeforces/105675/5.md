 ## 解决方案
 ## 问题理解

 我们需要构造两个正整数`x`和`y`使得它们的平方之差等于给定的非负整数`n`:\[
x^2-y^2=n
\]输出并不要求表达式本身的值。 它要求生成它的一对实际数字。 如果不存在这样的正对，我们打印`No`。 

输入值可以大到\(2^{60}\)，所以尝试值`x`或者`y`一一是不可能的。 解决方案必须使用表达式的数学结构而不是搜索。 答案值本身可能取决于\(2^{62}-1\)，它仍然适合 Python 整数。 

主要的边缘情况来自奇偶校验和非常小的值。 例如，`n = 2`没有解决办法。 一种诱人的方法可能会尝试将其写为`2 * 1`，但平方差的两个因子必须具有相同的奇偶性。 为了`n = 4`，因式分解`2 * 2`给出`x = 2, y = 0`，这是无效的，因为`y`必须是积极的。 为了`n = 1`，通常的构造给出`x = 1, y = 0`，这也未满足积极性要求。 为了`n = 0`，然而，这对`x = 1, y = 1`作品。 

这些案例的例子有：

 | 输入| 正确输出|
 |---|---|
 |`2`|`No`|
 |`4`|`No`|
 |`1`|`No`|
 |`0`|`Yes`其次是`1 1`|

 ## 方法

 直接的方法是尝试可能的值`y`并检查是否`y^2+n`是一个正方形。 最大可能值约为\(2^{60}\)，因此即使是检查数百万候选人的方法也太慢了。 

有用的变换来自平方差公式：\[
x^2-y^2=(x-y)(x+y)
\]让：\[
a=x-y,\quad b=x+y
\]那么我们需要：\[
a \cdot b=n
\]我们可以恢复：\[
x=\frac{a+b}{2},\quad y=\frac{b-a}{2}
\]两个因素`a`和`b`必须具有相同的奇偶性，因为它们的和和差必须都是偶数。 

如果`n`是奇数，它的所有因数都是奇数。 最简单的选择是`a = 1`和`b = n`。 这给出：\[
x=\frac{n+1}{2},\quad y=\frac{n-1}{2}
\]这有效，除非`n = 1`，因为它产生`y = 0`。 

如果`n`是偶数，则两个因数必须是偶数。 这正是可能发生的时候`n`能被4整除。我们可以选择`a = 2`和`b = n/2`。 这会创建一个有效的对，只要`b > a`，其中不包括`n = 4`。 

暴力方法之所以有效，是因为它直接检查定义，但忽略了隐藏在表达式内的因式分解。 分解将问题转化为恒定时间奇偶校验。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(√n) 或更差 | O(1) | O(1) | 太慢了 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`。 处理`n = 0`分别通过输出`x = 1, y = 1`，因为相等的正数的平方差为零。 

2.如果`n`是奇数，使用因子对`1`和`n`。 计算：\[
   x=(n+1)/2,\quad y=(n-1)/2
   \]拒绝结果，如果`y`为零，因为所需的数字必须是正数。 

3.如果`n`是偶数，首先检查它是否能被4整除。如果不能，则计算它的两个因数`n`不可能两者都是偶数，因此不存在有效的因子对。 

4. 对于能被 4 整除的数字，使用因子`2`和`n/2`。 计算：\[
   x=\frac{2+n/2}{2},\quad y=\frac{n/2-2}{2}
   \]拒绝如果`y`为零。 

5. 打印构建的对。 

为什么有效：平方差的每个有效表示都对应于两个因子`(x-y)`和`(x+y)`具有平等的地位。 该算法为每个可能的奇偶校验类别考虑最简单的可能因子对。 奇数总是有奇数因数对。 能被 4 整除的数有偶数对。 所有剩余的数字都不能满足奇偶校验要求，因此它们不能表示为两个正平方之差。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 0:
        print("Yes")
        print("1 1")
        return

    if n & 1:
        x = (n + 1) // 2
        y = (n - 1) // 2
        if y > 0:
            print("Yes")
            print(x, y)
        else:
            print("No")
        return

    if n % 4 != 0:
        print("No")
        return

    b = n // 2
    x = (2 + b) // 2
    y = (b - 2) // 2

    if y > 0:
        print("Yes")
        print(x, y)
    else:
        print("No")

if __name__ == "__main__":
    solve()
```第一个分支处理唯一的零情况。 它使用相同的值`x`和`y`，这两个数字都保持正值。 

奇数分支使用因式分解`n = 1 * n`。 计算是用整数除法编写的，因为奇偶校验保证结果是整数。 明确的`y > 0`检查防止无效输出`n = 1`。 

偶数分支拒绝不能被 4 整除的数字。其余值具有因子对`2`和`n/2`。 最终检查删除无效的情况`n = 4`，其中唯一可能的一对需要`y = 0`。 

Python 整数不会溢出，因此直接处理接近上限的值。 重要的边界不是数字溢出，而是确保`y`保持积极的态度。

 ## 边缘情况

 对于`n = 2`，算法进入偶分支。 自从`2`不能被 4 整除，它立即打印`No`。 这避免了使用因素的错误想法`1`和`2`，具有不同的奇偶性。 

为了`n = 4`，算法发现该数字可以被 4 整除，并尝试偶数因子对`2`和`2`。 这给出了`x = 2`和`y = 0`，因此阳性检查会拒绝它。 输出是`No`。 

为了`n = 1`，奇数结构给出`x = 1`和`y = 0`。 该算法检测到第二个值无效并打印`No`。 

为了`n = 0`，该算法不使用因式分解，因为不需要因子对方法。 就直接返回了`x = 1`和`y = 1`，满足：\[
1^2-1^2=0
\]对于较大的值，例如`n = 2^60`，该算法仅执行少量算术运算。 构造值仍低于要求\(2^{62}-1\)限制，因此相同的逻辑在最大输入大小下工作。
