 ## 解决方案
 ## 问题理解

 我们使用以 2 为底的多项式计算来计算数字的表示形式，该多项式的系数仅限于 0 到 7 之间的小数字。具体来说，每个多项式对应于选择系数$a_0, a_1, a_2, \dots$，每个都在 0 到 7 之间，并在以下位置对其进行评估$x = 2$。 这意味着每个多项式都会贡献一个以下形式的值$$P(2) = a_0 + a_1 \cdot 2 + a_2 \cdot 2^2 + \cdots$$所以这个问题就相当于问：我们可以用多少种方式来表达一个数$m$作为两个幂的和，其中每个幂$2^k$可以使用 0 到 7 的多重数吗？ 

输入最多可达$5 \cdot 10^5$的值$m$, 每个最多$10^{18}$。 这立即排除了任何超过大小的每个查询动态编程或位掩码枚举$m$。 即使对每个查询的位数进行线性扫描也是可以接受的，但任何位数的二次或涉及每个查询的卷积都不会通过。 

一个微妙的一点是，这不是标准的二进制表示形式。 在二进制中，2 的每个幂最多出现一次，但这里每个幂最多可以出现 7 次。 这会产生跨位进位，如果我们没有正确处理溢出传播，天真的每位贪婪推理就会失败。 

典型的错误方法是独立对待每个位：对于每个位$m$，选择一个系数$a_i$匹配该位 mod 2 或 mod 8。这会立即中断，因为在位置选择一个系数$i$通过进位影响高位。 例如，如果我们尝试表示$m = 8$，一个简单的方法可能会尝试使用系数 8$2^0$，但这是不可能的，因为系数以 7 为界，因此正确的表示必须涉及进入更高的位置。 

## 方法

 关键的观察是，计算 2 处的多项式相当于将系数解释为以 2 为底的数字，但数字范围为 0 到 7，而不是 0 到 1。因此，我们正在计算有多少种表示方法$m$在混合基数系统中，每个数字都是 0-7，位置权重是 2 的幂。 

如果我们扩展$m$在二进制中，每个位位置都有一个值，我们需要确定该位置和较低位置的系数有多少贡献可以在进位传播后产生该位。 

强力解释将尝试模拟所有系数分配。 由于每个位可以取 8 个值，并且最多有 60 个相关位位置，因此这已经是$8^{60}$，这是完全不可行的。 

关键的见解是该结构是带有有限进位的二进制表示上的数字 DP。 在每个位位置，我们不是跟踪精确的系数分配，而是跟踪将给定进位产生到下一位的方法的数量。 由于每个系数最多为 7，并且我们对 2 的幂求和，因此任何步骤的最大进位都受到一个常数（具体来说小于 8）的限制，这使得 DP 状态保持较小。 

我们从最低有效位到最高有效位处理位，维护每个进位状态可以发生的方式。 每个位都贡献一个转换：我们选择一个从 0 到 7 的系数，将其添加到当前进位加上目标位，并确定下一个进位。 

这将问题转化为最多 60 位且具有恒定大小状态空间的线性 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举系数 | O(8^60) | O(8^60) | O(60) | 太慢了|
 | 具有进位状态的位上的数字 DP | 每次查询 O(60 · 8) | O(8) | 已接受 |

 ## 算法演练

 我们对待二进制表示$m$作为位序列$b_0, b_1, \dots$，并从最不重要到最重要进行处理。 

1. 初始化一个DP表，其中`dp[c]`表示到目前为止处理带有进位值的位的方式数`c`进入当前位。 最初，`dp[0] = 1`。 
2. 对于每个位位置$i$， 提炼$b_i$，并创建一个新的DP表`ndp`。 
3. 对于每一种可能的进位`c`从 0 到 7，并且对于每个系数选择`a`从 0 到 7，计算总和：$$s = c + a$$该值对当前位有贡献，并可能产生进入下一位的进位。 

当前位约束强制：$$s \bmod 2 = b_i$$仅保留有效的组合。 
4. 如果有效，则更新：$$ndp[(c + a - b_i) / 2] += dp[c]$$该方程反映了减去比特贡献并将剩余值向上传播。 
5.处理完所有系数和进位后，替换`dp = ndp`。 
6. 处理完所有位后，答案为`dp[0]`，因为最高有效位之外不应保留任何进位。 

### 为什么它有效

 在每个位位置，DP 都会维护通过给定进位到达该位置的所有方法的完整摘要。 该转换考虑了分配符合当前二进制数字约束的数字 0-7 的所有有效方法。 由于在状态中完全捕获了进位，因此不会丢失任何历史信息。 这确保了每个有效系数分配都被精确地计数一次，并且每个无效分配在违反位约束的最早点被排除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    ms = list(map(int, input().split()))

    # precompute bits up to 60
    MAXB = 61

    for m in ms:
        bits = [(m >> i) & 1 for i in range(MAXB)]

        dp = [0] * 16
        dp[0] = 1

        for b in bits:
            ndp = [0] * 16

            for carry in range(16):
                if dp[carry] == 0:
                    continue
                for a in range(8):
                    s = carry + a
                    if (s & 1) != b:
                        continue
                    nc = s >> 1
                    if nc < 16:
                        ndp[nc] = (ndp[nc] + dp[carry]) % MOD

            dp = ndp

        print(dp[0] % MOD)

if __name__ == "__main__":
    solve()
```该实现直接镜像上述数字DP。 DP 阵列大小经过精心选择，可以安全地容纳进位传播，而不会出现边缘问题。 每次迭代处理一个二进制数字$m$，对于每个状态，我们尝试从 0 到 7 的所有系数值。奇偶校验强制当前位的正确性，同时右移一位计算下一个进位。 

一个常见的陷阱是低估了进位范围。 尽管直观的进位感觉很小，但中间和在减少之前可能会暂时超过 7，因此使用 16 这样的安全上限可以避免静默状态截断。

 ## 边缘情况

 对于$m = 0$，唯一有效的多项式是所有系数都为零的零多项式。 DP 从进位 0 开始，并且从不引入非零贡献，因此最终状态仍然有效并仅产生一种方式。 

对于二的幂，例如$m = 8$，天真的推理会尝试将系数 1 放置在位置 3，但系统也允许较低系数生成向上进位的配置。 DP 通过跨位传播进位状态来正确解释所有这些分解，确保计算所有有效结构而不仅仅是规范的二进制表示。
