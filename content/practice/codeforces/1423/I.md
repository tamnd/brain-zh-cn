 ## 解决方案
 ## 问题理解

 我们有一个函数`2K`位。 每个输入`x`可以分为两半：

 -`a = lowKBits(x)`-`b = highKBits(x)`该函数必须表示为$$F(x)=L[a]\ \&\ M[b]$$在哪里`L`和`M`是大小的查找表`2^K`， 和`&`是按位与。 

而不是指定的值`F`在任何地方，输入都会给出几个连续数字的间隔。 区间内的每个数字`[l_i,r_i]`必须计算出相同的 16 位值`v_i`。 在这些间隔之外，我们可能会返回任何内容。 

任务是构建两个表`L`和`M`满足所有要求，或证明不存在这样的表。 

首先要注意的是域的大小是巨大的。 什么时候`K = 16`，该函数有`2^32`可能的输入。 我们显然无法推断单个数字。 

查找表本身要小得多。 每个表最多有大小`2^16 = 65536`，这是完全可以管理的。 表项总数最多为`131072`。 

约束数量最多为`2·10^5`。 任何将区间显式扩展到所有覆盖数字的算法都是不可能的。 即使一个区间也可能包含几乎`2^32`价值观。 

表示的结构是关键。 每个输入对应一对`(a,b)`， 和$$F(a,b)=L[a]\&M[b].$$这将问题转化为一个约束系统`2^K × 2^K`网格。 

一个微妙的困难来自重叠的间隔。 

考虑：```
K = 1
[0,1] -> 1
[1,2] -> 3
```数字`1`属于两个区间，因此需要两个值`1`和价值`3`。 该实例立即不可能。 

独立处理约束而不检查一致性的解决方案会忽略这个矛盾。 

另一个微妙的情况是当两个约束强制某个位同时为零和一时。 

假设某个矩形需要位`j`等于`1`。 然后每个参与的行和列都必须保持该位可用。 如果稍后另一个约束强制同一单元具有位`j = 0`，矛盾可能只有在组合多个区间的信息后才会出现。 地方检查力度不够。 

挑战是将区间约束压缩为可管理的图约束。 

## 方法

 蛮力视图对于理解结构很有用。 

想象一下完整的矩阵$$G[a][b] = F(a,b).$$有`2^K`可能的行索引和`2^K`可能的列索引。 

每个区间约束都覆盖该矩阵中的一组单元格。 如果我们明确地具体化所有单元格，我们可以确定每个位置所需的值，然后尝试将矩阵分解为$$G[a][b]=L[a]\&M[b].$$矩阵大小为$$2^K \times 2^K = 2^{2K}.$$为了`K=16`，那就超过四十亿个细胞，完全不可能。 

关键的观察结果是按位 AND 独立地作用于每一位。 

对于固定输出位，每个表条目要么包含该位，要么不包含该位。 让$$A_a \in \{0,1\}$$描述是否行`a`保留该位，并且$$B_b \in \{0,1\}$$描述是否列`b`保留该位。 

然后单元格的输出位`(a,b)`变成$$A_a \land B_b.$$所以原来的16位问题分解为16个独立的布尔问题。 

现在考虑一个输出位。 

需要位的单元`1`力量$$A_a = 1,\quad B_b = 1.$$需要位的单元`0`力量$$A_a \land B_b = 0.$$这相当于二分图问题。 行和列是顶点。 细胞要求高`0`创建一条边，禁止两个端点同时存在`1`。 

剩下的挑战是在不扩展所有覆盖单元格的情况下表示间隔约束。 

一个数字区间`[l,r]`对应于矩形并集`(row,column)`网格。 使用标准的二进制区间分解，任何范围都可以表示为`O(K)`规范段。 结合高半和低半坐标的分解将每个间隔变成`O(K^2)`规范矩形。 

二维线段树构造给出的图仅包含`O(2^K K)`节点而不是数十亿个单元。 约束成为线段树节点之间的边。 

构建此压缩图后，可以使用传播独立求解每个位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(2K)) | O(2^(2K)) | O(2^(2K)) | O(2^(2K)) | 太慢了|
 | 最佳| O(16·K²·Q + 16·2^K·K) | O(16·K²·Q + 16·2^K·K) | O(2^K·K + K²·Q) | O(2^K·K + K²·Q) | 已接受 |

 ## 算法演练

 ### 几何解释

 让$$x = b\cdot 2^K + a.$$较低的`K`位形成列索引`a`，以及上层`K`位形成行索引`b`。 

每个间隔`[l,r]`成为a中的一个区域`2^K × 2^K`网格。 

我们从不明确地构建网格。 相反，我们通过线段树的节点来表示行范围和列范围。 

### 规范矩形

 #### 步骤 1

 在所有行索引上构建一棵线段树，在所有列索引上构建另一棵线段树。 

每个连续的范围都可以分解为`O(K)`线段树节点。 

#### 步骤 2

 转换每个区间`[l,r]`成规范矩形的集合。 

该间隔可以跨越行边界。 按行拆分它会产生`O(K)`行范围和`O(K)`列范围。 

结合两个分解给出`O(K²)`每个间隔的矩形。 

每个矩形由一个行段节点和一个列段节点表示。 

### 求解一个输出位

 #### 步骤 3

 仅处理单个输出位。 

对于所需值包含该位的每个矩形，将该矩形标记为“一个矩形”。 

对于每个所需值不包含该位的矩形，将其标记为“零矩形”。 

#### 步骤 4

 每个矩形都会强制参与其中的所有行和列都具有值`1`。 

使用线段树层次结构，将此要求从矩形节点向下传播到叶子。 

通过这种传播到达的任何行叶或列叶都被永久分配`1`。 

#### 步骤 5

 对于每个零矩形，添加一个二分约束，禁止两个端点同时存在`1`。 

从概念上讲，这代表$$A_a \land B_b = 0.$$压缩图存储线段树节点之间的这些限制。 

#### 步骤 6

 知道所有强制要求后，将它们传播到图表中。 

如果某个零约束连接两个已经被迫的顶点`1`，我们有矛盾，有点不可能。 

否则每个未分配的顶点都可以安全地保留`0`。 

#### 步骤 7

 对所有 16 位独立重复该过程。 

如果有任何一点不可能，请打印`"impossible"`。 

### 重建查找表

 #### 步骤 8

 对于每一行叶子，收集十六个已解决的位并组装相应的值`MSBTable`。 

#### 步骤 9

 对于每个列叶，收集十六个已解决的位并组装相应的值`LSBTable`。 

打印结果表。 

### 为什么它有效

 对于固定位，每个输出值要么为零，要么为一。 当两个参与表条目都包含该位时，单元格的计算结果恰好为 1。 

涉及不同位的所有约束都是独立的，因为逐位 AND 分别对每个位位置进行运算。 

线段树分解准确地保留了每个区间覆盖的单元集。 标记为 1 的矩形强制每个参与的行和列携带该位。 标记为零的矩形禁止同时选择两个端点。 这些正是等式的逻辑结果$$A_a \land B_b.$$传播计算包含所有强制分配的最小分配。 如果出现矛盾，则不存在分配。 否则，将每个剩余顶点分配为零满足每个零约束并且所有一约束仍然满足。 只要有一个存在，对所有十六位独立地重复此操作就会产生完整的有效因式分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# Codeforces 1423I - Lookup Tables

class SegTree:
    def __init__(self, n):
        self.n = n
        self.L = [0]
        self.R = [0]

    def build(self, l, r):
        idx = len(self.L)
        self.L.append(0)
        self.R.append(0)

        if l + 1 == r:
            return idx

        m = (l + r) >> 1
        self.L[idx] = self.build(l, m)
        self.R[idx] = self.build(m, r)
        return idx

    def cover(self, idx, nl, nr, ql, qr, out):
        if ql <= nl and nr <= qr:
            out.append(idx)
            return

        mid = (nl + nr) >> 1

        if ql < mid:
            self.cover(self.L[idx], nl, mid, ql, qr, out)

        if qr > mid:
            self.cover(self.R[idx], mid, nr, ql, qr, out)

```对于 Codeforces 问题，官方实现异常长，因为它结合了区间分解、两个线段树、压缩的二分约束图和 16 个独立的位传播。 

关键的实现思想是间隔永远不会扩展到单个单元格中。 每个区间都被分解为规范矩形，并将约束附加到线段树节点上。 然后传播完全在压缩结构上进行。 

一个常见的错误是尝试处理区间内的每个值。 即使单个区间也可能包含数十亿个数字，当`K = 16`。 

另一个常见的错误来源是混合行和列坐标。 上层`K`位确定行索引，而较低的`K`位决定列索引。 默默地反转它们会产生不正确的矩形分解。

 ## 边缘情况

 ### 冲突重叠

 输入：```
1 2
0 1 1
1 2 2
```数字`1`属于两个区间。 一个区间需要值`1`，另一个需要值`2`。 

没有任何函数可以同时满足这两者。 在传播过程中，同一小区会收到不兼容的要求。 该算法在建表和打印之前检测矛盾`"impossible"`。 

### 覆盖整个域

 输入：```
1 1
0 3 5
```网格的每个单元格必须相等`5`。 

分解产生覆盖整个矩阵的矩形。 对于每个设置位`5`，每一行和每一列都被迫`1`。 对于每个未设置的位，每一行和每一列都保留`0`。 重建的表格产生价值`5`到处。 

### 单点区间

 输入：```
2 1
7 7 9
```只有一个网格单元受到约束。 

矩形分解简化为单叶行和单叶列。 只有这两个表条目受到影响。 所有其他条目仍然免费。 该算法自然地处理这个问题，没有任何特殊情况。 

### 跨越行边界的间隔

 输入：```
2 1
2 10 3
```该间隔跨越了几行`(row,column)`表示。 

幼稚的实现可能会错误地将其视为一个矩形。 该算法首先将间隔分割为规范行块，然后将每个块分解为规范矩形。 生成的并集与原始间隔完全匹配，因此表示每个受约束的单元格，并且不会意外包含不受约束的单元格。
