 ## 解决方案
 ## 问题理解

 我们给定一个正整数`c`对于每个测试用例。 我们需要决定是否可以拆分`c`分成两个积极的部分`a`和`b`这样`a + b = c`以及出现在任意位置的所有不同质因数的乘积`a`,`b`， 和`c`小于`c`。 该乘积是根式函数，通常写为`rad`。 该任务只要求存在，所以我们输出`yes`如果至少存在一个有效的分割并且`no`否则。 

的价值`c`可以大到`10^18`，而只有几个测试用例。 这立即排除了迭代可能的值`a`或通过试除法进行保理`sqrt(c)`。 我们需要一种数论观察，将每个测试用例减少到少量操作。 

关键限制来自`c`本身。 由于每个素因数`c`出现在`abc`,`rad(abc)`总是包含`rad(c)`作为一个因素。 如果`c`没有重复的素因数，那么`rad(c)=c`，这已经使得`rad(abc)`至少`c`。 这样的数字永远无法满足所需的不等式。 

剩下的情况是当`c`不是无平方的。 如果素数平方整除`c`，我们可以强制两个被加数都包含重复的素数并使根式足够小。 整个问题简化为检查是否`c`有重复的素因数。 

一个常见的错误是只检查是否`c`是均匀的。 例如，`c=9`有一个解决方案：`3+6=9`， 和`rad(3*6*9)=3<9`。 仅尝试对偶数进行均等分割的解决方案将错误地拒绝这种情况。 

另一个边缘情况是`c=1`。 它根本不能分成两个正整数，所以答案是`no`。 仅检查 squarefreeness 而不处理此问题会错误地接受它，因为`1`是无平方的。 

最终的边界情况是一个大素数，例如`c=10^18+3`如果它是素数的话。 它没有重复因素，因此即使非常大的值也无济于事。 答案取决于因式分解的性质，而不是数字的大小。 

## 方法

 直接的方法是尝试每一种可能的分割`a+b=c`。 对于每个`a`从`1`到`c-1`，我们会计算`b=c-a`， 因素`a*b*c`，并检查根式是否小于`c`。 这是正确的，因为它会检查每个可能的候选者。 然而，对于`c=10^18`可能的分裂数量约为`10^18`，这远远超出了任何合理的运行时间。 

改变问题的观察是`c`本身就已经控制了答案。 每个素数除法`c`必须出现在`rad(abc)`。 如果`c`是无平方的，这些素数正好相乘`c`，使得不平等不可能存在。 

如果`c`包含一个平方因子，假设`p^2`划分`c`。 我们可以选择`a=p`和`b=c-p`。 自从`c`可以整除`p`，两个部分都是正倍数`p`。 写作`c=p*k`，这三个数字包含因式分解模式`p`,`p(k-1)`， 和`pk`。 唯一可能的额外素数来自`k`和`k-1`，它们是连续的，因此互质。 重复因素`c`保证足够的幂隐藏在相同的素数内，使得根式严格小于`c`。 

蛮力之所以有效，是因为它直接搜索有效的分解，但在以下情况下会失败：`c`很大。 结构观察表明，只有平方因子`c`问题将问题简化为检查是否`c`是无平方的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(c * 因式分解(c)) | O(1) | O(1) | 太慢了 |
 | 最佳| O(sqrt(c)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.特殊情况处理`c=1`。 不存在两个正整数其和为`1`，所以答案是立即`no`。 
2. 尝试找到一个素因数`p`的`c`这样`p`划分`c`至少两次。 我们通过检查是否`c`可以整除`p*p`。 找到这样一个主要手段`c`不是无平方的。 
3. 如果找到重复的素因数，则输出`yes`。 上述结构给出了有效的分割。 
4. 如果扫描结束没有找到重复因子，则输出`no`。 该数字是无方的，因此它自己的根式已经等于`c`，阻止任何可能的解决方案。 

这样做的原因是重复素因数的存在正是可能情况和不可能情况之间的分界线。 无正方形`c`迫使每个候选三元组的根式至少为`c`，而非正方形`c`提供可由两个被加数共享的重复因子。 

为什么它有效：

 对于任何有效的分割，所有素因数`c`出现在`rad(abc)`。 因此，如果`c`是无平方的，`rad(abc)`包含每一个素数`c`恰好一次且至少`rad(c)=c`。 不平等不能成立。 

现在假设`c`不是无平方的。 让`p^2`划分`c`，并选择`a=p`,`b=c-p`。 自从`c=p*k`和`p`划分`k`，我们得到`b=p(k-1)`。 的根式是`abc`由素数组成`p`,`k`， 和`k-1`。 因为`k`和`k-1`不共享素因数，重复因数`k`不增加自由基，同时`c`包含一个附加副本`p`。 因此根式严格小于`c`。 

该算法精确地检查这两种可能性，因此它不会返回错误的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(c):
    if c == 1:
        return "no"

    p = 2
    while p * p <= c:
        if c % (p * p) == 0:
            return "yes"
        p += 1

    return "no"

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        c = int(input())
        ans.append(solve_case(c))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```该解决方案检查重复因子而不是显式计算根式。 这避免了处理大型产品，只需要检测素数平方是否能整除`c`。 

循环条件使用`p*p <= c`，这是试分割的标准边界。 如果到目前为止不存在除数，则在不存在更小的匹配因子的情况下，任何更大的因子都不能具有平方贡献。 

Python 整数不会溢出，因此乘法`p*p`即使在附近也很安全`10^18`。 迭代次数是唯一关心的问题，对于给定数量的测试用例，平方根界限将其保持在可管理的范围内。

 ## 边缘情况

 对于`c=1`，算法立即返回`no`因为没有正对可以相加`1`。 无需输入因子搜索。 

对于无平方值，例如`c=30`，算法找不到素数`p`在哪里`p*p`划分`c`。 自从激进的`c`已经是`30`, 一切可能的`rad(abc)`至少是`30`，因此拒绝该值是正确的。 

对于重复的素数，例如`c=25`，算法发现`5*5`划分`25`并返回`yes`。 建设是`a=5`,`b=20`, 给予`rad(5*20*25)=10<25`。 

对于没有重复素因数的大值，该算法从不尝试构建根式分割或枚举分割。 只需要确认不存在平方因子，这正是决定答案的性质。
