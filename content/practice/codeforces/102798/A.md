 ## 解决方案
 ## 问题理解

 该问题描述了桥接助手场景。 有`n`桥两边都是老人。 每个人都必须过桥到对面，花`x`在那里休息几分钟，然后再回来。 你是唯一能够感动他们的人，并且你`t`每次过桥需要几分钟。 一次穿越可以容纳一名老人，而不会增加穿越时间。 任务是找到完成帮助所有人所需的最短总时间`2n`人们。 输入包含多个测试用例，每个测试用例给出`n`, 休息时间`x`，以及穿越时间`t`。 每种情况的输出是可能的最短完成时间。 

约束条件允许`n`,`x`， 和`t`一样大`10^9`，最多可达`10^4`测试用例。 任何用数据结构让人们一一移动或试图搜索时间表的模拟都是不可能的，因为即使`O(n)`每箱可达到`10^13`运营。 解决方案必须将过程减少到恒定数量的算术运算。 

棘手的部分是，答案并不总是只是交叉数乘以`t`。 每个老人在两次穿越之间都必须有足够的时间休息。 粗心的解决方案可能会忽略这个等待期并低估答案。 

例如，考虑：```
1
1 100 1
```总共有两个人。 穿越时间只有一分钟，但休息时间却有一百分钟。 仅计算四个所需交叉点的解决方案给出`4`，这是不可能的，因为至少有一个人必须休息一百分钟。 

另一个边缘情况是当过桥速度比弛豫时间慢得多时：```
1
1 1 100
```正确答案是`400`。 等待时间无关紧要，因为每次过境本身已经比休息时间长得多。 总是增加松弛时间的解决方案会高估答案。 

## 方法

 一种直接的方法是决定所有交叉点的完整顺序。 有`4n`老人过境点总数，因为每一个`2n`人会穿越两次。 尝试所有可能的订单是没有希望的，因为计划的数量呈指数级增长。 即使检查很大一部分可能性也无法在以下情况下工作：`n`达到`10^9`。 

关键的观察是老年人的身份并不重要。 唯一影响答案的是两大群交叉路口之间需要多少不可避免的等待。 

将该过程分为两个阶段。 首先，你帮助每个人到另一边休息。 这正好需要`2nt`时间。 此后，所有人都在等待返程通道，但您可以在开始返程之前选择等待的地点。 

有两个有意义的选择。 您可以在出发的一侧等待再返回，也可以立即穿越并在对面等待。 第一个选择意味着在返回阶段之前有一次额外的穿越，而第二个选择则改变了您等待时间的位置。 评估这两种可能性给出了最小值。 

第一个选项的总时间为：```
2nt + max(2nt, 2t + x)
```第二个选项的总时间为：```
2nt + max(2nt + t, t + x)
```答案是这两个值中较小的一个。 这样做的原因是在第一次之后`2n`交叉口，所有剩余的运动都是对称的。 剩下的唯一决定是单一松弛瓶颈的位置。

 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`x`， 和`t`。 

这些值可能非常大，因此所有计算都必须使用支持周围值的整数类型`10^13`。 
2. 计算第一阶段的时间。 

帮助所有人`2n`人们交叉一次正好需要`2n`交叉口，所以这部分费用`2nt`。 
3. 如果原侧等待完成，则计算结果。 

其余回程口岸也需要`2nt`时间。 先休息的人可能会强制额外延迟`2t + x`，所以这种情况是：```
first_phase + max(2nt, 2t + x)
```4. 计算对方等待的结果。 

在等待之前移动到另一侧会改变一次穿越的成本。 这给出：```
first_phase + max(2nt + t, t + x)
```5. 输出两个值中较小的一个。 

两个表达式都代表完整有效的调度，其中之一始终是最佳的。 

为什么它有效：

 第一个`2n`过马路是不可避免的，因为每个老人在休息之前都至少要过马路一次。 在这些穿越之后，唯一不确定的是第一个完成休息的人何时可以开始下半程旅程。 只有两个可能的地方，可以让帮手度过必要的等待时间，而无需改变所需的老人过路次数。 该算法会检查两个位置，因此它总是选择最佳的时间表。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x, t = map(int, input().split())

    first = 2 * n * t

    option1 = first + max(first, 2 * t + x)
    option2 = first + max(first + t, t + x)

    print(min(option1, option2))

def main():
    tc = int(input())
    for _ in range(tc):
        solve()

if __name__ == "__main__":
    main()
```变量`first`存储了行程中不可避免的前半段，每个老人都会过桥一次。 将此值分开可以避免重复相同的乘法，并使这两种情况更容易验证。 

这两个公式直接对应了帮助者可以花时间等待的两个可能的地方。 这`max`操作是必要的，因为在完成所有必需的穿越或第一个人完成其放松期之前，返回阶段无法完成。 

Python 整数自动处理来自约束的大值，因此不需要特殊的溢出处理。

import sys
import io

def solve_all(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    def solve():
        n, x, t = map(int, input().split())
        first = 2 * n * t
        option1 = first + max(first, 2 * t + x)

    tc = int(input())
    ans = []
    for _ in range(tc):
        ans.append(solve())

    return "\n".join(ans)

 ## 边缘情况

 对于第一个边缘情况：```
1
1 100 1
```第一阶段需要：```
2 * 1 * 1 = 2
```分钟。 第一个选项变为：```
2 + max(2, 2 + 100) = 104
```第二个选项变为：```
2 + max(3, 101) = 103
```答案是：```
103
```该算法正确地将等待时间置于更好的一侧，而不是忽略它。 

对于第二种边缘情况：```
1
1 1 100
```第一阶段是：```
2 * 1 * 100 = 200
```这两个选项是：```
200 + max(200, 201) = 401
200 + max(300, 101) = 500
```最小值是`401`。 较长的过桥时间已经在整个过程中占据主导地位，因此可以避免增加不必要的等待。 

对于最大尺寸的情况：```
1
1000000000 1 1000000000
```该算法从不创建时间表或存储人员。 它仅使用整数运算来计算公式，因此尽管有大量老年人，它仍可以处理输入。
