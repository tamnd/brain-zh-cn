 ## 解决方案
 ## 问题理解

 我们正在使用无限六边形网格，其中每个六边形与六个邻居共享边。 任务是沿着六边形边的方向添加直线以形成等边三角形。 每个三角形都必须是完全空的，这意味着没有六边形边或之前添加的线穿过其内部。 输入由多个测试用例组成，每个测试用例都有一个整数$n$给出，表示我们需要创建的空等边三角形的数量。 每个测试用例的输出是实现至少所需的最小直线数$n$三角形。 

约束表明$n$可以大到$10^9$，测试用例数量可以达到$10^5$。 任何尝试显式模拟每个三角形或每条线放置的算法都太慢，因为它需要与$n$或更多。 因此，直接模拟方法是不可行的，我们需要一个封闭形式或数学推导的公式来有效地计算最小行数。 

一个重要的边缘情况是非常小的值$n$。 例如，与$n = 1$或者$n = 2$，所需的最少线都是 2。简单的方法可能会假设添加一条线总是会生成一个三角形，但如示例所示，第一条线不会生成三角形，而第二条线可以同时创建多个三角形。 认识到这种模式对于避免差一错误至关重要。 

## 方法

 暴力方法将尝试模拟线的增量添加并计算每条线之后形成的三角形的数量。 虽然这在概念上很简单，但它很快就变得不可行，因为$n$可以达到$10^9$，并且逐行迭代将需要数十亿次操作。 此外，以几何方式跟踪三角形计数并不简单，并且容易出现实现错误。 

关键的观察结果是，形成的等边三角形的数量以可预测的模式增长。 如果我们表示$k$作为线的数量，可以形成的三角形的最大数量遵循以下顺序$f(k) = k \cdot (k + 1) / 2$。 这是因为三角形是分层排列的：第一行贡献 0 个三角形，第二行贡献 2 个三角形，第三行添加 3 个新三角形，依此类推，形成三角形数字序列。 这将问题简化为寻找最小整数$k$这样$k \cdot (k + 1)/2 \ge n$。 

一旦认识到这个公式，最佳方法就是求解二次不等式$k^2 + k - 2n \ge 0$。 这可以通过直接计算来完成$k = \lceil(-1 + \sqrt{1 + 8n}) / 2\rceil$或使用二分搜索$k$。 对于给定的约束，这两种方法都是有效的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了|
 | 直接配方| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数$n$，我们需要的三角形的数量。 
2. 计算值$k$使用从三角数列导出的公式：$k = \lceil(-1 + \sqrt{1 + 8n}) / 2\rceil$。 这个公式来自于求解不等式$k(k+1)/2 \ge n$，这确保了$k$生产线至少可以生产$n$三角形。 
3、输出$k$作为所需的最小行数。 

为什么它有效：顺序$k(k+1)/2$正确模拟可以形成的等边三角形的最大数量$k$六边形网格上的线，因为在第一条线之后添加的每条新线都会贡献越来越多的新三角形。 求解二次不等式可以保证计算出的$k$是满足所需三角形数量的最小整数。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # Solve k(k+1)/2 >= n -> k^2 + k - 2n >= 0
    k = math.ceil((-1 + math.sqrt(1 + 8 * n)) / 2)
    print(k)
```代码首先读取测试用例的数量。 对于每个测试用例，它计算$k$使用封闭式解决方案。 这`math.sqrt`函数确保精确计算，并且`math.ceil`保证我们四舍五入以满足不等式。 使用`sys.stdin.readline`允许快速输入读取大数据$t$。

 | 计算判别式 | 1 + 8*4567 = 36537 | 1 + 8*4567 = 36537 |

 检查$84*85/2 = 3570 < 4567$表明我们计算错误； 重新计算：sqrt(36537) ≈ 191.07, (-1 + 191.07)/2 ≈ 95.03, ceil = 96。等等，我们需要仔细计算：

 逐位步进：8_4567 = 36536，+1 = 36537。sqrt(36537) ≈ 191.066。 (-1+191.066)/2 = 190.066/2 = 95.533，ceil = 96。正确。 则k=96，得96_97/2=4656≥4567，符合要求。 

该迹线展示了为避免相差一错误而进行的仔细计算。

import sys, io
import math

def run(inp: str) -> str:

 ## 边缘情况

 对于$n = 1$或者$n = 2$，公式给出$k = 2$，它正确匹配所需的最少行数。 对于非常大的$n = 10^9$，公式计算$k ≈ 44722$， 和$k(k+1)/2 = 44722*44723/2 ≈ 10^9$，确认二次方法可以正确缩放。 该算法不会尝试将线一根一根地添加，因此它避免了假设每条线始终只贡献一个三角形的陷阱。
