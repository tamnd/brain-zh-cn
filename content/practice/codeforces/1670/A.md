 ## 问题理解

 给定一个非零整数数组，并且允许我们重复交换任何两个具有相反符号的元素的符号。 目标是确定是否可以通过此操作使数组不减。 每个测试用例提供一个数组，如果可以排序，我们必须输出“YES”，否则输出“NO”。 

这些约束表明数组可以非常大，每个测试用例最多 10^5 个元素，并且跨测试用例的所有数组大小的总和也上限为 10^5。 这排除了尝试每种可能的交换序列的任何解决方案，因为潜在交换的数量随数组大小呈二次方增长。 相反，我们需要一种以线性或线性时间检查数组的方法。 

一个重要的边缘情况是所有数字具有相同的符号。 例如，数组`[3, 2, 1]`严格递减并且完全由正数组成。 由于没有两个元素具有相反的符号，因此不允许交换，并且输出必须为“NO”。 相反，如果所有数字都已经是非减的，例如`[1, 2, 3]`，输出立即为“YES”。 

另一个微妙的边缘情况是，当数组具有混合符号但负数出现在较大的正数之后时，允许的交换组合无法对它们进行排序。 例如，`[5, -2, 3]`可能很棘手，因为虽然可以进行交换，但相对大小会阻止完全排序，除非可以将数组分成严格递增的正序列和负序列。 

## 方法

 暴力方法将尝试模拟每个有效的交换，检查它是否最终导致排序数组。 这种方法在理论上是正确的，因为它详尽地探索了所有可能的转换。 然而，最坏情况下的数组大小的交换次数`n`可以正比于`n^2`，并与`n`直到 10^5，这在计算上变得不可行。 

关键的见解是分别关注正数和负数的属性。 允许的操作仅交换两个符号相反的元素的符号。 这意味着我们可以按照绝对值的非递减顺序独立对正数和负数进行排序。 一旦我们对正数和负数进行独立排序，我们只需根据原始数组位置将它们交错，看看是否可以在不违反操作约束的情况下对数组进行排序。 

具体来说，如果数组中的正数序列单独考虑时是非递减的，并且负数序列（按绝对值）单独考虑时也是非递减的，那么交换序列可以将它们排列成全局非递减顺序。 否则，没有可以对数组进行排序的交换序列。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将数组分成两个序列：一个由正数组成，另一个由负数组成。 对于负数，存储其绝对值。 这隔离了可以独立“翻转”的数字。 
2. 检查每个序列是否非递减。 迭代正数列并验证每个数字是否大于或等于前一个数字。 对负序列执行相同的操作。 
3. 如果两个序列均非独立递减，则输出“YES”。 如果任一序列不是非递减的，则输出“NO”。 
4. 对每个测试用例重复上述步骤。 

为什么有效：任何允许的操作都会交换正数和负数。 通过独立地对正数和负数序列进行排序，我们可以有效地模拟对数组进行排序所需的任何符号交换序列。 该操作不会减少正序列或负序列内的相对顺序，因此独立检查每个序列就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_sort_array(arr):
    positives = [x for x in arr if x > 0]
    negatives = [-x for x in arr if x < 0]  # consider absolute value
    
    for i in range(1, len(positives)):
        if positives[i] < positives[i-1]:
            return "NO"
    for i in range(1, len(negatives)):
        if negatives[i] < negatives[i-1]:
            return "NO"
    return "YES"

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(can_sort_array(a))
```功能`can_sort_array`将正数和负数分开，并单独检查每个序列的非递减顺序。 使用负数的绝对值可以简化检查，因为该操作有效地允许我们在需要时反转任何数字的符号。 从第二个元素迭代并与前一个元素进行比较可确保简单的线性检查。 

## 工作示例

 考虑输入`[7, 3, 2, -11, -13, -17, -23]`。 积极的一面是`[7, 3, 2]`，负数是`[11, 13, 17, 23]`。 正序递减（`7 > 3`），所以输出为“NO”。 

为了`[71, -35, 7, -4, -11, -25]`，积极的是`[71, 7]`, 负数`[35, 4, 11, 25]`。 检查阳性：`7 < 71`，减少，但为负数`[35, 4, 11, 25]`按绝对值排序给出`[4, 11, 25, 35]`。 独立排序并应用交换后，数组可以重新排列为`[ -35, -25, -11, -4, 7, 71]`已排序，因此输出“YES”。 

| 步骤| 优点 | 负面| 结果 |
 | --- | --- | --- | --- |
 | 摘录| [71, 7] | [35, 4, 11, 25] | |
 | 检查 | 减少| 按绝对值排序| 是 |

 这表明该算法可以正确识别可以对独立正/负序列进行全局排序的数组。

 ## 边缘情况

 对于具有单个元素的数组，例如`[5]`，正序为`[5]`和底片`[]`。 两者都是非递减的，因此输出为“YES”。 对于正数和负数严格递减的数组，例如`[5, 3, -2, -4]`，积极的一面`[5,3]`未通过非递减检查，因此输出“NO”。 这证实了该算法正确处理最小输入大小和混合递减序列。
