 ## 解决方案
 ## 问题理解

 我们需要构建一个给定长度的整数数组。 唯一的要求是每对不同的位置都有一个质数作为其总和。 值本身只需保持在允许的范围内，并且接受任何有效的构造。 

关键的困难在于该条件适用于每一对元素，而不仅仅是相邻元素。 对于大型数组，检查所有对将涉及太多操作，因此解决方案必须以属性显而易见的方式创建数组，而无需测试每个对。 

长度可以达到$2 \cdot 10^5$，并且测试用例的总长度具有相同的界限。 这排除了任何比较对的方法，因为这需要$O(n^2)$工作。 即使一个包含 200000 个元素的测试用例也会创建大约 200 亿对，这无法满足时间限制。 我们需要一种在输出大小上只需要线性时间的构造。 

棘手的情况来自奇偶校验。 粗心的构造可能会意外地创建一个总和大于 2 的偶数对，而该对永远不可能是素数。 例如，一个带有输入的数组`3`无法构建为`2 4 6`，因为这对`2 + 4 = 6`不是素数。 正确的输出可以是：```
3
```生产：```
1 1 2
```总和是`1 + 1 = 2`,`1 + 2 = 3`， 和`1 + 2 = 3`，都是素数。 

另一个边缘情况是允许的最小长度。 对于输入：```
2
```该数组只有一对需要满足。 像这样的构造：```
1 2
```有效，因为唯一的总和是`3`。 假设必须有多个相等值的解决方案仍然需要处理这种情况。 

## 方法

 直接方法会尝试生成一些数字并验证所有对和。 验证很简单：对于每对索引，计算总和并测试它是否是素数。 问题是对的数量。 为了$n$元素有$\frac{n(n-1)}{2}$对，这变成了关于$2 \cdot 10^{10}$什么时候$n=200000$。 即使在考虑主检查之前，这也太慢了。 

有用的观察来自于对奇偶性的观察。 除 2 之外的任何素数都是奇数。 如果两个数具有相同的奇偶性，则它们的和为偶数。 这意味着两个偶数不能一起出现，因为它们的和将是大于 2 的偶数。两个奇数只有当它们的和恰好为 2 时才有效，这意味着两个数必须都是 1。 

这留下了一个非常简单的结构。 我们可以放尽可能多的`1`正如我们想要的，因为每一对`1`s 给出素数 2。我们可以恰好添加一个偶数，因为它只需要与 1 形成素数和。 选择`2`有效是因为`1 + 2 = 3`，这是素数。 

最终的数组始终是一个序列`n - 1`后面跟着一个`2`。 该构造不需要任何搜索、素性测试或特殊处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳| O(n) | 除了输出 | O(1) 已接受 |

 ## 算法演练

 1.读取需要的数组长度`n`。 
2. Create`n - 1`值的副本`1`。 这些元素中的任何两个总和为`2`，这是素数。 
3. 附加一个最终值`2`。 每个涉及该值和a的总和`1`变成`3`，这也是素数。 
4. 输出构造好的数组。 

这种结构起作用的原因是它避免了所有危险的配对。 唯一重复的值是`1`，唯一的偶数值为`2`，因此没有一对可以创建偶数合数。 

为什么它有效：不变的是生成的数组中的每一对都是两个`1`一个或一个`1`和一个`2`。 第一种情况总是给出总和`2`，第二种情况总是给出总和`3`。 由于两个值都是素数，因此每个可能的值都满足条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append(" ".join(["1"] * (n - 1) + ["2"]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```代码直接遵循算法的构造。 对于每个测试用例，它准确地创建`n - 1`并添加一个最后的`2`。 

完全避免了强力解决方案所需的乘法或素数逻辑。 该数组在构造时是有效的，因此程序只花时间创建所需的输出。 

列表大小由控制`n`，并且 Python 整数很容易足够大，因为最大的打印值仅为`2`。 除了确保 1 的数量准确无误之外，没有任何索引决策或边界计算会因一个错误而引入错误。`n - 1`。

 ## 边缘情况

 对于`n = 2`，该算法创建一个`1`和一个`2`:```
Input:
1
2
```输出是：```
1 2
```只有一对，它的和是`3`。 该构造不依赖于拥有多个副本`1`，因此自然会处理最小的输入。 

对于大量元素，例如：```
1
6
```输出是：```
1 1 1 1 1 2
```前五个元素中的每一对都给出`2`，每对包含最后一个元素的给出`3`。 该算法永远不会创建两个偶数，这避免了常见的奇偶校验错误。 

对于具有多个相等值的数组，例如：```
1
5
```结果是：```
1 1 1 1 2
```幼稚的实现可能会认为重复是危险的，但重复的值`1`这正是构建工作的原因，因为两个副本加起来就是最小的素数。
