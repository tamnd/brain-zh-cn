 ## 解决方案
 ## 问题理解

 我们得到了一个排列，这意味着每个数字`1`到`n`恰好出现一次。 操作采用当前数组的某些前缀，反转该前缀，然后将整个修改后的前缀移动到数组的末尾。 任务不是最小化操作数量。 我们最多只需要打印一个序列`2n`将排列转换为递增顺序的前缀长度。 

输入包含多个测试用例。 对于每个测试用例，数组表示数字的当前顺序。 输出是前缀长度的列表，按顺序应用这些操作必须将数组保留为`[1, 2, ..., n]`。 

总和`n`所有测试用例最多是`5000`。 二次解是可以接受的，因为元素总数很少。 我们可以花`O(n^2)`重复找位置的时间，但是模拟许多不必要操作的解决方案如果超过了，仍然会失败`2n`操作限制。 主要的挑战不是速度，而是发现有保证界限的构造。 

一个常见的错误是认为这是正常的排序，并尝试将元素逐个放入最终位置，同时保持固定的前缀或后缀。 这是行不通的，因为每个操作都会改变整个数组的前面。 例如，关于`[1, 4, 2, 3]`，固定后`4`最后进行了本地操作，以后的操作可以再次移动它。 该构造必须使用操作的全局旋转行为。 

另一个边缘情况是已经排序的排列。 对于输入：```
1
5
1 2 3 4 5
```正确的输出是零运算。 始终执行最终旋转的解决方案仍然有效，但不必要的工作会使推理变得复杂。 

第二个边缘情况是`n = 1`。 数组已排序，无需执行任何有用的操作。 正确的输出是：```
0
```如果实施不小心，尝试无条件添加轮换步骤可能会创建无效的前缀长度。 

## 方法

 暴力方法会尝试搜索可能的操作序列。 对于排列的每个状态，有`n`可能的移动，可能的排列数是`n!`。 即使使用记忆化，这也很快变得不可能，因为状态空间呈阶乘增长。 操作限制还意味着不需要直接通过搜索找到任何有效序列。 

关键的观察结果是，将数字按升序排列到前面会产生可预测的循环排列。 假设我们处理这些值`1, 2, ..., n - 1`。 当值`x`尚未在前面，选择紧接之前结尾的前缀`x`动作`x`到前面。 这是有效的，因为未触及的后缀以`x`，而所选前缀则相反并移到其后面。 

对所有值执行此操作后`n - 1`，排列没有完全排序，但它有一个非常具体的形式：```
[n - 1, n, 1, 2, ..., n - 2]
```这是排序数组的旋转。 两个带有前缀长度的操作`1`将此序列旋转回排序顺序。 整个建筑最多使用`n - 1 + 2 = n + 1`操作，安全地低于`2n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n) | O(n! * n) | O(n!) | 太慢了|
 | 建设性的前楼| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 从空的操作列表开始。 我们将通过按升序将值移至前面来构建答案。 
2. 对于每个值`x`从`1`到`n - 1`, 找到其当前位置`p`。 

如果`p`不是第一个位置，应用带前缀长度的操作`p - 1`。 之前的元素`x`被移动到它的后面，所以`x`成为第一个元素。 如果`x`已经是第一个了，不需要任何操作。 
3. 处理完所有值后`1`到`n - 1`，应用前缀长度的操作`1`两次。 

每个前缀长度`1`操作将第一个元素移到后面。 剩余的轮换从`[n - 1, n, 1, ..., n - 2]`到`[1, 2, ..., n]`。 

为什么有效：处理后的价值`x`，该值被放置在稍后将处理的所有值之前。 因此，前面选定值的序列是按升序构建的，但由于每个操作也会旋转数组，因此最终的排列是已排序排列的单个循环移位。 最后两次旋转正好消除了这种转变。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(a):
    n = len(a)
    ans = []

    for x in range(1, n):
        p = a.index(x) + 1
        if p > 1:
            k = p - 1
            ans.append(k)
            a[:] = a[k:] + a[:k][::-1]

    if n > 1:
        ans.append(1)
        a[:] = a[1:] + a[:1]
        ans.append(1)
        a[:] = a[1:] + a[:1]

    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        ans = solve_case(a)

        out.append(str(len(ans)))
        if ans:
            out.append(" ".join(map(str, ans)))
        else:
            out.append("")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```该实现保留当前排列，因为构造取决于每个值的当前位置。 自从总共`n`只是`5000`， 使用`list.index`找到每个值的速度足够快。 

每个选定操作之后的模拟只是为了在构建答案时保持当前状态。 该操作本身是作为删除第一个来实现的`k`元素，反转它们，并将它们放置在剩余后缀之后。 Python 切片直接处理这个问题。 

最后两个操作仅在以下情况下添加`n > 1`。 对于单元素数组，排列已经排序，并且除以下之外没有有效的前缀长度`1`存在，因此避免这些操作可以保持边界情况干净。

 ## 边缘情况

 对于已经排序的排列，例如：```
1
5
1 2 3 4 5
```每个值来自`1`到`n - 1`处理时已经在前面了，所以不添加任何操作。 由于仅需要最后两次旋转来修复第一阶段创建的循环移位，因此它们被省略，因为阵列从未进入该移位状态。 

对于单个元素：```
1
1
1
```不执行值循环，并且跳过最后的旋转步骤，因为没有可使用的有意义的前缀长度。 答案包含零运算。 

对于最小值最初不在前面附近的情况，如：```
1
5
5 3 1 4 2
```该算法找到的位置`1`，将其移到前面，然后继续`2`,`3`， 和`4`。 第一阶段保证最终状态是排序序列的旋转，因此最后两个前缀长度`1`操作无需任何特殊处理即可完成排序。
