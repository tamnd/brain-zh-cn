 ## 解决方案
 ## 问题理解

 我们有一个`n`经过`m`网格。 路径从左下角单元格开始，并且必须在右上角单元格结束。 每次移动时，路径可能会向上移动一个单元格、向左移动一个单元格或向右移动一个单元格。 它永远不会下降，也永远不会两次踩到一个细胞。 任务是计算存在多少条不同的有效路径，并将答案取模`998244353`。 

移动规则的重要部分是行数只能减少。 一旦路径向上移动离开一行，它就永远不会返回到该行。 这意味着每一行都可以独立考虑，从一行传递到下一行的唯一信息是路径向上移动的列。 

约束条件允许`n`和`m`最大为 100，有很多测试用例。 探索每条路径的解决方案是不可能的，因为路径的数量呈指数增长。 我们需要找到一个数学模式并直接计算它。 由于答案只涉及幂和模运算，`O(n)`或者`O(log n)`解决方案就足够了。 

一个常见的错误是认为路径在到达柱子后被迫直线向上移动。 例如，在一个`2 x 3`网格，答案不是 1。最底行可以从起始列 0 移动到第 0、1 或 2 列，然后再向上移动，给出 3 条路径。 

另一个错误是允许路径在行内反转。 例如，从一行中的第 0 列开始，移动到第 2 列，然后返回到第 1 列是无效的，因为第 1 列已经被访问过。 每一行访问过的单元格必须形成一个连续的段。 

## 方法

 蛮力的想法是模拟每条可能的路径。 从每个访问的单元格中，我们尝试每一个允许的移动，并在到达目标或卡住时停止。 这是正确的，因为它直接遵循有效路径的定义。 

问题是选择的数量呈爆炸式增长。 一条路径可以在每一行中做出许多水平选择，并且可能的路径数量随着网格尺寸呈指数增长。 即使是小网格也会很快创建太多的递归分支。 

关键的观察结果是行内路径的行为很简单。 当路径进入一行时，它位于某列`x`。 向上移动之前，可以选择任意列`y`在那一行作为它离开的地方。 之间的细胞`x`和`y`作为一个连续的水平段被访问。 不可能有其他形状，因为改变水平方向需要重新访问单元格。 

对于除顶行之外的每一行，离开的列可以是以下任意列`m`列。 底行从第 0 列开始，但仍然有`m`它可以离开的可能的列。 接下来的行的行为方式相同。 最上面一行不需要选择，因为一旦输入，路径只会水平移动，直到到达右上角的单元格。 

有`n - 1`我们选择退出列的行，每个选择都有`m`的可能性。 因此路径总数为`m^(n-1)`。

 | 蛮力 | 指数| O(nm) 递归堆栈 | 太慢了|
 | 最佳| O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`m`对于当前网格。 该路径在除最后一行之外的每一行中都可以选择退出列，因此我们需要计算`m`上升到权力`n - 1`。 
2. 计算`m^(n-1)`使用模幂。 指数在输入大小上可能很大，因此重复乘法不是预期的方法。 
3. 输出计算值取模`998244353`。 

为什么它有效：

 每个行转换都由路径向上的列完全描述。 输入一行后，选择任何退出列都会产生恰好一个有效的水平段，并且每个有效段恰好对应于一个退出列。 由于行是独立的并且顶行没有转换选择，因此可能的路径数是以下的乘积`m`选择超过`n - 1`行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    data = input().split()
    if not data:
        return
    t = int(data[0])
    ans = []
    idx = 1
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx + 1])
        idx += 2
        ans.append(str(pow(m, n - 1, MOD)))
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该实现使用 Python 内置的模幂运算。 这`pow(base, exponent, mod)`form 执行二进制求幂，因此只需要对数次运算。 

指数是`n - 1`因为底行及其上面的每一行直到顶行都需要决定向上移动的位置。 顶行仅完成路径并且不贡献额外的分支。 

没有边界检查或模拟，因为证明已经将问题简化为计算选择。 在求幂过程中应用模数以避免较大的中间值。

 ## 边缘情况

 对于一个`2 x 3`网格，一种天真的方法可能会认为只有一条路径，因为在选择最短路线后，起点和终点在同一列中垂直对齐。 该算法发现底行可以在三列中的任何一处退出，因此它计算`3^(2-1) = 3`。 

对于只有一列的网格，例如`5 x 1`，唯一可能的运动是向上。 公式给出`1^(5-1) = 1`，匹配单个有效路径。 

对于大型网格，例如`100 x 100`，枚举路径是不可能的。 该算法根本不创建路径，它仅使用模幂来评估独立列选择的数量。
