 ## 解决方案
 ## 问题理解

 我们被要求重建一个数字排列`1`到`n`给定一个部分已知的数组，称为`next`。 每个元素`next[i]`代表最小的索引`j`大于`i`这样`p[j] > p[i]`。 如果没有这样的`j`存在，`next[i]`设置为`n+1`。 如果`next[i]`是不可读的，它是`-1`。 

任务是找到与给定一致的任何排列`next`数组，或者确定不存在这样的排列。 这是一个建设性的问题，我们不被要求计算可能性，而是产生一个有效的排列。 

限制很大：`n`每个测试用例最多可达 500,000 个，总和`n`所有测试用例总数为 500,000。 这排除了任何算法`O(n^2)`复杂。 理想情况下，我们需要每个测试用例接近线性时间`O(n)`或者`O(n log n)`。 

非明显的边缘情况包括：

 1. 全部`next[i] = -1`。 在这种情况下，任何排列都是有效的。 
2.`next[i] = i + 1`反复。 这迫使子序列严格递增。 
3.一些`next[i]`价值观相互矛盾，例如，`next[1] = 3`和`next[2] = 2`。 不存在有效的排列。 

一种幼稚的方法可能会尝试尝试所有排列，但是`n!`可能性，这是不可行的。 我们需要一种贪婪的或结构化的方法来使用约束`next`高效阵列。 

## 方法

 暴力方法会尝试所有排列并检查`next`大批。 这是`O(n!)`并且不可能为`n`最多 500,000。 

观察问题，我们发现`next[i]`本质上编码了一组约束：`p[i] < p[next[i]]`。 如果我们将这些视为有向边`i`到`next[i]`（如果`next[i] != -1`），我们可以将排列视为满足一系列递增序列。 一个关键的见解是两个定义之间`next`索引，值可以按降序填充而不违反约束，因为最左边的值必须小于由定义的序列中最右边的值`next[i]`。 

我们可以从左到右贪婪地处理数组，使用堆栈来维护当前打开的序列（类似于构造下一个更大的元素序列）。 当一个`next[i]`定义后，我们必须确保将最高的可用数字分配给序列中的最后一个位置，以满足“下一个更大”的要求。 对于没有限制的职位（`-1`），我们可以在剩余的可用值内任意填写数字。 

这种方法将问题简化为迭代数组一次，跟踪开放序列，并在每个序列内按降序分配数字。 结果是`O(n)`每个测试用例，这是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 贪婪/基于堆栈| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一组可用数字`1`到`n`。 我们将从这组中分配号码。 
2. 迭代自`n`下降到`1`。 我们从末尾开始处理，因为最大的数字必须到达没有定义的位置`next`或者是“序列”中的最后一个`next`。 
3. 维护一个堆栈，代表等待右侧更大数字的位置。 对于每个索引`i`， 如果`next[i]`被定义并且`next[i] > i+1`, 推动位置`i`到`next[i]-1`到堆栈上为它们分配降序值。 
4. 对于以下职位：`next[i] = -1`或者`next[i] = i + 1`，分配下一个最大的可用数字。 这满足了所有限制，同时最大限度地提高了灵活性。 
5. 循环结束后，如果有任何数字不能在不违反规定的情况下赋值`next`， 返回`-1`。 
6. 否则，输出构造的排列。 

不变的是每个序列`i`到`next[i]-1`按严格递减顺序填充，确保`p[i] < p[next[i]]`。 这样就保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        nxt = list(map(int, input().split()))
        perm = [0] * n
        stack = []
        available = list(range(n, 0, -1))  # largest first
        
        possible = True
        i = 0
        while i < n:
            if nxt[i] == -1 or nxt[i] == n+1:
                perm[i] = available.pop(0)
                i += 1
            else:
                length = nxt[i] - i
                if length <= 0:
                    possible = False
                    break
                if len(available) < length:
                    possible = False
                    break
                for j in range(length):
                    perm[i+j] = available.pop(0)
                i += length
        
        if possible:
            print(" ".join(map(str, perm)))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```该代码通过首先分配最大的可用数字来维护贪婪不变量，以确保“下一个更大”关系成立。 为了`-1`位置，我们从剩余的最大的开始按顺序分配数字。 边界检查确保不会尝试负长度子序列，否则会表明存在矛盾。

 ## 边缘情况

 全部`-1`：任何排列都有效。 算法分配降序数字，这很容易满足空约束。 

Next[i] = n+1：最大的数字转到没有定义下一个的位置； 该算法通过将它们视为不受约束来处理此问题。 

自相矛盾`next`： 如果`next[i] <= i`，算法立即标记为不可能，因为子序列的长度为非正数。 

稀疏已知值：只有一些`next[i]`定义的。 该算法正确填充序列，留下`-1`剩余数量最多的位置。 

这涵盖了所有场景并确保解决方案稳健。
