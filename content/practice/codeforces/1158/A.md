 ## 解决方案
 ## 问题理解

 我们有一个聚会$n$男孩和$m$女孩们。 每个男孩给每个女孩一定数量的糖果，形成一个$n \times m$整数矩阵。 对于每个男孩，他给任何女孩的最小糖果数量指定为$b_i$。 对于每个女孩，她从任何男孩那里收到的糖果的最大数量指定为$g_j$。 我们的任务是重建一个合理的糖果分配，满足所有这些约束，同时最小化分发的糖果总数。 如果无法满足约束条件，我们必须输出$-1$。 

输入尺寸很大，可达$10^5$适合男孩和女孩，每个甜蜜数最多$10^8$。 这意味着任何显式迭代所有的解决方案$n \cdot m$矩阵条目可能太慢，因为$10^5 \cdot 10^5 = 10^{10}$操作将是令人望而却步的。 该解决方案必须依靠巧妙的聚合或排序来避免完整的矩阵遍历。 

当男孩中最大的最小甜度超过女孩中最小的最大甜度时，就会出现微妙的边缘情况。 例如，考虑$b = [5, 1]$和$g = [4, 6]$。 第一个男孩必须至少给出$5$糖果给某人，但没有一个女孩能收到超过$4$来自任何人。 这种配置是不可能的，并且在不检查可行性的情况下贪婪地填充矩阵的幼稚方法将悄无声息地失败。 

当多个男孩共享与女孩的最大甜度相同的最小甜度值时，会出现另一种边缘情况。 分布必须仔细地将最大的最小值分配到适当的列，以匹配女孩的最大值。 

## 方法

 蛮力方法将尝试构建整个$n \times m$明确矩阵。 我们将分配值以满足$b_i$对于每一行和$g_j$对于每一列。 人们可以尝试一项贪婪的任务：对于每个男孩，首先填满他最小的糖果$b_i$遍历所有女孩，然后尝试调整某些条目以匹配女孩的最大值。 虽然原则上是正确的，但这种方法$O(n \cdot m)$复杂性，这是不可行的$n, m$最多$10^5$。 

关键的见解来自于观察，每个男孩的最小糖果必须出现在他的行中的某个位置，每个女孩的最大糖果必须出现在她的列中的某个地方。 为了最小化总和，我们应该用行最小值填充尽可能多的条目，仅增加值以满足列最大值。 排序$b$和$g$允许我们将男孩的最大最小值与女孩的最大最大值对齐，以满足最小增量的约束。 

具体来说，如果最大的男孩最小值等于最小的女孩最大值，我们必须将其分配给那个女孩； 所有其他行的最低金额都可以分配给其他女孩，而无需增加不必要的金额。 这将问题简化为一些算术运算，而不是迭代整个矩阵。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n * m) | 太慢了|
 | 最佳 | O(n log n + m log m) | O(n log n + m log m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对数组进行排序$b$男孩的最小值和$g$女孩马克西玛的肖像。 让$b_{\text{max}}$是最大的男孩最小并且$b_{\text{second}}$第二大。 让$g_{\text{min}}$成为最小的女孩最大。 
2.如果$b_{\text{max}} > g_{\text{min}}$，情况不可能，输出$-1$。 
3. 将总和初始化为所有的总和$b_i$乘以$m$，因为每个男孩至少给每个女孩至少他的最低限度。 
4. 将各项之间的差值加到总和中$g_j$和$b_{\text{max}}$对于每个女孩，除了将收到的女孩$b_{\text{max}}$，因为每个女孩都必须在某个地方达到自己的极限。 
5.最后添加$b_{\text{max}} - b_{\text{second}}$如果最大的男孩最小值小于最大的女孩最大值，则为总和。 这说明了达到最大女孩的最大数量所需的额外糖果，同时保持最少的总和。 

不变量是每个男孩至少向每个女孩贡献他的最小糖果，并且每个女孩恰好收到一次最大糖果。 该算法确保不违反行或列约束，同时最大限度地减少额外的糖果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
b = list(map(int, input().split()))
g = list(map(int, input().split()))

b.sort()
g.sort()

if b[-1] > g[0]:
    print(-1)
    sys.exit()

total = 0
# sum of all minimal contributions
total += sum(b) * m

# add difference for each girl
for j in range(m):
    total += g[j] - b[-1]

# adjust for the largest boy if needed
if b[-1] < g[0]:
    total += b[-1] - b[-2]

print(total)
```第一步对数组进行排序，以轻松找到最大值和最小值并检查可行性。 将行最小值之和乘以$m$确保所有最低限度的贡献都被计算在内。 通过每个女孩的最大值和最大的男孩最小值之间的差异进行调整可确保满足每个列约束。 最终调整处理最大男孩最小值严格小于最大女孩最大值的情况。

def run(inp: str) -> str:
