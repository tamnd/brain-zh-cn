 ## 解决方案
 ## 问题理解

 我们有一个无限的二维网格，最初在原点有一个黑色单元格`(0, 0)`。 我们执行一系列扩展操作，每个操作要么输入“4”，要么输入“8”。 类型“4”扩展将所有正交相邻单元变黑，类型“8”扩展将所有正交或对角相邻单元变黑。 给定一个目标细胞`(x, y)`和一系列的扩展，我们必须确定目标单元格是否变黑。 

约束条件允许`n`最多`2*10^5`所有测试用例和坐标最多`10^9`。 显式模拟网格是不可能的，因为网格是无限的并且坐标是巨大的。 这立即排除了任何更新单个单元或存储整个网格状态的解决方案。 相反，我们必须对黑细胞的扩散进行几何推理。 

边缘情况包括负坐标和仅沿一个方向移动的扩展。 例如，如果字符串全部为“4”扩展，则对角单元格`(1,1)`永远不会变黑，但如果序列中有“8”，它就会变黑。 另一个微妙之处是扩展的顺序：即使序列中的单个“8”也可以到达较长的“4”序列无法到达的单元格。 

## 方法

 暴力解决方案很简单：维护一组黑色单元并为每个操作更新它。 对于“4”，我们将每个黑色单元的四个邻居相加； 对于“8”，我们添加所有八个邻居。 处理完所有操作后，我们检查是否`(x, y)`是在集合中。 这种方法原则上有效，但细胞数量呈指数增长，因此`n`大约`10^5`这变得不可行。 

关键的见解是黑色区域以可预测的几何图案生长。 正交扩展每步将距原点的曼哈顿距离增加 1，而对角扩展则增加切比雪夫距离（最大值`|x|`和`|y|`) 乘以 1。因此，问题简化为计算是否`(x, y)`应用组合扩展后，位于以原点为中心的菱形或正方形内。 

我们不需要追踪每个黑细胞。 我们只需要找到序列中的第一个“8”，因为这会将增长转化为切比雪夫度量，之后任何剩余的扩展都可以被认为是均匀扩展平方。 如果没有“8”，则覆盖的最大曼哈顿距离是“4”的数量。 使用它，我们可以在每个测试用例的恒定时间内检查单元格。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(8^n) | O(8^n) | O(黑色单元格数量) | 太慢了|
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，解析`n`,`x`,`y`，和字符串`s`。 
2. 检查原产地是否`(0, 0)`是目标。 如果是，则返回`YES`。 
3. 确定“8”第一次出现在`s`。 设其索引为`k`（从 0 开始）。 在这个索引之前，所有扩展都是“4”，并且每次将曼哈顿距离增加1。 
4. 计算曼哈顿距离`d = |x| + |y|`距离原点的目标。 
5. 如果没有“8”`s`，检查是否`d <= n`。 如果是，则可以通过正交移动到达该单元格； 否则，它不能。 
6.如果该位置至少有一个“8”`k`，然后之后`k`“4”区域是曼哈顿半径的菱形`k`。 “8”将度量转换为切比雪夫距离，因此其余步骤允许任何具有切比雪夫距离的单元格`<= remaining_length`从目前的钻石可以达到。 
7. 利用切比雪夫距离的性质`max(|x|, |y|)`，检查是否`max(|x|, |y|) <= total_expansions`。 如果是，则返回`YES`; 否则，`NO`。 

保证正确性的不变量是黑色区域的单调增长。 除非出现“8”，否则曼哈顿扩展无法到达仅对角线的单元格，并且在“8”之后，该区域根据切比雪夫距离在所有方向上均匀扩展。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x, y = map(int, input().split())
    s = input().strip()
    
    if x == 0 and y == 0:
        print("YES")
        continue
    
    first8 = s.find('8')
    
    if first8 == -1:
        # all '4's, check Manhattan distance
        if abs(x) + abs(y) <= n:
            print("YES")
        else:
            print("NO")
    else:
        # the first '8' occurs at index first8
        # after that, Chebyshev distance matters
        # maximum of |x|, |y| must be <= n
        if max(abs(x), abs(y)) <= n:
            print("YES")
        else:
            print("NO")
```我们首先处理目标是原点的简单情况。 然后我们找到字符串中的第一个“8”来识别对角线扩展何时开始。 如果不存在“8”，我们只需要曼哈顿距离来检查可达性。 如果有“8”，则可以到达总步数内具有最大坐标的任何单元格。 使用`find`绝对值比较也确保负坐标的正确性。

输入样本`(4 5 1, 4884)`:

 | 步骤| 运营| 目标| 距离检查 | 结果 |

 | 0 | 初始| (0,0) | (0,0) | - | 是 |

 第一个“8”出现较晚，因此前面的“4”无法达到目标。 剩余的“8”不足以走完总步数内的距离。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())
        s = input().strip()
        if x == 0 and y == 0:
            output.append("YES")
            continue
        first8 = s.find('8')
        if first8 == -1:
            output.append("YES" if abs(x)+abs(y) <= n else "NO")
        else:
            output.append("YES" if max(abs(x), abs(y)) <= n else "NO")
    return "\n".join(output)
