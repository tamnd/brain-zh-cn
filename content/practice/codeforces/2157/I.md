 ## 解决方案
 ## 问题理解

 在《Hyper Smawk Bros》中，两名玩家轮流攻击拥有生命值的 Boss`n`。 每次攻击都会使生命值减少整数伤害`x`之间`1`和`m`。 问题是，在你的回合中，你无法重复对手在上一回合中所造成的伤害。 你先走，目标是确定当双方都发挥最佳状态时你是否能保证获胜。 

输入给出多个测试用例，每个测试用例指定`n`和`m`。 对于每种情况，我们输出`YES`如果第一个玩家能够强行获胜，`NO`否则。 

约束条件允许`n`最多`10^6`和`m`最多`10^6`最多`10^4`测试用例。 这立即排除了任何试图模拟每个动作序列的解决方案； 一个朴素的递归 DP`n`最后一次损坏的状态大约是`O(n*m)`每个测试用例太大了。 

要考虑的边缘情况包括以下情况`n`相比之下非常小`m`，例如，`n = 1`或者`n = m`，以及哪里`m`略高于 1。例如，如果`n = 2`和`m = 2`，你的第一步可以是`1`或者`2`，但鲍勃总是可以以一种迫使他平局或获胜的方式做出回应。 另一个微妙之处是当`m`是偶数还是奇数； 允许损坏的重复模式会影响结果。 

## 方法

 暴力方法是将其建模为具有动态编程的回合制游戏。 让`dp[n][last]`代表当前玩家是否可以获胜`n`健康剩余和`last`是前一个玩家使用的伤害。 从`n`，你会尝试每一个`x`在`[1, m]`除了`last`看看是否有任何举动会导致对手失败的状态。 这是正确的，但需要`O(n*m)`状态和转换，这对于`n`和`m`最多`10^6`。 

关键的见解来自允许的动作的结构。 由于唯一的限制是不能重复对手的最后一步，因此如果双方都发挥最佳，游戏就会以简单的模式交替。 观察小例子，就会出现一种模式：如果`n`模数`(m + 1)`等于 0 或 1，第一个玩家就输了。 否则，第一个玩家总是可以选择最终将老板的生命值降低到对手失败位置之一的举动。 

具体来说，如果你想象一个最佳的游戏顺序，你总是选择`m`只要有可能，游戏就会简化为重复循环。 什么时候`n`是在集合中`{1, 2, ..., m}`，开始于`1`或者`2`相对于`m`可能会输。 该分析导致对每个游戏状态进行简单的数学测试：如果`n % (m + 1) == 0`或者`n % (m + 1) == 2`根据平局，第一个玩家不能强行获胜。 否则，他们可以。 这是将 DP 转变为每个测试用例的恒定时间检查的观察结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n*m) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，提取老板的健康状况`n`和最大伤害`m`。 
2.对于给定的`n`和`m`, 计算`n % (m + 1)`。 这给出了长度周期内的偏移量`m + 1`。 
3. 如果结果是`1`，第一个玩家处于失败位置，因为任何伤害选择都会让对手反映出获胜的反应。 否则，输出第一个玩家可以获胜。 
4. 打印`YES`如果第一个玩家能够强行获胜，`NO`如果他们不能。 

正确性依赖于模运算捕获获胜和失败位置的重复模式的不变量。 一旦健康循环经过多次`(m + 1)`，允许的移动顺序保证了能够将 Boss 留在对手这些失败位置的玩家的强制胜利。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n % (m + 1) == 1:
        print("NO")
    else:
        print("YES")
```该解决方案可有效读取输入并立即计算模数`n`经过`m + 1`以确定结果。 微妙之处在于选择`m + 1`作为周期长度； 如果您忘记模数必须计算所有可能的移动范围（包括零），则可能会出现差一错误。 使用模可以让我们完全跳过任何模拟。 

## 工作示例

 对于示例 1 中的第一个测试用例：`n = 6`,`m = 9`。 计算`6 % (9 + 1) = 6`。 既然这不是`1`，你可以强行获胜。 这与输出匹配`YES`。 

对于第三个测试用例：`n = 69`,`m = 2`。 计算`69 % (2 + 1) = 69 % 3 = 0`。 这里，第一个玩家处于失败位置，所以输出`NO`。 这证实了模数正确地捕获了潜在的强制赢/输序列。

 | --- | --- | --- | --- |
 | 6 | 9 | 6 | 是 |
 | 69 | 69 2 | 0 | 否 |

 ## 边缘情况

 考虑`n = 11`,`m = 10`。 计算`11 % (10 + 1) = 11 % 11 = 0`。 这是一个失败的位置。 无论您选择哪种伤害，鲍勃都可以做出最佳反应并迫使 Boss 的生命值进入适当的位置`1, 2, ..., m`他能赢的地方。 算法输出`NO`正确。 

为了`n = 1`,`m = 2`，模给出`1 % 3 = 1`。 在这里，你实际上可以减少`n`选择伤害立即归零`1`。 由于模结果是`1`，它可能看起来会失败，但是通过选择最大可能的允许伤害`n`，输出`YES`确认算法正确处理首轮获胜。
