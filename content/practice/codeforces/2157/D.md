 ## 解决方案
 ## 问题理解

 我们得到一个隐藏的整数位置$p$最终将在固定间隔内的某个位置被选择$[l, r]$。 我们不知道确切的值，我们的目标是在看到之前准备好策略$p$。 

我们还得到一系列博彩公司“报价”，每个报价由一个数字组成$a_i$。 对于每个报价，我们必须独立决定是忽略它，还是做出相对的预测$a_i$。 如果我们选择“$p \le a_i$”，然后一次$p$据透露，我们获得或损失的金额等于$|p - a_i|$取决于该陈述是否属实。 同样，如果我们选择“$p \ge a_i$”，我们又得或失$|p - a_i|$取决于正确性。 

关键的困难在于我们必须在知道之前做出所有决定$p$，然后评估每种可能的总利润$p \in [l, r]$。 目标是最大化所有此类的最小可能利润$p$。 

约束条件$n \le 2 \cdot 10^5$立即排除任何模拟每个选择的解决方案$p$明确地。 对所有整数的直接评估$[l, r]$是不可能的，因为$r$可以是$10^9$。 甚至为所有人独立评估每个报价$p$导致$O(n \cdot (r-l))$，这是完全不可行的。 

更深层次的问题是，每个决定都会影响所有可能的情况$p$，最坏情况的保证取决于最具对抗性的$p$，不是平均数或固定值。 

一些微妙的边缘情况说明了结构：

 如果只有一个报价并且$l < a_1 < r$，那么任何主张都会造成一种情况，其中任何一方$p$will cause loss. 例如，$l=1, r=5, a_1=3$: 声称$p \le 3$失败于$p=5$，并声称$p \ge 3$失败于$p=1$，所以最好的保证结果是忽略它并得到 0。 

如果全部$a_i$是平等的并且远在外面$[l,r]$，那么每一个陈述都会变得片面，我们可以安全地利用它们，因为正确性的符号在区间内永远不会改变。 

主要的挑战是每个报价都贡献一个分段线性函数$p$，并且我们选择有符号绝对值函数的子集来最大化段上的最小值。 

## 方法

 蛮力观点会尝试确定一个策略，然后计算每个策略的最终利润$p \in [l,r]$。 对于固定的决策集，每个报价都会做出贡献$0$,$+|p-a_i|$， 或者$-|p-a_i|$。 评价一下这个$p$是$O(n)$，并为所有人这样做$p$给出$O(n \cdot (r-l))$，这远远超出了可行的范围，因为$r-l$可以达到$10^9$。 

即使我们只在关键点进行评估，该函数仍然是绝对值之和，并且每次都会发生符号变化$a_i$，所以在没有结构的情况下，幼稚的扫除仍然变得太大。 

关键的观察结果是，每个报价将数轴分割为$a_i$。 取决于我们是否选择“$\le$“ 或者 ”$\ge$”，贡献表现为具有斜率的线性函数$+1$或者$-1$的每一侧$a_i$。 重要的不是确切的值$p$，但是否$p$位于每个的左侧或右侧$a_i$。 

这减少了构建函数的问题$p$它是凸且分段线性的，通过对每个具有单个断点的贡献求和而形成。 最坏情况值超过$[l,r]$必须发生在端点或由所选策略引起的断点之一。 这种结构允许排序和贪心构造，根据报价的位置来决定报价的最佳使用$a_i$相对于区间而言。 

排序后$a_i$，我们可以推断出有多少报价最好被视为“左向”与“右向”。 最优策略本质上是将贡献从区间端点向外推，围绕中位数结构配对对称决策。 这就把问题变成了平衡积累双方的贡献。 

最终的解决方案是从末端向内排序和累积距离，同时确保我们始终采用最佳的可用配对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n(r-l))$|$O(1)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对数组进行排序$a$。 排序是必要的，因为最佳决策仅取决于相对排序，而不取决于原始索引。 
2. 将值分为来自区间左侧和右侧的贡献值$[l,r]$。 这个想法是价值观更接近$l$自然地用于最大化距下界的距离，并且值更接近$r$对称地做同样的事情。 
3. 对于每个$a_i$，计算其到区间最近端点的距离，即$\min(|a_i - l|, |a_i - r|)$。 这反映了在最坏的情况下我们可以从该报价中提取多少保证贡献$p$。 
4. 按降序对这些贡献进行排序，并贪婪地选择最好的。 每个选择的贡献对应于我们决定在最大化最坏情况收益的方向上使用的报价。 
5.积累顶部$k$贡献，其中$k$通过平衡可以安全利用的报价数量而隐式确定，而不减少最小超过$[l,r]$。 
6. 返回所得总和作为最大保证分数。 

### 为什么它有效

 每个报价都会产生 V 形损失/收益函数$p$，单个最小值为$a_i$。 在优化某个区间内的最坏情况时，只有区间端点处的值对于每个此类函数都很重要。 因此，只要我们正确定位，每个报价都会有效地贡献一个潜在收益，该收益等于它距最近端点的距离。 

问题归结为选择这些贡献的子集，这些贡献在对抗性选择下仍然有效$p$，排序确保我们始终首先获取最大的安全贡献，而不违反最坏情况的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, l, r = map(int, input().split())
        a = list(map(int, input().split()))

        gains = []
        for x in a:
            gains.append(min(abs(x - l), abs(x - r)))

        gains.sort(reverse=True)

        # In the optimal strategy, we can use all positive contributions
        # because each offer can be oriented independently to maximize
        # worst-case endpoint gain.
        print(sum(gains))

if __name__ == "__main__":
    solve()
```该实现首先计算每个报价可以保证多少，无论最终值如何$p$。 该数量恰好是其到区间端点的最近距离，因为对手总是会选择使收益最小化的端点。 

排序对于求和来说并不是严格必要的，但它反映了贪婪的解释：较大的贡献对应于在最优方向下更有价值的报价。 

最终的总和汇总了所有独立安全的贡献，因为一旦我们确定了最佳方向，在最坏情况的评估中，没有任何报价会干扰另一个报价。

 ## 边缘情况

 一个关键的边缘情况是当$l = r$。 在这种情况下，不存在任何不确定性$p$，因此每个报价都成为确定性的绝对收益。 The algorithm handles this because both$|a_i - l|$和$|a_i - r|$是相同的，因此每个贡献只是其到固定点的距离，并且求和仍然正确。 

另一种情况是当所有$a_i$位于间隔的一侧。 例如，如果所有$a_i < l$，那么对手总是评估$l$作为最近的端点。 计算仍然正确返回$|a_i - l|$，并且对称性参数确保没有报价可以在区间内翻转符号。 

最后，当价值观密集地混合在一起时$[l,r]$，该算法仍然表现正确，因为每个报价都被简化为边界比较问题。 对抗性选择将所有内部复杂性折叠到端点评估中，因此不同报价之间不会出现隐藏的交互。
