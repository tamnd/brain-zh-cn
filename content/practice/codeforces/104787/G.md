 ## 解决方案
 ## 问题理解

 我们有两个数组，其中一个长度为$n$和长度之一$m$。 他们定义了一个$n \times m$每个单元格所在的网格$(x, y)$具有通过对行中的值求和而形成的值$x$来自第一个数组和列处的值$y$从第二个数组。 因此网格是完全可分离的：每行仅通过$a_x$，每列仅通过$b_y$。 

有效路径从左上角单元格开始，并重复移动到当前单元格上方或左侧以外的任何单元格，直到最终到达右下角。 因此，访问过的单元格的序列按偏序形成一条链，其中两个坐标都不会减少。 路不必一步步走； 只要尊重单调性，它就可以“跳跃”。 

路径的成本定义为连续访问单元值之间的绝对差之和。 我们希望所有有效的单调链的成本尽可能最大。 

约束条件允许$n, m \le 10^5$，这会立即排除任何单独检查网格单元或显式考虑所有路径的解决方案。 任何方法都依赖于$O(nm)$结构是不可能的。 我们被迫将网格压缩成仅依赖于数组本身的东西。 

朴素推理的一个微妙的失败案例来自于假设采取更多的中间点总是有帮助的。 例如，假设一条路径从非常大的值直接到非常小的值，然后又回到中等值。 贪婪的尝试可能会尝试任意插入中间点，但坐标的单调性阻止了重新排序的自由，因此我们不能在值空间中任意“之字形”，除非坐标顺序允许。 

另一个误导性的情况是假设答案仅独立于行或列的极值。 一个小例子已经显示了耦合：

 输入：$a = [1, 100]$,$b = [1, 100]$网格极值是$(1,1)=2$,$(2,2)=200$。 天真的猜测可能是答案只是$198$。 然而，插入一个精心选择的中间单元可以根据结构增加总和，因此我们必须更全面地推理允许的分解。 

## 方法

 蛮力的想法是考虑网格中所有有效的单元链。 由于每条链都是在两个坐标上递增的单元序列，因此我们将枚举所有此类序列并计算每个序列的绝对差之和。 一个单调链的数量$n \times m$网格是指数级的，因此即使对于小尺寸，这也很快变得不可能。 即使对所有单元和所有先前状态进行动态编程仍然太大，因为转换取决于所有先前可到达的点。 

关键的结构观察是每个单元格值都是线性的$a_x + b_y$。 这意味着两个单元格之间的任何差异都会干净地分为行贡献和列贡献：$$C[x,y] - C[x',y'] = (a_x - a_{x'}) + (b_y - b_{y'}).$$绝对值使事情变得复杂，但重要的结果是表达式仅取决于四个标量：所选的行值和列值。 一旦我们固定了线段的两个端点，贡献仅取决于$a_x, a_{x'}$和$b_y, b_{y'}$，不在任何中间结构上。 

这将问题分解为理解哪些端点可能很重要。 由于路径中的每个段都是独立的，因此在最大化或最小化这些线性表达式时，除了极端选择之外，最佳路径永远不会从使用内部行或列索引中受益。 任何最佳构造都可以简化为根据极值选择恒定数量的代表状态$a$和$b$。 

因此，我们不需要在网格中搜索，而只需要评估由极端行和极端列形成的配置。

 ## 算法演练

 我们将整个网格行为简化为从数组中的极值派生的一小组候选配置。 

1. 计算数组中的最小值和最大值$a$，并分别计算数组中的最小值和最大值$b$。 这四个值描述了可能影响绝对差异的所有极端行和列效应。 
2. 使用这些极值的组合形成候选单元格值：$a_{\min}, a_{\max}, b_{\min}, b_{\max}$。 每个单元格值只是一行和一列贡献的总和，因此值空间中的任何极值移动都必须来自这些组合。 
3. 考虑起始单元格$(1,1)$和结束单元格$(n,m)$，因为每条有效路径都锚定在这些点上。 
4. 评估从头到尾直线移动的直接贡献，这给出$|C[1,1] - C[n,m]|$。 
5. 评估 start 形式的所有两步分解$\rightarrow$中间的$\rightarrow$end，中间单元格是在行和列的四种极端组合中选择的。 对于每个候选中间单元，计算：$$|C[1,1] - C[i,j]| + |C[i,j] - C[n,m]|.$$6. 在所有这些候选者中取最大值。 

这足够的原因是，任何额外的中间点都不能引入新的有益结构，超出通过在由极端行和列选择形成的值空间中选择单个“转折点”已经可以实现的结构。 

### 为什么它有效

 任何有效路径都是按两个坐标排序的点链，因此它会产生一系列值$C[x,y]$。 因为每个$C[x,y]$在独立的行和列分量中是线性的，两点之间的任何线段仅取决于以下两个标量$a$和两个来自$b$。 仅当端点在至少一个方向上最大程度地分离时，绝对值函数才会受益，这种情况仅发生在极值选择时。 因此，最优路径可以被压缩为至多一个中间极值配置，而不会损失可实现的成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    a_min, a_max = min(a), max(a)
    b_min, b_max = min(b), max(b)
    
    start = a[0] + b[0]
    end = a[-1] + b[-1]
    
    candidates = []
    
    # direct
    ans = abs(start - end)
    
    # four extreme intermediate choices
    for ai in (a_min, a_max):
        for bj in (b_min, b_max):
            mid = ai + bj
            ans = max(ans,
                       abs(start - mid) + abs(mid - end))
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先提取两个阵列的全局极值，因为任何最佳配置都必须位于这些边界上。 开始值和结束值直接根据第一个和最后一个元素计算，因为路径必须在这些固定位置开始和结束。 

主要计算迭代极端行和列贡献的四种可能组合。 每个组合定义一个潜在的中间单元格值。 对于每个这样的中点，我们计算通过该中点将路径分成两段的成本。 

一个微妙的点是我们从不显式地构建网格或考虑超出端点的坐标。 所有结构都被编码为标量值，这使解决方案在输入大小上保持线性。

 ## 边缘情况

 单细胞网格是最简单的边界：路径没有边缘，因此成本为零。 该算法自然地处理这个问题，因为开始等于结束，使所有绝对差异消失。 

当两个数组中的所有值都相同时，每个网格单元都具有相同的值。 任何路径，无论选择多少个中间点，每步产生的贡献为零。 该算法也会崩溃到零，因为所有最小/最大值都重合，使得每个候选中点相等。 

当值高度倾斜时，例如一个数组同时包含非常小和非常大的值，而另一个数组则保持不变，则最佳中点选择变得至关重要。 该算法正确地捕捉到了这一点，因为它独立地评估两个极端，并允许最大化分段之间的分离的组合。
