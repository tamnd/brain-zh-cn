 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格，我们必须放置数字$1$通过$k$，每个恰好一次，进入网格的不同单元格。 所有其他单元格保持为空。 放置必须满足两个结构约束。 

首先，每行和每列必须至少包含两个填充单元格。 因此，即使网格很大，我们也不允许将数字集中在网格的小区域内。 

其次，对于每个索引$i$从$1$到$n$，放置在行中的数字集$i$必须与列中的数字集具有相同的最大公约数$i$。 这是对行和列如何关联的一个令人惊讶的强约束。 

输出不会要求我们打印网格。 相反，对于每个数字$i$，我们必须输出坐标$(x_i, y_i)$它所在的单元格的名称。 

这些限制迫使我们进行构建而不是任何搜索。 网格可以很大，$n$最多$2 \cdot 10^5$，我们可能需要放置最多$10^6$数字。 任何尝试对每个单元进行推理或模拟网格填充的解决方案都会太慢，因此我们必须在线性或近线性时间内构建一个模式。 

一种幼稚的方法会在检查行和列有效性时尝试贪婪地放置数字，但这会立即失败，因为任何本地放置都会影响行和列 gcd 相等的未来可行性。 即使检查有效性也会变得昂贵，因为重复计算不断增长的集合上的 gcd 会导致二次行为。 

一个更微妙的问题是行和列之间的对称性。 如果我们将一个数字放入$(i, j)$，它影响行$i$和列$j$除非我们强制执行全局结构，否则是不对称的。 这就是大多数天真的贪婪策略悄然崩溃的地方。 

## 方法

 关键的困难是 gcd 条件，但如果我们不再将数字视为值，而是关注它们的分布，事情就会变得简单得多。 gcd 约束仅取决于每行或每列中出现的标签，而不取决于它们的位置。 这表明我们应该强制每一行$i$包含与列完全相同的标签集$i$。 如果成立，则 gcd 自动相等。 

保证行和列标签集相同的最简洁方法是强制主对角线对称。 如果一个标签$t$被放置在$(i, j)$，我们也把它放在$(j, i)$。 然后行$i$收集与该列完全相同的标签$i$收集，只是从换位来看。 

这减少了构建无向图的问题$n$顶点，其中每个选定的边$(i, j)$对应于在单元格中放置标签$(i, j)$，而对称性迫使我们也包括相反的情况。 对角线放置$(i, i)$是一个自循环。 要求变成纯粹的图论：我们确切地需要$k$选定的定向展示位置，含义$k$对称单元，同时确保每个顶点的度数至少为二。 

一个自然的起点是一个简单的循环$n$顶点。 如果我们连接$1 \to 2 \to 3 \to \dots \to n \to 1$，每个顶点的度数正好为 2。 将每个无向边解释为两个有向放置$(i, j)$和$(j, i)$，这已经保证了每行和每列至少有两个填充单元格。 

这给了我们一个基础$n$边缘，但我们可能需要最多$10^6$位置，因此我们必须添加更多边。 重要的观察是，一旦每个顶点的度数至少为 2，添加额外的边就不能打破约束。 因此，任务变成扩展有效的基础结构以准确地达到$k$放置，同时避免重复。 

然后我们可以按任意顺序添加未使用的有效单元格。 对角线单元特别方便，因为它们不与周期冲突。 耗尽对角线后，我们继续扫描剩余的对，直到达到$k$展示位置。

 ## 算法演练

 我们将构造解释为选择$k$定向单元放置，但我们强制对称，以便行和列结构保持相同。 

1. 在顶点上构建初始循环$1 \dots n$。 对于每个$i$， 连接$i$到$i+1$， 和$n$连接回$1$。 这会产生$n$展示位置。 这保证了每一行和每一列都已经具有至少二度。 
2. 将所有这些循环对标记为已使用，因为在添加额外的放置时我们必须避免重复。 
3.添加自循环$(i, i)$为所有人$i$在需要的地方，继续直到我们到达$k$展示位置。 它们是安全的，因为它们不会干扰现有边缘并自动保持对称性。 
4. 如果我们还没有达到$k$，迭代所有对$(i, j)$和$i \le j$，跳过那些已经使用过的，然后添加它们直到完全达到$k$。 每个添加的对都会立即标记为已使用。 
5. 按顺序输出每个选择的对，分配标签$t$到$t$-第一个选定的单元格。 

### 为什么它有效

 该循环确保每个顶点的基度为二，因此在任何额外工作之前都满足行和列约束。 每个额外的放置都是对称添加的，将单元视为无向结构，因此行$i$和列$i$总是收到相同的标签组。 由于 gcd 仅取决于行或列中的标签多重集，因此相同的多重集意味着相同的 gcd，从而在整个构造过程中保留了要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    
    used = set()
    res = []

    def add(i, j):
        nonlocal res
        if len(res) >= k:
            return
        if (i, j) in used:
            return
        used.add((i, j))
        res.append((i, j))

    # 1) build cycle
    for i in range(1, n + 1):
        j = i + 1
        if j > n:
            j = 1
        add(i, j)
        if len(res) == k:
            break

    # 2) add diagonals
    if len(res) < k:
        for i in range(1, n + 1):
            add(i, i)
            if len(res) == k:
                break

    # 3) fill remaining arbitrary pairs
    if len(res) < k:
        for i in range(1, n + 1):
            for j in range(i, n + 1):
                add(i, j)
                if len(res) == k:
                    break
            if len(res) == k:
                break

    # output
    for x, y in res:
        print(x, y)

if __name__ == "__main__":
    main()
```该实现首先构建循环，这是保证行和列最小尺寸条件所需的唯一步骤。 这`used`set 确保我们不会两次分配相同的单元格，这一点很重要，因为重复放置会违反“每个单元格最多一个数字”的规则。 

循环结束后，我们用对角线扩展构造，然后用一般对扩展构造。 嵌套循环是安全的，因为我们一到达就停止$k$， 和$k$至多是$10^6$，因此成功插入的总数是有界的。 

主要的微妙之处在于，正确性完全取决于结构的对称性，而不是数字标签本身。 一旦循环建立，每一行每一列都已经有了足够的支撑，再增加也不能破坏可行性。

 ## 边缘情况

 一种边缘情况是当$k = 2n$。 在这种情况下，循环已经给出$n$位置和对角线给出了另一个$n$，因此在填充所有对角线后构造立即停止。 例如，与$n = 3, k = 6$，我们永远不会达到一般的对循环。 

另一个边缘情况是当$k$只是略大于$2n$。 在耗尽循环和对角线之后，算法进入一般填充阶段，但只需要一些额外的对。 因为我们跳过已经使用的单元格，所以不会出现重复项，并且终止很快就会发生。 

最后的边缘情况是$n = 2$。 周期为$(1,2),(2,1)$，它已经满足度数约束。 附加对角线$(1,1),(2,2)$足以达到任何有效$k \ge 4$，并且对称性可以轻松确保行列 gcd 相等，因为行和列都包含相同的两个标签。
