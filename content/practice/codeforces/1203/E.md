 ## 解决方案
 ## 问题理解

 我们有一组拳击手，每个拳击手都有一个正整数权重。 每个拳击手最多可以向上或向下调整自己的重量 1，但重量必须严格保持为正值。 我们的目标是组建尽可能最大的团队，调整后没有两名拳击手体重相同。 输入提供拳击手的数量，`n`，以及它们的权重列表。 输出是一个整数，表示具有唯一权重的最大团队的规模。 

约束表明`n`最大可达150,000，权重可达150,000。 尝试所有可能的调整组合的简单方法将涉及指数时间，这是不可行的。 我们需要一个在大致线性或线性时间（O(n log n) 或更好）内运行的解决方案，因为 O(n^2) 在最坏的情况下会导致超过 220 亿次操作，远远超过 2 秒的限制。 

一些边缘情况值得考虑。 如果所有拳击手的体重相同，我们必须小心地向上或向下调整重量，以最大化团队的力量。 例如，用权重`[1,1,1]`，最优结果为`[1,2,3]`给定一个规模为 3 的团队。另一种情况是当权重包括 1 时，因为我们无法进一步减少 1，所以调整只能增加这样的权重。 如果最大权重在上限附近多次出现，我们必须保证增加权重时不超过150,001。 

## 方法

 暴力解决方案很容易描述：对于每个拳击手，尝试所有三个可能的权重（当前、当前-1、当前+1）并检查该权重是否已在团队中分配。 如果没有，请将其添加到团队中。 继续，直到处理完所有拳击手。 这是正确的，因为它明确检查所有可行的权重分配。 问题是，在最坏的情况下，每个拳击手都会尝试三种可能性，并且检查唯一性可能需要重复搜索或更新集合，如果不仔细管理，则会导致 O(n^2) 复杂性。 和`n = 150,000`，这种方法会超时。 

关键的见解是我们处理拳击手的顺序很重要。 按重量对平角内裤进行排序可以让我们首先考虑较小的重量。 对于每个拳击手，如果它仍然为正并且可用，我们尝试将其权重减少 1，然后尝试原始权重，最后尝试增加 1。这种贪婪策略确保首先填充较小的权重，为较高的权重留出空间，而不会发生冲突。 这样做的原因是，一旦使用了权重，我们就无法重复使用它。 通过始终采用最小的可用选项，我们可以最大限度地减少以后的冲突。 这将问题简化为通过排序列表的单次传递，同时维护所用权重的集合或布尔数组，由于排序和 O(n) 空间而实现 O(n log n) 时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(最大(a_i)) | 已接受 |

 ## 算法演练

 1.读取拳击手的数量`n`和权重列表`a`。 
2. 按升序对权重列表进行排序。 排序确保我们首先处理较小的权重，这让我们可以贪婪地分配最小的可用唯一权重。 
3. 初始化布尔数组或设置以跟踪已分配的权重。 当我们将重量分配给拳击手时，我们会将其标记为已使用的重量。 
4. 初始化计数器`team_size`为零以计算成功分配的拳击手。 
5. 迭代每个权重`w`在排序列表中。 对于每个重量，按顺序尝试：

 a.`w-1`，仅当它为正且未使用时。 如果已分配，则将其标记为已使用并递增`team_size`。 

b. 如果`w-1`不可用，请尝试`w`本身。 如果可用，将其标记为已使用并增加`team_size`。 

c. 如果两者都不是`w-1`也不`w`可用，尝试一下`w+1`。 如果可用，将其标记为已使用并增加`team_size`。 
6. 处理完所有拳击手后，`team_size`将包含尽可能最大的团队规模。 输出这个值。 

为什么有效：该算法保持了所有分配的权重都是唯一的不变性。 排序可确保较小的权重获得优先权，从而避免浪费较小的数字，而这些数字只能通过减少权重为 2 或以上的拳击手来分配。 三步贪婪检查保证如果至少有一个附近的重量可用，每个拳击手都会为球队做出贡献。 由于所有选项均按升序进行测试，因此不会错过任何潜在的分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
weights = list(map(int, input().split()))
weights.sort()

MAX_W = 150001
used = [False] * (MAX_W + 2)
team_size = 0

for w in weights:
    if w > 1 and not used[w-1]:
        used[w-1] = True
        team_size += 1
    elif not used[w]:
        used[w] = True
        team_size += 1
    elif w + 1 <= MAX_W + 1 and not used[w+1]:
        used[w+1] = True
        team_size += 1

print(team_size)
```该解决方案首先读取输入并对拳击手的体重进行排序。 我们使用布尔数组来跟踪常量访问所使用的权重。 对排序权重的迭代确保我们首先处理较小的权重，避免不必要的冲突。 每个条件都处理贪婪选择：如果可能，则减少，然后保留，然后增加。 边界检查确保不使用负权重或过大的权重。 递增`team_size`只有成功分配权重才能保持正确性。

            team_size += 1

            used[w] = True
            team_size += 1

    return str(team_size)
