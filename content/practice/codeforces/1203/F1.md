 ## 解决方案
 ## 问题理解

 Polycarp 是一位具有初始评级的自由职业者`r`。 他有一个项目清单，每个项目都由两个数字定义：启动所需的最低评级，以及完成后的评级变化，可能是正面的，也可能是负面的。 问题是，是否存在一个顺序，可以让他完成所有项目，而他的评分不会低于零。 

关键的挑战是某些项目会降低评级，因此过早完成它们可能会使后续项目无法进行。 一旦达到评级阈值，积极的项目就可以随时完成，但消极的项目必须仔细排序，以便波利卡普的评级永远不会低于零。 

限制条件适中：最多 100 个项目，最多 30,000 个评级。 这意味着大约具有 O(n² log n) 次操作的解决方案是可行的。 项目的强力排列是 O(n!) 并且显然太慢了。 边缘情况包括由于初始评级太低而无法单独完成的项目，或者必须小心地将负面项目与正面项目交织在一起以维持非负面评级的一系列负面项目。 

例如，如果 Polycarp 的评级为 5 并且项目是`(4, -3), (2, 1)`，立即尝试第一个项目的幼稚方法会失败，因为评级会降至 2，从而使进一步的进展变得棘手。 正确的策略是先完成积极或消极影响小的项目。 

## 方法

 暴力方法会尝试项目的每种排列并检查是否满足评级约束。 这保证了正确性，但不可行，因为 n! 生长速度极快。 当 n = 100 时，甚至计算所有排列也是不可能的。 

关键的观察是，具有非负评级变化的项目可以按照其所需评级的升序贪婪地完成。 对于评级为负变化的项目，我们需要确保完成后评级永远不会低于零。 如果我们将负面项目视为“债务”，那么每个项目一开始就必须有足够的评级来承受评级下降。 按最高安全阈值对负面项目进行排序，具体`a_i + |b_i|`，确保我们最后完成要求最高的负面项目，从而实现最大的灵活性。 

最佳解决方案将项目分为正面和负面评级变更组。 积极的项目会根据其所需的评级进行贪婪的处理。 负面项目排序依据`a_i + |b_i|`并按该顺序执行。 我们迭代这两个组，在开始项目之前始终检查当前评级是否足够。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 贪婪评级和安全阈值 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将项目列表分为两组：具有非负数的项目`b_i`以及负面的项目`b_i`。 这种区别至关重要，因为一旦达到评级阈值，积极的项目就可以安全地完成，而消极的项目会降低评级并需要仔细订购。 
2. 将积极的项目按升序排列`a_i`。 首先完成最简单的积极项目可以尽早最大化评级，并有助于满足以后更困难的积极项目的门槛。 
3. 将负面项目按升序排列`a_i + |b_i|`。 这确保了我们在考虑到评级影响的情况下启动可以安全执行的负面项目，将最危险的负面下降推迟到我们积累了足够的评级缓冲时结束。 
4. 迭代所有积极的项目。 对于每个，检查 Polycarp 的当前评级是否满足要求`a_i`。 如果是，请添加`b_i`到目前的评级。 如果任何项目因评级不足而无法启动，则终止并返回“NO”。 
5. 按排序顺序迭代所有负项目。 检查当前等级是否满足`a_i`。 如果是，则减去`|b_i|`从目前的评级来看。 如果完成后的评级为负数或`a_i`大于当前额定值，终止并返回“NO”。 
6. 如果所有项目均成功完成，则返回“YES”。 

为什么有效：该算法保持了波利卡普的评分永远不会低于零的不变性。 积极的项目总是安全的，消极的项目只有在有足够的评级缓冲来吸收评级下降时才会尝试。 对负面项目进行排序`a_i + |b_i|`确保“影响最大”的项目最后处理，从而防止评级过早匮乏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, r = map(int, input().split())
pos_projects = []
neg_projects = []

for _ in range(n):
    a, b = map(int, input().split())
    if b >= 0:
        pos_projects.append((a, b))
    else:
        neg_projects.append((a, b))

# Process positive projects first
pos_projects.sort(key=lambda x: x[0])
for a, b in pos_projects:
    if r < a:
        print("NO")
        sys.exit()
    r += b

# Process negative projects carefully
neg_projects.sort(key=lambda x: x[0] + abs(x[1]), reverse=False)
for a, b in neg_projects:
    if r < a or r + b < 0:
        print("NO")
        sys.exit()
    r += b

print("YES")
```该代码将正项目和负项目分开。 积极的项目被排序并贪婪地执行。 负面项目排序依据`a_i + |b_i|`，保证了应用评级降低时的安全性。 我们在每个项目之前和之后检查评级以确保非负面性，精确匹配算法步骤。

    neg_projects = []

        a, b = map(int, input().split())
