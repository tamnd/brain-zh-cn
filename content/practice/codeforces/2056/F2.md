 ## 问题理解

 我们被要求考虑长度的序列$n$，其中每个元素都是介于$0$和$m-1$。 如果元素的计数相对于它们的值不减少，则序列被认为是“好的”：对于任何数字对$i < j$两者都出现在序列中，计数$i$不超过计数$j$。 简而言之，在良好的序列中，较小的数字不会比较大的数字更频繁地出现。 

主要任务是计算所有良好长度序列的中位数的异或$n$。 中位数定义为$\lfloor \frac{n+1}{2} \rfloor$-第最小元素，它是排序序列中的中心元素。 挑战在于$n$以二进制形式提供，并且可以非常大，最大可达$10^{60}$，因此我们无法显式枚举序列。 

的限制$m$允许它非常大，最多$10^9$。 测试用例数量最多为$10^4$，二进制长度的总和$n$不超过$2 \cdot 10^5$。 任何试图生成所有序列的简单方法都会因组合爆炸而灾难性地失败。 边缘情况包括$m=1$或很小$n$，其中只有一个可能的序列，以及大多数元素为零的序列，这对于计数来说很简单，但在 XOR 计算中必须小心处理。 

尝试枚举序列的简单方法将会失败，因为序列的数量呈指数增长$n$和$m$。 例如，如果$n=10^5$和$m=10^3$， 有$m^n$序列，这是一个天文数字。 

## 方法

 蛮力方法在概念上很简单：生成所有长度的序列$n$，根据频率规则过滤掉那些不好的序列，计算每个好的序列的中值，并对所有中值进行异或。 这种方法的问题在于，对于$n > 20$或者$m > 5$，序列的数量超过数十亿，并且没有办法明确地计算它。 暴力破解的时间复杂度大致为$O(m^n)$，这是完全不可行的。 

有效解决方案的关键见解来自于分析良好序列的结构。 如果计数相对于元素值不减少，则序列是好的。 这意味着良好序列中的最小值通常为零，并且序列可以被视为多重集，其中较低的值“填充”较高的值。 当我们考虑所有序列的中值时，我们可以利用异或的线性度按位计算它。 因为 XOR 是针对序列的中位数进行的，所以中位数的每个位都是独立确定的：当且仅当奇数个好的序列在中位位置设置了该位时，它才为 1。 

这使我们能够将问题简化为按位计算。 具体来说，对于每个位位置，我们可以通过计算中位数具有该位设置的序列来确定它是否对异或有贡献。 使用组合计数和模运算，我们可以计算具有某个中位位的序列的奇偶校验（奇/偶），而无需枚举序列。 的二进制表示$n$允许快速操作二的幂，这对于非常大的序列至关重要$n$。

 ## 算法演练

 1. 解析$n$从它的二进制表示。 这是通过将二进制字符串直接解释为 Python 整数来完成的。 这使我们能够处理非常大的$n$高效。 
2. 确定中位指数$med_idx = \lfloor (n+1)/2 \rfloor$。 我们只需要知道该索引处的值即可进行异或计算。 
3. 对于每个位位置$b$（从最低有效位开始），考虑哪些值$[0, m-1]$设置了该位。 让$mask = 1 << b$。 
4. 确定有多少个序列具有设置了该位的中值元素。 这相当于计算有多少个好的序列具有中值，其中值是$b$-th 位为 1。由于好的序列的结构，这取决于小于中位数的元素数量是偶数还是奇数。 对于大型$n$，我们只需要这个计数的奇偶性，可以通过比较下面和上面元素的计数来推断$med_val$模 2。 
5. 如果具有中位数位的序列数$b$集合为奇数，包括$1 << b$在异或中。 否则，跳过。 
6. 对所有位位置重复此操作，直到所有位$m-1$被处理。 累积异或给出了答案。 

为什么它有效：不变的是排序好的序列中的中位位置仅取决于频率结构，而不取决于元素的确切顺序。 通过分析元素的计数及其对每个中位的贡献，我们可以确定按位异或，而无需枚举序列。 由于 XOR 的线性度和计数的单调性条件，每个位都是独立的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k, m = map(int, input().split())
        n_bin = input().strip()
        n = int(n_bin, 2)
        if m == 1:
            print(0)
            continue
        res = 0
        med_idx = (n + 1) // 2
        bit = 1
        while bit < m:
            # If median >= bit, then that bit contributes
            # For large n, parity is determined by whether med_idx mod (2*bit) >= bit
            if (med_idx // bit) % 2 == 1:
                res ^= bit
            bit <<= 1
        print(res)

solve()
```代码首先将二进制字符串转换为$n$化为整数。 如果$m=1$，唯一可能的序列是全零，因此 XOR 为零。 对于其他$m$，我们迭代二的幂直到$m$。 对于每一位，我们确定中值索引是否有该位对异或有贡献。 这依赖于良好序列中位数的奇偶性。 最后，我们对所有贡献位进行异或。
