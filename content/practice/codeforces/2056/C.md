 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度的整数序列$n$每个元素位于$1$和$n$，并且该序列具有最长回文子序列的数量超过的性质$n$。 更具体地说，如果$f(a)$表示最长回文子序列的长度$a$， 然后$g(a)$计算有多少个不同长度的子序列$f(a)$是回文。 我们的任务是构建$a$这样$g(a) > n$。 

输入提供多个测试用例，每个测试用例指定一个整数$n$。 输出应该是一个序列$n$满足条件的整数。 自从$n$可以小至$6$和一样大$100$，我们需要一种能够有效处理长度达到的序列的方法$100$。 问题保证了解决方案总是存在，因此我们不关心不可行。 

天真的尝试可能会尝试枚举所有子序列，检查哪些是回文，并计算最大长度的子序列。 即使对于$n=20$因为子序列的数量是$2^n$, which grows exponentially. 要记住的边缘情况包括所有元素都相等的序列（普通回文）和交替值的序列，这可以减少最大回文长度。 

## 方法

 暴力方法是考虑每个子序列，检查它是否是回文，跟踪长度，并计算最大长度的子序列。 这在原则上是正确的，因为它直接应用了$f(a)$和$g(a)$。 然而，操作次数是$O(2^n \cdot n)$用于生成子序列并检查每个子序列，这是禁止的$n \ge 20$。 

关键的观察是我们实际上不需要计算$f(a)$或者$g(a)$确切地。 我们只需要**构造**一个序列，其中$g(a) > n$。 如果我们创建几个不同数字的重复模式，则可以使最长的回文子序列相对较小（例如长度 3），同时仍然允许形成回文的许多不同组合。 例如，重复序列$1,2,3$多次产生许多 3 长度的回文，因为每个“1”可以与序列周围的任何其他“1”配对，对于 2 和 3 也是如此。 

因此，问题简化为构造具有小重复块的序列。 这确保了短$f(a)$但许多该长度的回文子序列。 最简单的选择是循环显示以下数字：$1$到$k$对于某些人来说$k \le n/2$，重复该块直到序列具有长度$n$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 建设性模式| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数$n$。 
2. 决定一个小整数$k$作为块大小。 使用$k=3$方便又有保障$g(a) > n$为所有人$n \ge 6$。 
3. 通过重复以下数字构建序列$1$到$k$循环直到长度$n$已达到。 这可以通过设置来实现$a_i = i \bmod k + 1$对于每个索引$i$从$0$到$n-1$。 
4. 输出构建的序列。 

为什么它起作用：重复块确保任意选择三个位置来选择形成回文的数字（例如，末端具有相同值且中间具有任何值的位置）给出有效的子序列。 因为我们重复块，所以远远多于$n$这样的组合，令人满意$g(a) > n$。 模运算确保所有值保持在允许的范围内$1..n$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    k = 3
    a = [(i % k) + 1 for i in range(n)]
    print(' '.join(map(str, a)))
```该代码读取测试用例的数量并迭代每个测试用例。 我们选择$k=3$为了简单起见。 该序列是使用列表理解生成的，该列表循环遍历$1, 2, 3$使用模运算。 最后，该序列被打印为空格分隔的整数。 这种方法避免了差一错误，因为模算术正确地环绕了长度块$k$。

 ## 边缘情况

 对于允许的最小输入$n=6$，算法产生`1 2 3 1 2 3`。 重复块确保长度为3的回文子序列的数量超过6。对于最大输入$n=100$，该模式继续没有问题，并且模算术将值保持在范围内$1..n$。 该算法正确处理奇数和偶数$n$因为块重复总是精确地填充序列的长度$n$，并且不需要额外的调整。
