 ## 解决方案
 ## 问题理解

 我们有一棵树`n`顶点，其中每个顶点都有一个非负整数`a_v`写在上面。 我们还得到了一组`k`不同的非负整数`b_1, ..., b_k`。 任务是计算删除边的方法数量，以便生成的每个连接组件都对其属于该集合的顶点值进行按位异或`b`。 

换句话说，在选择要删除的某些边子集之后，每个连接的子图应该有一个总异或，它恰好是允许的之一`b_i`价值观。 我们的输出是所有此类边缘子集模数的计数`10^9 + 7`。 

关键的限制是`n`可以达到`10^5`在所有测试用例中，以及`k`最多为 4。这足够小，可以对`b`值是可行的。 尝试所有边子集的简单方法将是指数级的，并且显然是不可能的。 此外，XOR 是一种线性运算，这意味着我们可以有效地组合子树的结果，但我们必须仔细考虑切割边缘如何划分树。 

当出现微妙的边缘情况时`k = 1`唯一允许的 XOR 为零。 在这种情况下，每个边缘去除都必须遵守没有组件具有非零 XOR 的约束，这可能会显着限制所有子集。 另一个棘手的场景是当叶节点单独形成组件时。 例如，如果一棵树有顶点`[1,2,3]`有价值观`[0,1,1]`和`b = {1}`，移除边以隔离顶点 1 会产生有效分量。 假设所有节点必须保持连接的简单实现将错过此类解决方案。 

## 方法

 蛮力方法将尝试边缘的每个子集，删除它们，计算每个结果组件的 XOR，并检查所有组件 XOR 是否都在`b`。 有`2^(n-1)`边缘子集，这显然是不可行的`n = 10^5`。 暴力破解之所以有效，是因为每个组件都可以独立检查，但会失败，因为子集的数量呈指数增长。 

关键的见解是组件的异或仅取决于其子树的异或。 我们可以任意为树建立根并在每个节点执行动态规划过程。 让`dp[u][mask]`表示以 为根的子树的分裂方式数`u`这样的异或`u`与剪切相结合的子树对应于位掩码`b`价值观。 自从`k <= 4`, 最多有`16`面具，使这个DP可行。 

本质上，树结构允许我们递归地处理每个节点。 在每个节点，我们使用位掩码上的卷积来组合其子节点的 DP 结果。 我们还必须考虑将边缘切割给子代的可能性，这实际上会在该子代上启动一个新组件。 该方法将指数边子集问题转化为具有小常数因子 DP 的线性遍历。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | DP + 位掩码 | O(n * 2^k * 2^k) | O(n * 2^k * 2^k) | O(n * 2^k) | O(n * 2^k) | 已接受 |

 ## 算法演练

 1. 读取树、值`a_v`，以及集合`b`。 树在节点 1 处任意生根。 
2. 绘制每个地图`b_i`到一个位索引`0..k-1`并存储一个查找字典`b_to_idx`。 这让我们能够有效地将 XOR 结果表示为位掩码。 
3.对于每个节点`u`，维护一个DP数组`dp[u][mask]`尺寸的`2^k`。`dp[u][mask]`计算子树的分裂方式的数量`u`这样得到的 XOR 为`u`的子树表示为`mask`。 
4. 从根执行 DFS。 对于每个节点，初始化`dp[u][mask_u] = 1`在哪里`mask_u`代表单个值`a_u`的异或与`b`放。 
5. 对于每个孩子`v`的`u`，递归计算`dp[v]`。 结合`dp[u]`和`dp[v]`有两种方式：首先假设边缘`(u,v)`被保留，合并`v`进入`u`的组件，第二个假设边缘被切割，这会在以下位置开始一个新组件`v`。 相应地更新掩码。 
6.处理完所有children后，`dp[root][full_mask]`给出整棵树的有效分割数. 与允许的 XOR 值相对应的所有掩码的总和`b`。 
7. 输出结果取模`10^9 + 7`。 

为什么它有效：在每个节点，`dp[u]`正确地计算了划分其子树的所有方法，因为我们独立地考虑每个子树并考虑切割或保留边缘。 位掩码结束`b`确保我们永远不会计算无效的 XOR 值。 根递归地从子树收集所有组合，这保证了完整性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        edges = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            edges[u-1].append(v-1)
            edges[v-1].append(u-1)
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        b_to_idx = {val:i for i,val in enumerate(b)}
        
        def val_to_mask(x):
            mask = 0
            for i, val in enumerate(b):
                if x == val:
                    mask |= (1 << i)
            return mask
        
        dp = [None]*n
        visited = [False]*n
        
        def dfs(u):
            visited[u] = True
            mask_u = val_to_mask(a[u])
            dp_u = [0]*(1<<k)
            dp_u[mask_u] = 1
            for v in edges[u]:
                if visited[v]:
                    continue
                dfs(v)
                new_dp = [0]*(1<<k)
                for m1 in range(1<<k):
                    if dp_u[m1]==0:
                        continue
                    for m2 in range(1<<k):
                        if dp[v][m2]==0:
                            continue
                        # keep edge: merge masks
                        merged = m1 ^ m2
                        new_dp[merged] = (new_dp[merged] + dp_u[m1]*dp[v][m2]) % MOD
                        # cut edge: treat child as separate component if its mask valid
                        for i in range(k):
                            if m2 == (1<<i):
                                new_dp[m1] = (new_dp[m1] + dp_u[m1]*dp[v][m2]) % MOD
                dp_u = new_dp
            dp[u] = dp_u
        
        dfs(0)
        res = 0
        for mask in range(1<<k):
            for i in range(k):
                if mask == (1<<i):
                    res = (res + dp[0][mask]) % MOD
        print(res)

if __name__ == "__main__":
    solve()
```该解决方案设置 DFS 递归，构建 DP 数组，并仔细合并保留边缘和剪切边缘的掩模。 这`val_to_mask`函数确保每个顶点的值映射到一个位掩码`b`。 合并中的嵌套循环处理子树的所有组合，最终求和仅计算代表有效 XOR 值的掩码。 一个常见的错误是在每次乘法或求和后忘记取模，这会溢出。
