 ## 解决方案
 ## 问题理解

 我们有一个矩形网格。 每个单元格都包含一个整数值，正数或负数。 

米开朗基罗选择了一条从左上角到右下角的路径。 他只能向右或向下移动。 一条路径的得分是该路径上访问过的所有单元值的总和，并且他总是选择具有最大可能得分的路径。 

在选择路径之前，拉斐尔只选择一个单元格并翻转其符号。 一个值`x`变成`-x`。 

拉斐尔想让米开朗基罗的最终最优分数尽可能小。 米开朗基罗看到修改后的网格，然后选择他的最佳路径。 

对于每个测试用例，我们必须计算拉斐尔可以强制的最低分数。 

网格最多包含`10^6`所有测试用例中的单元格。 这立即排除了为每个可能的翻转单元重新计算完整动态编程表的任何方法。 单个`O(nm)`DP不错，但是`O((nm)^2)`是完全不可能的时候`nm = 10^6`。 

棘手的部分是，翻转一个单元格后，米开朗基罗可能会切换到完全不同的路径。 我们不能假设他继续使用与以前相同的最佳路径。 

考虑一个小例子：```
1 100
100 1
```原来的最佳路径使用了三个单元格并且有价值`102`。 

如果拉斐尔翻转`100`在右上角，米开朗基罗只需更改路线并使用其他路线`100`。 

任何只关注原始最优路径的解决方案都会在这里失败。 

另一种容易错过的情况是存在多个不同的最佳路径。```
0 0
0 0
```每条路都有价值`0`。 

翻转任何单元格都不会改变。 即使翻转的单元格位于一条最佳路径上，米开朗基罗也可以选择另一条具有相同分数的路径。 假设“破坏最佳路径就会破坏最佳路径”的解决方案是错误的。 

第三种极端情况发生在仅包含一个单元格的对角线上。```
5
```The start and end cell are the same. 任何路径都必须经过它。 After flipping, the answer is`-5`。 

当对角线仅包含一个单元格时，该对角线上没有可供路径使用的替代单元格。 

## 方法

 最直接的想法就是像拉斐尔的选择一样尝试每一个可能的细胞。 

对于固定单元，翻转其符号并使用标准网格 DP 重新计算最大路径和。 结果值是米开朗基罗的响应。 取所有单元格的最小值即可得出答案。 

这是正确的，因为它确实模拟了游戏。 

问题在于复杂性。 最大路径 DP 成本`O(nm)`。 有`nm`可能发生翻转的单元格。 总复杂度变为`O((nm)^2)`，达到`10^12`最坏情况下的操作。 

我们需要了解翻转单个单元如何影响最佳路径。 

让`f[i][j]`= 从起点到终点的最大路径总和`(i,j)`。 

让`g[i][j]`= 最大路径总和`(i,j)`到最后。 

然后```
val(i,j) = f[i][j] + g[i][j] - a[i][j]
```是任何经过的路径的最大得分`(i,j)`。 单元格值被计数两次，因此我们将其减去一次。 

现在假设拉斐尔翻转单元格`(i,j)`。 

如果米开朗基罗选择了一条仍然要走的路`(i,j)`，该路径恰好丢失`2 * a[i][j]`，因为贡献变化自`a[i][j]`到`-a[i][j]`。 

所以使用该单元格的最佳路径变为```
val(i,j) - 2*a[i][j]
```剩下的问题是避免的最佳路径`(i,j)`。 

这就是关键观察结果出现的地方。 

每一条单调的路径`(1,1)`到`(n,m)`恰好访问每个反对角线上的一个单元格`i + j = constant`。 

修复单元格`(i,j)`并让`d = i + j`。 

任何路径回避`(i,j)`仍必须穿过反对角线上的其他单元格`d`。 

对于任何细胞`(x,y)`在同一条对角线上，`val(x,y)`是所有经过的路径中最好的路径得分`(x,y)`。 

因此，最好的路径是避免`(i,j)`只是最大`val`在对角线上的所有其他单元格中`d`。 

这将问题转化为维护每个反对角线的最大和第二大值`val`。 

对于一个细胞`(i,j)`:

 如果它的`val`不是对角线上最大的，则最佳回避路径使用对角线最大值。 

如果它的`val`是唯一最大的值，删除它迫使我们使用第二大的值。 

之后，米开朗基罗的最优反应是```
max(
    path_using_flipped_cell,
    best_path_avoiding_flipped_cell
)
```拉斐尔选择所有单元格中的最小值。 

### 复杂性比较

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((纳米)^2) | O(纳米) | 太慢了 |
 | 最佳 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 计算`f[i][j]`，从起始点到每个单元格的最大路径总和。 
2. 计算`g[i][j]`，从每个像元到目的地的最大路径总和。 
3. 对每个单元进行计算```
val = f[i][j] + g[i][j] - a[i][j]
```这是穿过该单元格的所有路径中的最高分数。 
4. 按反对角线对单元格进行分组`d = i + j`。 
5. 对于每条对角线，存储最大值`mx1[d]`和第二大值`mx2[d]`。 

当多个单元格共享最大值时，`mx2[d]`允许变得等于`mx1[d]`。 这会自动正确处理关系。 
6. 枚举每个单元格`(i,j)`就像拉斐尔的翻转细胞一样。 
7. 计算```
through = val - 2*a[i][j]
```这是仍然使用翻转单元格的最佳路径分数。 
8. 计算避开该单元的最佳路径。 

如果`val == mx1[d]`， 使用`mx2[d]`。 

否则使用`mx1[d]`。 
9. 米开朗基罗选择了这两个选项中较好的一个：```
score = max(through, avoid)
```10.最小化`score`覆盖所有细胞。 

### 为什么它有效

 单调路径恰好访问每个反对角线上的一个单元格。 修复翻转的单元格`(i,j)`在对角线上`d`。 

任何路径回避`(i,j)`必须穿过同一对角线的另一个单元格。 相反，任何经过对角线另一个单元格的路径`d`自动回避`(i,j)`，因为一条路径只能访问该对角线上的一个单元格。 

对于每个对角单元格`(x,y)`,`val(x,y)`是经过它的所有路径中最好的分数。 因此，避免路径的最佳得分`(i,j)`正好是最大值`val`在对角线上的所有其他单元格中`d`。 

使用翻转单元的最佳路径完全丢失`2*a[i][j]`。 米开朗基罗选择“使用”和“避免”选项中较好的一个，而拉斐尔则选择最小化该结果的单元格。 每种可能性都会被评估一次，因此该算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10 ** 30

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    a = [list(map(int, input().split())) for _ in range(n)]

    f = [[-INF] * m for _ in range(n)]
    g = [[-INF] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            if i == 0 and j == 0:
                f[i][j] = a[i][j]
            else:
                best = -INF
                if i > 0:
                    best = max(best, f[i - 1][j])
                if j > 0:
                    best = max(best, f[i][j - 1])
                f[i][j] = best + a[i][j]

    for i in range(n - 1, -1, -1):
        for j in range(m - 1, -1, -1):
            if i == n - 1 and j == m - 1:
                g[i][j] = a[i][j]
            else:
                best = -INF
                if i + 1 < n:
                    best = max(best, g[i + 1][j])
                if j + 1 < m:
                    best = max(best, g[i][j + 1])
                g[i][j] = best + a[i][j]

    diag_cnt = n + m - 1
    mx1 = [-INF] * diag_cnt
    mx2 = [-INF] * diag_cnt

    val = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            cur = f[i][j] + g[i][j] - a[i][j]
            val[i][j] = cur

            d = i + j

            if cur >= mx1[d]:
                mx2[d] = mx1[d]
                mx1[d] = cur
            elif cur > mx2[d]:
                mx2[d] = cur

    ans = INF

    for i in range(n):
        for j in range(m):
            d = i + j
            cur = val[i][j]

            through = cur - 2 * a[i][j]

            if cur == mx1[d]:
                avoid = mx2[d]
            else:
                avoid = mx1[d]

            score = max(through, avoid)
            ans = min(ans, score)

    print(ans)
```第一个 DP 计算以每个单元结尾的最佳前缀。 第二个 DP 从每个单元格开始计算最佳后缀。 

将它们组合起来可以给出通过每个单元的最佳路径。 该数量在整个解决方案中重复使用，这就是为什么我们在选择翻转单元后永远不需要重新运行 DP。 

对角线最大值值得特别注意。 当新值至少是当前最大值时，它将成为新最大值，而旧最大值将成为第二最大值。 因为我们使用`>=`，相等的最大值被正确存储。 如果对角线上的两个单元格具有相同的最佳值，则删除一个单元格仍然会通过另一个单元格留下相同的值。 

所有计算都使用 Python 整数。 路径总和可能大约达到`(n+m) * 10^9`，因此需要 64 位算术。

 ## 边缘情况

 ### 单细胞网格

 输入：```
1
1 1
5
```只有一种可能的翻转，也只有一种可能的路径。`val = 5`。 

翻转后：```
through = 5 - 2*5 = -5
```对角线上没有替代单元格，因此结果为`-5`。 

该算法处理这个问题是因为该对角线上的第二个最大值仍然是负无穷大，并且`through`选项占主导地位。 

### 多条最优路径

 输入：```
1
2 2
0 0
0 0
```每条路都有分数`0`。 

对于每条对角线，最大和第二大的值都变为`0`。 

当排除某个单元格时，具有相同值的另一个单元格仍然可用。 算法返回`0`，这是正确的。 

### 最终路径未使用的翻转单元格

 输入：```
1
2 2
1 100
100 1
```翻转任一`100`使通过该单元的路径变得更糟。 

该算法比较：```
through = val - 200
```与来自同一对角线的最佳替代值进行对比。 

另一条路径获胜，与米开朗基罗在看到翻转后重新规划路线的能力相匹配。 

这正是解决方案必须考虑每个翻转单元的“使用”和“避免”情况的原因。
