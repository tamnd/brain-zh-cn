 ## 解决方案
 ## 问题理解

 我们得到一个数字$x$，我们必须构造另一个正整数$y$使得特定的整除条件成立。 该构造取决于通过连接十进制表示形式形成一个新数字$x$紧随其后的是$y$。 如果我们表示的位数$y$经过$k$，那么这个连接值可以写成$x \cdot 10^k + y$。 

要求是这个连接的数字可以被总和整除$x + y$。 所以我们需要强制执行条件$$x \cdot 10^k + y \equiv 0 \pmod{x + y}.$$除了产生任何有效的结果之外，我们没有被要求优化任何东西$y < 10^9$。 约束允许最多$10^4$测试用例，以及每个$x$下面是$10^8$，因此每个测试用例的任何构建都必须非常便宜，最好是恒定的时间。 

天真的解释会建议尝试以下值$y$并直接检查条件。 然而，串联引入了对数字长度的非线性依赖，并且强力$y$最多$10^9$显然是不可行的。 

一个微妙的边缘情况是$x$具有不同的数字长度，因为连接取决于有多少位数字$y$有。 忽略数字边界的粗心蛮力方法将会失败：例如，尝试小$y$没有固定数字长度的值会导致算术不一致，因为$10^k$离散地变化。 

## 方法

 蛮力方法会迭代候选值$y$, 计算$x \cdot 10^k + y$，并检查整除性$x + y$。 即使我们限制$k$最多 9 个（因为$y < 10^9$），每个测试用例仍然需要扫描最多$10^9$最坏情况下的值。 这是按顺序$10^{13}$跨所有测试用例的操作，这远远超出了任何可行的限制。 

关键的观察是我们不需要满足任意数字长度行为的条件。 相反，我们可以强制一个结构，其中$x + y$除一个数字，其构造变得可预测。 表达式$$x \cdot 10^k + y$$建议对齐$y$10 的幂，使得模数抵消变得简单。 

考虑该条件的一种有效方法是尝试求商$\frac{x \cdot 10^k + y}{x + y}$等于一些简单的东西，最好是 10 的幂或一个小整数。 在此类串联可分性问题中，一个众所周知的技巧是强制$y$是 的倍数$x$，这简化了表达式：$$y = kx.$$代入此式可得出：$$x \cdot 10^k + kx = x(10^k + k),$$和$$x + y = x(1 + k).$$因此，整除条件简化为检查是否：$$1 + k \mid 10^k + k.$$这将原来的问题变成选择一个小整数$k$使得上述整除性成立。 自从$k$只需要很小（在实践中，像这样的值$k \le 100$足够了），我们可以预先定义或搜索一个固定的小范围。 一旦有这样一个$k$找到了，我们输出$y = kx$，自动满足$y < 10^9$对于所有有效输入，因为$x < 10^8$我们选择小的$k$。 

这将数字相关的串联问题转换为每个测试用例的恒定时间算术构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解 y |$O(10^9)$每次测试 |$O(1)$| 太慢了 |
 | 尝试小 k，设置 y = kx |$O(1)$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$x$。 我们对待$x$作为一个固定的基值，将扩展构建$y$。 
2. 尝试较小的整数值$k$，从 1 开始向上。 我们限制小规模的原因$k$是我们有意塑造$y$作为线性倍数$x$，因此只需要少数候选即可满足模块化条件。 
3. 对于每个$k$，检查是否$1 + k$划分$10^k + k$。 这个条件保证了当$y = kx$，串联表达式可以被整除$x + y$。 
4. Once a valid$k$找到，设置$y = kx$。 自从$k$小且固定，这保证了$y < 10^9$。 
5、输出$y$并继续下一个测试用例。 

### 为什么它有效

 施工力量$y$成正比于$x$，它消除了数字串联和涉及两个自变量的模运算之间的相互作用。 唯一剩下的条件完全取决于$k$，使问题与大小无关$x$。 一旦有效$k$选择时，分子和分母共享一个因子$x$，将可整性要求降低为纯整数属性，涉及$k$独自的。 这保证了每个的正确性$x$，因为同样的$k$统一工作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def find_k():
    # small fixed search range is sufficient
    for k in range(1, 200):
        if (10 ** k + k) % (k + 1) == 0:
            return k
    return 1

k = find_k()

t = int(input())
for _ in range(t):
    x = int(input())
    print(x * k)
```该解决方案首先计算一个有效的乘数$k$满足所需的可分性约束，独立于$x$。 这在测试循环之外完成一次，确保每个测试用例的摊销恒定时间。 

每个答案都很简单$y = kx$，这确保了串联表达式所需的结构对齐，以干净地简化。 

一个微妙的实现细节是计算$10^k$必须使用 Python 整数完成，因为值增长很快，但这是安全的，因为预计算只完成一次。

 ## 边缘情况

 对于$x = 1$，算法产生$y = k$。 连接变成一个固定的小数，其整除性仅取决于预先计算的$k$，因此无论规模如何，正确性都会得到保留。 

对于大型$x$靠近$10^8$, 乘法$y = kx$仍然低于$10^9$因为$k$受预处理中选择的一个小常数的限制。 该结构不依赖于数字长度，因此不会出现溢出或串联不一致的情况。 

对于所有情况，相同的预先计算$k$确保行为一致，并且计算完全简化为整数乘法，避免任何脆弱的字符串操作或基于数字的逻辑。
