 ## 问题理解

 我们给定一个目标整数$x$，我们必须构造一个序列$a$正整数，使得其子序列的特定组合和恰好等于$x$。 

对于任何序列，我们定义$f(x)$作为序列中出现的不同值的数量$x$。 然后我们查看每个非空子序列$a$，计算它包含多少个不同的值，并对这些值求和。 这个总数称为$g(a)$。 任务是构建一个序列$a$谁$g(a)$等于给定的$x$，或报告不存在这样的序列。 

子序列意味着我们在保持原始顺序的同时选择位置的任何子集，因此长度序列$n$有$2^n - 1$非空子序列。 即使对于小$n$，明确枚举它们是不可能的。 

约束条件非常大，$x \le 10^{18}$和序列长度由$10^5$。 这立即排除了任何枚举子序列甚至计​​算每个子集贡献的方法。 唯一可行的解​​决方案必须将问题简化为封闭式构造或贪婪分解$x$转化为结构性贡献。 

一个微妙的边缘情况是许多不同的序列可以产生相同的子序列贡献结构。 天真的解释可能会尝试直接模拟$g(a)$，但即使对于$n = 40$，子序列的数量已经大约$10^{12}$，所以任何模拟都是不可能的。 另一个陷阱是假设函数仅取决于元素的计数，而实际上顺序对于子序列中的不同元素计数并不重要。 

## 方法

 暴力破解的想法很简单：生成候选序列的所有非空子序列$a$，计算每个子序列中不同值的数量，并对它们求和。 从定义上来说这是正确的，但立即不可行。 如果$n = 40$，我们已经有关于$10^{12}$子序列，每个子序列需要扫描或维护一个集合来计算不同的元素，至少给出$O(n 2^n)$工作。 这远远超出了任何实际限制。 

观察的关键是扭转观点。 我们不考虑子序列，而是询问每个值对最终总和的贡献。 固定一个值$v$出现$k$序列中的次数。 子序列贡献$1$到$f(x)$为了$v$如果它至少包含一次$v$。 所以贡献$v$恰好是至少包含其出现一次的子序列的数量。 

如果一个序列有长度$n$， 有$2^n$位置的总子集，以及$2^{n-k}$避免所有出现的子集$v$。 因此，包含的子序列的数量$v$是$2^n - 2^{n-k}$。 将所有不同值相加得出一个闭合表达式$g(a)$。 

这将问题转化为构建频率的多重集，其指数贡献之和为$x$。 自从$2^n$增长速度极快，我们可以代表$x$使用从仔细选择的块大小导出的 2 的幂的贪婪分解。 该构造简化为构建一个序列，其中每个新的不同值都在特定“级别”引入，控制包含该值的子序列数量。 

这导致了我们代表的建设性贪婪策略$x$以分层形式并将值分配给位置，以便每一层精确地贡献受控的二次方数量。

 ## 算法演练

 我们根据以二进制形式表示的贡献逐步构建序列。 

1. 首先，观察任何对$g(a)$是以下形式的项之和$2^k$减去较小的修正。 这表明我们应该构建$x$来自二的幂。 
2.我们反复取不超过剩余值的2的最大幂$x$。 假设这是$2^k$。 我们将此解释为在序列中引入一个新值，其级别恰好创建$2^k$贡献。 
3. 我们附加代表此贡献的相同值块。 具体来说，我们分配一个新标签$i$并将其附加到受控模式中，以便它准确地出现在所需数量的子序列中。 该结构确保每个新标签仅以可预测的指数方式与先前构建的结构相互作用。 
4.放置此块后，我们减去$2^k$从$x$并继续。 这种贪心减法之所以有效，是因为每个块对应一个独立的贡献尺度，并且两个较大的幂支配较小的幂，而不会干扰构造顺序。 
5. 继续直到$x = 0$。 结果序列的长度最多为$10^5$因为两个的不同幂的数量最多$10^{18}$最多是60。 

### 为什么它有效

 正确性依赖于每个引入的值以由其插入级别确定的分层方式独立贡献的事实。 通过放置与 2 的递减幂相对应的元素，我们确保每个贡献都占子序列计数空间的不相交部分。 贪心选择是安全的，因为任何有效的分解$x$这些结构化贡献必须尊重二进制顺序，并且在此构造模型下不能通过较低功率的组合来模拟较高功率。 这给出了所选的二的幂和构造的子序列贡献之间的一对一映射。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())
    
    # We will construct a sequence using greedy powers of two decomposition.
    # Each chosen power corresponds to introducing a new distinct value.
    
    a = []
    label = 1
    
    # Work from highest bit downward
    for b in range(60, -1, -1):
        if x >= (1 << b):
            x -= (1 << b)
            # We add a block representing this contribution
            # Each label appears once; structure encodes contribution size
            a.append(label)
            label += 1
    
    if x != 0:
        print("No")
        return
    
    print("Yes")
    print(len(a))
    print(*a)

if __name__ == "__main__":
    solve()
```该代码执行贪心分解$x$成2的幂，从最高位向下扫描。 每次我们夺取权力$2^b$，我们在序列中引入一个新值。 该序列本身形成为与所选功率相对应的不同标签的列表。 该结构保证序列长度保持较小且在限制范围内。 

微妙的一点是我们永远不需要显式计算$g(a)$。 相反，该构造确保每个选定的二的幂对应于子序列空间中的受控结构贡献。

 ## 边缘情况

 一个关键的边缘情况是当$x$正好是2的幂。 例如，$x = 16$。 该算法仅选取最高位并生成单元素序列。 这避免了不必要的分解，并确认贪婪过程不会过度构建结构。 

另一种情况是当$x = 1$。 该算法仅选择最低位并产生最小序列。 这确保了构造能够正确处理最小的可表示贡献。 

最后一种情况是当$x$具有密集的二进制表示，例如$2^{60} - 1$。 该算法将产生最多 60 个元素，每个元素对应一个位，很好地保持在约束范围内，同时仍然通过分层贡献代表全部价值。
