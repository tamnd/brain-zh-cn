 ## 问题理解

 我们被要求计算在部分指定的排列中填充缺失值的方法的数量，这样得到的排列可以分成两个连续的子序列，它们的组合顺序给出了排序的排列$1$到$n$。 形式上，排列$b$是排序序列的随机洗牌$[1, 2, \dots, n]$如果我们可以将排序后的数组分成两个连续的段，将它们作为子序列，并将它们交错形成$b$。 输入数组$p$可能有一些条目`-1`，代表缺失的数字。 每个缺失的数字必须由剩余未使用值中的不同整数替换，以形成有效的排列。 我们想要执行此操作的方法数量取模$998,244,353$。 

限制条件很高：$n$可以达到$10^6$，以及总和$n$所有测试用例不超过$10^6$。 这排除了任何二次的算法$n$。 我们需要一个线性或近线性的解决方案。 边缘情况发生时`-1`出现在关键位置或已知值时$p$防止洗牌； 例如，如果第一个值是`3`在长度为 3 的数组中，任何分区都不允许子序列按顺序交错。 数组没有`-1`或数组`-1`在所有职位上也是需要考虑的重要因素。 

## 方法

 暴力方法将枚举所有替换的方法`-1`使用未使用的数字并检查每个候选排列是否是已排序数组的重复洗牌。 生成所有排列是缺失条目数量的阶乘，因此即使对于$n=20$这种方法是不切实际的。 此外，检查排列是否是 riffle shuffle 需要扫描所有可能的分裂点，给出另一个因素$n$在复杂性上。 显然，这对于$n$最多$10^6$。 

关键的观察结果是，排序数组的随机洗牌完全由两半的相对顺序决定：如果我们在某个点拆分排序数组$k$，第一个$k$数字必须作为子序列以递增的顺序出现，其余的$n-k$数字也必须作为子序列以递增的顺序出现。 已知值$p$限制哪些分割点是可能的。 具体来说，小数的最早位置和大数的最新位置定义了分割的可行边界。 

一旦我们确定了必须进入第一个子序列的排序数组的最小前缀和第二个子序列的最小后缀，我们就可以用`-1`作为免费插槽。 填充它们相当于计算每个子序列中有多少数字进入每个序列的组合`-1`位置。 这相当于计算非递减的计数序列，可以使用阶乘和模逆来计算。 预计算阶乘高达$n$使我们能够有效地计算每个测试用例的答案。

 | 使用阶乘进行分割和计数 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘和模逆直到最大值$n$在所有测试用例中。 这允许恒定时间计算组合模$998,244,353$。 
2. 对于每个测试用例，识别所有已知数字$p$并标记他们的位置。 确定最早的位置`first_large`包含第二个子序列的值和最新位置`last_small`包含第一个子序列的值。 如果`first_large < last_small`，排列不可能是riffle shuffle，答案为零。 
3. 数一下数量`-1`之前的条目`first_large`作为`left_unknown`以及之后`last_small`作为`right_unknown`。 这些表示可用于第一和第二子序列中的数字的槽。 
4.让`left_total`是必须进入第一个子序列但尚未放置的数字数量，并且`right_total`是第二个子序列的类似数。 
5. 将数字有效放置到未知槽中的数量是两个组合的乘积：分配方式的数量`left_total`数入`left_unknown`职位和`right_total`数入`right_unknown`职位。 使用公式`C(n, k) = factorial[n] * inverse_factorial[k] * inverse_factorial[n-k] % MOD`。 
6. 将这些组合相乘并输出结果模`998\,244\,353`。 

工作原理：通过跟踪已知数字强制执行的最小和最大边界，我们确保不违反 riffle shuffle 属性。 以尊重这些边界的任何顺序用剩余的数字填充未知数可以保留所需的子序列。 阶乘考虑了所有不同的分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def precompute_factorials(max_n):
    fact = [1] * (max_n + 1)
    inv_fact = [1] * (max_n + 1)
    for i in range(2, max_n + 1):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
    for i in range(max_n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD
    return fact, inv_fact

def comb(n, k, fact, inv_fact):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

fact, inv_fact = precompute_factorials(10**6)

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    unknown_positions = [i for i, x in enumerate(p) if x == -1]
    used = set(x for x in p if x != -1)
    
    left_total = 0
    right_total = 0
    left_unknown = 0
    right_unknown = 0
    
    first_large = 0
    while first_large < n and (p[first_large] == -1 or p[first_large] <= n // 2):
        first_large += 1
    last_small = n - 1
    while last_small >= 0 and (p[last_small] == -1 or p[last_small] > n // 2):
        last_small -= 1
    
    if first_large <= last_small:
        print(0)
        continue
    
    left_unknown = sum(1 for i in range(first_large) if p[i] == -1)
    right_unknown = sum(1 for i in range(last_small + 1, n) if p[i] == -1)
    
    left_total = n // 2 - sum(1 for x in p if x != -1 and x <= n // 2)
    right_total = n - n // 2 - sum(1 for x in p if x != -1 and x > n // 2)
    
    ans = comb(left_unknown, left_total, fact, inv_fact) * comb(right_unknown, right_total, fact, inv_fact) % MOD
    print(ans)
```在代码中，我们预先计算阶乘和逆阶乘一次，以允许快速组合计算。 这`first_large`和`last_small`确定强制分裂，保证riffle shuffle属性。 计算未知槽和剩余数量使我们能够使用组合公式计算有效分配。 在 Python 中处理离一索引需要特别注意，因为所有位置都是零索引的。
