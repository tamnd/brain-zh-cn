 ## 解决方案
 ## 问题理解

 给定一个正整数数组`a`长度`n`。 对于每个元素`a_i`，我们可以将其增加`1`任意次数，费用为`1`per increment. 我们的目标是制作至少一对不同的索引`(i, j)`使得最大公约数`a_i`和`a_j`大于`1`。 任务是找到实现这一目标的最小总成本。 

因为所有`b_i = 1`，每次增量成本相同。 这简化了问题：我们不需要权衡增加哪些元素更便宜，只需要考虑需要多少增量才能实现大于 1 的 GCD。 

约束条件告诉我们，总和`n`所有测试用例不超过`2 * 10^5`，这意味着每个测试用例的 O(n log n) 解决方案是可以接受的，但 O(n^2) 会太慢。 小型阵列可能会被暴力破解，但大型阵列则需要更智能的方法。 

一个关键的边缘情况是当所有数字都是`1`。 然后每个数字必须至少递增一次才能创建公因数。 另一种情况是，当数组已包含重复项或可被另一个数整除的数字时，则不需要增量。 粗心的实现可能会忽略与所有其他数字互质或互质的数字，需要仔细计算最接近的非互质值的增量。 

## 方法

 蛮力方法会考虑所有对`(i, j)`并计算完成所需的最小增量数`gcd(a_i + x, a_j + y) > 1`。 对于每个数字，我们可以尝试添加`0, 1, 2, ...`直到达到一个公因数。 这原则上是可行的，但对于 n 高达 2 * 10^5 的情况，检查所有对和多个增量太慢，因为操作数量可能达到大约 n^2 * log(a_max)，这是令人望而却步的。 

关键的观察是最小的素数足以生成大于 1 的 GCD。每个整数都有一个素因子，如果两个数字共享一个素因子，它们的 GCD 至少是该素数。 因为我们可以递增数字，所以我们只需要检查小的素数因子，看看需要多少增量才能达到该素数的倍数。 自从`a_i <= 2 * 10^5`，可以使用埃拉托斯特尼筛法预先计算大约 450 个素数（2 * 10^5 的平方根）。 

最优策略迭代所有素数并计算使至少两个数是该素数的倍数所需的最小增量。 答案是所有素数中此类成本最小的。 这将问题从检查所有对减少为根据一小组素数检查所有数字，从而将复杂性降低到大约 O(n * π(sqrt(a_max)))，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * log a_max) | O(n^2 * log a_max) | O(n) | 太慢了 |
 | 最佳 | O(n * sqrt(a_max)) | O(n * sqrt(a_max)) | O(n + sqrt(a_max)) | O(n + sqrt(a_max)) | 已接受 |

 ## 算法演练

 1. 使用埃拉托斯特尼筛法预先计算 450 以内的所有素数。 我们将使用这些素数来测试可能产生大于 1 的 GCD 的除数。 
2. 对于每个测试用例，请阅读`n`和数组`a`。 初始化答案`ans`到一个代表无穷大的数字。 
3. 迭代每个素数`p`。 对于每个`a_i`，计算所需的最小增量`a_i`可除以`p`。 这是`(p - a_i % p) % p`。 
4. 收集当前素数的所有这些增量成本，对它们进行排序，并将两个最小的相加。 这给出了使至少两个数字可被整除的最小成本`p`。 
5. 更新`ans`与较小的电流`ans`以及步骤 4 中获得的总和。 
6.测试完所有素数后，输出`ans`对于测试用例。 
7. 对所有测试用例重复此操作。 

工作原理：该算法保证了正确性，因为任何大于 1 的数字都有一个素因子，并且在至少两个数字之间实现公共素因子可确保 GCD 大于 1。通过检查 sqrt(a_max) 之前的所有素数，我们覆盖了所有可能的最小 GCD，并将两个最小调整值相加，确保了每个候选素数的最小成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def sieve(n):
    is_prime = [True] * (n+1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5)+1):
        if is_prime[i]:
            for j in range(i*i, n+1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    return primes

primes = sieve(450)

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))  # b_i = 1 for all i, not used

    ans = float('inf')

    for p in primes:
        costs = [(p - x % p) % p for x in a]
        costs.sort()
        ans = min(ans, costs[0] + costs[1])
    
    print(ans)
```筛函数生成最多 450 个素数。在每个测试用例中，我们计算每个素数的增量成本，然后取两个最小值以确保至少有两个数字共享该素数因子。 排序可确保我们选择最少的调整。 使用模运算`(p - x % p) % p`正确处理已经被整除的数字`p`无需添加不必要的增量。
