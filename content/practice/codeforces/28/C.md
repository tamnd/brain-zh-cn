 ## 解决方案
 ## 问题理解

 每个学生独立、统一、随机选择一间卫生间。 一个房间可能包含多个洗手盆，因此进入该房间的学生会分成几个队列。 队列尽可能均衡，因为学生们会自行安排以尽量减少房间内最大的队列长度。 

如果一个房间包含`x`学生和`a[i]`盆地，那么该房间内的最大队列大小变为：$$\left\lceil \frac{x}{a[i]} \right\rceil$$一项随机分配的全局值是所有房间中的最大队列大小。 我们必须计算这个最大值的期望值。 

约束足够小以允许动态编程，但对于强力枚举来说太大。 最多有50名学生和50个房间。 可能的分配数量为：$$m^n$$和`n = m = 50`，这变成了`50^50`，这是完全不可能直接枚举的。 

小界限暗示着基于状态的概率 DP。 周围的任何算法`O(n^3 m)`或者`O(n^4)`在 2 秒限制内就可以了。 指数级的东西`n`或者`m`不是。 

问题中最危险的部分是了解到底是什么决定了房间中最大的队列大小。 粗心的实施可能会错误地使用楼层划分。 

考虑：```
2 1
3
```有2个学生，3个盆。 最大队列大小不是`0`， 虽然`2 // 3 = 0`。 每个学生只是占据一个单独的盆，所以答案是`1`。 

当学生分布不均匀时，就会出现另一个微妙的情况。```
5 1
2
```有 5 名学生和 2 个池，最佳划分是队列大小`3`和`2`。 最大的队列是`3`， 不是`2`。 

概率更大的边缘情况是许多房间都有大量盥洗池。```
2 2
100 100
```无论学生如何选择房间，每个被占用的房间都有最大的排队人数`1`。 期望值正好是`1`。 幼稚的模拟或不正确的转换可能会意外地计算空队列并产生较小的结果。 

最难的概念性错误是假设房间在确定最大值后是独立的。 它们不是独立的，因为房间内的学生人数必须总和为`n`。 DP 必须跟踪已分配的学生数量。 

## 方法

 蛮力方法很简单。 对于每个学生，选择其中一项`m`房间。 完成完整的作业后，计算进入每个房间的学生数量。 对于房间`i`，计算：$$\left\lceil \frac{cnt_i}{a_i} \right\rceil$$然后取各个房间的最大值和所有作业的平均值。 

这是有效的，因为每个任务的可能性都是相同的。 问题是分配的数量：$$m^n$$对于最大约束来说，这是一个天文数字。 

关键的观察是我们并不关心学生的确切身份。 只有进入每个房间的学生人数才重要。 

假设房间`i`收到`k`学生。 该事件的概率是二项式的：$$\binom{n}{k}\left(\frac1m\right)^k$$更重要的是，该房间产生的最大队列大小仅取决于`k`和`a[i]`。 

这表明重新定义问题。 不要直接计算预期最大值，而是计算：$$P(\text{maximum queue size} \le t)$$对于每个阈值`t`。 

对于固定阈值`t`， 房间`i`最多可以接受：$$a_i \cdot t$$学生，否则其最大队列超过`t`。 

现在的问题变成计算每个房间保持在其允许容量内的概率。 

这将问题转化为经典的多项式动态规划问题。 我们一一处理房间并跟踪已经分配了多少学生。 

对于每个房间，我们尝试分配`k`学生，前提是：$$\left\lceil \frac{k}{a_i} \right\rceil \le t$$等效地：$$k \le a_i t$$精确分配的概率贡献`k`这个房间的学生来自组合数学。 我们选择剩下的学生进入这个房间。 

一旦我们可以计算：$$P(\max \le t)$$预期值如下：$$E[\max] = \sum_{t \ge 1} P(\max \ge t)$$或等价：$$E[\max] = \sum_{t=1}^{n} \left(1 - P(\max \le t-1)\right)$$第二个公式很方便，因为最大队列大小始终介于`1`和`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m^n \cdot (n+m)) | O(m^n \cdot (n+m)) | O(米) | 太慢了 |
 | 最佳 | O(m \cdot n^3) | O(m \cdot n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预先计算二项式系数`C[n][k]`为所有人`0 ≤ n,k ≤ 50`。 

这些系数代表我们可以选择哪些学生进入特定房间的方式。 
2. 预计算幂`m`。 

由于每个分配都有概率：$$\frac1{m^n}$$我们反复除以`m`。 
3. 对于每个阈值`t`从`0`到`n`，计算：$$P_t = P(\max \le t)$$这意味着每个房间最多必须有最大的队列大小`t`。 
4. 对房间使用动态规划。 

定义：$$dp[i][j]$$作为精确分配的有效方法的数量`j`学生是第一批`i`房间同时尊重门槛`t`。 
5. 初始化：$$dp[0][0] = 1$$在处理任何房间之前，已以一种有效方式分配了零个学生。 
6. 一间一间地处理房间。 

假设我们在房间`i`并且已经分配了`j`学生。 尝试放置`k`其他学生进入这个房间。 

仅在以下情况下才允许此转换：$$\left\lceil \frac{k}{a_i} \right\rceil \le t$$这相当于：$$k \le a_i t$$7. 添加过渡：$$dp[i+1][j+k] += dp[i][j] \cdot \binom{n-j}{k}$$我们选择哪个`k`剩下的学生进入这个房间。 
8.所有房间处理完毕后，`dp[m][n]`等于最大队列大小最多的分配数量`t`。 
9. 除以：$$m^n$$获得概率：$$P_t$$10. 使用以下方法恢复期望：$$E = \sum_{x=1}^{n} \left(1 - P_{x-1}\right)$$期限`1 - P_{x-1}`正是最大队列大小至少为的概率`x`。 

### 为什么它有效

 对于固定阈值`t`，DP 精确计算每个房间都遵守限制的分配。 过渡选择有多少学生进入当前房间，并计算可以这样做的剩余学生的所有可能子集。 

每一份完整的作业都对应于 DP 的一条路径，因为每个房间都有唯一确定的学生人数。 相反，每个 DP 路径都构造一个有效的分配。 

期望公式之所以有效，是因为对于任何非负整数随机变量：$$E[X] = \sum_{x \ge 1} P(X \ge x)$$这里`X`是最大队列大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXN = 55

# binomial coefficients
C = [[0] * MAXN for _ in range(MAXN)]

for n in range(MAXN):
    C[n][0] = C[n][n] = 1
    for k in range(1, n):
        C[n][k] = C[n - 1][k - 1] + C[n - 1][k]

n, m = map(int, input().split())
a = list(map(int, input().split()))

total = float(m ** n)

# prob[t] = P(max <= t)
prob = [0.0] * (n + 1)

for t in range(n + 1):
    dp = [[0.0] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = 1.0

    for i in range(m):
        limit = a[i] * t

        for used in range(n + 1):
            if dp[i][used] == 0:
                continue

            for take in range(n - used + 1):
                if take > limit:
                    break

                ways = C[n - used][take]
                dp[i + 1][used + take] += dp[i][used] * ways

    prob[t] = dp[m][n] / total

ans = 0.0

for x in range(1, n + 1):
    ans += 1.0 - prob[x - 1]

print(f"{ans:.15f}")
```第一部分使用帕斯卡三角形预先计算二项式系数。 我们只需要 50 以内的值，因此这几乎不需要任何成本。 

DP 针对每个阈值独立重建`t`。 国家`dp[i][used]`存储处理第一个任务后存在多少个有效分配`i`房间和分配`used`学生。 

转变是核心组合步骤。 认为`used`学生已经被分配。 有`n - used`学生还是自由的。 准确选择`take`当前房间的其中一些可以在以下位置完成：$$\binom{n-used}{take}$$方式。 

条件`take <= a[i] * t`保证房间内最大队列不超过`t`。 

一个常见的错误是尝试直接使用多项式系数。 增量二项式构造更简单，并且避免了计数过多，因为在按顺序处理房间时，每个学生都被分配了一次。 

另一个微妙的点是它的含义`t = 0`。 这个门槛是不可能的，除非没有学生。 自从`n ≥ 1`,`prob[0]`自动变为零。 保留这种情况可以简化期望公式。 

最终的求和使用：$$E[X] = \sum_{x \ge 1} P(X \ge x)$$实施为：```
ans += 1 - prob[x - 1]
```## 工作示例

 ### 示例 1

 输入：```
1 1
2
```一个学生一个房间有两个脸盆。 

对于阈值`t = 0`：

 | 房间处理 | 学生分配| 有效途径|
 | --- | --- | --- |
 | 0 | 0 | 1 |
 | 1 | 1 | 0 |

 这个房间甚至不能容纳一名学生，因为`2 * 0 = 0`。 

所以：$$P(\max \le 0) = 0$$对于阈值`t = 1`：

 | 房间处理 | 学生分配| 有效途径|
 | --- | --- | --- |
 | 0 | 0 | 1 |
 | 1 | 1 | 1 |

 现在房间最多可容纳`2`学生，所以作业是有效的。$$P(\max \le 1) = 1$$期待：$$1 - P(\max \le 0) = 1$$输出：```
1.000000000000000
```这证实了即使流域比学生多，最大队列大小仍然至少为`1`。 

### 示例 2

 输入：```
2 2
1 1
```每个房间都有一个盥洗池，因此排队人数等于房间内的学生人数。 

对于阈值`t = 1`，每个房间最多可容纳一名学生。 

| 房间| 以前用过的学生 | 学生补充 | 结果状态 |
 | --- | --- | --- | --- |
 | 1 | 0 | 0 | dp[1][0] += 1 |
 | 1 | 0 | 1 | dp[1][1] += 2 |
 | 2 | 0 | 0 | dp[2][0] += 1 |
 | 2 | 1 | 1 | dp[2][2] += 2 |

 有`2^2 = 4`总作业数。 

恰好有两项作业将学生平均分配到各个房间。 

所以：$$P(\max \le 1) = \frac{2}{4} = \frac12$$最大队列大小是`1`或者`2`。 

因此：$$E = 1 \cdot \frac12 + 2 \cdot \frac12 = 1.5$$输出：```
1.500000000000000
```此示例说明了为什么直接计算概率比计算阈值有效分配更困难。

 ## 边缘情况

 考虑：```
2 1
3
```房间里的脸盆比学生还多。 对于阈值`t = 0`，房间最多可以接受`0`学生，因此 DP 无法同时安排这两名学生。 因此：$$P(\max \le 0)=0$$对于阈值`t = 1`，房间最多可容纳`3`学生，因此所有作业都有效：$$P(\max \le 1)=1$$期望正好变成`1`。 该算法可以正确处理此问题，因为它使用以下条件：$$k \le a_i t$$这对应于天花板划分，而不是楼层划分。 

现在考虑：```
5 1
2
```只有一间房间有两个脸盆。 每项作业都会将所有五个学生派到那里。 

对于阈值`t = 2`，房间最多可以接受`4`学生因为：$$2 \cdot 2 = 4$$DP 拒绝该分配。 

对于阈值`t = 3`，房间最多可容纳`6`学生，因此作业生效。 

因此最大队列大小恰好是`3`。 DP 精确地捕捉到了这个转变点。 

最后，考虑：```
2 2
100 100
```每个房间可以容纳任意数量的学生，同时保持队列大小`1`。 

对于阈值`t = 1`，每个房间限制变为`100`，因此每个可能的分配都是有效的。 DP 算所有的`2^2 = 4`分配和计算：$$P(\max \le 1)=1$$因此期望正是`1`。 空房间不会造成任何问题，因为总是允许分配零个学生。
