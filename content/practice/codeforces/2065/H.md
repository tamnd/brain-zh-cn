 ## 解决方案
 ## 问题理解

 该问题要求我们使用二进制字符串和翻转各个位的查询。 对于一个字符串$t$， 定义$f(t)$作为分割字符串的相同字符的连续块的最小数量。 例如，对于`00110001`，块是`[00][11][000][1]`和$f(t) = 4$。 每次翻转后，我们被要求计算$f(b)$遍历所有非空子序列$b$当前字符串的$s$。 最终总和必须以模数形式报告$998244353$。 

输入给出了多个测试用例。 每个测试用例都提供一个字符串和一系列翻转。 每次翻转都是累积的，因此一次查询后字符串的状态会影响下一次查询。 字符串长度和查询次数各能达到$2 \cdot 10^5$，并且所有测试用例的总和以相同的数字为界。 这意味着任何枚举子序列的简单解决方案都将太慢，因为子序列的数量是$2^n$，对于$n$靠近$10^5$。 

非明显的边缘情况包括所有字符都相同的字符串。 在这种情况下，$f(t) = 1$并且所有子序列仍然是一致的，在总和中产生非常规则的模式。 另一种微妙的情况发生在单次翻转分裂或合并块时，会发生巨大的变化$f(t)$对于许多子序列。 在每次查询后从头开始重新计算总和的幼稚方法将效率低下并在时间限制内失败。 

## 方法

 蛮力方法是枚举所有子序列$s$, 计算$f(b)$对于每个，并对它们求和。 这种方法原则上可行，但需要$O(2^n)$每个查询的操作，这是不可能的$n$可以达到$2 \cdot 10^5$。 即使对于小例子，这也变得不切实际，因为我们无法单独触及每个子序列。 

关键的见解来自以下观察：$f(b)$仅当子序列包含从 0 到 1 或 1 到 0 的“字符变化”时才会增加。让我们定义$dp[i]$作为总和$f(b)$遍历以位置结束的所有子序列$i$。 通过组合推理，我们可以看到每个位置$i$对总数的贡献与它从先前块延伸的子序列数量成正比。 如果$s[i]$等于$s[i-1]$，将其添加到任何先前的子序列不会引入新的块。 如果不同则增加$f(b)$对于包含前一个字符的所有子序列加 1。 这减少了问题$O(2^n)$到$O(n)$每个字符串评估。 

对于更新，翻转单个字符仅影响与其邻居的边界。 让$cnt$表示所有子序列的总和。 当我们翻转时$s[i]$，我们只需要调整可能的合并或拆分$s[i-1]$和$s[i+1]$。 使用 2 的幂来计算包含位置的子序列的数量，我们可以在每个查询的恒定时间内计算新的总和。 这将问题转化为一种有效的算法，可以使用组合恒等式处理初始计算和更新。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算两个模的幂$998244353$直到最大字符串长度。 这些表示包含给定位置的子序列的数量。 预计算允许$O(1)$稍后访问。 
2. 计算初始总和$f(b)$输入字符串的所有非空子序列$s$。 对于每对相邻字符，如果不同，则添加$2^{i-1}$到运行总数，因为包含这两个位置的所有子序列都会贡献一个额外的块。 对于单字符子序列，用以下命令初始化总和$n$因为每个字符单独形成一个块。 
3.对于每个查询翻转字符$s[v_i]$，检查其左右邻居。 如果角色被翻转，则重新计算受影响边界的贡献。 如果翻转合并两个先前不同的邻居，则减去相应的 2 的幂。 如果翻转分裂了相同的邻居，则将贡献加回去。 每次更新只触及两个边界，并且可以在恒定时间内完成。 
4. 调整翻转后，存储新的总和模$998244353$作为该查询的答案。 使用更新后的字符串状态继续处理下一个查询。 

这里的不变量是在每一个时刻，`total`持有总和$f(b)$当前字符串的所有子序列。 每次翻转仅影响边界，并且二次幂组合计数正确地对受影响的子序列的数量进行建模，因此算法在所有更新中保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    t = int(input())
    max_n = 2 * 10**5
    pow2 = [1] * (max_n + 2)
    for i in range(1, max_n + 2):
        pow2[i] = (pow2[i-1] * 2) % MOD

    for _ in range(t):
        s = list(input().strip())
        n = len(s)
        q = int(input())
        queries = list(map(lambda x: int(x)-1, input().split()))

        total = n  # sum of f(b) for subsequences of length 1
        for i in range(1, n):
            if s[i] != s[i-1]:
                total = (total + pow2[i-1]) % MOD

        res = []
        for idx in queries:
            for j in [idx-1, idx]:
                if 0 <= j < n-1:
                    if s[j] != s[j+1]:
                        total = (total - pow2[j] + MOD) % MOD
            s[idx] = '1' if s[idx] == '0' else '0'
            for j in [idx-1, idx]:
                if 0 <= j < n-1:
                    if s[j] != s[j+1]:
                        total = (total + pow2[j]) % MOD
            res.append(total)
        print(*res)

if __name__ == "__main__":
    solve()
```2 的幂的初始预计算允许恒定时间计算边界的贡献。 初始总和考虑包括一个字符的所有子序列，并添加相邻字符差异的贡献。 每个查询更新首先删除将要更改的边界处的旧贡献，翻转字符，然后添加新贡献。 在访问邻居之前仔细检查数组边界可以避免差一错误。 所有模运算确保总和保持在范围内。
