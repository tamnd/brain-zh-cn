 ## 解决方案
 ## 问题理解

 该问题要求我们分析一棵树，其中每个顶点都分配有一个数字，对于从 1 到 n 的每个数字，我们必须确定树中是否存在一条简单路径，其中该数字占多数。 简单路径是一系列不重复的相连顶点，多数是沿路径出现超过一半次数的数字。 该路径必须至少包含两个顶点。 

输入由多个测试用例组成，每个测试用例指定顶点数、顶点上的值以及连接它们的边。 输出是一个二进制字符串，其中每个位置对应于从 1 到 n 的数字； “1”表示存在该数量占多数的路径，而“0”表示不存在。 

鉴于 n 可以达到 500,000，并且所有测试用例的 n 总和也不超过 500,000，任何时间复杂度低于每个测试用例 O(n log n) 的解决方案都可能太慢。 枚举所有可能路径的朴素方法将是 O(n^2) 或更糟，因此不可行。 

当某个数字的所有出现都是叶节点或孤立在小分支中时，就会出现不明显的边缘情况。 例如，在大小为 4 且值为`[1,2,3,4]`路径 1-2-3-4 中，没有数字出现多次，因此所有输出都应为“0”。 粗心的方法可能会错误地将单个事件视为多数。 

## 方法

 暴力方法将检查树中的所有路径。 对于每个顶点值 i，我们将尝试找到长度至少为 2 的任何路径，并计算 i 沿着该路径的频率。 原则上这是可行的，因为我们直接检查多数的定义。 然而，树中的路径数量随 n 呈二次方增长； 具体来说，大约有 O(n^2) 条路径，使得这种方法对于 n 达到 500,000 时不可行。 每条路径还需要计算出现次数，因此在最坏情况下操作次数可能达到 O(n^3)，这远远超出了限制。 

解锁有效解决方案的关键观察是，如果存在一个子树，其中该值比沿任何路径组合的所有其他值出现的次数更多，则该值只能是路径上的多数。 特别是，对于给定值 v，如果树中存在两个叶子，使得 v 的所有出现都在它们之间的路径上，则 v 可能是多数。 这将问题简化为树中“值出现之间的最远距离”的形式。 

我们可以为每个测试用例使用一个 DFS 来实现这一点。 在 DFS 期间，我们跟踪每个值在树中最深的出现位置以及沿路径的第一个和最后一个出现位置之间的距离。 如果一个数字沿着树中的某个路径至少出现两次并且可以支配该路径中的其他数字，则它是多数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了|
 | 基于最优 DFS 的 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个字典，以存储每个值沿着任何 DFS 遍历在树中第一次和最后一次出现的情况。 
2. 从任意顶点开始执行 DFS，维护当前值沿路径出现的次数。 对于每个节点，更新迄今为止看到的相同值的出现之间的最大距离。 
3. 对于每个值，检查沿路径的最大距离是否大于或等于出现次数减去距离。 这确保了该值可以在某些路径上占据多数。 
4. 根据每个值是否满足多数条件，为每个测试用例构造二进制字符串。 
5. 输出结果字符串。 

为什么它有效：该算法之所以有效，是因为在树中，两个顶点之间的每条简单路径都是唯一的。 通过考虑每个值的最远出现次数，我们保证如果一个数字可以主导一条路径，那么它将出现在连接这些出现次数的路径上。 DFS 遍历使我们能够有效地收集这些信息，而无需枚举所有路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        edges = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            edges[u-1].append(v-1)
            edges[v-1].append(u-1)

        pos = defaultdict(list)
        for idx, val in enumerate(a):
            pos[val].append(idx)

        ans = ['0']*n
        for val, nodes in pos.items():
            if len(nodes) == 1:
                continue
            visited = [False]*n
            maxdist = 0
            def dfs(u, parent):
                nonlocal maxdist
                cnt = 1 if a[u]==val else 0
                for v in edges[u]:
                    if v == parent:
                        continue
                    res = dfs(v, u)
                    if a[u]==val and res>0:
                        maxdist = max(maxdist, res+1)
                    cnt += res
                return cnt
            dfs(nodes[0], -1)
            if maxdist >= 1:
                for node in nodes:
                    ans[node] = '1'
        print(''.join(ans))

if __name__ == "__main__":
    solve()
```该解决方案首先构建树的邻接表。 它收集每个值的所有出现的索引。 对于出现多次的值，它从第一次出现开始运行 DFS，以计算该值出现的最大路径距离。 如果该值出现在长度至少为 2 的路径上，我们将具有该值的所有节点标记为“1”。 

微妙的实现选择包括确保 DFS 避开父节点以防止循环，以及正确计算距离以保证多数条件。

 ## 边缘情况

 对于具有所有唯一值的树，例如`[1,2]`对于边 1-2，DFS 发现没有出现多次的值。 算法正确输出“00”。 对于所有节点都具有相同值的树，DFS 计算沿整棵树的距离，确认每个节点是该值占多数的路径的一部分，并按预期给出“111...”。 这证明了最小和最大多数条件的正确处理。
