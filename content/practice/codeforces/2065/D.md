 ## 解决方案
 ## 问题理解

 我们得到多个长度相等的数组，我们希望按某种顺序合并它们以最大化特殊分数。 单个数组的分数是通过对其所有前缀和求和来计算的。 例如，如果一个数组是`[a, b, c]`，其得分为`a + (a+b) + (a+b+c) = 3a + 2b + c`。 当我们连接多个数组时，前缀跨越数组，因此数组连接的顺序会影响总分。 

输入提供`t`测试用例。 每个测试用例给出`n`长度数组`m`。 任务是选择连接这些数组的顺序，以使最终得分（定义为连接数组的所有前缀和的总和）最大化。 

这些限制意味着我们最多可以有`2*10^5`所有测试用例的总元素，因此任何解决方案都慢于`O(n*m log n)`每个测试用例可能会超时。 这排除了所有的暴力枚举`n!`排列。 边缘情况包括具有相同元素的数组、具有非常大或非常小的元素的数组以及元素之和为负的数组（尽管在此问题中所有元素均为正）。 

简单的实现可以简单地独立地对数组分数求和并忽略顺序。 这会失败，因为数组出现得越早，其元素从后续前缀和中获得的权重就越大。 例如，与将其放置在前面相比，将大型数组放置在末尾会大大减少其贡献。 

## 方法

 暴力方法在概念上很简单：枚举数组的所有排列，连接每个排列，计算每个连接数组的分数，然后选择最大值。 为了`n`长度数组`m`，计算一个排列的分数需要`O(n*m)`并且有`n!`排列。 即使对于小公司来说，这也是不可行的`n`像8个或10个。 

关键的见解是数组的分数贡献取决于其内部前缀和及其相对于其他数组的位置。 我们可以为每个数组预先计算两个值：其总和及其前缀和的总和。 让`S`是数组中元素的总和`PS`是其前缀和的总和。 如果数组出现在位置`k`，其贡献为`PS + S * (sum of all elements of arrays before it)`。 这相当于一个加权调度问题：我们希望对数组进行排序，以最大化每个数组的内部前缀和加上其总和乘以已放置的元素总数的总和。 

从数学上讲，这相当于按数组的总和对数组进行排序`S`按降序排列。 总和较高的数组应该更早出现，因为由于后续数组，它们的元素会乘以更大的权重。 排序依据`S`最大化整个串联的加权贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n * m) | O(n! * n * m) | O(n*m) | 太慢了|
 | 最佳 | O(n*m + n log n) | O(n*m + n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`m`然后阅读`n`长度数组`m`。 
2. 对于每个数组，计算两个值：其元素之和 (`S`) 及其前缀和 (`PS`）。`S`表示该数组影响其后的数组时的总权重，而`PS`是其独立贡献。 
3. 按降序对数组进行排序`S`。 这确保了总和较大的数组首先出现，从而最大化它们对后续数组的加权贡献。 
4. 初始化`total_sum`为零和`result`为零。 遍历已排序的数组。 对于每个数组，添加`PS + total_sum * S`到`result`，然后递增`total_sum`经过`S`。 这会正确累积运行分数，考虑到较早的数组如何增加后面的数组的权重。 
5. 处理完所有数组后，`result`保留此测试用例的最高分数。 打印出来。 

工作原理：该算法在每一步都保持不变，到目前为止放置的元素的运行总和乘以下一个数组的总和。 通过按总和对数组进行排序，我们确保最大的数组尽早贡献，从而最大化它们的权重。 每个数组的内部前缀和也只添加一次。 没有其他排序可以产生更高的分数，因为将较小的和数组放在较大的数组之前会减少较大数组的乘法贡献，而贪婪排序可以防止这种情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        arrays = []
        for _ in range(n):
            arr = list(map(int, input().split()))
            total = sum(arr)
            prefix_sum = 0
            running = 0
            for x in arr:
                running += x
                prefix_sum += running
            arrays.append((total, prefix_sum))
        arrays.sort(reverse=True)  # sort by total sum descending
        total_sum = 0
        result = 0
        for total, prefix_sum in arrays:
            result += prefix_sum + total_sum * total
            total_sum += total
        print(result)

if __name__ == "__main__":
    main()
```该解决方案使用有效地读取输入`sys.stdin.readline`并将每个数组的总和和前缀总和存储为元组。 排序按降序就地完成，以优先考虑总和较大的数组。 最终结果是单次计算的，并保持运行总计。 关键的微妙之处包括正确计算每个数组的前缀和以及添加先前数组的乘法贡献。
