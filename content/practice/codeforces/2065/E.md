 ## 解决方案
 ## 问题理解

 该任务要求我们构造一个指定长度的二进制字符串，其中包含固定数量的`0`沙`1`s 使得计数之间的最大差异`0`沙`1`任何子串中的 s 都恰好是`k`。 换句话说，在字符串的所有可能的连续段中，最大的绝对差值是`0`s 和数量`1`s 必须恰好是`k`。 如果构造这样的字符串是不可能的，我们应该输出`-1`。 

输入提供多个测试用例，每个测试用例包含三个整数：`n`为计数`0`s,`m`为计数`1`沙`k`以获得所需的最大余额值。 全部的总和`n`和`m`所有测试用例不超过`2*10^5`，意味着`O(n+m)`每个测试用例的解决方案是可以接受的。 任何迭代所有子串的方法都会太慢，因为简单的子串评估是`O((n+m)^2)`，这将超过`10^10`最坏情况下的操作。 

微妙的边缘情况包括以下情况`k`超过两者`n`和`m`， 例如`n = 3, m = 2, k = 4`。 不可能创建余额为 4 的子串，因为计数之间的最大差异`0`沙`1`任何地方的 s 都不能超过其中一个字符的总数。 另一个棘手的情况是当其中一个计数为零时。 例如，`n = 5, m = 0, k = 5`只需重复即可实现`0`s，但是`k = 4`也是可以实现的，同时`k = 6`是不可能的。 粗心的方法可能无法检查这些限制。 

## 方法

 蛮力方法将生成所有可能的排列`n` `0`沙`m` `1`s，计算所有子串的平衡值，然后查看是否有任何排列完全达到`k`。 这原则上可行，但速度太慢，因为排列的数量呈阶乘增长（`O((n+m)!)`）并且评估所有子串会添加二次因子，使其对于给定的约束完全不可行。 

更快解决方案的关键见解是通过连续的相同字符来实现最大平衡值。 如果我们想要一个平衡的子串`k`，我们至少需要`k`连续的`0`或`1`s。 相反，如果`k`超过`n`或者`m`，这是不可能的，因为我们无法创建这样的运行。 由此，我们可以通过创建最多大小的块来构造字符串`k`, 之间交替`0`沙`1`s 以避免超出其他子串的余额。 始终将最大的块放在第一位，且尺寸准确`k`，我们保证所有子串之间的最大平衡是`k`。 任何剩余的字符都附加在较小的块中，以避免产生较大的余额。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((n+m)！ * (n+m)^2) | O(n+m) | 太慢了|
 | 最佳 | O(n+m) | O(n+m) | 已接受 |

 ## 算法演练

 1. 首先检查简单不可能的情况。 如果`k > max(n, m)`， 输出`-1`。 这是因为子字符串的数量不能超过单个字符的总数，因此需要平衡`k`无法实现。 
2. 初始化一个空结果字符串并跟踪剩余的`0`沙`1`作为`n_rem`和`m_rem`。 
3. 同时`n_rem`或者`m_rem`是积极的，决定接下来放置哪个角色。 首先放置一个大小的块`k`具有更多剩余计数的字符类型。 这确保了在字符串的早期实现最大平衡。 
4.放置一块大小后`k`，将该字符的剩余计数减少`k`。 
5. 放置一个相反类型的单个字符，以防止下一个块创建余额大于的子串`k`。 这种交替模式避免了超出平衡。 
6. 重复步骤 3-5，直到使用完所有字符。 如果另一个字符的剩余数量小于块大小，则一次将其全部放置。 
7. 将块连接成最终的字符串并输出。 

为什么它有效：该算法保持了一个不变量，即任何子字符串都不能超过`k`中断前连续的相同字符。 始终放置一块尺寸准确的块`k`首先，余额值`k`实现了，然后通过交替，我们可以防止超过`k`。 这保证了所有子串之间的最大平衡恰好是`k`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        if k > max(n, m):
            print(-1)
            continue
        
        n_rem, m_rem = n, m
        res = []
        flip = 0 if n >= m else 1
        
        while n_rem > 0 or m_rem > 0:
            if flip == 0:
                block = min(k, n_rem)
                res.append('0' * block)
                n_rem -= block
                if m_rem > 0:
                    res.append('1')
                    m_rem -= 1
            else:
                block = min(k, m_rem)
                res.append('1' * block)
                m_rem -= block
                if n_rem > 0:
                    res.append('0')
                    n_rem -= 1
        print(''.join(res))

if __name__ == "__main__":
    solve()
```该解决方案首先检查所请求的余额是否不可能。 然后，它会根据剩余计数更多的字符来选择优先考虑的字符。 它构造大小的块`k`对于主要字符，然后交错其他字符的单个单元以防止平衡溢出。 交替模式持续到所有字符都被使用为止。
