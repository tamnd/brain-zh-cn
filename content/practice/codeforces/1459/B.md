 ## 解决方案
 ## 问题理解

 机器人开始于`(0, 0)`并准确地使`n`移动。 每个动作都有长度`1`。 

第一步可以是任何基本方向。 之后，机器人被迫在垂直和水平运动之间交替。 如果它刚刚向北或向南移动，那么下一步一定是向东或向西移动。 如果它刚刚向东或向西移动，那么下一步一定是向北或向南移动。 

我们没有被要求计算路径。 我们只关心在精确之后可以到达多少个不同的坐标`n`移动。 

输入包含单个整数`n`，输出是不同最终位置的数量。 

约束很小，`n ≤ 1000`，因此即使是二次模拟也很容易拟合。 真正的挑战是识别可到达点背后的数学模式。 

一个常见的错误是计算运动序列而不是最终坐标。 例如：

 输入：```
2
```机器人有许多有效的方向选择，但所有可到达的位置只有：```
(1,1), (1,-1), (-1,1), (-1,-1)
```正确答案是：```
4
```另一个微妙的情况是`n = 3`。 

机器人在一个轴上进行两次移动，在另一轴上进行一次移动。 可能的坐标是：```
(±2, ±1)
(±1, ±2)
```有八个不同的位置，所以答案是：```
8
```一个天真的尝试，假设机器人总是以半径为菱形结束`n`会产生错误的结果。 

最重要的观察是，对于奇数次和偶数次移动，奇偶性的表现不同，最终的公式完全取决于是否`n`是奇数还是偶数。 

## 方法

 最直接的方法就是暴力破解。 我们可以递归地生成每个有效的转弯序列，跟踪机器人的位置，并将所有可到达的端点存储在一个集合中。 

这是正确的，因为每个有效的运动序列都会被探索一次。 不幸的是，第一步之后总是有两个选择，左或右。 路径数量增长如下`4 · 2^(n-1)`。 

为了`n = 1000`，这是一个天文数字，完全无法计算。 

关键的观察来自于对机芯结构的观察。 

第一次移动后，方向永远在水平和垂直之间交替。 这意味着 x 坐标和 y 坐标是独立构建的。 

认为`n`是均匀的。 

那么正是`n/2`移动是水平的并且`n/2`移动是垂直的。 每个坐标是`n/2`值等于`+1`或者`-1`。 

总和`k`价值观`±1`可以采取：```
k + 1
```不同的值：```
-k, -k+2, ..., k-2, k
```因此 x 和 y 都有`k+1`的可能性。 然而，由于它们的奇偶性是相连的，所以只有一半的网格点出现。 仔细数一下可以得出：```
(k + 1)^2 + k^2
```在哪里`k = n/2`。 

现在假设`n`很奇怪。 

一轴接收`(n+1)/2`当另一个接收时移动`(n-1)/2`移动。 

让：```
a = (n+1)/2
b = (n-1)/2
```第一个坐标有`a+1`可能的值，第二个有`b+1`可能的值。 每个组合都是可以实现的，产生：```
(a + 1)(b + 1)
```替换：```
(a + 1)(b + 1)
= ((n+1)/2 + 1)((n-1)/2 + 1)
= ((n+1)/2 + 1)^2
```因为`b + 1 = (n+1)/2`。 

这产生了一个非常紧凑的公式。

 ## 算法演练

 1. 阅读`n`。 
2.如果`n`是偶数，设置`k = n / 2`。 
3. 将答案计算为：```
k² + (k + 1)²
```当两个轴接收相同数量的移动时，这会计算所有可到达的格点。 
4. 如果`n`为奇数，设：```
k = (n + 1) / 2
```5. 将答案计算为：```
(k + 1)²
```一轴得到`k`移动，另一个得到`k-1`移动，导致一组可到达的矩形值，其大小等于`(k+1)²`。 
6. 打印结果。 

### 为什么它有效

 机器人在水平和垂直运动之间交替。 完成所有移动后，每个坐标只是几个独立坐标的总和`+1`和`-1`贡献。 

如果一个轴接收到`m`移动时，其坐标可以精确取`m+1`值，因为可能的总和是：```
-m, -m+2, ..., m-2, m
```对于奇数`n`，两个轴接收不同数量的移动，并且可以独立实现可达到的 x 和 y 值的每个组合。 

对于甚至`n`，两个轴接收相同的移动次数。 可到达点分为两个奇偶类，其大小为`k²`和`(k+1)²`，给出最终计数`k² + (k+1)²`。 

这些计数恰好描述了每个可到达端点一次，因此公式是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 0:
    k = n // 2
    print(k * k + (k + 1) * (k + 1))
else:
    k = (n + 1) // 2
    print((k + 1) * (k + 1))
```该实现直接评估封闭式表达式。 

对于甚至`n`，两个轴接收相同的移动次数，因此我们使用`k² + (k+1)²`。 

对于奇数`n`，一个轴比另一轴多接收一次移动。 计数简化为`(k+1)²`， 在哪里`k = (n+1)/2`。 

所有算术都可以轻松地适合 Python 整数。 即使对于最大输入`n = 1000`，答案仅在`500000`。

```输出：```

### 边缘情况 2：第一个偶数值

 输入：```

```执行：```

```输出：```

```这是偶数情况公式首次出现的地方。 任何尝试重用这里的奇怪公式的实现都会立即失败。

answer = 500² + 501²
