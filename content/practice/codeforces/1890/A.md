 ## 解决方案
 ## 问题理解

 我们给出了几个测试用例，每个测试用例都包含一个正整数数组。 任务不是从头开始构造一个新数组，而是决定是否可以对给定元素重新排序，以便结果序列中的每对相邻元素具有相同的总和。 换句话说，重新排列后，第一个和第二个元素的总和必须等于第二个和第三个元素的总和，并且这种相等必须在整个数组中一直持续。 

关键的限制是我们可以任意排列数组，因此结构不是固定的。 我们只关心是否存在某种满足邻接和条件的排序。 

输入大小较小，每个测​​试用例最多 100 个元素，最多 100 个测试用例。 这意味着每个测试用例达到大约二次的任何解决方案都已经足够快，但我们仍然应该针对每个用例进行恒定或线性检查，因为问题的结构允许直接表征。 

一种简单的方法是尝试数组的所有排列并检查条件。 这是复杂性的阶乘，即使 n 等于 10 也是不可能的。 

更微妙的错误方法会假设排序有直接帮助，例如检查排序的数组是否满足条件。 这会失败，因为条件取决于邻接结构，而不是数量级。 

当值重复时，就会出现典型的误导情况。 例如，像 1, 1, 4, 5 这样的数组不能被设为有效，即使它包含可能表明灵活性的重复项。 贪婪的重新排列尝试经常会失败，因为局部修复破坏了相邻总和的全局相等性。 

核心困难在于约束耦合了每个相邻对，因此局部一致性迫使一个非常严格的全局结构。 

## 方法

 如果我们尝试暴力破解，我们会生成数组的每个排列并检查所有相邻的总和是否相等。 对于每个排列，我们计算 n 减一和，因此总复杂度变为 O(n!·n)。 即使 n 等于 10，这也已经超出了可行的限制。 

关键的观察结果来自于用代数形式写下条件的含义。 假设存在有效的安排。 那么对于每个索引 i，我们必须让 b[i] + b[i+1] 等于相同的常数 k。 比较连续的等式得到 b[i] + b[i+1] = b[i+1] + b[i+2]，它立即简化为 b[i] = b[i+2]。 这意味着序列必须在两个值之间严格交替。 

一旦我们到达这一点，整个结构就会崩溃成一个非常简单的模式。 任何有效的数组必须看起来像 x, y, x, y, x, y 等等，或者相反的起点。 因此，数组中最多可以出现两个不同的值。 如果存在两个以上不同的值，则没有排列可以满足条件。 

当恰好存在两个值时，例如频率为 c1 和 c2 的 x 和 y，唯一剩下的问题是我们是否可以将它们放在交替位置。 这些位置分为两组：索引 1、3、5 等，以及索引 2、4、6 等。 其中一组必须完全为 x，另一组必须完全为 y。 这会强制计数的多重集与数组长度的奇偶校验分割相匹配。 

对于长度n，一组的大小为ceil(n/2)，另一组的大小为floor(n/2)。 因此频率必须按某种顺序与这些大小完全匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!·n) | O(n!·n) | O(n) | 太慢了 |
 | 频率分析| O(n) | O(n) | 已接受 |

 ## 算法演练

1. 读取测试用例的数组并计算每个不同值的频率。 此步骤将问题从对元素排序减少到有关计数的推理，因为顺序将被隐式构造。 
2. 如果不同值的数量大于两个，则立即断定不存在有效排列。 这是根据交替要求得出的，该要求在任何有效序列中只允许有两个值。 
3. 如果只有一个不同的值，则该数组已经是平凡有效的，因为每个相邻的和都是相同的。 
4. 如果正好有两个不同的值，则提取它们的频率 c1 和 c2。 计算两个所需的组大小，即floor(n/2) 和ceil(n/2)。 
5. 检查多组频率是否与这两个组大小匹配。 如果 c1 和 c2 恰好是这两个值（无论顺序如何），则存在有效的交替排列。 
6. 否则，返回不可能进行有效安排。 

这些步骤背后的推理来自强制相等 b[i] = b[i+2]。 这将任何有效配置折叠成严格的双色位置，唯一剩下的自由是将哪个值分配给奇数索引，哪个值分配给偶数索引。 

### 为什么它有效

 相邻和条件强制每个第二个元素之间相等，因为在减去连续约束时，相等的和消除了中间项。 这创建了第二周期的刚性周期结构。 一旦知道了这个结构，问题就完全简化为检查给定的多重集是否可以分为与该交替模式的固定位置计数相匹配的两组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1
    
    if len(freq) == 1:
        print("Yes")
        return
    
    if len(freq) > 2:
        print("No")
        return
    
    vals = list(freq.values())
    vals.sort()
    
    n1 = n // 2
    n2 = n - n1
    
    if (vals[0] == n1 and vals[1] == n2) or (vals[0] == n2 and vals[1] == n1):
        print("Yes")
    else:
        print("No")

t = int(input())
for _ in range(t):
    solve()
```该解决方案将数组压缩为频率图，这是用计数推理代替排列推理的关键变换。 一个和两个以上不同值的特殊情况直接编码先前导出的结构约束。 最终检查将频率与索引的强制奇偶校验分割对齐。 

一个常见的实现陷阱是忘记这两个值可以分配给任一奇偶校验类。 这就是为什么对称检查两个分配的原因。

 ## 边缘情况

 一种边缘情况是数组恰好有两个元素。 任何两个数字的排序都满足该条件，因为只有一个相邻的和。 该算法隐式处理此问题，因为频率大小与 1 和 1 所需的分割相匹配。 

另一种极端情况是所有元素都相同。 在这种情况下，频率图的大小为一，算法立即返回成功。 这符合任何排列都保留恒定邻接和的事实。 

当恰好有两个不同的值但计数以与奇偶校验分割不匹配的方式不平衡时，会发生更微妙的情况。 例如，在长度为 5 的数组中，如果计数为 4 和 1，则任何交替排列都无法将值正确分配到位置 1、3、5 和 2,4。 该算法会拒绝这种情况，因为排序后的频率对与 3 和 2 不匹配。 

这些案例证实，基于频率的条件完全捕获了邻接和要求所施加的所有结构约束。
