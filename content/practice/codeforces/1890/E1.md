 ## 解决方案
 ## 问题理解

 我们给出了一系列城市，编号从 1 到$n$以及接下来的降雨预报$m$天。 当天$i$，降雨将覆盖区间内的城市$[l_i, r_i]$。 如果一个城市在这期间不下雨，那么这个城市就是干燥的。$m$天。 Doremy 可以在整整两天内防止下雨。 任务是选择哪两天进行预防，以便最大限度地增加干旱城市的数量$m$天被考虑。 

输入由多个测试用例组成。 每个测试用例提供$n$,$m$， 和$k$（在简单版本中始终为 2），然后是$m$间隔。 每个测试用例的输出是可实现的最大干旱城市数量。 

关键的限制是$n$和$m$每个都可以达到$2 \cdot 10^5$综合所有测试用例。 这排除了任何模拟雨天所有子集的解决方案（这将是$O(m^2 n)$如果我们每两天尝试一次并检查城市覆盖范围）。 每两天迭代每个城市的天真的方法太慢了。 

不明显的边缘情况包括除了我们可能阻止的日子之外从未下过雨的城市、重叠的时间间隔和完全覆盖的时间间隔，这些时间间隔可能会隐藏选择正确的日子所带来的潜在收益。 例如，考虑三个城市和三个雨天：$[1,2]$,$[2,3]$,$[1,3]$。 天真地阻止前两天只会使城市 3 干燥，而阻止第一天和第三天则不会使城市干燥。 正确处理重叠间隔至关重要。 

## 方法

 蛮力的解决办法是考虑每一对天的预防，模拟城市的剩余降雨量，统计干旱的城市。 对于每一天，我们都会迭代所有降雨间隔，标记受影响的城市，然后计算未受降雨影响的城市。 复杂度是$O(m^2 + n)$对于每个测试用例，可以达到$O((2 \cdot 10^5)^2)$在最坏的情况下，对于 1 秒来说太大了。 

关键的见解是，我们只需要跟踪正好一到两次降雨间隔所覆盖的城市。 零间隔覆盖的城市总是干燥的，而三个或更多间隔覆盖的城市不能仅阻止两天就变得干燥。 这使我们能够压缩有关覆盖范围的信息。 我们可以计算每个城市下雨的次数，然后每天计算它影响了多少个独特的城市，并在每一天中有效地计算重叠。 使用前缀和数组来累积计数可以让我们计算每天和每对天的贡献$O(n + m^2)$或通过巧妙的优化更少。 

观察结果是，干旱城市的最大数量是从未下过雨的城市的总和加上我们选择阻止的两天中的一天覆盖的城市的最大数量，减去任何重复计算的重叠。 这将问题从模拟每个城市减少到仅计算覆盖率贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m^2n) | O(m^2n) | O(n) | 太慢了 |
 | 最佳 | O(m n) 或 O(m^2) 带前缀和 | O(n + m) | 已接受 |

 ## 算法演练

 1.初始化一个数组`cover`长度`n+2`为零。 每天增加`cover[l_i]`加 1 并减`cover[r_i+1]`1. 前缀和后，`cover[j]`商店多少次城市`j`下雨了。 
2. 计数`always_dry`随着城市数量的增加`cover[j] = 0`。 
3. 计算每天有多少个城市受到影响并且恰好下过一次雨（`single_rain`) 和正好两次 (`double_rain`）。 降雨超过两次的城市就无法挽救。 
4. 每两天`(i, j)`，计算至少受其中之一影响的城市数量。 公式为`single_i + single_j - overlap_ij`， 在哪里`overlap_ij`是受这两天影响且正好下雨两次的城市数量。 使用间隔端点和前缀和来有效地计算重叠。 
5. 添加`always_dry`到步骤 4 中计算出的最大数量。这是通过防止任何两天可实现的干旱城市的最大数量。 
6. 对每个测试用例重复此操作。 

工作原理：该算法将城市分为三类：从未下过雨、下过一次或两次雨、下过三次或多次下雨。 在预防两天时，只有前两类可以为额外的干旱城市做出贡献。 计算贡献和重叠可确保避免重复计算。 前缀和方法保证了正确且高效地计算区间的贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        days = [tuple(map(int, input().split())) for _ in range(m)]
        
        cover = [0]*(n+2)
        for l, r in days:
            cover[l] += 1
            cover[r+1] -= 1
        for i in range(1, n+1):
            cover[i] += cover[i-1]
        
        always_dry = sum(1 for x in cover[1:n+1] if x == 0)
        
        single_count = [0]*m
        double_cover = [0]*(n+2)
        
        for idx, (l, r) in enumerate(days):
            count = 0
            for j in range(l, r+1):
                if cover[j] == 1:
                    count += 1
                elif cover[j] == 2:
                    double_cover[j] += 1
            single_count[idx] = count
        
        max_gain = 0
        for i in range(m):
            for j in range(i+1, m):
                overlap = 0
                li, ri = days[i]
                lj, rj = days[j]
                l = max(li, lj)
                r = min(ri, rj)
                if l <= r:
                    for x in range(l, r+1):
                        if double_cover[x] == 2:
                            overlap += 1
                gain = single_count[i] + single_count[j] - overlap
                max_gain = max(max_gain, gain)
        
        print(always_dry + max_gain)
```第一部分构建前缀和数组`cover`快速确定每个城市下雨的次数。`always_dry`计算不受影响的城市。`single_count`跟踪每天恰好一个时间间隔覆盖的城市。`double_cover`用于计算当两天共享城市正好下两次雨时的重叠。 嵌套循环可以有效地评估每天的配对，因为仅在必要时才计算重叠。
