 ## 解决方案
 ## 问题理解

 数字 (n) 是故意从异常接近的质因数生成的。 对于(k=2)，有两个不同的(b)位素数(p_1，p_2)，其中(p_2)是紧接在(p_1)之后的素数，并且(n=p_1p_2)。 对于 (k=4)，有两个独立的这样的对，所以

 [
 n=p_1p_2q_1q_2。 
]

 每个素数都恰好有 (b) 位，并且所有素数因子都是不同的。 输入给出 (b)，无论有两个还是四个因子，以及十六进制的 (n)。 我们必须以十六进制打印质因数。 这些保证是我们利用的数学结构的一部分，而不仅仅是验证条件。 

最大可能的 (n) 有 (4b\le240) 位。 这对于普通的审判部门来说太大了。 尽管所有因子本身只有 60 位，但在最坏的情况下，尝试直到第一个因子为止的所有可能的除数可能需要大约 (2^{60}) 次除法。 对于 (k=4)，搜索直到 (\sqrt n) 的所有除数的通常通用界限会更糟，大约为 (2^{120}) 个候选者。 一秒的限制排除了这两种方法。 

该构造的有用部分并不在于素数仅仅是 60 位数字。 连续素数很接近，因此它们的乘积允许彼此极其接近的因子对。 紧密因子对正是费马分解方法的目的。 

有几种边缘情况，粗心的实现可能会处理不当。 第一个是从 (\sqrt n) 的下限而不是上限开始费马搜索。 例如，```
4 2
dd
```表示 (221=13\cdot17)。 由于 (\sqrt{221}) 位于 14 和 15 之间，因此正确的起始值为 (a=15)。 然后(15^2-221=4=2^2)，给出(13)和(17)。 从 14 开始会产生负差，因此立即对其调用整数平方根的实现会失败。 

第二种边缘情况假设 (a) 只能通过奇数值前进。 对于样品```
4 2
8f
```我们有(143=11\cdot13)，成功的值为(a=12)，它是偶数。 将搜索限制为奇数 (a) 将完全跳过答案。 

第三种边缘情况出现在 (k=4) 时。 为了```
6 4
534ee3
```因子是 (37,41,59,61)。 一种费马表示给出 (2257=37\cdot61) 和 (2419=41\cdot59)，但这些不是素因数。 在找到一种表示后停止的解决方案仅找到了两个复合除数。 我们需要另一种表示形式，然后需要结果除数之间的 gcd。 

最后，具有所有相等素因数的输入不是有效的测试用例。 该声明明确保证所有因素都是不同的，因此 (11\cdot11) 等测试将违反输入契约。 特别是，正确的测试套件不应期望提交的解决方案能够处理无效情况。 

## 方法

 最直接的方法是试分割。 从2开始，测试每个整数能否整除(n)，找到足够的因子后停止。 这是正确的，因为每个复合整数都有一个不大于其平方根的除数，并且这里第一个质因数本身大约为 (2^{b-1}) 或更大。 对于 (b=60)，这意味着可能约为 (2^{60}) 整除性测试。 即使每次测试的费用都极其低廉，但这也远远超出了时间限制。 

生成的素数的结构为我们提供了一个更好的起点。 首先假设 (k=2)，因此 (n=pq) 和 (p,q) 接近。 写

 [
 a=\frac{p+q}{2},\qquad c=\frac{q-p}{2}.
 ]

 因为 (p) 和 (q) 是奇数，所以两个表达式都是整数。 然后

 [
 n=pq=(a-c)(a+c)=a^2-c^2。 
]

 因此，

 [
 a^2-n=c^2。 
]

 我们不是搜索除数，而是搜索 (a^2-n) 是完美平方的最小 (a\ge\sqrt n)。 一旦找到这样的（a），两个因子就是（a-c）和（a+c）。 

这就是费马分解。 这里速度快的原因与生成过程较弱的原因相同：两个素因数很接近。 如果它们的差为(g=q-p)，则(a)的成功值仅约为

 [
 \frac{g^2}{8\sqrt n}
 ]

 远离 (\sqrt n) 的位置。 对于 (2^b) 附近的连续素数，典型的间隙位于素数大小的对数尺度上，因此对于 (b\le60) 来说，此搜索很小。 (x) 附近素数之间的平均差距大约为 (\ln x)。 

四因素情况最初看起来更困难，因为 (n) 不一定是两个接近数的乘积。 关键是将四个素数以不同的方式配对。 考虑

 [
 n=(p_1q_1)(p_2q_2)。 
]

 由于 (p_1,p_2) 接近且 (q_1,q_2) 接近，因此这两个乘积也接近。 我们可以类似地使用

 [
 n=(p_1q_2)(p_2q_1)。 
]

 两者都是有效的费马分解。 它们的四个因子是复合的，但它们每次只重叠一个素数。 例如，

 [
 \gcd(p_1q_1,p_1q_2)=p_1。 
]

 因此，一旦我们有了几个相近的因子对，普通的 gcd 运算就可以恢复各个素数。 

官方解决方案遵循相同的平方差思想，收集由费马表示产生的几个除数，然后在它们之间取 gcd。 

蛮力方法之所以有效，是因为整除性最终会暴露一个质因数，但会失败，因为该因数本身可能是 60 位。 观察到生成的因子是连续的素数，我们可以搜索平方差，从而将工作量从 (b) 中的指数搜索减少到由小的素数间隙控制的搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 最坏情况下的 (O(2^b)) 次除法 | (O(1)) | (O(1)) | 太慢了 |
 | 最佳| (O(T\cdot M(b)))，其中 (T) 由小的素数间隙控制 | (O(k)) | 已接受 |

 这里（M（b））表示（O（b））位整数的算术成本，（T）是测试的费马候选数。 对于生成的随机素数，(T) 非常小。 对于四因子构造，如果两个连续素数间隙是 (g) 和 (h)，则紧密的交叉对乘积会导致大约 (O((g+h)^2)) 费马迭代，这对于 (b\le60) 来说很小。 

## 算法演练

1. 将(n)从十六进制解析为Python的任意精度整数类型。 Python整数可以直接表示完整的240位值，因此不存在溢出问题。 
2. 计算 (a=\lceil\sqrt n\rceil)。 费马恒等式需要 (a^2-n\ge0)，因此从上限开始可以避免负值。 
3. 反复计算

 [
 d=a^2-n
 ]

 并测试 (d) 是否是完全平方数。 我们计算 (s=\lfloor\sqrt d\rfloor) 并检查是否 (s^2=d)。 如果是的话，那么

 [
 n=a^2-s^2=(a-s)(a+s),
 ]

 所以 (a-s) 和 (a+s) 都是 (n) 的约数。 我们将它们插入一个集合中，因为相同的除数可以由不同的表示产生。 

1. 继续下去，直到找到至少 (k) 个不同的约数。 对于(k=2)，第一个成功的表示必须是两个素因子本身，因为(n)恰好有两个素因子。 
2. 对于(k=4)，取上一步中收集的每对不同除数的最大公约数。 每个收集的除数都是四个原始素数中两个的乘积。 两个不同的此类乘积要么不共享素数，要么恰好共享一个素数，因此它们的 gcd 要么是 1，要么是所需素数之一。 
3. 保持所有 gcd 大于 1，对所得质因子进行排序，并以十六进制打印它们。 输出顺序在数学上并不重要，但排序使结果具有确定性。 

### 为什么它有效

 不变的是，插入除数集合中的每个数字都是 (n) 的真除数，因为它来自恒等式 (n=(a-s)(a+s))。 在双因子情况下，任何非平凡因子对都完全由两个素因子组成。 在四因子情况下，两个交叉对分解会产生四个不同的乘积，例如 (p_1q_1,p_2q_2,p_1q_2,p_2q_1)。 由于这四个素数是不同的，因此在这些乘积之间采用 gcd 可以分离出每个素数。 因此，最终打印的每个值都是素数并能整除 (n)，同时恢复所需数量的不同素数因子。 

## Python 解决方案```python
import sys
from math import isqrt, gcd

input = sys.stdin.readline

def factor_case(b, k, n):
    a = isqrt(n)
    if a * a < n:
        a += 1

    divs = set()

    while len(divs) < k:
        d = a * a - n
        s = isqrt(d)

        if s * s == d:
            divs.add(a - s)
            divs.add(a + s)

        a += 1

    if k == 2:
        ans = sorted(divs)
    else:
        values = list(divs)
        ans = set()

        for i in range(len(values)):
            for j in range(i + 1, len(values)):
                g = gcd(values[i], values[j])
                if g > 1:
                    ans.add(g)

        ans = sorted(ans)

    return ans[:k]

def solve():
    b, k = map(int, input().split())
    n = int(input().strip(), 16)

    ans = factor_case(b, k, n)

    for x in ans:
        print(format(x, "x"))

if __name__ == "__main__":
    solve()
```第一部分`factor_case`建立费马搜索点。`isqrt(n)`返回下限，因此当 (n) 不是完全平方数时，需要显式乘法检查才能移动到上限。 

主循环直接反映平方差恒等式。 因为 (a\ge\lceil\sqrt n\rceil),`d`永远不会是负数。`isqrt(d)`给出其平方最多为的最大整数`d`，并比较`s * s`和`d`是精确的完全平方检验。 

套装`divs`故意使用而不是列表。 平方表示给出两个除数，并且多个表示可以包含相同的除数。 停止条件要求不同的除数，匹配四因素情况所需的逻辑。 

对于(k=2)，从第一个成功表示得到的约数已经是两个素数。 对于 (k=4)，代码不执行素性测试。 这是安全的，因为我们收集的每个除数都是四个不同素数中两个的乘积。 两个不同的此类乘积不能具有复合 gcd：如果它们共享两个素数，则它们将是相同的乘积。 因此，它们的 gcd 要么是 1，要么是一个原始素数。 

Python 的任意精度整数在这里特别方便。 (n)的最大值只有240位，因此乘法、减法、平方根和gcd都是实用的。 

十六进制转换使用`format(x, "x")`。 它生成不带前导零的小写十六进制，与所需的表示完全匹配。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(T\cdot M(b)+k^2\log n)) | (T) 测试 Fermat 候选者，然后测试 (k=4) | 的最多 6 个 gcd
 | 空间| (O(k)) | 最多存储四个不同的约数和四个恢复的素数 |

 重要的量是 (T)，而不是 (n) 本身的大小。 对于具有间隙 (g) 的两个因子，费马在大约 (g^2/(8\sqrt n)) 增量后得出答案。 对于四个因子，如果两个连续素数间隙为 (g) 和 (h)，则交叉配对的差异约为 (2^b(g+h))，而其平方根约为 (2^{2b})。 最终的迭代次数大约为 ((g+h)^2/8)。 (2^b) 周围的连续素数间隙在此处相关的尺度上很小，因此对于 (b\le60) 来说搜索很容易实用。 问题的一秒限制是围绕这个结构快捷方式设计的。

## 边缘情况

 地板与天花板边界是通过显式检查来处理的`a * a < n`。 为了```
4 2
dd
```我们有（n=221），`isqrt(221)`给出 14，代码将其递增到 15。然后得到 (15^2-221=4)，因此除数为 (15-2=13) 和 (15+2=17)，打印为`d`和`11`。 

通过将 (a) 恰好增加 1 来处理奇偶校验问题。 为了```
4 2
8f
```成功值为(a=12)。 仅检查奇数值的搜索将检查 11、13、15 等，并且永远不会遇到 12 处所需的表示。该实现不会对 (a) 做出任何奇偶校验假设。 

四因子情况需要多个因子分解恒等式。 为了```
6 4
534ee3
```第一个方形表示产生 (2257) 和 (2419)，对应于 (37\cdot61) 和 (41\cdot59)。 第二个产生 (2183) 和 (2501)，对应于 (37\cdot59) 和 (41\cdot61)。 它们的成对 gcd 隔离了所有四个素数。 基于集合的停止条件保证算法在仅发现一对后不会停止。 

十六进制解析由`int(..., 16)`，因此即使示例使用小写字母，也接受大写和小写输入数字。 输出是用小写十六进制生成的，没有前导零，因此十进制 11 和 13 之类的值恰好变成`b`和`d`。 

最大值不需要特殊的溢出处理。 Python 的任意精度整数轻松支持 240 位整数，并且所有中间值（例如 (a^2)）仍保持可管理的大小。 该实现永远不会将 (n) 转换为浮点，这避免了当 (n) 接近 (2^{240}) 时丢失精度。 

有效测试中故意缺少全等因素情况。 例如，`4 2`(n=121) 表示 (11\cdot11)，但输入保证禁止重复因子。 允许解依赖于唯一性，并且gcd步骤的证明也依赖于它。
