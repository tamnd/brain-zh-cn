 ## 解决方案
 ## 问题理解

 我们已知边长`n`一个正方形。 该正方形必须包含以下每个整数`1`通过`n²`恰好一次，每行、每列和两条主对角线的总和相同。 所需的输出只是该公和，而不是平方本身。 如果这个尺寸不存在这样的正常幻方，我们打印`FAIL`。 

关键的区别是我们实际上不必构建正方形。 一旦存在有效的方格，它的公和就被强制。 所有值的总和`1`到`n²`是

 [
 1+2+\dots+n^2=\frac{n^2(n^2+1)}2.
 ]

有`n`行，并且每行具有相同的总和`m`，所以总数也是`n*m`。 使两个表达式相等给出

 [
 n m = \frac{n^2(n^2+1)}2,
 ]

 因此

 [
 m=\frac{n(n^2+1)}2.
 ]

 剩下的问题只是是否存在一个正常的幻方`n`。 经典存在定理指出，对于除`n = 2`。 订单`1`正方形只是`[1]`，奇数阶具有标准结构，例如连体方法，偶数阶`n >= 4`还具有双偶数和单偶数的标准结构。 因此给定范围内唯一不可能的输入是`2`。 

约束条件`n <= 1000`让这变得特别简单。 甚至一个`O(n²)`构造是不必要的，因为所请求的答案仅取决于`n`。 常数时间公式更好，并且根本不使用矩阵。 

有两种边缘情况很容易被误处理。 用于输入`1`，粗心的实现可能会假设幻方需要至少三行并打印`FAIL`， 但`[1]`是有效的，答案是`1`。 用于输入`2`，公式给出`5`，但不得打印该数字，因为`2 × 2`正常的幻方不存在。 必须对这四个数字进行排列，使所有四行总和一致，这是不可能的。 

例如，输入`1`产生：```
1
```输入时`2`产生：```
FAIL
```第一种情况是有效的，因为唯一的行、列和对角线都包含数字`1`。 第二种情况说明了为什么单独计算公式是不够的。 

## 方法

 直接的暴力方法会尝试所有可能的数字位置`1`通过`n²`，然后检查所得正方形的行、列和对角线之和是否相等。 有`(n²)!`可能的安排，并检查一种安排需要`O(n²)`简单实现的时间。 因此，最坏情况的复杂度是`O(n² * (n²)!)`。 Even for`n = 3`，这已经意味着检查`9! = 362880`安排，并为`n = 4`数字变成`16!`，这已经远远超出了实际的枚举范围。 

蛮力方法之所以有效，是因为它明确地搜索可能正方形的整个空间，但这种搜索解决的问题比法官提出的问题要困难得多。 我们没有被要求输出排列，只输出其公共线和。 

关键的观察是，共同总和完全由所有条目的总和决定。 每个有效方格都使用完全相同的数字，因此其总数是固定的。 自从`n`行总和相等，将总和除以`n`立即确定`m`。 我们只需要检查普通幻方的已知存在条件。 

这将问题简化为一种特殊情况和一种算术表达式。 为了`n = 2`， 打印`FAIL`。 对于所有其他积极的`n`， 打印`n * (n² + 1) / 2`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(n² * (n²)!)`|`O(n²)`| 太慢了|
 | 最佳 |`O(1)`|`O(1)`| 已接受 |

 ## 算法演练

 1.读取边长`n`。 输入仅包含一个正方形大小，因此不需要任何额外的数据结构。 
2.如果`n == 2`， 打印`FAIL`并停止。 正常的二阶幻方并不存在。 
3. 否则，计算正方形中所有值的总和。 由于条目完全是`1`通过`n²`，这个总数是`n²(n² + 1) / 2`。 
4. 将总数除以`n`行总和相等。 结果值是唯一可能的魔法常数，

 [
 m=\frac{n(n^2+1)}2.
 ]

 1. 打印`m`。 对于每一个`n != 2`，存在一个正常的幻方，因此这个强制值实际上是可以获得的。 

### 为什么它有效

 假设存在一个有效的正方形。 它是`n²`单元格包含来自的每个整数`1`到`n²`，所以所有单元格的总和固定为`n²(n²+1)/2`。 同时，细胞可以分为`n`行，每行都有总和`m`，所以他们的总数是`n*m`。 这两个总数必须相等，迫使`m = n(n²+1)/2`。 正常幻方不存在的唯一正序是`2`，因此检查一个顺序足以区分存在与不可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 2:
        print("FAIL")
        return

    print(n * (n * n + 1) // 2)

if __name__ == "__main__":
    solve()
```第一个分支处理独特的不可能订单。 它必须出现在公式之前，因为公式本身在数学上是有效的，作为`n = 2`，但是没有一个方块能够实现它。 

乘法使用Python整数，因此不存在溢出问题。 对于最大允许值`n = 1000`，表达式的计算结果为`1000 * 1000001 / 2 = 500000500`，它很容易在 Python 的整数范围内，也在典型的 32 位有符号整数的范围内。 

这`// 2`操作是准确的，因为`n(n² + 1)`总是均匀的。 如果`n`是偶数，因数`n`是均匀的。 如果`n`是奇数，那么`n²`是奇数并且`n² + 1`是均匀的。
