 ## 解决方案
 ## 问题理解

 我们有一堆`n`曲奇饼。 两名玩家交替移除饼干，X 教授首先移动。 合法的举动删除了`p^k`饼干，在哪里`p`是素数并且`k`是一个非负整数。 自从`k = 0`是允许的，完全删除`1`cookie 始终是合法的。 移除最后一块饼干的玩家获胜。 

任务是确定哪位教授在最佳发挥下获胜。 如果 X 获胜，我们还需要输出一个合法的第一步，使 Y 教授处于失败的位置。 

输入包含一个整数`n`，cookie 的初始数量，其中`1 <= n <= 10^9`。 针对所有位置的动态编程解决方案已经需要处理多达十亿个状态，这远远超出了可用时间和内存的范围。 即使优化的筛子或素数生成也不能解决真正的问题，因为游戏本身的结构要简单得多。 获胜策略只需使用`n mod 6`。 

在一些小情况下，基于不完整的移动列表的实现可能会失败。 为了`n = 1`, X 可以去除`1 = 2^0`，所以正确的输出是`X WINS`其次是`1`。 将指数视为正数的解决方案会错误地声称 X 没有移动。 

为了`n = 4`, X 通过移除获胜`4 = 2^2`，留下零个cookie。 因此正确的输出是`X WINS`其次是`4`。 这捕获了仅生成素数并忘记更高素数幂的实现。 

为了`n = 6`，正确的输出是`Y WINS`。 诱人的举动`2`树叶`4`， 但`4`本身就是为下一个玩家赢得胜利。 事实上，每一个合法的举动`6`留下非倍数`6`，以及每个非倍数`6`正在获胜。 

为了`n = 12`，正确的输出又是`Y WINS`。 同样的论点也适用，因为`12`可以整除`6`。 一个粗心的实现，只检查是否`n`这本身就是一个合法的举动，而不是分析由此产生的立场，可能会让这个案子出错。 

## 方法

 直接游戏求解器会对每个位置进行分类`0`通过`n`。 位置`0`输了，因为要移动的玩家没有 cookie。 对于每个正位置，我们将尝试不超过该位置的每个素数幂。 如果至少有一步棋达到了失败的位置，则该位置为获胜；如果每一个合法的棋步都达到了获胜的位置，则该位置为失败。 

这种递推式是正确的，因为博弈是有限的。 一旦进行移动，cookie 的数量就会严格减少，因此位置可以从较小的值到较大的值进行分类。 问题在于它的大小。 即使只考虑主要动作，也有`50,847,534`素数不超过`10^9`。 一个简单的 DP 拥有多达 10 亿个状态，检查每个状态的许多合法动作会导致大量操作，远远超出 1.5 秒的限制。 增加主要权力并不能改善情况。 

蛮力之所以有效，是因为游戏图是非循环的，但它失败了，因为它将所有位置视为不相关。 关键的观察结果是，合法的移动与余数模完美地相互作用`6`。 

每一个合法的举动都是一个主要的力量。 这些数字都不能被`6`，因为素数幂只有一个素因数。 现在考虑一个位置可以被`6`。 减去任何合法的移动会产生一个不能被整除的数字`6`。 相反，每个非零余数模`6`可以通过五个小的合法动作之一直接删除：`1`是`p^0`,`2`和`3`是素数，`4 = 2^2`， 和`5`是素数。 

认为`n`有残留物`1`模数`6`。 去除`1`达到的倍数`6`。 对于残留物`2`， 消除`2`; 对于残留物`3`， 消除`3`; 对于残留物`4`， 消除`4`; 和残留物`5`， 消除`5`。 因此每个非倍数`6`移动到多个`6`。 

这给出了完整的表征。 正好是正倍数`6`正在失去职位。 从多个`6`，每一个合法的举动都会涉及到一个非倍数`6`，即获胜。 从每个非倍数`6`，其中之一`1, 2, 3, 4, 5`达到的倍数`6`，给当前玩家一个获胜的棋步。

 ## 算法演练

 1.读取cookie初始数量`n`。 只取其余数`6`很重要，因为亏损头寸恰好是`6`。 
2. 计算`r = n % 6`。 如果`r == 0`， 输出`Y WINS`。 X 没有获胜的第一步，因为每个合法的移动都有一个非零的余数模`6`，所以所得的堆不能被整除`6`。 
3.如果`r != 0`， 输出`X WINS`并选择`r`作为X的第一步。 价值`r`总是合法的：`1`是任何素数的零次方，`2`和`3`是素数，`4`是`2^2`， 和`5`是素数。 
4. 移除后`r`，剩下的数是`n - r`，可除以`6`。 因此，Y 教授处于劣势。 无论 Y 做出什么合法的举动，所得的数字都不能被`6`，所以 X 可以再次移回到`6`。 重复这个策略最终会给 X 留下零个饼干。 

### 为什么它有效

 不变量是 X 总能将游戏返回到`6`Y移动后。 的倍数`6`无法移动到另一个倍数`6`，因为没有合法的移动可以被整除`6`。 另一方面，从每个非倍数`6`, X 可以去除其模余数`6`，而这种残留始终是合法的举动之一`1, 2, 3, 4, 5`。 因此，的倍数`6`正是失败的位置，算法既能识别获胜者，又能提供获胜的第一步。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    move = n % 6

    if move == 0:
        print("Y WINS")
    else:
        print("X WINS")
        print(move)

if __name__ == "__main__":
    solve()
```该程序读取唯一的输入值并计算其余数模`6`。 不需要生成素数，因为我们明确选择的唯一动作是五个最小的相关素数幂。 

当余数为零时，位置丢失，因此仅打印第一输出行。 当余数非零时，余数本身就是合法的移动并打印在第二行。 

边界`n = 1`自动工作：`1 % 6 = 1`，因此 X 删除了一个 cookie。 Python 中不存在溢出问题，即使在固定宽度语言中，所有涉及的值也最多是`10^9`。 

操作顺序在概念上也很重要。 我们必须测试`n % 6`在选择行动之前。 余数为零意味着没有任何移动可以保持整除性`6`，而非零余数则准确给出到达失败类别所需的移动。

 ## 边缘情况

 对于`n = 1`，算法计算`1 % 6 = 1`。 它选择移动`1`，这是合法的，因为`1 = 2^0`，剩余的堆为零。 输出是`X WINS`其次是`1`。 

为了`n = 4`，余数为`4`。 算法选择移动`4`， 和`4`是合法的，因为`4 = 2^2`。 堆立即变为零，所以 X 获胜。 这种情况验证了移动集包含超出素数本身的素数幂。 

为了`n = 6`，余数为零，因此算法报告`Y WINS`。 如果 X 移除`1`,`2`,`3`,`4`， 或者`5`，剩下的一堆分别是`5`,`4`,`3`,`2`， 或者`1`，所有非倍数`6`。 每个位置都可以让下一个玩家移除相应的残留物并返回到多个位置`6`。 

为了`n = 12`，完全相同的论点适用。 每一个合法的举动都会留下一个残留物`1, 2, 3, 4, 5`模数`6`，所以 X 不能移动到另一个失败的位置。 Y 总是可以通过删除该残差来回答并通过以下方式恢复整除性`6`。 

为最大值`n = 1,000,000,000`，余数为`4`，所以程序输出`X WINS`和`4`。 生成的堆包含`999,999,996`cookies，可以被整除`6`。 的大小`n`对执行的操作数量没有影响。
