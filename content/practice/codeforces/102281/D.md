 ## 解决方案
 ## 问题理解

 我们在三维空间中有三个点。 第一个点是我方航天器和激光炮的位置，第二个点是敌方球形航天器的中心及其半径，第三个点是瞄准系统选择的点。 

激光不会停在选定的点。 所选点仅决定其方向，因此射击是从我们的航天器开始并穿过目标点的无限射线。 当这条射线与球体相交或接触时，敌人就会被摧毁。 

我们需要输出两件事。 第一行表示光线是否击中球体。 第二行给出了从球体中心到射线任意点的最小欧几里德距离。 

所有坐标都在 -1000 到 1000 之间，半径最多为 1000。只有一种几何配置，因此输入大小不会产生渐近挑战。 1.5 秒的限制对于常数时间算术来说绰绰有余，但这也意味着没有理由通过大量采样点来近似射线。 Python 整数可以轻松处理所有中间平方距离，因为坐标差最多为 2000，而它们的平方仅为数百万量级。 

主要的边缘情况来自这样一个事实：激光束是一条射线，而不是一条无限的线。 无限线上最近的点可能位于大炮后面，在这种情况下，激光无法到达该点。 

例如，```
0 0 0
-2 0 0 1
1 0 0
```产生```
MISS
2.000000000000000
```敌人中心位于 x = -2，而激光沿 x 正方向传播。 从中心到无限 x 轴的距离为零，但实际射线的最近点是大炮本身，距离为 2。始终计算点到线距离的解决方案将错误地报告命中。 

相切也必须算作命中。 例如，```
0 0 0
5 1 0 1
10 0 0
```产生```
HIT
1.000000000000000
```射线是正 x 轴，球心距它正好 1 个单位。 激光接触球体，因此使用严格的比较，例如`distance < r`会错误地产生`MISS`。 

球体直接位于射线上的情况是另一种边界条件。 例如，```
0 0 0
5 0 0 2
1 0 0
```距离为零，所以答案是`HIT`。 基于归一化方向向量的公式也必须避免除以零，但该语句保证目标与大炮不同，因此方向向量永远不会为零。 

## 方法

 简单的几何模拟可以通过许多采样点来表示射线，并逐个检查这些点。 整数坐标边界提供了一个有用的上限，可以帮助您了解为什么这是错误的抽象。 如果目标与炮不同，方向向量的平方长度至少为1。敌人中心在射线方向上的投影参数的绝对值最多为6000，因为点积最多为(3 \cdot 2000 \cdot 2000)，而方向长度的平方至少为1。 

假设我们尝试每隔该参数的 (10^{-6}) 个单位检查一次光线。 在最坏的情况下，我们大约需要 6,000,001 次评估，并且这种采样仍然是数值近似，而不是精确的几何测试。 减小步长只会使操作计数更差。 

暴力破解的想法失败了，因为射线是一个连续的物体。 当到球体的距离可以直接用矢量代数表示时，没有必要检查各个点。 

关键的观察是光线的每个点都具有以下形式

 [
 S + tV,\qquad t \ge 0,
 ]

 其中（S）是大炮位置，（V=T-S）是目标确定的方向。 我们需要最小化从该点到敌人中心（E）的平方距离。 

让(W=E-S)。 从 (E) 到 (S+tV) 的距离平方为

 [
 f(t)=|W-tV|^2。 
]

 展开给出

 [
 f(t)=|W|^2-2t(W\cdot V)+t^2|V|^2。 
]

 这是 (t) 的二次函数。 其无约束最小值出现在

 [
 t_0=\frac{W\cdot V}{|V|^2}。 
]

 唯一的限制是 (t\ge0)。 如果(t_0\ge0)，则最近点在射线内部，因此普通的点到线距离是正确的。 如果(t_0<0)，无限直线的最近点位于大炮后面，并且最近可到达点是(S)。 

这将整个问题简化为几个点积和平方长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力采样 | 以 (10^{-6}) 分辨率进行 O(6,000,000) 次评估 | O(1) | O(1) | 太慢且近似|
 | 最佳矢量几何 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取炮位（S）、敌方中心（E）、半径（r）和目标点（T）。 构造方向向量 (V=T-S)。 保证大炮永远不会向自己射击意味着(V\ne0)，因此它的平方长度为正。 
2. 构造(W=E-S)，从大炮到敌人中心的矢量。 计算点积 (p=W\cdot V) 和平方方向长度 (q=V\cdot V)。 
3. 检查(p) 的符号。 由于(q>0)，(p/q)的符号恰好是最优参数(t_0)的符号。 
4. 如果（p<0），则敌人中心在无限直线上的垂直投影位于大炮后面。 实际射线的最近点就是大炮本身，因此所需的距离是 (|W|)。 
5. 如果 (p\ge0)，则垂直投影位于射线上。 最小平方距离是

 [
 |W|^2-\frac{p^2}{q}。 
]

 对于命中测试，我们可以避免取平方根。 距离至多为(r)的条件变为

 [
 |W|^2-\frac{p^2}{q}\le r^2。 
]

 乘以正值 (q) 得出

 [
 |W|^2q-p^2\le r^2q。 
]

 该比较中的所有数量都是整数，因此可以在没有浮点错误的情况下做出命中判定。 

1. 将实际距离计算为浮点值并用足够的位数打印出来。 在投影情况下，使用上面非负值的平方根。 在炮后情况下，使用 (\sqrt{|W|^2})。 
2. 打印`HIT`当计算的几何距离至多为半径时，包括精确的相切。 否则打印`MISS`。 

### 为什么它有效

 不变量是所选参数 (t) 始终描述射线距敌人中心最近的可到达点。 二次距离函数恰好有一个无约束最小值，因为它的 (t^2) 系数为 (V\cdot V>0)。 当最小值为 (t\ge0) 时，它属于射线。 当 (t<0) 时，二次方在整个允许区间 (t\ge0) 内不断增加，因此最小值出现在边界 (t=0) 处，即大炮。 

因此，该算法计算从中心到射线的精确最小距离。 当该距离最多为其半径时，球体恰好相交或接触，因此报告的`HIT`或者`MISS`决定是正确的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    xs, ys, zs = map(int, input().split())
    xe, ye, ze, r = map(int, input().split())
    xt, yt, zt = map(int, input().split())

    vx = xt - xs
    vy = yt - ys
    vz = zt - zs

    wx = xe - xs
    wy = ye - ys
    wz = ze - zs

    dot = wx * vx + wy * vy + wz * vz
    vv = vx * vx + vy * vy + vz * vz
    ww = wx * wx + wy * wy + wz * wz

    if dot < 0:
        dist2 = float(ww)
        hit = ww <= r * r
    else:
        cross2 = ww * vv - dot * dot
        dist2 = cross2 / vv
        hit = cross2 <= r * r * vv

    distance = math.sqrt(dist2)

    print("HIT" if hit else "MISS")
    print(f"{distance:.15f}")

if __name__ == "__main__":
    solve()
```第一部分构建`v`，射线方向，以及`w`，从大炮到敌人中心的矢量。 这些正是数学推导中使用的向量。`dot`存储 (W\cdot V)，同时`vv`存储 (|V|^2)。 由于目标与大炮不同，`vv`是严格正数。`ww`存储从大炮到敌人中心的平方距离。 

什么时候`dot < 0`，投影位于大炮后面。 该代码因此使用`ww`作为平方距离并直接与 (r^2) 进行比较。 该声明保证大炮位于敌方球体之外，因此该分支不会意外报告命中，因为大炮本身位于球体内部。 

为了`dot >= 0`，代码使用

 [
 |W|^2|V|^2-(W\cdot V)^2
 ]

 而不是直接计算归一化的点到线距离。 该表达式是叉积 (W\times V) 的平方长度，因此除以 (|V|^2) 后，得到到直线的平方距离。 

命中比较是故意使用整数来执行的。 接近相切的浮点舍入可以将数学上精确的等式转换为略高于或低于半径的值。 整数不等式`cross2 <= r * r * vv`准确地处理相切。 

只有最后的平方根需要浮点运算。 Python 整数具有任意精度，尽管这里的实际值足够小，普通 64 位整数就已经足够了。 

输出使用小数点后十五位数字，这比所需的 (10^{-6}) 绝对或相对误差要精确得多。

 ## 边缘情况

 第一个微妙的情况是敌人在大炮后面。 考虑```
0 0 0
-2 0 0 1
1 0 0
```这里 (V=(1,0,0)) 和 (W=(-2,0,0))，所以

 [
 W\cdot V=-2<0。 
]

 投影位于 (t=-2)，超出允许范围 (t\ge0)。 算法因此选择（t=0）大炮本身，并获得距离 2。由于半径仅为 1，因此结果为`MISS`。 这正是在不检查投影方向的情况下破坏使用点到无限线距离的解决方案的情况。 

第二种情况是相切的：```
0 0 0
5 1 0 1
10 0 0
```射线为x轴，敌人中心距其1个单位。 最近的点是`(5, 0, 0)`，所以距离等于半径。 整数比较使用`<=`， 不是`<`，并返回`HIT`。 打印的距离正好是`1.000000000000000`。 

第三种情况是中心直接在射线上：```
0 0 0
100 100 100 10
1 1 1
```向量`w`和`v`是平行的，所以

 [
 |W|^2|V|^2-(W\cdot V)^2=0。 
]

 距离为零，球体被击中。 这也验证了当垂直分量完全消失时叉积公式的行为正确。 

第四种情况运用了较大的坐标范围：```
-1000 -1000 -1000
0 0 0 1000
1000 1000 1000
```方向向量和中心向量都是平行的，因此尽管坐标处于允许的极值，但计算的距离为零。 对于普通的固定宽度整数算术来说，所有平方数量仍然足够小，并且 Python 的整数算术消除了任何溢出问题。 

最后一种边缘情况是仅更改一个坐标的目标：```
1000 1000 1000
-1000 -1000 -1000 1000
1000 1000 999
```目标与大炮不同，因此方向向量是有效的，但它几乎完全沿着大炮位置的坐标轴指向。 敌方中心投射到大炮后面，因为点积为负。 该算法使用从敌人中心到大炮的距离，而不是到无限线的距离，大约给出`3464.1016151377546`。 这确认了符号检查是在线距离公式之前应用的。
