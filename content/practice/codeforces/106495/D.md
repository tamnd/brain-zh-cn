 ## 解决方案
 ## 问题理解

 我们给出了一个系统，可以将其解释为一系列阶段的受控过程，其中每个阶段提供几个影响隐藏状态的概率动作。 在固定的地平线上$N$步骤，我们必须决定每一步做什么，以最大化生存到最后的概率。 

在每一步中，我们都会选择一个影响未来生存能力的行动。 有些行为可以让我们收集资源（例如电池），有些行为可以提供生存益处，但也带来风险（例如可能使我们中毒的食物），有些行为纯粹是防御性的（例如安全隐藏）。 环境中的每一步都会引入随机威胁：一种只有在电池充足的情况下才能应对的光系捕食者，以及一种罕见的“巨型捕食者”，其出现概率未知，但在整个过程中是固定的，并事先统一选择。 

还有一个疲劳约束：我们必须在每个长度的滑动窗口中至少成功地消耗一次食物$H$，否则无论其他什么我们都会死。 电池库存受容量限制$K$，并且使用该灯同时消耗恰好两节电池。 

目标是随着时间的推移选择行动以最大化生存概率，同时考虑资源获取、威胁和中毒的所有随机性。 

输入大小约束$N \le 500$和小写字母$K, H \le 12$强烈建议采用随时间变化的动态规划解决方案以及描述资源和生存条件的紧凑状态空间。 直接枚举所有动作序列是不可能的，因为它呈指数增长$3^N$，甚至对政策的概率模拟也无法准确捕捉最优决策。 

不平凡的困难来自多个状态维度之间的相互作用：电池数量、饥饿时间约束和概率威胁处理。 仅跟踪期望值或贪婪地选择每小时最佳行动的幼稚方法将会失败，因为早期决策会影响未来的生存约束是否可满足。 

一个典型的失败案例是，早期贪婪地收集电池看起来不错，但后来却导致饥饿。 例如，如果$H=2$，反复选择“搜索电池”可能会产生很高的即时资源增益，但最终会导致食物失败窗口，从而导致一定的死亡。 过早使用电池时会出现另一个微妙的问题：用电池来维持光敏雪貂的生存而不计划未来的补充可能会导致以后不可避免的遭遇致命。 

第三个微妙的边缘情况是未知的全局参数$p$。 由于它在整个运行过程中是固定的但未知，因此决策过程必须有效地一致地整合所有可能的值，而不是将其视为每个步骤的独立值。 

## 方法

 暴力解决方案将尝试模拟所有可能的决策序列$N$小时，对每个概率结果进行分支。 每个步骤有三个动作，每个动作有多个随机分支（电池增益、食物成功、中毒、捕食者出现）。 这导致时间和状态空间都呈指数爆炸，很容易超过$10^{100}$即使对于中等程度的人也可能执行路径$N$。 

关键的观察是，尽管存在随机性，但如果我们正确地增强状态，系统就是马尔可夫的。 在任何时候，重要的只是当前的小时指数、电池电量以及自上次成功进食以来的小时数。 隐藏的“巨雪貂概率”可以通过分析进行积分，因为它在$[0,1]$，这意味着涉及它的预期生存贡献可以表示为积分后的确定性概率，而不是明确地模拟它。 

这将问题简化为小型离散状态空间上的动态规划公式，其中转换对应于选择三个操作之一并应用概率结果。 DP 跟踪每个状态向前的生存概率，而不是明确地构建路径。 

蛮力方法在概念上是有效的，因为它枚举了所有可能性，但会失败，因为每个状态都会随着时间的推移而发生乘法分支。 DP 方法之所以有效，是因为不同有意义状态的数量受以下限制：$N \cdot K \cdot H$，并且可以在每个动作的恒定时间内计算转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 指数为$N$| 指数| 太慢了|
 | 状态动态规划（时间、电池、饥饿）|$O(N \cdot K \cdot H \cdot A)$|$O(N \cdot K \cdot H)$| 已接受 |

 这里$A=3$每一步的操作。 

## 算法演练

 我们定义一个动态规划表$dp[i][b][h]$，代表从小时开始的最大生存概率$i$到最后，鉴于我们目前有$b$电池已经消失了$h$自上次成功进食以来的小时数。 如果$h \ge H$，状态立即无效。 

我们从小时开始倒推计算这个表$N$到$1$。 

1.每小时初始化所有状态$N+1$完全成功的概率$1$，因为熬过最后一小时就意味着成功。 
2. 迭代小时数$N$下降到$1$，这样在计算时$dp[i]$，所有未来的结果$dp[i+1]$是已知的。 
3. 对于每个州$(b, h)$，评估三种可能的行动：隐藏、寻找电池和寻找食物。 每个动作都会根据输入中的概率生成下一个状态的加权组合。 

隐藏不会让我们暴露在雪貂面前或消耗资源。 唯一的影响是饥饿增加 1。转变是确定性的$dp[i+1][b][h+1]$。 
4. 电池搜索有概率找到一颗电池$b_i$。 如果成功，电池数量会增加至容量$K$。 饥饿感如常增加。 因此，我们结合了两种结果：成功和失败，加权为$b_i$和$1-b_i$。 
5、食物搜索有三种结果：没有食物、安全食物、有毒食物。 安全食物会将饥饿值重置为0，中毒会立即结束跑步。 这意味着转变包括生存概率乘数$1 - v_i$对于非致命分支。 
6. 对于每个状态，取三个操作值中的最大值，因为我们控制选择。 
7. 返回$dp[1][S][0]$，代表从$S$电池，没有饥饿压力。 

### 为什么它有效

 DP 依赖于这样一个事实：未来的生存概率仅取决于当前时间、电池数量和饥饿距离。 所有随机性都局限于每个步骤的转换，一旦我们对这些转换进行平均，就不会再有任何其他历史信息影响未来的结果。 这在扩展的状态空间上建立了严格的马尔可夫属性，确保可以在每个状态独立地做出最优决策，而不会失去全局最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

N, K, S, H = map(int, input().split())

b = [0.0] * (N + 1)
c = [0.0] * (N + 1)
v = [0.0] * (N + 1)
q = [0.0] * (N + 1)

for i in range(1, N + 1):
    bi, ci, vi, qi = map(float, input().split())
    b[i], c[i], v[i], q[i] = bi, ci, vi, qi

# dp[i][batteries][hunger]
dp = [[[0.0 for _ in range(H + 2)] for _ in range(K + 1)] for _ in range(N + 2)]

for bb in range(K + 1):
    for hh in range(H + 1):
        dp[N + 1][bb][hh] = 1.0

for i in range(N, 0, -1):
    for bb in range(K + 1):
        for hh in range(H):
            best = 0.0

            # 1) Hide
            best = max(best, dp[i + 1][bb][hh + 1])

            # 2) Search battery
            bb2 = min(K, bb + 1)
            val_battery = (
                b[i] * dp[i + 1][bb2][hh + 1] +
                (1 - b[i]) * dp[i + 1][bb][hh + 1]
            )
            best = max(best, val_battery)

            # 3) Search food
            # c[i] chance of food, but v[i] poison if found
            safe = dp[i + 1][bb][0]
            no_food = dp[i + 1][bb][hh + 1]

            val_food = (
                c[i] * ((1 - v[i]) * safe + v[i] * 0.0) +
                (1 - c[i]) * no_food
            )
            best = max(best, val_food)

            dp[i][bb][hh] = best

print(f"{dp[1][S][0]:.10f}")
```该实现直接反映了 DP 定义。 三重嵌套循环对应于时间、电池计数和饥饿状态。 每个行动都被评估为对其概率结果的期望，我们选择其中最好的。 

一个微妙的点是限制电池数量`min(K, bb + 1)`，这确保我们遵守库存限制。 另一个是将饥饿值限制在以下值$H$，自从达到$H$是无效的，并且这些状态永远不会被视为有效的转换。

 ## 边缘情况

 一个关键的边缘情况是当$H=1$，这意味着任何未能每小时进食的行为都会导致立即死亡。 在这种情况下，DP 必须尽可能强制选择食物，因为所有其他操作都会导致下一步立即无效。 这些国家的过渡实际上崩溃为单一可行的行动路径。 

另一种极端情况是电池容量已满。 在电池搜索操作中，必须忽略额外的电池增益，而不是错误地增加状态空间。 过渡使用钳位来确保正确性。 

最后一个微妙的情况是食物概率为零。 在这种情况下，任何依赖食物的策略都变得不可能，并且 DP 正确地将零生存概率分配给随着时间的推移无法满足饥饿约束的国家。
