 ## 解决方案
 ## 问题理解

 我们得到一个数组$n$整数，每个都在 1 到 5000 之间，我们被要求将该数组转换为从 1 到 5000 的数字排列$n$。 排列是一个序列，其中每个整数从 1 到$n$恰好出现一次。 允许的操作是将单个元素更改为任何其他整数。 目标是尽量减少此类更改的数量。 

输入给出序列长度$n$和数组本身。 输出是一个整数，表示所需的最小替换次数。 

限制是适度的：$n$最多可以到5000。因为天真$O(n^2)$方法可能涉及重复扫描阵列，我们应该寻求一个解决方案$O(n \log n)$或者$O(n)$。 内存使用也受到限制，但存储大小为 5000 的频率数组是可以接受的。 

边缘情况包括已经形成有效排列的序列、所有元素都相同的序列或许多数字不属于 1-to- 的序列。$n$范围。 例如，如果$n = 3$数组是$[5, 5, 5]$，正确的输出是 3，因为所有三个数字都必须更改为 1、2 和 3。粗心的方法可能只计算重复项而不检查边界，从而产生错误的答案。 

## 方法

 蛮力方法是迭代从 1 到$n$并检查每个是否都存在于数组中。 如果丢失，我们可以扫描数组以查找要替换的元素。 原则上这是可行的，但是重复扫描会增加复杂性$O(n^2)$在最坏的情况下，这对于$n = 5000$。 

最佳方法是利用计数。 我们观察到，对于有效的排列，每个数字 1 到$n$必须恰好出现一次。 任何超出此范围的数字或任何在该范围内的重复数字都必须更改。 因此，我们可以计算每个数字的频率，并迭代从 1 到$n$。 每个缺失的数字对应一项所需的更改。 我们还计算重复或越界的“额外”数字。 最小更改次数是缺失数字的总数，该数字始终会与足够的额外数字相匹配以进行替换。 

我们的见解是，问题归结为计算缺失的数字和多余的数字。 对数组进行排序或尝试进行复杂的交换是不必要的，因为任何多余的元素都可以重新用于填充缺失的槽。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化频率数组`freq`尺寸的$n+1$计算数字 1 到 的出现次数$n$。 暂时忽略此范围之外的数字。 
2. 迭代输入数组。 对于每个元素$a_i$，如果在 1 到$n$, 增量`freq[a_i]`。 否则，将其视为“多余”元素，最终需要更换。 
3. 初始化计数器`changes`为零。 迭代数字 1 到$n$。 如果`freq[i]`为零，表示数字$i$失踪了。 增量`changes`一个。 对于频率大于 1 的数字，额外的副本将有助于多余元素池。 
4. 返回`changes`。 该值正是所需的替换数量，因为每个缺失的数字都可以使用重复项或超出范围的数字中的额外元素来填充。 

不变的是，在计算频率后，缺失数量的总和等于所需的最小替换数。 要更改哪些元素并不存在歧义，因为任何多余的数字都可以更改为缺失的数字，而不会影响其他缺失的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

freq = [0] * (n + 1)
excess = 0

for x in a:
    if 1 <= x <= n:
        freq[x] += 1
    else:
        excess += 1

changes = 0
for i in range(1, n + 1):
    if freq[i] == 0:
        changes += 1

print(changes)
```该代码首先计算有效排列范围内每个数字出现的次数。 1 到 1 之外的任何数字$n$自动被认为是多余的。 然后，对于从 1 到$n$，我们检查它是否丢失。 每个缺失的数字直接对应于一项所需的更改。 我们不需要准确跟踪哪些多余的数字发生了变化，因为问题只要求计数。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    freq = [0] * (n + 1)
    excess = 0
    for x in a:
        if 1 <= x <= n:
            freq[x] += 1
        else:
            excess += 1
    changes = 0
    for i in range(1, n + 1):
        if freq[i] == 0:
            changes += 1
    return str(changes)

# Provided samples

 ## 边缘情况

 如果序列中的所有数字都等于排列范围之外的值，例如`[6, 6, 6]`为了`n=3`，该算法将所有三个计数为多余，并识别缺失的数字 1、2、3。`changes`计数器变为 3，匹配缺失数字的数量。 

如果序列在范围内有重复项，例如`[1, 1, 2, 4]`为了`n=4`，该算法计算频率`[0,2,1,0,1]`并识别丢失的数字 3
