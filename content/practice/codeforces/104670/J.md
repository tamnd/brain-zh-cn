 ## 解决方案
 ## 问题理解

 两个人从飞机上的两个给定坐标出发，在固定的时间内直线跑到各自的目的地。 两者都以恒定速度移动，因此每个人的位置都是其起点和终点之间的线性插值。 

任务是在整个运动过程中跟踪它们之间的距离，并报告开始和结束之间任何时刻发生的最大间距。 我们不要求它何时发生，只要求该距离的最大值。 

每个跑步者的路径完全由两点决定，因此整个系统减少为平面上的两个移动点，两个点在相同的时间间隔内同时追踪线段。 

输入大小是恒定的，即八个整数，因此约束不是关于可扩展性的，而是关于数值鲁棒性的。 预计会出现具有恒定时间几何结构的解决方案。 任何涉及时间或采样离散化的事情都是不必要的，并且可能是不正确的，因为最大值可能出现在采样点之间。 

天真的思维的一个微妙的失败案例是假设最大距离必须出现在端点之一。 但这并不总是正确的，因为两个线性移动点之间的距离函数不是线性的。 

例如，如果一个跑步者绕着另一个跑步者进行类似圆圈的相对运动（即使两者都是直线运动，它们的相对运动也可以创建转弯距离曲线），则最大值可能出现在时间间隔的内部，而不是在 t = 0 或 t = 1 时。 

另一种失效模式是均匀采样，例如均匀间隔检查1000次。 如果抛物线很窄，这可能会错过尖锐的峰值。 

关键的困难在于认识到虽然运动是几何的，但距离函数变成了一个变量的简单代数曲线。 

## 方法

 蛮力方法可以连续或密集采样来模拟时间。 我们可以在 0 到 1 之间的许多时间点评估两个跑步者之间的距离。这在概念上是正确的，因为该函数是连续的，因此足够密集的采样将接近最大值。 

然而，如果我们想要精确的正确性，采样是不可接受的。 任何有限离散化都有可能错过真正的最大值。 即使我们采样一百万个点，最大值也可能位于它们之间。 

结构洞察是每个跑步者的每个坐标在时间上都是线性的。 这意味着它们之间的差异向量在时间上也是线性的。 距离的平方成为时间的二次函数。 闭区间上的二次函数具有众所周知的形状：它的开口要么向上，要么向下，并且如果顶点位于区间内，则其最大值必须出现在端点或顶点处。 

这将问题从平面中的几何推理简化为分析单变量二次多项式。

 | --- | --- | --- | --- |
 | 均匀抽样| O(k) | O(1) | O(1) | 太慢/不准确|
 | 二次分析 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将时间参数化为 t，范围从 0 到 1。

1. 将卡里的位置表示为时间的函数。 如果她从 A 开始并在 C 结束，那么她的位置是 A + t(C − A)。 这对恒速线性运动进行编码。 
2. 将 Ola 的位置表示为 B + t(D − B)。 
3. 计算它们在时间 t 时的差向量。 这变成 (A − B) + t((C − A) − (D − B))。 此步骤很重要，因为它将问题简化为单个移动向量。 
4. 将平方距离写为差向量与其自身的点积。 这会产生 f(t) = at² + bt + c 形式的表达式，其中 a、b、c 是从坐标导出的标量值。 
5. 通过计算 t* = −b / (2a) 确定二次方程可以达到极值的候选时间。 这是因为二次方程的导数在其顶点处为零。 
6. 将 t* 限制在区间 [0, 1] 内，因为运动仅限于运行持续时间。 如果顶点位于外部，则它不可能是区间内的最大值。 
7. 在 t = 0、t = 1 和钳位 t* 时计算 f(t)。 这些值中的最大值是最大平方距离。 
8. 返回该最大值的平方根，以获得实际的欧氏距离。 

### 为什么它有效

 平方距离函数是 t 中的二次多项式，因为每个坐标在 t 中都是线性的，并且平方最多引入两次项。 闭区间上的二次函数不能有多个内部临界点，并且其极值完全由端点和该临界点确定。 由于平方保留非负值的排序，因此最大化平方距离相当于最大化距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def clamp(x, lo, hi):
    return max(lo, min(hi, x))

def dist2(x1, y1, x2, y2):
    dx = x1 - x2
    dy = y1 - y2
    return dx * dx + dy * dy

def solve():
    data = list(map(int, input().split()))
    ax, ay, bx, by, cx, cy, dx, dy = data

    # direction vectors
    pax, pay = cx - ax, cy - ay
    pbx, pby = dx - bx, dy - by

    # relative motion: P(t) - Q(t) = (A-B) + t((C-A)-(D-B))
    rx = ax - bx
    ry = ay - by
    vx = pax - pbx
    vy = pay - pby

    # f(t) = |r + t v|^2 = (v·v)t^2 + 2(r·v)t + (r·r)
    a = vx * vx + vy * vy
    b = 2 * (rx * vx + ry * vy)
    c = rx * rx + ry * ry

    best = c  # t = 0

    # t = 1
    best = max(best, a + b + c)

    if a != 0:
        t = -b / (2 * a)
        t = clamp(t, 0.0, 1.0)
        val = a * t * t + b * t + c
        best = max(best, val)

    print((best) ** 0.5)

if __name__ == "__main__":
    solve()
```代码首先将两条轨迹重写为速度形式，这避免了重复插值。 二次方程的系数直接来自线性表达式的平方范数的展开。 端点检查对应于 t = 0 和 t = 1。仅当二次方不平坦时才计算内部候选。 

一个微妙的点是数值稳定性。 对 t 使用浮点是安全的，因为该问题允许较小的相对或绝对误差，并且最终计算在平方距离上是单调的。

 ## 边缘情况

 当两个跑步者以相同的速度朝完全相同的方向移动时，就会出现一种重要的边缘情况。 在这种情况下，相对速度为零，因此二次项消失并且距离恒定。 该算法通过检查 a != 0 来处理此问题，这会跳过顶点评估。 

另一种情况是两者从同一点开始但在不同方向上发散。 最大值出现在 t = 1 时，并且算法可以正确地显式评估端点。 

退化情况是运动完全抵消，使得距离首先对称地增加然后减小。 这会产生一个清晰的内部最大值，并且计算出的顶点 t* 严格位于 [0,1] 内，该顶点被正确钳位和评估。
