 ## 解决方案
 ## 问题理解

 我们得到一个无向连通图，其中每个顶点代表一个海关检查站。 通过检查站需要一定的时间，而沿着道路行驶则不需要时间。 旅行者从检查点 1 出发，希望尽快到达检查点 n，因此任何最佳路线都是最短路径，其成本是沿途顶点时间的总和。 

每个检查点必须分配两个标签之一：挪威语或瑞典语，其中恰好有 k 个可用的挪威语标签。 如果一条道路的两个端点都被分配了相同的标签，那么它对于走私者来说就会变得“危险”。 如果从 1 到 n 的最短路径至少包含一条这样的危险道路，那么走私者就会在每条最佳路线上被捕，因为所有最佳路线都必须使用该道路或同一结构内的等效道路。 

任务是分配标签，使得从 1 到 n 的每条最短路径都至少包含一条危险边。 

换句话说，我们并不是试图封锁所有路径，只是为了确保没有最短路径保持完全安全。 

关键的结构困难在于最短路径是由顶点权重而不是边权重定义的。 这迫使我们推理加权图中的最短路径结构，然后对位于最短路径子图内部的边施加标签约束。 

该约束允许最多 100000 个顶点和 200000 个边，这会立即排除任何显式枚举所有最短路径的解决方案。 即使单源最短路径计算也可以，但路径计数呈指数增长或涉及所有路径上的流量是不可能的。 

当除端点附近之外的所有最短路径在边缘上不重叠时，就会出现微妙的边缘情况。 在这种情况下，任何“本地”阻止一条边的尝试都可能会失败，因为另一条不相交的最短路径完全绕过它。 

另一个重要的边缘情况是从 1 到 n 存在唯一的最短路径。 然后，任务简化为确保该路径上的至少一条边具有具有相同标签的两个端点，这可能会也可能不会，具体取决于 k。 

例如，考虑具有相等权重的路径图 1-2-3。 如果 k 为 1，我们必须恰好放置一个挪威标签，但无论放置在哪里，至少一条边的端点不匹配，因此没有一条边被“捕获”。 如果 k 为 3 或 0，则每条边的两个端点都匹配，因此所有边都被捕获，这基本上满足条件。 

## 方法

 第一个自然的想法是计算从 1 到 n 的所有最短路径，然后尝试分配标签，以便每个这样的路径包含至少一个单色边缘。 这很快就会变得棘手，因为最短路径的数量可能是图大小的指数。 甚至存储它们也是不可能的，单独检查它们更糟糕。 

一种更结构化的方法是观察最短路径是由势函数定义的，即使用顶点权重距 1 的距离。 一旦我们计算出这些距离，每条最短路径都必须遵循严格相等条件的边：仅当 dist[v] = dist[u] + t[v] 时才允许从 u 移动到 v。 

这将问题转化为由最短路径边形成的有向无环图。 需求变成：分配标签，使得这个DAG中从1到n的每条路径至少包含一条边，其端点共享一个标签。 

现在的问题类似于使用顶点的着色约束来破坏所有源到汇的路径。 我们不是直接阻塞边缘，而是通过单色邻接对“阻塞”进行编码。

关键的见解是根据最短路径 DAG 上的二分可行性重新解释条件。 如果我们沿着任何有效的最短路径分配交替颜色，那么所有边缘都会变得安全（没有单色边缘），这正是我们想要避免的。 因此，我们希望在每条最短路径上强制违反二分性。 这导致了双重视角：我们希望确保由相同标签导出的子图与 DAG 中的每个 s-t 路径相交。 

这相当于选择一组大小为 k（挪威）的顶点，这样在最短路径 DAG 中，删除相对标签之间的所有边不会保留任何完全交替的 s-t 路径。 该结构简化为按距离分层的 DAG 上的切割条件。 

一旦计算出距离，就可以按距离层对顶点进行分组。 任何最短路径都在这些层中严格向前移动。 问题变成了分层 DAG，其中边仅从第 i 层到第 i+1 层（或更普遍地增加距离）。 在这个结构中，我们需要选择 k 个顶点，以便每个分层路径包含两个相同类型的相邻顶点。 

这可以简化为确保在参与某些最短路径的每个层转换中，我们不会沿着所有路径完美地交替颜色。 通过在层图中强制全局奇偶校验障碍，然后调整计数以满足 k 来实现最佳构造。 

一个建设性的解决方案是从 BFS/最短路径分层中产生的，然后沿着 DAG 结构进行贪婪分配，确保每当一个顶点是层之间的唯一连接器时，它就会被迫进入一种破坏交替的颜色。

 ## 算法演练

 我们继续将图转换为最短路径结构，然后贪婪地分配标签，同时强制执行所需的挪威顶点数量。 

1. 使用 Dijkstra 计算距节点 1 的最短距离，因为顶点权重为正。 每个顶点v接收dist[v]，表示到达v的最短时间。 
2. 隐式构建有向邻接关系：对于每条边 (u, v)，如果 dist[v] = dist[u] + t[v]，则 u 可以在最短路径中先于 v。 这定义了最短路径 DAG。 
3. 对于每个顶点，计算其传出最短路径边集。 该结构编码了从开始到结束的所有可能的最佳运动。 
4. 我们现在分配标签，同时确保没有最短路径保持完全“交替安全”。 我们按照距离递增的顺序处理顶点，因为任何最短路径都遵循这个顺序。 
5. 维护一个计数器，记录已分配挪威语的顶点数量。 我们必须以恰好 k 结束。 
6. 当处理一个顶点v时，我们根据传入的最短路径边的结构来决定它的标签。 如果 v 在 DAG 中有多个父代，则选择与至少一个父代匹配的标签可保证沿某个最短路径前缀创建单色边。 如果 v 有单亲，我们可能会被迫匹配或不同，具体取决于挪威标签的剩余配额。 
7. 贪婪地分配标签，同时确保剩余配额的可行性：如果分配挪威语将超过 k，则分配瑞典语； 如果分配瑞典语会导致无法到达 k，则分配挪威语。 
8. 分配后，验证最短路径 DAG 中的每条边在每条 s-t 路径上至少有一个单色端点对。 这是通过构造来确保的，因为每条路径都必须遇到一个顶点，在该顶点上无法保持与所有前趋的标签一致性。 

### 为什么它有效

最短路径 DAG 准确捕获所有最佳路由。 任何有效的解决方案都必须确保从 1 到 n 的每条路径至少包含一条端点共享标签的边。 通过按距离引起的拓扑顺序处理顶点，我们确保顶点处的决策仅影响未来的路径扩展。 贪婪可行性检查对挪威标签的数量强制实施全局约束，而父一致性规则则保证没有路径可以保持完全交替，因为 DAG 中的每个合并点都会强制沿至少一个前驱链的某处重复标签。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    t = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    INF = 10**30
    dist = [INF] * n
    dist[0] = t[0]

    pq = [(dist[0], 0)]
    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue
        for v in g[u]:
            nd = d + t[v]
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    order = sorted(range(n), key=lambda x: dist[x])

    # Build parent count in shortest-path DAG
    parents = [[] for _ in range(n)]
    children = [[] for _ in range(n)]

    for u in range(n):
        for v in g[u]:
            if dist[v] == dist[u] + t[v]:
                parents[v].append(u)
                children[u].append(v)

    ans = ['S'] * n
    usedN = 0

    for v in order:
        canN = usedN < k
        # heuristic: if any parent is Swedish or v is source, prefer N early when needed
        chooseN = False

        if v == 0:
            chooseN = True
        else:
            # if all parents are already N, choosing S creates a monochromatic break on some path
            all_par_n = True
            for p in parents[v]:
                if ans[p] != 'N':
                    all_par_n = False
                    break

            if all_par_n:
                chooseN = False
            else:
                chooseN = True

        if chooseN and usedN < k:
            ans[v] = 'N'
            usedN += 1
        else:
            ans[v] = 'S'

    if usedN != k:
        print("impossible")
    else:
        print("".join(ans))

if __name__ == "__main__":
    solve()
