 ## 解决方案
 ## 问题理解

 墙是一系列独立的部分，每个部分都有一个初始高度。 怪物使用与参数相关的固定规则分别攻击每个部分$k$。 对线段的攻击是一个重复的过程：在任意时刻，如果当前高度可以被$k$，该片段立即被摧毁，并且对该片段的攻击无需额外时间即可停止。 否则，怪物会花费一分钟的时间将高度替换为$\lfloor h/k \rfloor$，然后从新的高度继续。 

因此，每个片段贡献一定的分钟数，总时间是所有片段的总和。 

在攻击开始之前，国王最多可以使用$m$卷轴。 每个滚动条仅应用于一个段，并按以下任意选定值增加其高度：$1$到$c$。 多个卷轴可以在同一段上使用，并且所有修改都发生在攻击开始之前。 目标是分配这些增量，以使总销毁时间最大化。 

这些限制使得简单的模拟变得不可行。 最多有$10^5$段，高度可达$10^9$。 直接模拟每个段的除法过程足够便宜，因为重复除以$k$快速减少值，大致给出$O(\log_k h)$每段步骤，但复杂性来自卷轴。 任何尝试测试所有分配卷轴的方式或尝试所有可能的增量的解决方案都远远超出了可行的限制。 

当段开始时已经被整除时，就会出现微妙的边缘情况$k$。 在这种情况下，它贡献的时间为零，即使是很小的增加也可以极大地改变它的行为。 例如，如果$k=2$和$h=4$，该段立即被销毁。 增加它通过$1$做到了$5$，现在需要多个除法步骤。 天真的贪婪假设“身高越高总是越差”，在这里立即崩溃。 

另一个重要的极端情况是重复除法很快达到零时。 例如，与$k=10$,$h=3$，该段在变为零之前正好需要一分钟，因为第一步立即变为零。 此类案例的表现与在多个部门级别中保持大量数字的情况不同。 

## 方法

 直接的暴力方法会模拟怪物每个部分的过程，然后尝试每种可能的卷轴分布。 即使我们将自己限制为整数增量，每个滚动都有$O(n)$选择，以及$m$卷轴会创建指数分支结构。 这显然是不可能的。 

即使我们修复单个段并尝试所有可能的增量$c$，重新计算每个候选者的销毁时间，我们仍然会得到$O(n \cdot c \cdot \log h)$，这完全超出了范围。 

关键的观察是，单个段的破坏过程仅取决于重复整数除以所获得的序列$k$。 每个段都遵循一条短链：$$h \rightarrow \lfloor h/k \rfloor \rightarrow \lfloor h/k^2 \rfloor \rightarrow \dots$$一旦这些值之一可以被整除，该过程就会停止$k$。 这意味着时间贡献由该链中的第一级决定，其中多个$k$出现。 

这种结构使函数分段稳定：小变化$h$并不总是改变答案，但当它们超过某些阈值时，步数会恰好改变 1。 这使我们能够从“事件”的角度进行思考，其中由于精心选择的增量，段的销毁时间增加了 1。 

我们不会在全球范围内分发卷轴，而是将卷轴的每一次潜在有益用途视为候选增益。 每个候选人都有一个卷轴的成本，并且总时间会有所增加。 然后，我们反复获取最佳可用增益，应用它，并更新它来自的段。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) | 太慢了|
 | 最优（每段贪婪收益）|$O((n + m)\log n \log_k H)$| O(n) | 已接受 |

 ## 算法演练

 我们维护每个分段的当前高度，并重复计算通过再应用一个滚动可以获取多少好处。 

### 1. 计算固定高度的破坏时间

 对于一个值$h$，我们模拟一下这个过程：

 我们反复除以$k$，每当当前值不能被整除时就计算步数$k$。 当我们降落在多个$k$，过程停止。 

这给出了每个细分市场的基线贡献。 

### 2.了解滚动会改变什么

 卷轴会增加一些高度$x \in [1, c]$。 这种变化的影响不是线性的。 相反，它改变了商的顺序$h, \lfloor h/k \rfloor, \lfloor h/k^2 \rfloor, \dots$，并且可能会更改值可被整除的第一个级别$k$。 第一个更改正是使总时间增加一个单位的原因。 

因此对于每个段，我们只关心改善其销毁时间的最小增量。 

### 3. 计算段的下一个有用增量

 对于具有当前值的段$h$，我们检查它的水平：$h_0 = h, h_1 = h//k, h_2 = h//k^2, \dots$在每个级别$t$，值$h_t$如果它还不能被整除，则相关$k$。 如果我们想在这个水平上多争取一分钟的时间，我们会尝试增加$h$以便$h_t$成为下一个倍数$k$。 

让$u = k^t$。 然后$h_t = \lfloor h/u \rfloor$。 我们想要下一个倍数：$$h_t' = \left(\left\lfloor \frac{h_t}{k} \right\rfloor + 1\right) \cdot k$$这对应于目标高度：$$h' = h_t' \cdot u$$所以所需增量为$x = h' - h$。 如果$x \le c$，这是一个有效的滚动移动，并额外增加一分钟的增益。 

我们计算所有级别的最佳增益。 

### 4.滚动使用的贪心选择

 我们对所有分段维护一个优先级队列，以每次滚动的最佳可实现增益为关键。 每个条目存储段索引和最佳增量$x$这增加了它的贡献。 

在每一步中，我们提取具有最大增益的段，应用增量，更新其高度，重新计算其下一个最佳增益，然后将其推回。 

这确保了每次滚动都在产生总时间最大立即增加的地方使用。 

### 5. 为什么它有效

 关键的不变量是每个卷轴都对应一个离散的改进事件：将总破坏时间恰好增加一个单位。 任何较大的跳跃都可以分解为多个单元改进，每个改进对应于跨越由 的幂描述的划分阈值之一$k$。 由于每个卷轴都是独立的并且成本相同，因此始终选择当前最大的可用边际增益可以保持最优性。 

## Python 解决方案```python
import sys
import heapq
input = sys.stdin.readline

def base_time(h, k):
    t = 0
    while h % k != 0:
        if h == 0:
            return t
        h //= k
        t += 1
    return t

def best_gain(h, k, c):
    if h == 0:
        return (0, 0)
    best_x = 0
    best_inc = 0

    # try all levels h / k^t
    u = 1
    x = h
    while u <= h:
        x = h // u
        if x == 0:
            break

        if x % k != 0:
            # move x to next multiple of k
            nxt = ((x // k) + 1) * k
            target = nxt * u
            inc = target - h
            if 1 <= inc <= c:
                if inc > best_inc:
                    best_inc = inc
                    best_x = inc

        u *= k

    return (best_inc, best_inc)

def compute_time(h, k):
    t = 0
    while True:
        if h % k == 0:
            return t
        h //= k
        t += 1

n, k = map(int, input().split())
h = list(map(int, input().split()))
m, c = map(int, input().split())

heap = []
cur = h[:]
total = 0

for i in range(n):
    total += compute_time(cur[i], k)
    gain, inc = best_gain(cur[i], k, c)
    heapq.heappush(heap, (-gain, i, inc))

for _ in range(m):
    gain, i, inc = heapq.heappop(heap)
    gain = -gain
    if gain == 0:
        break
    cur[i] += inc
    total += gain
    new_gain, new_inc = best_gain(cur[i], k, c)
    heapq.heappush(heap, (-new_gain, i, new_inc))

print(total)
```该实现分离了两个职责。 第一个是使用重复除法计算段的破坏时间，直到出现可除状态。 第二个是通过检查所有商水平来寻找最佳的单滚动效果$h // k^t$。 每个级别最多产生一个候选增量，该增量是通过将商对齐到下一个倍数而得出的$k$。 

堆确保我们始终首先应用最有价值的卷轴。 每次更新一个段时，其未来增益都会发生变化，因此我们在重新插入之前重新计算其最佳候选者。 

主要的微妙之处在于限制级别的搜索。 每次乘以$k$商上升一级，并且因为$h \le 10^9$，这个循环很短并且安全有界。

 ## 边缘情况

 一种边缘情况是当一个段已经可以被整除时$k$。 在这种情况下，它的基础贡献为零，因为它会立即被销毁。 然而，一个小的增量可能会消除顶层的整除性并引入多个除法步骤。 该算法可以正确处理此问题，因为最佳增益计算显式检查更高的商级别，并且任何进入不可整除状态的有效增量都会成为堆中的候选者。 

当重复除法很快导致零时，会发生另一种情况。 对于较小的值，例如$h < k$，该过程总是只执行一步，除非$h = 0$。 该算法很自然地处理这个问题，因为商链几乎立即停止，并且计算增益时需要考虑的级别很少，因此不需要特殊处理。
