 ## 解决方案
 ## 问题理解

 我们分为三组学生，由他们喜欢的编程语言决定。 任务是将所有学生分成三个练习组。 

唯一的限制是一个组不允许同时包含汇编爱好者和 C++ 爱好者。 基本风扇不会产生冲突，可以放置在任何地方。 

只要满足约束条件，我们就可以随意将学生分配到三个组中。 目标是在分区后使最大的组尽可能小。 

因此，问题不在于找到有效的分割，而在于平衡将三种类型的项划分到三个容器中的约束分区，其中一对类型不能在同一容器内共存。 

限制非常小，每种类型最多 1000 名学生，最多只有 5 个测试用例。 这排除了繁重的图或状态探索方法，但强烈建议直接数学表征或小案例分析。 

一种天真的方法会尝试将每个学生分配到小组并模拟所有可能性，但即使我们只考虑小组作业，结构仍然会随着学生数量的增加而组合增长。 This would be far beyond what is needed.

 当其中一种冲突类型与其他类型相比非常大时，就会出现微妙的边缘情况。 例如，如果汇编学生占主导地位而 C++ 学生很少，那么最佳策略就被迫小心地隔离他们，并且任何天真的贪婪平衡组大小都可以很容易地将不兼容的类型放在一起或高估可实现的平衡。 

当基础学生占主导地位时，就会出现另一种边缘情况。 由于它们很灵活，错误的解决方案可能会假设它们总是完全平滑分布，但它们无法解决汇编器和 C++ 必须保持分离的基本限制。 

## 方法

 蛮力观点是将这视为将每个学生分配到三个组之一，同时遵守约束：任何组都不能同时包含汇编学生和 C++ 学生。 人们可以想象迭代所有作业并检查有效性，然后跟踪最佳的最大组大小。 这在概念上是正确的，因为它探索了整个解决方案空间，但作业数量随着学生数量呈指数增长，即使对于最小的约束也是完全不可行的。 

关键的观察结果是，唯一真正的冲突发生在汇编学生和 C++ 学生之间。 基础学生的行为就像自由质量一样，可以分散以改善平衡。 一旦我们确定了如何允许组包含汇编和 C++ 学生，剩下的任务就变成分配基础学生以最小化最大负载。 

由于正好存在三个组，因此必须为每个组分配一个“类型约束”：要么允许汇编学生，要么允许 C++ 学生，但决不能同时允许两者。 这将结构简化为选择将多少组分配给冲突的每一方。 仅存在两种有意义的配置：一组处理所有汇编程序学生，而另外两组处理 C++ 学生，反之亦然。 

一旦这种分配得到解决，每一方都可以在内部将自己的学生分配到其允许的群体中，并且基础学生可以用作平衡资源。 实现最大小组规模 T 的可行性成为一个简单的容量条件：每个小组都有来自其强制语言的固定负载和由基础学生填充的剩余容量，并且总可用容量必须足以吸收所有基础学生。 

这将问题简化为检查两个配置并计算每个配置中最小的可行最大组大小。

 ## 算法演练

 我们推理如何在汇编器和 C++ 不能共存于单个组中的限制下构建这三个组。 

1. 决定有多少个组是“允许汇编程序”与“允许使用 C++”。 由于组必须非空，并且汇编程序和 C++ 都存在，因此唯一有意义的拆分是一组用于汇编程序端，两个用于 C++ 端，或者两个用于汇编程序端，一个用于 C++ 端。 
2. 对于选定的分组，将 Assembler 学生尽可能均匀地分配到允许的组中。 这可以最大限度地减少任何组中最大的汇编器负载，因为不平衡只会增加最大组大小。 
3. 对允许组内的 C++ 学生执行相同的操作。 同样，最优分配是尽可能平衡的。 
4. 现在将基础学生视为灵活的填充者。 对于候选最大组大小 T，计算在放置强制汇编或 C++ 学生后每组中存在多少未使用容量。 
5. 检查三组所有可用容量的总和是否至少等于 Basic 学生的数量。 如果是，则可以在不超过 T 的情况下分配基础学生以满足所有约束。 
6. 计算满足结构下限（每个组必须符合其强制语言分配）和全局容量约束的最小 T。 
7. 评估两个分割并返回较小的结果 T。 

### 为什么它有效

 关键的不变量是，一旦汇编器和 C++ 组被固定，Basic 学生的行为就像可分割的质量一样，可以自由地重新分配。 因此，对答案的唯一真正限制是每组的最小负载和总容量。 因为我们将问题简化为检查给定最大 T 的可行性，并且可行性仅取决于聚合容量而不是单独的分配，所以该结构完全由两种配置来表征。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(a, b, c):
    total = a + b + c

    def ceil_div(x, y):
        return (x + y - 1) // y

    # Case 1: 1 group for A-side, 2 groups for C-side
    t1 = max(
        ceil_div(total, 3),
        a,
        ceil_div(c, 2)
    )

    # Case 2: 2 groups for A-side, 1 group for C-side
    t2 = max(
        ceil_div(total, 3),
        c,
        ceil_div(a, 2)
    )

    return min(t1, t2)

def main():
    t = int(input())
    out = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        out.append(str(solve_case(a, b, c)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```直接按照推导公式实现。 总和除以三给出了不可避免的下限，因为所有学生必须恰好分布在三个组中。 第二项和第三项强制要求在任何配置中，分配给单一语言端的组必须至少容纳其负载最多的分区。 

比较两种配置的决定恰好对应于选择汇编程序还是 C++ 是“主导的隔离方”。

 ## 边缘情况

 一个关键的边缘情况是当一种冲突语言非常大而另一种非常小时。 在这种情况下，最佳解决方案主要是将大组拆分为允许数量的子组，而基础学生无法有意义地减少最大值。 

例如，使用输入`1000 1 1`，算法选择最佳隔离较大一侧的配置。 计算出的界限`ceil(1002/3) = 334`主要的要求是汇编器必须分成单个组，导致所选配置中强制最大值为 500。 该解决方案通过采取最大程度的全局和结构约束而不是仅仅依赖平均来正确捕获这种不平衡。
