 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，意味着每个值来自$1$到$n$在数组中只出现一次。 对于每个查询，我们查看一个连续的段，并询问是否可以将其拆分为两个连续的部分，使得左侧部分中的每个值都严格小于右侧部分中的每个值。 

从更可操作的角度来说，如果一个段内部存在一个剪切位置，其中左侧的所有数字都小于右侧的所有数字，则该段是“好”的。 剪切必须尊重数组顺序，因此我们不会重新排序元素，仅选择一个分割点。 

约束条件很大，双方$n$和$q$最多$3 \cdot 10^5$。 任何通过扫描段来处理每个查询的解决方案都会花费$O(n)$每个查询，导致$O(nq)$，这远远超出了可行的限度。 这推动我们进行近预处理$O(1)$或对数查询时间，通常使用前缀信息和全局结构。 

一个微妙的问题出现在看起来“大部分有序”但由于跨边界的单个反转而失败的段中。 例如，在这样的段中$[3,1,4,2]$，即使两半都包含本地的小元素和大元素，也没有有效的分割。 阻塞是全局性的：一些小元素出现在大元素的右侧，从而阻止任何干净的分离。 

## 方法

 暴力方法尝试每个查询段内的每个可能的分割点。 对于固定查询$[l, r]$，我们测试所有$i \in [l, r-1]$并检查是否$\max(a_l \dots a_i) < \min(a_{i+1} \dots a_r)$。 这需要重复计算范围最大值和最小值。 即使对 RMQ 进行了预处理，我们仍然会检查$O(n)$每个查询的分割点，导致$O(nq)$最坏情况下的行为。 

关键的观察是“存在分裂”的条件可以在全球范围内重新构建。 当且仅当我们可以按照原始顺序将段划分为两个集合，使得左集中的所有元素都小于右集中的所有元素时，才存在有效的分割。 这相当于说该段可以分为连续的块，其中没有“交叉反转”强制合并。 

我们不是测试所有分割点，而是在按顺序扫描时跟踪段内存在多少不相交的“排序块”。 每当当前块内无法维持最小所需值时，就会启动新块。 具体来说，我们可以维护一个贪婪分区：扩展当前块，直到它包含满足排名连续性所需的所有值，这相当于跟踪前缀最大值并确保与位置映射的一致性。 

更标准和更清晰的重新表述使用排列属性。 让`pos[x]`成为价值地位$x$。 在任何环节$[l, r]$，当且仅当我们对段中的值进行排序时，它们的位置形成间隔的并集，并且可以在某个值边界处分割而无需交错，该段才是好的。 这减少了检查该段是否可以通过“切割值”进行分区$k$这样所有的值$\le k$完全出现在所有值之前$> k$段内。 当我们按值顺序扫描时，可以通过跟踪值的最大和最小位置范围来验证此条件。 

我们预处理数组`pos[x]`，然后维护一个基于值顺序的数据结构，该结构允许我们查询一系列值的最小和最大位置。 对于一个段$[l, r]$，我们尝试寻找是否存在一个值阈值$k$这样：

 值的最小位置$1..k$位于里面$[l, r]$，以及值的最大位置$1..k$也位于里面$[l, r]$，对于其余值也类似。 这减少了检查段在映射到值空间时是否形成连续结构的问题，这可以使用值索引存储上的段树来回答$(minPos, maxPos)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分割检查 |$O(nq)$|$O(1)$| 太慢了 |
 | 线段树的值|$O((n+q)\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 构建数组`pos`这样`pos[v]`给出价值指数$v$在排列中。 这将问题从索引空间转换为值空间，这一点至关重要，因为值是一种排列，可以被视为有序轴。 
2. 在值域上构建线段树$[1, n]$，其中每个节点存储其范围内的值之间的最小和最大位置。 这允许我们查询任何值区间位于原始数组内的位置。 
3.对于每个查询段$[l, r]$，我们想要检测该段中的值是否可以分割成两个连续的值区间，而不会在位置上交错。 我们使用线段树隐式搜索值边界。 
4. 从值 1 开始向上，我们通过查询范围最小和最大位置来重复扩展候选左组。 如果在某个时刻位置间隔超出$[l, r]$，我们知道这个边界不能形成有效的切割，我们继续合并。 
5. 每当我们到达左组的位置间隔与完全包含在中的子集完全匹配的点时$[l, r]$，我们尝试分割：剩余的值也必须完全位于$[l, r]$没有重叠的位置。 如果存在这样的分区，则该段是好的。 
6. 如果找到有效边界，则回答“是”，否则回答“否”。 

### 为什么它有效

 排列结构确保每个值对应于唯一的位置，因此仅当两个值集之间没有交错时，值空间中的任何候选分割都会在位置空间中产生连续的间隔。 线段树通过最小/最大位置范围准确地捕获这种交错。 当值范围可以划分为两个连续的值块且其位置范围在查询段内不重叠时，就存在有效的分割。 这保证了正确性，因为任何交错都会迫使最小-最大位置间隔重叠，从而阻止干净的分离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, pos):
        self.n = len(pos) - 1
        self.minv = [0] * (4 * self.n)
        self.maxv = [0] * (4 * self.n)
        self.pos = pos
        self.build(1, 1, self.n)

    def build(self, v, l, r):
        if l == r:
            self.minv[v] = self.maxv[v] = self.pos[l]
        else:
            m = (l + r) // 2
            self.build(v * 2, l, m)
            self.build(v * 2 + 1, m + 1, r)
            self.minv[v] = min(self.minv[v * 2], self.minv[v * 2 + 1])
            self.maxv[v] = max(self.maxv[v * 2], self.maxv[v * 2 + 1])

    def query(self, v, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.minv[v], self.maxv[v]
        m = (l + r) // 2
        res_min = 10**18
        res_max = -1
        if ql <= m:
            mn, mx = self.query(v * 2, l, m, ql, qr)
            res_min = min(res_min, mn)
            res_max = max(res_max, mx)
        if qr > m:
            mn, mx = self.query(v * 2 + 1, m + 1, r, ql, qr)
            res_min = min(res_min, mn)
            res_max = max(res_max, mx)
        return res_min, res_max

n = int(input())
a = list(map(int, input().split()))
pos = [0] * (n + 1)

for i, x in enumerate(a, 1):
    pos[x] = i

st = SegTree(pos)

q = int(input())
out = []

for _ in range(q):
    l, r = map(int, input().split())

    lo, hi = 1, n
    ok = False

    while lo < hi:
        mid = (lo + hi) // 2
        mn, mx = st.query(1, 1, n, 1, mid)
        if mn >= l and mx <= r:
            ok = True
            hi = mid
        else:
            lo = mid + 1

    if ok:
        mn, mx = st.query(1, 1, n, 1, lo)
        if mn >= l and mx <= r and lo < n:
            mn2, mx2 = st.query(1, 1, n, lo + 1, n)
            if mn2 >= l and mx2 <= r:
                ok = True
            else:
                ok = False
        else:
            ok = False

    out.append("Yes" if ok else "No")

print("\n".join(out))
```核心实现细节是基于值索引的线段树。 每个节点总结了原始数组中出现的值范围。 然后，查询减少为检查某些值范围是否完全包含在查询间隔中。 二分查找尝试在值空间中定位有效的分割。 

最微妙的部分是保持收容检查的正确性`mn >= l and mx <= r`，这确保候选值块不会溢出到查询段之外。

 第二个示例强调有效性取决于值块是否在查询间隔内保持位置连续。

 ## 边缘情况

 关键的边缘情况是一个段，其中数组局部单调，但全局与段自然分割之外的值交错。 例如，在`[1, 3, 2, 4]`，3 和 2 之间的分割无效，因为 2 位于右侧但小于 3。线段树检测到这一点是因为值块`[1,3]`已经跨越了任何干净边界之外的位置。 

另一种边缘情况是包含连续值但位置分散的段，例如`[2, 1, 4, 3]`。 尽管值可以分为`[2,1]`和`[4,3]`，位置仍然是可分离的，因此算法通过找到尊重位置间隔的有效值阈值来正确返回“是”。 

这些案例证实，正确性不仅仅取决于顺序，还取决于值区间是否对应于连续的位置范围。
