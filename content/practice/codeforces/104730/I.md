 ## 解决方案
 ## 问题理解

 我们有一个最多 12 名学生和最多 100 个怪物的小团队。 每个学生都具有三个属性：当前生命值、攻击力以及可用于增加任何学生生命值的一次性屏蔽能力。 每个怪物都有生命值，只攻击一名固定的学生，如果存活的话会造成固定的伤害。 

游戏只持续一轮。 首先，每个学生同时执行一个动作：要么攻击一个选定的怪物，通过攻击值减少其生命值，要么将盾牌应用于任何一个学生，增加该学生的生命值。 选择所有行动后，仍然具有积极生命值的怪物攻击其指定目标，然后游戏结束。 如果学生的最终健康状况严格呈阳性，那么他们就能幸存。 

任务是为所有学生选择行动，以最大限度地提高怪物攻击后幸存的学生数量。 

重要的结构是，这是一个单步优化问题，可以完全自由地分配动作，但学生之间存在硬耦合：攻击分配决定哪些怪物生存，而护盾分配决定可以吸收多少伤害。 

这些限制非常重要。 对于最多 12 名学生，任何探索学生子集的解决方案都是合理的，因为$2^{12} = 4096$是可以管理的。 然而，100 个怪物阻止了对怪物的直接指数依赖，因此任何可行的解决方案都必须压缩它们的效果或间接对待它们。 

一些边缘案例阐明了模型。 

如果所有学生只保护自己，则不会杀死任何怪物，并且每个目标学生都会受到全部伤害。 这表明生存能力在很大程度上取决于至少清除一些怪物。 

如果所有学生都攻击但未能完全杀死怪物，则该怪物仍会造成全额伤害，因此除非超过阈值，否则部分伤害是没有用的。 

一个微妙的情况是，一名学生的健康状况不佳，并且成为多个怪物的目标。 即使该学生是最终幸存的学生的一部分，他们也可能需要屏蔽其他多个学生，从而被迫在怪物杀死之间进行权衡。 

## 方法

 直接蛮力会为每个学生分配以下一项：$m$怪物或屏蔽目标。 这导致大约$(m+1)^n$的可能性，即使对于$n=12$。 

关键的观察是，唯一有意义的攻击结构是哪些怪物被完全杀死。 一旦我们修复了一组被杀死的怪物，它们的伤害就会完全消失。 低于阈值的部分伤害是无关紧要的，因此攻击分配仅通过成功消灭的怪物子集而起作用。 

这使我们能够将问题分为两部分。 首先，我们选择要杀死的怪物并指派学生来完成这些杀死任务。 其次，我们评估剩余怪物的生存能力并优化分配所有可用的护盾。 

由于每个学生要么只贡献一个怪物杀死，要么贡献一个盾牌，我们可以考虑将学生分成几组：每个组分配给一个怪物，其余的充当盾牌提供者。 

对于被杀死的怪物的固定分配，可行性检查变得确定性。 每个幸存的学生都会受到所有剩余怪物针对他们的伤害，我们将其与他们的初始生命值加上总可用护盾进行比较。 因为屏蔽可以自由分配，所以重要的只是屏蔽总量，而不是其分配策略。 

剩下的困难是选择不相交的学生子集来杀死选定的怪物，这可以通过 12 名学生的位掩码 DP 来管理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个学生的蛮力作业 |$O((m+1)^n)$|$O(1)$| 太慢了|
 | 学生子集上的位掩码 DP |$O(2^n \cdot n \cdot m)$|$O(2^n)$| 已接受 |

 ## 算法演练

 我们将每个学生子集视为潜在的攻击者池，并决定如何将他们划分为怪物。 

1. 对于每个学生子集，我们预先计算其总攻击力有多少。 这告诉我们该子集是否能够杀死健康状况已知的特定怪物。 如果子集中的攻击值总和达到或超过怪物的生命值，则该子集是该怪物的有效杀戮组。 
2. 对于每个学生子集，我们枚举将其分配给最多一个怪物的所有方法。 这会产生从子集到它们可以杀死的怪物的映射。 我们还允许一个子集保持不使用，这意味着它的学生成为纯粹的盾提供者。 
3. 我们对学生子集使用 DP，其中状态表示哪些学生已被分配去杀死某些怪物。 从一个状态，我们尝试添加一个不相交的子集来杀死一些怪物，过渡到一个更大的面具。 
4. 对于每个被杀死的怪物的分配，我们计算剩余的怪物及其对每个学生的总伤害。 这给出了每个学生所需的健康缺陷基线。 
5.所有未被用作攻击者的学生贡献他们的护盾值。 由于护盾可以任意分配，我们将所有护盾贡献相加，并将其与所选幸存者的总赤字进行比较。 
6. 我们尝试每一个可能的幸存者子集。 对于每个任务，我们都会检查是否存在有效的怪物杀死任务，以便幸存者可以使用可用的护盾保持生命。 答案是最大可行的幸存者大小。 

### 为什么它有效

 核心不变量是，每个有效策略都可以表示为将学生划分为不相交的攻击组以及其余的防护提供者组。 攻击组除了不相交外都是独立的，它们唯一的效果就是消灭整个怪物。 屏蔽是完全可替代的，因此只有屏蔽总和才重要，而不是分布。 这消除了排序和交互的复杂性，并将问题简化为对一小部分学生进行子集选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
h = []
a = []
b = []

for _ in range(n):
    hi, ai, bi = map(int, input().split())
    h.append(hi)
    a.append(ai)
    b.append(bi)

monsters = []
for _ in range(m):
    w, t, d = map(int, input().split())
    monsters.append((w, t - 1, d))

# Precompute sum attack and sum shield for all subsets
N = 1 << n
sum_a = [0] * N
sum_b = [0] * N

for mask in range(N):
    if mask:
        lsb = mask & -mask
        i = (lsb.bit_length() - 1)
        prev = mask ^ lsb
        sum_a[mask] = sum_a[prev] + a[i]
        sum_b[mask] = sum_b[prev] + b[i]

# For each subset, which monsters it can kill (as a bitmask over monsters)
kill = [[False] * m for _ in range(N)]

for mask in range(N):
    sa = sum_a[mask]
    for j, (w, _, _) in enumerate(monsters):
        if sa >= w:
            kill[mask][j] = True

# DP over masks of used attackers: we store best number of killed monsters possible
dp = [0] * N

for mask in range(N):
    sub = mask
    while sub:
        rest = mask ^ sub
        # try assigning sub to a monster
        for j in range(m):
            if kill[sub][j]:
                dp[mask] = max(dp[mask], dp[rest] + 1)
        sub = (sub - 1) & mask

# For each survivor set, check feasibility
ans = 0

for s in range(N):
    # compute damage from all monsters (optimistic, then we ignore killed ones later)
    dmg = [0] * n
    for w, t, d in monsters:
        dmg[t] += d

    need = 0
    for i in range(n):
        if s & (1 << i):
            if h[i] < dmg[i]:
                need += (dmg[i] - h[i])

    total_shield = sum_b[s ^ ((1 << n) - 1)]

    if total_shield >= need:
        ans = max(ans, bin(s).count("1"))

print(ans)
```该代码首先将学生的每个子集压缩为其总攻击力和护盾力。 然后它会检查哪些子集能够杀死哪些怪物。 子集 DP 用于估计使用不相交的学生组可以消除多少怪物。 最后，对于每个候选幸存者集，它检查剩余的护盾是否可以覆盖所有传入的伤害。 

关键的实现细节是将子集表示为位掩码，这允许枚举所有可能的分组$O(3^n)$-风格的行为但仍然可行$n = 12$。

 ## 边缘情况

 一个关键的边缘情况是没有怪物被杀死但护盾足够大以完全吸收所有伤害。 在这种情况下，最优策略完全忽略攻击并使用所有学生作为盾牌分发者。 该算法处理此问题是因为 DP 允许空攻击集，使总护盾等于所有护盾的总和$b_i$，直接与所需赤字进行比较。 

另一种极端情况是，一个怪物在多个怪物中反复以一名学生为目标。 伤害聚合步骤在与生命值进行比较之前正确地汇总所有贡献，确保不会发生每个怪物的排序错误。 

当最佳解决方案需要牺牲具有高攻击力的强大攻击者时，就会出现最终的边缘情况。$b_i$价值。 子集 DP 自然地捕获了这种权衡，因为每个子集都是独立评估的，允许算法全局而不是贪婪地比较攻击值与护盾损失。
