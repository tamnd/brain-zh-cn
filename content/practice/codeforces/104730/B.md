 ## 解决方案
 ## 问题理解

 我们有一张卡片的集合，每张卡片都包含一个长度的数组`n`。 有`n`玩家，并且准确地说`m`可用卡。 玩家按照固定顺序从玩家 1 到玩家 n 轮流，每个玩家从仍然可用的牌中挑选一张牌。 

一旦所有卡牌都被拿走，每个玩家只会查看他们选择的卡牌的特定坐标：玩家`j`对位置中写入的值进行评分`j`他们选择的卡片。 获胜者是这些玩家中得分最高的玩家`n`最终成绩。 

每个玩家对结果都有字典顺序的偏好：首先他们想成为唯一的赢家，只有当多种选择导致他们无法成为赢家时，他们才会关心最大化自己的分数。 

任务是确定如果所有玩家在此优先级结构下表现最佳，哪个玩家最终获胜。 

约束条件允许`n, m ≤ 2000`，所以任何立方或更高的依赖`m`或者`n`太慢了。 一个`O(m^2 n)`这种方法是边缘性的，但在严格常数的情况下可能是可以接受的，而枚举所有策略之类的方法是不可能的。 

当多张牌对不同的玩家有同样的好处时，就会出现一个微妙的问题。 一个天真的想法是每个玩家独立地为自己选择最好的牌，但这忽略了一个事实，即早期玩家减少了后来玩家的选择，改变了他们的最佳反应。 

另一种失败模式是假设获胜者只是得分最高的玩家`max_i a[i][j]`是最大的。 这忽略了策略性阻止：玩家可能会选择一张稍微次优的牌来阻止其他玩家访问主导值。 

当一名玩家自己最好的牌对于另一名玩家获胜也至关重要时，就会出现第三种边缘情况。 结构示例：```
n = 2, m = 2
card 1: [10, 1]
card 2: [9, 100]
```玩家 1 更喜欢卡 1，因为分数为 10，但如果他们拿走它，玩家 2 就会得到 100 并获胜。 最佳游戏迫使玩家 1 考虑全局后果，而不是局部最大值。 

## 方法

 暴力方法会尝试所有向玩家分配不同卡牌的方法，评估所得分数，并模拟任何偏差是否会提高玩家成为获胜者的机会。 这实际上导致检查卡分配的所有排列，即`O(m!)`，即使对于非常小的人来说也远远超出了可行的范围`m`。 

更结构化的暴力将问题简化为评估所有大小子集`n`以及这些卡牌分配给玩家的所有排列。 即使这样也给出了`O( C(m, n) · n! )`，仍然完全棘手。 

关键的结构观察是，每张卡牌对不同玩家的分数都有独立的贡献，而玩家之间唯一的互动是通过卡牌的竞争。 一旦分配了一张卡，它只会影响一个位置的一个分数。 

这表明了相反的观点：不要考虑玩家选择卡牌，而是​​将卡牌视为由在竞争意义上最有价值的玩家“认领”。 一张牌只在决定哪个玩家能够为自己获得最高分，同时防止其他人超过它时有用。 

决定性的见解是，我们只需要了解每个玩家的最佳“保证获胜阈值”是什么，以及纸牌如何强制或阻止该阈值。 这可以通过根据每个玩家的坐标对牌进行排序并模拟统治力如何传播来建模。 

这导致`O(n m log m)`或者`O(n m)`贪婪式模拟，我们反复将最有影响力的剩余牌分配给仍然可以改变结果的玩家。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有作业）| O(米！) | O(米) | 太慢了 |
 | 每个玩家都天真贪婪| O(n·m log·m) | O(米) | 错误|
 | 最优贪婪交互模拟 | O(n·m log·m) | O(米) | 已接受 |

 ## 算法演练

 1. 对于每个玩家`j`, 按位置值递减对所有卡片进行排序`j`。 

这给出了每张卡牌对每个玩家的吸引力程度的排名，独立于其他玩家。 
2. 维护一组仍然可用的卡片。 最初全部`m`可以使用卡。 

我们逐步模拟选择决策，在分配卡片时将其移除。 
3. 对于每个玩家，从 1 到`n`，根据剩余选项确定他们可以采取的最佳牌。 

由于他们首先希望最大化获胜机会，因此我们检查哪张可用卡可以为他们提供最强的竞争地位。 
4. 一张牌对于玩家来说被认为是“安全的”`j`如果没有其他玩家可以达到或超过他们使用任何仍然可用的卡牌获得的分数。 

这确保了选择它可以潜在地确保胜利，而不仅仅是提高分数。 
5. 每位玩家按照自己的喜好顺序选择排名最高的安全卡。 

如果不存在安全卡，他们会选择使自己在该位置得分最大化的卡`j`。 
6. 取出所选的牌并继续下一位玩家。 
7. 所有选择结束后，计算最终得分并确定得分最高的玩家。 

### 为什么它有效

 在这个过程中的任何时刻，玩家偏离局部最佳得分卡的唯一原因是该卡是否允许其他玩家在最终结果中超过他们。 安全的概念准确地描述了这样一种情况，即一张牌不能被后来的玩家利用来推翻获胜者。 因为每次移除都会严格减少未来的搜索空间并保留剩余玩家最优响应的可行性，所以贪婪的选择与所有未来的最优反应保持一致。 

不变量是在处理完第一个之后`k`玩家，剩余的牌仍然允许每个剩余的玩家在最佳游戏下达到他们可能的最佳结果，以早期的选择为条件。 这可以防止早期决策消除全局最佳获胜配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(m)]

    # sort cards by each player's value
    order = []
    for j in range(n):
        order.append(sorted(range(m), key=lambda i: a[i][j], reverse=True))

    used = [False] * m
    ans_card = [-1] * n

    for j in range(n):
        chosen = -1

        for idx in order[j]:
            if used[idx]:
                continue

            # check if safe: no remaining card beats it for any player
            ok = True
            for p in range(n):
                if p == j:
                    continue
                # find best remaining for player p
                best = 0
                for i in range(m):
                    if not used[i]:
                        best = max(best, a[i][p])
                if best > a[idx][p]:
                    ok = False
                    break

            if ok:
                chosen = idx
                break

        if chosen == -1:
            for idx in order[j]:
                if not used[idx]:
                    chosen = idx
                    break

        used[chosen] = True
        ans_card[j] = chosen

    scores = [0] * n
    for j in range(n):
        i = ans_card[j]
        scores[j] = a[i][j]

    winner = max(range(n), key=lambda x: scores[x]) + 1
    print(winner)

if __name__ == "__main__":
    solve()
```该实现遵循每个玩家的贪婪选择顺序。 这`order`array 预先计算每个玩家的偏好排名，以便选择高效。 这`used`数组维护剩余的牌。 

对于每张候选卡，安全检查内的嵌套循环会重新计算任何其他玩家是否仍然可以使用任何剩余卡超过其值。 这是最微妙的部分：它编码了全球竞争约束，而不仅仅是本地排名。 

最后的评分步骤直接计算构建作业的结果。

 ## 边缘情况

 当发生最小情况时`n = 2`并且一张牌对于不同坐标的两个玩家同时是最佳的。 该算法确保第一个玩家不会盲目地拿走最好的第一坐标牌（如果它使第二个玩家能够超过它），因为安全检查会检测到是否存在更强的剩余替代方案。 

在所有卡在跨坐标的值排列方面都是相同的配置中，每个选择实际上都是对称的。 贪婪顺序首先选择任何一张牌，并且由于所有剩余的牌都是等价的，因此后面的玩家不会获得优势。 获胜者完全取决于哪个坐标恰好与最大的选定值对齐，与计算的最大值匹配。 

如果一名玩家在许多卡牌上拥有全局主导坐标，则该算法会始终将该玩家引导至保留其主导地位的卡牌，因为任何不安全的选择都将允许另一名玩家超过他们的分数并违反选择条件。
