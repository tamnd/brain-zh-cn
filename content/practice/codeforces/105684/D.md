 ## 解决方案
 ## 问题理解

 我们得到了多组棍子长度。 每根棍子都可以用作四边形的完整边。 我们想要计算从这些木棍中可以形成多少个不同的等腰梯形。 

有效的梯形恰好使用四根选定的棍子。 其中两个形成相等的腿，其余两个形成底座。 腿的长度必须相同，而底座的长度必须不同。 我们不允许形成一个退化的图形，所以梯形必须有正面积，这在几何上意味着与底边的差异相比，腿不能太短。 

如果两个梯形使用相同的多组边长，则认为它们是相同的，因为长度相等的棍子是无法区分的。 

约束最多可达 5000 根，长度可达 10 亿条。 这立即排除了 n 中的任何三次方，即使是简单的 O(n² √n) 或更糟糕的每次选择的结构也会太慢。 该结构表明我们应该按长度压缩并使用频率，因为实际值仅通过排序和差异起作用。 

一个微妙的问题是，即使我们选择了一对有效的底和一对相等的腿，我们也必须确保梯形在几何上是有效的。 粗心的解决方案可能会忽略存在条件并过多计算无法实现形状的无效四元组。 

## 方法

 思考这个问题的一个直接方法是尝试所有四连杆。 我们选择两根棍子作为腿，两根作为底座，然后检查所选的两个底座是否不同以及几何形状是否允许非退化的等腰梯形。 这已经导致了 O(n⁴) 种可能性，这远远超出了可行的范围。 

我们可以通过分离腿和底座的作用来减少这种情况。 如果我们固定公共腿长c，那么选择腿的方式数量仅取决于存在多少根长度为c的棍子，即C(freq[c], 2)。 固定腿后，剩下的问题纯粹是选择两个不同的底座长度a和b。 

因此，结构变为：对于每个不同值 c，计算有多少个无序不同值对 (a, b) 满足边长为 c 的梯形可行性条件。 

具有底边 a 和 b 以及边 c 的等腰梯形的几何条件是底边之间的差必须严格小于边长的两倍。 直观上，如果底座相距太远，腿就无法将它们连接起来，而不会将高度折叠为零。 这转化为 |a − b| < 2c。 

因此，对于每个 c，我们需要计算多重集中的值对，其差值以 2c 为界。 这是一个经典的“在排序数组的滑动窗口内计数对”问题。 

我们将数组压缩为具有频率的排序唯一值。 对于固定的 c，我们对排序值进行两指针扫描：对于每个左端点 j，我们尽可能扩展右端点 k，同时保持 V[k] − V[j] < 2c。 每个有效的 k 都会贡献从 j 开始的 (k − j) 对。 对 j 求和得出有效碱基对的数量。 

最后我们乘以 C(freq[c], 2) 并对所有 c 求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解四倍 | O(n⁴) | O(1) | O(1) | 太慢了 |
 | 固定腿+两个指针在底座上| O(平方米) | O(米) | 已接受 |

 这里m是不同长度的数量，最多为n。 

## 算法演练

 令 V 为不同长度的排序列表及其计数。

1. 构建所有棒长度的频率图并提取排序的唯一值 V。这减少了重复工作，因为相同的长度在所有有效配置中都是可互换的。 
2. 对于 V 中的每个值 c，如果 freq[c] 小于 2，则跳过它，因为我们无法从中形成两条相等的腿。 这可以防止对不可能的腿选择进行不必要的计算。 
3. 对于固定的 c，计算 L = 2c。 现在我们计算有多少个 a < b 满足 b − a < L 的无序对 (a, b)。 
4. 对 V 进行两指针扫描。保持右指针 k。 对于每个左指针 j，只要 V[k] − V[j] < L 成立，就前进 k。 这确保了窗口 [j, k) 中的所有元素都是 j 的有效伙伴。 
5. 对于每个 j，将 (k − j − 1) 添加到有效碱基对的计数中。 该表达式严格计算 j 和 k 之间与 j 形成有效无序对的所有索引。 
6. 完成 c 的扫描后，将有效碱基对的数量乘以 C(freq[c], 2) 并将其添加到答案中。 
7. 输出最终累加和。 

两指针扫描期间的关键不变量是，对于每个固定左端点 j，指针 k 是最小索引，使得 [j + 1, k − 1] 中的所有索引在 V[x] − V[j] < 2c 约束下与 j 形成有效对。 由于两个指针仅向前移动，因此在处理其左端点时，每对指针都只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def comb2(x):
    return x * (x - 1) // 2

def main():
    n = int(input())
    a = list(map(int, input().split()))

    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1

    vals = sorted(freq.keys())
    m = len(vals)

    ans = 0

    for c in vals:
        fc = freq[c]
        if fc < 2:
            continue

        limit = 2 * c

        k = 0
        cnt_pairs = 0

        for j in range(m):
            if k < j + 1:
                k = j + 1

            while k < m and vals[k] - vals[j] < limit:
                k += 1

            cnt_pairs += max(0, k - j - 1)

        ans += comb2(fc) * cnt_pairs

    print(ans)

if __name__ == "__main__":
    main()
```该实现首先将输入压缩为频率，因为在选择相同长度的边时只有多重性才重要。 对于每个候选腿长度 c，它使用两个指针扫描排序的不同值来计算有多少个碱基对是兼容的。 

内层表达式 k − j − 1 容易写错； 它表示严格位于 j 右侧但仍在允许的差异窗口内的有效伙伴的数量。 乘以 C(freq[c], 2) 可以解释选择两条相同腿的所有方法。 

## 工作示例

 考虑输入，其中排序的唯一值是 V = [1, 2, 3]，频率均等于 1（除了可能重复的边）。 

假设我们关注 c = 2 且 freq[2] = 2，因此我们可以形成一种选择边的方法。 

对于 c = 2，限制为 4。

 | 1 | 2 | 3 | 1 (3) | 1 (3) | 1 |

该迹线显示了滑动窗口如何在每个左端点精确地累积所有有效碱基对一次。 

现在考虑重复值仅影响边选择的情况：a = [5, 5, 1, 3]。 

对于 c = 5，freq[5] = 2，因此 C(2,2) = 1。基值为 [1, 3, 5]。 

限制为 10，因此所有对都有效。 

| j | V[j] | k | 有效合作伙伴| 贡献 |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | 3 | 2 | 2 |

 ## 边缘情况

 当所有棒的长度相同时，算法立即返回零，因为没有不同的碱基。 频率条件本身不会触发任何计算，并且碱基对扫描不会贡献任何东西，因为只有一个唯一值。 

当恰好有两个不同的长度但没有第三个值时，则不存在有效的梯形，因为底必须不同且边必须来自一个值。 该算法正确地生成零，因为在严格的不等式约束下，两个指针扫描二元素数组不会产生有效的不同对。 

当有许多重复值时，腿的贡献通过 C(freq[c], 2) 呈二次方增长，而基本结构是独立计算的。 这种分离确保了多重性不会干扰几何可行性检查，并且每个配置都只计算一次。
