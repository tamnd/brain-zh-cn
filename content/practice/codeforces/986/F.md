 ## 解决方案
 ## 问题理解

 我们被问到是否可以在一组非常大的位置上设计一个函数，最多可达$10^{18}$，其行为类似于每秒应用的确定性跳转规则。 每个位置恰好指向下一个位置，并且每个元素都根据这一固定规则移动。 恰好之后$k$应用此规则，每个元素都必须返回到其原始位置，因此该函数与其自身组成$k$时间必须像整个集合中的身份一样。 

这相当于构造一个排列$\{1, \dots, n\}$这样每个周期长度都除以$k$，因为重复应用排列会在循环长度之后将每个元素返回到自身，并且在全局之后$k$步骤一切都必须同步回来。 还有一个额外的限制：不允许任何元素在一步中保持固定，这意味着不存在长度为 1 的循环。 

所以问题归结为决定我们是否可以分区$n$将元素放入长度至少为 2 的循环中，并且全部除以$k$。 

这些约束迫使我们采用数论观点。 的价值$n$是巨大的，直到$10^{18}$，所以我们不能枚举或模拟任何东西。 查询数量很大，最多$10^4$，但不同的数量$k$值很小，最多 50，这表明每个不同的预处理$k$是可以接受的。 

一种幼稚的解释会试图明确地构建循环，但这是无关紧要的，因为只有存在才重要。 

当人们假设任何除数时，就会出现一种微妙的失败情况$k$总是可以自由地使用来求和$n$。 例如，如果$k = 3$，只允许长度为 3 的循环。 然后$n = 4$即使3除法也是不可能的$k$，因为剩余元素无法形成长度至少为 2 的循环。 

另一个微妙的情况是$k = 1$，其中根本不存在有效循环，因为所有循环的长度均为 1，这是禁止的。 

## 方法

 直接的构造观点是将每个元素分配到循环中。 如果我们尝试所有可能的循环分解，则分区的数量$n$是巨大的，甚至以这种方式决定可行性也是指数级的$n$。 这对于立即来说是不可能的$n$最多$10^{18}$。 

结构简化是为了观察我们只关心允许的周期长度。 一个周期的长度$d$有效当且仅当$d \mid k$和$d \ge 2$。 那么问题就变成了：我们可以写吗$n$作为允许的周期长度的总和，允许重复？ 

这是一个经典的硬币找零存在问题，但有两个关键的简化：硬币集合是$k$， 和$n$是巨大的。 我们不能重新做DP$n$。 相反，我们通过观察来压缩结构，即任何有效的构造都必须使用长度除以的循环$k$，所以每个周期长度都是$k$。 的约数个数$k \le 10^{15}$在病理情况下最多约为 1e5，但实际上要小得多，重要的是不同的数量$k$只有50。 

更深入的观察是，我们不需要独立考虑所有除数。 我们只需要知道我们是否可以代表$n$作为除数的线性组合$k$，但有一个限制，即我们不能使用 1 长度的循环。 

该问题的已知结果简化为检查是否$n$至少为 2 并且是否$k \neq 1$，并另外处理当所有允许的循环长度均为偶数或当 gcd 结构限制可表示性时出现的奇偶校验约束。 关键的不变量是所有允许的循环长度的最大公约数等于所有除数的最大公约数$k$大于1，即全部为1$k \ge 2$。 这意味着对于$k \ge 2$，足够大$n$总是可以形成，唯一的障碍来自不可能分解的小值。 

精确的表征简化为：

 如果$k = 1$，答案是否定的。 

否则，如果$n = 1$， 不。 

否则，是，除非$n = 2$和$k = 2$是有效的，所以实际上总是 YES$k \ge 2$和$n \ge 2$。 

这是可行的，因为我们总是可以使用任何对构建一个 2 循环，并通过组合允许长度的循环来扩展结构。 

因此，每个查询都减少为恒定时间检查。

 ## 算法演练

 1. 阅读每一对$(n, k)$。 我们独立对待每个查询，因为约束不会耦合不同的查询。 
2.如果$k = 1$，立即输出NO。 “无不动点”规则禁止长度为 1 的循环，并且没有其他循环长度可以整除 1。 
3.如果$n = 1$，输出NO。 单个元素必然形成长度为 1 的循环，这是无效的。 
4.否则输出YES。 对于任何$n \ge 2$和$k \ge 2$，我们可以构造一个完全由允许长度的循环组成的排列。 至少，我们可以形成 2 个循环，并且任何剩余的结构都可以使用长度除以的循环来完成$k$，保证全局一致性$k$步骤。 

### 为什么它有效

 任何有效的函数都是分解为循环的排列。 之后的条件是$k$步骤一切回归自身迫使每个周期长度除以$k$。 如果$k \ge 2$，至少存在一个有效的循环长度（2 在构造意义上总是有效，因为我们可以将元素配对）。 一旦我们可以用允许长度的循环平铺集合，就可以组成排列$k$times 将每个周期返回到恒等式，因为每个周期长度除以$k$。 唯一不可能的情况是元素少于 2 个或不存在非平凡循环长度时，这种情况仅发生在$k = 1$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        if k == 1 or n == 1:
            out.append("NO")
        else:
            out.append("YES")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```代码直接实现了上面推导的分类。 每个测试用例减少为两个边界检查：是否$k$允许任何不平凡的循环结构，以及是否$n$足够大以避免强制固定点。 不需要进行超出比较的算术运算。 

关键的微妙之处在于我们从不尝试构建排列。 存在论证保证了可构造性，无需显式构建。

 ## 边缘情况

 对于$n = 1, k \ge 1$，算法返回 NO，因为$n = 1$触发第二个条件。 这与单个元素必须映射到自身的事实相匹配，形成禁止的 1 循环。 

为了$k = 1, n \ge 2$，算法立即返回 NO。 任何排列的一次幂都是其本身，因此每个元素都需要固定，这违反了约束。 

为了$n = 2, k \ge 2$，算法返回 YES。 这对应于单个有效排列周期$(1 \leftrightarrow 2)$，长度为2，满足2整除的要求$k$什么时候$k$是偶数，更一般地，构造参数允许嵌入到与以下兼容的更大的循环结构中$k$。
