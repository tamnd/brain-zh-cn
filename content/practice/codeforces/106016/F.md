 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组。 任务是将元素分成两个非空组，使得每个元素恰好属于一个组。 对于每个组，我们计算其所有元素的按位 AND，并测量这两个 AND 结果之间的绝对差。 目标是选择使这种差异最大化的分割。 

关键的困难在于，组的值对于元素来说不是相加的或局部的，而是通过按位与来依赖于所有元素。 将单个元素添加到组中只能关闭位，而不能打开位，这使得该函数在分区方面高度非线性。 

跨测试用例的输入大小最多达到 10^5 个元素，因此任何尝试所有分区甚至所有子集分配的解决方案都立即不可行。 对所有分割的暴力破解将在 n 中呈指数级增长，甚至迭代所有子集也将涉及 2^n 个状态的数量级，这远远超出了任何实际限制。 这迫使我们寻找一种结构，将每个测试用例的搜索空间减少到线性或近线性。 

当所有数字都相同时，会出现微妙的边缘情况。 在这种情况下，任何分割都会为双方产生相同的 AND 值，因此答案为零。 另一个有趣的情况是，当存在一个元素具有不被其他元素共享的稀有位时，因为隔离它可以极大地改变剩余集合的AND。 例如，如果数组为 [8, 7, 7]，则拆分 8 会得到 AND({8}) = 8 和 AND({7,7}) = 7，产生差值 1，而其他拆分会产生更小的或相等的值。 “平衡分区更好”的天真的直觉在这里可能会失败，因为 AND 的行为与求和相反。 

## 方法

 强力解决方案会将所有可能的元素分配枚举到两个集合中。 对于每个作业，我们计算两边的 AND 并更新答案。 这正确地对问题进行了建模，但它有 2^n 个可能的分区，如果直接完成，每次评估的成本为 O(n)，导致指数爆炸，在 n 达到 10^5 时完全无法使用。 

为了避免这种情况，我们关注按位与的行为。 集合的 AND 由集合中每个元素中存在的位的交集确定。 这意味着每次我们向组中添加一个元素时，我们只能丢失其 AND 值中的位。 这种单调收缩行为是核心结构。 

现在考虑如何最大化两组 AND 之间的差异。 如果一个组包含多个元素，则其 AND 受到该组中最弱的元素的约束。 如果我们将单个元素隔离到它自己的组中，则该组的 AND 恰好成为该元素，这是我们可以分配给包含该索引的组的最大可能值。 同时，另一组成为所有剩余元素的与，这也是定义明确且易于计算的。 

这表明了一种强有力的候选策略：尝试使一组由单个元素组成，而另一组包含所有剩余元素。 每个最优解都可以简化为这样的配置，因为任何多元组只能减少其 AND 值，而不会在其他地方给出补偿自由度。 

为了有效地评估所有此类选择，我们预先计算整个数组的 AND，然后对于每个索引计算除该索引之外的所有元素的 AND。 这可以在线性时间内使用前缀和后缀 AND 数组来完成。 

然后，我们将每个索引 i 的候选差异评估为 |a[i] − AND(all except i)| 并取最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解分区 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 单例分割 + 前缀/后缀 AND | 每个测试用例 O(n) | O(n) | 已接受 |

## 算法演练

 ### 步骤

 1. 在输入数组上计算前缀 AND 和后缀 AND 数组。 

前缀数组存储直到位置 i 的所有元素的 AND，后缀数组存储从位置 i 到末尾的所有元素的 AND。 这使我们能够有效地模拟删除任何单个元素。 
2. 对于每个索引 i，计算除 a[i] 之外的所有元素的 AND 作为 prefix[i-1] AND suffix[i+1]。 

如果我们将元素 i 隔离到它自己的组中，这表示第二组的最佳可能值。 
3. 将元素 i 视为形成单例组，其 AND 恰好是 a[i]。 

这很重要，因为任何仅包含一个元素的组都无法通过 AND 来丢失位。 
4. 计算 a[i] 与剩余元素的 AND 之间的绝对差，并跟踪所有 i 上的最大值。 

每个索引代表一个候选分割，其中一组是最大“尖锐”的，而另一组在排除该元素的约束下尽可能强。 

### 为什么它有效

 正确性依赖于这样一个事实：集合的 AND 仅当集合增长时才会减少。 任何包含至少两个元素的组都有一个小于或等于其中每个单独元素的 AND，因此用包含其中一个元素的单例替换该组只能增加或保留其 AND 值。 同时，将元素移出另一组只能增加其 AND 值，但通过考虑单例的补集已经捕获了该移动。 这意味着每个分区都可以转换为单例与其余分区，而不会降低目标值，因此检查所有此类分区就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        if n == 2:
            # only possible split is 1 vs 1
            print(abs(a[0] - a[1]))
            continue
        
        pref = [0] * n
        suff = [0] * n
        
        pref[0] = a[0]
        for i in range(1, n):
            pref[i] = pref[i - 1] & a[i]
        
        suff[n - 1] = a[n - 1]
        for i in range(n - 2, -1, -1):
            suff[i] = suff[i + 1] & a[i]
        
        ans = 0
        
        for i in range(n):
            left = pref[i - 1] if i > 0 else (1 << 31) - 1
            right = suff[i + 1] if i + 1 < n else (1 << 31) - 1
            other_and = left & right
            ans = max(ans, abs(a[i] - other_and))
        
        print(ans)

if __name__ == "__main__":
    solve()
```该实现以线性传递方式构建前缀和后缀 AND 数组。 唯一微妙的一点是处理边界：当删除第一个或最后一个元素时，补码的一侧不存在，因此我们将中性 AND 值视为所有位集（此处`(1 << 31) - 1`）所以不影响结果。 

每个测试用例都是独立处理的，并且所有计算在数组大小上都是严格线性的。

 ## 边缘情况

 当所有元素都相同时，每个前缀和后缀 AND 都是相同的值，因此隔离任何元素都会在两侧产生相等的 AND。 对于像这样的输入`3 3 3 3`，任意元素的补集仍然是`3`，且差值始终为零。 该算法自然地处理这个问题，因为前缀和后缀数组保持不变，因此每个计算出的差异都会归零。 

当一个元素的位表示显着大于其他元素时，隔离它会产生很大的间隙。 例如，在`[16, 1, 1]`，隔离 16 产生补码 AND 等于`1`, 产生差异`15`，它被单例评估正确捕获。 

当最大值不唯一时，例如`[8, 8, 7]`，隔离 8 或隔离 7 均经过测试。 前缀/后缀结构确保每个案例的评估都是对称的，因此不需要特殊的外壳。
