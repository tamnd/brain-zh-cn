 ## 问题理解

 我们正在建造一系列排列在一条线上的沙柱，从位置 1 开始向右延伸。 每个位置都有一个非负整数高度，该高度表示该位置放置了多少个沙包。 所有沙包都是不可分割的，因此每个单元都只贡献一个位置的高度。 

配置必须满足三个结构规则。 首先，第一位置处的高度不能超过给定限制H，该限制来自栅栏约束。 其次，相邻柱子的高度最多相差1，这迫使整个形状逐渐变化，而不会急剧跳跃。 第三，所有n个沙包必须准确使用，这意味着所有高度的总和是固定的。 

只有具有正高度的位置才算作“已用点”，因此尾随零并不重要，但最后一个非零位置之前的所有内容都重要。 目标是排列沙子，以便在尊重平滑度约束和总和约束的同时最大限度地减少使用位置的数量。 

约束条件非常大，n 和 H 高达 10^18。 这立即排除了任何显式构建或模拟序列的方法。 任何解决方案都必须在每个测试用例的对数或恒定时间内工作，依赖于结构的封闭式推理而不是位置迭代。 

当 H 与 n 相比非常大时，就会出现微妙的边缘情况。 在这种情况下，最好的形状就是像 n, n-1, ..., 1 这样的下降楼梯，答案就会变小。 另一方面，当 H 很小时，我们被迫尽早“限制”高度，然后用高度为 1 的平坦区域扩展序列。尝试从左到右构建的朴素贪婪模拟经常会失败，因为它没有正确考虑在斜率约束下可以将多少总和打包到固定数量的位置中。 

例如，如果 n = 5 且 H = 2，贪婪方法可能会尝试放置 2, 1, 1, 1，这是有效且最佳的 3 个位置。 但如果它错误地尝试从较低的位置开始，例如 1、2、1，则可能会过度使用位置或错误计算可行性，因为它不会对容量进行全局推理。 

## 方法

 直接的强力策略将尝试构造长度递增的所有有效序列 k 并检查它们是否可以在尊重相邻差异约束和初始界限的情况下求和为 n。 对于每个 k，可以尝试通过根据规则 |hi − hi+1| 分配高度来最大化可实现的总和。 ≤ 1 且 h1 ≤ H。然而，即使评估单个 k 也需要模拟最多 k 个位置，并且 k 本身可以与 n 一样大，最大可达 10^18。 这使得暴力破解完全不可行。 

关键的观察是，对于固定长度 k，最佳可能的配置不是任意的。 为了在约束下最大化总和，我们应该始终从允许的最高值开始，每一步减少 1，直到达到 1。在那之后，我们可以将剩余位置的序列保持为 1，因为再次增加会违反早期保持最大累积所需的单调下降结构。 

这将问题简化为容量问题：对于每个 k，我们可以计算可实现的最大总和。 如果我们可以在 O(1) 内计算这个值，那么我们可以二分搜索最小的 k 使得这个最大和至少为 n。 一旦我们知道了这个 k，我们就可以向下调整值以精确匹配 n，因为降低高度永远不会违反差异约束。

 ## 算法演练

1. 确定占据位置的候选数量k，并计算在约束下可以放置的最大沙子总量。 这个想法是检查 k 个位置是否足以容纳所有 n 个沙包。 
2. 构建长度为 k 的最高有效形状。 从位置 1 处的高度 H 开始，然后每一步减少 1，直到达到高度 1。这给出了长度最多为 H 的递减前缀。 
3.如果k小于或等于H，则该序列是严格递减段：H，H−1，...，H−k+1。 总和是部分算术级数，代表不落地的最大包装。 
4. 如果 k 大于 H，则序列首先从 H 下降到 1，消耗 H 个位置。 之后，剩余位置的高度都可以为 1，而不会破坏 |hi − hi+1| ≤ 1 个约束。 这会产生一个线性扩展容量的平台。 
5. 使用适当的封闭形式计算该 k 的可实现总和。 这给出了 k 的单调函数，因为添加位置永远不会减少可实现的最大总和。 
6. 对最小的 k 进行二分查找，使得计算出的最大和至少为 n。 这确保了我们不会使用超过必要的位置，同时仍然能够容纳所有沙子。 
7. 找到k后，构建序列，并从右侧贪婪地减少一些高度，直到总和恰好为n。 从右侧减少可以保持有效性，因为降低值不会使相邻差异增加到超过 1。 

### 为什么它有效

 关键的属性是，对于任何固定长度 k，最大化总和的最佳布置是独特的结构，即有盖的下降楼梯，后面是平尾。 与此形状的任何偏差要么会减少早期的大值，要么会引入不必要的斜率变化，从而减少总和。 因为这个最大可实现的总和在 k 中是单调的，所以二分搜索可以正确识别最小的可行长度，并且可以在不破坏有效性的情况下删除任何多余的容量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_sum(k, H):
    if k <= H:
        # H + (H-1) + ... + (H-k+1)
        return k * (2 * H - k + 1) // 2
    else:
        # full descending to 1, then flat 1s
        return H * (H + 1) // 2 + (k - H)

def solve():
    n, H = map(int, input().split())

    lo, hi = 1, n
    ans = n

    while lo <= hi:
        mid = (lo + hi) // 2
        if max_sum(mid, H) >= n:
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    # construct initial maximal shape
    k = ans
    res = []

    cur = H
    remaining = k
    while remaining > 0 and cur > 0:
        res.append(cur)
        cur -= 1
        remaining -= 1

    if remaining > 0:
        res.extend([1] * remaining)

    # adjust down to exactly n
    total = sum(res)
    i = len(res) - 1
    while total > n:
        dec = min(res[i], total - n)
        res[i] -= dec
        total -= dec
        i -= 1

    # trim trailing zeros
    while res and res[-1] == 0:
        res.pop()

    print(len(res))

if __name__ == "__main__":
    solve()
```二分搜索隔离了可以在最佳填充剖面下支持所有沙包的最小数量的位置。 构造步骤遵循实现该容量的极值形状，最终调整通过安全地降低最右侧的高度来确保精确相等，在最右侧不能违反邻接约束。 

## 工作示例

 考虑样本输入 n = 5，H = 2。函数 max_sum 的行为如下：

 | k | 序列的形式 | 最大总和（k）|
 | --- | --- | --- |
 | 1 | [2] | 2 |
 | 2 | [2,1]| 3 |
 | 3 | [2,1,1]| 4 |
 | 4 | [2,1,1,1] | 5 |

 二分查找将 k = 4 确定为容量达到 5 的第一个长度。构建的序列为 [2,1,1,1]，其和已为 5，占据 4 个位置。 

该迹线表明，一旦结构达到高度 1，用平坦结构延伸会线性增加容量，这就是为什么在 k > H 后函数变为分段线性的原因。 

再举个例子，取 n = 10，H = 3。 

对于 k = 3，max_sum 为 3 + 2 + 1 = 6。 

对于 k = 4，max_sum 为 6 + 1 = 7。 

对于 k = 7，max_sum 为 6 + 4 = 10。 

所以答案变成7，对应[3,2,1,1,1,1,1]。 这证实了 H 处的转变点以及平台如何主导随后的增长。

 ## 边缘情况

 当H大于或等于n时，最优结构永远不会到达平坦区域。 该序列变成纯粹的下降楼梯，并且答案折叠到最小的 k，使得 k(k+1)/2 ≥ n。 该算法会自动处理此问题，因为容量函数的 k ≤ H 分支在整个二分搜索过程中保持活动状态。 

当 H 非常小时，尤其是 H = 1 时，结构退化为平坦的 1 序列。 在这种情况下 max_sum(k) = k，因此二分查找立即返回 k = n。 构造步骤产生了一个统一的数组，它基本上满足了邻接约束。 

当 n 略大于 H(H+1)/2 时，溶液进入稳定状态。 二分搜索识别出刚好超出 H 的 k，并且构造的序列变成一个完整的三角形，后面跟着一个短的平尾。 这是最敏感的转变点，正确性依赖于 max_sum 的两个公式体系之间的精确分离。
