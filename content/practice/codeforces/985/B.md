 ## 解决方案
 ## 问题理解

 我们有一组开关，每个开关控制一部分灯。 当按下开关时，与其连接的每个灯都会永久打开。 一旦灯打开，它就不会再关闭，即使稍后按下影响它的其他开关也是如此。 

如果我们按下所有开关，则保证每盏灯都会点亮。 任务是确定是否存在一个我们可以安全忽略的开关，同时仍然确保按下所有剩余的开关仍然会打开每个灯。 

另一种看待问题的方式是，每个开关贡献一组灯，所有组的并集覆盖所有灯。 我们想知道删除一组是否仍然会使并集保持不变。 

这些限制允许最多 2000 个开关和 2000 个灯，这使得大约 400 万次操作的二次或稍差的解决方案是可以接受的。 矩阵结构上的任何立方都会太慢，但与 n 乘以 m 成比例的运算就可以了。 

当一盏灯恰好被一个开关覆盖时，就会出现一种微妙的边缘情况。 在这种情况下，移除该开关将导致该灯无法点亮。 例如，如果灯 j 仅连接到开关 i，则开关 i 是必需的。 任何正确的解决方案都必须隐式或显式地检测此类唯一性条件。 

当多个开关冗余地覆盖所有灯时，会出现另一种边缘情况。 例如，如果每个灯都连接到所有开关，则移除任何单个开关仍然会使所有灯点亮。 一种简单的方法可能会使这一过程变得过于复杂，但仍然可以通过，但重要的是要认识到所有灯的冗余是正在测试的核心结构。 

## 方法

 一种直接的做法是模拟逐一移除每个开关的效果。 对于固定开关 i，我们将使用所有其他开关重新计算哪些灯保持点亮，并检查所有灯是否仍然被覆盖。 如果我们每次都从头开始重新计算覆盖率，我们就会重复扫描整个矩阵。 

这种强力方法检查 n 个候选，并为每个候选重新计算 n 个开关和 m 个灯的覆盖范围。 这导致 O(n^2 m) 次操作。 当 n 和 m 达到 2000 时，这会达到大约 8 × 10^9 次操作，这太慢了。 

关键的观察是我们实际上不需要重新计算所有内容。 拆除开关时唯一重要的是是否存在至少一盏灯未被覆盖。 对于灯 j，唯一危险的情况是所有点亮 j 的开关都包括被移除的开关。 同样，对于每个灯j，我们只需要知道有多少个开关覆盖它即可。 如果灯至少被遮盖两次，移除任何一个遮盖开关都不会将其关闭。 

这将问题简化为简单的计数结构。 对于每个灯，计算有多少个开关激活它。 然后，对于每个开关，验证它是否是任何灯的唯一提供者。 如果开关是某些灯的唯一提供者，则无法将其移除。 否则，就安全了。 

我们可以通过预先计算覆盖率计数然后再次扫描来有效地检查这一点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力重新计算| O(n^2 m) | O(n^2 m) | O(纳米) | 太慢了|
 | 计算每盏灯的覆盖范围| O(纳米) | O(米) | 已接受 |

 ## 算法演练

1. 阅读描述哪些开关激活哪些灯的输入矩阵。 该结构定义了开关和灯之间的二分关系。 
2. 对于每个灯，计算有多少个开关可以打开它。 这在灯上提供了捕获冗余的频率阵列。 这样做有用的原因是，只有当冗余恰好为 1 时，删除才是危险的。 
3. 对于每个开关，检查其激活的所有灯。 如果任何此类灯的总计数为 1，则将该开关标记为必需开关。 原因是，如果移除此开关，这样的灯就会熄灭。 
4. 如果我们发现至少一个不是必需的开关，我们可以安全地忽略它并仍然保持所有灯亮着。 输出“是”。 
5. 如果每个开关都是必需的，则每个开关都需要至少一个唯一支持的灯。 在这种情况下，输出“NO”。 

### 为什么它有效

 正确性取决于对失败的简单描述。 当且仅当没有灯完全依赖于开关时，开关才是可拆卸的。 全局条件“移除开关后所有灯保持点亮”分解为每个灯的独立检查，因为灯激活是单调的并且与开关相加。 由于每个灯只需要至少一个活动的邻居，因此当没有灯失去其最后一个支撑边缘时，失去开关是无害的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    mat = [input().strip() for _ in range(n)]
    
    cnt = [0] * m
    
    for i in range(n):
        row = mat[i]
        for j in range(m):
            if row[j] == '1':
                cnt[j] += 1
    
    for i in range(n):
        row = mat[i]
        ok = True
        for j in range(m):
            if row[j] == '1' and cnt[j] == 1:
                ok = False
                break
        if ok:
            print("YES")
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
```第一遍在灯上构建频率阵列。 这是关键的预处理步骤，它将所有开关交互分解为简单的计数。 

第二遍独立评估每个开关。 内循环检查开关是否负责任何唯一覆盖的灯。 早期中断很重要，因为一旦发现单个唯一依赖项，切换将立即被取消资格。 

将矩阵存储为字符串的决定避免了重复的解析开销，并使内存使用量保持在最低限度。

 ## 边缘情况

 关键的边缘情况是每盏灯都只有一个支持开关。 例如：```
2 2
10
01
```这里每个开关唯一负责一盏灯。 该算法将两个开关标记为必需开关，因为每个开关都覆盖了计数为 1 的灯。这正确地导致“否”。 

另一种边缘情况是开关没有唯一的职责，即使它覆盖了许多灯。 例如：```
3 3
111
111
111
```每个灯的计数为 3，因此任何开关都不会被取消资格。 该算法正确地识别出可以移除任何开关。 

带有一个开关的最小外壳：```
1 3
111
```所有灯的计数均为 1，因此单个开关至关重要，并且无法拆卸。 算法输出NO，符合要求。
