 ## 解决方案
 ## 问题理解

 我们被要求计算所有整数的总和$x$满足关于两个给定整数的一对模条件$a$和$b$。 具体来说，一个正整数$x$如果存在一些则被认为是好的$k$介于 1 和$a$这样划分$x$经过$k$产生余数$b$。 换句话说，$x$模数$k$必须等于$b$。 目标是将所有这些整数相加并返回结果模$10^9 + 7$。 

输入由两个数字组成，$a$和$b$，其中每一个都可以达到$10^7$。 自从$a$可以大到$10^7$，一种蛮力方法，检查所有数字直到$a \cdot b$或更高可能涉及数万亿次操作，这远远超出了 2 秒的时间限制。 因此，解决方案必须避免迭代每个候选者$x$单独。 

当发生微妙的边缘情况时$b$大于$a$。 对于小$a$和一个大$b$，没有整数满足条件，因为余数必须始终小于除数。 例如，如果$a = 1$和$b = 2$，没有整数$x$这样$x \mod 1 = 2$，正确的输出为 0。正确处理这一点至关重要，因为简单的实现可能会尝试不可能的除法。 

## 方法

 暴力解决方案将迭代所有可能的解决方案$k$从 1 到$a$，并且对于每个$k$迭代所有$x$开始于$b$直到足够大的界限，增加$k$并检查$x \mod k = b$。 虽然这在逻辑上是正确的，但迭代次数将会爆炸$a = 10^7$，大致产生$O(a \cdot (b/k))$不可行的操作。 

关键的见解是从模算术中识别出一种模式：所有$x$满足$x \mod k = b$形成一个算术级数，起始于$b$并增加了$k$。 我们可以将这样的序列求和$O(1)$一旦我们确定了符合约束的第一个和最后一个元素，就可以使用算术级数公式来计算时间。 此外，最大值$x$可以认为是有界的$a \cdot (b+1)$，我们可以利用整数除法属性对范围进行分组，其中商$x/k$保持不变，使我们能够避免迭代每个$x$单独。 这改变了潜在的$O(a^2)$问题转化为$O(\sqrt{a+b})$通过迭代间隔来解决问题$x$高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(a*b) | O(1) | O(1) | 太慢了 |
 | 最佳| O(√(a+b)) | O(√(a+b)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.首先检查是否$b$超过$a$。 如果是这样，则不存在好的整数，因为余数不能大于除数，我们可以立即返回 0。 
2. 迭代所有可能的整数值$q = \lfloor x / k \rfloor$。 每个值$q$定义一个连续的区间$k$满足的值$x = k \cdot q + b$。 自从$k \le a$和$k > b$（否则$x \mod k = b$是不可能的），计算相应的最小值和最大值$x$对于每个$q$将间隔界限乘以$q$并添加$b$。 
3. 对于每个间隔$x$共享相同商的值$q$，直接使用连续整数之和的公式对算术级数求和：$sum = n \cdot (first + last)/2$。 注意应用模数$10^9 + 7$每一步都避免溢出。 
4. 继续，直到所有间隔都满足$k \le a$已经筋疲力尽了。 该算法依赖于不同商数的观察$q$为了$x/k$的边界是$O(\sqrt{a+b})$因为每个商都会生成一个可能的递减序列$k$价值观。 
5. 输出总和模数$10^9 + 7$。 

为什么它有效：每个整数$x$满足$x \mod k = b$对于某些人来说$1 \le k \le a$恰好属于一个由其商定义的算术级数$q = x // k$。 通过迭代可能的商并有效计算每个区间的总和，我们捕获了所有有效的商$x$恰好一次，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def main():
    a, b = map(int, input().split())
    if b > a:
        print(0)
        return

    result = 0
    k = b + 1
    while k <= a:
        q = (a - b) // k
        max_k = (a - b) // q if q > 0 else a
        count = max_k - k + 1
        total = ((k + max_k) * count // 2) % MOD
        result = (result + total * q + count * b) % MOD
        k = max_k + 1

    print(result)

if __name__ == "__main__":
    main()
```该解决方案首先处理边缘情况$b > a$，立即返回0。 主循环有效地计算范围的总和$k$产生相同的商$q$，使用算术级数公式。 采用模运算来防止溢出。 变量`k`每次迭代后前进到下一个未处理的范围。 

## 工作示例

 用于输入`1 1`,`b`等于`a`，所以算法打印 0。不存在好的整数，因为$x \mod k = 1$是不可能的，当$k = 1$。 

用于输入`5 2`，初始的`k`从 3 开始。为每个间隔计算商，产生如下序列`x = 3*1 + 2 = 5`,`x = 4*1 + 2 = 6`等。每个算术级数和都与结果模相加$10^9 + 7$。 最终的总和变为 14，与预期答案相符。
