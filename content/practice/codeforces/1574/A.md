 ## 解决方案
 ## 问题理解

 我们被要求生成有效的括号序列，这些序列是仅由“(”和“)”组成的字符串，形成平衡的括号。 如果每个左括号都有相应的右括号并且在其匹配的左括号之前没有出现右括号，则序列有效。 输入给我们一个数字$n$，并且我们必须准确输出$n$不同长度的序列$2n$。 每个序列必须不同，但序列可以在不同的测试用例中重复。 

限制是适度的：$n$最多 50 个，并且最多可以有 50 个测试用例。 长度序列$2n = 100$足够小，我们可以直接生成序列而不用担心效率。 这意味着我们不需要复杂的组合生成算法或动态编程来计数序列； 简单的构造就足够了。 

一个微妙的点是，对于相同的序列，序列必须是不同的$n$。 打印相同平衡序列的简单解决方案$n$时间会不正确。 例如，如果$n = 3$，打印三份`"((()))"`会失败的。 我们需要一种系统的方法来生成保证不同但仍然有效的多个序列。 

边缘情况包括$n = 1$，其中唯一有效的序列是`"()"`。 对于小$n$，很容易忽略序列应该都是不同的，并且粗心的字符串连接可能会产生重复或不正确的嵌套序列。 

## 方法

 暴力方法将尝试生成所有可能的长度的括号序列$2n$并过滤掉无效的。 序列数量呈指数增长$n$作为$2^{2n}$。 检查每个序列的有效性需要扫描字符串并维护平衡计数器。 这对于非常小的情况是可行的$n$，但是当$n$是 50 因为$2^{100}$序列远远超出了任何程序的处理能力。 

最佳方法利用有效序列的结构。 长度平衡的括号序列$2n$可以通过嵌套或连接较小的平衡序列来构造。 一种系统化的生成方式$n$不同的序列是为了改变嵌套的程度。 从最简单的顺序开始`"()()()...()"`的$n$对。 然后从头开始逐步嵌套，产生`"((...))()"`,`"((...))()"`一对内部的移位，依此类推。 这保证了每个序列都是不同的，因为嵌套括号的位置不同，并且所有序列仍然有效，因为嵌套可以保持平衡。 

这种方法是线性的$n$对于每个测试用例，它准确地产生$n$根据需要进行序列。 它避免生成所有组合，仅关注受控构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(2n) * n) | O(2^(2n) * n) | O(2^(2n) * n) | O(2^(2n) * n) | 太慢了 |
 | 建设性嵌套 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$。 
2. 初始化一个空列表来保存$n$此测试用例的序列。 
3.为了$i$从 1 到$n$，构造一个序列如下。 地方$i$左括号`"("`一开始，然后$i$右括号`")"`关闭它们。 对于剩余的$n-i$对，将它们附加为`"()"`为了。 这确保了每个序列都有准确的$2n$人物。 
4. 将每个构造的序列附加到输出列表。 
5. 按顺序打印每个测试用例的序列。 

为什么它有效：第一个$i$对是嵌套的，其余对是平的。 每个值$i$产生不同的嵌套模式，因此序列是不同的。 嵌套可确保每个左括号都有一个匹配的右括号，并且永远不会出现在右括号之后，从而保留有效性不变式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def generate_sequences(n):
    sequences = []
    for i in range(1, n+1):
        seq = '(' * i + ')' * i + '()' * (n - i)
        sequences.append(seq)
    return sequences

t = int(input())
for _ in range(t):
    n = int(input())
    result = generate_sequences(n)
    for seq in result:
        print(seq)
```这`generate_sequences`功能封装了核心建设思想。 对于每个序列，开始时的嵌套对数量从 1 增长到$n$。 剩余的对添加为平的`"()"`序列。 这可以避免嵌套时出现相差一的错误，并保证序列是不同的。 使用字符串乘法简化了重复的创建`"("`或者`")"`字符，减少出错的机会。 快速输入确保读取多个测试用例的效率。 

## 工作示例

 对于$n = 3$，生成的序列为：

 | 我| 序列 |
 | --- | --- |
 | 1 |`()()()`|
 | 2 |`(()())`|
 | 3 |`((()))`|

 一步一步，对于 i = 2：我们放置两个左括号`"((`”，然后两个关闭`"))"`，剩下一对，我们将其添加为`"()"`。 结果是`"(()())"`。 每个序列都有长度$2*3 = 6$并且是平衡的。 

为了$n = 1$:

 | 我| 序列 |
 | --- | --- |
 | 1 |`()`|

 这个边缘情况证实了最小值$n$产生长度为 2 的有效序列。

 ## 边缘情况

 对于 n = 1，唯一有效的序列是`"()"`。 该算法通过构造准确地生成该序列。 

对于较大的 n，请考虑 n = 3。从 1 到 3 的每个 i 都会生成不同的序列。 i = 1 的序列是完全平坦的，i = 2 有一对嵌套，i = 3 是完全嵌套的。 该结构确保没有两个序列是相同的并且所有序列都是有效的。 这表明该方法可以正确处理最小和中等小的 n。
