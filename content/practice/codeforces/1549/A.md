 ## 解决方案
 ## 问题理解

 给定一个素数$P$，对于每个测试用例，我们必须输出两个整数$a$和$b$使得两者都位于 2 和$P$， 和$a < b$，以及除法时的余数$P$经过$a$并由$b$是平等的。 

更具体地说，我们正在寻找两个不同的除数，当用于除以相同的素数时，它们会留下相同的“剩余量”。 我们不需要找到所有这样的对，每个测试用例只需要找到一对有效的对。 

这些约束在价值上很大，但在结构上却很小。 测试用例数量最多为1000个，每个测试用例$P$可以大到$10^9$。 这立即排除了任何尝试搜索所有对的方法$(a, b)$甚至尝试所有值$a$并重复计算余数。 每个测试用例都不需要进行二次甚至线性扫描，但理论上仍然可行； 然而，真正的限制是我们希望每个测试用例都有一个恒定时间的构造。 

微妙的边缘情况是允许的最小素数$P = 5$。 任何建筑仍必须尊重$2 \le a < b \le P$。 天真的尝试选择类似的东西$(P-2, P-1)$如果不仔细检查，对于小值可能会失败，因为排序和余数相等可能不适用于任意模式。 

## 方法

 暴力方法会尝试所有对$(a, b)$和$2 \le a < b \le P$并检查是否$P \bmod a = P \bmod b$。 这是正确的，因为它直接强制执行条件。 然而，它粗略地检查$O(P^2)$成对，当$P$取决于$10^9$。 即使限制为单个测试用例也会使这变得不可行。 

更结构化的观察来自于理解条件的实际含义。 如果两个模除同一个数时产生相同的余数，则该数可以表示为以下形式$P = k a + r = \ell b + r$对于一些共享的剩余部分$r$。 关键的简化是我们根本不需要控制其余部分； 我们只需要它匹配即可。 

诀窍是故意强制使用简单的、共享的余数。 对于任意奇素数$P$，选择$a = 2$使$P \bmod 2 = 1$。 如果我们能找到另一个$b$这样$P \bmod b = 1$，我们完成了。 最简单的选择是$b = P - 1$，因为划分$P$经过$P - 1$总是留下余数 1。 

这将问题简化为每个测试用例的恒定时间构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(P^2)$|$O(1)$| 太慢了|
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取素数$P$。 我们独立处理每个测试用例，因为用例之间没有交互。 
2.修复$a = 2$。 这是最小的有效选择，并保证任何奇素数的可预测余数模式。 
3. 设置$b = P - 1$。 这一选择确保了$b$始终在范围内并且严格大于 2$P \ge 5$。 
4. 输出$a$和$b$。 

这种构造有效的原因来自于除法的算术属性。 自从$P$是大于 2 的奇素数，除以 2 总是留下余数 1。另一方面，除$P$经过$P - 1$总是产生商 1 和余数 1，因为$P = 1 \cdot (P - 1) + 1$。 这保证了所需的余数相等。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        p = int(input())
        print(2, p - 1)

if __name__ == "__main__":
    main()
```实施是直接的，因为每个测试用例的构建时间是恒定的。 不需要循环、搜索或素性检查，因为输入保证$P$是素数。 

唯一的微妙之处是确保$p - 1$始终有效。 自从$P \ge 5$，我们总是有$p - 1 \ge 4$，因此它安全地超过 2 并保持$a < b$。

 两个余数都匹配，因此该对有效。 

这证实了该构造并不依赖于 17 的特殊性质，仅依赖于除法的结构。

 输入：```

```我们再次使用$a = 2$,$b = 4$。 

| 步骤| 一个 | 乙| P 模 a | P 模 b |
 | --- | --- | --- | --- | --- |

 即使在最小的有效输入大小下，该结构也成立，因为 5 除以 2 和除以 4 都会留下余数 1。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        p = int(input())
        out.append(f"{2} {p-1}")
    return "\n".join(out) + "\n"

 ## 边缘情况

 最重要的边缘情况是最小素数$P = 5$。 在这种情况下，唯一有效的构造仍然必须满足严格的不等式。 该算法产生$(2, 4)$，直接检查发现余数均等于1，因此无需任何特殊处理即可满足约束。 

另一个隐式边缘情况是任何接近的大素数$10^9$。 即使在那里，$P - 1$仍然有效且与 2 不同，因此构造不会因溢出或排序问题而中断。
