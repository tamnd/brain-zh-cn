 ## 解决方案
 ## 问题理解

 我们给出了一个尺寸为的环形网格$2^k \times 2^k$，其中每个单元包含一个 60 位整数。 网格在水平和垂直方向上都环绕，因此越过边缘会使我们回到相反的一侧。 除了这个网格之外，我们还得到了一个固定的模式$F$，这只是一组$t$标记的细胞，与$t$很奇怪。 

一个操作包括将此图案放置在圆环上的任意位置，选择一个值$p$和异或运算$p$进入图案覆盖的每个单元格。 因为模式只是被翻译，所以每个操作都会准确地影响$t$细胞，处于固定的相对配置。 

任务是确定我们是否可以使用这样的操作将整个网格转换为全零，如果可以，找到最少的操作数。 

约束的维度很小（$k \le 9$，所以至多$512 \times 512$），但值很大，高达$2^{60}$。 这强烈表明 GF(2) 上的按位线性代数，但应用于环面上的结构化卷积式设置。 

重要的结构约束是操作是固定掩码的转换。 这立即暗示了该组的卷积$(\mathbb{Z}_{2^k} \times \mathbb{Z}_{2^k})$。 

一种幼稚的方法会尝试贪婪地或直接模拟操作，但单个操作以相关方式影响许多单元格，并且可能的放置数量为$4^k \le 2^{18}$，因此枚举布局之间的交互已经很大，但与 XOR 值选择结合使用时仍然不够。 

当假设局部独立时，幼稚思维的一个微妙的失败案例就会出现。 例如，如果尝试逐行修复单元格，很快就会破坏环形依赖性：

 想法示例：```
1 1
1 1
```将 2 单元格图案放置在不同的班次中。 贪婪行消除会失败，因为每个操作同时更改多个行和列。 

关键的困难在于运算在 GF(2) 上形成线性空间，但受到卷积结构的约束。 

## 方法

 每个操作选择一个班次$(x, y)$和一个值$p$、和异或$p$到翻译副本的所有单元格中$F$。 因为 XOR 是线性的，所以整个系统可以看作是 GF(2) 上的线性方程组，分别针对每一位$p$。 由于位不相互作用，我们可以将问题视为$60$独立的二元问题。 

修复一个位。 每个单元格要么是 0，要么是 1。每个操作都会添加一个转换后的大小掩码$t$，因此每个操作对应于在向量空间中添加一个向量到由网格位置索引的 GF(2) 上。 每次运算的系数是所选的位$p$。 

因此，我们需要将初始网格表示为所有翻译副本的线性组合$F$，并且我们希望最小化所选翻译的数量。 

这是阿贝尔群上的卷积基础问题。 关键的观察是所有翻译的集合$F$形成循环结构，因此卷积在 2D Walsh-Hadamard 变换（也称为网格组上的 XOR-Fourier 变换）下进行对角化。 

在该变换中，卷积变成了逐点乘法。 每个频率变成一个独立的线性方程：对于每个频率$\omega$，所有转变的贡献通过以下变换来缩放$F$在$\omega$。 自从$t$是奇数，变换永远不会同时在所有频率上消失，这保证了可解性所需的可逆条件。 

我们将问题简化为决定是否可以使用有限数量的“原子”（操作）来表示变换后的网格值，并最小化非零选择的移位系数的数量。 这变成了按频率优化，减少了变换空间中反转后对非零系数的计数。 

FFT 结束$\mathbb{Z}_2^k \times \mathbb{Z}_2^k$是二维 Walsh-Hadamard 变换，运行于$O(n \log n)$和$n = 2^{2k}$。

 ## 算法演练

 我们一点一点地工作，因为异或是线性的。 

1. 提取所有网格值的一位位置，生成二进制网格$A$。 稍后我们将对所有位的结果求和，但每个位都是独立的，因此我们单独求解它们。 这是必要的，因为每个操作都会在整个模式中贡献统一的位值。 
2.构建二元网格$F$of the same size, where cells in the pattern are 1 and others are 0. Since only translations are allowed, every operation corresponds to shifting this mask.
 3. 计算两者的 2D Walsh-Hadamard 变换$A$和$F$。 该变换将环面移位上的卷积转换为跨频率空间的点乘法。 
4. 对于每个频率单元$(u,v)$，除以变换后的值$A$通过转换后的值$F$在GF(2)中。 由于我们已经了解了位，除法对应于检查一致性：如果$F(u,v)=0$尽管$A(u,v)=1$，则不存在解。 这是一个直接障碍，因为任何转变都无法产生该频率。 
5. 如果可解，计算逆变换以获得系数网格$C$，其中每个单元格代表我们应该应用相应移位的次数（mod 2 是为了可行性，但整数计数对于最小化很重要）。 
6. 答案是位置的数量$C$是非零的，对所有位求和。 每个这样的位置对应于执行一个操作$p$设置了该位。 

### 为什么它有效

 所有翻译副本的集合$F$形成环面群上卷积下的闭合基。 沃尔什-哈达玛变换对角化该作用，将移位之间的全局依赖性转变为每个频率的独立标量方程。 因为$t$奇怪的是，基本模式在 GF(2) 可逆性所需的意义上在频率空间中具有完全支持，防止简并湮灭，否则会使某些网格组件无法到达。 因此，重建步骤相当于求解对角线性系统，并且非零逆系数的数量恰好对应于所需的独立移位激活的最小数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def fwht(a):
    n = len(a)
    step = 1
    while step < n:
        for i in range(0, n, step * 2):
            for j in range(step):
                u = a[i + j]
                v = a[i + j + step]
                a[i + j] = u + v
                a[i + j + step] = u - v
        step <<= 1

def solve_bit(grid, pattern, n):
    A = grid[:]
    F = pattern[:]

    fwht(A)
    fwht(F)

    m = len(A)
    res = [0] * m

    for i in range(m):
        if F[i] == 0:
            if A[i] != 0:
                return None
            res[i] = 0
        else:
            res[i] = A[i] // F[i]

    fwht(res)

    for i in range(m):
        if res[i] % 2 != 0:
            res[i] = 1
        else:
            res[i] = 0

    return sum(res)

def main():
    k = int(input())
    n = 1 << k
    g = n * n

    grid = [[0] * g for _ in range(60)]

    for i in range(n):
        row = list(map(int, input().split()))
        for j in range(n):
            val = row[j]
            for b in range(60):
                grid[b][i * n + j] = (val >> b) & 1

    t = int(input())
    pattern = [0] * g
    for _ in range(t):
        x, y = map(int, input().split())
        pattern[(x - 1) * n + (y - 1)] = 1

    ans = 0
    for b in range(60):
        cnt = solve_bit(grid[b], pattern, n)
        if cnt is None:
            print(-1)
            return
        ans += cnt

    print(ans)

if __name__ == "__main__":
    main()
```网格被展平为一维数组，以便二维环面移位成为大小为阿贝尔群的循环移位$n^2$。 每个位层都是独立处理的。 

FWHT 实现执行 XOR 卷积的标准蝶形运算。 正向变换应用于网格和图案，然后我们在频率空间中逐点求解。 

划分步骤按频率执行，并且当所需频率超出模式变换的范围时检测到不可行性。 

重建系数后，逆变换恢复移位贡献，奇偶校验提取给出每比特所需的最少操作数。

 ## 边缘情况

 当模式变换在频率空间中具有零时，就会出现临界边缘情况。 在这种情况下，任何在该频率上具有非零投影的网格组件都变得不可能构建。 该算法在除法步骤中检测到这一点，其中与零模式值配对的非零变换网格值立即触发拒绝。 

另一种情况是当图案密集但结构化时，例如除了一个单元格之外的完整网格。 尽管它几乎是均匀的，但由于奇数基数，其变换仍然保证可逆性，并且该算法重建有效的系数分布，在逆变换后产生一组稀疏的所需移位。
