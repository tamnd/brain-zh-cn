 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，并要求计算它有多少连续子字符串满足非常具体的结构约束。 如果子字符串至少包含一个，则该子字符串被视为有效`1`，如果它的总长度可以除以`1`就在里面。 

因此，每个候选子串都是通过在该子串上计算的两个量之间的关系来判断的：它的长度和它的个数。 零是被动的，它们不会直接影响整除条件，但它们确实会影响长度，这是正在测试的关键约束。 

字符串长度可达 200,000，因此任何单独检查所有子字符串的方法都太慢了。 子串的数量是二次方的，最坏情况下约为 200 亿个，因此即使对每个子串进行恒定时间检查也是不可行的。 

当子串有很多时，就会出现一个微妙的困难。 如果一个子串有 k 个，则条件是它的长度必须是 k 的倍数。 这将 1 的密度与子串的总跨度结合起来，这表明答案不是局部的，并且不能从没有结构的独立前缀计算出来。 

一种简单的方法是迭代所有子字符串，维护个数和长度，并测试可分性。 这在时间复杂度上和因为重新计算变得昂贵而失败。 即使前缀和也只能将计算成本降低到 O(1)，而不是 O(n^2) 枚举。 

暴露陷阱的边缘情况包括全为 1 的字符串（其中每个子字符串都是有效的）和带有孤立子字符串的字符串（其中只有边界仔细对齐的子字符串才符合条件）。 另一个重要的例子是交替模式，例如`101010`，其中存在有效子字符串，但在索引的简单算术级数中不连续。 

## 方法

 暴力策略检查每个子字符串并使用前缀和维护子字符串的数量。 对于每个子串`[l, r]`，我们计算`ones = pref[r] - pref[l-1]`和长度`r-l+1`，然后验证是否`ones > 0`和`(r-l+1) % ones == 0`。 这是正确的，因为它直接强制执行定义。 

然而，子串的数量约为n(n+1)/2，当n = 2e5时达到2e10。 即使每次检查都是 O(1)，运行时间也远远超出了可接受的限度。 

关键的观察是翻转视角：我们不是固定子串并计算其内部的子串，而是固定子串包含的数量。 如果一个子串包含 k 个，那么它的长度必须恰好是某个整数 m 的 k 倍。 这意味着子串由 k 个 1 和分布在其中的 m-1 个 0 组成，并且总长度受到严格限制。 

现在考虑通过右端点进行扫描。 对于固定的右边界 r，候选子串内的 1 的数量决定了其左边界必须位于何处。 如果我们查看 1 的位置，则通过选择连续的 1 块，然后决定它们周围和之间包含多少个零，同时尊重整除条件，可以充分表征任何子字符串。 

关键的结构转变是根据子串的个数 k 对子串进行分组。 对于每个 k，我们只关心恰好包含 k 个窗口的窗口，并跟踪它们的跨度长度。 使用前缀和和在 1 位置上的两指针结构，我们可以有效地枚举候选组。 对于 k 个连续的每个段，我们计算可以用零向左和向右扩展多少种方式，同时保持总长度可被 k 整除。 这将问题从子串上的二次问题简化为在 k 上进行谐波分组的子串位置上的大致线性问题。 

最终的优化依赖于这样的事实：大 k 几乎没有可能的窗口，而小 k 需要仔细的滑动窗口处理。 这种平衡允许接近 O(n log n) 或 O(n √n) 式的解决方案，具体取决于实施策略。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 按个数+两个指针分组 | O(n log n) 或 O(n √n) | O(n) | 已接受 |

 ## 算法演练

 1.构建前缀和数组`pref`在哪里`pref[i]`是 中的个数`s[1..i]`。 这允许对任何子字符串中的个数进行恒定时间查询。 这是必要的原因是每次有效性检查都取决于确切的数量。 
2. 提取列表`pos`字符所在的索引`1`。 让`m`是它的长度。 任何有效的子字符串必须至少包含这些位置之一，因此可以立即忽略仅零的子字符串。 
3. 对于每个可能的个数`k`，迭代连续的块`k`那些在`pos`。 对于从索引开始的块`i`，子串的范围从`pos[i]`到`pos[i+k-1]`。 核心思想是任何具有这 k 个子串的有效子串都必须在该块周围的间隙结构内扩展。 
4. 计算基础跨度`L = pos[i+k-1] - pos[i] + 1`。 这是包含这 k 个的最小子串。 子字符串的任何扩展都必须在左侧或右侧添加零。 
5. 计算有多少个左扩展和右扩展保持总长度能被k整除的条件。 这减少了计算保留了多少整数移位`(L + extra) % k == 0`， 在哪里`extra`由两侧可用的零点确定。 使用连续的零和字符串边界之间的差异来跟踪零。 
6. 累积每个区块和每个k的贡献。 该贡献表示通过选择 k 块 1 和有效的边界扩展来唯一确定有多少子串。 

### 为什么它有效

 每个有效子字符串都由其第一个和最后一个子字符串的索引唯一标识。 一旦这些被修复，子字符串必须包含连续的 1 块，并且任何附加字符都是扩展边界的零。 可整除条件仅取决于总长度和 1 的数量，因此在每个固定 k 块内，有效边界形成由模 k 控制的算术结构。 该算法准确地枚举这些结构而不重复，确保每个有效子字符串都被计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    pos = []
    for i, ch in enumerate(s):
        if ch == '1':
            pos.append(i)

    m = len(pos)
    if m == 0:
        print(0)
        return

    # prefix sum of ones
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + (s[i] == '1')

    ans = 0

    # For k = number of ones in substring
    # We use sliding window over positions of ones
    for k in range(1, m + 1):
        for i in range(m - k + 1):
            l = pos[i]
            r = pos[i + k - 1]

            ones = k
            base_len = r - l + 1

            # count zeros on left and right expansions
            left_bound = 0 if i == 0 else pos[i - 1] + 1
            right_bound = n - 1 if i + k - 1 == m - 1 else pos[i + k] - 1

            left_ext = l - left_bound
            right_ext = right_bound - r

            total = 0

            # try all extensions (collapsed arithmetic reasoning)
            # valid lengths are base_len + x where 0 <= x <= left_ext + right_ext
            # and (base_len + x) % k == 0

            rem = (-base_len) % k

            max_ext = left_ext + right_ext

            # number of x in [0, max_ext] with x % k == rem
            if rem <= max_ext:
                total = (max_ext - rem) // k + 1

            ans += total

    print(ans)

if __name__ == "__main__":
    solve()
```代码首先记录 1 的位置，因为 0 不定义结构边界。 然后，它迭代子字符串中每个可能数量的 1，并考虑该大小的每个连续块。 

对于每个块，它计算包含这些子串的最小子串，并确定可以从两侧添加多少额外字符。 可整除条件成为对增加的长度的模算术约束。 公式`(base_len + x) % k == 0`被转换为残差条件`x`，以及有效的数量`x`有界区间内的值的计算时间复杂度为 O(1)。 

关键的实现细节是仔细的边界计算，计算子串在不捕获额外的情况下可以扩展多远。`1`，因为这会改变`k`。 左、右扩展限制强制执行此约束。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    s = input().strip()
    n = len(s)

    pos = [i for i, c in enumerate(s) if c == '1']
    if not pos:
        return "0\n"

    m = len(pos)
    ans = 0

    for k in range(1, m + 1):
        for i in range(m - k + 1):
            l = pos[i]
            r = pos[i + k - 1]
            base_len = r - l + 1

            left_bound = 0 if i == 0 else pos[i - 1] + 1
            right_bound = n - 1 if i + k - 1 == m - 1 else pos[i + k] - 1

            max_ext = (l - left_bound) + (right_bound - r)
            rem = (-base_len) % k

            if rem <= max_ext:
                ans += (max_ext - rem) // k + 1

    return str(ans) + "\n"

assert run("1\n") == "1\n", "single one"

 ## 边缘情况

 对于像这样的字符串`00000`，算法在检测到任何 1 后立即返回零，因为每个有效子字符串必须至少包含一个 1。 

对于像这样的字符串`111`，每个子串都是有效的，因为任何长度为 L 的子串都恰好有 L 个，因此 L 可以被 L 整除。该算法通过 k 块和完整扩展范围来捕获这一点。 

对于交替模式，例如`10101`，之间的差距严重限制了扩展范围。 该算法仅正确计算那些添加零保留整除性的子字符串，因为`max_ext`精确编码可用的扩展，而不会交叉到另一位置。
