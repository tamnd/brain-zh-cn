 ## 解决方案
 ## 问题理解

 我们得到一排石头，每块石头都漆成三种颜色。 目标是移除尽可能少的石头，以便移除后不会有两块相邻的石头具有相同的颜色。 

换句话说，我们想要获取原始字符串并删除字符，直到剩余的每对连续字符都不同。 剩余棋子的顺序必须保持不变，因此我们不会重新排序，只是删除元素。 

输入的尺寸很小，最多 50 个石子。 这意味着即使是简单的线性扫描或更昂贵的推理也可以在时间限制内顺利进行。 任何达到二次复杂度的解决方案在这里实际上都是瞬时的，但问题的结构表明存在更简单的东西。 

这里的一个天真的错误是考虑重新排列或计算频率。 例如，给定`RRG`，有人可能会认为，因为有两个 R，所以无论位置如何，都必须始终删除一个。 在这种情况下这是正确的，但一般而言，仅频率是不够的，因为邻接很重要。 

另一种常见的错误方法是尝试全局“平衡”颜色，例如尝试以某种固定模式交替使用 R、G、B。 这在输入上失败，例如`RGRGRG`，即使任何严格的模式假设可能会错误地移除有效的棋子，也不需要移除。 

正确的解决方案必须仅依赖于局部邻接，而不是全局分布。 

## 方法

 蛮力的想法是通过尝试所有棋子子集并检查哪些子集满足没有两个相邻棋子相等的条件来模拟移除。 对于每个子集，我们在线性时间内验证有效性。 由于有$2^n$子集，这导致$O(n \cdot 2^n)$时间复杂度。 即使与$n = 50$，这变得天文数字般大，使其不可行。 

关键的观察是我们不需要在全局范围内选择保留哪些宝石。 相反，我们可以仅根据它与之前保留的棋子的关系，从左到右贪婪地决定是否必须移除棋子。 

问题的结构是经典的局部约束约简：有效性条件仅取决于相邻的保留元素。 这意味着一旦我们修复了我们所保持的位置$i-1$, 位置决策$i$完全取决于它是否与最后保留的颜色匹配。 

这将问题从组合选择简化为单通道滤波过程。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n \cdot 2^n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 首先将计数器设置为零，代表移除了多少石子。 
2. 追踪最后保存的石材颜色。 最初，这是未定义的，因为尚未处理任何宝石。 
3. 从左到右扫描字符串，一次处理一颗石头。 
4. 对于每颗宝石，将其颜色与最后保存的颜色进行比较。 如果相同，则必须移除这块石头，因为保留它会违反邻接规则。 
5. 如果它与最后保留的颜色不同，我们保留它并将最后保留的颜色更新为当前颜色。 
6. 继续直到绳子末端，累积移除的石子数量。 

### 为什么它有效

 在扫描中的任何一点，所保存的序列都保证满足没有两个相邻棋子相等的条件。 之所以保留这一点，是因为我们仅在与上次保留的石头不同时才添加一块石头。 如果匹配，则删除它总是安全的，因为它无法帮助将来的决策：保留它只会引入无效的邻接，而没有任何好处，因为所有未来的检查仅取决于最近保留的石头，而不是任何早期的石头。 这建立了一个贪婪的不变量，即保留的前缀对于其长度始终是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    s = input().strip()
    
    removed = 0
    last = None
    
    for c in s:
        if c == last:
            removed += 1
        else:
            last = c
    
    print(removed)

if __name__ == "__main__":
    solve()
```代码维护一个变量`last`代表最近保存的石头。 当当前字符匹配时`last`，它被丢弃并计为移除。 否则就变成新的了`last`。 这直接一次性实现了算法演练中的贪婪规则。 

重要的微妙之处是初始化：`last = None`确保始终保留第一个字符，因为它不能匹配之前的任何字符。 除此之外不存在任何边界问题，因为每次比较都是安全且统一的。

 ## 边缘情况

 对于像这样的单块石头`B`，算法集`last = None`，保留石头，并产生零清除。 没有触发删除的比较，这符合要求，因为单个元素始终有效。 

对于完全统一的字符串，例如`RRRRR`，第一个`R`被保留并且每个后续字符都等于`last`，因此每个都被计为已删除。 扫描永远不会更新`last`，这确保了结果准确无误$n-1$，与保持最大相同块的一个代表一致。 

对于交替字符串，例如`RGRGRG`，每个字符都不同于`last`，所以没有删除任何内容。 只有相等相邻对无效的不变性确保了该结构已经是最优的，并且算法正确地保留了所有元素。
