 ## 解决方案
 ## 问题理解

 我们有一个公司层次结构`n`员工，其中第一位员工是主管，其他每个员工都有一个直接上级。 这就自然形成了一棵以头为根的有根大树。 编程竞赛需要在严格的规则下组成两人团队：任何团队都不能让员工与其上级配对，无论是直接还是间接。 目标是确定在此约束下可以组建的最大团队数量。 

输入由多个测试用例组成。 对于每个测试用例，我们都会得到员工人数`n`和一个数组`n-1`代表每个员工的直接上级的整数。 输出是每个测试用例的最大团队数量。 

约束条件意味着`n`最多可达 200,000，总和`n`跨测试用例最多为 200,000 个。 由于时间限制为 2 秒，任何比每个测试用例的 O(n log n) 更差的解决方案都是有风险的。 考虑所有员工对 (O(n²)) 的简单方法是不可行的。 

非明显的边缘情况包括：

 - 每个员工都是根的直接子代的树。 例如，`n=4`与上级`[1,1,1]`。 最大团队数量为`1`， 不是`2`，因为根无法与任何人配对。 
- 每个员工都优于其他员工的连锁店。 为了`n=3`和`[1,2]`，无法组建队伍。 
- 稀疏且平衡的树，其中配对必须避免父子边缘。 对不同深度的节点进行错误计数可能会产生错误的答案。 

## 方法

 蛮力方法是考虑所有可能的员工对，并检查其中一个是否优于另一个。 这是可行的，因为我们可以迭代每个可能的对并通过遍历验证优越关系。 然而，这需要每个测试用例进行 O(n²) 次操作，这对于 n 高达 200,000 的情况来说太慢了。 

关键的见解来自于注意到上下级关系是树形结构。 树中的任何直接边都将上级与下级连接起来。 团队不能包含通过任何祖先-后代路径连接的节点。 因此，树中相同深度（级别）的员工永远不会相互优越。 我们可以根据深度对节点进行着色：偶数深度的节点和奇数深度的节点形成两个不相交的集合，其中同一集合中没有对违反规则。 那么，最大的球队数量是较小一组的规模除以 2，加上另一组的规模除以 2？ 更仔细的方法是简单地计算叶节点和内部节点的数量：将叶与不同子树中的叶配对可以避免上级冲突。 

一个更简单且正确的方法是认识到每个团队必须由来自不同分支的节点组成。 通过计算叶子的数量，独立对的最大数量受到以下限制：`floor(n / 2)`在平衡树中，在退化链中较少。 更直接的方法使用贪婪策略：最大团队数量是`n // 2`减去由于成为其父级的唯一子级或作为没有兄弟配对的叶子而被隔离的节点数。 为了有效地实现这一点，我们可以计算度数并使用 DFS 来跟踪配对的可能性。 该算法最终每个测试用例的复杂度为 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最优（DFS + 深度计数）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`以及一系列直接上级`p`。 
2. 使用上级数组构建树的邻接表。 每个`p[i]`成为父节点，我们追加`i+2`作为它的孩子。 
3. 初始化节点深度计数器。 从深度为 0 的根节点（员工 1）启动 DFS。 
4. 递归遍历树。 对于每个节点，增加当前深度节点的计数器。 对所有子级重复，深度+1。 
5、DFS后，统计偶数深度和奇数深度的节点数。 相同深度的员工不可能有高下之分。 
6. 团队最大数量为`min(even_count, odd_count)`。 每个团队需要两个人，但是偶数和奇数深度的集合是不相交的，因此我们可以安全地对来自不同深度集合的节点进行配对。 这给出了正确的最大值，因为我们无法在不违反上级规则的情况下将同一深度集中的两个节点配对。 
7. 输出每个测试用例的结果。 

**为什么有效：** 树中的节点距根部有明确的深度。 根据定义，一个节点不能是同一深度上另一个节点的上级，因为所有边都从父节点到子节点。 按深度将树分为偶数集和奇数集可确保没有团队违反上级约束。 计算较小的集合可确保我们最大化不相交对的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        parents = list(map(int, input().split()))
        tree = [[] for _ in range(n + 1)]
        for i, p in enumerate(parents, start=2):
            tree[p].append(i)
        
        depth_count = [0, 0]

        def dfs(node, depth):
            depth_count[depth % 2] += 1
            for child in tree[node]:
                dfs(child, depth + 1)
        
        dfs(1, 0)
        print(min(depth_count[0], depth_count[1]))

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 我们使用邻接表构建树，然后执行 DFS 按深度对节点进行计数。 增加了递归限制以处理深树。 最后，我们打印偶数和奇数深度计数的最小值，这保证了团队的最大数量。
