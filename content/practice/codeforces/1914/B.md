 ## 解决方案
 ## 问题理解

 我们有困难有问题`1`通过`n`。 我们必须将这些数字排列成代表 Monocarp 求解它们的顺序的排列。 

每当一个问题比所选顺序中的前一个问题更难时，Monocarp 就会变得兴奋。 第一个解决的问题永远不会被计算在内，因为没有之前的问题可供比较。 

对于排列`p`，兴奋发生在位置`i > 1`什么时候`p[i] > p[i-1]`。 任务是构建任意排列`1...n`正好产生`k`这样的职位。 

限制非常小。 最多可以有 1000 个测试用例，但是`n`最多 50。即使是`O(n²)`建设将是微不足道的。 挑战不在于效率，而在于找到一种简单的结构，始终能够准确地创建所需数量的增加的相邻对。 

一个常见的错误是认为兴奋的数量取决于排列中稍后出现的较大元素的数量。 只有相邻的比较才重要。 

例如，与```
5 4 3 2 1
```兴奋度为零，因为每个相邻的比较都会减少，即使序列中较早存在许多较大的数字。 

另一个容易出现的陷阱出现在以下情况：`k = n - 1`。 在这种情况下，每个相邻比较都必须增加，因此唯一有效的排列是严格递增的顺序：```
1 2 3 4 5
```一种结构如果不小心引入了哪怕一次减少，也只会产生`n - 2`兴奋。 

相反的极端是`k = 0`。 然后每个相邻比较都必须减少，因此严格减少的排列有效：```
5 4 3 2 1
```任何将较小数字放在较大数字之前的结构都会立即产生不必要的兴奋。 

## 方法

 蛮力的想法很简单。 生成排列`1...n`，计算有多少个位置满足`p[i] > p[i-1]`，当计数等于时停止`k`。 

计数本身需要`O(n)`每次排列的时间。 问题是排列的数量。 有`n!`的可能性。 即使是为了`n = 10`，这已经超过 360 万种排列，使得穷举搜索变得不切实际。 

关键的观察是我们不需要搜索。 我们只需要具有指定数量的递增相邻对的排列。 

假设我们将数字```
1 2 3 ... k+1
```一开始。 该前缀内的每个相邻比较都在增加，因此它的贡献正好`k`兴奋。 

现在考虑剩下的数字：```
k+2, k+3, ..., n
```如果我们以相反的顺序附加它们：```
n, n-1, ..., k+2
```那么该后缀内的每个比较都会减少。 

两个部分之间的边界怎么样？ 递增前缀的最后一个元素是`k+1`，反转后缀的第一个元素是`n`。 自从`n > k+1`，这个边界带来了额外的兴奋。 

这意味着上面的构造创建了`k+1`兴奋，不`k`。 

为了解决这个问题，我们让增加的部分完全包含`k`数字：```
1 2 3 ... k
```并反转其余部分：```
n, n-1, ..., k+1
```之间的比较`k`和`n`不断增加，让人兴奋不已。 前缀本身有贡献`k-1`兴奋。 一起：```
(k - 1) + 1 = k
```正是我们所需要的。 

### 复杂性比较

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!·n) | O(n!·n) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 创建一个包含数字的列表`1, 2, ..., k`。 

在这个前缀里面正好有`k - 1`增加相邻比较。 
2. 取剩下的数字`k + 1, k + 2, ..., n`。 

这些都是尚未使用的值。 
3. 以相反的顺序附加剩余的数字：```
n, n-1, ..., k+1
```该后缀内的每个相邻比较都在递减。 
4. 输出排列结果。 

两部分之间的边界是`k`其次是`n`，这恰恰带来了一种额外的兴奋。 

### 为什么它有效

 前缀`1, 2, ..., k`包含`k-1`增加相邻对，因为每个相邻对都会增加。 

后缀`n, n-1, ..., k+1`包含零个递增的相邻对，因为每个相邻对都会减少。 

唯一跨越边界的比较是`k`和`n`，并且自从`n > k`，它恰好贡献了一对递增的相邻对。 

因此兴奋点总数为```
(k - 1) + 1 + 0 = k.
```什么时候`k = 0`，前缀为空，整个排列变成```
n, n-1, ..., 1
```其兴奋度为零。 因此，构造工程适用于每个有效值`k`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())

    ans = list(range(1, k + 1))
    ans.extend(range(n, k, -1))

    print(*ans)
```该结构的第一行创建递增前缀`1...k`。 

第二行按降序附加所有剩余的数字。 电话```
range(n, k, -1)
```产生```
n, n-1, ..., k+1
```这正是证明所需的后缀。 

案例`k = 0`是自动处理的。 然后```
range(1, 1)
```产生一个空前缀，后缀变成```
n, n-1, ..., 1.
```不需要特殊的分支。 

案例`k = n - 1`也是自然处理的。 前缀变为```
1, 2, ..., n-1
```并且后缀仅包含`n`，产生完全递增的排列。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n, k = map(int, input().split())
        ans = list(range(1, k + 1))
        ans.extend(range(n, k, -1))
        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

# provided sample properties
assert run("1\n6 2\n") == "1 2 6 5 4 3"

# minimum size, k = 0
assert run("1\n2 0\n") == "2 1"

# minimum size, k = 1
assert run("1\n2 1\n") == "1 2"

# fully increasing
assert run("1\n5 4\n") == "1 2 3 4 5"

# fully decreasing
assert run("1\n5 0\n") == "5 4 3 2 1"

# larger boundary case
assert run("1\n7 3\n") == "1 2 3 7 6 5 4"

 ## 边缘情况

 ### 情况 1：没有兴奋感

 输入：```
1
5 0
```前缀为空。 后缀变为：```
5 4 3 2 1
```每个相邻的比较都会减少，因此兴奋计数为零。 该结构准确地产生了所需的值。 

### 案例 2：最大可能的兴奋

 输入：```
1
5 4
```前缀是：```
1 2 3 4
```后缀仅包含：```
5
```最终的排列是：```
1 2 3 4 5
```所有四个相邻比较都增加，准确给出`n - 1 = 4`兴奋。 

### 案例 3：边界贡献

 输入：```
1
6 2
```该构造给出：```
1 2 6 5 4 3
```前缀带来了一种兴奋（`1 → 2`）。 边界贡献了一种兴奋（`2 → 6`）。 后缀没有任何贡献。 总数正好是两个。 

这个案例展示了结构背后的中心思想：前缀提供了`k - 1`兴奋，边界提供了最后一个。
