 ## 解决方案
 ## 问题理解

 我们在飞机上有两个固定点：起始位置和目的地。 我们还收到一系列运动长度。 在步骤`i`，我们必须从当前位置移动到与当前位置的欧几里得距离恰好为的任何点`a_i`。 方向是完全自由的，但距离是固定的。 

完成所有动作后，我们想知道是否有可能准确落在目标点上。 

关键的困难在于，每一步都会引入连续的方向自由度，因此每一步之后可到达的点的集合是一个圆盘边界，而不是单个点。 经过多个步骤后，可达区域变成由固定长度段的所有可能向量和定义的不断增长的几何形状。 

这些限制以非常具体的方式发挥作用。 所有测试用例的操作总数最多为 2 · 10^5，因此任何显式模拟几何或存储点集的方法都是不可能的。 即使维持多边形或采样方向也太慢了。 

自然的失败模式来自于贪婪地思考方向选择。 例如，总是试图瞄准目标可能会失败，因为早期的选择可能会迫使后来的移动超出或低于最终距离。 另一个失败是假设只考虑总和，而忽略了抵消效应。 

例如，如果我们只将起点和终点之间的距离与所有距离之和进行比较`a_i`，我们可能会说：

 - 如果距离≤总和，则是

 这是不正确的。 考虑：```
start = (0,0), end = (1,0)
a = [2, 2]
```总和是 4，所以简单的逻辑说可达，但实际上我们不能在距离 1 处结束，因为长度为 2 的两个段只能到达 [0,4] 中的距离，但对向量组成有类似奇偶校验的约束。 

正确的解决方案不仅取决于总长度，还取决于段之间可以取消多少。 

## 方法

 暴力解释是在每次移动后跟踪所有可到达位置的完整集合。 步骤后`i`，每个可到达的点都会扩展为一个以先前每个点为中心且半径为圆的圆`a_i`。 这很快就会变成一个边界越来越复杂的连续区域。 事实上，之后的可达区域`i`步骤是一个圆盘，其半径仅取决于段长度的总结构，但从几何角度推导它仍然需要理解闵可夫斯基和。 显式模拟是不可能的。 

关键的观察结果是，唯一重要的不变量是距起点的最终距离的可能范围。 在每个段之后，我们实际上添加了一个固定长度但任意方向的向量。 这将问题简化为在所有移动后跟踪距原点的最小和最大可能距离。 

如果我们反过来思考，在所有段之后，相对于起点的终点是具有固定大小的向量的总和。 所有这些总和的集合形成一个环：最小值和最大值之间的所有距离。 

最大距离是微不足道的：我们将所有线段沿同一方向对齐，给出：```
max_dist = sum(a_i)
```最短距离取决于取消情况。 如果某一段与其他段相比太大，则无法完全取消。 如果我们不进行任何排序并直接推理，则可达到的最小距离为：```
min_dist = max(0, 2 * max(a_i) - sum(a_i))
```这是因为除了最大的部分之外的所有部分都可以尝试反对它。 如果最大的部分大于所有其他部分的总和，则剩余部分仍然存在。 

一旦我们知道了可达区间`[min_dist, max_dist]`，问题简化为检查起点和终点之间的实际距离是否位于其中。 

让：```
D = distance between start and end
```我们回答“是”当且仅当：```
min_dist ≤ D ≤ max_dist
```| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力几何| 指数/连续| 大| 太慢了|
 | 距离间隔 | 每次测试 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 现在我们将推理转化为具体的程序。 

1. 计算起点和终点之间的欧氏距离平方。 我们通过稍后比较平方值来避免平方根。 
2. 计算所有线段长度的总和。 这表示每次移动都沿同一方向对齐时可达到的最远距离。 
3. 确定最大线段长度。 这决定了其他段是否可以完全取消它。 
4. 使用以下公式计算可能的最小最终距离：```
min_dist = max(0, 2 * max_a - sum_a)
```这捕获了最佳取消后剩余的“不平衡”长度。 
5. 比较目标距离与间隔`[min_dist, sum_a]`。 如果在里面，输出“Yes”，否则输出“No”。 

这样做的原因是可到达的端点形成了连续的距离范围。 最小值和最大值之间的任何值都是可以实现的，因为我们可以连续旋转线段方向以在极端配置之间进行插值。 向量和的几何形状保证该区间内没有间隙。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        px, py, qx, qy = map(int, input().split())
        a = list(map(int, input().split()))
        
        total = sum(a)
        mx = max(a)
        
        dx = px - qx
        dy = py - qy
        dist_sq = dx * dx + dy * dy
        
        min_dist = max(0, 2 * mx - total)
        
        # compare squared distances to avoid sqrt
        if min_dist * min_dist <= dist_sq <= total * total:
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
```实现直接遵循导出的间隔检查。 唯一的微妙之处是使用平方距离来避免浮点错误。 最小和最大距离是在线性时间内计算的。 

表达式`2 * mx - total`被钳制在零，因为当没有单个段占主导地位时，消除可以完全消除位移。 最终检查纯粹是区间隶属度测试。

 ## 边缘情况

 当所有线段长度相同并且目标是同一点时，取消允许完全返回原点。 该算法计算`max_a = total / n`, 给予`min_dist = 0`，因此任何零距离目标都被接受。 

当只有一条线段时，可达集恰好是半径为一圆`a1`。 公式得出`min_dist = max_dist = a1`，因此仅指向精确距离`a1`被接受，精确匹配几何形状。 

当一个细分市场主导所有其他细分市场时，例如`[10,1,1]`，最小距离变为正值。 该算法将其捕获为`2 * 10 - 12 = 8`，这意味着最终位置距离开始的距离不能小于 8，这反映了最长移动的不可约超额。
