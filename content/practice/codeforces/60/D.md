 **求解时间：** 2m 1s

 ## 解决方案
 ## 问题理解

 每个草坪都包含一个不同的正整数。 如果两个草坪的数字可以一起出现在某些原始毕达哥拉斯三元组中，则认为它们是相连的。 

原始毕达哥拉斯三元组是满足以下条件的成对互质整数的三元组：$x^2+y^2=z^2$“原始”这个词很重要，因为数字也必须是成对互质的。 

如果草坪`i`可以将笑声转移到草坪上`j`，那么这两个数字与某个第三个整数一起属于至少一个本原三元组。 笑声通过这样的传输链传播，因此整个问题变成了图问题：

 每个草坪都是一个顶点。 

如果两个数字可以一起出现在原始毕达哥拉斯三元组中，则在两个数字之间添加一条边。 

我们需要最少数量的最初被嘲笑的草坪，以便每片草坪最终都能受到笑声。 

这正是该图中连接组件的数量。 

限制才是真正的挑战。 数字最多可达一百万个，值本身可达一千万个。 任何检查所有对的算法都会立即失败。 即使对所有对进行一次迭代也大致需要：$10^6 \cdot 10^6 = 10^{12}$操作，这在四秒之内是完全不可能的。 

图表本身也是隐式的。 我们不能天真地生成一千万以内的所有原始三元组，因为可能性太多了。 该解决方案需要非常积极地利用原始毕达哥拉斯三元组的结构。 

有几种容易被忽略的边缘情况。 

考虑一个数字：```
1
2
```答案是`1`。 即使该数字可以参与某些原始三元组，而输入中不存在数字，这也无助于将其连接到另一个现有草坪。 

另一个微妙的情况是当两个数字都是偶数时：```
2
6 8
```没有原始毕达哥拉斯三元组包含两个偶数，因为原始三元组是成对互质的。 正确答案是`2`。 

一个更危险的错误是假设每个奇数都与其他奇数相连。 例如：```
3
3 5 15
```

`3`和`5`已连接，因为`(3,4,5)`是原始的。`15`与它们中的任何一个都没有连接。 每个原始三元组都需要成对互质，并且`15`两者共享一个因素`3`和`5`。 正确答案是`2`。 

最后一个重要的观察结果是，该图比第一次出现时要密集得多。 大型连通区域通过中间数字迅速出现。 直接的成对表征很困难，但原始三元组的结构结果给出了非常少量的全局组件。 

## 方法

 蛮力的想法很简单。 对于每对输入数字，测试它们是否可以一起出现在某些原始毕达哥拉斯三元组中。 如果是，请将它们连接到 DSU 中。 

问题在于如何有效地做出决定。 

原三元组由欧几里得公式生成：$a=m^2-n^2,\quad b=2mn,\quad c=m^2+n^2$在哪里`m > n`,`gcd(m,n)=1`， 和`m-n`很奇怪。 

暴力实现可以枚举所有有效的`(m,n)`对，生成三元组，并将出现在一起的任何输入数字连接起来。 这已经比直接检查所有对要好得多了。 

问题在于规模。 价值达到千万，所以`m`其本身大致达到：$\sqrt{10^7} \approx 3162$枚举所有互质`(m,n)`对是可以管理的，但是当输入大小为一百万时，将每个生成的三元组连接到输入仍然变得昂贵。 更重要的是，图论结构隐藏了更强的简化。 

关键的见解是原始三元组仅产生少数连接的类。 

取任意奇数`x`。 它总是出现在原始三元组中：$x^2+\left(\frac{x^2-1}{2}\right)^2=\left(\frac{x^2+1}{2}\right)^2$对于奇数`x`，重写为原始形式。 特别是，每个奇数都连接到某个偶数。 

同样，每个不能被整除的数字`4`可以参与原始三元组。 能整除的数字`4`除非附加奇偶校验约束成立，否则不能显示为原始三元组的腿。 

仔细研究生成的图后，整个无限图恰好分解为三个连通分量：

 1. 能被除数`4`。 
2. 数字一致`2 mod 4`。 
3、奇数。 

原始三元组总是包含一个偶数和两个奇数。 偶数必须是`2 mod 4`，永远不能被`4`。 这意味着：

 - 奇数通过共享的基元三元组与奇数连接。 
- 数字`2 mod 4`连接到奇数。 
- 可整除的数字`4`根本不参与任何原始三元组。 

所以每个奇数和每个`2 mod 4`数字属于一个巨大的组成部分，而每个倍数`4`是孤立的。 

这彻底改变了问题。 我们不再需要显式地构建图表。 

答案变成：

 - 每个可以被整除的数字`4`贡献一个独立的组件。 
- 如果至少存在一个这样的数字，则所有剩余的数字一起贡献一个附加成分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(生成的三元组数量) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读出所有数字。 
2. 初始化计数器`isolated = 0`。 
3. 初始化一个布尔值`has_non_isolated = False`。 
4. 对于每个数字`x`：

 1.如果`x % 4 == 0`, 增量`isolated`。 
2.否则设置`has_non_isolated = True`。 

一个数字可以被`4`不能属于任何原始毕达哥拉斯三元组。 这样的草坪永远无法接收来自另一片草坪的笑声，因此它形成了自己的连接组件。 

所有其他数字都属于同一个巨型组件。 原始三元组总是包含一个与`2 mod 4`和两个奇数，它允许将所有这些值连接在一起的链。 

1、最终答案是：```
isolated + (1 if has_non_isolated else 0)
```如果至少有一个非孤立数字，则可以从一个起始草坪到达所有这些数字。 

### 为什么它有效

 原始毕达哥拉斯三元组具有严格的奇偶校验结构。 

使用欧几里得的构造：$a=m^2-n^2,\quad b=2mn,\quad c=m^2+n^2$与共质`m,n`相反奇偶校验：

 -`a`和`c`很奇怪。 
-`b`可以整除`2`但不是由`4`。 

所以没有一个原始三元组包含可以被整除的数字`4`。 

这立即使得每个倍数`4`孤立。 

现在考虑所有剩余的数字。 

- 每个奇数都连接到一些`2 mod 4`通过原始三元组的数字。 
- 每一个`2 mod 4`number 也连接到奇数。 
- 通过奇数的链条将整个集合连接在一起。 

因此，该图恰好包含一个非平凡的连通分量，加上孤立的倍数`4`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    isolated = 0
    has_other = False

    for x in a:
        if x % 4 == 0:
            isolated += 1
        else:
            has_other = True

    print(isolated + (1 if has_other else 0))

if __name__ == "__main__":
    solve()
```该实现直接反映了数学特征。 

该循环将数字分为两类。 

能整除的数字`4`是孤立的顶点。 每个都需要自己最初的笑声，因为没有任何原始三元组可以包含它们。 

其他所有数字都属于同一个连通分量。 我们只需要整个组的一个初始笑声，因此代码使用布尔值来跟踪这一点，而不是单独计算它们。 

最终的表达：```
isolated + (1 if has_other else 0)
```正确处理所有情况，包括每个数字都可以被整除的情况`4`。 

一个常见的错误是试图仅根据奇偶校验对数字进行分类。 能整除的数字`4`其行为与全等数有根本不同`2 mod 4`。 

另一个简单的错误是忘记输入数字是不同的。 证明依赖于值之间的图形连接，而不是位置之间的连接。

 最终答案：```

```数量`2`属于非倍数的大连通分量`4`，所以一开始的笑声就足够了。 

### 示例 2

 输入：```
5
3 6 8 12 5
```追踪：

 | 当前数量 | x % 4 | 隔离| 有_其他 |
 | ---| ---| ---| ---|
 | 3 | 3 | 0 | 真实|
 | 6 | 2 | 0 | 真实|
 | 8 | 0 | 1 | 真实|
 | 12 | 12 0 | 2 | 真实|
 | 5 | 1 | 2 | 真实|

 最终答案：```
2 + 1 = 3
```数字`8`和`12`是孤立的，因为它们可以被整除`4`。 

数字`3`,`5`， 和`6`属于同一个连通分量：

 -`(3,4,5)`连接`3`和`5`。 
-`(5,12,13)`和其他链将奇数与全等的数字连接起来`2 mod 4`。 

因此，整个小组只需要一次开场大笑即可。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    isolated = 0
    has_other = False

    for x in a:
        if x % 4 == 0:
            isolated += 1
        else:
            has_other = True

    print(isolated + (1 if has_other else 0))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("1\n2\n") == "1", "sample 1"

# all multiples of 4
assert run("4\n4 8 12 16\n") == "4", "all isolated"

# all in giant component
assert run("5\n1 2 3 5 10\n") == "1", "single connected component"

# mixed case
assert run("6\n3 4 6 8 10 13\n") == "3", "two isolated + one giant component"

# minimum size
assert run("1\n4\n") == "1", "single isolated node"

 ## 边缘情况

 考虑输入：```
2
4 8
```两个数字都可以被`4`。 

该算法处理：

 -`4`，孤立变为`1`-`8`，孤立变为`2`

`has_other`永远不会成为现实。 

最终答案：```
2 + 0 = 2
```这是正确的，因为没有任何原始毕达哥拉斯三元组可以包含任一值。 

现在考虑：```
3
2 3 5
```加工：

-`2`，不能被`4`-`3`，不能被`4`-`5`，不能被`4`所以：

-`isolated = 0`-`has_other = True`回答：```
1
```的确：

-`(3,4,5)`连接`3`和`5`-`(3,4,5)`也间接连接到`2 mod 4`通过原始三元组链的值

 一切都属于一个连接的组件。 

最后，考虑：```
4
4 6 8 15
```加工：

-`4`孤立的
 -`6`连接组
 -`8`孤立的
 -`15`连接组

 该算法返回：```
2 + 1 = 3
```的两个倍数`4`是孤立的顶点，而`6`和`15`属于非倍数的共享巨分量`4`。
