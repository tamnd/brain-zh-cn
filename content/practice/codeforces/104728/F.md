 ## 问题理解

 给定一个素数$p$，以及很多疑问。 每个查询提供一个巨大的整数$n$，我们需要评估自定义操作$n!$。 

操作$x \oplus p$行为就像采取$x \bmod p$，但有一点不同：在取余数之前，我们反复除以$x$经过$p$只要它能被整除$p$。 换句话说，所有因素$p$在计算余数模之前被完全去除$p$。 

一种更代数的方式来看待这个问题是，如果我们写$$x = p^k \cdot r \quad \text{where } p \nmid r,$$然后$x \oplus p = r \bmod p$。 自从$r$不能被整除$p$，这只是$r \bmod p$， 但$r$本身可能仍然很大。 

我们的任务是计算这个值$x = n!$，对于每个查询独立。 

这些约束使得直接计算阶乘变得不可能。 和$n$最多$10^{18}$，甚至迭代到$n$是不可能的。 单个阶乘计算已经超出了任何可行的时间限制，并且最多有$10^5$查询，因此即使每个查询的对数工作也必须非常高效。 

一种简单的方法会尝试计算$n! \bmod p$，然后除以因子$p$，但这仍然隐含地需要处理直到$n$，这是不可能的。 

出现微妙的边缘情况时$n < p$。 在这种情况下，$n!$不包含以下因素$p$，因此操作简化为简单$n! \bmod p$。 一个粗心的解决方案，总是应用“删除$p$如果不正确处理此基本情况，“-因素”递归可能会引入不正确的递归深度或不必要的模幂。 

另一个棘手的情况是当$n$很大但商很小$n // p$。 解决方案的结构在很大程度上取决于这种商分解，如果尝试直接模拟阶乘结构，则无法认识到这一点会导致指数行为。 

## 方法

 暴力方法将计算$n!$直接然后重复除以$p$虽然可能，最后取模$p$。 这在原则上是正确的，因为它完全遵循操作的定义。 然而，计算$n!$已经需要$O(n)$乘法，这是不可能的$n$最多$10^{18}$。 即使对于单个查询，这也是不可行的。 

关键的观察是我们永远不需要完整的阶乘，只需要它的模值$p$去除所有因素后$p$。 这表明将可被整除的数字的贡献分开$p$和那些不能被整除的$p$。 自从$p$是素数，倍数的结构$p$定期重复，允许在基础上进行分而治之的分解$p$。 

我们将数字从$1$到$n$成完整大小的块$p$和一个余数块。 每个完整的块都贡献一个结构化因子，可以使用威尔逊定理进行简化，其中$(p-1)! \equiv -1 \pmod p$。 这将每个完整块转换为简单的乘法贡献，其余部分是较小的阶乘问题。 这导致递归减少$n$到$n // p$，给出对数深度。

 | 最佳 |$O(\log_p n + p)$预处理|$O(p)$| 已接受 |

 ## 算法演练

 我们定义一个函数$F(n)$作为价值$n!$去除所有因素后$p$，取模$p$。 

### 预计算

 1. 计算阶乘模$p$对于所有值$0$到$p-1$。 这可以直接访问$(n \bmod p)!$每当我们需要它时。 

### 递归计算

 1.如果$n = 0$， 返回$1$，因为空乘积的贡献是中性的。 
2. 分裂$n$成完整大小的块$p$： 让$n = a \cdot p + b$， 在哪里$b = n \bmod p$。 这将数字分成完整的循环和部分尾部。 
3.尾部贡献$(b!)$，我们已经从预计算中知道了。 
4. 每个完整的块来自$1$到$p$贡献$(p-1)! \equiv -1 \pmod p$去除该因素后$p$。 这就是原始性的所在$p$是必不可少的。 
5. 因此，所有完整区块都贡献$(-1)^a$，因为有$a$这样的块。 
6. 我们递归地计算贡献$a!$，因为结构按比例重复$p$。 这给出了因子$F(a)$。 
7. 结合一切：$$F(n) = F(a) \cdot (-1)^a \cdot (b!) \bmod p.$$### 为什么它有效

 不变的是，在每个递归级别，我们都会分解出按残差类分组的数字的贡献模数$p$。 每组尺寸$p$删除多个后表现相同$p$，并减少到模常数值$p$。 递归跟踪每个尺度上存在多少个完整组，威尔逊定理确保这些组折叠成一个简单的符号因子。 因为每级都会减少$n$到$n // p$，没有损失任何贡献，并且所有因素$p$在模块化缩减之前始终被删除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T, p = map(int, input().split())

    fact = [1] * p
    for i in range(1, p):
        fact[i] = fact[i - 1] * i % p

    def F(n):
        if n == 0:
            return 1
        a, b = divmod(n, p)
        res = F(a)
        if a % 2:
            res = (res * (p - 1)) % p
        return res * fact[b] % p

    for _ in range(T):
        n = int(input())
        print(F(n))

if __name__ == "__main__":
    solve()
```该解决方案首先预先计算阶乘模$p$，它允许恒定时间查找任何剩余部分。 递归函数实现分解$n = a p + b$，确保每个级别删除一位数字$n$在基地$p$。 乘以$p-1$处理$(-1)^a$没有分支求幂的项。 

递归深度最多为$O(\log_p n)$，即使对于$n = 10^{18}$。

 ## 边缘情况

 当$n < p$，递归立即停止在阶乘查找表处。 例如，如果$n = 4$和$p = 11$，函数直接返回$4!$，因为没有除以$p$发生。 

什么时候$n = p$，分解给出$a = 1, b = 0$。 算法返回$F(1) \cdot (p-1) \cdot 1$，这与事实相符$p! = p \cdot (p-1)!$，并且删除后$p$，我们剩下$(p-1)! \equiv -1 \pmod p$，与递归结构一致。 

对于非常大的$n$, 重复除以$p$保证递归以对数深度终止，并且没有中间值超过模边界。
