 ## 解决方案
 ## 问题理解

 我们得到一个长度为 n 的约束数组。 对于每个位置 i，值 a[i] 告诉我们最终序列的前 a[i] 个字符必须匹配以位置 i 结尾的长度为 a[i] 的块。 换句话说，对于每个 i，段 s[1..a[i]] 被迫与 s[i-a[i]+1..i] 相同。 

因此，每个索引 i 都贡献了前缀中的位置和以 i 结尾的移位窗口之间的一组相等关系。 一旦强制执行所有这些等式，我们必须为 s 赋值，以满足所有约束。 在所有有效的构造中，我们希望最大化 s 中出现的不同值的数量，并且如果存在多个解决方案，我们必须输出字典顺序最小的序列。 

这些限制意味着职位不是独立的。 每当 a[i] 为正数时，它将前缀位置与 i 周围的位置联系起来，可能将许多索引链接在一起形成一个强制相等类。 一个幼稚的错误是独立对待每个 i 并仅在本地比较两个片段，而不传播早期约束的传递效应。 例如，如果位置 1 等于 3，并且 3 等于 5，则即使它们之间没有直接约束，1 也必须等于 5。 

当约束在实现中不一致地重叠时，会发生另一个微妙的失败，该实现仅检查每个 i 的成对条件，但不全局统一等价类。 这种方法可以通过小案件，但一旦多个重叠边界形成长长的平等链，这种方法就会失效。 

输入大小 n 最大可达 2×10^5，这排除了段比较的任何二次模拟。 每个约束最多可以跨越 O(n) 个位置，因此为每个 i 显式复制段将导致 O(n^2) 行为和 TLE。 该解决方案必须将所有约束减少到支持近线性并集和赋值的结构中。 

## 方法

 对于每个 i，直接模拟方法会将子字符串 s[i-a[i]+1..i] 复制到 s[1..a[i]]，可能会重写已处理的位置。 这很快就会变得昂贵：单个大 a[i] 可以触发 O(n) 分配，并且在所有 i 中，这会退化为 O(n^2)。 

关键的观察结果是，约束在处理过程中不需要显式值； 他们只强制执行职位之间的平等关系。 每个条件都表示对于每个偏移量 j，位置 j 必须等于位置 i-a[i]+j。 这不是复制操作，而是声明索引对属于同一等价类。 

一旦被视为等式约束，问题就变成了构建相等位置图并向连接的组件分配值。 为了最大化不同值的数量，每个组件都应该有自己的值。 为了实现按字典顺序排列的最小顺序，必须按照从左到右扫描时首次出现的顺序为组件分配值。 

这将问题简化为维护位置上的不相交集，统一所有约束对，然后贪婪地为每个组件分配标签。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分段传播 | O(n²) | O(n) | 太慢了 |
 | DSU 等式压缩 | O(n α(n)) | O(n α(n)) | O(n) | 已接受 |

 ## 算法演练

 我们将每个索引视为并查找结构中的一个节点，其中同一集合中的节点必须接收相同的值。

1. 初始化一个不相交的并集结构，其中每个位置 i 都是其自己的父级。 此时，每个索引都被认为是独立的，因此我们从最大可能数量的不同值开始。 
2. 对于从 1 到 n 的每个索引 i，迭代从 1 到 a[i] 的所有偏移量 j。 对于每个 j，将位置 j 与 DSU 中的位置 (i - a[i] + j) 合并。 这强制长度为 a[i] 的前缀段和结束段逐个位置相同。 
3. 处理完所有约束后，每个连通分量代表一组必须共享相同值的索引。 不同组件之间不存在进一步的限制。 
4. 遍历索引从1到n。 每当我们遇到一个其代表尚未分配值的组件时，就为其分配最小的未使用整数。 存储从根到值的映射。 
5. 对于每个位置 i，输出分配给其 DSU 代表的值。 

这种排序产生字典顺序最小序列的原因是，组件第一次出现时，它会被分配尽可能小的值。 任何后面的组件都必然出现在更高的索引处，因此它会收到更大或相同的标签，从而保持词典编排的最小性。 

### 为什么它有效

 所有约束都是纯等式，因此解空间正是等式图的连通分量上的赋值常量的集合。 DSU 正确计算这些组件，因为每个约束都是必须匹配的索引的直接并集，并且并集运算的传递性捕获所有间接依赖项。 由于不存在不等式或排序约束，因此为每个组件分配不同的值始终有效，并且使用首次看到的标签可确保最早的位置获得最小的可能值，这正是所有有效标签中按字典顺序排列的最小代表。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(x, y):
        rx, ry = find(x), find(y)
        if rx == ry:
            return
        if size[rx] < size[ry]:
            rx, ry = ry, rx
        parent[ry] = rx
        size[rx] += size[ry]

    for i in range(1, n + 1):
        ai = a[i - 1]
        start = i - ai
        for j in range(1, ai + 1):
            union(j, start + j)

    comp_val = {}
    cur = 1
    res = [0] * (n + 1)

    for i in range(1, n + 1):
        r = find(i)
        if r not in comp_val:
            comp_val[r] = cur
            cur += 1
        res[i] = comp_val[r]

    print(*res[1:])

if __name__ == "__main__":
    solve()
```DSU 用于压缩所有等式约束。 每个联合操作将前缀索引与其在后缀段中相应的对齐位置连接起来。 路径压缩和按大小合并可确保近线性的性能。 

第二遍构建答案。 仅当第一次以从左到右的顺序遇到组件时，字典 comp_val 才会分配新标签，这就是强制字典最小性的原因。 

一个常见的实现陷阱是尝试在联合操作期间分配值。 这破坏了正确性，因为联合只定义结构，而不定义顺序。 分配必须在已知所有约束之后进行。

 ## 边缘情况

 对于 n=1 且 a[1]=0，没有并集并且单个位置形成其自己的组件。 由于首先遇到其 DSU 根，该算法立即为其分配标签 1。 

对于所有 a[i]=0 的情况，每个索引都保持隔离。 在第二遍期间，每个位置引入一个新根，按顺序接收新标签，产生字典顺序最小的严格递增数组。 

对于像 a[i]=i-1 这样的完全链式约束，每个并集都连接整个前缀结构。 DSU 将所有节点合并为一个组件，并且所有位置的输出都变为常数 1，与强制相等性相匹配。 

对于重叠的混合约束，例如交替长和短 a[i]，DSU 确保即使连接是间接的，也能正确形成传递闭包。 最终的标签仅取决于组件结构，而不取决于各个联合的顺序。
