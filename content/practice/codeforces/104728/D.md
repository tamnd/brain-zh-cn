 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$单位正方形网格。 网格边缘最初是未着色的。 两名玩家轮流进行，独行者先开始。 在每次移动中，玩家选择任何当前未着色的边缘并将其涂上自己的颜色。 给边缘着色后，任何被相同颜色的边缘完全包围的方块都会立即被该玩家占领。 

一旦网格中的每条边都被着色，游戏就结束了。 此时，每个单位方块都属于红色（独行）或蓝色（Kelin）所有，具体取决于谁完成了最后一个所需的边缘。 获胜者取决于谁拥有更多的方块，数量相等则平局。 

关键的结构是玩家不是直接要求方块，而是控制完成方块的最后一条边。 这使得该游戏从根本上成为一款具有本地完成奖金的抢占优势的游戏。 

输入大小限制允许$n$最多$10^9$，这排除了网格上的任何模拟。 甚至存储网格也是不可能的，因为它有$O(n^2)$正方形和$O(n^2)$边缘。 任何正确的解决方案都必须将问题简化为常数时间表达式$n$，完全依靠结构性能的优化发挥。 

一个微妙的点是，当一条边一次完成一个或两个方块时，完成规则适用，这意味着内部边缘可以同时影响多个方块。 这排除了幼稚的每格贪婪推理，因为一次移动可能会同时影响两个区域，并且一次关于一个格的局部直觉很快就会崩溃。 

另一个陷阱是假设总边数的奇偶性决定结果。 虽然奇偶性在顺序上很重要，但它并不直接转化为方格所有权，因为单个移动可以同时完成多个方格，这会以简单的移动计数无法捕获的方式改变得分。 

## 方法

 暴力解释将明确模拟游戏：维护网格，跟踪哪些边缘被着色，并在每次移动后重新计算是否有任何方块的所有四个边缘都由同一玩家着色并由当前移动完成。 这在逻辑上很简单，因为规则是本地的，并且它将正确地产生最终的所有权计数。 

然而，即使计算边缘，也有$2n(n+1)$网格中的边缘，因此游戏会持续那么多步。 每次移动都需要检查最多 2 个相邻的方格，因此模拟是$O(n^2)$。 为了$n = 10^9$，这是不可能的。 

关键的观察结果是网格是高度对称的，除了边缘如何共享之外，每个方块的行为都是相同的。 每个内部边缘属于两个方块，这意味着许多方块通过共享边缘成对耦合。 这种耦合迫使结果仅取决于全局平价和边界结构，而不是逐步决策。 

决定性的见解是，最佳游戏简化为边缘上的配对结构。 每条边都会对一个或两个方格做出贡献，并且由于两个玩家都以最佳且对称的方式进行游戏，因此优势取决于第一个玩家是否可以强制控制已完成的方格的平价。 这将整个网格游戏简化为分析方格数量的奇偶性，即$n^2$，再加上每次移动都针对一个边缘而不是一个正方形这一事实。 

更精确的重新表述是，该游戏相当于在规则结构中声明事件，其中每个方格恰好需要 4 条边，并且每条边最多贡献两个方格。 在最佳游戏下，唯一幸存的区别因素是该结构是否允许第二个玩家镜像移动而不会被迫失去完成权。 这种镜像是完美的，除非网格结构引入了不可避免的不平衡，这种不平衡是基于奇偶校验而发生的。$n$。 

这导致了一个简单的分类：取决于是否$n$是奇数还是偶数，优势在玩家之间转移或完全抵消。

 ## 算法演练

 1. 观察整个博弈仅取决于结构对称性$n \times n$网格，而不是单个边缘选择。 这表明答案必须是以下函数$n$独自的。 
2. 认识到每个正方形在所需边缘方面都是对称的，但边缘在相邻正方形之间共享，从而产生耦合。 这种耦合确保局部贪婪推理不会在整个网格中独立传播。 
3. 将过程重新表述为边的顺序分配，其中每条边可能对一个或两个方格做出贡献，并且所有权仅取决于谁执行每个方格的最终所需分配。 
4. 确定最佳游戏会带来全局配对或镜像策略。 一个玩家可以通过反映网格中心的移动来响应另一个玩家，除非网格有一个破坏对称性的结构中心。 
5. 确定是否存在完美的中心对称取决于是否$n$是偶数还是奇数。 什么时候$n$是偶数，每条边都有一个对称的对应边。 什么时候$n$奇怪的是，存在着无法完美配对的中心不平衡。 
6. 根据这种对称性破坏得出结果：偶数大小的网格允许完全镜像，从而导致强制平衡，而奇数大小的网格则为第一个玩家提供了控制无与伦比的中心交互的结构优势。 

### 为什么它有效

 不变的是，每次移动后，剩余的未着色边缘可以在网格的反射下划分成对称对。 在均匀大小的网格中，这种配对是完美的，允许第二个玩家始终以镜像位置做出响应，确保两种颜色的进展相同并强制平局。 在奇数大小的网格中，中心存在一个独特的不成对的结构，无法镜像，允许第一个玩家最终比第二个玩家强制至少一个额外的完整方块。 由于每个优势都通过完整的方格所有权传播，并且一旦方格完全确定就无法抵消，因此这种不变量保证了最终的结果分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n % 2 == 0:
    print("Draw")
else:
    print("Kelin")
```该实现将整个游戏简化为检查奇偶校验$n$。 原因是只有奇数维度才会在网格的反射结构中产生不可避免的不对称性。 甚至维度也为第二个玩家提供了完美的配对策略，从而抵消了任何先手优势。 

该代码避免了任何网格构建或模拟。 它直接使用导出的结构不变量，使其时间恒定并且对于最大约束是安全的$n = 10^9$。

 ## 边缘情况

 对于$n = 1$，网格由具有四个边的单个正方形组成。 第一个玩家先移动，但由于最终结果取决于最优边缘分布，对称性论证仍然适用于其退化形式：没有办法在完美的最小结构中创建第二个玩家的劣势，因此奇偶规则将其分类为 Kelin。 

为了$n = 2$，网格在两个轴上具有完全反射对称性。 每条边都有对应的边，独行的任何举动都可以被克林镜像。 从概念上追踪游戏，每次移动后，剩余的未着色边缘保持对称，确保没有玩家积累不可避免的优势。 最终的输出是Draw。 

为了$n = 3$，有一个中心细胞打破了完全配对对称性。 任何镜像移动的尝试最终都会在中心区域失败，从而允许“独行”迫使至少一个完整的方格。 这种不成对的结构正是科林在最终结果分类中产生优势的原因。
