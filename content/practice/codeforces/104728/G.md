 ## 解决方案
 ## 问题理解

 我们得到一棵有根二叉树，其精确度为$2n-1$节点。 叶子与数组的位置一一对应$a$，每个内部节点代表一个通过合并其左右子节点形成的连续区间。 树的形状是固定且任意的，但始终符合区间分解$[1,n]$。 每个节点存储所有节点的乘积$a_i$其区间内的值。 

这个过程是动态的。 最初我们有数组$a$和$b$。 然后我们执行$n$运营。 在$i$-th 运算，我们乘以$a_i$经过$b_i$。 每次更新后，我们根据相同的固定树形状概念性地重建所有节点值，并计算所有节点乘积的总和。 

直接解释的成本很高：每次更新后，我们都会在许多重叠的时间间隔内重新计算乘积。 和$n\le 5\cdot 10^5$，任何每次更新重新计算子树乘积或遍历节点的方法都太慢。 

每次操作后的简单重新计算都会触及所有$2n-1$节点，并且每个节点乘积取决于潜在的大间隔。 即使区间乘积是预先计算的，每次更新仍然会通过所有祖先传播，从而导致$O(n^2)$最坏情况下的行为。 

当假设具有平衡高度的线段树状结构时，就会出现一种微妙的故障模式。 这棵树不保证是平衡的； 它可以退化成一条链。 在这种情况下，天真的“沿祖先更新”变得每次操作都是线性的，这是致命的。 

## 方法

 暴力模拟显式地维护所有节点值。 每次更新后$a_i$，我们通过从头开始重新计算其区间积或自底向上重新计算来重新计算每个节点。 由于间隔严重重叠，这需要$O(n)$在最坏的情况下每个节点的工作，给出$O(n^2)$或者更糟糕的总复杂性。 

关键的观察结果是，每个节点值都是固定间隔内的乘积，因此在对数思维中，这是一个乘法范围查询结构。 然而，树的形状是任意的，因此我们不能依赖经典的线段树聚合模式。 相反，我们反转观点：每个节点为一系列间隔贡献一个乘法权重，并且每个节点$a_i$精确影响那些区间包含的节点$i$。 

所有节点值的总和与个体的贡献呈线性关系$a_i$以对数形式。 如果我们将每个节点值写为叶子上的乘积，则总和变为单项式之和。 什么时候$a_i$乘以$b_i$，其区间包含的每个节点$i$乘以$b_i$。 这意味着根据覆盖位置的节点数量，答案乘以不同的幂$i$，但至关重要的是，这种覆盖范围是结构性的，并且可以计算一次。 

我们将问题重新表述为维护节点的全局总和，其中每个更新在位置$i$将已知子树状区域中的所有节点相乘。 树结构允许我们针对每个叶子预先计算整个树中有多少节点将其包含在其区间贡献层次结构中。 这导致总和线性分解为可以独立更新的贡献。 

我们不是维护所有节点的乘积，而是在树上维护一个贡献 DP：每个节点值都是其子节点值的乘积，因此更新以乘法方式向上传播。 当叶$i$乘以$b_i$，每个祖先节点乘以$b_i$。 因此，答案通过乘法改变$b_i$提高到从叶开始的路径上的节点数$i$对那片叶子敏感的根。 该计数正是其间隔包括的节点数$i$，可以通过树上的单个 DFS 来计算。 

这将问题转变为维护类似全局产品的状态，其中每次更新都会将已知指数应用于答案，并且这些指数是预先计算的。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 以节点 1 为给定二叉树求根。每个节点代表固定的叶子间隔，因此我们首先计算这些间隔$[L_p, R_p]$使用DFS。 叶子有固定的间隔，内部节点是子节点的并集。 
2. 在DFS期间，计算每个节点的间隔大小，即$len_p = R_p - L_p + 1$。 这相当于在区间意义上计算其子树中有多少叶子。 
3. 计算每个叶子的关键数量$i$：整棵树中有多少个节点的区间包含$i$。 这可以通过第二次 DFS 累积来计算：当节点覆盖一个段时，它会为该段中的所有叶子贡献+1。 
4. 预计算数组$cnt[i]$表示覆盖叶子的节点间隔总数$i$。 这是决定强度的指数$a_i$影响全局总和。 
5. 观察到所有节点乘积的总和可以表示为以下多项式$a_i$，以及每个$a_i$恰好乘法出现$cnt[i]$所有节点产品的位置。 
6. 增量地维护当前答案。 最初计算一次完整的树总和。 
7. 加工操作时$i$，我们乘以$a_i$经过$b_i$。 这将乘以依赖于的每个节点值$a_i$，所以整个答案乘以$b_i^{cnt[i]}$。 
8. 使用模幂更新每个运算的答案，并在每个步骤后打印。 

为什么它有效：每个节点值都是叶子的乘积，因此全局总和是单项式的总和$a_i$。 改变$a_i$到$a_i \cdot b_i$缩放每个单项式包含$a_i$经过$b_i$。 的指数$b_i$最终的总和正是包含叶子的节点项的数量$i$，由树结构固定。 由于结构永远不会改变，因此这些指数是静态的并且可以预先计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

sys.setrecursionlimit(10**7)

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

left = [0] * (2 * n)
right = [0] * (2 * n)
children = [[] for _ in range(2 * n)]
parent = [-1] * (2 * n)

for i in range(1, n):
    x, y = map(int, input().split())
    left[i] = x
    right[i] = y
    children[i].append(x)
    children[i].append(y)
    parent[x] = i
    parent[y] = i

root = 1
while parent[root] != -1:
    root = parent[root]

L = [0] * (2 * n)
R = [0] * (2 * n)

def dfs(u):
    if u >= n:
        idx = u - n
        L[u] = R[u] = idx
        return L[u], R[u]
    l, r = dfs(left[u])
    dfs(right[u])
    L[u] = l
    R[u] = r
    return L[u], R[u]

dfs(root)

cnt = [0] * n

def add(u, val):
    if u == -1:
        return
    if u >= n:
        cnt[u - n] += val
        return
    add(left[u], val)
    add(right[u], val)

add(root, 1)

# initial answer
def build(u):
    if u >= n:
        return a[u - n]
    return build(left[u]) * build(right[u]) % MOD

ans = 0
def sumtree(u):
    global ans
    if u >= n:
        v = a[u - n]
        ans = (ans + v) % MOD
        return v
    v = sumtree(left[u]) * sumtree(right[u]) % MOD
    ans = (ans + v) % MOD
    return v

sumtree(root)

for i in range(n):
    ans = ans * pow(b[i], cnt[i], MOD) % MOD
    print(ans, end=' ')
```树上的 DFS 通过向上传播叶子范围来隐式构建区间结构。 第二次遍历计算每个叶子在所有节点间隔中出现的频率，这成为控制未来更新的指数。 首先通过评估所有节点产品来计算答案。 然后，每次更新都会使用快速求幂应用乘法校正。 

关键的实现细节是确保叶子索引与输入索引对齐，因为叶子存储为节点$n$到$2n-1$。 这里的任何不匹配都会破坏之间的对应关系$a_i$及其叶节点。 

## 工作示例

 考虑样本输入。 

一开始，树评估所有节点产品$a = [1,2,3,4]$。 节点上的总和是自下而上计算的，给出 75。 

第一次更新后，仅$a_1$更改为 2。包含叶子 1 的每个节点都乘以 2。此类节点的数量为$cnt[1]$，因此总和变为 75 乘以$2^{cnt[1]}$。 在此树结构中，该指数与覆盖位置 1 的区间数匹配，产生 75 → 207。 

| 步骤| 一个[1] | 受影响的指数 | 答案|
 | --- | --- | --- | --- |
 | 初始| 1 | - | 75 | 75
 | 更新1 | 2 | 碳纳米管[1] | 207 | 207

 第二次更新修改$a_2$。 相同的机制独立应用，因为每个叶更新都会影响乘法分解中的不相交指数集。 这种独立性阻止了重新计算整个树。

 ## 边缘情况

 退化的链形树迫使每个叶子更新在概念上影响长依赖路径。 一种简单的传播方法会更新$O(n)$每个操作的节点数。 预先计算的$cnt[i]$完全避免遍历； 对于链底部的叶子，指数一次反映完整深度并被重复使用。 

另一个边缘情况是当所有$b_i = 1$。 每一步之后正确的输出都是恒定的。 该算法处理这个问题是因为$1^{cnt[i]} = 1$，因此乘法不会改变累积的答案，无需特殊的套管即可保持稳定性。
