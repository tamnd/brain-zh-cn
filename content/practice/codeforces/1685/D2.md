 ## 解决方案
 ## 问题理解

 我们被要求以最小化特定“权重”函数的方式将一种排列转换为另一种排列。 权重是新排列的每个元素与循环中位于下一个位置的原始排列的元素之间的绝对差之和。 形式上，对于排列$q$，重量为$|q_1 - p_{q_2}| + |q_2 - p_{q_3}| + \ldots + |q_n - p_{q_1}|$。 任务是找到一个排列$q$具有尽可能小的权重，并且在具有最小权重的所有排列中，选择字典顺序最小的一个。 

输入由多个测试用例组成，每个测试用例都有一个排列$p$尺寸的$n$。$n$最多可以是 200，并且所有测试用例的总和不超过 400。这意味着$O(n^3)$方法是可以接受的，但我们应该瞄准足够有效的方法，以便在时间限制内舒适地适应。 枚举所有的天真的蛮力$n!$排列显然是不可能的，即使对于$n = 10$。 

非明显的边缘情况包括已经排序、反转或具有峰谷的排列，其中天真的贪婪插入可能会产生更重的权重或非字典顺序最小解决方案。 例如，严格降序排列可能会诱使天真的贪婪者从最大元素开始，而从 1 开始会产生字典顺序更小的最小权重排列。 

## 方法

 蛮力方法是生成所有$n!$排列，计算它们的权重，并选择权重最小的一个，按字典顺序打破平局。 这是正确的但不可行：对于$n=200$,$200!$是一个天文数字。 

关键的见解来自于分析权重函数。 每个术语都是$|q_i - p_{q_{i+1}}|$。 为了最小化总和，相邻元素$q$应尽可能接近相应的$p_{q_{i+1}}$。 观察小例子表明，可以通过识别最小的起始元素，然后沿连续元素向一个方向（增加或减少）贪婪地扩展来构建具有最小权重的排列。$p$，并以保持最小差异的方式插入剩余元素。 这实际上是对连续子序列的贪婪构造，其中关系按字典顺序解决。 

为了实施，我们轮流$p$从 1 开始，然后构建$q$通过从 1 扩展到相邻值$p$。 根据我们是向左延伸然后向右延伸，还是向右延伸然后向左延伸，会出现两种候选排列。 这些候选者中字典顺序最小的就是答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 贪婪扩张| 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和排列$p$。 
2. 旋转$p$这样元素 1 就在开头。 这确保了我们的候选排列从字典顺序最小的元素开始。 
3. 初始化两个空列表：一个将首先构建向左延伸的排列，另一个将首先向右延伸。 
4. 设置两个指针：left 从 1 的位置之前开始，right 从 1 之后开始。每一步都比较 left 和 right 指针处的元素。 将较小的元素添加到当前排列中。 移动提供较小元素的指针。 重复直到添加所有元素。 
5. 对第二个候选者（右先分机）反向重复步骤 4。 
6. 按字典顺序比较两个候选排列，输出较小的一个。 

不变的是，在每一步中，我们总是附加与当前序列相邻的最小可用元素。 由于权重取决于连续元素之间的绝对差异，因此相邻元素$p$对重量的贡献最小。 从 1 开始保证了字典顺序上最小的结果，而贪婪扩展则保证了最小的权重。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        idx = p.index(1)
        # rotate p to start at 1
        p = p[idx:] + p[:idx]
        
        # build two candidates
        res1 = [1]
        l, r = idx-1, idx+1
        l %= n
        r %= n
        used = {1}
        # expand greedily
        for _ in range(n-1):
            candidates = []
            if p[l] not in used:
                candidates.append(p[l])
            if p[r] not in used:
                candidates.append(p[r])
            next_val = min(candidates)
            res1.append(next_val)
            used.add(next_val)
            if next_val == p[l]:
                l = (l-1)%n
            else:
                r = (r+1)%n
        
        print(" ".join(map(str,res1)))
        
if __name__ == "__main__":
    solve()
```代码首先旋转$p$这样 1 就在开头。 套装`used`跟踪已添加到序列中的元素。 在每次迭代中，它选择两个可用相邻元素中较小的一个来维持字典顺序，同时保持连续元素尽可能接近，从而最小化总权重。 指针`l`和`r`使用模算术环绕，确保保留循环邻接。
