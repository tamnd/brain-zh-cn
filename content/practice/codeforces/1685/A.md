 ## 解决方案
 ## 问题理解

 我们被要求在一个圆上排列一组整数，使得每个数字要么严格大于或严格小于其两个邻居。 输入由多个测试用例组成。 每个测试用例提供整数的数量，后跟整数本身。 输出应该确认这种圆形排列是可能的以及一种有效的排列，或者指示不可能性。 

关键是每个数字必须在循环顺序中形成“局部最大值”或“局部最小值”。 由于排列是圆形的，第一个和最后一个元素是相邻的，因此必须注意边界。 一种简单的方法可能会尝试所有排列来检查有效性，但对于一个测试用例中多达 100,000 个数字和 30,000 个测试用例，这在计算上是不可能的。 这暗示该解决方案本质上必须是建设性的、线性的或线性算数的。 

边缘情况包括所有元素都相等的数组，这是不可能的，因为没有元素可以严格大于或小于邻居。 对于小型数组，尤其是大小为 3 的数组，如果元素不明确或不适当平衡，也可能会很棘手。 

## 方法

 暴力方法将生成数组的每个排列并检查它是否满足局部最小-最大条件。 这在原则上是正确的，但具有阶乘时间复杂度 O(n!)，对于 n 高达 10^5 来说这是不切实际的。 

最佳解决方案的关键在于，为了满足最小-最大模式，我们可以将排序后的数组分成两半：较小的一半和较大的一半。 通过对它们进行交错，从较小的一半中取出一个元素，然后从较大的一半中取出一个元素，并继续这种模式，我们可以确保每个数字交替小于和大于其邻居。 如果最大的一半最多比较小的一半多一个元素，则这种交错总是可以产生一个有效的圆。 如果有太多相同的值，则会失败。 

排序交错之所以有效，是因为将最小的数字放置在最大的数字之间可以确保满足严格的不平等性。 排序使我们能够控制哪些元素比其邻居小或大。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（排列检查）| O(n!) | O(n) | 太慢了|
 | 建设性交错| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将数组按升序排序。 这让我们可以清楚地区分较小和较大的数字，并保证我们的交错策略将保持严格的不平等。 
2. 将数组分成两半。 让前半部分包含较小的数字，后半部分包含较大的数字。 如果 n 为奇数，则后半部分将多包含一个元素。 
3. 通过将较小一半的元素放置在偶数索引处并将较大一半的元素放置在奇数索引处（或反之亦然），将两半交错。 这确保每个元素都有来自另一半的邻居，从而强制执行最小-最大条件。 
4. 如果在任何时候较小的一半的最大数等于或大于较大的一半的最小数，则构造是不可能的。 否则，打印“YES”和交错数组。 

工作原理：通过将最小的可用数字放在两个较大的数字之间，将最大的数字放在两个较小的数字之间，我们保证每个元素严格大于或小于其邻居。 排序和交错保留了此属性，并且由于数组是循环的，因此最后一个和第一个元素也将满足该条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        half = n // 2
        if a[half-1] == a[half]:
            print("NO")
            continue
        res = []
        left = a[:half]
        right = a[half:]
        for i in range(half):
            res.append(left[i])
            res.append(right[i])
        if n % 2 == 1:
            res.append(right[-1])
        print("YES")
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量。 对于每个测试用例，它都会读取数组并对其进行排序。 支票`a[half-1] == a[half]`确保我们没有太多相等的数字来满足严格的不等式。 左半部和右半部的交错产生有效的循环最小-最大序列。 如果 n 为奇数，则附加右半部分的最后一个元素以完成循环。

 ## 边缘情况

 对于`n=3`并输入`[1,1,2]`, 左半部分`[1]`和右半边`[1,2]`具有边界相等性。 该算法检测到`a[half-1] == a[half]`并正确输出`NO`。 为了`n=6`和`[1,1,1,11,111,1111]`，排序后的数组`[1,1,1,11,111,1111]`分成左边`[1,1,1]`和对的`[11,111,1111]`。 交错产生`[1,11,1,111,1,1111]`，满足循环最小-最大性质。 该算法可以优雅地处理这两种情况。
