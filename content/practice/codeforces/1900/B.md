 ## 解决方案
 ## 问题理解

 问题提出了一组仅由`1`,`2`， 和`3`。 我们得到了计数`a`,`b`， 和`c`对于每个数字，代表次数`1`,`2`， 和`3`分别出现在黑板上。 劳拉可以执行一次操作，选择两个不同的数字，擦除它们，然后写入未选择的第三个数字。 任务是确定对于每个测试用例，通过一系列操作可以实现哪些个位数配置。 输出是三个整数，每个整数要么`0`或者`1`，表明是否有可能最终只有`1`s，仅`2`s，或仅`3`s 在黑板上。 

就每个测试用例的位数而言，限制是慷慨的，`1 ≤ a, b, c ≤ 100`，以及大量的测试用例，高达`10^5`。 这意味着该解决方案必须在每个测试用例中以接近恒定的时间运行，因为明确地迭代所有可能的操作是不可行的。 关键的挑战是捕获操作的组合效果而不直接模拟它们。 边缘情况包括所有计数相等或两个计数正好相差 1 的情况，因为这些情况会影响是否可以实现单位数配置。 

例如，如果输入是`a = 1, b = 1, c = 1`，三个数字中的任何一个都可以单独产生。 简单的模拟可能会使这一过程变得过于复杂，并且会错过结果的对称性。 同样，如果`a = 2, b = 3, c = 2`， 仅有的`2`可以单独得出，并且无法推理计数奇偶性可能会产生错误的答案。 

## 方法

 暴力方法是模拟每个操作序列，直到只剩下一种类型的数字或无法进行任何操作。 我们可以将棋盘表示为多重集并重复应用所有有效操作。 虽然正确，但这种方法的最坏情况将大致与位数的阶乘成正比，因为每次操作都会将棋盘减少一，从而导致`O((a+b+c)!)`复杂性，考虑到计数达到 100，这是很棘手的。 

关键的见解是关注奇偶校验而不是完全模拟。 每个操作将两个不同的计数减一，并将第三个计数加一。 这以可预测的方式保留了模 2 的和。 具体来说，对于一个数字`x`作为唯一剩余的类型，其他两位数字的奇偶性很重要。 例如，如果我们只想`1`剩下的，我们必须能够减少`b`和`c`通过将它们转换为的操作同时归零`1`s。 通过基于模 2 的计数来推理哪些组合是可以达到的，我们可以直接确定可行性，而无需模拟。 

这种洞察力使我们能够在每个测试用例的恒定时间内计算答案：使用简单的计数算术检查每个单位数目标是否可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((a+b+c)!) | O(a+b+c) | 太慢了 |
 | 奇偶分析 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取计数`a`,`b`,`c`。 这些代表当前的数字数量`1`,`2`,`3`。 
2. 初始化三个零的输出列表`[0, 0, 0]`代表是否为数字`1`,`2`,`3`可能是唯一剩下的类型。 
3. 判断是否仅`1`s 可以保留，检查是否`a`是非零并且如果`b`和`c`也不算太小。 具体来说，仅`1`s 是可能的，如果`b`和`c`要么都为零，要么它们的奇偶校验允许它们完全转换为`1`通过操作。 将输出列表的第一个元素设置为`1`如果可行的话。 
4. 对数字重复对称检查`2`和`3`，相应地设置输出列表的第二个和第三个元素。 
5. 打印当前测试用例的输出列表。 

为什么它有效：不变的是任何运算都会保留模 2 的数字总和，并且总是用第三个数字替换两个不同的数字。 使用奇偶校验，我们可以预测重复应用这些操作是否可以将两种类型的数字减少为零，同时使一种类型非零。 这保证了无需详尽模拟的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
res = []

for _ in range(t):
    a, b, c = map(int, input().split())
    answer = [0, 0, 0]
    
    digits = [a, b, c]
    
    for i in range(3):
        # If target digit count is non-zero
        if digits[i] > 0:
            # The other two digits
            j, k = (i+1)%3, (i+2)%3
            # If difference between the other two is <= 1, we can convert all to i
            if abs(digits[j] - digits[k]) <= 1:
                answer[i] = 1
    
    print(*answer)
```该代码读取测试用例的数量，然后迭代每个测试用例，根据非目标数字的奇偶校验差异计算可行性。 模运算`(i+1)%3`和`(i+2)%3`确保我们正确识别其他两位数字，无论目标如何。 我们检查其他两位数字的计数最多相差 1，这使得它们可以通过仅产生目标数字的操作减少到零。 这避免了不必要的循环并处理所有约束。
