 ## 解决方案
 ## 问题理解

 我们得到了从 1 到$n$以及一系列查询，要求从子数组中重复删除局部最小值和最大值，直到只剩下一个元素。 局部最小值是小于其邻居的任何元素（两端只有一个邻居），局部最大值是大于其邻居的任何元素。 删除过程交替进行：首先删除除局部最小值之外的所有内容，然后删除除局部最大值之外的所有内容，并重复直到剩下一个元素。 目标是有效计算每个查询的最终幸存元素。 

自从$n$和$q$两者都可以达到$10^5$，模拟每个删除步骤的简单方法会太慢。 考虑大小的子数组$n$交替高-低-高-低......； 每个删除步骤可以删除大约一半的元素，因此简单的模拟可能需要$O(n \log n)$每个查询，大致导致$10^5 \cdot 17 \approx 1.7 \cdot 10^6$每个查询的操作。 这似乎是可接受的，但如果子数组是完整数组并且许多查询重叠，则重复重新计算所有内容将超出时间限制。 我们需要一个更接近的解决方案$O(n + q)$或者$O(n \log n + q)$总共。 

边缘情况包括单元素子数组（其中答案通常是元素本身）和双元素子数组（其中第一次删除可能已经产生最终元素）。 另一个微妙之处是，严格递增或递减的子数组会快速折叠到第一个或最后一个元素，具体取决于首先发生的操作。 

## 方法

 暴力破解的方法是直接模拟删除过程。 对于每个查询，提取子数组并重复扫描它以识别局部最小值或最大值，删除其他子数组，然后继续，直到剩下一个元素。 这种方法之所以有效，是因为它忠实地实现了规则，但是在大型数组或大量查询上它变得太慢，因为每次扫描都是$O(k)$对于长度的子数组$k$，扫描次数为对数$k$。 

更快解决方案的关键见解来自于观察此过程下的排列结构。 在第一次局部最小值删除之后，只有原始子数组中的“谷”元素得以幸存。 在第二次局部最大值删除之后，幸存元素中只有峰值幸存。 至关重要的是，如果子数组的长度为 1 或 2，则答案是立即的。 对于较大的子数组，我们可以看到，在两次删除（最小值然后最大值）之后，幸存的元素形成严格位于其邻居之间的子序列。 在排列中，子数组的第一个和最后一个元素充当锚点：它们通常会幸存，因为它们是仅相对于一个邻居的局部极值。 通过这种观察，我们可以通过检查子数组的前几个元素和后几个元素的局部结构来避免完全模拟，从而允许每个查询进行恒定时间计算。 

最终的解决方案使用预先计算的左右邻居比较的组合来识别幸存元素，而无需模拟所有删除步骤。 本质上，幸存元素是第一个内部局部最小值或最大值（如果存在），否则是第一个或最后一个元素。

 ## 算法演练

 1. 预先计算排列的连续元素之间的差异数组。 这允许快速识别增加和减少$O(1)$每个邻居检查。 
2. 对于每个查询，提取索引$l$和$r$。 如果$l = r$，立即返回$a[l]$。 如果$r = l + 1$，返回最小值$a[l]$和$a[r]$如果第一个操作是类型 1，或者最大操作是类型 2。这些处理基本情况。 
3. 否则，检查子数组的前三个元素：$a[l], a[l+1], a[l+2]$。 如果子数组以局部最小值开始（第一个元素小于第二个元素），则它会在第一次操作中幸存下来。 如果不是，则前两个元素中的局部最小值是第一次操作后的幸存候选者。 
4. 同样，检查最后三个元素$a[r-2], a[r-1], a[r]$。 如果最后一个元素是局部最小值，它可能会在第一次操作中幸存下来。 此检查主要与最小值位于末尾的边缘情况相关。 
5. 一旦确定了第一个局部最小值删除的候选者，检查其中哪些在第二次删除（局部最大值）中幸存下来。 在排列中，这相当于在幸存的最小值中取最大的。 这可以使用预先计算的比较在恒定时间内完成。 
6. 返回幸存元素。 

为什么有效：该算法利用了排列是不同整数的序列这一事实。 第一次删除始终保留局部最小值元素的子集。 由于所有元素都是不同的，因此这些最小值由更大的数字分隔。 第二次删除仅保留其中的最大值。 在排列中，这种结构保证了两次删除后最多保留一个元素，并且仅通过比较边缘的一个小窗口就可以确定幸存的元素，避免了完全模拟。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
a = list(map(int, input().split()))

for _ in range(q):
    l, r = map(int, input().split())
    l -= 1
    r -= 1
    length = r - l + 1

    if length == 1:
        print(a[l])
        continue
    if length == 2:
        print(max(a[l], a[r]))
        continue

    # identify first deletion (local minima)
    if a[l] < a[l+1]:
        first_candidate = a[l]
    elif a[r] < a[r-1]:
        first_candidate = a[r]
    else:
        # pick first local minimum inside
        for i in range(l+1, r):
            if a[i] < a[i-1] and a[i] < a[i+1]:
                first_candidate = a[i]
                break
    # after second deletion (local maxima), pick largest surviving
    left_val = a[l]
    right_val = a[r]
    middle_val = first_candidate
    print(max(left_val, middle_val, right_val))
```该解决方案首先直接处理大小为 1 或 2 的子数组。 对于较长的子数组，它通过检查边缘和内部位置来识别第一次删除时局部最小值的候选者。 由于排列是不同的，因此在第一次删除后，我们只需要考虑幸存元素中的最大值。 该代码通过取候选局部最小值和子数组结尾中的最大值来计算此值。
