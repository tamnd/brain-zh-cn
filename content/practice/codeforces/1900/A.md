 ## 问题理解

 我们得到一排单元格，其中每个位置要么可用，要么被阻止。 只有可用的位置才能容纳水，而被阻挡的位置则充当永久性的墙壁，将线路分成独立的区域。 最初，不存在水，目标是确保每个可用的细胞最终都含有水。 

我们可以明确地将水放入任何空的可用单元格中，这是我们被要求计数的唯一操作。 第二个操作允许我们在空单元之间移动水，但这种移动可以是任意的，并且在物镜中不带电。 还有一个传播规则：如果一个空的可用单元两侧都立即有水，它将自动充满。 

任务是尽量减少直接放置水的次数，同时仍然能够通过放置、移动和传播最终填充每个可用的单元格。 

每个测试用例的单元数量最多为 100 个，这消除了对线性扫描之外的高级数据结构或优化的任何需求。 任何二次或更差的字符串解决方案仍然是安全的，但问题的结构强烈表明答案仅取决于局部模式而不是全局搜索。 

当空段很长但以不同方式包围时，就会出现微妙的失败情况。 例如，考虑没有任何内墙的一长段点。 一种幼稚的方法可能假设每个点都需要水，但仅从两个战略性放置的源传播就可以填满整个部分。 另一种边缘情况是当该段被阻塞的单元中断时，这会重置传播并使每个段独立。 

## 方法

 如果我们忽略传播规则，问题就会退化为简单地将水放入每个空单元中，这基本上是正确的，但完全忽略了优化。 这种幼稚的策略对每个点进行一次操作，并且当存在长的连续段时，显然变得次优。 

一种稍微深思熟虑的蛮力方法会尝试所有放置水的位置的选择并模拟传播。 对于长度为 n 的线段，选择 k 个放置位置会导致 C(n, k) 数量级的组合，并且每次模拟的时间复杂度为 O(n)，因此即使对于中等 n 的情况也是不可行的。 

关键的观察结果是，传播仅取决于连续的空细胞块的两端都有水。 一旦段中存在两个水源，它们之间的所有内容都可以被填充，并且段内不需要额外的放置。 这将问题简化为决定如何将“锚点”最佳地放置在“.”的每个最大连续段内。 人物。 

对于长度为 L 的线段，在两端放置水会填充中间的所有内容，因此单个线段大约贡献 ceil(L / 2) 个放置，因为每对放置可以覆盖它们之间的一个方块。 阻塞的单元会重置此逻辑，因此每个段都可以独立处理。

 | ---| ---| ---| ---|
 | 暴力模拟| 指数| O(n) | 太慢了 |
 | 贪心线段配对| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们处理字符串并隔离“.”的最大连续段 细胞。 每个这样的片段都是独立处理的，因为阻塞的细胞阻止了它们之间的任何相互作用。

1. 从左到右扫描字符串，识别出一段连续的“.” 人物。 该段是唯一水可以连续传播的区域。 
2. 对于长度为 L 的线段，计算从末端向内配对单元需要多少次放置。 在最好的情况下，每个位置都可以有效地填充两个单元格，奇数长度段中的中间部分可能除外。 
3. 因此，一个段所需的放置数量为 (L + 1) // 2。 
4. 对所有以“#”分隔的段计算该值的总和。 
5. 返回总数作为答案。 

配对背后的直觉是，当单个水位可以充当传播的两个边界源之一时，它是最有效的。 通过配对细胞，我们确保每个位置都最大限度地有助于向内扩散水。 

### 为什么它有效

 由于有阻挡墙，每段空单元都是独立的。 在一个分段内，只有当单元格可以夹在两个水源之间时，单元格才会被填充。 这意味着完全填充段的任何配置都必须隐式定义至少一对“覆盖”每个内部区域的放置。 最佳策略是重复使用每个位置作为多个此类对的一侧，这正是配对连续单元所实现的效果。 公式 (L + 1) // 2 捕获在两邻居激活规则下覆盖线性链所需的最小端点数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input().strip())
    s = input().strip()

    ans = 0
    i = 0

    while i < n:
        if s[i] == '#':
            i += 1
            continue

        j = i
        while j < n and s[j] == '.':
            j += 1

        length = j - i
        ans += (length + 1) // 2

        i = j

    print(ans)
```该代码依赖于单个线性扫描。 每当出现一个“.”块时 找到字符后，在应用分段公式之前将其完全展开。 关键的实现细节是从 i 到 j 的跳转，这确保每个字符只被处理一次。 

表达式 (length + 1) // 2 直接实现了前面讨论的配对逻辑。 整数除法统一处理偶数和奇数情况，避免特殊情况分支。

 ## 边缘情况

 单点输入，例如`.`形成长度为 1 的线段。算法计算 (1 + 1) // 2 = 1，正确反映需要单个放置。 

完全阻止的输入，例如`#####`根本不产生任何段。 扫描永远不会进入分段处理分支，因此累积的答案保持为零，这与没有细胞需要水的事实相匹配。 

像这样的交替模式`.#.#.`分成长度为 1 的多个段。每个段贡献一个操作，段的独立性确保最终结果只是孤立单元的总和，从而确认阻塞单元完全重置传播边界。
