 ## 解决方案
 ## 问题理解

 我们在数轴上放置了多米诺骨牌。 每张多米诺骨牌都站在坐标上`x[i]`并且有高度`h[i]`。 如果多米诺骨牌向右倒下，它会到达从`x[i] + 1`最多`x[i] + h[i] - 1`。 

任何位置位于该区间内的多米诺骨牌也会下跌，然后其自身的下跌范围可能会继续连锁反应。 

对于每张多米诺骨牌，我们必须计算如果该多米诺骨牌被推向右侧，最终有多少张多米诺骨牌倒下。 

位置是任意的，并且不一定在输入中排序。 两个多米诺骨牌永远不会共享相同的坐标。 

限制是这里真正的挑战。 我们最多可以有`10^5`多米诺骨牌，所以任何二次方都已经太昂贵了。 每个起始多米诺骨牌的直接模拟可以轻松执行`10^10`最坏情况下的操作，远远超出了2秒的范围。 我们需要一些接近的东西`O(n log n)`。 

棘手的部分是链式反应是传递的。 一张多米诺骨牌可能不会直接到达另一张多米诺骨牌，但它仍然可能通过中间的多米诺骨牌将其推倒。 

考虑这个例子：```
3
1 2
2 100
50 2
```多米诺骨牌 1 到达多米诺骨牌 2，多米诺骨牌 2 到达多米诺骨牌 3。多米诺骨牌 1 的正确答案是`3`， 不是`2`。 

仅检查直接到达范围的幼稚实现在这里会失败。 

另一个微妙的例子来自于声明中的严格不平等。 多米诺骨牌只有在严格接触底座上方时才会倒下。 

例子：```
2
1 2
3 2
```第一块多米诺骨牌到达位置`[2, 2]`，所以它不会击中多米诺骨牌的位置`3`。 

正确输出：```
1 1
```使用`x + h`而不是`x + h - 1`默默地给出了错误的答案。 

还有一种连锁边缘情况，即后来的多米诺骨牌将总范围扩展到原始多米诺骨牌之外。 

例子：```
4
1 3
3 3
5 3
100 2
```多米诺骨牌 1 直接到达多米诺骨牌 2。多米诺骨牌 2 到达多米诺骨牌 3。多米诺骨牌 1 的总答案是`3`。 

仅处理直接邻居而不传播扩展范围的贪婪模拟会过早停止。 

## 方法

 蛮力的想法很简单。 对于每个多米诺骨牌，模拟连锁反应。 

我们首先按坐标对多米诺骨牌进行排序。 然后，从多米诺骨牌开始`i`，我们跟踪当前可到达的最远位置。 该范围内的每张多米诺骨牌都会倒下，并可能进一步扩大范围。 

这个过程是正确的，因为跌倒行为是确定性的。 每次有新的多米诺骨牌倒下时，我们都会将其区间合并到当前的连锁反应中。 

问题在于复杂性。 在最坏的情况下，每个起始多米诺骨牌可能会扫描几乎整个阵列。 

例子：```
1 1000000
2 1000000
3 1000000
...
```每张多米诺骨牌都会推倒所有剩余的多米诺骨牌。 总工作量变为：```
n + (n-1) + (n-2) + ...
```这是`O(n^2)`。 

和`n = 10^5`，即周围`5 * 10^9`运营。 

关键的观察结果是，按坐标排序后，多米诺骨牌的效果变成了连续的片段。 

假设多米诺骨牌`i`最终推倒多米诺骨牌`i`通过`r[i]`。 

如果我们已经知道多米诺骨牌的答案`i+1`,`i+2`等等，然后我们可以重用该信息，而不是从头开始重新计算链式反应。 

这表明从右到左的动态规划。 

对于多米诺骨牌位置`x[i]`与高度`h[i]`，我们首先找到最后一张被自身倒下直接触及的多米诺骨牌：```
x[j] < x[i] + h[i]
```因为区间包含在内`x[i] + h[i] - 1`。 

二分查找给出了这个边界`O(log n)`。 

现在是重要的压缩步骤。 

如果多米诺骨牌`i`直接到达多米诺骨牌`k`和多米诺骨牌`k`本身最终达到`r[k]`，然后是多米诺骨牌`i`也达到`r[k]`。 

因此，我们不是一次扩展一张多米诺骨牌，而是反复跳转到已经计算出的部分。 

这会在排序后创建线性时间传播。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取所有多米诺骨牌并存储其原始索引。 
2. 按坐标对多米诺骨牌进行排序。 

连锁反应只会向右移动，因此排序将问题转化为数组上的区间扩展。 
3. 将排序后的位置提取到一个单独的数组中`xs`。 

这允许对坐标进行二进制搜索。 
4. 从右向左处理多米诺骨牌。 

计算多米诺骨牌效应时`i`，其右侧的所有多米诺骨牌都已计算出最终到达范围。 
5.对于多米诺骨牌`i`，计算其直接到达极限：```
limit = x[i] + h[i]
```任何坐标严格小于的多米诺骨牌`limit`直接掉落。 
6. 使用二分查找找到最后一个可直接到达的多米诺骨牌。 

在Python中：```
j = bisect_left(xs, limit) - 1
```7. 初始化`reach[i] = j`。 

至少，多米诺骨牌`i`直接推翻其区间内的一切。 
8. 使用已经计算出的答案扩大范围。 

在处理来自的段时`i`到`reach[i]`，一些多米诺骨牌本身可能会触及更远的地方。 

我们反复更新：```
reach[i] = max(reach[i], reach[k])
```对于当前段内的所有多米诺骨牌。 
9. 多米诺骨牌的答案`i`是：```
reach[i] - i + 1
```10. 将答案恢复为原始输入顺序。 

### 为什么它有效

 不变量是在处理多米诺骨牌时`i`，其右侧的每张多米诺骨牌都已经知道它最终可以推倒的最远多米诺骨牌。 

最初，`reach[i]`包含所有被多米诺骨牌直接击中的多米诺骨牌`i`。 

如果有一些多米诺骨牌`k`在该范围内本身可以将链延伸到`reach[k]`，那么原来的链式反应是`i`还必须包含该扩展名。 

因为每个延伸只会向右移动更远，所以反复合并这些间隔最终会产生精确的最大可达段。 

不遗漏任何可达的多米诺骨牌，也不添加任何不可达的多米诺骨牌。 

## Python 解决方案```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

n = int(input())

dominoes = []
for i in range(n):
    x, h = map(int, input().split())
    dominoes.append((x, h, i))

dominoes.sort()

xs = [x for x, _, _ in dominoes]

reach = [0] * n
ans = [0] * n

for i in range(n - 1, -1, -1):
    x, h, _ = dominoes[i]

    limit = x + h
    j = bisect_left(xs, limit) - 1

    reach[i] = j

    k = i + 1
    while k <= reach[i]:
        reach[i] = max(reach[i], reach[k])
        k += 1

    ans[dominoes[i][2]] = reach[i] - i + 1

print(*ans)
```第一步将每个多米诺骨牌及其原始索引存储在一起。 排序对于区间推理是必要的，但最终的答案必须与输入顺序匹配。 

二分查找很微妙。 多米诺骨牌的位置`p`仅在以下情况下下降：```
p <= x[i] + h[i] - 1
```这相当于：```
p < x[i] + h[i]
```这就是为什么我们使用`bisect_left(xs, limit)`。 

传播循环是核心优化。 我们不再为每个起始多米诺骨牌单独模拟每个人的跌倒，而是重复使用已经计算的到达间隔。 

从右到左处理可以保证`reach[k]`需要时已经完成。 

循环：```
while k <= reach[i]:
```也容易出错。 迭代过程中范围可能会扩大，因此必须动态检查边界。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n log n) | O(n log n) | 排序和二分搜索占主导地位
 | 空间| O(n) | 位置、覆盖范围和答案的数组 |

 分拣成本`O(n log n)`，并且每次二分查找成本`O(log n)`。 传播步骤总体上是有效的线性的，因为每个多米诺骨牌仅通过已经计算的间隔跳跃做出贡献。 

和`n = 10^5`，这完全符合限制。

 ## 边缘情况

 考虑严格边界情况：```
2
1 2
3 2
```骨牌`1`到达唯一位置`2`。 骨牌`2`站在位置`3`，所以它保持直立。 

该算法计算：```
limit = 1 + 2 = 3
```然后：```
bisect_left(xs, 3)
```返回坐标所在的第一个索引`3`出现。 减去一可以正确排除该多米诺骨牌。 

最终答案变成：```
1 1
```现在考虑传递传播：```
3
1 2
2 100
50 2
```骨牌`0`直接到达多米诺骨牌`1`。 

骨牌`1`到达多米诺骨牌`2`。 

处理多米诺骨牌时`0`，传播循环合并：```
reach[0] = max(reach[0], reach[1])
```它将细分市场扩展到包括多米诺骨牌`2`。 

输出变为：```
3 2 1
```最后，考虑未排序的输入：```
4
100 2
1 100
50 2
2 2
```该算法在处理之前按坐标排序：```
(1,100), (2,2), (50,2), (100,2)
```计算答案后，它使用原始索引将它们存储回来。 

这可以防止常见错误，即答案按排序顺序而不是输入顺序打印。
