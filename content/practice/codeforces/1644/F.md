 ## 解决方案
 ## 问题理解

 我们被要求覆盖所有可能的长度数组`n`其元素范围为`1`到`k`使用数组序列，其中序列中的每个数组都可以通过两个操作“生成”其他数组。 第一次手术，`F(a, k)`，拉伸每个元素`a`通过一些乘数并截断回长度`n`。 第二次手术，`G(a, x, y)`，交换所有出现的`x`和`y`。 

有效地，`F`允许我们重复元素以达到任何所需的频率模式，同时`G`允许我们在位置之间任意排列值。 面临的挑战是找到**起始数组的最小数量**，使得每个可能的长度数组`n`从数字`1..k`作为我们序列中某个数组的“祖先”是可以到达的。 

约束表明`n`和`k`每个最多可达200​​,000个，时间限制为6秒。 任何迭代所有方法`k^n`数组立即不可行，因为`k^n`是一个天文数字。 我们需要一种避免显式枚举数组的方法。 

边缘情况包括`n = 1`或者`k = 1`。 为了`k = 1`，每个数组都是相同的，因此单个数组就足够了。 为了`n = 1`，序列必须包含所有`k`自以来的数字`F`无法在单个元素数组中生成新数字。 小例子也说明了如何`F`和`G`相互作用以减少所需的阵列数量。 

## 方法

 一种简单的方法是显式构造每个长度的数组`n`超过`1..k`然后尝试用通过生成的序列覆盖它`F`和`G`。 这需要迭代`k^n`数组，这是不可能的`n > 10`由于组合爆炸。 即使使用巧妙的记忆法也无法避免组合核心。 

关键的见解是`F`使我们能够达到任何多重模式。 我们总是可以选择**元素数**跨度为 2 的幂的数组`n`，因为重复应用`F`允许我们创建任何频率配置。 同时地，`G`允许我们自由交换数字，因此实际值无关紧要——只有每个数字的计数很重要。 

因此，问题简化为：需要多少个阵列来覆盖**所有分区`n`进入`k`非负整数**，如果我们可以自由地相乘计数并自由地排列数字？ 答案来自组合学：所需的序列数是最少的`m`这样`k^m >= n`, 取模`998244353`。 序列中的每个阵列对应于频率扩展中的一个“位”。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n) | O(k^n) | O(k^n) | O(k^n) | 对于大 n | 不可行
 | 最佳 | O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.如果`k = 1`，那么只有一个数存在。 唯一可能的数组是`[1, 1, ..., 1]`。 返回`1`立即地。 
2. 否则，初始化一个计数器`res`为零和临时变量`cur`至 1。 
3.同时`cur < n`， 双倍的`cur`和增量`res`一个。 这将使用重复加倍来计算表示所有频率所需的最小阵列数。 
4. 乘法`res`以 1 为模`998244353`，因为问题明确要求取模。 
5、输出`res`。 

加倍循环之所以有效，是因为每次应用`F`允许我们将元素计数乘以任何正整数。 数组的最小数量对应于覆盖所需的加倍次数`n`使用权力`k`。 

**为什么起作用：** 通过将位置表示为频率功率的组合`k`，我们可以生成具有以下序列的任何目标数组`F`运营。 与 互换`G`消除对特定值的限制，因此只考虑物质。 加倍保证了所有长度的覆盖`n`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    if k == 1:
        print(1)
        return
    res = 0
    cur = 1
    while cur < n:
        cur *= k
        res += 1
    print(res % MOD)

solve()
```代码初始化`cur`到 1 来表示第一个数组，然后乘以`k`重复进行，直到计数超过`n`，计算所需的数组数量。 应用模数以确保符合问题约束。

 ## 边缘情况

 当`k = 1`，所有数组都是相同的。 我们的代码通过检查来处理它`k == 1`并返回`1`立即地。 这避免了循环加倍逻辑，这会错误地递增`res`。 

什么时候`n`远大于`k`， 例如`n = 2e5`和`k = 2`，加倍循环有效地计算`res = ceil(log_k(n)) = 18`，确认问题约束的方法规模。 

为最大`k`， 例如`k = n = 2e5`，单个数组就足够了，因为`F`是微不足道的，并且`G`允许任意交换，立即生成所有数组。 我们的代码输出`1`正确。
