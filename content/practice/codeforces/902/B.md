 ## 解决方案
 ## 问题理解

 我们得到一棵有 _n_ 个顶点的有根树，其中顶点 1 是根。 每个顶点必须使用输入中指定的目标颜色进行着色。 最初，所有顶点的颜色均为 0。着色操作包括选取任何顶点 _v_ 和颜色 _x_，并使用 _x_ 对以 _v_ 为根的子树中的所有顶点着色。 任务是找到实现每个顶点的目标着色所需的最少操作数。 

输入将树指定为父数组，其中每个条目 _p_i_ 表示顶点 _i_ 的父节点。 颜色以大小为 _n_ 的数组形式给出。 输出是一个整数：着色操作的最小数量。 

约束告诉我们 _n_ 最多可达 10⁴。 由于操作数量呈指数级增长，探索所有顶点子集或所有可能的操作序列的强力模拟会太慢。 我们需要一种线性时间方法，最好是 O(n)，因为我们每秒可以承受大约 10⁵ 操作。 

当子级与其父级具有相同的目标颜色时，就会出现微妙的边缘情况。 一种幼稚的方法可能会将子级着色视为单独的操作，但由于父级着色已经设置了其子树，因此不需要额外的步骤。 另一种情况是根本身具有非零颜色：必须始终将其算作第一个操作，因为最初所有颜色都为零。 例如，如果根是颜色 2 并且所有子项都是颜色 2，则答案仍然是 1，而不是 n。 

## 方法

 暴力方法将尝试单独为每个顶点着色或递归地模拟每个可能的子树着色。 人们可以想象从叶子开始并检查对父树着色是否有帮助，但在每次操作后跟踪整个树的确切状态既麻烦又缓慢。 在最坏的情况下，这会导致 O(n²) 操作，因为每个操作可能需要遍历整个子树。 

关键的见解是我们不需要显式模拟子树着色。 请注意，只有当顶点的颜色与其从父顶点继承的颜色不同时，着色操作才有意义。 如果一个顶点与其父节点具有相同的颜色，则一旦父节点的子树着色，它就已经正确着色。 相反，如果一个顶点与其父顶点不同，我们必须在该顶点或包含该顶点的祖先之一执行着色操作。 因此，最优策略是遍历这棵树，并对每个颜色与其父节点颜色不同的顶点进行计数。 根部经过特殊处理：由于它没有父级，因此根部的任何非零颜色始终算作一次操作。 

这一观察结果将问题简化为树上的单个 DFS。 对于每个顶点，我们将其目标颜色与其父顶点的目标颜色进行比较，如果不同，则增加操作计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

1. 解析输入以将树构建为邻接表。 每个顶点都保留其子节点的列表，以便于遍历。 
2. 初始化操作计数器。 如果根的颜色非零，则将计数器加一。 这代表了根部的第一个着色操作。 
3. 从根开始执行DFS。 对于访问的每个顶点，将其目标颜色与其父顶点的颜色进行比较。 如果颜色不同，则增加操作计数器。 原因是任何颜色与其父级不同的顶点都不能继承父级的着色，因此需要显式操作。 
4. 递归地继续所有孩子的DFS。 由于树是连接的且非循环的，因此该遍历仅访问每个顶点一次。 
5. DFS 完成后，计数器包含所需的最小操作数。 

工作原理：每个颜色与其父级相匹配的顶点都会由父级的着色操作自动处理。 只有具有不同颜色的顶点才需要显式操作。 通过遍历树一次并计算这些顶点，我们可以考虑所有必要的操作，而无需冗余。 DFS保证我们不会错过任何顶点，并且着色的子树属性确保只计算父子颜色差异就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(100000)

def main():
    n = int(input())
    parents = list(map(int, input().split()))
    colors = list(map(int, input().split()))
    
    tree = [[] for _ in range(n)]
    for i, p in enumerate(parents, start=1):
        tree[p-1].append(i)
    
    operations = 0
    
    def dfs(v, parent_color):
        nonlocal operations
        if colors[v] != parent_color:
            operations += 1
        for child in tree[v]:
            dfs(child, colors[v])
    
    dfs(0, 0)
    print(operations)

if __name__ == "__main__":
    main()
```该解决方案首先从父数组构造树。 DFS 函数获取当前顶点及其父顶点的颜色。 对于每个顶点，如果其颜色与父顶点不同，我们就会增加操作计数器。 我们将当前顶点的颜色传递给它的子节点，以便它们可以进行相同的比较。 使用`sys.setrecursionlimit`确保 DFS 不会达到大型树的递归限制。
