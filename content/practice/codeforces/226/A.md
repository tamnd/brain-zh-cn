 ## 解决方案
 ## 问题理解

 我们被要求计算一组_n_个外星人从三部分航天器的第三部分移动到第一部分所需的最短时间。 这些部分是线性链接的：部分 1 连接到部分 2，部分 2 连接到部分 1 和部分 3，部分 3 仅连接到 2。 一次只能有一个外星人可以移动，并且只有与当前源部分和目标部分中的每个外星人相比，其级别较高的外星人才能在相邻部分之间移动。 每个动作只需要一分钟，目标是确定所有外星人到达第 1 部分的总时间，以 _m_ 为模。 

输入包含两个数字，_n_ 和 _m_，两者都最大为 10^9。 因为 _n_ 可能非常大，所以任何单独模拟每个动作的解决方案都会太慢。 我们需要一种方法来以数学方式计算总时间，而无需迭代每个外星人。 

需要注意的边缘情况包括只有一名外星人的情况。 在这种情况下，外星人从第 3 区移动到第 2 区，然后从第 2 区移动到第 1 区，需要两分钟。 另一种边缘情况是当 _n_ 非常大时，简单迭代将超出合理的计算时间。 模运算引入了另一个微妙之处：必须注意在正确的点应用它以避免整数溢出。 

## 方法

 暴力方法会尝试模拟每个外星人按照规则移动。 对于每个外星人，我们会在移动之前检查源和目的地部分中所有外星人的排名，只有当外星人比其他人都高级时才移动该外星人。 计算每一步最终就会得出总时间。 这种方法在逻辑上是正确的，但在最坏的情况下会涉及 O(n^2) 次操作，因为每次移动都需要检查相关部分的当前占用者。 当 n 达到 10^9 时，这是不可行的。 

加速求解的关键在于认识到该问题等效于已知的组合序列。 如果我们按照资历递增将外星人从 1 编号到 n，则所有外星人从第 3 部分移动到第 1 部分所需的时间遵循递归模式。 让`T(n)`是 _n_ 个外星人的最短时间。 最后移动的外星人是最高级的，可以自由移动。 在此之前，所有其他 n-1 名外国人必须到达第 2 区，才能让高级外国人通过。 使用递归，我们可以得出`T(n) = 2*T(n-1) + 2`，简化为封闭公式`T(n) = 2^(n+1) - 2`。 一旦知道了这个公式，我们就可以使用模幂来计算结果，以有效地处理大的 _n_ 。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 识别递归关系。 定义`T(n)`作为n个外星人所需的最少动作。 通过观察该结构，最后一个移动的外星人（最高级的）只能在所有其他 n-1 个外星人都位于第 2 部分后才能这样做。将 n-1 个外星人重新定位到第 2 部分的移动递归地遵循相同的模式。 
2. 建立递归：`T(n) = 2*T(n-1) + 2`。 这`+2`考虑了最高级外星人从第 3 部分到第 2 部分，然后从 2 到 1 的移动。之所以出现 2 的因素，是因为 n-1 个外星人必须移到一边，然后在高级外星人通过后返回到第 2 部分，这反映了经典的“河内塔”问题。 
3、解决复发。 递归展开，我们看到闭式是`T(n) = 2^(n+1) - 2`。 这直接给出了最小步数，无需模拟。 
4. 计算`T(n) mod m`。 对于较大的 n，使用模幂来计算`2^(n+1) % m`在 O(log n) 时间内有效。 
5. 返回结果。 自从`T(n) = 2^(n+1) - 2`， 计算`(pow(2, n+1, m) - 2) % m`处理模数并防止出现负结果。 

为什么有效：关键的不变量是，在每个阶段，必须允许尚未移动的最高级外星人通过，这迫使所有较小的外星人暂时重新安置。 这强制了递归公式中的加倍行为。 封闭公式精确计算每次移动，模运算确保大数的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

# calculate 2^(n+1) % m
result = pow(2, n + 1, m) - 2
# ensure non-negative result modulo m
print(result % m)
```该解决方案读取 n 和 m，计算`2^(n+1) mod m`使用Python内置的快速求幂，减去2来计算基本移动，最后再次应用模m以保证非负结果。

 ## 边缘情况

 对于 n = 0，公式`2^(0+1)-2 = 0`正确返回 0，因为没有外星人需要移动。 对于 n = 1，该公式得出 2，与从第 3 部分直接移动到 2，然后从 2 移动到 1 相匹配。较大的 n 值（例如 10^9）可以通过模幂正确处理，从而避免直接计算完整的 2^(n+1) 并防止整数溢出。 模运算确保结果始终在 [0, m-1] 范围内，即使减去 2 也是如此。
