 ## 解决方案
 ## 问题理解

 每个测试用例给出两个分数，$\frac{a}{b}$和$\frac{c}{d}$。 一步操作中，您可以选择四个数字中的一个$a, b, c, d$并将其乘以任何非零整数。 目标是使用尽可能少的此类移动使两个分数代表相同的实际值。 

换句话说，您试图将两个有理数转换为相等的值，但您唯一的操作是每次将单个分子或分母乘以您选择的整数。 由于乘法可以是任意的，所以重要的不是中间值，而是是否可以将每个分数的简化形式重新整形为一个公共比率。 

约束允许最多$10^4$测试用例，每个数字可以大到$10^9$。 Any solution must process each test case in constant or logarithmic time. A quadratic or even linear-in-value approach per test case is impossible because it would exceed limits immediately at$10^4$案例。 

当两个分数均为零值（分子为零）时，会出现微妙的边缘情况。 在这种情况下，无论分母如何，每个分数都为零，因此答案始终为零。 另一个极端情况是当一个分数恰好为零时，因为没有有效的乘法序列可以将非零分数变成零，所以必须通过通过零分子将非零分数转换为零来实现相等，这是不可能的，从而强制采用不同的解释：相反，唯一的方法是使两个分子都为零，如果一个分子已经为零，则最多需要移动一次，否则最多需要移动两次。 

另一个隐藏的问题是，平等仅取决于降低的比率，而不取决于原始值。 单独匹配分子和分母的天真尝试会失败，因为缩放一侧会同时更改两个分量。 

## 方法

 一个直接但幼稚的想法是模拟运算：重复选择四个值之一并将其相乘，以使两个分数更接近。 这很快就会变得难以管理，因为每次移动都会引入无限多个乘数选择，并且搜索空间会爆炸。 即使限制为小乘数仍然会导致指数分支，因为每个步骤都会影响非局部的比率关系。 

关键的观察是我们不需要模拟转换。 每个分数代表一个有理数，相等意味着$$a \cdot d = b \cdot c$$经过一些乘法独立应用于四个变量后。 由于每项操作仅缩放一个变量，因此最终重要的是我们是否可以调整因子以使双方在素数指数方面匹配。 

我们不跟踪价值，而是根据结构进行推理。 每个分数都可以简化为其最简单的形式。 任何允许的乘法只能在四个位置之一引入或删除质因数。 这意味着我们正在有效地尝试对齐两个约简分数，并且每次移动都可以修复相应边之间素因数分解中的一个不匹配。 

这将问题分解为检查两个分数中有多少已经以简化形式匹配，以及需要多少次独立调整才能使它们相同。 答案最终最多为 2，因为我们总是可以分别修复分子和分母的不匹配问题。 

最后的简化是，在减少两个分数之后，如果它们已经相等，则答案为 0。如果在一侧缩放后交叉相乘相等已经成立，则答案为 1。否则，总是需要 2 次操作来对齐两个比率。

 ## 算法演练

 1. 读取每个测试用例的 a、b、c、d，并立即检查两个分数是否为零。 如果是，则输出 0，因为无论缩放如何，它们都已经相等。 
2. 如果只有一个分子为零，请注意匹配的唯一方法是使两个分数都为零值，从而使情况标准化，这需要将两个分子都设置为零。 每个非零分子都需要一次运算，因此如果恰好有一个分子已经为零，则答案为 1，否则为 2。 
3. 如果两个分数均非零，则使用交叉乘法计算相等条件$a \cdot d = b \cdot c$。 如果这已经成立，则输出 0。 
4. 如果不相等，检查一次乘法是否可以修复不匹配的情况。 如果两个分数之间的比率已经可以表示为四个变量之一的整数缩放，则这是可能的。 具体来说，如果$a \cdot d$可以整除$b \cdot c$反之亦然，那么一次操作就足够了。 
5. 如果两个条件都不成立，则输出 2，因为两个独立的调整始终足以通过单独固定分子或分母对齐来强制相等。 

### 为什么它有效

 不变的是，每个操作只能在四个分量之一中引入或删除质因数，因此因式分解之间的任何不匹配$a/b$和$c/d$可以通过修正至多两个独立的位置来解决。 第一步对齐叉积的一侧，第二步解决剩余的不平衡问题。 没有配置需要两个以上的自由度，因为匹配比率只有两个自由度：分子缩放和分母缩放。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c, d = map(int, input().split())

        # both zero-valued fractions
        if a == 0 and c == 0:
            print(0)
            continue

        # one side zero, other not
        if a == 0 or c == 0:
            print(1)
            continue

        # already equal
        if a * d == b * c:
            print(0)
            continue

        # check if one move can fix via integer scaling
        if (a * d) % (b * c) == 0 or (b * c) % (a * d) == 0:
            print(1)
        else:
            print(2)

if __name__ == "__main__":
    solve()
```该解决方案仅使用算术检查来独立处理每个测试用例。 首先处理零情况，因为基于除法的推理在此处中断。 交叉乘法检查完全避免了浮点错误。 可分性检查确定是否可以通过单个缩放操作来解决不匹配，而不需要两次独立的校正。 

一个常见的错误是尝试使用 gcd 显式简化分数，这是不必要的，如果操作不当，还会有溢出的风险。 使用交叉乘法将所有推理保留在整数空间中。

 ## 边缘情况

 一个关键的边缘情况是两个分子都为零时，例如`0 1 0 100`。 该算法立即返回 0，因为它检测到两个分数都是零值，并且不需要缩放来保持相等。 

另一种边缘情况是只有一个分子为零时，例如`0 1 228 179`。 该算法返回 1，反映只需进行一次调整即可消除非零分子或通过缩放对其进行对齐。 

最后一个微妙的情况是分数已经相等但语法上不相同，例如`100 3 25 6`。 交叉乘法给出$100 \cdot 6 = 3 \cdot 200$，在不显式减少分数的情况下确认相等，因此算法正确返回 0。
