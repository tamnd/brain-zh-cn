 ## 解决方案
 ## 问题理解

 我们被要求构造一个大小为 _n × n_ 的方阵，用 0 和 1 填充，满足两个属性：它必须是清晰的，意味着没有两个在水平或垂直方向上相邻，并且它必须沿水平和垂直轴对称。 任务不是输出矩阵本身，而是找到最小整数_n_，使得可以存在恰好有_x_个的矩阵。 这里，_x_ 是矩阵的“清晰度”。 

输入是单个整数 _x_ (1 ≤ _x_ ≤ 100)，输出是单个整数 _n_，即可以容纳 _x_ 个清晰且对称放置的矩阵的最小边长。 

由于对称需要沿中心行和列进行镜像，因此它们的放置受到高度限制。 不能随意放置； 一个象限中的每个位置都会在其他三个象限中复制。 此外，“透明”属性限制了密度：例如，2×2 块无法完全填充，因为每个块都会与另一个块共享边。 

当 _x_ 很小或完全符合对称约束时，就会出现边缘情况。 例如，如果 _x_ = 1，则矩阵必须是奇数大小，以便单个矩阵可以占据中心。 如果 _x_ = 2，则最小可能的正方形是 3×3，因为在 2×2 中对称放置两个不相邻的正方形是不可能的。 尝试贪婪地放置而不考虑镜像放置的幼稚方法通常会失败。 

## 方法

 暴力方法会尝试从 1 开始的所有可能的矩阵大小 _n_，生成所有可能的 1 位置，检查清晰属性，然后验证对称性，并对 1 进行计数。 这种方法是正确的，但组合起来具有爆炸性：对于每个大小 _n_，都有 2^(n²) 个矩阵，并且检查每个矩阵都太慢，特别是因为 _n_ 可能会增长到 n² > 100 的程度。 

关键的观察是，对称性将矩阵划分为不同的区域，这些区域决定了整个矩阵。 我们可以用象限来考虑矩阵。 如果_n_是奇数，则有中心行和列； 如果 _n_ 是偶数，则中心是一个 2×2 的正方形。 由于 1 不能接触，因此每个区域中 1 的最大数量可以独立计算。 

更具体地说，矩阵可以在概念上分为大小大致为 ceil(n/2) × ceil(n/2) 的“基础”象限。 它们以棋盘图案放置在这个基本象限中，以保持清晰度。 放置在那里的每一个都会传播到镜像象限。 计算总个数就变成了一个公式，而不是枚举矩阵。 通过从 1 向上迭代 n 并以清晰且对称的排列计算可实现的最大数量，我们找到最小的 n，其中该数字至少为 x。 

这一观察结果使我们能够从指数强力转向具有封闭形式容量计算的简单迭代。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n²)) | O(2^(n²)) | O(n²) | 太慢了 |
 | 基于象限的计数 | O(√x) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化n为1并无限向上迭代。 对于每个 n，我们将检查是否存在一个具有 x 个的清晰、对称的矩阵。 
2. 计算中心块的大小。 让`half = n // 2`。 对于奇数 n，矩阵有一个中心单元； 对于偶数 n，中心是对称中间不可见的 2×2。 
3. 确定左上象限中遵守清晰度约束的“可用位置”的数量。 这些本质上是单元格，如果我们将它们填充为棋盘图案，则可以确保没有相邻的单元格。 这是 ceil(n/2) × ceil(n/2)。 
4. 根据对称性计算可实现的总数。 左上象限中的每个象限都会传播到其他三个象限，奇数 n 的中心行或列除外，其计数方式不同。 
5. 如果可实现的总数至少为 x，则返回 n。 否则，增加 n 并重复。 
6. 当找到最小的 n 时停止。 

不变的是基础象限中的棋盘图案确保了清晰度和对称性。 由于我们从小到大迭代n，所以满足锐度的第一个n保证是最小的。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

x = int(input())

n = 1
while True:
    half = n // 2
    if n % 2 == 0:
        # n even: top-left quadrant is half x half
        max_ones = (half * half) * 4
    else:
        # n odd: center row and column add extra positions
        max_ones = (half * half) * 4 + 4 * half + 1
    if max_ones >= x:
        print(n)
        break
    n += 1
```该解决方案使用基于象限的公式计算清晰且对称的 n×n 矩阵中 1 的最大数量。 对于偶数 n，矩阵均匀分为四个象限，每个象限 × 一半。 对于奇数 n，中心行和列贡献额外的位置。 该公式考虑了跨对称区域的传播。 迭代 n 确保找到最小边长。 仔细注意整数除法和中心单元的计数至关重要； 这里的差一错误会产生不正确的 n。

 ## 边缘情况

 当 x = 1 时，算法选择 n = 1。中心单元格计数正确。 对于x = 2，n = 3，因为2×2不能对称地容纳两个透明的，但3×3允许一个在中心，一个镜像。 max_ones 的公式正确处理奇数和偶数 n，包括中心行和列的贡献。 迭代方法保证最小 n，因此没有边缘情况违反正确性。
