 ## 解决方案

 ## 问题理解

 我们有几个入口排列成一个循环，每个入口都有一队人在等待。 每分钟，每个队列前面的一个人会被处理，这意味着他们进入粉丝区并离开队列。 艾伦从入口 1 的队列末尾开始。时间以同步的步骤进行，艾伦每分钟都会做出确定性的行为：如果他当前不是队列中的第一个入口，他就会离开当前入口并加入下一个入口队列的末尾。 如果在处理他的入口时他已经在前面，则他进入粉丝区并且处理停止。 

任务是确定艾伦最终将通过哪个入口进入。 我们没有被要求逐步模拟整个过程，而只是确定最终队列位置，当该队列被处理时，Allen 恰好成为第一个。 

限制允许最多 100,000 个入口，队列大小最多为 1e9。 直接实时模拟会太慢，因为每一分钟最多只能减少n+1的总人数，而艾伦可能需要遍历很多周期才能稳定下来。 随着时间的推移，简单的模拟可能需要对所有减量求和，直到清除所有队列，在最坏的情况下，这将超过 1e9 步。 

当某些队列最初为空时，会出现微妙的边缘情况。 例如，如果队列中的人数为零，艾伦到达后可能会立即排在第一位，并且根据时间的不同，他可以在同一分钟或下一个周期进入。 另一个边缘情况是当所有队列都相等时，其中对称性可能暗示模糊性，但确定性“每分钟向右移动，除非进入”规则强制精确的循环位置。 

## 方法

 蛮力的想法是逐分钟地模拟该过程。 在每一步中，我们将每个队列减一（如果为正），然后检查 Allen 是否位于当前队列的前面。 如果没有，我们将他移至下一个队列。 这在概念上是简单且正确的，因为它遵循确切的规则。 

然而，每分钟需要 O(n) 次更新来减少队列，并且 Allen 可能会在系统中保留很多周期。 在最坏的情况下，如果所有a_i都很大（最多1e9），那么所有队列清空之前的分钟数也很大，使得总操作量达到1e14的量级，这是不可能的。 

关键的见解是停止从完全模拟的角度思考，而是计算艾伦到达时成为队列中第一个的时刻。 假设艾伦当前在某个时间 t 位于入口 i。 如果当他到达时，在他成为第一的那一刻，队列中在他前面的剩余人数恰好为零，那么他将从 i 进入。 重要的观察结果是，Allen 的到达模式是周期性的和确定性的：他按照 1、2、3... 的顺序循环访问队列，除非他进入，否则每次移动恰好花费一分钟。 

我们不跟踪时间，而是提出一个更简单的问题：对于每个队列 i，艾伦最早在什么时间 t 到达，以及他到达后是否能够立即进入？ 每个完整周期队列 i 中的人数减少一个。 如果 Allen 在 k 个完整周期后到达队列 i，则有效队列大小为 max(0, a_i - k)。 如果该值恰好在他排在第一位时变为 0，则 Allen 进入。 

因此，对于每个 i，我们计算需要多少个完整周期，以便 a_i 减少到足以使 Allen 不落后于任何人。 更具体地说，Allen 将在第一个 i 处进入，这样当他在完成 k 个完整周期后到达 i 时，我们有 a_i ≤ k，并根据确切的到达顺序确定决胜局。 我们通过跟踪有效阈值的下降来逻辑地模拟这一点。

我们可以将其转换为线性扫描：对于每个位置 i，所需的最早周期计数取决于 Allen 到达时已经完成的完整回合数。 Allen 第 k 次到达 i 的时间为 k * n + (i - 1)。 我们想要他在队列中第一个的时间最小，这对应于检查是否 a_i ≤ k。 

因此，对于每个 i，我们计算最小 k，使得 k ≥ a_i。 这意味着 k = a_i，时间变为 a_i * n + (i - 1)。 答案是使该值最小化的 i。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n * 最大(a_i)) | O(n) | 太慢了|
 | 周期时间公式| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个入口 i，将 a_i 解释为 Allen 可以“超越”该队列之前所需的完整周期数。 这是因为每个完整周期都会将所有队列减少一个有效层。 
2. 计算 Allen 到达 i 入口的候选时间：t_i = a_i * n + i。 i 偏移量表示 Allen 在一个周期内到达每个队列的确定性顺序。 
3. 跟踪给出最小t_i的入口，因为Allen成为第一的最早时间对应于最早的此类完成事件。 
4. 输出该入口的索引。 

该公式背后的直觉是，艾伦的位置确定性地循环通过入口，并且每个完整循环统一减少所有队列。 队列之间的唯一区别是在艾伦到达时队列变空之前需要多少个周期。 

### 为什么它有效

 在任何固定入口 i，艾伦以可预测的模式每 n 分钟到达一次。 在访问之间，所有队列在每个完整周期同步减少一个。 因此Allen在i处进入的条件相当于要求他第k次到达时至少已经过了a_i个完整周期。 最早的 k 正是 a_i，因此最早可行的进入时间由 a_i * n + i 唯一确定。 由于在此公式中所有入口都是独立的，因此选择最小保证艾伦可以成功使用第一个实际入口。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    best_time = 10**30
    best_idx = 1

    for i, ai in enumerate(a, start=1):
        t = ai * n + i
        if t < best_time:
            best_time = t
            best_idx = i

    print(best_idx)

if __name__ == "__main__":
    solve()
```该代码计算每个入口的直接候选时间，而不模拟队列演变。 乘以 n 捕获完整周期，而索引移位则考虑周期内排序。 比较选择最早的有效入口点。 

一个微妙的细节是 i 使用基于 1 的索引，因为到达时间取决于从入口 1 开始的队列位置排序。另一个重要的点是 Python 整数就足够了，因为值可以达到 1e14，并且在任意精度范围内。

 ## 边缘情况

 当所有队列为零时，艾伦总是立即符合资格。 公式得出 t_i = i，因此最小值为 i = 1。这与他从第一个入口进入的过程相匹配，不需要任何循环延迟。 

当队列相等时，例如 [10, 10, 10]，由于 +i 项，到达时间会随着 i 严格增加。 尽管从逻辑上讲，队列是相同的，但 Allen 仍然会稍早到达较小的索引，这决定了结果。 

当 a_i 非常大时，乘法占主导地位，算法自然地将这些索引推到很远的未来，确保只有较小的队列才重要。
