 ## 解决方案
 ## 问题理解

 平面上最多有 4096 个点，我们可以选择其中的四个作为四边形的顶点。 这四个点不必作为坐标不同，因为输入本身可能包含重复项，并且允许退化四边形。 任务是找到最大可能的区域并准确打印出来，包括可能的面积`.5`小数部分。 

中心几何事实是，最佳四边形可以被视为凸四边形，可能退化为三角形。 一旦对角线固定，它的面积就是位于该对角线两侧的两个三角形的面积之和。 对于固定的对角线，最大化四边形面积与找到每条边距对角线最远的点相同。 这是预期 (O(N^2)) 解决方案背后的关键观察结果。 

坐标范围很大，最大可达 (10^9)，因此浮点几何是不必要且不可取的。 每个加倍的区域都是一个整数叉积，因此我们可以使用精确的整数算术来执行整个计算。 在 C++ 中，有符号 64 位整数足以满足所需的叉积，而 Python 整数具有任意精度。 

值 (N=4096) 足够大，足以排除任何接近 (O(N^3)) 的值，更不用说 (O(N^4)) 了。 枚举每个四点子集已经给出

 [
 \binom{4096}{4}=11,710,951,848,960
 ]

 可能性，大约为（1.17\times10^{13}）。 预期的解决方案必须利用几何结构，而不是独立检查每个四元组。 凸包的成本仅为 (O(N\log N))，之后二次旋转卡尺阶段是主要工作。 

有几种边缘情况可能会悄无声息地破坏实现。 

例如，如果所有点都相同```
4
0 0
0 0
0 0
0 0
```答案是`0`。 假设至少三个不同点的凸包实现在这里可能会失败。 

例如，如果所有点共线```
4
0 0
1 0
2 0
3 0
```答案也是`0`。 尽管输入包含四个点，但外壳只有两个顶点。 

如果船体恰好有三个顶点，则答案就是该三角形的面积。 例如，```
4
0 0
4 0
0 4
1 1
```有一个三角形的外壳，第四个点位于其内部。 允许的最大四边形退化为三角形，所以答案是`8`，不为零，也不是任意的小四边形。 

最后，答案可能是一个半整数。 输入```
4
0 0
1 0
0 1
3 2
```面积最大增加一倍`5`，所以所需的输出是`2.5`。 通过浮点打印是不必要的，并且可能会引入格式错误。 我们将两倍面积保留为整数，直到最终输出。 

## 方法

 直接的方法是枚举四个输入点的每个选择。 对于每个四元组，我们可以考虑可能的顶点顺序，或者更有效地确定在恒定时间内从这四个点可获得的最大面积。 无论哪种方式，四元组的数量都是 (O(N^4))。 在 (N=4096) 处，大约有 (1.17\times10^{13}) 个四元组，这远远超出了可用时间。 

有用的观察是，可以将最大面积四边形视为凸四边形，并单独处理退化三角形的情况。 如果我们选择一条对角线 (A C)，则四边形将分为两个三角形：(A B C) 和 (A C D)。 它们的底边都是同一线段 (AC)，因此通过选择一侧距线 (AC) 最远的点和另一侧距线 (AC) 最远的点来最大化它们的组合面积。 加倍的三角形面积恰好是绝对叉积。 

这也告诉我们为什么只有凸包点才重要。 如果距固定线距离最大的点严格位于凸包内部，则凸包点将位于该方向上更远的位置。 因此，可以将最佳选择转移到船体上。 这种船体简化和固定对角线公式是 (O(N^2)) 方法的标准几何基础。 

按循环顺序计算凸包后，考虑固定的凸包顶点 (i)。 围绕船体向前移动对角线的另一个端点 (j)。 对于每条对角线 (i,j)，我们需要 (i) 和 (j) 之间的最佳顶点，以及另一条弧上的最佳顶点。 由于多边形是凸多边形，因此这些最远的顶点随着 (j) 向前移动而单调移动。 已经向前移动的指针永远不需要向后移动。 这是旋转卡尺步骤。 

因此，对所有相反顶点对的强力搜索变成了二次方。 对于每个 (i)，都有 (O(N)) 种可能的 (j)，而两个最远点指针一起也仅前进 (O(N)) 次。 已知船体后，所得算法为 (O(N^2))。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(N^4)) | (O(N)) | 太慢了|
 | 最佳 | (O(N^2)) | (O(N)) | 已接受 |

 ## 算法演练

 1. 读取所有点并计算它们的凸包。 

我们按字典顺序对点进行排序并使用单调链结构。 为了构建几何外壳，重复的坐标被删除，并且沿着边缘的共线点是不必要的，因为它们永远不会增加面积最大值。 当船体至少有四个顶点时，原始重数不会影响答案。 
2. 如果船体最多有两个顶点，则输出`0`。 

每个输入点都位于一条线上，因此每个可能的四边形的面积都为零。 
3. 如果船体正好有三个顶点，则计算该三角形的两倍面积并输出。 

任何第四个点要么在三角形内部，要么与其一个顶点重合。 这样的点不能创建比三角形本身更大的面积，而问题允许退化四边形，因此三角形面积是所需的最大值。 
4. 通过考虑以下索引，从概念上复制循环外壳数组`0`通过`2h-1`。 

这可以避免在遍历对角线的两个弧时出现尴尬的模运算。 索引处的一个点`i+h`与索引相同的几何点`i`。 
5.修复船体顶点`i`并让`j`逃离`i+2`通过`i+h-2`。 

这些正是每侧至少有一个船体顶点的对角线。 每个凸四边形都有这样的对角线，因此考虑这些对涵盖了每个候选者。 
6. 维护指针`k`求弧上的最佳顶点`i`到`j`。 

尽管`k+1 < j`替换时三角形面积增加一倍`k`经过`k+1`， 进步`k`。 对于凸多边形，从固定弦到连续顶点的距离是单峰的，因此一旦该值开始减小，移动得更远就无法找到更好的顶点。 
7. 维护指针`l`求互补弧上的最佳顶点`j`回到`i`。 

同样的单峰论点也适用于这一方。 作为`j`进步，最优`l`永远不需要向后移动，这就是将三次搜索变成二次搜索的原因。 
8. 将候选加倍面积计算为

 [
 \运算符名称{交叉}(i,j,k)+\运算符名称{交叉}(i,j,l)。 
]

 船体按逆时针方向存储，因此这两项对于相应的两条弧具有相同的符号。 每个叉积是一个三角形面积的两倍，它们的总和是四边形面积的两倍。 
9. 更新全局最大值并继续遍历所有对角线。 

每个可能的凸四边形在步骤 5 中考虑的对中都有一条对角线，对于该对角线，算法会选择每条边上的最佳可能顶点。 因此，其候选值至少是该四边形的面积。 由于每个候选本身都是有效的四边形结构，因此最大候选正是答案。 
10. 将双倍区域转换为所需的文本形式。 

如果加倍的面积是偶数，则打印`answer // 2`。 如果是奇数，则打印`answer // 2`其次是`.5`。 不需要浮点运算。 

为什么有效：对于每个选定的对角线，四边形面积恰好是两个三角形面积之和。 两个三角形的底边都是固定的，因此每条边都通过采用距对角线最大垂直距离的船体顶点来独立优化。 凸性使得每条边的距离序列单峰，并且随着对角线端点的前进，使其最大化索引单调。 因此，两个旋转指针为每条对角线找到最佳的一对，而无需扫描每对可能的相对顶点。 由于每个最大面积四边形都可以选择凸形，且顶点位于外壳上，因此这些候选对角线的全局最大值就是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return ((b[0] - a[0]) * (c[1] - a[1])
            - (b[1] - a[1]) * (c[0] - a[0]))

def convex_hull(points):
    points = sorted(set(points))

    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def largest_quadrilateral(points):
    hull = convex_hull(points)
    h = len(hull)

    if h <= 2:
        return 0

    if h == 3:
        return abs(cross(hull[0], hull[1], hull[2]))

    # Duplicate the hull so that all cyclic arcs can be traversed
    # with ordinary integer indices.
    p = hull + hull

    ans = 0
    limit_offset = h - 1

    for i in range(h):
        k = i + 1
        l = i + 3

        last_j = i + h - 2

        for j in range(i + 2, last_j + 1):
            if k >= j:
                k = j - 1

            # Best point on the arc i ... j.
            while k + 1 < j:
                cur = cross(p[i], p[k], p[j])
                nxt = cross(p[i], p[k + 1], p[j])
                if cur <= nxt:
                    k += 1
                else:
                    break

            if l <= j:
                l = j + 1

            # Best point on the complementary arc j ... i+h.
            while l + 1 <= i + h - 1:
                cur = cross(p[i], p[j], p[l])
                nxt = cross(p[i], p[j], p[l + 1])
                if cur <= nxt:
                    l += 1
                else:
                    break

            candidate = (
                cross(p[i], p[j], p[k])
                + cross(p[i], p[j], p[l])
            )

            if candidate > ans:
                ans = candidate

    return ans

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        points = [tuple(map(int, input().split())) for _ in range(n)]

        doubled = largest_quadrilateral(points)

        if doubled % 2 == 0:
            out.append(str(doubled // 2))
        else:
            out.append(str(doubled // 2) + ".5")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```这`convex_hull`函数使用标准的单调链结构。 这`<= 0`条件删除严格位于船体边缘内的点以及重复点。 仅保留极端端点就足以进行最大面积搜索。 

二次循环之前的特殊情况是必要的，因为基于对角线的四边形需要至少四个外壳顶点。 对于两个船体顶点，整个集合是共线的。 对于三个船体顶点，最佳允许的四边形退化为船体三角形，因此其面积的两倍是一个叉积。 

这`p = hull + hull`line 是一个小但有用的实现细节。 它让`j`,`k`， 和`l`移动通过船体的完整循环副本，无需重复`% h`最热循环内的操作。 

对于逆时针凸包，两条弧中使用的叉积是非负的。 这可以让实现避免`abs()`在二次循环内。 两个叉积恰好是由对角线形成的两个三角形的面积的两倍。 

条件`k + 1 < j`防止`k`成为对角线端点之一。 相似地，`l + 1 <= i + h - 1`保持`l`在互补弧内。 这些边界是最容易引入相差一错误的地方。 

指针被故意初始化为`k = i + 1`和`l = i + 3`。 最小的有效对角线有`j = i + 2`，所以它的第一条弧只包含`i+1`，而它的另一条弧开始于`i+3`。 

所有面积计算均保留整数。 对于大到 (10^9) 的坐标，叉积可以达到 (10^{18}) 的量级，因此具有固定宽度算术的语言需要足够宽的整数类型。 Python 的任意精度整数会​​自动处理这个问题。

对于四个共线点，```
1
4
0 0
1 0
2 0
3 0
```单调链外壳有两个端点，`(0,0)`和`(3,0)`。 该函数返回零，因为涉及输入点的每个叉积都为零。 

对于具有内部第四点的三角形船体，```
1
4
0 0
4 0
0 4
1 1
```船体包含`(0,0)`,`(4,0)`， 和`(0,4)`。 其面积翻倍为

 [
 |(4,0)\乘以(0,4)|=16,
 ]

 所以实际面积是`8`。 内点不能增加超出外接三角形的面积，并且允许的退化四边形可以达到该值。 特别的`h == 3`分支因此返回`16`，其格式为`8`。

复制的船体表示也是一种边缘条件保护。 对于有端点的对角线`i`和`j`，第一方严格使用它们之间的索引，而第二方严格使用它们之后的索引`j`和之前`i+h`。 循环边界`j <= i+h-2`,`k+1 < j`， 和`l+1 <= i+h-1`保证最远点指针永远不会成为对角线端点或穿过无效弧。
