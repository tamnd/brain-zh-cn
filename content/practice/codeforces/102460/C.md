 ## 解决方案
 ## 问题理解

 我们有一个正整数排序数组 (A)，其中 (3 \le n \le 50)。 我们必须确定三个不同位置 (i,j,k) 的每个选择是否满足

 [
 \frac{A[i]-A[j]}{A[k]} \in \mathbb Z.
 ]

 由于每个 (A[k]) 都是正数，因此这与询问 (A[k]) 是否整除 (A[i]-A[j]) 完全相同。 (i) 和 (j) 的顺序对于整除性并不重要，因为如果一个数整除 (x-y)，它也会整除 (y-x)。 

所需的输出是`yes`如果条件对于每个可能的不同索引三元组都成立，并且`no`一旦一个有效的三元组违反了它。 

该数组最多包含 50 个元素，因此即使 (O(n^3)) 枚举也只能执行

 [
 50\cdot49\cdot48=117600
 ]

 在最坏的情况下进行检查。 对于 2 秒的限制来说，这个时间很小，所以字面上的暴力实现已经足够快了。 基本解甚至不需要上限 (A[i]\le100)。 然而，它确实表明整数算术是完全安全的，并且不需要大数技术。 

有几个细节可能会使看似合理的实施变得错误。 首先，这三个指标必须是不同的。 例如，与`1 2 4`，唯一有效的三元组使用所有三个位置，结果是`no`因为

 [
 \frac{1-2}{4}=-\frac14
 ]

 不是整数。 意外地允许分母的索引与分子索引之一一致的实现可能会测试不属于问题的表达式。 

其次，分子是一个差异，而不是任何一个单独的数组值。 为了`2 4 6`, 分母`6`必须整除 (2-4=-2)，但事实并非如此，所以答案是`no`。 检查两个分子值是否都能被分母整除将解决不同的问题。 

第三，分子可以为负数。 例如，在`1 1 4`，如果分母是另一个元素，则差异可能是 (1-4=-3)，因此实现必须测试整除性，而不是假设分子为非负数。 蟒蛇的`%`运算符可以正确处理整除性测试中的负整数，因为 (x % d=0) 正好在 (d) 除 (x) 时。 

最后，重复的值是完全合法的。 为了`1 1 1 1 4`, 四者之间的每一个差异`1`s 为零，零可被所有正整数整除。 正确答案是`yes`。 

## 方法

 最直接的解决方案遵循数学定义。 枚举不同索引 (i,j,k) 的每个有序三元组，计算 (A[i]-A[j])，并检查它是否可被 (A[k]) 整除。 如果任何检查失败，答案会立即`no`; 如果所有检查都通过，答案是`yes`。 

正好有 (n(n-1)(n-2)) 个有序三元组。 最多 (n=50)，仅进行 117600 次整除性检查。 因此，虽然 (O(n^3)) 对于更大的数组来说变得没有吸引力，但对于这个问题的实际约束来说，它是完全可以接受的。 

有一个有用的观察结果可以将工作量减少到 (O(n^2))。 固定分母位置 (k)。 该条件表示对于每对不同于 (k) 的位置 (i,j)，

 [
 A[i]\等价于A[j]\pmod{A[k]}。 
]

 换句话说，删除 (A[k]) 后，每个剩余的数组值必须具有完全相同的余数模 (A[k])。 

我们不需要比较每一对来确定该属性。 选择一个参考位置 (r\ne k)。 如果每隔一个位置 (j\ne k,r) 满足

 [
 A[j]\equiv A[r]\pmod{A[k]},
 ]

 则任意两个这样的值具有相同的余数，因此它们的差可以被 (A[k]) 整除。 因此，对于每个（k），一个参考元素就足够了。 

蛮力之所以有效，是因为它直接检查每个所需的三元组，但它会多次重复本质上相同的模块化信息。 除 (A[k]) 之外的所有元素都必须属于以 (A[k]) 为模的一个残基类这一观察结果让我们可以将所有成对比较替换为针对一个参考的比较。 

对于给定的 (n\le50) 来说，二次版本不是必需的，但它给出了基础数学的更清晰的表达，并且尺度更好。

 | --- | --- | --- | --- |
 | 蛮力 | (O(n^3)) | (O(1)) | (O(1)) | 已接受 |
 | 残留等级检查| (O(n^2)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取 (n) 和数组 (A)。 我们只需要值本身，算法不需要给定的排序。 
2. 将每个数组位置（k）视为分母位置。 我们必须验证与 (k) 不同的位置上的每对值的差值都可以被 (A[k]) 整除。 
3. 选择与 (k) 不同的参考位置 (r)。 我们可以使用位置`0`除非 (k=0)，在这种情况下我们使用位置`1`。 因为(n\ge3)，这样的参考位置总是存在的。 
4. 对于每隔一个位置 (j)，跳过 (k) 和 (r)，检查是否
 [
 (A[j]-A[r])\bmod A[k]=0。 
]
 这表示 (A[j]) 和参考值具有相同的模 (A[k]) 余数。 
5. 如果任何此类差异不能被 (A[k]) 整除，则立即打印`no`。 失败的对 (j,r) 与分母 (k) 一起是不同位置的有效三元组，因此原始条件不成立。 
6. 如果每个位置(k)都通过，则打印`yes`。 对于每个分母，所有其他值都以该分母为模而全等，因此它们之间的每个差值都可以被它整除。 

### 为什么它有效

 固定任何分母位置 (k)。 该算法保证每个其他值 (A[j]) 具有与参考值 (A[r]) 相同的余数模 (A[k])。 因此，对于任意两个位置 (i,j\ne k)，

 [
 A[i]\等价A[r]\等价A[j]\pmod{A[k]}。 
]

 减去同余式可得

 [
 A[i]-A[j]\equiv0\pmod{A[k]},
 ]

 所以 (A[k]) 除 (A[i]-A[j])。 因此，分母为 (A[k]) 的每个三元组都是有效的。 由于该算法对每个 (k) 执行此参数，因此每个允许的三元组都是有效的。 相反，如果算法发现某些 (k) 具有不同余数的两个值，则它们的差值不能被 (A[k]) 整除，从而给出显式无效三元组。 因此该算法返回`yes`恰好当所需条件成立时。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    for k in range(n):
        # Choose any index different from k as the reference.
        ref = 0 if k != 0 else 1

        for j in range(n):
            if j == k or j == ref:
                continue

            if (a[j] - a[ref]) % a[k] != 0:
                print("no")
                return

    print("yes")

if __name__ == "__main__":
    solve()
```外层循环固定分母 (A[k])。 一旦 (k) 被固定，问题就变成了关于所有其他值模 (A[k]) 的余数的陈述。 

这`ref`选择保证参考索引与分母索引不同。 如果`k`不为零，索引`0`作品。 如果`k`为零，索引`1`作品。 由于 (n\ge3)，索引`1`永远存在。 

内循环会跳过两者`k`和`ref`。 每个剩余位置代表一个值，该值必须具有与`a[ref]`模数`a[k]`。 

表达式`(a[j] - a[ref]) % a[k]`优于执行除法并检查结果是否为整数。 它仅使用整数运算并直接测试整除性。 Python 整数还避免了任何溢出问题，尽管给定的值非常小，普通机器整数就已经足够了。 

算法在发现矛盾后立即返回。 这是安全的，因为所需的属性是通用的：一个无效的三元组足以确定答案是`no`。

 ## 边缘情况

 最小可能的数组具有三个位置。 为了`1 2 3`，尽管表达式允许分子有两种顺序，但三个位置只有一种无序选择。 取分母 3 和分子 (1-2=-1) 得出 (-1/3)，它不是整数。 该算法最终考虑(k=2)，比较值1和2模3，发现它们的差不能被3整除。它打印`no`。 

对于包含所有相等值的数组，例如`7 7 7`，每个分子差为零。 由于 (0) 可以被每个正整数整除，因此每个可能的表达式都是整数。 该算法选择任意参考值，每次比较都会产生零差值，因此会打印`yes`。 

分母等于 1 总是无害的。 例如，在`1 2 5`，每当分母位置包含 1 时，每个差值都可以被 1 整除。该算法不需要为此特殊情况，因为普通的模运算已经为每个模 1 的整数给出零。 

最大允许值也不需要特殊处理。 在`1 1 100`，当分母为 100 时，仅有的另外两个值都为 1，因此它们的差为零，条件通过。 当分母为 1 时，每个差值都会自动被 1 整除，最终结果为`yes`。 

直接处理负差异。 在`2 4 6`，考虑 2 和 4，分母为 6，生成 (2-4=-2)。 值 (-2) 不能被 6 整除，所以答案是`no`。 Python 表达式`(-2) % 6`是 4 而不是 (-2)，但它是非零，这正是整除性测试所需要的。 

重复的值必须被视为单独的位置，而不是折叠成一个集合。 在`2 2 5 5`，当分母为5时，剩下的两个2差为零。 当分母为2时，剩下的两个5的差为零。 每个所需的三元组都是有效的，所以答案是`yes`。 在检查之前删除重复项将更改可用位置集，并可能破坏使原始实例有效的结构。
