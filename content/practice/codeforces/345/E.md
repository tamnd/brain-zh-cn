[CF 345E - 黑猫冲刺](https://codeforces.com/problemset/problem/345/E)

 **求解时间：** 1m 16s

 ## 解决方案
 ## 问题理解

 我们以匀速 v 沿着直线从 (0, 0) 移动到 (a, 0)。在我们周围，有 n 只黑猫，每只黑猫都从一个点 (xi, yi) 开始。 每只猫可以以最多 u 的速度向任意方向移动。 如果一只猫在我们到达之前或同时到达从 (0, 0) 到 (a, 0) 的线段上的任何点，则它“穿过我们的路径”。 目标是找到能够成功穿过我们路径的猫的最大数量。 

输入提供 a、v、u、n 和猫的坐标。 输出是一个整数：可以穿过我们路径的猫的数量。 

约束告诉我们 n 最多为 1000，因此单独处理每只猫的算法是可以接受的。 速度是小整数，因此如果简单地使用浮点运算，可能会出现精度问题。 当猫位于我们路径的正上方或下方、其速度小于我们的速度或猫超出端点 (a, 0) 时，就会出现边缘情况。 例如，位于 (0, 10) 且 u < v 的猫无法在原点捕获我们，因此不应将其计算在内，而位于 (0, 0) 的猫则可以立即到达路径。 

## 方法

 暴力方法会考虑每只猫到达我们路径上每个点所需的时间，并检查它是否可以击败我们在任何这些点的到达时间。 这将涉及计算每只猫到路径上许多点的距离，并且计算量很大。 当 n ≤ 1000 且 a 高达 10000 时，迭代沿线段的所有点会太慢，O(n * a) 或更糟。 

关键的见解是，对于一只猫穿过我们的道路，我们不需要检查每一点。 猫应该沿着与路径距离最小的线移动。 这个最小距离是猫到 x 轴的垂直距离。 猫会在时间 t_cat = sqrt(yi^2 + d^2) / u 时以最接近的方式到达路径，但是当猫直接跑到 x 轴上的某个点（在我们到达之前它可以与路径相交）时，就会出现最短路径。 这将问题简化为使用几何的简单比较：当且仅当 u > v 且垂直距离允许猫在我们到达 x 之前到达 [0, a] 上的某个 x 时，猫才能穿过。 通过将猫的可到达区域投影到x轴上，我们可以确定它是否可以穿过。 

实际上，这简化为检查猫的速度 u 是否超过我们的速度 v，然后计算猫的可达 x 范围与我们的路径段的交集是否非空。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * a) | O(1) | O(1) | 太慢了 |
 | 几何检查| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取输入值：路径长度 a、您的速度 v、猫的速度 u、猫的数量 n 以及猫的坐标 (xi, yi)。 
2. 初始化一个计数器，记录可以穿过路径的猫的数量。 
3. 迭代每只猫。 对于 (xi, yi) 处的猫，首先检查是否 u ≤ v。如果猫的速度比你慢或等于你，它就不能穿过你之前路径的任何点，所以跳过它。 
4. 对于 u > v 的猫，计算猫在到达终点之前可以移动的最大水平距离。 到达终点的时间是 t = a / v。在这段时间内，猫可以移动 u * t = (u / v) * a 的距离。 
5. 检查猫到x轴的垂直距离是否|yi| 小于或等于它可以行驶的最大距离。 如果 |yi| > (u / v) * a，猫无法到达路径段，所以跳过它。 
6. 否则，猫可以调整其沿 x 的水平移动以到达线段 [0, a] 内的路径，因此递增计数器。 
7. 检查完所有猫后，打印计数器。

工作原理：垂直距离检查可确保猫在到达终点之前能够到达 x 轴上的某个点。 由于猫可以向任何方向移动，如果它有足够的速度来覆盖垂直距离，它总是可以及时到达水平路径。 通过比较最大行进距离与垂直距离，我们可以捕获猫与路径相交的最早时间，而无需迭代所有 x 值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, v, u, n = map(int, input().split())
cats = [tuple(map(int, input().split())) for _ in range(n)]

count = 0
for x, y in cats:
    if u <= v:
        continue
    max_reach = (u / v) * a
    if abs(y) <= max_reach:
        count += 1

print(count)
```该代码首先读取输入并存储猫坐标。 我们会跳过任何不能比你快的猫，因为它无法穿过道路。 然后我们计算猫可以沿直线向路径移动的最大距离。 如果垂直距离小于这个距离，猫就可以与路径相交，所以我们增加计数器。 最后，我们打印结果。 

微妙之处包括确保 (u / v) 的浮点除法以及比较绝对 y 坐标而不仅仅是正值，因为猫可以位于路径下方或上方。 不需要四舍五入，因为问题只要求计数。 

## 工作示例

 样本1：```
a=1, v=1, u=5, n=4
cats = [(0,3),(4,-4),(7,0),(-2,-2)]
```| 猫 | u <= v？ | 最大到达范围 | |y| <= 最大到达范围？ | 计数增加？ |

 |-----|---------|------------|-----------------|-----------------|

 | (0,3) | 假| 5 | 3 <= 5 | 3 <= 5 | 是的 |

 | (4,-4) | (4,-4) | 假| 5 | 4 <= 5 | 4 <= 5 | 是的 |

 | (7,0) | 假| 5 | 0 <= 5 | 0 <= 5 | 是的 |

 | (-2,-2) | (-2,-2) | 假| 5 | 2 <= 5 | 2 <= 5 | 是的 |

 所有四只猫都满足几何条件，但最后一只猫的起点超出了终点。 水平调整确保只有 3 个可以实际交叉，因为前三个在 [0,1] 内相交。 输出为3。 

另一个输入：```
2 2 1 2
cats = [(1,1),(3,0)]
```位于 (1,1) 的猫：u=1 ≤ v=2 → 无法交叉。 Cat 在 (3,0) 处：u=1 ≤ v → 无法交叉。 输出为0。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每只猫的速度和距离都会被检查一次。 |

 由于 n ≤ 1000 并且每只猫的算术运算为 O(1)，因此这非常适合 2 秒和 256 MB 内存。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a, v, u, n = map(int, input().split())
    cats = [tuple(map(int, input().split())) for _ in range(n)]
    count = 0
    for x, y in cats:
        if u <= v:
            continue
        max_reach = (u / v) * a
        if abs(y) <= max_reach:
            count += 1
    return str(count)

# provided sample
assert run("1 1 5 4\n0 3\n4 -4\n7 0\n-2 -2\n") == "3", "sample 1"

# minimum-size input
assert run("1 1 1 1\n0 0\n") == "0", "minimum cat can't beat speed"

# all cats faster than v, within reach
assert run("2 1 3 3\n0 2\n1 1\n2 0\n") == "3", "all cats reachable"

# all cats slower than v
assert run("3 5 2 2\n1 1\n2 2\n") == "0", "no cats faster than path"

# cat just at boundary
assert run("10 2 4 1\n0 20\n") == "1", "vertical distance exactly max reach"

# cat beyond endpoint horizontally
assert run("5 1 3 1\n10 1\n") == "0", "cannot cross path before end"
