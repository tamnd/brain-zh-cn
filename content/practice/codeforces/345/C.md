 ## 解决方案
 ## 问题理解

 我们收到了一小份比赛日期清单。 对于每个日期，我们必须确定该日历日是否既是该月的 13 日又是星期五。 答案很简单，就是满足这两个条件的比赛日期的数量。 

年份范围是从 1974 年到 2030 年，日期数量最多为 10 个。这些限制很小。 即使是为每个查询执行大量日历计算的算法也能轻松满足限制。 真正的挑战不是效率，而是正确确定给定日期的工作日，包括闰年和不同的月份长度。 

一个常见的错误是仅检查天数是否等于 13。请考虑：```
1
2013-09-13
```正确的输出是：```
1
```因为2013年9月13日是星期五。 忽略工作日将每 13 日计数一次，无论是否是星期五。 

另一个容易犯的错误是闰年处理不当。 考虑：```
1
2012-02-13
```正确的输出是：```
0
```任何忘记 2012 年是闰年的工作日计算都可能会产生错误的工作日并错误地计算该日期。 

第三个微妙的情况是重复的比赛日期：```
3
2012-01-13
2012-01-13
2012-01-13
```正确的输出是：```
3
```每场比赛必须独立计算。 该声明明确允许同一天举行多次比赛。 

## 方法

 最直接的解决方案是确定每个给定日期的工作日，并计算每月 13 日有多少个星期五。 

确定工作日的一种强力方法是选择一个已知的参考日期并逐日模拟，直到达到目标日期。 这是有效的，因为工作日每 7 天重复一次。 如果参考日期是几十年前的，那么每次查询可能需要遍历数万天。 该问题的最大跨度约为 56 年，即约 20,000 天。 如果只有十个查询，这仍然是完全可以接受的，但它不必要地麻烦。 

关键的观察是工作日计算具有众所周知的封闭式公式。 由于日期范围是固定的且很小，我们可以使用泽勒同余直接计算给定日期的工作日。 该公式通过算术自动处理闰年和月份长度，避免任何模拟。 

对于每个输入日期，我们首先检查日期部分是否为 13。如果不是，则该日期不可能是 13 号星期五。 如果是 13，我们使用泽勒同余计算它的工作日。 该公式返回代表工作日的代码，如果该代码对应于星期五，我们就计算日期。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·D) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 这里，$D$是参考日期与查询日期之间的天数。 

## 算法演练

 1. 读取比赛日期的数量。 
2. 对于每个日期字符串，提取年、月和日。 
3. 如果当天不是 13 点，则立即跳过该日期。 

任何日期都不能是 13 号星期五，除非该日期等于 13。 
4. 使用泽勒同余计算工作日。 

对于 1 月和 2 月，将其视为上一年的 13 月和 14 月。 这是公式定义的一部分。 
5.让$K$是本世纪内的年份，并且$J$是零基础的世纪。 
6. 评估泽勒公式：$$h = \left( q + \left\lfloor \frac{13(m+1)}{5} \right\rfloor + K + \left\lfloor \frac{K}{4} \right\rfloor + \left\lfloor \frac{J}{4} \right\rfloor + 5J \right) \bmod 7$$在哪里$q$是该月的哪一天。 
7. 在泽勒的编号中，星期五对应于$h = 6$。 
8.如果$h = 6$，增加答案。 
9. 处理完所有日期后，打印答案。 

### 为什么它有效

 泽勒同余是一个经过数学验证的公式，可将每个有效的公历日期映射到其工作日。 将 1 月和 2 月转换为上一年的 13 月和 14 月已纳入推导中，并保证了正确的闰年处理。 

仅当两个条件同时成立时，该算法才会计算日期：月份中的某一天等于 13，计算出的工作日等于星期五。 由于工作日计算对于每个有效输入日期都是正确的，因此每个计算的日期都是真正的 13 号星期五，并且输入中的每个星期五 13 号都只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_friday_13(year, month, day):
    if day != 13:
        return False

    if month <= 2:
        month += 12
        year -= 1

    q = day
    K = year % 100
    J = year // 100

    h = (
        q
        + (13 * (month + 1)) // 5
        + K
        + K // 4
        + J // 4
        + 5 * J
    ) % 7

    return h == 6  # Friday in Zeller's congruence

def solve():
    n = int(input())
    ans = 0

    for _ in range(n):
        s = input().strip()
        y, m, d = map(int, s.split('-'))

        if is_friday_13(y, m, d):
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案将工作日计算分离到辅助函数中。 第一个检查是该天是否等于 13。这可以避免对永远无法得出答案的日期进行不必要的算术。 

一月和二月的月份调整很容易被忽视。 泽勒的同余将它们视为上一年的第 13 个月和第 14 个月。 忘记这种转变会导致年初时的工作日不正确。 

所有算术都适合标准 Python 整数。 不需要对闰年进行特殊处理，因为该公式已经包含了公历规则。

 ## 边缘情况

 ### 重复的比赛日期

 输入：```
3
2012-01-13
2012-01-13
2012-01-13
```该算法独立处理每一行。 每个事件都有第 13 天，计算结果为星期五。 计数器增加三倍，产生：```
3
```不进行重复数据删除，符合问题需求。 

### 闰年日期

 输入：```
1
2012-02-13
```天等于 13，因此算法计算工作日。 在应用 Zeller 公式之前，2 月会转换为 2011 年的第 14 个月。 计算出的工作日是星期一，而不是星期五，所以答案是：```
0
```这验证了是否正确处理了闰年敏感日期。 

### 13 号但不是星期五的日期

 输入：```
1
2012-09-13
```每月某日条件成功。 周四返回工作日计算结果。 由于工作日不是星期五，因此计数器保持为零：```

```这证实这两个条件都是必需的。
