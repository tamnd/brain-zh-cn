 ## 解决方案
 ## 问题理解

 我们得到一棵通过“级别大小配置文件”间接描述的有根树。 我们只知道距根的每个距离存在多少个节点，而不是边。 数组`a[i]`告诉我们到底有多少个顶点`i`远离根的边，以及最大索引`h`是树的高度。 

任务不是重建一棵树。 我们必须决定这个轮廓是否唯一地确定同构的有根树。 如果多个非同构树可以产生相同的级别计数，我们必须显式构造两个不同的有效树。 否则，我们报告结构是唯一确定的。 

关键限制是所有级别的顶点总数最多为 200,000 个。 这立即意味着任何解决方案在节点数量上都必须是线性的或接近线性的。 每个级别配对的顶点数量的任何二次方都会失败，特别是因为高度也可能高达 100,000。 

一个微妙的困难是相同的级别大小不编码父子配对。 在相邻层中的节点之间分配子级的两种不同方式可以生成结构不同的树，同时保留相同的级别计数。 这就是歧义的全部根源。 

一个典型的陷阱是假设如果每个级别都“贪婪地”连接到前一个级别，则该结构是唯一的。 这是错误的：当一个关卡至少有两个可以“交换”附件模式而不改变计数的节点时，就会出现歧义。 

例如，考虑：```
h = 2
a = [1, 2, 1]
```第 1 层有两个节点，第 2 层有一个节点。一种构造可以将两个第 1 层节点附加到根，而第 2 层节点附加到其中一个节点。 另一种可以在 1 级节点之间进行不同的分布，从而产生具有相同级别计数的非同构树。 

核心挑战是检测这种重新安排是否可能，并在可能的情况下构建证人。 

## 方法

 暴力方法会尝试逐级枚举所有可能的父分配。 处于水平`i`，每个节点从级别中选择一个父节点`i-1`，并且我们必须检查所有赋值是否产生同构结构或者是否至少存在两个不同的结构。 

这会组合爆炸。 即使对于单个级别，如果`a[i] = k`和`a[i-1] = p`， 有`p^k`分配父母的方法。 在多个层面上，这变得非常大，远远超出了任何可行的计算。 

关键的观察是我们不需要探索所有的树。 我们只需要知道是否存在一个可以在局部引入歧义的级别，而与更深层次的结构无关。 

当两个连续级别有足够的容量允许在节点之间交换附件而不影响计数时，就会出现歧义。 具体来说，如果存在一个水平`i`这样两者：

 -`a[i] > 1`-`a[i-1] > 1`我们可以用两种结构上不同的方式分配孩子，然后我们可以构造两棵非同构树。 

然而，并不是每一对都立即保证含糊不清。 真正的区别条件是我们是否可以在某种程度上“改变”一个节点的父节点选择，同时保持可行性。 这简化为找到我们可以通过在父代选择中引入不匹配来打破对称性的第一个级别。 

我们通过始终按顺序将孩子分配给父母来构建规范树。 然后，我们构造第二棵树，除了在可能存在歧义的第一层之外，在所有地方都相同：我们以保留层计数但改变结构的方式交换两个节点的父分配。 

问题简化为找到两个节点存在于连续层中允许交换的最早级别，然后显式构建两个不同的父数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| 指数| 指数| 太慢了 |
 | 贪婪构造+第一次歧义交换| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 通过始终在级别连接节点来构建规范的父分配`i`到该级别的第一个节点`i-1`以循环或顺序的方式。 

这保证了树的有效性，因为级别大小在构造上是一致的。 
2. 使用索引范围跟踪节点如何跨级别分布。 对于每个级别，维护属于该级别的顶点 ID 段。 
3.从上到下扫描level并搜索第一个索引`i`使得两者`a[i] > 1`和`a[i-1] > 1`。 

这是我们至少有两个节点的父分配可能不同的第一个地方。 
4. 如果不存在这样的级别，则输出`"perfect"`。 

原因是每个级别最多有一个节点或其父级别的大小为 1，从而强制采用唯一的附件模式。 
5. 否则，构造两个父数组：

 一种使用简单的顺序分配。 

第二个在第一个模糊级别引入了交换：级别中有两个节点`i`交换父母的等级`i-1`。 
6. 通过保留级别上的每个节点，确保两种构造都保持有效的树`i`在 level 中只有一个父级`i-1`。 

### 为什么它有效

 树的结构完全由节点的级别决定`i`将它们的边缘分布到水平`i-1`。 如果任一级别的大小为 1，则不存在选择。 两个大小都超过 1 的第一个级别引入了至少一个二元自由度：级别中有两个节点`i`可以交换父母级别`i-1`不影响级别计数顺序。 这创建了两种结构上不同的邻接模式，保证了非同构的有根树。 

在此之前，所有分配都被迫对称，因此没有替代结构可以更早地发散。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

h = int(input())
a = list(map(int, input().split()))

# build level ranges of node ids
levels = []
cur = 1
for x in a:
    levels.append((cur, cur + x - 1))
    cur += x

n = cur - 1

parent1 = [0] * (n + 1)
parent2 = [0] * (n + 1)

# root
parent1[1] = 0
parent2[1] = 0

# build first tree (canonical)
for i in range(1, len(a)):
    l1, r1 = levels[i]
    l0, r0 = levels[i - 1]
    p = l0
    for v in range(l1, r1 + 1):
        parent1[v] = p
        p += 1
        if p > r0:
            p = l0

# check ambiguity
amb = -1
for i in range(1, len(a)):
    if a[i] > 1 and a[i - 1] > 1:
        amb = i
        break

if amb == -1:
    print("perfect")
    print(*parent1[1:])
    exit()

# build second tree identical except swap at first ambiguous level
parent2 = parent1[:]

l1, r1 = levels[amb]
l0, r0 = levels[amb - 1]

nodes = list(range(l1, r1 + 1))
if len(nodes) >= 2:
    # swap parents of first two nodes
    parent2[nodes[0]], parent2[nodes[1]] = parent2[nodes[1]], parent2[nodes[0]]

print("ambiguous")
print(*parent1[1:])
print(*parent2[1:])
```构造首先为每个级别分配连续的顶点 ID，以便我们可以在范围而不是邻接列表中进行推理。 这简化了父分配，因为每个级别都成为一个连续的块。 

第一个父数组通过循环前一级别的父数组来构建确定性树。 这确保每个节点都连接，同时保留级别大小。 

歧义检测扫描第一级别，其中当前级别和前一级别都具有多个节点。 该条件足以创建交换而不影响有效性。 

第二棵树是通过复制第一棵树并交换模糊级别中两个节点的父节点而派生的。 这个单一的局部变化足以打破同构，同时保留级别序列。

 ## 边缘情况

 当恰好一个级别的大小大于 1 但前一个级别的大小为 1 时，就会出现一种边缘情况。 在这种情况下，无法自由地重新分配父节点，因为每个节点仍然共享相同的单个祖先。 该算法正确地跳过它，因为条件`a[i] > 1 and a[i-1] > 1`失败。 

另一种情况是树深处存在歧义，但较早的级别都是单例。 该算法正确地选择了第一个有效级别，因为较早的级别不提供任何可供利用的分支结构。 

最后一个微妙的情况是存在多个不明确的级别。 仅使用最早的一个，因为更改更高级别已经保证了结构差异，而无需进行更深层次的修改，并且任何后续更改仍将保持有效性，但没有必要。
