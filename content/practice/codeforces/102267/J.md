 ## 解决方案
 ## 问题理解

 动物园是 (n) 个位置的循环。 公民选择起始位置 (a)、围绕自行车的方向以及最长长度的简单路径 (k)。 步行必须停留在所选路径内，返回 (a)，并访问路径的每个位置。 其移动次数不得超过(m)。 任务是计算所有可能的模 (10^9+7) 行走。 

暂时忘记循环的有用方法是查看 (a) 中选定的一个方向。 将 (a) 标记为位置 (0)，将下一个位置标记为 (1)，依此类推。 然后，有效的行走变成在整数段上从 (0) 到某个最大位置 (d) 的行走，其中每次移动都会将当前位置更改 (1) 或 (-1)。 步行从 (0) 开始和结束，永远不会低于 (0)，并且其最大位置最多为 (k)。 

这里有一个微妙的点。 我们不必明确选择 (d)。 如果步行到达最大位置 (d)，则所选路径正好具有该长度，因为必须访问该路径的最后位置。 因此，对停留在 (0) 和 (k) 之间的行走进行计数会自动对每个可能选择的路径进行一次计数。 然后可以通过 (2n) 因子恢复方向和起始位置。 

约束 (n\le 10^5) 排除了任何迭代每个起始位置和每个可能的行走的情况。 更重要的是，(m\le2000) 是使动态规划成为可能的小参数。 由于长度为 (i) 的步行距离其起点永远不会比 (i) 更远，因此时间 (i) 时的相关位置仅为 (0,\ldots,\min(i,k))。 对所有 (i\le m) 求和，得到 (O(m^2)) 个状态，当 (m=2000) 时最多约为 400 万。 

一个容易犯的错误是计算端点而不是移动。 例如，对于输入（4\3\3），唯一可能的非空闭合行走的长度为（2），即移动到相邻位置并立即返回。 有 (4) 个起始位置和 (2) 个方向，所以答案是 (8)。 将该步行视为具有长度 (3) 会错误地丢弃它。 正确的输出是（8）。 

另一个错误是假设步行必须精确到达距离 (k)。 例如，对于 (n=5,k=4,m=4)，步行 (0\to1\to0) 是有效的，即使其最大距离仅为 (1)。 它实际选择的路径长度为(1)，这是允许的，因为要求最多为(k)。 因此，DP 必须计算最大值最多为 (k) 的所有步行，而不仅仅是达到 (k) 的步行。 

当 (k=1) 时出现第三种边界情况。 唯一可能的移动是在位置 (0) 和 (1) 之间，因此仅对于偶数长度才存在有效行走。 对于 (n=2,k=1,m=2)，对于起始点和方向的 (2n=4) 个选择中的每一个都恰好有一次行走，给出输出 (4)。 意外允许位置 (2) 的重复会超出这种情况。 

## 方法

 直接的暴力解决方案可以选择起始位置、两个方向之一，然后枚举直到长度 (m) 的每个可能的移动序列。 每一步最多有两个选择，因此长度从(1)到(m)的序列数为

 [
 2+2^2+\cdots+2^m=2^{m+1}-2。 
]

 有 (2n) 个起始位置和方向选择。 在最坏的情况下，这大约意味着

 [
 2n(2^{m+1}-2)
 ]

 候选序列。 对于 (n=10^5) 和 (m=2000)，这是完全不可行的。 蛮力是正确的，因为它明确地检查每一个可能的行走，但行走的指数数量是问题所在。 

步行的结构给了我们一个小得多的状态空间。 一旦起点和方向确定，循环就是一条线段。 在时间 (i)，继续行走所需的唯一信息是距起点的当前距离 (j)。 从 (j) 开始，下一个位置是 (j-1) 或 (j+1)。 (0) 以下的位置被禁止，而 (k) 以上的位置被禁止。

这直接导致了动态规划的重现。 令 (dp[i][j]) 为从 (0) 开始、永不离开 ([0,k]) 并在位置 (j) 结束的长度 (i) 行走的数量。 过渡是

 [
 dp[i][j]=dp[i-1][j-1]+dp[i-1][j+1]。 
]

 在位置 (0) 处，第一项不存在，因为禁止移动到 (-1)。 在位置(k)处，禁止从(k)到(k+1)的转变。 

当其最终位置为 (0) 时，步行即结束。 我们对所有 (1\le i\le m) 求和 (dp[i][0])。 起始位置有(n)个选择，方向有(2)个选择，所以最终结果乘以(2n)。 

表观 (O(mk)) 复杂度也比乍看起来要好。 在时间 (i) 时，无法到达大于 (i) 的位置，因此只有 (\min(i,k)+1) 个位置相关。 从 (m\le2000) 开始，转换总数为 (O(m\min(m,k))=O(m^2))。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n2^m)) | (O(米)) | 太慢了 |
 | 最佳DP | (O(m\min(m,k))) | (O(\min(m,k))) | 已接受 |

 ## 算法演练

 1. 读取(n,k,m)。 我们将首先计算一个固定起始位置和一个固定方向的步行，然后在最后恢复 (2n) 个对称选择。 
2. 将所选方向表示为一维坐标系。 起始位置的坐标为 (0)，沿所选方向移动会增加坐标，向后移动会减少坐标。 由于所选路径的长度最多为 (k)，因此有效坐标为 (0,\ldots,k)。 
3. 初始化（dp[0][0]=1）。 在进行任何移动之前，恰好有一次长度为零的步行，并且位于起始位置。 
4. 对于从 (1) 到 (m) 的每个时间 (i)，计算到达每个可能位置 (j) 的方式数量。 复发率是
 [
 dp[i][j]=dp[i-1][j-1]+dp[i-1][j+1]。 
]
 位置（j）只能从前一次的两个相邻位置之一到达。 
5. 将 (j) 限制为 (0\le j\le\min(i,k))。 长度为 (i) 的步行无法到达大于 (i) 的距离，因此超出 (i) 的位置是不必要的。 下限 (0) 可防止步行在起始端点离开所选路径。 
6. 计算完整个时间层后，将 (dp[i][0]) 添加到答案中。 以 (0) 结束表示公民已返回起始位置，因此每个这样的状态都是有效的封闭步行。 
7. 将累计计数乘以 (2n)。 循环中有 (n) 个可能的起始位置和两个方向。 每个计数的一维行走都准确地确定了这些选择之一，并且每个这样的选择都具有相同的行走次数。 

### 为什么它有效

 对于固定的起始位置和方向，不变式是 (dp[i][j]) 精确计算保留在允许的线段内并在坐标 (j) 处结束的长度 (i) 行走。 递归精确地考虑了两个可能的先前坐标，而限制 (j\ge0) 和 (j\le k) 则删除了所选路径之外的每一个移动。 因此，(dp[i][0]) 精确计算长度为 (i) 的有效闭合游走。 

计数的步行可能具有最大坐标 (d<k)，但这是正确的。 其实际选择的路径结束于坐标 (d)，该坐标仍在允许的最大值 (k) 内。 由于必须访问所选路径的端点，因此 (d) 由步行到达的最大坐标唯一确定。 因此，DP 不会计算多个路径长度的相同步行。 最后，每次步行都可以放置在 (n) 个起始位置中的任何一个，并沿任一方向进行，给出因子 (2n)。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, k, m = map(int, input().split())

    limit = min(k, m)

    prev = [0] * (limit + 2)
    prev[0] = 1

    ans = 0

    for i in range(1, m + 1):
        cur = [0] * (limit + 2)
        upper = min(i, k)

        for j in range(upper + 1):
            ways = 0

            if j > 0:
                ways += prev[j - 1]

            if j + 1 <= limit:
                ways += prev[j + 1]

            cur[j] = ways % MOD

        ans += cur[0]
        ans %= MOD
        prev = cur

    ans = ans * (2 * n) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```DP 使用两个数组而不是存储所有 (m) 层。`prev[j]`代表前一个时间步长，`cur[j]`代表当前的。 这将内存从 (O(m^2)) 减少到 (O(m))。 

表达式`upper = min(i, k)`是关键的边界优化。 在时间(i)，坐标(j>i)不可达，而坐标(j>k)被所选路径禁止。 不需要计算其他位置。 

为了`j > 0`，之前的位置可能是`j - 1`。 为了`j + 1 <= limit`，之前的位置可能是`j + 1`。 什么时候`j == 0`，故意省略第一个转换，因为从 (0) 到 (-1) 的移动将离开选定的路径。 

额外的数组槽位于`limit + 1`不用作有效状态。 它只是让递归读取`prev[j + 1]`安全时`j == limit`，该值保持为零。 

Python 整数不会溢出，但减少每个状态模 (10^9+7) 可以保持中间值较小并遵循所需的输出模数。 最后乘以 (2n) 也是以模 (10^9+7) 进行。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(m\min(m,k))) | 在时间 (i) 时，只能到达 (0) 到 (\min(i,k))。 |
 | 空间| (O(\min(m,k))) | 仅存储先前和当前的 DP 层。 |

 自(m\le2000)以来，状态转换的数量最多为四百万数量级。 该算法永远不会单独迭代所有 (n) 个位置，因此 (n) 仅出现在与 (2n) 的最终乘法中。 这完全符合 (n) 的 (10^5) 界限和 256 MB 内存限制。

 ## 边缘情况

 当最大路径长度为（k=1）时，行走只能在位置（0）和（1）之间交替。 对于输入`2 1 2`, DP 有`dp[2][0] = 1`，而位置 (0) 处的所有奇数长度状态均为零。 累计计数为 (1)，乘以 (2n=4) 得出输出`4`。 遵守上边界，因为从位置 (1) 的转换只能返回到位置 (0)。 

当步行长度为奇数时，不可能返回起点。 为了`2 1 1`，第一步必须从 (0) 到 (1)，所以`dp[1][0] = 0`答案是`0`。 更一般地，每次移动都会更改当前坐标的奇偶性，因此从 (0) 开始的步行只有在偶数次移动后才能返回到 (0)。 

当 (k) 大于每个可达距离时，上限不会影响结果。 为了`5 4 4`，唯一的封闭行走长度是 (2) 和 (4)。 有一条长度为 (2) 的步行道和两条长度为 (4) 的步行道，为固定起点和方向提供 (3) 条步行道。 因子 (2n=10) 产生`30`。 这也说明了为什么 DP 必须接受最大距离小于 (k) 的步行。 

当 (k) 受到限制时，DP 必须删除会跨越该边界的步道。 为了`3 2 6`，长度为 (2,4,6) 的无限制非负闭合游走数量为 (1,2,5)，但在五个长度为 (6) 的游走中，到达位置 (3) 的游走被禁止，因为 (k=2)。 因此，对于固定的起点和方向，只剩下（1+2+4=7）条步行。 有 (2n=6) 个这样的选择，给出`42`。 

最后，(k<n) 使得所选路径被视为普通线段，而不是意外地环绕整个循环。 DP 仅跟踪沿明确选择的方向的距离，并且因子 (2n) 恢复循环的旋转和方向对称性，而不枚举其 (n) 位置。
