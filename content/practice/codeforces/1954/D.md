 ## 解决方案
 ## 问题理解

 我们得到了一组球，每个球都分配了一个`n`不同的颜色，其中颜色`i`有`a_i`球。 我们可以将这些球分组，但是每组最多可以有两个球，并且同一组中的两个球不能具有相同的颜色。 对于任何颜色子集，该子集的“值”是在这些约束下容纳这些颜色的所有球所需的最小组数。 我们的任务是计算所有值的总和`2^n`可能的颜色子集，模`998244353`。 

约束条件告诉我们`n`最多可达 5000 个，但球的总数也以 5000 个为界。这意味着即使`n`是比较大的，所有的总和`a_i`是谦虚的。 因此，根据球的总和而不是明确的子集数量进行缩放的算法是可行的。 试图枚举所有子集的简单方法是立即不可行的，因为`2^n`呈指数级增长。 

需要记住的一种边缘情况是仅包含一种颜色和多个球的子集。 例如，如果子集是`{1}`和`a_1 = 4`，最小组数为`2`因为每组只能配对两个球。 另一个棘手的情况是空子集，其值为零。 这些小细节至关重要，因为对空集或单例集的粗心处理可能会导致总和中出现相差一的错误。 

## 方法

 蛮力方法在概念上很简单。 对于每个`2^n`子集，我们可以计算该子集中任何单一颜色的球的最大数量，然后计算所需的最小组数。 对于一个子集`S`， 如果`max_count`是单一颜色中球的最大数量`S`，所需的组数至少为`max_count`，但将不同颜色的球配对有时会减少组的总数。 要为每个子集正确实现这一点，需要迭代子集、求和球和计算分组，这会花费`O(2^n * n)`。 这对于`n = 5000`。 

关键的见解来自于从动态规划的角度考虑问题。 我们可以累积地迭代球，而不是迭代子集。 由于所有球的总和最多为 5000，因此我们可以定义一个 DP 状态`dp[i][k]`作为使用第一个形成子集的方法的数量`i`颜色，以便所选球的总数为`k`。 这是一个经典的组合 DP 问题：对于每种颜色，我们可以选择 0 到`a_i`球，对于每个选择，我们都会更新`dp[i+1][new_k] += dp[i][k]`。 一旦我们知道确切包含的子集的数量`k`球，我们可以计算每个球的贡献`k`到最小组的最终总和，因为对于`k`球，最少组数为`(k + 1) // 2`（因为每组最多可以放2个球）。 这可以将问题从指数级减少到`n`球总数的二次方，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(2^n) | O(2^n) | 太慢了|
 | 总球数 | DP O(n * 总球数) | O(总球数) | 已接受 |

 ## 算法演练

 1. 计算球的总数，`total = sum(a_i)`。 这将是最大的`k`我们需要在我们的DP中考虑。 
2.初始化一个DP数组`dp`尺寸的`total + 1`和`dp[0] = 1`，代表空子集。 指数`k`表示在子集中选择的球的总数。 
3. 迭代每种颜色`i`。 对于每个球数`x`从`a_i`降到1，更新`dp[k + x] += dp[k]`为所有人`k`按降序排列。 这确保了对于之前的每个总计`k`，我们正在计算所有相加的方法`x`颜色球`i`没有重复计算子集。 
4. 处理完所有颜色后，`dp[k]`包含恰好具有的子集的数量`k`球。 子集的值`k`球是`(k + 1) // 2`，因为每组最多可以持有两个球。 
5. 迭代所有`k`从 1 到`total`, 和总和`dp[k] * ((k + 1) // 2)`。 应用模数`998244353`每一步都避免溢出。 
6. 输出总和作为答案。 

正确性取决于 DP 不变量：`dp[k]`准确地计算子集的数量`k`考虑所有颜色后的球。 配对球可以最佳地减少组数`(k + 1) // 2`对于任何子集大小`k`，因为每组配对两个球始终是最佳选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
a = list(map(int, input().split()))
total = sum(a)

dp = [0] * (total + 1)
dp[0] = 1

for balls in a:
    for k in range(total, -1, -1):
        if dp[k]:
            for x in range(1, balls + 1):
                dp[k + x] = (dp[k + x] + dp[k]) % MOD

result = 0
for k in range(1, total + 1):
    result = (result + dp[k] * ((k + 1) // 2)) % MOD

print(result)
```第一部分初始化空子集的 DP。 嵌套循环更新每种颜色的 DP 数组，按降序仔细迭代以避免多次计算相同的子集。 最后，我们应用整数除法公式计算按球数加权的值的总和`(k + 1) // 2`对于最小群体。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * 总计 ^2) | 对于每种颜色，我们迭代现有的 DP 总数，最多可达`a_i`球来更新新的总数。 由于total ≤ 5000，n*total^2 是可行的。 |
 | 空间| O（总计）| 我们只存储一个大小为 Total + 1 的 DP 数组。 

这完全符合 2 秒的限制，因为`5000*5000`运算量约为2500万次，这在Python中用简单的算术来说是可以接受的。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 998244353
    n = int(input())
    a = list(map(int, input().split()))
    total = sum(a)
    dp = [0] * (total + 1)
    dp[0] = 1
    for balls in a:
        for k in range(total, -1, -1):
            if dp[k]:
                for x in range(1, balls + 1):
                    dp[k + x] = (dp[k + x] + dp[k]) % MOD
    result = 0
    for k in range(1, total + 1):
        result = (result + dp[k] * ((k + 1)//2)) % MOD
    return str(result)
