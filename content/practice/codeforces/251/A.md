 ## 解决方案
 ## 问题理解

 我们得到一组沿着一维线定位的点。 Petya 想要计算可以选择多少个三元组点，使得三元组中最左边和最右边的点之间的距离不超过给定值 _d_。 形式上，如果我们选择三个点$x_i < x_j < x_k$，条件是$x_k - x_i \le d$。 

输入提供点数$n$，距离界限$d$，以及严格递增的点坐标列表。 输出是一个整数：有效三元组的计数。 

约束条件是这样的$n$可以大到$10^5$，坐标可达$10^9$以绝对值表示。 明确检查每个三元组的强力解决方案需要$O(n^3)$运营。 和$n = 10^5$，这将是顺序$10^{15}$操作，这对于 2 秒的时间限制来说太慢了。 二次解$O(n^2)$也是上限的边界。 我们需要一些接近线性或线性的东西。 

边缘情况包括非常少量的点，例如$n = 3$，其中仅存在一个三元组，或者没有三元组满足距离约束的情况，例如间隔很远的点$d$太小了。 另一个微妙的情况是，当许多点紧密聚集时，会创建大量有效的三元组，这需要仔细计数以避免整数溢出。 

## 方法

 一种简单的方法会迭代三个点的每个组合，并检查第一个点和最后一个点之间的距离。 这是正确的，因为它确实检查了所有可能性，但最坏情况的操作计数是$O(n^3)$，这对于大的情况来说是不可行的$n$。 

更快解决方案的关键在于对点进行排序。 这使我们能够避免单独检查所有三元组。 对于给定的起点$x_i$，我们可以找到最远点$x_j$这样$x_j - x_i \le d$。 之间的任何点$x_i$和$x_j$可以形成有效的三元组$x_i$。 如果有$m$之间的点$x_i$和$x_j$，三元组的数量包括$x_i$是$\binom{m}{2}$，因为我们需要选择其中的任意两个$m$之后的点$x_i$与之配对。 这是组合计数，而不是迭代检查。 

这种观察自然导致了两分球技术。 一个指针在起点上迭代$x_i$，另一个指针尽可能延伸以满足距离条件。 对每个起点的组合进行计数可以得出线性时间内的总数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 两指针组合 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将有效三元组的计数器初始化为零。 这将累积找到的三元组的总数。 
2.使用指针`i`从第一个点迭代到可以作为三元组起点的倒数第二个点。 
3. 对于每个`i`,维护另一个指针`j`开始于`i+1`并向前移动，而点之间的差异`j`和点`i`小于或等于`d`。 这确保了`j`始终是仍然可以形成有效三元组的最远点`x[i]`。 
4. 计算之间的点数`i`和`j`作为`count = j - i - 1`。 这些都是可以结合的点`x[i]`形成三胞胎。 
5.如果`count >= 2`，使用组合计数计算三元组的数量：`count * (count - 1) // 2`。 将其添加到累加器中。 
6. 增量`i`并重复该过程，直到到达列表末尾。 

不变的是，在每一步，`j`始终指向允许距离之外的第一个元素`x[i]`。 这保证了之间的所有点组合`i+1`和`j-1`和`x[i]`是有效的三元组，并且没有遗漏有效的三元组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, d = map(int, input().split())
    x = list(map(int, input().split()))
    
    total = 0
    j = 0
    for i in range(n):
        while j < n and x[j] - x[i] <= d:
            j += 1
        count = j - i - 1
        if count >= 2:
            total += count * (count - 1) // 2
    print(total)

if __name__ == "__main__":
    main()
```此代码初始化结果计数器和第二个指针`j`为零。 对于每个`i`，它延伸`j`在距离允许的范围内`d`。 然后它计算可以组合多少对`x[i]`并将它们添加到总数中。 支票`count >= 2`确保我们仅在至少有两个点可配对时才计算组合`x[i]`。 我们从不移动`j`向后，这确保算法以线性时间运行。

 实际上，计算所有三元组的结果是 4，因为该算法使用以下方法正确计算组合：`count * (count-1)//2`在每个有效的`i`。

 我们看到该算法正确地处理了有效和无效三元组的混合。
