 ## 解决方案
 ## 问题理解

 我们正在与一个具有隐藏整数阈值的系统进行交互$l$，统一从整数中选择$[x, y]$。 当我们在输入一定数量的字符后单击“保存”按钮时，系统会检查自上次成功保存以来我们已经输入了多长时间。 如果该长度最多为$l$，保存成功，我们的进度得以保留。 如果超过$l$，保存失败并且自上次保存以来输入的所有内容都将被丢弃。 

关键的难点在于$l$未知，并且失败的保存代价高昂，因为它既浪费打字工作又重置进度。 由于固定的上传延迟，成功的保存也很昂贵，但它保留了进度。 

我们必须总共输入$n$角色并确保他们最终都被保存。 每个角色需要一个时间单位，每次保存尝试都会花费额外的固定时间$t$。 目标是最小化期望的总时间，其中期望取代未知的均匀随机的时间$l$。 

一个关键的结构观察是，经过足够的保存尝试后，我们可以推断出$l$。 每次尝试都会比较选定的段长度$k$反对$l$: 成功意味着$l \ge k$, 失败意味着$l < k$。 因此，每次保存尝试都像一个无噪音的比较预言机，用于划分范围$[x,y]$。 

一次$l$已知，剩下的任务就变得确定了：我们最优地划分$n$字符分成大小块$l$，因为这是保存之间的最大安全间隔。 

限制很小：$n, x, y \le 100$。 这立即排除了对决策序列的任何指数策略$2^{100}$，但允许在区间上进行三次动态规划。 它还允许对所有可能的值求和$l$明确地。 

一个微妙的边缘情况是需要保存来确认进度，因此即使最后的文本块仍然会产生保存成本。 另一个是失败会导致自上次保存以来的所有进度丢失，因此任何仅假设局部惩罚而不重置行为的模型都会低估预期成本。 

## 方法

 一个幼稚的策略是固定保存间隔$k$并始终键入$k$保存前的字符。 这很简单，但并不是最优的，因为它忽略了从成功或失败中获得的信息。 特别是，如果保存失败，我们会了解到$l < k$，如果成功，我们就会学到$l \ge k$。 该信息应用于调整未来的决策。 

更基本的暴力观点是将所有可能的自适应策略模拟为决策树。 每个节点选择一个$k$，根据成功或失败进行分支，并在均匀分布上累积预期成本$l$。 这是正确的，但会组合爆炸，因为树的深度和分支因子都随着范围大小而增长，导致状态数量呈指数增长。 

关键的观察是知识的状态完全由一个区间来描述$[L, R]$包含可能的值$l$。 每次保存尝试都会将此间隔分为两个子间隔，具体取决于所选的是否$k$成功或失败。 这将问题转换为区间动态规划问题：对于每个区间，我们计算最优预期成本来识别$l$，然后将其与之后的确定性成本相结合$l$是已知的。 

一次$l$已知，剩余成本仅取决于有多少个完整大小的块$l$我们需要，再加上节省开销。 这将问题分为两部分：学习$l$，并执行给定的最佳$l$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 固定策略（常量$k$)|$O(n)$|$O(1)$| 次优 |
 | 全决策树模拟 | 指数| 指数| 太慢了|
 | 间隔 DP 超过$[L,R]$|$O((y-x)^3)$|$O((y-x)^2)$| 已接受 |

 ## 算法演练

 我们将解决方案分解为学习$l$然后完成打字过程。 

### 1. 计算之后的成本$l$已知

 对于固定的$l$，最好的策略是在准确输入后始终保存$l$人物。 任何较小的块都会增加保存次数，任何较大的块都有失败的风险。 

所以段数为$\lceil n / l \rceil$。 各段费用$l$打字时间加上$t$节省时间，所以总成本为：$$n + \lceil n/l \rceil \cdot t$$我们稍后将其平均$l \in [x,y]$。 

### 2.定义学习阶段的DP状态

 让$dp[L][R]$是确定确切值的最小预期成本$l$，假设我们知道它位于$[L,R]$。 

### 3. 通过选择探针长度进行转换$k$我们选择一个值$k \in [L,R]$并在输入后尝试保存$k$人物。 

这种尝试总是要付出代价$k + t$。 之后：

 - 如果成功，我们知道$l \in [k, R]$。 
- 如果发生故障，我们知道$l \in [L, k-1]$。 

因此预期成本为：$$k + t + \frac{R-k+1}{R-L+1} dp[k][R] + \frac{k-L}{R-L+1} dp[L][k-1]$$我们取所有最小值$k$。 

这样做的原因是每个动作都通过划分间隔来减少不确定性，并且没有其他信息$l$存在。 

### 4. 结合学习和完成

 最终的答案是：$$\frac{1}{y-x+1} \sum_{l=x}^{y} \left(dp[x][y] + n + \lceil n/l \rceil \cdot t \right)$$学习成本独立于$l$因为$dp[x][y]$已经对由以下因素引起的结果进行平均$l$。 

### 为什么它有效

 在过程中的任何一点，唯一相关的知识是可能值的区间$l$。 每个保存操作都会根据与所选内容的比较来生成此间隔的确定性分割$k$。 这意味着系统作为确定性区间细化过程而演化。 

DP 捕获了对此改进的最佳控制。 任何策略都对应一棵决策树，其节点为区间； 折叠相同的区间产生 DP 结构。 由于预期成本在概率上是线性的，并且转换仅取决于区间边界，因此最优子结构成立：一旦区间固定，未来的最优决策仅取决于该区间而不是过去的路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a):
    return pow(a, MOD - 2, MOD)

def solve():
    n, x, y, t = map(int, input().split())
    m = y - x + 1

    # dp[L][R] for learning l in [L,R]
    dp = [[0] * (y + 2) for _ in range(y + 2)]

    # intervals by length
    for length in range(2, m + 1):
        for L in range(x, y - length + 2):
            R = L + length - 1
            best = 10**30

            for k in range(L, R + 1):
                prob_fail_num = k - L
                prob_succ_num = R - k + 1

                cost = k + t

                if k > L:
                    cost += prob_fail_num / length * dp[L][k - 1]
                if k < R:
                    cost += prob_succ_num / length * dp[k][R]

                if cost < best:
                    best = cost

            dp[L][R] = best

    learn_cost = dp[x][y]

    inv = modinv(m)

    total = 0
    for l in range(x, y + 1):
        seg = (n + l - 1) // l
        total += n + seg * t
        total %= MOD

    ans = (int(learn_cost) + total * inv) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```DP 部分在所有可能的时间间隔内构建最佳策略$l$。 每个状态都会尝试所有可能的探测长度$k$，平衡直接成本$k+t$预期的持续成本由多少个值加权$l$落在每一边$k$。 

最后的循环计算之后的平均完成成本$l$是已知的。 该部分使用整数算术，因为它对每个部分都是纯粹确定性的$l$。 

模块化划分为$(y-x+1)$由于期望是统一的，所以使用模逆来处理。 

## 工作示例

 ### 示例 1

 输入：```
5 1 3 1
```我们考虑$l \in \{1,2,3\}$。 假设 DP 已经计算了这个时间间隔内的学习成本。 

对于每个$l$，完成成本为：

 | 我| 细分 | 总成本|
 | --- | --- | --- |
 | 1 | 5 |$5 + 5\cdot 1$|
 | 2 | 3 |$5 + 3\cdot 1$|
 | 3 | 2 |$5 + 2\cdot 1$|

 因此完成部分是这三个值的平均值。 DP 部分贡献了发现是否存在的预期成本$l$通过自适应探测为 1、2 或 3。 

这个例子展示了完成成本如何非线性地依赖于$l$，激励学习与执行的分离。 

### 示例 2

 输入：```
4 2 4 2
```这里$l \in \{2,3,4\}$。 探针例如$k=3$将区间分割成成功案例$[3,4]$以及失败案例$[2,2]$。 民主党将其与其他替代方案进行了比较，例如$k=2$或者$k=4$，每个都会产生不同的预期细化成本。 

这表明最佳探测不一定是二元分裂； 区间大小和探测成本的不平衡使最佳选择偏离中点。

 ## 边缘情况

 当$x = y$，DP 区间立即崩溃。 学习阶段变得无关紧要，因为不需要探测并且策略纯粹是确定性的。 该算法自然地处理这个问题，因为长度为 1 的间隔的 DP 表条目为零，并且期望减少到完成成本。 

什么时候$t$相对于打字成本来说较大，DP 倾向于选择较少的探测和较大的间隔，因为每次保存尝试都很昂贵。 这反映在转型成本中$k+t$，除非间隔大幅减少，否则它在细化效益中占主导地位。 

什么时候$n < l$，最优策略在输入所有内容后仍然执行保存$n$字符一次。 公式$\lceil n/l \rceil = 1$正确捕获这一点，因此不需要特殊处理。
