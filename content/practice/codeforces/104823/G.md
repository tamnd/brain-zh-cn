 ## 解决方案
 ## 问题理解

 我们给出了几个相同大小的二进制矩阵。 每个矩阵都可以看作是从网格位置到位的函数，并且输入中没有两个矩阵是相同的。 

任务是选择尽可能小的网格位置集，这样如果我们只查看这些位置，每个矩阵仍然会产生唯一的签名。 通过以固定顺序读取所选单元格并连接它们的值来形成签名。 如果两个矩阵的签名在至少一个选定位置上不同，则它们是可区分的。 我们希望所需的位置数量最少，以便所有给定的矩阵都具有成对不同的签名。 

关键维度上的约束非常小。 每个矩阵最多为 10 x 10，因此最多有 100 个位置。 矩阵的数量最多为 6。这立即表明对位置进行指数搜索是可行的，因为最多 100 个元素的子集是我们需要考虑的唯一组合对象，并且任何在动态编程意义上涉及完整网格结构的尝试都是不必要的。 测试用例的数量最多为 50 个，因此我们必须确保任何指数枚举都被有效修剪或表示为位集。 

一个幼稚的错误是假设贪婪地选择不同的位置是有效的。 例如，选择矩阵最常不同的位置仍然可能会失败，因为早期的选择可能会迫使以后无法区分。 

考虑具有三个矩阵 A、B、C 的情况，其中任何单个单元最多区分一对，但没有单个单元可以同时区分所有三个矩阵。 贪婪的选择可能会选择一个分隔 A 和 B 的单元格，然后需要另外两个单元格，而最佳解决方案会选择一对不同的单元格来同时分隔所有三个单元格。 

另一个陷阱是假设独立检查成对差异就足够了，而无需确保全局分离。 即使每对矩阵在所选集合中的某个地方有所不同，仍然可能错误地假设存在较小的集合，除非我们明确强制执行完整的签名唯一性。 

## 方法

 蛮力的观点很简单。 网格中的每个位置都可以选择或不选择，因此我们可以尝试位置的所有子集。 对于每个子集，我们通过读取所选位置的值来构造所有 k 矩阵的签名，并检查所有签名是否不同。 这是正确的，因为它直接实现了条件。 然而，位置最多有 100 个，因此这会导致 2^100 个子集，这是完全不可行的。 

关键的观察结果是 k 非常小，最多为 6。这意味着真正的约束不是网格大小，而是我们必须分离的对象数量。 我们可以考虑必须区分的矩阵对的子集，而不是考虑位置的子集。 

每个选定的单元格都会提供一点信息：它将矩阵集分成在该位置处值为 0 的矩阵和值为 1 的矩阵。 我们的目标是找到此类分割的最小集合，以确保每对矩阵至少由一个选定的位置分隔开。 换句话说，对于每对矩阵，必须存在一个不同的选定位置。 

这将问题转化为经典的对覆盖问题。 最多有 k(k−1)/2 对，即最多 15 个。每个网格位置定义这些对的子集：它恰好覆盖了在该单元格处不同的矩阵对。 我们需要选择覆盖对并集包含所有对的最少位置数。

这是覆盖最多 100 个集合的最小集合，覆盖最多 15 个元素，对于对集合上的位掩码动态编程来说足够小。 每个单元对应一个 15 位掩码，我们希望按位或变满的掩码数量最少。 

我们可以在 0 到 2^15 − 1 的掩码上运行 DP。对于每个网格位置，我们计算其对差掩码，然后放松过渡。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力对抗头寸 | O(2^100·k·n·m) | O(2^100·k·n·m) | O(k·n·m) | O(k·n·m) | 太慢了|
 | DP 成对掩模 | O(nm·2^{k^2})（实际上是 nm·2^15）| O(2^15) | O(2^15) | 已接受 |

 ## 算法演练

 我们首先通过仅关注给定单元区分哪些矩阵对来压缩问题。 

1. 枚举所有无序矩阵对，并为每对分配一个从 0 到 P−1 的索引，其中 P = k(k−1)/2。 这为我们提供了一个位掩码空间，其中每个位代表是否已区分特定对。 
2. 对于每个网格位置 (i, j)，计算一个掩码。 我们比较该位置的所有矩阵； 每当两个矩阵不同时，我们就设置相应的对位。 这个掩码准确地代表了这个单细胞可以区分哪些对。 
3. 将所有此类掩码收集到一个列表中，忽略掩码为零的单元，因为它们无法帮助区分任何对。 
4. 在掩码对上定义 DP 数组，其中 dp[x] 表示实现覆盖 x 所需的选定位置的最小数量。 初始化 dp[0] = 0 并将所有其他值初始化为无穷大。 
5. 对于每个单元掩码，以标准背包方式更新子集上的 DP。 对于每个现有状态 x，我们可以转换到 x | 面具成本+1。 
6. 处理完所有单元后，答案为 dp[full_mask]，其中 full_mask 已设置所有对位。 

我们不需要担心顺序或重复结构的原因是每个细胞对配对分离都有独立的贡献，只有它们贡献的并集才重要。 

### 为什么它有效

 每对矩阵必须至少在一个选定的单元格中不同，所选集合才有效。 将对编码为位将需求转换为有限宇宙上的完全覆盖条件。 每个细胞都对应着这个宇宙的一个固定子集，所以选择细胞就是选择子集来覆盖所有元素。 DP 探索这些子集的所有可实现的联合，并且因为我们始终为每个联合状态保留最小计数，所以最终值是达到完全覆盖所需的最佳单元数。 不会跳过任何有效的解决方案，因为每个子集选择都对应于一系列 DP 转换，并且不会接受无效的解决方案，因为显式检查了完全覆盖。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m, k = map(int, input().split())
        mats = []
        for _ in range(k):
            mat = [input().strip() for _ in range(n)]
            mats.append(mat)

        # build pair index
        pairs = []
        for i in range(k):
            for j in range(i + 1, k):
                pairs.append((i, j))
        p = len(pairs)

        full = (1 << p) - 1

        cell_masks = []
        for i in range(n):
            for j in range(m):
                mask = 0
                for idx, (a, b) in enumerate(pairs):
                    if mats[a][i][j] != mats[b][i][j]:
                        mask |= (1 << idx)
                if mask:
                    cell_masks.append(mask)

        INF = 10**9
        dp = [INF] * (1 << p)
        dp[0] = 0

        for mask in cell_masks:
            ndp = dp[:]
            for state in range(1 << p):
                if dp[state] == INF:
                    continue
                nxt = state | mask
                if dp[state] + 1 < ndp[nxt]:
                    ndp[nxt] = dp[state] + 1
            dp = ndp

        print(dp[full])

if __name__ == "__main__":
    solve()
```该解决方案首先将矩阵比较转换为成对差异，以便每个单元成为矩阵对上的位掩码。 然后，动态编程层重复合并这些掩码以建立覆盖范围。 关键的微妙之处在于使用复制的 DP 数组进行转换，以避免在单次迭代中多次重复使用同一单元，这将错误地允许多次选择一个位置。 

最终状态`full`对应于所有被区分的对，这保证了所有矩阵都是唯一的。 

## 工作示例

 考虑一个在 2 x 2 网格上包含三个矩阵的小场景。 目标是确定分隔这三个单元的最小数量。 

假设单元掩码计算如下：

 | 细胞| 初始状态| 配对 AB | 配对交流 | 配对 BC | 面膜|
 | --- | --- | --- | --- | --- | --- |
 | (0,0) | (0,0) | 一切平等| 0 | 1 | 1 | 110 | 110
 | (0,1)| AB 不同 | 1 | 0 | 1 | 101 | 101
 | (1,0)| 交流电不同| 0 | 1 | 0 | 010|
 | (1,1) | BC 不同 | 0 | 0 | 1 | 001|

 初始 dp 状态仅为 dp[000] = 0。 

处理 (0,0) 后，我们可以以成本 1 达到状态 110。在处理 (0,1) 后，我们可以以成本 2 达到 111，或者根据之前的状态以成本 1 达到 101。 DP 逐渐累积覆盖范围，直到以最小成本 2 达到全掩模 111。 

这表明来自不同单元的重叠覆盖通过按位或自然地组合。 

第二个示例是具有两个矩阵的示例案例，仅需要两个位置。 每个选定的位置都会产生部分分离，但只有它们的组合才能分离所有对。 DP 确保即使没有一个位置可以区分所有内容，也可以系统地探索组合。

 ## 边缘情况

 当许多细胞单独区分一对时，就会出现一种微妙的情况，但总的来说是冗余的。 例如，三个矩阵，其中一个单元格中的 A 和 B 不同，另一个单元格中的 B 和 C 不同，第三个单元格中的 A 和 C 不同。 该算法正确分配掩码 100、010、001，并要求所有三个掩码达到完全覆盖。 DP 自然会积累所有三个面罩，因为不存在以更便宜的方式覆盖两次的面罩。 

另一种情况是当单个细胞已经区分所有对时。 然后它的掩码已满，DP 立即将 dp[full] 更新为 1。任何额外的单元都不会改善结果，因为 DP 保持最小值。 

最后的边缘情况是某些单元格的掩码为零，因为所有矩阵在那里共享相同的值。 这些被安全地忽略，因为它们对任何对覆盖没有任何贡献，并且包含它们只会增加计算量而不会改善任何 DP 状态。
