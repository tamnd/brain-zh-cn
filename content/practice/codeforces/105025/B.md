 ## 解决方案
 ## 问题理解

 给定两个正整数$k$和$n$。 他们描述了一对隐藏的硬币价值$A$和$B$同时受到两种约束。 首先，一种硬币的价值是另一种硬币的乘法缩放：$A = k \cdot B$。 其次，相同的两个值相加相关：$A = B + n$。 

任务是判断是否存在正整数$A$和$B$同时满足两个方程。 如果存在这样的一对，我们必须输出一个有效的解决方案。 否则，我们输出$-1$。 

虽然该语句看起来像一个两个方程组，但关键的困难不是孤立地求解代数，而是确保结果值是整数并在约束下保持正值。 

约束条件允许$k, n \le 10^9$，因此任何解决方案都必须在每个测试用例的恒定时间内运行。 对可能的情况进行暴力搜索$A$或者$B$是不可能的，因为值可以大到$10^9$，甚至迭代到该界限也会超出时间限制。 

一个常见的错误来自于独立处理方程。 例如，采取$B = n$或者$A = k + n$忽略了两个方程必须同时成立。 当出现另一个微妙的问题时$k = 1$，因为系统退化并且许多方法除以$k - 1$休息。 

具体的边缘情况是$k = 1, n = 3$。 然后$A = B$从第一个方程中，还可以得到$A = B + 3$从第二个开始，这是不可能的。 任何盲目计算的解决方案$B = n / (k - 1)$会除以零并失败。 

## 方法

 该问题是一个变相的直接线性方程组。 蛮力的想法是尝试所有可能的值$B$并检查两个方程是否产生相同的结果$A$。 对于每个$B$，我们计算$A_1 = kB$和$A_2 = B + n$，并检查相等性。 这是正确的，但立即不可行，因为$B$可以达到$10^9$，在最坏的情况下导致线性时间。 

关键的观察是我们根本不需要搜索。 两个表达式为$A$必须相等，所以我们直接将它们相等：$$kB = B + n$$重新排列给出：$$(k - 1)B = n$$现在结构很简单。 如果$k = 1$，方程变为$0 \cdot B = n$，这只有在以下情况下才有可能$n = 0$， 但$n \ge 1$，所以无解。 否则，我们必须有$B = \frac{n}{k - 1}$，并且该值必须是整数。 一次$B$已确定，$A = kB$。 

这将整个问题减少到恒定数量的算术检查。

 | ---| ---| ---| ---|
 | 暴力破解 B |$O(n)$|$O(1)$| 太慢了|
 | 代数解 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取整数$k$和$n$。 这些定义了之间的比例和加法关系$A$和$B$。 
2. 检查是否$k = 1$。 如果是这样，两个方程都强制$A = B$，但第二个方程需要$A = B + n$，这对于任何正数都是不可能的$n$。 在这种情况下，输出$-1$。 
3.如果$k \ne 1$, 计算$k - 1$。 该值表示超出平等的缩放比例应用于多少$B$。 
4. 检查是否$n$可以整除$k - 1$。 这确保了$B = \frac{n}{k - 1}$是一个整数。 如果不可整除，则不存在有效的整数解，因此输出$-1$。 
5. 如果可整除，计算$B = n // (k - 1)$。 这是唯一符合这两个约束的候选值。 
6. 计算$A = k \cdot B$。 这保证了乘法和加法方程同时成立。 
7. 输出$A$和$B$。 

### 为什么它有效

 两个约束都定义同一变量的线性表达式$A$。 该算法通过使它们相等来强制一致性，将问题简化为单个线性丢番图方程。 由于代入后只有一个未知数，因此要么恰好有一个整数解，要么根本没有。 每一步都保留等价变换，因此产生的任何解都必须满足两个原始方程，并且任何有效解必须满足导出的整除条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

k, n = map(int, input().split())

if k == 1:
    # A = B and A = B + n => impossible for n > 0
    print(-1)
else:
    if n % (k - 1) != 0:
        print(-1)
    else:
        b = n // (k - 1)
        a = k * b
        if b > 0 and a > 0:
            print(a, b)
        else:
            print(-1)
```代码直接遵循导出的方程。 特殊情况$k = 1$显式处理以避免被零除。 可除性检查确保我们只构造整数解。 在限制条件下，阳性检查在技术上是多余的$k, n \ge 1$，但它可以防止格式错误的推导并保持逻辑明确。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    k, n = map(int, input().split())

    if k == 1:
        return "-1\n"
    if n % (k - 1) != 0:

 ## 边缘情况

 ###案例$k = 1$输入`1 3`力量$A = B$从乘法约束和$A = B + 3$来自加性约束。 该算法立即分支$k = 1$和输出$-1$无需任何算术，防止被零除的情况。 

### 不可分割$n$输入`4 7`导致$B = 7 / 3$，它不是整数。 该算法通过以下方式检测到这一点`n % (k - 1) != 0`并驳回该案。 这是至关重要的，因为否则分数硬币价值将被错误地接受。 

### 最小有效系统

 输入`2 2`给出$B = 2 / 1 = 2$,$A = 4$。 该算法正确地构造并输出一个有效的对，确认除了可分性和正性之外不需要额外的约束。
