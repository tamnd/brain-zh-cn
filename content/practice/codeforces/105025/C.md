 ## 解决方案
 ## 问题理解

 我们得到了代表屋顶连续部分的一系列高度。 每个部分都有固定的高度，我们希望将太阳能电池板放置在这些部分的连续间隔上。 唯一的限制是，在选定的区间内，高度必须是单调的，要么完全不减少，要么完全不增加。 

任务是找到最长的连续间隔并输出其端点。 

输入大小可以高达一百万个元素。 这立即排除了任何显式检查所有子数组的方法。 对所有端点对进行二次扫描将需要大约 10^12 次操作，这远远超出了时间限制。 即使是立方或嵌套扫描方法显然也是不可能的。 

需要线性或近线性扫描，这意味着我们应该期望一种解决方案能够在单次处理数组的同时保持某些局部单调性结构。 

当最佳段跨越具有相等值的长段时，会出现微妙的边缘情况。 例如，像 5 5 5 5 5 这样的数组对于非递减和非递增都是有效的，因此必须返回整个数组。 任何在坡度变化中不一致地处理相同元素的解决方案都有可能破坏这种情况。 

另一种边缘情况是当数组严格交替时，例如 1 3 2 4 3 5。最长的单调段可能只有长度 2，并且解必须在每次方向变化时正确重置。 

## 方法

 暴力破解的想法很简单：尝试每对端点 l 和 r，检查该段是非递减还是非递增，并跟踪最大长度。 对于每个分段，验证单调性需要 O(n) 时间，并且有 O(n^2) 个分段，总体上为 O(n^3)。 即使我们使用前缀比较来优化检查，我们仍然会得到 O(n^2)，这对于 n 高达 10^6 来说太慢了。 

关键的观察结果是单调性是局部属性。 一旦方向确定，它就会持续下去，直到被打破。 这意味着数组可以分解为最大单调游程，并且答案必须是这些游程之一或共享转折点的两个游程的组合。 

更准确地说，如果我们将每个位置视为潜在的“转折点”，我们可以向左和向右扩展，同时保持不减少或不增加的条件。 我们可以重用来自邻居的信息并维护运行的段，而不是从头开始重新计算每个 l。 

这导致了线性扫描解决方案，我们动态跟踪两种类型的单调段：增加和减少。 我们尽可能延长它们，并在条件中断时重置。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) 到 O(n^3) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 当我们遍历数组时，我们维护两个运行长度：以位置 i 结束的非递减线段的当前长度，以及以位置 i 结束的非递增线段的当前长度。 我们还跟踪迄今为止看到的最好的片段。

1. 将第一个元素的递增长度和递减长度初始化为 1。 此时，任何单个元素都是有效的。 
2. 从索引 1 开始从左到右迭代数组。 
3. 如果当前高度大于或等于前一个高度，我们可以延长非递减段。 否则，我们将其重置为长度 1，因为单调性被破坏。 
4. 如果当前高度小于或等于前一个高度，我们可以延长非增加段。 否则，我们将其重置为长度 1。 
5. 更新两个状态后，将当前最佳结局 i 与全局最佳答案进行比较。 如果任一单调方向产生较长的线段，则相应地更新存储的最佳端点。 
6. 继续直到数组末尾，通过记住每次运行的开始位置始终保持正确的段边界。 

关键细节是，我们不仅必须跟踪长度，还必须跟踪每次当前运行的起始索引，因为答案需要端点，而不仅仅是长度。 

### 为什么它有效

 在每个位置 i，任何以 i 结尾的有效单调子数组必须是以 i 结尾的最大非递减游程的一部分，或者是以 i 结尾的最大非递增游程的一部分。 这些运行是由局部比较唯一确定的，并且在不违反单调性的情况下无法进一步扩展。 由于每个有效解决方案都包含在这些最大运行之一中，因此检查所有运行隐式涵盖了所有候选方案。 该算法永远不会错过候选者，因为每个有效间隔恰好是这些维护的单调段之一的后缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n_and_rest = input().split()
    if not n_and_rest:
        return
    n = int(n_and_rest[0])
    h = list(map(int, input().split()))
    
    if n == 1:
        print(1, 1)
        return

    best_len = 1
    best_l = 1
    best_r = 1

    inc_start = 0
    dec_start = 0
    inc_len = 1
    dec_len = 1

    for i in range(1, n):
        if h[i] >= h[i - 1]:
            inc_len += 1
        else:
            inc_len = 1
            inc_start = i

        if h[i] <= h[i - 1]:
            dec_len += 1
        else:
            dec_len = 1
            dec_start = i

        if inc_len > best_len:
            best_len = inc_len
            best_l = inc_start + 1
            best_r = i + 1

        if dec_len > best_len:
            best_len = dec_len
            best_l = dec_start + 1
            best_r = i + 1

    print(best_l, best_r)

if __name__ == "__main__":
    solve()
```该实现保留了两个独立的滑动窗口。 当下一个元素不小于时，增加的窗口将扩展，否则它将重置并从当前索引开始。 递减窗口的行为是对称的。 

关键的实现细节是，当发生重置时，起始索引将设置为当前位置，而不是前一个位置。 这确保了严格反转（例如 1 3 2）的正确性，其中段必须分别从 3 和 2 重新开始。 

我们还以基于 1 的形式维护最佳索引，仅在输出时从基于 0 的索引转换。

 ## 边缘情况

 对于像 7 7 7 7 7 这样的常量数组情况，两个单调条件始终成立。 该算法不断扩展 inc_len 和 dec_len，从不触发重置。 最佳段在最终索引处更新以覆盖整个范围，正确生成 1 5。 

对于诸如 1 3 2 4 之类的尖锐之字形，递增线段在 2 和 4 处重置，而递减线段在 3 处重置。最长的有效行程为 1 3 或 3 4，具体取决于方向，并且算法正确地将长度 2 线段识别为最佳线段。 

对于严格单调递减的输入（如 5 4 3 2），递减计数器在每一步都会不间断地增长。 递增计数器在每一步都会重置，但不会影响最终答案，因为递减运行占主导地位。
