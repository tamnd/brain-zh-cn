 ## 解决方案
 ## 问题理解

 两名玩家通过交替在顶部放置方块来建造一座塔。 每个块的权重介于$l$和$r$，并且两个玩家都可以根据需要多次重复使用任何重量。 

塔起始总重$0$。 每次移动后，所选块的重量都会添加到总重量中。 当总重量达到至少时游戏立即结束$k$。 做出达到或超过动作的玩家$k$才是输的人。 

这个问题纯粹是战略性的：假设两个玩家都发挥最佳，并且语句中的第二个玩家是开始的玩家，我们必须确定第一步是否已经决定了游戏，或者第二个玩家是否可以通过正确的响应来强制获胜。 因此，输出是关于获胜玩家的二元决策。 

约束条件$k, l, r \le 10^9$排除对总和状态的任何模拟。 对所有可能的塔高度进行简单的动态规划$k$需要$O(k)$国家，这是完全不可行的。 试图追踪可达到的金额的更精细的 DP 仍然取决于$k$，太大了。 

游戏的结构表明，只有剩下的“差距”才能达到$k$重要的是，动作的确切顺序并不重要。 通过减去选定的权重，该差距会确定性地演变，并且当移动超过阈值时，就会触发失败条件。 这立即暗示问题应该分解为单个整数的经典减法游戏。 

当剩余间隙小于$l$。 在这种情况下，每一个可能的动作都会超过阈值，这意味着当前玩家被迫立即失败。 另一种拐角情况发生时$k$仅略大于$l$，一步棋就可以立即结束游戏，从而使第一个决定具有决定性。 

## 方法

 直接模拟将跟踪当前总和并递归地尝试来自中的每个可能的块权重$l$到$r$。 来自总和的状态$s$，我们将分支到所有州$s+x$。 这形成了一个分支因子高达的博弈树$r-l+1$，深度可达$k/l$。 即使忽略重叠状态，这也会远远超出任何合理的复杂性。 

关键的观察是只有剩余容量才能达到$k$很重要。 如果我们定义$N = k - s$，然后每一步减去一个值$x \in [l, r]$。 仅当不超过限制时，移动才是合法的，这意味着$x \le N$。 如果每一步都违反了这一点，玩家就会立即失败。 这将问题转化为一个标准的外卖游戏：有一堆大小$N = k-1$，并且玩家在之间移除$l$和$r$石头。 不能移动的玩家就输了。 

这是具有连续移动间隔的单堆上的经典公正游戏。 该结构是周期性的：结果仅取决于$N \bmod (l+r)$。 这种周期性的出现是因为最佳游戏将线路划分为不同长度的块$l+r$，其中第一个$l$每个块中的位置与其余块的行为不同$r$。

 ## 算法演练

 1、将问题转化为剩余容量$N = k - 1$。 这是塔被强制破坏之前可用的总量，因此每一步都相当于减少$N$一定数量的$[l, r]$。 
2.观察如果$N < l$，不存在合法的移动，因为即使是最小的块也超过了剩余容量。 在这种情况下，当前玩家立即失败。 
3. 计算周期长度$l + r$，它代表减法过程中“安全”和“危险”区间交替的自然周期结构。 
4.减少仓位使用$N \bmod (l + r)$。 这是有效的，因为在每个完整的长度段之后$l+r$，游戏状态以胜负结构重复。 
5. 如果余数在区间内$[0, l-1]$，该位置正在失败，因为每一个可能的动作要么立即超出，要么转变为对手的获胜状态。 
6. 否则，该位置获胜，因为至少存在一着棋将对手推入失败的残级。 

### 为什么它有效

 游戏将整数线分割成大小重复的段$l+r$。 在每个段中，第一个$l$位置对应于任何移动变得非法或强制转变为对对手有利的配置的状态。 这会创建一个固定的丢失状态重复每个周期的模式。 由于每次移动最多都会减少剩余容量$r$，它总是落在下一个结构化段内，保留这种周期性分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k, l, r = map(int, input().split())
    n = k - 1

    if n < l:
        print(2)
        return

    cycle = l + r
    rem = n % cycle

    if rem < l:
        print(2)
    else:
        print(1)

if __name__ == "__main__":
    solve()
```解决方案首先将获胜阈值转换为标准减法游戏大小$n = k-1$。 这种转变是必要的，因为当累计金额达到$k$，这对应于耗尽大小的资源$k-1$。 

支票`n < l`处理不存在合法举动的强制损失情况。 这避免了在无效状态下依赖模块化逻辑。 

表达式`n % (l + r)`将状态压缩为其重复结构中的规范代表。 与它比较$l$将失败和获胜残基分开，这些残基对玩家是否陷入循环的强制失败前缀进行编码。

 ## 边缘情况

 当$k-1 < l$，玩家在不突破门槛的情况下无法做出哪怕是最小的动作。 算法直接通过条件捕获这一点`n < l`，立即返回亏损。 

对于输入，其中$n$恰好是$l+r$，余数变为零。 这属于亏损部分$[0, l-1]$仅当$l > 0$，在约束条件下始终为真，因此此类头寸被正确识别为亏损。 

什么时候$l = r$，游戏简化为定步减法。 模逻辑仍然有效，因为周期变为$2l$，将头寸分割成大小交替的获胜和失败块$l$，并且相同的余数条件可以正确地对它们进行分类。
