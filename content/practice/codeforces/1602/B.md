 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，其中每个元素都在 1 和数组大小之间。 通过重复的步骤，数组中的每个元素都被替换为它在数组中出现的次数。 每次转换后，新数组将成为下一步的基础。 对于数组中的任何位置，我们可能会被问到在任意数量的步骤（可能高达十亿）之后它的值将是多少。 

输入包括多个测试用例。 每个测试用例都提供初始数组和多个查询。 每个查询指定一个索引和步数，我们必须在请求的步数之后报告该索引处的值。 

第一个观察结果是，任何测试用例中的数组大小都不会超过 2000，但查询数量可以高达 100,000。 这意味着独立模拟每个查询是不切实际的。 每一步都需要计算数组中每个元素的出现次数，时间复杂度为 O(n)。 天真地执行 k 步骤将是 O(n * k)，并且当 k 达到 10^9 时，这太慢了。 

当步数为零时会出现边缘情况，这应该直接返回初始数组。 另一个微妙的情况是元素过早稳定：某些数组达到了所有元素在几个步骤后不再发生变化的状态。 例如，所有相等值的数组在一步中变为常数，因此任何要求非常大的 k 的查询都将返回与第一次稳定后相同的值。 

## 方法

 强力解决方案明确地模拟每个转换步骤。 对于每个查询，我们将循环 k 次，计算每个元素的出现次数并更新数组。 这是正确的，但最坏的情况是 n=2000，k=10^9，q=100,000，这是完全不可行的。 

关键的见解是转型过程最终会趋于稳定。 由于每个元素都被其频率替换，因此数组不能产生大于 n 的值，并且重复计数会导致固定数组，其中每个元素等于上一步中其值的频率。 在实践中，稳定很快就会发生。 稳定任何大小为 n 的数组所需的最大步骤数最多为 n。 因此，我们可以预先计算所有数组，直到它们稳定并存储每个中间状态。 然后，如果 k 超过预先计算的步骤数，则回答任何查询都会减少到选择适当的步骤或最后一个稳定的数组。 

我们可以将此预计算表示为数组列表。 对于每一步，我们通过计算前一个数组元素的出现次数来计算一个新数组。 当新数组与前一个数组相同时我们停止。 一旦稳定的数组被预先计算，每个查询都是一个简单的数组查找，要么在步骤 k 要么在最后一步（如果 k 超过稳定）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * k * q) | O(n * k * q) | O(n) | 太慢了 |
 | 预计算直至稳定 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 对于每个测试用例，读取数组大小 n 和初始数组 a。 
2. 初始化列表`arrays`将初始数组作为其第一个元素。 这将存储每一步的数组直到稳定。 
3. 输入循环以生成后续数组。 计算当前数组中每个数字的出现次数。 将每个元素替换为其计数。 将新数组附加到`arrays`。 如果新数组与前一个数组相同，则中断循环，因为已达到稳定状态。 
4. 读取查询数q。 对于每个查询，读取索引 x 和步骤 k。 如果 k 超过使用最后稳定数组计算的步数，则调整 k。 输出步骤k对应的数组中位置x-1处的值。 

为什么有效：每个转换都是确定性的，并且仅取决于元素的数量。 由于最大可能值以 n 为界，并且只有 n 个位置，因此数组必须稳定在最多 n 个步骤中。 预先计算所有步骤可以保证任何查询都能得到正确回答，即使 k 非常大。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    arrays = [a[:]]  # store arrays at each step
    while True:
        prev = arrays[-1]
        freq = [0] * (n + 1)
        for val in prev:
            freq[val] += 1
        new_arr = [freq[val] for val in prev]
        if new_arr == prev:
            break
        arrays.append(new_arr)
    
    q = int(input())
    for _ in range(q):
        x, k = map(int, input().split())
        step = min(k, len(arrays)-1)
        print(arrays[step][x-1])
```解决方案首先要有效地读取输入。 我们存储所有中间数组来处理每个查询的 O(1) 查询。 计数是使用大小为 n+1 的简单频率数组完成的，这是安全的，因为所有值都 ≤ n。 当数组不再更改时循环停止，确保我们不会在不必要的步骤上浪费内存或计算。 对于每个查询，如果 k 大于稳定步长，我们将 k 钳位到最后一个预计算的数组，以保证正确性。
