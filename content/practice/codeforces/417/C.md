 ## 解决方案
 ## 问题理解

 我们被要求构建完整的比赛记录`n`每场比赛都有胜者和败者，并且没有两队比赛超过一次。 我们必须满足的最终条件是全局的：对于每对有序的不同团队`(i, j)`， 团队`i`必须击败球队`j`确切地`k`次。 

另一种查看此问题的方法是将其视为有向多重图`n`顶点。 每场比赛都是从胜者到败者的定向优势。 在任意两个顶点之间，每个方向最多可以有一条边，因为两支球队在同一配对中不能进行多次比赛。 要求变成对于每个有序对`(i, j)`，正好有`k`有向边从`i`到`j`。 

这会立即确定匹配的总数。 有`n(n-1)`有序对，每个对贡献准确`k`边，所以答案必须包含`m = k * n * (n-1)`如果存在解决方案，则进行游戏。 

限制条件`n, k ≤ 1000`允许大约一百万条边，因为`n(n-1)k ≤ 10^6`。 任何构造边的解决方案`O(n^2 k)`仍然可行，但是任何尝试模拟复杂调度或动态维护全局一致性的行为都会带来不必要的开销。 

一个微妙的边缘情况是`n = 1`。 There are no pairs of distinct teams, so there are no matches at all. The requirement is vacuously satisfied, so the correct answer is a single line`0`。 另一个角落是`k = 0`，同样不需要匹配，答案应该是`0`。 假设每对至少有一个边的粗心构造会错误地尝试输出非空的东西。 

主要困难不是可行性，而是在每个无序对在每个方向只能出现一次的限制下构造，同时仍然实现`k`在各个方向上获胜。 

## 方法

 暴力思维会尝试一对一地分配比赛，并使用回溯或增量调度来确保准确的获胜次数。 人们可以想象迭代所有有序对`(i, j)`并尝试准确分配`k`获胜于`i`到`j`，在每一步检查约束是否仍然可满足。 这很快就会退化为约束满足问题`O(n^2 k)`决定，但每个决定都取决于所有未来的任务。 在最坏的情况下，搜索空间会呈指数增长，因为每个分配都会对称地影响整个图中的剩余容量。 

需求的结构比看起来简单得多。 每对订购的`(i, j)`与所有其他因素无关：获胜次数`i`到`j`不与其他对互动。 唯一的限制是我们不能在同一层构造中多次重复使用相同的有序对。 这建议将结构分为`k`相同的回合。 

在每一轮中，我们需要确定每个无序对的方向`{i, j}`恰好一次，产生`i → j`或者`j → i`。 如果我们可以设计一个回合，其中每对作为有向边恰好出现一次，然后重复该结构`k`times 立即将所有计数精确相乘`k`每个有序对在每个方向上获胜。 

因此，任务简化为构建一次锦标赛（完整图的完整方向）。 标准的循环排序可以实现这一点：将团队排列成一个圆圈，并将每个边缘沿着圆圈向前定向。 重复这个方向`k`times 满足所有约束，因为每一对每轮只出现一次并且始终具有相同的方向。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力回溯| 指数| O(n²k) | O(n²k) | 太慢了 |
 | 循环赛建设| O(n²k) | O(n²k) | O(1) 额外 | 已接受 |

 ## 算法演练

 1.如果`n == 1`或者`k == 0`， 输出`0`并停止。 在这些情况下，没有可构建的有效匹配。 
2. 修正队伍顺序`1`到`n`。 
3. 对于单轮，迭代所有对`(i, j)`和`i < j`。 对于每一对，一致地决定一个方向，例如始终`i → j`。 这形成了一个完整的锦标赛，其中每对都只使用一次。 
4. 重复这个单轮构建`k`次。 每次重复都是相同的，产生相同的有向边集。 
5. 输出所有生成的匹配项。 边的总数为`k * n * (n - 1) / 2`如果每一对每轮仅贡献一次定向匹配，但由于每个有序对都必须出现`k`有时，我们通过构造一致性明确地在各轮中发出每对的两个方向。 

更精确的解释是，每个无序对在每轮中恰好贡献一个有向边，并且重复轮次确保每个有序对准确地出现`k`总共次数。 

### 为什么它有效

 每个无序对`{i, j}`每轮只考虑一次，并且其方向是固定的。 这保证了在一轮中，恰好有一个`i → j`或者`j → i`出现。 超过`k`相同的回合，每个有序对都完全相同`k`如果我们确保在不同的轮次中我们交替或系统地分配方向，以便在重复中均匀地覆盖两个方向，则可以多次进行。 循环移位解释确保每对都精确地指向两个方向`k`总体而言，满足所需的对称性。 关键的不变性是，每对在重复中都被独立且统一地处理，因此线性计数规模而不会产生干扰。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if n == 1 or k == 0:
    print(0)
    sys.exit()

res = []

for _ in range(k):
    for i in range(1, n + 1):
        for j in range(i + 1, n + 1):
            res.append((i, j))
            res.append((j, i))

print(len(res))
for a, b in res:
    print(a, b)
```该构造直接迭代所有无序对`(i, j)`并在每次重复中发出两种可能的定向匹配。 这确保了对于每个有序对`(i, j)`，每轮恰好出现一次，并且跨越`k`四舍五入，累积到恰好`k`发生。 

关键的实现细节是我们在每轮内显式输出每对的两个方向。 这避免了任何跟踪或平衡方向的需要。 循环的顺序确保了确定性的输出，并保证在单轮内不会丢失或重复任何对。

 ## 边缘情况

 当`n = 1`，循环永远不会生成任何对，因此结果列表保持为空，输出为`0`。 这符合要求，因为没有需要满足的有序对。 

什么时候`k = 0`，保护条件立即返回`0`无需输入构造逻辑。 这可以避免在不需要游戏时生成无效匹配。 

对于小`n = 2`，该结构每轮恰好产生两个定向边，每个方向一个。 重复这个`k`次产生平衡计数`k`双向，精确匹配要求。
