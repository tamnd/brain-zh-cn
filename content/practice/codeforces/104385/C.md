 ## 解决方案
 ## 问题理解

 我们得到了几堆石头。 两名玩家轮流进行，每个回合中一名玩家恰好选择一堆石子并从中取出一些石子。 不同的是，删除的数字必须是固定整数的幂$p$，所以允许的移动是$1, p, p^2, p^3, \dots$，只要所选值不超过堆大小。 当所有牌堆都空时，无法做出任何有效动作的玩家就会失败。 

任务是在假设两名玩家都发挥最佳的情况下确定第一位玩家是否强制获胜。 

约束条件很大：最多$3 \cdot 10^5$桩，以及桩尺寸和$p$可以大到$10^{18}$。 这立即排除了任何模拟移动甚至在所有可能状态上构建每桩 DP 的方法。 任何解决方案都必须独立处理每个堆并将每个堆减少到一个小的表示。 

当出现微妙的边缘情况时$p = 1$。 在这种情况下，每次移动都会恰好移除一颗石头，因此每个堆的行为就像一个标准的 Nim 堆，其中每次移动都会使堆减少 1。这将游戏分解为一个简单的奇偶校验问题，但这是一个幼稚的实现，仍然试图生成$p$可能会陷入无限循环，因为$p^k = 1$为所有人$k$。 

另一个重要的边缘情况是当堆非常大并且$p$也很大。 在这种情况下，大多数权力都超出了$p^1$立即超过堆大小，因此只有少数移动大小是相关的。 任何可以全局预先计算所有幂且不受限制的解决方案$10^{18}$风险溢出或不必要的工作。 

## 方法

 思考该游戏的一种直接方式是将其视为多桩公正游戏，其中每次移动都会精确地减少一堆来自固定移动集的值。 这表明了斯普拉格-格伦迪理论。 对于每个桩尺寸$a$，我们可以通过考虑所有可达状态来计算其 Grundy 值$a - p^k$并采取墨西哥。 

这在概念上可行，但在实践中太慢了。 每堆尺寸可达$10^{18}$可能有周围$O(\log_p a)$可能的移动，并独立重新计算最多可达$3 \cdot 10^5$桩导致大致$O(n \log a)$，这是临界点，但仍然可能很昂贵。 更糟糕的是，真正的问题是，除非我们找到结构，否则在朴素的 DP 公式中状态空间并不是独立的。 

关键的观察结果是，游戏的表现非常不同，具体取决于是否$p = 1$或者$p \ge 2$。 

什么时候$p \ge 2$，移动的集合是$1, p, p^2, \dots$。 这些是稀疏的并且呈指数增长。 这创建了一个基础 -$p$结构：每个整数$a$可以在基础上分解$p$，每一步对应减去一位数位置的权重$p^k$。 这使得游戏相当于一个 Nim 堆，其 Grundy 值是基数中数字的异或$p$，但最重要的是，进位不会以复杂的方式跨堆交互，因为每次移动只影响一堆。 

事实证明，对于$p \ge 2$，一堆的 Grundy 值只是其基数之和的奇偶性$p$数字。 这将每个堆减少为一位：无论该总和是偶数还是奇数。 一旦进行了这种减少，整个游戏就成为这些位上的标准 Nim。 

为了$p = 1$，每一步都会移走一块石头，因此每堆只直接贡献其奇偶性，因为每堆只是一个长度链$a$。 

因此，在这两种情况下，每个桩都会减少为单个 XOR 相关值，并且最终答案是通过对所有桩贡献进行异或来确定的。

 ## 算法演练

 我们独立处理每一堆并将其转换为单个 XOR 贡献。 

1.如果$p = 1$，我们观察到每次移动都恰好移走一颗石头。 一堆尺寸$a$行为就像一个链条，其中最佳游戏仅取决于是否$a$是奇数还是偶数。 所以我们将每一堆减少到$a \bmod 2$。 这是有效的，因为每一步都会翻转剩余棋子的平价。 
2.如果$p \ge 2$，我们分解每个桩的大小$a$在基地$p$。 我们通过取重复提取数字$a \bmod p$并除以$p$。 
3. 对于获得的每个数字，我们将其值模 2 累加到该堆的运行奇偶校验计数器中。 这代表了所有权力的总贡献是否$p$这堆中的奇数或偶数。 
4. 如果该奇偶校验为奇数，则该堆贡献 1，否则为 0。 
5. 我们对所有桩贡献进行异或。 如果最终的异或非零，则第一个玩家获胜。 

数字奇偶性之所以重要，是因为每次移动都会恰好消除一个幂$p$，并且这些移动独立地作用于基数中的每个数字位置$p$。 由于此类减法游戏中的 Grundy 值在此指数移动集中崩溃为奇偶校验，因此仅可选择贡献的总数是否为奇数会影响最终状态。 

### 为什么它有效

 每堆实际上是独立分量的总和，对应于$p$。 每一次移动都恰好去除了一个这样的成分，并且该结构确保了不同数量级之间不存在无法计数的相互作用。 这使得每一堆相当于一堆代币，其中只有可表示组件的奇偶性很重要。 这些奇偶校验的 XOR 给出了标准 Nim 结果条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def pile_value(a, p):
    if p == 1:
        return a % 2

    parity = 0
    while a > 0:
        parity ^= (a % p) % 2
        a //= p
    return parity

def solve():
    n, p = map(int, input().split())
    arr = list(map(int, input().split()))

    x = 0
    for a in arr:
        x ^= pile_value(a, p)

    print("GOOD" if x != 0 else "BAD")

if __name__ == "__main__":
    solve()
```代码将特殊情况分开$p = 1$立即因为碱分解退化。 对于一般$p$，通过重复提取基数来减少每堆$p$数字并对它们的奇偶校验进行异或运算。 最终的 XOR 使用标准公正博弈论确定获胜者。 

一个微妙的点是我们从不预先计算$p$，完全避免溢出。 循环运行在$O(\log_p a)$，这是安全的$10^{18}$。

 ## 边缘情况

 对于$p = 1$，算法将每一堆减少到$a \bmod 2$。 例如，输入`4 1`有桩`1 2 3 4`产生一堆值`1,0,1,0`，给出 XOR 0，所以第二个玩家获胜。 该实现直接处理此问题，无需进入数字循环，从而避免了对 1 的重复幂的无限迭代。 

对于非常大的$p$， 例如$p > a$，每堆仅贡献其最低数字。 例如，与$p = 10^{18}$和$a = 5$，base-p 分解有一个数字 5，堆值变为 1。循环每个堆执行一次，保持正确性和效率。 

对于大型同质输入（例如许多相同的桩），XOR 结构可确保正确处理取消行为。 如果出现偶数个相同的桩值，则它们抵消为零； 如果奇怪，它们会保留下来，符合标准 Nim 行为。
