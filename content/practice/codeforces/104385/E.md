 ## 解决方案
 ## 问题理解

 我们给出了一个范围从 0 到 2^n − 1 的完整线段树。该问题不是直接使用数组，而是通过在区间 [L, R] 上运行线段树查询过程来构造归纳图 G。 该过程准确地收集覆盖该区间所需的线段树节点，并使用与原始线段树中相同的父子结构连接它们。 每条边也被标记为 0 或 1，具体取决于它是否对应于向左子节点或右子节点的移动。 

因此，结果是一棵树，其节点是线段树区间，其边表示原始线段树结构中的邻接关系，但仅限于接触 [L, R] 的部分。 

然后两名玩家在这棵树上玩耍。 在每次移动中，玩家选择至少两个节点 x1 < x2 < ... < xm 的序列。 这些节点必须在 G 内部形成一条简单路径，并且沿该路径的边必须全部具有相同的标签：Lyra 只允许选择仅使用 0 边的路径，而 Bon Bon 仅限于仅使用 1 边的路径。 选择这样的路径后，所有选定的节点及其关联边都将从图中删除。 

每次移动后，剩余的图必须保持连接。 此外，禁止删除节点 1（原始线段树的根），除非该移动删除了整个图。 

无法做出有效动作的玩家失败。 对于每个测试用例，我们都会被问到 Lyra 是否在最佳发挥下获胜。 

约束的深度很小，因为 n ≤ 61，这意味着线段树的高度最多为 61。测试用例的数量可以大到 10^6，因此每个测试用例的解决方案本质上必须是 O(1) 或 O(log n)。 

主要困难在于，虽然树来自线段树结构，但游戏不是在数组上进行的，而是在结构化诱导树上进行的，并且移动取决于该结构中的单色路径。 

简单的模拟将显式构造查询树 G，在最坏的情况下具有 O(2^n) 结构，即使对于 n 很大时的单个测试用例也是不可能的。 

第二个天真的想法是模拟游戏状态或计算树上的 Grundy 值。 这会立即失败，因为树的大小是 n 的指数，并且可能的移动次数是组合的。 

一个微妙的边缘情况是当 [L, R] 完全匹配单个线段树节点间隔时。 在这种情况下，查询树退化为没有分支的单个链状结构。 相反，任何与线段树节点边界不完全对齐的区间都会在归纳树中产生分支结构。 

## 方法

 关键的观察是我们实际上并不是在处理任意树。 线段树范围查询生成的查询树具有非常严格的结构：它正是将 [L, R] 分解为 O(log n) 规范线段树节点，通过线段树层次结构连接。 

如果我们尝试用蛮力的方式思考，我们将明确构建 G，枚举所有有效的单色路径，并在一般图游戏上运行游戏求解器。 这很快就变得不可行，因为状态数量随着 G 中节点的数量呈指数增长，而且 G 本身可能很大。 

重要的简化来自于注意 G 的结构实际上是什么样子。 线段树分解创建一棵几乎总是分支的树：每当一个区间被分成两个规范部分时，相应的节点连接到不同的子树，在 G 中产生一个分支点。不发生分支的唯一情况是当 [L, R] 与一个线段树节点区间完全重合时，这意味着整个范围是一个 2 的幂对齐块。

这种结构上的区别将游戏变成了简单的结果检查。 如果导出的图是纯路径（无分支），则每次移动都会以受约束的方式减少路径，并且第二个玩家可以反映最佳游戏。 如果图表有任何分支，Lyra 就具有强制获胜优势，因为她总是可以选择消除不对称分支的移动，并比对手反映的速度更快地减少游戏。 

因此，整个问题简化为检查[L，R]是否完全对应于线段树节点区间。 

线段树节点间隔由 2 的幂的长度和该长度的倍数的对齐边界定义。 具体来说，当且仅当 R − L + 1 是 2 的幂且 L 能被 R − L + 1 整除时，[L, R] 才恰好是一个节点区间。 

其他一切都会产生一个分支查询树，因此 Lyra 会获得胜利。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 计算区间的长度，len = R − L + 1。这是原始线段树中覆盖范围的大小。 
2. 检查len是否为2的幂。 这可以使用标准位技巧 len & (len − 1) == 0 来完成。此条件确保间隔可能对应于完整线段树节点。 
3.如果len不是2的幂，则立即断定查询树必须包含分支，因为区间不能表示为单个线段树节点。 在这种情况下，莱拉获胜。 
4. 如果 len 是 2 的幂，则检查对齐：验证 L 是否能被 len 整除。 如果L % len == 0，那么[L,R]正好匹配一个线段树节点区间，因此查询树是一个单无分支链结构。 
5. 如果两个条件都成立，则 Lyra 失去输出。 否则，输出 Lyra 获胜。 

最后一步背后的原因是，只有完美对齐的线段树节点才能避免在查询分解过程中分裂成多个规范节点。 任何不对齐都会迫使查询过程组合多个节点，这会在归纳图中引入分支。 

它起作用的原因是基于线段树查询分解产生一组不相交规范区间的最小不变性。 单个规范区间在归纳树中产生线性结构，而多个规范区间必然创建分解分裂的分支节点。 这个分支点打破了对称性，并为第一个玩家提供了获胜策略。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_pow2(x):
    return x > 0 and (x & (x - 1)) == 0

t = int(input())
out = []

for _ in range(t):
    n, L, R = map(int, input().split())
    length = R - L + 1

    if is_pow2(length) and L % length == 0:
        out.append("No")
    else:
        out.append("Yes")

sys.stdout.write("\n".join(out))
```该解决方案完全依赖于线段树查询何时分解为一个规范区间的结构特征。 二次方检查过滤器可以对应于线段树中的单个节点的候选间隔。 对齐检查确保间隔恰好从与该节点的段一致的边界开始。 

最终决策直接编码游戏结果：Lyra 唯一失败的位置是查询树完全线性的位置，这意味着不存在分支结构来创建获胜的不对称性。

 考虑间隔完全对齐的情况。

现在考虑一个稍微移动的间隔。

 ## 边缘情况

 当间隔减少到单个点 L = R 时，算法认为长度 = 1，它是 2 的幂并且始终对齐。 这对应于一个简单的线段树节点。 由于规则禁止选择节点 1，除非删除整个图，因此 Lyra 失去了该位置，算法输出“否”。 

当区间是完整的2次方块但未对齐时，例如L = 5，R = 12，长度为8，但L不能被8整除。诱导查询树必须在更高的线段树级别进行分裂，引入分支节点。 该算法正确地输出“是”，这与 Lyra 可以通过早期分支移除强制不对称的事实相匹配。 

当间隔很大但几乎对齐时，例如 L = 0 和 R = 2^k − 2，长度不是 2 的幂，因此第一个条件已经失败。 这保证了分支，结果又是天琴座的获胜位置。
