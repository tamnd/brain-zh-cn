 ## 解决方案
 ## 问题理解

 我们得到一个整数$N$，代表驻扎在长坂桥前的曹操军队的士兵数量。 故事描述张飞的怒吼引起士兵恐慌，士兵四散奔逃。 不过，有一个特殊的例外：夏侯杰将军受到的影响有所不同，并明确表示不包括在“被吓跑”的人数中。 

因此，任务简化为在排除不属于被吓走的群体的一个人后，确定有多少士兵实际逃跑。 

尽管叙述非常程式化，但底层结构纯粹是算术。 输入大小可达$10^6$，这立即排除了任何涉及对具有复杂行为的单个士兵进行模拟的事情，但在这里即使这是不必要的，因为我们没有跟踪交互或序列。 常数时间计算就足够了。 

出现微妙的边缘情况时$N = 1$。 在这种情况下，如果唯一在场的人是被排除在外的人，那么被吓跑的士兵数量就会变成零。 任何朴素的减法都必须干净地处理这个问题，而不会产生负值。 

## 方法

 暴力解释会明确模拟每个士兵，标记他们是否因咆哮而逃跑，然后通过排除夏侯杰来调整计数。 从概念上讲，这将涉及迭代所有$N$实体并为每个士兵维护一个状态标志。 虽然这已经是线性的并且很容易通过$N \le 10^6$，这是不必要的，因为没有任何单独的状态转换实际上依赖于位置或交互。 

关键的观察是，这个故事定义了一个不应该被包括在最终统计中的特殊个体。 这意味着答案就是士兵总数减去一名被排除在外的人。 进一步的结构、顺序或条件不会影响结果。 

因此，该问题分解为常数时间算术计算。

 ## 算法演练

 1.读取整数$N$，代表桥前的士兵总数。 这是应用任何排除之前的全部人口。 
2. 确定最终“被吓走”的人数中没有包含一个人。 该语句明确定义了此异常，因此我们不会将该人计入结果中。 
3. 计算结果为$N - 1$。 这直接将被排除的个人从总数中删除。 
4. 如果$N = 1$，同样的公式仍然适用，自然会产生 0，这正确地表示没有士兵被算作被吓跑。 

### 为什么它有效

 关键的不变量是，除一名士兵外，所有士兵都参与了逃亡人数的最终统计。 由于该问题仅保证一个排除而没有其他过滤条件，因此最终答案始终是总大小减去该单个排除的实体。 士兵之间不存在依赖关系，没有条件行为，人口也没有动态变化，因此减法对于所有输入仍然有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    print(max(0, n - 1))

if __name__ == "__main__":
    main()
```有意将实现最小化。 减法$n - 1$对语句中描述的排除进行编码。 这`max(0, ...)`警卫确保正确性$n = 1$，防止退化情况下出现任何负输出。 

该解决方案使用恒定时间输入处理，并避免存储超出单个整数的任何内容。
