 ## 解决方案
 ## 问题理解

 我们得到了多组棍子长度，我们必须将它们全部排列成从原点开始的折线。 每根棍子都成为该多段线的一段，并且每一段都必须轴对齐，这意味着它要么是水平的，要么是垂直的。 唯一的结构限制是方向必须交替，因此两个连续的棍子不能都是水平的或都是垂直的。 

我们可以根据这种交替规则自由地排列棍子的顺序并选择方向。 折线可能在几何上重叠，但最佳构造无论如何都会避免这种情况。 目标是在放置所有木棍后，最大化从原点到最终端点的欧氏距离平方。 

键输出是一个整数，即端点到 (0, 0) 的距离的平方。 

约束 n 高达 100000 迫使任何解决方案都需要大约 O(n log n) 或 O(n) 时间。 任何天真的探索排列或分配方向的尝试都需要阶乘或指数时间，并且会立即失败。 即使对子集进行动态规划也是不可能的，因为 2^n 太大了。 

一个微妙的边缘情况来自 n 的奇偶性和长度的分布。 如果所有棍子都相等或者只有一根非常大的棍子，则在没有计划平衡的情况下交替方向的天真贪婪分配可能会产生非最佳投影。 例如，始终首先在一个方向上分配最长的棍子可能会导致抵消效应，从而减少最终位移，即使总长度是固定的。 

## 方法

 直接的暴力方法将尝试所有棒的排列以及尊重交替的水平和垂直方向的所有分配。 对于每个配置，我们模拟折线并计算端点。 这是正确的，因为它探索了每一个有效的构造，但它需要 n! 排列，甚至忽略排列，2^n 个方向选择，超过 n 大约 20 就变得不可行。 

关键的观察结果是，最终位置仅取决于有符号的水平位移之和和有符号的垂直位移之和。 交替约束意味着正好有 ⌈n/2⌉ 根棍子进入一个轴，而 ⌊n/2⌋ 根棍子进入另一个轴，但我们可以自由选择哪些棍子进入哪个轴。 

为了最大化平方距离 x^2 + y^2，我们希望独立地最大化 x 和 y 的绝对值。 由于方向可以翻转符号，因此重要的是将木棒分为两组，其总和的大小尽可能大。 这成为一个经典的划分思想：战略性地分配最大的木棒，以便两个组都获得大的总和。 

最佳结构是按降序对木棒进行排序，并将它们交替分配到 x 和 y 组。 这使两个总和尽可能大，因为将大与大配对可确保两个轴都不会缺乏贡献。

 | 蛮力 | O(n!·n) | O(n!·n) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(1) 额外 | 已接受 |

 ## 算法演练

 我们专注于构建两项总和，一项用于横向贡献，一项用于纵向贡献。 

1. 将所有棒长度按降序排列。 这确保了我们在轴之间分配时始终首先考虑较大的棍子。 
2. 初始化两个累加器，一个用于水平求和，一个用于垂直求和。 
3. 迭代排序列表。 将第一根棍子指定为水平，第二根棍子指定为垂直，第三根棍子指定为水平，依此类推交替。 这保证了两个组以平衡的方式接收大元素。 
4. 分配后，计算平方距离：horizo​​ntal_sum^2 + Vertical_sum^2。 
5. 输出该值。

交替分配起作用的原因是我们有效地平衡了两个相互竞争的总和。 如果我们将所有大棒分配给一个轴，则另一轴将变得太小，并且由于目标是二次的，不平衡会减少总平方和。 

### 为什么它有效

 最终端点由沿两个垂直轴的独立贡献确定。 因为我们可以自由选择方向符号，所以当分配的子集包含最大可能的长度总和时，每个轴的贡献最大化。 排序列表上的交替是一种贪婪的方式，以确保两个子集都收到可比较的高值元素。 将大元素聚集到一个轴上的任何偏差都会严格减少 x^2 + y^2，因为该函数在坐标之间的不平衡中是凸的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

a.sort(reverse=True)

x = 0
y = 0

for i, v in enumerate(a):
    if i % 2 == 0:
        x += v
    else:
        y += v

print(x * x + y * y)
```该解决方案首先读取所有棒长度并按降序对它们进行排序，以便将较大的贡献放在更早的位置。 然后，它交替分配到两个代表水平和垂直总计的累加器中。 这种交替在方向必须每一步切换的约束下对最佳轴分配进行编码。 最后，它使用标准公式 x^2 + y^2 计算平方欧氏距离。 

一个常见的错误是在决定分组之前尝试分配标志或方向。 正确的抽象是首先决定每个轴的总长度，然后应用符号，这就是贪婪分区足够的原因。

 ## 边缘情况

 当所有的棍子都具有相同的值时，排序不会改变顺序，但交替仍然可以确保几乎相等的分区。 例如，输入 4 4 4 4 生成 x = 8 和 y = 8，即 128。任何不平衡都会减少平方和。 

当有一根占主导地位的大棒和许多小棒时，将大棒单独放置在一个轴上是最佳选择，因为它可以防止其贡献被稀释。 贪婪排序自然地确保了这一点，因为它被放置在第一位，并且随后的较小值不会显着扭曲平衡。 

当n为奇数时，一个轴不可避免地会多收到一根棍子。 排序可确保此额外分配进入已具有当前最大部分和的轴，从而最大限度地减少对平方目标的不平衡影响。
