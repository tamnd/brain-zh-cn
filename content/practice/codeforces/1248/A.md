 ## 解决方案
 ## 问题理解

 我们在平面上有两个直线族。 第一族由以下形式的行组成$y = x + p_i$，第二个系列由以下形式的行组成$y = -x + q_j$。 每一个$p_i$在自己的群体中是独特的，并且每个$q_j$在自己的群体中是独特的。 

第一个族的每条线与第二个族的每条线恰好在一个点处相交。 任务是计算这些交点中有多少两个坐标均为整数。 

一个关键的观察是，我们并没有被要求计算坐标或检查一般意义上的几何交点。 我们只需要为每一对做出决定$(p_i, q_j)$，它们的交点是否位于整数坐标上，并计算有多少这样的对满足这个条件。 

这些约束清楚地表明，对所有对进行暴力破解是不可行的。 和$n, m$最多$10^5$每个测试用例和总和高达$10^5$， 一个$O(nm)$方法需要最多$10^{10}$最坏情况下的操作，远远超出了2秒的限制。 这立即迫使我们走向$O(n + m)$或者$O(n \log n)$每个测试的风格解决方案。 

经常导致错误的一个微妙点是误解“整数交点”在此设置中的含义。 交集总是存在并且是唯一的，但即使所有系数都是整数，它也不总是整数。 另一个问题是重复计算或尝试显式计算所有对的坐标，这是不必要的。 

一个天真的陷阱示例是：

 输入：```
n = 2, p = [0, 1]
m = 2, q = [0, 2]
```的交集$y = x + p$和$y = -x + q$发生在：$$x = \frac{q - p}{2}, \quad y = \frac{p + q}{2}$$即使所有输入都是整数，但只有当两个输入都为整数时，结果才是整数$q - p$和$p + q$是均匀的。 许多简单的解决方案错误地假设所有交集都是整数或忘记了奇偶校验条件。 

## 方法

 直接的方法是迭代每一对$(p_i, q_j)$，计算交点，并检查两个坐标是否都是整数。 这很简单：解方程，计算$x = (q_j - p_i)/2$,$y = (q_j + p_i)/2$，并验证能否被 2 整除。虽然正确，但这需要$O(nm)$每个测试用例的时间，即使对于中等输入大小也是不可行的。 

公式的结构揭示了一个简单得多的条件。 交点是积分当且仅当两者$q_j - p_i$和$q_j + p_i$是均匀的。 这两个条件相当于要求$p_i$和$q_j$具有相同的奇偶性。 如果$p_i$是偶数并且$q_j$是奇数，那么$p_i + q_j$是奇数并且不能产生整数$y$-协调。 如果奇偶校验相反，也会出现同样的问题。 

因此，整个问题归结为计算有多少对具有匹配的奇偶校验。 我们只需将两个数组分为偶数和奇数，然后将相应的组相乘。 

让$E_p, O_p$是偶数和奇数的计数$p_i$，并且类似地$E_q, O_q$为了$q_j$。 那么答案是：$$E_p \cdot E_q + O_p \cdot O_q$$暴力破解之所以有效，是因为它显式地检查每个几何交集，但它会失败，因为它会重复重新计算相同的奇偶校验条件。 完整性仅取决于奇偶校验的观察结果将几何问题简化为两个桶上的计数问题。

 ## 算法演练

 1.读取数组$p$并计算有多少个值是偶数和多少个奇数。 这分隔了表格的所有行$y = x + p_i$根据平等划分为两个阶层，这完全决定了他们如何与第二家庭互动。 
2.读取数组$q$并类似地计算偶数和奇数。 这反映了线路的相同分类$y = -x + q_j$。 
3. 计算两个值均为偶数的有效对的数量，这有助于$E_p \cdot E_q$与整数坐标的交点。 
4. 计算两个值均为奇数的有效对的数量，这有助于$O_p \cdot O_q$有效的交叉点。 
5. 将这两个贡献相加并输出结果。 

### 为什么它有效

 的交集$y = x + p$和$y = -x + q$是：$$x = \frac{q - p}{2}, \quad y = \frac{p + q}{2}$$两个坐标都是整数，恰好当$p + q$是偶数，当且仅当$p$和$q$共享相同的平价。 由于每对行为独立并且仅取决于奇偶校验，因此按奇偶校验对值进行分组可以保留所有必要的信息并保证正确性。

 ## 边缘情况

 一种边缘情况是两个数组中的所有值共享相同的奇偶校验。 例如，如果所有$p_i$和所有$q_j$是偶数，每对都贡献一个有效的整数交集。 算法算数$n \cdot m$因为奇数计数均为零，而偶数计数占主导地位，与完整的笛卡尔积匹配。 

另一种情况是完全奇偶校验不匹配，比如全部$p_i$均匀一致$q_j$很奇怪。 交集力公式$p + q$总是奇数，所以没有一对做出贡献。 算法正确计算$E_p \cdot E_q = 0$和$O_p \cdot O_q = 0$，产量为零。 

最后一个微妙的情况是最小输入大小，其中$n = m = 1$。 如果$p_1 = q_1$，答案仅取决于奇偶校验相等。 该算法正确地简化为奇偶校验的单次比较，避免任何特殊的大小写或相差一的问题。
