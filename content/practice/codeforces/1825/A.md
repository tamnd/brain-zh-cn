 ## 解决方案
 ## 问题理解

 我们得到一个保证是回文的字符串。 任务是找到该字符串的最长子序列，该子序列**不是**回文。 子序列是通过删除零个或多个字符同时保持剩余字符的相对顺序而获得的任何序列。 输出应该是该子序列的长度，或者`-1`如果每个非空子序列仍然是回文。 

输入字符串的长度最多为 50。由于最大长度很小，即使具有二次时间复杂度的算法也是可行的，但我们应该以线性时间方法为目标。 棘手的部分是理解回文字符串何时可以产生非回文子序列。 例如，像这样的字符串`"aaa"`只有重复的字符，因此任何子序列仍然是回文。 另一方面，`"ababa"`包含至少两个不同的字符，因此从一侧删除一个字符可能会破坏对称性并产生非回文。 

经常让人犯错的边缘情况包括完全由单个字符组成的字符串、长度为 1 的字符串以及回文但包含多个不同字符的字符串。 

## 方法

 一种强力方法是生成所有非空子序列，检查每个子序列的回文属性，并跟踪非回文子序列中的最大长度。 这在原则上是正确的，但完全不切实际：长度为 50 的字符串有$2^{50}$子序列，这是一个天文数字。 

关键的见解是我们不需要枚举子序列。 回文串是对称的。 子序列保持回文的唯一方法是它保持中心的对称性。 如果字符串至少包含两个不同的字符，则打破对称性的最简单方法是删除末尾出现的一个字符。 这保证了生成的字符串不再是回文。 因此，如果两端不同，则最长非回文子序列的长度是字符串的全长；如果所有字符都相同，则最长非回文子序列的长度是长度减一。 

简单来说，如果所有字符都相同，则不存在非回文子序列。 否则，从字符串中删除任何一个字符就足以打破对称性并实现最大非回文子序列长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取回文字符串`s`。 
3. 检查是否所有字符都在`s`通过将字符集与大小 1 进行比较，它们是相同的。如果为 true，则输出`-1`因为任何子序列也是回文。 
4. 如果至少有两个不同的字符，则输出`len(s) - 1`。 从任一端删除一个字符可确保对称性被破坏并产生最长的非回文子序列。 
5. 对所有测试用例重复此操作。 

为什么它有效：不变的是，可以通过从包含至少两个不同字符的字符串中删除一个字符来形成非回文子序列。 具有相同字符的字符串不能产生非回文，因此对全相等字符的检查可以保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    if len(set(s)) == 1:
        print(-1)
    else:
        print(len(s) - 1)
```代码首先读取测试用例的数量。 对于每个字符串，它将字符串转换为一组以计算唯一字符。 如果集合的大小为 1，则字符串由单个重复字符组成，因此我们输出`-1`。 否则，我们输出`len(s) - 1`正如所解释的。 使用`set`这里既简单又高效，并且剥离输入确保没有尾随换行符。

 ## 边缘情况

 对于字符串`"a"`，该集合包含单个元素，因此输出为`-1`。 任何子序列都不能破坏对称性。 为了`"aaaaa"`，所有字符都相同，因此设置大小为1，输出为`-1`。 对于像这样的字符串`"ab"`，删除任一`a`或者`b`产生`"b"`或者`"a"`，仍然是回文，所以最长的非回文子序列长度是`len(s)-1 = 1`，符合一般规律。 这些检查确认算法可以正确处理最小和最大输入大小、重复字符和小回文。
