 ## 解决方案
 ## 问题理解

 我们有一套$n$岛屿以树状结构连接。 这意味着任何两个岛屿都由一条路径连接，并且有$n-1$边缘。 洛天依想要见面$k$朋友们，每个人都位于一个不同的岛屿上。 我们被要求计算最小化到所有岛屿的总距离的预期岛屿数量$k$朋友们。 这些岛屿被称为好岛。 输出必须以模计算$10^9+7$并表示为表示分数的模逆乘法的整数。 

约束很严格：$n$可以达到$2 \cdot 10^5$，排除任何具有复杂性的算法$O(n^2)$或更高。 任何枚举所有的方法$k$-岛屿的元素子集，即$O(\binom{n}{k})$，显然是不可行的。 我们需要一种线性或近线性的方法$n$，可能使用树属性或组合推理。 

要考虑的边缘情况包括非常小的树，例如单个节点，其中$k=1$，以及最佳岛屿可能会根据朋友的分布方式而变化的链。 粗心的方法可能会尝试天真地计算所有子集的距离，这会在时间和内存上爆炸。 

## 方法

 暴力方法是枚举所有$\binom{n}{k}$放置方式$k$不同岛屿上的朋友。 对于每个位置，计算从每个岛屿到这些朋友的距离总和，并计算达到最小总和的岛屿。 这是可行的，因为它直接实现了问题定义，但复杂性是$O(\binom{n}{k} \cdot n)$，当$n$是$2 \cdot 10^5$。 即使对于中等$k$，这种方法不可行。 

关键的见解来自于认识到到所有的距离的总和$k$朋友可以用每条边的贡献来表示。 在树中，相邻节点之间的距离和差由它们分开的子树的大小决定。 如果我们在任何节点处建立树，则到节点子集的距离总和仅取决于每个子树中有多少朋友。 使用期望的线性，我们可以计算良好岛屿的预期数量，而无需枚举所有位置。 具体来说，我们可以计算每条边穿过该边会增加距离总和的概率。 使用组合函数，这可以将问题简化为$O(n)$基于 DFS 的计算，具有预先计算的阶乘以实现快速组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * C(n,k)) | O(n * C(n,k)) | O(n) | 太慢了 |
 | 通过 DFS 和组合学的期望值 | O(n + k \log MOD) | O(n + k \log MOD) | O(n + k) | 已接受 |

 ## 算法演练

 1. 预计算阶乘和逆阶乘模$10^9+7$最多$n$。 这使我们能够计算组合$C(n,k)$有效地为大型$n$和$k$使用模运算。 
2. 在节点处任意建立树的根$1$。 执行 DFS 来计算每个子树的大小。 让`sz[u]`表示以 为根的子树中的节点数`u`。 
3. 对于连接父级的每条边`u`和孩子`v`，树被有效地分成两部分。 计算放置所有的方法的数量$k$朋友完全在一边。 这是$C(sz[v], k) + C(n - sz[v], k)$。 补数给出了该边对距离和有贡献的配置数量。 
4. 对于每个节点，期望的好岛数为$1$减去某些边交叉相对于其他边增加其距离总和的概率。 使用预先计算的边缘概率，总结每个节点的贡献。 
5. 计算最终期望值模$10^9+7$使用分数的模逆运算。 

为什么有效：期望的线性使我们能够独立地处理每条边，因为可以通过子树大小来隔离边对距离和的贡献。 这避免了枚举所有子集并确保正确性，因为朋友的每个位置都有相同的可能性，并且每条边都确定性地对其端点之间的距离总和差做出贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD-2, MOD)

def prepare_factorials(n):
    fac = [1]*(n+1)
    ifac = [1]*(n+1)
    for i in range(1, n+1):
        fac[i] = fac[i-1]*i % MOD
    ifac[n] = modinv(fac[n])
    for i in range(n-1, -1, -1):
        ifac[i] = ifac[i+1]*(i+1) % MOD
    return fac, ifac

def comb(n, k, fac, ifac):
    if k < 0 or k > n:
        return 0
    return fac[n]*ifac[k]%MOD*ifac[n-k]%MOD

n, k = map(int, input().split())
edges = [[] for _ in range(n)]
for _ in range(n-1):
    u, v = map(int, input().split())
    edges[u-1].append(v-1)
    edges[v-1].append(u-1)

fac, ifac = prepare_factorials(n)

sz = [0]*n
def dfs(u, p):
    sz[u] = 1
    for v in edges[u]:
        if v == p:
            continue
        dfs(v, u)
        sz[u] += sz[v]
dfs(0, -1)

total_ways = comb(n, k, fac, ifac)
res = 0
for u in range(n):
    bad = 0
    for v in edges[u]:
        s = sz[v] if sz[v] < sz[u] else n - sz[u]
        bad += comb(s, k, fac, ifac)
    good = (total_ways - bad) % MOD
    res = (res + good) % MOD

res = res * modinv(total_ways) % MOD
print(res)
```该解决方案首先预先计算阶乘和逆阶乘以进行快速组合计算。 然后它使用 DFS 计算子树大小。 评估每条边以查看它如何分裂树，以及可以放置朋友的多少种方式，以便跨边的距离总和增加。 最后，使用模算术计算预期的良好岛屿数量。
