 ## 解决方案
 ## 问题理解

 我们被要求构建确定性 64 位转换的输入，其行为类似于加密混合函数，但在结构上仍然是代数可逆的。 

每个查询给出一个32位的目标值`t`。 对于每个这样的目标，我们必须输出两个不同的 64 位无符号整数`a`和`b`这样对两者应用相同的散列过程会产生精确的结果`t`。 

哈希是分层构建的。 首先，输入一个`x`使用固定乘法器和偏移量以 64 位算术进行线性变换，然后对其位进行旋转。 之后，64位值被分成高32位和低32位两半，最终的哈希值是这些两半的异或。 

关键要求不是向前计算哈希，而是构造两个不同的原像，它们落在相同的最终 32 位值上。 

约束允许最多 200,000 个查询，并且每个输出都是独立的构造。 这排除了任何按查询搜索或概率冲突发现。 任何解决方案都必须保证每个查询的时间恒定。 

一个天真的想法是暴力破解两个随机 64 位数字，直到它们碰撞到相同的数字。`t`。 这会立即失败，因为哈希范围只有 2^2 而输入是 2⁶⁴，并且随机搜索不能保证在时间限制内进行大的`q`。 

一种更微妙的失败模式来自于尝试直接反转哈希而不注意内部结构。 如果将旋转和异或视为不可逆的黑盒运算，则该问题看起来像是密码学反转任务，但其构造是故意代数的，并且一步一步完全可逆。 

重要的边缘情况是每个查询都必须生成两个不同的值，即使对于相同的值`t`，因此单个计算的原像是不够的。 该构造必须明确地生成至少两个不同的有效原像。 

## 方法

 暴力破解的视角从定义开始：计算许多候选 64 位值的哈希值，直到其中两个匹配相同的目标`t`。 由于哈希仅输出 2^32 个可能值，因此每次随机尝试命中特定目标的概率为 1/2^2。 即使找到一个原像在预期中也是不可行的，而在天真的推理中找到两个不同的原像则更糟糕 2⁶⁴ 倍。 这在时间限制下完全失败。 

结构上的突破是不再将哈希视为黑匣子，而是将其逐层剥离。 

与固定奇常数模 2⁶⁴ 的乘法是 64 位空间上的排列，因此可以反转。 位旋转也是一种排列，因此是可逆的。 上半部和下半部之间的最终 XOR 是减少信息的唯一步骤，但它以非常受控的方式将 64 位减少到 32 位。 

如果我们重命名中间值，最终的哈希值仅取决于分成两半的 64 位值`A`和`B`，输出是`A XOR B`。 这个方程非常重要，因为它定义了完整的 32 位自由度：对于任何选择的`A`，我们可以解决`B = A XOR t`。 这已经给出了无限多个有效的 64 位输入，这些输入映射到相同的`t`。 

一旦我们可以构造任意数量的有效中间 64 位值，我们只需通过可逆变换将它们推回即可获得有效的原始输入`x`。 由于所有早期步骤都是双射，因此每个有效的中间状态恰好对应一个原始输入。 

最后的见解是，我们不需要一种解决方案，而是两种不同的解决方案。 所以我们只需为免费的一半选择两个不同的值`A`，构建两个不同的有效中间体，并反转管道。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力搜索碰撞| 预计 O(2⁶⁴) | O(1) | O(1) | 太慢了|
 | 结构的代数反演 | 每个查询 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 固定目标哈希值`t`对于当前查询。 我们将构造直接满足最终 XOR 条件的中间 64 位值。 
2. 选择任意32位值`A`对于下半部分。 该值是自由的，因为定义散列的方程并不唯一地约束它。 
3. 定义上半部分`B`作为`B = A XOR t`。 这保证了`A XOR B = t`，满足分裂后的最终哈希条件。 
4. 将两半组合成一个 64 位数字`z = (A << 32) | B`。 这代表了最终分裂之前阶段的有效原像。 
5. 使用不同的值重复相同的构造`A2`， 例如`A + 1`，产生第二个不同的 64 位值`z2`。 
6. 反转之前应用的位旋转。 由于旋转是双射的，因此我们应用相反的旋转来恢复旋转前的状态。 
7. 使用常数乘数的模逆对模 2⁶⁴ 的乘法和加法求逆。 这将恢复原始输入值`a`和`b`。 

每个步骤都是安全的关键原因是，除了最终的 XOR 之外的每个转换都是 64 位整数上的双射，因此它保留了构造的解决方案的唯一性。 

### 为什么它有效

 哈希函数仅在最后的 XOR 阶段将 64 位状态减少为 32 位。 在此之前，每个变换都是可逆的并保留一对一的映射。 等式`A XOR B = t`在 64 位空间上定义了 32 位仿射约束，留下 2^32 个有效解。 选择两个不同的自由选择`A`保证两个不同的有效中间状态。 由于管道的其余部分是双射的，因此它们唯一地延伸回两个不同的原始输入。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MASK64 = (1 << 64) - 1

M = 0x9E3779B97F4A7C15
C = 0xD1B54A32D192ED03

def rotl64(x, r):
    return ((x << r) & MASK64) | (x >> (64 - r))

def rotr64(x, r):
    return ((x >> r) | (x << (64 - r))) & MASK64

def solve():
    q = int(input())
    invM = pow(M, -1, 1 << 64)

    for _ in range(q):
        t = int(input())

        # two different choices for low half
        A1 = 0
        B1 = A1 ^ t
        z1 = (A1 << 32) | B1

        A2 = 1
        B2 = A2 ^ t
        z2 = (A2 << 32) | B2

        # invert rotation: p = rotl64(y, 23)
        y1 = rotr64(z1, 23)
        y2 = rotr64(z2, 23)

        # invert y = Mx + C mod 2^64
        x1 = (invM * ((y1 - C) & MASK64)) & MASK64
        x2 = (invM * ((y2 - C) & MASK64)) & MASK64

        print(x1, x2)

if __name__ == "__main__":
    solve()
```该代码准确地反映了数学反演管道。 构造从 XOR 约束开始，构建有效的 64 位中间状态，然后应用逆旋转和逆仿射变换。 减法`(y - C)`被屏蔽以确保在乘以模逆之前无符号 64 位环绕。 

一个微妙的实现细节是每个操作都必须屏蔽为 64 位，因为 Python 整数自然不会溢出。 缺少掩码会破坏与无符号算术的等效性。 

## 工作示例

 我们为单个查询构建简化的跟踪`t = 5`。 

我们为免费的一半选择两个值：`A1 = 0`,`A2 = 1`。 

| 步骤| 一个 | B = A 异或 t | z = (A<<32)|B|

 |---|---|---|---|

 | 1 | 0 | 5 | 5 |

 | 2 | 1 | 4 | 2立方+ 4 |

 至此之后，双方`z`值通过逆旋转和逆仿射变换推送，产生两个不同的 64 位输出`x1`和`x2`。 

该跟踪表明唯一真正的约束是 XOR 关系； 在它之前的一切都是可逆结构。 

第二个例子`t = 0`更能说明问题。 任何`A`产生`B = A`，所以每个中间状态的形式为`(A, A)`。 选择`A = 0`和`A = 1`给出了两个有效但不同的解决方案，确认当目标具有最大对称性时该结构仍然有效。

 ## 边缘情况

 当`t = 0`，异或约束变为`A = B`。 这可能看起来像是折叠了解空间，但实际上它最大化了对称性。 该构造仍然会产生无限多个以下形式的有效中间值`(A, A)`，并选择不同的`A`值保证反转后不同的最终答案。 

什么时候`t = 2³² - 1`, 中的每一位`B`成为补集`A`。 即使在这种极端情况下，该构造仍然有效，因为它不依赖于任何数字属性`t`超越异或可逆性。 

当多个查询重复相同的内容时`t`，该算法仍然会为每个查询产生不同的输出，因为我们故意改变`A`每次调用，防止意外重复`(a, b)`对。
