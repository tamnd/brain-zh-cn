 ## 解决方案
 ## 问题理解

 该问题要求板条箱的尺寸能够提供最大可能的总装运价值。 只有当船舶的容量恰好能被所选板条箱尺寸整除时，才能使用船舶。 如果我们选择板条箱尺寸`x`，每艘船的容量是`x`贡献`x`价值单位，因为它可以在一个板条箱内携带一个不稳定的核心。 因此总价值为：`x * (number of capacities divisible by x)`我们需要找到`x`最大化这个值。 如果多个板条箱尺寸产生相同的最大值，我们会选择最小的一个。 

输入包含船舶容量列表。 每个容量最多为`10^6`，并且最多可以有`10^6`船舶。 值的上限是关键细节。 迭代每对可能的容量会太慢。 拥有100万艘船舶，`O(N^2)`方法需要围绕`10^12`不符合正常竞赛限制的操作。 我们需要一个在最大容量下接近线性的解决方案。 

棘手的情况来自不直接出现在输入中的除数和关系。 

例如：```
Input
5
2 3 3 4 5

Output
3
```粗心的方法可能只会测试显示为容量的值。 在这种情况下，这恰好可行，但总的来说这不是一个有效的想法。 最佳的板条箱大小可以是列表中不存在的数字。 

另一个例子：```
Input
5
2 4 6 8 10

Output
5
```板条箱尺寸`5`赋予价值`5 * 2 = 10`，因为容量`10`和`?`等等，仅`10`可以整除`5`，所以这个输出不正确。 实际计算是：```
x = 2  -> 2 * 5 = 10
x = 5  -> 5 * 1 = 5
```答案是：```
Input
5
2 4 6 8 10

Output
2
```这捕获了混淆除数数量和可整除容量数量的实现。 

领带盒也很容易处理不当：```
Input
4
1 2 3 6

Output
3
```这里：```
x = 1 -> 1 * 4 = 4
x = 2 -> 2 * 2 = 4
x = 3 -> 3 * 2 = 6
x = 6 -> 6 * 1 = 6
```两个都`3`和`6`给出最大值，因此必须返回较小的值。 

## 方法

 直接的方法是尝试每一种可能的板条箱尺寸，并计算有多少容量可以被它整除。 对于板条箱尺寸`x`, 扫描全部`N`容量给出`O(N)`工作。 由于最大容量可以是`10^6`，尝试一切可能`x`价值观给周围`10^12`在最坏的情况下，操作速度太慢。 

问题的结构为我们提供了更好的路线。 我们实际上并不关心个人能力。 我们只需要知道每种容量出现了多少次。 构建频率数组后，我们可以问一个不同的问题：对于每个可能的板条箱大小`x`，有多少个输入值是`x`？ 

这与在筛子中计数倍数的模式完全相同。 对于每一个`x`，我们访问`x, 2x, 3x, ...`并添加这些容量的频率。 操作次数大约为：`M/1 + M/2 + M/3 + ... + M/M`在哪里`M`是最大容量。 这是`M log M`，这很容易足够快`M = 10^6`。 

蛮力之所以有效，是因为它会检查每种可能性，但它会多次重复相同的整除工作。 筛式计数重复使用频率信息并处理每个除数关系一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N * M) | O(1) | O(1) | 太慢了|
 | 最佳| O(M log M + N) | O(M log M + N) | O(M)| 已接受 |

 ## 算法演练

 1. 读取所有船舶容量并存储每个容量出现的次数。 

频率阵列让我们回答“有多少艘船有能力`v`“在恒定的时间内。
 2. 迭代每个可能的 crate 大小`x`从`1`到最大容量。 

我们只需要考虑可以划分至少一个容量的大小。 较大的值无法做出任何贡献。 
3.对于当前`x`，将所有倍数的频率相加`x`。 

我们参观`x, 2x, 3x, ...`因为这些正是可以使用大小板条箱的容量`x`。 
4. 计算总支出如下：`x * count`在哪里`count`是可以使用该板条箱尺寸的船舶数量。 
5. 保留迄今为止看到的最佳答案。 当支出较大或支出相等时更换答案`x`较小。 

平局规则是在扫描期间处理的，因此不需要额外的处理。 

为什么它有效：

 对于任何固定的板条箱尺寸`x`，唯一可以部署的船只是容量是其倍数的船只`x`。 该算法通过将所有倍数的频率相加来精确计算这些船只的数量。`x`。 因此，计算出每种可能的支出`x`是正确的。 由于每个有效的板条箱大小都会被检查并保留最大支付，因此最终答案是最佳的板条箱大小。 只要找到相等的支出，就会应用平局决胜条件，因此会返回最小的有效板条箱大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mx = max(a)

    freq = [0] * (mx + 1)
    for v in a:
        freq[v] += 1

    best_value = 0
    answer = 1

    for x in range(1, mx + 1):
        count = 0
        for multiple in range(x, mx + 1, x):
            count += freq[multiple]

        value = x * count

        if value > best_value or (value == best_value and x < answer):
            best_value = value
            answer = x

    print(answer)

if __name__ == "__main__":
    solve()
```首先构建频率数组，因为输入量很大，重复扫描原始列表会浪费时间。 数组的索引表示容量，而存储的值表示有多少艘船具有该容量。 

外循环考虑了所有可能的板条箱尺寸。 内部循环直接跳过其倍数，避免检查无法贡献的容量。 乘法`x * count`可以达到约`10^12`，但 Python 整数可以处理这个问题而不用担心溢出。 

更新条件包含平局打破规则。 当两个板条箱尺寸产生相同的支出时，较小的尺寸将取代先前的答案。

 ## 边缘情况

 对于单艘船：```
Input
1
1
```唯一可能的板条箱尺寸是`1`。 频率阵列包含一艘满载的船`1`，所以支出是`1`，算法返回`1`。 

对于重复容量：```
Input
5
7 7 7 7 7
```板条箱尺寸`7`给予支付`7 * 5 = 35`。 每一个较小的除数都会带来较低的支出，因为板条箱价值的下降速度快于船只数量的增加速度。 该算法通过频率数组对出现的五次进行计数并选择`7`。 

对于领带：```
Input
4
1 2 3 6
```该算法计算：```
x = 3: count = 2, payout = 6
x = 6: count = 1, payout = 6
```什么时候`x = 6`已处理，赔付与当前最佳赔付相符，但是`6`大于`3`，所以答案仍然是`3`。 

对于最大限制的容量：```
Input
6
1000000 500000 250000 125000 2 4
```频率数组支持索引高达`1000000`，并且多重遍历仍然有效，因为它只访问每个候选大小的倍数。 该算法不与操作数成正比地分配内存，仅与最大容量成正比。
