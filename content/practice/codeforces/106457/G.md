 ## 解决方案
 ## 问题理解

 该问题描述了一支运输船队。 船`i`有载货能力`A_i`。 我们必须选择单个板条箱尺寸`x`。 一艘船只有当它的容量可以被分成尺寸精确的板条箱时才能使用`x`，所以船舶贡献当且仅当`A_i`是的倍数`x`。 

对于选定的板条箱大小，帝国的支出是板条箱大小乘以可以使用它的船只数量。 用数学术语来说，`x`是：`x * (number of A_i values divisible by x)`任务是找到支出最大的箱子大小。 如果多个板条箱尺寸产生相同的支出，则必须选择最小的板条箱尺寸。 

输入包含船舶数量及其容量。 输出是最佳的板条箱尺寸。 

重要的限制是最多可以有`10^6`船舶，且每艘船的容量最多为`10^6`。 一种针对每艘船检查每个可能的板条箱尺寸的解决方案将在`10^12`最坏情况下的操作，这远远超出了典型的一秒限制所允许的。 我们需要利用容量的小最大值，而不是船只的数量。 

关键的边缘情况来自关系和板条箱大小，它们显示为除数，但不是最常见的。 

例如，如果输入是：```
3
2 4 6
```正确的输出是：```
3
```板条箱尺寸`2`适用于所有三艘船，给予`2 * 3 = 6`。 板条箱尺寸`3`仅适用于有容量的船舶`6`, 给予`3 * 1 = 3`，所以这个例子不会产生平局。 仅查看最大值除数的粗心实现可能会错过较小除数中更好的候选者。 

领带盒是：```
4
2 4 6 8
```正确的输出是：```
4
```板条箱尺寸`2`给出`2 * 4 = 8`和板条箱尺寸`4`给出`4 * 2 = 8`。 由于两者的支出相同，我们必须选择较小的板条箱尺寸，所以答案是`2`。 如果粗心的实现在看到相等分数时更新答案，那么如果用后面的候选答案替换当前答案，则会返回错误的值。 

最小尺寸的情况是：```
1
1000000
```答案是：```
1000000
```应该计算唯一的一艘船，它的整个容量可以用作一个板条箱的大小。 

## 方法

 直接的解决方案是尝试所有可能的板条箱尺寸`x`。 对于每个`x`，我们扫描所有船只并计算有多少容量可以被整除`x`。 该方法是正确的，因为它评估了每种可能选择的确切支出。 然而，随着`N = 10^6`，这需要检查`10^6`可能的值最多`10^6`船舶，导致约`10^12`可分性测试。 

有用的观察结果是容量也受到限制`10^6`。 我们不必询问每艘船是否接受某个板条箱尺寸，而是可以反转该过程并询问每个板条箱尺寸的容量是其倍数。 

让`freq[v]`是有能力的船舶数量`v`。 对于固定尺寸的板条箱`x`，可用船舶的容量恰好是：`x, 2x, 3x, ...`直至最大容量。 我们可以使用类似筛子的循环对这些值的频率进行求和。 每个可能的板条箱尺寸都通过访问其倍数来处理，这比单独检查每艘船要快得多。 

计算完每个的计数后`x`，我们比较支出`x * count`。 当两个支出相等时，我们保留较小的一个`x`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N * 最大(A)) | O(1) | O(1) | 太慢了|
 | 最佳| O(max(A) log max(A)) | O(max(A) log max(A)) | O(最大(A)) | 已接受 |

 ## 算法演练

 1. 计算每种容量有多少艘船。 将此存储在`freq`， 在哪里`freq[v]`告诉我们容量的多少倍`v`出现。 这让我们能够处理价值而不是单独的船只。 
2. 迭代每个可能的 crate 大小`x`从`1`到最大容量。 对于每个`x`，将所有倍数的频率相加`x`。 这些正是可以用板条箱大小部署的船只`x`。 
3. 将支出计算为`x * count`。 如果它大于迄今为止看到的最佳支出，请替换答案。 如果相等，则保留较小的板条箱尺寸。 
4. 检查完所有候选后，输出存储的 crate 大小。 

为什么它有效：

 对于每种可能的板条箱尺寸`x`，算法访问可被整除的每个容量`x`，因此计算出的计数正是可以使用该板条箱大小的船舶数量。 因此，支付计算与问题中的定义相同。 既然一切可能`x`考虑并通过保持最小值来处理平局，最终的答案保证是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mx = max(a)
    freq = [0] * (mx + 1)

    for value in a:
        freq[value] += 1

    best_x = 1
    best_value = 0

    for x in range(1, mx + 1):
        count = 0
        for multiple in range(x, mx + 1, x):
            count += freq[multiple]

        value = x * count

        if value > best_value:
            best_value = value
            best_x = x
        elif value == best_value and x < best_x:
            best_x = x

    print(best_x)

if __name__ == "__main__":
    solve()
```频率数组仅存储输入范围内实际存在的容量。 其规模是由最大容量决定的，而不是由船舶数量决定的。 

外循环尝试所有可能的板条箱大小。 内循环遍历其倍数，并将它们的频率相加。 这避免了重复扫描整个船舶列表。 

平局条件是明确处理的。 当两个箱子尺寸具有相同的支出时，仅当新箱子尺寸较小时，当前答案才会被替换。 这可以防止结果依赖于迭代顺序。 

Python 整数不会溢出，因此乘法`x * count`即使在最大值下也是安全的。 唯一要处理的边界情况是最大容量本身，它包含在频率数组和每个多重循环中。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(M log M) | O(M log M) | 每个板条箱大小都会访问其倍数，其中`M`是最大容量。 |
 | 空间| O(M)| 频率数组存储每个容量的计数，最多可达`M`。 |

 和`M <= 10^6`，谐波串联筛在极限范围内舒适地运行。 内存占用也很小，因为只有一个 size 的整数数组`10^6 + 1`是需要的。

 ## 边缘情况

 对于领带盒：```
4
2 4 6 8
```频率数组包含每个容量的一次出现。 什么时候`x = 2`，倍数是`2, 4, 6, 8`，支付`8`。 什么时候`x = 4`，倍数是`4, 8`，还支付`8`。 算法达到`x = 4`稍后，但平分条件保持不变`x = 2`因为它更小。 

对于单艘船：```
1
1000000
```唯一有用的板条箱大小是`1000000`。 最大的支出来自于使用整艘船的容量作为板条箱的大小，给出`1000000 * 1`。 多重循环包含最大值本身，因此可以正确找到答案。 

对于许多重复容量：```
5
6 6 6 6 6
```板条箱尺寸`6`支付`30`，而较小的除数给出较小的支出。 频率方法一次对所有五艘船进行计数`freq[6]`，避免因容量重复而造成的错误。
