 ## 解决方案
 ## 问题理解

 该任务本质上是选择一个非空的船舶子集，其中每艘船都是不同的，并计算其中有多少个子集具有奇数大小。 

给你一个整数$n$，代表有多少艘不同的船只可用。 每个船舶子集都对应一个可能的舰队。 然而，只有大小为奇数的子集才被认为是有效的。 由于舰队必须至少包含一艘船，因此会自动排除空子集。 

所以问题归结为计算一组大小的子集$n$有奇数基数。 

如果我们从原始枚举的角度思考，每艘船都可以包含或排除，因此有$2^n$总子集。 其中，我们想要的正是那些所选元素数量为奇数的元素。 

一个小例子阐明了结构。 如果$n = 3$，子集是：$\{\}, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}$。 

奇数大小的子集是单例和完整的集合，给出$3 + 1 = 4$。 

约束条件允许$n \le 60$，这立即排除了任何显式枚举子集的方法。 甚至$2^{60}$远远超出了计算能力。 任何指数级的东西$n$太慢了，除非它简化为常数时间公式。 

出现微妙的边缘情况时$n = 1$。 唯一的子集是$\{1\}$，这是有效的，因为它的大小是 1。正确的答案是 1。错误地包含空集或错误计算奇偶校验的简单实现将在此处失败。 

另一种情况是$n = 2$。 子集是$\{1\}, \{2\}$，两者都有效，所以答案是 2。这已经表明奇数和偶数子集计数之间存在对称性，这成为关键的结构见解。 

## 方法

 暴力方法将生成所有$2^n$子集并计算大小为奇数的子集。 从概念上讲，这很简单：迭代从 0 到$2^n - 1$，对设置的位进行计数，如果奇偶校验为奇数，则增加答案。 这是正确的，因为每个子集仅表示一次并且奇偶校验是明确定义的。 

问题是运行时。 即使是为了$n = 40$,$2^{40}$已经是关于$10^{12}$的操作，远远超出了可行的限度。 问题大小高达 60 使其完全无法使用。 

关键的观察是有限集的子集均匀分布在奇偶校验类中。 每个子集可以与仅通过切换固定元素不同的另一个子集配对。 这种配对翻转奇偶校验，在偶数大小和奇数大小的子集之间创建一对一的对应关系。 

更具体地说，考虑所有子集$n$元素。 如果我们取任何子集$S$，切换第一个元素的存在将其映射到不同的子集$S'$。 其中一个具有偶数大小，另一个具有奇数大小。 这将整个幂集分成对，这意味着所有子集的一半是奇数大小的。 

由于有$2^n$确切地说，总子集$2^{n-1}$其中有奇数基数。 

空集不会影响此参数，因为它与包含所选元素的单例集配对，因此它已在配对结构中得到考虑。

 ## 算法演练

 1.读取整数$n$，代表不同船只的数量。 
2. 认识到每个子集对应于每艘船的二元选择，给出$2^n$总子集。 目标不是枚举它们，而是计算有多少个具有奇数大小。 
3. 使用子集可以通过翻转固定元素的成员资格来配对的结构事实，这保证了偶数和奇数大小之间的平等分割。 
4. 得出有效车队数量为$2^{n-1}$。 
5. 使用快速求幂或位移位直接计算该值。 

唯一的计算工作是评估 2 的幂，这可以根据实现在常数或对数时间内完成。 

### 为什么它有效

 不变的是，切换固定元素定义了偶数大小的子集和奇数大小的子集之间的双射。 每个子集要么包含所选元素，要么不包含，并且翻转该成员资格会更改奇偶校验而不会产生冲突。 由于此映射是可逆的并且覆盖整个幂集，因此两个奇偶校验类必须具有相同的大小，迫使每个奇偶校验类恰好包含所有子集的一半。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
print(1 << (n - 1))
```该解决方案依赖于位移而不是`pow(2, n-1)`因为它既简单又避免了浮点转换问题，尽管 Python 的整数可以安全地处理这两种问题。 移位直接构造$2^{n-1}$。 

唯一的微妙之处在于情况$n = 1$，其中移位变为$1 << 0 = 1$，匹配正确答案。 

## 工作示例

 ### 示例 1：n = 3

 我们跟踪子集如何按大小奇偶性划分。 

| 子集大小 | 计数 |
 | --- | --- |
 | 0 | 1 |
 | 1 | 3 |
 | 2 | 3 |
 | 3 | 1 |

 奇数大小的子集是大小为 1 和 3 的子集。 

这证实了配对直觉：每个偶数子集都有一个通过切换固定元素获得的相应奇数子集。 

输出是$2^{2} = 4$。 

### 示例 2：n = 4

这个例子强调了分布是对称的，无论$n$，不依赖小案例。

 ## 边缘情况

 对于$n = 1$，只有一个子集：单艘船。 该算法计算$2^{0} = 1$，它正确地将其视为有效，因为它的大小是奇数。 

对于较大的值，例如$n = 60$，结果变成一个非常大的整数，但Python可以处理任意精度的整数，因此不会发生溢出或精度问题。 计算仍然是单个位移位，因此执行时间恒定，即使在边界处也是稳定的。
