 ## 解决方案
 ## 问题理解

 我们有从 1 到 n 的整数排列。 一个操作可以获取任何元素并将其一直移动到前面或一直移动到后面。 所有其他元素的相对顺序保持不变。 

目标是将排列排序为

 1,2,3,…,n

 尽可能少地使用此类操作。 输入包含 n，后跟排列，每行一个值。 输出是所需的第一个或最后一个移动的最小数量。 

关键的限制是每个值都是不同的，并且从 1 到 n 的每个值都只出现一次。 官方限制为n≤10 5，时间限制为1秒，内存为256 MB。 当 n=10 5 时，二次算法已经执行了大约 10 10 次迭代，远远超出了一秒的范围。 我们需要一个本质上线性的解决方案。 

该操作具有非常具体的效果。 如果一个元素被移动，它只能成为最终排序数组的前缀或后缀的一部分。 不能插到中间。 这意味着有趣的问题实际上不是我们移动哪些元素，而是我们可以保持哪些连续的值块不变。 

考虑排列```
521354
```值 1、2、3 并非按递增的位置顺序排列，因为 2 出现在 1 之前，但 3、4、5 则按所需的顺序排列。 我们可以保持 3,4,5 不动，移动 1,2，所以答案是 2。粗心的方法只是简单地找到最长的递增子序列，会考虑长度为 4 的 1,3,4,5，并错误地回答 1。这些值的位置在增加，但它们的值不连续，因此无法仅使用前后移动将缺失的 2 插入到 1 和 3 之间。 

另一个边缘情况是已经排序的排列。```
41234
```答案是 0。任何将其答案初始化为至少 1 或仅搜索包含多个元素的运行的实现都可能会失败。 

反向排列是另一个有用的边界情况。```
44321
```只有一个值可以属于未触及的连续块，因此答案是 3。最长递增子序列计算在这里也给出 1，但出于不同的原因，这可以隐藏问题的真实结构。 

该语句要求所有值都不同，因此每个值都相等的输入不是有效的测试用例。 用于测试实现的相关模拟是一种排列，其中每个相邻值关系都被破坏，例如上面的反向排列。 

## 方法

 一种直接的方法是尝试每个可能的值区间[l,r]，检查这些值是否已经以正确的相对顺序出现，并保留最长的有效区间。 如果间隔的长度为 k，我们移动其他 n−k 个元素，因此它给出的答案为 n−k。 

构建后检查变得特别简单`pos`， 在哪里`pos[x]`是值 x 出现的位置。 区间 [l,r] 可以在以下情况下保持不变：

 pos[l]<pos[l+1]<⋯<pos[r]。 

一个简单的实现可以尝试每个起始值并延长间隔，直到该条件失败。 在最坏的情况下，已经排序的排列使每个扩展都成功，因此这执行

 1+2+⋯+n=O(n 2 )

 检查，大约是 5⋅10 9 检查 n=10 5，已经太大了。 检查每个区间并扫描其内容的更字面的蛮力将是立方的。 

关键的观察结果是区间的有效性仅取决于相邻值。 如果`pos[x] < pos[x+1]`，那么 x 和 x+1 可以是未触及块的连续成员。 因此，我们扫描从 1 到 n 的值，保持位置递增的连续值的当前长度。 

例如，如果位置数组是```
value:  1  2  3  4  5  6pos:    5  6  2  3  4  1
```那么比较是```
pos[1] < pos[2]   yespos[2] < pos[3]   nopos[3] < pos[4]   yespos[4] < pos[5]   yespos[5] < pos[6]   no
```所以最长的有效连续块的长度为3，即3,4,5。 

暴力方法之所以有效，是因为未触及的块完全决定了哪些元素可以保留在原处。 它失败是因为它重复检查重叠间隔。 只有相邻值才重要的观察结果让我们能够一次性找到最长的有效块。

 | ---| ---| ---| ---|
 | 蛮力 | O(n 2 ) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读排列和构造`pos`， 在哪里`pos[x]`是值 x 的索引。 我们使用位置是因为最终的排序顺序是由数值决定的，而输入则为我们提供了它们的当前位置。 
2. 开始`current = 1`和`best = 1`。 单个值始终可以保持不变，因此最长的有效块的长度至少为一。 
3. 扫描 x 从 2 到 n。 如果`pos[x - 1] < pos[x]`，通过设置扩展当前块`current += 1`。 这意味着 x−1 和 x 已经以排序排列所需的相同相对顺序出现。 
4.如果`pos[x - 1] >= pos[x]`， 重置`current`到 1。值 x−1 和 x 不能同时属于同一个未触及的连续块，因此任何以 x−1 结尾的块必须停在那里。 
5. 更新`best = max(best, current)`每次比较后。 在最后，`best`是可以保持不变的连续值的最大数量。 
6. 输出`n - best`。 保留块外部的每个值都必须移动，而块内部的每个值都可以保留在原来的位置。 

### 为什么它有效

 假设一个未触及的集合包含两个连续的值 x 和 x+1。 由于两个值都没有移动，因此它们的相对顺序永远不会改变。 在排序数组中，x 必须出现在 x+1 之前，因此必然`pos[x] < pos[x+1]`。 

更严格地说，所有未触及的值必须形成一个连续的值区间。 如果我们保持 x 和 x+2 不变，但移动了 x+1，则移动后的值只能放在前面或后面，因此它永远不会位于 x 和 x+2 之间。 因此，未触及的部分具有 l,l+1,…,r 的形式，并且当它们的位置严格增加时它恰好有效。 

对于任何此类有效间隔，将每个较小的值按降序移到前面。 每次移动都会正确放置下一个所需的前缀值。 然后将每个较大的值按升序移到后面。 未触及的间隔保留在这两个部分之间，产生完全排序的排列。 因此，如果最长有效间隔的长度为`best`，恰好 n−best 移动就足够了，并且没有解决方案可以使用更少的移动，因为必须移动这样一个间隔之外的每个元素。 

## Python 解决方案```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n = int(input())    pos = [0] * (n + 1)
    for i in range(1, n + 1):        x = int(input())        pos[x] = i
    best = 1    current = 1
    for x in range(2, n + 1):        if pos[x - 1] < pos[x]:            current += 1        else:            current = 1
        if current > best:            best = current
    print(n - best)

if __name__ == "__main__":    solve()
```第一个循环构造逆排列。 如果输入是`2 1 3 5 4`， 然后`pos[1] = 2`,`pos[2] = 1`,`pos[3] = 3`,`pos[4] = 5`， 和`pos[5] = 4`。 

第二个循环实现算法的连续位置扫描。 比较必须在`pos[x - 1]`和`pos[x]`，不在原始排列的相邻元素之间。 我们询问连续的数值是否已经以正确的顺序出现。 

当比较成功时，当前连续块增长。 当失败时，该块必须以当前值重新启动。 的更新为`best`在任一情况之后执行，因此以最终值 n 结尾的块会被正确处理。 

Python 中不存在整数溢出问题，并且数组仅包含 n+1 个整数。 该实现还处理 n=1：`best`从 1 开始，扫描为空，答案为`1 - 1 = 0`。

```没有可比较的连续值对。 该算法开始于`best = current = 1`，所以它立即输出 1−1=0。 单个值已经排序，不需要进行任何操作。

```位置数组是`[1,2,3,4,5]`当按值索引时。 每次比较都会成功，所以`current`从一增长到五。 算法得到`best = 5`和输出`0`。 这也说明了为什么即使最长块达到n，扫描也必须更新最佳长度。
