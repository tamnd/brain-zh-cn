 ## 解决方案
 ## 问题理解

 我们给定一个正整数`N`，这是经过一些未知的舍入操作后出现的值。 我们需要确定每个可能的正整数`X`可以用作舍入单位。 

舍入单位`X`有两个限制。 第一的，`X`必须除以 10 的某个次方，因此它唯一可能的素因数是 2 和 5。同样，`X`必须具有以下形式`2^a * 5^b`对于一些非负整数`a`和`b`。 二、四舍五入值`N`本身必须是以下的倍数`X`。 原始统计数据可以简单地表示为`N`，所以这两个条件也是充分的。 官方声明明确将任务简化为找到所有`X`满足这两个整除条件。 

输入包含一个整数`N`， 和`1 <= N <= 10^18`。 输出首先给出有效值的数量`X`，然后按升序打印这些值，每行一个。 公布的样本是`N = 30`,`N = 120`， 和`N = 8`。 

的上限`10^18`排除任何扫描所有可能值的情况`N`。 甚至一个`O(sqrt(N))`除数搜索可能需要周围`10^9`迭代次数，远远超出一秒的限制。 有用的结构是我们只关心 2 和 5 的指数`N`，这些指数最多分别为 59 和 25。 

有几种边缘情况可以欺骗更机械的基于除数的解决方案。 为了`N = 1`，正确的输出是`1`其次是`1`。 从 2 开始搜索的解决方案将错误地报告没有答案，即使`X = 1`始终有效。 

为了`N = 8`，正确的输出是`4`， 其次是`1`,`2`,`4`， 和`8`。 只考虑 10 次方的解决方案将会错过`2`,`4`， 和`8`，因为有效单位是质因数限制为 2 和 5 的所有数字，而不仅仅是本身为 10 次幂的数字。 

对于`N = 30`，正确的输出是`4`， 其次是`1`,`2`,`5`， 和`10`。 值如`3`,`6`， 和`15`是 30 的约数，但不能整除 10 的任何幂，因为它们包含素因数 3。枚举任意约数的解决方案`N`并接受所有这些都会产生错误的答案。 

为了`N = 120`，正确的值为`1, 2, 4, 5, 8, 10, 20, 40`。 这里是 2 的指数`N`是 3，5 的指数是 1，所以每个组合`2^a * 5^b`和`0 <= a <= 3`和`0 <= b <= 1`是有效的。 这给出了`(3 + 1)(1 + 1) = 8`答案。 

## 方法

 直接的暴力方法会尝试每个整数`X`从 1 到`N`，检查是否`X`划分`N`，然后检查是否`X`除了 2 和 5 之外没有素因数。这是正确的，因为这两个检查正是两个数学要求。 问题是范围。 为了`N = 10^18`，这样的循环执行`10^18`迭代，这是完全不可行的。 

稍微好一点的强力除数方法会枚举以下除数`N`通过检查每个整数`sqrt(N)`。 这将最坏的情况大致减少到`10^9`迭代时`N`就在附近`10^18`。 对于一秒竞赛问题来说，这仍然太慢了。 

关键的观察结果是，当且仅当一个数字具有以下形式时，它才能整除 10 的某个幂`X = 2^a * 5^b`。 

假设质因数分解`N`包含`N = 2^A * 5^B * R`，

在哪里`R`不能被 2 或 5 整除。因为`X`必须划分`N`，它的指数不能超过`N`。 因此，每个有效答案都恰好是以下之一`2^a * 5^b`， 在哪里`0 <= a <= A`和`0 <= b <= B`。 

不需要考虑其余的因素`N`根本不。 我们只是反复地划分`N`按 2 找到`A`，并反复除以 5 求出`B`。 

蛮力之所以有效，是因为它明确地测试了每个可能的单位，但由于数值范围巨大而失败。 有效单位仅包含素数 2 和 5 的观察结果让我们可以将搜索替换为`10^18`搜索最多约 60 个可能的 2 次方和 26 个可能的 5 次方的整数。 

一旦我们生成了每个`2^a * 5^b`，我们对结果值进行排序并打印它们。 生成的候选者数量最多是很少的`(59 + 1)(25 + 1) = 1560`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解结束`1..N`|`O(N log N)`在一个简单的实施中|`O(1)`不包括输出| 太慢了 |
 | 除数搜索最多`sqrt(N)`|`O(sqrt(N))`|`O(1)`不包括输出| 太慢了 |
 | 最优指数枚举 |`O(log N + K log K)`|`O(K)`| 已接受 |

 这里`K`是有效值的数量`X`， 和`K <= 1560`对于给定的界限。 

## 算法演练

 1. 阅读`N`并确定 2 除多少次。 开始于`a = 0`并反复划分`N`偶数时增加 2，增加`a`每次。 

在最后，`a`正好是原数的素因数分解中 2 的指数`N`。 
2. 对 5 进行同样的操作。尽可能重复将剩余数字除以 5，增加`b`。 

我们只需要这两个指数，因为每个有效的`X`除了 2 和 5 之外，不能包含任何质因数。 
3. 生成每对指数`i`和`j`满意的`0 <= i <= a`和`0 <= j <= b`。 

对于每一对，构建`2^i * 5^j`并存储它。 每个这样的值都可除`N`，因为没有一个指数超过了相应的指数`N`。 
4. 对生成的值进行排序。 

嵌套循环自然地通过指数而不是数值大小来枚举值，因此它们的生成顺序不一定是递增的。 排序准确地给出了问题所需的输出顺序。 
5. 打印生成的值的数量，然后打印每个值在其自己的行上。 

### 为什么它有效

 不变的是每个生成的值都具有以下形式`2^i * 5^j`指数不大于`N`。 因此，每个生成的值都除以`N`以及足够大的 10 次幂，因此它满足两个所需条件。 

相反，取任何有效的`X`。 自从`X`除 10 的幂，它的质因数分解只能包含 2 和 5，所以`X = 2^i * 5^j`。 自从`X`也分`N`，其指数满足`i <= a`和`j <= b`。 该算法精确地枚举了该对，因此每个有效的`X`被生成。 两个方向共同证明生成的集合正是所需的答案集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    x = n
    a = 0
    while x % 2 == 0:
        x //= 2
        a += 1

    b = 0
    while x % 5 == 0:
        x //= 5
        b += 1

    powers2 = [1] * (a + 1)
    for i in range(1, a + 1):
        powers2[i] = powers2[i - 1] * 2

    powers5 = [1] * (b + 1)
    for j in range(1, b + 1):
        powers5[j] = powers5[j - 1] * 5

    ans = []
    for p2 in powers2:
        for p5 in powers5:
            ans.append(p2 * p5)

    ans.sort()

    out = [str(len(ans))]
    out.extend(map(str, ans))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个循环从中提取 2 的指数`N`。 第二个循环从剩余值中提取 5 的指数。 在计算 5 的因数之前删除 2 的因数不会影响 5 的指数，因为 2 和 5 是不同的素数。 

两个幂数组避免了在嵌套循环内重复计算幂。 它们很小，因为`N <= 10^18`。 实际上，`2^60 > 10^18`和`5^26 > 10^18`，因此最多可以有 60 个 2 的幂和 26 个 5 的幂与答案相关。 

Python 整数不会溢出，但生成的乘积也受下式限制：`N`，因为每个生成的`2^i * 5^j`划分`N`。 指数使用包含范围，这是必要的，因为`X`本身可能包含 2 或 5 的全部幂`N`。 

排序步骤是必要的，因为指数顺序不等于数字顺序。 例如，与`N = 120`，这对`(3, 0)`产生 8 而`(0, 1)`产生 5.

 ## 边缘情况

 对于`N = 1`，算法不进入因子计数循环，因此`a = b = 0`。 嵌套枚举恰好有一对，`(0, 0)`，生产`2^0 * 5^0 = 1`。 输出是`1`其次是`1`，这是正确的，因为舍入到最接近的 1 倍数始终是有效的方法。 

为了`N = 8`，与问题相关的因式分解是`2^3`。 算法得到`a = 3`和`b = 0`，然后生成`1, 2, 4, 8`。 输出是`4`接下来是这四个值。 这解决了将“除以 10 的幂”解释为“是 10 的幂”的常见错误。 

为了`N = 30`，相关指数为`a = 1`和`b = 1`。 生成的集合是`{1, 2, 5, 10}`。 尽管 30 还有其他约数，例如 3、6 和 15，但它们都不能整除 10 的任何幂，因为每个约数都包含 3 的因数。该算法永远不会生成它们。 

为了`N = 120`，指数是`a = 3`和`b = 1`。 2 的四种可能的幂与 5 的两种可能的幂相结合，正好产生八个值。 最大的候选人是`2^3 * 5 = 40`，它整除 120。下一个仅涉及 2 和 5 的较大数字 80 不能整除 120，因为它需要 4 个 2 的因数，这说明了为什么两个指数界限必须包含在内但绝不能超过。 

为了`N = 10^18`，因式分解为`2^18 * 5^18`。 每对`(i, j)`和`0 <= i, j <= 18`是有效的，给出了 361 个答案。 这是输入范围下最大的相关指数组合，它说明了为什么枚举指数对即使在以下情况下仍然很小：`N`它本身是巨大的。 

本质上的简化是，原始的舍入故事不需要我们重建未知的原始统计数据。 一次`X`划分`N`，我们可以选择原始统计量为`N`本身，所以整个问题变成了寻找除数`N`其质因数仅限于 2 和 5。这将一个潜在的巨大除数问题变成了两个质数指数的小枚举。
