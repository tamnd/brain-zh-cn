 ## 解决方案
 ## 问题理解

 我们被要求确定给定的公司名称是否相对于垂直镜子对称。 实际上，我们给定一个由大写英文字母组成的字符串，我们需要检查该字符串在沿其左右轴垂直放置的镜子中反射时是否看起来相同。 只有某些字母以这种方式对称，例如`A`,`H`,`I`,`M`,`O`,`T`,`U`,`V`,`W`,`X`,`Y`。 像这样的字母`B`或者`C`镜像时看起来会有所不同，因此不能出现在有效的名称中。 

输入约束允许字符串长度最多为 100,000 个字符。 由于时间限制为 1 秒，这意味着算法必须在最坏情况下以线性时间 O(n) 运行。 任何二次或涉及字符串的嵌套迭代都会太慢。 内存有 256 MB 的空间，因此存储一小组有效字符或长度为 n 的布尔数组是微不足道的。 

尽管该问题保证非空输入，但要注意的主要边缘情况是空字符串或单字符字符串。 有效的单个字符（例如`A`）应该返回`YES`。 具有单个无效字符的字符串（例如`B`）应该返回`NO`。 另一个微妙的场景是包含所有有效字符但以不对称方式排列的字符串，例如`AHAH`无效，因为其相反`HAHA`不同。 

## 方法

 天真的方法很简单：反转字符串并检查每个字符是否都是镜像的并且在允许的集合中。 这是有效的，因为镜像相当于向后读取字符串，同时确保每个字符本身是对称的。 然而，在简单的实现中，人们可能会意外地尝试将每个字符映射到其镜像版本，这对于大写字母来说是不必要的，因为只有特定的子集有效。 这可能会引入冗余操作，但仍然是 O(n)。 

关键的见解是，问题简化为两个检查：首先，每个字符都必须属于垂直对称字母的集合； 其次，字符串向前和向后读时必须相同。 通过在一次传递中组合这些检查，我们可以在 O(n) 时间内有效地解决问题，而无需超出一小部分恒定大小的字母之外的额外内存。

 ## 算法演练

 1. 创建一个包含所有相对于垂直镜像对称的字母的集合：`A, H, I, M, O, T, U, V, W, X, Y`。 这允许对每个角色进行恒定时间的成员资格检查。 
2. 初始化两个指针，一个在字符串的开头，一个在字符串的结尾。 我们将向中间迭代。 
3. 在每一步中，检查起始指针和结束指针处的字符是否都在允许的集合中。 如果任一字符无效，则打印`NO`并终止。 这会立即处理单个不允许的字符使整个字符串无效的情况。 
4. 检查起始指针和结束指针处的字符是否相等。 如果没有，则打印`NO`并终止。 这可以确保字符串向前和向后读取相同的内容。 
5. 将起始指针向前移动一步，将结束指针向后移动一步，重复步骤 3 和 4，直到指针相遇或交叉。 
6. 如果循环完成但没有终止，则打印`YES`。 该字符串满足对称性和字符有效性。 

为什么它有效：不变的是在每次迭代中，当前指针之外的所有字符都已验证对称性和正确放置。 该算法仅检查所有对一次。 由于只允许有效字母并且每对都匹配，因此保证最终字符串与其镜像反射相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
valid_letters = {'A', 'H', 'I', 'M', 'O', 'T', 'U', 'V', 'W', 'X', 'Y'}

left, right = 0, len(s) - 1
while left <= right:
    if s[left] not in valid_letters or s[right] not in valid_letters:
        print("NO")
        sys.exit()
    if s[left] != s[right]:
        print("NO")
        sys.exit()
    left += 1
    right -= 1

print("YES")
```该代码首先读取输入字符串并删除所有尾随换行符。 有效的镜像字母集允许快速成员资格测试。 然后，我们使用两指针技术从外到内检查对称性。失败时立即退出可以避免不必要的工作。 这确保了算法在 O(n) 时间内运行并且仅使用 O(1) 额外空间。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    valid_letters = {'A', 'H', 'I', 'M', 'O', 'T', 'U', 'V', 'W', 'X', 'Y'}
    left, right = 0, len(s) - 1
    while left <= right:
        if s[left] not in valid_letters or s[right] not in valid_letters:
            return "NO"
        if s[left] != s[right]:
            return "NO"
        left += 1
        right -= 1
    return "YES"

# Provided sample
assert run("AHA\n") == "YES", "sample 1"

# Custom cases
assert run("ABBA\n") == "NO", "invalid letters"
assert run("AAA\n") == "YES", "all valid, odd length"
assert run("AHHHA\n") == "YES", "odd length palindrome"
assert run("XYX\n") == "YES", "symmetric X/Y letters"
assert run("XYZ\n") == "NO", "contains invalid Z"
assert run("A\n") == "YES", "single valid letter"
assert run("B\n") == "NO", "single invalid letter"

 ## 边缘情况

 对于单个字符`A`, 指针`left`和`right`两者都指向索引 0。循环运行一次，发现`A`在有效集合中，并且`s[left] == s[right]`，然后退出，返回`YES`。 对于单个无效字符`B`，同一循环立即检测到`B`不在有效集合中并返回`NO`。 具有最大长度和所有有效字符的字符串将在 O(n) 时间内处理，除了小集合之外没有额外的内存，从而确认了跨约束的鲁棒性。
