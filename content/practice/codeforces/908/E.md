 ## 解决方案
 ## 问题理解

 我们使用长度的二进制向量`m`，可以将其视为整数`0`到`2^m - 1`。 

有效的集合`S`必须满足三个结构特性。 

首先，它包含给定集合中的每个向量`T`。 

其次，它在XOR下是封闭的。 如果两个向量属于`S`，那么它们的按位异或也必须属于`S`。 

第三，按位与运算是封闭的。 如果两个向量属于`S`，那么它们的按位与也必须属于`S`。 

任务是数出有多少个不同的集合`S`满足所有这些要求。 

这些约束立即表明我们不应该显式地构建向量集。 周围空间包含`2^m`向量，以及`m`可以大到`1000`。 任何对向量进行一一推理的方法都是不可能的。 

输入的不寻常部分是`n`非常小。 我们最多有`50`给定向量，而维度`m`可以达到`1000`。 这种不对称性是关键。 我们不应该考虑行，而应该考虑列。 

一个常见的错误是关注向量本身并尝试生成闭包`T`在异或和与下。 即使对于中等维度，闭包也已经可以包含指数级的多个向量。 

另一个容易犯的错误是假设仅 XOR 下的闭包就足够了。 例如：```
m = 2
T = {10, 01}
```XOR 闭包是整个空间`{00,01,10,11}`。 该集合确实有效，但它并不是唯一涉及的线性代数对象。 AND 条件赋予了问题真正的结构。 

当所有向量中的几个坐标看起来相同时，就会出现第二种微妙的情况`T`。```
m = 2
T = {11}
```两个坐标在内部的行为相同`T`。 有两个有效集合：```
{00,11}
```和```
{00,01,10,11}
```将相同坐标视为永久合并的解决方案将错过其中一个。 

## 方法

 蛮力观点很有用，因为它揭示了底层的代数结构。 

假设我们尝试枚举每个集合`S`含有`T`并测试XOR和AND下是否闭合。 宇宙包含`2^m`向量，所以候选集的数量是$$2^{2^m}.$$即使是为了`m = 20`这个数字大得离谱。 

更复杂的蛮力将从`T`并重复将所有 XOR 和 AND 结果相加，直到达到闭包。 计算包含的最小有效集合`T`，但问题要求所有有效的集合，而不仅仅是最小的集合。 

关键的观察结果是 XOR 下的闭包使得`S`向量空间`F₂`，而 AND 下的闭包意味着`S`在坐标乘法下也是闭的。 

的一个子空间`F₂^m`在坐标乘法下闭合的是一个布尔子环`F₂^m`。 

这种子环具有非常刚性的形式。 

考虑两个坐标位置`i`和`j`。 如果每个向量`S`这两个位置总是有相同的位，那么里面的坐标是无法区分的`S`。 这种关系将坐标划分为块。 

对于任何块，每个向量`S`在该块上必须保持不变。 相反，一旦坐标分区固定，每个块上恒定的所有向量的集合在 XOR 和 AND 下都是封闭的。 

因此，每个有效集合精确对应于坐标位置的分区。 

现在要求每个向量`T`属于`S`。 

取两个坐标`i`和`j`。 仅当每个向量`T`在位置上有相同的位`i`和`j`。 

对于每个坐标，形成其列签名：$$(t_1[i], t_2[i], \dots, t_n[i]).$$具有不同签名的坐标永远不能放置在同一个块中。 

具有相同签名的坐标是完全可以互换的。 在这样一个规模的群体里面`c`，我们可以以任何我们喜欢的方式对坐标进行分区，并且每个这样的分区都会产生一个不同的有效集。 

一组大小的分区数量`c`是贝尔号码`Bell(c)`。 

不同的签名组是独立的，所以答案是$$\prod Bell(c_i),$$在哪里`c_i`是签名组的大小。 

唯一剩下的任务是计算贝尔数`1000`。 

使用斯特林数递推$$S(n,k)=S(n-1,k-1)+kS(n-1,k),$$我们可以计算所有贝尔数$$Bell(n)=\sum_{k=0}^{n} S(n,k)$$在`O(m²)`时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数为`2^m`| 指数| 太慢了|
 | 最佳 |`O(m² + mn)`|`O(m²)`| 已接受 |

 ## 算法演练

 1. 阅读全部`n`二进制字符串。 
2.对于每个坐标位置`j`，构建其列签名，其中包含`j`所有输入字符串的第 - 位。 
3. 按相同的签名对坐标进行分组，并记录每组的大小。 
4. 预先计算 Bell 数最多`m`。 
5. 使用斯特林递推$$S(n,k)=S(n-1,k-1)+kS(n-1,k)$$模数`10^9+7`。 
6. 对于每一个`n`, 总和`S(n,k)`获得`Bell(n)`。 
7. 将答案初始化为`1`。 
8. 对于每个大小的签名组`c`，将答案乘以`Bell(c)`模数`10^9+7`。 
9. 输出结果。 

步骤3就足够了，因为具有不同签名的坐标永远不能属于同一个分区块，而共享签名的坐标可以任意分区。 

### 为什么它有效

 每个好的集合都是一个布尔子环`F₂^m`。 的布尔子环`F₂^m`正是在某些坐标分区的块上恒定的向量集合。 

的向量`T`限制哪些坐标可以共享一个块。 只有当两个坐标的所有向量都可以合并时`T`为两个位置分配相同的位，这正是它们的列签名相等的条件。 

在一个签名类中，允许任意分区。 不同的签名类别是独立的。 一类大小的分区数量`c`是`Bell(c)`，因此将所有类别的贝尔数相乘会将每个有效集恰好计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    m, n = map(int, input().split())
    rows = [input().strip() for _ in range(n)]

    groups = {}

    for col in range(m):
        sig = tuple(rows[r][col] for r in range(n))
        groups[sig] = groups.get(sig, 0) + 1

    # Stirling numbers of the second kind
    stir = [[0] * (m + 1) for _ in range(m + 1)]
    stir[0][0] = 1

    bell = [0] * (m + 1)
    bell[0] = 1

    for i in range(1, m + 1):
        for k in range(1, i + 1):
            stir[i][k] = (
                stir[i - 1][k - 1] +
                k * stir[i - 1][k]
            ) % MOD

        bell[i] = sum(stir[i][1:i + 1]) % MOD

    ans = 1
    for cnt in groups.values():
        ans = (ans * bell[cnt]) % MOD

    print(ans)

solve()
```实现的第一部分构建列签名。 自从`n ≤ 50`，将签名存储为字符元组是完全安全的。 当这些元组相等时，两个坐标恰好属于同一组。 

贝尔数是通过第二类斯特林数计算的。 和`m ≤ 1000`， 这`O(m²)`动态程序执行大约一百万次状态更新，这很容易满足限制。 

一个常见的实现错误是尝试直接根据递归定义计算贝尔数。 这种递推涉及所有先前的贝尔数，而且很快就会变成二次方。 斯特林递推是简单且数值稳定的模数`10^9+7`。 

另一个微妙的点是`Bell(0)=1`。 尽管没有签名组的大小为零，但正确启动 Stirling DP 需要此基本情况。

 ## 边缘情况

 考虑```
1 1
0
```只有一个坐标，因此只有一个大小的签名类别`1`。 自从`Bell(1)=1`，算法返回`1`。 无需特殊处理。 

考虑```
2 1
11
```两个坐标具有相同的签名`(1)`。 团体规模为`2`, 给予`Bell(2)=2`。 该算法正确地计算了两个可能的坐标分区。 

考虑```
3 2
101
010
```签名是：```
(1,0), (0,1), (1,0)
```坐标`1`和`3`可以相互作用，但可以协调`2`不能加入他们。 答案就变成了$$Bell(2)\cdot Bell(1)=2.$$这说明了为什么按列签名分组是正确的标准。 当每个向量的时候两个坐标是可合并的`T`认为它们是相同的。
