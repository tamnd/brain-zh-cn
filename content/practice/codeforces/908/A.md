 **求解时间：** 1m 34s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们看到每张卡片的一面。 可见侧可以是小写字母或数字。 

我们要验证的说法是：

 “只要一张卡片的一侧有元音，另一侧就包含偶数。”

 我们可能会翻转一些牌。 任务是找到在最坏情况下必须检查的最少卡片数量，以确定该陈述是否对所有卡片都成立。 

关键的观察是，这是一个逻辑含义：

 > 元音⇒偶数

 为了验证一个含义，我们只需要检查可能违反它的卡片。 

输入长度最多为 50，这个长度很小。 即使是二次或三次解也能轻松拟合。 挑战不在于性能，而在于准确识别哪些卡很重要。 

一个常见的错误是翻转每个元音和每个数字。 一些可见的卡片永远不会违反规则，因此检查它们不会提供任何信息。 

考虑显示辅音的卡片`b`。```
b
```无论对方如何，这张牌都不能违背其含义。 如果隐藏的一侧是奇数，可见的一侧仍然不是元音。 如果隐藏的一面是字母，则含义无关。 正确的贡献是 0 次翻转。 

另一个容易犯的错误是忽略奇数。```
1
```如果隐藏的一面是`a`，该卡片将成为一个反例：一侧为元音，另一侧为奇数。 我们必须翻转这样的牌。 正确答案是 1。 

一个更微妙的情况是数字`0`。```
0
```自从`0`是偶数，隐藏元音仍然满足规则。 这张牌永远无法反驳其中的含义，所以不需要翻转。 平等地对待所有数字会错误地计算它。 

## 方法

 思考这个问题的一种强力方法是检查每个可见的字符，并询问翻转该卡片是否可以揭示对声明的违反。 由于最多有 50 张卡片，我们可以手动对每张卡片进行分类。 这已经以线性时间运行。 

真正的挑战是确定正确的分类。 

必须检查卡片的可见面是否为元音。 那么隐藏的一面一定是平坦的，我们不看就无法知道这一点。 

还必须检查卡片的可见面是否为奇数。 如果隐藏的一面恰好是元音，则该陈述将是错误的。 

所有其他卡都无关紧要。 

对于辅音，含义对反面没有限制。 辅音与奇数配对是完全有效的。 

对于偶数位，隐藏元音仍会满足含义，因为该数字是偶数。 

这一观察将整个问题简化为计算两组：

 1. 可见元音。 
2. 可见奇数位。 

答案很简单，就是他们工会的规模。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每张卡牌的暴力分类 | O(n) | O(1) | O(1) | 已接受 |
 | 元音和奇数的最佳计数 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取输入字符串。 
2. 创建包含元音的集合：`a`,`e`,`i`,`o`,`u`。 
3. 创建包含奇数位的集合：`1`,`3`,`5`,`7`,`9`。 
4. 将答案初始化为0。 
5. 扫描字符串中的每个字符。 
6. 如果该字符是元音，则增加答案。 

我们必须检查这样的卡片，因为隐藏的一面必须是偶数。 
7. 否则，如果该字符是奇数，则增加答案。 

我们必须检查这样的卡片，因为隐藏的一面可能是元音，从而造成违规。 
8. 忽略所有剩余字符。 

这些是辅音，甚至是数字，都不能直接违反含义。 
9. 打印最终计数。 

### 为什么它有效

 只有两侧为以下的牌才能违反该含义：```
vowel + odd digit
```如果可见的卡片已经显示了元音，我们必须检查隐藏的一面是否是奇数。 如果可见的卡片已经显示了奇数位，我们必须检查隐藏的一面是否是元音。 

通过精确检查这些卡片可以发现所有可能的反例。 相反，可见的辅音甚至数字永远不会参与违规，无论另一侧隐藏什么。 计算可见元音和可见奇数既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()

vowels = {'a', 'e', 'i', 'o', 'u'}
odd_digits = {'1', '3', '5', '7', '9'}

ans = 0

for ch in s:
    if ch in vowels or ch in odd_digits:
        ans += 1

print(ans)
```实现直接遵循推理。 

元音集恰好包含触发含义的字母。 每当出现一张牌时，必须翻转相应的牌。 

如果元音隐藏在另一侧，奇数位集合恰好包含可能违反含义的数字。 

该条件使用逻辑或，因为任一情况都需要检查。 任何字符都不能同时属于这两个组，但 OR 自然地表达了规则并使代码保持简单。 

输入大小很小，因此单个线性扫描就足够了。

 ## 边缘情况

 考虑一张仅显示辅音的卡片：```
b
```该算法检查是否`b`是元音或奇数。 两者都不是，所以答案仍然是 0。这是正确的，因为没有隐藏值可以使辅音违反含义。 

考虑一张显示奇数数字的卡片：```
1
```该算法识别`1`作为奇数位并将答案增加到 1。我们必须检查这张卡，因为隐藏的一面可能是元音，从而创建禁止的组合`(vowel, odd digit)`。 

考虑一张显示偶数位的卡片：```
0
```算法不计算它。 如果隐藏的一侧是元音，则仍然满足规则，因为数字是偶数。 如果隐藏的一侧不是元音，则也满足该规则。 无需翻转。 

考虑一个根本没有元音的字符串：```
bcdf
```每个字符都会被忽略。 答案是 0，这与当当前可见的任何卡面上没有出现元音时含义自动为真这一事实相符。
