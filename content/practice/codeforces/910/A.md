 ## 解决方案
 ## 问题理解

 我们得到一条从 1 到 n 的一维位置线。 有些位置包含一朵百合花，用`1`，而其他的是空的，用 a 表示`0`。 青蛙从位置 1 开始，想要到达位置 n。 

从任何有百合花的位置 x 开始，青蛙可以向前跳到任何位置 y，使得 1 ≤ y − x ≤ d，但前提是位置 y 也包含百合花。 每次跳跃只花费一次移动，并且我们希望到达位置 n 所需的最少跳跃次数。 如果不可能达到 n，则答案为 -1。 

该结构本质上是一个图，其中节点是百合位置，如果 j 在距离 d 内从 i 可达，则从 i 到 j 存在有向边。 该任务简化为在此隐式图中找到从节点 1 到节点 n 的最短路径。 

约束 n ≤ 100 立即表明二次或三次解也是可以接受的。 在此范围内，对所有转换进行完整的 BFS 是微不足道的，但由于尺寸较小，即使是贪婪扫描也能起作用。 

一些边缘情况很容易被忽略。 例如，如果除端点之外的所有位置均为零`10000001`，而 d 很小，青蛙被迫跳过大于 d 的间隙，导致无法到达目的地。 另一个微妙的情况是，存在多个短跳，但最大长度的贪婪跳转未能落在可达链上，例如：```
n = 7, d = 3
1000101
```尽管远跳看起来很诱人，但只有中间的百合位置才重要，跳过它们会破坏连接性。 

## 方法

 蛮力的想法是将每个百合位置视为一个节点并尝试每个可能的跳跃序列。 从位置 i 开始，我们可以尝试 [i+1, i+d] 中包含百合花的所有可达 j，递归地探索所有路径，直到到达 n。 这是正确的，因为它枚举了所有有效的路线，但它本质上是指数级的。 在最坏的情况下，每个位置都有一朵百合花并且 d 很大，路径的数量就像分支因子 d 随着深度 n 一样增长，即使 n = 100，这也很快变得不可行。 

关键的观察结果是所有边都具有相同的权重，每次跳跃的成本恰好为 1。这将问题转化为未加权的最短路径问题。 我们不需要探索所有路径，而是只需要最少的步数即可到达每个可到达的位置。 这很自然地暗示了动态规划或 BFS。 

直接 DP 解释是维持`dp[i]`作为到达位置 i 所需的最小跳跃。 我们初始化 dp[1] = 0 并向前放松转换：从 i 开始，我们尝试 (i+1 到 i+d) 中的所有 j。 如果 j 有百合花，我们更新 dp[j] = min(dp[j], dp[i] + 1)。 因为 n 很小，所以简单的 O(n·d) 松弛就足够了。 

等效的 BFS 公式将每个位置视为图中的一个节点，其边缘指向包含百合花的下一个 d 个位置。 BFS 保证未加权图中的最短路径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（所有路径）| 指数| O(n) 递归堆栈 | 太慢了 |
 | DP / BFS 超过头寸 | O(n·d) | O(n) | 已接受 |

 ## 算法演练

 1. 将字符串转换为布尔数组，我们可以在其中快速检查某个位置是否包含百合花。 这允许在转换期间进行恒定时间的有效性检查。 
2. 创建距离数组`dist`大小为 n+1 并将所有值初始化为一个大数，除了`dist[1] = 0`，因为我们从位置 1 开始，跳跃为零。 
3. 迭代从 1 到 n 的位置。 对于每个可到达的位置 i （意味着`dist[i]`不是无穷大），我们尝试向前跳跃。 
4. 从位置 i 开始，尝试从 i+1 到 min(n, i+d) 的所有下一个位置 j。 如果位置 j 有一朵百合花，我们可以再跳一次到达它，所以我们更新`dist[j] = min(dist[j], dist[i] + 1)`。 
5. 对所有位置继续这个放松过程。 因为我们总是向前传播最短的已知距离，所以后来的改进仍然完善了早期的近似值。 
6.处理完毕后，检查`dist[n]`。 如果仍为无穷大，则输出-1。 否则输出`dist[n]`。 

关键思想是每个位置都按递增顺序处理，并且所有转换都只会向前移动，因此一旦我们处理完 i，我们以后将永远找不到通往 i 的更好路径。 

### 为什么它有效

 该算法保持不变式`dist[i]`始终存储仅使用有效的百合位置到达 i 所需的最小跳跃次数。 当我们处理 i 时，已经考虑了到达 i 的所有最佳方式，因为由于严格向前移动，任何到达 i 的路径都必须来自较小的索引。 到达可到达位置的每一个可能的最后一步都会被检查一次，确保不会错过更短的路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, d = map(int, input().split())
    s = input().strip()
    
    INF = 10**9
    dist = [INF] * n
    dist[0] = 0  # position 1
    
    for i in range(n):
        if dist[i] == INF:
            continue
        if s[i] == '0':
            continue
        for j in range(i + 1, min(n, i + d + 1)):
            if s[j] == '1':
                if dist[j] > dist[i] + 1:
                    dist[j] = dist[i] + 1
    
    print(dist[n - 1] if dist[n - 1] != INF else -1)

if __name__ == "__main__":
    solve()
```该实现使用 0 索引数组来表示位置 1 到 n。 这`dist`数组跟踪到达每个索引所需的最小跳转次数。 嵌套循环枚举长度最多为 d 的所有可能的向前跳转。 

一个微妙的细节就是条件`if s[i] == '0'`。 即使某个位置有计算出的距离，除非它实际上包含百合花，否则它也是无关紧要的，因为青蛙无法站在那里。 这可以防止从无效状态传播转换。 

The inner loop carefully uses`min(n, i + d + 1)`以避免越界访问，同时保留所有有效的跳转长度。

 ### 示例 1

 输入：```

10010101
```我们追踪`dist`当我们处理时。 

| 我| 距离[i] | s[i] | 可达跳跃| 更新 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 1 | 1-4 | 1-4 距离[3]=1 |
 | 3 | 1 | 1 | 4-7 | 距离[4]=2，距离[6]=2 |

 | 6 | 2 | 1 | 7-7 | 7-7 距离[7]=3 |

 最终答案是 2，因为最佳路径是 1 → 4 → 8。 

此跟踪确认只要存在可到达的链，跳过无效位置（如索引 4）就不会阻止进度。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n·d) | 对于每个可到达的位置，我们扫描最多 d 个前向位置 |
 | 空间| O(n) | 距离数组为每个位置存储一个值 |

 当 n ≤ 100 时，最大操作次数最多为 10,000 次，这在时间限制下是微不足道的。
