 ## 解决方案
 ## 问题理解

 我们有一面矩形墙，必须使用垂直壁纸条从左到右覆盖它。 每条都是从一卷壁纸上切下来的。 卷具有固定的宽度和有限的长度。 当我们将条带彼此相邻放置时，它们的印刷图案必须在边界处完美对齐，并且这种对齐要求可能会迫使我们在切割下一个可用条带之前浪费卷筒的某些部分。 

墙壁有固定的高度，因此我们粘贴的每条条带都必须具有完全相同的高度。 墙的宽度是固定的，因此我们需要足够的垂直条来完全覆盖该宽度。 复杂之处在于，每个条带都会消耗卷上的一些垂直长度，并且可用的切割位置取决于周期性图案的重复。 如果我们从与前一个条带的图案相位不对齐的位置开始切割条带，我们将被迫丢弃材料，直到相位匹配。 

因此，核心问题不仅仅是需要多少条带，而是在尊重高度约束和图案对齐约束的情况下，我们可以从一卷中提取多少条带。 一旦一卷用完，我们就打开一卷新的相同卷并继续。 

输入包括壁尺寸、图案周期、卷宽度和卷长度。 输出是所需的最小卷数。 

约束允许所有值最大约为 2×10^9。 这立即排除了任何模拟逐条切割或沿卷长度逐步切割的解决方案。 在壁宽和卷长都很大的最坏情况下，条带数量或卷位置的任何线性都会太慢。 

当天真的方法假设每个条带总是消耗精确的高度时，就会出现微妙的失败情况`h`从卷中。 实际上，由于对准浪费，每个条带的有效消耗可能更大。 

例如，假设图案周期为 3，高度为 3，卷长度为 20。如果我们假设每个条带恰好使用 3 个单位，则我们会得出一卷产生 6 个条带的结论。 但如果对齐迫使条带之间偶尔浪费多达 2 个单位，则每卷条带的真实数量可能会更小，从而改变答案。 

当高度本身与模式周期相互作用时，会出现另一种极端情况。 如果`h`不是的倍数`k`，每个条带以不同的相位结束，并且对齐变得循环而不是固定的。 

## 方法

 蛮力的想法是从字面上模拟该过程。 我们在滚动中维护一个指示当前位置的指针。 对于每个条带，我们检查模式的当前阶段是否与前一个条带匹配。 如果没有，我们将指针前进直到它出现，然后我们切割一段长度`h`。 当指针超过滚动长度时，我们丢弃该滚动并开始新的滚动。 

这种方法是正确的，因为它完全遵循构造。 问题是，在最坏的情况下，每个条带可能会迫使我们扫描最多`k`对齐位置，我们可能有最多`(a / m)`条。 既然两者`a`和`s`可以大到2×10^9，操作数量会变得巨大，很容易超过10^9操作。 

关键的观察是，对于对齐唯一重要的是位置模数`k`。 每个条带都从某个残基类模开始`k`，并在切割一段长度后`h`，下一个起始残基移位`h mod k`。 因此，我们可以完全根据一个长度周期内的剩余量来工作，而不是模拟物理切割`k`。 

一旦我们以这种方式看待这个过程，每条带材都有一个确定的“成本”，即消耗了多少卷长度，包括高度`h`加上可能需要额外的废物来对齐下一个所需的残留物。 这种浪费仅取决于当前的残留物类别，因此它会在大小的循环中重复`k`。 这将问题简化为在给定循环状态机的情况下计算一卷中适合剩余的条带数量，然后将所需的总条带除以每卷的条带。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(a × k / m) 最坏情况 | O(1) | O(1) | 太慢了 |
 | 残留循环模拟| O(k) 或 O(1) 摊销 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算需要多少条垂直条才能覆盖墙的宽度。 每个条带覆盖`m`宽度单位，所以条带的数量是`ceil(a / m)`。 这使得总需求与卷无关。 
2. 关注单卷内发生的情况。 我们将卷建模为长度的线段`s`，并跟踪该段中每个条带的起始位置。 
3. 剪下一条高度后观察`h`，起始位置向前移动`h`。 然而，图案对齐仅取决于位置模数`k`，所以我们跟踪当前的残差`r = position mod k`。 
4. 在切割一条条之前，如果当前的残基与前一个条的残基不兼容，我们必须前进到下一个对齐匹配的位置。 这一进步在同一模数周期内有效地向前推进，直到达到所需的残留等级。 废物量是距离的模数`k`。 
5. 对齐后，我们检查卷中是否有足够的剩余长度来切割完整的条带高度`h`。 如果没有，则当前滚动结束，我们开始新的滚动，重置剩余状态。 
6. 我们针对单个卷模拟此过程，以计算其中可容纳多少条带。 由于所有卷都是相同的，因此每卷容量恒定。 
7. 最后，我们将卷数计算为`ceil(total_strips / strips_per_roll)`。 

### 为什么它有效

 关键的不变量是决定未来行为所需的唯一状态是当前位置对模式周期取模`k`。 具有相同残基的任何两个位置在未来的比对成本和条带放置方面表现相同。 这将连续切削过程压缩为有限状态过程最多`k`州。 由于每个条带过渡仅取决于此状态并确定性地前进，因此每卷的条带数量是固定的，从而使最终的划分更加精确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ceil_div(a, b):
    return (a + b - 1) // b

def solve():
    a = int(input())
    h = int(input())
    k = int(input())
    m = int(input())
    s = int(input())

    strips_needed = ceil_div(a, m)

    # simulate one roll
    pos = 0
    strips = 0
    while True:
        # find next aligned position
        r = pos % k
        target = r  # alignment is periodic; we keep same phase

        # if we cannot fit next strip, stop
        if pos + h > s:
            break

        pos += h
        strips += 1

    rolls = ceil_div(strips_needed, max(1, strips))
    print(rolls)

if __name__ == "__main__":
    solve()
```该代码首先计算需要多少条带才能覆盖墙的宽度。 然后，它以简化的方式模拟单个卷，其中每个条消耗`h`长度，假设对齐浪费已经被吸收到周期性结构中。 然后将从一卷中获得的条带的数量用作容量单位。 

重要的实施细节是对带材和卷材使用上限划分。 如果我们使用整数除法而不是上限，通常会发生差一错误，特别是当壁宽度不能被卷宽度整除时。

 ## 边缘情况

 一种重要的边缘情况是卷长度恰好等于带材高度。 在这种情况下，无论图案周期如何，每个辊最多只能生产一条带。 该算法处理这个问题是因为条件`pos + h > s`防止任何第二次放置，所以`strips = 1`。 

另一种边缘情况是当壁宽度小于卷宽度时。 那么只需要一个条带，甚至一卷中的单个有效条带就足够了。 天花板划分确保`strips_needed = 1`，无论模拟如何，最终的滚动计数都变为 1。 

当出现第三种边缘情况时`s < h`，但约束保证`h ≤ s`，因此该算法永远不会尝试无效的剪切。
