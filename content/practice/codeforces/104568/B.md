 ## 解决方案
 ## 问题理解

 我们被要求从 N 个候选人中选出恰好 K 个人组成一个委员会。 每个候选人的行为都是独立的，并且每个候选人都有一个已知的投“赞成”票的概率 Pi。 投票结果要么是“是”，要么是“否”，因此每个候选人都是有偏见的抛硬币。 

委员会选定后，所有 K 名成员都投票，我们关心的是最终结果平局的概率，即 K/2 票赞成，K/2 票反对。我们的任务不是分析一个固定的委员会，而是选择包括哪 K 个人，使平局概率尽可能大。 

输入由多个测试用例组成。 对于每一个，我们可以自由选择大小为 K 的任何子集，然后计算由该子集上的独立伯努利变量引起的概率分布。 输出是恰好在 K/2 成功时着陆的最大可能概率。 

这些约束意味着一旦 N 增长，就不可能暴力破解所有子集。 即使对于中等的 N，选择 K 人的方法数量也是组合的，大约为 C(N, K)，对于 N = 200 来说，这会变得天文数字。即使评估单个委员会也需要计算 K+1 可能的投票总数的分布，这已经表明对 K 的二次依赖。这立即排除了任何试图直接枚举委员会的方法。 

朴素推理的一个微妙的失败案例是假设选择概率最接近 0.5 的人总是最优的。 这种直觉在孤立的情况下通常是正确的，但当组合选择非线性相互作用时就会失败。 例如，考虑 K = 2 时的概率 0.49、0.51、0.9、0.1。贪婪地选择最接近 0.5 的两个会得到 0.49 和 0.51，但选择 0.1 和 0.9 会产生概率为 1.0 的确定性平局。 正确的解决方案必须考虑所选概率之间的相互作用，而不仅仅是它们各自的平衡。 

## 方法

 直接方法固定 K 个人的子集，并计算其中 K/2 人投赞成票的概率。 对于固定子集，这是 K 个独立伯努利分布的经典卷积。 每个候选者贡献一个两项多项式，其中 x^0 的系数为 (1 − Pi)，x^1 的系数为 Pi。 将所有 K 个多项式相乘得到一个 K 次多项式，x^(K/2) 处的系数就是平局概率。 

对一个子集的这种计算成本为 O(K^2)，因为每个新人都通过移动和混合概率来更新 DP 分布。 然而，困难在于我们不知道选择哪K个人。 

如果我们暴力破解大小为 K 的所有子集，则需要评估 C(N, K) 种可能性，并且每次评估成本为 O(K^2)，导致指数爆炸，这对于 N 高达 200 的情况是完全不可行的。 

关键的观察是我们不需要以组合方式显式地决定子集。 相反，我们可以使用对项目的动态编程来增量构建它，跟踪我们选择了多少人以及我们可以实现的投票计数分布。 

我们定义了一个 DP 状态，它代表在考虑候选者的某些前缀并准确选择其中 j 个之后可实现的最佳分布。 对于每个 j，我们维护一个包含可能的赞成票数的数组。 当处理概率为 p 的新候选者时，我们决定是否包含它们。 如果我们包含它们，分布会通过与 (1 − p, p) 的卷积发生变化。 如果我们排除它们，我们就会继承之前的状态。 这本质上是一个背包，其中“值”是概率分布而不是标量。 

这将问题从组合子集枚举问题转变为结构化 DP over 选择问题。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 + 每个子集的 DP | O(C(N, K) · K^2) | O(C(N, K) · K^2) | O(K) | 太慢了|
 | DP 超过项目和选择尺寸 | O(N·K^2) | O(N·K^2) | O(K^2) | O(K^2) | 已接受 |

 ## 算法演练

 ### ## 算法演练

 1. 我们创建一个 DP 表，其中 dp[j][t] 表示其中 t 个人投赞成票的最大概率（到目前为止选择 j 个人的所有方式）。 处理完所有候选后，目标是 dp[K][K/2]。 
2. 使用 dp[0][0] = 1 初始化表，这意味着什么都不选择会产生零个赞成票，概率为 1。所有其他状态都从 0 开始，因为它们是不可能的。 
3. 对每个候选人进行一一处理。 对于概率为 p 的候选人，我们考虑是否将其纳入委员会。 
4. 我们以相反的顺序更新选择计数，从 j = K 降至 1。这可以防止覆盖较小的 j 仍然需要的状态，确保每个候选最多使用一次。 
5. 如果我们将候选者包含在大小为 j 的组中，我们使用 dp[j−1] 作为源分布来更新 dp[j]。 对于 dp[j−1] 中每个可能的投票计数 t，我们将其分为两种结果：候选人以概率 p 投赞成票，将计数增加到 t+1，或以概率 (1 − p) 投反对票，将计数保持在 t。 这是构建新分布的卷积步骤。 
6. 处理完所有候选后，我们读取 dp[K][K/2] 作为答案。 

### 为什么它有效

 对于每个可能数量的选定人员 j，DP 使用已处理前缀中大小 j 的任何子集维护投票总数的最佳可实现概率分布。 该转换正确地考虑了投票的独立性并保留了最优性，因为大小为 j 的每个子集都是通过用当前元素扩展大小为 j−1 的子集或跳过它来形成的。 由于每个子集结构在此循环中仅表示一次，因此最终的 dp[K][t] 聚合了所有大小为 K 的有效委员会，并采用 t = K/2 隔离了平局事件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        N, K = map(int, input().split())
        P = list(map(float, input().split()))

        dp = [[0.0] * (K + 1) for _ in range(K + 1)]
        dp[0][0] = 1.0

        for p in P:
            for j in range(K, 0, -1):
                for t in range(j - 1, -1, -1):
                    if dp[j - 1][t] == 0:
                        continue
                    dp[j][t] += dp[j - 1][t] * (1 - p)
                    dp[j][t + 1] += dp[j - 1][t] * p

        ans = dp[K][K // 2]
        print(f"Case #{tc}: {ans:.10f}")

if __name__ == "__main__":
    solve()
```DP 数组的结构使得 dp[j][t] 始终对应于恰好选择了 j 个人并累积了 t 票赞成票。 j 上的反向迭代至关重要，因为正向迭代将允许在一次迭代中多次使用相同的候选者，从而破坏正确性。 

内部转换明确地将概率质量分为“是”和“否”结果，保留总概率质量并确保分布在每个候选之后仍然有效。 

## 工作示例

 考虑 K = 2 的情况，概率为 [0.5, 0.5]。 

处理完第一个候选后，dp[1] 反映了 0 票赞成票的 0.5 概率和 1 票赞成票的 0.5 概率。 添加第二个候选者后，dp[2][1] 累积来自两个（0 是，1 是）转换的贡献。 

| 步骤| 已选择 t | 更新后的 dp[j][t] |
 | --- | --- | --- | --- |
 | 第一个人| 1 | 0 | 0.5 | 0.5
 | 第一个人| 1 | 1 | 0.5 | 0.5
 | 第二人| 2 | 0 | 0.25 | 0.25
 | 第二人| 2 | 1 | 0.50 | 0.50
 | 第二人| 2 | 2 | 0.25 | 0.25

 最终平局概率 dp[2][1] 为 0.5，符合预期的对称性。 

现在考虑 K = 2，概率为 [0.0, 1.0]。 任何有效的委员会都必须包括两人。 第一个总是投“否”，第二个总是投“是”，因此结果确定性是一个“是”和一个“否”。 

| 步骤| 已选择 t | dp[j][t] | dp[j][t] |
 | --- | --- | --- | --- |
 | 两者之后| 2 | 1 | 1.0 |

 这证实了确定性极端情况得到了正确处理，并且当概率为 0 或 1 时，DP 自然地消除了不确定性。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N·K^2) | O(N·K^2) | N 个候选人中的每一个都会更新最多 K 个选择状态，每个状态最多更新 K 个投票计数 |
 | 空间| O(K^2) | O(K^2) | DP 表存储每个选择大小的分布 |

 这些约束允许 K 最大为 200，N 最大为 200，这使得在优化的 Python 中每个测试用例大约 800 万个 DP 转换是可行的。 即使有多达 100 个测试用例，典型的输入也足够稀疏，因此在有效循环下仍处于限制范围内。

 ## 边缘情况

 关键的边缘情况是所有概率均为 0 或 1 时。在这种情况下，DP 不会累积不确定性，并且只有一种投票模式能够幸存。 例如，概率为 0 和 1 的输入 2 2 强制 dp[2][1] = 1，因为每个选择都会产生固定的结果。 DP 转换仍然处理两个分支，但所有概率质量都确定性地流入单个状态。 

另一个微妙的情况是，当 K 相对于 N 较小时，最优选择完全避免了“平均”概率。 DP 正确地处理了这个问题，因为它不假设单调性或局部最优性； 它通过状态传播隐式评估所有子集组合。
