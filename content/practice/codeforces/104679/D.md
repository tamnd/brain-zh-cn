 ## 解决方案
 ## 问题理解

 该游戏是在正整数数组上进行的。 两名玩家轮流进行。 在每一回合中，玩家选择一个素数来除以数组的至少一个元素。 一旦成为素数$p$被选择时，数组中的每个数字都可以被$p$除以$p$同时地。 无法选择任何有效素数的玩家失败。 

关键的困难在于移动不是针对单个元素的局部操作，而是作用于整个数组中所有出现的质因数。 这通过共享素数在元素之间创建耦合，但仅通过它们的指数计数。 

输入是整数列表，输出是单个决策：假设两个玩家都发挥最佳，第一个玩家是否强制获胜。 

约束足够小，独立分解每个数字是可行的。 游戏的直接模拟将重复扫描数组，找到有效的素数，应用除法，然后继续。 这太慢了，因为每次移动都需要完整的数组更新，并且当数字包含重复的质因数时，移动次数可能会很大。 

一些失败的场景出现在天真的想法中。 如果试图通过总是选择最小的素数来贪婪地模拟移动，则结果是不正确的，因为不同素数之间的顺序并不重要。 

例如，考虑数组$[4, 2]$。 幼稚的策略可能会选择素数$2$，但即使使用其他策略，游戏的结构对于每个素数都是独立的，因此排序选择不会影响移动总数。 正确性取决于计算动作，而不是模拟它们。 

另一个微妙的问题是假设素数的每次出现都是独立贡献的。 为了$[4, 8]$，单独计算每个元素会超出素数的移动次数$2$，因为两个元素同时减少。 

## 方法

 直接模拟将阵列视为在每次移动后不断演变。 我们扫描数组中存在的素数，除以所有可整除的元素，然后重复，直到没有素数为止。 每次操作费用$O(n)$，在最坏的情况下，我们可能会执行许多操作，特别是当数字包含重复的小质因数时。 如果值很大，步数可能会达到所有元素的所有指数之和，从而使这种方法不切实际。 

结构见解是不同的素数独立演化。 选择素数$p$只影响指数$p$在每一个数字中； 它不与任何其他素数相互作用。 因此，游戏分解为独立的子游戏，每个素数一个。 

对于固定素数$p$，每次移动都会减少每个非零指数$p$恰好是一。 只要至少有一个数字仍具有正指数，这一移动就有可能$p$。 因此素数贡献的有效步数$p$正好是最大指数$p$遍历数组中的所有数字。 一旦最大值达到零，则没有元素包含$p$，因此游戏无法继续进行该素数。 

将所有素数的贡献相加就得到了整个游戏的总步数。 由于每次移动都会在全局范围内删除某个素数因子的一层，因此素数之间在移动计数方面不存在交互作用。 

获胜者纯粹由总步数的平价决定，因为玩家轮流进行，最后一步决定获胜者。

 ## 算法演练

 我们将游戏重新构建为计算所有素数中存在多少总“素数层移除”。 

1. 将数组中的每个数字分解为素数及其指数。 这隔离了游戏的独立组件。 
2. 对于每个素数$p$，保持所有数组元素中看到的最大指数。 这代表了多少次$p$在完全消失之前仍然可以被选择为有效的举动。 
3. 聚合所有素数的这些最大值。 总和代表游戏中的总步数。 
4. 通过检查总数的奇偶性来确定获胜者。 如果总步数为奇数，则先走最后一步的玩家获胜； 否则第二个玩家获胜。 

关键的推理步骤是我们如何聚合指数。 每次移动都会同时减少素数的所有非零出现，因此限制因素是最大指数，而不是总和。 

### 为什么它有效

 每个素数的行为就像一个高度等于每个元素中其指数的堆栈。 一次移动会从包含该素数的每个堆栈中删除一个级别。 当该素数的最高堆栈达到零时，该过程结束。 由于每次移动都会删除包含该素数的所有堆栈中的一层，因此此类删除的数量等于最大高度。 由于素数不会相互干扰，因此这些过程并行运行，不会改变计数。 因此，总游戏长度是独立堆叠高度的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    maxa = max(arr)

    # smallest prime factor sieve up to maxa
    spf = list(range(maxa + 1))
    for i in range(2, int(maxa ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, maxa + 1, i):
                if spf[j] == j:
                    spf[j] = i

    max_exp = {}

    for x in arr:
        while x > 1:
            p = spf[x]
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            if p in max_exp:
                if cnt > max_exp[p]:
                    max_exp[p] = cnt
            else:
                max_exp[p] = cnt

    total_moves = sum(max_exp.values())

    print("Alice" if total_moves % 2 == 1 else "Bob")

if __name__ == "__main__":
    solve()
```该解决方案首先构建一个最小的素因子筛，以便可以有效地分解每个整数。 这避免了重复试除并确保每个数字在接近对数的时间内分解。 

然后将每个数字分解为质因数。 对于遇到的每个素数，我们计算该数字中的指数并更新存储数组中最大指数的字典。 字典是所有独立素数堆栈的压缩表示。 

最后，将这些最大值相加就得出移动总数。 奇偶校验决定获胜者。 

一个常见的实现陷阱是错误地对所有元素的指数求和，而不是取每个素数的最大值。 这会过多计算移动，因为每次移动中所有出现的素数都会同时减少。 

## 工作示例

 考虑数组$[2, 4]$。 

我们考虑：$2 = 2^1$,$4 = 2^2$。 

| 步骤| 数量 | 总理| 找到指数 | 最大指数图|
 | ---| ---| ---| ---| ---|
 | 1 | 2 | 2 | 1 | {2：1} |
 | 2 | 4 | 2 | 2 | {2：2} |

 总移动次数为$2$。 第一步将两个数字都减少 2，给出$[1, 2]$。 第二步减少剩余的 2，结束游戏。 总数相等，因此第二个玩家获胜。 

现在考虑$[6, 10]$。 

因式分解给出$6 = 2 \cdot 3$,$10 = 2 \cdot 5$。 

| 数量 | 质因数 | 最大指数图更新 |
 | ---| ---| ---|
 | 6 | 2, 3, | 2, 3 {2:1, 3:1} |
 | 10 | 10 2, 5, | 2, 5 {2:1, 3:1, 5:1} |

 总移动次数为$3$。 每个素数只贡献一步。 第一个玩家获胜，因为总数是奇数。 

这些例子表明，素数的作用是独立的，并且答案仅取决于数组中存在多少个不同的素数因子“层”。

 ## 边缘情况

 一个最小数组，例如$[1]$不包含素数，因此移动次数为零，第二个玩家立即获胜。 该算法处理此问题是因为分解循环从不插入任何素数，从而使总和为空。 

像这样的案例$[16]$有一个高指数的素数。 分解收益率$2^4$，因此最大指数为 4。游戏持续 4 步：重复减半直至达到 1。算法通过最大指数 2 直接捕获这一点。 

混合情况如$[8, 9]$独立分离素数 2 和 3。 地图变成$\{2:3, 3:2\}$，产生总移动 5。每个素数独立演化，并且实现正确聚合最大值而不混合贡献。
