 ## 解决方案
 ## 问题理解

 我们得到了两个数字，它们概括了一对未知的正整数。 一个数字代表它们的和，另一个数字代表它们的差，其中差值是第一个减去第二个。 根据这两个值，我们需要重建原始对。 

任务本质上是反转一个简单的线性系统。 我们不是直接给出两个未知整数，而是给出它们的两个组合测量值，并且必须唯一地恢复原始值。 

由于计算纯粹是算术，因此结构上的约束是最小的。 这意味着该解决方案必须在每个测试用例中以恒定的时间运行，因为大范围内的任何循环都将是不必要的开销。 因此，预期的方法应该是直接代数运算。 

重建值的有效性产生了一个微妙的问题。 由于原始整数是正整数，因此计算结果也必须是正整数。 另一个重要的边缘情况是奇偶校验：如果和与差除以二时不产生整数结果，则输入与任何有效整数对不一致。 

例如，如果输入是和 5 和差 2，则重建工作顺利。 但如果输入是和 5 和差 3，则两个重构值都变为非整数，这表明在严格的整数设置中无效。 

## 方法

 强力解释将尝试所有可能的正整数对，并检查哪对与给定的和和差都匹配。 对于每个候选 x 和 y，我们将验证 x + y 是否等于给定的和以及 x − y 是否等于给定的差。 这在概念上是有效的，因为它详尽地搜索了解决方案空间。 

然而，候选对的数量随着总和的大小呈二次方增长。 如果总和约为 10^9，则要检查的对数与该幅度的平方成正比，这在计算上是不可行的。 

关键的观察是这两个方程已经定义了一个线性系统。 我们可以通过消除变量来直接求解未知数，而不是搜索。 将两个方程相加可分离一个变量，将它们相减可分离另一个变量。 这将问题从搜索简化为常数时间算术。 

问题的结构使得这种减少成为可能。 这些约束不会引入任何非线性行为或使反演复杂化的附加条件，因此直接代数可以完全确定解。

 ## 算法演练

 1. 读取两个给定值，这两个值表示按固定顺序排列的未知数之和及其差。 

顺序很重要，因为差异决定了哪个变量更大。 
2. 利用两个方程之间的关系来分离第一个数字。 将和与差相加会取消第二个变量，留下第一个数字的两倍。 
3. 将结果除以二，得到第一个原始数。 仅当输入与整数解一致时，该除法才保证有效。 
4. 通过从总和中减去第一个数字，或者等效地从总和中减去差值并除以二来计算第二个数字。 
5. 输出两个重建值。 

工作原理：系统在二维中定义了一个独特的线性交点。 只要算术除以二产生整数，从原始变量到和与差的变换就是可逆的。 由于加法和减法是线性运算，因此反转它们可以保持一致性并保证重构的对完全满足两个原始方程。

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = input().split()
    S = int(data[0])
    D = int(data[1])

    x = (S + D) // 2
    y = (S - D) // 2

    print(x, y)

if __name__ == "__main__":
    solve()
```该解决方案读取两个输入值并立即应用系统的代数求逆。 表达式 (S + D) 对应于第一个数字的两倍，而 (S − D) 对应于第二个数字的两倍。 使用整数除法是因为该问题保证了重建准确的有效输入。 

一个常见的错误是颠倒符号或交换公式，这会产生看起来正确但不正确的对。 另一个微妙的问题是忘记两个值都必须是整数，但在该问题的标准竞争性编程设置中，构造输入是为了避免小数结果。

| 步骤| 表达 | 价值|
 | --- | --- | --- |

 ## 边缘情况

 一种边缘情况是差值为零。 对于输入 2 和 0，重构产生的两个值相等。 该算法计算 (2 + 0) / 2 = 1 和 (2 − 0) / 2 = 1，生成有效的相同对。 这证实了该方法自然地处理对称性而无需特殊分支。 

另一种情况是当总和很大但差值也很大并且接近总和时。 对于输入 100 和 98，计算得出 x = 99 和 y = 1。算术保持稳定，因为两个表达式仍然生成非负整数，并且减法不会在 Python 中引入溢出或精度问题。 

最后一个边缘情况是奇偶校验一致性。 如果允许假设输入（例如 5 和 2），则公式将生成小数值。 该算法假设输入的构造使得 (S + D) 和 (S − D) 都是偶数，从而确保整数输出。
