 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并且被迫执行一个操作：选择一个位置并翻转该元素的符号。 执行此操作一次后，我们计算整个数组的总和并检查该总和是否为偶数。 任务是计算有多少种不同的翻转位置选择导致最终的总和相等。 

因此输入描述了一个整数列表。 每个选择对应于选择一个索引、否定该值并重新计算总和。 我们不允许跳过操作或翻转多个元素，因此每个候选结果的不同之处仅在于哪个元素的符号相反。 

这种形式的典型 Codeforces 问题所隐含的约束结构表明​​，数组大小可能足够大，以至于从头开始重新计算每个索引的总和会太慢。 二次扫描已经是边界，一旦数组达到大约 10^5 个元素，任何重新计算每个选择的总和的解决方案都立即变得不可行。 

一个可能会导致天真的推理失败的微妙点是假设翻转符号会以某种不平凡的方式改变贡献的平价。 另一个常见的陷阱是试图跟踪在符号翻转下有多少奇数或偶数发生变化，而实际上符号变化根本不影响奇偶性。 这些误解常常导致错误的案例分割。 

## 方法

 直接模拟方法依次考虑每个指标。 对于每个位置 i，我们暂时否定该元素，再次计算整个数组和，并检查它是否为偶数。 这是正确的，因为它明确评估每个允许的操作。 然而，每次重新计算总和都会花费线性时间，并且对每个索引执行此操作会导致二次算法。 对于 n 个元素，这会导致大约 n 个操作，每个操作的成本为 O(n)，总工作量为 O(n^2)，并且对于大输入来说太慢。 

关键的观察来自于理解当单个元素被求反时总和如何变化。 如果原始和是 S，我们翻转 Ai，新的和就变成 S - Ai + (-Ai)，简化为 S - 2Ai。 这个表达式很重要，因为它表明每个候选总和与 S 相差一个偶数，即 2Ai。 由于 2Ai 总是能被 2 整除，因此无论翻转哪个元素，和的奇偶校验都不会改变。 

这完全消除了单独评估每个指标的需要。 我们不需要检查 n 个不同的结果，而只需要检查一次原始和的奇偶性。 如果原始总和是偶数，则每个操作都保持偶数。 如果原始总和是奇数，则每个操作都保留奇数，这意味着没有一个结果有效。 

蛮力之所以有效，是因为它明确遵循问题定义，但它失败了，因为它重新计算了冗余信息。 符号翻转使总和发生偶数变化的观察结果将所有情况折叠成单个全局奇偶校验。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### Optimal idea execution

 1. Compute the sum of all elements in the array. 这给出了每个操作所衍生的基线值 S。 
2. Check whether S is even or odd. 这一信息位决定了每个可能的符号翻转的行为。 
3. 如果 S 是偶数，则得出结论：每个索引都会产生有效的操作，因为每次翻转都保留奇偶校验。 The answer is the total number of elements.
 4. 如果 S 是奇数，则得出结论：没有索引产生有效的运算，因为奇偶校验在允许的变换下是不变的。 答案是零。 

### 为什么它有效

核心不变量是翻转任何单个元素的符号，通过减去 2Ai 来改变总和。 由于 2Ai 始终是偶数，因此在每次允许的操作下，和的奇偶校验保持不变。 这意味着通过一次翻转从原始数组到达的所有状态都共享相同的奇偶校验。 因此，当初始和为偶数时，所有操作都有效，或者当初始和为奇数时，所有操作都无效。 不存在某些指数表现与其他指数不同的中间情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = list(map(int, input().split()))
    n = data[0]
    arr = data[1:]
    
    s = sum(arr)
    if s % 2 == 0:
        print(n)
    else:
        print(0)

if __name__ == "__main__":
    solve()
```该解决方案读取数组，计算一次总和，然后执行一次奇偶校验。 该结构假设输入以单行格式提供，其中 n 后跟数组元素，这在许多简化的 Codeforces 任务中是标准的。 

关键的实现细节是避免任何每个索引的重新计算。 一切仅取决于全局总和，因此决策时不需要除求和之外的循环。

 ## 边缘情况

 具有单个元素的最小数组直接突出了整个逻辑。 如果该值是偶数，则总和也是偶数，并且唯一可能的翻转保留奇偶性，因此答案是 1。 如果该值为奇数，则总和为奇数并且没有翻转会改变奇偶校验，因此答案为零。 

例如，输入：```
1
7
```总和是 7，是奇数。 翻转唯一的元素给出 -7，其奇偶性仍然是奇数，因为变换从和差框架中减去 14。 算法正确输出 0。 

对于全零数组，总和为零，即偶数。 每次翻转仍然使总和的奇偶性保持不变，因此所有指数都是有效的。 该算法输出 n，这符合所有操作都保持均匀性的事实。
