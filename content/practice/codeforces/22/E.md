 ## 解决方案
 ## 问题理解

 每个人都指向另一个人。 如果有人得知这个消息，他们会打电话给他们所指的人，然后这个人再打电话给下一个人，依此类推。 我们可以添加表格的额外有向边`x -> y`, 意思是人`x`还必须致电`y`。 

这一目标比简单地使图从一个起始节点连接起来更强大。 无论谁先得知消息，我们都需要成功的流程。 这意味着从每个节点，必须能够通过有向路径最终到达每个其他节点。 

原始图具有非常特殊的结构：每个节点的出度恰好为一。 这样的图称为函数图。 函数图中的每个连接组件都包含一个有向循环，树馈入该循环。 

我们需要添加最少数量的额外边，以便整个图变得强连接。 

界限`n ≤ 10^5`立即排除任何二次方。 甚至一个`O(n^2)`遍历所有对将执行周围`10^10`最坏的情况下操作，远远超出了时限。 我们需要一个线性或近线性算法。 由于该图已经准确地具有`n`边缘，一个`O(n)`基于 DFS 的解决方案是自然的目标。 

有几种微妙的情况可以打破天真的推理。 

考虑这个图：```
1 -> 2
2 -> 1
3 -> 4
4 -> 3
```输入：```
4
2 1 4 3
```有两个独立的周期。 仅添加一条边，例如`2 -> 3`，还不够。 从节点开始`4`，我们永远无法到达节点`1`或者`2`。 正确的答案需要添加两条边来连接两个方向的循环。 

另一个棘手的情况是当多棵树进入同一个循环时：```
1 -> 2
2 -> 3
3 -> 2
4 -> 3
5 -> 3
```输入：```
5
2 3 2 3 3
```粗心的解决方案可能会尝试连接叶节点。 这失败了，因为叶子是不相关的，障碍来自循环结构。 每条路径最终都会进入同一个循环`{2,3}`，因此只需要一条额外的边，从循环回到树根。 

最危险的边缘情况是图已经形成一个循环时：```
4
2 3 4 1
```该图已经是强连通的。 正确答案是零。 许多实现意外地强制至少添加一条边，因为它们只计算组件而不是检查是否已经存在单个 SCC。 

## 方法

 一种强力方法是根据任意强关联增强来思考。 我们可以计算所有强连通分量，然后反复尝试在它们之间添加边并测试整个图是否变得强连通。 

正确性很简单，因为我们在每次修改后都直接验证属性。 问题是成本。 强大的连接测试本身需要`O(n)`，并且可以有很多候选边。 即使尝试所有 SCC 对也很快就会变成二次方。 

图结构提供了我们可以利用的更强大的属性。 

由于每个节点的出度恰好为 1，因此每个连通分量恰好包含一个有向环。 循环之外的任何节点最终都会流入其中。 一旦进入循环，我们就永远无法离开它，因为每个节点只有一个出边。 

这一观察改变了整个问题。 

唯一真正的障碍是周期本身。 在一个组件内部，所有路径最终都会陷入该组件的循环中。 如果有`k`不同的周期，则图被划分为`k`无法到达彼此的汇区。 

为了使图强连接，我们必须将这些环连接在一起。 一个循环已经可以到达仅以反向方向而不是正向向其馈送的所有树。 重要的节点是传入树的根，特别是函数图中入度为零的节点。 这些都是从其他地方无法到达的地方。 

关键定理是：

 如果有`k`循环，最少添加边数为：

 -`0`什么时候`k = 1`并且不存在入度为零的节点。 
- 否则`max(number_of_cycles, number_of_zero_indegree_nodes)`。 

对于函数图，零入度节点的数量始终最多是连接所有不可访问区域所需的添加边的数量。 

标准结构很优雅：

 - 从每个周期收集一名代表，
 - 收集所有入度为零的节点，
 - 循环连接它们。 

这恰好产生了最少数量的边。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 构建有向图并计算每个节点的入度。 

由于每个节点只有一个出边，因此存储目标数组就足够了。 
2. 找出所有有向环。 

我们以三种状态运行 DFS：

 -`0`表示未访问过，
 -`1`表示当前在递归堆栈中，
 -`2`表示已完全处理。 

当DFS到达已经标记的节点时`1`，我们发现了一个循环。 该节点成为其循环的代表。 
3. 收集所有入度为零的节点。 

这些节点永远无法从它们自己的树外部到达。 在强连接图中，每个节点都必须可从其他每个节点访问，因此每个这样的根都需要至少一个传入的添加边。 
4. 处理已经强关联的情况。 

如果恰好存在一个环并且没有入度为零的节点，则该图已经是一个有向环。 输出`0`。 
5. 将零入度节点与循环匹配。 

让：

-`roots`是入度零节点，
 -`cycles`成为周期代表。 

我们创建边，以便每个根都接收来自另一个组件的连接，并且每个循环都获得传出逃逸路径。 
6. 建立循环连接模式。 

假设我们有：```
roots = [r1, r2, ..., rm]
cycles = [c1, c2, ..., ck]
```我们连接：```
c1 -> r2
c2 -> r3
...
ck -> r1
```小心地包裹索引以较大尺寸为模。 
7. 输出所有构造的边。 

添加的边数等于`max(k, m)`。 

### 为什么它有效

 函数图中的每条路径最终都会进入一个循环。 在增强之前，不同的周期是孤立的汇区。 强大的连接性要求每个周期都可以与其他周期可达。 

该结构将所有循环连接成一个有向环。 一旦路径到达任何循环，它就可以通过添加的边进入每个其他组件。 

零入度节点正是最初没有传入路径的节点。 为每个这样的节点提供一个传入的附加边缘会删除每个无法到达的入口点。 

循环构造保证：

 - 每个组件都可以到达其他每个组件，
 - 每个根接收一个传入路径，
 - 不添加不必要的边缘。 

由于每个周期和每个零度根至少需要一条边，因此下界为`max(k, m)`，并且构造完全实现了它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 25)

n = int(input())
to = [0] + list(map(int, input().split()))

indeg = [0] * (n + 1)

for i in range(1, n + 1):
    indeg[to[i]] += 1

state = [0] * (n + 1)
cycles = []

def dfs(u):
    state[u] = 1

    v = to[u]

    if state[v] == 0:
        dfs(v)
    elif state[v] == 1:
        cycles.append(v)

    state[u] = 2

for i in range(1, n + 1):
    if state[i] == 0:
        dfs(i)

roots = []

for i in range(1, n + 1):
    if indeg[i] == 0:
        roots.append(i)

if len(cycles) == 1 and len(roots) == 0:
    print(0)
    sys.exit()

m = len(roots)
k = len(cycles)

ans = []

t = max(m, k)

for i in range(t):
    a = cycles[i % k]
    b = roots[(i + 1) % m] if m > 0 else cycles[(i + 1) % k]
    ans.append((a, b))

print(len(ans))
for x, y in ans:
    print(x, y)
```DFS 使用经典的递归堆栈方法来检测循环。 由于每个节点只有一个出边，因此每个 DFS 路径本质上是线性的，并且总工作保持线性。 

该行：```
elif state[v] == 1:
    cycles.append(v)
```是关键时刻。 遇到当前递归堆栈内已有的节点意味着我们找到了有向循环。 我们每个周期只存储一个代表节点，因为这就是构建所需的全部。 

入度数组标识传入树的根。 这些是当前无法从其他地方到达的节点。 

特殊情况：```
if len(cycles) == 1 and len(roots) == 0:
```很重要。 具有一个环并且没有零入度节点的函数图本身必须是一个有向环，并且它已经是强连通的。 

循环构造使用模索引，因此它自然地环绕列表。 当没有根时，我们将循环直接相互连接。 

一个常见的错误是试图将根与根连接起来。 这无助于摆脱循环。 边必须源自循环代表，因为只有循环才能保证永远可达。 

## 工作示例

 ### 示例 1

 输入：```
3
3 3 2
```图形：```
1 -> 3
2 -> 3
3 -> 2
```周期为`{2,3}`。 

| 步骤| 周期| 根| 添加边缘 |
 | --- | --- | --- | --- |
 | DFS 之后 | [2] | []| []|
 | 入度扫描后 | [2] | [1] | []|
 | 建筑 | [2] | [1] | (2,1) |

 最终输出：```
1
2 1
```现在：```
1 -> 3 -> 2 -> 1
```所有节点都变得可相互访问。 

此示例说明了为什么零入度节点很重要。 节点`1`从循环中无法到达，因此需要一个传入边缘。 

### 示例 2

 输入：```
4
2 1 4 3
```图形：```
1 <-> 2
3 <-> 4
```| 步骤| 周期| 根| 添加边缘 |
 | --- | --- | --- | --- |
 | DFS 之后 | [1,3]| []| []|
 | 构造迭代 0 | [1,3]| []| (1,3) |
 | 构造迭代 1 | [1,3]| []| (3,1) |

 最终输出：```
2
1 3
3 1
```现在每个周期都可以到达另一个周期。 

该迹线显示了下限。 两个孤立的循环需要至少两个有向边才能在两个方向上实现可达性。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个节点在 DFS 中处理一次，在入度扫描中处理一次 |
 | 空间| O(n) | 用于图、入度、DFS 状态和答案存储的数组 |

 该图准确包含`n`边，因此线性遍历是最佳的。 和`10^5`节点，一个`O(n)`解决方案很容易满足时间限制和内存限制。

 ## 边缘情况

 Consider again the graph with two disconnected cycles:```
4
2 1 4 3
```DFS发现两个周期代表，例如`[1,3]`。 不存在入度为零的节点，因为每个节点已经有一个入边。 

算法输入`m == 0`直接分支并连接循环：```
1 -> 3
3 -> 1
```现在，路径可以在两个原始 SCC 之间双向移动。 

接下来，考虑一张具有一个循环但无法到达树根的图：```
5
2 3 2 3 3
```入度为：```
1: 0
2: 2
3: 3
4: 0
5: 0
```根是`[1,4,5]`。 比如说，只有一个周期代表`[2]`。 

该算法添加：```
2 -> 4
2 -> 5
2 -> 1
```现在每个根都有一条来自循环的传入路径，并且每个节点最终都可以通过原始边返回到循环。 

最后，考虑已经正确的情况：```
4
2 3 4 1
```存在一个循环并且没有零入度节点。 该算法立即输出零。 

如果没有这种检查，许多实现会意外地添加冗余边缘并破坏极简性。
