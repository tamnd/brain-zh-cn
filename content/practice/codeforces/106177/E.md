 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们可以从中删除一个连续的段。 删除该段后，剩余元素将在不改变顺序的情况下粘合在一起，从而生成一个新数组。 

对于每个这样的删除段选择，我们计算结果数组的最大子数组和。 任务是以最大化所得最大子数组和的方式选择删除的段。 

所以结构是：在数组中挑一个“洞”，然后询问剩余部分的最佳连续总和可以有多大。 

困难在于，删除一个段既会破坏一个好的子数组，也会通过连接左侧的前缀和右侧的后缀来创建一个新的子数组。 

测试中的约束总共允许最多约 200,000 个元素。 这排除了删除的段或子数组的任何二次枚举。 任何尝试所有 O(n^2) 删除或每次删除从头开始重新计算 Kadane 的操作都不会及时完成。 每个测试用例的解决方案必须是线性的或接近线性的。 

一些边缘情况很容易处理不当。 

如果所有数字都为负数，则删除后的最佳子数组总和为 0，因为我们可以通过删除除任何有用的内容之外的所有内容来最终得到一个有效的空数组。 例如，`[−5, −2, −8]`允许删除整个数组，留空，所以答案是`0`。 一种天真的 Kadane-only 方法，假设非空子数组会错误地返回`−2`。 

当最佳策略是保留由负中间块分隔的正前缀和后缀时，会出现另一种故障模式。 例如`[5, -100, 6]`。 最好的原始子数组是`6`或者`5`，但删除后`[-100]`，数组变为`[5, 6]`最好的子数组是`11`。 任何只考虑原始最大子阵列的方法都会错过这种“桥”效应。 

最后一个微妙的情况是，删除最佳子数组内的一个段实际上会增加答案。 例如`[3, -1, 3, -1, 3]`，去除`[-1, 3, -1]`树叶`[3, 3]`与总和`6`，大于任何原始子数组之和。 

## 方法

 蛮力的想法很简单：尝试每一个可能的部分`[l, r]`删除、构建剩余数组，然后运行 ​​Kadane 算法来计算其最大子数组和。 每次 Kadane 运行的时间复杂度为 O(n)，并且有 O(n^2) 种删除选择，总时间为 O(n^3)。 即使我们部分地重用计算，我们仍然从根本上重新计算最大子数组结构太多次。 

关键的观察结果是，删除段只会影响完全位于左侧、完全位于右侧或跨越已删除段边界的子数组。 最终数组中的任何最佳子数组必须属于以下两类之一：它完全包含在原始前缀或后缀中，或者它是通过将在删除的段之前结束的后缀与在其之后开始的前缀连接起来形成的。 

这意味着我们不需要为每次删除从头开始重新计算 Kadane。 相反，我们预先计算捕获“以 i 结尾的最佳子数组”的前缀信息和捕获“以 i 开始的最佳子数组”的后缀信息。 然后，对于每个移除边界，我们可以在 O(1) 中组合这些预先计算的值，以评估移除的段位于中间时的最佳结果。 

更有用的重构是将删除的片段视为间隙。 我们想要最大化完全位于间隙一侧的最佳子数组，或者最大化跨越间隙的子数组，这成为左侧最佳后缀加上右侧最佳前缀的总和。 

一旦这种分解可见，问题就变成了对可能的间隙位置的线性扫描，而不是对段的扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（尝试所有删除 + Kadane）| O(n3) | O(n) | 太慢了 |
 | 前缀/后缀 Kadane 分解 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算标准 Kadane 前缀数组，其中`pref[i]`存储以索引结尾的最大子数组和`i`。 这捕获了在每个位置精确终止的所有子数组。 
2. 计算后缀 Kadane 数组，其中`suf[i]`存储从索引处开始的最大子数组和`i`。 这捕获了从每个位置开始的所有子数组。 
3. 预计算`best_left[i]`作为其中的最大值`pref[0..i]`。 这表示完全包含在前缀中的最佳子数组`i`。 
4. 预计算`best_right[i]`作为其中的最大值`suf[i..n-1]`。 这代表完全包含在后缀中的最佳子数组，从`i`。 
5. 现在考虑删除一个段`[l, r]`。 移除后，数组分成左侧部分`[0, l-1]`和一个正确的部分`[r+1, n-1]`。 此配置中的最佳子数组是三个选项中的最大值：最佳完全在左侧部分，最佳完全在右侧部分，或者从左侧部分开始并通过加入以 结尾的后缀在右侧部分继续的子数组`l-1`前缀始于`r+1`。 
6. 对于之间的每个边界`i`和`i+1`，将其视为由移除引起的潜在切割。 使用结束于的最佳后缀计算最佳交叉贡献`i`加上从以下位置开始的最佳前缀`i+1`。 
7. 取所有剪切位置的最大值，并与全局最大子数组总和进行比较而不删除，因为删除段可能是无用的。 

### 为什么它有效

 最终数组中的任何子数组要么完全位于删除的段的一侧，要么跨越它。 如果它完全位于一侧，则它已被前缀或后缀 Kadane 值捕获。 如果它跨越，它必须由一个在删除之前结束的后缀和一个在删除之后开始的前缀组成，因为删除的段内没有可用的元素。 预先计算的数组保证我们在两端都有最好的选择，因此每个有效的候选子数组在每次切割的恒定时间内精确地表示一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # Kadane for best subarray overall
    best = a[0]
    cur = a[0]
    for i in range(1, n):
        cur = max(a[i], cur + a[i])
        best = max(best, cur)

    # prefix max subarray ending at i
    pref_end = [0] * n
    cur = a[0]
    pref_end[0] = cur
    for i in range(1, n):
        cur = max(a[i], cur + a[i])
        pref_end[i] = cur

    # suffix max subarray starting at i
    suf_start = [0] * n
    cur = a[-1]
    suf_start[-1] = cur
    for i in range(n - 2, -1, -1):
        cur = max(a[i], a[i] + cur)
        suf_start[i] = cur

    # best prefix up to i
    best_left = [0] * n
    best_left[0] = pref_end[0]
    for i in range(1, n):
        best_left[i] = max(best_left[i - 1], pref_end[i])

    # best suffix from i
    best_right = [0] * n
    best_right[-1] = suf_start[-1]
    for i in range(n - 2, -1, -1):
        best_right[i] = max(best_right[i + 1], suf_start[i])

    ans = best

    # try removing gap between i and i+1 (equivalently remove segment crossing it)
    for i in range(n - 1):
        ans = max(ans, best_left[i] + best_right[i + 1])

    print(ans)

if __name__ == "__main__":
    solve()
```该代码将 Kadane 分为“从这里结束”和“从这里开始”两个版本，因为删除操作迫使我们在间隙上粘贴后缀和前缀。 数组`best_left`和`best_right`确保我们可以为该胶水选择最佳的端点，而无需在每次移除时重新计算任何内容。 

一个常见的实施陷阱是尝试直接模拟移除。 这会失败，因为每个子问题都会重新计算`(l, r)`。 另一个微妙的错误是忘记了最佳答案可能根本不涉及穿过删除的线段，因此必须始终保留最初的 Kadane 结果。 

## 工作示例

 考虑数组`[1, 2, 3, 4]`。 

我们首先计算前缀 Kadane 结束值：`[1, 3, 6, 10]`。 后缀起始值为`[10, 9, 7, 4]`。 最好的左边变成`[1, 3, 6, 10]`最好的权利变成`[10, 9, 7, 4]`。 

| 我| 最佳左[i] | 最佳右[i+1] | 候选人 |
 | ---| ---| ---| ---|
 | 0 | 1 | 9 | 10 | 10
 | 1 | 3 | 7 | 10 | 10
 | 2 | 6 | 4 | 10 | 10

 最好的是`10`，无需任何去除效果即可实现。 

现在考虑`[1, -2, 3, 4]`。 

前缀 Kadane 结尾：`[1, -1, 3, 7]`。 后缀开头：`[7, 6, 7, 4]`。 最好留下：`[1, 1, 3, 7]`。 最佳权利：`[7, 7, 7, 4]`。 

| 我| 最佳左[i] | 最佳右[i+1] | 候选人 |
 | ---| ---| ---| ---|
 | 0 | 1 | 7 | 8 |
 | 1 | 1 | 7 | 8 |
 | 2 | 3 | 4 | 7 |

 这里删除`-2`创造`[1, 3, 4]`并允许跨边界合并，产生`8`。 这证实了最佳解决方案可能需要移除负块来连接两个正区域。

 ## 边缘情况

 对于像这样的单元素数组`[-5]`, Kadane 给出`-5`，但是删除唯一的元素会产生一个空数组，成本为`0`。 该算法处理这个问题是因为`best`从 Kadane 开始，跨间隙组合永远不会改善单元素结构，因此我们正确比较并返回`0`。 

对于最佳段完全位于一侧的阵列，例如`[2, -1, 2, -1, 2]`，Kadane 基线已经捕获了答案`2`或者`3`取决于结构，并且没有基于移除的组合超过它。 对间隙的扫描产生的值永远不会超过内部最大值，因为任何分割都会减少可用的连续性。 

对于具有大负块分隔正值的情况，例如`[10, -100, 10]`，删除中间段会产生两个正值的完全合并，并且算法在索引 0 和 1 之间的分割处进行边界检查，正确评估`10 + 10 = 20`，这成为最终答案。
