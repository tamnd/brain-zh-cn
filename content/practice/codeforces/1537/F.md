 ## 问题理解

 我们给出一个无向连通图，其中每个节点都有一个初始值和一个目标值。 我们可以选择任何边并将相同的整数添加到两个端点。 任务是确定是否存在一系列这样的操作，将每个节点的初始值转换为其目标值。 

每个测试用例指定节点和边的数量、初始值数组、目标值数组和边列表。 如果转换可能，则输出为“是”，否则输出为“否”。 

问题约束允许所有测试用例累积最多 200,000 个节点和边，因此每个测试用例的线性或线性复杂度低于线性或线性算术复杂度的任何算法都会超时。 尝试每种可能的操作的简单模拟是不可行的，因为每条边的整数操作数量是无限的。 

当所有节点的差异总和为奇数时，就会出现需要注意的边缘情况。 例如，如果有两个节点由初始值 [1, 1] 和目标值 [2, 3] 的边连接，则总差为 3。由于每个操作同时递增两个节点，因此增量之和必须是偶数。 任何试图在不检查奇偶性的情况下贪婪地添加值的幼稚方法都会错误地表明存在解决方案。 另一个微妙的情况出现在二分图中。 如果可以将图着色为两个集合，则操作对集合之间的奇偶性影响会有所不同，这可能会使某些转换变得不可能。 

## 方法

 暴力方法是模拟所有操作序列，沿边缘添加任意整数。 虽然这在原则上是正确的，但在计算上是不可能的，因为要添加的整数有无限多种选择，并且序列的数量随着边的数量呈指数增长。 即使限制为最少的操作也不能有效地减少搜索空间。 

关键的见解是关注**目标值和初始值之间的差异**。 让`delta[i] = t[i] - v[i]`。 每个边上的操作`(u, v)`添加`k`对双方`delta[u]`和`delta[v]`。 全部的总和`delta[i]`变化由`2*k`每次操作，因此模 2 的差值总和是不变的。 因此，解的必要条件是差之和为偶数。 

第二个见解涉及图结构。 如果图是**非二分图**，我们总是可以找到操作序列来在节点之间任意分配任何偶数总和。 如果图是二分图，则边上的操作仅连接不同分区中的节点，因此每个分区内的差值和必须具有相同的奇偶校验。 具体来说，总和为`delta[i]`一个分区中的总和减去另一分区中的总和必须是偶数。 

使用这些观察结果，我们可以将问题简化为检查：差异总和是否为偶数，以及如果图是二分图，则分区和是否满足奇偶约束。 这将解决方案简化为简单的基于 DFS 的着色加上总和检查，该解决方案以相对于节点和边的线性时间运行。

 ## 算法演练

 1. 计算差异`delta[i] = t[i] - v[i]`对于每个节点。 这表示必须添加到每个节点的总价值。 
2.检查总和`delta`。 如果是奇数，则立即返回NO，因为每次操作都会将总和更改为偶数。 
3. 尝试使用 DFS 对图进行双色以检测二分性。 将颜色 0 分配给起始节点并为相邻节点分配替代颜色。 如果检测到冲突（连接相同颜色的两个节点的边），则该图是非二分图。 
4. 如果图是非二分图，并且总和是偶数，则返回 YES。 任何均匀的差异分布都是可能的。 
5. 如果该图是二分图，则计算`delta`每个分区中的值。 检查分区总和之间的差异是否为偶数。 如果是，则返回YES； 否则，返回NO。 
6. 对每个测试用例重复此操作。 

**为什么有效**：非二分图允许奇数长度的循环，这可用于在节点之间传播任意整数变化。 二分图缺乏这样的循环，这限制了分区之间的奇偶性。 每个操作将总和更改为偶数的不变性以及跨分区的奇偶校验约束保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        v = list(map(int, input().split()))
        tvals = list(map(int, input().split()))
        delta = [tvals[i] - v[i] for i in range(n)]
        adj = [[] for _ in range(n)]
        for _ in range(m):
            a, b = map(int, input().split())
            adj[a-1].append(b-1)
            adj[b-1].append(a-1)

        color = [-1]*n
        is_bipartite = True
        part_sum = [0, 0]

        def dfs(u, c):
            nonlocal is_bipartite
            color[u] = c
            part_sum[c] += delta[u]
            for vtx in adj[u]:
                if color[vtx] == -1:
                    dfs(vtx, c^1)
                elif color[vtx] == color[u]:
                    is_bipartite = False

        dfs(0, 0)
        total = sum(delta)
        if total % 2 != 0:
            print("NO")
        elif not is_bipartite:
            print("YES")
        elif (part_sum[0] - part_sum[1]) % 2 == 0:
            print("YES")
        else:
            print("NO")

solve()
```该代码读取输入、计算差异并执行 DFS 以确定二分性，同时对每个分区的差异进行求和。 二部图的奇偶条件和总和的检查完全按照说明进行。
