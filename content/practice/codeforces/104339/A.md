 ## 解决方案
 ## 问题理解

 每个国王都指挥一支军队，分成相同的军团。 大麦有$a$团，每个团包含$x$士兵，所以他的军队总规模是$a \cdot x$。 啤酒花和麦芽的描述方式相同，使用$b \cdot y$和$c \cdot z$。 

任务不是对所有三支军队进行排名，而是找到其中最大的军队总规模，然后列出军队符合该最大规模的每个国王。 输出必须包含所有此类国王的名字，并且这些名字必须按字典顺序打印。 

约束足够小，直接算术就足够了。 每个值最多为$10^3$，所以每支军队的总规模最多为$10^6$。 即使我们多次重新计算所有内容，成本也可以忽略不计。 这使得每个测试用例的解决方案都在恒定的时间内得到解决。 

唯一的微妙之处来自平等案例。 如果一个国王严格更大，则很容易错误地打印单个国王，但该问题明确要求收集所有与最大值并列的国王。 另一个可能的错误是忘记了名字的字典顺序，这只有在多个国王符合资格时才重要。 

具体的边缘情况是所有三支军队均势时，例如：

 输入：```
2 2 2 3 3 3
```所有总计为$6$，所以正确的输出是：```
Barley Hops Malt
```一种天真的“选择最大值并打印一个名称”的方法在这里会失败。 

另一个边缘情况是当两个国王并列最大时：

 输入：```
2 3 3 6 3 4
```总计为大麦$12$, 啤酒花$9$, 麦芽$12$，因此必须打印大麦和麦芽。 

## 方法

 暴力解释将独立计算每支军队的规模，然后重复扫描结果以确定哪个是最大的。 由于只有三个值，即使是过于复杂的方法在复杂性上仍然微不足道，但可以想象将这种模式扩展到许多国王，而重复扫描会变得昂贵。 

在这个问题中，结构足够简单，不需要迭代细化。 我们计算一次三个乘积，对它们进行一次比较，然后选择等于最大值的所有条目。 关键的观察结果是“决策集”非常小并且大小固定，因此不需要排序或多次传递。 

蛮力的想法之所以有效，是因为它直接评估所有候选人。 它变得不必要并不是因为效率低下，而是因为没有可利用的组合结构，数据集是固定大小且完全独立的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 通过扫描直接评估 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 最优直接比较| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算每个国王的军队总规模：$A = a \cdot x$,$B = b \cdot y$， 和$C = c \cdot z$。 这会将来自团结构的输入转换为可比较的标量值。 
2. 确定其中的最大值$A$,$B$， 和$C$。 这代表着最强的军队规模。 
3. 初始化一个空的获奖者名单。 对于每个国王，检查其总数是否等于最大值。 如果是这样，请注明他们的名字。 这确保了关系得以保留。 
4. 按字典顺序输出选定的名称。 由于名称是固定字符串，因此这会减少“Barley”、“Hops”和“Malt”之间的排序。 

### 为什么它有效

 每个国王的力量都通过一次标量乘法完全捕获。 军队的比较简化为比较这些标量，并且与最大值相等可以正确识别所有最强的军队。 由于每个国王都会根据相同的参考值进行独立检查，因此不会遗漏或错误添加任何获胜者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c, x, y, z = map(int, input().split())

    barley = a * x
    hops = b * y
    malt = c * z

    mx = max(barley, hops, malt)

    ans = []
    if barley == mx:
        ans.append("Barley")
    if hops == mx:
        ans.append("Hops")
    if malt == mx:
        ans.append("Malt")

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```该解决方案首先将每个国王的军团转换为总数。 然后它找到三个计算值中的最大值。 当且仅当计算出的总数与该最大值匹配时，才会有条件地附加每个国王的名字。 检查的顺序在字典顺序上已经是正确的，因为“Barley”位于“Hops”和“Malt”之前，因此不需要额外的排序。

 ## 边缘情况

 当所有三支军队相等时，该算法仍然正确地包括每个国王，因为每次比较都会根据相同的最大值检查相等性。 对于输入：```
3 3 3 3 3 3
```计算出的总数均为 9，因此最大值为 9，并且所有三个条件检查都成功，以正确的顺序生成所有名称。 

当正好有两支军队并列最大时，例如：```
2 3 3 6 3 4
```大麦和麦芽的得分均为 12，而啤酒花的得分较小。 最大值为 12，因此仅附加这两个。 该算法不依赖于国王之间的严格排序，只依赖于全局最大值的平等，这确保了无论关系如何分配的正确性。
