 ## 解决方案
 ## 问题理解

 给定一个大的等边三角形网格，通过细分边长的大三角形而形成$n$分成单位等边三角形。 结构是标准的三角格子：大三角形的每条边都包含$n$单位段，内部充满规则排列的向上和向下的单位三角形。 

任务是计算该图中存在多少个不同的三角形。 如果三角形出现在网格中的任何位置，则无论其大小或方向如何，该三角形都会被计数。 如果两个三角形的位置或大小不同，即使它们在几何上全等，也被认为是不同的。 

输入是单个整数$n$，它控制三角形网格的大小。 输出是一个整数，表示结构内所有可能大小和方向的三角形总数。 

约束条件$n \le 10^4$立即排除任何直接枚举三角形的方法。 即使是适度谨慎$O(n^3)$或者$O(n^2)$几何枚举会太慢，因为候选子结构的数量大致随着三角晶格中三元组或子区域的数量而增长，而三角晶格本身的数量级为$n^2$细胞。 

一个微妙的边缘情况是$n = 1$，其中该图形恰好由一个单位三角形组成。 答案很简单，就是 1，因为只有一个三角形并且不存在更大的构型。 

另一个极端情况很小$n$， 例如$n = 2$，其中同时存在小单位三角形和一个较大的三角形。 手动计数在这里很容易，但也强调三角形出现在两个方向，并且较大的三角形重叠多个单位单元。 

## 方法

 蛮力方法将尝试枚举三角网格中所有可能的三元组，并检查它们是否形成与网格对齐的有效等边三角形。 每条边的长度和方向都需要根据网格结构进行验证。 即使限制于晶格对齐的三角形，候选顶点对的数量也已经是$O(n^4)$在最坏的情况下，因为有$O(n^2)$晶格点并选择三个点会产生三次或更糟的爆炸。 这不适用于$n = 10^4$。 

一种更结构化的方法是停止从任意几何角度思考，而是使用三角形网格的组合结构。 图中的每个三角形都以三个方向之一轴对齐：向上、向下或旋转版本，具体取决于解释。 关键的观察是，任何有效的三角形都是通过选择顶顶点和边长，然后检查它是否适合边界来完全确定的。 

这将问题转化为计算每个可能边长存在多少个三角形。 对于固定边长$k$，向上三角形适合的位置数是二次函数$n-k$，因为水平和垂直放置都随着线性收缩$k$。 这同样适用于向下三角形，但它们的有效位置略有不同，因为向下三角形仅存在于晶格的某些子层中。 

基本的见解是，我们不是单独枚举三角形，而是对所有可能的边长进行求和$k$，并且对于每个$k$，使用从三角形分层导出的算术公式计算存在多少个有效位置。 这将问题简化为封闭式求和$k$，产生$O(n)$甚至$O(1)$解取决于代数简化。 

最终的解决方案使用已知的三角网格结构：大小为 的三角网格中三角形的总数$n$是一个三次多项式$n$，通过对所有方向和大小的贡献求和得出。

 ## 算法演练

 1. 将网格视为由按水平容量先增加后减少的行排列的单位三角形组成。 这使我们能够根据层而不是坐标进行推理。 该结构确保每个较大的三角形对应于这些层的连续选择。 
2. 固定三角形边长$k$。 我们计算有多少个这个大小的三角形。 对于面朝上的三角形，顶部顶点必须位于至少有$k-1$它下面的行。 当我们向下移动时，可用的水平位置也会线性缩小。 
3. 导出大小向上的三角形的数量$k$作为二次函数$n-k+1$。 有效放置的数量形成三角形数字结构，因为每一行允许的起始位置比前一行少。 
4. 对朝下的三角形重复相同的推理。 这些是有效的倒置版本，占据了晶格中的间隙，并且它们的计数遵循类似的二次模式，但索引发生了变化。 
5. 对所有可能的边长求和$k$从 1 到$n$。 每个贡献都是一个多项式$k$和$n$，因此总和减少为封闭式总和$k$,$k^2$和常数。 
6. 将结果表达式简化为三次多项式$n$。 这完全消除了迭代的需要。 

### 为什么它有效

 网格中的每个三角形都由其方向、边长和最上面的顶点唯一确定。 点阵结构确保可行性仅取决于沿两个轴的线性约束，这使得计数可分为每层的独立贡献。 由于这些约束是线性的，因此对所有有效布局求和会产生多项式增长，并且在已以闭合形式捕获的端点之外不会留下任何不规则边界效应。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    if n == 1:
        print(1)
        return

    # Closed-form result for number of all triangles in triangular grid
    # derived from summing all orientations and sizes
    res = (n * (n + 2) * (2 * n + 1)) // 8
    print(res)

if __name__ == "__main__":
    solve()
```该代码直接计算封闭式表达式，而不是迭代三角形大小。 条件为$n = 1$对于公式的正确性来说并不是严格必要的，但它使边界行为明确并避免在退化情况下依赖代数取消。 

使用的公式对应于将三角晶格中的三角形标准分解为向上和向下贡献，每个贡献在有效位置上贡献二次和。 最终表达式被简化为除以常数因子的三次多项式。

 ## 边缘情况

 对于$n = 1$，网格仅包含一个单位三角形。 该算法计算$(1 \cdot 3 \cdot 3)/8 = 9/8$，它作为整数结果无效，因此我们显式返回 1。这说明了为什么必须在边界处小心应用封闭形式，而不是盲目信任代数简化。 

为了$n = 2$，该结构恰好包含一个较大的三角形加上多个单位三角形。 公式给出 5，匹配分解：三个向上的单位三角形，一个向下的单位三角形，以及一个跨越整个形状的大三角形。 这证实了多项式中考虑了两个方向。
