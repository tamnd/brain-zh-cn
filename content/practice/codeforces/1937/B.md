 ## 解决方案
 ## 问题理解

 我们有一个恰好有两行的网格`n`列。 每个细胞都包含`0`或者`1`。 

路径始终从左上角的单元格开始，到右下角的单元格结束。 由于只有两行并且移动仅限于向右和向下，因此每条有效路径都具有非常简单的形状。 我们沿着顶行向右移动一定数量的列，向下精确移动一次，然后继续沿着底行向右移动直到结束。 

每条路径都精确访问`n + 1`细胞。 读取写入这些单元中的位会产生一个长度为二进制的字符串`n + 1`。 

在所有可能的路径中，我们必须找到字典顺序最小的结果字符串。 之后，我们必须计算有多少条不同的路径恰好产生了那个最小的字符串。 

约束是关键的观察结果。 所有的总和`n`值最多是`2 · 10^5`，因此每个测试用例都是线性或接近线性的算法很容易足够快。 任何将所有路径与所有其他路径进行比较的方法都会变得过于昂贵，因为`n`可能发生向下移动的地方。 

最危险的边缘情况来自关系。 

考虑：```
n = 2
top    = 00
bottom = 00
```两种可能的路径都会产生`"000"`。```
Path down at column 1: 000
Path down at column 2: 000
```答案是：```
000
2
```仅找到一个最佳切换点的解决方案将错过第二条路径。 

另一个微妙的情况是第一个不同的位置出现得很晚。```
n = 4
top    = 0011
bottom = 1110
```可能的字符串有：```
01110
00110
00110
00111
```最小的字符串是`"00110"`，它是由两个不同的切换位置产生的。 计数需要准确理解相等前缀出现的位置。 

当每个候选字符串都相同时，就会出现最后一个极端情况。```
n = 3
top    = 000
bottom = 000
```每条路都给予`"0000"`，因此计数等于可能的向下位置的数量，即`3`。 

贪心构造仍然必须正确计算所有最佳路径。 

## 方法

 暴力解决方案很简单。 

如果我们在列处从顶行切换到底行`k`，生成的字符串是：```
top[0..k] + bottom[k..n-1]
```有`n`的可能值`k`。 我们可以显式构造所有`n`字符串，找到最小的一个，并计算它出现的次数。 

每个字符串都有长度`n + 1`，因此构建所有候选者的成本`O(n²)`时间。 

为了`n = 2 · 10^5`，这大约需要`4 · 10^10`最坏情况下的字符操作，这是完全不可行的。 

网格的结构提供了更好的路线。 

每条路径恰好对应一个开关列。 生成的字符串是：```
top prefix + bottom suffix
```假设我们当前在列`i`。 

如果`top[i + 1] < bottom[i]`，然后在顶行再多一步，立即在最终字符串的下一个位置放置一个较小的位。 任何较早切换的路径按字典顺序都会变得更糟。 

如果`top[i + 1] > bottom[i]`，那么现在切换更好。 

这两个选择完全不同的第一个位置决定了最佳切换位置。 这提供了构造最小字符串的贪婪方法。 

找到最佳切换列后，计算最佳路径就成为一个单独的问题。 每条最优路径必须生成完全相同的最小字符串。 

生成的最小字符串具有顶行前缀，后跟底行后缀。 仅当重叠区域满足顶行和底行单元之间的一系列相等性时，任何其他切换位置才会产生相同的字符串。 这可以通过围绕最佳切换点进行扩展来计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n²) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 ### 查找字典顺序最小的字符串

 设顶行为`a`最下面一行是`b`。 

在列处切换的路径`k`产生：```
a[0] a[1] ... a[k] b[k] b[k+1] ... b[n-1]
```我们搜索第一列，其中切换比继续更好。 

1. 从列开始`0`。 
2. 对于每一列`i`从`0`到`n-2`， 比较`a[i+1]`和`b[i]`。 
3.如果`a[i+1] == b[i]`，这两种选择都尚未产生词典编排优势，因此继续。 
4. 如果`a[i+1] < b[i]`，留在顶排更好。 继续寻找。 
5. 如果`a[i+1] > b[i]`，立即切换更好。 最优切换列为`i`，然后我们停下来。 
6. 如果不存在这样的列，则最优切换列为`n-1`。 
7. 将最小字符串构造为：```
a[:k+1] + b[k:]
```在哪里`k`是所选的切换列。 

### 计算最佳路径

 让`k`成为最佳切换柱。 

生成相同最小字符串的每个路径都必须保留该字符串的每个字符。 

假设另一条路径在列处切换`j`。 

为了使生成的字符串匹配，每个重叠位置必须满足：```
a[t] = b[t-1]
```对于之间的所有列`j+1`和`k`。 

这意味着我们需要周围最长的连续块`k`这些等式成立的地方。 

1. 初始化答案`1`，对应于最佳切换点本身。 
2. 向左移动`k`尽管：```
a[pos] == b[pos-1]
```每个成功的步骤都会添加另一个有效的切换位置。 

1. 有效位置的总数等于该匹配段的长度。 

等效的实现是：```
count = 1
pos = k
while pos > 0 and a[pos] == b[pos-1]:
    count += 1
    pos -= 1
```### 为什么它有效

 字典顺序由两个候选字符串不同的第一个位置确定。 在列`i`，选择是放置`a[i+1]`通过留在顶行或放置到字符串中`b[i]`现在就切换。 这些位不同的第一次比较完全确定了哪个路径族按字典顺序更小。 任何后面的字符都变得无关紧要。 

一旦确定了最佳切换点，只有在跨列移动开关不会改变任何字符的情况下，另一个切换点才能产生相同的字符串。 当新公开的顶行字符等于相应的底行字符时，将开关移动一列可以准确地保留字符串。 重复此条件可以表征所有最佳切换位置，因此对连续匹配区域进行计数可以得出最佳路径的准确数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()

        k = n - 1

        for i in range(n - 1):
            if a[i + 1] > b[i]:
                k = i
                break

        best = a[:k + 1] + b[k:]

        cnt = 1
        pos = k
        while pos > 0 and a[pos] == b[pos - 1]:
            cnt += 1
            pos -= 1

        out.append(best)
        out.append(str(cnt))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个循环确定最佳切换列。 我们从左到右扫描，因为字典顺序取决于最早的不同位置。 

当我们遇到`a[i+1] > b[i]`，切换立即在任何路径可能不同的第一个位置产生一个较小的位。 后来的决定无法弥补这种损失，因此最佳开关位置是固定的。 

然后直接从相应的顶部前缀和底部后缀构造最小字符串。 

为了计数，我们从所选的切换列向左移动。 每次`a[pos] == b[pos-1]`，将切换点提前一列，使生成的字符串保持不变。 一旦这种相等性失败，生成的字符串就会发生变化，因此其他位置都不再有效。 

计数循环中的索引是发生差一错误的主要地方。 等式使用`a[pos]`和`b[pos-1]`因为这些正是开关向左移动一列时交换的两个字符。

 ## 边缘情况

 ### 所有路径产生相同的字符串

 输入：```
1
3
000
000
```每个开关位置都会生成：```
0000
```贪婪扫描永远找不到一个位置`a[i+1] > b[i]`， 所以`k = 2`。 

计数循环检查：```
a[2] = b[1] = 0
a[1] = b[0] = 0
```两者匹配，产生：```
count = 3
```这等于有效开关位置的数量。 

### 最佳切换立即发生

 输入：```
1
4
1111
0000
```第一次比较时：```
a[1] = 1
b[0] = 0
```现在切换确实更好，所以`k = 0`。 

结果字符串是：```
1 + 0000 = 10000
```计数循环无法向左移动，因此答案计数保持不变`1`。 

### 最优切换之前的长等式链

 输入：```
1
5
00111
11110
```扫描到最后一次比较才发现：```
a[4] = 1
b[3] = 1
```并最终在最后切换。 

几个相邻的等式满足：```
a[pos] = b[pos-1]
```允许开关位置向左滑动而不改变产生的琴弦。 

计数循环正确地累积每个这样的位置并返回最佳路径的完整数量。
