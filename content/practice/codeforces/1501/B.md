 ## 解决方案
 ## 问题理解

 我们一层一层地制作蛋糕。 放置后`i`第-层，我们倒`a[i]`单位的奶油放在上面。 奶油向下扩散并覆盖顶部`a[i]`当前存在的层。 如果少于`a[i]`层，每个现有层都会被覆盖。 

对于每一层，我们必须决定它是否被至少一个奶油操作覆盖。 输出是一个由 0 和 1 组成的数组，从下到上排序。 值为`1`意味着该层被浸透，而`0`意味着它保持干燥。 

所有测试用例的总层数最多为`2·10^5`，对于线性解来说足够小，但对于二次解来说太大了。 检查每次浇注操作的每个受影响层的方法可能需要大约`n²`在最坏的情况下工作。 和`n = 2·10^5`，这意味着大约四百亿次操作，这远远超出了时间限制。 

有几种情况很容易处理不当。 

一种情况是奶油的量超过现有层的数量。 

输入：```
1
4
5 0 0 0
```第一个操作已经覆盖了所有现有层，所以答案是```
1 0 0 0
```尝试访问底部以下层的粗心实现可能会产生无效索引。 

另一个棘手的情况来自重叠的间隔。 

输入：```
1
6
0 3 0 0 1 3
```正确答案是```
1 1 0 1 1 1
```多次奶油操作会重复覆盖某些层，但一层只需覆盖一次。 独立模拟每个操作会浪费时间。 

第三种情况是没有倒奶油的时候。 

输入：```
1
3
0 0 0
```答案是```
0 0 0
```如果我们在应该结束后错误地传播先前的覆盖范围，则某些层可能会被标记为覆盖，即使没有操作到达它们。 

## 方法

 最直接的解决方案是处理每个浇注操作并明确标记其影响的层。 当我们处于位置时`i`，奶油从层到达`i`向下为`a[i]`职位。 我们可以迭代这些层并将它们标记为已覆盖。 

这种方法是正确的，因为每个受影响的层都至少被访问一次。 当许多值很大时就会出现问题。 例如，如果每个`a[i] = n`，第一个操作接触一层，第二个操作接触两层，依此类推，大致导致$$1 + 2 + \dots + n = O(n^2)$$运营。 

问题的结构提出了更好的观点。 每次浇注操作都会创建一个被覆盖的连续层段。 我们可以从上到下处理各层，并记住还有多少个向下的位置仍在某个活跃的奶油区间内，而不是立即标记整个段。 

假设我们当前在层`i`并且有`cur`从上面开始的间隔剩余的层。 然后分层`i`每当`cur > 0`。 如果`a[i]`本身大于`cur`，一个新的间隔开始于`i`将覆盖范围进一步向下延伸，因此我们更新```
cur = max(cur, a[i])
```处理完当前层后，我们向下移动一层并减少`cur`一个。 

从上到下的处理将许多重叠的间隔转换为单个计数器，从而提供线性复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从顶层开始，向底层移动。 
2. 维护一个变量`cur`，代表有多少连续层（包括当前层）仍被来自上面各层的奶油覆盖。 
3.就位`i`， 更新`cur = max(cur, a[i])`。 

如果新的浇注操作比以前的浇注操作向下延伸得更远，则其效果将取代旧的范围。 否则，前面的覆盖已经足够了。 
4. 如果`cur > 0`、标记层`i`如所覆盖。 

正值表示至少一个奶油间隔包含该层。 
5.处理完图层后，减少`cur`增加一，但绝不会低于零。 

向下移动一步会消耗一层剩余的覆盖范围。 
6. 继续直至到达底层。 

### 为什么它有效

 向下扫描的同时，`cur`始终等于从当前层开始的连续层数，保证被已遇到的某些奶油操作覆盖。 每个浇注操作都从自己的位置开始并向下延伸精确的时间`a[i]`层。 取现有值和之间的最大值`a[i]`保持当前影响较低层的最长间隔。 减少`cur`每一步正确地从剩余范围中删除一层后。 由于当某个间隔达到某一层时，该层就被标记为完全覆盖，因此该算法会产生正确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
out = []

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    ans = [0] * n
    cur = 0

    for i in range(n - 1, -1, -1):
        cur = max(cur, a[i])
        if cur > 0:
            ans[i] = 1
        cur = max(0, cur - 1)

    out.append(" ".join(map(str, ans)))

print("\n".join(out))
```扫描从右向左进行，因为顶层对应于最大的索引。 变量`cur`存储剩余的覆盖深度。 在决定图层状态之前`i`，我们将倒入该层的奶油加入最大量`a[i]`。 

操作顺序很重要。 我们首先更新`cur`，然后判断当前层是否被覆盖，然后才减少`cur`。 颠倒这些步骤会将每个间隔缩短一并产生错误的答案。 

致电给`max(0, cur - 1)`防止负值。 尽管负数仍然会满足条件`cur > 0`假的，保留`cur`非负使得变量的含义更加精确。
