 ## 解决方案
 ## 问题理解

 我们得到了火车的计划时刻表。 对于每个站`i`，时刻表显示火车应该准时到达`a[i]`并准时出发`b[i]`。 

恶劣天气会导致车站之间旅行延误。 对于每个段，我们知道一个额外的延迟`tm[i]`。 从车站实际行驶时间`i - 1`到车站`i`变成：$$(a_i - b_{i-1}) + tm_i$$和`b[0] = 0`。 

火车到达车站后，并不总是立即出发。 出发时间必须满足两个要求。 

首先，火车必须在车站停留至少$$\left\lceil \frac{b_i-a_i}{2} \right\rceil$$时间单位。 

二、不能在预定出发时间之前出发`b[i]`。 

任务是确定最终站的实际到达时间。 

限制非常小。 最多有 100 个测试用例，每个测试用例最多有 100 个站。 甚至一个$O(n^2)$解决方案很容易拟合，但过程本身自然是线性的，因为每个站仅依赖于前一个站。 

主要困难是正确模拟出发规则。 一个常见的错误是总是在`max(arrival + required_stay, b[i])`，包括终点站。 火车到达车站`n`就是答案。 我们不在乎它什么时候从车站出发`n`。 

另一个微妙的点是天花板的划分。 所需等待时间为$$\left\lceil \frac{b_i-a_i}{2} \right\rceil$$必须仔细计算。 例如，如果`a=1`和`b=4`，区间长度为`3`，所以所需停留时间为`2`， 不是`1`。 

考虑：```
1
1
1 4
0
```火车准时到达`1`。 至少需要留下来`2`出发前的单位，但由于这是最后一站，答案很简单`1`。 任何模拟从最终车站出发的解决方案都会错误地输出`4`。 

另一个容易犯的错误是使用楼层划分而不是天花板划分。```
1
2
1 4
10 11
0 0
```在1号站，所需停留时间为`ceil(3/2)=2`。 火车到达`1`，等到`4`，然后到达站 2`10`。 

使用楼层划分只会在等待一个单位后就允许出发，并产生错误的时间线。 

## 方法

 暴力模拟逐站跟踪。 

我们跟踪当前时间。 当我们到达车站时，我们计算实际到达时间。 然后我们通过检查两个出发条件来确定最早的有效出发时间。 我们重复直到到达最后一站。 

即使我们完全按照描述模拟该过程，每个站的工作量也是恒定的。 由于最多有 100 个站，所有测试用例的总工作量仅为约 10,000 个站更新。 

关键的观察结果是语句中没有隐藏优化问题。 每个到达和出发时间均由前一个时间唯一确定。 一旦我们知道当前的出发时间，就可以根据给定的出行公式立即得出下一个到达时间。 

让`cur`表示从前一站实际出发的时间。 然后是到达车站的时间`i`是$$cur + (a_i - b_{i-1}) + tm_i.$$抵达后，等候规则允许的最早出发时间为$$arrival + \left\lceil \frac{b_i-a_i}{2} \right\rceil.$$时间表允许的最早出发时间是`b[i]`。 

实际出发时间是这两个值中较大的一个。 

这种直接模拟已经在线性时间内运行并且是最佳的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n) | O(1) | O(1) | 已接受 |
 | 最佳模拟| O(n) | O(1) | O(1) | 已接受 |

 在这个问题中，暴力方法和最优方法实际上是相同的，因为该过程本质上是顺序的并且已经是线性的。 

## 算法演练

 1. 初始化`cur = 0`，代表从航站楼出发的时间。 
2. 处理站来自`1`到`n`。 
3.计算实际到达车站的时间`i`:$$arrival = cur + (a_i - b_{i-1}) + tm_i.$$这直接来自声明中给出的旅行时间公式。 
4. 如果`i = n`， 输出`arrival`并停止。 

该问题要求到达终点站，而不是离开终点站。 
5. 计算所需的最短停留时间：$$wait = \left\lceil \frac{b_i-a_i}{2} \right\rceil.$$在整数算术中，这是：$$(b_i-a_i+1)//2.$$6、满足停留条件的最早出发时间为：$$arrival + wait.$$7. 火车也不能提前出发`b[i]`。 

放$$cur = \max(arrival + wait,\; b_i).$$8. 继续前往下一站。 

### 为什么它有效

 该算法保持一个简单的不变量：`cur`始终是从前一站出发的实际出发时间。 

鉴于该不变量，该语句唯一确定到下一站的行程时间，因此计算出的到达时间是正确的。 出发规则规定，只有在这两个条件都满足的情况下，火车才可以出发。 最早的这样的时刻恰好是两个下界中的最大值：$$arrival + wait$$和$$b_i.$$因此计算出的出发时间就是真实的出发时间。 通过对所有车站的归纳，模拟产生的每个到达和出发时间都与真实的火车时间线相匹配。 何时站`n`到达时，计算出的到达时间正是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())

        a = [0] * n
        b = [0] * n

        for i in range(n):
            a[i], b[i] = map(int, input().split())

        tm = list(map(int, input().split()))

        cur = 0
        prev_b = 0

        for i in range(n):
            arrival = cur + (a[i] - prev_b) + tm[i]

            if i == n - 1:
                print(arrival)
                break

            wait = (b[i] - a[i] + 1) // 2
            cur = max(arrival + wait, b[i])

            prev_b = b[i]

if __name__ == "__main__":
    solve()
```数组`a`和`b`存储时间表。 变量`cur`始终保存从前一站出发的实际出发时间，这就是前面描述的不变量。 

对于车站`i`，我们使用报表中的行程公式计算实际到达时间。 价值`prev_b`代表前一站的预定出发时间，出现在该公式中。 

最精致的线条是：```
wait = (b[i] - a[i] + 1) // 2
```这对正整数执行上限除法。 使用`(b[i] - a[i]) // 2`每当间隔长度为奇数时就会不正确。 

另一个微妙的细节是最后一站周围的操作顺序。 在计算到达时间后，我们立即检查当前站点是否是最后一个站点。 我们从不模拟出发车站`n`，因为答案就是到达时间本身。 

Python 整数可以轻松处理此问题中的所有值，因此不存在溢出问题。
