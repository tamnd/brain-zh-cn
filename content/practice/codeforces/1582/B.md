 ## 解决方案
 ## 问题理解

 我们有几个数组。 对于每个数组，令所有元素的总和为$s$。 我们需要计算有多少个子序列的和准确$s-1$。 

子序列是通过删除任意数量的元素形成的，可能不删除任何元素，也可能删除全部元素。 其余元素的顺序保持不变。 

数组长度最多为60，这个长度足够小，可以直接扫描数组，但子序列的数量为$2^{60}$，这是巨大的。 枚举所有子序列是完全不可能的。 甚至$2^{40}$对于一秒的限制来说，操作已经太多了。 

值本身可以大到$10^9$，但这并不重要，因为我们从来不需要对总和进行动态规划。 事实证明，问题的结构仅取决于出现了多少个 0 和 1。 

一些边缘情况很容易被忽略。 

考虑```
1
2
1 0
```总和为 1。我们需要总和为 0 的子序列。空子序列和仅包含 0 的子序列都满足这一点，因此答案为 2。忘记空子序列的解决方案将返回 1。 

考虑```
1
2
1000 1000
```总和是 2000。要获得 1999，我们必须删除总和为 1 的元素，但不存在这样的元素或组合。 答案是 0。粗心的方法可能会错误地假设每个数组至少有一个有效的子序列。 

另一个有趣的案例是```
1
4
1 1 0 0
```总和为 2。几乎满的子序列的和必须为 1。我们可以恰好删除其中一个，并且可以独立选择剩余的每组零。 由于有两个零，因此有助于$2^2=4$选择。 有两种方法可以选择删除哪一种，所以答案是$2 \times 4 = 8$。 

## 方法

 暴力解决方案检查每个子序列，计算其总和，并计算有多少个相等$s-1$。 这是有效的，因为定义直接询问子序列。 问题是子序列的数量。 和$n=60$， 有$$2^{60}\approx 1.15\times 10^{18}$$可能性，这远远超出了任何实际。 

关键的观察来自于补语的观察。 具有总和的子序列$s-1$意味着移除的元素的总和为 1。 

由于所有数字都是非负数，因此删除的元素之和为 1 的唯一方法是删除恰好一个等于 1 的元素，并且不删除大于 1 的正数。 

零不会影响总和，因此每个零可以独立保留或删除。 如果有$z$零点和$o$那些，我们有$o$删除其中一项的选择以及$2^z$决定保留哪些零的方法。 

答案很简单$$o \times 2^z$$扫描一次数组即可得到两个计数。

 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n \cdot n)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读一个测试用例。 
2. 计算有多少个元素等于 0。令此计数为$z$。 

零很特殊，因为包含或排除它们永远不会改变总和。 
3. 计算有多少个元素等于 1。令此计数为$o$。 

有效的子序列必须恰好排除一个值为 1 的元素。 
4. 将答案计算为$$o \times 2^z$$有$o$被删除的一个的选择，每个零独立地有两种可能性。 
5. 输出结果。 

### 为什么它有效

 假设子序列有和$s-1$。 等价地，移除的元素的总和为 1。 

因为每个数组元素都是非负的，所以不能删除大于 1 的元素。 删除两个或多个元素就已经贡献了至少 2。因此必须删除恰好一个等于 1 的元素。 

零对删除的总和没有任何贡献，因此可以删除或保留它们，而不会影响有效性。 

每个有效子序列对应于删除的 1 中的一个选择以及每个零的一个独立选择。 相反，每个这样的组合都会产生一个有效的子序列。 由于这种对应关系是一对一的，因此计数恰好是$o \times 2^z$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    zeros = 0
    ones = 0

    for x in a:
        if x == 0:
            zeros += 1
        elif x == 1:
            ones += 1

    print(ones * (1 << zeros))
```该程序独立处理每个测试用例。 

数组上的循环对零和一进行计数。 大于 1 的值将被忽略，因为它们永远不能属于总和必须等于 1 的已删除集合。 

表达式`1 << zeros`计算$2^{\text{zeros}}$。 最多 60 个元素，最大值为$2^{60}$，它很容易适合 Python 的任意精度整数。 

乘法的顺序并不重要。 如果没有，答案自动为零。

 ## 边缘情况

 考虑```
1
2
1 0
```我们有`ones = 1`和`zeros = 1`。 算法返回$$1 \times 2^1 = 2$$两个有效子序列是`(0)`和空子序列。 由于可以自由删除零，因此该算法自然会对两者进行计数。 

考虑```
1
2
1000 1000
```没有 1 也没有 0。 该算法计算$$0 \times 2^0 = 0$$删除的元素的集合的总和不能为 1，因此答案正确为零。 

考虑```
1
4
1 1 0 0
```计数器变成`ones = 2`和`zeros = 2`。 答案是$$2 \times 2^2 = 8$$必须删除两个中的一个。 每个零可以独立地保留或消失。 该算法计算所有八种可能性，而不枚举子序列。
