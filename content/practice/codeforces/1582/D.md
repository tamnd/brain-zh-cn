 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 在每一个中，我们都从一个非零整数数组开始$a$。 我们的任务是构造另一个数组$b$具有相同的长度，使得两个条件同时成立。 首先，没有元素$b$允许为零。 其次，具有这些系数的数组的加权和必须恰好为零，这意味着点积$\sum a_i b_i$完美抵消。 还有一个限制，即总绝对和$b$必须保持在一个大但有限的范围内，因此我们不能使用任意大的数字。 

关键的难点是每一个$a_i$是非零的，所以我们不能通过将头寸清零来简单地抵消贡献。 相反，我们必须仔细平衡整个阵列的积极和消极贡献。 

就总数组大小而言，约束很大，最多可达$2 \cdot 10^5$所有测试用例中的元素。 这立即排除了任何试图搜索组合或求解每个测试用例需要大量计算的一般线性系统的方法。 每个测试用例超过线性时间的任何事情都会太慢。 

一个简单的方法是尝试为$b_i$并迭代修复不平衡。 这会以两种常见方式失败。 首先，调整可以很容易地传播，打破先前满足的约束。 其次，随机性不能保证总和恰好为零，而无需潜在地需要极大的值，从而违反了界限$\sum |b_i|$。 

另一个天真的想法是修复除一个变量之外的所有变量并求解最后一个变量。 即设定$b_n = -\frac{\sum_{i=1}^{n-1} a_i b_i}{a_n}$。 这确保了正确性，但未满足以下约束：$b_n$必须是一个受控大小的整数，并且还保证$b_n \neq 0$并不总是可能的。 真正的问题是只控制一种自由度限制太大。 

更深层次的问题是，我们需要一种结构化的方式来取消当地的捐款，而不是依赖脆弱的全球平衡。 

## 方法

 暴力的观点是将其视为整数的约束满足问题。 每个职位贡献$a_i b_i$，我们希望总和消失。 人们可以想象尝试值$b_1$通过$b_n$，检查总和并进行调整。 即使我们将自己限制为小整数，例如$\{-1, 1\}$，可能性的数量呈指数增长$2^n$，即使对于$n = 20$，更不用说$10^5$。 

关键的观察是，我们实际上并不需要在每个位置都有自由。 我们只需要构建本地取消即可。 如果我们可以确保小组索引的总和始终为零，则整个数组通过分区自动总和为零。 

这引出了至关重要的见解：指数对或小块指数可用于抵消来自$a$。 我们不是全局思考，而是构建$b$以便每个局部结构独立地实现平衡。 

一个特别有效的想法是将数组分成两两。 对于每对$(a_i, a_{i+1})$，我们选择$b_i$和$b_{i+1}$这样$a_i b_i + a_{i+1} b_{i+1} = 0$。 使用赋值总是可以实现这一点$b_i = a_{i+1}$,$b_{i+1} = -a_i$， 自从：$$a_i a_{i+1} + a_{i+1} (-a_i) = 0.$$这种结构保证每对独立贡献为零，因此整个总和为零。 它还尊重以下约束：$b_i$为零，因为所有$a_i$均非零。 

唯一的复杂性是当$n$很奇怪。 在这种情况下，一个元素未配对。 我们通过使用也完全抵消的三元结构来解决这个问题。 对于三个连续元素$a_i, a_{i+1}, a_{i+2}$，我们可以赋值：$$(b_i, b_{i+1}, b_{i+2}) = (a_{i+1} + a_{i+2}, -a_i, -a_i).$$然后：$$a_i(a_{i+1} + a_{i+2}) + a_{i+1}(-a_i) + a_{i+2}(-a_i) = 0.$$这使我们能够干净地处理所有剩余元素。

 ## 算法演练

 我们独立处理每个测试用例。 

1.如果元素个数$n$是偶数，我们以不相交的对来处理数组。 对于每对$(a_i, a_{i+1})$, 网络分配$b_i = a_{i+1}$和$b_{i+1} = -a_i$。 这确保了每一对对总和的贡献恰好为零，因此不需要全局协调。 
2.如果$n$很奇怪，我们首先处理第一个$n-3$使用与上面相同的配对策略的元素。 这在最后留下了三个元素。 
3.对于最后三个要素$a_{n-2}, a_{n-1}, a_n$，网络分配：$b_{n-2} = a_{n-1} + a_n$,$b_{n-1} = -a_{n-2}$,$b_n = -a_{n-2}$。 这将创建一个独立的取消块。 
4.输出构造好的数组$b$。 

这样做的原因是每个构造的块独立于其他块的贡献为零。 配对块有助于$a_i a_{i+1} - a_{i+1} a_i = 0$。 三重块的设计使得系数$a_{n-2}$完全抵消了其他两个位置的贡献。 由于数组被划分为独立的零和块，因此总和也必须为零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    b = [0] * n
    
    i = 0
    while i + 1 < n:
        if n - i == 3:
            x, y, z = a[i], a[i+1], a[i+2]
            b[i] = y + z
            b[i+1] = -x
            b[i+2] = -x
            i += 3
        else:
            b[i] = a[i+1]
            b[i+1] = -a[i]
            i += 2
    
    print(*b)
```该代码从左到右逐渐构建答案。 该循环确保我们总是消耗两个元素，或者当正好剩下三个元素时，切换到三元结构。 关键的微妙之处在于条件`n - i == 3`，这可以防止将数组分解为最后一对和剩余的单例，这是无法处理的。 

所有赋值都保持非零值，因为它们是非零整数的和或负。

 ## 边缘情况

 一种重要的边缘情况是数组长度为奇数时。 幼稚的配对策略会尝试让单个元素不被处理，这会立即失败，因为没有有效的非零赋值可以单独中和它。 三块结构通过确保最后三个元件始终形成一个封闭系统来解决这个问题。 例如，使用输入$a = [1,2,3,4,5]$，算法处理$(1,2)$和$(3,4)$，离开$(5)$不可能单独处理。 相反，该实现确保调整配对策略，以便最后一个操作始终同时处理三个元素，从而生成有效的取消块。 

另一种极端情况是所有数字都相同。 在这种情况下，简单的交替符号似乎就足够了，但如果不仔细构建，它可能会产生零条目。 配对方法完全避免了这种情况，因为每个$b_i$直接从非零导出$a_j$，保证非零输出，同时保持取消。 

最后的边缘情况是当值的大小很大，接近界限时$10^4$。 由于每个$b_i$被构造为另一个$a_j$或两个之和$a_j$，最大幅度仍受以下限制$2 \cdot 10^4$，确保总绝对值安全地保持在$10^9$。
