 ## 解决方案
 ## 问题理解

 我们得到了一个数字序列以及它们之间的一系列操作。 我们以值 1 开始每个段，然后从左到右应用操作。 每个位置要么将当前值乘以给定数字，要么将其除以该数字。 当我们继续进行时，我们记录每次操作后的中间值。 如果这些中间值中的每一个都是整数，则该段被称为有效。 

任务是计算整个过程中有多少连续段仅产生整数。 

关键的困难在于除法引入了全局约束：一旦我们除以一个数字，我们必须确保到该点为止的累积乘积包含所有所需的质因数，否则该值将不再是整数。 由于段可以从任何地方开始，因此条件必须适用于段内的每个前缀，而不仅仅是末尾。 

这些限制使得暴力破解变得不可行。 对于多达一百万个元素，即使检查所有段也已经是二次的，并且重新计算每个段内的因式分解或跟踪整除性将在每次操作中引入另一个对数或更差的因子。 任何重复重新计算素因数分解或独立模拟段的解决方案都会失败。 

当除法出现在任何补偿它们的乘法之前时，就会出现微妙的边缘情况。 例如，如果序列以除法开始，则从那里开始的每个段立即无效，但稍后开始的段仍可能再次有效。 另一个棘手的情况是，当主要因素赤字产生并随后修复时，因为只有本地部分重要，而不是全球历史。 

## 方法

 强力方法将迭代所有段并模拟每个段的过程。 对于固定段，我们将保持当前值并重复应用乘法或除法，同时检查该值是否仍然是整数。 这种方法是正确的，因为它直接遵循定义。 然而，在最坏的情况下，每个段都会花费线性时间，从而导致整体行为呈立方体行为。 

主要障碍是整除性取决于素因数平衡。 乘以一个数字会增加它的质因数，而除法则会删除它们。 只要该段的任何前缀中没有质数指数变为负数，该值就保持为整数。 

这将问题转化为跟踪，对于每个素数，其指数在每个前缀上是否保持非负。 我们不是从头开始重新计算每个段，而是从左到右处理数组，并维护在每个位置结束的段的最佳可能起点。 

关键的观察是，对于每个素数，我们只需要知道它的当前余额是否低于零。 如果是这样，则在该点之前开始的任何段都不能保持有效，因此起点必须向前移动。 每个素数独立地强制限制线段可以从左多远开始。 最终的有效开始由最严格的素数约束确定。

 | 最佳 | O(n log A) | O(n log A) | O(n log A) | O(n log A) | 已接受 |

 ## 算法演练

 我们从左到右处理数组，同时保持质因数施加的约束。 

1. 将每个数字分解为素数。 我们将乘法视为素数的加法，将除法视为素数的减法。 这将问题转化为跟踪多个独立的余额计数器，每个素数一个。 
2.维护字典`cur[p]`代表目前的prime盈余`p`在结束于位置的活动段内`i`。 正值意味着我们有该质数的额外副本可用于未来的划分。 
3. 维护另一本字典`bad[p]`它记录了迫使我们重新启动prime段的最早位置`p`。 最初，所有值均为零。 
4. 处理位置乘法时`i`，我们增加`cur[p]`对于每个素因数`a[i]`。 仅乘法不会发生约束冲突，因为它只会增加资源。 
5. 处理除法时`a[i]`，我们从中减去它的素因数`cur`。 如果对于任意素数`p`，该值变为负数，表示当前段不能包含该前缀。 然后我们重置`cur[p]`归零并设置`bad[p] = i`，这意味着在此结束的任何有效段都必须在此点之后开始。 
6. 对于每个位置`i`，最早的有效开始由最严格的素数约束确定。 我们计算`L = max(bad[p])`超过当前相关的所有素数。 结束于的有效段数`i`那么就是`i - L + 1`。 
7. 我们为每个职位累积这笔贡献。 

这样做的原因是每个素数约束都是独立的，并且对段起始位置强制执行单调限制。 一旦素数强制在位置重新启动`i`，任何较早的开始都会永久违反结束于的段内该素数的整数有效性`i`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 10**6 + 1

spf = list(range(MAXV))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV, i):
            if spf[j] == j:
                spf[j] = i

def factor(x):
    res = {}
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        res[p] = cnt
    return res

n = int(input())
a = list(map(int, input().split()))
b = input().strip()

cur = {}
bad = {}
L = 0
ans = 0

for i in range(n):
    if b[i] == '*':
        f = factor(a[i])
        for p, c in f.items():
            cur[p] = cur.get(p, 0) + c
    else:
        f = factor(a[i])
        for p, c in f.items():
            cur[p] = cur.get(p, 0) - c
            if cur[p] < 0:
                bad[p] = i + 1
                cur[p] = 0

    for p, v in bad.items():
        if v > L:
            L = v

    ans += (i + 1 - L)

print(ans)
```该实现依赖于线性扫描与使用最小素因子筛的快速分解相结合。 每个数字都被分解一次，并且每个质数仅贡献一些更新。 

变量`cur`跟踪运行段中当前可用的每个素数的额外副本数。 当除法强制出现赤字时，相应的素数在该位置被标记为无效，并且其计数器被重置，因为任何早期的盈余都不能重新用于必须超出此违规范围的段。 

变量`L`将所有特定于素数的约束聚合到单个全局左边界中，用于以每个位置结束的有效段。 

## 工作示例

 考虑一个乘法和除法相互作用的小序列：

 输入：```
5
2 6 3 2 3
*/*/*
```我们追踪素数 2 和 3。 

在每一步中，我们都保持`cur`和`L`。 

| 我| 操作| 一个[我] | 目前的变化| 糟糕的更新| 左 | 贡献 |
 | ---| ---| ---| ---| ---| ---| ---|
 | 1 | * | 2 | 2：+1 | 无 | 0 | 1 |
 | 2 | / | 6 | 2:-1,3:-1 → 重置两者 | 坏[2]=2,坏[3]=2 | 2 | 0 |
 | 3 | * | 3 | 3：+1 | 无 | 2 | 1 |
 | 4 | / | 2 | 2：-1 | 坏[2]=4 | 4 | 0 |
 | 5 | * | 3 | 3：+1 | 无 | 4 | 1 |

 该跟踪显示了除法如何积极地向前移动有效起始边界，而乘法则如何重建可用的主要资源。 

第二个例子：

 输入：```
4
1 2 4 2
*/**
```在这里，任何除法都不会产生赤字，因此边界永远不会超过零。 每个前缀仍然有效，表明该算法正确处理纯扩展段。

 ## 边缘情况

 第一种边缘情况是数组仅包含 1 时。 由于 1 没有质因数，因此乘法或除法都不会改变任何平衡。 算法永远不会更新`bad`， 所以`L`保持为零并且所有段都被计数。 这符合每个段都是有效的这一事实。 

另一个边缘情况是第一个操作是除法。 因式分解立即产生负余额，迫使`bad[p]`等于 1，移动`L`向前，以便不计算违规之前开始的任何段。 这可以正确消除无效前缀，同时仍允许稍后恢复。 

最后一种情况是同一数字的乘法和除法之间的重复振荡。 该算法通过在出现赤字时重置计数器来处理此问题，确保只有当前可行的主要余额影响活动段边界，而永远不会过时的历史盈余。
