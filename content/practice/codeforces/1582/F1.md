 ## 解决方案
 ## 问题理解

 我们给定一个整数数组，任务是确定所有可能的值`x`可以通过数组的某些递增子序列的异或来获得。 递增子序列是每个元素都严格大于前一个元素的子序列，并且子序列可以跳过原始数组的元素。 允许空子序列，这会产生 XOR`0`。 输出必须按升序列出所有可能的 XOR 值。 

数组大小可以大到 100,000，但每个元素最多 500。上限为`n`意味着我们无法负担单独检查所有子序列的算法，因为子序列的数量呈指数增长。 小界限`a_i`(500) 暗示我们可以利用有限的值范围，可能对可能的异或结果使用位掩码或动态编程等技术。 

非明显的边缘情况包括具有重复数字的数组或严格降序排列的数组。 例如，一个数组`[2, 2, 2]`仍然允许像这样的子序列`[2]`产生异或`2`， 但`[2,2]`无效，因为它没有增加。 忽略“严格递增”要求的粗心方法会计算重复项并产生无效的 XOR 值。 另一个边缘情况是`[0, 0, 0]`，其中空子序列产生`0`并且唯一有效的子序列也会产生`0`。 

## 方法

 暴力方法将考虑数组的所有子序列，计算它们的异或，并收集结果。 这是正确的，因为它枚举了每个可能的递增子序列。 然而，子序列的数量是`2^n`，这是周围`10^30`为了`n = 100,000`，使得这种方法完全不可行。 

更结构化的方法使用动态编程。 对于每个值`v`在数组中，我们可以考虑扩展之前以较小数字结尾的子序列。 我们跟踪可以获得以每个可能的最后一个元素结尾的所有异或结果。 一个简单的 DP，为每个数据存储一组 XOR`n`元素可以通过观察来简化`a_i <= 500`。 这允许 DP 表通过可能的最后元素和可能的 XOR 值进行索引。 关键的见解是维护每个`a_i`，使用小于的数字可实现的 XOR 集合`a_i`。 每当我们处理`a_i`，我们将其与所有先前可实现的较小值的 XOR 进行异或并更新表。 这避免了显式地迭代子序列。 

另一种更有效的方法使用类似线性代数的技术，称为“异或基”或“线性基”。 这个想法是维护一组代表最小 XOR 集的数字，这些数字可以为严格增加的子序列生成所有可实现的 XOR 值。 对于数组中的每个数字，我们使用小于它的数字更新基。 一旦建立了基础，每个异或值都可以作为基础元素的组合获得。 这极大地降低了复杂性，因为基本元素的数量最多为 9 个（因为 max`a_i = 500`适合 9 位），并且更新操作与基础大小呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(2^n) | O(2^n) | 太慢了 |
 | DP带套装| O(n * max_a * max_xor) | O(n * max_a * max_xor) | O(max_a * max_xor) | 已接受 |
 | 异或基础| O(n * 最大位数) | O(最大位数) | 已接受 |

 ## 算法演练

 1.初始化一个数组`dp`长度为 501，其中`dp[v]`是使用以数字结尾的严格递增子序列可实现的所有 XOR 值的集合`v`。 初始化`dp`和`dp[0] = {0}`对于空子序列。 
2. 迭代每个数字`a_i`在输入数组中。 对于每个`a_i`,创建一个临时集`new_xors`含有`a_i`本身，因为单元素子序列`[a_i]`是有效的。 
3. 对于每个较小的值`v`少于`a_i`， 结合`a_i`每个 XOR 值`dp[v]`。 具体来说，对于每个`x`在`dp[v]`, 计算`x ^ a_i`并将其添加到`new_xors`。 此步骤扩展了以以下结尾的所有有效子序列`v`通过添加`a_i`。 
4. 更新`dp[a_i]`将所有值相加`new_xors`。 这确保了`dp[a_i]`包含可以从以结尾的递增子序列获得的每个 XOR`a_i`。 
5.处理完所有元素后，取所有元素的并集`dp[v]`集形成最终可实现的 XOR 值集。 
6. 按升序对 XOR 值集进行排序并打印计数和值。 

为什么它有效：在每一步，`dp[v]`准确地表示通过增加以结尾的子序列可实现的所有 XOR 值`v`。 扩展较小的数字可以保留增加的属性，并且异或运算可以正确传播。 通过迭代所有元素并合并结果，不会遗漏任何有效的 XOR，并且不会包含无效的子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

max_val = 500
dp = [set() for _ in range(max_val + 1)]
dp[0].add(0)  # handle empty subsequence producing XOR 0

for num in a:
    new_xors = {num}
    for smaller in range(num):
        for x in dp[smaller]:
            new_xors.add(x ^ num)
    dp[num].update(new_xors)

result = set()
for s in dp:
    result.update(s)

res_list = sorted(result)
print(len(res_list))
print(*res_list)
```这`dp`数组确保每个`dp[v]`只存储以以下结尾的子序列的 XOR`v`，保持递增的后续性质。 嵌套循环是安全的，因为`num <= 500`，因此每个元素最多发生 500 次迭代，这是可以接受的`n <= 10^5`。 所有集合的并集产生所有可实现的异或。 最后排序可确保输出按升序排列。 

## 工作示例

 **示例输入 1**```
4
4 2 2 4
```| 步骤| 编号 | 较小| dp[num] 更新 |
 | ---| ---| ---| ---|
 | 1 | 4 | 0..3 | 0..3 {4,2,6,0} |
 | 2 | 2 | 0..1 | 0..1 {2,0} |
 | 3 | 2 | 0..1 | 0..1 已包含 {2,0} |
 | 4 | 4 | 0..3 | 0..3 合并新的 {4,2,6} |

 最终的`result`=`{0,2,4,6}`。 跟踪显示空子序列产生 0，单个元素产生它们自己的值，并且组合`[2,4]`产生 6.

 **示例输入 2**```
3
1 3 2
```| 步骤| 编号 | 较小| dp[num] 更新 |
 | ---| ---| ---| ---|
 | 1 | 1 | 0 | {1} |
 | 2 | 3 | 0..2 | 0..2 {3, 2, 0 ^ 3=3} |
 | 3 | 2 | 0..1 | 0..1 {2,1^2=3}|

 最终的`result`=`{0,1,2,3}`。 证明子序列严格递增并且所有异或都被捕获。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * max_val^2) | O(n * max_val^2) | 每个数字迭代所有较小的数字 (≤500)，对于每个较小的数字迭代其存储的 XOR 集 (≤max_val) |
 | 空间| O(max_val * max_val) |`dp`存储每个值 ≤500 的集合，每个集合可以有 ≤max_val 不同的 XOR 值 |

 和`n=1e5`和`max_val=500`，操作次数约为 1.25*10^7 左右，正好在 2 秒以内。 内存使用量也在 512 MB 以内。
