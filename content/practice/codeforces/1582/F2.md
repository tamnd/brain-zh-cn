 ## 解决方案
 ## 问题理解

 我们得到一个整数数组`a`长度`n`。 任务是找到所有非负整数`x`可以表示为某个严格递增子序列的异或`a`。 如果每个元素严格大于前一个元素，则子序列是严格递增的，并且 XOR 是标准的按位运算。 

输入约束很重要：`n`最多可达 1,000,000 个元素`a[i]`的范围是 0 到 5000。这立即排除了枚举所有子序列的简单方法，因为最多有`2^n`可能的子序列。 即使算法是二次的`n`如果内部操作很重，可能会太慢。 我们需要更接近线性或线性算术复杂度的东西`n`具有可管理的因素，具体取决于`a[i]`。 

边缘情况并不明显。 一种是空子序列，它总是产生 XOR 0。另一种是当所有元素都相等时，只有长度为 1 的子序列贡献新的 XOR 值。 此外，重复的元素需要小心处理，因为在形成子序列时我们不能将重复元素视为严格递增。 

## 方法

 强力方法枚举每个递增子序列并计算其异或。 对于长度的数组`n`，子序列的数量是`2^n`，这对于`n = 10^6`。 即使是跟踪每个位置上所有可能的 XOR 的动态编程方法，如果不进行优化，也会变得太大，因为 XOR 值本身可以达到`2^13`对于高达 5000 的数字，可能的 XOR 数量可能会爆炸。 

关键的见解来自于 GF(2) 上的线性代数（XOR 的行为类似于加法模 2）和贪婪序列构造的思想的结合。 我们不明确地考虑子序列，而是维护 XOR 值的“基础”，该基础可以通过严格增加以每个值结尾的序列来实现。 对于每个可能的数字`v`从最小到最大，我们维护一组可到达的异或序列，其结尾数字小于`v`。 当我们看到`v`，我们通过异或来扩展集合中的每个异或`v`。 这些集合的并集给出了所有可实现的 XOR，我们可以使用`set`或者`boolean`数组，因为 5000 以内的数字的异或运算以 8192 为界。 

这降低了复杂性，因为我们不再枚举子序列； 我们向前传播可实现的异或，通过按顺序处理值来遵守严格递增条件。

 ## 算法演练

 1. **初始化数据结构**：我们准备一个布尔集数组`reachable`尺寸的`max_value+1`(5001) 跟踪以每个值结尾的序列可实现的 XOR。 另外，初始化一个全局集`all_xor`含有`0`对于空子序列。 
2. **按顺序处理值**：迭代`v`从 0 到 5000。对于每个`v`存在于输入数组中，通过采用每个 XOR 来计算新的 XOR`x`在`all_xor`并形成`x ^ v`。 将这些收集到临时集合中`new_xor`。 
3. **更新可到达的异或**：合并`new_xor`进入`all_xor`。 这确保所有以数字 ≤ 结尾的子序列`v`被考虑并尊重严格增加的要求，因为我们只扩展数字大于先前元素的序列。 
4. **编译结果**：处理完所有值后，`all_xor`包含任何严格递增子序列可实现的所有异或。 对它们进行排序并输出。 

**为什么有效**：该算法保持了以下不变式：`all_xor`包含以数字 ≤ 当前结尾的严格递增子序列的所有异或`v`。 通过按升序处理，我们从不组合`v`数量≥`v`，从而保留了严格递增的性质。 每个新数字仅扩展严格大于最后一个元素的序列。 这保证了完整性和正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

max_val = 5000
present = [0] * (max_val + 1)
for num in a:
    present[num] = 1

all_xor = {0}

for v in range(max_val + 1):
    if present[v]:
        new_xor = set()
        for x in all_xor:
            new_xor.add(x ^ v)
        all_xor |= new_xor

result = sorted(all_xor)
print(len(result))
print(' '.join(map(str, result)))
```这段代码首先记录数组中出现了哪些数字，以避免不必要的迭代。 然后，它使用数字按升序迭代扩展可实现的 XOR 集。 集合并集`|=`确保没有重复。 最后，它输出计数和排序的 XOR 值。 

微妙之处包括初始化`all_xor`和`0`对于空子序列和处理`v`以递增顺序遵守严格递增条件。 忘记其中任何一个都会导致错误的结果。
