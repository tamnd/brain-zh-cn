 ## 解决方案
 ## 问题理解

 我们给定一个长度的字符串$n$。 我们可以重复应用交换操作来交换位置上的字符$i$和$i+k$，只要两个索引都有效。 这些交换可以按任何顺序执行任意次数。 

任务是确定通过应用这些交换的任意序列可以从原始字符串生成多少个不同的字符串。 如果两个字符串至少有一个位置不同，则认为两个字符串不同。 

关键结构是互换不会在全球范围内发挥作用。 每个掉期仅连接指数完全不同的头寸$k$。 这立即表明指数根据其余数模分为独立的组$k$。 

约束条件$n \le 10^6$意味着任何解决方案必须本质上是线性的或$O(n \log n)$。 任何涉及枚举排列或状态上的 BFS 的事情都是不可能的，因为状态空间是阶乘的$n$。 我们被迫将交换的效果压缩为组合计数问题，而不是模拟转换。 

天真的推理的一个微妙的失败案例是假设如果存在足够的交换，则字符串的任何排列都是可能的。 例如，与$n=4, k=2$，字符串“aabb”不能产生全部 4 个！ 排列。 仅位置 (1,3) 和 (2,4) 连接，因此字符只能在这些对内重新排列。 一个朴素的全局排列模型会大量计数。 

另一个边缘情况是当$k=1$。 那么每个相邻的交换都是允许的，这意味着整个字符串可以任意排列，所以答案是$n!$按字符的多重性划分。 

在另一个极端，当$k=n$，不可能进行交换，因此仅存在一种配置。 

## 方法

 暴力方法将每个索引建模为一个节点，并在之间添加边$i$和$i+k$。 然后我们将构建连接的组件并模拟每个组件内的所有可达排列。 各组成部分尺寸$m$会做出贡献$m!$重新排列，但由于重复的字符，必须删除重复项。 这导致每个分量都有多项系数。 

然而，暴力破解会失败，因为显式生成组件内的所有排列是指数级的。 即使构建状态图也是不可行的，因为每个组件单独可能都有大小$O(n)$，给出阶乘增长。 

关键的观察是，交换只允许在通过逐步增量形成的每个连接组件内进行任意重新排列$k$。 这些分量正是残基类模$\gcd(n,k)$由图导出的结构$i \leftrightarrow i+k$。 事实上，指数分为$k$独立链：$$i, i+k, i+2k, \dots$$在界限之内。 在每个链中，任何排列都是可以实现的，因为沿着链的相邻交换会在该组件上生成完整的对称组。 

因此，问题简化为：对于每个链，计算其多组字符存在多少种不同的排列。 这些是多项式计数，并且由于链是独立的，因此我们将所有链的结果相乘。

 ## 算法演练

 ### 步骤 1：将索引分区到链中

 我们按残差模对位置进行分组$k$。 对于每个余数$r$，考虑指数$r, r+k, r+2k, \dots$。 每个这样的组都是独立的，因为交换永远不会在不同组之间移动角色。 这是问题的根本解耦。 

### 第 2 步：计算每个链中的字符数

 对于每个链，我们收集出现在这些位置的多组字符。 由于链内的任何排列都是可到达的，因此不同排列的数量仅取决于多重性。 

### 步骤 3：计算每个链的多项式贡献

 如果一条链子有长度$m$，和字符数$c_1, c_2, \dots$，则不同排列的数量为：$$\frac{m!}{\prod c_i!}$$我们计算阶乘和模逆来有效地评估这一点。 

这是有效的原因是交换生成沿链的所有相邻转置，从而生成该链上的完整对称组。 

### 步骤 4：增加贡献

 由于链是独立的，因此可达字符串的总数是所有链的乘积。 

### 为什么它有效

 每个交换都保留按残差模的索引分区$k$，所以没有角色会离开它的链条。 在链内部，交换形成一个连接的路径图，相邻的交换生成该路径的所有排列。 因此，每个链准确地贡献其多重集的排列数量，独立于其他链。 独立意味着乘法。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, k = map(int, input().split())
    s = input().strip()

    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)

    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    used = [False] * n
    ans = 1

    for r in range(k):
        freq = [0] * 26
        length = 0
        i = r
        while i < n:
            freq[ord(s[i]) - 97] += 1
            length += 1
            i += k

        ways = fact[length]
        for c in freq:
            ways = ways * invfact[c] % MOD

        ans = ans * ways % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先预先计算阶乘和逆阶乘，直到$n$，因为每个链都需要多项式系数。 模逆是使用费马定理计算的，该定理是有效的，因为模数是素数。 

主循环迭代$k$残留类。 对于每个类，我们遍历索引，间隔为$k$，累积字符频率。 使用阶乘表直接应用多项式公式。
