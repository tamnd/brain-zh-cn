 ## 解决方案
 ## 问题理解

 我们在数轴上得到一组点，每个点代表朱丽叶在零时刻的可能初始位置。 罗密欧后来得知，当时`d`，朱丽叶必须位于已知区间内的某个位置`[A, B]`。 时间之间`0`和时间`d`，朱丽叶可以沿着这条线自由移动，但是她的速度是有限的：每分钟她最多只能移动一个单位距离，所以之后`d`分钟她就可以到达任何距离内的地方`d`从她开始的地方开始。 

任务是确定给定候选人中的哪些起点可以演变成内部的某个职位`[A, B]`恰好在之后`d`此类运动的分钟数。 输出是这些有效起点的索引列表。 

约束允许最多`10^5`候选点和坐标最多`10^9`， 和`d`还高达`10^9`。 这立即排除了任何模拟运动或每分钟检查可达性的方法。 任何解决方案都必须将每个点减少到恒定时间检查，因为`O(N)`或者`O(N log N)`预计解决方案会顺利通过，而任何二次方都会太慢。 

边界推理产生了一个微妙的问题。 一个常见的错误是将可达性视为单个点而不是间隔。 另一种是仅检查一个移动方向，例如验证是否`P_i`可以达到`A`或者`B`单独检查，而不是检查可达范围的重叠。 这些错误会导致朱丽叶拒绝有效的起点，而朱丽叶只是朝着区间的正确部分移动。 

例如，假设`d = 2`,`P_i = 5`， 和`[A, B] = [6, 7]`。 朱丽叶可以从`5`到`7`分两步进行，因此这个起点是有效的。 一个天真的检查，比如“她能到达吗？”`A`完全正确”会错误地拒绝它。

 ## 方法

 蛮力解释模拟从每个起始位置开始的运动。 从一点来看`x`， 后`d`分钟朱丽叶可以在中场休息的任何位置`[x - d, x + d]`。 为了检查有效性，可以枚举从`x`并验证是否有任何位于`[A, B]`。 这立即变得不可行，因为每个区间都包含`O(d)`整数位置，以及`d`可以大到`10^9`，使得模拟无法进行。 

关键的观察是运动将每个起点转化为一个连续的区间，我们只需要知道两个区间是否相交。 我们不是跟踪所有可能的位置，而是计算可达区间`[x - d, x + d]`并检查它是否与`[A, B]`。 区间重叠减少为一对线性不等式，进一步简化为对`x`。 

当且仅当存在位于两者中的某个位置时，这两个区间才会相交。 这恰好发生在`x + d >= A`和`x - d <= B`。 重新排列给出`x >= A - d`和`x <= B + d`。 因此每个候选点可以在恒定时间内独立检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(N·d) | O(1) | O(1) | 太慢了|
 | 间隔减少 | O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将可达性问题转化为原始点上的简单范围过滤器。 

1.计算仍能到达的最小起始位置`[A, B]`后`d`分钟，即`A - d`。 这是通过扭转最大向右运动来实现的。 
2.计算仍能到达的最大起始位置`[A, B]`，即`B + d`，来自反向最大向左运动。 
3. 迭代所有点`P[i]`。 
4. 对于每个点，检查它是否位于区间内`[A - d, B + d]`。 如果是，请将其索引包含在答案中。 
5. 按升序输出所有收集到的索引。 

我们反转间隔而不是向前模拟运动的原因是每个起始位置都映射到对称的可达段。 逆向工作将动态可达性问题转换为静态过滤条件。 

### 为什么它有效

 在零时间，起始位置`x`扩展到整个区间`[x - d, x + d]`在某个时间`d`。 朱丽叶有效当且仅当该区间相交`[A, B]`。 区间交集相当于两个区间完全位于另一个区间的左边或完全位于另一个区间的右边的条件。 平移这些非重叠条件会产生边界`x >= A - d`和`x <= B + d`。 因此，每个有效起始点都会被该过滤器捕获一次，并且没有无效点可以满足它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, A, B, d = map(int, input().split())
    P = list(map(int, input().split()))

    left = A - d
    right = B + d

    res = []
    for i, x in enumerate(P):
        if left <= x <= right:
            res.append(str(i))

    print(" ".join(res))

if __name__ == "__main__":
    solve()
```该实现直接对导出的间隔条件进行编码。 唯一微妙的一点是索引是根据输入顺序保留的，所以我们用`i`从零开始并将这些索引打印为字符串。 

必须注意不要以任何扩展方式重新计算每个点的可达性。 整个解决方案依赖于将每个点减少为与预先计算的间隔的单个比较。

 ## 边缘情况

 一种边缘情况是当`d = 0`。 在这种情况下，朱丽叶根本无法移动，因此唯一有效的起点是已经在里面的起点`[A, B]`。 该算法自然地处理这个问题，因为间隔变为`[A, B]`，因此条件简化为直接隶属度测试。 

另一种情况是当`A - d`变为负数。 由于输入中的坐标可以为零但不能为负，因此这只是将有效区域向左扩展到可能点的域之外。 该算法仍然有效，因为即使在负边界下，比较仍然有效，并且不需要特殊的钳位。 

最后一个微妙的情况是`[A, B]`非常大并且重叠几乎所有可能的位置。 在那种情况下，`A - d`和`B + d`可能会超出任一方向的输入边界，但间隔检查仍然正确，因为它仅取决于不等式关系，而不取决于绝对范围限制。
