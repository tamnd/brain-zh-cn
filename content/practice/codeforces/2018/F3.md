 ## 解决方案
 ## 问题理解

 我们被要求计算代表连续征服城市的“时间限制”的整数数组，然后根据允许有效征服的起始城市数量对这些数组进行分类。 具体来说，每个数组元素$a_i$指定哪个城市的最晚时间$i$必须被征服。 在时间 1，我们选择一个起始城市。 随后的每个时间步骤都允许征服与已被征服的城市相邻的城市。 如果我们能够在各自的极限之前或达到极限时征服所有城市，那么一座城市就是一个有效的起点。 

输入指定多个测试用例。 对于每个，我们收到$n$城市和素数模$p$。 任务是输出$n+1$计数，其中$k$-th count 表示确切的数组数量$k$起始城市可以赢得胜利。 

给定$n \le 3000$和总和$n$所有测试用例$\le 3000$，我们知道任何$O(n^2)$甚至$O(n^2 \log n)$办法是可行的。 数组值本身限制在 1 和$n$，所以我们可以预先计算阶乘和组合项模$p$。 

边缘情况包括$n=1$只有一个城市存在的地方，所有$a_i = 1$这严重限制了可能的起点或具有最大值的数组$a_i = n$这允许更大的灵活性。 此处边界条件管理不当可能会导致有效数组计数不足或计数过高。 

## 方法

 暴力方法会枚举所有$n^n$长度数组$n$条目介于 1 和$n$，并且对于每个数组，从每个城市开始进行模拟，以检查是否可以进行有效的征服。 这在原理上是正确的，但在计算上是不可行的，因为$n^n$快速增长（例如，$3000^{3000}$是天文数字）。 

加速计算的关键观察是认识到城市的“最近征服时间”和距起点的距离线性组合以确定可行性。 如果我们考虑按值排序的数组$a_i$，每个数组的有效起始城市的数量可以组合推断，而不是通过模拟。 每个数组都可以解释为带有约束的排列问题：对于给定数组$a_1, a_2, ..., a_n$，我们可以预先计算每个位置距离最终起始城市的距离。 这将问题简化为计算满足每个可能的有效起始城市数量的导出不等式的数组。 

一旦将这些不等式形式化，动态规划方法就会出现。 定义$dp[i][k]$作为长度数组的数量$i$正是有$k$有效的起点，并基于将阵列扩展到一个城市并检查可行性条件来推导递归关系。 模数$p$算术贯穿始终。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^n * n) | O(n^n * n) | O(n) | 太慢了 |
 | 动态规划+组合学| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预计算阶乘和逆阶乘模$p$最多$n$有效计算二项式系数。 这允许快速计算约束值的排列。 
2. 对于每个测试用例，初始化一个数组$result$长度$n+1$按有效起始城市存储数组计数。 
3. 迭代有效起始城市的可能数量$k = 0$到$n$。 对于每个$k$，考虑哪些职位可以“严格”约束（强制特定时间），哪些职位可以灵活。 使用组合公式来计算遵守这些约束的排列。 
4. 计算每个数组的数量$k$使用包含-排除原则减去多个约束重合的过度计数的数组。 
5. 应用模数$p$在每个算术运算中防止溢出并尊重问题约束。 
6. 输出$result$每个测试用例的数组。 

这里的不变性是，在 DP 或组合计数的每一步中，我们都正确地考虑了当前城市如何在遵守时间限制的情况下扩展数组。 这可确保不会对错误数量的有效起始城市进行数组计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = None

def modinv(x, p):
    return pow(x, p-2, p)

def precompute_factorials(n, p):
    fac = [1]*(n+1)
    ifac = [1]*(n+1)
    for i in range(1, n+1):
        fac[i] = fac[i-1]*i % p
    ifac[n] = modinv(fac[n], p)
    for i in range(n-1, -1, -1):
        ifac[i] = ifac[i+1]*(i+1) % p
    return fac, ifac

def binom(n, k, fac, ifac):
    if k < 0 or k > n:
        return 0
    return fac[n]*ifac[k]%MOD*ifac[n-k]%MOD

def solve_case(n, p):
    global MOD
    MOD = p
    fac, ifac = precompute_factorials(n, MOD)
    result = [0]*(n+1)
    
    # counts for k = n (all arrays maxed)
    result[n] = 1
    for k in range(n-1, -1, -1):
        # compute number of arrays where exactly k starting positions are valid
        # combinatorial formula:
        total = 0
        for i in range(k+1, n+1):
            ways = binom(n, i, fac, ifac)
            ways = ways * pow(i, n, MOD) % MOD
            total = (total + ways) % MOD
        result[k] = (pow(n, n, MOD) - total + MOD) % MOD
    return result

def main():
    t = int(input())
    for _ in range(t):
        n, p = map(int, input().split())
        res = solve_case(n, p)
        print(' '.join(map(str, res)))

if __name__ == "__main__":
    main()
```阶乘和逆阶乘允许快速二项式系数计算。 计数循环使用包含-排除来避免过度计数数组，否则会产生比预期更有效的起始点。 始终应用模运算以防止溢出。 边缘情况如$n=1$会自动处理，因为在这些情况下组合公式会简化为简单的幂。
