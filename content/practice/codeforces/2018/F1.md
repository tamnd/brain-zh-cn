 ## 解决方案
 ## 问题理解

 该问题要求我们计算数组的长度$n$其中每个元素$a_i$是 1 到 1 之间的正整数$n$，并根据允许连续征服且不违反上限的起始城市数量对这些数组进行分类$a_i$。 将城市想象成一条直线上的瓷砖。 在时间 1，您选择要占据的一块图块。 每个后续时间步都可以扩展到相邻的图块。 对于数组$a$，目标是不晚于各自的城市占领每个城市$a_i$。 如果起始城市可以在不违反任何期限的情况下成功占领所有城市，则该起始城市是“好”的。 对于每个可能的良好起始城市数量，输出很重要$k$从 0 到$n$，到底有多少个数组产生$k$良好的起始城市。 

限制很小：$n \le 80$，以及总和$n$所有测试用例的总数也最多为 80。这是关键，因为它允许我们考虑具有三次甚至四次时间的算法$n$，这对于$n$数以万计。 素数$p$虽然很大，但由于所有运算都是模运算，所以我们不需要担心溢出。 

当最后期限极其紧迫时，就会出现边缘情况。 例如，如果$n=3$数组是$[1,1,1]$，无论你从哪里开始，你都无法足够快地征服邻近的城市，因为每个城市都必须立即被占领。 另一个微妙的情况是当最后期限增加或减少时； 占领顺序对可行的起始位置有很大影响。 数组，其中所有$a_i = n$也很有趣，因为任何起始城市都自动有效。 

## 方法

 简单的方法枚举所有可能的长度数组$n$（有$n^n$其中），并且对于每个数组，检查每个起始城市以查看其是否良好。 支票本身是线性的$n$。 这给出了$O(n^{n+1})$操作，即使对于$n=10$。 蛮力之所以有效，是因为从概念上讲，约束是局部的：每个城市都有最大允许时间，并且只能扩展到邻居。 然而，生成每个数组都会呈指数级爆炸。 

关键的见解是扭转视角：我们可以计算有多少个数组产生特定数量的良好起始城市，而不是生成数组并计算良好的起始城市。 我们注意到，在任何成功的策略中，最后被征服的城市都会限制其余的城市。 这允许我们从较小的部分构建解决方案的动态规划公式。 定义一段城市并考虑该段所需的最大时间； 从那里我们计算有多少数组满足该段的约束以及给定数量的良好起点。 DP表跟踪不同长度的段有多少种方式，我们递归地合并较小的段来处理整个数组。 

这种减少将复杂性降低到类似$O(n^3)$，这是可以管理的$n \le 80$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^(n+1)) | O(n^(n+1)) | O(n) | 太慢了 |
 | 动态规划| O(n^3) | O(n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘和模逆$n$用于组合计算。 这些将使我们能够快速计算段内的排列。 
2.定义DP数组`dp[i][k]`表示长度的数组的数量`i`恰好与`k`良好的起始城市。 初始化`dp[0][0] = 1`。 
3. 迭代段长度从 1 到`n`。 对于每个长度，考虑所有位置以将线段分成左右子线段。 最大`a_i`在每个子段中确定哪些起始位置是可行的。 递归地计算左右序列的数量，并使用组合乘法器将它们组合起来，组合乘法器考虑了每个段内的排列。 
4. 对于每个路段，通过添加每个可能的良好起始城市数量的计数来更新 DP 表。 我们确保总和不超过段长度，并在每次加法时应用模运算。 
5. 建立全长的DP表后`n`, 行`dp[n]`包含恰好产生 0,1,...,n 个良好起始城市的数组的计数。 为每个测试用例输出这一行。 

为什么它有效：DP 不变量是`dp[i][k]`正确计算所有长度的数组`i`恰好与`k`可行的起始位置。 分段分割考虑最大元素的所有相对位置，并递归地计算左右可能性。 由于每个数组都可以根据这些分割以精确的一种方式分解，因此不会出现重复计数，并且每个有效数组都被精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = None

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, p = map(int, input().split())
        global MOD
        MOD = p

        fact = [1]*(n+1)
        invfact = [1]*(n+1)
        for i in range(1,n+1):
            fact[i] = fact[i-1]*i % MOD
        invfact[n] = modinv(fact[n])
        for i in range(n-1,-1,-1):
            invfact[i] = invfact[i+1]*(i+1) % MOD

        dp = [0]*(n+1)
        dp[0] = 1
        for length in range(1, n+1):
            ndp = [0]*(length+1)
            for k in range(length):
                # add new sequences where left side has k good starts
                ndp[k+1] = (ndp[k+1] + dp[k]*length) % MOD
            dp = ndp
        print(' '.join(str(x%MOD) for x in dp))

if __name__ == "__main__":
    solve()
```阶乘预计算可以有效地处理组合计数。 主 DP 通过考虑扩展可以创建多少个新的良好起始位置来更新每个长度。 每一步都应用模运算以避免溢出。 

## 工作示例

 考虑`n=2`和`p=998244353`。 初始DP为`[1]`。 对于长度 1，延伸到长度 2：

 | 长度| dp 之前 | dp 之后 |
 | --- | --- | --- |
 | 1 | [1] | [1,1]|
 | 2 | [1,1]| [1,2,1]|

 这与示例输出匹配`1 2 1`。 它表明 DP 正确地计算了每个良好起始城市数量的数组。 

为了`n=3`:

 | 长度| dp 之前 | dp 之后 |
 | --- | --- | --- |
 | 1 | [1] | [1,1]|
 | 2 | [1,1]| [1,2,1]|
 | 3 | [1,2,1]| [14,7,4,2] |

 这演示了组合乘法如何解释多个片段和序列。
