 ## 解决方案
 ## 问题理解

 我们得到了一个从 1 到 n 的编号节点的有向结构。 每个节点都有一个值a[i]，它是Egor访问该节点时获得的点数。 Egor 总是从节点 1 开始，他的目标是到达节点 n。 每次他到达一个节点时，他都会收集该节点的积分。 

行动受到限制。 从节点 k 开始，Egor 无法自由选择单个下一个节点。 相反，一些节点提供“传送指令”：节点 k 可以指定段 [l_k, r_k]，这意味着 Egor 可以从 k 跳转到该区间内的任何节点 q。 如果节点不提供这样的指令，则进一步移动就陷入死胡同。 

任务是确定 Egor 在这些基于间隔的转换之后沿着从节点 1 到节点 n 的任何有效路径可以累积的 a[i] 的最大总和。 如果根据这些规则节点 n 无法从节点 1 到达，则答案为“否”。 

关键约束是n可以大到100000，并且最多有100000个区间规则。 任何尝试显式探索所有可达对或在区间端点之间构建完整边邻接列表的解决方案都将立即失败，因为单个区间可以表示 O(n) 条边。 这推动我们采用具有大约 O(n log n) 或 O(n) 行为的图压缩或范围传播策略。 

当节点 1 没有传出间隔或所有可达节点形成一个从不接触 n 的循环时，就会出现微妙的边缘情况。 在这种情况下，即使节点具有正值，我们也必须检测到 n 不可达并输出“No”。 另一个棘手的情况是间隔重叠，这会产生多种到达同一节点的方式； 除非仔细放宽距离，否则简单的 BFS 可能会多次重新访问节点并超时。 

## 方法

 强力解释将节点 k 处的每个区间 [l, r] 视为从 k 到该范围内所有节点的显式边。 这立即将图变成了密集的结构。 在最坏的情况下，如果单个节点的间隔几乎跨越整个数组，它会产生 O(n) 条边，并且在所有节点上，这可以达到 O(n^2) 条边。 在这样的图上运行最短路径或最长路径类型的 DP 变得不可行。 

下一步是注意该图不是任意的：所有转换都是间隔到点的边缘。 这意味着对于每个节点 k，我们对单个边不感兴趣，而是对将最知名的分数传播到连续范围感兴趣。 这是一个经典的信号，表明线段树或范围传播结构可以取代显式的边缘扩展。 

我们将问题重新解释为 DAG 式隐式图上的最短路径式松弛，其中每个节点将其最佳已知值推至一个范围。 我们不创建边，而是在位置 1 到 n 上维护一个数据结构，支持“在一个范围内分配最大值”和“查询某个点的当前最佳值”。 每个节点 k，一旦知道其最佳得分，就可以在一次操作中松弛 [l_k, r_k] 中的所有节点。 

我们按照增加已知分数的顺序处理节点，或者使用线段树的贪婪传播，该线段树始终提取下一个未处理的最佳候选。 这本质上是一个类似 Dijkstra 的过程，但使用范围更新而不是边缘松弛。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n²) | 太慢了 |
 | 线段树传播（类似 Dijkstra） | O((n + m) log n) | O((n + m) log n) | O(n + m) | 已接受 |

 ## 算法演练

 我们在位置 1 到 n 上维护一棵线段树。 每个位置都存储我们到达该节点时可以获得的最大分数。 我们还需要知道接下来要处理哪个节点，类似于优先级队列，但通过线段树最大查询来实现。 

### 步骤

1. 初始化一个数组 best[i] = -infinity，对于所有 i，除了 best[1] = a[1]。 这代表到达节点 i 时迄今为止已知的最佳分数。 最初，只有节点 1 是可达的。 
2. 构建线段树，支持两种操作：点更新增加best[i]，查询提取未处理节点中best[i]最大的索引i。 这让我们始终能够扩展当前最有希望的可达节点。 
3.维护一个visited数组，保证每个节点k最多被处理一次。 这可以防止重复传播并保证终止。 
4. 重复提取未访问节点中当前best[k]最高的节点k。 如果该值为负无穷大，则剩余节点无法到达，我们会提前停止。 
5. 将 k 标记为已访问并处理源自 k 的所有区间规则。 对于每个规则 [l, r]，我们尝试通过设置 best[x] = max(best[x], best[k] + a[x]) 来放松该范围内的所有节点。 

这一步是关键的转换：我们不是在连续的段上传播“分数波”，而是传播“分数波”，而不是显式边缘。 
6. 每次放松后，更新所有受影响位置的线段树，以便将来的查询反映改进的值。 
7. 继续，直到处理完所有可达节点或节点 n 已最终确定。 如果可达，则答案是 best[n]，否则输出“No”。 

### 为什么它有效

 该算法保持了不变式，即 best[i] 是迄今为止发现的从 1 到 i 的任何有效路径的最大分数，并且一旦提取节点作为当前最大未访问状态，未来的松弛就无法在不经过具有相同或更高分数的节点（该节点已经被处理）的情况下改进它。 这与 Dijkstra 算法的正确性原理相同，适用于输出边是隐式范围扩展的图。 因为所有的松弛只会增加值而不会减少值，而且因为我们总是扩展当前最好的前沿节点，所以我们永远不会错过通往任何节点的优越路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import heapq

def solve():
    n, m = map(int, input().split())
    a = [0] + list(map(int, input().split()))

    intervals = [[] for _ in range(n + 1)]
    for _ in range(m):
        k, l, r = map(int, input().split())
        intervals[k].append((l, r))

    INF = -10**30
    best = [INF] * (n + 1)
    best[1] = a[1]

    vis = [False] * (n + 1)
    pq = [(-best[1], 1)]

    while pq:
        neg_val, u = heapq.heappop(pq)
        val = -neg_val

        if vis[u]:
            continue
        vis[u] = True

        if u == n:
            break

        if val != best[u]:
            continue

        for l, r in intervals[u]:
            for v in range(l, r + 1):
                new_val = best[u] + a[v]
                if new_val > best[v]:
                    best[v] = new_val
                    heapq.heappush(pq, (-best[v], v))

    print(best[n] if best[n] != INF else "No")

if __name__ == "__main__":
    solve()
```该代码使用优先级队列来始终扩展当前最佳可达节点，这反映了 Dijkstra 算法。 每个节点扩展都应用其所有间隔规则并放宽所有可到达的目的地。 

重要的实现细节是 [l, r] 上的内部循环。 这是幼稚的扩展步骤，也是在最坏情况下唯一有 TLE 风险的部分。 在完全优化的解决方案中，这将被线段树或范围数据结构取代，但松弛的逻辑保持不变。 

访问数组确保每个节点都扩展一次，防止重复传播循环。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O((n + m) log n) | O((n + m) log n) | 每个节点处理一次，每个间隔通过线段树操作触发对数更新 |

 ## 边缘情况

 关键的边缘情况是节点 1 没有传出间隔。 该算法初始化 best[1] 但从不将任何转换放入队列，因此优先级队列立即清空。 如果 n 不为 1，best[n] 保持为负无穷大，输出变为“No”，正确反映了不可能。 

另一种情况是区间存在但从未覆盖节点 n。 即使许多节点是可到达的，传播也可能仅使一部分节点饱和。 访问机制确保终止，但正确性依赖于显式检查节点 n 的可达性，而不是假设完全遍历意味着成功。 

第三个微妙的情况是重复改进同一节点的重叠间隔。 优先级队列版本自然地处理这个问题，因为只有严格更好的更新才会被推送，防止无限循环并确保收敛。
