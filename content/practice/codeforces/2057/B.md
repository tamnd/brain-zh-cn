 ## 解决方案
 ## 问题理解

 我们被要求帮助大猩猩使用特定的删除操作有效地清除数组。 该操作适用于任何连续的子数组：您选择该子数组中的最小值，然后从所选段中删除该最小值的每个出现位置。 当元素被删除并且索引重新编号时，数组会缩小。 目标是执行尽可能少的此类操作，直到数组为空。 此外，我们最多可以更改`k`数组中的元素可以更改为我们选择的任何值，这使我们能够在执行这些操作之前简化数组。 

输入提供多个测试用例。 每个测试用例由数组长度组成`n`, 变化次数`k`，以及数组本身。 每个测试用例的输出是最佳替换后所需的最少操作数。 鉴于总和`n`所有测试用例的 ≤ 10^5，我们必须高效地处理每个测试用例，最好是在线性或接近线性的时间内。 这排除了考虑所有可能的删除序列的强力方法，这将是指数级的。 

当所有数组元素已经相等或者当`k`足够大以使阵列均匀。 例如，与`a = [2, 3, 2]`和`k = 1`，改变中间`3`到`2`允许在一次操作中清除整个数组。 简单的方法可能只是简单地计算任意子数组中的最小值，而不考虑可能的替换，这将无法产生最佳答案。 

当数组在值之间频繁交替时，会出现另一个微妙之处。 例如，`a = [1, 2, 1, 2, 1]`和`k = 2`允许我们替换其中的两个`2`与`1`s、合并差距并减少操作次数。 粗心的做法忽视了价值`k`会多算操作。 

## 方法

 暴力方法将尝试在每个可能的连续子数组上模拟删除操作，尝试所有删除和替换序列。 这种方法理论上是正确的，但不切实际。 对于长度的数组`n`，子数组的数量为 O(n^2)，并且跟踪删除以组合方式增长。 即使大小为 1000 的小数组也会导致数百万种可能性，考虑到限制，这是不可接受的。 

简化问题的关键观察是，所需的操作数量取决于我们从左到右顺序扫描数组时遇到的不同值的数量，计算一个值相对于前一个元素发生变化的次数。 如果我们明智地选择，相同数字的每个“段”都可以在一次操作中删除。 通过更改为`k`元素，我们可以合并其中一些段以减少操作总数。 

如果数组中最小的数是`x`，每次我们遇到一个不等于的数字`x`，它开始一个新的段，这可能需要单独的操作。 因此，最佳策略是将数组视为由所选“锚”值（通常是第一个元素）的出现分隔的序列，并计算存在多少个不同数字的段。 我们可以使用替换来减少这些段的数量。 如果`k`如果足够大，可以改变段之间的所有不同元素，我们可以将操作数减少到 1。否则，我们应用贪心方法：每次替换可以删除一个额外的段，从而减少总操作数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`以及允许的更改`k`。 初始化操作次数计数器`ops = 0`。 
2. 选择第一个元素`first = a[0]`作为锚定值。 该元素将指导我们对段的计数。 这个选择之所以有效，是因为我们总是可以更改其他元素来匹配它。 
3. 从第一个元素开始遍历数组。 对于每个元素`a[i]`，检查是否等于`first`。 如果是，则继续； 它属于当前段。 如果不同则递增`ops`加 1 以考虑需要删除的部分。 跳过下一个`k`元素，模拟替换它们以匹配`first`。 每个替换有效合并最多`k`将连续的不同元素插入由锚定的段中`first`。 
4. 处理完数组后，自增`ops`加 1 以说明初始段或数组以不同值开头。 输出`ops`作为最小操作次数。 
5. 对每个测试用例重复此操作。 

为什么有效：每个操作都会删除连续块中当前段最小值的所有实例。 通过贪婪地选择一个锚值并替换最多`k`行中的元素，我们最大化每次操作删除的元素数量。 这一策略确保我们对每个不可更改的段永远不需要一次以上的操作，并且我们合并尽可能多的段`k`允许。 不变的是，在每次操作和替换之后，剩余段的数量反映了可实现的最小删除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        ops = 0
        i = 0
        first = a[0]
        
        while i < n:
            if a[i] == first:
                i += 1
                continue
            ops += 1
            i += k
        print(max(1, ops))

solve()
```此代码读取每个测试用例并初始化操作计数器。 我们迭代数组，跳过等于锚点的元素。 当找到不同的元素时，我们增加操作计数并跳过下一个`k`元素，模拟它们的转换。 我们输出最大值 1 和`ops`处理已经统一的数组。
