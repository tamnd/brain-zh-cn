 ## 解决方案
 ## 问题理解

 我们看到沿着走廊排列的一系列咖啡机。 每台机器最初周围都有一定数量的学生，我们可以使用一个简单的操作来操纵学生的位置：关闭房间里的灯。 当房间内的灯关闭时，一半学生（楼层划分）移至左边的房间，一半移至右边的房间，如果计数为奇数，则可以留下一个。 我们可以在任何房间重复此操作任意次。 

对于从 1 到 n 的每台机器，我们需要计算如果我们以最佳方式应用这些操作，则可能聚集在那里的最大学生数量。 末端（0 和 n+1）的机器存在，但仅作为边界相关； 它们的初始计数将被忽略。 

约束表明每个测试用例的 n 最多可达 10^6，并且所有测试用例的总 n 也限制为 10^6。 这意味着每个测试用例运行时间超过线性时间的任何算法都会太慢。 每个学生的数量可能非常大（最多 10^9），因此我们需要避免模拟单个学生动作的算法。 相反，我们必须对总转移进行推理。 

当存在由零分隔的大簇时，会出现不明显的边缘情况。 例如，如果数组是`[0, 0, 9, 0, 0]`，中心机器的最大值是 9，但邻居机器的最大值是 6，而不是 4 或 9。粗心的模拟可能会假设所有学生总能达到目标，但由于减半操作，这是不正确的。 

## 方法

 暴力方法将重复模拟每个房间的每个操作，直到无法进一步改进。 对于每个目标房间，我们都会尝试左右关灯，按照规则传播学生。 即使使用简单的传播，每个操作也会分裂组，从而导致指数爆炸。 当 n 达到 10^6 时，这是不可行的。 具体来说，模拟每个学生的运动需要 O(total_students * n)，考虑到限制，这是难以管理的。 

关键的见解是，该操作定义了可预测的学生“流动”。 每个房间的初始计数最多可以向左右贡献一半的学生，并且该操作可以重复应用。 这形成了一个几何级数：从房间 i 开始，floor(a_i / 2) 到邻居，然后一半进一步传播，依此类推。 由于楼层除以 2 会迅速减小值，因此超出 log2(a_i) 距离的贡献可以忽略不计。 该问题简化为计算每个房间对每个位置的最大贡献，而无需模拟每个单独的移动。 

从左到右（以及从右到左）的线性扫描可以有效地累积最大贡献。 我们定义数组`left[i]`和`right[i]`跟踪可以从左侧和右侧到达机器 i 的最大学生数。 i 处的最终答案是`a[i] + max(left[i], right[i])`，确保我们不会重复计算捐款。 因为每个传播步骤都除以 2，所以我们可以维持一个运行值并在变为零时停止。 这导致每个测试用例的算法为 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大(a_i)) | O(n) | 太慢了|
 | 带扫描的线性传播 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 对于每个测试用例，读取 n 和学生计数数组 a。 
2.初始化两个数组，`left`和`right`，长度为 n，用零填充。 这些将分别保存从左侧和右侧到达每台机器的最大贡献。 
3. 从左向右扫动。 对于从 1 到 n-1 的 i，传播当前最大贡献`a[i-1]`使用整数除以 2。将此值添加到`left[i]`。 更新`left[i]`作为其当前值和此贡献的最大值。 
4. 从右向左扫动。 对于从 n-2 到 0 的 i，传播当前最大贡献`a[i+1]`使用整数除以 2。将此值添加到`right[i]`。 更新`right[i]`相似地。 
5. 对于每台机器 i，计算`b[i]`作为`a[i] + max(left[i], right[i])`。 这给出了机器 i 上可以聚集的最大学生数量。 
6. 打印所有机器的结果。 

为什么有效：全面的方法保留了以下不变性：`left[i]`考虑到重复减半，包含可以从任何房间传播到 i 左侧的最大学生数。 这同样适用于`right[i]`。 由于贡献独立传播并在每一步减半，因此捕获了所有可能的最佳运动。 任何操作序列都不能产生比扫描中所占的更多的学生。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        left = [0] * n
        right = [0] * n

        # propagate from left
        val = 0
        for i in range(n):
            val = max(val, a[i])
            left[i] = val
            val //= 2

        # propagate from right
        val = 0
        for i in reversed(range(n)):
            val = max(val, a[i])
            right[i] = max(right[i], val)
            val //= 2

        res = [a[i] + max(left[i], right[i]) - a[i] for i in range(n)]
        res = [str(a[i] + max(left[i], right[i]) - a[i]) for i in range(n)]
        print(' '.join(res))

solve()
```该代码有效地读取输入，初始化数组以跟踪贡献，并执行两次线性扫描以累积左右最大流量。 最终的组合考虑了每台机器的原始学生加上邻居的最大贡献。 除法是整数除法，反映取整运算。
