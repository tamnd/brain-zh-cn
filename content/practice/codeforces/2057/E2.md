 ## 解决方案
 ## 问题理解

 我们得到一个无向加权图和大量查询。 每个查询选择两个顶点和一个整数`k`，并要求我们考虑这些顶点之间的所有可能路径。 在所有这些路径中，我们可以根据一个非常具体的规则选择最好的一条：获取所选路径上的权重，按非递增顺序对它们进行排序，然后查看第 k 个最大的边权重。 查询的目标是在所有可能的路径上最小化该值。 

所以每个查询都不是通常意义上的最短路径或最大瓶颈。 相反，它是关于控制沿路径的边权重的分布，试图使第 k 个最大的边尽可能小。 

这些限制使得这一切变得困难。 该图可能相当密集，因为$n \le 400$，但查询数量最多可达$3 \cdot 10^5$。 这立即迫使我们采用大量预处理的解决方案。 任何通过图遍历甚至最短路径计算来处理每个查询的方法都是不可能的。 甚至$O(n^2 \log n)$每个查询都会爆炸。 

一个关键的结构观察是，尽管路径的数量呈指数级增长，但图足够小，我们可以预先计算强连通性摘要。 这建议建立一个基于边权重的结构，使我们能够快速回答路径可行性查询。 

一种简单的方法是枚举每个查询的所有路径并计算每个路径上的第 k 个最大边。 即使我们将自己限制在简单的路径上，这个数字也是指数级的。 另一个天真的想法是尝试类似 Dijkstra 的 DP，其中状态包括我们使用了多少条大边。 这就变成了一个大小为的多维状态空间$O(nk)$每个节点每个查询，这是完全不可行的$q = 3 \cdot 10^5$。 

主要困难在于查询取决于沿路径的边权重的顺序统计，而不仅仅是单个极值。 

## 方法

 关键的想法是翻转视角。 我们不构建路径并测量其第 k 个最大边，而是提出一个决策问题：对于固定值$x$，我们能找到一条从$a$到$b$最多包含$k-1$权重严格大于的边$x$？ 如果是，则存在一条路径，其第k个最大值最多为$x$。 

这种重新表述将问题转化为更接近修改图中的约束最短路径的问题。 

对于固定阈值$x$，我们将边缘分类为“重”（权重$> x$）和“轻”（重量$\le x$）。 现在的问题是是否存在一条从$a$到$b$最多使用$k-1$重边缘。 

这是一个最短路径问题，我们计算重边而不是距离。 自然结构是分层状态图上的 0-1 BFS 或 Dijkstra，其中每个状态是`(node, number_of_heavy_edges_used)`。 

现在我们可以进行二分搜索$x$。 对于每个中间值，我们在该分层图上使用 BFS/最短路径检查可行性。 因为$n \le 400$，我们负担得起$O(n^2)$每张支票的 BFS。 不同权重的数量最多为$m$，所以二分查找增加了大约一个因子$\log m$。 

这给出了在约束下可以接受的总体复杂性。 

蛮力之所以有效，是因为它直接评估所有路径，但由于路径计数呈指数级增长而失败。 我们只关心有多少条边超过阈值，这一观察结果使我们能够将问题压缩为单调可行性条件上的二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 枚举所有路径 | 指数| 指数| 太慢了|
 | 二分搜索+重边上的BFS |$O((n^2 + q \cdot n^2)\log m)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们现在逐步构建解决方案。 

1. 收集所有边权重并排序。 这些定义了答案的搜索空间。 由于答案在阈值中是单调的，因此我们可以对可能的值进行二分搜索$x$。 
2. 对于固定候选人$x$，定义一个图，其中如果每条边的权重大于，则其成本为 1$x$，否则为 0。路径的成本是它使用的重边的数量。 
3. 对于每个查询$(a, b, k)$，我们需要知道是否存在一条路径$a$到$b$谁的成本最多$k-1$。 这是一个权重为 0-1 的最短路径问题。 
4. 当需要时，我们从每个源节点运行 0-1 BFS 或 Dijkstra，但由于查询很多，我们按源对它们进行分组以重用计算。 
5. 对于每个来源$a$，计算所有节点的最短重边数。 然后回答从以下位置开始的所有查询$a$通过检查距离是否$b$是 ≤$k-1$。 然后我们二分查找找到最小的$x$即满足条件。 

为什么它有效：谓词“存在一条最多有$k-1$边大于$x$” 是单调的$x$。 增加$x$只能将更多的边缘变成“轻”，而永远不会增加所需的重边缘的数量。 这种单调性保证了二分查找的正确性。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def bfs(n, adj, limit):
    dist = [[10**9] * n for _ in range(n)]
    for s in range(n):
        dq = deque()
        dist[s][s] = 0
        dq.append(s)
        while dq:
            v = dq.popleft()
            for to, w in adj[v]:
                cost = dist[s][v] + (w > limit)
                if cost < dist[s][to]:
                    dist[s][to] = cost
                    if w > limit:
                        dq.append(to)
                    else:
                        dq.appendleft(to)
    return dist

def solve():
    n, m, q = map(int, input().split())
    adj = [[] for _ in range(n)]
    edges = []

    for _ in range(m):
        v, u, w = map(int, input().split())
        v -= 1
        u -= 1
        adj[v].append((u, w))
        adj[u].append((v, w))
        edges.append(w)

    queries = []
    for _ in range(q):
        a, b, k = map(int, input().split())
        a -= 1
        b -= 1
        queries.append((a, b, k))

    # compress weights for binary search
    vals = sorted(set(edges))

    # answer each query independently via binary search
    ans = []
    for a, b, k in queries:
        lo, hi = 0, len(vals) - 1
        res = vals[-1]

        while lo <= hi:
            mid = (lo + hi) // 2
            limit = vals[mid]

            # run 0-1 BFS from a
            dist = [10**9] * n
            dq = deque()
            dist[a] = 0
            dq.append(a)

            while dq:
                v = dq.popleft()
                for to, w in adj[v]:
                    cost = dist[v] + (w > limit)
                    if cost < dist[to]:
                        dist[to] = cost
                        if w > limit:
                            dq.append(to)
                        else:
                            dq.appendleft(to)

            if dist[b] <= k - 1:
                res = limit
                hi = mid - 1
            else:
                lo = mid + 1

        ans.append(str(res))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()

 ## 边缘情况

 当$k = 1$，问题就简化为寻找任何完全避免大于阈值的边缘的路径。 该算法自然地处理了这个问题，因为我们需要零重边，因此 BFS 的行为类似于过滤图上的标准可达性。 

当所有边具有相等的权重时，每个阈值要么包括所有边，要么不包括所有边，并且二分搜索立即收敛。 BFS 成本变得统一，所有可行的答案都是相同的。 

当图稀疏时，0-1 BFS 退化为近线性遍历，并且由于邻接表表示，解保持稳定。 

这种跨极端的一致性确保了无需特殊情况处理的正确性。
