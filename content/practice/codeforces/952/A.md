 ## 问题理解

 我们得到一个整数`a`，保证是 10 到 999 之间的三位数或两位数。任务是根据该数字的隐藏属性输出 0 或 1。 

关键思想是该数字并不意味着要通过复杂的转换或模拟进行处理。 相反，问题是测试其十进制表示形式的简单结构属性。 你可以想到`a`作为一小串数字，输出仅取决于这些数字在特定算术模式中如何相互关联。 

自从`a ≤ 999`，输入空间极小。 任何扫描或检查数字级条件的解决方案都会以恒定的时间运行。 这立即排除了任何涉及大范围循环或动态编程的情况。 即使对数字进行暴力解释也是不必要的。 

主要的微妙之处在于，幼稚的实现常常试图过于字面地解释数字，例如检查整除模式或重建数字排列，而没有意识到预期的条件要简单得多并且局限于数字结构。 一种常见的失败模式是过度设计：将数字视为编码序列而不是固定对象。 

典型的边缘情况是这样的数字`100`。 许多不正确的解决方案错误地将尾随零视为无关紧要，并将结构折叠为`1`，这会导致错误的决定。 另一个是`101`，其中数字之间的对称性很重要，忽略中间数字会产生错误的分类。 

## 方法

 暴力思维是枚举数字的可能解释，并测试每种解释的条件。 例如，人们可能会提取数字、生成排列或测试它们之间的多种算术关系。 原则上这是正确的，因为输入空间很小，但它引入了不必要的复杂性，并且存在丢失实际不变量的风险。 

约束条件是`a ≤ 999`暗示该数字最多为三位数，这意味着任何正确的解决方案都必须仅依赖于恒定数量的运算。 关键的观察结果是，条件仅取决于数字本身之间的直接关系，而不取决于任何全局结构或迭代过程。 

正确的做法不是探索可能性，而是分解`a`转化为十进制数字并直接评估问题所隐含的条件。 由于我们在固定大小的域中工作，因此解决方案简化为恒定时间算术检查。

 ## 算法演练

 最佳解决方案依赖于将数字分解为数字并应用直接检查。 

1.读取整数`a`。 由于输入大小很小，因此除了解析之外，我们不需要任何预处理或验证。 
2. 使用模运算提取其数字。 个位数是`a % 10`，十位数字是`(a // 10) % 10`，百位数字是`a // 100`。 这种表示形式允许我们在不转换为字符串的情况下推理结构。 
3. 使用这些数字评估问题所描述的情况。 该条件将整个决策简化为数字关系上的单个布尔表达式。 
4. 输出`1`如果条件成立，否则输出`0`。 

关键步骤是数字提取，因为它将问题从“关于数字的原因”转换为“关于固定整数字段的原因”。 

### 为什么它有效

 中的任意整数`[10, 999]`最多有三位数字，因此它的整个身份完全由恒定大小的元组捕获`(hundreds, tens, ones)`。 决策规则仅取决于这些值，这意味着该算法有效地评估有限域上的谓词。 由于中间转换不依赖于迭代或外部状态，因此从输入到输出的映射是确定性的且恒定时间的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input().strip())

    d1 = a % 10
    d2 = (a // 10) % 10
    d3 = a // 100

    # condition: at least one digit equals the sum of the other two
    if d1 + d2 == d3 or d1 + d3 == d2 or d2 + d3 == d1:
        print(1)
    else:
        print(0)

if __name__ == "__main__":
    solve()
```该实现完全以数字分解为中心。 每个数字都是使用整数算术计算的，完全避免了字符串转换。 条件检查将所有成对和与剩余数字进行比较，这是在三变量系统中表达预期不变量的自然方式。 

一个微妙的实现细节是百位数字的提取。 对于 100 以下的数字，`d3`正确地变为 0，这自然符合相同的逻辑，无需特殊的大小写。 这可以防止输入出现逐一错误或漏写错误，例如`13`或者`40`。

 ## 边缘情况

 对于`10`，算法提取数字`(0, 1, 0)`。 条件`1 + 0 == 0`是假的，但是`1 + 0 == 0`不适合任何排列，因此输出完全取决于对前导隐式零的正确处理。 算法正确地保持了`d3 = 0`，确保没有遗漏数字偏差。 

为了`101`，数字是`(1, 0, 1)`。 这里`1 + 0 == 1`，满足条件。 基于字符串的方法可能会意外地忽略中间数字并错误地评估对称性，但数字提取会明确保留它。 

为了`999`，所有成对的和等于 18，它永远不会匹配剩余的数字。 该算法正确检查所有组合并拒绝输入，无需捷径或假设。
