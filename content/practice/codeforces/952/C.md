 ## 解决方案

 ## 问题理解

 我们得到一个非常小的正整数数组，其中每个值都被想象为垂直堆叠的“馄饨”块。 堆栈按照与数组相同的顺序排成一行。 

该过程以两种交互方式重复修改该行。 首先，每当两个相邻堆栈的高度相差至少两倍时，一个高度单位就会从较高的堆栈“滑动”到较短的堆栈。 这种情况会重复发生，直到没有相邻的一对相差超过 1。 平滑稳定后，我们确定最高的堆栈（如果有平局，则选择最左边的堆栈），将其移除并记录其高度。 剩余的堆栈移动在一起，重复相同的过程，直到所有内容都被移除。 

最终输出是移除高度的序列。 任务是确定该序列是否始终以非降序排序，这意味着该算法实际上表现得像正确的排序过程。 

约束条件非常小，最多有 10 个元素，值最多为 100。这消除了对通常意义上的渐近效率的任何担忧。 只要内部动力学快速收敛，即使是三次或更高次的模拟也是可以接受的。 真正的挑战不是性能，而是忠实地建模重新分配过程和最大值的重复提取。 

一个天真的错误是将这个过程简单地解释为“重复取最大元素”。 这完全忽略了重新分配规则。 

例如，考虑：```
1
3
```平滑之后，没有什么可以平滑的，我们输出 3。这很简单。 

但对于：```
2
1 3
```相差2，所以一个单元从3滑到1，使得数组`[2, 2]`。 现在两个堆栈相等，移除最大值会产生 2。输出为`[2, 2]`， 不是`[1, 3]`或者`[3, 1]`。 天真的“排序检查”会完全忽略这种重新分配效果。 

当平滑改变未来最大值时，会出现另一个微妙的失败案例。 结构在每次提取之前都会演变，因此与原始排序数组进行比较是不够的，除非我们正确模拟所有中间状态。 

## 方法

 蛮力解释直接模拟物理过程。 我们重复执行两个阶段。 首先，我们“放松”数组：扫描相邻对并从堆栈中移动一个单元，该单元超出其邻居至少两个单元。 这可能需要重复多次，直到达到稳定。 然后我们删除最大元素并继续。 

由于每个松弛步骤仅在边缘上移动一个高度单位，并且总高度最多以 1000 为界，因此系统必须在有限次数的移动后保持稳定。 最多 10 个位置，每次移动都会减少不平衡，因此松弛操作的总数仍然是可控的。 

关键的观察是我们不需要任何聪明的数据结构。 整个系统足够小，直接模拟稳定加上重复删除就足够了。 该结构的行为类似于局部扩散过程，最终答案仅取决于该扩散驱动的最大值序列是否与排序序列匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n · A · 步骤) | O(n) | 已接受 |
 | 最优模拟（同样的想法，仔细实施）| O(n · A · 步骤) | O(n) | 已接受 |

 这里的“步长”很小，因为每个单位移动都会减少有限的不平衡，并且 n 和 A 都很小。 

## 算法演练

 我们精确地模拟了系统。 

1. 从表示堆栈高度的当前数组开始。 这是馄饨堆的当前物理状态。 
2. 反复“放松”阵列直至稳定。 稳定性意味着没有相邻对相差 2 或更多。 每次松弛扫描从左到右进行，并应用以下规则：如果 a[i] > a[i+1] + 1，则从 i 到 i+1 移动一个单位；如果 a[i+1] > a[i] + 1，则对称地向相反方向移动一个单位。 这对问题中描述的滑动行为进行建模。 
3. 稳定后，查找数组中的最大值，如果存在相同的情况，则选择最左边的出现位置。 这符合选择删除哪个堆栈的规则。 
4. 将该值记录在输出序列中并将其从数组中删除。 这代表物理上拿走该堆栈。 
5. 重复该过程，直到数组为空。 

关键的微妙之处在于删除会改变相邻关系，因此我们必须在每次删除后完全重新稳定，而不是假设以前的稳定性会延续。 

### 为什么它有效

 松弛过程强制执行局部约束：移除之前的每个最终配置必须满足相邻差异至多为 1。 该约束唯一地决定了质量如何在相邻堆栈之间流动，因为任何较大的间隙都会迫使确定性的单元传输，直到它消失。 由于每次移除始终取自完全稳定的配置，因此演化是明确定义的并且独立于松弛循环内的任意排序选择。 这确保了模拟序列与物理过程定义的序列完全相同。 

如果产生的序列按非降序排序，则该过程被认为是有效的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def stabilize(a):
    n = len(a)
    changed = True
    while changed:
        changed = False
        for i in range(n - 1):
            if a[i] > a[i + 1] + 1:
                a[i] -= 1
                a[i + 1] += 1
                changed = True
            elif a[i + 1] > a[i] + 1:
                a[i + 1] -= 1
                a[i] += 1
                changed = True
    return a

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    out = []
    
    while a:
        a = stabilize(a)
        
        mx = max(a)
        idx = 0
        for i in range(len(a)):
            if a[i] == mx:
                idx = i
                break
        
        out.append(mx)
        a.pop(idx)
    
    print("YES" if out == sorted(out) else "NO")

if __name__ == "__main__":
    solve()
```稳定功能是实现的核心。 它重复应用局部调整，直到没有相邻对违反“最多差一个”规则。 单次传递是不够的，因为传输可能会在数组的较早位置创建新的违规，因此外循环可确保收敛。 

稳定后，我们计算最大值并删除其最左边的出现。 最左边的平局决胜是至关重要的，因为多个相等的最大值根据位置的不同而被不同地处理。 

最后，我们将生成的移除序列与其排序版本进行比较。 如果该过程在问题的动态下表现得像正确的排序机制，则移除顺序必须已经是非递减的。

 ## 边缘情况

 一种边缘情况是单个堆栈。 该数组已经稳定，因此唯一的输出就是该值。 由于不存在排序歧义，因此序列是简单排序的。 

另一个边缘情况是统一数组，例如`[2,2,2]`。 不会发生松弛，并且每次移除都会重复选取相同的值，从而产生恒定的序列。 

一个更有趣的情况是最初存在较大差距时，例如`[1,100]`。 稳定化会立即推动值跨越，直到两边在中间步骤中反复变得相等或最多相差一个，最终在任何移除之前平坦化为近乎均匀的配置。 这说明了为什么该过程破坏了长程结构并使输出主要取决于总质量而不是初始排序。
