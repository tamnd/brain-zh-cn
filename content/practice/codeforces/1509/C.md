 ## 解决方案
 ## 问题理解

 我们得到了所有理事会成员的跑步速度。 我们可以选择它们运行的​​任何顺序。 

对于所选顺序的每个前缀，我们都会查看所有已参加的跑步者。 该前缀的差异是迄今为止看到的最大和最小速度之间的差异。 第一个跑步者的贡献始终为零，因为最大值和最小值相同。 

我们的目标是安排跑步者，使所有前缀差异的总和尽可能小。 

输入只是一系列速度。 输出是选择最佳排序后可实现的最小差异总和。 

最重要的观察结果来自这样一个事实：差异仅取决于已选择的跑步者中当前的最小值和最大值。 一旦出现两个极端，该范围内跑步者的确切内部顺序就不再重要。 

约束条件是$n \le 2000$。 对所有排列进行强力搜索是完全不可能的，因为有$n!$可能的订单。 即使是对子集的动态规划也需要$2^n$国家，这也是遥不可及的。 和$n=2000$，围绕解决方案$O(n^2)$是现实的，同时$O(n^3)$已经太慢了。 

有几种容易被忽略的边缘情况。 

考虑：```
1
7
```答案是：```
0
```只有一名跑步者，因此所有差异为零。 

考虑：```
3
5 5 5
```答案是：```
0
```所有速度都是相同的。 每个前缀都有最大值等于最小值。 

考虑：```
3
1 2 100
```一个幼稚的策略可能会将跑步者按排序顺序排列。 差异变为：```
0 + 1 + 99 = 100
```但最佳顺序是：```
2, 1, 100
```给予：```
0 + 1 + 99 = 100
```在此示例中，两者恰好匹配，但在较大的情况下，最佳排序通常不是简单的排序顺序。 我们需要一种能够全局最小化累积成本的方法。 

## 方法

 强力解决方案将尝试所有可能的跑步者顺序。 对于每个排列，我们可以从左到右扫描，保持当前的最小和最大速度，计算每个差异，并保留最小的总数。 

这是有效的，因为它直接检查每个可行的安排。 

问题是排列的数量。 和$n=2000$， 有$2000!$可能的订单数量是一个天文数字。 即使是为了$n=15$，穷举搜索已经不可行了。 

为了找到更好的方法，让我们对速度进行排序。 

假设排序后的速度为：$$a_0 < a_1 < \cdots < a_{n-1}$$考虑逐步建立选定的跑步者组。 排序后，任何已选择的跑步者集合都必须在排序数组中占据一定的间隔。 如果我们知道所选的跑步者正是位置之间的跑步者$l$和$r$，那么他们当前的差异很简单：$$a_r - a_l$$现在想象一下向后构建最终的顺序。 

在某些阶段，我们仍然需要对所有间歇跑者进行排名$[l,r]$。 该区间内最终出现的最大差异正是：$$a_r - a_l$$当我们决定最后添加哪个端点时，剩下的问题就变成了较小的区间之一$[l+1,r]$或者$[l,r-1]$。 

这种区间结构建议在范围上进行动态规划。 

让$$dp[l][r]$$是构建排序位置位于的所有跑步者时所贡献的最小额外差异$[l,r]$。 

当间隔$[l,r]$包含多个跑步者，当前范围宽度$$a_r-a_l$$必须只支付一次，然后我们以较小的间隔继续。 

这给出了递归式：$$dp[l][r] = (a_r-a_l) + \min(dp[l+1][r], dp[l][r-1])$$基本情况是：$$dp[i][i]=0$$因为单个跑步者不会造成差异。 

答案是$dp[0][n-1]$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot n)$|$O(n)$| 太慢了|
 | 间隔上的最佳 DP |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 读取速度并对它们进行排序。 
2. 创建二维DP表其中`dp[l][r]`表示排序间隔所需的最小总差异贡献`l`到`r`。 
3. 将所有单元素间隔初始化为零，因为单个跑步者的差异为零。 
4. 按长度递增的顺序处理间隔。 
5. 对于一个间隔`[l, r]`，计算其宽度：$$a_r-a_l$$当间隔完全呈现时，该宽度必须出现一次。 
6. 支付此宽度后，最后添加左端点或右端点。 

如果最后添加左端点，则之前的状态为`[l+1,r]`。 

如果最后添加了右端点，则之前的状态为`[l,r-1]`。 
7. 选择这两种可能性中更好的一个：$$dp[l][r] = (a_r-a_l) + \min(dp[l+1][r],dp[l][r-1])$$8. 继续直到整个间隔`[0,n-1]`已经计算出来了。 
9. 输出`dp[0][n-1]`。 

### 为什么它有效

 排序后，已合并的每组跑步者都对应于排序数组的连续区间。 

对于间隔$[l,r]$，当整个间隔变为活动状态时造成的差异恰好是$a_r-a_l$。 此时，两个端点之一必须是最后添加的。 删除最后添加的端点会留下任一间隔$[l+1,r]$或间隔$[l,r-1]$。 

递归探索了两种可能性并保留了更便宜的一种。 由于每个有效的构造序列最终都会减少到单个元素间隔，并且每个转换都会解释该阶段引入的确切差异，因此 DP 会计算最小可能的总差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = sorted(map(int, input().split()))

    dp = [[0] * n for _ in range(n)]

    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1
            dp[l][r] = (a[r] - a[l]) + min(
                dp[l + 1][r],
                dp[l][r - 1]
            )

    print(dp[0][n - 1])

solve()
```第一步对速度进行排序。 排序后，每个相关状态都变成一个连续的区间，这是解决方案的关键结构属性。 

DP 表存储所有间隔的答案。 单元素间隔保持为零，因为当仅存在一种速度时不存在差异。 

外循环通过增加长度来处理间隔。 这保证了计算时`dp[l][r]`， 两个都`dp[l+1][r]`和`dp[l][r-1]`已经计算出来了。 

递归式直接与证明相符。 间隔宽度`a[r] - a[l]`支付一次，然后选择之前两个可能间隔中较好的一个。 

所有值都适合 Python 整数。 最大可能的答案大约是$n \cdot 10^9$，这远低于 Python 的限制。

 ## 边缘情况

 考虑：```
1
7
```排序后的数组仅包含一个元素。 DP 永远不会进入区间扩展循环。`dp[0][0]`保持为零，立即返回。 输出是：```
0
```考虑：```
3
5 5 5
```每个区间宽度为零。 

例如：```
dp[0][1] = 0
dp[1][2] = 0
dp[0][2] = 0
```最终答案仍然为零，正确反映了每个前缀具有相同的最大和最小速度。 

考虑：```
2
1 10
```唯一的非平凡区间是`[0,1]`。 

其宽度为：```
10 - 1 = 9
```两个较小的区间都是成本为零的单个元素，因此：```
dp[0][1] = 9
```答案正是全套的差异。 

考虑：```
4
1 2 3 100
```DP 探索了缩小每个间隔的两种方法。 它不承诺固定的顺序，例如排序顺序。 循环会在每个时间间隔自动选择更便宜的端点移除，从而保证全局最优的总差异，而不是局部有吸引力的安排。
