 ## 解决方案
 ## 问题理解

 我们被要求将一组学生排成一排，以使上镜的连续配对的数量最大化。 如果一对的平均身高是整数，那么他们就很上镜。 输入由多个测试用例组成。 每个测试用例都给出一个代表学生身高的整数列表。 对于每个测试用例，输出必须是这些高度的排列，以最大化上镜对的数量。 

主要观察结果是，如果两个数字都是偶数或奇数，则两个数字具有整数平均值。 这立即将问题简化为简单的分类：我们希望连续的数字共享相同的奇偶校验。 所有测试用例的高度总和以 2000 为界，因此相对于每个测试用例的高度数以线性时间运行的算法就足够了。 

可能棘手的边缘情况包括所有数字均为偶数、所有数字均为奇数或只有一个奇偶校验的数字。 例如，如果高度是`[2, 4, 6]`，任何顺序都会产生所有上镜对。 如果高度是`[1, 2, 3]`，需要仔细安排以最大化连续对。 

## 方法

 强力方法是生成高度列表的所有排列，计算每个排列的上镜连续对的数量，并选择具有最大计数的一个。 为了`n`直到 2000，这显然是不可行的，因为它具有阶乘时间复杂度。 即使是为了`n=10`，有 360 万种排列。 

关键的见解是上镜特性仅取决于奇偶性。 通过将数字分为奇数和偶数两组，我们可以确保同一组中的每一对连续数字都是上镜的。 这将问题简化为简单的排序或分组任务。 最简单的方法是输出所有偶数，然后输出所有奇数（反之亦然）。 同一奇偶校验组内的任何两个连续数字都将是上镜的，并且无法在相反奇偶校验的数字之间创建额外的上镜对。 这保证了最佳安排。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 奇偶分组 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取学生人数`n`以及他们的身高列表。 
2. 初始化两个空列表：一个用于奇数高度，一个用于偶数高度。 
3. 迭代高度列表。 如果高度是奇数，则将其附加到奇数列表中。 如果是偶数，则将其添加到偶数列表中。 
4. 连接偶数列表和奇数列表。 这种排序确保每组中的所有连续数字都具有相同的奇偶性，从而最大化上镜对的数量。 
5. 输出串联列表。 

工作原理：相同奇偶校验的连续对总是产生整数平均值。 通过将所有偶数和所有奇数分组在一起，我们保证了此类对的最大数量。 任何将不同奇偶性的数量交错的尝试都不能增加上镜对的数量，因此该策略是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    heights = list(map(int, input().split()))
    odd = []
    even = []
    for h in heights:
        if h % 2 == 0:
            even.append(h)
        else:
            odd.append(h)
    result = even + odd
    print(" ".join(map(str, result)))
```该解决方案使用有效地读取输入`sys.stdin.readline`。 它通过奇偶校验分隔高度并连接列表。 这种排序保证了上镜的连续对的最佳数量。 边界条件，例如所有数字是偶数或奇数，都是自然处理的。

 ## 边缘情况

 如果所有高度都相同，算法会将它们放入原始组中，自动生成最大数量的上镜对。 例如，输入`[2, 4, 6]`结果`[2,4,6]`，有两个上镜对`(2,4)`和`(4,6)`。 

如果某一奇偶校验仅存在一个高度，则将其放置在串联的末尾，这是最佳的。 为了`[1,2,4]`, 偶数`[2,4]`首先放置的是单奇数`1`。 上镜的一对`(2,4)`被计数，奇数不可能有额外的对。
