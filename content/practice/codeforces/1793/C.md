 ## 解决方案
 ## 问题理解

 我们给出了从 1 到 n 的整数排列。 我们的任务是找到一个连续的子段，其中第一个和最后一个元素既不是该子段的最小值也不是最大值。 如果不存在这样的子段，我们必须输出-1。 

排列很重要，因为它只包含从 1 到 n 的所有整数一次。 这立即告诉我们全局最小值是 1，全局最大值是 n。 如果两端都不是局部极值，则任何长度为 3 或以上的子段都可能满足该条件。 然而，在严格的递增或递减序列中，没有子段满足该属性，因为末尾的任何元素将始终是该子段的最小值或最大值。 

约束很严格：n 最多可以为 2×10^5，并且最多可以有 10^4 个测试用例。 这意味着检查所有 O(n^2) 子段的强力方法是不可行的，因为它可能需要大约 10^10 次操作。 每个测试用例我们需要一个 O(n) 或 O(n log n) 的解决方案。 边缘情况包括无法存在子段的非常小的数组 (n ≤ 2)，以及局部峰和谷位于末端的序列。 

## 方法

 一种简单的方法是迭代所有子段并检查第一个和最后一个元素是否是该段的内部元素（既不是最小值也不是最大值）。 这在逻辑上是正确的，但需要检查每个子段，导致复杂度为 O(n^2)，对于 n = 2×10^5 来说失败。 

关键的观察结果是最小有效子段长度为 3。对于长度为 3 的子段，中间元素自动相对于两端位于内部。 我们只需要找到任何连续元素的三元组，其中中间元素位于其他两个元素之间。 更具体地说，给定三个连续元素 a[i]、a[i+1]、a[i+2]，如果 a[i] < a[i+1] < a[i+2] 或 a[i] > a[i+1] > a[i+2] 不成立，则 a[i+1] 既不是最小值也不是最大值。 同样，我们只需检查 a[i+1] 是否严格位于 a[i] 和 a[i+2] 之间。 这将问题减少到在 O(n) 时间内扫描一次数组。 

我们不需要检查更长的子段，因为任何有效的三元组已经形成一个有效的子段，满足问题的要求。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 三重扫描 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取排列长度 n 和数组 a。 
2. 如果n < 3，则立即输出-1，因为不存在长度为3的子段。 
3. 从 i = 0 迭代到 n - 3（从零开始索引）。 对于每个连续的三元组 a[i]、a[i+1]、a[i+2]，检查中间元素 a[i+1] 是否严格位于其他两个元素之间。 具体来说，检查`(a[i] < a[i+1] < a[i+2]) or (a[i] > a[i+1] > a[i+2])`不成立。 如果不是，则 a[i+1] 是内部的。 
4. 如果找到这样的三元组，则输出从 1 开始的索引`i+1`和`i+3`作为子段的左端和右端。 
5. 如果扫描整个数组后没有找到有效的三元组，则输出-1。 

为什么它有效：不变的是，如果长度为 3 的子段的中间元素既不是最大值也不是最小值，则两端自动满足问题条件。 因为我们只需要一个有效的子段，所以扫描连续的三元组就足够了，并且该算法保证不会跳过任何三元组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    found = False
    for i in range(n - 2):
        if (a[i] < a[i+1] < a[i+2]) or (a[i] > a[i+1] > a[i+2]):
            continue
        print(i+1, i+3)
        found = True
        break
    if not found:
        print(-1)
```该代码有效地读取所有测试用例。 该循环检查每个连续的三元组并以基于 1 的格式输出索引，这在 Codeforces 中很常见。 我们使用`found`跟踪是否发现有效段。 这`continue`语句会跳过严格增加或减少的三元组，因为它们不满足条件。

 ## 边缘情况

 对于 n<3，算法立即输出 -1，正确处理最小尺寸数组。 对于严格递增或递减的序列，所有三元组都会被跳过`continue`条件，确保返回 -1。 对于存在多个有效子段的数组，算法始终输出第一个有效三元组，这是可以接受的，因为问题允许任何有效答案。
