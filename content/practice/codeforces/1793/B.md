 ## 解决方案
 ## 问题理解

 我们被要求重建一个整数循环数组，使得任意两个相邻元素之间的差恰好为 1。 Fedya 只记住该数组中所有局部最大值的总和以及所有局部最小值的总和。 局部最大值是严格大于其两个邻居的数字，局部最小值是严格小于其两个邻居的数字。 我们的目标是找到与给定总和一致且具有最小长度的任何数组。 

输入由多个测试用例组成。 对于每种情况，我们收到两个整数：局部最大值之和`x`和局部最小值的总和`y`， 和`y < x`。 输出必须是可能的最小数组长度`n`和一个有效的长度数组`n`。 由于数组是循环的，第一个和最后一个元素是相邻的，这意味着我们在构建序列时必须小心处理环绕。 

约束足够慷慨，`O(n)`每个测试用例的算法是可以接受的，但是任何试图尝试所有值排列的简单方法都是完全不可行的。 我们还需要处理负值以及最大值和最小值之间的巨大差异。 边缘情况包括：`x`和`y`差异很小（例如 1），并且当一个或两个总和为负时，这会影响我们可以放置峰值和谷值的位置。 

粗心的方法可能会尝试选择任意数量的交替峰和谷，而不确保总和匹配。 例如，如果`x = 2`和`y = -1`，只是创建`[0,1,0]`如果模式长度未考虑所有所需的最大值和最小值，则可能会意外地产生错误的总和。 该算法必须精确控制峰值和谷值的数量以满足总和。 

## 方法

 暴力方法会尝试生成一定长度的所有数组`n`，计算所有局部最大值和最小值，并检查它们的总和是否匹配`x`和`y`。 原则上这是正确的，但是可能的数组数量呈指数增长`n`，所以这是完全不切实际的。 即使我们有限`n`到 100，我们将粗略地检查`2^100`序列，这显然是不可行的。 

关键的见解是，数组必须由相邻的数字组成，因此每个局部最大值必须被小一号的数字包围，并且每个局部最小值必须被大一号的数字包围。 这意味着每个“峰值”都贡献`1`与两侧山谷的差异。 使用它，我们可以构建以下形式的重复模式`min, min+1, min, min+1,...`或者`max, max-1, max, max-1,...`以最小长度实现最大值和最小值的精确总和。 

当我们将每个最大值与相邻的最小值配对时，就会出现最小长度，产生如下序列`y, y+1, y, y+1,...`直到最大值的总和达到`x`。 这保证了每个额外的峰值都会使总和比周围的最小值精确地增加 1。 通过仔细扩展，我们可以构建任意的最短数组`x`和`y`且不超过总和。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 建设性模式| O(x-y) | O(x-y) | 已接受 |

 ## 算法演练

 1. 计算差异`d = x - y`。 这种差异告诉我们与最小值相比，最大值必须增加多少总“高度”。 
2. 数组中最大值的最小数量为 1。 分布`d`均匀地，构建一个序列，我们反复从最小值增加，创建最大值，然后减少回到最小值。 这会产生锯齿形。 
3. 从价值开始`y`作为第一个元素。 之间交替`y`和`y+1`形成一个峰值，跟踪剩余的差异以达到`x`。 
4. 如果剩余的差值大于 1，则通过添加继续该模式`1`根据需要到达峰值。 每个新峰值正好为总最大和加一。 
5.一旦峰值之和等于`x`，停止构建序列。 序列的长度是最小的，因为每个峰对`x`同时使用最少数量的元素。 
6. 输出最终长度和序列。 确保数组正确环绕成一个圆圈，这意味着第一个和最后一个元素正好相差一个。 

为什么它有效：不变量是每个局部最大值都被小一号的数字包围，并且每个局部最小值都被比大一号的数字包围。 通过小心地增加峰值，同时保持谷值`y`，我们保证最大值之和恰好是`x`最小值之和恰好是`y`。 数组中的每个元素最多参与一个峰或谷，这确保了最小长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        d = x - y
        arr = []
        # Start at minimum
        val = y
        arr.append(val)
        while d > 0:
            arr.append(val + 1)
            arr.append(val)
            d -= 1
        print(len(arr))
        print(' '.join(map(str, arr)))

solve()
```该解决方案读取测试用例的数量，然后针对每个用例计算最大值和最小值之和之间的差。 我们从最小值开始序列`y`并重复添加图案`[y+1, y]`直到差异`d`被占。 这保证了每个添加的峰值都会使总和恰好增加 1，同时保持谷值不变。 边缘处理确保第一个和最后一个元素相差一个，因为我们总是追加`[y+1, y]`模式。
