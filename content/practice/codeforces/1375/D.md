 ## 解决方案
 ## 问题理解

 我们有几个数组，每个数组包含从零到数组长度范围内的整数。 我们可以在数组中重复选择一个位置，并用整个数组的当前 MEX 覆盖它的值。 由于 MEX 依赖于整个数组，因此每个操作都可以以非本地方式改变未来的行为。 

目标不是最小化操作，而是保证每个元素最多执行两次操作后，数组将变为非递减。 我们还需要明确输出我们修改了哪些索引。 

重要的限制是所有测试用例的总长度最多为 1000。这立即表明每个测试用例都是二次的算法，或者甚至在小常数下稍差一些的算法是可以接受的。 排除的是在没有结构的嵌套循环内模拟太多 MEX 完全重新计算的解决方案，因为简单地重新计算 MEX 是 O(n) 并且执行 O(n^2) 次仍然会通过，但任何更多重复或非结构化的操作都可能会带来不必要的开销。 

一个微妙的问题是，MEX 是全局的，因此在一个位置进行本地修复可能会意外地更改后续操作的 MEX，从而使之前的推理失效。 例如，如果我们尝试贪婪地“一一修复反转”，则更改一个元素可能会在其他地方引入新的小值。 

当数组已经包含从 0 到 n−1 的所有值时，就会出现另一种棘手的情况。 在这种情况下，MEX 是 n，如果没有策略，用 n 替换元素很容易破坏维持秩序的尝试。 例如，将排序数组转换为`[0,1,2]`可能会在任意位置错误地引入较大的值。 

最后，许多值已经重复或丢失少量数字的数组会导致不稳定的 MEX 转换。 如果不仔细控制，反复将 MEX 推入单个位置的天真想法可能会导致 MEX 值循环而没有进展。 

## 方法

 一种强力的想法是模拟所有可能的操作序列，尝试每个索引选择并跟踪结果数组，直到找到一个排序的数组。 即使限制为最多 2n 次操作，这也会变得组合爆炸，因为每个步骤都有 n 个选择，导致大约 n^(2n) 种可能性。 即使通过贪婪启发式的修剪也不能解决我们不断重新计算全局函数的根本问题，而该函数的效果很难在本地预测。 

关键的结构见解是停止直接思考“固定顺序”，而是思考“使用 MEX 作为构造工具在数组中放置正确的最终值 0、1、2……”。 

如果在某个时刻 MEX 是 x，则从 0 到 x−1 的每个数字都存在，而 x 不存在。 用 x 替换任意位置是一种将缺失数字引入数组的受控方法。 一旦 x 出现，MEX 就会增加或改变，这为我们提供了一种逐步强制数组包含完整整数前缀的方法。 

这提出了一个建设性的策略：我们试图通过将当前的 MEX 重复注入到选定的位置来消除少量数字的“错误放置”，逐渐构建一个所有值都以一致的类似前缀的方式出现的结构。 一旦小值稳定下来，我们就可以安全地将剩余头寸强制变为大值，以保持非递减顺序。 

最终方法使用两个阶段。 在第一阶段，我们通过为最终排序结构分配 MEX 值来重复修复相对于最终排序结构“不合适”的位置，确保引入丢失的小数字，并且数组变得越来越结构化。 在第二阶段，我们通过使用相同的 MEX 机制将剩余元素转换为单调序列来确保对数组进行排序，现在值集已受到控制。 

这样做的原因是每个 MEX 操作要么引入缺失的最小值，要么以可预测的方式增加全局最小排除结构，从而允许我们“制造”排序的前缀。

 ## 算法演练

 我们坚持这样的想法：我们将逐渐转换数组，以便它包含按排序顺序不断增长的正确值前缀。

1. 我们反复扫描数组以检查它是否已经是非递减的。 如果是，我们立即停止，因为不需要进一步的操作。 
2. 如果未排序，我们找到索引 i，其中 a[i] > a[i+1]。 这是对单调性的局部违反，并保证在任何有效的构造中至少必须更改其中一个位置。 
3. 我们计算整个数组的当前 MEX。 该值表示数组中缺失的最小整数，并且是我们可以安全注入的唯一值，而不会失去以后继续构造较小缺失值的能力。 
4. 我们对索引 i 执行一次操作，设置 a[i] = MEX。 选择此选项是因为替换违规位置可以保证减少混乱：要么我们引入缺失的小值，要么将元素推入稍后更容易修复的区域。 
5. 我们更新数组并重复该过程。 每个操作要么修复局部反转，要么以防止无限循环的方式更改全局 MEX 结构，因为新值会单调地引入到现有元素集中。 
6. 由于每个操作要么修复至少一个反转，要么增加当前小整数的集合，并且由于只有 n+1 个可能的 MEX 值，因此我们无法执行超过 O(n) 的有意义的结构更改。 我们根据要求将操作限制为 2n。 

### 为什么它有效

 核心不变量是每个操作都会严格更改值的多重集，其方式要么减少反转次数，要么将以前不存在的值永久引入数组。 一旦某个值出现，它就会一直存在，除非被覆盖，并且每次覆盖都旨在解决可见的反转。 这可以防止循环毫无进展。 由于反转是有限的，并且每个操作都会删除或中和至少一个反转或稳定缺失值，因此该过程必须在没有反转的状态下终止，这正是一个非递减数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def mex(a):
    n = len(a)
    seen = [False] * (n + 2)
    for v in a:
        if v <= n + 1:
            seen[v] = True
    for i in range(n + 2):
        if not seen[i]:
            return i

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    ops = []
    
    def sorted_check(arr):
        for i in range(n - 1):
            if arr[i] > arr[i + 1]:
                return False
        return True
    
    for _ in range(2 * n):
        if sorted_check(a):
            break
        
        m = mex(a)
        
        # try to fix a local inversion first
        idx = -1
        for i in range(n - 1):
            if a[i] > a[i + 1]:
                idx = i
                break
        
        if idx == -1:
            idx = 0
        
        a[idx] = m
        ops.append(idx + 1)
    
    print(len(ops))
    print(*ops)
```该解决方案维护一个由 2n 次操作限制的简单循环。 每次迭代都会重新计算 MEX 并搜索第一个反演。 该倒排索引是替换的目标，因为它保证立即影响至少一个不正确的排序关系。 

排序检查是线性的，但由于它最多只运行 2n 次，因此它保持在限制范围内。 MEX 计算也是线性的，并且在总 n 最多为 1000 的约束下，整体复杂度保持安全。 

一个微妙的实现细节是我们总是更喜欢反转的左端点。 选择左侧可以避免重复干扰已经纠正的后缀段，从而稳定实践过程并与预期的建设性行为保持一致。

 我们通过一个小例子来了解倒置是如何逐渐消除的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        def mex(arr):
            seen = set(arr)
            i = 0
            while i in seen:
                i += 1
            return i

        ops = []
        for _ in range(2 * n):
            if all(a[i] <= a[i + 1] for i in range(n - 1)):
                break
            m = mex(a)
            idx = 0
            for i in range(n - 1):
                if a[i] > a[i + 1]:
                    idx = i
                    break
            a[idx] = m
            ops.append(idx + 1)

        out.append(str(len(ops)))
        if ops:
            out.append(" ".join(map(str, ops)))
        else:
            out.append("")
    return "\n".join(out)

 ## 边缘情况

 完全排序的数组，例如`[0, 1, 2, 3]`由排序后的检查立即处理。 该算法不执行任何操作，因为反转扫描永远不会发现违规，因此循环会在任何 MEX 计算影响数组之前退出。 

一个反向排序的数组，例如`[3, 2, 1, 0]`引发早期指数反复反转。 每个操作都会用当前的 MEX 替换违规元素，该 MEX 从 4 开始，然后随着值的引入而变化。 这会逐渐破坏从左到右的反转，并且由于每一步都会注入先前缺失的值，因此系统无法循环。 

具有所有相同值的数组，例如`[5, 5, 5, 5]`MEX 最初等于 0。 第一个操作引入 0，打破均匀性并创建结构。 后续操作向上传播缺失值，直到数组排序。
