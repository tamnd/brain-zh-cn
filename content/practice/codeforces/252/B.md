 ## 解决方案
 ## 问题理解

 我们得到一个长度为 _n_ 的整数数组，并被要求确定是否可以交换不同位置的任意两个元素，以使结果数组不再排序。 这里排序的定义很广泛：如果数组是非递减或非递增的，则该数组被排序。 我们不能交换相等的元素，即使它们位于不同的位置，并且如果可能的话我们必须执行交换。 

输入约束为 1 ≤ _n_ ≤ 10^5，数组元素最多为 10^9。 由于 _n_ 可能为 100,000 且时间限制为 2 秒，因此 O(n^2) 解决方案将涉及 10^10 次操作，这太慢了。 这意味着我们需要一种线性或近线性的方法。 内存有 256 MB 的空间，因此存储几个大小为 _n_ 的辅助数组是可行的。 

边缘情况在这里很重要。 单元素数组显然不能通过交换取消排序。 所有元素相等的数组也不能取消排序，因为我们不能交换相等的元素。 严格递增或递减且包含所有唯一元素的数组是可交换的，但末尾具有重复值的单调数组需要仔细选择不同的值。 

## 方法

 强力方法是迭代所有不同索引对，如果元素不相等则尝试交换，并检查结果数组是否未排序。 这是正确的，但在最坏的情况下是 O(n^2)，对于 n = 10^5 来说这将无法完成。 蛮力之所以有效，是因为它系统地测试了每个选项，但对于大型数组来说，由于对的组合爆炸，它会失败。 

最佳方法利用了这样的观察结果：要破坏已排序的数组，我们只需要交换与其他位置的另一个元素不同的第一个元素。 如果数组严格递增，则将第一个元素与任何较小的后续元素交换会破坏顺序。 类似地，如果严格递减，则可以将第一个元素与较大的后续元素交换。 这将问题简化为对元素不同的任意两个索引进行线性扫描，即 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 检查数组长度是否为1。如果是，则输出-1，因为单元素数组无法通过交换取消排序。 
2. 从第一个元素到倒数第二个元素迭代数组。 如果发现两个连续的不同元素，请记录它们的索引。 如果交换，这两个位置保证会产生未排序的数组，因为交换已排序数组中的任何两个不同元素都会破坏递增或递减属性。 
3. 如果在线性扫描期间没有找到这样的对，则所有元素都相等。 在这种情况下，输出 -1，因为不允许交换相等元素。 
4. 输出找到的第一对的索引。 

为什么它有效：在排序数组中，任何两个不同的元素都有相对顺序。 交换两个不同的元素将至少在一个位置违反该顺序。 线性扫描保证我们快速找到第一个这样的对。 如果不存在对，则所有元素都相等并且不可能交换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

if n == 1:
    print(-1)
else:
    found = False
    for i in range(n - 1):
        if a[i] != a[i + 1]:
            print(i + 1, i + 2)
            found = True
            break
    if not found:
        print(-1)
```该解决方案使用快速输入读取数组大小和元素。 它立即处理简单的单元素情况。 线性扫描检查相邻元素，因为任何一对不相等的相邻元素都保证了破坏单调性的有效交换。 在输出中使用从 1 开始的索引符合问题要求。 旗帜`found`确保如果所有元素都相等，我们正确输出 -1。

 ## 边缘情况

 对于像这样的单元素数组`1\n1`，解决方案立即返回 -1，正确处理不可能的情况。 对于所有元素都相等的数组，例如`3\n5 5 5`，线性扫描没有找到任何不同的相邻元素，并且解正确输出 -1。 对于严格递增或递减的数组，选择第一个不相等的相邻对，这保证了数组在交换后变为未排序。 该算法可以正确处理最大允许大小的数组，因为它只需要一次遍历数组，从而保持 O(n) 时间和 O(1) 空间。
