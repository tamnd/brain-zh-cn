 ## 解决方案
 ## 问题理解

 该问题要求我们测量数轴上两条路段的重叠程度。 每个线段都是一个闭区间，因此它包括两个端点，但答案是基于长度的，这意味着单个接触点的贡献为零。 给定两个区间`[a, b]`和`[c, d]`，我们需要输出它们的公共部分的长度，或者当公共部分没有正长度时为零。 

输入包含许多独立的测试用例。 病例数可达`10^5`，坐标可以大到`10^18`以绝对值表示。 这立即排除了每个案例中除常数或对数工作之外的任何内容，因为`10^5`案例只为大约几百万次简单操作留下空间。 坐标大小还意味着实现必须使用可以处理 64 位值的整数算术。 

主要的边缘情况来自于混淆交集作为一组点，交集作为长度。 例如：```
1
0 1 1 2
```间隔在坐标处相交`1`，但共同点只是要点`{1}`。 它的长度为零，所以答案是：```
0
```仅检查间隔是否重叠的解决方案可能会错误地返回`1`。 

另一种情况是一个区间完全位于另一个区间内：```
1
0 10 3 7
```交点是`[3,7]`，其长度为`4`。 仅检查一个端点的粗心实现可能会错过这种情况。 

最后一个棘手的情况是当两个区间都是点时：```
1
5 5 5 5
```间隔相同，但它们的长度仍然为零，因为端点之间没有距离。 

## 方法

 直接的方法是比较间隔并找出每种可能的重叠情况。 我们可以检查一个区间是否在另一个区间内开始，一个区间是否包含另一个区间，或者它们是否不相交。 这是有效的，因为两个间隔之间的每种可能的关系都属于这些类别之一。 然而，这会产生不必要的分支，并且很容易在接触端点时出错。 

区间的结构为我们提供了更简单的观察。 交点的左边界必须是两个左端点中较晚的一个，因为两个区间都必须到达该坐标。 同样，右边界必须是两个右端点中较早的一个。 如果生成的左边界小于右边界，则存在正长度交集。 否则，交集的长度为零。 

案例分析的蛮力风格也适用于恒定时间，但最小和最大观察将逻辑简化为单个公式。 问题不在于搜索或模拟，而在于识别共享区域的两个边界。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(1) | O(1) | O(1) | O(1) | 接受，但更容易犯错误 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取两个区间的四个端点。 

我们只需要端点，因为两个区间的交集完全由它们的边界确定。 
2. 计算交点的左侧为`max(a, c)`。 

交集中的任何点都必须属于两个区间，因此它不能位于任一区间开始之前。 
3. 计算交点的右侧为`min(b, d)`。 

交点中的任何点都必须在任一间隔结束之前结束。 
4. 如果左侧小于右侧，则输出两者之差。 否则输出零。 

需要严格的不等式，因为相等的边界意味着交点只是一个点。 

为什么它有效：该算法保持两个间隔可以同时包含一个点的精确可能范围。 最大起点删除了某个区间内不可用的每个位置，最小终点删除了某个区间之外的每个位置。 剩下的线段正是交点。 如果它没有正宽度，则其长度为零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        a, b, c, d = map(int, input().split())

        left = max(a, c)
        right = min(b, d)

        if left < right:
            ans.append(str(right - left))
        else:
            ans.append("0")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该解决方案读取所有测试用例并独立处理每个测试用例。 变量`left`和`right`表示描述交集所需的唯一两个值。 

比较使用`<`而不是`<=`。 这可以正确处理端点接触的情况，因为像这样的交集`[2,2]`长度为零。 Python 整数具有任意精度，因此大坐标不需要任何特殊处理。 

## 工作示例

 对于输入：```
3 7 1 5
```执行看起来像这样：

 | 步骤| 左| 对| 行动|
 | ---| ---| ---| ---|
 | 初始间隔 | - | - |`[3,7]`和`[1,5]`|
 | 寻找交叉点开始 | 3 | - | 最大值(3,1) |
 | 找到交叉点 | 3 | 5 | 分钟(7,5) |
 | 最终检查| 3 | 5 | 输出 5-3 = 2 |

 交点是`[3,5]`，所以答案是`2`。 这演示了正常的重叠情况。 

对于输入：```

```执行是：

 | 步骤| 左| 对| 行动|
 | ---| ---| ---| ---|
 | 初始间隔 | - | - |`[0,1]`和`[1,2]`|
 | 寻找交叉点开始 | 1 | - | 最大值(0,1) |
 | 找到交叉点 | 1 | 1 | 分钟(1,2) |
 | 最终检查| 1 | 1 | 输出 0 |

 两个音程相接触但不共享任何距离。 这证实了为什么相等必定产生零。

 ## 边缘情况

 对于接触端点的情况：```
1
0 1 1 2
```该算法计算`left = max(0,1) = 1`和`right = min(1,2) = 1`。 由于两个值相等，因此条件失败并且答案为零。 该算法正确地将共享点视为没有长度。 

对于包含的区间：```
1
0 10 3 7
```计算出的交集来自`3`到`7`，因为较晚的开始是`3`较早的结束是`7`。 答案是`7 - 3 = 4`，表明不需要特殊的包含逻辑。 

对于负坐标：```
1
-10 -2 -7 0
```交集是`[-7,-2]`。 该算法发现`left = -7`和`right = -2`, 给予`5`。 负位置的行为与正位置完全相同，因为只有顺序很重要。
