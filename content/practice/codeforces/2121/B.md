 ## 解决方案
 ## 问题理解

 我们被要求确定，对于给定的字符串，是否可以将其拆分为三个非空部分，$a$,$b$， 和$c$，使得$a + b + c = s$和中间部分$b$显示为连接的子字符串$a + c$。 换句话说，我们想知道是否存在“中间件”$b$在前缀组合中的某处已经可见$a$和后缀$c$。 

输入由多个测试用例组成，每个测试用例都有一个长度至少为 3 且最多为 3 的字符串$10^5$。 所有测试用例的字符串长度总和不超过$2 \cdot 10^5$。 这意味着我们无法检查每一个可能的分裂$a, b, c$天真地，因为大约有$O(n^2)$选择端点的方法$b$对于单个长度的字符串$n$。 任意算法逼近$O(n^2)$会太慢，所以我们需要接近的东西$O(n)$每串。 

一个微妙的边缘情况是字符串由相同的字符组成，例如“aaa”。 将其分成三段仍然允许中间部分出现在第一段和最后一段的串联中。 另一个棘手的情况是所有字符都不同，例如“abc”。 这里，中间字符必须匹配第一个或最后一个字符才能满足子字符串条件。 粗心的实现可能总是尝试将中间段视为多个字符或忽略最简单的分割选项，从而产生错误的答案。 

## 方法

 蛮力方法是迭代所有可能的开始和结束位置$b$然后检查是否$b$作为子字符串出现在$a+c$。 对于一个长度的字符串$n$，这可能需要$O(n^3)$最坏情况下的时间（选择开始和结束时间）$b$，然后检查子字符串$O(n)$比较）。 这显然是不可行的$n$最多$10^5$。 

关键的观察是我们不需要考虑长的中间段。 如果我们采取$b$作为单个字符，我们可以快速检查它是否与第一个字符匹配$s$或最后一个字符。 具体来说，如果$s[0] == s[1]$或者$s[1] == s[-1]$，存在有效的分割：我们可以选择$a$作为第一个字符，$b$作为第二个，并且$c$和其他人一样。 或者，如果$s[-2] == s[-1]$或者$s[0] == s[-2]$，我们可以选择最后一个字符作为$c$和它前面的一个$b$。 

这是可行的，因为长度为 1 的子串很容易出现在$a+c$if it matches either endpoint. 由于字符串长度至少为 3，因此此检查就足够了：我们不需要$b$长度超过一个字符才能满足条件。 这种贪婪的洞察力将复杂性降低到$O(1)$检查每个字符串，这足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个字符串$s$长度$n \ge 3$，考虑将其拆分为$b$作为单个字符。 专注于第二个角色$s[1]$或倒数第二个字符$s[-2]$。 
3. 检查是否$s[1]$比赛$s[0]$或者$s[-1]$。 如果是，则输出“Yes”。 否则，检查是否$s[-2]$比赛$s[0]$或者$s[-1]$。 如果任一条件为真，则输出“Yes”。 
4. 如果以上检查均未通过，则输出“No”。 

为什么有效：该方法保证了正确性，因为任何具有非空中间段的有效分割都必须允许该中间段出现在前缀和后缀的组合中。 由于单字符段是最小的非空子字符串，因此如果存在有效的分割，则将通过对照字符串端点检查第二个和倒数第二个字符来检测它。 较长的子字符串只需要其中一个字符与端点匹配，这一最小检查涵盖了端点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    if s[0] == s[1] or s[-1] == s[-2] or s[1] == s[-1] or s[0] == s[-2]:
        print("Yes")
    else:
        print("No")
```该解决方案首先读取测试用例的数量，然后迭代每个字符串。 它在读取字符串后修剪换行符以避免意外的不匹配。 检查直接实现了中间字符可以是单个字符并且必须与任一端匹配的观察。 条件的顺序是任意的，因为我们只需要一个真正的匹配。
