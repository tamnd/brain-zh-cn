 ## 解决方案
 ## 问题理解

 我们在数轴上得到一组不同的整数位置和一个起始位置。 从起始位置开始，我们一次可以向左或向右移动一个单位。 我们的目标是至少访问每个指定位置一次，并且我们希望计算实现此目标所需的最小移动次数。 

输入提供多个测试用例。 每个测试用例都会给出要访问的位置数量、起始点以及位置的排序列表。 每个测试用例的输出是一个整数，表示确保访问所有位置的最小步骤数。 

限制很小：职位数量`n`最多 10 个，起始位置和目标位置在 1 到 100 之间，最多可以有 1000 个测试用例。 因为`n`非常小，算法呈指数增长`n`是可行的。 我们不需要考虑高复杂度的图或动态规划方法，因为即使尝试访问顺序的所有排列在计算上也是合理的。 

当起始位置`s`超出了我们需要访问的位置范围。 例如，如果`s = 1`职位是`[3, 4, 5]`，最优路径是直接移动到最近的端点，然后依次遍历所有位置。 一个简单的实现假设`s`始终在位置范围内会产生错误的答案。 

另一个边缘情况是当`s`与位置之一重合。 例如，如果`s = 3`职位是`[3, 4, 5]`，最小步数减少，因为我们不需要移动到起始位置。 

## 方法

 蛮力方法将生成位置的所有排列并计算从`s`通过每一个排列。 这是正确的，因为它考虑了所有可能的顺序，但由于数轴的线性性质，这是不必要的。 和`n = 10`， 有`10! = 3,628,800`每个测试用例的排列。 乘以 1000 个测试用例，这种方法太慢了。 

关键的见解是所有位置都在一维线上并且已排序。 最小步数完全由我们必须访问的最左边和最右边的位置决定。 如果起始位置在这个区间内，则最优策略是先走到较近的端点，然后遍历到另一端。 如果起始位置在区间之外，我们直接移动到最近的端点并遍历到远端。 因此，最小步数是最左边和最右边位置之间的距离加上从起点到达间隔的任何附加距离。 

这将问题简化为简单的算术：找到最左边和最右边的位置，计算到达它们的距离`s`，并添加间隔长度。 这种方法是线性的`n`每个测试用例并且实施起来很简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有排列）| O(n! * n) | O(n! * n) | O(n) | 太慢了 |
 | 最佳（间隔+距离）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`,`s`，以及排序后的位置列表`x`。 
3. 确定最左边的位置`L = x[0]`和最右边的位置`R = x[-1]`。 
4. 如果起始位置`s`介于`L`和`R`（包含），最小路径是`R - s + s - L = R - L`，因为首先移动到较近的一端，然后遍历该区间总是会产生相同的总距离。 计算`max(R - s, s - L) + (R - L)`; 实际上，这简化为`(R - L)`什么时候`s`是在区间内。 
5. 如果起始位置`s`小于`L`，步骤是`R - s`，因为我们必须从`s`到`L`然后遍历到`R`。 
6. 如果起始位置`s`大于`R`，步骤是`s - L`，因为我们从`s`到`R`然后遍历到`L`。 
7. 输出计算出的最小步数。 

为什么有效：该解决方案利用了职位的一维性质。 最小的步骤序列始终是到达间隔的一个端点并遍历到另一个端点。 任何偏差，例如以非顺序顺序访问位置，都会不必要地增加步骤数。 这样就保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, s = map(int, input().split())
    x = list(map(int, input().split()))
    L, R = x[0], x[-1]

    if s < L:
        steps = R - s
    elif s > R:
        steps = s - L
    else:
        steps = (R - L) + min(R - s, s - L)
    
    print(steps)
```该代码可以有效地读取输入`sys.stdin.readline`快速处理许多测试用例。 它标识了间隔`[L, R]`包含所有位置。 取决于起始位置是否`s`位于该区间之外或之内，代码计算最小步数。 这`min(R - s, s - L)`确保我们从较近的一端开始`s`处于区间内，减少了行驶的距离。
