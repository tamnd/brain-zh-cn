 ## 解决方案
 ## 问题理解

 我们有一个连接的无向山丘地图。 每座山都有一个高度，山之间的路径形成一个图形。 我们需要从山 1 前往山 2，同时使所访问的最高山和最矮山之间的差异尽可能小。 

对于任何选定的路线，唯一重要的是该路线上出现的最小高度和最大高度。 如果一条路线访问高度 10、14、13 和 12，则其成本为`14 - 10 = 4`。 

输入给出了山丘的数量、小径的数量、每座山丘的高度以及由小径连接的山丘对。 输出是从山 1 到山 2 的所有路线中可能的最小高度差。 

山丘的数量最多为 5000 个，小径的数量最多为 25000 个。尝试每条可能路径的解决方案是不可能的，因为一张图可以包含大量不同的路线。 即使探索所有路径也会呈指数级增长。 我们需要将问题减少到在高度限制下检查连通性。 由于只有 5000 个山丘，因此算法围绕`O(n(n+m))`是现实的，但是任何涉及所有山丘或所有可能路径的事情都太昂贵了。 

第一种边缘情况是山 1 和山 2 具有相同的高度。 如果仅由这两座山组成的路线直接相连，则答案为零。 例如：```
Input
2 1
5 5
1 2

Output
0
```假设答案总是肯定的粗心解决方案将在这里失败。 

另一种边缘情况是最佳路线不使用最短图路径时。 例如：```
Input
5 5
1 100 50 51 2
1 2
1 3
3 4
4 5
5 2

Output
49
```直接路径有高度范围`99`，但路径较长`1 -> 3 -> 4 -> 5 -> 2`有范围`50 - 1 = 49`。 最小化边数而不是高度范围的解决方案会给出错误的结果。 

当几个山丘具有相同高度时，就会出现第三种边缘情况。 允许高度的窗口必须基于高度值，而不是山体指数。 例如：```
Input
3 2
7 7 10
1 2
2 3

Output
3
```两座高度为 7 的小山应一起处理。 将相等的高度分成不同的范围可能会错过有效的答案。 

## 方法

 直接方法会枚举从山 1 到山 2 的每条可能路线，计算每条路线的最小和最大高度，并保留最小差异。 这是正确的，因为考虑了所有可能的候选路线。 问题是路线的数量。 即使稀疏图也可以包含指数级的许多不同路径，因此这种方法立即变得不可用。 

关键的观察是我们不关心确切的路线，只关心某些路线是否存在于高度区间内。 

假设我们选择两个高度`low`和`high`。 我们询问山 1 和山 2 是否仅使用高度介于两者之间的山连接`low`和`high`。 如果它们是相连的，那么这个区间就是一个有效的候选答案。 

有效区间具有单调性。 如果`[low, high]`有效，然后增加`high`让它继续工作。 如果`[low, high]`不起作用，减少`high`无能为力。 这允许在排序的唯一高度上进行两指针扫描。 

对于每个左边界，我们仅向前移动右边界，直到间隔有效。 然后我们尝试删除当前最小的高度并继续。 连接性检查的数量与不同高度的数量成线性关系，因为右指针永远不会向后移动。 

暴力破解之所以有效，是因为它会检查所有可能的路线，但会失败，因为路线数量巨大。 观察到只有允许的高度间隔很重要，这让我们可以用重复的图形连接检查来替换路径枚举。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) | 太慢了|
 | 最佳| O(k(n+m)) | O(n+m) | 已接受 |

 这里`k`是不同高度的数量，并且`k <= n`。 

## 算法演练

 1. 对所有不同的山丘高度进行排序。 这些值是有用间隔的唯一可能的边界，因为在两个现有高度之间移动边界无法更改哪些山可用。 
2.维护两个指针`left`和`right`在排序的高度列表上。 当前候选区间是从`heights[left]`到`heights[right]`。 
3. 对于当前区间，从山 1 开始运行 BFS。在搜索过程中，仅访问高度在区间内的山。 如果到达山 2，则该区间包含有效路线。 
4. 如果间隔无效，则增加`right`。 添加更大的最大高度只能添加更多可用的山丘，因此可能会出现一条路线。 
5. 如果间隔有效，则用当前范围更新答案并增加`left`。 删除最小允许高度可能会产生更小的有效间隔。 
6. 继续，直到右指针到达高度列表的末尾。 

两个指针移动之所以安全，是因为只有当间隔扩大时，连接才会变得更容易。 一旦特定的最大高度足以满足给定的最小高度，搜索较小的最大高度就无济于事。 

为什么它有效：

 每条有效路线都有一个最小高度`L`和最大高度`R`，因此它对应于二指针过程所考虑的区间之一。 BFS 检查正确地确定某个区间是否包含从山 1 到山 2 的任何路线，因为它精确地探索了该区间内的山形成的子图。 该算法测试每个可能的最小左边界，并找到适合它的最小右边界，因此不会跳过更小的有效区间。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    h = list(map(int, input().split()))

    graph = [[] for _ in range(n)]
    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        graph[a].append(b)
        graph[b].append(a)

    values = sorted(set(h))

    def connected(low, high):
        if not (low <= h[0] <= high and low <= h[1] <= high):
            return False

        seen = [False] * n
        q = deque([0])
        seen[0] = True

        while q:
            u = q.popleft()
            if u == 1:
                return True
            for v in graph[u]:
                if not seen[v] and low <= h[v] <= high:
                    seen[v] = True
                    q.append(v)

        return False

    ans = values[-1] - values[0]
    right = 0

    for left in range(len(values)):
        if right < left:
            right = left

        while right < len(values) and not connected(values[left], values[right]):
            right += 1

        if right == len(values):
            break

        ans = min(ans, values[right] - values[left])

    print(ans)

if __name__ == "__main__":
    solve()
```输入解析构建了一个邻接列表，因为图足够稀疏，不需要显式存储所有边。 这`connected`从演练来看，函数是核心操作。 它执行 BFS，同时按当前高度间隔过滤顶点。 

两个指针循环仅将索引存储到已排序的高度列表中。 右指针永远不会向后移动，这就是 BFS 调用数量受到限制的原因。 仅在找到有效间隔后才会更新答案。 

开始时的边界检查`connected`处理任一端点超出当前高度范围的情况。 如果没有它，即使起点或终点山不可用，BFS 也可能错误地声称路线存在。 

Python整数不会溢出，因此即使高度可以达到一百万，高度计算也是安全的。

 ## 边缘情况

 对于等高情况：```
2 1
5 5
1 2
```排序后的高度列表仅包含`[5]`。 唯一检查的间隔是`[5,5]`。 两个端点都在其中，BFS 立即到达山 2，答案变为`5 - 5 = 0`。 

对于较长路线的情况：```
5 5
1 100 50 51 2
1 2
1 3
3 4
4 5
5 2
```间隔`[1,2]`无法到达山 2，因为替代路线所需的中间山不可用。 扩展到`[1,50]`仍然失败，但是`[1,51]`成功翻越高山`1,50,51,2`。 算法记录`51 - 1 = 50`在继续搜索之前。 最终有效最小值为`49`使用间隔`[2,51]`左指针移动后。 

对于重复高度：```
3 2
7 7 10
1 2
2 3
```排序后的唯一高度是`[7,10]`。 该算法永远不会将两个高度为 7 的山分开，因此间隔`[7,10]`正确包含两者并找到具有范围的路线`3`。 

对于所有情况，不变的是每次测试一个区间时，BFS 准确地表示在该高度限制下可用的图形。 两个指针只丢弃不能改善答案的区间，因此保留了最终的最小范围。
