 ## 解决方案
 ## 问题理解

 我们有两种不同的彩虹颜色名称。 

第一个颜色，`C1`，是简化的“人类视觉”系统必须从 ASCII 艺术中识别的单词。 第二种颜色，`C2`，是应该出现在原始文本中的单词，以便将图像作为普通字符串读取的语言模型看到该颜色而不是其他彩虹颜色。 

识别模型极其薄弱。 它不关心字母的实际形状。 大写字母的每个四连接组件都被视为单个大字母，它使用的唯一特征是该组件内部的孔数。 

有两个孔的组件被解释为`B`。 

有一个孔的组件被解释为以下之一`A`,`D`,`O`,`P`,`Q`,`R`。 

具有零孔的组件被解释为任何其他字母。 

由于六种彩虹颜色名称具有不同的孔数序列，因此识别颜色可以简化为识别孔数序列。 

这是一个纯粹的建设性问题。 输入尺寸很小，只有一对颜色名称，输出只需要满足一组几何约束。 挑战不在于效率，而在于找到一种始终有效的结构。 

主要缺陷是打印字符串中任何意外出现的其他颜色名称都会立即违反该声明。 另一个容易犯的错误是允许两个相邻的组件接触，这会将它们合并成一个更大的组件，并完全改变识别器看到的孔计数序列。 

## 方法

 暴力思维会尝试为每种颜色绘制实际的大写字母，然后以某种方式将语言模型颜色隐藏在图片中。 这在概念上是可行的，但它创建了大量的几何案例，并且使得正确性难以推理。 

关键的观察是识别器只计算漏洞。 它从不检查组件是否类似于真正的字母。 

一旦我们意识到，每一个角色`C1`可以用一个小模板代替，其唯一目的是创建一个恰好有 0、1 或 2 个孔的组件。 

我们可以预先计算与彩虹颜色中出现的每个字母相关的孔数。 

然后我们为每个字母构建一个连接组件`C1`，通过至少一列点分隔相邻组件。 识别器将准确读取预期的孔计数序列。 

对于语言模型部分，我们只需放置`C2`作为最后一行的普通文本。 由于每隔一行仅使用无害的填充字母，因此没有其他彩虹颜色名称可以作为子字符串出现。

 ## 算法演练

 1. 创建从以彩虹颜色出现的每个大写字母到其孔数的映射。 
2、准备三个固定模板。 

零孔组件：```
XXX
X..
X..
X..
XXX
```单孔组件：```
XXX
X.X
X.X
X.X
XXX
```两孔组件：```
XXX
X.X
XXX
X.X
XXX
```3. 对于每个字符`C1`，查找其孔数并将相应的模板附加到图片中。 
4. 在连续的组件之间插入一列点，使它们保持独立的字母。 
5. 添加最后一行，其中包含`C2`，后跟点，直到其长度与其他行匹配。 
6. 打印生成的矩形。 

### 为什么它有效

 每个模板形成一个四连接组件。 第一个模板不包含封闭区域，第二个模板仅包含一个封闭区域，第三个模板仅包含两个封闭区域。 

由于相邻模板由一整列点分隔开，因此组件永远不会接触。 因此，识别器对每个字符识别一个组成部分。 

识别器看到的孔计数序列正是对应于字母的序列`C1`，所以图片被解释为`C1`。 

最后一行明确包含`C2`作为独立的子串，满足语言模型的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

c1 = input().strip()
c2 = input().strip()

holes = {
    'A': 1, 'B': 2, 'C': 0, 'D': 1, 'E': 0, 'F': 0, 'G': 0,
    'H': 0, 'I': 0, 'J': 0, 'K': 0, 'L': 0, 'M': 0, 'N': 0,
    'O': 1, 'P': 1, 'Q': 1, 'R': 1, 'S': 0, 'T': 0, 'U': 0,
    'V': 0, 'W': 0, 'X': 0, 'Y': 0, 'Z': 0
}

templates = {
    0: [
        "XXX",
        "X..",
        "X..",
        "X..",
        "XXX",
    ],
    1: [
        "XXX",
        "X.X",
        "X.X",
        "X.X",
        "XXX",
    ],
    2: [
        "XXX",
        "X.X",
        "XXX",
        "X.X",
        "XXX",
    ]
}

rows = [""] * 5

for i, ch in enumerate(c1):
    pat = templates[holes[ch]]
    for r in range(5):
        rows[r] += pat[r]
        if i + 1 != len(c1):
            rows[r] += "."

width = max(len(rows[0]), len(c2))

for i in range(5):
    rows[i] += "." * (width - len(rows[i]))

rows.append(c2 + "." * (width - len(c2)))

print("\n".join(rows))
```第一部分构建孔数映射。 只有三个值很重要：0、1 和 2。 

这三个模板都经过精心挑选，以便每个模板都连接起来并具有所需数量的孔。 

构造循环将每个字符转换为`C1`到其模板中，并在相邻组件之间插入点分隔列。 如果没有该分隔符，两个组件可能会合并成一个更大的连接区域。 

五个绘图行完成后，我们计算所需的矩形宽度。 每行必须具有相同的长度，因此较短的行用点填充。 

最后，最后一行包含`C2`并填充到相同的宽度。

 ## 边缘情况

 颜色如`BLUE`以所有彩虹颜色中唯一的两孔字母开头。 施工人员通过选择专用的两孔模板来解决这个问题。 识别器看到一个恰好有两个封闭区域的组件，并将其正确解释为`B`。 

颜色如`ORANGE`以几个连续的单孔字母开头。 由于每个组件都由点列分隔，因此这些单孔组件永远不会合并。 识别器仍然看到三个不同的字母，而不是一个大的组成部分。 

颜色如`GREEN`包含零孔和一孔字母。 由于每个组件的孔数都是独立编码的，因此混合序列会自动处理，无需任何特殊逻辑。
