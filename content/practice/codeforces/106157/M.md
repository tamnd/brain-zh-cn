 ## 解决方案
 ## 问题理解

 我们得到了一条路线上高速公路停靠点的位置，并以严格递增的累积距离存储。 

在每对连续停靠点之间都有一个行驶段。 如果停在位置`i`被删除，其中`i`既不是第一个站点也不是最后一个站点，那么与该站点相邻的两个路段将成为一个较长的路段。 

任务是精确删除一个内部停靠点，以使剩余的最长行驶段尽可能小。 我们必须输出最小可能的最长距离。 

让`g[j] = s[j+1] - s[j]`是连续停靠点之间的距离。 

如果我们删除停止`i`，然后是间隙`g[i-1]`和`g[i]`消失并被一个长度间隙所取代`g[i-1] + g[i]`。 

所有其他差距保持不变。 

停靠点的数量可以多达 200,000 个，因此几乎有 200,000 个间隙。 对于每个可能被删除的停靠点，从头开始重新计算最大间隙的算法大约需要`O(n²)`工作量太大了。 和`n = 200,000`，这将意味着数百亿次操作。 

一些边缘情况值得关注。 

假设间隙是`10 20 30`。 

删除中间停止合并`10`和`20`，产生间隙`30 30`。 答案是`30`， 不是`20`。 任何只关注现有间隙而忽略合并段的解决方案都会失败。 

考虑：```
4
0 100 101 200
```差距是`100 1 99`。 

删除第二个停止点会产生一个间隙`101`，最多给出`101`。 

删除第三个停止点会产生一个间隙`100`，最多给出`100`。 

正确答案是`100`。 诸如“移除最小缺口旁边的止损”之类的贪婪规则并不可靠。 

另一种边界情况是当最佳移除发生在第一个或最后一个可移除停止点旁边时：```
3
0 5 12
```只能删除一站。 结果段长度为`12`，所以答案是`12`。 粗心的前缀或后缀处理可以轻松访问此处的无效索引。 

## 方法

 最直接的解决方案是尝试每一个可移动的停止点。 

对于选定的停靠点，合并其两个相邻间隙，然后扫描所有剩余间隙以找到最大的间隙。 这是正确的，因为它明确地评估了每个可能的删除的结果。 

问题是运行时间。 有`O(n)`候选人停下来，每次评估都需要`O(n)`重新计算最大间隙的时间。 总复杂度变为`O(n²)`，这是不可能的`n = 200,000`。 

关键的观察结果是，移除止损后，只有两个缺口发生变化。 

用于消除间隙`g[i-1]`和`g[i]`:

 合并后的间隙变为`g[i-1] + g[i]`。 

其他所有间隙都保持完全相同。 

因此，删除后的最大间隙就是以下值中的较大者：

 1.合并差距。 
2. 除`g[i-1]`和`g[i]`。 

这建议预先计算间隙数组的前缀和后缀的最大值。 

让：`pref[j]`= 之间的最大差距`g[0..j]`

`suff[j]`= 之间的最大差距`g[j..m-1]`在哪里`m = n - 1`。 

然后进行涉及间隙的移除`g[i-1]`和`g[i]`，可以在常数时间内从之前的前缀得到最大不受影响的间隙`g[i-1]`以及后面的后缀`g[i]`。 

每个候选删除的评估如下`O(1)`时间，给出总体`O(n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取停止位置。 
2. 构建间隙数组`g`， 在哪里`g[i] = s[i+1] - s[i]`。 
3.构建前缀最大数组`pref`。`pref[i]`存储从开始到索引的最大差距`i`。 
4.构建后缀最大数组`suff`。`suff[i]`存储与索引的最大差距`i`到最后。 
5. 迭代每个可移动的停止点。 

如果移除的挡块位于间隙之间`g[i-1]`和`g[i]`，则新的合并间隙为：`merged = g[i-1] + g[i]`。 
6. 计算未受影响的最大间隙。 

之前的差距`g[i-1]`贡献`pref[i-2]`如果存在这样的索引。 

之后的间隙`g[i]`贡献`suff[i+1]`如果存在这样的索引。 

这两个值中较大的一个是不受影响的最大间隙。 
7. 删除后最大的段是：`max(merged, unaffected_max)`。 
8. 取所有候选删除中的最小值。 
9. 输出最小值。 

### 为什么它有效

 对于任何选定的停靠点，正好修改两个相邻间隙。 其他所有间隙保持不变。 

删除该停止点后最长的段必须是新合并的间隙或未更改的间隙之一。 前缀和后缀最大数组给出了在恒定时间内合并对之外的最大不变间隙。 

由于该算法会评估每次有效删除的确切最长线段并返回其中的最小值，因此它始终会找到要删除的最佳停止点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = list(map(int, input().split()))

gaps = [s[i + 1] - s[i] for i in range(n - 1)]
m = n - 1

pref = [0] * m
pref[0] = gaps[0]
for i in range(1, m):
    pref[i] = max(pref[i - 1], gaps[i])

suff = [0] * m
suff[m - 1] = gaps[m - 1]
for i in range(m - 2, -1, -1):
    suff[i] = max(suff[i + 1], gaps[i])

ans = 10**18

for i in range(1, m):
    merged = gaps[i - 1] + gaps[i]

    other = 0
    if i - 2 >= 0:
        other = max(other, pref[i - 2])
    if i + 1 < m:
        other = max(other, suff[i + 1])

    ans = min(ans, max(merged, other))

print(ans)
```第一部分将停止位置转换为间隙长度。 使用间隙要简单得多，因为删除停止点只会影响两个相邻的间隙。 

前缀和后缀数组允许我们在常数时间内查询最大的不受影响的间隙。 如果没有它们，我们将需要重新扫描整个数组以删除每个候选者。 

索引处理是微妙的部分。 

当移除之间的停止时`g[i-1]`和`g[i]`，未受影响的间隙就是之前的一切`g[i-1]`以及之后的一切`g[i]`。 

这就是为什么左贡献使用`pref[i-2]`正确的贡献使用`suff[i+1]`。 

使用`0`当一侧不存在时，正确处理路线末端附近的移除。 

Python 整数很容易处理最大可能的距离值，因为坐标最多是`10^9`。

 ## 边缘情况

 考虑：```
3
0 5 12
```只有一个可移动的挡块。 间隙数组为`[5, 7]`。 删除中间的停止点将它们合并为`12`。 该算法评估单个候选者，计算`merged = 12`，发现没有不受影响的间隙，并且输出`12`。 

考虑：```
4
0 100 101 200
```差距是`[100, 1, 99]`。 

删除第二个停靠点会产生合并间隙`101`和另一个差距`99`，所以最大值变为`101`。 

删除第三个停靠点会产生合并间隙`100`和另一个差距`100`，所以最大值变为`100`。 

该算法检查两种可能性并正确返回`100`。 

考虑：```
5
0 1 100 101 102
```差距是`[1, 99, 1, 1]`。 

移除位置处的停止装置`1`将前两个间隙合并为`100`。 剩下的缺口是`1`和`1`，所以最大值是`100`。 

前缀和后缀查询正确处理了已删除对的一侧没有剩余间隙的事实。 这正是经常出现相差一错误的地方，而索引检查可以防止这些错误。
