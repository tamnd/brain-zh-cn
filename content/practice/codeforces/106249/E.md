 ## 解决方案
 ## 问题理解

 我们有一个无向连通图，其中标记的顶点代表水站。 Busy Beaver 想知道有多少个这样的图具有以下属性：每个可能的生成树都包含一个度数至少为`K`。 输入给出`N`和`K`，我们需要对所有满足此条件的连通图进行模数计数`998244353`。 

关键的困难在于条件涉及所有生成树，而不是图本身。 一个图可以有许多生成树，因此直接检查它们是不可能的。 约束条件`N <= 5000`还排除了任何试图枚举图、生成树、甚至所有边子集的行为。 可能的图形数量已经`2^(N(N-1)/2)`，因此解决方案必须使用结构表征和动态规划，而不是对候选对象进行图遍历。 

一个有用的观察是`K`总是大于一半`N`。 这意味着两个不同的顶点至少不能同时具有度数`K`在同一棵树中，因为树的度和只有`2N-2`。 这使得“存在高度顶点”条件比看起来更加严格。 

一些边缘情况很容易被忽略。 如果`N = 5`和`K = 4`，条件要求每个生成树中都有一个度数为 4 的顶点。 完整的图可以满足这一点，但循环则不能。 对于输入：```
5 4
```答案不是所有连通图的数量，因为许多连通图都有一个生成树，它是一条路径，最大度为 2。 

另一种情况是图表有一个明显的中心站。 为了：```
7 5
```以顶点 1 为中心的星形有效，因为删除顶点 1 会留下六个孤立的顶点。 仅检查原始图度数的粗心解决方案可能会在重要属性来自清晰度行为而不是图本身的大度数的图上失败。 

## 方法

 第一次尝试是直接推理生成树。 我们可以生成图的每个生成树，检查它的一个顶点是否至少有度数`K`，然后计算有效图。 这是正确的，因为该属性是在生成树上精确定义的，但生成树的数量增长得太快了。 即使单个密集图也可能具有大量生成树，从而使这种方法无法使用。 

关键的观察是用有关删除顶点的语句替换生成树条件。 

对于任意连通图`G`，考虑删除一个顶点`v`。 让`components(G-v)`是剩余连接组件的数量。 在每棵生成树中，`v`至少是`components(G-v)`。 这是因为移除后的每个组件`v`必须通过连接回来`v`在树上。 

相反的方向也很有用。 如果某个顶点至少有`K`移除后的分量，每个生成树必须至少给它度数`K`。 自从`K > N/2`，不能有两个这样的顶点。 因此每个有效图都有一个特殊的顶点`v`这样`G-v`至少有`K`成分。 

现在我们只需要计算固定特殊顶点的图并乘以`N`。 

移除后`v`，大多数顶点必须是孤立的，因为组件的数量非常多。 让`t`是超出单例组件的额外顶点的数量。 因为必须至少有`K`之间的组成部分`N-1`剩余的顶点，`t`至多是`N-K-1`。 

对于一群`s`顶点形成一个非单一组件，我们需要两件事。 内部图必须是连通的，并且这些顶点中至少有一个必须连接到`v`。 我们预先计算每个尺寸的连通图的数量，并将其用作组件权重。 

剩下的任务是最多一个小分区DP`N-K-1`非单一顶点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数为`N`| 指数为`N`| 太慢了|
 | 最佳 | O((N-K)^2) | O((N-K)^2) | O(N-K) | 已接受 |

 ## 算法演练

 1. 预先计算DP所需尺寸的连通标记图的数量。 如果`conn[i]`是连通图的数量`i`顶点，标准递归来自选择包含固定顶点的连接组件。 递归以二次时间运行。 
2.对于一个固定的特殊顶点，计算制作一个size的组件的权重`s`。 单例组件有重量`1`。 为了`s >= 2`，该组件可以是这些上的任何连通图`s`顶点，并且特殊顶点必须至少在一个地方接触它，给出权重：`conn[s] * (2^s - 1)`。 
3.让`dp[i]`代表排列方式的数量`i`非单一顶点到有效组件中。 其余的顶点将是孤立的组件。 要进行过渡，请从这些组件中选择包含一个固定顶点的组件`i`顶点，选择其大小，然后乘以组件权重。 
4. 对于每一个可能的数字`i`的非单一顶点，从`N-1`非特殊顶点并添加相应的贡献。 
5. 将一个选定的特殊顶点的计数乘以`N`，因为特殊顶点是唯一的。 

为什么它有效：

 不变量是，选择特殊顶点后，每个有效图都由删除该顶点后剩余的连通分量唯一地描述。 每个这样的组件要么是一个单例组件，要么是 DP 计数的加权非单例组件之一。 来自特殊顶点的边也通过要求每个组件至少有一个连接来处理。 由于两个特殊顶点不可能存在，因此乘以`N`不重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N, K = map(int, input().split())

    limit = N - K
    m = N - 1

    fact = [1] * (N + 1)
    invfact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[N] = pow(fact[N], MOD - 2, MOD)
    for i in range(N, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    conn = [0] * (limit + 2)
    conn[1] = 1
    pow2 = [1] * (limit + 2)
    for i in range(1, limit + 2):
        pow2[i] = pow2[i - 1] * 2 % MOD

    for n in range(2, limit + 2):
        total = pow2[n * (n - 1) // 2]
        bad = 0
        for s in range(1, n):
            bad += comb(n - 1, s - 1) * conn[s] % MOD * pow2[(n - s) * (n - s - 1) // 2]
            bad %= MOD
        conn[n] = (total - bad) % MOD

    weight = [0] * (limit + 2)
    for i in range(1, limit + 2):
        weight[i] = conn[i] * (pow2[i] - 1) % MOD
    weight[1] = 1

    dp = [0] * (limit + 1)
    dp[0] = 1
    for i in range(1, limit + 1):
        cur = 0
        for take in range(2, i + 1):
            cur += comb(i - 1, take - 1) * weight[take] % MOD * dp[i - take]
            cur %= MOD
        dp[i] = cur

    ans = 0
    for used in range(limit + 1):
        ans += comb(m, used) * dp[used] % MOD
        ans %= MOD

    ans = ans * N % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先构建连通图计数，因为组件 DP 需要它们。 尺寸仅可达`N-K+1`物质，至多约一半`N`，因为较大的非单一零件会留下太少的组件。 

这`conn`递归通过减去断开的图来计算所有连接的图，其中我们选择包含固定顶点的组件。 两项的幂计算剩余顶点内的任意边。 

这`weight`数组存储删除特殊顶点后单个组件的贡献。 因素`(2^s - 1)`是从该组件到特殊顶点的邻居非空选择的数量。 

主DP只统计非单例部分。 所有其他顶点都被迫隔离，因此在知道 DP 结果后，我们选择哪些顶点参与。 最终乘以`N`是安全的，因为特殊顶点是唯一的。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O((N-K)^2) | O((N-K)^2) | 组件 DP 和连通图递归都在少量可能的额外顶点上运行 |
 | 空间| O(N-K) | 仅存储达到 DP 限制的数组 |

 ## 边缘情况

 对于`N=5, K=4`在这种情况下，特殊顶点必须将剩余的四个顶点分成至少四个分量。 DP 只允许零个额外顶点，因此唯一有效的结构是以特殊顶点为中心的星形图。 该算法精确计算这些图并乘以可能的中心。 

对于`N=7, K=5`在这种情况下，移除特殊顶点必须在六个顶点中留下至少五个分量。 这意味着最多可以将一对顶点连接在一起。 组件 DP 通过允许恰好两个非单一顶点并将其他所有顶点视为孤立的来处理此问题。 

如果一个图有两个可能的高度中心，那么计数就会很危险，因为乘以`N`会重复计算。 这不可能发生在这里。 两个顶点都至少有强迫度`K`在每个生成树中将要求每个生成树至少具有度和`2K`，大于`2N-2`因为`K > N/2`。 该算法依赖于这种唯一性。
