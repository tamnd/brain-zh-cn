 ## 解决方案
 ## 问题理解

 我们有几个筹码放置在一条线上的整数位置上。 我们的目标是使用最便宜的移动顺序移动所有筹码，使它们最终位于一个共享坐标上。 

每个芯片可以以两种不同的方式移动。 筹码可以免费向左或向右跳跃 2 个单位，也可以以 1 个硬币为代价向左或向右移动 1 个单位。 关键的困难在于，零成本变动让我们可以在同一平价类别内自由改变头寸平价，而奇数变动实际上会产生成本。 

任务是计算所需的最小硬币总数，以便所有筹码可以重新定位到相同的整数位置。 

限制很小，最多100个筹码。 这意味着尝试所有候选目标位置的任何解决方案都已经可行，因为检查单个目标在 n 中是线性的，甚至扫描输入范围内的所有坐标在 O(n^2) 中仍然是可以接受的。 然而，动作的结构表明应该存在更多的数学简化，并且最佳解决方案应该将问题简化为与高达 10^9 的大坐标值无关的问题。 

一种简单的方法会考虑选择最小和最大芯片位置之间的每个可能的目标坐标，并计算将所有芯片移动到那里的成本。 问题不在于正确性，而在于冗余，因为许多目标由于奇偶校验而表现相同。 

当所有芯片都已处于同一位置时，会出现微妙的边缘情况。 在这种情况下，答案为零，任何基于移动成本的推理都必须保留这一点。 另一种边缘情况是所有位置共享相同的奇偶校验，例如所有偶数。 在这种情况下，零成本移动可以对齐所有内容，从而导致零答案，即使点之间的距离可能很大。 错误地假设成本等于距离的幼稚方法在这里会失败。 

## 方法

 关键的观察是，移动 2 是免费的，因此任何筹码都可以在具有相同奇偶性的所有位置之间自由移动，而无需支付任何费用。 这意味着我们支付硬币的唯一时间是当我们需要改变奇偶校验时，因为 ±1 的移动会翻转奇偶校验并花费一枚硬币。 

这将问题变成奇偶平衡问题而不是距离最小化问题。 

对于任何选定的目标坐标 T，位置 x 处的芯片有两种可能性。 如果 x 和 T 具有相同的奇偶性，我们可以使用 ±2 步完全移动它，并支付零个硬币。 如果它们的平价不同，我们必须支付至少一枚硬币来调整平价，然后剩下的又可以通过免费±2步来处理。 重要的是，一旦芯片支付了 ±1 步的费用，它就可以有效地将其奇偶性与 T 对齐，并免费完成其余的操作。 

因此，固定目标 T 的成本就是奇偶校验与 T 不同的芯片数量。 

T 的奇偶校验只有两个有意义的选择：偶数或奇数。 如果 T 是偶数，则每个偶数位置筹码的成本为零，每个奇数位置筹码的成本为一个硬币。 如果 T 是奇数，则角色互换。 因此，答案是偶数位置的数量和奇数位置的数量之间的最小值。 

暴力方法将尝试每个可能的目标坐标，计算所有芯片的奇偶校验不匹配，并取最小值。 由于奇偶性完全决定成本，因此这会减少到只有两种情况，而不是最多 10^9 个候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解坐标 | O(n * 范围) | O(1) | O(1) | 太慢/不必要|
 | 奇偶校验计数| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 计算有多少个筹码位置是偶数，有多少个筹码是奇数。 这直接捕获有多少芯片将匹配所选的目标奇偶校验。 
2. 计算如果我们选择偶数目标位置所需的硬币数量。 在这种情况下，每个奇数位置的筹码必须恰好支付一枚硬币来翻转平价，因此成本就是奇数位置的数量。 
3. 计算如果我们选择奇数目标位置所需的硬币数量。 对称地，该成本等于偶数位置的数量。 
4. 返回两个值中的最小值。 这对应于选择最小化所需奇偶校验翻转次数的目标奇偶校验。 

### 为什么它有效

 不变的是，在每个芯片最多进行一次 ±1 移动之后，每个芯片都可以与目标奇偶校验类别对齐，并且从那时起，可以使用自由 ±2 步来完成所有剩余的移动。 由于 ±2 移动可保持奇偶性并允许在奇偶性类别内不受限制地移动，因此距离不再影响成本。 唯一不可降低的成本是芯片是否以相对于所选目标的正确奇偶校验类别启动。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
x = list(map(int, input().split()))

even = 0
odd = 0

for v in x:
    if v % 2 == 0:
        even += 1
    else:
        odd += 1

print(min(even, odd))
```该实现仅跟踪奇偶校验计数。 该循环将数字分为偶数和奇数桶，它们直接对应于两个可能的目标奇偶校验选择。 最终的答案是较小的铲斗尺寸。 

不需要排序或坐标压缩，因为超出奇偶校验的绝对位置是不相关的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(sys.stdin.readline())
    x = list(map(int, sys.stdin.readline().split()))

    even = 0
    odd = 0
    for v in x:
        if v % 2 == 0:
            even += 1
        else:
            odd += 1

    return str(min(even, odd))

# provided sample
assert run("3\n1 2 3\n") == "1"

# all same parity (already optimal)

# all odd
assert run("4\n1 3 5 7\n") == "0"

# mixed balanced
assert run("4\n1 2 3 4\n") == "2"

# single element
assert run("1\n100\n") == "0"

 ## 边缘情况

 当所有筹码已经处于相同位置时，例如`5, 5, 5`，偶数和奇数计数都会合并为一组，并且答案立即变为零。 由于其中一个奇偶校验计数为零，因此该算法可以自然地处理此问题。 

当所有芯片具有相同的奇偶校验但坐标差异较大时，例如`2, 100, 100000`，解仍然返回零，因为奇偶校验消除了所有成本，无论距离如何。 

当分布混合时，例如偶数位置和奇数位置交替时，每个芯片都对其中一个奇偶校验桶做出贡献。 该算法仍然正确地选择较小的桶，确保最少的奇偶校验翻转。
