 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，我们可以重复选择任何数字并将其除以二，向下舍入。 目标是找到至少进行此类操作所需的最少数量$k$数组中的数字相等。 每个操作都会减少一个数字，但不会增加它，并且最终的数字可以包含零。 输入指定$n$，元素数量，以及$k$，我们想要相等的数字的数量。 输出是一个整数，表示除法运算的最小数量。 

限制因素很重要：$n$可以达到20万，数组中的数字也可以达到20万。 一种朴素的暴力方法，尝试对每个数字执行所有操作序列，其执行顺序为$O(200{,}000^2)$操作，远远超出了时间限制。 我们需要一种线性或接近线性扩展的方法$n$以及数字的范围。 

边缘情况包括许多数字已经相等、所有数字都是 2 的不同幂或其中的情况$k$等于$n$。 例如，如果$n = 3$,$k = 3$，数组为 [8, 4, 2]，最少的操作数为 3：将 8 除以 4 (1)、将 8 除以 2 (2)、将 4 除以 2 (3) 得到三个 2。 如果粗心的贪婪算法在第一个相等的对处停止，就会错过全局最小值。 

## 方法

 暴力解决方案在概念上很简单。 对于每个数字，您可以模拟所有除法序列，记录所有中间值，然后尝试选择$k$可以等于每个中间值的数字。 您将对运算求和并选择最小值。 这是可行的，因为每个除法序列都是可预测的，但它太慢了。 如果每个数字最多需要 18 步才能达到零（因为 200,000 → 1 大约是 18 个除法），那么对于$n = 200{,}000$，您已经看到每个数字大约有 360 万个中间值，导致简单枚举需要超过 7000 亿步。 

关键的观察是每个数字都可以表示为每次除法后的值序列。 例如，20 → 10 → 5 → 2 → 1 → 0。我们不需要考虑先除哪个数； 我们只需要知道，对于每个可能的最终值，每个原始数字需要多少次操作才能达到它。 一旦我们收集了这些计数，对于每个候选的最终值，我们可以选择$k$至少进行的最小操作计数$k$等于该值的数字。 

这种观察允许更快的方法。 我们处理每个数字，构建从每个可达值到达到它所需的操作数的映射，然后，对于每个候选值，对操作进行排序并对最小的求和$k$。 这将问题简化为类似的问题$O(n \log n)$总体时间，因为每个数字最多有$\log_2(\text{max a})$转换和排序最多一个小的大小列表$n$每个候选值是有效的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 最大(a) * k) | O(n * 最大(a)) | 太慢了 |
 | 最佳 | O(n log(max(a)) + n log n) | O(n log(max(a)) + n log n) | O(n log(max(a))) | O(n log(max(a))) | 已接受 |

 ## 算法演练

 1.初始化一个字典`ops_map`其中键是表示潜在最终值的整数，值是到达该键所需的操作计数列表。 
2. 对于每个数字`x`在数组中，模拟重复除以二，直到`x`达到零。 保留一个柜台`op`从零开始进行操作。 对于每个值`v`遇到，追加`op`到`ops_map[v]`并增加`op`。 此步骤构建所有可能的目标以及每个数字达到这些目标的成本。 
3. 处理完所有数字后，迭代每个键`ops_map`。 与键关联的每个列表表示可以成为该值的数字的操作计数。 按升序对列表进行排序。 
4. 对于每个键，如果列表至少有$k$元素，对第一个元素求和$k$值来计算所需的总操作$k$等于该值的数字。 跟踪所有键的最小总操作数。 
5. 输出最小总操作数。 这保证了获得至少所需的最小划分数$k$数量相等。 

工作原理：该算法枚举每个数字可以达到的所有值以及达到这些值的成本。 通过求和最小的$k$每个候选值的成本，我们保证所选择的$k$通过最少的操作，所有数字都可以等于该值。 排序可确保我们始终采用成本最低的数字，从而保持最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def main():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    ops_map = defaultdict(list)
    
    for x in a:
        val = x
        op = 0
        while True:
            ops_map[val].append(op)
            if val == 0:
                break
            val //= 2
            op += 1
    
    ans = float('inf')
    for val, ops_list in ops_map.items():
        if len(ops_list) >= k:
            ops_list.sort()
            total_ops = sum(ops_list[:k])
            if total_ops < ans:
                ans = total_ops
    
    print(ans)

if __name__ == "__main__":
    main()
```代码初始化`ops_map`作为列表的默认字典来存储达到每个值的成本。 内循环记录除以二得到的所有中间数，以及所需的运算次数。 最终循环过滤至少可实现的候选值$k$数字，对运算次数进行排序，求和最小的$k$，并更新最小答案。 这`val == 0`条件确保我们将零作为可达值。
