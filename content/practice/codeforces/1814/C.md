 ## 解决方案
 ## 问题理解

 我们被要求将带有彩球的盒子分配给两个机器人，以最大限度地减少一系列请求的总检索时间。 每个盒子都有无限量的独特颜色。 当机器人搜索颜色时，它会从分配的列表中按顺序检查盒子。 第一个机器人花费`s1`每盒秒数，秒`s2`每盒秒数。 一旦机器人找到所需的颜色，搜索就会停止。 我们的目标是将盒子分为两个序列，以便在发出所有请求时，所花费的时间总和最小化。 

输入给出盒子的数量`n`，速度`s1`和`s2`对于两个机器人，以及一个整数列表`r`在哪里`r[i]`是色球出现的次数`i`将被要求。 我们必须输出分配给机器人的两个序列。 每个框必须恰好出现一次，并且每个机器人列表中的顺序会影响时间。 

约束条件意味着`n`最大可达 2×10^5 以及所有的总和`n`跨测试用例的边界为 2×10^5，这允许每个测试用例进行线性时间操作。 每个机器人处理每个盒子的时间很小（最多 10 个），但每种颜色的请求数量最多可达 10^6。 模拟每个请求的每次搜索的简单方法是不可行的，因为操作数量可能达到 10^11。 最佳解决方案必须以这样的方式分配箱子，即尽早找到要求较重的箱子，并根据机器人的速度进行加权。 

边缘情况包括一个机器人比另一个机器人更快或所有请求具有相同频率的情况。 例如，如果`s1=1`,`s2=10`， 和`r=[5,1]`，首先将经常请求的箱子分配给速度更快的机器人至关重要。 随意分配框的粗心方法可能会导致总搜索时间比最小值高几倍。 

## 方法

 暴力方法是尝试两个机器人之间所有可能的盒子分区以及每个分区内的所有排列。 对于每个请求，我们可以模拟所有请求的总搜索时间。 这在原则上是正确的，但不可行，因为分区的数量是 2^n 并且排列的大小是阶乘的。 即使是 n=20 的单个测试用例也会产生数十亿种可能性，远远超过时间限制。 

关键的观察结果是，总搜索时间取决于机器人序列中每个盒子的位置和机器人的速度。 如果机器人有速度`s`检查`k`在到达一盒颜色之前`i`，每个请求的时间贡献为`(k+1)*s*r[i]`。 因此，我们想要具有高`r[i]`尽早出现在更快的机器人列表中。 按降序对所有框进行排序`r[i]`并贪婪地将它们分配给此时会产生较小增量贡献的机器人，从而产生最小的总时间。 这是可行的，因为该问题具有加权两台机器调度问题的结构，其中权重对应于请求计数，处理时间对应于机器人速度。 一旦应用这种贪婪方法，任何盒子分配或重新排序都不会减少贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n × n!) | O(2^n × n!) | O(n) | 太慢了 |
 | 按加权速度进行贪婪分配 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 创建配对列表`(r[i], i)`对于每个盒子。 这里`r[i]`是对盒子的请求数`i`和`i`是箱号。 排序依据`r[i]`确保我们首先处理最需要的箱子。 
2. 将此列表按降序排序`r[i]`。 将首先考虑最频繁请求的框，因此算法优先考虑最小化权重最高的框的时间。 
3.为机器人初始化两个空序列，`a`和`b`，和两个计数器，`time_a`和`time_b`，最初为零。 如果我们将下一个盒子附加到每个机器人，这些计数器将跟踪当前的总增量时间。 
4. 迭代排序列表。 对于每个盒子，计算分配给机器人的增量时间`a`作为`(current_length_a + 1) * s1 * r[i]`和机器人`b`作为`(current_length_b + 1) * s2 * r[i]`。 
5. 将盒子附加到增量时间较小的机器人上。 增加机器人的计数器。 
6.分配所有框后，输出序列`a`和`b`按照分配的顺序。 

为什么它有效：不变的是，在每一步中，我们将盒子分配给总时间增加最少的机器人。 由于请求是独立的，并且总时间与位置乘以请求计数成线性关系，因此这种贪婪的选择首先最小化最大权重的贡献。 排序可确保我们不会不必要地将高重量的盒子放在较慢的机器人上。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, s1, s2 = map(int, input().split())
        r = list(map(int, input().split()))
        boxes = [(r[i], i + 1) for i in range(n)]
        boxes.sort(reverse=True)
        
        # ensure s1 is the smaller time per box for simpler assignment
        if s1 > s2:
            s1, s2 = s2, s1
            swap = True
        else:
            swap = False
        
        a, b = [], []
        len_a, len_b = 0, 0
        for count, idx in boxes:
            if (len_a + 1) * s1 <= (len_b + 1) * s2:
                a.append(idx)
                len_a += 1
            else:
                b.append(idx)
                len_b += 1
        
        if swap:
            a, b = b, a
        
        print(len(a), *a)
        print(len(b), *b)

if __name__ == "__main__":
    solve()
```该解决方案首先通过交换速度来处理机器人 1 比机器人 2 慢的可能性。 排序可确保首先处理请求数较高的框。 基于增量贡献的贪婪分配保证了在每一步中，我们将盒子放置在总时间增加最少的地方。 输出以正确的顺序打印两个序列。
