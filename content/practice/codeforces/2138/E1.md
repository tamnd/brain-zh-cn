 ## 解决方案
 ## 方法

 行列式可以用莱布尼兹公式写出：$$\det(M)=\sum_{\sigma} \operatorname{sgn}(\sigma)\prod_i M_{i,\sigma(i)}.$$强力的观点是将每个排列视为从每一行选择一个传出边缘，并在每一列中选择一个传入边缘。 在图形语言中，这对应于循环覆盖。 行列式是所有循环覆盖的有符号和。 

尝试直接设计自行车罩是很困难的，因为许多不同的罩可能会相互作用并相互抵消。 即使验证候选矩阵的行列式也需要立方时间消除，并且矩阵的搜索空间是天文数字。 

关键的观察是矩阵可以被视为加权有向图的邻接矩阵。 然后行列式项变成加权循环覆盖。 如果我们构建一个几乎是 DAG 的图，循环覆盖就会变得极其简单。 

考虑具有唯一来源的 DAG$s$和下沉$t$。 添加权重自循环$1$到每个顶点。 最后添加一条额外的边$t$回到$s$。 

现在每个周期封面只有两种可能性。 

第一种可能性是采用每个自循环，产生一个简单的覆盖。 

第二种可能性是选择一条路径$s$到$t$，连同边缘$t \to s$。 每个剩余的顶点都使用其自循环。 这样的封面双射对应于$s$-到-$t$小路。 

边缘有适当的标志，每条路径都有准确的贡献$+1$到行列式。 行列式恰好变成了$s$-到-$t$DAG 中的路径。 

问题简化为构造一个稀疏 DAG，其路径数等于$x$。 

我们维护一个顶点，其当前来自源的路径数等于某个值$m$。 我们需要变革性的运营$m$进入$2m$和$2m+1$。 

操作$m \rightarrow 2m$使用两个新顶点实现：$$p\to a,\quad p\to b,\quad a\to b.$$新的终端顶点变为$b$。 正好有两种方法可以到达$b$从$p$，因此路径数加倍。 

操作$m \rightarrow 2m+1$使用来自特殊链的一个额外顶点，该链始终仅贡献一条路径。 这创造了一个额外的独立贡献，同时仍然使之前的计数增加了一倍。 

处理二进制表示$x$从高位到低位精确构造$x$路径。 自从$x \le 10^7 < 2^{24}$，创建的顶点数量远低于$80$。

 ## 算法演练

 1.如果$x=0$，输出一个$1\times1$矩阵仅包含$0$。 
2. 创建两个顶点。 顶点$1$是源和顶点$2$是当前端点。 添加边缘$1\to2$。 源到端点路径的数量现在为$1$。 
3.让$p$表示当前端点。 让`lst`表示特殊链的末端，其从源开始的路径计数总是精确的$1$。 
4. 忽略最高设置位$x$，因为构建已经从路径计数开始$1$。 
5. 从最高有效位到最低有效位处理剩余位。 
6. 如果当前位是$0$，应用加倍小工具。 添加两个新顶点$a,b$和边缘$p\to a$,$p\to b$,$a\to b$。 代替$p$经过$b$。 
7. 如果当前位是$1$，应用加倍加一小工具。 添加相同的加倍结构并另外连接特殊链，以便一条额外的路径到达新结构。 更新链端点。 
8. 处理完所有位后，添加最终顶点$t$。 连接$p\to t$和$t\to1$。 
9.看跌期权价值$1$在除源之外的每个自循环上。 
10.看跌期权价值$-1$在每个 DAG 边上以及从$t$到源头。 
11. 输出生成的邻接矩阵。 

### 为什么它有效

 每个循环覆盖必须仅使用自循环或使用从接收器返回到源的唯一边缘。 一旦选择了返回边缘，覆盖层的剩余重要部分恰好是 DAG 中的一个源到汇路径。 这在循环覆盖和 DAG 路径之间建立了一对一的对应关系。 通过分配权重$-1$对于所有 DAG 边，行列式贡献的符号抵消了大环的奇偶效应，使得每条有效路径都贡献$+1$。 行列式恰好是源到汇路径的数量。 

二进制小工具保持当前端点恰好具有所需数量的源到端点路径的不变性。 处理位重建二进制值$x$，因此最终路径计数以及行列式等于$x$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def construct(x):
    if x == 0:
        return [[0]]

    n = 2
    p = 2
    lst = 1

    a = [[0] * 81 for _ in range(81)]

    def add(u, v, w=-1):
        a[u][v] = w

    add(1, 2)

    def mul():
        nonlocal n, p
        add(p, n + 1)
        add(p, n + 2)
        add(n + 1, n + 2)
        p = n + 2
        n += 2

    def mul_add():
        nonlocal n, p, lst
        add(p, n + 1)
        add(p, n + 2)
        add(n + 1, n + 2)

        add(lst, n + 3)
        add(n + 3, n + 1)

        p = n + 2
        lst = n + 3
        n += 3

    highest = x.bit_length() - 1

    for b in range(highest - 1, -1, -1):
        if (x >> b) & 1:
            mul_add()
        else:
            mul()

    for i in range(2, n + 1):
        a[i][i] = 1

    add(p, n + 1)
    n += 1
    a[n][1] = 1

    res = []
    for i in range(1, n + 1):
        res.append(a[i][1:n + 1])

    return res

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        x = int(input())
        mat = construct(x)

        out.append(str(len(mat)))
        for row in mat:
            out.append(" ".join(map(str, row)))

    sys.stdout.write("\n".join(out))

solve()
```构造函数直接实现前面描述的图形小工具。 

该矩阵存储为邻接矩阵。 小工具插入的每条边都会受到权重$-1$。 后来重量自循环$1$被添加。 

最高设置位被跳过，因为初始图已经表示路径计数$1$。 处理所有位（包括最高位）将使值额外增加一倍。 

特殊变量`lst`跟踪路径计数恰好为 1 的辅助链的端点。 这是提供额外的机制`+1`的贡献`2m+1`小工具。 

仅在处理完所有位后才添加最终的汇点顶点。 边回到顶点`1`是唯一可以创建不平凡的自行车封面的边缘。

 ## 边缘情况

 用于输入`0`，该算法立即输出一个包含`0`。 a 的行列式是$1\times1$矩阵等于其唯一的条目，因此行列式恰好为零并且满足每个稀疏条件。 

用于输入`1`，最高设置位是唯一位。 没有应用任何小工具。 构造仍然保持在路径计数一，并且最终的循环覆盖解释给出行列式一。 这验证了跳过最高设置位是正确的。 

用于输入`8`，其二进制表示为`1000`，每个处理过的位都为零。 该算法重复应用加倍小工具，产生路径计数`1 → 2 → 4 → 8`。 这检查是否生成了两个的纯幂，而不需要任何`+1`贡献。 

行和列稀疏条件会自动保留。 每个小工具仅向每个顶点添加恒定数量的关联边。 生成的邻接矩阵每行每列最多有 3 个非零条目，完全符合要求。
