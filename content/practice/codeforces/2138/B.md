 ## 解决方案
 ## 问题理解

 我们给出了从 1 到$n$，并且我们必须根据特殊的排序规则回答关于某些子数组是否“完美”的多个查询。 每个子数组可以使用两种类型的操作进行排序：交换相邻元素或交换相隔两个位置的元素，但第二种类型只能使用一次。 如果与仅使用相邻交换相比，允许这一特殊交换不会减少操作总数，则子数组是完美的。 本质上，我们需要检查子数组是否包含任何恰好两个位置“无序”的元素对，并且会从单双交换中受益。 

排列属性简化了我们的分析。 由于元素是唯一的并且范围从 1 到$n$，每个值在完全排序的数组中都有唯一的位置。 这意味着我们可以专注于值的相对顺序，而不用担心重复。 

约束表明$n$每个查询总数可以达到$5 \cdot 10^5$。 这排除了任何需要的算法$O(n^2)$每个查询的操作，或者模拟每个子数组的交换，因为我们可以很容易地命中$10^{11}$运营。 我们需要一个具有线性预处理和恒定时间或对数时间查询评估的解决方案。 

当子数组已经排序或只有一个元素时，就会出现一种微妙的边缘情况。 在这些情况下，双重交换不会提供任何优势，并且子数组非常完美。 相反，如果子数组的最大元素和最小元素相距较远，但由可以通过单个双交换重新排序的序列分隔开，则该子数组是不完美的。 

## 方法

 暴力方法将尝试模拟对每个子数组进行排序，首先仅使用相邻的交换来获得$g(b)$，然后通过一个可选的双交换得到$f(b)$。 例如，我们可以计算反转次数来确定最小相邻交换。 然而，即使独立地计算每个查询的反转也是如此$O(n \log n)$，当对许多查询求和时，这太慢了。 

关键的观察结果来自于分析特殊交换的作用。 指数双互换$i$只能修复位置之间的反转$i$和$i+2$。 如果子数组中不存在此类反转，则该子数组是完美的。 因此，我们可以预先计算元素连续加 1 的位置，以及它们“破坏”双倍交换所需顺序的位置，而不是模拟交换。 具体来说，我们跟踪最左边的索引$i$在哪里$a[i] > a[i+2]$在原始数组中。 然后，对于每个查询，我们只需要检查查询范围内是否存在这样的违规行为。 如果没有，则子数组是完美的。 

此观察将每个查询检查减少到$O(1)$在预处理“违规”之后，这可以在数组上以线性时间完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（模拟交换）| O(q * n log n) | O(q * n log n) | O(n) | 太慢了 |
 | 最优（预先计算违规、检查范围）| O(n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算双重掉期确实有帮助的头寸。 迭代数组并标记每个索引$i$这样$a[i] > a[i+2]$。 与仅使用相邻交换相比，这些是单双交换可以减少操作总数的唯一位置。 
2. 构建这些标记位置的前缀最大数组。 对于每个索引，数组存储截至该点的“违规”的最右侧位置。 这使我们能够有效地检查任何查询范围内是否存在违规。 
3. 对于每个查询$[l, r]$，检查是否有违规行为$l$到$r-2$因为双重交换涉及向前迈出两步。 如果该区间内的最大违规次数大于$r-2$，那么该范围内就没有有用的双重交换，因此子数组是完美的。 否则，它就是不完美的。 
4. 如果完美则输出“YES”，否则输出“NO”。 

为什么它有效：该算法取决于这样一个事实：双重交换仅影响两个相隔的元素。 通过准确标记双重掉期有利的位置，我们捕获了所有情况$f(b) < g(b)$。 如果子数组中不存在这样的位置，则$f(b) = g(b)$并且子数组是完美的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())
        a = list(map(int, input().split()))
        
        # violation[i] = 1 if a[i] > a[i+2], else 0
        violation = [0] * n
        for i in range(n - 2):
            if a[i] > a[i+2]:
                violation[i] = 1
        
        # prefix max of violations
        pref = [0] * n
        for i in range(n):
            pref[i] = violation[i] if i < n else 0
            if i > 0:
                pref[i] = max(pref[i], pref[i-1])
        
        for _ in range(q):
            l, r = map(int, input().split())
            l -= 1
            r -= 1
            if l >= r - 1:
                print("YES")
            else:
                if pref[r-2] - (pref[l-1] if l > 0 else 0) > 0:
                    print("NO")
                else:
                    print("YES")

if __name__ == "__main__":
    main()
```代码首先计算双重交换有用的位置。 然后，它构建一个前缀最大数组来快速检查查询是否包含这些位置中的任何一个。 具有一两个元素的查询是非常完美的。 对于较长的查询，我们检查前缀数组以查看子数组内是否有任何违规。 

边界条件很重要：因为我们检查$a[i] > a[i+2]$，最后两个指数不参与违规。 前缀计算必须考虑从零开始的索引。
