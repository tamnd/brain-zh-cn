 ## 解决方案
 ## 问题理解

 该问题给出了从 1 到 1 的整数排列$n$并要求我们考虑基于一组间隔的某些“有趣”排列。 每个间隔允许我们在选定的索引处将其分成左段和右段$k_i$，然后我们取左段的最大值和右段的最小值。 如果**所有左段最大值中的最大值严格小于所有右段最小值中的最小值**，则排列是有趣的。 一旦我们知道某个排列是有趣的，我们就会被要求确定这种排列中可能的**最大反转数**，或者如果不存在有趣的排列则报告 -1。 

输入由多个测试用例组成，每个测试用例指定排列的长度$n$, 间隔数$m$，以及间隔列表$[l_i, r_i]$。 约束足够严格，以至于生成所有排列的简单方法是不可行的：$n$和$m$每个最多可以达到 5000，意思是$n!$排列不能直接探索。 因此，解决方案必须推理排列和区间的结构，而不是枚举排列。 

微妙之处来自于重叠的音程或相互包含的音程。 一种粗心的方法，假设间隔不重叠或者$k_i$可以为每个间隔独立选择，而不考虑交互会失败。 当间隔共同使得不可能满足左最大 < 右最小条件时，就会出现另一种边缘情况，例如，如果某个间隔几乎覆盖整个排列或强制左段最大值大于某个右段最小值。 

## 方法

 暴力方法将尝试枚举所有排列和所有有效的$k_i$每个区间的选择。 对于每个排列，我们可以计算所有间隔的左最大和右最小并检查有趣的条件，然后计算反转。 这在计算上是不可行的，因为$n!$阶乘增长。 

解锁最佳解决方案的关键观察是我们根本不需要枚举排列。 这些间隔强加**一种分割点结构**，最多允许**一个反转区域**：分割间隔左侧的所有元素必须小于右侧的所有元素才能满足感兴趣的条件。 因此，通过将**最大数字放在左侧区域**和**最小数字放在右侧区域**，同时考虑区间分割，可以获得最大化反转的排列。 那么反转的数量就是左右区域大小的乘积，加上每个区域内递归的反转。 

此外，如果某些间隔的左侧区域重叠或右侧区域重叠的方式使得所需的排序变得不可能，则不存在有趣的排列。 检测到这一点减少为计算**左段之间的最大前缀索引**和**右段之间的最小后缀索引**。 如果最大左索引达到或超过最小右索引，则不能满足条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * m) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$m$并存储所有间隔$[l_i, r_i]$。 如果$m = 0$，那么任何排列都是有趣的，并且最大反转是$\binom{n}{2} = n(n-1)/2$。 
2. 计算两个值：`max_left`作为最大值`l_i`在所有间隔中，并且`min_right`作为最小值`r_i`所有间隔之间。 这些对应于**我们可以在左侧段中进入的最右侧**和**我们可以在右侧段中开始的最左侧**。 
3.如果`max_left >= min_right`，任何选择都不能满足左最大和右最小条件$k_i$。 输出-1。 
4. 否则，计算左侧区域的大小 (`max_left`）和右区（`n - min_right + 1`）和中间区域（`min_right - max_left - 1`）。 将最大的数字放在左侧区域，将最小的数字放在右侧区域，以最大化反转。 
5. 最大反转数是通过**计算左右区之间的反转数**得到的：左区中的每个数字与右区中的每个数字形成一个反转，加上**左区**内**和**右区内**的所有反转，当每个区中的数字递减时，它们是最大的。 
6. 返回每个部分的反转总和。 

**为什么它有效：** 关键的不变量是任何有趣的排列都必须满足**所有左最大数字小于所有右最小数字**。 通过计算左右区域的极值位置，我们可以立即确定可行性。 一旦确认可行性，则通过对每个区域内的数量进行递减排序来获得最大反演次数，保证所有跨区域和区域内的反演都被统计到。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        intervals = [tuple(map(int, input().split())) for _ in range(m)]
        if m == 0:
            # Any permutation is interesting
            print(n * (n - 1) // 2)
            continue
        max_left = max(l for l, r in intervals)
        min_right = min(r for l, r in intervals)
        if max_left >= min_right:
            print(-1)
            continue
        # Sizes of zones
        left_size = max_left
        right_size = n - min_right + 1
        mid_size = n - left_size - right_size
        # Maximum inversions:
        inversions = (left_size * (left_size - 1)) // 2
        inversions += (right_size * (right_size - 1)) // 2
        inversions += left_size * right_size
        inversions += (mid_size * (mid_size - 1)) // 2
        # Include cross inversions for middle zone
        inversions += mid_size * (left_size + right_size)
        print(inversions)

if __name__ == "__main__":
    solve()
```该解决方案仔细计算极左和极右索引以检查可行性。 然后，它使用组合公式计算反演，而不生成任何排列。 注意包括所有跨区域反转，包括中间区域（如果存在）。
