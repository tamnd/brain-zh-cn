 ## 解决方案
 ## 问题理解

 该问题涉及一只乌龟玩多个整数序列和一个非负整数$x$。 对于每个序列，海龟只能执行一次操作：他设置$x$到$\text{mex}$其当前值以及所选序列中的数字。 目标是找到最大值$x$对于给定的起始值可达$k$，表示为$f(k)$。 最终，我们需要总和$f(k)$为所有人$k$从$0$到$m$。 

输入由多个测试用例组成。 每个测试用例给出$n$序列，每个序列可能高达$2 \cdot 10^5$元素和上限$m$的起始值$x$。 跨测试用例的所有序列的总和为$2 \cdot 10^5$，这意味着对于每个测试用例，我们无法模拟所有测试用例$x$单独值如果$m$很大。 我们需要一种有效的方法$m$最多$10^9$。 

边缘情况包括仅包含大数的序列，因此它们不会影响小的初始值$x$值，包含影响的连续小数字的序列$\text{mex}$重重地，并开始$x$值超出所有存在的数字，这可能会产生不同的行为。 一种简单的迭代方法$x$从$0$到$m$并且模拟所有序列将会慢得难以置信。 

## 方法

 蛮力方法将迭代每个可能的起始值$k = 0 \dots m$，以每个可能的顺序应用所有序列，并计算最大值$x$。 这是正确的，但很棘手，因为$m$可以大到$10^9$，以及每个$x$可能会触发一连串$n$行动、给予$O(m \cdot n)$最少的操作。 

关键的见解是该函数$f(k)$具有由序列确定的分段线性模式。 每个序列只能递增$x$到其集合中相对于的下一个缺失数字$x$。 通过预先计算每个序列中最小的排除数作为偏移量，我们可以确定重复模式$f(k)$然后使用算术级数有效地计算总和，而无需迭代所有$k$。 本质上，序列划分了$x$-axis 进入范围，其中$f(k)$以可预测的方式增长。 

这将问题简化为计算有多少个起始值$k$映射到相同的$f(k)$并使用连续整数之和的公式来计算$\sum f(k)$迅速地。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m * n) | O(l_i 总和) | 太慢了 |
 | 最佳 | O(n + l_i 总和 + log(max(a_i))) | O(总和 l_i + n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$序列并将每个序列展平为一组以删除重复项。 将这些集合存储在列表中。 这确保了$\text{mex}$计算正确，避免了冗余操作。 
2.初始化一个数组`count`记录有多少个序列包含每个数字。 我们只需要粗略的数字$n$因为$\text{mex}$永远不能超过序列总数加上起始值。 
3. 计算每个序列相对于起始的最小排除数$x=0$。 这告诉我们通过选择这个序列可以获得的第一个数字。 跟踪序列中的所有此类数字。 
4. 对最小排除数进行排序。 的成长$f(k)$现在是分段线性的：如果$x$低于最小排除数，按顺序选择序列$x$每次加一。 该模式会重复，并且可以使用算术公式求和。 
5. 对于每个范围$x$由连续的最小排除数定义，计算总和$f(k)$直接使用算术级数公式：$\sum_{i=0}^{r} (start + i) = (r + 1) \cdot start + r \cdot (r + 1)/2$。 
6. 如果$m$超过最大最小排除数，通过继续算术级数超出最后一个阈值来扩展总和。 
7. 输出测试用例的总和。 

该方法避免了迭代所有$x$单独地，降低了复杂性$O(m \cdot n)$到$O(n + \sum l_i + \text{sort})$，这是可行的。 

为什么它有效：$\text{mex}$操作保证每个序列只能增加$x$直到该序列中缺少的第一个数字并且$x$。 对最小排除数进行排序可以保证我们始终知道哪些$x$值是可实现的，并且算术级数公式有效地对分段线性函数求和$f(k)$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        count = {}
        total_numbers = 0
        for _ in range(n):
            arr = list(map(int, input().split()))[1:]
            unique = set(arr)
            for num in unique:
                count[num] = count.get(num, 0) + 1
            total_numbers += len(unique)

        # Build the list of minimal excluded numbers
        mex_candidates = sorted(count.keys())
        result = 0
        prev = -1
        for mex in mex_candidates:
            length = min(m, mex - 1) - prev
            if length > 0:
                result += (prev + 1 + mex - 1) * length // 2
                prev = mex - 1
            if prev >= m:
                break
        if prev < m:
            length = m - prev
            result += (prev + 1 + m) * length // 2
        print(result)

if __name__ == "__main__":
    solve()
```该代码首先读取序列，将其展平以删除重复项，然后对出现次数进行计数。 对最小排除数进行排序允许我们划分范围$0 \dots m$划分为线性和的区间$f(k)$。 算术级数公式有效地对每个区间求和。 最终的扩展句柄$m$大于遇到的最大数。
