 ## 解决方案
 ## 问题理解

 给定几个非负整数序列和一个初始整数$x$。 海龟可以重复选择任意序列并替换$x$与墨西哥人$x$以及该序列中的所有数字。 集合的 mex 是集合中不存在的最小非负整数。 目标是确定最大值$x$从给定的起点可以到达$k$。 这个函数称为$f(k)$。 最后，对于非负整数$m$，我们需要计算总和$f(0) + f(1) + \dots + f(m)$。 

约束告诉我们序列总数和所有序列中的元素总数最多为$2 \cdot 10^5$。 这排除了任何显式模拟每个可能的操作的算法$x$在范围内$0$到$m$， 因为$m$可以大到$10^9$。 任何对所有可能的暴力迭代方法$x$值是不可行的。 

一个微妙的方面是序列可以包含非常大的数字，可能比$m$，并且它们可能包含重复项。 一种追踪所有可能的天真的方法$x$值或使用大型数组将因内存或性能而失败。 边缘情况包括已经包含 0 的序列、由重复的相同数字组成的序列以及其中的情况$m$小于序列可实现的最大 mex。 

## 方法

 蛮力方法将尝试模拟每次启动的操作$x$从$0$到$m$。 对于每个$x$，我们可以对所有序列重复应用 mex 操作，直到$x$不再增加。 原则上这是正确的，但是随着$m$最多$10^9$，这将需要数十亿次迭代，这是不切实际的。 

关键的见解是认识到序列共同定义了“墨西哥边界”。 定义集合$S$序列中出现的所有数字。 最大$x$从任何开始都可以实现$k$由不在其中的最小非负整数确定$S$那至少是$k$。 这是因为对序列重复应用 mex 可以让我们“跳跃”$x$到任何缺失的整数$S$多于$x$，但我们不能超出序列中按顺序缺失的第一个整数。 因此，我们可以预先计算从 0 到第一个未被覆盖的整数的所有数字的 mex$S$，然后求和$f(k)$超过$0 \le k \le m$有效地使用算术级数公式来计算范围，其中$f(k)$是恒定的。 

这种见解减少了对每个问题的迭代模拟$x$从序列中计算一组整数，然后在连续的范围内执行一次传递$k$值来有效地计算总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m * 总长度) | O(米) | 太慢了 |
 | 最佳 | O(总长度 + mex_max) | O(总长度 + mex_max) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取序列数$n$和上限$m$。 
2. 构造一个集合$S$包含出现在任何一个中的每个整数$n$序列。 重复是无关紧要的，因为 mex 只关心存在。 
3. 初始化变量$mex = 0$。 增量$mex$尽管$mex$是在$S$。 在这个循环之后，$mex$是不存在于任何序列中的最小非负整数。 该值是从以下位置开始可实现的最大 mex$0$。 
4.观察对于任何起始值$k \ge mex$,$f(k) = k + 1$。 对于任何$k < mex$,$f(k) = mex$。 这给了我们两个连续的范围$k$:$0 \le k < mex$和$mex \le k \le m$。 The sum over each range can be computed using arithmetic progression formulas.
 5. 计算第一个范围的总和：$\text{sum1} = mex \cdot \min(m+1, mex)$。 这涵盖$f(k) = mex$为了$k < mex$或者$k \le m$，以较小者为准。 
6. 计算第二个范围的总和，如果$m \ge mex$:$\text{sum2} = \frac{(m + mex + 1)(m - mex + 1)}{2}$。 这是来自的连续整数的总和$mex$到$m$包容性。 
7. 最终答案是$\text{sum1} + \text{sum2}$。 
8. 对所有测试用例重复此操作。 

为什么它有效：该算法依赖于所有序列的 mex 给出序列无法到达的第一个整数的不变式。 每一次操作只能增加$x$按顺序到下一个缺失的整数。 所以，$f(k)$直到 mex 为止都是恒定的，然后线性增长。 这保证了正确性，而无需迭代每个可能的$x$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        S = set()
        for _ in range(n):
            data = list(map(int, input().split()))
            l_i = data[0]
            S.update(data[1:])
        mex = 0
        while mex in S:
            mex += 1
        limit = min(m, mex - 1)
        sum1 = mex * (limit + 1)
        if m >= mex:
            sum2 = (m + mex) * (m - mex + 1) // 2
        else:
            sum2 = 0
        print(sum1 + sum2)

if __name__ == "__main__":
    solve()
```第一个循环构建序列中所有数字的集合。 使用集合可以保证 O(1) 平均插入和查找。 计算 mex 可确保我们识别序列无法到达的第一个整数。 算术级数公式源自以下观察：$f(k)$在 mex 以下是常数，之后是线性的。 当以下情况时要注意边界：$m < mex$以避免负范围。 

## 工作示例

 样本1：

 | k | f(k) | f(k) |
 | ---| ---|
 | 0 | 3 |
 | 1 | 3 |
 | 2 | 3 |
 | 3 | 3 |
 | 4 | 4 |

 计算总和：$3 + 3 + 3 + 3 + 4 = 16$。 该表确认了我们的范围划分：$k < mex = 4$f(k) = 3，k = 4，f(k) = 4。 

样本2：

 | k | f(k) | f(k) |
 | ---| ---|
 | 0 | 4 |
 | 1 | 4 |
 | 2 | 4 |
 | 3 | 4 |
 | 4 | 4 |

 计算总和：$4 + 4 + 4 + 4 + 4 = 20$。 这里，mex = 5，所以所有 k ≤ m 都有 f(k) = mex，显示算术级数处理。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
