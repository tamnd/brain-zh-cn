 ## 解决方案
 ## 问题理解

 我们被要求找到长度排列中反转的最大数量$n$满足由一组间隔定义的特定“有趣”属性。 每个区间$[l_i, r_i]$有一个选择$k_i$使得左段的最大值$[l_i, k_i]$严格小于右段的最小值$[k_i + 1, r_i]$。 选择这些之后$k_i$对于所有间隔的值，所有左段最大值的总体最大值必须小于所有右段最小值的总体最小值。 如果没有排列满足这一点，则答案是$-1$。 否则，我们需要具有最多反转的排列，其中反转是一对位置$i < j$这样$p_i > p_j$。 

限制条件适中：$n$最多可达 5000，但总和$n$所有测试用例的数量也以 5000 为界。最多可以有$m = n/2$间隔，但重要的是在这个简单的版本中，间隔是严格不重叠和排序的：$r_i < l_{i+1}$。 这简化了关于它们的相对最大值和最小值的推理，因为我们永远不必处理交叉或重叠约束。 尝试所有排列的简单方法是不可能的，因为$n!$增长速度比任何可行的操作数都要快得多。 

当出现不明显的边缘情况时$m = 0$，即没有间隔。 那么有趣的条件通常成立，并且最大反转计数是完全反向排列的计数。 另一种边缘情况是间隔是连续的或几乎占据整个数组时； 允许的结构可以强制最大反转计数小于可能的反转总数$n$。 粗心的方法可能会错误计算这一点，因为它们可能会忽略在所有间隔中分离左最大和右最小的需要。 

## 方法

 暴力方法会枚举所有$n!$排列，检查每个区间选择$k_i$，计算左右部分的最大值和最小值，然后验证感兴趣的条件。 如果满足，则计算反转。 这在理论上是正确的，但完全不可行； 甚至为了$n = 10$,$n!$超过300万，这里$n$可以是5000。 

关键的见解来自于观察间隔不重叠。 让我们定义$X$作为最大的位置左侧的位置集$k_i$在所有间隔中，并且$Y$作为最小的右侧的位置$k_i$。 然后，有趣的条件简化为一个简单的排序约束：所有数字都在$X$必须小于中的所有数字$Y$。 由于间隔不重叠，我们可以将数组划分为连续的块，这些块完全位于$X$或者$Y$或在任何区间之外。 为了最大化反转，我们应该将最大的数字尽可能放在最左边，同时尊重数字的约束$X$小于中的数字$Y$。 在区间之外，我们可以反转片段以最大化局部反转。 

因此，最佳解决方案是贪婪的：确定必须由感兴趣的条件（实际上是最大左最大边界）分隔的第一个位置，并将最大的数字放在它后面。 然后，对于没有约束的每个连续段，我们可以按降序排列数字以最大化反转。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * m) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.如果$m = 0$，没有间隔。 有趣的条件是空性满足的，因此最大反转发生在完全反向排列中。 这会产生$n*(n-1)/2$倒置。 
2. 否则，确定影响数组左侧部分的第一个区间。 让`pos`是第一个区间的右端点。 由于区间是不相交且已排序的，`pos`有效地将必须位于感兴趣边界左侧和右侧的元素分开。 
3. 通过放置以下数字来构建排列`pos+1`到`n`首先按降序排列。 这些数字保证大于左侧区间中的所有数字，满足条件`max(left) < min(right)`。 
4. 放置数字`1`到`pos`在前一个块之后按降序排列。 这可以在不违反有趣条件的情况下最大化左段内的反转。 
5. 直接使用反向排序数组的公式计算反转计数：对于任意长度的连续块`l`，最大反转次数为`l*(l-1)/2`。 跨块的反转也很自然地发生，因为右块中较大的数字先于左块中较小的数字。 

为什么它有效：由第一个间隔确定的分离点就足够了，因为所有间隔都是不重叠的。 左段包含的数字小于右段，因此有趣的条件成立。 在每个段内，按降序排列数字可确保在不违反条件的情况下实现所有可能的反转。 没有其他排序可以产生更多的反转，因为只有当我们将较小的数字放在段内较大的数字之前或违反左最大和右最小之间的边界时，反转才会丢失。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_inversions(n, m, intervals):
    if m == 0:
        return n * (n - 1) // 2
    # the first interval defines the left/right separation
    pos = intervals[0][1]
    left_len = pos
    right_len = n - pos
    # max inversions: reverse the right block first, then left block
    return right_len * left_len + left_len * (left_len - 1) // 2 + right_len * (right_len - 1) // 2

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    intervals = [tuple(map(int, input().split())) for _ in range(m)]
    print(max_inversions(n, m, intervals))
```该解决方案首先检查是否不存在间隔，返回反转排列的完整反转计数。 否则，它计算分离点`pos`作为第一个区间的右边界。 反转数量是每个段内反转的总和加上跨越边界的反转的总和，通过乘以左右块的大小来计算。 我们永远不需要显式地构造排列； 反演公式就足够了。 主要的微妙之处是正确识别`pos`并处理从 1 开始的索引，这与输入格式一致。
