 ## 解决方案
 ## 问题理解

 我们有一个棋盘的四个独立的正方形碎片，每个碎片都是一个$n \times n$网格，其中每个单元格都已着色为黑色或白色。 价值$n$很奇怪，目标是将这四块组装成一个更大的$2n \times 2n$棋盘。 

我们可以将这四个棋子按任意顺序放置，但不能旋转或翻转它们。 将它们放入后$2 \times 2$块的布局，我们可以重新着色单个单元格。 成本是我们改变颜色的单元格的数量。 最终的目标是由此产生的$2n \times 2n$grid 是一个有效的棋盘，这意味着每个单元格的颜色与其相邻单元格的颜色不同。 

任务是在选择四件作品的最佳排列后，尽量减少所需的重新着色次数。 

约束条件$n \le 100$意味着每块最多有 10,000 个单元，因此完整的输入足够小，我们可以直接计算块之间的成本。 任何尝试所有放置的解决方案都是可行的，因为只有$4!$排列。 

一个微妙的点是，最终棋盘中的邻接跨越了棋子边界。 因此，相邻放置的两个部件在它们的接触边缘上施加了约束。 这就是天真的独立处理失败的地方。 

一个典型的错误是假设每个棋子都可以独立地制成棋盘图案，然后简单地组合起来。 这忽略了颜色奇偶性必须跨边界匹配。 例如，如果两个相邻的块都假设左上角单元格为黑色，但它们的相对偏移量不一致，则会发生边界冲突并且成本意外增加。 

另一个微妙的问题是，自从$n$很奇怪，每个块内的坐标奇偶校验行为一致，这意味着每个块在放置在最终网格中时都有固定的“检查奇偶校验对齐”。 这种对齐方式取决于该作品被分配到四个象限中的哪一个。 

## 方法

 蛮力视图首先注意到每个棋子都可以放入最终的四个象限中的任何一个$2n \times 2n$木板。 有$4!$将棋子分配给象限的方法，因此我们可以尝试所有排列。 

对于固定分配，我们必须计算需要翻转多少个单元格，以便最终的板正确交替。 最终的棋盘本身只有两种有效的颜色：左上角的单元格是黑色或白色。 一旦起始选择确定，所有其他单元格都由坐标奇偶性确定。 

因此，对于每个排列和两个起始颜色中的每一个，我们计算所有的不匹配成本$4n^2$细胞。 这已经足以保证正确性。 

关键的观察是我们永远不需要增量地模拟重新着色。 每个单元格独立贡献：我们只需要检查其当前颜色是否与最终位置的预期棋盘颜色匹配。 

这将问题简化为评估恒定数量的配置：$4!$排列乘以 2 个全局着色，每个都签入$O(n^2)$。 

一个更微妙的结构洞察是，每个部分总是落在一个固定的象限中，因此它的坐标会移动但不会变换。 这使得预期的颜色公式统一且易于计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过完整模拟对展示位置进行暴力破解 |$O(4! \cdot n^2)$|$O(n^2)$| 已接受 |
 | 具有奇偶成本计算的最优枚举 |$O(4! \cdot n^2)$|$O(n^2)$| 已接受 |

 在实践中，两种描述都归结为相同的算法，但“最佳”框架避免了不必要的状态模拟，并纯粹专注于奇偶校验比较。 

## 算法演练

 我们将这四块标记为$P_0, P_1, P_2, P_3$。 我们考虑了将它们分配到四个象限的所有方法：左上、右上、左下、右下。 

1. 生成四个棋子的所有排列。 每个排列代表象限中的一个固定位置。 这已经足够了，因为象限是不同的，并且旋转不会降低对称性。 
2. 对于每个排列，考虑两种可能的最终棋盘颜色。 人们假设细胞$(0,0)$是白色的，另一个假设是黑色的。 这些是唯一有效的全局模式，因为每个棋盘都是由其起始单元决定的。 
3. 对于每个单元格$(i, j)$在一块内部，计算其最终坐标$2n \times 2n$板取决于其指定的象限。 这是一个简单的偏移：左上角添加$(0,0)$, 右上角添加$(0,n)$, 左下角添加$(n,0)$，右下角添加$(n,n)$。 
4. 使用奇偶校验确定最终位置处的预期颜色。 如果我们将起始颜色定义为 0，则预期颜色为$(i + j) \bmod 2$。 如果起始颜色为 1，我们将其反转。 
5. 将预期颜色与给定单元格颜色进行比较并累积不匹配计数。 此计数表示此配置需要多少次重新着色操作。 
6. 跟踪所有排列和两个起始颜色选择的最小不匹配。 

结果是有限配置空间上的最小值，其中每个配置成本都是在网格上以线性时间计算的。 

### 为什么它有效

 每个有效的最终棋盘都由两个选择唯一确定：将棋子放置到象限中以及全局奇偶校验偏移。 一旦这些被修复，每个单元格的正确颜色将由奇偶校验强制执行，并且独立于所有其他单元格。 因此，成本函数分解为独立的每单元不匹配的总和，并且在小配置空间上的穷举搜索保证了全局最优值被检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def read_piece(n):
    g = []
    for _ in range(n):
        line = input().strip()
        g.append([int(c) for c in line])
    return g

def solve():
    n = int(input().strip())
    input()  # consume empty line after n

    pieces = []
    for _ in range(4):
        pieces.append(read_piece(n))
        input()  # empty line between pieces

    # quadrant offsets
    offsets = [(0, 0), (0, n), (n, 0), (n, n)]

    import itertools

    ans = 10**18

    for perm in itertools.permutations(range(4)):
        for start in (0, 1):
            cost = 0

            for qi in range(4):
                pi = perm[qi]
                ox, oy = offsets[qi]
                piece = pieces[pi]

                for i in range(n):
                    for j in range(n):
                        final_parity = (ox + i + oy + j) & 1
                        expected = final_parity ^ start
                        cost += (piece[i][j] != expected)

            ans = min(ans, cost)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先仔细解析四个网格，注意块之间的空行。 这是此问题中错误的常见来源，因为跳过或误读分隔符会错误地移动所有后续部分。 

每个排列都以固定顺序将棋子分配到象限。 偏移数组对最终电路板中每个象限的位置进行编码。 对于每个单元格，我们使用坐标加法计算其最终奇偶校验，然后与所选的全局起始颜色进行异或。 使用 XOR 是因为翻转起始颜色只会反转所有期望值。 

嵌套循环结束$4n^2$细胞是可以接受的，因为$n \le 100$，所以总操作量约为$4 \cdot 4! \cdot 2 \cdot 10^4$，这很容易在限制范围内。
