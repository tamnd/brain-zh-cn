 ## 解决方案
 ## 问题理解

 我们有一个从 1 到 n 的碱基线性排列。 我们的基地位于位置 k，我们一开始只有一名士兵在那里。 每天，我们都可以选择一个基地，并将任意数量的士兵从该基地向左或向右移动一个位置。 这次行动之后，一名新士兵出现在大本营。 任务是确定 m 天后可以容纳至少一名士兵的最大基地数量。 

输入给出多个测试用例，每个测试用例指定 n、m 和 k。 对于每个测试用例，输出是一个表示强化碱基最大数量的整数。 

约束表明每个测试用例 n 最多可达 10^5，m 最多可达 10^9。 由于所有测试用例的 n 总和以 2·10^5 为界，因此迭代整个基本数组是可行的，但由于 m 可能非常大，因此显式模拟每一天是不可能的。 这立即排除了任何尝试日常模拟的解决方案。 

当 m 小于到一端的距离时，就会出现一个微妙的问题。 例如，如果n = 5、k = 3、m = 1，则只能设防两个基地：本垒和一个邻近基地。 在这些情况下，假设士兵总能到达两端的天真方法会失败。 同样，当m极大时，所有基地最终都可以设防，但必须注意避免超过n。 

## 方法

 蛮力方法很简单：每天，以最佳方式模拟移动士兵以覆盖更多基地。 我们可以跟踪每个基地的士兵并决定将他们转移到哪里，重复此操作 m 次。 原则上这是可行的，但操作数量约为 O(n·m)，当 m 为 10^9 时，这是完全不切实际的。 

关键的见解是，我们加固基地的最快速度取决于它与本垒的距离。 本垒左侧的垒需要`home - i`第一个士兵到达的天数，右侧的基地需要`i - home`天。 在第一批士兵到达后，每天都会有一名额外的士兵到达基地，他们可以立即被派往外地。 

这将问题简化为简单的计算：对于距离 k 为 d 的基地，最早可以加固它的是`d`天。 由于接下来的每一天都会增加一名新士兵，因此可以设防的额外基地的最大数量从 k 开始每天向外扩展一个。 因此，最大强化基地数量的公式很简单：`min(n, m + 1)`。 这个公式之所以有效，是因为我们总是可以选择最近的未设防基地，并每天派一名士兵前往那里，第一天就已经算上本垒了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n·m) | O(n) | 太慢了 |
 | 基于距离的贪婪 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 
2. 对于每个测试用例，读取 n、m 和 k。 
3. 计算可加固的最大碱基数：`min(n, m + 1)`。 这是有效的，因为本垒在第 0 天就已经加固，并且每一天都可以加固一个基地。 如果 m 超过了该行末端的附加碱基数量，我们只需将 n 限制为上限。 
4. 打印每个测试用例的计算值。 

**为什么有效：** 不变的是，每天允许一名士兵从大本营到达一个新的未设防基地。 距离 k 为 d 的基地最早可以在 d 天后设防，并且由于每天都会有新的士兵出现在家里​​，我们总是可以用他们来掩护下一个最近的未设防的基地。 这确保了解决方案是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    # maximum fortified bases is the smaller of n or m+1
    print(min(n, m + 1))
```该代码读取多个测试用例，计算`min(n, m + 1)`对于每个，并打印结果。 不需要额外的数据结构。 该公式自动计算本垒，并且`min`防止超过碱基总数。

 ## 边缘情况

 当m=0时，无论n如何，都只能设防本垒。 对于相对于 n 而言较大的 m，该公式会自动限制 n 处的强化碱基。 当本垒位于端点时，最近的基地仍然首先被加固，因此贪婪方法仍然会产生最大值。 计算`min(n, m + 1)`无需显式分支或模拟即可处理所有这些场景。 

例如，输入`n=10, m=0, k=5`结果输出`1`，并输入`n=10, m=20, k=1`结果`10`，展示了对两种极端情况的正确处理。
