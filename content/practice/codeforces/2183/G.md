 ## 解决方案
 ## 问题理解

 交互式版本允许我们询问最多三个精心选择的指令并观察幸存的蛇。 在黑客版本中，速度已经在输入中给出，我们的工作是重现最佳交互式解决方案将输出的答案。 

每条蛇都从不同的整数位置开始。 其速度是其中之一`0`,`1`， 或者`2`。 

如果我们发出一秒指令`L`，每条蛇都以其速度向左移动。 在那一瞬间，每当两条蛇相遇时，速度更快的一条就会消失。 由于速度最多为`2`并且所有位置都是整数，在一秒内仅移动距离为的相邻蛇`1`或者`2`可以互动。 

关键问题不是“速度是多少？” 因为被黑的输入已经包含它们。 真正的问题是速度是否可以通过使用最多三个查询的某种策略唯一地恢复。 如果没有，我们必须打印`-1`。 

总和为`n`至多是`10^5`，因此任何每条蛇仅执行恒定工作量的解决方案都足够快。 任何二次方都被排除。 

微妙的部分是准确地描述何时无法确定速度，即使使用三个查询的最佳可能序列也是如此。 

考虑三个连续的蛇在位置`x, x+1, x+2`与速度`[0, 1, 0]`或者`[0, 2, 0]`。 在每一个有用的实验中，中间的蛇总是会死，因为它被困在两条静止的蛇之间。 从允许的查询中获得的每个观察结果在速度上都是相同的`1`和速度`2`。 这两个世界无法区分，所以答案一定是`-1`。 这是唯一的障碍。 

## 方法

 暴力思维模式是对长度可达的所有可能的查询字符串进行建模`4n`，模拟蛇系统，并询问每个速度分配是否都会产生唯一的成绩单。 这显然是不可能的。 可能的指令数量是指数级的，甚至单个模拟也很重要。 

官方的解决方案反而设计了三个固定查询：`L`

`LR`

`R`值得注意的是，这三个查询几乎揭示了一切。 

一秒钟后`L`，每条幸存的蛇都结束于`a_i - s_i`。 

现在看看查询`LR`。 第一秒一模一样`L`，所以同样的蛇能够生存。 第二秒将每个幸存者以自己的速度向右移动，恢复到原来的位置。 因此，输出`LR`只是幸存下来的蛇的原始位置的集合`L`询问。 

匹配之间的幸存者`L`和`LR`立即给出在第一次查询中幸存下来的每条蛇的速度。 

剩下的蛇正是那些被淘汰的蛇`L`。 它们的速度可以根据局部位置间隙和`R`询问。 只剩下一种模棱两可的配置：三个具有速度的连续位置`0, x, 0`， 在哪里`x`可能是`1`或者`2`。 只要存在这样的模式，正确的答案就是`-1`。 否则所有速度都是唯一确定的。

 ## 算法演练

 1. 模拟查询的答案`L`。 

让所得的幸存者位置为`vl`。 
2. 模拟查询的答案`LR`。 

令结果位置为`vlr`。 

中的每个位置`vlr`是幸存的蛇的原始位置`L`。 
3. 匹配`vlr`与原始位置数组相对应。 

如果位置`a[i]`出现在`vlr`， 蛇`i`幸存下来`L`询问。 
4.恢复每个幸存者的速度。 

假设蛇`i`幸存下来`L`。 

其地位在`vl`是`a[i] - s[i]`。 

因此`s[i] = a[i] - vl[j]`。 
5.有些蛇没能活下来`L`。 

对于每条未解决的蛇`i > 0`，检查间隙`d = a[i] - a[i-1]`。 

如果`d = 2`，或者如果`d = 1`并且之前的速度已知为非零，那么snake`i`必须有速度`2`。 

这些正是速度的情况`2`蛇在向左移动的过程中被迫死亡。 
6. 模拟查询`R`。 

设幸存者位置为`vr`。 

现在可以将所有剩余的未解决的蛇进行匹配`vr`，其速度为`vr[pos] - a[i]`。 
7. 检查唯一的不可能模式。 

对于每三个具有单位间隙的连续位置，`a[i+1] - a[i] = 1`和`a[i+2] - a[i+1] = 1`。 

如果重建的速度看起来像`[0, nonzero, 0]`那么中间值无法区分`1`和`2`。 

输出`-1`。 
8. 否则输出所有重建的速度。 

### 为什么它有效

 查询`L`识别哪些蛇能够在向左移动时幸存下来。 查询`LR`将该信息转换为原始索引，因为每个幸存者都会返回到其起始位置。 这两个查询一起准确确定每个幸存者的速度。 

唯一仍然未知的蛇是那些在`L`。 间隙的局部几何形状`1`和`2`迫使其中一些人加快速度`2`。 查询`R`确定所有剩余值。 

该社论证明，在最多三个查询的任何序列之后，唯一仍然基本上不明确的配置是具有速度的连续蛇的三重`0, x, 0`， 在哪里`x`或许`1`或者`2`。 如果存在这种模式，则任何策略都无法区分这两种可能性。 在所有其他配置中，上述三个固定查询唯一地确定每个速度。 

## Python 解决方案```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

def simulate(a, s, direction):
    n = len(a)

    if direction == 'L':
        pos = [a[i] - s[i] for i in range(n)]
    else:
        pos = [a[i] + s[i] for i in range(n)]

    alive = [True] * n

    for i in range(n - 1):
        d = a[i + 1] - a[i]

        if direction == 'L':
            if s[i + 1] > s[i] and d <= s[i + 1] - s[i]:
                alive[i + 1] = False
        else:
            if s[i] > s[i + 1] and d <= s[i] - s[i + 1]:
                alive[i] = False

    res = []
    for i in range(n):
        if alive[i]:
            res.append(pos[i])
    return res

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        s = list(map(int, input().split()))

        vl = simulate(a, s, 'L')
        vlr = [a[i] for i in range(n) if simulate(a, s, 'L').count(a[i] - s[i]) > 0]

        alive_after_l = [True] * n
        p = 0
        for i in range(n):
            if p < len(vlr) and vlr[p] == a[i]:
                p += 1
            else:
                alive_after_l[i] = False

        vr = simulate(a, s, 'R')

        ans = [-1] * n

        j = 0
        k = len(vlr)
        for i, x in enumerate(a):
            if j < k and vlr[j] == x:
                ans[i] = x - vl[j]
                j += 1

        for i in range(1, n):
            if ans[i] == -1:
                d = a[i] - a[i - 1]
                if d == 2 or (d == 1 and ans[i - 1] != 0):
                    ans[i] = 2

        for i, x in enumerate(a):
            if ans[i] == -1:
                j = bisect_left(vr, x)
                ans[i] = vr[j] - x

        bad = False
        for i in range(n - 2):
            if (
                a[i + 1] - a[i] == 1
                and a[i + 2] - a[i + 1] == 1
                and ans[i] == 0
                and ans[i + 1] != 0
                and ans[i + 2] == 0
            ):
                bad = True

        if bad:
            print(-1)
        else:
            print(*ans)

if __name__ == "__main__":
    solve()
```实现直接遵循重构论证。 

第一阶段模拟从三个固定查询获得的信息。 第二阶段填充了幸存的蛇的速度`L`。 第三阶段解决蛇必须有速度`2`不受当地差距的限制。 任何尚未解决的蛇都由`R`询问。 

最终扫描检查唯一不可能的配置。 缺少此检查会在官方测试中产生错误答案，因为此类实例必须返回`-1`即使输入已经包含具体的速度分配。
