 ## 解决方案
 ## 问题理解

 我们有一棵有根的树`n`顶点，其中根是顶点`1`，最初所有顶点都是白色的。 距离`d_i`一个顶点的`i`是从根到路径上的边数`i`。 我们可以执行同时将多个白色顶点着色为黑色的操作，但我们选择的顶点必须满足两个约束：没有两个顶点直接由边连接，并且没有两个顶点距根的距离相同。 目标是找到使所有顶点变黑的此类操作的最少数量。 

输入由多个测试用例组成，每个测试用例提供树结构。 每个测试用例的输出是一个整数：所需的最小操作数。 

这些限制足够强大，我们无法承受天真的做法。`n`最多可达 200,000 个，所有测试用例的总和也上限为 200,000 个。 这意味着我们的算法必须以相对于每个测试用例的顶点数量大致线性的时间运行，否则它将超过 2 秒的限制。 立即排除任何二次或需要显式枚举所有节点子集的情况。 

非明显的边缘情况包括许多顶点共享相同深度或某些顶点形成限制同时着色的链的情况。 例如，如果根有四个子代且没有孙子，则所有子代都处于相同深度，因此每个子代都必须在单独的操作中着色，即使没有直接连接。 一个粗心的算法试图同时给所有孩子着色会产生错误的答案。 另一个微妙的场景是一条链：`1-2-3-4`。 顶点`2`和`3`不能一起着色，因为它们是相邻的，并且它们的距离是连续的，因此我们必须仔细选择集合以尽量减少操作。 

## 方法

 暴力方法将尝试生成满足约束的白色顶点的所有有效子集，应用着色，并重复直到所有顶点都是黑色。 原则上这是可行的，因为它完全遵循规则。 然而，对于`n`最多 200,000 个，子集的数量呈指数级增长，甚至跟踪哪些顶点是着色的或未着色的也太慢了。 

一个关键的见解来自于约束的结构。 因为我们无法选取距离相同的两个顶点，所以每次操作每个深度最多只能选取一个顶点。 此外，两个选取的顶点不能相邻。 在树中，如果我们从未在同一操作中选择父级及其子级，则自动满足邻接约束。 这表明最小操作数与顶点在深度之间的分布方式以及有多少顶点有子节点有关。 

我们可以通过考虑每个顶点在操作调度方面的“有效程度”来形式化这一点：根可以在一个操作中着色，但如果其子节点共享相同的深度，则它们可能需要单独的操作。 每个顶点都会贡献其深度的“负载”。 然后，问题简化为：对于每个顶点，跟踪其子节点需要多少次操作，并在所有深度上取最大值。 该最大值给出了所需的最少操作数。 

换句话说，在调整由邻接约束引起的重叠后，最小操作数等于同一深度的最大子操作数。 通过计算每个顶点和每个深度的子级数量，我们可以使用简单的 DFS 有效地确定最少的操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（所有有效子集）| O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 深度计数 + DFS | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 使用邻接表构建树。 每个顶点存储连接顶点的列表。 
2. 从根开始执行 DFS 来计算距离`d_i`从根开始的每个顶点。 
3.初始化一个数组`cnt`在哪里`cnt[v]`计算顶点的直接子节点的数量`v`。 叶节点有`cnt[v] = 0`。 
4. 对于每个顶点，计算每个深度存在多少个子顶点。 如果需要，维护优先级队列或这些计数的多重集。 
5. 对于根来说，最少的操作次数为`1 + sum over children`如果所有子级都处于相同深度并且不相邻。 更一般地，最小操作数等于`max(cnt[v] + 1 for all vertices)`。 这`+1`考虑对顶点本身着色的操作。 
6. 输出这个最大值作为每个测试用例的答案。 

工作原理：DFS 确保我们在将每个顶点的子节点合并到父节点的操作计数之前对其进行处理。 计算每个深度的子级数量可确保相同深度的两个顶点不会同时着色。 所有顶点的最大值代表最坏情况的负载，即尊重邻接和深度约束所需的瓶颈操作计数。 这个不变量保证了正确性：在不违反问题规则的情况下，没有一组顶点可以通过更少的操作来着色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque, defaultdict

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        tree = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            tree[u-1].append(v-1)
            tree[v-1].append(u-1)
        
        depth_count = defaultdict(int)
        visited = [False]*n
        q = deque()
        q.append((0, 0))
        visited[0] = True
        while q:
            node, depth = q.popleft()
            depth_count[depth] += 1
            for neighbor in tree[node]:
                if not visited[neighbor]:
                    visited[neighbor] = True
                    q.append((neighbor, depth + 1))
        
        print(max(depth_count.values()))

if __name__ == "__main__":
    solve()
```该解决方案首先构建邻接列表并执行 BFS 来计算每个顶点的深度，并为每个深度递增计数器。 深度之间的最大计数给出了所需的最少操作数，因为它表示同一深度上不能一起着色的顶点的最大数量。 为了简单起见，这里使用 BFS 而不是 DFS，但 DFS 也同样有效。
