 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组和一个数字$k$。 任务是重复从数组中删除元素，始终选择长度的窗口$k$其 MEX 最大，并删除该窗口内的任何元素。 准确执行后$n-k+1$这样的删除，数组长度变成$k-1$。 我们的目标是最大化最终数组的 MEX。 

输入由多个测试用例组成。 每个测试用例最多可以有$2 \cdot 10^5$元素，以及所有元素的总和$n$跨测试用例的边界为$2 \cdot 10^5$。 由于每个测试用例都可以这么大，因此任何算法$O(n^2)$复杂性会太慢。 我们需要一个解决方案$O(n)$每个测试用例。 

边缘情况包括所有元素均为零的数组、范围中间缺少元素的数组以及其中$k = n$。 例如，对于一个数组`[0,0,0]`和`k=3`，删除一个元素后剩余的数组是`[0,0]`，因此 MEX 为 1。简单的滑动窗口 MEX 计算可能无法有效地处理重复删除。 

## 方法

 蛮力方法是从字面上模拟该过程。 对于每次删除，我们将：

 1. 计算每个长度窗口的 MEX$k$。 
2. 选择一个具有最大 MEX 的窗口。 
3. 从该窗口中删除一个元素。 

计算窗口的 MEX$O(k)$对于小数组是可行的，但是如果$n$是$2 \cdot 10^5$和$k$相当于$n$，这种方法可能需要长达$O(n^2)$，这太慢了。 

关键的观察是我们不关心删除的精确顺序。 最终的 MEX 由所有删除后数组中元素的多重集确定。 既然我们表演$n-k+1$删除，剩下的元素是$k-1$删除后仍能存活的最小或策略性选择的元素。 我们可以将问题转化为计算数组中每个整数的出现频率。 任意整数$x$发生超过$n-k+1$时间不能通过删除完全删除。 因此，可实现的最大 MEX 是最小的非负整数$x$其频率小于$n-k+1$。 

这将问题从模拟删除转变为简单的计数问题，产生$O(n)$每个测试用例的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 频率计数/MEX 逻辑 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化频率数组`count`尺寸的`n+2`（覆盖值高达`n`) 为零。 该数组将存储每个整数在数组中出现的次数。 
2. 迭代输入数组，递增`count[a[i]]`对于每个元素`a[i]`。 这一步让我们知道每个数字出现了多少次。 
3. 计算`deletions = n - k + 1`，将被删除的元素数量。 
4. 初始化`mex = 0`。 从0开始向上迭代。 对于每个整数`mex_candidate`，检查其在数组中的频率是否大于`deletions`。 如果是，则无法完全删除，因此增加`mex`并继续。 如果其频率小于或等于`deletions`，这个数字可以完全删除，所以当前`mex`就是答案。 
5.输出最终结果`mex`。 

为什么有效：之后$n-k+1$删除，仅$k-1$元素仍然存在。 任何出现次数超过的数字$n-k+1$times 保证至少在一次删除后仍然存在。 不能保证存活的最小非负整数正是剩余数组的 MEX。 这种洞察消除了模拟的需要。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        count = [0] * (n + 2)
        for x in a:
            count[x] += 1
        deletions = n - k + 1
        mex = 0
        while count[mex] > deletions:
            mex += 1
        print(mex)

if __name__ == "__main__":
    solve()
```该解决方案首先读取所有输入，计算出现次数，然后通过比较频率来确定 MEX`deletions`。 使用`n+2`在`count`确保我们可以随时检查`mex`最多`n+1`无索引错误。 通过递增可以避免差一错误`mex`仅当计数超过删除次数时。 

## 工作示例

 ### 输入示例 1```

a = [0,0,0]
```| 步骤| 计数| 删除 | 墨西哥候选人 | 墨西哥 |

 | 1 | [3,0,0,0] | 1 | 0 | 0 |
 | 2 | | | 0 计数 > 删除 → mex=1 | 1 |

 解释：仅`0`发生超过 1 次，因此它会生存。 可能缺失的最小整数是`1`。 

### 输入示例 2```

a = [0,1,2,1,0]
```| 步骤| 计数| 删除 | 墨西哥候选人 | 墨西哥 |
 | --- | --- | --- | --- | --- |
 | 1 | [2,2,1,0,0,0] | 3 | 0 | 0 次 ≤ 删除 → 答案=0 |
 | 2 | | | 接下来检查：1 计数 ≤ 删除 → mex=1 | |

 解释：数字 0 和 1 出现 ≤ 3 次，因此删除可以将它们完全删除。 数字 2 出现一次，也≤ 3。不能保证在删除中幸存的最小数字是 2，最终的 MEX=2。
