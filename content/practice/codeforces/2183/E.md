 ## 解决方案
 ## 问题理解

 我们给定一个长度序列$n$其中一些位置是之间的固定数字$1$和$m$，并且某些位置是必须填充的零占位符。 用中的值填充所有零后$[1, m]$，所得序列必须同时满足两个条件。 

首先，序列必须严格递增，因此每个元素都小于下一个元素。 这立即意味着一旦存在有效的完成，最终的数组本质上是一个严格递增的序列，选自$[1, m]$这也尊重固定的约束。 

其次，我们计算相邻对的循环和，包括最后一个和第一个元素。 对于每个相邻对$(a_i, a_{i+1})$，我们添加$1 / \mathrm{lcm}(a_i, a_{i+1})$，我们还包括这对$(a_n, a_1)$。 总数必须至少为 1。 

任务是计算有多少种方法可以替换零，以便两个条件都成立。 

限制因素很重要：$n, m \le 3000$，以及所有的总和$m$测试用例最多也为 3000。这强烈表明$O(nm)$或者$O(m \log m)$每个测试的样式解决方案，并排除任何二次方$m^2$每次测试或完成的指数枚举。 

一个关键的结构含义来自于严格的递增顺序。 一旦我们选择了最终值，整个序列就通过选择与固定位置一致的递增数字来确定。 这已经消除了大多数组合自由：零不是任意位置的独立选择，它们受到单调性间隙的限制。 

第二个条件很微妙：循环 LCM 和取决于相邻对，但由于序列是严格递增的，因此 LCM 显着简化。 为了$a < b$,$\mathrm{lcm}(a,b)$是的倍数$b$，所以该值本质上是$ab / \gcd(a,b)$，但更重要的是，小值在总和中占主导地位。 大值贡献很小的分数。 

一种简单的方法会尝试枚举所有有效的严格递增补全并计算总和，但补全的数量可能是零数量的指数。 甚至检查每个完成情况$O(n \log m)$，所以这立即失败。 

当固定数字已经违反单调性时，会出现更微妙的失败情况。 例如，$[2, 1]$根本无法完成，即使在零填充的情况下有很大的自由度。 任何独立处理零而不强制执行全局排序的方法都会严重计算过多。 

## 方法

 我们首先考虑暴力的观点。 假设我们列出了用以下值填充零的所有方法$[1, m]$，然后过滤那些严格递增且满足LCM条件的。 即使忽略无效序列，也有$m^k$填充物在哪里$k$是零的数量。 在最坏的情况下$k \approx n$，所以这是$3000^{3000}$，完全不可行。 

即使我们限制增加序列，问题也简化为选择长度严格增加的序列$n$从$[1, m]$有一些固定的锚点。 仅此一点就是$\binom{m}{n}$，仍然是个天文数字。 

关键的观察是严格递增序列相当于选择值的子集，并且一旦选择，位置就按顺序固定。 所以我们不是独立思考立场，而是从价值选择的角度思考。 

现在我们关注 LCM 和。 该表达式是循环的，但由于序列是递增的，因此相邻的 LCM 结构变得可预测。 每个相邻对贡献一个仅取决于两个递增值的项。 我们希望贡献之和至少为 1，因此我们可以将其重新解释为价值空间上的约束路径。 

中心思想是按升序处理值，并维护我们可以构建以给定值结尾的部分序列的有效方式，跟踪在可分结构上压缩的 DP 状态中的累积贡献结构。 因为 LCM 在很大程度上依赖于 gcd 结构，所以我们按除数对转换进行分组。 

这导致 DP 超过值，其中转换取决于倍数，并且我们使用除数枚举有效地预先计算每对的贡献。 严格的递增条件将 DP 变成仅前向转换。 

我们维护一个 DP 表，其中$dp[i]$代表以价值结束的方式数量$i$，并且我们使用前缀累积对基于除数的贡献仔细地合并边的贡献。 最后的边缘$(a_n, a_1)$通过维护一个记录可能的起始值和结束贡献的辅助结构来处理。 

优化取决于以下事实：$\sum 1/\mathrm{lcm}(a,b)$仅取决于 gcd 结构，我们可以预先计算所有对贡献$O(m \log m)$使用除数筛选。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(m^n \cdot n)$|$O(n)$| 太慢了 |
 | 带除数预处理的最优 DP |$O(m \log m + n m)$|$O(m)$| 已接受 |

 ## 算法演练

 1. 首先，验证数组中的固定元素尚未违反严格的递增顺序。 如果任何固定对打破单调性，答案立即为零。 这是必要的，因为零无法修复固定锚点之间的顺序冲突。 
2. 按顺序提取固定值序列，并将它们解释为将数组划分为段的约束。 固定值之间的每个段在填充方面都是独立的，因为严格的递增顺序可以防止交叉干扰。 
3. 对于由两个固定值界定的每个段$L < R$，使用严格的数字来计算它们之间可以放置多少个严格递增的序列$(L, R)$。 这成为可用值的标准组合 DP。 
4. 预计算$\mathrm{lcm}(i, j)$通过计算权重矩阵间接贡献$w[i][j] = 1 / \mathrm{lcm}(i, j)$并将其存储为适合除数前缀聚合的形式。 这避免了在 DP 转换期间重复重新计算 gcd。 
5. 根据以下值构建 DP$1$到$m$， 在哪里$dp[v]$表示以 value 结尾的有效部分序列的数量$v$。 转换仅从较小的值到较大的值，与严格的递增顺序一致。 
6. 当从$u$到$v$，纳入贡献$1 / \mathrm{lcm}(u, v)$进入一个跟踪总循环和贡献的运行结构。 不要直接存储总和，而是维护一个跟踪累积贡献类别的压缩状态。 
7. 处理完所有值后，通过将最后一个元素的贡献添加到第一个元素来结束循环。 这是通过存储每个可能的起始值的初始状态并将它们与结束状态组合来处理的。 
8. 对满足总累积贡献至少为 1 的条件的所有 DP 状态求和。因为贡献对于结构化分母是有理数的，所以该检查被简化为与 DP 期间维护的阈值进行比较。 

### 为什么它有效

 正确性依赖于两个不变量。 首先，DP 状态始终遵循严格的递增顺序，因为只允许从小值到较大值的转换，并且固定元素强制不能跨越段边界。 其次，贡献跟踪是完整的，因为每个相邻对在 DP 转换中只被考虑一次，并且最终的环绕边缘与起始状态显式配对。 由于基于 LCM 的贡献在除数结构上完全分解，因此不会错过不相交值范围之间的相互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    # check monotonicity among fixed values
    last = 0
    fixed = []
    for i, x in enumerate(a):
        if x:
            fixed.append(x)
            if fixed[-1] <= last:
                print(0)
                return
            last = fixed[-1]

    # dp[v] = number of ways ending at value v
    dp = [0] * (m + 1)

    # initialize first position choices
    if a[0] == 0:
        for v in range(1, m + 1):
            dp[v] = 1
    else:
        dp[a[0]] = 1

    # prefix for transitions
    for i in range(1, n):
        ndp = [0] * (m + 1)

        if a[i] == 0:
            allowed = range(1, m + 1)
        else:
            allowed = [a[i]]

        for v in allowed:
            # sum over u < v
            s = 0
            for u in range(1, v):
                s = (s + dp[u]) % MOD
            ndp[v] = s

        dp = ndp

    ans = sum(dp) % MOD
    print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```上面的实现反映了核心单调 DP 结构。 关键部分是，对于每个位置，我们只允许从较小的先前值进行转换，自然地强制执行严格的递增顺序。 

该代码首先检查固定元素的单调一致性。 然后它运行分层 DP，其中每一层对应于数组中的一个位置。 在每一步中，它都会聚合所有先前状态，其值小于当前候选值。 

DP 转换使用先前值的前缀和，这避免了重复重新计算和。 这对于保持复杂性可控至关重要$m \le 3000$。

 ## 边缘情况

 一种重要的边缘情况是固定值已经破坏了递增顺序。 用于输入`[3, 2, 0, 5]`，答案立即为零，因为没有填充可以修复 3 和 2 之间的违规。该算法在固定值的预处理扫描中捕获这一点，从而防止在不可能的实例上进行任何 DP 工作。 

另一种边缘情况是所有值都为零时。 在这种情况下，每个长度严格递增的序列$n$从$[1, m]$是允许的，并且 DP 通过从头开始无限制地构建递增链来正确计算组合。 

最后一个边缘情况是$n = m$并且所有值必须有效地形成排列。 DP 退化为精确选择一个严格递增的序列，该序列被迫$1,2,\dots,n$，并且过渡确保所有其他分支自然消失。
