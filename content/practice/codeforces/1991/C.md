 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组，在一次操作中我们可以选择任何数字$x$并替换每个元素$a_i$与它的绝对差异$x$,$|a_i - x|$。 我们的任务是在最多 40 次这样的操作中将数组转换为全零，否则报告这是不可能的。 输入由多个测试用例组成，每个测试用例都有一个数组，输出应该是数字序列$x$我们选择 进行操作，如果无法完成则选择 -1。 

关键约束是数组大小$n$最多$2 \cdot 10^5$和总和$n$所有测试用例也受$2 \cdot 10^5$。 这意味着每个测试用例的复杂度低于线性或接近线性的任何解决方案都可能会超时。 40 次操作的限制很宽泛，因此我们不需要最小化操作数量，但它足够严格，以至于天真的暴力尝试所有可能的操作$x$以组合方式获取值是不切实际的。 

一个微妙的边缘情况是数组已经全为零。 粗心的解决方案可能会尝试执行不必要的操作，但正确的输出应该是零操作。 当数组中的元素不是彼此的两倍的幂时，会出现另一种棘手的情况，这可能导致无法通过给定的操作将所有元素减少到零。 例如，数组$[1,2,3,4,5]$无法在 40 次操作中减少到零，因为差异永远不会对称地对齐到足以同时折叠所有值。 

## 方法

 蛮力方法会考虑所有可能的选择$x$在每一步中，重复应用该操作，直到数组变为全零。 每个操作将每个元素转换为$|a_i - x|$，如果我们尝试从 0 到最大元素的所有可能的整数，序列的数量会呈指数增长。 这在理论上是正确的，但不可行，因为$n$可以达到$2 \cdot 10^5$和值高达$10^9$使穷举搜索变得不可能。 

产生高效解决方案的见解来自于观察该操作保留了以最大公约数 (GCD) 为模的元素之间的差异集。 如果我们选择$x$作为最大元素，最大元素变为零，新数组由先前最大元素与所有元素之间的差组成。 迭代地重复这个过程可以将问题简化为计算差异的 GCD。 如果数组是可约的，这种方法保证最多$2 \log_2(\text{max element})$操作时，所有元素都会归零。 

因此，该策略是贪婪的：重复选择当前最大元素作为$x$，这会将其减少到零，并用相对于该最大值的差值替换数组。 每次迭代后，最大值都会减小，最终所有元素要么变为零，要么变成 GCD 差异的统一数组。 如果在任何时候数组包含多个不同的非零值且不是当前 GCD 的倍数，我们就声明这是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(10^9 · n · 运算) | O(n) | 太慢了 |
 | 贪心与 GCD | O(n·log(max a_i)) | O(n·log(max a_i)) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取整数数组。 
2. 如果所有元素都已为零，则立即输出零运算。 这可以有效地处理琐碎的情况。 
3. 计算不同非零元素的集合。 如果只有一个唯一的非零元素，则选择该元素作为$x$并执行一项操作将数组清零。 
4.否则重复选择$x$作为当前数组中的最大元素。 替换每个元素$a_i$和$|a_i - x|$。 记录选择的顺序$x$价值观。 
5. 每次操作后，检查所有元素是否都变为零。 如果是，则输出序列并停止。 
6. 如果经过 40 次操作后数组仍然包含非零元素，则输出 -1。 
7. 自始至终，保持一个操作计数器，以确保我们永远不会超过 40 的限制。 

这样做的原因是，在每一步选择最大元素可以保证至少一个数组元素变为零，并且绝对差运算可以确保差异集随着时间的推移而缩小。 操作序列逐渐将所有元素对齐为零，并且如果存在解，则问题结构保证收敛。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        if all(x == 0 for x in a):
            print(0)
            continue
        
        operations = []
        # Greedy approach: max element reduction
        for _ in range(40):
            if all(x == 0 for x in a):
                break
            x = max(a)
            operations.append(x)
            a = [abs(ai - x) for ai in a]
        
        if all(x == 0 for x in a):
            print(len(operations))
            print(" ".join(map(str, operations)))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```解决方案首先检查数组是否已经为零。 然后，它通过选择最大元素、用与该最大值的绝对差替换每个数组元素并记录操作来执行最多 40 次贪婪运算。 每一步之后，它都会检查数组现在是否全为零。 如果是，则输出操作； 否则，输出-1。 

微妙的选择包括每次操作后检查零条件、限制为 40 次操作以及一致地使用绝对差值。 使用Python的内置`max`确保我们始终有效地选择最大的元素。
