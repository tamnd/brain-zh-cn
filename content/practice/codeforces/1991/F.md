 ## 问题理解

 我们得到了一系列木棍，每根木棍的长度都是正整数。 对于每个查询，我们被问到是否可以从给定的连续子数组中恰好挑选出六个不同的木棍，以便我们可以形成**两个非退化三角形**。 非简并三角形是任意两条边之和严格大于第三条边的三角形。 

关键点是每个查询都对长度至少为 6 的连续子数组进行操作，并且我们需要选择六个**不同的索引**（不一定是六个不同的长度）来形成两个三角形。 约束很大：最多 100,000 个棍子和 100,000 个查询，这排除了任何检查查询中所有 6 个棍子组合的暴力解决方案。 

边缘情况很微妙。 如果一个范围内的所有棒都相等，则任何不同索引的三元组形成一个有效的三角形。 然而，如果只有两根大棍子，其余的都很小，则不可能形成三角形。 例如，一个子数组`[1, 1, 1, 1, 10, 10]`尽管有六根棍子，但不能形成两个三角形。 仅查看长度计数或三个最大的棍子的粗心实现可能会错误地回答“是”。 

另一个微妙之处是，棍长可以非常大，可达 10^9，但算术运算在 Python 中不会溢出，因此重点完全在于算法效率。 

## 方法

 最简单的方法是迭代给定子数组中所有 6 个棒的组合，并将每个分区检查为两个三元组。 检查每个三元组的三角不等式。 这可以保证正确性，但每个查询的复杂度为 O((r-l+1)^6)，考虑到 r-l+1 最多可达 10^5，这个复杂度太大了。 即使使用巧妙的三重迭代并避免显式组合生成，每个查询仍至少会导致 O((r-l+1)^3)，这对于大 n 和 q 来说是不可行的。 

关键的见解是，**如果我们对子数组进行排序，形成一个三角形就简化为检查三个连续元素是否可以形成一个三角形**。 排序确保对于三个连续的棒 a ≤ b ≤ c，我们只需要检查是否 a + b > c。 如果该不等式成立，则三元组形成一个非简并三角形。 

要在子数组中查找两个三角形，我们只需扫描形成三角形的第一个三元组，然后扫描其余元素以查找第二个三元组。 然而，由于排序，从头开始对每个查询执行此操作仍然是 O(n log n)。 这太慢了。 

我们可以利用观察结果进一步优化，即**只有任何范围内的六个最小或六个最大的棍子才能形成两个三角形**，因为当我们考虑最大或最小的元素时，三角形更有可能形成。 预先计算“排序元素的前缀”是不可行的，因为每个子数组都不同。 相反，我们利用这样一个事实：任何有效的三角形对都将出现在该范围内的 **6 个最小和 6 个最大元素**中。 这将每个查询减少为最多扫描 12 个棒，预处理后为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((r-l+1)^6 * q) | O(1) | O(1) | 太慢了 |
 | 排序+连续三元组| O(q * (r-l+1) log(r-l+1)) | O(q * (r-l+1) log(r-l+1)) | O(r-l+1) | 太慢了 |
 | 最佳：扫描 12 个极限棒 | O(q * 12) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个查询，提取从索引 l 到 r 的木棍子数组。 
2. 跟踪子数组中**六个最小和六个最大的棒长度**。 这确保我们捕获所有潜在的三角形，因为三角形的形成取决于三边之和。 
3. 将这 12 根棍子组合成一个列表并对其进行排序。 
4. 迭代此列表中的连续三元组，并使用条件 a + b > c 记录形成非简并三角形的所有三元组。 
5. 如果至少存在两个不相交的三元组（原始子数组中的索引不相交，不一定是值），则回答“YES”； 否则，回答“否”。 

为什么有效：形成三角形的任何三元组都将涉及子数组中最小或最大的元素，因为如果极端值违反三角形不等式，则不能由三个中等大小的元素形成三角形。 通过检查所有 12 个极端候选者，我们保证找到两个有效三角形（如果存在）。 对这些候选者进行排序可以实现高效的线性扫描。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_form_two_triangles(sub):
    sub = sorted(sub)
    triangles = []
    n = len(sub)
    for i in range(n-2):
        if sub[i] + sub[i+1] > sub[i+2]:
            triangles.append((i, i+1, i+2))
            if len(triangles) == 2:
                return True
    return False

def main():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    
    for _ in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        sub = a[l:r+1]
        
        # pick up to six smallest and six largest
        sub_sorted = sorted(sub)
        candidates = sub_sorted[:6] + sub_sorted[-6:]
        if can_form_two_triangles(candidates):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    main()
```解释：我们取一个连续的子数组，选择六个最小和六个最大的元素，并对它们进行排序。 这`can_form_two_triangles`函数扫描连续的三元组来查找三角形。 一旦找到两个，我们就返回“YES”。 此实现确保正确性，同时保持查询处理时间基本恒定。
