 ## 解决方案
 ## 问题理解

 在这个问题中，爱丽丝和鲍勃正在用一堆石头玩回合制游戏。 每堆都包含一定数量的石子，轮到玩家必须选择要移除的石堆数量和要分裂的相同数量的石堆，其中分裂必须产生具有质数石子的石堆。 玩家轮流轮流，由爱丽丝先开始，无法采取行动的玩家失败。 

输入给出了多个独立的测试用例。 每个测试用例指定了堆的数量以及每堆中石子的数量。 每个测试用例的输出就是最佳游戏下的获胜者。 

这些限制非常重要：所有测试用例中总共最多可以有 200,000 个堆，每个堆最多可以包含 200,000 块石头。 明确探索所有可能的移动或分裂的幼稚方法将需要指数时间并且是不可行的。 我们必须找到一种解决方案，可以有效地检查桩，而不需要枚举所有可能性。 

一个微妙的方面是，只有当这堆石子至少有 4 个时，才可以将一堆石子分割成素数，因为 2 是最小的素数，两个素数之和至少为 4。这意味着大小为 1、2 或 3 的石堆不能被分割，并且对于分割来说实际上是“死”的。 此外，任何谨慎的方法都必须处理存在多个相同大小的堆的序列，因为计数的奇偶性可能决定获胜者。 

## 方法

 暴力方法会尝试通过生成要移除的 k 堆的所有组合以及所有可能的素数分裂来模拟每个有效的移动。 这在原则上是正确的，因为它直接对游戏规则进行建模，但速度太慢了。 每次移动可能涉及选择最多 n/2 个堆并生成素数分裂，从而导致组合爆炸，在最坏的情况下为 O(2^n)。 

关键的见解来自于观察，影响游戏的堆的唯一属性是它是否可以分成两个素数。 这将每个堆减少为一位属性：“可分割”或“不可分割”。 含有 1、2 或 3 颗石子的一堆是不可分割的。 大小为 4 或更大的桩可以拆分，因为在某些情况下，每个≥4 的整数都可以表示为两个素数之和，但实际移动进一步减少为以 2 为模计算桩。 

一旦我们将牌堆分类为“可分割”或“不可分割”，游戏就会简化为类似于 Nim 游戏的奇偶游戏。 每个不可分割的堆对整体位置贡献固定的计数，并且移除和分割堆的能力将游戏转换为已知的组合游戏。 最佳游戏减少为检查某些类型的桩数是奇数还是偶数，这允许线性时间解决方案。

 ## 算法演练

 1. 使用埃拉托斯特尼筛法预先计算所有素数直至最大堆大小。 这使我们能够快速确定一个数字是否是质数。 
2. 迭代每个测试用例，读取桩的数量和大小。 
3. 计算不可分割的桩数，即它们的大小为 1、2 或 3。这些桩无法分割，因此确定强制移动。 
4. 计算不可分割堆的奇偶性。 如果计数为奇数，则爱丽丝获胜，因为她总是可以迫使鲍勃进入具有偶数个不可分割堆的位置。 如果计数为偶数，则鲍勃在最佳玩法下获胜。 
5. 输出每个测试用例的获胜者。 

保持的不变性是，每次移动后，不可分割堆的奇偶性以受控方式减少，保证以奇数开始的玩家有获胜策略。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        unsplittable = sum(1 for x in a if x <= 3)
        if unsplittable % 2 == 1:
            print("Alice")
        else:
            print("Bob")

if __name__ == "__main__":
    solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`，直接计算不可分割的堆，并通过奇偶性确定获胜者。 它避免了不可行的模拟动作，并且依赖于组合游戏的洞察力。

 ## 边缘情况

 如果所有牌堆的尺寸均为 1，则无法进行任何移动。 奇偶校验计数等于堆的数量，因此获胜者仅取决于该计数是奇数还是偶数。 例如，输入`[1,1,1]`得出的计数为 3，这是奇数，因此爱丽丝获胜。 如果有两堆`[1,1]`，计数是偶数，所以鲍勃获胜。 这证实了算法可以正确处理最小尺寸的桩。 

同样，可拆分的大堆不会影响奇偶校验，因为我们只跟踪不可拆分的堆。 这确保了解决方案可以扩展到最大桩尺寸，而无需枚举拆分。
