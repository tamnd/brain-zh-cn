 ## 解决方案
 ## 问题理解

 游戏以当前数字开始`m = n`。 基拉尼率先行动。 每回合，玩家减去一个正整数`x`从`m`。 如果`m > k`，玩家可以从中减去任何东西`1`通过`m-k`，因此新值可以是以下任意整数`k`通过`m-1`。 如果`m <= k`，允许的减法仅为`1`，因此游戏会每次减少第一个数字来继续。 

面对的玩家`m = 0`输是因为没有合法的举动。 对于每个测试用例，我们需要决定起始位置是否`(n, k)`假设两名玩家都做出最佳选择，Kilani 获胜。 我们打印`Kilani`以获得获胜的起始位置和`Ayoub`否则。 

最大可能`n`是`10^9`，同时最多可以有`10^4`测试用例。 处理每个值的算法`n`已经太慢了，因为单个测试用例可能需要十亿次操作。 具有二次工作的算法`n`是完全不可能的。 预期的解决方案必须利用允许的移动结构并将每个测试用例减少到恒定时间。 

在一些边界情况下，将游戏视为普通减法可能会导致错误的答案。 为了`n = 1, k = 1`，基拉尼获胜。 唯一的动作就是减去`1`，让阿尤布为零且没有移动。 粗心的奇偶规则应用于错误的范围可能会错误地对该位置进行分类。 

为了`n = 2, k = 2`, Kilani loses. 自从`m <= k`，唯一的举动是`2 -> 1`，然后阿尤布移动`1 -> 0`，让基拉尼无法动弹。 事实是`n = k`这里有一个特殊的边界问题。 

为了`n = 2, k = 1`，正确答案是`Ayoub`。 基拉尼只能从`2`到`1`，之后阿尤布移动到`0`。 这是紧邻奇数上方的第一个位置`k`，尽管采取了合法的行动，但它还是输了。 

为了`n = 3, k = 1`，答案是`Kilani`。 Kilani 可以直接从`3`到`1`，迫使阿尤布最后一步归零。 这区分了`n = k+1`从`n >= k+2`。 

## 方法

 一种直接的方法是对每个可能的值进行分类`m`作为胜利或失败。 如果每一次合法的举动都达到了获胜的位置，则该位置就是失败的。 如果至少有一个合法的动作达到了失败的位置，那么它就获胜了。 为了`m <= k`，只有一个转变，`m -> m-1`。 为了`m > k`， 有`m-k`可能的移动，达到每个值`k`通过`m-1`。 

这种动态规划方法是正确的，因为每一步都会减少`m`，因此我们可以按升序确定位置。 然而，计算上面一个位置的状态`k`最多可检查`m-k`以前的状态。 计算所有位置直到`n`因此需要二次时间，`O(n^2)`，在最坏的情况下。 和`n = 10^9`，这大约意味着`5 * 10^17`针对一个大型测试用例进行转换检查，这几乎是不可能的。 

关键的观察是我们实际上不需要对所有位置进行分类。 首先考虑以下位置`k`。 由于唯一的动作是减一，所以游戏只是一个普通的吃一游戏。 因此`k`正是在什么时候失去`k`是偶数，并且恰好在以下时间获胜`k`很奇怪。 

现在考虑大于`k`。 从任何这样的值`m`，玩家可以移动到区间内的每个值`[k, m-1]`。 一旦该区间包含一个亏损头寸，`m`自动获胜，因为玩家可以直接移动到失败的位置。 

如果`k`是偶数，那么`k`本身正在失去。 因此，每一个`m > k`正在获胜，因为每个这样的位置都可以直接移动到`k`。 

如果`k`是奇数，那么`k`正在获胜。 下一个位置，`k+1`，只能移动到`k`，所以它正在失败。 每个位置`m >= k+2`可以直接移动到`k+1`，使他们全部获胜。 

这样只剩下两个可能失败的起始位置。 什么时候`k`是偶数，仅`n = k`正在失去。 什么时候`k`是奇数，仅`n = k+1`正在失去。 对于基拉尼来说，其他每一个首发位置都是胜利。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`对于当前的测试用例。 我们只需要这两个值，因为游戏对其失败位置具有封闭形式的特征。 
2. 检查是否`k`是均匀的。 在这种情况下，位置`m = k`正在输，因为下面的游戏`k`仅由减一组成，偶数次此类移动会使玩家移动为零。 
3.如果`k`是偶数，分类`n = k`作为失去和每一个`n > k`作为胜利。 以上每个值`k`可以直接移动到失败的位置`k`。 
4. 如果`k`是奇数，位置`k`正在获胜，同时`k+1`正在失败，因为它唯一可能的目的地是获胜位置`k`。 
5.对于奇数`k`, 分类`n = k+1`视为失败且其他所有有效`n`作为胜利。 至少任意值`k+2`可以直接移动到失败的位置`k+1`。 
6. 打印`Ayoub`正是针对上述失败的情况。 打印`Kilani`对于所有其他情况。 

### 为什么它有效

 不变量是每个位置都大于`k`可以到达每个更小的位置`k`。 什么时候`k`是偶数，`k`是第一个亏损的仓位，因此它使每个较大的仓位都盈利。 什么时候`k`是奇数，`k`正在获胜并且`k+1`成为第一个亏损的仓位，然后使其之上的每个仓位都盈利。 因此，唯一亏损的头寸是`k`对于甚至`k`， 和`k+1`对于奇数`k`。 该算法会准确检查这些位置，因此它会为每个有效的位置产生正确的获胜者`(n, k)`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve(data: str) -> str:
    tokens = data.split()
    t = int(tokens[0])
    pos = 1
    ans = []

    for _ in range(t):
        n = int(tokens[pos])
        k = int(tokens[pos + 1])
        pos += 2

        if k % 2 == 0:
            losing = (n == k)
        else:
            losing = (n == k + 1)

        ans.append("Ayoub" if losing else "Kilani")

    return "\n".join(ans)

def main():
    data = sys.stdin.read()
    sys.stdout.write(solve(data))

if __name__ == "__main__":
    main()
```这`solve`函数会立即解析所有测试用例，并在加入它们之前将答案存储在列表中。 这样就避免了重复的输出操作，并且方便最多`10^4`案例。 

奇偶校验`k % 2 == 0`确定应用两种可能的亏损头寸模式中的哪一种。 对于甚至`k`， 仅有的`n == k`正在失去。 对于奇数`k`， 仅有的`n == k + 1`正在失去。 

比较必须使用相等而不是不平等。 例如，对于奇数`k = 1`， 两个都`n = 2`和`n = 3`是不同的：`2`正在失去，而`3`已经赢了，因为它可以直接移动到`2`。 

Python整数在这里没有溢出问题，最大的算术运算只有`k + 1`，与 Python 的整数范围相比很小。

 | --- | --- | --- | --- | --- |

 从`4`, Kilani 可以减去`2`，达到`2`。 位置`2`下一个玩家输了，所以阿尤布必须从`2`到`1`，之后基拉尼移动到`0`。 因此 Kilani 有一个制胜策略，输出为`Kilani`。

 ## 边缘情况

 对于`n = k = 1`，该算法发现`k`是奇数并检查是否`n == k+1`，这是错误的。 它返回`Kilani`。 实际的游戏是`1 -> 0`，所以起始玩家获胜。 

为了`n = k = 2`,`k`是偶数，所以算法检查是否`n == k`。 为真并返回`Ayoub`。 游戏是`2 -> 1 -> 0`，所以第二个玩家做出最后一步并获胜。 

为了`n = 2, k = 1`,`k`是奇数并且`n == k+1`，所以算法返回`Ayoub`。 第一步只有一个可能，`2 -> 1`，然后阿尤布移动`1 -> 0`，留下基拉尼一动不动。 

为了`n = 3, k = 1`，同样的奇数`k`规则适用，但现在`n`大于`k+1`。 算法返回`Kilani`。 Kilani 可以直接从`3`到失败的位置`2`，之后阿尤布被迫进入失败序列。 

对于最大边界`n = k = 10^9`,`k`是偶数并且`n == k`，所以算法返回`Ayoub`。 没有迭代正比于`n`发生，这正是为什么即使在最大输入值下解也保持恒定时间的原因。
