[CF 150A - 获胜或冻结](https://codeforces.com/problemset/problem/150/A)

 **标签：** 游戏、数学、数论
 **求解时间：** 2m 2s
 **已验证：** 否

 ## 解决方案
 ## 问题理解

 我们从一个数字开始`q`写在纸上。 在每一回合中，玩家必须用一个不平凡的除数替换当前数字，这意味着除数严格介于`1`以及号码本身。 

如果玩家无法采取行动，则该玩家立即获胜。 这与通常的正常游戏惯例相反，在普通游戏中，无法移动的玩家就会失败。 

任务是确定当第一个或第二个玩家都发挥最佳时是否获胜。 如果第一个玩家有获胜策略，我们还需要打印一个有效的第一步。 

输入的数量很小，只有一个整数，但值本身可以大到`10^13`。 这排除了任何试图重复枚举所有除数或执行昂贵的递归游戏状态探索的行为。 平方根因式分解大约为`3 * 10^6`2秒内是完全可以接受的，因为`sqrt(10^13)`是关于`3.16 * 10^6`。 

棘手的部分不是表现，而是因为不寻常的获胜条件而正确理解游戏逻辑。 

一个非常常见的错误是认为“没有动作就意味着失败”。 在许多情况下，这会产生完全相反的答案。 

考虑：

 输入：```
2
```数量`2`没有非平凡的因数。 第一个玩家无法移动，因此第一个玩家立即获胜。 正确的输出是：```
1
0
```使用标准 Sprague-Grundy 直觉的粗心实现会错误地打印播放器`2`。 

另一个微妙的情况是当该数字恰好是两个素数的乘积时。 

输入：```
6
```唯一合法的举动是`2`和`3`。 两者都是素数，因此下一个玩家没有动作并立即获胜。 这意味着搬到`2`或者`3`当前玩家输了。 每一个可能的举动`6`很糟糕，所以`6`本身正在失去。 

正确的输出是：```
2
```没有仔细反转终止条件的简单递归解决方案通常会导致这种情况的倒退。 

围绕主要权力还存在结构性边缘情况。 

输入：```
8
```合法的举动是`2`和`4`。 

如果我们搬到`2`，对手无法移动并立即获胜，因此该移动为失败。 

如果我们搬到`4`，对手必须移动到`2`，然后我们就无法移动并获胜。 

所以`8`获胜，有效的第一步是`4`。 

这个事例说明，游戏的胜败不仅仅取决于当前数字是否合数。 因式分解结构很重要。 

## 方法

 暴力解决方案会将每个可到达的数字视为游戏状态，并递归地确定它是赢还是输。 对于一个号码`x`，我们将枚举所有非平凡除数并递归分析它们。 

递归本身是可以管理的，因为每次移动都会严格减少数量，但昂贵的部分是除数枚举。 在最坏的情况下，我们将扫描最多`sqrt(x)`多次为许多州。 和`x`一样大`10^13`，这很快就会变得浪费。 

更深层次的问题是我们实际上并不需要完整的游戏搜索。 该游戏具有非常严格的结构，因为每一步都用适当的除数代替数字。 

让我们仔细地对状态进行分类。 

素数没有合法的移动。 由于无法移动的玩家获胜，因此每个素数都是获胜状态。 

现在看一个数字，其中只有一个可能的移动，例如`p^2`。 

例子：```
9 -> 3
```此举进入最高点，即为下一位玩家获胜。 所以`9`正在失去。 

现在看看`p^3`。 

例子：```
27 -> 9` or `3
```直接移动到`3`不好，因为对手立即获胜。 但搬到`9`很好，因为`9`正在失去。 所以`27`正在获胜。 

对于纯素数幂，这种交替行为持续存在。 

对于至少有两个不同质因数的数字，情况变得简单得多。 我们几乎总是可以立即进入失败状态。 

关键的观察结果是，唯一失败的状态是具有偶数个质因数的重数总数的数字。 

让：```
n = p1 * p2 * ... * pk
```其中重复的素数被重复计数。 定义：```
Ω(n) = total count of prime factors with multiplicity
```示例：```
Ω(12) = Ω(2^2 * 3) = 3
Ω(18) = Ω(2 * 3^2) = 3
Ω(36) = Ω(2^2 * 3^2) = 4
```每一步都会删除至少一个素因数，因此每一步都会严格减少`Ω(n)`。 

素数有`Ω = 1`并且正在获胜。 

一个数字与`Ω = 2`正在失败，因为每一步都达到了最高点。 

一个数字与`Ω = 3`正在获胜，因为我们可以搬到一个州`Ω = 2`。 

通过归纳法：

 - 奇数`Ω(n)`意味着胜利
 - 甚至`Ω(n)`意味着失去

 整个问题归结为对数字进行因式分解并计算素数重数。 

如果计数为偶数，则玩家`2`获胜。 

如果计数为奇数：

 - 如果根本没有合法的移动，则打印`0`- 否则打印任何留下偶数因数的除数

 最简单的方法是除以一个素因数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 可到达状态的数量呈指数级增长 O(深度) | 太慢了|
 | 最佳 | O(sqrt(q)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 因式分解数字`q`使用试除法最多`sqrt(q)`。 

对于每个除数`d`, 反复除`q`经过`d`在可能的情况下，计算有多少素因数被删除。 
2. 如果试除后剩余值大于`1`，它是一个大于的质因数`sqrt(original q)`，因此再次增加因子计数。 
3.让`cnt`是用重数计算的质因数总数。 

示例：```
12 = 2 * 2 * 3 -> cnt = 3
18 = 2 * 3 * 3 -> cnt = 3
36 = 2 * 2 * 3 * 3 -> cnt = 4
```4. 如果`cnt`是偶数，打印：```
2
```目前的状态是第一名玩家输了。 
5. 否则，第一个玩家获胜。 

打印：```
1
```6. 找到任何留下偶数个质因数的非平凡除数。 

除以一个质因数总是将计数减少一，从而将奇偶校验从奇数更改为偶数。 
7. 如果原数是质数，则没有合法的移动。 打印：```
0
```8. 否则打印：```
q / p
```在哪里`p`是 的任意素因数`q`。 

### 为什么它有效

 不变量是质因数总数的奇偶性。 

每一个动作都替换`n`与一个适当的除数。 这意味着至少有一个素因子消失了，所以 的值`Ω(n)`严格减少。 

一次移动改变了奇偶校验`Ω(n)`因为当且仅当该计数为奇数时，删除任何正数的质因数才会翻转奇偶校验。 由于我们总是可以通过除以素因数来恰好删除一个素因数，因此每个奇数状态都会移动到偶数状态。 

素数有`Ω = 1`并获胜，因为当前玩家无法移动。 

使用感应`Ω(n)`：

 - 所有奇数都获胜
 - 所有偶数计数都在丢失

 所以平局完全决定了比赛的胜负。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    original = n

    cnt = 0
    first_prime = -1

    d = 2
    while d * d <= n:
        while n % d == 0:
            if first_prime == -1:
                first_prime = d
            cnt += 1
            n //= d

        if d == 2:
            d = 3
        else:
            d += 2

    if n > 1:
        if first_prime == -1:
            first_prime = n
        cnt += 1

    if cnt % 2 == 0:
        print(2)
    else:
        print(1)

        if cnt == 1:
            print(0)
        else:
            print(original // first_prime)

solve()
```第一部分使用试除法执行素因数分解。 我们反复除以每个因子，而不是一次删除它，因为游戏取决于多重性。 例如，`12 = 2^2 * 3`必须做出贡献`3`总因素，不`2`。 

变量`first_prime`存储原始数字的一个素因数。 稍后，如果位置获胜，则除以该质数将因子计数恰好减少 1 并翻转奇偶校验。 

检查后循环跳过偶数`2`，这会稍微提高性能。 自从`sqrt(10^13)`仅在附近`3 * 10^6`，这个实现很容易满足时间限制。 

条件`cnt == 1`识别素数。 素数没有合法的非平凡除数，因此即使第一个玩家立即获胜，所需的移动输出为`0`。 

一个常见的实现错误是忘记处理循环后剩余的素因数。 例如，当因式分解时`10`，除以之后`2`我们只剩下`5`。 自从`5 * 5 > 5`，循环停止，我们必须手动计算最后一个素数。

 ## 边缘情况

 质数是最违反直觉的情况，因为没有移动的玩家获胜。 

输入：```
2
```因式分解：```
2 = 2
```所以：```
cnt = 1
```奇数奇偶意味着第一个玩家获胜。 由于不存在非平凡除数，因此正确的移动输出是：```
0
```该算法通过特殊情况来处理这个问题`cnt == 1`。 

现在考虑半素数。 

输入：```
15
```因式分解：```
15 = 3 * 5
```所以：```
cnt = 2
```即使平局也意味着输。 

可能的动作：```
15 -> 3
15 -> 5
```两个目标都是素数，并且素数是获胜状态，因为下一个玩家无法移动。 该算法正确打印：```
2
```现在考虑更高的素幂。 

输入：```
32
```因式分解：```
32 = 2^5
```所以：```
cnt = 5
```奇数平价意味着获胜。 

该算法选择：```
32 / 2 = 16
```现在：```
16 = 2^4
```双方势均力敌，正在输球。 

输出：```
1
16
```这证实了删除一个素因子总是能正确翻转游戏状态奇偶校验。
