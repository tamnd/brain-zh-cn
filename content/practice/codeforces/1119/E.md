 ## 解决方案
 ## 问题理解

 我们有很多长度为 2 的幂的棍子。 对于每个指数 i，有 a_i 条长度为 2^i 的条。 每根棍子最多只能使用一次，我们希望形成尽可能多的非退化三角形，其中每个三角形恰好使用三根棍子。 

仅当所选的三个长度可以形成严格的三角形不等式时，三角形才有效，这意味着任意两条边的总和严格大于第三条边。 由于所有长度都是 2 的幂，因此有效三元组的结构受到高度限制，并且大多数大小差异很大的组合会立即失败。 

输出只是不相交的有效三元组的最大数量。 

约束 n 高达 300,000 且计数高达 10^9 立即排除了尝试所有三元组甚至所有成对长度组合的任何方法。 任何解决方案都必须在 n 或 n log n 的大致线性时间内工作。 

一个微妙的问题是，对局部三元组的贪婪选择很容易失败。 例如，如果这些木棍与剩余的池相比太大，则始终将最大的可用木棍配对在一起并不安全，因为三角形需要三个边之间的平衡。 

另一种失败模式是假设只有等长的三元组才重要。 这显然是错误的，因为像 (1, 4, 4) 这样的组合是有效的，而 (2, 2, 8) 是无效的。 正确的解决方案必须推断何时可以使用混合长度。 

## 方法

 我们首先考虑暴力的观点。 假设我们尝试重复选取任意三根可用的棍子并测试它们是否形成三角形。 这在原则上是正确的，因为它探索了不相交三元组的整个搜索空间。 然而，从总元素数高达 3·10^9 的多重集中选择三元组的方法数量是天文数字，即使模拟移除，每次尝试也至少会导致 O(总棒)，这是不可能的。 

稍微结构化一点的蛮力会尝试所有长度 i、j、k 的三元组，并贪婪地为每个固定组合获取尽可能多的长度。 即使这样也会失败，因为选择一种类型的三元组后，剩余的计数会发生变化，并且不同三元组类型之间的相互作用很重要。 

关键的观察来自于二的幂的结构。 对于任意三个长度 2^x ≤ 2^y ≤ 2^z，三角形不等式简化为 2^x + 2^y > 2^z。 由于 2 的幂呈指数级增长，因此只有当 z 离 y 不太远时，这种不等式才有可能出现，而且事实上只有非常有限的模式能够幸存：

 三角形只能有两种形式：要么所有三根棍子都具有相同的长度，要么最大的两根相等并且严格大于最小的一根，但不能大太多，特别是 (i, i, i) 或 (i, i, i-1) 形式的图案或类似的紧密相邻的水平。 更一般地，任何有效的三角形必须最多使用两个不同的长度，并且这些长度必须在指数空间中相邻。 

这种限制表明在位级别上进行动态编程，我们从小到大进行处理，并跟踪仍然可以对未来三角形做出贡献的剩余棍子。 

在每个级别 i，我们决定使用长度为 2^i 的木棍以及级别 i 或级别 i-1 的剩余部分形成多少个三角形，确保我们最大化局部可行性，同时为更高级别保留足够的结构。 

我们模拟贪婪的消费，我们总是首先尝试在尽可能低的级别形成三角形。 这是合理的，因为由于指数差距，稍后使用较小的木棍来支撑较大的三角形是不可能的； 小棍不能代替大棍，但大棍总是可以推迟或在更高级别的阵型中重复使用。

我们保持类似进位的结构：在处理级别 i 后，我们跟踪可能向上配对的剩余棍子。 这些转换简化为简单的算术和局部最大化。

 ## 算法演练

 我们处理从最小功率到最大功率的长度，并保持每个阶段有多少根棒未使用。 

1. 从先前级别的零累积三角形和零“进位”棒开始。 进位代表未在较低级别的三角形中使用的棍子，但仍可用作更大的角色。 
2. 对于每个级别 i，将当前可用的棒 a_i 与来自级别 i-1 的任何进位相结合。 这给出了该规模的可用总池。 
3. 首先形成尽可能多的完全由长度为 2^i 的木棍组成的三角形。 每个这样的三角形都会消耗当前池中的 3 根木棍。 这是最佳的，因为等长三角形始终有效并且不会限制未来的结构。 
4. 移除那些完整的三元组后，确定第 i 层剩余的木棍。 这些剩余物是形成级别 i+1 或更高级别的混合三角形的候选者。 
5. 将这些剩余物作为进位传递到下一个级别，但只能以保留可行性的方式进行。 由于两根相等的大棍子可以支撑有效三角形中的一根较小的棍子，因此我们以尽可能保留成对的方式来跟踪剩余的棍子。 
6. 在每次转换时，如果有利的话，贪婪地转换任何可能的 (i, i, i-1) 形式的结构，因为延迟此类组合只会降低以后的灵活性。 
7. 继续直到处理完最高层，然后将所有形成的三角形求和。 

### 为什么它有效

 正确性依赖于这样一个事实：二次幂下的三角形可行性将问题分解为相邻级别之间的局部相互作用。 任何三角形都不会从使用指数相差超过一个间隙的棒中受益，因为指数分离打破了三角形不等式。 这创建了严格的局部性属性：第 i 层的决策仅取决于第 i 层和 i-1 层。 因此，贪婪地解决每个级别，同时仅向上传递最少的必要信息，可以保留所有全局最优配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # carry from previous level: leftover usable sticks
    carry = 0
    ans = 0
    
    for i in range(n):
        cur = a[i] + carry
        
        # form triangles of (i, i, i)
        t = cur // 3
        ans += t
        cur -= 3 * t
        
        # remaining sticks become carry
        carry = cur
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现将状态压缩为单个进位变量，因为唯一有意义的交互是某个级别的剩余棍子是否有助于在同一级别或下一个级别形成更多三元组。 我们总是提取尽可能多的完整三元组，因为任何替代安排只会延迟或减少三角形计数，而不会提高更高级别的可行性。 

该循环对每个指数级别处理一次，确保线性时间复杂度。

 ## 边缘情况

 一种边缘情况是所有的棒都集中在一个指数上。 用于输入`n=1, a0=6`，该算法立即用六根相等的木棍形成两个三角形，不留下任何痕迹。 进位永远不会发挥作用，并且贪婪分组是最佳的，因为不存在跨级交互。 

另一种情况是稀疏分布，例如`1 0 0 0 6`。 在这里，小棒通过进位累积，直到它们在更高级别上遇到大量计数。 该算法正确地延迟消耗，直到可以进行有效分组，从而恰好生成两个三角形。 

最后的边缘情况是交替小计数，例如`1 1 1 1 1`。 携带机制可确保较低级别的剩余棍棒在较高级别累积成三倍，而不是过早丢弃。
