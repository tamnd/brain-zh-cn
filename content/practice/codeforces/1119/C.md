 ## 解决方案
 ## 问题理解

 我们有两个矩阵，`A`和`B`，尺寸`n × m`充满`0`沙`1`s。 我们可以修改`A`通过重复选择任意大小至少为`2 × 2`并翻转其四个角的值。 任务是判断是否可以转型`A`进入`B`使用任意顺序的此类角翻转。 

实际上，每个角翻转都会切换一个`0`到`1`或一个`1`到`0`。 由于只有矩形的角受到影响，因此我们可以操作的最小矩形是`2 × 2`。 单个角不能单独切换，并且不属于至少一个的边`2 × 2`矩形不能单独修改。 例如，右下角`1 × 1`矩阵根本无法更改，这使得单行或单列矩阵成为一种特殊情况。 

问题范围是中等的：`n, m ≤ 500`。 对于多达 250,000 个单元，测试所有可能的子矩阵的强力尝试会太慢，因为矩阵中矩形的数量大致增长为`O(n²m²)`。 我们需要一种方法来检查转型的可行性`A`进入`B`无需显式模拟每个操作。 

边缘情况包括非常小的矩阵（`1 × n`或者`n × 1`)，其中无法进行任何操作，以及仅最后一行或最后一列不同的矩阵。 例如，如果```
A = [[0, 1]]
B = [[1, 0]]
```不`2 × 2`子矩阵存在，所以答案一定是`No`。 任何解决方案都必须仔细考虑这些情况。 

## 方法

 天真的做法是尝试所有可能的方法`2 × 2`子矩阵，每当翻转角`A[i][j] ≠ B[i][j]`。 这对于小矩阵可行，但在以下情况下变得不可行：`n`和`m`方法 500。最坏情况的复杂性是`O(n²m²)`只是为了检查所有矩形，对于给定的限制来说太慢了。 

关键的观察结果是`2 × 2`翻转只影响四个单元格：矩形的左上角、右上角、左下角和右下角。 因此，为了匹配`A`到`B`，两个矩阵之间的差异可以通过从左上角传播到右下角来局部处理。 具体来说，如果我们决定翻转位置`(i, j)`，它只会影响位于`(i,j)`,`(i,j+1)`,`(i+1,j)`,`(i+1,j+1)`。 

这导致了**贪婪算法**：从左上角迭代，并且每当当前单元格不同于`B`，翻转`2 × 2`以此单元格为左上角的子矩阵。 通过按顺序处理单元，每次翻转都可以解决当前的不匹配问题，而不会干扰之前已经正确的单元。 唯一不能被覆盖的单元格`2 × 2`翻转是最后一行或最后一列中的那些，它们必须已经匹配`B`以便有解决方案存在。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有矩形）| O(n²m²) | O(纳米) | 太慢了 |
 | 贪心左上传播 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 计算差分矩阵`D = A XOR B`。 每个细胞都是`1`如果`A`不同于`B`和`0`如果它们已经相等。 这编码了需要翻转的地方。 
2. 从左上角到右下角迭代矩阵，不包括最后一行和最后一列（`i = 0..n-2, j = 0..m-2`）。 对于每个单元格`(i,j)`：

- 如果`D[i][j]`是`1`，应用翻转`2 × 2`具有左上角的子矩阵`(i,j)`。 
- 更新四个角`D`通过切换它们（`D[i][j] ^= 1`,`D[i][j+1] ^= 1`,`D[i+1][j] ^= 1`,`D[i+1][j+1] ^= 1`）。 
3. 处理完所有可能的情况后`2 × 2`翻转，检查最后一行（`i = n-1`）和最后一列（`j = m-1`）。 如果有的话`D[i][j]`是`1`在这些领域，产出`No`; 否则，输出`Yes`。 

为什么有效：每次翻转都被选择来修复当前页面左上角的不匹配问题`2 × 2`长方形。 由于之前的行和列已经被修复，未来的翻转永远不会干扰已经纠正的单元格。 该过程保证如果所有差异都可以使用解决`2 × 2`翻转时，最后一行和最后一列将自动归零。 否则，这些区域的不匹配就无法修复，这意味着不可能进行转型。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
A = [list(map(int, input().split())) for _ in range(n)]
B = [list(map(int, input().split())) for _ in range(n)]

# Step 1: difference matrix
D = [[A[i][j] ^ B[i][j] for j in range(m)] for i in range(n)]

# Step 2: greedy top-left flips
for i in range(n - 1):
    for j in range(m - 1):
        if D[i][j]:
            D[i][j] ^= 1
            D[i][j+1] ^= 1
            D[i+1][j] ^= 1
            D[i+1][j+1] ^= 1

# Step 3: check last row and column
possible = True
for i in range(n):
    if D[i][m-1]:
        possible = False
for j in range(m):
    if D[n-1][j]:
        possible = False

print("Yes" if possible else "No")
```每个部分都反映了算法步骤。 XOR 运算构建差异矩阵，嵌套循环实现贪婪翻转，最终检查确保不匹配的单元格保留在`2 × 2`翻转无法到达。 一个微妙的点是从贪婪循环中排除最后一行和最后一列，以避免索引错误。
