 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，这是一个包含从 1 到$n$按某种顺序恰好一次。 根据这个排列，我们构建了一个无向图$n$顶点，其中每个顶点对应于排列中的一个位置。 两个顶点之间存在一条边$i < j$当且仅当较早位置的值大于较晚位置的值，$p_i > p_j$。 本质上，排列中的每个反转都定义了图中的一条边。 

任务是确定该图中多个测试用例的连接组件的数量。 连接组件是顶点的最大子集，使得每对都通过边直接或间接连接。 

约束条件允许$n$最多$10^5$每个测试用例和总和$n$超过所有测试用例$2 \cdot 10^5$。 这意味着任何比线性或接近线性复杂度更差的算法都会太慢。 检查每个可能的顶点对的简单方法最多可以执行$O(n^2)$每个测试用例的操作，这是不可行的。 

微妙的边缘情况包括严格增加排列（其中不存在边缘，因此每个顶点形成其自己的组件）和严格减少排列（其中所有顶点都连接在单个组件中）。 高值和低值之间交替的排列可能会创建多个交织在一起的组件，这需要仔细处理。 例如，对于$[2,1,4,3,5]$，如果不跟踪最大值，这些组件不会立即明显。 

## 方法

 蛮力方法是通过迭代每一对来显式构建完整的图$(i,j)$和$i<j$并检查是否$p_i>p_j$。 然后我们可以从每个未访问的顶点运行 BFS 或 DFS 来计算连接的组件。 虽然正确，但这需要$O(n^2)$建立边的操作加上$O(n + e)$遍历图，最多可达$O(n^2)$作为$e$也可以是$O(n^2)$。 这失败了$n=10^5$。 

关键的观察结果是图中的连接仅由反转决定，并且这些连接具有从左到右的顺序。 换句话说，任何顶点都连接到其右侧具有较小值的所有顶点，并且传递闭包意味着具有重叠最大值的连续线段形成单个组件。 我们不需要显式地存储边。 相反，我们可以从左到右扫描排列，同时跟踪迄今为止看到的最大值。 每当当前索引等于迄今为止看到的最大值时，我们就可以结束一个组件，因为该段中的所有顶点都通过反转直接或间接地互连。 

这种观察将问题简化为排列的单个线性扫描，维护运行最大值，并计算最大值等于当前索引的点。 这是$O(n)$每个测试用例，这对于给定的约束来说足够有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（构建图 + BFS/DFS）| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 具有最大跟踪能力的线性扫描 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化组件计数器，`components = 0`，以及一个跟踪运行最大值的变量，`current_max = 0`。 
2. 使用索引迭代排列`i`从 1 到`n`（为了清楚起见，从 1 开始，或者在代码中从 0 开始进行调整）。 
3. 对于每个位置，更新`current_max`成为最大的`current_max`和`p[i]`。 这会跟踪当前段中看到的最大值。 
4. 如果当前索引`i`等于`current_max`，我们已经到达了连接组件的末端。 增量`components`1. 推理是该段中的所有先前索引都通过反转链连接，因此当前顶点关闭该段。 
5. 扫描整个排列后，`components`包含此测试用例的连接组件的数量。 
6. 对每个测试用例重复上述步骤并输出结果。 

为什么有效：根据定义，只要较大的值在较小的值之前，就存在边缘。 任何索引序列（其中最大值恰好是序列的最右边索引）都会形成一个线段，其中每个顶点都直接或间接连接。 运行最大值确保我们捕获由重叠反转引起的所有间接连接。 每次运行最大值与当前索引匹配时，后续顶点都无法连接回该段，因此它形成一个不同的组件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    components = 0
    current_max = 0
    for i, val in enumerate(p, start=1):
        current_max = max(current_max, val)
        if current_max == i:
            components += 1
    print(components)
```该代码读取测试用例的数量，然后迭代每个测试用例。 对于每个排列，它都会跟踪运行最大值。 每当当前位置与运行最大值匹配时，组件就会结束，并且计数器递增。 枚举与`start=1`将数组索引与问题的从 1 开始的排列值对齐。 这可以防止在将索引与值进行比较时出现相差一的错误。
