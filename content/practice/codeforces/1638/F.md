 ## 解决方案
 ## 问题理解

 我们得到一系列垂直面板，每个面板的宽度为一，高度固定。 从视觉上看，每个面板都连接到顶部的水平条，并且可以向上或向下移动，但它必须始终保持与该条的连接，这意味着每个面板都保持垂直长度段$h_i$一个端点接触杆。 

独立重新定位面板后，我们放置两张矩形海报：一张必须完全位于栏上方，另一张完全位于栏下方。 每张海报必须完全包含在面板的联合内，并且不能越过栏。 目标是选择两张海报的垂直位移和位置，以使它们覆盖的面积之和最大化。 

关键的交互是，移动面板会改变它位于栏上方或下方的部分，从而改变它对于上方或下方海报的有用程度。 然而，每个面板的总高度保持固定，所以我们实际上是在重新分配每个面板$h_i$分为“上贡献”和“下贡献”。 

约束条件允许$n \le 10^4$和$h_i \le 10^{12}$。 这立即排除了子数组或分割配置上的任何三次或二次枚举。 甚至$O(n^2)$如果涉及昂贵的内部扫描，这些方法就会太慢。 我们应该期待$O(n \log n)$或者$O(n)$解决方案，可能基于前缀/后缀优化或间隔上的贪婪分解。 

一些边缘情况值得牢记。 例如，如果所有高度都很小且均匀，天真的贪婪者可能会错误地认为分裂总是有益的$[1,1,1,1]$。 如果一种方法尝试在不考虑连续性的情况下为每个面板分配部分高度，则它可能会错误地混合许多小段的贡献，这是无效的，因为每个海报必须占据单个连续的列块。 

另一个微妙的情况是当一个大的细分市场占主导地位时，例如$[100,1,1,100]$。 不正确的策略可能会尝试将两张海报交错在同一高区域内，但任何重叠都会减少总可用高度，因为每个面板的高度必须在顶部和底部之间分开。 

## 方法

 强力解释首先要考虑如何将每个面板分为上下海报。 对于每个面板$i$，我们可以指定一个值$u_i$作为栏上方使用的部分和$h_i - u_i$正如下面使用的部分。 然后我们会尝试一切可能的方法来选择两个不相交的间隔：一个用于上海报求和$u_i$，以及下面的海报总结的一个$h_i - u_i$。 这很快就变得不可行，因为分配分割和选择间隔的方法有多种。 

即使我们修复了分割配置，计算最好的不相交子数组对仍然需要成本$O(n^2)$如果天真地这样做。 这使得总体复杂性远远超出了极限。 

关键的观察结果是，以“平衡”方式部分分割面板没有任何优势。 任何内部分裂只会同时减少对两张海报的贡献。 相反，每个小组应该有效地致力于一侧或另一侧：要么完全为上面的海报做出贡献，要么完全为下面的海报做出贡献。 

一旦我们以这种方式看待问题，它就变成了一个干净的一维优化：我们选择原始数组的两个不相交的子数组，并且每个选定的子数组将其全部总和贡献给其中一张海报。 最终答案是两个不重叠子数组和的最大可能和。 

这将问题简化为经典结构：计算在每个位置或之前结束的最佳子数组，以及在每个位置或之后开始的最佳子数组，然后将它们组合起来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（分割+间隔）| 指数 /$O(n^3)$|$O(n)$| 太慢了 |
 | 最佳（前缀/后缀 Kadane）|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将问题转化为寻找两个不重叠的最大子数组和。 

1. 计算数组`left[i]`表示完全包含在前缀中的最大子数组和$[1, i]$。 这是使用 Kadane 算法完成的，同时跟踪迄今为止每个位置看到的最佳结果。 
2. 计算数组`right[i]`表示完全包含在后缀中的最大子数组和$[i, n]$。 这也是使用反向 Kadane 扫描计算的。 
3.尝试每个分割点$i$，解释为：第一张海报完全位于$[1, i]$，第二个完全在于$[i+1, n]$。 对于每个分割，计算`left[i] + right[i+1]`。 
4. 取所有分割点的最大值。 

这样做的原因是两个不相交子阵列的任何最佳配置都可以通过某些边界分隔开$i$。 一个子数组完全位于该边界的左侧，另一个子数组完全位于该边界的右侧。 前缀和后缀 DP 确保我们已经知道每一侧的最佳子数组，因此我们只需要选择正确的分割点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    left_best = [0] * n
    cur = a[0]
    best = a[0]
    left_best[0] = best

    for i in range(1, n):
        cur = max(a[i], cur + a[i])
        best = max(best, cur)
        left_best[i] = best

    right_best = [0] * n
    cur = a[-1]
    best = a[-1]
    right_best[-1] = best

    for i in range(n - 2, -1, -1):
        cur = max(a[i], cur + a[i])
        best = max(best, cur)
        right_best[i] = best

    ans = 0
    for i in range(n - 1):
        ans = max(ans, left_best[i] + right_best[i + 1])

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案依赖于两次 Kadane 通行证。 前向传递在每个索引处构建以前缀中任意位置结尾的最佳子数组和。 向后传递对后缀执行相同的操作。 最后的循环将左解和右解缝合在一起，没有重叠。 

一个微妙的点是初始化。 两个 Kadane 追踪器必须从各自方向的第一个元素开始； 用零初始化会错误地允许空子数组，除非明确允许，否则空子数组无效。 答案循环也停止于$n-2$，因为就索引分区而言，两侧都必须非空，即使单个海报解决方案是由已经捕获全数组子数组的前缀或后缀隐式处理的。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 对于单个面板，该算法简化为采用唯一可能的子数组，因为前缀和后缀结构通常是一致的。 输出很简单$h_1$，并且两个 Kadane 通道均使用该值正确初始化。 

例如：

 输入：```
1
7
```前缀和后缀数组都只包含 7，答案是 7，符合只有一张海报有效有用的事实。 

在统一数组中，例如：```
4
2 2 2 2
```Kadane 构建不断增加的前缀最佳值，并且任何拆分都会产生相同的总数。 该算法正确返回 8，对应于选择两个不相交的子数组，它们一起覆盖所有元素。 

在完全负数数组中：```
5
-1 -2 -3 -4 -5
```Kadane 确保每个最佳子数组都是单个元素。 然后分裂在不同的边上两次选取最小负元素，但由于避免了重叠，结果正确地变为$-1$，反映出任何更长的段只会使总和恶化。
