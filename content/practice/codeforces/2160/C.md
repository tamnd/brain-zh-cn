 ## 解决方案
 ## 问题理解

 我们给定一个目标整数$n$，我们想知道是否可以构造一些正整数$x$这样特定的变换应用于$x$并与 XOR 结合产生准确的结果$n$。 

转变$f(x)$取二进制表示$x$，反转位顺序，并将结果解释为新的二进制数。 至关重要的是，反转后的前导零被忽略，这意味着结果的有效位长度取决于反转字符串中的最高设置位。 

所以过程是：选择一个数字$x$，以二进制形式写入，将这些位反转，形成一个新整数$f(x)$，并检查是否$x \oplus f(x) = n$。 

输出只是每个测试用例的是/否决定。 

约束条件$n < 2^{30}$意味着我们只需要推理最多 30 位的数字。 任何有效的$x$重要的是还必须位于足够小的位宽内，以便反转位不会溢出到无限的搜索空间中。 对所有整数进行天真的搜索$2^{30}$已经太大了，因为这意味着最多$10^9$最坏情况下每个测试用例的候选数乘以$t = 10^4$。 

一个更微妙的问题是$f(x)$不是像求补或移位这样简单的按位运算。 反转结合了最低有效位$x$最高有效位$f(x)$，这打破了局部性。 这使得对位的贪心推理变得不可靠，除非我们明确地利用对称性。 

边缘情况出现时$x$具有单个设置位或非常稀疏的结构。 例如，$x = 1$产量$f(x) = 1$，所以异或为零。 这表明$n = 0$总是有可能的。 另一方面，像这样的小值$n = 8$尽管有许多表示形式，但仍会失败，因为反转位不能保持位置独立性，并且异或约束在整个位串中变得全局不一致。 

## 方法

 直接的暴力方法会考验每个候选人$x$，计算$f(x)$，并检查是否$x \oplus f(x) = n$。 计算成本$f(x)$与位长度成正比$x$，那么关于$O(\log x)$。 不过，候选人数最多$2^{30}$使得这完全不可行。 即使每个查询测试其中的一小部分也会导致数十亿次操作。 

关键的结构观察是二进制表示$x$一旦我们考虑 XOR 及其反转引起的回文约束，它就不是任意的。 每一点$x$与精确的一个镜像位交互$f(x)$。 这意味着系统分解为对位对的独立约束，但有一点不同：异或中不存在进位，因此一旦我们固定了位对的长度，就可以独立处理每个位位置$x$。 

我们可以将问题重新解释为构造二进制字符串$s$这样如果我们反转它得到$s^R$， 然后$s \oplus s^R = n$。 这将问题转化为对称位对的一致性检查。 唯一真正的困难是$s$未知，因此我们尝试最大 30 位的可能长度。 对于每个长度，我们尝试从两端向内分配位，确保与所需的 XOR 位一致$n$。 如果任何长度产生一致的分配，答案是肯定的。 

这减少了从整数搜索到检查有限约束系统可行性的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^{30} \cdot \log n)$|$O(1)$| 太慢了 |
 | 最佳 |$O(30^2)$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，考虑可能的二进制长度$L$从 1 到 30。这个想法是$x$不能需要超过 30 位，因为$n$本身是有界的。 
2.对于固定长度$L$， 解释$x$作为$L$-bit 二进制字符串$s$。 我们想要$s \oplus reverse(s) = n$，但只是最低的$L$的位$n$事情。 
3. 对于每个位置$i$从 0 到$L-1$，我们将它与位置配对$j = L-1-i$。 这两个位置通过 XOR 约束相互确定：$$s[i] \oplus s[j] = n[i]$$4. 如果$i = j$，这意味着我们位于奇数长度字符串的中间位，方程变为：$$s[i] \oplus s[i] = 0$$所以我们必须有$n[i] = 0$。 如果$n[i] = 1$，这个长度$L$是不可能的。 
5. 对于$i < j$，我们尝试与 XOR 一致的两个赋值：

 如果$n[i] = 0$， 然后$s[i] = s[j]$， 否则$s[i] \neq s[j]$。 我们传播分配并检查一致性。 
6. 如果我们成功地分配所有位且没有矛盾并确保$x > 0$，我们立即返回 YES。 
7.如果没有长度$L$有效，返回NO。 

### 为什么它有效

 正确性来自于将 XOR 方程简化为镜像位位置的独立约束。 XOR 消除了进位依赖性，因此每个位方程都是局部的。 反转操作仅对索引进行排列，因此整个系统成为变量对之间的一组等式或不等式约束。 任何有效的解决方案都精确对应于该约束图中的一致分配，并且每个一致分配都定义了一个有效整数$x$。 由于测试了所有可能的位长度，因此不会遗漏任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ok(n, L):
    bits = [(n >> i) & 1 for i in range(L)]
    s = [-1] * L

    for i in range(L):
        j = L - 1 - i
        if i > j:
            break

        if i == j:
            if bits[i] == 1:
                return False
            if s[i] == -1:
                s[i] = 0
            continue

        if bits[i] == 0:
            # s[i] == s[j]
            for a, b in [(i, j)]:
                if s[a] == -1 and s[b] == -1:
                    s[a], s[b] = 0, 0
                elif s[a] == -1:
                    s[a] = s[b]
                elif s[b] == -1:
                    s[b] = s[a]
                elif s[a] != s[b]:
                    return False
        else:
            # s[i] != s[j]
            if s[i] == -1 and s[j] == -1:
                s[i], s[j] = 0, 1
            elif s[i] == -1:
                s[i] = 1 - s[j]
            elif s[j] == -1:
                s[j] = 1 - s[i]
            elif s[i] == s[j]:
                return False

    if all(v == 0 for v in s):
        return False

    return True

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        ans = False
        for L in range(1, 31):
            if ok(n, L):
                ans = True
                break
        print("YES" if ans else "NO")

if __name__ == "__main__":
    solve()
```实现的核心是`ok`函数，它尝试构造一个固定长度的有效二进制字符串$L$。 数组`s`代表未知位$x$，初始化为`-1`意思是未分配。 对于每个镜像对，我们根据相应的位来强制相等或不相等$n$。 当一对中的两个位都未分配时，我们直接分配一个有效的配置； 否则我们传播约束并验证一致性。 

中间位条件在以下情况下被显式处理：$i = j$，因为一位与自身的异或不能产生 1。最终检查确保$x$通过拒绝全零赋值而为正。 

## 工作示例

 ### 示例 1：$n = 3$我们尝试$L = 2$首先，因为较小的长度通常就足够了。 

| 我| j | n[i] | 约束| 状态 |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | 1 | s[0] ≠ s[1] | s[0] ≠ s[1] | (0,1)|

 我们得到$s = 01$，对应于$x = 2$。 倒车给出$f(x) = 1$，异或为3，匹配$n$。 

这证实了该算法正确地探索了最小有效表示，而没有过度约束位分配。 

### 示例 2：$n = 8$我们测试的长度最大为 30。对于小型$L$，约束很快就会失效，因为中的高阶位 3$n$强制产生任何镜像二进制结构都无法匹配的不对称性。 对于所有候选长度，在配对步骤中至少出现一个约束矛盾，因此不可能进行分配。 

这表明全局不对称性如何$n$防止存在任何镜像二进制结构。

 ## 边缘情况

 对于$n = 0$，构造很简单，因为任何回文二进制数都可以。 该算法发现$L = 1$, 赋值$s = [0]$，并立即接受。 

为了$n = 1$，存在有效的构造$x = 1$。 在支票上，$L = 1$再次产生一个中间位，该位仅在以下情况下有效$n[i] = 0$，所以算法改为$L = 2$并找到一致的不对称分配。 

对于像这样的值$n = 8$，最高设置的位强制跨越镜像位置的约束，这些约束对于任何长度都不能同时满足。 每一次尝试$L$在固定的中间位或镜像对中的强制失配处产生矛盾，因此所有路径正确地失败。
