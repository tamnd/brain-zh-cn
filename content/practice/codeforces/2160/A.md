 ## 解决方案
 ## 问题理解

 给定一个整数多重集，我们可以将其分成几个较小的多重集，以便每个原始元素总体使用的次数完全相同。 换句话说，我们将出现的数字分为几组。 

对于每个组，我们可以计算其 MEX，即该组中缺失的最小非负整数。 当每个组具有完全相同的 MEX 值时，分区被称为有效分区。 该共享值成为分区的分数。 任务是选择一个分区，使这个分数尽可能小。 

这个问题之所以微妙，是因为我们没有选择一个集合并直接计算它的 MEX。 我们将数字的副本分发到多个组中，并迫使所有组在相同的第一个缺失数字上“失败”。 

约束很小：每个测试最多有 100 个元素，并且值也以 100 为界。这立即排除了分布或分区上的任何指数分布。 即使对值频率进行二次推理也是安全的，但任何显式枚举分区的操作都是不必要的，而且会显得矫枉过正。 

一个天真的错误是假设我们应该只计算整个数组或接近它的东西的 MEX。 但这会失败，因为分割会减少或增加可达到的分数。 另一个错误是认为最好的策略始终是最大化组大小，但 MEX 取决于从 0 向上的每个数字的存在，而不是总和或大小。 

具体的边缘情况是仅存在一个数字时。 例如，`[0, 0, 0]`。 如果我们把所有东西都放在一组，MEX 就是 1。但是如果我们分成三组`{0},{0},{0}`，每个组仍然有 MEX 1，因此得分为 1。粗心的解决方案可能会认为分裂会不可预测地改变 MEX，但这里它保留了结构。 

另一种边缘情况是 0 完全缺失。 例如`[1,2]`。 任何组都立即具有 MEX 0，因此无论分区如何，答案都强制为 0。 如果人们假设 MEX 依赖于更高的值，则很容易忽视这一点。 

## 方法

 暴力方法将尝试将事件分配到多个组中的所有方法，并计算所有组是否共享相同的 MEX。 这涉及到分区`n`元素分成任意子集，其增长速度超过指数。 即使是为了`n = 100`，这是完全不可行的。 

关键的观察结果是，分数完全取决于该组的完整副本的数量`{0, 1, 2, ..., x-1}`我们可以跨群体组建。 如果我们想要一个团体拥有 MEX`x`，然后每个数字`0`到`x-1`必须在该组中至少出现一次，同时`x`一定失踪了。 

实现所有组都具有相同 MEX 的有效分区`x`，每组至少消耗每个数字出现一次`0..x-1`。 因此，如果我们表示`freq[i]`作为值的频率`i`，我们可以形成的此类组的数量受到其中最小频率的限制`0..x-1`。 

设该最小值为`k`。 我们最多可以形成`k`每个组包含每个数字的一​​个副本`0..x-1`。 只要我们确保，所有剩余元素（包括额外的副本）都可以放置在任何地方而不影响 MEX`x`没有出现在任何组中。 

对于一个有效的构造，我们至少需要`k`团体，我们还需要确保`x`并非偶然出现在所有组中。 关键的限制是我们必须确保对于某些`x`，该结构是可行的并且产生尽可能小的此类值。 

这减少了对每个候选 MEX 的检查`x`, 是否所有数字`0..x-1`至少存在一次。 如果缺少任何一个，我们甚至无法形成一个 MEX ≥ x 的有效组。 因此，最小的`x`失败或受到限制的地方决定了答案。 

我们不构建分区，而是直接推断何时不可能在所有组中维持更高的 MEX。 答案最终是第一个频率下降得太低而无法支持跨群体重复覆盖的指数。

 ## 算法演练

 1. 计算数组中每个值的出现频率。 

这使我们能够立即访问可以跨组分配的每个数字的副本数。 
2. 从 0 向上开始检查候选 MEX 值。 

我们实际上是在问：我们能否强制所有群体至少拥有 MEX`x`？ 
3.对于固定的`x`，验证每个数字是否来自`0`到`x-1`至少出现一次。 

如果缺少任何一个，则任何组都无法包含所有必需的元素，因此 MEX 无法到达`x`。 
4. 追踪最大的`x`使得所有数字`0..x-1`存在。 

这是整数的连续前缀中断的点。 
5. 答案正是这个可实现的最大前缀长度。 

超过这一点，MEX 就无法在所有组中持续增加。 

### 为什么它有效

 具有相同 MEX 的每个组都强制执行共享的结构要求：每个组必须包含低于该 MEX 的所有数字。 这将问题简化为检查数字集从 0 开始的“前缀完整”程度。分区自由度不会改变此要求，因为全局丢失数字意味着不可能满足任何组中的条件。 因此，答案仅取决于多重集中存在的从 0 开始的最长连续前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = [0] * 105
        for x in a:
            freq[x] += 1
        
        mex = 0
        while freq[mex] > 0:
            mex += 1
        
        print(mex)

if __name__ == "__main__":
    solve()
```频率数组仅用于检测从 0 开始的第一个缺失整数。循环递增`mex`直到找到频率为零的值，这正是多重集的 MEX 定义。 

重要的实现细节是我们根本不尝试模拟分区。 该解决方案完全依赖于这样的观察：分区不会改变某个值是否存在于多重集中，因此不会影响确定可行性的前缀条件。

 ## 边缘情况

 对于像这样的输入`[0]`，频率检查看到`freq[0] > 0`并移动到`1`， 在哪里`freq[1] = 0`。 算法输出`1`，与任何分区（只能是一组）具有 MEX 1 的事实相匹配。 

对于像这样的输入`[2,3,4]`，循环立即失败`mex = 0`， 自从`0`缺席。 这会产生输出`0`，并且任何分区也必须具有 MEX 0，因为没有组可以包含 0。 

对于`[0,1,1,2,2]`，循环继续进行`0,1,2`但停在`3`。 这证实了重复并不重要，重要的是每个整数是否至少出现一次。
