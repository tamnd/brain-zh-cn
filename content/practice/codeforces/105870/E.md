 ## 解决方案
 ## 问题理解

 我们得到一个涉及两个变量的结构化多项式恒等式$x, y$在有限域上。 核心对象是一个二元多项式$P(x,y)$，但这不是任意的。 已知它是由隐藏的单变量多项式生成的$Q(z)$通过形式的表达$Q(x)-Q(y)$，和另一个隐藏多项式$R(z)$这是紧密相连的$Q$。 

定义关系是，当您乘以未知的二元多项式时$P(x,y)$通过差异$Q(x)-Q(y)$，结果折叠成纯单变量反对称形式$R(x)-R(y)$。 这意味着结构$P$不是独立噪声，而是编码两个单变量多项式如何通过替换相互作用$x$和$y$。 

任务是重建一致的多项式$Q$和$R$（或等效的组合物$R = T(Q)$）解释了观察到的领先部分$P$。 但是，输入并不能完全访问$P$。 仅最高程度的术语$P(x,y)$保证正确，而较低阶项可能丢失或损坏。 

因此，计算目标是从部分双变量数据中恢复隐藏的组成结构：找到$Q$和一个多项式$T$这样$R(x)=T(Q(x))$和主导结构$P$与观察到的相符。 

这些约束隐式地强制所有重建步骤在尺寸参数上接近二次或更好$n$，因为两者$P$和$Q$最多可以拥有学位$n$。 对系数的任何三次重建都已经是临界值，并且任何涉及对稠密多项式进行重复朴素卷积的操作都将太慢。 

一个天真的尝试会尝试猜测系数$Q$， 形式$R=T(Q)$， 扩张$R(x)-R(y)$, 除以$Q(x)-Q(y)$，并与$P$。 这会失败，因为系数空间太大，并且多元多项式环中的除法在部分信息下不稳定。 低度项中的小错误在扩展时会传播为高度不一致。 

第二个天真的想法是治疗$P(x,y)$作为通用二元多项式并尝试将其直接与商结构进行匹配。 但是，如果不利用反对称性和复合结构，这将成为求解大型非线性系统的系数，这是不可行的。 

关键的困难是只有顶部同质层$P$是可靠的，因此任何有效的解决方案都必须能够仅从领先度结构来重构。 

## 方法

 蛮力观点认为$Q$和$T$作为未知系数向量并尝试强制执行恒等式$$P(x,y)(Q(x)-Q(y)) = R(x)-R(y)$$通过两边展开并匹配系数。 原则上这是可行的，因为系统是多项式的并且完全由足够的方程确定，但是展开式会产生$O(n^3)$系数之间的相互作用$P$,$Q$， 和$R$。 即使存储中间表达式也变得昂贵，更重要的是，低度噪声$P$破坏了直接系数匹配的正确性。 

结构上的突破在于右侧不仅仅是任何反对称多项式。 它必须由由以下组成的单变量多项式生成$Q$。 这迫使$R$位于由生成的代数中$Q$，它强制整个二元表达式分解为对称构建块$f_d(x,y)=\sum Q(x)^i Q(y)^{d-i}$。 一旦认识到这一点，问题就不再是两个变量的问题，而是变相的单变量重建问题。 

我们不是立即恢复所有系数，而是逐层恢复信息：首先，领先的同质结构决定了$Q$和$T$，然后部分牛顿和式重建恢复了高阶系数$Q$，最后组合约束恢复系数$T$。 其他一切都表明不会影响可观察到的领先部分$P$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 直接系数匹配 |$O(n^3)$|$O(n^2)$| 太慢了 |
 | 结构化分解通过$Q, T$|$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 我们从实际可观察到的东西向后推算：只有最高阶的部分$P(x,y)$，表示为$P^{[\ge d]}$，是可靠的。 

### 1.从前导层提取度信息

 我们检查最高同质成分$P$。 它的结构仅在总度数与$\deg Q$。 从这个模式我们推断出$\deg Q = q$和$\deg T = s$独一无二。 这样做的原因是顶层$P$正是一个缩放版本$$f_{s-1}(x,y)=\sum_{i=0}^{s-1} Q(x)^{i}Q(y)^{s-1-i}$$它直接编码两个度数。 

### 2. 恢复高次系数$Q$我们现在治疗$Q$作为莫尼克。 关键思想是权力$Q^s$对系数进行编码$Q$以类似于牛顿恒等式的方式：$Q^s$确定根的对称和，从而确定系数$Q$。 

我们重建系数$Q$从最高到最低程度。 假设我们已经知道位置以上的所有系数$t$。 位置处的系数$t$呈线性展开$Q^s$，因为该术语的每次出现都必须与$s-1$已知的主导术语。 这将线性方程隔离在一个未知数中，从而允许顺序恢复。 

更有效的观点与众不同$Q^s$，使用身份$$\frac{d}{dz}Q(z)^s = s Q(z)^{s-1} Q'(z),$$它将系数提取变成三角线性系统。 

### 3. 确定有多少$Q$是实际需要的

 我们并不总是需要完整的多项式$Q$。 仅系数降至截止值$D = \min(n-d, q)$影响可观察部分$P$。 任何较低的值都不会影响主要的二度结构，因此我们在该深度处截断重建。 

这很重要，因为它使重建保持有界，并避免对不相关系数进行不必要的工作。 

### 4. 建立以下权力$Q$一旦我们足够了解$Q$，我们计算$Q^i$为所有人$i \le s$。 这是使用重复乘法迭代完成的，这是安全的，因为我们只需要多项式乘积达到次数$n$，结构保证$n = O(sq)$。 

### 5. 恢复 的首项系数$T$我们使用身份$$R(x)=T(Q(x))$$并评估于$y=0$，将双变量约束简化为单变量插值问题$Q(x)$。 扩展$T(Q(x))$在基础上$1, Q(x), Q(x)^2, \dots$允许我们分离系数$T$从已知的展开$R$，它本身是从观察到的部分得出的$P$。 

仅最高阶系数$T$在此阶段确定，因为较低的系数与未知的较低部分混合$Q$，这不影响主导项$P$。 

### 6. 使用重建验证一致性

 我们重建$$\frac{R(x)-R(y)}{Q(x)-Q(y)}$$使用恢复的$Q$和部分$T$，并将其主导结构与$P^{[\ge d]}$。 这是确定性地完成的$O(n^3)$或概率地使用随机评估和 Schwartz-Zippel$O(n^2)$。 

### 为什么它有效

 整个算法依赖于度过滤不变量：任何涉及的表达式的最高度部分$Q(x)-Q(y)$和$R(x)-R(y)$仅取决于最高阶分量$Q$和$T$。 较低阶系数不能在总阶数上向上传播，因为每次与$Q(x)-Q(y)$以受控方式改变程度。 这使得重建呈三角形：一旦高度结构被固定，所有剩余的未知数要么变得线性确定，要么与观察到的部分无关。$P$。

 ## 边缘情况

 一种微妙的情况是$\deg Q$超过可观察的截断深度$n-d$。 在这种情况下，算法必须避免尝试重建不存在的系数。 截止点$D$确保我们只对有意义的部分进行操作$Q$，因此即使真实多项式更大，我们也永远不会访问无效索引。 

另一个边缘情况是当$T$拥有学位 1。那么$R=Q$并且分解变得简并。 前导层提取仍然有效，因为$f_0(x,y)=1$，并且重构简化为验证单个单项式的一致性。 

当多个系数$Q$原则上可以影响相同的系数$Q^s$。 系数系统的三角形结构可以防止歧义：每一步都精确地隔离一个未知数，因为所有更高阶的贡献都已经固定。
