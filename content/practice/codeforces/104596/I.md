 ## 解决方案
 ## 问题理解

 我们有一个代表考古遗址的小网格。 每个细胞要么是宝藏，要么是岩石，要么是空旷的空间。 已知该结构由方形房间组成，其中每个房间都是最大轴对齐的空单元格方块，并且每个这样的房间都包含一件宝藏。 岩石充当破坏房间结构的坚硬障碍。 

任务是将网格的有效平铺重建到这些方形房间中，为每个房间分配唯一的标签，或确定不存在有效的分解。 每个空单元格必须恰好属于一个正方形房间，每个房间必须是一个完美的正方形，并且每个房间必须恰好包含一件宝藏。 

网格大小最多为$100 \times 100$，因此检查当地可行性并扩大区域的建设就足够了。 详尽的分区是不必要的。 

当一个人试图独立地贪婪地扩展每个宝藏而不检查重叠时，就会发生幼稚的失败情况。 两个房间可能会竞争同一个空单元，从而导致分配不一致。 

例子：```
1 3
$.$
```来自单个宝藏的贪婪扩展可能会错误地将整行分配为一个房间，忽略平方约束强制$1 \times 1$房间周围有宝藏。 任何不受控制的增长策略都会失败，因为房间边界受到全局限制。 

## 方法

 暴力方法会尝试为每个宝藏分配一个正方形大小，然后验证诱导平铺是否覆盖网格而没有重叠且没有丢失宝藏。 对于每个宝藏，我们可以尝试所有可能的正方形边长并检查一致性。 这导致正方形大小和位置的指数组合，并且每个验证成本$O(nm)$，即使对于$100 \times 100$网格。 

关键的观察是，每个宝藏唯一地确定以该宝藏为中心的最大平方，该最大平方可以存在于任何有效的解决方案中。 由于房间不重叠并且必须覆盖所有空单元格，因此将每个宝藏扩展到尽可能大的有效正方形，然后验证一致性就足够了。 一旦确定了最大平方，它要么一致地适合全局平铺，要么该实例是不可能的。 

这减少了从每个宝藏扩展到被岩石、网格边界或其他房间阻挡的问题，同时确保每个空单元格都被恰好声明一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 正方形的暴力枚举 |$O(2^{t} \cdot n^2)$|$O(n^2)$| 太慢了|
 | 每个宝藏的最大平方扩展 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们通过在每个宝藏周围生长方形区域来建造房间。 

### 步骤

 1.读取网格并收集所有宝藏的坐标。 

在任何有效的解决方案中，每个宝藏都被假设为正好一个方形房间的中心。 
2. 对于每个宝藏，尝试确定包含它的最大有效方格。 

我们在四个方向上均匀地向外扩展，同时确保所有单元都保留在网格内并且不会穿过岩石。 

边长受所有四个方向上到边界或障碍物的最小距离的限制。 
3. 对于宝藏周围的每个候选方格，验证：

 正方形内的每个单元格要么是空的，要么已经被一致分配，

 除了当前的宝藏之外，广场内没有其他宝藏。 

这确保了房间不会重叠，并且每个房间都恰好包含一件宝藏。 
4. 按照第一次遇到的行优先顺序为每个有效方块分配唯一标签。 
5. 用标签标记每个方块内的所有单元格。 岩石保持不变。 
6. 处理完所有宝藏后，验证每个非岩石单元是否已准确分配到一个房间。 
7. 如果分配时出现冲突或验证失败，则输出布局不可能。 

### 为什么它有效

 每件宝藏必须恰好属于一个正方形房间，并且正方形不能重叠。 贪婪地扩展到最大可行正方形可确保如果存在有效平铺，则构造的正方形将唯一匹配它。 任何较小的选择都会留下未被覆盖的空白空间，如果不破坏方形结构或引入额外的宝藏，就无法填充这些空白空间。 

因此，最大扩展过程保留了覆盖范围和唯一性约束，并且当不存在有效平铺时恰好发生故障。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [list(input().strip()) for _ in range(n)]

    treasures = []
    for i in range(n):
        for j in range(m):
            if g[i][j] == '$':
                treasures.append((i, j))

    used = [[False]*m for _ in range(n)]
    ans = [['']*m for _ in range(n)]

    def can_place(x1, y1, x2, y2, ti, tj):
        seen_t = False
        for i in range(x1, x2+1):
            for j in range(y1, y2+1):
                if g[i][j] == '#':
                    return False
                if g[i][j] == '$':
                    if (i, j) != (ti, tj):
                        return False
                    seen_t = True
                if used[i][j]:
                    return False
        return seen_t

    label = ord('A')

    for ti, tj in treasures:
        best = None

        for size in range(1, 101):
            x1, y1 = ti, tj
            x2, y2 = ti + size - 1, tj + size - 1
            if x2 >= n or y2 >= m:
                break
            if can_place(x1, y1, x2, y2, ti, tj):
                best = (x1, y1, x2, y2)
            else:
                break

        if best is None:
            print("elgnatcer")
            return

        x1, y1, x2, y2 = best

        for i in range(x1, x2+1):
            for j in range(y1, y2+1):
                used[i][j] = True
                ans[i][j] = chr(label)

        label += 1
        if label == ord('Z') + 1:
            label = ord('a')

    for i in range(n):
        for j in range(m):
            if g[i][j] == '#':
                ans[i][j] = '#'
            elif ans[i][j] == '':
                print("elgnatcer")
                return

    for row in ans:
        print(''.join(row))

if __name__ == "__main__":
    solve()
```该解决方案围绕其宝藏独立建造每个房间，并将其扩展，直到第一个无效的扩展。 辅助功能强制执行结构约束和每个房间的宝藏的唯一性。 最终验证确保全面覆盖。 

一个微妙的细节是单调扩展：一旦尺寸失败，更大的尺寸永远不会有效，因为添加更多单元格只会增加遇到岩石、另一个宝藏或先前分配的单元格的机会。

 ## 边缘情况

 被空白空间包围的单个宝藏测试算法是否正确扩展至边界条件。 当进一步的增长超过电网界限时，扩张就会停止。 

对角放置的两个宝藏之间有空白空间，确保独立扩展不会干扰，并且分配步骤不得覆盖已分配的单元格。 

与宝藏相邻的岩石的配置测试了扩张的提前终止； 任何穿过岩石生长的尝试都会立即使更大的方块失效，从而确保正确的边界检测。
