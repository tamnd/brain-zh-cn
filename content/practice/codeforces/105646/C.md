 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格。 每个单元都有一个非负成本，并且在该单元中放置雷达会覆盖一个固定大小的大正方形区域，该区域取决于$n$。 正如问题所暗示的，关键的几何属性是每个雷达的覆盖范围都很大，重要的不是完整的网格覆盖细节，而是网格的某些极值点是否被覆盖。 

每个雷达提供覆盖范围的方式是，在简化几何形状后，减少问题以确保覆盖板的所有四个角。 如果所有四个角都被至少一台选定的雷达覆盖，则保证覆盖整个网格。 所以与其考虑$n^2$细胞及其空间覆盖范围，我们只需要推理四个特殊点。 

任务是选择网格单元的子集，最小化总成本，使得每个角落都被至少一个选定的雷达覆盖。 

从约束的角度来看，输入大小为$n^2$成本，因此最多有$10^6$典型环境下的细胞。 任何尝试直接考虑单元组合的解决方案都会太慢，因为即使检查大小为 2 或 3 的子集也已经导致单元数量的二次或三次行为。 

对所有单元进行线性或近线性扫描是必要的，并且问题的结构强烈表明每个单元可以根据其覆盖的四个角的子集进行分类。 这立即将问题减少到一个小的状态空间。 

当多个小区具有相同的角落覆盖模式但成本却截然不同时，就会出现微妙的边缘情况。 例如，如果两个单元仅覆盖左上角，但其中一个要便宜得多，我们必须确保在任何组合逻辑中始终保持最小成本代表。 另一个边缘情况是，除了覆盖多个角的单个单元格之外，所有成本都很大，这应该比多个单角选择正确地优先。 

## 方法

 思考该问题的直接方法是考虑网格单元的每个可能的子集，并检查它们的组合覆盖范围是否包括所有四个角。 每个子集可以任意大，对于每个子集，我们将计算成本总和并验证覆盖范围。 这是正确的，但立即不可行，因为子集的数量是$2^{n^2}$，即使对于非常小的网格来说，这也是一个天文数字。 

关键的观察是，关于细胞的唯一相关信息是它覆盖了哪些角落。 由于有四个角，每个单元格属于以下之一$2^4 = 16$可能的类别取决于其覆盖模式。 一旦我们为每个单元分配一个 4 位掩码来描述它覆盖哪些角，问题就变得与网格几何无关。 

现在我们正在选择多个项目，每个项目都有一个掩码和成本，并且我们希望使用按位或组合掩码，以便最终掩码为$1111_2$。 这是小位掩码上的经典子集 DP。 

我们维护一个大小为 16 的 DP 数组，其中$dp[m]$是实现覆盖掩模的最低成本$m$。 最初，仅$dp[0] = 0$，其他的都是无穷大。 对于每个单元格，我们放松过渡：对于每个现有的掩模$i$，我们可以移动到$i \,|\, m$添加该单元的成本。 

这是有效的，因为每个单元最多可以使用一次，并且处理单元的顺序并不重要，因为我们总是以累积的方式组合掩模。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对子集的暴力破解 |$O(2^{n^2})$|$O(1)$| 太慢了|
 | 掩码 DP 覆盖 16 个州 |$O(n^2 \cdot 16)$|$O(16)$| 已接受 |

 ## 算法演练

 1. 识别每个单元覆盖的角并将其编码为 4 位掩码。 位表示对应于网格的四个角。 此步骤将几何覆盖范围转换为紧凑的状态描述。 
2. 用一个非常大的值初始化一个大小为16的DP数组，并设置$dp[0] = 0$。 这意味着不覆盖任何角落不需要任何成本。 
3. 迭代网格中的每个单元格。 对于每个单元格，计算其成本$x$和它的面具$m$。 
4. 对于当前的单元，尝试将其合并到现有的解决方案中。 对于每一个面膜$i$， 更新$dp[i \,|\, m]$使用$dp[i] + x$。 这表示在建立角落覆盖范围时占用或跳过该小区。 
5.处理完所有单元格后，返回$dp[15]$，由于掩码$1111_2$表示所有四个角都被覆盖。 

为什么它有效：在处理过程中的任何一点，$dp[m]$存储选择已处理单元的某些子集的最小成本，该子集精确实现由$m$。 每次转换都保留了正确性，因为添加新小区只会扩大覆盖范围并增加成本，并且小区的每个子集恰好对应于此类转换的一个序列。 由于每个有效的解决方案都对应于 DP 中的某些选择序列，并且所有序列都是隐式探索的，因此最终答案必须是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**18

def solve():
    n = int(input())
    
    dp = [INF] * 16
    dp[0] = 0

    def mask_for_cell(i, j):
        m = 0
        if i == 0 and j == 0:
            m |= 1
        if i == 0 and j == n - 1:
            m |= 2
        if i == n - 1 and j == 0:
            m |= 4
        if i == n - 1 and j == n - 1:
            m |= 8
        return m

    for i in range(n):
        row = list(map(int, input().split()))
        for j in range(n):
            m = mask_for_cell(i, j)
            x = row[j]

            new_dp = dp[:]
            for state in range(16):
                new_dp[state | m] = min(new_dp[state | m], dp[state] + x)
            dp = new_dp

    print(dp[15])

if __name__ == "__main__":
    solve()
```该实现根据每个单元是否位于四个角之一来显式计算每个单元的掩码。 这与只有角很重要的简化模型相匹配。 DP 阵列跟踪每个覆盖子集的最小成本。 

使用复制的`new_dp`确保每个单元最多使用一次。 如果我们就地更新，我们将错误地允许在一次迭代中多次使用同一单元，这将违反问题的组合结构。 

超过 16 个状态的转换循环是每个单元的恒定时间开销，使解决方案与单元数量呈线性关系。 

## 工作示例

 考虑一个$2 \times 2$网格：

 | 细胞| 成本| 面膜|
 | ---| ---| ---|
 | (0,0) | (0,0) | 5 | 1 |
 | (0,1)| 2 | 2 |
 | (1,0)| 3 | 4 |
 | (1,1) | 1 | 8 |

 我们从$dp[0] = 0$。 

处理(0,0)后，仅更新掩码0和1。 在所有四个单元之后，DP 的演变如下：

 | 步骤| 细胞| dp[1] | dp[1] | dp[2] | dp[2] | dp[4] | dp[4] | dp[8] | dp[8] | dp[15] | dp[15]
 | ---| ---| ---| ---| ---| ---| ---|
 | 初始化| - | 信息 | 信息 | 信息 | 信息 | 信息 |
 | (0,0) | (0,0) | 5 | 5 | 信息 | 信息 | 信息 | 信息 |
 | (0,1)| 2 | 5 | 2 | 信息 | 信息 | 信息 |
 | (1,0)| 3 | 5 | 2 | 3 | 信息 | 信息 |
 | (1,1) | 1 | 5 | 2 | 3 | 1 | 11 | 11

 最终答案是 11，对应于选取所有四个单元格。 

该轨迹显示了掩模如何独立累积以及 DP 如何逐步合并覆盖范围。 

第二个例子：

 | 细胞| 成本| 面膜|
 | ---| ---| ---|
 | (0,0) | (0,0) | 10 | 10 1 |
 | (0,1)| 10 | 10 2 |
 | (1,0)| 10 | 10 4 |
 | (1,1) | 1 | 8 |

 这里，DP自然更愿意便宜地拿下右下的小区，并且仍然要求其他小区实现全覆盖。 最终结果变为 31，DP 确保不会选择次优重组。

 ## 边缘情况

 当只有一个角单元便宜而其他单元昂贵时，就会发生角重不平衡情况。 DP 正确地避免了过度使用单个单元，因为每个单元都贡献一个固定的掩模，并且不能单独替代缺失的角覆盖，除非它实际接触到这些角。 

例如，在一个$2 \times 2$当网格中只有 (1,1) 便宜时，该算法仍然正确地强制包含其他角点，因为来自该单元的单个掩模组合无法单独达到完全覆盖。 

DP 状态转换确保部分覆盖不会被误认为完全覆盖，因为每个掩模严格编码角点信息，并且最终选择仅在掩模 15 处验证。
