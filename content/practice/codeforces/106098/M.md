 ## 解决方案
 ## 问题理解

 我们给定一个正整数`n`作为二进制字符串。 我们需要计算有多少个正整数`x`存在这样的二进制表示`x`的位数不超过`n`，以及三个值`n + x`,`n | x`， 和`n ^ x`都是相同的。 答案必须以模数形式打印`10^9 + 7`。 

问题的关键部分是理解加法何时表现得与按位运算完全相同。 在二进制加法中，唯一的区别是`n + x`和`n | x`来自携带。 如果两者都设置了一个位`n`和`x`，将这两位相加会产生一个进位。 如果没有两个数字都有的位置`1`，加法只是将现有的位放在一起，这正是 OR 的作用。 

第二个条件是 OR 和 XOR 必须匹配。 在两个数字都有的时候`1`, 或产生`1`而异或产生`0`。 在所有其他位位置，它们是相等的。 所以这个条件还要求`n`和`x`永远不要分享设定的位。 

这两个要求都简化为相同的简单条件：```
n & x = 0
```现在问题变成计算正整数`x`至多`m`位，其中`m`是二进制字符串的长度，仅使用其中的位置`n`有一个零。 

长度限制意味着最高可用位索引是`m - 1`。 的领先位`n`总是`1`，因此该位置永远不能被使用`x`。 剩余位置中的每个零都是一个自由选择：我们可以将其中一个`0`或者`1`在`x`。 自从`x`必须是正数，我们不能选择全零。 

输入尺寸可以达到`10^6`位。 这排除了将二进制字符串转换为普通整数并对该值使用算术循环的可能性，因为该值本身太大了。 该算法必须直接处理字符串并为每一位执行恒定量的工作，给出`O(m)`解决方案。 

一个常见的错误是忘记了`x`不能为零。 例如，如果`n = 111`，每一位都被占用。 唯一没有重叠设置位的数字是`0`，但这是不允许的，所以答案是`0`。 

另一种边缘情况是只有一个空闲位。 对于输入：```
m = 3
n = 101
```的有效值`x`仅是`{2}`因为`010`是唯一避免设置位的正掩码`n`。 正确的输出是：```
1
```计算所有掩码而不减去空掩码的解决方案将错误地输出`2`。 

## 方法

 蛮力的想法是尝试一切可能的方法`x`从`1`到`2^m - 1`，检查是否`n & x`为零，并计算有效选择。 这是正确的，因为上面导出的条件既是必要的又是充分的。 问题是`m`可以是`10^6`，因此候选者的数量是指数级的。 即使对于几百位，枚举也是不可能的。 

有用的观察是`x`是独立的。 对于每一位位置`n`有一个零，`x`可以选择其中之一`0`或者`1`。 对于每一位位置`n`有一个，`x`被迫选择`0`。 

如果有`cnt`长度内的零位`n`， 有`2^cnt`可能的掩码包括全零掩码。 自从`x`必须是肯定的，最终答案是`2^cnt - 1`。 

唯一剩下的挑战是计算`cnt`。 我们扫描二进制字符串并计算零个字符。 因为第一个字符总是`1`，计算所有零字符直接给出空闲位置的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m) | O(2^m) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取二进制字符串和字符串本身的长度。 只需要知道可用位位置的数量即可。 
2. 统计字符串中有多少个字符`0`。 每个这样的位置代表一个位`x`可以自由选择是否设置。 
3. 计算`2^cnt`模数`10^9 + 7`， 在哪里`cnt`是零位的数量。 
4. 将结果减一以删除无效选择，其中每一位`x`为零。 
5. 打印取模后的结果值`10^9 + 7`。 

为什么有效：每个有效`x`对应于选择零位置的子集`n`。 两个不同的子集创建两个不同的正整数，并且每个这样的子集满足`n & x = 0`。 唯一不允许的子集是空子集，它会创建`x = 0`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    m_line = input().strip()
    if not m_line:
        return
    m = int(m_line)
    s = input().strip()

    cnt = s.count('0')
    ans = pow(2, cnt, MOD) - 1
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```实现直接遵循计数参数。 字符串操作`count('0')`给出可用位位置的数量，而无需将二进制数转换为整数.

 幂是通过模幂计算的，因为零位的数量可以大到`10^6`。 蟒蛇的`pow`使用模数可以使中间值保持较小，并以相对于指数的对数时间运行。 

对幂取模后减一`MOD`。 最后的模运算处理值变为负数的情况。

## 测试用例```python
import sys
import io

MOD = 10**9 + 7

def solve_io(data: str) -> str:
    sys.stdin = io.StringIO(data)
    input = sys.stdin.readline

    m_line = input().strip()
    if not m_line:
        return ""

    m = int(m_line)
    s = input().strip()

    cnt = s.count("0")
    return str((pow(2, cnt, MOD) - 1) % MOD)

# sample 1
assert solve_io("5\n11010\n") == "3", "sample 1"

# all bits are one

# only one zero bit
assert solve_io("3\n101\n") == "1", "single choice"

# minimum size
assert solve_io("1\n1\n") == "0", "one bit number"

# many zeros
assert solve_io("6\n100000\n") == "31", "all lower bits are free"

 ## 边缘情况

 对于`n = 111`，每个位置已经包含一个`1`。 该算法计算零个空闲位置，计算`2^0 - 1`，并返回`0`。 这与没有积极的事实相符`x`可以避免重叠`n`。 

为了`n = 101`，唯一的零位置是中间位。 该算法计算一个空闲位置并计算`2^1 - 1 = 1`。 单个有效值为`x = 010`， 和`101 & 010 = 0`，所以三个表达式都是相等的。 

对于像这样的数字`n = 100000`，每个较低位都是免费的。 有五个零位置，因此这些位置的每个非空子集都是有效的。 答案就变成了`2^5 - 1 = 31`，这表明算法正确处理了最大选择数的情况。
