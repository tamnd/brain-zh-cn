 ## 解决方案
 ## 问题理解

 我们得到一个由所有整数索引的磁带，在两个方向上无限延伸。 着色是高度结构化的：它由黑白交替的块组成，每个块都有相同的未知长度$L$。 所以磁带看起来像$B^L W^L B^L W^L \dots$并且这种模式在两个方向上永远重复。 

与磁带交互的唯一方法是查询位置$x$，它返回该单元格是黑色还是白色。 任务是确定 的值$L$每个测试用例最多使用 2000 个查询。 

驱动解决方案的关键约束是交互限制。 任何向外线性扫描或检查每个位置的方法都是立即不可能的，因为$L$可以大到$10^{18}$。 即使是对数搜索也必须仔细构建，因为当函数是周期性的时，关于单调性的朴素二分搜索假设不会自动成立。 

一个微妙的边缘情况是当您隐式推理的起始位置与块边界不对齐时。 例如，如果位置 0 位于黑色段内，则右侧最近的变化位于下一个白色块的开头，而不是在$L$。 一个天真的假设“第一次颜色变化给出了$L$” 除非我们也知道之前的边界在哪里，否则就会中断。

 如果尝试使用“颜色是否等于 0 处的颜色”之类的谓词对位置进行二分搜索，则会出现另一种失败情况。 该谓词在全球范围内并不是单调的。 如果$L = 3$，与位置 0 的比较序列可能看起来像 true、true、true、false、false、false、true，这会破坏二分搜索逻辑。 

## 方法

 一个蛮力的想法是从起始位置向外走并查询每个单元格，直到我们观察到从一个色块到下一个色块的完全过渡，然后再返回，测量重复结构之间的距离。 这在概念上是正确的，因为磁带是周期性的，但它退化为$O(L)$查询，这在约束下是不可能的，因为$L$是无界的。 

关键的结构观察是，尽管磁带是周期性的，但每个单独的块在内部都是均匀的。 这意味着颜色变化的确切位置足以恢复$L$。 不必尝试全局推断周期性，定位块之间的两个连续边界点就足够了。 

一旦知道两个块之间的边界，到下一个边界的距离就是$L$。 困难在于在不假设全局单调性的情况下可靠地找到边界。 诀窍是将搜索锚定在单个参考位置周围，并明确定位到两侧最近的更改。 每一个最近的变化都可以在保证包含一次转换的区间内使用受控二分搜索来找到，因为我们构建区间时，一个端点位于已知的统一区域内，另一个端点位于不同的区域内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力扫描|$O(L)$查询 |$O(1)$| 太慢了 |
 | 边界定位+二分查找|$O(\log R)$查询 |$O(1)$| 已接受 |

 ## 算法演练

 1.固定任意参考位置，通常$x = 0$，并查询其颜色。 叫它$c$。 该点位于某个长度块内$L$，尽管我们不知道它的边界。 
2.向左搜索找到最近的位置$l$这样颜色在$l$不同于$c$。 该位置是左侧相邻块的第一个单元格。 
3.向右搜索找到最近的位置$r$这样颜色在$r$不同于$c$。 该位置是右侧相邻块的第一个单元格。 
4. 计算这两个边界相邻位置之间的距离并提取块长度为$L = r - l$。 自从$l$和$r$是同一块周围的连续过渡点，这种差异正好跨越一个完整的段。 
5、输出$L$作为测试用例的答案。 

唯一重要的部分是步骤 2 和 3。每个步骤都是在一个区间上使用二分搜索来实现，其中已知一个端点位于当前统一块内部，而另一个端点位于当前统一块外部。 这保证了在搜索间隔内只有一种颜色过渡，从而使谓词在该受限域内有效地单调。 

### 为什么它有效

 磁带中的每个块都是相同颜色的最大连续间隔，并且所有块共享相同的长度。 任何位置都恰好属于一个这样的区间。 当我们找到颜色与参考值不同的最接近左侧的位置时，我们正在识别该间隔的左边界。 同样的逻辑也适用于右边界。 

因为所有间隔的长度都相等，所以两个连续边界之间的距离是恒定的并且等于$L$。 该算法从不直接依赖于全局周期性； 它仅使用块是均匀的并且边界是单个过渡点的局部属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ask(x):
    print(f"? {x}")
    sys.stdout.flush()
    return input().strip()

def solve():
    c0 = ask(0)

    # find left boundary: first position to the left with different color
    lo, hi = -10**18, 0
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(mid) == c0:
            hi = mid
        else:
            lo = mid + 1
    left = lo

    # find right boundary: first position to the right with different color
    lo, hi = 0, 10**18
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(mid) == c0:
            lo = mid + 1
        else:
            hi = mid
    right = lo

    print(f"! {right - left}")
    sys.stdout.flush()

t = int(input())
for _ in range(t):
    solve()
```该代码通过以下方式使用交互式查询`ask`。 第一个查询锚定当前段的颜色。 每个二分搜索的结构使得间隔始终包含从参考颜色到相反颜色的一次过渡，从而使搜索能够安全地收敛。 

一个微妙的实现细节是在每次查询和最终答案后刷新，因为刷新失败会破坏与交互器的同步。 二分搜索边界被选择为大的固定限制，因为该问题保证磁带在两个方向上延伸得足够远。 

## 工作示例

 考虑一个假设的情况，其中$L = 3$位置 0 位于黑色段内。 

我们查询位置 0 并得到黑色。 

对于左边界搜索，算法会探索负位置，直到找到第一个白色单元格。 

| 步骤| 中查询 | 颜色(中) | 决定|
 | ---| ---| ---| ---|

 | 2 | -2 | 乙| 向左移动 |
 | 3 | -3 | 西 | 向右移动|

 最终它收敛到颜色不同于黑色的第一个位置，这是前一个白色块的开始。 

对于右边界搜索，适用类似的表：

 | 步骤| 中查询 | 颜色(中) | 决定|
 | ---| ---| ---| ---|
 | 1 | 5 | 西 | 向左移动 |

这些痕迹证实，尽管存在无限周期结构，但每次二分搜索都精确地隔离了一个转变点。

 ## 边缘情况

 一种边缘情况是参考位置正好位于两个线段之间的边界上。 在这种情况下，查询位置 0 已经揭示了块的开始而不是其内部。 然后左右搜索立即识别相邻的转换，并且计算出的距离仍然对应于$L$因为边界保持精确的间隔$L$分开。 

如果第一个二分搜索中点跨越多个段，则会出现另一种边缘情况。 受限搜索间隔确保谓词“与参考颜色匹配”在我们最终操作的间隔内恰好改变一次。 即使在早期探索过程中中间猜测位于其他部分，最终的收敛区间也会隔离单个边界，从而防止结果出现歧义。
