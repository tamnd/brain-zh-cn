 ## 解决方案
 ## 问题理解

 我们被要求建立一个长度的序列$n$，其中每个元素位于固定整数区间内$[l, r]$。 该序列不是任意的：连续元素的行为必须像受约束的行走一样，其中邻居之间的步长始终是素数，同时每个连续对必须生成序列中以前从未出现过的和。 

因此，我们有效地在有界线段中的整数上构造一条路径。 每一步从$a_i$到$a_{i+1}$仅当绝对差是素数时才允许，并且我们遍历的每条边都会产生“和标签”$a_i + a_{i+1}$它在整个路径上必须是全局唯一的。 

界限足够小，值永远不会超过 2000，并且$n$每个测试用例最多 1000 个，最多 1000 个测试用例。 这排除了每个测试用例的任何二次或更差的构造，除非它被大量修剪。 然而，只有 2000 的值范围是关键的结构约束：状态空间足够小，使得简单的贪婪构造或固定模式变得可行。 

一个天真的解释会尝试将其视为完整的图形路径构建问题：在整数上构建图形$[l, r]$，如果绝对差是素数，则连接边，然后尝试找到长度为的路径$n$对边缘标签具有唯一性约束。 这立即变得困难，因为“总和必须不同”条件将所有边全局耦合，而不是局部耦合。 

一种微妙的边缘情况是，间隔太小，甚至不允许一个有效的素数步骤。 例如，如果$l = r$，那么不可能有任何运动，并且$n > 1$使答案变得不可能。 另一种失败情况发生在$r - l$很小并且只有素数 2 可用，这迫使在单个奇偶校验类中移动并且可以快速捕获贪婪的构造。 

## 方法

 暴力尝试将使用 DFS 或回溯构建所有可能的序列，在每一步选择一个与素数不同的下一个值，并检查其对和是否已被使用。 每个状态将存储最后的值和一组使用的总和。 

每一步最多有大约$r - l \le 2000$候选者，但修剪很弱，因为唯一性约束取决于全球历史。 在最坏的情况下，这会呈指数增长：大致$O((r-l)^n)$，即使对于微小的情况也是完全不可行的$n$。 

关键的观察是我们根本不需要探索该图。 我们只需要一个有效的构造，而不是最优或最大路径。 这些约束在运动中是对称的和局部的，但仅在总和唯一性方面是全局的。 这表明我们应该避免以重复求和的方式重新访问值，而是强制执行一种结构，其中总和在设计上自动不同。 

保证不同总和的一个简单方法是强制每对连续值来自固定模式中不相交的“级别”，或者更强烈地确保每个转换都使用固定的步骤模式来防止重复求和。 由于素数包括 2，最稳定的结构是交替两个值，其差值是固定的，并且其和严格增加。 

这导致我们选择两个值的结构$x$和$y$这样$|x - y|$是素数，然后以某种模式重复它们。 总和是$x + y$反复或$x + x$,$x + y$,$y + x$,$y + y$取决于图案的选择。 然而，重复求和是被禁止的，所以唯一安全的方法是确保每条边都使用不同的对，如果我们从不重复使用无序对，这是最简单的。 这推动我们在一条线上进行类似路径的遍历，我们使用固定的素数步骤严格朝一个方向移动，确保总和严格增加。 

一个更清晰的见解是，如果我们选择一个主要步骤$p$并构建$a_i = l + (i-1)p$，我们得到恒定的差值，但重复求和，这违反了条件。 因此，我们通过增加偏移量来交替方向，以便每对总和是唯一的，同时仍然保持差异为质数。 

最终的建设性想法是使用固定的素数步长线性地遍历区间$p = 2$（最小的质数），但通过避免重新访问边缘来确保我们永远不会重用总和：我们构建一条简单的路径，该路径向前移动直到到达边界，然后根据需要通过移动起点来调整方向。 由于域很小，我们总能找到有效的起始偏移量和方向来产生单调和序列。 

在实践中，存在确定性构造：选择$p = 2$，从$l$，并构建一条从不重复使用任何边的锯齿形路径。 由于每条边都是唯一的并且遍历很简单，因此总和自动不同。

 ## 算法演练

 我们尽可能使用固定素数步长 2 构建一条简单路径，并调整方向以保持在边界内。 

1. 预先计算或假设 2 是质数，因此在边界内移动 ±2 始终有效。 这提供了在整个间隔内有效的稳定步骤。 
2. 从$l$作为第一个元素。 这将序列锚定在下边界，确保我们最大化向上移动的空间。 
3. 对于下一个位置，如果保持 ≤ r，则尝试移动 +2。 如果不是，则切换为移动 -2（如果保持 ≥ l）。 
4. 继续直到$n$元素产生。 这会在间隔内创建确定性行走。 
5. 如果在任何点上 +2 和 -2 都不可能，则间隔太小而无法支持长度$n$序列，所以输出-1。 

这样做的原因是每个步骤都有固定的幅度 2，即素数，并且序列永远不会重新访问某个值，因此每个相邻的和都位于两个不同的连续状态之间。 因为步行不会以相反的顺序重复使用边，也不会重复一对，所以总和会自动不同。 

### 为什么它有效

 该构造强制执行一个简单的不变量：每个连续对都是沿着整数线上的单个简单路径的唯一有序转换。 由于每个转换都是由固定的步幅值定义的，并且行走永远不会重新访问边缘，因此没有对$(a_i, a_{i+1})$重复。 重复求和需要重复一对或交换一对顺序，这两种情况都被有向行走结构所阻止。 因此两个约束同时成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, l, r = map(int, input().split())

        # If we only have one value, trivial case
        if l == r:
            if n == 1:
                print(l)
            else:
                print(-1)
            continue

        # Try to construct a simple alternating path using step 2
        # We will attempt to build a forward walk first
        cur = l
        res = [cur]

        direction = 2  # +2 initially

        possible = True

        for _ in range(n - 1):
            nxt = cur + direction

            if nxt < l or nxt > r:
                # flip direction
                direction *= -1
                nxt = cur + direction

            if nxt < l or nxt > r:
                possible = False
                break

            res.append(nxt)
            cur = nxt

        if not possible:
            print(-1)
        else:
            print(*res)

if __name__ == "__main__":
    solve()
```该代码从以下位置开始构建一条单链：$l$并反复尝试移动$+2$。 当它离开间隔时，它会翻转方向并移动$-2$。 这可确保所有差值恰好为 2，从而满足首要条件。 

边界处理至关重要：如果在翻转方向后没有进行第二次检查，当间隔太小时，我们仍然可以尝试出界。 该构造依赖于这样一个事实：在足够大的间隔内，对于所需的长度始终存在±2 步距。

 ## 边缘情况

 当$l = r$，唯一可能的数组所有元素都相等。 如果$n = 1$，这是有效的并返回单个值。 如果$n > 1$，不可能有素差，因此算法在尝试任何构造之前立即正确输出 -1。 

当间隔很小时，例如$l = 2, r = 3$，唯一可能的差异是 1，它不是素数。 该算法尝试移动±2，立即找到两个无效方向，并返回-1，匹配不可能的情况。 

当间隔较大时，±2 步行会继续进行，而不会触及许多步的边界，从而产生全长序列。 确定性步进保证不需要回溯，因此序列可以干净地构建，直到$n$元素产生。
