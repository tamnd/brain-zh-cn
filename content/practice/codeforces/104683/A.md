 ## 解决方案
 ## 问题理解

 我们得到了一系列编号从 1 到 n 的卡片。 对于每个查询，有人选择一个值 m 并要求所有可被 m 整除的卡号的总和。 换句话说，我们对 1 到 n 范围内出现的每个 m 倍数求和。 

因此，对于固定查询，任务是计算 m + 2m + 3m + …，只要该项不超过 n。 这只是由范围内 m 的倍数形成的算术级数之和。 

输入最多包含 100,000 个独立查询，每个 n 可以大到 1e9。 这种组合立即排除了每个查询迭代最多 n 个数字的任何方法。 当 n 很大且 t 也很大时，即使逐一迭代倍数也变得不可能，因为最坏的情况将涉及 1e14 次运算。 

主要的边缘情况来自于对倍数范围的误解。 幼稚的实现可能会尝试从 1 循环到 n 并检查整除性，这显然是不可行的。 另一个微妙的问题是溢出或精度，如果有人试图累加而没有意识到封闭形式的存在，尽管Python避免了溢出，但它仍然会TLE。 

一个小例子清楚地展示了结构。 如果n = 12且m = 2，则有效卡为2、4、6、8、10、12，它们的和为42。如果n = 1且m = 1，则答案为1，因为仅包含一个数字。 

## 方法

 蛮力的想法很简单。 对于每个查询，我们扫描从 1 到 n 的所有整数，并将那些可被 m 整除的整数相加。 这是正确的，因为它直接遵循定义。 然而，它每个查询执行n次迭代，当t和n都很大时，在最坏的情况下会导致1e14次操作，这远远超出了限制。 

关键的观察结果是，对总和有贡献的数字恰好是 m 的倍数：m、2m、3m 等，直到最大 k，使得 km ≤ n。 此类项的数量为floor(n / m)。 一旦我们确定了这一点，问题就简化为对按 m 缩放的前 k 个自然数求和。 

所以总和变成：

 m (1 + 2 + … + k)，其中 k = 下限 (n / m)。 

前k个整数之和为k(k + 1) / 2，所以最终结果为：

 m * k * (k + 1) / 2。 

这将每个查询减少为常数时间算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个查询 O(n) | O(1) | O(1) | 太慢了 |
 | 最佳| 每个查询 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取 n 和 m 进行查询。 这些定义了卡片的范围和有效倍数的步长。 
2. 计算 k = n // m。 这给出了 [1, n] 内适合的 m 倍数的数量，因为每个有效项的形式都是 i·m。 
3. 使用 k * (k + 1) // 2 计算从 1 到 k 的整数之和。这表示倍数的索引位置。 
4. 将该结果乘以 m，以从索引缩减为实际卡值。 
5. 输出查询结果。 

### 为什么它有效

 和中的每个有效数字都可以唯一地写为 i·m，其中 i 的范围从 1 到 k = Floor(n / m)。 这种映射是一对一的，因此对卡值求和相当于对连续整数的缩放序列求和。 由于该序列是具有恒定差值的算术序列，因此将其替换为其封闭形式可以保留所有有效输入的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        k = n // m
        ans = m * k * (k + 1) // 2
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于将问题转换为计算倍数并应用算术级数公式。 整数除法 n // m 至关重要，因为它决定了有多少个大小为 m 的完整步长适合该范围。 乘以 m 必须在计算三角数之后进行，以避免中间步骤中不必要的增长，尽管 Python 无论如何都会处理大整数。 

一个常见的错误是颠倒顺序或尝试在循环中重复计算 m * i。 另一个微妙的问题是忘记当 m > n 时 k 为零，但整数除法自然可以正确处理这种情况。

 ## 边缘情况

 当 m > n 时，k 由于整数除法而变为零。 例如，输入 n = 5、m = 10 生成 k = 0，公式计算结果为 0 * 1 / 2 * m = 0。这与在该范围内没有卡号可以被 m 整除的事实相符。 

当m等于n时，k变为1，结果简化为m * 1 = m，正确捕获单个有效元素。 

当 m = 1 时，包含从 1 到 n 的每个数字。 公式变为n(n + 1)/2，与前n个整数的标准和相匹配，确认通式正确退化为众所周知的情况。
