 ## 解决方案
 ## 问题理解

 我们被要求计算有多少个有效的长度序列$N$可以形成，其中每个元素都是介于$1$和$K$。 限制是针对相邻元素的：任意两个邻居必须是互质的。 唯一的例外是该值$1$可以坐在另一个人旁边$1$，因为该语句仅在这种情况下明确允许相等。 

因此，该任务是序列上的约束计数问题，其中约束是局部的并且仅取决于相邻值对。 这立即暗示了一种状态转换观点：每个位置仅取决于前一个值，而不取决于整个前缀。 

这些限制将我们推入一个非常具体的制度。 高度限制$K \le 66$很小，这表明我们可以负担得起$O(K^2)$甚至$O(K^3)$预处理。 长度$N \le 10^{18}$是巨大的，这排除了任何线性甚至对数的 N DP，无需求幂技巧。 这种组合强烈表明在大小的状态空间上的线性递归$K$，可以使用矩阵求幂来加速。 

一个基于序列的朴素 DP 会跟踪最后一个值并逐步扩展，给出$O(NK)$，当$N$达到$10^{18}$。 

微妙的边缘情况是价值$1$。 它是唯一可以相邻重复的数字。 例如，如果$K=2$，有效的转换包括$1 \to 1$,$1 \to 2$， 和$2 \to 1$，但不是$2 \to 2$。 任何严格对待“coprime”而不处理此异常的解决方案都将错误地禁止$1,1$。 

另一个不明显的问题是互质是对称的，因此转换形成无向的相容关系。 然而，仅靠对称性并不能简化计数。 它仅有助于构建过渡结构。 

## 方法

 直接方法显式地构建序列。 我们定义一个DP，其中$dp[i][x]$是长度有效序列的数量$i$以价值结尾$x$。 转换很简单：对于每个先前的值$y$， 如果$\gcd(x, y) = 1$或者$(x = y = 1)$，我们添加$dp[i-1][y]$到$dp[i][x]$。 这可以正确地对约束进行建模，因为每个有效序列都是由其最后一个元素及其前缀唯一确定的。 

这个DP费用$O(NK^2)$每层检查所有值对以来的时间。 和$N$最多$10^{18}$，这是不可能的。 

关键的观察是转换不依赖于位置$i$。 相同的允许邻接规则适用于每一步，因此 DP 更新是大小向量上的固定线性变换$K$。 这使我们能够将过渡表示为$K \times K$矩阵$T$， 在哪里$T[a][b] = 1$如果值$b$可以遵循价值$a$。 

那么DP演化就变成了重复乘法$T$。 后$N-1$步骤，状态向量为$T^{N-1} \cdot v$， 在哪里$v$是初始分布（所有长度为 1 的序列都是有效的，所以$v[x] = 1$）。 

这将问题简化为最多大小的矩阵的快速求幂$66 \times 66$，这是可行的$O(K^3 \log N)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力DP |$O(NK^2)$|$O(K)$| 太慢了|
 | 矩阵求幂|$O(K^3 \log N)$|$O(K^2)$| 已接受 |

 ## 算法演练

 我们解释每个值$1$到$K$作为一个国家。 有效的序列是有向图中的一次行走，其中一条边$a \to b$存在如果$a$可以跟随$b$。 

1.构建转移矩阵$T$尺寸的$K \times K$。 对于每对$(a, b)$， 放$T[a][b] = 1$如果$\gcd(a, b) = 1$，或者如果$a = b = 1$。 否则将其设置为$0$。 这将所有有效的邻接规则编码在一个结构中。 
2. 初始化一个向量$v$长度$K$，其中每个条目都是$1$。 这对应于长度为 1 的序列，因为允许任何单一高度。 
3. 计算矩阵幂$T^{N-1}$使用二进制求幂。 每次乘法将两个转换步骤合二为一，因此重复平方可减少指数$N$到$O(\log N)$乘法。 
4. 将结果矩阵乘以初始向量$v$，产生最终向量$u$。 每个$u[x]$计算长度的序列$N$以价值结尾$x$。 
5. 对所有条目求和$u$以获得有效序列的总数。 

乘法起作用的原因是每个矩阵条目编码一个状态可以在一步中转换到另一个状态的多种方式。 组合矩阵与序列中的连接步骤完全对应，保留所有可能路径的计数。 

正确性取决于以下事实：每个有效序列恰好对应于该状态图中的一条路径，并且每条路径通过矩阵乘法被精确地计数一次。 不会遗漏任何序列，因为每个有效邻接都被编码，并且不会计算无效序列，因为禁止的转换具有零权重。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(A, B):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        for k in range(n):
            if Ai[k]:
                aik = Ai[k]
                Bk = B[k]
                for j in range(n):
                    if Bk[j]:
                        res[i][j] = (res[i][j] + aik * Bk[j]) % MOD
    return res

def mat_pow(A, e):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1

    while e > 0:
        if e & 1:
            res = mat_mul(res, A)
        A = mat_mul(A, A)
        e >>= 1
    return res

def solve():
    K, N = map(int, input().split())

    if N == 1:
        print(K % MOD)
        return

    T = [[0] * K for _ in range(K)]

    for a in range(K):
        for b in range(K):
            if a == 0 and b == 0:
                T[a][b] = 1
            elif __import__("math").gcd(a + 1, b + 1) == 1:
                T[a][b] = 1

    P = mat_pow(T, N - 1)

    v = [1] * K
    ans = 0

    for i in range(K):
        for j in range(K):
            ans = (ans + P[i][j] * v[j]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该实现使用 gcd 检查显式构建转换矩阵，并针对该对进行了特殊情况修复$(1,1)$，这是索引$(0,0)$。 指数是$N-1$因为第一个元素不需要转换。 乘法是通过跳过零条目以稀疏感知方式编写的，这很重要，因为大多数 66 以内的整数对不是互质的。 

一个常见的陷阱是忘记索引已移位：矩阵使用$0$基于索引，而值是$1$-基于。 另一种是处理不当$N=1$，否则矩阵功率逻辑将错误地减少到零转换。 

## 工作示例

 ### 示例 1

 输入：```
2 4
```我们建立国家$\{1,2\}$。 有效的转换是：$1 \to 1, 1 \to 2, 2 \to 1$。 

| 步骤| DP 值 1 | DP 值 2 |
 | --- | --- | --- |
 | 1 | 1 | 1 |
 | 2 | 2 | 1 |
 | 3 | 3 | 2 |
 | 4 | 5 | 3 |

 最终答案是$8$。 

此跟踪显示循环如何累积路径：值$2$更具限制性，但仍然通过有效的转换进行传播$1$。 

### 示例 2

 输入：```
3 3
```值为$\{1,2,3\}$。 禁止邻接仅$2 \leftrightarrow 2$,$3 \leftrightarrow 3$， 和$2 \leftrightarrow 3$由于 gcd(2,3)=1 实际上是有效的，因此仅仔细控制除 (1,1) 之外的相等对。 

| 步骤| DP[1] | DP[2] | DP[3] |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 |
 | 2 | 3 | 1 | 1 |
 | 3 | 5 | 2 | 2 |

 最终答案是$9$。 

这个例子证实了互质性的对称性并不意味着均匀跃迁； 不同的值具有不同的阶数，矩阵求幂自然地捕获了这些阶数。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(K^3 \log N)$| 每个矩阵乘法都是三次$K$, 对指数上的二进制求幂重复$N$|
 | 空间|$O(K^2)$| 过渡矩阵和临时矩阵的存储 |

import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    K, N = map(int, input().split())

    if N == 1:
        return str(K % MOD)

    def mat_mul(A, B):
        n = len(A)
        res = [[0]*n for _ in range(n)]
        for i in range(n):
            for k in range(n):
                if A[i][k]:
                    for j in range(n):
                        res[i][j] = (res[i][j] + A[i][k]*B[k][j]) % MOD
        return res

    def mat_pow(A, e):
        n = len(A)
        res = [[0]*n for _ in range(n)]
        for i in range(n):
            res[i][i] = 1
        while e:
            if e & 1:
                res = mat_mul(res, A)
            A = mat_mul(A, A)
            e >>= 1
        return res

    T = [[0]*K for _ in range(K)]
    for i in range(K):
        for j in range(K):
            if i == 0 and j == 0:
                T[i][j] = 1
            elif math.gcd(i+1, j+1) == 1:
                T[i][j] = 1

    P = mat_pow(T, N-1)

    v = [1]*K
    ans = 0
    for i in range(K):
        for j in range(K):
            ans = (ans + P[i][j]*v[j]) % MOD

    return str(ans)

 ## 边缘情况

 的$N=1$case 绕过所有转换，因为没有应用邻接约束。 该算法显式返回$K$，因为每个值都形成一个有效的长度为 1 的序列。 任何矩阵幂实现都必须对此进行特殊处理或仔细处理指数零语义。 

这$K=1$案例简化为单一状态$1$，它本身始终有效。 转移矩阵是$[1]$，任何指数都保持不变，所以答案总是$1$，与公式一致。 

特别的一对$(1,1)$即使基于 gcd 的逻辑已经允许，也会通过强制其转换为 1 来处理； 这种冗余是无害的，但可以确保 gcd 逻辑被修改时的正确性。 一个不小心完全不允许相等的粗心实现会错误地消除所有重复序列，当$K=1$或者当 1 的长游程主导最佳路径时。
