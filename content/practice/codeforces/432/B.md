 ## 解决方案
 ## 问题理解

 我们被要求模拟一场足球比赛`n`球队，每支球队都有不同颜色的主场球衣和客场球衣。 每支球队都会进行主客场比赛。 默认情况下，主队穿主场球衣，客队穿客场球衣。 然而，如果颜色匹配，客队就会换上主场球衣。 

输入提供`n`其次是`n`代表每支球队主客场球衣颜色的整数对。 对于每个球队（按顺序），输出应该是其主场球衣和客场球衣所参加的比赛数量。 

约束条件允许`n`最多`10^5`颜色值高达`10^5`。 对一切的简单模拟`n*(n-1)`比赛结果在左右`10^10`在最坏的情况下，操作速度太慢了。 我们需要一个大致有效的解决方案`O(n)`或者`O(n log n)`时间。 

当球队的主场颜色重叠时，就会出现一个微妙的问题。 例如，如果球队 1 有主场颜色 1 和客场颜色 2，而球队 2 有主场颜色 2 和客场颜色 1，则每支球队的客场球衣都会与一些主场球衣发生冲突。 只计算“主场与客场”而不预先计算颜色频率的粗心方法会错误计算球队需要更换客场球衣的频率。 

## 方法

 暴力方法将迭代所有游戏。 对于每对`(i, j)`, 检查是否有团队`i`主场颜色等于球队颜色`j`是远离的颜色。 如果是这样，客队将穿着主场球衣。 计算两队的每次出现情况。 这种方法是正确的，但执行`n*(n-1)`比较，即`O(n^2)`。 为了`n = 10^5`，这需要 100 亿次操作，并且会超时。 

更快解决方案的关键在于我们只关心每个客场球衣的冲突总数。 我们可以针对每种颜色预先计算有多少支球队将该颜色作为主场球衣。 那么对于团队来说`i`，其客场球衣会与相同颜色的主场球衣发生冲突。 由于各队比赛`(n-1)`在客场比赛中，我们可以将碰撞次数添加到主场球衣计数中，并从客场球衣计数中减去，而无需模拟每场比赛。 这将复杂性降低到`O(n)`使用简单的计数数组或字典。 

暴力破解之所以有效，是因为它会单独检查每个匹配项，但在以下情况下会失败：`n`很大。 我们只需要颜色频率这一观察结果让我们可以将问题简化为团队的一次处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 最佳 | O(n) | O(最大颜色) | 已接受 |

 ## 算法演练

 1.初始化字典或数组`home_count`追踪有多少支球队将每种颜色作为主场球衣。 迭代所有团队并增量`home_count[color]`每个球队的主场颜色。 
2. 对于每个团队，初始化`home_games`作为`n-1`因为每支球队都在比赛`n-1`主场比赛。 初始化`away_games`作为`n-1`因为每个团队也有`n-1`客场比赛。 
3、球队客场比赛`i`, 检查有多少支主队与以下颜色相同`i`的客场套件。 将此计数添加到`home_games`因为这些游戏迫使团队`i`穿上主场球衣。 减去相同的计数`away_games`。 
4. 输出`home_games`和`away_games`按输入顺序为每个团队。 

为什么有效：每个团队都参加比赛`(n-1)`主场比赛和`(n-1)`客场比赛。 每次客场球衣冲突都会在另一支球队的主场球衣与客场颜色相匹配时发生。 计算主场颜色的频率可确保我们捕获所有冲突，而无需模拟个别匹配。 这个不变量保证了所有团队的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
teams = []
home_count = dict()

for _ in range(n):
    x, y = map(int, input().split())
    teams.append((x, y))
    home_count[x] = home_count.get(x, 0) + 1

for x, y in teams:
    home_games = n - 1 + home_count.get(y, 0)
    away_games = n - 1 - home_count.get(y, 0)
    print(home_games, away_games)
```我们首先构建一个字典来计算每种主色的出现次数。 然后，对于每支球队，我们通过查找有多少支球队共享客场颜色来计算因客场球衣碰撞而导致的额外主场比赛。 使用`dict.get(y, 0)`处理没有球队作为主场球衣的颜色。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 我们迭代一次来构建`home_count`一次计算输出 |
 | 空间| O(最大颜色) | 我们存储每种可能颜色的计数，最多 10^5 |

 这是有效的`n ≤ 10^5`并且可以在时间和内存限制内轻松适应。

 ## 边缘情况

 如果每支球队的客场球衣与主场球衣发生冲突，算法都会正确计数。 例如，输入：```
2
1 2
2 1
```1队主场踢了1场比赛，其客场球衣与2队的主场冲突，因此再次穿着主场球衣，总共2场主场比赛，0场客场比赛。 团队 2 具有对称行为。 这`home_count`字典确保每个客场球衣的所有冲突都精确计算一次，避免重复计算或遗漏任何冲突。 这适用于较大的碰撞链和不寻常的颜色分配。
