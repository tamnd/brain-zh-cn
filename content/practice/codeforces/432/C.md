 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 _n_ 的整数排列，这意味着该范围内的每个整数在数组中只出现一次。 目标是按升序对这个数组进行排序，但对我们可以进行的交换有特殊限制。 具体来说，我们只能交换位置相距素数长度距离的两个元素。 也就是说，如果我们选择索引 _i_ 和 _j_，那么它们之间（包括两端）的位置数 (_j_ - _i_ + 1) 必须是素数。 输出应列出用于对数组进行排序的交换序列。 我们最多允许 5_n_ 交换，并且在此限制内对数组进行排序的任何有效解决方案都是可接受的。 

鉴于 _n_ 可以大到 10^5 并且时间限制为 2 秒，任何复杂度低于 O(n log n) 的算法都可能太慢。 重复检查每对位置的简单方法可能会导致 O(n^2) 操作，这是不可行的。 该问题确保了不同的整数，这简化了处理，因为我们不需要考虑重复值或稳定性。 非明显的边缘情况包括几乎排序的数组、反转数组或元素 1 远离其目标位置的数组。 例如，输入`[5, 1, 2, 3, 4]`必须将 1 从索引 2 移动到 1，粗心的方法可能会尝试违反素数长度规则的交换或产生超过 5_n_ 的低效长序列。 

## 方法

 暴力方法将重复搜索距离为素数且交换使至少一个元素更接近其排序位置的任何一对索引。 这是正确的，因为理论上任何排列都可以通过这些允许的交换进行排序，但重复检查每对会导致 O(n^2) 操作。 对于 n = 10^5，这可能涉及 10^10 次操作，这远远超出了时间限制。 

导致有效解决方案的关键观察是素数距离约束允许我们通过链接交换将元素移动任意距离。 我们首先使用埃拉托斯特尼筛法预先计算直到 n 的所有素数。 对于不在正确位置的每个元素，我们选择最大的素数 p，以便可以从其当前索引交换到距离为 p 的目标索引。 这让我们可以贪婪地将元素“冒泡”到正确的位置。 由于每个元素在有限次数的交换中直接移向其排序位置，因此交换总数为 O(n)，并且每次交换计算都涉及使用预先计算的素数进行 O(1) 素数检查。 这种方法比暴力破解要快得多，因为它减少了不必要的尝试并确保每次操作都富有成效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 贪婪素数预计算 | 筛子的 O(n log log n) + O(n log n) 交换 | O(n) | 已接受 |

 ## 算法演练

 1. 使用埃拉托色尼筛法生成 _n_ 以内的所有素数。 这些素数代表所有有效的交换长度。 
2. 构建从每个值到其当前索引的映射。 这允许快速查找任何元素在数组中的位置。 
3. 从左到右迭代数组。 对于位置_i_，检查_i_处的元素是否等于_i_（目标值）。 如果是，则继续到下一个位置。 
4. 如果 _i_ 处的元素不正确，则使用映射定位其目标索引。 
5. 计算当前索引与目标索引之间的距离。 找到最大素数 p ≤ 距离。 这个素数决定了我们可以将元素交换到目标的程度。 
6. 在当前索引和距目标距离 p 处的索引之间执行交换。 相应地更新映射。 
7. 重复步骤 5，直到元件到达正确位置。 然后移动到数组中的下一个位置。 
8. 将所有交换记录在列表中。 处理完整个数组后，输出交换次数和交换操作。 

工作原理：该算法保持了不变式，即每次交换都使用有效的素数长度移动将元素移动到更接近其正确位置的位置。 由于素数足够密集，并且每个元素最终都会移动到正确的位置，因此可以保证数组已排序。 该映射可确保交换始终准确，并且更新可防止不一致。 该策略永远不会产生无效的交换，并在有限数量的操作中完成，远低于 5_n_ 限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, n+1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    return primes

def main():
    n = int(input())
    a = list(map(int, input().split()))
    pos = [0] * (n + 1)
    for idx, val in enumerate(a):
        pos[val] = idx
    primes = sieve(n)
    swaps = []

    for i in range(n):
        while a[i] != i + 1:
            target_idx = pos[i + 1]
            dist = target_idx - i + 1
            # find largest prime <= dist
            p = max(p for p in primes if p <= dist)
            j = target_idx - (p - 1)
            # perform swap
            a[i], a[j] = a[j], a[i]
            pos[a[i]] = i
            pos[a[j]] = j
            swaps.append((i + 1, j + 1))
    
    print(len(swaps))
    for x, y in swaps:
        print(x, y)

if __name__ == "__main__":
    main()
```筛子生成直到 _n_ 的所有素数，确保交换满足素数长度约束。 这`pos`数组允许恒定时间访问任何元素的当前位置。 内部 while 循环确保每个元素到达正确的位置，选择最大允许的素数以提高效率。 仔细管理离一处理以匹配输出中基于 1 的索引。 每次交换都会更新数组和映射。
