 ## 解决方案
 ## 问题理解

 票证是一系列`n`基数中的数字`k`，所以每个位置都包含一个值`0`到`k - 1`。 

让总数字和模`k`是$$S = a_1 + a_2 + \dots + a_n \pmod k.$$如果存在某个位置，其数字等于所有剩余数字模数之和，则该票是幸运的`k`。 

如果选择的数字是`a_i`，条件变为$$a_i \equiv S - a_i \pmod k,$$这相当于$$2a_i \equiv S \pmod k.$$所以对于固定票，运气只取决于总金额`S`以及某个数字是否是同余的解$$2x \equiv S \pmod k.$$这些约束完全改变了问题的性质。 长度`n`可以大到$10^{18}$，所以任何一个一一处理位置的算法都是不可能的。 甚至$O(n)$太慢了。 基地`k`至多是`2000`，这表明任何依赖`k`负担得起，但依赖`n`必须是对数。 

第一个陷阱是当同余时的情况$2x \equiv S\pmod k$没有解决办法。 例如，与`k = 4`和`S = 1`，没有满足的数字`2x ≡ 1 (mod 4)`。 每张总金额为奇数的彩票都自动算运气。 

第二个陷阱是当`k`是偶数，同余可以有两个解。 例如，与`k = 6`和`S = 2`,$$2x \equiv 2 \pmod 6$$有解决方案`x = 1`和`x = 4`。 假定唯一的禁止数字的计数参数将默默地过度计数。 

第三个陷阱是巨大的价值`n`。 表达式如`(k - 1)^n`必须以模计算`m`使用快速求幂。 

## 方法

 暴力解决方案将生成所有$k^n$票，计算总和模`k`，并检查某个位置是否满足$2a_i \equiv S$。 这是正确的，因为它直接实现了定义，但它立即变得无用。 即使是为了`k = 10`和`n = 20`， 有$10^{20}$门票。 

关键的观察结果是，条件仅取决于总和模`k`。 对于固定残基`S`，定义集合$$U_S = \{x \in \mathbb Z_k : 2x \equiv S \pmod k\}.$$当每一个数字都避开时，票就是不吉利的`U_S`， 在哪里`S`是机票的总金额。 

这就把问题变成了循环群上的计数问题$\mathbb Z_k$。 一旦我们表达“总和等于`S`“通过字符总和，巨大的价值`n`变得无害，因为每个贡献都表现为一个特征值`n`次幂。 

令人惊讶的是，在傅里叶展开之后，几乎所有的特征贡献都消失了。 最终答案崩溃为一个封闭公式，仅涉及`k`,`k - 1`,`k - 2`，和一个 gcd。

 | 最佳 |$O(\log n)$|$O(1)$| 已接受 |

 ## 算法演练

 ### 奇数`k`什么时候`k`是奇数，`2`是可逆模数`k`。 

对于每一个残留物`S`，方程$$2x \equiv S \pmod k$$仅有一个解，称之为`cS`， 在哪里`c = 2^{-1} (mod k)`。 

一张总金额不吉利的彩票`S`是一个数字永远不相等的序列`cS`。 

使用傅立叶反演$\mathbb Z_k$, 倒霉票数与总金额`S`是$$A_S = \frac1k \sum_r \chi_r(-S) \left( k\delta_{r,0} - \chi_r(cS) \right)^n .$$对所有残差求和`S`，除了那些令人满意的字符外，每个字符都消失了$$(n-2)r \equiv 0 \pmod k.$$如果$$d = \gcd(n-2,k),$$正是有`d`这样的人物，其中之一就是琐碎人物。 

简化后，$$F=(k-1)^n + (d-1)(-1)^n,$$在哪里`F`是倒霉票的数量。 

所需答案是$$k^n - F.$$＃＃＃ 甚至`k`让$$K=\frac{k}{2}.$$如果`S`是奇数，同余$2x \equiv S\pmod k$无解，因此每张总金额为奇数的彩票都是不吉利的。 

总和为固定残数的序列数等于$k^{n-1}$，因此所有奇数和都有贡献$$\frac{k}{2}\cdot k^{n-1} = \frac{k^n}{2}.$$现在考虑偶数，`S = 2y`。 

该同余式恰好有两个解：$$y,\qquad y+K.$$重复傅里叶计算，只有偶数字符才能幸存。 让$$d=\gcd(n-2,K).$$所有偶数总和的总贡献变为$$\frac{(k-2)^n + (d-1)(-2)^n}{2}.$$结合奇数和和偶数和部分，$$F = \frac{k^n}{2} + \frac{(k-2)^n + (d-1)(-2)^n}{2}.$$再次，答案是$$k^n - F.$$### 为什么它有效

 傅里叶变换对循环群上的计数问题进行对角化$\mathbb Z_k$。 对于固定的总残差`S`，限制“每个数字都避免解决方案集$2x \equiv S$" 成为字符和的乘积。将该字符和提高到`n`选择的次方帐户`n`独立的数字。 

对所有可能的残差求和后`S`，字符的正交性迫使几乎每个频率都抵消。 幸存的频率正是那些满足简单同余的频率，涉及`n - 2`，这解释了 gcd 术语的出现。 由于每张不幸的彩票都会被计算一次，而每张幸运的彩票都会被排除在外，因此从彩票总数中减去即可得到正确的答案。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

n, k, m = map(int, input().split())

total = pow(k, n, m)

if k % 2 == 1:
    d = gcd(n - 2, k)

    unlucky = pow(k - 1, n, m)

    term = (d - 1) % m
    if n % 2:
        term = (-term) % m

    unlucky = (unlucky + term) % m

else:
    K = k // 2
    d = gcd(n - 2, K)

    inv2 = pow(2, m - 2, m)

    part1 = total

    part2 = pow(k - 2, n, m)

    extra = (d - 1) % m
    extra = extra * pow(2, n, m) % m
    if n % 2:
        extra = (-extra) % m

    unlucky = (part1 + part2 + extra) % m
    unlucky = unlucky * inv2 % m

answer = (total - unlucky) % m
print(answer)
```计算遵循上面推导的公式。 

对于奇数`k`，唯一重要的量是$$d=\gcd(n-2,k).$$期限$(-1)^n$通过否定来处理`n`很奇怪。 

对于甚至`k`，除以二必须进行模运算`m`。 自从`m`保证是素数并且大于`2`，模逆`2`存在并且计算为$$2^{m-2}\pmod m.$$表达式$(-2)^n$被实现为$2^n$连同由奇偶校验确定的符号`n`。 

所有幂运算都使用 Python 的内置模幂运算，它运行在$O(\log n)$。

from math import gcd

def solve():
    input = sys.stdin.readline
    n, k, m = map(int, input().split())

    total = pow(k, n, m)

    if k % 2:
        d = gcd(n - 2, k)

        unlucky = pow(k - 1, n, m)

        term = (d - 1) % m
        if n % 2:
            term = (-term) % m

        unlucky = (unlucky + term) % m
    else:
        K = k // 2
        d = gcd(n - 2, K)

        inv2 = pow(2, m - 2, m)

        part2 = pow(k - 2, n, m)

        extra = (d - 1) % m
        extra = extra * pow(2, n, m) % m
        if n % 2:
            extra = (-extra) % m

        unlucky = (total + part2 + extra) % m
        unlucky = unlucky * inv2 % m

    print((total - unlucky) % m)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue().strip()

 ## 边缘情况

 ### 基地`k = 1`输入：```
1000000000000000000 1 1000000007
```只有一位数字值，`0`，而且只有一张票。 其总和为`0`，并且每个位置都满足$$2\cdot 0 \equiv 0.$$奇怪的是——`k`公式给出$$d=\gcd(n-2,1)=1,$$

$$F=(1-1)^n+0=0,$$所以答案是`1`。 

### 总和为奇数时`k`是偶数

 输入：```
3 4 1000000007
```任何总金额为`1`或者`3`模数`4`永远不会幸运，因为$$2x \equiv 1 \pmod 4$$和$$2x \equiv 3 \pmod 4$$没有解决办法。 

该公式明确计算项内的所有奇数和序列$$\frac{k^n}{2}.$$实现过程中不需要什么特别的。 

### 相同总和的两个有效数字

 输入：```
3 6 1000000007
```对于总金额`2`, 一致性$$2x \equiv 2 \pmod 6$$有解决方案`1`和`4`。 

仅禁止一位数字的天真的推导是错误的。 偶数-`k`公式正确地删除了两位数字，这就是为什么`(k - 2)^n`出现而不是`(k - 1)^n`。 

### 案例`n = 2`输入：```
2 5 1000000007
```这里$$d=\gcd(0,5)=5.$$这是最大可能的 gcd 贡献，并且正是许多傅里叶频率幸存的情况。 该公式在没有任何特殊处理的情况下仍然有效，因为`gcd(0, x) = x`已经正确定义。
