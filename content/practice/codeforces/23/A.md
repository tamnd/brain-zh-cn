 ## 解决方案
 ## 问题理解

 给定一串小写字母，任务是找到该字符串中至少出现两次的最长子串的长度。 重复出现的情况可能会重叠。 输入是最多 100 个字符的单个字符串。 输出是一个整数，表示此类重复子字符串的最大长度。 

因为字符串长度很小，最多 100，所以我们可以负担字符串长度的二次方的算法。 这使得比较所有子串对的方法变得可行。 该问题的边缘情况是没有子字符串重复、所有字符都相同或子字符串完全重叠的情况。 例如，字符串`aaaa`最长重复子串的长度为 3 (`aaa`)，可能会重叠：位置 0-2 和 1-3。 如果仅考虑非重叠位置，则简单的方法可能无法正确处理这种重叠。 

另一个微妙的情况是包含完全唯一字母的字符串，例如`abcd`。 在这里，正确答案是`0`因为没有子字符串重复，甚至单个字母也没有。 

## 方法

 最简单的方法是蛮力。 我们可以生成输入的所有可能的子字符串并计算每个子字符串出现的次数。 对于每个子字符串，我们在字符串上滑动一个窗口并比较相同长度的子字符串。 如果我们找到一个至少出现两次的子字符串，我们记录它的长度并更新最大值。 此方法是正确的，因为它显式地检查每个候选子串，但在最坏的情况下其复杂度为 O(n3)：生成所有子串的复杂度为 O(n2)，检查出现情况的复杂度为 O(n)。 对于 n = 100，这大约是 1,000,000 次操作，考虑到现代 CPU 速度，这是可以接受的，但速度较慢，可以进行优化。 

关键的见解是我们不需要单独检查每个子字符串。 相反，我们可以按降序迭代可能的长度，并检查该长度的任何子字符串是否重复。 一旦我们找到合适的长度，我们就可以停下来。 使用集合或字典来跟踪看到的子字符串，可以在 O(n²) 时间内检查所有固定长度的子字符串。 在最坏的情况下，这会将整体复杂度降低到 O(n³)，但实际上，速度更快，因为一旦找到最长的重复子串，我们就会提前停止。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 接受 n ≤ 100 |
 | 基于长度的集检查 | O(n³) 最坏情况，平均更快 | O(n²) | 已接受，实施起来更简单 |

 ## 算法演练

 1.确定输入字符串的长度`n`。 初始化一个变量`max_len`为 0。这将存储迄今为止找到的最长重复子串长度。 
2. 循环候选子串长度`l`从 1 到`n-1`。 我们不需要检查长度`n`因为长度的子串`n`只能出现一次。 
3. 对于每个长度`l`,初始化一个空集`seen`。 这将跟踪长度的所有子字符串`l`我们相遇。 
4. 滑动一个长度的窗口`l`从索引 0 到字符串`n-l`。 提取每个位置的子字符串。 
5. 如果子字符串已经存在`seen`， 更新`max_len`到`l`如果`l`大于当前`max_len`。 打破这个内部循环，因为我们已经找到了这个长度的重复子串。 
6. 如果子串不在`seen`，将其添加到集合中并继续。 
7.检查完所有长度后，输出`max_len`。 

为什么它有效：该算法保持一个不变量`max_len`是已找到的重复子串的最大长度。 通过首先检查较短的子字符串，我们确保不会遗漏有效的较长子字符串。 使用集合可以保证有效地检测到重复的子字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)
max_len = 0

for l in range(1, n):
    seen = set()
    for i in range(n - l + 1):
        sub = s[i:i+l]
        if sub in seen:
            max_len = l
            break
        seen.add(sub)

print(max_len)
```该解决方案读取字符串并迭代可能的子字符串长度。 内部循环使用切片构造每个子字符串。 使用集合可确保每次检查平均 O(1) 时间检测到重复项。 一旦发现重复的子字符串就中断内部循环可以避免不必要的工作。

 这里最长的重复子串是`aaa`出现重叠的情况，给出`max_len = 3`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 最坏情况 O(n3) | 长度上的外循环 O(n)，位置上的内循环 O(n)，子串切片 O(n) |

 假设 n ≤ 100，该解决方案最多执行 1,000,000 次子字符串检查，并且完全符合 2 秒的限制。 内存使用量仍然很少。

 ## 边缘情况

 像这样的单字符字符串`a`产生`0`因为没有子串可以重复。 该算法正确地迭代从 1 开始的长度，并且没有发现重复的子字符串。 

对于像这样的字符串`aaaaa`，该算法通过检查长度增加的子串来查找重叠重复。 它正确检测到`aaaa`作为最长的重复子串，因为`aaaa`发生在位置 0-3 和 1-4。 该集合可确保捕获重复项，并且一旦发现重复项就中断循环，以避免丢失较长的子字符串。
