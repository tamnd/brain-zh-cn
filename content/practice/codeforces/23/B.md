 ## 解决方案
 ## 问题理解

 我们可以将聚会视为一个无向的友谊图。 每个人都是一个顶点，一条边意味着两个人是朋友。 

这个过程会轮流淘汰人员。 首先，每个人都有学位`0`树叶。 在这些移除之后，一些剩下的人现在可能拥有学位`1`，所以他们接下来离开。 那么有学位的人`2`离开，依此类推，逐步增加所需的度数，直至达到`n - 1`。 

问题不是要求我们模拟给定的图表。 相反，对于给定数量的人`n`，我们必须以尽可能最好的方式设计友谊图，以便在整个过程结束后有尽可能多的人生存。 

从概念上讲，约束非常小，尽管可能有多达`10^5`测试用例。 每个测试用例仅包含一个整数`n`，输出只是一个整数答案。 这立即表明预期的解决方案是数学的或建设性的，每个测试用例都有恒定时间处理。 任何试图枚举图的算法都是没有希望的，因为无向图的数量`n`顶点是`2^(n(n-1)/2)`。 

问题的微妙部分是理解“最终生存”的真正含义。 粗心的解释可能会认为，如果一个人有足够多的朋友，他们就会永远留下来。 这是错误的，因为清除量会动态变化。 

考虑`n = 3`。 

三角形图的所有度数都等于`2`。 在第一轮中没有人离开，因为没有孤立的顶点。 没有人在第二轮中离开，因为没有 1 度顶点。 然后该过程达到程度`2`，三人一起离开。 正确答案是`0`， 不是`3`。 

不同的图表效果更好。 取一条边和一个孤立的顶点。 孤立的顶点首先离开。 其余两个顶点各有度数`1`，所以他们在下一轮离开。 其中一个人是最后移除的人，因此只有一个人可以留在流程的最后。 答案就变成了`1`。 

另一个容易犯的错误是假设答案总是`1`。 

拿`n = 4`。 一个周期的长度`4`给出每个顶点的度数`2`。 没有人离开学位`0`或者`1`。 当过程达到一定程度`2`，所有四个顶点都离开。 最后的答案还是`0`。 

但我们可以用一个三角形加上一个孤立的顶点来做得更好。 被孤立的人先离开。 三角形一直存在到度数`2`阶段，所有三个三角形顶点都被删除。 最后删除的顶点数仍然是`1`， 不是`3`。 

关键的观察是，这个过程最终总是会消除所有人。 我们唯一控制的是在最后一个移除阶段之前仍有多少人在场。 

## 方法

 蛮力方法是枚举所有可能的友谊图`n`顶点并模拟删除过程。 

对于固定图，模拟很简单。 在阶段`k`，删除当前度数等于的每个当前活动顶点`k`。 继续，直到处理完所有阶段。 然后记录在最终删除之前有多少顶点幸存下来。 

这是有效的，因为流程定义是明确且确定的。 问题是图表的数量。 上的无向图`n`顶点有`n(n-1)/2`可能的边，所以有$2^{\frac{n(n-1)}{2}}$不同的图表。 

即使是为了`n = 20`，这是一个天文数字。 再多的优化也无法使暴力破解变得可行。 

突破来自于分析过程中必须发生的事情。 

假设在某个时刻有`m`人们还活着。 他们每个人最多可以拥有学位`m - 1`。 最终该过程达到阶段`m - 1`。 到了那个阶段，剩下的人都必须离开，因为没有人能拥有比这更大的学位。`m - 1`。 

这意味着该过程始终以一起删除所有当前剩余的顶点而结束。 

现在的问题是：最终组的最大可能规模是多少？ 

假设最终幸存的群体有规模`m`。 就在最后一步之前，每一个`m`顶点必须具有精确的度数`m - 1`，否则它们早晚会被删除。 所以最后一组必须形成一个完整的尺寸图`m`。 

但是如果整个图最初恰好有`m`顶点，然后在最后阶段所有顶点一起消失，在该过程之后没有留下任何东西。 为了让一个人活得更久，我们至少需要在派系之外多一个顶点。 

这表明了最佳结构：

 1. 建立一个派系`m`顶点。 
2. 添加一个孤立的顶点。 

孤立的顶点在阶段消失`0`。 该派系在舞台之前保持不变`m - 1`，当所有团顶点被一起删除时。 

该构造使用`m + 1`总顶点数。 所以对于给定的`n`，最大可能的最终团大小是$m=n-1$因此答案很简单`n - 1`。

 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个值`n`, 计算`n - 1`。 

我们总是可以通过绘制完整的图表来实现这个值`n - 1`顶点和一个孤立的顶点。 
3. 打印结果。 

为什么这是正确答案？ 孤立的顶点在度数期间立即消失`0`阶段。 之后，剩余的`n - 1`顶点形成一个派系，因此每个顶点都有度`n - 2`。 它们在每个早期阶段都存活下来，因为它们的度数大于当前的移除数。 当进程到达阶段`n - 2`，将它们全部一起删除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    print(n - 1)
```实现故意很小，因为所有工作都在证明中。 

程序独立读取每个测试用例并输出`n - 1`。 没有图形构建或模拟，因为数学论证已经证明了最优值。 

唯一的边界条件是`n = 1`。 在这种情况下，公式给出`0`，这是正确的。 一个孤立的人在学位期间离开`0`舞台，所以之后就没有人留下来了。 

Python 整数是无界的，因此即使限制大得多，也不存在溢出问题。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append(str(n - 1))

    print("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

 ## 边缘情况

 考虑最小的输入：```
1
1
```只有一个人，没有友谊。 舞台期间`0`, 此人有学位`0`并立即离开。 

该算法计算：$1-1=0$这与过程完全匹配。 

现在考虑：```
1
2
```在两个人之间占据一条边。 最初两人都有学位`1`。 

在阶段`0`，没有人离开。 在阶段`1`，两人一起离开。 

该算法输出：$2-1=1$意味着最大可能的最终幸存群体规模是`1`。 我们通过使用一个孤立的顶点和一个单独的顶点来实现这一目标。 孤立的顶点先离开，然后剩下的人再离开。 

另一个棘手的情况是：```
1
4
```天真的猜测可能是`4`，使用四个顶点的完整图。 但每个顶点都有度数`3`，所以四个人一起消失在舞台上`3`。 

最佳的结构是一个规模大小的派系`3`加上一个孤立的顶点。 孤立的顶点先消失，集团存活到阶段`2`。 

该算法输出：$4-1=3$这是可以实现的并且是最佳的。
