 ## 解决方案
 ## 问题理解

 该问题描述了一个相互连接的村庄树。 一棵树在任意两个村庄之间只有一条路线，因此每条路都是单点故障。 我们需要添加最少数量的额外道路，以便每对村庄之间至少有两条不同的简单路线。 同样，添加道路后，图中必须没有桥梁，因为桥梁实际上就是一条道路，其删除将图分开并阻止两条独立的路线。 

输入给出了几个测试用例。 对于每个案例，我们都会收到村庄的数量和`N - 1`现有的道路形成一棵树。 输出是所需新道路的最少数量。 

所有测试中村庄总数的约束很大，因此算法必须接近线性。 尝试可能的新道路或检查许多对村庄的解决方案很快就会变得太慢。 对于多达数十万个节点，我们只需处理每个边和顶点恒定的次数。 

棘手的部分是了解叶子上发生了什么。 一片叶子只有一条事件路径，因此该路径始终是原始树中的一座桥。 消除这个弱点的唯一方法是将叶子连接到树的另一部分，创建一个包含其边缘的循环。 添加的道路的最小数量不是叶子的数量，因为一条新道路可以通过将两个叶子分支连接在一起来一次固定两个叶子。 

考虑一棵具有三个顶点的树：```
3
1 2
2 3
```有两片叶子。 正确答案是`1`，因为在之间添加一条边`1`和`3`创建包含两条原始道路的循环。 粗心的方法会在每片叶子上添加一条路，从而输出`2`。 

另一个边缘情况是叶子数量为奇数的树。 例如：```
5
1 2
1 3
1 4
1 5
```有四片叶子，所以答案是`2`。 在叶子数量为奇数的树上，贪婪地配对叶子而不处理最终不匹配叶子的方法可能会失败。 

## 方法

 一种直接的方法是重复选择成对的叶子并在它们之间添加道路。 这个想法是合理的，因为每增加一条道路都会产生一个循环，而循环正是消除桥梁的原因。 如果我们模拟每种可能选择的效果并不断寻找最佳道路集，则可能性的数量增长得太快。 对于具有许多叶子的树，可能的配对太多，并且搜索呈指数级增长。 

有用的观察来自于观察新道路的变化。 如果我们连接两个叶子，这些叶子之间的路径上的每条边都会成为循环的一部分。 最初不受保护的唯一边缘是终止于叶子的分支。 为了使整棵树没有桥梁，每个叶边都需要属于某个循环。 一条添加的道路最多可以包含两个叶子边缘，因为它的两个端点是唯一可以直接关闭两个外部分支的地方。 

这给出了一个下界：如果树有`L`叶子，我们至少需要`ceil(L / 2)`新道路。 我们总是可以通过配对叶子来实现这一点。 如果`L`是偶数，将每片叶子与另一片叶子配对。 如果`L`是奇怪的，将除了一个叶子之外的所有叶子配对，并在最终连接中使用剩余的叶子。 树结构保证这些添加覆盖所有叶边缘。 

整个问题归结为数叶子。 在给定的约束下，具有一个顶点的树是不可能的，并且这里每棵有效的树都至少有两个叶子。

 ## 算法演练

 1. 读取树并计算有多少个顶点恰好有一个邻居。 这些顶点是叶子，它们的关联道路是唯一最初不能属于任何循环的道路。 
2. 设叶子数为`L`。 由于一条新道路可以连接两个叶子并固定两个相应的分支，因此将叶子分成对。 
3.如果`L`是偶数，答案是`L / 2`。 每对都贡献一条新道路。 
4. 如果`L`是奇怪的，一片叶子不能与另一片叶子配对。 仍然需要另外一条路连接，所以答案变成`(L + 1) / 2`。 

这样做的原因是树内两个内部顶点之间的每条道路都已经位于叶子之间的路径上。 一旦所有叶边缘都包含在循环中，则所有其他边缘也都位于循环上，因为添加的叶连接会创建穿过内部路径的循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    t = int(data[0])
    idx = 1
    ans = []

    for _ in range(t):
        n = int(data[idx])
        idx += 1

        deg = [0] * n

        for _ in range(n - 1):
            u = int(data[idx]) - 1
            v = int(data[idx + 1]) - 1
            idx += 2
            deg[u] += 1
            deg[v] += 1

        leaves = 0
        for d in deg:
            if d == 1:
                leaves += 1

        ans.append(str((leaves + 1) // 2))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```该代码仅存储每个村庄的程度。 我们不需要邻接表，因为答案仅取决于存在多少叶子。 

在读取每条道路时，两个端点都会获得一度。 所有道路处理完毕后，度数为 1 的顶点就是叶子。 最终的表达`(leaves + 1) // 2`是取叶子数一半的上限的整数形式。 

主逻辑中不存在索引陷阱，因为顶点仅用于度计数。 输入使用基于一的索引，但数组在减一后使用基于零的索引。 村庄的最大可能数量很大，因此该解决方案使用缓冲输入。

 ## 边缘情况

 对于路径树：```
3
1 2
2 3
```叶子是`1`和`3`。 该算法计算两个叶子并返回`(2 + 1) // 2 = 1`。 在它们之间添加边会创建一个包含两个原始边的循环。 

对于明星来说：```
5
1 2
1 3
1 4
1 5
```有四片叶子。 算法返回`2`。 每条新道路可以连接两个外部村庄，因此两条道路足以覆盖所有四个叶子边缘。 

对于叶子数为奇数的树，例如：```
6
1 2
1 3
1 4
1 5
5 6
```叶子是`2`,`3`,`4`， 和`6`，所以这个特殊情况有四个叶子并且需要两条路。 如果从节点再添加一个分支`1`，叶子计数变为 5，公式返回 3，这是必要的，因为一个叶子不能与另一叶子配对。
