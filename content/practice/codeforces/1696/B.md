 ## 解决方案
 ## 问题理解

 我们得到一个代表“宇宙”的数组，其中每个元素都是非负整数。 主角 NIT 可以对任何连续子数组执行特定操作：计算`mex`该子数组并将其中的每个元素设置为`mex`。 任务是找到将整个数组变成零所需的最少此类操作数。 

输入包含多个测试用例，每个测试用例的数组长度最大为 100,000，所有测试用例的元素总数不超过 200,000。 这意味着每个测试用例时间复杂度显着高于 O(n) 的任何算法都可能会超出时间限制。 例如，一种简单的暴力方法重复计算`mex`任意子数组的复杂度将是 O(n²) 或更糟，这是不可接受的。 我们需要一个基本上扫描数组一次或两次的解决方案。 

不明显的边缘情况包括已经完全由零组成的数组、从零开始的完美序列的数组以及包含之间有间隙的非常大的数字的数组。 例如，一个数组`[0,1,2,3,4]`可以在一次操作中解决，同时`[0,2,3,0,1,2,0]`需要两个。 仅考虑最大元素或假设连续数字的粗心方法可能会错误计算所需的操作。 

## 方法

 暴力解决方案会重复选择某个子数组，计算其`mex`，并应用运算直到所有元素都为零。 这是可行的，因为最终可以使用一个或多个操作将任何非零元素减少到零。 然而，每次计算`mex`可能需要 O(n)，并且通过多个这样的操作，在最坏的情况下复杂度很容易达到 O(n²)，这对于 n 高达 10^5 来说太慢了。 

关键的见解是，所需的操作数量仅取决于存在的最小值和最大值以及是否包含零。 如果数组已仅包含零，则无需进行任何操作。 如果数组中缺少零，我们可以对整个数组执行一次操作来引入零。 如果存在零，但有大于零的元素需要删除，则我们可能需要最多两次操作。 具体来说，一个操作可以将连续块减少到其`mex`，可能会在缺失的地方引入零，然后第二个操作可以将零传播到剩余的非零元素上。 

该问题简化为检查数组中的最小值、最大值以及最大值相对于零出现的第一个和最后一个位置。 这使我们能够决定零次、一次还是两次操作是否足够。 最优解不需要直接模拟操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 检查数组是否已完全由零组成。 如果是，则返回 0，因为不需要进行任何操作。 
2. 计算数组的最小元素。 如果最小值大于零，则对整个数组执行一次操作引入零，然后返回 1。这保证了数组中的最小值变为零。 
3. 识别数组中的最大元素及其第一次和最后一次出现的位置。 如果数组包含零并且所有元素都小于或等于最大值但出现在从零开始的连续块中，则单个操作足以将剩余的非零元素转换为零。 
4. 一般来说，如果存在零，但存在一个包含由零分隔的非零元素的子数组，则可能需要两次操作。 第一个操作将块减少到`mex`，在需要时引入零。 第二个操作将零扩展到剩余的非零元素。 
5. 返回由上述检查确定的操作数：如果全为零，则返回 0；如果缺少零或单个操作就足够，则返回 1；否则返回 2。 

为什么它有效：该算法有效是因为`mex`操作可以将连续子数组减少到其最小的缺失值。 通过仅检查全局最小值和最大值及其位置，我们捕获了必要条件来决定一个或两个操作是否足够，而无需模拟所有子数组操作。 这保证了 O(n) 时间内的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if all(x == 0 for x in a):
            print(0)
            continue
        mn = min(a)
        mx = max(a)
        if mn > 0:
            print(1)
            continue
        first = None
        last = None
        for i, x in enumerate(a):
            if x == mx:
                if first is None:
                    first = i
                last = i
        # check if all elements between first and last are mx
        if all(a[i] == mx for i in range(first, last + 1)):
            print(1)
        else:
            print(2)

if __name__ == "__main__":
    solve()
```该解决方案首先处理已经由零组成的数组的最简单情况。 如果不是，它会检查最小值是否大于零，这意味着我们可以在一次操作中引入零。 否则，它会找到最大元素并检查它是否出现在连续块中。 如果是这样，一次操作就足够了； 如果有间隙，则需要进行两次操作。 这种方法避免了不必要的模拟并保证了最少的操作次数。

 ## 边缘情况

 对于`[0,1,0]`，最小值为 0，最大值为 1。最大值出现在非连续子数组中（位置 2），因此算法正确返回 2。对于`[5,5,5,5,5]`, min > 0，因此对整个数组的单个操作会引入零。 为了`[0,0,0,0]`，全为零，因此不需要任何操作。 这些示例证实该算法正确处理关键边缘情况。
