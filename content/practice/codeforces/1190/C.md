 ## 解决方案
 ## 问题理解

 我们得到一个代表一行卡片的二进制字符串，每张卡片都显示 0 或 1。移动包括选择恰好 k 个连续位置并强制所有这些位置变得相同，要么全 0，要么全 1。数组的其余部分保持不变。 两名玩家交替行动，从时风开始。 谁采取的行动使整个阵列变得统一，谁就赢得了这场比赛。 

关键在于，移动不是单个位的翻转，而是连续段的重新绘制。 假设玩家以最佳状态进行游戏，因此选择每一步棋都是为了最大化自己获胜的机会并最小化对手的获胜机会。 

任务是确定 Tokitsukaze 是否获胜、Quailty 获胜，或者游戏是否可以无限期地继续下去（形式上，超过 10^9 步，视为平局）。 

约束 n ≤ 10^5 立即排除对博弈树的任何模拟。 每次移动都会对线段和两种颜色选择的 O(nk) 种可能性进行分支，甚至浅层搜索也会呈指数级增长。 因此，问题的结构必须分解为关于初始配置的全局属性的推理。 

当字符串除了一小群相反的位之外已经几乎一致时，就会出现微妙的边缘情况。 例如，如果所有 1 都包含在长度为 k 的段内，则 Tokitsukaze 可以重新绘制该段并立即获胜。 只考虑多数颜色或局部图案的幼稚策略在这里会失败，因为获胜取决于少数颜色是否在空间上可压缩，而不是其数量。 

当两个玩家都无法强制立即完成时，就会出现另一种边缘情况，但棋盘可以保持在两个玩家始终都有可用的非获胜棋步的状态。 这会产生“再次”结果，并且通常在配置过于“分散”以至于任何 k 窗口重绘无法在有限数量的步骤中将其折叠时发生。 

## 方法

 暴力方法将明确地模拟游戏。 从给定状态，我们尝试 k 段的所有 O(n) 个选择以及两个重绘选项。 每次移动后，我们检查棋盘是否一致并继续递归。 这正确地模拟了最佳游戏，但分支因子已经是 θ(n)，深度也可以是 θ(n)，使得状态空间立即爆炸到 n 高达 10^5。 

关键的简化是停止考虑移动顺序，而是推理_每个色块的可压缩性_。 仅当该颜色完全包含在所选段内时，移动才能消除整个颜色。 这将问题简化为跟踪最左边和最右边出现的 0 和 1。 

让 1 占据区间 [l1, r1]，0 占据 [l0, r0]。 一次完成的唯一方法是选择一个 k 段来覆盖所有出现的一种颜色，然后将其重新绘制为相反的颜色。 这立即产生了间隔长度方面的获胜条件。 

如果两种颜色都不能被 k 窗口完全覆盖，那么游戏就变成了玩家能否迫使对方进入失败配置的问题。 关键的观察是，当没有任何一步棋能够以决定性的方式严格减少两种颜色的“不可约跨度”时，游戏就变得无限，这意味着每一步棋都可以以恢复类似复杂配置的方式来回答。 当两种颜色相对于 k 过于分散时，就会发生这种情况，因此没有玩家可以分离出完整的色块。

 ## 算法演练

1. 扫描字符串并记录 0 和 1 的第一次和最后一次出现。这给出了两个区间 [l0, r0] 和 [l1, r1]。 此步骤将整个游戏状态压缩为恒定大小的信息，因为只有极端位置对于完全消除才重要。 
2. 计算每个间隔的长度：len0 = r0 − l0 + 1 和 len1 = r1 − l1 + 1。这些表示每种颜色传播的距离。 
3. 确认时风能否一招制胜。 如果存在一个 k 长度的段覆盖所有出现的 0 或 1，就会发生这种情况。在区间术语中，这相当于检查 min(len0, len1) ≤ k。 如果是这样，时风会选择覆盖该颜色的部分并重新绘制它，立即获胜。 
4. 如果不可能立即获胜，则确定游戏是否可以无限期地继续下去。 当两个玩家都无法迫使游戏进入一个单一 k 段可以隔离整个颜色的位置，并且任何移动都可以被对手对称反击时，就会发生这种情况。 

表征这一点的结构条件是，两种颜色相对于 k 都“太宽”，并且以这样的方式重叠：每次尝试压缩一侧都会留下足够的结构供对手恢复复杂性。 在这种制度下，游戏永远不会在有限的时间内崩溃到统一状态。 

1. 如果立即获胜和无限比赛条件均不成立，则第二位玩家通过一步中的终结棋来响应时风的每一步棋，从而获得强制获胜。 

### 为什么它有效

 不变量是游戏中唯一有意义的进展是减少包含所有颜色出现的最小间隔。 一步棋要么完全消除一种颜色（立即获胜），要么没有充分减少两个间隔。 当两个间隔都超过 k 并且以防止孤立的方式交织时，每一步都保留了逆转的可能性，导致无限循环。 如果这种结构对称性被打破，第二个玩家总是可以迫使配置回到时风无法创造获胜压缩的位置。

 ## 边缘情况

 当弦已经均匀时，两个音程都会塌陷为一个点。 由于 min(len0, len1) 变为零，因此立即获胜条件被触发，这反映出无需采取任何操作即可实现一致性。 

当 k 等于 n 时，任何移动都会覆盖整个数组。 该算法正确地将其分类为获胜位置，因为第一个玩家可以直接强制一致性，而不管初始结构如何。 

当一种颜色出现在短于 k 的连续块中时，该块可以一步完全消除。 区间压缩准确地捕捉到了这一点，并且条件 min(len0, len1) ≤ k 确保了正确的检测。 

当两种颜色高度交错时，两个间隔几乎跨越整个阵列，并且都不能被隔离。 该算法根据边界重叠是否允许持续游戏将其路由到非终止或失败分支，这反映出无法在单个移动中降低结构复杂性。
