 ## 解决方案
 ## 问题理解

 我们在平面上得到了一组点，并且允许我们选择一种特殊类型的区域：两个 x 坐标之间的垂直条带，例如 l 和 r 之间，但在侧面开放，与水平阈值 a 相结合，这样我们只取严格高于该高度的点。 该区域向上无界，因此它的行为就像一个垂直板，捕获所选 x 区间内和所选截止值上方的所有点。 

对于每个这样的区域，我们获取其中的所有点并记录结果点集。 区域的不同选择可能会产生相同的点集，我们被要求计算这样可以得到多少个不同的非空点集。 

约束最多为 200,000 个点，这会立即排除任何尝试所有左右边界对或显式枚举子集的解决方案。 n 中的任何二次方都已经太大，因此解决方案必须依赖于排序和线性或近线性扫描，可能采用分而治之或扫描线的想法。 

一个微妙的点是 x 条件对双方都很严格。 完全位于边界的点永远不会被包括在内，因此该区域的行为就像按 x 顺序选择连续的线段。 另一个重要的方面是，高度阈值意味着在任何选定的 x 区间内，我们有效地选择按 y 排序的点的后缀。 x 排序和 y 阈值之间的相互作用驱动了有效集的结构。 

一个常见的失败案例来自于独立思考 x 和 y。 例如，如果所有点共享相同的 x 坐标，则每个有效区域仅由 y 阈值确定，因此不同集合的数量恰好为 n，而不是 2^n。 幼稚的子集解释在这里会完全计算过多。 

另一个陷阱是假设每个“y 中单调”的子集都是可以实现的。 这是不正确的，除非子集也对应于按 y 过滤后的 x 顺序的连续段（这是真正的约束）。 

## 方法

 暴力方法会尝试 l 和 r 的所有可能选择。 对于按 x 顺序排序的每对索引 i 和 j，我们将考虑它们之间的点集，然后将 a 从负无穷大向上改变。 随着 a 的增加，点按 y 的递增顺序删除，为每个间隔生成一系列子集。 这个想法是正确的，但太慢了，因为有 O(n^2) 个间隔，并且即使在线性时间内处理每个间隔，在最坏的情况下也会导致 O(n^3) 。 

关键的观察是，每个有效集都可以通过选择 x 顺序的段，然后选择高于某个 y 阈值的所有点来描述。 我们没有明确地列举所有片段，而是颠倒了观点。 我们按 x 对点进行排序，并考虑通过选择充当 y 中的截止点的“最高点”来构建集合，同时控制我们在 x 中向左和向右延伸的距离。 

一个关键的重组是在选定的集合内确定具有最小 y 的点。 该点确定阈值a。 一旦该点被固定，集合中的所有其他点的 y 都必须大于它，并且必须位于它周围的连续 x 区间内，而不包括集合之外具有更高 y 的任何点，否则会导致包含不一致。 

这导致了 x 阶上的经典分而治之结构：我们选择一个点作为最小 y 锚点，并向左和向右扩展，保持约束以确保所有包含的点都是高于阈值的有效候选点。 对于每个锚点，可以使用两指针或单调堆栈样式合并有效地组合有效左扩展和右扩展的数量，从而导致 O(n log n) 行为。

本质上的简化是，我们不是枚举区域，而是枚举可能的“所选集合中的最低点”，并计算该点之上的所有点可以形成多少个有效的连续 x 区间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 暴力破解 x 间隔和阈值 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 使用 y 锚定对 x 进行分而治之 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们首先按 x 坐标对所有点进行排序。 这确保每个有效区域对应于按此顺序选择连续段。 

接下来，我们将每个点视为有效集合中潜在的最低 y 点。 如果一个点是所选集合中最低的点，则每个其他所选点必须具有严格更大的 y 值，因此可以独立地考虑在该枢轴上方的这些点。 

对于每个这样的主元，我们计算存在多少个有效集合，其中该主元是最小 y。 

我们按如下方式进行。 

1. 按 x 坐标对点进行排序，并将它们从 0 到 n-1 索引。 这将问题转化为在线工作。 

2. 对于每个点 i，将其视为最终选择集中 y 最小的候选点。 这将阈值 a 固定为略低于 y[i]。 该集合必须仅包含 y 大于 y[i] 的点。 

3. 从索引 i 开始，向左和向右扩展，同时仅考虑 y 大于 y[i] 的点。 所选集合必须在 x 中保持连续，因此我们增长一个始终包含 i 的区间 [L, R]。 

4. 在扩展时，我们维护存在多少种有效方法来扩展区间，且不违反 y 大于 y[i] 的排除点不位于区间内的约束。 这是通过使用单调堆栈预先计算最近的阻塞点或通过扫描 y 阶并维护活动段来处理的。 

5. 对于每个主元 i，乘以有效的左选择和右选择的数量。 乘积表示有多少个区间以 i 作为其最小 y 点，并且所有选定的点自动满足 y > y[i]。 

6. 所有 i 的贡献总和。 结果对每个有效非空集精确计数一次，因为每个集都有唯一的最小 y 点。 

正确性依赖于任何有效集合中的最小 y 点都是唯一的并确定阈值 a 的事实。 一旦这个点被固定，所有剩余的自由度都是纯粹水平的，并且必须在x顺序上形成一个连续的区间，而不包括禁止点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    pts.sort()  # sort by x

    # We compute contribution using a monotonic stack idea on y.
    # prev greater / next greater structure over y in x-order.

    x = [p[0] for p in pts]
    y = [p[1] for p in pts]

    # nearest greater element boundaries in x-order based on y
    left = [-1] * n
    right = [n] * n

    stack = []
    for i in range(n):
        while stack and y[stack[-1]] < y[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    stack.clear()
    for i in range(n - 1, -1, -1):
        while stack and y[stack[-1]] < y[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    # Each point contributes as minimum-y anchor:
    # number of choices = (i - left[i]) * (right[i] - i)

    ans = 0
    for i in range(n):
        ans += (i - left[i]) * (right[i] - i)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案依赖于按 x 对点进行排序，以便每个有效选择都成为区间问题。 y 上的单调堆栈计算每个点在遇到大于或等于 y 的点之前可以向左和向右延伸多远，这将打破区间内具有唯一最小值的条件。 

左范围和右范围的乘法计算每个点作为 y 中唯一最小值的间隔数量，这与有效的矩形选择完全对应。 

一个微妙的实现细节是，比较必须严格基于 y 排序，以便永远不会出现平局，因为所有点都是不同的。 使用严格的更大处理可确保每个间隔恰好分配给一个主元。

 ## 边缘情况

 关键的边缘情况是所有点共享相同的 x 坐标。 在这种情况下，“间隔”就会崩溃，只有垂直阈值才重要。 该算法仍然会产生正确的计数，因为每个点都在 x 顺序上变得孤立，因此每个点恰好贡献了一个与最小 y 相对应的新有效集。 

另一个边缘情况是 x 顺序中严格单调的 y 值。 这里每个点都成为具有最大跨度的潜在枢轴，并且该结构产生间隔的完整组合增长。 单调堆栈通过允许每个新点延伸到具有较低 y 的所有先前点来正确地捕获这一点。 

最后的边缘情况是 y 值是随机的但 x 是排序的。 在这种情况下，堆栈边界会波动，每个点的贡献很大程度上取决于附近的最大值。 该算法通过最近的较大元素正确地划分间隔，确保每个有效集通过其唯一的最小 y 锚点精确计数一次。
