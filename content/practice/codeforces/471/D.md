 ## 解决方案
 ## 问题理解

 我们有两堵墙，由塔楼高度序列表示。 

熊墙包含`n`塔楼，而贺拉斯的墙包含`w`塔。 贺拉斯可以将他的整面墙垂直移动任意数量。 墙上的每座塔都必须移动相同的值，但该值可以是正值、负值或零。 

对于一段长度`w`在熊的墙中，我们想知道 Horace 是否可以选择一些垂直移动，以便他的墙与该部分完全匹配。 任务是计算存在多少个这样的段。 

关键细节是贺拉斯可能会为他墙上的每座塔添加相同的常数。 这意味着绝对高度并不重要。 只有连续塔之间的差异才重要。 

约束达到`2 · 10^5`元素。 任何比较每个长度的算法 -`w`直接根据模式进行细分将需要大致`n · w`操作，可以达到约`4 · 10^10`，远远超出了 2 秒的限制。 我们需要接近线性时间的东西。 

一些边缘情况很容易被忽略。 

考虑：```
n = 5, w = 1
a = [10, 20, 30, 40, 50]
b = [7]
```每座塔都可以与单塔墙相匹配，因为霍勒斯可以将他的墙移动任意数量。 正确答案是`5`。 

仅基于差异数组的解决方案将产生空的差异序列并且可能错误地返回`0`除非这种情况单独处理。 

另一个例子：```
a = [5, 8, 11]
b = [1, 4]
```该段`[5,8]`添加后匹配`4`对每一个元素`b`， 和`[8,11]`添加后也匹配`7`。 

答案是`2`，即使没有直接相等的高度。 

第三个例子说明了为什么连续差异就足够了：```
a = [100, 103, 106]
b = [1, 4, 7]
```差异是：```
a: [3, 3]
b: [3, 3]
```添加后墙壁匹配`99`对每一个元素`b`。 

## 方法

 强力解决方案检查每个长度 -`w`熊墙的一部分。 对于每个段，计算对齐第一个塔所需的移位，然后在应用该移位后验证剩余的每个塔是否匹配。 

这是正确的，因为有效的匹配必须使用单个常量移位。 当我们分析成本时，问题就出现了。 大约有`n`候选片段，每次比较可以检查最多`w`塔。 最坏情况的复杂度是`O(nw)`，这变成了关于`4 · 10^10`当两个数组都有长度时的操作`2 · 10^5`。 

关键的观察结果是，向每个塔添加一个常数可以保留连续的差异。 

假设贺拉斯的墙是：```
b1, b2, b3, ...
```我们增加了一些价值`c`：```
b1+c, b2+c, b3+c, ...
```然后：```
(b2+c) - (b1+c) = b2-b1
```对于每一个相邻的对也是如此。 

当且仅当它们的差异数组相同时，一段在某些移位后才与霍勒斯的墙相匹配。 

让：```
DA[i] = a[i+1] - a[i]
DB[i] = b[i+1] - b[i]
```原始墙壁的匹配完全对应于以下情况的出现`DB`里面`DA`。 

现在问题变成了整数序列上的经典字符串匹配问题。 我们需要计算模式有多少次`DB`出现在文本中`DA`。 

Knuth-Morris-Pratt 算法查找线性时间内模式的所有出现。 由于差异数组有长度`n-1`和`w-1`，总复杂度变为`O(n+w)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(西北) | O(1) | O(1) | 太慢了 |
 | 最优（差异 + KMP）| O(n+w) | O(n+w) | 已接受 |

 ## 算法演练

 1. 读取两个高度数组。 
2.特殊情况处理`w = 1`。 

在选择适当的垂直位移后，任何单塔都可以与单塔象墙相匹配。 答案很简单`n`。 
3. 建立熊墙的差异阵列。 

对于每个相邻对，存储：```
a[i+1] - a[i]
```两个匹配的墙必须具有相同的连续差异。 
4. 以同样的方式构建Horace墙的差分数组。 
5. 计算模式差异数组的 KMP 前缀函数。 

前缀函数为每个位置存储最长的正确前缀（也是后缀）的长度。 KMP 使用此信息来避免在不匹配后重新检查值。 
6. 对熊的差异数组运行 KMP 匹配。 

每当匹配的模式长度达到`len(DB)`，已发现一种情况。 
7. 计算所有出现的次数并打印结果。 

### 为什么它有效

 如果存在常数，两堵墙的差异仅在于垂直位移`c`这样每个对应的塔都完全不同`c`。 

如果存在这样的常数，则每个相邻的差异都是相同的，因此差异数组匹配。 

相反，如果差异数组匹配，则在将 Horace 墙的第一个塔与该段的第一个塔对齐后，所有剩余的塔都将强制匹配，因为每个连续的更改都是相同的。 因此匹配差异数组既是必要的也是充分的。 

KMP 会查找文本差异数组内模式差异数组的每次出现，因此每个有效段都会被精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def prefix_function(pattern):
    pi = [0] * len(pattern)

    for i in range(1, len(pattern)):
        j = pi[i - 1]

        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]

        if pattern[i] == pattern[j]:
            j += 1

        pi[i] = j

    return pi

def solve():
    n, w = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    if w == 1:
        print(n)
        return

    text = [a[i + 1] - a[i] for i in range(n - 1)]
    pattern = [b[i + 1] - b[i] for i in range(w - 1)]

    pi = prefix_function(pattern)

    j = 0
    ans = 0

    for x in text:
        while j > 0 and x != pattern[j]:
            j = pi[j - 1]

        if x == pattern[j]:
            j += 1

        if j == len(pattern):
            ans += 1
            j = pi[j - 1]

    print(ans)

solve()
```第一个重要的选择是处理`w = 1`立即地。 单元素墙的差异数组是空的，尝试在空图案上运行 KMP 会使实现不必要地复杂化。 每个位置都是有效的，所以答案很简单`n`。 

下一步将两面墙转换为不同的阵列。 这种转换消除了不相关的绝对高度，并准确地保留了垂直移位下保留的信息。 

前缀函数是标准 KMP 预处理阶段。 它记录了不匹配后有多少模式保持匹配，从而使扫描保持线性。 

在匹配阶段，`j`始终表示当前匹配的前缀长度。 什么时候`j`达到完整模式长度，已发现一个事件。 重置`j`到`pi[j-1]`允许正确计算重叠匹配。 

所有算术都适合 Python 整数。 差异可能是负数，但 KMP 处理任意整数序列的方式与处理字符串的方式完全相同。

 ## 边缘情况

 考虑单塔模式：```
5 1
10 20 30 40 50
7
```该算法立即触发`w == 1`分支和返回`5`。 每座塔都可以变得高度`7`选择合适的班次后，每个位置都是有效的。 

现在考虑匹配需要大偏移的情况：```
3 3
100 103 106
1 4 7
```差异数组是：```
DA = [3,3]
DB = [3,3]
```KMP 发现一个事件。 该算法从不使用实际的移位值`99`，因为匹配差异已经证明了这种转变的存在。 

最后，考虑重复值：```
5 3
7 7 7 7 7
2 2 2
```差异数组变为：```
DA = [0,0,0,0]
DB = [0,0]
```KMP 查找从以下位置开始的事件`0`,`1`， 和`2`，产生答案`3`。 重叠匹配会被正确计数，因为在每次完整匹配之后，KMP 使用前缀函数回退，而不是从零重新开始。
