 ## 解决方案
 ## 问题理解

 两队轮流将飞盘扔到长方形的海滩球场上。 每次投掷都是 2D 平面中的一个点，并且在同一个矩形内的某处有一个固定的目标点“tejin”。 分数完全由到该目标的欧几里得距离决定。 

两队的每次投掷都会与对方球队的所有投掷进行比较，但规则简化了比赛：只有距离的相对排名很重要。 首先，我们找到 A 队达到的最小距离和 R 队达到的最小距离。这两个距离较小的队获胜。 

确定获胜者后，该球队的每次投掷都比失败球队的最接近目标更接近目标，从而获得一分。 距离上的平局保证不存在，所以我们永远不必担心相等的比较。 

输入量很小，每队最多投掷 1000 次。 计算所有距离很简单，因为我们最多只需要 2000 个点。 任何对每个点计算一次距离并执行线性扫描的解决方案就已经足够了。 

一个微妙的一点是，我们必须比较距离，而不是粗心地比较距离的平方，除非我们是一致的。 由于欧几里德距离涉及平方根，因此比较平方距离以避免浮点问题是标准做法。 

边缘情况主要是结构性的而不是数字性的。 

一种特殊情况是，一支球队的所有投掷都严格地比另一支球队的所有投掷更远。 然后立即根据最短距离确定获胜者。 

另一种情况是，最近的投掷不是唯一的，而是属于坐标非常接近的不同团队。 该问题明确保证不存在相等的距离，因此我们不处理平局。 

最后一个微妙之处是得分取决于失败球队的最佳投球。 即使获胜的球队有多次非常好的投球，也只有那些严格优于对手的最佳投球才能做出贡献。 

## 方法

 直接模拟计算两个团队的所有平方距离，然后扫描以找到每个团队的最小值。 之后，我们比较两个最小值来决定获胜者。 一旦知道获胜者，我们就会对该团队的距离进行第二次传递，并计算有多少距离严格小于对手的最小值。 

这已经很符合约束条件了。 在这里，暴力破解的想法本质上是最佳的，因为除了简单的聚合之外，没有其他结构可供利用。 完整的计算与抛出次数呈线性关系，并且没有排序要求或点之间的组合交互。 

唯一潜在的过度杀伤方法是对所有距离进行排序，但排序是不必要的，因为我们只需要最小值和计数阈值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（扫描+比较）| O(N) | O(N) | 已接受 |
 | 最优（同样的想法，直接）| O(N) | O(1) 额外 | 已接受 |

 “最佳”解决方案实际上只是认识到问题简化为计算两个最小值和一个过滤计数。 

## 算法演练

 ## 算法演练

 1. 读取所有输入并分别存储 A 队和 R 队的坐标。 
2. 计算 A 队和 R 队每次投掷到目标点的欧氏距离平方。平方距离用于避免浮点精度问题，因为保留了比较。 
3. 扫描 A 队的所有距离以找到最小值，并对 R 队执行相同的操作。这为每个团队提供了最佳投掷。 
4. 比较两个最小值。 最小距离较小的团队被宣布为获胜者。 
5.让`best_loser`为失败队的最小距离。 遍历获胜队的距离并计算有多少严格小于`best_loser`。 
6. 输出获胜队伍标签和计数。 

关键思想是，评分规则仅取决于从对手的最佳投掷中得出的单个阈值，因此在确定该阈值后，问题的其余部分就变成了简单的过滤操作。 

### 为什么它有效

 每支球队对得分的贡献仅取决于一次投掷是否击败了对手的最佳表现。 根据定义，任何不严格优于对手最低限度的投掷都不能对得分有所贡献。 相反，每一次严格意义上更好的投掷都只计算一次。 由于所有比较都是独立的，并且仅基于到固定点的距离，因此除了确定最小值之外，投掷之间不存在相互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def dist2(x, y, tx, ty):
    dx = x - tx
    dy = y - ty
    return dx * dx + dy * dy

n = int(input())
w, l, tx, ty = map(int, input().split())

A = []
R = []

for _ in range(n):
    x, y = map(int, input().split())
    A.append(dist2(x, y, tx, ty))

for _ in range(n):
    x, y = map(int, input().split())
    R.append(dist2(x, y, tx, ty))

minA = min(A)
minR = min(R)

if minA < minR:
    winner = "A"
    threshold = minR
    score = sum(1 for d in A if d < threshold)
else:
    winner = "R"
    threshold = minA
    score = sum(1 for d in R if d < threshold)

print(winner, score)
```该实现将读取和距离计算完全分开，确保所有几何工作都简化为整数算术。 平方距离的使用一致，因此不会出现平方根。 

获胜者的决定是对最小值的直接比较。 之后，得分过程是对获胜团队列表的单个线性过滤器。 

一个常见的错误是多次重新计算距离或混合原始距离和平方距离。 另一种情况是不小心从两支球队中计算，而不是只计算获胜者。

 ## 边缘情况

 一个关键的边缘情况是两支球队都投掷一次。 获胜者只是较接近的点，获胜者的分数始终为 1，因为它必须严格比对手的唯一投掷更接近。 该算法自然地处理了这一问题，因为两个最小值都被正确计算，并且过滤器精确地计算了一个元素。 

另一种边缘情况是当一个团队的所有点都极度聚集在目标附近而另一团队则远离目标时。 在这种情况下，阈值比较仍然有效，因为所有获胜投掷都满足严格的不平等，因此每次投掷都有贡献。 

最后的边缘情况是坐标恰好位于矩形的边界上。 由于距离计算不依赖于边界，因此这些点的行为与内部点相同。 平方距离计算仍然有效并且不需要特殊的套管。
