 ## 解决方案
 ## 问题理解

 我们被要求计算有多少个整数的算术级数同时满足三个约束。 每个有效级数都是一个具有正公差的序列，因此它是严格递增的。 每一项必须位于从 L 到 R 的固定区间内。一个特定值 A 必须出现在序列内的某处。 最后，序列中所有项的总和必须恰好为 S。 

输入给出四个值：A、S、L 和 R。我们需要考虑 [L, R] 内包含 A 且总和为 S 的所有可能的算术级数，并计算存在多少个这样的级数。 

对值的限制非常严格，但对计数则不然。 L和R最大可达10^12，但区间长度最多为10^5。 总和 S 最大可达 10^18，这排除了任何枚举序列并直接计算总和的方法。 这表明每个级数的结构必须以代数方式利用而不是模拟。 

当级数的长度为 1 时，就会出现关键边缘情况。在这种情况下，序列就是 [x]，并且它的和总是 x。 这意味着仅当 S 等于 x 且 A 也必须等于 x 时才存在有效解。 另一个微妙的情况是当级数长度很大但公差为 1 时，这会在区间内创建密集的整数覆盖。 这些情况通常隐藏了界限或求和公式中的差一错误。 

如果尝试将 A 固定为第一个或最后一个元素，则会出现另一种失败模式。 A 只需要位于序列内部，不一定位于端点。 任何正确的解决方案都必须考虑到 A 是级数中的任意位置。 

## 方法

 直接的蛮力方法将尝试每一个可能的起始值、每一个可能的公差和每一个可能的长度。 对于每个候选级数，我们可以检查它是否在[L,R]内，是否包含A，以及它的和是否等于S。使用算术级数公式可以在常数时间内计算出总和，但候选三元组的数量是巨大的。 即使我们将起始限制为 [L, R] 并将差异限制为 R − L，这也已经为每个维度放弃了大约 10^5 个选择，导致在最坏的情况下大约有 10^15 个配置，这是完全不可行的。 

一旦我们以参数形式编写算术级数，问题的结构就会变得更加严格。 假设级数的长度为 n，第一项为 x，差值 d > 0。则序列为 x, x + d, ..., x + (n − 1)d。 其总和为 n/2 · (2x + (n − 1)d)。 A 出现在序列中的约束意味着存在某个索引 k 使得 A = x + k d。 这立即意味着 x = A − k d，并且还约束 x 和 d，以便所有项都保留在 [L, R] 内。 

我们可以将序列重新解释为以 A 的位置为中心，而不是独立选择 x、d 和 n。对于 (n, d, k) 的固定选择，其中 k 是 A 在序列中的位置（从 0 开始索引），其他一切都已确定。 然后，总和约束变成以 n、d 和 A 表示的线性方程。这将问题简化为在 L 和 R 引起的边界下计算整数解。

关键的观察结果是，一旦 n 和 d 固定，有效的 k 值就会形成一个连续的范围，该范围由级数在保持在 [L, R] 时向左和向右延伸的距离决定。 对于每个固定的（n，d），我们可以检查S是否与求和公式兼容，如果是，则计算A在级数中的有效位置有多少。 由于 R − L ≤ 10^5，差值 d 自然也是有界的，并且 n 也最多为 10^5。 这允许在大约 O((R − L)^2) 最坏情况下迭代可行的结构，但通过算术约束进行修剪，有效对的实际数量会缩减到可管理的大小。 

主要困难在于求和方程强烈限制 (n, d) 对。 对于每一对，总和条件唯一地确定 x，然后我们只需要验证 A 是否在级数中并且所有项都在边界内。 这将问题转化为对派生表达式除数的有界搜索，由于区间约束，该除数很小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对 (x, d, n) | 进行暴力破解 O((R−L)^2·(R−L)) | O((R−L)^2·(R−L)) | O(1) | O(1) | 太慢了|
 | 带验证的 (n, d) 代数枚举 | O((R−L) · sqrt(R−L)) | O((R−L) · sqrt(R−L)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们用长度 n、第一项 x 和公差 d 来表示任何算术级数。 求和条件给出了 x 的直接方程，因此我们完全消除了 x。 

1.固定长度n和差d。 我们知道序列必须位于 [L, R] 之内，因此最小可能的第一项是 L，最大可能的最后一项是 R。这意味着 x ≥ L 且 x + (n − 1)d ≤ R，这隐式限制了可行的 x 值。 
2. 使用等差数列公式 S = n/2 · (2x + (n − 1)d) 表示总和。 重新排列得出 2S = n(2x + (n − 1)d)。 由于 x 未知，我们将其视为 x 的线性约束。 
3. 求解 x： x = (2S / n − (n − 1)d) / 2。对于固定的 (n, d)，x 是唯一确定的，因此我们只需检查它是否是整数并且在范围内。 
4. 执行完整性条件。 表达式 2S / n 必须是整数，否则该 (n, d) 对无法产生有效的级数。 这会立即删除大多数候选人。 
5. x 确定后，验证边界约束 L ≤ x 和 x + (n − 1)d ≤ R。如果这些成立，则级数有效，前提是它还包含 A。 
6. 通过测试 A 是否位于等差数列中来检查 A 的包含性。 这简化为检查 A ≥ x 是否、(A − x) 是否可被 d 整除以及商是否小于 n。 
7. 计算满足所有约束的所有有效 (n, d) 对。 

为什么它有效：每个有效的算术级数恰好对应于一个三元组（n，d，x），并且对于每个这样的三元组，上述条件都是必要且充分的。 总和方程强制 x 的唯一性，而包含和边界确保我们只接受完全在允许的间隔内并包含 A 的序列。不会错过任何有效的级数，因为考虑了每个可能的 (n, d)，并且不会计算无效的级数，因为每个约束都被显式检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A, S, L, R = map(int, input().split())
    
    ans = 0
    
    max_len = R - L + 1
    
    for n in range(1, max_len + 1):
        # 2S must be divisible by n
        if (2 * S) % n != 0:
            continue
        
        val = (2 * S) // n
        
        # val = 2x + (n-1)d
        # we try d, derive x
        # rearrange: 2x = val - (n-1)d
        
        # bounds on d from x >= L and x+(n-1)d <= R
        # x = (val - (n-1)d)/2
        
        for d in range(1, max_len):
            rhs = val - (n - 1) * d
            if rhs % 2 != 0:
                continue
            
            x = rhs // 2
            if x < L:
                continue
            
            last = x + (n - 1) * d
            if last > R:
                continue
            
            # check if A is in progression
            if A < x or A > last:
                continue
            
            if (A - x) % d == 0:
                k = (A - x) // d
                if 0 <= k < n:
                    ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```其实现直接遵循等差数列公式的结构。 外循环固定长度 n，因为最大可能长度受间隔大小限制。 内循环尝试所有可行的差值 d，该差值也受区间限制。 

对于每对 (n, d)，求和公式唯一确定 x。 我们首先确保整除性，以便 x 是整数，然后重建 x 并验证级数是否保持在 [L, R] 范围内。 最后，我们使用模运算验证 A 位于级数内部。 

微妙的部分是检查的顺序。 我们总是在构造 x 之前测试整除性，并且在检查包含性之前验证边界。 这可以防止对大数进行不必要的算术，并避免中间值无效时的错误计数。 

## 工作示例

 考虑输入 5 15 1 10。我们测试可能的长度和差异。 对于 n = 2 且 d = 5，求和条件给出 x = 5，产生 [5, 10]，其中包含 5 并且总和为 15。对于 n = 3 且 d = 2，我们得到 x = 1，产生 [1, 3, 5]，这是无效的，因为 sum 不是 15，因此被拒绝。 只有与精确总和匹配的配置才能通过过滤。 

| n | d | x| 最后| 包含 A=5 | 有效 |

 | 2 | 5 | 5 | 10 | 10 是的 | 是的 |

现在考虑 5 5 5 5。唯一可能的序列是单个元素 [5]。 这里 n = 1 和 d 无关。 总和条件迫使 x = 5，它位于边界内，并且 A = 5 也被简单地包括在内。 该算法正确地计算出一个进展。 

| n | d | x| 最后| 包含 A=5 | 有效 |

 ## 边缘情况

 一个关键的边缘情况是当级数长度为 1 时。在这种情况下，总和条件强制唯一的元素恰好是 S，并且 A 的包含成为严格的相等检查。 对于输入 5 5 5 5，算法设置 n = 1，计算 x = 5，并立即接受。 

另一个微妙的情况是当差值为 1 时，这会最大化有效放置的数量。 例如，当 A = 5、S = 15、L = 1、R = 10 时，将出现序列 [1, 2, 3, 4, 5]。 该算法正确处理了这个问题，因为 A − x 可以被 d = 1 整除，因此每个位置都是有效的。 

在简单实现中会发生的故障模式是假设 A 必须是第一项或最后一项。 对于输入 5 15 1 10，这会丢失有效序列，例如 [1, 5, 9] 或 [3, 5, 7]。 该算法通过模运算检查所有可能的位置而不是固定 A 的角色来避免这种情况。
