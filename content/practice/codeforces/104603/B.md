 ## 解决方案
 ## 问题理解

 我们被赋予了一个$N \times N$网格，其中每个单元格要么可用（黑色），要么禁止（白色）。 任务是放置尽可能多的水平多米诺骨牌，其中每个多米诺骨牌恰好覆盖同一行中的两个相邻单元格。 仅当两个被覆盖的单元都是黑色时，多米诺骨牌才有效，并且任何单元都不能属于多于一个多米诺骨牌。 

因此，该问题相当于在所有行中选择尽可能多的不相交的水平相邻黑色单元对。 

网格大小最多为$50 \times 50$，所以最多有 2500 个单元格。 这会立即排除对展示位置的任何指数搜索。 即使是对放置或不放置多米诺骨牌的所有方法进行天真的回溯也会太大，因为单独的每一行都可以生成指数选择。 

一个关键的观察是行是独立的：多米诺骨牌永远不会交叉行。 因此，问题分解为解决每一行的相同子问题并对结果求和。 

一个微妙的边缘情况是具有交替模式的行，如果不小心，贪婪配对可能会失败。 例如，在像这样的行中`NNNN`，一个天真的贪婪的从左到右的配对正确地产生了 2 个多米诺骨牌，但是在像这样的模式中`NNNNN`，如果实现不严格执行不相交使用，粗心的跳过规则可能会误算。 另一种情况是有孤立的黑人的行，例如`NBNBN`，尽管有许多黑色单元格，但仍无法放置多米诺骨牌。 

## 方法

 强力解释将考虑水平多米诺骨牌在网格上的每种可能的放置方式。 这可以看作是选择相邻黑色单元之间的边，确保没有顶点被重用。 这正是图上的最大匹配问题，其中每个单元格都是一个节点，并且同一行中的水平邻居之间存在边。 

一个简单的解决方案会尝试所有边子集并检查有效性。 单元格数量多达 2500 个，即使限制在水平边缘也可以粗略得出$O(N^2)$边和边的子集呈指数增长，大约$2^{O(N^2)}$，这是完全不可行的。 

关键的简化是结构性的：边缘只存在于$(i, j)$和$(i, j+1)$。 这意味着每一行都是一个由白色单元格分隔的独立路径图。 在路径图中，最大匹配是微不足道的：从左到右贪婪地匹配连续的可用顶点。 

这将问题从全局匹配问题简化为$N$独立的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有多米诺骨牌子集进行暴力破解 |$O(2^{N^2})$|$O(N^2)$| 太慢了|
 | 逐行贪婪配对 |$O(N^2)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 逐行处理网格，因为多米诺骨牌永远不会跨越行边界。 这确保每个决策都局限于独立的子问题。 
2. 对于每一行，从左到右扫描，同时跟踪前一个单元格是否可以配对。 当我们看到两个连续的黑色单元格时，我们才会尝试配对。 
3. 当我们遇到黑色单元格时，检查下一个单元格。 如果它也是黑色的，则放置一个多米诺骨牌覆盖两者并跳过下一个位置。 这保证了没有重叠。 
4. 如果下一个单元格是白色的或者我们位于行的末尾，则我们无法从该位置开始放置多米诺骨牌，因此我们向前移动。 
5. 将每行放置的多米诺骨牌数量累加到全局总数中。 

### 为什么它有效

 每行形成一条路径，其中顶点是单元，边仅存在于连续的黑色单元之间。 路径图中不相交边的最大数量是通过尽可能贪婪地选择最左边的可用边来获得的。 任何跳过有效对的替代解决方案都不会增加未来的选项，因为跳过只会留下相同或更少的进一步右侧匹配的机会。 这表明贪婪构造总是为每行产生最佳匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    ans = 0

    for _ in range(n):
        row = input().strip()
        i = 0
        while i < n:
            if row[i] == 'N':
                if i + 1 < n and row[i + 1] == 'N':
                    ans += 1
                    i += 2
                else:
                    i += 1
            else:
                i += 1

    print(ans)

if __name__ == "__main__":
    solve()
```实现直接遵循逐行贪婪策略。 我们维护一个索引`i`并根据我们是否形成多米诺骨牌来向前推进。 当连续两个`N`出现单元格时，我们立即消耗两者并前进 2 以强制不相交使用。 否则，我们前进 1。 

关键的微妙之处在于我们永远不会重新考虑曾经跳过或使用的单元格。 这就是保证正确性的原因：每个单元最多参与一个决策，因此不可能出现重叠。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 像这样的单细胞网格`N`没有可能的多米诺骨牌放置。 The algorithm processes the row, sees no valid pair, and returns 0 correctly.

 像这样的全黑行`NNNNN`通过重复匹配索引 (0,1) 和 (2,3) 处的对来处理，留下一个剩余单元格。 扫描自然会跳过剩余部分，产生 2 个多米诺骨牌。 

像这样的交替模式`NBNBN`永远不会触发有效的相邻对，因此该算法永远不会增加计数器，从而正确地产生 0。
