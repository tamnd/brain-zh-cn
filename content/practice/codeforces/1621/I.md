 ## 解决方案
 ## 问题理解

 我们得到一个数组`A`长度`n`并要求对其反复应用复杂的变换。 这种转变称为`op`，通过重复查找长度递增的字典顺序最小的子数组并用该子数组更新数组的最后一个元素，从旧数组构建一个新数组。 表演后`op`在数组上，我们获取序列中的下一个数组，并要求我们回答有关该数组序列中元素的查询。 

关键的挑战是`n`可以大到10^5，查询次数`q`最多可达 10^6。 显式构建所有数组的简单方法将需要每个应用程序执行 O(n^2) 次操作`op`如果重复应用则为 O(n^3)，这太慢了。 相反，我们需要一种方法来有效地计算多次转换后的数组状态并回答查询，而无需显式模拟所有操作。 

在识别字典顺序上最小的子数组时出现了一个微妙的问题：单独挑选最小的元素是不够的。 考虑`[2, 1, 3, 1]`。 长度为 2 的最小子数组是`[1, 1]`而不是`[1, 3]`。 仅查看第一个最小元素或未能考虑字典顺序中的关系的粗心实现会产生错误的结果。 另一种边缘情况是当所有元素都相等时，在这种情况下序列立即稳定。 

## 方法

 蛮力方法很简单：模拟转换`op`步步。 对于每个`op`在一个大小的数组上`n`，对于每个长度`i = 1..n`，找到长度按字典顺序最小的子数组`i`并更新最后的`i`元素。 这需要扫描所有`n-i+1`每个长度的子数组`i`，给出单个操作总共 O(n^3) 次操作`op`。 重复`op` `n`时代使得这不可行`n`大约10^5。 

关键的见解是，经过多次应用`op`，序列稳定：一旦数字到达数组末尾，因为它是最小子数组的一部分，它就不能再向左移动。 这使我们能够为每个位置预先计算它最终将保持的最小值，以及达到它需要多少次操作。 的结构`op`是单调的，因为一旦选择了最小的前缀或后缀，它就只会向前传播。 

我们可以根据位置和等级对数组进行编码，然后使用单调堆栈和后缀最小值的组合来计算每个位置停止变化的最早操作。 这会将模拟减少到 O(n log n) 或 O(n)，具体取决于实现。 然后，通过将查询索引和操作编号映射到预先计算的值，可以在 O(1) 内回答查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了 |
 | 预计算+后缀传播| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取数组`A`和查询数量`q`。 初始化一个数组`final_state`尺寸的`n`重复应用后存储最终稳定的阵列`op`。 
2.使用单调栈来计算，对于每个位置`i`，第一个操作之后`A[i]`保证是最后的一部分`i`一些最小子数组中的元素。 堆栈确保我们始终有效地知道下一个较小的元素。 
3. 计算后缀最小值`A`对于每个长度`i`。 这表示将出现在最后位置的最小元素`D_i`一次申请后`op`。 
4. 向前传播这些后缀最小值。 对于职位`i`，它最终保持的最小值是后缀最小值中的最小值`i`到`n`。 这给了我们稳定的数组`final_state`。 
5. 回答每个问题`(i, j)`通过注意到之后`i >= j`, 位置处的元素`j`已经稳定下来了。 如果`i < j`，该元素仍为`A[j]`。 因此答案是`min(A[j], final_state[j])`具有适当的索引。 

为什么它有效：不变的是`op`从不向左移动值，仅将最小值传播到右侧。 因此，一旦某个值达到后缀中的最小位置，它就会保留在那里以进行所有进一步的转换。 这保证了预计算最终稳定的数组足以满足所有查询。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
A = list(map(int, input().split()))
q = int(input())

# compute final stabilized array
final_state = A[:]
for i in range(n-2, -1, -1):
    final_state[i] = min(final_state[i], final_state[i+1])

# answer queries
for _ in range(q):
    op_idx, pos = map(int, input().split())
    pos -= 1
    # if operation index >= position, the element has stabilized
    if op_idx >= pos + 1:
        print(final_state[pos])
    else:
        print(A[pos])
```第一个循环计算每个位置的后缀最小值。 这确保每个元素存储在任何应用程序中都会成为的最小值`op`。 在回答查询时，我们只需要检查操作次数是否足以使元素稳定下来。 仔细的索引在这里很重要：Python 中的数组是从 0 开始的，但查询是从 1 开始的。
