 ## 解决方案
 ## 问题理解

 我们最多有一个非常小的棋盘$8 \times 8$。 任务不是计算复杂的值，而是找到骑士在棋盘内没有合法移动的任何单元格。 如果存在这样的单元格，我们必须输出其中一个； 否则我们可以输出板上的任何坐标。 

关键对象是标准的骑士动作：从牢房中$(r, c)$，一个马试图跳到该形式的八个可能的偏移量$(\pm 2, \pm 1)$和$(\pm 1, \pm 2)$。 如果这八个目的地中没有一个位于棋盘内，则该单元称为隔离单元。 

由于两个维度的边界为$8$，细胞总数最多为$64$。 这立即将问题置于直接模拟不仅足够而且概念上比任何优化更清晰的状态。 任何检查每个单元并检查最多八次移动的方法都会在每个测试用例的恒定时间内运行。 

当电路板非常小时，就会出现微妙的边缘情况。 上一个$1 \times m$或者$n \times 1$棋盘上，每个单元格都是隔离的，因为马的每个动作都会离开棋盘。 上一个$2 \times 2$板，同样的情况发生。 在较大的板上，例如$3 \times 3$，一些中心单元变得孤立，而边界单元仍然允许至少一次有效的移动，具体取决于几何形状。 该定义纯粹是局部的，因此不需要考虑全局约束或奇偶校验问题。 

## 方法

 暴力解决方案检查每个单元并尝试所有八个骑士动作。 如果至少有一个动作留在网格内，则该单元格不是孤立的。 如果没有，我们立即退货。 由于最多有$64$细胞和$8$每个单元的方向，每个测试用例的工作仅限于几百个操作，这非常快。 

由于董事会太小，因此没有更深层次的结构可供利用。 进一步思考的唯一原因是认识到该条件纯粹是几何和局部的：隔离仅取决于周围是否存在$3 \times 3$和$5 \times 5$邻里存在于界限之内。 这意味着我们不需要预处理或搜索。 

最优解与暴力法相同，只是直接实现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$每次测试|$O(1)$| 已接受 |
 | 最佳 |$O(nm)$每次测试|$O(1)$| 已接受 |

 ## 算法演练

 我们独立处理每个测试用例并扫描电路板。 

1. 迭代每个单元格$(r, c)$在$n \times m$网格。 每个细胞都是被隔离的候选细胞。 
2. 对于固定单元格，检查所有八个骑士动作。 每次移动都会产生一个目标细胞$(r + dr, c + dc)$，然后我们验证它是否仍在棋盘边界内$1 \le r \le n$,$1 \le c \le m$。 
3. 如果至少一项移动有效，则将该单元格标记为非隔离并继续进行下一项。 这确保我们只接受有效骑士转换为零的单元格。 
4. 如果我们发现一个单元格的八个动作都无效，我们立即输出它并停止处理当前的测试用例。 
5.如果扫描完所有位置都没有找到孤立的细胞，则输出任意一个细胞，例如$(1, 1)$。 

关键思想是，隔离的定义完全是本地的，并且仅取决于马移动可到达的直接邻域，因此详尽的检查不会错过任何有效的候选者。 

### 为什么它有效

 当所有八个骑士偏移都离开网格时，单元格就会被隔离。 该算法直接测试该条件。 由于每个单元格都是独立检查的，并且枚举了所有可能的移动，因此当且仅当它满足定义时，单元格才会被报告为孤立的。 如果不存在这样的单元格，则问题允许返回任何坐标，因此在所有情况下都保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    moves = [(2, 1), (2, -1), (-2, 1), (-2, -1),
             (1, 2), (1, -2), (-1, 2), (-1, -2)]
    
    for _ in range(t):
        n, m = map(int, input().split())
        
        found = False
        for r in range(1, n + 1):
            for c in range(1, m + 1):
                isolated = True
                
                for dr, dc in moves:
                    nr, nc = r + dr, c + dc
                    if 1 <= nr <= n and 1 <= nc <= m:
                        isolated = False
                        break
                
                if isolated:
                    print(r, c)
                    found = True
                    break
            
            if found:
                break
        
        if not found:
            print(1, 1)

if __name__ == "__main__":
    solve()
```实现实际上遵循算法。 唯一的微妙之处是提前终止：一旦发现孤立的细胞，我们就停止进一步扫描，因为任何有效的答案都是可以接受的。 动作清单是固定且详尽的，无需案例分析即可确保正确性。 

## 工作示例

 考虑一个$3 \times 3$木板。 我们检查中心单元格$(2, 2)$。 骑士的每一次移动都会超出网格，因此它会立即被归类为孤立的。 算法在迭代过程中一旦遇到该单元格就会停止。

 | --- | --- | --- |
 | (1,1) | 是的 | 没有 |
 | (1,2) | 是的 | 没有 |
 | (1,3) | 是的 | 没有 |
 | (2,2) | 没有 | 是的 |

 这证实了该算法在这种情况下正确识别了唯一的孤立位置。 

现在考虑一个$2 \times 3$木板。 每个单元格内至少有一个骑士动作，因此不存在孤立的单元格。 该算法扫描所有位置，找到没有孤立的位置，然后输出$(1,1)$。 

| 细胞| 有效的骑士动作存在 | 隔离|
 | --- | --- | --- |
 | (1,1) | 是的 | 没有 |
 | (1,2) | 是的 | 没有 |
 | (1,3) | 是的 | 没有 |
 | (2,1) | 是的 | 没有 |

 这演示了隔离集为空时的回退行为。

 ## 边缘情况

 上一个$1 \times m$或者$n \times 1$在棋盘上，每个单元格都是孤立的，因为所有骑士的移动都会立即超出至少一个坐标的范围。 该算法处理此问题是因为对于每个单元格，所有八个候选移动均未通过边界检查，因此遇到的第一个单元格将作为孤立的单元格返回。 

上一个$2 \times 2$棋盘上，同样的逻辑适用，但现在以更密集的形式：每个骑士的移动都会由于高度或宽度不足而离开网格。 扫描会将第一个细胞分类为孤立的并立即停止。 

在较大的板上，例如$3 \times 3$，只有中心单元格内没有有效的骑士移动。 该算法在迭代期间到达它并正确地将其识别为隔离的，因为每个偏移量都会超出范围。
