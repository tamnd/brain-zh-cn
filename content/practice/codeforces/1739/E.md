 ## 解决方案
 ## 问题理解

 我们有一个走廊，表示为两排$n$列，其中每个单元格要么是干净的 (0)，要么是脏的 (1)。 清洁机器人从左上角的单元格开始$(1,1)$，保证是干净的。 机器人贪婪地移动：每一步，它都会选择曼哈顿距离最近的脏单元并清洁它。 如果两个或多个脏单元以最近距离连接，就会出现问题 - 在这种情况下机器人会发生故障。 我们的任务是在启动机器人之前决定需要手动清洁哪些脏单元，以便它可以清洁剩余的单元而不会遇到平局。 目标是为机器人留下尽可能多的脏单元，同时避免故障。 

列数$n$可以达到$2 \cdot 10^5$，意味着任何$O(n^2)$的方法是不可行的。 我们只能负担线性或线性算数时间算法。 机器人检查到所有脏单元的所有距离的简单模拟将是$O(n^2)$，这太慢了。 

不明显的边缘情况包括两行中的脏单元垂直对齐的情况。 例如，考虑：```
2
01
11
```如果我们把所有的细胞都弄脏，机器人就会$(1,1)$会看到两个$(1,2)$和$(2,1)$距离 1。这会导致故障。 粗心的方法可能会忽略相对位置，并错误地将所有脏单元格视为可以安全离开。 

当一行完全干净（除了最后一个单元格之外）时，会发生另一种棘手的情况。 机器人可能需要遍历对面的行以避免平局，因此解决方案必须考虑两行中脏单元格的相对位置，而不仅仅是脏单元格的数量。 

## 方法

 蛮力方法会尝试让脏细胞的每个子集保持不变并模拟机器人的运动。 对于每次模拟，机器人都会在每一步找到最近的脏单元，$O(n^2)$最坏情况下的时间。 这是正确的，但不可行$n = 2 \cdot 10^5$。 

关键的见解来自于观察机器人的行为。 仅当两个脏单元与其当前位置等距时，它才会发生故障。 因为走廊只有两行，所以我们可以从右到左处理列，跟踪每行中最远的剩余脏单元。 如果我们知道两行中最远的脏单元格，我们就可以计算机器人在粘在一行时必须行进的最大距离。 这减少了为每行维护两个运行“尾部”并计算每个可能的起始配置的最小总行程的问题。 本质上，我们可以根据哪一行的尾部更远，在每一列贪婪地决定手动清理哪个脏单元。 这允许线性$O(n)$使用前缀/后缀跟踪的解决方案，无需模拟每个机器人运动。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将走廊输入转换为代表第 1 行和第 2 行的两个数组。将字符“0”和“1”替换为整数以便于计算。 
2. 预先计算两个后缀数组：`suff1[i]`和`suff2[i]`。`suff1[i]`是第 1 行中距列最远的脏单元格$i$到$n$。 相似地，`suff2[i]`是第 2 行。如果右侧没有脏单元格，则该值为$-1$。 这有助于快速找到每行中的下一个脏单元，而无需重复扫描所有列。 
3. 初始化`ans`作为一个大值。 这将跟踪我们需要手动清洁以避免故障的最小单元数量。 我们还追踪`cur`作为机器人从左侧开始迄今为止行驶的最大距离。 
4. 从左到右处理每一列。 在列$i$，我们有两个选择：先转到第 1 行或第 2 行。 然后，机器人将继续沿着相对行中剩余的脏单元格移动。 对于每个选择，考虑曼哈顿距离和后缀数组，计算机器人必须覆盖的距离才能到达两行中最远的剩余脏单元。 更新`ans`以最小的距离。 
5.处理完所有列后，减去`ans`脏细胞总数。 这给出了可以保持脏状态的最大数量的单元，同时确保机器人不会发生故障。 

不变的是，在每一列，我们总是知道两行中最远的脏单元格。 通过基于后缀数组做出决策，我们保证机器人永远不会面临平局，因为我们通过从右到左贪婪地手动清理来消除潜在的冲突。 这确保了可以按安全顺序清洁剩余的脏电池。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    row1 = list(map(int, list(input().strip())))
    row2 = list(map(int, list(input().strip())))
    
    total_dirty = sum(row1) + sum(row2)
    
    suff1 = [-1] * (n + 2)
    suff2 = [-1] * (n + 2)
    
    for i in range(n - 1, -1, -1):
        suff1[i] = suff1[i + 1]
        suff2[i] = suff2[i + 1]
        if row1[i]:
            suff1[i] = i
        if row2[i]:
            suff2[i] = i
    
    res = total_dirty
    left = 0
    right1 = suff1[0]
    right2 = suff2[0]
    
    cur = 0
    for i in range(n):
        cur = max(cur, right1 if i % 2 == 0 else right2)
        remain = max((right1 - i) if right1 != -1 else 0,
                     (right2 - i) if right2 != -1 else 0)
        res = min(res, total_dirty - remain)
    
    print(res)

solve()
```该解决方案首先将输入转换为整数，计算后缀数组以查找最远的脏单元格，然后从左到右迭代以计算可以保留的脏单元格的最大数量。 后缀数组避免了重新扫描列，循环逻辑确保关系永远不会被忽视。
