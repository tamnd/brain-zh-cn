 ## 解决方案
 ## 问题理解

 我们被要求找到给定整数 _n_ 周围最接近的素数。 具体来说，我们需要两个数_a_和_b_，使得_a_≤_n_≤_b_并且_a_和_b_都是素数。 在包含 _n_ 的所有素数区间中，优选长度 _b - a_ 最小的素数区间。 如果多个间隔的长度相等，则问题无法区分，因此返回任何最短间隔都是有效的。 

输入是 2 到 10,000 之间的单个整数 _n_。 这个界限足够小，可以直接搜索 _n_ 周围的素数。 每个输出都保证存在，因为在一定范围内始终存在小于或等于 _n_ 的素数和大于或等于 _n_ 的素数（对于最大 10,000 的数字，连续素数之间的差距永远不会超过 100）。 

边缘情况包括 _n_ 本身是素数，或者 _n_ 非常接近最小素数 (2)。 例如，如果 _n_ = 2，则最小线段为 [2,3]。 粗心的实现可能会尝试搜索低于 2 的值，但会失败或返回无效的负数。 另一个微妙的情况是素数间隙，例如在 89 左右，下一个素数是 97。天真的差一搜索可能会错过上限。 

## 方法

 最明显的方法是蛮力：从 _n_ 开始，向下扫描找到最近的较小或等于的素数，然后向上扫描找到最近的较大或等于的素数。 两种搜索与到最近素数的距离都是线性的。 

这是可行的，因为数字很小并且素数也不是太稀疏。 对于 _n_ = 10,000，最近的较低素数是 9973，相距 27 步，最近的较高素数是 10,007，相距 7 步。 对这些扫描中的每个数字进行简单的试除法需要检查其平方根的整除性，每个候选值大约为 O(√n)。 将此值乘以最坏情况下的搜索距离（约 100）最多可进行 1,000 次操作，完全在 2 秒的限制之内。 

效率的关键洞察是使用埃拉托斯特尼筛法预先计算所有素数，直至达到某个合理的最大值。 一旦我们拥有了最多 10,000 个素数的列表，找到最近的较低和较高素数就变成了在排序列表中进行小型线性扫描或二分搜索的问题。 这消除了重复的可分性检查并简化了边缘情况处理。 

蛮力方法简单且正确，但基于筛选的方法更干净、更快。 使用筛子还可以保证我们永远不会错过素数，并使处理 _n_ 等于素数变得简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(√n * 间隙) | O(1) | O(1) | 可接受但冗长|
 | 筛选+搜索| O(n log log n + log n) | O(n log log n + log n) | O(n) | 干净，接受|

 ## 算法演练

 1. 创建布尔数组`is_prime`表示比 _n_ 稍高的数字，最初将所有 ≥ 2 的数字标记为素数。 使用埃拉托色尼筛法将每个素数的倍数标记为非素数。 筛子确保`is_prime[x]`是`True`当且仅当 _x_ 是素数。 
2. 要找到下界 _a_，请从 _n_ 开始向下扫描，直到`is_prime[a]`是`True`。 这会找到小于或等于 _n_ 的最大素数。 
3. 要找到上限 _b_，请从 _n_ 开始向上扫描，直到`is_prime[b]`是`True`。 这会找到大于或等于 _n_ 的最小素数。 
4. 输出_a_和_b_。 这对保证存在，因为筛子覆盖了必要的范围，并且扫描保证了与 _n_ 的最小距离。 

为什么有效：筛子确保我们永远不会错误地识别素数。 向下扫描 _a_ 并向上扫描 _b_ 可以保证 _n_ 周围最接近的素数，从而产生最小的线段长度。 该算法很快终止，因为低于 10,000 的素数间隙总是很小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAX_N = 11000  # Slightly larger than the max n to handle upper bound

# Sieve of Eratosthenes
is_prime = [True] * (MAX_N + 1)
is_prime[0] = is_prime[1] = False
for i in range(2, int(MAX_N**0.5) + 1):
    if is_prime[i]:
        for j in range(i*i, MAX_N + 1, i):
            is_prime[j] = False

n = int(input())

# Find closest prime <= n
a = n
while not is_prime[a]:
    a -= 1

# Find closest prime >= n
b = n
while not is_prime[b]:
    b += 1

print(a, b)
```筛子预计算确保`is_prime`准确反映 11,000 以内的所有数字的素数。 向下和向上扫描处理边缘情况，包括 _n_ 本身为素数的情况。 选择稍高的 MAX_N 可确保向上搜索永远不会超出数组范围。 循环是安全的，因为 11,000 以下的连续素数之间的最大差距很小。

 ## 边缘情况

 对于 n = 2，向下扫描不能低于 2。算法立即将 2 识别为素数，因此`a = 2`。 类似地，向上扫描会发现 2，产生 [2,2]。 对于 n = 10,000，向下扫描找到 9973，向上扫描找到 10,007。 通过使用 MAX_N = 11,000，我们可以避免索引越界错误并正确处理上限附近罕见的素数间隙。 这些示例证实该算法能够一致地处理最小和最大输入、n 处的素数以及正常情况。
