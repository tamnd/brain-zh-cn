 ## 解决方案
 ## 问题理解

 我们被要求计算给定整数的阶乘$n$。 阶乘是所有正整数的乘积$n$，所以对于$n = 3$，阶乘是$1 \times 2 \times 3 = 6$。 输入是单个整数，输出是该乘积的单个整数结果。 

约束非常严格：$n$保证在 1 到 10 之间。这个值非常小，大大简化了问题。 即使是在循环中将数字相乘的简单实现也非常快，因为计算$10!$仅涉及 10 次乘法，远低于对性能的任何关注。 内存使用量可以忽略不计，因为 10 的阶乘很容易符合标准 32 位整数。 

尽管很简单，但我们应该小心边界情况。 最小的输入是$n = 1$，它应该返回 1。任何错误地初始化产品变量或在 2 而不是 1 处启动循环的实现都可能会错误计算。 同样，最大的输入是$n = 10$，即$3628800$。 这足够小，可以容纳标准整数，但如果问题扩大，简单的实现可能会溢出。 

## 方法

 由于输入范围很小，暴力方法也是此处的最佳方法。 它包括初始化一个变量来保存乘积，然后将其迭代地乘以从 1 到 的每个整数$n$。 这是可行的，因为乘法是结合律和交换律的，所以我们可以安全地以任何顺序构建乘积。 

这里不需要记忆或递归，因为数字很小，堆栈深度和重复计算都不是问题。 人们也可以递归地实现阶乘，定义$factorial(n) = n \times factorial(n-1)$与基本情况$factorial(1) = 1$。 迭代和递归方法计算出完全相同的结果，但迭代方法避免了递归调用的微小开销，这对于如此小的数字来说是微不足道的，但仍然是很好的实践。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 迭代| O(n) | O(1) | O(1) | 已接受 |
 | 递归| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取输入的整数$n$。 这是我们需要计算其阶乘的数字。 
2. 初始化变量`fact`到 1. 这将保存累积乘积。 从 1 开始确保正确处理$n = 1$。 
3. 循环整数$i$从 2 到$n$包容性。 乘`fact`经过$i$在每次迭代时。 从 2 开始是一种优化，因为乘以 1 不会改变结果。 
4. 循环结束后，`fact`包含的阶乘$n$。 打印该值。 

为什么有效：每次迭代都会成倍增加`fact`按顺序排列下一个整数。 到循环结束时，`fact`正是$1 \times 2 \times \dots \times n$。 不变量是处理整数后$i$,`fact`等于的阶乘$i$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
fact = 1
for i in range(2, n + 1):
    fact *= i
print(fact)
```我们使用快速 I/O 读取整数以匹配竞争性编程约定，尽管对于如此小的输入，标准`input()`也还好。 我们从 2 开始循环，以避免不必要的乘以 1。最终打印输出阶乘。 不需要特殊处理，因为 Python 整数可以自动增长超出 32 位限制。

 ## 边缘情况

 对于$n = 1$，从2到循环$n$不执行，离开`fact = 1`。 这符合以下定义$1!$。 为了$n = 10$，循环执行了 9 次乘法，结果是`fact = 3628800`，这是正确的并且在整数限制内。 1 到 10 之间的所有其他输入的行为类似，并且不存在隐藏的故障模式。
