 ## 解决方案
 ## 问题理解

 我们需要决定在一组简化的规则下给定的字符串是否可以被解释为有效的域名。 

该字符串只能包含小写英文字母、数字和点。 点将字符串分成段。 字符串不能以点开头或以点结尾，并且两个点不能连续出现。 按点分割后，最后一段的长度必须恰好为 2 或 3。 

输入长度最多为 100，这个长度很小。 即使是低效的解决方案也能在时限内顺利运行。 真正的挑战不是优化，而是仔细实施每条规则，不遗漏极端情况。 

一个常见的错误是仅检查允许的字符，而忘记了涉及点的结构约束。 例如：

 输入：```
abc..com
```正确输出：```
NO
```该字符串仅使用有效字符，但连续的点会创建一个空段，这是禁止的。 

另一个简单的错误是忘记域不能以点开头或结尾。 

输入：```
.google
```正确输出：```
NO
```粗心的基于拆分的解决方案可能会产生`["", "google"]`并一不小心就接受了。 

最后一个段长度限制也会导致微妙的失败。 

输入：```
abc.c
```正确输出：```
NO
```最后一段的长度为 1，但仅允许长度 2 和 3。 

同样：

 输入：```
abc.comm
```正确输出：```
NO
```最后一段的长度是4。 

另一个陷阱是大写字母。 该语句仅允许小写字母。 

输入：```
Codeforces.com
```正确输出：```
NO
```解决方案使用`isalnum()`直接会错误地接受大写字符。 

## 方法

 最直接的暴力想法就是精确模拟定义。 我们逐个字符扫描字符串并独立验证每个规则。 

我们可以首先检查每个字符是否属于允许的集合。 然后我们验证字符串既不以点开头也不以点结尾。 接下来我们检查相邻的字符对是否不包含两个点。 最后，我们按点分割字符串并检查最后一段的长度。 

这已经以线性时间运行，因为每次传递都接触字符串一次。 当长度最多为 100 时，即使重复扫描字符串也可以忽略不计。 

另一种可能的强力解释是生成所有可能的方法将字符串拆分为域段并手动检查有效性。 这种方法变得不必要的复杂，并且随着职位数量呈指数级增长。 尽管约束足够小，仍然可以通过，但问题结构提供了一条更清晰的路线。 

关键的观察是每条规则都是本地的。 允许的字符取决于各个位置，连续点有效性仅取决于相邻字符，后缀条件仅取决于最终段。 不需要全局搜索或解析。 一次从左到右的扫描与一次最终后缀检查相结合即可完全确定有效性。 

因此，最佳解决方案就是直接验证器。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 详尽的分割/搜索 | O(2^n) | O(2^n) | O(n) | 不必要的缓慢 |
 | 直接验证扫描| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取输入字符串。 
2. 检查字符串是否以点开头或结尾。 

有效域的开头或结尾不能有空段。 
3. 扫描字符串中的每个字符。 

如果字符不是小写字母、数字或点，则立即拒绝该字符串。 
4. 在同一次扫描期间，检查相邻字符。 

如果两个连续字符都是点，则拒绝该字符串，因为这会创建一个空段。 
5. 使用点作为分隔符分割字符串。 
6. 取出最后一段并检查其长度。 

长度必须为 2 或 3。 
7. 如果每项检查都通过，则打印`"YES"`。 否则打印`"NO"`。 

### 为什么它有效

 该算法直接对有效域定义中的每个条件进行编码。 字符扫描保证不会出现禁止的符号。 边界检查可防止开头或结尾出现空段。 连续点检查可防止中间出现空段。 按点分割会暴露最终的片段，因此可以准确验证其长度限制。 由于每条规则都经过明确检查，并且当规则失败时会立即拒绝，因此该算法完全接受有效域名并拒绝所有无效域名。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    if s[0] == '.' or s[-1] == '.':
        print("NO")
        return

    for i, ch in enumerate(s):
        valid = (
            ('a' <= ch <= 'z') or
            ('0' <= ch <= '9') or
            ch == '.'
        )

        if not valid:
            print("NO")
            return

        if i > 0 and s[i] == '.' and s[i - 1] == '.':
            print("NO")
            return

    parts = s.split('.')
    last_len = len(parts[-1])

    if last_len == 2 or last_len == 3:
        print("YES")
    else:
        print("NO")

solve()
```第一个条件立即处理边界点。 这可以避免分割后意外接受空的前导或尾随段。 

主循环将两次检查合并为一次传递。 首先，它使用显式范围比较而不是像这样的帮助器来验证字符`isalnum()`。 这很重要，因为`isalnum()`会错误地允许大写字母。 

仅当以下情况时才开始邻接检查：`i > 0`，防止对第一个字符的越界访问。 

验证后，字符串将被点分割。 由于我们已经拒绝了连续点和边界点，因此每个段都保证非空。 唯一剩下的条件是最后一个段的大小。 

该实现从不使用分割结果之外的额外数据结构，并且每个操作在字符串长度上都是线性的。

 ## 边缘情况

 考虑输入：```
.google
```该算法立即检查第一个字符并发现它是一个点。 它在发生任何拆分之前拒绝字符串。 这可以防止意外接受空的第一段。 

现在考虑：```
abc..com
```在扫描过程中，当算法到达第二个点时，它将与前一个字符进行比较并检测`".."`。 该字符串立即被拒绝。 任何后续处理都无法覆盖此失败。 

对于输入：```
abc.c
```所有字符和点结构检查均成功。 分割后，最终的片段是`"c"`，其长度为 1。由于仅接受长度 2 和 3，因此算法打印`"NO"`。 

最后，考虑：```
Codeforces.com
```当扫描第一个字符时`'C'`，小写范围检查失败，因为`'C'`在外面`'a'`到`'z'`。 该算法立即拒绝该字符串，正确执行仅使用小写字母的规则。
