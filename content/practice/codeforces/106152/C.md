 ## 解决方案
 ## 问题理解

 我们有一系列食品，每种食品都有一个需求值。 对于每一项，我们可以选择接受或跳过。 

限制是我们不能拿两个相邻的物品。 如果我们选择项目`i`，然后项`i+1`必须被跳过。 

任务是找到在此规则下可获得的最大可能的总意愿。 输入包括食品的数量及其期望值。 输出是一个整数，即可实现的最大总期望值。 

约束条件`n ≤ 10000`足够小以至于`O(n²)`在最坏的情况下，该解决方案已经执行了大约 1 亿次操作，这是不必要的昂贵。 由于该问题仅询问相邻位置，因此强烈建议采用动态规划解决方案，其中每个位置取决于恒定数量的先前位置。 一个`O(n)`解决方案是自然的目标。 

一个常见的错误是贪婪地从每个相邻对中获取较大的值。 本地选择并不一定会带来最佳的全球答案。 

考虑：```
3
2 1 2
```正确答案是：```
4
```我们采取第一项和第三项。 仅查看邻近值的贪婪策略可能会错过这种组合。 

另一种边缘情况是只有一个项目时。```
1
42
```答案是：```
42
```盲目访问的DP实现`dp[i-2]`如果不处理小索引可能会在这里失败。 

当许多值为零时，会出现第三种边缘情况。```
5
0 0 0 0 0
```答案是：```
0
```该算法必须正确处理不采取任何措施实际上是最佳的情况。 

## 方法

 蛮力方法是检查食品的每个子集，检查它是否包含相邻的选定位置，并计算其合意性总和。 这是正确的，因为它明确考虑了每个有效的选择。 

问题是有`2^n`子集。 即使是为了`n = 50`，这已经远远超出了可以及时计算的范围，而实际的极限是`n = 10000`。 

关键的观察是，当我们站在这个位置时`i`，只有两种有意义的可能性。 

要么我们跳过项目`i`，在这种情况下，最佳答案为`i`正是最佳答案`i-1`。 

或者我们拿物品`i`，在这种情况下项目`i-1`不能被采取。 最佳可实现值成为最佳答案`i-2`加上项目的可取性`i`。 

这意味着位置决定`i`仅取决于两个先前计算的状态。 该结构正是动态规划的设计目的。 

让`dp[i]`表示使用第一个可获得的最大意愿`i`项目。 

然后：```
dp[i] = max(
    dp[i-1],
    dp[i-2] + value[i]
)
```每个状态都计算一次，给出线性时间解。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(1) | O(1) | 太慢了 |
 | 最佳DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`和期望值。 
2. 处理基本情况`n = 1`通过返回唯一的值。 
3. 创建一个DP数组，其中`dp[i]`存储从第一个获得的最大意愿`i`项目。 
4. Set`dp[0] = 0`，代表空前缀。 
5. 设置`dp[1] = value[0]`，因为只有一件物品，最好的选择就是拿走它。 
6. For every position`i`从`2`到`n`，计算：```
dp[i] = max(
    dp[i-1],
    dp[i-2] + value[i-1]
)
```第一个选项跳过当前项目。 第二个选项将其与至少早一个位置结束的最佳有效解决方案相结合。 
7. 输出`dp[n]`。 

### 为什么它有效

 不变的是`dp[i]`始终存储第一个的最佳答案`i`项目。 

对于`i`第一项，每个有效的解决方案都属于两个组之一。 

要么该项目未被选择，赋予价值`dp[i-1]`，或者被选择，强制项目`i-1`被排除并赋予价值`dp[i-2] + value[i]`。 

由于这些是唯一的可能性，我们选择其中较大的一个，`dp[i]`是最优的。 通过归纳法，每个状态都是正确的，包括最终答案`dp[n]`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

if n == 1:
    print(a[0])
else:
    dp = [0] * (n + 1)

    dp[0] = 0
    dp[1] = a[0]

    for i in range(2, n + 1):
        dp[i] = max(dp[i - 1], dp[i - 2] + a[i - 1])

    print(dp[n])
```为了方便起见，DP 数组使用从 1 开始的索引。`dp[i]`指的是第一个`i`items，而原始数组仍然从 0 开始。 

过渡使用`a[i - 1]`因为`i`-th DP 状态对应于索引处存储的元素`i - 1`。 

最常见的实现错误是混合数组索引系统并意外使用`a[i]`，这会将每个值移动一位并导致不正确的结果或索引错误。 

初始化也很重要。`dp[0]`表示从空前缀中不获取任何内容，而`dp[1]`代表第一项的最佳答案。

 ## 边缘情况

 考虑：```
1
42
```该算法立即使用基本情况并打印`42`。 不需要 DP 转换。 这可以避免无效访问`dp[-1]`或其他超出范围的位置。 

考虑：```
3
2 1 2
```DP 值变为：```
dp[1] = 2
dp[2] = 2
dp[3] = 4
```该算法正确地组合了第一项和第三项，产生`4`。 

考虑：```
5
0 0 0 0 0
```DP 表保持全零：```
dp = [0, 0, 0, 0, 0, 0]
```输出是`0`，这是可实现的最大愿望。 

这些案例表明，递归可以正确处理小输入、非贪婪最优选择和零值项。
