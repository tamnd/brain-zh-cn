 ## 解决方案
 ## 问题理解

 我们得到一个仅由两个符号组成的字符串：破折号和下划线。 我们可以任意重新排序该字符串。 固定顺序后，字符串表示一个值，定义为等于模式“-_-”的子序列数，这意味着我们选择三个索引 i < j < k，使得这些位置的字符按顺序为破折号、下划线、破折号。 

任务是以最大化存在这样的三元组数量的方式对字符进行排列。 

输入给出了多个独立的测试用例。 对于每个字符，我们只关心字符数，而不是它们的原始顺序，因为完全允许重新排列。 

所有测试用例的总长度最多为 2·10^5 的约束意味着每个测试用例在最坏的情况下需要 O(n) 或 O(n log n) 解决方案。 任何在单个字符串上的二次方都已经太慢了。 

当局部思考布局时，会出现一个微妙的失败案例。 一个天真的想法可能是贪婪地从左到右构建字符串，放置字符以最大化直接贡献。 这失败了，因为破折号的贡献取决于破折号之间下划线的全局分布，而不是局部邻接。 

另一种边缘情况是字符串的破折号少于两个或没有下划线。 例如，如果只有一个破折号，则无论如何排列都不可能存在“-_-”子序列，因此答案必须为零。 假设所有三种字符类型都存在的简单组合公式将错误地产生正值。 

## 方法

 暴力方法会尝试字符串的所有排列，并计算每种排列中“-_-”子序列的数量。 对于长度为 n 的字符串，这是 n！ 排列，并且每个排列以 O(n^2) 或 O(n^3) 计算子序列使得即使 n = 10 也完全不可行。 

关键的观察结果是，只有破折号和下划线的数量才重要，并且最佳排列会将所有相同的字符放置在连续的块中。 一旦我们修复了排列，子序列“-_-”的数量仅取决于每个下划线前后出现的破折号的数量。 

对于任何下划线，如果它前面有 L 破折号，后面有 R 破折号，则它贡献 L·R 子序列。 将所有下划线相加即可得到总值。 

如果我们决定将 x 破折号放在所有下划线的左侧，将剩余的 d − x 破折号放在右侧，则每个下划线贡献 x(d − x)。 如果有 u 下划线，则总计变为 u · x(d − x)。 问题归结为选择 x 来最大化该二次表达式。 

当 x 尽可能接近 d/2 时，表达式 x(d − x) 最大化，因此最佳分割是将破折号均匀分布在所有下划线的两侧。 所有下划线应放在中间，因为将它们混合成多个块只会减少产品结构。

 ## 算法演练

 1. 统计字符串中破折号 d 和下划线 u 的数量。 该排列仅取决于这些计数，而不取决于原始顺序。 
2. 如果 d < 2 或 u = 0，则返回 0。如果破折号少于两个，则无法形成有效的模式“-_-”。 
3. 计算所有下划线左侧和右侧有多少个破折号。 要最大化 x(d − x)，请为一侧设置 x = d // 2，为另一侧设置 d − x。 
4. 计算子序列的总数为 u · x · (d − x)。 
5. 输出该值。

为什么它有效：一旦将下划线放置在单个块中，每个下划线在其左侧和右侧都会看到相同数量的破折号。 任何将下划线移动到不同区域的偏差都会降低对称性并减少至少一个乘法贡献。 最佳结构是通过将破折号分成围绕中间下划线块的两组来完全确定的，这可以同时最大化每个下划线的乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        d = s.count('-')
        u = n - d

        if d < 2 or u == 0:
            print(0)
            continue

        left = d // 2
        right = d - left
        print(u * left * right)

if __name__ == "__main__":
    solve()
```该解决方案将问题简化为仅计算字符。 将破折号分成两半是使用整数除法计算的，它通过将额外的破折号放在一侧自然地处理奇数计数。 

主要的微妙之处在于认识到“块”中的排列结构始终是最佳的，并且没有交错可以改善贡献的乘积形式。

 ## 边缘情况

 当破折号少于两个时，算法立即返回零。 例如，输入`_-`给出 d = 1，u = 1，并且条件 d < 2 触发直接零输出。 任何排列仍然会使每个下划线的至少一侧为空，因此无法形成有效的三元组。 

当没有下划线时，例如`-----`，我们也返回零。 尽管我们可以分割破折号，但该公式会乘以 u（为零），这与不存在“-_-”子序列的事实相匹配。 

当破折号为奇数时，例如 d = 5，则分割变为 2 和 3。这相当于将所有下划线放在中间并尽可能均匀地分布破折号。 对于 u = 1，结果变为 1 · 2 · 3 = 6，并且任何不均匀分割（如 1 和 4）仅产生 4，从而确认楼层分割分割是最佳的。
