 ## 解决方案
 ## 问题理解

 我们得到一个恰好由三个整数组成的序列。 我们可以使用任意两个位置之间的交换来重新排列这三个值，并且在这样做之后，我们希望结果排列满足一个非常特定的模式：第一个元素必须严格大于第二个，第二个元素必须严格小于第三个。 换句话说，中间元素必须是严格的局部最小值。 

由于序列长度固定为 3，因此唯一重要的是我们最终得到的三个数字的排列。 位置之间任意数量的交换都可以生成任意排列，因此该操作根本不限制可达性。 真正的问题纯粹是组合问题：是否存在三个值的多重集的任何排列，使得中间严格小于两端。 

输入大小是恒定的，因此不存在渐近问题。 即使完全枚举所有可能的排列也是微不足道的。 更重要的是正确处理平等。 如果任何两个值相等，那么根据结构的不同，实现严格的不平等可能变得不可能，特别是当重复项占据极端位置时。 

当所有值都相等时，就会出现微妙的边缘情况，例如输入`1 1 1`。 每个排列都是相同的，并且条件`a1 > a2 < a3`永远不可能成立，因为严格的不平等在任何地方都行不通。 另一种情况是两个值相等且第三个值较大时，例如`1 1 2`。 即使我们可以放置`2`在某个地方，相等的对阻止在中间形成严格的最小值。 例如，`2 1 1`失败是因为中间并不严格小于两端，并且任何排列都以破坏严格性的方式保持相等值之一相邻。 

一个天真的错误是假设排序或选择最小值总是有效。 例如，当最小值重复时，以最小值作为中间并任意排列其他值会失败，因为两边都需要严格不平等。 

## 方法

 在只有三个元素的情况下，暴力策略是枚举输入数组的所有六种排列，并检查是否有任何排列满足中间元素严格小于两个邻居的条件。 如果我们找到这样的排列，我们立即输出它。 否则，我们的结论是不可能的。 

这是有效的，因为搜索空间是完整的且大小恒定。 除了这六种安排之外，没有隐藏的结构可以减少或扩大可能性的数量。 

然而，枚举排列是不必要的，因为条件仅取决于三个值之间的排序关系。 关键的观察是中间元素必须是三个元素中唯一的最小值。 如果最小值出现多次，则无法同时将其严格低于其他两个值，因为其中一个邻居将相等，从而违反了严格的不平等。 如果最小值是唯一的，我们总是可以将其放在中间，并按任意顺序排列其余两个值。 

这将问题从排列搜索简化为简单的频率和比较检查。

 ## 算法演练

 1. 读取三个整数并将它们存储在列表中。 在此阶段不假设任何有关排序的事情，因为交换允许任何重新排列。 
2. 计算三个数字中的最小值。 该值是中间位置唯一可能的候选值，因为中间必须严格小于两端。 
3. 计算该最小值在列表中出现的次数。 这个计数决定了可行性。 如果最小值出现多次，则它的任何放置都会在其旁边放置至少一个相等的值，从而违反了严格的不平等。 
4. 如果最小值至少出现两次，则输出`-1`。 这直接对应于不可能在具有最小元素重复项的多重集中创建严格的局部最小值。 
5. 否则，最小值是唯一的。 将其放在中间位置。 
6. 将剩余的两个值以任意顺序放置在第一和第三位置。 由于两者都严格大于最小值，因此无论其相对顺序如何，都满足两个不等式条件。 
7. 输出构建的排列。 

### 为什么它有效

 条件`a1 > a2 < a3`力量`a2`严格小于两者`a1`和`a3`。 这意味着`a2`必须是三个值中唯一的最小值。 如果最小值不是唯一的，则任何重新排列都无法在保持严格不平等的同时将两侧的相等最小值分开。 相反，如果最小值是唯一的，则将其放在中间可以保证两个剩余值都严格更大，因此它们在两侧的任何排序都可以保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = list(map(int, input().split()))

mn = min(a)
cnt = a.count(mn)

if cnt >= 2:
    print(-1)
else:
    a.remove(mn)
    # remaining two elements can be in any order
    print(a[0], mn, a[1])
```该解决方案依赖于这样一个事实：列表删除仅删除最小值的一次出现，这是安全的，因为我们已经确认它是唯一的。 删除后，只剩下两个元素，我们将最小值放在它们之间。 

这里的一个常见陷阱是忘记`remove`仅删除第一个出现的位置。 只有在验证唯一性之后才可以。 如果没有这种检查，删除可能会在有重复的情况下默默地消除错误的实例，并产生不正确的排列。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 边缘情况

 最重要的边缘情况是最小值多次出现时。 用于输入`2 1 2`，最小值为`1`而且它是独一无二的，所以建设成功并产生了`2 1 2`满足条件。 然而，对于`1 1 2`，最小值为`1`但它出现了两次，任何将其放在中间的尝试都会失败，因为至少有一侧将等于它，从而打破了严格的不平等。 该算法通过在构造任何输出之前检查最小值的频率来处理此问题。 

另一种边缘情况是当输入严格递减时，例如`10 5 1`。 最小值是唯一的，所以我们放置`1`中间和输出`10 1 5`或者`5 1 10`。 两者都满足条件，因为严格的不平等仅取决于较大的值，而不取决于外部元素之间的相对顺序。
