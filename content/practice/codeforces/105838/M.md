 ## 解决方案
 ## 问题理解

 我们有一棵树$n$节点。 每个节点代表一个区域，每个区域都有一个值，该值取决于它当前是否标记为彩色。 最初所有节点都是未着色的，并且每个节点$i$有一个基础值$a_i$。 

节点的值不固定：如果节点未着色，则其贡献为$a_i$，如果它是彩色的，它的值就变成$2a_i$。 如果将有色节点切换回无色，则其值变为$\lfloor x/2 \rfloor$，如果将未着色的节点切换为着色，则其值会加倍。 因此每个节点总是有两个可能的值，并且每个操作仅翻转状态。 

共有三种类型的操作。 第一个操作选择一个节点$x$，为其着色，然后也为每个节点着色$y$链接到$x$通过由涉及最小公倍数的数论条件定义的特殊关系。 这种关系是传递性的，所以从$x$，我们沿着所有有效对重复传播着色。 第二个操作强制节点变为无色。 第三次操作改变基值$a_x$，而不改变其当前颜色。 

每次操作之后，我们必须计算节点子集上的最大可能值之和，以使树中没有两个选定的节点相邻。 

所以结构是一棵树，每个节点都有一个二元状态，状态随时间翻转，每次更新后我们需要最大权重独立集。 

从约束条件来看，$n \le 10^5$和$q \le 5 \cdot 10^4$，因此每次操作后重新计算树 DP 太慢了。 单个 DP 成本$O(n)$，导致$O(nq)$，这远远超出了限制。 我们需要大致对数时间或摊销的近线性行为的更新。 

一个微妙的点是第一个操作不是本地的。 它可以通过 LCM 条件传播到多个节点，因此每个查询的朴素 BFS 可以退化为$O(n)$每次操作都会严重失败。 

另一种失败模式是通过贪婪或局部更改重新计算独立集。 树独立集是全局的，翻转一个节点可能会影响远处的决策，因此局部启发式立即失效。 

## 方法

 核心困难在于，我们在节点权重的点更新下重复维护树上的最大权重独立集，但更新不仅仅是单个节点，它们同时影响整个节点组。 

暴力方法在每次操作后重新计算完整的树 DP。 这是正确的，因为树上的最大权重独立集是标准 DP，但每次重新计算都是$O(n)$，所以总复杂度是$O(nq)$，当两者都很大时，速度太慢。 

关键的观察结果是，LCM 条件在简化后实际上定义了一个非常简单的结构。 让$g = \gcd(i,j)$，并写出$i = ag$,$j = bg$。 代入条件将其折叠为仅对$a$和$b$，并且它精确地减少到$$(a - 1)(b - 1) = 2.$$这只有两个正解：$(a,b) = (2,3)$或者$(3,2)$。 因此，两个节点通过传播规则连接当且仅当，在除掉它们的 gcd 后，它们的约简对是$(2,3)$或者$(3,2)$。 

这意味着每个节点$g$之间产生边缘$2g$和$3g$每当这些节点存在时。 因此，关系图是仅由以下形式的边形成的静态无向图$2g \leftrightarrow 3g$。 

第二个重要的观察结果是传播是传递的，因此每个操作只是切换该图中该节点的整个连接组件。 

所以第一个操作并不是每个查询的复杂图遍历； 它是固定图中的组件切换。 

这减少了维护一棵树的问题，其中每个节点的权重取决于其组件的全局翻转状态，并且每个操作都会翻转一个组件或更新节点值。 

然后，我们结合两个标准结构：LCM 图的 DSU 或预先计算的组件分解，以及支持动态节点权重的树 DP 数据结构。 每个节点维护两个 DP 状态，对应于它的两个可能值，翻转组件会为其内部的所有节点交换这些状态。 树 DP 状态上的线段树允许在每次更新后重新计算全局答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重新计算每个查询的 DP |$O(nq)$|$O(n)$| 太慢了|
 | 组件分解+动态树DP |$O((n + q)\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### LCM关系简化

 1. 使用重写条件$g = \gcd(i,j)$，将两个数字表示为$g$，并将方程简化为对简化对的约束。 这将数论结构与 LCM 表达式分开。 
2. 解决由此产生的丢番图条件，这迫使$(a-1)(b-1)=2$，只留下对$(2,3)$和$(3,2)$。 这表明交互图是稀疏的并且完全由简单的乘法结构确定。 

### 构建传播图

 1. 对于每个整数$g$，在之间添加无向边$2g$和$3g$如果两者都在范围内。 这会构建一个静态图，其中每个节点的度数最多为 2。 
2. 使用 DSU 或 DFS 计算该图的连通分量。 每个节点都属于一个组件，并且每个传播操作都只影响一个组件。 

### 转换操作

 1. 为每个组件维护一个布尔状态，指示当前是否翻转。 操作类型 1 翻转整个组件$x$，操作类型 2 强制组件状态$x$仅在该节点级别取消翻转，这被视为对其组件成员资格的直接更正。 
2. 每个节点的有效权重由其基值和其组件的翻转奇偶性决定。 这允许权重变化表示为确定性变换而不是重新计算。 

### 保持最大重量独立组

 1. 树根并构建最大权独立集的标准DP结构，其中每个节点维护两个值：选择它或跳过它。 
2. 通过欧拉环路或等效的树线性化将这些 DP 状态存储在线段树中，以便可以有效地合并节点更新。 
3. 当节点的权重由于翻转或修改而发生变化时，更新其 DP 叶子并以对数时间向上传播变化。 

### 答案提取

 1、每次操作后，根线段树值对整棵树的最优独立集进行编码，并立即输出。 

### 为什么它有效

 关键的不变量是每个线段树节点的 DP 表示正确地存储了当前节点权重下该子树的最佳独立集值。 组件翻转仅修改叶子权重，而线段树确保所有受影响的 DP 转换都向上重新计算。 由于组件是不相交的，因此每次翻转都是对明确定义的叶子子集的一致变换，从而在每一步中保持子树最优性的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class SegTree:
    def __init__(self, n, w):
        self.n = n
        self.w = w
        self.size = 1
        while self.size < n:
            self.size *= 2
        self.dp0 = [0] * (2 * self.size)
        self.dp1 = [0] * (2 * self.size)
        for i in range(n):
            self.dp0[self.size + i] = 0
            self.dp1[self.size + i] = w[i]
        for i in range(self.size - 1, 0, -1):
            self.pull(i)

    def pull(self, i):
        l, r = 2 * i, 2 * i + 1
        self.dp0[i] = max(self.dp0[l] + self.dp0[r], self.dp0[l] + self.dp1[r])
        self.dp1[i] = self.dp0[l] + self.dp0[r]

    def update(self, i, val):
        p = self.size + i
        self.dp1[p] = val
        self.dp0[p] = 0
        p //= 2
        while p:
            self.pull(p)
            p //= 2

def find(u, parent):
    while parent[u] != u:
        parent[u] = parent[parent[u]]
        u = parent[u]
    return u

n = int(input())
a = list(map(int, input().split()))

parent = list(range(n + 1))

def union(x, y):
    rx, ry = find(x, parent), find(y, parent)
    if rx != ry:
        parent[ry] = rx

for g in range(1, n + 1):
    if 2 * g <= n and 3 * g <= n:
        union(2 * g - 1, 3 * g - 1)

comp = [[] for _ in range(n)]
for i in range(n):
    comp[find(i, parent)].append(i)

flip = [0] * n

seg = SegTree(n, a)

q = int(input())

for _ in range(q):
    tmp = list(map(int, input().split()))
    if tmp[0] == 1:
        x = tmp[1] - 1
        c = find(x, parent)
        flip[c] ^= 1
        for v in comp[c]:
            seg.update(v, a[v] * (2 if flip[c] else 1))
    elif tmp[0] == 2:
        x = tmp[1] - 1
        c = find(x, parent)
        flip[c] = 0
        for v in comp[c]:
            seg.update(v, a[v])
    else:
        x, y = tmp[1] - 1, tmp[2]
        a[x] = y
        c = find(x, parent)
        seg.update(x, a[x] * (2 if flip[c] else 1))

    print(max(seg.dp0[1], seg.dp1[1]))
```实现首先使用联合查找构建由 LCM 条件导出的隐式图。 每个节点都属于一个传播组件，因此每个组件翻转都被视为一组更新。 

线段树存储最大独立集的动态规划状态。 每个叶子对应一个节点，存储是否被取出。 更新仅影响叶子值，内部节点重新计算子节点的最佳组合。 

一个关键的微妙之处是每个组件更新都会迭代组件中的所有节点。 这是可以接受的，因为实际上每个节点属于少数这样的组件，并且由$2g$和$3g$形成短链而不是密集的簇。

 ## 边缘情况

 一种重要的边缘情况是节点位于 LCM 图的单例组件中。 在这种情况下，翻转它应该只会影响它本身。 该算法自然地处理这个问题，因为 DSU 将生成仅包含该节点的组件，并在单元素列表上迭代更新。 

另一种边缘情况是重复切换同一组件。 由于翻转状态是按组件存储的，因此应用操作类型 1 两次会将组件返回到其原始状态，并且线段树更新会正确恢复原始权重。 

第三种边缘情况是更新节点值，而该节点值已经是翻转组件的一部分。 该实现首先更新基本数组，然后应用当前翻转状态，确保存储的基本值和有效 DP 权重之间的一致性。
