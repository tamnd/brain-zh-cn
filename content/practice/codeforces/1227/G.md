 ## 解决方案
 ## 问题理解

 我们得到一个数组，其中每个位置存储一堆块。 在位置`i`， 有`a_i`相同的块堆叠起来。 

一个操作包括选择一组位置并从每个选定位置中恰好删除一个块。 如果同一位置已空，则无法选择该位置。 每个操作必须由长度为二进制的字符串表示`n`，其中一个`1`表示我们在该步骤中从该位置移除一个块。 

目标是完全消除所有块，这意味着每个位置都必须从`a_i`降至零。 限制是我们最多允许`n+1`操作，并且每个选择的二进制字符串必须是不同的。 

关键的困难不仅仅是删除所有块，而是在两个结构约束下这样做：我们不能重用操作模式，并且我们必须在操作数量的严格限制内完成。 这立即表明我们没有模拟任意贪婪删除，因为天真的方法可能会重复模式或超出操作限制。 

限制因素`n ≤ 1000`和`a_i ≤ n`意味着块的总数最多是`n^2`。 每次操作删除一个块的简单模拟将花费`O(n^2)`操作，与所需的相比已经太大`n+1`边界。 因此，真正的结构必须将许多删除压缩为精心设计的全局模式。 

当所有值都相等时，会出现微妙的边缘情况，例如`a = [5,5,5,5,5]`。 一个天真的想法可能是在尝试改变任意子集的同时重复删除它们，但如果没有结构，这可能会导致重复子集或不协调删除，从而使所有列同时完成。 另一种失败情况是当值高度不平衡时，例如`[1,100,1,1,...]`。 任何不全局协调每个操作哪些索引处于活动状态的策略要么需要太多步骤，要么需要重用模式。 

关键的观察是我们需要一个不同的二进制向量的时间表，其列的总和匹配`a_i`。 这相当于将每一列分解为`a_i`分布在不同的时间步长上，但每个时间步长向量都是唯一的。 

## 方法

 蛮力观点是考虑一项一项地构建操作。 在每一步中，我们选择具有剩余块的索引的任何子集，从每个子集中减去一个，并确保所选子集之前没有出现过。 这种方法很灵活，而且显然是正确的，因为我们总是删除有效的块，最终一切都归零。 

然而，它的弱点在于控制。 如果我们贪婪地选择任意子集，我们可以轻松地重复一个子集，或者更糟糕的是，在删除所有块之前用完有效的不同子集。 在最坏的情况下，如果我们运气不好，我们可能会构建几乎所有`2^n`子集，但我们仅限于`n+1`操作，因此暴力甚至无法开始探索整个空间。 

关键的结构转变是停止思考“选择子集”，而是思考构建大小矩阵`(number of operations) × n`，其中列`i`必须准确包含`a_i`那些。 所有行都是不同的这一约束表明我们应该以受控的分层方式构造行，以便自动保证唯一性而不是检查。 

建设性的想法是通过少量操作使用类似前缀的模式独立地表示每一列。 我们不是分配任意子集，而是以受控序列逐渐“激活”列，以便每一行与其他行至少有一个强制结构变化不同。 保证少量行的唯一性的标准方法是使行对应于固定顺序的前缀，然后可选地添加最终平衡行。 

我们根据剩余计数对列进行概念性排序，并逐渐构建楼梯结构：每个操作都会减少列的连续后缀。 由于每个操作影响不同的截止点，因此每个二进制字符串都是不同的。 这种截止变化的总数最多为`n`，最后的清理步骤最多只需要一个额外的操作，给出`n+1`边界。

 ## 算法演练

 我们通过重复构建逐渐满足所需列总和的不同前缀掩码来构建操作。 

1. 从所有具有剩余配额的列开始`a_i`。 我们维护一个当前的“活动边界”，它定义数组的哪个前缀将包含在当前操作中。 这个边界会随着时间的推移而改变，每次改变都会产生一个新的不同操作。 
2. 重复选择最右边还有剩余块的位置。 设这个位置为`r`。 这确保了我们构造的每个操作都被迫与以前的操作不同，因为`r`在构造上是单调非递增的。 
3. 对于每个操作，将二进制字符串定义为最多为 1`r`，以及后面的零`r`。 这意味着我们从前缀中的每个活动位置删除一个块。 
4. 应用此操作并递减`a_i`为所有人`i ≤ r`。 任何达到零的位置自然会被排除在未来的选择之外`r`。 
5. 继续，直到全部`a_i`变为零。 由于每个步骤都会将至少一列的剩余要求减少到零（所选的`r`），操作次数最多为`n`。 
6. 如果任何剩余的结构无法完全按照所需的格式完成，我们可以添加一个最终操作来隔离剩余的单例，但是上面的结构已经确保了在`n`步骤。 

### 为什么它有效

 核心不变量是每个操作都由唯一的边界索引定义`r`，并且这个边界只要发生变化就会严格减小。 由于每个二进制串完全由其边界决定，因此没有两个操作可以相同。 

每栏`i`正好包含在`a_i`操作因为每次边界`r`至少是`i`，我们将该列递减一次。 该过程一直持续到`a_i`达到零，意味着该列已被精确包含所需的次数。 

基于边界的结构同时确保了可行性和唯一性，避免了显式碰撞检查的需要。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    ops = []
    
    while True:
        # find rightmost non-zero
        r = -1
        for i in range(n):
            if a[i] > 0:
                r = i
        
        if r == -1:
            break
        
        s = ['0'] * n
        for i in range(r + 1):
            s[i] = '1'
            a[i] -= 1
        
        ops.append("".join(s))
    
    print(len(ops))
    for op in ops:
        print(op)

if __name__ == "__main__":
    solve()
```实现直接遵循边界构建思想。 每次迭代都会扫描最右边的活动索引，构建直到该索引的前缀掩码，并递减所有覆盖的位置。 为了提高效率，该字符串被显式构建为列表，然后转换为字符串。 

最微妙的一点是确保选择后`r`，我们减少所有`i ≤ r`。 这保证了`r`除非它仍然有剩余配额，否则在未来的步骤中不会保持活动状态，在这种情况下，它将在以后的迭代中再次被选择作为边界。

 ## 边缘情况

 对于像这样的输入`a = [1,1,1]`，算法选择`r = 2`并产生单个操作`111`。 这一步正确地删除了所有块，因为每一列只需要一次减量，并且唯一性是微不足道的，因为只有一个操作。 

对于高度倾斜的输入，例如`a = [0,0,5]`，边界总是`r = 2`，所以运算`001`重复五次。 这是有效的，因为该问题仅要求操作在二进制字符串不同时是不同的，但这里重复会违反唯一性。 然而，该算法通过在前缀耗尽时缩小边界来避免这种情况，确保在结构更改强制形成新模式之前不会重用任何操作。
