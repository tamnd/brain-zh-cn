 ## 解决方案
 ## 问题理解

 系统的状态可以通过两个位置来查看：青蛙位置$f$从1开始递增，以及蚱蜢的位置$g$开始于$N$并减少。 每时每刻，$f$增加 2 或 3，同时$g$减少 1 或 2。我们想要最小的$t$这样之后$t$每个移动，存在一个配置$f_t = g_t$。 

这相当于问我们是否可以划分总距离$N-1$进入$t$青蛙跳跃的大小$\{2,3\}$和$t$蚱蜢跳跃的大小$\{1,2\}$以便两者覆盖完全相同的交汇点。 如果他们在某个位置相遇$x$，然后青蛙覆盖$x-1$，和蚱蜢覆盖$N-x$，意味着总和约束是$x-1 + (N-x) = N-1$，始终固定。 所以核心困难是在相同步数后同步可达的部分和。 

约束条件很大，有$N$最多$2 \cdot 10^9$，这立即排除了任何关于位置或时间的动态规划。 任何模拟逐步运动的方法都是不可能的，因为即使$10^9$脚步已经远远超出了极限。 该解决方案必须将问题简化为两个有界步骤过程的可达和的算术条件。 

一个天真的错误是假设青蛙总是在距离大致减半后在中点相遇。 但这失败了，因为跳跃组是不对称的。 例如，如果$N = 5$，答案为 1，因为两者都可以一次到达单元格 3 或 4，但中点逻辑会错误地建议分数位置或通常需要更多步骤。 

另一个微妙的边缘情况是奇偶性和可达性。 因为青蛙移动加 2 或 3，它可以在一定的剩余约束下达到任何足够大的数字，而 1 或 2 的蚱蜢移动允许不同的奇偶灵活性。 小的$N$值表明，即使每步的平均距离看起来兼容，也并非所有步数都是可行的。 

## 方法

 暴力方法试图模拟两只动物的所有可能的跳跃序列，以增加时间$t$。 对于每个$t$，我们将枚举青蛙可以使用的所有可能的总和$t$元素来自$\{2,3\}$，类似地，蚱蜢可以使用以下方法获得的所有总和$t$元素来自$\{1,2\}$。 然后我们检查是否存在共享的会议位置。 可能性的数量呈指数级增长，因为双方都有$2^t$配置，使得这甚至不可行$t$30左右。 

关键的观察是，每一方实际上并没有产生任意的总和集。 后$t$移动时，青蛙的位置完全取决于它选择跳跃 3 而不是 2 的次数，同样，蚱蜢的位置取决于它选择跳跃 2 而不是 1 的次数。这将每一边简化为单个变量的线性表达式。 

对于青蛙来说，之后$t$步骤，如果使用$k$长度为 3 的跳跃和$t-k$长度为2的跳跃，其总距离为$2t + k$，因此它的可达位置形成一个区间$2t$到$3t$。 对于蚱蜢来说，之后$t$步，其总后退距离为$t + k'$，形成一个区间$t$到$2t$。 因此，每一边都产生一个连续的可达距离范围，而不是指数集。 

这样，问题就变成了寻找最小的$t$这样这两个间隔可以产生互补距离，总和为$N-1$。 如果青蛙到达一定距离$a$从左边和蚱蜢到达距离$b$从右边开始，会议要求$a + b = N-1$。 这成为对间隔是否可行的可行性检查$[2t, 3t]$和$[t, 2t]$可以在此总和约束下对齐。 

我们将条件简化为是否存在$a$这样$a \in [2t, 3t]$和$N-1-a \in [t, 2t]$。 这变成了每个简单的区间交集问题$t$，并且自从$N$很大，我们推导出最小有效值的直接公式$t$。

 ## 算法演练

 我们根据距端点的距离重写可达性条件。 

1.代表青蛙经过后的距离$t$秒为任意整数$[2t, 3t]$。 这是因为每次移动都会增加 2 或 3，因此最小值是全 2，最大值是全 3。 
2.表示之后的蚱蜢距离$t$秒为任意整数$[t, 2t]$，因为每次移动都会从右侧减去 1 或 2，这意味着向左的总移动位于该范围内。 
3. 要召开会议，请选择一个分割点$a$这样青蛙就能到达$a$和蚱蜢到达$N-1-a$。 这将问题转化为寻找$a$使得两个约束同时成立。 
4.转化为不等式：$a \in [2t, 3t]$和$N-1-a \in [t, 2t]$。 第二个不等式变为$a \in [N-1-2t, N-1-t]$。 
5. 存在条件是区间的交集$[2t, 3t]$和$[N-1-2t, N-1-t]$。 如果重叠，可以随时会面$t$。 
6. 找到最小的$t$其交集非空。 解决不等式：$2t \le N-1-t$和$N-1-2t \le 3t$，这减少到界限$t$。 

由此产生的最小$t$是直接从这些不等式中获得的。 

### 为什么它有效

 任何固定时间$t$，两个步行者的可到达位置形成连续的间隔，因为它们的步长在选项之间相差正好 1。 这消除了组合分支并将可达性转变为数轴上的凸集。 相交相当于线性变换下两个凸区域相交$a + b = N-1$。 由于两组都保留间隔$t$，检查可行性减少为间隔重叠，从而保留正确性，而无需检查各个路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    target = N - 1

    lo, hi = 0, 10**18

    def ok(t):
        frog_L, frog_R = 2 * t, 3 * t
        grass_L, grass_R = t, 2 * t

        # need exists a such that:
        # a in frog interval AND target - a in grass interval
        L = max(frog_L, target - grass_R)
        R = min(frog_R, target - grass_L)
        return L <= R

    ans = -1
    l, r = 0, N

    while l <= r:
        mid = (l + r) // 2
        if ok(mid):
            ans = mid
            r = mid - 1
        else:
            l = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
```该代码实现了随时间的二分查找$t$，因为可行性条件是单调的：如果在某个时间可能会面$t$，仍然有可能获得更大的$t$。 功能`ok(t)`构造两个可达区间并检查是否存在有效的分割点$a$同时满足两个约束条件。 

关键的实现细节是将grasshopper约束正确地转换为一个区间$a$。 一个常见的错误是只比较平均速度而不是全范围，这会破坏小范围的正确性$N$。

 ## 边缘情况

 对于$N = 2$，两者都已从相邻单元格开始，不需要移动，因此答案为 0。区间构造给出目标 1，并且在$t=0$青蛙距离为 0，蚱蜢距离为 0，这与约束条件直接匹配。 

对于非常小的$N$例如3或4，只需一侧单跳就足够了，算法正确地找到了第一个$t$其中间隔在转换后的约束下相交。 区间方法不依赖于假设正数$t$，因此它自然地处理这些边界情况，无需特殊分支。
