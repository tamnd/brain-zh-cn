 ## 解决方案
 ## 问题理解

 该问题要求可以放置在平面上某处的圆的最小半径，使得该圆至少包含`M`出于`N`给定点。 点是固定的，但圆心是完全自由的。 我们只需要半径，而不需要中心位置。 最初的问题是寻找尽可能小的“人口圈”的几何版本，其中的点代表人们的位置。 

输入最多提供 500 个具有整数坐标的点以及必须覆盖的目标点数量。 坐标的绝对值可以大到一百万，因此几何图形必须避免枚举每个可能的中心。 和`N = 500`， 一个`O(N^3)`解决方案可能已经接近极限，但重复多次就会变得太慢。 由于我们需要精确的浮点答案，因此最终算法需要可管理的运算数量和受控的数值误差。 

一个常见的错误是只考虑中心是现有点的圆。 最佳圆不必以给定点为中心。 例如，使用输入```
2 2
0 0
2 0
```正确的输出是`1.0`，因为圆的中心是`(1,0)`有半径`1`涵盖了这两点。 仅尝试点中心的方法会选择给定点之一作为中心并获取半径`2`。 

另一种边缘情况是答案由恰好位于边界上的点确定。 例如：```
3 3
0 0
2 0
1 1
```最小半径约为`1.0`。 最佳圆的边界上有一些点，因此使用严格`< r`检查过程中的比较可能会错误地拒绝真实答案。 

当许多点相同时会出现第三种情况：```
3 3
5 5
5 5
5 5
```答案是`0`。 任何假设每对点形成非零直径的方法在这里都会失败。 

## 方法

 最直接的方法是猜测圆心并计算它覆盖了多少个点。 困难在于中心可以在平面上的任何地方，因此有无限多种可能性。 一个自然的限制是观察到覆盖一组点的最小圆通常由边界点确定，因此我们可以尝试由点对定义的圆。 枚举对并检查每个点给出`O(N^3)`方法。 

对于每一对，我们可以计算可能的半径圆心`R`通过这两个点，然后计算每个候选人覆盖了多少点。 这是有效的，因为对于固定半径，覆盖最大数量点的最佳圆可以移动，直到其边界接触至少一个点，并且有用的候选中心可以由这些角度事件表示。 问题是我们需要在半径上进行二分搜索来执行这个过程，使其粗略地`O(N^3 log W)`，对于 500 点来说太慢了。 

关键的观察是半径的可行性是单调的。 如果一个半径`R`可以覆盖`M`点，每个更大的半径也可以覆盖`M`点。 这让我们可以二分查找答案。 

对于固定半径，问题变成检查某个中心是否至少在内部`M`的`N`半径的圆`R`以给定点为中心。 我们不需要搜索整个飞机。 对于每个点，想象答案圆的中心在半径的圆周上移动`R`围绕该点画圈。 可以覆盖的其他点在该圆周上创建角间隔。 如果某个角度包含在足够的间隔内，则中心的该位置覆盖了足够的点。 

这样做的原因是，如果存在有效的覆盖圆，则其中心位于半径内`R`它所覆盖的每个点的圆盘。 我们可以将中心移动到这些圆盘之一的边界，而不会丢失覆盖范围。 因此检查所有边界圆就足够了。 

对于每个选定的作为边界参考的点，我们计算其他点贡献的所有有效角度间隔，对间隔端点进行排序，并使用扫描线找到最大重叠。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N3 log W) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(N² log N log W) | O(N² log N log W) | O(N) | 已接受 |

 ## 算法演练

 1.二分查找半径。 搜索范围从`0`以及足够大的值，因为答案是连续的，并且可行性函数仅从 false 变为 true 一次。 
2. 对于候选半径，运行可行性检查。 如果存在此半径的圆，则检查返回 true，至少覆盖`M`点。 
3. 对于每个点，将其视为位于候选圆边界上的点。 准确地考虑所有可能的距离中心`radius`从这一点来看。 这些中心形成一个圆，我们用角度表示其上的位置。 
4. 对于每个其他点，确定中心也足够接近以覆盖该点的角度范围。 两个极限角来自两个可能的半径圆`radius`通过这两个点。 
5. 将间隔端点添加到事件列表。 当间隔开始时，增加当前覆盖计数。 当它结束时，减少它。 扫描期间的最大计数告诉我们该边界圆上的中心覆盖的最大点数。 
6. 如果最大覆盖范围达到`M`对于任何参考点，候选半径都是可能的。 不然就太小了。 

对每个点都进行扫描，因为最佳圆可能在边界上有任何被覆盖的点。 检查所有这些可确保考虑最佳边界位置。 

为什么有效：二分查找是正确的，因为增加半径只能添加可能的中心，而永远不会删除它们。 可行性检查是正确的，因为每个有效的解决方案都可以转换为中心接触覆盖点半径圆盘边界的解决方案。 角度扫描检查所有此类边界位置并找到同时覆盖点的最大数量。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

eps = 1e-12
PI = math.pi

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    pts = []
    for _ in range(n):
        x = int(next(it))
        y = int(next(it))
        pts.append((x, y))

    def check(r):
        if r == 0:
            return n >= m

        rr = r * r
        for i in range(n):
            events = []
            x1, y1 = pts[i]
            for j in range(n):
                if i == j:
                    continue
                x2, y2 = pts[j]
                dx = x2 - x1
                dy = y2 - y1
                d2 = dx * dx + dy * dy

                if d2 > 4 * rr + eps:
                    continue

                d = math.sqrt(d2)
                if d < eps:
                    continue

                base = math.atan2(dy, dx)
                half = math.sqrt(max(0.0, rr - d2 / 4.0))
                angle = math.acos(d / (2 * r))

                l = base - angle
                h = base + angle

                while l < 0:
                    l += 2 * PI
                    h += 2 * PI
                while l >= 2 * PI:
                    l -= 2 * PI
                    h -= 2 * PI

                if h <= 2 * PI:
                    events.append((l, 1))
                    events.append((h, -1))
                else:
                    events.append((l, 1))
                    events.append((2 * PI, -1))
                    events.append((0, 1))
                    events.append((h - 2 * PI, -1))

            events.sort(key=lambda x: (x[0], -x[1]))
            cur = 1
            best = 1
            for _, v in events:
                cur += v
                if cur > best:
                    best = cur
            if best >= m:
                return True
        return False

    lo, hi = 0.0, 2e6
    for _ in range(50):
        mid = (lo + hi) / 2
        if check(mid):
            hi = mid
        else:
            lo = mid

    print("{:.15f}".format(hi))

if __name__ == "__main__":
    solve()
```该代码首先读取所有点并定义二分搜索所使用的可行性测试。 二分查找使用 50 次迭代，这已经足够了，因为所需的精度仅为`1e-4`。 

里面`check`，每个点都作为候选圆的边界点。 对于另一个影响扫掠的点，两点之间的距离不得超过`2r`，否则没有半径的圆`r`可以同时包含两者。 有效的中心位置成为一个角度间隔。 

间隔处理是最微妙的部分。 角度环绕从`2π`回到`0`，因此跨越此边界的区间被分成两个正常区间。 在结束事件之前以相同的角度对事件进行排序可以处理点正好位于边界上的情况。 

初始覆盖计数为`1`因为所选的边界点总是被候选圆覆盖。 扫描仅计算其他点。

 ## 边缘情况

 对于最优中心不是输入点之一的情况，```
2 2
0 0
2 0
```该算法可以处理它，因为二分搜索不会猜测中心。 在半径可行性检查期间`1`，选择任一点作为边界参考会创建一个包含中间中心位置的角度区间。 扫描发现覆盖范围`2`。 

对于重复点，```
3 3
5 5
5 5
5 5
```二分查找测试非常小的半径。 在半径处`0`，特殊情况立即返回 true，因为所有点都已经位于同一位置。 这避免了角度计算中被零除的情况。 

对于点恰好位于圆边界上的解，```
3 3
0 0
2 0
1 1
```间隔端点包含在扫描期间。 排序顺序以相同的角度在结束事件之前处理开始事件，因此可以正确计算边界上的中心。 这可以防止精度误差丢失真正的最小半径。
