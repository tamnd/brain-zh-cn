 ## 解决方案
 ## 问题理解

 该问题给出了有根树的每个深度级别上必须出现的顶点数。 第一个数字描述了树的高度，接下来的序列描述了有多少个顶点正好是距根的 0 条边、1 条边、2 条边等等。 任务是确定该信息是否强制形成唯一的有根树形状，或者两个不同的非同构树是否可以满足相同的深度计数。 如果树不是唯一的，我们必须构造两个有效的父数组来表示两棵不同的树。 这是 Codeforces“哈希树”问题背后的经典思想。 

高度可以很大，最高可达 100000 左右，并且顶点总数是有界的。 这意味着解的顶点数量应该接近线性。 构建所有可能的树或比较许多可能的排列会增长得太快，因为不同的父代选择的数量可能会变得巨大。 我们需要找到一个结构属性来准确地告诉我们何时出现歧义。 

一些边缘情况很容易被忽略。 如果根之后的每一层都只有一个顶点，则树被迫成为单路径。 例如，输入```
2
1 1 1
```只有一棵可能的树，所以输出是```
perfect
```一种仅检查某个级别是否具有多个节点的粗心方法可能会错误地认为这是不明确的。 

另一个重要的情况是当两个相邻级别都包含多个顶点时。 例如，```
2
1 2 2
```是模棱两可的。 第一层有两个节点，下一层也有两个节点。 我们可以将两个更深的节点附加在同一个父节点下，或者将它们拆分到两个父节点之间。 这些给出了不同的有根树形状。 

正确的输出开始于```
ambiguous
```接下来是两个不同的有效树。 仅在序列中查找重复值而不考虑相邻级别的解决方案将错过这种情况。 

## 方法

 解决该问题的直接方法是尝试构建与级别计数匹配的所有可能的树。 对于一个级别上的每个顶点，我们将选择它从下一个级别接收多少个子节点。 这是正确的，因为构建这样一棵树的唯一自由是在连续级别的父级之间分配子级。 然而，即使是具有多个顶点的单个级别也会创建大量分布。 顶点多达数十万个，可能性的数量远远超出了我们所能探索的范围。 

关键的观察是，我们唯一可以选择改变树结构的情况是当两个连续的级别都具有分支时。 假设水平`i`包含至少两个顶点和水平`i + 1`还包含至少两个顶点。 孩子们在水平`i + 1`可以集中在一个父项下，也可以分布在多个父项中。 这两个选择创建了不同的子树形状。 

如果没有相邻的级别对具有此属性，则每个分支级别后面都有一条链。 一旦一个级别有多个顶点，下一个级别就无法进一步分裂，因此无法重新排列子级并创建另一个非同构树。 这棵树是唯一确定的。 

当存在歧义时，我们可以首先构建任何有效的树，然后在第一对连续分支级别进行局部修改。 将一个子项从第一个父项移动到第二个父项会更改形状，同时保留所有深度计数。

 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取每个深度级别的高度和顶点数。 跟踪最终顶点编号中每个级别的起始索引。 根是顶点 1，顶点按级别顺序分配。 
2. 通过将当前级别的每个顶点附加到前一级别的最后一个顶点来构建第一棵树。 这总是会创建一个有效的树，因为每个顶点都准确地接收到所需的深度。 
3. 扫描每对相邻层。 如果一个级别和下一个级别都包含至少两个顶点，则该树是不明确的。 原因是下一级的孩子可以有多种排列方式。 
4. 如果不存在这样的对，则打印`perfect`因为每棵有效的树都必须具有相同的结构。 
5. 如果发现级别含糊不清`i`和`i + 1`，使用第一个构造的树作为第一个答案。 对于第二个答案，更改级别上一个顶点的父级`i + 1`从关卡的第一个顶点`i`到标高的第二个顶点`i`。 这仅改变连接模式，而不改变任何深度上的顶点数量。 

为什么它有效：

 节点的父节点只能是上一层的顶点。 如果两个连续的级别都有多个顶点，则至少有两种可能的方式来分配子项，并且这些方式可以为同一深度的顶点生成不同数量的子项。 这种差异无法通过重命名顶点来消除，因此树不是同构的。 

如果每个相邻对都包含一个只有一个顶点的级别，则每个分支决策都是强制的。 具有一个顶点的级别只有一个可能的父级，并且分支级别后面不能跟有可以重新排列的另一分支级别。 整个树的形状是固定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    h = int(input())
    a = list(map(int, input().split()))

    start = [0] * (h + 1)
    cur = 1
    for i in range(h + 1):
        start[i] = cur
        cur += a[i]

    n = cur - 1

    parent1 = [0] * (n + 1)
    parent2 = [0] * (n + 1)

    current = 1
    for level in range(1, h + 1):
        prev_start = start[level - 1]
        prev_vertex = prev_start
        for j in range(a[level]):
            parent1[current] = prev_vertex
            parent2[current] = prev_vertex
            current += 1

        if level > 0 and a[level - 1] > 1 and a[level] > 1:
            pass

    for i in range(h):
        if a[i] > 1 and a[i + 1] > 1:
            child = start[i + 1]
            parent2[child] = start[i] + 1

            print("ambiguous")
            print(*parent1[1:])
            print(*parent2[1:])
            return

    print("perfect")

if __name__ == "__main__":
    solve()
```数组`start`存储每个深度级别在编号中的开始位置。 这使得在恒定时间内识别水平的第一和第二顶点成为可能。 

第一棵树是贪婪地创建的。 新级别上的每个顶点都附加到前一级别的第一个顶点。 这会产生一棵有效的树，因为在构建过程中只有深度才重要。 

歧义性扫描与构造是分开的，因为条件仅取决于输入序列。 一旦找到一对相邻的分支级别，更改更深级别上第一个顶点的父级就足以创建第二棵树。 

索引细节是最容易出错的地方。 根是顶点 1，而不是 0，所以`start[i]`始终指的是真实的顶点数。 输出要求顶点的父级按从 1 到`n`，这就是最终切片跳过未使用的零索引的原因。

 对于输入```
2

```施工流程为：

 | 水平| 计数 | 开始索引 | 歧义检查|
 | ---| ---| ---| ---|
 | 0 | 1 | 1 | 没有|
 | 1 | 1 | 2 | 没有|
 | 2 | 1 | 3 | 没有|

 不存在包含两个顶点的相邻层对。 树是被迫的，所以答案是：```

```该跟踪演示了链不可能重新排列的情况。 

对于输入```
2
1 2 2
```级别是：

 | 水平| 计数 | 开始索引 | 歧义检查|
 | ---| ---| ---| ---|
 | 0 | 1 | 1 | 没有|
 | 1 | 2 | 2 | 是的，下一级别|
 | 2 | 2 | 4 | |

 第一棵树可以构建为：```
0 1 1 2 2
```第二棵树将顶点 4 更改为具有父级 3：```
0 1 1 3 2
```深度计数保持不变，但子树大小不同，因此树不是同构的。

import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    
    h = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))

    start = [0] * (h + 1)
    cur = 1
    for i in range(h + 1):
        start[i] = cur
        cur += a[i]

    n = cur - 1
    p1 = [0] * (n + 1)
    p2 = [0] * (n + 1)

    cur = 1
    for level in range(1, h + 1):
        for _ in range(a[level]):
            p1[cur] = start[level - 1]
            p2[cur] = start[level - 1]
            cur += 1

    out = []
    for i in range(h):
        if a[i] > 1 and a[i + 1] > 1:
            p2[start[i + 1]] = start[i] + 1
            out.append("ambiguous")
            out.append(" ".join(map(str, p1[1:])))
            out.append(" ".join(map(str, p2[1:])))
            sys.stdin = old
            return "\n".join(out) + "\n"

    sys.stdin = old
    return "perfect\n"

assert run("2\n1 1 1\n") == "perfect\n", "single path"
assert run("2\n1 2 2\n").splitlines()[0] == "ambiguous", "branching case"
assert run("3\n1 2 1 1\n") == "perfect\n", "branch followed by chain"
assert run("3\n1 2 2 1\n").splitlines()[0] == "ambiguous", "two branching levels"
assert run("1\n1 5\n").splitlines()[0] == "perfect", "star tree"

 ## 边缘情况

 用于链条箱```
2
1 1 1
```该算法构造父母`0 1 2`。 在扫描期间，相邻级别上的计数永远不会大于 1，因此不可能进行修改。 它打印`perfect`，它匹配唯一可能的形状。 

对于模棱两可的情况```
2
1 2 2
```该算法发现级别 1 和级别 2 都有多个顶点。 第一棵树将顶点 4 和 5 连接到顶点 2 下。第二棵树将顶点 4 移动到顶点 3 下。级别计数保持不变`1, 2, 2`，但是一棵树有一个带有两个子节点的节点，而另一棵树则将它们展开。 

对于像这样的边界情况```
3
1 2 1 1
```第 1 层分支，但第 2 层仅包含一个顶点。 该顶点必须只有一个父顶点，因此没有替代结构。 该算法正确地忽略了单个分支级别并打印`perfect`。 

为了```
3
1 2 2 1
```1 级和 2 级都是分支。 第一个更深的顶点可以附加到第 1 层的两个节点中的任何一个。该算法检测该相邻对并生成两个不同的有效树。
