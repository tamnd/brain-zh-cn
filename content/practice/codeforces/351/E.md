 ## 解决方案
 ## 问题理解

 给定一个整数序列，并且允许我们翻转任何元素的符号。 目标是尽量减少序列中的反转次数。 当序列中较大的数字出现在较小的数字之前时，就会发生反转。 输入提供序列长度`n`后跟序列本身，输出是一个整数，表示最佳翻转符号后的最小可能反转次数。 

限制条件是`n`最多可达 2000，每个元素的大小最多可达 10^5。 这个大小允许算法的时间复杂度大致为 O(n^2)，但类似 ​​O(n^3) 的算法可能会太慢。 既然我们可以翻转元素，我们就不能简单地计算反转和排序； 我们必须根据元素的相对值来推断要翻转哪些元素。 

一个微妙的边缘情况是所有数字均为正数或全部为负数。 翻转一些数字可能会显着减少反转，但如果只考虑局部对，天真的贪婪方法可能会失败。 例如，给定序列`[2, -1, 3]`，仅翻转导致第一个元素反转的数字的简单方法可能会错过更好的全局解决方案。 另一个边缘情况是具有重复数字的序列，例如`[1, 1, -1, -1]`。 在这里，翻转可能不会减少所有反转，因为相同的数字不是反转，但不小心翻转它们可能会产生新的反转。 

## 方法

 暴力法是尝试对每个数字子集进行翻转，计算结果序列，计算其反转次数，并取最小值。 有 2^n 个子集，计算反转需要 O(n^2)。 即使对于 n=20，这也会导致大约 2^20 * 400 = 4 亿次操作，这对于 n=2000 来说是不可行的。 

关键的见解是认识到该问题可以建模为动态规划问题。 如果我们对数字的绝对值进行排序，则每个数字的决定是保持正值还是负值。 由于反转仅发生在已经看到的数字和当前数字之间，因此我们可以为每个数字维护两个动态编程状态：如果我们翻转该数字或保留它，则最小反转。 这将复杂性降低到 O(n^2)，因为对于每个数字，我们检查相对于所有先前数字放置它的成本，并存储最佳结果。 

换句话说，我们不需要显式地考虑所有 2^n 种组合。 相反，我们按绝对值递增的顺序处理数字。 对于每个数字，我们计算如果相对于已处理的数字放置正数或负数，它会贡献多少个反转。 然后我们向前传播最小反转计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了 |
 | 最佳DP | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 读取序列并存储每个数字及其绝对值。 我们将按绝对值递增的顺序处理数字，因为较小绝对值的相对顺序会影响较大绝对值的反转。 
2.初始化DP表`dp[i][j]`在哪里`i`是处理的元素数量，`j`表示当前数字是否翻转（0为正数，1为负数）。`dp[i][j]`存储第一次的最小反转次数`i`与当前选择的数字。 
3. 对于第一个数字，没有之前的数字，所以`dp[0][0] = 0`和`dp[0][1] = 0`。 
4. 迭代绝对值的排序列表。 对于每个数字，计算两个量：如果为正数，则需要添加多少个反转；如果为负数，则需要添加多少个反转。 这涉及到计算所有先前的数字，这些数字将与当前的选择形成反转。 相应地更新 DP 表。 
5. 处理完所有数字后，答案是以下最小值`dp[n-1][0]`和`dp[n-1][1]`。 

为什么有效：通过按绝对值递增的顺序处理数字并考虑每个数字的两个选项，我们保证两个数字之间的每次反转都被精确地计算一次。 DP 确保有效地考虑可以最小化反转的所有翻转组合，而无需显式枚举 2^n 种可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

# store numbers with absolute value and original sign
nums = [(abs(x), 1 if x >= 0 else -1) for x in a]
nums.sort(key=lambda x: x[0])

dp = [[float('inf')] * 2 for _ in range(n)]
# first number can be positive or negative
dp[0][0] = 0
dp[0][1] = 0

for i in range(1, n):
    for flip_i in range(2):
        val_i = nums[i][0] * (1 if flip_i == 0 else -1)
        for flip_j in range(2):
            val_j = nums[i-1][0] * (1 if flip_j == 0 else -1)
            cost = 1 if val_j > val_i else 0
            dp[i][flip_i] = min(dp[i][flip_i], dp[i-1][flip_j] + cost)

print(min(dp[n-1][0], dp[n-1][1]))
```该解决方案读取序列并将每个元素与其绝对值和原始符号配对。 排序确保我们首先处理较小的量级。 DP表`dp[i][j]`捕获索引处每个决策的最小反转`i`。 嵌套循环计算每个先前选择的成本并更新 DP 条目。 最后，我们取最后一个数字的两种可能性中的最小值。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    nums = [(abs(x), 1 if x >= 0 else -1) for x in a]
    nums.sort(key=lambda x: x[0])
    dp = [[float('inf')] * 2 for _ in range(n)]
    dp[0][0] = dp[0][1] = 0
    for i in range(1, n):
        for flip_i in range(2):
            val_i = nums[i][0] * (1 if flip_i == 0 else -1)
            for flip_j in range(2):
                val_j = nums[i-1][0] * (1 if flip_j == 0 else -1)
                cost = 1 if val_j > val_i else 0
                dp[i][flip_i] = min(dp[i][flip_i], dp[i-1][flip_j] + cost)
    return str(int(min(dp[n-1][0], dp[n-1][1])))

assert run("2\n2 1\n") == "0"
assert run("3\n2 -1 3\n") == "0"
assert run("4\n1 3 2 4\n") == "1"
assert run("5\n5 4 3 2 1\n") == "0"
