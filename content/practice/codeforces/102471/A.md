 ## 问题理解

 我们有一个由单位正方形组成的 n×m 矩形网格。 它的网格点坐标为整数，因此总共有 (n+1)(m+1) 个点。 我们可以选择任意两个不同的网格点作为线段的端点，包括对角线段和穿过其他网格点的线段。 

当线段的中点也是网格点时，该线段才有效。 我们需要计算满足该条件的每个不同的非零段。 

坐标视点使条件更容易推理。 假设端点是 (x 1 ​ ,y 1 ​ ) 和 (x 2 ​ ,y 2 ​ )。 他们的中点是

 （2 x 1​+x 2​​，2 y 1​+y 2​​）。 

由于所有网格点都有整数坐标，因此当 x 1 ​ +x 2 ​ 和 y 1 ​ +y 2 ​ 均为偶数时，中点就是网格点。 同样，两个端点的 x 坐标和 y 坐标必须具有相同的奇偶性。 

约束条件为 1≤n,m≤1000，因此网格点的数量可能刚刚超过 100 万个。 检查每对点的算法在最大尺寸下需要大约 5×10 11 对点的检查，这远远超出了一秒解决方案所能承受的范围。 我们需要计算有效对的数量，而无需显式构造它们。 

有两个小案例通常会暴露错误的计数。 用于输入`1 1`，有四个网格点，但每对不同的角都有一个中点，该中点不是整数网格点，所以答案是`0`。 计算所有对角线或所有距离均匀的对角线的解决方案可能会意外地计算这些线段。 

用于输入`1 2`，有六个网格点。 两个水平行各包含三个点，并且只有跨越两个单位间隔的两对具有网格点中点。 答案是`2`。 仅考虑水平和垂直线段的解决方案可能会意外地实现这一点，但它在较大的网格上会失败，因为也存在有效的对角线段。 

## 方法

 直接的方法是将坐标分配给所有 (n+1)(m+1) 个网格点并检查每个无序对。 对于一对端点，我们计算中点并检查两个坐标是否都是整数。 这是正确的，因为每个可能的段都由一对端点表示。 

问题是对的数量。 当 n=m=1000 时，有 1,002,001 个点，产生

 ( 2 1,002,001 ​ )=501,?×10 9

 对，大约 5.02×10 11。即使对每对进行非常便宜的恒定时间检查也太慢了。 

关键的观察结果是，中点条件并不取决于点之间的实际距离。 它仅取决于坐标奇偶性。 当两个端点的 x 坐标具有相同的奇偶性并且它们的 y 坐标具有相同的奇偶性时，它们恰好具有整数中点。 

这将每个网格点分为四个奇偶校验类别之一：

 （偶，偶），（偶，奇），（奇，偶），（奇，奇）。 

同一类内的每一对不同点都是有效的，而来自不同类的每一对都是无效的。 因此，我们不需要检查每一对，而只需要每个类的大小，并且可以为每个类添加 ( 2 k ​ )。 

0,1,…,n中偶数坐标的个数为⌊n/2⌋+1，奇数坐标的个数为⌈n/2⌉。 这同样独立地适用于 y 坐标。 这立即给出了所有四个班级的规模。

 ## 算法演练

 1. 计算n+1个可能的x坐标中出现了多少个偶数和奇数整数。 因为范围从零开始，所以有 ⌊n/2⌋+1 个偶数值，其余值为奇数。 
2、以同样的方式统计m+1个可能的y坐标中的偶数和奇数。 偶数的个数为⌊m/2⌋+1，奇数的个数为⌈m/2⌉。 
3. 通过乘以相应的坐标计数来构造四个奇偶校验类大小。 例如，具有偶数 x 和奇数 y 的点数为`even_x * odd_y`。 
4. 对于每个包含 k 个点的奇偶校验类，将 ( 2 k ​ )=k(k−1)/2 添加到答案中。 从该类中选择的两个不同点的坐标和都是偶数，因此它的中点是一个网格点。 
5. 打印四项贡献的总和。 不需要几何枚举，因为奇偶校验分类已经捕获了整个中点条件。 

### 为什么它有效

 考虑任意两个网格点。 当两个坐标平均值均为整数时，它们的中点恰好是一个网格点。 当两个整数具有相同的奇偶校验时，两个整数的平均值恰好是一个整数。 因此，有效段必须具有具有相同 x 奇偶校验和相同 y 奇偶校验的端点，这意味着两个端点属于四个奇偶校验类别中的同一个。 

相反，同一奇偶校验类中的任意两个不同点的坐标和为偶数，因此它们的中点具有整数坐标并且位于矩形网格内，因为它位于连接两个网格点的线段上。 因此，算法计数的每一对都是有效的，并且每个有效对都只计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    even_x = n // 2 + 1
    odd_x = (n + 1) - even_x

    even_y = m // 2 + 1
    odd_y = (m + 1) - even_y

    classes = (
        even_x * even_y,
        even_x * odd_y,
        odd_x * even_y,
        odd_x * odd_y,
    )

    ans = sum(k * (k - 1) // 2 for k in classes)
    print(ans)

solve()
```前两个计数描述了 x 坐标从 0 到 n 的奇偶校验分布。 这`+ 1`在`n // 2 + 1`占坐标零，它是偶数。 然后通过从坐标总数中减去偶数计数来获得奇数计数。 

对 y 坐标执行相同的计算。 将 1 个 x 奇偶校验计数乘以 1 个 y 奇偶校验计数即可得出相应奇偶校验类别中的网格点数。 

表达式`k * (k - 1) // 2`计算无序的不同点对。 我们始终使用整数运算，因此不存在浮点精度问题。 Python 整数也可以轻松处理最大答案。 

没有要构造的坐标数组，也没有显式访问任何点对。 整个计算由恒定数量的算术运算组成。

 ## 边缘情况

 对于`1 1`，坐标集是`{0,1}`在两个方向上。 四个奇偶校验类别中的每一个都包含一个点，因此 k 的每个值都是 1，并且每个 k(k−1)/2 贡献都为零。 算法打印`0`，正确拒绝诱人但无效的角对角对角线。 

为了`1 2`，x 坐标有 1 个偶数和 1 个奇数，而 y 坐标有 2 个偶数和 1 个奇数。 四个班级规模为 2,1,2,1，即 1+0+1+0=2。 两个有效段是两行上的长度-两个水平段。 

为了`1000 1000`，每个坐标方向有 501 个偶数和 500 个奇数。 四个班级规模变为251001、250500、250500、250000。 他们的对数总计为`125500500000`。 这种情况证实了该实现处理了最大可能的答案而没有溢出，并且解决方案中没有隐藏与网格点数量成比例的迭代。
