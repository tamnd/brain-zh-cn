 ## 解决方案
 ## 问题理解

 我们从两个排列 (A) 和 (B) 开始，两者都包含从 (1) 到 (N) 的每个整数恰好一次。 我们可以重新排列 (A)，但只能通过交换相邻元素。 目标不是构建一种特定的最大安排。 我们需要最少数量的相邻交换，将原始 (A) 转换为任意排列，其值

 [
 \sum_{i=1}^{N}|a_i-b_i|
 ]

 尽可能大。 

因为相邻交换可以生成每个排列，所以真正的问题是表征使总和最大化的所有排列，然后找到在相邻交换距离中最接近原始排列 (A) 的排列。 

界限 (N\le 250000) 排除了 (N) 中的任何二次方，更不用说枚举排列了。 即使 (O(N^2)) 也需要大约 (6.25\times10^{10}) 最大尺寸的基本运算，远远超出两秒的限制。 我们基本上需要线性时间，或者最多 (O(N\log N))。 幸运的是，(A) 和 (B) 恰好是 (1,\ldots,N) 的排列，因此它们的值已经为我们提供了它们的排名。 实际上不需要排序。 

在一些小情况下，诱人的解决方案会失败。 对于(N=3)、(A=[1,2,3])、(B=[1,2,3])，逆排列([3,2,1])是最优的，但需要三个相邻交换。 正确答案只有 (2)，因为 ([2,3,1]) 和 ([3,1,2]) 也是最优的。 假设反向排列是唯一最优的解决方案会犯这个错误。 

对于 (N=1)、(A=[1]) 和 (B=[1])，答案为 (0)。 没有什么可以交换的，唯一可能的安排已经是最优的了。 任何盲目地将值的两半视为非空的实现都必须单独处理这种情况。 

对于 (N=2)、(A=[1,2])、(B=[1,2])，答案为 (1)。 唯一的最大化排列是([2,1])。 这会捕获对偶数 (N) 使用不正确的中间值规则的实现。 

最后，答案可以比(N)大得多。 对于 (N=250000)、(A=B=[1,2,\ldots,N])，所需的交换次数为 (125000^2=15625000000)。 在这种情况下，32 位整数会溢出。 Python 整数具有任意精度，因此实现不需要特殊的整数类型。 

在保持输入有效的同时，实际上无法满足“全等值”测试用例的请求，因为 (A) 和 (B) 是排列，因此不包含重复值。 最接近的相关情况是 (N=1)，其中整个排列由单个值 (1) 组成。 

## 方法

 暴力方法可以枚举 (1,\ldots,N) 的每个排列 (C)，计算

 [
 \sum_i |c_i-b_i|,
 ]

 保持最大值，并在所有最大化器中选择 (A) 中需要最少相邻交换的那个。 这是正确的，因为相邻交换可以到达每个排列，并且两个排列之间的相邻交换数量可以根据它们的相对顺序来计算。 问题在于候选人的数量。 有 (N!) 种排列，评估每一种排列需要 (N) 次操作，给出 (O(N\cdot N!)) 工作。 在 (N=10) 处，这已经是大约 (36) 万次值比较，并且阶乘增长使得该方法对于实际限制毫无用处。 

第一个有用的观察是重写目标。 自从

 [
 |x-y|=x+y-2\min(x,y),
 ]

 我们有

 \sum_i c_i+\sum_i b_i-2\sum_i\min(c_i,b_i)。 
]

 两个排列都包含 (1,\ldots,N)，因此前两个和是固定的。 最大化原始表达式与最小化完全相同

 [
 \sum_i\min(c_i,b_i)。 
]

 现在按阈值扩展每个最小值：

 [
 \min(x,y)=\sum_{t=1}^{N}[x\ge t\text{ 和 }y\ge t]。 
]

 对于固定阈值 (t)，恰好 (N-t+1) 个位置在 (C) 中包含至少 (t) 个值，并且完全相同数量的位置具有 (b_i\ge t)。 如果 (N) 个元素集的两个子集都包含 (k) 个元素，则它们的交集的大小至少为

 [
 \max(0,2k-N)。 
]

因此，每个阈值对 (\sum_i\min(c_i,b_i)) 的贡献都有一个下限。 

关键的阈值在中间附近。 让(N=2m)。 (C) 的 (m) 个最大值，即 (m+1,\ldots,2m) 必须占据 (B) 值位于 (m) 个最小值之间的位置。 否则，两组（m）位置将重叠，使得阈值贡献大于其最小值。 

对于奇数 (N=2m+1) 的相同推理表明，值 (m+2,\ldots,2m+1) 必须占据 (B) 在 (1,\ldots,m) 之间的位置，值 (1,\ldots,m) 必须占据 (B) 在 (m+2,\ldots,2m+1) 之间的位置，并且中间值 (m+1) 必须与中间值 (B=m+1) 配对。 

在每个组中，确切的顺序不会影响最大值。 这是关键的简化。 我们不需要决定哪个特定的大值进入哪个低（B）位置。 我们只需要将元素移动到正确的组中即可。 

这将原始排列问题转换为类别字符串上更简单的问题。 对于偶数 (N)，每个值要么属于低半部分，要么属于高半部分。 对于奇数 (N)，有一个附加的中间类别仅包含一个值。 每个位置的目标类别直接由其 (B) 值确定。 

将一个类别序列转换为另一个类别序列所需的最小相邻交换次数可以通过将每个类别的第一次出现与第一个目标出现、第二次出现与第二个目标出现等进行匹配来获得。 对于固定类别，跨越两次出现的同一类别无济于事，因此按顺序匹配它们是最佳选择。 如果当前出现位置为 (p_1,p_2,\ldots) 且目标位置为 (q_1,q_2,\ldots)，则它们对总位置移动的贡献为

 [
 \sum_j |p_j-q_j|。 
]

 每个相邻的交换都会将两个元素移动一个位置，因此所有类别的总和会将每个交换计算两次。 因此，答案是总位置运动的一半。 

因此最终的算法是线性的。 我们对（A）中的每个值进行分类，根据其（B）值对每个位置进行分类，收集每个类别的出现位置，并匹配相应的出现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(N\cdot N!)) | (O(N)) | 太慢了|
 | 最佳 | (O(N)) | (O(N)) | 已接受 |

 ## 算法演练

 1.设(m=\lfloor N/2\rfloor)。 定义 (A) 值的类别。 值 (1,\ldots,m) 属于低类别，值 (m+2,\ldots,N) 属于高类别，当 (N) 为奇数时，值 (m+1) 属于中类别。 

该分类准确地捕获了可以出现在最佳排列中的三个组。 
2. 根据（B）中每个位置的值对每个位置进行分类。 如果 (B_i\le m)，则最佳排列必须在那里放置一个高 (A) 值。 如果 (B_i>m+1)，则必须在那里放置一个低 (A) 值。 对于奇数（N），具有（B_i=m+1）的唯一位置必须接收中间值。 

对于偶数 (N)，没有中间类别，因此条件只是交换低半部分和高半部分。 
3. 扫描 (A) 并记录每个类别当前出现的位置。 还扫描由（B）引起的目标类别并记录每个类别必须出现的位置。 

某一类别内的确切值并不重要。 这就是为什么仅记录类别就足够了。 
4. 对于每个类别，按从左到右的顺序将其当前出现的情况和目标出现的情况配对。 添加每个配对位置之间的绝对差。 

以其他顺序匹配出现将迫使两个相同类别的元素交叉。 由于它们在目标上是可以互换的，因此这种交叉只能增加交换，而不能改善结果。 
5. 将总位置运动除以二并打印。 

每个相邻的交换将一个元素向左移动一个位置，并将另一个元素向右移动一个位置。 因此，它恰好对绝对位置变化的总和做出了 (2) 的贡献。 

### 为什么它有效

阈值论证证明每个最大化排列在每个位置都具有所需的类别。 相反，满足这些类别要求的任何排列同时达到所有阈值下界，因此它正在最大化。 一旦类别固定，属于同一类别的值对于目标来说是可以互换的。 两个类别序列之间的最小相邻交换变换是通过按顺序匹配相同类别出现来获得的。 因此，计算出的位置移动恰好是最小交换次数的两倍，并且算法返回所需的最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    m = n // 2

    # Categories:
    # 0 = low values
    # 1 = middle value, only for odd n
    # 2 = high values
    #
    # Store positions of each category in the current A
    # and in the required target category sequence.
    cur = [[], [], []]
    target = [[], [], []]

    for i, x in enumerate(a):
        if x <= m:
            cur[0].append(i)
        elif n % 2 == 1 and x == m + 1:
            cur[1].append(i)
        else:
            cur[2].append(i)

    for i, x in enumerate(b):
        if x <= m:
            # Small B values need large A values.
            target[2].append(i)
        elif n % 2 == 1 and x == m + 1:
            # The middle value must meet the middle value.
            target[1].append(i)
        else:
            # Large B values need small A values.
            target[0].append(i)

    movement = 0

    for c in range(3):
        for p, q in zip(cur[c], target[c]):
            movement += abs(p - q)

    print(movement // 2)

if __name__ == "__main__":
    solve()
```第一个循环按数值对 (A) 中的元素进行分类。 对于偶数 (N)，低半部分是 (1,\ldots,N/2)，而每个较大的值都属于高半部分。 对于奇数 (N)，单个值 ((N+1)/2) 接收其自己的类别。 

第二个循环从另一个方向执行相同的分类。 在最佳布置中，较小的 (B_i) 需要较大的 (A) 值，而较大的 (B_i) 需要较小的 (A) 值。 对于奇数（N），中间位置必须接收中间值。 

位置存储为从零开始的索引。 这很方便，因为两个位置之间的距离仍然恰好是在它们之间移动元素所需的相邻交换的数量。 无需进行边界调整。 

这`zip`操作按照自然的从左到右的顺序对出现的事件进行配对。 两个列表包含相同的出现次数，因为 (A) 和 (B) 都是排列。 总移动量在所有类别上累积并除以二，因为每个相邻交换恰好改变两个元素的位置。 

答案可以超过 (2^{31}-1)，但 Python 整数会根据需要自动扩展。 最大可能的答案约为 (N^2)，这可以通过 Python 的整数算术轻松处理。

 ### 示例 1

 输入是```
3
1 2 3
1 2 3
```这里（N=3）和（m=1）。 (1) 为低值，(2) 为中值，(3) 为高值。 

| 职位| 一个值 | 当前类别 | B值| 目标类别|
 | ---| ---| ---| ---| ---|
 | 0 | 1 | 低| 1 | 高|
 | 1 | 2 | 中| 2 | 中|
 | 2 | 3 | 高| 3 | 低|

 低类别当前位于位置 (0)，但必须位于位置 (2)，贡献 (2)。 高类别从位置 (2) 移动到位置 (0)，贡献另一个位置 (2)。 中间类别不动。 

| 类别 | 当前位置 | 目标职位| 运动|
 | ---| ---| ---| ---|
 | 低| [0]| [2] | 2 |
 | 中| [1] | [1] | 0 |
 | 高| [2] | [0]| 2 |

 总运动量为 (4)，因此答案为 (4/2=2)。 

这说明了为什么不需要反转 (A)。 目标可以是 ([2,3,1])，它具有相同的最大目标并且只需要两次交换。 

### 示例 2

 输入是```
4
3 4 1 2
3 2 4 1
```现在 (N=4) 和 (m=2)。 值 (1,2) 较低，而 (3,4) 较高。 

| 职位| 一个值 | 当前类别 | B值| 目标类别|
 | ---| ---| ---| ---| ---|
 | 0 | 3 | 高| 3 | 低|
 | 1 | 4 | 高| 2 | 高|
 | 2 | 1 | 低| 4 | 低|
 | 3 | 2 | 低| 1 | 高|

 高值当前占据位置 (0,1)，但它们需要位置 (1,3)。 他们的运动是

 [
 |0-1|+|1-3|=3。 
]

 低值从位置 (2,3) 移动到位置 (0,2)，也对 (3) 产生影响。 

| 类别 | 当前位置 | 目标职位| 运动|
 | ---| ---| ---| ---|
 | 低| [2, 3] | [0, 2] | 3 |
 | 高| [0, 1] | [1, 3] | 3 |

 总移动量为 (6)，因此最小交换次数为 (6/2=3)。 

这也说明了为什么我们不需要决定目标位置的最终高值应该是 (3,4) 还是 (4,3)。 两种选择都同样好，出现匹配会自动选择相对于原始 (A) 更便宜的排序。

## 边缘情况

 对于 (N=1)，输入```
1
1
1
```只有一种可能的安排。 中间类别包含单个值，其当前位置和目标位置均为零，并且移动为零。 该算法打印 (0)。 

对于偶数边界 (N=2)，```
2
1 2
1 2
```第一个 (B) 位置的值较低，因此需要较高的值 (2)。 第二个位置需要低值 (1)。 当前类别顺序为 Low、High，而目标类别顺序为 High、Low。 两个类别的出现各移动一个位置，给出总移动 (2) 和答案 (1)。 

对于奇数情况（N=3），```
3
1 2 3
1 2 3
```中间值（2）必须保持在中间位置，而（1）和（3）交换类别。 低出现次数和高出现次数各移动两个位置，给出总移动 (4) 和答案 (2)。 这正是盲目选择完全反向排列会高估所需交换次数的情况。 

对于已经是最佳的配置，```
4
3 4 1 2
1 2 3 4
```前两个位置具有较小的 (B) 值，并且已经包含较大的 (A) 值 (3,4)。 最后两个位置具有较大的 (B) 值，并且已包含较低的值 (1,2)。 每个当前类别位置都与其目标位置相匹配，因此移动为零并且不需要交换。 

对于最大尺寸的情况，取 (N=250000) 和 (A=B=[1,2,\ldots,N])。 前 (125000) 个位置当前包含低值，但必须包含高值，而最后 (125000) 个位置包含高值，但必须包含低值。 每个低值出现必须与每个高值出现交叉，产生

 [
 125000\cdot125000=15625000000
 ]

 相邻的互换。 该算法准确地获得了该值，而无需构建最终的排列。
