 ## 解决方案
 ## 问题理解

 对于每种花类型，花束可以包含一定数量的该类型的花，并且每当使用一种类型时，其选择的数量必须是奇数。 我们想要尽可能多的花总数。 某种类型根本不必出现在花束中，因此它的贡献可能为零。 

对于一种类型`a_i`可用的花，最好的奇数贡献就是不超过的最大奇数`a_i`。 如果`a_i`已经很奇怪了，我们可以全部使用。 如果`a_i`是偶数，必须留下一朵花，所以贡献度变成`a_i - 1`。 

对每种类型独立进行此调整后，每个非零贡献都是奇数。 现在总数的奇偶性仅取决于我们使用的类型数量。 奇数个奇数的和为奇数，偶数个奇数的和为偶数。 因此，如果`n`很奇怪，我们可以保留每种类型。 如果`n`是偶数，我们必须完全省略一种类型。 为了尽可能减少损失，我们忽略调整后贡献最小的类型。 

约束条件`n <= 100000`意味着解决方案应该在大致线性的时间内处理数组。 一个`O(n^2)`方法可以执行`10^10`操作的上限，远远超出了一秒的限制。 甚至一个`O(n log n)`这里不需要方法，因为答案只需要一个总和和一个最小值。 个人价值观满足`a_i <= 1000`，因此答案很容易适合标准的 32 位整数，尽管 Python 整数也可以自然地处理它。 

有几种边缘情况可能会欺骗仅专注于使每个选定计数为奇数的实现。 例如，对于一种类型，```
1
2
```最大的有效花束包含`1`花，不是`2`，因为唯一可用的计数必须是奇数。 

当类型数量为偶数时，我们必须删除一整个类型。 例如，```
2
2 3
```变为调整后的计数`1`和`3`。 保留两者都给予`4`，它是偶数，所以正确答案是`3`。 一个粗心的解决方案只是将每种类型的最大奇数计数相加，就会输出`4`。 

我们删除的类型应该在将其可用计数调整为奇数之后选择。 例如，```
4
2 7 4 9
```变成`1, 7, 3, 9`。 由于有四种类型，因此必须省略一种，并删除贡献`1`给出最大答案`19`。 根据原件选择类型`a_i`不考虑奇数调整可能会做出错误的选择。 

## 方法

 直接的暴力方法可以考虑花类型的每个子集。 对于每个子集，我们将从每个选定类型中取出最大的可能奇数，将这些贡献相加，检查选定类型的数量是否为奇数，并保留最大的有效总数。 这是正确的，因为一旦选定类型的集合固定，从任何选定类型中取出较少的花只会使花束变小。 

问题是子集的数量。 和`n`类型有`2^n`可能的子集。 在`n = 100000`，这是关于`10^30103`可能性，因此即使在恒定时间内检查一个子集也是没有希望的。 蛮力之所以有效，是因为它明确地探索了所有可能的类型集合，但当类型数量变大时，它就会失败。 

关键的观察消除了几乎所有这些选择。 对于每种类型，除了其最大可用奇数之外，没有任何理由采取任何东西。 调整后，每种使用的类型都会贡献奇数。 因此，唯一剩下的决定是使用多少类型。 如果`n`是奇数，使用所有类型已经给出奇数总数。 如果`n`是偶数，使用所有类型得到偶数总数，因此必须省略一种类型。 由于所有调整后的贡献都是正的，省略不止一种类型只会使答案更小。 最好的省略类型就是调整后贡献最小的类型。 

这将整个问题简化为一次遍历数组，保持调整后的奇数计数及其最小值之和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(2^n * n)`|`O(n)`| 太慢了|
 | 最佳 |`O(n)`|`O(1)`额外 | 已接受 |

 ## 算法演练

 1. 阅读`n`可用的花数并初始化总和和最小调整贡献。 
2. 对于每一个`a_i`，将其转换为不超过它的最大奇数。 如果`a_i`是偶数，减一。 将调整后的值添加到总数中并更新最小值。 

这对于个体类型来说是最佳的，因为将奇数贡献减少任何正数都会使其无效或使花束变小。 
3.如果`n`为奇数，保持总数不变。 每个调整后的贡献都是奇数，而且它们的数量也是奇数，因此它们的总和也是奇数。 
4. 如果`n`为偶数时，从总数中减去调整后的最小贡献。 这有效地忽略了整个花型，留下`n - 1`使用的类型。 自从`n - 1`是奇数，所得的和是奇数。 

只删除一种类型是最佳的，因为所有调整后的贡献都是正的，并且在所有单一类型中，删除最小的一种会损失最少的花朵。 
5. 打印结果总计。 

### 为什么它有效

 调整后，我们可能包含的每种类型都会贡献一个正奇数，这就是该类型的最大有效贡献。 因此，任何最佳花束都会对其包含的每种类型使用最大奇数贡献。 

奇数之和的奇偶性由项数决定。 什么时候`n`为奇数，则可以使用所有调整后的捐款，并且总数自动为奇数。 什么时候`n`是偶数，使用所有贡献会产生偶数总和，因此奇数总数需要奇数个已使用类型。 最大的这个数字是`n - 1`，意味着应该删除一种类型。 由于每个调整后的贡献都是正的，因此删除更多类型并不能改善答案，并且删除最小的贡献会得到最大的剩余总和。 因此，该算法总是构建最佳花束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    total = 0
    mn = 10**18

    for x in a:
        if x % 2 == 0:
            x -= 1

        total += x
        mn = min(mn, x)

    if n % 2 == 0:
        total -= mn

    print(total)

if __name__ == "__main__":
    solve()
```该循环一起执行前两个算法步骤。 对于一个均匀的`x`，减一最多变为最大的奇数值`x`。 对于一个奇怪的`x`，没有任何变化。 然后将调整后的值添加到`total`， 尽管`mn`如果类型数量是偶数，则记录要删除的最便宜的类型。 

奇偶校验使用`n`， 不是`total`。 一旦调整后的贡献均为奇数，则其总和的奇偶性完全由贡献的数量决定。 其中奇数个给出奇数和，而偶数个给出偶数和。 

什么时候`n`是偶数，`mn`保证存在，因为`n >= 1`，并且每个调整值至少是`1`。 减法`mn`删除一种类型的全部贡献。 在偶数情况下不存在差一问题，因为剩余的已使用类型数量恰好是`n - 1`。 

Python的整数类型不会溢出，最大可能的答案如下`100000 * 999`，因此即使是 32 位有符号整数也足够了。

 ## 边缘情况

 对于单一类型，不存在涉及省略类型的奇偶校验调整，因为`n`已经很奇怪了。 为了```
1
2
```价值`2`减少为`1`，给出答案`1`。 拿走两朵花将违反该类型的所选计数为奇数的要求。 

当类型数量为偶数时，保留每个调整后的贡献始终会产生偶数总数。 考虑```
2
2 3
```调整后的值为`1`和`3`，其总和为`4`。 该算法找到最小贡献`1`并减去它，留下`3`。 生成的花束使用一种类型，具有奇数朵花，并且数量最多。 

最小调整贡献可以来自原始计数为偶数的类型。 为了```
4
2 7 4 9
```调整后的值为`1, 7, 3, 9`。 最小的是`1`，因此算法删除该类型并返回`19`。 仅查看原始值可能会错误地表明`2`不是一个有意义的候选者，因为它是偶数，但在执行奇数计数要求后，它的实际贡献是`1`。 

最后，即使在边界情况下，最大可用计数也是其本身`a_i = 1000`。 为了```
2
1 1000
```调整后的捐款为`1`和`999`。 由于有两种类型，必须省略一种，并删除贡献`1`给出`999`。 这会检查偶数转换和最大允许值的最小移除逻辑`a_i`。
