 ## 解决方案
 ## 问题理解

 该问题使用历史年份编号系统，其中没有零年。 纪元开始之后的年份写为正整数，而纪元之前的年份写为负整数。 因此，年份的顺序是：`..., -3, -2, -1, 1, 2, 3, ...`我们得到一个事件发生的年份以及它与另一事件相隔的年数。 正分离意味着时间向前移动，负分离意味着时间向后移动。 任务是使用这种不寻常的编号系统找到第二个事件的年份。 

这些值可以大到$10^9$以绝对值表示。 这立即排除了逐年模拟运动的可能性，因为这种规模的循环需要多达 20 亿次迭代。 该解决方案必须使用具有恒定时间运算的直接算术。 

棘手的部分是普通的整数加法不起作用，因为日历从年份跳转`-1`直接到年份`1`。 例如，一年后搬家`-1`给出`1`， 不是`0`。 任何简单计算的解决方案`A + n`在这个转变过程中将会失败。 

考虑输入：```
-1
1
```正确的输出是：```
1
```使用普通算术的粗心实现会产生`0`，这不是有效的年份。 

另一个边界情况是从第一个正年份向后移动：```
1
-1
```正确的输出是：```
-1
```正常减法给出`0`，再次产生一个不存在的年份。 

## 方法

 直接的做法是不断地从当前年度向目标迈进。 如果距离为正，我们将年份一次递增。 如果距离为负，我们将一次递减它一步。 这很容易理解，因为每次操作都恰好代表一年的移动。 但是，如果距离有绝对值$10^9$，这会执行十亿次迭代，这远远超出了程序在时间限制内可以完成的范围。 

关键的观察是日历中唯一不寻常的部分是缺少零年。 我们可以暂时将历史年份编号转换为正常的连续整数线。 

对于此转换，将每个正年份映射到其自身。 负年份会移动一位，因为缺少零会产生间隙。 变换是：```
year > 0  -> year
year < 0  -> year + 1
```现在序列变得连续：```
-3 -> -2
-2 -> -1
-1 -> 0
 1 -> 1
 2 -> 2
 3 -> 3
```在这个变换的空间中，移动`n`年只是添加`n`。 之后，我们将结果转换回来。 大于零的值已经是正年份，而零和负值对应于纪元之前的年份，需要向后移一位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O( | n | ) |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将起始年份转换为连续表示。 如果年份为正，则保持不变。 如果是负数，则加一，以便当年`-1`变为零。 
2. 将给定的年数添加到转换后的值上。 这是有效的，因为转换后的时间线没有间隙。 
3. 将转换后的年份转换回原始日历格式。 正变换值保持不变，而零变换值和负变换值减一。 

为什么有效：该转换在真实历史年份和普通整数之间创建了一对一的映射。 历史上每个相邻的年份都会成为一个相邻的整数，包括之间的过渡`-1`和`1`。 由于此映射保留了事件之间的距离，因此添加`n`在变换后的空间中给出了正确的目的地年份。 反向变换恢复所需的历史符号。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def to_linear(year):
    if year > 0:
        return year
    return year + 1

def from_linear(value):
    if value > 0:
        return value
    return value - 1

def solve():
    a = int(input())
    n = int(input())

    current = to_linear(a)
    answer = from_linear(current + n)

    print(answer)

if __name__ == "__main__":
    solve()
```功能`to_linear`消除了缺失的年份差距。 重要的边界是`-1`，这变成`0`，使其与年份直接相邻`1`，表示为`1`。 

加法仅在转换后完成，因此程序永远不会创建无效的零年份作为最终答案。 功能`from_linear`通过将所有非正转换值移回负历史年份来处理反向转换。 

不使用循环或大数组，因此即使对于最大允许值，实现也保持恒定时间。

 ## 边缘情况

 对于输入：```
-1
1
```该算法转换`-1`转化为线性值`0`。 加一年后，该值变为`1`。 因为是正数，所以反向转换返回`1`。 这可以避免输出无效的零年份。 

对于输入：```
1
-1
```该算法转换`1`转化为线性值`1`。 减去一给出`0`。 反向转换将零变为`-1`，正确返回纪元之前的年份。 

对于输入：```
-1000000000
2000000000
```转换将起始值更改为`-999999999`。 添加距离得出`1000000001`，它转换回`1000000001`。 计算保持恒定时间，因为它从不遍历个别年份。
