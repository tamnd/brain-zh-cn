 ## 解决方案
 ## 问题理解

 该问题模拟了三台排成一排的投影仪。 它们按照左、中、右、中的重复顺序一次打开一秒。 左侧投影仪可用于`A`总共秒数，中间的秒数为`B`秒，以及正确的一秒`C`秒。 任务是找出在下一台应打开的投影仪没有剩余寿命之前该过程会持续多少秒。 原始陈述来自 Codeforces Gym 问题 102747B。 

输入由三个非负整数组成，表示左、中、右投影仪的可用操作秒数。 输出是无限转动序列的最长有效前缀的长度。 

约束的重要部分是可用工作总量可以大到大约`2 * 10^9`。 每秒打开一台投影仪的模拟可能需要数十亿次迭代，这对于较短的时间限制来说太慢了。 我们需要使用序列的重复结构并立即跳过大量操作。 由于只有三个值，因此预期的解决方案应该接近恒定时间。 

一些边缘情况可能会破坏直接模拟或错误的公式。 如果中间的投影仪没有寿命，则该过程立即停止。```
Input:
0
5
7

Output:
0
```在检查可用性之前始终添加一个完整周期的解决方案会错误地计算从未发生过的秒数。 

另一个棘手的情况是当其中一个侧投影仪在一个周期结束时恰好耗尽。```
Input:
1
2
1

Output:
4
```顺序是左、中、右、中。 四秒后，所有可用生命周期均已用完，但下一个左侧投影仪激活失败。 计算失败的激活会产生`5`。 

第三个常见错误是将中间的投影仪视为其他投影仪。 每四秒使用两次，因此不能与左右投影仪分组。```
Input:
10
1
10

Output:
1
```仅发生第一个左侧激活。 下一个需要激活的是中间的投影仪，它已经耗尽了它的一秒钟。 

## 方法

 直接的做法是重复执行该顺序并减少当前投影机的剩余寿命。 每一秒执行一次操作，答案是遇到零生命周期之前成功操作的次数。 这种方法很容易被证明是正确的，因为它完全遵循声明所描述的过程。 

当可用生命周期很大时就会出现问题。 在最坏的情况下，如果所有三个值都接近`10^9`，模拟需要数十亿步。 时间复杂度与答案本身成正比，这是不可接受的。 

有用的观察来自于固定的模式。 每四秒，该过程总是消耗左侧投影仪 1 秒、中间投影仪 2 秒和右侧投影仪 1 秒。 我们可以跳过尽可能多的完整的四个激活组，而不是单独处理这四个激活。 

完整周期的数量受到无法在另一个周期中生存的第一台投影仪的限制。 一个周期需要左一秒、中间两秒、右一秒，因此完整周期的数量为：`min(A, B // 2, C)`删除这些完整的循环后，最多还需要检查四个激活。 这是有效的，因为唯一剩下的故障必须发生在下一个不完整的周期内。

 ## 算法演练

 1. 了解投影机的三个可用寿命。 
2. 计算可以发生多少个完整的四秒周期。 一个周期消耗左一秒、中间两秒和右一秒，因此完整周期的数量受到以下限制：`min(A, B // 2, C)`。 
3. 每个完整周期增加四秒，并减去所有三台投影机的使用寿命。 在这一步之后，至少有一台投影仪无法完成另一个完整的循环。 
4. 按左、中、右、中的顺序检查接下来的几个激活。 由于完整的循环已不再可能，因此无需检查这四个位置以外的位置。 如果当前投影仪还有寿命，则消耗一秒，增加答案。 否则，停止。 
5. 打印累计成功秒数。 

为什么它有效：

 该算法保留每台投影仪消耗的确切秒数。 一个完整的循环有固定的消耗模式，因此用循环跳转替换许多单独的操作不会改变系统的状态。 在完成最大可能数量的完整周期后，剩余状态无法再经历另一个完整周期。 唯一可能的延续是下一个循环的前缀，并且检查该前缀直接给出准确的最终长度。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())
    c = int(input())

    cycles = min(a, b // 2, c)

    ans = cycles * 4
    a -= cycles
    b -= cycles * 2
    c -= cycles

    for i in range(4):
        if i == 0 or i == 2:
            if i == 0:
                if a == 0:
                    break
                a -= 1
            else:
                if c == 0:
                    break
                c -= 1
        else:
            if b == 0:
                break
            b -= 1
        ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```代码的第一部分删除了所有可能的完整循环。 表达式`min(a, b // 2, c)`直接代表限制资源，因为每个周期都需要这些数量。 

减少之后，剩余的值很小，因为只能发生一个部分循环。 该循环处理重复模式中的四个可能的位置。 该代码在减少资源之前进行检查，这避免了对失败的激活进行计数。 

不存在索引问题，因为序列长度是固定的。 Python 整数也足以获得最大答案，因为总可用生命周期受到问题约束的限制。

 ## 边缘情况

 对于第一个所需投影仪的零寿命，该算法计算零个完整周期，并且剩余的四步检查立即停止。 例如：```
0
5
7
```第一个激活的是左侧投影仪，但它没有剩余秒数，所以答案是`0`。 

对于精确的循环耗尽：```
1
2
1
```该算法需要一个完整的周期，因为`min(1, 2 // 2, 1) = 1`。 它消耗所有资源并记录四秒。 下一次检查失败，因为左侧投影仪是空的，所以答案仍然存在`4`。 

对于中间投影机限制：```
10
1
10
```完整循环的数量为零，因为`1 // 2 = 0`。 剩余的模拟激活左侧投影仪一次，然后发现中间投影仪无法打开。 结果是`1`，符合实际流程。
