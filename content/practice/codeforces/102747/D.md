 ## 解决方案
 ## 问题理解

 该问题描述了由两种部件制成的过山车。 特殊部分已经存在，每个部分都会改变火车速度：当火车进入特殊部分时，它必须具有一种速度，而当它离开时，它具有另一种速度。 在特殊部件之间我们可以建造普通轨道，而普通轨道只能减慢火车速度。 任务是为所有特殊部件选择一个顺序，并添加普通轨道的最小总长度，以便整个骑行成为可能。 输入给出了每个特殊片段的开始和结束速度，输出是所需的最小附加轨道量。 这是 IOI 2016 Roller Coaster Railroad 任务，原来的完整约束允许多达 200000 个特殊路段。 

困难在于特殊件的顺序不固定。 直接方法会尝试每种可能的排序，但可能的排序数量会随着阶乘而增长。 即使对于几十块，这也是不可能的，因此最终的解决方案必须避免依赖于排列的数量。 

大的约束意味着算法必须接近线性或近线性。 对于 200000 个部分，诸如子集动态规划或尝试所有订单之类的方法将立即被排除。 成功的解决方案使用排序、图形连接和最小生成树，所有这些都可以轻松地满足所需的规模。 

有几种情况很容易处理不当。 仅按照输入顺序贪婪地连接各个部分的解决方案会失败，因为顺序是决策的一部分。 例如，如果输入是：```
2
10 1
1 10
```正确的输出是`0`。 两个特殊部分可以连续放置，因为第一个部分以速度 1 离开火车，第二个部分接受速度 1。始终在相邻输入条目之间添加轨道的方法会错误地添加不必要的长度。 

另一个常见的错误是忘记火车需要有效的开始和结束状态。 例如：```
2
5 10
1 2
```仅通过检查两部分之间的间隙并不能得到答案。 第一个路段要求列车以5速到达，但从0速开始行驶，因此在第一个特殊路段之前需要进行额外的施工。 最终算法通过引入人工部分来处理这些边界要求。 

当许多部分已经可以以零额外长度连接时，就会出现第三种边缘情况。 例如：```
3
1 3
3 5
5 7
```答案是`0`。 粗心的实现可能会添加轨道，因为它只检查结束速度是否大于下一个起始速度，然后再考虑各部分可以按不同的顺序链接。 

## 方法

 暴力解决方案将问题视为排序问题。 它尝试特殊部分的每种排列，计算连续部分之间所需的轨道，并保留最小值。 对于固定顺序，计算很简单，因为在一段速度结束后`x`，只有添加足够的轨道以将速度降低到所需值才能到达下一段。 如果转换需要速度`a`当前速度是`b`，增加的长度为`max(0, a - b)`。 

问题是有`n!`可能的订单。 在最大的约束条件下，这大约意味着`200000!`可能的安排，这远远超出了程序可以探索的范围。 

关键的观察是顺序可以用不同的方式表示。 将每个特殊部分视为从其进入速度到其离开速度的有向边。 沿着边缘移动会将当前速度从起始值更改为结束值。 我们需要通过在必要时添加普通轨道将这些边缘连接成一条连续的路径。 

这些边缘的平衡告诉我们相邻速度值之间需要多少额外的移动。 如果与进入某个速度级别相比，离开该速度级别的边缘太多，则必须添加一些反向运动。 如果太少，可以通过扩展路径免费连接现有的片段。 添加所有强制连接后，剩下的问题是某些组的部分仍然可能断开。 用最便宜的链路连接这些组就成为最小生成树问题。 

最终算法对起始速度和结束速度进行排序，添加强制跟踪成本，在相邻组件之间创建可能的连接，并运行 Kruskal 算法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.增加一个人工特殊路段，起始速度和结束速度非常大`0`。 这代表了整个骑行的开始和结束，使建筑可以被视为一条连续的路径，而不是一条两端开放的路径。 
2. 将所有起始速度和所有结束速度分别排序。 将排序的结束速度与排序的起始速度进行匹配。 当结束速度大于相应的起始速度时，必须支付缺失的差额作为附加赛道。 支付后，交换两个值，以便剩余的图形表示具有平衡的方向。 
3. 在每个匹配的终点和起点之间创建零成本连接。 这些连接表示将特殊部分直接放置在彼此之后，而无需额外的轨道。 
4. 在相邻排序组之间创建额外的可能连接。 连接两个相邻组的成本是它们之间的间隙（如果存在间隙）。 这些是唯一能够以尽可能低的成本连接先前分离的组件的连接。 
5. 在这些连接上运行 Kruskal 算法。 使用不相交的集合联合结构来跟踪哪些组已经连接。 每个选定的边都会为答案贡献其成本。 

这样做的原因是排序的匹配步骤消除了所有不可避免的速度不平衡。 之后，剩下的每个选择都只是关于连接独立的部分组。 在图中连接组的最便宜的方法正是最小生成树，并且克鲁斯卡尔算法找到了最小的总成本。 不变的是，在每个选择的 MST 边之后，当前连接的组在所有合并它们的方法中具有最便宜的可能成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        self.parent[b] = a
        return True

def solve():
    n = int(input())
    starts = []
    ends = []

    for i in range(n):
        s, t = map(int, input().split())
        starts.append((s, i))
        ends.append((t, i))

    inf = 10 ** 9
    starts.append((inf, n))
    ends.append((0, n))

    starts.sort()
    ends.sort()

    ans = 0
    for i in range(n + 1):
        if ends[i][0] > starts[i][0]:
            ans += ends[i][0] - starts[i][0]
            ends[i], starts[i] = (starts[i][0], ends[i][1]), (ends[i][0], starts[i][1])

    edges = []

    for i in range(n + 1):
        edges.append((0, ends[i][1], starts[i][1]))
        if i + 1 < n + 1:
            cost = max(0, starts[i + 1][0] - ends[i][0])
            edges.append((cost, starts[i + 1][1], ends[i][1]))

    edges.sort()

    dsu = DSU(n + 1)

    for cost, a, b in edges:
        if dsu.union(a, b):
            ans += cost

    print(ans)

solve()
```该解决方案首先将每个特殊路段存储为两个值：该路段之前的速度和该路段之后的速度。 添加了人工部分，以便排序匹配也考虑到整个骑行的开始和结束。 

排序阶段是最微妙的部分。 如果结束速度大于其匹配的起始速度，则必须插入普通轨道来弥补差异。 支付完毕后，交换值可以使剩余的不匹配结构保持平衡。 

边缘构建阶段仅创建可以出现在最佳解决方案中的连接。 零成本边代表直接转换，而相邻的排序组代表合并断开部分的最便宜的方式。 不相交集并集在选择 MST 边时可防止循环。 

所有值均可达到约`10^9`，并且最终答案可能比 32 位整数大得多。 Python 整数会自动处理此问题，因此不需要溢出处理。

 ## 边缘情况

 对于零成本连锁案例：```
3
1 3
3 5
5 7
```排序匹配发现，各个部分可以排列成一条连续的链。 强制成本为零，MST阶段只需要零成本边，所以最终答案不变`0`。 

对于直接转换的情况：```
2
10 1
1 10
```人工部分允许算法将整个骑行过程视为一条路径。 排序后的匹配正确匹配了所需的速度，发现两个特殊部分可以相互跟随，并且不添加不必要的轨道。 

对于没有额外轨道就无法开始骑行的情况：```
2
5 10
1 2
```人工起步部分暴露了缺失的速度提升。 该算法在平衡阶段支付所需的金额，而不是假设可以立即输入第一个给定部分。 

对于重复值：```
3
5 5
5 5
5 5
```所有特殊部分都有相同的行为。 排序阶段处理相等的值而不依赖于它们的顺序，并且MST阶段只需要零成本边来连接它们。 答案是`0`。
