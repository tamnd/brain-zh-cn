 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，并且允许我们选择一个整数$X$。 一次$X$是固定的，每个数组值都通过 XOR 进行转换$X$，我们关心最大的变换值。 目标是挑选$X$使得这个最大值尽可能小。 

重新表述该任务的一个有用方法是，我们尝试使用 XOR“对齐”所有数字，以便对齐后没有数字变得太大。 由于 XOR 独立于位起作用，因此选择$X$意味着我们正在一点一点地决定如何以一致的方式翻转所有数字。 

输入大小可达$10^5$，每个数字适合 30 位。 这立即排除了任何尝试所有可能的解决方案$X$， 自从$X$也有多达$2^{30}$的可能性。 甚至检查一名候选人$X$成本$O(n)$，所以暴力破解$X$需要大约$10^5 \cdot 2^{30}$，这是完全不可行的。 

该结构还表明，仅排序是不够的，因为 XOR 不保留顺序。 使用任意掩码应用异或后，两个值相近的数字可能会变得相距很远。 

天真的推理的一个微妙的失败案例是假设我们可以选择$X$贪婪地独立最小化每个元素。 例如，如果我们尝试通过选择来最小化最大值$X$这使得最大的元素变小，我们可以将较小的元素分解为大的元素。 

例子：```
n = 2
a = [0, 7]
```如果我们选择$X = 7$，那么结果就变成$[7, 0]$，最大值为 7。如果我们选择$X = 0$，最大值也是 7。 但是，只关注一个元素的贪婪想法忽略了异或同时影响两个元素，因此局部最小化并不可靠。 

关键的难点在于$X$必须同时控制所有数字的所有位。 

## 方法

 蛮力方法会尝试一切可能的方法$X$从$0$到$2^{30}-1$。 对于每个$X$, 计算所有$a_i \oplus X$并跟踪最大值。 这是正确的，因为它直接评估每个候选人的目标函数。 然而，它需要$2^{30}$候选人，以及每个候选人的成本$O(n)$，大致导致$10^{14}$操作，远远超出了限制。 

为了改善这一点，我们需要停止思考$X$作为一个平面数字，而是一点一点地构造它。 关键的观察是最大值取决于任何位置的最高位$a_i \oplus X$变成1。如果我们能保证没有数字超过二进制中的某个前缀，我们就可以限制最大值。 

这自然就产生了按位 trie 结构。 每个数字都是从根到深度30的路径。选择时$X$，我们以翻转分支的方式有效地遍历 trie。 目标变成：我们可以选择吗？$X$以便所有数字都保留在子树内以避免产生较大的异或结果？ 

我们将数字从最高有效位到最低有效位递归地分割。 在每一位，我们尝试决定在应用异或约束后是否可以将所有数字保留在一个分支内。 如果必须使用两个分支，则该位有助于答案。 

该问题简化为位位置上的分而治之，在每个级别上，我们尝试对齐数字，以使所得的 XOR 最大值最小化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n \cdot 2^{30})$|$O(1)$| 太慢了|
 | 按位 Trie / 分而治之 |$O(n \log A)$|$O(n \log A)$| 已接受 |

 ## 算法演练

 我们使用从最高有效位（位 29）到位 0 的位。在每个级别，我们维护一组数字和正在考虑的当前位。 

1. 从所有数字和最高位索引开始。 

这个想法是确定我们是否可以使答案小于当前位定义的阈值。 
2. 根据当前位将当前集合分为两组：位 0 的组和位 1 的组。 

这种分离很重要，因为 XOR 可以翻转位，但它无法在不一致影响所有元素的情况下合并组之间的结构差异。 
3. 如果其中一个组为空，我们仅继续处理下一位的非空组。 

这意味着在这一点上，所有数字都一致，因此我们不会在该位置的最终最大值中产生任何“成本”。 
4. 如果两个组都非空，我们就必须在答案中考虑这一位。 

我们无法选择一个$X$这使得两个组在此级别的行为相同，因此该位在最终结果中贡献 1。 然后我们对两组进行递归以获取较低位。 
5. 合并递归结果：当需要两个分支时，我们采用最大贡献，因为最终答案由最坏情况的转换值决定。 
6. 当到达位 -1 或当组仅包含一种无法再拆分的结构类型时，递归停止。 

其原理与异或如何影响二进制前缀有关。 在任何位级别，如果数字中同时存在 0 和 1，则任何 XOR 掩码都无法消除转换后某些对在该位处发散的事实。 该差异直接转化为最大 XOR 值的下限。 

该算法有效地找到最小的可能阈值，以便所有数字都可以在 XOR 下保持在一致的二进制分区内。 递归确保我们只为结构上不可避免的位“付费”。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    def dfs(arr, bit):
        if bit < 0 or len(arr) <= 1:
            return 0

        zero = []
        one = []

        for x in arr:
            if (x >> bit) & 1:
                one.append(x)
            else:
                zero.append(x)

        if not zero:
            return dfs(one, bit - 1)
        if not one:
            return dfs(zero, bit - 1)

        return (1 << bit) + min(dfs(zero, bit - 1), dfs(one, bit - 1))

    print(dfs(a, 29))

if __name__ == "__main__":
    solve()
```核心实现使用位位置的递归函数。 每次调用都会将当前集合划分为当前位中包含 0 或 1 的集合。 如果一侧是空的，我们可以完全忽略这一点并向下移动。 如果两者都存在，我们就被迫在最终答案中考虑这一点，所以我们添加$2^{bit}$并继续探索这两种可能性，取得更好的结果。 

递归编码了我们正在通过位构建约束树的想法。 每个级别的决策不是关于单个数字，而是关于选择后当前位是否可以在所有数字中统一$X$。

 ## 边缘情况

 一种重要的边缘情况是所有数字都相同。 例如：```
n = 3
a = [5, 5, 5]
```在每一位上，只存在一组，因此递归总是遵循一个分支。 该算法从不添加任何贡献，产生 0，这与选择的事实相匹配$X = 0$产生零最大差异。 

另一种情况是当数字形成完整的二进制集时，例如：```
0, 1, 2, 3
```在最高的不同位，两个组都存在，迫使做出贡献。 递归仅确保计算必要的分割，并且较低位不会引入额外成本，因为一旦以较高位为条件，每个子树就会变得均匀。
