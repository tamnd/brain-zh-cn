 ## 解决方案

 ## 问题理解

 我们得到一个整数$X$，我们需要将它分成两个正整数$a$和$b$这样它们的最小公倍数恰好是$X$。 在所有这些有效对中，我们想要最小化两个数字中较大者的那个。 

换句话说，我们不只是寻找任何因式分解$X$，但是一对“涵盖”所有素数幂$X$通过他们的 LCM，同时保持两个数字尽可能平衡，以便最大元素尽可能小。 

约束条件$X \le 10^{12}$立即排除对所有对进行任何二次甚至简单的线性搜索。 蛮力压倒一切$a \le X$是不可能的，因为$X$可以非常大并且大约有$10^6$最坏情况密度场景中的潜在除数。 

出现微妙的边缘情况时$X = 1$。 在这种情况下，双方$a = 1$和$b = 1$是必需的，因为 LCM(1,1) = 1，并且不存在其他对。 任何解决方案都必须明确处理这个问题或自然地收敛到它。 

另一个潜在的失败案例是假设选择$a$作为除数$X$和设置$b = X / a$始终有效。 但事实并非如此，因为 LCM 取决于素数指数，而不仅仅是产品结构。 例如，如果$X = 12$，选择$a = 4$,$b = 3$有效，但是$a = 6$,$b = 2$也有效； 然而，许多除数对，例如$a = 12$,$b = 1$有效但次优。 

关键难点是在优化最大值的同时保证LCM条件。 

## 方法

 蛮力的想法很简单：枚举所有对$(a, b)$这样$\text{lcm}(a, b) = X$，然后跟踪该对最小化$\max(a, b)$。 迫在眉睫的问题是，有$O(X)$候选人，即使我们限制为除数，也可以有$O(\sqrt{X})$除数，导致$O(D^2)$对。 和$X$最多$10^{12}$，这在计算上变得不可行。 

转折点是意识到两者$a$和$b$必须划分$X$，因为如果$\text{lcm}(a,b) = X$, 的每个素因数$a$和$b$已经包含在$X$。 所以我们只需要搜索$X$，不是任意整数。 

现在问题变成：除数对之间$a, b$，找到一个 LCM 等于$X$并最大限度地减少$\max(a,b)$。 如果我们固定一个除数$a$, 最小有效伙伴$b$不是任意的； 它必须准确贡献缺失的素数幂，以便 LCM 变为$X$。 

这导致更清洁的重新配制。 我们迭代所有除数$a \mid X$，并计算：$$b = \frac{X}{\gcd(a, X/a)}$$然而，一个更简单、更标准的观察可以解决一切：如果我们强制执行$a \cdot b = X$和$\gcd(a,b)=1$，则 LCM 变为$X$。 最优答案总是对应于分裂$X$分成两个互质部分。 目标是找到一个因子对$(a, b)$与产品$X$，然后检查哪对是互质的并最小化最大值。 

更直接地，最优解的已知结构是：我们尝试所有除数$a \le \sqrt{X}$， 放$b = X/a$，并通过计算 LCM$\text{lcm}(a,b) = X \cdot \frac{a}{\gcd(a,b)} / a = \frac{X}{\gcd(a,b)}$。 所以条件简化为$\gcd(a,b) = 1$。 在所有有效对中，我们选择最小化的一个$\max(a,b)$。 

因此，最佳解决方案是单次传递除数，最多可达$\sqrt{X}$，使用 gcd 检查。

 ## 算法演练

 我们将任务重写为寻找除数对$(a, b)$的$X$这样$a \cdot b = X$和$\gcd(a,b)=1$，最小化$\max(a,b)$。 

1. 迭代所有整数$i$从$1$到$\lfloor \sqrt{X} \rfloor$。 

我们只检查平方根，因为除数是对称对的$(i, X/i)$，我们希望避免多余的工作。 
2.如果$i$划分$X$， 放$a = i$和$b = X / i$。 

这确保我们只考虑有效的因子对。 
3. 计算$g = \gcd(a, b)$。 

此步骤检查该对是否共享会扭曲 LCM 的主要因素$X$。 
4.如果$g = 1$，该对对于 LCM 条件有效。 

然后我们考虑$\max(a,b)$作为候选答案。 
5. 跟踪最小化的对$\max(a,b)$所有有效候选人。 

答案是所有迭代后存储的最佳对。 

### 为什么它有效

 任何有效的解决方案必须仅使用来自$X$。 如果是一对$(a,b)$共享一个公共素因子，该因子在 LCM 中仅计算一次，这意味着 LCM 将严格小于$X$除非用更高的指数补偿，这将迫使其中一个数字超过相应的指数结构$X$。 最佳配置完全避免了重复，这意味着最佳对恰好是$X$。 检查所有除数确保考虑每种可能的分解，并最小化$\max(a,b)$确保平衡。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    x = int(input().strip())

    best_a, best_b = 1, x
    best_max = x

    i = 1
    while i * i <= x:
        if x % i == 0:
            a = i
            b = x // i

            if math.gcd(a, b) == 1:
                if max(a, b) < best_max:
                    best_a, best_b = a, b
                    best_max = max(a, b)

            # check the symmetric pair is not needed since (a,b) already covers it

        i += 1

    print(best_a, best_b)

if __name__ == "__main__":
    solve()
```该代码仅迭代至$\sqrt{X}$，确保效率$10^{12}$约束。 每个除数对都会测试一次，gcd 滤波保证了 LCM 条件的正确性。 每当找到更小的最大值时，就会更新最佳对，这直接对优化目标进行编码。 

一个微妙的细节是初始化：从$(1, X)$保证有效的基线，因为$\gcd(1,X)=1$总是成立。

 ## 边缘情况

 对于$X = 1$，循环运行一次$i = 1$。 我们得到$a = 1$,$b = 1$， 和$\gcd(1,1)=1$，因此算法返回 (1,1)，这是正确的。 

对于总理$X$，只有除数对是$(1,X)$。 由于 gcd 为 1，因此会自动选择它，并且不存在其他候选者。 

对于完美的正方形，例如$X = 36$，对称除数（如 (6,6)）无法通过 gcd 测试，因为 gcd 不为 1，从而防止无效的 LCM 约简。 只有像 (4,9) 这样的互质对才能生存，并且算法正确地选择最平衡的一对。 

对于像这样的大国$X = 10^{12}$，循环仍然只运行到$10^6$，并且 gcd 检查保持恒定时间。 该算法避免了对除数数量或分解深度的任何依赖，仅依赖于平方根枚举。
