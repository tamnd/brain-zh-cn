 ## 问题理解

 我们有一个代表纸杯蛋糕美味的数组和两个玩家。 亚西尔总是拿走所有纸杯蛋糕，总结全部内容。 Adel 可以选择任何**不**覆盖整个数组的连续子数组。 亚西尔想知道他的总美味是否严格大于阿德尔可以达到的**任何可能的总和**。 

输入由多个测试用例组成。 每个测试用例都会给出纸杯蛋糕的数量和味道值的数组。 如果 Yasser 始终具有严格更高的总数，则每个测试用例的输出为“是”，否则为“否”。 

查看约束条件，每个数组最多可以有$10^5$元素，所有测试用例的总数也是$10^5$。 这立即排除了任何$O(n^2)$方法，因为迭代所有子数组大致是$10^{10}$最坏情况下的操作。 需要线性或近线性解。 美味值可以是很大的负值或正值（$-10^9$到$10^9$），所以我们还需要小心具有固定大小整数的语言中的整数溢出，尽管 Python 会自动处理这个问题。 

当数组只有两个元素时，会出现微妙的边缘情况。 Adel 一次只能取一个元素，而 Yasser 的总和将始终等于两者的总和。 如果其中一个元素大于另一个元素，亚西尔就会很高兴；反之亦然。 如果 Adel 可以取的最大子数组总和等于 Yasser 的总和，则答案为“否”。 例如，当数组具有交替的正数和负数时，会出现另一种边缘情况`[5, -5, 5]`。 亚西尔的总和是`5`，但阿德尔可以选择最后一个`5`独自一人，与亚西尔的总数相当。 粗心的实现可能会忽略不获取整个数组的限制，或者无法正确考虑前缀和后缀子数组。 

## 方法

 暴力方法很简单：对于每个测试用例，计算 Yasser 的总和。 然后，对于 Adel 可以采用的每个有效子数组，计算其总和并与 Yasser 的进行比较。 这保证了正确性，因为我们确实检查了每种可能性。 然而，这是$O(n^2)$对于每个测试用例。 和$n$最多$10^5$，这太慢了。 

关键的见解来自于认识到唯一可能威胁 Yasser 的子数组是前缀或后缀。 任何完全位于数组内部且不接触边界的子数组的总和将严格小于延伸到边缘的某些前缀或后缀，因为我们可以包含更多元素，从而可能增加总和。 因此，检查前缀的最大和（不包括整个数组）和后缀的最大和就足够了。 如果这两者都严格小于 Yasser 的总和，则任何内部子数组都不能超过他的总和，答案为“是”。 否则，答案是“否”。 这将每个测试用例的复杂性降低到线性。

 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 通过对整个数组求和来计算 Yasser 的总和。 这很简单，并且构成了比较的基线。 
2. 计算最大前缀和，考虑排除最后一个元素的前缀。 将运行总和初始化为零，从第一个元素迭代到倒数第二个元素，将每个元素添加到运行总和中，并跟踪遇到的最大值。 我们停在倒数第二个，因为阿德尔无法获取完整的数组。 
3. 考虑排除第一个元素的后缀，计算最大后缀和。 将运行总和初始化为零，从最后一个元素反向迭代到第二个元素，将每个元素添加到运行总和中，并跟踪遇到的最大值。 我们从最后一个元素开始，因为如果我们想避免获取完整数组，则第一个元素不能包含在后缀中。 
4. 将 Yasser 的总数与最大前缀和后缀总和进行比较。 如果任一最大值大于或等于 Yasser 的总数，则打印“NO”。 否则，打印“YES”。 

为什么它有效：不变的是除完整数组之外的任何子数组的最大总和始终是前缀或后缀。 内部子数组以前缀和后缀之和为界。 通过确保没有任何前缀或后缀之和满足或超过 Yasser 的总和，我们保证 Adel 的任何子数组选择都不能超过 Yasser 的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        total = sum(a)
        
        # check max prefix sum excluding last element
        max_prefix = curr = 0
        for i in range(n - 1):
            curr += a[i]
            if curr > max_prefix:
                max_prefix = curr
        
        # check max suffix sum excluding first element
        max_suffix = curr = 0
        for i in range(n - 1, 0, -1):
            curr += a[i]
            if curr > max_suffix:
                max_suffix = curr
        
        if max_prefix >= total or max_suffix >= total:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    main()
```我们使用快速 I/O`sys.stdin.readline`由于测试用例的潜在数量。 前缀和后缀总和初始化为零并增量更新，确保正确处理负值。 通过将前缀停止在以下位置可以避免差一错误`n - 1`和后缀`1`。 比较使用`>=`因为幸福条件严格来说更大。
