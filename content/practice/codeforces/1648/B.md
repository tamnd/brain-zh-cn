 ## 解决方案
 ## 问题理解

 给定一个正整数的多重集，我们必须决定它是否在一个非常具体的操作下封闭：在分子至少是分母的任何有序元素对之间进行整数除法。 每当我们从数组中选取两个值，使用向下除法将较大的值除以较小的值时，结果也必须已经存在于数组中。 

输入由多个独立的测试用例组成。 每个测试用例都会为我们提供一个数组及其值的上限。 对于每种情况，我们必须决定在该地板划分操作下数组是否“闭合”。 

这些限制使我们远离任何试图显式测试所有对的方法。 由于测试用例中的总元素多达 100 万个，一个简单的双循环将需要大约 10^12 次操作，这远远超出了两秒内可行的范围。 即使稍微优化的对枚举也是不可能的。 

不明显的困难在于，条件不仅涉及存在的对，还涉及所有派生值。 一种简单的方法可能只检查数组中的现有对，但这忽略了每个可能的商必须已经存在的要求，即使它不是输入排序中任何“明显”交互的一部分。 

典型的失败情况是数组包含一个大数和一个小数但省略了中间商。 例如，如果存在 10 和 3，则如果 3 存在，则 Floor(10/3) = 3 就可以，但根据结构，floor(10/4) 或 Floor(10/6) 可能会产生缺失值。 即使缺少一个派生值也会使整个数组无效。 

## 方法

 暴力解决方案检查每个有序对 (x, y)，其中 x ≥ y，计算下限 (x/y)，并验证成员资格。 这是正确的，因为它直接强制执行定义。 然而，它是数组大小的二次方，并且对于大输入，这立即变得不可行。 

关键的观察是我们不需要显式地重新计算所有成对除法。 重要的是该集合是否包含可以作为现有元素的商形成的所有值。 由于所有值都以 c 为界，因此我们可以在频率数组中工作并模拟闭包。 

我们不是迭代元素，而是迭代值。 对于每个存在的值 y，我们尝试“生成”y 到 c 的所有倍数，并确保派生楼层的一致性。 这将问题转化为在值范围内类似筛子的传播过程。 

该结构类似于除法下的数论闭包：如果一个值存在，则该值的任意倍数除以该值的所有结果也必须存在。 这使我们能够以受控的方式从小值向上传播约束。

 ## 算法演练

 1.使用数组统计数组中每个数字的出现频率`freq`。 
2. 构建布尔存在数组`ok[x]`表示是否值`x`存在于数组中。 这允许 O(1) 成员资格检查。 
3. 对于每一个可能的值`y`从 1 到 c，只有当它存在于数组中时，我们才将其视为潜在除数。 
4. 对于每一个这样的`y`，我们迭代倍数`x = y, 2y, 3y, ...`直到c。 每个倍数贡献一个商`x // y`。 
5. 每个计算出的商必须存在于数组中。 如果我们发现缺少任何商，我们可以立即得出结论该数组不是整数。 
6. 如果我们完成所有检查且没有矛盾，则该数组是完整的。 

重要的微妙之处在于，我们只需要以结构化的方式检查现有值导出的商。 迭代倍数可以避免冗余对生成，同时仍然覆盖每个有效的楼层划分结果。 

### 为什么它有效

 x ≥ y 的每个有效对 (x, y) 都可以表示为 x = k·y + r，并且 Floor(x/y) = k。 通过迭代 y 的所有倍数，我们生成将 y 与某个较大元素配对时产生的每个可能的 k。 因此，如果缺少任何所需的商，将会在这次扫描期间发现。 频率数组确保我们正确地考虑存在而不是排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        a = list(map(int, input().split()))

        freq = [0] * (c + 1)
        for x in a:
            freq[x] += 1

        ok = [False] * (c + 1)
        for i in range(1, c + 1):
            if freq[i]:
                ok[i] = True

        bad = False

        for y in range(1, c + 1):
            if not ok[y]:
                continue

            for x in range(y, c + 1, y):
                q = x // y
                if not ok[q]:
                    bad = True
                    break

            if bad:
                break

        print("No" if bad else "Yes")

if __name__ == "__main__":
    solve()
```该代码首先将输入压缩到存在数组中，以便成员资格检查的时间恒定。 然后它迭代数组中实际出现的每个可能的除数候选 y。 对于每个这样的 y，它会遍历 y 的所有倍数并确保每个结果商都存在。 发现违规行为时尽早退出可确保效率。 

主要的微妙点是我们从不迭代原始对。 相反，我们将问题重构为倍数的算术级数，这保证了覆盖范围而不会出现二次爆炸。

 ## 边缘情况

 一个关键的边缘情况是当数组包含 1 时。由于每个整数除以 1 都会产生自身，因此 1 的存在强制一个非常强的闭包条件：所有值在除法链下必须是自洽的。 该算法自然地处理这个问题，因为对于 y = 1，每个 x 的倍数都会产生商 x，并且检查简化为验证闭包集中涉及的所有元素是否存在。 

另一种边缘情况是数组只有一个值。 在这种情况下，唯一可能的商是 1，仅当值本身为 1 时才有效。扫描可以正确确认或拒绝此情况，无需特殊大小写。 

最后一个重要的情况是稀疏数组，例如与不相关数字混合的 2 的幂。 这些很快就会失败，因为像 3、5 或 7 这样的中间商在多重扫描期间出现，即使它们不存在于输入中，从而确保了非闭包的早期检测。
