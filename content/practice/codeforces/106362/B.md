 ## 解决方案
 ## 问题理解

 任务是构建从 1 到 n 的整数排列，以最大化在排列上定义的某个“美”度量。 您不是选择任意数字或从固定数组中计算值，而是需要对 1 到 n 进行重新排序，以使给定分数尽可能大。 

分数的结构基于排列中相邻元素之间的相互作用。 每对相邻的值根据两个值之间的距离对整体美感做出贡献。 由于每个元素最多参与两个邻接关系，因此大数相对于小数的放置方式决定了最终结果。 

尽管最初的陈述提出了一个类似于公式的界限，在偶数和奇数 n 之间有所不同，但关键的结论是，最佳结构遵循数字下半部分和上半部分之间非常规则的交替模式。 最终可实现的结果仅取决于可以创建多少个这样的有效大-小配对，结果简化为单独的 n 函数。 

从复杂性的角度来看，n 可以足够大，以至于任何二次甚至$O(n \log n)$涉及重复模拟或排列优化的策略是不必要的。 该结构强烈表明答案是建设性的和线性的，因为我们只需要输出一个排列而不是搜索多个排列。 

一种天真的误解是尝试所有排列并计算每种排列的美感。 对于 n = 10，这已经涉及 10！ 的可能性，这远远超出了可行的计算。 即使尝试没有结构的贪婪交换也可能会失败，因为局部改进不能保证全局最优。 

当 n 很小时，会出现微妙的边缘情况。 对于 n = 1 或 n = 2，排列空间是微不足道的，任何构造仍然必须与一般规则保持一致。 另一个边缘情况是偶数 n 和奇数 n 之间的过渡，其中交替结构中的中心元素表现不同，但不会改变整体最优策略。 

## 方法

 强力方法将生成 1 到 n 的每个排列，通过迭代相邻对来计算每个排列的美观分数，并取最大值。 这在概念上是正确的，因为它直接评估定义。 然而，它需要生成n！ 排列并为每个排列计算 O(n) 分数，从而产生 O(n · n!) 次操作。 即使对于中等的 n，这也立即变得不可行。 

关键的结构见解是，巨大的贡献来自于尽可能频繁地将小值与大值配对。 如果我们将排序顺序两端的数字彼此相邻放置，则每个邻接的贡献都接近最大可能的差异。 因此，最优策略在值的上半部分和下半部分之间交替。 

对于偶数 n，我们可以完美地将两半的元素配对。 对于奇数 n，在这种对称结构中，一个元素保持不配对，稍微降低了可实现的分数，但相同的交替想法仍然最大化了可能的结果。 

这将问题从排列搜索减少到通过确定性配对直接构造排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·n!) | O(n·n!) | O(n) | 太慢了|
 | 最佳施工| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们通过将上半部分的元素与下半部分的元素以交替顺序配对来构建排列。 

1. 将数字 1 到 n 分成两个概念组：从 1 开始向上的下段，以及从 n 开始向下的上段。 目标是将它们交错，以便每个邻接都尽可能大。 
2. 开始放置元件，从上侧取出一个元件，然后从下侧取出一个元件，然后继续交替。 这确保了每对相邻的值都连接了大小相距甚远的值，从而最大限度地提高了它们对美观度的贡献。 
3. 当 n 为偶数时，两半完美对齐，因此每个元素都以平衡交替序列配对。 
4. 当n为奇数时，构造方式相同，但上半部分的一个元素保留在最后。 将其放在最后可以避免破坏早期的高差异邻接关系。 
5. 直接输出构建的排列，无需进一步优化，因为结构已经保证了极大性。 

### 为什么它有效

 不变的是，在构造的每个步骤之后，下一个选择的元素总是从与前一个选择相比的剩余未使用数字的相反极端中获取。 这保证了每个邻接都是在较大的剩余间隙之间形成的，并且任何重新排列都不能在不减少另一个局部贡献的情况下增加任何单个局部贡献。 由于在每个数字恰好使用一次的约束下，所有贡献已经局部最大化，因此全局总和也最大化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    left = 1
    right = n
    res = []
    
    while left <= right:
        if left == right:
            res.append(left)
        else:
            res.append(right)
            res.append(left)
        left += 1
        right -= 1
    
    print(*res)

if __name__ == "__main__":
    solve()
```该解决方案读取 n 并使用两个指针在一次传递中构造排列。 一个指针从最小值开始，另一个指针从最大值开始。 通过始终附加当前最大的然后当前最小的，我们强制执行产生最佳排列的交替高低结构。 

唯一微妙的细节是当 n 为奇数时处理中间元素。 在这种情况下，两个指针在相同的值处相遇，并且它被附加一次而不重复。 这确保了两种奇偶校验情况的正确性，而无需单独的逻辑分支。 

## 工作示例

 考虑 n = 6。 

| 步骤| 左| 对| 行动| 排列|
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 6 | 取 6, 1 | 6, 1 |
 | 2 | 2 | 5 | 取 5, 2 | 6, 1, 5, 2 |
 | 3 | 3 | 4 | 采取 4, 3 | 6, 1, 5, 2, 4, 3 | 6, 1, 5, 2, 4, 3 |

 这会产生排列 [6, 1, 5, 2, 4, 3]，它在每一步都会交替极端。 每个相邻对都连接来自剩余集合相对端的元素，这使得差异很大。 

现在考虑 n = 7。 

| 步骤| 左| 对| 行动| 排列|
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 7 | 取 7, 1 | 7, 1 |
 | 2 | 2 | 6 | 采取 6, 2 | 7, 1, 6, 2 |
 | 3 | 3 | 5 | 取 5, 3 | 7, 1, 6, 2, 5, 3 | 7, 1, 6, 2, 5, 3 |
 | 4 | 4 | 4 | 采取 4 | 7、1、6、2、5、3、4 |

 中间的元素自然地闭合了序列，而不会破坏之前形成的交替结构。 该结构仍然保留相同的极值配对原理。

 ## 边缘情况

 当 n = 1 时，算法立即检测到左等于右并输出单个值。 不可能进行配对，并且构造会正确退化。 

对于 n = 2，算法根据交替顺序生成 2 1 或 1 2。 由于只有一个邻接，两者都是有效的并且达到相同的最佳结构。 

对于奇数 n，例如 n = 5 或 n = 7，当左等于右时会遇到中间元素。 此时它会被附加一次，保持正确性而不重复，并保持直到该点的交替高低结构。
