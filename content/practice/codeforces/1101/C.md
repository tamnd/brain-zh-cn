 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 每个测试用例都在数轴上提供了一组闭合线段。 任务是将每个片段分配给两个组中的一个，使得一组中的片段不与另一组中的任何片段重叠。 这里的重叠是指两个线段的交集非空，包括单点接触。 

查看要求的另一种方法是，如果我们从组 1 中选择任何线段并从组 2 中选择任何线段，则这两个线段必须在线上完全不相交。 

我们必须确定这样的段二分是否存在，如果存在，则输出一个有效的赋值。 

这些约束足够严格，任何比较每个测试用例的所有段对的解决方案都会失败。 最坏情况下，单个测试包含100000个段，最多有50000个测试用例。 每次测试中的二次检查意味着总共大约 10^10 次比较，这远远超出了 2 秒的限制。 这立即排除了成对检查或任何重复扫描每个段的完整集合的方法。 

当所有段通过重叠连接（甚至是间接连接）时，就会出现微妙的极端情况。 例如，如果线段 A 与 B 重叠，B 与 C 重叠，即使 A 不与 C 重叠，这三者也能有效地形成连通结构。 在这种情况下，如果两个组都必须非空，则不可能将它们分成两个没有交叉点的组。 这种情况对应于在重叠下形成单个连通分量的整个集合。 

当片段已经可以通过“间隙”完全分开时，就会出现另一种边缘情况。 例如，如果所有段都位于 [1, 10] 或 [20, 30] 中，并且两个簇之间没有重叠，则自然存在有效分区。 挑战在于检测这种分裂是否存在并有效地构建它。 

## 方法

 天真的想法是将每个线段视为图中的一个节点，并在两个节点相交时连接两个节点。 那么条件就变成了：我们必须为节点分配两种颜色，使得没有边连接不同的颜色。 然而，这不是标准的二分条件，因为我们不需要避免相同颜色的边缘，我们需要避免交叉颜色的边缘。 这翻转了逻辑：我们必须确保每个连接的组件完全位于一组内，而不是分隔相邻节点。 

因此，简单的解决方案首先通过检查每对线段来构建完整的交集图。 如果两个段重叠，我们将它们合并成一个组件。 然后我们尝试将组件分配给两组。 但如果只有一个成分，我们就无法将其分成两个非空组，所以答案是不可能的。 如果至少有两个组件，我们可以将每个完整组件分配给组 1 或组 2，确保两个组都非空。 

问题是构建交叉口结构。 检查所有对的成本为 O(n^2)。 即使我们稍微优化，它仍然太慢。 

关键的观察结果是，路段上的交叉点连通性是通过排序捕获的。 如果我们按左端点对段进行排序并进行扫描，我们可以将任何重叠链合并为单个间隔组件。 每当一个段在当前最大右端点之后开始时，我们就知道一个新组件开始了。 

因此，我们不需要构建图，只需在排序后使用单遍将区间合并到连接的组件中。 一旦识别出组件，问题就简化为检查是否存在多个组件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（成对重叠图）| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 最优（排序+扫描合并）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

我们独立处理每个测试用例。 

1. 读取所有段并保留其原始索引。 我们需要索引，因为输出必须与输入顺序匹配，而不是排序顺序。 
2. 按段的左端点对段进行排序。 排序至关重要，因为它允许我们使用单次扫描而不是成对比较来检测重叠。 
3. 使用第一段初始化当前组件间隔。 还维护一个组件 ID 计数器。 
4. 从左到右遍历线段。 对于每个段，将其左端点与当前组件的最大右端点进行比较。 
5. 如果当前段在当前最大右端点之前或处开始，则它与当前组件重叠，因此如果需要，我们通过扩展最大右端点来合并它。 
6. 如果它在当前最大右端点之后开始，则意味着它不与当前组件中的任何内容相交。 我们完成前一个组件并开始一个新组件。 
7. 处理完所有段后，我们将段划分为连接的组件，其中每个组件是重叠段的最大链。 
8. 如果只有一个组件，则输出 -1，因为任何拆分都会迫使组之间至少有一个重叠。 
9. 否则，将组 1 分配给第一个组件中的所有段，将组 2 分配给所有剩余组件。 

### 为什么它有效

 当存在连接两个线段的成对相交线段链时，两个线段恰好位于同一组件中。 一个组件中的任何段都与该组件中的每个其他段重叠（直接或间接），因此将它们放在不同的组中将强制跨组交叉。 相反，不同组件中的段在排序扫描中由间隙分隔，这意味着一个组件中的任何段都不能与另一组件中的任何段重叠。 这保证了将整个组件分配给组会产生有效的解决方案，并且当且仅当至少有两个组件时才存在解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        segs = []
        for i in range(n):
            l, r = map(int, input().split())
            segs.append((l, r, i))

        segs.sort()

        comp = [0] * n
        cid = 0

        cur_l, cur_r, idx = segs[0]

        comp[idx] = cid

        for l, r, i in segs[1:]:
            if l <= cur_r:
                if r > cur_r:
                    cur_r = r
                comp[i] = cid
            else:
                cid += 1
                cur_r = r
                comp[i] = cid

        if cid == 0:
            out.append("-1")
            continue

        ans = [0] * n
        for i in range(n):
            ans[i] = 1 if comp[i] == 0 else 2

        out.append(" ".join(map(str, ans)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现依赖于按左端点排序，以便重叠检测简化为与运行的最大右端点的简单比较。 变量`cur_r`是关键状态：它跟踪当前连接组件的最远范围。 当某个片段位于该范围内时，它会被吸收到同一组件中。 当它位于外部时，我们启动一个新组件。 

一个常见的陷阱是忘记保留原始索引。 由于排序会重新排列段，因此我们必须将分配存储回原始顺序。 另一个微妙的问题是，合并只需要跟踪最大右端点； 跟踪左边界是不必要的，因为重叠完全取决于下一段是否在当前到达结束之前开始。

 输入：```

```排序后的段变为：

 (2,3,idx1),(5,5,idx0)

 | 步骤| 细分 | 当前_r | 组件| 行动|

 输出分配变为：

 组件 0 → 组 1，组件 1 → 组 2

 所以输出是`2 1`。 

这证实了非重叠片段被干净地分成不同的组件。

 ## 边缘情况

 由重叠段组成的完全连接的链，例如`[1, 5], [2, 6], [3, 7]`，在扫描期间产生单个合并分量，因为运行的最大右端点永远不会下降。 该算法将所有段分配给组件 0 并正确输出`-1`。 

完全不相交的集合，例如`[1,2], [5,6], [10,11]`创建三个组件，因为每个新段都在前一个段之后开始`cur_r`。 扫描在每个间隙处正确重置，产生多个分量并实现有效的两组分割。 

感人的片段，例如`[1,3]`和`[3,5]`被视为重叠，因为`l <= cur_r`。 这确保它们保持在同一组件中，这是必需的，因为它们共享一个点并且不能跨组分离。
