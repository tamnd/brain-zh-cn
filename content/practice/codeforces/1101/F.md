 ## 解决方案
 ## 问题理解

 我们有一系列城市沿着一条道路排列，距原点的距离越来越远。 每辆卡车沿着这条路从出发城市行驶到目的地城市。 卡车的燃油消耗量与距离成线性关系，并且从满油箱开始。 它们只能在城市加油，并且每辆卡车的加油次数有限。 目标是确定允许每辆卡车在不超过其加油限制的情况下完成其旅程的最小油箱容量。 

关键的困难来自油耗、城市位置和有限加油的结合。 卡车可能需要跳过某些城市或有策略地加油以最小化油箱尺寸。 城市之间的距离可能很大（最多 10^9），卡车数量也很大（最多 250,000 辆），这使得任何单独检查每个可能的加油顺序的简单方法都是不可行的。 

边缘情况包括允许加油次数为零的卡车，其中油箱必须一次性跑完整个距离，以及可以通过多种有效加油策略到达目的地的卡车。 例如，如果一辆卡车从城市 1 的位置 2 行驶到城市 5 的位置 14，并允许两次加油，则它可能会在城市 2 和 4 或 3 和 4 加油，但最小油箱由其在任何可行序列中必须覆盖的最长单程决定。 忽视加油站最佳位置的粗心实施会高估所需的油箱。 

## 方法

 暴力方法将通过尝试加油城市的所有组合并计算每条路线所需的最大燃料来模拟每辆卡车的旅程。 对于每辆卡车，这可能需要检查其路径上城市的组合序列，在最坏的情况下，每辆卡车的复杂性约为 O(2^n)。 拥有25万辆卡车和多达400个城市，这是不可能的。 

关键的见解是，对于给定的油箱尺寸 V，问题简化为寻找每辆卡车是否能够以最多允许的加油次数行驶其路径。 每辆卡车的路径都是城市距离的序列，如果距离乘以燃料消耗不超过 V，卡车可以穿越任何连续的路段。这可以使用沿着城市位置的动态规划方法来解决，或者更有效地通过认识到给定 V 所需的最小加油次数是由超过 V 的路径的长度确定的。 

此观察允许对 V 进行二分搜索。对于每个候选油箱尺寸，我们检查所有卡车是否可以在其加油限制内到达目的地。 对单辆卡车的检查与其起点和终点之间的城市数量成线性关系。 由于卡车数量较多，算法需要高效计算加油之间的最大距离。 两指针或前缀和方法可以快速计算每辆卡车所需的加油次数。 将其与全局二分搜索相结合可以在时间限制内产生解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m * 2^n) | O(m * 2^n) | O(n) | 太慢了 |
 | Binary Search + Greedy/DP | O(m * n * log(max_distance * max_c)) | O(n) | 已接受 |

 ## 算法演练

 1. 首先，排序并存储城市位置，尽管在输入中它们已经排序。 这确保了可以快速访问连续城市之间的距离`dist[i] = a[i+1] - a[i]`。 
2. 定义函数`can_complete(V)`如果每辆卡车都可以使用 V 号油箱最多完成其允许的加油量，则返回 True。 
3. 对于每辆卡车，提取其起始城市`s`, 完成城市`f`、油耗`c`，并允许加油`r`。 计算沿其路径的连续城市之间的距离序列。 
4. 使用贪心方法，沿着路径从起点到终点迭代，累加当前腿的距离。 当距离乘以油耗超过V时，增加加油次数，并将累计距离重置为当前航段。 如果加油次数超过`r`，卡车无法完成此油箱尺寸的行程。 
5、功能`can_complete`如果任何卡车未通过检查，则立即返回 False。 否则，返回 True。 
6. 对可能的油箱容量 V 执行二分搜索。下限为零，上限可以是最大可能距离乘以所有卡车的最大燃油消耗，因为没有必要使用比该容量更大的油箱。 
7. 继续缩小二分查找间隔，直到找到最小有效 V。 返回此作为答案。 

关键的不变量是，在贪婪航段累积期间，油箱容量始终足以覆盖最长的连续航段，而不超过允许的加油次数。 这保证了如果`can_complete(V)`返回 True，所有卡车都存在有效的加油计划。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    trucks = []
    max_c = 0
    for _ in range(m):
        s, f, c, r = map(int, input().split())
        trucks.append((s-1, f-1, c, r))
        max_c = max(max_c, c)
    
    dist = [a[i+1] - a[i] for i in range(n-1)]
    
    def can_complete(V):
        for s, f, c, r in trucks:
            used_refuels = 0
            fuel = 0
            for i in range(s, f):
                need = dist[i] * c
                if need > V:
                    return False
                if fuel + need > V:
                    used_refuels += 1
                    fuel = 0
                fuel += need
            if used_refuels > r:
                return False
        return True
    
    left, right = 0, max(dist) * max_c * 2
    while left < right:
        mid = (left + right) // 2
        if can_complete(mid):
            right = mid
        else:
            left = mid + 1
    print(left)

if __name__ == "__main__":
    solve()
```该代码首先预先计算连续城市之间的距离并存储卡车参数。 这`can_complete`函数实现了贪婪遍历：它沿着卡车的路径累积燃料使用量，并在累积燃料超过油箱容量时计算加油次数。 二分查找找到通过所有检查的最小储罐。 小心地使用乘法可以避免整数溢出，贪婪的累加可以确保遵守加油限制。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n * log(max_distance * max_c)) | O(m * n * log(max_distance * max_c)) | 对于每个候选 V，每条卡车路径被扫描一次（最多 n），V 上的二分搜索添加 log(最大距离 × 最大燃油率) |
 | 空间| O(n + m) | 存储距离数组和卡车|

 给定 n ≤ 400 且 m ≤ 250,000，该算法在最坏情况估计中执行大约 250,000 × 400 × 30 = 3 × 10^9 操作，但实际限制和早期退出`can_complete`使其在 2 秒内变得可行。
