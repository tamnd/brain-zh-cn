 ## 解决方案
 ## 问题理解

 该问题提出了一系列骑自行车的人，每个人都有一个敏捷性值。 Leo 位于最后面，他想超越所有骑自行车的人到达前面。 他有两种操作可供选择：直接越过他前面的骑车人，成本等于骑车人的敏捷性，或者交换任意两个骑车人的敏捷性值，成本与他们之间的距离成正比。 目标是确定 Leo 到达数组每个前缀前面的最小总成本。 

关键的挑战是数组大小可达一百万，我们必须计算每个前缀的答案。 这立即排除了朴素的递归或完全组合方法，因为枚举所有交换排列的复杂性将呈指数级增长。 相反，我们需要一种能够有效地考虑最佳交换和移动成本的方法。 

边缘情况包括所有敏捷性值都相等的情况，其中最小路径是简单的并且不需要交换，以及较小的敏捷性出现在阵列中较晚的情况，使得交换有利。 例如，如果数组是`[5, 1, 10]`，无掉期成本的移动`10 + 1 + 5 = 16`，但策略性地交换`1`到前面可能会降低成本`1 + 5 + 10 = 16`- 有时相等，有时较低，强调交换的顺序至关重要。 

## 方法

 暴力方法会尝试所有可能的交换和超越序列。 它将维护一个优先级队列或递归回溯来考虑每个运动排列。 原则上这是可行的，因为所有序列都是有限的，但实际上它至少需要`O(n!)`操作，这对于`n`最多一百万。 

关键的见解是，对于给定的前缀，最佳策略是始终选择最便宜的敏捷性来超越下一个的组合，有可能使用最少的交换操作将最小值向前推进。 具体来说，我们可以将问题视为重复取剩余前缀中的最小值，必要时支付交换成本使其更接近 Leo，然后越过它。 

这将问题简化为贪婪策略，可以使用最小堆或维护位置的排序数据结构来有效地模拟该策略。 我们不是尝试所有排列，而是通过始终将最小的剩余敏捷性移向前面来保持超车和交换成本的运行总和，这保证了每一步的增量成本最小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最优（贪婪 + 前缀最小跟踪）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.对于每个长度的前缀`i`，初始化一个数据结构，允许快速检索最小敏捷性及其位置。 最小堆可以达到这个目的，因为我们需要有效地知道前缀中剩余的最小敏捷性。 
2. 跟踪总成本，并将其初始化为零。 Leo 从前缀中最后一位骑车者后面开始。 
3. 当前缀中有未超车的骑车人时，找到敏捷性最小的骑车人。 如果这个骑自行车的人已经直接在 Leo 前面，则越过他们并将他们的敏捷性添加到总成本中。 
4. 如果最小敏捷性自行车手不在 Leo 正前方，请计算将他们交换到前面的成本。 交换成本是 Leo 和骑自行车的人之间的距离，因为每次将他们向前移动一个位置会产生每次交换的成本。 通过更新数据结构中的位置来虚拟地执行交换，并通过交换距离增加总成本。 
5. 重复步骤 3-4，直到 Leo 超过了该前缀的第一个骑车人。 记录该前缀的总成本。 
6. 迭代从长度 1 到`n`并使用相同的策略独立计算成本。 

为什么有效：通过始终向前移动最小的剩余敏捷性，我们保证每次超车操作当时都会产生尽可能小的成本。 仅当相对于单独移动所有干预的骑车人严格降低超车成本时，才会应用交换。 不变的是，处理完长度的前缀后`i`，已针对该前缀最佳应用了移动和交换的最小序列。 

## Python 解决方案```python
import sys
import heapq
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        result = []
        prefix_heap = []
        total_cost = 0
        # We process each prefix incrementally
        for i in range(n):
            # Push new element into the heap with its position
            heapq.heappush(prefix_heap, (a[i], i))
            cost = 0
            visited = [False]*(i+1)
            pos = i
            temp_heap = prefix_heap.copy()
            while temp_heap:
                val, idx = heapq.heappop(temp_heap)
                if visited[idx]:
                    continue
                # Move forward cost
                move_cost = val
                swap_cost = pos - idx
                cost += move_cost + swap_cost
                visited[idx] = True
                pos = idx - 1
            result.append(cost)
        print(*result)

if __name__ == "__main__":
    solve()
```该解决方案使用最小堆来有效地选择每个前缀中的最小敏捷性。 我们通过调整我们的头寸来隐式模拟掉期`visited`数组并随着距离的向前移动而添加交换成本。 每个前缀都是独立处理的，复制堆以保持前缀隔离。 堆确保我们始终首先移动最小的敏捷性，这支撑了贪婪的正确性。
