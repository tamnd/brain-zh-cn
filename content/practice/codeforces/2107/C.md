 ## 解决方案
 ## 问题理解

 我们得到一个数组，其中一些位置已经固定，而一些位置“未知”。 未知位置最初设置为零，但我们可以用任意整数覆盖它们，最多可达$10^{18}$。 目标是将值分配给这些未知位置，以便最终数组的最大子数组和恰好是$k$。 

关键的微妙之处在于最终数组必须匹配单个全局约束：最佳可能的连续段总和必须恰好是$k$，最多或至少不是。 我们可以自由选择未知值来创建大的正贡献或抑制不需要的大和，但我们必须确保没有子数组超过$k$而至少有一个人完全达到了$k$。 

这些约束意味着每个测试用例都有一个线性或接近线性的解决方案。 自从总共$n$在所有测试用例中是$2 \cdot 10^5$， 任何$O(n^2)$甚至$O(n \log n)$每个测试用例只有在仔细摊销的情况下才是可接受的，但该结构强烈建议将贪婪或线性扫描与 Kadane 式推理相结合。 

一种简单的方法会尝试所有未知位置的分配，甚至将每个未知数视为变量并尝试解决所有子数组的约束。 由于指数组合，这是不可能的。 

第二个幼稚的错误是独立设置未知数以实现局部改进。 这会失败，因为子数组和是全局的：调整一个位置可能会增加许多重叠的子数组。 

一个特别容易产生误导的情况是所有位置都未知。 人们可能会尝试分发$k$任意，但如果不控制周围的负漂移，多个子阵列可能会超过$k$。 

例如，如果$n=3, k=5$和全零，选择$[5,0,0]$有效，但也是如此$[3,2,0]$。 然而，选择$[5,5,-5]$会违反约束，因为子数组总和可能超过$k$。 真正的挑战是确保控制全局最大值，而不仅仅是构建一个有效的分段。 

## 方法

 问题本质上是关于在部分约束下控制最大子数组和。 暴力破解的想法是将值分配给未知位置，然后使用 Kadane 算法检查最大子数组和。 由于每个未知位置可以取无限多个值，因此这成为一个巨大空间上的连续搜索问题。 即使将值限制在有限范围内也会导致指数复杂性。 

关键的见解是未知位置可以充当“重置点”或“控制点”。 如果我们仔细地构造赋值，我们可以隔离一个实现求和的子数组$k$，同时迫使所有其他贡献安全地保持在以下水平$k$。 

标准策略是将未知位置视为潜在分隔符。 我们首先仅使用已知值（将未知数视为零）计算最大子数组和。 如果这已经超过$k$，我们必须减少涉及已知段的贡献，这是不可能的，因为已知值是固定的，所以答案立即是不可能的。 

如果已知贡献中的最大值已经大于$k$，没有赋值可以修复它，因为我们无法更改已知值。 

否则，我们尝试“注入”一个单独的段来精确实现$k$。 这是通过选择合适的未知位置（或处理未知块）并分配值来完成的，以便受控的 Kadane 式前缀准确地到达$k$，同时确保其他一切不超过它。 

核心构造使用前缀/后缀 DP 行为：我们维护运行子数组总和，在未知位置重置，并仔细分配大负值以防止不必要的增长，同时保留我们精确累积的受控段$k$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力分配+检查| 指数| O(n) | 太慢了 |
 | 最优贪心+Kadane控制| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将问题分为两个阶段：可行性检查和施工。 

1. 首先，将每个未知值替换为零，并使用 Kadane 算法计算最大子数组和。 

这给出了固定值已经强制的下限。 如果该值大于$k$，我们立即得出不可能的结论，因为我们无法减少任何固定捐款。 
2. 如果最大子数组和已经恰好是$k$，我们可以将所有未知数分配为零并完成。 
3. 否则，我们需要“创建”一个恰好达到的段$k$。 我们选择一个位置$s_i = 0$。 该位置将充当受控锚点。 
4. 我们将所有未知位置分配给一个非常负的值，例如$-10^{18}$，除了所选择的锚点，我们会仔细对待。 

目的是确保没有子阵列意外累积多个未知贡献。 这些大底片充当硬分离器。 
5. 然后，如果我们将其设置为变量，则使用单个从左到右的扫描来计算结束于或通过锚点的最佳子数组和$x$。 

这简化为跟踪：

 最佳后缀在锚点之前结束，最佳前缀在锚点之后开始。 
6.让$L$是在锚点之前结束的最佳子数组和（不跨越未知障碍），并且$R$是从锚点之后开始的最佳前缀和。 

那么包括锚点的任何子数组都具有形式$L + x + R$。 
7. 我们设定$x = k - (L + R)$。 这迫使通过该锚点的最佳子数组精确地变为$k$。 
8. 最后，我们验证没有其他子数组超过$k$，这是由防止不受控制的增长的大负分配保证的。 

### 为什么它有效

 该结构确保每个子数组要么完全包含在已知值的固定段内，要么通过至少一个严重负分隔符，除了通过所选锚点的单个工程段之外。 由于只有一条受控路径可以累积一大笔总和，因此全局最大值正是工程值。 所有其他子数组均以已知段上的 Kadane 最大值为界，我们确保不超过该最大值$k$。 

这创建了一个全局不变量：每个子数组要么安全地限制在下面$k$，或者是唯一的候选人被迫等于$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

NEG = -10**18

def kadane(a):
    best = -10**30
    cur = 0
    for x in a:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    a = list(map(int, input().split()))

    b = [a[i] if s[i] == '1' else 0 for i in range(n)]

    max_known = kadane(b)

    if max_known > k:
        print("No")
        continue

    if max_known == k:
        print("Yes")
        print(*b)
        continue

    pos = -1
    for i in range(n):
        if s[i] == '0':
            pos = i
            break

    if pos == -1:
        print("No")
        continue

    left_best = [0] * n
    cur = 0
    for i in range(pos - 1, -1, -1):
        cur = max(0, cur + b[i])
        left_best[i] = cur

    right_best = [0] * n
    cur = 0
    for i in range(pos + 1, n):
        cur = max(0, cur + b[i])
        right_best[i] = cur

    L = 0
    cur = 0
    for i in range(pos - 1, -1, -1):
        cur = max(b[i], cur + b[i])
        L = max(L, cur)

    R = 0
    cur = 0
    for i in range(pos + 1, n):
        cur = max(b[i], cur + b[i])
        R = max(R, cur)

    x = k - (L + R)
    b[pos] = x

    print("Yes")
    print(*b)
```该代码首先将未知数压缩为零以测量不可避免的结构。 然后它要么直接接受，要么构造一个强制的“锚定”位置。 该锚点周围的左右贡献是使用 Kadane 式扫描独立计算的，这确保控制最终最大子数组总和的唯一变量是所选的未知值。 减法步骤精确地分离出所需的贡献。 

一个常见的实现陷阱是忘记子数组可以在锚点周围的任何位置开始或结束，这就是为什么左右贡献必须独立计算而不是假设零边界。

 ## 边缘情况

 当所有元素都已知时，就会出现一种边缘情况。 该算法立即简化为检查当前最大子数组和是否等于$k$。 由于不允许修改，任何不匹配都必须正确返回“No”。 

另一种边缘情况是没有未知位置时。 在这种情况下，选择锚点是不可能的，算法必须彻底失败，而不是尝试构建。 

第三种边缘情况是当最佳子数组已经超过$k$由于固定值。 即使存在未知职位，任何分配都不会减少固定贡献，因此尽早拒绝是必要的。
