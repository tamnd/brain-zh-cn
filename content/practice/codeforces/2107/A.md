 ## 解决方案
 ## 问题理解

 我们有几个独立的数组，对于每个数组，我们需要将其元素分成两个非空组。 每个数字必须恰好属于一组，因此我们实际上选择了索引的二进制标签。 

分割后，我们计算第一组中所有值的 GCD 和第二组中所有值的 GCD。 要求是这两个 GCD 必须不同。 如果我们不能产生这样的分裂，我们就报告不可能。 

约束非常小：每个测试用例最多 100 个元素和 500 个测试用例。 这立即表明，任何每个测试用例甚至是二次的解决方案都非常快。 真正的挑战不是性能，而是理解何时可以或不可以存在这种分裂。 

最重要的边缘情况是所有元素都相同。 如果每个值都相同，则任何分区在两组中都会产生相同的 GCD，因此答案必定是不可能的。 一种更微妙的情况是，只有一个不同的值被重复，即使它出现了很多次。 

另一种重要的情况是当一个元素与所有其他元素非常不同时。 一个天真的想法可能是始终隔离单个元素，但如果该元素的值实际上并没有以相对于其余组有意义的方式改变 GCD，那么这种想法可能会失败。 

## 方法

 暴力策略会将每个元素分配给 B 组或 C 组，并计算两个 GCD。 有 2^n 种可能的分配，并且对于每个分配计算两个 GCD 需要 O(n)。 这导致 O(n·2^n)，即使对于 n = 100，这也远远超出了可行性。 

关键的观察是我们不需要考虑任意分区。 我们只需要检查是否存在 GCD 不同的分裂。 这相当于找到一种方法将数组分开，使得至少有一组“打破”了可分性的整体结构。 

令 g 为整个数组的 GCD。 仅当所有元素在缩放时都等于 g 时，每个元素才能被 g 整除。 如果所有元素都等于 g，则每个分区都保留 GCD = g，所以答案是不可能的。 

如果并非所有元素都相等，则至少存在一个在可分性方面与全局最小结构不同的元素。 一个建设性的想法是将最小元素与数组的其余部分分开，但这并不总是必要的或最佳的。 

更可靠的方法是选择最小的元素并将其单独放置在一组中，并将所有其他元素放置在另一组中。 单例组的 GCD 就是该元素，而其余元素的 GCD 不能等于它，除非每个其他元素都是它的倍数，以一种非常特定的方式强制整个数组相等。 这将问题简化为简单的可行性检查：数组是否包含至少两个不同的值。 

因此，问题归结为检查唯一性和构建单例分区。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·2^n) | O(n·2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 扫描数组并判断所有元素是否相等。 如果是，则立即输出“No”。 这是必要的，因为任何分区都保留相同的 GCD 值。 
2. 找到任意索引 i，使得 a[i] 与至少一个其他元素不同。 这样的索引在有效的情况下总是存在的。 
3. 将元素 i 分配给 B 组，并将所有其他元素分配给 C 组。这保证了两个组都非空。 
4. 隐式计算 GCD：B 组的 GCD 等于 a[i]，而 C 组具有不同的结构，因为它至少包含一个不等于 a[i] 的元素。 
5. 输出分区。 

### 为什么它有效

该构造迫使 B 组具有等于单个值的固定 GCD。 C 组必须包含至少一个与该值不同的元素，否则所有元素将相同，与初始检查相矛盾。 由于 GCD 对所有元素之间的精确相等很敏感，因此引入不同的值可确保第二个 GCD 在存在有效解决方案的所有情况下都无法与单例 GCD 匹配。 

不变量是一组具有固定的、未混合的 GCD，而另一组包含一组异构值。 这种结构不对称性保证了当阵列不均匀时两个 GCD 不能重合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    if len(set(a)) == 1:
        print("No")
        continue
    
    print("Yes")
    x = a[0]
    idx = 0
    
    for i in range(n):
        if a[i] != x:
            idx = i
            break
    
    res = [2] * n
    res[idx] = 1
    print(*res)
```该解决方案首先使用集合检查所有值是否相同。 这是唯一不可能的情况。 否则，它会选择与第一个元素不同的任何元素，并将其隔离到组 1 中。其他所有元素都进入组 2。 

一个微妙的实现细节是我们不显式计算任何 GCD。 正确性纯粹来自于相等性和非均匀性的结构推理，避免了不必要的计算。

 ## 边缘情况

 例如，当所有值都相等时`5 5 5 5`，算法立即正确拒绝，因为`set(a)`大小为 1。任何分区都会在两侧产生 GCD 5。 

当只有一个不同的元素时，例如`5 5 5 3`，该算法隔离`3`进入自己的组。 单例组的 GCD 为 3，而其余组的 GCD 为 5，因此条件成立。 

当值剧烈变化时，例如`1 2 1 2`，算法仍然选择一个值与第一个元素不同的索引并将其隔离。 即使存在多个有效分区，该构造仍然有效，因为它仅依赖于非均匀性，而不依赖于结构。
