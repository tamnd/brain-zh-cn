 ## 解决方案
 ## 问题理解

 乔治希望通过从任务列表中选择工作部分来最大化他的收入，每个部分都有给定的利润。 任务按顺序排列在数组中`p`长度`n`。 他必须准确选择`k`不重叠的段，每个长度`m`。 段由其起始索引和结束索引定义`[l, r]`，并且任何两个线段都不能重叠。 目标是最大化所有选定细分市场的利润总和。 

输入给出`n`,`m`， 和`k`其次是一系列的利润。 输出是一个数字：可实现的最大总和`k`长度不重叠的段`m`。 

这些限制表明暴力方法是不可行的。 自从`n`最多可以达到 5000 并且`k*m`可以达到`n`，尝试所有组合`k`各部分将涉及以下顺序的操作`O(n^k)`，这对于 1 秒的时间限制来说远远超出了可接受的范围。 动态规划方法是必要的。 边缘情况包括位于数组最开始或最末尾的段、所有利润为零或所有利润相等。 例如，如果`n=5, m=2, k=1`和`p=[1,1,1,1,1]`，任何段的总和为 2，因此算法必须正确选择一个段，而无需假设更高的方差。 

## 方法

 蛮力方法会考虑所有组合`k`不重叠的段。 这是正确的，但在计算上是不可行的。 具体来说，我们将枚举第一个段的每个可能的起始索引，然后对于每个选择，递归地枚举剩余的有效选择`k-1`段。 每个选择大约涉及`n`选项，导致 O(n^k) 复杂度。 为了`n=5000`甚至`k=3`，这会导致数十亿次操作，这太慢了。 

关键的见解是这些段具有固定的长度`m`并且必须不重叠。 我们可以预先计算长度为每个连续子数组的总和`m`然后使用动态规划来跟踪第一个可实现的最大利润`i`用于选择的数组元素`j`段。 让`dp[i][j]`是第一个的最大利润`i`精确选择时的元素`j`段。 状态转换很简单：对于每个位置`i`，我们可以跳过它（继承`dp[i-1][j]`) 或取结束于`i`（如果`i >= m`) 并将其总和添加到`dp[i-m][j-1]`。 这将复杂度降低到 O(n*k)，这在约束下是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^k) | O(n^k) | O(1) | O(1) | 太慢了 |
 | 动态规划| O(n*k) | O(n*k) | 已接受 |

 ## 算法演练

 1. 预先计算数组的前缀和`p`在 O(1) 内快速计算任意子数组的和。 让`prefix[i]`存储第一个的总和`i`元素。 
2.初始化2D DP表`dp`尺寸的`(n+1) x (k+1)`， 在哪里`dp[i][j]`是使用第一个可实现的最大总和`i`元素并精确选择`j`段。 将所有条目设置为 0。 
3. 对于每个索引`i`从 1 到`n`，计算结束于的线段的总和`i`长度`m`，即`segment_sum = prefix[i] - prefix[i-m]`如果`i >= m`。 
4. 对于每个`j`从 1 到`k`， 更新`dp[i][j]`作为两个选择中的最大值：要么跳过当前元素（`dp[i-1][j]`) 或取结束于`i`（`dp[i-m][j-1] + segment_sum`） 如果`i >= m`。 
5.填表后答案为`dp[n][k]`。 

工作原理：DP 表正确地表示了数组的每个前缀和段数可实现的最大利润。 过渡确保片段不会重叠，因为当我们采用以`i`，我们只将其添加到利润中`dp[i-m][j-1]`，它严格对应于该段之前的元素。 前缀和允许恒定时间段和计算。 该算法保证所有有效段选择的总和最大。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    p = list(map(int, input().split()))

    prefix = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix[i] = prefix[i-1] + p[i-1]

    dp = [[0]*(k+1) for _ in range(n+1)]

    for i in range(1, n + 1):
        for j in range(0, k+1):
            dp[i][j] = dp[i-1][j]
            if j > 0 and i >= m:
                dp[i][j] = max(dp[i][j], dp[i-m][j-1] + prefix[i] - prefix[i-m])

    print(dp[n][k])

solve()
```前缀和计算将段和查询从 O(m) 转换为 O(1)。 DP表按顺序更新，以确保考虑所有可能的段选择，并通过索引维护不重叠约束`dp[i-m][j-1]`。 将表初始化为零可以处理未选择段的情况。
