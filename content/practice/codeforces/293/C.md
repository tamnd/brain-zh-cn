 ## 解决方案
 ## 问题理解

 三个原始立方体都有边长$a$,$b$， 和$c$。 他们的单位立方体总数是$$a^3+b^3+c^3.$$维塔利想要建造一个更大的立方体，其边长为$a+b+c$，这需要$$(a+b+c)^3$$单位立方体。 

他正好矮了$n$立方体，所以$$(a+b+c)^3-(a^3+b^3+c^3)=n.$$我们只被给予$n$，我们必须计算有多少个正整数三元组$(a,b,c)$本来可以产生这个价值。 

界限$n \le 10^{14}$立即排除对可能值的任何搜索$a$,$b$， 或者$c$。 的立方根$10^{14}$在附近$4.6 \times 10^4$，因此即使在所有可能的边长上进行三重循环也需要超过$10^{13}$迭代。 

关键的观察结果是该表达式具有很强的代数结构。 一旦它转化为乘法方程，问题就变成了枚举约数的约数之一$3.3 \times 10^{13}$。 该大小的数字具有相对较少的除数，使得基于除数的枚举变得实用。 

一些边缘情况很容易被错误处理。 

例如，如果```
n = 1
```然后$$(a+b+c)^3-(a^3+b^3+c^3)$$总是可以整除$3$，所以答案一定是$0$。 一种开始枚举除数而不检查整除性的解决方案$3$浪费工作并可能产生不正确的结果。 

另一个微妙的情况是```
n = 24
```这对应于$$3(a+b)(b+c)(c+a)=24.$$因数三倍$(1,1,8)$满足乘积条件，但不对应于正整数值$a,b,c$。 正在恢复中$a,b,c$需要奇偶性约束和正性约束。 忽略这些限制就得不偿失了。 

第三个常见错误是忘记了$(a,b,c)$已订购。 三元组$(1,2,3)$和$(2,1,3)$是不同的解决方案。 当我们枚举排序因子三元组时，我们必须恢复正确的重数。 

## 方法

 从身份开始$$(a+b+c)^3-(a^3+b^3+c^3) = 3(a+b)(b+c)(c+a).$$让$$x=a+b,\quad y=b+c,\quad z=c+a.$$那么问题就变成了$$3xyz=n.$$如果$n$不能被整除$3$，没有解决方案。 

一个蛮力的想法是枚举所有因子三元组$(x,y,z)$谁的产品是$n/3$,重建$a,b,c$，并统计有效的。 这已经比枚举好很多了$a,b,c$，因为 a 的约数个数$10^{13}$-size 整数很小。 

剩下的挑战是有效计数。 

给定$$m=\frac n3,$$我们需要所有正整数三元组满足$$xyz=m.$$从$$a=\frac{x+z-y}{2},\quad b=\frac{x+y-z}{2},\quad c=\frac{y+z-x}{2},$$三元组恰好对应于有效正整数$$x+y+z \equiv 0 \pmod 2$$严格的三角不等式成立：$$x+y>z,\quad y+z>x,\quad z+x>y.$$由于我们按排序顺序枚举因子三元组$x \le y \le z$， 仅有的$$x+y>z$$需要检查。 

蛮力因子枚举是正确的，但独立枚举所有正三元组仍然太大。 观察结果表明$xyz=m$让我们只枚举$m$。 即使是最坏的情况$m$，除数计数只有几千，因此检查除数对很容易足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解结束$a,b,c$|$O((\sqrt[3]{n})^3)$|$O(1)$| 太慢了 |
 | 除数枚举 |$O(d(m)^2)$|$O(d(m))$| 已接受 |

 这里$d(m)$表示除数的个数$m$。
