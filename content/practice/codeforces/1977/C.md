 ## 解决方案
 ## 问题理解

 我们得到一个整数数组。 如果子序列的所有元素的最小公倍数没有出现在原始数组中的任何位置，则该子序列被称为特殊子序列。 

任务是找到这样一个子序列的最大可能长度。 

子序列内元素的顺序对于 LCM 来说并不重要。 只有选择的值才重要。 由于数组的每个元素都可以被采用或跳过，因此子序列的数量呈指数级增长，因此我们需要利用数论结构而不是枚举它们。 

数组长度可以大到 2000，并且所有测试用例的所有长度之和也最多为 2000。这是一个非常不寻常的约束。 这意味着我们可以为每个测试用例提供大约二次的工作量，但任何指数级的工作都是不可能的。 甚至$O(n^3)$在最坏的情况下会感到不舒服。 

值本身可以大到$10^9$，这排除了对值的动态规划。 任何解决方案都必须直接使用除数和 LCM，而不是构建按值索引的大型表。 

一些边缘情况很容易被忽略。 

考虑：```
1
5
1 2 4 8 16
```每个非空子序列都有一个 LCM，它是数组元素之一。 空子序列有 LCM$0$，但其长度为零。 正确答案是 0。 

一个常见的错误是假设如果整个数组的 LCM 属于该数组，则不存在答案。 那是错误的。 

例如：```
1
4
2 3 6 12
```整个阵列的LCM是12，存在。 然而后续$[2,3]$有 LCM 6，它也存在，而$[2,12]$有LCM 12。我们必须更加仔细地搜索，而不仅仅是检查全阵列LCM。 

另一个微妙的情况是：```
1
3
2 3 5
```整个阵列的LCM是30，不存在。 然后立即取出所有元素给出长度为 3 的特殊子序列。错过此观察会导致不必要的工作。 

## 方法

 蛮力方法很简单。 枚举所有子序列，计算其 LCM，并保留 LCM 未出现在数组中的最大长度。 

这是正确的，因为它直接检查定义。 不幸的是它需要检查$2^n$子序列。 即使是为了$n=50$这已经是不可能的了，而这里$n$可以达到2000。 

关键的观察结果来自于 LCM 实际发生的情况。 

让$M$是整个阵列的LCM。 

任何子序列 LCM 必须除$M$。 它所包含的质数永远不能大于数组中某处已出现的质数。 

现在考虑两种情况。 

如果$M$本身没有出现在数组中，那么整个数组就已经是特殊的了。 其 LCM 等于$M$，数组中不存在。 答案是立即$n$。 

有趣的情况是当$M$确实出现在数组中。 

那么每个特殊子序列必须有一个 LCM，它是$M$。 此外，如果一个值不能整除$M$，它不可能是任何子序列的LCM。 

关键的事实是，每个候选特殊 LCM 都必须是$M$没有出现在数组中。 

一个数的约数个数可达$10^9$很小。 事实上，即使最大可能的除数计数也只有一千左右。 这使得枚举所有约数成为可能$M$。 

对于固定候选除数$d$，LCM 等于的最大子序列是什么$d$？ 

每个选定的元素必须除$d$。 任何不能被整除的元素$d$将迫使 LCM 超过$d$。 

所有元素之间划分$d$，我们只需将它们全部取走即可。 可以计算它们的组合 LCM。 如果 LCM 等于$d$，则可以包含每个这样的元素，从而给出该候选的最大可能长度。 

我们对每个除数重复此操作$d$的$M$数组中不存在的值并取最大的有效计数。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n \cdot n)$|$O(n)$| 太慢了|
 | 最佳|$O(n \cdot \tau(M))$|$O(\tau(M))$| 已接受 |

 这里$\tau(M)$表示除数的个数$M$。 

## 算法演练

 1. 读取数组并计算所有元素的 LCM。 
2. 计算 LCM 时，一旦超过数组最大值，就停止增长。 

这很重要，因为实际的全阵列 LCM 可能会变得巨大。 我们只需要知道它是否大于每个数组元素。 
3.让`mx`是最大数组值。 
4. 如果全阵列 LCM 大于`mx`，那么它不能属于该数组。 

在这种情况下，整个数组是特殊的，所以输出`n`。 
5. 否则，全数组 LCM 等于某个数组值。 调用这个值`M`。 
6. 枚举每个除数`M`。 
7. 对于每个除数`d`未出现在数组中的：

 1.收集所有除法的数组元素`d`。 
2. 数一数。 
3. 计算所有收集元素的 LCM。 
4. 如果所得的 LCM 等于`d`，则该除数可以实现为子序列 LCM。 
5. 用计数更新答案。 
8. 输出找到的最大计数。 

### 为什么它有效

 每个子序列 LCM 都划分全阵列 LCM$M$。 如果$M$本身不存在于数组中，每个元素都已经给出了最大可能长度的特殊子序列。 

否则$M$属于数组。 任何特殊子序列的 LCM 必须等于某个除数$d$的$M$没有出现在数组中。 

对于固定除数$d$，每个选定的元素必须除$d$。 包括所有这些元素给出了可以实现的最大可能的子序列$d$。 如果所有这些符合条件的元素的 LCM 等于$d$， 然后$d$是可以实现的。 如果不是，则它们的子集都不能产生$d$，因为删除元素只能减少可用的质数幂。 

因此，每一个可行的特殊 LCM 都会被检查一次，并且对于每一个，我们都会计算最大可实现的长度。 最大的长度就是答案。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def lcm(a, b):
    return a // gcd(a, b) * b

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        mx = max(a)
        s = set(a)

        cur_lcm = 1
        overflow = False

        for x in a:
            cur_lcm = lcm(cur_lcm, x)
            if cur_lcm > mx:
                overflow = True
                break

        if overflow:
            ans.append(str(n))
            continue

        M = cur_lcm

        divisors = []
        d = 1
        while d * d <= M:
            if M % d == 0:
                divisors.append(d)
                if d * d != M:
                    divisors.append(M // d)
            d += 1

        best = 0

        for target in divisors:
            if target in s:
                continue

            cnt = 0
            cur = 1

            for x in a:
                if target % x == 0:
                    cnt += 1
                    cur = lcm(cur, x)
                    if cur > target:
                        break

            if cur == target:
                best = max(best, cnt)

        ans.append(str(best))

    sys.stdout.write("\n".join(ans))

solve()
```第一部分计算整个阵列的 LCM。 我们决不允许它不必要地增长。 一旦它超过了最大数组元素，我们就已经知道它不能出现在数组中，所以答案就变成了`n`。 

仅当全阵列 LCM 等于阵列值时才运行下一阶段。 在这种情况下，我们枚举该 LCM 的所有约数。 

对于每个候选除数，我们精确地检查那些除它的数组元素。 任何不划分候选者的元素永远不能属于其 LCM 等于该候选者的子序列。 

LCM 计算使用```
a // gcd(a, b) * b
```而不是`a * b // gcd(a, b)`以避免具有固定大小整数的语言中的中间溢出。 Python 不会溢出，但这仍然是标准的竞争性编程实现。 

一个微妙的点是我们跳过数组中已经存在的每个除数。 该问题要求阵列中不存在生成的 LCM。

 ## 边缘情况

 考虑：```
1
3
2 3 5
```全数组 LCM 为 30，而最大数组值为 5。由于 30 超出了每个数组元素，因此无法出现。 该算法立即返回 3。不需要除数枚举。 

现在考虑：```
1
1
1
```全数组LCM为1，属于数组。 唯一的除数也是 1，并且它存在于数组中。 不存在特殊子序列，因此答案为 0。 

最后考虑：```
1
5
1 2 4 8 16
```全数组LCM等于16，属于数组。 每个 16 的约数也都存在。 每个可能的子序列 LCM 都是这些除数之一，因此没有一个是特殊的。 该算法检查所有除数，发现没有有效目标，并正确输出 0。
