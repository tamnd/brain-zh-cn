 ## 解决方案
 ## 问题理解

 我们被要求表示一个给定的正整数$x$作为二的幂的和，但有严格的附加约束：二的幂的系数只能是-1、0或1，并且两个非零系数不能相邻。 具体来说，我们必须生成一个数组$a$长度$n$在哪里$1 \le n \le 32$,$a_i \in \{-1, 0, 1\}$， 和$$x = \sum_{i=0}^{n-1} a_i \cdot 2^i$$附加条件是如果$a_i$和$a_{i+1}$两者都非零，这违反了规则。 

输入由多个测试用例组成，每个测试用例包含一个整数$x$。 对于每个$x$，我们必须构造一个有效的数组$a$并输出其长度和内容。 自从$x < 2^{30}$, 最大长度$n$永远不需要超过 32，因此任何迭代 的位的算法$x$是高效的。 

主要的微妙之处来自于“没有相邻的非零系数”约束。 例如，如果$x = 3$，一个朴素的二进制展开给出$11_2 = 1 \cdot 2^1 + 1 \cdot 2^0$，但这违反了邻接规则。 该解决方案必须插入零或使用负系数来“展开”非零项，同时仍然求和$x$。 

边缘情况包括少量（例如$1$或者$2$），小于 2 的幂的数字（例如$3, 7, 15$），以及二进制交替的数字（例如$21 = 10101_2$）。 

## 方法

 暴力方法会尝试长度最大为 32 且系数为 的所有序列$-1,0,1$，检查总和，并验证没有相邻的非零值。 这显然是不可行的，因为序列的数量随着$3^{32} \approx 2 \times 10^{15}$。 

关键的见解是我们可以贪婪地构建序列，处理$x$从最低有效位到最高有效位，并确保没有相邻的非零系数。 如果二进制展开式中出现两个连续的，我们可以将它们转换成如下模式$[-1, 0, 1]$它保留总和并扩展非零系数。 这让人想起密码学中使用的“平衡三元”或非相邻形式 (NAF) 表示数字，它保证没有两个非零数字相邻，并且所有数字都在 {-1,0,1} 中。 

贪婪方法之所以有效，是因为对于任何会导致邻接的位，我们都可以传播结转，要么增加下一个更高位，要么将当前位调整为 -1。 这确保了总和保持正确，同时维持邻接规则。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | O(3^32) | O(3^32) | O(32) | 太慢了|
 | 贪婪/NAF 构造 | 每个测试用例的 O(log x) | 每个测试用例的 O(log x) | 已接受 |

 ## 算法演练

 1. 从一个空列表开始`a`来保存系数。 
2. 初始化变量`x`到给定的数字。 
3. 重复同时`x`不为零：

 1.如果`x % 2 == 0`, 附加`0`到`a`因为最低有效位没有任何贡献。 
2.如果`x % 2 == 1`, 附加`1`到`a`因为简单的 1 符合非邻接规则。 
3.如果`x % 2 == 3`, 附加`-1`到`a`并增加`x`加 1 以结转到下一个较高位。 这解决了两个的邻接关系。 
4. 划分`x`除以 2（整数除法）右移并继续。 
4. 输出`n = len(a)`和数组`a`。 

工作原理：在每一步中，该算法都会通过将一对 1 转换为`[-1,0,1]`带有进位的图案。 这保证了以下不变式：中没有两个非零元素`a`是相邻的，而总和$a_i \cdot 2^i$被维持。 因为$x < 2^{30}$, the process terminates after at most 32 iterations.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        a = []
        while x != 0:
            if x % 2 == 0:
                a.append(0)
            elif x % 2 == 1:
                a.append(1)
            else:  # x % 2 == 3
                a.append(-1)
                x += 1
            x //= 2
        print(len(a))
        print(' '.join(map(str, a)))

if __name__ == "__main__":
    solve()
```这`while x != 0`循环遍历每一位`x`。 条件`x % 2 == 3`处理两个连续的二进制出现并且违反邻接规则的情况。 追加`-1`并递增`x`有效地结转到下一位，保留总和。 使用`x //= 2`相当于向右移动并通过更高的 2 次幂前进。 

边界考虑因素包括第一位（`2^0`）以及事实`x`可以是奇数或偶数。 自从`x < 2^{30}`, 列表`a`永远不会超过 32 个元素，满足问题约束。
