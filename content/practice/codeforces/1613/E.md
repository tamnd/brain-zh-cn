 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格`n × m`包含三种类型的细胞：游离细胞、封闭细胞和单个实验室。 机器人可以占据任何空闲单元，并且在每一步我们都可以发出四个命令之一：向上、向下、向左或向右移动。 然而，机器人“疯了”，永远不会听从命令； 如果可能的话，它将选择不同方向上的有效相邻小区。 如果不存在这样的移动，机器人将保持在原地。 

我们的任务是标记所有空闲单元，机器人可以从这些空闲单元中被迫最终到达实验室。 如果从那里开始，我们总是可以将机器人（通过重复的命令）引导到实验室，无论它在每一步选择哪个替代方向，则将空闲单元标记为可到达。 

输入可以很大：`n`和`m`可以单独达到`10^6`，但所有测试用例中的单元总数受以下限制`10^6`。 这排除了任何复杂度为 O(n·m·某大) 的解决方案，因为每个测试用例的简单线性 O(n·m) 是可以接受的，但网格大小的任何二次方都不能接受。 

边缘情况包括具有单个单元的网格、除实验室之外完全被阻挡的网格，以及机器人在角落或狭窄通道中有多个空闲邻居的场景。 一种简单的方法可能会尝试模拟每个自由单元中所有可能的机器人行为，这些自由单元会组合爆炸。 例如，考虑：```
2 2
..
.L
```从左上角开始，粗心的模拟可能会假设机器人最终会移向实验室，但机器人可能会始终选择“错误”的邻居，而永远不会到达实验室。 

## 方法

 暴力法是从每个自由单元开始模拟所有可能的机器人运动。 在每一步中，我们都会考虑除命令方向之外的所有方向，递归地探索机器人的选项。 原则上这是可行的，但是状态空间随着自由邻居的数量呈指数增长，使得不可能`n·m`最多`10^6`。 

高效解决方案的关键在于扭转问题：我们不是模拟机器人所有可能的移动方式，而是从实验室向后传播**安全可达性**。 我们将网格视为一个图，其中每个自由单元都有与其自由邻居的边。 如果机器人在收到相反方向的命令时可以移动的所有方向上都无法逃离通往实验室的路径，则该单元是安全的。 换句话说，一旦一个细胞有**至多一个未访问过的自由邻居**，它就会变得“被迫”，因为这样我们就可以随时命令机器人，使其疯狂的选择引导它沿着该邻居前进。 

通过在实验室执行 **BFS 或 DFS**，标记可以被迫最终到达实验室的单元，我们可以完全避免模拟机器人的组合选择。 这种传播利用了一个简单的属性，即当除了一个邻居之外的所有单元都已经安全或被阻止时，单元就变得安全，然后我们可以发出命令将机器人引导到实验室。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（模拟所有动作）| O(4^(n·m)) | O(4^(n·m)) | O(n·m) | 太慢了 |
 | 实验室的 BFS/DFS 传播 | O(n·m) | O(n·m) | 已接受 |

 ## 算法演练

 1. 读取网格并找到实验室单元格。 以实验室为起点初始化队列。 
2. 为每个空闲单元预先计算其未访问的空闲邻居的数量。 这有助于确定细胞何时变得“被迫”。 
3. 当队列不为空时，弹出一个单元格`c`。 对于每个自由邻居`n`的`c`尚未被标记为强制：

 - 减少`n`将未访问的自由邻居计数减一。 
- 如果计数小于或等于 1，则表示机器人从`n`如果我们总是发出适当的命令，就不可避免地最终会走向实验室。 添加`n`到队列并将其标记为强制。 
4. BFS/DFS 完成后，所有标记为强制的单元格都是机器人可以从中汇集到实验室的单元格。 更新网格以替换`.`和`+`对于这些单元格并输出它。 

这样做的原因是，当每个单元最多有一个可以让机器人逃脱的邻居时，它就会被添加到队列中。 通过归纳，无论机器人如何选择，队列中的所有单元都保证到达实验室，因为在每一步中，机器人要么移动到已经确定的安全单元中，要么没有其他空闲邻居。 

## Python 解决方案```python
import sys
from collections import deque
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]
        
        # Count free neighbors
        neighbors = [[0]*m for _ in range(n)]
        q = deque()
        
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'L':
                    lab = (i,j)
                    q.append((i,j))
                if grid[i][j] != '#':
                    cnt = 0
                    for dx,dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                        ni,nj = i+dx, j+dy
                        if 0<=ni<n and 0<=nj<m and grid[ni][nj] != '#':
                            cnt += 1
                    neighbors[i][j] = cnt
        
        visited = [[False]*m for _ in range(n)]
        visited[lab[0]][lab[1]] = True
        
        while q:
            i,j = q.popleft()
            for dx,dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                ni,nj = i+dx,j+dy
                if 0<=ni<n and 0<=nj<m and grid[ni][nj] == '.' and not visited[ni][nj]:
                    neighbors[ni][nj] -= 1
                    if neighbors[ni][nj] <= 1:
                        visited[ni][nj] = True
                        grid[ni][nj] = '+'
                        q.append((ni,nj))
        
        for row in grid:
            print("".join(row))

if __name__ == "__main__":
    solve()
```这`neighbors`数组跟踪有多少空闲邻居尚未被强制。 仅当该数字降至一或零时，我们才将单元入队，以确保机器人别无选择，只能最终移向实验室。 这`visited`array 可以防止重新访问单元格并确保线性时间复杂度。 

## 工作示例

 **示例输入 1**```
3 3
...
.L.
...
```| 步骤| 队列| 强制细胞|

 | 初始化| [(1,1)] | 实验室标记|
 | 流行 (1,1) | []| 没有邻居有 <=1 个空闲邻居，没有添加任何内容 |

 输出保持不变。 中心实验室的邻居有两个或更多空闲单元，因此没有单元被强制。 

**示例输入 2**```
4 5
#....
..##L
...#.
.....
```| 步骤| 队列| 强制细胞|
 | ---| ---| ---|
 | 初始化| [(1,4)] | 实验室|
 | 流行 (1,4) | 邻居更新 | 添加单元格 (1,3),(2,4) |
 | 流行 (1,3) | ... | (1,2) 添加 |
 | 继续 | ... | 传播到 (1,1),(2,1),(3,1),(3,2),(3,3),(3,4) |

 最终强制单元格标记为`+`如示例输出中所示。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n·m) | 每个单元最多被访问一次，每个邻居最多被检查四次 |
 | 空间| O(n·m) | 存储网格、访问数组和邻居数组 |

 和`n·m ≤ 10^6`在所有测试用例中，这完全符合 2 秒的时间限制和内存限制。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    return out.getvalue().strip()

# Provided samples
assert run("4\n3 3\n...\n.L.\n...\n4 5\n#....\n..##L\n...#.\n.....\n1 1\nL\n1 9\n....L..#.\n") == (

), "sample 1"

# Custom: single cell lab
assert run("1\n1 1\nL\n") == "L", "single lab"
