 ## 解决方案
 ## 问题理解

 我们得到了一系列不同的正整数。 我们的任务是构造大约序列长度一半的数字对，其中每对数字$(x, y)$，两个数字都来自序列，它们是不同的，当$x$除以$y$没有出现在序列中。 每个测试用例都要求$\lfloor n/2 \rfloor$这样的对。 

每个测试用例的输入大小最多可达 200,000 个元素，所有测试用例的总和也以 200,000 为界。 这意味着任何检查每个可能对的解决方案都会太慢：一个天真的解决方案$O(n^2)$方法将围绕$4 \cdot 10^{10}$最坏情况下的操作，2秒之内是远远不可能实现的。 因此，我们需要一个线性或$O(n \log n)$方法。 

可能导致简单解决方案失败的边缘情况包括非常小的数组，其中一个或两个数字可能为 1，因为$x \mod 1 = 0$，并且 0 可能会也可能不会出现在数组中。 另一个微妙之处是，如果我们选择任意元素，贪婪配对可能会意外地产生序列中存在的余数； 例如，在数组中$[1, 4]$, 配对$1$和$4$产量$1 \mod 4 = 1$，它在数组中，因此无效。 任何解决方案都必须考虑到以下事实：较小的数字与较大的数字可能会复制数组中的元素。 

## 方法

 蛮力方法是迭代所有对$(x, y)$, 计算$x \mod y$，并检查数组中是否存在。 这是正确的但不切实际：对于$n = 2 \cdot 10^5$，它需要$O(n^2)$模运算和成员资格检查，这太慢了。 

关键的见解是大数模小数往往会产生更小的余数。 如果我们对数组进行排序，我们可以选择大数字作为$x$和小数字如$y$。 然后，$x \mod y$保证严格小于$y$。 如果我们选择$y$从排序数组的最小一半开始，$x$从最大的一半开始，剩下的$x \mod y$不能是任何最大的数字，并且因为我们选择的集合$y$很小，保证不与最大的数冲突。 这种贪婪配对总是有效的，并且可以在排序后的线性时间内实现。 

通过排序，我们可以安全地将后半部分的每个元素与前半部分的元素配对。 由于数组元素是不同的，并且向下取整函数可确保半配对，因此这会准确生成所需数量的对，而无需担心冲突。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 贪婪排序配对 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组并按升序对其进行排序。 排序确保我们可以轻松识别最小和最大的数字。 
2. 计算所需对的数量：$\lfloor n/2 \rfloor$。 
3. 配对最大的$\lfloor n/2 \rfloor$最小的数字$\lfloor n/2 \rfloor$数字按顺序排列。 也就是说，配对$i$- 最大的数字$i$-第一个最小的数字。 
4. 打印每对$(x, y)$按照选择的顺序。 通过建设，$x$总是大于$y$， 所以$x \mod y < y$并且不能出现在数组中最大的数字之中。 这保证了数组中不存在余数。 

为什么有效：排序将数组分为上半部分和下半部分。 总是将大量配对$x$数量较少$y$, 余数$x \mod y$小于$y$。 由于我们只将来自不同半部的元素配对，因此余数不能与上半部的任何元素重合，其中包含所有潜在的$x$价值观。 这个不变量确保所有对满足模条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    half = n // 2
    for i in range(half):
        print(a[n - i - 1], a[i])
```代码首先读取测试用例的数量。 对于每个测试用例，它读取数组，对其进行排序，并计算所需对的数量。 我们迭代索引$0$到$half-1$并将上半部分的每个元素与下半部分的相应元素配对。 排序是关键，因为它使我们能够保证满足模条件，而无需额外检查。

 ## 边缘情况

 对于数组`[1, 4]`，算法将最大的 4 与最小的 1 配对。余数`4 % 1`是 0，它不在数组中，产生有效的对。 如果我们天真地将 1 与 4 配对，则余数`1 % 4`将为 1，它出现在数组中并且违反了规则。 对最大与最小进行排序和配对可以自动避免这种失败。 类似地，对于奇数长度的数组，例如`[3, 8, 5]`，该算法仅产生`floor(n/2)=1`一对，这里`(8,3)`，保证正确性。
