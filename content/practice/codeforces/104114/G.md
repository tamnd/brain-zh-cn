 ## 解决方案
 ## 问题理解

 我们得到了一行固定的轴位置，已经从左到右排序，并且我们必须为这些轴分配给定的多组齿轮半径。 

一旦放置，每对相邻的齿轮都必须相切。 由于所有齿轮都位于同一条线上，因此相切会转化为严格的几何约束：如果两个相邻的轴位于同一位置$x_i$和$x_{i+1}$，指定的半径是$s_i$和$s_{i+1}$，那么中心之间的距离必须等于半径之和。 这给出了连续分配之间的确定性关系：每个相邻对必须满足$$s_i + s_{i+1} = x_{i+1} - x_i.$$所以任务不是自由分配半径。 我们对给定的半径进行排列，以便每个相邻对都满足线性约束，并且每个半径仅使用一次。 

这些约束促使我们寻求线性或近线性的解决方案。 高达$5 \cdot 10^5$齿轮，任何尝试所有排列甚至尝试每个起始配置并天真的模拟的解决方案都不会通过。 任何平方项$n$已经太慢了，甚至$O(n \log n)$解决方案必须避免重复繁重的检查。 

一个微妙的问题是约束定义了一条刚性链。 一旦我们确定了第一个齿轮半径，所有其他半径都会受到传播的影响。 这创建了一个隐藏的依赖关系：在第一个选择之后没有局部自由度，只有针对多重集的全局一致性检查。 

一种常见的故障模式来自于假设这只是相邻差异和半径之间的匹配问题。 例如，如果尝试在局部将差异与半径进行贪婪配对，则可能会产生满足局部约束但全局失败的序列。 

另一种失败模式是尝试任意修复端点而不检查一致性。 由于系统完全由第一个值决定，错误的选择会产生看似有效但不正确的完整序列。 

## 方法

 蛮力思想首先从给定的多重集中任意选择第一个轴的半径。 一次$s_1$选择后，每个下一个半径都被强制：$$s_{i+1} = (x_{i+1} - x_i) - s_i.$$这唯一地确定了线性时间内的完整序列。 构造完成后，我们验证它是否是输入半径的排列。 这在逻辑上是正确的，因为每个有效的解决方案都必须满足递归性。 

然而，尝试了所有的可能性$s_1$太贵了。 在最坏的情况下，我们会尝试$O(n)$候选人，每个成本$O(n)$重建和验证，导致$O(n^2)$工作。 

关键的观察是序列一次不是任意的$s_1$是固定的。 每个值都是仿射函数$s_1$与系数要么$+1$或者$-1$。 这意味着整个序列的行为相对于$s_1$，但不同指数的走势相反。 这样一来，构造出的序列的排序顺序就会以结构化的方式发生变化，可行性就变成了这个移动排序列表是否能够匹配半径固定排序列表的问题。 

我们不是尝试所有的起点，而是对待$s_1$作为连续参数，并询问是否存在一个值可以使生成的多重集完全匹配。 这成为一维参数的可行性问题，可以通过检查是否存在有效区间来解决$s_1$存在。 

我们可以检查候选人$s_1$通过构建序列并使用频率结构比较多重集，在线性时间内完成。 为了避免扫描所有候选者，我们利用了这样一个事实：只有当两个构造值交换顺序时，有效性才会发生变化，这种情况发生在可预测的线性边界处。 这使我们能够寻找可行的$s_1$使用对数或线性可行的引导检查（通常是在值域上进行二分搜索并进行验证）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对第一个元素的暴力破解 |$O(n^2)$|$O(n)$| 太慢了 |
 | 参数/单调可行性检查|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们重新制定了结构，以便一旦$s_1$确定了，整个序列就确定了。 我们计算前缀边差异$d_i = x_{i+1} - x_i$，然后将每个半径表示为线性函数$s_1$。 

1. 计算所有距离$d_i = x_{i+1} - x_i$。 这些编码了邻居之间的半径必须如何求和。 
2. 递归地表达序列$s_{i+1} = d_i - s_i$。 这意味着每个位置要么是$+s_1$或者$-s_1$加上一个仅取决于距离的常数。 
3. 预计算每个索引$i$一对$(a_i, b_i)$这样$s_i = a_i \cdot s_1 + b_i$， 在哪里$a_i \in \{+1, -1\}$。 这是由循环中的重复替换得出的。 
4. 观察指数分为两个单调组：具有系数的组$+1$增加为$s_1$增加，并且那些有系数的$-1$减少。 
5. 测试候选人的可行性$s_1$,构造所有$s_i$并使用递增组和递减组之间的两指针合并与已排序的半径多重集进行比较。 如果发生不匹配，则丢弃该候选者。 
6. 在足够大的整数范围（以坐标差和半径和为界）上使用二分搜索来查找任何$s_1$这会产生有效的多集匹配。 
7.一旦有效$s_1$找到后，使用递归重建完整序列并将其输出。 

它的工作原理与系统的刚性有关。 一旦第一个值固定，递归就会强制形成唯一的链，因此解空间是一维的。 仿射函数的排序结构确保只有当两个线性表达式之间的顺序关系交换时可行性才会发生变化，而这种情况只能在有限多个阈值下发生。 这将组合分配问题转变为结构化的单参数搜索。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build(x, s1):
    n = len(x)
    s = [0] * n
    s[0] = s1
    for i in range(n - 1):
        d = x[i + 1] - x[i]
        s[i + 1] = d - s[i]
    return s

def ok(x, r_sorted, s1):
    s = build(x, s1)
    s_sorted = sorted(s)
    return s_sorted == r_sorted

def solve():
    n = int(input())
    x = list(map(int, input().split()))
    r = list(map(int, input().split()))
    r_sorted = sorted(r)

    lo, hi = -10**18, 10**18
    ans = None

    for _ in range(60):
        mid = (lo + hi) // 2
        s = build(x, mid)
        s_sorted = sorted(s)

        if s_sorted <= r_sorted:
            lo = mid
        else:
            hi = mid

    for cand in [lo, hi]:
        s = build(x, cand)
        if sorted(s) == r_sorted:
            ans = s
            break

    print(*ans)

if __name__ == "__main__":
    solve()
```代码直接对递归结构进行编码。 这`build`函数从选定的起始半径执行强制传播。 这`ok`逻辑降低了多集比较的正确性，因为只允许排列。 

在第一个半径上使用二分搜索，因为可行性对于生成的多重集在以下变化下如何移动而言是单调的。$s_1$。 一旦搜索范围缩小到一个紧密的区间，我们就会显式地测试端点，因为只有完全匹配才是有效的。 

一个微妙的实现细节是重建必须是确定性的并且与递归一致。 交替传播中的任何算术错误都会立即破坏可行性，因为后来的值取决于所有先前的值。

 考虑一个轴距固定的小链条，我们寻找一致的分配。

```我们计算距离：$$d = [3, 6, 5]$$尝试候选人$s_1 = 2$:

 ## 边缘情况

 如果初始猜测不正确，则当重复将值驱动为零或负数时，就会出现临界边缘情况。 由于半径严格为正，因此这种失败会立即使候选无效，并且会在重建过程中发现这一点。 

当存在多个有效配置时，会出现另一种边缘情况。 该算法不依赖唯一性； 它只搜索任何可行的$s_1$。 一旦找到，确定性传播就保证了完全有效的排列。 

最后一个微妙的情况是当值非常大时。 由于所有计算都是输入坐标和半径的线性组合，因此需要使用 64 位整数以避免中间减法和加法期间的溢出。
