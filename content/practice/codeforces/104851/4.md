 ## 解决方案
 ## 问题理解

 我们正在向固定数量的儿童分发总数量的蛋糕。 每个孩子都必须收到完全相同的数量，但厨师可以将蛋糕切成两半，这意味着每个蛋糕可以贡献一个完整单位或两个半单位。 分配之后，任何东西都不能剩下，哪怕是一半。 

因此，这种情况相当于选择一些完整的蛋糕，并可能将一些蛋糕分成两半，这样蛋糕块的总数就可以平均分配给 D 个孩子，没有剩余。 每个孩子得到相同的份额，蛋糕的总量必须至少为 A。 

假设最佳使用分割，输出是最初需要购买的最小可能数量的整个蛋糕。 

关键的限制是每个蛋糕贡献 1 或 2 个半单位，具体取决于它是否被分割。 这引入了类似奇偶校验的灵活性：总量可以是 D 的任何整数或半整数倍，但由于所有内容都必须完全分配而没有剩余，因此当以一半表示时，总“蛋糕质量”必须恰好是 D/2 的整数倍。 

输入大小高达 10^9，因此任何依赖于迭代可能的蛋糕数量的解决方案都是不可能的。 我们需要一个直接的算术构造，可能涉及整除性和上限逻辑。 

当 A 已经可以被 D 整除或者 A 略低于 D 的倍数时，就会出现微妙的边缘情况。另一种情况是当 A 比 D 小时，此时分数共享力会向上舍入。 此外，D 等于 1 的情况表现不同，因为不存在分布约束。 

## 方法

 直接的暴力方法会尝试从 0 向上增加蛋糕的数量，模拟是否可以使用分割将至少 A 个蛋糕单元分配给 D 个子级。 对于蛋糕 C 的每个候选数量，我们将检查是否可以表示 C 和 2C（半个单位）之间可被 D/2 整除的某个总量。 这需要扫描可能的分割分布，有效地迭代切蛋糕的数量。 

这很快就变得不可行，因为 C 本身可以达到 10^9，并且对于每个 C，我们需要推理多个分割配置。 即使是对 C 进行线性扫描也已经太大了。 

关键的观察结果是，将蛋糕切成两半可以有效地使我们能够在按比例缩放的单位系统中工作，其中每个蛋糕贡献 2 个半单位或每半个 1 个半单位。 因此，我们不再考虑蛋糕，而是考虑半蛋糕。 令总需求量为半个整数 M，其中 M 必须满足 M ≥ 2A，且 M 可被 D 整除。 

给定固定的 M，所需的蛋糕数量取决于我们可以使用多少个完整的蛋糕以及我们必须形成多少个半蛋糕。 每个蛋糕最多可以贡献 2 个半单位，因此给定 M 所需的最小蛋糕数量为 ceil(M / 2)。 然而，我们还必须确保 M 在离散分布中是可实现的，但由于允许自由地一半，所以任何整数 M ≥ 0 都可以使用足够的完整蛋糕和分割蛋糕来表示。 

因此，问题简化为找到最小的 M，使得 M ≥ 2A 且 M % D = 0，然后将其转换回蛋糕作为 ceil(M / 2)。 

这样的M的最小值是不小于2A的D的最小倍数。

 ## 算法演练

 ## 最佳构造

1. 通过将要求 A 加倍为 2A，将问题转换为半单位。 这避免了显式处理小数部分，并将每个蛋糕变成一致整数系统中的 1 或 2 个单位。 
2. 计算 D 的最小倍数，至少为 2A。 该值表示可以在 D 个孩子之间平均分配且没有剩余的总可分配金额。 
3. 如果 2A 已能被 D 整除，则取 M = 2A。 否则计算 M = ((2A + D - 1) // D) * D。这确保 M 是满足这两个约束的第一个可行总数。 
4. 通过计算 ceil(M / 2) 将总的半单位转换回蛋糕。 每个蛋糕最多贡献 2 个半单位，因此这给出了足以达到 M 的最小蛋糕数量。 
5. 输出该值。 

### 为什么它有效

 转换为半单位消除了所有分数模糊性，使每个可行的分布都对应于一个整数总 M。由于每个子项必须获得相等的份额，因此 M 必须能被 D 整除。任何低于 2A 的 M 都无法满足最低要求，因此搜索空间从 2A 开始减少为 D 的倍数。 其中，最小化蛋糕数量相当于最小化 M，并且由于每个蛋糕最多贡献 2 个半单位，因此使用 ceil(M/2) 蛋糕是最佳的，并且始终可以通过混合完整蛋糕和分割蛋糕来实现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    D = int(input())
    A = int(input())

    need = 2 * A

    M = ((need + D - 1) // D) * D

    # each cake contributes up to 2 half-units
    ans = (M + 1) // 2

    print(ans)

if __name__ == "__main__":
    solve()
```实现首先将需求缩放为半个单位。 然后，它使用标准天花板除法技巧计算 D 的最小有效倍数。 最后，它通过上限除以 2 进行转换，因为每个蛋糕最多贡献两个半单位。 

一个微妙的点是整数除法必须小心地进行：`(M + 1) // 2`确保奇数 M 的正确性，这对应于一个半单位必须来自部分使用的蛋糕的情况。

 ## 边缘情况

 当 D = 1 时，平均分配的约束变得微不足道，答案简化为简单地满足最低要求 A，如果需要，可以使用一半。 该算法处理此问题是因为 1 的下一个倍数始终是值本身，因此 M = 2A 并且结果恰好变为 A。 

当A=0时，严格要求不需要蛋糕。 该算法计算出 need = 0，因此 M = 0，答案变为 0，正确反映不需要购买。 

当 2A 已经是 D 的倍数时，上限步骤不起作用。 在这种情况下，M = 2A，解决方案简化为 ceil(2A / 2) = A cakes，这符合每个蛋糕都可以得到充分利用而不会浪费的直觉。
