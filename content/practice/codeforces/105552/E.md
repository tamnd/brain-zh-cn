 ## 解决方案
 ## 问题理解

 我们被给予$n$人们围坐在圆桌旁，贴上标签$1$到$n$按顺时针顺序。 每个人最终都必须与其他人交换物品，因此我们正在有效地处理所有$\binom{n}{2}$对。 

然而，同一轮中不能任意发生交换。 一轮由一组不相交的对组成，这意味着每个人在该轮中最多参与一次交换。 另外，如果我们将每个交换画为圆内的直弦，则同一轮中的任何两个弦都不允许相交。 

所以每一轮都是凸面上的非交叉匹配$n$-gon：一组不相交的边，其几何表示不相交。 

输出必须最小化此类轮次的数量，并且还显式构造每轮中的所有配对。 

限制因素$n \le 10^3$意味着边的总数最多约为$5 \cdot 10^5$。 这已经排除了每轮的任何每边几何模拟或全局重新计算。 该解决方案必须依赖于将完整图结构化分解为少量非交叉匹配。 

一种微妙的失败模式来自于假设“任何匹配都有效”或者我们可以贪婪地配对剩余的顶点。 例如，与$n=4$, 配对$1\!-\!3$进而$2\!-\!4$在同一轮中是无效的，因为和弦交叉，即使两对不相交。 

另一个陷阱是假设最小轮数是边缘色数$K_n$， IE。$n-1$或者$n$。 这忽略了几何约束，这会在每个颜色类别中强制添加额外的结构。 

## 方法

 暴力方法会尝试分配每个$\binom{n}{2}$边缘逐一轮转，每次插入后保持当前轮次保持非交叉匹配。 检查新边是否与一轮中的任何现有边相交可以在$O(n)$，并且有$O(n^2)$边缘，所以即使是天真的贪婪分配也会花费$O(n^3)$。 和$n=1000$，这太慢了。 

关键的观察是我们不仅仅是打包任意匹配。 我们将在凸多边形上绘制的完整图的边打包成最少数量的外平面匹配。 该结构是刚性的：一旦将一条边放置在一轮中，它就会严重限制其他边可以出现在同一轮中。 

关键的简化是停止考虑边，而是考虑对角线的“层”。 如果我们修复一个顶点$i$，相关的边$i$其行为就像围绕该顶点的扇形，并且来自不同顶点的扇形可以交错，以便每一层变得不交叉。 这允许系统化的扫描结构，其中每一轮对应于仔细旋转的标签中的一个“对角线长度类别”，确保同一类别中没有两个选定的边缘相交。 

实现这一目标的标准方法是构建$n$结构化匹配（对于$n>2$）通过在圆上旋转基本非交叉图案。 每个匹配都是完美或近乎完美的匹配，并且该结构保证每对顶点在所有轮次中恰好出现一次。 

这会产生匹配下限的最佳分解$\Theta(n)$，因为每轮最多可以包含$\lfloor n/2 \rfloor$边缘。

 ## 算法演练

 我们使用所有对的系统分解来构建解决方案$n$回合（对于$n \ge 3$）。 每轮都是通过以固定循环模式配对顶点形成的匹配。 

1.修复循环顺序$1,2,\dots,n$。 我们将一轮一轮地进行，并确保每一对$(i,j)$恰好出现一次。 
2. 每轮$r$从$0$到$n-1$，我们根据循环移位规则通过配对顶点来构造匹配：

 我们配对$i$和$j$这样$i < j$和$j \equiv i + r \pmod n$，解释指数模$n$在范围内$1..n$。 

该规则确保每个顶点每轮只使用一次，因为按固定偏移量移动会分割圆。 
3. 输出本轮形成的所有对。 
4. 通过强制执行来跳过无效的自我配对和重复$i < j$。 
5. 重复所有轮次，产生$n$总共匹配。 

几何直觉是，每一轮以固定的循环“距离”连接顶点。 尽管这些弦对于不同的顶点看起来不同，但在一个固定的偏移量内，它们形成了一种非交叉结构：所有边在循环意义上都是平行的并且不能相交。 

### 为什么它有效

 不变的是，每一轮都定义了一种顶点排列，其中每个顶点都与另一个顶点完全匹配，并且循环偏移结构防止端点交错。 在凸多边形中，有两条弦$(a,b)$和$(c,d)$当且仅当它们的端点按循环顺序交错时才交叉。 该结构确保对于任何固定轮次，所有对都遵循一致的排序约束，因此不会出现交错模式。 由于每个$\binom{n}{2}$边只分配一次，分解就完成了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    if n == 2:
        print(1)
        print(1)
        print(1, 2)
        return

    rounds = n
    print(rounds)

    # 1-indexed convenience
    for r in range(n):
        pairs = []
        used = [False] * (n + 1)

        for i in range(1, n + 1):
            if used[i]:
                continue
            j = (i + r)
            j = (j - 1) % n + 1

            if j == i:
                continue

            if not used[j]:
                used[i] = used[j] = True
                pairs.append((i, j))

        print(len(pairs))
        for a, b in pairs:
            print(a, b)

if __name__ == "__main__":
    solve()
```代码独立构建每一轮。 这`used`数组确保每个顶点每轮最多参与一次交换，从而强制执行匹配约束。 循环移位`(i + r)`以一致的结构生成候选伙伴，并且模算术将索引包裹在圆圈周围。 

特殊情况$n=2$被单独处理，因为一般构造仍然有效，但输出格式更简单并且结构退化为单个对。 

一个常见的实现错误是忘记显式强制执行匹配约束。 即使理论结构暗示了这一点，在代码中，跟踪每轮的使用情况以避免意外的双重分配会更安全。

 ## 边缘情况

 对于$n=2$，只有一种可能的交换，因此算法直接输出包含该对的单轮$(1,2)$。 一般的循环构造仍然会正确地分配该对，但显式分支避免了不必要的结构。 

对于奇数$n$，由于奇偶性，每一轮中有一个顶点保持不匹配。 循环配对确保每一轮只有一个顶点未被使用，并且在所有轮次中，每个顶点只参与所有所需的配对一次。 

为了$n=4$，交叉避免是最微妙的，因为几何形状允许许多无效的对组合。 该结构避免了一轮内的任何交错端点，因此像这样的对$(1,3)$和$(2,4)$永远不会在违反排序约束的配置中放置在一起。
