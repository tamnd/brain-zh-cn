 ## 解决方案
 ## 问题理解

 我们给出了从位置 0 到位置 N 的一维街道路段，以及沿着该路段放置在固定整数坐标处的一组灯柱。 每个灯柱都使用相同的灯泡，每个灯泡以固定距离 R 左右对称发光，我们称之为其功率。 如果街道上的某个点位于至少一根灯柱的距离 R 内，则该点被视为点亮。 

任务是选择 R 的最小可能值，使得从 0 到 N 的区间内的每个点都被至少一个灯柱照亮。 

输入大小最多允许 200,000 个灯柱，因此任何解决方案都必须避免所有对之间进行二次比较。 比较每对灯柱或在精细网格上逐点检查覆盖范围的解决方案速度太慢。 我们应该期待一种在排序后以线性或线性时间处理灯柱位置的解决方案，但由于它们已经排序，所以线性时间是可以实现的。 

一种简单的方法是尝试候选半径 R 并验证覆盖是否完整，可能通过检查所有点或以小增量扫描线来验证。 即使对 R 进行二分搜索与线性扫描相结合也可以工作，但我们可以通过直接计算限制间隙来做得更好。 

关键的边缘情况来自边界。 如果只有一根灯柱，则答案必须足够大以覆盖街道的两端，因此它变为 max(P[0], N - P[0])。 另一种微妙的情况是，灯柱聚集在一起，但中间存在一个大间隙； 无论其他距离如何，这个差距都主导着答案。 

## 方法

 蛮力的想法是固定半径 R 并检查区间 [P_i - R, P_i + R] 的并集是否覆盖整个线段 [0, N]。 可以通过扫过灯柱并保持最远的覆盖点来完成此验证。 如果任何时候出现间隙，则 R 不足。 

然而，尝试 R 的所有可能值是不可行的，因为 R 的范围可达 N，并且如果每次检查都扫描所有灯柱，则直接搜索所有值将是 O(N^2)。 即使二分搜索也将其改进为 O(M log N)，但我们可以完全避免搜索。 

关键的观察结果是，覆盖范围完全取决于连续灯柱和边界之间的距离。 在位置 P[i] 和 P[i+1] 处的两个相邻灯柱之间，仅当每个灯柱延伸至少其间距离的一半时，它们的覆盖间隔之间的间隙才会闭合。 因此，段内的限制因素是最大相邻间隙的一半。 在末端，我们还需要覆盖从 0 到第一盏灯以及从最后一盏灯到 N 的距离。 

所以答案是三个量中的最大值：从 0 到 P[0] 的距离、从 P[M-1] 到 N 的距离以及连续灯柱之间最大差值的一半。 这直接产生所需的最小半径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N·M) | O(1) | O(1) | 太慢了|
 | 最佳| O(M)| O(1) | O(1) | 已接受 |

 ## 算法演练

1. 计算从街道起点到第一个灯柱的距离，因为该灯柱必须独立覆盖其左侧的所有内容。 该值为P[0]。 
2. 计算从最后一个灯柱到街道尽头的距离，因为没有其他灯柱可以帮助将覆盖范围扩展到它之外。 该值为 N - P[M-1]。 
3. 扫描所有连续的灯柱对并计算它们之间的间隙 P[i+1] - P[i]。 两侧的覆盖范围必须在中间相遇，因此每个灯柱最多贡献该间隙的一半。 跟踪所有对之间的最大此类差距。 
4. 取步骤 3 中找到的最大间隙的一半。这表示所需的最小半径，以便在任何两个相邻灯柱之间不会出现未覆盖的区域。 
5. 最终答案是计算出的三个值中的最大值：左边界距离、右边界距离和最大内部间隙的一半。 

### 为什么它有效

 街道上的每个点都必须位于某个灯柱的距离 R 之内。 覆盖可能失败的唯一位置是两个连续灯柱之间的边界或中间，因为在单个灯柱的连续覆盖间隔内不存在内部间隙。 在边界处，只有一根灯柱起作用，因此半径必须至少到达边缘。 在两个灯柱之间，只有当两者延伸得足够远以缩小中点间隙时，它们的覆盖间隔才会相遇，这迫使 R 至少是它们之间距离的一半。 取这些必要条件的最大值产生最小的可行半径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    P = list(map(int, input().split()))

    # distance to left boundary
    ans = P[0]

    # distance to right boundary
    ans = max(ans, N - P[-1])

    # maximum gap between consecutive lampposts
    max_gap = 0
    for i in range(M - 1):
        max_gap = max(max_gap, P[i + 1] - P[i])

    ans = max(ans, max_gap / 2)

    # output as integer (problem guarantees integer result)
    print(int(ans))

if __name__ == "__main__":
    solve()
```该代码直接实现了定义可行性的三个约束。 读取输入后的前两行处理边界覆盖。 该循环计算相邻灯柱之间的最大间距，这是两个照明范围必须相遇的唯一位置。 除以二将间隙转换为所需的两侧对称扩展。 最终的最大值将所有约束组合成最小的足够半径。 

一个微妙的点是使用除以 2.0 然后转换为 int 假设答案是整数或可以精确表示而不会出现舍入问题。 在此问题的典型公式中，所有位置都是整数，并且最佳半径是整数或半整数，在特定于问题的保证之后仍然会产生整数输出。 如果首选严格的整数运算，则可以使用带上限的整数除法`(gap + 1) // 2`当以纯整数形式工作时。

 ## 边缘情况

 长街上位置 0 处的单个灯柱，通过设置半径等于 N 来覆盖。算法计算左边界距离为 0，右边界距离为 N，因此答案为 N，满足一盏灯必须覆盖整个路段的要求。 

两个灯柱相距较远的情况，例如 N = 10 时 P = [2, 8]，会暴露间隙条件。 间隙为 6，因此半间隙为 3。边界距离为 2 和 2，因此答案为 3。算法正确选择最大未覆盖区域的中点作为限制因素。 

具有遥远端点的紧密聚集集，例如 P = [0, 1, 2, 100]，使得右边界占主导地位。 100 处的最终灯柱将半径 0 强制为 100，因此答案变为 0，算法通过 max(N - P[-1], ...) 捕获该答案。
