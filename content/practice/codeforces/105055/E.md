 ## 解决方案
 ## 问题理解

 我们得到一个仅由字符组成的字符串`a`和`b`。 该字符串不是任意的：它应该是二进制密码的编码，其中每个`0`被块取代`ab`和每个`1`被块取代`aba`。 原始密码是一个位序列，编码将这些固定块按顺序连接起来。 

我们的任务是恢复任何可能产生给定字符串的有效原始位串。 如果字符串无法分割成有效块序列`ab`和`aba`，我们必须报告失败。 

所以真正的问题是对具有两个终结规则的字符串语法的解析问题。 我们必须判断输入字符串是否属于连接生成的语言`ab`和`aba`，如果是，则重建一个有效的选择序列。 

长度限制最多为 100,000 个字符。 这立即排除了对所有可能的分段的任何指数搜索。 一种天真的回溯方法，尝试之间的每一个分割`ab`和`aba`可以在多个位置分支，并且在最坏的情况下，分解的数量呈指数增长，因为每次出现`aba`引入了消费两个或三个角色之间的选择。 

因此，我们需要一种线性或近线性解析策略。 

每当前缀出现时，就会出现微妙的失败情况`aba`发生。 在这种情况下，两种解释都是可能的：要么采取`aba`作为`1`，或取`ab`作为`0`并留下下一个字符进行解析。 一种贪婪的策略，总是更喜欢输入上较长的比赛休息时间，例如`ababa`，在哪里取`aba`即使存在有效的分解，首先也会留下无效的后缀。 

## 方法

 暴力解决方案会尝试从位置零开始分割字符串，每当我们看到有效标记时就分支。 从任何位置`i`， 如果`s[i:i+2] = ab`，我们尝试将其解释为`0`，如果`s[i:i+3] = aba`，我们尝试将其解释为`1`。 这形成了一个递归树，其中每个`aba`可以分支成两个延续。 

这种方法的正确性很简单，因为它探索了所有可能的细分。 然而，在最坏的情况下，比如像这样的字符串`ababababa...`，几乎每个位置都允许两种选择，并且递归状态的数量随着长度呈指数增长。 这远远超出了可行的范围`n = 10^5`。 

关键的观察结果是，这是一条线上的经典可达性问题：在每个索引处`i`，我们只关心后缀是否`i..n`可以解析。 每个位置仅取决于最多两个前锋位置，`i+2`和`i+3`。 这种结构允许在线性时间内从右到左进行动态编程。 

我们不探索路径，而是计算布尔可行性数组`dp[i]`指示后缀是否开始于`i`可以完全解析。 一旦知道这一点，我们就使用 DP 表从左到右贪婪地重建任何有效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力回溯| O(2^n) | O(2^n) | O(n) | 太慢了|
 | 动态规划+重构| O(n) | O(n) | 已接受 |

 ## 算法演练

 ### 1. 定义问题的状态

 我们定义`dp[i]`子串是否从位置开始`i`可以完全划分为有效的块。 位置`n`（字符串结尾）始终有效，因为空后缀不需要标记。 

### 2. 计算从右到左的转换

 我们处理索引`n-1`下降到`0`。 在每个位置`i`，我们检查是否可以获取有效令牌：

 如果子串`s[i:i+2]`等于`ab`，然后我们可以移动到`i+2`如果`dp[i+2]`是真的。 

如果子串`s[i:i+3]`等于`aba`，然后我们可以移动到`i+3`如果`dp[i+3]`是真的。 

我们储存`dp[i] = true`如果任一选项成功。 

### 3. 重建有效答案

 如果`dp[0]`为 false，不存在有效的解析，我们输出失败。 否则我们从索引开始`0`并反复选择有效的转换。 我们更喜欢采取`ab`第一个（代表`0`)，但前提是它根据以下规则导致有效的后缀`dp`。 如果没有，我们采取`aba`（代表`1`）。 

这种重建确保我们构建一致的位序列。 

### 为什么它有效

 民主党保证`dp[i]`当存在至少一个有效的后缀分段（从`i`。 每次转换都会将问题简化为更小的后缀，因此不存在循环。 在重建过程中，我们总是移动到已知可解的状态，因此我们永远不会过早陷入困境。 这确保输出对应于字符串的完整有效分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)

dp = [False] * (n + 1)
dp[n] = True

for i in range(n - 1, -1, -1):
    if i + 2 <= n and s[i:i+2] == "ab" and dp[i+2]:
        dp[i] = True
    if i + 3 <= n and s[i:i+3] == "aba" and dp[i+3]:
        dp[i] = True

if not dp[0]:
    print(":(")
    sys.exit()

i = 0
ans = []

while i < n:
    if i + 2 <= n and s[i:i+2] == "ab" and dp[i+2]:
        ans.append('0')
        i += 2
    else:
        ans.append('1')
        i += 3

print("".join(ans))
```DP 数组是向后填充的，这样当我们计算时`dp[i]`， 两个都`dp[i+2]`和`dp[i+3]`是已知的。 重建阶段依赖于每一步都存在至少一个有效转换的不变量，因为`dp[0]`被证实属实。 

更喜欢的选择`ab`首先是任意的； 任何一致的打破平局的方法都有效，因为 DP 保证至少保留一条有效路径。
