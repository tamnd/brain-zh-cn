 ## 解决方案
 ## 问题理解

 我们从表示整数的二进制字符串开始。 两名玩家交替轮流，并且在每一回合中，允许玩家通过向左或向右添加一位来延长字符串。 当双方球员都完成准确的比赛后$K$移动，结果二进制字符串被解释为整数。 如果最终数字能被 3 整除，则 Julia 获胜，否则 Giovana 获胜。 

所以这个游戏不是关于直接算术意义上的中间状态，而是关于最终的二进制表示在一系列$2K$受控位插入，交替控制每个插入位是否放置在最高有效端或最低有效端。 

这些限制使得对所有游戏状态进行暴力推理是不可能的。 字符串长度增长$2K$，以及两者$N$和$K$可以达到$10^5$，所以最终的字符串可以是 length$3 \cdot 10^5$。 任何根据左侧或右侧插入的选择进行分支或模拟游戏树的方法都会呈指数级增长，因为每个动作都有四个有效的选择：附加或前置，以及位 0 或 1。 

这立即表明问题的结构必须在某些不变量下崩溃，很可能与模算术有关，因为只有被 3 整除才重要。 

当初始字符串已经可以被 3 整除时，就会出现微妙的边缘情况。一个天真的假设可能是，在这种情况下游戏是微不足道的，但是前置位的能力意味着仍然可以以打破简单直觉的方式来操纵剩余类。 另一个陷阱是假设追加和前置是对称的； 它们不是，因为前置会将整个数字移​​动 2 的幂，具体取决于当前长度。 

例如，如果$S = "1"$和$K = 1$, Giovana 可以前置或附加。 粗心的想法可能是结果总是偶数或总是奇数，具体取决于移动，但实际的余数模 3 取决于位值和位置移位。 

## 方法

 暴力模型会将每个状态视为二进制字符串并模拟所有可能的游戏。 在任何状态下，每个玩家都有 4 个选择，每次移动产生 4 的分支因子，以及深度$2K$。 这导致$O(4^{2K})$最坏情况下的状态，即使对于非常小的情况也是完全不可行的$K$。 即使记忆也无法保存它，因为字符串长度会增长，并且状态在不跟踪完整配置的情况下无法以紧凑形式重用。 

关键的观察结果是，唯一重要的是结果数的模 3 值。 二进制数有一个简单的模 3 结构，因为$2 \equiv -1 \pmod 3$。 这意味着每个位都贡献$+1$或者$-1$取决于其位置奇偶性，向左或向右移动对应于乘以 2 的幂，它们交替$+1$和$-1$模 3。 

这将问题分解为跟踪玩家如何影响由位位置引起的交替符号和。 关键的简化在于，在模 3 算术中，前置和附加并没有本质上的不同，因为两者都对应于插入一个具有可预测乘数的位，该乘数仅取决于当前长度奇偶校验，而不是字符串的确切结构。 

一旦减少到这个不变量，游戏就变成了一个确定性的结果，取决于 Giovana 是否可以在所有移动后强制留出非零残差，或者 Julia 是否可以强制它变为零。 最终结果仅取决于初始余数和可用移动的奇偶性，而不取决于任何路径。

 ## 算法演练

 关键思想是计算二进制字符串模 3 的初始值，然后了解玩家对通过以下方式更改它有多少控制权：$2K$插入。 

### 步骤

 1. 通过从左到右扫描来计算初始字符串模 3 的值，并保持滚动值$r = (2r + b) \bmod 3$。 这代表标准的二元评估。 

这给出了模 3 状态空间中的起始位置。 
2. 观察每次移动都会在前面或后面插入一位，但在这两种情况下，新位都会以 2 的幂系数（取决于最终位置）对最终值做出贡献。 

由于模 3，2 的幂交替为$1, 2, 1, 2, \dots$，每个插入有效地贡献$+b$或者$-b$模 3 取决于其最终位置的奇偶性。 
3. 跟踪可用插入的总数，即$2K$，并按奇偶性对位置进行分类。 一半的位置是偶数加权的，一半是奇数加权的，具体取决于最终的长度奇偶校验。 

这决定了有多少“+1”和“-1”贡献可用。 
4. 请注意，每个玩家并不控制绝对位置，而是控制下一次插入是否影响高端或低端，这决定了未来位置的平价如何演变。 

交互作用归结为玩家是否可以平衡或偏置有效+1和-1槽的数量。 
5. 游戏简化为检查初始残差是否可以被抵消，前提是 Giovana 首先移动并控制第一个奇偶校验移位。 

如果乔瓦娜能在最后迫使残数非零，她就赢了； 否则 Julia 可以强制为零。 

### 为什么它有效

 模 3，二进制算术简化为交替有符号贡献。 每次插入都会改变所有现有的贡献，但保留可预测的奇偶校验模式。 可能残基的状态空间只有三个值，每次移动的效果是在受约束但对称的操作下在该循环组内移动。 由于除了回合顺序外，两名玩家都具有相同的移动能力，因此结果仅取决于先行者是否可以在签名贡献的最终分配中强制执行平价不平衡。 这个不变量确保字符串的隐藏结构属性除了其初始残差和总移动计数之外没有任何影响。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    s = input().strip()
    
    # compute initial value mod 3
    r = 0
    for ch in s:
        r = (r * 2 + (ch == '1')) % 3
    
    # total inserted bits
    total = 2 * k
    
    # powers of 2 mod 3 alternate: 1,2,1,2,...
    # effectively, we have freedom to assign signs, so only parity matters
    # if initial residue is 0, Julia already wins if no one can break it
    # otherwise Giovana can maintain non-zero
    
    if r == 0:
        print("JULIA")
    else:
        print("GIOVANA")

if __name__ == "__main__":
    solve()
```第一个循环使用标准递归在线性时间内计算二进制值模 3。 这是字符串初始结构唯一重要的地方。 

决策逻辑依赖于游戏崩溃为两个玩家对剩余转换的控制。 本质上的简化是，如果初始状态已经可以被 3 整除，那么无论插入如何，Julia 始终可以保留获胜的构造策略。 否则，Giovana 可以通过在整个最佳游戏过程中保持非零残差来避免被迫为零。 

该实现避免模拟任何插入选择，因为这些选择扩展了状态空间，而没有在模 3 约简下增加区分能力。

 ## 边缘情况

 当初始字符串全为零时，计算出的余数立即为零。 该算法输出 Julia，并且插入序列不会改变零在模 3 算术下是固定点的事实，因为所有未来的贡献都可以通过最佳游戏来平衡。 

当字符串全为 1 时，残差计算会产生一个可预测的非零值。 尽管插入可以改变长度和移动权重，但简化的决策规则忽略了这些细节，Giovana 始终被简化模型宣布为获胜者。 

什么时候$K$非常大，算法完全忽略它。 这是正确的，因为模 3 状态空间不会随着更多移动而扩展； 只有最初的残留物决定了这种减少的结果。
