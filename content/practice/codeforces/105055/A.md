 ## 解决方案
 ## 问题理解

 我们得到了一系列贴纸包，每个包都有一个成本和其中包含的多组贴纸。 每个贴纸都有一个从 1 到 M 的标识符，目标是获取该范围内每个标识符的至少一份副本。 

使问题变得有趣的限制是我们不允许选择任意包。 我们必须选择一个连续的包段，这意味着我们选择一个间隔$[i, j]$，我们购买该范围内的每一包。 这种选择的成本是该区间内所有包的价格之和。 好处是这些包中出现的所有贴纸的联合，仅将包中的重复项计算为对覆盖范围的单一贡献。 

任务是找到一个有效区间，覆盖从 1 到 M 的所有贴纸，并且总成本最小。 如果没有一个区间能够实现全覆盖，那么答案是不可能的。 

这些限制允许最多 200,000 个包，并且所有包中的贴纸条目总数为 200,000 个。 这立即表明任何显式检查所有间隔的解决方案都太慢。 一个天真的$O(N^2)$扫描所有间隔将需要大约$4 \cdot 10^{10}$在最坏的情况下进行检查，这远远超出了可行的限度。 即使每次检查都是线性的，也完全无法使用。 

更微妙的一点是，困难不仅仅是选择一个区间，而是验证它是否包含所有 M 个不同的贴纸。 该检查本身必须是高效且增量的。 

一些边缘情况值得牢记。 如果 M 为 1，则任何包含贴纸 1 的单个包都已形成有效答案，并且最佳间隔就是最便宜的此类包。 假设间隔越长越好的幼稚方法可能会错误地不必要地扩大间隔。 

另一个特殊情况是某些贴纸从未出现在任何包装中。 例如，如果 M = 3 并且没有包包含贴纸 2，则任何间隔都不会有效。 仅检查间隔而不预先验证全局可行性的解决方案可能会浪费时间或错误地返回部分间隔。 

最后，包内的重复项仅就集合成员身份而言很重要。 一包就像$[1,1,1]$应该表现得完全一样$[1]$。 任何计算频率而不是存在的解决方案都可能使正确性变得过于复杂，而没有任何好处。 

## 方法

 蛮力的想法很简单：尝试每个可能的间隔$[i, j]$，将里面的所有贴纸收集起来，检查工会是否覆盖了所有M贴纸。 虽然原则上是正确的，但这种方法会从头开始重复重新计算并集。 即使进行增量维护，仍然存在$O(N^2)$间隔，并且更新每次扩展的覆盖范围仍然会导致二次行为。 这会立即失败$N = 2 \cdot 10^5$。 

关键的观察是，条件“这个区间覆盖所有贴纸”对于扩展来说是单调的：如果一个区间已经覆盖了所有贴纸，则扩展它只会保留有效性，而不会破坏它。 这表明了一个两指针或滑动窗口结构，其中我们维持在每个右边界结束的最小有效间隔。 

然而，还有一个额外的问题：我们正在最小化成本，而不仅仅是找到任何有效的区间。 所以我们不能简单地停在第一个有效窗口； 我们必须考虑所有右端点并跟踪最便宜的有效左边界。 

这自然会导致包阵列上出现滑动窗口。 当我们展开右侧指针时，我们会维护贴纸上的频率结构，并跟踪当前覆盖了多少个不同的贴纸。 一旦窗口变得有效，我们就会尝试从左侧缩小，同时保持有效性，从而最大限度地减少过程中的成本。 使用包值的前缀更新来增量维护成本。 

这将问题从间隔的二次枚举减少到每次指针移动均摊常数时间更新的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(N^2 \cdot M)$|$O(M)$| 太慢了|
 | 滑动窗|$O(N + \sum K_i)$|$O(M)$| 已接受 |

 ## 算法演练

 我们将每个包视为一个单位，并附有成本和贴纸列表。 我们维护一个滑动窗口$[L, R]$、成本的运行总和以及每个贴纸在当前窗口内出现的次数的频率计数。 

1. 初始化 L = 0，current_cost = 0，并用零填充大小为 M + 1 的数组 freq。 还要保持计数器被覆盖 = 0，指示窗口中当前存在多少个不同的贴纸。 
2. 将 R 从左向右展开到所有包上。 当我们包含包 R 时，我们将其成本添加到 current_cost 并迭代其贴纸列表。 对于每个贴纸，如果 freq 变为 1，我们就会增加覆盖范围。 这一步是正确的，因为我们只关心贴纸在时间间隔内是否至少出现一次，而不关心它出现了多少次。 
3、添加pack R后，检查covered是否等于M，如果不等于，则继续扩展R。 
4. 当covered等于M时，当前窗口有效。 此时，我们尝试在保持有效性的同时缩小 L。 我们反复尝试移除 L 包：减去其成本，并降低其贴纸的频率。 如果任何贴纸频率下降到零，我们就会减少覆盖并停止收缩。 这确保我们为这个固定的 R 保持尽可能小的左边界。 
5. 每次收缩后窗口有效时，我们使用 current_cost 和区间 [L, R] 更新最佳答案。 这是安全的原因是，对于固定的 R，贪婪收缩步骤保证了所有有效左端点之间的最小成本。 
6. 继续移动 R 直至结束。 记录的最佳间隔就是最终答案。 如果未找到有效间隔，则输出 -1。 

### 为什么它有效

 在每个位置 R，算法都会维护最小的 L，使得 [L, R] 覆盖所有贴纸。 任何较大的 L 只会删除有效的候选者或增加成本，而任何较小的 L 都会破坏覆盖范围。 这表明，对于每个 R，算法准确地考虑以 R 结尾的最佳区间。由于每个有效区间都有一些右端点 R，因此在本次扫描中必须遇到它，以确保全局最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    packs = []
    for _ in range(n):
        arr = list(map(int, input().split()))
        k = arr[0]
        v = arr[1]
        stickers = arr[2:]
        packs.append((v, stickers))
    
    freq = [0] * (m + 1)
    covered = 0
    
    best = float('inf')
    best_l = -1
    best_r = -1
    
    current_cost = 0
    l = 0
    
    for r in range(n):
        cost_r, stickers = packs[r]
        current_cost += cost_r
        
        for s in stickers:
            if freq[s] == 0:
                covered += 1
            freq[s] += 1
        
        if covered < m:
            continue
        
        while l <= r:
            cost_l, stickers_l = packs[l]
            can_remove = True
            
            for s in stickers_l:
                freq[s] -= 1
                if freq[s] == 0:
                    covered -= 1
                    can_remove = False
            
            current_cost -= cost_l
            if not can_remove:
                break
            l += 1
        
        if covered == m and current_cost < best:
            best = current_cost
            best_l = l
            best_r = r
    
    if best == float('inf'):
        print(-1)
    else:
        print(best)
        print(best_l + 1, best_r + 1)

if __name__ == "__main__":
    solve()
```该实现将频率阵列保留在贴纸上并维持运行成本。 重要的微妙之处在于，当缩小左边界时，我们会立即检测到贴纸计数何时降至零并停止缩小，因为进一步删除会破坏有效性。 

另一个细节是索引：内部指针是从零开始的，但输出必须是从一开始的，因此两个端点最后都会移位+1。

 ## 边缘情况

 一个关键的边缘情况是贴纸在一个包装内多次出现。 该算法可以正确处理这个问题，因为频率只关心零状态和非零状态。 即使一个包包含同一张贴纸的许多副本，删除它也会减少频率，但不会错误地减少覆盖范围，除非删除最后一个副本。 

另一种情况是只有一个包包含所有必需的贴纸。 该算法从 L = R = 该包开始，立即达到完全覆盖，并且缩小尝试将在第一次删除时失败，留下正确的单元素间隔。 

最后一个微妙的情况是仅在阵列的最末端实现覆盖。 由于该算法在每次扩展 R 后都会检查有效性，因此仍会评估最后一个可能的窗口并将其与最佳答案进行比较，以确保不会错过任何后期有效间隔。
