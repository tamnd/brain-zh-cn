 ## 解决方案
 ## 问题理解

 两名运动员在健身房轮流进行固定大小的重复训练。 马塞尔总是执行第一个拦截，然后是若昂扎奥，然后再次是马塞尔，依此类推。 每个块恰好包含`M`重复。 他们不追踪每个人的个人贡献； 相反，有一个计数器`N`记录总共完成了多少次重复。 

任务是确定接下来轮到谁`N`考虑到轮流严格按照大小块交替，重复已经执行过`M`。 

重新表述这种情况的一个有用方法是将重复序列想象成大小不同的块`M`。 块 0 是 Marcel 的，块 1 是 Joãozão 的，块 2 又是 Marcel 的，依此类推。 总计`N`告诉我们我们在这个分块序列中有多远，我们需要确定我们当前处于哪个块以及它是否已经完成。 

约束条件允许`N`和`M`最多`10^9`。 这立即排除了任何不断重复增加重复的模拟，因为在最坏的情况下这将需要多达十亿步。 该解决方案必须使用算术在恒定时间内计算答案。 

出现微妙的边缘情况时`N`恰好是`M`。 例如，如果`M = 3`和`N = 6`，那么恰好两个完整的块已经完成。 在这种情况下，我们正处于新区块的开始处，因此 Marcel 应该是下一个，因为在 Joãozão 完成完整的区块后，转弯总是以 Marcel 重新开始。 一个简单的实现，只检查`(N // M) % 2`如果不考虑我们是在块的内部还是边界，如果它以相同的方式对待完成和部分进度，很容易错误地转移答案。 

另一个重要的边缘情况是当`N < M`。 例如，如果`M = 8`和`N = 6`，我们仍在马塞尔的第一个街区内。 正确答案仍然是 Marcel，即使尚未到达下一个完整块边界。 

## 方法

 暴力模拟会逐一跟踪重复，每次出现一个块时都会切换活跃的人。`M`重复次数完成。 我们将维护一个当前区块进度的计数器和一个轮到谁的切换开关。 每次重复都会增加计数器，一旦达到`M`，我们重置它并切换玩家。 

这种方法是正确的，因为它直接反映了问题中描述的过程。 然而，它执行`N`迭代，并且自从`N`可以大到`10^9`，在时限内运行速度太慢了。 

关键的观察是，只有完整的区块才能决定下一个轮到谁。 每一个`M`重复会翻转活跃玩家。 因此，我们不需要模拟单独的重复，而只需要统计已经完成了多少个完整的块，即`N // M`，然后确定我们是在部分完成的块内还是恰好在边界处。 

“块内”和“精确边界”之间的区别决定了我们应该查看当前块还是下一个块。 如果`N % M == 0`，我们正处于新区块的开始处，因此下一个玩家直接由已完成区块的奇偶性决定。 如果`N % M != 0`，我们仍在当前区块内，因此下一个玩家是当前活跃的玩家。

 ## 算法演练

 1. 计算有多少个完整的大小块`M`使用整数除法完全完成`q = N // M`。 这会计算转弯完全切换的次数。 这很重要，因为每个完成的方块都会翻转活跃玩家。 
2. 使用以下命令计算我们在当前块内的距离`r = N % M`。 这表明我们是否正好处于边界或仍在区块中间。 
3.如果`r == 0`，那么当前在部分填充的块中不会执行任何重复。 下一个开始的块是块`q`，所以下一个玩家的身份仅取决于是否`q`是偶数还是奇数。 由于 Marcel 从块 0 开始，偶数索引对应于 Marcel，奇数索引对应于 Joãozão。 
4. 如果`r != 0`，我们在街区内`q`。 这意味着当前活跃玩家仍在处理该块，因此下一个重复属于分配给该块的同一个玩家`q`。 适用相同的奇偶规则。 
5. 输出“MARCEL”如果`q`是偶数，否则输出“JOAOZAO”。 

核心决策将整个过程简化为跟踪我们所在的区块并使用奇偶校验将区块映射到玩家。 

### 为什么它有效

 每个完整块的大小`M`恰好对应于单个玩家的一个不间断回合，并且回合从 Marcel 开始确定性地交替。 因此，仅区块索引就可以唯一地确定玩家。 剩下的`r`不会改变我们所在的区块，只会改变我们是在它的末端还是在它的内部。 由于下一个操作始终由当前块分配确定，因此`q`足以在所有情况下确定正确的玩家。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())

q = N // M
r = N % M

if q % 2 == 0:
    print("MARCEL")
else:
    print("JOAOZAO")
```该代码首先读取两个整数并计算已完成的完整块数。 计算余数，但除了确认我们是在块内还是在边界外，不会影响最终决策，并且这两种情况都解析为相同的基于奇偶校验的规则。 

关键的实现选择是完全忽略模拟。 除了确认划分行为之外，无需跟踪块内的进度。 整数除法和模完全编码系统的状态。

 ## 边缘情况

 当`N = 0`，没有重复执行。 该算法计算`q = 0`，它是偶数，所以它输出 Marcel. 这符合马塞尔总是先开始的事实。 

什么时候`N`正好可以整除`M`， 例如`N = 20, M = 5`，我们有`q = 4`。 该算法将此视为新块的开始，并且由于块 4 再次对应于 Marcel（偶数索引），因此输出是正确的。 

什么时候`M = 1`，每个重复都是它自己的块。 该算法将问题简化为交替每一步，并且奇偶校验`N`直接确定结果，该结果与预期的交替序列相匹配。
