 ## 问题理解

 我们给定一个整数参数$N$和有理函数$$f(x) = \frac{5xN^2}{x^2 + 3xN - 5N^2}.$$任务是找到所有真实值$a$这样就可以堵住$a$进入函数返回相同的值，意思是$f(a) = a$。 我们必须输出存在多少个这样的值并明确列出它们。 

输入大小很小：$N$在于$[-300, 300]$并且非零。 这立即排除了对渐近重方法的任何需要； 任何最终解决每个测试用例的恒定大小代数问题的解决方案就足够了。 

主要的微妙之处在于我们正在求解具有域限制的有理方程。 对于某些值，分母可能为零，并且即使这些值在化简后显示为代数根，也必须将其排除。 在不跟踪此限制的情况下将两边乘以分母的简单代数运算将意外地包含无效点。 

第二个微妙的点是取消$x$很诱人，因为分子包含$x$， 但$x = 0$必须单独对待。 尽管当分母在零处非零时它是有效的，但在化简过程中很容易丢失该根。 

边缘情况包括：

 对于$N = 1$，分母变为$x^2 + 3x - 5$，它有实根，因此一些候选解可能与函数的极点重合。 粗心的求解器可能会包含这样的点。 

为了$x = 0$，我们总是得到$f(0) = 0$只要分母非零，并且由于分母的计算结果为$-5N^2 \neq 0$，对于任何情况，零始终是有效的解决方案$N \neq 0$。 

最后，方程可以简化为二次方程，这意味着最多有两个超过零的附加根，但我们必须验证没有一个与禁止分母零相一致。 

## 方法

 强力解释是处理方程$f(x) = x$作为持续的平等并尝试枚举候选人的真实价值。 这是不可能的，因为真正的解决方案是不可枚举的。 

相反，我们直接符号求解代数方程。 函数相等$$\frac{5xN^2}{x^2 + 3xN - 5N^2} = x$$可以通过将两边乘以分母来进行变换，但前提是明确排除分母为零的值。 这产生了一个可以精确找到其根的多项式方程。 

执行代数：$$5xN^2 = x(x^2 + 3xN - 5N^2)$$展开右侧：$$5xN^2 = x^3 + 3x^2N - 5xN^2.$$将一切都放在一边：$$0 = x^3 + 3x^2N - 10xN^2.$$因式分解$x$：$$x(x^2 + 3Nx - 10N^2) = 0.$$所以一种解决方案总是$x = 0$。 其余的解来自二次方程：$$x^2 + 3Nx - 10N^2 = 0.$$其判别式为：$$\Delta = 9N^2 + 40N^2 = 49N^2.$$所以：$$x = \frac{-3N \pm 7|N|}{2}.$$自从$N^2$总是正数，我们直接化简：$$x = \frac{-3N \pm 7N}{2}.$$因此这两个根是：$$x_1 = 2N, \quad x_2 = -5N.$$我们仍然必须验证这些不会使分母为零。 替换他们从未做过的节目$N \neq 0$，所以三个根都是有效的。 

蛮力思想失败了，因为它将有理方程视为需要对实数进行搜索，而结构干净利落地折叠成具有明显因式分解的立方体。 关键的观察是，有理函数与恒等函数的等式总是在清除分母后产生多项式方程，并且在这里它完全因式分解。

 ## 算法演练

 1.从等式开始$f(x) = x$并将两边乘以分母，但前提是分母在有效解中不为零。 这确保我们不会从禁止点引入无效根。 
2. 将所得表达式展开为多项式方程$x$。 该结构变成三次方，因为原始分母是二次方并乘以$x$。 
3. 将所有项移至一侧以获得三次多项式。 此步骤将函数方程转换为标准的求根问题。 
4. 分解$x$，因为每个术语都包含它。 这立即表明$x = 0$是一个解决方案，前提是原始函数是在那里定义的。 
5. 求解剩余的二次方程$x^2 + 3Nx - 10N^2 = 0$使用判别法。 判别式简化为完美平方，确保干净的整数根。 
6. 计算两个根为$2N$和$-5N$。 
7.输出三个值$0$,$2N$， 和$-5N$。 

### 为什么它有效

 该变换在分母非零的域上保留了原始有理方程和导出的多项式方程之间的等价性。 原方程的每个有效解都必须满足多项式，并且任何不取消分母的多项式的根都对应于有效解。 因为我们明确地检查了根的结构并且没有一个与分母零重合$N \neq 0$，解集是精确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

N = int(input().strip())

res = [0, 2 * N, -5 * N]

# remove duplicates just in case (though none occur for N != 0)
res = list(set(res))

print(len(res))
print(*res)
```该实现直接对封闭式推导进行编码。 唯一的计算是形成三个候选根。 集合被用作安全措施，尽管从代数角度来看，这三个值对于所有非零值都是不同的$N$。 

必须注意不要尝试直接数值求解有理方程，因为浮点方法是不必要的，并且即使约束很小也存在精度问题的风险。

 ## 边缘情况

 对于$N = 1$，方程变得特别清晰，有助于验证导出的公式不依赖于较大值的意外取消。 替代$N = 1$生根$0, 2, -5$。 分母是$x^2 + 3x - 5$，这三个点都不为零，因此没有根无效。 

为了$N = -1$，我们得到根$0, -2, 5$。 一个常见的错误是忘记两者$2N$和$-5N$一致地翻转符号，但结构保持对称。 分母检查仍然是安全的，因为用任何一个值替换非零值都不会产生零$N$。 

对于任何$N$, 根$x = 0$尤为重要。 它之所以存在只是因为原始有理表​​达式的分子与$x$，分母计算为$-5N^2$，它始终不为零。 这保证了删除$x$简化过程中的因子不会丢弃有效的解决方案，只要我们在分解后明确地重新引入它。
