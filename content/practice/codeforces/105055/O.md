 ## 解决方案
 ## 问题理解

 情况是一次简单的公路旅行，但方向错误。 有两个距离是相关的：第一个是旅行者走错方向后走了多远，第二个是沿着正确的路线从起点到目的地的剩余距离。 

意识到错误后，他们通过掉头有效地取消了部分旅程，然后继续沿着正确的道路前进。 他们实际行驶的总距离是错误方向的路段和到达目的地的正确路线的总和。 

因此，任务简化为计算结合绕行路线和最终正确行程时总共行驶了多少公里。 

输入提供两个整数 A 和 B。A 是掉头之前沿错误方向行驶的距离。 B是从起点到终点的正确距离。 输出是行驶的总距离，包括错误路径和正确路线。 

约束很小，每个值最大为 10^6。 这立即排除了对高级数据结构或优化的任何需要。 常数时间算术表达式就足够了。 

不存在涉及排序、奇偶性或结构的微妙边缘情况。 唯一有意义的边缘情况是 A 或 B 等于 1 时，但即使如此，计算仍然是直接算术和。 关键是要明白，错误方向的路段并没有被取消，它在物理上行驶了两次：一次错误地前进，一次返回正确的路径。 

## 方法

 暴力解释将逐步模拟整个旅程。 人们可以想象，朝错误的方向前进 A 公里，然后回到起点 A 公里，最后到达目的地 B 公里。 这会产生 A + A + B 的总行进距离。虽然这在概念上是有效的，但它引入了不必要的模拟。 

问题的结构使得模拟变得多余。 转弯时，错误方向的行进会完全镜像，这意味着绕行的长度对最终距离的贡献是其长度的两倍。 然后添加一次正确的路径。 这将过程压缩为直接公式，无需任何迭代。 

关键的观察结果是，旅程由三个线性段组成，其长度完全由输入值决定。 需要模拟或状态跟踪的步骤之间不存在依赖性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(A + B) | O(1) | O(1) | 概念上太慢，没有必要 |
 | 直接公式 (2A + B) | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取代表错误方向行驶距离的整数A。 该段总共会遍历两次，一次向前，一次返回。 
2. 读取代表从起点到目的地的正确距离的整数B。 该段在行程结束时恰好遍历一次。 
3. 计算总距离为 2 × A + B。2 的因数考虑了错误方向导致的往返行程。 
4. 直接输出计算值。 

### 为什么它有效

 行进路径分解为三个不相交的路段：长度为 A 的初始前向错误、长度为 A 的返回以及长度为 B 的最终正确遍历。这些路段是独立且连续的，因此总距离是可加的。 不存在重叠或取消，因为距离衡量的是物理旅行，而不是净位移。 这保证了将线段长度相加得出准确的总距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = int(input().strip())
b = int(input().strip())

print(2 * a + b)
```该解决方案读取两个整数并直接应用派生表达式。 使用`strip()`即使存在尾随换行符，也能确保安全解析。 在单个表达式中，乘法在加法之前完成，避免了中间变量，但保持逻辑明确。 

唯一微妙的一点是认识到错误方向的旅行不会被丢弃，而是会被计算两次。 这直接编码在`2 * a`。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a = int(input().strip())
    b = int(input().strip())
    return str(2 * a + b)

# provided samples
assert run("4\n2\n") == "10", "sample 1"
assert run("5\n7\n") == "17", "sample 2"
assert run("2\n4\n") == "8", "sample 3"

# minimum values
assert run("1\n1\n") == "3", "min case"

# asymmetric small values
assert run("1\n10\n") == "12", "small A, large B"

# large values
assert run("1000000\n1000000\n") == "3000000", "max case"

 ## 边缘情况

 当两个距离均为 1 时，可能出现最小的输入。在这种情况下，旅行者走错 1 公里，返回 1 公里，然后正确前进 1 公里，总计 3。公式 2A + B 正确生成 3，证实即使是最小路径也能保留结构。 

当A较大而B较小时，例如A = 10^6且B = 1，绕行在结果中占主导地位。 计算仍然简化为单个表达式，并且 Python 中不会出现由于任意精度整数而导致的溢出问题。 

当 B 较大且 A 最小时，相对于最终路段，绕行变得可以忽略不计，但它的贡献值仍然是其值的两倍。 这证实了绕行与最终路线长度无关，并且加法分解在所有情况下仍然有效。
