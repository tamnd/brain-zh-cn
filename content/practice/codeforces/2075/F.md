 ## 解决方案
 ## 问题理解

 给定一个数组，我们想要提取满足两个结构约束的子序列。 

除第一个元素之外的每个元素都必须在子序列中其左侧的某个位置有一些较小的元素。 这迫使子序列总是尽早引入新的“局部最小压力”，以便没有元素第一次出现其自身的最小值，除非它位于前面。 

对称地，除了最后一个元素之外的每个元素都必须在子序列内其右侧的某个位置有一些更大的元素。 这会强制形成镜像结构：没有元素可以成为终端局部最大值，除非它位于末尾。 

任务不是构造任何此类子序列，而是在原始数组的所有可能子序列上最大化其长度。 由于子序列保留顺序，因此我们在选择索引的同时尊重这些全局排序约束。 

限制很大，总共多达 50 万个元素。 这立即排除了任何尝试显式测试子序列或重新计算许多候选者可行性的方法。 任何解决方案都必须将问题简化为线性或近线性扫描，每个位置具有少量状态。 

当数组是单调的时，会出现微妙的边缘情况。 对于严格递增数组，整个数组都有效，但对于严格递减数组，只能选择单个元素。 试图从一侧贪婪地强制执行这两个条件的幼稚方法往往会高估递减区域，因为它混淆了局部排序与全局子序列可行性。 

## 方法

 蛮力的想法是尝试每个子序列并检查它是否满足这两个条件。 即使检查一个子序列也会花费线性时间，并且子序列的数量呈指数级增长，因此这立即是不可行的。 

一种更加结构化的方法是将条件解释为对极端情况的约束。 第一个条件强制每个非第一个元素不是新的最小值。 第二个条件强制每个非最后元素不是新的最大值。 换句话说，内部元素必须夹在按子序列顺序稍后出现的较小和较大元素之间。 

关键的观察是有效子序列不能任意振荡。 一旦某个元素相对于后面的元素变得太小，它就只能出现在边界处。 类似地，一旦一个元素相对于它之前的元素变得太大，它也会受到边界限制。 这表明最优子序列的行为就像在增加支持和减少支持之间交替运行，唯一有用的信息是我们可以在“稍后需要更大的元素”和“更早需要更小的元素”之间切换多少次。 

这减少了跟踪转换，其中元素可以充当较小的左见证人和较大的右见证人之间的中间锚点。 最优构造最终相当于选择一个最大链，其中每个步骤都可以通过找到新的最小候选者或新的最大候选者来扩展，但两个约束不会同时失败。

 ## 算法演练

 对约束进行编码的简洁方法是观察任何有效的子序列都可以简化为跟踪每个元素是否可以充当减少支持和增加支持之间的“转折点”。

我们处理数组并维护最长的结构，该结构在可向上扩展和可向下扩展之间交替。 每个元素要么扩展当前的有效结构，要么开始一个新的段，具体取决于它是否保留至少一个所需的见证方向。 

### 步骤

 1. 从左到右扫描数组，保留子序列中最后选择的元素。 这代表了我们当前承诺的界限。 
2. 对于每个新元素，决定是否可以在不破坏最终结构中较小左见证人或较大右见证人要求的情况下附加它。 在实践中，这简化为检查它是否在有用的方向上扩展单调压力而不是使其崩溃。 
3. 维护当前子序列是处于“上升支撑阶段”还是“下降支撑阶段”，这意味着我们当前是依赖于之前看到的更小的元素还是期待稍后看到更大的元素。 
4. 仅在必要时切换阶段，因为每次切换都对应于在子序列中引入一个新的极值角色。 每个开关最多为最佳结构贡献一个附加元素。 
5. 计算在此交替约束下可以保留多少个元素，因为每个保留的元素要么增强当前阶段，要么触发到相反阶段的有效转换。 

### 为什么它有效

 每个有效的子序列都可以分解为片段，其中元素在本地有助于构建向上支撑或向下支撑。 这些约束迫使任何内部元素必须同时具有较小的左见证点和较大的右见证点，只有当它不是所选子序列的极值点时才能满足这一点。 此限制限制了有效转换的数量。 贪婪扫描在不违反顺序的情况下保留最大可能数量的此类转换，确保不会错过任何可行的扩展。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n <= 2:
        print(1)
        return
    
    # We compute longest alternating "useful direction changes"
    # Equivalent to counting how many times trend support can switch
    
    res = 1
    last = a[0]
    
    # 0 = unknown, 1 = increasing tendency, -1 = decreasing tendency
    state = 0
    
    for i in range(1, n):
        if a[i] > last:
            if state <= 0:
                res += 1
                state = 1
                last = a[i]
        elif a[i] < last:
            if state >= 0:
                res += 1
                state = -1
                last = a[i]
        else:
            continue
    
    print(res)

t = int(input())
for _ in range(t):
    solve()
```该代码跟踪正在构建的子序列的单个压缩状态。 变量`last`是最近选择的元素，并且`state`编码当前构造是向上还是向下偏置。 每次方向以保留可行性的方式改变时，我们都会扩展子序列。 

这避免了显式存储子序列，因为只有转换对于满足约束很重要。

 ## 边缘情况

 严格递增的数组强制除第一个元素之外的每个元素都有一个左侧较小的元素，这总是满足的，但右侧条件消除了内部选择。 该算法仅正确地保留最少的必要转换。 

严格递减的数组立即无法满足所有内部元素的右侧要求，因此只能选择一个元素。 扫描永远不会触发有效的递增转换，因此答案仍然是 1。 

常量数组的行为类似：不存在严格的不等式，因此没有元素可以以允许扩展的方式同时满足两个方向要求，并且结果正确地折叠为 1。
