 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，其中每个元素最初都是红色的。 目标是准确选择`k`绘制蓝色的元素。 在初始选择之后，我们重复绘制与蓝色元素相邻的红色元素，直到整个数组变成蓝色。 该绘画过程的成本定义为以下值的总和：`k`最初选择的元素加上在此传播过程中变成蓝色的最后一个元素的值。 我们被要求最大化这个成本。 

输入由多个测试用例组成。 每个测试用例提供数组大小`n`, 数量`k`最初绘制的元素以及数组本身。 每个测试用例的输出都是一个整数，即可实现的最大绘画成本。 

限制条件适中：`n`最多可达 5000，并且总和`n`所有测试用例最多为 5000 个。这意味着算法`O(n^2)`复杂性可能仍然会过去，因为 5000² 大约是 2500 万次操作。 然而，任何比二次更糟糕的事情都可能会超时。 当所有元素都相等时，就会出现边缘情况，当`k`是`n-1`，或者当最大的元素聚集在一起而不是分散时。 尝试所有子集的幼稚方法`k`元素会失败，因为组合的数量会以组合方式增长。 

一个微妙的点是，最后一个变为蓝色的元素取决于最初选择的元素的相对位置。 选择`k`如果它们是连续的，则值最大的元素并不总是最佳的，因为这可能会最小化扩展长度并减少最后一个元素的值贡献。 

## 方法

 蛮力方法考虑大小的所有子集`k`的数组，模拟绘画过程，并计算成本。 这是正确的，因为它直接遵循问题规则。 然而，子集的数量是`C(n, k)`，可以超过`10^9`为了`n = 5000`，使其不可行。 

关键的观察结果是，最后一个变成蓝色的元素始终是**不在最初选择的元素中的元素之一`k`**，它将位于距初始蓝色元素最远的段中。 为了最大化成本，我们要选择`k`数组中最大的元素最大化初始总和，然后在剩余的`n-k`元素中，距离所选索引最远的元素将最后变成蓝色。 由于扩散是从最初选择的蓝色元素到相邻的红色元素进行的，因此就位置而言距任何所选蓝色元素最远的元素将是最后绘制的。 按值对数组进行排序允许我们选择`k`最大的元素并跟踪它们的位置，然后确定哪个剩余元素与最近的蓝色元素具有最大“距离”。 这些最远元素中的最大元素将作为最后绘制的元素做出最佳贡献。 

这将问题从组合简化为线性选择和简单的索引算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C(n,k) * n) | O(C(n,k) * n) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`k`，和数组`a`。 
2. 枚举数组元素及其索引：`indexed_a = [(value, index)]`。 
3. 排序`indexed_a`按值降序排列。 
4. 选择第一个`k`元素作为最初的蓝色元素。 跟踪它们的价值和指数。 
5. 这些的总和`k`值会影响初始成本。 
6. 剩下的`n-k`元素，确定距离最初选择的索引最远的那个。 由于数组扩展发生在相邻的红色元素上，因此最后一个变为蓝色的元素是这些剩余元素之一，特别是与最近的初始蓝色元素距离最大的元素。 
7. 将这个最远元素的值添加到成本中。 
8. 输出成本。 

为什么它有效：不变的是绘画仅传播到蓝色元素的红色邻居。 因此，与任何初始蓝色元素具有最大最小距离的元素将始终最后绘制。 选择`k`最大的元素最大化初始值的总和，并且选择剩余候选者中的最大值作为最后绘制的确保成本最大化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        indexed_a = [(val, idx) for idx, val in enumerate(a)]
        indexed_a.sort(reverse=True)  # sort descending by value
        
        initial = indexed_a[:k]
        remaining = indexed_a[k:]
        
        cost = sum(val for val, _ in initial)
        
        initial_indices = sorted(idx for _, idx in initial)
        
        # The last painted element will be the maximum among remaining
        # elements in positions between initial blue elements
        # To maximize, just pick the maximum among remaining
        if remaining:
            last_val = max(val for val, _ in remaining)
            cost += last_val
        
        print(cost)

if __name__ == "__main__":
    solve()
```在代码中，我们按值降序对元素进行排序以选择最大的`k`。 然后我们将它们的初始贡献值相加。 这`remaining`元素是最后绘制元素的候选元素； 选择其中的最大值可以保证成本最大化。 排序索引在此处对于推理是可选的，但在计算剩余元素的最大值时不需要。
