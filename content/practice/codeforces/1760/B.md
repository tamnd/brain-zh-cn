 ## 解决方案
 ## 问题理解

 我们得到了几个小写字符串。 对于每个字符串，我们需要包含该字符串中出现的每个字符的最小字母表。 

字母表始终是英文字母表的前缀。 大小为 1 的字母表仅包含`a`，大小为 2 的字母表包含`a`和`b`， 等等。 大小为 26 的字母表包含每个小写字母。 

问题很简单：仍然包含字符串中使用的所有字符的字母表的最小前缀是什么？ 

思考这个问题的一个有用方法是关注当前最大的字母。 如果一个字符串包含字母`w`，那么任何有效的字母表必须包含来自`a`通过`w`。 自从`w`是第 23 个字母，则答案必须至少为 23。如果所有其他字母都早于`w`，那么大小为 23 的字母表就足够了。 

限制很小。 每个字符串的长度最多为 100，并且最多有 1000 个测试用例。 甚至一个$O(n^2)$解决方案在这里就完全没问题了。 我们只需要扫描每个字符串一次。 

一个容易犯的错误是计算不同的字符而不是找到最大的字符。 

考虑：```
1
3
bcf
```不同的字母是`{b,c,f}`，其大小为 3。粗心的解决方案将输出 3。正确答案是 6，因为`f`是第 6 个字母，并且任何包含以下字母的字母表`f`还必须包含`a`通过`e`。 

另一个错误是使用字符串长度。 

考虑：```
1
5
zzzzz
```字符串长度是 5，但答案是 26，因为`z`是第26个字母。 

第三个错误是对字符进行排序并使用唯一字母的数量。 

考虑：```
1
4
down
```有四个不同的字母，但最大的是`w`，所以答案是 23。 

## 方法

 暴力方法会尝试从 1 到 26 的每个字母大小。对于每个大小，我们将检查字符串的每个字符是否属于该字母。 第一个有效尺寸就是答案。 

这是可行的，因为只有 26 种可能的字母大小。 对于一个长度的字符串$n$，复杂度为$O(26n)$。 

关键的观察结果是答案完全由字符串中最大的字符决定。 如果最大的字符是`k`，那么每个较小的字符都会自动包含在大小对应的字母表中`k`。 任何较小的字母都会错过`k`本身。 

这将问题简化为查找最大字符并将其转换为字母表中的位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(26n) | O(26n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`和字符串`s`。 
3. 找出最大的字符`s`。 
4. 使用以下命令将该字符转换为其字母位置：`ord(max_char) - ord('a') + 1`5. 输出结果值。 

这样做的原因是字母表的大小`x`完全包含来自的字母`a`通过`x`第-个字母。 字符串中出现的最大字符是唯一确定此前缀必须延伸多远的字符。 

### 为什么它有效

 让`c`是字符串中出现的最大字符。 

任何有效的字母表必须包含`c`，所以它的大小必须至少是字母位置`c`。 

大小等于位置的字母表`c`包含来自的每一个字母`a`通过`c`。 由于字符串中没有字符大于`c`，所有字符都包含在内。 

最小有效字母大小恰好是最大字符的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    s = input().strip()

    ans = ord(max(s)) - ord('a') + 1
    print(ans)
```实现直接遵循算法的观察结果。 

致电给`max(s)`查找字符串中按字典顺序最大的小写字母。 由于小写字母在 ASCII 表中按字母顺序出现，因此最大的字符也是按字母顺序排列的最新字符。 

表达式```
ord(max(s)) - ord('a') + 1
```将该字符转换为从 1 开始的字母表索引。 例如：```
ord('a') - ord('a') + 1 = 1
ord('f') - ord('a') + 1 = 6
ord('z') - ord('a') + 1 = 26
```不存在溢出问题，因为所有值都很小。 唯一微妙的一点是删除尾随换行符`.strip()`在处理字符串之前。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        s = input().strip()
        out.append(str(ord(max(s)) - ord('a') + 1))

    return "\n".join(out)

# provided sample
assert run(
    "5\n"
    "1\n"
    "a\n"
    "4\n"
    "down\n"
    "10\n"
    "codeforces\n"
    "3\n"
    "bcf\n"
    "5\n"
    "zzzzz\n"
) == "1\n23\n19\n6\n26"

# minimum size
assert run("1\n1\na\n") == "1"

# largest possible letter
assert run("1\n1\nz\n") == "26"

# all characters identical
assert run("1\n5\nmmmmm\n") == "13"

# mixed letters

```每个角色都是`z`。 最大字符数仍为`z`，其位置为26。算法输出26。重复出现不影响结果。
