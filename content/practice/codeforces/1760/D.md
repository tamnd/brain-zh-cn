 ## 解决方案
 ## 问题理解

 给定一个整数数组，需要根据精确的定义来确定它是否形成“谷”。 从概念上讲，山谷是一个平坦的子阵列，其高度低于其两侧的邻居。 形式上，必须恰好存在一个由相等元素组成的连续段，这样，如果该段不在边界处，则其左邻居严格更大，并且其右邻居也严格更大。 如果平坦段位于边界处，则只有存在的邻居必须满足此条件。 如果恰好存在一个这样的谷段，则输出为“是”，否则输出为“否”。 

这些约束允许长度最多为 200,000 的数组和最多 10,000 个测试用例，但跨测试用例的所有数组长度总和不超过 200,000。 这意味着我们必须在相对于其大小的线性时间内处理每个数组。 任何显式检查每个可能的子数组的方法都是二次的，而且速度太慢。 仔细的线性扫描就足够了。 

容易错误处理的边缘情况包括长度为 1 的数组、所有元素都相等的数组或具有多个平坦段（单独看起来像山谷）的数组。 例如，`[1, 1, 1]`是一个山谷，因为左边界开始平坦部分，并且其左侧没有更小的邻居，但是`[2, 1, 1, 1, 2]`中间有一个清晰的山谷，应该返回“YES”。 数组就像`[1, 2, 1, 2, 1]`有多个潜在的最小点，因此输出应该为“NO”。 错误计算平坦区域或未能验证边界条件是常见的错误来源。 

## 方法

 蛮力方法将检查每个可能的长度至少为 1 的子数组，看看它是否满足山谷性质。 对于每个子数组，我们将验证所有元素是否相等，并检查邻居是否存在。 这是正确的，但是每个数组的长度`n`可能有 O(n^2) 个子数组，这对于`n = 2*10^5`。 

关键的见解是，只有阵列的最小元素才能形成有效的山谷，因为任何山谷都必须低于其周围环境。 我们可以先找到数组中的最小值，然后查看该值的连续段。 对于每个连续的最小元素段，我们检查边界条件：段之前的元素（如果存在）必须严格大于，段之后的元素（如果存在）必须严格大于。 如果恰好有一个这样的线段满足这一点，则该阵列是一个谷； 否则，就不是。 通过关注最小元素和线性扫描，我们将数组大小的复杂性从二次降低到线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于当前数组，求最小值。 这是山谷的唯一候选者，因为任何山谷都必须低于其邻居。 
2. 初始化有效谷段数量的计数器。 
3. 从左到右迭代数组。 每当遇到最小值时，请识别相等最小值的连续段。 
4. 对于该段，检查边界元素。 如果该段从数组的开头开始，则仅检查右邻居。 如果它以最后一个索引结束，则仅检查左邻居。 否则，验证左邻居大于最小值并且右邻居也大于最小值。 
5. 如果该段满足边界条件，则增加谷值计数器。 
6. 继续扫描阵列到下一个最小段，直至结束。 
7. 最后，如果正好有一个段通过了边界检查，则打印“YES”。 否则，打印“NO”。 

为什么有效：最小值观察确保我们只考虑潜在的山谷，而边界检查确保我们恰好满足山谷的定义一次。 线性扫描保证我们检查所有连续的最小段，而不会丢失重叠或部分检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_valley(a):
    n = len(a)
    min_val = min(a)
    i = 0
    valley_count = 0
    
    while i < n:
        if a[i] == min_val:
            start = i
            while i + 1 < n and a[i + 1] == min_val:
                i += 1
            end = i
            left_ok = start == 0 or a[start - 1] > min_val
            right_ok = end == n - 1 or a[end + 1] > min_val
            if left_ok and right_ok:
                valley_count += 1
            i += 1
        else:
            i += 1
    return valley_count == 1

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print("YES" if is_valley(a) else "NO")
```功能`is_valley`扫描数组一次。 内部 while 循环对连续的最小值进行分组，并显式检查边界条件。 递增`i`小心避免跳过段或重复计数。
