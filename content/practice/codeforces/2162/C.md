 ## 问题理解

 我们有两个整数`a`和`b`。 我们可以重复选择一个整数`x`这样`0 ≤ x ≤ a`（当前值`a`）并替换`a`和`a XOR x`。 我们的目标是生成最多 100 个此类操作的序列，这些操作可以转换`a`准确地进入`b`，或判定不可能。 

输入由多个测试用例组成，每个测试用例指定一对`(a, b)`。 输出应该列出一系列选择的`x`值或`-1`如果没有序列可以达到目标。 约束条件适中：两者`a`和`b`最多可以达到 10^9，并且我们最多可以有 1000 个测试用例。 每个操作都会独立影响位，因为 XOR 是按位运算的。 这暗示我们也许能够贪婪地构造一个解决方案，而不是模拟每一个可能的解决方案`x`。 

当出现不明显的边缘情况时`a`小于`b`并且没有单一的`x`满意的`0 ≤ x ≤ a`可以翻转必要的位来达到`b`。 例如，`a = 3`和`b = 5`。 总是尝试的天真方法`x = a`首先会失败，因为 XOR 只能减少或重新排列`a`无需创建新的更高位`a`本身。 

另一个边缘情况是当`a = b`。 在这里，简单的答案是零操作。 最后，如果`b = 0`, 单次操作`x = a`就够了，减少`a`立即归零。 

## 方法

 蛮力方法会尝试一切可能的方法`x`在每一步并递归检查是否`b`可以到达。 这是正确的，因为 XOR 运算是可逆的，并且我们可以测试所有序列。 然而，可能的数量`x`值高达`a+1`每一步，以及`a`可以是 10^9。 即使进行修剪，这种方法也很棘手。 

关键的观察结果是，异或运算在两个元素的域上是线性的。 这意味着每一位`a`通过选择合适的可以独立翻转`x`。 具体来说，对于任何不同的位`a`和`b`，如果我们选择`x`恰好设置了这些位（并且小于或等于`a`），我们可以一步翻转它们。 在实践中，对于大多数输入，我们最多可以通过两步来实现转换：

 - 如果`a = b`，什么也不做。 
- 否则，计算`c = a XOR b`。 这是我们需要翻转的一组位。 
- 如果`c ≤ a`， 然后`x = c`在一次操作中翻转所需的位。 
- 否则，将翻转分为两步：首先翻转最高位`a`然后使用剩余的部分。 

这给出了一个简单的构造算法，除非不可能，否则总是最多使用两个操作。 不可能的情况发生时`a = 0`和`b ≠ 0`，因为 XOR 只能减少或重新排列零位，而不能创建新的零位。

 ## 算法演练

 1. 读取整数`a`和`b`。 如果`a = b`，立即返回零操作，因为不需要任何更改。 
2. 计算`c = a XOR b`。 这代表需要更改才能转动的位`a`进入`b`。 
3.如果`c ≤ a`， 选择`x = c`并执行单个操作：`a := a XOR x`。 这会转`a`进入`b`直接地。 
4. 如果`c > a`，直接单步异或是不可能的，因为`x`不得超过`a`。 在这种情况下，我们可以将操作分为两步。 首先，选择`x1`作为最高位`a`（或任何部分`a`）减少`a`这样剩余的所需翻转`c`现在小于或等于更新的`a`。 然后，选择`x2 = a XOR b`来完成转变。 
5.如果`a = 0`和`b ≠ 0`， 输出`-1`，因为没有有效的`x`可以创建零位。 

工作原理：XOR 运算是其自身的逆运算，并且独立作用于每个位。 通过计算`a XOR b`，我们确切地知道哪些位必须改变。 这些位要么可以在一个操作中全部设置，要么我们可以将它们分成最多两个操作，同时尊重`x ≤ a`约束。 不变的是，在每次操作之后，我们应用的所有翻转都对应于`c`，保证我们永远不会超出目标。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        if a == b:
            print(0)
            continue
        if a > b:
            # Try one-step solution
            x = a ^ b
            if x <= a:
                print(1)
                print(x)
            else:
                # Two-step solution
                x1 = 1
                while x1 <= a:
                    x1 <<= 1
                x1 >>= 1
                a1 = a ^ x1
                x2 = a1 ^ b
                print(2)
                print(x1, x2)
        else:
            # a < b
            print(-1)

if __name__ == "__main__":
    solve()
```该解决方案首先处理以下简单情况`a = b`零操作。 如果`a > b`，它尝试使用单步异或`x = a XOR b`。 如果超过`a`，它通过翻转最大位将操作分为两步`a`首先，然后完成剩余的异或。 什么时候`a < b`，这是不可能的，因为 XOR 无法创建比现有位更高的新位`a`。 while循环找到最高位`a`高效。
