 ## 解决方案
 ## 问题理解

 分数不是以单个分子和分母形式给出的。 相反，我们收到两个数组。 

第一个数组中所有数字的乘积是分子，第二个数组中所有数字的乘积是分母。 

我们的任务是在完全归约后输出两个代表相同分数的新数组。 换句话说，如果$$N=\prod a_i,\qquad D=\prod b_i$$那么我们必须将两者分开$N$和$D$通过它们的最大公约数，并再次将所得分子和分母表示为不超过的整数数组$10^7$。 

第一个挑战是产品本身非常庞大。 甚至几十个接近的值$10^7$已经超出了正常的整数范围，这里我们可能有最多$10^5$数字。 建设中$N$和$D$直接是不可能的。 

这些约束强烈建议采用素因子方法。 每个个体的值最多为$10^7$，可以使用最小素因子筛对其进行有效分解。 由于有多达$2 \cdot 10^5$总数，任何涉及所有分子和分母元素之间的成对 gcd 计算的算法都将过于昂贵。 

一个微妙的点是输出仍然必须表示为不大于的整数数组$10^7$。 约简后，剩余的质因数必须重新分配为满足该界限的数字。 

考虑以下示例：```
1 1
12
18
```分数是$12/18$。 最大公约数是$6$，所以减少的分数是$2/3$。 

粗心的解决方案会贪婪地取消数组元素之间的因子，但不会完全删除所有公共素因子，可能会错误地留下$4/6$，没有减少。 

另一个重要的情况是当一切都取消时：```
1 1
100
100
```减少的分数是$1/1$。 

输出数组不能为空。 删除所有因素并打印零数字的解决方案将违反格式。 我们必须输出至少一个值，即`1`。 

另一个棘手的例子：```
2 1
8 9
6
```分子等于$72$，分母等于$6$，所以减少的分数是$12/1$。 

主要因素$2$从分母开始仅取消分子分解的一部分。 任何只比较整数而不是质数指数的方法都可能很容易错过这种部分取消。 

## 方法

 最直接的想法是重建分子和分母乘积，计算它们的 gcd，将两者除以它，然后以某种方式重建数组。 

这在数学上是正确的，但完全不可行。 该产品包含多达$10^5$因素，每个都大到$10^7$。 得到的整数将有数十万位数字。 

一个稍微复杂的蛮力想法是重复计算分子元素和分母元素之间的 gcd。 对于每对$(a_i,b_j)$，除掉它们的公因数。 

这最终会产生一个约化分数，因为每个公素因子都必须出现在某个对内。 不幸的是，最多有$10^5$两边的数字，导致$10^{10}$最坏情况下成对。 

关键的观察是减少仅取决于素数指数。 

如果一个素数$p$出现$x$分子中的时间和$y$乘以分母，然后减少后：$$p^{x-\min(x,y)}$$保留在分子中并且$$p^{y-\min(x,y)}$$仍保留在分母中。 

因此，我们可以将每个输入值因式分解并计算两边每个质数的总指数，而不是取消各个数字之间的因子。 

知道所有计数后，我们减去每个素数的共同数量。 剩下的正是减少的分子和分母的质因数分解。 

最后一步是重建数组。 我们收集剩余的质因数并将它们贪婪地相乘，每当下一个乘法超过时就开始一个新的输出数$10^7$。 因为每个质因数本身至多是$10^7$，这总是成功的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对取消| O(nm log A) | O(1) | O(1) | 太慢了 |
 | 最优素因子计数 | O(A 对数 A + K) | O(A) | 已接受 |

 这里$A=10^7$， 和$K$是所有输入数字的质因数总数。 

## 算法演练

 1. 为所有数字建立一个最小质因数筛$10^7$。 
2. 使用筛子对每个分子值进行因式分解，并在映射中累积素数指数`cntA`。 
3. 使用筛子对每个分母值进行因式分解，并在图中累积素数指数`cntB`。 
4. 对于任一图中出现的每个素数，计算$$c=\min(cntA[p],cntB[p]).$$减去`c`从这两个方面来看。 

这正好删除了对 gcd 贡献的指数。 
5. 重建简化分子。 

对于每一个素数$p$, 附加$p$确切地`cntA[p]`次进入剩余素因子流。 

将因子乘以当前输出数，同时乘积不超过$10^7$。 否则，完成当前数字并开始新的数字。 
6. 使用相同的过程和剩余指数重建约化分母`cntB`。 
7. 如果任一重建数组为空，则将其替换为`[1]`。 
8. 输出两个数组的大小，然后输出数组本身。 

### 为什么它有效

 整数的分解是唯一的。 每个素数对分子和分母都有独立的贡献。 

对于每个素数$p$，gcd 正好去除$$p^{\min(cntA[p],cntB[p])}.$$减去这些指数后，剩下的指数正是约简分数的指数。 不存在公质因数，因为每个质数至少一侧的指数为零。 

重建阶段仅将剩余的质因数分组为不超过$10^7$。 它不会改变质因数的多重集，因此所表示的分子和分母与约化分数保持相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 10 ** 7

def build_spf(n):
    spf = list(range(n + 1))
    spf[0] = spf[1] = 0

    limit = int(n ** 0.5)
    for i in range(2, limit + 1):
        if spf[i] == i:
            step = i
            start = i * i
            for j in range(start, n + 1, step):
                if spf[j] == j:
                    spf[j] = i
    return spf

def factorize(x, spf, cnt):
    while x > 1:
        p = spf[x]
        c = 0
        while x % p == 0:
            x //= p
            c += 1
        cnt[p] = cnt.get(p, 0) + c

def rebuild(cnt):
    res = []
    cur = 1

    for p in sorted(cnt):
        e = cnt[p]
        for _ in range(e):
            if cur * p <= MAXV:
                cur *= p
            else:
                res.append(cur)
                cur = p

    if cur > 1:
        res.append(cur)

    if not res:
        res = [1]

    return res

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    mx = max(max(a), max(b))
    spf = build_spf(mx)

    cntA = {}
    cntB = {}

    for x in a:
        factorize(x, spf, cntA)

    for x in b:
        factorize(x, spf, cntB)

    primes = set(cntA) | set(cntB)

    for p in primes:
        common = min(cntA.get(p, 0), cntB.get(p, 0))
        if common:
            cntA[p] = cntA.get(p, 0) - common
            cntB[p] = cntB.get(p, 0) - common

    num = rebuild(cntA)
    den = rebuild(cntB)

    print(len(num), len(den))
    print(*num)
    print(*den)

if __name__ == "__main__":
    solve()
```筛子存储每个整数的最小素因数。 然后因式分解变得非常快，因为每次除法都会删除至少一个素因数。 

地图`cntA`和`cntB`存储总指数，而不是每个数字的信息。 这正是分数归约所需要的。 

在重建过程中，我们保留所有剩余的素因子。 贪婪打包是安全的，因为每个素因子最多$10^7$。 如果乘法超出限制，我们只需开始一个新的输出数字。 

当所有因素都取消时，对空数组的特殊处理是必要的。 输出格式要求每一侧至少有一个数字。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(M 对数 M + K) | 筛子构造加上全分解工作|
 | 空间| O(M)| 最小素因子数组 |

 这里$M$是输入中出现的最大值，最多$10^7$， 和$K$是提取的质因数的总数。 

主要成本是构建最小素因子筛。 这种方法是针对原始约束的预期解决方案，并且非常适合优化实现的限制。

 ## 边缘情况

 考虑：```
1 1
100
100
```双方的因子计数相同：$$2^2 \cdot 5^2$$所有指数都取消，不留下素因数。 重建过程产生空列表，其被替换为`[1]`。 输出变为：```
1 1
1
1
```它正确地代表了约简分数。 

现在考虑：```
2 1
8 9
6
```分子包含$2^3 \cdot 3^2$，而分母包含$2 \cdot 3$。 减去共同指数后，剩下的因式分解为$2^2 \cdot 3$。 该算法重构`12`，生产`12/1`。 

最后：```
1 1
9999991
9999991
```该值为一个大素数。 因式分解图在两侧都包含该素数的一次出现。 取消将其完全删除，留下`1/1`。 这证实了该算法处理大素数就像处理合数一样容易，因为一切都是通过素数指数处理的。
