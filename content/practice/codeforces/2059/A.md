 ## 解决方案
 ## 问题理解

 我们有两个数组，`a`和`b`，长度`n`，其中每个数组都是“好”的 - 意味着数组中的每个值至少出现两次。 米莉亚可以重新排列`a`以任何顺序，然后她将计算一个新数组`c`其中每个元素是相应元素的总和`a`和`b`。 任务是确定是否可以重新排列`a`这样`c`包含至少三个不同的数字。 

限制是适度的：`n`范围从 3 到 50，每个元素可以大到$10^9$。 小的`n`允许我们考虑最坏情况下的二次解`n`。 测试用例的数量最多为 1000 个，因此任何解决方案都应有效地总共处理最多 50,000 个元素。 

当两个数组仅包含两个重复多次的唯一值时，就会出现微妙的边缘情况。 例如，如果`a = [1,1,2,2]`和`b = [3,3,4,4]`，无论我们如何重新排列`a`，如果总和发生冲突，所得总和可能只会产生两个不同的值。 另一个边缘情况是所有元素都相同，例如`a = [1,1,1]`和`b = [1,1,1]`，仅产生一个值`c`。 

## 方法

 天真的方法是尝试每一种排列`a`并计算`c`，然后计算不同值。 这是正确但不切实际的：`n`最多可以有50个，所以有50个！ 排列，这是一个天文数字。 

关键的见解来自于我们不需要探索所有排列的理解。 由于每个数组都很好，因此我们有重复的元素，并且我们想检查是否可以产生三个不同的和。 考虑总和数组`c`以非降序对两个数组进行排序后。 极值和是通过将最大值配对获得的`a`最大的`b`和最小的`a`与最小的`b`。 类似地，配对最大的`a`与最小的`b`产生相反的极端。 如果这三个和不完全相同，我们已经可以保证至少有三个不同的和。 

在实践中，这将问题简化为检查总和是否`min(a)+min(b)`,`max(a)+max(b)`， 和`min(a)+max(b)`（或者`max(a)+min(b)`) 并不都相等。 由于排序，这在 O(n log n) 中是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 | O(n!) | O(n) | 太慢了|
 | 排序+检查极端| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和数组`a`和`b`。 
3. 对两者进行排序`a`和`b`按非递减顺序。 排序确保我们可以轻松计算极值和并检测可能的冲突。 
4. 计算三个候选和：最小的和`c1 = a[0] + b[0]`, 最大总和`c2 = a[-1] + b[-1]`，以及混合极端之一`c3 = a[0] + b[-1]`。 
5. 创建一组这些和。 该集会自动删除重复值。 
6. 如果集合的大小至少为三，则打印`YES`; 否则，打印`NO`。 

为什么有效：排序可以清楚地显示来自的最小和最大贡献`a`和`b`。 由于数组很好，因此我们总是有重复项，这可以防止意外崩溃为更少的不同总和。 通过检查极端值，我们捕获了确定是否可以实现三个不同总和所需的所有可能变化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    a.sort()
    b.sort()
    
    sums = {a[0]+b[0], a[-1]+b[-1], a[0]+b[-1]}
    
    if len(sums) >= 3:
        print("YES")
    else:
        print("NO")
```该解决方案使用有效地读取输入`sys.stdin.readline`。 对两个数组进行排序可确保我们可以直接选择极端组合来检查不同的总和。 使用集合可以自动处理重复的和。 该解决方案依赖于良好的数组和极限和的结构，避免了不必要的排列。

 ## 边缘情况

 当所有元素都相同时，例如`a = [1,1,1]`和`b = [1,1,1]`，算法计算`c1 = c2 = c3 = 2`。 和集的大小为 1，因此输出为`NO`。 什么时候`a`和`b`每个包含两个重复值，算法考虑极值和`a[0]+b[0]`,`a[-1]+b[-1]`,`a[0]+b[-1]`，如果可能的话，这足以检测三个不同的和。 为了`a = [1,2,1,2]`和`b = [1,2,1,2]`，总和为 2, 4, 3，给出三个不同的值。 这证实了算法可以正确处理所识别的微妙场景。
