 ## 解决方案
 ## 问题理解

 给定一个二进制网格，我们可以将单元格从 0 翻转到 1 或从 1 翻转到 0。目标是变换网格，以便每个边长为偶数的方形子矩阵包含奇数个 1。 

该条件看起来是全局的，因为它适用于每个均匀大小的正方形，但关键的观察结果是这些约束强烈限制了值在网格中的变化方式。 我们不会被要求检查单个配置的属性，而是要找到使所有这些约束同时成立所需的最小翻转次数，或者确定没有配置可以满足它们。 

网格总共最多可以有一百万个单元格，因此任何尝试枚举所有子方格或显式检查每个约束的方法都会立即失败。 即使在最坏的情况下迭代所有正方形也已经是三次方，甚至考虑所有 O(n^2 m^2) 子矩阵也是完全不可能的。 

更微妙的困难是约束严重重叠。 一个单元格参与许多偶数方格，一种天真的贪婪翻转策略可以修复一个方格，同时破坏许多其他方格。 在这种结构中，局部修复不能干净地组合起来。 

一个小例子说明了为什么局部推理是危险的。 考虑一个 2×2 网格：```
1 0
0 1
```这已经满足条件了，因为唯一的偶数正方形是整个网格，并且它包含两个偶数，所以它实际上违反了规则。 翻转单个单元格可以修复它，但根据我们翻转的单元格，效果在更大的网格中传播不同。 这表明我们不能独立地对待正方形。 

正确的解决方案来自于识别网格中隐藏的对称类，而不是处理单个正方形。 

## 方法

 一个蛮力的想法是尝试所有可能的最终网格并计算每个网格需要多少次翻转，然后检查它是否满足条件。 这在原则上是正确的，因为每个有效的配置都可以被测试，但是网格的数量是 2^(nm)，这远远超出了任何计算限制，即使对于微小的实例也是如此。 

更结构化的强力方法是枚举所有偶数平方并逐步强制约束，但每次放置都会影响许多重叠的子矩阵，并且在每次更改后检查有效性在最坏的情况下仍然会导致至少 O(n^2 m^2) 工作。 在 nm ≤ 10^6 约束下，这会立即失败。 

关键的见解是，尽管该条件讨论了所有大小的所有偶数正方形，但它实际上完全由最小的偶数正方形（即 2×2 块）决定。 一旦每个 2×2 子矩阵满足具有奇数个 1 的条件，所有较大的偶数平方也自动满足它。 这将无限的约束族分解为局部约束。 

现在问题变成：将值分配给网格，以便每个 2×2 块都具有奇校验，同时最小化原始网格的翻转成本。 

结构上的突破在于，每个单元都属于基于 (i mod 2, j mod 2) 的四个奇偶校验类别之一。 任何 2×2 块都包含每个类别中的一个单元格。 这意味着每个约束都只涉及每个类别的一个代表，因此整个网格简化为为每个类别选择一个值，然后评估一致性和成本。 

我们尝试对这四个类值进行所有分配，但只有完整 2×2 块的奇偶校验为奇数的分配才有效。 这给出了要评估的恒定数量的配置，并且对于每个配置，我们计算整个网格的不匹配成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解网格 | O(2^(nm)) | O(2^(nm)) | O(纳米) | 太慢了 |
 | 直接检查所有方块 | O(n^2 m^2) | O(n^2 m^2) | O(1) | O(1) | 太慢了 |
 | 4 类枚举 | O(16·纳米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 根据坐标奇偶性将所有单元格分为四组：(i mod 2, j mod 2)。 这是有效的，因为每个偶数方块包含每组中完全相同数量的细胞。 
2. 观察到在任何有效网格中，同一组中的所有单元格必须采用一致的值。 如果同一组中的两个单元格不同，则在足够大的偶数正方形内交换它们将违反约束的均匀性。 
3. 将网格减少为四个布尔变量，表示分配给四个组中每个组的值。 
4. 施加来自任意 2×2 块的约束。 由于每个 2×2 恰好包含每组中的一个单元格，因此四个组值的总和必须是奇数。 
5. 枚举这四个变量的所有 16 个赋值，但仅保留满足奇偶校验约束的那些。 这样的作业一共有 8 个。 
6. 对于每个有效分配，通过扫描一次网格并对与分配的组值不同的单元格数量进行求和来计算成本。 
7. 返回所有有效分配中的最小成本。 

我们可以将每个组视为统一的原因是，任何违规都会在某些偶数方格内产生矛盾，其中在同一奇偶校验类别内交换位置不会改变成员资格计数，但会破坏约束的一致性。 

### 为什么它有效

每个偶数方格都由来自四个奇偶类别中每个类别的相同数量的单元组成，因此其总数量仅取决于分配给每个类别的数量，而不是它们的位置。 因此，该条件从多个尺度上的几何约束分解为四个变量上的单个奇偶校验约束。 一旦这四个值固定，所有较大的约束都会自动一致，因为较大的偶数方块是奇偶校验行为相同的 2×2 块的并集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # count ones in each parity class
    cnt = [[0, 0], [0, 0]]
    sz = [[0, 0], [0, 0]]

    for i in range(n):
        for j in range(m):
            ii = i % 2
            jj = j % 2
            sz[ii][jj] += 1
            if g[i][j] == '1':
                cnt[ii][jj] += 1

    best = 10**18

    # try all assignments of 4 variables: a00,a01,a10,a11
    for mask in range(16):
        a = [[0, 0], [0, 0]]
        for i in range(2):
            for j in range(2):
                a[i][j] = (mask >> (i * 2 + j)) & 1

        # check constraint: each 2x2 block has odd sum
        total = a[0][0] + a[0][1] + a[1][0] + a[1][1]
        if total % 2 == 0:
            continue

        cost = 0
        for i in range(2):
            for j in range(2):
                if a[i][j] == 1:
                    cost += sz[i][j] - cnt[i][j]
                else:
                    cost += cnt[i][j]
        best = min(best, cost)

    print(best if best < 10**18 else -1)

if __name__ == "__main__":
    solve()
```该实现首先将网格压缩为四个聚合桶，避免对精确位置的任何依赖。 每个掩码代表对这四个存储桶的一个候选值分配。 奇偶校验确保遵守 2×2 约束。 成本计算使用预先计算的计数，以便在预处理后在 O(1) 内评估每个候选者。 

一个微妙的点是，成本是使用类别频率来计算的，而不是通过每次分配重新扫描网格来计算。 这避免了时间复杂度超过 nm 的不必要的 16 倍。

 ## 边缘情况

 1×1 网格永远不包含任何偶数正方形，因此无论其值如何，它始终有效。 该算法自然地处理这个问题，因为类聚合仍然有效，并且所有分配都被评估，当不需要翻转时，最小成本正确地变为零。 

在 2×2 网格中，只有一个约束，算法通过四个变量的奇偶校验条件强制执行该约束。 由于每个变量恰好对应一个单元格，因此成本计算变成了所有有效配置的直接枚举，即使在最小的非平凡情况下也能确保正确性。 

在高度均匀的网格（例如全零或全一）中，该算法不假设任何结构。 它只是评估所有有效的奇偶校验分配并选择最接近的一个，从而避免过度拟合单一模式并确保跨极端的稳健性。
