 ## 解决方案
 ## 问题理解

 我们被要求构建从 1 到 n 的数字排列，以便每个连续的段在按位或运算下以非常特定的方式表现。 

对于任何子数组，我们获取其中的所有值并计算它们的按位或。 要求是该 OR 值必须始终至少与子数组的长度一样大。 因此，如果一个段的长度为 5，则其元素的 OR 必须至少为 5，并且这必须适用于每个可能的段，而不仅仅是整个数组。 

输出不是唯一的。 满足此条件的任何排列都是可以接受的，因此该任务纯粹是建设性的。 

约束很小，n 最多为 100，测试用例最多为 100 个。 这排除了每次测试的线性或近线性构造之外的任何优化需求。 即使天真地检查候选排列也是可行的，因为 n 很小，但直接构建一个排列是预期的目标。 

一个微妙的点是 OR 的行为与总和或最小约束不同。 它不会线性累积。 单个大位可以支配许多值。 这通常建议采用分配两个幂或仔细排序数字的结构，以便前缀和子数组获得足够的位覆盖范围。 

一个天真的尝试可能是对排列进行排序或反转它或随机洗牌。 这些很容易失败。 例如，对于 n = 3，恒等排列 [1, 2, 3] 在子数组 [1, 2] 上失败，因为 1 OR 2 = 3 没问题，但其他排列（如 [1, 3, 2]）仍然可能通过或失败，具体取决于结构。 真正的挑战是确保每个窗口长度 k 始终具有至少覆盖 k 的 OR，这与二进制表示而不是数值大小密切相关。 

## 方法

 暴力破解的想法很简单：生成一个排列并检查它是否满足条件。 检查需要迭代所有 O(n²) 子数组，每个 OR 计算成本为 O(n)，每次排列的时间为 O(n³)。 因为有 n! 排列，即使 n = 100，这也是完全不可行的。 

即使我们修正了一个排列，暴力检查仍然是 O(n3)，这是边界，但对于 n = 100 来说是可以接受的。然而，盲目地生成候选是没有意义的。 因此，真正的问题是如何构造一个排列来保证每个段中的比特覆盖。 

关键的观察结果是对于短子阵列，该条件最弱。 长度为 k 的子数组要求 OR ≥ k，因此 k 值决定了段中必须出现多少位。 对于较小的 k，这很容易； 对于较大的 k，我们需要更高的位来足够频繁地出现。 

重新解释该条件的一个有用方法是，长度为 k 的每个段都必须包含足够的二进制覆盖范围，以便从 1 到 k 的所有数字都受 OR“支配”。 这表明我们需要一种结构，其中具有相似最高位的数字以受控方式分布。 

这个问题的已知构造技巧出人意料地简单：对于 n ≥ 2，反转自然排列就可以了。 即我们输出[n, n-1, ..., 1]。 

为什么这有效？ 因为对于任何子数组，按降序排列的一组连续整数的 OR 往往会很快提前包含高位，更重要的是，任何长度为 k 的段必须包含至少一个来自某个位范围顶部的数字，以确保 OR 增长足够。 关键属性是，按照相反的顺序，每个长度为 k 的前缀都包含一个数字，其二进制表示形式满足 k 范围要求。 

更具体地说，考虑长度为 k 的任何线段。 该段中的最大可能值至少为 n - k + 1。按照相反的顺序，段往往会尽早包含较大的值，以确保高位出现在每个窗口中。 这些高位保证 OR 相对于 k 不会太小。

一种更结构化的方式是，该构造确保对于任何 k 长度的段，都存在一个其最高设置位至少为 log2(k) 的元素，这迫使 OR 足够大以支配 k。 

这使得暴力的想法变得不必要：我们不验证约束，而是直接强制执行单调高位分布。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（检查排列）| O(n3 · n!) | O(n3 · n!) | O(n) | 太慢了 |
 | 构造逆排列 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取 n。 
2. 通过列出从 n 到 1 的整数来构造排列。 

这可确保携带较高二进制位的较大值出现在数组的早期。 
3. 输出构建的排列。 

选择降序的原因是它可以最大限度地早期暴露所有子阵列中的高位。 由于每个子数组必须包含跨越一定大小范围的值，因此这种排序确保没有段仅由小的低位数字组成。 

### 为什么它有效

 不变量是，在任何长度为 k 的子数组中，至少存在一个其最高有效位足够大以强制 OR 至少为 k 的元素。 由于数字按降序排列，因此任何大小为 k 的窗口都不可避免地包含范围上部的值，并且这些值在 OR 结果中占主导地位。 这可以防止任何子数组的 OR 相对于其长度太小，从而确保所需的不等式全局成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    res = list(range(n, 0, -1))
    print(*res)
```解决方案是直接构建，无需模拟。 唯一重要的选择是排序方向。 反向打印可确保首先出现最大值，这是强制执行按位 OR 约束的结构属性。 

除了处理 n = 1 之外，不存在任何边界问题，其中相同的构造简单地输出 [1]，这是有效的。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys

    out = []
    for _ in range(t):
        n = int(sys.stdin.readline())
        res = list(range(n, 0, -1))
        out.append(" ".join(map(str, res)))

 ## 边缘情况

 对于 n = 1，排列 [1] 简单地满足条件，因为每个子数组的 OR 等于 1 且长度为 1。算法输出 [1]，因为单个元素的范围反转是其本身。 

对于 n = 2，输出为 [2, 1]。 子数组 [2]、[1] 和 [2,1] 的 OR 值分别为 2、1 和 3，均满足所需的下限。 该结构确保较大的元素首先出现，这立即满足了唯一的重要部分。 

对于较大的 n，每个窗口必须包含至少一个来自反转数组前缀的高值，并且该元素保证足够的位覆盖范围以保持 OR 高于窗口长度要求。
