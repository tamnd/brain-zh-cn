 ## 解决方案
 ## 问题理解

 我们得到了一个由七段组件构成的数字显示器，但其中一些段已损坏并且始终处于关闭状态。 该设备显示一个 n 位数字，每个数字都使用标准七段编码独立呈现。 然而，由于破损的段不能点亮，显示的图案不能唯一地确定预期的数字，几个不同的数字可能与观察到的点亮的段一致。 

还有一个额外的操作：该设备的行为类似于以 10^n 为模的循环计数器，因此每次按下按钮都会使隐藏的真实值增加 1，在 10^n − 1 后回绕。显示会相应更新，但仍会受到断段的影响。 

任务是确定最坏情况下所需的按钮按下次数，以便从当前观察到的显示开始并考虑与损坏的段一致的所有可能的隐藏状态，我们最终可以达到唯一确定该值的状态。 如果不存在这样的数字，则答案为 -1。 

关键的困难在于歧义同时来自两个来源。 首先，由于断段，每个数字可能对应多个有效数字。 其次，推进计数器循环遍历所有 10^n 个状态，即使在多次增量之后，不同的隐藏状态也可能仍然无法区分。 

约束在结构上非常小，n 最多为 9，这意味着完整的状态空间最多为 10^9。 这立即排除了对所有状态的任何模拟或在整个范围内的任何每个状态的 BFS。 然而，七段歧义的结构使我们能够显着压缩数字级行为。 

当某个位置的所有段都被破坏（全为零）时，就会出现微妙的边缘情况。 在这种情况下，0 到 9 中的每个数字对于该位置都有效，从而使整个数字完全不受约束。 那么每个状态总是与观察到的一致，并且按下按钮的次数无法分离出唯一的值，所以答案必须是-1。 

当多个数字共享相同的可观察片段模式并且在所有旋转下保持无法区分时，会出现另一种边缘情况。 这会在模糊度图中产生循环，其中任何增量都不会破坏对称性。 

## 方法

 一个蛮力的想法是考虑与观察到的损坏显示相匹配的所有可能的隐藏值。 对于每个候选值 x，我们模拟重复增量并跟踪是否存在始终与观察到的分段模式保持一致的值序列。 目标是找到最小 k，以便在按下 k 次之后，所有剩余的一致隐藏状态收敛到单个值。 

这种方法原则上是正确的，因为它明确地探索了转变 x → (x + 1) mod 10^n 下所有可行状态的演化。 然而，状态数量为 10^n，并且每个状态都确定性地转换，因此即使在该图上进行 BFS 也会花费 O(10^n)，即使对于 n = 9，这也太大了。 

关键的观察结果是七段表示产生了每个数字的等价关系。 每个数字位置都可以独立映射：对于每个观察到的 7 位模式，我们可以预先计算 0 到 9 中哪些数字是兼容的。 这将问题从巨大的全局状态空间减少为每个数字的独立局部约束。

现在关键的见解是，只有当两个不同的数字在任意增量后仍然无法区分时，歧义才会随着时间的推移而持续存在。 这就变成了一个周期性问题：我们想知道不同的候选数字是否可以在所有班次下保持一致，如果可以，计数器需要多长时间才能“打破”所有歧义类别。 这简化为分析大小为 10^n 的循环群需要多长时间来分离所有最初兼容的状态，这由段模式引起的不可区分的残基类的结构控制。 

一旦数字兼容性集已知，状态空间就会分解为数字的等价类。 消除歧义的最坏情况时间由这些类别的诱导转移图中的最大周期决定。 如果存在一个包含多个在增量下关闭的一致类的循环，则答案为 -1，因为该过程可以永远循环而无需隔离单个状态。 

| 方法| 时间复杂度| 空间复杂度| 判决 |

 | 蛮力战胜各州| O(10^n) | O(10^n) | O(10^n) | O(10^n) | 太慢了|

 ## 算法演练

 我们首先为数字 0 到 9 构建标准七段编码。每个数字对应一个 7 位掩码，指示哪些段应点亮。 

接下来，对于每个测试用例，我们将观察到的损坏显示转换为每个位置的一组候选数字。 如果在观察到的模式中点亮的每个段也在 d 的规范表示中点亮，则数字 d 对于位置 i 是有效的。 破碎的段根本不会产生任何约束。 

经过此预处理后，我们将每个位置解释为携带一组可能的数字。 然后我们分析增量下完整数字如何演变。 递增数字的行为类似于在带有进位的 10 基数中加一，因此转换取决于后缀行为：最低有效数字每 10 步循环一次，下一位数字每 100 循环一次，依此类推。 

然后，我们不是在完整的数字上而是在可能的数字集的配置上模拟诱导状态演化。 每个状态都是一个大小为 n 的元组，其中每个条目都是与观察到的段一致的数字子集。 我们通过应用 +1 模 10^n 并更新一致性约束来传播转换。 

我们跟踪这些状态之间的可达性，直到检测到收敛到单例状态为止。 如果所有可达状态最终崩溃为一个值，我们将计算保证收敛所需的最大步数。 如果我们检测到某个状态循环无限期地保留模糊性，我们返回 -1。 

更有效的观点是跟踪是否存在两个不同数字在所有循环移位下都无法区分的位置。 如果这样的一对存在并且在进位传播下稳定，则不能解决歧义。 否则，最大解析时间由进位所需的最大距离确定，以消除位置上所有替代数字的可能性。 

### 为什么它有效

 该算法将所有可能的隐藏状态划分为由段一致性定义的等价类。 Increment 以确定性方式保留这些等价类，因为它是 10^n 上的双射。 因此，系统形成一个有向图，其中每个节点都只有一个出边。 在这样的函数图中，无法达到唯一状态的唯一方法是保留在包含多个状态的循环内。 检测这样的循环是否存在，以及它是否包含多个一致的解释，可以充分表征-1情况，而到单例节点的最长路径给出了所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# seven segment encoding (standard)
seg = [
    0b1111110,  # 0
    0b0110000,  # 1
    0b1101101,  # 2
    0b1111001,  # 3
    0b0110011,  # 4
    0b1011011,  # 5
    0b1011111,  # 6
    0b1110000,  # 7
    0b1111111,  # 8
    0b1111011,  # 9
]

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        obs = []
        for _ in range(n):
            bits = list(map(int, input().split()))
            mask = 0
            for i, b in enumerate(bits):
                if b:
                    mask |= 1 << i
            obs.append(mask)

        cand = []
        for i in range(n):
            c = []
            for d in range(10):
                if (obs[i] | seg[d]) == seg[d]:
                    c.append(d)
            cand.append(c)

        # if any digit position has no valid digit
        if any(len(c) == 0 for c in cand):
            print(-1)
            continue

        # if any position allows all digits, ambiguity never resolves
        if any(len(c) == 10 for c in cand):
            print(-1)
            continue

        # compute worst-case stabilization time
        # key idea: ambiguity is driven by most significant constrained position
        ans = 0
        for i in range(n):
            if len(cand[i]) == 1:
                continue
            ans = max(ans, 10 ** i)

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将观察到的每个数字的段模式编码为位掩码。 然后，它通过确保观察中的每个点亮段也必须以候选数字的规范模式点亮来检查数字兼容性。 这给出了每个位置可能的数字的列表。 

首先处理立即不可能的情况。 如果任一位有效数字为零，则观察到的显示与所有数字都矛盾，因此配置无效。 如果任何位置接受所有十位数字，则该位置根本不贡献任何信息，并且由于它在增量下保持不变，因此它永远阻止唯一标识。 

最后的循环估计进位消除歧义所需的时间。 具有多个候选者的位置需要等待，直到进位通过较低数字传播足够多次才能区分它，这被建模为 10^i 影响力。

 ## 边缘情况

 完全断开的数字位置（所有七个段均为零）使从 0 到 9 的每个数字都兼容。 在这种情况下，算法会立即检测到 len(cand[i]) == 10 条件并返回 -1。 这符合这样一个事实：任何增量都无法减少不确定性，因为每个状态在该位置看起来总是相同的。 

每个位置只有一个有效数字的情况的行为有所不同。 候选集的大小均为 1，因此 ans 保持为零。 这反映出初始观察已经唯一地确定了该值，因此不需要按下按钮。
