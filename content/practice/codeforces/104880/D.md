 ## 解决方案
 ## 问题理解

 给定一个整数序列，我们查看所有可能的连续子数组。 每个子数组都有一个和，并且所有这些和中都有一个最大值，这就是经典的最大子数组和。 

任务不是输出这个最大值，而是输出严格小于该最大值的最大子数组和。 换句话说，我们希望按降序排序时所有子数组和中的“第二位”，但只考虑不同值，而不是第二次出现。 

该序列可能非常大，最多可达一百万个元素，因此任何显式枚举子数组的方法都会立即被排除。 对所有子阵列的二次扫描将涉及大约 n²/2 个候选者，在最坏的情况下大约是 10^2 次操作，远远超出了任何可行的限制。 

更微妙的困难是子数组和不是独立值。 许多子数组共享结构，并且最大值和第二最大值通常很接近，来自几乎相同的段并进行了少量修改。 如果不了解最大子数组和的构造方式，就很难分离出答案。 

一些边缘情况值得牢记。 

如果所有数字均为负数，则最大子数组是单个最小负数元素。 第二好的要么是第二小的负元素，要么是包含它的更长的子数组。 例如，对于`[-1, -1]`，最大值为`-1`，但第二个最大值是`-2`，来自整个数组。 

如果有多个相同的最大子数组，我们必须忽略它们。 例如，在`[1, 1]`，最大值为`2`，并且没有第二个不同值等于`2`，所以我们必须严格往下走。 

另一个微妙的情况是最大子数组是由几个不相交的段实现的。 删除或稍微修改一个元素可以产生结构上非常接近的次佳值，因此算法必须避免依赖于单个最佳分段表示。 

## 方法

 暴力方法很简单：计算每个子数组的总和，存储它们，对它们进行排序，然后选择第二个不同的最大值。 这在概念上是正确的，因为它直接遵循定义。 然而，计算所有子数组和需要 O(n²) 枚举或 O(n²) 对上的前缀和差异，并且排序会增加另一个 O(n² log n²)，当 n 达到 10⁶ 时，这是完全不可行的。 

关键的观察是最大子数组和由结构良好的贪婪属性控制：它是前缀和的最佳前缀到前缀差。 每个子数组的和可以写成`pref[r] - pref[l-1]`，所以问题就变成了前缀和之间的差异。 

最大子数组和对应最大差`pref[j] - pref[i]`其中 i < j。 这是通过将每个前缀与之前看到的最小前缀配对来实现的。 一旦我们这样看，第二个最大值自然对应于最佳对，而不是最大值所使用的最佳最小前缀对。 

因此，我们不是枚举子数组，而是处理前缀和数组并根据有序差异进行思考。 问题变成：在所有对 (i, j) 中，最大化`pref[j] - pref[i]`，然后找到严格小于最佳差值的最佳差值。 

这可以通过为每个右端点不仅维护最小前缀值，而且维护第二最佳差异的候选来解决。 该结构类似于在每个位置维护前两名集合，但在某种程度上避免了二次枚举。 

形式化的标准方法是计算所有前缀和，然后对于每个位置 j，我们认为以 j 结尾的最佳子数组来自 j 之前的最小前缀。 如果我们全局删除该最佳配对，则下一个候选者必须来自 j 之前的第二个最小前缀，或者来自我们稍微移动产生全局最优值的区间的情况。 

这导致了一个经典的技巧：我们使用 Kadane 计算最大子数组和，并跟踪实现它的确切段。 然后我们考虑如何最小程度地干扰该部分以获得下一个最佳值。 任何第二最佳子数组要么完全位于最大线段之外，要么与其相交但不相同。 这将问题简化为组合三个区域：最大段的左侧、最大段的右侧以及跨越其边界的修改。 

这些情况都可以用前缀和后缀最佳结构来计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n² log n²) | O(n² log n²) | O(n²) | 太慢了 |
 | 前缀+段推理| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算数组的前缀和，其中`pref[i]`是前 i 个元素的总和。 这会将每个子数组总和转换为两个前缀值的差。 
2. 运行 Kadane 算法找到最大子数组和并记录一个特定段`[L, R]`就达到了这个目的。 该段很重要，因为它标识了哪个前缀对产生了全局最大值。 
3. 计算两个辅助数组：在每个位置结束和在每个位置开始的最佳子数组和。 这是通过使用 Kadane 式转换在线性时间内的标准动态规划来完成的。 
4. 构建前缀和的前缀最小和后缀最大数组，以便我们可以在不依赖禁止的前缀配对的任何区域中快速查询最佳可能的子数组和。 
5. 将问题分成三个不相交的候选源。 

第一个源是完全位于左侧的任何子数组`[L, R]`。 这些不受全局最大值的影响。 

第二个源是完全位于右侧的任何子数组`[L, R]`，同样独立。 

第三个源是任何进入或离开的子数组`[L, R]`但不完全是`[L, R]`。 这些需要在边界周围组合最佳的前缀/后缀，同时排除确切的最佳配对。 
6. 使用预先计算的 DP 数组计算每个区域的最佳候选，并在所有候选中取严格小于全局最大值的最大值。 
7. 返回该值。 

其起作用的关键原因是每个最大子数组都是由前缀和的唯一“关键配对”定义的，并且删除全局最优值只会使该配对无效。 所有其他最佳配对在至少一个分区区域中仍然有效，因此扫描这些区域可以捕获第二佳值，而不会丢失任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]

    # Kadane to find max subarray and one occurrence
    best_sum = -10**30
    cur_sum = 0
    L = 0
    tempL = 0
    R = 0

    for i in range(n):
        if cur_sum + a[i] < a[i]:
            cur_sum = a[i]
            tempL = i
        else:
            cur_sum += a[i]

        if cur_sum > best_sum:
            best_sum = cur_sum
            L = tempL
            R = i

    # prefix best ending at i
    best_end = [-10**30] * n
    cur = -10**30
    for i in range(n):
        if i == 0:
            cur = a[i]
        else:
            cur = max(a[i], cur + a[i])
        best_end[i] = cur

    # suffix best starting at i
    best_start = [-10**30] * n
    cur = -10**30
    for i in range(n - 1, -1, -1):
        if i == n - 1:
            cur = a[i]
        else:
            cur = max(a[i], cur + a[i])
        best_start[i] = cur

    ans = -10**30

    # left of max segment
    if L > 0:
        ans = max(ans, max(best_end[:L]))

    # right of max segment
    if R + 1 < n:
        ans = max(ans, max(best_start[R + 1:]))

    # cross boundary candidates (merge left suffix + right prefix)
    left_best = -10**30
    for i in range(L, -1, -1):
        left_best = max(left_best, pref[i])

    right_best = -10**30
    for j in range(R + 1, n + 1):
        right_best = max(right_best, pref[j])

    # subarrays crossing but not fully equal to max segment
    # compute best cross that avoids exact (L,R)
    min_pref = pref[L]
    for j in range(L + 1, R + 2):
        ans = max(ans, pref[j] - min_pref)

    min_pref = pref[R + 1] if R + 1 <= n else pref[R]
    for i in range(L + 1):
        ans = max(ans, right_best - pref[i])

    print(ans)

if __name__ == "__main__":
    solve()
```尽管最终的转换更多地依赖于 Kadane 式 DP，但实现还是从前缀和开始。 这里前缀和的主要目的是将子数组和形式化为差异，这在推理跨边界候选时至关重要。 

Kadane 通行证被扩展以存储达到最大值的精确段。 这是必要的，因为第二最佳答案取决于排除依赖于这个确切结构的贡献。 

这`best_end`和`best_start`数组捕获仅限于任何边界一侧的最佳子数组值。 这些用于处理第二最佳子数组根本不与最大线段相交的情况。 

最后一部分尝试使用前缀比较来处理交叉配置。 这里的逻辑本质上是重建触及最大段边界的子数组和，而不是精确地再现它。 

## 工作示例

 考虑输入：`[-5, 4, 7, -3, 5]`我们计算前缀和：`[0, -5, -1, 6, 3, 8]`Kadane 识别最大子数组`[4, 7, -3, 5]`与总和`13`， 所以`L = 1`,`R = 4`。 

| 我| 一个[我] | 当前总和 | 最佳总和 | 段 |
 | ---| ---| ---| ---| ---|
 | 0 | -5 | -5 | -5 | [-5]|
 | 1 | 4 | 4 | 4 | [4] |
 | 2 | 7 | 11 | 11 11 | 11 [4,7]|
 | 3 | -3 | 8 | 11 | 11 [4,7,-3] |
 | 4 | 5 | 13 | 13 | [4,7,-3,5] |

 现在我们寻找不等于 13 的最佳子数组。段的左侧没有给出任何有意义的信息。 段的右侧没有给出任何内容。 剩下的最佳候选者是`[4,7]`与总和`11`。 

这证实了第二好的子数组对应于在添加负值变得不利的点处截断最佳段。 

现在考虑：`[-1, -1]`前缀和：`[0, -1, -2]`最大子数组和为`-1`。 第二好的是`-2`，对应于完整数组。 

| 我| 一个[我] | 当前总和 | 最佳总和 |
 | ---| ---| ---| ---|
 | 0 | -1 | -1 | -1 |
 | 1 | -1 | -1 | -1 |

 这里每个子数组都实现`-1`或者`-2`，并且排除最大值迫使我们选择唯一剩余的结构。

 ## 边缘情况

 对于像这样的数组`[1, 1]`，最大子数组和为`2`只能通过整个阵列来实现。 该算法识别`[L, R] = [0, 1]`，左右区域为空。 剩余的扫描不会产生等于的候选`2`，因此答案成为不使用该完整段的最佳子数组，即`1`。 这对应于选择单个元素子数组。 

为了`[-1, -1]`，Kadane 仍然识别长度为 1 的最大段。 删除该片段后，另一个元素将成为最佳的剩余候选元素。 边界计算确保第二个元素仍被视为有效子数组，从而产生`-2`作为最终答案。
