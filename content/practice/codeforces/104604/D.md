 ## 解决方案
 ## 问题理解

 我们有许多独立的整数对$(a, b)$。 对于每一对，我们必须决定是否可以构造四个正整数$u, v, x, y$从而同时满足两个约束。 

第一的，$a = u + v$，以及两者$u$和$v$必须划分$b$。 第二，$b = x + y$，以及两者$x$和$y$必须划分$a$。 因此，每个数字必须可表示为其对应数字的两个除数之和，并且相同的结构必须在两个方向上都成立。 

该任务纯粹是对每个测试用例的可行性检查。 

约束条件非常大，最多可达$10^{18}$，直到$10^5$查询。 这立即排除了任何枚举除数的方法$a$或者$b$，因为即使是一个数字也可能有太多的除数，无法在时间限制下枚举。 该解决方案必须依赖于结构数论而不是显式因式分解。 

一个微妙的边缘情况是当数字很小或相等时。 例如，$a = b$行为不同，因为约束变得对称并且可能崩溃为平凡的除数分区。 另一种边缘情况是当一个数字是素数时，因为它的除数结构极其有限，并且常常迫使不可能。 

## 方法

 我们从字面解释开始。 对于固定对$(a, b)$，我们会尝试所有的方法来分割$a$进入$u+v$，检查两者是否相除$b$，同时确保$b$可以分解为以下的约数$a$。 

这种强力方法需要迭代两个数字的所有除数并测试所有对和。 即使我们预先计算除数$O(\sqrt{n})$，候选对的数量成为除数计数的二次方，这对于$10^{18}$价值观和$10^5$查询。 

关键的观察是，如果$u\mid b$和$v\mid b$和$u+v=a$， 然后$u$和$v$被限制为相同数字的约数。 解决此类问题的一个经典技巧是从任意除数切换到最小的结构基础：最大公约数。 

让$g = \gcd(a, b)$。 的每个除数$b$参与总和$a = u+v$必须与$g$，类似地对于$a$。 该系统是对称的，归一化后$g$，问题简化为检查缩放对是否满足固定的小整数恒等式集。 

关键的减少是两个数字都必须可以使用除数来表示，除数的结构完全由质因数分解决定$\gcd(a,b)$，并且所有其他素数分量都是无关的，因为它们不能一致地出现在两个除数集中。 这将问题分解为检查比率的一组有限可能性$a/g$和$b/g$，结果证明只有几个有效的配置。 

归约后，唯一可行的情况对应于特定对称排列中两个归一化值均为 2 或 3 的情况。 这会为每个查询生成一个恒定时间的决策规则。

 ## 算法演练

 我们独立处理每个查询。 

### 1. 计算最大公约数

 我们计算$g = \gcd(a, b)$。 这捕获了两个数字的完整共享乘法结构，这是唯一可以同时支持两个方向除数约束的部分。 

### 2. 标准化该对

 我们定义$$A = \frac{a}{g}, \quad B = \frac{b}{g}.$$现在$\gcd(A, B) = 1$。 任何有效的构造都必须与这个互质结构一致。 

### 3. 分析除数和约束

 我们需要：

 -$a = u+v$， 和$u \mid b$,$v \mid b$-$b = x+y$， 和$x \mid a$,$y \mid a$缩放后$g$，任何除数$b$有助于$a$必须是除数$B$，类似地对于$A$。 

因为$A$和$B$互质，一个的除数出现在另一个的和结构中的唯一方式是通过平凡的组合。 这迫使每一边都可以表示为两个除数之和，其唯一的共享结构是 1。 

因此，每一边本身必须表现得像“二除数和结构”，只有当数字是以下任一情况时才会发生这种情况：

 - 2 (1 + 1)，或
 - 允许两个相等除数的乘积结构，强制方形折叠。 

### 4. 最终表征

 检查所有有效配置简化为验证一组恒定的模式$(A, B)$。 有效案例有：

 -$A = B = 2$-$A = 1, B = 2$-$A = 2, B = 1$所有其他情况都会失败，因为在不违反互质约束的情况下，一侧不能表示为另一侧的两个约数之和。 

### 为什么它有效

 不变的是任何有效的构造都必须在两个方向上保持除数兼容性。 除以 gcd 后，两个数字成为互质，从而消除了共享的质因数。 由于互质数的约数只能通过 1 对齐，因此唯一可能的和会简化为微不足道的分解。 这将解空间限制为一组有限的归一化对，从而使决策时间恒定。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        a, b = map(int, input().split())
        g = math.gcd(a, b)
        A, B = a // g, b // g

        if (A, B) in [(1, 2), (2, 1), (2, 2)]:
            print("SI")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该实现直接应用 gcd 标准化并检查一小组有效标准化状态中的成员资格。 gcd 步骤至关重要，因为它删除了所有共享的乘法结构，只留下不可约的交互模式。 

计算 gcd 后必须小心使用整数除法； 使用浮动除法会破坏大输入的正确性。

 ## 边缘情况

 当两个数字相等且较小时，gcd 归一化会将它们折叠为$(1,1)$。 这立即被拒绝，并且算法正确地避免了假设对称性意味着有效性。 

当一个数字除另一个数字时，gcd 归一化会产生一对像$(1, k)$。 仅有的$k=2$能够通过常量大小写检查，因此较大的可分链会被正确拒绝。 

当输入互质时，gcd 为 1，算法将所有内容简化为平凡的标准化对，确保不会因意外除数重合而出现误报。
