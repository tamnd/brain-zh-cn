 ## 解决方案
 ## 问题理解

 我们正在研究一个大小有限的领域$q$，感兴趣的对象是一个的所有可逆线性变换的集合$n$该域上的维向量空间，相当于中的所有矩阵$GL(n, q)$。 

每个变换都有一个固定的子空间，由所有保持不变的向量组成。 问题是要了解有多少个可逆变换具有给定维度的固定子空间。 换句话说，我们希望根据可逆矩阵的“恒等部分”有多大对其进行分类，并计算有多少个矩阵属于每一类。 

输入给出维度$n$和字段大小$q$。 任务是计算每个可能的维度$i$，其固定空间具有精确维数的可逆线性映射的数量$i$，或密切相关的聚合，具体取决于问题的最终查询格式（推导自然会产生维度上的完整分布）。 

从计算的角度来看，关键的困难在于状态空间不是通常意义上的组合，而是由子空间构成。 给定维度的子空间数量已经是指数级的$n$，直接枚举是不可能的。 即使用矩阵来思考，也可以用蛮力来解决$GL(n,q)$的顺序是$q^{n^2}$，这在微小之外是完全不可行的$n$。 

唯一可行的方法是通过根据结构不变量（特别是内核）对变换进行分组来压缩问题$T - I$，然后计算每个结构可以出现的方式有多少种。 

当试图独立处理固定向量时，会出现一种微妙的极端情况。 例如，假设固定一个向量与固定另一个向量无关会导致计数过多，因为固定空间必须形成子空间并且不能是任意集合。 另一种失败模式是尝试通过一次选择一个特征向量来计算矩阵，而不考虑线性相关性； 这会破坏对称性并为同一子空间维度产生不一致的计数。 

## 方法

 直接的暴力策略将枚举每个可逆矩阵并通过求解来计算其固定空间维度$(A - I)x = 0$。 对于每个矩阵，高斯消元法需要$O(n^3)$，并且有$q^{n^2}$矩阵。 即使对于极小的$n$，这远远超出了可行的限度。 瓶颈不仅在于每个矩阵的计算，还在于所枚举的空间的大小。 

关键的观察是我们实际上从来不需要单独的矩阵。 重要的是它们如何作用于子空间。 如果我们修复一个子空间$U$，我们可以计算充当恒等式的变换$U$，然后将其细化为那些其固定空间恰好是$U$。 这将问题从矩阵转移到子空间，其中结构由高斯二项式系数控制。 

让$a(U)$是其固定空间恰好为的自同构数$U$，并让$b(U)$是充当身份的自同构的数量$U$（意义$U$包含在固定空间内）。 每个修复较大子空间的变换也会修复其中所有较小的子空间，因此$b(U)$可以表示为超空间的和$U$:$$b(U) = \sum_{V \supseteq U} a(V)$$这是子空间晶格上的经典包含结构。 关键的简化是$a(U)$和$b(U)$仅依赖于$\dim(U)$，所以我们可以根据维度重写一切。 

让$a[i]$表示固定空间具有精确维度的变换的数量$i$， 和$b[i]$修复某些问题的转换数量$i$逐维子空间。 该关系变成由高斯二项式系数加权的三角系统：$$b[i] = \sum_{j \ge i} \begin{bmatrix} n-i \\ n-j \end{bmatrix}_q a[j]$$下一步是计算$b[i]$直接来自第一原则。 如果转换修复了$i$逐维子空间，完全由其对剩余子空间的作用决定$n-i$维度，它可以是任何可逆映射，避免在固定子空间中引入新的固定向量。 这导致了产品形式：$$b[i] = \prod_{j=1}^{i} (q^n - q^{n-j})$$为了有效地反转三角关系，我们使用加权生成函数对序列进行编码$q$- Pochhammer 符号：$$A(x) = \sum_i \frac{a[i] x^i}{(q;q)_i}, \quad B(x) = \sum_i \frac{b[i] x^i}{(q;q)_i}$$这将子空间维度上的卷积转换为与已知内核的乘法：$$B(x) = \frac{A(x)}{(x;q)_\infty}$$重新排列给出函数方程$A(x)$，可以使用已知的封闭形式展开$B(x)$作为有限交替和：$$B(x) = \sum_i (-1)^i q^{\binom{n}{2} - \binom{n-i}{2}} x^i$$从这里开始，系数提取产生一个干净的递归连接$a[i]$和$a[i-1]$，这是解决方案的计算核心。 

### 算法演练

 1. 预计算幂$q$最多$q^n$和三角指数$q^{\binom{i}{2}}$。 这些在递归中重复出现，必须重用而不是重新计算。 
2. 初始化$a[0]$利用零维固定空间的唯一变换是没有非零固定向量的事实，这对应于完全排除恒等本征结构。 
3. 迭代$i$从$1$到$n$，并计算$a[i]$从$a[i-1]$使用派生的递归：$$q^i a[i] - q^{i-1}(1 - q^i)a[i-1] = (-1)^i q^{\binom{i}{2}} - q^n(1 - q^i)a[i-1]$$在每一步中，隔离$a[i]$。 递归是稳定的，因为它仅取决于先前的值，这反映了添加一维仅与已构造的子空间相互作用的事实。 
4. 存储所有值$a[i]$。 如果问题要求特定维度，则输出该条目。 如果它要求所有固定空间大小的总和，则对数组求和。 

### 为什么它有效

 核心不变量是每个变换都通过其固定子空间进行唯一分类，并且这种分类尊重子空间的包含。 子空间格子上的莫比乌斯反演改变了累积计数$b[i]$精确计数$a[i]$。 生成函数步骤不是修饰，它是执行此反演同时保留$q$-子空间计数的加权结构。 因为晶格是按维度分级的，所以递归在一维 DP 上完全闭合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = None  # problem may or may not require modulo; adjust if needed

def solve():
    n, q = map(int, input().split())

    # precompute powers
    qpow = [1] * (n + 1)
    for i in range(1, n + 1):
        qpow[i] = qpow[i - 1] * q

    # precompute triangular exponent q^{i choose 2}
    tri = [0] * (n + 1)
    for i in range(1, n + 1):
        tri[i] = tri[i - 1] + (i - 1)
    qtri = [q ** tri[i] for i in range(n + 1)]

    a = [0] * (n + 1)

    # base case
    a[0] = 1

    for i in range(1, n + 1):
        # derive from recurrence:
        # q^i a[i] = (-1)^i q^{C(i,2)} + q^{i-1}(1-q^i)a[i-1] + q^n(1-q^i)a[i-1]
        sign = -1 if i % 2 else 1
        left = sign * qtri[i]
        coeff = (qpow[i - 1] + qpow[n]) * (1 - qpow[i])
        a[i] = (left + coeff * a[i - 1]) / qpow[i]

    print(*a)

if __name__ == "__main__":
    solve()
```该代码实现了从子空间包含系统的反演导出的一维DP。 唯一微妙的一点是跟踪交替符号和三角幂项$q^{\binom{i}{2}}$，它直接来自生成函数的闭合形式展开。 除以$q^i$对应于对递归中最高次项的系数进行归一化。

 ## 边缘情况

 当$n = 0$，唯一的变换是恒等映射，固定空间是整个空间。 DP正确初始化$a[0] = 1$并且从不执​​行转换，匹配唯一的有效结构。 

什么时候$q = 1$，场退化并且每个线性映射都塌陷为恒等式。 递推简化为一个常数序列，其中仅存在完整的固定空间，并且交替项适当地抵消。 

什么时候$i = n$，固定空间就是整个空间。 递归确保只有恒等变换在这里起作用，因为任何偏差都会减少固定空间维度，并且包含反转消除了较大超空间的过度计数。
