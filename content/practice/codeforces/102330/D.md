 ## 解决方案
 ## 问题理解

 我们目前有两个优惠，`x`来自巴纳姆和`y`来自卡莱尔，与`x <= y`。 巴纳姆将他的报价提高了`a`，然后卡莱尔将他的报价减少`b`。 在接下来的一对动作中，变化变为`2a`和`2b`， 然后`3a`和`3b`， 等等。 

一旦两个报价相遇或交叉，该过程就会结束。 答案是实际说出的最后一个报价。 由于当巴纳姆的当前报价至少是卡莱尔当前或下一个报价时，每个终止条件都会发生，因此答案将始终是巴纳姆在终止回合的报价。 

假设我们已经完成了`k`回合。 巴纳姆补充道

 a(1+2+⋯+k)=a 2 k(k+1) ​

 到他原来的报价。 卡莱尔减去了

 b(1+2+⋯+k)=b 2 k(k+1) ​ .

 因此，在回合的两次移动之后`k`，他们的报价是

 B k ​ =x+a 2 k(k+1) ​

 和

 C k ​ =y−b 2 k(k+1) ​ .

 该过程循环终止`k`当这两个值满足时`B_k >= C_k`。 重新排列给出

 (a+b) 2 k(k+1) ​ ≥y−x。 

所以整个模拟简化为寻找最小的非负整数`k`满足这个不等式。 一次`k`众所周知，答案很简单`B_k`。 

最多有`2000`测试用例，同时`x`和`y`几乎可以相差`10^12`。 因此，轮数可以约为`sqrt(10^12)`， 大致`1.4 * 10^6`，即使步长仅为`1`。 因此，直接模拟可以在所有测试中执行数十亿次迭代，这远远超出了一秒的限制。 我们需要利用三角数的单调增长，而不是模拟每一轮。 

一些边界情况值得特别注意。 例如，如果初始报价已经相等`1 1 5 7`，协商立即结束，答案为`1`。 始终先执行一轮的循环将错误地输出较大的值。 

边界上的平等也必须立即终止。 为了`1 4 1 1`，两轮之后报价变为`4`和`1`，答案是`4`。 更一般地，条件是`>=`，不仅`>`。 用严格比较代替它可以将答案移至下一轮。 

步长可以有很大不同。 为了`7 18 1 3`，答案是`10`：巴纳姆说之后`8`卡莱尔说`15`，巴纳姆说`10`，之后卡莱尔的意图`9`已经不大于`10`。 仅检查巴纳姆的报价是否已达到卡莱尔之前的报价的解决方案将错过此终止条件。 

## 方法

 简单的解决方案模拟了一轮又一轮的谈判。 回合中`k`，它将巴纳姆的报价增加了`k*a`并将卡莱尔的报价降低`k*b`，然后检查报价是否满足。 这是正确的，因为它完全遵循流程描述的报价顺序。 

问题是轮数。 和`y-x`附近`10^12`和`a=b=1`，我们大致需要

 2 k(k+1) ​ ≈5⋅10 11 ,

 这给出了`k`大约`10^6`。 和`2000`测试用例，最坏情况的模拟可以达到大约`2 * 10^9`回合。 尽管每一轮都是恒定时间，但这也太大了。 

有用的观察是，一轮之后`k`，差距减少的总量恰好是

 (a+b) 2 k(k+1) ​ .

 三角数`k(k+1)/2`对于非负数是严格递增的`k`，所以谓词

 (a+b) 2 k(k+1) ​ ≥y−x

 对于所有较小的都是错误的`k`对于所有足够大的情况都是如此`k`。 这种单调性使得二分搜索成为模拟的自然替代品。 

关于报价的顺序还有一个微妙的点。 巴纳姆在每一轮中首先发言。 如果他的新报价已经达到卡莱尔之前的报价，则该过程立即停止在巴纳姆的价值上。 如果没有，卡莱尔接下来发言。 如果卡莱尔的新报价已降至巴纳姆的价值或更低，则该过程也会在巴纳姆的价值处停止。 两种情况都由单一条件捕获`B_k >= C_k`， 因为`C_k <= C_{k-1}`。 如果巴纳姆达到`C_{k-1}`，他当然也达到了更小的`C_k`。 

因此我们只需要第一轮，该轮之后的报价就可以满足`B_k >= C_k`。 答案就是巴纳姆那轮的报价。

 ## 算法演练

 1. 计算初始间隙`d = y - x`。 如果`d`为零，报价已经同意，所以答案是`x`并且不需要回合。 
2. 对于候选轮`k`，计算三角数

 T k ​ = 2 k(k+1) ​ 。 

在该轮的两个报价之后，他们的距离是

 d−(a+b)T k ​ .

 当该值为非正数时，谈判在该轮结束。 
3. 使用二分查找找到最小的`k`为此

 (a+b)Tk​≥d。 

谓词是单调的，因为`T_k`严格增加`k`。 
4.一旦最小有效`k`找到，计算巴纳姆的报价

 x+aT k ​ .

 这就是谈判结束时的金额。 
5. 打印当前测试用例的该值，并对所有测试用例重复该值。 

### 为什么它有效

 回合前`k`，巴纳姆所做的累计增加是`a(1 + ... + k)`，而卡莱尔的累计减少量为`b(1 + ... + k)`。 因此，它们彼此的联合运动是`(a+b)T_k`。 这个动作至少是原来差距的第一轮，正是相应减少后巴纳姆的报价至少是卡莱尔的报价的第一轮。 

因为卡莱尔一轮又一轮的报价`k`不大于他在回合前的报价`k`，当巴纳姆首先说话时发生的任何交叉也由相同的条件表示`B_k >= C_k`。 因此最小的`k`二分查找找到的正是终止轮，并且`x + aT_k`正是最后所说的金额。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        x, y, a, b = map(int, input().split())

        if x == y:
            out.append(str(x))
            continue

        gap = y - x
        step = a + b

        # Find the smallest k such that
        # step * k * (k + 1) / 2 >= gap.
        lo, hi = 0, 1

        while step * hi * (hi + 1) // 2 < gap:
            hi *= 2

        while lo < hi:
            mid = (lo + hi) // 2
            triangular = mid * (mid + 1) // 2

            if step * triangular >= gap:
                hi = mid
            else:
                lo = mid + 1

        k = lo
        triangular = k * (k + 1) // 2
        answer = x + a * triangular

        out.append(str(answer))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个特殊案例手柄`x == y`直接地。 在那种情况下`k = 0`满足终止条件，因此执行另一次迭代将出现差一错误。 

对于其他每个测试，`gap`存储初始报价之间的距离，而`step = a + b`是三角形级数每单位距离减少的量。 表达式`k * (k + 1) // 2`是之后的累积乘数`k`回合。 

二分查找的上限是通过加倍找到的`hi`。 这避免了依赖手动选择的常数。 由于需要`k`只是差距的平方根附近，这种加倍只需要很少的运算。 

二分查找保持了通常的不变量，即答案位于`[lo, hi]`。 当中点已经满足所需的不等式时，仍然有可能`mid`本身就是答案，所以`hi`移动到`mid`。 否则答案一定更大，所以`lo`变成`mid + 1`。 

Python 整数具有任意精度，因此诸如`a * k * (k + 1)`不要溢出。 整数除法也在乘以之前完成`a`在最终的计算中，由于`k(k+1)`始终为偶数且三角数为整数。 

## 工作示例

 对于第一个样本，`x = 7`,`y = 18`,`a = 1`， 和`b = 3`。 初始间隙为`11`，每轮都贡献`4T_k`走向关闭它。 

| k | T_k | 巴纳姆`B_k`| 卡莱尔`C_k`|`4T_k >= 11`|
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 7 | 18 | 18 没有 |
 | 1 | 1 | 8 | 15 | 15 没有 |
 | 2 | 3 | 10 | 10 9 | 是的 |

 第一轮有效回合是`k = 2`。 巴纳姆的报价是`7 + 1 * 3 = 10`，所以答案是`10`。 这个例子还说明了为什么仅检查卡莱尔之前的报价是不够的。 巴纳姆的`10`没有达到上一个`15`，但卡莱尔的下一个预期报价是`9`，所以谈判仍然结束于`10`。 

对于第二个样本，双方开始于`4`。 

| k | T_k | 巴纳姆`B_k`| 卡莱尔`C_k`| 状况 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 4 | 4 | 是的 |

 最小有效值`k`为零，所以答案仍然存在`4`。 这证实了必须在不进行谈判的情况下处理初始平等。

 ## 边缘情况

 初始相等情况是`1 1 1 1`。 这里`gap = 0`， 所以`k = 0`已经满足条件了。 算法立即返回`x = 1`，避免不必要的第一轮。 

等式边界表示为`1 4 1 1`。 初始间隙为`3`。 为了`k = 1`，总平仓金额为`2`，这是不够的。 为了`k = 2`，三角数为`3`， 所以`(a+b)T_2 = 6`，超过了间隙。 巴纳姆的报价是`1 + 3 = 4`，给出正确答案`4`。 严格比较会错误地处理两个报价完全一致的情况。 

第一个样本，`7 18 1 3`，捕获两个报价之间的排序问题。 在`k = 2`, 巴纳姆提供`10`而卡莱尔在同一轮后的报价是`9`。 该过程结束于`10`，尽管巴纳姆的报价没有达到卡莱尔之前的报价`15`。 组合间隙条件正确地捕获了这一点。 

对于大案`1 1000000000000 1000000 1000000`，差距是`999999999999`。 在`k = 999999`，三角数为`499999500000`，乘以后仍然太小`2 * 10^6`。 在`k = 1000000`，三角数变为`500000500000`，这就足够了。 巴纳姆的最终报价是

 1+1000000⋅500000500000=500000500000000001。 

计算完全在 Python 的整数范围内，因为 Python 整数自动增长，并且二分搜索避免了迭代一百万轮。
