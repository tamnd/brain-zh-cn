 ## 解决方案
 ## 问题理解

 有`n`火车车厢。 在车里`i`,`a[i]`化学队买票后，座位仍然空着。 信息学团队准确地`k`参与者并希望购买门票，以便他们乘坐的每辆车都满员。 由于除了化学参与者之外，任何人都不允许共享这样的汽车，因此所选汽车中的每个剩余空闲座位都必须由信息学参与者占据。 

因此，如果车队使用一组汽车，那么这些汽车中的空闲座位总数必须恰好是`k`。 所选择的汽车应根据其第一辆车和最后一辆车的编号形成尽可能小的连续段。 一辆汽车`a[i] = 0`可以发生在两辆相关车厢之间，因为它已经满了并且不需要新票。 我们只需要输出最佳线段的端点。 

例如，与`a = [1, 2, 3, 4]`和`k = 5`，2 号车和 3 号车正好有 5 个空闲座位，所以答案是`2 3`。 和`a = [1, 0, 2]`和`k = 3`，从1号车到3号车整个段正好有3个空座，中间的车已经满了。 

汽车数量最多为`10^5`。 二次算法会考虑`n(n+1)/2`，这接近于`5 * 10^9`最大尺寸的间隔。 这远远超出了一秒竞争性编程极限所能承受的范围。 的价值观`a[i]`和`k`可以达到`10^9`，它们的总和也可以达到`10^9`，因此从概念上讲，实现应该使用整数算术来安全地处理此大小的总和。 Python 整数在这里不存在溢出问题。 

有几种边缘情况可能会导致粗心的实施失败。 首先，答案可以是一辆车。 用于输入```
1 5
5
```正确的输出是`1 1`。 仅检查长度至少为 2 的段的实现将会错过它。 

其次，答案中可能会出现完全满载的汽车。 为了```
3 3
1 0 2
```正确的输出是`1 3`。 中间的零没有任何贡献，但端点仍然必须报告为`1`和`3`。 

第三，需要一个准确的金额。 为了```
2 5
2 2
```正确的输出是`-1`。 整趟车只有四个空座，所以买五张票并不能填满所有选定的车厢。 

最后，零值汽车可以创建多个具有相同数量的非零汽车但端点距离不同的段。 为了```
5 3
0 1 0 2 0
```正确的输出是`2 4`。 该段包含三个空闲座位，而将其扩展以包括任一零值端点将使间隔更长，因此更糟。 

## 方法

 直接解法可以枚举每个可能的区间`[l, r]`并计算其总和。 使用前缀和，可以在常数时间内获得每个区间和，因此该算法需要`O(n^2)`时间和`O(n)`记忆。 这是正确的，因为第一辆车和最后一辆车的每一个可能的选择都被明确检查，并且在那些总和为`k`，我们可以保留最短的一个。 

问题是间隔的数量。 为了`n = 100000`， 有`n(n + 1) / 2 = 5,000,050,000`不同的间隔。 尽管每次求和查找的时间都是恒定的，但数十亿次迭代还是太慢了。 

关键的观察是每个`a[i]`是非负的。 这使得区间和具有单调行为。 如果我们向右延长一个区间，它的总和只能保持不变或增加。 如果我们将它的左端点向右移动，它的和只能保持不变或减少。 

这正是两指针滑动窗口所需的结构。 我们维护一个窗口`[l, r]`及其总和。 我们延长`r`直到总和达到或超过`k`。 如果总和正好是`k`，当前窗口是候选窗口。 然后我们尽可能从左侧删除元素，因为删除正值会使窗口更短并且可以揭示更好的答案。 零值汽车需要特别小心，因为删除它们不会改变总和，并且可以缩短答案，即使总和保持等于`k`。 

暴力破解之所以有效，是因为每个区间都独立地回答了“这个片段是否包含精确的”问题。`k`有空座位吗？”非负值使总和单调的观察结果让我们可以在移动到下一个间隔时重用一个间隔的信息，从而将工作量减少到线性时间。

 ## 算法演练

 1. 阅读`n`,`k`，和数组`a`。 我们需要找到一个区间，其总和恰好为`k`，具有最小长度。 
2.初始化左指针`l = 0`，当前总和`s = 0`，以及存储迄今为止找到的最佳间隔的变量。 
3. 向右移动指针`r`从左到右。 添加`a[r]`到`s`，因为当前窗口现在包含这辆车。 
4. 虽然`s > k`， 消除`a[l]`从`s`并增加`l`。 由于所有值都是非负的，因此减少过多总和的唯一方法是将左边界向前移动。 
5. 缩小窗口后，如果`s == k`，当前区间有效。 将其长度与迄今为止找到的最佳间隔进行比较，如果较短则保留它。 
6. 什么时候`s == k`，重复删除前导零很有用，因为它们不会改变总和。 在实现中，这自然是在比较候选长度之前由相同的左边界移动逻辑处理的，或者在找到精确总和后通过显式缩小零来处理。 这很重要，因为`[0, 1, 2]`和`[1, 2]`具有相同的总和，但后者是更好的间隔。 
7.处理完每个右端点后，如果没有区间有和`k`被发现，打印`-1`。 否则，使用基于 1 的汽车编号打印最佳间隔的端点。 

### 为什么它有效

 每时每刻，窗口都包含一系列连续的汽车和`s`正好是他们的空闲座位的总和。 因为所有`a[i]`是非负的，延伸右端点永远不会减少`s`，而推进左端点永远不会增加它。 因此，一旦窗口的总和大于`k`，保持当前的左端点不能产生有效的更大的右端点，因此左端点可以安全地前进。 每当窗口有精确的总和时`k`，这是一个有效的解决方案，并且删除前导零给出了具有相同右端点的最短间隔。 由于每个右端点都被处理并且每个指针仅向前移动，因此该算法考虑与每个位置相关的最短可能有效间隔，因此找到一个全局最短的有效间隔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    left = 0
    current_sum = 0

    best_left = -1
    best_right = -1
    best_len = n + 1

    for right in range(n):
        current_sum += a[right]

        while left <= right and current_sum > k:
            current_sum -= a[left]
            left += 1

        if current_sum == k:
            while left <= right and a[left] == 0:
                left += 1

            length = right - left + 1

            if length < best_len:
                best_len = length
                best_left = left
                best_right = right

    if best_left == -1:
        print(-1)
    else:
        print(best_left + 1, best_right + 1)

if __name__ == "__main__":
    solve()
```输入被读取一次并存储在`a`，之后`left`和`right`代表当前的滑动窗口。`current_sum`每当边界移动时就会更新，因此不需要前缀和数组。 

这`while current_sum > k`循环是安全的，因为所有值都是非负的。 一旦总和太大，移动左边界是唯一可以减少总和的操作。 每个元素最多从窗口中删除一次，因此此循环仅贡献`O(n)`总工作量而不是`O(n)`适用于每个正确的端点。 

第二个循环在找到精确的总和后从左侧删除零值的汽车。 这是一个微妙的边界条件。 假设当前窗口是`[0, 1, 2]`和`k = 3`。 它的总和已经是正确的，但是`[1, 2]`是一个严格更短的有效间隔。 因为去掉零并不会改变`current_sum`，我们可以安全地丢弃这样的汽车。 

答案在内部使用从零开始的索引存储，并且仅在打印时转换为从一开始的索引。 Python 中不需要特殊的整数类型，因为 Python 整数会根据需要自动增长。

 ## 边缘情况

 ### 单车

 对于```
1 5
5
```右指针访问唯一的汽车，产生`current_sum = 5`。 因为这等于`k`, 区间`[0, 0]`成为最佳答案。 转换为基于一的索引后，程序打印`1 1`。 

这里常见的错误是初始化最佳答案，就好像必须选择至少两辆车一样。 问题中没有任何要求，因此一辆车是有效且通常是最佳间隔。 

### 答案里已经满了车

 对于```
3 3
1 0 2
```窗口增长为`[1]`， 然后`[1, 0]`， 然后`[1, 0, 2]`。 它的总和正好变成三。 零值汽车已经满了，但它位于包含信息学参与者的两辆汽车之间，因此端点是`1`和`3`。 

零不能简单地被视为障碍。 这样做会错误地得出结论：没有连续间隔具有所需的总和。 

### 没有可能的精确总和

 对于```
2 5
2 2
```整趟列车的空闲座位总数为四个。 由于每`a[i]`是非负的，任何子数组的总和都不可能大于总和，因此达到 5 是不可能的。 右指针最终处理整个数组而不产生`current_sum == 5`，程序打印`-1`。 

一个粗心的实现，至少搜索最小的和`k`可能会错误地接受整个数组。 要求是平等，而不是`sum >= k`。 

### 零值边界

 对于```
5 3
0 1 0 2 0
```第一个精确窗口是`[0, 1, 0, 2]`，其总和为三。 然后，该算法会删除前导零而不更改总和，留下`[1, 0, 2]`。 结果答案是汽车`2`通过`4`。 

不包括尾随零，因为在评估候选值时右指针尚未前进到它。 包括任一零边界都会产生更长的间隔，而无需添加任何有用的座位。
