 ## 解决方案
 ## 问题理解

 佩蒂亚每分钟向沃瓦扔一个球。 他们之间的距离是`L`，并且每个球都以一定速度移动`X`，所以一个球需要`L / X`分钟即可到达沃瓦。 

Vova 不会立即投篮。 当球进入距离时他开始投篮`D`他的。 他的枪会立即开火，但每次射击后他都需要`M`几分钟后才能再次点火。 如果射程内已经有几个球，他总是射出最近的一个，这是那些仍然活着的球中最古老的球，因为每个球都有相同的速度。 

我们需要当第一个球到达 Vova 时 Petya 扔出的球数。 如果 Vova 能够永远射出每一个球，答案是`-1`。 

参数都可以大到`10^9`。 这立即排除了任何与分钟数或球数成比例的模拟，因为答案本身可以是`10^9`。 所需的解决方案必须仅使用恒定数量的算术运算。 Python 整数还可以生成诸如`X * (M - 1)`安全，无需任何特殊的溢出处理。 

第一个微妙的情况是`M = 1`。 沃娃每分钟可以射门一次，与佩蒂亚创造球的次数完全相同。 例如，`5 2 2 1`有答案`-1`。 模拟最终可能只是因为实现限制而停止，但从数学上讲，每个球在到达 Vova 之前都会被移除。 

第二种微妙的情况是，当球到达 Vova 的同时，Vova 可以射门。 例如，`6 1 3 2`有答案`4`。 第四个球与第四个可能的射门同时到达沃瓦。 比赛在那一刻结束，因此对于 Vova 来说，平局必须被视为失败，而不是成功的射门。 

第三个微妙的情况是最终公式中的精确除法。 例如，与`L = 10`,`X = 2`,`D = 6`， 和`M = 2`，相关比率恰好是`6 / 2 = 3`，所以答案是`4`， 不是`5`。 使用浮点并采用近似上限可能会引入不必要的错误源，因此该实现使用整数除法。 

## 方法

 直接模拟可以一颗一颗地处理球。 对于每个球，我们可以确定它何时进入 Vova 的射击范围，跟踪枪何时可用，并决定该球是否在到达 Vova 之前被射击。 这是有效的，因为除了发射时间之外，所有球都是相同的，并且最近的球始终是最古老的幸存球。 

这种方法的问题在于球的数量。 考虑`X = 1`,`D = 10^9`， 和`M = 2`。 第一个到达 Vova 的球只能在大约`10^9`球已被抛出。 所有这些球的循环执行大约十亿次迭代，这远远超出了 0.5 秒的限制。 即使经过优化的事件模拟也无法解决根本问题，因为事件太多了。 

关键的观察是我们实际上不需要知道任何单个球在哪里。 当第一个球到达射击距离时，第一次击球发生。 之后，每一个镜头都准确无误地发生`M`分钟后，只要还有球在等待。 由于 Petya 发射球的时间间隔为一分钟`M >= 1`， 这`k`第 次射击始终瞄准`k`第-个球。 

让第一个球及时投出`1`。 到达拍摄边界后`(L - D) / X`分钟。 因此`k`第-次射击发生在`1 + (L - D) / X + (k - 1)M`。 

这`k`第一个球到达 Vova 的时间为`k + L / X`。 

在射门前到达 Vova 的第一个球恰好是第一个球`k`其到达时间小于或等于其预定发射时间。 比较这些表达式会导致`L`完全取消，只留下一个条件`D`,`X`， 和`M`。 

为了`M = 1`，由此产生的不平等永远不可能成为现实。 为了`M > 1`, 第一个输球是`1 + ceil(D / (X(M - 1)))`。 

因此，整个模拟被分解为一个整数除法和一些算术运算。

 ## 算法演练

 1. 阅读`L`,`X`,`D`， 和`M`。 距离`L`最终会消除不平等，但它仍然是输入的一部分。 
2.如果`M = 1`， 打印`-1`。 Petya每分钟发射一个球，Vova也可以每分钟发射一次，所以枪永远不会落后。 
3.为了`M > 1`，计算每球投篮优势变化的分钟数。 沃娃收益`M - 1`相对于 Petya 一分钟的发射间隔，额外延迟了几分钟。 
4. 将优势乘以球速。 相关数量为`X * (M - 1)`。 第一个失球取决于投篮距离内有多少个这样的单位`D`。 
5. 计算`ceil(D / (X * (M - 1)))`使用整数运算。 如果`q = D // denominator`和`r = D % denominator`，上限为`q`什么时候`r = 0`， 否则`q + 1`。 
6. 添加`1`到该上限并打印结果。 额外的`1`这是因为第一个球在击球序列开始之前有一个初始的一分钟偏移。 

从时间上可以直接看出为什么这样做有效`k`第-个球。 它的到达时间是`k + L/X`，而其可能的拍摄时间为`1 + (L-D)/X + (k-1)M`。 当到达不晚于射门时比赛结束，因为平等意味着球已经到达Vova。 重新排列给出`k + L/X <= 1 + (L-D)/X + (k-1)M`。 

取消后`L/X`并重新排列，`(M - 1)k >= (M - 1) + D/X`。 

乘以`X`给出`X(M - 1)(k - 1) >= D`。 

因此尽可能最小`k`正是`1 + ceil(D / (X(M - 1)))`。 

推导背后的不变量是`k`第-次射击始终涉及`k`第-个球。 第一次射击会移除第一个球，之后的每次射击都会移除在射击区域中等待的最旧的球。 由于球按顺序发射并以相同的速度移动，所以后面的球不可能比较早的幸存球更近。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    L, X, D, M = map(int, input().split())

    if M == 1:
        print(-1)
        return

    denominator = X * (M - 1)
    shots_needed = (D + denominator - 1) // denominator

    print(shots_needed + 1)

if __name__ == "__main__":
    solve()
```第一个分支处理唯一答案为无限的情况。 什么时候`M > 1`, 分母`X * (M - 1)`是正数，因此上限划分是明确定义的。 

表达式`(D + denominator - 1) // denominator`计算没有浮点数的整数上限。 这很重要，因为所有输入值都是整数，并且比率精确的边界会将答案更改为 1。 

变量`L`已读取但不会出现在最终计算中。 那是故意的。 走完全程所需的时间和到达射击边界所需的时间都包含相同的时间`L/X`分量，因此当比较两个时间时它消失。 

实现中没有数组、队列或每个球的状态。 Python 的任意精度整数也可以处理乘积`X * (M - 1)`直接，其值可以接近`10^18`。

 ## 边缘情况

 当`M = 1`，考虑确切的输入`5 2 2 1`。 主公式的分母将包含`M - 1 = 0`，因此盲目应用该公式会尝试除以零。 更重要的是，物理过程是不同的：沃娃每分钟可以射门一次，而佩蒂亚每分钟只能创造一个新球。 队列永远不会增长，因此没有球到达 Vova，正确的结果是`-1`。 

对于同时到达边界，使用`6 1 3 2`。 前四个可能的射击时间是`4`,`6`,`8`， 和`10`。 第四个球到达Vova的时间`10`。 因为到达Vova就结束了游戏，时间上是平等的`10`算作球的成功到达，而不是成功的射门。 算法检查`arrival <= shot`，这导致`k = 4`。 

对于精确的上限边界，请使用`10 2 6 2`。 这里`X(M-1) = 2`， 和`D = 6`， 所以`D / (X(M-1)) = 3`确切地。 答案是`1 + 3 = 4`。 使用严格不等式或错误舍入除法的公式可能会返回`3`或者`5`。 

对于非精确边界，请使用`10 3 5 3`。 分母是`3 * 2 = 6`， 尽管`D = 5`。 该比率介于 0 和 1 之间，因此其上限为`1`，给出答案`2`。 这检查整数上限是否实现为`(D + denominator - 1) // denominator`而不是普通的楼层划分。
