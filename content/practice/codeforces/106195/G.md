 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和一个排列。 该排列描述了不相交循环的集合：每个索引都指向另一个索引，并且没有索引指向其自身。 该操作选择一个索引`x`并改变两者的符号`a[x]`和`a[p[x]]`。 

目标是输出一系列选定的索引，以便在执行所有操作后，通过排列连接的每对都具有非负和。 操作次数不能超过数组大小的一半。 

约束允许最多`2 * 10^5`元素，因此任何重复尝试不同操作集或模拟多种可能性的解决方案都是不可能的。 我们需要对每个索引处理固定次数。 排列结构特别有用，因为它意味着关系图只是循环的集合。 

一个常见的错误是通过对总和为负数的每对进行操作来修复该对。 这不起作用，因为操作重叠。 翻转两条相邻的边可能会将同一顶点翻转两次，从而导致效果在意外的位置取消。 

例如，考虑：```
n = 3
a = [-5, 4, 4]
p = [2, 3, 1]
```周期为`1 -> 2 -> 3 -> 1`。 总和是`-1`,`8`， 和`-1`。 粗心的解决方案可能会翻转第一条和第三条边，因为它们是负值。 顶点`1`翻转两次并返回其原始符号，而顶点`2`和`3`被翻转一次。 最终状态不一定满足每条边。 

另一个重要的情况是当一个循环包含奇数个负值时。 简单地翻转所有负值将在该循环上留下奇数个操作，这不能通过选择边来直接表示，因为每个操作都会翻转两个顶点。 

例如：```
n = 3
a = [-1, 10, 10]
p = [2, 3, 1]
```正确的输出可以是：```
1
1
```翻转指数`1`将数组更改为`[1, 10, 10]`，使每个周期边沿有效。 坚持使每个值都非负而不考虑奇偶性的解决方案可能无法构造操作。 

## 方法

 蛮力方法是检查可能的操作集。 由于每个循环都可以有许多可能的边子集，因此它呈指数增长。 即使长度为 20 的循环也已经有超过一百万个可能的边缘选择。 暴力破解的想法是正确的，因为它会检查所有可能的最终配置，但它无法处理大输入。 

关键的观察是首先停止考虑操作并考虑数组值的最终符号。 如果每个值都变为非负数，则每个所需的总和自动有效。 唯一的限制是，符号改变的顶点集在每个循环内必须具有偶数大小，因为操作总是翻转两个顶点。 

对于每个周期，首先标记所有负值。 如果标记的顶点数量是偶数，则这已经是要翻转的有效顶点集。 如果是奇数，则翻转该循环中绝对值最小的附加顶点。 进行此更改后，除了可能选择的一个值之外，每个值都是非负的。 由于它具有最小的绝对值，因此它的相邻值至少同样大，因此两个相邻的和保持非负值。 

剩下的任务是将所需的顶点集转换为实际的边操作。 在一个循环中，如果我们选择或不选择一条边，则当恰好选择两个关联边之一时，每个顶点都会翻转。 这形成了一个简单的异或关系。 我们可以通过绕着循环走一圈来找到一个有效的边集。 有效边集的补集也是有效的，因为翻转每条边都会更改每个顶点的两个关联边并抵消。 我们选择两组中较小的一个，保证最多一半的循环边缘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将排列分解为独立的循环。 每个循环都可以单独求解，因为没有任何操作连接两个不同的循环。 
2. 对于每个循环，收集当前值为负的顶点。 这些是应该翻转以使其值为正的顶点。 
3. 如果循环中负顶点的数量为奇数，则找到绝对值最小的顶点并将其添加到翻转集合中。 这恰好改变了一个额外的值。 接触该顶点的两条边仍然有效，因为相邻的绝对值不小于。 
4. 将选定的顶点翻转集转换为边操作。 按顺序遍历循环，并指定是否使用连续顶点之间的异或转换来选择每个循环边。 
5. 计算所选边的数量。 所有循环边的互补集给出相同的顶点翻转，因此如果当前集包含超过一半的循环边，则将其替换为其补集。 
6. 将选定的边代表添加到答案中。 从循环中选择一条边意味着输出其排列边代表该循环边的索引。 

为什么它有效：

 该算法保持了所选操作精确翻转所构建的翻转集中的顶点的不变性。 每个循环以所有值非负或一个最小绝对值负值结束，同时两个相邻值至少一样大。 因此，通过排列连接的每一对都有一个非负和。 边转换是正确的，因为当存在一个相邻的选定边时，顶点将被精确翻转，这正是构造过程中使用的异或条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    p = [x - 1 for x in map(int, input().split())]

    visited = [False] * n
    answer = []

    for start in range(n):
        if visited[start]:
            continue

        cycle = []
        cur = start
        while not visited[cur]:
            visited[cur] = True
            cycle.append(cur)
            cur = p[cur]

        m = len(cycle)
        flip = [False] * m

        cnt = 0
        for i, v in enumerate(cycle):
            if a[v] < 0:
                flip[i] = True
                cnt += 1

        if cnt % 2 == 1:
            pos = 0
            for i in range(1, m):
                if abs(a[cycle[i]]) < abs(a[cycle[pos]]):
                    pos = i
            flip[pos] = not flip[pos]

        edges = []
        state = False
        edge = [False] * m

        for i in range(m):
            if flip[i]:
                state = not state
            edge[i] = state

        if sum(edge) > m - sum(edge):
            edge = [not x for x in edge]

        for i, take in enumerate(edge):
            if take:
                edges.append(cycle[i])

        answer.extend(edges)

    print(len(answer))
    if answer:
        print(*[x + 1 for x in answer])

if __name__ == "__main__":
    solve()
```第一部分读取数组并将排列转换为基于零的索引。 然后，该排列恰好遍历一次以提取循环。 

在每个周期内，`flip`代表应该改变符号的顶点。 奇偶校验校正在需要时添加最小绝对值顶点。 这是最终数组可能包含负值的唯一情况，并且选择最小的量值可以保留相邻的和。 

这`edge`数组是操作表示。 变量`state`在遍历循环时存储异或前缀。 每当当前异或值表示需要下一个转换时，就会选择一个边沿。 当它较小时取补是强制执行操作限制的原因。 

输出存储循环边缘索引。 如果选择了循环中的一条边，则使用其起始顶点作为操作参数将精确翻转所需的对。

 ## 边缘情况

 对于所有对和已经非负的情况，算法可能不输出任何操作。 例如：```
2
5 5
2 1
```该循环不包含负值，因此翻转集为空并且输出为零操作。 

对于具有奇数个负值的循环：```
3
-1 10 10
2 3 1
```负集仅包含第一个顶点。 该算法添加最小绝对值顶点（它已经是第一个顶点），从而无需第二个负值。 生成的操作翻转该顶点，产生值`[1,10,10]`。 

对于许多顶点为负的循环，算法不会直接为每个负值输出一次操作。 它首先将所需的顶点翻转转换为边缘选择，然后选择两个等效边缘集中较小的一个。 这就是将操作总数保持在所需限制内的原因。
