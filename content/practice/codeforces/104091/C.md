 ## 解决方案
 ## 问题理解

 我们需要精确计算有多少个小数`n`数字满足特殊的邻接规则。 

如果一个数字的每对相邻数字都形成一个可以被`3`。 例如，`12754`很美丽，因为`12`,`27`,`75`， 和`54`都可以被整除`3`。 另一方面，`1221`并不美丽，因为`22`不能被整除`3`。 

第一个数字不能为零，因为该数字必须恰好具有`n`数字。 如果满足整除条件，则每个剩余​​数字都可能为零。 

输入包含单个整数`n`， 在哪里`2 ≤ n ≤ 27`。 输出的是美女总数`n`数字。 

的价值`n`非常小。 即使是复杂度与`n × 100`或者`n × 1000`很容易符合限制。 彻底检查每一个`n`数字是不可能的，因为有`9 × 10^(n-1)`候选人。 对于最大的值，`n = 27`，这大约是`9 × 10^26`数字，远远超出任何实际计算。 

一个微妙的情况是第一个数字。 例如，当`n = 2`, 数量`03`满足邻接规则，因为`03 = 3`可以整除`3`，但它不是有效的两位数。 该算法必须禁止前导零。 

另一个容易犯的错误是误解了条件。 这对`75`可以整除`3`，但是这两个数字都没有任何特殊属性。 例如，`12`是有效的，因为`12`可以整除`3`， 尽管`13`不是因为`13 % 3 = 1`。 

一个更有趣的观察来自于整除`3`。 自从```
10a + b ≡ a + b (mod 3),
```一对可以整除`3`恰好当两个数字的余数之和可被整除时`3`。 实际的十进制值永远不需要计算。 

## 方法

 最直接的解决办法就是生成每一个`n`数字，测试每个相邻的对，并计算有效的。 这显然是正确的，因为每个候选人都是经过独立审查的。 不幸的是，运行时间与`9 × 10^(n-1)`，大致变成`10^27`最坏情况下的操作。 

该条件仅涉及相邻数字。 一旦前一个数字被固定，前面的数字就不再重要了。 这正是最后一位动态规划有效的情况。 

关键的观察结果是整除`3`仅取决于两个相邻数字的余数。 我们可以从左到右构建数字，同时只记住最后一位数字。 如果我们已经知道有多少个以数字结尾的有效前缀`d`，然后每个数字`x`满意的`(10d + x) % 3 == 0`可以扩展这些前缀。 

最后一位可能的数字只有十种，因此动态程序的每一层只包含十种状态。 每个状态最多尝试十次转换，每个数字仅提供大约一百次操作。

 | 蛮力 | O(10ⁿ×n)| O(1) | O(1) | 太慢了|

 ## 算法演练

 1. 创建数组`dp`尺寸的`10`， 在哪里`dp[d]`存储以数字结尾的有效前缀的数量`d`。 
2. 初始化第一个数字。 数字`1`通过`9`每个形成一个有效的长度前缀`1`，所以设`dp[1]`通过`dp[9]`到`1`。 离开`dp[0]`等于`0`因为前导零是被禁止的。 
3. 重复`n - 1`次，每个剩余位置一次。 
4. 创建一个新数组`next_dp`充满零。 
5. 对于每个可能的前一个数字`a`以及每一个可能的下一个数字`b`，检查是否`(10 * a + b) % 3 == 0`。 如果是，则每个以以下结尾的有效前缀`a`可以通过以下方式扩展`b`，所以添加`dp[a]`到`next_dp[b]`。 
6. 更换`dp`和`next_dp`。 
7. 处理完所有位置后，将每个值相加`dp`。 每个状态代表以不同的最终数字结尾的有效数字，因此它们的总和就是所需的答案。 

### 为什么它有效

 动态规划不变量是处理后`k`数字，`dp[d]`等于有效数`k`最终数字为的数字前缀`d`。 

初始化是正确的，因为每个非零数字恰好形成一个长度为 1 的有效前缀。 

在过渡期间，每个扩展都只被考虑一次。 当新创建的相邻对可以被整除时，精确地允许转换`3`。 不添加无效扩展名，也不遗漏有效扩展名。 

通过对处理后的长度进行归纳，每次迭代后不变式仍然成立。 毕竟`n`数字都经过处理，每一个都漂亮`n`根据最后一位数字，数字恰好属于一个状态，因此将所有状态相加即可得出正确答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

dp = [0] * 10
for d in range(1, 10):
    dp[d] = 1

for _ in range(n - 1):
    ndp = [0] * 10
    for a in range(10):
        if dp[a] == 0:
            continue
        for b in range(10):
            if (10 * a + b) % 3 == 0:
                ndp[b] += dp[a]
    dp = ndp

print(sum(dp))
```初始化表示所有可能的一位数字前缀。 排除数字零，因为最终数字必须恰好包含`n`数字。 

每次迭代都会将前缀扩展一位数字。 使用新数组是因为当前位置的转换不得影响同一层内的其他转换。 

跳过计数为零的状态并不是正确性所必需的，但它避免了不必要的工作。 

Python 整数会自动增长到任意大小，因此即使答案可能超出 32 位整数的范围，它也是合适的。
