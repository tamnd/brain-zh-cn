 ## 解决方案
 ## 问题理解

 我们给出了一个带有基数的位置数字系统$b$。 每个整数在该基数中都有一个表示，我们对该表示中尾随零的数量感兴趣。 

一个数字被认为是有效的，如果，当以基数书写时$b$，其最后一位数字至少包含$d$零。 换句话说，该数字必须能被$b^d$。 任务是计算范围内有多少个整数$[l, r]$满足这个整除条件。 

这些限制立即使我们远离任何直接枚举。 范围可达$10^{18}$，因此迭代所有数字是不可能的。 基地$b$最多 100，所以$b^d$仍然是可以管理的，因为$d \le 9$，但数字范围太大，无法进行简单检查。 

仅用十进制直觉思考时会出现常见的失败案例。 例如，在基数 10 中，计算以至少 2 个零结尾的数字意味着计算 100 的倍数。但在基数 2 或基数 7 中，有效数字之间的间距会发生巨大变化。 一个简单的循环检查每个数字的整除性$[l, r]$对于像这样的范围会超时$10^{18}$。 

另一个微妙的陷阱是处理$d = 0$。 在这种情况下，每个数字都是有效的，因为至少有零个尾随零总是正确的。 任何忘记这种特殊情况的实现都会错误地尝试计算整除性$b^0 = 1$，这在数学上很好，但如果处理不一致，可能会在逻辑中引入不必要的复杂性或边缘情况错误。 

## 方法

 蛮力的想法很简单：迭代每个整数$x$从$l$到$r$，将其转换为基数$b$，计算尾随零，并检查计数是否至少为$d$。 这是正确的，因为它直接遵循定义。 但是，将数字转换为基数$b$成本$O(\log_b x)$，我们这样做最多$10^{18}$数字。 即使使用快速算术，这也是远远不可能的。 

关键的观察是基数中的尾随零$b$等价于整除$b^d$。 如果一个数字至少以$d$基数为零$b$，那么它必须是以下形式$k \cdot b^d$。 所以问题就简化为计算有多少个倍数$b^d$位于$[l, r]$。 

这将问题变成了经典的前缀计数任务。 我们计算一下有多少个倍数$b^d$小于或等于$r$, 减去多少个小于$l$，并在常数时间内得到答案。 

唯一的微妙之处是确保边缘情况的正确性，例如$l = 1$和大值$b^d$，可能超过$10^{18}$。

 ## 算法演练

 我们将问题简化为计算固定值的倍数$p = b^d$在一个范围内。 

1. 计算$p = b^d$。 这代表最小的数字，其基数为$b$代表性至少有$d$尾随零。 
2.如果$d = 0$，立即返回$r - l + 1$，因为每个数字都满足条件。 
3. 计算有多少个倍数$p$小于或等于$r$，即$\left\lfloor \frac{r}{p} \right\rfloor$。 
4. 计算有多少个倍数$p$严格小于$l$，即$\left\lfloor \frac{l-1}{p} \right\rfloor$。 
5. 将这两个值相减，得到有效数字的个数$[l, r]$。 

第 4 步背后的推理很重要：我们将前缀计数为$r$并删除之前的所有内容$l$，所以我们必须排除严格小于的数字$l$，不是那些小于或等于$l$。 

### 为什么它有效

 每个整数可以被$b^d$至少有$d$基数尾随零$b$，因为乘以$b$将基数中的数字向左移动$b$并附加一个零。 相反，任意数至少有$d$尾随零必须能被整除$b^d$。 这在有效数字和倍数之间建立了一一对应关系$b^d$，因此计算有效数字可以精确地减少为计算一个区间内的倍数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

b = int(input().strip())
d = int(input().strip())
l = int(input().strip())
r = int(input().strip())

if d == 0:
    print(r - l + 1)
else:
    p = pow(b, d)
    def count(x):
        if x <= 0:
            return 0
        return x // p

    ans = count(r) - count(l - 1)
    print(ans)
```该解决方案是围绕将问题简化为倍数算术问题而构建的。 关键一步是计算$b^d$有效地使用内置的幂运算，可以安全地处理 Python 大整数范围内的大值。 

减法`count(r) - count(l - 1)`确保正确包含左边界，因为任何倍数$p$等于$l$必须计算。

 ## 边缘情况

 当$d = 0$，定义变得空洞：每个数字至少有零个尾随零。 该算法通过立即返回完整的间隔大小来处理此问题，避免不必要的求幂。 

什么时候$b^d > r$，除了可能的零之外，没有有效的数字，因为它超出了范围$l \ge 1$。 基于除法的公式自然会返回零，因为$\lfloor r / p \rfloor$和$\lfloor (l-1)/p \rfloor$为零。 

什么时候$l$本身是一个倍数$b^d$，减法$l - 1$确保包容性。 例如，与$l = 8$,$b^d = 8$， 期限$count(l - 1) = count(7) = 0$，所以 8 被正确计数。 

这些情况证实算术公式与所有边界条件下的原始尾随零定义相匹配。
