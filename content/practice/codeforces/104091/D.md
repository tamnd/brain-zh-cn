 ## 解决方案
 ## 问题理解

 我们有一个矩形网格$n$行和$m$列。 这个网格里面有$q$称为侦察兵的特殊部件。 每个侦察兵都坐在不同的牢房里$(x, y)$， 在哪里$x$是从上到下的行索引，$y$是从左到右的列索引。 

侦察兵“攻击”严格位于其右侧或严格下方区域的每个单元，包括其自己的位置。 正式地，侦察员在$(x, y)$覆盖所有细胞$(i, j)$这样$i \ge x$和$j \ge y$。 如果多个侦察兵覆盖同一个单元格，我们仍然只计算一次。 

任务是计算至少一个侦察兵覆盖了多少个不同的网格单元。 

网格尺寸限制非常大，可达$10^9 \times 10^9$，所以我们无法模拟网格。 侦察兵人数最多可达$10^5$，这意味着任何解决方案都必须避免每个单元的处理，而是依赖于聚合几何贡献。 

检查每个网格单元或什至尝试在其整个矩形上迭代每个侦查器的简单方法是不可能的，因为单个侦查器可能覆盖$10^{18}$细胞。 

一个不太明显的失败案例来自重叠。 例如，如果一名侦察兵在$(1, 1)$另一个在$(2, 2)$，第二个侦察兵的区域完全包含在第一个侦察兵的区域中，因此除非我们明确处理交叉点，否则天真的求和会严重超算。 

关键的困难在于每个侦​​察兵定义了一个右下矩形，我们需要这些矩形的并集的大小。 

## 方法

 每个侦察兵定义一个轴对齐的矩形，延伸到网格的右下角。 所以问题就变成了计算并集面积$q$矩形，其中每个矩形是$[x, n] \times [y, m]$。 

强力解释将标记每个矩形中的每个单元格，但每个矩形可能很大，这使得这完全不可行。 即使我们尝试只处理边界结构，直接扩展仍然取决于$n \cdot m$，太大了。 

关键的观察结果是所有矩形共享相同的“目标角”$(n, m)$，并且它们的形状是单调的：它们在网格边界内无限地向右下方延伸。 这种单调结构允许我们对侦察兵进行排序，并将联合过程压缩为逐行或逐列计算贡献。 

我们不是以二维方式思考，而是颠倒视角。 对于固定行$x$, 一个细胞$(x, y)$当且仅当某个地方存在侦察兵时才被覆盖$(x', y')$和$x' \le x$和$y' \le y$。 同样地，如果我们查看最多具有行坐标的所有侦察兵$x$，他们对列覆盖率施加了阈值。 

这建议从下到上扫描行。 当我们向上移动时，更多的侦察兵变得活跃，每个活跃的侦察兵都会对我们必须考虑的列的左侧距离做出限制。 对于给定的行，只有最小的列阈值才重要：一旦我们知道最小值$y$在所有球探中$x' \le x$，从该最小值到的所有列$m$被覆盖。 

因此，对于每一行，覆盖的区间就是$[ \min y \text{ among active scouts},\ m]$，答案是各行间隔长度的总和。 我们通过按唯一性分组来避免显式迭代行$x$坐标。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个单元的暴力破解 |$O(nm)$|$O(1)$| 太慢了|
 | 使用聚合按行扫描 |$O(q \log q)$|$O(q)$| 已接受 |

 ## 算法演练

 1.读取所有侦察位置并按行坐标分组$x$。 我们为每一行存储列位置列表$y$。 这是必要的，因为当我们以自下而上的方式到达侦察兵的行时，侦察兵的效果就会被激活。 
2. 按升序对所有不同的行坐标进行排序。 我们将从下到上处理行，以便一旦激活侦察器，它对上面的所有行都保持活动状态。 
3. 保持运行值`min_y`，初始化为$m+1$。 这表示当前在扫描中处于活动状态的所有侦察兵中的最小列索引。 
4. 从行开始$n$下降到$1$。 在每一行$x$，首先通过更新激活位于该行的所有侦察兵`min_y = min(min_y, y)`对于他们每个人来说。 此步骤确保`min_y`始终反映所有活跃球探施加的最严格的左边界。 
5. 处理行的激活后$x$，计算这一行覆盖了多少个单元格：它是$\max(0, m - min_y + 1)$。 这是有效的，因为每一列`min_y`到$m$保证至少有一名活跃的球探覆盖。 
6. 将该值累加到答案中。 
7. 继续，直到处理完第 1 行。 

### 为什么它有效

 在任意固定行$x$, 一个细胞$(x, y)$如果存在至少一名侦察兵，则被覆盖$(x', y')$这样$x' \le x$和$y' \le y$。 在所有活跃的球探中（那些拥有$x' \le x$），条件简化为$y \ge \min y'$。 因此，每行的覆盖范围完全由活动侦察器中的最小列阈值决定。 扫描准确地保持了这种不变性，因此每一行都被正确计数，没有重叠或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())
    
    by_row = {}
    for _ in range(q):
        x, y = map(int, input().split())
        if x not in by_row:
            by_row[x] = []
        by_row[x].append(y)

    min_y = m + 1
    ans = 0

    for x in range(n, 0, -1):
        if x in by_row:
            for y in by_row[x]:
                if y < min_y:
                    min_y = y

        if min_y <= m:
            ans += (m - min_y + 1)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案按行对侦察兵进行分组，以避免重复扫描。 关键状态变量是`min_y`，它将所有活动的侦察兵压缩到一个有效的边界中。 循环从$n$下降到$1$确保侦察兵一旦激活，就会影响其上方的所有行。 

表达式`m - min_y + 1`直接计算每行中被覆盖的后缀的长度。 条件`min_y <= m`当没有激活​​任何侦察兵或所有活动的侦察兵都位于网格范围之外时，可以防止计数。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |$O(q + n)$| 每个侦察处理一次，行扫描一次 |
 | 空间|$O(q)$| 按行分组的侦察兵存储 |

 约束条件允许$q \le 10^5$， 但$n$可以很大。 线性扫描$n$由于每次迭代操作简单，因此在 Python 中是可以接受的，并且主要成本仍然是输入处理。
