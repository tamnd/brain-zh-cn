 ## 解决方案
 ## 问题理解

 我们给定了单位面积 S 的总量，我们希望将该面积划分为几个不相交的正方形图。 每个图本身必须是边长为整数的完美正方形，因此每个选定的图贡献的面积是完美平方数，如 1、4、9、16 等。 

构造规则本质上是贪婪的。 从完整的剩余区域开始，我们反复选择不超过剩余区域的最大可能的正方形区域。 放置这样一个正方形后，我们从剩余预算中减去它的面积并重复，直到没有剩下。 输出是所有选定正方形区域的列表，以非递增顺序写入。 

尽管该陈述是以城市建设模拟中建设“场”的形式构建的，但其核心任务是纯粹的数字任务：通过在每一步中始终取最大的可行平方，将 S 重复分解为完全平方和。 

高达 10^17 的约束 S 立即排除了任何迭代所有可能的平方或逐个单元相减的方法。 即使简单地迭代从 1 到 S 的所有 k 也是不可能的。 然而，最大 10^17 的不同平方值的数量大约只有 10^8（因为 sqrt(S) 大约是 10^8），并且贪婪的性质表明我们只需要重复计算整数平方根并进行减法。 

当 S 已经是完全平方数或略低于 1 时，就会出现边缘情况。 例如，S = 15 应该产生 9, 4, 1, 1，而 S = 16 产生 16。当 S 很大并且分解产生许多项时，为每个步骤重新计算平方或线性扫描的简单实现可能会严重退化。 

另一个微妙的情况是当 S 非常大并且平方不稀疏时，例如 S = 10^17 - 1。尝试递减 S 或顺序搜索下一个平方的粗心方法会超时，即使通过整数平方根实现贪婪步骤仍然有效。 

## 方法

 从字面上看，是对语句的强力解释。 在每一步中，我们尝试所有整数边长 k ，使得 k^2 ≤ 剩余 S，选择最大的 k，减去 k^2，然后继续。 这是正确的，因为它完全符合规则。 然而，每个步骤都需要扫描最多 sqrt(S) 个候选者，并且在最坏的情况下，S 会缓慢缩小，因此操作总数与 S 成正比，或者在病态推理中至少与 S sqrt(S) 成正比。 更具体地说，如果我们总是减去 1，我们就会执行 S 步，这对于 S 达到 10^17 来说是不可能的。 

关键的观察是我们永远不需要明确地扫描最大的正方形。 不超过数字x的最大平方就是floor(sqrt(x))^2。 这将每个贪婪步骤变成了常数时间计算：计算整数平方根，平方，减去。 该过程会非常快地减少 S，因为每一步都会删除至少是 S 以下最大可能平方的值。 

这将问题转化为重复的整数平方根提取，这是有效的，因为每次迭代都会严格减少 S，并且迭代次数受到分解中平方项数量的限制，在实践中，对于较大的值，该数量很小，并且在行为上类似于对数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 最坏情况 O(S√S) | O(1) | O(1) | 太慢了|
 | 最优贪心与 sqrt | O(k log S) | O(k log S) | O(1) | O(1) | 已接受 |

 这里 k 是分解中的方格数。 

## 算法演练

1. 从完整值 S 和空结果列表开始。 该列表将存储我们在每一步中选择的正方形区域。 
2. 当 S 大于零时，将 r 计算为 S 的平方根的整数下限。这确定了仍适合剩余区域的正方形的最大可能边长。 
3. 计算平方面积 r² 并将其附加到结果列表中。 这是现阶段我们可以合法承担的最大贡献。 
4. S 减去 r² 即可得到剩余面积。 
5. 重复直到S 变为零。 
6. 输出收集到的列表，该列表自动按非递增顺序排列，因为每一步都为当前余数选择最大可能的平方，而余数只会减少。 

关键思想是，每一步都是由最优性强制的：一旦我们固定了余数 S，任何边长大于 Floor(sqrt(S)) 的正方形都会超过 S，因此对于最大有效正方形不存在其他选择。 

### 为什么它有效

 在任何时刻，剩余值为 x，任何有效的正方形面积都必须为 k²，其中 k ≤ Floor(sqrt(x))。 这样的最大可能的正方形是唯一的floor(sqrt(x))²。 选择任何较小的值将与我们始终在该步骤中选择允许的最大平方的要求相矛盾。 由于该过程纯粹是贪婪的，并且余数总是精确地减去所选平方，因此该算法保持了不变式：所有先前选择的平方都是有效的，并且它们的总和等于原始值减去当前余数。 当余数达到零时，我们就得到了完整的有效分解，并且每一步都是局部强制的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        S = int(input())
        res = []
        while S > 0:
            r = int(S ** 0.5)
            sq = r * r
            res.append(str(sq))
            S -= sq
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```该解决方案使用浮点平方根行为重复计算剩余值的整数平方根。 关键步骤是将其转换为整数以获得下限值，然后对其进行平方以获得不超过余数的最大平方。 我们将结果存储为字符串，以避免在输出格式化期间重复转换。 

循环继续，直到剩余值变为零，保证终止。 每次迭代都会严格减少 S，并且由于 S 是非负的，因此不可能出现无限循环。 

一个微妙的实现细节是确保浮点精度不会对大正方形进行错误分类。 实际上，对于高达 10^17 的值，Python 的浮点精度就足够了，但在更严格的环境中，人们会更喜欢`math.isqrt`以避免边缘错误。

## 测试用例```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            S = int(input())
            res = []
            while S > 0:
                r = math.isqrt(S)
                sq = r * r
                res.append(str(sq))
                S -= sq
            out.append(" ".join(res))
        return "\n".join(out)

    return solve()

 ## 边缘情况

 对于 S = 1，该算法计算 Floor(sqrt(1)) = 1，选择 1，并立即终止，产生单元素输出。 

对于像 S = 100 这样的完美平方，第一步直接选择 100，因为 Floor(sqrt(100)) = 10，并且减法立即将 S 减少到零，确认没有发生不必要的分解。 

对于正好低于平方的值，例如 S = 15，算法首先选择 9，然后继续选择较小的平方。 序列 15 → 9 → 6 → 4 → 2 → 1 → 0 表明，即使初始余数接近平方边界，每一步仍然严格遵循最大有效平方规则，并确保终止的进展。
