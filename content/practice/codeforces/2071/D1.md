 ## 解决方案
 ## 问题理解

 我们被赋予了第一个$n$无限二进制序列的元素，其中后面的每个元素$n$-th 被递归地定义为所有先前元素的异或（直到其索引的一半）。 正式来说，为了$m > n$， 期限$a_m$是所有元素的异或$a_1 \oplus a_2 \oplus \dots \oplus a_{\lfloor m/2 \rfloor}$。 对于问题的简单版本，我们只需要计算单个位置处的序列值$l = r$，而不是一个范围。 

输入指定多个测试用例。 每个测试用例给出$n$, 位置$l$，以及第一个$n$序列的元素。 输出是序列的值$l$第-个位置。 

这些限制是有启发性的。$n$可以达到$2 \cdot 10^5$和$l$可以大到$10^{18}$。 这立即排除了任何构造直到索引的序列的方法$l$，自迭代以来$10^{18}$次是不可行的。 总和$n$所有测试用例的边界为$2 \cdot 10^5$，它允许对序列的初始段进行预处理，但是大的$l$迫使我们以数学方式利用递归结构。 

当出现不明显的边缘情况时$l \le n$。 在这种情况下，答案只是$l$- 输入数组中的第一个元素。 另一个微妙的情况出现时$l$超出了$n$，但由于递归 XOR 结构，重复的 XOR 可能会导致周期性或易于计算的模式。 一种幼稚的方法，盲目地将递归应用于大的$l$效率和记忆力都会失败。 

## 方法

 暴力方法会尝试生成序列的所有元素，直到$l$。 这很简单：从给定的开始$n$元素，然后迭代计算每个新元素作为前一个元素的异或（最多其索引的一半）。 虽然这适用于小型$l$，它需要$O(l)$操作，这是完全不可行的$l$达到$10^{18}$。 

关键的观察是由以下定义的序列$a_m = a_1 \oplus \dots \oplus a_{\lfloor m/2 \rfloor}$表现出基于二的幂的模式。 如果我们计算初始元素的累积异或，我们可以使用索引的二进制表示递归地确定任意位置的值。 每一步本质上都将问题简化为更小的索引，最终落在预先计算的长度前缀内$n$。 

最佳方法使用递归或迭代减少：如果$l \le n$，我们返回$a_l$。 否则，我们计算$a_l$作为$a_{\lfloor l/2 \rfloor}$异或与$a_{\lfloor l/2 \rfloor - 1}$根据需要，重复将索引减半，直到它位于已知段内。 由于每一步都会将索引减半，因此操作次数与$\log l$，这甚至对于$l \approx 10^{18}$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(l) | O(l) | 太慢了|
 | 最佳 | O(log l) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算第一个的前缀异或数组$n$元素。 让`prefix[i]`店铺$a_1 \oplus a_2 \oplus \dots \oplus a_i$。 这允许对第一个段内的任何连续段进行恒定时间异或查询$n$元素。 
2. 对于每个查询$l$，检查是否$l \le n$。 如果是，则返回`a[l-1]`直接地。 这处理请求的索引位于输入数组内部的边缘情况。 
3.如果$l > n$,初始化一个变量`index = l`。 尽管`index > n`， 代替`index`和$\lfloor index / 2 \rfloor$。 这是有效的，因为递归仅取决于当前索引一半以内的元素的异或。 
4.一次`index <= n`，返回值`a[index - 1]`。 这利用了重复减半会产生已知元素的特性。 

为什么它有效：复发是根据以下定义的$\lfloor m/2 \rfloor$。 通过重复将任何大于的指数减半$n$，我们最终到达预先计算的前缀内的索引。 前缀 XOR 确保捕获此减少的所有依赖项。 此不变量保证不会丢失 XOR 值并且返回值是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, l, r = map(int, input().split())
        a = list(map(int, input().split()))
        # Prefix XOR array for quick lookup
        prefix = [0] * n
        prefix[0] = a[0]
        for i in range(1, n):
            prefix[i] = prefix[i-1] ^ a[i]
        def get_value(pos):
            while pos > n:
                pos //= 2
            return a[pos-1]
        # Since l = r, just compute single value
        print(get_value(l))

if __name__ == "__main__":
    solve()
```前缀 XOR 数组是为了在扩展需要时允许高效计算而准备的。 功能`get_value`重复将位置减半，直到它落在已知前缀内，这保证了正确性。 这避免了创建大型数组并尊重$l \le 10^{18}$边界。 单元素范围直接通过简单的打印处理。
