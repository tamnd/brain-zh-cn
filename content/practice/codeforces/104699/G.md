 ## 解决方案
 ## 问题理解

 我们有一个非常大的网格，高度$h$和宽度$w$，但只有少量有意义的单元格。 大多数单元格是空的，有些单元格包含阻止移动的岩石，有些单元格包含当路径通过它们时增加分数的值。 

路径从左上角单元格开始$(1,1)$并且必须在右下角单元格结束$(h,w)$。 每一步只允许向左、向右或向下移动。 禁止向上移动，这意味着路径从上到下逐行前进，但在一行内它可以在决定向下之前水平徘徊。 

每当路径进入具有奖励值的单元格时，该值就会添加到总分中。 有岩石的牢房根本无法参观。 

任务是选择一条有效的路径来最大化收集的总奖励。 

这些限制使得这个问题变得有趣。 网格宽度可达$10^9$，因此不可能存储或迭代所有列。 特殊细胞的数量最多为$10^5$，因此任何解决方案都必须主要依赖于这些单元而不是整个网格。 显式迭代行和列的解决方案最多需要$10^{14}$在最坏的情况下操作，因此是不可能的。 

一个关键的结构约束是行中的运动是单调的。 一旦我们从一排向下移动，我们就再也不会回来。 这强烈建议采用按行的动态编程方法。 

有一些微妙的边缘情况打破了天真的思维。 

如果一行不包含岩石，人们可能会错误地认为我们可以自由地将前一行中任何列的最佳值转移到下一行中的任何列。 这是错误的，因为垂直转换是列固定的：向下移动会保留列索引。 

当岩石劈开一排时，会出现另一种失败情况。 例如，考虑这样的行：```
. + . # + .
```天真的从左到右扫描会错误地允许影响力穿过岩石，但实际上岩石会阻止水平连接，因此同一行内的左侧无法到达岩石右侧的值。 

最后，一个常见的错误是假设只有垂直进入单元格才能收集奖励。 事实上，只要路径穿过单元格，包括水平遍历，就会收集奖励，这会改变行内传播的建模方式。 

## 方法

 强力解释将网格视为一个图，其中每个单元格都是一个节点，边连接左、右和下邻居。 在此图上运行最短路径或最长路径类型的 DP 在概念上很简单。 然而，网格最多包含$10^5 \times 10^9$节点，因此即使显式访问一小部分也变得不可能。 最坏情况下的状态数量远远超出了任何可行的计算。 

关键的观察是垂直移动严格来自行$i$划船$i+1$，并且在一行内不存在与移动本身相关的成本。 这意味着每一行的行为就像一个一维分段问题，我们可以在连接的分段内自由地重新分配 DP 值，除了岩石将行分成独立的部分。 

我们没有考虑单个单元，而是将每一行视为岩石之间间隔的集合。 在每个区间内，某个位置的最佳值取决于从前一行进入该区间的最佳切入点以及沿水平路径的累积奖励。 

这将问题简化为独立处理每一行，在固定列垂直传播 DP 值，然后在每个无岩石段内执行从左到右和从右到左的松弛。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 全网格图 DP |$O(hw)$|$O(hw)$| 太慢了|
 | 具有坐标压缩的行式分段 DP |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们逐行处理网格，只维护重要列而不是每一列的最佳可实现分数。 

1. 提取每行中的所有特殊列，包括奖励单元和岩石，并对它们进行排序。 我们还确保在第一列和最后一列对于转换很重要时予以考虑。 这是必要的，因为水平移动只会在发生某事的位置有意义地改变状态。 
2.维护字典`dp_prev`它存储前一行中每个相关列可达到的最佳分数。 最初，仅$(1,1)$值为 0。 
3. 对于当前行，我们首先计算一个尝试性的垂直过渡。 对于每一列$j$存在于这一行并且不是岩石，我们设置：$$dp_{cur}[j] = dp_{prev}[j] + value(j)$$如果一个细胞是一块石头，它就会被完全忽略。 此步骤模拟了这样一个事实：从上方输入单元格的唯一方法是直接从同一列。 
4. 现在我们必须考虑行内的水平移动。 岩石将行分成独立的部分。 在每个段内，我们计算两次扫描。 

在从左到右的扫描中，我们跟踪表格的最佳值：$$dp_{cur}[k] - prefix\_sum(k)$$这样我们就可以有效地将值更新到右侧。 

在从右到左的扫描中，我们以相反的方向对称地传播信息。 这确保了无论方向如何，都会考虑线段中任意两点之间的最佳路径。 
5.处理完所有段后，我们覆盖`dp_prev`和`dp_cur`，只为下一行保留有意义的位置。 
6. 处理完所有行后，答案就是存储在的值$(h,w)$，这必须是通过有效传播达到的。 

### 为什么它有效

 在固定的行段内，移动成本为零，并且除了岩石之外没有方向限制。 这使得段内的每条路径相当于选择一个入口点，然后扫到任何目标单元格，同时收集所有中间奖励。 DP 变换保留了以下不变量：`dp_prev[j]`代表进入行后可获得的最佳分数$i$在列$j$。 水平松弛步骤在不违反移动约束的情况下计算行内所有可达状态的闭合。 由于行按升序处理，垂直移动是列直线，因此未来的行无法追溯改进过去的决策，这保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict

NEG = -10**30

def solve():
    h, w, n = map(int, input().split())

    rows = defaultdict(list)
    has_start = False

    for _ in range(n):
        parts = input().split()
        i = int(parts[0])
        j = int(parts[1])
        if parts[2] == '#':
            rows[i].append((j, None))
        else:
            val = int(parts[3])
            rows[i].append((j, val))

    dp_prev = {1: 0}

    for i in range(1, h + 1):
        cells = rows.get(i, [])

        # collect columns in this row
        cols = set(dp_prev.keys())
        for j, v in cells:
            cols.add(j)

        cols = sorted(cols)

        blocked = set()
        reward = {}
        for j, v in cells:
            if v is None:
                blocked.add(j)
            else:
                reward[j] = v

        dp_cur = {j: NEG for j in cols}

        # vertical transitions
        for j in cols:
            if j in blocked:
                continue
            if j in dp_prev:
                dp_cur[j] = dp_prev[j] + reward.get(j, 0)

        # horizontal propagation per segment
        new_dp = dp_cur.copy()

        # left to right
        best = NEG
        for j in cols:
            if j in blocked:
                best = NEG
                continue
            best = max(best, dp_cur[j])
            if best != NEG:
                new_dp[j] = max(new_dp[j], best + reward.get(j, 0))

        # right to left
        best = NEG
        for j in reversed(cols):
            if j in blocked:
                best = NEG
                continue
            best = max(best, dp_cur[j])
            if best != NEG:
                new_dp[j] = max(new_dp[j], best + reward.get(j, 0))

        dp_prev = new_dp

    ans = dp_prev.get(w, 0)
    print(ans)

if __name__ == "__main__":
    solve()
```该实现维护每行动态编程状态的稀疏表示。 字典`dp_prev`避免在整个宽度上迭代，并且仅包含在转换中重要的列。 

垂直转换步骤强制执行从行到行的移动保留列索引的规则。 水平扫描模拟行段内的自由运动，同时在遇到岩石时重置。 

使用`NEG`确保无法到达的状态在扫描期间不会错误地传播值。 如果没有这个，无效的转换可能会污染可到达的段。

 ## 边缘情况

 完全分成孤立的单单元段的行可以正确处理，因为每次遇到岩石时，扫描都会重置最佳传播值。 这可以防止任何 DP 值在行的断开部分之间泄漏。 

当一行中除起始列或结束列之外的所有列都被阻塞时，垂直转换自然不会产生有效状态，并且 DP 仅通过可行位置正确传播。 

如果同一个连接段中存在多个奖励，则水平扫描可确保所有奖励都做出贡献，因为最佳前缀会连续前进，因此无论遍历顺序如何，都不会跳过奖励。
