 ## 解决方案
 ## 问题理解

 我们有一棵树，其中每个顶点代表一个核。 每个节点都有两个独立的属性，一个值可以被认为是它的中子计数，另一个可以被认为是它的质子计数。 树的边缘代表可能的相互作用，每次电荷移动穿过边缘时，电荷的值都会根据方向以及使用基于中子或基于质子的差异之间的选择而变化。 

更准确地说，当从节点 i 移动到节点 j 时，我们可以将当前电荷增加 aj − ai 或 bj − bi。 该过程从初始电荷等于 1 的特殊节点 s 开始，电荷通过树传播，以便每个节点根据沿着 s 的唯一路径所做的选择接收一些值。 

任务是确定此传播过程后任何节点上可能出现的最大电荷值。 

这些约束最多允许 10^5 个节点，这会立即排除任何为每个节点独立重新计算值或尝试枚举边缘转换的所有可能选择的解决方案。 任何在路径上进行指数分支甚至每个节点进行二次遍历的方法都太慢。 树结构表明，每个节点从一开始就通过唯一的路径到达，因此挑战不在于连接性，而在于沿着这些固定路径优化选择。 

朴素推理的一个微妙的失败案例是假设每个边独立地贡献其可能的最佳增量，而不考虑沿路径的一致性。 例如，贪婪地选择每条边的 max(bj − bi, aj − ai) 可能会失败，因为选择通过共享节点值进行交互。 

另一个陷阱是假设问题相当于全局选择所有 a 值或所有 b 值。 这也失败了，因为最佳选择可以将每个边缘混合，但结构仍然以受控方式伸缩。 

## 方法

 强力解释将尝试探索 a 或 b 对每个边遍历的所有可能分配。 由于从 s 到任何节点的每条路径的长度都达到 O(n)，因此在最坏的情况下这会导致 2^(n) 种可能的组合。 即使将我们限制在路径上的动态规划也无济于事，因为在没有结构的情况下重新计算每个节点的最佳值仍然会导致 O(n^2) 总工作量。 

关键的观察是，虽然每条边允许两种选择，但沿着路径的贡献可以重新组织，以便每个节点的效果变得独立于路径历史。 这样做的原因是，每次移动仅取决于节点值的差异，因此当沿着路径扩展总和时，内部节点的贡献会以结构化方式抵消，除非我们故意破坏对称性。 

如果我们检查节点出现在路径中时如何贡献，它要么充当差异的源，要么充当差异的目的地。 对于每次出现，我们独立选择使用 a 还是 b。 这将整个路径转换为每个节点外观的独立局部贡献的总和。 这将问题从路径依赖组合简化为简单的树累积。 

一旦以这种形式重写，每个节点都会贡献一个固定的最佳内部值，并且只有路径的端点需要特殊处理。 这允许来自 s 的单个 DFS。

 ## 算法演练

 我们以 s 为树根，并沿着从 s 向外的路径计算值。 

### 步骤

1. 将树的根设在 s 处。 这为每个节点固定了一个唯一的父节点，这使我们能够将路径推理为根到节点链。 方向很重要，因为边缘贡献取决于方向。 
2. 对于每个节点 i，计算两个局部量：ai 和 bi 的最大值以及 ai 和 bi 的最小值。 这些代表了节点做出积极或消极贡献时的最佳和最差选择。 
3.定义一个运行值dp[v]，表示从根s到节点v的累积贡献，不包括v本身的最终正贡献。 我们将 dp[s] 初始化为 −min(as, bs)，因为 s 仅充当沿第一条边的传出差值源。 
4. 从 s 使用 DFS 或 BFS 遍历树。 当从父级 u 移动到子级 v 时，将 dp[v] 更新为 dp[u] + (max(av, bv) − min(av, bv))。 这捕捉到了这样一个事实：内部节点沿着路径贡献一个正向事件和一个负向事件。 
5. 对于每个节点 v，将其最终可实现值计算为 dp[v] + max(av, bv)。 这增加了 v 作为终端节点的最佳可能传入贡献。 
6. 跟踪所有节点上的最大值。 

### 为什么它有效

 从 s 到 v 的每条路径都可以分解为路径上每个节点的贡献。 每个内部节点在边遍历中恰好出现两次，一次作为源，一次作为目的地。 因为我们可以在每次边遍历上独立选择a或b，所以最优策略是为正出现分配较大的值，为负出现分配较小的值。 这使得每个内部节点精确贡献 max(ai, bi) − min(ai, bi)，与路径结构无关。 端点打破了这种对称性，这就是为什么 s 和 v 是分开处理的。 这保证了 dp[v] 编码到 v 为止的最佳可能累积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, s = map(int, input().split())
    a = [0] + list(map(int, input().split()))
    b = [0] + list(map(int, input().split()))
    
    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    hi = [0] * (n + 1)
    lo = [0] * (n + 1)
    for i in range(1, n + 1):
        hi[i] = max(a[i], b[i])
        lo[i] = min(a[i], b[i])

    dp = [0] * (n + 1)
    visited = [False] * (n + 1)

    dp[s] = -lo[s]
    visited[s] = True

    ans = -10**30

    stack = [s]

    while stack:
        u = stack.pop()
        ans = max(ans, dp[u] + hi[u])

        for v in g[u]:
            if not visited[v]:
                visited[v] = True
                dp[v] = dp[u] + (hi[v] - lo[v])
                stack.append(v)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先为每个节点预先计算 hi 和 lo，以便每次转换都成为恒定时间。 DFS 堆栈确保我们只遍历每条边一次，从而保持线性复杂度。 dp 数组存储来自根的累积内部贡献，而最终答案是通过添加每个节点的最佳传入贡献来计算的。 

初始化 dp[s] = −lo[s] 编码了根没有传入边的事实，因此它在第一次转换中仅产生负贡献一次。 其他每个节点都通过 dp 转移公式做出正向和负向贡献。

 ## 边缘情况

 最小单节点树隔离初始化行为。 在这种情况下，dp[s] 为 −min(as, bs)，最终值变为 max(as, bs)，这正确地匹配了没有发生转换并且只有最佳内在节点值很重要的想法。 

二节点树强调第一条边的符号处理。 从 s 开始，转换必须正确应用单个 hi-lo 贡献，而不会重复计算任一端点。 

星形树测试多个子节点是否独立地从根继承相同的 dp 基数。 由于每个子节点使用 s 中相同的累积值，因此正确性取决于确保分支之间没有交叉污染，这是通过树遍历和独立 dp 更新来保证的。
