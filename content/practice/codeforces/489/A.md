 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，必须通过执行数组位置交换将其转换为非递减顺序。 有趣的是，我们不需要最小交换次数。 任何有效序列最多包含`n`互换被接受。 

输出由交换操作本身组成。 按打印顺序应用它们后，数组必须进行排序。 

数组长度最多为 3000。这足够小，可以`O(n²)`解决方案是完全可以接受的，因为`3000² = 9,000,000`操作，很容易符合限制。 不需要复杂的数据结构或`O(n log n)`技术。 

主要挑战来自重复值。 如果所有值都是不同的，我们可以简单地将每个值映射到排序数组中的目标位置。 对于重复项，多个位置可能包含相同的值，因此粗心的映射可能会将一次出现分配给多个目标位置。 

考虑：```
3
2 1 2
```排序后的数组为：```
1 2 2
```如果我们只映射值`2`对于“它在排序数组中的位置”，有两个有效位置。 将它们视为可互换而不跟踪个别事件可能会产生错误的交换。 

另一个边缘情况是已经排序的数组：```
4
1 2 3 4
```正确答案是：```
0
```某些实现不必要地执行交换，即使不需要。 

第三种情况是所有元素都相等：```
5
7 7 7 7 7
```同样，答案应该包含零交换。 任何仅基于价值比较的逻辑都必须避免为相同元素发明移动。 

## 方法

 一个蛮力的想法是重复找到应该出现在每个位置的最小元素并将其交换到位。 对于职位`i`，我们扫描后缀`i...n-1`，找到正确的元素，并根据需要执行一次交换。 

这种方法是正确的，因为固定位置后`i`，这个位置再也不会改变。 不幸的是，它需要一个`O(n)`扫描每个`n`位置，导致`O(n²)`时间。 

有趣的是，`O(n²)`这里已经足够快了。 真正的观察不是提高渐近复杂度，而是最多产生`n`交换，同时干净地处理重复值。 

关键思想是对数组的副本进行排序并维护每个元素的当前位置。 当位置`i`尚未包含其最终值，我们找到一个保存应在此处的值的位置并交换两个位置。 

每次交换永久固定一个位置。 由于只有`n`持仓量，掉期总数最多为`n-1`。 

为了使定位元素变得容易，我们对元素进行排序`(value, original_index)`。 这为每次出现的重复值提供了唯一的标识。 然后每个元素确切地知道它属于哪个最终位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最佳| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 将每个元素及其原始索引存储为`(value, index)`。 
2. 按值对这些对进行排序。 排序后，定位`i`该数组的 代表最终应占据位置的元素`i`按排序顺序。 
3. 创建数组`pos`在哪里`pos[original_index]`存储该元素在工作数组中的当前位置。 
4. 创建另一个数组`cur`在哪里`cur[position]`存储当前哪个原始元素占据该位置。 
5. 从左到右处理位置。 
6. 就位`i`，检查正确的元素是否已经存在。 正确的元素是其原始索引出现在排序对列表中的位置的元素`i`。 
7. 如果正确的元素已经在位置`i`， 继续。 
8. 否则，使用以下命令找到其当前位置`pos`。 
9.交换两个位置`cur`，更新他们的条目`pos`，并记录交换。 
10. 继续，直到每个位置都包含其指定元素。 

每次交换都会将正确的元素放入其最终位置。 这个立场再也不会改变。 

### 为什么它有效

 排序后的列表`(value, original_index)`pairs 为每个值的每次出现分配一个唯一的目的地。 即使是重复项也变得可以区分，因为它们的原始索引不同。 

在步骤`i`，如果正确的元素尚不存在，我们将该元素精确移动到位置`i`。 交换后位置`i`包含按排序顺序为其指定的元素。 

由于后面的操作仅影响大于或等于的头寸`i+1`， 位置`i`永远保持正确。 对每个位置重复此参数最终会生成完全排序的数组。 

由于每次交换至少固定一个新位置，因此交换数量永远不会超过`n-1`，满足问题要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    sorted_pairs = sorted((a[i], i) for i in range(n))

    cur = list(range(n))
    pos = list(range(n))

    swaps = []

    for i in range(n):
        target_id = sorted_pairs[i][1]

        if cur[i] == target_id:
            continue

        j = pos[target_id]

        swaps.append((i, j))

        x = cur[i]
        y = cur[j]

        cur[i], cur[j] = cur[j], cur[i]
        pos[x], pos[y] = pos[y], pos[x]

    print(len(swaps))
    for i, j in swaps:
        print(i, j)

solve()
```该解决方案从不直接重新排列值。 相反，它重新排列表示元素原始位置的标识符。 

数组`sorted_pairs`确定每个原始元素在最终排序顺序中所属的位置。 数组`cur`告诉我们当前哪个原始元素占据每个位置，而`pos`提供逆映射。 

当发生交换时，两个结构必须一致更新。 忘记更新`cur`或者`pos`是最常见的实现错误，并且会立即中断未来的查找。 

该算法从左到右固定位置。 一旦一个位置被固定，就不会再被触及。

 ## 边缘情况

 考虑重复值的情况：```
3
2 1 2
```排序后的配对列表变为：```
(1,1) (2,0) (2,2)
```值的两次出现`2`仍然可以区分，因为它们的原始索引不同。 该算法将一个副本分配给位置 1，另一个副本分配给位置 2。不存在歧义，因此结果数组已正确排序。 

考虑一个已经排序的数组：```
4
1 2 3 4
```排序后的配对列表与当前的排列相匹配。 对于每个职位`i`,`cur[i]`已经等于所需的原始索引。 没有记录交换，输出很简单：```
0
```考虑所有元素相等：```
5
7 7 7 7 7
```排序`(value, index)`由于索引是不同的，所以对保留了它们的顺序。 每个位置都已经包含其指定的元素，因此同样不会发生交换。 该算法自然会输出零操作。 

这些案例说明了为什么通过其原始索引为每个事件分配唯一标识是使解决方案正确的关键细节。
