 ## 解决方案
 ## 问题理解

 我们沿河有一系列休息点。 观点`i`位于位置`x[i]`并且具有风景如画的价值`b[i]`。 旅行者从坐标开始`0`并且必须在最后一个休息点完成，这也是最远的一个。 

如果旅行者离开位置`p`定位`q`一天之内，当天走过的距离是`q - p`。 他每天的理想距离是`l`，所以那天造成的挫败感等于$$(q-p-l)^2.$$路线是任何以点结束的休息点的递增序列`n`。 对于选定的路线，$$F = \sum ( \text{daily distance} - l )^2$$是总的挫败感，并且$$B = \sum b_i$$是所访问的休息点的总风景如画。 

要最小化的数量是$$\frac{F}{B}.$$输出不是这个比率的值。 我们必须自己打印一条最佳路线。 

第一个挑战是目标是一个比率。 动态规划通常处理附加成本，但这里的分子和分母取决于整个路径。 

约束足够小以允许二次动态规划。 我们最多有`1000`休息点。 一个图的顶点是静止点，其边代表可能的跳跃，该图包含大约一百万个有向边。 一个`O(n²)`DP 是完全可以接受的，而指数枚举路线是不可能的。 

一个微妙之处是路线可能会跳过任意​​休息点。 另一个微妙的点是，如画只是为访问过的点积累的，而挫败感则取决于每一次跳跃。 任何贪婪地选择当地良好跳跃的方法都很容易失败，因为风景如画的地点可能会证明更糟糕的行程安排是合理的。 

考虑：```
n = 2, l = 10

(10, 1)
(20, 1000)
```使用这两点都会让人沮丧`0 + 0 = 0`， 比率`0`。 

直接进入第2点会让人沮丧`(20-10)^2 = 100`， 比率`100/1000 = 0.1`。 

即使两条路线的终点相同，最佳路线也会使用更多的点。 

另一个容易犯的错误是忘记旅程从坐标开始`0`。 为了```
1 10
20 5
```唯一的一天覆盖了距离`20`， 不是`0`。 挫败感是`(20-10)^2 = 100`。 

## 方法

 强力解决方案将枚举中间休息点的每个子集，并检查在该点结束的每条可能的路线`n`。 由于每个点都可能被使用或跳过，因此大致有`2^(n-1)`路线。 和`n = 1000`，这是完全不可行的。 

比率目标提出了一种经典的优化技巧。 假设我们以某种方式知道最佳比率`R`。 那么一条路线在什么时候是最佳的$$\frac{F}{B} \le R.$$乘以`B > 0`给出$$F - R B \le 0.$$这会将比率转换为加法表达式。 

现在想象一下确定一个候选值`C`。 将路径的成本定义为$$F - C B.$$如果该表达式的最小可能值为负，则某些路由满足$$\frac{F}{B} < C.$$如果最小值为正，则每条路线的比率都大于`C`。 

这将原始问题变成了适合二分搜索的决策问题。 

对于固定的`C`，路径成本变为$$\sum \Big((x_i-x_j-l)^2\Big) - C \sum b_i.$$该表达式是沿路径相加的。 这意味着我们可以使用动态规划来计算最小值。 

让`dp[i]`是结束于点的路线的最小变换成本`i`。 

然后$$dp[i] = -C b_i + \min_j \left( dp[j] + (x_i-x_j-l)^2 \right),$$在哪里`j < i`。 

起始位置`0`行为类似于具有坐标的虚拟节点`0`和成本`0`。 

由于每个转换都会被检查，复杂度为`O(n²)`每次 DP 运行。 

通过二分查找找到最佳比例`C`。 在获得足够精度后，最后一次 DP 运行将重建路径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳| O(n² log M) | O(n² log M) | O(n) | 已接受 |

 这里`M`是答案的搜索范围。 

## 算法演练

 1. 存储所有坐标和风景值。 
2. 对答案进行二分查找`C`。 
3.对于固定的`C`，运行动态规划。 
4.让`dp[i]`表示最小值$$F - C B$$在所有以点结束的路线中`i`。 
5、处理起始坐标`0`作为虚拟顶点。 

从起点直接到点的过渡`i`有成本$$(x_i-l)^2 - C b_i.$$6. 对于每对`j < i`， 放松$$dp[j] + (x_i-x_j-l)^2 - C b_i.$$这对应访问点`i`紧接在点之后`j`。 
7. 填写DP表后，检查`dp[n]`。 

如果`dp[n] < 0`，那么某些路线的比率小于`C`，因此将二分查找区间向下移动。 

否则向上移动。 
8. 重复二分查找大约六十次。 双精度很容易支持这一点。 
9. 使用结果值最后一次运行 DP`C`。 
10. 在计算转换时，存储产生最佳值的前身。 
11. 通过从点向后跟随前驱指针来重建路线`n`。 
12. 反转重建的序列并打印它。 

### 为什么它有效

 对于任何固定值`C`, DP 计算$$\min_{\text{route}} (F - C B).$$如果该最小值为负，则某些路线满足$$F - C B < 0,$$这相当于$$\frac{F}{B} < C.$$如果最小值非负，则每条路线至少有比率`C`。 

因此，最小变换成本的符号准确地回答了是否`C`高于或低于最佳比率。 二分搜索收敛到最小的可行比率。 

最终的 DP 是以任意接近最优比率的值来求解变换后的问题。 标准分数规划理论保证在此值最小化变换目标的任何路线都是原始比率目标的最佳路线。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, l = map(int, input().split())

    x = [0] * (n + 1)
    b = [0] * (n + 1)

    for i in range(1, n + 1):
        x[i], b[i] = map(int, input().split())

    def dp_run(C, restore=False):
        INF = 1e100

        dp = [INF] * (n + 1)
        parent = [-1] * (n + 1)

        for i in range(1, n + 1):
            best = (x[i] - l) ** 2 - C * b[i]
            par = 0

            for j in range(1, i):
                cand = dp[j] + (x[i] - x[j] - l) ** 2 - C * b[i]
                if cand < best:
                    best = cand
                    par = j

            dp[i] = best
            parent[i] = par

        if not restore:
            return dp[n]

        path = []
        cur = n

        while cur:
            path.append(cur)
            cur = parent[cur]

        path.reverse()
        return path

    lo = 0.0
    hi = 1e12

    for _ in range(70):
        mid = (lo + hi) / 2.0

        if dp_run(mid) < 0:
            hi = mid
        else:
            lo = mid

    path = dp_run(hi, True)
    print(*path)

if __name__ == "__main__":
    solve()
```关键的例程是`dp_run(C)`。 对于固定的候选比例`C`，它计算最小转换成本。 虚拟起始位置由直接转换处理$$(x_i-l)^2 - C b_i.$$没有明确的顶点`0`DP 表中需要。 

过渡会考虑每个较早的休息点。 自从`n`只是`1000`，二次环足够小。 

二分搜索保持了真正的最佳比率位于内部的不变性`[lo, hi]`。 每当变换后的最优值变为负数时，我们知道`mid`大于答案，因此上限向下移动。 

重建运行使用完全相同的 DP，但存储负责最佳过渡的前身。 继前辈之后`n`以相反的顺序产生最佳路线。 

一个常见的实现错误是使用上次二分搜索迭代的中点进行重建。 使用最终上限`hi`更安全，因为它在整个搜索过程中保持在可行的一侧。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n² log M) | O(n² log M) | 每次二分搜索迭代一个 O(n²) DP |
 | 空间| O(n) | DP 和前代阵列 |

 ## 边缘情况

 考虑：```
1 10
20 5
```只有一条路线。 DP 计算$$(20-10)^2 - C \cdot 5.$$起始位置被正确视为坐标`0`，所以每日距离为`20`。 重建输出`1`。 

考虑：```
2 10
10 1
20 1000
```使用两个点收益率`0`。 直接进入正题`2`收益率`100/1000 = 0.1`。 

DP 通过其转换来比较两种可能性。 路线`1 -> 2`产生转化成本`-1001C`，而直接路线产生`100 - 1000C`。 接近最佳比例时，第一个表达式较小，因此重构返回`1 2`。 

考虑：```
3 10
10 1
11 1000
20 1
```贪婪策略可能会访问点`2`因为它的风景如画。 民主党不做出地方决定。 它评估完整的路线成本，包括访问点造成的不良跳跃长度`2`。 每个状态中只有全局最优的前驱存活，因此最终的路线仍然是正确的。
