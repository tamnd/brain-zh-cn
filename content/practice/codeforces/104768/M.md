 ## 解决方案
 ## 问题理解

 我们有一排卡片，每张卡片上都写着两个数字。 对于每个位置，一个数字最初面朝上，另一个数字面朝下。 初始配置是固定的：我们在卡 i 上看到的值为$a_i$， 尽管$b_i$隐藏在下面。 

我们最多可以执行一个操作：选择一个连续的卡片段并翻转该段中的每张卡片，交换其中所有卡片的可见数字和隐藏数字。 执行此操作后，每个位置仍然准确地显示一个数字，来自原始顶侧或来自翻转的底侧，具体取决于它是否位于所选段内。 

一旦形成最终的可见数组，我们就计算它的中值，定义为$(n+1)/2$- 所有可见数字中的第一个最大值。 自从$n$很奇怪，这是一个明确定义的中阶统计量。 

目标是最佳地选择分段（或选择根本不翻转），以便该中位数变得尽可能大。 

约束条件达到$3 \cdot 10^5$，这立即排除了所有区间内的任何二次或分段暴力方法。 甚至$O(n^2)$扫描所有可能的翻转太慢，因为有$O(n^2)$段。 这促使我们寻求一种解决方案，避免显式尝试间隔，而是将问题简化为可以在线性时间内评估的单调可行性检查，很可能在对答案的二分搜索中进行评估。 

一个微妙的点是，每个元素的操作不是独立的：我们不能自由选择每张卡是否采取$a_i$或者$b_i$。 选择必须来自单个连续的翻转段，这引入了全局结构约束。 任何独立决定每个索引的天真贪婪都会失败。 

作为陷阱的一个例子，假设我们可以独立地选择更好的$a_i$和$b_i$。 这会高估答案，因为它忽略了“单段”限制。 

另一个失败案例是尝试在不优化检查的情况下为每个候选中值暴力破解最佳片段。 简单的模拟会重复地重新计算每个间隔的计数，即$O(n^2)$每个测试想法都立即不可行。 

## 方法

 直接的暴力方法将枚举每个可能的部分$[l, r]$，模拟翻转它，然后计算结果数组的中位数。 每次计算中位数都需要排序或选择过程，即$O(n)$如果仔细完成的话，每个间隔。 由于有$O(n^2)$间隔，这大致导致$O(n^3)$总工作量，即使对于较小的约束，也远远超出了限制。 

关键的结构转变是不再考虑显式构造最终数组，而是考虑候选中值是否$x$是可以实现的。 如果我们固定一个阈值$x$，问题就变成：我们至少可以做$k = (n+1)/2$最终数组中的元素大于或等于$x$？ 

一旦以这种方式重新构建，每张卡都会独立地对“好或坏”分类做出贡献，具体取决于其可见值是否至少为$x$。 唯一的复杂之处是翻转段会改变可见的值，因此每个位置都有两种可能的状态，对好元素的计数有不同的贡献。 

这导致了一个干净的转换：我们从基线配置（无翻转）开始，计算有多少位置已经满足$a_i \ge x$，然后解释翻转$[l, r]$作为修改该部分的贡献。 段中的每个索引要么提高计数，要么恶化计数，要么没有效果，具体取决于是否从$a_i$到$b_i$跨过门槛。 

这将问题简化为在 +1、-1 和 0 值的数组上查找最大子数组和，这可以使用 Kadane 算法在线性时间内解决。 然后我们检查最佳可能的改进是否仍然允许达到至少$k$good elements.

 由于可行性是单调的$x$，我们对输入中出现的所有值进行二分搜索答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 通过模拟对间隔进行暴力破解 |$O(n^3)$|$O(n)$| 太慢了|

 ## 算法演练

 我们将任务简化为检查是否为固定值$x$可以作为中位数。 

## 算法演练

 1. 固定候选值$x$并将“好”位置的概念定义为可见数量至少为$x$。 我们的目标是看看我们是否能够至少实现$k = (n+1)/2$好的职位。 
2. 如果我们不翻转任何东西，计算好位置的基线数量。 这只是索引的计数，其中$a_i \ge x$。 
3. 对于每个指数，确定翻转如何影响其贡献。 如果我们在 i 处保持不变，贡献取决于$a_i$。 如果翻转的话，取决于$b_i$。 在翻转段中包含 i 引起的变化是以下三种情况之一：如果$a_i < x \le b_i$，如果$a_i \ge x > b_i$，或者不执行任何其他操作。 
4. 将每个位置编码为一个值$w_i$， 在哪里$w_i = +1$为了获得收益，$w_i = -1$造成损失，并且$w_i = 0$否则。 任何选择的翻转段贡献的总和$w_i$超过该间隔。 
5. 计算最大子数组和$w$。 这代表通过选择最佳翻转段可实现的最佳改进。 我们也允许不选择任何分段，因此改进至少为 0。 
6. 最佳可实现的良好元素数量$x$是基线加上最大改进。 如果这个值至少是$k$， 然后$x$是可行的。 
7. 对所有可能值进行二分搜索$x$出现在输入中，使用可行性检查作为谓词。 

### 为什么它有效

 对于固定阈值$x$，一旦我们决定它是否位于翻转的部分内，每张卡都会独立地影响它是否有助于或损害“好”元素的计数。 唯一的全局约束是翻转的索引必须形成单个连续的块。 该约束正是最大子数组和所捕获的内容：任何有效的翻转都对应于连续的间隔，并且任何间隔都对应于有效的翻转。 因此，优化中位数减少为选择使超过阈值的元素计数的净收益最大化的区间。 二分搜索然后利用单调性：如果我们至少可以实现中位数$x$，我们也可以用任何较小的值来实现它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can(x, a, b, k):
    n = len(a)
    base = 0

    w = [0] * n
    for i in range(n):
        ai, bi = a[i], b[i]

        if ai >= x:
            base += 1

        if ai < x and bi >= x:
            w[i] = 1
        elif ai >= x and bi < x:
            w[i] = -1
        else:
            w[i] = 0

    best = 0
    cur = 0
    for v in w:
        cur = max(0, cur + v)
        best = max(best, cur)

    return base + best >= k

def solve():
    n = int(input())
    a = []
    b = []

    for _ in range(n):
        x, y = map(int, input().split())
        a.append(x)
        b.append(y)

    k = (n + 1) // 2

    vals = list(set(a + b))
    vals.sort()

    lo, hi = 0, len(vals) - 1
    ans = vals[0]

    while lo <= hi:
        mid = (lo + hi) // 2
        x = vals[mid]

        if can(x, a, b, k):
            ans = x
            lo = mid + 1
        else:
            hi = mid - 1

    print(ans)

if __name__ == "__main__":
    solve()
```该代码将可行性检查与答案搜索分开。 这`can`函数计算已经好的卡片的基线数量，然后构建表示翻转任何部分的效果的增益/损失数组。 Kadane 的算法以其最简单的形式出现：我们维护运行的最佳子数组总和，同时允许重置为零，这隐式处理“选择不翻转”选项。 

二分搜索遍历卡片两侧的所有不同值。 这已经足够了，因为只有当阈值超过这些值之一时，答案才会改变。 

一个微妙的实现细节是用最小值初始化答案，因为可行性是单调递减的$x$。 如果中间值有效，我们就向上推； 否则我们就会向下走。

 ## 边缘情况

 一个关键的边缘情况是翻转在任何地方都是有害的。 在那种情况下所有$w_i \le 0$，因此 Kadane 自然返回零，并且算法回退到未翻转的配置。 例如，如果每个$a_i$已经很大并且每个$b_i$较小时，最好的策略是完全避免翻转，可行性检查反映了这一点，不会产生任何积极的收益。 

另一个微妙的情况是当收益和损失交织在一起时。 该算法可以处理此问题，因为 Kadane 仅选择累积增益为正的连续区域。 如果有利的指数是分散的，则不会强制将有害的头寸纳入其中。 

最后一个极端情况是最佳间隔是整个数组。 当几乎每个索引都受益于交换时就会发生这种情况。 然后，子数组总和在整个范围内自然增长，并且 Kadane 无需特殊处理即可正确地将整个区间识别为最佳区间。
