 ## 解决方案
 ## 问题理解

 给定两个字符串集合，每个集合包含相同数量的字符串，并且每个字符串具有相同的固定长度。 任务是独立地对每个集合内的字符串重新排序，然后将每个重新排序的集合连接成一个长字符串。 之后，我们比较两个生成的长字符串，但有一个变化：一个允许循环旋转，这意味着我们可以在任何位置切割它并将前缀移动到末尾。 

因此，真正的问题是我们是否可以对两个集合中的字符串进行排列，以便在进行一些字符循环移位后两个连接的字符串变得相同。 

每个测试用例都是独立的。 我们要么需要输出描述有效重新排序的索引的两个排列，要么报告这是不可能的。 

总大小的限制比每个测试的限制更严格。 所有测试用例的所有字符总和最多为一百万，因此任何解决方案都必须在每个测试用例的线性时间内运行。 任何涉及字符串之间的嵌套比较或尝试所有重新排序的操作都是立即不可行的。 

当所有字符串看起来非常相似但与多重集不同时，就会出现微妙的边缘情况。 例如，如果 A 包含 {"aa", "ab"} 并且 B 包含 {"aa", "ac"}，则即使在旋转后，重新排列也无法使连接的字符串匹配，因为一个集合包含另一个集合不包含的字符模式。 一个幼稚的想法可能会尝试在不检查多重集相等性的情况下对齐最终串联的旋转，这会错误地认为单独的重新排列始终足以修复不匹配。 

## 方法

 蛮力解释首先从直接思考排列开始。 我们可以尝试 A 的每种排序和 B 的每种排序，构建两个连接的字符串，并检查其中一个是否是另一个的循环旋转。 这在概念上是简单且正确的，因为它明确地匹配定义。 然而，它是 n 的阶乘，甚至每次尝试构建和比较字符串的成本都是 O(nm)，这远远超出了任何可行的限制。 

关键的观察是循环旋转作用于最终的连接字符串，而不是单个块。 如果两个串联是彼此的循环移位，则它们必须以完全相同的重数包含完全相同的字符，更重要的是，必须在整个构造中保留长度为 m 的块的相同多重集。 由于我们可以在每个序列内任意排列，因此唯一的结构要求是两个序列都由完全相同的字符串多重集组成。 

一旦实现这一点，循环条件在更深的意义上就变得无关紧要了。 如果两个字符串多重集相同，我们可以简单地为两个序列选择相同的排序。 那么连接的字符串实际上是相等的，这是具有移位零的循环同构的特殊情况。 如果多重集不同，则任何重新排序都无法修复该差异，因为排列不会创建或销毁字符串。 

这将问题从复杂的全局对齐问题简化为简单的多集比较问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力排列 | O(n!·n·m) | O(n!·n·m) | O(纳米) | 太慢了|
 | 多集匹配 | O(nm log n) 或 O(nm) | O(纳米) | 已接受 |

 ## 算法演练

 我们现在将观察结果转化为建设性的程序。

1. 读取测试用例的两个字符串列表，并将每个字符串与其在输入中的原始索引相关联。 
2. 根据字符串内容按字典顺序对两个列表进行排序。 这允许相同的字符串按顺序自然对齐。 
3. 排序后，逐位置比较两个字符串序列。 如果出现任何不匹配，则意味着多重集不相同并且不存在有效的排列，因此我们输出-1。 
4. 如果它们匹配，则通过按排序顺序获取索引来构造两个排列。 A的排列是A排序后的顺序，B也是如此。 
5. 输出这两个排列。 

排序足够的关键原因是它提供了多重集的规范表示。 如果两个多重集相等，则它们的排序表示相同，并且相同元素之间的任何配对都是有效的。 

### 为什么它有效

 连接字符串之间的循环同构仅取决于最终字符串内容，而不取决于字符串内部如何分组为块。 由于我们可以在两个序列中任意排列块，因此每当底层多重集匹配时，我们总是可以按相同的顺序对齐相同的字符串。 这会产生相同的连接字符串，这很容易满足循环等价。 如果多重集不同，则至少有一个字符串的频率不同，并且没有任何排列或旋转可以协调这种不匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n, m = map(int, input().split())
        
        A = []
        B = []
        
        for i in range(n):
            A.append((input().strip(), i + 1))
        for i in range(n):
            B.append((input().strip(), i + 1))
        
        A.sort()
        B.sort()
        
        ok = True
        for i in range(n):
            if A[i][0] != B[i][0]:
                ok = False
                break
        
        if not ok:
            out.append("-1")
            continue
        
        p = [str(x[1]) for x in A]
        q = [str(x[1]) for x in B]
        
        out.append(" ".join(p))
        out.append(" ".join(q))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案首先将字符串及其索引分组，以便排序不会丢失原始位置。 排序纯粹是根据字符串内容进行的，这是安全的，因为相同的字符串是可以互换的。 排序后，直接检查两个序列是否相等。 如果匹配，则输出对应的索引顺序； 否则我们报告不可能。 

一个常见的实现陷阱是在排序过程中忘记保留原始索引，这将导致无法重建所需的排列。 另一个微妙的问题是有效地处理多个测试用例，而不会错误地重新初始化全局状态。 

## 工作示例

 考虑两个集合都可以匹配的情况：

 输入：

 A = [“abc”，“def”，“ghi”]

 B = [“bcd”，“efg”，“hia”]

 排序后，我们对齐相同的字符串。 如果它们是相同的多重集，排序顺序将完全匹配，并且我们将为两者输出相同的排列结构。 

现在考虑一个不匹配的情况：

 A = [“abc”]

 B = [“定义”]

 | 步骤| 已排序 | B 排序 | 比赛|
 | ---| ---| ---| ---|
 | 排序后 | ABC | 定义 | 没有 |

 由于唯一的元素不同，算法立即返回 -1，这表明没有排列可以弥补差距。 

这表明该算法将问题简化为纯粹的多重集相等性检查。

 ## 边缘情况

 如果所有字符串都相同，则两个排序数组基本匹配。 该算法输出任何相同的排序，并且立即满足循环移位，因为两个连接的字符串是相同的。 

如果存在大量重复项，例如许多重复的字符串，排序仍然可以正确地将它们分组。 该算法不依赖于唯一性，并且相同的块可以互换，因此任何稳定的排列都是有效的。 

如果两个多重集之间只有一个字符串不同，排序将暴露单个位置的不匹配情况。 该算法正确地拒绝了这种情况，而无需尝试任何旋转推理，这将是无关紧要的，因为没有旋转可以修复丢失或额外的块。
