 ## 解决方案
 ## 问题理解

 我们被赋予了一组$n$必须将学生分成正好两个小组。 两队必须非空。 还有一个下界$k$，这意味着每个团队必须至少包含$k$学生。 在每个团队内部，学生需要组成不相交的双人组进行热身练习，这会带来额外的结构性限制：一个团队必须包含偶数数量的学生，否则将有一个学生无法匹配。 

所以任务纯粹是可行性检查：确定是否存在分裂$n = a + b$使得两者$a$和$b$都是正数，至少两者都是$k$，并且两者都是偶数。 

约束条件非常大，$n$最多$10^9$。 这立即排除了对可能的分裂的任何构建或搜索。 任何有效的解决方案都必须将问题减少到恒定数量的算术检查。 

一个微妙但重要的边缘条件是“非空团队”与约束之间的相互作用$k = 0$。 即使$k = 0$，该语句仍然要求两个团队都非空，因此每个团队必须至少有一名学生，同时每个团队必须允许配对，强制大小相等。 这意味着每个团队的真正下限不仅仅是$k$，但也至少$1$，与均匀度相结合。 

一个幼稚的错误是仅强制被 2 整除或仅强制最小大小，而不正确组合这两个约束。 例如，如果$n = 4$和$k = 3$，人们可能会错误地认为这是可能的，因为$4 \ge 2k$，但不存在满足两支球队至少为 3 的平分。 

## 方法

 蛮力方法会尝试所有可能的团队规模$a$从$1$到$n-1$， 放$b = n - a$，并检查两者是否满足约束：至少非空$k$，甚至。 这可以正常工作，因为它直接枚举所有分区，但是当$n$很大。 在最坏的情况下它执行$O(n)$检查，这是不可能的$n$最多$10^9$。 

关键的观察结果是，唯一有意义的候选者是偶数。 由于两队都必须分成两队，$a$和$b$必须是均匀的。 这立即意味着$n$本身一定是偶数，因为两个偶数之和是偶数。 

一旦我们限制为偶数尺寸，问题就变成了选择偶数$a$这样：$a \ge k$,$b = n - a \ge k$，并且两者自动保持偶数，如果$n$是均匀的。 

因此，最小有效团队规模不是$k$，但至少是最小的偶数$\max(k, 1)$，因为团队也必须是非空的。 一旦我们选择了最小的可行均匀尺寸$L$，可行性条件简化为检查我们是否可以至少分配$L$每个团队的学生，即是否$2L \le n$。 

该问题归结为恒定时间算术检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解 |$O(n)$|$O(1)$| 太慢了|
 | 奇偶校验和界限减少 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将所有约束转换为单个最小有效团队规模，然后检查两个这样的团队是否适合$n$。 

1. 计算每个团队所需的最小规模：$m = \max(k, 1)$。 这既强化了教师的约束，又强化了团队不能为空的要求。 
2. 圆形$m$直到最接近的偶数。 调用这个值$L$。 如果$m$已经是均匀的，$L = m$。 否则，$L = m + 1$。 这确保了每个团队可以在内部分成对。 
3. 检查是否$n$是均匀的。 如果是奇数，则立即返回“NO”，因为两个偶数规模的球队的总和不能为奇数。 
4. 检查是否$n \ge 2L$。 如果这种情况成立，则将一个团队的规模分配为$L$另一个作为$n - L$，两者都是偶数且至少$k$。 
5. 如果两个条件都成立，则输出“YES”，否则输出“NO”。 

步骤 3 背后的原因是在加法中保留了奇偶性，因此两个偶数之和不能产生奇数总和。 步骤 4 保证即使在满足配对约束后，仍然有足够的质量来同时满足两个团队的需求。 

### 为什么它有效

 该算法通过将每个可行的团队规模减少到最小可能的有效偶数规模来表征所有有效的解决方案$L$。 任何有效的分区必须至少具有两个部分$L$，因为任何较小的值要么违反最小大小，要么破坏配对奇偶校验。 如果两个这样的最小有效块已经超过$n$，在不破坏均匀性或下限约束的情况下，任何再分配都无法修复赤字。 相反，如果$2L \le n$，我们可以通过将一支球队视为$L$并均匀分配剩余部分以保持奇偶性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
k = int(input())

m = max(k, 1)

if m % 2 == 0:
    L = m
else:
    L = m + 1

if n % 2 == 1:
    print("NO")
else:
    if n >= 2 * L:
        print("YES")
    else:
        print("NO")
```该实现直接反映了导出的条件。 的计算$m = \max(k, 1)$处理非空要求。 舍入为$L$强制配对可行性。 奇偶校验打开$n$是必不可少的且不能跳过，因为它会立即排除所有奇数总数。 最后，不等式$n \ge 2L$保证两个团队能够同时满足所有约束。

 ## 边缘情况

 一个重要的边缘情况是当$k = 0$。 尽管似乎没有最低要求，但团队仍然必须是非空的，因此有效下界变为 1，而在强制配对后，它变为 2。例如，$n = 4, k = 0$，算法计算$m = 1$， 然后$L = 2$，并且自从$n = 4 \ge 4$，它返回 YES，对应于 2 和 2 的分割。 

另一种边缘情况发生在$n$很奇怪。 例如，$n = 7, k = 2$。 即使两支球队各自都能满足规模限制，奇偶性也使得任何分裂都是不可能的，因为两个偶数总和不能为奇数。 该算法立即通过以下方式检测到这一点$n \% 2$查看。 

更微妙的情况是当$k$相对于$n$。 例如，$n = 10, k = 6$。 这里$m = 6$,$L = 6$， 但$2L = 12 > 10$，因此即使每个团队单独满足约束条件，算法也会正确地拒绝该案例。
