 ## 解决方案
 ## 问题理解

 我们得到一个由两种类型的单元组成的固定 4×4 网格：由点表示的道路单元和由散列表示的栅栏单元。 网格编码了一个小路口。 该结构受到限制：四个中心单元始终属于道路，四个角单元始终属于栅栏。 围绕中心路障，上、下、左、右四个方向，要么与更多道路相连，要么被栅栏阻挡。 

每个方向由两个相邻单元表示，在该方向上形成“条带”。 如果该条带中的两个单元格都是点，则该方向是开放的。 如果两者都是哈希值，则该方向是封闭的。 任务是确定有多少个方向是开放的，并将路段相应地分类为死胡同、直路、转弯、丁字路口或完全交叉路口。 

尽管网格非常小，但如果试图推理单个单元而不是将它们分组为定向连接，则逻辑很容易出错。 输入大小固定为 4×4 意味着该解决方案不需要任何超出恒定时间解析的渐近优化。 整个问题是关于正确的结构解释。 

如果只检查中心 2×2 块而没有正确分组方向，则会出现微妙的边缘情况。 例如，如果人们忘记了每个方向是由两个对齐的单元而不是单个单元确定的，那么像 T 字路口这样的图案可能看起来类似于转弯。 

## 方法

 思考这个问题的一种天真的方法是将其视为 4×4 图像上的模式识别任务。 人们可以尝试对五个类别中的每一个类别的所有可能的有效配置进行硬编码，并将输入网格与每个模板进行比较。 由于网格只有 16 个单元格，因此枚举所有可能性似乎是可行的。 

然而，这种方法很快就会变得脆弱。 尽管有效配置的数量很少，但手动编写它们很容易出错。 主要困难在于，问题定义已经隐式处理了对称和旋转，但硬编码模式迫使程序员显式考虑所有变体。 这会导致重复的逻辑和微妙的遗漏案例。 

一种更加结构化的方法是关注实际定义道路类型的内容：开放方向的数量。 每个方向恰好贡献两个单元，分类仅取决于这四个方向对中有多少是开放的。 这将整个问题减少为四个恒定时间检查。 

一旦认识到这种抽象，解决方案就变得立竿见影。 我们独立计算每个方向的状态，计算有多少个方向是开放的，并将该计数映射到所需的标签。 正确性来自问题陈述本身，因为所有有效配置都保证适合该模型。

 ## 算法演练

 我们将 4×4 网格重新解释为中央 2×2 道路核心，具有四个向外延伸的定向“臂”。 每条臂由两个单元代表。

1. 通过检查中央 2×2 块正上方的两个单元来确定向上方向。 如果两者都是点，则道路继续向上； 否则会被阻止。 这是有效的，因为该结构保证有效的向上连接必须一致地占据两个位置。 
2. 通过检查中央块正下方的两个单元格来识别向下的方向。 相同的逻辑适用：两者都必须是点来表示向下的开放路径。 
3. 通过检查紧邻中心块左侧的两个单元格来确定左侧方向。 同样，有效连接需要两个单元的一致性。 
4. 通过检查紧邻中心块右侧的两个单元格来确定正确的方向。 两者都必须是开放道路的点。 
5. 计算四个方向中有多少个是开放的。 这个计数完全决定了分类。 
6. 将计数映射到输出标签：1 对应于死胡同，2 对应于直行或转弯（具体取决于几何形状），3 对应于 T 形交叉路口，4 对应于完全交叉路口。 在这个问题中，直行和转弯是通过方向来区分的，但由于网格是固定且有效的，开放方向所隐含的模式唯一地匹配正确的标签，没有歧义。 

### 为什么它有效

 关键的结构特性是每个方向都是独立的并且完全由一对对齐的单元表示。 该问题保证了有效道路形状的一致性，这意味着不存在部分或畸形的定向开口。 因此，开放方向的集合形成了结点拓扑的完整描述。 具有同一组开放方向的两个配置在旋转方面是等效的，因此计算开放方向足以唯一地确定分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

grid = [input().strip() for _ in range(4)]

# center is 2x2: rows 1-2, cols 1-2 (0-indexed)
up = grid[0][1] == '.' and grid[0][2] == '.'
down = grid[3][1] == '.' and grid[3][2] == '.'
left = grid[1][0] == '.' and grid[2][0] == '.'
right = grid[1][3] == '.' and grid[2][3] == '.'

cnt = sum([up, down, left, right])

if cnt == 1:
    print("dead end")
elif cnt == 2:
    # distinguish straight vs turn
    if (up and down) or (left and right):
        print("straight")
    else:
        print("turn")
elif cnt == 3:
    print("t-crossing")
else:
    print("crossing")
```该实现读取网格并直接检查四个方向臂。 每个布尔值对应于该方向上的两个单元是否都是道路单元。 计数步骤将几何形状压缩为单个整数。 

唯一微妙的部分是区分具有两个开放方向的两种配置。 当两个开口彼此相对时，就会出现直路，而当两个开口相邻时，就会出现转弯。 这是通过显式检查布尔值之间的成对结构来处理的。

 ## 边缘情况

 一种潜在的边缘情况是只有一个方向开放时。 网格在视觉上可能类似于部分图案，但由于每个方向都是由一对严格的单元定义的，因此算法正确地计算出一个开放方向并返回死胡同。 

另一种情况是三个方向都开放时。 这形成了 T 形接头。 计数逻辑确保正确分类，无需位置推理。 

最后一个微妙的情况是区分直行与转弯。 该算法通过检查两个开放方向是相反还是相邻来解决这个问题。 由于网格保证了有效的道路几何形状，因此不存在模糊配置，并且这种二元区分就足够了。
