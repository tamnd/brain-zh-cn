 ## 解决方案
 ## 问题理解

 我们得到一个代表城市和双向道路的无向连通图。 有些道路有一个特殊的属性：如果删除这样的道路会断开图形，那么该道路被认为是昂贵的。 每条昂贵的道路都有相同的单位成本，所有其他道路都是免费的。 

旅程被定义为在图表中行走，旅行者可以从任何地方开始，并且可以任意频繁地重新访问城市和道路，唯一的要求是每个城市至少访问一次。 目标是尽量减少旅行者在步行过程中被迫穿越昂贵道路的次数。 

关键点是，成本与进入城市或总体使用的道路数量无关，而是与我们穿过图中桥梁边缘的次数有关。 

约束多达二十万个顶点和边，这立即排除了任何尝试模拟行走或在每次使用边后重新计算连接的解决方案。 任何顶点或边数甚至是二次方的方法都会失败。 我们正在寻找线性或近线性图算法，通常类似于带有预处理的深度优先搜索。 

当图表根本不包含桥时，就会出现一种微妙的情况。 在这种情况下，每条路都是免费的，因此无论如何遍历，答案都是零。 另一个不明显的情况是当图已经是一棵树时。 那么每条边都是昂贵的，问题就相当于最小化我们遍历树边的频率，同时仍然访问所有节点。 

## 方法

 思考该任务的一个直接方法是想象我们正在规划一条明确的路线。 每次我们在城市之间移动时，当且仅当我们过桥时才需要付费。 因此，天真的想法是尝试构建一条访问所有顶点并最大限度地减少桥梁交叉数量的步行。 

一种强力的观点是将问题视为对（当前节点、访问集）对的状态空间搜索，但这会呈指数爆炸，显然是不可能的。 

即使我们简化并说我们只关心图的结构，我们仍然面临着桥的行为就像不可避免的瓶颈的问题。 每次桥遍历都是昂贵的，但在图的任何最大区域内，没有边是桥，移动是自由的。 这建议将每个这样的区域压缩到单个节点中。 

这导致了关键的观察：不是桥的边位于双连接组件内部，并且在每个这样的组件内部我们可以任意移动而无需成本。 将每个双连接组件收缩为单个节点后，每个剩余的边都是一座桥。 由此产生的结构是一棵树，通常称为桥树。 

现在的问题变成了：我们有一棵树，沿着一条边移动需要花费一个单位，并且我们希望一次遍历至少访问每个节点一次，同时最小化总的边遍历。 

在树上，任何覆盖所有顶点的行走都必须多次遍历边，除非它遵循精心选择的主干路径。 标准的想法是采用深度优先遍历：每条边都遍历两次，一次向下，一次返回。 这会产生两倍于边数的成本。 

然而，我们可以通过避免沿着单一路径回溯来改进这一点。 如果我们选择树中的一条路径作为遍历的主干，那么该路径上的边只能遍历一次，而所有侧分支仍然会遍历两次。 脊柱越长，我们支付两次的边缘就越少。 因此我们想要树中最长的简单路径，即直径。

如果桥树有 k 个节点，则它有 k 条边减去 1 个边。 最佳成本变为边数的两倍减去边的直径长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力状态搜索 | 指数| 指数| 太慢了|
 | 桥梁收缩+树径| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 使用具有发现时间和低链接值的深度优先搜索来识别原始图中的所有桥。 如果从 v 的子树到 u 的祖先没有后边，则边 (u, v) 是桥。 
2. 一旦知道了桥，就仅使用非桥边构建连接的组件。 每个组件代表一个可以自由移动的区域，因为其内部的边缘并不重要。 
3. 使用仅限于非桥边的 DFS 或 DSU 为每个顶点分配组件标识符。 这会产生收缩的图节点。 
4. 只要属于这些组件的任意两个顶点之间存在桥，就通过连接组件 u 和组件 v 来构建桥树。 
5. 使用两次广度优先搜索计算该树的直径。 首先从任意节点运行BFS来找到最远的节点a。 然后从 a 运行 BFS 来找到最大距离，即边的直径。 
6. 令 k 为组件数量，d 为桥树的直径。 答案是 2 倍（k 减 1）减 d。 

这种结构起作用的原因是，在组件内部我们可以自由移动而无需成本，因此只有组件之间的转换很重要，并且这些转换形成一棵树，其中每条边都有单位成本。 

### 为什么它有效

 收缩后，每条边都精确对应一座桥，因此每次付费移动都对应于组件之间的移动。 任何有效的遍历都对应于在这棵树上访问所有节点的遍历。 在覆盖所有节点的任何树遍历中，除了位于选定的简单路径上的边之外，每条边都必须至少使用两次，可以遍历一次而不会破坏未访问分支的连接性。 最大化单次遍历路径可以最小化总成本，即直径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    edges = []
    
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, i))
        g[v].append((u, i))
        edges.append((u, v))
    
    tin = [-1] * n
    low = [0] * n
    timer = 0
    is_bridge = [False] * m

    def dfs(v, pe):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, ei in g[v]:
            if ei == pe:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, ei)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    is_bridge[ei] = True

    dfs(0, -1)

    comp = [-1] * n
    comp_id = 0

    from collections import deque

    for i in range(n):
        if comp[i] == -1:
            q = deque([i])
            comp[i] = comp_id
            while q:
                v = q.popleft()
                for to, ei in g[v]:
                    if is_bridge[ei]:
                        continue
                    if comp[to] == -1:
                        comp[to] = comp_id
                        q.append(to)
            comp_id += 1

    if comp_id == 1:
        print(0)
        return

    tree = [[] for _ in range(comp_id)]
    for u, v in edges:
        cu, cv = comp[u], comp[v]
        if cu != cv:
            tree[cu].append(cv)
            tree[cv].append(cu)

    def bfs(start):
        dist = [-1] * comp_id
        dist[start] = 0
        q = deque([start])
        while q:
            v = q.popleft()
            for to in tree[v]:
                if dist[to] == -1:
                    dist[to] = dist[v] + 1
                    q.append(to)
        far = max(range(comp_id), key=lambda x: dist[x])
        return far, dist[far]

    a, _ = bfs(0)
    b, diameter = bfs(a)

    edges_tree = comp_id - 1
    print(2 * edges_tree - diameter)

if __name__ == "__main__":
    solve()
```实现首先使用标准低链路 DFS 计算所有桥。 递归仔细跟踪发现时间并传播最低的可达祖先。 任何不能通过后边缘绕过的边缘都被标记为桥。 

之后，通过运行忽略桥边的 BFS 将顶点分组为组件。 此步骤确保每个组件在自由运动下最大限度地连接。 

然后将压缩图显式构建为邻接列表。 由于多个原始边可能连接同一对组件，因此重复对于 BFS 直径计算并不重要。 

最后，两次 BFS 遍历计算桥树的直径。 答案使用之前推导的公式。 

## 工作示例

 考虑一个小图，它已经是一个由三个节点组成的树：1-2-3。 

| 步骤| 当前节点 | 行动| 组件数量 |
 | --- | --- | --- | --- |
 | 开始| 1 | 构建桥梁树（与图相同）| 3 |
 | 广度FS 1 | 1 | 找到最远的节点是 3 | 3 |
 | 广度FS 2 | 3 | 直径为 2 | 3 |

 树有 2 条边，所以答案是 2 * 2 减 2，即 2。这对应于走 1-2-3 而无需沿着完整路径返回。 

现在考虑一个带有叶子 3-4 的三角形 1-2-3-1。 

| 步骤| 组件结构| 桥树|
 | --- | --- | --- |
 | 压缩后| 循环成为一个组成部分 | 节点 A 连接到节点 B |
 | 直径 BFS | A 和 B 之间 | 1 |

 只有一条桥边，因此 k 等于 2，直径为 1，生成成本 2 * 1 减 1 等于 1。 

这表明只有桥梁会产生成本，而循环是完全免费的。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + m) | 桥梁使用 1 个 DFS，部件使用 1 个 BFS，直径使用 1 个 BFS 两次 |
 | 空间| O(n + m) | 图存储加上组件和辅助数组 |

 该算法完全符合限制，因为所有操作都与图的大小成线性关系。

 ## 边缘情况

 没有桥的图在组件压缩后立即处理。 所有顶点都属于单个组件，因此桥树只有一个节点，并且算法返回零成本。 

就桥梁而言，纯树是最昂贵的结构。 每条边都成为桥树的一部分，并且直径计算允许最长路径仅遍历一次，从而正确地降低了成本。 

具有单个桥的高度循环图表明所有复杂性都崩溃到一个关键边缘。 压缩步骤确保所有循环在树阶段之前消失，从而防止内部结构的过度计数。
