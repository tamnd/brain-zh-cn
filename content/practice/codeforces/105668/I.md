 ## 解决方案
 ## 问题理解

 我们正在研究一个矩形网格，其中每个单元格要么是空的，要么属于一个连接的结构。 网格是固定的，对于每个查询，我们都会得到一个子矩形。 任务是确定在该子矩形内，被占据的单元是否仅形成“有效的蛇形组件”。 

在这种情况下，蛇是一组连接的网格单元，形成没有分支的单个路径状结构。 蛇中的每个单元（端点除外）在结构内恰好有两个邻居，并且路径不会任意转向。 该形状以受控方式交替方向，因此它看起来像锯齿链，而不是树或脂肪区域。 

每个查询都会问：如果我们仅将注意力限制在给定矩形内的单元格上，那么占据单元格的每个连接组件是否都会形成一条有效的蛇？ 

网格大小和查询数量足够大，以至于每个查询从头开始重新计算连接性是不可行的。 当维度和查询计数都很大时，任何重建组件或每次查询执行 BFS/DSU 的解决方案都将超出时间限制，因为最坏情况的行为在所有查询中将接近二次或更糟。 

当组件局部看起来像路径但包含小的禁止模式（例如 2×2 块或不属于简单交替蛇形结构的直三元组）时，就会出现微妙的故障情况。 

例如，考虑一个形成 2×2 正方形的组件：```
11
11
```这是连接的，但它不是蛇，因为分支是隐式发生的。 简单的路径重建可能仍然按某种顺序列出所有单元，但局部结构违反了蛇的定义。 

另一个例子是 T 形：```
111
010
```这也是相连的，但是有一个分支点，所以不可能是蛇。 仅在本地检查连通性或度约束而不确保全局路径结构的解决方案可能会错误地接受它。 

主要困难在于“成为一条蛇”不仅仅是查询引起的任意子图中的局部度条件； 它必须排除一小组可能出现在网格中任何位置的禁止几何图案。 

## 方法

 一种简单的方法独立处理每个查询。 对于给定的矩形，我们对其单元格运行洪水填充或 DSU，提取每个连接的组件，然后验证该组件是否形成蛇。 

为了验证一个组件，我们可能会收集它的所有单元格，对它们进行排序，并尝试将顺序解释为路径。 人们可以尝试两种单调排序，一种是两个坐标都增加，另一种是一个坐标反转，然后验证邻接一致性和恒定步长行为。 这适用于单个组件，但成本高昂：每个查询都可能触及整个矩形，并且重复排序在运行时占据主导地位。 

如果网格是N×M，有Q个查询，仅遍历加上排序开销，最坏情况的复杂度就变成了O(QNM)，当Q很大时，这远远超出了限制。 

关键的结构观察是，由于非常小的局部原因，网格组件不能成为蛇。 我们可以预先计算网格中全局发生违规的位置，而不是分析每个查询的整个组件。 

非蛇组件必须包含一组恒定的禁止模式之一。 直观上，有效的蛇不能分支，也不能形成 2×2 的填充块。 这意味着每个无效结构包含三个连续对齐的单元或一个 2×2 正方形。 

这减少了从全局连接推理到检测固定大小模式的问题。 一旦这些模式的所有出现都在网格中预先标记，每个查询就变成矩形和查询：检查是否有任何禁止的模式完全位于查询矩形内。 

这可以使用 2D 前缀和来回答，因为每个模式在代表性单元格上贡献一个标记，并且我们只需要测试是否有任何标记位于查询范围内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（每个查询 DSU/BFS + 验证）| O(QNM log NM) 最坏情况 | O(NM) | 太慢了 |
 | 最优（模式标记+前缀和）| O(NM + Q) | O(NM) | 已接受 |

 ## 算法演练

 ### 1. 描述禁止的局部模式

 我们首先确定打破蛇结构的最小配置。 任何无效组件必须包含直线上的三个连续单元或完整的 2×2 块。 这种减少来自这样一个事实：分支或脂肪区域总是迫使这些模式之一出现在局部。 

### 2. 预先计算违规网格

 我们扫描整个网格一次。 对于每个单元格，我们检查它是否可以作为禁止模式的“锚点”。 例如，水平三元组或垂直三元组的中间单元格，以及 2×2 块的左上角单元格。 

每当这样的模式存在时，我们就在辅助数组中标记相应的位置。 

此步骤是必要的，因为稍后必须在恒定时间内回答查询，因此所有昂贵的结构检测都转移到预处理。 

### 3. 为每个模式类型构建 2D 前缀和

 每个模式类型都存储在其自己的二进制网格中。 我们构造前缀和，以便我们可以查询任意矩形内出现的次数。 

我们保留单独的网格，因为不同的模式有不同的锚偏移量，混合它们会使查询翻译不明确。 

### 4. 使用矩形和检查回答每个查询

 对于查询矩形，我们将其转换为每个模式网格上的前缀和查询。 如果任何网格报告非零值，则矩形内存在禁止的配置，这意味着答案是否定的。 否则，矩形是安全的。 

### 为什么它有效

正确性依赖于这样一个事实：每个非蛇组件都必须包含至少一个预先计算的禁止模式。 这些模式是无效结构的本地证书。 由于每次违规行为都是通过恒定大小的见证人检测到的，因此不需要大规模重建。 前缀和确保如果任何见证人完全位于查询矩形内，则将通过聚合恰好检测到一次，如果不存在，则不会存在无效结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_prefix(grid):
    n, m = len(grid), len(grid[0])
    ps = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n):
        for j in range(m):
            ps[i + 1][j + 1] = grid[i][j] + ps[i][j + 1] + ps[i + 1][j] - ps[i][j]
    return ps

def get(ps, r1, c1, r2, c2):
    return ps[r2][c2] - ps[r1][c2] - ps[r2][c1] + ps[r1][c1]

def solve():
    n, m, q = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    hor = [[0] * m for _ in range(n)]
    ver = [[0] * m for _ in range(n)]
    sq  = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            if j + 2 < m and g[i][j] == g[i][j+1] == g[i][j+2]:
                hor[i][j+1] = 1
            if i + 2 < n and g[i][j] == g[i+1][j] == g[i+2][j]:
                ver[i+1][j] = 1
            if i + 1 < n and j + 1 < m:
                if g[i][j] == g[i][j+1] == g[i+1][j] == g[i+1][j+1]:
                    sq[i][j] = 1

    ph = build_prefix(hor)
    pv = build_prefix(ver)
    psq = build_prefix(sq)

    out = []
    for _ in range(q):
        r1, c1, r2, c2 = map(int, input().split())
        r1 -= 1
        c1 -= 1

        bad = 0
        bad += get(ph, r1, c1, r2, c2)
        bad += get(pv, r1, c1, r2, c2)
        bad += get(psq, r1, c1, r2, c2)

        out.append("NO" if bad else "YES")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案将检测分为三个独立的模式网格。 水平和垂直阵列标记任何长度为 3 的直线段的中间单元，确保每个这样的段至少贡献一个标记。 方形数组标记任何 2×2 均匀块的左上角。 

每个网格都转换为二维前缀和，以便每个查询成为矩形上的恒定时间包含测试。 索引时必须小心：查询矩形在输入中是从 1 开始的，但前缀和使用从 1 开始的内部偏移量，因此我们只相应地转换左上角。

 ## 边缘情况

 一个关键的边缘情况是组件很大但仅局部无效。 例如：```
1111
0000
```如果只检查端点，天真的方法可能会认为这是一个简单的类似路径的结构，但每个长度为 3 的段都包含一个禁止的直三元组。 该算法标记每个三元组的中间，因此任何覆盖该行的查询都将正确检测无效性。 

另一种情况是嵌入更大区域的 2×2 块：```
1110
1110
0111
```尽管大部分区域是蛇形的，但左上角的 2×2 块会触发标记。 覆盖该区域的任何查询都将在前缀和中包含标记的单元格，确保立即拒绝，而无需分析组件的其余部分。 

最后一个微妙的情况是同一个查询矩形中存在多个小的有效蛇。 由于该算法仅标记禁止模式，因此多个独立的有效组件不会干扰正确性。 只有标记的存在才会改变答案，因此不相交的蛇可以被干净地处理，无需额外的簿记。
