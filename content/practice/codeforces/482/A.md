 ## 解决方案
 ## 问题理解

 我们被要求构造一个从 1 到 _n_ 的整数排列，使得连续元素之间的绝对差集恰好包含 _k_ 个不同的值。 换句话说，如果我们将排列写成数组，则差值 |p₁ − p2|, |p2 − p₃|, …, |pₙ₋₁ − pₙ| 应该形成一个恰好包含 _k_ 个元素的集合。 

输入由两个整数 _n_ 和 _k_ 组成，其中 1 ≤ k < n ≤ 10⁵。 这立即告诉我们 _n_ 可能很大，因此任何需要 O(n²) 操作的解决方案都会太慢。 我们需要一种在线性或近线性时间内工作的算法，最好是 O(n)。 内存不受限制，因为存储排列数组需要 O(n) 空间。 

微妙之处在于需要恰好 _k_ 个不同的差异。 对于小_k_，差异应该以受控的方式重复。 例如，对于 n = 5、k = 2，排列 1 5 2 4 3 产生差异 {4, 3, 1, 1}，这恰好给出 3 个不同的差异，这是错误的。 如果只是打乱元素的粗心方法很容易超出或低于明显差异的数量。 

边缘情况包括 k = 1，这要求所有差异都相同（n > 2 不可能在标准排列中严格获得 1 个不同差异）和 k = n − 1，这需要最大数量的不同差异（这可以通过交替的高低模式来实现）。 

## 方法

 一种天真的方法会尝试生成所有 n！ 排列并检查每个排列的差异，计算不同的值。 当 n 达到 10⁵ 时，这显然是不可行的。 即使更智能的回溯也太慢，因为它仍然具有指数复杂性。 

关键的观察是，为了准确生成 _k_ 个不同的差异，我们可以以受控方式构建排列：从最小和最大的剩余数字开始，并在它们之间交替。 每次我们从另一端选择一个数字时，我们都会产生一个新的差异。 以这种方式选择_k_个数字后，剩余的数字可以按升序附加，重复产生1的差异，这不会引入新的明显差异。 这确保了前_k_个差异是不同的，而其余的差异是重复的。 

这将问题简化为使用两个指针的线性扫描，在 O(n) 时间内精确产生 _k_ 个不同的差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 高低交替贪婪 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个指针，`left = 1`和`right = n`。 这些代表最小和最大的未使用数字。 
2.初始化一个空列表`perm`来存储排列。 
3. 重复 _k_ + 1 次，左右指针交替：

 - 在奇数迭代中，将值附加到`left`并增加`left`。 
- 在偶数迭代中，将值附加到`right`并减少`right`。 

这确保了每个连续的差异都是不同的，并产生前_k_个差异。 
4. 放置_k_+1个元素后，将剩余的数字从`left`到`right`按递增顺序。 现在每个差异都是 1，这不会引入新的明显差异。 
5. 打印排列。 

为什么有效：每次我们从末端交替选择时，连续元素之间的绝对差异是不同的，因为每个数字都来自最末端，产生的差异比之前所有差异都大。 创建 _k_ 个不同差异后，剩余的数字是连续的，产生重复差异 1，这不会添加新的不同差异。 这保证了恰好 _k_ 个不同的差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
perm = []
left, right = 1, n

# create first k+1 elements with distinct differences
for i in range(k + 1):
    if i % 2 == 0:
        perm.append(left)
        left += 1
    else:
        perm.append(right)
        right -= 1

# append remaining numbers in increasing order
for x in range(left, right + 1):
    perm.append(x)

print(" ".join(map(str, perm)))
```代码严格遵循算法。 第一个循环在最小和最大剩余数字之间交替，产生前 k 个不同的差异。 第二个循环按顺序附加剩余的数字，这引入了 1 的重复差异。边界处理很简单，因为`left`和`right`收敛而不跳过任何数字。 使用`map(str, perm)`避免多个打印语句，这对于速度很重要。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    perm = []
    left, right = 1, n
    for i in range(k + 1):
        if i % 2 == 0:
            perm.append(left)
            left += 1
        else:
            perm.append(right)
            right -= 1
    for x in range(left, right + 1):
        perm.append(x)
    return " ".join(map(str, perm))
