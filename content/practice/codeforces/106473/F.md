 ## 解决方案
 ## 问题理解

 我们得到一串小写字母。 我们可能会重新排列它的所有字符，并且需要构建一个新字符串，其前缀永远不会成为回文，除了长度为 1 的前缀之外。 换句话说，在选择第一个字符后，每个较长的前缀必须在其两端具有不同的字符，或者必须在内部某处失去回文对称性。 输入包含许多独立的字符串，对于每个字符串，我们要么打印满足规则的排列，要么报告不存在排列。 

所有测试用例的字符总数最多为$10^6$。 这排除了检查每种可能的排列，因为即使是中等长度的字符串也有多种排列。 这也意味着预期的解决方案应该在字符串长度上接近线性，因为一百万个字符的扫描很容易，而重复的回文检查或昂贵的搜索则不太适合。 

棘手的情况来自字符频率。 像这样的字符串`abba`无法重新排列成有效答案。 任何第一个字符都会再次出现，并且只有两个不同的字母，第一个字符的第二次出现会创建回文前缀。 仅包含一个字符的字符串也会失败，因为长度为 2 的前缀立即成为回文。 

单例角色完全改变了情况。 例如：```
Input:
1
aabbc
```正确的输出可以是：```
YES
cabba
```人物`c`出现一次，所以把它放在前面意味着每个较长的前缀都以`c`但以不同的角色结束。 

另一个重要的情况是两个不同的字符：```
Input:
1
aabb
```正确的输出是：```
NO
```粗心的解决方案可能会尝试交替字符并产生类似的结果`abab`，但是前缀`aba`是一个回文。 任何两个字符的排列都有相同的基本问题。 

## 方法

 一种直接的方法是尝试生成字符的排列并测试每个排列。 这是正确的，因为我们最终会检查所有可能的重新排列，但它具有阶乘复杂性。 对于一个长度的字符串$n$，可能的订单数为$n!$，即使对于很小的值，这也是不可能的$n$。 

有用的观察是，我们实际上不需要在构建答案后检查前缀。 我们只需要控制第一个字符再次出现的位置即可。 如果第一个字符只出现一次，可以放在前面，不再是前缀可以是回文。 

更困难的情况是每个字符至少出现两次。 如果所有字符都相等，则答案是不可能的，因为前两个字符始终相同。 如果恰好有两个不同的字符，则第一个字符的第二次出现始终会创建回文前缀。 其余情况的不可能性推理和构造都是基于这种频率分裂。 

当至少存在三个不同字符时，选择任意字符`x`。 放置一份`x`在开始时，将所有剩余的副本放入`x`放在最后，并将所有其他字符按排序顺序放置在它们之间。 中间部分不包含`x`，因此最后一个块之前结尾的前缀不能是回文。 到达最后一个块的前缀仅以一个开头`x`在遇到不同的角色之前，而其相反则需要几个前导`x`字符，因此这些前缀也不能是回文。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳| O(n) | 除了输出存储之外，O(1) | 已接受 |

 ## 算法演练

 1. 计算字符串中每个字母的出现频率。 我们需要这些计数，因为有效排列的存在仅取决于存在多少个不同的字符以及某个字符是否恰好出现一次。 
2. 搜索只出现过一次的字符。 如果存在，则将其放在第一位，然后附加所有其他字符。 由于后面的字符不等于第一个字符，因此每个较长的前缀都有不同的第一个和最后一个字符。 
3. 如果没有单个字符，则计算不同字母的数量。 如果这个数字是一或二，则打印`NO`。 在这些情况下，每种可能的排列都会产生错误的前缀。 
4. 如果至少有三个不同的字母，请选择一个字符`x`。 放置 1 次出现`x`在开始时，将所有其他非`x`其后按排序顺序的字符，并附加剩余的副本`x`在最后。 
5. 输出构造好的字符串。 

为什么它有效：

 第一个字符是对于前缀回文唯一重要的字符。 回文前缀必须以与其开头相同的字符结尾。 该结构要么通过选择唯一的第一个字符来实现这一点，要么通过以另一个字符开头的中间部分将第一个字符与其所有后续副本分开。 不可能的情况正是这样的情况，即没有这种分离可以避免重复的对称前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(s):
    cnt = [0] * 26
    for c in s:
        cnt[ord(c) - 97] += 1

    single = -1
    for i in range(26):
        if cnt[i] == 1:
            single = i
            break

    if single != -1:
        ans = [chr(single + 97)]
        for i in range(26):
            if i != single:
                ans.append(chr(i + 97) * cnt[i])
        return "YES\n" + "".join(ans)

    kinds = sum(1 for x in cnt if x > 0)

    if kinds <= 2:
        return "NO"

    first = next(i for i in range(26) if cnt[i] > 0)

    ans = [chr(first + 97)]

    for i in range(26):
        if i != first:
            ans.append(chr(i + 97) * cnt[i])

    ans.append(chr(first + 97) * (cnt[first] - 1))

    return "YES\n" + "".join(ans)

def main():
    t = int(input())
    out = []
    for _ in range(t):
        s = input().strip()
        out.append(solve_case(s))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```频率数组是原始顺序所需的唯一信息，因为该任务允许任意重新排列。 单例搜索首先处理最简单的建设性案例。 如果失败，不同的字符计数会将不可能的输入与构造案例分开。 

在最终的构建中，第一次出现`first`是单独添加的。 这可以避免在开始时意外地将所有副本放在一起。 仅在放置所有其他字母后才附加其余副本。 乘以`cnt[first] - 1`是安全的，因为只有当每个计数至少为 2 时分支才会到达此点。

 ## 边缘情况

 单个字符串，例如：```
1
a
```立即处理。 唯一的前缀长度为一，限制从长度二开始，因此答案有效。 

具有一个重复字符的字符串：```
1
aaaa
```没有有效的安排。 每种可能的排列都是相同的，并且前两个字符已经形成`aa`，一个回文。 

包含两个不同字母的字符串：```
1
aabb
```施工前被拒绝。 如果第一个字符是`a`，下一个出现的`a`创建一个前缀，其第一个和最后一个字符匹配并且其内部仅包含`b`字符，产生回文。 如果第一个字符是，则同样的论点适用`b`。 

包含多个字母但没有单个字母的字符串：```
1
aabbcc
```使用最终的结构。 选择`a`给出一个类似的形式`abbcca a`与最后一个副本`a`与第一个分隔符不能反映它的字符。 该算法永远不需要单独测试前缀，因为放置规则通过构造阻止它们。
