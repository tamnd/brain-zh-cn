 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，其中每个值都使用固定位数表示。 有一个特殊的操作：我们可以选择数组的任何连续段并翻转该段内每个数字的所有位。 翻转意味着用 x 位空间内的按位补码替换每个值，因此每个数字`v`变成`(2^x - 1) - v`。 

游戏持续时间正好`k`移动。 从第一个玩家开始，两名玩家交替移动，两人都表现完美，但目标相反。 第一个玩家想要最大化数组的最终总和，而第二个玩家想要最小化它。 恰好之后`k`段翻转，我们输出最终的和。 

关键在于，每个操作都会翻转一个线段，但从简单的加法意义上来说，效果并不是局部的。 每次被奇数个选定段覆盖时，每个位置都会在其原始值和补码之间切换。 

这些限制迫使我们采取谨慎的结构性解决方案。 跨测试的数组大小最多为 50,000，因此任何解决方案每次测试都必须大致呈线性或接近线性。 移动次数`k`可以大到 10^12，这会立即排除任何游戏模拟。 位宽`x`最多为 10，因此值位于非常小的有界范围内，但仅此并不能简化组合游戏，除非我们以不同的方式解释翻转。 

一个常见的陷阱是认为每个动作都可以独立分析或贪婪地应用以提高局部总和。 这会失败，因为段翻转重叠并相互作用。 另一种失败模式是模拟每次移动并显式维护数组，这由于以下原因而变得不可能`k`并且由于应用段更新的二次成本。 

## 方法

 从直接模拟的角度开始。 每次移动都包括选择一个段并在其中切换所有值`v`和`maxVal - v`， 在哪里`maxVal = 2^x - 1`。 如果我们尝试从字面上模拟这一点，则每次移动都会花费`O(n)`时间，导致`O(nk)`，当`k`达到10^12。 

更重要的是，游戏结构建议指数分支：在每一步，玩家可以选择 O(n^2) 段中的任何一个。 单纯的极小极大搜索是完全不可能的。 

关键的观察是停止考虑价值，而是考虑对总和的贡献。 对于每个位置，翻转它会改变它的贡献`a[i]`到`maxVal - a[i]`。 因此，值的变化是一个固定的增量：`(maxVal - a[i]) - a[i] = maxVal - 2*a[i]`。 

所以每个指数都有一个权重，无论是正数还是负数，代表着翻转它的好处有多大。 然而，翻转不是独立的，因为我们只能翻转连续的段，这意味着我们正在选择其效果通过奇偶校验组合的范围。 

这将问题转化为权重数组上的游戏，其中每次移动都会选择一个段并翻转该段中所有值的符号。 分数是数值的总和，玩家在恰好之后交替最大化和最小化`k`运营。 

现在出现了关键的结构简化：由于每个操作只是一个段上的符号反转，因此应用同一段两次就可以抵消。 因此，唯一重要的是每个位置总体上翻转的次数是偶数还是奇数。 整个游戏简化为决定翻转的最终奇偶配置`k`移动，玩家控制分段异或运算。 

这成为前缀奇偶状态的经典交替游戏。 更深层的结果是，最优玩法分解为一组非常小的全局策略：玩家要么立即采取行动来最大化全局收益，要么强制进行最小的修正，并且因为`k`规模很大，游戏在前几步之后就稳定为周期性或稳定的模式。 该解决方案简化为计算有多少有效的“有用”操作很重要，结果仅取决于奇偶校验`k`以及最佳单段增益与最差单段损失。 

因此，我们将整个游戏简化为评估对数组和的最佳可能的单次操作效果，然后推理玩家是否可以交替采用它或其逆。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解游戏模拟| O(k·n) | O(k·n) | O(n) | 太慢了|
 | 最佳奇偶校验 + 增益降低 | 每次测试 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算常数值`M = 2^x - 1`。 这是任何元素可以采用的最大值，并定义补码变换。 
2. 将数组转换为“增益数组”，其中每个元素代表该位置翻转一次后总和的变化。 对于每个`a[i]`, 计算`b[i] = M - 2 * a[i]`。 这隔离了翻转的效果：对线段应用翻转会增加以下总和：`b[i]`超过该部分的总和。 
3. 计算数组的初始总和，这是任何移动之前的基线。 
4. 观察分段运算将以下总和相加`b[i]`在该段上，因此每次移动都会有效地选择一个子数组并添加其总和（然后隐式翻转符号以供将来重叠）。 这减少了选择具有一定价值贡献的子数组的每次移动。 
5. 计算最大子数组和`b`和最小子数组和`b`。 最大值对应于可能的最佳移动，最小值对应于可能的最差移动（对手可以强制执行）。 
6. 现在解释一下游戏结束的原因`k`移动。 由于每次移动都会在最大化和最小化之间交替，因此贡献序列变成最佳和最差子阵列增益之间的重复交互。 净效果仅取决于每个玩家应用移动的次数。 
7.如果`k`是奇数，第一个玩家多走一步，所以结果是：

 初始总和+(猫猫移动次数)*best_gain+(金石移动次数)*worst_gain。 
8.如果`k`为偶数，则双方棋步相等，最终结果为：

 初始总和+(k/2)*(best_gain+worst_gain)，因为最佳游戏强制交替极值段。 

### 为什么它有效

 关键的不变量是，每一步仅取决于阵列上线性函数的当前配置，并且该函数恰好是`b[i]`超过选定的部分。 由于段的选择不会影响`b`，整个游戏简化为在交替控制下重复选择子阵列极值。 没有任何举措引入新的结构； 它仅重用相同的增益景观。 这将游戏分解为重复应用两个极值操作，这完全决定了最终状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_subarray(arr):
    best = -10**30
    cur = 0
    for v in arr:
        cur = max(v, cur + v)
        best = max(best, cur)
    return best

def min_subarray(arr):
    best = 10**30
    cur = 0
    for v in arr:
        cur = min(v, cur + v)
        best = min(best, cur)
    return best

t = int(input())
for _ in range(t):
    n, x, k = map(int, input().split())
    a = list(map(int, input().split()))

    M = (1 << x) - 1

    base = sum(a)
    b = [M - 2 * v for v in a]

    best = max_subarray(b)
    worst = min_subarray(b)

    if k % 2 == 1:
        moves_a = (k + 1) // 2
        moves_b = k // 2
    else:
        moves_a = moves_b = k // 2

    ans = base + moves_a * best + moves_b * worst
    print(ans)
```该解决方案在进行任何操作之前首先计算数组的基线总和。 然后，它将每个元素转换为其翻转增量，从而将段反转的效果线性化为加性贡献。 

Kadane 扫描计算最佳和最差的可能段效应。 这些代表了玩家在一次移动中可以执行的操作。 最后一步根据回合顺序分配这些收益，因为每个玩家的每次移动恰好贡献一个片段，并且顺序决定最佳或最差选择是否更频繁地占主导地位。 

一个微妙的点是，相同的段结构在各个移动中重复使用，因此不需要在每次移动后重新计算数组。 所有效果都会被捕获一次`b`。

 ### 示例 1

 输入：```

a = [0, 7, 1, 6, 3]
```我们计算`M = 7`， 所以`b = [7, -7, 5, -5, 1]`。 

| 步骤| 行动| 结果 |
 | --- | --- | --- |
 | 1 | 计算基础总和 | 17 | 17
 | 2 | 计算最佳子数组 | 7 |
 | 3 | 计算最差子数组 | -7 |
 | 4 | k=1 所以只有毛毛移动 | +7 |

 最终答案：`17 + 7 = 24`这符合单一最佳翻转针对最有利可图的细分市场的想法。

| 步骤| 玩家| 行动增益|

 ## 边缘情况

 一种微妙的情况是所有元素都等于`0`或全部等于`2^x - 1`。 在那种情况下每`b[i]`均匀地变为最大或最小，并且 Kadane 结果都崩溃到可预测的极端。 该算法干净地处理了这个问题，因为子数组最大值和最小值仍然返回正确的常量值，并且基于奇偶校验的聚合确保不会出现虚假结构。 

另一个边缘情况是当`k`很大但是`n`很小。 解决方案仍然忽略`k`除了奇偶校验和除法之外，大小完全不同，因此不存在溢出或迭代爆炸的风险。 

最后一个重要的情况是最佳子数组为负数。 当翻转任何段是有害的时就会发生这种情况。 Kadane 实现仍然正确地选择危害最小的部分，而对手的最差选择变得更加负面，从而产生正确的极小极大平衡。
