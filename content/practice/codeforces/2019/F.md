 ## 解决方案
 ## 问题理解

 给定一个正整数数组，并且在没有两个相邻元素都可以都是红色的约束下，我们可以将其中一些标记为“红色”。 得分计算为三个分量的总和：红色元素中的最大值、红色元素中的最小值以及红色元素的总数。 任务是确定每个阵列可达到的最大可能得分。 

该数组最多可以有 200,000 个元素，并且多个测试用例的所有数组长度之和不超过 200,000。 这表明任何迭代所有元素子集的解决方案都是不可行的，因为它需要$O(2^n)$的操作，这是一个天文数字$n = 2 \cdot 10^5$。 我们需要一个相对于线性或接近线性时间运行的解决方案$n$。 

当所有元素都相同时，就会出现微妙的边缘情况。 例如，在数组中`[5, 5, 5]`，将第一个和最后一个元素标记为红色是最佳选择，因为它可以在不违反邻接约束的情况下最大化红色元素的数量。 天真地仅标记最大的元素可能会导致分数不理想。 类似地，长度为 1 或 2 的数组是边缘情况，因为邻接约束极大地限制了可以选择的元素。 

## 方法

 暴力方法将枚举数组索引的所有子集，检查邻接约束，计算每个有效子集的分数，并选择最大值。 这种方法原则上是正确的，因为它会检查所有可能的配置，但速度慢得令人绝望：$n = 20$，我们已经拥有超过一百万个子集，并且对于$n = 2 \cdot 10^5$，这是不可能的。 

优化的关键见解是分数仅取决于三个数字：最大值、最小值和所选元素的数量。 一旦我们选择了最大元素，我们希望选择尽可能多的附加元素，而不选择相邻的元素。 如果我们还从所选元素中选择最小元素，则只需最大化最大和最小之间的元素数量即可增加计数，因为添加较小或相等的元素有助于 max、min 和 size 的总和，而不会减少 max 或 min。 

因此，问题简化为元素的贪婪选择：首先，始终包含最大元素。 然后，我们可以尝试以尊重邻接规则的方式包含其他元素。 最佳解决方案要么是单个元素（单独的最大元素），要么以始终包含全局最大值和不减少所选元素中最小值的可选元素的模式从数组中选择非相邻元素。 实际上，这可以归结为一个简单的公式：当我们从最大的元素开始选择非相邻元素时，可达到的最大分数要么是最大元素加一（如果仅选择最大值），要么是最大值、最小值和计数的总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取长度`n`和数组`a`。 
2. 识别最大元素`mx`在`a`。 该元素将始终是最佳选择的一部分，因为它直接影响分数。 
3. 初始化变量`ans`到`mx + 1`。 如果我们只选择最大元素作为红色元素，这表示分数。 
4. 检查数组中选择不相邻元素会增加计数但不会减少最小值的位置。 一个简单的贪婪策略是扫描数组，如果每个元素不与先前标记的红色元素相邻，则将每个元素标记为红色，并跟踪所选元素的最小值和最大值。 
5. 处理数组后，将分数计算为最大、最小和红色元素数量的总和。 更新`ans`如果这个分数比之前的大`ans`。 
6. 输出`ans`对于每个测试用例。 

为什么有效：不变的是必须始终选择最大元素才能最大化分数。 非相邻选择确保我们不违反约束，而在不破坏邻接性的情况下选择尽可能多的元素的贪婪方法保证了计数的最大贡献。 通过跟踪所选元素中的最小值和最大值，我们可以准确地计算分数分量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_plus_min_plus_size():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Find global max
        mx = max(a)
        ans = mx + 1  # At least selecting one element
        
        # Greedy selection of non-adjacent elements
        # Compute two possibilities: start with first element or second element
        def compute(arr):
            selected_count = 0
            selected_min = float('inf')
            selected_max = float('-inf')
            i = 0
            while i < len(arr):
                val = arr[i]
                selected_count += 1
                selected_min = min(selected_min, val)
                selected_max = max(selected_max, val)
                i += 2
            return selected_max + selected_min + selected_count
        
        ans = max(ans, compute(a), compute(a[1:]))
        print(ans)

max_plus_min_plus_size()
```该解决方案首先确保全局最大值对分数的贡献。 然后它评估两个贪婪选择：一个从索引 0 开始，一个从索引 1 开始，这涵盖了选择不相邻元素的所有情况。 打印这些可能性中的最高分数。
