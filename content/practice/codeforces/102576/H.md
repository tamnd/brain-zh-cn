 ## 解决方案
 ## 问题理解

 我们有一个凸多边形，其顶点是灯塔。 一些顶点对通过电车轨道连接，弗拉迪克只能沿着这些轨道移动。 有效行程是该图中的一条路径，但具有几何限制：所绘制的行程链不能与自身相交，并且不能两次访问同一点。 

任务是找到这样一条路径的最大可能总欧几里得长度。 

灯塔的数量最多为 300 个，这排除了任何依赖于枚举路径或顶点子集的解决方案。 具有 300 个顶点的图仍然可以有近 45,000 个边，因此接近立方时间的解决方案是自然的目标。 所有测试的顶点总数仅为 3000，这允许进行更繁重的每次测试处理。 

主要困难不是图遍历。 一般图中的最长路径很困难，但这里所有顶点都位于凸多边形上。 顶点的顺序为我们提供了强大的几何结构：每当我们采用弦时，剩余的可能路线都被限制在该弦的一侧。 这会产生更小的独立子问题。 

一些情况很容易打破幼稚的方法。 如果存在交叉的电车线路，即使它们给出了更大的图论路径，它们也不能同时出现在答案中。 例如，两个对角线都可用的正方形不允许该路线`1-3-2-4`，因为对角线在中间交叉。 正确的路线必须避免交叉口。 

另一个陷阱是假设最长的路径必须从固定的灯塔开始。 考虑一个只有三个连续边可用的正方形。 最佳路线从这些边的一端开始，在另一端结束，因此固定第一个顶点可能会失去最佳路径。 

第三个问题是多边形是圆形的。 路径可以跨越最后一个和第一个索引顶点之间的人工边界。 任何区间 DP 仅适用于`0...n-1`如果不处理圆圈可能会错过有效答案。 

## 方法

 强力解决方案将尝试所有可能的顶点序列，仅保留形成有效电车路径的序列，并拒绝那些具有自相交的序列。 这是正确的，因为每个可能的行程都被明确考虑。 然而，可能的路径数量是指数级的。 即使对子集进行完整搜索也已经需要大约`2^300`状态，这是不可能的。 

有用的观察结果是多边形是凸的。 采取一条有效路径并查看其在某些顶点间隔内的第一条边。 一旦选择了该边，路径的其余部分将被迫保留在弦的一侧，因为在两侧使用顶点将使未来的某些线段与所选弦交叉。 

这意味着该问题可以通过区间动态规划来解决。 我们跟踪仍然可用的多边形线段以及当前路线所在的端点。 当我们选择下一个有轨电车边缘时，剩下的问题就变成了另一个具有已知端点的较小区间。 

因为多边形是圆形的，所以我们复制顶点并在这个双倍数组上运行区间 DP。 每个可能的圆形长度区间`n`然后显示为普通间隔。

 ## 算法演练

 1. 复制多边形顶点。 顶点`i`被复制到位置`i+n`，并且每个有轨电车边缘都会被相应地复制。 这会将圆形范围转换为正常间隔。 
2. 定义`dp[l][r]`作为仅使用以下顶点的有效路线的最大长度`l`到`r`其当前端点是`l`。 
3. 通过增加长度来处理间隔。 对于一个间隔`[l,r]`，首先继承跳过顶点的答案`l`，这给出了`dp[l+1][r]`。 
4. 尝试所有可能的第一个电车边缘`l`到一个顶点`k`区间内。 如果该边存在，则在旅行到`k`，剩余行程必须留在室内`[k,r]`并从`k`。 过渡是：$$dp[l][r] = \max(dp[l][r], dist(l,k)+dp[k][r])$$1.答案是最大值`dp[i][i+n-1]`超过所有起始位置。 这些间隔代表了圆形多边形切割位置的每种可能选择。 

DP 背后的不变量是，间隔内的每条有效路由都具有从其当前端点开始的第一个边，或者根本不使用该端点。 在第一种情况下，所选边将剩余搜索空间划分为弦正确一侧的较小区间。 在第二种情况下，删除端点会留下另一个有效间隔问题。 由于每条有效路线都遵循这两种形式之一，因此递归会考虑所有可能的答案，并且永远不会创建无效的交叉点。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve_case():
    n = int(input())
    pts = []
    for _ in range(n):
        x, y = map(int, input().split())
        pts.append((x, y))

    m = int(input())

    size = 2 * n
    edges = [[-1.0] * size for _ in range(size)]

    def length(a, b):
        x1, y1 = pts[a % n]
        x2, y2 = pts[b % n]
        return math.hypot(x1 - x2, y1 - y2)

    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        w = length(a, b)
        for x in (a, a + n):
            for y in (b, b + n):
                if x < size and y < size:
                    edges[x][y] = w
                    edges[y][x] = w

    dp = [[0.0] * size for _ in range(size)]

    for ln in range(2, n + 1):
        for l in range(size - ln + 1):
            r = l + ln - 1
            best = dp[l + 1][r]
            row = edges[l]
            for k in range(l + 1, r + 1):
                if row[k] >= 0:
                    cand = row[k] + dp[k][r]
                    if cand > best:
                        best = cand
            dp[l][r] = best

    ans = 0.0
    for i in range(n):
        if dp[i][i + n - 1] > ans:
            ans = dp[i][i + n - 1]
    return ans

def main():
    data = sys.stdin.read().split()
    if not data:
        return

    it = iter(data)

    def next_input():
        return next(it)

    global input
    old_input = input

    def fake_input():
        return next_input() + "\n"

    input = fake_input

    t = int(input())
    out = []
    for _ in range(t):
        out.append(f"{solve_case():.12f}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```边缘矩阵存储每条可用电车线路的长度。 通过对坐标取模来处理重复的索引`n`，因此复制的顶点共享相同的几何位置。 

DP表最多只存储长度的区间`n`。 双多边形中较长的间隔会重复灯塔，并可能创建无效的路线。 间隔长度循环保证每个依赖性在使用之前已经被计算。 

转换尝试离开当前端点的所有可能的第一条有轨电车线路。 如果不存在有轨电车线路，则州政府只需保留忽略该端点的选项。 Python 整数安全地处理坐标范围，并且所有几何计算仅在计算最终长度时才使用浮点。

## 边缘情况

 当不存在有轨电车线路时，每个 DP 转换都会失败并且每个状态都保持为零。 答案是正确的`0`，因为弗拉迪克不能移动到任何地方。 

当最佳路线环绕输入顺序的末尾时，复制的多边形就会捕获它。 对于可用边为的正方形`1-4`,`4-3`,`3-2`,`2-1`，最优路线使用三个边。 在原始索引中，这跨越了人为边界，但在双倍数组中，它显示为普通区间。 

当两个可用的和弦交叉时，DP 永远不会将它们组合成一条路线。 选择一个和弦会将剩余状态限制在该和弦的一侧，因此交叉和弦不能稍后出现在同一路径中。 这是取代显式相交检查的几何属性。
