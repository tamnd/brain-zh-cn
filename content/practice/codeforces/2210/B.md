 ## 解决方案
 ## 问题理解

 我们有一排$n$椅子，最初都没有标记。 一个排列$p$长度$n$给出，意味着每个数字$1$到$n$恰好出现一次。 我们从第一把椅子开始向右移动。 在每把椅子上，如果已经被标记，游戏立即停止。 否则，我们可以选择继续或跳过它。 如果我们坐下，站起来后，我们用当前椅子的排列值来标记椅子，$p_i$，然后继续到下一张椅子。 目标是最大化我们坐的椅子总数。 

输入给出多个测试用例，每个测试用例指定$n$和排列$p$。 输出是每个测试用例可以坐的最大椅子。 

限制因素很大。$n$可以达到$2\cdot 10^5$，以及所有的总和$n$所有测试用例最多是$2\cdot 10^5$。 这限制了我们每个测试用例只能使用线性或近线性算法。 任何复杂的方法$O(n^2)$会太慢。 

当排列创建一个包含第一把椅子的循环时，就会出现微妙的边缘情况。 例如，如果$p = [1,2,3]$，坐在第一张椅子上立即标记自己，因此游戏在第一步后结束。 总是坐着的天真贪婪的方法将无法考虑这些自我标记或早期周期场景，从而产生错误的结果。 

当有一条长链指向前方且没有循环时，会出现另一种边缘情况，例如$p = [2,3,4,1]$，坐在椅子上$1$最终将标记椅子$1$本身。 在这里，在击中标记的椅子之前有策略地坐着以最大化链条长度很重要。 

## 方法

 蛮力方法尝试坐在所有椅子子集上，模拟每个选择的标记过程。 这是有效的，因为我们可以准确地遵循规则并计算椅子数量。 然而，对于$n$大约$2\cdot 10^5$， 有$2^n$子集，使得暴力破解变得不可行。 

关键的见解是，排列定义了一个有向图，其中每把椅子都指向一把椅子。 每一步都对应着遍历这个图。 当我们第一次重新访问一把标记的椅子时游戏就结束了，这相当于进入了图中的一个循环。 因此，最大化乘坐的椅子数量减少了找到最长的椅子前缀，该前缀形成不相交的循环和链条，其中每条链条都可以安全地穿过。 

一个更简单的观点是从左到右扫描椅子，并在标记意义上尚未访问过椅子时坐下。 当我们坐下来时，我们会标记$p_i$。 如果$p_i \le i$，那么该标记不会影响未来的椅子，但如果$p_i > i$，它可能标志着我们未来想要坐的椅子。 因此，为了最大化坐席，我们只需要跟踪迄今为止遇到的最大“标记索引”。 对于每把椅子，如果超出当前标记的索引，我们就可以安全地坐。 否则，我们不能坐以待毙。 

这将问题转化为贪婪的线性扫描：维护将从以前的座位中标记的最右边的椅子，并且仅在当前椅子索引超过该值时才坐下。 这一观察结果减少了解决方案$O(n^2)$到$O(n)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`max_marked`到 0。这将跟踪已被或将被先前站点标记的最远索引。 
2. 初始化计数器`count`到 0，代表我们坐的椅子数量。 
3. 从索引迭代椅子$1$到$n$（基于 1 的索引与排列保持一致）。 对于每把椅子$i$:

 1. 如果 $i \le max_marked`，那么坐在这里就会结束游戏，所以跳过这把椅子。 
2. 否则，请坐在椅子上$i$。 增量`count`1.
 3. 更新`max_marked`是其当前值的最大值并且$p_i$。 这可以确保我们跟踪最右边已标记的椅子，并且可能会阻止未来的座位。 
4. 迭代结束后，`count`包含我们可以坐的最大数量的椅子。 
5、输出`count`对于测试用例。 

为什么它有效：不变的是`max_marked`始终存储在我们到达任何索引时已标记或将标记的最右边的椅子。 只坐在索引大于的椅子上`max_marked`，我们确保没有人提前结束比赛。 这种贪婪策略之所以有效，是因为标记只会阻挡未来的椅子，而不会阻挡更早的椅子，因此从左到右扫描，同时保持最远的标记是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    max_marked = 0
    count = 0
    for i in range(n):
        if i + 1 <= max_marked:
            continue
        count += 1
        max_marked = max(max_marked, p[i])
    print(count)
```代码初始化`max_marked`和`count`，然后迭代每把椅子。 支票`i + 1 <= max_marked`确保从 1 开始索引。 当坐在椅子上时，`max_marked`更新以反映此坐标记的椅子。 这种方法可以正确处理标记通过排列链的传播，避免过早结束游戏，并且以线性时间运行。

def run(inp: str) -> str:

    output = io.StringIO()
    sys.stdout = output

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        max_marked = 0
        count = 0
        for i in range(n):

                continue
            count += 1
            max_marked = max(max_marked, p[i])
        print(count)
    return output.getvalue().strip()
