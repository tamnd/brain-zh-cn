 ## 解决方案
 ## 问题理解

 机器人在一维走廊内移动，该走廊可以被视为从 0 到 L 的整数点的一段。左墙位于位置 0，右墙位于位置 L。机器人从位置 X 开始，最初面向左或右。 每一秒它都会向当前面向的方向移动一个单位。 当它试图穿过墙壁时，它首先撞到边界，立即反转方向，然后继续向相反方向移动。 

任务是在T秒后确定机器人的位置。 

约束允许 L 和 T 最大为 10^9，这立即排除了任何逐步模拟。 线性模拟每次测试最多需要 10^9 次操作，这太慢了。 该解决方案必须将运动压缩为直接公式或每次测试的 O(1) 计算量。 

朴素推理的一个常见失败案例是忽略边界处的“弹跳”行为并将运动视为简单的线性运动。 例如，当 L = 10、X = 3 时，向右移动 T = 4，简单的计算将给出 7，这在这里恰好是正确的。 但如果机器人撞到墙壁并反射，运动就不是单调的，线性外推通常会失败。 

当发生多次反射时，会出现另一个微妙的故障。 例如，如果L = 5，X = 2，向右移动T = 10，机器人会反复弹跳。 任何只考虑第一次碰撞的方法都会很快失效。 

## 方法

 该运动本质上是在边界处有反射的直线行走。 直接模拟跟踪每一步的位置和方向，更新墙壁的位置和翻转方向。 这是正确的，但需要 O(T) 时间，当 T 很大时这是不可行的。 

关键的观察结果是，可以通过展开走廊来消除反射。 想象一下，机器人在到达墙壁后，不再弹跳，而是继续进入走廊的镜像副本。 这将运动转换为无限线上的简单直线运动。 

更具体地说，我们将 [0, L] 中的位置映射到长度为 2L 的周期结构中。 机器人的移动就像在一条没有墙壁的线上一样，从 X 开始，根据方向每步移动 ±1。 经过 T 个步骤后，其“展开位置”为 X + d·T，其中 d 向右为 +1，向左为 -1。 然后我们使用周期 2L 的对称性将该位置映射回 [0, L]。 

如果 p = (X + d·T) mod (2L)，则：

 如果 p ≤ L，则答案为 p。 

如果 p > L，则答案为 2L − p。 

这是有效的，因为从一堵墙到另一堵墙的每次完整遍历都对应于长度为 L 的线段，而反射相当于反转方向，这正是折叠图编码的内容。

 | --- | --- | --- | --- |
 | 暴力模拟| O(T)| O(1) | O(1) | 太慢了|
 | 模块化反射映射| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将方向转换为数值速度 d，其中右变为 +1，左变为 -1。 这将运动变成算术而不是分支逻辑。 
2. 将 T 步后的原始位置计算为 p = X + d·T。 这代表了没有墙壁的运动，就好像走廊无限延伸。 
3. 使用模运算将 p 归一化到 [0, 2L] 范围内：p = p mod (2L)。 这捕获了由反射创建的重复结构。 
4. 如果模数调整后p为负值，则加2L进行平移。 这确保了周期表示的一致性。 
5. 将展开的位置映射回真实的走廊。 如果 p 在 [0, L] 范围内，则它已经对应于有效位置。 如果 p 在 (L, 2L] 中，则将其反映为 p = 2L − p。

反射步骤完全对应于机器人穿过“虚拟镜像走廊”的中点并返回到原始部分。 

### 为什么它有效

 不变的是，机器人在展开线上的运动在相同长度 L 的前向段和镜像段之间交替。每次越过边界时，其方向翻转相当于继续运动到该段的反射副本中。 模运算将这种无限展开压缩为长度为 2L 的单个周期间隔，最后的反射步骤在原始段内选择机器人的正确图像。 由于每个壁相互作用精确对应于周期的对称半部之间的过渡，因此映射中不会丢失任何信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    L = int(input().strip())
    X = int(input().strip())
    S = input().strip()
    T = int(input().strip())

    d = 1 if S == 'R' else -1

    p = X + d * T

    mod = 2 * L
    p %= mod
    if p < 0:
        p += mod

    if p <= L:
        print(p)
    else:
        print(2 * L - p)

if __name__ == "__main__":
    solve()
```实现直接应用展开线模型。 方向被编码为±1，以便运动成为单个算术表达式。 以 2L 为模是将无限反射压缩到有界周期域的关键步骤。 

最后的条件处理折叠回原来的走廊。 L 处的阈值至关重要：它将前向遍历与镜像遍历分开。 

一个微妙的问题是处理模数后的负值。 Python 的模数已经返回正模数的非负结果，但保持调整可以使逻辑在翻译为其他语言时变得稳健。

 ### 示例 1

| 步骤| 表达| 价值|

| 步骤| 表达| 价值|

 | 方向d| R → +1 | 1 |

 这表明了边界跨越。 在到达 10 处的右侧墙壁后，机器人有效地反射并向左移动，通过将 13 折叠回 7 来捕捉到这一点。

 ## 边缘情况

 一种边缘情况是从墙壁开始向外移动。 例如，L = 5，X = 5，S = R，T = 1。机器人在展开空间中从 5 移动到 6，反射后映射到 4，因为 6 > 5 意味着 10 − 6 = 4。算法通过折叠规则自然地处理这个问题。 

另一种情况是重复整个循环。 对于 L = 4、X = 1、S = R、T = 6，展开位置为 7，模 8 给出 7，反射给出 1。这与机器人在两次完整遍历后返回到其原始位置的事实相匹配。 

第三种情况是非常大的 T。由于计算仅取决于 T 模 2L，因此像 T = 10^9 这样的值与其减少的余数的行为相同。 该算法从不依赖于 T 的绝对大小，只依赖于它在反射引起的循环中的位置。
