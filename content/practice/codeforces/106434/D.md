 ## 解决方案
 ## 问题理解

 我们得到一个正整数列表。 从这个列表中，我们在概念上形成了每对无序的不同元素。 对于每一对，我们计算两个数字的最小公倍数，产生一个非常大的多重值集。 任务是对所有这些 LCM 值求最大公约数并输出该单个数字。 

重要的一点是我们实际上不需要构建成对的 LCM 列表。 对于多达一百万个数字，对的数量约为 10^12，这使得即使每个操作都是恒定时间，也无法进行任何直接模拟。 这立即排除了任何显式迭代对甚至存储每对中间结果的方法。 该解决方案必须将成对 LCM 的结构简化为可以从每个元素的统计数据中导出的结构。 

每个输入值可以大到 10^9，因此如果我们想要推理 LCM 和 GCD 行为，则需要进行因式分解。 因此，该解决方案必须依赖于素数指数结构，而不是全整数算术。 

当所有数字都相同时，就会出现微妙的极端情况。 在这种情况下，每个 LCM 都等于该数字本身，因此答案应该是该数字。 任何错误地假设元素之间多样性的方法都可能在这里失败。 另一个极端情况是素数在整个数组中只出现一次； 该质数的贡献仍然必须正确处理，因为它会影响涉及该单个事件与其他事件配对的 LCM。 

## 方法

 直接方法遵循字面意思。 我们计算每对的 LCM，然后对所有结果求 GCD。 这在概念上是简单且正确的，因为它完全符合定义。 然而，它执行二次对运算。 当 n 达到 10^6 时，这会导致大约 10^12 LCM 计算，这远远超出了任何可行的限制。 即使 n = 2000，这也是临界值，并且每个 LCM 本身都需要 GCD 计算，这使其速度更慢。 

关键的观察结果是，LCM 和 GCD 是针对每个素因子独立确定的。 如果我们将每个数字表示为素数的乘积，则一对的最小公倍数是通过对每个素数取任一数字中出现的最大指数来形成的。 最终答案是所有此类成对最大值的 GCD，这意味着对于每个素数，我们只关心所有对中该最大值的最小可能值。 

对于固定素数，假设我们在数组中查看它的指数。 为了最小化一对中的最大指数，我们能做的最好的事情就是尽可能避免与最大指数配对。 可达到的最小最大值恰好是该素数的整个指数列表中的第二大指数。 这将全局成对问题转变为每素数统计问题。 

因此，我们不是对每个素数进行处理，而是跟踪所有数字中最大和第二大的指数。 答案是通过将每个素数乘以它的第二大指数来构建的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（成对 LCM + GCD）| O(n² log A) | O(n² log A) | O(1) | O(1) | 太慢了|
 | 素数指数跟踪 | O(n√A) | O(n√A) | O(#primes) | O(#primes) | 已接受 |

 ## 算法演练

1. 将每个数字分解为素数。 这是必要的，因为 LCM 和 GCD 在每个素数分量上的行为是独立的，并且在指数级别上工作消除了对完整整数值的依赖。 
2. 维护一个字典或哈希映射，从素数到迄今为止在所有数字中看到的前两个指数。 在扫描数字时，对于当前数字中的每个质因数指数，更新最大和第二大的值。 这已经足够了，因为只有指数之间的排序很重要，而不是哪个指数产生它们。 
3. 对于每个数字，在分解过程中，累积其指数图并更新全局统计数据。 如果素数没有出现在数字中，则其指数隐式为零，但只有非零出现才需要显式处理，因为零永远不会影响前两个最大值。 
4. 处理完所有数字后，通过迭代映射中的所有素数来计算答案。 对于每个素数，将其提高到存储的第二大指数并乘以结果。 
5.输出最终产品。 

仅跟踪前两个指数就足够的原因是，固定素数的任何成对最小公倍数仅取决于两个所选数字中较大的指数。 为了最大限度地减少所有对中的这种情况，我们希望避免总是采用全局最大指数，并且我们可以实现的最佳保证下限由第二大的出现次数决定。 

### 为什么它有效

 对于固定素数，令所有数字的指数为 e1 ≥ e2 ≥ ... ≥ ek。 任何对贡献的最大指数等于 max(ei, ej)。 包含指数为 e1 的元素的每个对都至少产生 e1，因此这些对不能将值降低到 e1 以下。 然而，存在通过在剩余元素中选择两个索引来完全避免 e1 的对，给出最大值 e2。 因此，最小可能的成对最大值恰好是 e2。 由于最终答案是所有成对 LCM 的 GCD，因此它采用所有此类最大值的最小值，即每个素数独立的 e2。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict
import math

# Precompute primes up to sqrt(1e9)
MAXP = 31623
is_prime = [True] * (MAXP + 1)
primes = []
for i in range(2, MAXP + 1):
    if is_prime[i]:
        primes.append(i)
        for j in range(i * i, MAXP + 1, i):
            is_prime[j] = False

def factorize(x):
    res = {}
    for p in primes:
        if p * p > x:
            break
        if x % p == 0:
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            res[p] = cnt
    if x > 1:
        res[x] = res.get(x, 0) + 1
    return res

n = int(input())
data = list(map(int, input().split()))

best = defaultdict(lambda: [0, 0])

for v in data:
    fac = factorize(v)
    for p, c in fac.items():
        if c > best[p][0]:
            best[p][1] = best[p][0]
            best[p][0] = c
        elif c > best[p][1]:
            best[p][1] = c

ans = 1
for p, (mx1, mx2) in best.items():
    if mx2 > 0:
        ans *= p ** mx2

print(ans)
```因式分解步骤使用预先计算的素数将每个数字分解为素数幂，直到平方根界限。 这避免了从头开始重复试除，并使每个因式分解对于实践中的大输入来说足够高效。 

这`best`结构存储每个素数、遇到的最大和第二大指数。 更新逻辑确保我们始终保持正确的排序，而无需对完整列表进行排序。 

最终的乘法仅使用第二大指数，因为它们代表每个素数的所有对中的最小可能最大值。 

## 工作示例

 考虑一个小输入，其中数字共享重叠因子，例如 18、30、24。 

| 步骤| 数量 | 质因数 | 更新的最佳状态（p：[max1，max2]）|
 | --- | --- | --- | --- |
 | 1 | 18 | 18 21, 32 | 21, 32 | 2:[1,0], 3:[2,0] |
 | 2 | 30| 2、3、5 | | 2:[1,1]、3:[2,1]、5:[1,0] |
 | 3 | 24 | 2 立方, 3 1 | 2:[3,1]、3:[2,1]、5:[1,0] |

 处理完所有数字后，第二大指数是 21、31 和 5⁰（被忽略，因为它没有任何贡献）。 答案变为 2 × 3 = 6。 

该轨迹显示了算法如何逐渐独立地完善有关每个素数的知识。 它还表明，最终结果仅取决于每个素数的第二强出现，而不取决于素数如何在各个数字内组合。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |

 | 空间| O(P)| 对于遇到的每个素数最多存储两个值 |

 约束条件最多允许一百万个数字，因此分解策略在实践中必须高效。 由于每个数字在删除小的质因数后会迅速减少，并且大多数数字在此过程的早期就变小，因此该方法在典型 CF 假设下保持在限制范围内。

 ## 边缘情况

 当所有数字都相同时，每个素数指数只有一个值。 在这种情况下，第二个最大值等于最大值本身，因此算法无需特殊处理即可返回正确的值。 

例如，输入`5 5 5`导致 prime 5 处于最佳状态`[1, 1]`，产生输出 5。 

当素数只出现在一个数中时，它的第二个最大值保持为零。 这意味着它对最终的乘积没有贡献，这与始终存在一对这样的事实相匹配：LCM 中素数的指数不会因单次出现而被迫高于零。 

例如，输入`2 16`产生素数 2 的指数为`[4, 1]`，因此结果变为 21 = 2，匹配唯一可能的 LCM 对。
