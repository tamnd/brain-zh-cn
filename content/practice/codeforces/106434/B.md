 ## 解决方案
 ## 问题理解

 我们得到了一个我们只能看到扭曲形式的数组。 观察到的数组中的每个元素最初可以是其观察值周围固定区间内的任何整数。 具体来说，如果我们看到一个值`a[i]`，那么加密前的真实值可以是以下任意整数`a[i] - l`最多`a[i] + r`，但绝不是负数。 

问题是我们是否可以为每个位置选择一个有效的原始值，以便生成的隐藏数组是非递减的。 

所以我们不会被要求唯一地重建数组。 我们只需要确定是否存在至少一种方法来为每个位置选择一个有效值，以便对序列进行排序。 

约束条件达到`n = 2 * 10^5`，因此任何解都必须接近线性。 任何涉及尝试范围内所有选择的事情都是立即不可能的，因为每个元素最多有`O(10^9)`可能的值。 即使是对范围内的每个元素进行搜索也会爆炸。 

一个天真的想法是独立对待每个位置，但排序约束将所有位置紧密耦合。 关键的困难在于，每一个选择都会限制未来的选择。 

一些失败案例阐明了可能出现的问题。 

如果我们在每一步贪婪地选择最小的可能值，我们可能会在以后陷入困境，因为小的早期值会迫使后面的元素太小而无法保持不递减。 

如果我们在每一步选择最大的可能值，我们可能会不必要地阻止需要较小早期选择的有效解决方案。 

真正的问题是每个位置都是一个区间，我们需要检查是否可以选择一系列值，从每个区间中选择一个值，形成一个非递减序列。 

## 方法

 蛮力解释很简单：对于每个位置，考虑其区间内所有可能的原始值`[a[i] - l, a[i] + r]`，并尝试对所有组合使用回溯或动态规划来构建非递减序列。 这是正确的，因为它直接探讨了有效性的定义。 然而，每个位置最多有`O(r + l)`可能性，以及以上`n`位置这会导致指数数量的组合，大致`(range size)^n`，这是完全不可行的。 

关键的观察是我们永远不需要记住一个位置的所有可能值。 如果我们从左到右处理，重要的只是前缀的可行值范围。 我们不是跟踪所有选择，而是跟踪最后选择的元素的所有可能值的间隔，以保持前缀有效。 

在位置`i`，假设我们已经知道最后选择的值必须位于某个区间内`[L, R]`。 对于下一个元素，我们必须选择一个值`x`这样`x >= L`和`x`在于`[a[i] - l, a[i] + r]`。 所以我们可以选择的最小可能值是`max(L, a[i] - l)`，最大值为`a[i] + r`。 如果该区间无效（下限超过上限），则无法构建。 

这就把问题变成了一个简单的区间传播过程。

 ## 算法演练

 我们维护有效前缀的最后一个元素的所有可能值的集合。 我们不保留一个集合，只保留它的可行范围`[L, R]`。 

1. 将第一个元素的范围初始化为`[a[0] - l, a[0] + r]`。 我们将下限限制为至少为零，因为原始值必须是非负的。 
2. 将此范围设置为当前可行区间。 
3. 对于每个下一个位置`i`，计算其允许的间隔`[low_i, high_i] = [a[i] - l, a[i] + r]`,再次夹紧`low_i`为零。 
4. 为了保持非递减顺序，新值必须至少为`L`。 所以我们将区间相交`[low_i, high_i]`和`[L, +infinity)`，给出一个新的下界`L' = max(L, low_i)`和上限`R' = high_i`。 
5. 如果在任何时候`L' > R'`，该位置不能选择有效值`i`不打破单调性，所以我们立即断定这是不可能的。 
6. 否则，更新`[L, R] = [L', R']`并继续。 
7. 如果我们成功处理所有元素，则存在一个有效的非递减隐藏数组。 

### 为什么它有效

 该算法在处理位置后保持了不变性`i`, 区间`[L, R]`恰好包含可以充当前缀的某些有效非递减序列的最后一个元素的所有值`1..i`。 每个步骤都会计算该集合与下一个元素的有效范围的交集。 由于两个约束都是凸区间，并且单调性仅施加下界，因此可达集始终保持区间。 如果间隔变空，则没有序列可以同时满足值约束和排序约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, l, r = map(int, input().split())
a = list(map(int, input().split()))

L = max(0, a[0] - l)
R = a[0] + r

for i in range(1, n):
    low = max(0, a[i] - l)
    high = a[i] + r

    L = max(L, low)
    R = high

    if L > R:
        print("NO")
        sys.exit()

print("YES")
```实现直接遵循间隔维护逻辑。 唯一微妙的细节是将下限限制为零，因为原始值不能为负。 另一个重要的一点是，除非通过可行性，否则我们永远不会根据先前的状态缩小上限，因为任何更大的值总是有利于未来的灵活性。

 ## 边缘情况

 一个微妙的边缘情况是`l = r = 0`。 在这种情况下，数组是固定的，问题减少为检查给定数组是否已经是非递减的。 该算法自然地处理这个问题，因为每个间隔都会崩溃为单个值，并且任何减少都会立即导致`L > R`。 

另一种情况是，早期的元素允许较宽的范围，但后来的元素强制设定一个尖锐的下限。 例如，像这样的序列`10, 0, 0`具有足够大的`l`和`r`如果第一个间隔强制最小值高于零，则在第二个位置可能仍然无效。 区间传播通过交叉范围和崩溃的可行性立即检测到这一点。 

最后一种情况是，第一个元素已经从较高值开始，但唯一可行的重建需要较小的值。 该算法正确地允许第一个间隔尽可能宽，并且不会过早地提交单个值，从而确保正确考虑后续约束。
