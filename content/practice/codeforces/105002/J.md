 ## 解决方案
 ## 问题理解

 我们得到了多套卡片，每张卡片上都写有一个数字。 从这些卡片中，我们考虑卡片的每个可能的子集。 对于每个子集，我们计算其中出现了多少个不同的值，然后将所有子集的数量相加。 

因此，任务不是一一评估子集，而是确定所有指数子集中“出现了多少个不同数字”的总贡献。 

输入尺寸可以达到$n = 10^5$，这立即排除了任何迭代所有子集的方法。 子集的数量是$2^n$，这是一个天文数字。 即使隐式生成子集也是不可能的。 任何有效的解决方案都必须以线性或近线性时间处理数组，可能使用每个值的组合计数参数。 

当所有数字都相等时，会出现微妙的边缘情况。 在这种情况下，如果每个子集非空，则它恰好贡献一个不同的值，但天真的推理可能会重复计算子集或错误地将重复项视为独立贡献。 

另一个特殊情况是所有数字都不同。 然后大小的每个子集$k$准确贡献$k$不同的值，所以答案简化为求和$k \cdot \binom{n}{k}$，它具有已知的封闭形式，但也可以从每个元素的贡献中导出。 

## 方法

 蛮力的想法很简单。 我们迭代索引的每个子集并计算其中不同值的数量。 对于每个子集，我们可以将其元素插入到集合中并计算其大小。 这是正确的，因为它直接遵循定义。 然而，它需要迭代所有$2^n$子集，并且对于每个子集可能扫描最多$n$元素。 这导致了复杂性的数量级$O(n 2^n)$，这远远超出了可行的范围。 

关键的观察是，我们可以翻转视角并独立思考每个值，而不是将子集视为整个对象。 当且仅当子集至少包含该值的一次出现时，该子集才为给定值的答案贡献一个单位。 这将问题转化为计数问题，对于每个不同的数字$x$，有多少个子集至少包含一个索引，其值为$x$。 

如果一个值$x$出现$k$次，那么有$n-k$其他元素。 避免的子集数量$x$完全是$2^{n-k}$，因为我们自由选择剩余元素的任何子集。 子集总数为$2^n$，因此至少包含一次出现的子集的数量$x$是$2^n - 2^{n-k}$。 每个这样的子集都对该值的非重复计数贡献 1。 

将所有不同值相加即可得出完整答案。 这将问题简化为计算频率和快速求二的幂的幂。

 | 最佳|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 计算数组中每个不同数字的出现频率。 这是必要的，因为一个值的贡献仅取决于它出现的次数，而不是它出现的位置。 
2. 预计算$2^n \bmod (10^9+7)$，因为该术语在所有值之间共享并表示子集的总数。 
3. 对于每个具有频率的不同值$k$, 计算$2^{n-k}$。 这会计算完全排除该值的所有子集。 
4. 减法$2^{n-k}$从$2^n$。 这给出了至少包含一次该值的子集的数量。 
5. 将这个贡献添加到全局答案模中$10^9+7$。 
6. 返回所有不同值的最终总和。 

关键思想是，如果某个值出现在每个子集中，则该子集对该值的计数只贡献一次，因此我们可以安全地对每个值的独立贡献求和。 

### 为什么它有效

 固定一个值$x$。 每个子集要么包含$x$至少一次或不包含任何内容。 第二类很容易统计，因为我们只是禁止所有包含以下内容的索引$x$，离开$n-k$自由职位。 补码原则保证这两个类别划分所有子集。 由于每个子集对不同计数的贡献正好为 1$x$如果它属于第一类，则对值求和可以对原始问题进行精确分解，而不会重叠或重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    total_subsets = pow2[n]

    ans = 0
    for k in freq.values():
        without = pow2[n - k]
        contrib = (total_subsets - without) % MOD
        ans = (ans + contrib) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```实现首先构建频率图，因为只有多重性才重要。 然后它预先计算 2 的幂$n$，允许恒定时间查找子集计数。 期限$2^n$作为子集总数存储一次。 

对于每个不同的值，我们减去完全排除它的子集的数量。 减法是按模进行的$10^9+7$，因此我们在每一步之后进行标准化以避免负值。

 ## 边缘情况

 当所有元素都相同时，表示输入`5 1 1 1 1 1`，该值的频率为 5。该算法计算总子集$2^5 = 32$，并且排除该值的子集是$2^0 = 1$, 给予贡献$31$。 由于只有一个不同值，因此答案为 31。对于该值，每个非空子集都会被精确计数一次，这与不同计数的定义相匹配。 

当所有元素都不同时，说`3 1 2 3`，每个值的频率为 1。对于每个值，排除它的子集是$2^{2} = 4$，所以贡献是$8 - 4 = 4$。 对三个相同的贡献求和得出 12。这证实了值之间的对称性得到了正确处理，并且每个值没有子集被重复计算。
