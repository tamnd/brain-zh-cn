 ## 解决方案
 ## 问题理解

 我们得到了一条有效的多米诺骨牌链，并且已经按顺序排列。 每个图块都有两个从 0 到 6 的数字。链中的相邻图块在接触端已经匹配，因此链是一致的。 

完整的多米诺骨牌集合恰好包含 0 到 6 之间每对无序值的一个图块，因此总共 28 个图块。 其中一些已经在链中使用，其余的瓷砖可用。 

任务是检查是否可以将任何未使用的图块添加到链的左端或右端，并遵守接触端必须具有相同数量的规则。 如果可能，我们必须输出此类图块的一个有效位置和方向。 如果不是，我们输出不存在任何移动。 

关键点是只有链的两个端点才重要。 如果候选图块的一端与最左边的暴露数字匹配，则该候选图块在左侧有效，对于右端也是如此。 

约束很小：链中最多有 28 个图块，并且可能的图块范围也恰好是 28 个。这立即排除了任何繁重的搜索。 即使直接扫描所有可能的图块也足够了，因为总状态空间的大小是恒定的。 

一个微妙的例子是方向。 像 (2, 5) 这样的图块可以放置为 (2, 5) 或 (5, 2)，具体取决于哪一侧连接到链端。 忘记翻转图块的粗心解决方案会错误地拒绝有效的移动。 

另一种边缘情况是多个图块有效时。 该问题允许任何有效答案，因此我们可以在第一个匹配处停止。 

## 方法

 暴力解释将模拟每个剩余的图块，并尝试将其以两个方向连接到链的两端。 对于每个图块，我们最多检查两个位置。 由于总共最多有 28 个图块，因此每次恒定时间最多进行 56 次检查。 即使我们明确地重建未使用的图块集，总工作量也可以忽略不计。 

不需要更深层次的组合或图形结构，因为链已经固定并且永远不会分支。 唯一的决定是是否可以扩展一个端点。 

关键的观察是我们不需要以复杂的方式显式地重建未使用的集合。 我们可以标记链中出现的所有图块，然后扫描完整的 28 个图块空间并测试端点的有效性。 

这将问题简化为对恒定宇宙的直接存在性检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 所有展示位置的暴力枚举 | O(28²) | O(28) | 已接受 |
 | 通过端点检查扫描所有图块 | O(28²) | O(28) | 已接受 |

 ## 算法演练

1. 读取多米诺骨牌链并按顺序存放。 阅读时，记录哪些图块对已被使用。 我们将 (a, b) 和 (b, a) 视为相同的图块，因为多米诺骨牌的可用性是无序的。 
2. 识别链的暴露端点。 左端点是第一个图块的左值，右端点是最后一个图块的右值。 这两个数字决定了所有可能的扩展。 
3. 迭代所有可能的多米诺骨牌 (a, b)，其中 0 ≤ a ≤ b ≤ 6。此枚举表示多米诺骨牌集中可用的完整牌组。 
4. 跳过链中已使用的任何图块。 这确保我们只考虑剩余的部分。 
5. 对于每个未使用的图块，检查它是否可以放置在左端。 如果 a 或 b 与左端点匹配，则为真。 如果是这样，则调整图块的方向，使匹配的数字连接到链上，然后立即以“L”方向输出。 
6. 如果左侧无法使用，请检查是否可以放置在右侧。 如果 a 或 b 匹配正确的端点，则为真。 如果是，则对其进行定向，使匹配的数字连接到右侧，然后以“R”方向输出。 
7. 如果没有方块满足任一条件，则输出“FISH”。 

### 为什么它有效

 该算法依赖于这样一个事实：任何有效的移动都必须恰好涉及链的一个端点。 由于多米诺骨牌集合是有限的并且是完全枚举的，因此每个可能的候选者都会被测试。 使用过的图块过滤可确保我们永远不会重复使用现有的多米诺骨牌，而端点匹配可确保邻接有效性。 因为我们在找到任何有效位置后立即输出，所以保留了完整性：如果存在解决方案，它将在枚举期间出现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
used = set()

tiles = []
for _ in range(n):
    a, b = map(int, input().split())
    tiles.append((a, b))
    used.add((a, b))

left_end = tiles[0][0]
right_end = tiles[-1][1]

for a in range(7):
    for b in range(a, 7):
        if (a, b) in used:
            continue

        if a == left_end or b == left_end:
            if b == left_end:
                a, b = b, a
            print("L")
            print(a, b)
            sys.exit(0)

        if a == right_end or b == right_end:
            if a == right_end:
                a, b = b, a
            print("R")
            print(a, b)
            sys.exit(0)

print("FISH")
```该实现首先将所有使用过的多米诺骨牌存储在一组中以进行 O(1) 成员资格检查。 这很重要，因为我们在枚举过程中根据使用的集合反复测试候选者。 

端点直接取自第一个和最后一个图块。 由于输入保证了有效的链，因此这些值是明确定义的。 

嵌套循环以规范形式枚举所有 28 个可能的多米诺骨牌 (a ≤ b)。 对于每个图块，我们首先确保它未被使用，然后测试左右兼容性。 通过交换端点来处理方向，以便将匹配的数字放置在正确的一侧。 

提前退出使用`sys.exit(0)`确保我们在找到有效的移动后立即停止，这符合任何有效答案都可接受的要求。

 ## 边缘情况

 一种边缘情况是链由单个图块组成。 在这种情况下，两个端点都来自同一个图块，因此左侧和右侧都是有效的附着点。 该算法仍然有效，因为它始终独立检查两个端点，并且接受任何匹配的未使用的图块。 

另一种情况是图块同时匹配两个端点。 例如，如果左端点是 3，右端点也是 3，则任何包含 3 的图块都可以沿任一方向附加。 该算法可以选择它找到的第一个匹配，这是可以接受的，因为允许任何有效答案。 

最后一种情况是所有剩余块均与两个端点有效断开连接。 对所有 28 个图块的枚举可确保正确检测到这种情况，因为没有候选者会通过任一端点测试，从而导致最终的“FISH”输出。
