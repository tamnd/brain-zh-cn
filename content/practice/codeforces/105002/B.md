 ## 问题理解

 我们得到三堆科学卡，每堆对应一个不同的符号。 一堆是R类型的卡，另一张是S类型的卡，还有一张是T类型的卡。还有一张特殊的卡，“科学家公会”，在看到最初的分布后可以将其分配给三种类型中的任何一种。 

评分系统有两个组成部分。 首先，每个符号贡献的分数等于您最终获得的该符号卡牌数量的平方。 其次，通过取出三个符号中的每一个的一张牌形成的每一个完整的三元组都会获得 7 分的奖励，其中这样的三元组的数量是三个最终计数中的最小值。 

任务是选择特殊卡牌应加入哪个符号以使最终得分最大化，然后计算该最大得分。 

输入大小非常大，每次计数最多 10^9，因此任何解决方案都必须在恒定时间内运行。 任何涉及迭代或模拟的事情都会被立即排除。 评分函数的结构表明我们只需要评估恒定数量的配置，因为唯一的决定是在哪里放置单个额外项目。 

当其中一堆非常小或为零时，就会出现一个微妙的陷阱。 奖励项取决于三个值中的最小值，因此增加最小的堆可能会增加平方项和三元组的数量。 例如，如果一堆牌为 0，则将额外的牌放在那里可能会解锁奖励积分，这些积分的价值超过了较大堆牌中的局部收益。 

## 方法

 暴力策略会尝试额外卡的所有可能分配并直接计算分数。 由于只有三个选择，这已经很小了，但仍然需要计算每种情况的完整评分公式。 天真的版本可能会更进一步，尝试分布多个假设调整或低效地重新计算最小值。 这将导致对大值的三重计数和二次运算进行不必要的重新计算。 

关键的观察是分数仅取决于最后的三元组`(R, S, T)`将其中之一精确地添加到其中之一后。 一旦我们选择了一个位置，就会使用直接算术在 O(1) 中计算分数。 只有三个状态需要评估，因此我们可以计算所有状态并选择最好的状态。 

该函数的结构非常简单，除了枚举三个可能的增量之外，不需要更深入的优化。

 ## 算法演练

 我们将特殊卡视为可以添加到三个计数之一的单位。 对于每个选项，我们计算结果分数并进行比较。 

1. 从原始计数 R、S 和 T 开始。 

我们还考虑三个候选状态：将额外的卡添加到 R、S 或 T。 
2. 对于每个候选人，计算最终计数。 

如果该卡被添加到R，则新状态为(R+1，S，T)。 对于其他人来说也是如此。 
3. 对于每个州，使用以下公式计算分数：

 每堆的平方和加上三堆最小值的 7 倍。 

这一步是常数时间，因为它只涉及三个算术运算和一分钟。 
4. 记录迄今为止看到的最佳分数以及相应的符号选择。 

每当发现严格更好的分数时，请更新答案。 
5. 评估所有三个选项后，输出产生最高分数的符号和分数本身。 

### 为什么它有效

 决策空间是完全离散的，并且仅限于三种可能性。 评分函数仅取决于最终计数，并且除了这些计数之外没有隐藏的交互作用。 由于每个配置都经过精确评估，因此该算法会探索整个可行空间。 因此保证能找到所有可行放置的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def score(r, s, t):
    m = min(r, s, t)
    return r * r + s * s + t * t + 7 * m

def main():
    R, S, T = map(int, input().split())

    best_val = -1
    best_choice = "R"

    # put in R
    v = score(R + 1, S, T)
    if v > best_val:
        best_val = v
        best_choice = "R"

    # put in S
    v = score(R, S + 1, T)
    if v > best_val:
        best_val = v
        best_choice = "S"

    # put in T
    v = score(R, S, T + 1)
    if v > best_val:
        best_val = v
        best_choice = "T"

    print(best_choice, best_val)

if __name__ == "__main__":
    main()
```该解决方案将评分隔离到辅助函数中，以便对每个候选配置进行一致的评估。 关键细节是每个案例都是独立计算的，确保状态之间不会意外结转。 

比较只是严格的改进，这很好，因为关系可以返回任何有效的选择。

 ## 边缘情况

 当所有堆都为零时，将卡片添加到任何符号都会产生相同的结构：一个平方项等于 1，其他项为 0，而最小值仍为 0。该算法独立评估所有三种情况，因此它可以正确返回任何符号。 

当一堆占主导地位而其他堆为零时，添加到主要堆中会显着增加平方，而添加到较小堆中不会以有意义的方式改变最小值。 该算法明确地评估这两种效应，因此它自然会在适当的时候更喜欢占主导地位的堆。 

当所有值相等时，三个候选状态中的每一个在增量后都是对称的，因此所有计算的分数都匹配。 由于该算法只需要任何最佳答案，因此返回遇到的第一个最大值是正确的。
