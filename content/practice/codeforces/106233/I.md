 ## 解决方案
 ## 问题理解

 我们在平面上放置了一系列魔法标记。 这`i`第 - 个标记有坐标`(xi, yi)`。 技巧选择连续的标记段，并将该段中的每个标记围绕给定点顺时针旋转 90、180 或 270 度。 在每个技巧之后，我们需要包含所有标记的最小轴对齐矩形的面积。 

挑战在于操作是针对数组中的位置，而不是针对整个点集。 一个标记可以移动多次，以后操作的段端点取决于原始索引。 我们需要在每次更新后保留所有标记的坐标，并快速找到全局最小和最大 x 和 y 值。 

约束允许最多`2 * 10^5`标记和`2 * 10^5`轮换。 移动所选区间内每个标记的直接模拟最多需要`O(nq)`操作，可以到达周围`4 * 10^10`坐标变化并且远远超出了几秒钟所允许的范围。 解决方案必须使每个运算接近对数。 

困难的情况不是旋转本身，而是随着时间的推移保持变换正确。 一个线段可以旋转多次，并且旋转可以围绕不同的中心。 例如，如果单个点旋转两次，则第二次旋转必须使用该点已更改的位置。 

对于输入：```
1 1
5 7
1 1 0 0 90
```重点`(5,7)`变成`(-7,5)`，因此边界矩形的面积为零。 仅存储宽度和高度的粗心实现将丢失绝对位置并失败。 

另一种情况是：```
2 1
0 0
10 1
1 2 5 5 180
```两个点都围绕`(5,5)`并成为`(10,10)`和`(0,9)`。 答案是`90`。 仅旋转线段中心或仅交换坐标而不处理平移的解决方案将产生错误的矩形。 

## 方法

 一个简单的解决方案是显式存储每个点。 对于每个查询，迭代自`l`到`r`，旋转每个点，并更新全局最小和最大坐标。 这是正确的，因为每个点始终保持在其真实的当前位置。 当间隔很大时就会出现问题。 在最坏的情况下，每个查询都会触及所有`n`点，所以复杂度变成`O(nq)`。 

有用的观察是矩形不需要知道其内部的每个点。 对于任何点集，其边界框完全由四个值确定：最小 x、最大 x、最小 y 和最大 y。 如果我们可以一次更新整个段的这四个值，问题就会变得小得多。 

绕点的旋转是仿射变换。 它使用以下形式的公式更改坐标：```
x' = a*x + b*y + c
y' = d*x + e*y + f
```这里使用的四种可能的旋转仅交换符号和坐标。 将这种变换应用于边界框只需要检查框的四个角，因为仿射变换将轴对齐矩形的极值点映射到极值候选点。 

这自然会导致线段树。 每个节点存储其间隔的边界框和等待传递给子节点的惰性仿射变换。 当查询覆盖整个节点时，我们会变换其存储的矩形，而不是访问所有点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(nq) | O(n) | 太慢了|
 | 具有惰性转换的线段树 | O((n+q) log n) | O((n+q) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 在标记的原始排序上构建线段树。 对于每个节点，存储该区间内所有点的最小和最大 x 和 y 值。 最初，每个惰性转换都是恒等转换。 
2. 将每次旋转表示为仿射变换。 顺时针旋转 90 度`(x0, y0)`，公式为：```
x' = y0 - y + x0
y' = x - x0 + y0
```180 度和 270 度的情况以相同的表示方式处理。 

1. 当更新完全覆盖线段树节点时，将旋转直接应用于节点的边界框。 变换四个角，找到新的最小和最大坐标，并将它们存储起来。 
2. 将新的转换与节点现有的惰性转换相结合。 新的转换必须在先前待处理的转换之后应用，因为它代表最新的更改。 
3. 当访问部分覆盖的节点时，将其惰性转换推送给两个子节点。 这可以在继续递归之前保持子信息同步。 
4. 每次更新后，根包含每个标记的边界框，因此它的宽度和高度给出了答案：```
(max_x - min_x) * (max_y - min_y)
```工作原理：线段树的不变性是每个节点都存储其区间内所有点的当前位置的精确边界框，以及仍需要传播到子节点的变换。 对整个区间应用旋转是安全的，因为区间内的每个点都会接受相同的仿射变换。 由于变换后的矩形角包含变换后的极值，因此更新后的边界框是准确的。 组合惰性转换可以为未来的操作保留相同的含义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def compose(t2, t1):
    a2, b2, c2, d2, e2, f2 = t2
    a1, b1, c1, d1, e1, f1 = t1
    return (
        a2 * a1 + b2 * d1,
        a2 * b1 + b2 * e1,
        a2 * c1 + b2 * f1 + c2,
        d2 * a1 + e2 * d1,
        d2 * b1 + e2 * e1,
        d2 * c1 + e2 * f1 + f2,
    )

def apply_transform(node, t):
    a, b, c, d, e, f = t
    mnx, mxx, mny, mxy = node[:4]

    xs = []
    ys = []
    for x, y in ((mnx, mny), (mnx, mxy), (mxx, mny), (mxx, mxy)):
        xs.append(a * x + b * y + c)
        ys.append(d * x + e * y + f)

    node[0] = min(xs)
    node[1] = max(xs)
    node[2] = min(ys)
    node[3] = max(ys)

    node[4] = compose(t, node[4])

def build(v, l, r, pts, tree):
    if l == r:
        x, y = pts[l]
        tree[v] = [x, x, y, y, (1, 0, 0, 0, 1, 0)]
        return
    m = (l + r) // 2
    build(v * 2, l, m, pts, tree)
    build(v * 2 + 1, m + 1, r, pts, tree)
    pull(v, tree)

def pull(v, tree):
    left = tree[v * 2]
    right = tree[v * 2 + 1]
    tree[v][0] = min(left[0], right[0])
    tree[v][1] = max(left[1], right[1])
    tree[v][2] = min(left[2], right[2])
    tree[v][3] = max(left[3], right[3])

def push(v, tree):
    t = tree[v][4]
    if t != (1, 0, 0, 0, 1, 0):
        apply_transform(tree[v * 2], t)
        apply_transform(tree[v * 2 + 1], t)
        tree[v][4] = (1, 0, 0, 0, 1, 0)

def update(v, l, r, ql, qr, t, tree):
    if ql <= l and r <= qr:
        apply_transform(tree[v], t)
        return
    push(v, tree)
    m = (l + r) // 2
    if ql <= m:
        update(v * 2, l, m, ql, qr, t, tree)
    if qr > m:
        update(v * 2 + 1, m + 1, r, ql, qr, t, tree)
    pull(v, tree)

def rotation(x, y, a):
    if a == 90:
        return (0, -1, x + y, 1, 0, y - x)
    if a == 180:
        return (-1, 0, 2 * x, 0, -1, 2 * y)
    return (0, 1, x - y, -1, 0, x + y)

def solve():
    n, q = map(int, input().split())
    pts = [None] + [tuple(map(int, input().split())) for _ in range(n)]

    tree = [[0, 0, 0, 0, (1, 0, 0, 0, 1, 0)] for _ in range(4 * n + 5)]
    build(1, 1, n, pts, tree)

    ans = []
    for _ in range(q):
        l, r, x, y, a = map(int, input().split())
        update(1, 1, n, l, r, rotation(x, y, a), tree)
        ans.append(str((tree[1][1] - tree[1][0]) * (tree[1][3] - tree[1][2])))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该树存储四个坐标和一个待处理的变换。 这`apply_transform`功能是解决方案的核心。 它通过变换所有四个角来更新边界矩形，然后存储组合变换以供以后传播。 

作文顺序是最容易出错的地方。 如果一个节点已经有变换`old`，以及新的旋转`new`到达，产生的变换是`new(old(point))`，所以乘法顺序`compose`遵循那个方向。 

递归使用正常的线段树区间逻辑。 完全覆盖立即应用转换，而部分覆盖则在访问儿童之前将待处理的操作推后。 Python 整数在这里不会溢出，这很有用，因为坐标在旋转过程中会增长。

 ## 边缘情况

 对于单个点：```
1 1
5 7
1 1 0 0 90
```线段树叶存储了精确的点。 旋转变换将存储的最小和最大坐标更改为新的点位置。 根具有相等的 x 值和相等的 y 值，因此面积为零。 

对于围绕任意中心的旋转：```
2 1
0 0
10 1
1 2 5 5 180
```直接变换根矩形。 旧矩形的四个角成为新矩形的候选角。 算法得到x范围`[0,10]`和 y 范围`[9,10]`,给定面积`90`。 

对于重复变换：```
3 2
1 1
2 2
3 3
1 2 0 0 180
2 3 10 10 270
```第一个更新存储前两个位置的待定 180 度旋转。 在第二次更新期间，树在下降之前推动此变换，因此第二次旋转应用于已经旋转的坐标。 这保留了每个标记的实际当前状态。
