 ## 解决方案
 ## 问题理解

 我们正在为一个点规划一条连续路径，该点从平面左侧的固定起始位置移动到右侧的固定结束位置。 水平位移是固定的，但我们可以自由选择平面上的任何曲线，只要运动是连续的并且以单位速度行进，因此总行进时间等于路径长度。 

一路上，单位时间有恒定的背景成本，此外垂直线上放置一两个固定的“放射源”$x = 0$。 每个源所贡献的成本随着到该点的距离的平方反比而急剧增长。 因此，路径的总成本是路径长度加上每个岛屿的所有平方反比距离贡献的时间积分。 

任务是选择一条几何路径，使总累积成本最小化。 

重要的结构细节是所有岛屿都位于同一垂直线上。 这破坏了您在具有潜力的一般最短路径中可能期望的大多数对称性，因为每个“交互”仅在路径接近时才会发生$x = 0$。 在该区域之外，成本纯粹是累加的且是统一的。 

从限制条件来看，岛屿数量极少，最多只有两个。 这立即表明，只要对路径形状的优化是低维的，任何解决方案都允许每个候选路径很重。 如果我们天真地尝试离散平面或搜索所有曲线，我们将处理无限维优化，这是不可行的。 即使对精细网格进行采样也会太慢，因为成本评估本身涉及连续积分。 

一个常见的微妙失败案例来自于假设最佳路径始终是一条直线。 

例如，考虑一个位于$(0, 0)$， 开始$(-10, -1)$， 结尾$(10, 1)$。 一条直线经过最靠近岛屿的位置：$x = 0$，平方反比项在该点附近爆炸。 向上或向下弯曲以增加最小距离的稍长路径可以减少积分，而不是增加长度。 因此，限制直线通常是不正确的。 

另一个陷阱是假设路径必须经过一个“中点”$x=0$通过线性插值确定。 这也会失败，因为成本函数在交叉点的垂直坐标中是非线性的。 

## 方法

 蛮力观点会尝试从头到尾考虑所有可能的连续曲线并计算它们的积分。 即使我们将自己限制为具有许多段的分段线性路径，自由度也会变大，并且优化会变成高维连续问题。 每个候选路径的评估已经需要整合有理函数，因此任何对形状的组合搜索都变得毫无希望。 

关键的观察结果是所有奇点都位于一条垂直线上。 这表明路径仅“重要”在于它如何从左半平面通过$x < 0$到右半平面$x > 0$。 在每个半平面内，没有点源，因此唯一的成本是路径长度加上仅取决于到线上固定点的距离的平滑贡献。 

这种结构意味着，对于一条最优路径，我们只需要决定一个几何自由度：路径与线相交的点$x = 0$。 一旦交叉点固定，每一侧的最佳子路径就会变成一条直线段，因为在每个半平面中，除了调整到岛屿的距离剖面外，没有理由弯曲，而且这种效果完全由端点决定。 

所以问题归结为选择一个真实的值$y^\*$，我们穿过的高度$x = 0$。 完整的路径变成两条直线：从开始到$(0, y^\*)$，并从$(0, y^\*)$到目的地。 对于每一个选择$y^\*$，我们可以以封闭形式计算精确的成本。 

由于最多有两个岛屿，因此评估单个候选者$y^\*$是持续不断的工作，我们可以优化$y^\*$使用三元搜索，因为生成的成本函数是平滑且单峰的。

 ## 算法演练

 我们将路径视为在可变点相交的两条直线段$(0, y)$。 该算法对此进行了优化$y$。 

1.修复候选路口高度$y$。 这完全确定了路径几何形状，因为两条线段都是固定端点之间的直线$(0, y)$。 
2. 计算两条线段的几何长度。 左段长度为$\sqrt{10^2 + (y - A)^2}$，右段长度为$\sqrt{10^2 + (B - y)^2}$。 这说明了旅行时间和恒定的背景辐射。 
3. 对于每个岛屿$(0, C_i)$，分别计算其对两个部分的贡献。 沿着每个线段，到岛的距离的平方是线段参数的二次函数，因此积分$1/d^2$简化为封闭形式的反正切表达式。 
4. 将所有岛屿和两个部分的所有贡献相加以获得总成本$f(y)$。 
5. 执行三元搜索$y$在区间内$[-10, 10]$（或稍微扩大的安全范围）。 每个评价都是$O(N)$，并且自从$N \le 2$，这在实践中是常数时间。 
6. 返回最小值$f(y)$。 

它的工作原理与成本函数的结构有关。 在每个半平面内，一旦端点固定，任何与直线段的偏差都会线性增加路径长度，同时只会以平滑的方式影响积分项，不会产生额外的局部最小值。 唯一的全局自由度是在穿越奇异线时允许路径接近每个岛屿的距离$x=0$。 这种相互作用完全由单个参数捕获$y$，使成本有效地成为一变量平滑函数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

EPS = 1e-12

def segment_cost(x1, y1, x2, y2, islands):
    dx = x2 - x1
    dy = y2 - y1

    length = math.hypot(dx, dy)
    total = length

    for c in islands:
        b = y1 - c
        k = dy / dx

        A = 1.0 + k * k
        B = 2.0 * k * b
        C = b * b

        D = 4.0 * A * C - B * B
        if D < 0:
            D = 0.0
        sqrtD = math.sqrt(D)

        def F(x):
            return math.atan((2.0 * A * x + B) / (sqrtD + EPS))

        val1 = F(x1)
        val2 = F(x2)

        total += (2.0 / (sqrtD + EPS)) * (val2 - val1)

    return total

def solve_case(N, A, B, Cs):
    islands = Cs

    def f(y):
        cost = 0.0
        cost += segment_cost(-10.0, A, 0.0, y, islands)
        cost += segment_cost(0.0, y, 10.0, B, islands)
        return cost

    lo, hi = -10.0, 10.0

    for _ in range(80):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        if f(m1) < f(m2):
            hi = m2
        else:
            lo = m1

    return f((lo + hi) / 2.0)

def main():
    T = int(input())
    for tc in range(1, T + 1):
        parts = input().split()
        N = int(parts[0])
        A = float(parts[1])
        B = float(parts[2])

        Cs = list(map(float, input().split())) if N > 0 else []

        ans = solve_case(N, A, B, Cs)
        print(f"Case #{tc}: {ans:.6f}")

if __name__ == "__main__":
    main()
```该代码首先定义一个函数来评估单个直线段的贡献，结合几何长度和平方反比辐射积分。 每个岛屿都是独立加工的，并添加到总成本中。 

核心思想是唯一的自由变量是交叉高度$y$，所以求解器将所有内容包装到一个函数中$f(y)$并执行三元搜索。 选择 80 次迭代足以在所需的条件下达到数值稳定性$10^{-3}$容错性。 

积分计算时必须小心，因为该表达式涉及二次分母和小判别式附近的数值不稳定。 小的 epsilon 可以稳定反正切计算。 

## 工作示例

 考虑一个岛屿场景，该岛位于$C_1 = 0$，开始是$( -10, -2 )$，结束是$(10, 2)$。 

我们评估三个候选交叉高度。 

| y | 左段成本| 右段成本| 总计 |
 | --- | --- | --- | --- |
 | -2 | 左转，离岛较远| 向右更长，离岛更远| 中等|
 | 0 | 对称，最接近岛屿 | 对称，最接近岛屿 | 高|
 | 2 | 向左越远，离岛越远| 右近，离岛较远| 中等|

 这表明远离岛屿高度，成本最小化。 

对于双岛的情况，权衡就是平衡到两个岛的距离$C_1$和$C_2$，以及最优的$y$位于他们之间。

 ## 边缘情况

 当没有岛屿时，算法简化为从开始到结束选择一条直线段。 三元搜索仍然评估仅包含几何长度的函数，并且最小值正确地出现在凸函数的任何一致的中点行为处。 

当交叉高度$y$接近岛屿坐标$C_i$，由于平方反比奇点，积分项变大。 反正切计算中的数值稳定性确保函数对于所有测试值都保持有限，并且三元搜索自然地避免了奇异区域，因为它急剧增加了成本。 

当两个岛屿都存在并且彼此非常接近时，它们之间的成本景观就会急剧达到顶峰。 单峰结构仍然成立，因为两个贡献在交叉高度上都是凸的，因此组合函数保留了三元搜索可以可靠定位的单个最小值。
