 ## 解决方案
 ## 问题理解

 该树的每个顶点上都包含一个小写字母。 每个有序的顶点对都定义一个字符串：从第一个顶点开始，沿着唯一的路径走到第二个顶点，然后连接遇到的字母。 任务是在所有此类有序路径中按字典顺序找到第 K 个最小的字符串。 

顶点数量多达10万个，这意味着可能的路径数量可达100亿条。 枚举每条路径或对它们进行排序是不可能的。 我们需要利用 K 最多只有 100000 的事实。我们只需要字典顺序的开头，而不是整个集合。 

一个常见的错误是将路径视为无向的。 从 u 到 v 的路径和从 v 到 u 的路径是不同的字符串，因为它们的字母读取方向不同。 

例如：```
2 1
a b
1 2
```可能的字符串是`a`,`b`,`ab`， 和`ba`。 答案是`a`， 不是`ab`，因为具有相同前缀的较短字符串较小。 

## 方法

 直接的解决方案是生成所有 N² 路径，将每个路径转换为字符串，对它们进行排序，然后取出第 K 个元素。 一棵树的遍历可以在 O(N) 时间内找到一条路径，因此这种方法在最坏的情况下需要 O(N³) 的工作，这远远超出了极限。 

有用的观察结果是 K 很小。 我们可以使用优先级队列按字典顺序生成路径，而不是构建整个排序列表。 每个队列元素代表一条已构建的路径。 最初，每个顶点都是长度为一的有效路径。 当我们删除最小路径时，我们会在每个可能的方向上将其扩展一个相邻顶点，但不会立即返回到前一个顶点。 

这相当于探索所有有效树路径的隐式特里树。 优先级队列总是包含最小的未完成前缀，因此重复取最小值给出下一个字典路径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N3) | O(N²) | 太慢了 |
 | 优先级队列枚举| O((N+K) log(N+K) + S) | O(N+K) | 接受 K ≤ 100000 |

 ## 算法演练

 1. 将每个顶点作为初始路径插入优先级队列中。 这些字符串中的每一个都代表一条在同一顶点开始和结束的路径。 
2. 从队列中删除最小的字符串。 这是按字典顺序排列的下一条路径，因此将其视为答案之一。 
3、如果这是第K个被移除的字符串，则立即输出。 不需要生成剩余的路径。 
4. 否则，将当前路径延伸到除我们来自的顶点之外的最后一个顶点的每个邻居。 将这些新路径插入队列中。 

这样做的原因是每条有效路径都有一个通过删除其最后一个顶点而获得的前驱路径。 优先级队列保持所有可能的连续有序，因此在较小的路径之前不能跳过任何路径。 

为什么它有效：

 队列不变式是它包含可能成为下一个答案的每个生成路径。 当最小元素被移除时，不在队列中的每条路径要么已经被输出，要么具有更小的前缀并在队列中等待。 因此，删除的元素始终是下一个字典路径。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    letters = input().split()

    graph = [[] for _ in range(n)]
    for _ in range(n - 1):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        graph[a].append(b)
        graph[b].append(a)

    heap = []

    for i in range(n):
        heapq.heappush(heap, (letters[i], i, -1))

    count = 0

    while heap:
        s, node, parent = heapq.heappop(heap)
        count += 1

        if count == k:
            print(s)
            return

        for nxt in graph[node]:
            if nxt != parent:
                heapq.heappush(heap, (s + letters[nxt], nxt, node))

if __name__ == "__main__":
    solve()
```队列将当前字符串以及路径的最后两个顶点存储在一起。 前一个顶点是必要的，因为树路径不能立即向后走，否则同一条边将被遍历两次。 

初始化插入 N 个长度为 1 的路径。 删除路径后，将添加所有可能的一步扩展。 一旦提取了 K 条路径，算法就会停止，因此它不会尝试构建整个路径集。 

主要的实现细节是保留前一个顶点。 如果没有它，扩展将产生无效的遍历，例如`a b a b a`，它们不是树中的简单路径。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O((N+K) log(N+K) + L) | 每个提取的路径都会创建扩展，并且仅删除 K 条路径 |
 | 空间| O(N+K) | 堆存储活动候选者 |

 该解决方案依赖于 K 以 100000 为界。仅生成排序的前缀可以避免可能路径的二次数量。 

## 边缘情况

 单个顶点树：```
1 1
a
```唯一的路径是`a`，所以答案是`a`。 初始队列已经包含完整的答案。 

重复字母：```
3 3
a a a
1 2
2 3
```许多字符串对其第一个字符进行同等比较。 堆仍然处理这个问题，因为比较的是整个字符串，而不仅仅是第一个字母。 

定向路径：```
2 4
a b
1 2
```有序路径是：```
a
ab
b
ba
```最后的答案是`ba`。 将树视为无向树会错误地合并`ab`和`ba`。 存储的前一个顶点保留了遍历的方向。
