 ## 解决方案
 ## 问题理解

 我们有几个表情符号值数组。 目标不是对整个数组进行排序。 相反，我们可以选择数组的连续部分并删除该部分内的一些元素，以便其余元素按非递减顺序排列。 所选部分之前和之后的元素并不重要，也不算作删除。 

我们必须输出的第一个值是可以保留的表情符号的最大可能数量。 第二个值是在所选间隔内获得最佳序列所需的删除表情符号的最小数量。 

这些约束迫使求解接近线性。 单个测试用例最多可以包含 100000 个值，所有大小的总和最多为 1000000。尝试每个间隔已经给出了二次工作，最大的情况大约为 10^10 次操作，这远远超出了限制。 我们需要一个 O(N log N) 方法。 

一个常见的错误是仅计算最长的非递减子序列长度并输出 N 减去该值。 这会将所选间隔之外的表情符号视为已删除，这是不允许的。 例如，数组`1 2 3 100 0`具有长度为 4 的最长非递减子序列，使用`1 2 3 100`，但答案只删除了`0`如果选择整个间隔。 外部元素不会自动删除。 

另一种边缘情况是整个数组已经非递减。 用于输入`1 2 2 5`，正确的输出是`4 0`。 始终将删除的元素计为的解决方案`N - length`可能会意外地在这里工作，但在最佳子序列位于较小间隔内的数组上失败。 

## 方法

 暴力方法是尝试每一个可能的间隔，计算其中最长的非递减子序列，并保留最佳答案。 有 O(N^2) 个间隔，并且为每个间隔计算子序列已经很昂贵，因此直接实现中总工作量变为 O(N^3)。 

关键的观察是剩余的表情符号必须形成原始数组的非递减子序列。 保留表情符号的最大数量是最长的非递减子序列。 关于删除的额外条件意味着我们必须记住子序列的开始和结束位置，因为只能删除这些位置之间的元素。 

我们可以使用耐心排序思想来求最长非递减子序列。 在处理数组时，我们为每个子序列长度维护尽可能小的结束值。 除了这些信息之外，我们还保留足够的位置数据来重建包含最佳子序列的最佳间隔。 

子序列长度给出了第一个答案。 一旦选择的最优子序列具有第一个索引`l`和最后一个索引`r`，删除的次数为`(r - l + 1) - length`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N^3) | O(N^3) | O(N) | 太慢了 |
 | 最佳 | O(N log N) | O(N log N) | O(N) | 已接受 |

 ## 算法演练

 1. 仅出于排序目的压缩值并从左到右处理数组。 对于每个值，我们需要知道当前元素可以扩展的最佳非递减子序列。 
2. 对压缩值使用 Fenwick 树。 每个 Fenwick 节点存储以该前缀中的值结尾的最佳子序列状态。 状态包含子序列长度、起始位置和结束位置。 
3. 对于当前值`a[i]`，查询之前所有小于或等于它的值。 最佳返回状态可以扩展，因为添加`a[i]`保持序列非递减。 
4. 通过将长度加一并将结束位置设置为来创建一个新状态`i`。 更新压缩位置处的 Fenwick 树`a[i]`。 
5.处理完所有元素后，选择长度最大的状态。 如果多个状态的长度相同，则选择间隔大小最小的一个。 
6. 答案长度是选择的状态长度。 删除的表情符号的数量是其间隔的大小减去保留的长度。 

为什么它有效：

 每个有效的最终消息都对应于某个区间内的非递减子序列。 芬威克树考虑了所有可能的前驱关系，因为一个值可以精确地扩展以不大于其自身的值结尾的子序列。 存储的最佳状态保留了可以导致最佳结果的候选状态，因此最终的最大长度是最长的可能非递减子序列，并且选择的间隔是最佳解决方案中最小的间隔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(a):
    vals = sorted(set(a))
    comp = {v: i + 1 for i, v in enumerate(vals)}
    m = len(vals)

    bit = [(0, 0, 0)] * (m + 2)

    def better(x, y):
        if x[0] != y[0]:
            return x if x[0] > y[0] else y
        if x[0] == 0:
            return x
        sx = x[2] - x[1] + 1
        sy = y[2] - y[1] + 1
        return x if sx < sy else y

    def query(i):
        ans = (0, 0, 0)
        while i:
            ans = better(ans, bit[i])
            i -= i & -i
        return ans

    def update(i, value):
        while i <= m:
            bit[i] = better(bit[i], value)
            i += i & -i

    answer = (0, 0, 0)

    for i, x in enumerate(a):
        prev = query(comp[x])
        if prev[0] == 0:
            cur = (1, i, i)
        else:
            cur = (prev[0] + 1, prev[1], i)
        update(comp[x], cur)
        answer = better(answer, cur)

    return answer[0], answer[2] - answer[1] + 1 - answer[0]

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        x, y = solve_case(a)
        out.append(f"{x} {y}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```Fenwick 树存储有关值前缀的信息。 查询前缀正是非递减子序列所需的操作，因为前一个选择的值不能超过当前的值。 

状态存储起始索引而不仅仅是长度。 这是处理异常删除规则的细节。 我们不希望删除的数量包含所选区间之外的表情符号，因此必须跟踪区间边界。 

压缩坐标是必要的，因为表情符号值可以大到 10^9，但只有它们的相对顺序很重要。 压缩值的数量最多为 N，因此所有 Fenwick 操作仍为 O(log N)。

 最终的子序列是`3 3 1 3`？ 该候选者被拒绝，因为它不是非递减的。 有效的最佳状态对应于包含以下内容的区间：`1 3 3 3`，长度为 4，间隔大小为 7，因此删除了三个表情符号。

 ## 边缘情况

 对于单个表情符号，所选间隔仅包含该元素。 该算法创建一个长度为 1 的子序列，间隔长度也为 1，因此删除次数为零。 

对于具有重复值的数组，必须接受相等性。 Fenwick 查询使用小于或等于当前值的值，这是处理非递减序列和严格递增序列之间的区别。 

对于递减数组，例如`5 4 3 2 1`，每个元素只能开始长度为1的子序列。 该算法仍然返回正确的最大长度，并且不会在所选间隔之外进行不必要的删除。 

对于最佳子序列被不相关元素包围的情况，存储的开始和结束位置防止将那些外部元素计为移除。 这是该问题与普通最长子序列问题之间的主要区别。
