 ## 问题理解

 该任务的核心是确定给定的整数是否表现得像素数，并对每个查询做出相应的响应。 更具体地说，输入由一个或多个整数组成，对于每个整数，我们必须确定它是否是合数，然后输出一个简单的判断。 

从计算的角度来看，这里的关键结构对象是每个查询的单个数字。 查询之间没有交互，因此可以独立分析每个值。 输出通常是每个输入数字的二元决策，通常表示为“是”或“否”等单词，具体取决于数字是否满足所需的非质数条件。 

此类问题隐含的约束通常允许值达到 10^9 或 10^12 左右。 这立即排除了任何尝试通过简单除法将数字分解为 n 的方法，因为在最坏的情况下，每个测试用例最多需要 10^9 次操作。 即使迭代到 n 本身也远远超出了可行的限制。 如果我们依赖直接整除性检查，则平方根有界方法（其中每个数字仅测试到 √n）是唯一合理的方向。 

有一些边缘情况很容易被错误处理。 

一是值 1。例如，如果输入为 1，仅测试从 2 向上整除的朴素素数检查可能会错误地将其分类为素数，因为未找到除数。 正确的输出应将 1 视为非素数。 

另一个边缘情况是 2。由于 2 是最小的质数，因此任何从 2 向上开始检查除数的循环都必须确保它不会错误地将 2 标记为合数。 例如，如果循环运行`for i in range(2, n)`并默认将任何没有除数的数字视为合数，如果逻辑反转，则 2 将被错误处理。 

第三种微妙情况是大于 2 的偶数。例如，16 应该立即被识别为复合数，而无需进行全因子检查，而 17 则需要更深入的检查。 幼稚的方法可能会以类似的方式对待两者并做不必要的工作。 

## 方法

 最直接的策略是测试每个数字是否能被从 2 到数字本身减一的每个整数整除。 这是有效的，因为当且仅当一个数字除了 1 和它本身之外没有约数时，它才是素数。 从定义来看，正确性是直接的，但成本与数字的值成线性关系。 如果输入最多 10^9，这意味着每个测试用例最多 10^9 次迭代，即使对于单个查询也是不可行的。 

这一改进来自于观察到任何合数都必须有一个因子对，并且这些因子中至少有一个小于或等于该数的平方根。 这大大减少了搜索空间。 我们不需要检查到 n，而只需要检查到 √n。 这将问题从每个数字的线性复杂度转变为每个数字的次线性复杂度，这足以满足典型的约束。 

进一步的改进是单独处理小案件甚至案件。 如果数字小于 2，则自动为非素数。 如果是 2 或 3，则它是质数。 如果它是偶数并且大于2，则立即合成。 在这些检查之后，我们只测试奇数除数。

 ## 算法演练

 优化方法遵循搜索空间的结构化缩减。 

1、读取需要分类的整数n。 
2. 立即处理低于 2 的值，将其标记为非素数。 这是必要的，因为素数的定义是从 2 开始的。 
3. 如果 n 等于 2 或 3，则返回它是素数。 这些是最小的素数，充当算法的边界锚。 
4. 如果 n 能被 2 整除并且大于 2，则将其分类为非素数。 这会从进一步处理中删除所有偶数，从而显着减少后续工作。 
5. 迭代从 3 到 √n 的奇数整数。 对于每个候选除数 i，检查 n mod i 是否等于 0。 
6. 如果发现任何约数，则立即将 n 分类为非素数并停止进一步检查。 即使只有一个除数的存在也足以反驳素性。 
7. 如果完成循环后没有找到约数，则将 n 分类为素数。 

正确性依赖于这样一个事实：任何合数 n 必须具有一个因子对 (a, b)，使得 a × b = n。 如果a和b都大于√n，它们的乘积将超过n，这是不可能的。 因此，至少有一个因素必须位于测试范围内，以确保环路能够检测到它（如果存在）。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0:
        return False

    limit = int(math.isqrt(n))
    i = 3
    while i <= limit:
        if n % i == 0:
            return False
        i += 2
    return True

def solve():
    data = input().strip().split()
    if not data:
        return

    t = 1
    nums = list(map(int, data))

    # If multiple numbers are given, treat first as t or process all
    # Here we assume single or multiple independent queries
    res = []
    for n in nums:
        res.append("YES" if not is_prime(n) else "NO")

    print("\n".join(res))

if __name__ == "__main__":
    solve()
```功能`is_prime`干净地封装了逻辑。 早期退出在任何循环开始之前处理较小的数字甚至值，这避免了不必要的计算。 该循环仅检查奇数除数，直到通过计算得出的整数平方根`math.isqrt`，这避免了浮点精度问题。 

这`solve`函数是防御性地编写的，以处理输入格式的单个和多个整数，因为这种风格的问题有时在它们呈现查询的方式上有所不同。
