 ## 解决方案
 ## 问题理解

 我们被给予`n`具有长度的线段`a[i]`。 我们需要计算有多少种方式来准确选择`k`使所选线段可以形成一个非退化多边形，其顶点位于圆上。 具有相同长度的段仍然是不同的选择，因为每个发现的段都被认为是唯一的。 

对于一组边长，能够形成非退化多边形相当于最长边严格小于所有剩余边的总和。 满足这个条件的多边形可以排列成循环多边形，所以问题就变成了计数`k`-元素子集，其中没有选定的段至少与其他段的总长度一样长。 

输入尺寸允许`n`达到大约一百个并且长度可能足够大以至于不可能检查所有子集。 可能的选择数量是`C(n, k)`，即使对于中等值，其增长也太快`n`。 我们需要一个多项式时间的解决方案。 一个段的最大长度仅为`10000`，这是我们可以利用的关键界限。 

棘手的部分是我们不能只看全局的最大值。 子集可能因其自身最大的元素而无效。 例如：```
Input
4 3
1 2 3 10
```答案是`1`因为唯一有效的选择是`{1,2,3}`。 仅检查所有分段总和的粗心实现可能会错误地得出大分段始终可以参与的结论。 

另一个边缘情况是重复长度。 例如：```
Input
5 3
3 3 3 1 2
```答案是`7`。 三段长度`3`是不同的对象，因此包含不同副本的组合必须单独计数。 将长度视为唯一值会低估。 

最后一个边界情况是平等。 条件很严格。 例如：```
Input
3 3
1 2 3
```答案是`0`因为`3 = 1 + 2`，生成退化三角形而不是有效的多边形。 使用`<=`而不是`<`会给出错误的结果。 

## 方法

 直接的方法是生成大小的每个子集`k`，找到它的最大边，并测试该最大值是否小于其他边的总和。 这是正确的，因为它准确地检查每个可能选择的多边形不等式。 然而，可以有`C(100,50)`子集，这远远超出了可以处理的范围。 

有用的观察是每个无效子集都有一个显着的一侧：其最大的一侧。 对长度进行排序后，假设当前最大选择的段有长度`x`。 当其他子集恰好无效时`k-1`所选片段的总长度最多`x`。 

这让我们可以计算无效子集，而不是尝试直接计算有效子集。 由于最大可能的段长度仅为`10000`，我们只需要关于总和的动态规划信息`10000`。 较大的总和永远不会使子集无效。 

我们按升序处理这些片段。 插入段之前`x`进入动态规划表后，该表仅包含较小的段。 我们用它来计算有多少组`k-1`较小的段最多有总和`x`。 每个这样的组都创建一个无效的子集`x`作为最大的元素。 计算完这些坏子集后，我们插入`x`放入表格中，以便它可以作为未来选择的最大元素。 

所有可能的总数`k`-子集是`C(n, k)`。 减去无效的即可得到答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(C(n,k) * k)`|`O(k)`| 太慢了|
 | 最佳 |`O(n * k * A)`|`O(k * A)`| 已接受 |

 这里`A`是最大段长度，最多`10000`。 

## 算法演练

 1. 按非递减顺序对所有段长度进行排序。 按照这个顺序处理可以保证当我们检查一个段时，动态规划表中已经存储的每个段都小于或等于并且只能是非最大边。 
2.创建动态规划表`dp[j][s]`。 它存储了选择的方式数量`j`处理后的段的总长度恰好是`s`， 在哪里`s`仅限于`10000`。 
3.对于每个段长度`x`，首先计算无效多边形，其中`x`是最大的一面。 我们需要团体`k-1`总和最多为之前的段`x`。 
4. 将该计数添加到无效子集总数中。 这对每个无效子集计数一次，因为每个无效子集恰好有一个最大的选定段。 
5. 插入`x`进入动态规划表。 向后迭代大小，以便当前段不会在同一子集中多次重复使用。 
6. 计算选择的方式总数`k`使用组合进行分段并减去无效计数。 

为什么有效：每个无效选择都有一个唯一的最大边。 当处理该边时，所有其他选定的边都已插入到`dp`，因此该算法只对选择进行一次计数。 每一个不被算作无效的选择，其最大边都小于其余边的总和，这正是多边形不等式。 减法精确地留下有效的循环多边形。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7
MAX_A = 10000

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    comb = [[0] * (k + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        comb[i][0] = 1
        for j in range(1, min(i, k) + 1):
            if j == i:
                comb[i][j] = 1
            else:
                comb[i][j] = (comb[i - 1][j - 1] + comb[i - 1][j]) % MOD

    dp = [[0] * (MAX_A + 1) for _ in range(k)]
    dp[0][0] = 1

    invalid = 0

    for x in a:
        if k > 1:
            bad = 0
            for s in range(x + 1):
                bad += dp[k - 1][s]
            invalid = (invalid + bad) % MOD

        for cnt in range(k - 2, -1, -1):
            current = dp[cnt]
            nxt = dp[cnt + 1]
            for s in range(MAX_A - x + 1):
                if current[s]:
                    nxt[s + x] = (nxt[s + x] + current[s]) % MOD

    answer = (comb[n][k] - invalid) % MOD
    print(answer)

if __name__ == "__main__":
    solve()
```组合表计算可能的总数`k`- 段选择。 这些值需要取模`10^9+7`，因此帕斯卡三角形避免了溢出并直接处理所有情况。 

动态规划表仅存储最多的和`10000`。 更大的总和永远不会出现在无效子集检查中，因为正在测试的最大边永远不会大于`10000`。 

计算坏子集的循环发生在插入当前段之前。 这种排序可以防止将当前段计为较小的边之一。 更新循环向后遍历所选计数，这是标准的 0/1 背包模式，并防止多次使用一个段。 

## 工作示例

 对于第一个样本：```
5 3
1 2 3 3 3
```处理状态为：

 | 当前部分 | 以此为最大的无效组 | 存储的子集大小 |
 | ---| ---| ---|
 | 1 | 0 | 1：{1} |
 | 2 | 0 | 较小组的总和 |
 | 3 | 前两个段的总和 ≤ 3 的组 | 更新了 3 |
 | 3 | 与之前的值进行相同的检查 | 更新了另外 3 |
 | 3 | 与之前的值进行相同的检查 | 更新了另外 3 |

 无效选项将从总数中删除`3`-元素选择。 剩下的答案是`7`。 

对于第二个样本：```
6 4
1 5 2 3 4 1
```排序后：```
1 1 2 3 4 5
```重要的状态是：

 | 当前部分 | 需要前 3 个段且总和 ≤ 当前值 | 结果 |
 | ---| ---| ---|
 | 1 | 不可能| 没有无效的子集 |
 | 2 | 除了小额资金之外，这是不可能的| 没有无效的子集 |
 | 3 | 之前的三元组太大了 | 没有无效的子集 |
 | 4 | 检查先前的小金额三元组 | 无效计数 |
 | 5 | 所有剩余可能的最大侧故障都被计算在内 无效计数 |

 该算法按最长边计算每个坏四边形，并从所有可能的选择中减去它们。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(n * k * A)`| 每个段更新每个子集大小和每个可能的总和`A = 10000`。 |
 | 空间|`O(k * A)`| 该表存储每个子集大小的计数以及可能的相关总和。 |

 和`n <= 100`,`k <= 100`， 和`A <= 10000`，操作次数约为`10^8`在最大的情况下，并通过优化的 Python 循环满足预期的限制。

    a = list(map(int, data().split()))
    a.sort()

    MAX_A = 10000

    dp[0][0] = 1

 ## 边缘情况

 对于平等边界：```
3 3
1 2 3
```加工时`3`，动态规划表包含对`{1,2}`与总和`3`。 由于查询计数总计并包括当前最大边，因此该子集被标记为无效。 最终的答案是`0`。 

对于重复值：```
5 3
3 3 3 1 2
```排序的顺序是`1,2,3,3,3`。 每个副本`3`单独插入到动态规划表中。 不同的索引产生不同的选择，因此算法自然地保留了多样性。 

对于统治其他球队的大一方：```
4 3
1 2 3 10
```什么时候`10`处理后，该表包含较小值之间的所有对。 每对最多有和`10`，所以所有包含的子集`10`均无效。 唯一剩下的有效三角形是`{1,2,3}`。 

对于最小可能的多边形尺寸：```
3 3
2 3 4
```该算法检查唯一可能的子集。 最大的边是`4`，而其他两侧的总和为`5`，所以子集是有效的，答案是`1`。
