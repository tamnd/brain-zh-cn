 ## 解决方案
 ## 问题理解

 我们被告知，所有浆果最初都装在相同的罐子里，每个罐子里的浆果数量都相同。 每个罐子只含有一种浆果。 经过分类过程中的一些混乱后，所有浆果都被清空成一堆，我们得到了该堆中发现的黑醋栗浆果的总数。 

在所有装有醋栗的罐子中，有的是黑醋栗，有的是红醋栗，但在包装时被误认为是同一品种。 我们对原始结构的了解是，所有罐子的一小部分，等于`p`，含有醋栗（黑色和红色一起）。 其余的罐子里装有其他浆果，这些浆果对最终计算并不重要，只是它们对总数有所贡献。 

关键是所有罐子的容量都相同，因此“罐子的分数”直接翻译为“浆果总数的分数”。 

任务是确定所有醋栗浆果中黑醋栗的比例，因为我们知道黑醋栗的数量`n`，我们可以从罐子的比例推断出醋栗浆果的总数`p`。 

输入大小很小，因此解决方案必须是恒定时间。 任何涉及对罐子或浆果进行模拟的方法都是不必要的。 唯一的微妙之处在于使用相同大小的约束将一小部分罐子正确地转换为一小部分浆果。 

边缘情况出现时`n = 0`，其中不存在黑醋栗，并且无论什么，答案都必须恰好为零`p`。 另一个极端情况是当`p = 1`，意味着所有罐子都是醋栗罐，所以堆里的所有浆果都是醋栗，答案就变成了`n / total_currants`，这应该完全简化，没有除法问题。 

一个天真的错误是对待`p`直接作为醋栗浆果的分数，而不考虑相同大小的罐子假设，或者忽略浆果总数通过罐子结构隐式固定的事实。 

## 方法

 暴力解释将尝试重建罐子的数量。 如果我们假设每个罐子包含`k`浆果，我们可以尝试列举可能的`k`，然后将所有浆果分成罐子，然后根据分数分配醋栗罐子`p`，最后分发黑醋栗和红醋栗。 这很快就会变得不确定并且在计算上毫无意义，因为无穷多个`(k, number of jars)`对满足约束条件。 

关键的观察是我们实际上不需要知道`k`或罐子的数量。 由于每个罐子的大小相同，因此罐子的比例和浆果的比例是相同的。 这将整个结构折叠成一个比例关系：所有浆果中醋栗浆果的比例恰好是`p`。 由于浆果总数固定为一百万，我们可以直接计算醋栗浆果的总数：`p * 1e6`。 

一旦知道了醋栗总量，答案就变成了一个简单的比率：黑醋栗与醋栗总量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |

 | 暴力重建罐子 | O(N) 或更差（欠定搜索） | O(1) | O(1) | 太慢/不明确|
 | 正比例推理| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`p`。 在此刻`n`是黑醋栗浆果的数量，并且`p`是属于醋栗罐的所有浆果的比例。 
2. 将醋栗罐的比例转换为醋栗浆果的总数。 由于所有罐子中含有相同数量的浆果，因此该分数同样适用于浆果。 浆果总数为`1,000,000`，所以醋栗浆果总数等于`p * 1,000,000`。 
3. 计算所需比率为`n / (p * 1,000,000)`。 这直接将黑醋栗与所有醋栗进行比较。 
4. 将值输出为具有足够精度的浮点数以满足所需的误差范围。 

### 为什么它有效

 所有罐子都有相同的大小，因此从罐子到浆果的映射是线性的。 罐子的任何子集都对应于按常数因子缩放的相同浆果子集。 因此，醋栗罐的比例等于醋栗浆果的比例。 这使得醋栗总数完全由下式决定：`p`以及已知的浆果总数，只留下一个部门来分离黑醋栗。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, p = input().split()
    n = int(n)
    p = float(p)

    total = p * 1_000_000.0
    if total == 0:
        print(0.0)
        return

    ans = n / total
    print(ans)

if __name__ == "__main__":
    solve()
```直接按照推导公式实现。 唯一需要注意的是浮点转换`p`，因为它最多保留六位小数。 乘以`1e6`必须以浮点形式完成以保持精度。 

守卫`if total == 0`处理退化情况`p = 0`，这意味着根本没有醋栗浆果。 在那种情况下，`n`也必须为零，并且答案被定义为零而不进行除法。

 ## 边缘情况

 ### 案例：没有黑醋栗

 输入：```
0 0.7
```葡萄干总数变为`700000`。 计算`0 / 700000`评估为`0`没有数值不稳定。 该算法永远不会被零除，除非`p = 0`。 

### 案例：没有醋栗罐

 输入：```
0 0
```这里醋栗总数变为零。 该算法显式检查此条件并返回`0.0`直接地。 这避免了未定义的划分，并符合系统中根本不存在醋栗的解释。
