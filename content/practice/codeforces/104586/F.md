 ## 解决方案
 ## 问题理解

 我们得到了一棵洞穴树。 每个洞穴都包含一定数量的球。 角色从一个固定的洞穴开始，穿过树走向一片叶子，但在每个交叉点，他都会随机选择下一个未访问过的边缘。 他永远不会返回已经使用过的边，因此他的行走始终是从起始节点到某个叶子的简单路径。 

如果步行经过每个洞穴，就会贡献其球数。 任务是计算从给定起始节点开始时收集的预期球总数。 

输入大小高达一万个节点，因此任何显式枚举路径或模拟随机游走的解决方案都是不可能的。 树中路径的完整枚举将随着分支程度呈指数增长，因此唯一可行的方向是在本地计算期望并通过树上的动态编程将它们组合起来。 

当起始节点已经是叶子时，会出现微妙的边缘情况。 在这种情况下，行走永远不会移动，因此答案就是该节点处的值。 另一个极端情况是当树退化为一条路径时，随机性完全消失并且期望变得确定性，这对于健全性检查很有用。 

## 方法

 强力解释将显式模拟从起始节点开始的所有可能的根到叶路径。 在每个具有 d 度的节点处，步行分为 d 个同样可能的延续。 即使在大小为 10000 的树中，不同的根到叶路径的数量也可能是指数级的，因此这种方法会立即失败。 

关键的观察结果是，该过程是在树上随机游走，永远不会重新访问节点，因此一旦我们进入子子树，未来的期望仅取决于该子树，而不取决于图的其余部分。 这允许我们定义一个函数 E[v] 作为从节点 v 开始并远离我们来自的父节点收集的球的预期数量。 

在节点 v 处，除父节点外的每个邻居都有相同的可能性被选为下一步。 如果我们移动到邻居 u，我们就会根据 E[u] 收集 u 子树中的所有内容。 因此，E[v] 变为 v 处的值加上所有子项 u 的 E[u] 平均值。 这是一个标准树 DP，但按度数减一进行归一化。 

为了清楚地计算这一点，我们将树根置于起始节点，并执行 DFS 自下而上计算期望值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解路径 | O(exp(n)) | O(exp(n)) | O(n) | 太慢了|
 | 充满期待的树DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将树的根设在起始节点 s 处。 行走总是远离父节点，因此对于每个节点，我们在计算转移概率时将其父节点视为禁止的。 

对于每个节点 v，我们计算从其父节点进入 v 时从 v 开始收集的预期球数。 

1. 构建树的邻接表。 

这为邻居提供了恒定的时间访问，这是必要的，因为转换取决于程度。 
2. 从起始节点运行 DFS，传递父节点。 

需要父级，因为转换规则排除了我们来自的边缘。 
3. 对于每个节点 v，收集除父节点之外的所有邻居。 

这些是有效的后续步骤。 如果没有这样的邻居，则 v 是有根意义上的叶子。 
4. 如果 v 是叶子，则设置 dp[v] = a[v]。 

步行在此停止，因此期望值正是当地的值。 
5. 否则计算 dp[v] = a[v] 加上所有有效邻居 u 上 dp[u] 的平均值。 

每个邻居的选择概率为 1 / deg(v 不包括父代)，因此期望是线性的：

dp[v] = a[v] + sum(dp[u]) / k。 
6. 返回 dp[s]，即在起始节点计算的值。 

递归自然地从叶子向上传播期望，因为 dp[u] 在用于 dp[v] 之前已完全确定。 

### 为什么它有效

 在任何节点 v 处，一旦步行从其父节点到达 v，未来路径就是仅依赖于 v 及其子树的马尔可夫过程。 每个输出边都是在剩余边中统一选择的，因此未来增益的期望恰好是子期望的平均值。 期望的线性确保对独立子树的贡献求和并对选择进行平均可以产生正确的全局期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

n, s = map(int, input().split())
a = list(map(float, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    x, y = map(int, input().split())
    x -= 1
    y -= 1
    g[x].append(y)
    g[y].append(x)

dp = [0.0] * n

def dfs(v, p):
    children = []
    for to in g[v]:
        if to != p:
            dfs(to, v)
            children.append(to)

    if not children:
        dp[v] = a[v]
        return dp[v]

    total = 0.0
    for to in children:
        total += dp[to]

    dp[v] = a[v] + total / len(children)
    return dp[v]

print(dfs(s - 1, -1))
```该解决方案以邻接形式构建树，并从起始节点运行 DFS。 递归自下而上计算 dp 值。 每个节点仅聚合其子节点的结果，不包括父边缘以强制执行非回溯规则。 

唯一微妙的部分是确保使用有效传出边的数量而不是完整度数来完成概率归一化。 这就是为什么在 DFS 期间显式过滤子项的原因。 

## 工作示例

 ### 示例 1

 输入：```
4 4
0 2 0 0
1 2
2 3
3 4
```这是一条链，因此除端点之外的每个节点在 DFS 中都有一个以 4 为根的子节点。 

| 节点| 儿童 | dp值计算|
 | ---| ---| ---|
 | 1 | 无 | 0 |
 | 2 | 1 | 2 + 0 = 2 |
 | 3 | 2 | 0 + 2 = 2 |
 | 4 | 3 | 0 + 2 = 2 |

 节点 4 的期望为 2，因为每条路径都是确定性的并且总是经过节点 2。 

### 示例 2

 输入：```
6 6
0 1 2 2 0 0
1 3
3 5
5 4
5 6
2 4
```从节点 6 开始，正好有一个邻居，因此步行一开始是确定性的。 

| 节点| 儿童 | DP |
 | ---| ---| ---|
 | 1 | 无 | 0 |
 | 2 | 无 | 1 |
 | 3 | 5 | 2 + dp[5] | 2 + dp[5] |
 | 4 | 5 | 2 + dp[5] | 2 + dp[5] |
 | 5 | 4,6 | 0 + (dp[4] + dp[6]) / 2 |
 | 6 | 5 | 0 + dp[5] | 0 + dp[5] |

 自下而上求解得出 dp[5] = 2、dp[4] = 4、dp[3] = 6、dp[6] = 2.5。 

该表显示了分支如何引入平均，而叶链如何向上传播确定性贡献。

 ## 边缘情况

 叶起始节点由基本情况直接处理。 由于没有子节点，DFS 分配 dp[v] = a[v]，这与没有发生移动的事实相匹配。 

高度节点是通过对所有子节点求平均值来处理的。 因为我们明确排除了父级，所以我们永远不会错误地包含向后移动，否则会扭曲概率。 

线性链简化为确定性行走。 每个节点恰好有一个子节点，因此平均退化为直接传播而无需稀释，这与沿单个路径强制移动的预期行为相匹配。
