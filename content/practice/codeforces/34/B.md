 ## 解决方案
 ## 问题理解

 鲍勃正在参加一场旧电视拍卖，每台电视都有一个价格。 有些电视是免费的，有些是正价，有些甚至是负价，这意味着主人愿意付钱给鲍勃把它们拿走。 鲍勃最多可以携带 _m_ 台电视，并且他希望最大化他能赚到的总钱。 输入给出电视数量 _n_、携带限额 _m_ 以及电视价格数组。 输出是鲍勃通过挑选最多 _m_ 台电视可以赚取的最大金额。 

约束很小：_n_ 和 _m_ 最多为 100，而电视价格在 -1000 到 1000 之间。这意味着我们可以负担时间复杂度高达大约 O(n log n) 甚至 O(n²) 的算法，而不必担心效率。 

一个微妙的一点是，鲍勃只能从负价格的电视中受益。 选择价格为正的电视会降低他的总收益。 如果不检查其标志而盲目地对最便宜的电视进行求和，则会错误地包含正价格并降低总金额。 例如，如果 _n = 5_，_m = 3_，并且价格为`-5 2 4 1 3`，正确答案是`5`（只选`-5`）， 不是`2 + 4 + 1 = 7`如果只是按升序排序并对前三个求和，粗心的方法可能会这样做。 

另一个边缘情况是负价电视数量少于 _m_ 台。 在这种情况下，鲍勃应该只获取可用的负价格并忽略其余的，因为获取免费或正电视不会增加他的收益。 

## 方法

 暴力方法将考虑尺寸最大为 _m_ 的电视的每个子集，并计算每个子集的总金额。 对于每个组合，鲍勃将负价格相加。 这是正确的，因为它检查了所有可能性，但它的复杂性是指数级的：有 O(2ⁿ) 子集。 当 _n = 100_ 时，这显然是不可行的。 

关键的见解是，唯一对鲍勃的总价格做出正贡献的电视是那些价格为负的电视。 因此，我们只需要挑选负价格最小的，最多 _m_ 台电视。 按升序对数组进行排序可确保所有负价格排在第一位。 然后我们可以迭代前 _m_ 个元素，仅对负值求和。 这将问题从考虑所有子集简化为简单排序，然后进行线性扫描。 

蛮力方法之所以有效，是因为它探索了所有可能性，但当 _n_ 由于指数组合而增长时，它就会失败。 只有负价格才重要的观察结果使我们能够将问题简化为对数组的一个小前缀进行排序和求和，从而实现 O(n log n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2ⁿ) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(1) 或 O(n) | 已接受 |

 ## 算法演练

 1.读取电视数量`n`和携带限额`m`，以及一系列价格。 
2. 按升序对价格数组进行排序。 这将所有负价格带到了前面。 
3. 初始化变量`total`到 0。这将累积 Bob 的收入。 
4. 迭代第一个`m`已排序数组的元素。 
5. 对于每个价格，如果它是负数，则将其绝对值添加（或等效地减去它）`total`。 如果它为零或正数，则停止迭代，因为更多的电视不会增加总数。 
6. 输出累计值`total`。 

这是有效的，因为排序后，第一个`m`元素是最小的，只有负数对鲍勃的增益有正向贡献。 不变的是在任何一步，`total`等于鲍勃迄今为止选择的负价格的绝对值之和。 正数不会增加总和，因此忽略它们是安全的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
prices = list(map(int, input().split()))

prices.sort()
total = 0

for i in range(min(m, n)):
    if prices[i] < 0:
        total += -prices[i]
    else:
        break

print(total)
```代码首先读取`n`和`m`和价目表。 排序可确保负价格位于最前面。 循环最多迭代`m`次，如果遇到非负价格则提前停止。 添加`-prices[i]`将负成本转化为正收入。 这`min(m, n)`确保我们永远不会越界，如果`m > n`，尽管问题保证`m ≤ n`。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    prices = list(map(int, input().split()))
    prices.sort()
    total = 0
    for i in range(min(m, n)):
        if prices[i] < 0:
            total += -prices[i]
        else:
            break
    return str(total)

# provided sample

 ## 边缘情况

 如果负价格少于`m`，该算法仍然有效。 用于输入`4 5`和价格`-1 -2 -3 -4`，排序后的数组是`-4 -3 -2 -1`。 我们迭代所有四个负价格，将它们的绝对值相加得到`10`，然后停止，因为没有更多的电视。 虽然`m = 5`，我们永远不会访问越界元素。 这证实了该算法可以处理以下情况`m`正确超过负价格的数量。 

当所有价格均为正数时，例如`1 2 3`和`m = 3`，第一个排序元素为 1，为非负数。 循环立即中断，总计为`0`。 这表明该算法正确地避免了选择会减少鲍勃收入的电视。
