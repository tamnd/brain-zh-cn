 ## 解决方案
 ## 问题理解

 我们给出了站成一圈的士兵的高度。 如果两名士兵并排站立，并且所有相邻对之间的身高差尽可能小，则可以组成一个侦察单位。 

圆形排列改变了一个重要的细节。 第一个和最后一个士兵也是邻居。 仅检查从左到右相邻位置的线性扫描会错过这一对。 

输入是一个小的高度数组。 我们需要输出具有最小绝对差的任何相邻对的从 1 开始的索引。 

限制很小。 最多有100名士兵，所以即使是一个$O(n^2)$解决方案将在限制内舒适地运行。 尽管如此，问题的结构自然会导致更简单的线性扫描。 由于每个有效的对都必须已经是圈中的邻居，因此我们永远不需要将每个士兵与其他士兵进行比较。 

主要的边缘情况是最后一个士兵和第一个士兵之间的圆形连接。 

考虑这个输入：```
5
10 12 13 15 10
```最小的区别是士兵 5 和 1 之间：```
|10 - 10| = 0
```一个粗心的实现，只检查对`(1,2), (2,3), (3,4), (4,5)`会错误地错过最佳答案。 

当多对共享相同的最小差异时，会发生另一种微妙的情况。```
4
5 7 9 11
```每个相邻对都有差异`2`。 任何有效的对都可以被打印。 实现不应假定唯一性。 

最小输入大小也很重要：```
2
100 1
```士兵只有两个，而且因为排列是圆形的，所以两个方向都是邻居。 答案一定还是`1 2`或者`2 1`。 

## 方法

 蛮力的想法很简单。 比较每对士兵，检查他们是否是圈内的邻居，并跟踪最小身高差。 由于有$n^2$对，最坏情况下的操作次数约为$100^2 = 10{,}000$，这仍然是完全可以接受的。 

暴力的问题不在于性能，而在于不必要的工作。 大多数对都是无关紧要的，因为只允许相邻的士兵。 问题的结构已经告诉我们哪些比较很重要。 

每个士兵只有两个邻居。 如果我们绕圈走一圈并比较每个相邻的对，我们将检查每个有效候选者一次。 这将任务简化为简单的线性扫描。 

关键的观察结果是答案必须来自以下对之一：```
(1,2), (2,3), ..., (n-1,n), (n,1)
```没有其他对是合法的。 

因此，最佳解决方案检查所有相邻对，计算它们的绝对差，并记住最小的一个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取士兵人数和身高。 
2. 用一个很大的值初始化当前的最佳差值。 
3. 迭代所有位置`0`到`n-1`。 
4. 对于每个位置`i`，确定其邻居为`(i + 1) % n`。 

模运算使数组成为圆形。 什么时候`i`是最后一个索引，邻居成为第一个士兵。 
5. 计算两个相邻高度之间的绝对差。 
6. 如果该差值小于当前最佳值，则更新答案索引并存储新的最小差值。 
7. 完成扫描后，使用基于 1 的索引打印存储的对。 

### 为什么它有效

 该算法仅检查每个有效的相邻对一次。 由于该问题只允许圆圈内的相邻士兵，因此在该集合之外不存在有效答案。 通过保持迄今为止看到的最小绝对差，该算法保证扫描完成后存储的对是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

best_diff = float('inf')
ans_l = 1
ans_r = 2

for i in range(n):
    j = (i + 1) % n
    diff = abs(a[i] - a[j])

    if diff < best_diff:
        best_diff = diff
        ans_l = i + 1
        ans_r = j + 1

print(ans_l, ans_r)
```该程序首先将士兵的身高读入数组中。`best_diff`存储迄今为止发现的最小差异。 它从无穷大开始，因此第一对总是替换它。 

该循环对每个士兵扫描一次。 对于每个索引`i`，下一个邻居的计算方式为：```
j = (i + 1) % n
```这是最重要的实施细节。 如果没有模数，最后一个士兵的右边将没有邻居，而圆形对`(n,1)`将被跳过。 

比较使用绝对差，因为高度顺序并不重要：```
diff = abs(a[i] - a[j])
```存储时索引会转换回基于 1 的形式，因为 Codeforces 问题通常期望索引从 1 开始。 

该算法使用恒定的额外内存并且仅遍历一次数组。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    best_diff = float('inf')
    ans_l = 1
    ans_r = 2

    for i in range(n):
        j = (i + 1) % n
        diff = abs(a[i] - a[j])

        if diff < best_diff:
            best_diff = diff
            ans_l = i + 1
            ans_r = j + 1

    print(ans_l, ans_r)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()

    backup_stdout = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup_stdout
    return out.getvalue().strip()

 ## 边缘情况

 考虑圆形边界情况：```
5
10 12 13 15 10
```该算法按以下顺序检查对：```
(1,2), (2,3), (3,4), (4,5), (5,1)
```最终比较得出差异`0`，这成为新的最小值。 因为模运算将最后一个士兵连接回第一个士兵，所以正确答案`5 1`被发现。 

现在考虑相等的高度：```
4
7 7 7 7
```每个相邻对都有差异`0`。 第一次比较已将最小值设置为`0`，并且后来的一对都没有改进它。 算法返回`1 2`，这是有效的，因为可以打印任何最佳对。 

最后，检查可能的最小输入：```
2
100 1
```循环检查：```
(1,2)
(2,1)
```第一对已经达到最小差异`99`。 算法存储并打印`1 2`。 尽管圆的概念以相反的顺序复制了同一对，但答案仍然是正确的。
