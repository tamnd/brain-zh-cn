 ## 解决方案
 ## 问题理解

 我们得到一个小的整数数组。 Kinich 可以通过重复选择两个包含相同值的不同索引来得分，但每个索引最多只能使用一次。 任务是确定每个测试用例的此类配对的最大数量。 

输入由多个测试用例组成。 每个测试用例指定数组的长度和数组元素本身。 输出是 Kinich 在该测试用例中可以达到的最高分数。 由于每个操作恰好消耗相同值的两个元素，因此分数完全取决于存在多少对相同的数字。 

约束非常严格：数组长度$n$最多 20 个，每个元素都在 1 到$n$。 这意味着即使是暴力方法也是可行的，因为我们可能检查的组合总数受以下限制：$n \choose 2$重复，这对于$n \le 20$。 

当所有元素不同或所有元素相同时，会出现不明显的边缘情况。 例如，如果数组是 [1,2,3,4]，则不可能进行任何操作，因此分数应该为 0。相反，如果数组是 [2,2,2,2]，则我们可以生成两个不相交的对，从而得到 2 分。在这些情况下，仅计算唯一数字或忘记防止重复使用索引的粗心实现可能会产生不正确的结果。 

## 方法

 暴力方法会尝试每对可能的相等数字，将它们标记为已使用，然后递归以最大化分数。 这是正确的，因为它探索了所有可能的配对序列。 然而，即使有$n=20$，这种递归方法有阶乘增长，对于这个问题来说是不必要的。 

关键的观察是我们不需要考虑数字的位置，只需要考虑它们的频率。 每个号码最多可以贡献$\lfloor \text{frequency} / 2 \rfloor$指向分数，因为每对都需要出现两次。 求和$\lfloor \text{frequency} / 2 \rfloor$对所有不同的数字直接给出最高分。 这将问题简化为对出现次数进行计数，这对于给定的约束来说是微不足道的。 

暴力破解之所以有效，是因为它显式枚举了所有有效的配对，但在以下情况下会失败：$n$由于组合数量的爆炸性增长，数字变得越来越大。 关于计算频率的观察将问题转化为简单的算术，避免了任何组合爆炸。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢/不必要|
 | 频率计数 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取数组长度$n$和数组元素。 
3.初始化一个size的频率数组$n+1$为零。 这将存储从 1 到每个整数出现的次数$n$。 
4. 遍历数组并递增每个数字的频率。 
5. 将分数初始化为0。 
6. 对于频率数组中的每个数字，计算频率除以 2 可以形成多少对。将其添加到分数中。 
7. 输出测试用例的分数。 

这是有效的，因为任何数字的不重叠对的最大数量恰好是其出现次数的一半。 对所有数字进行求和即可得出可达到的最高分数，而无需跟踪各个指数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    freq = [0] * (n + 1)
    for x in a:
        freq[x] += 1
    
    score = 0
    for count in freq:
        score += count // 2
    
    print(score)
```该解决方案使用有效地读取输入`sys.stdin.readline`，计算每个数字的出现次数，并计算不重叠对的最大数量。 频率数组的大小`n+1`为了方便基于 1 的索引，整数除法确保只计算完整的对。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = [0] * (n + 1)
        for x in a:
            freq[x] += 1
        score = sum(count // 2 for count in freq)
        print(score)
    
    return output.getvalue().strip()

 ## 边缘情况

 对于像这样的单元素数组`[1]`，算法初始化频率数组，计数`1`一次，除以 2 得到 0 对，输出 0。对于元素全部相等的数组，例如`[2,2,2,2]`，频率为 4，整数除以 2 得到 2 对，这正是最大分数。 混合情况如`[1,1,2,2,2,2]`产量频率计数`[0,2,4,...]`，产生 1+2=3 点，表明该算法正确处理不同数字的不同频率。
