 ## 解决方案
 ## 问题理解

 我们有一排敌人，每个敌人都有固定的生命值和固定的位置。 Xilonen 可以从单一选定的位置进行攻击`p`，每次攻击都会减少敌人的生命值`m - |p - x|`如果该差异是非负的。 目标是选择`p`这样至少`k`可以用最少的攻击次数击败敌人。 输出是最小攻击次数，或者`-1`如果没有位置允许杀戮`k`敌人。 

第一个关键观察结果是每次攻击的伤害随着距离的增加而线性减少。 这意味着敌人距离越远`p`，需要更多的攻击才能击败它。 我们还注意到`p`可以是任意整数，不限制敌人的位置，并且敌人的位置是严格递增的。 

约束条件意味着`n`最多可达 100,000 个`m`和`h_i`最多 10^9。 这意味着我们无法采用 O(n^2) 的蛮力方法来模拟每个可能的位置`p`。 我们还需要处理最多 10^4 个测试用例，其总和为`n`所有情况下最多 10^5。 因此，我们的算法在最坏的情况下每个测试用例的时间复杂度大约为 O(n log n)，理想情况下速度更快。 

边缘情况包括敌人之间的距离比`m`，使得不可能一次影响多个敌人，或者当所有敌人都在距离内时`m`，允许一个位置击中多个目标。 例如，如果`n=2`,`m=1`,`k=2`，位置是`[1, 3]`, 没有单个`p`可以到达两个敌人，所以答案是`-1`。 一种幼稚的方法，总是假设我们可以击中第一个`k`敌人会在这里失败。 

## 方法

 蛮力方法将迭代所有可能的整数位置`p`并计算击败每个敌人所需的攻击次数。 然后我们将对这些计数进行排序并选择`k`最小的看有多少次攻击就够了。 虽然这是正确的，但它太慢了，因为`p`范围可达 10^9，导致潜在的巨大搜索空间。 

关键的见解是攻击模式是分段线性的。 每个敌人都会定义一个可以对其造成伤害的位置区间。 具体来说，敌人位于`x_i`与健康`h_i`可以生存到`ceil(h_i / (m - |p - x_i|))`攻击，随着`|p - x_i|`减少。 因此，对于任意数量的攻击`t`，我们可以计算出敌人最多被击败的位置间隔`t`攻击。 这将问题转化为区间覆盖问题：我们需要一个位置`p`其间隔至少为`k`敌人。 

我们可以将其与攻击次数的二分搜索结合起来。 对于候选人`t`，我们为所有将被击败的敌人生成间隔`t`攻击。 然后我们检查是否有任何位置至少被覆盖`k`使用扫描线方法对这些间隔进行统计，我们通过对间隔端点进行排序来有效地计算重叠。 二分查找确保我们找到最小的`t`高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m_范围) | O(n) | 太慢了|
 | 区间+二分查找 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`,`m`,`k`, 健康数组`h`，和位置数组`x`。 
2. 定义辅助函数`possible(t)`至少返回 True`k`敌人可以被击败`t`攻击。 
3. 在`possible(t)`，迭代所有敌人。 对于每个敌人，计算最大距离`d`这样`m - d`次`t`至少是`h_i`。 如果`d >= m`，跳过敌人； 它不能被击败`t`攻击。 否则，添加间隔`[x_i - d, x_i + d]`到一个列表。 
4. 对区间端点进行排序并执行扫描线。 跟踪每个点的重叠间隔数。 如果在任何一点至少有`k`重叠间隔，返回 True。 
5. 使用二分查找`t`。 放`low = 1`,`high = max(h)`，或安全上限，例如 10^9。 对于每个中间值，请调用`possible(mid)`。 如果为 True，则减少`high`; 如果为假，则增加`low`。 
6.二分查找后，如果没有有效的`t`找到，输出`-1`。 否则，输出最小的`t`成立。 

为什么它有效：二分查找保证第一个`t`为此`possible(t)`返回 True 是最小的。 基于间隔的扫描确保我们只考虑能够真正击败敌人的位置`t`攻击，并且计算重叠保证我们找到`p`至少击败`k`敌人。 这种方法避免了迭代所有整数位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        h = list(map(int, input().split()))
        x = list(map(int, input().split()))
        
        def possible(t_attacks):
            events = []
            for hi, xi in zip(h, x):
                d = m - math.ceil(hi / t_attacks)
                if d < 0:
                    continue
                left = xi - d
                right = xi + d
                events.append((left, 1))
                events.append((right + 1, -1))
            events.sort()
            count = 0
            for pos, delta in events:
                count += delta
                if count >= k:
                    return True
            return False
        
        low, high = 1, max(h)
        answer = -1
        while low <= high:
            mid = (low + high) // 2
            if possible(mid):
                answer = mid
                high = mid - 1
            else:
                low = mid + 1
        print(answer)
        
solve()
```该代码使用有效地读取输入`sys.stdin.readline`并处理多个测试用例。 这`possible`函数计算每个敌人在候选攻击次数内可以被击败的间隔，然后在排序的间隔端点上使用扫线方法来查看是否存在至少被覆盖的位置`k`间隔。 二分查找用于最大限度地减少攻击次数。 

微妙之处包括处理天花板`hi / t`正确地，确保间隔包含两端，并添加`+1`到右端点以保证扫描线的正确性。 间隔端点中的相差一错误会破坏重叠间隔的计数。 

## 工作示例

 **示例1：**`n=5, m=5, k=3, h=[7,7,7,7,7], x=[1,2,3,4,5]`。 

| 攻击t | 敌人的间隔| 最大重叠|
 | --- | --- | --- |
 | 1 | [1-2,1+2],[2-2,2+2],[3-2,3+2],[4-2,4+2],[5-2,5+2] | 3 在位置 2、3、4 |
 | 2 | [1-3,1+3],[2-3,2+3],... | 重叠 >= 3 |

 二分查找发现`t=2`最少要击败 3 个敌人。 

**示例2：**`n=2, m=10, k=2, h=[1,1], x=[1,20]`。 

t=1 的间隔：敌人1=[1-9,1+9]=[-8,10]，敌人2=[20-9,20+9]=[11,29]。 没有重叠。 二分查找返回`-1`。 

该跟踪确认非重叠间隔正确产生`-1`。
