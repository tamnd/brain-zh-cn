 ## 解决方案
 ## 问题理解

 我们被要求计算纳特兰地区从第一个城市到最后一个城市的不同路径的数量，其中每个城市都有一个吸引力值。 这些路径遵循一个简单的规则：从城市出发$i$你可以去城市旅行$j$如果$i < j$和$\gcd(a_i, a_j) \neq 1$。 这使得底层结构成为有向无环图（DAG），因为所有边都从较低指数的城市指向较高指数的城市，因此循环是不可能的。 输入由城市数量组成$n$和吸引力值$a_i$。 输出是从城市 1 到城市的不同路径的数量$n$, 取模$998\,244\,353$。 

限制很严格。 和$n$最多$2 \cdot 10^5$和每个$a_i$最多$10^6$，迭代所有可能的城市对来检查 GCD 需要大约$2 \cdot 10^5 \cdot 2 \cdot 10^5 / 2 \approx 2 \cdot 10^{10}$操作，这远远超出了4秒的时间限制。 这排除了朴素的成对方法。 我们还需要仔细处理模运算以避免溢出，因为路径数量会快速增长。 

当所有城市都是成对互质时，就会出现微妙的边缘情况。 例如，对于城市$[2, 3, 5]$，除了可能从城市 1 到城市 2 之外，不存在任何边，如果$\gcd(2,3) \neq 1$，确实如此。 在这种情况下，幼稚迭代可能会重复计算路径，或者假设不存在边缘而存在边缘，从而给出不正确的路径计数。 另一个边缘情况是当多个城市具有相同的吸引力时，这会创建连接相同城市对的多条有效路径。 

## 方法

 暴力方法将城市建模为 DAG 并显式计算每对之间的边$i < j$如果$\gcd(a_i, a_j) \neq 1$。 DAG 构建完成后，从城市 1 到城市进行深度优先搜索 (DFS) 或动态规划$n$可以计算所有路径。 原则上这是可行的，但是检查$\gcd$每对都是$O(n^2)$， 关于$4 \cdot 10^{10}$最大投入的操作。 即使 DFS 记忆仍然需要构建 DAG，所以这是不切实际的。 

关键的观察结果是，当且仅当两个数字共享素因数时，它们的 GCD 才大于 1。 我们可以将每个吸引力值分解为其素数因子，并且对于每个素数$p$，追踪吸引力可除以的最新城市$p$。 这使我们能够动态传播路径数量，而无需检查每对路径。 具体来说，我们维护一个动态编程数组`dp[i]`计算到达城市的路径数量$i$。 对于每个素因数$p$的$a_i$，我们知道最近的城市`last[p]`有因素$p$前$i$; 任何路径到达`last[p]`可以继续去市区$i$。 我们总结所有主要因素对计算的贡献`dp[i]`。 

这将问题转化为因式分解和线性遍历，大大降低了复杂性。 使用筛子进行素因数分解高达$10^6$确保每个城市都经过处理$O(\log a_i)$时间，因为对于以下数字，不同质因数的数量最多约为 7 个$10^6$。 这种方法既可行又有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 log max(a)) | O(n^2 log max(a)) | O(n^2) | O(n^2) | 太慢了|
 | 质因子 DP | O(n log max(a)) | O(n log max(a)) | O(最大(a)) | 已接受 |

 ## 算法演练

 1. 预先计算所有数字的最小素因数 (SPF)$10^6$使用筛子。 这使我们能够快速将任何数字考虑在内$O(\log a_i)$反复除以它的最小质因数。 
2.初始化一个数组`dp`尺寸的$n+1$全为零。 放`dp[1] = 1`，因为从城市 1 开始只有一条路径。 
3.初始化字典`last`跟踪每个主要因素的最后一个城市指数。 这使我们能够有效地传播路径。 
4. 迭代从索引 1 到$n$。 对于每个城市$i$：

- 因素`a[i]`使用 SPF 数组分析其主要因素。 
- 对于每个素因数$p$的`a[i]`， 添加`dp[last[p]]`到`dp[i]`模数$998\,244\,353$， 在哪里`last[p]`是之前最近的城市`i`有因素$p$。 如果`last[p]`尚不存在，贡献为零。 
- 更新后`dp[i]`， 更新`last[p] = i`对于所有素因数$p$。 
5.最终答案是`dp[n]`，到达城市的不同路径的数量$n$。 

为什么有效：从城市 1 到城市的每条路径$i$可以被路径沿线城市的素因子唯一分解。 每个主要因素都确保与共享该因素的后来城市的连接。 不变的是处理后的城市$i$,`dp[i]`正确计算所有结束于的不同路径$i$仅使用有效的边。 对主要因子的贡献进行求和可确保不会遗漏或重复计算路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAX_A = 10**6 + 1

# Sieve to compute smallest prime factors
spf = list(range(MAX_A))
for i in range(2, int(MAX_A**0.5) + 1):
    if spf[i] == i:
        for j in range(i*i, MAX_A, i):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    factors = set()
    while x > 1:
        factors.add(spf[x])
        x //= spf[x]
    return factors

def main():
    n = int(input())
    a = list(map(int, input().split()))
    dp = [0] * n
    dp[0] = 1
    last = dict()

    for i in range(n):
        primes = factorize(a[i])
        for p in primes:
            if p in last:
                dp[i] = (dp[i] + dp[last[p]]) % MOD
        for p in primes:
            last[p] = i

    print(dp[n-1] % MOD)

if __name__ == "__main__":
    main()
```筛子有效地预先计算最小的素因数。 这`factorize`函数产生任意数字的不同质因数。 动态规划数组`dp`累积到每个城市的路径数量。 这`last`字典确保贡献仅来自共享至少一个素因子的先前城市。 更新中`last[p]`添加贡献保证后，我们不会多次计算路径。 边界处理自然由 Python 的从零开始的索引来处理。
