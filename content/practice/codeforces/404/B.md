 ## 解决方案
 ## 问题理解

 瓦莱拉绕着方形体育场的周边奔跑。 正方形有边长`a`，并且路线按逆时针顺序沿着边界。 

起点是左下角`(0, 0)`。 运行后`a`他达到的米数`(a, 0)`，又一个`a`他达到的米数`(a, a)`， 等等。 总周长是`4a`，所以每跑完一圈他就会回到`(0, 0)`并继续重复相同的路径。 

教练每次都会给瓦莱拉喝一杯`d`米。 我们必须在瓦莱拉跑完后输出他的坐标`d`,`2d`,`3d`, ...,`nd`米。 

关键的观察结果是，只有当前一圈的位置才重要。 如果 Valera 已跑完总距离`s`，那么他的位置由下式确定`s mod (4a)`，因为每个完整的周长都会把他返回到完全相同的位置。 

约束足够大，我们必须生成最多`10^5`答案。 任何逐米模拟运动的解决方案都是不可能的。 即使距离表示为实数，在最坏的情况下，微步模拟也需要数十亿次操作。 我们需要一个直接的公式来在恒定时间内计算每个答案。 

一些边缘情况很容易导致错误的答案。 

考虑：```
a = 2
d = 2
n = 1
```准确运行后`2`米，瓦莱拉位于`(2, 0)`，第一个角。 如果不小心使用严格的不等式，可能会让他处于下一个边缘。 

另一个例子：```
a = 3
d = 12
n = 1
```自从`12 = 4a`，他正好跑完一圈并返回`(0, 0)`。 如果我们忘记取模`4a`，我们可能会错误地尝试将他定位到边界之外。 

一个更微妙的情况是：```
a = 2
d = 5
n = 1
```周长是`8`， 所以`5 mod 8 = 5`。 距离`5`位于顶部边缘。 正确的位置是`(1, 2)`。 假设只有一圈或错误地计算边缘过渡的解决方案将在这里失败。 

## 方法

 最直接的想法就是模拟跑。 对于每一次饮酒活动，我们可以从`(0,0)`并沿着边缘重复移动，直到覆盖所需的距离。 这是正确的，因为它完全遵循路径。 

问题在于规模。 距离可以大到`10^5`，并且最多有`10^5`查询。 增量模拟运动需要太多的操作。 即使通过重复减去边长来处理每个查询也是不必要的工作。 

路径的结构提供了一个更简单的解决方案。 体育场边界是一个长度周期`4a`。 每跑一圈后，跑步者都会返回到相同的位置。 对于`i`第 次喝了酒，总行驶距离为$$s=i\cdot d$$仅有的$$r=s\bmod (4a)$$很重要。 

现在周长被分为四段长度`a`。 

如果`r`属于第一段，瓦莱拉位于底部边缘。 

如果`r`属于第二段，他在右边缘。 

如果`r`属于第三段，他在顶部边缘。 

如果`r`属于第四段，他在左边缘。 

每种情况都通过一个简单的公式给出坐标。 由于每个查询都是在恒定时间内独立处理的，因此整个解决方案运行在`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·距离) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算周长`p = 4 * a`。 
2. 保持每次饮酒后的总行驶距离。 而不是重新计算`i * d`，我们可以保留一个运行值：`cur = (cur + d) mod p`。 

之后`i`第-次迭代，`cur`等于`(i*d) mod p`。 
3.确定在正方形的哪一边`cur`谎言。 

如果`0 <= cur <= a`，跑步者位于底部边缘。 

如果`a < cur <= 2a`，跑步者位于右侧边缘。 

如果`2a < cur <= 3a`，跑步者位于顶部边缘。 

否则他就在左边。 
4. 将沿该边缘的距离转换为坐标。 

对于底边：$$(x,y)=(cur,0)$$对于右边缘：$$(x,y)=(a,cur-a)$$对于顶边：$$(x,y)=(a-(cur-2a),a)$$对于左边缘：$$(x,y)=(0,a-(cur-3a))$$5. 输出坐标。 

### 为什么它有效

 在任何时刻，跑步者的位置仅取决于他当前一圈的进步程度。 取模`4a`删除所有已完成的圈，同时保留周边的准确位置。 

的区间分解`[0,4a)`与正方形的四个边相匹配。 在每个间隔内，运动以单位速度沿单个直边发生，因此坐标公式描述了沿周长距起点的距离等于的唯一点`cur`。 由于每个可能的值`cur`恰好属于一个边缘，算法总是产生正确的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, d = map(float, input().split())
n = int(input())

perimeter = 4.0 * a
cur = 0.0

out = []

for _ in range(n):
    cur = (cur + d) % perimeter

    if cur <= a:
        x = cur
        y = 0.0
    elif cur <= 2.0 * a:
        x = a
        y = cur - a
    elif cur <= 3.0 * a:
        x = 3.0 * a - cur
        y = a
    else:
        x = 0.0
        y = 4.0 * a - cur

    out.append(f"{x:.10f} {y:.10f}")

sys.stdout.write("\n".join(out))
```第一部分读取正方形边长和喝水间隔。 周界只计算一次，因为它会被每个查询重复使用。 

变量`cur`删除完成的圈数后，存储当前沿周界的距离。 更新它```
cur = (cur + d) % perimeter
```避免重复计算`i * d`并保持数值较小。 

四个条件分支直接对应于正方形的四个边。 这些公式是根据跑步者沿着当前边缘前进的距离得出的。 

一个微妙的点是处理角落位置。 使用`<=`保持距离完全等于`a`,`2a`， 或者`3a`在一个明确的一侧。 无论选择哪一条相邻边，坐标都是相同的，因此这可以避免歧义。 

输出量大，可达`10^5`线。 将答案收集到列表中并打印一次比逐行写入要快得多。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    a, d = map(float, input().split())
    n = int(input())

    perimeter = 4.0 * a
    cur = 0.0

    out = []

    for _ in range(n):
        cur = (cur + d) % perimeter

        if cur <= a:
            x, y = cur, 0.0
        elif cur <= 2.0 * a:
            x, y = a, cur - a
        elif cur <= 3.0 * a:
            x, y = 3.0 * a - cur, a
        else:
            x, y = 0.0, 4.0 * a - cur

        out.append(f"{x:.10f} {y:.10f}")

    return "\n".join(out)

# provided sample
assert run("2 5\n2\n") == (
    "1.0000000000 2.0000000000\n"
    "2.0000000000 0.0000000000"
)

# minimum-size input
assert run("1 1\n1\n") == "1.0000000000 0.0000000000"

# exactly one full lap
assert run("3 12\n1\n") == "0.0000000000 0.0000000000"

# corner transitions
assert run("2 2\n4\n") == (
    "2.0000000000 0.0000000000\n"
    "2.0000000000 2.0000000000\n"
    "0.0000000000 2.0000000000\n"
    "0.0000000000 0.0000000000"
)

# repeated cycling
assert run("3 4\n4\n") == (
    "3.0000000000 1.0000000000\n"
    "1.0000000000 3.0000000000\n"
    "0.0000000000 0.0000000000\n"
    "3.0000000000 1.0000000000"
)
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|

 ## 边缘情况

 ### 恰好降落在拐角处

 输入：```
2 2
1
```周界位置为`2`，等于边长。 算法进入第一个分支（`cur <= a`）和输出：```
2.0000000000 0.0000000000
```这是正确的角。 任何相邻边解释都会产生相同的坐标，因此结果是明确的。 

### 距离等于完整周长

 输入：```
3 12
1
```周长是`12`。 

该算法计算：```
cur = 12 mod 12 = 0
```自从`cur = 0`，坐标变为：```
0.0000000000 0.0000000000
```跑步者已完成一整圈并返回起点。 

### 跨越许多圈的长距离

 输入：```
2 21
1
```周长是`8`。 

该算法计算：```
cur = 21 mod 8 = 5
```自从`5`位于之间`4`和`6`，跑步者位于顶部边缘。 

坐标：```
x = 6 - 5 = 1
y = 2
```输出：```
1.0000000000 2.0000000000
```只有剩下的才是重要的。 距离完成圈数二十米对最终位置没有影响。 

### 重复环绕

 输入：```
2 7
3
```周长 = 8。 

余数的序列为：```
7, 6, 5
```生产：```
0 1
0 2
1 2
```该算法从不明确跟踪完整的圈数。 模运算将每个查询映射到当前周界循环，这正是确定位置所需的信息。
