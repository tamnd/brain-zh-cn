 ## 解决方案
 ## 问题理解

 我们有一个机器人站在由整数索引的无限一维单元条上，从单元 0 开始。机器人被给予一系列移动，每个移动要么向左 (`L`）或右（`R`）。 在机器人启动之前，我们可以在某些单元格上放置障碍物，单元格 0 除外。如果某个移动会使机器人降落在有障碍物的单元格上，则该移动将被跳过。 机器人执行整个序列后，必须在指定的完成单元上结束，并在最后一次移动时仅访问该单元一次。 我们不能在精加工单元上设置障碍物。 

任务是确定机器人成功完成序列所需的最小障碍物数量，并计算放置障碍物的方式数量并选择完成单元来实现这一目标。 

The input string can be up to$10^6$字符长。 这立即排除了尝试模拟所有障碍物放置组合的解决方案，因为可能的集合数量呈指数级增长。 我们需要一个线性或近线性的解决方案。 一个微妙的点是，如果机器人被阻挡，它可以跳过移动，所以我们不能在不战略性地考虑障碍物的情况下天真地跟踪它的路径。 此外，完成单元不能为 0，并且在最后只能访问一次 - 任何不考虑跳过的移动而假设路径的粗心解决方案都可能会过度计数。 例如，`RR`需要在 1 处放置障碍物（以便机器人可以跳到 2）或选择 2 作为没有障碍物的终点； 天真的计数可能会错误地将 1 算作终点或放错障碍物。 

## 方法

 蛮力方法很简单：尝试将每个单元子集作为障碍物，模拟机器人的运动，检查最终单元并计算有效配置。 这在原则上是正确的，但完全不可行：对于长度序列$n$, 大致有$2^n$障碍物组，会爆炸$n$最多$10^6$。 即使为每个障碍物设置简单地模拟一条路径也会太慢。 

关键的见解是关注**所需的最少障碍物数量**，这对应于防止机器人在最后一次移动之前重新访问单元格。 我们没有测试所有子集，而是跟踪机器人在没有障碍物移动时的位置前缀和。 我们定义`pos[i]`作为机器人在第一个之后的位置`i`假设没有障碍物的情况下移动。 机器人的路径多次访问某些位置。 为了使最后一个单元格被访问一次，必须阻止最后一次移动之前访问的所有位置，否则机器人必须跳过移动，否则会导致重新访问。 问题归结为确定**最后一步之前访问的必须被阻止的位置数量**，然后计算仅满足最后一次访问的完成单元格。 

一旦我们知道哪些位置需要障碍物（除了最左边和最右边可到达的最大位置之外的所有已访问位置），我们就可以计算精确放置的方法数量`k`障碍物并选择有效的终点单元格。 这可以通过一次前缀和来完成。 仅访问一次的位置不需要障碍物的观察使我们能够将复杂性降低到$O(n)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个`pos`大小数组$n+1$和`pos[0] = 0`。 迭代移动序列。 对于每一步`s[i]`， 更新`pos[i+1] = pos[i] + 1`如果`R`和`pos[i] - 1`如果`L`。 这会计算机器人每走一步后的未受阻挡位置。 
2. 跟踪达到的**最小和最大仓位**`pos`。 最小值确定机器人将向左走多远，最大值确定机器人将向右走多远。 该范围之外的任何位置都是零障碍物的候选终点单元。 
3. 初始化计数器`needed_obstacles = 0`。 迭代序列。 对于每个中间位置，如果它位于最小位置和最大位置之间并且不是最后一步，则递增`needed_obstacles`。 这会计算如果不阻止的话会导致重新访问的单元格。 
4. 计算有效路径的数量，请注意，对于每个需要阻挡的中间位置，恰好有一种方法可以在那里放置障碍物。 完成单元可以是已访问位置范围之外的任何位置。 
5. 对可能的完成单元格的数量进行求和以计算最终答案。 这给出了精确放置的方法数量`k`障碍物并选择完成单元。 

**为什么它有效：** 不变的是，在最后一步之前访问的每个单元格都必须被阻止，否则这些单元格将被重新访问。 通过仅阻止这些单元格，机器人在最后一次移动之前不会重新访问任何单元格，并且保证最后一个单元格被恰好访问一次。 前缀和方法确保我们只考虑机器人实际接触的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)

# prefix sums of positions
pos = [0] * (n + 1)
for i, ch in enumerate(s):
    if ch == 'R':
        pos[i + 1] = pos[i] + 1
    else:
        pos[i + 1] = pos[i] - 1

min_pos = min(pos)
max_pos = max(pos)

# obstacles needed are positions strictly between min and max
needed_obstacles = 0
for p in pos[:-1]:
    if min_pos < p < max_pos:
        needed_obstacles += 1

# number of ways to choose finishing cell
finish_options = (max_pos - min_pos + 1) - (needed_obstacles + 1)
print(finish_options)
```前缀和计算跟踪机器人无障碍的自然路径。 我们跳过循环中的最后一个位置，因为结束单元格只能访问一次。 严格计数之间的细胞`min_pos`和`max_pos`给出障碍物位置的数量。 完成单元格选项是最小和最大之间未阻塞的所有位置。

 | 右 | 1 | 0 | 1 | 0 |
 | 右 | 2 | 0 | 2 | 0 |

 机器人自然移动到2。不需要障碍物。 完成单元格选项 = 1（单元格 2）。 

**样本2：`RL`**

 | 移动| 位置 | 最小 | 最大| 需要障碍|
 | --- | --- | --- | --- | --- |
 | 0 | 0 | 0 | 0 | 0 |
 | 右 | 1 | 0 | 1 | 0 |
 | 左 | 0 | 0 | 1 | 0 |

 位置 0 和 1 被访问。 为了在一次访问中以 1 或 -1 结束，必须适当地设置障碍。 计算产生 1 个有效配置。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    n = len(s)

    for i, ch in enumerate(s):
        pos[i + 1] = pos[i] + 1 if ch == 'R' else pos[i] - 1
    min_pos = min(pos)
    max_pos = max(pos)
