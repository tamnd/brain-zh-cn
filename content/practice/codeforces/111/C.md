 ## 解决方案
 ## 问题理解

 我们有一块尺寸为 _n_ × _m_ 的棋盘，每个单元格上都有一只蜘蛛。 每个蜘蛛都可以移动到任何相邻的单元格或留在原地，只要它留在棋盘内即可。 所有蜘蛛同时移动，多个蜘蛛移动后可以占据同一个单元格。 目标是在一次移动后最大化空单元格的数量。 输入是两个整数 _n_ 和 _m_，输出是一个整数，表示没有蜘蛛的单元格的最大数量。 

约束很小：_n_ 和 _m_ 都最多为 40，它们的乘积最多为 40。这意味着我们正在处理非常小的板，因此指数或阶乘时间算法是可行的。 主要挑战不是效率，而是如何重新排列蜘蛛的推理。 

不明显的边缘情况包括非常小的板。 例如，如果棋盘为 1x1，则唯一的单元格必须包含蜘蛛，因此输出为 0。对于 1x2 棋盘，一只蜘蛛可以移动到另一个单元格中，留下一个空单元格。 假设对称或忽略可用邻居数量的粗心方法将在窄板上失败。 

## 方法

 蛮力方法是尝试每只蜘蛛的所有可能的动作。 每个蜘蛛有五个选项，因此对于_n_·_m_个蜘蛛来说有$5^{n \cdot m}$运动组合。 即使对于最大 40 节电池的板，$5^{40}$是一个天文数字，所以这显然是不可行的。 

关键的观察是蜘蛛可以同时移动和重叠。 为了最大化空单元格，我们希望将蜘蛛集中到尽可能少的单元格中。 每个单元格最多有四个邻居，因此我们可以将问题视为平铺问题：我们可以将每个蜘蛛分配给邻居，从而使某些单元格最终为空。 在小板上，如果每个目的地可以容纳多个蜘蛛，则最大空单元格数是单元格数减去容纳所有蜘蛛程序所需的最小单元格数。 这相当于计算$\lceil \frac{n \cdot m}{2} \rceil$如果两个维度都大于 1，则为最大空单元格。对于单行或单列，最大值为$\lfloor \frac{n \cdot m}{2} \rfloor$由于边界限制。 

暴力破解会失败，因为它枚举了所有的运动模式。 对蜘蛛进行分组的观察将问题简化为基于棋盘尺寸的简单算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(5^(n·m)) | O(5^(n·m)) | O(n·m) | 太慢了 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 检查_n_ 或_m_ 是否为1。对于单行或单列，蜘蛛只能沿线移动。 在这种情况下，空单元格的最大数量是$\lfloor \frac{n \cdot m}{2} \rfloor$。 这可以正确处理所有窄板。 
2. 对于两个维度均大于 1 的棋盘，当蜘蛛以棋盘图案分组时，会出现最大空单元格。 这使得大约一半的单元格是空的。 如果 _n_·_m_ 是偶数，则恰好一半可以为空。 如果奇数，$\lfloor \frac{n \cdot m}{2} \rfloor$单元格可以为空。 直接计算这个值。 
3. 输出计算出的空单元格数。 

为什么有效：蜘蛛可以占据同一个单元格，因此唯一的限制是棋盘边界。 棋盘分组保证了最大的空单元格而不违反移动规则。 该公式可以正确处理窄板和普通板。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    if n == 1 or m == 1:
        print((n * m) // 2)
    else:
        print((n * m + 1) // 2)

if __name__ == "__main__":
    main()
```该解决方案读取电路板尺寸并根据电路板是单行/列还是更大来应用公式。 除法处理整数楼层，在第二个公式中加 1 处理奇数尺寸的板，给出最大空单元格所需的上限。 不需要复杂的数据结构。

 ## 边缘情况

 对于 1x1 板，公式`(1*1)//2 = 0`正确输出 0。对于 1x5 板，公式`(1*5)//2 = 2`留下两个单元格为空，因为沿单行的最大移动允许将三只蜘蛛分组到一个或两个单元格中。 对于像 5x5 这样的奇数方板，`(25+1)//2 = 13`正确计算棋盘图案下的最大空单元格。 每个边缘情况都尊重边界和移动规则。
