 ## 问题理解

 给定两个极大的整数$l$和$r$，写成十进制字符串，我们需要统计有多少个整数在包含范围内$[l, r]$满足特殊的数字属性。 

当一个数字的所有十进制数字的乘积是素数时，该数字被认为是有效的。 由于素数的限制非常严格，因此该条件迫使数字的数字结构受到高度限制。 任务是计算给定区间内有多少个有效数字。 

这些约束清楚地表明我们无法将输入转换为内置整数类型，因此所有算术都必须在字符串上完成。 范围长度可达$10^{100000}$，因此任何解决方案都必须在位数的大致线性时间内工作。 

一个简单的方法是迭代中的每个数字$[l, r]$，计算数字的乘积，并测试素数。 即使数字乘法很便宜，范围的大小也使得这变得不可能。 

一种微妙的边缘情况是包含数字零的数字。 例如，数字 105 的数字积为零，这不是素数。 另一种边缘情况是仅由 1 组成的数字，例如 111 或 1，其中乘积为 1，也不是素数。 这些失败表明，有效数字在结构上必定非常罕见，而不仅仅是数字上受到限制。 

最后一个边缘情况是个位数。 例如，2、3、5 和 7 是有效的，因为它们的数字积等于它们自己，它们是素数。 相反，4、6、8 和 9 无效，因为它们的数字乘积不是素数。 

## 方法

 暴力解决方案将扫描来自的每个数字$l$到$r$，将其转换为数字，计算数字的乘积，并检查它是否是质数。 即使我们通过注意到乘积快速增长来优化素性检查，范围内的整数数量也可能是巨大的，并且该方法在区间的大小上基本上是线性的。 数字可能高达$10^5$数字，甚至每个数字迭代一次也是不可能的。 

关键的观察结果来自于分析数字乘积为素数意味着什么。 素数只有一个素因数。 每个数字只贡献小质数$2, 3, 5, 7$，任何复合数字都会立即引入多个素因数。 数字 0、1、4、6、8 和 9 要么引入额外的因子，要么完全破坏素性。 这会强制任何有效数字仅包含该组中的一位数字$\{2, 3, 5, 7\}$，而其他数字必须为 1。禁止出现任何 0。 

这种结构崩溃将问题从任意算术问题简化为受约束的数字模式计数问题。 我们不是迭代数字，而是计算范围内有多少数字串满足一个简单的条件，这非常适合数字动态规划。 

我们定义一个函数$f(x)$计算小于或等于的有效数字$x$，并将最终答案计算为$f(r) - f(l - 1)$，其中对表示为字符串的大整数执行减法。

 ## 算法演练

 该问题简化为计算十进制表示中恰好包含一位数字的数字$\{2, 3, 5, 7\}$，数字开始后不包含零，并且所有其他数字等于 1。 

我们使用数字 DP 代替上限的字符串表示形式。 

1. 我们定义一个关于位置的 DP 状态，一个严格的约束，我们是否已经开始了这个数字，以及我们是否已经使用了特殊的素数数字。 该位置跟踪我们放置的数字。 strict 标志确保我们不会超出边界的前缀。 开始标志确保我们忽略前导零。 使用的标志确保我们准确地选择一个特殊数字。 
2. 在每个位置，我们尝试从 0 到 9 的所有数字，但我们会尽早修剪掉无效的转换。 如果我们已经开始数字，则禁止使用数字 0，因为它会使数字乘积为零。 在开始之前，允许使用零来表示前导填充。 
3. 当我们输入一个数字时，我们会更新开始标志。 如果我们在未开始时放置一个非零数字，则数字从该位置开始。 
4. 仅当我们在其中放入数字时，我们才会更新已使用的标志$\{2, 3, 5, 7\}$。 如果我们尝试放置第二个这样的数字，则转换无效。 
5. 等于 1 的数字不会影响已使用的标志，并且在数字开始之后始终允许。 
6. DP 累积所有有效完成的计数，最后我们只接受数字已开始且恰好使用了一个特殊数字的状态。 
7. 为了计算一个范围内的答案，我们评估$f(r)$并减去$f(l - 1)$，其中大整数字符串的递减是单独处理的。 

正确性来自于以下不变量：每个 DP 状态准确地表示具有固定结构分类的边界的有效前缀的数量：一个数字是否已经开始以及它的单个允许的非 1 数字是否已经被放置。 因为每个无效数字选择都被本地排除，所以永远不会构造无效数字，并且因为每个有效数字在该 DP 中都只有一个表示形式（一旦开始就强制执行前导零，不会产生歧义），因此计数是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from functools import lru_cache

def dec_str(s: str) -> str:
    s = list(s)
    i = len(s) - 1
    while i >= 0 and s[i] == '0':
        s[i] = '9'
        i -= 1
    if i >= 0:
        s[i] = str(int(s[i]) - 1)
    # strip leading zeros
    res = ''.join(s).lstrip('0')
    return res if res else "0"

def solve(x: str) -> int:
    n = len(x)
    primes = {'2', '3', '5', '7'}

    @lru_cache(None)
    def dp(pos: int, tight: int, started: int, used: int) -> int:
        if pos == n:
            return 1 if started and used == 1 else 0

        limit = int(x[pos]) if tight else 9
        res = 0

        for d in range(limit + 1):
            nd = str(d)

            ntight = 1 if (tight and d == limit) else 0

            if not started:
                if d == 0:
                    res += dp(pos + 1, ntight, 0, used)
                else:
                    if nd in primes:
                        res += dp(pos + 1, ntight, 1, 1)
                    elif nd == '1':
                        res += dp(pos + 1, ntight, 1, 0)
            else:
                if d == 0:
                    continue
                if nd in primes:
                    if used:
                        continue
                    res += dp(pos + 1, ntight, 1, 1)
                elif nd == '1':
                    res += dp(pos + 1, ntight, 1, used)
                else:
                    continue

        return res

    return dp(0, 1, 0, 0)

def main():
    l = input().strip()
    r = input().strip()

    def less_or_equal(a, b):
        if len(a) != len(b):
            return len(a) < len(b)
        return a <= b

    if l == "0":
        left_val = 0
    else:
        left_val = solve(dec_str(l))

    right_val = solve(r)
    print(right_val - left_val)

if __name__ == "__main__":
    main()
```DP 的重点是跟踪数字是否已经开始，因为否则前导零会创建同一整数的多个表示形式。 转换规则强制执行关键的结构限制：最多一位数字$\{2,3,5,7\}$，并且一旦数字开始就没有零。 

减法步骤是必要的，因为数字 DP 自然地对数字进行计数$[0, x]$，而问题要求一个闭区间。

 ## 边缘情况

 对于像这样的输入$l = 1, r = 1$，DP 正确地拒绝该数字，因为它从不使用质数数字，因此使用的标志在终止时保持为零。 

对于像这样的输入$l = 2, r = 2$，DP 立即接受，因为数字 2 是质数并且该数字满足精确一约束。 

对于包含带零的数字（例如 101）的范围，尝试在数字开始后放置零的转换将被拒绝，从而防止对无效产品进行计数。 

对于大的统一字符串，例如$111\ldots111$，DP 遍历所有数字，但从不设置已使用的标志，确保这些数字被排除在外，即使它们满足 1 的数字限制。
