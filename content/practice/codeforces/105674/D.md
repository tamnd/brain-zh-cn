 ## 解决方案
 ## 问题理解

 我们有一个网格$k$行和$n$列。 每个细胞可能含有也可能不含矿物质。 我们不是直接观察网格，而是得到扫描仪的输出。 

For each column$p$，扫描仪定义了一个从列开始的“三角形”区域$p$当我们向上移动行时向左扩展。 具体来说，专栏$p$贡献一切$k$柱格$p$， 柱子$p-1$仅贡献其顶部$k-1$细胞、柱$p-2$仅贡献其顶部$k-2$细胞，依此类推，直到贡献消失。 扫描仪输出$b_p$就是这个三角形区域内矿物细胞的数量。 

任务不是重建一个有效的网格，而是计算有多少个不同的二进制网格（每个单元中是矿物的或空的）精确地为所有列产生给定的扫描仪输出。 答案需要模数$10^9+7$。 

这些限制立即塑造了问题。 行数极少，最多 7 行，而列数最多 200 行。这种不对称性表明，任何将行视为主要指数维度的解决方案都是可以接受的，但列或完整网格配置中的任何指数维度都是不可能的。 该结构还表明每个单元格都对多个扫描仪答案做出贡献，因此我们正在处理全局约束系统而不是独立的列。 

当扫描仪输出不一致时，会出现微妙的边缘情况。 例如，如果$k=2$,$n=3$， 和$b=[0, 3, 0]$，那么仅第 2 列就需要比其三角形区域中物理上可能的矿物质更多的矿物质。 在这种情况下，正确答案是 0。任何独立处理列而不检查重叠约束的方法都会错误地计算不可能的配置。 

另一个棘手的情况是，存在多种配置，但无法通过天真的每列推理来区分。 由于每个细胞都贡献于多个$b_p$，如果不考虑未来的列，就无法最终确定列中的局部决策。 

## 方法

 直接的蛮力方法是迭代所有$2^{nk}$可能的网格并验证每个网格是否与扫描仪输出匹配。 这在概念上是正确的，因为它测试了每个配置，但即使是$n=200$和$k=7$，这是一个天文数字，远远超出了任何可行的计算。 

关键的结构洞察是重新解释每个细胞的影响。 行中的一个单元格$r$， 柱子$c$有助于扫描仪结果$b_p$对于连续的范围$p$价值观。 具体来说，如果我们修复一个单元格，它会影响从其列到其行确定的右侧有限距离的所有扫描仪查询。 这会将网格变成列轴上间隔的集合。 

每行都有固定的行为：行中的一个单元格$r$在列$c$正好有助于$k-r+1$连续扫描仪输出开始于$c$。 所以每一个网格配置就相当于为每个cell选择是否激活一个区间$[c, c+L-1]$在哪里$L$仅取决于行。 

这将问题转化为计算从结构化族中选择间隔的方式有多少种，以便它们的重叠计数与给定的数组匹配$b$。 间隔是高度规则的：在每一列$c$，从 1 到 的每个长度恰好有一个潜在区间$k$，对应于$k$行。 

因为$k$很小，我们可以逐列处理网格，同时仅维护当前活动的间隔。 在每一步中，我们都会跟踪每个剩余生命周期存在多少个活动间隔。 这将全局组合爆炸减少为有界状态转换系统。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解网格 |$O(2^{nk})$|$O(nk)$| 太慢了 |
 | 具有活动间隔状态的 DP 列 |$O(n \cdot 2^k \cdot S)$在哪里$S$是可达状态的数量 |$O(S)$| 已接受 |

 ## 算法演练

 我们从左到右处理列。 关键思想是在任何列$p$，仅从最后开始的间隔$k$列仍然可以处于活动状态，因为最长可能的间隔长度是$k$。 这使我们能够使用描述按剩余长度分组的活动间隔的小状态来表示整个系统。 

1.我们为列定义一个状态$p$作为数组`cnt[1..k]`， 在哪里`cnt[t]`表示当前有多少个活动间隔覆盖列$p$并且恰好有$t$其余列，包括当前列。 

这种状态完全决定了对$b_p$，因为扫描仪值为$p$只是所有的总和`cnt[t]`。 
2. 在每一列，我们通过检查活动间隔的总和是否等于给定的来验证可行性$b_p$。 如果不匹配，则丢弃该状态。 

此步骤强制与扫描仪输出保持本地一致性。 
3. 从列中的每个州$p$，我们考虑所有可能的方式来激活列中的新细胞$p$。 每行$r$对应于固定长度的潜在区间$L = k - r + 1$，因此每一行都贡献一个二元决策：要么激活该单元格，要么不激活该单元格。 

有$2^k$每列的选择。 
4. 选择从列开始的间隔后$p$，我们过渡到列$p+1$。 所有活动间隔将其剩余长度减少 1，因此`cnt[t]`转移到`cnt[t-1]`。 达到零的间隔消失。 
5. 新激活的区间按照其全长插入到下一个状态。 如果我们激活对应于长度的一行$L$，它被添加到`cnt[L]`在下一个状态。 
6. 我们使用列上的动态规划来累积到达每个状态的方法数量。 

### 为什么它有效

 该状态准确捕获影响未来转换的信息：哪些间隔仍然有效以及它们将继续贡献多长时间。 每个间隔一旦开始就独立运行，它与系统其余部分的唯一交互是通过每列的总和。 因为所有间隔都有有限的生命周期$k$，没有早于的信息$k$步骤是永远需要的。 这保证了两个历史导致相同的`cnt`state 对于所有未来的列都是无法区分的，因此将它们合并到 DP 中可以保持正确性。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline
MOD = 10**9 + 7

def encode(cnt):
    # tuple form for hashing
    return tuple(cnt)

def solve():
    n, k = map(int, input().split())
    b = list(map(int, input().split()))

    # dp[state] = number of ways
    # state: (cnt1, cnt2, ..., cntk)
    dp = defaultdict(int)
    dp[tuple([0] * k)] = 1

    for i in range(n):
        ndp = defaultdict(int)

        bi = b[i]

        for state, ways in dp.items():
            cnt = list(state)

            # check current coverage constraint
            if sum(cnt) != bi:
                continue

            # try all subsets of k rows (2^k choices)
            for mask in range(1 << k):
                # build next state
                nxt = [0] * k

                # decay old intervals
                for t in range(k - 1):
                    nxt[t] = cnt[t + 1]

                # add new intervals from current column
                for r in range(k):
                    if mask & (1 << r):
                        L = k - r
                        nxt[L - 1] += 1

                ndp[tuple(nxt)] = (ndp[tuple(nxt)] + ways) % MOD

        dp = ndp

    print(sum(dp.values()) % MOD)

if __name__ == "__main__":
    solve()
```DP字典只存储每列的可达区间配置。 每个配置都会记录有多少活跃贡献将保留到未来的列中。 该转换执行两个逻辑上独立的操作：首先，所有现有贡献衰减一步，其次，我们可以选择引入与当前列中所选单元格相对应的新贡献。 

一个常见的实现陷阱是混合衰减和插入顺序。 如果新的间隔立即以与旧的间隔相同的步骤衰减，则它们的生命周期将变得不正确，这会改变所有贡献并破坏与旧间隔的一致性$b_p$。 该代码通过首先构造衰减数组然后才插入新间隔来避免这种情况。 

另一个微妙的问题是状态爆炸。 尽管理论上的状态数量很大，但实际上由于活动间隔总和必须匹配的限制，许多状态是无法到达的$b_p$在每一步。 This pruning is essential for passing within limits.

 ## 边缘情况

 一个关键的边缘情况是所有扫描仪输出都为零。 在这种情况下，每个状态的所有列都必须保持为空。 DP 从空配置开始，每一步都只有全零状态，从而形成一个有效的配置。 

另一种边缘情况是当列需要比实际存在的更多的活动间隔时。 例如，如果$k=2$和$b_p=3$，则没有状态可以满足约束`sum(cnt) == b_p`，DP 立即消除所有配置，产生输出 0。 

第三种微妙的情况是间隔重叠迫使贡献延迟。 柱上的单次激活$c$可能会影响最多$k$未来的列，因此正确性取决于维护完整的剩余长度向量，而不仅仅是总活动计数。 DP 状态显式跟踪这种衰减，确保正确处理远程依赖关系而不会产生歧义。
