 ## 解决方案
 ## 问题理解

 我们被要求计算数组中元素彼此“接近”的特定子集。 更准确地说，我们有一个整数数组`a`长度`n`，我们想要尺寸的数量-`m`元组中最大和最小元素之间的差异最多为`k`。 输出是模数$10^9+7$。 

输入表示多个测试用例，每个测试用例指定一个序列和元组约束。 每个测试用例的输出是一个整数：有效元组的数量模$10^9+7$。 

约束表明`n`可以大到$2 \cdot 10^5$， 但`m`很小，最多 100。这意味着尝试所有方法的幼稚方法$C(n, m)$直接元组是不可能的，因为操作数量以组合方式增长。 相反，我们需要一种利用小规模的方法`m`以及数组的有序结构。 

非明显的边缘情况包括所有元素都相同或其中的数组`k`为零。 例如，对于`n=3`,`m=2`,`k=0`， 和`a=[1,1,2]`，只有成对的相同元素才有效。 只考虑全局差异的粗心方法会过多计算包括元素在内的元组`2`。 

## 方法

 蛮力方法生成大小指数的所有组合`m`，然后检查每个元组的最大值和最小值之间的差异。 这是正确但不可行的：生成所有$C(2 \cdot 10^5, 100)$元组非常大，无法在任何合理的时间内运行。 

优化的关键观察是元素可以排序，这使我们能够处理连续的子数组。 一旦数组排序完毕，任何大小的元组`m`索引处具有最小元素`i`窗口内必须包含以最大元素结束的所有其他元素，即最多`k`大于`a[i]`。 这将问题转化为对有效范围内的索引组合进行计数。 

自从`m`很小并且`n`很大，预计算阶乘模$10^9+7$让我们有效地计算组合。 对于每个`i`，我们找到最大的索引`j`这样`a[j] - a[i] <= k`。 然后以以下开头的有效元组的数量`a[i]`是`C(j - i, m - 1)`，因为我们选择`m-1`的附加元素`j-i`之后的元素`i`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^m) | O(n^m) | O(n) | 太慢了|
 | 最佳| O(n log n + n * m) | O(n log n + n * m) | O(n) | 已接受 |

 ## 算法演练

 1. 预计算阶乘和逆阶乘模$10^9+7$达到最大`n`跨所有测试用例。 这允许使用公式快速计算组合$C(n, r) = \text{fact}[n] \cdot \text{inv\_fact}[r] \cdot \text{inv\_fact}[n-r]$。 
2. 对于每个测试用例，请阅读`n`,`m`,`k`，和数组`a`。 种类`a`按升序排列。 排序可确保有效差异内的元素是连续的。 
3. 初始化变量`ans = 0`。 这将累积有效元组的数量。 
4. 迭代每个索引`i`从 0 到`n-1`。 对于元素`a[i]`，使用两指针方法找到最大索引`j`这样`a[j] - a[i] <= k`。 
5. 如果该窗口中的元素数量`count = j - i`至少是`m-1`，然后添加`C(count, m-1)`到`ans`。 否则，没有大小元组`m`可以开始于`a[i]`。 
6. 输出`ans % MOD`对于测试用例。 

为什么它有效：排序保证了之间的所有元素`i`和`j`在之内`k`的`a[i]`。 两指针方法确保我们只有效地考虑有效窗口，而无需重新扫描元素。 组合学确保该窗口内的所有元组都被正确计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAX = 2 * 10**5 + 100

fact = [1] * MAX
inv_fact = [1] * MAX

# precompute factorials and inverse factorials modulo MOD
for i in range(1, MAX):
    fact[i] = fact[i-1] * i % MOD

inv_fact[MAX-1] = pow(fact[MAX-1], MOD-2, MOD)
for i in range(MAX-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, r):
    if n < r or r < 0:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n-r] % MOD

t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()
    ans = 0
    j = 0
    for i in range(n):
        while j < n and a[j] - a[i] <= k:
            j += 1
        count = j - i - 1
        if count >= m - 1:
            ans = (ans + comb(count, m-1)) % MOD
    print(ans)
```该解决方案首先准备组合计算。 排序使我们能够找到元素最多相差的窗口`k`。 两指针方法避免了冗余工作并保证了阵列的线性扫描。 关键的微妙之处在于我们从中减去一`j - i`因为索引处的元素`i`已经算作最小值了。
