 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中，数轴上都有一组闭区间。 从这个集合中，我们希望保留尽可能多的间隔，但仅限于结构约束。 

如果间隔子集内至少存在一个间隔与该子集中的每个其他间隔相交，则该间隔子集被视为有效。 换句话说，在选定的子集中，我们必须能够选择一个“代表性”区间，使得该区间与所有其他区间重叠，或者通过共享至少一个点，或者通过完全覆盖重叠区域。 

任务不是直接构造子集，而是确定必须删除多少个区间才能使剩余的集合满足此属性。 

约束条件很大：所有测试用例的区间总数可以达到 200,000 个。 这立即排除了间隔内的二次解，例如检查所有对或显式测试每个候选子集。 每个测试用例的任何解决方案都必须接近线性或对数，通常为 O(n log n)。 

当间隔由于单个“异常值”间隔而几乎不满足条件时，就会出现微妙的边缘情况。 

例如，考虑间隔：```
[1, 2], [2, 3], [3, 5], [4, 5]
```没有一个区间与所有其他区间相交。 尽管链中存在重叠，但不存在触及两个极端的单一区间。 假设重叠链就足够的天真贪婪策略将错误地保留所有间隔。 

另一个重要的边缘情况是所有区间相交于一个点时：```
[1, 10], [2, 3], [4, 5], [6, 7]
```这里第一个间隔与所有其他间隔相交，因此答案是零删除。 任何仅检查成对重叠密度而不跟踪全局“中心”间隔的方法都可能会错过此结构。 

核心困难在于认识到该条件相当于找到一个大子集，其中一个区间充当通用相交中心，并最大化该子集的大小。 

## 方法

 暴力方法将尝试间隔的每个子集，并检查是否存在与该子集中的所有其他间隔相交的间隔。 即使我们修复了候选“中心”间隔，我们仍然需要验证与每个其他选定间隔的交集。 在最坏的情况下，这会导致大约 O(n²) 个子集，并且每个子集的检查时间为 O(n)，这远远超出了可行的限制。 

我们可以换个角度来看。 假设我们猜测哪个区间将作为最终集合中的通用相交区间。 如果该间隔是固定的，则所有其他间隔都必须与它相交。 这将问题简化为计算有多少间隔与给定间隔重叠。 

对于固定区间 [l, r]，另一个区间 [L, R] 与其相交当且仅当：```
L ≤ r and R ≥ l
```因此，对于每个区间，我们可以计算有多少个区间与其相交。 通过选择最大化此计数的间隔来实现最佳可能的有效集，因为它可以充当所需的集线器。 

因此，问题就变成了：对于每个区间，计算有多少个区间与它​​重叠，取最大值，然后从 n 中减去。 

为了有效地计算重叠计数，我们按左端点对间隔进行排序，并在右端点上使用二分搜索。 使用排序数组和前缀结构，我们可以计算在给定 r 之前开始的间隔数，并减去在 l 之前结束的间隔。 

这将问题从检查所有对减少为每个时间间隔的对数查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按左端点对所有区间进行排序，并单独维护右端点的排序列表。 

排序创建的结构允许我们使用二分搜索而不是成对比较来计算重叠。 
2. 对于每个区间 [l, r]，计算有多少个区间的左端点 ≤ r。 

这给出了可以在右侧相交的候选间隔超集。 
3. 在这些候选项中，减去右端点 < l 的区间。 

这些区间完全位于左侧且不能与 [l, r] 相交。 
4. 剩余计数是与当前区间相交的区间数。 
5. 跟踪所有时间间隔内的最大此类计数。 

该最大值表示以单个间隔为中心的最大可能的“好”子集。 
6. 输出 n 减去该最大值。 

### 为什么它有效

 有效集合要求存在一个与集合中所有其他间隔相交的间隔。 该区间必须属于集合本身。 因此，每个有效集合完全对应于选择一个候选区间并获取与其相交的所有区间。 不可能有更大的结构，因为任何没有这种通用相交区间的集合都会立即违反定义。 因此，最大化所有候选者的交集计数会产生最佳子集大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        segs = []
        L = []
        R = []
        
        for _ in range(n):
            l, r = map(int, input().split())
            segs.append((l, r))
            L.append(l)
            R.append(r)
        
        L.sort()
        R.sort()
        
        def count_leq(arr, x):
            lo, hi = 0, n
            while lo < hi:
                mid = (lo + hi) // 2
                if arr[mid] <= x:
                    lo = mid + 1
                else:
                    hi = mid
            return lo
        
        best = 0
        
        for l, r in segs:
            # intervals with L <= r
            left_part = count_leq(L, r)
            # intervals with R < l
            right_bad = count_leq(R, l - 1)
            overlap = left_part - right_bad
            if overlap > best:
                best = overlap
        
        print(n - best)

if __name__ == "__main__":
    solve()
```该解决方案构建两个排序数组，一个用于左端点，一个用于右端点。 对于每个间隔，它计算有多少个间隔在其右边界之前或在其右边界处开始，然后删除那些严格在其左边界之前结束的间隔。 该差值精确计算与其相交的间隔。 

二分查找函数`count_leq`手动实现以避免开销并确保每个查询的 O(log n)。 每个间隔都被视为潜在的枢纽，并跟踪最大重叠。 

减法步骤使用`l - 1`通过严格的不平等处理隐式地进行。 这避免了对在当前间隔开始之前结束的间隔进行计数。

 ## 边缘情况

 一种重要的边缘情况是所有区间都相交于一点。 例如：```
[1, 10], [2, 3], [4, 5], [6, 7]
```该算法将每个区间评估为潜在的枢纽。 对于 [1, 10]，所有区间满足`L ≤ 10`并且没有一个在 1 之前结束，因此重叠变为 4，这是最大的。 输出为零删除，符合预期结果。 

另一个边缘情况是没有全局交集的严格链接：```
[1,2], [2,3], [3,4], [4,5]
```每个间隔仅与其相邻间隔重叠。 最大重叠计数为 2，因此算法返回 2 个删除，正确地表明必须删除至少两个间隔才能获得有效的中心结构。 

最终的边缘情况是相同的间隔，例如：```
[1,5], [1,5], [1,5]
```每个区间都与所有其他区间重叠，因此每个候选区间都会产生重叠 3，而答案为零。
