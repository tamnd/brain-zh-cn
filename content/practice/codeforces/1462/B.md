 ## 解决方案
 ## 问题理解

 问题给出一串数字，并询问是否可以使用最多一个连续删除将其转换为字符串“2020”。 Polycarp 可以删除字符串中任意位置的零个或多个连续字符。 输入由多个测试用例组成，每个测试用例提供字符串的长度和字符串本身。 如果这样的转换是可能的，则每个测试用例的输出为“是”，否则为“否”。 

约束条件适中：字符串长度在 4 到 200 之间，最多可以有 1000 个测试用例。 由于每个字符串相对较短，因此解决方案可以在不超过时间限制的情况下检查多个可能的删除。 边缘情况包括正好是“2020”的字符串、开头或结尾带有“2020”的字符串，以及可以通过删除内部块形成“2020”的字符串。 例如，“22020”通过删除第一个字符可以变成“2020”，而“20202”通过删除最后一个字符可以变成“2020”。 如果仅检查“2020”作为连续子字符串，简单的方法可能会错过这些位置。 

## 方法

 暴力方法将尝试删除所有可能的子字符串，重建剩余的字符串，并将其与“2020”进行比较。 对于一个长度的字符串`n`， 有`n*(n+1)/2`子串，复杂度为`O(n^3)`用于检查每个删除。 考虑到较小的目标字符串“2020”和问题的结构，这是不必要的。 

关键点是“2020”的长度为 4，因此原始字符串中最多 4 个字符与形成它相关。 我们只需要检查是否是第一个`k`字符串的字符和最后一个字符`4-k`对于某些人来说，字符形成“2020”`k`从 0 到 4。这涵盖了单个连续删除可能使“2020”完好无损的所有情况。 该观察结果将问题从考虑所有删除减少到检查每个字符串的五种情况：单独的前缀、单独的后缀以及总共四个字符的前缀和后缀的组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 前缀后缀检查 | 每个字符串 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取字符串`s`和它的长度`n`。 
3. 检查是否`s`本身就是“2020”； 如果是，则打印“YES”。 
4. 否则，迭代`k`从0到4，代表从开头开始的字符数`s`。 拿第一个`k`字符和最后一个`4-k`字符，连接它们，并与“2020”进行比较。 
5. 如果有任何组合匹配，则打印“YES”； 如果没有匹配，则打印“NO”。 

这样做的原因是任何有效的单删除转换`s`输入“2020”必须保留原始字符串的某些前缀和某些后缀不变。 由于“2020”的长度固定为4，因此未触及的字符只能分布在开始和结束之间。 这保证了检查所有`k`从0到4涵盖了所有可能的有效删除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        target = "2020"
        found = False
        for k in range(5):
            if s[:k] + s[n-(4-k):] == target:
                found = True
                break
        print("YES" if found else "NO")

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 对于每个字符串，它会针对“2020”精确检查五个潜在的前缀后缀组合。 切片操作是安全的，因为`n >= 4`是有保证的。 当发现匹配时，循环立即中断，以避免不必要的检查。
