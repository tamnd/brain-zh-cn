 ## 解决方案
 ## 问题理解

 我们被要求计算有根树中顶点序列的数量，以便我们可以根据特定规则沿着它们“跳跃”芯片。 这棵树有`n`顶点编号从`1`到`n`和`1`作为根。 每个顶点`x`有一个距离`d_x`从根源上。 芯片从根部开始，可以移动到一定距离的顶点`d_v + 1`从当前顶点`v`。 有一个微妙的限制：如果当前顶点不是根，则芯片不能移动到直接邻居，否则它可以跳转到下一个深度的任何顶点。 目标是计算在此跳跃规则下可访问的所有顶点序列。 

输入作为多个测试用例给出，每个测试用例使用父数组指定树。 每个测试用例的输出是一个整数：有效序列的数量模`998244353`。 

约束很严格：`n`可以达到`3 * 10^5`所有测试用例的总计。 这排除了任何比以下更糟糕的解决方案`O(n)`每个测试用例，因此直接枚举序列是不可行的。 生成所有序列的简单方法将发生组合爆炸，因为即使是深度为 10、分支因子为 3 的普通树也可以生成超过 59,000 个序列。 

非明显的边缘情况包括根有多个子节点但没有孙子节点的树、线性链（如链表）以及顶点只有一个子节点的树。 在线性链中，唯一有效的序列是从根到叶的完整路径。 如果根有多个子节点，则每个子节点都可以独立启动自己的序列。 

## 方法

 暴力解决方案将尝试生成从根开始的所有序列并检查每个跳转条件。 对于每个顶点，我们可以尝试下一个深度的每个可能的顶点。 这种方法原则上是正确的，但是序列的数量随着树的大小呈指数增长。 和`n = 10^5`这是完全不可行的。 

关键的观察是有效序列可以递归计数。 对于任何顶点，从该顶点开始的有效序列的数量仅取决于可以从其子节点开始的序列。 在每个顶点，我们可以通过跳转到非邻居子节点来停止或扩展序列。 如果一个顶点有`k`子级，包括其子级在内的序列数是乘积`(1 + sequences_from_child)`。 我们添加`1`考虑在带走孩子之前停止的顺序。 根有点特殊，因为它可以不受限制地跳转到任何子节点。 

这将问题从指数序列枚举转化为线性树DP。 DP 递归以后序方式应用，因此我们在计算父序列之前计算子序列的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 树DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析输入并根据父数组将树构造为邻接列表。 
2.初始化一个DP数组`dp[v]`对于每个顶点，它将存储从顶点开始的有效序列的数量`v`。 
3.定义处理顶点的递归DFS函数`v`：

 - 初始化`dp[v] = 1`计算仅由以下内容组成的序列`v`。 
- 对于每个孩子`u`的`v`，递归计算`dp[u]`。 
- 乘法`dp[v]`经过`(1 + dp[u])`模数`998244353`对于每个孩子。 这说明了选择包含或排除子级中的序列`u`。 
4.在根顶点启动DFS`1`。 
5. 测试用例的结果是`dp[1]`模数`998244353`。 
6. 对每个测试用例重复步骤 1-5。 

工作原理：DP 递归正确地计算所有序列，因为在每个顶点，我们对每个子项都有两个选项 - 要么包含源自子项的序列，要么不包含。 子项的乘积确保包含/排除每个子项的所有组合都被计算在内。 DFS 确保子项在父项之前计算，尊重递归中的依赖性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

MOD = 998244353

def solve():
    t = int(input())
    results = []
    for _ in range(t):
        n = int(input())
        parents = list(map(int, input().split()))
        tree = [[] for _ in range(n + 1)]
        for i, p in enumerate(parents, start=2):
            tree[p].append(i)

        dp = [0] * (n + 1)

        def dfs(v):
            dp[v] = 1
            for u in tree[v]:
                dfs(u)
                dp[v] = dp[v] * (1 + dp[u]) % MOD

        dfs(1)
        results.append(dp[1])

    print("\n".join(map(str, results)))

if __name__ == "__main__":
    solve()
```该代码使用从 1 开始的索引从父数组构造树。 我们使用 DFS 从根开始填充 DP 数组。 乘法`dp[v] = dp[v] * (1 + dp[u]) % MOD`计算包含或排除以 child 为根的子树的所有序列`u`。 最终的结果就是根的DP值。

 ## 边缘情况

 在长度为 5 的链中（`1-2-3-4-5`)，每个顶点只有一个子顶点。 DFS 计算`dp[5] = 1`， 然后`dp[4] = 1*(1+1)=2`,`dp[3] = 2*(1+1)=4`…但我们必须只计算遵循“下一个深度”限制的序列，这在链中与计算从根开始到任何地方结束的路径完全对应。 DP公式自然就做到了这一点。 该算法通过乘法处理星树`(1 + dp[child])`对于每个孩子，计算所有选择的组合
