 ## 解决方案
 ## 问题理解

 该问题要求我们计算以下整数：`0`到`n`包含其中整数除以时留下相同的余数`3`并由`5`。 我们不需要生成每个数字并检查条件，而只需计算存在多少个这样的数字。 输入由多个测试用例组成，每个测试用例都有一个整数`n`，输出是每个测试用例的一个整数，表示满足条件的数字的计数。 

的界限`n`上升到`10^9`，并且可能最多有`10^4`测试用例。 一种简单的方法，迭代每个数字直到`n`最多需要`10^9`每个测试用例的操作，这太慢了。 这迫使我们寻找数学公式或模式，而不是模拟每个数字。 

当出现不明显的边缘情况时`n`小于`3`或者`5`。 例如，与`n = 0`， 仅有的`0`满足条件，给出计数`1`。 另一种边缘情况发生在`n`刚好低于`15`因为有效数字的模式每次都会重复`15`数字。 粗心的实现可能无法正确包含最后一个块。 

## 方法

 蛮力方法迭代自`0`到`n`并检查每个整数`i % 3 == i % 5`。 这是正确的，但对于`n`最多`10^9`。 操作次数可达`10^9 * 10^4`在最坏的情况下，这是不可行的。 

关键的观察是条件`i % 3 == i % 5`周期性发生。 的最小公倍数`3`和`5`是`15`，因此该序列每 15 个数字重复一次。 每块 15 个数字中，恰好有这些数字`0, 1, 2, 15, ...`满足`i % 3 == i % 5`。 通过检查第一个块，我们看到`0, 1, 2`满足它。 因此，对于任何`n`，我们可以计算出有多少个完整的 15 块`[0, n]`以及还剩下多少个额外的数字，然后计算剩余的数字中满足条件的数字。 

这将问题简化为简单的整数算术：除法、取模和乘法。

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`。 
2. 计算有多少个完整的 15 数字块`[0, n]`使用整数除法：`full_blocks = n // 15`。 
3. 计算完整块之外的剩余数字：`remainder = n % 15`。 
4. 每个完整区块的贡献`3`有效数字（`0, 1, 2`块内）。 乘`full_blocks * 3`。 
5. 剩余块贡献`min(remainder + 1, 3)`有效数字，因为任何块中只有前三个数字满足条件。 
6. 将完整块和剩余块的贡献相加以获得答案。 
7. 打印测试用例的结果。 

**为什么有效：** 条件`i % 3 == i % 5`每 15 个数字重复一次。 通过计算完整的 15 个数字块并仔细处理剩余的数字，我们保证我们对满足条件的所有数字恰好计数一次。 这可以避免迭代所有数字，同时仍然提供正确的计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        full_blocks = n // 15
        remainder = n % 15
        count = full_blocks * 3 + min(remainder + 1, 3)
        print(count)

if __name__ == "__main__":
    solve()
```该代码使用快速 I/O 有效地读取所有测试用例。 计算使用整数除法和取模来计算完整的 15 个数字块和剩余数字。`min(remainder + 1, 3)`确保我们在余数块中最多只计算三个数字。 This avoids mistakes at boundaries, such as`n`just below a multiple of 15.

 ## 边缘情况

 对于`n = 0`，算法正确返回`1`因为只有`0 % 3 == 0 % 5`。 为了`n = 14`，14 的余数块仅正确计算前三个数字。 为了`n`等于 15 的倍数，例如 15，该公式从余数中添加一个额外的数字，正好给出四个数字，与手动计数一致。 该模式每 15 个数字重复一次的不变性保证了所有边缘情况的正确性。
