 ## 解决方案
 ## 问题理解

 我们看到首都周围的山丘呈圆形排列。 每座山都有一个高度和一个可以通过火发送信号的守望者。 核心问题是：有多少对守望者可以看到彼此的信号？ 

一对小山`(i, j)`如果沿着连接它们的两条弧线中的至少一条，没有比这两条弧线更高的山，则可以进行通信`i`和`j`。 直观上，信号沿着一段线段“传播”，除非被比端点高的山阻挡。 

输入由一个整数组成`n`后面的山丘数量`n`按顺时针顺序表示高度的整数。 输出是一个整数：可以通信的无序对的计数。 

和`n`最多 10^6 且时间限制为 4 秒，任何复杂度低于 O(n log n) 的算法都不太可能有效运行。 简单的 O(n²) 方法是不可行的，因为它可能需要多达 10^12 次比较。 边缘情况包括所有高度相等的山丘、多个最大高度山丘以及一座高山挡住多座山的序列。 例如，`[5, 5, 5]`应该计算所有三对，但忽略相等性的粗心方法可能会低估。 

## 方法

 蛮力方法在概念上很简单：迭代所有对`(i, j)`并检查它们之间的两条弧线是否有阻挡山。 这是可行的，因为问题的条件是明确的：对于至少一个弧，所有中间山丘必须低于两个端点中较小的一个。 在实践中，对于`n=10^6`，这意味着在最坏的情况下大约需要进行 5×10^11 次比较，这太慢了。 

优化的关键见解来自于注意到通信条件仅取决于严格高于给定山丘的山丘。 如果我们按照高度递减的顺序处理山丘，我们可以使用单调堆栈或多集结构有效地跟踪每个山丘形成了多少个新对。 本质上，最高的山丘彼此之间是微不足道的，而对于较低的山丘，可见对的数量由比当前山丘短的连续山丘序列决定。 通过仔细计算重复项（等高的山丘）和圆形邻接，我们可以在 O(n) 时间内计算出总数。 

强力方法和最佳方法之间的区别在于，强力方法显式检查每一对，而最佳方法使用堆栈在单次传递中按高度聚合可见性计数，以维护仍然可见的候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最优（单调堆栈）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 识别阵列中最高的山丘。 只有这些山丘可以阻挡信号，因此首先开始计算涉及这些山丘的对。 如果有多个最高的山，它们之间的每一对都可以看到对方。 
2. 旋转阵列，以便从最大高度的山开始计数。 这避免了使用线性堆栈时出现循环环绕的复杂情况。 
3. 初始化一个用于存储元组的堆栈`(height, count)`，代表相同高度的连续山丘。 顺时针遍历数组。 对于每座山：

 - 从堆栈中弹出所有比当前山丘短的山丘。 每个弹出的山丘都有贡献`count`成对，因为当前的山可以看到所有这些较短的山。 
- 如果堆栈顶部与当前山的高度相同，则增加其高度`count`并添加`count`成对的等高山丘之间的内部可见度。 
- 将当前山（或更新顶部）推入堆栈。 
4. 完成顺时针传递后，处理堆叠中剩余的山丘以进行圆形连接。 两侧最高的山丘可以互相看到，并且堆栈确保较小山丘之间的所有内部可见度都已被计算在内。 
5. 对堆栈操作期间计算的所有对求和。 返回这笔金额。 

为什么它有效：单调堆栈确保我们只考虑可能阻挡信号的山丘。 通过按降序处理高度，每一个较短的山丘的可见度都被计算一次。 重复的高度被分组在一起以正确计算内部对。 圆度是通过从最大高度的山开始处理的，这保证了遍历永远不会错过被对面更高的山阻挡的连接。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_pairs(heights):
    n = len(heights)
    if n == 1:
        return 0

    max_h = max(heights)
    max_idx = heights.index(max_h)

    # Rotate array so we start from a maximum hill
    heights = heights[max_idx:] + heights[:max_idx]

    stack = []
    total = 0

    for h in heights:
        count = 1
        while stack and stack[-1][0] < h:
            total += stack[-1][1]
            stack.pop()
        if stack and stack[-1][0] == h:
            cnt_equal = stack[-1][1]
            total += cnt_equal
            stack[-1] = (h, cnt_equal + 1)
        else:
            if stack:
                total += 1  # sees the previous taller hill
            stack.append((h, 1))

    return total

n = int(input())
heights = list(map(int, input().split()))
print(count_pairs(heights))
```该解决方案首先旋转阵列以简化循环处理，然后使用堆栈来保持降低的高度。 每次弹出都会计算当前山可以看到的所有可见对。 等高的山丘被合并以计算内部对，并且通过遍历自然地计算堆栈中的单个剩余对（最高的山丘）。

 ## 边缘情况

 对于`[5, 5, 5, 5]`，所有的山都是平等的。 该算法合并连续的相等山丘，计算内部对，并正确计算相邻的圆形对，总共产生 6 对。 

为了`[5, 1, 5, 2, 5]`，从前 5 个山丘开始，确保最后 5 个山丘的全景可见性。堆栈跟踪等高的山丘，计算 5 个山丘中的 3 对，以及中间较小山丘的对。 总共9个是正确的。
