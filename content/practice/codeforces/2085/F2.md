 ## 解决方案
 ## 问题理解

 我们需要确定在给定数组中创建至少一个“彩色”子数组所需的相邻交换的最小数量。 彩色子数组的长度正好是`k`并包含来自的所有整数`1`到`k`正好一次。 数组`a`长度`n`可以有重复的元素，但每个整数`1`到`k`至少出现一次，这保证了最终可以形成一个彩色子数组。 

输入由多个测试用例组成，每个测试用例指定数组长度`n`，目标子数组大小`k`，以及数组本身。 每个测试用例的输出是一个整数：产生彩色子数组的相邻交换的最小数量。 

约束条件允许`n`所有测试用例最多 400,000 个。 这立即排除了任何检查所有可能的长度子数组的暴力方法`k`或者单独模拟每个交换，因为操作数量会爆炸。 在 O(n·k) 时间内迭代所有子数组的简单解决方案太慢了。 

边缘情况包括在某些位置已经是彩色的数组、数字的所有实例都聚集在开头或结尾的数组，或者单个数字的多个重复项需要多次交换才能将它们分开的数组。 例如，一个数组`[1, 1, 2, 2, 3]`和`k=3`最初并不是彩色的，但可以通过两次交换来改变`[1, 2, 3]`。 

## 方法

 暴力解决方案将滑动一个长度的窗口`k`遍历数组，计算每个数字的出现次数。 如果窗口缺少任何数字或有重复项，我们将尝试交换相邻元素来修复它。 原则上这是正确的，但是检查每个窗口并模拟交换会导致 O(n·k) 操作，这对于`n`高达 400,000。 

最佳方法利用贪婪策略和计数技巧。 关键的观察是，**形成彩色子数组的最小交换次数取决于每个数字在某些理想序列中距其目标位置的距离。`1..k`**。 我们可以：

 1. 统计每个整数出现的次数`1`到`k`出现在**候选序列中每个数字的最后一次出现**。 
2. 从第一个出现的地方开始`1`并贪婪地尝试形成一个连续的序列`1..k`向前穿过阵列。 
3. 每当序列中缺少一个数字时，我们就知道需要进行交换以使其更靠近窗口。 因此，所需交换的总数等于相对于完美序列中的位置而言无序的元素数量。 

我们的见解是，只有**最长的已排序子序列 1..k** 才重要。 最小交换次数等于`k`减去该子序列的长度。 使用映射来跟踪数字的最新位置允许 O(n) 中的一次传递来确定最佳子序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力滑动窗口| O(n·k) | O(k) | 太慢了|
 | 贪心最长有序子序列 | O(n) | O(k) | 已接受 |

 ## 算法演练

 1.初始化一个字典`last_pos`映射每个数字`1..k`到`-1`记录最后看到的位置。 
2. 初始化计数器`length`跟踪已排序的最长子序列的长度。 
3. 迭代数组`a`：

 1. 对于元素`x`在索引处`i`，检查最后的位置`x-1`在`last_pos`。 
2.如果`x`是`1`或者`last_pos[x-1] < i`, 增量`length`为了`x`相对于 1`x-1`。 
3. 更新`last_pos[x] = i`。 
4. 处理完整个数组后，`length`包含最长有序子序列的长度`1..k`。 
5. 最少需要的交换次数为`k - length`。 

为什么有效：任何已订购的序列都不需要交换。 每个丢失或无序的元素必须移动到正确的相对位置，这可以通过相邻交换来完成。 由于交换一次仅将元素移动一个位置，因此最小移动次数恰好对应于不在最长有序子序列中的元素数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    # Track the length of the longest subsequence ending at each number
    dp = [0] * (k + 2)  # dp[x] = length of subsequence ending with x
    pos = [-1] * (k + 2)
    
    for idx, val in enumerate(a):
        if val == 1:
            dp[1] = max(dp[1], 1)
        else:
            dp[val] = max(dp[val], dp[val - 1] + 1)
    
    min_swaps = k - dp[k]
    print(min_swaps)
```代码中使用了动态编程数组`dp`在哪里`dp[x]`表示以 number 结尾的最长子序列的长度`x`。 为了`1`，序列以长度 1 开始。对于数字`2..k`，我们将序列扩展为`x-1`如果可能的话。 最小交换次数是`k`以及已经跟随的最长序列`1..k`。
