 ## 解决方案
 ## 问题理解

 我们给定两个正整数，`x`和`y`，我们被要求找到一个非负整数`k`这样当我们添加`k`对于这两个数字，它们的总和等于它们的按位异或。 换句话说，我们想要`(x + k) + (y + k) = (x + k) ⊕ (y + k)`。 如果没有这样的`k`存在，我们应该返回`-1`。 允许有多个答案，因此任何有效的答案`k`作品。 

约束条件比较大：`x`和`y`可以达到`10^9`， 和`k`可以大到`10^18`。 测试用例数量`t`可以达到`10^4`。 这排除了迭代所有可能的暴力解决方案`k`值，因为即使是简单的线性搜索也会超出可行的时间限制。 

一个关键的、不明显的边缘情况发生在`x`等于`y`。 如果`x = y`， 然后`(x + k) ⊕ (y + k)`永远会是`0`对于任何`k`， 尽管`(x + k) + (y + k)`总是积极的。 例如，如果`x = y = 6`, 没有有效的`k`，答案一定是`-1`。 一个简单的解决方案假设`k = 0`始终有效会在这里失败。 另一个微妙的情况出现时`x`和`y`仅在一位上有所不同，这影响了选择`k`。 

## 方法

 蛮力方法会迭代所有可能的方法`k`值，计算`(x+k) + (y+k)`和`(x+k) ⊕ (y+k)`，并返回第一个`k`则满足等式。 这对于正确性是有效的，因为它会检查每种可能性，但这是不可行的：如果`k`上升到`10^18`，没有办法探索那么多候选者。 甚至限制`k`较小的范围可能会失败，因为该解决方案可能需要非常大的`k`。 

关键的见解来自对异或运算的分析。 身份`(a + b) = a ⊕ b + 2*(a & b)`对于任何整数都成立`a`和`b`。 将其应用于我们的问题给出`(x + k) + (y + k) = (x + k) ⊕ (y + k) + 2*((x + k) & (y + k))`。 为了维持平等，我们需要`2*((x + k) & (y + k)) = 0`，这意味着`(x + k) & (y + k) = 0`。 因此，问题归结为寻找一个`k`这样`x + k`和`y + k`没有设置重叠位。 

这一观察使我们能够构建`k`贪婪地：对于每个位位置，同时`x`和`y`有一个`1`，我们必须添加足够的`k`“继承”其中之一，确保`(x + k)`和`(y + k)`没有两个`1`是一致的。 通过处理二进制表示，我们可以构造一个有效的`k`高效。

 ## 算法演练

 1.如果`x`等于`y`， 返回`-1`。 不`k`在这种情况下满足等式，因为`(x+k) ⊕ (y+k)`永远会是`0`，而总和不为零。 
2. 计算绝对差`d = y - x`。 我们可以假设`y > x`不失一般性的交换。 
3. 检查是否`d`可以表示为 2 的幂之和，使得每个设置位对应于一个位置，其中`x`有一个`0`。 这保证了添加`k`不会产生重叠`1`s 位于相同的位位置`x+k`和`y+k`。 
4. 构建`k`作为`d`。 具体来说，选择`k = d`如果`(x & d) == 0`。 在这种情况下，添加`k`到`x`不翻转已经存在的位`1`在`x`，确保`(x+k) & (y+k) = 0`。 
5. 如果`(x & d) != 0`，最简单的保证方法是`k = 2^ceil(log2(max(x, y)))`减`x`或其他有建设性的价值。 然而，最小的非负数`k`满意的`(x+k) & (y+k) = 0`总是可以使用上面的按位对齐来获得。 
6. 返回构造好的`k`。 

不变量是`(x+k) & (y+k) = 0`。 由于两个数字的和与异或仅相差其 AND 的两倍，因此确保 AND 为零即可保证相等。 通过添加`k`在两个数字最初都有的位置`0`s，我们保持这个不变式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        if x == y:
            print(-1)
            continue
        if x > y:
            x, y = y, x
        d = y - x
        if (x & d) == 0:
            print(d)
        else:
            k = 0
            bit = 1
            while (x + k) & (y + k):
                while x & bit or y & bit:
                    bit <<= 1
                k += bit
            print(k)

if __name__ == "__main__":
    solve()
```第一部分读取测试用例的数量并对其进行循环。 对于每种情况，它处理`x == y`立即出现边缘情况。 核心见解在于`(x & d) == 0`，它检测是否添加`d`将产生重叠位。 如果不，`d`本身是一个有效的`k`。 否则，我们构造一个`k`通过找到可以安全添加的最低位来迭代以避免重叠。
