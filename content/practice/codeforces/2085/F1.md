 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，其中每个数字从 1 到给定的幻数$k$至少出现一次。 目标是转换该数组，使其包含长度为连续的子数组$k$其中从 1 到$k$恰好出现一次。 我们可以在数组中执行相邻交换，目标是最小化产生至少一个“彩色”子数组所需的此类交换数量。 

约束条件是这样的$n \le 3000$和总和$n$所有测试用例的数量也最多为 3000。这意味着具有复杂性的算法$O(n k)$或者$O(n^2)$可行，但算法复杂$O(n^3)$会太慢。 1 到 之间的每个数字$k$保证至少出现一次，所以我们不需要处理缺失的元素。 当数字大量重复时，就会出现不明显的边缘情况，例如在 [1,1,1,2,3] 这样的数组中$k=3$。 如果不正确地跟踪每个数字最后一次出现的位置，粗心的滑动窗口或计数方法可能会错误地计算掉期。 

## 方法

 简单的方法是考虑每个可能的长度子数组$k$，然后对于每个子数组，计算将其排列成彩色数组所需的最小交换次数。 要计算交换，可以尝试所有$k!$子数组的排列并计算每个排列需要多少次相邻交换。 虽然这原则上可行，但复杂性是$O(n k! k)$甚至变得不可行$k=8$，因为阶乘占主导地位。 

关键的观察是该问题可以简化为元素频率的计数问题。 考虑一个从某个索引开始并不断增长以包含每个数字最后一次出现的窗口$[1,k]$。 如果我们固定每个数字的最后出现位置，则通过对它们的位置进行排序并将它们“滑动”到连续索引中，可以最大限度地减少以任何顺序将这些元素组合在一起所需的交换总数。 更具体地说，是将一组头寸分组的掉期次数$p_1 < p_2 < \dots < p_k$进入连续槽等于$\sum_{i=1}^k (p_i - (p_1 + i - 1)) = \sum p_i - \frac{k(k-1)}{2} - k p_1$。 通过迭代所有可能的最后出现的情况，我们可以有效地找到最小值。 

因此，问题简化为当我们从左到右扫描时跟踪每个值的最新位置，从而保持将相应元素分组到彩色子数组中的最小成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（每个窗口的所有排列）| O(nk!k) | O(nk!k) | O(k) | 太慢了|
 | 最佳（使用最后出现的位置进行分组）| O(n·k) | O(k) | 已接受 |

 ## 算法演练

 1.初始化一个字典`last_pos`将每个数字从 1 映射到$k$到 -1，表示该数字的最后一个已知索引。 
2. 初始化变量`min_swaps`到无穷大。 这将存储找到的最小数量的交换。 
3. 使用索引迭代数组`i`从 0 到$n-1$。 对于每个`a[i]`， 更新`last_pos[a[i]] = i`记录最近发生的情况。 
4. 检查是否所有数字都从 1 到$k$至少见过一次。 如果有任何数字有`-1`作为最后一次出现，继续下一次迭代。 
5. 收集数字 1 到 最后位置的列表$k$并对它们进行排序。 设这些位置为$p_1 < p_2 < ... < p_k$。 
6. 使用以下公式计算使这些头寸连续所需的掉期：$\sum_{j=1}^{k} (p_j - (p_1 + j - 1))$。 这是可行的，因为每个元素必须向左移动以填充其当前位置和理想的连续槽之间的间隙。 总和给出了所需的相邻交换总数。 
7. 更新`min_swaps`电流之间的最小值`min_swaps`以及计算出的掉期。 
8. 处理完整个数组后，`min_swaps`包含生成至少一个彩色子数组所需的最少操作数。 

为什么它有效：每次迭代都会考虑以当前索引结尾且可以包含所有数字的最早可能窗口。 成本公式捕获将元素对齐到连续槽位所需的最小相邻交换次数。 对位置进行排序可确保我们始终计算最小交换，而不会重复计算或重叠移动。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    last_pos = [-1] * (k + 1)
    min_swaps = float('inf')
    
    for i in range(n):
        last_pos[a[i]] = i
        if all(pos != -1 for pos in last_pos[1:]):
            positions = [last_pos[j] for j in range(1, k+1)]
            positions.sort()
            swaps = sum(positions[j] - (positions[0] + j) + 1 for j in range(k))
            min_swaps = min(min_swaps, swaps)
    
    print(min_swaps)
```该解决方案首先读取测试用例的数量并迭代每个测试用例。 它更新每个数字的最后看到的位置，并且仅当完整的集合可用时才计算交换。 排序可确保交换计算以最小移动顺序对齐元素。 边界条件，例如数组，其中第一个$k$元素已经形成一个彩色子数组，并且已正确处理，因为`positions`将反映这一点，产生零掉期。
