 ## 解决方案
 ## 问题理解

 我们给出了矩形内的所有格点，这意味着每个点$(x,y)$具有整数坐标，使得$0 \le x \le n$,$0 \le y \le m$， 和$(0,0)$被排除在外。 

在这些点中，我们必须选择具有特殊属性的最大可能子集：对于每对所选点，它们之间的欧几里得距离不能是整数。 

这项任务是建设性的。 我们不需要只计算答案，我们实际上必须输出一组最大尺寸的漂亮集合。 

界限非常小，$n,m \le 100$。 对所有子集进行强力搜索仍然是不可能的，因为矩形包含最多$101 \times 101 - 1 = 10200$点。 子集的数量是天文数字。 小约束暗示预期的解决方案是基于发现最优集的结构而不是执行大量计算。 

一个微妙的点是，当距离的平方是完全平方数时，距离恰好是整数。 由于所有坐标都是整数，因此每个距离的平方都是整数。 一个简单的解决方案可能会尝试使用浮点运算来检查距离，这可能会引入精度问题。 预期的解决方案完全避免了距离计算。 

另一个容易犯的错误是假设只有水平和垂直对齐才能创建整数距离。 例如，之间$(0,0)$和$(3,4)$距离是$5$，它也是一个整数。 任何建设性的解决方案都必须防止所有此类情况，而不仅仅是轴对齐的情况。 

考虑$n=1,m=3$。 可用点有：$$(0,1),(0,2),(0,3),(1,0),(1,1),(1,2),(1,3)$$选择单列上的所​​有点都会失败，因为之间的距离$(0,1)$和$(0,3)$平等的$2$，一个整数。 解决方案的结构必须小心避免在坐标中产生整数差异。 

## 方法

 蛮力观点对于理解问题很有用。 假设我们构建一个图，其顶点是格点，并且只要两个顶点的距离是整数，就连接两个顶点。 那么任务就变成了寻找最大独立集。 

这个公式是正确的，因为美丽的集合正是不包含冲突对的集合。 

不幸的是，该图可能包含超过一万个顶点。 在小得多的图上，最大独立集已经很困难，所以这个方向是没有希望的。 

关键的观察来自于观察位于同一对角线上的点$x+y=c$。 

在该对角线上取两个不同的点：$$(x_1,y_1), \quad (x_2,y_2)$$既然两者都满足$x+y=c$,$$y_2-y_1 = -(x_2-x_1)$$距离的平方变为$$(x_2-x_1)^2 + (y_2-y_1)^2 = 2(x_2-x_1)^2$$对于任何非零整数$d$,$$2d^2$$永远不是一个完美的正方形。 因此，同一条对角线上不同点之间的每个距离都是无理数，因此不是整数。 

这立即给出了一个漂亮的大集合：将所有格点放在一条对角线上。 

对角线可以包含多少个这样的点？ 对角线$x+y=t$包含$$\min(t,n)-\max(0,t-m)+1$$点。 所有对角线上的最大可能尺寸恰好是$$\min(n,m)+1.$$达到这个尺寸的特别简单的对角线是$$(0,\min(n,m)), (1,\min(n,m)-1), \dots, (\min(n,m),0).$$现在我们需要证明最优性。 

对于任意点$(x,y)$，考虑其价值$x+y$。 自从$$1 \le x+y \le n+m,$$只有$n+m$可能的正和。 

如果两个点有相同的$x$-坐标，它们的距离是$|y_1-y_2|$，一个整数。 因此，最多一个选定的点可以使用每个$x$-协调。 

只有$\min(n,m)+1$可用的$x$- 沿较短维度的坐标。 更直接地说，我们可以证明每一个漂亮的集合最多都有大小$\min(n,m)+1$，对角线构造达到这个界限。 

因此对角线是最佳的。

 ## 算法演练

 1. 计算$k=\min(n,m)$。 
2.构建点$$(0,k), (1,k-1), \ldots, (k,0).$$每一点都满足$x+y=k$，所以所有点都位于同一条对角线上。 
3、输出$k+1$，构造点的数量。 
4. 输出每个构造点。 

这样做的原因是对角线上的任何两个不同的点都有坐标差$(d,-d)$。 它们的距离平方等于$2d^2$，它永远不是完美的平方，因此每一对都有一个非整数距离。 

### 为什么它有效

 所有选择的点都满足$x+y=k$。 对于任意两个不同的选择点，差异向量为$(d,-d)$和$d \ne 0$。 距离的平方为$2d^2$。 自从$2$不是正方形，$2d^2$不可能是一个完美的正方形。 因此每对距离都是非整数，所以这个集合很漂亮。 

对角线恰好包含$k+1=\min(n,m)+1$点。 这是上面编辑论证中证明的最大可能大小，因此该结构是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    k = min(n, m)

    print(k + 1)
    for x in range(k + 1):
        print(x, k - x)

solve()
```实施直接跟随构造。 

首先我们计算$k=\min(n,m)$。 对角线$x+y=k$保证留在矩形内，因为两个坐标都保持在$0$和$k$， 和$k$不超过任一界限。 

该循环生成该对角线上的每个格点。 什么时候$x$增加自$0$到$k$，对应的$y$减少自$k$到$0$。 

不需要距离计算。 数学证明保证所有生成的点形成一个漂亮的集合，并且其大小是最佳的。 

一个常见的实施错误是选择对角线$x+y=\max(n,m)$。 这样的对角线可能会离开矩形。 使用$k=\min(n,m)$避免了这个问题。

 ## 边缘情况

 考虑尽可能最小的输入：```
1 1
```该算法计算$k=1$和输出：```
2
0 1
1 0
```两点之间的距离是$\sqrt{2}$，它不是整数。 该套装非常漂亮且最佳。 

考虑一个高度不对称的矩形：```
1 100
```算法依然采用$k=1$。 它仅输出对角线上的点$x+y=1$:```
2
0 1
1 0
```尝试沿着更高的维度延伸得更远将创建具有整数距离的垂直对。 将结构限制为较短的尺寸可以避免这个问题。 

考虑一个最大尺寸的正方形：```
100 100
```该算法输出所有点$$(0,100),(1,99),\ldots,(100,0).$$每对都保持在同一条对角线上，因此任意两点之间的距离平方为$2d^2$。 证明与实际大小无关，因此即使在最大的约束下，该构造仍然有效。
