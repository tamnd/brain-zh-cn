 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，我们可以将每个元素绘制为黑色或白色。 绘制后，我们将数组分成两个子数组：一个包含所有白色元素，一个包含所有黑色元素。 在每个子数组中，连续的相同数字被视为单个段。 我们的目标是最大化两个子阵列的段总数。 

输入很简单：数组的长度$n$（最多$10^5$) 和数组本身，元素的边界为$1$和$n$。 输出是一个整数，即可实现的最大段总数。 

这些约束意味着解必须是线性的或接近线性的$n$。 任何探索所有可能的绘画任务的算法，这将是$2^n$，是完全不可行的。 甚至逼近二次方$n$可能会超时$n = 10^5$。 

微妙的边缘情况包括所有元素都相同的数组，其中最佳解决方案可能涉及将单个重复数字分成两种颜色，或具有交替图案的数组，这可以通过交替颜色来最大化分段。 例如，对于数组$[1,1,2,2,1,1]$，将一个数字的所有部分涂成相同颜色的简单方法会比交错分配产生更少的段。 

## 方法

 蛮力方法是尝试所有$2^n$绘制数组并计算段总数的方法。 这是正确的，但完全不切实际，因为$n$可以达到$10^5$。 即使存储所有可能性或迭代索引子集也会超出内存或时间限制。 

最佳解决方案的关键见解是认识到每个子数组中的段数仅取决于连续数字的变化位置以及我们如何在两种颜色之间分割相同的数字。 连续的相同数字最多可以为每个子数组贡献一个段，并且每个不同的数字串都提供了通过交替分配来增加段的机会。 

这一观察结果使我们能够将问题简化为对数组的不同数字进行动态规划。 对于每个不同的值，如果我们将先前出现的值涂成黑色或白色，我们就会跟踪最大分段。 转换取决于当前出现的情况是继续前一个段还是在任一子数组中开始一个新段。 这种方法与数组长度加上不同数字的数量呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | DP 按值运行 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将数组压缩为连续的相同数字。 每次运行都由其值和长度表示。 这简化了分段计算，因为一次运行中的内部重复会分解为单个分段。 
2. 维护一个字典，将每个值映射到两个计数器：`max_white`和`max_black`。 如果最后一个出现被分配为白色或黑色，则这些跟踪以该值结尾的最大总片段数。 
3. 按顺序迭代运行。 对于每次运行的值`v`， 更新`max_white[v]`作为最大值`(previous max_black[v] + 1)`和`(global max segments so far if last of other value was white)`。 同样，更新`max_black[v]`对称地。 这捕获是否继续使用相同颜色的段或切换颜色会产生更多段。 
4. 保持所有值的全局最大值，以了解迄今为止看到的最佳总分段。 
5. 处理完所有运行后，全局最大值就是答案。 

为什么它有效：该算法保留了以下不变式：`max_white[v]`和`max_black[v]`始终反映以 value 结尾的序列的最佳总片段`v`白色或黑色。 每次运行都只处理一次，并且转换会考虑所有有效的先前序列。 不会遗漏任何组合，并且我们绝不会重复计算分段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    # compress consecutive duplicates
    runs = [a[0]]
    for i in range(1, n):
        if a[i] != a[i-1]:
            runs.append(a[i])
    
    max_white = dict()
    max_black = dict()
    global_max = 0
    
    for val in runs:
        mw = max_black.get(val, 0) + 1
        mb = max_white.get(val, 0) + 1
        
        max_white[val] = max(max_white.get(val, 0), mw)
        max_black[val] = max(max_black.get(val, 0), mb)
        
        global_max = max(global_max, max_white[val], max_black[val])
    
    print(global_max)

if __name__ == "__main__":
    main()
```压缩步骤确保我们只处理连续值之间的更改，这是新段可以开始的唯一点。`max_white`和`max_black`对于未见的值被初始化为 0。 更新为`max(...)`确保我们永远不会减少先前计算的最佳值。 这`global_max`最后捕获所有值的最大值。

 ## 边缘情况

 对于单元素数组`[42]`，算法压缩为`[42]`， 套`max_white[42]=1`,`max_black[42]=1`，并返回`1`。 这符合预期。 

为了`[5,5,5,5,5]`，压缩将其减少为`[5]`，如果绘制最佳，则允许两个部分：一个白色，一个黑色。 该算法计算`max_white[5]=2`,`max_black[5]=2`，产生`2`根据需要。 

对于交替数组，该算法将更新交错`max_white`和`max_black`正确捕获每个步骤的最大分段，确保全局最大值在所有运行中正确累积。
