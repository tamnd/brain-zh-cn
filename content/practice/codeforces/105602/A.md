 ## 解决方案
 # 问题理解

 分形以边长的单个正方形开始`a`。 为了构建下一个级别，每条边都被分成三个相等的部分，并且一个新的正方形向外连接到中间三分之一。 之后，内部构造线消失，只留下外部边框。 重复相同的操作，但仅限于上一步中创建的正方形的外边缘。 

任务是找到以下结果的闭合形状的两个测量值：`N`级别：其边界和该边界所包围的区域的总长度。 

关卡数可以达到500，所以模拟绘图不太现实。 小方块的数量呈指数增长，因为每个创建的方块都会产生三个新的附着位置。 任何存储每个正方形或边缘的算法都会很快超出内存。 所需的解决方案必须使用分形的重复结构而不是构造它。 

边长可以大到 1,000,000，因此面积的中间值可以达到大约`10^12`。 Python 浮点数足以满足所需的输出精度，但在转换之前应使用整数公式，以避免在数百次迭代中累积误差。 

有几种情况很容易处理不当。 例如，当不进行任何构造时：```
Input
0
5
```答案是原来的正方形：```
Perimeter: 20
Area: 25
```总是添加第一代方块的解决方案将输出更大的值。 

另一种情况是第一个非零电平：```
Input
1
3
```四个正方形的边长`1`被添加。 周长变成`4*3 + 4*(3-1) = 20`， 不是`24`，因为四个相连的正方形与原始正方形各共享一条边，并且这些共享边不再是边界的一部分。 

第三个常见错误出现在大`N`。 例如：```
Input
500
1000000
```新的正方形数量巨大，但它们的边长却变得极小。 即使最终的公式只需要一些算术运算，模拟也会失败。 

## 方法

 直接的方法是逐级构建分形。 在第一层，我们添加四个正方形。 在下一个级别，这四个方块中的每一个都会创建三个新方块，因此添加的方块数量每一代都会增加三倍。 后`N`级别，最后一步添加的新方块数为`4 * 3^(N-1)`。 为了`N = 500`，这远远超出了任何可以存储或处理的东西。 

暴力法之所以感觉自然，是因为图片本身是递归的。 同样的递归给出了捷径。 我们只需要计算一代人贡献了多少周长和面积。 

考虑一个边长为正方形的情况`s`被依附。 一侧长度`s`已经到了境界。 它从外面消失，而新正方形的其他三个边出现。 周长变化为`3s - s = 2s`。 

处于水平`k`，每个新正方形都有边长`a / 3^k`。 这样的正方形的数量是`4 * 3^(k-1)`。 总周长增量为：`4 * 3^(k-1) * 2a / 3^k = 8a / 3`令人惊讶的是，每个级别都会增加相同的周长。 

区域就更简单了。 每个新方块仅增加自己的面积。 等级贡献`k`是：`4 * 3^(k-1) * (a / 3^k)^2 = 4a^2 / 3^(k+1)`这些值形成几何级数，因此可以计算整个分形而无需创建任何几何图形。

 | --- | --- | --- | --- |
 | 蛮力 | O(3^N) | O(3^N) | O(3^N) | O(3^N) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从原始平方值开始。 它的周长是`4a`它的面积是`a²`，因为零层仅包含起始方块。 
2. 将所有球员的外线贡献相加`N`建设水平。 每个级别都会增加边界`8a/3`，所以最终周长为：`4a + N * 8a / 3`3. 将增加的面积计算为几何和。 第一代添加的贡献`4a²/9`，并且每一代都小三倍。 为了`N`级别，附加面积为：`2a²/3 * (1 - 3^(-N))`4. 将多余的面积添加到原始正方形面积中，并打印两个结果并保留足够的小数位。 

该算法背后的不变性是每一代都具有完全相同的周长效果和可预测的缩放区域效果。 前几代内部的构造细节并不重要。 对下一代来说最重要的是新创建的正方形的数量和大小，它们遵循固定的三的幂。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    n = int(input())
    a = int(input())

    perimeter = 4 * a + n * (8 * a / 3)

    if n == 0:
        area = a * a
    else:
        area = a * a + (2 * a * a / 3) * (1 - 3 ** (-n))

    print("{:.10f}".format(perimeter))
    print("{:.10f}".format(area))

if __name__ == "__main__":
    solve()
```代码的第一部分读取级别和初始边长。 只有一个测试用例，因此不需要循环测试用例。 

周长公式利用了每个级别贡献相同数量的事实。 乘以`n`是安全的，因为`n`只有500。 

对于面积，表达式使用等比级数的闭合形式。 的特殊处理`n == 0`避免依赖`3 ** (-0)`，并且还保持公式的含义清晰。 

Python 的浮点类型在这里有足够的精度，因为输出只需要小数点后六位数字。 指数`3 ** (-n)`很快就变得非常小，这也可以通过浮点运算正确处理。

 ## 边缘情况

 对于零级，算法跳过所有递归贡献并返回初始平方。 有输入：```
0
5
```计算出的周长是`4 * 5 = 20`面积是`5 * 5 = 25`。 

对于第一级，算法仅应用一个周长增量和一个面积项。 和：```
1
3
```周长公式给出`12 + 8 = 20`。 面积公式给出`9 + 4 = 13`，匹配四个添加的单位方块。 

对于非常大的级别，该算法从不尝试创建单独的方块。 和：```
500
1000000
```计算仅评估封闭公式。 价值`3^-500`在所需精度下实际上为零，因此该面积自然接近其极限，而不会溢出或过多计算。
