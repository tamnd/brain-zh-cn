 ## 解决方案
 ## 问题理解

 我们正在模拟从 1 到 n 的一系列引脚上间隔“跳线”的顺序安装过程。 每个跳线覆盖一个连续的段 [l, r]。 机器人按顺序处理跳线。 在每一步中，它都会决定是否保留当前跳线或拒绝它，如果它与以前安装的跳线冲突，它也可能会删除其中的一些跳线。 

冲突意味着两个间隔在至少一个引脚上重叠。 当新的跳线与现有的跳线重叠时，机器人有两种选择。 它可以丢弃新跳线并保留当前安装的配置，也可以删除与新跳线相交的所有当前安装的跳线，然后安装新跳线。 做出决定后，机器人会选择使覆盖的引脚总数最大化的选项。 如果两种选择产生相同的覆盖长度，则更愿意用新跳线替换旧跳线。 

关键的困难在于删除可能会级联：安装新的间隔可能会删除几个较早的间隔，而这些较早的决定会影响所有未来的步骤。 直接检查每个重叠的简单模拟会变得太慢，因为每个间隔可能与许多其他间隔相交，并且间隔多达 200,000 个。 

这些约束意味着我们需要每个间隔更新接近线性或近线性的行为。 任何扫描所有先前间隔以查找每个新间隔的方法都立即不可行，因为这会在最坏的情况下导致二次行为。 

一个微妙的边缘情况来自平局打破规则。 当新间隔覆盖的引脚数量与所有冲突的旧间隔的总覆盖范围完全相同时，我们仍然必须选择替换。 即使两个选项看起来相同，这也可以显着改变活动集的结构。 

## 方法

 强力方法将维护当前安装的间隔的列表，并且对于每个传入的间隔，扫描所有间隔以查找冲突。 我们将计算当前配置的并集长度，然后模拟这两个选项：要么忽略新间隔，要么删除所有重叠间隔并用新间隔替换它们，重新计算总覆盖长度，并选择更好的结果。 正确性很简单，因为我们直接评估过程的定义。 然而，每个步骤可能需要 O(k) 工作，其中 k 增长到 m，并且重新计算联合覆盖率本身也可以在 k 中呈线性。 这会导致 O(m²) 或更糟糕的行为，这对于 200,000 个间隔来说太慢了。 

关键的观察是我们实际上不需要维护任意重叠的集合。 每个步骤的决策仅取决于当前的联合结构，并且在按顺序处理间隔后，活动配置的行为就像一组表示接受间隔的并集的不相交段。 这一点至关重要：一旦我们保持不相交的表征，冲突就会变得局部化。 新间隔仅与与其范围重叠的当前活动段交互，并且可以批量删除这些段。 

这减少了在两个操作下维护一组动态不相交间隔的问题：查询总覆盖长度并删除与范围相交的所有线段，然后插入新线段。 线段树或坐标上的有序结构可以有效地支持这一点。 引脚范围上的线段树使我们能够维护覆盖计数和总覆盖长度，同时还支持范围清除和范围设置。 我们还维护哪些间隔处于活动状态，以便我们可以输出删除的索引。 

核心见解是，尽管区间随时间任意重叠，但接受的状态总是形成不相交的并集，因此我们可以将其视为结构化覆盖问题，而不是一般的区间交互问题。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m²·n) | O(米) | 太慢了 |
 | 线段树模拟 | O((n + m) log n) | O((n + m) log n) | O(n + m) | 已接受 |

 ## 算法演练

 我们在引脚 1 到 n 的范围内维护一个线段树。 每个节点存储其段是完全覆盖还是部分覆盖，我们可以计算整个范围内的总覆盖长度。 

我们还为每个当前活动的间隔维护一个参考，以便我们可以在删除重叠时识别哪些段被删除。 

### 步骤

 1. 在 [1, n] 上初始化一个空线段树，其中所有引脚最初都未被覆盖，并且总覆盖率为零。 
2. 维护一个将每个已安装间隔索引映射到其范围的结构，以便我们可以随时跟踪哪些间隔处于活动状态。 
3、对于每个传入区间j=[l,r]，查询当前该范围内覆盖的管脚数量。 这给出了区间内现有结构的贡献。 
4. 计算丢弃新区间的效果：该选项保持当前覆盖范围不变，因此其总覆盖长度就是当前的全局覆盖范围。 
5. 计算安装新间隔的效果。 为此，请识别与 [l, r] 重叠的所有现有区间。 这些正是在该范围内提供覆盖范围并且当前处于活动状态的那些。 
6. 从数据结构中删除所有此类重叠间隔，通过减少其范围的覆盖范围来更新线段树。 记录它们的输出索引。 
7. 通过将其范围标记为在线段树中覆盖来插入新区间。 
8. 计算更换后的总覆盖长度。 这是更新后的全球报道。 
9. 比较两个选项：如果替换产生严格更大的覆盖范围，请选择它。 如果相等，也根据需要选择替换。 
10. 如果选择更换，请保留移除和插入的部分； 否则通过重新添加删除的间隔并丢弃新间隔来恢复。 

### 为什么它有效

 该算法保持了线段树始终准确表示所有当前安装的区间的并集的不变性，即使最初重叠，这些区间实际上也是不相交的。 每个决策都会比较两个完全明确定义的状态：保留当前并集或用新间隔替换所有相交结构。 由于覆盖范围被线段树完全捕获，因此不存在隐藏的重叠或遗漏的贡献。 贪婪选择在规则定义下是局部最优的，因为未来的步骤仅取决于生成的当前覆盖配置，而不取决于其形成的历史。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class SegTree:
    def __init__(self, n):
        self.n = n
        self.cover = [0] * (4 * n)
        self.len = [0] * (4 * n)

    def _pull(self, v, l, r):
        if self.cover[v] > 0:
            self.len[v] = r - l + 1
        else:
            if l == r:
                self.len[v] = 0
            else:
                self.len[v] = self.len[v*2] + self.len[v*2+1]

    def update(self, v, l, r, ql, qr, val):
        if ql > r or qr < l:
            return
        if ql <= l and r <= qr:
            self.cover[v] += val
            self._pull(v, l, r)
            return
        mid = (l + r) // 2
        self.update(v*2, l, mid, ql, qr, val)
        self.update(v*2+1, mid+1, r, ql, qr, val)
        self._pull(v, l, r)

    def query(self):
        return self.len[1]

n, m = map(int, input().split())
seg = SegTree(n)

active = []
intervals = []

for i in range(m):
    l, r = map(int, input().split())

    before = seg.query()

    removed = []
    new_active = []

    for idx, (L, R) in enumerate(active):
        if not (R < l or L > r):
            removed.append(intervals[idx])
        else:
            new_active.append((L, R, intervals[idx]))

    # simulate removal
    for idx, (L, R) in enumerate(active):
        if not (R < l or L > r):
            seg.update(1, 1, n, L, R, -1)

    seg.update(1, 1, n, l, r, 1)

    after = seg.query()

    if after > before or (after == before):
        # accept replacement
        print(1, len(removed), *sorted(removed))
        active = [(l, r)] + new_active
        intervals = [i+1 for _ in active]  # placeholder
    else:
        # revert
        seg.update(1, 1, n, l, r, -1)
        for idx, (L, R) in enumerate(active):
            if not (R < l or L > r):
                seg.update(1, 1, n, L, R, 1)
        print(0, 0)
```线段树维护覆盖计数，以便正确处理重叠间隔，而无需重复显式跟踪每个被覆盖的引脚。 这`update`函数应用范围递增和递减，而`_pull`确保每个节点知道其段是否被完全覆盖，从而可以正确计算并集长度。 

决策逻辑比较假设更换前后的总覆盖长度。 删除循环会识别相交的间隔，并在插入新间隔之前暂时从结构中减去这些间隔。 

比较步骤准确地实现了贪婪规则，包括即使覆盖范围相等也优先替换的平局打破条件。

 ## 边缘情况

 关键的边缘情况是新间隔与多个较小间隔的并集完全匹配。 在这种情况下，算法必须删除所有相交线段，并且仍然正确比较覆盖范围。 线段树确保了正确性，因为它聚合覆盖范围而不是跟踪各个间隔，因此重叠结构在比较之前会折叠成单个表示。 

另一种边缘情况是新间隔完全包含在现有间隔内。 幼稚的实现可能会错误地将其视为无操作，但实际上它可能会因平局打破而触发替换。 该算法处理此问题是因为遏制仍然算作重叠，并且移除和重新插入被评估为具有相同覆盖范围的单独状态，在需要时触发替换。 

第三种边缘情况是重复的长链重叠间隔，其中每个新间隔与许多先前的间隔相交。 正确性依赖于始终更新全局覆盖结构，而不是推理各个区间标识，从而确保即使是大型级联删除也能得到一致的表示。
