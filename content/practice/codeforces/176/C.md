 ## 解决方案
 ## 问题理解

 我们有两个芯片$n \times m$网格。 在每一回合中，第一个玩家在四相邻网格中将一个未粘合的筹码恰好移动一格。 之后，第二位玩家永久粘贴当前空的方块。 

允许芯片移动到粘合的正方形上。 一旦这样做，该芯片就会永久卡住。 当两个筹码占据同一格子时，第一个玩家立即获胜。 如果两个筹码在相遇之前都无法移动，则第二个玩家获胜。 

电路板尺寸可以大到$100 \times 100$，但事实证明这是一种误导。 获胜条件仅取决于两个芯片的相对位移，而不取决于单元格总数。 整个游戏的状态空间是巨大的，因为粘合位置会随着时间的推移而累积，因此任何对整个游戏树进行建模的尝试都是没有希望的。 

简单的实现可能会尝试表示所有粘合单元并运行极小极大搜索。 即使在一个$10 \times 10$板上已经有$100$第一次移动时可能的粘合位置，然后$99$关于下一步行动，等等。 分支因子立即爆炸。 

棘手的部分是电路板尺寸本身大多无关紧要。 两个距离很远的筹码给了第二个玩家足够的时间来建立障碍并迫使两个筹码都被困住。 两个靠近的芯片通常可以在胶水发挥决定性作用之前相遇。 

一个容易犯的错误是只看曼哈顿距离。 例如：```
10 10 1 1 5 5
```这里的位移是$(4,4)$。 曼哈顿距离仅为$8$，但正确答案是`Second`。 仅基于距离的策略会错误地预测第一个玩家的胜利。 

另一个微妙的情况是：```
10 10 1 1 4 5
```位移为$(3,4)$。 对于第一个玩家来说，这也是一个失败的配置，即使许多附近的位置都获胜。 

最后一个陷阱是假设a中的每个位置$5 \times 5$邻里正在获胜。 成对的$(3,4)$和$(4,4)$是特殊的例外。 

## 方法

 蛮力的想法很简单。 代表整个棋盘，跟踪哪些单元被粘合，为第一个玩家生成每个合法的移动，为第二个玩家生成每个粘合位置，然后运行极小极大。 

这是正确的，因为它探索了完整的博弈树。 问题是可达到的职位数量呈天文数字增长。 仅仅经过几圈之后，就已经有数百万种不同的胶水配置。 任何基于搜索的解决方案都无法在这种限制下生存。 

关键的观察是最佳发挥仅取决于两个筹码的相对位置。 分析游戏后，人们会发现一组非常小的失败配置。 

让$$dx = |x_1 - x_2|,\qquad dy = |y_1 - y_2|$$并重新排序它们，以便$dx \le dy$。 

完整的解决方案是：

 如果$dy > 4$，第二个玩家获胜。 

如果$(dx,dy) = (4,4)$，第二个玩家获胜。 

如果$(dx,dy) = (3,4)$，第二个玩家获胜。 

其他所有位置都是第一个玩家获胜。 这种表征是问题的预期解决方案。 

一旦知道了这种模式，游戏就会减少到一些整数比较。

 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取电路板尺寸和两个芯片的坐标。 
2. 计算绝对坐标差：$$dx = |x_1 - x_2|$$

$$dy = |y_1 - y_2|$$只有相对位移很重要。 
3. 对值重新排序，以便$dx \le dy$。 

这让我们能够以相同的方式对待对称位置。 
4.如果$dy > 4$， 输出`"Second"`。 

对于第一个玩家来说，在一个方向上相隔四个以上单元格的位置将会失败。 
5.如果$(dx,dy) = (4,4)$， 输出`"Second"`。 
6. 如果$(dx,dy) = (3,4)$， 输出`"Second"`。 
7. 在剩下的每种情况下，输出`"First"`。 

### 为什么它有效

 游戏按照筹码之间的相对位移进行了完整的分类。 归一化后，使得$dx \le dy$, 之外的每个位置$5 \times 5$第一个玩家的邻居会失败，因为第二个玩家总是可以在筹码相遇之前创建足够的粘合单元。 在该社区内，详尽的游戏分析只留下两种失败的配置，$(3,4)$和$(4,4)$。 所有其他标准化位移都承认第一个玩家的强制策略。 

因为该算法准确地实现了这种特征，所以它的答案对于每个合法输入都是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x1, y1, x2, y2 = map(int, input().split())

    dx = abs(x1 - x2)
    dy = abs(y1 - y2)

    if dx > dy:
        dx, dy = dy, dx

    if dy > 4:
        print("Second")
    elif (dx, dy) == (4, 4):
        print("Second")
    elif (dx, dy) == (3, 4):
        print("Second")
    else:
        print("First")

if __name__ == "__main__":
    solve()
```第一部分计算芯片之间的相对位移。 在此步骤之后，实际坐标甚至板尺寸都不再重要。 

互换保证了等价头寸，例如$(1,4)$和$(4,1)$由同一对表示。 忘记这种标准化将会对对称位置进行错误分类。 

其余逻辑直接实现获胜位置表征。 检查的顺序并不重要，重要的是测试`dy > 4`首先让结构稍微清晰一些。 

不存在溢出问题，因为每个值最多$100$。

import io

def solve():
    n, m, x1, y1, x2, y2 = map(int, input().split())

    dy = abs(y1 - y2)

    if dx > dy:
        dx, dy = dy, dx

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

 ## 边缘情况

 考虑：```
10 10 1 1 5 5
```我们得到$dx = 4$,$dy = 4$。 算法达到显式$(4,4)$检查并输出`Second`。 仅基于“所有最多有四个差异的位置都获胜”规则的解决方案在这里将失败。 

现在考虑：```
10 10 1 1 4 5
```标准化位移为$(3,4)$。 这是另一种特殊的失败状态。 专用检查正确返回`Second`。 

最后：```
100 100 1 1 1 6
```标准化位移为$(0,5)$。 自从$dy > 4$，算法立即输出`Second`。 这证实了大距离规则优先于所有较小的局部模式。 答案是在不考虑实际电路板尺寸的情况下确定的。
