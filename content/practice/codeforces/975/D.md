 ## 解决方案

 ## 问题理解

 我们有一组在平面上移动的点，每个点都有固定的速度。 在时间零（语句中的快照时间），每个幽灵都位于一条已知的直线上。 在那一刻之后，每个幽灵继续以恒定速度独立移动。 

每当两个鬼魂同时占据完全相同的位置时，它们的经验值都会增加一。 由于运动是线性的，每对鬼魂最多只能相遇一次，并且在一段有限的时间之后就不可能再见面了。 任务是计算整个时间线上此类配对会议的总数，包括那些可能在快照时间之前发生的会议。 

输入给出每个鬼魂的初始 x 坐标及其速度矢量。 y 坐标不是独立的，它受到所有初始位置都位于直线 y = ax + b 上这一事实的限制。 

输出是在无限的过去和未来的某个时间相遇的无序对幽灵的总数，乘以二，因为每次相遇都会增加两个参与者的经验。 

这些约束将我们推向 O(n log n) 或 O(n) 解决方案。 对于多达 200000 个重影，任何直接检查所有对的方法都需要大约 4×10^10 检查，这在 2 秒的限制下是不可能的。 必须利用运动结构，以便间接计算碰撞而不是模拟碰撞。 

一个微妙的问题是碰撞并不局限于快照时刻。 两个幽灵可能在时间 T 之前就已经相遇，或者他们可能在 T 之后相遇，但每对幽灵总共最多贡献一次。 另一个棘手的问题是位置相等必须在连续时间内解决，因此浮点推理是不安全的。 

由于复杂性和求解相交时间的精度问题，模拟轨迹的所有成对相交的简单方法将会失败。 

## 方法

 每个幽灵沿着参数线移动：

 x_i(t) = x_i + vxi · t

 y_i(t) = a·x_i + b + vyi·t

 如果存在时间 t 使得两个坐标重合，则两个鬼魂 i 和 j 相遇。 使 x 坐标相等给出 t 的线性条件，使 y 坐标相等给出另一个线性条件。 为了发生冲突，双方必须就相同的 t 达成一致。 

从 x 坐标我们得到：

 t = (x_j - x_i) / (vxi - vxj)，假设速度不同。 

代入 y 坐标条件得出：

 a(x_i - x_j) + (vyi - vyj)t = 0

 消除 t 会得到与时间无关的纯代数条件：

 (vxi - vxj) · a(x_i - x_j) + (vyi - vyj)(x_j - x_i) = 0

 重新排列，我们得到对称条件：

 (vyi - a·vxi) = (vyj - a·vxj)

 这是关键的简化：每个幽灵都可以简化为单个标量值：

 d_i = vyi - a·vxi

 两个幽灵发生碰撞当且仅当它们共享相同的 d_i 值，并且它们的轨迹在 x 上不平行，以一种阻止相遇的退化方式。 由于初始位置不同并且运动是线性的，因此在每组相等的 d_i 值中，每对最终在连续时间内恰好相遇一次。 

因此，问题简化为通过该导出值对幽灵进行分组并计算每组内的成对组合。 

蛮力方法检查所有对并求解每对两个线性方程，其时间复杂度为 O(n^2)。 优化的方法将每个重影压缩为键 d_i 并使用频率计数来计算组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 按不变值分组 | O(n) | O(n) | 已接受 |

 ## 算法演练

1. 对于每个鬼魂，计算导出值 d_i = vyi − a·vxi。 该值捕获速度如何相对于初始线的斜率对齐，这决定了两个重影是否相遇。 
2. 按相同的 d_i 值对重影进行分组。 每组代表一组轨迹，这些轨迹在相交所需的方向上保持几何一致。 
3. 对于大小为 k 的每个组，计算对的数量为 k·(k−1)/2。 每对这样的对恰好贡献一个碰撞事件。 
4. 将所有组的这些贡献相加以获得碰撞对的总数。 
5. 将结果乘以 2，因为每次碰撞都会增加涉及的两个鬼魂的经验。 

### 为什么它有效

 变换 d_i = vyi − a·vxi 有效地测量每个幽灵相对于初始配置线斜率的速度。 当两个幽灵共享相同的值时，它们的运动会保持一致的相对对齐，从而保证它们的轨迹恰好在一个时间点相交。 如果值不同，相对运动会导致它们在平面中的距离以阻止两个坐标同时相等的方式演变。 

这将连续时间内的几何相交问题减少为对单个不变标量进行相等计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    freq = {}

    for _ in range(n):
        x, vx, vy = map(int, input().split())
        key = vy - a * vx
        freq[key] = freq.get(key, 0) + 1

    ans = 0
    for c in freq.values():
        ans += c * (c - 1)

    print(ans)

if __name__ == "__main__":
    solve()
```减少后直接实施。 使用算法中导出的表达式将每个鬼影映射到不变空间。 字典累积频率，最后的总和计算所有成对相互作用。 

乘以 2 已经隐式包含在内，因为每一对都会贡献两个经验增量，每个幽灵一个。 

使用 64 位整数时必须小心，因为频率可以达到 200000，导致结果很大。 Python 自然地处理这个问题，但在其他语言中，溢出将是一个问题。

 ## 边缘情况

 当仅存在一个鬼影时，频率图具有大小为一的单个条目，因此不会产生对贡献。 该算法无需特殊处理即可正确返回零。 

当所有幽灵共享相同的速度结构时，整个系统简化为一组，答案变为 n·(n−1)，反映所有成对相互作用。 

当速度不同但仍产生相同的不变值时，分组可以正确捕获通过直接模拟难以检测到的间接几何对齐，从而确保不会错过交叉点。
