 ## 解决方案
 ## 问题理解

 输入中的每个单词都旨在描述一个对象，但该语言有一个规范化规则：如果两个单词包含完全相同的一组不同字母，则表示同一个对象，忽略每个字母出现的次数并忽略顺序。 

因此，我们不是将单词视为字符串，而是真正按其独特的字符集对它们进行分组。 例如，“a”、“aa”和“aaaa”都简化为相同的表示形式，因为它们都只包含字母“a”。 类似地，“ab”、“baba”和“aabb”都简化为同一个对象，因为它们不同的字母是`{a, b}`。 

任务是计算所有给定单词中出现了多少个不同的此类字母集。 

约束足够小，我们可以独立处理每个单词并直接构建其字母集的表示。 最多有 1000 个单词，每个单词的长度最多为 1000，因此直接扫描所有字符最多会产生 10^6 个字符操作，这在 Python 中相当快。 

如果我们尝试使用原始单词作为关键字，就会出现一个微妙的问题。 像“ab”和“baab”这样的两个单词是不同的字符串，但代表同一个对象，因此直接处理字符串会过度计数。 另一个潜在的错误是将排列视为不同的排列。 例如，“abc”、“cba”和“bca”在规则下都是相同的对象。 

主要的边缘情况是字母大量重复。 像“aaaaaaa”这样的单词必须折叠为单个代表，如果错过了这个标准化步骤，答案将会被夸大。 

## 方法

 强力解释会将每个单词与其他单词进行比较，检查它们是否定义相同的对象。 为了进行这种比较，我们将计算每对的字符集并进行比较。 如果有 n 个单词，则每次比较的成本高达 O(26) 或 O(length)，并且对所有对执行此操作会导致 O(n²·k)，这是不必要的，但在小限制下仍然可以接受。 

关键的观察是对象的相等性是“字符集”下的相等性。 这建议为每个单词构建一个规范形式并将其插入到哈希集中。 可以通过收集所有不同的字母并将它们编码为排序的字符串或位掩码来构建规范形式。 由于小写英文字母的大小是固定的（26），因此很容易构建紧凑且无冲突的表示。 

这将问题简化为计算每个单词一个签名并计算存在多少个唯一签名。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对比较 | O(n²·k) | O(n·k) | O(n·k) | 一般形式太慢|
 | 规范集+哈希| O(n·k) | O(n·k) | O(n) | 已接受 |

 ## 算法演练

 1. 读取输入中的所有单词。 每个单词将被独立处理，因为对象身份仅取决于其自身的字符。 
2. 对于每个单词，构造其包含的字符集的表示。 一个简单可靠的方法是标记单词中出现的 26 个小写字母中的哪一个。 此步骤将单词压缩为忽略频率和顺序的结构。 
3. 将此结构转换为可散列形式。 一种实用的方法是通过连接按字母顺序出现的所有字母来构建字符串。 这确保具有相同集合的任何两个单词产生完全相同的字符串。 
4. 将此规范表示插入到集合中。 该集合会自动删除重复项，因此重复出现的同一对象会自然地合并。 
5. 处理完所有单词后，输出集合的大小，它对应于不同对象的数量。 

### 为什么它有效

 核心不变量是每个单词都映射到仅由其字符集决定的唯一规范形式。 当且仅当两个单词包含完全相同的字母时，它们才会映射到相同的规范形式。 由于该集合仅存储规范形式，因此它将所有等效单词分组在一起，并对每个等价类仅计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    words = input().split()

    seen = set()

    for w in words:
        mask = [0] * 26
        for ch in w:
            mask[ord(ch) - 97] = 1

        key = []
        for i in range(26):
            if mask[i]:
                key.append(chr(i + 97))

        seen.add("".join(key))

    print(len(seen))

if __name__ == "__main__":
    solve()
```该解决方案一次性读取所有单词，然后将每个单词转换为 26 长度的存在数组。 这避免了对字长或字符频率的任何依赖。 按字母顺序重建步骤可确保“ab”和“ba”等排列折叠为相同的键。 

一个常见的实现陷阱是忘记对单词进行规范化并将原始字符串插入到集合中。 这会错误地将字谜视为独特的。 另一个错误是直接在集合中使用列表，这在 Python 中是无效的，因为列表不可散列。

 ## 边缘情况

 一个重要的边缘情况是单词内的极端重复。 对于像“aaaaa”这样的输入，算法仅在掩码中标记一个字母，因此规范密钥变为“a”。 这确保重复的字符不会使表示膨胀。 

另一个边缘情况是许多字谜。 例如，“abc”、“bca”和“cab”都产生相同的掩码，因此产生相同的密钥。 该集合正确地将它们折叠成一个条目，因为每个排列都映射到相同的排序字母表示。 

最后一种边缘情况是所有单词结构相同但长度不同，例如“a”、“aa”、“aaa”、“aaaa”。 每个都产生相同的规范键“a”，因此集合中只剩下一个条目，产生正确的计数 1。
