 ## 解决方案
 ## 问题理解

 我们有一个有 14 个位置的圆形板。 每个位置都包含一定数量的棋子。 一步棋是选择一个有棋子的位置，将其中的所有棋子移走，然后将这些棋子一颗一颗地分布到随后的位置上，沿着圆圈顺时针移动。 

重新分配后，我们查看所有 14 个位置，并从最终计数为偶数的每个位置收集棋子。 目标是选择移动的起始位置，以使收集到的金额最大化。 

重要的是，只进行一步操作，唯一的决定是拾取并重新分配哪一堆。 

限制非常小：正好 14 个位置。 尽管每个位置可能包含最多 10^9 颗棋子，但结构是固定且微小的。 这立即表明我们有能力模拟每一个可能的起始位置。 任何试图做比线性扫描更复杂的事情的解决方案都是不必要的。 

一个微妙的点是，重新分配是确定性的，并且由初始数组和所选索引完全描述。 移动过程中没有交互或分支。 

一个幼稚的错误是在重新分配后通过“跳跃”计数错误地重新计算整个板，而不是正确模拟环绕。 例如，忘记棋子从位置 14 回绕到位置 1 会导致不正确的最终状态。 

另一个潜在的陷阱是假设我们只需要检查所选索引附近的局部效应。 事实上，每个位置在 14 步的完整循环中最多只能获得一颗额外的石头，因此即使是距离较远的位置也会受到影响。 

边缘情况包括：

 当所有石头都堆成一堆时，比如说`[0, 0, 0, ..., 7, 0, 0]`，分布会环绕多次，并且每个位置都可以多次更改奇偶校验。 

当仅存在一个非零堆时，结果完全取决于我们从哪里开始，因为这决定了整个周期的奇偶校验翻转模式。 

## 方法

 蛮力的想法很简单：对于从 1 到 14 的每个索引 i，模拟从该堆中取出所有石头并将它们一一分布在圆形阵列中。 模拟后，计算所有偶数桩的总和。 我们在所有选择中采取最大化。 

这是正确的，因为问题明确地将我们限制为一步，而每步完全由其起始位置决定。 

这种模拟的成本很重要。 对于包含 a[i] 个石头的一堆，我们执行 O(a[i]) 更新。 由于 a[i] 最大可达 10^9，因此这种简单的模拟在最坏的情况下速度太慢。 

关键的观察结果是，尽管 a[i] 很大，但电路板尺寸是恒定的。 每完整旋转 14 步后，每个位置都会从移动的堆中额外接收一颗石子。 因此，最终的效果仅取决于我们完成了多少个完整周期以及剩余的部分步骤。 

我们不需要单独模拟每块石头。 相反，我们计算每个位置被访问的次数并使用算术更新计数。 由于棋盘大小是固定的，对于每个起始索引，我们可以在 O(14) 中计算结果配置。 

因此，我们将潜在的巨大每次移动成本减少到每个起始位置的恒定时间模拟中。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每块石头的暴力模拟| O(14 * a[i]) | O(14 * a[i]) | O(14) | 太慢了 |
 | 每次启动时基于周期的模拟 | O(14 * 14) | O(14) | 已接受 |

 ## 算法演练

 1. 迭代从 0 到 13 的每个可能的起始位置 i。这是我们选择清空的堆。 
2. 对于每个起始位置，将初始数组复制到工作数组中。 我们需要独立的模拟，因为每个选择都是单独评估的。 
3. 将位置 i 的所有棋子提取到变量 k 中，并将该位置设置为零。 
4. 从位置 i 开始，将 k 个石子一颗一颗地绕圆圈分布。 

不要迭代 k 次，而是计算发生了多少个 14 个步骤的完整循环以及还剩下多少个额外步骤。 

每个位置恰好接收到楼层（k / 14）个石头，以及在我收到一个额外的石头后的第一个（k mod 14）位置。 
5. 将这些计算出的增量应用于复制的数组。 
6. 分配完毕后，扫描所有 14 个位置，并对偶数的值求和。 
7. 跟踪所有起始位置的最大总和。 

关键思想是用跨固定长度周期的直接算术分布来取代每石模拟。 

### 为什么它有效

 每个石子在长度为 14 的固定循环中确定性地移动到下一个位置。在 14 步之后，石子返回到其原始索引，偏移了完整的循环。 这意味着除了由余数确定的小前缀之外，循环中的每个位置都会被统一访问。 对每个单元的最终贡献仅取决于旋转经过它的次数，这完全由 k 模 14 和 k 除以 14 确定。这保证了重建的板与完全模拟相同，同时避免了逐步迭代。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = list(map(int, input().split()))
    n = 14
    ans = 0

    for i in range(n):
        b = a[:]  # copy board
        k = b[i]
        if k == 0:
            pass
        b[i] = 0

        full = k // n
        rem = k % n

        # distribute full cycles
        for j in range(n):
            b[j] += full

        # distribute remainder
        for t in range(1, rem + 1):
            b[(i + t) % n] += 1

        # compute score
        cur = 0
        for x in b:
            if x % 2 == 0:
                cur += x

        ans = max(ans, cur)

    print(ans)

if __name__ == "__main__":
    solve()
```实现直接遵循循环分解。 完整周期对所有 14 个位置的贡献一致，这就是为什么我们简单地添加`full`到每一个细胞。 剩下的人将一颗额外的石头分配给下一个`rem`使用模块化索引在所选索引之后的位置。 

处理索引时需要小心：重新分配从下一个单元格开始`(i + 1) % 14`，而不是所选单元格本身。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a = list(map(int, sys.stdin.readline().split()))
    n = 14
    ans = 0

    for i in range(n):
        b = a[:]
        k = b[i]
        b[i] = 0

        rem = k % n

            b[j] += full

        for t in range(1, rem + 1):
            b[(i + t) % n] += 1

        cur = sum(x for x in b if x % 2 == 0)
        ans = max(ans, cur)

    return str(ans)
