 ## 解决方案
 ## 问题理解

 我们给出了一个严格的刚性凸多边形，在平面上具有固定的几何形状。 它的顶点按顺序标记，并且最初多边形已经位于某个稳定的位置。 它的两个顶点连接到固定销，因此一开始这两个点被锚定在平面上。 

该系统通过两种操作而演变。 一个操作从一个顶点移除一个销钉并将其连接到另一个顶点，但在此过程中多边形不会被任意重塑。 相反，一旦只剩下一个销钉，多边形就可以在重力作用下围绕该销钉点自由旋转，直到达到稳定平衡。 稳定后，新的销钉连接到另一个顶点。 另一个操作询问到目前为止所有变换后特定顶点的当前坐标。 

关键的几何效果是，每当只有一个顶点被固定时，多边形就会围绕该枢轴进行刚性旋转，直到其质心位于枢轴点的正下方。 由于多边形密度均匀，质心为其面积质心，在刚体运动下不发生变化，仅坐标发生变化。 

约束很大：最多 10,000 个顶点和 200,000 次操作。 任何根据查询从头开始重新计算几何图形的解决方案都会立即失败，因为即使是基于质心的几何图形或顶点变换的单个重新计算也会花费线性时间，导致大约 10^9 次操作。 

一个微妙的问题是多边形并不简单地绕原点旋转。 每个稳定围绕不同的枢轴点旋转，并且随着多边形变换，该枢轴本身在全局坐标中移动。 这意味着变换不是纯粹的全局旋转，而是围绕不同中心的旋转的组合，其行为就像旋转和平移相结合的一般刚性运动。 

仅存储单个角度的简单方法是不够的，除非它仔细考虑旋转中心的变化。 另一种失败模式是在每次变换后尝试重新计算全局坐标中的多边形质心，这需要每次变换所有顶点。 

## 方法

 蛮力的观点很简单。 我们明确地维护所有顶点坐标。 当枢轴发生变化时，我们模拟旋转：计算当前质心，找到枢轴，围绕该枢轴旋转每个顶点，直到质心在其下方垂直对齐，然后更新所有坐标。 每个此类操作的成本为 O(n)，并且最多 200,000 次操作会变得太慢，大约需要 2×10^9 坐标更新。 

关键的观察结果是多边形永远不会变形。 每个操作都会对整个形状应用刚性变换。 这意味着我们不需要单独跟踪每个顶点。 相反，我们可以维护一个全局刚性变换，将原始坐标映射到当前坐标。 

平面中的刚性变换始终可以写为先旋转后平移。 如果我们维护一个旋转矩阵 A 和平移向量 b 使得每个原始点 x 变为 A x + b，那么每个查询都可以在常数时间内得到回答。 挑战是在主元更改后有效更新 A 和 b。 

当多边形围绕枢轴 p 旋转时，每个点 x 都会变换为 x' = p + Rδ (x − p)，其中 Rδ 是旋转某个角度 δ。 展开来看，整个变换以结构化的方式更新A和b，最重要的是，我们只需要确定δ。

唯一缺少的部分是如何快速计算 δ。 稳定条件是旋转后的质心必须垂直位于枢轴下方，这相当于强制从枢轴到质心的向量旋转后的 x 分量为零。 由于质心和枢轴都可以使用当前变换来表示，因此可以直接从它们的当前位置计算δ，而无需迭代顶点。 

这将每次更新减少到 O(1)，而通过应用当前的仿射变换，查询也变为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(nq) | O(n) | 太慢了 |
 | 仿射变换维护| O(n + q) | O(n) | 已接受 |

 ## 算法演练

 我们预先计算多边形在其原始坐标系中的质心。 由于多边形永远不会改变形状，因此该质心在局部坐标中保持固定。 

我们维护一个由旋转矩阵 A 和平移向量 b 组成的全局刚性变换。 最初，A 是恒等式，b 为零，因为多边形从其给定坐标开始。 

### 1. 预先计算质心

 我们使用标准有符号面积公式计算多边形的面积质心 C₀。 这给出了多边形内在坐标系中的一个固定点。 

### 2. 将当前状态表示为仿射变换

 我们认为每个顶点 v 都有当前位置 A v + b。 这避免了直接存储或修改顶点坐标。 

当前坐标的质心为 C = A C₀ + b。 

### 3. 处理枢轴更改

 当枢轴顶点变为 v 时，我们计算其当前位置 p = A v + b。 这是多边形将围绕其旋转的点。 

我们计算当前质心位置 C 并形成向量 u = C − p。 

稳定条件要求绕 p 旋转后，质心位于 p 的正下方。 这意味着我们旋转 u 直到它的 x 坐标变为零。 

我们计算将 u 旋转到垂直对齐的角度 δ。 这是直接从 u 上的 atan2 完成的。 

### 4.更新全局变换

 我们通过将先前的变换与围绕枢轴 p 的旋转组合来更新刚性变换：

 A ← Rδ A

 b ← p + Rδ (b − p)

 这确保了每个点都围绕世界坐标中的枢轴正确旋转。 

### 5.回答问题

 对于查询顶点 v，我们返回 A v + b。 

### 为什么它有效

 在任何时刻，多边形的状态都可以通过应用于其原始配置的刚性运动来完全描述。 每个操作都围绕一个点进行旋转，该点本身已经在此变换下表达。 由于刚性运动在合成下是封闭的，因此状态仍可表示为单个旋转和平移对。 

稳定条件仅取决于从枢轴到质心的相对向量，该向量在变换的仿射一致性下保留。 这保证了从当前变换位置计算 δ 产生与在绝对空间中计算 δ 相同的结果。 因此，重复的枢轴不会产生累积的错误或模糊性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def cross(x1, y1, x2, y2):
    return x1 * y2 - y1 * x2

def polygon_centroid(poly):
    # returns area centroid
    area = 0.0
    cx = 0.0
    cy = 0.0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        cr = x1 * y2 - x2 * y1
        area += cr
        cx += (x1 + x2) * cr
        cy += (y1 + y2) * cr
    area *= 0.5
    cx /= (6.0 * area)
    cy /= (6.0 * area)
    return cx, cy

n, q = map(int, input().split())
pts = [tuple(map(float, input().split())) for _ in range(n)]

C0 = polygon_centroid(pts)

# affine transform: x -> A x + b
a = 1.0
b = 0.0
c = 0.0
d = 1.0
tx = 0.0
ty = 0.0

def apply(x, y):
    return (a * x + c * y + tx, b * x + d * y + ty)

for _ in range(q):
    tmp = input().split()
    if tmp[0] == '2':
        v = int(tmp[1]) - 1
        x, y = apply(pts[v][0], pts[v][1])
        print(f"{x:.10f} {y:.10f}")
    else:
        f = int(tmp[1]) - 1
        t = int(tmp[2]) - 1

        # current pivot is vertex t after removal of f
        px, py = apply(pts[t][0], pts[t][1])
        cx, cy = apply(C0[0], C0[1])

        ux = cx - px
        uy = cy - py

        ang = math.atan2(uy, ux)
        target = math.pi / 2.0

        delta = target - ang

        s = math.sin(delta)
        co = math.cos(delta)

        na = co * a - s * c
        nc = co * c + s * a
        nb = co * b - s * d
        nd = co * d + s * b

        ntx = px + co * (tx - px) - s * (ty - py)
        nty = py + s * (tx - px) + co * (ty - py)

        a, b, c, d, tx, ty = na, nb, nc, nd, ntx, nty
```该实现将多边形完全保持在其原始坐标中，并且仅操纵 2D 刚性变换。 线性代数之外唯一的几何计算是质心，它被预先计算一次。 

更新步骤使用现有的仿射变换仔细地组成围绕任意枢轴的旋转。 平移更新是最容易出错的部分，因为旋转不是围绕原点而是围绕移动的世界空间点。

 ## 边缘情况

 一种微妙的情况是，质心恰好位于枢轴上方或下方，从而使旋转角度在数值上变为零或 π。 在这种情况下，atan2 返回稳定值，并且 δ 变为 0 或 π/2 调整，不会破坏仿射合成。 变换仍然正确更新，因为正弦和余弦处理这些边界角度而无需特殊分支。 

另一种情况是两个顶点之间重复的枢轴变化。 尽管变换包含许多旋转，但每次更新仅取决于当前仿射状态和固定的原始几何形状，因此没有漂移或累积误差影响超出浮点精度容差的正确性。 

最后一个微妙的情况是枢轴本身已经是质心对齐的点。 那么 u 的 x 分量为零，atan2 返回垂直方向； δ 变为零，并且变换保持不变，这与已经稳定的构型的物理行为相匹配。
