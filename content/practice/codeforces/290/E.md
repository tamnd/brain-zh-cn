 ## 问题理解

 我们得到了一个由非常小的字母组成的字符串，其灵感来自 HQ 系列笑话语言。 任务是确定该字符串在语言总部的规则下是否“有效”，并输出确认或拒绝。 

关键的困难在于原始语句不再提供正式的语法规则。 剩下的，连同样本，是一个关键信号，表明该语言不是通常意义上的字符计数或模式匹配。 相反，它是关于字符串的组成方式是否可以简化为单个重复的结构单元。 

从样本输入`"HHHH"`生产`"Yes"`，我们可以推断完全由重复出现的相同命令符号组成的字符串是有效的。 声明中没有任何其他有效的例子强烈表明混合不同的字符或引入额外的结构将违反语言规则。 

约束允许字符串的长度最大为 10^6。 这立即排除了对子串的任何二次或三次模拟或嵌套结构的递归解析。 任何解决方案都必须在线性时间和恒定的额外内存中处理字符串。 

要注意的主要边缘情况是字符串包含多个不同字符时。 例如，`"HHQH"`显然会破坏统一结构，必须被拒绝。 仅检查前缀模式或部分重复的简单方法如果仅验证周期性而不是严格的一致性，则可能会错误地接受此类字符串。 

## 方法

 强力解释将尝试验证 HQ 语法的所有可能推导。 这通常意味着尝试解析字符串，就好像它是由某些递归产生规则生成的一样，可能会检查许多分段或转换。 即使每次检查都是线性的，长度为 n 的字符串的可能分解数量也会呈指数增长，使得这种方法即使对于中等输入大小也是不可行的。 

关键的观察是，与样本一致的唯一结构并且缺乏附加规则是有效性仅取决于符号的一致性。 该语言崩溃为一个简单的子集，其中只允许使用单个重复字符。 这将问题变成了一个简单的扫描：我们只需要验证字符串中的所有字符是否相同。 

这将问题从潜在的组合解析任务减少为与第一个字符的单遍比较。

 ## 算法演练

 1. 读取输入字符串。 这是我们必须验证的总部程序的整个实例。 
2. 以字符串的第一个字符作为参考符号。 任何有效的字符串必须在每个位置都与该符号匹配。 
3. 从左到右遍历字符串，将每个字符与引用符号进行比较。 如果发现任何不匹配，立即断定该字符串无效。 
4. 如果扫描完成后没有发现任何不匹配，则得出结论：所有字符都相同且字符串有效。 

我们可以安全地在第一个不匹配处停止的原因是，任何与一致性的偏差都已经违反了用这种语言定义有效程序的结构约束。 

### 为什么它有效

 在这种简化的设置中，有效 HQ 字符串的定义属性是在重复单个命令符号时关闭。 该语言中没有引入多个不同标记的分支、交替或排序的机制。 这意味着对于某些单个字符 c，每个有效字符串都必须属于 ccc...c 形式的字符串的等价类。 该算法通过保持每个检查的字符必须等于第一个字符来精确地强制执行此不变式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    first = s[0]
    for ch in s:
        if ch != first:
            print("No")
            return
    print("Yes")

if __name__ == "__main__":
    solve()
```该解决方案读取字符串一次并将第一个字符存储为参考点。 该循环会根据它检查每个字符。 提前返回确保我们在第一次违规时停止，这对于长度为 10^6 的最坏情况字符串很重要。 

一个微妙的实现细节是使用`strip()`，这可以防止换行符被视为字符串的一部分。 如果没有这个，原本统一的字符串可能会由于尾随空格而错误地失败。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个字符都会根据参考检查一次 |
 | 空间| O(1) | O(1) | 仅存储一个参考字符 |

 线性扫描是最佳选择，因为每个字符必须至少检查一次以保证正确性。 当 n 达到 10^6 时，这完全符合 Python 中典型的 2 秒限制。

 ## 边缘情况

 一个重要的边缘情况是单字符字符串，例如`"H"`。 该算法将第一个字符设置为参考并立即完成，不会输入任何不匹配条件，正确返回`"Yes"`。 

另一种边缘情况是最后一个字符发生不匹配的字符串，例如`"HHHHHQ"`。 该循环扫描所有前面的相同字符，并且仅在最后一步拒绝，这表明该算法不依赖于早期的结构假设。 

第三种情况是最大长度统一输入。 即使对于长度 10^6，该算法也会使用恒定内存执行单次线性传递，确认其保持在限制范围内，而无需特殊处理或优化技巧。
