 ## 解决方案
 ## 问题理解

 我们有一个网格，其中一些单元格被阻挡，而其余单元格可用。 每个可用的单元格必须涂成红色或蓝色。 

选择颜色后，我们想要放置尽可能多的多米诺骨牌。 仅当两个相邻的可用单元都是红色时，水平多米诺骨牌才可以覆盖它们。 仅当两个相邻的可用单元都是蓝色时，垂直多米诺骨牌才可以覆盖它们。 多米诺骨牌不能重叠。 

对于可用单元的每种可能的颜色，我们计算可以放置的多米诺骨牌的最大数量。 任务是将所有颜色的这些最大值相加并报告结果模数`998244353`。 

首先要注意的是，董事会可能包含最多`3·10^5`细胞。 自从`nm ≤ 3·10^5`，一个维度可能很大，而另一个维度很小，但单元格总数仍然有界。 

直接枚举颜色是不可能的。 即使只有 50 个白细胞的主板也已经具有`2^50`着色。 这里我们可能有最多`3·10^5`白细胞，因此完全排除了任何对个体颜色进行解释的方法。 

第二个限制更为微妙。 答案是所有颜色的总和，但求和的数量是最大的类似匹配值。 当我们颠倒求和顺序并计算有多少颜色对特定局部结构做出贡献时，这种形式的问题通常会变得容易处理。 

一些边缘情况很容易被错误处理。 

考虑长度为 1 的行段：```
o
```任何水平多米诺骨牌都不能放置在那里。 任何盲目假设每个白细胞都参与某对的公式都会多算。 

考虑长度为 2 的行段：```
oo
```有四种颜色：```
RR -> 1 domino
RB -> 0
BR -> 0
BB -> 0
```该部分的总贡献为 1。独立计算每个相邻对的朴素计数参数将获得错误的值，因为不同的多米诺骨牌放置会相互作用。 

另一个重要的情况是长连续段：```
ooooo
```用于着色```
RRRRR
```水平多米诺骨牌的最大数量是 2，而不是 4。相邻候选对重叠，因此我们无法独立计算有效对。 

整个解决方案围绕正确处理这些重叠展开。 

## 方法

 假设我们尝试暴力。 

对于所有白色单元格的每种颜色，我们确定水平红色多米诺骨牌和垂直蓝色多米诺骨牌的最大数量。 然后我们将这些值添加到答案中。 

这是正确的，因为它直接遵循该语句。 不幸的是有`2^w`着色，在哪里`w`是白细胞的数量。 和`w`达到`3·10^5`，这是一个天文数字。 

关键的观察结果是最大值分解为相邻白细胞对的独立贡献。 

首先关注水平多米诺骨牌。 

取长度为连续白细胞的最大水平段`L`。 对于固定着色，该段内水平多米诺骨牌的最大数量等于其顶点为单元且其可用边为相邻红-红对的路径上的最大匹配。 

我们不是对所有颜色的最大匹配求和，而是提出一个不同的问题：

 对于段内特定的相邻细胞对，这对细胞以多少种颜色参与贪婪匹配？ 

这个观点导致DP根据出现的匹配对的数量来计算颜色。 

显着的简化是每个最大白色段都可以独立处理。 水平多米诺骨牌仅取决于行段。 垂直多米诺骨牌仅取决于柱段。 

让`f[L]`表示一段长度所贡献的水平多米诺骨牌总数`L`覆盖该部分的所有颜色。 一次`f[L]`已知，每行段的长度`L`贡献```
f[L] * 2^(total_white - L)
```到全局答案，因为该段之外的单元格可以任意着色。 

完全相同的推理也适用于列段。 

剩下的任务就是计算`f[L]`。 

考虑段的最左边位置。 

如果前两个单元形成多米诺骨牌，它们必须都是红色的。 这会提供一对匹配并留下一段长度`L-2`。 

否则，第一个单元格不会在匹配对中使用，留下一段长度`L-1`。 

这会产生与官方解决方案相同的重现：

 让`dp[i]`= 长度所有颜色的总贡献-`i`部分。 

前两个单元格成为匹配的多米诺骨牌的着色恰好具有一个额外的多米诺骨牌加上剩余后缀中出现的任何内容。 

得到的递归结果是$$dp[i] = 2dp[i-1] + dp[i-2] + 2^{i-2}.$$最后一项计算颜色，其中前两个单元格都是红色并形成新创建的多米诺骨牌。 

预先计算这些值后，我们扫描所有行段和列段并累积它们的贡献。

 ## 算法演练

 1. 统计白细胞总数，称其为`w`。 
2. 预先计算两个模的幂`998244353`最多`w`。 
3. 预先计算DP数组。 

让`dp[i]`是单个白色长度段贡献的多米诺骨牌总数`i`跨越该部分的所有颜色。 

使用$$dp[i] = 2dp[i-1] + dp[i-2] + 2^{i-2}.$$和$$dp[0]=0,\quad dp[1]=0.$$4. 扫描每一行。 

找到每个最大连续长度的白细胞`len`。 

它对最终答案的贡献等于$$dp[len] \cdot 2^{w-len}.$$将此值添加到答案中。 
5. 扫描每一列。 

再次找到白细胞的每个最大连续运行。 

对于一个长度的运行`len`， 添加$$dp[len] \cdot 2^{w-len}.$$6.输出累加答案取模`998244353`。 

### 为什么它有效

 对于固定的行段，`dp[len]`已经等于该段所有颜色的最大水平多米诺骨牌计数之和。 该段外的每个细胞的颜色都是独立的，可以在`2^(w-len)`方式。 乘以该系数可将细分市场的贡献扩展到整个董事会。 

同样的论点也适用于列段。 

每个水平多米诺骨牌恰好属于一个最大行段，每个垂直多米诺骨牌恰好属于一个最大列段。 将所有行段和所有列段的贡献相加即可准确计算问题所需的数量。 

复发为`dp`按第一个位置的状态划分所有颜色。 如果前两个单元形成匹配的多米诺骨牌，我们将获得一个多米诺骨牌并在长度上递归`i-2`; 否则我们就长度递归`i-1`。 这些情况是详尽且不相交的，因此递归将每种颜色恰好计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n, m = map(int, input().split())
g = [input().strip() for _ in range(n)]

white = sum(row.count('o') for row in g)

pow2 = [1] * (white + 1)
for i in range(1, white + 1):
    pow2[i] = (pow2[i - 1] * 2) % MOD

dp = [0] * (max(2, white + 1))
for i in range(2, white + 1):
    dp[i] = (
        2 * dp[i - 1]
        + dp[i - 2]
        + pow2[i - 2]
    ) % MOD

ans = 0

for r in range(n):
    cnt = 0
    for c in range(m + 1):
        if c < m and g[r][c] == 'o':
            cnt += 1
        else:
            if cnt >= 2:
                ans = (ans + dp[cnt] * pow2[white - cnt]) % MOD
            cnt = 0

for c in range(m):
    cnt = 0
    for r in range(n + 1):
        if r < n and g[r][c] == 'o':
            cnt += 1
        else:
            if cnt >= 2:
                ans = (ans + dp[cnt] * pow2[white - cnt]) % MOD
            cnt = 0

print(ans % MOD)
```实现直接遵循数学分解。 

电源阵列存储`2^k`模数`MOD`对于每一个可能的`k`。 自从`white`至多是`3·10^5`，这个预计算是线性的。 

DP 复发评估一次最多`white`。 这是有效的，因为任何片段都不能长于白细胞总数。 

扫描行和列时，超出边界的哨兵迭代会自动刷新最终段。 这可以避免每次循环后出现特殊情况的代码。 

因素`pow2[white - cnt]`是最重要的细节。`dp[cnt]`只考虑当前段内的颜色。 所有剩余的白细胞可以独立着色，准确贡献`2^(white-cnt)`扩展。 

所有算术均以模进行`998244353`。

def solve():
    input = sys.stdin.readline

    MOD = 998244353

    n, m = map(int, input().split())

    white = sum(row.count('o') for row in g)

    pow2 = [1] * (white + 1)
    for i in range(1, white + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    dp = [0] * (max(2, white + 1))
    for i in range(2, white + 1):
        dp[i] = (
            2 * dp[i - 1]
            + dp[i - 2]
            + pow2[i - 2]
        ) % MOD

    ans = 0

    for r in range(n):
        cur = 0

                cur += 1
            else:
                if cur >= 2:
                    ans = (ans + dp[cur] * pow2[white - cur]) % MOD
                cur = 0

    for c in range(m):
        cur = 0
        for r in range(n + 1):
            if r < n and g[r][c] == 'o':

                    ans = (ans + dp[cur] * pow2[white - cur]) % MOD

    print(ans)

 ## 边缘情况

 考虑```
1 1
o
```有一个白细胞并且没有相邻的一对。 行扫描找到长度为 1 的段，这没有任何贡献，因为该算法仅处理至少为 2 的长度。列扫描的行为相同。 答案是0。 

考虑```
1 3
o*o
```存在两个白细胞，但它们属于不同的部分。 一个常见的错误是将它们视为一个长度为 2 的片段。 该算法重置阻塞单元处的段长度，产生两个长度为 1 的段并回答 0。 

考虑```
1 5
ooooo
```一种简单的方法可以独立地计算每个相邻对。 有四对相邻的多米诺骨牌，但在一次匹配中只能共存两块多米诺骨牌。 DP 递归已经编码了最大匹配行为，因此可以正确处理重叠对。 

考虑```
5 1
o
o
o
o
o
```只有垂直的多米诺骨牌才重要。 行扫描没有任何贡献，因为每个行段的长度都是 1。列扫描处理一个长度为 5 的段并生成整个答案。 这证实了水平和垂直贡献是对称处理的。
