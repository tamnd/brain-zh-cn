 ## 解决方案
 ## 问题理解

 我们得到一系列矩形积木，将它们逐一添加以构建更大的矩形底座。 第一天之后，我们从一个矩形开始。 接下来的每一天，一个新的矩形都会沿着整个边附加到当前形状，并且每次附加后，整个结构仍然必须形成一个矩形。 

每个新块在连接之前都可以旋转 90 度。 附加规则很严格：新块的一个完整边必须与当前矩形的一个完整边完全匹配，并且它们沿着该边粘合。 粘合后，结果仍然是一个矩形，这意味着附件有效地沿一个方向延伸前一个矩形，而不会产生任何突起或孔。 

我们被要求确定给定的块序列是否可以以某种有效的方式排列以满足这些约束。 如果可能的话，我们必须输出所有可能的最终矩形尺寸。 如果两个矩形仅交换宽度和高度不同，则认为它们是相同的。 

约束 n 高达 100000 意味着我们需要粗略线性或近线性处理。 任何尝试所有放置或保留大量几何配置的方法都会失败，因为如果在所有方向和侧面尝试每个附件，则朴素状态的数量会呈指数增长。 

幼稚推理的主要危险是假设一旦形成矩形，未来的附件就会独立运行。 实际上，每个附件都会限制所有先前选择的几何形状和方向。 

当方向选择复合时，就会出现微妙的失败案例：

 输入```
2
2 3
3 4
```天真的贪婪方法可能会附加 2×3，然后扩展 3×4，但根据第一个块是否被视为 2×3 还是 3×2，第二步可能适合也可能不适合。 如果我们不追踪这两种可能性，我们可能会错误地得出不可能性的结论。 

核心困难在于，在每一步中，矩形都可以以多个一致的方向进行解释，并且我们必须保留所有全局一致的解释。 

## 方法

 强力模拟会尝试各种方法来定向和连接每个矩形。 在步骤 i，每个当前矩形状态最多可以通过四种方式接收新块：选择块的方向并选择它是沿宽度还是高度附加。 这会为每个州创建最多四个分支因子。 即使我们合并相同的状态，不同状态的数量也会随着 n 快速增长，在最坏的情况下导致指数爆炸。 

关键的观察结果是，尽管有这种分支，但几何形状却受到极大的限制。 一旦我们修复了有效的矩形状态，每个附件都会被强制，即它根据哪条边匹配以确定的方式扩展宽度或高度。 这严重限制了分歧。 

更深层次的结构事实是，不同的有效矩形维度的数量永远不会超过两个。 直观上，歧义仅来自于跨步骤交换宽度和高度的解释。 一旦我们致力于一致的“轴解释”，所有未来的步骤都会确定性地传播。 唯一的选择是全局交换解释。 

这使我们能够维护一个非常小的候选矩形集，并逐步更新它们。 每个候选者最多产生恒定数量的下一个候选者，并且我们合并重复项。

 ## 算法演练

 我们维护一小组可能的矩形尺寸，它们可以在处理每个块前缀后表示当前状态。 

每个状态都是一对（W，H），其中顺序在全局上并不重要，因此我们在存储时对其进行归一化。 

### 步骤

 1. 使用第一个矩形初始化状态集。 我们考虑这两个方向，因为我们还不知道哪一侧对应于宽度或高度。 
2. 对于每个下一个矩形 (a, b)，生成其两个可能的方向：(a, b) 和 (b, a)。 这说明了旋转自由度。 
3. 对于每个当前状态（W、H），尝试以所有有效方式附加新矩形：

 如果新矩形的一侧等于 W，我们可以将其沿宽度方向附加，产生一个新状态 (W, H + other_side)。 

如果一侧等于 H，我们可以将其沿高度一侧附加，生成 (W + other_side, H)。 

关键的限制是只有当存在精确的边匹配时才可能连接。 
4. 从新矩形的当前状态和方向的所有组合中收集所有结果状态。 
5. 通过对每个状态的维度进行排序来标准化每个状态，以便使用 (min(W, H), max(W, H))。 这确保了等效的矩形被合并。 
6. 如果在任何步骤中没有保留有效状态，则构建是不可能的。 
7. 处理完所有矩形后，输出所有不同的剩余状态。 

关键的想法是，在每一步中，我们只保持几何上一致的矩形解释，并且我们绝不允许不兼容的部分历史合并。 

### 为什么它有效

在任何时候，有效状态都对所有先前矩形如何连接的完整几何解释进行编码。 处理新矩形时，唯一的自由度是方向和选择要附加的边，但两者都完全受到与当前矩形相等条件的约束。 任何在步骤 i 中幸存下来的状态都保证可以扩展到前缀的完整构造。 由于每个有效的完整构造必须恰好对应于此类状态转换的一个序列，因此我们不会丢失解决方案。 

状态的有限数量来自这样一个事实：在所有约束中幸存的唯一模糊性是宽度和高度解释之间的全局交换，因此最多存在两种一致的几何解释。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def normalize(w, h):
    if w > h:
        w, h = h, w
    return (w, h)

n = int(input())
a1, b1 = map(int, input().split())

states = set()
states.add(normalize(a1, b1))

for _ in range(n - 1):
    a, b = map(int, input().split())
    nxt = set()

    for W, H in states:
        for x, y in ((a, b), (b, a)):
            if x == W:
                nxt.add(normalize(W, H + y))
            if x == H:
                nxt.add(normalize(W + y, H))

    states = nxt
    if not states:
        print(0)
        sys.exit()

print(len(states))
for w, h in states:
    print(w, h)
```实现直接遵循状态转换模型。 归一化步骤至关重要，因为它合并了同一矩形的对称表示。 如果没有它，状态空间将错误地加倍。 

嵌套循环仍然高效，因为状态数量受一个常数限制（在有效情况下最多两个），使得转换在 n 中有效地呈线性。

 ## 边缘情况

 一个关键的边缘情况是，第一个矩形可以在两个方向上解释，然后又分成不同的有效结构。 例如，从非方形底座开始仍然可以允许两种解释在几个步骤中都存在。 该算法同时保持两种状态，并且每个后续块独立地对它们进行过滤，确保不会过早丢弃有效的方向。 

当块与当前矩形的两个尺寸都匹配时，会发生另一种边缘情况，从而有效地允许两个不同的附着方向。 在这种情况下，算法会生成两个候选状态，但如果它们产生相同的最终维度，则归一化会将它们合并。 这可以防止人为重复状态并确保状态空间保持有界。
