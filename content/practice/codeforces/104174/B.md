 ## 解决方案
 ## 问题理解

 我们得到了一张城市图，其中每个城市当前属于两个派系之一，标记为 1 或 2。有些城市是“可修改的”，这意味着我们可以翻转其派系，而其他城市是固定的且无法更改。 

目标是使图表“中立”，这意味着对于两个城市之间的每条道路，端点必须属于不同的派系。 用图术语来说，我们希望 1 和 2 的最终分配能够形成每条边的正确二分。 

但是，我们不能随意指定颜色。 我们从最初的着色开始，并且只允许翻转标记为可编辑的城市的颜色。 每次翻转都算作一次操作，我们希望最大限度地减少所需的翻转次数。 如果不可能达到有效的中性配置，我们必须输出-1。 

这些约束允许最多 10^4 个节点和 2·10^5 个边，这立即表明任何涉及颜色分配指数枚举的解决方案都是不可能的。 即使每个边缘情况二次都是可以接受的，但是尝试所有分配或重复重新计算大型结构之类的任何事情都会太慢。 每个组件的线性或近线性图遍历是目标。 

一个关键的微妙之处是图表可能会断开连接。 每个连接的组件可以独立处理，但只有通过对组件答案求和才能实现全局成本最小化交互。 

对于朴素推理来说，有一些重要的失败模式。 最常见的错误是假设我们可以贪婪地逐边修复违规行为。 例如，考虑一个三角形，其中所有节点都以颜色 1 开始，并且只有一个节点可编辑。 局部翻转错误的节点可能会修复一个边缘但破坏另一个边缘，从而导致振荡或不正确的极小值。 当组件在结构上已经是二分的，但初始颜色与二分冲突并且固定节点强制分配不一致时，就会出现另一个问题。 

第三种微妙的情况是，当一个组件在图结构中是二分的，但两种可能的二分都需要翻转不可编辑的节点。 在这种情况下，答案不是“只选择另一边”，而是明确不可能的。 

## 方法

 如果我们忽略哪些节点可编辑的限制，问题就会变得简单。 可以使用 BFS 或 DFS 检查图的每个连接组件的二分性，并沿边缘分配交替颜色。 如果发现冲突，则不存在有效的 2 着色，答案为 -1。 

然而，这里的问题是我们已经有了初始着色，并且我们希望最大限度地减少编辑约束下的更改数量。 这将问题转化为选择一个二分分配，该二分分配在汉明距离中最接近给定分配，但具有强制固定顶点。 

蛮力方法是尝试与二分约束一致的所有可能的颜色分配。 每个组件的大小呈指数关系，本质上是 2^{组件或节点的数量}，这对于 n 高达 10^4 来说是不可行的。 

关键的观察是，每个连接的组件，如果是二分的，则恰好有两种有效的着色：一种及其全局翻转。 一旦我们修复了根并传播交替奇偶校验，每个节点都会获得一个奇偶校验标签。 这减少了从搜索分配到在每个组件的两个全局状态之间进行选择的问题。 

一旦我们计算出这两个候选作业，我们就评估它们的成本：需要翻转多少个可编辑节点来匹配每个作业。 固定节点限制可行性：如果固定节点不同意候选分配，则该候选无效。

这将问题转化为每个组件的决策：计算对齐“奇偶校验 0 根”和“奇偶校验 1 根”的成本，然后选择最小的有效根。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 组件二分+两种颜色选择 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们使用 BFS 或 DFS 独立处理每个连接的组件。 

1.我们迭代所有节点。 当我们找到一个未访问的节点时，我们为其组件启动一个 BFS。 这确保我们正确处理断开连接的图。 
2. 在 BFS 期间，我们为每个节点分配一个奇偶校验值（0 或 1），表示其在二分着色中相对于起始节点的位置。 对于每条边 u-v，我们强制执行 parity[v] = parity[u] XOR 1。如果我们发现矛盾，则该图不是二分图，我们立即返回 -1。 
3. BFS 完成一个组件后，我们现在有了一个结构二分。 这为我们提供了一个基本的有效着色，但我们仍然需要将其与初始派系值对齐。 
4. 我们计算该组件的两个假设的全局分配：

 其中奇偶校验 0 对应于派系 1，奇偶校验 1 对应于派系 2，

 另一个地方这些含义互换了。 
5. 对于每项任务，我们都会计算成本。 如果节点是固定的，我们必须保证赋值与其初始值相匹配； 否则分配无效。 如果一个节点是可编辑的，如果其分配的颜色与其初始颜色不同，我们会将成本加 1。 
6. 我们在组件的有效分配中选取最小成本并将其添加到全局答案中。 如果两个赋值都无效，我们返回 -1。 
7. 处理完所有组件后，我们输出总成本。 

关键思想是 BFS 修复了图中唯一的结构自由度，而其他一切都简化为在约束下选择该结构与初始状态的最佳对齐方式。 

### 为什么它有效

 在任何连接的组件中，如果存在有效的中性配置，则该图必须是二分图。 一旦二分性被固定，每个有效的着色在全局翻转之前都是唯一确定的。 BFS 奇偶校验分配恰好捕获了这个等价类。 固定节点仅限制允许两次翻转中的哪一个，而一旦选择分配，可编辑节点就会独立地影响成本。 这保证了每个组件的两个候选着色之外不存在最佳解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    col = list(map(int, input().split()))
    can = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    vis = [-1] * n
    ans = 0

    for i in range(n):
        if vis[i] != -1:
            continue

        q = deque([i])
        vis[i] = 0
        comp = []

        ok = True

        while q:
            u = q.popleft()
            comp.append(u)
            for v in g[u]:
                if vis[v] == -1:
                    vis[v] = vis[u] ^ 1
                    q.append(v)
                elif vis[v] == vis[u]:
                    ok = False

        if not ok:
            print(-1)
            return

        cost0 = 0
        cost1 = 0
        valid0 = True
        valid1 = True

        for u in comp:
            if vis[u] == 0:
                if col[u] == 2:
                    cost0 += 1
                if col[u] == 1:
                    cost1 += 1
            else:
                if col[u] == 1:
                    cost0 += 1
                if col[u] == 2:
                    cost1 += 1

            if can[u] == 0:
                if vis[u] == 0 and col[u] != 1:
                    valid0 = False
                if vis[u] == 1 and col[u] != 2:
                    valid0 = False
                if vis[u] == 0 and col[u] != 2:
                    valid1 = False
                if vis[u] == 1 and col[u] != 1:
                    valid1 = False

        if not valid0 and not valid1:
            print(-1)
            return

        best = 10**18
        if valid0:
            best = min(best, cost0)
        if valid1:
            best = min(best, cost1)

        ans += best

    print(ans)

if __name__ == "__main__":
    solve()
```BFS 部分构造每个连接组件的二分区，同时检查一致性。 这`vis`数组对组件中的奇偶校验进行编码。 如果发现冲突，我们立即终止。 

BFS 之后，我们评估两个全局翻转。 成本计算将当前节点颜色与隐含的二分分配进行比较。 这`can`array 强制某些节点不能更改，这是通过使需要更改固定节点的分配无效来处理的。 

组件的最终累积反映了不同组件中的选择不相互作用。 

## 工作示例

 ### 示例 1

 输入：```
4 2
1 1 1 2
1 1 1 0
1 2
2 3
```我们有一个包含节点 1、2、3 和一个单独的节点 4 的组件。 

| 步骤| 节点| 平价 | 初始| 固定| 成本翻转A | 成本翻转B |
 | ---| ---| ---| ---| ---| ---| ---|
 | BFS | 1 | 0 | 1 | 1 | 0 | 1 |
 | BFS | 2 | 1 | 1 | 1 | 1 | 0 |
 | BFS | 3 | 0 | 1 | 1 | 0 | 1 |

 节点 4 已被隔离并且已经免费生效。 

对于组件，翻转 A 或翻转 B 都给出有效的二分，但考虑到约束，翻转 A 总体上产生的变化较少，导致总成本为 1。 

这个例子展示了即使是简单的线性组件也需要在两个全局翻转之间进行选择，而不是局部决策。 

### 示例 2

 输入：```
4 4
1 1 1 1
0 0 1 1
1 2
2 3
3 4
1 4
```该图是一个长度为 4 的循环，在结构上是二分的。 然而，强制固定节点限制了可能的翻转。 

| 节点| 平价 | 初始| 固定| 有效翻转 A | 有效翻转 B |
 | ---| ---| ---| ---| ---| ---|
 | 1 | 0 | 1 | 0 | 好的 | 好的 |
 | 2 | 1 | 1 | 0 | 好的 | 好的 |
 | 3 | 0 | 1 | 1 | 好的 | 好的 |
 | 4 | 1 | 1 | 1 | 好的 | 好的 |

 尽管这两种翻转在结构上都是有效的，但每个节点都是固定的，并且在调整成本时两种配置中都会出现不匹配，从而在不违反固定约束的情况下实现中立性方面都无效。 结果是-1。 

这表明仅二分结构是不够的，可行性取决于与固定节点的兼容性。

 | 测量| 复杂性 | 说明|

 | 时间 | O(n + m) | 每个节点和边在 BFS 期间处理一次，在评估期间处理一次 |

 ## 边缘情况

 一种边缘情况是结构上不是二分图。 考虑一个三角形，其中节点以长度为3的循环连接。BFS最终会找到连接具有相同奇偶校验的两个节点的边，立即将该组件标记为无效。 即使许多节点可编辑，这也会正确输出 -1，因为没有分配可以满足所有边。 

另一个边缘情况是二分图，其中固定节点强制两个奇偶校验选择之间出现矛盾的分配。 在这种情况下，两个全局翻转都可能违反固定约束，并且算法正确地使两个候选无效并返回 -1。 

最后一种微妙的情况是多个断开连接的组件，其中一个组件是可解的，而另一个组件则不可解。 该算法在遇到无效组件时立即停止，这符合整个配置必须全局有效的要求。
