 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并要求最小化连续重复。 形式上，我们将数组的相等性定义为两个连续元素相等的位置数。 任务是执行用相同的新数字替换任何连续对的操作，并将相等相邻对的总数减少到最多一个。 目标是计算每个数组的此类操作的最少数量。 

输入由多个测试用例组成，每个测试用例的数组大小最多为 200,000，所有测试用例的数组大小总和也不超过 200,000。 这意味着任何算法都必须在每个测试用例的数组大小中以大致线性的时间运行，以避免超时。 重复迭代所有对的二次解将不起作用，因为在最坏的情况下它们可能需要 10^10 次运算。 

当数组大部分均匀时，或者当重复值出现在孤立的块中时，就会出现不明显的边缘情况。 例如，数组`[1,1,1,1,1]`需要两次操作才能打破相等元素的长连续性。 仅计算重复对而不对其进行分组的简单方法可能会错误计算操作，尤其是在处理重叠对时。 

另一个棘手的场景是不需要任何操作的时候，比如`[1,2,1,2,1]`，它已经等于 0。粗心的解决方案可能会尝试无论如何应用一个操作。 

## 方法

 蛮力方法很简单。 我们可以重复扫描数组来定位连续的相等元素，并执行允许的操作来打破它们。 每次操作后，我们更新数组并重复，直到相等计数最多为 1。虽然正确，但这种方法在最坏的情况下可能需要 O(n^2)，因为每个操作可能只会将相等性减少 1，而我们最多可能有 n 个相等对。 当 n 达到 2×10^5 时，这太慢了。 

关键的见解是我们不需要显式地模拟操作。 连续的相等元素自然形成块。 每块长度`l`贡献`l-1`到平等。 减少块的长度`l`至多一对相等，我们大约需要`(l-1 - 1) // 2 + 1`操作如果`l>1`，这简化为`(l-2)//2 + 1`。 对于长度为 1 或 2 的块，不需要或需要一次操作。 主要观察结果是，对重叠对的操作可以有效地覆盖块，而无需额外的簿记。 我们只需要计算这些块的数量并计算每个块所需的操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 块计数| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 首先读取数组。 初始化一个变量`operations`为零。 这将累积所需的操作数量。 
2. 迭代数组以找出连续的相等元素。 维护两个指针：`i`作为块的开始并且`j`作为当前扫描索引。 每次`a[j]`不同于`a[i]`，块结束。 
3.对于每个长度的块`l`（从`i`到`j-1`）， 如果`l <= 2`，我们不需要进行操作。 如果`l > 2`, 计算`(l-2) // 2 + 1`并将其添加到`operations`。 这个公式来自这样的事实：每个操作都可以通过将一对设置为新值来固定块中的两个位置。 
4. 移动起始指针`i`到`j`并重复直到数组末尾。 
5. 打印总计`operations`对于数组。 

工作原理：通过处理连续相等值的块并应用公式，我们保证每个块最多减少到一对相等。 重叠是自动处理的，因为块内的操作会影响相邻的相等对。 在单例或已经最小的块上不会浪费任何操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations(n, a):
    operations = 0
    i = 0
    while i < n - 1:
        if a[i] == a[i + 1]:
            j = i + 1
            while j < n and a[j] == a[i]:
                j += 1
            length = j - i
            if length > 2:
                operations += (length - 2)
            i = j
        else:
            i += 1
    return operations

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_operations(n, a))
```该代码使用扫描指针来定位具有相等值的块。 内部循环扩展块直到值发生变化。 对于每个长度大于二的块，我们添加`(length - 2)`操作，保证在这些操作之后，块最多减少到一个相等。 外部指针跳过该块以避免重复计数。

 ## 边缘情况

 由于内部指针扫描到每个块的末尾，因此可以正确处理数组开头、中间或末尾的长块。 单个相等对不会触发额外的操作，因为`length > 2`查看。 孤立的重复和大小恰好为 2 的块也不会增加操作计数，从而避免了差一错误。 该算法自动跳过单例，确保没有不必要的操作。
