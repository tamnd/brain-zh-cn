 ## 解决方案
 ## 问题理解

 我们正在设计一枚由两部分组成的奖牌。 外部是一个有外半径的环$r_1$和内半径$r_2$。 内部是一个半径为 的实心圆盘$r_2$。 两个部分具有相同的厚度，因此它们的质量仅取决于面积和密度。 

外圈采用密度$p_1$，从一个列表中选择。 内盘使用密度$p_2$，从另一个列表中选择。 外半径$r_1$也是从列表中选择的。 声明中的固定规则要求$$\frac{m_{out}}{m_{in}} = \frac{A}{B}$$我们必须最大化内半径$r_2$。 

输入给出了外半径和两种密度的所有可能选择。 我们必须输出最大的可实现的$r_2$。 

限制很小。 每个值最多为 5000，并且数组大小也足够小，即使检查每个组合也很容易及时适应。 这立即告诉我们问题不在于优化技巧或高级数据结构。 真正的任务是推导正确的公式并了解哪些选择可以最大化答案。 

危险的部分是代数。 粗心的推导很容易使分数反转，或者忘记质量取决于面积，从而引入平方半径。 

一种微妙的边缘情况是选择了错误的密度。 认为：```
r1 = 10
p1 choices = [1, 100]
p2 choices = [1]
A = 1, B = 1
```如果我们使用$p_1 = 1$，环很轻，内盘必须保持相对较小以保持所需的质量比。 使用$p_1 = 100$允许更大的内盘。 忽略密度的贪婪方法在这里会失败。 

另一个容易犯的错误是最大化错误的变量。 公式为$r_2$包含$r_1^2$， 不是$r_1$。 如果有人尝试线性最大化比率而不是使用精确的导出表达式，他们可能会得到不正确的比较。 

第三个陷阱是浮点精度。 答案不一定是整数。 例如：```
1 5
1 3
1 2
1 1
```产生$$r_2 = 5 \sqrt{\frac{3}{5}}$$这是不合理的。 整数运算会默默地截断结果。 

## 方法

 最直接的方法就是尝试每一个可能的三元组$(r_1, p_1, p_2)$。 对于每个组合，导出相应的$r_2$从质量方程中得出并保留最大值。 

这是可行的，因为可能性的数量非常少。 即使所有三个数组的大小均为 100，总组合也仅为$10^6$，这在 Python 中完全没问题。 

有趣的部分是简化公式。 

外环面积为$$\pi (r_1^2 - r_2^2)$$内盘面积为$$\pi r_2^2$$由于厚度是均匀的，质量等于密度乘以面积直至一个公共常数因子。 所以：$$m_{out} = p_1 \pi (r_1^2 - r_2^2)$$

$$m_{in} = p_2 \pi r_2^2$$所需比例为$$\frac{p_1 (r_1^2 - r_2^2)}{p_2 r_2^2} = \frac{A}{B}$$解决$r_2^2$:$$B p_1 (r_1^2 - r_2^2) = A p_2 r_2^2$$

$$B p_1 r_1^2 = r_2^2 (A p_2 + B p_1)$$

$$r_2^2 = \frac{B p_1 r_1^2}{A p_2 + B p_1}$$

$$r_2 = r_1 \sqrt{ \frac{B p_1}{A p_2 + B p_1} }$$现在优化就变得很明显了。 当出现以下情况时，表达量增加：

 -$r_1$增加
 -$p_1$增加
 -$p_2$减少

 因此，我们不需要暴力破解每个组合，我们只需要：

 - 最大$r_1$- 最大$p_1$- 最小值$p_2$这减少了读取输入后不断工作的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nmk)$|$O(1)$| 已接受 |
 | 最佳 |$O(n + m + k)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取所有候选外半径并选择最大值$R$。 

较大的外半径总是会增加最终的答案，因为$r_2$与$r_1$。 
2. 读取外环的所有候选密度并选择最大值$P_1$。 

增加$p_1$使外圈更重，从而允许更大的内盘，同时保持所需的质量比。 
3. 读取内盘的所有候选密度并选择最小值$P_2$。 

较轻的内盘在其质量变得太大之前允许更大的半径。 
4. 读取常量$A$和$B$。 
5. 计算$$r_2 = R \sqrt{ \frac{B P_1}{A P_2 + B P_1} }$$1. 以足够的精度打印结果。 

### 为什么它有效

 推导公式表示$r_2$完全按照自变量：$$r_2 = r_1 \sqrt{ \frac{B p_1}{A p_2 + B p_1} }$$分子随着增长$r_1$和$p_1$，而分母随着增长$p_2$。 由于所有值都是正数，因此最大化$r_1$和$p_1$并最小化$p_2$总是最大化整个表达式。 变量之间不会产生权衡，因此选择每个独立的最优值会产生全局最优答案。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

# read radii
data = list(map(int, input().split()))
n = data[0]
x = data[1:]

# read p1 values
data = list(map(int, input().split()))
m = data[0]
y = data[1:]

# read p2 values
data = list(map(int, input().split()))
k = data[0]
z = data[1:]

A, B = map(int, input().split())

r1 = max(x)
p1 = max(y)
p2 = min(z)

ans = r1 * math.sqrt((B * p1) / (A * p2 + B * p1))

print("{:.12f}".format(ans))
```实现直接遵循数学推导。 

第一个重要的细节是选择正确的极值。 我们想要最大的外半径和外密度，但需要最小的内密度。 交换最小值或最大值会产生一个看似有效的数字，但实际上是完全错误的。 

第二个细节是使用浮点除法。 在 Python 中，这会自动发生`/`，但在另一种语言中使用整数除法会破坏精度。 

最终公式直接来自重新排列质量方程。 平方根适用于整个分数，而不仅仅是分母。 括号在这里很重要。 

输出使用12位小数，轻松满足要求$10^{-6}$精确。

 ## 边缘情况

 考虑选择错误的密度方向会破坏解决方案的情况：```
1 10
2 1 100
1 1
1 1
```该算法选择：$$r_1 = 10,\quad p_1 = 100,\quad p_2 = 1$$然后：$$r_2 = 10 \sqrt{\frac{100}{101}} \approx 9.95037$$如果我们错误地最小化$p_1$，结果将变为：$$10 \sqrt{\frac{1}{2}} \approx 7.07$$这远非最佳。 

现在考虑相反的方向$p_2$:```
1 10
1 10
2 1 100
1 1
```该算法选择最小的$p_2$，即 1：$$r_2 = 10 \sqrt{\frac{10}{11}} \approx 9.5346$$选择$p_2 = 100$相反给出：$$10 \sqrt{\frac{10}{110}} \approx 3.015$$巨大的下降证实了最小化$p_2$是必要的。 

最后，考虑精度敏感的情况：```
1 5
1 3
1 2
1 1
```确切的答案是：$$5 \sqrt{\frac35} \approx 3.872983346207$$该实现使用浮点运算并打印许多小数位，因此所需的$10^{-6}$安全地达到精度。
