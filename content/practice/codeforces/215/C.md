 ## 解决方案
 ## 问题理解

 每个十字由两个以同一单元格为中心的轴对齐矩形定义`(x0, y0)`。 

第一个矩形延伸`a`单元格垂直和`b`单元格从中心水平延伸，所以它的大小是：$(2a+1)(2b+1)$第二个矩形的定义类似`c`和`d`。 

如果一个单元格属于这些矩形中的至少一个，则该单元格属于十字形。 由于两个矩形都以同一点为中心，因此交叉面积就是两个矩形并集的大小。 

我们必须计算有多少个有序元组`(a, b, c, d, x0, y0)`准确地产生面积的交叉`s`，同时完全保持在`n × m`网格。 

元组是有序的。 除非所有四个参数都相等，否则交换两个矩形会产生不同的答案。 

网格尺寸最多为`500`，所以细胞总数最多为`250000`。 对所有六个变量进行暴力破解是不可能的。 甚至迭代所有值`a, b, c, d`独立地已经给出了粗略的`500^4`，远远超出了极限。 

关键的观察结果是面积公式仅取决于矩形大小，而不取决于中心位置。 一旦我们知道了一个有效的四元组`(a,b,c,d)`与联合区`s`，计算可能的中心变得很容易。 

有几种边缘情况可能会悄然破坏实施。 

假设一个矩形完全包含另一个矩形。 例如：```
n = 5, m = 5, s = 9
```元组```
(a,b,c,d) = (1,1,0,0)
```创建一个`3 × 3`正方形加上一个中心单元格。 联盟区仍在`9`， 不是`10`。 直接添加矩形区域的粗心实现会导致计数过多。 

当两个矩形部分重叠时会发生另一种微妙的情况：```
(a,b,c,d) = (1,0,0,1)
```这是经典的加号形状。 垂直矩形的面积`3`，水平矩形的面积`3`，但中心单元同时属于两者。 联合区域为`5`， 不是`6`。 

尽可能最小的交叉也很重要：```
2 2 1
```唯一可能的矩形是`1 × 1`，这意味着所有四个参数均为零。 每个网格单元都可以作为中心，所以答案是`4`。 

意外需要正臂长的实现会错误地返回`0`。 

## 方法

 直接暴力方法在概念上很简单。 

我们列举了所有可能的值`a, b, c, d`。 对于每个四元组，我们显式计算覆盖单元的集合或以几何方式计算联合面积。 如果面积等于`s`，我们计算有多少个中心将整个十字保持在网格内。 

收容条件很简单。 由于两个矩形共享相同的中心，因此十字形适合网格内部当且仅当：$x_0-\max(a,c)\ge1,\quad x_0+\max(a,c)\le n$对于列也类似。 

所以有效中心的数量为：$(n-2\max(a,c))(m-2\max(b,d))$前提是这两个因素都是积极的。 

由于状态空间巨大，暴力破解会失败。 每个参数大约可以达到`250`，给出关于：$250^4\approx4\times10^9$在考虑中心之前就翻了四倍。 

关键的见解是，在用奇数边长重写矩形尺寸后，矩形尺寸很小。 

定义：$h_1=2a+1,\quad w_1=2b+1,\quad h_2=2c+1,\quad w_2=2d+1$所有维度均为奇数正整数。 

联合区域变为：$h_1w_1+h_2w_2-\min(h_1,h_2)\min(w_1,w_2)$因为两个居中矩形的重叠恰好是较小的高度乘以较小的宽度。 

现在搜索空间变得易于管理。 每个矩形区域必须划分与以下内容相关的内容`s`，所有边长都是奇数约数。 最多的数字的奇数约数的个数`250000`相比之下很小`500`。 

我们不是独立迭代所有坐标，而是枚举有效的奇数矩形尺寸，其面积不超过`s`。 这减少了足以进行完整搜索的状态总数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n⁴) 式参数枚举 | O(1) | O(1) | 太慢了 |
 | 最佳 | O(D²) 其中 D 是有效奇数矩形的数量 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 枚举所有可能的奇数矩形尺寸`(h, w)`这样`h ≤ n`,`w ≤ m`， 和`h*w ≤ s`。 

每个生成的矩形`(a,b)`唯一对应于：$h=2a+1,\quad w=2b+1$因此迭代奇数维相当于迭代所有参数对。 
2. 将每个有效矩形存储在列表中。 

总计数很小，因为只允许奇数维度，并且面积由`s`。 
3. 迭代每对有序的矩形。 

设矩形为`(h1,w1)`和`(h2,w2)`。 
4. 计算重叠面积。 

由于两个矩形共享相同的中心，因此重叠尺寸很简单：$\min(h_1,h_2)\times\min(w_1,w_2)$5. 使用包含-排除计算并集面积。$A=h_1w_1+h_2w_2-\min(h_1,h_2)\min(w_1,w_2)$如果`A != s`，跳过这一对。 
6. 确定十字距中心的延伸距离。 

最大垂直范围为：$\max(a,c)=\frac{\max(h_1,h_2)-1}{2}$水平方向也类似。 
7. 计算有效中心。 

中心可以放置在任何行和列中，使两个矩形都保持在网格内：$(n-\max(h_1,h_2)+1)(m-\max(w_1,w_2)+1)$8. 将此计数添加到答案中。 

有序对很重要，所以我们不会除以二。 

### 为什么它有效

 每个十字唯一对应于两个居中的奇数大小的矩形。 之间的转换`(a,b,c,d)`并且矩形尺寸是双射的，因此不会丢失任何配置。 

对于任何两个居中矩形，它们的重叠本身就是一个居中矩形，其边长是坐标方向的最小值。 包含-排除计算精确的并集区域。 

放置计数也是准确的，因为如果较大的垂直跨度和较大的水平跨度都保留在板内，则交叉拟合。 对于每个有序四元组，每个有效中心都会被计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s = map(int, input().split())

    rects = []

    for h in range(1, n + 1, 2):
        for w in range(1, m + 1, 2):
            if h * w <= s:
                rects.append((h, w))

    ans = 0

    for h1, w1 in rects:
        area1 = h1 * w1

        for h2, w2 in rects:
            overlap = min(h1, h2) * min(w1, w2)

            union_area = area1 + h2 * w2 - overlap

            if union_area != s:
                continue

            max_h = max(h1, h2)
            max_w = max(w1, w2)

            positions = (n - max_h + 1) * (m - max_w + 1)

            ans += positions

    print(ans)

if __name__ == "__main__":
    solve()
```实施直接遵循数学重构。 

第一个循环枚举所有可能的居中矩形。 边长必须是奇数，因为每个矩形都围绕中心单元对称扩展。 

核心双循环迭代有序矩形对。 有序迭代很重要，因为问题有以下特点：```
(a,b,c,d)
```从：```
(c,d,a,b)
```重叠公式之所以有效，是因为两个矩形都对齐并居中。 它们的交点跨越较小的高度和较小的宽度。 

放置公式很容易因相差一而出错。 如果一个矩形有高度`h`，那么中心可能正好占据：```
n - h + 1
```行。 例如，与`n = 5`和`h = 3`，中心可以成行`2,3,4`，即`3 = 5-3+1`。 

所有算术都安全地适合 64 位整数。 Python 整数会自动处理这个问题。

 ## 边缘情况

 考虑：```
2 2 3
```不存在有效的交叉。 

唯一可能的奇数矩形尺寸是`(1,1)`。 组合两个这样的矩形仍然给出联合区域`1`。 

该算法枚举所有对，计算：$1+1-1=1$这永远不等于`3`，所以最终答案仍然为零。 

现在考虑：```
3 3 9
```实现面积的唯一方法`9`正在使用`3 × 3`长方形。 这对：```
(3,3),(1,1)
```仍有联合区`9`因为较小的矩形完全位于较大的矩形内部。 

该算法可以正确处理此问题，因为重叠等于较小的矩形面积：$9+1-1=9$最后，检查经典的加号形状：```
5 5 5
```使用矩形`(3,1)`和`(1,3)`。 

重叠部分正好是一个中心单元格：$3+3-1=5$最大尺寸为`(3,3)`，所以中心可能占据：$(5-3+1)^2=9$职位。 

由于矩形顺序很重要，因此两者`(3,1)+(1,3)`和`(1,3)+(3,1)`贡献，给予`18`总配置。
