 ## 解决方案
 # 问题理解

 我们被赋予了一个`n × m`其单元格包含颜色的网格。 可用的颜色是`{R, G}`什么时候`c = 2`， 或者`{R, G, B}`什么时候`c = 3`。 

目标是最多修改`q`使水平或垂直方向上的两个相邻单元格不具有相同的颜色。 该语句保证在允许的更改数量内始终存在解决方案。 

网格很小，最多`100 × 100`，所以最多有`10,000`细胞。 这排除了任何特别激进的情况，但问题是建设性的，而不是计算性的。 挑战在于找到一种保证保持在允许的修改次数之内的颜色。 

关键的观察来自于细胞的奇偶性。 细胞具有`(row + column) % 2 = 0`形成棋盘的一侧，并且具有奇偶校验的单元格`1`形成另一个。 相邻单元始终属于相反的奇偶校验。 

为了`c = 2`，每个有效的颜色必须是两个棋盘图案之一：```
R G R G ...
G R G R ...
```或相同的图案`R`和`G`交换了。 

为了`c = 3`，额外的颜色提供了更多的自由度。 我们可以保持一个奇偶校验的每个单元格不变，而仅对另一奇偶校验的单元格重新着色。 由于一个奇偶校验最多包含`⌊nm/2⌋`单元格，这会自动遵守最困难的子任务中使用的修改限制。 

当一个奇偶校验固定时，就会出现一种微妙的情况。 对于另一个奇偶校验的小区，其邻居可以使用一种、两种或三种不同的颜色。 如果所有三种颜色都出现在其邻居中，则固定奇偶校验的选择将不起作用，因为当前单元格中没有剩余颜色。 解决方案是尝试将两个奇偶校验类别作为固定侧。 问题的保证意味着这些尝试中至少有一次会成功。 

考虑以下示例：```
3 3
3 4
RGB
GBR
BRG
```如果我们坚持保持错误的奇偶校验不变，某些单元格可能会看到它周围的所有三种颜色，并且无法分配。 尝试两个奇偶校验可以避免这个陷阱。 

另一个简单的错误是错误地计算了修改`c = 2`。 例如：```
1 4
2 2
RGRG
```网格已经与一种棋盘图案完全匹配，因此正确的答案是不改变地输出它。 解决方案始终始于`R`当相反的模式更匹配时，左上角的 会错误地修改每个单元格。 

# 方法

 蛮力的想法是搜索网格的所有可能的有效颜色，并选择一个最多需要的颜色`q`修改。 即使只有三种颜色，网格`10,000`细胞有`3^10000`可能的着色，这是完全不可行的。 

邻接图的结构使问题变得简单。 网格是二分的。 每条边都连接相对的奇偶校验。 这意味着我们可以独立地推理两个奇偶校验类。 

什么时候`c = 2`，一旦选择了一个单元格的颜色，就会强制连接的棋盘图的每种正确的颜色。 确切地说有两种可能性。 我们只需将两者与原始网格进行比较，然后选择需要较少更改的网格。 

什么时候`c = 3`，我们利用只需要修改一个奇偶校验类这一事实。 假设我们保持所有奇偶校验 0 单元不变。 然后每个奇偶校验 1 单元都可以独立选择，因为它们都不相邻。 对于每个这样的单元格，我们选择与所有固定邻居不同的颜色。 如果某个单元格的邻居使用所有三种颜色，则此尝试失败。 然后我们重复构造并固定相反的奇偶校验。 

每个成功的构建仅更改一个奇偶校验类的单元格，因此修改的数量永远不会超过该奇偶校验类的大小。

 # 算法演练

 ### 案例 1：`c = 2`1. 构建棋盘图案，其左上角单元格为`R`。 
2. 构建棋盘图案，其左上角单元格为`G`。 
3. 计算每个图案有多少个单元格与原始网格不同。 
4. 输出差异数较少的模式。 

由于每个有效的 2 色网格都必须是这两种模式之一，因此更好的一种总是最佳的。 

### 案例 2：`c = 3`1. 尝试用奇偶校验修复所有单元格`0`。 
2. 将原始网格复制到工作网格中。 
3. 对于每个奇偶校验单元格`1`，看看它的邻居。 
4.让`used`是出现在这些邻居中的颜色集。 
5. 如果当前颜色不在`used`，保持不变。 
6. 否则，选择任意颜色`{R, G, B}`那不在`used`。 
7. 如果不存在这种颜色，则此尝试失败。 
8. 如果每个奇偶校验 1 单元均已成功分配，则输出结果网格。 
9. 否则重复相同的过程并进行奇偶校验`1`固定和奇偶校验`0`重新着色。 

### 为什么它有效

 当一个奇偶校验类别固定时，要重新着色的两个单元都不相邻。 每个重新着色的单元只需要避免其固定邻居的颜色。 

如果选择的颜色与所有相邻固定单元格不同，则与该单元格相关的每个边缘都将变得有效。 由于网格的每条边在每个奇偶校验类别中都有一个端点，因此所有边同时变得有效。 

尝试固定奇偶校验的两种选择可以保证我们找到声明所承诺的结构。 成功的尝试仅更改一个奇偶校验类别中的单元格，因此修改次数受该类别的大小限制。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
c, q = map(int, input().split())
a = [list(input().strip()) for _ in range(n)]

if c == 2:
    patterns = []

    for start in ['R', 'G']:
        grid = []
        diff = 0

        for i in range(n):
            row = []
            for j in range(m):
                if (i + j) % 2 == 0:
                    ch = start
                else:
                    ch = 'G' if start == 'R' else 'R'

                row.append(ch)
                if ch != a[i][j]:
                    diff += 1

            grid.append(row)

        patterns.append((diff, grid))

    ans = min(patterns, key=lambda x: x[0])[1]

    for row in ans:
        print(''.join(row))

else:
    colors = ['R', 'G', 'B']

    def build(fixed_parity):
        b = [row[:] for row in a]

        for i in range(n):
            for j in range(m):
                if (i + j) % 2 == fixed_parity:
                    continue

                used = set()

                for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    ni = i + di
                    nj = j + dj

                    if 0 <= ni < n and 0 <= nj < m:
                        used.add(b[ni][nj])

                if b[i][j] not in used:
                    continue

                found = False

                for col in colors:
                    if col not in used:
                        b[i][j] = col
                        found = True
                        break

                if not found:
                    return None

        return b

    ans = build(0)
    if ans is None:
        ans = build(1)

    for row in ans:
        print(''.join(row))
```这`c = 2`分支只是评估两种棋盘颜色并选择较接近的一种。 

这`c = 3`分支执行基于奇偶校验的构造。 工作网格开始时是原始网格的副本。 属于固定奇偶校验的单元永远不会被触及。 每个其他单元格都是独立处理的。 

这里有一个小的实现细节很重要。 在检查邻居时，我们从工作网格而不是原始网格中读取。 固定奇偶校验单元保持不变，而重新着色的单元永远不会彼此相邻，因此先前分配的值不会产生冲突。 

当所有三种颜色都出现在重新着色的单元格的相邻单元格中时，就会出现故障情况。 在这种情况下，该奇偶校验选项不存在有效的颜色，因此我们尝试相反的奇偶校验。

### 固定奇偶校验错误选择

 想象一下这样的配置，其中一个细胞可以看到其固定邻居中的所有三种颜色。 该奇偶校验选择失败，因为没有可用的颜色。 该算法检测到这一点时`used = {R, G, B}`并返回该尝试的失败。 然后，它会重试固定的相反奇偶校验，这是对`c = 3`案件。
