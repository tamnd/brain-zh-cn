 ## 解决方案
 ## 问题理解

 我们给出一个数组，其元素仅是`1`和`-1`。 

当每个前缀和都是非负且每个后缀和也是非负时，子序列被称为好的子序列。 对于子数组上的每个查询`[l, r]`，我们必须找到该子数组内一个好的子序列的最大可能长度。 还有一些更新查询可以翻转单个元素`1`到`-1`反之亦然。 

数组长度和查询次数都一样大`5 · 10^5`。 任何扫描整个查询范围的解决方案都会立即变得太慢。 甚至一个`O(length of range)`在最坏的情况下，查询将变成二次。 我们大概需要`O(log n)`每次更新和每次查询。 

问题的微妙部分是理解一个好的子序列实际上是什么样子的。 

取子序列：```
1 -1 1
```其前缀和为：```
1, 0, 1
```全部都是非负数。 

其后缀和为：```
1, 0, 1
```全部都是非负的，所以子序列很好。 

现在考虑：```
1 1 -1
```前缀和是非负的，但后缀仅包含`-1`有总和`-1`，所以子序列不好。 

仅检查前缀和的简单方法会错误地接受它。 

另一个容易犯的错误是假设每个`-1`必须与之前的匹配`1`。 例如：```
1 1 1
```不包含`-1`无论如何，它是一个有效的良好长度子序列`3`。 

后缀条件使结构变得有趣。 

## 方法

 暴力解决方案将枚举一个范围的所有子序列，并检查每个子序列是否满足前缀和后缀约束。 

对于一定长度范围`m`， 有`2^m`子序列。 即使是为了`m = 50`，这是完全不可能的，实际极限是几十万。 

关键的观察结果来自于重写条件。 

当且仅当每个前缀和至多是子序列的总和时，后缀和才是非负的。 因此，一个好的子序列正是其前缀和位于其中的子序列：```
0 ≤ prefix_sum ≤ total_sum
```假设我们从左到右扫描范围并贪婪地构建仅满足下界的最长子序列`prefix_sum ≥ 0`。 

每一个`1`总是有用的，所以我们总是接受它。 

对于一个`-1`，仅当当前余额为正时我们才采用它。 

让```
c1 = number of chosen 1's
c2 = number of chosen -1's
```并让```
mx = maximum balance ever reached during this greedy process
```得到的子序列满足前缀条件，但可能违反上限`prefix_sum ≤ total_sum`。 

最终余额为：```
c1 - c2
```为了使子序列有效，我们只需要减少最大余额`mx`最多下降到`c1 - c2`。 

可以证明，删除```
mx - (c1 - c2)
```已选择`-1`施工结束时的值总是足够的。 最终长度变为：```
(c1 + c2) - (mx - (c1 - c2))
= 2*c1 - mx
```所以答案仅取决于：```
c1 = number of 1's in the range
mx = maximum balance reached by the greedy process
```下一个观察结果是，这种贪婪平衡演变为：```
s = max(0, s + a[i])
```这正是卡丹的复发。 

价值`mx`是曾经达到的最大值`s`，这正是该范围的最大子数组和。 

因此：```
answer = 2 * (number of 1's in range) - (maximum subarray sum of range)
```现在问题变成了一个标准的线段树任务。 我们需要范围查询：```
number of 1's
maximum subarray sum
```与点更新。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次查询 O(2^m · m) | O(米) | 太慢了|
 | 线段树| 每次查询/更新 O(log n) | O(n) | 已接受 |

 ## 算法演练

 1. 构建线段树。 
2. 对于每个节点存储：

 -`num`: 数量`1`段中的值。 
-`sum`: 段总和。 
-`pre`：最大前缀和。 
-`suf`：最大后缀和。 
-`mx`：最大子数组和。 
3. 对于一片叶子：

 - 如果该值为`1`， 店铺：```
num=1, sum=1, pre=1, suf=1, mx=1
```- 如果该值为`-1`， 店铺：```
num=0, sum=-1, pre=0, suf=0, mx=0
```Kadane 风格的解释中允许使用空子数组，因此负值贡献为零。 
4. 使用标准最大子数组公式合并两个子数组：```
num = left.num + right.num
sum = left.sum + right.sum

pre = max(left.pre, left.sum + right.pre)
suf = max(right.suf, left.suf + right.sum)

mx = max(
    left.mx,
    right.mx,
    left.suf + right.pre
)
```5. 对于翻转更新，修改一个叶子并重新计算到根的路径上的所有节点。 
6. 对于范围查询，检索描述的线段树节点`[l, r]`。 
7. 答案是：```
2 * num - mx
```### 为什么它有效

 贪婪的建筑保留了每一个`1`并采取`-1`确切地说，这样做不会使余额为负数。 这会产生满足前缀条件的最长子序列。 

唯一剩下的障碍是后缀条件，这相当于要求每个前缀总和保持在最终余额以下。 如果达到的最大余额是`mx`最终余额为`c1 - c2`，我们必须缩小差距`mx - (c1 - c2)`。 删除恰好那么多选定的内容`-1`值就足够了，最终长度为`2*c1 - mx`。 

贪婪平衡过程与 Kadane 递归过程相同，因此`mx`等于范围的最大子数组和。 线段树准确地维护更新后计算该值所需的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Node:
    __slots__ = ("num", "sum", "pre", "suf", "mx")

    def __init__(self, num=0, sm=0, pre=0, suf=0, mx=0):
        self.num = num
        self.sum = sm
        self.pre = pre
        self.suf = suf
        self.mx = mx

def merge(a, b):
    res = Node()
    res.num = a.num + b.num
    res.sum = a.sum + b.sum
    res.pre = max(a.pre, a.sum + b.pre)
    res.suf = max(b.suf, a.suf + b.sum)
    res.mx = max(a.mx, b.mx, a.suf + b.pre)
    return res

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.arr = arr
        self.st = [Node() for _ in range(4 * self.n)]
        self.build(1, 0, self.n - 1)

    def make_leaf(self, v):
        if v == 1:
            return Node(1, 1, 1, 1, 1)
        return Node(0, -1, 0, 0, 0)

    def build(self, p, l, r):
        if l == r:
            self.st[p] = self.make_leaf(self.arr[l])
            return

        m = (l + r) // 2
        self.build(p * 2, l, m)
        self.build(p * 2 + 1, m + 1, r)
        self.st[p] = merge(self.st[p * 2], self.st[p * 2 + 1])

    def update(self, p, l, r, idx):
        if l == r:
            self.arr[idx] *= -1
            self.st[p] = self.make_leaf(self.arr[idx])
            return

        m = (l + r) // 2
        if idx <= m:
            self.update(p * 2, l, m, idx)
        else:
            self.update(p * 2 + 1, m + 1, r, idx)

        self.st[p] = merge(self.st[p * 2], self.st[p * 2 + 1])

    def query(self, p, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.st[p]

        m = (l + r) // 2

        if qr <= m:
            return self.query(p * 2, l, m, ql, qr)

        if ql > m:
            return self.query(p * 2 + 1, m + 1, r, ql, qr)

        left = self.query(p * 2, l, m, ql, qr)
        right = self.query(p * 2 + 1, m + 1, r, ql, qr)
        return merge(left, right)

n, q = map(int, input().split())
a = list(map(int, input().split()))

seg = SegTree(a)

ans = []

for _ in range(q):
    parts = list(map(int, input().split()))

    if parts[0] == 1:
        pos = parts[1] - 1
        seg.update(1, 0, n - 1, pos)
    else:
        l, r = parts[1] - 1, parts[2] - 1
        node = seg.query(1, 0, n - 1, l, r)
        ans.append(str(2 * node.num - node.mx))

sys.stdout.write("\n".join(ans))
```线段树节点正是经典的最大子数组节点。 唯一的额外字段是`num`，计算有多少个`1`值出现在段中。 

合并操作与 Kadane 线段树合并相同。 最大子数组可以完全位于左子数组中，完全位于右子数组中，或者通过边界`left.suf + right.pre`。 

叶子为`-1`用途`pre = suf = mx = 0`。 这是允许最佳子数组为空的标准公式。 缺少此详细信息会更改仅包含负值的范围的答案。 

最终公式`2 * node.num - node.mx`直接应用于查询的段。

 ## 边缘情况

 考虑：```
1
-1
```唯一的非空子序列是`[-1]`。 它的前缀和为负数，因此无效。 该算法存储：```
num = 0
mx = 0
```并返回：```
2 * 0 - 0 = 0
```这与正确答案相匹配。 

现在考虑：```
3
1 1 -1
```仅检查前缀和的解决方案将保留所有三个元素。 后缀仅由`-1`是负数，所以子序列不好。 

该范围的段数据给出：```
num = 2
mx = 2
```答案就变成了：```
2 * 2 - 2 = 2
```这才是正确的美。 

最后，考虑：```
3
1 1 1
```没有`-1`根本没有价值观。 每个前缀和后缀之和都是正数。 树报告：```
num = 3
mx = 3
```所以：```
2 * 3 - 3 = 3
```并选择完整阵列。
