 ## 解决方案
 ## 问题理解

 我们有一排书。 每本书都有一种颜色。 我们可以重复选择任何一本书并将其移动到行的末尾。 

目标是使最终的排列由色块组成，这意味着每种颜色都恰好出现在一个连续的部分中。 不同的颜色可以以任何顺序出现，但相同颜色的书最终必须相邻。 

我们需要移动的图书数量最少。 

手术不寻常。 我们从来不会在中间的某个地方插入一本书。 每本移动的书都会移至最右侧。 因此，有些书籍永远保持原来的相对顺序，而移动的书籍则在最后被收集。 

输入大小达到$5 \cdot 10^5$。 任何尝试所有可能的最终颜色顺序、移动书籍的所有子集或执行二次扫描的算法都是立即不可能的。 甚至$O(n \sqrt n)$在这种规模下会感到不舒服。 我们需要一些接近线性或$O(n \log n)$。 

困难的部分是了解保留在原处的书籍会是什么样子。 一个天真的想法是保留最大的已经很漂亮的子序列，但该操作比任意删除要严格得多。 我们必须尊重仅将书籍移到最后所创建的结构。 

一些边缘情况很容易被错误处理。 

考虑：```
1 2 1
```答案是1.移动中间的书：```
1 1 2
```仅检查每种颜色在原始数组中是否已经连续的解决方案会错误地得出两本书必须移动的结论。 

另一个微妙的情况是：```
1 2 2 1
```答案是1.移动最后一个`1`：```
1 2 2 1
→
1 2 2 1   (remove last 1)
→
1 2 2 1   (append to end, same position)
```更自然的是，先移动`1`：```
2 2 1 1
```重要的观察是，颜色不一定需要将其所有出现都保留在静止部分中。 

第三种情况是一种颜色已经占据了完整的区间：```
1 2 2 2 3
```答案是 0。任何强制颜色按值的递增或递减顺序出现的算法都会失败，因为色块的最终顺序完全不受限制。 

## 方法

 蛮力观点是决定哪些书保留在原处。 凡是没有留下来的书，都要移到最后。 

假设我们知道这套文具书。 它们的相对顺序永远不会改变。 移除所有移动的书籍后，固定书籍必须已经形成一个漂亮的书架，因为移动的书籍是后来追加的，并且不能改变固定前缀的内部结构。 

这表明寻找可以保留的最大的书籍子集。 如果我们能保留$k$书，那么答案就是$n-k$。 

问题是有$2^n$可能的子集。 即使尝试直接表征所有有效子集也是不可行的。 

关键的观察来自于查看每种颜色的第一次和最后一次出现。 

让：

-$L_c$= 第一次出现的颜色$c$-$R_c$= 最后出现的颜色$c$-$cnt_c$= 颜色频率$c$如果我们决定那个颜色$c$参与静止部分，那么一旦我们保留任何发生$c$，里面的每一次出现$[L_c,R_c]$也必须属于同一色块。 否则另一种颜色会分裂该块。 

这种区间结构将问题转化为位置的动态规划问题。 

定义$dp[i]$作为仅使用从以下位置开始的后缀位置可以保持静止的最大书籍数量$i$。 

当我们站在一个位置上$i$，存在两种可能性。 

我们可以简单地删除当前的书。 然后我们什么也没得到并继续$dp[i+1]$。 

或者我们可以开始保留间隔从这里开始的颜色。 假设颜色是$c$和$i=L_c$。 

里面$[L_c,R_c]$，每次出现的颜色$c$可以留下来。 对于整个区间位于该范围内的所有其他颜色，我们也可以保留其所有出现的情况。 这将创建一个嵌套间隔链。 

最初接受的解决方案从右到左处理位置，并为每种颜色保留选择其间隔时可获得的最佳值。 区间结构允许每个位置仅处理一次，从而产生线性复杂度。 

过渡最终计算出可以保留的最大书籍数量，答案是：$$n - \max(\text{stationary books})$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了|
 | 最优DP+区间处理|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 首先计算每种颜色的第一次出现、最后一次出现和频率。 

让`dp[i]`表示仅考虑位置时可以保持静止的最大书籍数量`i`向前。 

从右到左处理位置。 

1.如果我们把书移到位置`i`，我们得到`dp[i+1]`。 
2. 设当前颜色为`c`。 
3. 维护`best[c]`，选择颜色区间对应的值`c`。 
4.如果位置`i`是最后一次出现`c`, 初始化$$best[c] = cnt_c$$因为至少我们可以保留所有出现的这种颜色。 
5.否则更新$$best[c] = best[c] + 1$$同时向左移动通过另一个相同颜色的出现。 
6.如果位置`i`是第一次出现`c`，我们可以完成颜色区间`c`并在最后一次出现后继续：$$best[c] += dp[R_c + 1]$$7. 设置$$dp[i] = \max(dp[i+1], best[c])$$8. 继续直至位置 1。 

文具书籍的最大数量为`dp[1]`。 答案是`n - dp[1]`。 

### 为什么它有效

 对于每种颜色，其第一次出现和最后一次出现之间的间隔决定了必须一致处理的区域。 当扫描到达颜色出现处时`c`,`best[c]`存储保持当前区间后缀的最佳解决方案`c`。 

向左移动将保留的间隔再延长一次`c`。 一旦扫描到达第一次出现，整个间隔`c`已被核算。 那时我们可以立即开始连接一个最佳解决方案`R_c`。 

每个有效的平稳集都可以分解为这样的完整颜色区间，并且 DP 产生的每个过渡都对应于一个可实现的平稳集。 递归检查每个位置的两种可能性：丢弃当前的书或致力于其颜色的区间结构。 由于所有间隔都只处理一次，因此可以正确计算可以保留的最大书籍数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    first = [-1] * (n + 1)
    last = [-1] * (n + 1)
    cnt = [0] * (n + 1)

    for i, x in enumerate(a):
        if first[x] == -1:
            first[x] = i
        last[x] = i
        cnt[x] += 1

    dp = [0] * (n + 1)
    best = [0] * (n + 1)

    for i in range(n - 1, -1, -1):
        c = a[i]

        if i == last[c]:
            best[c] = cnt[c]
        else:
            best[c] += 1

        if i == first[c]:
            best[c] += dp[last[c] + 1]

        dp[i] = max(dp[i + 1], best[c])

    print(n - dp[0])

if __name__ == "__main__":
    solve()
```第一遍计算每种颜色的间隔信息​​。`best[c]`是中心思想。 从右向左扫描时，存储部分处理过的颜色区间值`c`。 遇到另一种情况`c`通过一本保存完好的书来延长这一间隔。 

第一次发生时的特殊处理至关重要。 只有在到达第一次出现后，我们才知道该颜色的整个区间都已被覆盖。 此时，我们可以在间隔结束后开始附加最佳解决方案。 

DP数组是后缀DP。`dp[i]`始终代表从位置开始的后缀中可用的最佳答案`i`。 服用`max(dp[i + 1], best[c])`完全对应于丢弃当前书或使用其颜色的区间结构之间的选择。 

所有值都适合 32 位整数，因为它们永远不会超过`n`，但 Python 整数消除了任何担忧。 

## 工作示例

 ### 示例 1

 输入：```
5
1 2 2 1 3
```间隔：

 | 颜色 | 第一 | 最后 | 计数 |
 | --- | --- | --- | --- |
 | 1 | 0 | 3 | 2 |
 | 2 | 1 | 2 | 2 |
 | 3 | 4 | 4 | 1 |

 从右到左 DP：

 | 我| 颜色 | 更新后最佳[颜色] | dp[i] | dp[i] |
 | --- | --- | --- | --- |
 | 4 | 3 | 1 | 1 |
 | 3 | 1 | 2 | 2 |
 | 2 | 2 | 2 | 2 |
 | 1 | 2 | 3 | 3 |
 | 0 | 1 | 4 | 4 |

 我们可以保留 4 本书，所以答案是：```
5 - 4 = 1
```该迹线显示了在位置 1 处完成颜色 2 的间隔如何允许 DP 连接到后面的间隔。

 DP进化：

 | 我| 颜色 | 更新后最佳[颜色] | dp[i] | dp[i] |

 ## 边缘情况

 考虑：```
3
1 2 1
```颜色间隔`1`是`[0,2]`。 颜色间隔`2`是`[1,1]`。 

从右向左扫描时，DP 认识到保留两次出现的`1`以及单次出现的`2`区间内是可以的。 最大静止计数变为`2`，产生答案`1`。 这与移动相匹配：```
1 2 1
→
1 1 2
```考虑：```
4
1 2 2 1
```颜色`2`已经形成一个连续的块。 DP 保留整个间隔并将其与一次出现的颜色块组合起来`1`。 静止计数达到`3`，所以答案是`1`。 

如果贪婪策略坚持在选择颜色后保留每次出现的颜色，就会错过这种可能性。 

考虑：```
5
1 2 2 2 3
```每种颜色已经占据一个连续的段。 间隔是不相交的并且已经有效。 DP保留所有五本书，获得`dp[0] = 5`，所以答案是`0`。 

这证实了该算法可以正确处理根本不需要操作的货架。
