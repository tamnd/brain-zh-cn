 ## 解决方案
 ## 问题理解

 我们有一份家务困难清单。 Vasya 必须准确接收`b`难度最大的家务`x`，而 Petya 必须准确接收`a`难度严格大于的家务`x`。 

价值`x`必须是整数。 我们需要计算有多少个整数满足分割。 

整理好困难之后，情况就变得更容易推理了。 正是因为`b`家务活必须满足`h[i] ≤ x`，第一个`b`最小的家务活必须由 Vasya 负责，其余的`a`家务活必须属于Petya。 

这立即创建了两个边界值：

 - 瓦夏最大的苦差事是`b`-第一个最小值。 
- Petya 承担的最小的家务是`(b + 1)`-第一个最小值。 

如果我们将它们表示为：

 -`L = sorted_h[b - 1]`-`R = sorted_h[b]`然后`x`必须满足：

 -`x ≥ L`，否则 Vasya 收到的金额将少于`b`家务活。 
-`x < R`，否则 Petya 将收到少于`a`家务活。 

所以每个有效整数`x`位于区间内`[L, R - 1]`。 

这里的约束很小，最多只有 2000 个元素，因此即使是二次解也能轻松通过。 尽管如此，问题的结构导致了一个非常紧凑的问题`O(n log n)`排序后的解决方案。 

棘手的情况来自边界周围的重复值。 

考虑这个输入：```
7 3 4
1 2 3 3 3 4 5
```排序后，第四小的值是`3`，第五个最小值也是`3`。 

我们需要：```
3 ≤ x < 3
```这是不可能的。 正确答案是`0`。 

粗心的实现可能会尝试计算两个边界位置之间的数字并意外返回`1`。 

当差距很大时，会发生另一种微妙的情况：```
5 2 3
1 2 10 20 30
```这里：```
L = 2
R = 10
```任意整数`2`通过`9`有效，所以答案是`8`。 

有效值不限于现有的困难。 它们都是间隙中的整数。 

## 方法

 蛮力的想法很简单。 我们可以尝试每一个可能的整数`x`，计算有多少家务事满足`h[i] ≤ x`，并检查该计数是否等于`b`。 

最小的难度至少是`1`，最大可达`10^9`，因此迭代所有可能的`x`价值观是完全不现实的。 即使每张支票只花了`O(n)`, 扫描最多`10^9`整数需要大约`2 × 10^12`最坏情况下的操作。 

关键的观察结果是，只有 Vasya 的家务和 Petya 的家务之间的界限才重要。 

数组排序完成后，第一个`b`元素必须属于 Vasya，其余的`a`元素必须属于 Petya。 这些组内的确切值不再重要。 

认为：```
sorted_h[b - 1] = L
sorted_h[b] = R
```让 Vasya 仍然准确接收`b`家务活，`x`必须至少是`L`，因为 Vasya 分配的最难的杂务必须满足`h[i] ≤ x`。 

让 Petya 仍能准确接收`a`家务活，`x`必须严格小于`R`，因为 Petya 最简单的分配任务必须满足`h[i] > x`。 

这意味着有效整数恰好是：```
L, L + 1, ..., R - 1
```计数为：```
R - L
```如果`L == R`，答案自然就变成了`0`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(10^9·n) | O(10^9·n) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(1) 除了排序之外的额外空间 | 已接受 |

 ## 算法演练

 1. 读取数值`n`,`a`， 和`b`，以及家务困难列表。 
2. 按非降序对难度数组进行排序。 

排序后，首先`b`家务活是瓦夏唯一可能接受的家务活，如果他必须完全承担的话`b`可接受的最小家务活。 
3.设：```
L = h[b - 1]
R = h[b]
```

`L`是分配给 Vasya 的最大难度，并且`R`是分配给 Petya 的最小难度。 
4. 每个有效整数`x`必须满足：```
L ≤ x < R
```左边的条件保证瓦夏保留他所有的家务。 合适的条件保证了佩蒂亚能够完成所有的家务。 
5. 该区间内的整数个数为：```
R - L
```6. 打印`R - L`。 

### 为什么它有效

 排序之后，两兄弟的分界点就固定了。 Vasya 必须恰好收到第一个`b`家务活，Petya 必须准确地收到剩余的`a`家务活。 

对于分配给 Vasya 的每项杂务，我们需要`h[i] ≤ x`。 最强的限制来自Vasya最难的杂务，它有价值`L`。 

对于分配给 Petya 的每项杂务，我们需要`h[i] > x`。 最强的限制来自 Petya 最简单的家务，它有价值`R`。 

因此有效整数正是这两个边界之间的整数。 任何较小的值都会排除 Vasya 的一项杂务，任何较大的值都会包括 Petya 的一项杂务。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    h = list(map(int, input().split()))

    h.sort()

    print(h[b] - h[b - 1])

solve()
```该解决方案完全依赖于排序顺序。 

排序后，索引`b - 1`是分配给 Vasya 的最后一项杂务，而索引`b`这是分配给 Petya 的第一项杂务。 Python 使用从零开始的索引，因此即使问题在概念上使用从一开始的排序来描述琐事，这些位置也是正确的。 

答案很简单，就是来自的整数个数`h[b - 1]`通过`h[b] - 1`，等于`h[b] - h[b - 1]`。 

一个常见的差一错误是尝试使用`h[a - 1]`和`h[a]`。 边界是由 Vasya 伯爵确定的，而不是 Petya 伯爵确定的，因为第一个`b`已排序的元素属于 Vasya。 

另一个容易犯的错误是手动减去一个：```
h[b] - h[b - 1] - 1
```这会错误地排除左端点，即使`x = h[b - 1]`是有效的。

 ## 边缘情况

 考虑重复边界情况：```
7 3 4
1 2 3 3 3 4 5
```排序后：```
[1, 2, 3, 3, 3, 4, 5]
```我们计算：```
L = h[3] = 3
R = h[4] = 3
```该算法返回：```
3 - 3 = 0
```这是正确的，因为没有整数可以同时满足：```
x ≥ 3
x < 3
```现在考虑大间隙的情况：```
5 2 3
1 2 10 20 30
```排序后：```
[1, 2, 10, 20, 30]
```我们得到：```
L = 2
R = 10
```该算法返回：```
10 - 2 = 8
```有效整数是：```
2, 3, 4, 5, 6, 7, 8, 9
```这证实了答案计算了间隔中的每个整数，而不仅仅是数组中已经存在的困难。 

最后，检查可能的最小输入：```
2 1 1
1 2
```排序后：```
[1, 2]
```我们计算：```
L = 1
R = 2
```算法返回`1`，仅表示`x = 1`作品。 

如果`x = 0`，瓦夏不做家务。 如果`x = 2`, Petya 不做家务。 边界逻辑在最小尺寸下仍然可以完美工作。
