 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$最初包含以下数字的完美排列的网格$1$到$n^2$。 原始网格的定义属性是每行总和等于相同的值，并且每列总和也等于相同的值。 这一结构仅被一个操作所破坏：两个单元格的值被交换。 

任务是识别两个交换单元格的坐标。 如果我们将这两个值交换回来，网格将再次成为有效的“魔法”网格，这意味着所有行总和和列总和变得相等。 

关键的限制是$n$可以大到 1000，因此网格最多包含一百万个单元。 任何重新计算许多候选交换的行或列属性的解决方案都必须在网格上以线性时间有效运行。 二次或偶数$O(n^3)$交换模拟是不可行的，但是任何基于网格单次传递的东西都是可以接受的。 

一个微妙的点是所有值都是不同的，因此每个值都唯一标识其位置。 这消除了歧义：如果行总和中的值错误，则可以追溯到唯一位置。 

另一个重要的观察结果是，网格与有效的幻方正好有两个单元格的不同。 这意味着所有结构违规都是局部的，并且除了受交换位置影响的行和列之外，每行和每列都是正确的。 

如果假设只需要检查行或列，就会出现幼稚的失败情况。 考虑进行保留行总和但破坏列总和的交换，反之亦然； 这种情况迫使我们同时对两个维度进行推理。 

## 方法

 一个直接的暴力想法是考虑每对单元格，交换它们，并检查生成的网格是否变得神奇。 对于每一对，重新计算所有行和列的总和成本$O(n^2)$，并且有$O(n^4)$对。 这导致了天文数字般的复杂性$O(n^6)$，即使对于小规模来说，这也是完全不可行的$n$。 

我们需要避免模拟交换。 问题的结构建议查看聚合信息而不是配置。 在正确的魔法网格中，每行总和等于一个常数$S$，每列总和也等于$S$。 如果发生交换，则恰好两行和两列的总和将不正确，因为只有包含交换单元格的单元格才会受到影响。 

这将问题简化为识别哪些行和列“不平衡”，然后定位负责的确切单元格。 由于值是不同的，我们可以计算预期总和并将其与实际总和进行比较$O(n^2)$，然后推断出受影响的两个行和列。 

一旦我们隔离了两个坏行和两个坏列，交换的元素必定位于它们的交点处。 这将候选空间减少到最多四个单元，我们可以通过检查哪个交换恢复一致性来确定正确的对。

 | 暴力交换检查 |$O(n^6)$|$O(1)$| 太慢了 |
 | 行/列偏差分析 |$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 ## 算法演练

 1. 计算预期幻数和$S = \frac{n(n^2+1)}{2}$。 这是正确网格中每行和每列应具有的总和，因为网格是以下排列$1 \ldots n^2$。 
2. 在网格上单次计算所有行总和。 识别总和不同于的行$S$。 这些是包含交换元素之一的候选行。 
3. 类似地计算所有列的总和并识别总和不同于的列$S$。 这些是包含交换元素的候选列。 
4. 根据单次交换的性质，恰好两行和两列将是不正确的。 打电话给他们$r_1, r_2$和$c_1, c_2$。 这是因为每个交换的单元格只影响一行和一列。 
5. 考虑四个交叉单元：$(r_1,c_1), (r_1,c_2), (r_2,c_1), (r_2,c_2)$。 这些是唯一可能包含交换值的位置。 
6. 尝试交换这四个候选值中任意对的值，并检查行和列的总和是否都等于$S$。 恰好一次交换就能满足这个条件。 
7. 输出有效对的坐标。 

### 为什么它有效

 每个交换的单元格都会对一行总和和一列总和产生附加误差。 由于正好有两个交换的单元格，因此受影响的行和列的数量不能超过两个，并且不能少于两个，除非两个交换的单元格位于同一行或列中，这仍然会产生与相同交集逻辑一致的恰好一个行或列不平衡模式。 此限制迫使所有不正确的结构集中在最多四个坐标中，并且没有其他单元格可以独立影响总和。 因此，限制对异常行和列的交集的关注足以唯一地恢复原始交换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [list(map(int, input().split())) for _ in range(n)]

    S = n * (n * n + 1) // 2

    row_sum = [0] * n
    col_sum = [0] * n

    for i in range(n):
        for j in range(n):
            v = a[i][j]
            row_sum[i] += v
            col_sum[j] += v

    bad_rows = [i for i in range(n) if row_sum[i] != S]
    bad_cols = [j for j in range(n) if col_sum[j] != S]

    if len(bad_rows) == 1:
        bad_rows.append(bad_rows[0])
    if len(bad_cols) == 1:
        bad_cols.append(bad_cols[0])

    r1, r2 = bad_rows[0], bad_rows[1]
    c1, c2 = bad_cols[0], bad_cols[1]

    def check_swap(x1, y1, x2, y2):
        # simulate swap effect locally by computing affected rows/cols
        rs = row_sum[:]
        cs = col_sum[:]

        v1 = a[x1][y1]
        v2 = a[x2][y2]

        rs[x1] += v2 - v1
        rs[x2] += v1 - v2
        cs[y1] += v2 - v1
        cs[y2] += v1 - v2

        return all(rs[i] == S for i in range(n)) and all(cs[j] == S for j in range(n))

    candidates = [
        (r1, c1, r2, c2),
        (r1, c2, r2, c1)
    ]

    for x1, y1, x2, y2 in candidates:
        if check_swap(x1, y1, x2, y2):
            print(x1 + 1, y1 + 1)
            print(x2 + 1, y2 + 1)
            return

solve()
