 ## 解决方案
 ## 问题理解

 该问题描述了一个包含艺术品的走廊。 每件作品都有一个旧的标识符，有些作品是双胞胎，因为它们共享相同的标识符。 新标识符必须准确保留这些组：具有相同旧标识符的两个作品必须仍然具有相同的新标识符，而两个不同的旧标识符必须接收不同的新标识符。 

走廊里的作品顺序不能改变。 检查员从左到右读取新的标识符，当较早的作品比较晚的作品具有更大的标识符时，一对位置被认为是不好的。 任务是分配新的标识符，以使反转次数尽可能少。 任何具有最少反转次数的分配都被接受。 

关键限制是每个旧标识符最多出现两次。 所有测试用例的工作总数最多为$10^5$，因此解必须接近线性。 对整个数组进行排序是可以接受的，但比较每对作品则不可以。 二次方法将达到大约$10^{10}$最大输入的操作，远远超出了典型的一秒限制。 

棘手的情况来自于出现在不同位置的重复标识符。 粗心的解决方案可能只根据第一次出现或根据旧代码的数值来分配标识符，但分组固定后原始值没有任何意义。 

例如：```
1
3
3 2 1
```正确的输出可以是：```
1 2 3
```保留原始值的解决方案将输出`3 2 1`，产生不必要的反转。 旧的标签只描述哪些作品是双胞胎。 

另一种情况是：```
1
4
2 1 1 2
```正确的输出可以是：```
1 2 2 1
```这两对必须保持在一起。 给予第一`2`与第二个不同的值`2`会违反双胞胎的要求。 

## 方法

 直接方法将尝试组的所有可能的排序，并根据该排序分配新的编号。 这个想法是正确的，因为一旦将组按递增顺序放置，倒置就会最小化。 然而，对于许多不同的组，尝试所有订单都是阶乘的，并且立即变得不可能。 

更实用的强力方法是在尝试不同的任务时重复计算反转。 即使我们只考虑一小部分可能的分配，计算所有对也需要$O(n^2)$工作。 和$n = 10^5$，这大约是$10^{10}$比较。 

重要的观察是我们不需要搜索作业。 每个旧标识符代表一个不可分割的群体。 如果我们选择这些组的排序，并按该顺序分配连续的新编号，则组之间的反转计数仅取决于走廊中这些组的相对顺序。 为了最大限度地减少倒置，组应根据其首次出现的顺序从左到右以新的编号顺序显示。 

想象一下扫描走廊。 遇到的第一个新组应该收到代码`1`，因为在它之前放置任何其他组都会在第一次出现时产生反转。 下一个看不见的组应该收到下一个代码，依此类推。 重复出现会重复使用已分配给该组的代码。 

这是有效的，因为每个组都可以被视为单个对象。 将较小的代码分配给首次出现较早的组不会比与首次出现较晚的组交换它产生更多的反转。 重复这个交换论证会导致第一次出现的顺序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 创建从旧代码到新代码的空映射。 该映射代表保留的双胞胎群体。 相同旧代码的每次出现都必须接收相同的值。 
2. 从左到右扫描作品。 当旧代码第一次出现时，为其分配下一个可用的新代码。 这遵循团体在走廊中自然出现的顺序。 
3. 当旧代码再次出现时，重新使用之前分配的新代码。 第二次出现不会影响排序，因为它的组已被放置。 
4. 按照原来的走廊顺序输出分配的代码。 

为什么它有效：

 每个组的第一次出现决定了该组可以影响反转的最早位置。 假设两个组 A 和 B 首次出现，其中 A 出现在 B 之前。为 B 分配比 A 更小的新代码将在这些首次出现之间创建反转。 交换它们的新代码可以消除这种倒置，并且不会损害任何涉及后续事件的配对，因为一个组的所有成员都会一起移动。 重复应用此参数意味着最佳排序恰好是组的第一次出现顺序。 该算法精确地分配了该顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        mapping = {}
        nxt = 1
        res = []

        for x in a:
            if x not in mapping:
                mapping[x] = nxt
                nxt += 1
            res.append(mapping[x])

        ans.append(" ".join(map(str, res)))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```字典存储旧标识符和新标识符之间的关系。 第一次出现某个值时，代码会分配下一个数字。 这是唯一需要做出决定的时刻。 

扫描顺序是主要的实现细节。 如果首先对数组进行排序，则原始走廊顺序将丢失，并且生成的分配可能会增加反转。 该算法只会重新标记，而不会重新排列作品。 

变量`nxt`从 1 开始，因为所有新标识符都必须为正数。 这里自然使用Python整数，因此不存在溢出问题。

 ## 边缘情况

 对于：```
1
3
3 2 1
```该算法从一个空地图开始。 它看到`3`首先并分配代码`1`， 然后`2`接收代码`2`， 和`1`接收代码`3`。 结果是`1 2 3`，这会删除原始标签创建的反转。 

为了：```
1
4
2 1 1 2
```第一个`2`接收代码`1`，以及第一个`1`接收代码`2`。 When the algorithm reaches the third position, it finds that`1`地图中已存在，因此它重用代码`2`。 决赛`2`还重用了代码`1`。 结果使两对双胞胎完好无损。 

为了：```
1
5
7 7 7 7 7
```只有一组。 第一个位置创建唯一的映射条目，后面的每个位置都重用它。 输出是：```
1 1 1 1 1
```没有其他作业可以改善这一点，因为没有单独的组可以重新排序。
