 ## 解决方案
 ## 问题理解

 任务是构造一个长度排列\(n > 1\)使得没有元素占据其原始位置。 换句话说，对于一个排列\(p\)尺寸的\(n\)，我们要求\(p_i \ne i\)对于每个索引\(i\)。 每个测试用例由一个整数组成\(n\)，输出应该是一个序列\(n\)形成满足规定条件的有效排列的整数。 

限制是适度的：\(n\)最多可以是 100 个，并且最多有 100 个测试用例。 这意味着任何 \(O(n^2)\) 方法都足够快，尽管线性时间解决方案是可能的。 主要的边缘情况发生在\(n\)是最小的，特别是\(n = 2\)，其中只有一种可能的混乱：交换两个数字。 对于较大的\(n\)，有多个有效排列，因此解决方案可以是建设性的，并且不需要搜索或优化。 

简单地随机化数字的简单方法可能会失败，因为它可能会意外地将一些数字放置在其原始位置，并且验证它需要检查每个排列。 考虑到问题的简单性，这将变得不必要的复杂。 

## 方法

 蛮力方法是生成所有长度的排列\(n\)并测试每个元素以确保没有元素处于其原始位置。 虽然正确，但这种方法的复杂度为阶乘，\(O(n!)\)，并且即使对于\(n = 10\)。 

关键的观察结果是，将所有元素简单循环移位一个位置即可为所有元素生成有效的排列。\(n > 1\)。 具体来说，将第一个元素放在第二个位置，第二个元素放在第三个位置，...，最后一个元素放在第一个位置，可以保证没有元素保留在其原始位置。 这是一种线性时间构造方法，并且有效地满足所有约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力（所有排列）| O(n!) | O(n) | 太慢了|
 | 循环移位| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量，\(t\)。 
2. 对于每个测试用例：
 1.读取整数\(n\)，排列的长度。 
2. 生成从 1 到 的整数列表\(n\)。 
3. 通过执行循环移位构建排列：将第一个元素移至末尾，并将所有其他元素向左移动一个位置。 
4. 将生成的排列打印为空格分隔的字符串。 

为什么它有效：通过将每个元素向左移动一个位置并将第一个元素移动到末尾，每个数字\(i\)从位置移动\(i\)到位置 \((i-1 \mod n) + 1\)。 这保证了没有元素保留在其原始位置，这满足了所有问题的要求\(n > 1\)。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        perm = list(range(1, n + 1))
        # cyclic shift: first element moves to the end
        perm = perm[1:] + perm[:1]
        print(' '.join(map(str, perm)))

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量，然后迭代每个测试用例。 它构建了一个从 1 到\(n\)并立即应用循环移位，这是生成有效混乱的最简单方法。 打印作为空格分隔的字符串完成，确保格式正确。 使用`sys.stdin.readline`确保最大数量的测试用例的快速输入处理。

 ## 边缘情况

 最小的\(n = 2\)案件`[1,2]`变成`[2,1]`随着循环移位。 最大\(n = 100\)案例使用相同的原理； 第一个元素移动到末尾，所有其他元素向左移动，这保证没有元素保留在其原始位置。 奇数、偶数和最大尺寸输入都遵循相同的线性移位逻辑，以确认正确性。
