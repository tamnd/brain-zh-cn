 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，目标是通过重复删除不包含所选值的连续段来使所有元素相等$x$。 的选择$x$至关重要，因为一旦我们选择它，它就无法改变。 操作受到限制，任何删除的段都必须不含$x$，并且每次删除都会折叠序列以缩小间隙。 每个测试用例的输出是留下完全由以下内容组成的序列所需的此类删除操作的最小数量$x$。 

输入约束允许$n$最多$2 \cdot 10^5$和$t$最多$2 \cdot 10^4$，总和为$n$所有测试用例的上限也为$2 \cdot 10^5$。 这排除了任何检查所有子段或显式尝试每个可能的操作序列的解决方案，因为此类方法将以二次或三次时间运行。 该解对于每个序列的大小必须是线性的或接近线性的。 

当出现不明显的边缘情况时$x$出现稀疏或已经在阵列中占据主导地位。 例如，如果序列是`[1, 2, 1, 2, 1]`我们选择$x = 1$，那么每个段`[2]`可以单独删除，需要进行三个操作。 如果不仔细考虑先前删除所造成的间隙，则每次删除最大段的天真贪婪策略可能会多算或少算。 类似地，如果所有元素都相等，则需要零次操作，如果算法假设至少有一次删除，则可以忽略这一点。 

## 方法

 暴力方法会尝试每个候选人$x$并模拟删除所有有效段，直到仅$x$遗迹。 我们将从左到右扫描，重复查找不包含的连续块$x$并删除它们。 这可以正常工作，但可能需要多次检查每个块。 在最坏的情况下，如果序列交替$x$和其他元素，每个元素可以是单独操作的一部分，产生$O(n^2)$计算所有候选人时的行为$x$。 和$n$最多$2 \cdot 10^5$，这太慢了。 

关键的观察是对于固定的$x$，我们可以计算移除操作的数量，而无需模拟它们。 每个操作都会删除一个连续的非$x$值，并且因为移除破坏了序列，所以连续的非$x$值之间用$x$可以在一次操作中删除。 因此，操作的数量就是连续非“间隙”的数量。$x$值，但有一个问题：每次操作后，我们必须跳过至少一个位置才能到达下一个非$x$由于倒塌而阻塞。 这导致了对数计数：从大小间隙开始$k$，它可以被删除`ceil(log2(k+1))`如果我们总是删除之间的最大段操作$x$s。 一种更简单且足够的方法是从左到右扫描，每次遇到连续的非连续块时递增操作计数器。$x$值，然后跳过一步来模拟崩溃。 我们对每个候选人重复这一点$x$并选择$x$最大限度地减少操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了|
 | 贪婪计数非 x 块 | O(n * 唯一元素) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，首先识别序列中的所有不同值。 每个不同的值都是一个候选值$x$。 
2. 对于每位候选人$x$，将操作计数器初始化为零。 如果解决这个问题，我们将计算需要多少移除量$x$。 
3. 从左到右扫描序列。 每次我们遇到一个不等于的值$x$，开始计算此类值的连续块。 将此块的操作计数器加一。 
4. 数完一个块后，跳过下一个元素$x$（如果存在）模拟因移除而导致的崩溃，然后继续扫描以查找下一个块。 这确保了我们不会重复计算由单个分隔的段$x$。 
5. 跟踪所有候选者的最小操作数$x$。 处理完所有候选后，最小计数就是测试用例的答案。 

为什么有效：每次删除操作都可以消除整个连续的非$x$价值观。 因为段包含$x$无法删除，连续非的每个段$x$值之间用$x$s 至少需要一项操作。 该算法正确地计算这些最小片段，同时通过跳过$x$每次操作后。 扫描每位候选人$x$确保我们选择能够最大限度减少操作的选项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations(a):
    candidates = set(a)
    res = float('inf')
    for x in candidates:
        ops = 0
        i = 0
        n = len(a)
        while i < n:
            if a[i] != x:
                ops += 1
                while i < n and a[i] != x:
                    i += 1
            else:
                i += 1
        res = min(res, ops)
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_operations(a))
```功能`min_operations`迭代每个候选者$x$在序列中。 它对每个候选者扫描一次序列，计算连续的非候选块$x$值并通过在处理块后跳过元素来模拟移除。 外循环处理多个测试用例。 使用`set`对于候选者，确保我们不处理重复值，将时间复杂度保持在可接受的范围内。 内部 while 循环通过确保每个非$x$段只计算一次。
