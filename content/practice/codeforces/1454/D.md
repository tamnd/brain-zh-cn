 ## 解决方案
 ## 问题理解

 我们得到一个整数$n$，我们希望将其分解为一系列大于 1 的整数。这些整数不是任意因子，而是受到整除链的约束：下一个数字必须能被前一个数字整除。 同时，如果我们将序列中的所有数字相乘，我们必须恢复原始值$n$。 在所有有效序列中，我们想要具有最大可能长度的序列。 

思考这个问题的一个有用方法是，我们正在构建一个从某个基数开始的乘法链$a_1$，并且每个下一个元素都通过添加更多素因数来扩展它，而不删除结构。 因为每个元素都除下一个元素，所以序列只能通过“累积”因子来增长。 

约束的值很大，最多$10^{10}$每次测试，最多可进行 5000 次测试。 这强烈表明，任何依赖于重复因式分解或贪婪构造的解决方案在理想情况下都必须对每个数字都是有效的$O(\sqrt{n})$或更好地摊销。 

天真的误解常常来自于试图将其视为任意因素划分。 例如，对于$n = 12$，人们可以尝试这样的序列$2, 3, 2$或者$2, 6$，但整除条件阻止了许多重新排列。 另一个微妙的失败是假设分裂成素数的顺序总是最优的。 它忽略了每一步必须除下一步的要求，而不仅仅是乘以$n$。 

真正的边缘情况出现时$n$是素数幂，例如$2^{10}$。 在这里，最佳答案不是任意分裂，而是非常结构化的双链。 任何贪婪的“重复取最小因子”方法都必须仔细确保它在每一步都保持可整性有效，否则它会提前崩溃并错过最大长度。 

## 方法

 暴力策略会尝试构建所有有效的序列。 可以从任何除数开始$n$，然后通过选择保留总乘积约束和可分链的较大倍数来递归扩展序列。 这本质上是探索一棵树，其中每个状态都是部分序列，下一个状态选择有效的扩展。 

正确性很简单，因为它枚举了所有可能性，但分支因子很大。 即使对于中等$n$，除数的数量可能很大，并且每次扩展都需要检查整除性和剩余因子可行性。 在最坏的情况下，素因数的数量呈指数增长。 

关键的观察结果是，可分性条件迫使结构非常严格：每个$a_i$必须通过将先前的值乘以某个整数来获得。 该整数必须整除$n / a_i$，并且为了最大化长度，我们希望在仍然有效的情况下使每个乘法尽可能小。 

这立即表明了一种贪婪的方法：因子$n$分解为素数，然后尽可能在每一步取一个素因子来构造一条链。 尽可能长的链对应于重复地逐个剥离单个素因子，因为每一步只能通过乘以至少一个素因子来增加，并且尽可能晚地分裂因子可以最大化步数。 

最优结构是：计算素因数分解$n = \prod p_i^{e_i}$。 最大长度是用重数计算的素数因子总数减去与分组相关的东西，但更直接的是，我们构建一个链，在该链中逐步乘以素数，在每一步重用最小的可用结构。 

一种更清晰的解释是：我们想要一个链，其中每个步骤只要有可能就添加一个素因子。 这导致从最小除数（通常是素数）开始构建一个序列，并以受控顺序重复乘以素数。

 ## 算法演练

 我们依靠素因数分解，然后从这些因子构建最长的有效乘法链。 

1. 因式分解$n$化为素数。 我们存储每个素数及其指数，因为重数直接决定了我们可以延长链的次数。 
2. 将所有素数因子收集到一个列表中，根据其指数重复每个素数。 这为我们提供了一组必须全部出现在构造中的原子“构建步骤”。 
3. 对素数列表进行排序。 排序并不是严格要求正确性的，但它确保了确定性的构造，并帮助我们始终如一地首先选择最小的扩展，这与最大化链长度保持一致。 
4. 隐式地从 1 开始构建序列，但由于所有$a_i > 1$，我们首先将第一个素数作为$a_1$。 
5. 迭代地将前一个值乘以下一个未使用的素因数。 每次乘法都会产生序列中的下一个元素。 
6. 当所有质因数都被恰好使用一次时停止。 所得序列长度等于质因数的数量。 

这个微妙的步骤就是为什么我们可以安全地一一使用每个素因数。 每个$a_i$划分$a_{i+1}$因为我们只是乘以一个整数，剩下的乘积仍然完成$n$。 该结构确保没有因素被跳过或错误地重复使用。 

### 为什么它有效

 在每一步中，当前值都是素数多重集的子集的乘积$n$。 移动到下一个元素相当于从该多重集中添加一个额外的质因数。 这保证了整除性，因为乘法只会增加素因数分解中的指数，而不会减少它们。 由于所有素数最终都会被消耗，因此通过使用每个可用素数因子作为单独的步骤来最大化链长度，并且任何有效序列都不能超过此长度，因为每个步骤必须引入至少一个素数因子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def factorize(n):
    factors = []
    p = 2
    while p * p <= n:
        while n % p == 0:
            factors.append(p)
            n //= p
        p += 1
    if n > 1:
        factors.append(n)
    return factors

t = int(input())
for _ in range(t):
    n = int(input())
    primes = factorize(n)
    primes.sort()

    # build chain
    res = []
    cur = 1
    for p in primes:
        cur *= p
        res.append(cur)

    print(len(res))
    print(*res)
```因式分解循环提取素数$O(\sqrt{n})$，考虑到总约束和界限，这就足够了$n$。 排序列表确保了一致的顺序，尽管任何顺序的素数相乘仍然会产生有效的链。 

该构造从隐式值 1 开始，但由于该问题要求所有元素都大于 1，因此第一个乘法立即产生有效的$a_1$。 每个后续值都保证能被前一个值整除，因为它是通过乘以一个附加整数而形成的。 

一个常见的实施错误是忘记增量累积乘积，而是从头开始重新计算，这可能会导致不必要的开销或精度问题。 另一个微妙的问题是对大于的大素数处理不当$\sqrt{n}$，必须附加在循环之后。

 ## 边缘情况

 一个主要输入，例如$n = 13$产生一个单元素序列。 该算法进行因式分解并且找不到小除数，因此因数列表仅包含 13。构造步骤不会产生中间乘法，并且输出正确反映了最大长度 1。 

对于像这样的主要力量$n = 8$，因式分解给出$[2,2,2]$。 算法构建$2 \rightarrow 4 \rightarrow 8$，每一步乘以下一个素因数。 可整除条件在每一步都成立，因为每个值严格来说都是同一多重集的前缀积。 

对于像这样的混合复合材料$n = 360$，所有因素都被一一消耗。 即使存在不同的顺序，素数乘法的任何顺序都保持有效性，因为乘法是可交换的，并且前缀积属性确保每次转换时的整除性。
