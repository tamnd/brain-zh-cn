 ## 解决方案
 ## 问题理解

 我们被要求确定简化的“独特投标拍卖”的获胜者。 每个参与者选择一个数字，获胜者是选择了其他人没有选择的数字的参与者，并且该数字是所有此类唯一数字中最小的。 如果没有唯一的数字，则结果为 -1。 输入提供了多个测试用例，每个测试用例都有多个参与者及其选择的数字，我们必须为每个用例返回获胜参与者的从 1 开始的索引。 

这些限制是至关重要的。 每个参加人数最多为`n`，并且最多可以有`2·10^5`所有测试用例的参与者。 这排除了任何比较每对数字的解决方案（`O(n^2)`），因为在最坏的情况下，这可能需要`4·10^10`操作，这远远超出了一秒钟可以运行的范围。 理想情况下，我们需要每个测试用例有一个线性或近线性解决方案`O(n)`。 

非明显的边缘情况包括所有数字都是重复的、存在单个参与者或最小的数字重复但稍大的数字是唯一的情况。 例如，对于输入`[1,1,2]`, 获胜者是选择的参与者`2`， 不是`1`， 因为`1`并不独特。 类似地，如果所有数字都是`[1,1,2,2]`，没有赢家。 这些很微妙，因为只寻找最小数字而不检查唯一性的天真方法将会失败。 

## 方法

 蛮力方法很简单：对于每个数字，计算它出现的次数，然后扫描所有数字以找到恰好出现一次的最小数字。 计数可以通过嵌套循环或重复扫描来完成。 这是正确的，因为它明确地实现了问题定义。 然而，它太慢了。 计算每个数字的频率`O(n)`扫描每个测试用例的结果`O(n^2)`每个测试用例，这对于上限是不可接受的`n`。 

关键的见解是我们只需要每个数字的频率，而不是它在第一次扫描期间的位置。 我们可以使用字典将数字映射到其出现次数。 一旦我们有了频率图，我们就可以过滤出只出现一次的数字，并选择其中的最小值。 然后，对原始列表进行一次遍历即可识别获胜者的从 1 开始的索引。 这种方法是线性的：一次构建计数图，一次查找索引，`O(n)`每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个空字典来统计每个数字的出现次数。 
2. 迭代参与者号码，增加字典中每个号码的计数。 这将创建每个数字出现次数的频率图。 
3. 找出所有恰好为 1 的数字。 如果没有这样的数字，则立即为此测试用例返回 -1。 
4. 找出这些唯一数字中最小的数字。 这是中奖号码。 
5. 迭代原始号码列表并找到第一次出现中奖号码的索引。 由于中奖号码是唯一的，因此这种情况只会出现一次。 
6. 输出索引，调整为从 1 开始的索引。 

为什么它有效：字典确保准确的频率计数，并且扫描最小的唯一数字保证我们遵循问题的规则。 因为我们随后扫描该数字的索引，所以我们正确地将值映射回参与者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        count = {}
        for num in a:
            count[num] = count.get(num, 0) + 1
        # collect unique numbers
        unique_numbers = [num for num, freq in count.items() if freq == 1]
        if not unique_numbers:
            print(-1)
            continue
        winner_value = min(unique_numbers)
        # find 1-based index
        for i, num in enumerate(a):
            if num == winner_value:
                print(i + 1)
                break

if __name__ == "__main__":
    main()
```代码首先读取测试用例的数量。 对于每种情况，它都会读取参与者的数量及其数量。 这`count`字典存储每个数字的出现频率。 列表理解过滤掉唯一的数字。 如果没有唯一的数字，我们输出-1。 否则，我们找到最小的唯一数字并扫描原始数组以找到参与者的索引。 使用`enumerate`通过向循环索引添加 1 来确保基于 1 的索引是简单的。

 ## 边缘情况

 如果输入仅包含一名参与者，例如，`[1]`，该算法正确计算一次出现，将其识别为唯一，并返回索引 1。对于全相等数组，例如，`[5,5,5,5,5]`，频率图没有计数 1 的值，触发输出 -1。 如果最小的唯一数字位于数组末尾，例如，`[2,3,3,2,1]`，算法正确识别`1`作为获胜者并找到其索引。 这些边缘情况确认该算法正确处理边界、单个元素、重复项和数组位置。
