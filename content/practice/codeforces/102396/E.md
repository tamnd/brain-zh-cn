 ## 解决方案
 ## 问题理解

 给定一个非零三元向量 a，其中每个 a i ​ 为 −1、0 或 1。我们必须构造另一个整数数组 x 和模数 m，使得在所有非零三元向量 c 中，整除条件

 i=1 Σ n ​ c i ​ x i ​ ≡0(modm)

 恰好两个向量成立，即指定向量 a 及其负向量 -a。 构造本身就是答案，因此不需要处理输入模数或数组 x。 

限制 n≤30 是中心数值限制。 它允许 2 到 2 29 的幂，这仍然严格低于每个 x i 所需的 2 30 界限。 同时，模数必须小于2 n，因此基于二进制数2 n -1 的构造是特别自然的。 暴力破解所有三元向量将需要 3 n -1 个候选，当 n=30 时，这大约是 2.06×10 14 个候选。 即使在恒定时间内检查每个候选者也是没有希望的，并且在 O(n) 中检查其点积更糟糕。 

粗心的构造可能会错误处理两种边缘情况。 例如，与```
1
1
```唯一的非零三元向量是 1 和 −1，因此 m=1, x 1 ​ =1 已经有效。 坚持 m>1 的构造在这里将不必要地失败。 

目标向量中的零更加微妙。 为了```
2
1 0
```我们必须将 (1,0) 与 (1,1) 和 (1,−1) 区分开来。 简单地设置 x i ​ =a i ​ 2 i 即可得到 x 2 ​ =0，这使得第二个系数的每个选择都变得无关紧要，并产生许多不需要的解决方案。 该结构必须赋予零位置自己的权重，同时仍然防止它们参与可整除的总和。 

官方问题允许任何有效的构造，不一定是示例构造。 

## 方法

 直接方法是枚举除全零向量之外的每个向量 c∈{−1,0,1} n，计算 Σc i ​ x i ​，并测试可被 m 整除。 这样的向量正好有 3 n -1 个。 对于n=30，这大约是2.06×10 14 种可能性，因此暴力破解是完全不可行的。 

有用的观察是我们实际上不需要搜索 x。 系数集 {−1,0,1} 与 2 的幂相互作用非常清晰。 如果我们给坐标权重 1,2,4,…，每个有符号和都有一个严格的二进制结构。 特别是，使用权重 1,2,…,2 k−1 上的 {−1,0,1} 中的系数获得 2 k −1 的唯一方法是将每个系数用作 +1，而获得其负值的唯一方法是将每个系数用作 −1。 

剩下的困难是一些目标系数可能为零。 诀窍是按幅度将零位置与非零位置分开。 为所有零位置赋予 2 的最小幂，并为所有非零位置赋予较大幂。 然后目标向量恰好使用所有较大的权重，因此其点积成为精心选择的模数。 

令 z 为零条目的数量，k=n−z 为非零条目的数量。 为零位置分配权重

 1,2,…,2 z−1 ,

 并分配非零位置

 2 z ,2 z+1 ,…,2 n−1 。 

对于非零目标条目，将其分配的权重乘以 a i ​，因此目标符号直接构建到 x i ​中。 对于零目标条目，请使用分配的正权重。 

那么目标点积是

 a i ​  =0 Σ ​ a i ​ (a i ​ 2 j )= j=z Σ n−1 ​ 2 j =2 n −2 z 。 

我们选择这个值作为m。 它是正数，因为 k≥1，并且根据要求它小于 2 n。 

构造有效是因为任何三元组合的总绝对值最多为

 1+2+⋯+2 n−1 =2 n −1。 

我们的模数满足 m≥2 n−1，因此此范围内 m 的唯一可能的倍数是 0、m 和 −m。 然后，低 z 位迫使每个零位置系数消失，之后剩余的问题简化为 2 k -1 的唯一二进制表示。

 ## 算法演练

 1. 计算目标向量中有多少个条目为零。 设这个数为z。 其他 k=n−z 条目非零，且 k≥1。 
2. 设置

 m=2 n -2 z 。 

这正是功率 2 z ,2 z+1 ,…,2 n−1 的总和，这将是分配给非零目标位置的权重。 由于 k≥1，所以 m≥1，并且显然 m<2 n。

1. 遍历目标数组。 对于每个零条目，分配下一个未使用的二的低幂，从 1 开始。因此零位置接收 2 0 ,2 1 ,…,2 z−1 。 
2. 对于每个非零条目 a i ​，分配下一个未使用的 2 的高次幂并将其乘以 a i ​。 因此，目标值1获得正权重，目标值-1获得相应的负权重。 
3. 得到的目标点积正好是 m。 它的否定具有点积−m，因此两个规定的解决方案都是有效的。 
4. 考虑满足整除条件的任何非零三元向量 c。 其绝对点积至多为2 n −1，而m≥2 n−1。 因此它的点积必须是 0,m,−m 之一。 
5. 如果点积为零，则查看系数非零的两个的最大幂。 该功率严格大于所有较小功率的总和，因此消除是不可能的。 因此，每个系数都必须为零，这与 c 非零的要求相矛盾。 
6. 假设点积为 m 或 −m。 以 2 z 为模简化方程。 每个高权重都可以被 2 z 整除，而零位置权重恰好是 1,2,…,2 z−1。 它们的带符号和的绝对值低于 2 z，因此它实际上必须等于 0。 有符号二进制表示的唯一性迫使零目标位置上的每个系数都为零。 
7. 去除那些零位置并将剩余方程除以 2 z 后，权重变为 1,2,…,2 k−1，所需的绝对和为 2 k −1。 唯一可能的三元表示是全+1，或全-1，具体取决于原始和的符号。 撤销 x i​中存储的符号，唯一的解是 a 和 −a。 

### 为什么它有效

 关键的不变量是，2 的低幂专门属于所需答案为零的坐标，而每个非零目标坐标接收 2 z 的倍数。 任何可整除的组合必须首先使其低部分等于零，迫使所有零目标系数消失。 剩余的高次幂形成一个完整的二元序列，其唯一的三元表示 2 k −1 和 −(2 k −1) 是全正和全负选择。 x i 中存储的符号将这些选择精确地转换为 a 和 −a。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    z = a.count(0)

    # Sum of powers 2^z, ..., 2^(n-1).
    m = (1 << n) - (1 << z)

    x = [0] * n

    low_power = 0
    high_power = z

    for i in range(n):
        if a[i] == 0:
            x[i] = 1 << low_power
            low_power += 1
        else:
            x[i] = a[i] * (1 << high_power)
            high_power += 1

    print(m)
    print(*x)

if __name__ == "__main__":
    solve()
```第一行`solve`读取目标向量，并且`z`记录有多少个坐标最终必须具有零系数。 该计数确定了两个的低幂和高幂之间的边界在哪里。 

模量计算如下`(1 << n) - (1 << z)`。 This is the sum of every power from 2 z through 2 n−1, so it is exactly the absolute dot product obtained by the desired vector.

 The two counters have different roles.`low_power`从零开始，仅用于目标零。`high_power`开始于`z`并且仅用于非零目标条目。 因此，这两个组占据不相交的二进制位置范围。 

对于非零`a[i]`，表达式`a[i] * (1 << high_power)`将所需的符号直接存储到`x[i]`。 如果目标系数为-1，则对应的`x[i]`是负数。 当学生选择目标系数−1时，他们的乘积与`x[i]`为正，将所需的 2 次幂贡献给目标总和。 

最大指定绝对值为 2 n−1。 由于 n≤30，因此最多为 2 29，严格低于 2 30。Python 整数也具有任意精度，因此不存在溢出问题。 

不存在多个测试用例循环，因为原始输入仅包含一个实例。 该构造仅使用整数移位和一次线性遍历数组。

    out = solution(inp).split()
    data = list(map(int, out))

    a = list(map(int, inp.split()[1:n + 1]))

    x = data[1:]

    assert 1 <= m < (1 << n)

        if s % m == 0:
            found.append(c)

    expected = {tuple(a), tuple(-v for v in a)}
    assert set(found) == expected

    return out
