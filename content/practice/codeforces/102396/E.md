 ## 解决方案
 ## 问题理解

 给定一个长度为 (n) 的目标向量 (a)，其中每个坐标都是 (-1)、(0) 或 (1)，并且至少有一个坐标非零。 我们必须构造另一个整数向量 (x) 和模数 (m)，使得在所有非零向量 (b\in{-1,0,1}^n) 中，同余

 [
 \sum_{i=1}^{n} b_i x_i \equiv 0 \pmod m
 ]

 对于两个向量成立，即 (b=a) 和 (b=-a)。 

困难在于我们没有被要求找到固定 (x) 和 (m) 的解。 我们正在设计 (x) 和 (m)，以便规定的向量成为改变每个符号的唯一解决方案。 

界限 (n\le 30) 是关键的数值约束。 它允许我们使用涉及 2 的幂 (2^{29}) 的数字，这些数字仍然在每个 (x_i) 的允许范围内。 同时，模数必须严格小于(2^n)，因此我们不能简单地使用与任意独立构造的乘积一样大的模数。 下面的结构通过将坐标分成两个独立的模块化系统来精确获得所需的空间量。 

有两种边缘情况值得特别注意。 如果 (a) 恰好有一个非零坐标，则假设输入为```
3
0 -1 0
```我们不能使用 (2^k-1) 的一般结构，因为 (k=1) 会给出模 (1)，并且每个整数都可以被 (1) 整除。 相反，我们使用 (m=2^n-1)，输入 (x_2=-m)，并赋予其他坐标幂 (1,2)。 它们的带符号和的绝对值小于 (m)，因此它们不能创建另一个非零解。 

第二种边缘情况是没有零坐标时。 例如，```
3
1 -1 1
```施工仍在进行。 该结构的零坐标部分完全消失，因此其相应的模因子为（1）。 然后，两个模 (2^n-1) 的幂强制目标向量及其负值。 

## 方法

 直接方法会枚举每个可能的学生答案 (b)。 每个坐标有三个选择，因此有 (3^n-1) 个非零候选。 对于每个候选者，我们可以计算标量积并检查整除性。 这是正确的，因为它确实检查了每个可能的答案，但对于 (n=30) 它需要大致

 [
 3^{30}\约2.06\cdot 10^{14}
 ]

 候选向量，远远超出了时间限制。 

有用的观察是我们控制 (x) 和 (m)。 我们可以通过不同的模数因子使不同组的坐标可见。 假设(a)的(k)坐标非零且(z=n-k)坐标为零。 对于 (k\ge2)，选择

 [
 M_1=2^k-1,\qquad M_2=2^z,
 ]

 并使用

 [
 m=M_1M_2。 
]

 由于 (M_1<2^k)，我们有

 [
 m=(2^k-1)2^z<2^{k+z}=2^n。 
]

 非零坐标将是 (M_2) 的倍数，因此它们以 (M_2) 为模消失。 零坐标将是 (M_1) 的倍数，因此它们以 (M_1) 为模消失。 然后，单一整除条件模 (m=M_1M_2) 分为两个独立条件。 

对于非零坐标，二次方给出了关键的唯一性。 如果为 (k) 个非零坐标指定幂 (1,2,\ldots,2^{k-1})，则

 [
 1+2+\cdots+2^{k-1}=2^k-1=M_1。 
]

 因此，所需的向量恰好产生 (M_1)。 任何其他产生 (M_1) 倍数的向量实际上必须产生 (0)、(M_1) 或 (-M_1)，因为绝对值最多为 (M_1)。 二进制表示的普通唯一性则迫使系数向量为 (0)、全部为 (1) 或全部为 (-1)。 

对于零坐标，二模 (2^z) 的幂具有不同的有用属性。 他们的绝对有符号和最多是

 [
 1+2+\cdots+2^{z-1}=2^z-1,
 ]

 它严格小于 (2^z)。 因此，只有当有符号和恰好为零时，它才能被 (2^z) 整除。 然后，二进制唯一性迫使每个零坐标系数为零。 

暴力方法之所以有效，是因为可能的向量集是有限且明确的，但它会失败，因为该集的大小为 (3^n)。 通过观察模数可以因式分解，我们可以用两个基于二进制表示的唯一性参数来替换一次大型搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(3^nn)) | (O(3^nn)) | (O(n)) | (O(n)) | 太慢了 |
 | 最佳| (O(n)) | (O(n)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 计算(a)的非零条目的数量(k)，并令(z=n-k)。 我们将使用非零坐标对规定的符号进行编码，并使用零坐标来创建一个独立的约束来防止它们发生变化。 
2. 如果(k=1)且(n=1)，则输出(m=1)且(x_1=1)。 唯一的非零选择是 (1) 和 (-1)，因此两者且只有这些选择满足整除条件。 
3. 如果(k=1)且(n>1)，则选择(m=2^n-1)。 将 (x_j=a_jm) 置于唯一的非零坐标 (j) 处。 以任意顺序为剩余坐标分配幂 (1,2,\ldots,2^{n-2})。 所需的坐标贡献 (\pm m)，而其他坐标的每个有符号组合最多具有绝对值 (2^{n-1}-1<m)。 因此，任何解中的其他坐标都必须为零，并且唯一的非零坐标必须为 (1) 或 (-1)。 
4. 对于 (k\ge2)，定义 (M_1=2^k-1) 和 (M_2=2^z)。 设置（m=M_1M_2）。 不等式 (m<2^n) 直接从 (M_1<2^k) 得出。 
5. 枚举 (a) 的非零位置。 如果第 (r) 个这样的位置包含 (a_i)，则设置

 [
 x_i=a_iM_2 2^r。 
]

 乘以 (M_2) 会使该坐标不可见模 (M_2)，而模 (M_1) 则其行为与带符号的二进制权重 (a_i2^r) 完全相同。 

1. 列举 (a) 的零位置。 对于第 (s) 个这样的位置，设置

 [
 x_i=M_1 2^s。 
]

这些坐标是不可见的模（M_1），而模（M_2）它们形成普通的二进制权重（1,2,\ldots,2^{z-1}）。 

1. 考虑任意候选向量 (b)。 由于 (M_1) 和 (M_2) 互质，因此可被它们的乘积整除等价于可被每个因子整除。 取模 (M_1)，每个零坐标贡献都会消失，只留下非零坐标。 模 (M_2)，每个非零坐标贡献消失，只留下 (a_i=0) 的坐标。 
2. 模 (M_2) 条件强制 (b) 的每个零坐标条目为零。 然后，剩余模 (M_1) 条件表示非零坐标上的系数必须全部为零，全部等于 (a) 的相应条目，或者全部等于它们的负数。 问题排除了全零情况，仅留下 (a) 和 (-a)。 

### 为什么它有效

 中心不变量是两组坐标由互质模因子分开。 属于(a)支撑的坐标是(M_2)的倍数，因此它不能影响(M_2)条件。 支撑之外的坐标是(M_1)的倍数，因此它不会影响(M_1)条件。 因此，零坐标被迫保持为零，而非零坐标则简化为 (0)、(M_1) 或 (-M_1) 的有符号二进制表示。 二进制唯一性准确地给出了三个向量 (0,a,-a)，并且零向量不是允许的学生答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    nonzero = [i for i in range(n) if a[i] != 0]
    zero = [i for i in range(n) if a[i] == 0]

    k = len(nonzero)
    z = len(zero)

    # Special case: n = 1, necessarily k = 1.
    if n == 1:
        print(1)
        print(a[0])
        return

    # Special case: exactly one nonzero coordinate.
    if k == 1:
        m = (1 << n) - 1
        x = [0] * n

        j = nonzero[0]
        x[j] = a[j] * m

        value = 1
        for i in zero:
            x[i] = value
            value <<= 1

        print(m)
        print(*x)
        return

    # General case.
    m1 = (1 << k) - 1
    m2 = 1 << z
    m = m1 * m2

    x = [0] * n

    # Encode nonzero coordinates modulo m1.
    weight = 1
    for i in nonzero:
        x[i] = a[i] * m2 * weight
        weight <<= 1

    # Encode zero coordinates modulo m2.
    weight = 1
    for i in zero:
        x[i] = m1 * weight
        weight <<= 1

    print(m)
    print(*x)

if __name__ == "__main__":
    solve()
```输入首先被划分为 (a) 的支持及其补集。 保留这些索引列表足以分配连续的二进制权重，而无需更改数组的原始顺序。 

(k=1) 分支是必要的，因为主要构造将使用 (M_1=2^1-1=1)，这没有给出有用的模块化限制。 对于 (n=1)，模 (1) 实际上就足够了，因为唯一的非零向量是 (1) 和 (-1)。 

对于一般情况，`m1`是 (2^k-1) 并且`m2`是 (2^z)。 它们的乘积严格小于 (2^n)，完全满足模数限制。 

分配给非零坐标的值乘以`m2`。 分配给零坐标的值乘以`m1`。 这是证明中使用的 CRT 式分离。 

分配给非零坐标的最大值最多为

 [
 2^z 2^{k-1}=2^{n-1},
 ]

 且最大零坐标值小于

 [
 (2^k-1)2^{z-1}<2^{n-1}。 
]

 因此，当 (n\le30) 时，每个 (x_i) 都严格介于 (-2^{30}) 和 (2^{30}) 之间。 Python 整数不会溢出，但构造也保持在原始数值范围内，而不是依赖于 Python 的任意精度。

### 示例 2

 考虑```
4
1 0 -1 0
```这里（k=2）和（z=2）。 因此

 [
 M_1=3，\qquad M_2=4，\qquad m=12。

 两个非零坐标接收权重 (1) 和 (2) 乘以 (M_2)。 两个零坐标接收 (1) 和 (2)，乘以 (M_1)。 

| 坐标 | (a_i) | 角色 | (x_i)|
 | --- | --- | --- | --- |
 | 1 | 1 | 非零，权重 (1) | (4) |
 | 2 | 0 | 零，重量 (1) | (3) |
 | 3 | -1 | 非零，权重 (2) | (-8) |
 | 4 | 0 | 零，重量 (2) | (6) |

 对于目标向量，

 [
 1\cdot4+0\cdot3+(-1)(-8)+0\cdot6=12,
 ]

 所以它是有效的。 它的负数产生 (-12)，这也是有效的。 

现在分别检查两个模块化组件。 模(4)，非零坐标消失，零坐标贡献

 [
 3(b_2+2b_4)。 
]

 由于 (3) 可逆模 (4)，因此需要

 [
 b_2+2b_4\equiv0\pmod4。 
]

 它的绝对值最多为 (3)，因此它实际上必须等于 0。 满足这一点的唯一三元选择是(b_2=b_4=0)。 

对 (3) 取模，仅保留坐标 (1) 和 (3)。 他们的状况变成

 [
 b_1-2b_3\equiv0\pmod3。 
]

 唯一的可能性是 ((b_1,b_3)=(1,-1),(-1,1),(0,0))。 排除零向量，仅留下指定向量及其负值。

1
-1
```该算法输出 (m=1) 和 (x_1=-1)。 每个整数都可以被 (1) 整除，但单个系数唯一允许的非零选择是 (-1) 和 (1)。 禁止零选择，因此所需的解集正是两个向量(a)和(-a)。 

对于具有更多位置的恰好一个非零坐标，请考虑```

```该算法使用（m=15），给出第二个坐标（x_2=15），并给出其他坐标（1,2,4）。 仅使用这三个较小权重的任何有符号和最多具有绝对值 (7)，因此它不能是 (15) 的非零倍数。 因此，所有零坐标都必须接收系数零。 第二个系数可以是 (1) 或 (-1)，精确给出两个所需的向量。
