 ## 解决方案
 ## 问题理解

 给定一个整数集合，并要求我们理解按位规则引起的连通性。 每个数字都可以被视为图中的一个节点。 如果两个节点的按位与非零，则表示它们共享至少一个位位置，且两个节点的位位置均为 1，则这两个节点已连接。 

一旦考虑了这些连接，任务就是确定结果图有多少个连接的组件。 

关键的困难在于该图没有明确构建。 对于较大的输入，检查每一对会太慢，因此必须从位模式推断结构。 

从复杂性的角度来看，如果有大约 2×10^5 个数字，则检查所有对的二次解将需要大约 10^10 次操作，这远远超出了两秒内的任何实际限制。 即使明确构建所有边缘也是不可能的。 这立即迫使我们避免成对推理，而是利用位表示中的结构。 

一些边缘情况很容易被忽略。 

如果所有数字都为零，则没有两个节点共享设置位，因此每个节点都是隔离的。 例如，输入`[0, 0, 0]`必须生产 3 个组件。 

如果所有数字都相同且非零，则每个节点与其他每个节点至少共享一位，因此答案必须为 1。 

如果存在零值和非零值的混合，则零永远不会连接到任何东西，但非零值仍可能形成一个大的连接结构。 

当数字不直接成对重叠而是通过中间值传递连接时，就会出现一种微妙的情况。 例如，`2 (010)`,`4 (100)`,`6 (110)`即使形成单个组件`2 & 4 = 0`，因为两者都通过连接`6`。 

## 方法

 暴力解决方案通过检查每对数字并在其 AND 非零时添加一条边来构建完整的图。 然后 DFS 或 BFS 对连接的组件进行计数。 这是正确的，因为它直接模拟了连通性的定义。 

然而，成对检查是瓶颈。 和`n`元素，有`n(n-1)/2`比较，每个比较都需要按位运算。 为了`n = 2×10^5`，这太大了。 即使边构造是可能的，在密集图上运行图遍历也将是昂贵的。 

关键的观察结果是 AND 条件仅取决于共享位。 我们可以根据数字所包含的位对数字进行分组，而不是相互比较数字。 每个数字属于多个位组，每个位组对应一个设置位。 如果我们连接共享特定位的所有数字，则任何具有非零 AND 的数字对都将最终形成相同的连接结构。 

这将问题从对推理转变为对位推理。 每个位都充当中心：包含该位的所有数字都属于同一个联合。 最终的连通分量正是这些并集形成的连通分量。 

我们可以使用不相交的集合联合结构来有效地实现这一点，合并共享给定位的所有索引。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对检查 | O(n²) | O(1) 额外（或 O(n²) 图）| 太慢了|
 | 按位 DSU 分组 | O(n·B α(n)) | O(n·B α(n)) | O(n + B) | 已接受 |

 这里`B`是表示值所需的位数，通常约为 20 到 30。 

## 算法演练

 1. 初始化一个不相交的并集结构，其中每个数字都从其自己的组件开始。 这表示假设没有连接的状态。 
2. 对于从 0 到最大相关位的每个位位置，维护一个其编号包含该位的索引列表。 这通过共享结构特征对节点进行分组，而不是成对比较它们。 
3. 对于每一位，如果多个数字包含该位，则使用 DSU 并集将它们全部合并到一个连接组中。 我们可以通过将列表中的第一个元素作为代表并将其与同一列表中的所有其他元素联合起来来做到这一点。 
4. 处理完所有位后，计算剩余多少个不同的 DSU 根。 每个根对应一个连通分量。 

每个位内的合并有效的原因是共享一个位的任何两个数字都保证通过边直接连接。 一旦它们被合并，联合查找的传递性确保任何共享位链也被连接起来。 

### 为什么它有效

 每个数字都连接到与其共享至少一个公共位的所有数字。 如果两个数字共享一个位，则通过该位的分组将它们强制放入同一组件中。 如果它们不直接共享位，但可以通过中间数连接，那么这些中间数必须共享形成链的位。 DSU 准确地保留了位共享关系上的传递闭包，这与 AND 条件定义的图连接性相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    dsu = DSU(n)

    bit_to_nodes = [[] for _ in range(32)]

    for i, val in enumerate(a):
        for b in range(32):
            if val & (1 << b):
                bit_to_nodes[b].append(i)

    for b in range(32):
        nodes = bit_to_nodes[b]
        for i in range(1, len(nodes)):
            dsu.union(nodes[0], nodes[i])

    roots = set(dsu.find(i) for i in range(n))
    print(len(roots))

if __name__ == "__main__":
    solve()
```DSU 实现使用路径压缩和按大小并集来保持操作有效恒定。 位分组步骤确保我们仅在存在直接结构原因的情况下执行并集，而不是显式探索边缘。 

位循环的大小是固定的，因此主要成本与每个位包含的数字数量成正比，这在典型约束下是有效的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
        def f(self, x):
            while self.p[x] != x:
                self.p[x] = self.p[self.p[x]]
                x = self.p[x]
            return x
        def u(self, a, b):
            a, b = self.f(a), self.f(b)
            if a != b:
                self.p[b] = a

    n = int(input())
    a = list(map(int, input().split()))
    d = DSU(n)
    bits = [[] for _ in range(32)]
    for i, v in enumerate(a):
        for b in range(32):
            if v & (1 << b):
                bits[b].append(i)
    for b in range(32):
        for i in range(1, len(bits[b])):
            d.u(bits[b][0], bits[b][i])
    return str(len({d.f(i) for i in range(n)}))

 ## 边缘情况

 对于完全由零组成的输入，位分组步骤永远不会将任何索引分配给任何存储桶。 因此，不会执行联合操作，并且每个节点仍保留其自己的父节点。 DSU 根数等于`n`，匹配不同零之间没有 AND 产生连接条件的事实。 

对于所有数字都相同且非零的输入，每个索引都被插入到同一组位桶中。 每个位桶都会触发联合，将所有节点折叠成一个代表。 即使联合在多个位上重复，DSU 也会安全地忽略冗余合并，因此最终的结构是单个组件。 

对于稀疏输入，例如`[1, 2, 4]`，每个数字激活一个不相交的位桶。 由于没有桶包含多个索引，因此根本不会发生并集。 DSU 保持其初始状态，正确生成三个组件。
