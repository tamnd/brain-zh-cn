 ## 解决方案
 ## 问题理解

 我们给出了几个独立的场景。 每个场景中都有$n$怪物在概念上排成一行，每个怪物都有一些整数健康值。 一旦怪物的生命值为零，怪物就会消失。 

我们可以执行两种操作。 第一个动作是局部的：我们选择一个活着的怪物并将其生命值减少恰好一个。 第二个行动是全球性的：我们将每个活着的怪物的生命值减少一个。 不同的是，如果这个全局动作导致至少一个怪物达到零，该动作会立即再次触发，重复，直到完整的通过将没有怪物减少到零。 我们最多只能使用这个全局动作一次，而局部动作可以任意使用多次。 我们的目标是尽量减少我们最终使用的本地操作数量，同时确保所有怪物最终都被杀死。 

关键的困难在于，全局操作可以级联并可能消除一条“链”中的多个怪物，但其有用性完全取决于它相对于生命值分布的激活时间。 

约束条件很大：所有测试用例的怪物总数最多为$2 \cdot 10^5$。 这排除了任何对所有健康值逐步模拟全局操作或以简单方式重复扫描数组的解决方案。 任何有效的方法都必须将每个测试用例减少到至多线性或接近线性的工作。 

简单的模拟会尝试所有可能的时刻来应用全局咒语并模拟其级联行为。 这立即变得不可行，因为每次模拟都可能需要$O(n)$，并且有$O(n)$选择，导致$O(n^2)$每个测试用例。 

当许多怪物具有相同的最低生命值时，就会出现微妙的边缘情况。 例如，如果所有值都相等$[3,3,3]$，仅全局咒语就会立即擦除所有内容，产生零的本地操作。 另一方面，如果最小值是唯一的，但其余的明显更大，则过早或延迟的全局使用不会改变最终答案，但幼稚的推理可能会错误地假设时间很重要。 

当最小值为 1 时，会出现另一种棘手的情况。例如，$[1,100,100]$。 如果我们立即使用全局咒语，我们只会杀死第一个怪物并减少其他怪物，但我们可能不会以任何有意义的方式减少本地操作的数量，除非我们将决策与剩余值的结构保持一致。 

核心观察是，全局咒语有效地将所有值统一向下“移动”一次，任何原始值为 1 的怪物都会成为级联在本地停止的枢轴。 

## 方法

 一个蛮力的想法是在每个可能的时刻尝试使用全局咒语。 由于全局咒语仅应用一次，我们可以想象选择一个怪物子集已经被局部操作部分减少的时间。 对于每个选择，我们模拟全局效果并计算需要多少次额外的本地操作才能完成剩余的怪物。 然而，模拟的成本很高：应用全局咒语和跟踪级联删除需要重复扫描数组，并将其与所有可能的预操作结合起来会导致二次或更糟糕的复杂性。 

关键的简化来自于视角的翻转。 我们不是考虑何时应用全局咒语，而是问如果应用它，还剩下什么结构。 使用一次全局法术后，每个怪物的生命值都会减少1，并且所有原值为1的怪物都会立即消失。 剩下的是价值至少为 2 的怪物，现在减少了 1。从那时起，只有本地操作才重要。 

这意味着全局法术可以被解释为选择一个截止点：所有值为 1 的怪物免费消失，而所有其他怪物则减少一次。 剩下的唯一成本就是处理剩余怪物的剩余生命值。 

在不使用全局法术的情况下，每个怪物都必须完全使用本地操作来减少，成本$\sum a_i$。 通过全局咒语，我们为每个怪物“节省”了一个工作单元$a_i \ge 1$，但前提是我们正确地解释级联：真正的收益是所有的都免费消失，而所有其他的都被减少一次，有效地转移了问题。 

所以我们比较两种情况：

 如果我们从不使用全局咒语，答案很简单$\sum a_i$。 

如果我们使用一次，每个怪物都会失去 1 点生命值，并且所有原始值为 1 的怪物都会消失。 剩余成本变为$\sum \max(0, a_i - 1)$。 

我们取这两个值中的最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 法术计时的暴力模拟|$O(n^2)$|$O(n)$| 太慢了 |
 | 比较两种配置（使用/不使用全局拼写）|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们为每个测试用例计算两个量：所有值的总和，以及$\max(0, a_i - 1)$。 答案是两者中较小的一个。 

1. 读取怪物生命值数组。 这给出了仅使用本地操作杀死所有内容的完整成本结构。 
2. 计算所有值的总和。 这代表了我们从不使用全局咒语的情况，因此必须手动删除每个生命单位。 
3. 计算每个值贡献的第二个总和$a_i - 1$如果它至少为 1，否则为 0。这相当于应用一次全局法术，将每个怪物减少 1 并立即消除那些为零的怪物。 
4. 取两个总和中的最小值。 这直接比较了从不使用全局咒语与使用一次的成本。 

### 为什么它有效

 全局法术仅使用一次时，会对所有活着的怪物应用统一的减量。 它唯一的非线性效果是，在级联过程中达到零的怪物会立即消失，不需要任何进一步的操作。 此行为相当于将每个怪物减少一个单位，然后删除所有零。 由于不允许额外使用全局咒语，因此考虑多个应用程序没有任何好处，并且所有最佳策略都归结为所考虑的两种情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    total = 0
    reduced = 0
    
    for x in a:
        total += x
        if x > 1:
            reduced += x - 1
    
    print(min(total, reduced))
```该解决方案通过数组一次处理每个测试用例。 变量`total`累积不使用全局咒语的成本。 变量`reduced`通过从每个正值中减去 1 来模拟应用一次全局咒语，但由于所有值至少为 1，因此我们可以安全地计算`x - 1`对于所有元素。 这两者中的最小值捕获了最佳策略。 

一个微妙的实现细节是，不需要在归约后显式检查零，因为输入保证$a_i \ge 1$。 这消除了边界复杂性并保持计算严格线性。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        reduced = sum(x - 1 for x in a)
        out.append(str(min(total, reduced)))
    return "\n".join(out) + "\n"

 ## 边缘情况

 对于所有怪物的值为 1 的输入，例如$[1,1,1]$，算法计算出总计 = 3 和减少 = 0，正确选择 0。这与单个全局咒语通过级联立即杀死所有内容的事实相匹配。 

对于像这样的混合情况$[1,2,2]$，总计为 5，减少为 3。该算法正确地捕捉到，只有较大的怪物才能从均匀减少中受益，而那些已经处于 1 的怪物在法术后不再贡献进一步的成本。 

对于单元素数组$[k]$，总计为$k$并且减少的是$k-1$，正确反映全局咒语如果使用只能保存一个工作单元。
