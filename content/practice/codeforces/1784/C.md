 ## 解决方案
 ## 问题理解

 我们被要求找到在游戏中杀死怪物所需的单目标伤害法术的最少数量，其中强大的区域效果法术也可以施放一次。 每个怪物都有一个正整数的生命值，并且效果区域法术会反复将每个活着的怪物的生命值减少一，直到不再发生新的死亡。 对于怪物数组的每个前缀，我们需要计算这个最小值。 输入为我们提供了多个测试用例，每个测试用例指定了怪物的数量及其各自的生命值。 输出是一个整数列表，每个整数对应于长度递增的前缀所需的最小单目标咒语。 

鉴于测试用例中所有怪物的总和可以达到$2 \cdot 10^5$，我们需要一个相对于怪物数量以线性或近线性时间运行的解决方案。 一步步模拟每个法术的简单方法会太慢，因为一个具有高生命值的怪物可能需要最多$n$每个前缀重复迭代，这会导致计算量爆炸。 

不明显的边缘情况包括怪物的生命值已经连续增加或减少的情况，这会影响使用效果区域法术是否是最佳的。 例如，如果前缀中的所有怪物的生命值都是1，则区域效果法术可以立即杀死它们，而无需任何单目标法术。 相反，如果一个怪物的生命值非常高，而其他怪物的生命值很低，则区域效果法术只有在完成一些有针对性的伤害以减少生命值最高的“尖峰”后才会有帮助。 

## 方法

 蛮力方法是针对每个前缀逐一模拟施法咒语，以每种可能的组合应用类型 1 和类型 2 咒语。 这在逻辑上是正确的，但效率极低。 对于每个长度的前缀$k$，我们可能必须模拟$O(\sum a_i)$操作，这是不可接受的，当$n$取决于$2 \cdot 10^5$。 

最佳方法依赖于两个观察结果。 首先，由于2型法术只有在第一次使用时杀死至少一个怪物才有效，因此我们可以将其视为在特殊的重复级联中将最大生命值减少一个。 其次，对于每个前缀，所需的最小 1 类法术等于零和最大怪物生命值之间的最大值减去当前前缀长度。 这是因为作用范围法术有效地统一减少所有生命值，但只能从生命值等级底部的怪物开始级联死亡。 通过维持最大的怪物生命值并计算级联效果区域已经杀死了多少怪物，我们可以在线性时间内计算每个前缀的答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n \cdot \max a_i)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$以及一系列怪物的生命值$a$。 
3. 初始化变量`max_health`到 0，代表当前前缀中迄今为止看到的最大健康状况。 
4. 按顺序迭代怪物。 对于每个以位置结尾的前缀$i$:

 a. 更新`max_health`作为其当前值和之间的最大值$a[i]$。 

b. 计算此前缀所需的 1 类法术的最小数量：`max(0, max_health - (i + 1))`。 这里`(i + 1)`代表前缀的长度，即受区域效果法术影响的怪物数量。 

c. 存储或打印该值。 
5. 对所有测试用例重复此操作。 

**为什么有效**：关键属性是效果区域法术每次级联都会使每个怪物的生命值减少一个，并且如果前缀有长度$k$，那么至多之后`k`重复，所有怪物生命值≤`k`没有任何单一目标法术就会被杀死。 剩余生命值如上`k`必须用1类法术来处理。 保持运行最大值可确保我们正确计算每个前缀中剩余的最高怪物。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res = []
        max_health = 0
        for i in range(n):
            max_health = max(max_health, a[i])
            res.append(max(0, max_health - (i + 1)))
        print(' '.join(map(str, res)))

if __name__ == "__main__":
    solve()
```**解释**：变量`max_health`跟踪当前前缀中最大的怪物生命值。 表达式`max(0, max_health - (i + 1))`有效计算在前缀长度上应用效果区域级联后剩余的生命值。 这消除了模拟每个咒语的需要，允许每个测试用例进行线性时间计算。
