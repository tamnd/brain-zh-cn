 ## 问题理解

 我们在无限的二维网格上得到一个目标点，我们想要确定是否可以使用一种非常特定的运动从原点开始到达它。 每个动作都有一个固定的长度，每次都会加倍，从 1 开始，然后是 2，然后是 4，依此类推。 在第 i 次移动中，我们必须精确移动$2^i$朝着四个基本方向之一迈出一步。 

任务不仅是确定目的地是否可达，而且还要构建有效的方向序列以在可能的情况下实现目的地。 

运动的结构从根本上解决了在受约束的类二进制系统中表示坐标的问题。 每一步都会消耗一点“移动力”，方向决定该力对 x 或 y 坐标的贡献方式。 

约束（如最初的 Expogo 式问题）通常允许坐标达到很大的幅度，这排除了对所有路径的任何模拟。 对所有方向序列的强力搜索将在每一步分支 4 个分支，即使对于 30 次移动，这也已经超过$4^{30}$，这是一个天文数字。 该解决方案必须直接从坐标构建路径。 

当两个坐标均为偶数时，会出现微妙的边缘情况。 例如，第一步从 (0, 0) 到达 (2, 2) 已经破坏了系统的奇偶校验结构。 由于每次移动的长度都是 2 的幂，奇偶校验约束向后传播：除以 2 必须在每个阶段保持完整性。 任何忽略这一点的幼稚尝试都会错误地假设所有点都是可到达的。 

另一个常见的失败案例是假设曼哈顿距离奇偶校验就足够了。 例如，(1, 1) 和 (2, 0) 在约束下的表现非常不同，尽管它们的坐标总和可能表明类似的可行性。 

## 方法

 强力解决方案尝试探索长度方向的所有序列，直到达到由坐标大小确定的某个最大界限。 在每一步中，它都会选择四个方向之一，并从 x 或 y 中减去相应的 2 的幂。 这正确地枚举了所有可能的路径，但状态空间呈指数增长。 如果我们需要最多 40 步，则可能性的数量变为$4^{40}$，这远远超出了任何可行的计算。 

关键的观察是任何有效构造中的最后一步必须解析 x 或 y 的最低二进制级别。 由于最后一步的大小为 1，因此它只能将 x 或 y 精确地改变 ±1。 这迫使我们在未完成的每一步中至少有一个坐标是奇怪的。 一旦我们确定了哪个轴负责奇校验，我们就可以唯一地确定最后移动的方向，然后通过调整后将两个坐标减半来减少问题。 

这将问题变成了从目标向后进行贪婪重建。 我们不是构建前进的路径，而是一次剥离一个动作，始终确保在消除当前动作的贡献后，两个坐标在除以 2 时仍保持整数。

 ## 算法演练

 我们重建从目标点开始并向后移动到原点的移动序列。 

1. 首先，考虑当前坐标(x,y)。 如果 x 和 y 都为零，则构造完成。 反向构建的序列是有效答案。 
2.如果x和y都是偶数，则不移动大小$2^k$可以从整数个先前状态进入这样的状态。 这意味着配置无效并且不存在解决方案。 原因是每次移动都会在一个坐标方向上翻转奇偶校验。 
3. 如果 x 是奇数，则最后的移动一定影响了 x 坐标。 我们必须决定它是来自左派还是右派。 我们测试 (x-1)/2 或 (x+1)/2 中哪一个是整数，同时与下一个状态保持一致。 我们选择将两个坐标除以 2 后使下一个坐标为整数的方向。 
4. 如果 y 是奇数，我们在垂直方向应用相同的推理，选择向上或向下移动，具体取决于哪种选择在减半后保持完整性。 
5. 应用所选的移动后，我们通过减去该移动并将两个坐标除以 2 将 (x, y) 更新为之前的状态。我们还将相应的方向附加到答案序列中。 
6. 重复此过程，直到到达 (0, 0)。 收集到的序列是倒序的，所以我们最后将其反转。 

正确性依赖于结构不变量：在每一步之后，当前 (x, y) 表示在某些移动前缀之后可到达的有效状态，并且每当移动剩余时，恰好有一个坐标必须是奇数。 这确保了向后重建永远不会出现导致不一致的歧义，并且每条有效路径都对应于奇偶驱动决策的唯一序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x, y = map(int, input().split())
    
    if x == 0 and y == 0:
        print("")
        return

    ans = []

    while x != 0 or y != 0:
        if x % 2 == 0 and y % 2 == 0:
            print("IMPOSSIBLE")
            return

        # decide direction based on parity
        if x % 2 != 0:
            # try East or West
            if ((x - 1) // 2) % 2 == y % 2:
                ans.append('E')
                x = (x - 1) // 2
            else:
                ans.append('W')
                x = (x + 1) // 2
            y = y // 2
        else:
            # y is odd
            if ((y - 1) // 2) % 2 == x % 2:
                ans.append('N')
                y = (y - 1) // 2
            else:
                ans.append('S')
                y = (y + 1) // 2
            x = x // 2

    print("".join(ans[::-1]))

if __name__ == "__main__":
    solve()
```实施直接遵循落后的建设。 当两个坐标都达到零时循环停止。 双偶状态的奇偶校验是直接不可行的条件。 每次迭代都会将坐标的大小大约减少一半，从而确保对数深度。 

方向选择是通过测试哪种调整会导致有效的减半步骤来实现的。 反向构造存储在列表中并最终反转，因为我们构建了从最后一步到第一次的路径。 

一个微妙的细节是负数的整数除法行为。 Python 的地板除法在这里仍然可以正确工作，因为所选择的移动可以保证除法之前的均匀转换，从而保持正确性。

 ## 边缘情况

 最重要的边缘情况是当两个坐标都处于非终止状态时。 例如，从 (2, 2) 开始立即强制失败。 该算法在每次迭代的顶部检测到这一点并终止，因为在有效的向后重建中，没有任何二次方移动序列可以创建两个坐标同时可被 2 整除的状态。 

另一种情况是纯粹的轴对齐目标，如 (0, 8)。 重建永远不会触及 x 坐标，并且算法通过减半重复求解 y。 每一步都清楚地映射到垂直移动，并且该序列变成了 8 的简单二进制分解。 

第三种情况是以强制在水平和垂直决策之间重复切换的方式协调交替奇偶校验，例如 (5, 3)。 该算法仍然减少每一步的幅度，并且至少一个坐标为奇数的不变性保证了有效方向始终可用，直到两个坐标都达到零。
