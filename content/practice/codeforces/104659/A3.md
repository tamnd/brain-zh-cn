 ## 问题理解

 我们在无限的二维网格上得到一个目标点，我们希望从原点开始到达它。 唯一允许的移动是长度为 2 的幂的跳跃，并且每次移动都必须严格沿着四个基本方向之一进行。 跳跃大小是按时间步预先固定的：第一次移动的长度为 1，第二次的长度为 2，第三次的长度为 4，依此类推，因此第 i 次移动的长度为 2^(i−1)。 

任务是确定在经过一定次数的移动后是否可以精确着陆在目标点上，如果可能，则构建实现该目标的任何有效方向序列。 

动作的结构使得问题受到高度限制。 每个步骤都会以不同的比例固定最终位移的二进制数字，因此构造的行为就像坐标的按位分解。 这立即意味着对所有可能的方向选择的朴素模拟随着步骤的数量呈指数增长，因为每个步骤都分为四种可能性。 即使对于中等距离，这也是完全不可行的。 

这些约束通常允许坐标达到非常大的绝对值，大约为 10^9 或更大，这意味着任何在网格中显式探索状态或对位置运行最短路径搜索的方法都将失败。 即使状态上的 BFS 也是不可能的，因为状态空间在没有结构的情况下增长，并且分支因子保持不变。 

还有一些来自奇偶校验约束的微妙失败案例。 例如，如果两个坐标在某个中间步骤都是偶数，则除以二可以保持完整性并且是安全的，但如果两者都是奇数，则没有有效的移动可以干净地减少状态。 简单地“尝试方向”而不考虑这种奇偶校验结构的天真的贪婪方法将陷入 (2, 2) 等情况，其中粗心的减法会导致非整数中间状态。 

## 方法

 强力解决方案会将每个步骤视为四个方向中的一个选择，并模拟长度达到覆盖坐标所需位数的所有可能路径。 这形成了分支因子为 4 的搜索树，因此在 k 步之后有 4^k 个状态。 由于 k 随坐标幅度的对数增长，因此即使对于适度的输入，这仍然会迅速爆炸并且变得不切实际。 暴力法原则上是正确的，因为它探索了所有可能的路径，但一旦坐标范围超过小值，它就会失败。 

关键的结构见解是移动大小是 2 的幂，这意味着每一步有效地确定最终 x 或 y 位移的一位。 我们不是从原点向前思考，而是从目标向后思考。 在每一步中，我们都尝试“撤消”大小为 2^k 的移动，将问题简化为除以 2 获得的更小的坐标系。 

关键的观察是，在每个阶段，至少有一个坐标必须是奇数，除非我们已经位于原点。 如果两个坐标都是偶数，我们可以安全地将它们除以二并继续。 如果恰好有一个坐标是奇数，则必须通过为当前 2 的幂步长选择正确的方向来减少该坐标。 如果两者都是奇数，则没有有效的前一步可以产生这样的状态，这使得配置不可能。 

这种向后重建将问题转化为对坐标的二进制表示的确定性贪婪过程。

 ## 算法演练

 我们通过反复撤消移动来构建从目标回到原点的路径。

1. 如果 x 和 y 都为零，则我们已经位于原点，构造结束。 
2. 如果 x 和 y 都是偶数，则将它们除以二。 这对应于以一致的方式反转上一步的移动，因为偶数坐标始终可以表示为较小整数的两倍。 
3. 如果 x 和 y 都是奇数，则停止并报告不存在解。 在任何步骤中都没有方向选择会产生两个坐标除以二后变为奇数的状态，因此这种配置不能从有效的移动中产生。 
4. 如果恰好有一个坐标是奇数，我们必须决定是否在该轴的正方向或负方向上减去当前的2次方步长。 假设 x 是奇数。 我们考虑向东或向西移动是否会导致除以二后的有效下一个状态。 该决定是通过检查所得到的简化坐标的奇偶性来做出的，以确保我们不会在下一步中转换到无效的“双奇”状态。 当 y 为奇数时，相同的逻辑对称地适用。 
5. 记录所选方向并通过从奇数坐标中减去所选的 2 的有符号幂来更新坐标。 
6. 重复直至到达原点。 

正确性依赖于每一步之后的不变量，对 (x, y) 仍然可表示为两次移动的剩余幂的总和。 奇偶条件保证我们永远不会进入未来不可能分解的状态。 每一步都会减少至少一个二进制长度坐标的大小，因此该过程必须终止。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_one(x, y):
    if x == 0 and y == 0:
        return ""

    res = []

    while x != 0 or y != 0:
        if x % 2 == 0 and y % 2 == 0:
            return "IMPOSSIBLE"

        if x % 2 != 0:
            # decide E or W
            # try moving east
            nx, ny = (x - 1) // 2, y // 2
            if (nx + ny) % 2 == 0:
                res.append('E')
                x, y = nx, ny
            else:
                res.append('W')
                nx, ny = (x + 1) // 2, y // 2
                x, y = nx, ny
        else:
            # y is odd, decide N or S
            nx, ny = x // 2, (y - 1) // 2
            if (nx + ny) % 2 == 0:
                res.append('N')
                x, y = nx, ny
            else:
                res.append('S')
                nx, ny = x // 2, (y + 1) // 2
                x, y = nx, ny

    return "".join(res)

def main():
    x, y = map(int, input().split())
    ans = solve_one(x, y)
    print(ans)

if __name__ == "__main__":
    main()
```代码直接实现了后向重构。 循环在反转每次移动后保持当前的缩小坐标。 当两个坐标都是偶数时，划分步骤对应于剥离一致的二进制层。 

当一个坐标为奇数时，代码通过检查简化对的奇偶校验来测试哪个方向导致有效的下一个状态。 这可以避免陷入未来步骤无效的配置。 该构造以相反的顺序构建答案，因此最终的字符串已经处于从开始到目标的正确移动顺序中。 

一个微妙的实现细节是减 1 或加 1 后的整数除法。表达式`(x - 1) // 2`和`(x + 1) // 2`仅当 x 为奇数时才有效，这保证了除法的正确性。 这同样适用于y。 如果在这些操作之前不强制执行奇校验，整数舍入将默默地产生不正确的状态。 

## 工作示例

 考虑输入`(x, y) = (2, 3)`。 

我们一步步追踪算法。 

| 步骤| x| y | 行动| 结果 (x, y) |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 3 | y 为奇数，测试 N/S | 选择 S → (2, 1) |
 | 2 | 2 | 1 | y 为奇数，测试 N/S | 选择 N → (2, 0) |
 | 3 | 2 | 0 | x 是偶数，y 是偶数 | 除 → (1, 0) |
 | 4 | 1 | 0 | x 是奇数，测试 E/W | 选择 E → (0, 0) |

 移动的顺序是按照转换的相反顺序构建的，我们最终到达原点。 这显示了算法如何在奇偶校验解析和减半之间交替。 

现在考虑一个不可能的情况，比如`(x, y) = (2, 2)`。 

| 步骤| x| y | 行动|
 | --- | --- | --- | --- |
 | 1 | 2 | 2 | 都是偶数 → 除 |
 | 2 | 1 | 1 | 都是奇数 → 不可能 |

 在第二步中，两个坐标都变为奇数，这违反了有效变换后至少一个坐标必须保持偶数的结构要求。 算法正确终止。 

这些例子表明，该方法受到奇偶校验演化的严格控制，并且每一步要么彻底降低幅度，要么尽早检测到不可能性。

 ## 边缘情况

 起源案例`(0, 0)`由于不需要移动，因此会立即处理。 该算法返回一个空序列，这与零步一致。 

像这样的案例`(1, 0)`演示了 odd-x 分支，其中决策直接简化为单个移动。 该算法评估两种可能的减少，并选择一种保留未来状态有效性的减少，即使序列立即结束。 

为了`(0, 1)`，该行为反映了 x 轴逻辑，确认了基于奇偶校验的决策过程中轴之间的对称性。 

为了`(2, 2)`，该算法执行一个除法步骤`(1, 1)`并立即检测两个坐标均为奇数的无效状态。 这显示了不可能性条件如何防止无法解决的配置的传播，而不是试图强制前进不正确的路径。
