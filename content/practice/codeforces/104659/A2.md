 ## 问题理解

 我们在无限的二维网格上得到一个目标点。 从原点开始，我们希望通过一系列移动到达该点。 每个动作都有一个固定的长度，每一步加倍，从 1 开始，然后是 2，然后是 4，依此类推。 在每一步中，我们选择四个基本方向之一，并且每个长度只能使用一次。 

任务是确定是否有可能准确地达到目标，如果可能，则构建实现该目标的有效方向序列。 

输入是一对表示最终坐标的整数。 输出要么是描述每个步骤所采取的方向的字符串，要么是不存在有效序列的信号。 

每个步长是 2 的不同幂的约束是关键的结构限制。 这意味着运动本质上是最终位移的二元分解，但 x 和 y 之间存在耦合，因为每个步骤一次仅影响一个轴。 

当独立对待 x 和 y 时，幼稚思维的自然失败案例就会出现。 例如，如果目标是 (1,1)，人们可能会尝试将 1 长度的步长分配给 x 并忽略 y，但随后没有剩余的步长可以解决不平衡问题，因为所有剩余的移动都是偶数长度。 

当两个坐标均为偶数但不为零时，会出现另一种微妙的边缘情况。 例如，(2,2)。 一个天真的贪婪尝试可能会尝试向东移动两次，向北移动两次，但步长是固定的，不能任意分割。 正确的行为取决于奇偶校验约束而不是大小。 

核心困难在于，每个步骤同时在一个维度上编码二元决策，同时约束另一个维度，因此局部贪婪选择必须尊重全局奇偶结构。 

## 方法

 强力方法会尝试将每个二次方步长分配给四个方向之一并模拟所有可能的序列。 由于有 k 个步骤，因此有 4^k 种可能性。 即使对于 30 左右的中等 k，这也变得完全不可行，因为它扩展到数十亿个状态。 

关键的观察是动作的结构不是任意的。 每个步长都是 2 的幂，与二进制表示形式一致。 这表明我们应该逆向推理：我们不是构建一条前进的道路，而是从目标出发，一步一步地展开。 

在每个阶段，我们决定必须使用哪个方向来获得最大的剩余功率。 这一决定完全由奇偶校验决定。 如果 x 和 y 都是偶数，则最后不能使用奇数长度的移动，这会立即产生矛盾，除非我们已经位于原点。 如果其中一个是奇数，则只有一个方向对于最后一步有效，因为减去奇数步会以受控方式翻转奇偶校验。 

通过重复应用这种推理，并在解决最后一步后将坐标除以 2，我们可以将问题大小每步减少一位。 这将指数搜索转变为线性重建过程。

 ## 算法演练

 我们从目标坐标向后重建路径，同时每次迭代消耗一个二的幂步长。

1. 如果目标是 (0, 0)，我们就已经完成并且不产生任何动作。 这构成了递归的基本情况。 
2. 在每一步中，检查 x 和 y 是否都是偶数。 如果是，并且该点不是 (0, 0)，那么之前的任何有效动作都不会产生这种状态，因此我们得出不可能的结论。 
3. 否则，至少有一个坐标是奇数。 这意味着最后一次移动在至少一个轴贡献中必须具有奇数长度，因此我们确定可以使用哪个方向。 
4. 如果 x 是奇数，我们通过检查 x 模 4 的奇偶校验来确定最后的移动是东还是西。这是有效的，因为在向后滚动时减去或添加 2 的幂必须保留正确的奇偶校验结构。 
5. 如果 y 是奇数，我们同样使用相同的奇偶推理在北和南之间做出决定。 
6. 选择方向后，我们从 (x, y) 中减去相应的有符号二次方贡献，将方向附加到答案中，然后将两个坐标除以 2 以移位到下一个较小的位级别。 
7. 重复直到到达 (0, 0)。 

关键的不变量是，在处理 k 个步骤之后，剩余的坐标表示在一致地去除低位的所有贡献后除以 2^k 的原始目标。 每个步骤都保留了对于简化问题仍然存在有效分解的属性。 如果在任何时候两个坐标都变为偶数且非零，则不存在一致的二进制分解，因此算法安全终止。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x, y = map(int, input().split())
    
    if x == 0 and y == 0:
        print("")
        return

    moves = []
    
    while x != 0 or y != 0:
        if x % 2 == 0 and y % 2 == 0:
            print("IMPOSSIBLE")
            return

        # determine direction
        if abs(x) % 2 == 1:
            # x is odd: decide E or W
            if ((x - 1) // 2) % 2 == 0:
                moves.append('E')
                x = (x - 1) // 2
            else:
                moves.append('W')
                x = (x + 1) // 2
            y //= 2
        else:
            # y is odd: decide N or S
            if ((y - 1) // 2) % 2 == 0:
                moves.append('N')
                y = (y - 1) // 2
            else:
                moves.append('S')
                y = (y + 1) // 2
            x //= 2

    print("".join(moves))

if __name__ == "__main__":
    solve()
```该代码实现了反向重构循环。 每次迭代通过检查奇偶校验来精确解决一个位级移动。 决策分支将 x 驱动和 y 驱动情况分开，确保一次仅调整一个坐标。 应用反向移动后，两个坐标都缩小了两倍，反映了当前二次幂层的删除。 

一个微妙的点是整数除法必须保持有符号的正确性。 在Python中使用下取整除法是有效的，因为在减去或加上一个奇数之后，中间值在减半之前保证是偶数。

 ## 边缘情况

 原始情况 (0, 0) 很重要，因为它完全绕过重建循环。 由于不需要移动，该算法正确地输出一个空序列。 

像 (2, 2) 这样的情况执行偶校验转换。 第一步不能通过天真的推理直接选择，但算法正确地识别出一个坐标必须贡献最后一步，而另一个坐标通过减半一致减少。 

对于 (1, 0) 这样的情况，只有 x 轴有贡献。 该算法重复选择水平移动，每一步都干净地减小了问题规模，而不会进入无效的奇偶校验状态。
