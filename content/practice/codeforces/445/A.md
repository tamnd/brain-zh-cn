 ## 解决方案
 ## 问题理解

 我们有一个棋盘，表示为`n`经过`m`网格中每个单元格要么好，要么坏。 好的单元格用“.”表示。 坏单元用“-”表示。 在每个好的单元格上，我们必须放置一个白色（“W”）或黑色（“B”）的棋子，这样没有两个相同颜色的棋子共享一侧。 坏单元保持为空，并且在邻接检查中不被考虑。 任务是产生任何有效的棋子排列。 

输入大小适中：两者`n`和`m`最多 100。这立即排除了时间复杂度低于 O(n * m) 的解决方案，因为 n * m 可以达到 10,000，并且任何具有二次因子或重复深度递归的算法可能效率低下。 内存也足以用于板的简单 2D 阵列表示。 

当好单元完全被坏单元包围时，就会出现微妙的边缘情况。 例如，如果输入是：```
3 3
---
-.-
---
```那么中间的单元格可以是“W”或“B”。 一种基于邻接的天真方法假设所有邻居都是好的，可能会放错颜色。 另一个边缘情况是单电池板，`1 1`，其中任一颜色均有效。 粗心的检查器可能要求邻居存在，但在这个最小输入上失败。 

## 方法

 暴力方法会尝试在每个好的单元格上放置一种颜色，然后递归或迭代地检查所有可能的组合，同时尊重邻接约束。 这种方法是正确的，但组合起来具有爆炸性。 对于一个`n * m`板子上有大约一半的好单元，放置的数量大约是 2^(n*m/2)。 显然，这超出了任何可行的运行时间，即使对于 n = m = 10 也是如此，并且对于上限 100 来说也是不可能的。 

关键的见解是棋盘是二分结构：我们可以以棋盘图案对棋盘进行着色，这样没有两个相邻单元格具有相同的行+列和奇偶校验。 具体来说，对于位置 (i, j) 的单元格，如果 (i + j) 是偶数，我们可以放置“B”，如果 (i + j) 是奇数，我们可以放置“W”。 这种模式自动保证相邻的好单元格具有相反的颜色。 坏单元格被忽略，因此它们保持为“-”并且不影响着色。 

这将问题简化为网格上的简单迭代，计算奇偶性，并根据单元类型和奇偶性分配适当的字符。 不需要递归或回溯。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n*m)) | O(2^(n*m)) | O(n*m) | 太慢了|
 | 最佳 | O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 阅读尺寸`n`和`m`从输入然后`n`代表董事会的字符串。 每个字符串都有长度`m`。 
2. 将空输出板初始化为字符串或字符列表。 
3. 迭代每一行`i`从 0 到 n-1。 对于每一行，迭代每一列`j`从0到m-1。 
4. 对于 (i, j) 处的每个单元格，检查它是否为坏单元格（“-”）。 如果是这样，则将其直接复制到输出。 
5. 如果单元格良好（“.”），则计算总和`i + j`。 如果`(i + j) % 2 == 0`，将“B”放在该单元格上； 否则，放置“W”。 哪个奇偶校验得到哪种颜色的选择是任意的； 关键是全面的一致性。 
6. 处理完一行中的所有列后，将该行附加到输出板。 
7. 逐行打印输出板。 

工作原理：行+列的奇偶校验确保没有两个相邻单元格共享相同的奇偶校验。 由于我们为偶数和奇数和分配不同的颜色，因此任何两个相邻的好单元格自动具有相反的颜色。 坏单元永远不会改变，因此它们永远不会违反邻接规则。 这保证了任何板的有效着色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
board = [input().strip() for _ in range(n)]
output = []

for i in range(n):
    row = []
    for j in range(m):
        if board[i][j] == '-':
            row.append('-')
        elif (i + j) % 2 == 0:
            row.append('B')
        else:
            row.append('W')
    output.append(''.join(row))

print('\n'.join(output))
```代码直接遵循算法。 读板使用`sys.stdin.readline`用于快速输入。 为了提高效率，每一行都是使用字符列表增量构建的，然后连接成一个字符串。 奇偶校验`(i + j) % 2`一致地指定颜色。 单单元板、全坏行或不规则图案等边缘条件可以自然处理，因为我们从不假设邻居存在超出计算范围`(i + j)`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n*m) | 我们只访问每个单元一次来计算奇偶性并分配颜色。 |
 | 空间| O(n*m) | 我们存储输出板，其尺寸与输入板相同。 |

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    board = [input().strip() for _ in range(n)]
    output = []
    for i in range(n):
        row = []
        for j in range(m):
            if board[i][j] == '-':
                row.append('-')
            elif (i + j) % 2 == 0:
                row.append('B')
            else:
                row.append('W')
        output.append(''.join(row))
    return '\n'.join(output)

 ## 边缘情况

 单电池板：```
1 1
.
```该算法计算 (0+0) % 2 = 0 并放置“B”。 不存在邻接，因此颜色有效。 

完全被坏细胞包围的细胞：```
3 3
---
-.-
---
```只有单元格 (1,1) 是好的。 (1+1)%2=2%2=0，所以放置“B”。 不存在相邻的好单元，因此邻接不变量通常成立。 

一整行或一列坏单元格：```
2 3
---
.W.
```坏单元保留“-”，好单元根据奇偶校验进行分配。 该算法将“W”置于(1,1)，因为(1+1)%2=0，与奇偶校验规则一致。 相邻的坏小区不会干扰。
