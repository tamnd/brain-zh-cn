 ## 解决方案
 ## 问题理解

 我们得到一长串非负整数。 我们还给出了一个目标值`x`。 任务是查看序列内部并找到一个连续的段，其元素之和恰好为`x`。 在所有这些片段中，我们被要求选择一个具有最大可能长度的片段。 如果多个段共享该最大长度，则其中任何一个都是可接受的。 如果没有段具有精确的总和`x`，我们报告失败。 

输出不是段本身，而是描述它的两个值：其长度和使用基于 1 的索引的起始位置。 

约束决定了解决方案。 数组大小可以达到 500 万个元素，因此任何显式检查所有子数组的方法都将无法生存。 即使将前缀和存储在一个简单的数组中，在内存中也是有边界的，但如果小心完成，仍然是可能的。 总和上限达到 10^16，这保证了 32 位算术不足以进行累加，因此始终需要 64 位整数。 

一个关键的结构属性是所有数字都是非负数。 这完全决定了有效窗口移动的方向：一旦窗口总和超过`x`，进一步扩大永远无法解决问题，只有缩小才有帮助。 

有一些边缘情况打破了天真的推理：

 第一个边缘情况是当`x = 0`。 由于所有数字都是非负数，因此唯一有效的段是完全由零组成的段。 假设正增长的天真滑动窗口可能仍然有效，但是如果不仔细处理零扩展，仅在总和变化时移动指针的实现可能会陷入困境。 

示例：

 输入：```
5 0
1 0 0 0 2
```正确答案是`3 2`，三个零的线段。 

第二个边缘情况是当所有元素都很大并且总和超过`x`立即地; 这里只有收缩问题，并且未能正确收缩会导致在两指针实现中无限扩展尝试。 

## 方法

 暴力解决方案将枚举每个起始索引`l`，并且对于每个`l`， 延长`r`同时保持运行总和，直到超过或匹配`x`。 如果匹配，我们将更新最佳长度。 这是正确的，因为每个子数组都会被考虑，但在最坏的情况下，它会检查 O(n^2) 段，并且总工作会退化为 O(n^2) 次添加。 和`n = 5 * 10^6`，这是完全不可行的。 

关键的观察来自于所有数字都是非负的事实。 这保证了如果我们维护一个窗口`[l, r]`并且总和变得太大，增加`r`只会让情况变得更糟。 这种单调行为使我们能够维持一个滑动窗口，其中两个端点仅向前移动。 每个元素最多进入和离开窗口一次，因此我们可以在线性时间内跟踪有效的总和。 

我们不检查所有子数组，而是维护一个始终代表当前总和的动态区间。 我们贪婪地扩展右端，当总和变得太大时，我们从左端收缩，直到它再次有效。 每次总和等于`x`，如果窗口比之前的窗口长，我们会更新最佳答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 滑动窗 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化两个指针`l = 0`,`r = 0`，以及运行总和`s = 0`。 还存储最佳答案`(best_len, best_l)`初始化为未找到。 这两个指针定义当前正在考虑的窗口。 
2. 移动`r`从左到右穿过数组，添加`a[r]`到`s`在每一步。 这将扩展当前窗口以包含更多元素。 
3. 每次展开后，同时`s > x`和`l <= r`, 减去`a[l]`从`s`和增量`l`。 这恢复了窗口的可行性，因为所有值都是非负的，这意味着缩小是减少总和的唯一方法。 
4. 如果在任何时候`s == x`,比较当前窗口长度`r - l + 1`迄今为止发现的最佳长度。 如果更大，则更新最佳答案`(length, l + 1)`因为输出使用从 1 开始的索引。 
5. 继续直到`r`到达数组末尾。 最终存储的答案是最长的有效段。 

### 为什么它有效

 正确性取决于单调性：一旦总和超过`x`，如果不首先从左侧删除元素，则右端点的未来扩展无法修复它。 由于所有值都是非负数，因此总和仅在扩展时增加`r`，并且仅在移动时减小`l`。 这确保每个子数组都有正确的端点`r`在处理过程中仅由一个左指针位置唯一地表示。 因此，不会跳过任何有效窗口，并且当每个候选窗口在约束下变得最小时，都会准确地评估每个候选窗口`s <= x`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))

    l = 0
    s = 0

    best_len = 0
    best_l = -1

    for r in range(n):
        s += a[r]

        while l <= r and s > x:
            s -= a[l]
            l += 1

        if s == x:
            length = r - l + 1
            if length > best_len:
                best_len = length
                best_l = l + 1

    if best_l == -1:
        print(-1)
    else:
        print(best_len, best_l)

if __name__ == "__main__":
    solve()
```该实现使用两个索引维护一个滑动窗口。 总和`s`始终表示当前段的总和`[l, r]`。 每当总和超过时，内循环负责恢复有效性`x`。 由于每个元素最多从左侧删除一次，因此该循环不会产生二次行为。 

答案更新仅发生在`s == x`，并且它跟踪迄今为止看到的最大窗口长度。 索引转换为基于 1 的形式是在赋值时处理的，以避免以后重复调整。
