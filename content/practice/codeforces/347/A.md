 ## 解决方案
 ## 问题理解

 我们得到一个 _n_ 个整数的列表，需要将它们排列成一行，以使连续数字之间的差值之和最大化。 具体来说，如果安排是$x_1, x_2, \dots, x_n$，该值计算为$(x_1 - x_2) + (x_2 - x_3) + \dots + (x_{n-1} - x_n)$。 观察公式，取消中间项，使总值为$x_1 - x_n$。 这意味着通过将最大的数放在前面、将最小的数放在最后来获得最大值。 然而，挑战在于该问题还需要产生该最大值的所有排列中按字典顺序排列的最小序列。 

限制条件适中：$n$最大可达 100，整数范围为 -1000 到 1000。这使得解可达$O(n^2)$舒适但天真的排列，其规模为$O(n!)$，都是不切实际的。 边缘情况包括多个元素具有相同最大值或最小值的序列、只有两个元素的序列以及所有数字都相等的序列。 幼稚的方法可能会选择任何顺序而不确保字典顺序最小性，从而产生正确的最大值但输出序列错误。 

## 方法

 暴力方法将生成输入数组的所有排列，计算每个排列的值，并选择具有最高值的排列，通过字典序比较打破平局。 为了$n = 100$，这种方法是不可能的，因为$100!$排列是天文数字。 

关键的见解来自于观察差值和的抵消。 总和简化为$x_1 - x_n$。 最大化这个需要将最大的数字放在前面，将最小的数字放在最后。 一旦第一个和最后一个位置固定，剩余的数字就不会影响总和。 为了获得字典顺序最小的序列，中间的数字应该按升序排列。 这保证了给定的第一个和最后一个数字的最小可能序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将数组按升序排序。 这可以轻松识别最小和最大数字，并简化构建字典顺序最小序列。 
2. 将最大的数字放在第一个位置。 这最大化了$x_1$在简化总和中$x_1 - x_n$。 
3. 将最小的数字放在最后一个位置。 这最大限度地减少了$x_n$总而言之。 
4. 取出剩余的数字（除最大和最小之外的所有数字）并将它们按升序排列在第一个位置和最后一个位置之间。 这确保了序列按字典顺序最小化，同时保持最大值。 
5. 打印结果序列。 

为什么有效：通过固定两端的最大和最小数字，我们保证了最大差异。 对中间数字进行升序排序可确保按字典顺序排列尽可能最小的序列。 中间数字的任何其他顺序都不会改变总和，但会导致更大的词典顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

a.sort()
largest = a[-1]
smallest = a[0]
middle = a[1:-1]

result = [largest] + middle + [smallest]
print(' '.join(map(str, result)))
```该代码首先对输入数组进行排序。`largest`取最后一个元素，`smallest`取第一个，并且`middle`包含其间的所有元素。 将它们连接为`[largest] + middle + [smallest]`产生所需的输出。 对中间进行排序可确保词典编排最少。 该方法小心地避免以破坏顺序的方式修改原始数组。 

## 工作示例

 **样品1**

 输入：`5\n100 -100 50 0 -50\n`| 步骤| 数组| 行动| 结果 |
 | ---| ---| ---| ---|
 | 1 | [-100, -50, 0, 50, 100] | 已排序 | [-100, -50, 0, 50, 100] |
 | 2 | 100 | 100 选择最大 | 最大 = 100 |
 | 3 | -100 | -100 选择最小的| 最小=-100 |
 | 4 | [-50, 0, 50] | 中| 中间 = [-50, 0, 50] |
 | 5 | 连接| [100] + [-50, 0, 50] + [-100] | [100, -50, 0, 50, -100] |

 该序列产生总和`(100 - (-50)) + (-50 - 0) + (0 - 50) + (50 - (-100)) = 200`。 

**样品2**

 输入：`4\n1 2 3 4\n`| 步骤| 数组| 行动| 结果 |
 | ---| ---| ---| ---|
 | 1 | [1,2,3,4]| 已排序 | [1,2,3,4]|
 | 2 | 4 | 选择最大 | 最大 = 4 |
 | 3 | 1 | 选择最小的| 最小 = 1 |
 | 4 | [2, 3] | 中| 中间 = [2, 3] |
 | 5 | 连接| [4] + [2, 3] + [1] | [4,2,3,1]|

 和：`(4 - 2) + (2 - 3) + (3 - 1) = 3 + (-1) + 2 = 4`，这是最大的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    largest = a[-1]
    smallest = a[0]
    middle = a[1:-1]
    result = [largest] + middle + [smallest]
    return ' '.join(map(str, result))

# Provided samples

assert run("3\n5 5 5\n") == "5 5 5", "all equal"

assert run("6\n0 100 -100 50 -50 25\n") == "100 -50 0 25 50 -100", "mixed numbers"

 ## 边缘情况

 对于`n = 2`，数组`[10, -10]`直接产生`[10, -10]`与总和`20`。 没有中间元素，因此词典编目选择很简单。 例如，当所有数字都相等时`[5, 5, 5]`，最大和为零，任何排列都是有效的。 排序并遵循算法仍然会产生结果`[5, 5, 5]`，按字典顺序排列是最小的。 对于具有负数或混合符号的序列，适用相同的逻辑，排序可确保中间的数字保持字典顺序最小性，同时保留最大差值和。
