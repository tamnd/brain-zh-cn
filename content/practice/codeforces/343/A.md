 ## 解决方案
 ## 问题理解

 我们被要求仅使用单位电阻构建一个电阻网络来实现特定的有理电阻$\frac{a}{b}$。 允许的操作是串联一个电阻，使总电阻增加 1，并联一个电阻，使总电阻变化$R_e$到$\frac{R_e}{R_e + 1}$。 输入由两个整数组成$a$和$b$以不可约形式表示目标电阻的分子和分母。 输出是精确实现该电阻所需的最小单位电阻器数量。 

限制条件很大：$a$和$b$每个都可以达到$10^{18}$。 这立即排除了任何显式模拟所有可能的串联和并联组合的强力方法，因为可能性的数量呈指数增长。 相反，我们需要一种以代数方式处理数字的方法。 

当目标分数为 1 时，会出现微妙的边缘情况。使用始终首先拆分系列的简单递归方法可能会错误地计算额外的电阻或无限循环。 例如，对于输入`1 1`，最小的解决方案是单个电阻，而不是多个串联或并联组成。 对于大于 1 的分数，会出现另一种边缘情况，例如`3 2`，其中需要串联和并联的组合，并且不小心的整数除法可能会产生错误数量的电阻器。 

## 方法

 蛮力方法是递归地尝试串联和并联加法的每种组合，直到分数$\frac{a}{b}$已达到。 在每一步中，如果我们串联一个电阻，我们就会将分子增加分母； 如果我们并行添加，我们就会变换$R \to \frac{R}{R+1}$。 递归将跟踪所使用的电阻器的数量。 这种方法原则上是正确的，但其复杂度是指数级的。 分子和分母高达$10^{18}$，这变得不可行。 

关键的见解是可以使用欧几里得算法来反转该问题。 每个阻力分数都可以简化为以下形式$\frac{a}{b}$，我们可以向后推算：如果$a > b$，最后一个操作一定是级数加法，相当于电阻减 1，减少$\frac{a}{b}$到$\frac{a-b}{b}$。 如果$a < b$，最后一个运算一定是并行加法，可以用代数方式反转为$R \to \frac{R}{1-R}$，给出一个新的分数$\frac{a}{b-a}$。 重复此过程可将问题简化为基本情况$1/1$。 这相当于计算连分数表示中的商之和$a/b$，这直接产生最少数量的电阻器。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 欧几里得/连分数| O(log(最大(a,b))) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.从分数开始$a/b$以不可约的形式。 初始化一个计数器`resistors = 0`。 
2. 虽然$a \neq b$，检查是否$a > b$。 如果是的话，最后一步一定是一系列添加。 减去$b$从$a$并将计数器加 1。 
3.如果$a < b$，最后一步一定是并行加法。 将分数变换为$a/(b-a)$使用并联公式的代数反演。 将计数器加 1。 
4. 重复此过程直至$a = b = 1$。 此时，将计数器加 1 以计算最终电阻。 
5. 输出计数器。 

工作原理：算法的每一步都反映了构建目标电阻所执行的最后操作。 串联加法对应于分子减去分母，并联加法对应于进行“倒数减1”变换。 这确保了我们计算最少数量的电阻器，因为我们总是反转可能产生当前分数的最后一个操作，类似于欧几里德算法中的贪婪步骤。 该过程终止是因为在每一步中$a$或者$b$严格递减，并且基本情况$1/1$已达到。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b = map(int, input().split())
resistors = 0

while a != b:
    if a > b:
        q = a // b
        a -= q * b
        resistors += q
    else:
        q = b // a
        b -= q * a
        resistors += q

resistors += 1
print(resistors)
```该解决方案读取分数，并重复应用类似欧几里德的归约。 除法和减法一次处理多个串联或并行加法，防止缓慢的逐一递减。 决赛`resistors += 1`占最后一个单位电阻对应`1/1`。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a, b = map(int, input().split())
    resistors = 0
    while a != b:
        if a > b:
            q = a // b
            a -= q * b
            resistors += q
        else:
            q = b // a
            b -= q * a
            resistors += q
    resistors += 1
    return str(resistors)
