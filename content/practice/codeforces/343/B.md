 ## 解决方案
 ## 问题理解

 我们得到了一个序列，描述了两条电线（一根称为“正”，另一根称为“负”）从设备的左侧延伸到右侧时如何重叠。 在沿路径的每个位置，其中一根导线实际上位于另一根导线的上方。 “+”字符表示该位置的正极线位于负极线上方，而“-”表示负极线位于正极线上方。 

左侧是固定的：正极线从顶部触点开始，负极线从底部触点开始。 只要我们不切断它们或分离它们的端点，我们就可以在平面上自由移动电线。 问题是我们是否可以不断地使电线变形，使它们最终完全不缠结，这意味着不保留交叉点，同时保留端点。 

输入长度最多可达 100000。这排除了任何尝试显式建模电线几何形状或维护通过昂贵的更新动态变化的交叉结构的模拟。 任何字符数量的二次方都会太慢。 

一个微妙的点是该序列并未描述独立的交叉。 它描述了一种连续的辫状相互作用。 两个连续的相同符号不一定与分开的符号具有相同的行为方式，因为一根导线完全“缠绕”另一根导线被编码为特定的交替模式。 

一个天真的错误是假设我们可以取消相邻的相反交叉或将序列视为类似于括号的堆栈减少问题。 例如，将“+”解释为打开事件，将“-”解释为关闭事件会立即失败：

 输入：```
-+
```一个天真的取消想法可能会建议交叉点取消，但正确的答案是“否”，因为这代表了一个完整的扭曲，如果不移动端点就无法将其删除。 

另一种失败情况是独立处理每个“+”并简单地检查计数是否平衡。 在计数逻辑下，序列“+-+-”看起来似乎无害，但它可以表示一个非平凡的编织结构，必须将其解释为单个全局约束。 

## 方法

 思考该问题的一种强力方法是模拟平面中两条曲线的实际变形。 人们可以将电线建模为折线，并在跟踪交叉点的同时反复尝试局部拉直线段。 每次我们移除一个交叉点时，其他地方可能会出现新的交叉点，因此此过程可能需要多次重新访问整个结构。 在最坏的情况下，每个局部调整都会与所有先前的局部调整相互作用，导致序列长度上的更新数量呈二次或更差。 

关键的观察是，我们实际上并不关心几何形状，只关心序列是否编码一根线绕另一根线的重要“缠绕”。 这将问题简化为跟踪前缀结构是否强制出现不可能状态。 

关键的简化是，该序列的行为就像一堆方向变化，重要的是我们是否以需要通过另一个端点约束提升电线的方式“过度取消”交叉。 我们可以将这个过程解释为跟踪单个整数余额，其中我们根据正线是否高于或低于来递增或递减，但有一个重要的约束：如果余额以强制反转固定端点的方式超出阈值，则配置变得不可能。 

这会导致贪婪的线性扫描，其中我们维护一个表示当前相对缠绕状态的计数器。 每当我们看到一个符号时，我们都会调整计数器，但我们也强制计数器永远不会违反固定端点引起的约束。 最终状态决定了辫子是否平凡。 

在这个特定问题中，条件简化为检查序列是否编码了完整的旋转。 这可以通过确保我们一次不需要超过一个不平衡的活动“层”来检测，这相当于确保运行状态的绝对值永远不会超过 1，从而强制换行。

 ## 算法演练

 我们从左到右处理序列，同时保持单个整数状态`bal`。 

1. 初始化`bal = 0`。 这表示，在考虑任何交叉之前，系统处于与固定端点一致的中性配置。 
2. 扫描序列中的每个字符。 如果字符是“+”，我们将其视为向上推配置，因此我们递增`bal`by 1. 如果是“-”，我们减1`bal`1. 这个模型模拟了每个局部交叉如何影响相对排序。 
3. 每次更新后，检查状态是否已陷入不可能的状态。 如果在任何一点的大小`bal`超过 1，我们立即得出结论，该配置代表了在固定端点下无法撤消的完整扭曲，因此我们拒绝。 
4. 如果扫描在不违反约束的情况下完成，则配置可以连续解开，因此我们接受。 

阈值检查背后的关键思想是，任何累积超过一个不平衡单位的尝试都会迫使一根导线以一种在不改变端点顺序的情况下无法撤消的方式“缠绕”另一根导线。 

### 为什么它有效

 该过程在端点固定且有序的约束下隐式跟踪两根导线之间的网络绕组。 任何有效的解开都对应于在任何前缀处不会引入超过一个局部优势的变形。 如果运行不平衡超过这个界限，它就会编码一根导线围绕另一根导线的完整旋转，这是一种拓扑障碍，无法仅通过平面变形来消除。 因此，该算法是安全的，因为它准确地拒绝那些强制进行这种旋转的序列，并接受不平衡仍然可以局部解决的所有其他序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()

bal = 0
for ch in s:
    if ch == '+':
        bal += 1
    else:
        bal -= 1
    
    if abs(bal) > 1:
        print("No")
        sys.exit()

print("Yes")
```该代码维护一个正在运行的计数器，并在每个字符的恒定时间内更新它。 尽早退出很重要，因为一旦配置变得不可能，进一步的处理就无法恢复有效性。 

唯一的微妙之处是我们必须在每次更新后立即检查约束，而不仅仅是在最后。 延迟检查将导致无效的中间配置被错误地接受。

```| 步骤| 字符 | 巴尔 | 腹肌（平衡）| 决定|

这些痕迹显示了如何在本地强制执行约束并防止不可移动结构的累积。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        s = input().strip()
        bal = 0
        for ch in s:
            if ch == '+':
                bal += 1
            else:
                bal -= 1
            if abs(bal) > 1:
                return "No"
        return "Yes"
    finally:
        sys.stdin = old_stdin

# provided sample
assert run("-++-") == "Yes"

# minimum size
assert run("+") == "Yes"

# immediate invalid wrap
assert run("--") == "No"

# alternating safe case
assert run("+-+-") == "Yes"

# longer valid neutral sequence
assert run("-+-++-") == "Yes"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 | + | 是的 | 最小有效配置|
 | --| 没有 | 立即违规检测|
 | +-+- | 是的 | 交替序列保持有界 |
 | -+-++- | 是的 | 无溢出的混合序列|

 ## 边缘情况

 单字符输入（如“+”或“-”）始终保持有效，因为它无法创建完整的换行。 该算法处理一次更新并立即完成，不会超过阈值。 

诸如“--”之类的两个字符序列表明最早可能发生的故障。 第二步之后，余额变为-2，这立即违反了约束。 该算法此时会正确拒绝，无需进一步扫描。 

诸如“+-+-”之类的交替序列永远不会累积超过一个单位的不平衡。 运行状态在 -1、0 和 1 之间振荡，这对应于可以通过将一根导线滑过另一根导线来移除的局部交叉，而无需更改端点顺序。 

像“-+-++-”这样的混合较长序列表明，即使前缀包含两个方向，只要运行不平衡不超过允许的范围，结构就保持清晰。 该算法通过在每个前缀处强制执行约束而不是依赖于最终总和来保持正确性。
