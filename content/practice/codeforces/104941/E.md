 ## 解决方案
 ## 问题理解

 我们得到了一个由道路连接的城镇的无向图，Womais 可以在其中任意次数地遍历边，甚至可以自由地重新访问顶点。 他从一个固定的城镇开始$s$并想要到达目的地$t$。 每经过一条道路都会为总行走长度贡献长度 1。 

问题不在于找到一条最短路径，而在于所有可能的路径的奇偶结构$s$到$t$。 我们必须确定每一次有效的步行是否来自$s$到$t$总长度为偶数。 如果即使一次步行的长度为奇数，则答案变为“否”。 

该图可以很大，最大可达$2 \cdot 10^5$顶点和边，因此任何枚举路径甚至存储所有简单路径的方法都是不可能的。 即使仅跟踪顶点的简单 BFS 也是不够的，因为奇偶校验取决于如何到达顶点，而不仅仅是是否到达。 

一个关键的微妙之处是重新访问节点会改变一切。 包含环的图允许相同的两个节点之间有无限多个不同的行走长度。 例如，如果有任何循环可以从$s$在前往的路线上$t$，我们可以通过围绕该周期来调整步行的奇偶性。 

打破天真的思维的典型边缘情况是三角形：

 输入：```
3 3
1 2
1 3
3 2
2 1
```从 1 到 2 有两条不同的步道：直达（长度 1）和途经 3（长度 2）。 由于双方都存在，所以正确答案是“否”。 

另一个重要的例子是一棵树。 在一棵树中，只有一条简单路径，因此所有行走都会简化为该路径加上长度为 2 的回溯循环，从而保留奇偶性。 因此，树总是仅根据唯一的路径长度给出“是”或“否”。 

核心困难是确定图表何时强制之间存在唯一的奇偶性$s$和$t$，以及何时可以通过替代路线翻转奇偶校验。 

## 方法

 蛮力方法将尝试探索从$s$到$t$，跟踪路径长度并检查奇数长度的步行是否与偶数长度的步行一起存在。 这会立即失败，因为在有循环的图中，游走是无限的。 即使限制在有限的深度也无济于事，因为循环可以被任意多次遍历，产生任意大的路径族。 状态空间的边数呈指数增长，使得这种方法在计算上不可行。 

更结构化的观点来自于将问题转化为奇偶可达性问题。 我们不只是跟踪哪些顶点是可到达的，而是跟踪一个顶点是否可以以偶数或奇数距离到达$s$。 这自然地暗示了一个图复制的想法：每个节点$u$分为两种状态，$u_0$和$u_1$，表示距离奇偶性。 每条边都会翻转奇偶校验，因此我们连接$u_0 \to v_1$和$u_1 \to v_0$。 

现在的问题是是否存在一条从$s_0$到$t_1$。 如果存在这样的路径，则存在奇数长度的步行。 如果不存在，则所有可达步行$t$必须是均匀的。 

然而，这仍然没有完全抓住问题的要求。 我们不会被问到是否存在奇数行走，而是询问是否所有行走都是偶数。 这相当于检查是否$t_1$无法从以下位置到达$s_0$在奇偶扩展图中。 

关键的观察是扩展图的结构仅取决于连接的组件和类似二分性的约束。 如果在两个奇偶校验中都可到达顶点的情况下存在冲突，则存在允许奇偶校验翻转的循环，这意味着偶数游走和奇数游走均存在。 因此，检测奇偶校验分配是否一致就相当于检查修改后的双向性。 

我们有效地执行 BFS，将奇偶校验分配给每个节点$s$。 如果我们试图将冲突的奇偶校验分配给同一个节点，我们会检测到两个奇偶校验都可能在图中的某个位置，这意味着之间存在偶数和奇数游走$s$和$t$。 否则，奇偶校验是一致且固定的。 

这将问题简化为具有奇偶校验跟踪的图上的单个 BFS/DFS。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力横扫各行各业| 指数| 指数| 太慢了 |
 | 双重状态上的奇偶 BFS |$O(n + m)$|$O(n)$| 已接受 |

 ## 算法演练

 我们使用相对于起始节点的奇偶校验状态对每个顶点进行建模$s$。 

1.初始化一个数组`dist`尺寸的$n$值为-1，表示未访问。 放`dist[s] = 0`因为到自身的距离是偶数。 
2. 从以下位置开始运行 BFS$s$，使用顶点队列。 每次我们穿过一条边$u \to v$，我们尝试分配`dist[v] = dist[u] XOR 1`。 这编码了每个边缘翻转奇偶校验的事实。 
3. 如果我们到达一个顶点$v$如果已经有一个值，并且新计算的奇偶校验与现有的奇偶校验冲突，我们不会覆盖它，而是记录存在矛盾。 
4. BFS完成后，我们检查是否$t$已分配奇偶校验以及是否观察到任何矛盾。 
5. 如果在连通分量中任何地方存在矛盾$s$，那么偶数和奇数行走之间都可能$s$和$t$，所以我们输出“No”。 
6. 否则，奇偶校验是固定的。 如果`dist[t] == 1`，则仅存在奇数长度结构，但由于不存在矛盾，因此所有路径都保持奇偶性。 如果`dist[t] == 0`，所有的行走都是偶数，所以我们输出“Yes”。 

关键思想是矛盾对应于可从以下位置到达的奇数循环$s$，允许奇偶校验翻转而不改变连接。 

### 为什么它有效

 每个 BFS 分配都会强制执行以下连接组件的一致奇偶校验标记：$s$。 如果组件是二分的，则每个边缘一致地强制相反的奇偶校验分配，因此两个节点之间的每次行走都具有相同的奇偶校验。 如果该分量不是二分的，则至少存在一个奇数循环，这允许游走以翻转奇偶校验返回到同一顶点。 这使得该组件中任意两个顶点之间的偶数和奇数长度行走都成为可能。 因此，一致的奇偶标记的存在正是所有在两者之间行走的条件$s$和$t$共享相同的平价。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    s, t = map(int, input().split())
    s -= 1
    t -= 1

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    dist = [-1] * n
    q = deque()
    dist[s] = 0
    q.append(s)

    ok = True

    while q:
        u = q.popleft()
        for v in g[u]:
            nd = dist[u] ^ 1
            if dist[v] == -1:
                dist[v] = nd
                q.append(v)
            elif dist[v] != nd:
                ok = False

    if not ok:
        print("No")
        return

    print("Yes")

if __name__ == "__main__":
    solve()
```该图被构建为标准邻接表。 BFS 开始于$s$并分配奇偶校验级别。 XOR 运算是关键的实现细节，无需额外的状态结构即可编码边缘遍历奇偶校验翻转。 这`ok`flag 跟踪是否出现任何奇偶校验矛盾，这对应于检测连接组件中的奇数循环。 

最终决定完全取决于奇偶校验分配是否保持一致。 如果是这样，则之间的所有行走$s$和$t$具有相同的奇偶性，在这个公式中意味着不存在构建偶数和奇数替代方案的方法。

 ## 边缘情况

 关键的边缘情况是图是简单路径。 在这种情况下，BFS 干净地分配交替奇偶校验，没有矛盾。 例如：```
4 3
1 4
1 2
2 3
3 4
```遍历分配1→0、2→1、3→0、4→1。 不会发生冲突，因此各行各业的平等都是固定的。 由于不存在循环，因此不存在替代奇偶校验路径。 

另一种情况是包含可从以下位置到达的奇数循环的图：$s$但不一定是最短路径$t$。 即使$t$位于循环之外，循环允许返回到具有翻转奇偶校验的早期节点，最终将矛盾传播到可达结构中。 这确保了算法仍然标记不一致，即使循环不是直接在一个$s \to t$路线。 

最后一个微妙的情况是$s$等于$t$。 问题保证它们不同，但如果它们相等，答案将始终是“是”，因为空走的长度为零，并且任何循环只会引入额外但不相关的替代方案。
