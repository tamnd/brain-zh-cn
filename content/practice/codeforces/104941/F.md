 ## 问题理解

 我们有一组参赛者，每个参赛者都用两个整数描述。 认为每个参赛者都有两个“动作”：第一个动作是$a_i$，第二步是$b_i$。 如果我们选择两个不同的参赛者$i$和$j$，他们玩两个游戏：在第一个游戏中我们比较$a_i$与$a_j$，在第二场比赛中我们比较$b_i$与$b_j$。 每场比赛的得分是所选数值的绝对差值。 所以第一场比赛贡献$|a_i - a_j|$，第二个贡献$|b_i - b_j|$。 

如果这两个值重合，则认为一对参赛者表现不佳，这意味着$$|a_i - a_j| = |b_i - b_j|.$$任务是计算有多少对是好的，即有多少对违反了这个等式。 

输入大小可达$n = 3 \cdot 10^5$，因此任何对上的二次枚举都会立即变得太慢。 解必须接近线性或$n \log n$， 自从$n^2$意思是关于$10^{10}$最坏情况下的比较。 

一个微妙的边缘情况是当许多对共享相同的结构时，这可能会导致差异的幼稚散列发生冲突或错过符号变体。 例如，如果所有参赛者都相同，则每一对都满足平等，因此答案为零。 任何仅部分捕获绝对差条件而不处理符号对称性的方法在以下情况下都会失败：$$(1, 5), (5, 1), (3, 3).$$另一个棘手的情况是当差异相等但来自不同的符号配置时，例如：$$|a_i - a_j| = |b_i - b_j| \iff a_i - a_j = b_i - b_j \ \text{or}\ a_i - a_j = -(b_i - b_j).$$遗漏其中一个案例会导致多算好对。 

## 方法

 直接方法很简单：迭代所有对$i < j$并检查是否$|a_i - a_j| = |b_i - b_j|$。 这是正确的，但要付出代价$O(n^2)$比较。 和$n = 3 \cdot 10^5$，这是远远不可能的。 

关键的观察是将绝对值条件分解为两个线性等式来消除绝对值条件：$$a_i - a_j = b_i - b_j \quad \text{or} \quad a_i - a_j = -(b_i - b_j).$$重新排列给出：$$a_i - b_i = a_j - b_j \quad \text{or} \quad a_i + b_i = a_j + b_j.$$因此，当某个值满足以下任一条件时，一对就是“坏”的：$a_i - b_i$匹配或值$a_i + b_i$匹配。 这将问题简化为计算两个不同的派生数组中的相等对。 

然而，直接将两个计数相加会超出同时满足两个等式的对的计数。 当以下情况发生时，就会发生这种情况：$$a_i - b_i = a_j - b_j \quad \text{and} \quad a_i + b_i = a_j + b_j,$$这意味着$(a_i, b_i) = (a_j, b_j)$。 因此，必须仔细纠正重复的内容。 

因此我们计算：

 1.总对，
 2. 通过和与差等式减去“坏”对，并使用频率计数仔细处理重复项。 

有效的解决方案使用排序或哈希图来计算转换后的键的频率$a_i - b_i$和$a_i + b_i$。

 ## 算法演练

 我们将条件重写为两个独立的关键系统：$d_i = a_i - b_i$和$s_i = a_i + b_i$。 我们计算每个系统中有多少对共享相同的值。 

1. 将总对数计算为$\frac{n(n-1)}{2}$。 这是我们减去“坏”对的基线。 
2. 为所有值构建频率图$d_i = a_i - b_i$。 对于出现的每个不同值$f$次，它贡献$\frac{f(f-1)}{2}$坏对。 这计算了所有满足的对$a_i - b_i = a_j - b_j$。 
3. 为所有值构建第二个频率图$s_i = a_i + b_i$。 同样，每个频率$f$贡献$\frac{f(f-1)}{2}$对，其中$a_i + b_i = a_j + b_j$。 
4. 将两个映射的贡献相加，以获得至少满足一个坏等式的对的总数。 该总和会重复计算两个条件都成立的对。 
5. 识别重复项
