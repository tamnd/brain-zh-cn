 ## 解决方案
 ## 问题理解

 我们正在研究一个矩形城市网格$N$行和$M$列。 您可以放置$K$任意网格单元上的消防站。 每个站都可以使用切比雪夫距离到达其他单元，这意味着允许在八个方向上移动，并且两个单元之间的距离是它们的行差和列差的最大值。 

放置在单元上的站可以有效保护以该位置为中心的正方形内的所有单元，边长$2d+1$，因为切比雪夫距离内的每个单元格$d$满足$\max(|x_1-x_2|, |y_1-y_2|)\le d$。 

任务是最优地选择站点位置，使得网格中的每个单元都被至少一个站点覆盖，并且我们希望尽可能最小的站点$d$对此最多可以实现$K$站。 

网格可以非常大，最多可达$10^9 \times 10^9$，所以我们不能逐个单元地模拟任何东西。 站的数量要少得多，最多$10^5$，这表明解决方案必须将网格压缩为结构计数问题。 

一个天真的尝试会尝试放置站点并模拟覆盖范围，但即使代表网格也是不可能的。 另一个天真的想法是尝试所有的位置$K$站，但这具有爆炸性，即使对于微小的输入也无关紧要。 

出现微妙的边缘情况时$N$和$M$都很小但是$K$很大。 例如，如果$N=M=2$和$K=4$， 然后$d=0$就足够了，因为每个站恰好覆盖一个小区。 任何假设的解决方案$d\ge 1$默认情况下会在这里失败。 

主要挑战是认识到覆盖范围仅取决于有多少$(2d+1)\times(2d+1)$需要用正方形来平铺网格，而不是精确的站点放置。 

## 方法

 蛮力观点从固定候选距离开始$d$。 如果一个车站覆盖一个正方形的边$2d+1$，那么网格必须被这些正方形覆盖。 人们可以尝试以所有可能的方式放置站点并检查覆盖范围，但这是不可行的，因为电网最多有$10^{18}$单元格，甚至枚举位置也是不可能的。 

关键的观察是一旦$d$是固定的，最优的排列总是网格状的堆积。 每个站点覆盖一个连续的块，因此为了最大限度地减少站点的数量，我们将这些块打包成常规平铺而不重叠。 沿着每个维度，我们需要$\lceil N/(2d+1)\rceil$垂直块和$\lceil M/(2d+1)\rceil$水平块。 他们的产品给出了所需的最少站数$d$。 

这将问题从几何放置转变为简单的可行性检查。 然后我们寻找最小的$d$使得所需的块数不超过$K$。 自从增加$d$仅增加覆盖范围大小，可行性是单调的，这使得二分搜索适用。

 | 暴力放置 | 不可行（指数）| O(1) | O(1) | 太慢了 |

 ## 算法演练

 我们对待$d$作为变量，我们要最小化并检查给定的$d$就足够了。 

1.对于固定的$d$，计算覆盖边长为$s = 2d + 1$。 这代表一个站点在每个方向上可以完全覆盖多少个连续小区。 
2. 计算垂直覆盖网格需要多少个站：$a = \lceil N / s \rceil$。 这计算了有多少条垂直高度的条带$s$是必需的。 
3. 计算水平方向需要多少个站：$b = \lceil M / s \rceil$。 这计算了水平条的宽度$s$。 
4. 所需站点总数为$a \times b$。 这相当于在完整的网格分解中每个块放置一个站点。 
5. 检查是否$a \times b \le K$。 如果是，那么距离$d$就足够了； 否则就太小了。 
6. 使用二分查找$d$从$0$最多$\max(N, M)$，保持最小可行值。 

二分查找有效的原因是增加$d$只会增加$s$，这减少了$\lceil N/s \rceil$和$\lceil M/s \rceil$，因此所需的站数永远不会增加。 

### 为什么它有效

 对于任何固定的$d$，网格最多可以被划分为大小的块$(2d+1)\times(2d+1)$。 每个站点无法覆盖多个这样的块边界交叉区域而不浪费覆盖范围，因此最佳布置就像平铺一样。 表达式$\lceil N/s\rceil \cdot \lceil M/s\rceil$不仅仅是一种构造，它是最小可能的计数，因为任何覆盖都必须为由该分区引起的每个不相交块区域分配至少一个站点。 这使得可行性检查精确而不是近似，因此对其进行二分搜索会产生真正的最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can(d, n, m, k):
    s = 2 * d + 1
    a = (n + s - 1) // s
    b = (m + s - 1) // s
    return a * b <= k

def solve():
    n, m, k = map(int, input().split())

    lo, hi = 0, max(n, m)

    while lo < hi:
        mid = (lo + hi) // 2
        if can(mid, n, m, k):
            hi = mid
        else:
            lo = mid + 1

    print(lo)

if __name__ == "__main__":
    solve()
```该解决方案是围绕单调可行性测试构建的。 功能`can`直接编码平铺参数：它转换半径$d$转换为块大小并计算每个维度需要多少个块。 

二分查找保持以下任何值的不变性`lo`是不可行的并且任何等于或以上的值`hi`是潜在可行的。 中点检查逐渐缩小区间，直到最小有效值$d$被发现。 

唯一微妙的一点是确保正确处理整数上限除法，因为这里的差一错误会直接改变所需站的数量。

 ## 边缘情况

 当$N$和$M$均为 1，算法计算$d=0$立即从$s=1$并且只需要一个站。 可行性检查正确返回 true，无需任何特殊处理。 

当网格极度倾斜时，例如$1 \times M$，计算简化为一维覆盖问题。 该公式仍然适用，因为其中之一$a$或者$b$变为 1，另一个捕获沿线的完整分割。 

什么时候$K$与网格大小相比非常大，算法仍然正确返回$d=0$， 自从$\lceil N/1\rceil \cdot \lceil M/1\rceil = N \cdot M \le K$是唯一重要的条件。
