 ## 解决方案
 ## 问题理解

 我们从一个整数列表开始。 两名玩家轮流进行，从 Naya 开始，每一步都包括从当前列表中选择任意两个数字，删除它们，然后插入它们的最大公约数。 恰好经过 N − 1 次移动后，只剩下一个数字。 

最终值完全取决于成对 gcd 运算的顺序。 由于玩家轮流进行并且双方都发挥最佳状态，所以真正的问题不是模拟游戏，而是确定 Naya 是否可以强制最后剩余的数字恰好为 1，或者 Hassan 是否可以阻止该结果。 

约束最多允许 200,000 个数字，每个数字最多 10^9。 任何试图模拟该过程的解决方案都会直接执行 N-1 次合并操作，并且每个操作都涉及扫描或重新计算候选者。 即使每一步都是 O(N)，总数也已经是二次的并且远远超出了限制。 这立即排除了任何显式模拟游戏状态的方法。 

一个微妙但关键的边缘情况是当数组已经包含 1 时。在这种情况下，涉及该元素的任何 gcd 都会生成 1，因此游戏可能会被迫立即以 1 结束。 另一个边缘情况是所有数字共享一个大于 1 的公因数。例如，如果所有值都是偶数，则每个 gcd 保持偶数，因此无论玩什么游戏都不可能达到 1。 

真正的困难在于理解最终的价值是由玩家的选择控制的还是由结构决定的。 

## 方法

 暴力破解的解释很简单：模拟游戏状态。 在每一步中，尝试所有可能的对，计算所得的 gcd，对两个玩家进行递归，并确定 Naya 是否有获胜策略。 这形成了一个游戏树，其中每个状态分支为 O(N^2) 种可能性，深度为 N − 1。即使是激进的记忆也无济于事，因为数组状态会随着每次合并而组合变化，并且不同的多重集会在计数上爆炸。 

失败点在于操作不独立。 每次合并都会以保留深度不变量的方式更改多重集：整个数组的 gcd 结构由全局 gcd 控制，而不是由本地配对选择控制。 

关键的观察结果是 gcd 是结合律和交换律的。 无论如何选择对，对所有元素重复应用 gcd 后的最终单个数字始终是整个数组的 gcd。 游戏并没有改变这个事实； 它仅决定元素组合的顺序。 

所以唯一的问题是 Naya 是否可以强制过程以值 1 结束。由于最终值固定为 gcd(A1, A2, ..., AN)，所以游戏简化为检查这个全局 gcd 是否等于 1。如果是 1，Naya 就保证获胜。 如果它大于 1，则任何移动序列都无法进一步减小它。 

这消除了所有游戏的复杂性：最佳游戏并不重要，因为结果是不变的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| 指数| O(N) 到 O(N^2) 状态 | 太慢了 |
 | 计算全局 GCD | O(N log A) | O(N log A) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取数组大小和数组值。 除了这些初始值之外，游戏的结构无关紧要，因为所有后续操作都保留单个不变量。 
2. 迭代计算数组中所有元素的 gcd。 从第一个元素开始，将 gcd 操作折叠到整个列表中。 这将构建代表所有合并后最终可能值的全局 gcd。 
3. 计算出全局gcd后，检查是否等于1。 
4. 如果等于1，则输出Naya，否则输出Hassan。

关键的推理步骤是每次操作都用 gcd(X, Y) 替换两个数字 X 和 Y，这不能引入任何新的素因子，只能保留或删除现有的素因子。 在整个序列上重复此操作相当于计算整个多重集的 gcd。 

### 为什么它有效

 不变的是，在任何操作序列之后，所有剩余元素的 gcd 与原始数组的 gcd 相同。 每个替换步骤都会保留多重集的 gcd，因为 gcd(X, Y) 可除 X 和 Y，因此替换它们不会改变整体 gcd。 由于该过程以单个数字结束，因此该数字必须等于所有初始元素的 gcd。 游戏选择仅影响中间分组，而不影响最终的不变值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import gcd

def main():
    n = int(input())
    arr = list(map(int, input().split()))
    
    g = 0
    for x in arr:
        g = gcd(g, x)
    
    if g == 1:
        print("Naya")
    else:
        print("Hassan")

if __name__ == "__main__":
    main()
```该实现保持一个正在运行的 gcd 累加器。 使用 0 进行初始化是有效的，因为 gcd(0, x) = x，因此第一个元素正确地播种该值。 每次更新都会在数组上以线性时间将下一个元素折叠到全局 gcd 中。 

最后的决定是与1直接比较，反映结构上是否可以完全归约到1。

 ## 边缘情况

 单元素情况是最干净的边界。 如果 N = 1 并且值为 1，则答案立即为 Naya，因为不需要任何操作。 如果 N = 1 并且该值大于 1，则最终值就是该数字，因此哈桑获胜。 该算法自然地处理这个问题，因为 gcd 循环返回元素本身。 

对于像 [4, 8, 12, 16] 这样的完全一致的数组，每次合并都会保留均匀性，并且运行的 gcd 保持为 4。最终的输出是 Hassan。 跟踪算法，累加器从 0 开始，在第一个元素之后变为 4，并且永远不会偏离 4。 

对于至少包含一个 1 的数组，例如 [10, 15, 1, 27]，在处理 1 的点处 gcd 立即降至 1。 从那时起，无论进一步输入如何，它都保持为 1，保证了 Naya 的胜利。
