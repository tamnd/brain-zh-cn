 ## 解决方案
 ## 问题理解

 我们被要求使用两种颜色对排成一行的不同整数序列进行着色，以便两个条件同时成立。 首先，原始序列中任意两个相邻的数字必须具有不同的颜色。 其次，如果我们将数字按升序排列，则新序列中的相邻数字也必须具有不同的颜色。 输入给出了多个测试用例，每个测试用例提供了卡片的数量及其整数值。 如果存在有效的着色，则每个测试用例的输出只是“是”，否则为“否”。 

限制很小：一个测试用例中的卡片数量最多为 100 张，测试用例最多为 200 个。 这意味着即使是 O(n²) 解决方案通常也会运行得足够快，但我们应该努力采用线性或线性算术方法，因为可以通过洞察力而不是对所有着色进行强力检查来解决问题。 

一个微妙之处是我们不能仅仅独立地替换原始数组或排序数组中的颜色。 考虑顺序`[2, 3, 1]`。 原始颜色的交替给出`[red, blue, red]`，但是排序后`[1, 2, 3]`颜色变成`[red, red, blue]`，失败了。 当最小或最大元素出现在强制排序序列中重复颜色的位置时，就会出现边缘情况。 这表明原始数组中的邻接关系并不简单地映射到排序数组中的邻接关系。 

## 方法

 暴力方法会尝试数组的所有 2ⁿ 可能的颜色并检查这两个条件。 这是正确的，因为它检查了每种可能性，但对于 n = 100 来说显然是不切实际的，因为 2^⁰⁰ 是一个天文数字。 即使对于较小的 n，也没有必要，因为问题具有隐藏结构。 

关键的观察是，如果序列根据排序顺序和原始顺序是“之字形着色”，则可以同时满足这两个条件。 如果我们标记排序序列中的位置，则这些位置之间交替的颜色可确保满足排序的邻接性。 在实践中，我们可以根据排序顺序的索引分配颜色：奇数索引获得一种颜色，偶数索引获得另一种颜色。 按排序顺序分配颜色后，我们将它们映射回原始位置。 然后我们只需要验证原始数组中的相邻元素是否具有不同的颜色。 如果存在，则存在有效的着色。 否则，它不会。 这是可行的，因为按排序顺序交替可以保证排序条件，并且 n 的小尺寸允许我们有效地检查原始数组中的邻接关系。

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取 n 和数组 a。 我们需要独立处理每个数组。 
2. 构建包含每个元素及其原始索引的元组列表。 这允许我们在记住原始位置的同时对数组进行排序。 
3. 按值对数组进行排序。 排序后，沿排序数组分配交替颜色。 例如，索引 0（最小值）获取颜色 0，索引 1 获取颜色 1，依此类推。 将颜色分配存储在映射到原始索引的单独数组中。 
4. 迭代原始数组。 对于每对相邻元素，检查它们分配的颜色是否不同。 如果任何一对具有相同的颜色，则此测试用例的答案为“否”。 
5. 如果所有相邻对都有不同的颜色，则答案为“是”。 输出结果并继续下一个测试用例。 

为什么有效：通过按排序顺序交替颜色，我们保证满足排序邻接关系。 通过将颜色映射回原始位置，我们可以检查是否保留了原始邻接关系。 该算法利用了这样一个事实：对于两种颜色，沿着排序顺序交替分配可以最大限度地减少冲突，并且较小的数组大小使我们能够轻松检测冲突。 如果存在冲突，则没有其他颜色可以同时满足这两个条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        indexed_a = list(enumerate(a))
        indexed_a.sort(key=lambda x: x[1])
        
        color = [0] * n
        for i, (idx, _) in enumerate(indexed_a):
            color[idx] = i % 2  # alternate colors in sorted order
        
        ok = True
        for i in range(n - 1):
            if color[i] == color[i + 1]:
                ok = False
                break
        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```该代码首先枚举元素以保留原始位置并按值排序。 然后，它沿着排序顺序交替分配颜色并映射回原始位置。 最后，它检查原始数组中的邻接性并输出结果。 使用模可以确保我们正确地交替颜色，并且检查循环可以有效地检测任何无效的邻接。

 ## 边缘情况

 对于`[2,3,1]`，排序后的序列`[1,2,3]`如果我们尝试按原始顺序任意替换颜色，则会发生冲突。 该算法根据排序位置分配颜色：`[0,1,2] → colors 0,1,0]`。 映射回原始索引给出`[1,0,0]`。 检查原始邻接关系，位置 1 和 2 的颜色均为 0，产生冲突。 输出为“否”，确认算法正确处理了这种边缘情况。 类似地，大小为 2 的数组始终是可解的，因为两个元素始终可以具有不同的颜色，并且排序顺序将保留这种交替。
