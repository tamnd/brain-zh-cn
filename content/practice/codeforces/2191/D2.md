 ## 解决方案
 ## 问题理解

 我们得到一个字符串`s`括号长度`n`。 任务是考虑所有非空子序列`s`并为每个计算一个“分数”。 分数定义如下：如果子序列不是正则括号序列，则其分数为0。如果它是正则括号序列，我们根据类似字典序的比较来查找比当前序列“更好”的最长正则括号子序列，其中左括号`(`比结束更好`)`。 子序列的得分就是该最佳子序列的长度。 最后，我们需要将所有这些分数的总和模 998244353。 

约束很小：所有约束的总和`n`所有测试用例的数量最多为 100。这意味着我们可以负担大约 O(n^3) 或稍高的算法，因为在最坏的情况下，2 秒限制的操作总数仍然是可以接受的。 

当序列仅包含一种类型的括号时，会出现不明显的边缘情况。 例如，`s = "("`或者`s = "))))"`。 这里的所有子序列要么不完整，要么不平衡，因此正确的分数是 0。粗心的实现可能会尝试构建一个“更好”的子序列，并错误地假设单个子序列`(`可以形成有效的对。 

另一个棘手的情况是当序列完全规则时，例如`s = "()()"`。 在这里，我们必须检查所有子序列并正确识别按字典顺序比子序列本身更好的最长子序列。 这种微妙之处需要仔细记录位置和计数，而不仅仅是长度。 

## 方法

 蛮力方法将枚举所有 2^n 个非空子序列`s`。 对于每个子序列，我们将检查它是否是常规括号序列，然后再次枚举其所有子序列以找到“更好”的最长子序列。 这在原则上是正确的，但对于 n ≥ 20 来说完全不可行，因为实际上无法生成 2^100 个子序列。 

关键的观察结果是，分数仅取决于左括号和右括号的数量及其相对位置。 我们可以使用动态规划来跟踪在给定余额下构建子序列的方法数量，而不是生成子序列。 定义DP状态`dp[i][j]`作为使用第一个的子序列的数量`i`目前有平衡的角色`j`（数量`(`减去数量`)`迄今为止）。 然后我们可以通过包含或跳过下一个括号来更新它。 当我们遇到右括号时，任何以正平衡结尾的子序列都可能对分数有所贡献。 

最优方法将问题简化为前缀和和余额上的 DP，有效地计算每个子序列的贡献，而无需显式枚举它们。 我们还维护一个并行数组来存储每个州贡献的总分。 然后通过对有效状态进行求和来计算总和，最后余额为零。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * 2^n) | O(2^n * 2^n) | O(2^n) | O(2^n) | 太慢了|
 | DP 超平衡 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.初始化一个DP数组`dp[i][j]`在哪里`i`范围从 0 到 n 且`j`超过 0 到 n。 这里`dp[i][j]`表示第一个子序列的数量`i`具有平衡性的角色`j`。 同时初始化`score[i][j]`存储这些子序列的分数总和。 
2. 设置基本情况`dp[0][0] = 1`因为空子序列的余额为零。`score[0][0] = 0`。 
3. 从左到右迭代字符串。 对于每个角色`s[i]`对于每个可能的平衡`j`从 0 到 n：

 - 如果`s[i]`是`(`，我们可以跳过它（保留`dp[i+1][j] += dp[i][j]`和`score[i+1][j] += score[i][j]`）或包含它（增加余额：`dp[i+1][j+1] += dp[i][j]`和`score[i+1][j+1] += score[i][j]`）。 
- 如果`s[i]`是`)`，我们可以跳过它或仅在以下情况下包含它`j > 0`（关闭的数量不能超过我们打开的数量）。 包含后，余额会减少`j-1`，分数增加 2，因为添加匹配对扩展了子序列。 所以`dp[i+1][j-1] += dp[i][j]`和`score[i+1][j-1] += score[i][j] + 2*dp[i][j]`。 
4.处理完所有字符后，答案就是`score[n][0]`模 998244353。只有最终余额为零的子序列才是有效的常规括号序列。 
5. 对每个测试用例重复此操作。 

关键的不变量是`dp[i][j]`和`score[i][j]`使用第一个正确地解释所有子序列`i`具有平衡性的人物`j`。 通过仔细包含或跳过每个括号并仅在右括号形成一对时更新分数，我们确保每个有效子序列对总和贡献正确的金额。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

for _ in range(int(input())):
    n = int(input())
    s = input().strip()
    dp = [[0]*(n+2) for _ in range(n+1)]
    score = [[0]*(n+2) for _ in range(n+1)]
    
    dp[0][0] = 1
    score[0][0] = 0
    
    for i in range(n):
        for j in range(n+1):
            if dp[i][j] == 0:
                continue
            if s[i] == '(':
                # skip
                dp[i+1][j] = (dp[i+1][j] + dp[i][j]) % MOD
                score[i+1][j] = (score[i+1][j] + score[i][j]) % MOD
                # take
                dp[i+1][j+1] = (dp[i+1][j+1] + dp[i][j]) % MOD
                score[i+1][j+1] = (score[i+1][j+1] + score[i][j]) % MOD
            else:
                # skip
                dp[i+1][j] = (dp[i+1][j] + dp[i][j]) % MOD
                score[i+1][j] = (score[i+1][j] + score[i][j]) % MOD
                # take if possible
                if j > 0:
                    dp[i+1][j-1] = (dp[i+1][j-1] + dp[i][j]) % MOD
                    score[i+1][j-1] = (score[i+1][j-1] + score[i][j] + 2*dp[i][j]) % MOD
    print(score[n][0] % MOD)
```第一个嵌套循环初始化子序列的计数。 为了`(`，包括它增加平衡，而对于`)`包含它会减少平衡并将分数增加 2 以说明新形成的对。 我们总是执行模运算以避免整数溢出。 最终答案来自`score[n][0]`因为只有最终余额为零的序列才有效。
