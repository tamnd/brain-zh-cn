 ## 解决方案
 ## 问题理解

 我们得到一串括号`s`这已经是一个有效的常规括号序列。 任务是找到最长的非空子序列`t`的`s`这也是一个有效的常规括号序列并且比`s`。 一个序列`t`比`s`如果它的开头与`s`但在某些位置发散`t`有`'('`和`s`有`')'`， 或者`s`是一个前缀`t`但短于`t`。 如果不存在这样的子序列，我们返回`-1`。 

输入允许最多`10^4`测试用例，每个用例的字符串长度可达`2 * 10^5`。 所有测试用例的所有长度之和仅限于`2 * 10^5`。 这告诉我们，在线性时间内处理每个字符串的算法是可以接受的，但是任何尝试生成所有子序列或对字符执行嵌套迭代的解决方案都将太慢，因为子序列的数量呈指数增长。 

当原始序列以某种方式“完美平衡”时，就会出现微妙的边缘情况，而无法通过插入额外的前缀来改进前缀`'('`。 例如，对于`s = "()"`或者`s = "(())()"`，任何非空子序列都等于`s`或 更短而不是更好，所以输出必须是`-1`。 简单地计算括号的粗心方法可能会错误地认为删除`')'`或添加`'('`是可能的，但这是不正确的，因为子序列必须尊重原始顺序。 

## 方法

 蛮力方法是考虑所有非空子序列`s`，检查每个子序列是否是正则括号序列，然后按字典顺序与`s`。 这种方法原则上是正确的，但是生成所有子序列需要`O(2^n)`时间，这对于`n`最多`2 * 10^5`。 

关键的观察是，为了构造一个更好的子序列，我们希望分歧的第一个位置包含`'('`在`t`和`')'`在`s`。 因此，我们只需要考虑从开头或结尾删除最少数量的字符`s`实现以 more 开头的常规括号序列`'('`处于发散位置。 换句话说，最优的`t`总是通过取一些前缀来获得`'('`s 从开头和一些后缀`')'`从最后开始。 这是因为任何内部重新排序都会违反子序列条件或不必要地减少长度。 计算数量`'('`沙`')'`进入`s`给出快速线性时间解。 

这将问题简化为计算`min(count_open, count_close)`乘以 2 即可得到最长更好子序列的长度。 如果这个长度等于`n`， 然后`s`本身是唯一的最大子序列，答案是`-1`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于给定的字符串`s`, 统计总数`'('`人物 （`count_open`） 和`')'`人物 （`count_close`）。 此步骤需要的时间为线性时间`s`。 
2. 更好的子序列的最大长度是最小值的两倍`count_open`和`count_close`。 这是因为我们需要相同数量的`'('`和`')'`保持规则的括号序列，并且子序列必须短于`s`被认为更好。 
3. 如果计算出的长度等于`s`，则不存在更好的子序列。 输出`-1`在这种情况下。 否则，输出计算出的长度。 

工作原理：每个常规括号子序列都可以由一系列左括号和后跟相同数量的右括号表示，可能以保持有效性的方式交错。 第一个分歧可以使`t`比`s`必须位于我们替换 a 的位置`')'`在`s`和`'('`在`t`。 通过计算数量`'('`和`')'`，我们确保可以形成最长的有效括号子序列，该子序列提前发散并满足“更好”的条件。 该算法保留了子序列是规则的并且优于子序列的不变量`s`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        count_open = s.count('(')
        count_close = s.count(')')
        max_len = min(count_open, count_close) * 2
        if max_len == n:
            print(-1)
        else:
            print(max_len)

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它会计算`'('`和`')'`在字符串中。 将较小的计数乘以二即可得到最长可能的更好子序列的长度。 支票`max_len == n`确保我们不会返回`s`本身，这并没有更好。

 ## 边缘情况

 对于长度为 2 的字符串，`s = "()"`，计数给出`count_open = count_close = 1`。 计算出的`max_len`是`2`，等于`n`，所以输出是`-1`，正确表明不存在更好的子序列。 

对于更长的完美嵌套序列，例如`s = "((()))"`,`count_open = 3`,`count_close = 3`,`max_len = 6 = n`，所以输出是`-1`。 

为了`s = "(((())))"`,`count_open = 4`,`count_close = 4`,`max_len = 8`。 去掉一对括号，我们可以得到`((()))`，长度为 6，优于`s`，所以输出是`6`。 该算法通过比较正确地识别了这一点`max_len`到`n`并隐式减去可移除对。
