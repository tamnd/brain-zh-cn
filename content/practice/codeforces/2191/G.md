 ## 解决方案
 ## 问题理解

 我们给出了部分填充的大小排列$n$，表示为数组$a$其中零表示未知位置。 任务是计算完整排列的数量$p$符合$a$这样当我们构造一个序列时$f(p)$，通过取每个连续三元组的中位数来定义$p$, 中的所有元素$f(p)$是不同的。 

换句话说，对于每一个$i$从$1$到$n-2$，我们计算中位数$(p_i, p_{i+1}, p_{i+2})$。 结果是一个新的长度序列$n-2$，并且这个序列中任何数字都不能出现两次。 输入保证第一个和最后一个位置填充在某个地方$1$和$n$，它们是最小值和最大值。 

约束条件是这样的$n$可以达到$2 \cdot 10^5$，最多可达$10^4$测试用例和总和$n$所有测试均不超过$2 \cdot 10^5$。 这排除了任何二次解$n$。 我们需要一个大致线性或线性算术的算法$n$每个测试用例。 

当较大或较小的数字被迫占据三元组中的中间位置时，就会出现微妙的边缘情况。 例如，如果序列有$1$和$n$由于被一些未知数分开，只有某些位置才能使中位数保持不同。 任意填充零然后检查唯一性的幼稚方法将在时间和正确性上失败。 

## 方法

 蛮力方法是生成符合以下条件的所有排列$a$, 计算$f(p)$对于每个，并计算有多少个具有不同的中位数。 为了$n \sim 10^5$，这是不可能的，因为有$n!$排列，即使许多位置是固定的。 直接计算每个排列的中位数会进一步增加一个乘法因子$n$，使得这不可行。 

关键的见解是推理数字的相对顺序，而不是枚举完整的排列。 三元组中的每个中位数都是排序顺序中的中间元素。 为了使所有中位数不同，我们可以利用这样一个事实：只有当前中位数的直接邻居会影响下一个中位数。 这将问题简化为组合安排，其中我们在每一步跟踪最大的可用数字，并以避免中位数冲突的方式贪婪地分配数字。 

实际上，未知位置可以被视为必须用剩余数字填充的槽，同时保持严格的局部顺序以保持中值唯一性。 1 和 的位置$n$修复极值，并且可以通过考虑已知元素之间的间隔，计算不重复中位数的有效插入的数量来计算填充剩余数字的方法数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 找出所有固定数字的位置$a$，包括 1 和$n$。 这些位置创建了边界，其中未知数字的顺序必须遵守固定数字以避免重复的中位数。 
2. 对于连续固定号码之间的每个间隔，确定未知时隙的数量以及可以分配给这些时隙的号码范围。 只能使用不出现在任何固定位置的数字。 
3. 从左到右处理每个区间。 对于固定数字之后的第一个未知槽，第一个三元组的中位数已经由固定数字确定。 下一个中位数取决于以确保唯一性的顺序选择下一个最大的可用数字。 这减少了使用阶乘为每个区间乘以选择。 
4. 使用模运算来计算阶乘和乘积模$998\,244\,353$。 预先计算阶乘高达$n$启用$O(1)$每个区间的计算。 
5. 将所有区间的计数相乘，得到与以下一致的排列总数$a$并且具有不同的中位数。 

为什么有效：通过将问题分解为由固定数字确定的区间，我们确保局部排序保留中位数的唯一性。 一旦边界固定，每个间隔都是独立的，因此将计数相乘是有效的。 不变的是，在先前间隔中分配的中位数不会与当前间隔中的中位数冲突，因为数字是从不相交的集合中选择的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

# Precompute factorials up to 2*10^5
N = 2 * 10**5 + 10
fact = [1] * N
for i in range(1, N):
    fact[i] = fact[i-1] * i % MOD

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # collect fixed positions
        fixed = []
        for i, val in enumerate(a):
            if val != 0:
                fixed.append((i, val))
        
        fixed.sort()
        
        # intervals between fixed numbers
        result = 1
        for i in range(1, len(fixed)):
            lpos, lval = fixed[i-1]
            rpos, rval = fixed[i]
            length = rpos - lpos - 1
            available = rval - lval - 1
            if available < length:
                result = 0
                break
            # number of ways to choose positions in interval
            result = result * fact[available] % MOD
            result = result * pow(fact[available - length], MOD-2, MOD) % MOD
        print(result)
        
solve()
```第一部分预先计算阶乘以允许快速组合计数。 然后，对于每个测试用例，我们提取非零元素的位置和值并对它们进行排序。 连续固定数字上的循环处理必须插入数字的间隔。 我们检查是否有足够的数字来填补未知的空位； 如果不是，则计数为零。 否则，我们使用阶乘和模逆来计算除法的路数。 印刷`result`给出有效排列的总数.
