[CF 453A - 小马驹和预期最大值](https://codeforces.com/problemset/problem/453/A)

 **求解时间：** 1m 46s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们掷出一个公平的骰子，上面的编号为`1`到`m`， 确切地`n`次。 每一次滚动都是独立的，每张脸都有概率出现`1 / m`。 

其中`n`滚动时，我们只查看出现的最大值。 任务是计算该最大值的期望值。 

输入包含`m`和`n`， 在哪里`m`是骰子上的面数，`n`是投掷次数。 输出是一个实数，表示所有抛出后最大结果的期望。 

约束条件允许两者`m`和`n`一样大`100000`。 枚举所有可能的掷骰顺序是不可能的，因为有`m^n`结果。 即使对于中等值，例如`m = 100`和`n = 100`，这个数字是一个天文数字。 

解决方案执行的功与`m`完全没问题。 解正比于`m^2`已经需要大约`10^10`在最坏的情况下进行操作，远远超出了时间限制。 

当只有一次投掷时，会出现一种微妙的情况。 

输入：```
6 1
```最大值就是骰子结果本身，所以答案是数字的平均值`1..6`，等于`3.5`。 

另一种容易错过的情况是骰子只有一个面时。 

输入：```
1 100000
```每卷总是`1`，所以最大值总是`1`，并且期望值正是`1`。 

一个常见的错误是试图计算最大值等于的概率`k`直接并犯一个差一错误。 例如：

 输入：```
2 2
```最大值等于`1`仅当两个卷都处于`1`，这有概率发生`1/4`。 最大值等于`2`有概率`3/4`。 期望是$$1 \cdot \frac14 + 2 \cdot \frac34 = 1.75.$$累积概率的不正确处理通常会产生不同的结果。 

## 方法

 最直接的方法是枚举每个可能的掷骰序列，计算其最大值，并对所有最大值进行平均。 这是正确的，因为期望只是概率加权的平均值。 不幸的是，有`m^n`可能的结果。 和`m = n = 100000`，这是完全不可行的。 

关键的观察结果是，通过累积概率更容易推理最大值。 

假设我们想要最大值最多为的概率`k`。 每卷必须最多`k`。 由于每个卷独立地降落在`{1,2,...,k}`有概率`k/m`，我们得到$$P(\max \le k) = \left(\frac{k}{m}\right)^n.$$由此，我们可以得到最大值恰好为的概率`k`：$$P(\max = k) = P(\max \le k) - P(\max \le k-1) = \left(\frac{k}{m}\right)^n - \left(\frac{k-1}{m}\right)^n.$$那么期望值为$$E[\max] = \sum_{k=1}^{m} k \cdot P(\max = k).$$代入上面的公式可以得到`O(m)`解决方案。 

自从`m ≤ 100000`，对每个值求一次幂和一些算术运算`k`很容易符合限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(m^n)$|$O(n)$| 太慢了 |
 | 最佳|$O(m)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读`m`和`n`。 
2. 初始化`answer = 0`。 
3. 对于每个值`k`从`1`到`m`, 计算$$p_k = \left(\frac{k}{m}\right)^n$$这是最大值不超过的概率`k`。 
4. 计算$$p = p_k - p_{k-1}$$在哪里$$p_{k-1}=\left(\frac{k-1}{m}\right)^n.$$这给出了最大值恰好是的概率`k`。 
5. 添加$$k \cdot p$$到运行的答案。 
6. 处理完所有值后`k`，打印累积的期望值。 

### 为什么它有效

 对于每个整数`k`，事件“`maximum ≤ k`“恰好在每次掷骰最多时发生`k`。 因为掷骰子是独立的，所以它的概率是$$\left(\frac{k}{m}\right)^n.$$事件“`maximum = k`” 对整个样本空间进行划分。它们的概率是通过减去连续累积概率得到的：$$P(\max = k) = P(\max \le k)-P(\max \le k-1).$$期望公式$$E[X] = \sum_x x \cdot P(X=x)$$应用于随机变量“最大滚动”可以精确地给出算法累积的值。 每个可能的最大值都会贡献其值乘以其概率，因此最终的总和等于预期的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    m, n = map(int, input().split())

    ans = 0.0

    for k in range(1, m + 1):
        p1 = (k / m) ** n
        p0 = ((k - 1) / m) ** n
        ans += k * (p1 - p0)

    print("{:.12f}".format(ans))

solve()
```实现直接遵循数学推导。 

该循环迭代所有可能的最大值。 对于每个`k`，它计算所有掷骰子最多的累积概率`k`，然后减去相应的概率`k - 1`。 差异恰好是最大值等于的概率`k`。 

使用浮点运算就足够了，因为所需的误差容限仅为`10^{-4}`。 Python 的双精度浮点类型可以轻松提供更高的精度。 

表达式为`k = 1`自然有效，因为$$\left(\frac{0}{m}\right)^n = 0.$$无需特殊处理。 

打印小数点后十二位数字足以满足判断。

 ## 边缘情况

 考虑输入```
1 100000
```该循环仅运行`k = 1`。$$(1/1)^{100000}=1, \qquad (0/1)^{100000}=0.$$最大值等于的概率`1`是`1`，所以贡献是$$1 \cdot 1 = 1.$$该算法准确输出`1`。 

考虑输入```
6 1
```对于每一个`k`，概率差变为$$\frac{k}{6}-\frac{k-1}{6} = \frac16.$$每个面都以相同的概率做出贡献，产生公平骰子的标准平均值。 输出是`3.5`。 

考虑输入```
2 2
```累积概率为$$P(\max \le 1)=\left(\frac12\right)^2=\frac14,$$

$$P(\max \le 2)=1.$$减去连续值得出概率`1/4`和`3/4`对于最大值`1`和`2`。 对加权贡献求和得出`1.75`，完全匹配最大值的真实分布。
