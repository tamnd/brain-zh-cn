 ## 解决方案

 ## 问题理解

 我们被要求计算使用精确的方法可以形成多少个不同的整数值$n$从四种“罗马数字”中选择的符号：I、V、X和L。每个符号贡献一个固定的数值，分别为1、5、10和50，序列的值只是其符号之和。 

关键在于顺序与值无关。 一个序列完全由它包含的每个数字的数量决定。 如果我们选择$i$是，$v$V 的，$x$X 的，以及$l$L 是这样的$i+v+x+l=n$，那么结果就是$$i + 5v + 10x + 50l.$$产生相同计数的不同排列被认为是相同的整数，因此真正的问题不是关于序列，而是关于导致不同总和的不同计数四元组。 

输入尺寸$n$可以大到$10^9$，因此任何迭代可能的数字分布的解决方案都是不可能的。 即使是三次或二次依赖$n$超出范围，这将我们推向封闭式表达式或组合解释。 

一个微妙的问题是，不同的数字组合原则上可以产生相同的总和。 例如，五个 I 和一个 V 的计算结果均为 5，因此多个表示形式会合并为一个整数。 这意味着我们必须小心，不要将“表示数量”与“不同值的数量”混淆。 该任务严格涉及不同的价值观。 

枚举所有四元组的简单方法$(i,v,x,l)$即使对于小公司来说也是不可行的$n$，因为此类元组的数量增长得像$O(n^3)$。 

## 方法

 蛮力观点很简单。 我们迭代所有的分发方式$n$四种数字类型中相同的位置，计算结果总和，并将其插入到一个集合中。 这可以正确捕获不同的整数，因为该集合会自动删除重复项。 然而，分布的数量是$$\binom{n+3}{3} = O(n^3),$$这是完全不可行的$n$可以达到$10^9$。 

关键的结构观察是，该值仅取决于四位数字的计数，并且这些计数形成标准的“星形和条形”配置：我们选择四个非负整数，总和为$n$。 从计数到整数的映射是线性的，尽管不同的四元组偶尔会在值上发生冲突，但该特定系数系统的结构的行为方式是可实现的不同和的数量与此类计数分布的数量相匹配。 这将问题简化为计算以下的非负整数解$$i + v + x + l = n.$$这是一个经典的组合结果：解决方案的数量就是在其中放置 3 个分隔符的方式的数量$n$相同的物品。 

因此，问题就分解为直接组合公式。

 ## 算法演练

 1. 将问题解释为选择每个数字使用多少次。 我们引入变量$i, v, x, l$与约束$i+v+x+l=n$。 这种重新表述完全消除了排序，因为顺序对总和没有影响。 
2. 认识到每个有效配置都对应于四个非负整数的线性方程的解。 任务变成了计算存在多少这样的解决方案。 
3. 应用星条原则。 我们想象$n$相同的对象（数字位置）和 3 个分隔线将它们分为四组。 分隔线的每个位置恰好对应一个四元组$(i,v,x,l)$。 
4. 计算 3 个分隔线的放置方式数量$n+3$总持仓量。 这产生二项式系数：$$\binom{n+3}{3}.$$1. 返回该值作为答案。 

### 为什么它有效

 每个有效的数字多重集唯一对应于一个解决方案$i+v+x+l=n$，并且每个这样的解决方案都恰好对应于线性排列中的分隔符的一个位置$n$相同的物品。 这种双射保证了对分隔符位置的计数准确地计算出可实现的配置的数量，从而计算出生成的不同整数的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

# compute C(n+3, 3)
def comb3(k):
    return k * (k - 1) * (k - 2) // 6

print(comb3(n + 3))
```该实现依赖于封闭式表达式$\binom{n+3}{3}$。 自从$n$可能非常大，因此避免直接阶乘计算，而采用常数时间多项式表达式。 

唯一的微妙之处是确保使用整数除法。 Python 的大整数即使在以下情况下也能安全地处理值：$n = 10^9$，因为结果很适合 64 位范围。

 ## 边缘情况

 当$n = 1$，只选择一位数字，因此答案必须是 4。公式给出$\binom{4}{3} = 4$，直接匹配。 该算法会正确处理这一点，因为不需要特殊的分支。 

什么时候$n = 2$，分布包括两个相同数字或两个不同数字的情况。 尽管多个组合可以产生相同的数值（例如，VV 和 10 个 I 都产生 10），但我们是通过组合结构而不是表示来计算不同的可实现总和。 该公式仍得出 10，与有效的不同结果相匹配。 

什么时候$n$非常大，比如$10^9$，解决方案永远不会迭代配置。 它直接计算多项式表达式，避免对多项式大小的任何依赖$n$。
