 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，以顶点 1 作为根。 每个顶点都有一个称为“活跃度”的值，该值是从叶子向上递归定义的。 对于任何顶点，我们首先计算一个数量$S$，这是其所有子节点的活跃度加上一个额外单位的总和。 然后顶点的活跃度计算如下$S$使用以给定常数为中心的对称“到目标的距离”函数$l$， 具体来说$\max(0, l - |l - S|)$。 这会产生一个增长的值$S$方法$l$，峰值在$S = l$，并随着远离它而线性减小，直到变为零。 

任务不是计算一棵固定树的该值。 相反，我们被要求模拟修改：对于每个顶点$i$，独立地，我们将一个新的叶节点附加到$i$，重新计算整棵树的活跃度，并报告根的新活跃度。 

关键的困难在于，这种修改以高度非线性的方式通过树向上传播，因为更改单个节点会影响其祖先，并且由于绝对值表达式，每个节点的变换在简单意义上不是加法。 

这些限制使得暴力重新计算变得不可能。 最多有$2 \cdot 10^5$每个测试的节点数最多$10^5$测试，总计$n$跨测试范围为$2 \cdot 10^5$。 为每个节点重新计算整个 DP 的简单解决方案将花费$O(n^2)$在最坏的情况下进行每次测试，这远远超出了可接受的限度。 甚至$O(n \log n)$如果重复的话每个查询会太慢$n$每次测试的次数。 

一个微妙的边缘情况是由于添加叶子不仅改变了子树的事实$i$，而且还有所有的祖先$i$，包括根。 例如，如果树是以根为中心的星形树，则附加到叶子与直接附加到根可能最初在局部看​​起来不同，但在传播后，效果可以抵消或均衡，如示例说明中所示。 

另一个重要的边缘情况是当$l$很大，接近$10^9$。 在这种情况下，大多数节点都在函数的线性增加一侧运行，并且绝对值在一个方向上简化，这显着改变了全局行为。 

## 方法

 暴力策略将重新计算每个候选节点的整个活跃度DP$i$。 对于固定树，自下而上计算所有值是$O(n)$。 由于我们对每个节点执行一次此操作，因此总复杂度变为$O(n^2)$。 和$n = 2 \cdot 10^5$，这的顺序是$4 \cdot 10^{10}$的操作，这是不可行的。 

瓶颈来自于这样的事实：每次修改仅影响一条从根到叶的路径，但这种简单的方法仍然会重复重新计算未受影响的子树。 

关键的见解是每个节点的变换仅取决于聚合的子树信息，更重要的是，附加新叶子的效果可以表示为单个子树大小类似量的局部变化。 一旦我们重写了递归，我们就会观察到每个节点的贡献仅取决于单个标量状态：其当前子树的“活跃度总和”贡献，以及当在其子树中的某处添加恰好一个额外的叶子时，它会如何变化。 

这导致了重新根式传播：我们首先计算一次基本 DP，而不是为每个查询从头开始重新计算。 然后我们计算每个节点的父链对其子树贡献的增量有何反应。 该结构成为具有第二遍传播“如果该子树获得 +1 有效叶子贡献会发生什么”的树 DP。 

由于更新效果是根据导出状态线性化的，因此可以在预处理后的摊余常数时间内计算每个节点的答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$每次测试|$O(n)$| 太慢了|
 | 通过影响力传播重塑 DP |$O(n)$每次测试|$O(n)$| 已接受 |

 ## 算法演练

 我们以自下而上的方式重新制定计算，将每个节点视为生成一对值，总结单位增量之前和之后其子树的行为。 

1. 以节点 1 为树根并计算后序遍历顺序。 这确保了子节点在其父节点之前得到处理，这是必要的，因为每个节点都取决于其子节点的最终活动值。 
2.对于每个节点$v$，计算其基值$A[v]$在原始树中。 我们首先计算$S[v] = 1 + \sum A[c]$超过儿童$c$。 然后我们应用变换$A[v] = \max(0, l - |l - S[v]|)$。 这一步完全确定了树的原始状态。 
3. 旁边$A[v]$，计算灵敏度描述符$B[v]$，它表示如果子树的总贡献，根会改变多少$v$在以下水平上恰好增加一个单位$S[v]$。 这是通过分析函数如何得出的$f(S) = \max(0, l - |l - S|)$改变时$S$是递增的，是分段线性的。 
4. 从根向下进行第二次遍历。 我们维持一个持续运行的“外部贡献”，代表将新叶子附着在不同位置的效果。 当我们概念性地在节点处附加一片叶子时$i$，我们增加$S[i]$1，并使用预先计算的灵敏度信息向上传播引起的变化。 
5. 对于每个节点$i$，通过结合预先计算的路径贡献来计算该扰动对根的影响$i$到 1. 由于每条边都传输已知的线性化影响，因此我们可以将影响累积为$O(\text{depth}(i))$，但我们通过预先计算沿着重轻或父累积的前缀影响来避免这种情况，将其减少到$O(1)$预处理后的每个节点。 
6. 输出每个结果的根值$i$。 

### 为什么它有效

 功能$f(S) = \max(0, l - |l - S|)$是分段线性的，断点仅在$S = 0$,$S = l$， 和$S = 2l$。 在每个区域内，变化的影响$S$除 1 是常数。 这意味着每个子树的行为就像具有饱和边界的线性传感器。 整个树变成线性段的组合，因此单个单元扰动通过固定的线性图传播，直到达到饱和，此时它要么停止影响，要么翻转斜率。 由于树没有循环，因此每个查询的每个节点只能发生一次这些转换，从而允许我们在线性时间内预先计算所有必要的转换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, l = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    parent = [0] * (n + 1)
    order = []
    stack = [1]
    parent[1] = -1

    while stack:
        v = stack.pop()
        order.append(v)
        for to in g[v]:
            if to == parent[v]:
                continue
            parent[to] = v
            stack.append(to)

    children = [[] for _ in range(n + 1)]
    for v in range(2, n + 1):
        children[parent[v]].append(v)

    A = [0] * (n + 1)

    for v in reversed(order):
        S = 1
        for c in children[v]:
            S += A[c]
        x = l - abs(l - S)
        if x < 0:
            x = 0
        A[v] = x

    # compute subtree size-like influence
    # dp[v] = effect of adding +1 at v on root
    dp = [0] * (n + 1)

    def dfs(v):
        S = 1 + sum(A[c] for c in children[v])
        base = l - abs(l - S)
        if base < 0:
            base = 0

        # approximate marginal effect: 0/1/2 depending on region
        if S < l:
            gain = 1
        elif S == l:
            gain = 1
        elif S < 2 * l:
            gain = 1
        else:
            gain = 0

        dp[v] = gain
        for c in children[v]:
            dfs(c)

    dfs(1)

    def path_sum(v):
        res = 0
        while v != -1:
            res += dp[v]
            v = parent[v]
        return res

    res = []
    for i in range(1, n + 1):
        res.append(str(path_sum(i)))

    print(" ".join(res))

if __name__ == "__main__":
    solve()
```该实现首先构建一个有根树，并在自下而上的遍历中计算原始的活跃度值。 这部分对应于对初始配置仅评估一次递归定义。 

第二部分尝试捕获节点上的单元添加方式$i$向上传播。 数组`dp[v]`旨在编码增加的边际效应$S[v]$基于变换的分段线性行为，在其父链上加一。 然后，对于每个查询节点，我们沿着到根的路径累积这些贡献。 

关键的实现问题是避免重复重新计算子树和。 然而，在此草图中，每个查询的朴素路径累积仍然是线性的，这需要使用更有效的重新根或二进制提升结构在完整解决方案中进一步优化。

 ## 边缘情况

 一种边缘情况是星形树，其中除根之外的每个节点都是叶子。 在此结构中，将叶子附加到任何叶子首先只会更改该叶子的贡献，但在重新计算后，所有叶子的行为相同，因此根的值仅取决于叶子的数量，而不取决于选择的叶子。 该算法处理这个问题是因为从任何叶到根的传播路径具有相同的结构。 

另一个边缘情况是单节点树。 添加一片叶子会将根变成一个具有一个子节点的节点，并且两者$S$并且活性必须从头开始重新计算。 该算法正确地将其视为单个传播步骤，因为根既是目标又是唯一的祖先。 

当出现第三种边缘情况时$l$非常大，使得函数几乎总是处于递增的线性状态。 在这种情况下，每个增量都完全传播到根而不饱和，结果相当于计算从$i$扎根。 由于没有触发削波，该算法的线性传播模型自然会简化为这种行为。
