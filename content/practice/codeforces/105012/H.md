 ## 解决方案
 ## 问题理解

 我们正在研究一个$n \times n$网格开始完全白色。 我们必须准确地绘制$k$单元格为黑色，但顺时针旋转 90 度后，最终图案必须看起来没有变化。 

旋转对称意味着如果旋转网格，每个黑色单元格必须落在另一个黑色单元格上，并且每个白色单元格必须落在白色单元格上。 换句话说，黑色单元并不是独立放置的，它们必须在旋转操作下进入轨道。 

输入给出多个测试用例，每个测试用例都有一个网格大小$n$和所需数量的黑色单元格$k$。 对于每个测试用例，我们决定是否存在任何有效的配置$k$黑色单元格满足旋转对称性。 

关键的限制是$n \le 30000$，并且最多可以有 1000 个测试用例。 任何解决方案都必须$O(1)$每个测试用例或最坏的情况$O(n)$具有非常小的常数。 任何涉及显式网格构建或模拟的事情都是不可能的，因为大规模的完整网格操作将超出时间和内存限制。 

当考虑细胞的对称群时，会出现一个微妙的问题。 有些细胞以大小为 4 的组旋转，有些以大小 2 的组旋转，并且在中心（当$n$是奇数），一些细胞被单独固定。 尝试贪婪地分配黑色单元格而不尊重这些分组的简单方法将会失败，因为它可能会将单个黑色单元格放入一个组中，从而迫使其他单元格也成为黑色。 

典型的失败案例是$n = 3, k = 1$。 如果您尝试将单个黑色单元放置在任何位置，旋转会强制 4 个对称位置，这会立即超过$k$。 所以答案是否定的。 这表明对单个细胞的局部推理是不够的。 

另一个边缘情况是当$n$为奇数且中心单元存在。 该细胞在旋转下保持不变，因此它的行为与所有其他细胞不同。 忽略这种区别会导致错误的奇偶推理。 

## 方法

 一旦我们停止考虑单个细胞，而是根据它们的旋转轨道对它们进行分类，问题就会变得简单得多。 

强力解释是构建网格并尝试枚举所有可能的子集$k$黑色单元格，检查旋转下构型是否不变。 这将涉及$\binom{n^2}{k}$可能性，甚至检查单个配置成本$O(n^2)$。 即使对于非常小的情况，这也是完全不可行的$n$。 

一种更结构化的强力方法是显式模拟旋转轨道：对于每个单元，将其四个旋转位置分组并在它们之间强制执行相等约束。 这导致了约束系统$n^2$变量。 即使我们从概念上解决它，也要决定一个解决方案是否完全符合$k$黑细胞的存在仍然减少到计算有效轨道贡献。 

关键的观察是旋转将网格划分成独立的轨道。 每个轨道根据其大小贡献 0 个或固定数量的黑色单元。 只有两种重要的轨道类型：

 映射到四个不同位置的细胞形成大小为 4 的组。选择这样的轨道会贡献 0 或 4 个黑色细胞。 

中心行或列上的单元格（当$n$是奇数）在旋转下形成 size-2 或 size-1 结构，但更准确地说，中心单元单独形成一个贡献 0 或 1 的固定点。 

因此，整个问题简化为询问是否$k$可以表示为这些轨道类型的贡献之和。 

我们可以准确计算存在多少个轨道：

 有$\left\lfloor \frac{n^2}{4} \right\rfloor$独立的 4 个周期，但更容易直接推理：除了中心之外的每个轨道总共贡献 4 个细胞，并且所有这些轨道都是可互换的。 

因此，我们需要检查是否可以选择一些完整轨道，并可能在以下情况下使用中心进行调整：$n$很奇怪。 

这导致了一个简单的算术条件：

 如果$n$是偶数，所有轨道的大小都是 4，所以$k$必须能被 4 整除。 

如果$n$奇怪的是，我们有一个特殊的中心单元。 其余$n^2 - 1$细胞形成 4 个周期，因此我们可以选择任意数量的周期以及可选的中心。 这意味着$k$必须满足$k \equiv 0 \pmod 4$或者$k \equiv 1 \pmod 4$，只要我们不超过容量，但容量总是足够的，因为$k \le n^2$。

 ## 算法演练

 我们独立处理每个测试用例，并仅使用从轨道结构导出的模运算来确定可行性。 

1. 计算是否$n$是偶数还是奇数。 这确定是否存在固定中心单元。 不动点的存在改变了允许的余数结构$k$。 
2.如果$n$是否为偶数，检查是否$k \mod 4 = 0$。 如果不是，则返回 NO，因为每个有效轨道恰好贡献四个单元，因此任何有效配置的总大小必须能被 4 整除。 
3.如果$n$是奇数，首先计算我们是否可以表示$k$使用 4 个循环加可选的一个中心单元。 这意味着我们检查是否$k \mod 4 = 0$或者$k \mod 4 = 1$。 中心单元考虑了额外的+1可能性。 
4. 如果条件成立则返回YES，否则返回NO。 

按奇偶校验分裂背后的原因是旋转组结构仅在存在固定点时才会改变。 不存在其他结构差异。 

### 为什么它有效

 网格分解为不相交的旋转轨道，每个轨道必须是全黑或全白，以保持旋转下的不变性。 所有大小为 4 的轨道对总黑色计数的贡献是 4 的倍数。 什么时候$n$是奇数，恰好有一个轨道的大小为 1，贡献 0 或 1。不存在其他轨道大小。 这划分了所有可实现的值$k$变成 4 的总和，可选地加 1。这些形式之外的任何值都不能对应于完整轨道的并集，因此不存在有效的对称着色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())

    if n % 2 == 0:
        print("YES" if k % 4 == 0 else "NO")
    else:
        print("YES" if k % 4 in (0, 1) else "NO")
```该实现直接反映了轨道分解。 唯一微妙的一点是确保在模数条件之前应用奇偶校验分割，因为中心单元的存在会改变允许的余数类别。 

决策逻辑是恒定时间的，因此即使 1000 个测试用例也能立即处理。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        if n % 2 == 0:
            out.append("YES" if k % 4 == 0 else "NO")
        else:
            out.append("YES" if k % 4 in (0, 1) else "NO")
    return "\n".join(out)

# minimum size odd grid

 ## 边缘情况

 对于$n = 1, k = 1$，网格由固定旋转的单个单元组成。 该算法分类$n$作为奇数和检查$k \mod 4 \in \{0,1\}$。 自从$1 \mod 4 = 1$，它输出 YES，匹配将唯一单元格着色为黑色是有效的事实。 

为了$n = 2, k = 2$，所有单元格形成 4 个循环，分为大小为 4 的一个轨道。任何有效的配置都必须使用 0 或 4 个黑色单元格，因此$k = 2$是不可能的。 该算法检测到$n$Even 并检查能否被 4 整除，正确生成 NO。 

为了$n = 3, k = 1$，在不违反对称性约束的情况下，只能使用中心单元。 该算法输出 YES，因为$1 \mod 4 = 1$，正好对应于选择中心轨道并且没有 4 周期。
