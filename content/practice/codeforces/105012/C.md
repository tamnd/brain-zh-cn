 ## 解决方案
 ## 问题理解

 我们被给予$n$独立舞者放置在整数线上的某处。 每个舞者从某个整数坐标开始，然后同时向左或向右移动一步，每个方向以概率独立选择$1/2$。 

在这种随机运动发生之前，我们可以任意选择舞者的初始位置。 当所有舞者移动后，我们会查看多组最终位置。 如果最终位置的多重集与初始多重集相同，则该运动被称为“疯狂”，这意味着对于每个整数坐标$x$, 舞者数量$x$移动之前和移动之后是完全一样的。 

任务是选择舞者的初始配置，以使该事件发生的概率最大化。 输出不是概率本身，而是$\log_2(\text{ans})$，其中 ans 是最大概率。 如果事件不可能发生，则输出被定义为零。 

主要限制是$n \le 40000$，这立即排除了任何模拟或枚举移动配置的解决方案，因为每个配置已经有$2^n$的可能性。 即使存储所有舞者的状态也可以，但推理必须将问题分解为计算结构化配置而不是概率模拟。 

出现微妙的边缘情况时$n = 1$。 单个舞者总是移动到不同的位置，因此多组舞者不可能保持不变。 概率为零，输出也必定为零。 任何涉及对数的公式必须明确避免采用$\log 0$。 

另一个不明显的问题是，不同的初始放置会产生不同的概率，并且最佳排列并不是均匀的间距。 例如，将所有舞者排成一条线且间隙较大并没有帮助，因为位置的同一性只有通过运动后的碰撞和配对才重要。 

## 方法

 关键的困难是理解必须存在什么结构，以便每个舞者向左或向右移动后，多组占据的位置保持不变。 直接方法会考虑所有$2^n$运动结果并检查它们是否保留多重集，甚至评估一种配置成本$O(n)$, 给予$O(n2^n)$，这是完全不可行的。 

更具结构性的观点会有所帮助。 每个舞者贡献之一$+1$或者$-1$位移。 为了使多重集保持不变，每个位置$x$到达的人数必须与最初入住的人数完全相同。 这迫使舞者进行完美的“重新标记”：每个原始位置都必须以精确保留计数的方式将其占用者映射到相邻位置。 

这成为一种类似流程的配对约束。 每位舞者就位$x$必须与另一位舞者匹配，以便他们的左/右结果可以交换而不改变计数。 关键的观察结果是，只有对称配对才有助于有效的配置。 在任何有效的配置中，舞者的排列必须使每个左移与右移相匹配，产生相同的重新分配结构。 这本质上迫使分解为运动一致性的独立 2 个周期。 

一旦以这种方式重新表述，问题就简化为最大化我们可以通过选择初始位置来强制执行的独立对约束的数量。 最佳策略是对舞者进行最佳配对，因为每对舞者都贡献一个固定的概率因子。 放置在同一坐标的一对舞者保持平衡的可能性更高，因为他们的动作可以局部相互抵消。 

对于团体规模$k$放置在一个坐标上，有效平衡结果的数量由二项式对称性控制，最好的配置是将舞者分成两对，最多一个单例，如果$n$很奇怪。 每对贡献一个因子$1/2$，因为四个联合移动结果中恰好有两个在本地保持计数相等。 

因此，最佳排列是最大化对的数量，这很简单$\lfloor n/2 \rfloor$。 每对贡献概率$1/2$，而如果不小心处理，未配对的舞者会使事件不可能发生，除非被隔离，否则这会有效地将概率降低到零。 

最大概率变为：$$\text{ans} = 2^{-\lfloor n/2 \rfloor}$$所以$$\log_2(\text{ans}) = -\lfloor n/2 \rfloor.$$为了$n = 1$，概率为零，我们明确输出零。

 ## 算法演练

 我们将问题简化为计算我们可以形成多少个独立的抵消对。 

1.如果$n = 1$，立即返回 0，因为单个舞者在移动后总是会改变位置，因此多重组相等是不可能的。 
2. 对于$n \ge 2$，将最佳配置解释为将舞者分组。 每对在随机移动后是否保持局部平衡方面表现独立。 配对之所以重要，是因为当一个舞者向左移动、另一个向右移动时，两个舞者可以抵消彼此的位移效果。 
3. 计算$k = \lfloor n/2 \rfloor$。 这是我们可以形成的不相交对的最大数量。 
4. 每对贡献一个乘法概率因子$1/2$，因为恰好有一半的关节移动结果保留了局部所需的对称性。 
5. 总概率变为$2^{-k}$，所以所需的输出是$\log_2(2^{-k}) = -k$。 

### 为什么它有效

 关键的不变量是，在任何有效的配置中，多集计数的保存迫使舞者成对匹配，其位移结果总体上抵消。 任何不可分解为独立对的配置都会在某些位置引入净流量的不对称性，这必然会破坏移动后计数的相等性。 由于每一对独立的舞者恰好贡献一个二元约束（左右一致性），因此最大化概率相当于最大化此类独立约束的数量，这是通过将尽可能多的舞者配对来实现的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n == 1:
    print(0)
else:
    print(-(n // 2))
```该实现直接对导出的公式进行编码。 唯一的特殊情况是$n = 1$，其中零概率的对数在模型中未定义，并被语句强制为零。 

该部门$n // 2$捕获最大数量的独立抵消对。 整数除法是安全的，因为 Python 可以轻松地处理大整数 n，并且不涉及溢出或模运算。

 ## 边缘情况

 对于$n = 1$，算法直接输出0。这绕过了一般公式，因为$\log_2(0)$未定义。 检查是恒定时间的并确保正确性。 

为了$n = 2$，该算法计算一对并返回 -1。 这与存在一个独立取消约束的解释相匹配。 

对于奇数$n$， 例如$n = 5$，该算法使用整数除法形成 2 对，并在最佳结构中概念上留下一个未配对的舞者。 输出与配对解释保持一致，因为只有完整的配对才有助于有效的抵消结构。
