 ## 解决方案
 ## 问题理解

 我们得到一个数组，它表示类似排列的论文文档，其中位置和值都很重要。 索引 i 处的值是当前放置在那里的文章的标签。 对手可以在任意两个位置之间执行任意交换，目标是修改数组，以便最终配置没有索引 i，其中值等于 i。 换句话说，我们要消除所有不动点。 

该过程仅在交换被计数的意义上是交互式的，但最终的要求是静态的：执行一定数量的交换后，数组必须变得自身混乱，这意味着每个位置 i 必须满足 a[i] ≠ i。 如果这是不可能的，我们必须报告这一事实。 

这些约束强制每个测试用例采用线性或近线性解决方案。 由于所有测试用例的 n 总和最多为 10^5，因此每个测试用例的任何解决方案都会立即失败。 即使具有大量常量的 O(n log n) 也是可以接受的，但交换的结构强烈表明我们应该能够在 O(n) 中进行推理。 

一个关键的微妙之处是交换不受限制，因此我们不会随着时间的推移跟踪过程，而是要求达到任何有效混乱所需的最小交换数量。 另一个微妙之处是初始数组可能已经满足条件，在这种情况下需要零操作。 

主要的边缘情况围绕强制固定点。 如果索引 i 满足 a[i] = i 并且没有办法在不创建另一个固定点的情况下移走该值，则答案变得不可能。 一个最小的例子是像 [1, 1, 1] 这样的数组，其中每次交换都在位置 1 处保留至少一个 1，从而无法删除固定点。 

## 方法

 强力解释将每个状态视为完整的数组配置，并将每次移动视为任意两个索引之间的交换。 从任何配置，我们都可以生成所有 O(n^2) 可能的交换并执行 BFS 或最短路径搜索，直到达到任何没有固定点的配置。 虽然这种方法是正确的，但它会立即爆炸。 状态空间是 n！，甚至分支因子 O(n^2) 也使它完全不可行。 

关键的观察是，我们并不是真正在寻找排列，而是在寻找是否可以避免将某些值放置在其禁止位置。 每个索引 i 禁止在最终排列中的位置 i 处取值 i。 由于交换允许任意重新排序，唯一的障碍来自结构约束：如果太多值以不可避免的方式“锁定”到其位置，我们就会失败。 

决定性的简化是根据头寸是否已经安全或不安全对头寸进行分类，然后推理掉期如何消除所有不安全的固定点。 a[i] = i 的位置 i 是一个约束，必须通过将 i 移动到其他位置来打破该约束，但该移动必须通过移动到 i 的另一个元素来平衡。 这创建了一个配对结构：固定点必须成对解决，除非我们对非固定位置有足够的灵活性。 

事实证明，问题归结为检查我们是否可以消除所有固定点，如果可以，则计算需要多少次交换才能确保每个固定点都被打破。 每次交换最多可以修复两个有问题的位置，但前提是我们有足够的“空闲”元素，这些元素不是固定点或可以用作缓冲区。 

最佳推理简化为计算固定点并确定是否存在至少一个索引 i ，使得数组已经是混乱的，或者我们可以使用至少一个非固定元素来破坏对称性。 最小交换次数与定点数量密切相关，但受到数组是否完全由定点主导的限制。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 排列上的强力 BFS | O(n!) | O(n!) | 太慢了|
 | 定点配对推理 | O(n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 扫描数组并识别所有索引 i，使得 a[i] = i。 这些都是必须消除的强制约束。 
2. 如果没有不动点，则数组已经满足条件，所以答案为 0。这是唯一不需要操作的情况。 
3. 如果恰好存在一个固定点，则不可能在不创建另一个固定点的情况下使用交换来消除它，因为涉及该位置的任何交换都会在其他地方引入新的相等性。 
4. 如果有多个固定点，计算需要多少次交换才能打破所有固定点。 每次交换最多可以通过交换两个坏位置来消除两个固定点。 
5. 因此，交换的最小数量是固定点数量一半的上限，但前提是结构允许配对，当至少有两个固定点并且并非所有位置都是固定点时，它总是这样做。 
6. 输出计算值，除非不可能性条件触发。 

### 为什么它有效

 固定点 i = a[i] 表示置换结构中长度为 1 的自包含循环。 交换操作对应于切割和重新连接循环。 消除所有定点循环需要打破每个单例循环并将其合并到一个更大的循环中，其中没有元素映射到自身。 一次交换可以通过交换元素来删除最多两个单例循环，从而每次操作最多减少两个固定点的数量。 如果恰好存在一个单例循环，则没有第二个循环与之配对，并且任何移动它的尝试都必然会在其他地方创建一个新的单例，从而保留至少一个固定点保留的不变性。 这个不变量阻止了完全消除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        fixed = 0
        for i in range(n):
            if a[i] == i + 1:
                fixed += 1
        
        if fixed == 0:
            out.append("0")
        elif fixed == 1:
            out.append("-1")
        else:
            out.append(str((fixed + 1) // 2))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案独立处理每个测试用例，并在单个线性扫描中对固定点进行计数。 关键决策完全基于价值等于指数的仓位数量。 

区分大小写是至关重要的。 由于不需要任何操作，零定点立即返回零。 精确地解决一个固定点是不可能的，因为互换不能消除单个孤立的约束。 对于两个或多个，每次交换可以被视为将两个固定点配对并将它们一起解析，这直接导致上限一半公式。 

整数除法`(fixed + 1) // 2`干净地编码配对逻辑，无需浮点运算。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        fixed = sum(1 for i in range(n) if a[i] == i + 1)
        if fixed == 0:
            res.append("0")
        elif fixed == 1:
            res.append("-1")
        else:
            res.append(str((fixed + 1) // 2))
    return "\n".join(res)

# minimum size

# already deranged

# all fixed
assert run("1\n4\n1 2 3 4\n") == "2"

 ## 边缘情况

 最小的情况 n = 1 直接暴露了不可能性条件。 对于单个元素，如果它是固定的，则没有第二个位置可以交换，因此至少保留一个固定点的不变量无法被打破。 当fixed = 1 时，算法正确返回-1。 

在像 [2, 3, 1] 这样的情况下，根本不存在不动点。 扫描发现 a[i] = i + 1 的零个匹配项，因此算法返回 0，而不尝试任何交换推理。 这证实了该解决方案不会过度计算不必要的操作。 

对于像 [1, 2, 3, 4] 这样的全固定数组，计数为 4，公式得出 2。执行反映了每次交换都可以通过配对消除两个固定点，并且两次交换后不会留下任何剩余的单例。
