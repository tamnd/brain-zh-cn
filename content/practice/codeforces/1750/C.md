 ## 解决方案
 ## 问题理解

 我们有两个长度相等的二进制字符串。 单个操作选择一个段 ([l,r])。 段内的字符串 (a) 的每一位都被翻转，而段外的字符串 (b) 的每一位都被翻转。 

目标不是将一个字符串转换为另一个字符串。 目标更强大：在应用一些操作序列之后，两个字符串的每个字符都必须变为零。 我们必须要么使用最多 (n+5) 次操作构造这样的序列，要么证明不存在解。 

所有测试用例中所有字符串的长度最多为 (2 \cdot 10^5)。 任何显式模拟每个角色的每个操作的解决方案都将过于昂贵。 我们需要一个总工作量与输入大小呈线性关系的结构。 

一个微妙的点是该操作同时影响两个字符串。 只看一个字符串就隐藏了问题的结构。 另一个容易犯的错误是假设每对字符串都可以解决。 有些配对根本不可能。 

考虑：```
n = 2
a = 11
b = 10
```答案是否定的。 仅关注将 (a) 变为零的构造可能会错误地声称成功。 

另一个有趣的案例是：```
n = 3
a = 010
b = 101
```这里每个位置都不同。 答案是肯定的，即使这些字符串是互补的。 

第三种边缘情况是：```
n = 3
a = 111
b = 111
```字符串是相同的，答案是YES，但是清除(a)中的字符串后，还需要一些额外的调整操作。 

## 方法

 暴力的观点是将每对字符串视为图中的一个状态并搜索操作序列。 每个测试用例有 (O(n^2)) 种可能的操作，而状态数为 (2^{2n})。 即使对于非常小的（n），这也是不可能的。 

关键的观察来自于检查单个位置发生的情况。 

选择线段 ([l,r]) 上的操作。 对于位置 (i)：

 - 如果 (i \in [l,r])，则 (a_i) 翻转而 (b_i) 不翻转。 
- 如果 (i \notin [l,r])，则 (a_i) 不翻转且 (b_i) 翻转。 

该对 ((a_i,b_i)) 中恰好有一位被翻转。 

这意味着（a_i）和（b_i）之间的关系每次都会改变。 如果它们是平等的，它们就会变得不同。 如果它们不同，它们就会变得平等。 

因此，每个操作都会同时切换每个位置的平等状态。 

让

 [
 c_i = a_i \oplus b_i。 
]

 每个操作都会翻转每个值 (c_i)。 因此，在任何操作序列之后，向量 (c) 只能是其原始形式或其按位补码。 

对于最终状态，我们需要 (a_i=b_i=0)，这意味着每个位置都有 (c_i=0)。 

因此，只有在最初满足以下条件时才存在解决方案：

 - 全部 (c_i=0)，即 (a=b)，或
 - 所有（c_i=1），意味着（a）和（b）是补集。 

如果这两个条件都不成立，则答案是不可能的。 

一旦满足了这个条件，构建操作就变得很容易。 我们使用单个位置的运算来消除字符串 (a) 中的每个 (1)。 完成此操作后，产生的全局奇偶性决定我们是否以全相等的情况或全补的情况结束。 对三个操作的微小修正更正解决了剩余的奇偶校验问题。

 ## 算法演练

 1. 检查每个位置是否满足(a_i=b_i)。 
2. 检查每个位置是否满足(a_i\neq b_i)。 
3. 如果两个条件都不成立，则打印`NO`。 
4. 否则，从空操作列表开始。 
5. 对于 (a_i=1) 的每个位置 (i)，添加操作 ((i,i))。 

长度为 1 的操作恰好翻转 (a) 的一位。 对每个人重复此操作使得 (a) 变为全零。 
6. 令 (cnt) 为原始字符串 (a) 中 1 的数量。 
7. 如果字符串最初相等：

 - 如果 (cnt) 是偶数，我们就已经完成了。 
- 如果 (cnt) 为奇数，则附加三个运算：
 [
 (1,n),\(1,1),\(2,n)。 
]
 8. 如果字符串最初是补码：

 - 如果 (cnt) 是奇数，我们就已经完成了。 
- 如果 (cnt) 为偶数，则附加相同的三个操作：
 [
 (1,n),\(1,1),\(2,n)。 
]
 9. 输出所有记录的操作。 

### 为什么它有效

 假设我们对 (a_i=1) 的每个位置执行长度一运算。 

每个此类操作都会翻转 (a) 的一位，因此最终 (a) 变为全零。 

唯一剩下的问题是 (b) 的状态。 答案取决于所执行操作的数量的奇偶性。 

每个操作都会切换字符串之间的全局关系。 如果我们从相等的字符串开始，那么在偶数次操作之后它们仍然相等，并且在奇数次操作之后它们变成补码。 由于 (a) 已经全为零，因此等式意味着 (b) 也全零。 

如果我们从互补字符串开始，则需要相反的奇偶校验。 

这三个额外的操作是奇偶校验调整小工具。 它们对字符串的综合影响是中性的，但它们将操作数量改变了三，从而翻转了所需的奇偶校验。 这使我们能够在所有情况下满足正确的最终关系。 

因为存在条件既是充分必要的，所以构造总是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()

        same = all(a[i] == b[i] for i in range(n))
        comp = all(a[i] != b[i] for i in range(n))

        if not same and not comp:
            out.append("NO")
            continue

        ops = []

        ones = 0
        for i, ch in enumerate(a, start=1):
            if ch == '1':
                ops.append((i, i))
                ones += 1

        need_flip = False

        if same:
            need_flip = (ones % 2 == 1)
        else:
            need_flip = (ones % 2 == 0)

        if need_flip:
            ops.append((1, n))
            ops.append((1, 1))
            ops.append((2, n))

        out.append("YES")
        out.append(str(len(ops)))
        for l, r in ops:
            out.append(f"{l} {r}")

    sys.stdout.write("\n".join(out))

solve()
```第一部分检查唯一可以达到目标状态的两种配置：相同的字符串和互补的字符串。 

下一个循环为 (a) 中的每一个记录一个单位置操作。 这是强制 (a) 变为全零的最简单方法。 

奇偶校验逻辑是构造的核心。 清除所有 1 后，只有全局相等/补数关系才重要。 根据起始关系，我们需要偶数或奇数的操作。 

最后三个运算始终有效，因为 (n \ge 2)。 它们的组合效果保留了所实现的配置，同时更改了操作计数的奇偶校验。

 考虑：```

考虑：

 ``
