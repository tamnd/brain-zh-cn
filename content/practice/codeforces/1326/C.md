 ## 解决方案

 ## 问题理解

 我们得到了从 1 到 n 的数字排列，我们必须将其恰好分成 k 个连续的段。 每个段贡献一个等于该段内最大元素的值，目标是选择分割点以使这些段最大值的总和尽可能大。 在找到这个最大可能的总和后，我们还需要计算有多少种不同的方式来放置 k 段来实现它。 

一个关键细节是片段是连续的，因此我们仅在相邻索引之间选择 k−1 个切割位置。 一旦削减确定，每个位置都恰好属于一个段，并且每个段恰好贡献一个最大值。 

最大 200,000 的约束 n 强制执行 O(n log n) 或 O(n) 解决方案。 任何尝试显式评估分区或重复重新计算段最大值的操作都会立即失败，因为分区的数量随 k 组合增长。 

当人们认为我们应该在没有全球战略的情况下贪婪地削减大价值时，就会出现天真的错误。 例如，在像 [1, 3, 2, 4] 这样 k = 2 的排列中，紧接在 4 之前进行切割看起来不错，但最佳分割取决于较早的大元素是否已“分配”给段。 另一种微妙的故障模式是当存在多个相等的最佳切割配置时错误地计算分区，因为多个相邻切割选择可能会产生相同的最大贡献结构。 

## 方法

 蛮力方法会尝试所有方法在 n−1 个间隙中选择 k−1 个切割位置。 对于每个选择，我们通过独立扫描每个段来计算段最大值。 即使使用前缀预处理，评估一个分区的成本仍然是 O(n)，并且存在 O(n 选择 k−1) 个分区。 即使 n = 30，这也会变得天文数字，使得暴力破解无法使用。 

关键的观察结果是，每个细分市场的贡献取决于哪些元素对细分市场的最大值“负责”。 由于每个元素都是唯一的，因此每个值都有可能成为一个段中的最大值。 因此，策略是将 k 个最大的元素分配为“锚点”，因为每个段最大值必须来自某个元素，并且选择较大的锚点总是会增加总和。 

一旦我们决定某些元素充当段最大值，剩下的任务就变成分布切割，以便每个选定的最大值被隔离到自己的段中，同时保留顺序。 这将问题转化为选择 k 个元素并计算放置切口的方式，以便每个选定的元素都是从左侧开始第一次出现的段最大值。 

我们按值的降序处理元素，并决定每个“前 k”元素可以在哪里开始一个段。 在连续选择的锚点之间，空闲位置的数量决定了我们可以放置切割的方式，这变成了一个乘法计数过程。

 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们首先确定排列中所有值的位置。 由于是排列，所以从 1 到 n 的每个值都只出现一次，因此我们可以构建一个位置数组 pos[value]。 

然后，我们按降序处理值，因为如果包含较高的值，则它们必须主导段最大值。

1. 我们迭代从 n 到 1 的值并收集 k 个最大值的位置。 这些职位是唯一可以贡献最大金额的候选人。 这是因为用较小的值替换任何选定的最大值会严格减少总和。 
2. 我们按升序对选定的位置进行排序。 这些位置从左到右定义了段的结构。 
3. 最大可能的总和只是 k 个最大值的总和，因为每个选定的锚点仅作为分段最大值贡献一次。 
4. 为了计算配置，我们检查连续选定位置之间的间隙。 假设所选位置为 x1 < x2 < ... < xk。 对于每个连续对，可用切割位置的数量为 xi+1 − xi。 每个这样的间隙独立地影响有效分区的数量。 
5. 最终答案是所有这些间隙大小以 998244353 为模的乘积。 

计数之所以有效，是因为一旦我们确定哪些元素是段最大值，每个有效分区都是通过在连续选定的最大值之间的每个间隙中选择一个切口来确定的。 每个间隙的行为都是独立的，因为切割不能跨越段边界。 

### 为什么它有效

 该算法依赖于这样一个事实：在最优解决方案中，k 个最大值必须各自显示为不同段的最大值。 任何其他配置都可以通过将较小的段最大值与较大的未使用值交换来转换，从而严格增加目标。 一旦这些最大值被固定，分区自由度正是选择在连续最大值之间分离片段的位置，并且这些选择在间隙之间是独立的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    p = list(map(int, input().split()))

    pos = [0] * (n + 1)
    for i, v in enumerate(p):
        pos[v] = i

    # take k largest values
    chosen_vals = list(range(n, n - k, -1))
    chosen_pos = [pos[v] for v in chosen_vals]
    chosen_pos.sort()

    # maximum sum
    max_sum = sum(chosen_vals)

    # count ways
    ways = 1
    for i in range(k - 1):
        gap = chosen_pos[i + 1] - chosen_pos[i]
        ways = (ways * gap) % MOD

    print(max_sum, ways)

if __name__ == "__main__":
    solve()
```位置数组允许恒定时间查找每个值在排列中的位置，从而避免重复扫描。 对所选位置进行排序是必要的，因为排列顺序与值顺序不一致。 

计数循环将连续选择的最大值之间的间隙相乘。 每个间隙代表保持段最大值固定的有效切割位置的数量。

 | 步骤| 选择的职位| 差距|
 | ---| ---| ---|

这与切割可以放置在索引 (1,2) 或 (2,3) 之间的事实相匹配，从而产生两个有效的最佳分区。

 ## 边缘情况

 当 k = 1 时，整个数组是一个段。 该算法仅选择最大元素，并且由于没有间隙，因此乘积循环为空并返回 1，这与单个有效分区匹配。 

当 k = n 时，每个元素形成自己的段。 选中的值都是元素，间隙都是1，因为连续位置相差1。乘积仍然是1，符合只有一个分区存在的事实。
