 ## 解决方案
 ## 问题理解

 我们需要构造一个正十进制数`n`数字。 每个数字都必须非零，并且整个数字必须不能被其中出现的每个数字整除。 

对于每个测试用例，输入仅给出所需的长度`n`。 我们可以输出该长度的任何有效数字。 如果不存在这样的数字，我们打印`-1`。 

这些限制立即表明我们不应该搜索候选号码。 单个测试用例可能需要生成最多`10^5`位数，所有长度之和也达到`10^5`。 任何检查许多候选者或对大整数执行昂贵算术的算法都是不必要的。 预期的解决方案必须及时构建与输出大小成正比的答案。 

第一个不明显的边缘情况是`n = 1`。 

输入：```
1
1
```输出：```
-1
```一位数的正数总是能被它自己整除。 由于数字中唯一的数字等于数字，因此不存在有效答案。 

另一个容易犯的错误是构建一个完全由以下内容组成的数字`9`s。 

输入：```
1
3
```候选人：```
999
```这失败了，因为`999`可以整除`9`。 没有零位是不够的。 

第三个错误是忘记了每一个数字的整除性都必须失败。 例如：```
444
```可以整除`4`，因此即使所有数字都不为零，它也是无效的。 

挑战在于无法有效地检查整除性。 挑战在于找到一种保证适用于大于 1 的所有长度的模式。 

## 方法

 暴力策略将产生`n`- 数字并测试每个候选人是否满足条件。 测试一个候选者很容易：检查其数字并检查每个数字的整除性。 问题在于搜索空间。 有`9^n`数字与`n`非零数字。 即使是为了`n = 20`，这已经是一个天文数字了。 为了`n = 100000`，穷举搜索是完全不可能的。 

关键的观察是我们只需要一个有效答案，而不是全部。 

假设我们构造一个仅包含数字的数字`2`和`3`。 如果这个数是奇数，那么它不能被整除`2`。 如果它的各位数字之和不是以下的倍数`3`，那么它不能被整除`3`。 由于这些是数字中出现的唯一数字，因此这两个要求都将得到满足。 

一个非常简单的模式就可以实现这一点：```
2333...333
```第一个数字是`2`，以及剩余的`n - 1`数字是`3`。 

让我们来验证一下。 

最后一位数字是`3`，所以这个数是奇数，不能被整除`2`。 

数字和等于$$2 + 3(n-1)=3n-1.$$自从`3n - 1`留下余数`2`当除以`3`，该数字不能被`3`。 

唯一存在的数字是`2`和`3`，因此该数字不能被它的任何数字整除。 

该结构适用于每个`n > 1`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(9^n·n) | O(9^n·n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`。 
2.如果`n = 1`， 打印`-1`。 

一位正数总是能被它唯一的数字整除，因此不存在解。 
3. 否则，输出由1组成的字符串`'2'`其次是`n - 1`的副本`'3'`。 

这给出了一个`n`-仅包含数字的数字`2`和`3`。 

### 为什么它有效

 对于每一个`n > 1`,构造的数字以数字结尾`3`，所以很奇怪。 任意数能被`2`必须是偶数，因此该数字不能被整除`2`。 

数字和是$$2 + 3(n-1)=3n-1.$$该值不能被整除`3`，所以数字本身不能被整除`3`。 

号码中唯一出现的数字是`2`和`3`。 我们已经证明这个数字不能被它们整除。 因此，它不能被十进制表示形式中出现的任何数字整除。 

为了`n = 1`，不存在有效数字，因此打印`-1`是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 1:
            ans.append("-1")
        else:
            ans.append("2" + "3" * (n - 1))

    sys.stdout.write("\n".join(ans))

solve()
```该程序独立处理每个测试用例。 

特殊情况`n == 1`必须先处理。 忘记这个案例会产生`"2"`，这是无效的，因为`2`可以整除`2`。 

对于所有较大的长度，表达式`"2" + "3" * (n - 1)`直接构建所需的字符串。 使用字符串比构造一个大整数更好，因为`n`可以达到`100000`。 该问题只要求我们打印数字，而不要求对其进行算术运算。 

输出累积在列表中并在最后打印一次。 这避免了重复的输出操作并符合标准的竞争性编程实践。

 ## 边缘情况

 考虑输入：```
1
1
```算法立即进入特殊分支并打印`-1`。 这是正确的，因为每个一位正整数都可以被它自己整除。 没有任何建筑能够满足要求。 

考虑输入：```
1
2
```算法输出`23`。 这个数是奇数，所以不能被整除`2`。 其位数和为`5`，所以它不能被整除`3`。 由于唯一存在的数字是`2`和`3`，答案有效。 

考虑输入：```
1
100000
```该算法构建了一个`'2'`其次是`99999`的副本`'3'`。 不对大整数执行算术运算。 输出正好`100000`数字，保持奇数，并且有数字和$$2 + 3 \cdot 99999 = 299999,$$不能被整除`3`。 用于小值的相同证明不变地适用于最大输入大小。
