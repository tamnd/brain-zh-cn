 ## 解决方案
 ## 问题理解

 我们被要求分析一组的排列$n$智者，其中有些人彼此认识。 对于这些智者的每个排列，我们可以创建一个长度为的二进制字符串$n-1$指示熟人相邻：如果排列中两个连续的智者彼此认识，则为“1”，否则为“0”。 我们的目标是对每个可能的长度的二进制字符串进行计数$n-1$，有多少种排列产生它。 

输入将熟人关系编码为$n \times n$对角线上有零的对称二元矩阵。 输出是一个长度的数组$2^{n-1}$，每个位置对应于解释为整数的二进制字符串。 

对于暴力破解来说，约束非常严格。 和$n \le 18$, 枚举所有$n!$直接排列是不可行的，因为$18! \approx 6.4 \cdot 10^{15}$。 这排除了任何生成排列的简单方法。 该问题需要更智能的组合或动态编程方法。 

边缘情况包括所有智者都互相认识的情况。 然后只有全为 1 的字符串出现，并且每个其他字符串的计数都必须为零。 另一种情况是，没有两个智者互相认识。 那么只出现全零的字符串。 不处理空或完整邻接字符串的粗心实现可能会错误计算这些极端情况。 

## 方法

 暴力方法将生成所有$n!$排列，并且对于每个排列，通过检查邻接矩阵中的连续对来构建二进制字符串。 然后我们会增加该字符串的计数器。 这是有效的，因为它准确地反映了问题定义，但其时间复杂度是$n$，这是不可接受的$n = 18$。 

加速计算的关键观察是，可以使用智者子集的动态规划来解决问题。 具体来说，对于每个人的子集，我们可以使用表示连续人的邻接关系的给定二进制字符串来跟踪以特定智者结尾的排列方式的数量。 这将问题从阶乘时间转变为$O(n \cdot 2^n \cdot 2^{n-1})$，这简化为$O(n \cdot 4^n)$-可接受的$n \le 18$。 

这是可行的，因为排列可以逐步构建：如果我们知道以 man 结尾的子集存在多少个序列$u$带绳子$s$，然后添加一个新人$v$通过是否确定性地扩展字符串$u$和$v$彼此认识。 DP状态定义为$(mask, last, bitmask)$在哪里`mask`编码哪些男人已经被使用过，`last`是部分排列中的最后一个人，并且`bitmask`是迄今为止生成的邻接串的整数表示。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(2^{n-1}) | O(2^{n-1}) | 太慢了 |
 | 子集上的DP | O(n * 4^n) | O(n * 4^n) | O(n * 2^n * 2^{n-1}) | 已接受 |

 ## 算法演练

 1. 将输入矩阵解析为邻接数组，其中`adj[i][j]`如果是智者，则为 1`i`识智者`j`，否则为 0。 
2.初始化动态规划表`dp`索引为`(mask, last, bitmask)`。 这里，`mask`是一个用过的智者的位掩码，`last`是当前排列中最后一个智者的索引，并且`bitmask`是表示到目前为止邻接串的整数。 将所有条目设置为零。 
3. 通过单独放置每个智者来为 DP 播种。 对于包含单个人的排列`i`， 放`dp[1 << i][i][0] = 1`。 单个元素的邻接串为空，对应于整数 0。 
4. 迭代从 1 到 的所有掩码`(1 << n) - 1`。 对于每个掩码，迭代所有可能的最后一个人`u`在当前子集中。 如果`dp[mask][u][*] > 0`，考虑添加任何未使用的人`v`来扩展排列。 
5. 对于每位候选人`v`，计算新的掩码`mask2 = mask | (1 << v)`。 计算新的邻接串整数`bitmask2 = (bitmask << 1) | adj[u][v]`。 增量`dp[mask2][v][bitmask2]`经过`dp[mask][u][bitmask]`。 
6. 填充 DP 后，迭代所有最终状态`mask = (1 << n) - 1`。 对于每个`last`和`bitmask`，将计数累加到`result[bitmask]`。 
7. 打印结果数组`result`长度`2^{n-1}`。 

不变的是`dp[mask][last][bitmask]`总是精确计算由 表示的子集的排列数`mask`结束于`last`生成编码为的邻接字符串`bitmask`。 DP 转换在更新邻接字符串时正确扩展有效排列，因此不会对任何排列进行多次计数，并且所有排列都会被考虑。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
adj = [list(map(int, line.strip())) for line in sys.stdin]

size = 1 << n
dp = [{} for _ in range(size)]

for i in range(n):
    dp[1 << i][i] = {0: 1}

for mask in range(size):
    for u in range(n):
        if not (mask & (1 << u)) or not dp[mask][u]:
            continue
        for bitmask, count in dp[mask][u].items():
            for v in range(n):
                if mask & (1 << v):
                    continue
                mask2 = mask | (1 << v)
                bitmask2 = (bitmask << 1) | adj[u][v]
                if v not in dp[mask2]:
                    dp[mask2][v] = {}
                dp[mask2][v][bitmask2] = dp[mask2][v].get(bitmask2, 0) + count

result = [0] * (1 << (n - 1))
final_mask = (1 << n) - 1
for u in range(n):
    if u in dp[final_mask]:
        for bitmask, count in dp[final_mask][u].items():
            result[bitmask] += count

print(" ".join(map(str, result)))
```邻接矩阵被转换为整数，允许按位运算有效地扩展邻接串。 每个 DP 字典仅处理该子集和最后一个元素出现的位掩码，从而节省内存。 使用字典可以避免存储完整的内容`2^{n-1}`除非需要，否则每个子集都有状态。 这`get`方法干净地累积计数而不会覆盖。 

## 工作示例

 对于输入：```
3
011
101
110
```我们初始化`dp[1<<0][0] = {0:1}`,`dp[1<<1][1] = {0:1}`,`dp[1<<2][2] = {0:1}`。 

| 面膜| 最后| 位掩码| 计数|
 | ---| ---| ---| ---|
 | 001| 0 | 0 | 1 |
 | 010| 1 | 0 | 1 |
 | 100 | 100 2 | 0 | 1 |

 添加剩余人员：

 来自面具`001`， 最后的`0`, 位掩码`0`：加1（相邻=1）→掩码=011，最后=1，位掩码=1； 添加 2（相邻 = 1）→ 掩码 = 101，最后 = 2，位掩码 = 1。 

最终，所有排列仅生成`11`（`3`十进制），所以`result = [0,0,0,6]`。 

第二个例子：```
4
0100
1010
0101
0010
```代表一条链1-2-3-4。 仅出现某些邻接字符串：尊重链的排列会产生如下字符串`1110`,`0111`等。运行 DP 可正确累加计数`result`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * 2^n * 2^{n-1}) ≈ O(n * 4^n) | 我们迭代所有子集 (2^n)、每个最后一个人 (n) 以及每个可能的位掩码（最多 2^{n-1}）。 每次转换都是恒定时间。 |
 | 空间| O(n * 2^n * 2^{n-1}) | 每个 DP 状态都存储每个最后一个人的位掩码计数的字典。 |

 假设 n ≤ 18，则 4^18 ≈ 6800 万，完全符合 4 秒的限制。 内存使用量受每个子集实际生成的位掩码状态数量的限制。
