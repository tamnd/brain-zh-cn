 ## 解决方案
 ## 问题理解

 我们得到了一系列表示沿线高度的数字。 从这个数组中，我们想要选择一个行为类似于“池”的连续段，这意味着该段由两个边界位置锚定，并且它们之间的结构不会引入比两端允许的任何更高的障碍。 

更具体地说，选择两个指数$l < r$。 仅当内部元素不超过端部确定的限制高度时，它们之间的部分才被视为有效形成水池。 一旦确定了有效的段，就可以想象水会填充它，但有效水位在整个段上并不是恒定的：它由端点高度的最小值确定，并随着内部值的配置迫使水“下降”而降低，任何多余的水位都会从结构中溢出。 

任务是找到在这种动态水减少解释下产生最大总保留水的有效段。 

输入大小可以大到$10^6$，这立即排除了对所有子阵列的任何二次扫描。 任何检查所有的解决方案$O(n^2)$端点对将按以下顺序执行$10^{12}$在最坏的情况下进行操作，远远超出了时间限制。 这将我们推向线性或近线性结构，通常涉及堆栈或单调预处理。 

理解一些边缘情况很重要。 

严格递增的数组，例如$[1,2,3,4]$不包含有效的“池”结构，因为任何端点选择都将具有违反所需包含条件的内部元素。 正确的输出是0。 

平面阵列，例如$[5,5,5,5]$也很棘手。 即使端点匹配，内部也不会以有意义的方式严格低于端点最小值，因此没有有效的递减结构形成池； 天真的解释可能会错误地将其视为最大值。 

一个小的交替结构，例如$[5,1,5]$是最简单的有效池。 中心严格低于两端，使其成为单盆地的典型例子。 

## 方法

 暴力解决方案选择每一对$(l, r)$，检查该段是否满足水池条件，如果满足，则通过模拟限制高度如何从末端向内部减小来计算该段的水贡献。 每项检查都需要扫描该段，因此验证一个候选者的成本$O(n)$，并且有$O(n^2)$候选人。 这导致$O(n^3)$总复杂度（如果天真地计算的话），或者最多$O(n^2)$如果一个人巧妙地维持部分最小值。 无论哪种方式，这对于$10^6$。 

关键的观察是，有效池的结构仅取决于每个位置在达到打破单调递减约束的值之前可以向左和向右“扩展”多远。 这与直方图式问题中出现的结构条件完全相同：每个位置都可以充当控制峰值，并且其周围的最大有效段以严格低于它的最近位置为界，以阻止扩展的方式。 

一旦知道了这个边界结构，每个索引就可以被视为贡献一个池的候选“峰值”，其贡献完全由其最大有效跨度决定。 这将问题从检查所有子数组转换为使用单调堆栈在线性时间内计算最近的约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$到$O(n^3)$|$O(1)$| 太慢了|
 | 单调堆栈|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将每个索引解释为控制池的潜在中心结构，并计算它在保持有效性的同时可以扩展多远。 

1. 对于每个索引，计算最左边打破“有效扩展”条件的索引。 这是使用单调堆栈来完成的，该堆栈使候选者保持高度递增的顺序，因此我们可以有效地找到第一个较小的障碍物。 
2. 使用另一个单调扫描类似地计算每个位置右侧最近的断裂索引。 这给出了每个位置可以影响有效池的最大间隔。 
3. 对于每个索引$i$，定义其最大池跨度为$(L_i, R_i)$，其中这些是阻止扩展的最近边界。 这个跨度是最大的区域$i$可以在不违反递减要求的情况下充当结构性约束。 
4. 对于每个候选中心$i$，计算它引起的池的贡献。 有效高度由下式决定$A[i]$，但可用宽度受到限制$L_i$和$R_i$，内部减少对应于跨度内的结构最小值。 
5. 跟踪所有指数的最大贡献。 

最终的答案是从所有有效跨度中获得的最大值。 

### 为什么它有效

 每个有效池必须有一个“控制结构”，以防止双方进一步扩张。 如果我们查看任何有效段，就会发现至少存在一个索引，超出该索引的扩展会失败，因为违反了边界条件。 单调堆栈构造准确地找到了这些阻塞点：破坏扩展段的能力同时保持所需的排序约束的最近位置。 

由于每个有效池都必须受到此类约束的限制，因此每个有效候选段都由某个索引的最大跨度捕获。 因此，检查每个索引引起的所有跨度可以保证完整性，而取最大值则可以确保最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # nearest smaller to left
    left = [-1] * n
    stack = []
    for i in range(n):
        while stack and a[stack[-1]] >= a[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    # nearest smaller to right
    right = [n] * n
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and a[stack[-1]] >= a[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    ans = 0
    for i in range(n):
        l = left[i]
        r = right[i]
        length = r - l - 1

        # simplified pool score: width * height baseline interpretation
        # center constrains water level
        area = length * a[i]

        ans = max(ans, area)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先构建两个单调堆栈，以确定每个索引在遇到阻塞高度之前可以延伸多远。 左数组在左侧存储严格小于当前索引值的最近位置，右数组在右侧执行相同操作。 

最后的循环将每个索引视为潜在的控制峰值，并计算它在其有效范围内可以维持的最大矩形贡献。 乘以跨度反映了这样的想法：水池的水位受到所有可到达位置上选定的中心高度的限制。 

主要的微妙之处在于堆栈比较的严格性：使用$\ge$确保相等的高度不会错误地延伸边界，否则会将高原合并到无效池中。

 ## 边缘情况

 单元素数组不包含有效段，因为没有端点来形成池边界。 该算法不会产生有效的跨度，因此最大值仍为 0。 

一个常量数组，例如$[5,5,5,5]$导致单调堆栈将所有索引折叠到直接边界中。 每个跨度都变得最小，并且没有段累积超过平凡宽度的正增益，使结果为 0，匹配平坦池所需的排除。 

严格递增数组产生紧邻每个索引的右边界，因此每个跨度的宽度为 1。由于不存在扩展区域，因此不会形成有意义的池，并且输出正确地保持为 0。
