 ## 解决方案
 ## 问题理解

 我们正在建造一个三角形装饰$N$水平水平。 等级$i$恰好包含$i$贴纸，并且每个贴纸必须使用三种颜色之一进行着色：红色、绿色或蓝色。 我们得到的每种颜色的总供应量是有限的，我们必须计算有多少种方法可以在不超过这些供应量的情况下填充整个三角形。 

每个级别对颜色的显示方式都有限制。 一个关卡可以是单色的，这意味着它的所有贴纸都是相同的颜色，也可以使用多种颜色，但只能以完美平衡的方式：每当一个关卡上使用多种颜色时，所有使用的颜色必须在该关卡中出现相同的次数。 这会强制在关卡上设置的每个选定颜色均匀地分割关卡大小。 

所以对于一个尺寸级别$i$，如果我们选择$k$那个级别的颜色，然后$k$必须划分$i$，并且每种选择的颜色都准确贡献$i/k$贴纸。 每个级别的选择都是独立进行的，但总体上受到每种颜色的可用总数的限​​制。 

输出是有效完整结构的数量，模$10^9 + 7$。 

限制条件$N \le 20$并供应高达$100$每种颜色立即表明解决方案的结构不是纯粹的贪婪或组合封闭形式。 三角形的高度很小，但不同级别的颜色分布创建了一个与状态相关的计数过程。 真正的约束不是$N$，而是跨层级的资源使用量的累积。 

一个天真的想法是为每个级别独立选择有效的着色模式而不跟踪全局消耗。 这会立即失败，因为相同的本地选择可能会提前耗尽颜色并使后续级别无效。 另一个微妙的错误是独立处理级别并乘以计数，这完全忽略了全局耦合。 

第二种简单的方法是逐级分配颜色，同时跟踪剩余计数。 这是正确的，但如果没有记忆，它就会爆炸，因为每个级别都会分支成多个颜色子集选择。 

## 方法

 强力方法逐级构建三角形，并在每个级别尝试满足整除规则的所有有效颜色分配。 对于级别$i$，我们考虑所有子集$\{R,G,B\}$，判断它们的大小是否整除$i$，然后尝试分配$i/k$每个所选颜色的贴纸。 这是正确的，因为它直接枚举了所有合法的配置。 

然而，这种方法会反复审视相同的情况。 在处理几个级别之后，我们可以通过不同的早期决策序列达到相同的剩余资源状态。 蛮力无法识别这些重叠，因此它会多次重新计算相同的子问题。 和$N \le 20$，每个级别最多分支为 7 个有效的颜色集选择，总搜索树的深度呈指数分布，大致如下$7^{20}$，这远远超出了可行性。 

关键的观察结果是，对未来决策唯一重要的是剩下多少红色、绿色和蓝色贴纸，以及我们当前正在处理的级别。 这将问题转化为标准的多维动态规划状态。 每个状态代表一个独立于我们如何到达那里的过程的后缀。 

然后我们记住每个状态的结果$(i, r, g, b)$， 在哪里$i$是当前级别并且$r,g,b$是剩余的供应。 这将指数递归折叠为可管理数量的可到达状态，因为每个级别仅减少计数和$N$很小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数为$N$(≈$7^N$) |$O(N)$递归栈| 太慢了|
 | 最优 DP（记忆递归）|$O(N \cdot R \cdot G \cdot B \cdot 7)$|$O(N \cdot R \cdot G \cdot B)$| 已接受 |

 ## 算法演练

 1. 定义一个递归函数，处理从 1 到$N$，同时跟踪剩余计数$R, G, B$。 这确保每个决定都尊重早期的消费。 
2. 如果我们已经处理了所有级别，则返回 1，因为已形成有效的完整配置。 这充当递归树的基本情况。 
3. 对于当前级别$i$，枚举其中的所有颜色子集$\{R,G,B\}$。 每个子集代表该级别上使用的颜色。 
4. 对于每个尺寸子集$k$，检查是否$i$可以整除$k$。 如果不是，则该分配是不可能的，因为均等分配不会产生整数。 
5. 如果有效，计算每种颜色所需的分配：$i/k$。 从剩余资源中减去这些数量并递归地解决下一个级别$i+1$。 
6. 如果减法后任何颜色变为负值，请立即丢弃该分支，因为它违反了资源限制。 
7. 对所有有效子集的结果求和，并将计算值存储在由以下键控的记忆表中$(i, r, g, b)$。 

### 为什么它有效

 每个有效的装饰恰好对应于一个逐级决策序列，并且每个这样的序列唯一地确定通过状态空间的路径。 递归探索所有这样的路径，并且记忆确保每个状态被解决一次。 由于未来的决策不依赖于早期级别的选择顺序，因此 DP 状态完全捕获所有相关信息，从而使递归完整且非冗余。 

## Python 解决方案```python
import sys
from functools import lru_cache

input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    n, R, G, B = map(int, input().split())

    colors = (0, 1, 2)

    @lru_cache(maxsize=None)
    def dp(level, r, g, b):
        if level > n:
            return 1

        total = 0
        req = level

        # iterate all subsets of {R,G,B}
        for mask in range(1, 8):
            cnt = (mask & 1) + ((mask >> 1) & 1) + ((mask >> 2) & 1)
            if req % cnt != 0:
                continue

            share = req // cnt
            nr, ng, nb = r, g, b

            if mask & 1:
                nr -= share
            if mask & 2:
                ng -= share
            if mask & 4:
                nb -= share

            if nr < 0 or ng < 0 or nb < 0:
                continue

            total = (total + dp(level + 1, nr, ng, nb)) % MOD

        return total

    print(dp(1, R, G, B))

if __name__ == "__main__":
    solve()
```该解决方案以级别上的记忆递归为中心。 功能`dp(level, r, g, b)`准确地编码了施工过程中剩余的自由度。 从 1 到 7 的每个遮罩代表当前级别使用的颜色的选择。 可分割性检查确保级别可以在选定的颜色之间均匀分割，并且减法步骤强制全局资源一致性。 

记忆至关重要，因为许多不同的级别分配序列会导致相同的剩余计数。 如果没有缓存，这些状态将被多次重新计算。

 ## 边缘情况

 当除一级之外的所有资源均为零时，递归立即使所有分支失败，因为任何有效子集都需要正分配。 状态转换在第一个减法步骤中正确修剪所有无效路径。 

对于单个级别$N=1$，算法检查所有非空子集。 仅接受级别大小可被子集大小整除的那些子集，在本例中包括所有子集，因为级别大小为 1。结果恰好是$2^3 - 1 = 7$，匹配所有可能的非空颜色选择。 

对于供应高度不平衡的情况，例如$R=100, G=0, B=0$，只有单色红色分配得以保留。 DP 仍然探索其他分支，但当出现负计数时立即修剪它们，确保正确性而无需额外的逻辑。
