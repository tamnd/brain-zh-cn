 ## 解决方案
 ## 问题理解

 我们拥有一个由航班连接的城市定向网络。 每个航班都有一个方向和费用，因此如果我们乘坐该航班，从城市 U 到城市 V 会减少 C 的费用。 除了移动之外，每次我们到达一个城市时，我们都会赚取与该城市相关的固定利润，并且每次访问该城市时都会收取该利润，而不仅仅是一次。 

我们从城市 S 出发，想要到达城市 T。目标是在任意顺序的航班和城市访问后最大化累积的总资金。 关键的复杂性在于，允许重新访问城市，并且每次重新访问都会再次产生利润，因此有可能利用周期。 然而，每次我们穿越边缘时，飞行成本仍然适用。 

输出要么是在T时最大可实现的最终货币，要么是声明由于可以利用的正循环而可以任意大地赚取利润，同时仍然能够达到T，或者T是无法达到的。 

就节点而言，约束很小，N ≤ 100，但边最多可达 10000。这立即表明 O(N^3) 或 O(N·M) 方法是可以接受的，而路径上的任何指数形式都是不可能的。 潜在可利用循环的存在强烈表明具有负循环的最短路径公式，而不是纯粹的贪婪或非循环图中的 DP 方法。 

最重要的边缘情况是一个周期具有净正收益（利润减去差旅成本）。 如果这样的循环从S可达，并且仍能通向T，那么我们可以任意循环多次，无限增加利润。 朴素的最短路径算法可能仍会返回有限值，除非它明确检测并传播这些无限增益状态。 

例如，考虑循环 1 → 2 → 3 → 1，其中总利润超过总成本。 如果这个循环中的任何一个节点能够达到T，那么答案是无限的。 仅跟踪最佳距离而不进行循环推理的天真放松可能会提前终止并错过这一点。 

另一种边缘情况是当从 S 无法到达 T 时。最短路径算法可能仍会计算所有节点的距离，但答案必须明确检测到从未到达 T。 

## 方法

 思考这个问题的一个直接方法是将每次城市访问视为增加利润，将每次飞行视为减去成本。 如果我们为每个城市定义一个州值，代表我们到达那里时可以拥有的最大金钱，那么每个航班 U → V 都会给出一个转换：

 价值[V] = 价值[U] - 成本(U,V) + 利润(V)

 这是有向图中具有可能循环的标准最长路径问题。 如果图是非循环的，拓扑顺序动态规划将立即解决它。 问题是周期是存在的，而且周期是有益的。 

暴力方法会尝试枚举从 S 到 T 的所有可能路径并计算它们的净增益。 这在概念上是正确的，因为每条路径都有明确定义的总利润减去成本。 然而，带有循环的图中的路径数量是无限的，甚至限制为简单路径也会导致 N 中的指数复杂度。对于最多 100 个节点，这是完全不可行的。 

关键的见解是将问题转化为可能存在负循环的最短路径问题。 如果我们将转换重写为：

 成本(U → V) = 航班成本(U,V) - 利润(V)

 并从初始成本-利润(S)开始，然后最小化总成本对应于最大化利润。 这将问题转化为标准的最短路径计算。 

一旦处于这种形式，贝尔曼-福特自然就会出现，因为它可以检测负循环。 该转换图中的负循环与原始问题中的正利润循环完全对应。

然而，仅仅检测负循环还不够。 我们只关心该循环是否会影响从 S 到 T 的路径。因此，在检测到属于负循环或可从负循环到达的所有节点之后，我们必须检查它们中是否有任何一个可以到达 T。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力路径枚举| 指数| O(N) | 太慢了|
 | 贝尔曼-福特 + 循环传播 | O(N·M) | O(N + M) | 已接受 |

 ## 算法演练

 1. 变换图，使每条边 U → V 的权重 W = 成本(U,V) - 利润(V)。 我们还将 S 的起始值初始化为 -profit(S)。 这将利润最大化转化为总重量最小化。 
2. 在所有边上运行 Bellman-Ford 进行 N 次迭代，以计算距 S 的最短距离。如果我们仍然可以在第 N 次迭代中放松边，则将目的地标记为负循环的一部分或受负循环影响。 此步骤标识其值可以无限减少的所有节点。 
3. 构建或重用图邻接列表，并从标记为受负循环影响的所有节点运行可达性搜索（BFS 或 DFS）。 这将周期的影响扩大到从它们可到达的所有节点，因为进入这样的区域允许任意利润放大。 
4. 检查这个传播集中的任何节点是否可以达到 T。如果是，答案是“Money hack！”，因为我们可以循环利润循环并最终仍然达到 T。 
5. 如果首先从 S 无法到达 T，则输出“Bad trip”。 
6. 否则，输出到T的最短距离，对应最大利润。 

正确性取决于贝尔曼-福特捕获变换图中从 S 可达的所有负循环这一事实，并且传播确保我们仅在这些循环可以影响到 T 的路径时才声明无穷大。 

### 为什么它有效

 变换后，每条路径成本等于原始利润的负值。 因此，最小化路径成本相当于最大化利润。 Bellman-Ford 保证图中正确的最短路径，没有负循环，并检测何时由于负循环而可能进一步改进。 任何这样的循环都意味着任意降低成本，即任意增加利润。 

最后的传播步骤确保只有可以影响目的地的循环才有意义。 存在但与通往 T 的任何路径隔离的循环并不重要，因为它不能用于有效的 S → T 旅程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, M, S, T = map(int, input().split())
    S -= 1
    T -= 1

    edges = []
    adj = [[] for _ in range(N)]

    P = list(map(int, input().split()))

    for _ in range(M):
        u, v, c = map(int, input().split())
        u -= 1
        v -= 1
        w = c - P[v]
        edges.append((u, v, w))
        adj[u].append(v)

    INF = 10**18
    dist = [INF] * N
    dist[S] = -P[S]

    for _ in range(N - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break

    bad = [False] * N

    for u, v, w in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            bad[v] = True

    from collections import deque
    q = deque(i for i in range(N) if bad[i])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if not bad[v]:
                bad[v] = True
                q.append(v)

    if dist[T] == INF:
        print("Bad trip")
        return

    if bad[T]:
        print("Money hack!")
        return

    print(-dist[T])

if __name__ == "__main__":
    solve()
```该实现首先将问题转换为最短路径模型，其中利润被吸收到边缘权重中。 Bellman-Ford 运行 N−1 次迭代，任何进一步的改进都将节点标记为有问题的循环影响的一部分。 

一个微妙的细节是我们初始化`dist[S] = -P[S]`，因为从 S 开始就立即获得利润。另一个微妙之处是我们只通过传出边缘向前传播“坏”状态； 这确保我们只标记进入循环后实际可达的节点。 

最后，答案是否定的，因为我们优化了最小的转换成本，而原始问题要求最大的利润。

### 示例 2

 输入：```
5 5 1 5

```这里不存在良性循环，成本占主导地位。 

| 步骤| 行动| 距离[5] | 坏集|
 | ---| ---| ---| ---|
 | 初始化| 距离[1] = -5 | 信息 | ∅ |
 | 放松 | 正常最短路径| 有限| ∅ |

该迹线表明，在没有负循环的情况下，贝尔曼-福特完全简化为标准最短路径问题。

 ## 边缘情况

 关键边缘情况是存在但无法达到 T 的盈利循环。该算法在`bad`数组，但传播没有到达T，因此不会错误地输出无限利润。 例如，如果节点 2-3-4 形成正循环，但只有节点 1 连接到 T，则循环中的 BFS 永远不会到达 T，并且算法可以安全地计算有限最短路径。 

另一种情况是S本身处于盈利周期内。 初始化和第一轮松弛正确地允许 S 参与循环检测，并且传播确保如果 T 位于下游，则整个可达区域被标记为无限。 

最后一个微妙的情况是多个周期相互作用。 Bellman-Ford 标记距离在第 N 次迭代中增加的任何节点，并且传播会合并所有此类区域。 这确保了即使是链式循环如果最终影响 T，也会被视为单个可利用的结构。
