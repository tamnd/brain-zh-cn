 ## 问题理解

 任务是找到特殊形式的三次方程的实数解$$f(x) = x^3 + ax + b$$其中输入给出两个系数`a`和`b`。 这两个值都是非负的，这保证了方程只有一个实根。 程序必须以足够的精度输出该根，以便法官在允许的浮点误差内接受答案。 

乍一看，这看起来像是一个标准的方程求解问题，并且有三次方程的数学公式。 然而，直接实现三次公式通常并不是这里最好的竞争性编程方法。 输入值可以大到$10^9$，而法官只需要一个数值近似值，而不是一个精确的符号答案。 这表明寻找一种数值方法而不是用代数方法处理方程。 

尺寸为`a`和`b`排除任何尝试许多候选值的方法。 我们无法扫描可能的答案，因为根可能在附近$-10^9$，并且检查数十亿的值是不可能的。 解决方案需要使用函数的单调结构并以少量固定数量的操作完成。 

重要的性质来自导数：$$f'(x)=3x^2+a$$自从`a`是非负的，导数总是正的。 这意味着该函数在各处都是严格递增的。 严格递增连续函数最多过零一次，并且由于该问题保证根存在，因此我们可以使用二分查找来定位它。 

有一些浮点陷阱可能会破坏看似正确的实现。 一个常见的错误是选择的区间并不总是包含答案。 例如，使用输入```
1000000000 0
```方程是$$x^3 + 10^9x = 0$$答案正是`0`。 如果由于三次项占主导地位，解仅搜索正值，则它会错过其他情况下可能根的负值。 

另一个错误是使用对于大的间隔来说太小`b`。 例如：```
0 1000000000
```需要解决$$x^3+10^9=0$$这给出了接近于的根`-1000`。 搜索范围如`[-100,100]`永远达不到答案。 

两个系数都为零的情况也需要注意：```
0 0
```方程变为$$x^3=0$$答案是`0`。 当答案恰好位于搜索间隔的边界或中点时，二分搜索实现仍必须正确收敛。 

## 方法

 最直接的想法就是尝试猜测答案。 由于函数很简单，我们可以选择多个值`x`， 评价$$x^3+ax+b$$并寻找它变为零的地方。 这是正确的，因为该函数是连续的，因此足够接近根的值将产生一个小的绝对值。 问题是没有有用的离散范围可供搜索。 根可以小至`0`或周围`-1000`对于给定的限制，任意精度的扫描将需要太多的评估。 即使我们尝试了数百万个候选者，也无法保证精度要求。 

关键的观察是我们不是在搜索任意函数。 这里的三次函数是严格递增的，因为它的导数总是正的。 这意味着每个小于根的值都会产生负结果，每个大于根的值都会产生正结果。 

这正是实数二分查找所需的条件。 我们维护一个包含根的区间，反复检查中间的部分，并丢弃不能包含答案的一半。 经过足够的迭代后，间隔变得非常小，并且任一端点都是一个很好的近似值。 

剩下的唯一问题是如何选择初始边界。 因为`b`是非负数，根不能是正数。 如果`x`是积极的，每一项$$x^3+ax+b$$是非负数，因此该函数不能等于零，除非`x = 0`当两个系数都为零时。 负侧需要足够大以容纳根。 自从$$(-100000)^3$$已经比任何可能的正数小得多`b`，使用类似的范围`[-10^6, 10^6]`足够安全。 另一种常见的方法是从`b`，但是固定的大区间更简单并且容易满足约束条件。
