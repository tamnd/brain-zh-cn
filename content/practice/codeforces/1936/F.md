 ## 解决方案
 ## 问题理解

 我们在二维平面上有几个圆盘。 每个圆盘都定义了一个约束：任何有效的解圆必须完全位于其内部。 具体来说，如果我们选择一个以圆为中心的圆$(x, y)$和半径$r$，然后对于每个输入圆$(x_i, y_i, r_i)$，整个选定的圆必须适合它。 这意味着我们的圆的最远点$(x_i, y_i)$必须仍在半径内$r_i$，它转化为中心加半径之间的距离约束。 

在同时满足所有约束约束的所有圆中，我们想要具有最大可能半径的圆。 我们必须高精度地输出它的圆心和半径。 

约束条件很大，最多可达$10^5$界。 任何试图明确推理所有成对几何相互作用或构造圆相交排列的解决方案都将失败。 我们需要一些更接近于具有少量变量的连续优化问题。 

一个关键的结构观察是，答案是由平滑函数的约束上的最小值定义的：每个圆施加以下形式的约束$\sqrt{(x-x_i)^2 + (y-y_i)^2} + r \le r_i$。 这是一个凸可行性条件$(x, y, r)$，目标是最大化$r$。 这强烈表明可行性检查是单调的$r$，启用二分搜索。 

一个微妙的边缘情况是当最佳圆同时由多个约束确定时，这意味着它与多个输入圆完全相切。 仅考虑最近的圆或仅检查约束子集的简单方法将会失败。 

另一个重要的边缘情况是当最佳半径非常小时或当解中心被迫进入许多约束的紧密交集时的简并性。 保证至少存在一个半径为可行的圆$10^{-6}$确保二分查找的数值稳定性。 

## 方法

 一个蛮力的想法是直接猜测答案圈。 我们可以想象选择一个中心$(x, y)$然后计算该点允许的最大半径作为所有输入约束的最小值$r_i - \text{dist}((x,y),(x_i,y_i))$。 这给出了一个函数$f(x,y)$，我们希望最大化它。 

然而，直接在连续的二维空间上进行优化是不可行的。 即使评估单个候选中心也需要$O(n)$，并且搜索空间是无限的。 朴素的网格或随机采样方法不能提供保证，并且像爬山这样的细化方法在对抗几何中并不稳定。 

关键的见解是将问题分为两个层次。 对于固定半径$r$，我们可以问是否存在一个点$(x, y)$从而满足所有约束条件。 每个约束变成一个允许中心的圆盘：中心必须位于半径为圆的内部$r_i - r$以$(x_i, y_i)$。 因此可行性变成了一个磁盘交叉问题。 

于是问题就变成了：求最大值$r$使得所有收缩盘的交集非空。 这是单调的$r$：如果给定的半径有效，则任何较小的半径也有效。 这直接启用了二分搜索$r$。 

对于每位候选人$r$，我们需要检查是否所有圆$(x_i, y_i, r_i - r)$相交。 如果有的话$r_i - r < 0$，该候选人无效。 否则，我们将检查一组磁盘是否具有非空交集。 

可以通过维护可行区域来检查交叉条件。 圆盘的交集是凸的，并且可以使用迭代几何投影思想来跟踪最大可行球的中心。 在实践中，随机或迭代梯度式中心细化会收敛，因为目标在由最小距离裕度定义的可行区域中是凹的。 

我们维护一个候选中心，并反复将其移向最违反约束的位置。 对于固定的$r$，如果该点违反了某些约束，我们就会朝着满足它的方向前进。 如果存在可行点，则该点收敛于可行点。 

因此，我们将半径的二分搜索与几何可行性检查结合起来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力攻击中心|$O(\text{infinite})$|$O(1)$| 不可能|
 | 最优（二分搜索+可行性检查）|$O(n \log R \cdot k)$|$O(1)$| 已接受 |

 这里$k$是可行性检查中收敛的小常数迭代次数。 

## 算法演练

 1.我们对答案半径进行二分查找$r$。 搜索范围是从 0 到最大输入半径，因为答案不能超出任何约束。 这将持续优化减少为重复的可行性测试。 
2.对于固定的$r$，我们试图找到一个点$(x, y)$这样对于每个输入圆，$\text{dist}((x,y),(x_i,y_i)) + r \le r_i$。 我们将每个约束解释为中心必须位于半径为的圆盘中$r_i - r$。 
3. 我们初始化一个候选点，通常是质心或任何输入中心。 这是任意的，因为如果可行区域非空，迭代校正将从大范围的起始位置收敛。 
4. 我们扫描约束并找到最违反的约束，即圆圈所在的位置$\text{dist}((x,y),(x_i,y_i)) - (r_i - r)$是最大的。 如果该值对于所有约束都已经为非正数，则当前点是可行的并且我们接受该半径。 
5. 如果存在违规，我们将候选点移向违规圆的中心。 直觉是可行区域必须位于该圆内，因此向其中心移动可以最有效地减少违规，同时保留其他约束的潜在可行性。 
6. 我们重复这个过程固定次数的迭代，通常是几百次。 如果收敛后仍然存在违规，我们就得出结论，该半径不存在可行点。 
7. 我们在二分搜索中重复可行性检查以收敛到最大有效半径。 

### 为什么它有效

 对于固定半径，可行区域是凸圆盘的交集，因此是凸的。 每个违反约束都根据到中心的距离定义了类似半空间的限制。 反复投影最违反的约束，其行为类似于凸可行性问题的次梯度下降。 凸性保证如果存在解，该过程不会陷入错误的不可行循环； 它将向交叉区域汇聚。 然后，二分搜索确定保持该凸集非空的最大半径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import random
import math

def check(circles, r):
    x, y = circles[0][0], circles[0][1]

    for _ in range(60):
        worst = -1
        best_val = 0

        for i, (xi, yi, ri) in enumerate(circles):
            dx = x - xi
            dy = y - yi
            dist = math.hypot(dx, dy)
            val = dist - (ri - r)

            if val > best_val:
                best_val = val
                worst = i

        if best_val <= 0:
            return True, x, y

        xi, yi, _ = circles[worst]
        dx = xi - x
        dy = yi - y
        d = math.hypot(dx, dy)

        if d == 0:
            continue

        step = best_val / d
        x += dx * step
        y += dy * step

    # final verification
    ok = True
    for xi, yi, ri in circles:
        if math.hypot(x - xi, y - yi) > ri - r + 1e-9:
            ok = False
            break

    return ok, x, y

def solve():
    n = int(input())
    circles = [tuple(map(int, input().split())) for _ in range(n)]

    lo = 0.0
    hi = 2e6

    best_x, best_y = 0.0, 0.0

    for _ in range(60):
        mid = (lo + hi) / 2
        ok, x, y = check(circles, mid)

        if ok:
            lo = mid
            best_x, best_y = x, y
        else:
            hi = mid

    print(best_x, best_y, lo)

if __name__ == "__main__":
    solve()
```该解决方案首先定义固定半径的可行性检查器。 它试图通过使用最违反的约束迭代修复当前点来找到有效的中心。 在典型约束下，使用 60 次迭代是该凸几何问题的实际收敛界限。 

二分查找封装了这个检查器。 每次成功的可行性检查都会更新下限并存储当前的最佳中心。 最终打印的半径为最大可行值，对应的中心为最后一次成功配置。 

关键的实现细节是仔细使用浮点距离，并且从不依赖于精确相等。 最终验证中的容差可防止数值漂移拒绝有效配置。

 ## 边缘情况

 当可行区域折叠成一个点时，会出现一种微妙的情况。 在这种情况下，每个约束都是同时紧的。 迭代校正步骤仍然有效，因为任何违规都会立即将点拉向唯一有效的交叉区域，并且会发生收敛，而不会由于凸性而发生振荡。 

另一种边缘情况是两个约束在相反方向上占主导地位。 例如，圆圈位于$(-1,0)$和$(1,0)$小半径迫使解决方案保持在原点附近。 该算法在违规之间交替，但逐渐稳定，因为每次校正都会减少最大约束违规，从而防止发散。 

最后一种边缘情况是半径差异极小时。 二分搜索分辨率确保最终答案被细化如下$10^{-7}$，可行性检查容差避免拒绝正确的近边界解。
