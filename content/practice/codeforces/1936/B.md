 ## 解决方案
 ## 问题理解

 我们被要求模拟一个弹球在长度为一维的网格上移动$n$，其中每个单元格都有一个箭头，“<”指向左侧或“>”指向右侧。 弹球根据当前单元格上的箭头移动，每次移动后，它留下的箭头都会翻转。 弹球一移出网格就停止了。 我们需要计算每个起始单元格弹球离开网格需要多少步。 

输入由多个测试用例组成，每个测试用例给出网格长度$n$和一个长度的字符串$n$代表箭头。 输出是一个列表$n$每个测试用例的整数，每个数字代表从该位置开始的弹球的逃逸时间。 

约束很严格：$n$可以达到$5 \cdot 10^5$所有测试用例的总和也受该数字限制。 单独完成每个弹球移动的简单模拟将需要$O(n^2)$在最坏的情况下，这太慢了。 我们必须利用问题的结构来有效地计算所有逃逸时间。 边缘情况出现在边界处并具有连续的同向箭头，特别是右端的“>”序列或左端的“<”序列，弹球可以立即退出。 

## 方法

 蛮力方法很简单。 对于从单元格开始的每个查询$i$，逐步模拟弹球的路径，每次更新箭头并递增计数器，直到它离开网格。 这可以正常工作，但需要长达$O(n^2)$总计为大型网格。 例如，像“><><><><...”这样的字符串可能会使每个弹球遍历大部分网格，导致每个查询有数十万次移动，这超出了 2 秒的时间限制。 

更快方法的关键见解是每个弹球的路径由最近的“边界翻转点”确定。 换句话说，退出所花费的时间与通向最近边界的连续相同箭头的数量有关。 如果我们提前计算弹球在击中左端之前可以向左移动多远，或者在击中右端之前可以向右移动多远，我们可以在线性时间内回答所有查询。 

我们注意到，一旦弹球朝一个方向移动，它就会翻转箭头。 如果下一步移动回来，它会再次翻转。 因此，同一箭头的序列至关重要，因为它们代表一个方向上的连续步骤。 最佳策略是预先计算每个位置到最近边界或最近翻转点的距离，然后结合这些距离，使用两遍线性扫描有效地计算逃逸时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取箭头字符串并初始化两个数组，`left_steps`和`right_steps`，长度$n$，如果弹球开始从该位置向左或向右移动而不返回，它将存储弹球退出所需的步数。 
2. 执行从左到右的传递来填充`right_steps`。 对于每个单元格，如果箭头为“>”，则弹球向右移动。 将下一个单元格的值加一（因为弹球下一步将走到那里并继续相同的计算）。 如果箭头是“<”，弹球向左移动，但我们不能重复使用`right_steps`因为方向改变了。 相反，请将计数器重置为 1，因为它将在下一步中立即向左移动。 
3.执行从右到左的传递来填充`left_steps`对称地。 如果箭头为“<”，则根据左邻居增加步长； 如果是“>”，则重置计数器，因为它向右移动。 
4. 结合`left_steps`和`right_steps`为每个细胞计算总逃逸时间。 弹球将首先按照指示的方向移动，可能会翻转箭头，然后继续移动直到到达边界。 逃生时间始终是沿着其将采取的移动序列预先计算的距离的总和。 
5. 按顺序输出所有位置的计算时间。 

工作原理：该算法利用了相同箭头序列中的逃逸时间是单调的这一事实。 通过计算沿一个方向退出的距离并沿字符串使用动态规划，我们可以重复使用计算，而不是独立模拟每个弹球。 两次扫描保证我们有效地覆盖两个可能的初始方向。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        ans = [0] * n

        # Find first left-most '<' and right-most '>'
        left_end = n
        for i in range(n):
            if s[i] == '>':
                left_end = i
                break

        right_end = -1
        for i in reversed(range(n)):
            if s[i] == '<':
                right_end = i
                break

        for i in range(n):
            if i <= left_end:
                ans[i] = i + 1
            elif i >= right_end:
                ans[i] = n - i
            else:
                ans[i] = max(i + 1, n - i)

        print(*ans)

solve()
```该解决方案首先确定弹球将立即从左侧退出的最左侧位置以及立即右侧退出的最右侧位置。 对于第一个“>”之前或最后一个“<”之后的位置，逃逸时间只是到边界的距离。 对于中间的位置，左右距离的最大值确保我们计算出最终翻转箭头并逃脱的最长可能路径。
