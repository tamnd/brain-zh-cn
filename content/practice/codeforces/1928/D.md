 ## 解决方案
 ## 问题理解

 我们被要求组建一支来自多个种族的军队，每个种族都有一定数量的生物。 来自同一种族的每个生物对，如果被放置在不同的小队中，则贡献固定的金额`b`以军队的实力。 另一方面，除了第一个小队之外，每增加一个小队都会使总兵力减少`x`。 我们的任务是确定如何将生物划分为小队，以最大限度地发挥军队的力量。 

输入由多个测试用例组成。 对于每个测试用例，我们知道比赛的数量`n`, 配对奖金`b`, 球队罚球`x`，和数组`c`给出每个种族的生物数量。 我们必须输出一个整数，代表每种情况下的最大军队力量。 

约束表明`n`最多可达 200,000，但所有的总和`c_i`所有测试用例不超过200,000。 这意味着我们可以对生物总数进行线性运算，但任何二次运算都可以`c_i`太慢了。 因此，任何尝试各种方法将生物单独分成小队的暴力方法都无法扩展。 不明显的边缘情况包括只有一种生物的种族，或者由于较高的战斗力而分成多个小队会降低整体实力的情况`x`。 例如，如果`b = 1`和`x = 10`，即使将两个生物组成的种族分成不同的小队也比将它们放在一起更糟糕，从而产生零附加力量的正确答案。 

## 方法

 暴力解决方案将枚举所有可能的小队数量，尝试所有方法将生物分配给小队，计算所得的配对贡献和来自多个小队的惩罚，并选择最大值。 对于与`c_i`生物，划分它们的方法数量呈指数增长，因此即使对于中等值，这种方法也很快变得不可行`c_i`。 在最坏的情况下，操作次数将超过 2 × 10^5 × 2 × 10^5，这在一秒内是不可能的。 

关键的见解是独立考虑每个种族，并认识到一场种族的贡献完全取决于它分为多少个小队。 为了`k`分队，与`c_i`生物贡献`b * (sum_{j=1}^{k} (number of creatures in squad j choose 2))`。 为了最大化奖励，同一种族的生物应该尽可能均匀地分布在小队中，因为通过平衡可以最小化平方和。 这一观察结果将问题简化为一个变量的函数：小队的数量`k`。 然后，军队总兵力就是所有种族跨小队贡献值减去惩罚值的总和`(k - 1) * x`。 该函数是单峰的`k`因为增加`k`首先增加对贡献，但最终惩罚占主导地位。 这允许我们使用三元搜索`k`或者简单地迭代可能的`k`有效值，因为最大`k`对于一场比赛来说最多是`c_i`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(总和 c_i)) | O(总和 c_i) | 太慢了 |
 | 最佳 | O(总和 c_i) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`,`b`,`x`，和数组`c`。 
2. 排序`c`如果您愿意，可以按降序排列，但这并不是绝对必要的。 
3. 对于给定的小队总数`k`，计算每个种族的贡献。 对于与`c_i`生物，尽可能均匀地分成`k`小队。 让`q = c_i // k`和`r = c_i % k`。 然后`r`小队有`q+1`生物和`k-r`小队有`q`生物。 队间对的数量为`(q+1)*q/2 * r + q*(q-1)/2 * (k-r)`。 乘以`b`以获得贡献。 
4. 将所有比赛的贡献相加并减去球队罚分`(k-1) * x`以获得军队总实力。 
5. 求值`k`最大限度地提高军队总兵力。 由于该函数是单峰的，因此您可以从 1 迭代到最大值`c_i`跨种族或使用三元搜索来提高速度。 给定约束，对所有可能的情况进行简单循环`k`高效工作。 
6. 输出测试用例的最大兵力。 

为什么有效：通过在小队中均匀分配生物，可以最大限度地提高每个种族的贡献。 惩罚是线性的`k`。 通过迭代或搜索`k`，我们确保找到全局最大值，因为该函数是单峰的。 不均匀分割的组合不能改善结果，因为任何不平衡都会减少对贡献的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_strength(n, b, x, c):
    max_c = max(c)
    best = 0
    for k in range(1, max_c + 1):
        total = 0
        for ci in c:
            if ci < k:
                continue
            q, r = divmod(ci, k)
            total += b * (r * q * (q + 1) // 2 + (k - r) * q * (q - 1) // 2)
        total -= (k - 1) * x
        best = max(best, total)
    return best

t = int(input())
for _ in range(t):
    n, b, x = map(int, input().split())
    c = list(map(int, input().split()))
    print(max_strength(n, b, x, c))
```功能`max_strength`实现该算法。 内循环尽可能均匀地分布每个种族的生物`k`小队。 我们使用整数除法和模数来处理余数，确保没有小队被跳过或重复计算。 的减法`(k-1) * x`正确模拟球队处罚。 迭代至`max_c`就足够了，因为使用比最大比赛更多的小队不会产生额外的配对。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(总和 c_i * max_c) | 外循环在各个比赛中运行至 max(c_i)，内循环对所有比赛的贡献进行求和，总和以 2e5 为界 |
 | 空间| O(n) | 每个测试用例仅存储数组 c |

 和`sum c_i ≤ 2 × 10^5`和`max_c ≤ 2 × 10^5`，这在 1 秒内是可以接受的。
