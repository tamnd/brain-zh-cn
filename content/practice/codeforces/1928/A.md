 ## 解决方案
 ## 问题理解

 我们有一个有边的矩形$a$和$b$，我们被问到是否可以沿着平行于其一条边的线将这个矩形切成两个具有整数尺寸的较小矩形，然后用这两块形成一个与原始形状**不同的矩形$a \times b$长方形。 相互旋转的矩形（例如，$6 \times 4$和$4 \times 6$) 被认为是相同的。 

输入提供多个测试用例。 每个测试用例由两个整数组成$a$和$b$代表矩形的尺寸。 如果可以形成另一个矩形，则输出必须回答“是”，否则回答“否”。 

限制条件很大：$a$和$b$可以达到$10^9$，并且最多可以有$10^4$测试用例。 这排除了任何尝试枚举所有可能的切割或模拟形成所有可能的矩形的方法。 我们需要一个能够在**每个测试用例的恒定时间内**计算答案的解决方案。 

最小的不平凡的矩形突出了微妙的边缘情况。 一个$1 \times 1$矩形根本无法被切割，所以答案是“否”。 一个$2 \times 1$矩形只能被切割成$1 \times 1$矩形，可以重新组装成$1 \times 2$，旋转后与原来相同，所以答案也是“否”。 矩形尺寸$2 \times 2$或更大的通常允许切割，从而产生新的矩形。 

## 方法

 暴力方法将尝试所有可能的水平和垂直切割，生成结果矩形，并检查是否可以形成不同的矩形。 每次切割都会生成两个矩形，我们可以尝试将它们以水平和垂直堆叠配置组合起来。 对于大尺寸，这很快就变得不可行，因为即使是尺寸接近的矩形$10^9$会创造$10^9$的可能性，并且与$10^4$测试用例，不可能在1秒内跑完。 

关键的观察是几何和组合的。 要形成一个与原来不同的新矩形，我们需要原来的矩形至少有一条边至少为2。如果两条边都为1，我们就不能切割。 如果至少一条边是 2 或更大，我们总是可以沿着该边进行切割，生成两个矩形，这两个矩形可以重新排列成不同比例的矩形。 具体来说，任何矩形$a \ge 2$或者$b \ge 2$可以被切成至少一维为 1 的两块，并且这些块可以堆叠形成一个新的矩形，其边长是切割块的总和。 唯一的例外是矩形$2 \times 1$或者$1 \times 2$，它不能产生新的形状，因为沿着较大的边切割会产生两个$1 \times 1$正方形，它们重建成相同的矩形。 

因此，问题简化为一个简单的条件检查：矩形太小而无法生成新形状，如果它是$1 \times 1$或者$2 \times 1$（或者$1 \times 2$），否则“是”。

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$a$和$b$。 
3. 交换$a$和$b$如果有必要的话$a \le b$。 这简化了关于较小边和较大边的推理。 
4. 检查是否$a = 1$和$b = 1$。 如果为 true，则输出“No”，因为$1 \times 1$矩形不能被切割。 
5. 检查是否$a = 1$和$b = 2$。 如果为 true，则输出“No”，因为$1 \times 2$矩形只能在切割和重新排列后产生相同的矩形。 
6. 否则，输出“Yes”，因为存在可以生成新矩形的剪切。 
7. 对所有测试用例重复此操作。 

为什么它有效：不变的是矩形的最小边决定是否可以进行有意义的切割。 如果最小边至少为 2，则水平或垂直切割可以创建两个可以重新组合成新矩形的块。 唯一的例外是最小尺寸的矩形$1 \times 1$和$1 \times 2$，这是明确处理的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    if a > b:
        a, b = b, a
    if a == 1 and b <= 2:
        print("No")
    else:
        print("Yes")
```该代码使用有效地读取所有测试用例`sys.stdin.readline`。 交换确保我们始终首先处理较小的一侧，这简化了边缘情况检查。 条件`a == 1 and b <= 2`捕获无法生成新形状的最小矩形。 所有其他矩形自动满足可能切割的几何条件。

 ## 边缘情况

 对于$1 \times 1$矩形，算法正确地识别出`a==1 and b<=2`为 true，则输出“No”。 为了$1 \times 2$，相同的条件触发“否”。 对于像这样的矩形$2 \times 3$或更大，条件为假，算法输出“是”，捕获剪切可以产生新矩形的一般情况。 交换步骤确保较小的一侧始终位于`a`，因此边缘条件检查是均匀的，不会错过任何最小情况。
