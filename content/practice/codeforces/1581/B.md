 ## 解决方案
 ## 问题理解

 我们被要求确定是否可以用给定数量的节点构造一个简单的、连通的、无向的图`n`和边缘`m`使得图的直径严格小于`k-1`。 图的直径是任意两个节点之间的最大距离，其中距离是通过连接它们的路径上的最小边数来测量的。 不允许有自环或多边。 

输入由多个测试用例组成。 每个测试用例指定的值`n`,`m`， 和`k`。 对于每个条件，如果可以构建满足这些条件的图，我们必须输出“YES”，如果不可能，则必须输出“NO”。 

鉴于限制条件，`n`和`m`可以达到$10^9$并且最多可以有$10^5$测试用例。 这意味着我们无法显式地构造图或执行任何可缩放的操作`n`或者`m`。 相反，我们必须根据节点、边的数量和所需直径对可能发生的情况进行数学推理。 

边缘情况出现时`n`非常小。 如果`n = 1`，唯一有效的图没有边且直径为 0，这可能满足以下一些值`k`。 如果`k = 1`，要求直径小于0，这是不可能的。 什么时候`m = 0`，如果`n > 1`。 在这些情况下，简单的计数可能会产生不正确的结果。 

## 方法

 蛮力方法是尝试显式构造图并检查其直径。 对于小`n`，可以尝试所有可能的边缘组合并测量直径。 这适用于微小的输入，但完全失败`n`和`m`按顺序$10^9$因为即使构建邻接表也需要花费大量的时间和空间。 

关键的见解是连通图中的最小和最大边数`n`节点是已知的。 连通图必须至少有`n-1`边缘。 没有循环或多重边的最大边数为$\frac{n(n-1)}{2}$。 

直径限制进一步限制了可能性。 直径严格小于`k-1`可以解释为：

 - 如果`k = 1`，直径必须为 0。这仅适用于`n = 1`。 
- 如果`k = 2`，直径必须小于 1，即 0，这又要求`n = 1`。 
- 为了`k >= 3`，任何连通图的直径都在 1 和`n-1`。 星图的直径为 2，链的直径为`n-1`。 

我们现在可以完全进行数学推理：图必须是连通的（`m >= n-1`），边的数量不能超过完整图（`m <= n(n-1)/2`）， 和`k`施加了额外的限制`n`。 这些条件足以在 O(1) 时间内回答每个测试用例。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n²) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`,`m`,`k`。 
3. 首先处理琐碎的不可能的事情：如果`n = 1`，图的直径为 0。这满足直径约束，如果`k > 1`和`m = 0`。 否则的话，那是不可能的。 
4. 如果`n = 2`，图可以有 0 条或 1 条边。 如果有边缘，则直径为 1；如果没有，则直径为 0。 检查这是否满足`k-1`。 
5. 对于`n >= 3`，该图必须是连通的。 所以`m >= n-1`。 如果`m < n-1`，输出“否”。 
6. 最大可能的边数为$\frac{n(n-1)}{2}$。 如果`m > n(n-1)/2`，输出“否”。 
7. 直径要求取决于`k`。 星图与`n >= 3`直径为 2。因此，如果`k = 1`，这是不可能的。 如果`k = 2`，只有完全图的直径才能为 1，所以`m`必须等于`n(n-1)/2`。 否则，`k >= 3`总是可以实现的，只要`n >= 3`和`m`是在有效范围内。 
8. 如果满足所有条件，则输出“YES”。 否则，输出“NO”。 

工作原理：该算法依赖于连通图的数学特性和标准结构（链、星、完整）的已知直径。 每项检查都直接对应于一个不可能性约束。 由于我们只对计数和界限进行推理，因此不需要实际的图形构建。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        if n == 1:
            print("YES" if m == 0 and k > 1 else "NO")
            continue
        if n == 2:
            if m > 1 or m < 1:
                print("NO")
            else:
                print("YES" if k > 1 else "NO")
            continue
        min_edges = n - 1
        max_edges = n * (n - 1) // 2
        if m < min_edges or m > max_edges or k == 1:
            print("NO")
        elif k == 2:
            print("YES" if m == max_edges else "NO")
        else:
            print("YES")

if __name__ == "__main__":
    main()
```该解决方案首先处理最小的图形，其中边数和直径要求是极端情况。 然后，它计算连通图的最小和最大边，并直接应用基于星形图和完全图结构的直径逻辑。 这确保了每个测试用例的 O(1)。
