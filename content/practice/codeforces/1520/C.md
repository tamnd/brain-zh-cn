 ## 解决方案
 ## 问题理解

 我们被要求填写一个$n \times n$方格网的数字来自$1$到$n^2$使得没有两个水平或垂直相邻的单元包含连续的整数。 换句话说，相邻单元格中的数字之间的差异不可能恰好为 1。 输入由多个测试用例组成，每个测试用例提供一个整数$n$，输出要么是该大小的有效矩阵，要么是$-1$如果不存在解决方案。 

限制相当小：$n$范围从 1 到 100，最多可以有 100 个测试用例。 这意味着我们可以提供大致复杂的解决方案$O(n^2)$每个测试用例，因为$100 \cdot 100^2 = 10^6$4 秒的时间限制内的操作是可接受的。 

一些边缘情况立即显而易见。 为了$n = 1$，解决方案很简单：一个数字为 1 的单元格。对于$n = 2$然而，不存在任何安排。 1 到 4 的任何放置都将迫使至少一对连续数字共享一条边。 对于较大的$n$，挑战在于排列数字以避免连续整数的邻接，并且天真的逐行填充将会失败，因为连续的数字将不可避免地成为邻居。 

## 方法

 蛮力方法将尝试生成所有排列$1$到$n^2$并检查每一项是否有邻接违规。 虽然这在原则上是正确的，但它是完全不可行的：对于$n = 5$， 有$25!$排列，这是一个天文数字。 

关键的观察是，我们可以通过将连续数字分成两组来避免相邻的数字：奇数和偶数。 如果我们首先用所有奇数填充网格，然后用所有偶数填充网格，则任何两个连续数字（始终相距一）之间的差异永远不会在水平或垂直方向上相邻。 这对所有人都有效$n \ge 3$。 这些子集中的排列可以遵循简单的从上到下、从左到右的模式。 

这个想法大大降低了复杂性：我们不检查排列，而是系统地按奇偶校验顺序排列数字。 唯一的例外是$n = 2$，无法解决，并且$n = 1$，这是微不足道的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((n^2)!) | O((n^2)!) | O(n^2) | O(n^2) | 太慢了|
 | 奇偶放置 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$。 如果$n = 2$， 输出$-1$立即，因为不存在解决方案。 如果$n = 1$，输出包含 1 的单个单元格。 
2.初始化一个空的$n \times n$网格。 
3. 生成两个列表：一个包含从 1 到 的所有奇数$n^2$以及从 1 到所有偶数的一个$n^2$。 
4. 将奇数列表与偶数列表连接起来形成最终序列。 这可以确保连续的数字永远不会连续出现在网格中。 
5. 使用串联顺序从左到右逐行填充网格。 维护一个指针来跟踪下一个要放置的数字。 
6. 输出完成的网格。 

为什么它有效：关键的不变性是每对连续的整数被分成不同的集合，并且我们按顺序填充网格。 通过将所有奇数放在前面，差值为 1 的两个数字不能出现在水平或垂直相邻的单元格中。 这个简单的排序解决了所有的邻接约束$n \ge 3$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def not_adjacent_matrix(n):
    if n == 2:
        return -1
    if n == 1:
        return [[1]]
    
    grid = [[0] * n for _ in range(n)]
    odds = [i for i in range(1, n*n + 1) if i % 2 == 1]
    evens = [i for i in range(1, n*n + 1) if i % 2 == 0]
    sequence = odds + evens
    
    idx = 0
    for r in range(n):
        for c in range(n):
            grid[r][c] = sequence[idx]
            idx += 1
    return grid

t = int(input())
for _ in range(t):
    n = int(input())
    result = not_adjacent_matrix(n)
    if result == -1:
        print(-1)
    else:
        for row in result:
            print(' '.join(map(str, row)))
```该代码使用以下方式处理快速输入`sys.stdin.readline`。 这`not_adjacent_matrix`函数首先检查无法解决的问题$n = 2$和琐碎的$n = 1$案例。 它构造奇数和偶数列表并将它们连接起来，然后逐行填充网格。 使用简单索引`idx`确保我们按顺序放置数字而不会出现错误。 使用列表推导式可以保证正确性并避免差一错误。 

## 工作示例

 用于输入`n = 3`，奇数是`[1, 3, 5, 7, 9]`和偶数`[2, 4, 6, 8]`。 连接：`[1, 3, 5, 7, 9, 2, 4, 6, 8]`。 逐行填充会产生：

 | 遥控 | 0 | 1 | 2 |
 | --- | --- | --- | --- |
 | 0 | 1 | 3 | 5 |
 | 1 | 7 | 9 | 2 |
 | 2 | 4 | 6 | 8 |

 水平或垂直邻居没有相差 1。 

用于输入`n = 2`，我们立即返回`-1`因为 1-4 的任何位置都会有一对差值为 1 的相邻对。
