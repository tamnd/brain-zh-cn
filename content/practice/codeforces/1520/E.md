 ## 解决方案
 ## 问题理解

 我们有一个用字符串表示的一维板。 每个`'*'`是一只羊，每一个`'.'`是一个空单元格。 一次移动，一只羊可以向左或向右精确移动一个位置到相邻的空单元格中。 目标是让所有羊占据连续的位置，它们之间没有间隙，同时最小化单格移动的总数。 

重要的细节是羊是无法区分的。 我们不关心哪只羊最终处于哪个最终位置，只关心所有羊变得连续。 由于每次移动都会改变一只羊的位置，因此答案是所有羊移动的总距离。 

在所有测试用例的总和中，测试用例的长度可以长达一百万。 任何重复模拟运动或尝试每个可能的最终片段的算法都会太慢。 我们需要每个测试用例接近线性时间。 

一些边缘情况值得特别关注。 

如果根本没有羊：```
...
```答案是`0`。 羊已经“分组”了，因为没有羊。 粗心的实现可能会尝试访问中间羊并崩溃。 

如果只有一只羊：```
.*.
```答案是`0`。 一只羊已经是一个连续的群体。 

如果羊之间的距离很大：```
*...*...*
```最佳解决方案不是将所有事情都朝着一个终点移动。 将羊聚集到最左边的羊的幼稚策略会执行不必​​要的工作。 最佳聚集点由羊的中位数决定。 

另一个微妙的情况是当羊的数量是偶数时：```
*.*.*
```有两个中间羊候选人。 任一中间位置给出相同的最小总距离。 实现只需要一致地选择一个即可。 

## 方法

 最直接的想法是选择一个最终的连续块，并计算需要多少次移动才能将每只羊放入该块中。 假设有`k`羊。 如果块从位置开始`L`，那么羊必须占据的位置：```
L, L+1, L+2, ..., L+k-1
```我们可以从左到右匹配羊并计算总移动成本。 对每个可能的起始位置重复此操作会产生正确的答案。 

问题是最多有`n`可能的起始位置，并评估每个位置的成本`O(k)`。 在最坏的情况下，这会变成`O(n²)`，这是不可能的`n = 10^6`。 

为了改善这一点，我们需要了解真正重要的是什么。 

假设羊的位置是：```
p0, p1, p2, ..., p(k-1)
```如果它们最终占据了连续的单元格，那么羊`i`必须去：```
x + i
```对于某些起始位置`x`。 

总成本变为：```
|p0 - (x+0)| +
|p1 - (x+1)| +
...
|p(k-1) - (x+k-1)|
```通过定义重新排列表达式：```
qi = pi - i
```那么成本就变成：```
|q0 - x| + |q1 - x| + ... + |q(k-1) - x|
```现在问题已经转变为经典任务：选择一个值`x`最小化绝对偏差之和。 

绝对偏差之和最小是在中位数处实现的。 

这意味着我们不需要搜索所有可能的最终块。 我们只需要：

 1. 记录所有羊的位置。 
2. 构建转变后的价值观`qi = pi - i`。 
3. 选择转换后的中值。 
4. 计算到该中位数的距离总和。 

由于羊的位置是按升序收集的，变换后的序列也是非降序的，因此中位数立即可用。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 最坏情况 | O(n²) O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 扫描字符串并将所有羊的索引存储在数组中`pos`。 
2.如果有0只或1只羊，则输出`0`。 
3.让`k`是羊的数量。 
4. 构造变换后的序列：```
q[i] = pos[i] - i
```这消除了迫使羊进入连续位置的影响。 
5. 选择中值：```
median = q[k // 2]
```自从`q`已排序，这是有效的中位数。 
6. 计算：```
answer = Σ |q[i] - median|
```7. 输出答案。 

### 为什么它有效

 假设最后一个连续块从位置开始`x`。 然后是羊`i`必须占据位置`x+i`，因为改变羊的相对顺序只能增加运动量，而没有任何好处。 

成本是：```
Σ |pos[i] - (x+i)|
```重写：```
Σ |(pos[i]-i) - x|
```价值观`pos[i]-i`是固定的。 唯一剩下的变量是`x`。 绝对值的一个基本属性是到一组数字的距离之和在中位数处最小。 选择中间变换值会产生最小可能的移动成本，这正是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    answers = []

    for _ in range(t):
        n = int(input())
        s = input().strip()

        pos = []

        for i, ch in enumerate(s):
            if ch == '*':
                pos.append(i)

        k = len(pos)

        if k <= 1:
            answers.append("0")
            continue

        q = [pos[i] - i for i in range(k)]
        median = q[k // 2]

        ans = 0
        for x in q:
            ans += abs(x - median)

        answers.append(str(ans))

    sys.stdout.write("\n".join(answers))

if __name__ == "__main__":
    solve()
```第一个循环提取所有羊的位置。 只处理羊的位置比推理空单元要简单得多。 

转变`pos[i] - i`是关键的一步。 如果没有它，我们仍然必须考虑最终位置必须是连续的这一事实。 减法`i`消除该约束并将问题转变为纯粹的中值最小化问题。 

中位数直接取自转换后的数组。 不需要排序，因为原始羊位置是按升序排列的，减去升序索引可以保留非降序。 

答案可能会变得很大，因此我们将其累加到一个整数变量中。 Python 整数自动处理超出 32 位限制的值。

 ## 边缘情况

 ### 没有羊

 输入：```
1
3
...
```位置数组变为：```
[]
```算法立即检测到羊的数量最多为一只并返回`0`。 不尝试进行中值计算。 

### 正好一只羊

 输入：```
1
3
.*.
```职位：```
[1]
```同样，算法返回`0`。 一只羊已经形成一个连续的块。 

### 偶数只羊

 输入：```
1
4
*..*
```职位：```
[0, 3]
```转换后的值：```
[0, 2]
```实施选择：```
median = 2
```成本：```
|0-2| + |2-2| = 2
```选择另一个中值`0`也会产生成本`2`。 任一中位数都是最优的，因此选择`q[k//2]`是正确的。 

### 羊之间的距离很大

 输入：```
1
9
*...*...*
```职位：```
[0, 4, 8]
```转换后的值：```
[0, 3, 6]
```中位数：```
3
```成本：```
3 + 0 + 3 = 6
```该算法自然地将羊聚集在中间的羊周围。 这避免了迫使所有绵羊走向一个端点的常见错误，这将需要更多的移动。
