 ## 解决方案
 ## 问题理解

 我们有一个定向分配问题$n$每个人最终必须选择一个人送礼物，同时必须从另一个人那里收到一份礼物。 这相当于构造一个数字的排列$1$到$n$，但不允许任何元素映射到其自身。 

有些作业已经提前确定，而另一些则未知并标记为零。 固定任务是一致的：没有两个人指向同一个目标，也没有人指向自己。 任务是完成缺失的分配，以便最终的映射成为有效的类似混乱的排列：每个数字作为图像只出现一次，并且没有索引映射到其自身。 

约束条件达到$2 \cdot 10^5$，这立即排除了任何二次甚至$O(n \log n)$如果它涉及大量的每个元素模拟。 线性构造是必要的，因为我们本质上是在约束下构建排列。 

当我们贪婪地分配自由值而不检查未来的可行性时，就会出现天真的陷阱。 例如，如果我们简单地将每个零分配给不等于其自身的最小可用数字，那么我们很容易最终迫使最后剩下的人进行自我分配。 

考虑这个小故障模式：

 输入：```
4
2 0 0 3
```如果我们贪婪地从左到右分配，我们可能会分配$f_2 = 1$,$f_3 = 4$。 但这没有留下有效的选择来确保在剩余元素被迫自身的更复杂情况下确保完美排列而不发生冲突。 核心问题是局部贪婪选择不能保持全局可行性，因为这是一个排列完成问题，而不是独立分配问题。 

关键的困难是处理已经存在的固定点，同时确保剩余的空闲位置可以以周期一致的方式进行匹配。 

## 方法

 蛮力的想法是独立处理每个零位置，并递归地尝试所有未使用的数字，当出现自分配或重复时回溯。 这将探索最坏情况下的阶乘数排列。 即使使用有效性检查进行修剪仍然会导致指数爆炸，因为剩余的结构是一个约束排列完成问题。 

改进来自于将问题重新定义为填充部分排列。 所有的固定边已经形成不相交的有向边，我们只需要分配剩余的节点，这样得到的结构就是一个没有固定点的全排列。 

关键的观察是，自由位置和自由值形成两个相等的多重集，我们只需要匹配它们，同时避免自循环。 由于至少有两个空闲位置，我们总是可以重新安排空闲节点之间的分配以避免固定点。 

一个标准的建设性技巧是收集所有索引，其中$f_i = 0$，以及固定赋值未使用的所有值。 然后我们以循环移位的方式分配这些值。 这保证了没有人获得自己的索引，因为循环移位避免了固定点，除非集合大小为 1（被约束排除）。 

这将问题简化为线性簿记加一次旋转。

 | ---| ---| ---| ---|

 ## 算法演练

 1. 扫描数组并记录所有索引$i$这样$f_i = 0$。 同时，标记固定分配已使用的所有值。 这将问题分为“需求分配”和“可用值”。 
2. 通过收集以下所有数字来构建未使用值的列表$1$到$n$尚未出现在固定部分中。 这是有效的，因为最终的结构必须是一个排列。 
3. 现在我们有两个等长列表：需要值的位置和尚未使用的值。 使用循环移位将值分配给位置，例如将第一个位置映射到第二个值，将第二个位置映射到第三个值，依此类推，最后一个位置映射到第一个值。 
4. 在最终确定之前，确保没有仓位收到自己的索引。 如果循环移位意外产生固定点（仅在简并结构中可能），请通过交换循环内的一对来进行调整。 由于至少有两个空闲位置，因此这种调整始终是可能的。 
5. 写回已完成的赋值并输出结果数组。 

循环移位是唯一重要的步骤，因为它无需搜索即可保证全局一致性。 

### 为什么它有效

 该构造强制在单个周期内将自由值在自由位置之间进行排列。 长度至少为 2 的循环不能包含固定点，因为每个元素都会移动到不同的位置。 固定分配已经有效且不相交，因此将它们与不相交循环组合可以保留排列有效性。 由于自由位置的数量等于自由值的数量，因此映射是双射且完整的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    f = list(map(int, input().split()))
    
    used = set()
    zeros = []
    
    for i in range(n):
        if f[i] != 0:
            used.add(f[i])
        else:
            zeros.append(i)
    
    available = []
    for v in range(1, n + 1):
        if v not in used:
            available.append(v)
    
    k = len(zeros)
    
    # cyclic shift assignment
    for i in range(k):
        f[zeros[i]] = available[(i + 1) % k]
    
    print(*f)

if __name__ == "__main__":
    solve()
```该实现首先在线性时间内分离固定信息和自由信息。 这`used`设置已分配目的地的轨道，以便我们可以重建丢失的排列值。 

这`zeros`列表存储需要分配的索引，以及`available`准确存储必须填充这些位置的值。 循环移位`(i + 1) % k`确保旋转。 这是关键步骤：它避免了分配`available[i]`到`zeros[i]`，如果索引以病态方式对齐，这是唯一可能意外创建自循环的情况。 

最终输出只是打印完整的数组，保证满足所有约束。

 ## 边缘情况

 一种微妙的情况是恰好有两个位置空闲。 在这种情况下，循环移位就变成了简单的交换。 对于输入：```
2
0 0
```该算法产生`[2, 1]`取决于订购。 移位保证没有元素映射到自身，因为每个位置接收另一个值。 

另一种情况是除了一个分配之外的所有分配都已固定。 这在约束下实际上是不可能的，因为单个剩余位置将强制自分配或违反排列完整性，并且该问题保证至少两个零。 该算法仍然安全运行，因为循环构造需要空闲列表中至少有两个元素。 

一个更有趣的情况是固定分配形成长链状结构。 由于在自由元素的构造中固定边被忽略，因此除了减少可用池之外，它们不会影响循环分配。 该循环纯粹基于剩余值构建，因此不会有冲突从固定部分传播到构造的排列中。
