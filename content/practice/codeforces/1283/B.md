 ## 解决方案
 ## 问题理解

 我们正在向固定数量的孩子分发固定数量的相同糖果。 每个孩子必须收到非负整数数量的糖果，并且我们可以留下一些未使用的糖果。 仅当分配给子项的值紧密平衡时，该分布才被认为是有效的：分配的最大和最小计数最多相差 1，因此每个子项都会收到某个值$a$或下一个值$a+1$。 除此之外，价值更高$a+1$不会太常见，具体来说它最多可以出现在一半的孩子中，向下取整。 

我们的目标不是找到有效的分配本身，而是在尊重这些约束的同时最大化实际分发的糖果数量。 

输入数据量很大，最多可达$5 \cdot 10^4$测试用例和值$n$和$k$最多$10^9$。 任何尝试模拟分布或迭代每个测试用例可能分配的解决方案都会太慢。 正确的解决方案必须将每个测试用例简化为常数时间算术。 

一个天真的但诱人的想法是尝试确定有多少孩子得到$a+1$糖果并计算每个选择的可行性。 在边缘情况下，这种情况会崩溃，即对高价值儿童数量的限制与剩余糖果相互作用。 例如，与$k = 5$，尝试贪婪地最大化平均分布可能会导致分配太多$a+1$价值观，违反$\lfloor k/2 \rfloor$即使稍微不同的分割将允许更多的总糖果。 

另一种失败模式来自假设均匀分配所有糖果（如$n/k$) 总是最优的。 什么时候$k = 3$和$n = 8$，均匀分割​​给出$[2,2,2]$使用了 6 颗糖果，但更好的有效配置可以通过利用$a/a+1$结构仔细。 

## 方法

 蛮力方法是尝试所有可能的值$a$，并为每个决定有多少个孩子可以带$a+1$，然后检查使用的糖果总数是否达到$n$或更少，并选择最佳的有效总和。 对于每个$a$，我们将扫描分配较高的子项的可能计数，重新计算总数并验证约束。 这需要迭代值直至$n$，并且对于每个尝试$k$分裂，导致不可行$O(nk)$或更糟糕的过程。 

关键的观察是任何有效的分配都完全由两个整数决定：有多少孩子收到$a+1$，以及有多少人收到$a$。 一旦我们确定了高价值孩子的数量$x$，剩下的都是被迫的。 约束条件$x \le \lfloor k/2 \rfloor$直接限制了可以提升的孩子数量。 对于任何固定的$x$，我们可以将最大糖果计算为$$(k-x)\cdot a + x \cdot (a+1) = k\cdot a + x.$$因为我们想要最大化糖果总数，所以我们想要最大化两者$a$和$x$，但它们是通过总糖果不超过的要求耦合的$n$。 

这减少了选择问题$x$最优并推导$a$从剩余预算中。 结构变成线性的，并且最佳配置总是出现在由约束确定的边界处$x$。

 ## 算法演练

 我们将分布重写为两组：$k-x$孩子们收到$a$， 和$x$孩子们收到$a+1$， 在哪里$0 \le x \le \lfloor k/2 \rfloor$。 

1. 固定候选人编号$x$，接受的儿童数量$a+1$。 这立即决定了分配的结构，因为所有剩余的孩子都必须接收$a$。 
2. 表示所用糖果的总数$k \cdot a + x$。 这来自于$a$每个孩子的糖果，并为每个孩子添加一颗额外的糖果$x$选定的孩子。 
3.对于固定的$x$, 最大化$a$受$k \cdot a + x \le n$。 这给出了$a = \left\lfloor \frac{n-x}{k} \right\rfloor$。 
4. 代回计算所使用的糖果总数：$$\text{candies}(x) = k \cdot \left\lfloor \frac{n-x}{k} \right\rfloor + x.$$5. 自从$x$受到限制$0 \le x \le \lfloor k/2 \rfloor$，问题简化为仅检查该函数的边界行为。 增加$x$1 偶尔会减少基数除法项，因此我们测试两个极端$x = 0$和$x = \lfloor k/2 \rfloor$，并取最大值。 

只有端点很重要的原因是该函数是分段线性的，周期性下降的倍数$k$，并且在允许的范围内$x$，最大值必须出现在可行区间的边界之一处。 

### 为什么它有效

 分布仅取决于有多少孩子获得较大的值，并且每个可行的配置都折叠为单个整数参数$x$。 对于每个$x$, 最好的可能$a$是通过贪婪地为每个孩子填充尽可能多的完整值来唯一确定的$k$-尽可能多的糖果组。 自从增加$x$仅移动余项，同时逐步减小基商，没有内部值$x$可以同时严格控制两个端点。 这确保了仅评估边界情况$x$捕获最优解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        x = k // 2

        def calc(x):
            a = (n - x) // k
            return a * k + x

        ans = max(calc(0), calc(x))
        print(ans)

if __name__ == "__main__":
    solve()
```该代码对接收儿童数量的两个关键候选者进行了编码$a+1$。 辅助函数计算固定的最佳可实现总数$x$，首先确定最大可能的基值$a$，然后重建总数。 

只选择检查$x = 0$和$x = k//2$从约束结构可以看出，中间值不能同时改善基本分配和奖金分配。

 ## 边缘情况

 当$k = 1$，对的约束$a+1$变得无关紧要，因为只有一个孩子。 该算法评估$x = 0$并正确返回$n$， 因为$a = n$总计变为$n$。 

什么时候$n < k$，许多孩子的收入为零。 为了$n = 5, k = 10$，计算为$x = 0$给出$a = 0$，总计 0，同时$x = 5$仍然产生$a = 0$总共 5 个，匹配最佳行为，即最多一半的孩子可以获得一颗糖果。 

什么时候$k$相对于$n$，第二个候选人$x = k/2$确保通过允许的提升子项最大化剩余分配。 例如，$n = 6, k = 10$产量$x = 5$，总数为 5，这是在不超过 5 个孩子可以收到一颗糖果而其余孩子收到零颗糖果的约束下的最佳包装。
