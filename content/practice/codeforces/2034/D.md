 ## 解决方案
 ## 问题理解

 我们得到一系列石柱，每根石柱都有一个底座，顶部有少量铭文：0、1 或 2。我们可以将该序列视为整数数组`a[i]`表示第 i 列上的铭文数量。 目标是使用一系列移动将该数组重新排序为非递减顺序。 每次移动都允许我们从一列中取出一个铭文并将其转移到另一列，但前提是它们当前铭文计数之间的差值恰好为 1。换句话说，我们只能将铭文从多一个铭文的列移动到少一个铭文的列。 

输入由多个测试用例组成。 每个测试用例指定列数和铭文的初始配置。 输出必须描述最多的有效序列`n`移动（其中`n`是产生非递减序列的列数。 

问题的限制是显着的。 每列只能有 0、1 或 2 个铭文，这极大地限制了可能配置的数量。 所有测试用例的列总数最多可达 200,000，因此任何尝试模拟所有可能的传输或执行 O(n²) 操作的解决方案都会太慢。 每个测试用例需要一个线性或接近线性的解决方案。 

当存在多个 2 和 0 并且只有一个 1 在它们之间进行调解时，就会出现一种微妙的边缘情况。 例如，考虑`[2, 0, 2]`。 天真地以错误的顺序交换元素可能会导致序列未排序，因为我们无法直接在 2 和 0 之间移动。算法必须始终遵循`|difference| = 1`限制。 

## 方法

 暴力方法很简单：迭代数组，找到左列大于右列且差值为 1 的任何一对列，执行移动，然后重复，直到数组排序完毕。 这种方法原则上是正确的，但在最坏的情况下可能需要 O(n²) 次操作，例如当序列为`[2, 0, 2, 0, 2, ...]`。 和`n`达到 200,000 时，这在计算上变得不可行。 

关键的观察结果是，列高只有三个可能的值：0、1 和 2。因此，对数组进行排序就简化为计算每个值的出现次数并按排序顺序重建数组。 移动本身可以系统地确定：出现在 1 之前的每个 2 都可以将一个铭文转移到 1，而出现在 0 之前的每个 1 可以将一个铭文转移到 0。由于总是至少有一列恰好有一个铭文，所以这个 1 充当了一个枢轴来调解 0 和 2 之间的转移。 

这一观察结果使我们能够将问题简化为简单的线性扫描。 我们记录所有 0、1 和 2 的索引。 然后，我们模拟按顺序将 1 从 2 移动到 0，始终选择最左边的候选列以保证顺序不降。 每次移动都涉及两个索引，其值之差恰好为 1，因此所有移动都是有效的。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 计数+贪婪转移| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化三个列表：`zeros`,`ones`， 和`twos`，分别保存具有 0、1 和 2 个铭文的列的索引。 
2. 迭代数组`a`一次。 对于每一列，根据其值将其索引附加到适当的列表。 这为我们提供了按当前高度的完整索引划分。 
3.初始化一个空列表`moves`来存储操作。 
4. 将 1 秒从 2 秒转移到 1 秒，以在高柱和中柱之间进行调解。 对于每个索引`twos`即在索引之前`ones`在数组中，执行从 2 到 1 的移动，并将其记录在`moves`。 更新`a`相应地排列。 
5. 将 1 从 1 转移到 0，以在中列和低列之间进行调解。 对于每个索引`ones`即在索引之前`zeros`，执行从 1 到 0 的移动并将其记录在`moves`。 更新`a`相应地排列。 
6. 完成所有传输后，数组`a`将按非降序排序。 输出移动次数，后跟移动操作列表。 

工作原理：在每一步中，该算法仅在相差 1 的列之间传输铭文。通过先处理 2 到 1，然后再处理 1 到 0，我们确保所有 2 都向右移动，所有 0 都向左移动。 由于列总数很小并且值有界，这保证了最终序列已排序并且没有移动违反差异约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        zeros, ones, twos = [], [], []
        for i, val in enumerate(a):
            if val == 0:
                zeros.append(i)
            elif val == 1:
                ones.append(i)
            else:
                twos.append(i)
        
        moves = []
        
        z_ptr, o_ptr, t_ptr = 0, 0, 0
        
        while t_ptr < len(twos) and o_ptr < len(ones):
            if twos[t_ptr] < ones[o_ptr]:
                moves.append((twos[t_ptr] + 1, ones[o_ptr] + 1))
                t_ptr += 1
                o_ptr += 1
            else:
                o_ptr += 1
        
        o_ptr, z_ptr = 0, 0
        while o_ptr < len(ones) and z_ptr < len(zeros):
            if ones[o_ptr] < zeros[z_ptr]:
                moves.append((ones[o_ptr] + 1, zeros[z_ptr] + 1))
                o_ptr += 1
                z_ptr += 1
            else:
                z_ptr += 1
        
        print(len(moves))
        for u, v in moves:
            print(u, v)

if __name__ == "__main__":
    solve()
```该代码首先按索引的值对索引进行分区。 然后，它使用两指针技术来模拟从较高值到较低值的有效传输，同时保持所需的差值恰好为 1。`+1`将从零开始的 Python 索引转换为从一开始的问题索引。 仔细排序 while 循环可确保不会尝试无效的移动。
