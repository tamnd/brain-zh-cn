 ## 解决方案
 ## 问题理解

 该问题将 Rakhsh 的身体建模为一条线$n$点，其中每个点要么较弱（$0$）或强（$1$）。 罗斯坦希望确保在任何连续的时间间隔内$m$斑点，至少有一个斑点是强的。 他可以执行一项手术，蒂玛，立即加强任何连续的$k$点，将它们全部变成$1$s。 任务是确定 Timar 操作的最小数量，以保证没有间隔$m$连续的点仍然完全疲软。 

输入给出多个测试用例，每个测试用例指定字符串长度$n$, 最小安全区间长度$m$, Timar 段长度$k$，以及二进制字符串$s$。 每个测试用例的输出是一个整数，指示所需的最小操作数。 

约束意味着$n$可以达到$2 \cdot 10^5$每个测试用例，所有测试用例的总和$n$跨测试用例也仅限于$2 \cdot 10^5$。 这排除了复杂度高于$O(n)$每个测试用例。 反复检查所有内容的幼稚方法$m$-长度间隔会导致$O(nm)$每个测试用例，这太慢了。 边缘情况包括已经满足条件的字符串、所有的字符串$0$s，以及情况$m>k$，这可能需要仔细放置操作以覆盖所有弱间隔而没有间隙。 

## 方法

 蛮力方法将扫描每个$m$-length 窗口，如果它完全是$0$s，在该窗口中的某个位置应用 Timar 操作。 这在原则上是正确的，但是天真的扫描和应用操作会导致$O(nm/k)$复杂度太高，当$n$方法$2 \cdot 10^5$。 

关键的观察是，问题可以简化为处理连续的片段$0$s。 对于长度为零的每个连续块$L$，必须应用足够的 Timar 操作来完全覆盖它，确保每个$m$- 该块中的长度间隔至少包含一个$1$。 最少的操作次数是$\lceil L / k \rceil$，并且始终从最左边的弱点开始蒂马尔并向右移动$k$每次，我们都保证最小的覆盖范围。 这将问题减少到$O(n)$每个测试用例，因为我们只需要迭代字符串一次并计算连续零的长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$|$O(1)$| 太慢了|
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1.初始化一个计数器`ops = 0`存储使用的 Timar 操作数。 
2. 遍历字符串`s`有索引`i`从0开始。 
3.如果`s[i]`是`1`, 增量`i`并继续，因为这个位置已经很强大了。 
4. 如果`s[i]`是`0`，新的弱点开始了。 初始化`length = 0`。 
5. 虽然`i < n`和`s[i]`是`0`, 两者都增加`length`和`i`。 这捕获了完整的连续零段。 
6. 计算该段所需的 Timar 操作数：`ceil(length / k)`，可以实现为`(length + k - 1) // k`。 
7.将此号码添加到`ops`。 
8. 重复直到字符串末尾。 
9. 输出`ops`作为当前测试用例的最小操作数。 

工作原理：该算法保持了不变性，即所有先前处理的弱段都被 Timar 操作完全覆盖，并且每个操作都完全覆盖$k$从线段左侧开始的点。 通过按顺序处理段，计数不会重叠，并且每个段$m$-长度为零的间隔保证至少包含一个$1$应用操作后。 这保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        s = input().strip()
        ops = 0
        i = 0
        while i < n:
            if s[i] == '1':
                i += 1
            else:
                length = 0
                while i < n and s[i] == '0':
                    length += 1
                    i += 1
                ops += (length + k - 1) // k
        print(ops)

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它读取`n`,`m`,`k`和二进制字符串`s`。 指数`i`在字符串中按顺序移动，跳过强点。 当遇到零时，它会计算连续的弱段并计算使用整数除法实现上限所需的最小 Timar 操作数。 为每个测试用例打印结果。 使用`strip()`确保尾随换行符不会干扰处理。

 ## 边缘情况

 如果字符串已经安全，算法会跳过所有 1 并报告 0 操作。 对于长度超过的连续零`k`，它正确地将操作数计算为`(length + k - 1) // k`。 对于散布着 1 的单个零，每个长度为 1 的零段都会导致一次操作，从而确认该算法正确处理稀疏弱点。 从左到右的贪婪覆盖确保没有间隔`m`连续的零仍然未被覆盖。
