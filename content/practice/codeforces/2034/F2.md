 ## 解决方案
 ## 问题理解

 我们被要求计算经过乘法奖励的随机过程后宝石收藏的预期总价值。 海亚姆从一个箱子开始，里面装有`n`红红宝石，每颗价值`2`， 和`m`蓝色蓝宝石，每颗价值`1`。 每回合，他都会从箱子中均匀随机抽取一颗宝石，并将其移至挎包中。 宝箱中的某些宝石数量会触发一项皇家法令，使背包中当前所有宝石的价值翻倍。 该过程一直持续到所有宝石都被抽取为止，目标是计算预期的最终值模`998,244,353`。 

输入给出多个测试用例，每个测试用例都有初始计数`n`和`m`和一组`k`滚动条，每个滚动条指定一个条件`(r_i, b_i)`剩余的宝石会触发加倍。 限制条件允许`n + m`最多`2*10^5`所有测试用例的总和`k`最多`5000`。 这表明任何每步复杂度与`n*m`是可行的，但任何平方`n + m`每个测试用例可能太慢。 

当不存在卷轴时会出现边缘情况。 例如，如果`n=3, m=4, k=0`，期望值总是`3*2 + 4*1 = 10`。 另一个微妙的情况是当第一个绘制的宝石上触发卷轴时。 朴素的线性模拟可能会忽略法令的概率权重并产生不正确的期望。 

## 方法

 强力解决方案将模拟每个可能的抽签顺序并跟踪乘法效应。 这是正确的，因为期望是所有序列的线性组合，但对于大的情况则失败`n + m`因为序列的数量呈阶乘增长。 具体来说，序列数为`(n + m)! / (n! m!)`，这超过了`10^100`对于适度的输入大小。 

关键的见解是，挎包的预期价值与宝石呈线性关系。 我们可以独立地推理每颗宝石：对于红宝石，它的基值是 2，我们将它在挎包中经历的每一次法令乘以 2。 同样，蓝色蓝宝石的基值为 1。我们不是模拟每个序列，而是计算每个潜在宝箱状态在抽取宝石时发生的概率以及是否触发法令。 通过对红色和蓝色宝石的剩余计数使用动态规划并计算预期乘法因子，我们将问题从阶乘时间减少到多项式时间`n*m`和线性`k`。 此外，我们可以利用模逆进行概率计算，以避免浮点运算。 

最佳解决方案依赖于定义`dp[r][b]`作为背包中宝石的预期乘数，当`r`红色和`b`蓝色仍然存在。 通过从小到大的剩余计数迭代并在精确的状态上应用加倍法令，我们可以有效地传播期望。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O((n+m)!) | O(n+m) | 太慢了|
 | 剩余计数的动态规划 | O(n*m + k) | O(n*m) | 已接受 |

 ## 算法演练

 1.初始化一个集合或者字典`scrolls`快速检查给定的剩余状态`(r, b)`触发法令。 这允许在 DP 期间进行恒定时间查找。 
2. 创建二维数组`dp`尺寸的`(n+1) x (m+1)`存储绘制宝石的预期乘数`r`红色和`b`蓝色留在胸口。 放`dp[0][0] = 1`作为基本情况，因为没有宝石剩余，并且不可能进一步加倍。 
3. 迭代`r`从 0 到`n`和`b`从 0 到`m`。 对于每个`dp[r][b]`，计算再抽取一颗宝石时的预期乘数：

 - 如果`r > 0`，抽出红宝石的概率是`r / (r + b)`。 添加`dp[r-1][b] * prob_red`到`dp[r][b]`。 
- 如果`b > 0`，绘制蓝宝石的概率为`b / (r + b)`。 添加`dp[r][b-1] * prob_blue`到`dp[r][b]`。 
4. 如果当前状态`(r, b)`是在`scrolls`, 乘以`dp[r][b]`乘以 2 来说明该法令。 每一步都应用模算术。 
5. 填写完毕后`dp`表，通过将所有宝石的基值乘以总和来计算期望值`dp[n][m]`。 对于红宝石来说，这有助于`2 * n * dp[n][m]`，对于蓝色蓝宝石`1 * m * dp[n][m]`。 
6. 要处理模算术中的概率，请使用模逆来表示分数。 如果`p/q`是一个概率，计算`p * q^{-1} % MOD`。 

这里的不变量是`dp[r][b]`始终代表宝箱中剩余的任何宝石的预期乘法因子`r`红色和`b`蓝色宝石。 通过将值从宝石较少的状态传播到宝石较多的状态，我们确保每个宝石对期望的贡献考虑到影响它的所有可能的法令。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        scrolls = set()
        for _ in range(k):
            r, b = map(int, input().split())
            scrolls.add((r, b))
        
        dp = [[0]*(m+1) for _ in range(n+1)]
        dp[0][0] = 1

        for r in range(n+1):
            for b in range(m+1):
                if r == 0 and b == 0:
                    continue
                total = r + b
                val = 0
                if r > 0:
                    val += dp[r-1][b] * r * modinv(total)
                if b > 0:
                    val += dp[r][b-1] * b * modinv(total)
                val %= MOD
                if (r, b) in scrolls:
                    val = (val * 2) % MOD
                dp[r][b] = val

        result = (2 * n * dp[n][m] + 1 * m * dp[n][m]) % MOD
        print(result)

solve()
```这`modinv`函数处理模除法，因为概率是分数。`dp[r][b]`存储宝石的预期乘数`r`红色和`b`蓝色仍然存在。 当状态与滚动匹配时，立即应用加倍。 最后，所有宝石的总和将基础值乘以预期乘数。 

## 工作示例

 **示例1**：`n=1, m=1, k=1`, 滚动`(1,0)`。 

| r | 乙| dp[r][b] | dp[r][b] | 说明|
 | --- | --- | --- | --- |
 | 0 | 0 | 1 | 基本情况|
 | 1 | 0 | 2 | 只剩下红色，滚动触发加倍 |
 | 0 | 1 | 1 | 只剩下蓝色，没有卷轴|
 | 1 | 1 | 3/2 | 概率：红色 1/2 -> 2，蓝色 1/2 -> 1 |

 最终期望值：红色贡献`2*dp[1][1] = 2*3/2 = 3`， 蓝色的`1*dp[1][1] = 3/2`。 和`4.5`, 取模`998244353`是`499122180`。 

**示例2**：`n=3, m=4, k=0`。 

由于不存在卷轴，因此每颗宝石都保持其基本价值。 期望值为`3*2 + 4*1 = 10`。
