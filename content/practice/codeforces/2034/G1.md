 ## 解决方案
 ## 问题理解

 我们在实线上得到一组闭区间。 每个区间代表一个战士的活跃时间。 我们必须为每个间隔分配一种颜色。 

在至少一个间隔覆盖的每个实时时刻，我们都会查看包含该时刻的所有间隔。 在这些活动区间中，一定存在某种颜色只出现一次。 一种颜色可以在全局范围内被多个间隔使用，但在任何覆盖时间，我们都需要在活动间隔中至少有一种唯一表示的颜色。 

任务是找到尽可能少的颜色数并构建一种有效的颜色。 

简单版本在整条实线上使用重叠，而不仅仅是在整数坐标处。 由于区间是闭区间，因此两个区间如$[1,2]$和$[2,3]$单点重叠$2$。 

所有测试用例的间隔总数最多为$2 \cdot 10^5$。 任何检查所有间隔对的解决方案都已经需要$O(n^2)$工作，大约会达到$4 \cdot 10^{10}$最坏情况下的操作。 甚至$O(n^2)$记忆是不可能的。 我们周围需要一些东西$O(n \log n)$。 

这个问题最危险的部分是了解线上每个点必须保持什么。 

考虑：```
[1,4]
[2,5]
[3,6]
```时$3.5$，所有三个间隔均处于活动状态。 如果所有三个都收到相同的颜色，则没有颜色恰好出现一次，因此着色无效。 

另一个微妙的情况是端点相交：```
[1,2]
[2,3]
```间隔在时间上重叠$2$。 给两个间隔相同的颜色会失败，因为有时$2$该颜色出现两次并且不存在其他颜色。 

第三个陷阱是假设只有最大重叠很重要。 例如：```
[1,5]
[2,6]
[3,7]
[4,7]
[6,7]
```最大重叠尺寸为$4$，但答案是$3$， 不是$4$。 该条件涉及活动间隔之间的颜色多样性，而不是使每个活动间隔接收不同的颜色。 

理解有效着色的结构是解决问题的关键。 

## 方法

 蛮力观点是考虑线上的每个关键点。 收集所有间隔端点后，活动间隔集仅在经过端点时发生变化。 人们可以检查连续端点之间的每个区域并强制执行那里的条件。 

假设我们已经固定了颜色。 对于每个区域，我们将计算每种颜色存在多少个活动间隔，并验证某些颜色是否恰好出现一次。 即使检查单一颜色也会变得昂贵。 以这种方式构建最佳着色是完全不可行的。 

突破来自于查看重叠图。 

创建一个顶点为区间的图。 如果相应的区间相交，则两个顶点相邻。 由于我们正在处理一条线上的间隔，因此这是一个间隔图。 

现在关注某个点$t$。 所有间隔包含$t$在重叠图中形成一个团，因为它们中的每一对相交于$t$。 

假设我们为重叠图正确着色。 然后在每个派系内部，所有顶点都有不同的颜色。 特别是，在覆盖任意点的区间中$t$，每个活动颜色恰好出现一次。 所需条件自动满足。 

这立即给出了有效的着色。 

下一个问题是我们是否真的需要适当的着色。 令人惊讶的是，该问题所需的最小颜色数正是区间图的色数。 

为什么？ 

取任意一组覆盖同一点的区间$t$。 让它有$m$这样的间隔。 

时$t$，其中的每个颜色类别$m$间隔最多只能包含一个间隔。 如果某种颜色出现两次，那么该颜色就不是唯一的。 如果每种颜色都出现$0$或者至少$2$有时，不会有独特的颜色。 因此，通过公共点的间隔必须都具有不同的颜色。 

因此，每个大小的派系$m$至少需要$m$颜色。 答案至少是最大派系规模。 

对于区间图，经典定理指出：$$\chi = \omega$$在哪里$\chi$是色数并且$\omega$是最大团大小。 

由于最大团大小等于同时活动区间的最大数量，因此问题简化为对区间图进行最佳着色。 

区间图允许非常简单的贪婪着色。 

按左端点对间隔进行排序。 从左到右处理它们。 每当一个间隔开始时，重复使用前一个间隔已经结束的最小可用颜色。 如果没有可用的颜色，请创建新颜色。 

这种贪心算法恰好使用最大重叠计数，这对于区间图来说是最佳的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n²) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将每个区间及其原始索引存储在一起。 
2. 通过增加左端点对间隔进行排序。 
3. 维护当前活动颜色的优先级队列。 各入口店`(right_endpoint, color)`。 
4.维护另一个包含可以重用的自由颜色的优先级队列。 
5. 处理新区间之前$[l,r]$，重复删除右端点严格小于的活动区间`l`。 

因为区间是闭区间，所以区间结束于`l`仍然与新的区间重叠`l`。 这些颜色还不能重复使用。 
6. 每个移除的区间都会释放其颜色。 将该颜色插入自由颜色堆中。 
7. 如果存在自由颜色，则取最小的颜色并将其分配给当前间隔。 
8. 否则创建新颜色。 将总颜色数增加一并指定新颜色。 
9. 插入`(r, assigned_color)`进入活动堆。 
10. 将分配的颜色存储在间隔的原始位置。 
11、处理完所有区间后，输出颜色数量和构造的着色。 

### 为什么它有效

 在每一步中，活动堆恰好包含与当前位置重叠的那些间隔。 仅在其上一个间隔严格在下一个间隔开始之前结束后，颜色才会被重用，这意味着两个间隔是不相交的。 

因此，两个重叠的间隔永远不会收到相同的颜色。 着色是区间图的适当着色。 

对于任意点$t$，所有区间包含$t$拉帮结派。 由于着色是正确的，因此该团中的每个区间都有不同的颜色。 每个活动颜色恰好出现一次，因此满足所需的条件。 

贪婪算法使用的颜色数量等于同时活动间隔的最大数量。 该数量是区间图的团数，它是任何有效解决方案的下界。 由于该算法达到了该下限，因此着色是最佳的。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())

        intervals = []
        for i in range(n):
            l, r = map(int, input().split())
            intervals.append((l, r, i))

        intervals.sort()

        active = []      # (right, color)
        free_colors = [] # available colors

        colors = [0] * n
        color_cnt = 0

        for l, r, idx in intervals:
            while active and active[0][0] < l:
                _, c = heapq.heappop(active)
                heapq.heappush(free_colors, c)

            if free_colors:
                c = heapq.heappop(free_colors)
            else:
                color_cnt += 1
                c = color_cnt

            colors[idx] = c
            heapq.heappush(active, (r, c))

        out.append(str(color_cnt))
        out.append(" ".join(map(str, colors)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```间隔按起点排序，因为这是新重叠出现的自然顺序。 

活动堆跟踪当前由可能仍与未来间隔重叠的间隔占用的颜色。 条件`active[0][0] < l`至关重要。 间隔是闭合的，因此间隔结束于`l`与新区间恰好相交于一点。 重复使用该颜色会将相同的颜色分配给重叠的间隔并破坏正确性。 

自由颜色堆存储可用的颜色。 为了保证正确性，重复使用最小的可用颜色并不是必需的，但它会产生紧凑的着色并且易于实现。 

每个间隔恰好进入和离开堆一次，给出$O(n \log n)$复杂。

 ## 边缘情况

 ### 端点相交

 输入：```
1
2
1 2
2 3
```当处理第二个区间时，第一个区间的右端点等于`2`。 由于释放条件为`right < left`，第一个颜色没有被释放。 

该算法创建第二种颜色：```
2
1 2
```这是正确的，因为间隔在点处重叠`2`。 

### 完全不相交的区间

 输入：```
1
3
1 2
4 5
7 8
```在每个新的间隔开始之前，前一个间隔已经结束。 它的颜色被释放并重复使用。 

该算法产生：```
1
1 1 1
```任何地方都不存在重叠，因此一种颜色是最佳的。 

### 多个区间共享一个点

 输入：```
1
4
1 5
2 5
3 5
5 7
```所有四个区间都包含点`5`。 他们每个人都必须有一种独特的颜色。 

该算法使所有四种颜色保持活动状态，因为没有任何间隔以`5`可以在处理前释放`[5,7]`。 

输出使用四种颜色，匹配派系大小和最小可能答案。 

### 嵌套间隔

 输入：```
1
4
1 10
2 9
3 8
4 7
```每个间隔与其他间隔相交。 重叠图是一个大小为四的派系。 

处理过程中任何颜色都不会变得空闲，因此该算法创建四种颜色：```
4
1 2 3 4
```任何少于四种颜色的解决方案都会强制两个重叠间隔共享一种颜色，从而违反了所有四个间隔都处于活动状态的点的要求。
