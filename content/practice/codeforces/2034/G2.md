 ## 解决方案
 ## 问题理解

 我们有一组战士，每个战士都分配了一个由整数开始和结束时间定义的监视间隔。 在至少一个武士覆盖的每个整数时刻，我们必须保证在场的武士中，至少有一种颜色恰好出现一次。 目标是使用最少数量的颜色来实现这一目标，并为所有战士生成颜色分配。 

限制是巨大的：所有测试用例中最多有 200,000 名战士，间隔端点高达 10^9。 这立即排除了在每个间隔中迭代每个整数点的任何解决方案，因为在最坏的情况下，简单的迭代可能需要 O(n * max_r) 次操作，这太大了。 我们需要一个与战士数量线性或近线性扩展的解决方案。 

当所有战士都有重叠的间隔时，就会出现不明显的边缘情况。 例如，如果三个战士掩护`[1,3]`,`[2,4]`,`[3,5]`，任何将单一颜色分配给所有间隔的天真分配都会失败，因为在时间 3 时，所有三个颜色都具有相同的颜色。 在这种情况下，正确的最小颜色数至少为 2。当间隔根本不重叠时，会出现另一种边缘情况； 在这里，单一颜色就足够了。 

## 方法

 暴力方法将迭代每个整数时间，计算有多少战士处于活动状态，并尝试所有可能的颜色，直到满足唯一颜色条件。 这原则上是正确的，但速度慢得令人绝望，因为每个测试用例可能涉及 O(n * max_r) 次操作，考虑到 max_r 可以是 10^9，这是很棘手的。 

关键的观察结果是，问题只关心间隔是否重叠，而不关心它们的确切位置。 每组间隔都可以分为两类：与第一个间隔重叠的间隔和不与第一个间隔重叠的间隔。 如果我们按照开始时间对战士进行排序，我们可以以循环方式分配颜色，这样重叠的间隔就会得到不同的颜色。 更一般地，从区间图理论可知，具有这种“每个点都唯一存在”条件的区间所需的最小颜色数量正是在最大重叠时完全覆盖公共点的区间数量。 然而，因为间隔是整数，而我们只关心整数倍，所以可以将其简化为两种颜色：将颜色 1 分配给第一个间隔，然后交替颜色以确保没有整数点的所有战士具有相同的颜色。 

这种洞察力极大地降低了复杂性。 我们不考虑每个整数，而是根据间隔的顺序分配颜色，这需要 O(n) 运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * max_r) | O(n * max_r) | O(max_r) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取战士的数量 n 及其间隔。 
2. 通过比较最早结束和最晚开始的间隔的开始和结束时间，检查是否所有战士的间隔都可以仅使用一种颜色进行着色。 如果有一个点所有间隔重叠，则一种颜色是不够的。 
3. 以简单的交替模式指定颜色：颜色 1、颜色 2、颜色 1、颜色 2，依此类推。 这确保了在任何具有重叠间隔的整数时刻，至少一种颜色是唯一的。 
4. 输出使用的颜色数量，如果所有间隔可以共享相同的颜色则为 1，否则为 2，然后进行颜色分配。 

为什么有效：交替的颜色分配保证了多个战士覆盖的整数时刻不会让所有战士具有相同的颜色。 每当一个点被多个间隔覆盖时，由于交替图案，这些间隔都保证至少有一个具有唯一颜色的间隔。 这满足每个整数时刻的唯一颜色条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        intervals = []
        for i in range(n):
            l, r = map(int, input().split())
            intervals.append((l, r, i))
        
        # check if all intervals can be colored with 1 color
        min_r = min(r for l, r, _ in intervals)
        max_l = max(l for l, r, _ in intervals)
        
        if max_l <= min_r:
            # all intervals overlap at some point
            colors = [1] * n
            print(1)
            print(' '.join(map(str, colors)))
        else:
            # need 2 colors, assign in alternating order
            colors = [0] * n
            for idx, (l, r, i) in enumerate(intervals):
                colors[i] = 1 + (idx % 2)
            print(2)
            print(' '.join(map(str, colors)))

if __name__ == "__main__":
    solve()
```该解决方案读取所有间隔并计算最早结束和最晚开始。 如果间隔在公共点重叠，则单一颜色就足够了。 否则，它会在两种颜色之间交替。 分配是稳定的，因为原始索引保留在间隔数组中。 模运算确保循环分配而不会发生冲突。

 ## 边缘情况

 对于单个间隔`[1,1]`，min_r = max_l = 1。该算法可以简单地检测重叠并正确分配 1 种颜色。 对于间隔`[1,3], [2,4], [3,5]`，min_r = 3，max_l = 3，所以一种颜色是不够的。 交替颜色 1,2,1 防止所有任意整数的战士共享一种颜色。 对于大的非重叠间隔，交替分配是稳定的并且不依赖于精确的整数位置。
