 ## 解决方案
 ## 问题理解

 我们正在 k 维整数格中工作。 状态是具有 k 个整数坐标的点，每次移动恰好将一个坐标改变 +1 或 -1。 在 2n 次移动之后，我们想要计算有多少种不同的移动序列使我们回到原点。 

思考这个问题的一个有用方法是，每次移动都会选择 k 个轴之一，然后选择沿该轴的方向。 如果最后每个坐标的总位移为零，则路径有效，这意味着每个轴接收的 +1 移动与 -1 移动一样多。 

输入给出多个独立的查询。 每个查询询问返回原点的 k 维长度为 2n 的行走次数，以 998244353 为模。 

这些约束迫使我们远离任何位置上的状态空间动态规划。 可能位置的数量在每个坐标中无限增长，甚至限制到 i 步后可到达的位置，每层产生 θ(i^k) 个状态。 当 n 高达 10^5 且 t 高达 200000 时，任何在 n 上迭代每个测试用例或在 k 维状态上维护 DP 的方法都太慢。 

当独立进行维度推理时，会出现一个微妙的问题。 一种简单的方法可能会将每个坐标视为长度为 2n 的独立一维行走并乘以结果，但这忽略了每一步仅选择一个坐标。 维度之间的耦合是核心困难。 

## 方法

 从蛮力观点开始：在 2n 个步骤的每一步中，我们选择 k 个坐标之一，然后决定是递增还是递减它。 这给出了 (2k)^{2n} 总序列。 我们将过滤那些以原点结尾的内容。 

这种蛮力是正确的，但完全不可行。 即使 n = 20 也已经产生了天文数字般的大分支。 

关键的结构观察是问题分为两层选择。 

首先，我们决定每个坐标在所有步骤中使用多少次。 假设坐标 i 被选择了 ti 次，总和 ti = 2n。 只有所有 ti 为偶数的序列才能返回原点，因为每个轴的行为类似于一维行走，并且必须平衡 + 和 − 移动。 

其次，一旦我们确定了 ti ，坐标 i 的有效符号分配数量就是以零结束的长度 ti 1D 平衡行走的数量，即二项式系数 C(ti, ti/2)。 

最后，我们必须考虑跨坐标的步骤的交错。 如果坐标 1 使用 t1 次，坐标 2 使用 t2 次，依此类推，排列这些标记步骤的方式数就是多项式系数：

 (2n)! / (t1!t2!...tk!)

 所以完整的答案变成了 2n 到 k 个偶数部分的所有组合的总和：

 对 ti 偶数求和，总和 ti = 2n：

 (2n)! / (t1!...tk!) × ∏ C(ti, ti/2)

 如果直接计算，该表达式仍然以 k 或 n 为指数。 下一步是认识生成函数的简化。 

对于每个坐标，定义其贡献系列：

 f(x) = 对偶数 t 求和：C(t, t/2) x^t / t！ 

这对一维行走贡献进行编码。 多项式结构意味着总答案是：

 (2n)! × [x^{2n}] (f(x))^k

 现在我们使用经典恒等式：

 sum_{m ≥ 0} C(2m, m) x^{2m} / (2m)! = I_0(2√x) 型形式，但更重要的是，组合地我们可以直接以系数形式重写，从而获得干净的卷积解释。 经过代数简化后，系数提取简化为：

 答案 = n 的分区之和：

 (2n)! / ( (2a1)!...(2ak)! ) × ∏ C(2ai, ai)

 这看起来仍然很重，但有一个关键的简化：C(2ai, ai) = (2ai)！ / (ai!)^2，因此取消会将所有内容折叠为：

 答案=（2n）！ × a1+...+ak=n 的和 1 / (a1!^2 ... ak!^2)

现在我们识别序列 b[a] = 1/(a!)^2 的 k 倍卷积。 这可以通过 O(nk) 中的多项式求幂来计算，或者根据 k 机制更快地计算。 由于在最难的子任务中 k ≤ 100，我们将 k 视为小参数并根据总和 n 计算 DP。 

令 dp[j] 为选择处理坐标的值，使得总的半步和为 j。 每个坐标都与数组 b 进行卷积。 重复 k 次，就变成了同一个多项式的 k 次方。 

我们使用重复卷积求幂来计算 dp = b^k，并通过 O(kn) 中的 DP 进行优化，因为卷积具有较小的 k，由于模数较大且查询较多，因此不适合 FFT。 

最后乘以(2n)！。

 ## 算法演练

 我们根据每个坐标消耗多少成对的上下移动来重新表述该问题。 每个坐标贡献偶数步，因此我们以对为单位进行工作。 

1. 将问题从 2n 个步骤转换为 n 对。 每个坐标i贡献ai对，所有ai的总和为n。 这是自然的减少，因为有效的返回需要配对 +1 和 -1 沿每个轴移动。 
2. 预先计算高达 2n 的阶乘和逆阶乘。 这允许二项式系数和多项式权重的恒定时间计算。 
3. 构建数组 b，其中 b[a] = 1 / (a!)^2。 这表示精确分配一对 +/- 步长的坐标的贡献。 
4. 计算 b 与其自身的 k 次卷积，并在 n 处截断。 处理完k个坐标后，dp[j]表示在k个坐标中分配j对的总权重。 这是有效的，因为每个坐标独立地贡献了它消耗的对数量的分布。 
5. 将 dp[n] 乘以 (2n)！ 恢复标准化过程中被分解的多项式和符号分配因子。 

### 为什么它有效

 关键的不变量是，处理 i 坐标后，dp[j] 等于 j 个总步长对对这些 i 坐标的所有分配的总和，其中每个分配贡献 1/(ai!)^2 坐标的乘积。 添加新坐标完全对应于与 b 进行卷积，因为在旧坐标和新坐标之间分配 j 对会将总和分成独立的选择。 这确保了在 k 次迭代之后，dp 准确捕获对计数的所有有效分布，并且最终的乘法恢复标记游走的准确组合计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

MAXN = 200000

fact = [1] * (2 * MAXN + 1)
invfact = [1] * (2 * MAXN + 1)

for i in range(1, 2 * MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[2 * MAXN] = modinv(fact[2 * MAXN])
for i in range(2 * MAXN, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def solve_case(n, k):
    # b[a] = 1 / (a!^2)
    b = [0] * (n + 1)
    for i in range(n + 1):
        b[i] = invfact[i] * invfact[i] % MOD

    dp = [0] * (n + 1)
    dp[0] = 1

    for _ in range(k):
        new_dp = [0] * (n + 1)
        for i in range(n + 1):
            if dp[i] == 0:
                continue
            for j in range(n - i + 1):
                new_dp[i + j] = (new_dp[i + j] + dp[i] * b[j]) % MOD
        dp = new_dp

    return fact[2 * n] * dp[n] % MOD

def main():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        print(solve_case(n, k))

if __name__ == "__main__":
    main()
```该解决方案首先构建高达 2n 的阶乘和逆阶乘，以便无需重新计算即可计算二项式相关量。 数组 b 以标准化形式对每个坐标的贡献进行编码，其中阶乘项被分解。 

DP 阵列跟踪已在处理的坐标之间分配了多少步对。 每个卷积步骤通过将其 ai 贡献分布到所有可能的总数中来整合一个坐标。 嵌套循环结构是在n处截断的卷积的直接实现。 

最后乘以(2n)！ 恢复全局多项式因子，该因子负责步骤的排序以及从标准化权重转换回实际计数的转换。 

一个常见的陷阱是忘记 DP 超过 n（对），而不是 2n 步。 另一个是省略最终的阶乘缩放，这很重要，因为所有中间状态都在归一化组合空间中运行。 

## 工作示例

 ### 示例 1：n = 1，k = 2

 有两个步骤。 我们需要在二维中返回原点。 

| 步骤| dp 状态 |
 | ---| ---|
 | 初始化| dp[0]=1 | dp[0]=1 |
 | 坐标 1 之后 | dp[0]=1, dp[1]=1 |
 | 坐标 2 之后 | dp[0]=1，dp[1]=2，dp[2]=1 |

 由于 n=1，我们取 dp[1]。 最终答案是（2）！ × 2 = 4。 

这匹配四个可能的路径：±x 或±y。 

### 示例 2：n = 2，k = 1

 单坐标，一维 4 步。 

| 步骤| dp 状态 |
 | ---| ---|
 | 初始化| dp[0]=1 | dp[0]=1 |
 | 坐标 1 之后 | dp[0]=1，dp[1]=1，dp[2]=1 |

 我们取dp[2]=1。 最终答案是（4）！ × 1 / (2!2!) = 6，但由于 k=1，因此崩溃为 C(4,2)=6。 

这证实了该框架正确地简化为标准的一维行走。

 ## 边缘情况

 对于 n = 0，DP 从 dp[0]=1 开始，并且没有卷积改变它。 最后的乘法使用(0)！ = 1，因此输出为 1，与单个空走匹配。 

对于 k = 1，卷积退化为 b 上的单遍，并且 dp[n] 变为 1/(n!)^2。 乘以 (2n)！ 产生 (2n)!/(n!^2)，这正是中心二项式系数，与一维返回路径一致。 

对于 n = 1 和任意 k，k 次卷积后的 dp 产生 k，因为一对可以分配给任何坐标。 乘以2！ 给出 2k，与我们在每两个步骤中选择一个轴和一个方向的事实相匹配。
