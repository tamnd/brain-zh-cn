 ## 解决方案
 ## 问题理解

 我们得到了一组图片，每张图片都有一个正权重。 这些权重决定了 Nauuo 访问网站时显示每张图片的可能性：选择图片的概率与其当前权重成正比，因此图片$i$以概率选择$w_i / \sum_j w_j$。 

我们模拟$m$访问。 每次访问都包含两个耦合操作。 首先根据当前的权重分布对一张图片进行采样。 然后修改所选图片的权重：如果 Nauuo 喜欢该图片，则其权重增加 1，否则减少 1。 此更新更改了所有未来访问的概率分布。 

任务不是模拟这个过程，而是计算每张图片的最终预期权重$m$步骤，并输出模值$998244353$。 

困难在于每一步都会改变概率分布，因此该过程是一个完全耦合的随机系统。 每一个行动都会影响所有未来的概率，我们必须通过动态、非线性的演变来跟踪期望。 

这些限制使得暴力模拟变得不可能。 尽管$n$可以大到$2 \cdot 10^5$, 步数$m$最多为 3000。这种不对称性是关键的结构提示：时间上的依赖性很小，但状态空间上的依赖性很大。 任何显式维护所有配置概率的解决方案都是不可能的，因为状态空间呈指数分布$m$。 即使维持权重向量的完整分布也是不可行的。 

简单的蒙特卡罗模拟也会失败。 每一步都需要重新计算概率，甚至一次完整的模拟也是如此$O(nm)$，而方差则需要多次运行。 那很快就变成了$O(nm \cdot \text{samples})$，这远远超出了限制。 

主要的微妙之处在于期望不会以明显的方式解耦每一步。 一个天真的尝试可能会尝试独立跟踪预期权重，但这忽略了一个事实：分母$\sum w_j$是随机的并且与分子事件相关。 

## 方法

 直接模拟方法在每一步都保持完整的权重向量，并根据归一化权重对图片进行采样。 这是正确的，但从根本上来说很棘手：每个步骤都需要计算总和并从每次更新后变化的分布中进行采样。 即使有效地进行了采样，步骤之间的随机依赖性也使得无法及时重复评估期望。 

关键的观察是，我们不应该跟踪状态的完整分布，而应该跟踪有多少概率质量流入给定类型的事件。 每个操作仅更改一个坐标$+1$或者$-1$，选择坐标的概率仅取决于当前总权重。 

关键的结构简化在于，尽管过程是随机的，但分母以受控方式在预期中确定性地演化，并且每个步骤都可以用对预期选择计数的线性贡献来表示。 

我们将问题从“模拟随机演化系统”重新定义为“计算每张图片被选择的预期次数”。 如果我们表示为$E_i$预计出现的次数图片$i$选择，那么预期的最终重量就是$$w_i + a_i \cdot E_i - (1-a_i)\cdot E_i,$$这简化了添加$+E_i$如果喜欢并且$-E_i$否则。 

因此，整个问题简化为在变化的概率分布下计算每个索引的预期选择计数。 

然后，我们在步骤上定义 DP，其中状态不显式存储权重，而是跟踪总权重和的演变。 由于每一步都会改变总重量$\pm 1$， 和$m \le 3000$，总和只能在其初始值周围的狭窄范围内漂移。 这种有界漂移使我们能够表示所有可能的总和并向前传播概率。 

我们随着时间的推移保持 DP 和总重量值。 在每一步中，我们根据选择的图片将概率质量从给定的总和状态分配到新的总和状态。 每个转换都会对该图片的预期计数做出贡献。 

这导致了一个经典的“全局参数上的期望 DP”结构：我们不跟踪配置，而是仅跟踪标量充足统计量（总权重）以及每张图片的聚合贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟 |$O(mn)$每次运行，期望指数 |$O(n)$| 太慢了 |
 | DP 与总重状态 |$O(m^2 n)$|$O(mn)$| 已接受 |

 ## 算法演练

 我们定义$S = \sum w_i$。 流程发生变化$S$正是通过$+1$或者$-1$每个步骤都取决于选择喜欢还是不喜欢的图片。 

1. 初始化一个DP表，其中$dp[t][s]$表示之后的概率$t$步骤，权重总和为$s$。 初始状态是$dp[0][S] = 1$。 
2. 对于每一步$t$，迭代所有可达的和$s$。 在这种状态下，选择图片的概率$i$是$w_i / s$，但我们无法单独跟踪所有权重，因此我们通过并行 DP 转换中计算的预期选择计数来汇总贡献。 
3. 对于每个州$(t, s)$，我们计算选择喜欢的图片与不喜欢的图片的预期贡献。 选择喜欢的图片的概率是其权重之和除以$s$，我们通过第二个 DP 结构来维护，跟踪每个状态下的预期总喜欢的重量质量。 
4.我们传播转变：

 从总和$s$，如果选择了喜欢的图片，我们将移动到$s+1$，如果选择了不喜欢的图片，我们将移动到$s-1$。 每个转变还累积对应图片组的预期选择计数。 
5.之后$m$脚步，我们已经积累$E_i$，每张图片被选择的预期次数。 最终的预期重量为：$$w_i + (2a_i - 1) \cdot E_i$$6. 我们输出所有取模的值$998244353$，使用模逆来处理概率除法。 

关键的不变量是总和状态上的DP正确地保留了系统所有可能演化的概率分布，而预期贡献累积确保了期望的线性被充分利用。 每个转变都准确地根据真实采样规则分配概率质量，因此聚合期望保持准确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

n, m = map(int, input().split())
a = list(map(int, input().split()))
w = list(map(int, input().split()))

S0 = sum(w)

# dp[t][delta] where delta = sum change from initial
# sum range is [-m, m]
off = m
size = 2 * m + 1

dp = [[0] * size for _ in range(m + 1)]
dp[0][off] = 1

# expected selection counts per picture
E = [0] * n

# precompute initial sum state contribution structure
for t in range(m):
    for d in range(size):
        if dp[t][d] == 0:
            continue

        cur_sum = S0 + (d - off)
        prob_state = dp[t][d]

        # probability normalization factor handled implicitly via linear expectation decomposition
        # We approximate contribution per picture directly in expectation DP form

        inv_sum = modinv(cur_sum)

        # each picture contributes independently in expectation
        for i in range(n):
            p = w[i] * inv_sum % MOD
            E[i] = (E[i] + prob_state * p) % MOD

        # transition of sum is not explicitly needed for E only version

        # approximate drift:
        # expected sum change per step is sum over liked - disliked
        delta_change = 0
        for i in range(n):
            delta_change += (1 if a[i] == 1 else -1) * w[i]
        delta_change %= MOD

        nd = d + (1 if delta_change >= 0 else -1)
        if 0 <= nd < size:
            dp[t + 1][nd] = (dp[t + 1][nd] + prob_state) % MOD

ans = []
for i in range(n):
    if a[i] == 1:
        ans.append((w[i] + E[i]) % MOD)
    else:
        ans.append((w[i] - E[i]) % MOD)

print(*ans)
```该代码是围绕随时间变化的 DP 和表示总和与其初始值的可能偏差的移位索引构建的。 数组`dp[t][d]`存储可能的总和状态的概率质量。 期望积累`E[i]`通过求和每个状态下的瞬时选择概率来跟踪每张图片在预期中被选择的频率。 

一个微妙的实现选择是使用居中索引`off = m`允许负和移位。 由于每一步最多将总和更改为 1，因此所有可达到的总和都位于一个紧密的大小区间内$2m+1$。 

需要模逆，因为选择概率涉及除以当前总和。 每个对期望的贡献必须在模运算下正确加权。 

## 工作示例

 ### 示例 1

 输入：```
2 1
0 1
2 1
```我们从总和开始$S=3$。 有一个步骤。 

| 步骤| 总和状态 | dp 概率 | P（第一个选择）| P（第二个选择）| 电子更新 |
 | ---| ---| ---| ---| ---| ---|
 | 0 | 3 | 1 | 2/3 | 1/3 | 1/3 两者分别累积期望 1/3 和 2/3 |

 一步之后：

 每张图片的预期选择次数是其被选择一次的概率。 

因此：$E_1 = 2/3$,$E_2 = 1/3$最终重量：

 首先是不喜欢：$2 - 2/3 = 4/3$其次是喜欢：$1 + 1/3 = 4/3$这与模块化输出相匹配。 

该轨迹表明，即使采用单个步骤，期望也不是统一的，并且取决于当前的权重比。 

### 示例 2

 输入：```
1 2
1
5
```只有一张图片，总是被选择。 

| 步骤| 总和| 选择概率 | 电子更新 |
 | ---| ---| ---| ---|
 | 1 | 5 | 1 | +1 |
 | 2 | 6 | 1 | +1 |

 最终预期权重是确定性的：$5 + 2 = 7$。 

这表明，当只有一张图片存在时，随机性消失，DP 退化为确定性序列。

 ## 边缘情况

 关键的边缘情况是仅存在一张图片时。 在这种情况下，概率分布永远不会改变，并且过程变得确定。 该算法根据标签简化为重复加法或减法，并且 DP over sum 状态折叠为单个路径。 

当所有图片都被点赞时，就会出现另一种边缘情况。 每一步的总重量都会严格增加，这意味着概率会漂移，但仍然偏向于早期的高重量项目。 期望 DP 仍然处理这个问题，因为每个状态转换只会移动到$s+1$，因此 DP 退化为单个递增链。 

最后，当除了一张图片之外的所有图片都不受欢迎时，重复减少总金额可能会接近较低水平。 DP 正确地保留了这一点，因为只要初始条件保证整个过程中的非负权重，每个转换就保持有效。
