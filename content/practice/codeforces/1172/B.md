 ## 解决方案
 ## 问题理解

 我们被要求计算有多少种方法可以将给定树的节点放置在一个圆上，使得在节点之间绘制为直线的边缘不会交叉。 这棵树有`n`节点标记为`1`到`n`， 和`n-1`连接它们的边。 输入是边列表，输出是围绕圆模的节点的有效排列数`998244353`。 

将节点放置在圆上并绘制不相交的边相当于为节点分配位置，以便没有边“跳过”会导致相交的另一个节点。 观察小例子表明，任何与其邻居相连的节点都可以围绕圆自由排列，只要其邻居占据连续的弧即可。 

关键的限制是`n`可以大到`2*10^5`。 这意味着复杂度为 O(n^2) 或更高的算法将太慢。 我们需要一个大致为 O(n) 或 O(n log n) 的解决方案。 边缘情况包括具有高度节点（星形）的树和长链（线性树）。 如果不正确考虑模运算或度计数，基于阶乘的简单解决方案可能会失败。 例如，连接到中心节点 1 的 4 个节点的星形树有`3!`将叶子排序为 1 左右的方法，乘以 4 种从圆上任意位置开始中心节点的选择。 

## 方法

 蛮力方法是生成所有`n!`节点的排列，并检查根据排列绘制边是否会导致任何交叉。 检查每个排列的交叉需要 O(n^2) 运算，因为必须比较每对边。 这种方法显然不可行`n = 2*10^5`因为`n!`增长速度比任何多项式都快，甚至无法迭代所有排列。 

关键的见解是关注每个节点施加的本地约束。 对于一个节点`d`邻居，邻居必须占据其周围连续的位置以避免交叉。 这意味着，对于度节点`d`， 这`d`孩子们可以被安排在`d!`绕过它的方法。 此外，圆本身可以自由旋转，从而`n`起始节点的选择方法。 将它们相乘得出有效排列的总数：`n * product(deg[i]!)`对于所有节点`i`。 

这将问题简化为基于度数的简单计算，即 O(n)。 除了计算度数模的阶乘之外，不需要 DFS、DP 或组合生成`998244353`。 该问题的树结构保证每条边恰好贡献两个节点的度数，因此计算度数既简单又安全。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n^2) | O(n! * n^2) | O(n) | 太慢了 |
 | 学位计数| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个列表`deg`尺寸的`n+1`存储每个节点的度数，最初全为零。 
2.读取每条边`(u, v)`从输入和增量`deg[u]`和`deg[v]`。 每个节点的度数是它拥有的直接邻居的数量。 
3. 预先计算阶乘模`998244353`最多`n`。 这允许有效计算`deg[i]! % MOD`对于所有节点。 
4. 将答案初始化为`ans = n`来解释`n`旋转圆的方法。 
5. 乘法`ans`通过每个节点的度模的阶乘`998244353`。 具体来说，`ans = ans * factorial[deg[i]] % MOD`为所有人`i`从`1`到`n`。 
6. 输出`ans`。 

工作原理：不变的是，对于每个节点，其子节点可以按任意顺序排列在其周围的连续位置中。 由于树是连通的且是非循环的，因此确保每个节点的局部不交叉足以防止全局的任何边交叉。 旋转圆可以解释所有对称排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n = int(input())
    deg = [0] * (n + 1)
    for _ in range(n - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    # Precompute factorials modulo MOD
    factorial = [1] * (n + 1)
    for i in range(1, n + 1):
        factorial[i] = factorial[i-1] * i % MOD

    ans = n
    for i in range(1, n + 1):
        ans = ans * factorial[deg[i]] % MOD

    print(ans)

if __name__ == "__main__":
    main()
```该解决方案首先读取边缘并计算度数。 预先计算阶乘可确保我们避免重复阶乘计算。 乘法`n`与每个度的阶乘给出正确的模数计数`998244353`。 

微妙之处包括将阶乘数组初始化为大小`n+1`包括`0!`，正确处理模乘法，并迭代节点索引`1`到`n`匹配输入标签。

 ## 边缘情况

 二节点树 (`2\n1 2`) 产生两个有效排列：要么节点 1 首先，要么节点 2 首先。 算法正确计算`n=2`乘以`deg[1]! * deg[2]! = 1*1 = 1`, 给予`2`。 

对于一棵有 5 个叶子的星树（`1`连接到`2,3,4,5`），中心节点贡献`4!`排列叶子的方法和旋转给出`5`选择，导致`5*24=120`，符合预期答案。 该算法无需修改即可处理最小度和高度情况。
