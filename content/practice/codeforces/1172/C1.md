 ## 解决方案
 ## 问题理解

 我们正在使用一个图片系统，其中每张图片都有一个权重，控制我们访问网站时显示它的可能性。 任意时刻看到图片的概率$i$是它的重量除以所有图片的总重量。 每次访问后，我们立即仅更改所显示图片的权重：如果喜欢它，我们将其权重增加一，否则将其减少一。 

我们重复这个过程$m$独立访问，每次访问的分布取决于当前权重，而当前权重本身是根据早期结果演变的。 任务是计算所有访问后每张图片的预期最终权重，不是作为实数，而是作为大素数下的模分数。 

关键的困难在于分布是自适应的。 每一步都会改变所有未来步骤的概率，因此我们正在处理自我强化的随机过程而不是独立抽样。 

约束很小，有$n \le 50$和$m \le 50$。 这强烈表明我们可以同时跟踪涉及所有图片的状态分布，但前提是我们仔细利用结构。 对所有随机性分支进行简单模拟是不可能的，因为状态空间随着步数呈指数增长。 

一个天真的期望尝试会尝试模拟或递归计算每个可能的访问图片序列的概率。 后$m$步骤有$n^m$序列，即使对于$m=50$。 

一个更微妙的失败案例来自于尝试仅独立跟踪每张图片的预期权重，同时忽略相关性。 这种方法立即失效，因为概率取决于权重之和，而权重之和本身就是与每个单独权重相关的随机变量。 例如，一次访问后，增量取决于选择的索引，这会影响所有未来的概率。 

因此，主要的障碍是期望不能跨图片解耦。 

## 方法

 蛮力观点是将系统的完整状态定义为每一步之后的精确权重向量及其概率。 每个步骤分为$n$可能性，每张图片都有一个。 从一个状态，我们将概率质量分布为$n$新状态取决于选择的图片。 这在概念上是有效的，因为它直接遵循流程定义。 

然而，之后$m$步骤，状态数变为$n^m$，每个状态存储一个$n$维向量。 即使是为了$n=2, m=50$，这变得天文数字般大。 

关键的观察是我们不需要权重向量的完整分布。 我们只需要预期的最终重量。 这表明我们要扭转观点：我们不是跟踪向前的完整状态，而是跟踪概率质量如何根据对每张图片权重变化的贡献进行重新分配。 

一个关键的重新表述是关注在此过程中每张图片被选择的预期次数。 如果我们知道预期计数$E[c_i]$多少次图片$i$显示出来，那么图片最终的预计重量$i$简直就是$$w_i + (\mathbf{1}_{a_i=1} - \mathbf{1}_{a_i=0}) \cdot E[c_i].$$因此，整个问题简化为通过自修改概率过程计算预期选择计数。 

现在我们介绍随时间步长的动态规划和期望空间中的隐式权重演化。 重要的技巧是要注意，虽然权重是随机的，但它们的预期贡献呈线性演变，并且分母结构允许我们用代表累积选择的 DP 状态的预期归一化概率来表达转变。 

我们定义了一个 DP，它跟踪一定次数的选择后达到配置的概率，但我们通过仅跟踪每张图片被选择的次数来压缩状态。 自从$m \le 50$，我们可以将状态表示为计数元组$(c_1, \dots, c_n)$与总和$\le m$，但我们并没有明确列举所有$n^m$序列； 相反，我们增量地计算步骤转换，并在计算概率时重用对称性。 

每一步选择图片的概率$i$仅取决于当前权重：$$w_i + \Delta_i(c_i)$$除以总重量$$W + \sum_j \Delta_j(c_j).$$由于每一步只改变一个坐标$\pm 1$，计数状态之间的转换是稀疏且结构化的。 

我们逐层计算DP，其中每一层对应于step$t$，并且状态是之后可达的计数向量$t$更新。 每个转变恰好更新一个坐标，并且我们相应地累积概率质量。 

最后，预期计数源自 DP 分布。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解序列 |$O(n^m)$|$O(m)$| 太慢了 |
 | DP 计数状态 |$O(m \cdot \text{states})$（压缩）|$O(\text{states})$| 已接受 |

 ## 算法演练

 我们围绕随时间步长演变的概率 DP 构建解决方案，跟踪每张图片被选择的次数。 

1. 从所有选择计数为零且概率质量为1的初始状态开始。此时，权重正是给定的初始权重。 
2. 对于从 1 到$m$，我们计算从当前 DP 层到下一层的转换。 每个状态代表一个计数向量$(c_1, \dots, c_n)$，从这个状态我们考虑选择任何图片$i$。 
3. 对于一个州$c$，我们将当前权重计算为$w_i + (2a_i - 1)c_i$，其中喜欢的图片增加权重，不喜欢的图片减少权重。 这给出了该状态下每张图片的精确确定性权重。 
4.我们计算总重量$S = \sum_i w_i + \sum_i (2a_i - 1)c_i$。 这是概率的归一化因子。 
5. 来自州$c$，通过选择图片进行转场$i$导致一个新的状态$c'$仅在哪里$c_i$增加 1。这种转变的概率是当前的权重$i$除以$S$。 
6.我们将DP概率质量累积到下一层状态$c'$。 这确保了所有可能的序列都被考虑在内，而无需显式枚举它们。 
7.完成后$m$步骤，我们通过对所有状态求和来计算预期计数：每个状态贡献其概率乘以其计数向量。 
8. 最后，我们利用计数变化和权重更新之间的线性关系将预期计数转换为预期权重，然后使用模逆在模运算下输出结果。 

### 为什么它有效

 DP 将所有可能的图片选择序列的整个概率空间划分为由计数向量索引的不相交集合。 每个序列都精确地产生一个计数向量，并且每个转换根据过程定义保留精确的概率质量。 由于一旦计数固定，权重演化就是确定性的，因此对 DP 状态的调节足以准确计算期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def inv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    w = list(map(int, input().split()))
    
    # dp[state] = probability of reaching this count vector
    # state is tuple of counts
    from collections import defaultdict
    
    dp = {tuple([0]*n): 1}
    
    for _ in range(m):
        ndp = defaultdict(int)
        
        for state, prob in dp.items():
            # compute current weights
            weights = []
            total = 0
            
            for i in range(n):
                delta = 1 if a[i] == 1 else -1
                wi = w[i] + delta * state[i]
                weights.append(wi)
                total += wi
            
            if total == 0:
                continue
            
            total_inv = inv(total)
            
            for i in range(n):
                if weights[i] <= 0:
                    continue
                p = prob * weights[i] % MOD * total_inv % MOD
                new_state = list(state)
                new_state[i] += 1
                ndp[tuple(new_state)] = (ndp[tuple(new_state)] + p) % MOD
        
        dp = ndp
    
    exp_counts = [0] * n
    
    for state, prob in dp.items():
        for i in range(n):
            exp_counts[i] = (exp_counts[i] + state[i] * prob) % MOD
    
    res = []
    for i in range(n):
        delta = 1 if a[i] == 1 else -1
        val = (w[i] + delta * exp_counts[i]) % MOD
        res.append(str(val))
    
    print(" ".join(res))

if __name__ == "__main__":
    solve()
```DP 字典存储可达计数向量上的概率质量。 每次迭代都会通过一次访问来扩展状态，每次转换精确更新一个坐标。 

每个状态内的权重计算至关重要，因为概率取决于不断变化的权重，而不仅仅是初始值。 模逆用于处理概率计算中的除法。 

一个微妙的问题是，权重为零或负的状态在转换中会被跳过。 这符合这样的图片不能以正概率被选择的解释。

 ## 边缘情况

 当只喜欢一张图片时，就会出现一种边缘情况。 在这种情况下，无论权重演化如何，所有概率质量总是选择该图片，因此该过程变得确定性。 DP 正确地处理了这一问题，因为每个状态都有一个有效的转换。 

另一个极端情况是不喜欢的图片权重为零。 从这些状态开始，完全跳过这些图片的转换，因为它们对概率的贡献变为零。 这可以防止无效的负权重采样路径影响DP，并确保概率质量仅流经有效的配置。 

最后一个微妙的情况是对称性，即多张图片以相同的权重和类型开始。 DP 仍然单独对待它们，但它们的分布演变相同，并且由于对称转移概率，期望值保持相等。
