 ## 解决方案
 ## 问题理解

 该问题描述了一系列历史发明。 每项发明都有一个标题、发明日期和代表它与切片面包的伟大程度的分数。 目标是找到切片面包发明后发生的最伟大的发明，切片面包被认为是在 1928 年 7 月 7 日出现的。 

输入包含多个发明记录。 每条记录都包含一个名称、一个使用三个字母的月份缩写书写的日期，后跟日和年，以及 0 到 1 之间的小数分数。输出只是具有最大分数的有效发明的名称。 

发明数量可达1万项。 这足够小，我们可以检查每一项发明一次。 任何比较每对发明的方法在最坏的情况下都会执行大约 1 亿次比较，这对于简单的最大搜索来说是不必要的。 

主要的实施困难不是搜索本身，而是正确解释日期。 粗心的解决方案可能会将日期作为字符串进行比较，或者忘记年份可能并不总是有四位数字。 日期必须转换为保留时间顺序的表示形式。 

例如，输入如下：```
3
Old Machine
Jan 1, 3000
0.9
New Machine
Jan 1, 2000
0.8
Ancient Tool
Jan 1, 100
0.99
```只有一项有效的发明，即旧机器，因为另外两项是在切片面包之前创建的。 正确的输出是：```
Old Machine
```仅选择最大分数的解决方案将错误地输出古代工具。 

另一个边缘案例是恰好在 1928 年 7 月 7 日创建的发明。它不算数，因为该措辞要求在切片面包之后进行发明。 例如：```
2
Exact Date
Jul 7, 1928
1.0
Later
Jul 8, 1928
0.5
```正确的输出是：```
Later
```使用大于或等于的比较会错误地选择精确日期。 

## 方法

 最简单的方法是存储每项发明并检查所有可能的选择。 对于每项发明，我们都会检查它是否是在 1928 年 7 月 7 日之后创建的，然后将其得分与其他所有有效发明进行比较。 这是正确的，因为还必须在这些比较中找到所有有效候选人中的最高分数。 然而，对于 10,000 项发明，这会执行大约 1 亿次比较，而解决问题不需要发明之间进行任何交互。 

有用的观察是，这仅要求过滤记录中的最大值。 一旦我们处理了其他发明，我们就不需要了解它们的任何信息。 我们可以扫描一次输入，在切片面包日期之前或当天丢弃发明，并保留迄今为止看到的最佳分数。 

蛮力解决方案之所以有效，是因为它最终会检查所有可能的获胜者，但它会失败，因为它重复了不必要的比较。 可以增量地维持最大值的观察结果将问题简化为单遍。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N²) | O(N) | 概念上太慢|
 | 最佳| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读发明数量。 独立处理每个发明记录，因为答案仅取决于迄今为止找到的最佳有效候选者。 
2. 将发明日期转换为可比较的数字形式。 一种方便的表示形式是将年、月和日存储为元组。 元组按从最大单位到最小单位排序时按时间顺序进行比较。 
3.检查发明日期是否严格在1928年7月7日之后。相同日期必须拒绝，因为该发明必须比切片面包更新。 
4. 对于每个有效的发明，将其得分与当前的最佳得分进行比较。 如果本发明得分较高，则替换已存储的答案。 
5. 处理完所有记录后，打印存储的标题。 

工作原理：在扫描过程中，存储的发明始终是迄今为止处理的所有记录中得分最高的有效发明。 当检查另一个有效的发明时，要么它具有较小的分数并且不变量保持为真，要么它具有较大的分数并且替换存储的答案恢复不变量。 最终记录下来后，所存储的答案一定是最伟大的有效发明。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

months = {
    "Jan": 1,
    "Feb": 2,
    "Mar": 3,
    "Apr": 4,
    "May": 5,
    "Jun": 6,
    "Jul": 7,
    "Aug": 8,
    "Sep": 9,
    "Oct": 10,
    "Nov": 11,
    "Dec": 12,
}

def parse_date(s):
    month, day, year = s.replace(",", "").split()
    return (int(year), months[month], int(day))

def solve(data=None):
    global input
    if data is not None:
        import io
        input = io.StringIO(data).readline

    n = int(input())

    cutoff = (1928, 7, 7)
    best_score = -1.0
    answer = ""

    for _ in range(n):
        title = input().rstrip("\n")
        date = parse_date(input().rstrip("\n"))
        score = float(input().rstrip("\n"))

        if date > cutoff and score > best_score:
            best_score = score
            answer = title

    return answer

if __name__ == "__main__":
    print(solve())
```月份字典将文本月份转换为数字，以便可以直接比较日期。 解析器从输入中删除逗号，例如`Jul 7, 1928`在分割碎片之前。 

扫描仅保留两个状态：迄今为止找到的最佳分数和相应的标题。 比较使用`>`用于日期检查，因为切片面包日期的发明不包括在内。 

分数比较使用浮点值，因为输入分数是小数。 由于该问题保证了最有效的发明不存在平局，因此不需要精确的平局处理。

 ## 边缘情况

 对于恰好在截止日期的发明：```
2
Exact
Jul 7, 1928
1.0
Later
Jul 8, 1928
0.5
```该算法将 Exact 解析为`(1928, 7, 7)`。 由于这不大于截止元组，因此会跳过它。 后来成为第一个有效的发明并被印刷。 

对于一项满分的老发明：```
2
Ancient
Jan 1, 1000
1.0
Modern
Jan 1, 2000
0.2
```在分数比较之前，古代被忽略。 该算法绝不允许无效的发明成为当前的最佳答案，因此 Modern 被正确选择。
