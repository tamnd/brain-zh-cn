 ## 解决方案
 ## 问题理解

 我们有（N）个纪念碑。 纪念碑 (i) 具有坐标 ((x_i,y_i)) 和正等级 (g_i)。 摩根选择了两个不同的纪念碑作为一条线的端点。 气球位于这两个纪念碑之间，并且该线将所有剩余的纪念碑分成两个开放的半平面。 

每张照片包含两个选定的端点纪念碑，以及线两侧之一的所有纪念碑。 如果两张照片的总和是 (A) 和 (B)，我们希望在每对可能的端点纪念碑上最小化 (|A-B|)。 

输入给出了纪念碑的数量及其坐标和等级。 输出是两个照片等级之间可能的最小差异。 

关键的几何简化是两个端点纪念碑出现在两张照片中。 因此，他们的成绩会添加到两个总和中，并在我们计算差值时取消。 对于一对固定端点 (i,j)，假设严格位于其线一侧的纪念碑的等级总和为 (S)。 设所有古迹的总等级为（T）。 对方有等级

 [
 T-g_i-g_j-S。 
]

 因此差异是

 \左|2S-T+g_i+g_j\右|。 
]

 所以整个问题就变成了：对于穿过两个纪念碑的每条线，尽快找到一侧的点的等级总和。 

坐标限制达到(10^9)，因此坐标差和叉积可以比32位整数大得多。 叉积大约可以达到(10^{18})，而所有等级的总和可以达到(4\cdot10^{12})。 Python整数直接处理这些值，因此在实现中不存在溢出问题。 

限制（N\le 4000）是主要的算法信号。 枚举所有端点对已经给出了大约 (N^2/2) 种可能性，因此在每对上花费 (O(N)) 工作大约需要

 31,976,004,000
 ]

 最坏情况下的点分类。 这远远超出了 15 秒的限制。 我们需要一起处理与一个固定端点关联的所有对。 

第一个边缘情况是 (N=2)。 例如，```
2
0 0 1
1 2 999
```有答案`0`。 这条线的两边都没有纪念碑。 两张照片都包含两个端点，因此两个等级均为 (1000)。 如果粗心的解决方案仅对每个端点进行一次计数，则会错误地报告 (998)。 

第二个边缘情况是 (N=3)。 例如，```
3
0 0 5
1 0 10
0 1 7
```有答案`5`。 无论选择哪一对作为界碑，剩下的碑一侧都是空的，另一侧是空的。 端点取消，留下的差异等于剩余纪念碑的等级。 最好的选择是让纪念碑的等级为（5）。 

另一个容易犯的错误是在测试线的两侧时使用了错误的严格性。 该声明保证没有三个纪念碑共线，因此没有第三个纪念碑可以完全位于边界线上。 我们可以安全地使用严格的跨产品测试。 将端点本身视为边的一部分是错误的，并且将其复制到边和中也会破坏答案。 

官方 SWERC 分析描述了通过对每个固定纪念碑周围的其他纪念碑进行排序并逐步更新差异，从 (O(N^3)) 解决方案到 (O(N^2\log N)) 解决方案的相同减少。 

## 方法

 直接解决方案很简单。 枚举每对 (i,j) 作为两个边界纪念碑。 然后检查每个其他纪念碑 (k)，使用叉积计算 (i,j,k) 的方向，并将 (g_k) 添加到两侧总和之一。 一旦所有点都被分类，计算两侧总和的差。 

这是正确的，因为边界纪念碑的每种可能选择都被明确考虑，并且叉积准确地告诉我们每个剩余纪念碑占据边界线的哪一侧。 问题是成本。 有 (O(N^2)) 个端点对，每个端点对都需要 (O(N)) 个分类，从而给出 (O(N^3))。 对于（N=4000），最坏的情况包含大约（3.2\cdot10^{10}）个点分类，因此这种方法不可行。 

删除（N）的额外因素的观察结果是，对于一个固定的纪念碑（i），可以按角度顺序考虑所有可能的第二端点。 

将纪念碑 (i) 暂时放置在原点，并查看从 (i) 到每个其他纪念碑的矢量。 按极角对这些向量进行排序。 当第二个边界纪念碑按此排序顺序顺时针移动时，位于特定开放半平面中的纪念碑组会不断变化。 更准确地说，新边界线一侧的纪念碑形成宽度小于（180^\circ）的连续角区间。 

这个间隔可以通过两指针扫描来维持。 左端点是当前边界向量。 右端点仅向前移动，因为旋转边界向量无法使对应半圆的端点向后移动。 因此，在一个固定 (i) 的整个扫描过程中，每个指针仅移动 (O(N)) 次。 

固定 (i) 剩下的唯一昂贵的操作是按角度对其他 (N-1) 个纪念碑进行排序，其成本为 (O(N\log N))。 对 (i) 的所有 (N) 个可能选择重复此操作，得到 (O(N^2\log N))。 

官方分析准确地给出了这种复杂性，并描述了围绕每个固定限制纪念碑对纪念碑进行排序，然后逐步计算等级差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(N^3)) | (O(N)) | 太慢了|
 | 最佳 | (O(N^2\log N)) | (O(N)) | 已接受 |

 ## 算法演练

 1. 读取所有纪念碑并计算总等级（T）。 我们将重复使用（T-g_i-g_j），即除两个边界纪念碑之外的所有纪念碑的总等级。 
2. 固定一座纪念碑(i)作为第一座界碑。 对于每个其他纪念碑 (j)，形成向量
 [
 v_j=(x_j-x_i,\y_j-y_i)。 
]
 存储它的方向、矢量分量和等级。 我们按 (i) 周围的极角对这些向量进行排序。 

排序为我们提供了一个循环顺序，其中第二个边界纪念碑可以围绕 (i) 旋转。 
3. 通过允许索引达到 (2(N-1)-1)，从概念上复制角序列。 我们实际上不需要复制矢量对象。 指数（k）指的是`vectors[k % m]`，其中（m=N​​-1）。 

这将圆角顺序变成了线性序列，因此半圆区间可以跨越 (0^\circ) 边界，无需特殊情况。 
4. 维护当前空心半圆末端的指针 (k)。 对于当前边界向量 (v_j)，advance (k) while
 [
 \运算符名称{交叉}(v_j,v_k)>0。 
]

 正叉积意味着 (v_k) 从 (v_j) 逆时针旋转，角度严格介于 (0^\circ) 和 (180^\circ) 之间。 由于没有三个标杆共线，因此对于来自同一固定标杆的两个不同向量，叉积不能为零。 
5. 按角度顺序维护等级的前缀和。 如果当前半圆包含从 (j+1) 到 (k-1) 的索引，则其等级总和在 (O(1)) 中从前缀总和中获得。 

边界纪念碑本身被排除在外，因为间隔严格在 (j) 之后开始。 这正是我们需要的边和。 
6. 对于界碑 (i) 和 (j)，令`side`是当前半圆内的成绩总和。 所有无界古迹的等级为
 [
 T-g_i-g_j。 
]
 因此两边的和是`side`和
 [
 T-g_i-g_j-\text{侧面}。 
]
 因此照片差异为
 [
 \left|2\cdot\text{side}-(T-g_i-g_j)\right|。 
]
 7. 用这个差值更新全局最小值。 如果答案为零，则立即停止，因为不存在更小的绝对差异。 
8. 对每个可能的第一个边界标杆 (i) 重复角度排序和两指针扫描。 在这些扫描中至少一次会遇到每一对无序边界纪念碑，因此全局最小值包含真正的最优值。 

### 为什么它有效

 对于固定纪念碑（i），排序后的向量表示第二边界纪念碑的所有可能方向。 对于任何当前方向 (v_j)，相应边界线一侧的纪念碑恰好是那些方向从 (v_j) 严格逆时针方向小于 (180^\circ) 的纪念碑。 叉积条件精确地确定了该区间。 

当 (j) 按角度顺序前进时，(180^\circ) 间隔的端点永远不会向后移动。 因此，两指针扫描会访问每个可能的边区间，同时保持其等级总和。 前缀和将每个间隔转换为 (O(1)) 查询。 

每一对界碑都定义了一个这样的间隔，并且这两张照片恰好是两个互补的边和加上相同的两个端点等级。 因此，该算法使用的公式计算每个可能对的精确差异。 取所有对的最小值即可给出所需的答案。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    total_grade = sum(g for _, _, g in points)
    answer = total_grade

    for i in range(n):
        xi, yi, gi = points[i]

        vectors = []
        for j in range(n):
            if i == j:
                continue

            xj, yj, gj = points[j]
            dx = xj - xi
            dy = yj - yi

            vectors.append((math.atan2(dy, dx), dx, dy, gj))

        vectors.sort(key=lambda v: v[0])
        m = n - 1

        grades = [v[3] for v in vectors]

        prefix = [0] * (2 * m + 1)
        for p in range(2 * m):
            prefix[p + 1] = prefix[p] + grades[p % m]

        k = 1

        for j in range(m):
            if k < j + 1:
                k = j + 1

            _, ax, ay, gj = vectors[j]

            limit = j + m

            while k < limit:
                _, bx, by, _ = vectors[k % m]

                cross = ax * by - ay * bx

                if cross <= 0:
                    break

                k += 1

            side = prefix[k] - prefix[j + 1]
            other = total_grade - gi - gj

            diff = abs(2 * side - other)

            if diff < answer:
                answer = diff

                if answer == 0:
                    print(0)
                    return

    print(answer)

if __name__ == "__main__":
    solve()
```外环选择第一个界碑。 对于该固定点，内部构造为每个其他纪念碑创建一个向量。 该向量存储其角度排序键和精确的整数坐标，因为后面的叉积计算必须使用原始整数分量。`atan2`仅用于获得循环排序。 实际的 (180^\circ) 隶属度测试使用精确的整数叉积，因此不使用浮点运算来确定纪念碑是否属于一侧。 这对于大到 (10^9) 的坐标特别有用。 

向量按 ([-\pi,\pi]) 中的角度排序。 前缀数组的长度为(2m+1)，表示成绩序列的两个副本。 我们不复制向量对象本身，这使得每枢轴内存较小。 

指针`k`永远不会重置`j`增加。 这是关键的两指针属性。 开半圆的末端绕圆单调移动，所以`k`只能在一次完整扫描期间增加。 因此，固定主元的叉积测试总数是 (O(N))，而不是 (O(N^2))。 

条件`cross <= 0`停止半圆。 零叉积意味着两个向量共线，这对于两个不同的其他纪念碑来说不会发生，因为没有三个纪念碑在一条线上。 使用`<= 0`尽管如此，它仍然是安全边界约定，并且还排除了一次完整旋转后当前向量的重复副本。 

表达式```
side = prefix[k] - prefix[j + 1]
```刻意开始之后`j`。 目前的界碑不得计入双方总和中。 两个端点等级分别插入到两个照片等级中，并在计算它们的差异时取消。 

Python 整数自动扩展到任意精度，因此 (10^{18}) 附近的叉积和 (4\cdot10^{12}) 附近的总成绩不需要特殊处理。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(N^2\log N)) | 对于每个固定纪念碑，对 (N-1) 个方向进行排序，然后执行 (O(N)) 两指针扫描。 |

 对于 (N=4000)，该算法对每个大约 (N) 个元素执行 (N) 次角度排序，然后每次排序仅进行 (O(N)) 几何更新。 这是官方 SWERC 分析中描述的预期 (O(N^2\log N)) 方法。 内存使用量保持线性，因为一个枢轴的角度数据可以在处理下一个枢轴之前被丢弃。

 ## 边缘情况

 为了两座纪念碑，```
2
0 0 1
1 2 999
```唯一的边界对包含每个纪念碑。 两边的总和都为零，而两张照片都包含终点等级 (1+999)。 照片等级为（1000）和（1000），所以答案是`0`。 该算法处理这个问题是因为`other = total_grade - gi - gj`为零且前缀间隔为空。 

为了三座纪念碑，```
3
0 0 5
1 0 10
0 1 7
```将任何纪念碑固定为第一边界。 其他两个向量之间的角度严格介于 (0^\circ) 和 (180^\circ) 之间，因此一个可能的边界对将第三个纪念碑放在一侧，而将另一侧留空。 对于每一对来说，差异恰好是剩余纪念碑的等级。 选择离开等级 (5) 的一对给出答案`5`。 

对于同等成绩，```
4
0 0 7
3 0 7
0 4 7
3 4 7
```该算法可以找到两侧和相等的对，产生差值为零。 立刻`answer == 0`，执行立即返回，因为绝对差异不能更小。 

对于最大坐标值，```
3
0 0 1000000000
1000000000 0 999999999
0 1000000000 1
```所有三个点形成一个有效的三角形。 由于纪念碑只有三座，所以答案是最小的等级，`1`。 叉积涉及 (10^{18}) 左右的值，Python 可以准确处理该值。 

对于最大尺寸测试，对于 (0\le i<4000)，点为 ((i,i^2))。 这些点中没有三个点是共线的，因为一条直线最多可以在两个点处与严格二次曲线 (y=x^2) 相交。 每个等级都是 (1)，因此存在零差异，算法一旦找到差异就可以终止。 此测试验证了几何假设和预期的 (O(N^2\log N)) 缩放。
