 ## 解决方案
 ## 问题理解

 我们有两个步长，`a`和`b`。 从零开始，我们按递增顺序绘制每个非负整数，但是一个数字是否变成白色取决于是否可以通过重复添加从已经是白色的数字中到达它`a`或者`b`。 

形式上，零从白色开始。 对于任何数字`i`，如果减去它就变成白色`a`或者`b`落在一个已经是白色的数字上。 如果前任都不起作用，则该数字保持黑色。 

这个过程相当于构建所有可以组成的数字`i = x·a + y·b`对于非负整数`x`和`y`，因为通过重复添加可以到达每个白色数字`a`或者`b`从零开始。 

问题不是列出颜色，而是确定是否有无限多个黑色数字。 这完全取决于可达（白色）数字的集合最终是否变得足够密集以覆盖所有足够大的整数。 

约束很小，有`t ≤ 100`和`a, b ≤ 10^4`。 这表明我们没有在大范围的整数上模拟该过程。 对达到某个大截止值的简单模拟是任意且不可靠的，因为过渡结构取决于数论，而不是局部传播深度。 

一个关键的边缘情况是当`a`和`b`是平等的。 例如，如果`a = b = 10`，只有 10 的倍数是白色的。 所有其他整数都是永久黑色的，并且它们的数量是无穷多的。 另一种边缘情况是其中一个是`1`， 例如`a = 1, b = 10`，其中每个数字都可以通过重复 +1 步骤到达，因此根本不存在黑色数字。 

## 方法

 强力解释尝试按顺序模拟着色：将数组维持在某个较大的限制范围内`N`， 标记`0`为白色，并且对于每个`i`，将其标记为白色，如果`i-a`或者`i-b`是白色的。 然后数黑色的数字。 这对于固定界限来说是正确的，但问题是“无限黑”不能从任何固定截止值决定，除非我们知道超过该界限行为稳定的理论界限。 尝试增加限制仍然不能保证正确性，因为在病态情况下，即使黑色数字稍后出现，第一长段数字也可能都是白色的。 

关键的见解是白数形成了由下式生成的加法半群：`a`和`b`。 这是一个经典的数论结构：所有白数都是线性组合`x·a + y·b`。 问题是这个半群最终是否涵盖了所有足够大的整数。 这恰好发生在`gcd(a, b) = 1`，因为半群是余有限的，这意味着只有有限多个整数是不可到达的。 如果`gcd(a, b) > 1`，所有白数都是 gcd 的倍数，在结构之外留下无限多个整数，因此黑数也有无限多个。 

这将整个动态过程简化为单个算术条件。

 ## 算法演练

 1. 读取整数`a`和`b`对于每个测试用例。 目标是确定加法过程最终是否能够达到所有大整数，还是留下无限多个无法达到的值。 
2. 计算`g = gcd(a, b)`。 这捕获了所有可达数的基本周期结构，因为每个可达值都必须能被整除`g`。 
3.如果`g == 1`，得出结论，可达集是稠密的，因为只有有限多个整数丢失，因此黑数不能无限持续。 
4. 否则，如果`g > 1`，得出所有可达数都是以下数的倍数的结论`g`，意味着每个不能被整除的整数`g`永久无法访问。 由于这样的整数有无限多个，因此黑数也是无限的。 

### 为什么它有效

 每个白数都是通过重复相加构成的`a`和`b`，所以它必须位于集合中`{x·a + y·b}`。 所有这些组合都可以被整除`g = gcd(a, b)`, so no number outside this residue class can ever become white. 什么时候`g = 1`，弗罗贝尼乌斯硬币问题的经典结果保证所有足够大的整数都是可表示的，这迫使只有有限多个黑色数字。 什么时候`g > 1`，不可达残基类无限重复，保证有无限多个黑数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    g = math.gcd(a, b)
    if g == 1:
        print("Finite")
    else:
        print("Infinite")
```该解决方案使用Python的内置gcd函数来提取关键的结构不变量。 每个测试用例都是独立的，因此我们只需重复应用相同的检查即可。 

决策逻辑是数论特征的直接翻译：gcd 等于 1 意味着最终覆盖，否则周期性阻塞仍然存在。

## 测试用例```python
import sys, io
import math

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        a, b = map(int, input().split())
        out.append("Finite" if math.gcd(a, b) == 1 else "Infinite")
    return "\n".join(out)

# provided samples
assert solve("4\n10 10\n1 10\n6 9\n7 3\n") == "Infinite\nFinite\nInfinite\nFinite"

# custom cases
assert solve("1\n1 1\n") == "Infinite"
assert solve("1\n1 2\n") == "Finite"
assert solve("1\n4 6\n") == "Infinite"
assert solve("1\n5 10\n") == "Infinite"

 ## 边缘情况

 当`a = b`，该过程退化为单步可达性系统。 为了`a = b = 10`，每个可达数都是 10 的倍数。该算法计算`gcd(10, 10) = 10`，立即将其分类为无限黑数，与所有非 10 的倍数永远无法到达的事实相匹配。 

当一个值是`1`， 例如`a = 1, b = 10`，我们得到`gcd = 1`。 该算法返回有限的黑色数字。 实际过程中，每一个数都可以通过重复相加得到`1`，因此根本不会出现黑色数字。 gcd 检查捕获这一点而不模拟传播。 

当值共享更大的 gcd 时，例如`a = 12, b = 18`，算法输出无穷大。 可到达集合被限制为 6 的倍数，在该残差类之外留下无限多个整数，这些整数永远保持为黑色。
