 ## 解决方案
 ## 问题理解

 游戏可以被视为沿着 10 x 10 网格上的固定蛇形路径排列的有向状态线。 每个单元格对应于该路径上的一个位置，从左下角单元格开始，到左上角单元格结束。 沿着路径的移动是确定性的：在行内，您以交替方向水平移动，在行边界处，您垂直向上移动。 因此，每个单元格都有一个唯一的后继单元格，除非它是最终的目标单元格。 

每一轮都包括滚动一个公平的六面骰子。 玩家尝试沿着路径向前移动同样的步数。 如果骰子值超过目标，玩家将留在原地。 着陆后，如果单元格包含梯子的底部，玩家可以选择留下来或立即传送到棋盘上更高的梯子端点。 一旦梯子被拿走，即使另一个梯子从着陆单元开始，它也不能立即被锁住。 

任务是计算达到目标所需的最小预期转弯数，假设每次机会都做出是否使用梯子的最佳决策。 

状态空间小且固定：正好有 100 个单元。 这立即表明任何对状态数具有三次或更差依赖性的解决方案都是可以接受的，而任何指数或涉及对骰子序列进行重复重新计算的解决方案都是不必要的。 线性系统或最短路径式动态规划是可行的。 

梯子落在本身包含梯子的单元格上时会出现一个微妙的问题。 一个天真的贪婪假设“如果梯子上升，就总是采取梯子”是错误的，因为采取梯子可能会跳过更好的预期位置单元格，该单元格提供更有利的未来骰子转换。 另一种失败情况是在目标附近超调：从近端状态移动 5 或 6 步可能会导致相同的“无移动”结果，这会影响转换概率，必须明确处理。 

## 方法

 暴力解释将每个游戏状态视为棋盘上的一个位置，并将每个骰子结果视为一个过渡。 从每个单元格中，我们模拟所有可能的骰子掷骰，应用移动，可选地选择梯子使用，并递归计算完成的预期时间。 

这种朴素的递归构建了马尔可夫决策过程。 虽然概念上是正确的，但除非记住，否则重复重新计算每个状态的期望值会导致指数爆炸。 即使使用记忆，如果以循环依赖顺序评估转换，则朴素递归可能需要重复松弛直到收敛。 

关键的观察是，这是一个有限的马尔可夫决策过程，具有非负的预期成本和单调的目标进展。 每个状态都有一个固定的期望值方程，该方程仅依赖于已定义的状态或其本身，因此可以使用类似于值迭代的迭代松弛来求解系统，或者更直接地作为基于期望成本的最短路径类 DP 来求解。 

每个状态对应一个线性方程：

 状态 i 的预期成本等于 1（对于当前回合）加上最佳后继状态的六个骰子结果的平均值。 “最佳继任者”取决于我们是否选择在可能的情况下攀登阶梯。 这在转换定义中引入了局部最小值。 

因此，如果所有后继状态已知，则可以计算每个状态。 由于运动总是向前或停留，因此可以按照从目标到开始的相反顺序处理状态。 这会产生稳定的 DP 排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力递归 | 指数| O(n) | 太慢了|
 | DP 状态（相反顺序）| O(100 × 6) | O(100) | 已接受 |

 ## 算法演练

我们首先按照蛇形遍历顺序将 10 x 10 板展平为包含 100 个位置的单个数组。 每个位置 i 要么存储梯子目的地，要么不存储。 

然后我们计算所有骰子结果的下一个位置。 从状态 i 开始，对于每个骰子掷 r，我们通过沿着路径向前移动 r 步来确定目标位置 j，如果超出，则夹紧目标。 

一旦到达 j，我们可以停留在 j，或者如果梯子从那里开始，则跳到其终点。 我们选择产生较小预期时间的选项。 

我们将 dp[i] 定义为从位置 i 到达目标所需的最小预期转弯数。 

我们以相反的顺序处理位置，从 99 到 0。 

1. 将目标单元格处的 dp 初始化为 0，因为游戏结束后不需要回合。 
2. 对于每个其他位置 i，计算转弯的期望值。 每回合始终花费 1。 
3. 对于从 1 到 6 的每个骰子结果 r，计算移动 r 步后的着陆单元 j，或者如果移动超调则计算目标。 这在阶梯决策之前给出了确定性的下一个位置。 
4. 如果 j 有梯子，则计算两个候选结果：停留在 j 并采取梯子目的地。 由于玩家的行为是最优的，因此选择这两种状态之间的最小期望 dp 值。 
5. 平均这六个生成的 dp 值并加 1 以说明当前回合。 将其分配给 dp[i]。 
6. 继续，直到处理完所有状态，确保已计算任何状态的依赖项（所有前向位置）。 

这种排序起作用的核心原因是移动永远不会降低沿路径的索引。 每个转变都严格向前或保持在目标位置，因此 dp 仅依赖于较高指数的状态。 这使得递归成为非循环的，并保证单个向后传递就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = 10
grid = [list(map(int, input().split())) for _ in range(n)]

# flatten board in serpentine order
pos = []
coords = []
for i in range(n):
    row = n - 1 - i
    if i % 2 == 0:
        for col in range(n):
            pos.append((row, col))
            coords.append((row, col))
    else:
        for col in range(n - 1, -1, -1):
            pos.append((row, col))
            coords.append((row, col))

idx = {coords[i]: i for i in range(100)}

ladder = [0] * 100
for i in range(n):
    for j in range(n):
        if grid[i][j] > 0:
            start = idx[(n - 1 - i, j)]
            ladder[start] = start + grid[i][j] * 10

def clamp(x):
    return min(x, 99)

dp = [0.0] * 100
dp[99] = 0.0

for i in range(98, -1, -1):
    total = 0.0
    for dice in range(1, 7):
        j = i + dice
        if j >= 100:
            j = 99
        best = dp[j]
        if ladder[j]:
            best = min(best, dp[ladder[j]])
        total += best
    dp[i] = 1.0 + total / 6.0

print(dp[0])
```代码首先构建所有 100 个方格的精确路径排序，以便每次移动都成为一个简单的索引增量。 梯形数组在此线性化中将每个起始单元映射到其目标索引。 

DP 数组存储期望值，我们从末尾向后迭代，因为所有转换都在此索引空间中向前进行。 对于每次掷骰子，我们计算着陆指数，然后通过比较“停留”与“攀登”来在本地应用最佳阶梯决策。 

最终答案是dp[0]，对应于起始单元格。 

## 工作示例

 我们使用无梯子的情况，因为它隔离了概率结构。 

### 示例：空板

 | 状态 i | dp[i] 计算 |
 | ---| ---|
 | 99 | 99 0 |
 | 98 | 98 1 + 平均值（6 卷中的 dp[99]）= 1 |
 | 97 | 97 1 + (dp[98]+dp[99] 混合)/6 |
 | ... | ... |
 | 0 | 积攒满满期待|

 在每个步骤中，该值表示仅存在确定性向前运动时所需的预期匝数。 临近结束时，许多骰子结果在目标处饱和，导致 dp[99] 贡献重复为 0。 

这表明，通过限制到目标状态的转换自然可以处理超调，这会降低接近结束时的预期值增长。 

### 示例：接近起点的单梯子

 假设位置 2 处存在一个梯子，可以跳转到位置 20。 

在计算 dp[2] 时，我们比较了在 2 处着陆的两种转换选项：停留贡献 dp[2]，而攀爬贡献 dp[20]。 如果dp[20]较小，则DP会倾向于攀爬； 否则它将忽略梯子。 

这表明阶梯决策是嵌入全局期望中的局部优化，并且不需要扩展状态空间。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(100 × 6) | 每个州评估 6 个骰子结果一次 |
 | 空间| O(100) | DP阵列加线性化板|

 状态空间的大小是恒定的，因此该解决方案在实践中运行时间恒定，并且很容易满足限制。 即使推广到更大的网格，相同的结构在状态数乘以骰子结果方面仍将保持线性。

 ## 边缘情况

 直接通向目标的阶梯测试 DP 是否正确地将目标视为吸引人的。 从该着陆单元开始，dp 为零，因此占据梯子必须始终占主导地位，除非它不会带来任何好处。 

通过掷骰子超越目标可确保所有大于剩余距离的值正确映射到目标状态。 这可以防止数组溢出并确保期望不会错误地超出范围。 

登陆同一单元的多个梯子可以安全处理，因为 DP 只比较目标值，而不比较梯子标识，因此收敛不受影响。
