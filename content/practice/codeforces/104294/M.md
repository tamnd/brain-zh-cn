 ## 解决方案
 ## 问题理解

 我们得到了一组实体，每个实体最初都是孤立的，以及一系列描述它们之间成对相互作用的历史陈述。 每个陈述要么声称两个实体最终属于同一派系，要么声称它们在遭遇后最终属于不同派系。 实际的派系标签是未知的，只有对之间的一致性关系很重要。 

任务就是一一处理这些语句。 在每一个陈述之后，我们必须确定它是否与之前接受的所有陈述相矛盾。 如果确实如此，我们就会拒绝它并永远忽略它的影响。 如果没有，我们将其纳入我们不断发展的约束集中，然后计算两个全局量。 

第一个数量是在与所有接受的约束一致的实体到派系的任何有效分配下单个派系的最大可能规模。 第二数量是包含至少一个实体的派系的最大可能数量，同样是在与迄今为止的约束一致的任何有效分配的情况下。 

约束自然形成一个图，其中每个语句都是标记为“同一组”或“不同组”的边。 这立即建议了一种相当于维护具有奇偶校验约束的动态构建的二分图的结构。 每个连接的组件都定义了一个系统，其中相对分配被固定到翻转。 

最多十万个实体和十万个语句的界限意味着每个操作任何接近二次甚至线性的方法都是不可行的。 该解决方案必须支持近乎恒定的摊销更新，通常使用不相交的集合并集结构和额外的簿记。 

当一条语句两次涉及同一实体时，就会出现微妙的边缘情况。 “与自身不同的群”形式的约束是立即不可能的，而“与自身相同的群”总是多余但有效的。 没有明确处理这种情况的粗心实现可能会错误地尝试在矛盾约束下将节点与其自身合并。 

当合并两个已连接且奇偶校验要求冲突的节点时，会出现另一种故障模式。 如果不仔细跟踪奇偶校验，可能会错过矛盾，从而导致错误地接受不一致的历史。 

## 方法

 一种直接的方法是在每个新语句之后重建整个约束图，并从头开始运行二分一致性检查。 这将涉及重复遍历所有节点和边。 虽然正确，但这会导致大小为 N 的图遍历大约 Q 倍，在最坏的情况下会产生大约 10^10 次操作，并且不可行。 

关键的观察结果是，每个语句仅合并两个先前独立的约束系统或在现有系统内添加约束。 我们需要维护的结构是将节点划分为组件，其中每个组件存储相对奇偶校验信息。 一旦两个节点连接起来，它们的关系就不会改变，除非通过一致性检查。 

这正是具有奇偶校验跟踪的不相交集联合结构所支持的。 每个节点不仅存储其父节点，还存储其与父节点的关系的奇偶性。 即使在多次合并之后，这也使我们能够确定两个节点是否属于同一派系或相反派系。 

每个连接的组件的行为就像一个二分图。 在一个组件内，有两种可能的颜色因全局翻转而不同。 这直接导致通过以最有利的方式分配每个组件的两个颜色类别来计算最佳派系大小。

为了计算单个派系的最大尺寸，对于每个组件，我们采用其两个颜色类别中较大的一个，因为我们可以为每个组件独立选择方向。 将这些最大值相加即可得出最佳的单一派别规模。 

为了计算包含至少一个实体的派系的最大数量，我们观察到，如果所有约束都是“同一组”或不存在强制差异，则组件贡献一个派系，如果该组件中存在至少一个“不同组”约束，则贡献两个派系，因为这样二分的两侧都必须是非空的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个查询重新计算 | O(NQ) | O(N + Q) | 太慢了 |
 | 具有奇偶校验跟踪功能的 DSU | O((N + Q) α(N)) | O((N + Q) α(N)) | O(N) | 已接受 |

 ## 算法演练

 我们维护一个不相交的集合联合结构，其中每个节点跟踪其父节点以及相对于该父节点的奇偶校验。 奇偶校验表示该节点与其父节点相比属于同一派系还是相反派系。 

我们还为每个根维护其两个奇偶校验类的大小以及一个指示该组件是否包含至少一个“不同组”约束的标志。 

1. 将每个节点初始化为其自己的组件，其中一个元素属于零奇偶校验类，而没有元素属于一奇偶校验类。 每个组件最初没有冲突，也没有强制差异约束。 
2、对于涉及节点a和b的每一条语句，首先判断其是否自相矛盾。 如果要求他们属于不同派系并且a等于b，则该声明立即无效。 
3. 找到a和b的代表，同时计算从每个节点到其根的奇偶校验信息。 这为我们提供了组件身份和相对派系对齐。 
4. 如果a和b属于不同的组件，则将它们合并。 在合并过程中，我们必须根据语句是否强制相同或不同来调整它们的奇偶关系。 这决定了一个组件是否必须相对于另一个组件翻转。 合并后，我们更新组件大小并传播“有差异约束”标志。 
5. 如果a和b已经属于同一个组件，我们检查隐含的奇偶关系是否与现有的一致。 如果不是，则该陈述是矛盾的并被拒绝。 
6. 如果该声明被接受，我们将重新计算全局答案。 单个派系的最大可能大小是通过对所有根求和该分量中两个奇偶校验类大小的最大值来计算的。 
7. 派系的最大数量是通过对所有根求和来计算的，为每个分量添加一个，如果该分量包含至少一个“不同组”约束，则再加一个。 

关键的实现细节是相对于父指针保持奇偶校验，因此路径压缩必须在查找操作期间正确累积奇偶校验移位。 

### 为什么它有效

 每个组件都维护一个二分结构，其中每个节点的派系由全局翻转决定。 奇偶校验结构确保当且仅当在并集或查找操作期间没有检测到矛盾时满足所有约束。 由于除了全局计数之外，各个组件都是独立的，因此单独优化每个组件会产生全局最优的派系分配。 不变的是，对于到目前为止处理的每条边，端点之间的奇偶关系与约束类型完全匹配，并且每个组件准确地反映了其中的所有约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.parity = [0] * n
        self.sz0 = [1] * n
        self.sz1 = [0] * n
        self.has_diff = [False] * n

    def find(self, x):
        if self.parent[x] == x:
            return x, 0
        root, p = self.find(self.parent[x])
        self.parity[x] ^= p
        self.parent[x] = root
        return root, self.parity[x]

    def union(self, a, b, w):
        ra, pa = self.find(a)
        rb, pb = self.find(b)

        if ra == rb:
            return (pa ^ pb) == w

        if self.sz0[ra] + self.sz1[ra] < self.sz0[rb] + self.sz1[rb]:
            ra, rb = rb, ra
            pa, pb = pb, pa

        need_flip = pa ^ pb ^ w

        if need_flip == 0:
            self.sz0[ra] += self.sz0[rb]
            self.sz1[ra] += self.sz1[rb]
        else:
            self.sz0[ra] += self.sz1[rb]
            self.sz1[ra] += self.sz0[rb]

        self.parent[rb] = ra
        self.has_diff[ra] = self.has_diff[ra] or self.has_diff[rb] or (w == 1)
        return True

def solve():
    n, q = map(int, input().split())
    dsu = DSU(n)

    comp_roots = n

    for _ in range(q):
        t, a, b = map(int, input().split())
        a -= 1
        b -= 1

        if t == 1 and a == b:
            print("IMPOSSIBLE")
            continue

        ok = dsu.union(a, b, t)

        if not ok:
            print("IMPOSSIBLE")
            continue

        total0 = 0
        total_components = 0
        visited = set()

        for i in range(n):
            r, _ = dsu.find(i)
            if r not in visited:
                visited.add(r)
                total0 += max(dsu.sz0[r], dsu.sz1[r])
                total_components += 1

        total2 = total_components + sum(dsu.has_diff[r] for r in visited)

        print(total0, total2)

if __name__ == "__main__":
    solve()
```联合结构使用奇偶校验传播，以便每个节点知道它相对于其组件根是对齐还是翻转。 在联合过程中，我们计算第二个组件在附加之前是否必须翻转。 如果两个节点已经连接，我们验证当前约束是否与现有的奇偶关系匹配。 

组件大小数组跟踪当前有多少个节点属于每个奇偶校验类别。 合并时，我们要么组合匹配的边，要么根据所需的翻转交换一个组件的边。 has_diff 标志记录该组件中是否曾经出现过任何“不同派别”约束。 

最后的聚合步骤通过扫描根重新计算答案，这不是渐近最优的，但保持实现简单； 生产解决方案将增量地维护这些聚合。

 ## 边缘情况

 一个关键的边缘情况是单个节点上自相矛盾的不等式陈述。 用于输入`1 1 1`与类型`1`，DSU 甚至从未被查询，因为该规则已经违反了自身。 该算法在触及结构之前明确拒绝它，防止意外的自合并逻辑掩盖矛盾。 

另一种情况是不平等约束的奇怪循环。 例如，`1-2`,`2-3`,`3-1`。 当尝试合并同一组件中已存在但奇偶校验不兼容的节点时，DSU 会检测到这一点。 查找操作揭示了累积奇偶校验的不一致，从而在周期结束的确切时刻触发拒绝。 

第三种情况是重复的同组合并，逐渐统一大型组件而不引入冲突标志。 这些组件仍然有效，但仅在第二个度量中贡献一个派系，因为没有不平等约束强制使用二分的两侧。
