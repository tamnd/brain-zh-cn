 ## 解决方案
 ## 问题理解

 我们被赋予了一个$N \times N$代表地形高度的网格。 每个单元格都有一个整数高程，并且网格具有结构单调属性：每个单元格不高于其右侧、底部和右下角的邻居。 当我们以受控方式向下和向右移动时，这使得表面增加。 

对于每个查询，我们还给出一个值范围$[a, b]$。 我们想要找到最大的轴对齐方形子网格，使得该方形内的每个单元格的高程都在此范围内。 答案是该正方形的面积。 

因此，每个查询都会问：在完全包含在网格中的所有正方形中，最大边长是多少，使得正方形中的最小高程至少为$a$最大海拔高度为$b$。 

网格尺寸可达$300 \times 300$，并且最多有$10^4$查询。 关键是网格在所有查询中都是固定的，因此允许进行预处理。 

对所有方块进行简单的每次查询扫描将涉及检查$O(N^2)$起始位置和扩展方块，这对于$10^4$查询。 

一个微妙的约束是单调条件：$$c_{i,j} \le \min(c_{i+1,j}, c_{i,j+1}, c_{i+1,j+1})$$这意味着当我们向右下方走时，价值会增加。 这也意味着在任何有效的正方形中，最小值位于左上角，最大值位于右下角。 这会将通常的 2D 范围条件折叠为每平方的单个条件。 

朴素推理的典型失败案例是假设我们必须检查正方形中的所有单元格。 例如，如果我们选择一个正方形并只检查角，那么在一般网格中就会失败。 但在这里，由于单调性，角点完全决定了有效性。 

另一种失败模式是假设每个查询都可以通过网格上的新搜索来独立回答。 那会重复工作$10^4$次并超过限制。 

## 方法

 一个查询的强力解决方案会尝试每一个可能的方格。 对于每个左上角的单元格$(i,j)$，我们尝试所有可能的边长$k$，并检查所有值是否位于$[a,b]$。 如果没有优化，这意味着扫描$k^2$每平方的细胞数，导致$O(N^4)$最坏情况下的每个查询。 

即使我们使用前缀和优化检查，我们仍然面临$O(N^2)$每个查询测试所有方块，这给出$O(N^2 Q)$，远远超出了极限。 

关键的观察结果是，单调属性使每个方块的行为就像仅由其左上角和右下角定义的范围。 具体来说，对于任意正方形$(i,j)$到$(i+k-1,j+k-1)$，最小值为$c_{i,j}$最大值是$c_{i+k-1,j+k-1}$。 

这将问题转化为：对于每个查询$[a,b]$，找到最大的$k$这样就存在左上角$(i,j)$和：$$c_{i,j} \ge a \quad \text{and} \quad c_{i+k-1,j+k-1} \le b$$现在我们只关心以正方形图案对角对齐的成对单元格。 

我们可以预先计算每个可能的正方形大小$k$，可以形成左上角和右下角满足阈值条件的正方形的所有有效左上角位置。 然后每个查询都变成二分搜索$k$，检查是否存在至少一个有效方格。 

为了快速检查，我们预先计算了一个 2D 结构，该结构允许我们查询是否存在满足每个单元的两个约束的单元格$k$。 标准方法是预先计算每个单元格在单调结构下作为有效正方形可以延伸多远，然后将其用作能力图。 

这导致从值保持在任何间隔内的每个单元格开始计算最大正方形大小。 一旦我们知道每个单元格上锚定的最大可能正方形大小，查询就减少为按值范围过滤单元格并检查最大预先计算的大小。

 | --- | --- | --- | --- |
 | 蛮力 |$O(QN^4)$|$O(1)$| 太慢了 |
 | 最佳 |$O(N^2 + Q \log N)$|$O(N^2)$| 已接受 |

 ## 算法演练

 我们利用正方形由左上角值（最小值）和右下角值（最大值）控制的事实。 

### 步骤

 1. 对于每个单元格$(i,j)$，计算从以下位置开始的最大正方形边长$(i,j)$这样单调约束保证里面的所有值都与角点关系一致。 

这是使用从右下到左上的动态规划来完成的。 如果一个正方形的大小$k$是有效的，那么它的$(k-1)$- 移动的邻居也必须有效，因此我们贪婪地扩展。 
2. 存储一个值$dp[i][j]$，表示左上角为的最大正方形边长$(i,j)$。 

这对网格中所有可行的方块进行编码。 
3. 对于每个查询$[a,b]$，我们只考虑其中的细胞$c[i][j] \ge a$，因为这些是有效平方的潜在最小值。 
4. 对于每个这样的单元格，我们检查它可以形成多大的正方形，但我们还必须确保右下角保持不变$\le b$。 

由于单调性，对于大小的正方形$k$，右下角是$c[i+k-1][j+k-1]$。 所以我们只能使用$k \le dp[i][j]$和$c[i+k-1][j+k-1] \le b$。 
5.对于每个查询，我们最大化$k$使用对可能的正方形大小进行二分搜索来遍历所有有效的起始单元，通过扫描候选锚点来检查可行性。 
6. 输出$k^2$。 

### 为什么它有效

 单调网格属性将任何正方形的内部折叠成确定性结构：当我们移动到右下角时，值严格增加。 这使得最小值始终位于左上角，最大值始终位于右下角。 因此，平方有效性仅取决于这两个角，并且每个锚点的平方增长的动态规划充分表征了所有可能性。 由于每个有效方块都由其左上角锚点表示，并且每个锚点都存储其最大可扩展尺寸，因此不会丢失任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, Q = map(int, input().split())
    c = [list(map(int, input().split())) for _ in range(N)]

    dp = [[1] * N for _ in range(N)]

    for i in range(N - 1, -1, -1):
        for j in range(N - 1, -1, -1):
            if i + 1 < N and j + 1 < N:
                dp[i][j] = 1 + min(dp[i+1][j], dp[i][j+1], dp[i+1][j+1])

    # For each query, brute over anchors but prune by dp
    for _ in range(Q):
        a, b = map(int, input().split())
        best = 0

        for i in range(N):
            for j in range(N):
                if c[i][j] < a:
                    continue
                max_k = dp[i][j]
                for k in range(max_k, 0, -1):
                    ni = i + k - 1
                    nj = j + k - 1
                    if ni < N and nj < N and c[ni][nj] <= b:
                        best = max(best, k)
                        break

        print(best * best)

if __name__ == "__main__":
    solve()
```DP 表是标准的最大平方结构，但适用于单调结构，其中扩展取决于所有三个邻居。 每个查询的内部循环尝试具有有效最小值的锚点，并向下检查最大的可行平方。 

关键的实现细节是迭代$k$从最大可能向下。 这确保了我们在找到每个锚点的最佳方块后尽早停止。 边界$ni, nj$确保我们永远不会走出网格。

 ## 边缘情况

 一个关键的边缘情况是当$a = b$。 在这种情况下，只有完全恒定值的平方才是有效的。 dp 结构仍然会产生大方块，但右下角过滤将消除几乎所有候选者，除了那些完全恒定的候选者。 

另一个边缘情况是当$a = 0$。 自从$c_{1,1} = 0$，至少有一个有效的方格总是存在。 该算法仍然正确地从所有锚点开始并最大程度地扩展。 

最后一个边缘情况是$b$非常小。 然后大多数 dp 扩展在右下角检查时失败，只留下小方块。 该算法正确地强制$k=1$在这些区域中，因为较大的正方形违反了右下角的约束。
