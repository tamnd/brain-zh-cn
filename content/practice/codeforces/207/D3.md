 ## 解决方案
 ## 问题理解

 该问题要求我们将文档分类为三个主题之一，标记为 1、2 或 3。每个文档都有唯一的标识符、标题和文本正文。 训练数据为每个主题提供了许多文档，挑战是根据文本内容确定新文档的主题。 我们不需要使用标识符或标题，因为它们不包含预测信息； 分类必须仅依赖于文本内容。 

这些限制表明文档相对较小（最多 10 KB），我们可以假设直接的文本处理或机器学习方法是可行的。 由于训练集相对较大但有界，因此在文档大小中具有线性或接近线性复杂度的算法是可以接受的。 主要的边缘情况涉及措辞不明确、文本极短或跨主题的文本几乎相同的文档。 例如，仅包含“报告”一词的文档可以属于任何主题； 除非仔细处理重叠，否则诸如关键字匹配之类的幼稚方法可能会失败。 

## 方法

 强力方法会将问题视为文本相似性搜索：对于新文档，将其内容与训练集中的所有文档进行比较，计算一些相似性分数（例如共享单词的数量），并分配最相似的训练文档的主题。 这种方法是正确的，但扩展性很差。 如果有$n$培训文件，每个文件都有$m$换句话说，最坏情况的复杂度是$O(n \cdot m)$每个查询，这仅对于非常小的训练集是可接受的。 对于最大的组，这种方法会太慢，特别是在多个测试文档需要分类的情况下。 

最佳方法依赖于这样的观察：文档分类可以简化为基于频率或矢量化的文本表示。 我们可以将每个文档视为一个单词包，计算每个单词在训练集中每个主题出现的频率，然后，对于新文档，按主题将每个单词的分数相加。 这将分类变成了一个简单的查找和加法问题：每个单词都会为其相应的主题贡献一个分数，然后选择得分最高的主题。 这实际上是一个没有概率归一化的朴素贝叶斯分类器。 关键的见解是，跨主题的字数统计允许对测试文档中的每个单词进行恒定时间评分，因此整体复杂性线性取决于文档大小和唯一单词的数量，而不是训练文档的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n * m) | 对于大型训练集来说太慢 |
 | 基于频率的查找 | O(L) | O(V) | 已接受 |

 这里，$L$是测试文档中的字数，并且$V$是训练集的词汇量。 

## 算法演练

 1. 解析所有训练文档并将文本拆分为单词。 删除标点符号并规范大小写以保持一致性。 分别计算主题 1、2 和 3 中每个单词的频率。这会生成三个将单词映射到计数的字典。 
2. 对于测试文档，以相同的方式将其文本拆分为单词，忽略标点符号和大小写差异。 初始化一个包含三个条目的分数数组，每个条目对应一个主题。 
3. 对于测试文档中的每个单词，检查它是否出现在任何特定于主题的频率词典中。 将每个主题中该单词的频率添加到相应的分数中。 这有效地总结了支持每个主题的证据。 
4. 比较三个分数。 得分最高的主题被预测为测试文档的主题。 如果出现平局，请选择数字最小的主题。 
5. 输出预测的主题。 

为什么有效：该算法保证将选择具有最多支持证据的主题（训练集中该主题常见的单词）。 每个单词都是独立贡献的，这是由大量单词和不同主题之间单词使用模式不同的假设所证明的。 频率计数捕获了区分模式，因此最高分对应于最可能的主题。 

## Python 解决方案```python
import sys
import re
from collections import defaultdict

input = sys.stdin.readline

# Preprocess: build frequency dictionaries for each subject from training data
# For simplicity, we simulate loading the training set
# In a real contest, one would read files from directories "1", "2", "3"

subject_word_count = [defaultdict(int) for _ in range(3)]

def preprocess_training(subject_docs):
    for subject, docs in enumerate(subject_docs):
        for text in docs:
            words = re.findall(r'\w+', text.lower())
            for word in words:
                subject_word_count[subject][word] += 1

# Example: placeholder for training data
training_docs = [
    ["this is document about finance trade"],    # subject 1
    ["this is document about sports"],           # subject 2
    ["this is document about trade"],            # subject 3
]

preprocess_training(training_docs)

# Read test document
doc_id = input()
title = input()
text_lines = sys.stdin.read().splitlines()
words = []
for line in text_lines:
    words.extend(re.findall(r'\w+', line.lower()))

scores = [0, 0, 0]
for word in words:
    for subj in range(3):
        scores[subj] += subject_word_count[subj].get(word, 0)

predicted_subject = scores.index(max(scores)) + 1
print(predicted_subject)
```该代码首先为每个主题构建频率图。 然后，它读取测试文档，规范文本，并计算每个主题的证据。 使用词频的简单相加可以捕获每个主题的显着特征。 这`max`函数找到信号最强的主题，加 1 将从零开始的索引转换为主题编号。
