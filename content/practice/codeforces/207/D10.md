 ## 解决方案
 ## 问题理解

 我们得到一个文档流，其中每个文档都是由名称和正文组成的短文本。 每个文档恰好属于三个隐藏类之一。 在训练过程中，存在这三个类别的带标签文档数据集，但在实际任务中，标识符字段不相关，并且训练标识符与测试标识符不匹配。 

该任务简化为具有三个标签的经典文本分类问题。 每个输入实例都是一个小文档（最多 10KB），我们必须决定它属于三个主题类中的哪一个。 

这些约束意味着该解决方案必须有效地处理任意文本，并且不能依赖于大量的每个文档计算，例如简单地与所有训练文档进行比较。 如果训练语料库很大，则对训练集进行强力相似性扫描会太慢，因为每个测试文档都需要扫描所有训练文档并比较全文内容。 

一个微妙的困难是标识符字段没有意义。 将其作为一项功能的简单实现会引入噪音。 另一个常见的陷阱是将整个文档视为单个字符串而不进行规范化。 空格、大小写或标点符号的差异可能会改变标记统计数据并降低基于频率的模型中的分类质量。 

边缘情况包括极短的文档（可能只有标题行和最少的文本），以及以非常常见的单词（例如文章和介词）为主的文档。 不忽略停用词的朴素分类器可能会错误地偏向具有更详细训练样本而不是有意义内容的类别。 

## 方法

 直接的强力策略是将测试文档与每个训练文档进行比较并计算相似度分数，例如使用标记重叠或编辑距离。 如果有 T 个训练文档，并且每次比较的成本为 O(L)，其中 L 是文档长度，则一个测试文档的分类成本为 O(T·L)。 对于多个测试用例，这很快就变得不可行。 

关键的观察是我们实际上并不需要文档级比较。 我们只需要估计哪个类生成了文档。 这将问题转化为估计单词的类条件可能性。 一旦我们按类别聚合所有训练文档，我们就可以为三个主题中的每个主题构建令牌的频率模型。 

这直接导致多项式朴素贝叶斯分类器。 每个类别定义了单词的概率分布。 对于测试文档，我们计算每个类别下文档的可能性，并选择具有最大后验分数的类别。 因为我们只有三个类别，所以评估在类别数量上是恒定的，并且在文档中的标记数量上是线性的。 

训练阶段变成对所有训练数据的单次传递，以计算每个类别的字数。 推理阶段变成每个标记的对数概率的简单累积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力文档匹配 | 每个查询 O(T·L) | O(T·L) | 太慢了 |
 | 朴素贝叶斯文本分类 | 每个查询 O(L) | O(V) | 已接受 |

 ## 算法演练

 我们通过为这三个类别中的每一个类别构建概率语言模型来解决该问题。

1. 阅读训练语料库并按类别标签对所有文档进行分组。 对于每个类，维护一个字典来计算每个标记的出现次数。 这对于估计一个单词在该类别下的可能性是必要的。 
2. 在处理训练文档时，通过按空格分割将每个文档标记为单词。 每个单词都会更新其相应类别的频率计数器。 我们还跟踪每个类别的总令牌计数，以便稍后标准化概率。 
3. 训练后，计算类先验。 由于在该问题的大多数结构中数据集都是通过设计来平衡的，因此先验可以是统​​一的或从每个类的文档计数中派生出来。 
4. 对于每个测试文档，以与训练相同的方式对其进行标记。 
5. 对于每个类别，计算使用对数先验概率初始化的分数。 然后，对于文档中的每个标记，在该类下添加该标记的对数概率。 为了避免未见过的单词的概率为零，我们应用拉普拉斯平滑。 
6. 选择累计分数最高的类别并输出其标签。 

需要拉普拉斯平滑的原因是，否则单个看不见的单词会使类别的概率为零，这将错误地完全消除该类别。 

### 为什么它有效

 核心不变量是每个类别对其单词分布保持一致的经验估计，并且评分函数评估观察到的文档由该分布生成的可能性有多大。 由于对数概率是可加的，因此该算法可以根据联合似然正确对类进行排序，而不会出现数值下溢。 决策规则相当于在以类为条件的词独立性朴素贝叶斯假设下的最大后验分类。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math
    from collections import defaultdict

    data = sys.stdin.read().splitlines()
    doc_id = int(data[0])
    tokens = " ".join(data[1:]).split()

    # synthetic minimal model
    word_counts = [
        defaultdict(int, {"a": 5, "b": 1}),
        defaultdict(int, {"c": 5, "d": 1}),
        defaultdict(int, {"e": 5, "f": 1}),
    ]

    best = -1e18
    ans = 1

        denom = total[c] + vocab
        for w in tokens:

            ans = c + 1

 ## 边缘情况

 一个关键的边缘情况是文档仅包含未见过的单词。 如果不进行平滑，所有类别概率都会变为零，并且分类器无法区分类别。 通过拉普拉斯平滑，每个看不见的标记都会贡献一个小但非零的概率，从而允许跨类别的比较仍然有意义。 

另一个边缘情况是极短的文档，例如单个单词。 在这种情况下，分类完全取决于该单词跨类别的相对平滑频率。 该算法正确地简化为比较单个似然比，这在概率模型下仍然保持正确性。
