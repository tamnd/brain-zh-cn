 ## 解决方案
 ## 问题理解

 我们得到了一组孩子，每个孩子都从一定量的糖开始。 旁边是一组事件，每个孩子一个事件。 每个事件都涉及两个子事件：事件的所有者和另一个固定的“参考”子事件。 

当一个事件执行时，我们比较这两个孩子当前的糖含量。 如果事件的所有者当前的糖含量严格低于所引用的孩子，则所有者将获得固定的奖金。 否则什么也不会发生。 关键的复杂性在于，所有事件都以统一的随机顺序执行，因此较早的事件可能会以不平凡的方式改变未来的比较。 

任务是为每个孩子计算处理所有事件后预期的最终糖量，并输出对大质数取模的结果。 

约束足够大，任何模拟事件顺序的方法都是不可能的。 每次测试多达 50 万名儿童，并且事件数量相同，即使是单个测试$O(n \log n)$如果不小心重复，每个测试的解决方案将处于边缘状态，并且任何探索排列或试图明确推理事件顺序的内容都会立即被排除。 该解决方案必须将排序的随机性减少为封闭形式的概率计算或非常结构化的依赖关系。 

如果尝试按输入顺序模拟或贪婪地处理事件，则会立即出现一种微妙的故障模式。 实际的执行顺序是随机的，因此任何确定性遍历都会给出完全不同的中间状态。 例如，如果两个事件通过比较相互依赖，交换它们的顺序可能会翻转是否触发奖励，因此固定顺序的天真评估会产生与预期不符的有偏差的结果。 

另一个常见的陷阱是假设事件之间是独立的。 如果事件$i$取决于孩子的糖分$b_i$，而那个孩子的糖分取决于其他事件，那么事件的结果$i$与那些较早的事件是否出现在它之前相关。 将这些视为独立概率会导致错误的聚合。 

## 方法

 暴力策略将枚举所有$n!$事件顺序的排列，模拟每一个，并对结果进行平均。 即使我们乐观地将模拟减少到$O(n)$根据订购，这变成$O(n \cdot n!)$，这是完全不可行的。 即使采样也不会通过，因为所需的精度是精确模素数。 

关键的结构观察是每个事件仅取决于涉及两个子事件的比较：事件自己的子事件和固定的参考子事件。 此外，事件只会增加糖分，而不会减少糖分。 这意味着唯一的不确定性来自于在随机排列中发生给定事件之前两个涉及的孩子中的每一个收到多少奖励更新。 

这将问题转换为有关相对顺序而不是完整排列的推理。 特别是对于任何事件$i$，仅影响任一孩子的事件$i$或孩子$b_i$对其比较很重要。 这种依赖关系形成了一个函数图，其中每个节点都指向另一个节点，因此该结构分解为树，馈入有向循环。 

在每个连接的结构内部，随机排列会产生对称排序，该排序可以分解为成对排序概率。 这种对称性消除了显式跟踪复杂的更新级联的需要：只有相对顺序才重要，而且这些顺序是统一的。 

一旦进行了这种减少，每个事件的预期贡献就变成了局部表达式，仅取决于初始值是否相等或严格排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 |$O(n \cdot n!)$|$O(n)$| 太慢了|
 | 对称性+成对概率降低|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 一旦我们了解随机性如何影响比较，最终的计算就会减少为独立评估每个事件。 

1. 对于每个孩子$i$，识别其事件$i$，比较孩子$i$带着孩子$b_i$。 我们只需要了解比较条件在当前事件为真的可能性有多大$i$以随机排列执行。 
2. Observe that since all events are placed in a uniformly random order, the relative order between event$i$和事件$b_i$在任一方向上都有相同的可能性。 这给出了基线概率$1/2$一个出现在另一个之前。 
3. 对比较唯一的确定性影响是初始糖值$a_i$和$a_{b_i}$，因为任何早期事件在随机排序下都会对称地影响双方。 
4. 如果$a_i < a_{b_i}$，那么即使在任何随机性影响之前，比较也已经有利于在大多数排序中触发，因此事件以概率触发$1$。 
5. 如果$a_i > a_{b_i}$，对称性意味着没有排序偏差可以逆转期望中的严格优势，因此事件永远不会对期望做出贡献。 
6. 如果$a_i = a_{b_i}$，双方都没有结构优势，随机排序使得触发条件恰好有一半的时间成立。 
7. 乘以每个事件的权重$w_i$通过其触发概率并将其添加到初始值$a_i$以获得预期的最终值。 

### 为什么它有效

 随机排列使任何一对事件的相对顺序统一。 由于每次更新仅影响比较的一个端点，并且所有更新都是相加的，因此任何更深的依赖链都会由于对称性而在预期中抵消：循环或依赖链中的任何节点都无法系统地获得比另一个节点更早的优势。 这将系统折叠成仅由初始排序确定的成对比较，在排列平均下保持不变。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
INV2 = (MOD + 1) // 2

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    w = list(map(int, input().split()))
    
    ans = a[:]
    
    for i in range(n):
        j = b[i] - 1
        
        if a[i] < a[j]:
            ans[i] = (ans[i] + w[i]) % MOD
        elif a[i] == a[j]:
            ans[i] = (ans[i] + w[i] * INV2) % MOD
        else:
            pass
    
    print(*ans)
```该实现直接对每个事件应用概率分类。 唯一的微妙之处是处理相等的情况，其中概率为$1/2$，使用二的模逆来实现。 

每个事件都是独立处理的$O(1)$，因此总复杂度与输入大小保持线性关系。 

重要的设计选择是避免对事件顺序进行任何模拟。 整个随机性被吸收到基于初始值的简单案例区分中。

## 测试用例```python
import sys, io

MOD = 10**9 + 7
INV2 = (MOD + 1) // 2

def solve():
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        w = list(map(int, input().split()))
        ans = a[:]
        for i in range(n):
            j = b[i] - 1
            if a[i] < a[j]:
                ans[i] = (ans[i] + w[i]) % MOD
            elif a[i] == a[j]:
                ans[i] = (ans[i] + w[i] * INV2) % MOD
        out.append(" ".join(map(str, ans)))
    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

 ## 边缘情况

 最小的单子系统暴露了基本行为。 和$n = 1$，事件将孩子与自身进行比较，因此相等成立，并且事件在期望中贡献了其权重的一半。 该算法正确地应用了相等规则，产生$a_1 + w_1 / 2$。 

在双节点对称交换中，两个子节点以相同的初始值相互比较。 每个事件都有概率触发$1/2$，与有序对称性无关。 该算法干净地处理了这个问题，因为两个比较都属于相等分支。 

在严格有序的一对中，其中$a_i < a_j$，即使引用指针形成环，分类也仅取决于初始比较。 该算法分配概率为 1，符合这样的事实：没有对称随机更新序列可以逆转最初引入的确定性排序偏差。
