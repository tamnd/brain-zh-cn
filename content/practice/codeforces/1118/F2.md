 ## 解决方案
 ## 问题理解

 我们有一棵树$n$顶点。 每个顶点都用以下之一着色$k$颜色或保持未着色。 这棵树是相连的，所以有$n-1$边缘。 我们被要求准确选择$k-1$边缘并删除它们，将树分成$k$成分。 如果没有组件包含不同颜色的顶点，则边的子集被认为是_nice_。 无色顶点可以自由地连接任何有色组件。 

输入提供$n$,$k$，每个顶点的颜色（0表示无色），以及$n-1$定义树的边。 输出是良好子集总数的模$998244353$。 

约束条件允许$n$最多$3 \cdot 10^5$和$k$最多$n$。 暴力枚举所有$\binom{n-1}{k-1}$边缘子集是不可行的，因为它可能超过$10^{20}$。 因此，该解决方案必须在线性或近线性时间内运行$n$。 

当某种颜色的所有顶点都是叶子时，当多种颜色共享一条路径时，或者当无色顶点出现在有色顶点之间时，就会出现边缘情况。 天真地分割树而不检查组件是否只包含一种颜色会导致计算过多。 例如，在颜色为 1-0-2 的三个顶点链中，删除中间边缘会在一侧产生两个具有不同颜色的组件，这是无效的。 

## 方法

 蛮力方法尝试了所有方法$\binom{n-1}{k-1}$边缘子集，检查连通性，并验证每个组件中的颜色约束。 这对于小树来说是正确的，但对于$n \sim 10^5$。 

更快解决方案的关键见解来自于观察，在一个好的子集中，连接不同颜色的顶点的边不能保留在同一组件中。 同样，必须切割连接不同颜色顶点的边。 因此，我们可以将禁止边标记为连接两种不同颜色的边，并将有效边计数为连接相同颜色或至少一个未着色顶点的边。 一个好的子集只是一个选择$k-1$来自不违反分色的有效边缘的边缘。 

这使我们能够使用单个 DFS 来识别仅连接一种颜色或未着色顶点的边来解决该问题。 一旦连接不同颜色的边被排除，剩余的边形成独立的链，其中任何选择$k-1$不合并不同颜色的边是有效的。 使用组合学和模运算，我们可以有效地计算所有有效选择。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((n-1 选择 k-1) * n) | O(n) | 太慢了 |
 | DFS + 组合学 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将树表示为邻接表。 存储每个顶点的颜色，其中 0 表示无色。 
2. 从任意顶点执行DFS。 在每个顶点，记录其子树是否包含给定颜色。 这使我们能够识别连接两种不同颜色的边缘。 
3. 如果每条边的端点包含不同的非零颜色，则将其标记为_forbidden_​​。 必须在任何好的子集中删除这些边缘。 
4. DFS之后，剩余的边连接相同颜色的顶点或未着色的顶点。 所有好的子集都必须包含所有禁止边，因为需要删除它们才能分离颜色。 
5. 计算所有_有效_（未禁止）的边。 可供选择的方式数量$k-1$要删除的边等于每个颜色子树中边的选择数量的乘积。 
6. 使用模运算来计算结果模$998244353$。 如果二项式系数需要组合公式，请预先计算阶乘。 
7. 输出最终计数。 

**为什么有效：** DFS 不变量确保对于每条边，我们都知道它是否连接多种颜色。 准确去除$k-1$避免合并不同颜色的边，相当于只从允许的位置选择边，这保证了每个组件都包含单一颜色的顶点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

MOD = 998244353

def main():
    n, k = map(int, input().split())
    colors = list(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    for _ in range(n-1):
        u, v = map(int, input().split())
        adj[u-1].append(v-1)
        adj[v-1].append(u-1)

    # Mark edges that are "forbidden" (connect different colors)
    is_forbidden = [False] * (n-1)
    edge_index = {}
    idx = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                edge_index[(u, v)] = idx
                idx += 1

    def dfs(u, parent):
        # set of colors in subtree
        subtree_colors = set()
        if colors[u] != 0:
            subtree_colors.add(colors[u])
        for v in adj[u]:
            if v == parent:
                continue
            child_colors = dfs(v, u)
            # if both sides have different non-zero colors, mark edge forbidden
            if colors[u] != 0 and child_colors & {colors[u]} == set():
                e = (u, v) if u < v else (v, u)
                is_forbidden[edge_index[e]] = True
            subtree_colors |= child_colors
        return subtree_colors

    dfs(0, -1)

    # Count valid edges
    result = 1
    for forbidden in is_forbidden:
        if not forbidden:
            result = (result * 2) % MOD

    print(result)

if __name__ == "__main__":
    main()
```DFS 正确识别连接不同颜色的边。 然后我们计算好的子集的数量为$2^{\text{number of valid edges}}$模数$998244353$。 乘以 2 代表每个有效边的两个选择：保留它或删除它。
