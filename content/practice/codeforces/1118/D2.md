 ## 解决方案
 ## 问题理解

 波利卡普必须写一份课程作业：`m`页数，但如果没有咖啡因，他就无法无限期地工作。 他有`n`一杯咖啡，每杯都含有咖啡因剂量`a_i`。 他每天可以喝任意几杯，但同一天喝的越晚，每杯对生产力的贡献就越小。 具体来说，一天的第一杯咖啡可以让他写下`a_i`页数，第二个杯子`max(0, a_i - 1)`页，第三页`max(0, a_i - 2)`， 等等。 目标是尽量减少完成课程所需的天数。 

输入约束很大：`n`可以达到`2 * 10^5`和`m`最多`10^9`。 这立即排除了任何尝试所有可能的每日咖啡杯分组的蛮力方法，因为存在指数级的可能性`n`。 每个咖啡因值也可以很大，高达`10^9`，因此必须小心避免累积和中的整数溢出。 

主要的微妙之处在于每日收益递减。 例如，如果 Polycarp 有含有咖啡因的杯子`[3, 1, 2]`如果他想在一天内完成课程作业，他必须将杯子从高到低排序，以最大化所写的页数：一天的输出是`3 + max(0,2-1) + max(0,1-2)=3 + 1 + 0 = 4`。 一个天真的贪婪者如果不每天对杯子进行分类，可能会低估生产力。 当杯子太少而无法到达时，就会出现另一种边缘情况`m`页数，即使每个杯子是在不同的一天饮用的：`[1,1,1]`和`m=5`，答案是`-1`。 

## 方法

 蛮力方法是尝试将杯子的所有分区分成几天，并检查是否有任何安排至少允许写入`m`页。 这在理论上是正确的，但分区数量呈指数增长`n`，所以这对于`n`最多`2 * 10^5`。 

一个关键的观察是，为了尽量减少天数，每天应该增加写的页数。 一天之内，应先饮用较大的咖啡因杯，因为较早的杯子效果更佳。 这使得一天的生产力可以计算为以下总和`max(0, a_i - j)`在排序列表上，其中`j`是当天杯子的从零开始的指数。 

然后问题简化为决策问题：给定`d`天，波利卡普能完成吗`m`如果我们以最佳方式分配杯子？ 可以通过按降序对咖啡因杯进行排序，然后对每天的页数进行求和（假设每天都有每个咖啡因杯）来有效地回答这个问题。`d`第-个杯子（以便第一天在位置获得杯子`0, d, 2d,...`, 第二天`1, 1+d, 1+2d,...`等等）。 这确保了杯子被分配到天数，以最大限度地提高每日生产力，同时考虑到收益递减。 一旦我们可以检查给定的可行性`d`，二分查找`d`给出最小天数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最优（二分搜索+贪婪）| O(n log n + n log n) = O(n log n) | O(n log n + n log n) = O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将所有咖啡杯按咖啡因含量降序排列。 这确保了在任何一天中，最有生产力的杯子都会首先被消耗。 
2. 定义函数`can_finish(days)`这决定了是否至少可以写`m`页面在`days`天。 在此函数内，迭代每天的索引`i`从`0`到`days-1`。 
3. 一天`i`, 总页数为`sum(max(0, cups[i + j*days] - j) for j in range(...))`。 这里`i + j*days`为指定日期的杯子编制索引`i`在位置`j`，跳过分配给前几天的杯子。 这种分配遵循收益递减的原则，因为`j`增加处罚。 
4. 如果所有天的累计页数至少为`m`，返回真。 否则，返回 False。 
5. 应用二分查找`d`从`1`到`n`。 如果`can_finish(d)`是真的，尝试更小`d`尽量减少天数； 如果为假，则增加`d`。 
6. 如果没有足够的天数可以完成课程作业，则输出`-1`。 否则，输出最小的`d`成立。 

这是有效的，因为对杯子进行排序可以保证最早使用生产率最高的杯子，并且以循环方式分配杯子`d`在收益递减规则下，days 最大化每天的产出。 不变的是，对于任何分配，在当天早些时候移动更高咖啡因的杯子不能减少总页数，因此贪婪分配实现了固定的最大可能页数`d`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_finish(cups, days, m):
    total = 0
    n = len(cups)
    for i in range(days):
        j = 0
        while i + j * days < n:
            total += max(0, cups[i + j * days] - j)
            j += 1
            if total >= m:
                return True
    return total >= m

def main():
    n, m = map(int, input().split())
    cups = list(map(int, input().split()))
    cups.sort(reverse=True)

    left, right = 1, n
    answer = -1
    while left <= right:
        mid = (left + right) // 2
        if can_finish(cups, mid, m):
            answer = mid
            right = mid - 1
        else:
            left = mid + 1
    print(answer)

if __name__ == "__main__":
    main()
```该解决方案首先对咖啡杯进行分类，以最大限度地提高早期生产力。 辅助函数通过在几天内循环分配杯子来模拟收益递减。 二分搜索可确保有效找到最小可行天数。 关键的微妙之处包括使用`max(0, ...)`处理惩罚超过咖啡因时没有任何贡献的杯子，以及循环索引计算`i + j*days`。 

## 工作示例

 样本1：`5 8`和`cups=[2,3,1,1,2]`。 

| 日 | 杯子选择| 写页数 | 累计|
 | --- | --- | --- | --- |
 | 1 | 3 | 3 | 3 |
 | 2 | 2,5 | 2+(2-1)=3 | 6 |
 | 3 | 1,4| 2+(1-1)=2 | 8 |

 答：4天。 循环分配确保没有一天超过最大生产力。 

样本2：`3 5`和`cups=[1,1,1]`。 

| 日 | 杯子选择| 写页数 | 累计|
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 |
 | 2 | 1 | 1 | 2 |
 | 3 | 1 | 1 | 3 |

 答案：-1。 即使单独使用每个杯子，`m=5`无法到达。
