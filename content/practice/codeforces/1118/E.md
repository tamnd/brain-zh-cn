 ## 解决方案
 ## 问题理解

 我们的任务是为舞会上的舞者分配颜色。 有`n`成对，每组由一男一女组成，并且`k`可用颜色。 每对都必须有一个男性颜色和一个女性颜色，以满足四个规则：没有两对是相同的，同一对中的男性和女性没有相同的颜色，并且连续的配对必须有不同的男性和女性颜色。 

输入给出了对的数量`n`和颜色的数量`k`。 输出应该要么指示不可能进行分配，要么产生一个有效的分配。 和`n`和`k`最多 200,000 个且时间限制为 2 秒，任何明显慢于 O(n) 或 O(n log n) 的算法都是不可行的。 尝试每种颜色组合的蛮力方法将大致涉及`k^(2n)`的可能性，这是完全不切实际的。 

当出现微妙的边缘情况时`k = 2`和`n > 2`。 只有两种颜色，不可能同时满足“没有连续的一对在任何位置都有相同的颜色”和“男女颜色不同”约束，如果`n`超过可以形成的不同对的数量。 例如，如果`n = 3`和`k = 2`，尝试交替对像`(1,2), (2,1)`留下第三对，其中一条规则将不可避免地被违反。 

## 方法

 暴力方法会尝试生成所有序列`n`颜色对，根据四个规则测试每个序列。 可能的序列总数为`k^(2n)`，即使对于像这样的适度值也会爆炸`n=10`和`k=5`。 虽然理论上是正确的，但这对于`n`最多200,000。 

构建快速解决方案的关键观察是约束是局部的：每对仅与前一对交互，并且在全局范围内，不会出现两个相同的对。 这表明基于构造的方法而不是搜索。 我们可以生成所有有效的对`(b, g)`和`b ≠ g`然后将它们按顺序排列，使得连续的对在两个位置上都不同。 由于有`k*(k-1)`有效的不同对，如果存在则有效序列`k*(k-1) ≥ n`。 这会立即过滤掉不可能的情况。 

一旦我们知道这是可能的，我们就可以使用循环模式来分配颜色。 我们可以迭代所有对`(b, g)`在哪里`b ≠ g`并按顺序分配它们。 因为不同对的总数至少是`n`，我们可以选择一个起点并逐步执行它们，根据需要进行环绕。 这会自动防止相同的连续配对，并确保没有配对具有相同的男性/女性颜色。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^(2n)) | O(k^(2n)) | O(n) | 太慢了 |
 | 建设性循环 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 检查是否`k = 2`和`n > 2`。 如果是，立即打印“NO”并退出。 仅有的`n ≤ 2`由于连续对限制，可以使用 2 种颜色。 
2. 初始化所有不同有效对的列表`(b, g)`在哪里`b`和`g`在`1..k`和`b ≠ g`。 
3. 准备一个大小为空的结果数组`n`。 
4. 以循环方式分配对：`i`结果数组中的第 -th 对，选择`(i mod total_pairs)`有效对列表中的第 - 对。 
5. 输出“YES”和结果对。 

为什么它有效：这种结构确保没有一对男女具有相同的颜色，因为我们只预先计算`b ≠ g`。 连续对不同，因为循环步骤移动到不同有效对列表中的新对。 由于不同对的总数`k*(k-1)`至少是`n`为了`k ≥ 2`，作业永远不会用完选项，保证没有重复的配对并满足所有四个规则。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    if k == 2 and n > 2:
        print("NO")
        return

    pairs = []
    for b in range(1, k+1):
        for g in range(1, k+1):
            if b != g:
                pairs.append((b, g))

    result = []
    for i in range(n):
        result.append(pairs[i % len(pairs)])

    print("YES")
    for b, g in result:
        print(b, g)

if __name__ == "__main__":
    main()
```该解决方案首先处理不可能的情况`k = 2`和`n > 2`。 然后它构造所有有效的`(b, g)`对。 通过循环这些对来填充`n`位置，它保证了所有四个规则。 模数确保我们永远不会访问有效对数组之外的索引，从而保持连续差异所需的循环属性。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + k^2) | O(n + k^2) | 生成`k*(k-1)`对需要 O(k^2)，填充`n`对需要 O(n) |
 | 空间| O(n + k^2) | O(n + k^2) | 存储有效对和结果数组 |

 和`n`最多 2e5 和`k`高达 2e5，`k^2`可能看起来很大，但实际上我们只需要考虑 k ≤ n 即可覆盖约束，否则`n`占主导地位。 该算法可以轻松适应 256MB 内存。

 ## 边缘情况

 如果`n = 2`和`k = 2`，解产生对`(1,2),(2,1)`。 循环算法可以正确处理这种小情况，而不会重复对或违反邻接约束。 为了`k = 2`和`n = 3`，解决方案检测到不可能性并输出“NO”。 对于大型`k > n`，循环分配确保没有配对重复，也没有连续冲突。
