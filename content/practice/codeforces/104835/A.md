 ## 解决方案
 ## 问题理解

 我们收到了几份独立的面包店订单。 每个顺序描述了一层堆栈，其中第一层具有一定的初始厚度，接下来的每一层都比前一层厚一个单位。 一旦我们知道了第一个厚度和使用了多少层，结构就完全确定了。 

对于每个订单，我们需要计算整个堆栈的总厚度，即所有层厚度的总和。 与其考虑抽象序列，不如将其视为一个算术级数，我们对从$L$，每一步增加 1，并且有$N$条款。 

约束非常小，最多有 100 个测试用例，值为$L$和$N$最多 1000。这意味着每个测试用例在恒定时间内运行的任何解决方案都足够快，甚至$O(N)$每个测试用例模拟仍然是可以接受的，因为操作总数最多为$10^5$，这在 Python 中是微不足道的。 

需要注意的主要边缘情况是只有一层时。 在这种情况下，答案很简单$L$，因为没有发生增量。 另一个角落是当$N$相对于$L$，但仍在范围内，其中必须小心地进行算术求和以避免不必要的循环，即使这里仍然是安全的。 

## 方法

 计算答案的一种直接方法是显式构造每个层的厚度并对它们求和。 对于给定的测试用例，我们将从$L$，然后重复加1生成下一层，继续这个过程$N$次数，同时累加总数。 这是有效的，因为它直接遵循问题的定义。 问题不在于正确性，而在于效率思维：这种方法与$N$，意味着每个测试用例的成本$O(N)$运营。 和$T = 100$和$N = 1000$，这最多是$10^5$添加，这仍然没问题，但考虑到序列的结构，这是不必要的工作。 

关键的观察是该序列是一个算术级数。 我们可以使用算术序列之和的公式来代替模拟。 第一项是$L$，最后一项是$L + (N - 1)$，并且有$N$条款。 所以总和是：$$\text{sum} = \frac{N}{2} \cdot (2L + (N - 1))$$这将每个测试用例减少为恒定时间计算，完全消除了迭代。 The correctness comes from standard properties of arithmetic series, and the structure of the problem guarantees no deviation from this pattern.

 ## 算法演练

 我们使用算术级数公式独立计算每个测试用例。 

1.读取测试用例数量$T$。 这设置了我们必须处理多少个独立序列。 
2. 对于每个测试用例，请阅读$L$和$N$，定义序列的起点和长度。 
3.如果$N = 1$， 返回$L$立即，因为只有一层并且不会发生进展。 
4. 否则，使用以下公式计算总和$N \cdot (2L + (N - 1)) // 2$。 这是有效的，因为从开始到结束的配对项总是产生相同的总和。 
5. 输出每个测试用例的计算值。 

### 为什么它有效

 每个序列在每一步都严格加 1，这保证了它形成一个差值为 1 的算术级数。在这样的序列中，可以通过将第一项和最后一项、第二项和倒数第二项配对来重写总和。 每对都有相同的总和$2L + (N - 1)$，并且正好有$N/2$这样的对（整数处理涵盖偶数和奇数情况）。 无论大小如何，这个不变量都成立$L$或者$N$，确保公式始终匹配序列的直接和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        L, N = map(int, input().split())
        # sum of arithmetic progression: L + (L+1) + ... + (L+N-1)
        # = N * (2L + (N-1)) / 2
        total = N * (2 * L + (N - 1)) // 2
        print(total)

if __name__ == "__main__":
    solve()
```该解决方案读取所有测试用例并直接应用封闭式公式。 乘法在除法之前完成，以保留整数运算和整数除法`//`确保我们始终保持整数。 这可以避免浮点错误。 

关键的实现细节是将表达式保持为整数安全形式。 写作`(N / 2) * (...)`在其他语言中会存在浮点问题的风险，但在这里我们明确使用整数乘法和取整除法。

 ## 边缘情况

 ### 单层外壳

 输入：```
10 1
```这里序列只有一个值 10。该算法计算：$$1 \cdot (2 \cdot 10 + 0) // 2 = 20 // 2 = 10$$该公式仍然有效，因为最后一项等于第一项，因此配对可以正确退化。 

### 最大长度级数

 输入：```
1 1000
```该序列从 1 到 1000。该算法计算：$$1000 \cdot (2 + 999) // 2 = 1000 \cdot 1001 // 2$$这可以在整数算术中干净地进行计算，并且 Python 中不存在溢出问题。 该结构避免了循环遍历所有 1000 项，同时仍然产生精确的总和。
