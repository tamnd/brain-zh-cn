 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格$n \times m$，其中每个单元格包含一个高度值。 可以将此网格视为具有不同高度的果仁蜜饼块的景观。 Zeynep 反复将糖浆倒入一些起始细胞上。 从每个起点开始，糖浆会扩散到相邻的单元格，但只能沿着允许“向下流动或保持水平”的移动。 

允许的单元格移动$(i, j)$转到四个相邻位置：直接向上、直接向下、对角左上和对角右下。 在符号中，这些是$(i-1, j)$,$(i+1, j)$,$(i-1, j-1)$， 和$(i+1, j+1)$。 仅当邻居的高度小于或等于当前单元格的高度时，糖浆才能移动到邻居。 一旦糖浆被倒入查询点，它就会根据这些规则尽可能地扩散，并且我们记录它到达的每个单元格。 完成一次浇注后，该过程将重置并重新开始下一次浇注。 

任务是确定在所有浇注中哪个网格单元被访问次数最多。 如果多个单元格相连，我们必须选择行索引最小的一个，如果仍然相连，则选择列索引最小的一个。 

网格最多有 100 x 100 个单元，因此最多有 10,000 个节点。 每个查询都可以开始类似洪水的遍历，最多有1000个查询。 这立即排除了任何尝试在整个网格上为每个查询进行超出网格大小的线性或近线性工作的昂贵重新计算的方法。 一个解决方案大致是$O(q \cdot n \cdot m)$是可以接受的，因为它的顺序是$10^7$运营。 

天真的实现的一个微妙的失败案例是忘记了运动受到高度的限制。 例如，如果所有高度都沿着路径严格增加，但您忽略约束，则您会错误地将网格视为完全连接。 

另一个陷阱是不同浇注之间混合连接。 每个查询都必须独立处理。 如果错误地在查询中保留访问过的状态，那么早期的 BFS 结果将污染后来的结果并人为地增加计数。 

## 方法

 该问题的直接解释建议从每个查询单元格执行洪水填充。 从起始位置开始，我们使用队列或堆栈探索所有可到达的单元格，仅遵循满足高度约束的有效移动。 每次我们到达一个单元格时，我们都会增加它的全局计数器。 

考虑到限制，这种强力策略已经接近最优。 每个 BFS 或 DFS 最多探索$n \cdot m$单元格，并且由于四种可能的移动，每个单元格被处理固定次数。 对于多达 1000 个查询，最坏情况下的工作大约是$1000 \times 10000 = 10^7$国事访问，如果仔细实现的话，这在 Python 中是可以接受的。 

不需要更高级的预处理，因为图结构是查询相关的，即可达性取决于起点和单调高度条件。 预先计算所有对之间的可达性是不必要的并且更昂贵。 

关键的观察结果是每个查询都是独立的，并且在固定网格上贡献简单的加性频率。 这将问题转化为重复的受限可达性计数。

 ## 算法演练

 我们独立模拟每次糖浆倾倒并累积覆盖计数。 

1. 初始化一个2D数组`cnt`尺寸的$n \times m$带零。 这将存储在所有浇注中到达每个单元格的次数。 
2. 对于每个查询起始单元，运行 BFS 或 DFS。 我们还维护一个本地访问数组，以确保我们不会在一次浇注中两次处理相同的单元。 这是必要的，因为多个路径可以到达同一个单元格，但每个查询只应计算一次。 
3. 从起始单元格开始，将其推入队列并标记为已访问。 处理细胞时$(i, j)$，我们尝试所有四个允许的方向。 对于每个邻居$(ni, nj)$，我们检查两个条件：它在网格内部并且其高度小于或等于$h[i][j]$。 如果两者都成立并且在此查询中尚未访问过，我们将其标记为已访问并将其添加到队列中。 
4. 每次我们标记查询中访问过的单元格时，我们都会递增`cnt[i][j]`一个。 这确保每个单元每次倾倒最多贡献一次。 
5. 处理完所有查询后，我们扫描`cnt`数组寻找最大值。 如果多个单元格共享相同的最大值，我们选择行最小的单元格，然后选择列最小的单元格。 

### 为什么它有效

 每个查询的 BFS 都使用允许的移动精确枚举在单调非增加高度约束下可到达的所有单元格。 因为我们对每个查询标记已访问，所以每个单元每次倾倒最多计数一次，符合“被糖浆覆盖”的定义。 对查询求和可以累积独立的贡献。 由于我们评估每个查询的所有可达状态，因此不会遗漏任何可达单元，也不包含不可达单元。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m, q = map(int, input().split())
    h = [list(map(int, input().split())) for _ in range(n)]

    cnt = [[0] * m for _ in range(n)]

    dirs = [(-1, 0), (1, 0), (-1, -1), (1, 1)]

    for _ in range(q):
        si, sj = map(int, input().split())
        si -= 1
        sj -= 1

        vis = [[False] * m for _ in range(n)]
        dq = deque()
        dq.append((si, sj))
        vis[si][sj] = True
        cnt[si][sj] += 1

        while dq:
            i, j = dq.popleft()
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < m:
                    if not vis[ni][nj] and h[ni][nj] <= h[i][j]:
                        vis[ni][nj] = True
                        cnt[ni][nj] += 1
                        dq.append((ni, nj))

    best_i, best_j = 0, 0
    for i in range(n):
        for j in range(m):
            if cnt[i][j] > cnt[best_i][best_j]:
                best_i, best_j = i, j
            elif cnt[i][j] == cnt[best_i][best_j]:
                if i < best_i or (i == best_i and j < best_j):
                    best_i, best_j = i, j

    print(best_i + 1, best_j + 1, cnt[best_i][best_j])

if __name__ == "__main__":
    solve()
```网格直接存储为整数，并为每个查询创建一个新的访问矩阵，因为跨查询重用会错误地合并独立的洪水填充。 BFS 使用双端队列来确保每个查询的线性时间遍历。 

方向列表准确地编码了四个允许的移动。 扩展边缘时应用高度检查，确保我们仅遵循有效的下坡或平坦过渡。 

最后，通过对网格进行单次扫描来选择最佳单元，同时考虑最大频率和字典顺序打破规则。

 ## 边缘情况

 考虑一个网格，其中所有值都相等，并且每个单元格都可以从每个起点到达。 每个 BFS 都会淹没整个网格，因此每个单元都精确累积$q$增量。 该算法随后扫描网格并选择字典顺序最小的坐标，即 (1,1)，匹配所需的平局打破规则。 

现在考虑一个严格高度峰值位于 (2,2) 且被较低邻居包围的情况。 如果查询从较低的单元格开始，则它无法爬到峰值，因为所有移动都需要不增加高度。 如果查询从峰值开始，BFS 可以根据模式向外扩展到所有相等或较低的连接单元。 每个查询的访问检查确保每个有效起点仅对峰值进行一次计数，并且 BFS 限制确保不会发生非法向上转换。
