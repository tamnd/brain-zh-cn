 ## 解决方案
 ## 问题理解

 我们有两个有向图，每个都有相同数量的顶点。 每个图已经是强连通的，并且每个图内的每个有向循环的长度可被固定整数整除$k$。 这已经在两个图上施加了隐藏结构：它们的行为类似于具有一致的顶点模块化分层的图。 

两个图中的每个顶点也被标记为传出或传入。 我们必须通过精确相加来连接两个图$n$新的有向边，每条边总是在图之间，而不是在一个图内。 

度数约束是严格的：每个传出顶点必须恰好发出一条新边，并且每个传入顶点必须恰好接收一条新边。 由于有$n$每个图中的顶点，这恰好迫使$n$整体边缘，将两个图中的所有传出“源”与所有传入“汇”配对。 

最终的要求是结构性的：添加这些边后，组合图中的每个有向循环必须仍然具有可整除的长度$k$。 这意味着我们不仅仅是匹配端点，我们还以保留全局周期性约束的方式缝合两个模块化结构图。 

约束条件很大：最多$2 \cdot 10^5$顶点和$5 \cdot 10^5$总边数。 任何解决方案在总输入大小上都必须基本上是线性的。 这立即排除了任何试图模拟添加边缘或重复测试循环的构造。 关键必须是从每个图的内部结构导出的纯粹组合条件。 

如果忽略循环限制，一种简单的故障模式很快就会出现。 例如，如果我们只任意匹配传出和传入顶点，我们可能会在长度不能被整除的图上创建一个 2 循环$k$。 即使两个图都单独满足条件，交叉边也会立即破坏它。 

如果人们认为只计算物质，就会出现另一种微妙的失败。 两个图可以具有相同数量的传入和传出顶点，但由于其内部模块化结构的对齐方式仍然不兼容。 这是核心困难：约束不是局部的，它取决于循环长度引起的隐藏残差类。 

## 方法

 蛮力的想法是尝试所有可能的方法将一个图中的传出顶点连接到另一个图中的传入顶点，尊重度数约束，然后检查生成的图是否具有可整除的所有循环$k$。 即使忽略循环检查成本，两个集合之间的双射数量也是$n$，所以这种方法立即不可行。 

即使是更温和的尝试，例如构建流或匹配，然后显式验证循环，也会失败，因为添加边后的循环验证将需要对大小的图进行图遍历$2n$每次构建或重复重新计算强连接组件。 这至少导致$O(n^2)$或更糟糕的行为。 

关键的观察结果来自两个图中已经存在的循环条件。 如果有向图中的每个循环长度都可以整除$k$，那么该图允许通过余数模对顶点进行一致的标记$k$，其中每条边都以固定偏移模数增加标签$k$。 这是一个标准的结果：我们可以分配一个潜在的函数（mod$k$）沿着有向路径，循环的一致性确保它是明确定义的。 

因此每个图都可以被压缩成一个分区$k$层（或残基），并且每条边都尊重该分层。 

现在考虑当我们添加交叉边时会发生什么。 新边创建一个循环，该循环经过图 A 内部的路径，然后跳转到图 B，然后通过内部路径返回。 因为内部路径遵循模增量，所以总循环长度模$k$仅取决于这些隐式分层中端点的残差差异。 

这将整个问题简化为匹配顶点，以便残差约束在两个图中一致对齐。 每个顶点实际上都有一个隐藏标签$\mathbb{Z}_k$，并且有效边必须保持全局一致性。 

当且仅当一个图中传出顶点的残差类的多重集与另一图中传入顶点的残差类的多重集匹配时，传出到传入的匹配才变得可行，并且对于相反方向是对称的。 由于该问题允许图之间存在两个方向的边，因此最终条件崩溃为两个图引起的残差分布之间的类似奇偶校验的平衡。 

由于每个图都是强连接的并且具有相同的循环可分性，因此其残基分配在全局移位之前是唯一的。 我们可以通过固定根并执行 DFS 来计算这些残差，并以模数赋值$k$。 然后，可行性简化为检查我们是否能够一致地配对顶点，同时考虑类型约束和残差兼容性。 

## 算法演练

 1. 对于每个图，选择任意根顶点并将其分配残差 0。运行 DFS 或 BFS，每当我们遍历一条边时$u \to v$， 分配$res[v] = (res[u] + 1) \bmod k$，或者如果已经分配则一致地推导它。 因为所有循环的长度都可以被$k$，不存在矛盾。 这会为两个图中的每个顶点生成明确定义的残基标记。 
2. 计算每个残差类有多少个顶点属于四个类别中的每一个：图 1 传出、图 1 传入、图 2 传出、图 2 传入。 这些分布对与交叉边相关的所有约束进行编码。 
3. 观察到每条添加的边都必须在图之间，因此我们有效地在一个图中的传出顶点和另一图中的传入顶点之间构建双射。 这分为两个独立的二分匹配问题：从图 1 传出到图 2 传入的边，以及从图 2 传出到图 1 传入的边。 
4.对于保留循环残差结构的匹配，边只能连接残差兼容的顶点，因为它们的残差差与图之间的遍历引起的固定模移位相匹配。 因为两个图的模内部一致$k$，在通过全局移位对一个图的残基进行归一化之后，这种兼容性减少到相同残基类别内的匹配。 
5.我们尝试一切$k$可能的移位对齐图 1 和图 2 的残基系统。对于每个移位，我们检查是否每个残基类别$r$，图 1 中带有残差的传出顶点数$r$等于图 2 中带有残差的传入顶点数$r + \delta \bmod k$，对于相反方向也类似。 
6. 如果任何移位满足两个等式，则输出 YES。 否则输出NO。 

### 为什么它有效

 不变的是每个图都有一个一致的势函数模$k$，并且任何有向路径都会通过其长度来改变势能。 添加交叉边后形成的任何循环必须具有总电势变化零模$k$，这会强制交叉边的端点残基在两个图之间的单个全局移位下对齐。 一旦这种对齐方式得到解决，问题就减少到在残基类中匹配相等的多重集。 如果这样的移位不存在，则任何交叉边都必然引入长度违反整除性约束的环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_res(n, adj, k):
    res = [-1] * (n + 1)
    stack = [(1, 0)]
    res[1] = 0
    while stack:
        u, r = stack.pop()
        for v in adj[u]:
            nr = (res[u] + 1) % k
            if res[v] == -1:
                res[v] = nr
                stack.append((v, nr))
            else:
                if res[v] != nr:
                    return None
    return res[1:]

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        m1 = int(input())
        adj1 = [[] for _ in range(n + 1)]
        for _ in range(m1):
            u, v = map(int, input().split())
            adj1[u].append(v)

        m2 = int(input())
        adj2 = [[] for _ in range(n + 1)]
        for _ in range(m2):
            u, v = map(int, input().split())
            adj2[u].append(v)

        b = list(map(int, input().split()))

        # build dummy residues (conceptual; structure assumed consistent)
        r1 = build_res(n, adj1, k)
        r2 = build_res(n, adj2, k)

        if r1 is None or r2 is None:
            print("NO")
            continue

        cnt1_out = [[0] * k for _ in range(2)]
        cnt1_in  = [[0] * k for _ in range(2)]
        cnt2_out = [[0] * k for _ in range(2)]
        cnt2_in  = [[0] * k for _ in range(2)]

        for i in range(n):
            if a[i] == 1:
                cnt1_out[0][r1[i]] += 1
            else:
                cnt1_in[0][r1[i]] += 1

        for i in range(n):
            if b[i] == 1:
                cnt2_out[1][r2[i]] += 1
            else:
                cnt2_in[1][r2[i]] += 1

        ok = False
        for shift in range(k):
            good = True
            for r in range(k):
                rr = (r + shift) % k
                if cnt1_out[0][r] != cnt2_in[1][rr]:
                    good = False
                    break
                if cnt2_out[1][r] != cnt1_in[0][rr]:
                    good = False
                    break
            if good:
                ok = True
                break

        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```实现的核心是残差分配，它依赖于传播固定的+1模$k$沿着边缘。 这是有效的，因为输入保证强制所有循环的长度可被$k$，因此任何替代传播路径都会产生相同的残差。 

第二部分按类型和残基对顶点进行分组。 通过移位检查匹配条件$k$，这说明了两个图可能具有不同的绝对残基起源的事实。 

一个常见的实施陷阱是忘记必须在所有残基上全局测试移位，而不是每个顶点或每个边。 另一个微妙的问题是对称地处理传入和传出计数； 它们形成了两个必须同时成立的独立的二分约束。

 ## 边缘情况

 一个微妙的边缘情况是，两个图各自有效，但在每个班次下具有不兼容的残差分布。 在这种情况下，DFS 仍然会产生一致的标签，但最终的匹配步骤会失败，因为图 1 中的传出顶点上有一个残差类过多，而图 2 中没有移位的类与传入顶点匹配。该算法正确地拒绝了这种情况，因为移位循环从未在所有类之间找到相等性。 

另一种情况是当$k = 1$。 每个循环条件都变得空洞，问题简化为仅检查传出和传入顶点之间的度数可行性。 该算法正确退化，因为所有残基都为零并且只有总计数重要。 

第三种情况是其中所有顶点由于结构而位于一个残差类的图。 即便如此，移位机制仍然有效，因为两个图都分解为一个类，并且可行性仅取决于图之间传入和传出计数的全局平衡。
