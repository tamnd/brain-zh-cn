 ## 解决方案
 ## 问题理解

 我们在奥林匹克竞赛中得到一系列问题，每个问题都有一个分数和一个跳过参数。 比赛从第一个问题开始。 对于提出的每个问题，Prokhor 可以提交它并赚取积分，也可以跳过它并失去从该问题中赚取积分的机会。 下一个问题由选择决定：提交当前问题将下一个问题限制为具有较小索引的问题，而跳过允许下一个问题是索引最多为当前问题的跳过参数的任何问题。 系统总是选择以前没有见过的最大索引。 我们的任务是计算 Prokhor 可以获得的最大总分。 

这些约束意味着每个测试用例的问题数量可以达到$4 \cdot 10^5$，并且所有测试用例的总和不超过此界限。 这排除了探索所有可能序列的简单模拟，因为可能的提交/跳过路径的数量呈指数增长。 每个测试用例必须在大致线性的时间内有效地处理。 

当最优策略需要跳过第一个问题时，就会出现不明显的边缘情况。 例如，如果$a = [15,16]$和$b=[2,1]$，提交第一题可以得到 15 分，但跳过它可以进入第二题，得到 16 分。 总是提交第一个问题的粗心做法会产生 15 个问题，而不是 16 个问题。 

当跳过参数超过当前索引或所有剩余问题都已出现时，就会出现另一个微妙之处。 该算法必须正确跟踪哪些问题已被处理，以避免重复计算或索引错误。 

## 方法

 暴力方法将探索所有可能的提交和跳过序列。 对于每个问题，我们都会递归地考虑提交或跳过，根据规则更新下一个问题。 虽然原则上是正确的，但这种方法的最坏情况复杂度为指数级$n$并且无法处理$n = 10^5$。 即使对所有子集的记忆也太大了，因为状态空间随着已处理问题的索引而增长。 

关键的见解是，选择下一个问题的过程总是优先选择范围内最大的未访问索引。 这种单调属性使我们能够使用动态规划向后计算最佳分数。 我们不是跟踪访问问题的所有子集，而是定义$dp[i]$作为从问题开始可获得的最高分数$i$。 我们可以表达$dp[i]$按照$dp[i+1]$和$dp[b_i]$，使用移动到更小或有界索引的规则。 这将问题简化为从上一个问题向后的单遍，这是线性的$n$。 

向后 DP 之所以有效，是因为当我们计算时$dp[i]$, we already know the optimal results for all subsequent positions. 提交问题时$i$，下一个问题在左边，这个问题已经在$dp$。 当跳过时，下一个问题取决于跳过参数，该参数也对应于先前计算的值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 后向DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个DP数组$dp$长度$n+2$存储从每个问题开始可达到的最大分数。 我们使用额外的元素来简化边界条件。 
2. 按照相反的顺序处理问题，从$i = n$下降到$1$。 
3.针对问题$i$，考虑两个选项。 如果 Prokhor 提交了，下一个问题将在左边，这意味着$dp[i] = a[i] + dp[i+1]$最初。 如果他跳过了，则下一个问题由skip参数决定$b_i$。 使用预先计算的$dp[b_i+1]$，我们可以计算跳过时可达到的总和。 
4. 更新$dp[i]$作为提交或跳过的最大值。 
5.处理完所有问题后，得到的值$dp[1]$包含从第一个问题开始的最大可实现点。 

该算法之所以有效，是因为 DP 不变量保证对于每个索引，$dp[i]$是从问题开始的最优分数$i$，考虑所有未来的决定。 通过反向迭代，每个依赖关系都已计算出来。 基于跳过索引的最大选择被正确处理，因为$dp[i]$包括允许的下一个问题的最佳延续。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    dp = [0] * (n + 2)  # dp[i] = max score starting from i
    for i in range(n - 1, -1, -1):
        next_submit = dp[i + 1]
        next_skip = dp[b[i]]  # skip i goes to b[i], 0-based adjustment
        dp[i] = max(a[i] + next_submit, next_skip)
    
    print(dp[0])
```我们对 Python 列表使用从零开始的索引。 这`dp`数组有长度$n+2$最后简化边缘情况。`dp[i]`表示从问题出发的最大点数$i$， 所以`dp[n]`和`dp[n+1]`初始化为零，对应于没有剩余问题。 计算`dp[b[i]]`跳过问题后直接访问继续`i`。 最大操作在每一步选择最优决策。
