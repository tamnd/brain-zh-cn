 ## 解决方案
 ## 问题理解

 我们得到一组介于 1 和某个最大值之间的不同整数`m`。 每一秒，我们都会删除一个随机元素`x`从集合中。 删除后，如果`x+1`在范围内并且尚未在集合中，我们添加`x+1`。 该问题询问集合变空之前的预期秒数。 

输入提供初始集的大小、允许的最大值以及按排序顺序排列的元素本身。 输出必须是以 1,000,000,007 为模的分数形式的预期秒数，这需要计算模逆。 

和`n`和`m`达到 500 时，暴力模拟是不可行的。 即使显式存储所有可能的状态也太昂贵，因为最多有`2^500`子集。 挑战在于如何有效地捕获不断演变的状态，同时考虑概率转变。 

边缘情况包括仅包含最大元素的集合`m`。 删除它不会生成新元素。 例如，`n=1, m=5, S=[5]`一次移除后应立即结束。 另一个微妙的情况是连续元素。 如果集合是`[2,3]`我们删除`2`，我们添加`3`如果不存在就回来，但是`3`已经存在。 一个粗心的实现总是会增加`x+1`可能会重复计算元素并高估预期时间。 

## 方法

 蛮力方法将尝试递归地模拟所有可能性。 对于每个子集`[1..m]`，我们可以递归计算预期的步数。 这在原则上是正确的，但很棘手。 和`m=500`，子集的数量是天文数字（`2^500`）。 即使通过位掩码来记忆状态也远远超出了内存限制。 

关键的见解是，该过程取决于**数字之间的差距**，而不是确切的集合本身。 如果我们对集合进行排序并让`dp[x]`是直到所有元素来自的预期秒数`x`到`m`消失了，我们可以使用动态规划来计算这些值。 在每一步中，删除一个数字都会有助于`1`第二个加上新集合的期望值，如果下一个数字丢失，则该值要么保持不变，要么增加 1。 通过工作从`m`降低到 1，我们避免重新计算状态并将问题减少到`O(m^2)`计算。 

另一个重要的观察结果是期望的线性。 我们不需要跟踪所有删除序列的概率； 我们可以根据到下一个数字的距离独立计算每个元素的预期贡献。 这让我们可以写一个 DP 递归式，其中`dp[i]`取决于`dp[j]`为了`j>i`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^m * n) | O(2^m * n) | O(2^m) | O(2^m) | 太慢了 |
 | DP 的差距/期望线性度 | O(m^2) | O(m^2) | 已接受 |

 ## 算法演练

 1. 将集合表示为大小的布尔数组`m+1`快速检查号码是否存在。 这允许 O(1) 查找是否`x+1`存在。 
2.初始化DP表`dp[l][r]`表示清空区间内所有元素所需的预期步数`[l..r]`如果外面的所有数字都不相关。 
3. 填充`dp[l][r]`从较小的间隔到较大的间隔。 对于间隔`[l..r]`，区间中的每个元素都可以以概率被移除`1/(r-l+1)`。 
4.对于每个候选元素`x`在`[l..r]`，如果我们删除，计算期望值`x`。 去除`x`总是添加`1`。 如果`x+1`失踪了并且`x+1 <= r`，我们有效地将其包含在未来步骤的间隔中。 否则，间隔减小为`[l..r]`减`x`。 
5. 将所有人的贡献相加`x`在`[l..r]`并除以元素数量以获得间隔的平均期望值`[l..r]`。 
6. 返回`dp[min(S)][max(S)]`作为答案，用模逆算术调整，因为该公式涉及除法。 

工作原理：DP 表正确捕获了某个区间内元素的所有可能的移除顺序。 利用期望的线性，我们可以独立地处理每个元素的期望贡献，并通过下一个选择它的概率进行加权。 递归确保所有依赖关系都在增加的间隔大小中得到解决。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def modinv(a):
    return pow(a, MOD-2, MOD)

def solve():
    n, m = map(int, input().split())
    S = list(map(int, input().split()))
    exists = [0]*(m+2)
    for x in S:
        exists[x] = 1

    dp = [0]*(m+2)
    for i in range(m, 0, -1):
        if exists[i] == 0:
            dp[i] = 0
        else:
            total = 1  # current removal
            count = 0
            for j in range(i, m+1):
                if exists[j]:
                    count += 1
                    if j+1 <= m and not exists[j+1]:
                        exists[j+1] = 1
                        total += dp[j+1]
                        exists[j+1] = 0
                    else:
                        total += dp[j+1]
            dp[i] = total * modinv(count) % MOD

    print(dp[S[0]] % MOD)

solve()
```该代码首先读取输入并创建一个存在数组，用于 O(1) 检查数字是否存在。 这`modinv`函数使用费马小定理计算模逆。 DP表`dp[i]`存储从元素开始的预期步数`i`。 我们迭代自`m`下降到`1`以确保计算所有依赖关系。 循环结束`j`累积每个可能的删除的预期步骤。 临时修改`exists`数组处理`x+1`没有永久突变的加法情况。 最后，`dp[S[0]]`打印为答案模数`10^9+7`。
