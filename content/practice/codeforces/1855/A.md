 ## 解决方案
 ## 问题理解

 该问题要求我们确保没有学生坐在与自己编号相同的椅子上，从而使教室中的每个学生都“快乐”。 我们对学生和主席进行了初步的排列。 每个学生都可以通过一个号码来识别`1`到`n`，每把椅子也有一个编号`1`到`n`。 输入提供一个排列数组`p`这样`p[i]`告诉我们主席在哪里学生`i`最初是坐着的。 我们的任务是确定任意两个学生之间所需的**最小交换次数**，以便每个学生不再坐在自己编号的椅子上。 

由于排列大小`n`最多可以有 10^5，并且最多可以有 1000 个测试用例，我们需要一种在每个测试用例的线性时间内工作的算法。 任何显式模拟所有可能交换的算法都会太慢，因为在简单的方法中交换数量可能高达 O(n^2)。 当排列已经完全由快乐的学生组成时，需要 0 次交换，或者当有一个固定点（学生坐在自己的椅子上）而其余的形成循环时，会出现不明显的边缘情况，这会影响 1 次或 2 次交换是否足够。 

粗心的实现可能会尝试单独解析每个固定点，而不考虑排列结构。 例如，在排列中`[1,2,3]`，每个学生都坐在自己的椅子上。 最少交换次数不是 3 次而是 2 次，因为解决一名学生会改变周期。 这说明需要根据循环而不是单个元素进行推理。 

## 方法

 蛮力方法是反复将坐在自己椅子上的学生与不在自己椅子上的其他学生交换。 这是正确的但效率低下，因为我们可能需要扫描整个数组以查找每个固定点。 在最坏的情况下，这可能需要 O(n^2) 次操作，这对于 n = 10^5 来说太慢了。 

关键的观察结果是，问题简化为计算**固定点和不快乐学生的连续块**。 如果没有固定点，则不需要交换。 如果至少有一个固定点，则必须进行交换才能打破循环。 具体来说，如果排列包含至少一个连续的快乐学生序列，则最小移动次数取决于不快乐的学生是否形成连续的块或多个块。 实际上，最小交换次数是：

 -`0`如果没有固定点（所有学生都已经高兴了）
 -`1`如果不高兴的学生在排列中的某个地方形成连续的块
 -`2`否则（不高兴的学生被分成多个不连续的块）

 这种洞察力使我们能够以 O(n) 的速度计算每个测试用例的答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和排列`p`。 
3. 确定位置`p[i] == i + 1`，这些是不动点。 
4. 如果没有不动点，则打印`0`因为所有的学生都已经很幸福了。 
5. 否则，找到排列中最左边和最右边的不动点。 检查它们之间的所有位置是否都是固定点。 
6. 如果最左和最右固定点之间的所有位置也是固定点，则形成一个连续的块，只需要 1 次交换，因此打印`1`。 
7. 否则，打印`2`因为固定点被分成多个块，需要至少2次交换。 

**为什么它有效**

 这种方法之所以有效，是因为任何排列都可以分解为学生的循环。 周期长度 >1 的学生可以重新安排，以便对每个周期进行一次交换感到满意。 当固定点被孤立时，就会出现边缘情况； 我们需要检查连续的段以确定 1 次或 2 次交换是否足够。 最左边和最右边的固定点定义了包含所有固定点的最小跨度，确保了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    
    fixed = [i for i in range(n) if p[i] == i + 1]
    if not fixed:
        print(0)
        continue
    
    left, right = fixed[0], fixed[-1]
    if all(p[i] == i + 1 for i in range(left, right + 1)):
        print(1)
    else:
        print(2)
```该解决方案一次性识别固定点，确定连续固定点的跨度，并决定是否需要 0、1 或 2 次交换。 使用`i + 1`确保正确的从 1 开始的学生编号。 

## 工作示例

 对于输入排列`[1,2,3]`:

 | 我| p[i] | p[i] 固定的？ |
 | --- | --- | --- |
 | 0 | 1 | 是的 |
 | 1 | 2 | 是的 |
 | 2 | 3 | 是的 |

 所有学生都是固定点。 最左边 = 0，最右边 = 2。0 和 2 之间的所有位置都是固定的。 最小移动 = 1。 

对于`[1,2,5,4,3]`:

 | 我| p[i] | p[i] 固定的？ |
 | --- | --- | --- |
 | 0 | 1 | 是的 |
 | 1 | 2 | 是的 |
 | 2 | 5 | 没有 |
 | 3 | 4 | 是的 |
 | 4 | 3 | 没有 |

 最左边的固定 = 0，最右边的固定 = 3。0 和 3 之间的位置是`[1,2,5,4]`。 并非所有都是固定的。 最少移动次数 = 2。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 单次遍历数组以识别固定点并检查跨度 |
 | 空间| O(n) | 存储固定点的索引，如果仅使用左/右，可以优化为 O(1) |

 该算法完全符合 1 秒的时间限制，总 n ≤ 10^5。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())

        n = int(input())
        p = list(map(int, input().split()))
        fixed = [i for i in range(n) if p[i] == i + 1]
        if not fixed:
            output.append("0")
            continue
        left, right = fixed[0], fixed[-1]
        if all(p[i] == i + 1 for i in range(left, right + 1)):
            output.append("1")
        else:
            output.append("2")
    return "\n".join(output)

 ## 边缘情况

 末尾有一个固定点，例如`[1,3,2]`，通过识别最左边和最右边的固定点并检查跨度来处理。 即使只有一名学生最初不满意，跨度检查也会正确识别是否只需要一次交换就足够了还是需要两次。 这确保了所有最小和最大配置的正确性。
