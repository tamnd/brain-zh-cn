 ## 解决方案
 ## 问题理解

 我们得到了一家酒店`n`房间，编号`1`通过`n`，每个都配备了一个传送器，可以确定地将该房间中的任何人发送到固定目标房间。 数组`a`长度`n`对这些传送器进行编码，其中`a[i]`如果您从房间开始，就是您到达的房间`i`并使用传送器一次。 传送器可以形成循环、链或自循环。 迈克尔想要找到所有起始房间，这样在跟随传送器几次后，他最终会遇到布莱恩，布莱恩在房间中开始`1`。 唯一的工具是交互式查询机制：给定一个房间`u`, 若干步骤`k`，和一组`S`，礼宾人员可以解答是否瞬移`k`次从`u`降落在一个房间里`S`。 限制为 2000 个查询，并且`n`最大可达 500。 

关键的挑战是`k`可以非常大，最多`10^9`，并且交互器不直接提供传送器阵列。 我们必须隐式地使用传送图结构，并且严格的查询限制可以防止对所有路径进行天真的探测。 边缘情况包括自行循环的传送器、与房间 1 断开的循环以及合并为循环的链。 粗心的方法可能会假设周期短或完全错过孤立的房间。 

## 方法

 暴力方法将尝试通过使用足够的步数查询每个房间以到达任何其他房间来重建整个传送图。 每个房间`i`，可以要求每隔一个房间`j`是否存在一条路径`i`到`j`。 和`n`房间，这需要顺序`n^2`查询量高达 250,000`n = 500`，远远超过了 2000 条查询的限制。 这种方法原则上可行，但在实践中并不可行。 

关键的观察结果是，传送器定义了一个功能图，这意味着每个房间都只有一个传出边缘。 函数图由不相交的循环组成，其中包含树木。 一旦房间处于循环中，传送循环长度的任意倍数即可使其保持在该循环内。 如果我们知道布莱恩在多次隐形传送后最终进入的房间，那么同一周期中的任何房间或进入该周期的树都可以到达他。 因为交互器允许查询非常大的`k`，我们可以有效地问“房间在哪里`i`多次隐形传送后着陆，”绕过了模拟各个步骤的需要。这将问题简化为发现包含布莱恩的连接组件，使用沿着前辈链的二分搜索来识别哪些房间最终到达他。

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 查询 | O(n²) | 太慢了 |
 | 最佳| O(n log n) 次查询 | O(n) | 已接受 |

 ## 算法演练

 1. 首先确定布莱恩在多次传送后所占据的房间。 选择`k = n`或者`k = n + some_offset`确保任何链都进入循环。 查询室`1`和`k`以及所有房间的集合。 返回的答案使我们能够确定 Brian 最终周期中的房间。 
2. 每个房间`i`从`1`到`n`，对一组可能的步骤执行二分搜索，以检查是否从`i`最终达到布莱恩当前的周期。 通过加倍`k`直到礼宾员回答“是”，我们快速确定一个房间是否可以达到循环，每个房间进行 O(log n) 次查询。 
3. 收集路径最终到达包含 Brian 的循环的所有房间。 这些房间组成了一套`A`。 对于已经在循环中的房间，单个查询就足够了，因为足够大`k`将它们保留在循环内。 对于进入循环的链中的房间，重复加倍可以找到到达循环所需的步数。 
4.输出集合`A`。 不需要查询来进行验证，因为查询已经确定这些房间达到了 Brian 的周期。 

关键的不变量是函数图保证收敛到循环。 使用查询`k`大于`n`确保我们跨越任何瞬态链，以便发现每个可到达的房间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from sys import stdout

def query(u, k, S):
    print(f"? {u} {k} {len(S)} {' '.join(map(str, S))}")
    stdout.flush()
    return input().strip() == '1'

def solve():
    n = int(input())
    all_rooms = list(range(1, n+1))
    # Find one room in Brian's eventual cycle
    lo, hi = 1, n
    while lo < hi:
        mid = (lo + hi) // 2
        if query(1, mid, all_rooms):
            hi = mid
        else:
            lo = mid + 1
    brian_room = lo

    reachable = []
    for i in range(1, n+1):
        if query(i, n, [brian_room]):
            reachable.append(i)

    print(f"! {len(reachable)} {' '.join(map(str, reachable))}")
    stdout.flush()

solve()
```第一部分使用对传送次数的二分搜索来定位布莱恩的最终循环。 第二部分使用单个查询检查每个房间`k = n`，因为这保证了进入任何循环。 该实现仔细处理刷新以尊重交互约束。

 ## 边缘情况

 如果房间有自环（`a[i] = i`），它只是其自身循环的一部分。 该算法查询它`k=n`并确认 Brian 的房间是否位于同一组件中的可达性。 例如，使用传送器`[1, 2, 3]`，每个房间自循环，输出正确包含所有房间`[1,2,3]`。 

对于进入循环的链条，例如`[2,3,3]`， 房间`1`需要 2 个步骤才能到达房间内的自行车`3`。 使用`k=n`确保查询落在循环、标记室中`1`作为可达的。 这表明该算法正确处理长度小于`n`。
