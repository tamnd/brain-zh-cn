 ## 解决方案
 ## 问题理解

 我们可以重复选择数组中的两个位置，并将一个位置的值添加到另一个位置。 源元素在使用时不会被消耗或更改，因此该操作的行为就像索引之间可重用的“值传输”。 

目标不是通过交换对数组进行排序，而是重塑值，以便在最多五十次这样的添加之后，最终数组变得单调非递减。 由于值可以是负数、正数或零，因此困难不在于直接对元素进行排序，而在于仅使用附加更新来控制它们的大小。 

这些限制使得结构相当小。 每个测试最多有二十个元素，每个元素都在负二十到二十之间。 这强烈表明构建而不是优化或搜索。 任何解决方案都可以在操作数量上提供二次甚至温和的三次行为，只要它保持在每个测试用例五十次操作的固定上限之内。 

主要的微妙之处在于，天真的“本地修复违规”方法很容易超出操作限制。 例如，如果值振荡，则一一重复修复相邻的反转可能需要大量步骤。 另一个陷阱是试图贪婪地泡沫化价值，而不确保每项操作都对全球结构做出贡献； 当值的符号交替时，这种方法可能会停滞不前。 

正确的策略必须在恒定数量的阶段中创建全局单调结构，而与确切的初始安排无关。 

## 方法

 暴力思维会尝试直接修复反转。 人们可能会扫描数组，并且每当一对满足$a_i > a_{i+1}$，尝试通过添加仔细选择的值来减少它。 这很快就会变得不稳定，因为任何局部修复都可能破坏早期的位置，并且不能保证重复的传递在五十次操作内收敛。 在最坏的情况下，值会在正负状态之间振荡，导致无限的修复周期。 

关键的观察是我们不限于相邻操作或保留值。 我们可以选择任何索引作为可重用的“影响力”来源，并将其值推送到数组中。 这建议构建一个主导主元元素，其大小足以在一步中控制所有其他条目。 

一旦存在这样的主元，我们就可以在一次传递中均质化整个数组相对于该主元的符号。 之后，将数组转换为排序结构变得很容易，因为可以通过累积前缀或后缀累积来强制单调性。 

关键的结构见解是，如果所有数字都是非负数，则前缀和会自动生成一个非递减序列。 对称地，如果所有数字都是非正数，则后缀累积也会产生非递减序列，因为从右向左传播时，递增的负部分和仍然遵循顺序。 

因此，问题简化为两个阶段：首先强制所有元素位于零的一侧，然后传播顺序。 

| Approach | 时间复杂度| Space Complexity | 判决 |
 | --- | --- | --- | --- |
 | Local inversion fixing | O(操作)，但在最坏情况下是无界的 | O(1) | O(1) | 太慢了 |
 | 枢轴符号标准化 + 前缀/后缀构造 | O(n) operations | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们选择单个枢轴索引$p$，数组中绝对值最大的元素的位置。 

1. 识别$p$这样$|a_p|$是所有元素中最大的。 这确保了$a_p$在大小上主导所有其他值。 
2.如果$a_p \ge 0$，我们强制每个元素变得非负。 对于每个$i \ne p$，我们执行一项操作$a_i := a_i + a_p$。 的统治地位$a_p$保证即使是最小的可能值$a_i = -a_p$此操作后变为零。 
3.如果$a_p < 0$，我们反而强制每个元素变得非正。 再次为每个$i \ne p$，我们执行$a_i := a_i + a_p$。 自从$a_p$是最负值，任何正元素$a_i \le |a_p|$单次相加后变为非正数。 

此时，数组被分成两个对称的情况。 

1.如果所有元素都非负，我们使用前缀累加构造一个非减序列。 对于每个$i$从$2$到$n$，我们执行$a_i := a_i + a_{i-1}$。 每个步骤都会保留顺序，因为添加非负前缀不能减少值，而且它还会向前传播早期的增长。 
2. 如果所有元素都是非正数，我们从右到左构建序列。 对于每个$i$从$n-1$下降到$1$，我们执行$a_i := a_i + a_{i+1}$。 每个操作都会向左推更多的负质量，并且因为两个操作数都是非正的，所以不等式$a_i \le a_{i+1}$每一步之后仍然有效。 

### 为什么它有效

 第一阶段之后的不变量是所有元素完全位于零的一侧，并且每个元素的大小都受到枢轴的限制。 这保证了与主元的单次加法足以翻转整个数组的符号一致性。 

在第二阶段，不变的是我们在具有固定符号的序列上重复应用累积和。 在非负情况下，前缀和保持单调性，因为每个元素都成为不断增长的前缀的总和。 在非正的情况下，后缀和保持单调性，因为每个元素都成为收缩后缀的和，并且更多的负累加总是小于或等于后面的元素。 

该构造避免了对早期结构的任何恢复，因为每次操作都只是加强全局排序方向，而不是修复局部不一致。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    p = 0
    for i in range(n):
        if abs(a[i]) > abs(a[p]):
            p = i

    ops = []

    if a[p] >= 0:
        for i in range(n):
            if i != p:
                ops.append((i + 1, p + 1))
                a[i] += a[p]

        for i in range(1, n):
            ops.append((i + 1, i))
            a[i] += a[i - 1]

    else:
        for i in range(n):
            if i != p:
                ops.append((i + 1, p + 1))
                a[i] += a[p]

        for i in range(n - 2, -1, -1):
            ops.append((i + 1, i + 2))
            a[i] += a[i + 1]

    print(len(ops))
    for i, j in ops:
        print(i, j)
```实现直接遵循两阶段结构。 第一个循环通过绝对值选择主导枢轴。 第一个构造循环对每个非枢轴元素仅应用一次操作，确保统一的符号控制。 第二阶段根据主元符号在前缀或后缀传播之间切换。 索引处理是此处离一错误的主要来源，因为该问题使用基于 1 的索引，而代码在基于 0 的数组中运行。 

## 工作示例

 ### 示例：`[2, 1]`我们选择枢轴`2`在索引 1 处。由于它是正数，我们首先确保非负数，但数组已经是非负数，因此不需要更改。 然后我们应用前缀传播。 

| 步骤| 数组状态 | 运营|
 | --- | --- | --- |
 | 开始 | [2, 1] | 无 |
 | 前缀 i=2 | [2, 3] | a2 += a1 |

 该数组立即变为非递减，因为前缀和使排序与累加对齐。 

这表明单个主导正枢轴如何将问题简化为简单的累积过程。 

＃＃＃ 例子：`[3, 10, -20, 5]`枢轴是`-20`（最大绝对值）。 由于它是负数，我们首先将所有值推为非正数。 

| 步骤| 数组状态| 运营|
 | --- | --- | --- |
 | 开始 | [3, 10, -20, 5] | 无 |
 | 我=1 | [-17, 10, -20, 5] | a1 += a3 |
 | 我=2 | [-17, -10, -20, 5] | a2 += a3 |
 | 我=4 | [-17, -10, -20, -15] | a4 += a3 |

 现在所有元素都是非正的。 我们进行后缀累积。 

| 步骤| 数组状态| 运营|
 | --- | --- | --- |
 | 我=3 | [-17, -10, -35, -15] | a3 += a4 |
 | 我=2 | [-17, -45, -35, -15] | a2 += a3 |
 | 我=1 | [-62, -45, -35, -15] | a1 += a2 |

 最终数组是非递减的。 

该轨迹强调了为什么后缀方向在处理非正数组时至关重要：累加方向必须与符号结构对齐。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 时间 | 每次测试 O(n) | 每个阶段最多对每个索引执行一个操作 |

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out_lines = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        p = 0
        for i in range(n):
            if abs(a[i]) > abs(a[p]):
                p = i

        ops = []

        if a[p] >= 0:
            for i in range(n):
                if i != p:
                    ops.append((i + 1, p + 1))
                    a[i] += a[p]
            for i in range(1, n):
                ops.append((i + 1, i))
                a[i] += a[i - 1]
        else:
            for i in range(n):
                if i != p:
                    ops.append((i + 1, p + 1))
                    a[i] += a[p]
            for i in range(n - 2, -1, -1):
                ops.append((i + 1, i + 2))
                a[i] += a[i + 1]

        out_lines.append(str(len(ops)))
        for i, j in ops:
            out_lines.append(f"{i} {j}")

    return "\n".join(out_lines)

# minimal
assert run("1\n1\n5\n") == "0"

# already sorted
assert run("1\n3\n1 2 3\n").split()[0] <= "4"

# all negative
assert run("1\n3\n-1 -2 -3\n") != ""

# mixed
assert run("1\n4\n2 -1 3 -2\n") != ""
