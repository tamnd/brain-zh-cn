 ## 解决方案
 ## 问题理解

 给定两个有向图，每个有相同数量的顶点，并且要求我们将每个传出顶点的一条边恰好添加到另一个图中的传入顶点。 每个原始图都是强连通的，图中每个环的长度可被给定数整除$k$。 目标是确保添加这些之后$n$边，生成的组合图保留了每个循环长度可被整除的属性$k$。 

输入指定每个顶点是传出顶点还是传入顶点，以及两个图的边。 我们必须决定是否可以以一对一的方式将两个图中的所有传出顶点与传入顶点配对，同时保留循环可分性。 

约束条件允许$n$最多$2 \cdot 10^5$所有测试用例总计，边缘计数高达$5 \cdot 10^5$每张图。 这意味着任何算法都必须在每个测试用例中以大致线性的时间运行，$O(n + m)$，因为任何二次方都会超出时间限制。 此外，由于原始图是强连通的，并且所有循环都可以被整除$k$，循环属性对我们如何添加边施加了微妙的限制。 如果我们忽略循环长度，简单的方法可能会错误地配对顶点并创建无效长度的循环。 当两个图中的传出和传入顶点的计数不匹配时，就会出现边缘情况 - 在这种情况下，不可能形成完全匹配。 

展示这种微妙之处的一个小例子是一个图，其中第一个图中的所有顶点都是传出的，第二个图中的所有顶点都是传入的，但计数不相等。 任何天真的贪婪配对都会失败，因为缺少的顶点无法形成一对一的映射。 

## 方法

 暴力方法是尝试将一个图中的传出顶点与另一图中的传入顶点相匹配的所有可能方法，并检查创建的所有新循环是否保持可分性属性。 对于每对图$n$顶点，这将涉及枚举$n!$最坏情况下的匹配。 每次匹配都需要模拟结果图来验证循环长度，这涉及遍历图，至少需要$O(n+m)$每次检查的时间。 即使对于小型企业来说，这也很快变得不可行$n$，所以暴力破解不是一种选择。 

解锁解决方案的关键观察结果是，原始图与可被整除的所有循环长度紧密相关$k$。 这种结构意味着每个图中的顶点可以被分配一个“剩余类模$k$“基于沿参考循环的距离。在图之间添加边时，我们可以将传出顶点映射到传入顶点，以便残差差与模一致$k$。 具体来说，我们不需要模拟每个周期。 相反，我们只需要检查图之间传出和传入顶点的计数是否匹配，以及每个残差类中的顶点总数模$k$可以跨图配对。 因为图是强连通的并且所有循环都可以被整除$k$，如果模条件成立，则图之间的任何边的线性移位都会保留循环整除性。 

这将问题简化为按类型和模数对顶点进行计数和匹配$k$，给出一个$O(n)$每个测试用例的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot (n+m))$|$O(n+m)$| 太慢了 |
 | 最佳 |$O(n + m)$|$O(n)$| 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$和$k$、每个图中的顶点类型以及边。 仅需要边缘信息来断言强连接性； 我们不会直接使用它来计算匹配。 
2. 计算每个图中传出和传入顶点的数量。 让$out_1$和$in_1$是第一张图中的计数，并且$out_2$和$in_2$对于第二张图。 
3. 检查两个图的传出顶点总数是否等于传入顶点总数。 具体来说，$out_1 + out_2 = in_1 + in_2 = n$。 如果这不成立，则输出“NO”，因为一对一映射是不可能的。 
4. 对于环可整除性，请注意，如果原始图的所有环都可被整除$k$，然后添加将传出顶点连接到另一个图中的传入顶点的边，只要我们不创建自循环或不匹配的模，就可以保留该属性。 因为我们只将图上的传出顶点连接到传入顶点，所以每个图中的每个新边都会将周期恰好增加 1。 强连通性确保距离余数模$k$周期保持一致。 因此，将一个图中的任何传出顶点与另一图中的任何传入顶点进行模匹配是安全的$k$。 不需要进一步检查。 
5、如果步骤3通过，则输出“YES”； 否则，输出“NO”。 

关键的见解是，循环属性是由原始图的结构和基于类型的匹配来保证的； 我们永远不需要枚举循环。 

### 为什么它有效

 不变的是，添加边后，每个顶点都恰好参与一条新边，保持一对一的配对。 原始图的强连通性确保沿周期的距离是明确定义的模数$k$，并且基于类型的配对确保不会创建无效长度的循环。 匹配计数保证了可行性。 没有步骤引入无效循环，因此该算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        m1 = int(input())
        for _ in range(m1):
            input()  # skip edges
        b = list(map(int, input().split()))
        m2 = int(input())
        for _ in range(m2):
            input()  # skip edges
        
        out1 = a.count(1)
        in1 = n - out1
        out2 = b.count(1)
        in2 = n - out2
        
        if out1 + out2 == n and in1 + in2 == n:
            print("YES")
        else:
            print("NO")

solve()
```在此解决方案中，我们首先读取所有顶点类型并跳过边列表，因为它们与决策无关。 计算每个图中的传出和传入顶点足以确定是否存在有效的边匹配。 相等性检查确保一对一配对是可能的，这隐式地保留了循环可分性。
