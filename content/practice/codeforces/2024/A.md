 ## 解决方案
 ## 问题理解

 我们有两种类型的银行存款和爱丽丝拥有的一些硬币。 “盈利”存款至少需要一定金额，`b`，开立，而“无利可图”存款没有最低限额。 爱丽丝可以将一些硬币存入“无利可图”，以将“有利可图”所需的最低金额减少两倍。 然而，花在“无利可图”上的硬币以后不能转移到“有利润”。 我们的目标是找到爱丽丝在可能策略性地使用“无利可图”之后实际可以存入“有利可图”的最大硬币数量。 

输入由多个测试用例组成。 每个测试用例给出 Alice 的总硬币数`a`和初始阈值`b`为“有利可图”。 输出应该是 Alice 在“盈利”状态下可以存入的最大存款，如果她不能满足要求，则输出为零。 

约束条件允许`a`和`b`最多$10^9$直至$10^4$测试用例。 这意味着任何解决方案都必须大致运行$O(1)$per test case to stay within the 1-second limit. 尝试每一种可能的“无利可图”存款的嵌套循环或方法太慢。 

主要的边缘情况发生在爱丽丝的总代币略低于、恰好等于或远高于“盈利”最小值时。 例如，如果`a = 1`和`b = 2`，即使她在“Unprofitable”中没有存入任何资金，也无法打开“Profitable”，所以答案是零。 如果`a = b`，她可以直接存入所有的币。 另一个微妙的情况是当`b > a`但足够小`a`可以减少`b`使用“无利可图”存款达到门槛。 这些都需要仔细推理以避免出现大错特错。 

## 方法

 天真的方法会迭代爱丽丝可以存入“无利可图”的每一个可能的金额，从 0 到`a`，计算每个人减少的“盈利”最小值，然后检查她是否有足够的硬币来满足它。 虽然正确，但这需要最多$10^9$最坏情况下的迭代，这显然是不可行的。 

关键的观察是问题简化为一个数学公式。 让`x`是存入“无利可图”的硬币。 “盈利”的新最低标准变为`b - 2*x`。 剩下存入“盈利”的硬币是`a - x`。 我们需要`a - x >= b - 2*x`。 解决这个不等式给出`x >= b - a`。 我们也知道`x >= 0`和`x <= a`。 最优选择是最小的`x`满足不等式，因为在“无利可图”中存入更多货币不必要地减少了可用于“有利可图”的代币。 所以“盈利”的最大存款是`a - max(b - a, 0) = min(a, a - (b - a)) = min(a, b)`，但我们需要确保减少不会产生负阈值，给出一个简单的公式`max(0, a - ceil((b - a)/2))`。 这会崩溃到只是`min(a, max(a, (a + b)//2))`具有整数除法处理。 

暴力破解之所以有效，是因为它系统地检查了所有有效的“无利可图”存款，但在以下情况下会失败：`a`和`b`很大。 观察到不等式有一个简单的代数解，我们可以在每个测试用例的恒定时间内计算答案。

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`a`和`b`。 
3. 检查是否`a`小于一半`b`。 如果`a * 2 < b`，那么即使将所有资金存入“Unprofitable”也不足以降低门槛。 在这种情况下，输出`0`。 
4. 否则，计算 Alice 可以存入“Profitable”的最大硬币数为`(a + b) // 2`。 这个公式来自于求解`a - x >= b - 2*x`为了`x`并最大化`a - x`。 
5. 打印每个测试用例的结果。 

为什么有效：不平等`a - x >= b - 2*x`确保 Alice 满足降低的阈值。 解决`x`给出“无利可图”所需的最少硬币. 正是选择这个`x`最大化剩余的“盈利”硬币。 如果即使当`x = a`，Alice 无法打开“有利可图”，答案为零。 整数除法正确地处理了硬币的离散性质。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    if 2 * a < b:
        print(0)
    else:
        print((a + b) // 2)
```代码读取所有测试用例并立即应用导出的公式。 支票`2 * a < b`处理 Alice 即使最大程度减少也无法满足最小值的情况。 使用整数除法`(a + b) // 2`确保我们向下舍入到满足约束的最大整数存款。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        if 2 * a < b:
            output.append("0")
        else:
            output.append(str((a + b) // 2))
    return "\n".join(output)

 ## 边缘情况

 当`a < b / 2`，即使将所有币存入“无利可图”也无法降低足够的最低限额。 例如，`a = 1`,`b = 3`。 算法检查`2*a < b`，这是正确的，并且输出`0`。 如果`a = b`，Alice 可以存入一切，其中公式`(a+b)//2`正确计算。 大数字如`a = b = 10^9`不要溢出 Python 整数并产生正确的存款。 整数除法可确保部分硬币正确向下舍入。
