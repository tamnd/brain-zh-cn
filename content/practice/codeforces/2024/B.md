 ## 解决方案
 ## 问题理解

 我们有一台自动售货机`n`隐藏槽，每个槽包含已知数量的柠檬水罐。 还有`n`按钮，每个按钮都映射到一个插槽，但映射会丢失。 如果相应的槽位还有剩余，按下按钮可能会给你一个罐头； 否则，什么也不会发生。 您无法看到罐子来自哪个插槽，也无法看到当前的内容。 

任务是：给定槽中的初始计数和目标`k`，确定保证获得至少`k`罐头，无论哪个按钮对应哪个插槽。 我们事先知道总罐数至少为`k`。 

约束表明我们最多可能有`2 * 10^5`所有测试用例的槽位总和，以及`k`可以大到`10^9`。 这排除了我们尝试每种可能的按下顺序的任何暴力模拟，因为单独按下按钮直到我们到达`k`可能需要 O(k) 次操作，这太大了。 我们需要一种可以扩展的方法`n`而不是`k`。 

当某些插槽的计数非常大而其他插槽的计数非常小时，就会出现微妙的边缘情况。 例如，如果`a = [1, 1000000000]`和`k = 2`，盲目地按下按钮可能会过度按压第一个插槽并浪费压力，而最佳策略必须考虑最坏情况的分布以保证`k`罐头。 

## 方法

 最简单的解决方案是模拟所有的按压顺序。 人们可以尝试一种贪婪的方法：重复选择任何按钮，直到它失败为止，然后移至另一个按钮。 虽然原则上是正确的，但当计数很大时，模拟这太慢了，因为在最坏的情况下，它需要 O(k) 次按下，最多为 10^9。 

关键的观察结果是，按下的最小次数取决于按降序排序的插槽计数。 如果我们将槽计数表示为`a_1 ≥ a_2 ≥ ... ≥ a_n`，最坏的情况发生在我们的压力机首先击中最大的槽位但错过较小的槽位直到最后。 因为我们可以根据成功或失败在每次按下后进行调整，所以我们可以通过**对每个按钮的按下次数进行二分搜索**来对此进行建模。 

最佳解决方案可以看作是在按钮上分配按键，从而考虑到哪个按钮映射到哪个插槽的不确定性。 如果我们分配`x`按下每个按钮，我们从每个槽收集到的保证罐头是`min(a_i, x)`，因为一个槽的罐数少于`x`不能提供超出其内容的内容。 将所有插槽的总和得出总保证罐数。 因此，最小总压力是最小的`x`使得总和`min(a_i, x)`所有槽位的至少`k`。 

按降序对槽数进行排序使我们能够有效地进行计算。 排序后，我们可以使用贪心方法：尝试“首先从最大的槽中获取尽可能多的”，这减少了对可能的按下次数的二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每个测试用例的 O(k) | O(n) | 太慢了 |
 | 贪心/二分搜索| 每个测试用例的 O(n log max(a_i)) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`k`和数组`a`。 种类`a`按降序排列。 排序确保我们首先尝试“覆盖”最大的槽。 
2. 初始化两个指针用于二分查找：`low = 1`（至少按 1 次）和`high = k`（最坏的情况：每罐按 1 次）。 
3.同时`low < high`, 计算`mid = (low + high) // 2`。 对于这位候选人`mid`按每个按钮，计算`sum(min(a_i, mid))`在所有插槽上。 这个总和是按下每个按钮时保证的罐数`mid`时间在适应性策略中。 
4. 如果总和至少为`k`，那么我们就有可能实现`k`每个按钮按下的次数较少，因此设置`high = mid`。 否则，设置`low = mid + 1`增加按压次数。 
5. 二分查找完成后，`low`是每个按钮所需的最少按下次数。 
6. 要查找按下的总数，请注意，我们将按下每个按钮直至其指定的位置`low`次。 但因为`k`可能小于总和`min(a_i, low)`，我们调整最后一次按下次数以完全满足`k`。 因此，总压力计算为`min(a_i, low)`直到总和达到`k`。 

**为什么有效：** 二分搜索保持了以下不变式：`low`总是可行或太小，并且`high`总是足以保证`k`罐头。 自从`min(a_i, x)`是单调的`x`，搜索收敛到最小值。 排序确保我们考虑最坏情况下的压力分布，无论按钮到插槽的映射如何，都能保证罐子的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_presses(n, k, a):
    a.sort(reverse=True)
    low, high = 1, k
    while low < high:
        mid = (low + high) // 2
        total = sum(min(ai, mid) for ai in a)
        if total >= k:
            high = mid
        else:
            low = mid + 1
    # low is the minimum presses per button in worst case
    total_presses = 0
    remaining = k
    for ai in a:
        take = min(ai, low, remaining)
        total_presses += take
        remaining -= take
        if remaining == 0:
            break
    return total_presses

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print(min_presses(n, k, a))
```代码的每一部分都直接对应于算法步骤。 排序对于保证罐的贪心计算至关重要。 二分搜索循环有效地找到每个按钮的最小按下次数，而无需模拟每次按下。 求和`min(a_i, mid)`保证我们尊重插槽限制。 最后的循环确保总按下次数完全满足`k`。 

## 工作示例

 **示例1**：

 输入：`n=2, k=2, a=[1,2]`| 步骤| 已排序`a`| 中| 总和（分钟（a_i，中））| 决定|
 | --- | --- | --- | --- | --- |
 | 初始化| [2,1]| - | - | 低=1，高=2 |
 | 1 | - | 中=1 | 最小值(2,1)+最小值(1,1)=2 | 总和>=k → 高=1 |
 | 完成 | - | 低=1 | 总按压数 = min(2,1)+min(1,1)=2 | 输出2 |

 我们按每个按钮一次。 最坏的情况，我们只能得到 2 罐。 

**示例2**：

 输入：`n=3, k=4, a=[2,1,3]`| 步骤| 已排序`a`| 中| 总和（分钟（a_i，中））| 决定|
 | --- | --- | --- | --- | --- |
 | 初始化| [3,2,1]| - | - | 低=1，高=4 |
 | 1 | - | 中=2 | 最小值(3,2)+最小值(2,2)+最小值(1,2)=2+2+1=5 | 总和>=k → 高=2 |
 | 2 | - | 中=1 | 1+1+1=3 | 总和<k → 低=2 |
 | 完成 | - | 低=2 | min(a_i,2) 的总和，直到 4 罐 = 2+2=4 | 输出4 |

 这证实了算法正确地在插槽之间分配压力，以保证`k`。
