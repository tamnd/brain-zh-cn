 ## 解决方案
 ## 问题理解

 我们得到一棵有根二叉树，其节点标记为从 1 到 n。 每个节点对应于长度为 2n 的未知有效括号序列中的一对匹配括号。 节点的编号不是任意的：它是由原始序列引起的，其中从左到右扫描字符串时，节点对按照其左括号出现的顺序进行编号。 

树本身是由连接每对相邻字符的结构规则定义的。 如果一个节点对应于一对位置 (i, j)，那么我们检查原始字符串中的 i+1 和 j+1。 如果 i+1 是左括号，则它成为该节点的左子节点。 如果 j+1 是左括号，则它成为右孩子。 这些子项对应于左括号恰好位于这些位置的括号对。 树的根是节点 1。 

任务是重建任何有效的括号序列，该序列可以在所描述的构造下产生这个精确的树。 

输入大小很大，测试用例的总 n 高达 2×10^5。 每个测试用例的任何解决方案都必须接近线性。 尝试所有放置或重复模拟字符串的二次重建会立即变得太慢，因为即使是 10^5 个节点也意味着在放置和扫描的简单模拟中需要 10^10 个操作。 

如果假设树仅对嵌套结构进行唯一编码，则会出现一种微妙的失败情况。 例如，具有两个子节点的根可能表明两个子节点都出现在同一外部对内，但构造实际上取决于 i+1 和 j+1 处的邻接关系，这意味着兄弟节点对应于“端点后的下一个左括号”，而不是通用子树包含。 对此的误解通常会导致将子项任意放置在间隔内并产生无效或不一致的序列。 

另一种特殊情况是节点只有一个子节点或没有子节点。 天真的“总是在父区间内立即打开子节点”构造可能会意外地重叠区间或产生不匹配的顺序，因为右子节点开口与 j+1 相关，而不是与当前遍历位置相关。 

## 方法

 直接的暴力方法会尝试将位置 1 到 2n 分配给所有左括号和右括号，同时尊重每个节点 i 都有其左括号和右括号，并且父子关系必须匹配邻接约束。 这变成了 2n 个位置上的约束放置问题，且间隔之间存在依赖规则。 即使我们尝试回溯，每个节点也可以分支到多个位置，并且总配置在 n 中呈指数级爆炸。 即使 n 约为 20，这也是不可行的。 

关键的观察结果是，当正确解释时，树实际上定义了序列的确定性分解。 每个节点对应一个区间，使用 i+1 和 j+1 的构造规则意味着每个节点的子节点必须立即出现在其区间的开始之后或结束之后。 这消除了排序的自由度：一旦我们修复了结构，就可以通过模拟间隔生成方式的相反过程来重建序列。 

我们没有放置括号，而是为节点分配位置。 每个节点将有两个位置：进入时的开仓位置和退出时的平仓位置。 我们执行的遍历尊重以下事实：从放置左括号的那一刻起就发现了左子节点，从放置右括号的那一刻起就发现了右子节点。 这自然会导致深度优先重建，在进入节点时我们发出“(”，离开节点时发出“)”，同时以正确的顺序递归处理子节点。

该结构保证必须在打开父级之后立即处理左子级，并且必须在关闭父级之前立即处理右子级，因为它们与原始构造中的 i+1 和 j+1 转换完全对应。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力放置/回溯 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 从树结构进行DFS重建 | O(n) | O(n) | 已接受 |

 ## 算法演练

 如果我们将树扩展回基于遍历的编码，我们通过模拟如何生成括号来重建字符串。 

1. 从根节点 1 开始。该节点对应于序列中最外面的对，因此它必须生成任何有效构造中的第一个左括号。 
2. 对于节点 u，输入 u 时立即输出“(”。这对应于分配与 u 关联的对的左括号。
 3. 如果u的左孩子存在，则递归处理。 左子节点被定义为来自原始结构中的位置 i+1，这意味着它必须是打开 u 后立即出现的第一个结构。 
4.完成左子树后，递归处理u的右子树（如果存在）。 这对应于原始序列中紧随 j 之后开始的结构，因此它必须放置在 u 的所有左派生内容之后。 
5. 两个子进程都处理完后输出')'。 这样就确定了对应于u的区间。 
6. 对从根可到达的所有节点重复此 DFS，这确保每个节点恰好贡献一个左括号和一个右括号。 

它之所以有效，是因为将每个节点解释为一对匹配位置，定义了重构字符串中的连续间隔。 构造规则将子级严格绑定到 i+1 和 j+1，这迫使左子级在打开后尽可能早的点开始，右子级在关闭后尽可能早的点开始。 这消除了在 DFS 结构之外排序同级的任何自由。 递归保持每个子树都完全包含在其父区间内，并且不可能进行交错，因为这会违反定义子树创建的邻接约束。 

## Python 解决方案```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

def solve():
    n = int(input())
    left = [0] * (n + 1)
    right = [0] * (n + 1)

    for i in range(1, n + 1):
        l, r = map(int, input().split())
        left[i] = l
        right[i] = r

    res = []

    def dfs(u):
        res.append('(')
        if left[u]:
            dfs(left[u])
        if right[u]:
            dfs(right[u])
        res.append(')')

    dfs(1)
    print(''.join(res))

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```该代码读取每个测试用例的树结构并将子级存储在数组中。 DFS功能是核心的重构机制。 它在输入节点时发出左括号，在处理其子节点后发出右括号，与原始括号对的区间语义相匹配。 

唯一的微妙之处是递归深度。 由于树可以是长度可达 10^5 的链，因此增加了递归限制以避免堆栈溢出。 遍历顺序严格遵循左子节点在右子节点之前，这编码了以下依赖关系：左子节点源自 i+1 个转换，右子节点源自 j+1 个转换。

 ## 边缘情况

 单节点树直接映射到一对括号。 DFS 进入节点 1，打印“(”，找不到子节点，然后打印“)”，准确地生成“()”，这是唯一有效的序列。 

像 1 → 2 → 3 → … → n 这样的深链强调递归深度。 根据结构，遍历会重复进入左（或右）子级，但在下降之前仍然发出一个开口，在返回后发出一个关闭，从而保留正确的嵌套。 堆栈线性增长，但永远不会超过 n 帧。 

仅具有右子节点的节点表明右子节点不与现有内部块中的位置相关联，而是在左子树完成后附加。 DFS 仍然输出正确的嵌套，因为右子树包含在相同的父区间内，但在线性化中出现得较晚，这符合基于 j+1 的构造规则。
