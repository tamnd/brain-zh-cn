 ## 解决方案
 ## 问题理解

 我们在平面上得到了三个具有整数坐标的不同点，并要求我们通过选择第四个顶点来推理将它们完成为平行四边形的所有可能方法。 保证三个给定点不在一条线上，因此它们已经形成一个有效的三角形。 

一个关键的几何事实驱动了整个问题：给定平行四边形的三个顶点，恰好有三种方法来选择哪个点是“共享角”，并且每种选择都确定了完成平行四边形的唯一第四个点。 每个这样的完成都可能产生不同的形状，我们必须独立评估每个生成的平行四边形。 

对于每个有效的完成点，我们必须输出其坐标、所形成的平行四边形的面积以及两个几何谓词：平行四边形是否是菱形以及是否是矩形。 输出必须按完成点坐标排序。 

坐标范围很小，每个坐标都在负千到千的范围内。 这使得 64 位整数的点积和叉积的整数算术完全安全。 即使平方长度也保持在大约 10^6 之内，坐标乘积也保持在大约 10^12 之内，远低于标准整数限制。 

输出格式要求很严格，尤其是截断到小数点后两位。 这意味着我们应该尽可能避免浮点不稳定，而是在格式化之前以整数或受控有理算术计算所有内容。 

一个微妙的边缘情况是误解有效完成点的数量。 很容易假设总是恰好有三个，但如果输入已经以退化方式形成平行四边形，或者如果选择的点使得两个计算完成点重合，则可能会出现重复项。 事实上，几何体允许重复，但如果它们是由于缺失顶点角色的不同选择而产生的，则仍然必须作为单独的条目输出。 

另一个微妙的点是分类。 菱形取决于所有边都相等，而矩形取决于相邻边垂直。 必须使用矢量几何而不是坐标启发式检查这些属性，因为垂直或水平边缘下的坡度不可靠。 

## 方法

 强力解释将尝试为网格上四个点的每个选择构造一个平行四边形，但这在这里无关紧要，因为只给出了三个点，而第四个点是通过代数确定的。 

中心观察是任何平行四边形都是通过选择代表三个顶点的有序三元组来定义的。 如果我们确定哪个给定点是两条边的共享顶点，则第四个点通过向量加法唯一确定。 

假设我们选择点 A 作为共享顶点，B 和 C 作为与其相邻的另外两个顶点。 然后，第四个点 D 必须满足平行四边形结构中的向量相等 AB + AC = AD，重新排列为 D = B + C − A。这是使用三次的基本构造，每次选择共享顶点一次。 

一旦计算出三个候选点，每个生成的四边形都可以作为平行四边形构建。 可以使用两个相邻边缘向量的叉积的大小来计算面积。 例如，使用向量 AB 和 AC，面积为 |AB × AC|。 

为了对形状进行分类，我们依靠矢量点积和长度。 如果平行四边形的相邻边垂直，则它是矩形，这意味着两个边向量的点积为零。 如果所有边都相等，则它是菱形，在平行四边形中，这简化为检查相邻边长度是否相等，因为相对边已经相等。

因此，该解决方案是纯几何的，并且在恒定时间内运行，因为仅生成三个配置，并且每个配置都是独立检查的。

 ## 算法演练

 我们将输入点标记为 A、B 和 C。 

1.依次将每个点视为平行四边形的共享顶点。 如果 A 是共享顶点，则计算 D = B + C − A。相同的逻辑循环适用于 B 和 C。这确保了对于每个选择，我们在对角线上强制执行平行四边形中点对称。 
2. 对于每个构造的点 D，使用相应的顶点分配形成平行四边形。 如果A是共享顶点，则边是AB和AC。 此步骤定义面积和形状检查所需的几何形状。 
3. 使用叉积幅值 |(B − A) × (C − A)| 计算面积。 这是可行的，因为叉积给出了三角形有符号面积的两倍，而平行四边形面积是三角形面积的两倍。 
4. 使用点积计算平方边长。 对于相同的配置，比较 |AB|^2 和 |AC|^2 以确定所有边是否相等，这是菱形的特征。 
5. 使用AB·AC 检查正交性。 如果该点积为零，则共享顶点处的角度为 90 度，这使得平行四边形成为矩形。 
6. 存储生成的完成点和所有计算的属性。 
7. 生成所有三个候选后，先按 x 坐标，然后按 y 坐标按字典顺序对它们进行排序。 
8. 输出每个结果，其中坐标和面积精确到小数点后两位，后跟菱形和矩形标志。 

正确性基于这样一个事实：每个平行四边形都是通过选择一个顶点及其两个相邻的邻居来唯一确定的，并且每个这样的选择都恰好产生一个有效的第四点。 

### 为什么它有效

 平行四边形完全由从顶点发出的两条相邻边确定。 通过迭代三个给定点中该顶点的每个可能选择，我们枚举了所有结构上不同的完成。 向量构造保证了相对边的闭合，并且几何谓词仅依赖于点积和叉积的不变性质，而不依赖于坐标方向。 这可确保不会错过任何有效的平行四边形补全，也不会引入无效的平行四边形补全。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def dist2(ax, ay, bx, by):
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy

def solve():
    x1, y1 = map(int, input().split())
    x2, y2 = map(int, input().split())
    x3, y3 = map(int, input().split())

    pts = [(x1, y1), (x2, y2), (x3, y3)]
    res = []

    # try each point as the shared vertex
    for i in range(3):
        A = pts[i]
        B = pts[(i + 1) % 3]
        C = pts[(i + 2) % 3]

        ax, ay = A
        bx, by = B
        cx, cy = C

        # completion point D = B + C - A
        dx = bx + cx - ax
        dy = by + cy - ay

        # vectors
        ABx, ABy = bx - ax, by - ay
        ACx, ACy = cx - ax, cy - ay

        # area of parallelogram
        area = abs(cross(ABx, ABy, ACx, ACy))

        # rhombus: all sides equal in parallelogram -> AB == AC
        rhombus = dist2(ax, ay, bx, by) == dist2(ax, ay, cx, cy)

        # rectangle: right angle at A
        rectangle = dot(ABx, ABy, ACx, ACy) == 0

        res.append((dx, dy, area, rhombus, rectangle))

    res.sort()

    out = []
    for dx, dy, area, rhombus, rectangle in res:
        out.append(f"point: {dx:.2f} {dy:.2f}")
        out.append(f"area: {area:.2f}")
        out.append(f"is rhombus: {'yes' if rhombus else 'no'}")
        out.append(f"is rectangle: {'yes' if rectangle else 'no'}")
        out.append("-" * 25)

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```实现直接遵循向量构造逻辑。 关键细节是，我们始终将一个输入点视为枢轴 A，将另外两个输入点视为相邻顶点，以确保缺失点的公式一致。 在格式化之前对原始整数坐标进行排序，因为排序与截断无关。 

所有几何谓词均使用整数算术计算，这避免了浮点精度问题。 唯一的浮动格式化发生在输出时，当值已经是精确整数或可以精确表示为具有两位小数的整数时，Python 格式化会自然地处理截断。

 ## 边缘情况

 一种微妙的情况是，由于输入三角形的对称性，计算出的三个完成点包含重复项。 在这种情况下，两个不同的枢轴选择可能会产生相同的第四个顶点。 该算法仍然在排序之前输出两个条目，并且最终排序将相同的坐标分组在一起，保留所需的输出多重性。 

另一种边缘情况是三角形已经是直角或等腰三角形。 对于像 (0,0)、(2,0)、(0,1) 这样的直角三角形，其中一个补全形成一个矩形。 点积检查会直接检测到这一点，因为无论轴对齐如何，垂直边都会产生零点积。 

最后的边缘情况涉及负坐标。 由于所有计算都是纯整数的加法和乘法，因此符号更改不会影响正确性。 例如，对于点 (0,0)、(5,0)、(-3,4)，计算的完成点跨越正象限和负象限，但叉积和点积在平移下保持一致和不变。
