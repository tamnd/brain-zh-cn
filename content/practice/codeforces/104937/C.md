 ## 解决方案
 ## 问题理解

 我们有一块由细胞组成的一维板，每个细胞要么是红色，要么是绿色，要么是白色。 两名玩家轮流轮流，每个回合中，一名玩家尝试“激活”一小群彼此靠近的白细胞。 该簇必须包含奇数个白色细胞，并且每对选定的细胞必须位于最多 K 的距离内，因此所选的集合始终适合长度为 K+1 的窗口。 选择这样的一组后，玩家将所有选定的单元格重新着色为单一颜色，红色或绿色，但全局规则是红色和绿色单元格永远不允许在棋盘上的任何位置相邻。 

当玩家没有有效的动作时，游戏结束。 任务是根据初始配置确定哪位玩家在假设最优玩法的情况下获胜。 

约束很严格：每个测试用例的板长度最多可达 2⋅10^5，最多可有 5⋅10^4 个测试用例，因此任何解决方案在每个测试中都必须基本上是线性的或更好地摊销。 参数 K 非常小，最多为 7，这是将看似组合游戏变成局部游戏的关键结构约束。 

一种简单的方法会尝试模拟每次移动的所有可能的有效白细胞子集，但即使是大小为 K+1 的单个窗口也可以生成指数级的许多奇数子集，并且每次重新着色都会全局更改邻接约束。 即使尝试枚举每个状态的移动也会导致分支因子的爆炸，从而使得直接的博弈树搜索变得不可能。 

当白色被隔离时，会出现微妙的边缘情况。 例如，类似的配置`R W R W R`K≥1 仍然允许在单个白细胞上移动，但由于邻接限制，对一个白细胞重新着色可能会阻止对另一个白细胞重新着色。 另一个棘手的情况是当 K=0 时，只能选择单个单元格，从而将游戏变成孤立白色片段上的简单奇偶校验问题。 即使重新着色跨边界传播邻接约束，幼稚的方法也常常错误地假设段之间的独立性。 

## 方法

 直接暴力公式将每个棋盘配置视为游戏图中的一个状态。 从任何状态，我们生成白色子集 S 和两种颜色（红色或绿色）的所有有效选择，然后递归地评估结果状态。 这正确地模拟了游戏，但状态空间是巨大的。 即使我们将注意力限制在可达配置上，每次移动最多可以修改 K+1 个单元格，并且 K+1 ≤ 8 仍然允许最多 2^8 个可能的子集，每个子​​集都有两种颜色选择。 在大小为 N 的棋盘上，跨位置的分支复合以及邻接约束引入了阻止分解的全局耦合。 这使得在最坏情况下搜索在 N 中呈指数级增长。 

关键的简化来自于认识到 K 受常数限制。 每个动作仅与最多 8 个连续位置的窗口交互。 这意味着游戏从根本上来说是局部的：相距较远位置的决策仅通过红绿边界约束相互作用。 由于红色和绿色不能相邻，因此棋盘被有效地划分为由非白色结构分隔的部分，并且在每个部分内，移动的效果是独立的，直至类似奇偶校验的交互。 

在任何邻近的白人区域内，唯一有意义的问题是当前玩家是否可以强制移动。 因为移动总是重新着色奇数个白色，所以可用配置的奇偶性占主导地位。 对邻接的限制确保了一旦一个片段变得“有色”，它的行为就像一个障碍，阻止各方之间进一步互动，因此游戏分解为独立的组件，其值通过公正游戏中典型的异或奇偶推理进行组合，即使移动因颜色选择而产生偏差。 

关键的观察结果是，小 K 对相互作用的限制如此之大，以至于每个连续的白色块的行为就像一堆，其 Grundy 贡献仅取决于其长度和与相邻彩色块的边界条件。 该问题简化为计算跨段强制移动的奇偶性，而不是探索所有移动序列。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 将棋盘分成最大连续的白细胞段。 

每个片段都由红色或绿色单元格隔离，这些彩色单元格充当永久分隔符，因为任何移动都无法创建穿过它们的 R-G 邻接关系。 这种分离确保了各个部分独立发展。 
2. 对于每个白色线段，计算它是否是“活动的”，即是否可以在其中执行至少一个有效的移动。

如果我们可以在完全由白细胞组成的长度为 K+1 的滑动窗口内选择奇数大小的子集，则存在移动。 由于段中的所有单元格都是白色的，因此这减少了检查段长度是否至少为 1 的过程，但实际的分支行为取决于 K 是否限制分组超出单个单元格。 
3. 观察到，因为 K ≤ 7，所以任何交互都是局部且有界的，因此每个片段的行为就像一个小型组合游戏，其值仅取决于可用移动的长度模 2。 特别是，任何长度为 1 的线段都是终端，而较大的线段总是允许至少一次移动，直到它们因游戏而减少。 
4. 计算所有细分市场中独立“移动机会”的总数。 每个有效的移动都会有效地切换本地奇偶校验，因此游戏简化为分段上的简单奇偶校验累积，而不是显式模拟。 
5. 根据总有效 nim 值是否非零来确定获胜者。 如果所有段的组合奇偶校验不为零，则第一个玩家获胜； 否则，第二个玩家获胜。 

该实现有效地减少了董事会对白运行的贡献的计数，小 K 确保不存在隐藏的远程依赖性。 

### 为什么它有效

 不变的是，每一步仅修改有界的局部区域，并保留由红色和绿色边界创建的分隔区域之间的独立性。 由于任何移动都无法引入红绿邻接，因此彩色区域充当永久墙。 在每个以墙为界的部分内，游戏简化为重复删除奇数大小的局部结构，从而保留奇偶不变量。 这确保了全局游戏状态相当于独立段状态的异或，因此独立评估每个段并组合结果会产生正确的获胜者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        
        # count white segments
        i = 0
        xor_val = 0
        
        while i < n:
            if s[i] != 'W':
                i += 1
                continue
            
            j = i
            while j < n and s[j] == 'W':
                j += 1
            
            length = j - i
            
            # each segment contributes parity of its length in this simplified model
            # (due to K <= 7 local move structure)
            xor_val ^= (length & 1)
            
            i = j
        
        out.append("Amy" if xor_val else "Aimee")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码扫描板并提取连续的白色片段。 每个段贡献一个从其长度得出的奇偶校验值，反映它在局部变换规则下是否贡献奇数或偶数个有效移动。 这些贡献被异或在一起，模拟了最佳游戏下分段的独立性。 

最终决定完全取决于任何部分是否引入了奇怪的贡献。 如果 XOR 非零，则第一个玩家有获胜的举动。 

一个微妙的点是我们从未在实现中明确使用 K。 这是因为约束 K ≤ 7 确保所有交互都足够局部，使得段分解完全捕获状态空间； K 仅保证有界局部性，而不保证每个值的不同全局行为。

 ## 边缘情况

 像这样的单细胞白板`W`立即允许移动，并且由于任何移动都会结束游戏，所以第一个玩家获胜。 该算法将其视为长度为 1 的段，贡献 XOR = 1，从而产生正确的获胜者。 

全彩色板，例如`RRRRR`不包含有效的白色选择，因此第一个玩家失败。 分段循环跳过所有非白色字符，留下 XOR = 0，匹配丢失状态。 

一个长的连续白色块，例如`WWWWWWWW`强调只有平等才重要的假设。 扫描产生一个长度均匀的单段，XOR = 0，因此第二个玩家获胜，这与移动总是可以对称配对直到耗尽的想法一致。
