 ## 解决方案
 ## 问题理解

 我们正在开发一个网格$(1,1)$到$(N,M)$，并且移动仅限于向右或向上移动。 这意味着每条有效路径都是单调的：两个坐标都沿着路径严格增加。 

最重要的是，我们得到了$K$路径必须全部访问的特殊单元格。 仅当路径除了在拐角处开始和结束之外还经过每个所需的单元格时，路径才有效。 

主要困难是所需的积分没有排序。 其中一些可能会产生矛盾，因为单调路径无法访问两个坐标中另一个所需点“之前”的点。 例如，如果需要的一个点是$(2,5)$另一个是$(3,4)$，没有单调路径可以访问两者，因为在两个维度上，任何一个路径都不会以一致的顺序支配另一个路径。 

限制很大：最多$10^5$测试用例，总计$K$在所有测试中也$10^5$，网格尺寸可达$10^5$。 这排除了任何每次测试$O(K^2)$或 DP 通过网格。 该解决方案必须粗略地处理每个测试$O(K \log K)$或更好。 

当所需点与单调排序不一致时，就会出现关键边缘情况。 例如：```
1
3 3 2
2 3
3 2
```不存在有效路径，因为$(2,3)$和$(3,2)$不能以单调序列访问。 任何在不检查可行性的情况下将独立路径段相乘的幼稚计数都会错误地产生肯定的答案。 

当存在重复点时，会出现另一种失败情况。 尽管该语句允许重复的坐标，但单独处理它们可能会重复计算路径，除非对它们进行重复数据删除。 

## 方法

 在没有限制的情况下，自然的想法是尝试访问的所有排列$K$按某种顺序要求的点。 对于每个排序，我们检查它是否是单调的（按两个坐标排序），然后将连续点之间的每个段的二项式系数相乘。 这是正确的，因为在两个固定点之间$(x_1,y_1)$和$(x_2,y_2)$，单调路径的数量为$\binom{(x_2-x_1)+(y_2-y_1)}{x_2-x_1}$。 

问题是有$K!$排列，这是不可能的$K$最多$10^5$。 在点部分排序的最坏情况下，即使限制有效排序也无济于事。 

关键的观察是任何有效路径必须同时以两个坐标的升序访问所需的点。 这意味着我们可以对所有需要的点进行排序$x$，如果两个点共享相同的$x$， 经过$y$。 排序后，我们只需要检查可行性即可：$y$- 坐标也必须是非递减的。 如果此条件失败，则答案为零。 

一旦排序，问题就变成了独立子问题的简单乘积：计算排序链中连续点之间的路径，然后相乘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力排列 |$O(K! \cdot K)$|$O(K)$| 太慢了|
 | 分选+DP产品|$O(K \log K)$|$O(K)$| 已接受 |

 ## 算法演练

 我们将问题简化为一系列单调片段。 

### 步骤

 1.收集所有需要的点并添加起点$(1,1)$和终点$(N,M)$。 

这些定义了路径的完整强制链。 
2. 对所有点进行递增排序$x$，如果$x$相等，通过增加$y$。 

这反映了这样一个事实：如果可能的话，每条右/上路径都必须按此顺序访问点。 
3. 通过扫描排序列表并验证来检查可行性$y$- 坐标不减。 

如果发生任何减少，则返回 0，因为没有单调路径可以满足这两个要求。 
4. 对于每对连续的点$(x_i,y_i)$和$(x_{i+1},y_{i+1})$，计算它们之间的单调路径数：$$\binom{(x_{i+1}-x_i)+(y_{i+1}-y_i)}{x_{i+1}-x_i}$$5. 将所有段计数模数相乘$998244353$。 

每一段都是独立的，因为一旦路径到达所需的点，剩下的选择仅取决于下一段。 
6.输出最终产品。 

### 为什么它有效

 单调路径强加与两个坐标一致的全序。 排序强制执行访问所需点的唯一可能的候选顺序。 可行性检查确保该订单在两个维度上都是一致的。 一旦固定，每个线段就成为一个独立的格路径问题，并且独立性来自于不相交坐标区间中的选择不相互作用的事实。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def comb(n, k):
    if k < 0 or k > n:
        return 0
    k = min(k, n - k)
    res = 1
    for i in range(1, k + 1):
        res = res * (n - k + i) // i
    return res % MOD

def solve():
    T = int(input())
    for _ in range(T):
        N, M, K = map(int, input().split())
        pts = [(1, 1)]
        for _ in range(K):
            x, y = map(int, input().split())
            pts.append((x, y))
        pts.append((N, M))

        pts.sort()

        ok = True
        for i in range(len(pts) - 1):
            if pts[i][1] > pts[i + 1][1]:
                ok = False
                break

        if not ok:
            print(0)
            continue

        ans = 1
        for i in range(len(pts) - 1):
            x1, y1 = pts[i]
            x2, y2 = pts[i + 1]
            dx = x2 - x1
            dy = y2 - y1
            if dx < 0 or dy < 0:
                ok = False
                break
            ways = comb(dx + dy, dx)
            ans = ans * ways % MOD

        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先插入端点，以便所有约束都成为段转换。 排序确保我们执行与单调移动一致的唯一可能的访问顺序。 可行性检查是必要的，因为单独排序并不能保证路径存在； 这$y$-序列也必须是单调的。 

组合函数直接使用二项式系数计算格路径计数，二项式系数表示在总移动中选择正确移动的位置。

 ## 边缘情况

 当所需点不兼容单调排序时，按$x$揭示了减少$y$，立即强制回答0。例如$(2,5)$和$(3,4)$产生一个递减的排序序列$y$，算法在乘法之前停止，正确拒绝不可能的约束。 

什么时候$K=0$，仅保留端点，并且解简化为单个二项式系数$\binom{N+M-2}{N-1}$，自然由同一细分产品结构处理。 

当多个点重合时，排序使它们保持相邻，并且零长度段提供乘法同一性，无需特殊的大小写即可保持正确性。
