 ## 解决方案
 ## 问题理解

 我们给出了有向无环图的完整结构，但边的权重未知。 了解权重的唯一方法是通过交互式预言机：我们选择一对顶点$s, t$和一个标量$c$，预言机返回所有有向路径的总和$s$到$t$。 图中每个边权重乘以后，每条路径贡献其边权重的乘积$c$。 

所以如果一条路径有边$e_1, e_2, \dots, e_k$与原始重量$w_1, w_2, \dots, w_k$，那么缩放后，路径贡献$(w_1 c)(w_2 c)\cdots(w_k c) = (w_1 w_2 \cdots w_k)c^k$。 神谕对所有路径进行求和。 

当我们查询完成后，系统会显示一个值$k$，并且我们必须输出从顶点 1 到顶点的相同路径和$n$缩放下$k$。 

最重要的限制是我们最多允许 999 个查询，而$n \le 1000$和$m \le 5000$。 这排除了任何试图重建单个边权重或枚举路径的策略，因为即使是所有路径的单个成对计算在具有许多分支路径的 DAG 中也已经是指数级的。 

朴素推理的一个微妙的失败案例是认为我们可以通过查询小子问题来隔离边缘。 例如，如果我们查询$f(u, v, c)$只期待直接边缘$u \to v$贡献，这是不正确的：

 如果还有更长的路$u \to x \to v$，那么即使对于像这样的小图$u \to v$,$u \to x \to v$,

 查询已经混合了贡献：$$f(u,v,c) = w_{uv}c + (w_{ux}w_{xv})c^2.$$因此，边缘权重与所有替代路径纠缠在一起，使得局部提取变得不可靠。 

关键的困难在于路径贡献通过乘法和求和在全局范围内相互作用，而我们只观察聚合值。 

## 方法

 蛮力观点将尝试恢复所有边缘权重。 即使在 DAG 中，每条边也会参与指数级多的路径，因此隔离一个权重需要减去所有替代路径的贡献。 这很快就会变得棘手，因为每个查询都会在所有路径上返回一个类似于全局多项式的表达式。 

关键的观察是对于固定端点$1$和$n$，答案作为函数$c$不是任意的。 每条路径贡献的项与$c^{\text{length}}$，所以整个表达式变成了一个多项式$c$:$$f(1,n,c) = \sum_{d \ge 1} a_d c^d,$$在哪里$a_d$是所有长度路径的总贡献$d$，每个都由原始边权重的乘积加权。 

不存在常数项，因为从 开始不存在长度为零的路径$1$到$n$什么时候$1 \ne n$。 这最多将问题转化为重建一个度数$n-1$没有常数项的多项式。 一旦我们知道了这个多项式，回答最终的查询就只是评估$c = k$。 

因此，我们不是学习图形，而是学习多项式。 

我们可以通过直接查询来获取该多项式的值$f(1,n,c)$对于选定的值$c$，然后进行插值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（恢复边缘/路径）| 指数| 高| 太慢了 |
 | 多项式插值$f(1,n,c)$|$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 该解决方案将一切简化为采样和重建多项式。 

1. 查询预言机$f(1,n,c)$999 个不同的值$c$， 例如$c = 1, 2, \dots, 999$。 每个查询返回一个未知多项式上的一个点$P(c)$。 除了确保函数定义良好之外，图结构无关紧要。 
2. 存放每对$(c_i, y_i)$， 在哪里$y_i = P(c_i)$。 这些是对次数最多为 999、常数项为零的单个多项式的评估。 
3. 重构多项式$P(c)$模数$998244353$在 999 个点上使用插值。 直接一个$O(n^2)$拉格朗日插值在此尺度上就足够了。 
4.重建后，读取值$k$来自交互者。 
5. 评估$P(k)$使用重建的表示并输出结果。 

唯一微妙的一点是确保插值是模数完成的$998244353$，其中所有除法都替换为模逆。 

### 为什么它有效

 每个查询都有固定的$(1,n)$和变量$c$生成一个多项式，其系数汇总了按长度分组的所有路径的贡献。 由于每条路径恰好贡献一个单项式$c^{\text{length}}$，整个函数是单项式的和，因此是多项式。 

不同的值$c$给出同一个多项式的评估。 当已知常数项为零时，次数最多为 999 的多项式由 999 次不同的计算唯一确定。 这保证了插值步骤准确地重建了原始函数，因此对其进行评估$k$给出所需的答案。 

## Python 解决方案```python
import sys

input = sys.stdin.readline
MOD = 998244353

def inv(x):
    return pow(x, MOD - 2, MOD)

def lagrange(x, xs, ys):
    n = len(xs)

    pre = [1] * n
    suf = [1] * n

    for i in range(1, n):
        pre[i] = pre[i - 1] * (x - xs[i - 1]) % MOD
    for i in range(n - 2, -1, -1):
        suf[i] = suf[i + 1] * (x - xs[i + 1]) % MOD

    res = 0
    for i in range(n):
        num = pre[i] * suf[i] % MOD
        den = 1
        for j in range(n):
            if i != j:
                den = den * (xs[i] - xs[j]) % MOD
        res = (res + ys[i] * num % MOD * inv(den)) % MOD

    return res

def main():
    n, m = map(int, input().split())
    for _ in range(m):
        input()

    xs = []
    ys = []

    for c in range(1, n):
        print(f"? 1 {n} {c}")
        sys.stdout.flush()
        xs.append(c)
        ys.append(int(input()))

    print("!")
    sys.stdout.flush()

    k = int(input())
    print(lagrange(k, xs, ys))

if __name__ == "__main__":
    main()
```程序在读取图形边缘后完全忽略它们，因为所有必需的信息都嵌入到交互式多项式中$f(1,n,c)$。 

主循环查询$c = 1$到$n-1$, 准确采集$n-1$点，它与多项式中未知系数的数量相匹配（除零常数项之外的所有路径长度贡献）。 收到后$k$，它使用拉格朗日插值法重建多项式并对其进行评估。 

插值例程构建前缀和后缀乘积，以有效地计算每个点的分子。 分母按每项直接计算，并使用模幂求逆。 

## 工作示例

 由于这是交互式的，请考虑一个最小的概念示例。 

假设只有两个顶点具有单边$1 \to 2$重量$w$。 然后：$$f(1,2,c) = wc.$$我们会查询：

 | 询问$c$| 返回值 |
 | ---| ---|
 | 1 |$w$|
 | 2 |$2w$|
 | 3 |$3w$|

 这重建了多项式$P(c) = wc$，并评估于$k$给出$wk$。 

稍微复杂一点的情况：

 假设有两条路径：$1 \to 2 \to 3$有重量$a, b$，和一条直接边$1 \to 3$有重量$d$。 

然后：$$f(1,3,c) = dc + (ab)c^2.$$查询：

 | c | 价值|
 | ---| ---|
 | 1 |$d + ab$|
 | 2 |$2d + 4ab$|
 | 3 |$3d + 9ab$|

 根据这些评估，插值分离线性和二次分量，恢复完整的多项式结构。 

这证实了该方法正确捕获了直接贡献和多步骤贡献。

 ## 边缘情况

 当没有路径从$1$到$n$。 然后每个查询都返回零，无论$c$，产生零多项式。 插值将所有系数重建为零，并且最终答案在任何时候都正确为零$k$。 

另一种边缘情况是所有路径都具有相同的长度。 那么该多项式只有一个非零系数。 例如，如果所有路径的长度都是 3，则每个查询返回的倍数$c^3$，并且插值自然地恢复单项多项式而没有不稳定。 

最后一种情况是当$n = 1$。 然后$f(1,1,c)$对于所有人来说都是 1$c$（空路径），因此多项式是常数。 该算法仍然有效，但只需要退化插值，无论什么，最终答案都是1$k$。
