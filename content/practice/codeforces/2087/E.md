 ## 解决方案
 ## 问题理解

 我们得到一系列排成一行的箭头，每个箭头指向左或右。 每个箭头还有一个关联的整数奖励，用于将其涂成红色，该奖励可以是正数、负数或零。 最初，所有箭头都是蓝色的。 游戏允许您执行一系列重新绘制操作，从任何箭头开始，然后在后续的每个动作中，您必须选择前一个方向的箭头。 也就是说，如果前一个箭头指向左侧，则下一个箭头必须位于较小的索引处； 如果它指向右侧，则下一个箭头必须位于更大的索引处。 箭头不必相邻。 

目标是最大化所有重新涂成红色的箭头的奖励总和。 每个查询对应一个测试用例，最多可达$3 \cdot 10^5$箭头，并且所有测试用例中所有箭头的总和不超过$3 \cdot 10^5$。 这个约束立即表明任何解决方案都必须在相对于箭头数量的线性时间内处理每个测试用例。 

边缘情况很微妙，因为有些奖励可能是负面的。 在这些情况下，有时完全跳过箭头是最佳选择。 例如，如果所有奖励都是负数，则可达到的最高分数为零。 当所有箭头都指向同一方向时，会出现另一种边缘情况； 最佳序列可能涉及仅在方向链的末端选择最大的奖励，而不是从中间的任何地方开始。 

## 方法

 暴力方法会考虑从每个箭头开始并递归地模拟每个有效的重画序列。 对于每个起始索引，算法将根据当前箭头的方向进行分支，并考虑每个可能的有效下一个箭头。 这种方法是正确的，但显然不可行，因为在最坏的情况下，它探索了指数数量的序列，远远超出了限制$n \approx 3 \cdot 10^5$。 

关键的观察是，指向同一方向的每个箭头序列形成一个独立的链，可以在其中贪婪地执行奖励选择。 如果我们从左到右遍历箭头，对于向右指向的箭头，我们可以传播运行的最大和，对于向左指向的箭头，类似地从右向左遍历。 实际上，我们可以将问题视为计算每个箭头从该箭头（如果包含该箭头）开始可获得的最大贡献，然后在所有箭头上选择最大的此类贡献。 这通过计算两个数组来减少线性时间的解：一个将“>”箭头的最大和向右传播，另一个将“<”箭头的最大和向左传播。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取箭头的数量$n$、一串指示和一系列奖励。 
2.初始化两个数组`dp_right`和`dp_left`长度$n$，用零填充。 这些将存储从每个方向的每个箭头开始可获得的最大总和。 
3. 从左向右移动箭头。 如果当前箭头指向右（'>'），则设置`dp_right[i] = reward[i] + max(0, dp_right[i-1])`。 否则，设置`dp_right[i] = 0`。 这会累积连续的向右箭头序列并跳过负和序列。 
4. 从右向左移动箭头。 如果当前箭头指向左（'<'），则设置`dp_left[i] = reward[i] + max(0, dp_left[i+1])`。 否则，设置`dp_left[i] = 0`。 这会累积连续的向左箭头序列。 
5. 测试用例的答案是所有结果中的最大值`dp_right[i]`和`dp_left[i]`，因为允许在任何箭头处开始序列。 还要在最大值中包含 0，以说明跳过所有箭头。 
6. 打印结果。 

为什么它有效：定向传播确保对于每个箭头，我们考虑通过继续其指向方向可获得的最大总和。 通过对所有起始位置取最大值，我们捕获所有可能的操作序列。 由于以下原因，负奖励被自动排除`max(0, ...)`逻辑，它对执行零操作的选择进行建模。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        c = list(map(int, input().split()))
        
        dp_right = [0] * n
        dp_left = [0] * n
        
        # propagate for '>' arrows
        for i in range(n):
            if s[i] == '>':
                dp_right[i] = c[i]
                if i > 0:
                    dp_right[i] += max(0, dp_right[i-1])
        
        # propagate for '<' arrows
        for i in reversed(range(n)):
            if s[i] == '<':
                dp_left[i] = c[i]
                if i < n-1:
                    dp_left[i] += max(0, dp_left[i+1])
        
        ans = 0
        for i in range(n):
            ans = max(ans, dp_right[i], dp_left[i])
        
        print(ans)

if __name__ == "__main__":
    solve()
```该代码通过扫描数组两次（一次从左到右，一次从右到左）来保持线性时间复杂度。 使用`max(0, ...)`自动丢弃具有负贡献的序列，避免不必要的操作。 通过在传播之前检查数组索引来仔细处理边界条件。

 ## 边缘情况

 对于所有箭头都指向同一方向的序列，算法会正确地沿该方向传播总和并自动选择最大连续子序列。 对于具有负奖励的序列，`max(0, ...)`逻辑确保不包含任何负面贡献。 在单箭头序列中，最大值要么是奖励，要么是零。 对于空操作，答案默认为零，正确处理最好不要重新绘制任何箭头的情况。
