 ## 解决方案
 ## 问题理解

 我们被要求组织一场竞技比赛的表演赛，其中包括$2n$独特的玩家，每个人都有独特的评级。 关键要求是每个玩家都应该与评级最接近的另一位玩家配对。 更准确地说，每个玩家都有一个或多个“最佳对手”，定义为那些评分与自己的绝对差异最小的玩家。 任务是确定是否可以形成$n$不相交的配对，使得在每一对中，两个参与者都是彼此最好的对手。 

输入很简单：测试用例的数量$t$， 其次是$t$测试用例块。 每个测试用例给出$n$和一个列表$2n$评级。 如果在最佳对手标准下存在完美配对，则输出为“是”，否则输出为“否”。 

限制很小：$n$最多可以达到 50，所以$2n \le 100$，评级高达$10^5$。 这意味着即使是$O(n^2)$算法将在时间限制内顺利运行，但采用暴力方法检查所有$n!$可能的配对是不可行的。 

当评级分散时，最接近的邻居形成一条链，但该链无法完美匹配时，就会出现微妙的边缘情况。 例如，通过评级`[1, 3, 5, 8]`，配对最近的邻居产生`(1, 3)`和`(5, 8)`。 这里，3的最佳对手是1，5的最佳对手是3，8的最佳对手是5。`(1, 3)`和`(5, 8)`有效，但如果我们尝试过`(1, 5)`和`(3, 8)`，配对失败。 仅通过邻近度任意对元素进行配对的粗心方法将在此类序列上失败。 

## 方法

 蛮力方法是生成所有可能的配对方式$2n$玩家并检查每对是否是共同的最佳对手。 每个配对都可以表示为完美匹配，其中有$(2n-1)!!$的可能性。 为了$n = 50$，这是一个天文数字。 蛮力之所以有效，是因为从概念上讲它保证了正确性，但由于组合爆炸，它是不切实际的。 

关键的见解是，当评级排序时，最佳对手关系是本地的。 对评级进行排序可以保证对于任何玩家来说，最接近的评级都是相邻的。 由于所有评级都是不同的，因此每个玩家都有一个最好的对手：使绝对差异最小化的相邻评级。 因此，对评级列表进行排序并将相邻玩家配对就足够了。 如果$2n$是偶数，我们可以配对玩家`(a[0], a[1]), (a[2], a[3]), ..., (a[2n-2], a[2n-1])`。 该配对中的每个玩家都按排序顺序与他们最好的对手相邻，这保证了相互性。 如果相邻评级之间没有最小差异，则完美匹配是不可能的。 

这一观察结果将问题简化为排序和检查相邻差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((2n)!/n!) | O((2n)!/n!) | O(n) | 太慢了|
 | 排序 + 相邻配对 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$和名单$2n$不同的评级。 
3. 按升序对评级进行排序。 排序可确保最接近的评级是相邻的，这是由评级的独特性保证的。 
4. 对于每对相邻的评级`(ratings[2*i], ratings[2*i + 1])`，检查与其邻居的差异。 如果`ratings[2*i+1] - ratings[2*i]`与任何其他评级相比，两个玩家的值都是最小的，那么这对玩家是有效的。 由于排序保证了邻接性，因此我们只需要检查与相邻对的差异。 
5、如果所有相邻对都满足最小差性质，则输出YES； 否则，输出NO。 

为什么有效：排序可确保每个玩家的最近邻居紧邻他们之前或之后。 在排序列表中按顺序对玩家进行配对可确保每个玩家都与其最接近的可能对手相匹配。 由于评级是不同的，因此每个玩家的最小差异是唯一的，并且发生在相邻评级中。 这个不变量保证了构建的配对满足相互的最佳对手要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        valid = True
        for i in range(0, 2*n, 2):
            # check if the left neighbor is closer than previous pair, or right neighbor
            left_diff = a[i+1] - a[i]
            if i > 0:
                prev_diff = a[i] - a[i-1]
                if prev_diff < left_diff:
                    valid = False
                    break
            if i + 2 < 2*n:
                next_diff = a[i+2] - a[i+1]
                if next_diff < left_diff:
                    valid = False
                    break
        print("YES" if valid else "NO")

if __name__ == "__main__":
    solve()
```该解决方案首先对评级进行排序，以使最接近的评级相邻。 然后，它以两步迭代来检查每对与其直接邻居之间的最小差异属性。 这确保了每一对都由彼此最好的对手组成。 边界检查可防止访问列表末尾的邻居时出现超出范围的错误。
