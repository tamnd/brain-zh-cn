 ## 解决方案
 ## 问题理解

 我们正在处理 Nim 的一个变体，这是一种经典的两人公正游戏。 在标准 Nim 中，游戏的状态是由石子堆定义的。 轮到玩家时，玩家选择任何非空的石堆并移走一颗或多颗石子。 最后能够移动的玩家获胜。 使用所有堆大小的 XOR（数量）可以有效地确定获胜者。 如果 XOR 为零，则第二个玩家有获胜策略； 否则，第一个玩家就这样做。 

在这个问题中，移动存在动态限制。 有一组“特殊数字”$S$，最初是空的。 该限制的作用如下：如果玩家试图减少一堆$x$到$y$并且存在一个数字$s \in S$这样$x > s > y$，此动作被禁止。 实际上，玩家无法跳过该组中的任何数字$S$。 查询切换数字$S$或者根据一组特定的牌堆询问获胜者。 如果第一个玩家可以强制获胜，则类型 2 查询的输出为“First”，否则为“Second”。 

限制很严格：我们最多可以有 300,000 个查询，每个查询最多涉及三个堆，堆大小和特殊编号最多为 300,000 个。 这排除了任何明确枚举所有可能的游戏状态的方法。 相反，我们需要一种在处理变化的集合时有效计算数字的方法$S$。 

当桩非常小时，当桩与中的数字匹配时，就会出现边缘情况$S$，或者当切换数字时$S$影响之前的假设。 例如，如果$S = \{2\}$一堆的大小为 3，唯一允许的移动是将其减少到 2 或 1； 禁止直接将其减至0。 忽略这一限制的幼稚方法会预测出错误的获胜者。 

## 方法

 蛮力方法将把每一堆建模为一个独立的游戏，并递归地计算格伦迪数。 对于一堆大小$x$，我们将生成所有合法的移动，计算结果位置的 Grundy 数，并采用 mex。 虽然正确，但这是不可行的：当堆大小高达 300,000 和 300,000 个查询时，递归计算的数量将会爆炸，导致最坏情况的复杂性远远超出合理限制。 

关键的见解是禁止的数字将非负整数划分为连续的区间。 每个区间内$[l, r]$，在区间内所有从一堆到更小尺寸的移动都是允许的。 跨越间隔的移动受到限制。 对于给定的集合$S$，我们可以通过利用这些间隔来有效地预先计算每个可能的桩尺寸的数量。 具体来说，如果我们对特殊数字进行排序并考虑连续数字之间的间隔，则每个间隔的行为类似于标准 Nim，但会移动下限。 任何堆的 Grundy 数就是它在模 2 的区间内的位置，因为每个区间的行为就像一个小的 1 堆 Nim 堆，交替 Grundy 数。 更新中$S$动态地只需要更新区间边界。 

这将问题简化为维护特殊数字的排序列表并根据其间隔在恒定时间内计算每个堆的数量。 这些数字的异或给出了获胜者。

 ## 算法演练

 1. 维护一个排序列表或一组数字$S$。 排序或使用平衡 BST 确保我们可以找到任意一堆的间隔$O(\log |S|)$。 
2. 对于切换的查询$s_i$，检查是否$s_i$存在于集合中。 如果存在，则将其删除； 否则，将其插入。 更新集合会自动更新间隔。 
3. 对于类型 2 查询，迭代每一堆$a_j$。 找到最近的小于和大于的特殊数字$a_j$来识别区间$[l, r]$含有$a_j$。 
4. 计算数字$a_j$作为$a_j - l$。 如果构造间隔来处理模 2 模式，则这会给出反映受限移动的正确 Grundy 数。 
5. 对查询中所有桩的编号进行异或。 如果结果为零，则打印“Second”； 否则，打印“First”。 
6. 对所有查询重复此操作。 

为什么有效：通过将桩映射到由特殊数字定义的间隔，我们将复杂的禁止移动规则简化为间隔内的标准 Nim。 每个间隔的行为都是独立的，并且根据间隔偏移计算出的数字遵守约束。 这些数字的异或正确地预测了获胜者，因为间隔形成了不相交的子游戏，从而保持了公正的游戏结构。 

## Python 解决方案```python
import sys
import bisect
input = sys.stdin.readline

q = int(input())
S = []

for _ in range(q):
    tmp = list(map(int, input().split()))
    if tmp[0] == 1:
        s = tmp[1]
        idx = bisect.bisect_left(S, s)
        if idx < len(S) and S[idx] == s:
            S.pop(idx)
        else:
            S.insert(idx, s)
    else:
        k = tmp[1]
        piles = tmp[2:]
        xor_sum = 0
        for pile in piles:
            idx = bisect.bisect_right(S, pile)
            l = S[idx - 1] if idx > 0 else 0
            xor_sum ^= pile - l
        print("First" if xor_sum != 0 else "Second")
```该代码使用二分搜索来维护特殊数字的排序列表，以进行插入、删除和区间查找。 对于每一堆，间隔由最接近的较小特殊数字确定。 减去下界给出数字，XOR 组合独立的子游戏。 堆小于任何特殊数字的边缘情况通过使用零作为左边界来处理。
