 ## 解决方案
 ## 问题理解

 给定一个整数数组，需要构造一个仅包含 1、2 或 3 的并行标签数组。目标是恰好满足三个配对条件中的两个，每个配对条件涉及两个索引，其中原始数字相等，并且分配的标签形成对 (1,2)、(1,3) 或 (2,3) 之一。 本质上，我们试图对数组中的重复项进行着色，以便这三个“颜色对”中的两个出现在重复项中的某个位置，但第三个却没有。 

输入由多个测试用例组成。 每个测试用例都有一个大小最多为 100 的数组，数组元素以 100 为界。由于数组大小很小，我们可以提供每个测试用例进行二次运算的解决方案，但我们仍然应该寻找一种简单直接的方法。 边缘情况包括所有数字都相同的数组、没有重复项的数组或恰好有两个重复项的数组。 例如，一个数组`[7,7,7,7,7,7,7]`不能恰好满足两个条件，因为任何重复项的标记都将满足所有三个条件，因此输出必须是`-1`。 另一个微妙的情况是只有唯一元素的数组； 不存在对，因此解决方案是不可能的。 

## 方法

 简单的暴力方法会尝试为每个元素分配标签 (1,2,3)，并检查是否恰好满足两个条件。 对于大小的数组`n`， 那是`3^n`的可能性，即使对于`n=20`，所以我们需要一种更聪明的方法。 关键的观察结果是，所有三个条件仅取决于成对的相等数字。 因此，我们可以专注于重复项。 

如果一个元素出现三次或多次，我们就有足够的自由来分配标签来恰好满足两个条件。 我们可以将前两次出现标记为 1 和 2，满足条件 (1,2)，然后将第三次出现标记为 3，这样可以满足条件 (1,3) 或 (2,3)。 如果我们小心的话，我们可以选择标签来恰好满足三个条件中的两个。 

如果所有重复项最多出现两次，那么我们必须仔细分析。 所有元素恰好重复两次的数组允许我们将标签 1 和 2 分配给一个元素，然后将 1 和 2 分配给另一个元素，但条件 (1,3) 或 (2,3) 可能会失败。 如果没有元素出现超过两次，并且没有足够的重复项来区分标签，则该问题可能无法解决。 具有所有唯一元素或仅成对重复元素的数组通常无法恰好满足两个条件，从而产生`-1`。 

最佳解决方案的工作原理是按频率对数组元素进行分类。 如果一个元素出现三次或多次，它就成为“flex”元素，允许我们控制哪两个条件成立。 否则，如果所有重复项只出现两次，我们会仔细为一个元素分配标签 1 和 2，为其他元素分配标签 1 和 2，以确保只满足两个条件。 如果结构不允许恰好两个条件，我们输出`-1`。 这种方法是线性的`n`对于每个测试用例，因为我们只迭代数组并根据计数分配标签。

 ## 算法演练

 1. 统计数组中每个数字出现的频率。 这使我们能够知道哪些数字是重复的以及它们出现了多少次。 
2.初始化输出数组`b`带零。 这将保存标签 1、2 或 3。 
3. 跟踪是否存在频率至少为 3 的数字。如果存在这样的数字，我们可以为其前三个出现分配标签 1、2、3。 这很重要，因为它允许我们控制满足哪两个条件。 
4. 对于所有其他重复项（频率 2），分配标签 1 和 2。这些分配自动满足该数字的第一个条件 (1,2)。 
5. 如果没有频率至少为 3 的数字且频率为 2 的重复数为奇数，则不可能恰好满足两个条件。 输出`-1`在这种情况下。 奇数计数将迫使所有三个条件都得到满足。 
6. 对于任何剩余元素（频率 1），默认分配标签 1。 这些不会影响这三个条件中的任何一个，因此不会影响计数。 
7、输出构造好的数组`b`。 

工作原理：通过让“flex”元素出现三次，我们可以分配标签 1、2、3 以有选择地满足两个条件。 频率为 2 的重复项仅满足 (1,2) 条件，因此我们避免无意中创建第三个条件。 如果没有元素的频率≥3并且频率为2的元素的数量是奇数，则任何标签都将满足所有三个条件，因此我们报告`-1`。 不变的是，只有仔细标记的重复项才有助于满足条件，从而使我们能够控制计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    freq = {}
    for x in a:
        freq[x] = freq.get(x, 0) + 1
    
    b = [0] * n
    idx_map = {}
    for i, x in enumerate(a):
        if x not in idx_map:
            idx_map[x] = []
        idx_map[x].append(i)
    
    # Find a number with at least 3 occurrences
    flex_idx = -1
    for num, positions in idx_map.items():
        if len(positions) >= 3:
            flex_idx = num
            break
    
    if flex_idx != -1:
        # assign 1,2,3 to first three occurrences
        positions = idx_map[flex_idx]
        b[positions[0]] = 1
        b[positions[1]] = 2
        b[positions[2]] = 3
        # assign 1,2 to remaining duplicates if any
        for pos in positions[3:]:
            b[pos] = 1
        # assign 1,2 to all other duplicates (frequency 2)
        for num, positions in idx_map.items():
            if num == flex_idx:
                continue
            if len(positions) == 2:
                b[positions[0]] = 1
                b[positions[1]] = 2
            elif len(positions) == 1:
                b[positions[0]] = 1
    else:
        # Count elements with frequency 2
        pairs = [num for num, positions in idx_map.items() if len(positions) == 2]
        if len(pairs) % 2 == 1:
            print(-1)
            continue
        flip = True
        for num, positions in idx_map.items():
            if len(positions) == 2:
                if flip:
                    b[positions[0]] = 1
                    b[positions[1]] = 2
                else:
                    b[positions[0]] = 2
                    b[positions[1]] = 1
                flip = not flip
            else:
                b[positions[0]] = 1
    print(' '.join(map(str, b)))
```该代码首先构建频率图和索引列表以有效地处理重复项。 这`flex_idx`element 允许选择性分配 1,2,3，这是恰好满足两个条件的核心见解。 对于没有 flex 元素的数组，频率 2 元素的交替分配可以防止意外创建第三个条件。 默认情况下，单例标记为 1，因为它们不影响任何条件。
