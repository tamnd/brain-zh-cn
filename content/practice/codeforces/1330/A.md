 ## 解决方案

 ## 问题理解

 我们获得参与者的比赛结果历史记录，其中每个结果都是一个排名（名次）。 之后，我们可以想象更多的未来比赛，确切地说`x`其中，我们可以任意选择未来比赛中的排名。 

目标是确定使用现有结果和这些结果可以“覆盖”多少个最小的正排名`x`假设的未来结果。 换句话说，我们想要最大的整数`v`这样每个等级都来自`1`到`v`在旧结果加上一些选择中至少出现一次`x`额外的结果。 

关键是，未来的比赛可以分配任何排名值，因此它们充当灵活的“插槽”，可以填补缺失的排名。 约束只是我们有确切的`x`这样的插槽。 

尽管输入大小很小，但问题本质上是关于计算正整数前缀中的缺失值。 

一种简单的方法是尝试模拟增加值或贪婪地测试每个值的可行性`v`，但困难在于理解缺失的排名只在一定范围内起作用。 

当当前结果已包含重复排名时，会出现微妙的边缘情况。 例如，如果所有`a_i = 1`，那么更高的排名完全缺失，未来的位置必须覆盖它们。 

另一个重要的边缘情况是当`x`足够大以填补所有空白：那么只要未来有足够的比赛来分配缺失的排名，答案就可以超出输入中看到的最大值。 

## 方法

 一个蛮力的想法是尝试增加`v`从 1 向上，对于每个`v`，检查我们是否可以覆盖所有数字`1`到`v`使用现有数组加上最多`x`额外的价值。 检查固定方案的可行性`v`，我们将标记其中的数字`[1, v]`已经存在于`a`，计算缺失的数量，并确保这个数量不超过`x`。 

这是有效的，因为每个缺失值都需要至少一场未来的竞赛来“创建”它。 但是，为每个独立执行此操作`v`需要重复扫描数组，导致粗略`O(n * max_value)`在最坏的情况下每个测试用例，考虑到限制，这是不必要的。 

关键的观察结果是，答案取决于前缀中缺少多少个不同的整数`[1, v]`。 如果我们跟踪当前数组中的哪些数字落入该范围，我们可以维护已覆盖值的计数并增量扩展`v`直到缺失值的数量超过`x`。 

我们可以维护一个频率数组或一个布尔存在数组，其值达到安全界限（略高于 100+）`x`）。 然后我们模拟增加`v`，计算中有多少个数字`[1, v]`仍然失踪。 一旦缺失超过`x`，我们停下来。 

这将问题转化为对可能值的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * V) | O(V) | 太慢了|
 | 最佳 | O(n + V) | O(V) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 为给定数组中的所有值构建频率或存在集。 这告诉我们我们已经拥有哪些排名。 
2. 从`v = 1`并维护一个计数器`missing`，代表有多少个数字`[1, v]`不存在于数组中。 
3. 对于每个`v`，检查数组中是否存在。 如果没有，则增加`missing`因为这个排名需要使用其中之一来“创建”`x`未来的比赛。 
4. 停止时`missing`变得大于`x`。 最后有效`v`就是答案。 

我们向上扫描的原因是，条件变得更加困难，因为`v`增加。 每个新数字要么不增加成本（如果已经存在），要么消耗一个单位的有限的未来灵活性。 

### 为什么它有效

 在任何时候，覆盖前缀`[1, v]`需要确保该范围内每个缺失的数字都由未来的比赛提供。 未来的每场比赛都会贡献一个排名，因此我们只能修复`x`缺失值。 该算法准确地跟踪需要多少修复`v`成长。 由于只有当我们传递缺失的数字时，要求才会增加，因此第一次超过`x`，不大于`v`可以有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))

        present = [False] * 300  # safe upper bound: 100 + 100 + margin
        for v in a:
            present[v] = True

        missing = 0
        v = 0

        while True:
            v += 1
            if v < len(present) and not present[v]:
                missing += 1
            if missing > x:
                print(v - 1)
                break

def main():
    solve()

if __name__ == "__main__":
    main()
```该解决方案首先为输入中的所有排名构建一个存在表。 这允许恒定时间检查排名是否已经存在。 

然后它递增`v`步步。 每次考虑新数字时，它都会更新缺少的所需排名数。 一旦这个超过`x`，之前的值是最大可实现的前缀。 

循环限制是安全的，因为即使在最坏的情况下，我们只需要考虑大约`max(a_i) + x`。

 ## 边缘情况

 当所有元素都相同时，例如`a = [1, 1, 1]`，仅排名`1`最初被覆盖。 该算法仅标记`1`存在并立即为每个增量缺失`v ≥ 2`。 与小`x`，它会快速停止，正确限制前缀可以延伸的距离。 

什么时候`x = 0`，该算法变成纯粹的前缀完整性检查。 它停在第一个缺失的数字处，这与未来的比赛无法弥补差距的事实相符。 

当所有值都很大时，例如`a = [80, 90]`，早期值全部缺失。 该算法计算缺失值`1`向上并消耗`x`快速、正确地弹跳`v`靠近`x`。
