 ## 问题理解

 我们给定一个序列`b`长度`n`，代表鲍勃的猜测，和两个整数`x`和`y`描述这个猜测如何与未知的隐藏序列重叠`a`相同长度的。 隐藏序列使用的颜色来自`1`到`n+1`，这意味着始终至少有一种备用颜色可用。 

价值`x`计算精确匹配：位置`i`在哪里`a[i] == b[i]`。 价值`y`如果我们忽略顺序，则计算有多少个元素匹配，因此它是之间的总多重集交集大小`a`和`b`。 

我们必须构造任何有效的隐藏数组`a`符合这两个约束，或者报告这是不可能的。 

约束很严格：`n`总计最多为`10^5`跨所有测试用例，因此每个测试用例的任何解决方案都必须是线性或接近线性的。 尝试搜索或回溯分配的解决方案将立即失败，因为即使`O(n^2)`每个测试用例太大。 

棘手的部分是`x`和`y`同时限制位置匹配和频率重叠。 一个天真的尝试，首先迫使`x`匹配然后贪婪地填充剩余元素经常会中断`y`，因为多重集约束全局耦合所有位置。 

一个微妙的失败案例是当我们贪婪地匹配`b`为时过早，没有为以后的不匹配保留结构。 例如，如果我们尝试始终重用`b[i]`只要有可能，我们就可能会意外地膨胀`y`超出允许范围或无法为不匹配的位置保留足够的不同颜色。 

关键的隐藏结构是，我们实际上将位置分为两种类型：必须完全匹配的位置，以及必须有助于多重集重叠但不一定位于同一索引的位置。 

## 方法

 一个蛮力的想法是将值分配给`a`并验证约束条件。 由于每个位置最多有`n+1`选择，这变成`(n+1)^n`，即使对于`n = 10`。 

一个不太天真的想法是修复`x`位置完全匹配，然后尝试分配剩余的值，以便完全匹配`y - x`附加值在多重集中匹配，但位置不匹配。 即使这也成为了剩余颜色之间的匹配问题`b`和展示位置`a`，并且没有结构的朴素匹配会导致每个配置呈指数或至少二次配对尝试。 

关键的观察是，我们实际上从来不需要“搜索”其中的值`a`。 相反，我们可以构建`a`通过利用总是有一种额外的颜色可用这一事实，以一种受控的方式（`n+1`）。 这种额外的颜色可以作为安全的填充物，避免意外增加`y`。 

我们可以认为建设分两个阶段。 首先，我们决定哪些位置需要强制匹配以满足`x`。 其次，我们确保准确`y`通过仔细选择我们重用其中值的位置，多重集中的总重叠`b`我们通过使用“安全颜色”故意避免它们。 

主要思想是首先贪婪地假设每个位置都是多集项中的匹配，然后将重叠减少到精确`y`通过使用备用颜色打破一些火柴。 然后我们调整位置匹配以确保准确`x`指数保持固定。 

这将问题转化为在全局频率约束下选择精确匹配和不匹配的位置，这可以通过对位置进行排序和策略性地分配值来处理。

 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(n) | 太慢了 |
 | 建设性的贪婪与备用颜色| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们构建`a`使用频率控制和两阶段分配。 

### 1. 计算频率`b`我们计算每种颜色在鲍勃的猜测中出现的次数。 这是必要的，因为多集重叠`y`完全取决于我们重复使用这些事件的次数。 

我们还准备了按值分组的索引列表，因为我们可能需要选择特定位置来进行精确匹配。 

### 2.选择精确匹配的位置

 我们必须准确地选择`x`索引其中`a[i] = b[i]`。 

一个自然的贪婪选择是优先考虑频率较高的颜色，但我们不需要复杂的选择。 我们可以最初将所有位置标记为未分配，然后准确执行`x`通过在有效候选人中仔细选择职位来进行匹配。 

我们维护一个候选人职位库并准确分配`x`其中要匹配的`b[i]`。 

### 3. 控制多集重叠相等`y`如果我们匹配所有地方的所有内容，我们将获得最大可能的重叠等于`n`。 我们必须将其精确地减少到`y`。 

每个职位都贡献`y`如果`a[i] == b[i]`。 由于精确匹配已经固定为`x`职位，我们还需要`y - x`没有位置相等的附加多集匹配。 

为了实现这一点，我们从概念上分配剩余值`a`所以确切地说`y`总位置与值匹配`b`数组中的某个位置，但不一定位于同一索引处。 

我们通过允许`y - x`“安全重用”位置并迫使所有其他位置采用新颜色`n+1`，这保证对多重集重叠没有贡献。 

### 4. 使用轮换技巧避免自我冲突

 为了确保我们不会意外地在同一索引处创建额外的匹配项，我们以移位的方式分配重用值。 我们获取所有不固定匹配的索引并旋转它们`b`其中的值，跳过自我分配。 

这确保了我们最大限度地提高安全匹配，同时防止不需要的精确匹配。 

### 5. 用虚拟颜色填充剩余位置

 任何既不是强制精确匹配也不是受控重叠集一部分的位置都将填充颜色`n+1`。 这种颜色保证不会以不受控制的方式干扰计数。 

### 为什么它有效

 该结构始终保持两个不变量。 首先，确切地说`x`索引被分配相同的值`b`，因为我们明确选择了它们。 其次，分配值来自多重集的位置总数`b`正是`y`，因为所有其他潜在的匹配要么被仔细配对，要么使用虚拟颜色被消除。 备用颜色确保我们始终有办法打破多余的匹配而不影响所需的匹配，从而防止出现过度受限的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())
        b = list(map(int, input().split()))

        # positions grouped by value
        pos = {}
        for i, v in enumerate(b):
            pos.setdefault(v, []).append(i)

        a = [-1] * n

        # step 1: mark x exact matches greedily
        used = [False] * n
        exact = 0

        for v in pos:
            for i in pos[v]:
                if exact < x:
                    a[i] = b[i]
                    used[i] = True
                    exact += 1

        if exact != x:
            print("NO")
            continue

        # step 2: collect remaining indices
        rem = [i for i in range(n) if a[i] == -1]

        # step 3: rotate values to avoid direct match where possible
        vals = [b[i] for i in rem]
        m = len(rem)

        shifted = vals[:]
        if m > 1:
            shifted = vals[1:] + vals[:1]

        # step 4: assign y-x matches among remaining
        need = y - x
        for i in range(m):
            if need > 0 and shifted[i] != b[rem[i]]:
                a[rem[i]] = shifted[i]
                need -= 1
            else:
                a[rem[i]] = n + 1

        if need != 0:
            print("NO")
            continue

        print("YES")
        print(*a)

if __name__ == "__main__":
    solve()
```代码首先强制执行`x`贪婪地精确匹配。 然后，它仅作用于剩余位置，通过循环移位构建潜在匹配，以便我们可以创建受控重叠，而不会意外创建额外的固定点。 实现所需的多集重叠不需要的任何位置都用`n+1`，它充当中性元素，不会增加超出我们预期的交集。 

关键的实现细节是，这种转变确保我们可以在形成重叠时避免自匹配对。 后备方案`n+1`防止意外膨胀`y`。

 ## 边缘情况

 一个关键的边缘情况是当`x = y = 0`。 在这种情况下，我们必须确保没有位置在价值或多集贡献上匹配。 该结构将所有位置分配给备用颜色`n+1`，保证零交集和零精确匹配。 

另一个微妙的情况是`x = n`。 在这里，我们被迫精确匹配每个位置，因此唯一有效的构造是`a = b`。 任何引入旋转或虚拟值的尝试都会立即违反精确匹配约束，并且如果算法无法干净地分配所有所需的匹配，则算法会提前正确终止。 

第三种情况是当`y = n`但`x`很小。 这会强制最大的多重集重叠，这意味着每个值`b`必须出现在`a`，但不一定处于相同的位置。 循环移位通过重用所有值来确保这一点，同时防止对齐，除非明确选择`x`。
