 ## 问题理解

 我们有两个二进制字符串，`a`和`b`, 等长`n`。 任务是转型`a`进入`b`使用一系列前缀翻转操作。 长度的前缀翻转`k`反转第一个`k`的字符`a`并同时反转该前缀内的所有位。 输出必须列出完成此操作的前缀长度序列，并且操作数不得超过`2n`。 

约束表明`n`可以达到`10^5`每个测试用例，所有测试用例的总和`n`跨测试用例限制为`10^5`。 这意味着我们的解决方案必须是线性的`n`对于每个测试用例。 以简单的方式模拟每个可能的前缀翻转的二次算法会太慢。 

当字符串已经相同时，就会出现微妙的边缘情况。 在这种情况下，最优序列为空。 粗心的方法总是会翻转大小前缀`n`首先可以执行不必要的操作。 当第一位和最后一位不同时，会出现另一种棘手的情况。 选择错误的前缀可能会强制执行不必要的操作。 

小例子说明了这些观点。 如果`a = "01"`和`b = "10"`，一个天真的方法可能会先翻转整个字符串，产生`"10"`，这恰好在一次操作中解决了问题，但根据操作顺序，中间状态可能需要仔细处理以确保正确性。 

## 方法

 暴力方法会尝试直接匹配`a`到`b`通过从左到右扫描并在发生不匹配时翻转前缀。 对于每个不匹配，我们可以翻转一个前缀来纠正第一个不正确的位，但这在最坏的情况下需要 O(n^2) 次操作，因为每次翻转的模拟时间为 O(n) 。 原则上这是正确的，但是显式模拟每次翻转对于`n = 10^5`。 

关键的洞察力是向后推理。 我们只关心每一位的最终配置`a`匹配`b`。 从最后一位到第一位的工作使我们能够决定哪些前缀翻转是必要的，而无需实际模拟每一步。 对于每个位置`i`从`n-1`下降到`0`， 如果`a[i]`（应用所有先前的翻转后）不匹配`b[i]`，我们可以翻转长度的整个前缀`i+1`。 如果该点的第一位也不匹配，我们首先翻转长度为 1 的前缀，有效地反转它，然后再翻转较大的前缀。 

这种方法避免了每次模拟整个字符串的翻转。 相反，我们维护两个代表字符串当前逻辑“头”和“尾”的指针，以及一个翻转状态来确定当前段是否被反转。 每个操作的时间复杂度为 O(1)，每个字符串最多执行 2n 次操作，满足问题约束。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化指针`l = 0`和`r = n-1`跟踪当前片段`a`正在考虑中。 维持一个`flip`跟踪该段是否逻辑反转的标志。 
2. 从最后一个字符迭代到第一个字符（索引`i = n-1`下降到`0`）。 在每一步中，考虑到当前“尾部”的有效位`flip`状态。 
3. 如果当前有效位匹配`b[i]`，不执行任何操作并将指针向内移动。 如果不匹配，请检查仅翻转第一位（当前“头”）是否会将其与`b[i]`。 如果是，则将长度为 1 的翻转附加到操作列表中。 
4. 附加长度翻转`i+1`将最后一位与`b[i]`。 交换`l`和`r`并反转`flip`标志来解释由前缀翻转引起的反转和反转。 
5. 继续，直到处理完所有位置。 操作的结果列表，最多 2n，变换`a`进入`b`。 

工作原理：每个操作都确保最右边的未处理位得到纠正，而不会干扰已经纠正的位。 不变量是当前指针右侧的所有位都匹配`b`，段指针加上翻转标志准确地跟踪了逻辑状态`a`。 以相反顺序翻转前缀可确保正确的位不会被无意中更改。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(input().strip())
        b = list(input().strip())
        ops = []

        l, r = 0, n - 1
        flip = 0

        for i in reversed(range(n)):
            current = a[l] if flip == 0 else ('1' if a[l] == '0' else '0')
            if (r-l)%2 == 1:
                current = a[r] if flip == 0 else ('1' if a[r] == '0' else '0')

            if current != b[i]:
                first_bit = a[l] if flip == 0 else ('1' if a[l] == '0' else '0')
                if first_bit != b[i]:
                    ops.append(1)
                ops.append(i+1)
                flip ^= 1
                l, r = r, l

            if l < r:
                r -= 1
            else:
                l += 1

        print(len(ops), *ops)

if __name__ == "__main__":
    solve()
```该解决方案读取输入，处理每个测试用例，并维护指向当前头部和尾部的逻辑指针。 这`flip`flag 允许我们避免物理上反转和反转数组，这将是昂贵的。 对第一位的检查确保长度为 1 的额外翻转可以纠正第一位需要在完整前缀翻转之前对齐的情况。
