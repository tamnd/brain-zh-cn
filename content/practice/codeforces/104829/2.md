 ## 问题理解

 我们得到了两块矩形胶合板。 它们的放置方式必须使一个矩形水平，另一个矩形垂直，并以直角相交。 所得图形必须是正确的十字。 这意味着重叠部分必须严格位于两个矩形内部，因此四个臂中的每一个都在交点之外延伸正距离。 

最终图形的面积是两个矩形的并集。 由于在添加矩形区域时重叠会被计算两次，因此目标是在满足交叉条件的同时使重叠尽可能小。 如果没有位置可以产生有效的交叉，答案是`0`。 

每条边的长度最多为`1000`，因此不需要复杂的优化。 唯一真正的困难是确定哪条矩形边充当水平臂长度的角色，哪一条充当垂直臂长度的角色。 每个矩形都可以旋转 90 度，仅给出恒定数量的可能方向。 

最常见的错误是忘记每条臂都必须具有严格的正长度。 例如，使用输入```
2 2 2 2
```正确答案是```
4
```重叠必须准确`1 × 1`、产地`4 + 4 - 1 = 7`。 允许重叠具有矩形的全宽或全高的粗心实现将错误地接受无效的放置。 

另一个容易犯的错误是假设每对矩形都可以形成一个十字。 考虑```
1 2 5 7
```长方形的较小边是`1`重叠后两侧不能有正延伸，因为重叠必须至少有宽度`1`。 正确答案是```
0
```当旋转改变答案时，就会出现第三种微妙的情况。 例如，```
3 5 4 2
```只有一种方向选择才能产生最佳区域。 忽略旋转会错过正确的最大值。 

## 方法

 直接几何搜索会将两个矩形视为可移动对象，将一个矩形滑动到另一个矩形上，计算每个可能的重叠，并测试交叉条件是否成立。 这种方法是正确的，因为最终会检查每个有效的位置。 不幸的是，即使坐标限制为整数值，当边长达到时，也大约有一百万个相对位置`1000`，并且还必须检查每个方向。 连续的位置使得搜索变得更加不实用。 

在观察了面积的决定因素之后，几何形状变得更加简单。 联合面积等于$$A_1 + A_2 - \text{overlap}.$$矩形区域是固定的，因此最大化联合区域与最小化重叠区域完全相同。 

对于有效的交叉，重叠必须具有正的宽度和高度。 让水平矩形有高度`h`，垂直矩形的宽度`w`。 重叠被强制精确地`w × h`。 让它变得更大只会减少联合面积。 因此，只要重叠严格符合两个矩形的内部，就会立即获得尽可能小的重叠。 

假设水平矩形有尺寸`(L, h)`垂直矩形有尺寸`(w, H)`。 正确的交叉恰好存在于$$L > w \quad\text{and}\quad H > h.$$这些不平等保证了交叉口两侧的积极延伸。 

每个矩形只有两个可能的方向，因此只有四个方向对需要检查。 每一项都独立检查，并保留最佳有效区域。

 ## 算法演练

 1. 生成第一个矩形的两个可能的方向：`(a, b)`和`(b, a)`，其中第一个值表示水平长度，第二个值表示高度。 
2. 生成第二个矩形的两个可能的方向：`(c, d)`和`(d, c)`，其中第一个值表示垂直矩形的宽度，第二个值表示其高度。 
3. 对于每对方向，检查水平矩形是否比垂直矩形的宽度宽，以及垂直矩形是否比水平矩形的高度高。 

这些严格的不等式正是要求所有四个臂都具有正长度。 
4. 如果方向有效，则将联合面积计算为$$L \cdot h + w \cdot H - w \cdot h.$$最后一项是重叠区域。 
5. 保留所有四个方向对的最大有效区域。 
6. 如果四种配置均无效，则输出`0`。 

### 为什么它有效

 对于任何固定方向，每个有效放置的重叠宽度至少为垂直矩形的宽度，重叠高度至少为水平矩形的高度。 增加任一维度只会扩大重叠并减少联合面积。 因此，该方向的最佳放置总是使用尽可能小的重叠，即`w × h`。 

剩下的问题是这个最小重叠是否可行。 当它严格位于两个矩形内部时，它是完全可行的，这相当于`L > w`和`H > h`。 由于会检查每个方向，因此该算法会考虑每种可能的几何配置并返回可实现的最大联合区域。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, c, d = map(int, input().split())

ans = 0

first = [(a, b), (b, a)]
second = [(c, d), (d, c)]

for L, h in first:
    for w, H in second:
        if L > w and H > h:
            area = L * h + w * H - w * h
            ans = max(ans, area)

print(ans)
```该程序首先枚举每个矩形的两次旋转。 每个方向的解释都是一致的，第一个矩形充当水平条，第二个矩形充当垂直条。 

在计算面积之前检查两个严格的不等式。 使用`>`而不是`>=`是必不可少的。 平等意味着一只手臂的长度为零，违反了十字的定义。 

面积公式直接应用了包含排除原理。 因为每个值最多都是`1000`，最大可能面积仅为`2,000,000`，它很容易适合 Python 整数。 

仅存在四个方向对，因此该实现执行恒定量的工作。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline
    a, b, c, d = map(int, input().split())

    ans = 0
    first = [(a, b), (b, a)]
    second = [(c, d), (d, c)]

    for L, h in first:
        for w, H in second:
            if L > w and H > h:
                ans = max(ans, L * h + w * H - w * h)

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    out = sys.stdout.getvalue().strip()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out
