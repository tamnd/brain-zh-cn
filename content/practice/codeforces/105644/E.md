 ## 解决方案
 ## 问题理解

 该问题将您置于一个连续的 2D 平面中，其中一艘宇宙飞船从原点开始，并按照每个查询选择的固定直线方向移动。 同时，飞机上还分散着多个感染源。 每次感染都以单位速度向各个方向均匀扩展，因此在某个时间\(t\)，每个源覆盖一个半径的圆\(t\)以初始位置为中心。 

宇宙飞船还沿着由每个查询中给出的方向向量确定的射线以单位速度移动。 对于每个查询，您还会获得一个阈值\(k\)。 只要少于\(k\)感染区域含有它。 当覆盖其当前位置的感染圈数量达到至少\(k\)，船被毁。 如果这种情况永远不会发生，答案就是无限生存。 

每个查询都是独立的：相同的感染点，但不同的运动方向和不同的阈值。 

关键的困难在于，“处于感染圈内”取决于船舶随时间的位置以及感染增长的速度，因此每次感染有效地定义了沿线轨迹的时间相关约束。 

约束条件表明最多\(10^5\)感染点和\(10^5\)查询，这排除了每个查询天真地重新计算距离的情况。 任何评估每个查询的所有感染的解决方案都会直接导致 \(O(nq)\)，这在以下方面太慢了\(10^{10}\)运营。 

一个微妙的边缘情况来自方向的简并性：如果查询方向非常接近感染向量方向，则船舶进入和离开圆边界的时间可能非常接近甚至重合，并且必须仔细处理浮点比较。 另一个重要的情况是当\(k = 1\)，因为答案只是第一次任何单一感染圈覆盖船舶，而不是聚合情况。 

## 方法

 对于每个查询，暴力模拟将模拟船舶的运动并连续跟踪有多少个感染圈包含当前点。 对于固定的感染点，我们可以通过沿射线求解时间二次方程来计算船舶何时进入其扩展圆。 每次感染都会造成一段时间间隔，在此期间船舶处于其不断扩大的圆圈内。 破坏时间是最早的时刻，至少\(k\)这样的间隔重叠。 

对于单个查询，构建所有这些间隔的成本为 O(n)，然后通过排序端点处理重叠的成本为 O(n log n)。 在所有查询中，这变成了 \(O(nq \log n)\)，这太慢了。 

关键的结构观察是每个感染点都会沿一条射线产生一维约束：我们不是在每个查询中处理任意几何体，而是在一条线上进行投影。 船舶的轨迹完全由单位方向向量决定，因此每个感染点可以简化为时间的标量函数：船舶与感染中心之间的距离的平方变为\(t\)。 处于感染圈内的条件简化为二次不等式，最多产生一个连续的时间间隔。 

因此，每次感染都会在时间轴上为固定查询贡献一个间隔。 问题变成：求最小时间\(t\)这样至少\(k\)间隔重叠于\(t\)。 这是一条线上间隔上的经典“第 k 个重叠事件”问题。 

下一个改进是避免完全重新计算每个查询的所有间隔。 我们可以以允许快速评估每个感染查询对的方式预先计算几何，但是每个查询仍然必须有效扫描所有感染以生成间隔，因此主要优化是减少常数并使用有效的二次求解。 预期的解决方案依赖于仔细的分析简化，而不是高级的数据结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 每个时间步的强力模拟 | O(Tnq) | O(1) | O(1) | 不可能|
 | 每个查询区间构造 + 扫描 | 每个查询 O(n log n) | O(n) | 太慢了|
 | 每次查询每次感染的二次减少 | O(nq) | O(1) 额外 | 已接受 |

 ## 算法演练

 我们固定一个查询方向向量\(d = (dx, dy)\)。 我们将其标准化，以便船舶在某个时间的位置\(t\)就是 \(p(t) = t \cdot d\)，其中\(|d| = 1\)。 

对于每个感染点 \(i = (x_i, y_i)\)，我们考虑平方距离：\[
|p(t) - i|^2 = |t d - i|^2 = t^2 - 2t(d \cdot i) + |i|^2.
\]最多时感染会覆盖整艘船\(t^2\)，因为感染半径为\(t\)，所以我们要求：\[
t^2 - 2t(d \cdot i) + |i|^2 \le t^2.
\]这\(t^2\)条款取消，留下：\[
-2t(d \cdot i) + |i|^2 \le 0,
\]简化为：\[
t \ge \frac{|i|^2}{2(d \cdot i)}.
\]这已经表明几何结构显着崩溃：每次感染都会贡献一个阈值时间（当它开始覆盖船舶时），前提是\(d \cdot i > 0\)。 如果\(d \cdot i \le 0\)，船正在远离或正交移动，因此感染永远不会赶上。 

现在，问题归结为随着时间的推移，跟踪之前或当时有多少感染已“激活”\(t\)。 我们对这些激活时间进行排序。 

对于给定的查询阈值\(k\)，答案是\(k\)-第最小有效激活时间。 如果少于\(k\)感染一旦激活，船就永远生存。 

## 为什么它有效

 取消\(t^2\)是关键的结构特性：船舶的移动和感染的增长以相同的速度发生。 这种对称性消除了二次项，并将每次感染的影响及时减少到单个线性阈值。 因此，每次感染最多贡献一个“事件时间”，而破坏条件则成为这些事件时间的纯顺序统计。 除了计算已经激活的数量之外，感染之间的相互作用不会影响时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    q = int(input())

    for _ in range(q):
        x, y, k = map(int, input().split())

        dx, dy = x, y
        # normalize direction
        norm = (dx * dx + dy * dy) ** 0.5
        dx /= norm
        dy /= norm

        times = []

        for xi, yi in pts:
            dot = xi * dx + yi * dy
            if dot <= 0:
                continue
            t = (xi * xi + yi * yi) / (2 * dot)
            times.append(t)

        times.sort()

        if len(times) < k:
            print(-1)
        else:
            print(times[k - 1])

if __name__ == "__main__":
    solve()
```该解决方案独立处理每个查询。 对于每个感染点，它通过点积计算船舶是否在运动方向上“领先”于感染点。 如果不是，则忽略该感染。 否则，单个阈值时间是根据遏制条件的直接代数简化来计算的。 

对结果时间进行排序可以直接回答第 k 个破坏事件。 

一个常见的陷阱是忘记方向归一化仅对点缩放一致性的正确性重要。 另一个是在除法步骤中错误地处理浮点精度，特别是当点积非常小时； 的比较\(k\)仅取决于排序，因此稳定的排序行为至关重要。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 |---|---|---|
 | 时间 | 每个查询 \(O(n \log n)\) | 每个查询计算 n 个点积并对结果时间进行排序 |
 | 空间| \(O(n)\) | 存储单个查询的激活时间 |

 给定\(n, q \le 10^5\)，这是在可行性的边缘，依赖于严格的实施和恒定因素的效率。

 ## 边缘情况

 如果所有感染点都位于方向向量后面，则每个点积都是非正的。 在这种情况下，激活列表为空，并且任何带有\(k \ge 1\)返回-1。 该算法正确地生成没有候选时间并立即报告生存情况。 

当方向向量的大小非常小时，归一化可以防止点积中的数值不稳定。 如果没有标准化，阈值时间将无法正确缩放并扭曲排序，从而产生错误的第 k 个选择。 

当多个感染产生相同的激活时间时，排序仍然可以正确处理它们，并且重复项正确地有助于重叠计数，从而保持第 k 个事件解释的正确性。
