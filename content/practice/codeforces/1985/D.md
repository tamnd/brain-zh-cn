 ## 解决方案
 ## 问题理解

 我们得到了一个由点和散列组成的网格。 在这个网格的某个地方，有一个由所有单元形成的形状，其到隐藏中心的曼哈顿距离严格小于半径。 这将创建一个与网格轴对齐的菱形区域。 该区域内的每个单元格都标记为`#`，而外面的一切都是`.`。 任务是恢复该菱形中心的整数坐标。 

曼哈顿圆具有非常严格的结构。 如果从中心移动，边界会向四个对角线方向均匀扩展，形成对称菱形。 这种对称性是允许在不知道半径的情况下从网格进行重建的关键属性。 

这些约束允许所有测试用例最多包含 200,000 个单元，因此任何以恒定次数检查每个单元的解决方案都是可以接受的。 如果网格很大，单个测试用例中的任何二次方都会太慢。 

一个幼稚的错误是尝试通过测试每个可能的中心和半径来模拟或拟合圆。 对于每个候选中心，需要验证所有`#`细胞满足曼哈顿条件，这使得最坏情况下的复杂度约为 O(n²m²)。 另一种错误的方法是假设中心是所有几何中心的几何中点`#`细胞没有理由。 如果形状在坐标空间中不完全对称，但作为曼哈顿球仍然有效，则可能会失败。 

一个具体的陷阱是假设中心是边界框的中心`#`。 这在这里有效，但前提是您了解为什么曼哈顿球总是均匀地饱和所有四个极值方向。 

## 方法

 强力策略是将每个细胞视为潜在的中心。 对于每位候选人`(i, j)`，我们计算到任何的最大曼哈顿距离`#`细胞并检查是否所有`#`位于一致的半径内。 这需要扫描每个候选者的整个网格，在最坏的情况下导致 O((nm)²) 行为，即使对于中等网格来说也太慢了。 

关键的观察结果是，曼哈顿球的中心位于`(h, k)`具有非常特定的边界形状。 最上面的`#`细胞正好位于距离`r-1`位于中心上方，最底部位于下方相同距离处，最左边和最右边也是如此。 这意味着可以纯粹从极值坐标恢复中心`#`细胞。 

让`min_row`,`max_row`,`min_col`,`max_col`是所有的边界框`#`细胞。 曼哈顿球是完全对称的，因此中心必须恰好位于顶部和底部极端之间以及左侧和右侧极端之间的中间位置。 该中点保证是整数，因为菱形的结构确保奇偶校验对齐。 

这将问题简化为通过网格的单次传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力中心检查 | O((nm)²) | O(1) | O(1) | 太慢了 |
 | 边界框中点 | O(纳米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化四个变量`min_row`,`max_row`,`min_col`,`max_col`跟踪所有的极端位置`#`细胞。 我们以相反的极端开始它们，以便任何有效的单元正确更新它们。 
2. 逐行扫描网格中的每个单元格。 当我们遇到一个`#`，使用其坐标更新所有四个边界。 
3. 处理完网格后，将中心行计算为`(min_row + max_row) // 2`。 这是可行的，因为钻石是垂直对称的，因此中心正好位于最高点和最低点之间的中间位置`#`。 
4. 将中心列计算为`(min_col + max_col) // 2`使用相同的对称性论证。 
5. 输出结果`(center_row, center_col)`。 

### 为什么它有效

 曼哈顿圆由到中心的曼哈顿距离严格小于固定半径的所有点定义。 这将创建一个凸菱形，其中每个水平和垂直极值均由中心唯一确定。 最上面的`#`正是`r-1`中心上方的台阶，最底部是`r-1`步骤如下，左侧和右侧类似。 由于形状已完全填充，因此没有`#`位于这些极端之外，并且每个边界上至少有一个。 因此，边界框正好位于`(h, k)`，使极值的中点等于真实中心。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        
        min_r = n
        max_r = 1
        min_c = m
        max_c = 1
        
        for i in range(1, n + 1):
            row = input().strip()
            for j, ch in enumerate(row, start=1):
                if ch == '#':
                    if i < min_r:
                        min_r = i
                    if i > max_r:
                        max_r = i
                    if j < min_c:
                        min_c = j
                    if j > max_c:
                        max_c = j
        
        center_r = (min_r + max_r) // 2
        center_c = (min_c + max_c) // 2
        
        print(center_r, center_c)

if __name__ == "__main__":
    solve()
```该实现维护四个边界变量并在一次传递中更新它们。 使用基于 1 的索引直接与问题陈述对齐，避免了差一转换。 整数除以 2 是安全的，因为曼哈顿圆保证对称性，因此极值之和始终是偶数。 

一个微妙的细节是我们从不尝试明确地重建半径。 半径隐式编码为边界框从中心延伸的距离，但对于输出来说不是必需的。

 ## 边缘情况

 包含单个的最小网格`#`很重要，因为最小和最大坐标都会立即崩溃。 该算法将所有边界设置为该位置，并且中点保持不变，从而产生正确的中心。 

实心矩形块的形状与曼哈顿钻石不同，但在保证下仍然有效。 在这种情况下，边界框是精确的，并且中点仍然位于真正的对称中心。 

薄菱形（形状仅跨越几行或几列）测试整数除法是否正确运行。 由于曼哈顿圆始终具有对称极值距离，因此最小坐标和最大坐标之和保持偶数，从而防止舍入问题。
