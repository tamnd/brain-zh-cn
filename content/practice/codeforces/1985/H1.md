 ## 解决方案
 ## 问题理解

 我们得到一个网格，其中包含`n`行和`m`列，其中每个单元格要么为空（“.”），要么为已填充（“#”）。 填充单元格的连接组件是一组“#”图块，您只需沿着共享一侧的相邻图块移动即可在任意两个图块之间移动。 该问题允许一个操作：您可以选择任何行或列，并用“#”填充该行或列中的每个单元格。 我们的目标是确定最多一次此类操作可实现的连接组件的最大大小。 

输入包含多个测试用例，其总和`n * m`所有情况均以 10^6 为界。 这意味着我们可以在每个网格上进行线性遍历，但在整个网格上进行二次或嵌套遍历可能会太慢。 因为我们只能进行一行或一列操作，所以我们必须推断哪一个操作将合并或扩展组件以最大化最大的簇。 

边缘情况包括微小网格、已完全填充的网格或每个填充单元格都被隔离的网格。 例如，带有“.”的 1x1 网格 在填充其唯一的行或列后应返回 1，并且每行和每列已经至少有一个“#”的网格可以通过连接分散的图块来最大化。 对于小网格来说，对每个可能的行或列进行简单的洪水填充是可行的，但在接近 10^6 总单元格限制时变得太慢。 

## 方法

 暴力方法会迭代每一行和每一列，模拟用“#”填充它，然后为每次模拟使用 DFS 或 BFS 计算最大连接组件的大小。 这是正确的，因为我们正在详尽地检查所有可能性，但它太慢了。 对于尺寸的网格`n*m`，每次模拟需要 O(n_m) 进行 DFS，并且有`n+m`模拟，每个测试用例的时间复杂度为 O((n+m)_n_m)。 在最坏的情况下，n_m ~ 10^6 和 n+m ~ 2000，这会导致每个测试用例大约 2*10^9 次操作，这是不可行的。 

关键的观察结果是填充行或列只会添加一行中的单元格。 因此，运算后的最大连通分量至多为所选行或列中的单元格加上同一行或列中现有的“#”单元格之和。 我们可以预先计算每行和每列中“#”的数量。 然后，对于每个潜在的操作，所得连接分量的大小是该行和列中“#”的总和，如果交集单元格为空，则加一（以避免重复计数）。 这将问题简化为对所有行和列进行线性扫描以找到可实现的最大总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n+m) * n * m) | O(n*m) | 太慢了 |
 | 最佳 | O(n*m + n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 对于每个网格，计算每行和每列中填充的单元格的数量。 让`row_count[i]`是行中“#”的数量`i`和`col_count[j]`列中“#”的数量`j`。 这需要遍历整个网格一次，O(n*m)。 
2. 识别空的或已填充的单元格以计算潜在的最大大小。 每个操作都会影响整行或整列，因此请分别考虑两种类型的操作： 填充行`i`或填充柱`j`。 
3、模拟填充一行时`i`，所得的最大分量是该行中的单元格计数加上与该行相交的任何列中的单元格计数，但我们必须针对重复计数进行调整。 那么最大连通分量是`row_count[i] + max_col_count`， 在哪里`max_col_count`是列数的最大值，如果 (i,j) 处的相交单元格为空，则调整 +1。 
4、同样，模拟填充柱时`j`, 计算`col_count[j] + max_row_count`对空交叉路口进行相同的调整。 
5. 答案是行和列上所有此类操作的最大值。 
6. 边缘情况：如果网格完全填满，任何操作都不会增加尺寸。 如果网格只有一行或一列，填充它很简单。 

不变的是，填充一行或一列只会沿着该行创建一个连接组件，并且最大的合并发生在填充较多的行和填充较多的列的交集处。 预先计算行数和列数可确保我们捕获最佳合并，而无需模拟每个 DFS。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [input().strip() for _ in range(n)]
        
        row_count = [0]*n
        col_count = [0]*m
        
        for i in range(n):
            for j in range(m):
                if grid[i][j] == '#':
                    row_count[i] += 1
                    col_count[j] += 1
        
        max_row = max(row_count)
        max_col = max(col_count)
        
        # find if there exists an empty cell at intersection
        found_empty = False
        for i in range(n):
            if row_count[i] == max_row:
                for j in range(m):
                    if col_count[j] == max_col and grid[i][j] == '.':
                        found_empty = True
                        break
                if found_empty:
                    break
        
        ans = max_row + max_col
        if found_empty:
            ans += 1
        
        print(ans)

solve()
```第一部分读取输入并计算每行和每列的“#”单元格数。 然后我们计算最大行数和列数。 棘手的部分是检查具有最大计数的行和列的交集是否为空，这允许在总数中再添加一个单元格以避免重复计算。 最后，我们打印答案。
