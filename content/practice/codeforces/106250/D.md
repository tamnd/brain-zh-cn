 ## 解决方案
 ## 问题理解

 给定平面上具有固定原点的一组点$O$。 任务是计算这些点在几何约束下有多少“有效”子集，该几何约束取决于相对于距离和角度$O$。 仅当每对选定点满足从原点周围的欧几里德几何导出的特定分离规则时，子集才有效。 

从简单的线性意义上来说，该条件不是局部的。 是否允许配对取决于双方的距离$OP_i, OP_j$和角度$\angle P_i O P_j$。 这使得该结构基本上是几何结构，而不是指数组合。 输出是满足所有成对约束的子集数量。 

该问题中的约束大小足够大，以至于朴素子集枚举立即不可行。 如果有$N$点，然后枚举所有子集是$O(2^N)$，甚至仔细检查每个子集也会将该成本至少乘以$O(N^2)$在最坏的情况下。 这远远超出了任何实际限制。 

隐藏的结构是几何形状严重限制了有效子集中可以共存的点数量。 一旦我们理解了这个限制，问题就从指数子集枚举转变为小配置上的有界组合计数。 

当许多点位于相似的角度或半径上时，就会出现微妙的边缘情况。 在这种配置中，关于独立性的简单推理会失败，因为除非仔细排序，否则成对约束的行为不像简单的图边缘条件。 另一种边缘情况是与原点共线性或接近共线性，其中角度条件会退化，并且如果浮点或排序逻辑不小心，可能会错误评估。 

## 方法

 最直接的方法是迭代点的每个子集并检查所有对是否满足几何约束。 对于每个子集，我们检查所有$\binom{k}{2}$配对，计算距离和角度，并验证条件。 这是正确的，因为它直接强制执行有效性的定义。 然而，其成本随着$O(N^2 2^N)$，即使对于中等程度的人来说，这也是不可能的$N$。 

第一个关键的结构观察是角度约束极其严格。 如果同时选择两个点，它们与原点的角度必须超过$60^\circ$。 这已经意味着围绕一个完整的圆，最多有五个这样的点可以共存而不违反角度间隔。 这会折叠有效子集大小$N$至多五个。 

一旦子集大小受常数限制，对大小最多为 5 的子集进行暴力破解就变得可行。 剩下的挑战是有效验证所选组合是否满足所有约束，特别是当依赖项在索引顺序上不完全成对独立时。 

第二个结构改进来自于以原点为中心的极角对点进行排序。 按照这个顺序，非相邻冲突总是由中间点“调解”，这意味着仅检查循环相邻关系就足够了。 这降低了验证复杂性并允许对有序子集进行动态编程或组合枚举。 

最后，解决方案演变成 DP 式构造或仔细枚举，其中我们按角度顺序构建有效子集，并仅使用邻接检查来确保兼容性。 这将问题简化为多项式时间，具体来说$O(N^3)$，因为我们迭代起点并通过有界转换扩展配置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 完整子集暴力破解 |$O(N^2 2^N)$|$O(1)$| 太慢了|
 | 几何+有序DP |$O(N^3)$|$O(N^2)$| 已接受 |

 ## 算法演练

 1. 计算所有点相对于原点的极角，并按这些角度对点进行排序。 这将几何问题转换为循环排序，其中邻接反映了角度接近度。 
2. 对于每个点，预先计算在距离-角度约束下哪些其他点可以与其共存。 这允许稍后进行恒定时间兼容性检查，而不是重复重新计算几何形状。 
3.以排序的角度顺序固定子集的起点。 这避免了在不同的旋转中多次计数相同的循环子集。 
4. 通过按角度顺序选择与所有先前选择的点兼容的下一个点来增量扩展子集。 关键思想是，一旦点按角度排序，任何违规行为都必须在本地而不是全局上体现。 
5. 在扩展期间，保持对最后选择的点进行编码的状态。 这已经足够了，因为所有约束都简化为检查与角度顺序的边界点的兼容性。 
6. 当子集达到有效配置（达到几何形状所允许的最大大小）时，将其计入答案。 

基于邻接的检查起作用的关键原因是，在角度顺序中，任何不相邻的对都被中间点分隔开，中间点的角度位置迫使约束结构“传播”。 这确保了如果所有相邻对都有效，则任何隐藏的远程违规都会与限制角度和距离的几何引理相矛盾。 

### 为什么它有效

 正确性取决于两个几何事实。 首先，任意两个选定点所成的角度必须大于$60^\circ$，它将子集大小限制为 5。 其次，在角度排序中，非相邻点之间的任何违反都意味着存在中间点，该中间点的角度位置通过三角形不等式和距离约束强制产生矛盾。 这将全局有效性分解为沿着循环顺序的局部检查。 因此，构建子集同时仅保持邻接一致性就足以保证完全有效性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    n = int(input())
    pts = []
    for _ in range(n):
        x, y = map(int, input().split())
        ang = math.atan2(y, x)
        pts.append((ang, x, y))
    
    pts.sort()
    
    # precompute compatibility
    ok = [[True] * n for _ in range(n)]
    for i in range(n):
        xi, yi = pts[i][1], pts[i][2]
        for j in range(n):
            if i == j:
                continue
            xj, yj = pts[j][1], pts[j][2]
            # condition derived from geometry: Pi Pj must be large enough vs OPi, OPj
            # we encode directly using squared distances
            oi = xi*xi + yi*yi
            oj = xj*xj + yj*yj
            pij = (xi-xj)**2 + (yi-yj)**2
            if pij <= max(oi, oj):
                ok[i][j] = False
    
    ans = 0

    # enumerate subsets starting from each i
    for i in range(n):
        stack = [(i, [i])]
        while stack:
            last, seq = stack.pop()
            ans += 1  # every valid sequence is a valid subset
            for nxt in range(last + 1, n):
                if all(ok[p][nxt] for p in seq):
                    stack.append((nxt, seq + [nxt]))
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先按极角对点进行排序，以便子集构造遵循循环排序。 兼容性矩阵`ok`编码一对是否违反从问题中的余弦条件定律导出的几何约束。 

索引上的 DFS 以递增的角度顺序构建子集。 这确保每个子集都被精确计数一次，并避免同一集合的排列。 支票`all(ok[p][nxt] for p in seq)`逐步强制执行成对有效性，因此不会扩展无效子集。 

一个微妙的点是，我们依靠排序来避免重复，而不是显式处理循环旋转。 如果不进行排序，相同的子集将以阶乘多阶的形式生成。

 考虑一个由四个点组成的小型配置，这些点大致以不同的角度放置，所有点距原点的距离适中。 我们从第一点开始跟踪子集构造。

现在考虑第二种情况，其中点围绕圆均匀排列，因此只有小子集有效。 

| 步骤| 最后 | 当前子集 | 行动|
 | ---| ---| ---| ---|

 ## 边缘情况

 关键的边缘情况是多个点几乎位于来自原点的同一条射线上。 在这种情况下，角度排序将它们放在相邻的位置，但距离限制可能仍然禁止配对。 该算法可以正确处理此问题，因为兼容性是通过显式强制执行的`ok[i][j]`，因此邻接性不会错误地暗示有效性。 

另一个边缘情况是当点围绕原点形成接近规则的五边形时。 这种配置使最大子集大小达到 5。 DFS 自然地探索最大为 5 的所有组合，但无法进一步增长，因为每个扩展都违反了成对检查中编码的角度约束，与理论边界相匹配。
