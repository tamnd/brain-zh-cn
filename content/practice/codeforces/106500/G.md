 ## 解决方案
 ## 问题理解

 我们有一个三维属性向量的集合。 一次移动选择一个向量，选择其三个坐标的任何子集，并同时从所有选定的坐标中加一或减一。 目标是使每个向量相同，同时最小化总移动次数。 

对于选定的最终向量`(x, y, z)`，考虑一个原始向量`(a, b, c)`。 如果一个坐标需要增加，它可以与其他增加的坐标共享移动。 如果一个坐标需要减小，它只能与其他减小的坐标共享移动。 这意味着该向量的移动次数是最大正差值加上最大负差值的绝对值：```
max(x-a, y-b, z-c, 0) + max(a-x, b-y, c-z, 0)
```输入大小可以达到`100000`，因此检查每个可能的最终坐标是不可能的。 可能的坐标搜索空间太大，即使对每个维度进行大范围的线性扫描也会超出可用时间。 我们需要利用成本函数的结构，而不是尝试所有可能的答案。 

一个常见的错误是认为答案只是覆盖所有点的最小立方体。 如果一次移动可以独立地改变每个坐标，那么这是正确的，但这里的正向和负向变化不能合并在一次移动中。 例如，用点`(0,0,0)`和`(10,10,0)`，坐标范围小到足以建议答案`5`，但是将一个点移动到另一个点需要同时增加两个坐标和成本`10`朝着正确的方向。 

另一种边缘情况是所有向量都相同。 对于输入：```
3
5 7 9
5 7 9
5 7 9
```答案是`0`。 总是尝试向中间值移动的解决方案如果忽略当前值已经是最佳值，则可能会浪费操作。 

第二种边缘情况是只有一个坐标不同时。 对于输入：```
2
1 4 8
6 4 8
```答案是`5`。 仅第一个坐标发生变化，但最终坐标仍需选择。 操作计数是两个值之间的距离，而不是其一半。 

## 方法

 蛮力方法会尝试所有可能的最终三元组`(x, y, z)`在坐标范围内。 对于每个候选人，我们通过检查所有候选人来计算总成本`n`向量。 候选人数量可以约为`100000^3`，并且每一项的成本`O(n)`，给出不可能的最坏情况。 

关键的观察结果是成本函数是凸的。 每个向量贡献一个由线性表达式的最大值组成的函数，并且凸函数的总和仍然是凸的。 凸函数没有远离全局最小值的局部最小值，因此我们可以从一个好的位置开始，反复向更好的邻居移动。 

对于每个维度，中位数是一个很好的起点，因为基于绝对值的凸函数在中位数附近被最小化。 选择三个坐标中位数后，我们执行离散梯度搜索。 我们尝试在三个维度的所有 27 个方向上移动当前点。 如果某个举动改善了答案，我们就会接受并继续。 否则，我们将跳跃大小减少一半。 由于该函数是凸函数，因此大的跳跃会找到正确的区域，而较小的跳跃会细化精确的整数最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(范围³ * n) | O(1) | O(1) | 太慢了 |
 | 凸搜索 | O(n log C) | O(n log C) | O(n) | 已接受 |

 ## 算法演练

 1.读取所有向量并分别存储三个坐标数组。 我们需要这些数组来查找起点和评估成本函数。 
2.选择每个坐标的中位数作为初始候选`(x, y, z)`。 基于距离的凸函数往往在中位数附近达到最小值，从而给出一个强有力的起始位置。 
3. 定义候选点的成本。 对于每个向量，计算必须增加的最大量和必须减少的最大量。 它们的总和是该向量所需的操作数。 
4. 将初始跳跃大小设置为所有三个坐标之间的最大分布。 这足够大以跨越整个可能的搜索区域。 
5. 尝试每个坐标变化的每个方向`-jump`,`0`， 或者`jump`。 如果新职位的成本较小，则立即转移到该职位。 
6. 如果 27 个相邻位置都没有改善结果，则将跳跃大小减半。 较小的跳跃允许搜索接近精确的整数最优值。 
7. 当跳跃大小变为零时，当前位置是最优的，其成本就是答案。 

为什么它有效是基于凸性。 一个向量的成本是线性函数的两个最大值之和，它是凸的。 将所有向量相加使函数保持凸形。 凸函数不能将更好的点隐藏在更差的点后面，因此通过检查邻居进行局部改进会导致全局最小值。 减小的跳跃大小使搜索最终可以测试每个必要的附近整数位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)

    a = []
    b = []
    c = []

    for _ in range(n):
        x, y, z = map(int, input().split())
        a.append(x)
        b.append(y)
        c.append(z)

    def value(x, y, z):
        ans = 0
        for i in range(n):
            d1 = x - a[i]
            d2 = y - b[i]
            d3 = z - c[i]
            ans += max(d1, d2, d3, 0)
            ans += max(-d1, -d2, -d3, 0)
        return ans

    sa = sorted(a)
    sb = sorted(b)
    sc = sorted(c)

    x = sa[n // 2]
    y = sb[n // 2]
    z = sc[n // 2]

    best = value(x, y, z)

    step = max(
        max(a) - min(a),
        max(b) - min(b),
        max(c) - min(c)
    )

    while step:
        moved = False
        current = best

        for dx in (-1, 0, 1):
            for dy in (-1, 0, 1):
                for dz in (-1, 0, 1):
                    nx = x + dx * step
                    ny = y + dy * step
                    nz = z + dz * step
                    cur = value(nx, ny, nz)
                    if cur < current:
                        current = cur
                        x, y, z = nx, ny, nz
                        moved = True

        best = current
        if not moved:
            step //= 2

    print(best)

solve()
```这`value`函数直接实现固定最终向量的操作计数。 两个最大表达式代表两组运算：增加和减少。 

中值初始化避免从搜索空间的任意角落开始。 分拣成本`O(n log n)`，这是可以接受的`100000`元素。 

搜索循环使用整数跳转。 重要的边界条件是允许每个维度上的零移动，因为最佳值可能位于平坦区域而不是严格的斜坡上。 反复减半`step`保证最终检查的结果足够接近最优值。

 对于输入：```

```中位点是`(2,2,2)`。

 | 决赛| (2,2,2) | (2,2,2) | 2 | 回答 |

 第三向量需要将第一坐标减少一次并且将第三坐标减少一次。 它们无法组合，因为它们相对于目标的方向相反，因此需要两次操作。

3 2 1
```中位点是`(3,3,1)`。 

| 步骤| 职位| 成本| 行动|

    sys.stdin = old

        return ""

    n = int(next(it))
    pts = []
    for _ in range(n):
        pts.append((int(next(it)), int(next(it)), int(next(it))))

    a = [p[0] for p in pts]
    b = [p[1] for p in pts]

 ## 边缘情况

 对于相同的向量，例如：```
3
5 7 9
5 7 9
5 7 9
```中位数正是当前值。 成本函数返回零，搜索永远找不到改进的举动。 

对于单个坐标差：```
2
1 4 8
6 4 8
```搜索从中值附近开始`(6,4,8)`。 第一个向量必须将其第一个坐标增加 5。 由于只涉及一个方向，因此该公式给出`5`，与实际的移动次数相匹配。 

对于多个坐标必须向同一方向移动的情况，如：```
2
0 0 0
5 5 5
```选择中间值的成本为`5`，因为所有三个坐标都可以在每次操作中一起调整。 该算法通过最大项来捕获这一点，而不是单独处理坐标。
