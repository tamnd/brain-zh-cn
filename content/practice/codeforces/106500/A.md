 ## 解决方案
 ## 问题理解

 我们有两个整数，$a$和$b$，描述连续放置的形状的线性排列。 在这一行中正好有两个三角形，所有剩余的形状都是正方形。 

几何约束以相对方式描述。 如果我们找到第一个三角形，然后向右移动，我们最终将到达第二个三角形，并且它们之间正好有$a$正方形。 对称地，如果我们从第二个三角形开始向左移动，我们会遇到第一个三角形$b$之间的正方形。 

这完全确定了序列内两个三角形位置的相对排序约束，序列的其余位置用正方形填充。 任务不是构造排列本身，而是确定在与给定一致的所有可能的有效配置下，该行可以有多少个总位置$a$和$b$。 

关键的困难在于，除了同一性之外，三角形是无法区分的，因此只有它们的相对顺序很重要。 根据最终布局中第一个三角形放置在第二个三角形的左侧还是右侧，序列的总长度可能会略有不同。 输出要求形状的最小和最大可能总数。 

约束条件允许$a, b$最多$10^9$，这会立即排除任何显式构造或模拟行的方法。 任何解决方案都必须将配置简化为从相对布局逻辑导出的恒定时间公式。 

当两个三角形在某个方向上相邻时，会出现微妙的边缘情况。 例如，如果$a = 0$和$b = 0$，无论方向如何，两个三角形都彼此相邻，粗心的推理可能会重复计算或错过两个顺序折叠到相同布局长度的事实。 

## 方法

 强力解释将尝试枚举连续两个三角形的所有可能位置，并检查所需的正方形数量是否匹配。 人们可以想象固定第一个三角形的位置，然后将第二个三角形放置在其左侧或右侧，并计算它们之间的正方形。 然而，由于原则上正方形的总数是无界的并且位置可以任意移动，因此这种方法退化为尝试许多偏移。 即使我们将注意力限制在可行范围内，候选配置的数量也会随着序列的最终长度而增长，在最坏的情况下，序列的长度会随着序列的最终长度而增长$a + b$，远远超出可接受的限度，当$a, b \le 10^9$。 

问题的结构消除了这种搜索的需要。 唯一的自由度是两个三角形的顺序以及它们之间的正方形块由输入根据方向固定的事实。 一旦我们确定了哪个三角形被认为是最左边，布局就会变得僵化：一个方向强制存在一个间隙$a$正方形，相反的方向强制间隙$b$正方形。 因此，整个配置是通过将两个标记放置在具有固定间隔的线上，并计算有多少个方形槽被强制进入剩余空间来确定的。 

这将问题简化为分析同一约束的两个可能方向并计算每种情况下所得的总长度。

 ## 算法演练

 1. 将两个三角形视为一条线上的有序位置，并将其中一个视为最左边的三角形。 在这个方向上，第二个三角形恰好出现在其右侧$a$它们之间的正方形。 这直接意味着如果左三角形位于位置 0，则右三角形位于位置$a + 1$，因此此排序贡献的最小跨度是$a + 2$包括两个三角形的位置。 
2. 反转视点并假设第二个三角形位于第一个三角形的左侧。 在这种情况下，给定的条件表明有$b$它们之间的正方形，所以这个方向上三角形之间的距离是$b + 1$。 这会产生一个跨度$b + 2$职位。 
3. 请注意，两种解释必须对应于相同的物理配置，这意味着两种三角形排序都是描述相同底层约束的有效方法。 行的总长度取决于我们在构建序列时所遵循的解释。 
4. 当我们选择更紧密的配置时，可能的总长度会达到最小，这对应于按照最小化与强制方形间隙的重叠的顺序放置三角形。 这产生了一个基本长度$\min(a, b) + 2$三角形端点的位置，但由于正方形必须存在于解释的两个方向上，因此实际的最小全行长度变为$a + b + 2$减去一个共享端点结构的重叠调整。 
5. 当我们考虑到任一顺序都可以独立支配结构这一事实时，就会出现最大可能的长度，给出了第二种有效的解释，即两者之间的不对称性$a$和$b$完全以相反的方向表达。 

一种更稳定的查看结构的方法是通过放置两个标记位置来完全确定行，而方块正是剩余的间隙。 唯一不明确的是在描述中首先考虑哪个三角形，因此总长度变为$a + 2 + b$或者$a + b + 2$，但这些是相同的表达式。 相反，变化来自端点是否包含在内，或者一个三角形是否被视为一个方向上边界的一部分，而不是另一个方向上的边界的一部分。 这产生两个连续的整数可能性。 

## 为什么它有效

 核心不变量是，配置完全由两个三角形之间的相对距离决定，并且该距离在两个方向上都是固定的：$a$和$b$。 由于每个有效的排列都对应于选择三角形的排序，然后在它们之间放置固定数量的正方形，因此所有解决方案都简化为计算一维晶格上的线性跨度。 任何中间配置都不能在不改变相对顺序的情况下违反平方计数，这是问题描述所禁止的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())

    # minimal arrangement: triangles as close as constraints allow
    mn = min(a, b) + 2

    # maximal arrangement: triangles as far apart as constraints force
    mx = a + b + 2

    print(mn, mx)

if __name__ == "__main__":
    solve()
```该实现直接对两个三角形形成线性结构端点的观察进行编码，并且通过选择如何解释方向约束来获得每个有效行。 

唯一微妙的一点是端点计数的一致性。 每个三角形贡献一个位置，每个正方形在它们之间或外部的间隙中贡献一个额外的位置。 这就是为什么所有表达式都简化为线性函数$a$和$b$偏移量恒定为 2。

 ## 边缘情况

 当$a = 0$和$b = 0$，两个三角形在两种解释中都必须相邻。 该算法仍然会产生一致的结果，因为两个计算的跨度都崩溃为相同的最小配置，从而产生单个可能的长度。 

为了$a = 0, b > 0$，从左到右的解释强制一侧相邻，而相反则强加非零间隙。 该算法自然地将它们分为最小和最大配置，因为一个方向产生紧密的布局，而另一个方向则通过以下方式完全扩展它：$b$正方形。 

为了$a, b$在最大值时，计算保持稳定，因为它仅使用最多的加法$2 \cdot 10^9$，这完全符合 Python 中的 32 位整数安全性，不需要特殊处理。 

如果一个幼稚的实现尝试模拟放置，它会尝试沿着潜在的位置枚举位置$10^9$-length 行，由于时间和内存限制而立即失败。
