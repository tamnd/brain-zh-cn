 ## 解决方案
 ## 问题理解

 我们得到的数字来自$1$到$n-1$，我们必须选择尽可能多的数字，同时保持一个非常具体的乘法条件：如果我们将所有选定的数字相乘，结果必须留下余数$1$当除以$n$。 

这是一个子序列问题，因此顺序是固定的，我们只需选择要保留的元素。 由于数组已经排序，因此最终答案也必须按升序报告，这意味着我们实际上正在选择一个子集。 

约束条件$n \le 10^5$立即排除任何尝试所有子集甚至任何二次方的方法$n$。 子集的完整枚举将是$2^{n}$，这是不可能的。 甚至检查大小的所有子集$n/2$会组合爆炸。 这推动我们走向数论结构，在该结构中我们避免显式子集探索，而是利用模乘法的性质。 

当贪婪地思考时，就会出现一个微妙的问题。 人们可能会尝试继续将数字相乘，直到乘积变得无效模$n$，但模块化产品并不单调。 添加一个数字可以根据其残差类别“修复”或“破坏”条件，因此按顺序进行贪婪累加会失败。 

第二个常见错误是假设我们总是可以获取所有数字。 例如，当$n = 5$, 采取$[1,2,3,4]$给出产品$24 \equiv 4 \pmod 5$，这是无效的。 因此，必须删除一些元素，任务就变成了准确识别哪些元素保留了与产品一致的元素。$1$。 

关键的困难在于，删除一个数字会以乘法方式影响乘积，因此我们需要一种可以对乘积取模进行推理的结构$n$无需显式计算所有子集。 

## 方法

 蛮力方法将迭代所有子集$[1, n-1]$，计算它们的乘积模$n$，并跟踪最佳有效子集。 这在概念上是正确的，因为它直接检查条件，但它需要$O(2^n \cdot n)$时间，因为每个子集可能需要乘以$n$元素。 即使对于$n = 40$，更不用说$10^5$。 

转折点是认识到我们正在研究乘法结构模$n$，但我们不需要保持所有元素的可逆性。 相反，我们只关心产品是否等于$1$，这建议尽可能将元素与其模逆配对。 

如果一个元素$x$有乘法逆模$n$, 存在$y$这样$xy \equiv 1 \pmod n$。 这些元素自然地形成对，并且将两者都贡献为中性产品。 唯一不能干净配对的元素是那些不可逆模的元素$n$，即那些不与$n$。 

然而，简单地采用所有互质元素仍然不能保证产品$1$。 我们需要一个更强的结构：可逆留数模的集合$n$形成一个乘法群，并且在任何有限群内，所有元素的乘积都是紧密结构的。 对于这个问题，我们不依赖完整的群论，而是使用建设性配对策略。 

我们结对$(x, y)$这样$xy \equiv 1 \pmod n$。 每对贡献产品$1$，因此任何完整对的集合也会乘以$1$。 我们必须小心对待的唯一不成对元素是$1$，它始终保持有效并提供中性乘法。 

这将问题简化为选择可以与中的不同逆元配对的所有数字$[1, n-1]$，确保我们包含每对的两个元素。 构造变得确定性：迭代数字并将每个未使用的可逆元素与其逆模匹配$n$。 

最终的答案是所有这样的配对元素加上数字$1$，始终可以包含在内。

 | 蛮力 |$O(2^n \cdot n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

## 算法演练

 1. 标记所有数字$1$到$n-1$与最初未使用的一样。 我们将逐渐在它们之间建立不相交的逆对。 
2. 对于每个数字$x$从$1$到$n-1$，如果还没有使用，检查它是否有乘法逆模$n$位于范围内。 实际上，这个数字是$y$这样$x \cdot y \equiv 1 \pmod n$。 
3. 如果有这样一个$y$存在并且不同于$x$，以及两者$x$和$y$未使用，请将两者都包含在答案中并将其标记为已使用。 这确保了他们的产品做出贡献$1 \pmod n$。 
4. 如果不存在有效的合作伙伴或$x = y$，暂时跳过它，因为单独包含它会破坏产品条件，除非它是$1$。 
5.处理完所有元素后，显式包含$1$在答案中，因为它不会影响产品并且始终是安全的。 
6. 按升序输出收集到的元素。 

### 为什么它有效

 关键的不变量是除了$1$是完整逆对模的一部分$n$。 每个这样的对都贡献一个乘法恒等模$n$，所以所有选定对的乘积仍然存在$1$。 添加$1$不改变产品。 任何未配对的元素都将对应于所选集合中没有明显逆元的残基，并且包含它会阻止产品被$1$，所以排除它是必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

used = [False] * n
res = []

def modinv(x, n):
    # extended Euclid for modular inverse
    a, b, m = x, n, n
    u0, u1 = 1, 0
    while b:
        q = a // b
        a, b = b, a - q * b
        u0, u1 = u1, u0 - q * u1
    if a != 1:
        return -1
    return u0 % m

for x in range(1, n):
    if used[x]:
        continue
    if x == 1:
        continue
    y = modinv(x, n)
    if y == -1 or y == x or y <= 0 or y >= n:
        continue
    if not used[y]:
        used[x] = used[y] = True
        res.append(x)
        res.append(y)

res.append(1)
res.sort()

print(len(res))
print(*res)
```该代码使用扩展欧几里得算法构造模逆对。 每个数字要么配对一次，要么跳过。 数组`used`确保没有元素在多对中重复使用。 

的特殊处理`1`避免尝试将其与自身配对，因为它是其自身的逆，但必须被视为不会破坏乘积条件的单例。 

最后排序可确保输出遵循所需的递增顺序。

 ## 边缘情况

 当$n = 2$，唯一的元素是$1$。 该算法完全跳过配对并直接输出$[1]$，这很容易满足条件，因为空乘积是$1$。 

什么时候$n$中的每个数都是质数$[1, n-1]$具有唯一的逆。 该算法几乎将所有东西配对，除了$1$，因此结果包括除因自逆结构而排除的所有数字外，自逆结构仅影响素数$1$。 这符合近乎完整的集合有效的预期。 

什么时候$n$是复合的并且具有自逆元$x$这样$x^2 \equiv 1 \pmod n$，这些元素将被跳过，除非它们是$1$。 该算法自然会排除它们，因为它们的倒数等于自身，从而防止错误配对并保持乘积约束的正确性。
