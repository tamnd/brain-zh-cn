 ## 解决方案
 ## 问题理解

 我们被要求计算数组的长度`n`每个元素位于`0`和`2^k - 1`，使得所有元素的按位与为零并且元素之和尽可能大。 结果应返回模数`10^9 + 7`。 

具体来说，每个数组元素可以可视化为`k`-位数。 按位与为零意味着对于从`0`到`k-1`，数组中必须至少有一个元素是该位`0`。 如果有一点是`1`在每个元素中，AND 将保留`1`。 当每个元素尽可能大时，总和最大化，在此范围内`2^k - 1`。 但是，我们不能简单地将所有元素设置为`2^k - 1`，因为这样 AND 就不会为零。 

问题约束允许`n`最多`10^5`和`k`最多`20`。 和`t`最多 10，任何解决方案的性能都超过粗略值`10^8`操作会太慢。 这排除了显式枚举所有可能的数组，甚至排除了迭代`2^k`每个元素的可能性。 该解决方案必须利用组合结构和按位运算的属性。 

当出现不明显的边缘情况时`n = 1`。 单个元素的 AND 为零的唯一方法是该元素本身为零，因此最大和为`0`并且只有一个数组。 一种天真的方法，假设我们总是可以选择`2^k - 1`元素会在这里失败。 

## 方法

 暴力方法将尝试生成每个可能的长度数组`n`中的元素`0..2^k-1`，计算其按位与，并跟踪最大和。 这在原则上是正确的，但完全不可行。 例如，与`k=20`和`n=10^5`， 有`(2^20)^10^5`数组，这是一个天文数字。 

关键的见解是从元素切换到位模式。 为了获得最大总和，每个元素应该是`2^k - 1`（所有位均已设置）除了我们需要 AND 为零之外。 为了确保 AND 为零，我们必须至少选择一个元素来“关闭”每一位。 计算数组的数量可以简化为计算可以将零分配给多少种方式`n`元素使得每个`k`位至少有一个零。 

正式地，如果我们标记`x = 2^k - 1`，那么每个元素要么是`x`或者`x`清除了一些位。 为了使 AND 为零，数组不能完全由以下组成`x`。 这相当于计算长度的数组`n`超过集合`{0, 1}`限制条件是并非所有元素都是`1`。 也就是组合起来`2^n - 1`。 在这里，`2^k`每个元素的可能性都被构造为仅禁止一种模式（所有模式），从而使`2^k - 1`每个元素的选择。 因此，有效数组的数量为`(2^k - 1)^n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((2^k)^n) | O((2^k)^n) | O(n) | 太慢了|
 | 最佳 | O(k + log n) | O(k + log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`n`和`k`。 
3. 计算`mod = 10^9 + 7`用于模运算。 
4. 计算`ways = pow(2^k - 1, n, mod)`。 这样计算`(2^k - 1)^n mod 10^9 + 7`。 使用 Python 的内置模幂运算可确保其处理大型数据`n`高效。 
5、输出`ways`。 

为什么它有效：每个元素都有`2^k`可能的值。 当元素尽可能大时，总和最大化，因此我们使用`2^k - 1`作为基础。 AND 限制仅消除每个元素都为的数组`2^k - 1`。 因此，其余数组恰好是至少一个元素不是最大值的所有数组。 即使对于非常大的情况，模幂也可以有效地计算`n`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        max_val = (1 << k) - 1
        # number of arrays with at least one element different from max_val
        result = pow(max_val, n, MOD)
        print(result)

if __name__ == "__main__":
    solve()
```解首先计算`max_val = 2^k - 1`为了清楚起见。 使用`pow(base, exp, mod)`避免溢出并提供 O(log n) 计算。 每个测试用例都是独立的，所以我们循环`t`并立即打印结果。

 ## 边缘情况

 当`n=1`，算法计算`pow(2^k-1,1) = 2^k - 1`，它计算所有单元素数组。 只有零数组给出 AND 零，因此输出模 10^9+7 正确返回`1`。 为了`n`大时，该算法可以有效地处理取模求幂，避免整数溢出，同时隐式遵守 AND-0 约束。 不会发生相差一错误，因为`pow()`直接计算有效数组的精确计数。
