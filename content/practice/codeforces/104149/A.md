 ## 解决方案
 ## 问题理解

 我们得到一组 n 个对象，每个对象代表一个链节。 一些链接对已经连接起来，形成一个无向简单图。 最终目标是使用单个允许的操作重新排列连接：我们可以选择一个链接，断开其所有当前连接，然后将其任意重新连接到其他链接，然后再次锁定它。 最多执行一次此操作后，我们希望每个链接最终都恰好连接到其他两个链接，并且所有链接一起必须形成一个闭环，其中每个节点恰好包含一次。 

用图术语来说，目标结构是一个跨越所有 n 个顶点的简单循环，即连通的 2-正则图。 允许的操作受到极大限制：我们只能完全“重置”一个顶点的邻接列表一次，而除了与该顶点相关的边之外，所有其他边都保持不变。 

约束允许最多 100,000 个节点和 200,000 个边。 任何尝试组合地探索所有可能的重建或模拟边缘重新连线的解决方案都会立即失败，因为所选顶点周围的潜在重新连接的数量会随着其度数和 n 的组合而增长。 可行的方法必须将问题减少到图上的少量结构检查。 

当图已经接近循环但存在局部缺陷时，就会出现微妙的边缘情况。 例如，如果除了一个顶点的度数为 4 和另一个顶点的度数为 0 之外，所有顶点都已具有度数 2，则简单的度数检查可能会错误地接受或拒绝，具体取决于操作的解释。 另一种失败情况发生在图已经是有效循环但操作是不必要的时，并且算法错误地假设必须始终使用操作并破坏循环结构。 

## 方法

 暴力解释将尝试选择要操作的顶点，然后模拟删除其所有边并以各种可能的方式重新连接它以恢复单个循环。 对于选定的顶点 v，我们必须考虑如何重新连接其邻居，并可能引入新的边，以确保所有顶点最终的度数恰好为 2，并且保留连接性。 即使我们修复所有其他顶点，将 v 附加回结构的方法数量也是 n 的指数，因为我们实际上是在尝试将 v 嵌入到哈密顿循环中。 

这会失败，因为核心需求不是本地的。 最终的结构是哈密顿循环，并且决定是否可以通过修改单个顶点将图变成图仍然受到全局度和连通性约束的控制。 关键的观察是，在一个循环中，每个顶点的度数恰好为 2。因此，在初始图中，除了可能修改的顶点之外，所有顶点的度数都必须最多为 2，并且事实上在任何有效解中都恰好为 2，因为除了所选顶点之外，我们不允许减少度数。 

这立即形成了一个强大的结构：在最终配置中最多有一个顶点可以违反度 2，并且该顶点正是我们允许修改的顶点。 在初始图中，每个其他顶点的度数必须恰好为 2，因为我们无法删除与它们相关的边，也无法在一个循环中将它们的度数增加到超过 2。 因此，该图几乎已经是一个循环，除了可能在一个边缘错误的顶点处。

问题简化为检查是否存在顶点 v，这样如果我们忽略与 v 相关的所有边，则剩余图已经是 n 个顶点上的单个简单循环减去 v 的作用，并且可以适当地重新连接 v 以恢复完整的循环。 这意味着一个非常强的必要条件：除 v 之外的每个顶点的度数必须恰好为 2，并且其余结构必须形成可以通过 v 闭合的单个路径。 

因此，解决方案变成了度分析加上删除一个顶点的图上的连通性检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力重建| 指数| O(n + m) | 太慢了|
 | 学位+结构检查| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们首先根据输入边计算每个顶点的度数。 这提供了有关顶点是否已经与循环兼容的即时信息。 

接下来，我们确定可以修改的候选顶点。 由于最终结构中所有其他顶点必须已经满足度数 2，因此度数不等于 2 的任何顶点都被迫成为唯一可能的修改点。 如果存在多个这样的顶点，则不可能有解决方案。 

如果没有度数不为 2 的顶点，则该图已经是不相交环的集合。 在这种情况下，我们必须确保它恰好是一个周期，这意味着图必须是连通的。 否则，我们无法使用单个允许的操作合并循环，因此答案是否定的。 

如果恰好有一个顶点 v 的度数不为 2，我们模拟删除 v 及其所有关联边。 删除之后，每个剩余的顶点必须以非常特定的模式具有恰好为 2 或 1 的度数：剩余的结构应该是一条路径，其端点恰好是附加到 v 的邻居。 

然后，我们在删除 v 后检查图的连通性，忽略与 v 相关的边。如果所有剩余顶点都连接并形成一个简单的路径结构（即，恰好两个顶点的度数为 1，所有其他顶点的度数为 2），则可以通过将 v 连接到这两个端点来重新插入 v，形成单个循环。 

最后，如果这些条件成立，我们输出 yes，否则输出 no。 

### 为什么它有效

 在任何有效的最终配置中，图都是一个单循环，它强制每个顶点的度数恰好为 2。 由于我们只能修改一个顶点，因此初始图中的所有其他顶点必须已经满足这一条件。 这迫使形成一种刚性结构，其中最多有一个顶点可以违反 2 级，并且所有结构不一致都必须集中在那里。 删除该顶点将问题简化为检查剩余图是否已经是一条简单路径，可以通过重新连接删除的顶点来将其闭合为一个循环，这正是允许的操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    deg = [0] * n

    edges = []
    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        adj[a].append(b)
        adj[b].append(a)
        deg[a] += 1
        deg[b] += 1
        edges.append((a, b))

    bad = [i for i in range(n) if deg[i] != 2]

    if len(bad) == 0:
        # must already be a single cycle
        vis = [False] * n
        stack = [0]
        vis[0] = True
        cnt = 1
        while stack:
            v = stack.pop()
            for to in adj[v]:
                if not vis[to]:
                    vis[to] = True
                    stack.append(to)
                    cnt += 1
        print("yes" if cnt == n else "no")
        return

    if len(bad) != 1:
        print("no")
        return

    bad_v = bad[0]

    # remove bad_v implicitly
    vis = [False] * n
    stack = []

    start = -1
    for i in range(n):
        if i != bad_v and deg[i] > 0:
            start = i
            break

    if start == -1:
        print("no")
        return

    stack.append(start)
    vis[start] = True
    cnt = 1

    while stack:
        v = stack.pop()
        for to in adj[v]:
            if to == bad_v:
                continue
            if not vis[to]:
                vis[to] = True
                stack.append(to)
                cnt += 1

    # count remaining vertices
    remaining = n - 1
    if cnt != remaining:
        print("no")
        return

    # check degree structure after removal
    deg2 = 0
    deg1 = 0

    for i in range(n):
        if i == bad_v:
            continue
        d = sum(1 for to in adj[i] if to != bad_v)
        if d == 1:
            deg1 += 1
        elif d == 2:
            deg2 += 1
        else:
            print("no")
            return

    if deg1 == 2 and deg2 == n - 3:
        print("yes")
    else:
        print("no")

if __name__ == "__main__":
    solve()
```该解决方案首先构建邻接列表和计算度，这是立即检测结构违规所必需的。 套装`bad`捕获当前状态下不属于循环的所有顶点。 

如果没有坏顶点，则该图一定已经是循环的并集。 由于我们无法在不破坏度数约束的情况下执行任何合并组件的操作，因此我们只需验证图是否已连接。 

如果恰好有一个坏顶点，我们会从概念上删除它并分析剩余的结构。 DFS 确保导出子图的连通性。 我们在遍历和度检查期间明确忽略与已删除顶点相关的边，这精确地模拟了允许的操作。 

最终的度数条件强制要求剩余的图是一条简单路径，恰好有两个度数为 1 的端点。这些端点对应于删除的顶点将重新连接以形成循环的位置。 

## 工作示例

 ### 示例 1

 输入：```
4 3
1 2
2 3
2 4
```这里的度数是`[1, 3, 1, 1]`。 顶点 2 是唯一需要修改的候选点。 

| 步骤| 行动| 剩余图状态 |
 | --- | --- | --- |
 | 1 | 识别坏顶点 = 2 | 节点 1、3、4 仍然存在 |
 | 2 | 删除顶点 2 | 边缘已移除 |
 | 3 | 检查连接性 | 1、3、4通过原始结构断开|
 | 4 | 学位检查 | 超过两个端点 |

 剩余的结构不是覆盖除 2 之外的所有节点的单一路径，因此答案是否定的。 

### 示例 2

 输入：```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```所有顶点的度数都是 3，因此每个顶点都是坏的。 

| 步骤| 行动| 状态|
 | --- | --- | --- |
 | 1 | 计算坏顶点 | 4 |
 | 2 | 检查约束 | 多个坏顶点 |
 | 3 | 拒绝 | 立即失败 |

 这证实了密集图无法通过一次修改来纠正。

 ## 边缘情况

 一个关键的边缘情况是图已经是一个循环。 在这种情况下，没有顶点的度数不同于 2，因此算法进入“已经有效”分支并仅检查连通性。 如果循环被分成多个部分，例如两个不相交的三角形，则 DFS 计数将小于 n，正确答案为“否”。 

另一种边缘情况是多个顶点违反度 2 时。例如，中心连接到所有其他顶点的星形图会产生许多坏顶点。 由于只能修改一个顶点，因此算法会立即拒绝，这与没有任何一次重新布线可以将所有多余度数正确分配到循环结构中的事实相匹配。
