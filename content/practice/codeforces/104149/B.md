 ## 解决方案
 ## 问题理解

 我们得到了几锅药水。 每个大锅包含已知数量的升，并且每升具有已知浓度的成分。 我们的目标是将这些大锅的各个部分组合起来，使最终混合物具有精确的目标浓度，同时最大化我们最终得到的总升数。 

您可以倒出大锅的任何部分，因此每个大锅的行为就像连续供应液体一样。 限制仅针对最终混合物：您所采取的所有物质的加权平均浓度必须符合所需的目标。 

重申目标的一个有用方法是，每个单位的液体贡献一个“值”，等于其浓度高于或低于目标的程度。 我们希望挑选尽可能多的液体，同时使这些偏差完全抵消。 

限制很小，最多有几千个大锅和对实数的简单算术运算。 这立即排除了涉及指数搜索或子集复杂动态规划的任何情况。 预计会出现线性或线性贪婪策略。 

当贪婪地思考“首先获取接近目标的一切”时，就会出现微妙的失败案例。 这种方法忽略了一侧过度填充会迫使另一侧进行补偿，并且通常需要部分使用大锅。 

例如，如果目标是 0.5，我们有两个大锅：一个浓度为 0.9，另一个浓度为 0.1，如果体积匹配，则将两者全部取走即可得到精确平衡，但即使两者都离目标“很远”，改变体积也会稍微打破平衡。 正确的答案通常需要精确地修剪一侧。 

另一种极端情况是所有大锅都位于目标的一侧。 那么就不可能使用所有的东西，我们必须丢弃部分最极端的坩埚来恢复平衡。 

## 方法

 一个蛮力的想法是考虑每个可能的坩埚子集，并针对每个子集决定从每个坩埚中取出多少，以使最终混合物达到目标浓度。 即使我们忽略连续性并只考虑选择子集，这也已经导致$2^n$可能性太大了$n \le 1000$。 在每个子集中引入连续优化使其更加不可行。 

关键的观察是对最终混合物的约束可以以线性形式重写。 如果我们表示为$x_i$从大锅中取出的量$i$，并由$p_i$其浓度、条件$$\frac{\sum x_i p_i}{\sum x_i} = p$$相当于$$\sum x_i (p_i - p) = 0.$$这将问题转化为选择非负数$x_i \le c_i$使得有符号加权和变为零，同时最大化$\sum x_i$。 

现在每个单位的液体都有一个“偏差”$d_i = p_i - p$。 正偏差将混合物推至目标上方，负偏差将其拉至目标下方。 任务变成了精确地平衡这些力量。 

这种结构意味着一种贪婪的策略：我们从获取一切开始，然后通过去除液体来调整以修复不平衡。 从坩埚中去除液体会以线性方式改变总体积和偏差总和，因此去除的每个单元在纠正不平衡方面具有恒定的效率。 

这将问题简化为一维平衡过程，我们总是从有助于最快纠正不平衡的一侧去除液体。

 ## 算法演练

 ### 步骤

 1. 换算目标浓度$p$进入偏差基线并计算$d_i = p_i - p$对于每个大锅。 这重新构建了问题，以便正确的混合物的总偏差恰好为零。 
2. 首先假设我们从每个大锅中取出所有可用的液体。 计算总体积和总偏差总和。 这代表了最乐观的起点，尽管它通常会违反平衡条件。 
3. 如果总偏差已经为零，则当前总成交量是最优的，我们可以立即停止。 
4. 如果偏差为正，则混合物浓度太高。 减少它的唯一方法是从具有正偏差的坩埚中去除液体，因为去除负偏差会使不平衡变得更糟。 
5. 将具有正偏差的坩埚按每升偏差降序排列。 这会优先去除液体，以最快的速度修复每单位体积损失的不平衡。 
6. 迭代这些坩埚，从每个坩埚中移除尽可能多的东西，直到耗尽或总偏差达到零。 每次移除都会线性减少体积和偏差。 
7. 如果偏差为负，则对负偏差的坩埚进行对称处理，首先除去负偏差最大的坩埚，直至恢复平衡。 
8. 平衡后的剩余体积是可达到的最大有效混合物。 

### 为什么它有效

 在每一步中，我们都会维护一个混合物，其偏差可以仅使用目标一侧的移除来纠正。 每个移除的单元都会对体积损失提供固定的偏差校正比率，因此首先选择最大的比率可以最大限度地减少浪费的体积。 由于我们总是直接恢复零偏差条件，而不会在错误的方向上超调，因此我们在约束下保留最大剩余体积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, p = input().split()
    n = int(n)
    p = float(p)

    pos = []
    neg = []

    total_v = 0.0
    total_d = 0.0

    for _ in range(n):
        c, pi = input().split()
        c = float(c)
        pi = float(pi)

        d = pi - p
        total_v += c
        total_d += c * d

        if d > 0:
            pos.append([d, c])
        elif d < 0:
            neg.append([d, c])

    if abs(total_d) < 1e-12:
        print(total_v)
        return

    if total_d > 0:
        pos.sort(reverse=True)
        for d, c in pos:
            if total_d <= 0:
                break
            take = min(c, total_d / d)
            total_v -= take
            total_d -= take * d

    else:
        neg.sort()
        for d, c in neg:
            if total_d >= 0:
                break
            take = min(c, total_d / d)
            total_v -= take
            total_d -= take * d

    print(total_v)

if __name__ == "__main__":
    solve()
```该解决方案首先计算完整的混合物，然后将不平衡校正视为受控去除过程。 关键的实现细节完全以浮点方式工作，并进行仔细的线性更新：每次删除都会按比例减少体积和偏差。 

分选仅适用于偏差的一侧，确保我们始终首先去除最“有效”的液体。 明确处理正例和负例之间的对称性，以避免更新公式中的符号错误。 

## 工作示例

 ### 示例 1

 输入：```
3 0.5
5 0.3
1 0.4
10 0.9
```我们计算偏差：

 | 步骤| 所取体积| 总偏差|
 | --- | --- | --- |
 | 开始| 16 | 16 +3.0 |

 混合物太浓，因此我们首先消除正偏差。 

我们对正偏差进行排序：0.4 和 0.9，但按距 0.5 的距离加权得出 0.4 和 0.9 的贡献。 

我们首先从 0.9 开始删除，直到恢复平衡，然后在偏差达到零时停止。 剩余体积变为 8.75。 

这表明只需要从高浓度坩埚中部分去除，而不是完全排除。

 输入：```

1 0.4
1 0.9
```| 步骤| 所取体积| 总偏差|

从 0.9 的坩埚中取出足够的物质后，系统达到平衡，最终体积为 3.5。 

这个例子强调了最佳解决方案通常使用从单个大锅中部分移除而不是丢弃整个大锅。

 ## 边缘情况

 一种重要的情况是所有坩埚的浓度都高于目标浓度。 算法正确进入“正偏差”分支，先从最强的大锅中移出，直至偏差消除。 即使不存在平衡伙伴，分数去除也可确保有效的精确解。 

另一种情况是初始混合物已经平衡。 偏差总和为零，因此算法立即返回完整体积，无需排序或删除，从而保持最优性。 

第三种情况是只需要进行微小调整的情况。 由于去除是连续的，因此该算法可以在穿过坩埚的中途停止，确保满足精度要求，而不会超出目标混合物。
