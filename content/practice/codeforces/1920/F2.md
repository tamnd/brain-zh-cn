 ## 解决方案
 ## 问题理解

 我们有一个矩形网格，其中一些单元是岛屿，一些是开阔的海洋，一些是水下火山。 托马斯想以完全环绕岛屿的方式航行，但又不想踏上岛屿。 对于每个海洋或火山起始单元，我们需要确定最大安全性，定义为从任何单元到最近火山的往返行程中的最小曼哈顿距离。 网格保证岛屿形成远离边缘的单个连接块，并且所有海洋/火山单元形成一个连接组件。 

这些约束允许最多 300,000 个单元和 300,000 个查询，因此任何通过模拟路径独立处理每个查询的算法都太慢。 每个查询的朴素 BFS 将花费 O(n*m) 个查询，在最坏的情况下导致大约 10^11 次操作，这是不可接受的。 挑战在于有效地预先计算每个海洋/火山单元的安全性并在 O(1) 时间内回答查询。 

不明显的边缘情况包括从火山旁边开始、从开放水域的一角开始或岛屿周围有狭窄的通道。 粗心的实现可能会假设只有一条路径来环绕岛屿，当存在多个环绕路线时就会失败，或者可能会错误计算沿对角线的距离与曼哈顿距离。 例如，如果一座火山孤立在岛屿附近，但起始单元较远，则最大安全性应反映任何环绕路径上的最近点，而不是沿直线到最近火山的直接曼哈顿距离。 

## 方法

 暴力方法是枚举每个查询点的所有可能的往返行程，计算每条路径到火山的最小距离，并取其中的最大值。 这在原则上是正确的，但环绕路径的数量随着岛屿周长呈指数增长，使其不可行。 对于 3_10^5 个单元格和多个查询，此方法的复杂度为 O(n_m*q) 并且会失败。 

关键的见解是，给定单元的最大安全性相当于我们与所有火山保持的最大曼哈顿距离，同时仍然能够形成绕岛的环路。 这可以被视为一个几何问题：仅考虑海洋/火山网格，使用多源 BFS 计算每个单元到最近火山的距离，然后认识到最大安全性是允许完全环绕岛屿的路径的最大值。 由于该岛是远离边缘的单个连接组件，因此岛外的一组海洋/火山单元在其周围形成了一个“框架”。 该问题简化为传播从火山到所有海洋单元的距离并根据查询报告它们。 

我们可以使用 BFS 同时计算所有火山单元的距离，填充每个海洋/火山单元到任何火山的最小曼哈顿距离。 然后，由于岛屿周围的所有海洋/火山单元都可以到达，因此该距离正是从该单元出发的往返行程的最大安全距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n_m_q) | O(n_m_q) | O(n*m) | 太慢了 |
 | 多源BFS | O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 将网格解析为二维字符数组。 记录 BFS 队列中所有火山单元的位置。 
2. 初始化一个2D数组`dist`与网格具有相同的尺寸，充满无穷大。 对于每个火山细胞`(r,c)`， 放`dist[r][c]=0`并添加`(r,c)`到 BFS 队列。 
3. 同时对所有火山单元执行 BFS。 对于每个出队的单元格，检查其四个邻居（上、下、左、右）。 如果邻居是海洋或火山单元，并且当前路径提供的距离小于之前记录的距离，则更新`dist[neighbor]=dist[current]+1`并将其排入队列。 
4. BFS完成后，`dist[r][c]`包含每个海洋或火山单元到最近火山的曼哈顿距离。 
5. 对于每个查询`(x,y)`，简单地输出`dist[x-1][y-1]`。 这是可行的，因为岛屿周围的每个海洋/火山单元都可以到达，因此预先计算的距离等于往返的最大安全性。 

BFS 维护的不变量是每个单元的距离是到任何火山的最小曼哈顿距离。 由于BFS均匀扩展，一旦某个单元被访问到一定距离，就不再存在更短的路径。 这样就保证了正确性。 

## Python 解决方案```python
import sys
from collections import deque
input = sys.stdin.readline

n, m, q = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]
dist = [[-1]*m for _ in range(n)]
queue = deque()

for r in range(n):
    for c in range(m):
        if grid[r][c]=='v':
            dist[r][c]=0
            queue.append((r,c))

directions = [(0,1),(0,-1),(1,0),(-1,0)]

while queue:
    r, c = queue.popleft()
    for dr, dc in directions:
        nr, nc = r+dr, c+dc
        if 0<=nr<n and 0<=nc<m and grid[nr][nc] in {'.','v'} and dist[nr][nc]==-1:
            dist[nr][nc]=dist[r][c]+1
            queue.append((nr,nc))

for _ in range(q):
    x, y = map(int, input().split())
    print(dist[x-1][y-1])
```第一部分读取网格并识别火山单元以进行 BFS 初始化。 BFS 确保距离传播到所有可到达的海洋/火山单元。 使用以下命令在 O(1) 内回答查询`dist`大批。 使用`-1`因为未访问的标记避免了与火山单元的有效距离为零的碰撞。

 ## 边缘情况

 如果起始单元是火山，则最大安全性为零。 例如，`(2,2)`在 3x3 网格中，火山位于`(2,2)`产量`0`。 如果像元与所有火山的距离达到最大，BFS 将确保计算出正确的距离。 由于 BFS 会通过所有可到达的海洋细胞传播距离，因此可以正确处理狭窄的通道。 即使环路必须在拐角处原路返回，但到最近的火山的距离已经是最小的，这符合最大安全定义。
