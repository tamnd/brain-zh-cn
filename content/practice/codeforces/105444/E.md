 ## 解决方案
 ## 问题理解

 每个组件都是具有整数坐标的平面上的一个点，每个点都被标记为未测试、正测试或负测试。 我们被要求假设这些点的某些子集是“泄漏源”。 

某一点的测量工作原理如下：如果您在某一点进行测试，氦气会在那里释放并向上扩散，同时在上升时也会向侧面扩展。 因此，不仅如果测试点本身泄漏，而且如果在特定的加宽锥形区域中存在位于其上方的任何泄漏点，也可以检测到泄漏。 

几何可以更具体地重新表述。 泄漏点位于$(x_j, y_j)$影响测试$(x_i, y_i)$如果它位于其上方并且水平距离不太远。 给定的条件，$$|x_i - x_j| \le \frac{y_j - y_i}{2},$$描述了一个向上开口的对称圆锥体。 

任务是选择尽可能少的泄漏点，以便每个阳性测试都可以用其影响区域中至少一个泄漏点或本身泄漏来解释，而每个阴性测试根本不能用任何泄漏点来解释，而且本身也不能泄漏。 如果不可能进行这样的选择，那么答案就是不可能的。 

输入大小高达 200000 个点，因此对点对进行任何二次推理都是不可行的。 甚至一个$O(n \log n)$或者$O(n)$预计有解决方案。 由于几何关系的密度，任何试图明确检查所有点对之间影响的方法都会立即失败。 

当负点在几何意义上位于许多正点“下方”时，就会出现微妙的边缘情况。 如果不小心，选择一个泄漏点来满足正约束可能会意外违反其上方的负约束，因为影响区域在加宽的锥体中向上无界。 

当正点上方没有可能的泄漏源时，会出现另一种故障模式。 即使该点本身在输入中没有被标记为泄漏，我们也可能被迫将其包含在内，并且如果它同时被负约束结构禁止，则实例变得不可能。 忽略这些全局相互作用的天真贪婪方法会错误地假设可行性。 

## 方法

 暴力策略将尝试将点的每个子集作为泄漏组件的集合，并检查是否所有正点都得到解释并且所有负点是否保持干净。 对于每个子集，验证约束需要检查点对之间的影响，即$O(n^2)$。 结合$2^n$子集，即使对于小实例，这也是完全不可行的。 

关键的结构观察是几何影响关系可以转化为修正坐标系中的支配关系。 条件$$|x_i - x_j| \le \frac{y_j - y_i}{2}$$可以重写为两个线性不等式：$$y_j - 2x_j \ge y_i - 2x_i \quad \text{and} \quad y_j + 2x_j \ge y_i + 2x_i.$$这建议定义新坐标$$p = y - 2x, \quad q = y + 2x.$$在这些坐标中，有一个点$j$影响$i$恰好在什么时候$p_j \ge p_i$和$q_j \ge q_i$。 影响区域在二维偏序中成为东北主导关系。 

现在，每个正点都需要至少一个选定的泄漏点，该泄漏点在此偏序中占主导地位。 每个选定的泄漏点都覆盖了它所控制的所有点。 

负点充当禁止约束：不允许选定的泄漏点支配负点，因为这将立即与其观察到的负结果相矛盾。 

这将问题简化为选择覆盖主导下的所有正点的最小点子集，同时完全保持在由负点引起的禁止主导区域之外。 一旦以这种方式表达，结构就会崩溃，以选择主导顺序中的最大可行元素，因为最大点覆盖了它们下面的所有点。 

暴力破解会失败，因为它处理成对的交互，而转换后的结构表明覆盖范围是单调的，并且会崩溃为全局排序。 该变换将几何简化为偏序理论，从而实现基于极值元素的贪婪构造。

 ## 算法演练

 我们在变换后的坐标中工作$p = y - 2x$和$q = y + 2x$，其中影响力变成了坐标方面的优势。 

1. 将每个点变换为$(p, q)$形式。 这将几何影响转换为单调偏序。 现在的目标纯粹是组合性的。 
2. 识别所有禁止作为潜在泄漏源的点。 如果某个点是阴性测试，则该点被禁止，因为选择它会立即与观察结果相矛盾。 
3. 删除所有禁止点。 任何有效的解决方案都必须仅从剩余的集合中选择泄漏点。 
4. 检查每个积极点的可行性。 对于每个正点，验证是否至少存在一个剩余点支配它。 如果不存在这样的点，则该实例是不可能的，因为没有泄漏配置可以解释该观察结果。 
5.观察到任何有效的解决方案都必须从剩余的点中选择，并且任何不被另一个剩余点支配的点作为解释源严格来说更有力。 这些点支配其下方的所有点，因此不能通过用支配点替换它们来改进。 
6. 收集支配关系下剩余集合中的所有最大点。 这些点没有其他剩余点同时具有$p$和$q$大于或等于。 
7. 输出这些最大点的数量作为泄漏组件所需的最小数量。 

### 为什么它有效

 删除禁止点后，任何有效的泄漏集都必须使用优势解释每个正点。 如果某个正值点可以由某个选定的泄漏点来解释，则用最大支配点替换该泄漏点永远不会减少覆盖范围，也不会违反可行性，因为最大点支配其替代点所做的一切。 重复应用此替换会将任何有效的解决方案按优势顺序向上推，直到仅保留最大元素。 这表明最小可行集总是可以被视为最大元素的子集，并且最大元素的更小的子集仍然可以覆盖所有正点而不丢失必要的优势覆盖。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    
    for _ in range(n):
        x, y, c = input().split()
        x = int(x)
        y = int(y)
        
        p = y - 2 * x
        q = y + 2 * x
        
        pts.append((p, q, c))
    
    allowed = []
    
    # negative points cannot be selected
    forbidden = set()
    
    for p, q, c in pts:
        if c == 'N':
            forbidden.add((p, q))
    
    for p, q, c in pts:
        if (p, q) not in forbidden:
            allowed.append((p, q, c))
    
    # check feasibility: every P must be dominated by some allowed point
    for p, q, c in allowed:
        if c == 'P':
            ok = False
            for p2, q2, _ in allowed:
                if p2 >= p and q2 >= q:
                    ok = True
                    break
            if not ok:
                print("impossible")
                return
    
    # extract maximal points in allowed set
    ans = 0
    for i, (p1, q1, _) in enumerate(allowed):
        dominated = False
        for j, (p2, q2, _) in enumerate(allowed):
            if j != i and p2 >= p1 and q2 >= q1:
                dominated = True
                break
        if not dominated:
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```第一步执行坐标变换，将几何影响转换为单调优势关系。 第二阶段消除所有负面点，因为选择它们会立即与约束相矛盾。 

可行性检查确保每个正点都在至少一个允许点的优势区域内。 如果没有这种检查，当某些正约束从根本上无法解释时，我们可能会错误地假设存在解决方案。 

最后，计算最大元素是有效的，因为任何非极大点作为解释源都更糟糕：它涵盖了主导点所涵盖内容的子集，因此在最小构造中永远不需要它。 

## 工作示例

 考虑一个小型配置，其中一个点是正极，两个点是潜在源。 

| 步骤| 行动| 剩余积分 | 最大候选人 |
 | --- | --- | --- | --- |
 | 开始| 变换坐标 | 所有点| - |
 | 过滤| 删除底片 | 允许集 | - |
 | 检查 P | 验证覆盖范围 | 相同| - |
 | 最大扫描 | 识别非支配点 | 相同| 选定集|

 在单个右上角的点支配一切的情况下，它成为唯一的最大元素，因此答案为 1。这表明一旦考虑支配性，所有较低的点将变得无关紧要。 

现在考虑存在两个分离的最大区域的情况。 每个区域都包含不互相支配的点，因此两者都作为最大元素存在。 这表明答案计算了独立的优势峰值。

 ## 边缘情况

 当负点位于许多潜在泄漏源上方时，就会出现临界边缘情况。 在变换空间中，这会删除大面积的候选点。 该算法通过在任何优势推理之前排除所有禁止点来处理此问题，确保不考虑任何无效源。 

另一种情况是当一个正点被孤立时，没有允许的支配点。 可行性检查通过扫描任何允许的支配者来尽早发现这一点，防止错误地假设最大点就足够了。 

第三种情况是所有点的优势度都没有可比性。 在这种情况下，每个允许的点都变得最大，并且算法正确地返回完整计数，这反映出没有点可以替代另一个点来覆盖正数。
