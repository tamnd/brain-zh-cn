 ## 解决方案
 ## 问题理解

 我们得到了一组代表橙子的整数标签。 对这些标签进行排序后，我们得到一个有序序列$b_1 \le b_2 \le \dots \le b_n$。 根据这个序列，我们构建了一个完整的加权图$n$顶点，其中顶点之间的权重$i$和顶点$j$是绝对差值$|b_i - b_j|$。 

任务是计算该图中最大生成树的权重，这意味着我们要准确选择$n-1$连接所有顶点的边，同时最大化所选边权重的总和。 

约束足够大，无法构建完整的图。 一个天真的解决方案需要$O(n^2)$边，并会尝试通过 Kruskal 或 Prim 建立最大生成树，当$n$达到$10^5$。 这迫使我们对结构而不是枚举进行推理。 

当所有值都相等时，会出现微妙但重要的边缘情况。 在这种情况下，每条边的权重都为零，因此答案也必须为零。 假设至少有一个正边缘的幼稚实现可能仍然在数值上有效，但许多不正确的贪婪构造会失败，因为它们假设存在有意义的排序间隙。 

另一个边缘情况出现时$n = 2$。 该图只有一条边，所以答案很简单$|b_2 - b_1|$。 任何派生公式都必须正确退化为这种情况。 

## 方法

 蛮力方法很简单：构建完整的图$n(n-1)/2$边并运行 Kruskal 算法以获得最大生成树。 每个边的权重被计算为绝对差，并且排序边在运行时占据主导地位$O(n^2 \log n)$。 和$n = 10^5$，这在时间和内存上都是不可能的，因为甚至存储边缘也是不可行的。 

关键的观察结果是权重函数$|b_i - b_j|$仅取决于排序数组中的位置。 在排序序列中，最大的差异总是来自端点或端点附近。 这意味着在克鲁斯卡尔的过程中，唯一重要的边是那些连接当前未连接段的极端的边。 

如果我们从概念上想象运行 Kruskal，边的权重是从最大到最小的。 最大可能的边位于$b_1$和$b_n$。 一旦选择，下一个有用的边总是将一个新的极端元素（下一个最小或下一个最大的剩余元素）连接到已经连接的极端之一。 此过程避免了考虑内部到内部连接的任何需要，因为它们始终由涉及端点的边主导。 

这种结构使我们能够将问题简化为对排序数组的线性扫描，根据每个元素距端点的距离来累积贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（完整图上的克鲁斯卡尔）|$O(n^2 \log n)$|$O(n^2)$| 太慢了|
 | 最优（排序结构贪婪）|$O(n \log n)$|$O(1)$额外 | 已接受 |

 ## 算法演练

 这个想法是用单个元素相对于全局最小值和最大值的贡献来表达 MST 权重。 

1. 对数组进行排序$b$。 排序至关重要，因为所有结构推理都依赖于按值排序而不是按索引排序。 
2. 计算全局最小值$b_1$和最大$b_n$。 这两个端点将形成跨越结构的主干。 
3.添加基础贡献$b_n - b_1$到答案。 这对应于极端之间的第一个也是最强的联系。 
4. 对于每个室内元素$b_i$在哪里$2 \le i \le n-1$，计算距离每个端点的距离。 具体计算$f(b_i) = \max(b_i - b_1, b_n - b_i)$。 这代表了附加成本$b_i$到最终树结构中的更远端点。 
5. 将所有这些贡献总结为最终答案。 

这样做的原因是，除了极端之间的初始连接之外，每个内部元素实际上都为 MST 贡献了一个边缘。 最佳选择始终将其附加到最大化边权重的端点，因为 Kruskal 构建的 MST 总是更喜欢仍保持连接性的较大可用边。 

### 为什么它有效

 在排序集上的绝对差的最大生成树中，该过程相当于从其边界重复合并当前活动区间。 第一条边连接两个全球极端。 之后，每个剩余的顶点都连接到产生较大差异的端点，因为非极值点之间的任何连接始终由到至少一个端点的连接主导。 这创建了一种确定性结构，其中每个内部元素恰好贡献一个最大可能的附着成本，并且没有替代边缘配置可以在不违反生成树约束的情况下增加总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    b = list(map(int, input().split()))
    b.sort()

    if n == 1:
        print(0)
        return

    mn = b[0]
    mx = b[-1]

    ans = mx - mn

    for i in range(1, n - 1):
        ans += max(b[i] - mn, mx - b[i])

    print(ans)

if __name__ == "__main__":
    solve()
```解决方案首先对数组进行排序，这是唯一的非线性步骤。 排序之后，我们直接提取最小值和最大值。 基本术语$mx - mn$对应端点之间的强制连接。 

内部元素的循环计算每个元素的最佳可能附着成本。 使用`max(b[i] - mn, mx - b[i])`编码决定元素是否更有利地连接到 Kruskal 驱动的构造中的左端点或右端点。 

一个微妙的实现细节是处理$n = 1$。 如果没有这个保护，公式仍然有效，但会错误地计算$b_n - b_1$与单个元素。 显式返回零可以避免歧义。

 ## 边缘情况

 对于$n = 1$，算法立即返回零，因为生成树中没有边可包含。 完全跳过循环，并且公式从不尝试无效索引。 

为了$n = 2$，初始化将答案设置为$b_2 - b_1$，并且循环为空。 这匹配唯一可能的生成树。 

对于相同的值，两者$mn$和$mx$相等，因此基项为零，并且每个内部贡献的计算结果为零。 该算法无需特殊分支即可正确生成零，因为对于每个元素，最大值内的两项都为零。
