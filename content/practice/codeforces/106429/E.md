 ## 解决方案
 ## 问题理解

 我们正在模拟一个过程，其中蛇随着时间的推移穿过固定的细胞序列。 在每个时间步$t$，蛇的头部占据了一个已知的单元格$c(t)$。 有些细胞可能会随着时间的推移而重复，这意味着蛇可以稍后重新访问相同的位置。 

蛇在选定的时间“吃苹果”，每吃一次，它的长度就会增加一倍。 分数贡献取决于时间和当前长度：直观上，与较大的蛇呆更长时间是有益的，因为当蛇较长时，每个单位时间贡献更多。 

不过按时吃饭$t$仅当该单元格对于生成苹果有效时才允许，这取决于该单元格最后一次被访问的时间。$t$。 如果最近访问了同一个单元格，则会存在一个限制窗口，在此期间苹果不能被视为在该位置有效。 

目标是选择一系列的进食时间和相应的长度，以最大化迄今为止的总分$N$，加上最后的延续阶段，蛇将保持其最终长度直到结束。 

从约束的角度来看，该结构强烈建议在时间和长度上采用二次或接近二次的动态规划解决方案。 对于所有状态三元组的任何三次方法对于周围的典型限制来说都太慢$N \approx 5000$。 这推动我们走向 DP，其中使用对先前状态的范围查询来优化转换。 

当单元重复时会出现常见的失败情况。 例如，如果$c(t) = c(t')$，然后选择进餐时间$t$取决于我们是否“无效”最近使用同一单元格的情况。 忽略这种依赖性的天真的 DP 将会过多计算非法转换。 

另一个微妙的问题是最终的延期期限。 如果最后用餐时间是$t$，我们仍然从$t+1$到$N$，因此忘记这个后缀贡献会导致系统性地低估答案。 

## 方法

 对问题建模最直接的方法是定义 DP 状态$dp[t][i]$，代表如果最后一个苹果及时被吃掉的话可获得的最好分数$t$蛇吃完后的长度是$i$。 

转换到状态$(t, i)$，我们尝试之前所有的用餐时间$k < t$，其中先前的长度是$i-1$。 在两次进食事件之间，蛇有长度$i-1$，所以区间的贡献$[k, t]$随时间线性增长。 这会产生形式的转变$$dp[t][i] = \max_k \left(dp[k][i-1] + (i-1)\cdot (t-k) + 1\right)$$附加约束条件是$k$必须距当前单元格的最后一次无效出现足够远。 

这种直接方法检查所有有效的$k$对于每个$(t, i)$，导致三个嵌套循环。 状态数为$O(N^2)$，以及每次转换成本$O(N)$，生产$O(N^3)$，当$N$甚至是中等大小。 

关键的观察是对于固定$i$，过渡可以重新排列成线性形式$t$和一个独立于前缀的术语$k$:$$dp[t][i] = t\cdot(i-1) + 1 + \max_k \left(dp[k][i-1] - k\cdot(i-1)\right)$$这会改变每一层$i$陷入对从先前 DP 层派生的预计算数组的范围最大查询问题。 唯一剩下的复杂因素是有效性约束$k \ge f(t) + i - 1$，这成为每个状态的左移动边界。 这是通过限制 RMQ 范围来解决的。 

一旦DP层简化为范围查询，我们就可以使用线段树或稀疏表来有效地回答每个转换。 这将整体复杂性降低到$O(N^2 \log N)$， 或者$O(N^2)$具有线性时间RMQ结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 所有状态和转换上的暴力 DP |$O(N^3)$|$O(N^2)$| 太慢了|
 | 具有 RMQ 优化的 DP |$O(N^2 \log N)$|$O(N^2)$| 已接受 |

 ## 算法演练

 让$c(t)$是此时蛇头的位置$t$。 我们首先计算，每次$t$，上一次出现相同的单元格，表示为$f(t)$。 这可以通过单元标识符上的散列映射来完成。 

然后我们在蛇长度的层上构建 DP。 

1. 预计算$f(t)$对于所有时代$t$。 这捕获了每个单元格在时间之前最近被访问的时间$t$，它决定了某个时刻是否有一个苹果$t$可以合法地依赖先前的职位。 
2.初始化基础层$dp[t][1]$为所有人$t$。 这对应于吃掉的第一个苹果，其中没有先前的长度贡献。 由于没有之前的段可以优化，因此转换很简单。 
3. 对于每个长度$i \ge 2$,构造一个辅助数组$A[k] = dp[k][i-1] - k\cdot(i-1)$。 这隔离了仅依赖于前一个决策点的转换部分$k$，将其与当前时间分开$t$。 
4. 建立一个范围最大的结构$A[k]$。 这允许查询之前的最佳进食时间$k$在任何有效间隔内有效。 
5. 每一次$t$，确定先前状态的有效范围。 左边界是$f(t) + i - 1$，从任何更早的$k$会违反由于重复访问同一单元而引起的间距限制。 
6. 计算$$dp[t][i] = t\cdot(i-1) + 1 + \max_{k \in [L, t-1]} A[k]$$在哪里$L = f(t) + i - 1$。 每个状态都由单个 RMQ 查询与线性重建相结合来填充。 

1. 填充完所有层后，通过将最后一段延伸到时间来计算最终答案$N$。 对于每个$(t, i)$，最终贡献为$dp[t][i] + i\cdot(N-t)$。 

关键的不变量是处理层之后$i-1$, 每个值$dp[k][i-1]$已经代表了在时间结束的序列的最佳分数$k$与长度$i-1$。 建层时$i$，每个候选转换恰好考虑一个有效的前一个端点并保留最优性，因为所有剩余的结构仅取决于$k$通过捕获的线性变换$A[k]$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.size = 1
        while self.size < self.n:
            self.size *= 2
        self.seg = [-10**18] * (2 * self.size)
        for i in range(self.n):
            self.seg[self.size + i] = arr[i]
        for i in range(self.size - 1, 0, -1):
            self.seg[i] = max(self.seg[2 * i], self.seg[2 * i + 1])

    def query(self, l, r):
        if l > r:
            return -10**18
        l += self.size
        r += self.size
        res = -10**18
        while l <= r:
            if l % 2 == 1:
                res = max(res, self.seg[l])
                l += 1
            if r % 2 == 0:
                res = max(res, self.seg[r])
                r -= 1
            l //= 2
            r //= 2
        return res

def solve():
    N = int(input().strip())
    c = list(map(int, input().split()))

    last = {}
    f = [0] * N
    for i in range(N):
        if c[i] in last:
            f[i] = last[c[i]] + 1
        else:
            f[i] = 0
        last[c[i]] = i

    NEG = -10**18

    dp_prev = [NEG] * N
    dp_cur = [NEG] * N

    for i in range(N):
        dp_prev[i] = 1  # base: length 1

    for length in range(2, N + 1):
        arr = [dp_prev[k] - k * (length - 1) for k in range(N)]
        st = SegTree(arr)

        for t in range(N):
            L = f[t] + length - 1
            if L >= t:
                continue
            best = st.query(L, t - 1)
            if best <= NEG // 2:
                continue
            dp_cur[t] = t * (length - 1) + 1 + best

        dp_prev, dp_cur = dp_cur, [NEG] * N

    ans = 0
    for t in range(N):
        for length in range(1, N + 1):
            if dp_prev[t] > NEG // 2:
                ans = max(ans, dp_prev[t] + length * (N - t - 1))

    print(ans)

if __name__ == "__main__":
    solve()
```该实现通过蛇形长度层将 DP 分开。 数组`arr`对变换后的先前 DP 状态进行编码，以便每次转换都成为范围最大查询。 线段树用于评估每个查询的所有候选先前进食时间（以对数时间表示）。 

递归使用仔细的索引：`length - 1`代表之前蛇的长度，术语`k * (length - 1)`调整饮食事件之间时间的线性贡献。 边界`L = f[t] + length - 1`强制执行来自重复访问同一单元的限制。 

最终答案包括一个延续阶段，但这里它被简化为基于最后一个事件后剩余时间的后缀贡献。 

## 工作示例

 考虑一个简单的情况，其中所有单元格都是不同的，因此没有位置重复。 然后$f(t) = 0$为所有人$t$。 让$N = 3$，序列是$[1, 2, 3]$。 

### 示例 1

 我们计算基础层$dp[t][1] = 1$。 

| t | dp[t][1] | dp[t][1] |
 | ---| ---|
 | 0 | 1 |
 | 1 | 1 |
 | 2 | 1 |

 对于长度 2，过渡使用$A[k] = 1 - k$。 

在$t=2$， 有效的$k$是$0,1$。 

最好的$A[k]$位于$k=0$, 给予$dp[2][2] = 2\cdot1 + 1 + 1 = 4$。 

这显示了线性分解如何将区间贡献转变为简单的最大查询。 

### 示例 2

 现在考虑重复：$c = [1, 2, 1, 3]$。 

在$t=2$，单元格 1 重复，所以$f(2)=0$。 对于较大的$i$，有效范围缩小，因为$f(t) + i - 1$增长，防止重复使用最近出现的同一单元格的转换。 

这演示了约束如何直接删除无效的 DP 转换，而不需要对蛇体几何形状进行显式模拟。

 ## 边缘情况

 当同一单元立即重复时，就会出现一种边缘情况。 在那种情况下，$f(t) = t-1$，因此对于较小的蛇长度，有效的过渡范围会崩溃。 该算法正确地处理了这个问题，因为左边界$L = f(t) + i - 1$很快超过$t-1$，使得DP状态不可达，并且跳过线段树查询。 

另一种边缘情况是给定的先前状态不存在$(t, i)$。 该实现通过在更新 DP 表之前检查查询结果与负无穷标记来保护这一点，从而防止无效状态的意外传播。 

最后的边缘情况是最佳解决方案仅使用单个饮食事件。 在这种情况下，所有转换都是无关紧要的，并且基础层$dp[t][1]$占主导地位。 最终的答案逻辑仍然正确地评估这些状态，因为它考虑了上次的所有可能$t$。
