 ## 解决方案
 ## 问题理解

 我们被要求计算一系列递归定义的图（称为 Doe 图）中的最短路径。 每个图都由阶数 _n_ 定义。 基本情况很简单：_D_(0) 是单个顶点，_D_(1) 是由一条边连接的两个顶点。 对于 _n_ ≥ 2，图 _D_(n) 是通过以特定方式组合 _D_(n-1) 和 _D_(n-2) 形成的：将 _D_(n-2) 的顶点数移动 _D_(n-1) 的大小，并添加两条新边连接 _D_(n-1) 和 _D_(n-2) 的边界顶点。 这种递归构造类似于斐波那契数列：_D_(n) 中的顶点数为 |_D_(n-1)| + |_D_(n-2)|。 

输入给出图形顺序_n_（最多1000）和查询数量_t_（最多10^5）。 每个查询都会询问图中由全局编号标识的两个顶点之间的最短距离。 顶点可以大到 10^16，因为 |_D_(1000)| 是一个天文数字。 我们被要求打印每个查询的最短路径的长度。 

主要挑战是显式构建图表是不可能的。 一个简单的 BFS 需要存储所有 |_D_(n)| 顶点，对于 n=1000，其超出内存数量级。 此外，查询的数量很大，因此必须有效地回答每个查询。 对于涉及递归结构深处或最大索引附近的顶点的查询，模拟图的粗心方法将会失败。 

要记住的边缘情况包括：查询左子图 _D_(n-1) 中的顶点、右子图 _D_(n-2) 中的顶点，以及各一个。 例如，在 _D_(5) 中，查询第一个顶点（_D_(4) 中）和第六个顶点（_D_(3) 中的第一个）需要使用递归步骤中添加的两个“桥接边”。 

## 方法

 暴力方法很简单：将 _D_(n) 构建为邻接列表，然后为每个查询运行 BFS 或 Dijkstra。 这是可行的，因为 BFS 在未加权图中找到最短路径。 然而，顶点的数量像斐波那契数一样呈指数增长： |_D_(n)| ~ φ^n，其中 φ ≈ 1.618。 对于 n=1000，|_D_(n)| 大约是 10^208，使得任何基于邻接的方法都不可能。 BFS 的时间复杂度也令人望而却步：即使是一个查询也需要 O(|_D_(n)|)。 

关键的见解是 Doe 图具有自相似的递归结构。 每个 _D_(n) 由由两条边连接的 _D_(n-1) 和 _D_(n-2) 组成。 这使我们能够递归地计算最短路径，而无需构建图。 对于 _D_(n) 中顶点 _u_ 和 _v_ 之间的查询，我们可以确定每个顶点属于哪个子图。 如果两者都在同一个子图中，我们递归。 如果它们在不同的子图中，最短路径必须经过两个连接边之一。 我们预先计算直到 n 的所有 _D_(k) 的大小，以有效地确定边界并应用此递归计算。

 ## 算法演练

 1. 预先计算 k = 0 到 n 时所有图 _D_(k) 的大小。 让`size[k] = |D(k)|`。 使用斐波那契递推，这在 n 中是线性的：`size[k] = size[k-1] + size[k-2]`。 这使我们能够快速确定顶点属于哪个子图。 
2. 定义递归函数`dist(n, u, v)`返回顶点之间的最短距离`u`和`v`在图 _D_(n) 中。 
3. 基本情况：如果 n = 0，则图只有一个顶点，因此无法进行查询。 如果 n = 1，且 u 和 v 不同，则距离为 1。 
4. 确定 u 和 v 的位置：

 - 如果两者都 ≤ size[n-1]，则它们位于 _D_(n-1) 中。 递归与`dist(n-1, u, v)`。 
- 如果两者都 > size[n-1]，则它们位于 _D_(n-2) 中。 移位指数：`u' = u - size[n-1]`,`v' = v - size[n-1]`，并递归`dist(n-2, u', v')`。 
5. 如果 u 在 _D_(n-1) 中且 v 在 _D_(n-2) 中（反之亦然），则最短路径必须使用两条连接边之一：`(size[n-1], size[n-1]+1)`和`(size[n-1]+1, 1)`。 计算两个选项的路径长度：

 - 通过第一条边的路径：`dist(n-1, u, size[n-1]) + 1 + dist(n-2, 1, v')`- 通过第二条边的路径：`dist(n-1, u, 1) + 1 + dist(n-2, 1, v')`（根据索引进行调整）

 取两者中的最小值。 
6. 返回计算出的最小距离。 递归地应用这个直到达到基本情况。 

为什么它有效：递归反映了图的结构。 每个顶点要么完全位于两个子图之一内，要么必须穿过两个连接边之一。 这保证了算法找到最短路径，因为这两个边缘选项考虑了所有可能的最小路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(3000)

# Precompute sizes of D(k)
n_max = 1000
size = [0] * (n_max + 1)
size[0] = 1
size[1] = 2
for k in range(2, n_max + 1):
    size[k] = size[k-1] + size[k-2]

def dist(n, u, v):
    if n == 0:
        return 0  # only one vertex, no path possible
    if n == 1:
        return 1  # two vertices connected
    if u > v:
        u, v = v, u

    if v <= size[n-1]:
        return dist(n-1, u, v)
    elif u > size[n-1]:
        return dist(n-2, u - size[n-1], v - size[n-1])
    else:
        # u in D(n-1), v in D(n-2)
        d1 = dist(n-1, u, size[n-1]) + 1 + dist(n-2, 1, v - size[n-1])
        d2 = dist(n-1, u, 1) + 1 + dist(n-2, 1, v - size[n-1])
        return min(d1, d2)

t, n = map(int, input().split())
for _ in range(t):
    a, b = map(int, input().split())
    print(dist(n, a, b))
```该解决方案使用自上而下的递归方法。 这`size`数组让我们可以快速确定一个顶点是属于 _D_(n-1) 还是 _D_(n-2)。 递归通过考虑两个连接边来仔细处理跨越两个子图之间的边界。 我们将 Python 的递归限制增加到 3000，以确保安全递归高达 n = 1000。
