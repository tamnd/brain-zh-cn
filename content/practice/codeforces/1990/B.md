 ## 解决方案
 ## 问题理解

 我们需要构造一个长度的数组$n$，其中每个元素是$+1$或者$-1$。 基于前缀和和后缀和定义了两个特殊位置。 

对于前缀，我们查看所有部分和$S_i = a_1 + \dots + a_i$。 我们计算这些总和中的最大值，然后选择达到该最大值的最小索引。 该索引必须准确无误$x$。 

对于后缀，我们查看所有后缀和$T_i = a_i + \dots + a_n$。 我们计算它们的最大值，然后选择达到该最大值的最大索引。 该索引必须准确无误$y$。 

So the task is to shape the prefix-sum profile so its first peak is at$x$，并独立塑造后缀和轮廓，使其最后一个峰值位于$y$，同时仅使用$\pm1$。 

约束条件允许$n$最多$10^5$跨所有测试用例，因此任何解决方案对于每个测试用例都必须是线性的。 任何涉及所有子数组的模拟或重复重新计算总和的事情都会太慢。 

一个微妙的问题是前缀和后缀条件不是以任意方式独立的：仅满足前缀要求的简单构造很容易破坏后缀条件。 例如，将所有内容填充为$+1$直到位置$x$然后之后交替通常会使后缀最大值出现得太晚或太早，具体取决于奇偶校验。 

## 方法

 暴力方法会尝试所有$2^n$的作业$\pm1$，然后计算所有前缀和后缀总和并验证条件。 这是指数级的，即使对于小型企业来说也是不可行的。$n$。 

关键的观察是，前缀和和后缀和在以下情况下以非常结构化的方式表现单调：$\pm1$数组。 前缀和增加 1 或减少 1，因此其最大值完全由我们停止维持正漂移的位置控制。 

同样的想法也适用于后缀和，但从右侧开始。 

主要的结构见解是我们可以构建阵列，以便在位置之间有一个受控的“山”$y$和$x$。 之间$y$和$x$，我们强制执行一种模式，保证全局最大前缀恰好出现在$x$，同时确保全局最大后缀恰好出现在$y$。 

这是通过设置之间的段来实现的$y$和$x$致所有人$+1$，并放置$-1$以防止早期或以后积累更大金额的方式将其转移到外部。

 ## 算法演练

 我们直接构造数组。 

1.初始化一个数组$a$长度$n$。 我们将确定性地分配值。 
2. 地点$+1$在整个段上$[y, x]$。 这创建了一个有保证的增加区域，强制前缀和后缀最大值都通过此间隔。 
3. 对于左边的位置$y$，我们分配值，以便前缀总和永远不会超过在位置实现的值$x$。 这是通过填充它们来完成的$-1$，这可以防止早期积累。 
4. 对于以下位置$x$，我们还分配$-1$，确保从太右开始的后缀不能超过后缀最大值$y$。 
5. 输出结果数组。 

关键思想是该段$[y, x]$充当前缀和后缀总和可以达到其全局最大值的独特区域。 在该区域之外，所有贡献都是负的，确保不会出现替代最大值。 

### 为什么它有效

 区间内$[y, x]$，每一步都会增加前缀和后缀的总和，保证在该段内实现最大值。 由于外部的所有值都是$-1$, 任何之前结尾的前缀$x$严格小于前缀 at$x$，以及之后开始的任何后缀$y$严格小于后缀 at$y$。 因此最大前缀和的第一次出现正好在$x$，并且最大后缀和的最后一次出现恰好在$y$。 该结构隔离了同时强制两种条件的最大累积和的单一平台。 ∎

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())

        a = [-1] * n

        for i in range(y - 1, x):
            a[i] = 1

        print(*a)

if __name__ == "__main__":
    solve()
```该解决方案将所有内容初始化为$-1$，确保不会出现意外的早期最大值。 然后它分配$+1$在间隔上$[y, x]$，这是唯一允许增加前缀和后缀总和的区域。 

一个常见的错误是尝试单独强制执行前缀和后缀约束； 这是因为两者都依赖于全球累积结构。 这里的正确性依赖于单个连续的正块。

 ## 边缘情况

 当$x = y + 1$，正段收缩到两个相邻元素。 前缀最大值立即强制在右端点，而后缀最大值强制在左端点，并且该构造仍然有效，因为不存在竞争段。 

什么时候$y = 1$，整个前缀结构从一开始就受到控制，因此正段从第一个元素开始。 后缀条件自动满足，因为每个后缀都包含最大块。 

什么时候$x = n$，正数段延伸到数组末尾，确保后面的前缀不能超过最终的总和，因此最大前缀必然为$n$。
