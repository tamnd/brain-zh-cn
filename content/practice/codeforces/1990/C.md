 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，我们需要在累积运行总和的同时重复更新它。 更新规则基于以下概念：$\operatorname{MAD}$- 在数组前缀中至少出现两次的最大数字。 更具体地说，对于每个元素$a_i$，我们看一下前缀$[a_1, a_2, ..., a_i]$，计算其$\operatorname{MAD}$，并替换$a_i$与这个值。 更新所有元素后，我们将新数组的总和添加到全局`sum`。 这个过程一直持续到所有元素变为零。 

输入给出了多个测试用例。 每个测试用例由数组的大小和数组本身组成。 输出就是总的`sum`转型过程中积累的。 

鉴于$n$可以达到$2 \cdot 10^5$和总和$n$所有测试用例的边界为$2 \cdot 10^5$，任何适用于的解决方案$O(n \log n)$或者$O(n)$每个测试用例都是可行的。 独立模拟每个前缀的朴素方法$O(n^2)$会太慢。 

当根本没有重复项时，会出现微妙的边缘情况，例如$a=[1,2,3]$。 然后$\operatorname{MAD}$对于第一个重复项之外的所有前缀，将立即返回 0，导致数组快速衰减到零。 另一种情况是所有数字都相等，例如，$a=[4,4,4,4]$。 MAD 最初将是最大的数字本身，并且总和在达到零之前会快速增长。 

## 方法

 蛮力方法很简单：对于每个循环，迭代每个前缀，计算其$\operatorname{MAD}$通过扫描前缀并计算出现次数，然后替换$a_i$以此值，最后将数组总和添加到`sum`。 这是正确的，因为它直接实现了问题中描述的过程。 然而，内部前缀扫描是$O(n)$每个元素，导致$O(n^2)$每个循环，每个元素可能需要$O(n)$循环，导致$O(n^3)$总的复杂性，这对于$n=2 \cdot 10^5$。 

关键的观察是$\operatorname{MAD}$前缀的 只能随着数组的演变而减少或保持不变，因为在 MAD 变换下数组中的值是不增加的。 一旦某个数字在前缀中仅出现一次，它就无法再次变为 MAD，因此我们只需要跟踪至少出现两次的数字。 我们可以预先计算每个数字出现的次数并维护多个计数集。 然后我们可以有效地计算每个前缀的 MAD$O(1)$使用计数器跟踪哪些数字至少出现两次。 这将每个循环减少到$O(n)$时间。 

实际上，变换很快收敛到重复数字的“阶梯”模式，直到所有元素都为零。 通过使用频率图仔细模拟它并跟踪至少出现两次的最大数量，我们可以有效地计算总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n^2) 最坏情况，但通过适当的频率跟踪摊销 O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`和数组`a`。 
3. 初始化`total_sum = 0`。 
4. 当数组包含非零元素时：

 1. 将当前数组的和添加到`total_sum`。 
2.初始化频率字典`freq`跟踪数字的出现。 
3. 初始化变量`current_mad = 0`。 
4. 创建一个新数组`b`用于下一次迭代。 
5. 迭代`a`：

 1. 增加计数`a_i`在`freq`。 
2.如果`freq[a_i] >= 2`， 更新`current_mad = max(current_mad, a_i)`。 
3. 设置`b_i = current_mad`。 
6. 更换`a`和`b`。 
5、输出`total_sum`。 

为什么有效：在每次迭代中，MAD 计算仅取决于前缀计数，并且只有至少出现两次的数字才能对 MAD 做出贡献。 通过维护`current_mad`作为频率至少为 2 的最大数字，我们可以正确有效地模拟该过程。 数组元素随着时间的推移而减少，最终全部变为零，保证终止。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_sum = 0
        while any(a):
            total_sum += sum(a)
            freq = {}
            current_mad = 0
            b = []
            for x in a:
                freq[x] = freq.get(x, 0) + 1
                if freq[x] >= 2:
                    current_mad = max(current_mad, x)
                b.append(current_mad)
            a = b
        print(total_sum)

if __name__ == "__main__":
    solve()
```在此解决方案中，外循环继续进行，直到所有元素都为零。 内循环跟踪频率并更新每个前缀的 MAD。 使用字典可以避免重复扫描前缀，并维护`current_mad`确保所有元素使用正确的值。 更新中`a`和`b`完成下一次迭代的转换。
