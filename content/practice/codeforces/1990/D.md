 ## 解决方案
 ## 问题理解

 我们得到一个一维整数数组，其中每个整数表示网格的一行中有多少个连续单元格最初是黑色的。 更具体地说，对于大小的网格$n \times n$， 排$i$有它的第一个$a_i$细胞颜色为黑色，其余细胞$n - a_i$细胞是白色的。 我们的目标是使用两种类型的操作完全白化网格：我们可以将整行涂成白色，或者将任何行涂成白色$2 \times 2$子网格白色。 我们被要求计算所需的最少操作数。 

约束条件告诉我们$n$可以大到$2 \cdot 10^5$，以及总和$n$所有测试用例也不超过$2 \cdot 10^5$。 这立即排除了任何逐个单元检查网格或显式模拟绘制每个子网格的方法，因为这会导致$O(n^2)$操作，这太慢了。 我们必须直接使用数组$a$并找到一种依赖于黑色单元格位置模式而不是暴力网格更新的策略。 

当某些行完全白色时，会出现微妙的边缘情况（$a_i = 0$）或全黑（$a_i = n$）。 一种幼稚的方法可能会尝试$2 \times 2$到处都有子网格或绘制所有行，这可能会导致相差一的错误或不必要的操作。 例如，单行网格，其中$a_1 = 0$不需要任何操作，但粗心的实现可能会返回 1，因为它预计至少绘制一个单元格。 另一个棘手的情况是当黑色单元形成连续的对角线时 - 这些不能被完全覆盖$2 \times 2$单独的操作，因此必须明智地使用行操作。 

## 方法

 最简单的暴力策略将迭代网格中的所有黑色单元格，重复应用$2 \times 2$在存在黑色单元格的地方进行绘制，直到没有黑色单元格剩余为止。 这在原则上是正确的，因为$2 \times 2$操作可以删除任何一对相邻的黑色单元，全行绘制可以立即清除一行。 然而，在最坏的情况下$n = 2 \cdot 10^5$，每个单元可能需要单独考虑，给出复杂性$O(n^2)$，这超出了时间限制几个数量级。 

实现更快解决方案的关键见解是我们不需要考虑每个单独的黑色单元。 数组$a$已经编码了所有必要的信息：它告诉我们每行中出现了多少个黑色单元格以及它们的结束位置。 如果我们想象从右到左逐列扫描网格，每一列$j$有一些最高的行$i$这样$a_i \ge j$。 对于柱$j$，黑色单元格形成连续的垂直线段。 因为一个$2 \times 2$操作可以覆盖连续两行中任意两个相邻的黑色单元格，覆盖列中所有黑色单元格的最少操作次数$j$本质上是该列中黑色单元格数量的上限除以二。 配对后列顶部仍有剩余黑色单元的任何行必须通过行操作清除。 

我们可以通过观察操作总数等于行堆栈中黑色单元格的最大“高度”（从底部开始计数）来形式化这一点。 我们从底部行到顶部处理数组，跟踪有多少$2 \times 2$我们可以对每行应用操作，并且仅当剩余黑色单元格剩余时才使用全行操作。 这将问题简化为数组上的线性传递，这在约束范围内是可行的。

 ## 算法演练

 1. 从变量开始`res`计算操作和变量的数量`carry`跟踪前一行中剩余的黑色单元格。 最初，两者都为零。 
2. 从最后一行迭代到第一行。 对于每一行`i`，计算未覆盖的黑色单元的有效数量，即`max(a[i] - carry, 0)`。 这表示当前行中尚未属于行的黑色单元格$2 \times 2$从下面的行开始。 
3.数量$2 \times 2$我们可以在这一行执行的操作是`effective // 2`。 将其添加到`res`。 
4. 任何无法配对的剩余黑色电池（即，如果`effective`是奇数）被结转到上面的行。 更新`carry`到`effective % 2`。 
5. 处理完所有行后，如果`carry`仍然是 1，这意味着顶行有一个不匹配的黑色单元格。 应用最后一个操作来清除它，递增`res`一个。 
6. 输出`res`。 

这是有效的，因为我们贪婪地使用连续行中的黑色单元格进行配对$2 \times 2$尽可能进行操作，并且仅在剩余单个剩余单元格时才采用全行操作。 不变的是，处理完每一行后，没有$2 \times 2$操作可以覆盖比计数更多的黑色单元格，并且`carry`正确跟踪任何未配对的黑色单元格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    res = 0
    carry = 0
    for i in reversed(range(n)):
        effective = max(a[i] - carry, 0)
        res += effective // 2
        carry = effective % 2
    if carry:
        res += 1
    print(res)
```循环从下到上迭代，因为$2 \times 2$操作影响当前行和下一行。`effective`确保我们不会过多计算已覆盖的黑色单元格。 使用`carry`简化了剩余单元格的跟踪，无需单独扫描列。 最终检查为`carry`处理顶行有一个单独的黑色单元格的边缘情况。
