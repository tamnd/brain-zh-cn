 ## 解决方案
 ## 问题理解

 我们需要构造一组整数，每个整数最多使用`s`位，这样如果我们对集合的每个非空子集进行按位与，则精确地`k`出现不同的值。 该集合本身就是输出，因此我们可以自由选择满足不同子集与结果所需数量的任何数字。 

例如，使用集合`{9, 6, 10}`，单例子集给出`9`,`6`， 和`10`。 一些较大的子集给出`9 & 10 = 8`,`10 & 6 = 2`， 和`9 & 6 = 0`。 因此，结果值的集合是`{0, 2, 6, 8, 9, 10}`，其中包含六个值。 官方示例正是使用了这种结构。 

关键的困难在于一组大小的非空子集的数量`n`是`2^n - 1`。 输出本身最多限制为`125`数字，因此直接枚举每个子集可能需要最多`2^125 - 1`， 大致`4.25 * 10^37`, 与运算。 即使每次操作的成本都非常低，但这也远远超出了三秒限制所能支持的范围。 评分约束允许`k`达到顺序`2^20`，因此该构造必须在其表示答案的数量上呈指数增长，而无需明确枚举这些答案。 

有一些边缘情况很容易破坏粗心的结构。 第一的，`k = 1`仅需要一个不同的 AND 值。 套装`{0}`有效，因为它唯一的非空子集 AND 等于`0`。 假设必须创建正值的构造可能会不必要地消耗比特或错误处理基本情况。 

其次，一个奇怪的目标，例如`k = 3`必须在构造之上创建一个新的 AND 值`2`。 例如，`{1, 0, 3}`产生不同的值`1`,`0`， 和`3`。 简单地在构造中附加零`2`除非先对现有结构进行改造，否则不一定会按要求的方式增加答案。 

第三，二的幂是位数的边界情况。 为了`k = 4`, 集合`{3, 2, 1}`准确地产生`0, 1, 2, 3`，四个不同的值。 在此阶段意外激活一位附加位的结构可能会产生需要比所需更多位的数字。 

最后，提供的位限制`s`是每个构造数字的硬上限。 如果数学上正确的集合之一的值达到`2^s`或更多。 下面的构造仅在需要增加不同 AND 值的数量时才引入一个新位，并且该问题保证了所请求的`k`和`s`承认一个答案。 

## 方法

 暴力方法首先选择一些数字集并枚举每个非空子集。 对于每个子集，我们计算其 AND 并将结果插入到一组不同的值中。 这是正确的，因为该问题精确地要求所有非空子集生成的不同 AND 值的数量。 

问题是`2^n - 1`子集。 最大允许输出尺寸为`125`， 这意味着`2^125 - 1`子集，大约`4.25 * 10^37`。 搜索可能的集合甚至更糟，因此暴力破解并不是一种现实的构建策略。 

关键的观察是我们不需要独立控制每个子集。 我们可以构造一个集合，同时保持其位的非常强的不变量。 假设每个当前数字仅使用较低的`b`位。 然后每个当前子集也只使用那些`b`位。 这给了我们一个完全未使用的位`b`。 

该未使用的位可以分隔两组子集 AND。 如果我们将该新位放入每个现有数字中，则每个旧子集都会获得新位集。 然后我们添加一个新数字，该数字的新位为零，旧位全部为 1。 不包含新数字的子集保留新位设置，而包含新数字的子集则清除新位。 两组不能重叠，因此不同结果的数量加倍。 

我们还可以将不同结果的数量恰好增加 1。 保留一个新位后，将所有由该位组成的数字相加。 它的单例 AND 是一个新值，而将其与任何先前的子集进行 AND 运算时，先前的子集保持不变，因为新数字在每个先前使用的位置中都包含 1。 

这为我们提供了对不同答案数量的两种操作：将其增加一或加倍。 目标`k`可以从构建`1`正是使用这些操作，遵循二进制结构`k`。 官方社论正是使用了这个不变量和这两个构造操作。 

从一个答案开始，我们递归地减少一个奇数`k`到`k - 1`，因为添加一个很容易。 对于一个均匀的`k`，我们递归地求解`k / 2`，然后进行加倍运算。 由于反复减半达到`1`很快，仅`O(log k)`需要建设水平。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(2^n)`子集评估 |`O(2^n)`在最坏的情况下| 太慢了|
 | 最佳 |`O(log^2 k)`|`O(log k)`| 已接受 |

 ## 算法演练

 1. 开始于`k = 1`和集合`{0}`。 恰好存在一个非空子集，因此恰好存在一个不同的 AND 值。 我们还维护`bit`，下一个可用于构造的位位置。 
2. 如果当前目标`k`是奇数且大于一，首先构造一个集合`k - 1`。 然后，我们移动到一个新位，并在迄今为止使用的每个位（包括新位）中附加一个包含 1 的数字。 这个数字本身恰好创建了一个新的 AND 值。 将其与任何旧子集进行“与”操作不会更改该子集的结果，因为所有先前相关的位在新数字中都是一。 
3. 如果当前目标`k`是偶数，首先构造一个集合，其不同结果的数量为`k / 2`。 让`bit`是第一个未使用的位。 在每个现有数字中设置该位。 
4. 附加一个新数字，其较低者`bit`位全为 1，新位为零。 从数字上看，这个数字是`(1 << bit) - 1`。 
5. 考虑不包含新添加的数字的子集。 它的 AND 具有新的位集，并且它的低位正是由相应的旧子集产生的 AND。 因此这些子集产生`k / 2`具有新位设置的组中的值。 
6. 现在考虑包含新数字的子集。 它的新位变为零，而较低位保持不变，因为新数字在这些位置处都有 1。 这些给了另一个`k / 2`值，现在新位被清除。 
7. 两组不能包含相同的整数，因为一组设置了新位，另一组将其清除。 因此，不同 AND 值的数量恰好变为`k`。 
8. 递归重复，直到达到`k = 1`，然后返回构造的数字。 递归深度只是对数，因为每个偶数目标都会除以二，而每个大于一的奇数目标都会减一，然后最终达到偶数值。 

不变的是构建目标之后`k`，所有生成的子集 AND 值均由当前结构表示，并且所有数字仅使用已引入的位。 这`+1`运算恰好添加一个新值，而加倍运算则为每个旧 AND 值创建两个不相交的副本。 由于这些操作改变了不同结果的数量`x`到`x + 1`或者`2x`准确地说，按照递归分解`k`保证最终的集合准确无误`k`不同的子集与值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build(k):
    if k == 1:
        return [0], 0

    if k & 1:
        result, bit = build(k - 1)

        # Reserve a fresh bit and add a number having
        # all currently relevant bits set.
        bit += 1
        result.append((1 << bit) - 1)

        return result, bit

    result, bit = build(k // 2)

    # Put the fresh bit into every old number.
    mask = 1 << bit
    for i in range(len(result)):
        result[i] |= mask

    # The new number has the fresh bit cleared and
    # every older bit set.
    result.append(mask - 1)

    bit += 1
    return result, bit

def solve():
    k, s = map(int, input().split())

    result, _ = build(k)

    print(len(result))
    print(*result)

if __name__ == "__main__":
    solve()
```递归`build`函数是两个构造规则的直接实现。 基本情况返回`{0}`，它有一个不同的子集 AND。 

对于一个奇怪的`k`，递归调用创建`k - 1`价值观。 我们增加位计数器并追加`(1 << bit) - 1`。 由于所有先前构造的数字都使用较低位，因此该附加值大于每个旧子集 AND，因此恰好贡献了一个新结果。 

对于一个均匀的`k`，递归调用创建`k / 2`价值观。 表达式`1 << bit`标识当前未使用的位，并将其与每个现有数字进行“或”运算，将该位放入每个旧子集“与”中。 所附的`mask - 1`已设置所有旧位，但清除新位。 因此，旧子集和包含新数字的子集由新位分隔。 

Python 整数具有任意精度，因此不存在整数溢出问题。 唯一相关的边界是问题的`s`位限制。 该构造仅使用递归期间引入的新位，并且该问题保证了所请求的足够可用位`k`。 

递归深度很小，受位数的限制`k`，因此对于规定的约束，Python 的递归限制并未达到。

## 测试用例

 输出不是唯一的，因此测试助手验证生成的集合，而不是将其与一个固定序列进行比较。 它检查输出大小，`s`位限制，集合元素的唯一性，并且对于小情况，直接枚举每个非空子集以验证不同 AND 结果的确切数量。```python
import sys
import io

def build(k):
    if k == 1:
        return [0], 0

    if k & 1:
        result, bit = build(k - 1)
        bit += 1
        result.append((1 << bit) - 1)
        return result, bit

    result, bit = build(k // 2)

    mask = 1 << bit
    for i in range(len(result)):
        result[i] |= mask

    result.append(mask - 1)
    bit += 1
    return result, bit

def solve_case(inp):
    data = inp.split()
    k = int(data[0])
    s = int(data[1])

    result, _ = build(k)

    return str(len(result)) + "\n" + " ".join(map(str, result)) + "\n"

def run(inp: str) -> str:
    return solve_case(inp)

def validate(inp: str, out: str):
    k, s = map(int, inp.split())

    data = list(map(int, out.split()))
    assert data, "empty output"

    n = data[0]
    a = data[1:]

    assert n == len(a), "wrong number of printed values"
    assert 1 <= n <= 125, "invalid set size"
    assert len(set(a)) == n, "the output must be a set"
    assert all(0 <= x < (1 << s) for x in a), "number does not fit in s bits"

    if n <= 20:
        values = set()

        for mask in range(1, 1 << n):
            cur = (1 << s) - 1
            for i in range(n):
                if mask & (1 << i):
                    cur &= a[i]
            values.add(cur)

        assert len(values) == k, (
            f"expected {k} distinct AND values, got {len(values)}"
        )

# Small power of two

# Odd target, exercises the +1 construction

# all subsets would be exponential.
case5 = "1048576 20"
validate(case5, run(case5))

 ## 边缘情况

 对于`k = 1`，确切的输入是`1 1`。 算法立即到达基本情况并返回`{0}`。 只有一个非空子集，包含单个数字`0`，所以唯一的 AND 结果是`0`。 因此，输出是一个数字，并且只有一个不同的结果。 

对于奇数目标`k = 3`， 考虑`3 2`。 该算法首先构造答案`2`, 给予`{1, 0}`。 然后它移动到下一位并附加`3`，生产`{1, 0, 3}`。 单身人士`3`是一个新的结果，而`3 & 1 = 1`和`3 & 0 = 0`，因此不会出现其他新值。 不同的结果正是`{0, 1, 3}`，给出所需的输出计数`3`。 

对于二次方边界`k = 4`， 考虑`4 2`。 该建筑给出了`{3, 2, 1}`。 它的子集 AND 值是`3`,`2`,`1`,`2`,`1`,`0`， 和`0`，所以不同的结果正是`{0, 1, 2, 3}`。 每个值都适合两位。 这说明了为什么加倍操作必须通过新引入的位来区分子集。 

为了最大目标`k = 2^20`，递归过程完全由加倍运算组成。 每次加倍都会引入一个新位，并使构造元素的数量保持较小。 结果数字仍然低于`2^20`，所以它们适合`20`位。 因此，该构造达到了评分约束的最大目标，而无需枚举其指数级多个子集中的任何一个。 

对于类似的建设性问题，最有用的不变量是新的位可以充当分隔符。 如果每个旧结果都得到该位设置，并且涉及专门选择的新元素的每个结果都被清除，则两个以前相同的结果集合将变得不相交。 一旦这个想法被认识到，将可达到的状态数量加倍就变成了简单的按位构造，而不是指数搜索。
