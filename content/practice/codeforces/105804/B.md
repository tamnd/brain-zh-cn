 ## 解决方案
 ## 问题理解

 我们得到一个无向连通图，表示由双向道路连接的城镇。 每条道路连接两个不同的城镇，整个网络最初是连接的，因此任何一对城镇之间的旅行都是可能的。 

任务是用定向系统取代该系统。 每条现有道路都必须指定一个方向，如果需要，我们还可以添加新的有向道路。 完成此操作后，生成的有向图必须保持强连接，这意味着我们必须能够从每个城镇沿着有向边到达每个其他城镇。 

我们的目标是尽量减少我们添加的新道路数量，同时我们可以根据自己的意愿自由调整现有道路的方向。 由于给出了多个测试用例，我们必须为每个图独立计算这个最小值。 

驱动该解决方案的关键约束是所有测试用例的边总数最多为 200,000。 这排除了任何在二次时间内重新计算连通性或对每条边执行繁重图算法的解决方案。 每个测试用例 O(n + m) 左右的任何内容都是安全的，但重复多次 O(m log m) 仍然是可以接受的。 任何尝试重复模拟方向或重新计算可达性的操作都会超时。 

一个微妙的极端情况来自已经“几乎是树”的图。 如果图是一棵树，那么无论我们如何定向边，我们都无法获得覆盖所有节点的有向循环。 一种幼稚的方法可能会尝试任意定向边缘，并假设可以在本地固定强连通性，但树从根本上缺乏循环，因此额外的边缘是不可避免的。 

当图已经是 2 边连接但不是 2 顶点连接时，会出现另一种失败情况。 一些依赖局部度或生成树方向的幼稚策略会错过关节点，除非我们添加额外的边，否则会破坏强大的连接性。 

## 方法

 强力解释是尝试给定无向边的所有可能方向，然后检查生成的有向图是否强连通。 对于每个有效的方向，我们将计算需要多少额外的边来修复连接间隙。 这立即变得不可行，因为 m 个边中的每一个都有两个选择，导致 2^m 个配置。 即使 m = 20，这也已经爆炸了，这里 m 达到 200,000。 

关键的观察是，我们并不是任意意义上的真正自由。 有向图中的强连通性可以在结构上表征：每个有向图都可以压缩为强连通分量，并且凝结图是有向无环图。 为了使整个图强连接，我们需要消除这个 DAG 结构中的源和汇。 

关键的简化是我们可以优化边缘的方向。 这意味着我们可以选择一个方向，以最大限度地减少定向后 SCC 源和汇的数量。 经典的结果是，在任何连接的无向图中，我们可以对边进行定向，使得生成的有向图具有这样的结构，其中需要外部连接的组件的数量减少为铰接结构和桥的函数。 事实上，在最优定向之后，使图强连接所需的最小边数取决于 DFS 树分解中出现多少个“不平衡”组件。 

关键的见解是建立 DFS 树的根并将每个树边缘向下定向，同时仔细处理后边缘。 这会产生一个有向结构，其 SCC 凝结与原始图中的桥密切对应。 每个桥有效地将图分成在两个方向上都无法相互到达的部分。 每一个这样的“单向瓶颈”都迫使我们添加一个额外的有向边来恢复双向可达性。

因此，我们不是搜索方向，而是使用 DFS 计算桥梁结构。 一旦识别出桥，我们就在概念上将图压缩成桥树。 一棵有 k 个叶子的树需要 ceil(leaf_count / 2) 条额外的边来使其强连接，因为每条添加的边都可以配对两个叶子，并消除压缩树中的两个 1 度要求。 

整个问题简化为：找到所有桥，构建桥树，计算该树中有多少个节点的度数为 1，并计算需要多少条边来将它们配对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力方向 | O(2^m) | O(2^m) | O(n + m) | 太慢了|
 | DFS+桥分解 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 为图构建邻接表，同时跟踪边索引，以便我们可以区分平行遍历方向。 这是必要的，因为我们需要使用 DFS 来识别桥。 
2. 运行 DFS 来计算发现时间和低链路值。 在遍历过程中，对于每个树边，我们将低链接信息从子节点传播回父节点。 当子级的最低可达祖先严格大于父级的发现时间时，就会识别出桥。 此条件捕获了删除该边会断开图的事实。 
3. 找到所有桥后，将原始图视为“压缩结构”，其中每个非桥边将其端点保留在同一组件中，而桥则定义组件之间的连接。 
4. 通过仅计算与桥相关的节点的度数来构建概念桥树。 桥的每个端点在这棵树中贡献一个度数。 
5. 计算该桥树中有多少个节点的度数为 1。这些节点对应于结构“末端”且无法对称到达其他部分的组件。 
6. 答案是此类叶子数量的一半，四舍五入。 每个添加的有向边缘可以连接两片叶子，同时固定它们。 

### 为什么它有效

 基于 DFS 的桥分解准确地识别了在任何方向上强制执行单向遍历约束的边。 任何这样的边都会在两个最大 2 边连接组件之间产生瓶颈。 将这些组件收缩后，剩下的结构就是一棵树。 在有向树状结构中，强连接性要求每个节点都具有传入和传出可达路径，这意味着消除压缩树中的叶子。 每条添加的边都可以通过在两个叶子之间创建循环来消除它们，因此最佳策略是对叶子进行配对，从而得出公式 ceil(L / 2)。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    
    edges = []
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, i))
        g[v].append((u, i))
        edges.append((u, v))
    
    tin = [-1] * n
    low = [0] * n
    timer = 0
    is_bridge = [False] * m

    def dfs(v, pe):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        
        for to, ei in g[v]:
            if ei == pe:
                continue
            if tin[to] == -1:
                dfs(to, ei)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    is_bridge[ei] = True
            else:
                low[v] = min(low[v], tin[to])

    dfs(0, -1)

    comp_deg = [0] * n

    for i, (u, v) in enumerate(edges):
        if is_bridge[i]:
            comp_deg[u] += 1
            comp_deg[v] += 1

    leaves = 0
    for i in range(n):
        if comp_deg[i] == 1:
            leaves += 1

    if m == 0:
        print(0)
    else:
        print((leaves + 1) // 2)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```DFS 是标准的低链路计算。 唯一微妙的部分是确保边缘不会与回溯到父边缘相混淆，这是使用边缘索引而不仅仅是父节点来处理的。 识别桥之后，我们完全忽略非桥边缘，因为它们在最佳方向后位于强连接组件内。 

叶子计数步骤假设每个桥端点都对桥树的度有所贡献。 如果一个节点恰好与一座桥相关，那么它的行为就像收缩结构中的一片叶子。 

最终公式`(leaves + 1) // 2`最佳配对端点。 

## 工作示例

 考虑一个简单的三角图，其中每个节点都连接到每个其他节点。 没有边缘是桥梁。 

| 步骤| 桥梁| 度（桥树）| 叶子|
 | --- | --- | --- | --- |
 | 初始| 无 | 全部 0 | 0 |

 没有叶子，所以答案变成 0。这符合直觉，因为我们可以循环定向三角形并且已经获得了很强的连通性。 

现在考虑折线图 1-2-3-4。 

| 步骤| 桥梁| 度| 叶子|
 | --- | --- | --- | --- |
 | 边缘 1-2 | 是的 | 1,1 | 2 |
 | 边缘 2-3 | 是的 | 2,2 | |
 | 边缘 3-4 | 是的 | 1,1 | 2 |

 这里所有的边都是桥，所以桥树中每个内部节点的度数都是 2，而端点 1 和 4 的度数都是 1。叶子 = 2，所以答案是 (2+1)//2 = 1。 

这对应于添加连接链端点的单个有向边，在定向后将结构转变为循环。

 ## 边缘情况

 已经是循环的图没有桥。 在这种情况下，DFS 不会将任何边缘标记为关键，因此桥结构中的每个度数都为零。 叶子计数变为零，算法输出为零，这与我们可以一致地定向循环的事实相匹配。 

纯树是最敏感的情况，因为每条边都是一座桥。 DFS 标记所有边，桥树与原始树相同。 叶子与树叶完全对应。 配对公式确保我们添加足够的边来关闭叶子之间的循环，并且每个内部顶点都已经很好，因为一旦引入循环，它就通过其子节点具有传入和传出路径。 

星形图产生大量等于 n − 1 的叶子。该算法将它们贪婪地以两个为一组进行配对，大约产生 (n − 1)/2 个附加边。 这符合这样的直觉：每条添加的边一次只能固定单向分离的两个端点。
