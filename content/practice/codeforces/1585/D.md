 ## 解决方案
 ## 问题理解

 我们被要求确定是否可以仅使用称为 3 周期的操作对整数数组进行排序。 3 循环选择三个不同的索引并在它们之间轮换元素。 例如，如果我们的数组是`[a, b, c, d]`我们选择指数`1, 2, 3`，3个周期后数组变成`[c, a, b, d]`。 任务不是显式地对数组进行排序，而只是决定是否可以以这种方式对其进行排序。 

输入由多个测试用例组成。 每个测试用例都给出数组的大小和数组本身。 数组中的每个整数都在 1 到 n 之间。 由于 n 可以高达 500,000，并且所有测试用例的总和也是 500,000，因此我们需要一种线性或接近线性的方法。 任何模拟所有可能的 3 周期序列的解决方案都是组合的，并且在这些约束下是不可能的。 

排列奇偶性中出现了微妙的边缘情况。 3循环是排列论意义上的奇排列：它可以分解为偶数个相邻交换。 这意味着并非所有排列都可以单独使用 3 循环进行排序。 例如，`[2, 1]`不可能，因为交换两个元素需要 2 个周期，而不能表示为单个 3 个周期。 具有重复元素的数组，例如`[2, 2]`，是可简单排序的，因为交换相同的数字没有效果并且数组已经排序。 

## 方法

 蛮力方法是尝试 3 周期的所有序列。 对于大小为 n 的数组，3 循环的数量约为 n3，并且序列的数量呈指数增长。 对于 n 达到 500,000 的情况，这显然是不可行的。 即使尝试使用 3 循环贪婪地将每个元素移动到其排序位置也会很混乱，因为 3 循环只能旋转三个元素，并且某些配置无法通过任何组合来解决。 

关键的见解是查看排序引起的索引排列。 如果我们对位置进行编号`1..n`并考虑每个元素必须去哪里才能实现排序数组，我们得到位置的排列。 那么问题就归结为置换论的问题：这个置换能否表示为3个循环的乘积？ 这相当于询问排列是否是偶排列。 对于具有不同元素的数组，除了简单的两元素交换之外，任何排列都可以表示为 3 周期的乘积。 重复的元素使其变得更容易，因为交换相同的元素可以有效地取消奇数奇偶校验，从而允许对所有具有重复项的数组进行排序。 

因此，最佳方法是：

 1. 计算重复项。 如果至少有一个重复项，则答案始终为“是”。 
2. 否则，计算排序引起的排列的奇偶校验。 如果排列是偶数，则可以表示为3循环； 如果是奇数，则不能。 偶数返回 YES，奇数返回 NO。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n3) | O(n! * n3) | O(n) | 太慢了 |
 | 排列奇偶校验 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 对于每个测试用例，读取 n 和数组 a。 
2. 检查 a 中的任何值是否出现多次。 如果是，则立即输出YES。 重复元素允许我们通过交换重复项来修复任何奇怪的排列。 
3. 如果所有元素都不同，则计算对数组进行排序所需的排列。 这是通过将每个元素与其索引配对、按值对对进行排序并记录原始索引的新位置来完成的。 
4. 计算该排列的奇偶校验。 初始化一个大小为 n 的访问数组来标记哪些位置已被处理。 对于每个未访问过的位置，遵循它形成的循环，直到返回到起点。 计算每个周期的长度； 长度为 k 的循环贡献 k-1 次换位。 对所有循环求和以确定换位总数。 
5、如果换位总数为偶数，则输出YES； 否则输出NO。 

为什么有效：该算法利用了任何排列都可以分解为循环的事实。 排列的奇偶性（换位的偶数或奇数）决定了它是否可以表示为 3 个循环的乘积。 重复元素允许调整奇偶校验，使所有具有重复项的数组都可排序。 通过显式地计算循环和换位，我们确定排序是否可行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if len(set(a)) < n:
            print("YES")
            continue
        
        # Compute permutation
        b = sorted((val, i) for i, val in enumerate(a))
        p = [0] * n
        for idx, (_, original_idx) in enumerate(b):
            p[original_idx] = idx
        
        # Count transpositions to compute parity
        visited = [False] * n
        transpositions = 0
        for i in range(n):
            if not visited[i]:
                cycle_len = 0
                j = i
                while not visited[j]:
                    visited[j] = True
                    j = p[j]
                    cycle_len += 1
                transpositions += cycle_len - 1
        
        print("YES" if transpositions % 2 == 0 else "NO")

if __name__ == "__main__":
    solve()
```该解决方案首先处理重复项，这立即保证了可排序性。 对于不同的元素，排列数组将当前索引映射到它们的排序位置。 通过访问此排列中的每个循环，我们计算需要多少次转置。 每个长度为 k 的循环需要 k-1 次换位。 这些转置之和给出了排列奇偶性。

这些示例表明循环计数方法可以正确确定可排序性。

 ## 边缘情况

 对于`[2, 1]`，所有元素都是不同的并且排列`(2 1)`是单次转置，奇校验。 算法标记visited[0]，循环到1，回到0，计算转置=1→输出NO。 为了`[2, 2]`，存在重复项，因此算法立即输出 YES，无需计算奇偶校验。 这演示了最小大小数组和重复边缘情况的处理。
