 ## 解决方案
 ## 问题理解

 每个大于 1 的自然数都被分配一个“友元”，定义为它的最大真因数，意味着严格小于它但仍能整除它的最大数。 例如，6的真因数是1、2、3，它的友元是3。 

任务是考虑从 2 到 n 的所有数字，计算每个数字的友元，并对所有这些值求和。 

因此，输入是单个整数 n，输出是 2 到 n 中每个整数的最大真因数之和。 

该约束达到大约一千万，这就排除了对每个数字天真地重新计算除数的情况。 在最坏的情况下，对每个整数进行简单的除数扫描大约需要 O(n√n) 次操作，这太慢了。 即使是 O(n log n) 的解决方案也必须仔细实施以保持在时间限制内。 

素数周围出现微妙的边缘情况。 对于素数 p，最大真因数始终为 1。对于像 p² 这样的数字，答案是 p，而不是 p² / 2 或某种近似值。 另一种边缘情况是 n = 2 或 n = 3，其中仅存在少数项且总和很小，因此循环边界中的任何差一错误都会立即显示出来。 

例如，如果 n = 6，则值为：

 2 → 1

 3 → 1

 4 → 2

 5 → 1

 6 → 3

 总和 = 8

 错误地指定“除 1 以外的最小除数”而不是“最大真除数”的幼稚方法会错误地为 6 给出 2，而不是 3。 

## 方法

 蛮力方法是独立计算每个数字的最大真因数。 对于固定的 x，我们可以扫描最多 x/2 或最多 √x 的所有除数并跟踪最大的有效除数。 即使使用 √x 扫描，这也会导致大约

 n × √n 运算，当 n = 10⁷ 时，其步数约为 10^10，远远超出了限制。 

关键的结构观察是，一个数的“朋友”是由它的最小非平凡因子以相反的方式确定的：如果我们知道 x 的除数 d，那么 x 对答案有贡献 d，但前提是 d 是 x 的最大真因数。 通过翻转视角，可以更有效地重新表述这一点：我们不是问“对于每个 x，它的最佳除数是什么”，而是问“对于每个可能的除数 d，它会成为哪些数字的最大真因数？”

 当 x = d × k 并且 k 是大于 1 的最小可能因子时，除数 d 恰好成为 x 的最大真因数。这意味着 k 必须是 k 的倍数结构中的最小质因数。 这自然会导致类似筛子的结构：对于每个数字 i，我们将 i 作为其倍数的候选答案传播，其中它是最大真因数。 

实现这一点的简洁方法是使用类似于埃拉托斯特尼筛法的筛子，但我们不标记素数，而是仅当 i 是迄今为止低于 j 的最大除数时，才为 i 的每个倍数 j 分配值 i。 如果我们从 1 向上迭代 i，那么每当我们将 i 分配给倍数时，后面更大的除数就会覆盖它，保证最终存储的值是最大的真除数。 

由于筛子中的谐波级数行为，这将问题减少到大约 n log n 次运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（每个数字除数扫描）| O(n√n) | O(n√n) | O(1) | O(1) | 太慢了 |
 | 除数的筛传播 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 创建数组`best`大小为 n+1，初始化为 0。该数组将存储为每个数字找到的最大真除数。 
2. 将 i 从 1 迭代到 n。 值 i 被视为其倍数的候选除数。 
3. 对于每个倍数 j = 2i, 3i, 4i, … 直到 n，分配`best[j] = i`。 由于我们向上移动 i ，较大的 i 值会覆盖较小的值。 
4. 筛完后，将所有值相加`best[2] + best[3] + ... + best[n]`并输出结果。 

我们从 2i 开始标记的原因是，一个数不是它自己的真约数，所以 i 不能对 i 本身做出贡献。 

### 为什么它有效

 当我们处理一个值 i 时，每个倍数 j = i × k 都被分配 i 作为候选除数。 稍后，当我们达到一个更大的除数 d 也能整除 j 时，d 将覆盖 i。 因为我们按升序迭代 i，所以每个 j 的最后一个赋值对应于小于 j 的最大除数。 这正是最大真因数的定义。 

这创建了一个单调覆盖不变量：`best[j]`始终保存遍历中到目前为止遇到的 j 的最大除数，并且由于最终会遇到所有除数，因此最终值是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    best = [0] * (n + 1)

    for i in range(1, n + 1):
        for j in range(2 * i, n + 1, i):
            best[j] = i

    ans = sum(best[2:])
    print(ans)

if __name__ == "__main__":
    solve()
```外循环迭代所有可能的除数候选。 内部循环遍历倍数，确保每个数字接收来自其所有除数的更新。 关键的实现细节是从`2 * i`，这可以防止自分配。 

总和从索引 2 开始，因为数字 1 不是问题域的一部分。

 ## 边缘情况

 对于 n = 2，只有数字 2 起作用，其最大真因数为 1。该算法在 i = 1 期间将 best[2] 初始化为 1，并且后面的值不会覆盖它，因此输出是正确的。 

对于素数范围，每个素数 p 只能从 i = 1 开始分配，因此 best[p] 保持为 1。筛子不会错误地覆盖素数，因为没有 i > 1 可以整除它们。 

对于像 36 这样的完全平方数，正确的值为 18。在扫描期间，i = 18 将覆盖 36 之前所有较小的除数，并且由于不存在低于 36 的更大的真除数，因此它作为最终值保持稳定。
