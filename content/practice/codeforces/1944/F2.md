 ## 解决方案
 ## 问题理解

 我们被要求计算数组的长度`n`之间有元素`0`和`k`可以使用特定操作将其减少到全零。 该操作允许选择两个不同的索引`l`和`r`并从之间的所有元素中减去 1`l`和`r`包容性。 “好”数组是指重复应用此操作可以将所有元素归零的数组。 

该问题是组合问题，因为数组的总数是`(k+1)^n`。 测试每个阵列的强力方法是不切实际的。 限制条件表明`n`最多可达 3000 并且`k`最多`n`。 总结所有测试用例，`n^2`不超过 10^7，这暗示`O(n^2)`每个测试用例的算法都是可行的。 模数`p`是大且素数，这意味着模逆可以在计算中安全地使用。 

理解数组“好”的原因是一个微妙的问题。 如果我们解释该操作，它可以减少不在段边缘的任何元素，但该段中至少需要存在两个元素才能使操作有效。 因此，长度的数组`n < 3`行为不同，最大元素出现在边界的数组可能会很棘手。 例如，`[1,0,1]`很好，因为从索引 1 到 3 减去两次得到`[0,0,0]`。 粗心的方法可能会计算无法沿着数组正确传播归约的数组，例如`[1,0,2]`，同样好。 

任务是计算好数组的数量模`p`有效地处理多个测试用例。 

## 方法

 天真的方法是生成所有`(k+1)^n`数组，然后模拟操作来检查每个数组是否可以归零。 这是有效的，因为操作是确定性的。 然而，数组的总数呈指数增长； 为了`n=3000`和`k=3000`，这是完全不可行的，远远超过了任何合理的操作次数。 

关键的见解是该操作相当于添加`1`到相反的类似前缀和的结构。 将该操作视为从段中减 1：其累积效果可以表示为连续元素之间的差异。 更正式地说，我们可以将每个数组视为定义一个“差异数组”`d[i] = b[i] - b[i-1]`。 该操作允许从长度至少为 2 的任何连续子序列中减 1。可以减少到零的数组是那些最大元素不会阻止这些减量在数组中传播的数组。 

这个问题结构允许我们使用动态规划来解决它所应用的步数和每个前缀的当前最大值。 DP状态`dp[i][j]`可以解释为长度良好的序列的数量`i`具有最大元素`j`。 递归依赖于这样一个事实：与之前的元素相比，向数组中添加新元素只会使最大值最多增加 1，并且该操作确保约简可以传播。 

这导致`O(n^2)`动态规划解决方案。 对于每个长度`i`，我们迭代可能的最大值`j`并使用累积和来有效地更新转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((k+1)^n * n) | O((k+1)^n * n) | O(n) | 太慢了 |
 | 动态规划| 每个测试用例 O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘和模逆`2*n`使用模数`p`。 这是有效的二项式系数计算所必需的。 阶乘有助于使用模逆在恒定时间内计算组合。 
2.对于每个测试用例，初始化一个DP数组`dp[i][j]`表示长度良好的数组的数量`i`恰好与最大元素`j`。 初始化`dp[1][x] = 1`为所有人`0 <= x <= k`因为单元素数组非常好。 
3. 迭代长度`2`到`n`。 对于每个长度`i`，维护一个前缀和数组`prefix[j]`先前长度的 DP 值。 这允许有效计算附加新元素的方式数量，而无需每次重新计算总和。 
4. 对于每个潜在的最大值`j`终于`i`，好的数组的数量是前一个长度的数组的总和，其中最大值不超过`j`。 这确保添加具有值的元素`j`保持递减可以传播的属性。 
5. 始终使用模运算来防止溢出并遵守模数`p`。 
6. 总和`dp[n][j]`为了`0 <= j <= k`获取长度良好数组的总数`n`和最大元素`k`。 
7. 打印每个测试用例的结果。 

这样做的原因是 DP 不变量保证对于数组的任何前缀，都会跟踪最大元素，并且所有计数的数组都可以传播递减以将所有元素减少到零。 转换仅考虑前缀和新元素的有效组合，确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = None
MAXN = 0
fact = []
invfact = []

def modinv(x):
    return pow(x, MOD - 2, MOD)

def precompute_factorials(n):
    global fact, invfact
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i-1] * i % MOD
    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i-1] = invfact[i] * i % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def solve_case(n, k, p):
    global MOD, MAXN
    MOD = p
    MAXN = n
    precompute_factorials(2*n)
    dp = [0] * (k + 1)
    for j in range(k + 1):
        dp[j] = 1
    for i in range(2, n + 1):
        new_dp = [0] * (k + 1)
        prefix = [0] * (k + 2)
        for j in range(k + 1):
            prefix[j+1] = (prefix[j] + dp[j]) % MOD
        for j in range(k + 1):
            new_dp[j] = prefix[j+1] % MOD
        dp = new_dp
    return sum(dp) % MOD

t = int(input())
for _ in range(t):
    n, k, p = map(int, input().split())
    print(solve_case(n, k, p))
```在此实现中，阶乘预计算允许有效使用组合计数，而 DP 通过最大元素跟踪有效数组。 前缀总和避免了重新计算每个潜在最大值的总和。 模运算确保大素数下的正确性。
