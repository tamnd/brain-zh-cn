 ## 解决方案
 ## 问题理解

 Dima 有固定数量的可供运输的仓鼠，以及一系列类型的盒子，每种类型都有不同的容量。 使用的每个盒子必须完全装满，并且所有选择的盒子必须是单一类型，因为购买混合类型会消除折扣。 

所以决定是：从列表中选择一个容量值，假设它成立`a`每盒仓鼠，然后使用可用的材料尽可能多地包装该尺寸的整盒`N`仓鼠。 任何无法放入完整盒子的剩余仓鼠都会被留下，对结果没有贡献。 

对于选定的容量`a`，可用盒子的数量为`N // a`，运输的仓鼠数量为`a * (N // a)`。 目标是选择使运输总量最大化的索引。 

限制条件非常大：`N`最大可达10^18，每个容量也可达10^18，而类型数量可达10万种。 这立即排除了任何试图模拟包装或单独迭代仓鼠或盒子的方法。 即使对容量进行二次推理也是不可能的。 唯一可行的方向是在恒定时间内独立评估每种类型。 

一些边缘情况值得关注。 什么时候`N = 0`，不存在仓鼠，因此每个容量都会产生零个运输的仓鼠，并且任何类型都有效，但盒子的数量也必须为零。 当箱体容量大于`N`，该类型也有助于零运输仓鼠，因为无法形成完整的盒子。 这些情况可能会悄悄地破坏错误的贪婪逻辑，该逻辑假设至少有一个完整的盒子始终存在。 

## 方法

 暴力解释将尝试推理选择每种类型后剩下多少只仓鼠以及可以形成多少个完整的盒子。 对于每个容量`a_i`，我们计算有多少个完整的盒子适合并乘以得到运输的总数。 这已经接近最佳状态，因为每种类型都可以独立评估而无需交互。 

一个幼稚的错误是尝试枚举每种类型需要多少个盒子`1`最多`N / a_i`，计算每种类型的最佳选择。 这将导致总复杂度与所有可能的盒子计数之和成正比，在最坏的情况下达到 10^18 并且完全不可行。 

关键的观察结果是问题的结构消除了所有组合相互作用。 一旦容量确定，就必须采取最佳策略：尽可能多地装满箱子。 拿更少的盒子没有任何好处，因为未使用的仓鼠以后无法改进任何东西。 这将问题简化为评估每种类型的单个公式并选择最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解每种类型的盒子数量 | O(NK) | O(1) | O(1) | 太慢了|
 | 评估每种类型一次 | O(K) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每种盒子类型，并计算选择该类型时可实现的最佳结果。 

1. 阅读`N`以及能力列表。 这些定义了可用仓鼠的总数和所有可能的盒子尺寸。 
2. 初始化变量来存储迄今为止找到的最佳答案，包括最佳索引和最佳传输值。 
3. 对于每种类型`i`，计算可以形成多少个完整的盒子，即`N // a[i]`。 这直接强制要求盒子必须完全填满。 
4. 计算运输的仓鼠为`a[i] * (N // a[i])`。 这衡量了该选择的总可用输出。 
5. 如果该值大于迄今为止看到的最佳值，则更新最佳索引并存储索引和框数。 
6. 扫描完所有类型后，输出存储的最佳索引和对应的箱数。 

中心思想是每种候选类型都会产生确定性结果，因此问题变成了对独立选项的线性扫描。 

### 为什么它有效

 对于任何固定容量，最佳策略是完全确定的，因为部分盒子是被禁止的，未使用的仓鼠不能跨类型重新分配。 因此，每种类型都定义了一种可能的结果。 由于选择之间不存在耦合，因此独立比较这些结果足以保证找到全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    best_idx = 1
    best_val = -1
    best_boxes = 0

    for i, x in enumerate(a, start=1):
        boxes = n // x
        total = boxes * x

        if total > best_val:
            best_val = total
            best_idx = i
            best_boxes = boxes

    print(best_idx, best_boxes)

if __name__ == "__main__":
    solve()
```实现直接遵循每种类型的派生公式。 整数除法可以安全地处理所有大值，因为 Python 整数不会溢出。 比较使用运输总量作为主要指标，而存储箱子数量仅用于在确定最佳类型后输出。 该索引以基于 1 的形式进行跟踪，以匹配输入规范。 

一个微妙的点是初始化：设置`best_val`到`-1`确保即使当`N = 0`，仍然选择第一种类型，产生带有零个框的有效答案。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(K) | 使用常数时间算术对 K 个容量中的每一个进行精确评估一次 |
 | 空间| O(1) | O(1) | 在输入数组之外仅维护少数变量 |

 这些限制允许最多 100,000 种类型，因此单次线性扫描完全在限制范围内。 每次迭代仅执行整数除法和乘法，这是常数时间运算。

 ## 边缘情况

 当`N = 0`，计算`N // a[i]`始终为零，因此每种类型都会产生零运输的仓鼠。 该算法仍然选择第一种类型，因为比较使用严格的大于检查，从`-1`，所有候选人的分数为零。 输出正确报告零框。 

当所有容量超过`N`，每个候选者产生零个盒子。 该算法不会尝试过早丢弃这些类型，这避免了过滤逻辑的不正确行为。 第一种类型作为有效答案返回。 

当多种类型达到相同的最大传输值时，算法将保留第一个遇到的最大值。 由于该问题允许任何正确答案，因此这种平局打破是有效且一致的。
