 ## 解决方案
 ## 问题理解

 我们有几块木板，每块都有固定的长度。 由这些木板制成的木桶的“强度”或“容量”被定义为其中使用的最短木板的长度。 因此，如果我们选择一些木板子集，那么该木桶的质量完全取决于其最薄弱的木板。 

我们可以进行一个特殊操作：我们可以从一块板上取出一个连续的段并将其移动到另一块板上。 这有效地重新分配了两块板之间的长度，同时保留了所有长度的总和。 执行此操作后，所有板仍然存在，只是调整了长度。 

目标是最多执行一次这样的转移，以便在调整后，我们选择最小长度尽可能大的板子集。 由于我们总是可以随意丢弃棋盘，因此最终答案只是最多一次重新分配操作后最小棋盘长度的最大可能值。 

约束高达 n = 10^5，因此任何尝试模拟重新分配任意分数或重复重新计算最佳子集的方法都会失败。 我们需要一种解决方案，将问题减少到少量候选配置，并在线性或近线性时间内评估它们。 

一个关键的微妙之处在于操作是连续的，而不是离散的。 我们可以移动小数长度，这意味着状态空间是实值的。 这立即排除了对分割的组合搜索。 答案必须来自长度排序数组的结构属性。 

一个天真的错误是假设只有整数传输或贪婪的局部移动才重要。 例如，从最大板移动到最小长度可能看起来是最佳的，但最佳移动取决于相对于目标阈值平衡所有板，而不是局部均衡极端值。 

## 方法

 如果没有魔法操作，答案很简单：我们只需采用最小板长度，因为我们包含的每个板都必须遵守该下限。 

该操作引入了一个自由度：我们可以选择两个板并将一定数量的 x 从一个板转移到另一个板。 这仅改变两个值，同时保留总和。 其效果是，我们可以尝试通过牺牲部分强板来“举起”弱板。 

一个蛮力的想法是尝试所有的板对，模拟传输实际数量 x，并检查所得的最佳最小值。 对于固定对，我们可以想象将较小的董事会增加到某个阈值，同时确保捐赠者保持非负数。 然而，由于 x 是连续的，我们仍然需要通过分析得出最佳传输。 即使我们做到了这一点，在 n = 10^5 时尝试所有 O(n^2) 对也是不可能的。 

关键的观察是，最终答案仅取决于我们是否可以使所有选定的板达到至少某个阈值 T。如果我们固定 T，我们可以询问是否可以调整最多一次传输，以便所有板都至少达到 T。这将问题转化为对 T 的可行性检查。 

该结构在 T 中变得单调，这表明二分搜索。 对于给定的 T，低于 T 的董事会需要通过从高于 T 的董事会获取质量来“帮助”。由于我们只允许在两个董事会之间进行一次转移，唯一有用的解释是所有赤字必须由单个捐赠董事会承担，而所有盈余可以从一个来源董事会汇集。 

因此，我们计算低于 T 的董事会的总赤字和高于 T 的董事会的总盈余。可行性要求存在一个董事会可以作为足以弥补所有赤字的单一盈余来源，即某些董事会必须有足够的高于 T 的盈余来弥补整个赤字。 这将每次检查减少为线性扫描。 

我们二分查找最大可行T。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解配对和转账金额 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 通过线性可行性检查对答案进行二分搜索 | O(n log A) | O(n log A) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们尝试确定最大值 T，以便在最多一次传输后，我们保留的每块板的长度至少为 T。 

1. 我们在测试可行性时对数组进行排序或简单扫描，因为顺序与总和无关，但有助于对赤字和盈余进行一致的推理。 
2. 对于固定候选 T，我们计算 ai < T 的所有板的总长度缺失量。对于每个这样的板，缺失量为 T - ai，我们将这些值求和为单个赤字值 D。这表示必须从其他地方“导入”的总量。 
3. 我们还计算，对于每个 ai > T 的董事会，它在 T 之上还有多少额外的资金。如果一个董事会有 ai，它的盈余是 ai - T。我们将每个董事会视为潜在的捐助者。 
4. 我们检查是否存在至少一个董事会，其盈余至少为 D。如果存在这样一个董事会，那么我们可以从概念上将所有赤字从该单一捐助者转移到所有较小的董事会，使每个董事会至少达到 T。 
5. 如果不存在这样的捐助者，那么即使将所有盈余集中在一个董事会中也是不够的，这意味着“只能转移一次”的约束阻碍了资源的有效分配。 
6. 我们使用上面的可行性检查在 [0, max(ai)] 范围内二分搜索 T。 

二分查找完成后，我们输出最好的T。 

### 为什么它有效

 该算法依赖于这样一个事实：只有一块板可以充当传输长度的净源。 操作后的任何可行配置都可以解释为选择一个供体板和一个接收器板，所有其他调整概念上都通过该对进行。 可行性检查通过将所有赤字压缩为单一所需金额并要求单一盈余来源来弥补这一点来对此进行编码。 T 中可行性的单调性保证了二分搜索找到可实现的最大最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can(a, T):
    deficit = 0
    max_surplus = 0

    for x in a:
        if x < T:
            deficit += T - x
        else:
            max_surplus = max(max_surplus, x - T)

    return max_surplus >= deficit

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    lo, hi = 0.0, max(a)

    for _ in range(60):
        mid = (lo + hi) / 2
        if can(a, mid):
            lo = mid
        else:
            hi = mid

    print(f"{lo:.1f}")

if __name__ == "__main__":
    solve()
```该实现将可行性检查与二分搜索分开。 这`can`函数计算总赤字并跟踪最大可能的单一捐助者盈余。 这一点至关重要，因为单一转移的约束将所有重新分配压缩为一个有效来源。 使用浮点二分搜索可以避免精度问题，因为输出只需要一位小数。 

二分搜索运行固定迭代次数 (60)，这足以实现双精度收敛。 格式化步骤根据需要四舍五入到小数点后一位。

 ## 边缘情况

 一种边缘情况是所有板都相同。 例如：```
4
5 5 5 5
```任何 T > 5 的赤字立即为正，但不存在盈余。 可行性检查拒绝所有 T > 5，二分查找稳定在 5.0。 该算法正确返回原始值，因为没有任何传输可以改进统一配置。 

另一种情况是一个非常大的板和许多小板：```
5
1 1 1 1 100
```对于T = 2，赤字为4,4,4,4，总和为16，而最大盈余为98。这是可行的。 随着 T 的增加，赤字迅速增长，最终超过单个捐助者可以提供的范围。 该算法自然会找到充分利用捐赠者的平衡点。 

第三种情况是最小输入：```
1
7
```没有其他板可以转出或转入。 对于 T ≤ 7，可行性检查始终返回 true，二分查找返回 7.0。
