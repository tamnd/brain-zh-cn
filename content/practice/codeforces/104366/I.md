 ## 解决方案
 ## 问题理解

 我们得到了 3D 向量的集合。 从这些向量中，我们可以选择任何子集，包括空集，并对所选向量按分量求和以获得单个结果向量。 如果选择的子集是$S$，结果是一个向量$y_S = (y_1, y_2, y_3)$，其中每个坐标只是该坐标在所有选定向量上的总和。 

所选子集的分数是其结果坐标的绝对值之和，即$|y_1| + |y_2| + |y_3|$。 任务是找到所有子集的最大可能得分。 

约束条件$n \le 10^5$意味着我们不能尝试所有子集，因为这将呈指数增长$n$并且立即不可能。 甚至二次或三次的想法也被排除，因为$n^2$如果每个操作不是非常便宜，那么对于像 Python 这样的语言中的一秒限制来说已经太大了。 这促使我们寻求一个大致线性或线性时间的小常数倍的解决方案。 

一个微妙的点是允许空子集。 这意味着答案总是至少为零，并且任何假设我们必须选择至少一个向量的方法都可能在输入上失败，因为输入在每个方向上的所有贡献都是负的。 

当贪婪地进行坐标推理时，会出现一种常见的失败模式。 例如，人们可能会考虑选择具有正数的向量$x_1$，然后分别为正$x_2$，但这是无效的，因为同一向量同时对所有三个坐标做出贡献，并且选择它有助于一个坐标，同时在符号交互后伤害另一个坐标。 该决定在所有三个维度上都是全球性的。 

另一个误导性的想法是独立地最大化每个坐标和的绝对值。 例如，考虑向量$(10, -100, 0)$和$(-9, 0, 0)$。 最大化$|x_1|$可能建议同时采用两者，但这会减少其他坐标的组合结构，并且不能反映求和后如何应用绝对值。 

## 方法

 暴力法是枚举向量的每个子集，计算每个子集的向量和，并评估$|x_1| + |x_2| + |x_3|$。 这是正确的，因为它直接遵循定义。 然而，它需要评估$2^n$子集，甚至对于$n = 40$这已经变得不可行了，因为$2^{40}$是万亿的量级。 

关键的观察结果是在求和之后应用绝对值，这会引入每个坐标的全局符号模糊性。 对于每个坐标，我们不知道最终的和是正还是负，但是一旦我们确定了三个坐标的符号选择，绝对值就会消失并且表达式变成线性。 

具体来说，对于任何固定的符号选择$s_1, s_2, s_3 \in \{+1, -1\}$，我们有$$|y_1| + |y_2| + |y_3| = \max_{s \in \{\pm 1\}^3} (s_1 y_1 + s_2 y_2 + s_3 y_3).$$由于每个$y_i$本身是所选向量的和，我们可以将表达式重写为向量的和：$$\sum_{v \in S} (s_1 v_1 + s_2 v_2 + s_3 v_3).$$现在，对于固定符号模式，子集选择变得简单。 每个向量都是独立贡献的，所以我们要么接受它，要么不接受它，这取决于它的点积是否与$(s_1, s_2, s_3)$是积极的。 如果它是负数或零，则包含它无助于最大化总和。 

因此，对于八种符号组合中的每一种，我们都可以通过仅对正贡献求和来计算线性时间内的最佳可实现值。 最终答案是这八种情况中的最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n \cdot n)$|$O(1)$| 太慢了 |
 | 最佳 |$O(8n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将问题转化为评估从符号选择中得出的一小组线性目标。 

### 算法演练

 1. 迭代所有 8 个可能的符号三元组$(s_1, s_2, s_3)$其中每个分量要么是+1，要么是-1。 

每个三元组代表关于最终坐标和的最终符号的假设。 
2. 对于固定符号三元组，将运行总计初始化为零。 这将代表该符号假设下的最佳可实现值。 
3. 扫描所有向量。 对于每个向量$v = (x_1, x_2, x_3)$，计算其贡献$c = s_1 x_1 + s_2 x_2 + s_3 x_3$。 
4.如果$c > 0$， 添加$c$到运行总计。 否则，忽略该向量。 

这是有效的，因为在固定的线性目标下，选择负贡献的项目只会减少总数。 
5. 处理完所有向量后，将获得的总和与迄今为止的最佳答案进行比较，并保留最大值。 
6. 输出所有 8 个符号配置中的最大值。 

### 为什么它有效

 修复符号三元组会删除绝对值，并将目标转换为每个向量独立二元决策的线性函数。 在没有耦合约束的线性目标下，每个向量独立贡献，因此最优性减少为局部决策：当且仅当它增加总和时才包含它。 符号三元组的外部最大化解决了唯一剩余的歧义，即每个坐标中最终求和向量的未知方向。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    
    signs = [(sx, sy, sz)
             for sx in (1, -1)
             for sy in (1, -1)
             for sz in (1, -1)]
    
    ans = 0
    
    for sx, sy, sz in signs:
        total = 0
        for x, y, z in pts:
            val = sx * x + sy * y + sz * z
            if val > 0:
                total += val
        ans = max(ans, total)
    
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先将所有向量读入内存，因为我们将在八个符号配置中重用它们。 显式枚举了八个符号三元组，这避免了任何位操作开销并保持实现简单。 

对于每个符号配置，我们重新计算每个向量的贡献。 关键的实现细节是条件`if val > 0`。 包含贡献为零的向量不会改变结果，但排除它们可以保持逻辑一致并避免不必要的添加。 

答案在所有配置中全局维护，因为每种配置代表原始绝对值表达式的不同线性化。

 ## 边缘情况

 空子集的情况是自然处理的，因为如果所有向量在每个符号配置下都有负贡献，则不会选择任何向量并且运行总数保持为零。 例如，考虑向量$(-1,-1,-1)$。 每个符号选择都会产生一个非正点积，因此没有添加任何内容，并且答案正确为零。 

另一种边缘情况是向量在不同的符号配置下相互抵消。 例如，$(10,-10,0)$和$(-10,10,0)$在某些符号模式下产生零，但在其他符号模式下产生正累积。 该算法探索了所有八种可能性，因此始终考虑与全局结构一致的正确配置。 

最后，零向量在任何符号选择下都没有贡献。 它们被条件安全地忽略`val > 0`，并且包含或排除它们永远不会改变结果。
