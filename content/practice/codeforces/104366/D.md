 ## 解决方案
 ## 问题理解

 我们得到了数轴上的线段集合。 从这些细分中，我们考虑它们的每个可能的子集。 对于任何选定的子集，我们想象将其所有线段绘制到数轴上，其中重叠部分仍然只计算一次。 这意味着每个子集都会生成一个总绘制长度，这是所选间隔的并集的度量。 

任务不是计算单个子集的联合长度，而是计算所有间隔子集上的联合长度之和。 由于有 2ⁿ 子集，我们在一个指数级的大空间上求和，我们需要一种方法来分析而不是枚举来计算贡献。 

约束 n 高达 2 × 10⁵ 迫使我们远离任何显式处理子集甚至成对子集 DP 的东西。 任何解决方案都必须接近 O(n log n) 或 O(n)。 

这里最常见的失败模式来自于独立处理重叠或尝试逐个间隔添加贡献而没有正确处理联合效应。 例如，对于间隔 [1,3] 和 [2,4]，朴素加法会在选择两者的子集中对重叠行为进行双重计数。 

另一个微妙的陷阱是误解了所总结的内容。 我们不是对所选间隔的总长度求和，而是对它们的并集长度求和。 这种区别很重要，因为重叠会破坏结构，并使贡献依赖于相对顺序。 

一个小的说明性案例：

 输入：

 [1,3], [2,4]

 子集：

 空集 → 0

 {1} → 2

 {2} → 2

 {1,2} → 3

 答案 = 7

 跨子集的间隔长度的简单总和会错误地为整个子集生成 8，或者错误地处理子集之间的重叠重复。 

## 方法

 暴力方法枚举所有子集，并为每个子集合并间隔并计算并集长度。 合并大小为 k 的子集的成本为 O(k log k) 或 O(k)，具体取决于实现。 对所有子集求和，这大约导致 O(n 2ⁿ)，即使对于 n = 20，这也是不可行的。 

关键的转变是停止将子集视为组合对象，而是考虑线上的各个点。 每个点 x 对答案的贡献次数与它被至少一个选定区间覆盖的次数完全相同。 如果我们可以计算，对于每个 x，有多少子集在 x 处激活覆盖范围，那么我们可以将其整合到所有 x 上。 

现在固定一个点x。 假设它被 n 个间隔中的 k 个覆盖。 为了将 x 绘制在子集中，我们必须至少选择这 k 个间隔之一。 剩余的 n − k 间隔与 x 是否被覆盖无关。 因此，x 未被绘制的子集的数量正是那些没有选择 k 个覆盖区间的子集，即 2^(n−k)。 因此，绘制 x 的子集为 2ⁿ − 2^(n−k)。 每个这样的子集在 x 处贡献一个无穷小的长度，因此我们将这个贡献乘以 k 为常数的度量。 

这减少了计算沿线覆盖计数的问题，这可以通过扫描端点来获得。 然而，直接对连续 x 进行积分是不必要的。 相反，我们使用覆盖范围发生变化的事件点上的扫描线来转换问题。 

在连续的排序端点之间，覆盖计数 k 是恒定的。 如果我们知道长度为 L 的线段上的 k，那么它对答案的贡献是：

 L × (2ⁿ − 2^(n−k))。 

因此，我们只需要在所有区间端点引起的不相交基本段上构建覆盖剖面。 

这是有效的，因为最多有 2n 个不同的端点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·2ⁿ) | O(n·2ⁿ) | O(n) | 太慢了 |
 | 扫描+覆盖计数| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

我们将所有区间端点转换为排序的事件列表，并跟踪覆盖范围在数轴上的变化。 

1. 提取所有区间端点并构建在 l 处增加覆盖范围并在 r 之后减少覆盖范围的事件。 我们在实现逻辑中将间隔视为半开，因此段可以完全分离。 这确保了连续事件位置之间的覆盖范围是分段恒定的。 
2. 对所有事件坐标进行排序。 这将数轴划分为段，段内没有间隔开始或结束。 这样做的原因是覆盖范围只能在端点发生变化。 
3.从左向右扫动，保持运行计数器`cur`表示当前有多少个区间覆盖了活跃仓位。 
4. 对于每对相邻的事件位置 x[i] 和 x[i+1]，计算段长度 L = x[i+1] − x[i]。 在此段期间，覆盖范围是恒定的并且等于`cur`。 
5. 对于该细分市场，其贡献计算如下：

 L × (2ⁿ − 2^(n−cur))。 

减法项对未能激活覆盖该段的任何区间的子集进行计数。 
6. 将这个贡献累加到最终答案中，对 998244353 取模。 
7. 更新`cur`在处理下一段之前，在位置 x[i+1] 处使用该坐标处发生的所有事件。 

### 为什么它有效

 线上的每个点都属于扫描线段之一，并且在每个线段内，覆盖间隔的集合是固定的。 对于一个固定线段，其被绘制的唯一条件是其覆盖区间至少在子集中被选择。 由于非覆盖间隔的选择不会影响该段的覆盖范围，因此它们贡献了 2^(n−cur) 的乘法因子。 这种独立性保证了对段贡献求和可以准确计算每个子集的并集长度，而不会重复计算重叠。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    events = []
    
    coords = set()
    segs = []
    
    for _ in range(n):
        l, r = map(int, input().split())
        segs.append((l, r))
        coords.add(l)
        coords.add(r)
    
    coords = sorted(coords)
    idx = {v: i for i, v in enumerate(coords)}
    
    diff = [0] * (len(coords) + 1)
    
    for l, r in segs:
        diff[idx[l]] += 1
        diff[idx[r]] -= 1
    
    cur = 0
    ans = 0
    
    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD
    
    for i in range(len(coords) - 1):
        cur += diff[i]
        if cur == 0:
            continue
        L = coords[i + 1] - coords[i]
        if L == 0:
            continue
        # segments covered by cur intervals
        total = pow2[n]
        bad = pow2[n - cur]
        ans += L * ((total - bad) % MOD)
        ans %= MOD
    
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```该代码从所有端点构建一个压缩坐标系，然后使用差异数组来跟踪覆盖每个坐标区域的间隔数。 扫描计算每个段的覆盖范围并应用之前导出的公式。 2 的预计算能力避免了循环内的重新计算，这一点很重要，因为每个段必须在 O(1) 内处理。 

一个微妙的实现点是正确处理连续坐标之间的段，因为覆盖范围仅在端点处发生变化。 另一个是确保模减法`total - bad`，因为在应用模数之前中间值可能变为负值。

 ## 边缘情况

 临界边缘情况是所有区间都相同，例如 [1,10]、[1,10]。 线段上的覆盖范围始终为 2，因此每个单位长度贡献 2ⁿ − 2^(n−2)，这可以正确计算除那些不选择相同间隔的子集之外的所有子集。 

另一种边缘情况是嵌套区间，例如 [1,10]、[2,9]、[3,8]。 扫描确保增加中间的覆盖范围并减少边界的覆盖范围，并且每个区域只计算一次，因为贡献与不相交的坐标段相关，而不是与区间标识相关。
