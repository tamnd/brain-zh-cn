 ## 解决方案
 ## 问题理解

 我们沿着一维长度段放置路灯$n$。 我们最多可以选择$k$这些灯的位置。 每个光都会为线段上的每个点贡献亮度，但贡献会随着距离呈二次方衰减：如果一个点位于一定距离处$r$来自光，光贡献$d \cdot r^2$该点的亮度。 

然而，有两个影响几何形状的关键约束。 首先，亮度是相加的，因此每个点都会收到所有灯光贡献的总和。 其次，灯光有一个特殊的规则：在它自己的位置，它贡献无限的亮度，这实际上意味着整个段的最小亮度永远不会恰好出现在灯光位置。 

还有一个阻碍规则：路灯互相遮挡。 如果光源位于光源和点之间，则光源的贡献不会穿过它。 这有效地将片段划分为由灯光分隔的独立区域。 

目标是最多放置$k$照亮该段，使得该段中所有点的最小亮度尽可能大。 换句话说，我们试图通过定位灯光来“消除”最薄弱的地方，以消除覆盖范围的深谷。 

输入尺寸很大：最多$10^5$测试用例，与$n$和$k$一样大$10^9$。 任何逐点模拟位置或评估亮度的解决方案都是不可能的。 甚至存储灯的配置也是不可行的。 该解决方案必须仅取决于最佳安排的结构特性，而不是显式构造。 

当出现微妙的边缘情况时$k = 1$。 单灯必须最佳放置在中点。 另一个边缘情况是当$k = n$，因为灯光可以有效消除大的未覆盖间隙，并且结构变得完全饱和。 天真的直觉可能会建议贪婪的放置或等间距模拟，但这两种方法都会失败，因为亮度与距离成二次关系，并且由于附加贡献而成为非局部的。 

## 方法

 蛮力策略会尝试一切方法来放置$k$沿着该段点亮，然后评估每个配置的整个间隔的最小亮度。 即使我们将位置离散化为整数坐标，可供选择的方法数量$k$之间的位置$n$是组合的，并且评估每个配置至少需要对段进行线性扫描或解决连续最小化问题。 这很快就会呈指数增长，或者至少是$O(n^k)$，即使输入很小，这也是完全不可行的。 

关键的结构观察是，在任何最佳配置中，瓶颈点（亮度最小的点）将位于两个相邻灯之间或边界与灯之间的间隙中间。 由于每个灯贡献距离的凸二次函数，因此在最佳布局中相邻灯之间的任何间隔中的总亮度也是凸的且对称的。 这将优化安排推向段的统一划分。 

一旦我们认识到问题是通过均衡最差间隙来控制的，光的确切位置就变得不如诱导分区大小重要。 该细分市场有效地分为$k+1$独立的间隔，最小亮度由最大的间隔决定。 当这些间隔尽可能相等时，即可实现最佳配置。 

这将问题简化为分析单个长度区间$L = \frac{n}{k+1}$，并计算由对称放置光边界引起的最小亮度。 贡献的二次结构导致了该区间内最差点的封闭式表达式。

 ## 算法演练

 ### 最优推理步骤

 1. 观察到，在最佳布置中，灯光将片段划分为由阻挡点分隔的独立区域。 这减少了相距较远的区域之间的相互作用，使我们能够独立分析每个区域。 
2. 由于我们正在最大化最小亮度，因此瓶颈必须位于连续灯光之间或边界与灯光之间的最大间隙。 间隙大小的任何不平衡都可以通过移动灯光来改善。 
3. 得出结论，最佳放置将段分配为$k+1$等长间隔，每个长度$L = \frac{n}{k+1}$。 这确保了没有哪个地区表现得特别弱。 
4. 关注单个区间长度$L$。 由于二次距离成本的对称性，该区间中最差的点是其中点。 
5. 将中点处的亮度计算为两个最近的边界光的贡献之和。 每项贡献均遵循以下形式$d \cdot r^2$， 在哪里$r = L/2$，所以双方都贡献$d \cdot (L/2)^2$。 
6. 添加双方的贡献以获得总的最小亮度：$$2 \cdot d \cdot (L/2)^2 = d \cdot \frac{L^2}{2}$$1.替补$L = \frac{n}{k+1}$得到最终公式：$$\text{answer} = d \cdot \frac{n^2}{2 (k+1)^2}$$### 为什么它有效

 关键的不变量是两个相邻光之间的线段的每个内部点都会经历凸二次亮度分布，并且凸性迫使最小值出现在最大间隔的中点。 任何与等间距的偏差都会产生一个较大的间隔，其中点的亮度严格小于较小间隔的中点的亮度。 由于亮度在区间内是相加且对称的，因此改善最差区间可改善全局最小值。 因此，问题简化为平衡区间长度，并且一旦平衡，二次评估就变得确定性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k, d = map(int, input().split())
        L = n / (k + 1)
        ans = d * (L * L) / 2.0
        out.append(f"{ans:.10f}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码直接实现派生的封闭式表达式。 唯一的微妙之处是浮点精度：因为$n$,$k$， 和$d$可以很大，中间值必须以双精度计算。 使用 Python float 就足够了，因为所需的容错能力是$10^{-4}$。 

划分由$k+1$对应于将街道分成相等的最大段。 平方步长反映了影响力随距离的二次衰减。 的因素为$1/2$来自对称组合两个边界光的贡献。

 ## 边缘情况

 当$k = 1$，该算法将整个线段缩减为长度相等的两半$n/2$。 中点是最小亮度的唯一候选点。 用于输入`1 1 1`，计算得出$L = 0.5$和最终值$0.125$，匹配两侧的对称二次贡献。 

什么时候$k = n$，区间长度变为$n/(n+1)$，小于 1。这意味着每个区域都非常小，并且二次惩罚很快缩小。 该公式仍然适用，无需修改，因为推导不假设$k \ll n$，只是间隔相等。 

什么时候$n$很大，比如$10^9$，浮点稳定性很重要。 该计算仅使用双精度数的乘法和除法，它保持稳定，因为中间幅度保持在$10^{18}$，远低于 IEEE 754 在所需精度水平上翻倍的精度损失阈值。
