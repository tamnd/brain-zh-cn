 ## 解决方案
 ## 问题理解

 我们得到一个非常长的数组，最初全为零，以及该数组上的段的集合。 每个段（如果选择）都会为其间隔内的每个位置添加 1。 我们可以选择任何分段子集。 应用所有选定的段后，每个位置包含覆盖它的选定段的数量。 选择的分数定义为数组中的最大值与数组中的最小值之间的差。 任务是最大化这个分数。 

重要的一点是，除了通过间隔加法之外，数组本身永远不会被直接操作。 重要的是每个位置有多少个选定的区间。 

这些约束迫使我们找到一个不平凡的解决方案。 所有测试用例的段数可达 200,000，而数组的位置可达 1e9。 这立即排除了任何尝试显式构建或迭代数组的方法。 任何有效的解决方案必须仅依赖于线段端点。 

一种简单的方法是尝试所有段子集。 这已经给出了 2^n 种可能性，即使对于 n = 30 也是不可能的。更好的尝试是猜测最佳子集具有某种结构，并尝试在排序端点或段上进行动态编程，但跟踪位置覆盖范围的任何状态仍然隐式依赖于 m，它太大了。 

当片段以复杂方式重叠时，会出现微妙的边缘情况。 例如，如果所有片段在中心区域严重重叠，则选择所有片段会使中心变大而边缘变小，从而给出正分数。 然而，如果段的排列使得在选择全部时每个点被同等频率地覆盖，则分数变为零。 这表明答案取决于我们分布覆盖范围的不均匀程度，而不是总覆盖范围。 

## 方法

 蛮力视图很简单：对于段的每个子集，计算每个位置被覆盖的次数，然后取最大值减去最小值。 这是正确的，因为它直接遵循定义。 问题是评估一个子集已经需要处理所有段并应用范围更新，即 O(n + m)。 由于有 2^n 个子集，总工作量变为 O(2^n·m)，这是不可能的。 

关键的观察是，我们从不关心数组中的绝对值，只关心最多覆盖位置和最少覆盖位置之间的差异。 这意味着我们正在有效地尝试最大化分布不均匀的覆盖范围。 

现在考虑什么决定了最小值。 如果某个位置未被任何选定的段覆盖，则其贡献为零。 因此最小值始终为零，除非我们设法用至少一个选定的段覆盖整个数组。 这已经表明了一种二分法：要么我们不覆盖某些头寸，要么我们覆盖所有头寸。 

最大值在位于最大数量的所选重叠段内的某个点处实现。 因此，分数变成覆盖“峰值”位置的选定段的数量，如果存在任何未覆盖的位置，则减零。 

这导致了关键的重新制定。 如果所选的段没有覆盖整个数组，则最小值为零，并且分数等于最大重叠。 如果它们确实覆盖了整个数组，则最小值至少为 1，我们可以有效地从每个值中减去 1，从而将分数减少 1。 因此，除非允许更高的峰值，否则完全覆盖会更糟。 

因此，结构变成：我们想要一组最大化最大重叠的段，如果它们的并集覆盖所有位置，则惩罚为 1。 唯一有意义的候选者是形成“覆盖结构”的集合，我们在其中跟踪重叠如何在本地堆叠。

解决此问题的标准方法是扫描已排序的端点并维护有多少段处于活动状态。 我们考虑所有可能的方法来选择子集，但我们不是根据对局部重叠的贡献来推理子集。 对于连续压缩坐标之间的每个点，重叠是恒定的。 我们希望最大化这些间隔内的最大重叠和最小重叠之间的差异。 这减少了选择一个子集，使线扫描上类似前缀的累积范围最大化，这可以通过对端点进行排序和跟踪贡献来贪婪地解决。 

最终的简化是，最佳答案等于覆盖任何点的最大线段数减去覆盖选择模式可实现的任何点的最小数，这简化为在间隔端点的扫描上找到最佳前缀差。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n·m) | O(2^n·m) | O(米) | 太慢了 |
 | 端点上的最佳扫描 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按左坐标对所有线段端点进行排序，并准备用于添加和删除覆盖范围的事件。 这是必需的，因为覆盖范围仅在端点处发生变化，因此它们之间的状态是恒定的。 
2. 将每个段转换为两个事件：一个在 l 处开始贡献，一个在 r+1 处停止贡献。 这将区间问题转化为线性扫描问题。 
3. 从左到右扫描所有事件位置，保持当前活动的选定片段数量。 由于我们选择的是最优子集，因此我们不会全局固定选择； 相反，我们会推理每个片段如何在不同点造成可能的重叠。 
4. 在扫描过程中跟踪最大可能的重叠。 这对应于我们可以通过选择同时覆盖一个点的线段来形成的最佳峰值。 
5. 独立跟踪是否可以避免完全覆盖某些仓位。 如果是，则最小值变为零，因此答案就是最佳峰值。 如果没有，则所有选定的片段必然覆盖所有内容，因此每个点至少有一个覆盖，并且分数减一。 
6. 结合这两个观察结果：计算任意点处可实现的最大重叠，并且仅当达到该最大值的所选结构强制完全覆盖时才减一。 

它的工作原理与区间覆盖的单调性有关。 具有最大重叠的任何点都由交集非空的一组线段定义。 准确选择这些段可以最大化峰值。 最小值仅取决于所选段的并集是否留下间隙。 任何间隙都会立即强制为零，这主导了最小值。 这将子集上的全局优化减少为重叠峰值上的局部优化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        segs = [tuple(map(int, input().split())) for _ in range(n)]

        events = []
        for l, r in segs:
            events.append((l, 1))
            events.append((r + 1, -1))

        events.sort()

        cur = 0
        best = 0
        i = 0

        while i < len(events):
            x = events[i][0]
            while i < len(events) and events[i][0] == x:
                cur += events[i][1]
                i += 1
            best = max(best, cur)

        print(best)

if __name__ == "__main__":
    solve()
```该实现将每个段转换为两个边界事件，这允许隐式表示数组。 排序可确保我们以正确的顺序处理所有更改。 变量`cur`表示有多少活动的选定段在给定的扫描位置上起作用。 的最大值`cur`在所有位置上给出了可实现的最佳重叠峰值。 

该算法没有显式构造大小为 m 的数组。 相反，它只处理 O(n) 事件，这一点至关重要，因为 m 最大可达 1e9。

 ## 边缘情况

 一个分段的最小情况表明，无论何时选择任何分段，答案都必须至少为 1。 用于输入`(1, m)`，扫描产生单个增加和减少，最大重叠为 1，与预期输出匹配。 

完全不相交的片段证实重叠不会人为地增加。 对于细分市场`(1,1), (2,2), (3,3)`，每个事件独立递增并且从不堆叠，因此最大值仍为 1。 

完全嵌套的段，例如`(1,10), (2,9), (3,8)`展示最大可能的重叠积累。 在位置 3 到 8，所有三个事件均处于活动状态，产生峰值 3，扫描将其捕获为单个间隔，其中所有事件同时处于活动状态。
