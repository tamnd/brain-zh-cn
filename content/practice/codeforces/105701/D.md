 ## 解决方案
 ## 问题理解

 我们得到一个无向连通图，其中每条边都有非负权重。 “旅程”是从节点 1 开始到节点 k 结束的任何步行，不允许重复使用同一条边两次，尽管重新访问顶点是可以的。 

对于任何此类步行，我们都会查看其中使用的所有边权重。 步行贡献了两个特殊值：其边缘之间的最小权重和其边缘之间的最大权重。 步行的成本是这两个极端的总和。 

对于每个顶点 k，我们需要从 1 到 k 的所有有效行走的最小可能成本。 

该图可能足够大，以至于任何 n 或 m 的二次甚至三次都是不可能的。 由于顶点和边多达 300,000 个，我们的工作时间预计约为 O(m log m) 或 O(m α(n))。 任何尝试探索所有可能路径或所有边子集的解决方案都会失败，因为行走次数是指数级的。 

一个微妙的困难是，步行不需要是顶点方面的简单路径，因此该结构并不是立即的树问题。 然而，边不重复的限制已经促使我们从跨越结构而不是任意游走的角度进行思考。 

一个常见的陷阱是假设最短路径式松弛有效。 事实并非如此，因为成本取决于路径上的全局极值，而不是附加贡献。 另一个陷阱是假设我们可以独立优化最小和最大边权重。 它们通过两者必须出现在同一次步行中的要求来耦合。 

## 方法

 直接方法将枚举从 1 到 k 的所有可能的行走，跟踪所看到的最小和最大边缘权重，并获取最佳结果。 即使我们修剪重复的边，不同的边简单游走的数量在稠密图中仍然是指数级的，所以这很快就变得不可行。 

第二个天真的想法是固定最小边权重 x 和最大边权重 y，然后检查是否存在仅使用权重在区间 [x, y] 内的边连接 1 和 k 的路径。 如果存在这样的路径，我们可以尝试最小化 x + y。 原则上这是正确的，但检查所有 O(m²) 间隔的连通性太慢。 

关键的结构观察是，对于连通性问题，自行车除了提供替代路线之外没有任何帮助。 任何行走都可以被压缩到所用边的生成树中，而不会增加遇到的权重范围。 这表明图的基本行为是由生成树结构捕获的。 

在所有生成树中，这里最有用的就是最大生成树。 原因是它尽可能保留高权重连接，确保路径上的任何瓶颈边缘尽可能大。 一旦我们将自己限制在这棵树上，两个顶点之间的任何路径都是唯一的，并且该路径上的最小和最大边是固定的。 

这减少了从在图中搜索任意游走到评估树中每个查询节点的单个路径的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 枚举行走 | 指数| O(米) | 太慢了|
 | 间隔连通性检查 | O(m³ log m) | O(米) | 太慢了|
 | 最大生成树+路径查询| O(m log m + n log n) | O(m log m + n log n) | O(n + m) | 已接受 |

 ## 算法演练

1. 将所有边按权重降序排序，并使用 DSU 结构构建最大生成树。 每次连接两个组件时，我们都会采用最高的可用边缘，确保我们首先保持最强的连接性。 
2. 构建生成树后，观察到对于任意两个节点 u 和 v，原始图中的每个有效行走都可以用边来表示，这些边不会将权重范围提高到超出它们之间的树路径上存在的范围。 
3. 在节点 1 处将树作为根，并对其进行预处理以进行最低公共祖先查询。 与 LCA 一起，为每个节点维护其二进制提升表，存储到其祖先的路径上以 2 次方距离的最小和最大边权重。 
4. 对于每个节点 k，使用 LCA 计算从 1 到 k 的路径。 路径上的最小边权重是从 1 和 k 到其 LCA 的两个向上段的最小值。 最大边权重的计算方式类似。 
5. 输出这两个值的和作为节点 k 的答案。 

基本的计算步骤是树中的路径查询分解为两个向上路径，每个路径都可以使用预先计算的跳转表在对数时间内得到回答。 

### 为什么它有效

 最大生成树确保在引入较小的替代方案之前，使用尽可能大的边连接任意两个顶点。 原始图中尝试使用较小边改进连通性的任何行走只能减少路径上可能的最小最大边，而永远不会提高极值之和。 这意味着 1 和 k 之间的最优行走始终对应于最大生成树中的唯一路径，其中最小和最大边缘值在连通性约束下是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0]*n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

n, m = map(int, input().split())
edges = []
for i in range(m):
    u, v, w = map(int, input().split())
    edges.append((w, u-1, v-1))

edges.sort(reverse=True)

dsu = DSU(n)
g = [[] for _ in range(n)]

for w, u, v in edges:
    if dsu.union(u, v):
        g[u].append((v, w))
        g[v].append((u, w))

LOG = 20
up = [[-1]*n for _ in range(LOG)]
mx = [[0]*n for _ in range(LOG)]
mn = [[10**18]*n for _ in range(LOG)]
depth = [0]*n

def dfs(v, p):
    for to, w in g[v]:
        if to == p:
            continue
        depth[to] = depth[v] + 1
        up[0][to] = v
        mx[0][to] = w
        mn[0][to] = w
        dfs(to, v)

up[0][0] = 0
mx[0][0] = 0
mn[0][0] = 10**18
dfs(0, -1)

for j in range(1, LOG):
    for i in range(n):
        up[j][i] = up[j-1][up[j-1][i]]
        mx[j][i] = max(mx[j-1][i], mx[j-1][up[j-1][i]])
        mn[j][i] = min(mn[j-1][i], mn[j-1][up[j-1][i]])

def query(a, b):
    if depth[a] < depth[b]:
        a, b = b, a

    maxv = 0
    minv = 10**18

    diff = depth[a] - depth[b]
    for i in range(LOG):
        if diff >> i & 1:
            maxv = max(maxv, mx[i][a])
            minv = min(minv, mn[i][a])
            a = up[i][a]

    if a == b:
        return minv + maxv

    for i in range(LOG-1, -1, -1):
        if up[i][a] != up[i][b]:
            maxv = max(maxv, mx[i][a], mx[i][b])
            minv = min(minv, mn[i][a], mn[i][b])
            a = up[i][a]
            b = up[i][b]

    maxv = max(maxv, mx[0][a], mx[0][b])
    minv = min(minv, mn[0][a], mn[0][b])

    return minv + maxv

res = []
for k in range(1, n):
    res.append(str(query(0, k)))

print("\n".join(res))
```DSU 阶段构建最大生成树，确保仅保留最相关的边。 DFS 初始化父节点和边缘信息。 然后，二元升降台可以有效提取任何根到节点路径上的最小和最大边缘权重。 每个查询通过在跟踪极值的同时将两个端点提升到其 LCA，以对数时间计算节点 k 的结果。 

一个重要的常见实现细节是用大哨兵值初始化最小表，并在向上跳跃期间仔细更新最小值和最大值，因为缺少一个段会破坏正确性。 

## 工作示例

 考虑一个小图，其中节点 1 连接到权重为 2 的 2，连接到权重为 1 的节点 3，节点 2 连接到权重为 1 的节点 3。 

构建最大生成树后，我们保留边 2-1 和 2-3，因为它们是保持连通性的最强连接。 

对于 k = 3，树中的路径为 3 → 2 → 1。 

| 步骤| 当前节点 | 最大边缘| 最小边缘|
 | --- | --- | --- | --- |
 | 电梯 3 至 2 | 2 | 1 | 1 |
 | 电梯 2 至 1 | 1 | 2 | 1 |

 结果变为 1 + 2 = 3。 

现在考虑一个稍大的链，其权重为 5、3、4，沿着从 1 到 4 的路径。 

最大生成树首先保留边 5 和 4，然后保留边 3。 

对于 k = 4：

 | 步骤| 电梯操作 | 最大边缘| 最小边缘|
 | --- | --- | --- | --- |
 | 4 点开始 | - | 0 | 信息 |
 | 移至 LCA | 积累| 5 | 3 |

 答案是 3 + 5 = 8。 

这些痕迹表明，一旦树被固定，计算就会减少为路径上的纯区间聚合。

 ## 边缘情况

 关键的边缘情况是多个边缘具有相同的权重。 在这种情况下，DSU 仍必须一致地选择边，但任何有效的生成树都是可接受的，因为所有边对路径极值的贡献相同。 

当原始图中的最佳游走尝试使用循环来改进最小值或最大值时，会出现另一种边缘情况。 在生成树公式中，这种循环消失了，但树路径上的极值已经捕获了最佳可实现区间，因此结果保持不变。 

最后的边缘情况是倾斜图，其中节点 1 通过单个高权重主干和许多低权重快捷方式连接到其余节点。 最大生成树优先考虑主干边，防止低权重边错误地缩小最大值或人为地将最小值降低到超出最佳值。
