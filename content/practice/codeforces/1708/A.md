 **求解时间：** 2m 2s

 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 唯一允许的操作选择某个位置`i > 1`并取代`a[i]`和`a[i] - a[i-1]`。 

该操作仅影响一个元素，并且总是减去紧邻其左侧的当前值。 我们可以按任何顺序多次执行该操作。 目标是使除第一个元素之外的所有元素都为零。 

对于每个测试用例，我们必须确定是否存在这样的操作序列。 

限制非常小。 数组长度最多为100，测试用例最多为100个。 即使是相对低效的方法也能轻松满足限制。 真正的挑战是认识到当变换可能时完全表征的数学属性。 

微妙的一点是操作永远不会改变`a[1]`。 无论第一个元素以什么值开始，它都会永远保留。 由于每个其他元素最终必须通过重复从左侧减去值而变为零，因此第一个元素充当所有后续元素必须兼容的“单元”。 

一个容易犯的错误是假设每个元素都可以独立地归零。 

考虑：```
1
2
5 7
```正确答案是：```
NO
```从 7 开始，重复减去 5 得到 2，然后是 -3，而且我们永远不可能精确到 0。如果粗心的解决方案只检查每个元素是否至少是前一个元素，就会错误地回答“是”。 

另一个常见的错误是关注相邻的整除性。 

考虑：```
1
3
2 4 6
```答案是：```
YES
```虽然6不能被4整除，但我们可以先通过两次减去2将4变成0，并且可以使用不变的第一个元素值2来减少6。相邻元素之间的关系不是关键属性。 

当所有元素已经相等时，会出现第三种边缘情况：```
1
4
7 7 7 7
```答案是：```
YES
```每个非第一个元素可以通过减去 7 一次而减为零。 

## 方法

 蛮力的观点是模拟这个过程。 对于每个位置，我们可以重复减去当前的左邻居，直到该值变为零或小于左邻居。 如果它达到零，则该位置已解决。 否则这个答案是不可能的。 

这是有效的，因为重复减法正是该操作的作用。 问题是值可以大到`10^9`。 如果`a[1] = 1`，减少一个值`10^9`可能需要十亿次操作。 实际操作序列太大而无法模拟。 

关键的观察结果是第一个元素永远不会改变。 

假设第一个元素等于`x = a[1]`。 

使`a[2]`变成零，我们反复减去`x`。 当且仅当`a[2]`可以整除`x`。 

现在考虑后面的位置。 即使我们修改`a[2]`,`a[3]`等等，一旦位置变为零，它就会保持为零，因为减去零不会改变任何东西。 最终每个较早的元素都可以减少到零，留下`a[1] = x`不变。 

对于任何职位`i > 1`，唯一可以帮助减少它的非零值仍然是`x`。 重复减法`x`恰好达到零时`a[i]`可以整除`x`。 

因此，整个问题简化为检查每个元素是否可以被第一个元素整除。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(sum(aᵢ) / a₁) | O(sum(aᵢ) / a₁) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取数组并将第一个元素存储为`x = a[1]`。 
2. 检查从第二个位置到最后一个位置的每个元素。 
3. 对于每个元素`a[i]`, 计算`a[i] % x`。 
4. 如果有余数不为零，则打印`"NO"`因为重复减去`x`永远无法将该值精确地减少到零。 
5. 如果所有元素都可以被整除`x`， 打印`"YES"`。 

### 为什么它有效

 第一个元素在任何操作期间都不会改变。 设其值为`x`。 

对于任何职位`i > 1`，每一个影响的操作`a[i]`从中减去一些值。 要完全为零，减去的总金额必须等于原始值`a[i]`。 

在减少所有较早的位置后，左侧唯一可用的持久非零值是`x`。 每减少一次`a[i]`有效地重复减法`x`。 一个数可以通过重复减法减至零`x`当且仅当它是的倍数`x`。 

因此每个位置都必须满足`a[i] % x == 0`。 如果这个条件适用于所有位置，我们可以独立地将每个元素减少到零。 即使只有一个位置失败，目标配置也是不可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        x = a[0]
        
        ok = True
        for v in a[1:]:
            if v % x != 0:
                ok = False
                break
        
        print("YES" if ok else "NO")

solve()
```该解决方案首先存储第一个元素，因为它是整个过程中唯一不变的值。 

剩余元素上的循环检查证明中导出的整除条件。 当找到一个不可整除的元素的那一刻，我们就已经知道答案一定是`"NO"`，因此循环可以提前终止。 

所有算术都使用 Python 整数。 由于 Python 支持任意精度整数，因此不存在溢出问题，尽管给定的边界对于标准 64 位整数来说已经足够小了。 

索引很简单，因为第一个元素是单独处理的，并且后面的每个元素必须满足相同的条件。

 ## 边缘情况

 考虑：```
1
2
5 7
```算法集`x = 5`并检查`7 % 5 = 2`。 由于余数不为零，因此输出`"NO"`。 

尝试操作顺序证实了这一点。 7经过一次减法就变成2，再减一次就变成负数。 零是无法达到的。 

考虑：```
1
3
2 4 6
```该算法检查：```
4 % 2 = 0
6 % 2 = 0
```和输出`"YES"`。 

这是一个有用的反例，反驳了每个元素都必须能被它的前一个元素整除的想法。 实际的不变量仅取决于第一个元素。 

考虑：```
1
4
7 7 7 7
```该算法找到每个能被 7 整除的元素并输出`"YES"`。 

每个非第一个元素都可以在一次操作中减少到零，从而确认相等的数组始终有效。
