 ## 解决方案
 ## 问题理解

 我们有一个国家集合，其中每个国家都是图中的一个节点，每个直接敌人关系都是一条边。 重要的结构保证是这些关系形成一棵树，因此不存在循环，并且该图恰好由 n − 1 条边连接。 

“友谊”的概念并不是直接作为边缘关系给出的。 相反，它源自一个规则：如果一个国家 x 有一个敌人 y，而该敌人 y 有另一个敌人 z，那么 z 就成为 x 的朋友。 用图术语来说，这意味着从 x 通过恰好遵循两条边可到达的任何节点都对应于 x 的友元。 超出此规则不会发生进一步的传播，因此友谊严格依赖于长度恰好为 2 的路径。 

任务是为每个节点计算有多少个不同的节点与它的距离正好为 2，然后输出使该值最大化的任何节点以及最大计数。 

这些约束意味着每个测试用例的 n 最多为 200,000，最多有 10,000 个测试用例，但所有 n 的总和以 200,000 为界。 这立即表明任何算法都必须在总输入大小上呈线性。 每个测试用例的 n 为二次方的解决方案会太慢，如果重复应用，即使每个测试用例的 O(n log n) 也会有风险。 

一种幼稚的解释是，对于每个节点，运行深度为 2 的 BFS 并计算距离为 2 的节点。虽然正确，但这会重复大量工作，并且在星形树中存在 O(n²) 行为的风险。 

一些微妙的案例值得一提。 在一个中心节点与所有其他节点相连的星形树中，每个叶子节点的 BFS 都会重复遍历中心节点和所有其他叶子节点，从而导致冗余工作。 另一个边缘情况是路径图：在一条长链中，每个 BFS 仍然走了一小部分，但累积起来它仍然是二次的。 

关键的观察是距离为 2 的节点可以纯粹根据局部度信息进行计数，而无需执行重复遍历。 

## 方法

 暴力解决方案将每个节点视为起点，并执行深度为 2 的 BFS 或 DFS。 从节点 x 开始，它探索所有邻居 y，然后探索 y 的所有邻居，收集距离恰好为 2 的邻居。 这是正确的，因为它直接遵循友谊的定义。 

然而，每个 BFS 可以触及密集邻域中的 O(n) 个节点，并且对每个节点执行此操作会导致最坏情况树（例如星形树）的总复杂度为 O(n²)。 冗余来自于重复扫描相同的邻接列表。 

关键的结构见解是，与 x 距离恰好为 2 的任何节点 z 必须通过 x 的某个中间邻居 y 连接。 对于固定的 y，除了 x 之外，y 的每个邻居都贡献一个距 x 距离为 2 的有效节点。 这意味着每个邻居 y 为 x 贡献 deg(y) − 1 个候选。 对 x 的所有邻居求和即可得出答案。 

这将计算从重复的图遍历转移到邻接列表上的单次传递，其中每条边贡献恒定量的信息。

 ## 算法演练

1. 构建树的邻接表并计算每个节点的度。 度数代表每个国家有多少个直接敌人，将用于推断二级联系。 
2. 对于每个节点 x，将计数器 ans[x] 初始化为零。 这将存储有多少个节点距离恰好为 2。 
3. 迭代节点 x 的每个邻居 y。 对于每个这样的邻居，我们考虑连接到 y 的所有节点。 
4. 将 deg(y) − 1 添加到 ans[x]。 减法将 x 本身从 y 的邻居计数中删除，只留下距离 x 到 y 恰好两步的节点。 
5.处理完所有节点后，扫描ans寻找最大值的节点。 如果多个节点共享最大值，则可以返回其中任何一个。 

### 为什么它有效

 对于任何固定节点 x，距离恰好为 2 的每个节点都必须显示为 x 的某个邻居 y 的邻居。 由于图是一棵树，任何两个节点之间都存在一条简单路径，因此不存在循环重复计算。 当对 x 的所有邻居 y 求和 deg(y) − 1 时，距离为 2 的每个有效节点只被计数一次，因为它对应于来自 x 的唯一路径上的唯一中间邻居 y。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        g = [[] for _ in range(n + 1)]
        deg = [0] * (n + 1)

        for _ in range(n - 1):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)
            deg[u] += 1
            deg[v] += 1

        ans = [0] * (n + 1)

        for x in range(1, n + 1):
            total = 0
            for y in g[x]:
                total += deg[y] - 1
            ans[x] = total

        best_node = 1
        best_val = ans[1]

        for i in range(2, n + 1):
            if ans[i] > best_val:
                best_val = ans[i]
                best_node = i

        print(best_node, best_val)

if __name__ == "__main__":
    solve()
```该解决方案首先在线性时间内构造邻接表和度计数。 然后，核心计算通过求和其邻居的贡献来独立评估每个节点。 每个邻居减一是防止对原始节点本身进行计数的关键修正。 

最终扫描是一个简单的线性扫描来定位最大值。

 ## 边缘情况

 二节点树，例如`1 - 2`为两个节点生成零个朋友。 该算法很自然地处理这个问题，因为每个节点恰好有一个度数为 1 的邻居，因此每个贡献在减一后都变为零。 

星形树是最重要的压力情况。 对于连接到所有其他节点的中心节点，每个叶子对中心的贡献为零，而每个叶子通过中心累积所有其他叶子。 该公式正确地将最大值分配给中心，而无需任何遍历。 

长路径测试跨低度节点的积累。 内部节点有两个邻居，均为二级，产生零贡献，而端点在距离二处正确地累积了一个节点。
