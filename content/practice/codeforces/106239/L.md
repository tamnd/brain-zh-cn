 ## 解决方案
 ## 问题理解

 我们给出了一组$n$不同的问题类型，每种问题都与预期概率比相关$p_i / q_i$该模型对预计有多少参与者解决该问题进行了建模。 有$m$参与者总数，因此对于每种问题类型，我们通过缩放该概率来估计需要多少该颜色的气球$m$并四舍五入到最接近的整数。 

每个问题类型都已经准备了一定数量的气球。 如果准备的数量不足以满足预计的需求，我们会购买缺少的数量。 如果足够了，我们对该类型不做任何事情。 任务是计算所有问题类型中必须额外购买的气球总数。 

输入规模非常小，最多有 14 个问题类型和最多 200 名参与者。 这立即告诉我们，任何解决方案，即使对每个项目进行简单的算术，也很容易足够快。 唯一真正的微妙之处是舍入步骤的正确性，因为浮点计算是有风险且不必要的。 

一个常见的陷阱是计算$m \cdot p_i / q_i$使用浮点运算，然后应用强制转换或舍入。 这可能会引入精度误差，尤其是当值接近整数边界时。 另一个微妙的问题是忘记正确应用上限，例如直接使用整数除法，这会截断而不是向上舍入。 

一个具体的失败例子是$m = 10$,$p = 1$,$q = 11$。 真实值为$10/11$，在上限之后应变为 1。 整数除法会得到 0，这会低估需求并导致错误的短缺计算。 

## 方法

 蛮力方法本质上已经是最佳的。 对于每种问题类型，我们使用定义直接计算所需的气球数量，然后将其与现有可用的气球数量进行比较。 每个项目的成本是恒定的，因此总运行时间与$n$，最多为 14。 

如果要使用浮点算术字面解释计算，那么实现仍然是微不足道的，但正确性变得脆弱。 关键的见解是所需的值是有理数的上限$m \cdot p_i / q_i$，并且可以使用整数算术来精确计算，而不存在任何除法精度问题。 

这种转换来自于以完全避免分数的方式重写上限运算。 我们不计算实数并四舍五入，而是计算$\lceil x/y \rceil = (x + y - 1) // y$，保证所有正整数的正确性。 这完全消除了浮点并使计算既精确又安全。

 | 直接浮点计算 | O(n) | O(1) | O(1) | 有风险|

 ## 算法演练

 1. 对于每种问题类型，计算总预期需求分子为$m \cdot p_i$。 这表示参与者缩放的已解决实例的预期总数。 
2. 使用公式将比率转换为整数上限$(m \cdot p_i + q_i - 1) // q_i$。 这确保了除法后有余数时我们总是四舍五入。 
3. 将计算出的需求与已有的气球进行比较$w_i$。 如果要求更大，则计算差值。 
4. 将所有正差值累加到总和中。 该总和代表必须购买的气球总数。 
5. 输出处理完所有问题类型后的最终累加值。 

### 为什么它有效

 每个问题类型都是独立的，因此总需求只是个别短缺的总和。 上限公式保证每个$need_i$是不小于真实分数期望的最小整数。 由于我们仅在供应不足时购买，因此对答案的每个贡献正是该类型的赤字，并且类别之间不存在可能使求和无效的相互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    ans = 0

    for _ in range(n):
        p, q, w = map(int, input().split())
        need = (m * p + q - 1) // q
        if need > w:
            ans += need - w

    print(ans)

if __name__ == "__main__":
    solve()
```直接按照推导公式实现。 关键是整数上限计算，它完全避免了任何浮点运算。 乘法$m * p$是安全的，因为约束很小，并且 Python 本身可以处理大整数。 减法步骤受到保护，因此我们只累积短缺，确保我们不会错误地将剩余添加为负值。 

## 工作示例

 考虑具有三种问题类型的情况，其中$m = 10$。 假设输入是$(p, q, w)$作为$(1, 1, 0)$,$(50, 100, 10)$， 和$(1, 11, 0)$。 

对于第一种类型，要求是$\lceil 10 \cdot 1 / 1 \rceil = 10$，所以短缺量为$10$。 

对于第二种类型，要求是$\lceil 10 \cdot 50 / 100 \rceil = \lceil 5 \rceil = 5$，并且自从$w = 10$，无需购买。 

对于第三种类型，要求是$\lceil 10 \cdot 1 / 11 \rceil = 1$，所以短缺量为$1$。

 ## 边缘情况

 一种重要的边缘情况是现有气球已经完全满足计算的要求。 对于像这样的输入$m = 10$,$p = 50$,$q = 100$,$w = 5$，要求变为$\lceil 5 \rceil = 5$。 该算法计算出的赤字为零，因为比较`need > w`失败。 这证实了平等不会引发不必要的购买。 

另一种情况是真实小数值刚好高于整数边界。 为了$m = 7$,$p = 2$,$q = 3$，我们得到$14/3$。 公式$(14 + 2)/3$确保正确舍入为 5，而不是 4。简单的整数除法会产生 4，并默默地少算 1，这直接破坏了正确性。
