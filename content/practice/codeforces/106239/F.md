 ## 解决方案
 ## 问题理解

 该平面包含一个正方形区域$0$到$N$在两个轴上。 在这个区域内，我们有许多无限的直线，每条直线都有重量。 每条线都是斜率$+1$，写为$y = x + b$，或斜率$-1$，写为$y = -x + c$。 每条线都将其权重贡献给它所经过的每个点，并且在任何一点，总能量是覆盖该点的所有线的权重之和。 

任务是选择正方形内部或边界上的任意点，并最大化该点的总能量。 最优点不需要是整数坐标，也不需要是直线交点； 它可以位于连续区域中的任何位置。 

约束足够严格，不可能迭代候选点。 高达$10^5$每个测试的行数和跨测试的总和由$10^5$，任何尝试检查所有交叉点或直接对平面进行采样的解决方案都将超出时间限制。 有效的方法必须将连续几何图形简化为可管理的离散结构，并避免线之间的二次相互作用。 

一个微妙的困难是，最佳点可能位于不发生线相交的区域。 例如，如果所有线在一个方向上平行并且高度集中在一条带中，则最大值可能出现在连续线段的任何位置。 

另一个问题是最优点不一定位于整数坐标处。 即使在小情况下，仅评估线相交的简单方法也会失败。 

考虑这个例子：

 输入：```
N = 2
1 line: y = x (weight 10)
1 line: y = -x + 2 (weight 10)
```两条线相交于$(1,1)$，并且该点是最优的。 但是如果我们稍微移动一条线，这样它们就不会在正方形内相交，比如说$y = x + 1$和$y = -x + 1$，则沿着边界附近的线段而不是在离散的交点处实现最大值。 仅依赖交叉点的方法会错过这一点。 

关键的难点在于平面是连续的，但线条的结构是高度对齐的。 

## 方法

 直接的暴力视图会尝试考虑正方形中的每个可能的点并计算有多少条线穿过它。 这是不可行的，因为空间是连续的。 即使我们将自己限制在直线的交点上，也有$O(Q^2)$这些点，这远远超出了限制$Q = 10^5$。 

重要的结构来自于所有线都只属于两个方向这一事实。 这表明坐标变换将几何图形转变为轴对齐结构。 

定义新变量：$$u = x + y, \quad v = x - y$$在这样的改造下，每一行都变得极其简单。 一条线$y = x + b$变成$x - y = -b$，这意味着它对应于一个常数$v$。 同样，一行$y = -x + c$变成$x + y = c$，这意味着它对应于一个常数$u$。 

这意味着每条线都沿着单个水平或垂直线贡献重量$(u, v)$-空间。 问题变成选择一个点$(u, v)$最大化：$$U(u) + V(v)$$在哪里$U(u)$是所有线的权重总和$x+y = u$， 和$V(v)$是所有线的权重总和$x-y = v$。 

剩下的复杂问题是，并非所有$(u, v)$对有效。 原始约束$0 \le x, y \le N$变成：$$0 \le \frac{u+v}{2} \le N, \quad 0 \le \frac{u-v}{2} \le N$$简化为：$$-u \le v \le u, \quad 0 \le u \le 2N$$所以有效区域是一个菱形约束$(u,v)$-空间。 

现在的问题纯粹是：最大化$U(u) + V(v)$在受单调约束限制的矩形值网格上$|v| \le u$。 两个都$U$和$V$是仅在给定坐标处定义的分段常数函数。 

对所有事件坐标对进行强力扫描仍然会导致$O(Q^2)$。 关键的观察结果是，最优解决方案只需要考虑临界值$u$和$v$，和边界条件$v = \pm u$，因为事件坐标之间的函数都不会改变。 

因此，我们将搜索减少到扫过排序$u$- 值同时保持可以查询最大值的结构$V(v)$里面$[-u, u]$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对点或交叉点进行暴力破解 |$O(Q^2)$|$O(Q)$| 太慢了|
 | 坐标变换+扫描+范围最大值|$O(Q \log Q)$|$O(Q)$| 已接受 |

 ## 算法演练

 我们现在将几何问题转换为约束下的两个独立的一维加权坐标。 

1. 将每一行转化为一个坐标事件。 对于每一行$y = x + b$, 计算$v = -b$并将其重量添加到位置$v$。 对于每一行$y = -x + c$, 计算$u = c$并将其重量添加到位置$u$。 这将创建两个稀疏映射：一张超过$u$和一过$v$。 
2.收集所有不同的$u$- 坐标和$v$- 坐标并对它们进行排序。 这些是目标函数可以改变值的唯一地方。 他们之间，两人$U$和$V$保持不变。 
3. 构建一个结构$v$- 允许在时间间隔内进行快速最大查询的值。 因为我们只需要最大$V(v)$超出范围$[-u, u]$，线段树或坐标压缩数组可以工作。 
4. 对于每位候选人$u$, 计算$U(u)$直接来自预先计算的地图。 然后查询最大值$V(v)$在范围内$[-u, u]$。 将它们结合起来得到候选答案。 
5.唯一的$u$- 需要测试的值是事件位置$U(u)$变化，以及约束边界处的值$u = |v_i|$变得活跃。 这确保我们不会错过可行的过渡$v$-范围开始包括新的段$V$结构。 
6. 在所有候选者中取最大值。 

这样做的原因是两者$U(u)$和$V(v)$是阶跃函数。 在连续的事件坐标之间，两个函数都不会发生变化，并且只有在跨越断点时，扩大或缩小可行间隔才有意义$V$或者与约束区域的边界对齐。 因此，当我们恰好处于不连续点时，必定会出现最优值$U$，或主动$v$-范围边界触及不连续性$V$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        N, Q = map(int, input().split())

        U = {}
        V = {}

        u_vals = set()
        v_vals = set()

        for _ in range(Q):
            t, x, y, e = map(int, input().split())
            if t == 1:
                v = x - y  # = -b
                V[v] = V.get(v, 0) + e
                v_vals.add(v)
            else:
                u = x + y  # = c
                U[u] = U.get(u, 0) + e
                u_vals.add(u)

        v_list = sorted(v_vals)
        u_list = sorted(u_vals)

        if not v_list:
            # only u-lines
            print(max(U.values()))
            continue
        if not u_list:
            # only v-lines
            print(max(V.values()))
            continue

        v_index = {v:i for i, v in enumerate(v_list)}
        seg = [0] * (4 * len(v_list))

        def build(i, l, r):
            if l == r:
                seg[i] = V[v_list[l]]
                return
            m = (l + r) // 2
            build(i*2, l, m)
            build(i*2+1, m+1, r)
            seg[i] = max(seg[i*2], seg[i*2+1])

        def query(i, l, r, ql, qr):
            if ql <= l and r <= qr:
                return seg[i]
            if r < ql or l > qr:
                return 0
            m = (l + r) // 2
            return max(
                query(i*2, l, m, ql, qr),
                query(i*2+1, m+1, r, ql, qr)
            )

        build(1, 0, len(v_list)-1)

        ans = 0

        for u in u_list:
            base = U[u]

            L = -u
            R = u

            # find indices in v_list
            import bisect
            l = bisect.bisect_left(v_list, L)
            r = bisect.bisect_right(v_list, R) - 1

            if l <= r:
                best_v = query(1, 0, len(v_list)-1, l, r)
                ans = max(ans, base + best_v)
            else:
                ans = max(ans, base)

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将这两个线族转换为两个独立的权重数组，这些数组由转换后的坐标索引。 线段树是建立在所有$v$- 坐标以支持范围内的最大查询。 对于每个$u$-坐标，代码计算可行区间$v$值作为$[-u, u]$，然后查询最佳可实现的$V(v)$在该区间内并将其与$U(u)$。 

一个微妙的点是仅使用事件坐标$u$，因为他们之间$U(u)$不会改变。 这可确保扫描在范围查询的对数因子范围内保持线性。

 ## 边缘情况

 当所有行仅属于一个族时，就会出现一种关键的边缘情况，这意味着要么全部都是$u$-行或全部是$v$- 线。 在这种情况下，答案会简化为简单的权重最大值，因为最佳点始终可以放置在满足约束的任何位置，而不会影响缺失的维度。 该算法明确地检查这一点并避免空范围查询。 

当最好的时候会出现另一种边缘情况$v$-对于给定的范围为空$u$。 发生这种情况时$|u|$小于所有现有的$v$- 坐标。 在这种情况下，代码正确地回退到仅使用$U(u)$，因为没有$v$-line 可以被激活。 

最后一个微妙的情况是当最佳点恰好位于边界上时$v = \pm u$。 这些点对应于$x=0$或者$y=0$在原始坐标中。 转换准确地保留了它们，并且因为我们使用包含二等分处理在范围查询中包含边界，所以完全捕获了这些情况。
