 ## 解决方案
 ## 问题理解

 我们被要求计算 Adilbek 在固定时间内可以完全解决的填字游戏的预期数量，假设每个填字游戏需要`t_i`或者`t_i + 1`秒以相同的概率独立。 他严格按照顺序做填字游戏，当总时间达到或超过时立即停止`T`。 我们要计算的期望值是所有可能完成的填字游戏数量的概率加权和。 

输入给出`n`，填字游戏的数量，`T`、总可用时间和列表`t`个人填字游戏时间。 输出是期望值，表示为`P * Q^{-1} mod 10^9+7`在哪里`P/Q`是理性预期值。 

约束很严格：`n`最多可达 2·10^5 并且`T`最多 2·10^14。 这排除了任何考虑所有因素的暴力方法`2^n`完成时间的顺序。 简单的递归或显式概率表会太慢。 每个`t_i`最大为 10^9，因此必须小心处理累积和以避免整数溢出。 

边缘情况包括以下情况`T`小于第一个填字游戏时间（预期值应为 0）或恰好足以满足一个填字游戏（预期值可能是小数）。 当多个填字游戏具有相同的时间时，会出现另一种微妙的情况 - 完成的概率分布涉及 1/2 的幂，并且需要精确的模运算。 

## 方法

 朴素的方法考虑每一个可能的成功序列和额外的秒延迟，计算完成 0、1、... 的精确概率，`n`填字游戏。 对于每个填字游戏，有两个选项，给出`2^n`总序列。 为了`n=2*10^5`，这是不可行的。 

关键的见解是期望的线性。 我们不需要考虑延迟的所有组合。 Adilbek 完成的填字游戏的预期数量是他及时完成每个填字游戏的概率之和。 如果`dp[i]`表示之后总时间上的概率分布`i`填字游戏，的预期贡献`(i+1)`第 - 个填字游戏只是完成所有先前填字游戏并有足够剩余时间的概率之和。 

我们可以使用累积概率的滑动窗口有效地实现这一点。 让`prefix[i]`是次数的总和`t[0..i-1]`。 如果之后还有时间`i`填字游戏超过`T - t[i]`，填字游戏肯定完成了； 如果超过`T - t[i] - 1`，以 1/2 的概率完成。 这将问题简化为计算序列上的累积和并应用 1/2 的幂。 模逆处理模算术下的 1/2 因子。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 线性期望 + 前缀和 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算填字游戏时间的前缀和。 这给出了`S[i] = t_0 + t_1 + … + t_{i-1}`。 这些代表完成第一个任务的最短时间`i`填字游戏。 
2. 计算 2 的模逆，因为每多一秒发生的概率就是 1/2。 模逆将允许概率计算`10^9+7`。 
3. 初始化变量`prob`1 代表之前所有填字游戏在最短时间内完成的概率。 
4. 迭代每个填字游戏`i`。 如果累计总和`S[i] + t[i]`小于或等于`T`，填字游戏肯定完成了。 添加`prob`到预期值。 如果`S[i] + t[i] + 1`小于或等于`T`，填字游戏完成的概率为 1/2； 添加`prob * 1/2`。 乘`prob`考虑到额外一秒的情况后，减少了 1/2，因为继续完成后续填字游戏的概率减半。 
5. 迭代完所有填字游戏后，我们得到了有理分数形式的期望值`P/Q`。 乘以`Q^-1 mod 10^9+7`以获得最终答案。 

为什么有效：期望的线性使我们能够独立地对每个填字游戏的预期贡献求和。 前缀和确保我们只考虑可行的完成。 1/2 的幂正确地考虑了额外的秒延迟，同时避免了序列的指数枚举。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def main():
    n, T = map(int, input().split())
    t = list(map(int, input().split()))
    
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + t[i]
    
    inv2 = modinv(2)
    expected = 0
    prob = 1
    
    for i in range(n):
        if prefix[i + 1] <= T:
            expected = (expected + prob) % MOD
        elif prefix[i] + t[i] <= T:
            expected = (expected + prob * inv2) % MOD
            prob = (prob * inv2) % MOD
            break
        else:
            break
        prob = (prob * inv2) % MOD

    print(expected)

if __name__ == "__main__":
    main()
```该解决方案从前缀和开始，以实现最短的完成时间。 我们显式处理模逆以避免浮点运算。 这`prob`变量保持所有先前填字游戏在最短时间内完成的概率。 乘以`inv2`模拟下一个填字游戏多花一秒钟的机会。 边缘情况自然可以通过前缀和比较来处理。
