 ## 解决方案
 ## 问题理解

 在这个问题中，我们得到二维平面上的一组点，每个点代表特定位置的温度测量。 我们被要求找到可以形成的最大正方形，使得其中的所有点都满足与温度相关的特定标准（例如，低于阈值或形成凸形状 - 取决于确切的陈述）。 输出通常是该正方形的大小或定义它的一组特定坐标。 

输入由点数及其后面组成`(x, y)`坐标。 如果问题涉及多个测试用例，则每个测试用例都是独立的，必须单独处理。 输出必须精确：要么是代表最大平方的数值，要么是特定顺序的坐标。 

约束条件很重要：点数可以很大，最多可达 10^5，坐标值也可以很大，最多可达 10^9。 这排除了任何显式检查每个可能的正方形的解决方案，因为这将需要每个测试用例进行 O(n^2) 次操作，这太慢了。 我们需要一个在每个测试用例的 O(n log n) 或 O(n) 时间内工作的解决方案。 

边缘情况包括所有点共线、多个点共享相同坐标或最大正方形必须与轴对齐但没有点正好位于其角点的情况。 简单的边界框方法可能会错过这些，从而产生太小或未对齐的正方形。 

## 方法

 蛮力方法很简单：将每对点视为正方形的潜在对角，计算其他两个角，并检查所有点是否满足正方形内的条件。 这是有效的，因为正确的正方形必须具有与现有点重合或由现有点确定的角。 然而，这需要检查 O(n^2) 点对，并且对于每对验证正方形内的所有点给出 O(n^3)，这对于 n = 10^5 来说是不可行的。 

关键的见解来自几何。 与可覆盖一组点的轴对齐的最大正方形完全由极值 x 和 y 坐标确定。 我们只需跟踪所有点的最小和最大 x 和 y 值，而不是检查每对点。 最大正方形的边长是最大的`(max_x - min_x)`和`(max_y - min_y)`，因为正方形必须覆盖两个维度的全部分布。 如果问题允许旋转，则解决方案需要考虑凸包并使用旋转卡尺方法，由于按角度对点进行排序，该方法仍然可以在 O(n log n) 中工作。 

这一观察结果将解决方案从三次或二次蛮力简化为线性或线性算术复杂性，具体取决于是否考虑旋转。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了|
 | 极限坐标/凸包| O(n) 或 O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取点数`n`和名单`(x, y)`坐标。 这会初始化用于处理的数据结构。 
2. 计算最小和最大 x 坐标 (`min_x`,`max_x`）以及最小和最大 y 坐标（`min_y`,`max_y`）。 每个极值都是沿该轴的最远点。 
3. 计算最大轴对齐正方形的边长为`side = max(max_x - min_x, max_y - min_y)`。 这确保了正方形跨越所有点。 
4. 或者，如果问题询问正方形的坐标，请选择一个角作为`(min_x, min_y)`并构造有边的正方形`side`。 如果允许旋转，则计算凸包并应用旋转卡尺找到凸包内的最大平方。 
5. 根据需要输出计算出的边长或坐标。 

这样做的原因是任何覆盖所有点的轴对齐正方形必须至少跨越两个轴的极值坐标。 扩展较小的维度可确保正方形有效。 不变量是在步骤2之后，`min_x ≤ all_x ≤ max_x`和`min_y ≤ all_y ≤ max_y`，这保证没有点位于步骤 3 中计算的平方之外。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        xs = []
        ys = []
        for _ in range(n):
            x, y = map(int, input().split())
            xs.append(x)
            ys.append(y)
        min_x = min(xs)
        max_x = max(xs)
        min_y = min(ys)
        max_y = max(ys)
        side = max(max_x - min_x, max_y - min_y)
        print(side)

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量。 对于每个测试用例，它分别收集 x 和 y 坐标以有效计算最小值和最大值。 最大边长是使用边界框的宽度和高度的最大值来计算的。 我们使用`max`用于平方大小的单遍计算。 通过仔细使用极值并计算最大差值（而不是指数）可以避免相差一的错误。

 ## 边缘情况

 如果所有点都在同一位置，`min_x = max_x`和`min_y = max_y`， 所以`side = 0`。 该算法无需特殊处理即可正确输出 0。 对于形成一条线的点，该算法会扩展较小的尺寸以匹配较大的尺寸，从而生成一个有效的正方形。 如果需要，可以通过考虑凸包来处理旋转配置，但对于轴对齐的正方形，极端坐标方法就足够了。
