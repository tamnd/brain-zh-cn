 ## 解决方案
 ## 问题理解

 我们得到了一系列排列成一直线的门。 每扇门要么打开，要么关闭。 Yousef 在第一扇门之前开始，并且必须严格按顺序从 1 号门移动到 n 号门。 通过打开的门会花费时间，而关闭的门会完全阻止移动，除非使用特殊能力。 

特殊能力是持续一段连续时间窗口的单次激活`x`。 在该窗口期间，所有关闭的门都像打开的门一样，允许通过。 窗外，紧闭的门仍然无法通行。 

问题是是否存在一种方法可以选择一个时刻来激活此能力，以便尤瑟夫可以从左到右穿过所有门而不会被卡住。 

输入尺寸非常小，`n ≤ 10`和`x ≤ 10`，因此即使每个测试用例尝试多种可能性的方法也是可行的。 然而，单次激活的存在会产生全局约束：一旦使用该能力，其时间必须与紧闭的门的连续区域保持一致，否则会阻碍进度。 

当关闭的门被分成多个独立的组时，就会出现关键边缘情况。 例如，如果关闭的门出现在序列的早期和晚期，并且它们之间有很长的开放间隙，那么短的激活窗口可能无法同时覆盖两个组。 

另一个重要的情况是当所有关闭的门都紧密排列但其跨度大于`x`。 例如，如果`x = 2`并且有4个连续关闭的门，那么即使最佳时机也无法覆盖所有门。 

最后，第一扇或最后一扇门关闭可能会产生误导。 一种天真的方法可能假设在第一个关闭的门处启动按钮总是有效，但如果后来关闭的门出现在激活窗口之外，则遍历失败。 

## 方法

 暴力方法会模拟每一个可能的时刻来激活按钮，然后模拟一步一步穿过门。 对于每个激活的起始位置，我们通过仅在选定的时间间隔内将关闭的门视为打开来检查 Yousef 是否可以通过所有门。 

由于最多有`n`可能的激活起点和每次模拟成本`O(n)`，这会产生一个`O(n^2)`每个测试用例的解决方案，这已经是微不足道的了`n ≤ 10`。 然而，我们可以通过避免完全模拟来进一步简化。 

关键的观察结果是，该按钮仅对连续的关闭的门块起作用。 如果尤瑟夫在激活窗口外遇到关着的门，他会立即停下来。 因此，唯一重要的是关闭的门的最长连续段，因为该段决定了连续通过所有阻塞位置所需的最小时间窗口。 

一旦我们确定了连续运行的最大长度`1`是，问题简化为检查此运行是否适合激活窗口`x`。 如果最长的这样的线段大于`x`，那么任何按钮的放置都无法完全覆盖它，并且遍历变得不可能。 否则，我们始终可以对齐激活窗口以完全覆盖该段，同时遍历路径的其余部分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n^2) | O(n^2) | O(1) | O(1) | 已接受 |
 | 最大连续块| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从左到右扫描阵列，同时跟踪当前连续的关闭的门块的长度。 

每次我们看到一个`1`，我们扩展当前块。 当我们看到一个`0`，我们将块长度重置为零。 
2. 维护一个变量`best`它存储迄今为止遇到的最大块长度。 

该值代表优素福必须在不间断的一段时间内克服的最困难的连续障碍。 
3.处理完整个数组后，进行比较`best`和`x`。 

如果`best`大于`x`，那么即使是最好的激活窗口也无法覆盖全部阻塞。 
4. 如果`best`小于或等于`x`，输出“YES”，否则输出“NO”。 

我们只跟踪连续块的原因是，分离的关闭的门不会在单个激活窗口下交互，除非它们在时间上处于单个连续段内。 由于 Yousef 每秒确定地向前移动一扇门，因此时间顺序与索引顺序直接对齐。 

### 为什么它有效

 该算法依赖于这样一个不变量：任何未能通过的情况都必须发生在超过按钮持续时间的连续关闭的门段内。 由于 Yousef 严格从左向右移动，并且每扇门只花费一个时间单位，因此任何激活窗口也对应于一个连续的索引段。 因此，唯一重要的约束是是否存在连续的段`1`s 长于`x`。 如果不存在，我们总是可以调整激活以覆盖每个必要的阻塞位置，而不会错过其他地方的进度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    best = 0
    cur = 0
    
    for v in a:
        if v == 1:
            cur += 1
            best = max(best, cur)
        else:
            cur = 0
    
    print("YES" if best <= x else "NO")
```该实现只保留两个变量，`cur`和`best`。 这`cur`计数器测量当前关闭的门的连续次数，并且每当打开的门中断连续次数时它就会重置。 这`best`变量存储观察到的最大条纹。 

一个微妙的点是，我们不需要显式模拟 Yousef 的移动或激活时间。 移动的线性结构确保任何可行的策略仅依赖于连续的块，因此将问题减少到单次扫描就足够了。

这强调了条件取决于所需的阻塞位置是否在遍历期间形成单个连续的段。

 ## 边缘情况

 像这样的最小情况`n = 1`单扇关闭的门测试算法是否正确地将单个元素视为有效的连续块。 扫描产生`best = 1`，以及与`x`行为正确。 

完全阻塞的数组，例如`1 1 1 1 1`检查算法是否不会过早地重置或错误地分割段。 计数器不断增长，产生正确的最大段长度。 

混合模式，例如`0 1 1 0 1 1`确保正确处理开门时的重置。 该算法记录两个单独的块并仅保留最大值，这反映了对激活的真实约束。
