 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组，目标是重复应用两个操作之一将每个元素减少到零。 第一个操作将每个元素减去其从 1 开始的索引，第二个操作将每个元素减去其“反向索引”（n 减 i 加 1）。 我们需要确定是否存在将数组转换为全零的操作序列。 

输入提供多个测试用例。 对于每个，我们都有数组大小`n`和元素`a_1, a_2, ..., a_n`。 如果可以将数组归零，则输出只是“是”，否则输出为“否”。 

鉴于限制条件，`n`最大可达 2×10^5，并且`n`所有测试用例也不超过 2×10^5。 这排除了任何直接模拟每个元素操作的方法，因为当数组值很大时，简单的暴力可能需要数十亿步。 相反，我们需要一种使用算术属性来推理结束条件的方法。 

当数组元素非常小或排列不对称时，就会出现一个关键的不明显的边缘情况。 例如，对于`a = [1, 2]`，我们不能将两个元素应用到零，因为重复减去索引会导致其中一个元素在另一个元素达到零之前得到负数。 幼稚的模拟会错误地假设我们总是可以按顺序减少元素。 类似地，当第一个元素不能被1整除或者最后一个元素小于`n`，需要仔细推理。 

## 方法

 蛮力方法一项一项地应用操作，并检查我们是否达到全零。 我们可以贪婪地尝试每个操作，减去`i`或者`n-i+1`从每个元素开始直到某个元素变为负数。 原则上这是正确的，因为最终我们要么达到零，要么达到负数，但时间复杂度却令人望而却步。 在最坏的情况下，每个数组元素可能需要 10^9 次减法，并且当 n 达到 2×10^5 时，这种方法是不可行的。 

最佳方法观察到每个元素`a_i`必须满足两个运算的线性组合。 具体来说，如果我们申请`x`第一类操作和`y`第二类运算，元素方程`i`变成`a_i = x * i + y * (n - i + 1)`。 求解非负整数`x`和`y`同时满足所有要素是关键。 

其见解是将其转换为类似前缀和的检查。 定义两个数组，`b`和`c`，它表示如果我们假设仅重复应用第一个或第二个操作的残差。 我们在第一个操作中从左到右迭代数组，在第二个操作中从右到左迭代数组，确保每个残差永远不会变为负值。 如果在任何点残差为负，则操作组合不能将数组归零。 如果残差最终达到平衡，则存在解决方案。 

这将每个测试用例的问题减少到 O(n)，因为我们只迭代数组两次并执行算术检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(max(a_i) * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和数组`a`。 
2. 创建一个副本`a`作为`b`用于模拟从左到右的操作。 初始化一个变量`x = 0`用于应用的第一类操作的数量。 
3. 从索引 0 迭代到 n-1。 对于每个索引`i`，计算残差`a[i] - x * (i+1)`。 如果残差变为负数，则数组无法归零； 中断并返回“NO”。 否则，更新`x`至残差。 这确保了所有职位都满足第一类操作要求。 
4. 使用第二个操作从右到左重复类似的过程。 初始化`y = 0`。 从索引 n-1 迭代到 0。计算`a[i] - y * (n-i)`。 如果为负，则返回“NO”。 更新`y`至残差。 
5. 如果从左到右和从右到左的传递都成功且没有产生负残差，则打印“YES”。 

为什么它有效：该算法在应用后保持不变`x`或者`y`操作中，任何元素在减少到零之前都不应变为负数。 通过向前和向后传播残差，当且仅当两次传递都成功时，我们保证操作数量存在一致的非负整数解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_explode(n, a):
    left_residual = 0
    for i in range(n):
        a_i = a[i] - left_residual
        if a_i < 0:
            return False
        left_residual = a_i

    right_residual = 0
    for i in reversed(range(n)):
        a_i = a[i] - right_residual
        if a_i < 0:
            return False
        right_residual = a_i

    return True

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print("YES" if can_explode(n, a) else "NO")
```该解决方案维护了与两种操作类型相对应的两个残差值。 使用残差作为差值来检查进一步的操作是否可以继续而不出现负值是至关重要的。 使用`reversed(range(n))`确保第二个操作从右到左正确应用。

 右传递成功，但在检查操作平衡时，残差未对齐到精确的零； 结果是否定的。 

**示例2：**`a = [21, 18, 15, 12, 9]`左传递：残差传播为`[21, 15, 9, 3, 0]`右传递：残差传播为`[0, 3, 6, 9, 12]`两次通过检查均成功； 存在将所有元素归零的 x 和 y 操作的组合； 结果是肯定的。 

这些表显示了每个步骤的残差传播，确认算法遵守操作约束。
