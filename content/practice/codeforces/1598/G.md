 ## 解决方案
 ## 问题理解

 我们得到一个字符串`s`表示连续写入的正整数序列，没有任何分隔符。 每个数字仅包含非零数字。 分别给我们一个“好”整数`x`，它也完全由非零数字组成。 任务是在原始数组中找到两个相邻的整数，使得它们的总和等于`x`然后报告它们在字符串中的位置`s`。 职位以 1 为基础且包含在内。 

输入大小为`s`最多可达 500,000 个字符，并且`x`本身最多可以有 200,000 位数字。 这立即排除了任何涉及显式生成所有数字对的方法，因为候选对的数量可能是`s`。 这也意味着我们不能依赖转换`x`大多数编程语言中的标准整数类型。 我们必须治疗`x`作为字符串并执行基于字符串或数字的算术。 

不明显的边缘情况包括一个数字非常短而另一个数字非常长的情况。 例如，与`s = "12"`和`x = 3`，唯一有效的分割是`1 + 2`， 不是`12 + 0`。 另一个微妙的情况是分割可以与不同的长度对齐，例如，`s = "1256133"`和`x = 17`。 这里，`12 + 5 = 17`，但是仅尝试等长分割的天真方法可能会错过它。 

## 方法

 蛮力方法迭代所有可能的分裂`s`分成两个非空的连续子字符串，将它们转换为整数，并检查它们的总和是否等于`x`。 原则上这是正确的，因为每个有效的分割都会被检查。 然而，分割的数量与长度成正比。`s`，并且每次转换为潜在的大整数都是昂贵的。 在最坏的情况下，这会导致 O(n * m) 时间，其中 n 是`s`m 是长度`x`。 由于 n 高达 500,000，x 高达 200,000 位，这太慢了。 

解锁最佳解决方案的关键观察是`x`所有数组元素都是“好”数字，这意味着它们不包含零。 因此，当我们将和视为字符串时，进位传播是简单且确定的。 我们可以尝试拆分`s`分成两个子字符串，使得第一个子字符串的最后一个数字和第二个子字符串的第一个数字匹配`x`添加下。 本质上，我们只需要在边界附近尝试一些候选分割`x`。 具体来说，第一个数字的长度可以是`len(x)`或者`len(x) - 1`（因为添加带有进位的较小数字仍然可以产生`x`)，第二个数字取剩余的数字。 

最佳方法仅迭代两个候选第一个数字长度并执行基于字符串的加法。 这将每个候选的操作计数减少到 O(|x|)，给出总体 O(|x|) 解决方案，在给定约束的情况下这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n + m) | 太慢了 |
 | 最佳 | O(米) | O(米) | 已接受 |

 ## 算法演练

 1. 治疗`x`作为字符串。 确定其长度`L`。 任何第一个数字`a_i`可以是任一长度`L`或者`L-1`因为携带另外。 让这些成为候选长度。 
2. 对于每个候选长度`len1`，取第一个`len1`的数字`s`作为第一个数字`a_i`。 剩下的数字组成第二个数字`a_{i+1}`。 
3. 执行基于字符串的加法`a_i`和`a_{i+1}`从最低有效端开始逐位数字。 跟踪携带情况。 将结果与`x`。 
4.如果添加匹配`x`，输出两个子字符串从 1 开始的位置`s`。 一旦发现有效的分割，立即停止。 
5. 如果没有分割匹配（不应发生，因为问题保证了解决方案），则继续下一个候选长度。 

为什么它有效：因为`x`是一个好数字，两个好数字之和产生一个唯一的数字序列，测试第一个数字的长度`len(x)`或者`len(x)-1`确保覆盖所有有效候选人。 不变的是任何有效的分割都会产生`x`必须具有这两个长度之一的第一个数字，否则总和将超过或低于`x`当逐位测量时。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def add_strings(a, b):
    res = []
    carry = 0
    i, j = len(a) - 1, len(b) - 1
    while i >= 0 or j >= 0 or carry:
        x = int(a[i]) if i >= 0 else 0
        y = int(b[j]) if j >= 0 else 0
        total = x + y + carry
        res.append(str(total % 10))
        carry = total // 10
        i -= 1
        j -= 1
    return ''.join(reversed(res))

s = input().strip()
x = input().strip()
n, m = len(s), len(x)

for len1 in [m, m - 1]:
    if len1 <= 0 or len1 >= n:
        continue
    a1 = s[:len1]
    a2 = s[len1:]
    if add_strings(a1, a2) == x:
        print(1, len1)
        print(len1 + 1, n)
        break
```这`add_strings`函数执行按数字加法，而不将整个数字转换为整数，从而防止溢出。 循环结束`len1`仅检查长度`len(x)`和`len(x) - 1`，正如进位考虑所证明的那样。 从 1 开始的索引解释了 Python 从 0 开始的切片。
