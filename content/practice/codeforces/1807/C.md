 ## 解决方案
 ## 问题理解

 我们得到一个由小写字母组成的字符串，并且允许我们重复地将整个字符类“折叠”为二进制数字。 例如，一次操作选择一封信`x`，并全局重写每次出现的`x`在字符串中`0`或者`1`。 不同的字母可以独立映射，并且每个字母都可以在我们选择它时准确地分配两个二进制值之一。 

为每个字母分配一个二进制值后，结果字符串就变成了一个二进制字符串。 目标是确定我们是否可以选择分配，以便最终的二进制字符串完美交替，这意味着每个相邻的字符对都不同。 

关键的困难在于字符串结构在位置级别不能直接编辑。 我们不能翻转单个字符； 相反，每个字母都充当一个刚性块，必须在所有出现的地方一致地映射。 

约束范围较小，每个测​​试用例总长度最多2000个，最多100个测试用例。 这使得每个测试用例的任何解决方案都达到大致二次方，但如果常数很低，即使是三次方解决方案也可能很难通过。 然而，问题结构强烈表明存在更简单的可行性条件。 

当一个字母同时出现在需要交替模式中不同二进制值的两个位置时，就会出现微妙的边缘情况。 例如，在`aa`，无论我们如何映射`a`，结果总是`00`或者`11`，均无效。 这立即表明，在相互冲突的平价立场上重复字母是主要障碍。 

另一个边缘情况是长度为 1 的字符串。 任何单个字符都可以映射到`0`或者`1`，并且根据定义两者都是有效的交替字符串。 

## 方法

 蛮力观点首先将每个不同的字母视为一个二进制变量。 如果有`k`不同的字母，我们为每个字母分配`0`或者`1`，生产`2^k`作业。 对于每个分配，我们构造结果字符串并检查它是否交替`O(n)`时间。 这导致总复杂度为`O(n · 2^k)`。 在最坏的情况下，所有字符都是不同的，所以`k = n`，搜索空间呈指数增长，即使对于`n = 20`，更不用说`2000`。 

关键的观察结果是交替仅取决于邻接约束。 对于每个索引`i`，我们要求`s[i] != s[i+1]`映射后。 如果有两个位置`i`和`i+1`包含相同的原始字母，那么它们在映射后必须相等，这立即违反了交替。 因此，任何出现在两个相邻位置的字母都会使答案不可能。 

更一般地说，如果我们查看奇偶校验结构，我们就会意识到我们正在尝试为每个字母分配一个值，以便该字母的所有出现都一致地落入必须全局交替的位置。 但交替约束根本不依赖于字母表结构，只依赖于字符串是否包含任何伪装的重复相邻字符。 

这大大简化了：构建失败的唯一原因是某些字母出现在相邻位置。 如果不存在这样的邻接，我们总是可以通过选择任何所需的交替模式并根据每个字母的首次出现位置奇偶性一致地映射每个字母来构造有效的交替二进制字符串。 由于没有字母会强制两个相邻的相同结果，因此始终可以实现一致性。 

因此问题减少到一次扫描检查是否存在索引`i`这样`s[i] == s[i+1]`。

 | --- | --- | --- | --- |
 | 蛮力（尝试所有作业）| O(n·2^k) | O(n·2^k) | O(n) | 太慢了|
 | 最优（相邻检查）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取字符串`s`。 我们只需要检查局部结构，因此不需要预处理。 
2. 从左到右扫描字符串，将每个字符与下一个字符进行比较。 这样做的原因是任何违规都必须来自邻接约束，因为交替仅在邻居之间定义。 
3.如果我们发现`s[i] == s[i+1]`，立即得出答案是`"NO"`。 这是因为同一字母的两次出现必然会映射到相同的二进制值，从而产生相同的相邻位，从而破坏了交替。 
4. 如果扫描完成后没有找到任何相等的相邻字符，则输出`"YES"`。 在这种情况下，我们总是可以以尊重交替模式的方式一致地分配二进制值，因为没有字母在任何边界上强制矛盾。 

### 为什么它有效

 唯一重要的约束是某些字母是否强制两个相邻位置之间相等。 如果存在这样的约束，无论我们如何分配，交替都是不可能的`0`和`1`。 如果不存在这样的约束，则每个邻接都连接两个不同的字母，并且我们可以自由分配二进制值，以便导出的二进制字符串交替，因为没有字母在边缘上创建强制相等。 这将全局分配问题减少为纯粹的本地检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        ok = True
        for i in range(n - 1):
            if s[i] == s[i + 1]:
                ok = False
                break
        
        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```该解决方案独立读取每个测试用例并执行单个线性扫描。 关键的实现细节是一旦发现重复的相邻字符就尽早停止，因为进一步的检查无法改变结果。 

该逻辑不会尝试显式构造二进制字符串，因为可行性仅取决于检测结构上的不可能性，而不取决于模拟分配。

 ## 边缘情况

 单字符情况表明长度为 1 的字符串总是成功，因为不存在要违反的邻接约束。 该算法读取字符串，没有找到`i`这样`s[i] == s[i+1]`，并返回`"YES"`立即地。 

两个相同字符的情况就像`aa`在第一次比较时触发失败条件。 扫描检测到`s[0] == s[1]`，将标志设置为 false，然后停止。 这正确地捕捉到了将相同的相邻字母分成交替的二进制值的可能性。 

没有重复相邻字母的长字符串，例如`abcabcabc`，通过而不触发条件，确认全局可行性完全由局部邻接结构决定。
