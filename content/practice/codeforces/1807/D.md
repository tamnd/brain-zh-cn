 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和一系列查询。 每个查询都会询问，如果我们用固定值覆盖某个子数组中的所有元素，数组的总和是否会变为奇数。 查询不会永久修改数组。 对于每个查询，如果假设覆盖后总和是奇数，我们只需要“是”，如果是偶数，我们只需要“否”。 

数组大小$n$最高可达20万条，查询数量$q$也可以是200,000，但是所有的总和$n$和所有$q$测试用例数量保持在 200,000 以下。 这意味着我们可以为每个测试用例提供线性工作，但不能为每个查询提供线性工作。 一个$O(n \cdot q)$方法立即就太慢了，因为在最坏的情况下，它可能需要$4 \cdot 10^{10}$运营。 

要考虑的边缘情况包括非常小的数组、覆盖整个数组的查询以及替换值非常大的查询。 例如，如果数组是`[2]`并且查询要求将唯一的元素设置为`1`，总和变为`1`这很奇怪，答案是“是”。 为每个查询重新计算整个数组之和的简单方法将适用于小型数组，但不适用于大型数组。 

另一个微妙之处是我们只关心**平价**。 大数本身并不需要完整的算术； 知道它们是奇数还是偶数就足够了。 一个常见的错误是计算大量数字的总和，从而冒着溢出或不必要的计算的风险。 

## 方法

 暴力方法迭代查询范围、替换元素、计算总和并检查奇偶校验。 这是有效的，因为它完全模拟了问题。 对于每个查询，我们最多可以执行$r - l + 1$操作，并且对大小为 200,000 的数组进行 200,000 次查询，这给出了最坏情况$O(n \cdot q) = O(4 \cdot 10^{10})$，这太慢了。 

关键的见解是我们只需要**平价**，而不是全额。 我们可以不替换元素，而是将旧总和减去替换元素的总和加上新值的总和来计算新总和。 令替换范围的长度为$m = r - l + 1$。 新总和的奇偶性为：```
new_sum_parity = (old_sum - sum_of_range + m * k) % 2
```因为只有奇偶校验很重要，所以减法和加法可以模 2 进行。每个元素模 2 要么是 0 要么 1。原始范围模 2 的总和可以使用前缀和数组模 2 来预先计算。乘以替换值$k$通过范围长度$m$模 2 就是简单的$0$如果$k$是偶数或$m % 2$如果$k$很奇怪。 

此观察将查询处理减少为$O(1)$计算原始数组的前缀和后的每个查询。 这对于给定的约束有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * q) | O(n) | 太慢了 |
 | 最佳 | O(n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 计算整个数组模 2 的总和。这表示数组的当前奇偶校验。 我们只需要 0 表示偶数，1 表示奇数。 
2. 计算对 2 取模的前缀和数组。让`prefix[i]`是第一个的模 2 之和`i`元素。 这允许 O(1) 查询任何子数组的和奇偶校验`[l, r]`使用`prefix[r] - prefix[l-1]`模 2。 
3. 对于每个查询`(l, r, k)`，计算长度`m = r - l + 1`。 根据前缀和数组计算范围和模 2 的奇偶校验。 
4. 计算奇偶校验`m * k`。 这是`0`如果`k`是偶数，或者`m % 2`如果`k`很奇怪。 
5. 将新的数组奇偶校验计算为`(total_parity - range_parity + replacement_parity) % 2`。 
6. 如果结果为1，则打印“YES”。 否则，打印“NO”。 

原理：所有算术都是以 2 为模。不变的是任何以 2 为模的加法和减法序列都会给出正确的奇偶校验。 由于每个查询都是独立的，因此我们从不修改实际的数组，而只依赖于预先计算的前缀和和数组总和奇偶校验。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())
        a = list(map(int, input().split()))
        prefix = [0] * (n + 1)
        total_parity = 0
        for i in range(n):
            prefix[i + 1] = (prefix[i] + a[i]) % 2
            total_parity = (total_parity + a[i]) % 2

        for _ in range(q):
            l, r, k = map(int, input().split())
            m = r - l + 1
            range_parity = (prefix[r] - prefix[l - 1]) % 2
            replacement_parity = (m % 2) if (k % 2 == 1) else 0
            new_parity = (total_parity - range_parity + replacement_parity) % 2
            print("YES" if new_parity == 1 else "NO")

if __name__ == "__main__":
    solve()
```该代码首先计算前缀和模 2，以允许快速子数组奇偶校验查询。 然后，每个查询的处理时间为 O(1)，计算替换范围对整体奇偶校验的影响。 微妙之处包括使用`l-1`在基于 1 的索引的前缀数组中，并减少所有算术模 2 以避免出现大数字。
