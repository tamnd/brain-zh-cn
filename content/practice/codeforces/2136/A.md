 ## 解决方案
 ## 问题理解

 我们知道半场的比分和全场的比分。 

如果半场比分是`a:b`，那么上半场RiOI队的得分正好`a`进球数和 KDOI 队得分完全一致`b`目标。 

如果最后的分数是`c:d`，然后在下半场RiOI队得分`c-a`进球数和 KDOI 队得分`d-b`目标。 

唯一的限制是，在每个半场内，任何球队都不能连续进三个球。 两半是独立的。 上半场结束时的连胜并没有延续到下半场。 

对于每个测试用例，我们必须确定是否可以将上半场和下半场的进球进行安排，使得两个半场都不包含同一支球队连续三个进球。 

分数最多为 100，测试用例最多为 1000 个。 这些界限很小。 即使是对每个可能的分数对执行一些计算的解决方案也很容易满足限制。 真正的挑战是确定有效进球序列存在时的数学条件。 

一个常见的错误是只考虑比赛总得分。 该限制分别适用于每一半。 例如：```
a=1 b=4 c=2 d=5
```上半场有进球`1:4`下半场贡献`1:1`。 两半都可以有效排列，所以答案是`YES`。 

另一个容易犯的错误是忘记了没有进球的半场总是有效的。 例如：```
a=4 b=1 c=4 d=1
```下半场零进球。 空序列不能包含三个连续的目标，所以答案是`YES`。 

当一支球队的进球远多于另一队时，就会出现最重要的边缘情况。 例如：```
a=0 b=100
```每一个进球都属于KDOI。 这不可避免地会产生连续 100 个 KDOI 目标，这违反了规则。 仅前半部分是不可能的，所以答案是`NO`。 

## 方法

 蛮力观点对于发现这种情况很有用。 

假设一半包含`x`RiOI 目标和`y`KDOI 目标。 我们可以尝试包含确切计数的所有序列，并检查是否有任何序列避免了三个相同的连续目标。 这是正确的，因为它直接测试有效性的定义。 

问题在于序列的数量巨大。 半程已进 100 个进球`2^100`可能的安排。 穷尽搜索是没有希望的。 

关键的观察是，团队的目标只能出现在长度最多为 2 的块中。 

假设一支球队比另一支球队进球更多。 让```
big = max(x, y)
small = min(x, y)
```这`small`目标可以用作分隔符。 他们最多创造`small + 1`差距：```
_ S _ S _ S _ ...
```在每个差距内，进球较多的球队最多可以贡献 2 个进球，否则会出现 3 球的情况。 

由于有`small + 1`差距，每个差距最多可容纳 2 个进球，较大球队的最大进球数为```
2 * (small + 1)
```因此，有效序列恰好存在于```
big <= 2 * (small + 1)
```这个条件也足够了。 如果成立，我们可以将较大团队的目标分配到可用的差距中，每个差距不超过 2 个。 

我们只需要分别检查上半场和下半场的这个条件。

 ## 算法演练

 对于每个测试用例：

 1. 计算上半场的比分：```
(a, b)
```2. 检查是否存在有效的前半序列。 

让：```
big = max(a, b)
small = min(a, b)
```如果满足以下条件，则一半有效：```
big <= 2 * (small + 1)
```3. 计算下半场的进球数：```
x = c - a
y = d - b
```4. 检查相同条件`(x, y)`。 

同样，如果满足以下条件，则一半有效：```
max(x, y) <= 2 * (min(x, y) + 1)
```5. 打印`"YES"`如果两半都有效。 否则打印`"NO"`。 

### 为什么它有效

 考虑任意一半的计数`(x, y)`。 设较大的计数为`big`较小的计数是`small`。 

这`small`目标最多将序列分为`small + 1`可以放置更大团队目标的位置。 由于连续三个相同进球被禁止，因此每个位置最多可以包含 2 个这样的进球。 因此每个有效序列都满足```
big <= 2 * (small + 1)
```相反，如果这个不等式成立，我们可以将`big`之间的目标`small + 1`位置，以便没有位置获得超过 2 个进球。 将分隔符目标放置在这些位置之间会产生有效的序列。 

因此，不等式既是必要的，也是充分的。 由于两半是独立的，因此当两半都满足条件时，梦就可能实现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def valid(x, y):
    big = max(x, y)
    small = min(x, y)
    return big <= 2 * (small + 1)

t = int(input())

for _ in range(t):
    a, b, c, d = map(int, input().split())

    first_half = valid(a, b)
    second_half = valid(c - a, d - b)

    print("YES" if first_half and second_half else "NO")
```辅助函数实现了有效一半的数学特征。 

对于每个测试用例，我们评估两个独立的一半。 前半部分直接使用`(a, b)`。 下半场采用半场结束后的附加进球数，即`(c-a, d-b)`。 

不需要构建实际的目标序列。 证明表明，不等式完全决定了是否存在有效的安排。 

该实现自动避免了所有边界问题。 空半部分之所以有效，是因为，例如，`(0, 0)`满足不等式。 仅一支球队得分的情况也能正确处理。 例如`(0, 2)`是有效的，同时`(0, 3)`不是。

 ## 边缘情况

 考虑：```
1
0 2 0 2
```上半年，`big = 2`和`small = 0`。 条件变为：```
2 <= 2 * (0 + 1)
```这是真的。 顺序`KK`之所以允许，是因为该限制禁止连续三个进球，而不是两个。 算法打印`YES`。 

现在考虑：```
1
0 3 0 3
```这里：```
big = 3
small = 0
```和```
3 <= 2
```是假的。 唯一可能的顺序是`KKK`，其中包含同一支球队连续三个进球。 算法正确打印`NO`。 

另一个微妙的情况是：```
1
4 1 4 1
```下半场的比分是：```
(0, 0)
```该条件立即成立，因为两个计数均为零。 由于各半场是独立的，因此空的下半场是完全有效的。 算法输出`YES`。 

最后，考虑：```
1
1 1 1 4
```前半部分满足条件。 下半场贡献`(0, 3)`，失败是因为`3 > 2`。 只看最终得分会错过这个问题，但分别正确检查每一半会产生`NO`。
