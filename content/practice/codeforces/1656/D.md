 ## 解决方案
 ## 问题理解

 我们得到一个数字$n$，我们要检查是否存在一个整数$k \ge 2$这样我们就可以分开$n$准确地进入$k$具有特殊属性的正整数：当其中每一个$k$数字除以$k$，所有余数必须不同。 

这种情况迫使情况变得非常结构化。 这$k$余数必须与集合完全相同$\{0, 1, 2, \dots, k-1\}$按某种顺序，因为有$k$数字，并且没有两个可以共享余数类模$k$。 因此，该构造相当于从每个残差类中选择一个数字取模$k$，均为正数，其总和为$n$。 

从约束条件来看，$n$可以大到$10^{18}$，并且最多有$10^5$测试用例。 这立即排除了尝试所有方法的任何方法$k$或显式构造候选分解。 任何有效的解决方案都必须决定$k$大致在$O(\sqrt{n})$每个测试用例或更好，并且在实践中更接近$O(1)$或对数行为。 

一些边缘情况已经很突出。 

如果$n = 2$, 没有办法选择$k \ge 2$具有不同残基的正整数 mod$k$，因为即使对于$k = 2$，最小的有效结构将需要一个与 0 全等的数字和一个与 1 模 2 全等的数字，强制至少$1 + 2 = 3$。 所以$2$是不可能的。 

如果$n$很小，比如$4$，简单的构造经常会失败，因为余数要求至少迫使最小总和超过$n$。 

关键的微妙之处在于，这种分解的存在并不是关于任意的划分$n$，但关于是否$n$可以使用每个残基类模中的一个元素来表示$k$。 

## 方法

 一个蛮力的想法是尝试每一个$k$从$2$到$n$。 对于每个$k$，我们尝试构造$k$带残数的数字$0$到$k-1$。 残差的最小正代表$r$是$r$本身是为了$r > 0$，但残渣$0$强制一些形式$k$， 自从$0$不允许为正整数。 所以固定的最小总和$k$变成：$$k + (0 + 1 + 2 + \dots + (k-1)) = k + \frac{k(k-1)}{2}.$$如果即使这个最小值超过$n$, 构造是不可能的$k$。 否则，我们需要在数字之间分配剩余值，同时保留不同的残差，这在残酷的模拟中很快就会变得混乱。 

尝试所有$k$最多$10^{18}$显然是不可行的。 甚至限制为$\sqrt{n}$候选人仍然剩下$10^9$跨最坏情况输入的操作，这对于$10^5$测试。 

关键的观察是扭转视角。 而不是构造一个固定的数字$k$，我们分析在留数固定的情况下总和的表现。 如果我们选择数字$a_i$这样：$$a_i = b_i + t_i \cdot k$$具有明显的$b_i \in \{0, \dots, k-1\}$， 然后：$$n = \sum b_i + k \sum t_i.$$当所有的情况下，可能的总和最小$t_i = 0$，除非我们必须修复残基 0 类的正值，这会产生强制$k$。 这导致了干净的必要条件：$$n \ge \frac{k(k+1)}{2}.$$现在结构变得更加清晰：我们只需要找到任何$k$使得这个不等式成立并且可以完成残差分配。 更深层次的简化表明，这样的$k$存在当且仅当$n$不是以下形式$2^x$。 2 的幂失败，因为它们无法满足此结构下的剩余平衡要求，而所有其他数字至少承认一个有效的$k$。 

这会导致非常快速的检查：找到任何$k$这样$k(k+1)/2 \le n$，然后通过确保$n$不是二的幂； 如果是，请回答$-1$，否则这样一个$k$始终存在（通常$k = 2$或者基于小除数的选择有效）。

 ## 算法演练

 我们使用直接结构测试得出每个测试用例的答案$n$。 

1. 检查是否$n$是二的幂。 如果是则立即返回$-1$。 原因是这样的数字在任何模数下都不能分解为有效的残差覆盖和$k \ge 2$，因为该结构需要对残基类别进行非平凡的混合，而 2 的幂无法支持。 
2.如果$n$不是2的幂，选择一个小的候选者$k$。 可靠的选择是从$k = 2$向上，直到找到一个满足从最小剩余和约束导出的可行性条件的有效条件。 
3. 对于给定的$k$，验证是否$n \ge \frac{k(k+1)}{2}$。 这确保我们至少可以分配最小的代表$0, 1, \dots, k-1$（调整后残数 0 必须表示为$k$）。 
4. 一旦有效$k$找到后立即输出。 

### 为什么它有效

 留数条件强制任何有效分解为一组完整的余数模$k$，它将解决方案的结构固定为加法倍数$k$。 构建这样一个集合的可行性仅取决于是否$n$可以容纳所需的最低代表总和加上$k$。 2 的幂恰好是所有人都无法实现这种平衡的值$k$，而所有其他数字至少允许一个表示对齐的模数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        if is_power_of_two(n):
            print(-1)
            continue
        
        k = 2
        while k * (k + 1) // 2 > n:
            k += 1
        
        print(k)

if __name__ == "__main__":
    solve()
```该代码首先隔离了结构性障碍：立即拒绝 2 的幂。 这可以避免任何不必要的搜索。 然后辅助循环找到最小的可行值$k$从而满足最小残差和约束。 

条件$k(k+1)/2 \le n$用作可行性过滤器。 它直接来自对每个残基类别的最小代表求和。 循环是安全的，因为$k$增长缓慢，大致范围为$O(\sqrt{n})$，但实际上它对于所有有效输入都非常早地停止。

 ## 边缘情况

 一个关键的边缘情况是当$n$是二的幂。 例如，$n = 16$。 该算法在尝试构建之前立即拒绝它$k$。 这可以避免进入循环，否则会错误地尝试较小的值$k$并产生误导性的可行性结果。 

另一个边缘情况是最小的输入，例如$n = 2$和$n = 4$。 对于这些，即使它们不是以相同方式2的幂，也不能满足留数结构，并且2的幂检查正确地过滤它们。 

最后的边缘情况是$n$刚好高于 2 的幂，例如$17$。 这里算法选择一个小的$k$， 通常$2$，并且可行性条件立即通过，确认接近阈值是最容易构造的。
