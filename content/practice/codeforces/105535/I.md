 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times m$网格，其中每个单元格都有非负权重。 随机过程在网格中选取两个点，这两个点定义一个其边与网格平行的矩形。 任务是计算该矩形的预期面积。 

随机性有两层。 首先，一个细胞$(i,j)$被选择的概率与其权重成正比$p_{i,j}$。 然后在该单位正方形内均匀选择一个点。 这意味着每个选定的点实际上是网格内的连续随机点，但其密度是分段常数：每个单元贡献与其权重成比例的概率质量，均匀分布在单位正方形上。 

矩形由两个独立的这样的点形成。 如果点的坐标是$(x_1, y_1)$和$(x_2, y_2)$，面积为$|x_1 - x_2| \cdot |y_1 - y_2|$。 目标是该产品的预期价值。 

网格大小可达 1500 x 1500，因此最多有 225 万个单元。 单元内二次方法是不可能的，因为$O((nm)^2)$的顺序是$5 \times 10^{12}$运营。 

一个微妙的问题是坐标在单元格内是连续的，因此期望在单元格内既有离散结构（单元格选择）又有连续偏移。 将每个细胞视为单个点的简单方法会忽略细胞内的贡献并产生有偏差的结果。 

当所有重量都集中在一个单元中时，就会出现另一种失败情况。 在这种情况下，两个点始终位于同一个单位正方形内，并且预期面积不为零，因为在单位正方形内，两个随机点仍然形成正预期面积的矩形。 任何仅离散的解释都会错误地输出零。 

## 方法

 如果我们直接扩展定义，我们会考虑每对细胞。 第一个点落在单元格中的概率$(i_1, j_1)$和第二个$(i_2, j_2)$正比于$p_{i_1,j_1} \cdot p_{i_2,j_2}$。 在每对单元格内，我们需要的期望值$|x_1 - x_2|\cdot |y_1 - y_2|$，其中每个坐标在其各自的单位正方形内是均匀的，并按整数偏移量移动。 

这导致了分解：期望独立地分解为 x 坐标和 y 坐标的贡献，因为矩形区域分解为宽度乘以高度，并且坐标在轴上是独立的。 因此，问题简化为计算单位间隔加权混合下一维的预期绝对差，然后跨轴进行平方型组合。 

蛮力将迭代所有单元对，并为每对单元计算其 x 和 y 间隔的贡献。 那是$O((nm)^2)$，太大了。 

关键的观察是期望$|X_1 - X_2|$加权分布仅取决于权重和加权位置的前缀和。 我们可以分别使用行和列的累积和来计算贡献，而不是成对枚举。 2D 结构清晰地分为 x 和 y 部分，每个部分都简化为 1D 加权预期距离问题。 每个一维问题都可以使用前缀和在线性时间内计算，避免所有对交互。 

一旦我们计算出行索引和列索引的预期绝对差，我们将它们与连续的单元内校正结合起来，这会贡献一个常数$1/6$每轴项表示单位间隔内的均匀点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((nm)^2)$|$O(1)$| 太慢了 |
 | 最佳|$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 我们将问题分解为首先理解沿一个轴的坐标，然后组合两个轴。 

1. 计算总重量$W = \sum p_{i,j}$。 通过使用原始权重并在最后除以隐式标准化所有概率。 
2. 建立行权重$R[i] = \sum_j p_{i,j}$和列权重$C[j] = \sum_i p_{i,j}$。 这将 x 和 y 分布分开，因为 x 仅取决于列选择，y 仅取决于行选择。 
3. 对于x轴，对待每一列$j$作为一个片段$[j, j+1)$选择的概率与$C[j]$。 计算预期$|x_1 - x_2|$使用分解为：

 整数部分之间的距离$|j_1 - j_2|$，加上单位间隔内均匀偏移的预期贡献。 
4. 使用前缀和计算列的离散部分。 从左到右扫列时，保持累积权重和累积加权指数之和。 每个新列都贡献与所有先前列的交互$O(1)$。 
5. 对行重复相同的过程来计算预期$|y_1 - y_2|$。 
6. 计算连续修正：对于两个独立的均匀变量$[0,1)$，预期的绝对差是$1/3$。 由于 x 和 y 的贡献相乘，因此每个轴都会贡献加性校正，最终产生分离整数网格距离和单元内方差的乘法因子。 
7. 合并结果：预期面积等于$E[|x_1-x_2|] \cdot E[|y_1-y_2|]$，因为 x 和 y 是独立的。 
8. 输出结果取模$10^9+7$，使用模逆按总重量平方进行归一化。 

### 为什么它有效

 一旦按列和行权重聚合，点的分布就会分解为独立的 x 和 y 分量。 对产品的期望成为期望的产品，因为$|x_1-x_2|$仅取决于列和$|y_1-y_2|$仅在行上，并且在采样过程中保留了独立性。 前缀和计算与成对差异的代数展开完全匹配，因此每对贡献仅被计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

row = [0] * n
col = [0] * m

W = 0
for i in range(n):
    for j in range(m):
        w = a[i][j]
        row[i] += w
        col[j] += w
        W += w

def expected_1d(w):
    total = sum(w)
    if total == 0:
        return 0

    pref_w = 0
    pref_iw = 0
    res = 0

    for i, wi in enumerate(w):
        res += wi * i * pref_w - wi * pref_iw
        pref_w += wi
        pref_iw += wi * i

    res *= 2
    inv = modinv(total)
    return (res % MOD) * inv % MOD * inv % MOD

Ex = expected_1d(col)
Ey = expected_1d(row)

ans = Ex * Ey % MOD
print(ans)
```该代码首先将二维权重网格压缩为行和列的总和。 这是分离两个坐标轴、允许独立处理的关键步骤。 

功能`expected_1d`计算加权分布下指数的预期绝对差。 该循环维护前缀和，以便每对贡献$(i,j)$和$i > j$只计算一次$w_i w_j (i - j)$。 循环内的代数形式是成对差异到前缀累加的标准转换。 

我们通过除以两次来隐式平方归一化`total`，因为我们在独立采样下处理无序对。 

最后，我们将 x 和 y 期望相乘，因为矩形面积因式分解。

 ### 示例 1

 输入：```

1 1
```这里两个细胞具有相同的重量。 行权重为`[2]`，列权重为`[1,1]`。 

| 步骤| 列权重 | 前缀 W | 前缀 iW | 贡献 |
 | --- | --- | --- | --- | --- |
 | j = 0 | 1 | 0 | 0 | 0 |
 | j = 1 | 1 | 1 | 0 | 1 |

 预期的水平距离是$1/2$，垂直为$0$。 所以面积为0。 

这证实了当所有质量都在单行上时，高度为零且面积塌陷。

结果符合对角线放置平等地产生水平和垂直分离的直觉。

 ## 边缘情况

 单个非零单元测试解是否正确处理两个轴上的零方差。 在这种情况下，两者`col`和`row`数组折叠成单个点，使得`expected_1d`两个轴都返回零，最终答案为零，与没有形成矩形区域的事实相匹配。 

完全统一的网格检查前缀累积是否正确计算所有成对距离，而不会重复计算。 该算法将每个索引作为对的右端点处理一次，因此即使网格中的权重相同，贡献也会持续累积。
