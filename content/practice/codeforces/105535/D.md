 ## 解决方案
 ## 问题理解

 我们在平面上得到一组点，但缺少一个点。 已经有$n-1$固定点，我们可以选择最终的坐标$n$第-点。 添加此点后，我们会考虑点之间的所有成对距离，但距离不是欧几里得距离或曼哈顿距离。 相反，它是切比雪夫距离，定义为水平和垂直坐标差的最大值。 

所以每一对点都会贡献一个值，我们最终得到一组$\frac{n(n-1)}{2}$距离。 因为$n$是奇数，这个多重集的大小是奇数，因此有一个明确定义的中位数：$\frac{m+1}{2}$- 第一个最小的元素，其中$m$是对的数量。 

任务是为大边界框内的缺失点选择整数坐标，以便所有成对切比雪夫距离的中值恰好变为$k$，或确定不存在这样的放置。 

约束意味着$n$可以大到$2 \cdot 10^5$，这立即排除了任何显式计算所有成对距离的方法。 即使存储它们也需要大约 2 \cdot 10^5^2 条目，这是不可行的。 任何解决方案都必须避免枚举对，而是依赖于距离的计数或结构属性。 

一个微妙的困难来自这样一个事实：添加一个点会改变涉及它的所有距离，同时保持现有距离不变。 这意味着我们不是在解决静态中值问题，而是通过精确引入来调整分布$n-1$新的价值观。 

一个常见的失败案例是尝试根据局部几何贪婪地猜测新点。 例如，如果所有现有点都聚集在一起，但中位数必须很大，则可以尝试将新点放置在较远的位置。 然而，这可能会同时产生太多的大距离，从而使中线向相反方向移动。 新点和所有现有点之间的耦合使得朴素的几何直觉变得不可靠。 

## 方法

 蛮力的想法是在允许的网格内尝试新点的每个可能的整数坐标，并每次重新计算中值。 对于每个候选人职位$(x_n, y_n)$，我们将计算所有成对的切比雪夫距离$n$点，排序，并检查中位数。 计算所有距离需要$O(n^2)$，并且尝试所有网格点会将其乘以最多$10^{12}$可能性，远远超出任何限制。 

关键的观察是我们不需要明确地知道所有距离。 中位数仅取决于距离的数量$\le k$以及有多少个$> k$。 因此，问题归结为控制阈值计数。 

对于切比雪夫距离，条件$\max(|x_i-x_j|, |y_i-y_j|) \le k$相当于两者$|x_i-x_j| \le k$和$|y_i-y_j| \le k$。 这将每个点转换为边长的正方形$2k$以其为中心，如果它们的坐标位于重叠的正方形内，则对是“好”的。 

我们不是直接推理对，而是翻转视角：对于每个点，我们关心一个点中有多少其他点$k$-切比雪夫邻域半径。 添加新点有贡献$n-1$新的距离，其中每一个都是$\le k$或者$> k$。 因此，新点的效果完全取决于其切比雪夫球半径内有多少现有点$k$。 

因此，我们将任务简化为找到一个点，使其中现有点的数量$k$-neighborhood 在最终中位数中准确地产生所需的平衡。 这成为轴对齐约束的几何可行性问题。 

最佳解决方案利用了这样一个事实：答案空间可以简化为从现有点导出的候选坐标。 由于约束仅取决于差异$k$，任何最佳位置都可以移动以与由$x_i \pm k$和$y_i \pm k$，这将搜索空间减少到$O(n)$候选人。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3 + n^2 \cdot G)$|$O(n^2)$| 太慢了 |
 | 最佳|$O(n \log n)$或者$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 首先计算现有的成对距离的数量$n-1$积分是固定的，因此他们对“$\le k$“ 和 ”$> k$”已经确定了。这是我们无法改变的底线。
 2.让$C$是现有对的数量与距离$\le k$。 我们使用扫描式结构或在转换后的坐标中排序来计算一次，具体取决于实现偏好。 
3. 插入新点后的总对数变为$\frac{n(n-1)}{2}$。 由此我们计算中位数指数$m$，并翻译条件“中位数等于$k$” 变成了必须有多少距离的要求$\le k$。 
4.让$t$是所需的距离对的数量$\le k$。 现有配置贡献$C$，所以新点必须准确贡献$t - C$其中的“好”优势$n-1$入射边缘。 
5. 对于候选人职位$(x,y)$，计算有多少现有点满足$\max(|x-x_i|, |y-y_i|) \le k$。 这个计数直接给出了新距离的数量$\le k$。 
6. 条件简化为检查该计数是否等于步骤 4 中导出的固定目标。如果匹配，则该点有效。 
7. 我们不扫描所有网格点。 相反，我们观察到计数仅在跨越线时发生变化$x_i \pm k$或者$y_i \pm k$。 因此，测试由这些边界形成的候选位置就足够了。 
8. 枚举所有此类候选人$x$和$y$值，测试每个$O(n)$，并输出任意有效点。 

### 为什么它有效

 切比雪夫约束在每个现有点周围创建轴对齐的正方形区域，并且在由垂直和水平边界线形成的排列的每个单元内，此类正方形内的点数是恒定的$x_i \pm k$和$y_i \pm k$。 任何最佳解决方案都可以在单元内移动，而不改变距离内的点$k$，因此限制对边界引起的代表的关注保留了所有可能的有效性情况。 这将连续搜索空间变成有限多个等价区域，同时保持对计数条件不变。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_within(points, x, y, k):
    c = 0
    for xi, yi in points:
        if max(abs(x - xi), abs(y - yi)) <= k:
            c += 1
    return c

def solve():
    n = int(input())
    k = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n - 1)]

    total_pairs = n * (n - 1) // 2
    median_pos = (total_pairs + 1) // 2

    # We binary interpret condition:
    # need exactly median_pos pairs <= k
    # existing pairs fixed; we only adjust via new point

    # compute existing contribution C (O(n^2) naive for clarity; optimized solutions use data structures)
    C = 0
    for i in range(n - 1):
        for j in range(i + 1, n - 1):
            if max(abs(pts[i][0] - pts[j][0]), abs(pts[i][1] - pts[j][1])) <= k:
                C += 1

    target = median_pos - C

    xs = set()
    ys = set()

    for x, y in pts:
        xs.add(x)
        xs.add(x + k)
        xs.add(x - k)
        ys.add(y)
        ys.add(y + k)
        ys.add(y - k)

    xs = list(xs)
    ys = list(ys)

    for x in xs:
        for y in ys:
            cnt = count_within(pts, x, y, k)
            if cnt == target:
                print(x, y)
                return

    print(-1)

if __name__ == "__main__":
    solve()
```该解决方案首先将中位数要求固定为精确的计数条件。 然后，它计算现有点的贡献，以便我们确切地知道有多少“好”边必须来自新点。 

候选生成步骤至关重要。 我们不搜索整个网格，而是只考虑与移动的现有点对齐的坐标$k$，因为点是否位于切比雪夫距离内的指示函数$k$仅在这些阈值处发生变化。 这保证了如果任何地方存在有效职位，则至少有来自该地区的一名代表接受测试。 

功能`count_within`评估候选人满足多少约束。 尽管写为线性扫描，但它应用于减少的候选集，从而使整体复杂性对于预期推理保持可控。 

## 工作示例

 考虑一个小情况，其中已经存在三个点，我们必须添加一个点。 

输入：```
4
2
0 0
0 2
2 0
```We compute all existing distances first. 在这三个点之间，所有成对的切比雪夫距离都是 2。所以现有的贡献$C = 3$。 插入后的总对数为 6，因此中间位置为 3。我们正好需要 3 个距离$\le 2$，因此新点必须贡献 0 个额外的“好”边。 

| 步骤| 中位数位置 | 现有的C | 目标| 解读|
 | --- | --- | --- | --- | --- |
 | 初始化| 3 | 3 | 0 | 新点一定远离一切|

 尝试候选位置，任何靠近原点的点都会增加计数，因此我们选择类似于 (10,10) 的值。 这会在距离 2 内产生零点，满足条件。 

第二个例子：```
3
1
0 0
10 10
```现在我们需要放置一个点，以便恰好一半的距离是$\le 1$。 由于现有距离为 10，$C = 0$。 插入后的总对数为 3，中间位置为 2，因此目标为 2。新点必须恰好位于两个现有点的距离 1 之内。 像 (0,1) 这样的放置可以满足这一点。 

| 步骤| 中位数位置 | 现有的C | 目标| 选定点|
 | --- | --- | --- | --- | --- |
 | 初始化| 2 | 0 | 2 | (0,1)|

 这显示了新点如何“激活”受控数量的短边。

 ## 边缘情况

 当所有现有点重合时，每对距离都为零，因此中位数几乎为零，除非新点创建足够的非零距离。 该算法通过计算大量现有的数据来处理这个问题$C$，迫使目标贡献变为负数或不可能，这在需要时正确地产生没有解决方案。 

当所有点相对于$k$，现有贡献$C$变为零，增加中位数的唯一方法是通过新点。 候选枚举仍然包括现有点附近的位置，从而允许精确控制激活$k$-有界边缘，确保不遗漏可行性。 

如果要求的目标超过$n-1$，没有位置可以满足它，因为新点贡献最大$n-1$边缘。 这自然可以在计算中得到`target`，超出范围并导致失败。
