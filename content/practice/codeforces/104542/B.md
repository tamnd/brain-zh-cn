 ## 解决方案
 ## 问题理解

 我们被要求构造一个具有两个约束的正整数数组：其长度固定为$n$，所有元素的总和恰好是$k$。 一旦选择了数组，我们就会查看每个有序对$(i, j)$并通过连接十进制表示形式形成一个新数字$a_i$其次是$a_j$。 检查每个这样的串联值的素数，然后我们计算其中有多少个$n^2$值是素数。 目标是设计数组以使该计数尽可能小。 

关键的困难是我们没有评估固定数组。 我们在全局总和约束下选择数组，分数取决于通过串联的所有成对交互。 

限制条件非常大：$t$可以达到$10^5$和$n, k$可以达到$10^9$，而测试用例中的元素总数很大。 这立即排除了任何模拟数组或检查连接值的素数的解决方案。 解决方案必须将问题简化为关于结构的封闭式推理，而不是计算。 

当所有值都相同时，特别是当所有值都为 1 时，就会出现微妙的边缘情况。在这种情况下，每个串联都变成相同的数字（例如 11），并且如果该数字是素数，则每个对都会对分数做出贡献。 这会在答案中产生二次爆炸，如果假设素数稀疏，就很容易忽略这一点。 

另一个重要的极端情况是，当我们引入一个不同于 1 的单个值时。该单个更改可能会破坏大部分创建重复素数模式的“统一串联结构”，而事实证明，这是显着降低分数的唯一方法。 

## 方法

 暴力方法是尝试所有可能的分发方式$k$进入$n$正整数，然后模拟所有$n^2$连接并测试每个连接的素性。 即使素性检查很快，可能的数组数量组合起来也是巨大的，甚至评估一种配置成本$O(n^2)$，这已经是不可行的了。 

关键的观察是我们并没有真正独立地控制各个串联。 串联数字的结构在很大程度上取决于值的位数，特别是像 1 这样的小值是否重复出现。 如果所有值均为 1，则每个串联将变为 11，从而产生单个数字的最大可能重复次数。 

为了降低分数，我们希望避免重复的可能是素数的相同串联。 唯一重要的可控结构是有多少个元素等于 1。一旦至少一个元素不为 1，产生重复串联的对称性就会消失，从而防止在统一情况之外出现额外的强制素数。 

因此，最优策略完全取决于我们在尊重总和约束的情况下可以放置多少个 1。 为了最大化 1 的数量，我们将尽可能多的元素分配给 1，并将剩余的质量放入单个元素中。 

如果所有元素都是 1，则每个串联都是 11，给出$n^2$最坏情况下的素数。 如果我们被迫增加至少一个元素（因为$k > n$），我们将 1 的数量减少到$n-1$，并且该结构的结构崩溃了，因此只有 1 之间的相互作用才重要，从而产生了非常小的固定分数。

 ## 算法演练

 ### 关键构建洞察

 1. 首先决定有多少个元素可以设置为 1，同时遵守总和约束。 
2.如果$k = n$，每个元素都必须为 1，因为正整数的最小可能和恰好是$n$。 在这种情况下，就没有灵活性。 
3.如果$k > n$，我们可以设置$n-1$元素为 1，并将剩余的和放入单个元素$k-(n-1)$。 这样可以在保持有效性的同时最大化 1 的数量。 
4. 分数仅取决于剩余的 1 数量，因为其他值在最佳配置中不会贡献额外的强制素数串联。 

### 最终答案计算

 1. 如果所有元素都是1，则每次串联变成11，所以所有$n^2$两人一组贡献，给出答案$n^2$。 
2. 否则，完全正确$n-1$元素为 1，结构崩溃，因此只有这些相同的最小元素之间的相互作用才重要，产生$(n-1)^2$。 

### 为什么它有效

 该构造表明，控制重复串联模式的唯一方法是控制存在多少个相同的最小值。 任何与所有的偏差都会破坏统一的串联结构。 由于我们正在最小化素数，因此我们总是希望避免完全对称的情况，除非受到总和约束的强制。 因此，最佳配置减少为最大化 1 的数量，这完全决定了分数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())

        if k == n:
            out.append(str(n * n))
        else:
            out.append(str((n - 1) * (n - 1)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案将每个测试用例减少为单个比较$k$和$n$。 推理依赖于这样一个事实：最小总和配置强制所有值都为 1，而任何多余的质量必须集中到一个元素中，从而保留最大可能的 1 数量。 

一个常见的错误是尝试显式构造数组或推理连接数字的素数。 这是不必要的，因为结构会分解为仅计算相同的最小元素。

 ## 边缘情况

 当$n = k$，构造时强制使用全1。 这会产生最大的对称性，并且每个串联都变得相同，因此分数达到$n^2$。 任何试图通过修改值来“改进”这种情况的解决方案都会违反总和约束。 

什么时候$k > n$，我们不能再让所有值都等于 1。最佳做法是通过仅增加一个元素来最大程度地减少干扰。 这保留了最大可能的 1 数量，并确保分数纯粹由这些 1 之间的相互作用决定，给出$(n-1)^2$。 

什么时候$n = 1$，只有一个串联$con(a_1, a_1)$，并且施工是强制的。 该公式正确地简化为$1$，匹配单个可能的对。
