 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，必须将其分为三个类别之一。 

如果存在实数，则序列被视为几何级数$c$和$b$这样每个元素都有形式$c \cdot b^{i-1}$。 简单来说，只要除法有意义，连续元素就必须具有相同的比率。 

任务不仅是检查整个数组是否已经形成等比级数，还要检查是否恰好删除一个元素可以使其成为一个。 所需的输出是：

 -`0`如果序列已经是几何序列。 
-`1`如果删除一个元素可以使其成为几何图形。 
-`2`否则。 

数组大小可以达到$10^5$，这会立即排除任何重复扫描数组大部分的算法。 二次解大约需要$10^{10}$最坏的情况下操作，远远超出了时限。 我们需要接近线性时间的东西。 

棘手的部分是，当出现零时，级数比可能是小数、负数，甚至是未定义的。 使用浮点运算是危险的，因为精度错误可能会悄悄地破坏比较。 实现必须准确比较比率。 

一些边缘情况会导致简单的解决方案失败。 

考虑：```
3
0 0 0
```正确答案是`0`。 每个比率都是有效的，因为所有元素都为零。 除以先前元素的粗心实现会在除以零时崩溃。 

另一个危险的情况是：```
4
1 2 4 7
```正确答案是`1`因为删除`7`留下完美的几何级数。 固定前两个元素的比率并立即拒绝不匹配的简单方法可能会忽略删除最后一个元素可以解决问题。 

负比率也很重要：```
5
2 -4 8 -16 32
```这已经是几何比例了`-2`。 假设比率为非负的实现将会失败。 

一个更微妙的情况是：```
5
1 0 0 0 0
```答案是`1`。 删除第一个元素会留下所有零，这是几何的。 但原始数组本身不是几何数组，因为没有单一比率变换`1`进入`0`然后保持一切一致。 

最后，短数组需要特殊处理。 任何长度最多为 2 的序列自动是几何序列，因为我们总是可以选择合适的常数。 

## 方法

 蛮力的想法很简单。 对于每一个可能被删除的索引，构造剩余序列并检查它是否形成等比级数。 我们还测试了没有删除的原始数组。 

检查一个候选序列需要线性时间，因为我们必须验证所有相邻的比率。 对每次删除重复此操作会导致$O(n^2)$时间复杂度。 

为了$n = 10^5$，这意味着大约$10^{10}$的操作，这是完全不可行的。 

关键的观察是，如果一个序列在删除一个元素后变成几何序列，那么几乎整个数组已经遵循一个公比。 只有恒定数量的位置才能参与不一致。 

假设我们比较连续的三元组。 按几何级数计算：$$a_i^2 = a_{i-1} \cdot a_{i+1}$$这完全避免了除法，并且即使在负值的情况下也能工作。 每当这种等式失败时，问题必定涉及附近的元素之一。 单个错误删除无法修复任意多个不相关的不匹配。 

这意味着我们只需要识别一些可疑的索引并测试它们周围的删除。 每个测试仍然需要线性时间，但测试删除的数量变得恒定，从而给出整体线性复杂性。 

最终算法扫描数组一次以定位第一个违规，然后尝试删除附近的元素，例如$i-1$,$i$， 或者$i+1$。 如果存在有效答案，则其中之一必须是已删除的元素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 最佳|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 立即处理小阵列。 

任何长度最多为 2 的数组自动是几何数组，因此 print`0`。 
2. 定义辅助函数`good(skip)`。 

该函数检查删除索引后序列是否变为几何序列`skip`。 如果`skip = -1`，没有任何内容被删除。 
3. 内部`good(skip)`，逻辑地构建剩余序列，而不实际创建新数组。 

我们遍历索引并忽略跳过的索引。 
4. 如果剩余序列的长度至多为2，则返回`True`。 

任何两个数总是构成等比级数。 
5. 找到前三个剩余元素并计算预期关系。 

我们不存储比率，而是使用叉乘进行比较：$$a_i \cdot a_{j-1} = a_{i-1} \cdot a_j$$这避免了浮点问题和除以零。 

1. 继续扫描剩余序列。 

对于过滤序列中的每个连续三元组，验证：$$x_2^2 = x_1 \cdot x_3$$如果任何三元组违反此条件，则返回`False`。 

1. 扫描一次原始数组，找到第一个违规三元组。 

如果不存在，则序列已经是几何序列，因此打印`0`。 
2. 假设第一次违规发生在索引周围`i-1`,`i`， 和`i+1`。 

如果一次删除可以修复序列，则删除的元素必须位于此违规附近。 我们尝试删除每个附近的索引。 
3. 对于每个候选删除，调用`good(candidate)`。 

如果任何调用成功，则打印`1`。 
4. 如果所有考生都失败，则打印`2`。 

### 为什么它有效

 A geometric progression satisfies the local condition:$$a_i^2 = a_{i-1} \cdot a_{i+1}$$对于每个中间位置。 

如果删除一个元素可以修复序列，则原始数组中的每个违规都必须涉及该删除的位置。 一旦我们遇到第一个损坏的三元组，被删除的元素必定属于该邻域。 删除任何遥远的元素将使违规行为保持不变。 

该算法测试所有此类附近的可能性，并且辅助函数对结果序列执行精确验证。 由于每个有效的解决方案都必须出现在这些候选方案中，因此算法不会错过正确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_geometric(arr):
    m = len(arr)

    if m <= 2:
        return True

    for i in range(1, m - 1):
        if arr[i] * arr[i] != arr[i - 1] * arr[i + 1]:
            return False

    return True

def good(a, skip):
    b = []

    for i in range(len(a)):
        if i != skip:
            b.append(a[i])

    return is_geometric(b)

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if is_geometric(a):
        print(0)
        return

    bad = -1

    for i in range(1, n - 1):
        if a[i] * a[i] != a[i - 1] * a[i + 1]:
            bad = i
            break

    candidates = set()

    for x in [bad - 1, bad, bad + 1]:
        if 0 <= x < n:
            candidates.add(x)

    for idx in candidates:
        if good(a, idx):
            print(1)
            return

    print(2)

solve()
```功能`is_geometric`使用身份执行实际验证：$$a_i^2 = a_{i-1} \cdot a_{i+1}$$这是核心实施细节。 使用除法会产生零和浮点精度问题。 交叉乘法使整数的一切都精确。 

帮手`good`模拟删除一个元素。 剩余的序列被复制到临时数组中，因为仅测试恒定数量的删除，因此总工作保持线性。 

main函数首先检查原始数组是否已经工作。 如果不是，它会找到第一个违规的中间索引。 仅测试附近的索引作为删除候选者。 

当违规行为出现在开头或结尾附近时，候选集可以避免重复检查。 

Python 整数自动安全地处理大型产品，因此溢出不是这里的问题。 在 C++ 等语言中，使用`long long`将是必要的。

 ## 边缘情况

 考虑全零序列：```
3
0 0 0
```该算法检查：$$0^2 = 0 \cdot 0$$这对于每个三元组都是如此。 任何地方都不会发生除法，因此不存在被零除错误的风险。 输出变为`0`。 

现在检查：```
4
1 2 4 7
```第一个坏三元组是`(2, 4, 7)`因为：$$4^2 \ne 2 \cdot 7$$该算法测试删除索引`1`,`2`， 和`3`。 去除`7`产生`[1,2,4]`，满足：$$2^2 = 1 \cdot 4$$输出是`1`。 

对于负比率：```
5
2 -4 8 -16 32
```支票变成：$$(-4)^2 = 2 \cdot 8$$

$$8^2 = (-4) \cdot (-16)$$

$$(-16)^2 = 8 \cdot 32$$所有这些都是有效的，因此该序列会立即被接受。 实施从来不采取积极的态度。 

最后，考虑：```
5
1 0 0 0 0
```第一次违规出现在`(1,0,0)`因为：$$0^2 \ne 1 \cdot 0$$删除索引`0`树叶`[0,0,0,0]`，它通过了每一项检查。 算法正确打印`1`。
