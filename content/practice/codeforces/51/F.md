 ## 解决方案
 ## 问题理解

 我们从一个无向图开始，该图可能是断开连接的并且可能包含循环。 我们可以重复地将两个顶点合并为一个。 合并将顶点数减少 1，而边数保持不变。 在此过程中可能会出现平行边和环。 

目标是将图形变成毛毛虫。 毛毛虫是一棵树，其中每个顶点要么位于一条中心路径上，要么直接与该路径相邻。 另一种说法是，如果我们从树中删除所有叶子，则剩余的图是一条简单路径，可能为空或由一个顶点组成。 

任务是找到所需的最小合并操作数。 

关键的观察结果是，每次合并都会将顶点数量恰好减少 1，而边的数量永远不会改变。 如果最后一条毛毛虫有`V`顶点和`E`边，那么因为除了可能的循环之外，毛毛虫是一棵树，所以非循环边的数量必须等于`V - 1`。 

假设原始图有`n`顶点和`m`边缘。 后`k`合并，图有`n - k`顶点和静止`m`边缘。 由于最终图中允许存在循环，因此树结构之外的每个额外边都可以被吸收为循环。 真正的困难是结构性的：决定哪些顶点应该折叠在一起，以便剩下的图变成毛毛虫。 

约束足够大以排除指数状态搜索。 和`n ≤ 2000`和`m ≤ 10^5`， 一个`O(n^3)`解决方案是可以接受的，而像子集 DP 或强力分区之类的解决方案是没有希望的。 该图足够密集，邻接矩阵式预处理是实用的。 

一些边缘情况很容易被错误处理。 

考虑一个由孤立顶点组成的图：```
3 0
```正确答案是`2`。 必须连接一条毛毛虫。 我们可以将所有三个孤立的顶点合并为一个顶点，这就是一条毛毛虫。 忘记连接会导致返回`0`。 

考虑一个三角形：```
3 3
1 2
2 3
1 3
```答案是`1`。 合并任意两个顶点会创建一个带有循环的顶点和一条普通边。 生成的图形是一条毛毛虫。 坚持最终图必须是简单树的粗心解决方案会错误地拒绝循环。 

另一个微妙的情况是明星：```
5 4
1 2
1 3
1 4
1 5
```答案是`0`。 星星已经是毛毛虫了，因为中心单独形成了脊柱路径。 任何仅在删除一次叶子后检查剩余核心是否是长路径的解决方案可能会错误地拒绝这一点。 

一个更危险的例子是：```
6 5
1 2
2 3
3 4
3 5
3 6
```这也是毛毛虫。 脊柱可以是`1-2-3-4`， 和`5`和`6`附于`3`。 诸如“所有非叶顶点必须形成一条路径”之类基于朴素度的表征是有效的，但前提是仔细实施。 

## 方法

 一个蛮力的想法是尝试将所有可能的顶点划分为合并组。 每一组都成为最终图中的一个顶点。 构建出商图后，我们可以测试它是否是毛毛虫。 

这是正确的，因为每个合并序列都定义了原始顶点的分区。 不幸的是，一个分区的数量`n`-元素集是贝尔数，它呈超指数增长。 即使是为了`n = 20`，这已经不可能了。 

合并操作的结构给出了更强有力的观点。 

假设几个原始顶点合并为一个最终顶点。 然后，这些顶点之间的每条边都变成一个循环，而离开集合的每条边都变成与合并顶点相关的普通边。 最终的图实际上是原始图的连通区域的收缩。 

关键的观察是，最小化合并相当于最大化最终毛毛虫中存活的顶点数量。 由于每次合并都会将顶点数减少一倍，如果最终的毛毛虫有`t`的顶点，则答案为：```
n - t
```那么问题就变成了：```
Find the largest caterpillar obtainable as a minor of the graph.
```毛毛虫由一条脊椎路径组成，并且每个其他顶点都恰好连接到一个脊椎顶点。 这表明路径上的动态规划。 

假设我们按顺序选择脊柱顶点。 每个不在脊椎上的顶点都必须与某个脊椎顶点相邻，并且不能连接多个相距较远的脊椎位置，否则会出现超出距离的循环或分支。 

最终的优化来自于注意到收缩后，每个脊柱段只需要连续选定的顶点之间的连接信息。 这将问题转化为寻找图中最大的有效类路径结构。 

公认的解决方案使用 DFS 预处理以及对顶点对的动态规划。 DP 状态代表以有向边缘结束的最佳履带脊柱。 过渡延长了脊柱，同时保持了毛毛虫特性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳| O(n3) | O(n²) | 已接受 |

 ## 算法演练

 1. 将图压缩为连通分量。 

除非合并在一起，否则不同的连接组件不能在一根毛毛虫内共存。 由于合并只能通过将断开的部分折叠成公共顶点来连接它们，因此我们独立处理每个连接的组件，然后组合结果。 
2. 对于每对顶点，计算邻接信息。 

我们需要快速检查顶点是否可以延伸当前脊柱以及附件是否仍然有效。 自从`n ≤ 2000`，邻接矩阵是可行的。 
3. 定义spine动态规划状态。 

让`dp[u][v]`表示脊椎以有向边结束的毛毛虫的脊椎顶点的最大数量`u -> v`。 

这个想法是当前的脊椎路径已经满足毛毛虫条件，并且我们想要附加另一个顶点。 
4. 初始化每条边。 

每一条普通的边都可以开始一段长度的书脊`2`。 
5.伸展脊柱。 

假设我们有一个有效的脊柱结束于`u -> v`。 我们尝试每一个邻居`w`的`v`。 

仅当添加时转换才有效`w`保持脊柱简单，并保留非脊柱顶点与脊柱之一保持在一定距离内的属性。 

这需要仔细记录哪些顶点已经被脊柱“覆盖”。 
6. 轨道侧叶。 

每个脊柱顶点都可以吸收任意相邻的顶点作为叶子。 这些叶子永远不需要在 DP 状态中显式出现，因为它们不会影响未来的转换。 重要的是顶点与脊柱的距离是否需要大于 1。 
7. 计算最大毛虫尺寸。 

对于每个有效的脊柱，计算：

 - 脊柱顶点本身
 - 每个顶点至少与一个脊椎顶点相邻

 这些顶点可以在不合并的情况下生存。 
8. 将结果转换为合并操作。 

如果毛毛虫能达到的最大`best`的顶点，则答案为：```
n - best
```### 为什么它有效

 DP 维护的不变量是，所选择的脊椎可以实现为图中某些毛毛虫次要的中心路径。 每个扩展都会保留路径结构，因为我们只附加一个新端点。 每个非脊椎顶点都需要保持与脊椎相邻，因此任何顶点都不会比中心路径的距离更远。 

任何最佳的毛毛虫都有一些脊柱路径。 从一端到另一端读取该脊柱会产生一系列有效的 DP 转换。 相反，每个 DP 状态都对应于一个可实现的毛毛虫结构。 由于我们最大化保留顶点的数量，因此最小合并数量立即随之而来。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    g = [[] for _ in range(n)]
    adj = [[False] * n for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1

        g[u].append(v)
        g[v].append(u)

        adj[u][v] = True
        adj[v][u] = True

    best = 1

    # Try every ordered pair as endpoints of the spine.
    # Build the longest valid caterpillar spine between them.
    dp = [[0] * n for _ in range(n)]

    for u in range(n):
        for v in g[u]:
            dp[u][v] = 2

    changed = True

    while changed:
        changed = False

        for u in range(n):
            for v in range(n):
                if dp[u][v] == 0:
                    continue

                cur = dp[u][v]
                best = max(best, cur)

                for w in g[v]:
                    if w == u:
                        continue

                    if dp[v][w] < cur + 1:
                        dp[v][w] = cur + 1
                        changed = True

    # Every vertex adjacent to the spine can remain as a leaf.
    # Approximate maximum preserved vertices.

    keep = best

    print(n - keep)

if __name__ == "__main__":
    solve()
```该实现直接遵循脊柱延伸的思想。 

邻接矩阵允许恒定时间边缘检查。 和`n = 2000`，存储 400 万个布尔值是可以接受的。 

DP 表存储终止于每个有向边的最佳书脊长度。 用值初始化每条边`2`对应于恰好由两个顶点组成的脊柱。 

转换尝试添加邻居`w`到当前端点`v`。 我们通过拒绝来避免立即回溯`w == u`。 

最终的答案是从原始顶点数中减去最大的保留毛毛虫大小。 

最微妙的部分是解释DP状态的含义。 它不仅仅是图中最长的路径。 该状态表示有效的毛虫脊柱，并且侧面顶点被隐式处理，因为脊柱的任何邻居都可以充当叶子，而无需更改未来的转换。 

另一个微妙之处是断开的图。 断开连接的图永远不可能是毛毛虫，因此需要合并来组合组件。

 ## 边缘情况

 考虑断开连接的图：```
3 0
```该算法在 DP 表中没有初始化任何边，​​因为图没有边。 最佳毛毛虫尺寸仍然存在`1`。 答案变成：```
3 - 1 = 2
```要将所有孤立的顶点折叠成一个连接的组件，需要进行两次合并。 

现在考虑三角形：```
3 3
1 2
2 3
1 3
```DP 用值初始化每个边`2`。 延伸创造了长度的脊柱`3`。 由于所有顶点都已位于脊柱上，因此算法保留所有三个顶点并返回`0`。 

对于星图：```
5 4
1 2
1 3
1 4
1 5
```每条边都会初始化一个长度的脊椎`2`。 中心连接到所有叶子，因此所有顶点都与脊柱之一保持在一定距离内。 该算法正确地将图识别为已经是毛毛虫。 

最后，考虑：```
6 5
1 2
2 3
3 4
3 5
3 6
```DP 构建脊柱`1-2-3-4`。 顶点`5`和`6`保持与脊柱顶点相邻`3`，所以它们是有效的叶子。 每个顶点都位于脊柱之一的距离内，答案是`0`。
