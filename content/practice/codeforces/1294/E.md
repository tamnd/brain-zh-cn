 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times m$矩阵。 目标矩阵是完全固定的：行主序来自$1$到$n \cdot m$。 最终应定位的值$(r,c)$是$$(r-1)\cdot m + c.$$我们可以执行两种操作。 我们可以任意改变任何单个单元格的值，需要花费一次移动的时间。 我们还可以循环地将整列向上移动一个位置，从而花费一次移动。 

目标是使用最少的总移动次数将给定矩阵转换为目标矩阵。 

第一个观察结果是列移位永远不会在列之间移动元素。 每个值始终保留在其原始列中。 由于每个数字的目标位置已知，因此可以独立优化每一列。 总的答案就是所有列的最优成本之和。 

正是这些约束使得这种分解成为必要。 两个都$n$和$m$可以大到$2 \cdot 10^5$，尽管他们的产品也受到$2 \cdot 10^5$。 任何尝试所有行对或重复模拟移位的算法都会变得过于昂贵。 我们需要细胞数量接近线性的东西。 

有几种容易被忽略的边缘情况。 

考虑```
2 2
100 100
100 100
```没有值属于目标矩阵中的任何位置。 每个单元最终都必须被重写。 正确答案是$4$。 只关注轮班机会的粗心解决方案可能会错误地认为某些轮班有帮助。 

考虑```
3 1
2
3
1
```目标列是```
1
2
3
```单个向上循环移位立即产生目标列。 正确答案是$1$。 在单列实例上，班次计算中的差一错误经常会失败。 

考虑```
3 2
1 2
3 4
5 100
```只有一个细胞是错误的。 正确答案是$1$，通过重写最后一个值。 每当某些值对齐时总是执行移位的解决方案可能会意外地花费额外的操作。 

最微妙的情况是，某个值属于目标矩阵中的当前列，但所考虑的移位量无法到达其目标行。 这些值不应该影响该班次的分数。 

例如：```
3 2
5 2
3 4
1 6
```在第一列中，值$5$属于那里，因为$5 \equiv 1 \pmod 2$，但其目标行与与某些班次相关的行不同。 错误地计算它会导致低估答案。 

## 方法

 考虑该问题的一种强力方法是单独处理每一列并尝试每种可能的循环移位次数。 如果我们选择一些移位量$s$，我们可以模拟移位的列，计算有多少位置已经包含正确的值，并重写其余的。 

对于一列，有$n$可能的移位量。 天真地评估一个班次需要检查所有班次$n$行。 这给出了$O(n^2)$每列的工作量和$O(n^2m)$全面的。 

自从$n \cdot m$可能达到$2 \cdot 10^5$，平方因子太昂贵了。 在最糟糕的状态下，$n=2\cdot10^5$和$m=1$，这大约需要$4\cdot10^{10}$运营。 

关键的观察是，对于固定列，每个单元格最多可以帮助一个移位量。 

假设我们正在检查列$j$。 仅当值的目标列也属于此列时，该值才属于此列$j$。 使用目标公式，$$x=(r-1)m+j$$对于某些目标行$r$。 

给定一个值$x$，我们可以立即确定它是否属于列$j$。 如果不是，它就没用，最终必须重写。 

如果它确实属于，我们可以计算它的目标行。 然后我们可以准确地确定多少次循环移位才能将该值放入正确的行中。 这样的移位量只有一个。 

我们不是尝试每个班次并检查每个单元，而是逆转该过程。 对于每个单元格，我们计算它支持的唯一转变并增加该转变的计数器。 

处理完一列的所有行后，我们知道每个班次$s$应用后有多少细胞变得正确$s$轮班。 

如果我们选择平移$s$，成本为：$$s + (n - \text{correct}_s).$$第一项是执行的列移位次数。 第二项是必须重写的剩余单元的数量。 

取所有最小值$s$给出该色谱柱的最佳成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2m)$|$O(n)$| 太慢了 |
 | 最佳 |$O(nm)$|$O(n)$| 已接受 |

 ## 算法演练

 对于每列独立：

 1. 创建数组`cnt`长度`n`，初始化为零。`cnt[s]`如果我们准确执行，将存储有多少个单元格变得正确`s`该列向上循环移位。 
2. 对于每一行`i`，检查值`a[i][j]`。 
3. 检查该值是否属于列`j`在目标矩阵中。 

值属于列`j`当且仅当$$(a[i][j]-1)\bmod m = j.$$如果此条件失败，请忽略该值。 
4. 计算该值的目标行。 

由于行内部索引为零，$$target = \frac{a[i][j]-1}{m}.$$5. 确定哪个移位量将该值放入其目标行。 

后`s`向上移动，当前位于 row 的元素`i`移动到$$(i-s+n)\bmod n.$$我们希望这个位置等于`target`。 

重新排列给出$$s = (i-target+n)\bmod n.$$6. 某些值属于该列，但对应于矩阵外的目标行。 

由于有效的目标行是`0 ... n-1`，忽略计算出的目标行至少为`n`。 
7. 增量`cnt[s]`。 
8. 处理完所有行后，评估每个移位量`s`。 

选择的成本`s`是$$s + (n-cnt[s]).$$9. 取所有班次中的最小成本并将其添加到全局答案中。 
10. 对每一列重复此操作。 

### 为什么它有效

 对于固定列，列移位永远不会与其他列交互，因此优化是独立的。 

每个有效值都只有一个目标行。 对于固定的当前行和目标行，恰好有一个循环移位量将值移动到其正确位置。 该算法直接计算该贡献。 

选择转移金额后$s$，每个计数值已经占据其最终位置并且不需要重写。 必须通过更改其值来纠正每隔一行，每行需要执行一次操作。 自从演出以来$s$准确地转移成本$s$移动，该选择的总成本为$s + (n-cnt[s])$。 

评估每个可能的移位量，因此获得的最小成本对于该列来说是最佳的。 对列求和是有效的，因为不同列上的操作不会相互影响。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]

    ans = 0

    for col in range(m):
        cnt = [0] * n

        for row in range(n):
            x = a[row][col]

            if (x - 1) % m != col:
                continue

            target = (x - 1) // m

            if target >= n:
                continue

            shift = (row - target + n) % n
            cnt[shift] += 1

        best = n

        for shift in range(n):
            cost = shift + (n - cnt[shift])
            if cost < best:
                best = cost

        ans += best

    print(ans)

solve()
```外循环独立处理列，因为移位不会在列之间移动元素。 

条件```
(x - 1) % m != col
```检查该值是否属于目标矩阵中的当前列。 任何未通过此测试的值都无法使用移位来修复，并且只能通过重写来贡献。 

目标行计算```
target = (x - 1) // m
```使用从零开始的索引。 一个常见的错误是混合从一开始的行号和从零开始的行号，这会产生不正确的移位计算。 

支票```
if target >= n:
    continue
```是必不可少的。 值可以满足列条件，同时仍然对应于矩阵之外的行。 这些值不能占据任何有效的目标位置。 

平移公式```
shift = (row - target + n) % n
```直接来自求解循环运动方程。 反转减法会产生相反的移位方向，并在许多测试中产生错误的答案。 

最后，对于每个移位量，我们将执行移位的成本与重写每个仍然不正确的行的成本结合起来。

 ## 边缘情况

 ### 值不属于任何目标列

 输入：```
2 2
100 100
100 100
```对于每一列，$$(100-1)\bmod 2 = 1.$$只有第 1 列通过了列测试，但是$$(100-1)/2 = 49$$它超过了最大有效行索引。 任何条目都不会对任何班次计数产生影响。 

全部`cnt[s]`保持为零，因此最小成本为$$0 + (2-0)=2$$每列。 总答案：`4`。 

### 单列循环行为

 输入：```
3 1
2
3
1
```目标行是：

 | 价值| 目标行|
 | ---| ---|
 | 1 | 0 |
 | 2 | 1 |
 | 3 | 2 |

 支持的班次有：

 | 当前行 | 价值| 班次|
 | ---| ---| ---|
 | 0 | 2 | 2 |
 | 1 | 3 | 2 |
 | 2 | 1 | 2 |

 因此`cnt[2] = 3`。 

费用：

 | 班次| 成本|
 | ---| ---|
 | 0 | 3 |
 | 1 | 4 |
 | 2 | 2 |

 算法输出`1`？ 我们仔细计算一下。 向上移动一个柱子就变成了`[3,1,2]`, 两班转变为`[1,2,3]`。 由于每个班次花费一次移动，所以正确的成本是`2`， 不是`1`。 

这个例子强调了为什么必须仔细推导平移公式。 该算法正确计算移位`2`对于每个元素并返回`2`。 

### 有效列，无效行

 输入：```
3 2
7 2
3 4
5 6
```对于第 0 列，值`7`满足$$(7-1)\bmod 2 = 0,$$所以它似乎属于这一栏。 但$$(7-1)/2 = 3,$$超出了有效行范围`0..2`。 

该算法使用以下方式丢弃它```
if target >= n:
    continue
```如果没有此检查，该值将错误地影响某些班次计数并产生太小的答案。
