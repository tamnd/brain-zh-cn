 ## 解决方案
 ## 问题理解

 对于每个测试用例，我们都会得到一个整数`n`。 我们必须确定是否`n`可以写成三个**不同**整数的乘积`a`,`b`， 和`c`，其中每个人至少`2`。 

如果存在这样的分解，我们打印`"YES"`和一个有效的三元组。 如果不存在这样的三元组，我们打印`"NO"`。 

输入最多包含 100 个测试用例，每个值`n`至多是`10^9`。 这种大小的数字仍然可以通过试除法进行因式分解`√n`， 因为`√(10^9) ≈ 31623`。 即使我们对每个测试用例都执行这项工作，计算总量仍然在时间限制内。 

主要的困难不是因式分解本身。 挑战在于找到三个不同的因素。 

考虑`n = 64 = 2^6`。 存在分解：```
64 = 2 × 4 × 8
```这三个因素都是不同的，并且至少`2`。 

现在考虑`n = 32 = 2^5`。 

可能的因式分解包括：```
32 = 2 × 2 × 8
32 = 2 × 4 × 4
```每个分解都会重复一个因子，所以正确答案是`"NO"`。 

另一个微妙的情况是当`n`正好有两个不同的质因数，但其中一个只出现一次。 例如：```
n = 12 = 2^2 × 3
```我们可以选择`2`和`3`，离开`2`作为剩余因素。 因素变为：```
2, 3, 2
```哪些是不明确的。 解决方案必须拒绝这种情况。 

另一个例子是：```
n = 72 = 2^3 × 3^2
```选择`2`和`3`树叶：```
72 / (2 × 3) = 12
```给予：```
2, 3, 12
```这是有效的。 

仅仅找到任意两个除数并将余数用作第三个因子的粗心实现可能会意外地产生重复值。 

## 方法

 暴力解决方案会尝试所有可能的三元组`(a, b, c)`这样`a × b × c = n`。 一种方法是迭代所有除数`a`，所有除数`b`，并检查剩余的商是否形成`c`。 

即使我们将自己限制为除数，这种方法也变得不切实际。 搜索空间增长得太快，尤其是在执行多达 100 个测试用例时。 

关键的观察是我们不需要所有因素。 我们只需要**三个不同的因素**。 

假设我们提取一个非平凡除数`a`从`n`。 除以之后`a`，我们得到一个较小的数字。 如果我们可以提取第二个除数`b`这不同于`a`，则剩余商自动变为：```
c = n / (a × b)
```问题简化为找到两个不同的除数，同时确保最终的商与两者不同。 

质因数分解使这变得容易。 我们反复搜索当前数字的最小除数。 

找到的第一个除数变为`a`。 

移除后`a`，我们再次搜索。 下一个除数不同于`a`变成`b`。 

剩下的一切都分配给`c`。 

如果`c`大于`1`并且与两者不同`a`和`b`，我们有一个有效的答案。 否则不存在有效的三元组。 

这是有效的，因为任何有效的分解最终都必须来自于`n`。 贪婪地提取因子为最终数字留下尽可能多的因子质量，从而更容易获得三个不同的值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) 或更糟 | O(1) | O(1) | 太慢了|
 | 最佳 | O(√n) | O(√n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 存储原始值`n`。 
2. 找到最小的除数`n`大于`1`。 

设该除数为`a`。 
3. 如果不存在除数，则`n`是素数。 

素数不能写成三个大于的整数的乘积`1`，所以打印`"NO"`。 
4. 划分`n`经过`a`。 
5. 寻找约数的另一个约数。 

除数必须不同于`a`。 
6. 设该除数为`b`。 
7. 如果不存在这样的除数，则打印`"NO"`。 
8. 计算```
c = original_n / (a × b)
```9. 检查是否`c`与两者不同`a`和`b`，以及是否`c > 1`。 
10. 如果所有检查都通过，则打印`"YES"`和三重`(a, b, c)`。 否则打印`"NO"`。 

### 为什么它有效

 该算法从中提取两个不同的重要因素`n`。 删除它们后，每个剩余的素因子都被收集到`c`。 

如果存在有效答案，则质因数分解`n`包含足够的重数和足够的不同质因数来创建三个不同的数字。 贪婪地取前两个因子，留下最大可能的余数`c`，这最大化了机会`c`与之前的选择不同。 

每当算法输出一个三元组时，乘积就是`n`因为：```
c = n / (a × b)
```并且所有三个值都被检查为不同且大于`1`。 

每当算法失败时，就无法构造三个不同的因素。 剩余因式分解结构太小，导致其中一个因式重复或变成`1`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    original = n

    a = -1
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            a = d
            n //= d
            break

    if a == -1:
        print("NO")
        continue

    b = -1
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0 and d != a:
            b = d
            n //= d
            break

    if b == -1:
        print("NO")
        continue

    c = original // (a * b)

    if c > 1 and c != a and c != b:
        print("YES")
        print(a, b, c)
    else:
        print("NO")
```第一个循环搜索原始数字的最小除数。 这变成了`a`。 

除以之后`a`，第二个循环搜索另一个不同于的除数`a`。 这变成了`b`。 

剩余的商是根据原始数字而不是根据修改后的值计算的`n`。 这两种方法都有效，但使用原始值可以使公式明确，并避免在推理代码时出现错误。 

最终的清晰度检查至关重要。 如果没有它，诸如此类的情况`12 = 2 × 3 × 2`会被错误地接受。 

所有算术都适合 Python 整数，并且不存在溢出风险。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        original = n

        a = -1
        for d in range(2, int(n ** 0.5) + 1):
            if n % d == 0:
                a = d
                n //= d
                break

        if a == -1:
            out.append("NO")
            continue

        b = -1
        for d in range(2, int(n ** 0.5) + 1):
            if n % d == 0 and d != a:
                b = d
                n //= d
                break

        if b == -1:
            out.append("NO")
            continue

        c = original // (a * b)

        if c > 1 and c != a and c != b:
            out.append("YES")
            out.append(f"{a} {b} {c}")
        else:
            out.append("NO")

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return result

# provided sample structure
out = run("5\n64\n32\n97\n2\n12345\n")
assert out.splitlines()[0] == "YES"
assert out.splitlines()[2] == "NO"
assert out.splitlines()[3] == "NO"
assert out.splitlines()[4] == "NO"

# prime number
assert run("1\n97\n").strip() == "NO"

# smallest input
assert run("1\n2\n").strip() == "NO"

# valid case with two prime factors
res = run("1\n72\n").splitlines()
assert res[0] == "YES"

# power of two that fails
assert run("1\n32\n").strip() == "NO"

# power of two that succeeds
res = run("1\n64\n").splitlines()
assert res[0] == "YES"

 ## 边缘情况

 考虑：```
n = 12
```该算法选择：```
a = 2
```划分后：```
n = 6
```下一个不同的除数是：```
b = 3
```余数变为：```
c = 12 / (2 × 3) = 2
```自从`c = a`，三元组不明确。 算法正确打印`"NO"`。 

考虑：```
n = 64
```因式分解为：```
64 = 2^6
```该算法提取：```
a = 2
b = 4
c = 8
```所有三个值都是不同的，因此它会打印`"YES"`。 

考虑：```
n = 97
```第一次搜索期间未找到除数。 由于 97 是质数，因此不存在分解为三个大于 1 的整数。 该算法立即打印`"NO"`。 

考虑：```
n = 36
```该算法发现：```
a = 2
```然后：```
b = 3
```最后：```
c = 36 / (2 × 3) = 6
```三重`(2, 3, 6)`有效，并且算法打印`"YES"`。 此案例演示了具有多个质因数的数字如何自然地产生有效的分解。
