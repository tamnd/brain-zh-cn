 ## 解决方案
 ## 问题理解

 董事会有`N`行和`M`列。 它的细胞有七种颜色，沿着对角线循环重复。 Alice 命名单元格后`(X, Y)`，我们必须确定分配给该单元格的颜色编号。 

电路板尺寸可以大到`10^6 × 10^6`，但只查询一个单元格。 这立即排除了任何明确建立董事会的方法。 即使存储颜色也需要最多`10^12`细胞，这远远超出了记忆和时间的限制。 该解决方案必须直接从坐标计算答案。 

关键的观察是同一对角线上的每个单元格具有常数`X + Y`具有相同的颜色。 移动一步到下一个对角线会增加`X + Y`增加一位，因此在七种颜色的循环中颜色也增加一位。 

一个常见的差一错误是忘记颜色的编号是从`1`而不是`0`。 例如，对于输入```
1 1 1 1
```正确答案是```
1
```因为第一个对角线以颜色开始`1`。 使用`(X + Y) % 7`直接会错误地产生`2`。 

另一个微妙的情况是对角线索引是七的倍数时。 例如，```
5 9 3 6
```有`X + Y = 9`。 由于第一条对角线对应于`X + Y = 2`，偏移量为`7`，它恰好绕循环一次。 正确的颜色是`1`， 不是`7`。 

## 方法

 简单的模拟将生成整个板对角线对角线，按重复顺序分配颜色`1, 2, ..., 7, 1, ...`。 这是正确的，因为它直接遵循着色规则。 不幸的是，董事会可能包含最多`10^12`细胞，使得运行时间和内存完全不切实际。 

关键的观察结果是颜色仅取决于包含查询单元格的对角线。 第一条对角线有`X + Y = 2`并接收颜色`1`。 每增加一分`X + Y`移动到下一个对角线并将颜色前进一位。 由于有七种颜色，我们只需要对角线偏移模七。 

对角线偏移量为```
(X + Y) - 2
```并将其转换回`1`基于颜色编号给出```
((X + Y - 2) % 7) + 1
```这可以在恒定时间内计算答案，而无需构建电路板的任何部分。

 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取四个整数`N`,`M`,`X`， 和`Y`。 计算不需要板尺寸，因为查询的坐标保证有效。 
2. 计算对角线偏移量为`X + Y - 2`。 第一条对角线有和`2`，所以减去`2`使其偏移量为零。 
3. 计算颜色`((X + Y - 2) % 7) + 1`。 模运算每七个对角线包裹一次颜色，加一会将结果转换回所需的编号`1`到`7`。 
4. 打印最终的颜色。 

### 为什么它有效

 同一条对角线上的每个单元格具有相同的值`X + Y`，所以它们必须接收相同的颜色。 相邻对角线的不同之处在于`X + Y`正好 1，在七种颜色的重复序列中向前迈出一步。 由于第一条对角线以颜色开始`1`, 移动通过`(X + Y - 2)`对角线并取模七的余数总是会产生唯一的正确颜色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, x, y = map(int, input().split())
print((x + y - 2) % 7 + 1)
```该程序读取输入，计算对角线偏移，应用模七，将结果转换回`1`基于编号，并打印它。 

故意不使用板尺寸，因为一旦查询的单元格已知，它们就不会影响颜色。 减二是关键的减一调整。 如果没有它，第一条对角线将错误地从颜色开始`3`而不是颜色`1`。 

Python 整数可以轻松处理最大可能的坐标和，因此不存在溢出问题。

 ## 边缘情况

 考虑尽可能最小的输入：```
1 1 1 1
```该算法计算`X + Y - 2 = 0`， 然后`0 % 7 = 0`，最后加一即可得到颜色`1`。 这证实了第一条对角线的处理正确。 

现在考虑偏移量恰好为 7 的对角线：```
5 9 3 6
```偏移量是`3 + 6 - 2 = 7`。 服用`7 % 7`给出`0`，加一产生颜色`1`。 这会在每七个对角线之后正确地重新启动重复序列。 

最后，考虑换行前的最后一条对角线：```
7 7 1 7
```偏移量是`1 + 7 - 2 = 6`。 剩下的还是`6`，所以颜色变成`7`。 下一条对角线将返回颜色`1`，匹配所需的循环模式。
