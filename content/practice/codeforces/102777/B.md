 ## 解决方案
 ## 问题理解

 在将每个字符替换为摩尔斯电码表示形式并将所有这些表示形式连接在一起后，我们需要确定小写英文字符串是否成为回文。 原始字母在编码前被分开，但生成的莫尔斯序列只是一串连续的点和破折号。 如果最终序列的两端读数相同，则答案为“是”，否则为“否”。 

输入长度最多为 1000 个字符。 一个字母的摩尔斯电码最多包含四个符号，因此即使编码的字符串也只有几千个字符长。 这意味着线性扫描很容易足够快，而具有二次行为的算法是不必要的，只会使实现更加复杂。 

错误的主要来源是假设可以在原始字母上检查回文性质。 编码完全改变了结构，因为不同的字母可能会创建匹配或不匹配的点和破折号图案。 

例如，输入`aarrghh`应该产生`NO`。 如果粗心的解决方案仅检查字母是否构成回文，则会发现字母是对称的，并错误地返回 YES。 必须检查莫尔斯电码表示法。 

另一个陷阱是忘记编码后字符边界消失。 输入`panne`应该产生`NO`。 字母本身不能简单地镜像为组，因为最终的比较是在各个莫尔斯符号之间进行的。 

空字符串不是可能的输入，因为该语句保证小写字母的非空序列。 单字符输入，例如`a`产生`.−`，这不是回文，所以正确的输出是NO。 

## 方法

 直接的方法是将整个输入字符串转换为摩尔斯电码，然后从头到尾比较字符。 这需要创建编码字符串并检查其第一个符号是否等于其最后一个符号，其第二个符号是否等于其倒数第二个符号，依此类推。 该方法是正确的，因为当所有镜像位置都包含相同字符时，字符串就是回文串。 

暴力实现还可以重复比较编码字符串中的每对位置。 如果编码长度约为 4000 个字符，则在最坏的情况下将执行约 1600 万次比较。 对于这些约束来说，这仍然不是灾难性的，但它是不必要的，并且忽略了回文检查的更简单的结构。 

关键的观察是我们不需要比较每一对。 回文只需要从两端传递一次。 一旦我们有了莫尔斯字符串，两个指针就可以向内移动，并在发现不同的符号时立即拒绝答案。 

蛮力之所以有效，是因为它检查与最佳解决方案相同的信息，但它重复了许多比较。 观察到在向中心移动时可以检查镜像位置，从而将工作减少为线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(平方米) | O(米) | 较大的变体太慢 |
 | 最佳 | O(米) | O(米) | 已接受 |

 这里，`m`是莫尔斯编码字符串的长度。 

## 算法演练

 1. 将每个小写英文字母的莫尔斯表示形式存储在数组中，其中索引与字母位置匹配。 这避免了在处理输入时重建映射。 
2. 读取原始字符串，并将每个字符的摩尔斯电码附加到一个连续的序列中。 有意不存储字母之间的空格，因为回文检查发生在最终的莫尔斯电码流上。 
3. 在编码序列的开头设置一个指针，在末尾设置另一个指针。 比较它们指向的两个符号。 
4. 如果符号不同，则该序列不可能是回文，所以答案立即是否定的。 任何镜像位置的不匹配都足以证明失败。 
5. 将两个指针向中心移动并继续，直到它们相遇或交叉。 如果每个镜像对都匹配，则输出 YES。 

工作原理：该算法保持了两个指针已经经过的每对位置都等于其镜像位置的不变性。 回文正是由该属性定义的。 如果算法到达中间没有发现不匹配，则每个所需的对都已被验证，因此编码的字符串必须是回文。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    morse = [
        ".-", "-...", "-.-.", "-..", ".", "..-.", "--.", "....", "..",
        ".---", "-.-", ".-..", "--", "-.", "---", ".--.", "--.-", ".-.",
        "...", "-", "..-", "...-", ".--", "-..-", "-.--", "--.."
    ]

    s = input().strip()

    encoded = []
    for ch in s:
        encoded.append(morse[ord(ch) - ord('a')])

    encoded = "".join(encoded)

    left = 0
    right = len(encoded) - 1

    while left < right:
        if encoded[left] != encoded[right]:
            print("NO")
            return
        left += 1
        right -= 1

    print("YES")

if __name__ == "__main__":
    solve()
```这`morse`数组存储一次翻译表。 指数计算采用`ord(ch) - ord('a')`将小写字母转换为从零开始的位置，因此不需要查找字典。 

在构建莫尔斯序列时使用编码列表，因为重复连接字符串可能会在某些语言中创建不必要的临时字符串。 在循环之后加入一次可以使构造简单而高效。 

两指针循环使用`left < right`因为奇数长度回文的中间字符不需要与自身进行比较。 每次成功比较后，两个指针都会向内精确移动一个位置，从而避免任何相差一的问题。

 ## 边缘情况

 输入`aarrghh`这是一个有用的例子，因为字母本身看起来是对称的。 该算法首先将其转换为莫尔斯符号，然后比较新序列的外部符号。 两指针扫描期间出现不匹配，因此正确返回NO。 

输入`panne`演示了为什么无法保留字母边界。 该算法从不比较`p`和`e`或者`a`和`n`作为字母。 它仅比较连接的莫尔斯序列内的位置，这是任务定义的实际对象。 

输入`e`产生莫尔斯序列`.`。 两个指针从相同的位置开始，因此跳过循环并且算法返回 YES。 这是单字符回文的正确行为。 

输入`zzzz`creates four identical Morse blocks. 连接后，每对镜像符号都是相等的，因此指针向内移动，直到它们交叉，答案仍然是“是”。
