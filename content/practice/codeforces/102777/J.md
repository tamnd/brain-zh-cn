 ## 解决方案
 ## 问题理解

 我们有一个`N × M`长方形板。 芯片从左上方的单元开始，沿着覆盖电路板的螺旋路径移动。 恰好之后`k`移动时，我们需要确定芯片停止处的单元格的颜色。 板子本身没有给出，因为它太大了。 它的颜色遵循重复的彩虹图案：每个对角条纹都有七种颜色之一，并且颜色循环重复。 答案是分配给最后一个单元格的 1 到 7 之间的数字。 

尺寸可以大到`10^9`，因此构建电路板是不可能的。 即使迭代所有单元格也是不可能的，因为可能有多达`10^18`细胞。 该解决方案必须仅执行少量算术运算，这排除了任何依赖于`N`,`M`，或访问过的单元格的数量。 

困难的情况是由巨大的尺寸和螺旋仅在边界改变方向的事实引起的。 直接模拟常常在这些地方失败。 

例如，对于单个单元板：```
1 1 0
```芯片永远不会离开起始单元。 答案一定是颜色`(0, 0)`，而不是尝试执行螺旋步骤的结果。 

另一个重要的情况是非常薄的板：```
1 5 3
```螺旋只是一条直线。 假设每层都有四个非空边的实现可以访问板外的单元。 

最终的边界情况是`k`正是图层上的最后一个运动。 例如：```
3 3 8
```八次移动后，筹码到达外部方块的最后一个单元格。 在检查当前层之前找到下一层的解决方案将产生错误的坐标。 

## 方法

 最直接的解决方案是存储板或模拟螺旋。 模拟很容易，因为我们只需要记住当前的位置和方向。 每次移动都会检查下一个单元格是否在棋盘内以及是否已被访问过。 后`k`移动我们计算颜色。 

这是有效的，因为螺旋路径有一个简单的局部规则。 问题是限制。 在最坏的情况下，`N`和`M`都是`10^9`，所以可以有`10^18`细胞和模拟将需要大约`10^18`运营。 即使是几十亿的操作，也远远超出了时间限制。 

关键的观察结果是螺旋由矩形层组成。 我们可以跳过完整的外层，而不是遵循每一步。 移除后`s`从外面层数，剩下的矩形有大小`(N - 2s) × (M - 2s)`。 进入层之前已经通过的细胞数量`s`可以直接计算。 这让我们可以通过二分搜索找到正确的层。 

一旦知道了该层，与该层的周长相比，剩余的移动次数就很小。 我们可以通过检查当前矩形的哪一边包含剩余距离来确定位置。 然后颜色立即从对角线索引开始。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k) | O(NM) | 太慢了 |
 | 最佳| O(log(min(N, M))) | O(log(min(N, M))) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 使用二分查找找到包含答案的螺旋层。 一层`s`包含行中的矩形`s`划船`N-1-s`并来自专栏`s`到专栏`M-1-s`。 该层之前的单元格数量是从外部移除的区域：`N*M - (N-2*s)*(M-2*s)`。 

已到达起始点的最大有效层是包含芯片的层。 

1. 将坐标系移动到所选图层。 减去前一层所花费的移动次数`k`。 芯片现在从这个较小矩形的左上角开始。 
2. 以数学方式绕该层的周界走一圈。 螺旋首先向右，然后向下，然后向左，然后向上。 每条边的长度告诉我们剩余距离是否位于该边。 
3. 将最终的从零开始的坐标转换为颜色。 对角条纹由下式确定`row + column`。 所需的颜色是：`(row + column) mod 7 + 1`。 

这样做的原因是螺旋的每个完整的外层都独立于其内部的层。 在当前层的所有单元都通过之前，芯片不能进入内层。 二分查找准确地找到了芯片停止的层，并且侧面计算保留了与原始螺旋相同的顺序。 最终坐标与完整模拟将达到的坐标相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, M, k = map(int, input().split())

    def before(layer):
        return N * M - (N - 2 * layer) * (M - 2 * layer)

    lo, hi = 0, min(N, M) // 2
    while lo <= hi:
        mid = (lo + hi) // 2
        if before(mid) <= k:
            lo = mid + 1
        else:
            hi = mid - 1

    layer = hi
    k -= before(layer)

    top = layer
    left = layer
    bottom = N - 1 - layer
    right = M - 1 - layer

    r, c = top, left

    if top == bottom:
        c += k
    elif left == right:
        r += k
    else:
        top_len = right - left
        if k <= top_len:
            c += k
        else:
            k -= top_len
            down_len = bottom - top
            if k <= down_len:
                r += k
            else:
                k -= down_len
                left_len = right - left
                if k <= left_len:
                    c = right - k
                    r = bottom
                else:
                    k -= left_len
                    r = bottom - k
                    c = left

    print((r + c) % 7 + 1)

if __name__ == "__main__":
    solve()
```功能`before(layer)`是中央快捷方式。 它计算有多少个单元属于所请求的单元之前的所有外层。 由于坐标和产品可以达到`10^18`，Python整数自然使用，无需担心溢出。 

二分搜索仅搜索可能的层数，最多为`5 * 10^8`，因此需要的迭代次数少于 30 次。 

定位到层后，代码首先处理退化情况。 一行或一列的剩余矩形没有四个有意义的边，因此单独处理它可以避免无效的长度。 

对于正常的矩形，剩余的移动量按螺旋顺序与四个边进行比较。 比较使用的是移动中测量的边长，而不是单元格，这避免了拐角处的差一错误。

 ## 边缘情况

 对于一个`1 × 1`板，二分搜索选择第 0 层，剩余矩形的两个维度均为 1。 对单个单元格的特殊处理返回起始位置，因此输入```
1 1 0
```产生颜色`1`。 

对于单排板，例如```
1 5 3
```剩下的矩形有`top == bottom`。 该算法不会尝试遍历不存在的垂直边，而是简单地沿着行移动到列`3`, 赋予颜色`4`。 

对于恰好在图层边界处结束的移动：```
3 3 8
```该算法将芯片保持在零层内，因为`k`仍在该层的周界内。 它达到`(2,0)`，其对角线索引为`2`，产生颜色`3`。 这避免了过早切换到内层的常见错误。
