 ## 解决方案
 ## 问题理解

 该任务要求我们找到将正整数变成零所需的最少移动次数。 一步操作可以将当前值减一，也可以将其替换为将数字分成两个因子并保留较大的一个而获得的较小因子。 例如，我们可以从 12 移动到 6，因为 12 = 2 × 6，并且可以从 15 移动到 5，因为 15 = 3 × 5。 

对于每个查询，我们都会得到一个起始数字，并且必须输出达到零的最短可能序列长度。 

查询的最大值为 10^6，最多可以有 1000 个查询。 探索每个可能的移动序列的解决方案是不可能的，因为状态数量很大并且分支因子随着除数的数量而增长。 即使是尝试每个值的所有可能性的简单模拟也会在值范围内接近二次工作，这对于两秒的限制来说太大了。 我们需要一种预处理方法来计算最大查询之前所有值的答案。 

棘手的情况是没有有用因子移动的数字。 素数被迫一一减少，因为它们不能分解为两个大于一的因子。 例如，输入`5`必须产生输出`5`。 假设每个数字都有因子转换的粗心实现可能会错误地访问不存在的除数。 

另一个容易犯的错误是让因子从数字转移到自身。 该运算要求两个因子都大于1，因此像4这样的数字可以移动到2，但不能移动到4。对于输入`4`，正确答案是`3`:`4 -> 2 -> 1 -> 0`或者`4 -> 3 -> 2 -> 1 -> 0`都不是最优的。 最佳路径的长度为三。 将数字本身包含在可能的转换中将创建无效的零成本循环。 

价值`1`也很特别。 它没有因子移动，并且只能进行一次减量操作。 用于输入`1`，答案是`1`。 

## 方法

 直接的解决方案是递归地定义数字的答案。 从一个值`n`，我们尝试一切可能的举动。 递减过渡给我们`dp[n - 1]`，而每个有效的因式分解`n = a × b`让我们过渡到`b`。 我们选择最好的下一个状态并添加一步。 

这种递归是正确的，因为每个第一步都必须是减量或因子替换，因此检查所有可能的第一步涵盖了每个最佳路径。 问题是重复检查每个数字的所有因式分解的成本很高。 如果我们独立计算每个状态，除数检查的总量就会变得太大。 

关键的观察是，当我们按升序处理数字时，每个较小数字的答案都是已知的。 我们不需要搜索未来状态。 我们可以预先计算答案`0`到最大查询值，使用动态规划。 

对于每个数字，我们将其分解一次并生成其除数。 每个真除数都可以是乘法分割后较大的因数。 在这些除数中，我们找到最小的已计算答案并将其用作可能的转换。 减量转换始终可用，因此它与因子转换进行比较。 

蛮力方法之所以有效，是因为当从较大数到较小数查看时，状态图是非循环的，但它会失败，因为它会重复发现相同的较小状态。 处理一次状态并重用它们的答案会将搜索变成一个动态程序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 太大，所有状态可能都是 O(n²) | O(n) | 太慢了 |
 | 最佳| O(N * 平均除数计数) | O(N) | 已接受 |

 ## 算法演练

 1. 读取所有查询并找到最大请求值。 我们只需要计算动态编程值直到这个最大值，因为每次转换总是会减少数字。 
2. 用筛子构建最小素因子数组。 这让我们可以快速分解每个数字，而不是测试每个可能的除数。 
3. 初始化`dp[0] = 0`。 处理号码来自`1`按递增顺序达到最大值。 先前的状态已经最终确定，因为每个可能的移动都会达到较小的值。 
4. 从减量运算开始计算当前数字。 这给出了候选值`dp[n - 1] + 1`。 
5.因式分解`n`并从其质因数分解生成所有因数。 对于每个真除数`d`大于 1，考虑从`n`到`d`。 由此产生的候选答案是`dp[d] + 1`。 
6. 将最小的候选存储为`dp[n]`。 预处理后，直接从该数组回答每个查询。 

为什么它有效：每一个有效的第一步`n`要么将数字减一，要么将其更改为真除数。 该算法会检查这些移动的每个可能的目的地，并选择已计算出的最佳距离为零的最小目的地。 由于所有转换都是从较大的数字到较小的数字，因此计算的递增顺序保证了递归中使用的每个值都已经是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    queries = [int(input()) for _ in range(q)]
    limit = max(queries)

    spf = list(range(limit + 1))
    if limit >= 1:
        spf[1] = 1

    for i in range(2, int(limit ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, limit + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def get_divisors(x):
        factors = []
        while x > 1:
            p = spf[x]
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            factors.append((p, cnt))

        divisors = [1]
        for p, cnt in factors:
            current = []
            power = 1
            for _ in range(cnt + 1):
                for d in divisors:
                    current.append(d * power)
                power *= p
            divisors = current
        return divisors

    dp = [0] * (limit + 1)

    for n in range(1, limit + 1):
        best = dp[n - 1]

        for d in get_divisors(n):
            if d != 1 and d != n:
                if dp[d] < best:
                    best = dp[d]

        dp[n] = best + 1

    print("\n".join(str(dp[x]) for x in queries))

if __name__ == "__main__":
    solve()
```筛子存储每个数字的最小质因数。 这避免了动态规划达到新值时的重复试除。 

除数生成器首先获得素数分解，然后通过组合素数幂来构建所有除数。 10^6 以内的值的除数数量很少，因此为每个状态生成它们的速度足够快。 

动态规划循环开始于`dp[n - 1]`，代表强制递减选项。 因子循环仅接受不同于`1`和`n`，因为两者都不代表有效的因子替换。 所有存储的值都很小，因此 Python 整数溢出不是问题。

 ## 边缘情况

 对于输入`1`，该算法不创建除数，只考虑`dp[0] + 1`，给出正确答案`1`。 

对于输入`5`，因子生成仅返回除数`1`和`5`。 两者都被排除在因子移动之外，因此该算法仅使用递减并获得`dp[5] = 5`。 

对于输入`4`，生成的除数是`1`,`2`， 和`4`。 仅有的`2`是一个有效的目的地。 该算法将递减路径与`dp[2] + 1`，选择要素转移并产生`3`。 

对于输入`12`，除数包括`2`,`3`,`4`， 和`6`。 该算法检查每个有效目的地并选择其中最小的已知距离。 这避免了仅检查最小因子的常见错误，因为操作在拆分后保留了较大的因子。
