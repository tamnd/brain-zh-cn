 ## 解决方案
 ## 问题理解

 我们需要选择一个正整数 (x)，使得 (x^n) 可以被 (m) 整除，并且在所有这些正整数中我们需要最小的一个。 如果不存在这样的 (x)，我们打印`ABSENT`。 

值 (n) 可以大到 (10^9)，因此线性依赖于 (n) 的算法已经是不必要的。 更重要的是，(m)不是任意的。 它只能是列出的值之一，即 (1,2,3,5,7,11,13,17) 或 (1000000007)。 除 (1) 之外的每个值都是质数。 这个限制是问题的中心观察。 

答案永远不需要我们搜索大范围的整数。 如果 (m>1) 且 (n>0)，则选择 (x=m) 立即有效，因为 (m^n) 可被 (m) 整除。 由于(m)本身是能被(m)整除的最小正整数，所以当(n=1)时，没有更小的(x)可以工作，而对于更大的指数，我们仍然需要(x)包含素因数(m)，所以(x\ge m)。 

边界情况值得单独关注。 用于输入`0 2`，对于每个正 (x)，我们有 (x^0=1)，并且 (1) 不能被 (2) 整除，所以答案是`ABSENT`。 总是打印 (m) for (n=0) 的粗心解决方案将输出`2`，这是错误的。 

用于输入`0 1`，答案是`1`，因为每个正整数的零次方都等于 (1)，并且 (1) 可以被 (1) 整除。 将 (n=0) 视为自动不可能的解决方案将在这里失败。 

用于输入`1 1`，答案也是`1`。 由于 (1) 可以整除每个整数，因此尽可能小的正值 (x) 就足够了。 

提供的语句摘录中还存在格式问题：显示的示例部分包含`2 2`和`3 3`输入和输出之间没有可靠的分离。 在问题所述的数学条件下，`2 2`有答案`2`， 尽管`3 3`有答案`3`。 下面的解决方案遵循正式声明，而不是损坏的示例格式。 

## 方法

 直接的暴力解决方案将尝试 (x=1,2,3,\ldots)，计算 (x^n) 是否能被 (m) 整除，并在第一个成功值处停止。 这是正确的，因为候选者是按递增顺序检查的，因此第一个有效候选者必然是最小的。 

问题是最坏的情况。 考虑 (n=1) 和 (m=1000000007)。 第一个有效 (x) 是 (1000000007)，因此强力搜索将准确检查 (1000000007) 个候选者。 即使每个可除性检查都减少为恒定时间操作，这也远远超出了一秒竞赛解决方案应该做的事情。 直接计算幂会更糟，因为 (x^n) 可能变得巨大。 

使搜索消失的观察结果是每个允许的 (m>1) 都是素数。 假设 (m=p)，其中 (p) 是素数，且 (n>0)。 如果 (p\mid x^n)，则 (p\mid x)。 这是从素数的基本属性得出的：如果素数整除一个乘积，它必须整除它的一个因数。 由于 (x^n=x\cdot x\cdots x)，幂可被 (p) 整除，迫使 (p) 整除 (x)。 

可被 (p) 整除的最小正 (x) 恰好是 (p)。 因此答案很简单：(m)。 

唯一的例外是 (m=1)，其中最小正整数始终为 (1)。 另一个例外情况是 (n=0)，因为每个正数 (x) 都满足 (x^0=1)。 因此，对于 (m>1)，当 (n=0) 时无解。

 ## 算法演练

 1. 读(n)和(m)。 我们只需要这两个值，因为可能的 (m) 值的受限集合直接为我们提供了所需的数论性质。 
2. 如果(m=1)，则打印`1`。 当 (n=0) 时，每个正整数的任何非负幂至少被定义为 (1)，并且 (1) 可被 (1) 整除。 因此，最小的正整数就是答案。 
3. 如果 (m>1) 且 (n=0)，则打印`ABSENT`。 对于每个正整数 (x)，(x^0=1)，并且没有 (m>1) 能整除 (1)。 
4. 否则(m>1)且(n>0)。 由于 (m) 的每个允许值都是素数，因此任何满足 (m\mid x^n) 的 (x) 本身必须能被 (m) 整除。 最小的正 (x) 是 (m)，因此打印 (m)。 

### 为什么它有效

 对于(m=1)，答案显然是(1)。 对于 (m>1) 和 (n=0)，每个候选者的零次幂都等于 (1)，因此没有候选者有效。 对于 (m>1) 和 (n>0)，(m) 的允许值为素数。 如果 (m\mid x^n)，素性力 (m\mid x)，因此每个有效 (x) 至少为 (m)。 同时，(x=m) 有效，因为 (m^n) 可被 (m) 整除。 因此 (m) 恰好是最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if m == 1:
        print(1)
    elif n == 0:
        print("ABSENT")
    else:
        print(m)

solve()
```第一个分支在查看 (in) 之前处理 (m=1)。 此顺序对于输入很重要`0 1`，因为答案是`1`， 不是`ABSENT`。 

第二个分支处理唯一不可能的情况。 一旦 (m>1)，(x^0) 始终为 (1)，因此不存在有效的正整数。 

最后一个分支涵盖了所有剩余的情况。 这里 (n>0) 和 (m) 是允许的素数之一，因此数字本身是最小有效基数。 

实现中没有求幂。 这避免了不必要的工作和构造极大整数的可能性。 Python 也有任意精度整数，但依赖它并不能解决潜在执行大量计算的算法问题。

 ## 边缘情况

 对于`0 2`，算法首先检查是否(m=1)，这是假的。 然后它看到 (n=0) 并打印`ABSENT`。 这是正确的，因为每个正 (x) 都满足 (x^0=1) 和 (2\nmid1)。 

为了`0 1`，第一个条件立即成功并打印`1`。 这些检查的顺序可以防止有效的 (m=1) 情况仅仅因为 (n=0) 被错误地分类为不可能的情况。 

为了`1 1`，第一个条件再次打印`1`。 由于 (1) 可以整除每个整数，因此最小的正基数始终足够。 

为了`1 17`，算法到达最后一个分支并打印`17`。 这里（17^1=17），并且小于（17）的正整数不能被（17）整除。 

为了`1000000000 1000000007`，该算法在打印答案之前仍然只执行两次比较。 巨大的指数永远不会导致循环，巨大的素数也不会导致搜索。 输出是`1000000007`。 

所有分支的中心不变量很简单：一旦 (m>1) 且 (n>0)，每个有效基数必须是素数 (m) 的倍数。 最小的可能倍数就是 (m) 本身，因此没有什么可搜索的了。
