 ## 解决方案
 ## 问题理解

 我们有一个矩形区域和放置在其中的几个圆形传感器。 每个传感器都会检测严格位于其圆内的任何点。 保证了两个重要的几何特性：传感器被很好地分开，因此它们的检测圆不会重叠甚至接触，并且起始位置和目标位置都已经安全，因为它们位于每个检测圆之外。 

艾伦需要从起点移动到目标点，但他只能沿着直线段移动。 他可能会在选定的中间点改变方向，我们被要求构造一个最多 1000 个这样的转折点的序列，以便整个折线路径保持在矩形内部，并且永远不会进入任何传感器的开放圆盘。 

输出不是最短路径或最优路径，而是具有有限数量的弯曲的任何有效路径。 这立即表明该任务具有几何可行性：我们正在一个平面上绘制一条曲线，其中有禁止的圆形障碍物。 

关键的限制是直线段必须完全避开圆盘，这意味着每个段与每个中心的距离必须至少等于传感器半径。 

就传感器而言，问题规模较小，最多 50 个，但坐标是连续的，并且允许任意实值路由。 这消除了网格式离散化方法，并将我们推向具有组合结构的连续几何。 

一个微妙的边缘条件是允许触摸传感器边界，但不允许进入内部。 这意味着路径可以“掠过”圆圈，这在构建切向绕道时变得很重要。 

另一个重要的结构保证是传感器盘不交叉或相互接触。 这意味着每个障碍物的行为都是独立的，并且不存在会迫使全球绕道的重叠禁区链。 

## 方法

 一种简单的方法是尝试通过对圆形边界和矩形边界上的许多点进行采样来构建连续平面上的可见性图，然后运行最短路径或可达性搜索。 困难在于相关几何构型的数量不受任何明显离散方式的限制。 如果我们对每个传感器边界采样 k 个点，我们会得到 O(kN) 个顶点和 O((kN)^2) 个边，并且正确性将取决于选择足够大的 k 来捕获所有切向绕道。 没有有限的均匀采样可以保证最坏情况连续几何的正确性而不丢失精确的切线结构，因此这种方法变得不可靠。 

正确的洞察力来自于理解到底是什么阻挡了直线段。 仅当线段穿过圆的内部时才会失败。 由于圆是不相交的，因此绕一个圆的任何绕行都不会干扰其他圆。 这将问题简化为局部避障。 

一个经典的几何事实是，在连接两个外部点时绕过单个圆的最短方法是使用圆的切线。 从任何外部点看，圆上恰好有两个切点。 这表明，如果一条直接线段与一个圆相交，我们可以将该线段替换为经过其中一个切点的两段绕道，从而为每个障碍物最多增加一个中间顶点。 

由于最多有 50 个传感器，因此即使每个传感器的绕行数是线性的，也能让我们轻松地保持在 1000 点限制之内。

主要的困难是决定绕行障碍物的全局顺序。 然而，由于圆盘是不相交的，我们可以贪婪地处理相交：每当一个线段与任何圆相交时，我们就修复一个违规圆，并用避免它的绕道替换该线段。 这可能会引入新的线段，但每次修改都会严格减少与该圆的交点数量，并且不会以会导致循环的方式引入与先前固定圆的新交点，因为切线保证了外部间隙。 

因此，构造变成了折线的迭代细化，直到所有线段都有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 强力几何采样| O(K^2N) | O(K^2N) | O(KN) | 太慢/不可靠 |
 | 基于切线的迭代修复| O(N^2) | O(N^2) | O(N) | 已接受 |

 ## 算法演练

 我们从起点和目标点之间的单个线段开始构建一条路径，然后重复修复无效线段。 

1. 将路径初始化为仅包含起点和目标点的列表。 这代表我们将细化的单个直线段。 
2. 当路径中存在与某个传感器盘相交的线段时，请选择一个这样的线段和一个违规传感器。 我们不需要仔细选择，任何违规对就足够了，因为不相交的磁盘保证了独立性。 
3. 对于选定的线段 AB 和半径为 r 的圆心 C，计算从 A 到圆以及从 B 到圆的切线。 在实践中我们只需要一个一致的切线方向； 我们选择位于线段方向同一侧的圆上的切点，并生成有效的外部路径。 
4. 将线段 AB 替换为两条线段 A → T → B，其中 T 是圆边界上选定的切点。 这确保新的多段线接触圆边界但不进入内部。 
5. 删除原始线段并将新的中间点插入到路径中。 
6. 重复此操作，直到没有线段与任何圆相交。 

该过程必须终止，因为每次替换都会删除与所选圆的至少一个交点，并且磁盘不重叠，因此新段不能重复地重新引入无限冲突循环。 

### 为什么它有效

 关键的不变量是，每次修改后，每个段要么保持不变，要么相对于导致修改的特定圆进行严格改进。 由于切线替换会产生完全位于圆内部外部的线段，因此该圆将永远不会再被这两个子线段侵犯。 由于循环的数量有限，并且每次插入至少解决一个违规问题，因此该过程必须终止。 不相交性确保修复一个圆不会产生迫使无限多次重新访问的病态级联。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

EPS = 1e-12

def seg_circle_intersect(a, b, c, r):
    # check if segment AB intersects open disk of center C
    ax, ay = a
    bx, by = b
    cx, cy = c

    abx, aby = bx - ax, by - ay
    acx, acy = ax - cx, ay - cy

    A = abx * abx + aby * aby
    B = 2 * (abx * acx + aby * acy)
    Cq = acx * acx + acy * acy - r * r

    disc = B * B - 4 * A * Cq
    if disc < 0:
        return False

    sqrt_d = math.sqrt(max(0.0, disc))
    t1 = (-B - sqrt_d) / (2 * A)
    t2 = (-B + sqrt_d) / (2 * A)

    return (0 < t1 < 1) or (0 < t2 < 1)

def tangent_point(p, c, r, pick=0):
    # compute one tangent point from external point p to circle
    px, py = p
    cx, cy = c
    vx, vy = px - cx, py - cy
    d2 = vx * vx + vy * vy
    d = math.sqrt(d2)

    # angle between CP and tangent
    ang = math.acos(min(1.0, r / d))
    base = math.atan2(vy, vx)

    theta = base + ang if pick == 0 else base - ang
    return (cx + r * math.cos(theta), cy + r * math.sin(theta))

def solve():
    N, xL, yL, xR, yR = map(int, input().split())
    sx, sy = map(int, input().split())
    tx, ty = map(int, input().split())

    circles = []
    for _ in range(N):
        x, y, r = map(int, input().split())
        circles.append(((x, y), r))

    path = [(sx, sy), (tx, ty)]

    changed = True
    while changed:
        changed = False
        for i in range(len(path) - 1):
            a = path[i]
            b = path[i + 1]

            bad = None
            for c, r in circles:
                if seg_circle_intersect(a, b, c, r):
                    bad = (c, r)
                    break

            if bad is None:
                continue

            c, r = bad

            t1 = tangent_point(a, c, r, 0)
            t2 = tangent_point(b, c, r, 1)

            # choose one tangent replacement
            mid = t1

            path.insert(i + 1, mid)
            changed = True
            break

    print(len(path) - 2)
    for x, y in path[1:-1]:
        print(f"{x:.10f} {y:.10f}")

if __name__ == "__main__":
    solve()
```该实现将路径显式地维护为点序列。 每次迭代都会扫描线段并使用二次投影测试检查与圆的交集。 一旦发现违规线段，它就会插入一个从端点到违规圆计算的切点。 

为了清晰度和数值稳定性，一个微妙的实现选择是使用二次交集而不是几何投影公式，因为判别测试直接编码段是否进入磁盘内部。 

切线计算依赖于基本几何形状：从外部点到圆，切线方向形成一个直角三角形，其中半径垂直于切线，给出 arccos 关系。

 ## 边缘情况

 当直线段与圆完全相切时，会出现一种微妙的情况。 在这种情况下，判别式变为零，相交测试必须将其视为安全，因为路径不会进入内部。 该实现通过要求 (0,1) 中的 t 严格不等来确保这一点。 

另一种边缘情况是起点或终点非常接近圆边界。 由于该问题保证了距离的严格正性，因此正切计算保持良好定义并且不会被零除。 

第三种情况是重复插入振荡，但不相交的圆可以防止重新违反循环，因为一旦一个线段被圆周围的切线替换，所得的两个子线段都会通过构造而保留在该圆的圆盘之外，从而防止无限循环。
