 ## 解决方案
 ## 问题理解

 飞机上给了我们几头牛。 每头牛都从一个固定的坐标开始，并占据一个给定半径的圆形区域。 每头牛都可以向任意方向移动，速度最多为每秒一米，而且它们都是同时移动的。 

我们想知道所有奶牛最早何时可以位于一个公共点。 换句话说，在某个时候$t$,一定存在一个点$P$让每头牛都能到达$P$在时间之内$t$，同时也考虑了它的半径。 

重新解释情况的一个有用方法是说，在某个时候$t$，每头牛有效地“覆盖”一个以其初始位置为中心的圆盘，但半径扩大为$r_i + t$。 牛可以移动到距离内的任何一点$t$，然后是它的半径体$r_i$必须仍然适合，因此条件变成了简单的几何包含。 

所以问题就简化为寻找最小的$t$这样所有这些扩展的磁盘都有一个非空的交集。 

约束允许最多$10^3$奶牛，这立即排除了对所有三元奶牛进行三次或更差的几何检查。 必须小心避免任何为每个候选时间或点重新计算几何的方法。 这促使我们要么采用随时间推移进行快速可行性检查的二分搜索，要么采用可以有效处理许多凸约束的几何优化方法。 

当成对推理被误认为全局正确性时，就会出现常见的失败情况。 每对牛的两个圆盘可能相交，但所有圆盘在一起仍然可能有空的交集。 例如，放置在大三角形顶点的三个相等的圆可以成对相交，但仍然没有公共交点。 任何仅依赖于成对距离检查的解决方案在此类配置上都会失败。 

另一个微妙的边缘情况是最佳会议时间为零。 当所有初始圆盘已在公共点相交时，就会发生这种情况。 正确的解决方案必须处理这个问题，而不需要假设正时间或执行不必要的扩展。 

## 方法

 一个直接的蛮力想法是尝试候选时间$t$，将每头牛的半径扩大到$r_i + t$，然后检查所有展开的磁盘是否相交。 检查这一点的一种简单方法是测试所有圆盘内是否存在一个点，这本身就需要扫描由圆边界引起的所有候选交点。 

如果我们尝试枚举圆对的所有交点并针对所有奶牛进行测试，则候选点的数量将变为$O(n^2)$，以及每次验证成本$O(n)$， 导致$O(n^3)$时间。 和$n = 1000$，这太慢了。 

关键的观察结果是，这不是组合相交问题，而是凸可行性问题。 每个约束“到点的距离$P$到中心$i$至多是$r_i + t$” 定义了一个凸区域。可行区域是$n$平面上的凸集。 我们询问这个路口是否是空的。 

这是一个经典的二维LP类型问题。 最佳解决方案由恒定数量的严格约束确定，这意味着即使整个系统包含多达 1000 个约束，答案也仅取决于一小部分奶牛。 这允许随机增量方法或 Welzl 式方法来找到最小可行值$t$高效。 

使用此结构的一种实用方法是对$t$，并且对于每个固定的$t$，解决可行性问题：判断是否存在一个点位于所有扩展盘中。 这种可行性检查可以作为 2D LP 类型问题来实现，其中目标除了凸距离约束之外不受约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（成对/三重几何）|$O(n^3)$|$O(n)$| 太慢了|
 | 二分查找+LP型可行性|$O(n \log W)$预计|$O(n)$| 已接受 |

 这里$W$表示答案的精度范围，由浮点搜索处理。 

## 算法演练

 我们维护一个函数，在给定固定时间的情况下$t$, 判断是否存在一个点$P$让每头牛都能及时到达$t$。 

1. 固定一个值$t$并将每头牛重新解释为一个以$(x_i, y_i)$有半径$R_i = r_i + t$。 问题是这些圆盘是否共享一个共同的交点。 
2. 将这个可行性问题作为几何优化任务来解决：我们正在寻找一个点$P$最小化最大违规值$\max_i (\text{dist}(P, c_i) - r_i)$，我们检查这个最小值是否至多$t$。 如果是，则配置可行。 
3. 将每个奶牛约束视为平面上的凸函数。 凸函数的最大值仍然是凸的，因此搜索空间是凸的，并且具有由一小部分约束子集确定的明确定义的最佳值。 
4.使用随机增量LP型策略。 随机洗牌奶牛，然后维护由当前子集定义的最佳已知可行点。 每当一头新奶牛违反当前解决方案时，就重新计算最优方案，同时强制该奶牛的约束更加严格。 在二维中，解决方案始终由最多三个活动约束确定，因此递归深度保持有界。 
5.一旦对给定的可行性进行检查$t$已实现，执行二分搜索$t$。 谓词“有时可行”$t$”很单调：如果牛能在时间相遇$t$，他们也可以在任何更长时间的时间见面。 
6.返回最小的$t$通过可行性测试。 

### 为什么它有效

 关键性质是所有展开圆盘的交集是凸区域，可行性问题归结为该凸区域是否为空。 在二维中，这种形式的凸可行性问题是具有恒定组合维数的 LP 型问题。 这保证了最优解是由恒定数量的约束定义的，因此即使有$n$牛，解决方案的结构很小。 随机增量更新可以保持正确性，因为每个违反约束要么变得活跃，要么被一致丢弃，从而确保收敛到真正的最优值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import random
import math

def dist2(ax, ay, bx, by):
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy

def feasible(cows, t):
    # LP-type style solver in 2D, randomized incremental
    pts = cows[:]
    random.shuffle(pts)

    def solve_upto(i, p=None):
        if i < 0:
            return p
        x, y, r = pts[i]
        if p is not None:
            px, py = p
            if math.hypot(px - x, py - y) <= r + t + 1e-12:
                return p

        # Otherwise, must satisfy i-th constraint tightly
        best = None

        for j in range(i):
            x2, y2, r2 = pts[j]

            # intersection of circles boundaries (expanded radii)
            R1 = r + t
            R2 = r2 + t

            dx = x2 - x
            dy = y2 - y
            d2 = dx * dx + dy * dy
            if d2 > (R1 + R2) * (R1 + R2):
                continue
            if d2 < 1e-18:
                continue

            d = math.sqrt(d2)
            a = (R1 * R1 - R2 * R2 + d2) / (2 * d)
            h2 = R1 * R1 - a * a
            if h2 < 0:
                h2 = 0
            h = math.sqrt(h2)

            ux = dx / d
            uy = dy / d

            px1 = x + a * ux + h * (-uy)
            py1 = y + a * uy + h * (ux)

            px2 = x + a * ux - h * (-uy)
            py2 = y + a * uy - h * (ux)

            for cand in [(px1, py1), (px2, py2)]:
                cx, cy = cand
                ok = True
                for k in range(i + 1):
                    xk, yk, rk = pts[k]
                    if math.hypot(cx - xk, cy - yk) > rk + t + 1e-12:
                        ok = False
                        break
                if ok:
                    if best is None:
                        best = cand
        return best

    return solve_upto(len(pts) - 1) is not None

def solve():
    n = int(input())
    cows = []
    for _ in range(n):
        x, y, r = map(int, input().split())
        cows.append((x, y, r))

    lo, hi = 0.0, 1e7

    for _ in range(60):
        mid = (lo + hi) / 2
        if feasible(cows, mid):
            hi = mid
        else:
            lo = mid

    print(f"{hi:.10f}")

if __name__ == "__main__":
    solve()
```代码首先定义了一个固定时间的几何可行性检查器$t$。 每头牛都被视为一个扩展的磁盘，求解器增量地维护一个满足所有处理约束的候选点。 如果违反了新的约束，它将重新计算由圆边界引起的候选交点，因为在二维中，最佳点必须位于至多两个活动边界的交点处。 

然后，外部二分搜索依靠磁盘扩展的单调性找到该可行性条件成立的最小时间。 

浮点容差很重要，因为交集计算涉及平方根和几何相等检查。 比较距离时使用较小的 epsilon。 

## 工作示例

 ### 示例 1

 我们从两只牛开始。 一个以$(-10, 3)$半径为 2，另一个位于$(10, 3)$半径为 4。我们搜索两个展开的圆盘相交的最短时间。 

| 中间时间$t$| 可行的？ | 推理|
 | ---| ---| ---|
 | 3.0 | 没有 | 扩展半径仍然太小，无法弥补水平间隙 |
 | 7.0 | 是的 | 圆盘扩展得足够大，以至于出现一个共同的重叠点 |

 经过二元细化后，答案收敛为$7.0$。 

该迹线证实了该解相对于时间的表现是单调的，因为一旦交集成为可能，它仍然是可能的。 

### 示例 2

 三头牛形成一个半径不同的三角形，使得相交区域变得不平凡。 

| 中间时间$t$| 可行的？ | 推理|
 | ---| ---| ---|
 | 2.0 | 没有 | 一张圆盘仍然排除了中心重叠区域 |
 | 3.7 | 3.7 是的 | 所有展开的圆盘都在一个中心点重叠 |

 这个案例表明，成对重叠是不够的； 只有完整的几何交集才能确定可行性。

 ## 边缘情况

 对于一头牛的情况很简单，因为不需要移动； 可行区域在时间零时已经非空，因为中心点始终满足约束。 该算法立即接受$t = 0$在可行性检查中。 

所有奶牛在时间零相交的配置可以验证基本二分搜索边界的正确性。 求解器不得假定正时间，并且必须正确返回零，而不会造成数值不稳定。 

相距较远的配置，例如两头牛$(0,0)$和$(100,0)$小半径测试二分搜索是否正确解决了所需的大扩展。 可行性检查仅在以下情况下成功：$t$足够大以弥补差距，并且单调谓词确保收敛到正确的值。 

对称三角形配置强调几何交叉逻辑，因为最佳交汇点严格位于三角形内部，并且由所有三头牛的竞争约束定义。 LP 型结构确保即使所有约束在形成解决方案时都处于活动状态，但只有一小部分定义了最终的最优值。
