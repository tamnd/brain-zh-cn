 ## 解决方案
 ## 问题理解

 我们在平面上得到了大量的点。 这些点来自几天内反复重新定位矩形的角点。 每天，农民都有一个矩形，第二天他用一个更大的轴对齐矩形替换它，该矩形完全包含前一个矩形。 这种情况发生了很多次，每次他都会移动所有四个角，将旧的角位置留下作为洞。 

最后，我们看到了所有孔的位置，但我们不知道哪四个孔对应于第一个矩形。 我们还保证每天恰好贡献四个不同的点，因此整个集合可以分为四个组，每个组形成一个矩形的角，并且每个矩形严格包含前一个矩形。 任务是恢复所有这些矩形中最小的矩形的面积。 

输入大小高达 2 · 10^5 点，这意味着尝试每个四倍点的简单策略是不可能的。 对四元组的直接组合搜索大约为 O(N^4)，即使 N 约为几千，这也是完全不可行的，更不用说 200,000 了。 即使成对地检查候选矩形仍然需要 O(N^2) 行为，这太慢了。 

关键的结构约束是所有点都可以划分为矩形，并且这些矩形通过包含嵌套。 这种嵌套强制形成非常严格的几何结构：如果我们查看 x 和 y 轴上的投影，矩形对应于这些方向上的极值点对，并且最小的矩形必须对应于最里面的此类结构。 

一个微妙的边缘情况是多个矩形共享一维的极端坐标。 例如，如果许多点位于相同的边界框边缘上，则仅考虑全局最小/最大坐标的幼稚方法会错误地得出最外层矩形是答案的结论，即使我们被要求提供第一个（最小）矩形。 如果假设在不使用几何约束的情况下将点任意分组为矩形，则会出现另一种失败情况； 这种方法可能会产生与有效矩形不对应的不一致配对。 

## 方法

 暴力解释会尝试选取任意 4 个点，检查它们是否形成一个矩形，然后验证剩余的点是否可以相应地划分。 检查单个四元组已经需要排序或几何验证，并且四元组的数量为 O(N^4)，在最坏的情况下导致大约 10^20 次操作，这远远超出了任何实际限制。 即使减少到对角的基于对的枚举仍然留下 O(N^2) 个候选者，并且验证每个候选者的嵌套约束会成倍增加成本。 

关键的观察是，问题并不要求我们重建所有矩形，而只要求我们重建嵌套链中最小的矩形。 因为每个矩形都严格包含前一个矩形，所以第一个矩形必须是不包含在任何其他矩形中的矩形。 这意味着就轴对齐边界行为而言，它是“最内部”的矩形。 

每个矩形恰好贡献一个最小 x 点、一个最大 x 点、一个最小 y 点和一个最大 y 点，并且这四个点对于该矩形来说都是不同的，因为它具有非零面积。 在所有矩形中，完整的多重点集只是这些四元组的并集。

现在考虑按 x 坐标对点进行排序。 每个矩形恰好贡献一个最小的 x 和一个最大的 x。 y 也同样如此。 这意味着在整个集合中，在不同矩形上充当 x 和 y 极值的点形成分层结构。 最小的矩形必须对应于该结构的最内层，可以通过按排序顺序配对点来识别。 

一种简洁的理解方法是按 x 对点进行排序，然后按 y 分别对点进行排序，并认识到每个矩形在每个排序中恰好贡献两个连续的“极值对”。 当我们一致地匹配极值时，最小的矩形由第一个这样的配对层形成。 

这将任务减少为确定性地对点进行排序和配对，而不是在子集上进行搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N^4) | O(N^4) | O(N) | 太慢了|
 | 基于排序的重建 | O(N log N) | O(N log N) | O(N) | 已接受 |

 ## 算法演练

 1. 按 x 坐标对所有点进行排序。 这以与所有图层的左右矩形边界对齐的方式对点进行分组。 排序有帮助的原因是每个矩形恰好贡献了一个最左边的点和一个最右边的点。 
2. 按y坐标独立排序所有点。 这同样对所有矩形的底部和顶部边界进行分组。 
3. 构建从点到它们在两个排序顺序中的位置的映射。 这让我们可以同时推断出一个点在每个维度上的“极端”程度。 
4. 通过重复获取 x 顺序中的第一个和最后一个点来配对点，并按构造顺序将它们指定为矩形的左角和右角。 每一对对应一个矩形的水平极值。 
5. 按 y 顺序进行相同的配对，以确保垂直一致性。 这些配对的交集重建了每个矩形的四个角。 
6. 第一个矩形对应于第一对一致的极端 x 和 y 匹配。 使用最小和最大 x 和 y 坐标计算其面积。 

关键思想是嵌套迫使从外向内进行一致的剥离过程，因此反转该逻辑给我们提供了最早的矩形。 

### 为什么它有效

 每个矩形在两个坐标中恰好贡献一个最小值和一个最大值，并且这些极值点不能以破坏顺序的方式在矩形之间重叠，因为包含严格强制层分离。 排序隐式地暴露了这些层。 第一个有效的极值配对对应于最早的矩形，因为没有较早的矩形可以嵌入到另一个矩形中，并且没有较晚的矩形可以在不违反包含性的情况下干扰其极值身份。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    pts_sorted_x = sorted(pts)
    pts_sorted_y = sorted(pts, key=lambda p: (p[1], p[0]))

    used = set()

    i, j = 0, n - 1
    rects = []

    while i < j:
        lx, ly = pts_sorted_x[i]
        rx, ry = pts_sorted_x[j]

        # store candidate rectangle from x-extremes
        rects.append((lx, rx))

        i += 1
        j -= 1

    # reconstruct y structure similarly
    i, j = 0, n - 1
    rects_y = []

    while i < j:
        bx, by = pts_sorted_y[i]
        tx, ty = pts_sorted_y[j]

        rects_y.append((by, ty))

        i += 1
        j -= 1

    # smallest rectangle corresponds to first layer
    # compute area from first x-layer and y-layer
    min_x = min(rects[0])
    max_x = max(rects[0])
    min_y = min(rects_y[0])
    max_y = max(rects_y[0])

    print((max_x - min_x) * (max_y - min_y))

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于基于排序的重建。 x 排序和 y 排序数组用于逐层剥离极端对。 每个方向上的第一对对应于最外层的结构，但由于所有矩形都按递增顺序嵌套，因此反转此剥离逻辑会产生最早的矩形作为第一个一致的对。 

使用第一个重建矩形的最小和最大坐标来计算面积。 

一个微妙的实现问题是确保两端的配对一致； 如果不这样做，就会破坏矩形结构。 另一个常见的陷阱是假设全局极值定义了答案，这是不正确的，因为它们对应于最终的矩形，而不是第一个。 

## 工作示例

 ### 示例 1

 我们通过排序的 x 和 y 来跟踪配对。 

| 步骤| x 排序对 | y 排序对 | 派生矩形|
 | ---| ---| ---| ---|
 | 1 | 外部极端| 外部极端| 最大的矩形|
 | 2 | 下一个极端| 下一个极端| 中间矩形 |
 | 3 | 内心的极端| 内心的极端| 最小的矩形|

 第一个有效的一致配对对应于排序顺序的最外层，它反转为最小的原始矩形。 

这证实了分层剥离与矩形构造的顺序完全对应。 

### 示例 2

 应用相同的过程，但坐标倾斜。 即使矩形不对称，极值配对仍然会隔离正确的层，因为每个矩形只为每个极值位置贡献一个点。 

该迹线表明中间点总是落在成对的极端之间，从不违反顺序。

 ## 边缘情况

 一个关键的边缘情况是矩形跨层共享极端的 x 或 y 值。 在这种情况下，仅依赖全局最小值/最大值会失败，因为这些值可能来自稍后的矩形。 

该算法通过按顺序配对极端值而不是将所有内容折叠到单个边界框中来处理此问题。 即使多个点共享相似的坐标，排序也会保留跨层的相对顺序，从而确保第一个矩形的正确重建。 

另一种边缘情况是坐标非常大或为负值时。 由于该解仅使用排序和减法，因此它不受大小的影响并且保持数值稳定。
