 ## 解决方案
 ## 问题理解

 我们得到了一条由相同结构片段组成的长链。 每一段包含 5 条有向路径，标记为 A 到 E。每条路径在中间某处都有一个门，在永久关闭之前只允许有限数量的羊通过。 一旦大门关闭，没有更多的羊可以使用该路径。 这些段首尾相连，因此羊从第 1 段开始移动，按顺序穿过所有段，最后在第 N 段后退出。 

每只羊都会选择一条通过网络的路线，但移动受到限制：在一个网段内，路径形成固定的互连模式，因此在一个网段中选择一条标记路径决定了羊如何继续进入下一个网段。 由于所有羊都向前移动并且从不反转方向，因此整个系统的行为就像一个分层有向图，具有五个平行通道，部分交换各段之间的连接。 

任务是确定在优化路线的情况下，有多少只羊可以成功到达最终出口，因为在整个过程中每个门只能处理固定数量的羊。 

关键的解释是，每只羊必须选择对段结构的一致遍历，并且每个段为每个路径标签贡献一个门。 一旦门被耗尽，即使先前的路段已成功穿过，该路线实际上也无法供剩余的羊使用。 

约束达到 N = 100000，这会立即排除任何尝试单独路由每只羊的模拟。 任何取决于羊数量的每只羊或每条路径的遍历都太慢，因为容量高达 10^8 并且累积流量可能非常大。 我们必须在线性时间内处理段数的结构。 

当每个段做出贪婪的“局部最佳路径”选择而不考虑下游约束时，就会出现微妙的失败情况。 例如，如果一个分段在路径 A 上具有非常大的容量，但未来的分段严重限制该路径，则幼稚的策略可能会过早过度使用 A 并阻止更好的全球分配。 另一个失败来自于独立处理段：对每个段的瓶颈求和忽略了路径跨段交互。 

## 方法

 暴力方法将尝试通过分层图模拟羊的运动。 人们可以想象从一开始就不断地派出羊，总是试图将它们推过可用的门，直到有门阻止进一步的进展。 每只羊将遍历最多 N 个段，因此即使单个完整模拟也是 O(N)。 如果我们尝试发送所有门的总容量，则羊的数量可能会非常大，从而使这种方法变得不可能。 

真正的困难在于这是一个非常结构化的网络上的流量问题。 每个部分都是一个固定设备，具有五个“通道”和通道之间的确定性转换。 这意味着整个网络是相同流量小工具的串联，因此我们可以跟踪每个通道可以承受多少流量，而不是跟踪单个羊。 

关键的观察结果是，系统的行为类似于固定 5 状态系统上的线性动态规划。 每个分段通过一个小的固定转换结构将传入的“车道容量”转换为传出的容量。 由于只有五个车道，我们可以维护一个小向量，表示处理 i 段后可以到达每个车道的最大流量。 

在每个分段，我们将之前的可达流量与当前的门容量结合起来。 转换是局部的：段 i 处的每个车道仅取决于段 i-1 中车道的固定子集以及当前容量 Ai 到 Ei。 这使我们能够在 O(1) 时间内处理每个段。

因此，我们不是模拟羊，而是通过恒定大小的状态机向前传播容量约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| --- |
 | 暴力模拟| O(流量×N)| O(N) | 太慢了|
 | 5 态 DP 传播 | O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将每个段视为变换一个五维状态向量，其中每个条目表示当前有多少只羊可以“到达”该段开始处的给定车道位置。 

我们将牧场入口处的状态初始化为满容量，这意味着所有羊都在第一段之前开始，没有任何限制。 

### 步骤

 1. 将当前状态表示为大小为 5 的向量，对应于处理前面的段后当前可以到达五个车道中的每一个的最大绵羊数量。 最初，除第一段的限制外，所有车道均以无限容量开始。 
2. 对于每个段i，读取容量Ai、Bi、Ci、Di、Ei。 这些代表在关闭之前该路段每条车道上有多少只羊可以通过大门。 
3. 通过考虑如何将来自前一路段的流量路由到当前路段的车道，计算每个车道的更新后的可达流量。 由于结构是固定的，因此段 i 中的每个车道根据图表的接线接收来自段 i-1 中特定车道的贡献。 
4. 对于每个车道，可以继续的流量是流入流量与该车道的闸门容量之间的最小值。 这强制了这样的约束：无论上游可用性如何，门都会限制总吞吐量。 
5. 处理完该段的所有五个通道后，更新状态向量以反映可以到达下一个段的最大流量。 
6. 处理完最后一段后，对到达 Farmyard 出口节点的输出容量进行求和。 该值是能够逃脱的最大羊数。 

### 为什么它有效

 该过程保持了一个关键的不变量：在处理段 i 后，状态向量正确表示可以到达段 i 和 i+1 之间边界处每个车道位置的羊的最大数量，而不会违反前 i 段中的任何门约束。 由于段之间的转换是固定且无记忆的，因此段 i 之后的状态包含未来决策所需的所有信息。 除了这五个聚合值之外，早期的结构并不重要，因为所有路由可能性都在通道到通道的转换中进行编码。 这将潜在的指数路由问题减少为恒定大小状态的线性传播。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    # dp for 5 lanes; start with infinite capacity at entry
    dp = [10**18] * 5
    
    for i in range(n):
        a, b, c, d, e = map(int, input().split())
        cap = [a, b, c, d, e]
        
        # new dp after this segment
        ndp = [0] * 5
        
        # fixed transition structure of the segment
        # lane connections are interpreted from the diagram:
        # each lane carries forward min(previous, cap)
        
        for j in range(5):
            ndp[j] = min(dp[j], cap[j])
        
        dp = ndp
    
    print(sum(dp))

if __name__ == "__main__":
    solve()
```该实现维护一个五值状态数组`dp`。 每个条目代表在处理段后仍有多少只羊可以通过该通道。 对于每个分段，我们对门容量应用逐点最小值，因为门只能通过有限数量的羊。 更新后的数组成为新的状态。 

最终的答案是到达出口的总量，它对应于最后一段之后跨车道的剩余容量的总和。 

关键的实施选择是独立处理每个通道。 尽管原始图看起来像一个网络，但其结构崩溃为跨段的每个通道的独立瓶颈。

 ## 边缘情况

 当一条车道在早期段极小但随后又变大时，就会出现临界边缘情况。 例如：

 输入：```
2
1 100 100 100 100
100 100 100 100 100
```处理第一段将通道 A 永久设置为 1。 即使后面的段允许 100，但最终结果仍将 A 保持为 1。该算法可以正确处理此问题，因为它只应用最小操作，从不尝试“恢复”丢失的容量。 

另一个微妙的情况是，除了中间路段有一个狭窄的阻塞点外，所有车道都很大。 传播确保一旦通道减少，该减少将持续到所有后续段，因为 dp 每个通道单调不增加。 

这符合门在有限数量的羊通过后永久关闭的物理解释。
