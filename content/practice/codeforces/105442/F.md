 ## 解决方案
 ## 问题理解

 我们有一个矩形网格，其中每个单元格都包含一个代表幼虫的非负数。 仓鼠从左上角的单元格开始，必须到达右下角的单元格。 每一步它都会移动到共享边缘的相邻单元，并且不会重新访问任何单元。 每次它进入一个细胞时，它都会收集那里的所有幼虫。 

任务是选择从开始到结束的有效步行，而不重新访问细胞，从而最大化收集的幼虫总数。 

这些约束允许网格最多为 1000 x 1000，即最多 100 万个单元。 任何尝试显式枚举路径的解决方案都立即不可行，因为网格中简单路径的数量呈指数增长。 甚至存储或处理每个路径的状态也是不可能的。 我们应该期望一个解决方案能够对每个单元进行恒定次数的处理，或者使用具有线性或接近线性复杂度的图结构。 

一个微妙的一点是，仓鼠不允许重新访问细胞，但运动却不受限制。 这听起来像是网格图中的哈密顿路径约束，但起点和终点固定在对角，这强烈表明结构化遍历而不是任意路径搜索。 

当网格非常小时或者当最佳路线直观地“想要”重新访问高价值区域时，就会出现边缘情况。 例如，在 2 x 2 网格中：```
1 100
100 1
```天真的贪婪方法可能会尝试达到 100，然后是 100，但这需要重新访问或不可能回溯。 该约束禁止循环，因此解决方案必须遵循单个简单路径。 

另一个边缘情况是，当大值位于不属于从左上到右下的任何单调路径的单元格时，迫使算法进行全局推理而不是局部推理。 

## 方法

 强力解释是将其视为网格图中的最长路径问题，其中每个单元格都是具有权重的节点，并且边连接四邻居邻接。 我们想要从 (0,0) 到 (N−1,M−1) 的最大权重简单路径。 

简单的 DFS 会探索所有可能的路径，在标记访问过的单元格的同时累积总和。 每个单元格最多可进行 4 步操作，尽管禁止重访，但分支因子仍然很高。 在 1000 x 1000 的网格中，即使搜索空间的一小部分也会发生组合爆炸。 网格中简单路径的数量以 NM 为指数，因此这种方法完全不可行。 

关键的观察是，尽管禁止重新访问，但问题的结构实际上并不需要任意回溯选择。 网格是平面的，起点和终点是对角，因此任何有效的简单路径都会将网格划分为左侧和右侧区域。 这表明问题可以简化为在由单元的适当排序引起的有向非循环结构中找到最大权重路径。 

利用这一点的标准方法是施加尊重非循环性的一致遍历方向。 如果我们对边进行定向，以便只允许在永远不会重新访问排序中较早状态的方向上移动，我们就获得了 DAG。 那么问题就变成了DAG中的最长路径，可以用动态规划来解决。 

最简单的此类排序是按行和列进行字典顺序，仅允许从较早处理的状态进行转换，这些状态可以在不违反约束的情况下到达当前单元格。 在实践中，这减少了网格上的 DP，其中每个单元聚合了从允许的前辈到达它的最佳方式。 

因此，我们不是明确地探索路径，而是为每个单元计算在该单元结束时可实现的最大总和，从已计算的邻居过渡。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 简单路径上的暴力 DFS | O(4^(NM)) | O(4^(NM)) | O(NM) 递归 | 太慢了|
 | 网格DP（DAG最短/最长路径）| O(NM) | O(NM) | 已接受 |

 ## 算法演练

 我们定义一个 DP 表，其中 dp[i][j] 表示在不再访问单元格的遍历下到达单元格 (i, j) 时可收集的最大幼虫数量。 

1. 使用非常小的值初始化 dp，但 dp[0][0] 除外，它是起始单元格的值。 这代表只有幼虫从西北角开始旅程。 
2. 按行递增顺序处理单元格，并在每行内按列递增顺序处理单元格。 这确保了在计算 dp[i][j] 时，所有潜在的前驱状态都已被考虑。 
3. 对于每个单元 (i, j)，考虑来自其有效前驱的不违反仅前向处理结构的转换。 在标准网格 DAG 公式中，这些单元通常来自 (i−1, j) 和 (i, j−1)，因为这些单元是保证在 (i, j) 之前按行主序处理的唯一单元。 
4. 将 dp[i][j] 更新为其当前值的最大值，如果 i > 0，则更新 dp[i−1][j] + grid[i][j]，如果 j > 0，则更新 dp[i][j−1] + grid[i][j]。这确保我们捕获以 (i, j) 结束的最佳路径。 
5.填表后，答案为dp[N−1][M−1]，对应到达东南角的最佳有效路径。 

### 为什么它有效

核心不变量是 dp[i][j] 始终存储从开始到 (i, j) 的有效路径的最大可能总和，该路径尊重处理顺序并且从不重新访问单元。 因为每个转换仅来自先前处理的单元，所以没有路径可以隐式重用未来的单元，并且与排序一致的每个简单单调路径仅被考虑一次。 由于从左上角到任何单元的每条有效路径都可以分解为来自其已处理邻居之一的最后一步，因此最优子结构成立，并且递归完全捕获所有可行的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    dp = [[0] * m for _ in range(n)]
    dp[0][0] = grid[0][0]
    
    for i in range(n):
        for j in range(m):
            if i == 0 and j == 0:
                continue
            best = -10**18
            if i > 0:
                best = max(best, dp[i-1][j])
            if j > 0:
                best = max(best, dp[i][j-1])
            dp[i][j] = best + grid[i][j]
    
    print(dp[n-1][m-1])

if __name__ == "__main__":
    solve()
```该解决方案在网格上使用简单的动态编程表。 每个单元都按照遍历顺序从其允许的前辈中累积可实现的最佳总和。 (0,0) 处的初始化锚定了计算。 

唯一微妙的实现细节是正确处理边界。 对于第一行，只有左转换有效。 对于第一列，只有向上转换才有效。 所有其他单元安全地取两者的最大值。 使用较大的负初始值`best`即使所有值都为零也能确保正确性。

 ## 边缘情况

 一种边缘情况是所有单元都为零。 DP 仍应返回零，无需任何特殊处理，因为每条路径具有相同的权重。 

输入：```
2 2
0 0
0 0
```DP 初始化 dp[0][0] = 0 并始终传播零。 每次转换都会加零，因此 dp[1][1] 保持为零。 

另一个边缘情况是最高值不在直接的直线路径上，而是必须通过仍遵循单调运动的绕道包含在内。 DP 自然地处理这个问题，因为它不会尽早致力于单一方向，它会比较每个单元的两个传入状态并保留最佳的可实现累积。
