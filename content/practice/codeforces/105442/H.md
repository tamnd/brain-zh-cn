 ## 解决方案
 ## 问题理解

 我们有两行平行的位置，索引都从 0 到 n − 1。第一行已经充满了鸟，其中多只鸟可能从同一位置开始。 第二行最初是空的，但每只鸟在第二行上都有固定的目标位置。 

每只鸟都定义了从第一行的起始索引到第二行的目标索引的直线段。 所有鸟同时起飞。 “危险对”是指飞行段在几何意义上相交的任何一对不同的鸟，不包括它们从同一位置开始或在同一位置结束的小情况。 

任务是计算存在多少个这样的相交对。 

这些限制意味着总共最多 2 · 10^5 只鸟。 明确考虑所有对的解决方案将需要 n^2 次比较，这远远超出了可行的限制。 即使是十亿次操作在典型的时间限制中也已经太大了，因此必须利用交叉点的结构。 

一个微妙的问题是，多只鸟可以共享相同的起点或相同的目的地。 即使简单的交叉测试会检测到它们端点的重叠，也决不能对这些对进行计数。 例如，如果两只鸟从位置 3 出发并前往不同的目的地，则根据定义，即使它们的线段可能在几何上交叉，它们也不被视为危险。 同样，如果两只鸟共享相同的目的地，它们也会被排除在外。 

当目的地大量重复时，就会出现另一个极端情况。 如果许多鸟飞向同一个目标，任何基于反转的推理都必须确保我们不会意外地计算出应该被过滤掉的对。 

## 方法

 暴力解决方案将比较每对鸟并检查它们的线段是否相交。 对于 m 只鸟，这意味着检查 m(m − 1) / 2 对。 对于每一对，我们比较端点并使用开始和结束索引的排序条件来检测交叉。 这是正确的，但对于 m 最大为 2 · 10^5 的情况，它会立即失败，因为它会导致大约 2 · 10^10 检查。 

关键的观察是每只鸟都由一对完整描述（起始位置，目标位置）。 当两个线段的起始位置以一种方式排序但其目标位置以相反的方式排序时，两个线段恰好交叉。 这是经典的反转结构：如果我们按起始位置对鸟类进行排序，然后查看目的地序列，则该序列中的每个反转都对应于一个交叉对。 

但是，我们必须小心处理重复项。 共享相同起点或相同目的地的鸟类不得计算在内。 这意味着在计算反转时，我们需要将相等的起始组视为一个块，并避免计算内部相互作用。 这同样适用于相同的目的地。 

我们通过按相同的起始位置对鸟类进行分组来解决这个问题。 在每个组内，我们按目的地进行排序，并确保我们只考虑组之间的交互。 然后，我们按递增的开始顺序处理组，并在目的地值上维护一棵芬威克树，计算有多少个先前看到的目的地大于当前目的地。 这自然会计算反转，同时考虑到相同的起始点不会相互作用。 

Fenwick 树结构允许我们插入目的地并查询在对数时间内有多少个先前目的地超过给定值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(平方米) | O(1) | O(1) | 太慢了|
 | 排序 + Fenwick 树 | O(m log n) | O(n) | 已接受 |

 ## 算法演练

 我们将每只鸟视为一对 (s, d)，其中 s 是其起始位置，d 是其目的地。 多只鸟可以共享相同的 s，因此我们首先将它们分组。

1. 将所有小鸟收集成对（s，d）。 将输入结构展平为大小为 m 的单个列表。 这简化了推理，因为我们不再关心原始的每个位置的存储。 
2. 通过增加起始位置 s 对所有鸟进行排序，对于相等的 s，按目的地 d 排序。 这确保了在起始组内，我们以一致的顺序一起处理所有鸟类。 组内的排序稍后将防止计算具有相同开始的鸟类之间的相互作用。 
3. 在目标索引上初始化 Fenwick 树。 该结构维护有多少先前处理的鸟具有每个目标值。 
4. 从左到右扫描已排序的列表。 对于每只鸟 (s, d)，我们查询有多少先前处理过的鸟的目的地大于 d。 这个数字被添加到答案中，因为这些代表了反转，即较早的鸟飞往更高的目的地，这意味着与当前的鸟交叉。 
5. 处理完查询后，将 d 插入 Fenwick 树中，以便未来的鸟类可以根据它进行计数。 
6. 由于具有相同 start 的鸟连续出现，我们确保它们不会造成内部反转。 这是通过按 (s, d) 排序来实现的，这意味着在一致处理该块的所有查询之后插入相等起始鸟，而不将块内对计算为反转。 

### 为什么它有效

 每只鸟对应从 (s, 0) 到 (d, 1) 的一段。 当且仅当两个线段的端点按相反方向排序时，这两个线段才交叉：s1 < s2 但 d1 > d2。 当我们考虑按 s 排序的 d 值序列时，这正是反转的定义。 芬威克树维护已见过的目的地的前缀计数，因此每个查询精确地计算有多少较早的段与当前的段形成反转。 按相等起始分组可确保我们永远不会比较定义中应排除的段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, v):
        i += 1
        while i <= self.n:
            self.bit[i] += v
            i += i & -i

    def sum(self, i):
        i += 1
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s

    def range_sum(self, l, r):
        if r < l:
            return 0
        return self.sum(r) - (self.sum(l - 1) if l > 0 else 0)

n = int(input())
pairs = []

for i in range(n):
    tmp = list(map(int, input().split()))
    p = tmp[0]
    for x in tmp[1:]:
        pairs.append((i, x))

pairs.sort()

max_d = n
fw = Fenwick(max_d + 1)

ans = 0

for s, d in pairs:
    # count previously seen destinations greater than d
    ans += fw.range_sum(d + 1, max_d)
    fw.add(d, 1)

print(ans)
```该解决方案首先将所有输入的鸟类展平为一个（起点，目的地）对列表。 排序确保我们按升序处理开始，这对于反转解释的成立至关重要。 

芬威克树用于维护目标值的动态频率表。 对于每只鸟，我们查询有多少个先前处理的目的地严格大于其自己的目的地。 该计数会添加到答案中，因为它代表交叉对。 

查询后，我们插入当前目的地，使其成为未来比较集的一部分。 

一个微妙的点是，我们依赖于所有目的地都位于有限范围 [0, n − 1] 内这一事实，这使得 Fenwick 索引变得简单。 range_sum(d + 1, max_d) 的使用强制执行严格的不平等，因此永远不会计算相同的目的地，这符合问题的规则，即具有相同目的地的鸟类不是危险的配对。 

## 工作示例

 考虑一个存在三只鸟的小例子：

 输入：```
0: 1
1: 0
1: 1
```这意味着鸟是（0→1），（1→0），（1→1）。 

排序后的对变为：

 (0,1), (1,0), (1,1)

 我们一步步追踪芬威克州。 

| 步骤| 鸟 | 查询 (>d) | 插入后的芬威克状态| 运行答案|
 | ---| ---| ---| ---| ---|
 | 1 | (0,1)| 0 | {1:1} | 0 |
 | 2 | (1,0)| 1 | {0:1,1:1} | 1 |
 | 3 | (1,1) | 0 | {0:1,1:2} | 1 |

 第二只鸟与第一只鸟贡献了一个反转，因为在开始顺序中 1 > 0，但在目的地顺序中 1 < 0，形成交叉。 

现在考虑一个有重复的情况：

 输入：```
0: 0 1
1: 1
```对：

 (0,0), (0,1), (1,1)

 处理显示在起始 0 内，没有对进行计数，并且仅包括有效的交叉起始反转。 Fenwick 结构绝不会以产生错误交叉的方式相互比较两个 (0, *) 对。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 空间| O(n + m) | Fenwick 树和输入对的存储 |

 ## 边缘情况

 一种极端情况是许多鸟共享相同的起始位置。 例如，所有的鸟都从0开始，前往不同的目的地。 输入产生一个具有相同 s 值的大组。 由于排序将它们放在一起，芬威克树永远不会看到这些鸟的较早开始，因此组内不会计算倒置，正确地产生零。 

另一个极端情况是所有鸟类共享相同的目的地。 即使起始位置不同，所有对都会形成相等的 d 值，并且 Fenwick 查询中的严格不等式会阻止对它们进行计数。 例如，(0→5)、(1→5)、(2→5) 不会产生危险对，因为所有比较都不满足 d1 > d2 条件。 

最后的边缘情况是完全反向的映射，其中起点不断增加，而目的地严格减少。 这会创建最大数量的反转，并且芬威克树将每个先前元素累加为大于当前元素，产生完整的三角形计数，从而确认反转逻辑的正确性。
