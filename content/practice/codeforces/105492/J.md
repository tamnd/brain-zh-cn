 ## 解决方案
 ## 问题理解

 我们从游戏记分牌收到一系列快照，其中每个快照包含两个整数，代表两支参赛球队当时的得分。 这些快照按照到达的顺序发送，但该顺序可能无法反映比赛进行的实际时间顺序。 

任务是确定给定的序列是否可以代表真实比赛的有效时间线。 有效的时间线意味着从一个快照到下一个快照，两支球队的得分都不会下降。 两个分数都可以保持不变或增加，但永远不会随时间下降。 

所以我们不会重建时间线，也不会重新排序任何内容。 我们只是简单地检查给定的顺序是否已经同时遵守两个坐标上的单调性约束。 

约束很小：最多 100 个快照，每个分数在 0 到 100 之间。这立即告诉我们，任何二次解都是非常安全的，线性扫描就足够了。 不需要复杂的数据结构或搜索。 

这个问题的主要微妙之处在于理解“时间顺序”的含义。 它不是按时间显式排序或比较时间戳。 我们唯一的线索是分数只会随着时间的推移而增加。 这条规则完全决定了有效性。 

一些边缘情况可以打破天真的思维：

 如果我们只检查总分是否增加，我们可能会失败。 例如，(2, 5) 紧接着 (3, 4)，总计为 7，然后是 7，因此总计不会减少，但第二队的得分从 5 下降到 4，这是无效的。 如果粗心的解决方案会错误地接受这一点。 

如果我们只检查每个快照在某些部分意义上（例如最大或最小排序）是否“大于或等于”，我们也会失败。 例如，(1, 10) 到 (2, 0) 的最大值不断增加，但违反了两个分量的单调性。 

因此，必须在连续快照之间按组件检查正确的条件。 

## 方法

 暴力思维可能会尝试通过考虑所有快照对并检查是否存在满足全局单调性约束的一致顺序来验证一致性。 这类似于构建偏序图并检查有效的线性扩展。 虽然这在理论上是正确的，但在这里完全没有必要，因为输入顺序是固定的，我们不允许对任何内容重新排序。 

相反，我们观察到，如果序列在时间顺序上有效，则每个相邻的转换必须为两个团队保留非递减值。 相反，如果每个相邻对都满足此条件，则整个序列必须有效，因为单调性是传递的：一旦没有步骤减少任一坐标，则较早的快照不能违反较晚的快照。 

这将问题简化为对数组进行单遍检查，在每一步验证简单的不等式条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（全局一致性推理）| O(n²) 或更糟 | O(n) | 已接受但没有必要 |
 | 最优（相邻验证）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 按给定顺序读取所有快照，并将它们存储为整数对。 
2. 从第二个快照迭代到最后一个快照。 
3. 对于位置 i 处的每个快照，将其与位置 i−1 处的前一个快照进行比较。 
4. 如果任一队的得分从 i−1 下降到 i，则立即断定该序列无效。 
5. 如果循环结束后没有发现任何减少，则得出序列有效的结论。 

每个步骤都侧重于邻接性，因为任何违反单调性的行为都必须首先出现在某些直接过渡中。 如果发生掉落，则无法在多个步骤中“隐藏”它。 

### 为什么它有效

关键的不变量是，在处理每个位置 i 后，从 0 到 i 的所有快照都是一致的，因为两个分数序列都是非递减的。 如果在任何时候我们检测到减少，我们就会打破不变量并正确拒绝该序列。 

如果没有相邻对违反单调性，则对于任何索引 i < j，重复应用非递减属性可确保 a[i] ≤ a[j] 和 b[i] ≤ b[j]。 这保证了整个序列在时间上有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
prev_a, prev_b = map(int, input().split())

ok = True

for _ in range(n - 1):
    a, b = map(int, input().split())
    if a < prev_a or b < prev_b:
        ok = False
    prev_a, prev_b = a, b

print("yes" if ok else "no")
```该解决方案在向前扫描时仅保留先前的快照，这已经足够了，因为有效性仅取决于连续的转换。 变量`prev_a`和`prev_b`代表时间线中最后确认的有效状态。 

条件检查`a < prev_a or b < prev_b`直接编码了两个分数都不允许降低的规则。 无条件更新以前的值可以确保我们即使在检测到违规后也能继续检查完整的序列，尽管我们也可以提前中断。

 所有转换都保留不递减的分数，所以答案是肯定的。 

该跟踪表明，一旦两个序列逐步单调，整个时间线就会保持一致。 

### 示例 2

 输入：```
3
0 0
1 0
0 2
```| 我| 上一页 | 当前| 有效的转换 |
 | --- | --- | --- | --- |
 | 1 | (0,0) | (0,0) | (1,0)| 是的 |

 在第二次转换时，第一支球队的分数从 1 降至 0，这会立即破坏有效性。 

这表明，即使一个坐标显着增加，另一坐标的任何减少都会使整个序列无效。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们只处理每个快照一次并执行恒定时间比较 |
 | 空间| O(1) | O(1) | 仅存储前一对分数 |

 约束允许最多 100 个快照，但即使这个数量大得多，线性扫描也将保持高效。 该解决方案是最佳的，因为每个输入值必须至少读取一次。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    prev_a, prev_b = map(int, input().split())

    ok = True

    for _ in range(n - 1):
        a, b = map(int, input().split())
        if a < prev_a or b < prev_b:
            ok = False
        prev_a, prev_b = a, b

    return "yes" if ok else "no"

# provided samples
assert run("4\n1 0\n2 0\n4 0\n4 1\n") == "yes"
assert run("3\n0 0\n1 0\n0 2\n") == "no"

# minimum size
assert run("1\n5 7\n") == "yes"

# monotone increase both
assert run("3\n0 0\n0 1\n2 3\n") == "yes"

# single drop in second coordinate
assert run("3\n0 0\n1 2\n2 1\n") == "no"

# flat sequence
assert run("4\n2 2\n2 2\n2 2\n2 2\n") == "yes"

 ## 边缘情况

 具有单个快照的最小输入始终代表有效的时间线，因为没有先前的状态违反单调性。 该算法读取第一对并立即输出 yes，而不进入循环。 

快照中所有分数保持相同的平坦序列也是有效的。 每次比较`a < prev_a or b < prev_b`计算结果为 false，因为允许相等。 不变量在每一步都成立。 

一种微妙的失败情况是一个坐标显着增加而另一个坐标略有减少。 例如，(1, 10) 后跟 (5, 3) 可能看起来像是整体进展，但第二次坐标下降会立即使其失效。 该算法在第一次违规转换时捕获了这一点并正确地拒绝它。
