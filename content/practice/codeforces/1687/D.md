 ## 解决方案
 ## 问题理解

 对于每个整数，查看它周围的两个连续的完全平方数。 

如果$$m^2 \le x < (m+1)^2,$$然后$g(x)=m^2$和$f(x)=(m+1)^2$。 当该数字严格靠近下方方块而不是上方方块时，该数字被称为“可爱”。 

简短的计算给出$$x-m^2 < (m+1)^2-x$$这相当于$$x \le m^2+m.$$在两个连续方块之间的块内，可爱的数字形成一个连续的区间：$$[m^2,\;m^2+m].$$例如：$$[1,2],\quad [4,6],\quad [9,12],\quad [16,20],\ldots$$我们给定一个排序数组$a$。 我们必须找到最小的非负移位$k$这样每个值$a_i+k$属于那些可爱的间隔之一。 

限制因素使问题变得困难。 数组长度达到$10^6$，所以多次检查所有元素的任何事情都是不可能的。 价值观本身最多是$2\cdot10^6$，它比$n$，表明重复值应该被压缩掉。 时间限制也排除了逐一检查轮班的情况。 

当许多数组元素相等时，会出现微妙的边缘情况。 考虑```
3
5 5 5
```所有三个值在移位后始终表现相同。 单独处理重复项会浪费大量工作。 删除重复项不会改变可行性。 

另一个容易犯的错误是错误地处理中点。 例如，之间$9$和$16$，可爱区间是$[9,12]$。 价值$13$已经接近$16$比$9$，所以它不可爱。 使用非严格不等式会错误地对中点相邻值进行分类。 

第三个陷阱是假设所有移位的数字必须以相同的可爱间隔结束。 为了```
2
1 100
```最佳移位将两个值置于完全不同的可爱区间内。 任何基于选择单个目标间隔的解决方案都会立即失败。 

## 方法

 蛮力的想法很简单。 尝试$k=0,1,2,\ldots$并检查是否每个$a_i+k$很可爱。 使用整数平方根可以轻松确定一个数字是否可爱。 

问题在于搜索空间。 答案可能是数百万，每张支票都涉及到$10^6$元素。 最坏的情况很容易超过$10^{12}$运营。 

关键的观察是可爱数字的集合不是任意的。 可爱区域和非可爱区域交替出现，每个区域都是一个连续的区间。 

可爱的间隔是$$[1,2], [4,6], [9,12], [16,20], \ldots$$它们之间的非可爱间隔是$$[3,3], [7,8], [13,15], \ldots$$它们的长度遵循一个简单的模式：$$1,1,2,2,3,3,4,4,\ldots$$我们不是直接搜索移位，而是枚举哪个可爱区间包含移位后的最小数组值。 

认为$a_0+k$位于一个特定的可爱区间内。 这立即给出了一系列可能的$k$。 然后，我们检查数轴上的每个交替线段，并确定哪些数组值将落在该线段内。 

如果该段很可爱，则其内部的值就可以，但它们不能跨越其右边界。 这给出了一个上限$k$。 

如果该片段不可爱，那么那里可能没有任何价值。 自从增加$k$将所有内容向右移动，我们可以强制最左边的违规值离开该段。 这给出了下界$k$。 

所有约束都变为间隔更新$k$。 如果生成的可行范围非空，则其左端点是所选可爱区间的最小有效答案。 产生可行范围的第一个可爱区间给出了全局最优值。 这是预期的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\text{answer}\cdot n)$|$O(1)$| 太慢了|
 | 最佳 |$O(M\log U)$|$O(U)$| 已接受 |

 这里$U$是值范围并且$M$是必须检查的交替段的数量。 

## 算法演练

 1. 从数组中删除重复值。 

相同的价值观总是一起移动，因此只有不同的价值观才重要。 
2. 生成可爱和非可爱片段交替的边界。 

它们的长度是$$1,1,2,2,3,3,\ldots$$这允许在线性时间内生成所有段边界。 
3. 列举每一个可爱的片段$i$。 

认为$a_0+k$位于该段内。 
4. 根据该假设，计算初始可行范围$$[lo,hi].$$这正是保持的一组班次$a_0+k$内段$i$。 
5. 扫描后续段$j$。 

对不同的数组值使用二分搜索，找到所有位于段内的值$j$对于当前的移位范围。 
6.如果段$j$很可爱，更新上限。 

当前该段内的任何值都不得跨越其右边界。 
7.如果段$j$不可爱，更新下界。 

每个有问题的值都必须通过增加$k$。 
8. 如果在任何时候$lo>hi$，当前起始段无法产生有效答案。 
9. 第一个可行区间不为空的可爱线段给出答案$lo$。 

### 为什么它有效

 对于固定的可爱片段，包含$a_0+k$，每个数组值单调移动为$k$增加。 在任何段内，当前占用该段的值集都可以通过二分搜索找到。 

可爱的段仅施加上限，因为向右移动太远会导致某些值离开该段。 非可爱段仅施加下限，因为增加$k$最终将所有令人反感的价值观排除在外。 

当前起始段的每个有效班次都位于维护的间隔内$[lo,hi]$，以及里面的每个班次$[lo,hi]$满足所有已处理的约束。 当间隔变空时，该起始段不存在可行的移位。 当处理完所有相关段后它仍为非空时，其左端点是该假设下的最小有效移位。 由于可爱的片段是按递增顺序考虑的，因此第一个成功的片段给出了全局最小的答案。 

## Python 解决方案```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    a = sorted(set(a))
    m = len(a)

    V = []
    cur = 0

    LIM = 4020200

    for i in range(1, LIM + 1):
        V.append(cur)
        cur += i
        V.append(cur)
        cur += i - 1

    for i in range(2, LIM, 2):
        lo = max(0, V[i] - a[0])
        hi = V[i + 1] - 1 - a[0]

        add = lo

        j = i
        while j <= LIM and lo <= hi:
            if V[j] - V[i] > 15505000:
                break

            x = bisect_left(a, V[j] - add)
            y = bisect_left(a, V[j + 1] - add, x)

            if x < y:
                if j % 2 == 0:
                    hi = min(hi, V[j + 1] - a[y - 1] - 1)
                else:
                    lo = max(lo, V[j + 1] - a[x])

            j += 1

        if lo <= hi:
            print(lo)
            return

solve()
```第一步压缩重复项。 这很关键，因为$n$可以达到一百万，而取值范围只有两百万。 

数组`V`存储交替的段边界。 连续的对定义可爱和非可爱区域。 生成规则反映了长度模式$1,1,2,2,3,3,\ldots$。 

对于每个候选的可爱片段，`lo`和`hi`描述将最小数组值保留在该段内的所有移位。 

二分搜索定位其移位位置落在特定段内的所有不同值。 由于数组已排序，因此一对下界足以识别整个块。 

更新内容```
hi = min(hi, ...)
```来自可爱的片段。 跨越正确的边界将使一些价值进入不同的区域。 

更新内容```
lo = max(lo, ...)
```来自非可爱的部分。 我们必须加大转变力度，将所有令人反感的价值观赶出该地区。 

逐一的细节是实现中最微妙的部分。 线段边界被视为半开区间，因此公式使用`-1`正是右端点必须保持包容性的位置。

 ## 边缘情况

 考虑```
3
5 5 5
```价值$5$已经很可爱了，因为它就在里面$[4,6]$。 重复压缩后，数组就变成了`[5]`。 该算法立即找到可行的移位范围，其中包含$0$，所以答案是$0$。 

考虑```
1
13
```价值$13$位于非可爱区间$[13,15]$。 该算法从候选可爱片段开始并计算可行范围。 第一个成功的范围是通过以下方式获得的$k=3$，生产$16$，这很可爱。 

考虑```
2
2 3
```数量$2$很可爱，同时$3$不是。 粗心的中点治疗可能会错误地接受$k=0$。 间隔更新检测到$3$占据非可爱段并将下限提高到$1$。 移位后，数组变为$(3,4)$，只有这样两个值才满足定义。
