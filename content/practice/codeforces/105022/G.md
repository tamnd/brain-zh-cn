 ## 解决方案
 ## 问题理解

 给定两个长度为 N 的序列，我们使用它们定义一个 N × N 矩阵，其中每个条目都是通过将第一个序列的行权重与第二个序列的列权重相乘而形成的。 具体来说，条目 (i, j) 是 a_i 乘以 b_j，因此每一行都是同一向量的缩放副本，并且每一列也以相同的乘法方式构造。 

根据该矩阵 A，我们需要计算标准矩阵乘法下的 A 的 K 次方。 得到A^K后，我们就不需要完整的矩阵了。 唯一感兴趣的数量是其所有条目的总和。 

约束允许 N 最大为 100000，这立即排除了在完整 N × N 结构上的任何直接矩阵乘法或求幂。 单个矩阵乘法在简单形式中已经需要 N^3 运算，即使 N = 1000，这也远远超出了限制，更不用说 100000 了。即使优化的乘法仍然太大，因为矩阵很密集。 

指数 K 可以大到 998244352，这也排除了迭代乘法。 任何有效的解决方案都必须将问题简化为 O(N) 或 O(1) 聚合上的运算，并以对数时间或更短的时间处理求幂。 

当 K = 0 时，会出现微妙的边缘情况。在这种情况下，无论 a_i 和 b_i 如何，A^0 都是单位矩阵。 其条目之和恰好为 N，因为只有对角线条目为 1。除非单独处理，否则导出正幂的任何公式通常都会在 K = 0 处中断。 

另一个极端情况是 K = 1，其中答案必须减少到 A 本身所有条目的总和。 该值是 (sum a_i) 乘以 (sum b_i)。 任何导出的公式都必须完全折叠到此。 

最后，a_i 或 b_i 中的负值很重要，因为点积和幂等中间乘积必须对 998244353 取模。延迟模数归约的粗心实现可能会溢出或产生不正确的行为。 

## 方法

 解决这个问题的简单方法是从两个序列显式构造矩阵 A，然后使用标准矩阵乘法将其与自身相乘 K 次。 两个 N × N 矩阵的每次乘法都需要 O(N^3) 次运算，并且重复 K 次使得复杂性过高，即使对于很小的 N 也是如此。由于时间和内存的原因，即使是 N = 100000 的单个乘法也是不可能的。 

关键的结构观察是 A 不是一般矩阵。 每个条目都是行相关项和列相关项的乘积，这意味着 A 是两个向量的外积。 这使得 A 成为 1 阶矩阵。 1 阶矩阵在乘法下具有非常强的闭包性质：两个 1 阶矩阵的乘积保持为 1 级，并且结构以可预测的标量方式演化。 

如果我们写 A = a * b^T，那么 A 乘以自身就会折叠成涉及点积 b^T a 的标量因子，同时保留外积结构。 这意味着重复乘法不会增加结构的复杂性，只会增加单个标量指数的复杂性。 

这将问题从矩阵求幂简化为结合一些向量和和点积的标量求幂。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力矩阵乘法 | O(K·N^3) | O(K·N^3) | O(N^2) | O(N^2) | 太慢了|
 | Rank-1 归约 + 求幂 | O(N + log K) | O(N + log K) | O(1) 额外 | 已接受 |

 ## 算法演练

 我们将第一个序列表示为向量 a，将第二个序列表示为 b。 

### 1. 计算三个核心聚合

 我们计算 a 中所有元素的总和、b 中所有元素的总和以及它们的点积。 

总和捕获了当所有条目聚合时外积的行为方式。 点积是外积矩阵相乘时出现的关键标量。

### 2. 处理指数为零的情况

 如果 K = 0，则结果是单位矩阵，并且其条目之和恰好为 N。我们立即返回该值，因为正幂的代数公式不适用。 

### 3. 计算标量转移因子

 设 s 为点积 sum_i a_i * b_i。 A 本身的每次乘法都会将 s 因子引入矩阵结构中。 经过 K - 1 次乘法后，该因子变为 s^(K-1)。 

这是有效的，因为每个中间乘法都会通过 (a b^T)(a b^T) = a (b^T a) b^T 崩溃。 

### 4. 与外部总和相结合

 1 阶矩阵 a b^T 中所有条目的总和为 (sum a_i) * (sum b_i)。 经过 K 次乘法后，该值按 s^(K-1) 缩放。 

所以最终的答案是：

 (a_i 总和) * (b_i 总和) * (点(a, b))^(K-1)

 ### 为什么它有效

 矩阵 A 从外积开始，它是 1 阶线性变换。 两个这样的矩阵的乘法仅引入一个新的标量项，即定义向量的内积，同时保留外积形式。 这意味着由 A 的幂生成的可能矩阵的空间在缩放范围内是一维的。 每个幂 A^k 的区别仅在于应用于相同的 1 阶结构的标量因子。 由于求和项在该结构上是线性的，因此最终答案仅取决于三个标量和一个幂运算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(x, e):
    res = 1
    while e > 0:
        if e & 1:
            res = res * x % MOD
        x = x * x % MOD
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    sum_a = 0
    sum_b = 0
    dot = 0

    for i in range(n):
        ai = a[i] % MOD
        bi = b[i] % MOD
        sum_a = (sum_a + ai) % MOD
        sum_b = (sum_b + bi) % MOD
        dot = (dot + ai * bi) % MOD

    if k == 0:
        print(n % MOD)
        return

    factor = mod_pow(dot, k - 1)
    ans = sum_a * sum_b % MOD
    ans = ans * factor % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先在数组上的单个线性传递中计算所需的三个聚合。 每个值立即以给定模数为模减少，以避免溢出并保持模算术中点积的一致性。 

特殊情况 K = 0 在任何求幂之前显式处理。 这避免了无效的指数逻辑并直接返回单位矩阵和。 

模幂可以在对数时间内有效地计算标量转移因子，这是必要的，因为 K 可以大到 998244352。 

最后，将结果组装为两个和以及指数点积的乘积，并在每一步应用模乘法以保持正确性。

 ## 边缘情况

 当 K = 0 时，算法绕过所有向量结构并直接返回 N。这可以避免错误地应用 1 阶幂公式，否则会尝试将点积提高到负指数。 

当 N = 1 时，矩阵简化为单个值 a_1 * b_1。 在这种情况下，公式变为 (a_1 b_1)^K，算法生成 sum_a = a_1, sum_b = b_1, dot = a_1 b_1，因此结果变为 a_1 b_1 * (a_1 b_1)^(K-1)，正确地简化为 (a_1 b_1)^K。 

当值为负或较大时，每次乘法的模数归约可确保正确性。 如果没有立即取模，点积可能会溢出并默默地破坏幂基，从而导致完全错误的结果。
