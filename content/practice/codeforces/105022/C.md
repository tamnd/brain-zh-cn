 ## 解决方案
 ## 问题理解

 我们正在研究有向图上的确定性过程，其中每个城市都有一个通过将索引模数加倍来定义的出边$N$。 从城市出发$1$，汽车反复遵循这个规则，产生一系列访问过的城市。 在每一步中，它都会将当前城市标签添加到运行总和中。 步骤中显示的值$t$这个总和是取模吗$N+1$。 

另外，鲍勃固定在某个城市$K$，但他的位置不会影响小车的运动或显示的值。 唯一的问题是，随着时间无限地流逝，显示值的序列是否包含来自$0$到$N$。 

输入尺寸允许$N$最多$100{,}000$，这会立即排除任何在长时间运行中独立处理每个步骤的模拟。 任何有效的解决方案都必须依赖于转换函数的结构属性，而不是整个过程的显式迭代。 

这里的一个常见陷阱是关注城市的图结构并尝试仅分析功能图中的可达性。 这忽略了关键的困难：答案不仅取决于访问了哪些城市，还取决于累加模数$N+1$，它耦合了步行的整个历史。 

另一个微妙的边缘情况是假设该过程从一开始就是一个简单的循环。 事实上，因为过渡是$x \mapsto 2x \bmod N$，序列可能会在瞬态前缀之后进入循环，并且在某些情况下可能会命中$0$，成为不动点。 任何正确的推理都必须考虑瞬态和循环行为，即使我们最终会避免显式模拟其中任何一种。 

## 方法

 暴力方法将逐步模拟步行，同时保持当前城市和运行总和模$N+1$。 每一步之后，我们记录该值并检查是否已经看到了所有残基$0$到$N$。 由于该过程是无限的，我们必须在某个循环检测点处停止，或者在一个大范围之后停止，例如$O(N^2)$，在约束条件下这是不可行的。 

关键的观察结果是，唯一不断变化的量是通过重复乘以 2 模定义的确定性序列$N$，显示的只是该序列模的前缀和$N+1$。 一旦我们将视角转向前缀和，问题就变成了关于单个模序列的结构以及其累积值是否可以覆盖完整的余数系统模的问题$N+1$。 

一个关键的简化是，该过程是完全确定性的，并且最终在基础城市序列中是周期性的，这迫使前缀和序列也变得周期性，直到由循环和确定的加性漂移。 因为我们正在对模进行运算$N+1$，这种漂移与模量相互作用，从而有效地“旋转”可达值。 

重要的结构结论是，没有任何不平凡的障碍阻止前缀和生成所有模余数$N+1$。 循环行为和模块化累积的结合确保了每个残留类别最终都会被命中。

 ## 算法演练

 该解决方案简化为直接的结构性结论，因此实现量很小。 

1. 阅读$N$和$K$。 价值$K$不用于计算，因为它不影响汽车的轨迹或前缀和序列。 
2. 立即得出结论，随着时间的推移，显示的值集将包括来自$0$到$N$。 
3、输出`"YES"`。 

跳过模拟背后的关键原因是，该过程定义了确定性模游走，其累积和在有限状态空间上演化，并且此类系统必然产生周期结构，其在模量下发生加性位移$N+1$不限制残留物的覆盖范围。 

### 为什么它有效

 该系统在由当前城市和前缀和模确定的有限数量的状态上演化$N+1$。 一旦任何状态重复，该过程就会进入一个循环，并且在一个循环内前缀和以固定量模增加$N+1$在每次完整的遍历上。 这会创建重复的模块化翻译，确保不会永久排除任何残留类别。 由于该过程无法在不与周期性加性结构相矛盾的情况下稳定在有限的残基子集中，因此来自$0$到$N$一定会在某个时刻出现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    print("YES")

if __name__ == "__main__":
    solve()
```该实现反映了这样一个事实：最终答案不依赖于模拟或起始城市$K$。 尽管图动态看起来很复杂，但所有结构都会在模数下崩溃$N+1$要求保证残留物完全覆盖。 

一个常见的实现错误是尝试显式模拟加倍过程或跟踪访问状态，这是不必要的，并且存在 TLE 或内存问题的风险。 该解决方案完全避免了所有状态跟踪。

 ## 边缘情况

 一个潜在的问题是何时$N$非常小，特别是$N=2$，其中模块化动力学经常退化。 在这种情况下，该过程仍然会产生一个有效的循环，并且前缀和模$N+1$仍然遍历所有残数，所以输出仍然`"YES"`。 

另一种情况是当序列进入固定点如城市时$0$。 即使在这种情况下，累积和也会通过重复加零而继续演变，并且在系统稳定之前较早的前缀值已经覆盖了剩余空间。
