 ## 解决方案
 ## 问题理解

 我们得到了一组由整数表示的馅饼。 相等的整数意味着相等的填充物。 我们可以选择任何吃它们的顺序。 

对于每一个出现多次的馅料，我们可以查看进食顺序中连续出现的馅料之间的距离。 距离严格定义为它们之间的馅饼数量。 例如，在序列中：```
1 2 3 1
```两次出现填充`1`有距离`2`。 

我们的目标是排列所有馅饼，使所有相同馅料之间的最小距离尽可能大。 我们必须输出可达到的最大最小距离。 

测试用例的数量最多为 100 个，但重要的约束是所有测试用例的馅饼总数最多为`10^5`。 这立即表明解决方案`O(n log n)`每个测试用例都是可以接受的，而任何二次的都是不可能的。 如果重复模拟重新排列的结构执行与答案时间成比例的工作，那么它会太慢`n`。 

有几种边缘情况很容易误判。 

考虑：```
3
3 3 3
```唯一可能的顺序是：```
3 3 3
```距离是`0`和`0`，所以答案是：```
0
```仅基于不同填充物数量的简单公式在这里会失败，因为只有一种填充物。 

考虑：```
6
1 1 1 2 2 3
```最频繁的填充出现了 3 次。 人们可以尝试均匀分布三份副本：```
1 2 1 3 1 2
```最小距离仅为`1`。 答案取决于有多少元素可以放入由最频繁的值创建的间隙中，而不仅仅是频率本身。 

另一个微妙的情况是：```
6
2 5 2 3 1 4
```示例答案是`4`。 既然值`2`出现两次，我们可以将所有四个剩余元素放在它们之间：```
2 5 3 1 4 2
```距离变为`4`。 这表明距离可能远大于重复值的频率。 

## 方法

 强力方法将生成多重集的排列，计算每个排列中相等填充之间的最小距离，并取最佳值。 这是正确的，因为它直接搜索整个解空间。 不幸的是，即使对于`n = 15`, 已经有超过`10^12`排列。 实际限制是`10^5`，所以穷举搜索是完全不可能的。 

关键的观察结果是，只有具有最大频率的填充物才是重要的。 

假设最大频率为`mx`。 让`cnt`是准确发生的填充数`mx`次。 

想象一下将所有出现的最频繁的填充放在第一位。 由于每一个填充物都会出现`mx`时代，他们创造`mx - 1`连续副本之间的内部间隙。 

例如，如果两个填充物各出现四次：```
A A A A
B B B B
```那么有`3`必须分隔连续副本的间隙层。 

其他的馅饼只能用来填补这些空白。 让```
rest = n - mx * cnt
```是频率严格小于最大值的小馅饼的数量。 

这些`rest`元素可以分布在`mx - 1`间隙组。 如果每个间隙接收到```
rest // (mx - 1)
```元素，并且某些间隙接收一个额外的元素，则最小的间隙大小恰好变为```
rest // (mx - 1)
```在考虑了以下事实之后`cnt`最大频率填充物具有相同的结构，最终公式为```
(rest // (mx - 1)) + cnt - 1
```这是官方解决方案中证明的值。 

整个问题归结为计算频率。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1、统计每次填充的次数。 
2. 求最大频率`mx`。 
3. 计算到底发生了多少次填充`mx`次。 调用这个值`cnt`。 
4. 计算剩余的肉饼数量：```
rest = n - mx * cnt
```5.如果`mx = 1`，每种馅料都是独一无二的。 The problem guarantees at least one duplicate, but handling this case makes the formula complete. 答案是`n - 1`。 
6. 否则计算：```
answer = rest // (mx - 1) + cnt - 1
```7. 输出答案。 

第 6 步有效的原因是`mx - 1`最频繁的填充所产生的强制分离层是瓶颈。 所有剩余元素必须分布在这些层之间。 商告诉我们每层可以接收多少个填料，并且`cnt - 1`考虑了占据每层内位置的额外最大频率填充。 

### 为什么它有效

 让频率最高的填充物成为主色。 任何有效的排列都必须将连续出现的每个主色分隔一定数量的元素。 由于每种主色都出现`mx`次，正好有`mx - 1`需要填充的区间。 

非主导元素的总供给量为`rest`。 尽可能均匀地分布它们可以最大化最小间隔。 没有任何安排可以使每个间隔大于`rest // (mx - 1)`，因为只有`rest`可用填充元件。 

当存在多种主色时，它们可以相互交织。 这有效地有助于`cnt - 1`每个间隔都有额外的位置。 由此产生的值既是可实现的也是最佳的，给出：```
rest // (mx - 1) + cnt - 1
```## Python 解决方案```python
import sys
from collections import Counter

input = sys.stdin.readline

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = Counter(a)

        mx = max(freq.values())
        cnt = sum(1 for v in freq.values() if v == mx)

        rest = n - mx * cnt

        answer = rest // (mx - 1) + cnt - 1
        ans.append(str(answer))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```实现直接遵循数学公式。`Counter`计算线性时间内的所有频率。 变量`mx`存储最大频率。 变量`cnt`计算有多少填充物达到该频率。 

表达式```
rest = n - mx * cnt
```删除所有出现的最大频率填充。 剩下的正是可以用来填补空白的元素。 

最终公式使用整数除法。 这很重要，因为我们将填充元素分布在`mx - 1`间隙，并且只有完整的组才有助于最小间隙大小。 

所有计算都适合标准 Python 整数。

 ## 边缘情况

 考虑：```
1
3
5 5 5
```这里`mx = 3`,`cnt = 1`， 和`rest = 0`。 公式给出：```
0 // 2 + 1 - 1 = 0
```任何重新排列都不能产生正距离，因为每个位置都包含相同的填充。 

考虑：```
1
6
1 1 1 2 2 2
```我们有`mx = 3`,`cnt = 2`， 和`rest = 0`。 

公式给出：```
0 // 2 + 2 - 1 = 1
```安排例如：```
1 2 1 2 1 2
```达到最小距离`1`，并且不可能有更大的值，因为没有额外的填充物可用于扩大间隙。 

考虑：```
1
6
2 5 2 3 1 4
```我们有`mx = 2`,`cnt = 1`， 和`rest = 4`。 

公式给出：```
4 // 1 + 1 - 1 = 4
```安排：```
2 5 3 1 4 2
```将所有剩余的四个馅饼放在两个副本之间`2`, 产生距离`4`，与最佳答案匹配。
