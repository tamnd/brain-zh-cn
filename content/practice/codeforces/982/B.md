 ## 解决方案

 ## 问题理解

 巴士由$n$独立的行，每行恰好包含两个座位。 每行都有固定的宽度$w_i$，并且所有宽度都是不同的，因此我们始终可以毫无歧义地比较行。 

乘客按照固定的顺序一一到达。 有两种类型的行为。 内向的人总是坚持坐在完全空的一排，并在所有这些排中选择宽度最小的一排。 外向的人只能坐在已经有一个座位的一排，并且在那些部分坐满的排中选择宽度最大的一排。 

任务是模拟这个过程和输出，为每个到达顺序的乘客，他们乘坐哪排。 

约束条件达到$n = 200{,}000$，因此模拟涉及到$2n = 400{,}000$运营。 任何扫描每位乘客所有行的解决方案都会像$O(n^2)$，这远远超出了可行的限度。 这立即迫使我们维护有序的候选行集，以便可以在对数时间内做出每个决策。 

两个群体之间的互动出现了一个微妙的问题。 内向的人从“空集”中删除行并将它们移动到“半填充集”中。 外向的人会从那个半满的集合中消费。 通过扫描所有行来重新计算这些集合的简单实现将失败，不是因为正确性，而是因为它会在完成之前很长时间就超时。 

当最小宽度的空行和最大宽度的半填充行以交错方式演变时，就会出现边缘情况。 例如，如果宽度是$[1,2,3]$顺序是$010101$，可用集合的结构在每次移动后都会发生变化，并且正确性取决于始终从正确的动态前沿中进行选择，而不是从头开始重新计算。 

## 方法

 暴力模拟将为每位乘客扫描所有行并检查它们是否为空或半占用，然后应用选择规则。 对于内向的人来说，这意味着扫描所有$n$行以找到空的宽度中的最小宽度，并再次进行外向扫描以找到半填充的宽度中的最大值。 每位乘客的费用$O(n)$，导致$O(n^2)$总操作量，大致$1.6 \times 10^{11}$最坏的情况下进行检查，这是不可行的。 

关键的观察是，这两种选择都依赖于维护动态变化的有序结构。 内向的人总是需要可用空行中的最小值，而外向的人总是需要部分填充的行中的最大值。 这正是优先级队列（堆）或平衡有序集的设计目的。 如果我们将空行存储在以宽度为键的最小堆中，将半填充的行存储在以宽度为键的最大堆中，则每个操作都会在对数时间内变成一次推送或弹出。 

我们还需要记住给定宽度对应于哪一行，以便当我们输出赋值时我们可以映射回行索引。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(n)$| 太慢了|
 | 最优（堆）|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们维持两个优先结构。 一种存储按增加宽度排序的所有当前空行。 另一个存储已经有一名乘客的所有行，按宽度递减排序。 

我们还维护从宽度到行索引的映射，因为选择是基于宽度的，但输出需要行号。 

### 步骤

 1. 从每个宽度初始化一个映射$w_i$到其行索引$i$。 这确保我们可以将选定的宽度转换回正确的输出行。 
2. 将所有行插入按宽度键控的空行最小堆中。 一开始，每一行都是空的。 
3. 为半占用的行维护一个空的最大堆。 内向者占据第一个座位后，该堆将存储行。 
4. 按照输入字符串的顺序处理乘客。 
5. 如果当前乘客是内向者，则从空堆中提取宽度最小的行。 将此行分配给乘客，然后将其推入半占用的堆中。 原因是这一行不再是空的，现在应该适合外向者。 
6. 如果当前乘客是外向的，则从半占用的堆中提取宽度最大的行。 将这一排分配给乘客并将其完全删除，因为两个座位现在都已满。 选择规则保证了正确性，因为外向的人总是喜欢部分填充的行中最大的宽度。 

### 为什么它有效

 在任何时刻，每一行都属于三种状态之一：完全未使用、部分填充或完全填充。 内向规则仅与未使用的行交互，外向规则仅与部分填充的行交互。 堆强制要求根据每条规则的最佳候选者始终可用$O(1)$访问时间和可拆卸时间$O(\log n)$。 由于行永远不会在状态之间向后移动，因此结构在整个过程中保持一致，从而保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    w = list(map(int, input().split()))
    s = input().strip()

    import heapq

    # min-heap for empty rows: (width, row_index)
    empty = []
    # max-heap for half-occupied rows: (-width, row_index)
    half = []

    for i, wi in enumerate(w, 1):
        heapq.heappush(empty, (wi, i))

    res = []

    for c in s:
        if c == '0':
            wi, idx = heapq.heappop(empty)
            res.append(idx)
            heapq.heappush(half, (-wi, idx))
        else:
            wi_neg, idx = heapq.heappop(half)
            res.append(idx)

    print(*res)

if __name__ == "__main__":
    solve()
```空堆存储按宽度排序的所有未使用的行，以便内向的人始终可以获取最小的可用行。 一旦选择了一行，它就会被移动到宽度为负的半填充堆中，以便 Python 的最小堆表现得像最大堆。 

半填充的堆确保外向者始终检索可用行中宽度最大的行。 一旦外向的人入座，这一排就被占满并完全移走。 

关键的实现细节是，行永远不会重新插入到空堆中，并且每行只移动到半满堆中一次，从而保证正确的状态转换。

 ## 边缘情况

 关键的边缘情况是最小的空行成为序列中稍后的半填充行中最大的空行。 由于宽度不同且状态转换是单向的，因此该算法不需要协调堆之间的冲突； 一旦一行离开空堆，它就不会再在那里竞争。 

对于输入：```
n = 2
w = [2, 1]
s = 0101
```逐步：

 内向者首先选择第 2 行（宽度 1），然后外向者必须根据半堆选择第 2 行或第 1 行。 堆确保第 2 行正确地处于半填充结构中，因此外向行为保持一致。 

这证实了在整个模拟过程中保持正确性的是状态分离，而不是重新计算。
