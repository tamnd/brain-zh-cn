 ## 解决方案

 ## 问题理解

 我们得到了一系列不同的正整数，代表随着时间的推移观察到的鲨鱼的每日移动距离。 我们引入一个阈值$k$。 如果距离小于，每一天都被归类为“停留日”$k$，或者“搬家日”（如果至少是）$k$。 

关键的结构解释是，所有日期都被分为最大连续的停留天数段，并由移动天数分隔。 每个这样的线段代表一个位置，线段的长度是鲨鱼在该位置停留的连续天数。 

鲨鱼永远不会返回到之前的位置，这意味着分割是线性的并且一旦固定$k$被选中。 然而，我们施加的约束更强：所有停留段必须具有相同的长度。 在所有门槛中$k$满足此属性，我们希望最大化分段数量，如果多个阈值达到该最大值，我们选择最小的$k$。 

约束条件$n \le 10^5$意味着任何解决方案都比$O(n \log n)$是有风险的，任何超过所有候选阈值的二次方都是不可能的。 由于距离不同，排序成为一种自然的工具，并且问题的结构强烈表明候选阈值仅对数组元素周围的值起作用。 

当所有值相对于值都非常小或非常大时，就会出现微妙的边缘情况$k$。 如果$k$小于所有值，每天都成为移动日，产生零停留段，这是无效的。 如果$k$大于所有值，我们得到一个长段，它通常满足相等的长度，但给出最小的分段计数。 

另一种重要的情况是当形成段但它们的长度不同时。 例如，如果选择其中一项$k$产生像 2, 1, 2 这样的段长度，那么即使段存在也是无效的，因为需要相等。 

## 方法

 暴力策略会尝试所有可能的阈值$k$从 1 到$10^9$，模拟分段，计算所有停留段长度，并验证它们是否相等。 这立即变得不可行，因为每次模拟都是$O(n)$，以及候选人的数量$k$值高达$10^9$，导致最坏情况的复杂性远远超出任何限制。 

我们需要观察到，唯一有意义的阈值是那些改变至少一个元素的分类的阈值。 由于分类仅取决于是否$a_i \ge k$，唯一相关值$k$位于数组的连续排序值之间。 

更深入的见解是，一旦我们确定了一个阈值$k$，序列变成二进制数组：1代表值$\ge k$, 否则为 0。 然后问题就变成了这个二进制数组的分割问题。 我们希望所有连续的零块具有相同的长度，并且我们希望最大化零块的数量。 

我们可以迭代候选值，而不是直接尝试所有阈值$k$从排序数组派生的值并有效评估诱导分割。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解所有k |$O(n \cdot 10^9)$|$O(1)$| 太慢了|
 | 排序阈值评估 |$O(n^2)$朴素模拟 |$O(1)$| 太慢了|
 | 对不同值的优化扫描 |$O(n \log n)$|$O(n)$| 已接受 |

 最佳方法依赖于对阈值转换发生位置的排序和增量评估，有效地维护段长度，而不是每次都从头开始重新计算。 

## 算法演练

 1. 对数组进行排序，同时跟踪原始值。 排序顺序告诉我们元素何时从“低于阈值”切换到“高于阈值”，如下所示$k$增加。 
2、扫一扫$k$使用排序值作为断点从低到高。 两个连续值之间$a[i]$和$a[i+1]$，二进制数组的结构不会改变，所以只有这些点很重要。 
3.对于固定候选人$k$，构建一个概念性的二进制数组，其中位置为$a_i < k$为零，其他为一。 不要每次都显式地构建它，而是模拟零的运行。 
4. 遍历数组一次，计算所有零段的长度。 忽略单段，因为它们代表移动。 
5. 检查所有零段长度是否相等。 如果没有，则丢弃此$k$。 
6. 如果有效，则计算零段的数量。 如果此计数大于迄今为止找到的最佳计数，请更新答案。 如果相等则选择较小的$k$。 

### 为什么它有效

 关键的不变量是对于固定的$k$，零的分割完全由相对顺序决定$a_i$关于$k$。 自从改变$k$仅更改精确值的比较$a_i$，所有有效的段结构必须出现在这些离散的转变点处。 因此，仅评估这些候选者涵盖了所有可能的不同细分。 相等条件将问题简化为检查二进制分区中的统一块长度，这可以在每个候选的线性时间内进行验证。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def get_segments(arr, k):
    seg_lengths = []
    i = 0
    n = len(arr)
    
    while i < n:
        if arr[i] >= k:
            i += 1
            continue
        j = i
        while j < n and arr[j] < k:
            j += 1
        seg_lengths.append(j - i)
        i = j
    
    return seg_lengths

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    vals = sorted(set(a))
    
    best_segments = 0
    best_k = 0
    
    for k in vals:
        segs = get_segments(a, k)
        if not segs:
            continue
        
        if len(set(segs)) == 1:
            cnt = len(segs)
            if cnt > best_segments or (cnt == best_segments and (best_k == 0 or k < best_k)):
                best_segments = cnt
                best_k = k
    
    print(best_k)

if __name__ == "__main__":
    solve()
```功能`get_segments`构造值严格低于的所有连续块$k$。 每个区块对应一个位置。 然后，该解决方案通过将段长度转换为一组并检查其大小是否为一来验证一致性。 

外循环仅迭代数组的不同值，因为两个连续值之间的任何阈值都会产生相同的分类模式，因此仅测试代表性点就足够了。 

在打破平局逻辑时必须小心：当多个阈值产生相同数量的段时，我们明确地更喜欢较小的阈值$k$，确保确定性输出。

 ## 边缘情况

 当所有元素都小于所选元素时$k$，整个数组变成一个段。 该算法通过生成一个零块来处理这个问题，其长度为$n$，这是有效的并且产生段计数 1。 

当$k$小于所有元素，不存在零段。 由于段列表为空，因此实现正确地跳过了此类情况。 

当段存在但长度不等时，`set`检查立即拒绝它们。 例如，如果候选人产生长度$[2, 1, 2]$，集合变为$\{1,2\}$，验证失败并被丢弃。 

这些行为确保只有结构一致的阈值才能得出最终答案。
