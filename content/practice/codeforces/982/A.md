 ## 解决方案
 ## 问题理解

 我们有一排椅子，每张椅子要么有人占用，要么空着。 配置表示为二进制字符串，其中`1`意味着一个人坐着并且`0`意思是座位是空的。 

仅当没有两个人坐在一起时，座位安排才被视为有效。 除此之外，我们不仅仅检查有效性。 我们还需要确定配置是否已经是“最大”，这意味着在不违反任何两个被占用的椅子不相邻的规则的情况下，无法在任何空椅子上放置额外的人。 

因此，任务不是构建一个座位，而是同时验证两个属性。 首先，当前的排列必须已经满足邻接规则。 其次，每个空座位必须被至少一个已经被占用的邻居“挡住”，这样在其中插入一个人就会立即违反规则。 

约束条件`n ≤ 1000`意味着 O(n²) 模拟仍然会通过，但没有必要。 一次线性扫描就足够了，因为关于座位的每个决定仅取决于其紧邻的座位。 

一些边缘情况比乍一看更重要。 

如果字符串是`"0"`为了`n = 1`，那么它不是最大的，因为我们可以将一个人放在那里并且仍然满足规则。 

如果字符串是`"1"`，那么它就是最大的，因为我们已经有一个人了，不可能有额外的安置。 

如果我们看到`"101"`，它是有效且最大的，因为单个零与两个一相邻，因此它不能容纳任何人。 

如果我们看到`"1001"`，它是有效的但不是最大的，因为中间`"00"`包含至少一个我们仍然可以放置人的位置。 

这些示例显示了关键的微妙之处：最大化是指任何有效插入的存在，而不仅仅是当前配置的局部有效性。 

## 方法

 蛮力策略会尝试每个空位置并检查是否放置一个`1`那里保持配置有效。 对于每个候选位置，我们扫描邻居以确保不违反邻接关系。 如果任何放置有效，则配置不是最大的。 这种方法是正确的，但对于每个`n`我们可以扫描到的位置`n`字符，给出 O(n²) 行为。 

问题的结构允许更直接的观察。 仅当两个相邻位置都在时，座位才可用`0`（或者不存在于边界处）。 因此，当每次配置时，配置都是最大的`0`被“阻塞”，意味着至少一个相邻位置被`1`。 如果一个`0`没有相邻的`1`，它立即成为一个有效的插入点。 

这将问题简化为一次扫描，检查是否有任何索引违反了此阻塞条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们扫描一次字符串并检查是否存在可以放置人的位置。 

1. 迭代每个索引`i`在字符串中。 

每个职位如果当前是，则为安置的候选者`0`。 
2. 对于每个`0`，检查它的邻居。 

如果左邻居（如果存在）和右邻居（如果存在）都满足，则放置有效。`0`。 
3. 如果我们找到这样的位置，我们可以立即断定座位不是最大的。 

这是因为我们已经明确地找到了保留邻接规则的有效插入。 
4. 如果扫描全串后不存在该位置，则配置为最大。 

### 为什么它有效

 关键属性是安排一个人担任职位的有效性`i`仅取决于`i-1`和`i+1`。 如果任一邻居是`1`，禁止放置。 如果两者都是`0`（或出界），始终允许放置。 因此，任何两个邻居都为空的索引的存在等价于非极大值。 扫描会针对每个可能的插入点精确检查此条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
s = input().strip()

for i in range(n):
    if s[i] == '0':
        left_ok = (i == 0) or (s[i - 1] == '0')
        right_ok = (i == n - 1) or (s[i + 1] == '0')
        if left_ok and right_ok:
            print("No")
            sys.exit()

print("Yes")
```该代码对字符串执行一次传递。 对于每个零，它检查两个邻居是否也为零或在边界处不存在。 如果找到这样的位置，我们立即输出`"No"`因为我们可以在不违反规则的情况下插入一个人。 否则，循环完成并输出`"Yes"`。 

边界处理是明确完成的：当`i = 0`或者`i = n - 1`，我们将失踪的邻居视为自动安全的。 这避免了索引错误，并符合边只有一个约束而不是两个约束的想法。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input().strip())
    s = input().strip()

    for i in range(n):
        if s[i] == '0':
            left_ok = (i == 0) or (s[i - 1] == '0')
            right_ok = (i == n - 1) or (s[i + 1] == '0')
            if left_ok and right_ok:
                return "No"
    return "Yes"

# provided samples
assert run("3\n101\n") == "Yes"

# minimum size, empty seat always improvable
assert run("1\n0\n") == "No"

# single occupied seat is maximal
assert run("1\n1\n") == "Yes"

# clear non-maximal case
assert run("3\n000\n") == "No"

# alternating pattern already maximal
assert run("5\n10101\n") == "Yes"

# boundary case with middle free space
assert run("4\n1001\n") == "Yes"

 ## 边缘情况

 对于`n = 1`，考虑输入`"0"`。 该算法检查索引 0，发现它是`0`，并且由于边界规则，两个邻居都被视为安全。 它立即断定可以插入并输出`"No"`。 

为了`"1"`，循环永远找不到`0`，所以它永远不会触发拒绝，最终的输出是`"Yes"`。 

为了`"1001"`，检查索引 1 和 2。 在索引 1 处，左边是`1`所以放置失败。 在索引 2 处，右边是`1`所以放置失败。 由于没有索引满足两个空邻居条件，因此算法正确返回`"Yes"`。
