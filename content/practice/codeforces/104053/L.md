 ## 解决方案
 ## 问题理解

 我们给出一个场景，其中$n$不同的人将被安排到$m$标记了车站，每个车站都有一个队列。 这里的队列不仅仅是一个集合，而是一个有序列表，因此每个车站内人员的内部排序很重要。 

车站的人员分配和车站内的秩序都没有固定。 一旦您决定，对于每个车站，哪些人会去那里以及他们出现的顺序，每个有效的配置都会被完整描述。 

如果存在至少一个站，其中分配的人员集合不同或者他们的顺序不同，则两种配置被认为是不同的。 

所以任务是纯粹的组合：计算我们可以分割多少种方式$n$标记元素进入$m$标记有序序列，允许某些站为空，并返回模 998244353 的结果。 

从约束条件来看，$n$可以大到$10^5$并且最多有100个测试用例。 这立即排除了子集上的任何指数枚举或 DP。 甚至$O(n^2)$在最坏的情况下，每个测试用例都太慢。 该解决方案必须在预处理后将每个测试用例减少到恒定数量的组合评估。 

当考虑空车站时，会出现一种微妙的边缘情况。 例如，当$n = 1, m = 3$，单人可以被分配到三个站中的任意一个，另外两个保持空着。 任何正确的公式自然必须包含具有空队列的配置。 另一个边缘情况是当$m = 1$，在这种情况下，答案减少为计算所有排列$n$人们，因为一切都被强制放入一个有序队列中。 

## 方法

 直接的暴力方法会尝试将每个人分配给其中一个$m$站，然后独立地对每个站进行排序。 这导致了大量的状态。 即使我们只考虑任务，也有$m^n$分配人员的方式，对于每次分配，我们必须考虑每个站内的排列。 这远远超出了任何可行的计算。 

关键的结构观察是内部排序和分配以消除复杂性的方式相互作用。 我们可以考虑首先全局决定所有内部顺序，然后决定如何将它们拆分为队列，而不是直接构建队列。 

重新构建结构的一个有用方法是想象我们首先将所有$n$人在一个单一的排列。 一旦我们确定了一个排列，每个站就对应于提取该排列的子序列，保留顺序。 唯一剩下的自由是如何将排列中的每个人分配给其中一个$m$站，但现在每个站内的相对顺序已经由全局排列确定。 

这种观点将问题分为两个独立的部分：选择所有人的全局排序，然后决定如何将该排序拆分为$m$标记子序列，可能为空。 选择分割方式的数量是经典的星条计数：我们正在分配$n$将元素排序为$m$有序的桶，允许空，相当于选择$m-1$之间的分隔符$n + m - 1$职位。 

这导致了一个干净的封闭形式：答案变成了排列的数量$n$元素乘以弱组合的数量$n$进入$m$部分。 

最终结果：$$\text{answer} = n! \cdot \binom{n + m - 1}{m - 1}$$| 方法| 时间复杂度| 空间复杂度| 判决 |

 ## 算法演练

 1. 预先计算阶乘和逆阶乘直至最大值$n + m$跨所有测试用例。 这是必要的，因为两者$n!$并且重复需要二项式系数，并且每个测试用例重新计算它们会太慢。 
2. 对于每个测试用例，请阅读$n$和$m$。 有效配置的结构仅取决于这两个值，而不取决于任何附加的输入结构。 
3. 计算$n!$，代表全局排序的方式数量$n$人们。 这捕获了所有可能的相对顺序，稍后可以将其分发到站点中。 
4. 计算$\binom{n + m - 1}{m - 1}$，表示将有序序列拆分为的方法数$m$当只有相对顺序很重要时，可能会出现空的连续组。 这相当于在尊重秩序的同时选择去每个车站的人数。 
5. 将模 998244353 下的两个量相乘并输出结果。 

### 为什么它有效

 核心不变量是每个有效的配置都可以由两个独立的选择唯一地表示：所有人的全局排列和弱组合$n$确定该排列中有多少元素属于每个站。 排列确定了所有个体的相对顺序，而组合仅决定了站点之间的切割尺寸。 没有两个不同的对会产生相同的最终配置，并且每个有效配置都可以唯一地分解为这样的对，因此对这些对进行计数就可以得出方案的确切数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAX = 200000

fact = [1] * (MAX + 1)
invfact = [1] * (MAX + 1)

for i in range(1, MAX + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAX] = pow(fact[MAX], MOD - 2, MOD)
for i in range(MAX, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    ans = fact[n] * C(n + m - 1, m - 1) % MOD
    print(ans)
```阶乘表构建一次，以便可以在恒定时间内回答每个测试用例。 组合函数使用预先计算的逆阶乘以避免重复重新计算模逆。 表达式$C(n + m - 1, m - 1)$在选定的预计算限制下是安全的，因为$n + m \le 2 \cdot 10^5$。 

一个常见的实施陷阱是忘记车站可能是空的，这就是为什么需要弱组合而不是严格组合的原因。 另一个微妙的问题是每个测试用例的阶乘溢出或重新计算，这将在最坏情况的输入下出现 TLE。 

## 工作示例

 ### 示例 1

 让$n = 2, m = 2$。 

我们计算$2! = 2$， 和$\binom{2 + 2 - 1}{2 - 1} = \binom{3}{1} = 3$。 

所以答案是$2 \cdot 3 = 6$。 

| 步骤| 价值|
 | ---| ---|
 |$n!$| 2 |
 |$C(n+m-1, m-1)$| 3 |
 | 结果 | 6 |

 这证实了我们正确地统计了同一车站内的人员或跨车站的人员等病例。 

### 示例 2

 让$n = 3, m = 1$。 

我们计算$3! = 6$， 和$\binom{3}{0} = 1$。 

| 步骤| 价值|
 | ---| ---|
 |$n!$| 6 |
 |$C(n+m-1, m-1)$| 1 |
 | 结果 | 6 |

 这与单一车站的直觉相符，所有的安排只是所有人的排列。

 ## 边缘情况

 当$m = 1$，公式简化为$n! \cdot \binom{n}{0} = n!$，这正确地反映了所有人都必须位于一个有序队列中。 该算法可以自然地处理这个问题，因为二项式系数的计算结果为 1。 

当$m = n$，在多种配置下，每个站最多可容纳一个人。 公式变为$n! \cdot \binom{2n-1}{n-1}$，这正确地包括某些站为空而其他站包含一个元素的情况。 组合部分考虑了所有有效的分布。 

什么时候$n = 1$，表达式变为$1! \cdot \binom{m}{m-1} = m$，对应于选择哪个站接收单人。 排列组件很简单，组合组件完全确定答案，匹配空队列的预期行为。
