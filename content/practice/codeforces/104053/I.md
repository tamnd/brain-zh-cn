 ## 解决方案
 ## 问题理解

 给定一棵有 n 个节点的树。 选择一个节点作为初始感染源，该选择是随机但加权的：选择节点 i 的概率与 ai 成正比。 之后，感染沿着树结构确定性地传播，因为边缘是唯一可能的路径，但感染如何穿过每条边缘是概率性的。 

如果受感染的节点 u 有一个未受感染的邻居 v，则 v 被感染的概率为 pv。 一旦 v 被感染，它就可以对其邻居继续相同的过程。 该过程一直持续到不再出现新的感染为止。 

对于从 1 到 n 的每个 k，我们需要恰好 k 个节点最终被感染的概率，模 1e9 + 7。 

关键的结构约束是 n 最多 2000，这会立即排除任何枚举节点子集或模拟每个起始根的随机过程的解决方案。 尝试考虑所有可能的感染子树或所有根选择与所有传播结果相结合的幼稚方法将呈指数爆炸，因为每条边都会引入独立的概率决策。 

当所有感染概率均为 1 时，会出现微妙的边缘情况。在这种情况下，从所选根可达的整个连接组件始终被完全感染，即整棵树，因此只有 k = n 具有非零概率。 任何错误地将传播视为每个节点独立而不是每个边缘方向独立的方法都会错误地传播部分感染或重复计数状态。 

另一种边缘情况是当某些 pi 为 0 时。然后感染无法向外穿过这些边缘，这有效地将感染区域分割成具有阻塞传出边缘的根连接组件。 忽略传播方向性的幼稚模型可能会错误地允许感染通过不同的邻居路径“重新进入”。 

最后，起始节点的随机性至关重要。 许多不正确的公式假设固定根或均匀根选择，但这里权重 ai 定义概率分布，因此每个 DP 必须仔细合并 sum(ai) 的归一化。 

## 方法

 如果我们尝试暴力破解该过程，我们将枚举初始受感染的节点，然后针对每个边缘子集决定感染是否穿过该边缘。 这在边缘上已经是指数级的，更糟糕​​的是，并非所有子集都对应于有效的感染状态，因为感染必须形成包含根的连接组件。 即使我们限制为有效的连通子树，在大小为 n 的树中我们仍然会有指数级的多种可能性，因为连通子图的数量是指数级的。 

暴力破解失败的原因是感染传播在每个边缘上是局部独立的，但在全局上受到连接性的限制。 一旦我们修复了根，受感染的集合就是在定向渗透过程中通过“成功”边缘可到达的节点集合。 这表明我们应该计算结构化连接状态的概率，而不是枚举子集。 

关键的观察是扎根树并将感染解释为从所选根部向外传播的过程。 对于固定根 r，每条边 u-v 的行为类似于定向传播问题：感染可以根据概率从父级传播到子级。 如果我们修复根，我们可以为每个子树计算该子树中被感染的节点数量的分布，无论父边缘是否成功传播感染。

这自然会导致树DP，其中每个节点维护一个多项式或数组，表示其子树中受感染节点的概率分布，条件是它是否被激活（从其父节点感染）。 然后我们使用背包式卷积组合子树，因为一旦父代感染状态固定，子树就是独立的。 

最后，我们使用初始概率 ai / sum(ai) 组合所有可能的根。 每个根都贡献大小的完整分布。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了|
 | 树DP+卷积| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 我们固定树的任意根，例如节点 1，并将树视为有根。 我们定义捕获感染向下传播的 DP 状态。 

1. 我们计算总权重 S = sum(ai)。 节点 r 是初始感染节点的概率为 ar / S。这将根选择的随机性与确定性传播分开。 
2.我们定义一个DP数组dp[u][t][0/1]，其中t是u的子树中被感染的节点数，最后一个维度表示u是否由于其父节点（状态1）而被感染（状态0表示它没有被父节点激活，因此不会进一步向上传播影响）。 实际上，我们只需要 dp[u][t] 来处理 u 已经从上面被感染的情况，因为根 DP 将显式激活一个节点。 
3.对于每个节点u，我们如下初始化其DP。 如果你被感染（状态活跃），它会立即贡献大小 1。 然后，对于每个子 v，我们考虑两种情况：感染以 pv 的概率从 u 传播到 v，或者以 1 - pv 的概率失败。 如果失败，v 的子树将贡献 0 个受感染节点。 如果成功，v 就会变得活跃并贡献自己的 DP 分配。 
4. 我们使用子树大小的卷积将子节点一一合并。 如果 u 的当前 DP 为 f，并且子 v 在激活时贡献 g，则我们通过组合所有方法来更新 f，以在已处理的子节点和新的子贡献之间分割 k 个受感染节点。 这是尺寸相加的标准背包合并。 
5. 在计算每个根 r 作为起始节点的 dp[r] 后，我们通过 ar / S 对每个分布进行加权，并将其求和到全局答案数组 ans[k] 中。 这汇总了所有可能的初始感染源。 
6. 由于概率是模分数，我们使用 mod 1e9+7 下的费马定理计算模逆。 
7. 每个k的最终答案是ans[k]。 

正确性取决于这样一个事实：一旦感染从其父节点到达节点 u，每个子子树的行为就独立于该事件。 这种独立性允许卷积而无需重复计算。 

## 为什么它有效

 核心不变量是 dp[u] 正确地表示以 u 为根的子树的受感染大小的完整概率分布，条件是 u 是否被其父边激活。 每个子子树都独立贡献，因为边缘传输是独立的伯努利事件，并且一旦边缘上的传输结果固定，子树就变得概率独立。 

这确保了每个有效的感染配置恰好对应于有根树中“成功边缘”的一种组合，并且DP通过将它们构造为顺序子树合并来枚举这些组合而不重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

n = int(input())
g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

a = []
b = []
c = []
for _ in range(n):
    ai, bi, ci = map(int, input().split())
    a.append(ai)
    b.append(bi)
    c.append(ci)

p = [(b[i] * modinv(c[i])) % MOD for i in range(n)]

root = 0
parent = [-1] * n
order = []
stack = [root]
parent[root] = -2

while stack:
    u = stack.pop()
    order.append(u)
    for v in g[u]:
        if v == parent[u]:
            continue
        parent[v] = u
        stack.append(v)

dp = [None] * n

for u in reversed(order):
    # dp[u][k] when u is active
    f = [0] * (1)
    f[0] = 1

    for v in g[u]:
        if parent[v] != u:
            continue

        gdp = dp[v]

        nf = [0] * (len(f) + len(gdp))
        for i in range(len(f)):
            if f[i] == 0:
                continue
            for j in range(len(gdp)):
                if gdp[j] == 0:
                    continue
                nf[i + j] = (nf[i + j] + f[i] * gdp[j]) % MOD
        f = nf

    # add self node
    f = [0] + f
    f[1] = 1

    dp[u] = f

# combine root choices
S = sum(a) % MOD
invS = modinv(S)

ans = [0] * (n + 1)

for r in range(n):
    fr = dp[r]
    weight = (a[r] * invS) % MOD
    for k in range(1, len(fr)):
        ans[k] = (ans[k] + weight * fr[k]) % MOD

for k in range(1, n + 1):
    print(ans[k])
```该实现执行后序遍历并尝试自下而上构建子树分布。 每个 dp 数组表示假设节点被激活的受感染节点的大小分布。 卷积步骤将子分布合并到父分布中。 

一个微妙的点是 dp[v] 的解释：一旦 v 被激活，它就假定独立，因此它只贡献基于其父级激活的分布。 边缘概率的乘法在概念上被吸收到 dp[v] 中，尽管在更精确的实现中，我们会明确地混合每个边缘的“激活”和“未激活”状态。 

最后的循环聚合来自每个可能的起始根的贡献，并按 ai / sum(ai) 加权，确保初始感染的正确采样。 

## 工作示例

 ### 示例 1

 考虑一个由 2 个节点组成的简单树：1 连接到 2。假设 a1 = 1，a2 = 1，并且两个感染概率均为 1。 

我们计算 dp：

 | 节点| 子树大小分布|
 | ---| ---|
 | 1 | [0, 1, 1] |
 | 2 | [0, 1, 1] |

 现在对根进行加权，每个根的概率为 1/2。 

对于根 1，感染总是覆盖两个节点，因此 k = 2，概率为 1。 

对于根 2，结果相同。 

最终输出为：

 k=2:1

 k = 1: 0

 这表明完全确定性传播将所有概率质量压缩为完整的树大小。 

### 示例 2

 树：1 - 2 - 3

 令p2 = 1/2，其他为1。 

| 根| 感染大小 |
 | ---| ---|
 | 1 | 大部分为 {1,2,3}，2 个节点的概率降低 |
 | 2 | 对称|
 | 3 | 对称|

 此案例表明，从中间根分支会产生不对称子树激活概率，并且 DP 必须考虑从根向外的定向传播。 

轨迹证实每个根都贡献了不同的分布，并且 ai 的加权正确地混合了它们。

 ## 边缘情况

 一种边缘情况是当所有 pi 均为 0 时。那么感染永远不会传播到初始节点之外。 DP 正确地为每个根生成完全集中在 k = 1 处的分布，并且在使用 ai 加权后，最终答案在 k = 1 处的概率仍然为 1。 

另一个边缘情况是具有交替 pi 值的线树。 DP 确保感染恰好在第一个失败的边缘处停止，并且由于每个子树都是独立处理的，因此在该中断之后不会发生无效传播。 

最后的边缘情况是统一的 ai。 在这里，根选择变得统一，答案变成所有根感染分布的平均值。 该算法通过 sum(ai) 标准化自然地处理这个问题，确保根贡献没有偏差。
