 ## 解决方案
 ## 问题理解

 我们为每个测试用例提供一个数组，并且要求我们仅关注该数组中的位置对。 从每对有序的不同索引中，我们可以计算两个值之间的绝对差。 在所有这些差异中，有一个最大值由数组中存在的最小和最大数字确定。 

任务不是找到最大差异（这很简单），而是计算有多少有序索引对实际实现了该差异。 由于对是有序的，因此选择索引 i 然后 j 被认为与选择 j 然后 i 不同，即使它们使用相同的两个值。 

关于约束的关键观察是所有测试用例的元素总数最多为 100000。这立即排除了任何比较所有对的二次解。 在最坏的情况下，每个测试用例的朴素双循环将降级到大约 10^10 次操作，这远远超出了时间限制。 该解决方案必须将每个测试用例的时间减少到线性时间。 

当所有元素都相等时，就会出现微妙的边缘情况。 在这种情况下，最大差异为零，并且每个有序的不同索引对满足 |a[i] − a[j]| = 0。如果没有显式处理相等的端点，任何假设最大差异来自不同值的方法都会在此处失败。 

当最大值和最小值多次出现时，会出现另一种边缘情况。 例如，如果最小值出现 k 次，最大值出现 m 次，则答案不是 1 或 2，而是取决于所有出现的组合。 一个常见的错误是只计算每个端点出现的一次，而不是所有重复的端点。 

## 方法

 暴力解决方案检查每个有序对 (i, j)，计算 |a[i] − a[j]|，跟踪全局最大差异，并计算有多少对实现了该差异。 这是正确的，但需要两个嵌套循环，导致每个测试用例的工作量为 O(n²)。 当n达到100000时，这是不可行的。 

关键的结构见解是数组中的最大绝对差总是在全局最小值和全局最大值之间实现。 没有其他对可以超过这个差距。 因此，我们永远不需要比较任意元素； 我们只需要知道最小值和最大值出现了多少次。 

一旦我们知道最小值出现 cnt_min 次并且最大值出现 cnt_max 次，每个有效的有序对必须选择一个端点作为最小值，另一个作为最大值。 由于顺序很重要，因此两个方向都有贡献，给出从 min 到 max 的 cnt_min × cnt_max 对和从 max 到 min 的 cnt_max × cnt_min，总共 2 × cnt_min × cnt_max。 

如果最小值和最大值相同，则每个元素都是相同的，并且不同索引的所有有序对都是有效的。 该计数为 n × (n − 1)。

 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，扫描一次数组以确定最小值和最大值。 这就确定了仅有的两个可以形成最大差异的候选者。 
2. 统计最小值出现了多少次，最大值出现了多少次。 这些频率决定了形成极端对时存在多少种选择。 
3. 如果最小值和最大值相同，则直接将不同索引的有序对的数量计算为 n × (n − 1)，因为每对都会产生差值 0。 
4. 否则，将结果计算为 2 × cnt_min × cnt_max。 这说明了最小和最大元素之间的两个排序方向。 
5. 输出测试用例的结果。 

### 为什么它有效

任何具有最大绝对差值的对都必须涉及两个全局极值，因为任何中间值都会减少可能的差距。 数组结构将问题分解为对端点进行计数，而不是检查所有对。 由于每次出现的最小值都可以与每次出现的最大值在两个方向上配对，因此计数变得纯粹组合且与位置无关。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        mn = min(a)
        mx = max(a)
        
        if mn == mx:
            print(n * (n - 1))
            continue
        
        cnt_mn = 0
        cnt_mx = 0
        
        for x in a:
            if x == mn:
                cnt_mn += 1
            if x == mx:
                cnt_mx += 1
        
        print(2 * cnt_mn * cnt_mx)

if __name__ == "__main__":
    solve()
```该解决方案首先读取所有测试用例并独立迭代每个数组。 它使用 Python 内置函数提供的单遍计算最小值和最大值，这些函数在时间上是线性的。 

所有值都相等的特殊情况是显式处理的，因为否则 cnt_min 和 cnt_max 将相同，并且通用公式将错误地减少到零。 

计数循环会小心地独立地递增两个计数器，因为同一元素只能在统一情况下同时为最小值和最大值，而这种情况已经被分离出来。 

最后直接打印公式2×cnt_min×cnt_max。

 ## 边缘情况

 对于所有值都相同的输入，例如`4 5 5 5 5`，算法将 mn 和 mx 设置为相同的值并直接计算 n × (n − 1)。 由于每个有序的不同索引对都是有效的，因此这与预期计数相匹配，而不依赖于否则会崩溃的频率逻辑。 

对于像这样的情况`1 1 10 10 10`，扫描产生 mn = 1（计数 2）和 mx = 10（计数 3）。结果变为 2 × 2 × 3 = 12。两个最小元素中的每一个都与两个方向上的三个最大元素中的每一个配对，并且计数机制准确地捕获了这种对称性。
