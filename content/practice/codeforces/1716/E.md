 ## 解决方案
 ## 问题理解

 该数组恰好包含$2^n$元素。 每个查询选择一个级别$k$，并将每个位置与相差的位置交换$2^k$。 交换是在不相交的对中同时完成的，因此每个大小的块$2^{k+1}$将其左半部分与右半部分交换。 

应用交换后，我们需要所有连续子数组之间的最大总和，其中允许空子数组且贡献为零。 

数组本身会永久更改，因此查询会累积。 我们并不是对原始数组重复应用相同的操作，而是改变当前的排列。 

数组的大小最多为$2^{18}=262144$，这是适中的。 卡丹通票很便宜，但也可以$2\cdot10^5$查询。 每次查询后重建数组并重新计算答案大约需要$$2\cdot10^5 \times 2^{18}\approx 5\cdot10^{10}$$的操作，远远超出了极限。 

交换操作本身就是具有欺骗性的。 一个查询$k=0$交换相邻元素。 重复两次即可恢复原来的顺序。 更一般地说，每个级别独立运行，并且可以被视为翻转每个索引中的一位。 查询的顺序仅确定哪些级别已被翻转奇数次。 

有几种情况很容易导致错误。 

认为```
n = 1
a = [-5, -7]
```在唯一可能的查询之后，数组变成```
[-7, -5]
```正确答案是 0，因为允许空子数组。 坚持选择至少一个元素的 Kadane 的粗心实现将输出 -5。 

另一个陷阱是忘记操作会累积。 为了```
n = 2
a = [1,2,3,4]
queries: 0,0
```第一个查询给出```
[2,1,4,3]
```第二次查询恢复```
[1,2,3,4]
```答案是 10 和 10。将每个查询重新应用到原始数组会意外地产生相同的第一状态两次。 

最微妙的问题是理解级别交换在较大块内的作用。 为了```
[1,2,3,4,5,6,7,8]
```和$k=1$，每块长度有四次变化```
[1,2,3,4] → [3,4,1,2]
[5,6,7,8] → [7,8,5,6]
```该操作不会全局移动数组。 它只在大小块内交换一半$2^{k+1}$。 

## 方法

 最简单的方法是显式维护当前数组。 对于每个查询，我们执行所有必需的交换，然后运行 ​​Kadane 算法以获得最大子数组和。 这是正确的，因为 Kadane 准确地计算出所需的数量。 

不幸的是，一个查询可能会触及所有$2^n$元素，Kadane 也会扫描整个数组。 和$2\cdot10^5$查询和$2^{18}$元素，总工作变为$10^{11}$，这是无望的。 

关键的观察是每次交换都会交换某个段的两半。 这与线段树的结构完全相同。 当一个节点代表一个段时，它的答案仅取决于四个数字：

 总和。 

最大前缀和。 

最大后缀和。 

最大子数组和。 

这些是用于最大子数组查询的常用值。 

通常，左孩子总是在右孩子之前。 在这里，水平翻转可能会反转该高度的每个节点内的顺序。 由于每个节点只有两个可能的方向，因此我们可以预先计算两个版本。 

对于每个节点，我们存储两个状态。 

状态 0 表示子级按正常顺序连接。 

状态 1 表示子级以相反的顺序连接。 

当组合孩子时，相反的顺序只是交换他们的角色。 由于每个节点只有两种可能性，因此预处理保持线性。 

查询切换一级。 该高度的所有节点同时改变方向。 我们不是单独接触它们，而是维护一个描述哪些级别被翻转的位掩码。 使用该掩码，我们知道应该在根处使用哪个状态。 根的最大子数组值就是答案。

 ## 算法演练

 1. 在数组上构建完全二叉树。 

每个节点对应一个长度为2的幂的线段。 
2. 对于叶子，两个方向是相同的。 

总和等于元素本身。 如果为正，则前缀、后缀和最大子数组都是元素值，否则为零，因为允许空子数组。 
3. 对于内部节点，计算两个版本。 

版本 0 连接左子节点，然后连接右子节点。 

版本 1 连接右子节点，然后连接左子节点。 
4. 合并两个片段$A$和$B$，使用标准公式。 

总和是$A.sum+B.sum$。 

最大前缀是哪个更好$A.pref$和$A.sum+B.pref$。 

最大后缀是哪个更好$B.suff$和$B.sum+A.suff$。 

最大子数组是里面最好的段中的最大值$A$，里面最好的一段$B$，以及跨越边界的线段，其值为$A.suff+B.pref$。 
5. 维护一个掩码，描述哪些级别已翻转奇数次。 

有值的查询$k$切换位$k$。 
6. 在预处理过程中，从底部开始编号。 

对于高度处的节点$h$，其方向仅取决于位$h-1$当前掩码的。 
7. 根有两个预先计算的状态。 

更新掩码后，选择最高位模式对应的根状态并输出其最大子数组值。 

### 为什么它有效

 每个查询独立地交换每个段的两半，其大小为$2^{k+1}$。 该高度的节点恰好经历一次局部反转，而更深或更高的节点不受影响。 因此，每个节点的排序仅取决于其自身级别上翻转的奇偶性。 

因为一个节点只有两种可能的顺序，所以存储这两种可能性完全描述了每个未来的排列。 合并公式与线段树中用于最大子数组和的公式完全相同，因此为每个方向计算的值是正确的。 由于根代表整个数组，因此它的最大子数组值等于答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Node:
    __slots__ = ("sm", "pref", "suff", "best")

    def __init__(self, sm=0, pref=0, suff=0, best=0):
        self.sm = sm
        self.pref = pref
        self.suff = suff
        self.best = best

def merge(a, b):
    res = Node()
    res.sm = a.sm + b.sm
    res.pref = max(a.pref, a.sm + b.pref)
    res.suff = max(b.suff, b.sm + a.suff)
    res.best = max(a.best, b.best, a.suff + b.pref)
    return res

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    m = 1 << n

    dp = [[None, None] for _ in range(2 * m)]

    for i, x in enumerate(a):
        val = max(0, x)
        node = Node(x, val, val, val)
        dp[m + i][0] = node
        dp[m + i][1] = node

    for v in range(m - 1, 0, -1):
        left = v << 1
        right = left | 1

        dp[v][0] = merge(dp[left][0], dp[right][0])
        dp[v][1] = merge(dp[right][1], dp[left][1])

    orient = [0] * (n + 1)

    q = int(input())
    out = []

    for _ in range(q):
        k = int(input())
        level = k + 1
        orient[level] ^= 1

        cur = 1
        for h in range(n, 0, -1):
            bit = orient[h]
            cur = (cur << 1) | bit

        out.append(str(dp[cur][0].best))

    sys.stdout.write("\n".join(out))

solve()
```因为允许空子数组，所以对于负前缀、后缀和最大值，叶存储零。 

合并例程是标准的最大子数组合并。 只需要四个数字。 

每个内部节点存储两个方向。 在一个方向上，左孩子在右孩子之前，而在另一种方向上，它们的顺序相反。 

方向数组保持每个级别上翻转的奇偶性。 由于两次应用相同的查询会自行取消，因此只有奇偶校验很重要。 

该实现仔细地区分线段树的高度和查询值。 询问$k$影响长度段$2^{k+1}$，对应级别$k+1$从叶子向上数时。
