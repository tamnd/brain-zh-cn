 ## 解决方案
 ## 问题理解

 我们被要求计算某些具有满足组合属性的有界元素的数组。 具体来说，考虑所有长度的数组`n`其中每个元素之间`0`和`k`。 如果从一个数组开始，我们可以重复选择任何长度至少为 2 的连续子数组并减去该数组，则该数组被称为好数组`1`从该子数组的每个元素开始，直到数组变为全零。 我们的目标是计算有多少数组是好的，以给定素数为模`p`。 

了解数组的优点至关重要。 一个小例子阐明了规则。 为了`n=3`和`k=1`，数组`[0,1,1]`很好，因为我们可以选择索引`2..3`并减去`1`，达到`[0,0,0]`。 数组`[1,0,1]`不好，因为不能选择长度至少为两个的连续段来一起减少两个非零元素。 

这些约束为算法选择提供了指导。 最大`n`是 3000 和`n^2`所有测试用例不超过 10^7。 这排除了所有的天真的枚举`(k+1)^n`数组，可以轻松到达`3000^3000`。 相反，我们需要一种动态编程方法，其运行时间大致如下：`O(n*k)`或者`O(n^2)`每个测试用例。 模数`p`如果组合学发挥作用，质数允许我们使用模逆。 

可能导致粗心实施的边缘情况包括`k`等于`1`或者`n`，其中许多序列都不是很好或很坏，而数组中的所有元素都是最大的。 例如，对于`n=3`和`k=3`,`[3,3,3]`很好，但是`[3,0,3]`并不是因为没有长度至少为 2 的连续段可以减少两个外部三而不影响中间的零。 

## 方法

 暴力方法很简单：生成每个长度的数组`n`中的元素`[0, k]`并模拟归约操作。 对于每个数组，重复减去`1`从某个子数组开始，直到所有元素都为零或无法移动。 虽然正确，但操作次数是天文数字。 为了`n=3000`和`k=3000`， 有`(k+1)^n ≈ 3001^3000`数组，即使每次检查只花费一微秒也是不可行的。 

关键的见解是使用组合数学重新表述问题。 缩减操作实质上允许缩减长度至少为二的任何连续段。 如果连续元素之间的差异不超过 1，并且没有元素以不能包含在长度至少为 2 的段中的方式隔离，则该数组是好的数组。 这减少了对每个元素最多的数组的计数`1`比之前的大，这相当于对受相邻差异限制的组合或序列进行计数。 

正式地，让`dp[i][j]`是长度数组的数量`i`结尾为`j`那很好。 其递归式为：```
dp[i][j] = sum(dp[i-1][0..j])
```在哪里`0 ≤ j ≤ k`。 这是有效的，因为任何以前的数组以`x ≤ j`可以延伸到`j`同时保持序列最终可以归零的性质。 可以使用前缀和来有效地计算总和，以减少天真的计算`O(k)`每`dp`过渡到`O(1)`，给出一个`O(n*k)`每个测试用例的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((k+1)^n * n^2) | O((k+1)^n * n^2) | O(n) | 太慢了 |
 | 带有前缀和的 DP | O(n*k) | O(k) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`,`k`， 和`p`。 
2.初始化一个DP数组`dp`尺寸的`k+1`， 在哪里`dp[j]`表示当前长度以 value 结尾的良好序列的数量`j`。 
3. 基本情况：对于长度为1的序列，任意值`0..k`非常好，所以`dp[j] = 1`为所有人`j`。 
4. 对于每个位置`i`从 2 到`n`，计算一个新的`dp_new`大批。 计算`dp_new[j]`, 总结所有之前的`dp[x]`在哪里`0 ≤ x ≤ j`使用运行前缀和来避免重新计算每个的和`j`。 
5、加工后长度`i`， 分配`dp_new`到`dp`并继续。 
6.达到长度后`n`，答案是所有的总和`dp[j]`为了`0 ≤ j ≤ k`模数`p`。 

为什么它有效：DP 不变量是`dp[i][j]`计算所有好的长度序列`i`结尾为`j`。 关键的观察是，当且仅当每个步骤扩展以更小或相等的值结尾的序列时，序列才能减少到零，从而允许连续递减操作起作用。 前缀总和确保我们有效地累积所有有效的扩展。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, p = map(int, input().split())
        dp = [1] * (k + 1)
        for _ in range(1, n):
            prefix = [0] * (k + 2)
            for j in range(k + 1):
                prefix[j + 1] = (prefix[j] + dp[j]) % p
            dp = [prefix[j + 1] for j in range(k + 1)]
        print(sum(dp) % p)

if __name__ == "__main__":
    solve()
```该代码使用快速 I/O`sys.stdin.readline`对于多个测试用例。 它维护一个长度为 DP 的数组`k+1`并使用长度的前缀和数组`k+2`来计算转换。 模运算确保数字永远不会超过给定的素数`p`。 一个微妙的点是前缀索引偏移一以避免负索引，负索引是偏移一错误的常见来源。
