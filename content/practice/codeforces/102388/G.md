 ## 解决方案
 ## 问题理解

 我们追踪一只从深处开始的蜗牛`n`，其中深度`0`意味着它已经到达地面。 每一天它都会攀升`a`米。 如果爬升到达或经过地面，蜗牛会立即逃脱，整个过程结束。 否则，夜幕降临，蜗牛掉落`b`米，所以它的深度增加`b`。 

对于每个测试用例，任务是确定蜗牛到达地面的第一天。 如果蜗牛永远无法逃脱，我们输出`-1`。 

约束很小：最多有 10 个测试用例，并且`n`,`a`， 和`b`都最多为 1000。因此，当可以逃脱时，直接模拟对于一个测试用例最多执行约 1000 天的周期，这很容易在 1 秒的限制内。 即便如此，该过程的结构为我们提供了一个 O(1) 公式，该公式更清晰，并且在界限大幅增加的情况下仍然保持高效。 

棘手的部分是，蜗牛在最后一次攀爬尝试后并没有掉落。 例如，与`n = 5, a = 5, b = 100`，答案是`1`，因为蜗牛在第一天到达地面。 一个粗心的实施总是在检查蜗牛是否逃脱之前应用夜幕降临，可能会错误地报告它仍在井中。 

另一个边缘情况是攀爬和跌落同样大时。 为了`n = 10, a = 5, b = 5`，蜗牛从深度 10 爬到 5，再回落到 10，如此循环往复。 正确的输出是`-1`。 仅检查是否`a`非零就会错过这种情况。 

案例`a < b`除非蜗牛在第一天到达地面，否则也是不可能的。 例如，`n = 6, a = 3, b = 4`给出`-1`。 在每一个不成功的日子之后，蜗牛实际上比以前更深，所以它永远无法恢复。 

最后，`a = 0`必须自然处理。 例如，`n = 1, a = 0, b = 0`产生`-1`，因为蜗牛根本不动。 

## 方法

 最直接的解决方案是模拟每一天。 我们保持当前深度，减去`a`白天，立即检查深度是否为零。 如果没有，我们添加`b`过夜并继续。 这完全遵循物理过程，因此每当模拟因逃逸而终止时，报告的日期都是正确的。 

模拟还必须检测不可能的过程。 经过一天一夜的失败后，深度发生了变化`a - b`向上的方向。 如果`a <= b`，蜗牛在完成一整天一夜后，再也没有离地面更近。 如果它在第一天没有逃脱，那么它永远也不会。 

在给定的约束下，暴力破解已经足够快了。 什么时候`a > b`，最小可能的净进度是每天一米，初始深度最多为 1000。因此，成功的模拟每个测试用例最多需要大约 1000 次迭代，或者所有测试用例大约需要 10000 次迭代。 没有必要因为实际限制而拒绝这种方法。 

更有用的观察是，在每不成功的一天之后，蜗牛的深度正好减少`a - b`。 假设蜗牛第一天没有逃脱。 在最后一天之前，它已经完成了几个完整的昼夜循环，每个循环都给出相同的净进度。 我们可以直接计算需要多少个这样的周期，而不是模拟它们。 

如果蜗牛在深处开始新的一天`d`，它恰好在那天逃脱`d <= a`。 第一天，这意味着`n <= a`，立即给出答案`1`。 否则，在每完成一次不成功的一天之后，深度就会减少`a - b`。 如果`a <= b`，没有任何积极的进展，所以逃跑是不可能的。 如果`a > b`，我们只需要一个上限除法来确定需要多少个额外的周期。 

蛮力方法之所以有效，是因为每次迭代都代表真实的一天。 当它变得不那么有吸引力时`n`增长是因为它的运行时间与天数成正比。 观察到每一天不成功的深度都会改变相同的固定量，这让我们可以用一次算术计算来代替所有这些重复操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 最坏情况下的 O(n) | O(1) | O(1) | 接受给定的约束|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.首先检查是否`n <= a`。 蜗牛在第一次白天爬升时到达地面，所以答案是立即的`1`。 夜间坠落无关紧要，因为一旦到达地面，该过程就会停止。 
2.如果第一天没有逃脱，检查是否`a <= b`。 每个完整的昼夜循环都不会向上移动或将蜗牛进一步向下推。 既然第一天已经失败了，蜗牛就逃不掉了，所以返回吧`-1`。 
3.现在我们知道了`a > b`，因此每个不成功的完整一天都会减少深度`a - b`。 让`k`是蜗牛逃脱后的天数。 后`k - 1`完整的昼夜循环，其深度为`n - (k - 1)(a - b)`。 

当天`k`，它爬升`a`米，所以逃生需要`n - (k - 1)(a - b) <= a`。 

重新排列给出`n - a <= (k - 1)(a - b)`。 

因此，所需的完整不成功周期的数量是`ceil((n - a) / (a - b))`。 

最后一天的攀爬又增加了一天，所以答案是`ceil((n - a) / (a - b)) + 1`。 
4. 使用整数算术计算上限除法：`(x + y - 1) // y`为积极的`x`和`y`， 在哪里`x = n - a`和`y = a - b`。 这避免了浮点运算并给出了精确的整数答案。 

**为什么有效。** 在最后一天之前，每个完成的昼夜周期都会使蜗牛的深度发生精确的变化`a - b`。 什么时候`a <= b`，这种改变无法使蜗牛向上移动，因此在第一天失败后逃脱是不可能的。 什么时候`a > b`，任意数量的完整循环后的深度完全由相同的固定下降确定。 该公式找到了下一次白天爬升可以到达地面的最小完整周期数。 由于计算使用最小的此类值，因此它准确地给出了第一个逃亡日。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, a, b = map(int, input().split())

        if n <= a:
            print(1)
            continue

        if a <= b:
            print(-1)
            continue

        net = a - b
        remaining = n - a

        days = (remaining + net - 1) // net + 1
        print(days)

if __name__ == "__main__":
    solve()
```该程序首先处理第一天的逃逸案例`n <= a`。 该检查必须在不可能条件之前进行，因为即使在以下情况下，蜗牛也可以逃脱：`a <= b`。 例如，`n = 5, a = 5, b = 100`有答案`1`。 

在那之后，`a <= b`意味着每个完整的循环都无法提高蜗牛的深度。 由于第一天蜗牛没有逃脱，所以答案是`-1`。 

对于其余的情况，`net = a - b`是严格正数。 变量`remaining = n - a`代表白天攀登完成逃生之前还需要多少额外的进展。 上限部门计算在最终攀登之前需要多少个完整的昼夜循环。 

决赛`+ 1`代表逃亡日本身。 这是问题中最常见的偏差点。 我们在成功爬升之前计算完整的周期，而不是成功爬升。 

对于这些约束，Python 整数不会溢出，并且所有计算都使用整数运算，因此不存在精度问题。

 ## 边缘情况

 当蜗牛第一天能逃脱时，答案总是`1`，无论夜幕降临。 对于输入`5 5 100`，算法首先检查`5 <= 5`并返回`1`。 检查的解决方案`a <= b`首先会错误地宣布该过程不可能，即使蜗牛从未到达夜间。 

什么时候`a = b`第一天失败后，蜗牛每天晚上都会回到完全相同的深度。 为了`10 5 5`，第一次攀爬将深度从 10 更改为 5，然后夜间将其返回到 10。该算法显示`n > a`和`a <= b`，所以它返回`-1`而不尝试无限模拟。 

什么时候`a < b`，在第一天不成功之后，情况就更糟了。 为了`6 3 4`，第一次攀登将深度从 6 更改为 3，然后夜间将其更改为 7。随后的每个循环开始时都会比前一个循环更深。 由于初始爬升不足，算法返回`-1`。 

什么时候`a = 0`，蜗牛根本爬不上去。 为了`1 0 0`，第一天的情况`1 <= 0`是假的，并且`a <= b`是真的，所以答案是`-1`。 如果`b`是积极的，这种情况也是不可能的，因为蜗牛只向下移动。 

当所需的周期数完全除以净进度时，就会出现精确的边界情况。 为了`n = 7, a = 3, b = 1`，第一天在深度 4 结束，然后第一个晚上将深度带到 5。第二天在深度 2 结束，然后第二个晚上将深度带到 3。第三次攀爬到达地面。 公式给出`ceil((7 - 3) / 2) + 1 = 2 + 1 = 3`，因此上限计算不会引入额外的天数。 

最后一天的边界也是该公式使用的原因`n - a`，而不是简单地`n`。 蜗牛需要足够近，以便它在白天的攀登才能完成这项工作。 计算成功攀登后的夜晚会增加一个不正确的额外周期。
