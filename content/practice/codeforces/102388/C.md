 ## 解决方案
 ## 问题理解

 我们有一个长方形的桌子，宽度`m`和身高`n`。 球从内点开始`(x0, y0)`并且必须达到`(x1, y1)`。 它总是沿着直线段传播，从具有相等入射角和反射角的墙壁反射。 所需的墙壁触点数量恰好是`k`，我们想要轨迹的最小总长度。 

关键的困难在于弹跳会改变方向，因此尝试直接模拟球意味着要处理许多可能的反射序列。 约束足够小以允许线性扫描`k`，但它们足够大，以至于对反弹序列进行指数搜索是完全不可能的。 自从`k`可以是 100，甚至`2^k`可能性已经是关于`1.27 * 10^30`。 表的维度最多为 100，因此变换平面中的坐标对于普通浮点运算而言仍然足够小，并且测试用例的数量仅为 100。 

有几种情况通常会导致错误的解决方案。 首先，零跳出必须允许直接分段，因此```
1
100 100 1 1 1 1 0
```有答案`0.00`。 始终构建反射图像的解决方案将意外地迫使至少一个墙壁接触。 

其次，到达角落算作两次弹跳，因为球同时接触一面垂直墙壁和一面水平墙壁。 为了```
1
100 100 1 2 1 2 2
```球可以从`(1,2)`到角落`(0,0)`并回到`(1,2)`，给出距离`2 * sqrt(5) = 4.47`。 计算碰撞事件而不是墙壁接触的解决方案可能会错误地将其视为一次反弹。 

第三，反射图像的方向很重要。 为了```
1
10 10 1 1 9 1 1
```直接距离是`8`，但该路径的反弹次数为零。 仅一次反弹，最接近的有效反射目标位于`-9`或者`11`，距离起始 x 坐标均为 10 个单位，所以答案是`10.00`。 简单地将一个表格宽度添加到目标坐标将给出错误的几何形状。 

## 方法

 直接的暴力方法是枚举每一个可能的墙方向序列。 在每次反弹时，我们可以从概念上选择下一次碰撞是与垂直墙还是水平墙，然后遵循生成的反射轨迹并检查端点是否可以是所请求的点`k`碰撞。 有`2^k`方向序列，所以在最坏的情况下`k = 100`这大约意味着`1.27 * 10^30`案例。 该方法在概念上是正确的，因为每个合法轨迹都有一定的垂直和水平墙壁接触序列，但搜索空间呈指数增长。 

消除这种爆炸的观察是完全停止反映轨迹。 相反，只要球弹起，就反映整个桌子。 在这个展开的平面中，球沿着一条直线行进。 原始目的地的每个反射副本都代表真实表中的可能轨迹。 

假设展开的直线穿过`p`垂直表格边界和`q`水平表格边界。 那么真实的轨迹正好是`|p| + |q|`弹跳。 我们需要`|p| + |q| = k`。 

对于有符号整数`p`，我们可以计算相应的反射副本的x坐标`x1`。 如果`p`是偶数，副本位于`p * m + x1`。 

如果`p`是奇数，副本位于`(p + 1) * m - x1`。 

相同的公式适用于 y 坐标`q`和`n`。 

的迹象`p`和`q`告诉我们球穿过展开的副本的方向。 对于每一个可能`p`从`-k`通过`k`，剩余的水平弹跳次数为`k - |p|`，最多给出两个选择`q`。 我们计算到每个结果图像的欧几里德距离并取最小值。 

暴力搜索之所以有效，是因为每个弹跳序列都对应于一条可能的展开线。 它失败了，因为序列的数量呈指数级增长。 展开的观察让我们完全忘记了反弹的顺序。 只有垂直和水平边界交叉点的有符号数才重要，从而将搜索减少到`O(k)`候选人。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(2^k)`|`O(k)`| 太慢了|
 | 最佳 |`O(k)`每个测试用例|`O(1)`| 已接受 |

 ## 算法演练

 1. 考虑该表在各个方向上无限重复。 每隔一个副本都会进行镜像，因此反射桌子就相当于让球沿直线延伸。 
2. 分配一个有符号整数`p`垂直墙壁交叉点的数量。 它的绝对值是垂直弹跳的次数。 同样，分配`q`到水平交叉口。 

拐角碰撞自然适合这个模型。 如果直线穿过角点，则会在同一点穿过一个垂直边界和一个水平边界，因此该事件会产生两次反弹。 
3. 由于跳出的总数必须恰好是`k`，限制候选人`|p| + |q| = k`。 
4. 枚举`p`从`-k`到`k`。 对于每个值，计算`r = k - |p|`。 唯一可能的值`q`是`r`和`-r`。 
5. 将每个带符号的反弹计数转换为展开的目标坐标。 对于 x 轴，定义`image_x(p) = p*m + x1`什么时候`p`是偶数，并且`image_x(p) = (p+1)*m - x1`什么时候`p`很奇怪。 

应用类似公式可得`image_y(q)`。 
6.展开的轨迹现在只是来自`(x0, y0)`到`(image_x, image_y)`。 它的长度是`sqrt((image_x - x0)^2 + (image_y - y0)^2)`。 
7. 保留所有候选者之间的最小距离并打印出小数点后恰好两位数。 

### 为什么它有效

 不变的是，原始表中的每个合法反射轨迹恰好对应于从起点到展开平面中目的地的适当反射副本的一条直线段。 该段穿过的垂直边界的数量恰好是垂直墙壁弹跳的数量，水平方向也是如此。 因此每个候选人都满意`|p| + |q| = k`准确地代表了一条法律轨迹`k`弹跳。 相反，每条法律轨迹都会展开到其中一位候选人身上。 由于该算法检查满足跳出计数的每个可能的签名对并选择最短的对应段，因此它计算的最小值正是所需的答案。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def image_coordinate(pos, length, bounces):
    if bounces % 2 == 0:
        return bounces * length + pos
    return (bounces + 1) * length - pos

def solve_case(m, n, x0, y0, x1, y1, k):
    ans = float("inf")

    for p in range(-k, k + 1):
        remaining = k - abs(p)

        x = image_coordinate(x1, m, p)

        for q in {remaining, -remaining}:
            y = image_coordinate(y1, n, q)

            dx = x - x0
            dy = y - y0

            dist = math.hypot(dx, dy)
            ans = min(ans, dist)

    return ans

def main():
    t = int(input())

    for _ in range(t):
        m, n, x0, y0, x1, y1, k = map(int, input().split())
        ans = solve_case(m, n, x0, y0, x1, y1, k)
        print(f"{ans:.2f}")

if __name__ == "__main__":
    main()
```这`image_coordinate`函数直接实现反射模式。 当签名副本索引为偶数时，目标保持其原始方向。 当它是奇数时，目标被镜像到相应的重复矩形内。 

负指数是故意的。 例如，与`p = -1`，公式给出`-x1`，这是目的地在左墙上的倒影。 和`p = -2`，它给出`-2m + x1`，代表相反方向的两个垂直墙壁交叉点。 

主循环考虑每个可能的有符号垂直交叉计数。 一次`p`是固定的，`k - |p|`被强制为水平交叉点的数量，因此只有两个可能的符号`q`。 套装`{remaining, -remaining}`避免在以下情况下进行两次相同的计算`remaining`为零。`math.hypot(dx, dy)`计算欧氏距离，无需手动编写平方根表达式。 所有坐标计算都是整数，并且在给定约束下很小，因此Python中不存在整数溢出问题。 

这`:.2f`格式化执行所需的输出舍入。 无需特殊处理`k = 0`，因为那时`p = 0`和`q = 0`是唯一可能的候选值，给出直接距离。

 ## 边缘情况

 第一个边缘情况是`k = 0`。 为了```
1
100 100 1 1 1 1 0
```循环只能选择`p = 0`，这迫使`q = 0`。 目标图像正是`(1,1)`，所以两个坐标差都为零，答案是`0.00`。 不考虑反射路径，因为任何非零符号索引都会引入至少一个墙壁交叉。 

第二种边缘情况是角球击中。 为了```
1
100 100 1 2 1 2 2
```选择`p = -1`和`q = -1`给出图像`(-1,-2)`。 直线段从`(1,2)`到`(-1,-2)`经过`(0,0)`。 在原始表中，这意味着在同一物理角处有一次垂直墙壁接触和一次水平墙壁接触，因此它正确地算作两次弹跳。 距离是`sqrt(2^2 + 4^2) = 4.47`。 

第三种边缘情况是奇数反射副本。 为了```
1
10 10 1 1 9 1 1
```我们只需要一次反弹。 选择`p = -1`和`q = 0`给出`image_x = (0)*10 - 9 = -9`和`image_y = 1`。 展开距离为`|-9 - 1| = 10`，所以结果是`10.00`。 选择正垂直方向给出图像`11`，也有 10 个单位的距离。 直接目的地为`9`距离只有 8 个单位，但它代表零反弹，因此被拒绝。 

第四种边缘情况是具有相同坐标的大量反弹计数：```
1
100 100 50 50 50 50 100
```最好的解决方案是均匀分布 100 次弹跳，`p = -50`和`q = -50`。 两个指数都是偶数，所以图像是`-4950`在每个轴上。 每个坐标变化`5000`，给定距离`sqrt(5000^2 + 5000^2) = 7071.067...`，打印为`7071.07`。 更不平衡的分割，例如 49 和 51 次反弹，会产生更大的欧几里德距离，因此枚举自然会找到平衡的选择，而不需要单独的优化参数。
