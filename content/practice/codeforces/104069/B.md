 ## 解决方案
 ## 问题理解

 我们得到一个学生列表，其中每个学生都有一个名字和一个关联的整数。 对于每个整数，我们可以将其分解为素数。 在该整数的所有素数因子中，我们关心整除它的最大素数。 对于每个学生，我们计算他们人数的“最大素因数”。 任务是找到该值最大的学生。 如果多个学生共享相同的最大素因数，我们将返回输入顺序中最早出现的那个。 

输入规模最大为10万学生，每个数字最多为1亿。 这立即排除了任何使用每个查询最多 n 的朴素试除法独立分解数字的方法。 在最坏的情况下，即使每个数字的 O(n √x) 也会导致大约 10^5 × 10^4 次操作，这在 Python 中已经是临界值，在常量重的实现中更糟。 

一个微妙的边缘情况来自于本身是质数的数字。 对于这样的学生，答案就是数字本身，因为它是唯一的，因此也是最大的质因数。 另一种情况是数字是多个素数的乘积，其中最大的因子不一定是最频繁或最小的； 例如，2 × 3 × 97 应基于 97 进行评估。最后，关系严格取决于输入顺序，因此我们必须保留首次出现行为。 

## 方法

 一种直接的方法是独立地分解每个数字。 对于每个整数 x，我们尝试将其除以 2 到 √x 之间的每个整数并跟踪质因数。 这在逻辑上是有效的，因为任何合数都必须有一个不大于其平方根的因子。 然而，对 100,000 个数字执行此操作会使最坏情况下的工作量约为 100,000 × 10,000 次操作，这在 Python 中太慢，并且即使在常量很大的优化语言中仍然很浪费。 

关键的观察是我们不需要完全分解。 我们只需要最大的素因数。 这允许一种更加增量的方法：对于每个数字 x，我们重复地将其除以小质数或因数，但我们不存储所有因数，而是只跟踪在归约过程中遇到的最大除数。 一旦我们剔除所有小因子，如果剩余值大于 1，则该剩余值本身就是素因子，并且自动成为最大可能的候选值。 

这将问题简化为每个数字的有效因子提取，并提前终止和恒定时间跟踪迄今为止找到的最大因子。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个数字最多可试除 √x | O(n √x) | O(1) | O(1) | 太慢了 |
 | 通过最大跟踪进行增量因子剥离 | 最坏情况为 O(n √x)，由于早期归约，实践中速度很快 | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们一一处理每个学生，同时保留迄今为止看到的最佳答案。

1. 读取学生姓名和学号x，并为该学生初始化一个变量best_factor = 1。 该变量跟踪为 x 发现的最大质因数。 
2. 尝试反复将 x 除以 2。 每次成功除法时，我们都会更新 best_factor = 2。我们这样做是因为如果 2 整除 x 一次，它就是一个质因数，我们想立即记录它。 
3. 删除所有 2 的因数后，我们迭代从 3 到 √x 的奇数候选 p。 对于每个 p，当 x 可整除时，我们重复将 x 除以 p，每当我们这样做时，我们都会更新 best_factor = p。 这确保了我们捕获 x 的所有素因数，并且由于我们仅在出现有效除数时进行覆盖，因此最终存储的值是遇到的最大值。 
4. 如果处理完所有候选 x > 1，则 x 本身是一个比所有先前提取的因子都大的质数，因此我们设置 best_factor = max(best_factor, x)。 
5. 将 best_factor 与全局最大值 best_so_far 进行比较。 如果更大，我们将更新当前学生的答案。 如果相等，我们什么也不做，保留较早的一个。 
6.处理完所有学生后，输出存储的姓名。 

这样做的原因是每个合数至少有一个不超过其平方根的质因数，因此保证在迭代过程中找到所有较小的质数。 一旦所有小因子都被移除，任何剩余的值都必须是质数，并且由于它没有进一步可约，所以它必须是原始数字的最大因子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_prime_factor(x: int) -> int:
    best = 1

    while x % 2 == 0:
        best = 2
        x //= 2

    p = 3
    while p * p <= x:
        while x % p == 0:
            best = p
            x //= p
        p += 2

    if x > 1:
        best = max(best, x)

    return best

def main():
    n = int(input())
    best_name = ""
    best_value = -1

    for _ in range(n):
        parts = input().split()
        name = parts[0]
        x = int(parts[1])

        val = max_prime_factor(x)

        if val > best_value:
            best_value = val
            best_name = name

    print(best_name)

if __name__ == "__main__":
    main()
```因式分解例程首先删除 2 的所有因数以简化后续循环。 这是一种标准优化，允许随后仅逐步执行奇数，从而将迭代次数减半。 

循环条件`p * p <= x`至关重要，因为 x 在除以它时会缩小，因此边界动态保持正确。 如果我们使用原始值，我们就会过度迭代。 

最后检查`if x > 1`捕获剩余因子是从未被除掉的大素数的情况。 

主循环仅存储全局最大值，确保关系自动解析以支持最早出现的情况。

 ## 边缘情况

 一个重要的情况是数字本身是质数。 例如，输入`alice 97`。 因式分解循环没有找到任何除数，因此循环后 x 仍为 97。最终检查`if x > 1`确保 97 被记录为最大素因数，并且如果后面的学生没有超过 97，算法会正确返回 alice。 

另一种情况是完美的力量，例如`49`。 从 49 开始，我们除以 7 两次。 每个除法最佳更新为7。去除后，x变为1，因此最终值仍为7。这证实了重复因素不会扭曲最大跟踪逻辑。 

第三种情况是质因数很大而很小的数字，例如2×50000017。算法会快速删除因数2，然后将剩余的值识别为素数，确保不会因为试除限制过小而错过大因数。
