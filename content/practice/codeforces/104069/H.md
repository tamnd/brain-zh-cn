 ## 解决方案
 ## 问题理解

 我们给定一个整数$N$代表一支足球队的球员人数。 我们必须数一下我们可以用多少种方式来分割这些$N$将球员分为四个有序组：守门员、后卫、中场和进攻。 

守门员组必须包含一名球员。 其他三组必须每组至少包含一名球员。 每个玩家都属于一个组，只有组的大小才重要，而不是分配了哪些特定玩家。 

所以问题归结为计算整数四元组的数量$(g,d,m,a)$这样$$g = 1,\quad d \ge 1,\quad m \ge 1,\quad a \ge 1,\quad g+d+m+a = N.$$替代$g=1$，我们需要解决方案的数量$$d + m + a = N - 1$$所有变量至少$1$。 

这是一个经典的约束整数组合问题。 

约束条件$N \le 10^6$意味着任何解决方案都必须是$O(1)$或者在最坏的情况下$O(\log N)$每个测试用例。 对所有分区或组合枚举进行循环是不可能的，因为它会以二次方或三次方方式增长$N$。 

微妙的边缘情况发生在小$N$。 如果$N < 4$，不存在有效的阵型，因为固定一名守门员后我们无法满足三个正组。 

## 方法

 暴力解决方案会尝试所有可能的分割$N$选手分为四组。 我们修复守门员，然后迭代所有可能的防守规模，然后是中场，并将其余的分配给进攻。 这会导致两个嵌套循环$d$和$m$， 和$a$自动确定。 迭代次数增长如下$O(N^2)$，当$N$达到$10^6$。 

关键的观察结果是，只有团体规模才重要，而不是玩家的身份。 一旦我们修复了守门员，剩下的问题就是计算正整数解$d+m+a=N-1$。 这是一个标准的星条问题​​。 

我们通过设置来转换变量$d' = d-1$,$m' = m-1$,$a' = a-1$。 然后$$d' + m' + a' = N - 4,$$其中所有变量都是非负的。 

非负解的数量$x_1 + x_2 + x_3 = S$是$$\binom{S+2}{2}.$$这里$S = N-4$，所以答案就变成了$$\binom{N-2}{2}.$$扩大，$$\binom{N-2}{2} = \frac{(N-2)(N-3)}{2}.$$这给出了一个$O(1)$公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(N^2)$|$O(1)$| 太慢了 |
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取整数$N$。 该值代表包括守门员在内的全部球员。 
2.如果$N < 4$， 输出$0$。 这是必要的，因为剩余的三个组必须每个包含至少一名玩家，要求至少$1 + 3 = 4$玩家总数。 
3. 计算$N - 2$。 这种转变来自于将约束分区转换为二项式系数表达式。 
4. 计算$(N-2)(N-3)/2$。 这直接评估$\binom{N-2}{2}$使用标准身份。 
5. 输出计算值。 

### 为什么它有效

 修复守门员会从总数中删除一名球员，留下$N-1$玩家进行分配。 要求其余三组中的每一组都非空，迫使出现一个标准组合问题，其中三个正部分的总和为$N-1$。 将每个变量移动$1$将问题转化为分布问题$N-4$三个 bin 之间无法区分单位。 每个解决方案都唯一对应于一个有效的阵型，因此计算组合可以得出有效战术分布的准确数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n < 4:
    print(0)
else:
    print((n - 2) * (n - 3) // 2)
```实现直接来自派生的封闭形式。 整数除法是安全的，因为$(N-2)(N-3)$总是偶数：两个连续整数中，有一个是偶数，保证可被整除$2$。 

唯一的条件检查处理无效制度$N < 4$，其中不存在有效的分割。 

## 工作示例

 ### 示例 1：$N = 4$我们计算$d + m + a = 3$与每个至少$1$。 

| 步骤| 价值|
 | --- | --- |
 |$N$| 4 |
 |$N-4$| 0 |
 | 解决方案数量 |$\binom{2}{2} = 1$|

 这对应于唯一的分割$(1,1,1,1)$。 

痕迹证实，当不存在超出最低要求的额外球员时，只有一种阵型是可能的。 

### 示例 2：$N = 6$我们计算$d + m + a = 5$。 

| 步骤| 价值|
 | --- | --- |
 |$N$| 6 |
 |$N-4$| 2 |
 | 解决方案 |$\binom{4}{2} = 6$|

 这与将 5 分成三个正部分的六种方法相匹配。 

轨迹显示了如何增加$N$由于组合物的组合增长，灵活性成倍增加。

 ## 边缘情况

 对于$N=3$，算法正确返回$0$因为没有应用该公式并且约束强制至少有四个玩家。 执行到达条件分支并立即终止。 

为了$N=4$，计算评估$(2 \cdot 1)/2 = 1$，对应于唯一分解$(1,1,1,1)$。 不存在替代性的划分，因为每个非守门员组必须至少包含一名球员，没有任何自由度。 

对于大型$N$， 例如$10^6$，计算保持稳定，因为乘法是在 Python 的无界整数中完成的，并且中间乘积非常适合 64 位范围。
