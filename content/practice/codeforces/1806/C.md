 ## 解决方案
 ## 问题理解

 我们得到一个数组`p`长度`2n`。 我们想要修改它的值并获得另一个数组`q`相同长度的。 

目标数组不是任意的。 它必须满足一个非常严格的条件：对于精确的每一个选择`n`位置，所选值的乘积必须等于剩余值的总和`n`职位。 

在满足该条件的所有数组中，我们需要与`p`:$$\sum |p_i-q_i|$$输出只是最小距离。 

这些约束首先暗示这不是一个建设性的搜索问题。 总价值`n`所有测试用例最多是`2 \cdot 10^5`，因此可接受的解决方案必须接近每个测试用例的线性。 任何枚举子集的尝试都是不可能的，因为即使是单个测试`n = 20`已经拥有超过$10^{11}$大小的子集`n`。 

真正的挑战是了解一个好的阵列应该是什么样子。 一旦知道了该结构，优化就变得简单了。 

一个常见的错误是假设有许多有效的目标数组。 实际上，这个条件非常严格，几乎所有数组都被排除在外。 

例如，当`n = 3`，数组```
1 1 1 1 1 1
```不好。 任何选择的三重都有产品`1`，而剩下的三元组有总和`3`。 

甚至出现另一个简单的陷阱`n`。 考虑`n = 4`和```
-1 -1 -1 -1 -1 -1 -1 4
```这个阵法确实不错。 仅检查全零候选的解决方案将错过最佳值。 

案例`n = 1`也很特别。 条件变为$$q_1=q_2$$所以每对相等的数字都是好的。 治疗`n = 1`按照一般逻辑给出了错误的答案。 

## 方法

 暴力方法会尝试表征候选数组并通过检查每个大小子集来验证条件`n`。 

对于固定长度的数组`2n`，验证已经花费$$\binom{2n}{n}$$运营。 这种情况呈指数级增长，几乎立即变得毫无希望。 

关键的观察结果是，这种情况比最初出现时要严重得多。 我们可以对每个好的数组进行完全分类，而不是在所有数组中进行搜索。 

让我们看看条件的作用是什么。 

为了`n = 1`，每个好的数组都有以下形式```
[x, x]
```因为每个元素必须彼此相等。 

对于较大的`n`，一个位置不同的两个子集之间的标准比较参数表明几乎所有值都必须相同。 将这个想法推向结论会产生官方解决方案中使用的完整分类：

 对于奇数`n ≥ 3`，唯一好的数组是```
0 0 0 ... 0
```对于甚至`n ≥ 4`，正好有两个好的数组可供排列：```
0 0 0 ... 0
```和```
-1 -1 ... -1 n
```哪里有`2n-1`的副本`-1`和一份`n`。 

为了`n = 2`，还有一种额外的可能性：```
2 2 2 2
```连同```
0 0 0 0
```和```
-1 -1 -1 2
```这些都是很好的数组。 

一旦搜索空间缩减为少数候选者，优化就很容易了。 我们简单地计算距离`p`给每个有效的家庭并取最小值。

 ## 算法演练

 ###案例`n = 1`1. 设这两个数为`a`和`b`。 
2. 每个好的数组都是`[x, x]`。 
3. 最小值`|a-x| + |b-x|`时获得`x`位于之间`a`和`b`。 
4. 答案很简单`|a-b|`。 

＃＃＃ 案件`n ≥ 2`1. 计算到全零数组的距离：$$\sum |p_i|$$这个候选人总是存在的。 

1.如果`n = 2`，还计算到全二数组的距离：$$\sum |p_i-2|$$1.如果`n`是偶数，计算到包含一个值的族的距离`n`和`2n-1`值等于`-1`。 
2. 对于那个家庭，从$$\text{base}=\sum |p_i+1|$$这是将每个位置转变为的成本`-1`。 

1. 选择一个职位`n`反而。 更换位置`i`改变成本$$|p_i-n|-|p_i+1|$$1. 这个家庭的最佳成本是$$\text{base} + \min_i \left(|p_i-n|-|p_i+1|\right)$$1. 在所有有效候选者中取最小值。 

### 为什么它有效

 分类定理将良好数组的范围减少到恒定数量的族。 每个好的数组都属于这些系列之一，并且我们评估的每个系列都完全由好的数组组成。 优化步骤计算到每个家庭的精确最小距离。 由于覆盖了每个可能的好数组并且没有遗漏任何候选数组，因此这些距离中的最小值正是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        if n == 1:
            ans.append(str(abs(p[0] - p[1])))
            continue

        res = sum(abs(x) for x in p)

        if n == 2:
            res = min(res, sum(abs(x - 2) for x in p))

        if n % 2 == 0:
            base = sum(abs(x + 1) for x in p)
            best_delta = min(abs(x - n) - abs(x + 1) for x in p)
            res = min(res, base + best_delta)

        ans.append(str(res))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```第一分行处理特殊情况`n = 1`案件。 最佳相等值不需要显式计算，因为两个数字与共同目标之间的最小距离正是它们的绝对差。 

对于较大的`n`，答案是用将一切都变成零的成本来初始化的。 

这`n = 2`分支评估额外的全二良好数组。 

偶数-`n`支行评价一家人一`n`并且所有剩余值等于`-1`。 该实现避免了单独尝试每个位置。 变量`base`假设每个位置都变成`-1`。 那么我们只需要从最便宜的位置升级即可`-1`到`n`，这正是最小 Delta 表达式。 

所有算术都可以轻松地适合 Python 整数。 距离大约可以达到$2 \cdot 10^5 \cdot 10^9$，这远远超出了 32 位限制，但 Python 会自动处理这个问题。

 ## 边缘情况

 ### 案例 1：`n = 1`输入：```
1
1
6 9
```唯一有效的数组是`[x,x]`。 

该算法立即返回：$$|6-9| = 3$$没有执行其他分支。 

### 情况 2：偶数`n`特殊家庭最适合的地方

 输入：```
1
4
-1 -1 -1 -1 -1 -1 -1 4
```零数组成本为：$$7 \cdot 1 + 4 = 11$$对于特殊的家庭来说，```
base = 5
best_delta = -5
```给出总成本`0`。 

该算法正确地识别出输入已经是一个好的数组。 

### 情况 3：奇数`n`输入：```
1
3
-2 -2 2 2 0 0
```对于奇数`n ≥ 3`，唯一好的数组是全零。 

该算法计算：$$2+2+2+2+0+0=8$$并返回`8`。 

甚至没有——`n`考虑候选者，这正是分类所需要的。
