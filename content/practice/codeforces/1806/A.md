 ## 解决方案
 ## 问题理解

 我们被要求计算角色 YunQian 到达无限笛卡尔平面上的目标点的最小移动次数。 云浅有两种移动方式：她可以从斜上方移动$(x, y)$到$(x+1, y+1)$，或者她可以直接向左移动$(x, y)$到$(x-1, y)$。 输入提供起始坐标$(a, b)$和目标坐标$(c, d)$对于多个测试用例。 输出应该是最小移动次数或$-1$如果无法达到目标。 

坐标范围介于$-10^8$和$10^8$，并且最多可以有$10^4$测试用例。 探索每条可能路径的简单模拟会立即被排除，因为即使是一条路径也可能需要最多$2 \cdot 10^8$在最坏的情况下移动。 这意味着解决方案必须是纯粹分析性的，基于几何和简单算术而不是搜索。 

当目标直接位于起点左侧或起点上方且没有水平位移时，会出现边缘情况。 例如，如果开始是$(-1,0)$目标是$(-1,2)$，仅使用左移动无法到达目标，因为左移动会减少$x$但离开$y$不变，对角线移动都会增加$x$和$y$。 对此的误解会导致错误的假设，即任何垂直或水平位移总是可以实现的。 

## 方法

 暴力方法将枚举所有向左和对角移动的序列，直到到达目标。 这是可行的，因为移动是确定性的，并且可以在每次移动后跟踪坐标。 这种方法的问题是潜在的移动次数可以达到$10^8$或更多，并且移动序列呈指数级增长，因此在计算上是不可行的。 

关键的见解是观察对角线移动会增加$x$和$y$增加 1，而向左移动仅减少$x$。 如果我们表示$dx = c - a$和$dy = d - b$，那么只有当对角线移动的次数达到目标时才有可能$k$并向左移动$l$满足两个约束：$k - l = dx$和$k = dy$。 由此，我们得出$l = dy - dx$。 仅当两者都有效时，移动才有效$k \ge 0$和$l \ge 0$，否则不可能达到目标。 这将每个测试用例的问题简化为简单的算术，从而允许$O(1)$每个测试用例的解决方案。

 ## 算法演练

 1. 计算水平和垂直位移：$dx = c - a$,$dy = d - b$。 这些代表我们必须实现的 x 和 y 坐标的净变化。 
2. 检查垂直位移是否为负值。 由于对角线移动只会增加$y$向左移动离开$y$不变，如果$dy < 0$，就不可能达到目标。 返回$-1$在这种情况下。 
3. 计算所需的向左移动次数：$l = dy - dx$。 这来自解决系统$k - l = dx$和$k = dy$， 在哪里$k$是对角线移动的次数。 
4. 验证左移动次数是否为非负数。 如果$l < 0$，目标位于仅对角线移动的右侧，使得目标无法到达。 返回$-1$。 
5. 如果前面的两项检查都通过，则最小移动次数是向左移动和对角移动的总和：$k + l = dy + (dy - dx) = 2 \cdot dy - dx$。 返回这个值。 

为什么它有效：该算法之所以有效，是因为移动是线性且确定的。 每个垂直增加都必须来自对角线移动，给出$k = dy$。 水平位移是对角线和左移动的净效应，给出$dx = k - l$。 解决这个系统可以保证最少的移动，因为任何额外的对角或向左移动都会超出目标。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    dx = c - a
    dy = d - b
    if dy < 0:
        print(-1)
        continue
    l = dy - dx
    if l < 0:
        print(-1)
        continue
    print(dy + l)
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它计算坐标差异。 它立即检查垂直位移是否为负，可用的移动无法覆盖该负值。 然后它计算所需的左移动次数并检查它是否为负数。 对角线移动和向左移动的总和给出了最小移动次数。 使用`sys.stdin.readline`确保最大程度的快速 I/O$10^4$测试用例。
