 ## 解决方案
 ## 问题理解

 我们被要求确定目标金额是否`n`可以使用任意数量的整数组成`1`到`k`，排除单个禁用整数`x`。 如果可能的话，我们必须构造一个有效的整数序列，其总和恰好为`n`。 每个测试用例提供三个整数：`n`（目标总和），`k`（最大可用整数），以及`x`（禁止的整数）。 

限制很小：`n`,`k`， 和`x`最多 100 个，并且最多可以有 100 个测试用例。 这允许算法具有大约 O(n²) 的复杂度，但更简单的 O(n) 或 O(1) 构造方法是更可取的。 因为我们可以无限复制每个允许的数字，所以问题就简化为从集合中找到多个数字集`[1, k] \ {x}`总和就是`n`。 

当禁止的整数时出现边缘情况`x`要么非常小，要么非常大。 例如，如果`x = 1`和`n = 1`，我们无法求和，因为允许的最小数是 2。同样，如果`x = k = 1`，可用整数集为空，并且任何正数`n`是不可能的。 另一个微妙之处是，如果`n`小于允许的最小数（例如，`n = 2`但`1`被禁止），就不可能达到目标。 

## 方法

 暴力解决方案将尝试以下整数的所有组合`1`到`k`排除`x`。 这可以递归地或通过动态编程来实现。 它的时间复杂度很高，可能是O(n·k)，对于小数据来说是不必要的`n`。 

一个关键的观察简化了问题：由于我们可以使用允许的整数的无限副本，因此我们只需要检查是否`n`可以使用允许的最小整数的重复副本来形成。 如果`1`并不被禁止，我们总是可以形成`n`通过采取`n`的副本`1`。 如果`1`被禁止但是`2`是允许的，`n`必须至少是`2`可以写成二的总和（或者二三的混合，如果有的话）。 构造性性质允许我们输出一个简单的贪婪序列：用允许的最小整数填充尽可能多的值，然后在必要时用下一个最小的整数进行调整。 

这种见解将问题简化为对允许的最小整数的简单检查，然后直接构造总和，每个测试用例产生 O(n) 时间，这已经足够快了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·k) | O(n) | 有效但没有必要 |
 | 贪婪/建设性| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 确定允许的最小整数`a`。 这是 1（如果`x != 1`) 或 2 (如果`x = 1`和`k >= 2`）。 如果`x = 1`和`k = 1`，不允许使用整数，答案是“NO”。 
2. 判断是否`n`可以使用`a`。 如果`n < a`，打印“NO”，因为我们无法形成`n`整数大于`n`。 否则，继续构建序列。 
3. 贪心构造序列。 如果`a = 1`， 拿`n`1. 如果`a = 2`， 和`n`是偶数，取`n / 2`2. 如果`n`是奇数并且`k >= 3`和`3`是允许的，取一 3 并`(n - 3)/2`2份。否则不可能。 
4. 输出“YES”、序列中整数的总数以及序列本身。 

为什么有效：允许的最小整数在求和结构中占主导地位，因为它们提供了最大的灵活性。 任意金额`n`至少可以使用该整数的倍数构造允许的最小整数，并使用下一个允许的最小整数进行微调，如果`n`不能被最小整数整除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k, x = map(int, input().split())
    
    if k == 1 and x == 1:
        print("NO")
        continue
    
    if x != 1:
        # 1 is allowed
        print("YES")
        print(n)
        print("1 " * n)
    else:
        # 1 is forbidden, use 2 if possible
        if n == 1:
            print("NO")
        elif n % 2 == 0:
            print("YES")
            print(n // 2)
            print("2 " * (n // 2))
        elif k >= 3:
            print("YES")
            count = 1 + (n - 3) // 2
            print(count)
            print("3 " + "2 " * ((n - 3) // 2))
        else:
            print("NO")
```该解决方案首先处理不允许数字的退化情况。 然后它检查是否`1`可以使用，可以立即施工。 如果`1`被禁止，解决方案使用`2`对于甚至`n`和`3 + 2`对于奇数`n`如果可能的话。 这符合上述的建设性逻辑。

 ## 边缘情况

 如果唯一允许的数字是 2 并且`n`是奇数，算法正确输出“NO”，因为无法仅使用 2 秒来求和奇数。 例如，`n = 5, k = 2, x = 1`产生“否”。 如果`1`是允许的，即使是大的`n`使用简单地构建`n`1. 如果`n`等于禁止整数但有其他整数可用时，算法会选择允许的最小整数，确保在不使用禁止数的情况下也能达到总和。
