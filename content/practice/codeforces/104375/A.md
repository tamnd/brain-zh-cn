 ## 解决方案
 ## 问题理解

 每个人的全名都以单词序列的形式给出。 根据该名称，通过获取每个单词的第一个字母并按顺序连接这些字母来构造一个称为 NAME 的紧凑标识符。 因此，像“jose Osorio jimenez orozco”这样的名字就变成了“jojo”。 

任务不是为输出显式生成这些标识符，而是计算所有给定人员中存在多少个不同的此类 NAME 字符串。 

输入大小最多为 10,000 个姓名，每个姓名最多 20 个单词。 这意味着处理的总字数最多只有几十万。 任何处理每个单词一次并对每个单词执行持续工作的解决方案都可以轻松满足时间限制。 我们无法承受将每个名字与其他每个名字进行比较的任何行为，因为这会引入人数的二次行为。 

一个微妙的边缘情况来自重复的结构。 两个完全不同的全名可以产生相同的首字母。 例如，“juan perez”和“jose prieto”都会生成“jp”，并且这些必须算作一个唯一的名称。 另一个特殊情况是相同的全名多次出现，也会折叠成一个名称。 

一个天真的错误是假设输入名称的唯一性意味着生成的首字母的唯一性。 当不同的单词序列共享相同的第一个字母时，该假设立即失效。 

## 方法

 一种直接的方法是计算每个人的姓名并将其存储在一个列表中，然后对于每个新的姓名，通过扫描列表来检查它是否已经出现。 这是正确的，因为它通过比较明确地强制执行唯一性。 然而，每次插入都需要扫描所有先前看到的条目，这会导致最坏的情况，即大约 N 平方的比较。 当 N 达到 10,000 时，这可以达到 1 亿次比较，当涉及字符串时，这在 Python 中是临界值或太慢了。 

关键的观察是我们只关心不同的字符串，而不关心它们的频率或顺序。 一旦我们认识到这一点，问题就简化为维护一组字符串。 哈希集提供了预期的恒定时间插入和成员资格检查，因此我们可以处理每个名称一次，计算其缩写，并将结果插入到集合中。 最终的答案就是集合的大小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力列表检查 | O(N²·L) | O(N·L) | O(N·L) | 太慢了 |
 | NAME 的哈希集 | O(N·L) | O(N·L) | O(N·L) | O(N·L) | 已接受 |

 这里 L 表示每个名字的平均单词数，因为提取首字母需要扫描每个单词。 

## 算法演练

 1.读取名字的数量N。这决定了我们将处理多少个独立的字符串。 
2. 初始化一个空集来存储所有唯一的NAME 字符串。 该集合是有效增强唯一性的中心结构。 
3. 对于 N 个名称中的每一个，读取该行并将其拆分为标记。 第一个标记是单词数，其余标记是名称的单词。 除了知道后面有多少个单词之外，我们忽略整数。 
4. 通过迭代所有单词并获取每个单词的第一个字符来构造 NAME。 按顺序连接保留了原始名称的结构。 
5. 将构建的 NAME 插入集合中。 如果它已经存在，则该集合保持不变，这正是我们想要的。 
6. 处理完所有名称后，输出集合的大小。 这表示遇到的不同 NAME 值的数量。 

### 为什么它有效

每个名称仅根据其单词确定性地映射到单个字符串。 这种映射在相同的输入中是一致的，因此当且仅当两个人的首字母序列匹配时，他们才会产生相同的 NAME。 集合恰好为每个不同值存储一个代表，因此在处理所有输入之后，此映射下的每个等价类名称恰好为集合贡献了一个元素。 因此，最终大小正是唯一名称的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    seen = set()

    for _ in range(n):
        parts = input().strip().split()
        x = int(parts[0])
        words = parts[1:]

        name = ''.join(word[0] for word in words)
        seen.add(name)

    print(len(seen))

if __name__ == "__main__":
    main()
```该解决方案读取每一行一次并立即构建压缩表示。 每行开头的整数对于切片正确性并不严格要求，因为输入保证了一致性，但它有助于从概念上验证结构。 

关键的实现细节是使用生成器表达式构建 NAME。 这可以避免循环中重复的字符串连接，否则会导致 Python 字符串出现二次行为。 使用`join`确保每个名称的线性结构。 

套装`seen`是核心的正确性机制。 它保证重复项会自动合并，无需任何手动检查。

 ## 边缘情况

 一种重要的边缘情况是重复相同的名称。 例如：```
3
2 a b
2 a b
2 a b
```每个都会产生名称“ab”。 该算法按顺序处理它们：

 在名字之后，设置 = {ab}。 第二次之后，插入将被忽略，因为它已经存在。 第三次之后，再次没有变化。 最终输出为 1，与不同 NAME 值的数量匹配。 

另一种情况是最大长度名称：```
1
20 a a a a a a a a a a a a a a a a a a a a
```构造的 NAME 是一个由 20 个重复的“a”字符组成的字符串。 该集合恰好接收一个元素，输出为 1。该算法可以毫无问题地处理这一问题，因为字符串构造和散列随长度线性缩放，并且只有一次插入。 

最后一个微妙的情况是不同名字的首字母冲突：```
2
2 aa bb
2 ab ab
```两者都产生“ab”。 该集合再次将它们折叠成一个条目，表明唯一性仅由派生的名称决定，而不是由全名结构决定。
