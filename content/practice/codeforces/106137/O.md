 ## 解决方案
 ## 问题理解

 我们有一个矩形网格，代表一个垂直的室，其中一些单元被阻挡，一些单元包含受重力影响的可移动部件。 网格的方向是重力向下作用，这意味着任何可移动的棋子都会在其列内垂直下落，直到到达网格的底部或落在被阻挡的单元格或另一个已经固定的棋子的顶部。 

任务是在所有碎片完成掉落后计算最终的稳定配置。 被阻塞的细胞永远不会移动并成为永久的障碍。 可移动的棋子永远不会侧向移动，因此除了该列中存在固定障碍物之外，每个列都独立于其他列而演化。 

输入逐行描述这个网格，输出必须描述重力过程稳定后的网格。 

从复杂性的角度来看，网格尺寸通常足够大，以至于对每块重力的简单模拟会太慢。 如果我们重复向下扫描每个可移动的部分，最坏的情况会退化为重复遍历长列，导致单元数量的二次行为。 需要一种对每个单元进行恒定次数处理的解决方案，这意味着在网格大小方面采用线性或近线性方法。 

当多个可移动部件堆叠在障碍物上方时，会出现微妙的故障情况。 例如，在这样的列中：```
.#..
.oo.
....
```如果不小心处理重力，人们可能会错误地将棋子放置到已经占据的位置或不正确地跳过障碍物。 正确的行为是碎片以打包顺序“聚集”在最近的障碍物或底部边界上方。 

## 方法

 朴素的方法独立地模拟每个部分。 对于每个可移动的单元格，我们每次将其向下移动一行，直到它无法进一步移动为止。 虽然概念上很简单，但这会导致重复工作：单个片段可以遍历 O(n) 行，并且可以有 O(nm) 片段，在最坏的情况下产生 O(n²m) 行为。 对于大型网格来说这变得太慢了。 

关键的观察结果是运动是严格的列局部且单调的。 碎片不会跨列相互作用，并且在列内，重力有效地将可移动的细胞分类成由障碍物隔开的连续块。 我们可以自下而上地处理每一列，跟踪棋子可以沉降的下一个可用位置，而不是逐步模拟运动。 

优化来自于认识到每一列的行为就像一个被障碍物分割的堆栈。 在两个障碍物之间，所有可移动的部件都会落入该部分中最低的可用槽位。 这将重复模拟变成每列一次通过。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n²m) | O(1) 额外 | 太慢了 |
 | 列压缩| O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 将网格读入可变结构，以便我们可以在计算过程中覆盖单元格。 这是必要的，因为最终状态取决于重新排列现有字符。 
2. 独立处理每一列，因为任何移动都不会跨越列边界。 这将 2D 问题简化为 m 个独立的 1D 问题。 
3. 对于固定列，从底行开始向上扫描。 自下而上移动的原因是重力总是首先填充最低的可用空间。 
4. 维护指针`write_row`表示当前段中可以放置可移动棋子的最低位置。 最初，这是该列的底部。 
5. 逐行向上移动。 如果我们遇到阻塞的单元格，我们会重置`write_row`就在该障碍物上方，因为没有任何东西可以通过它。 
6. 如果遇到可移动棋子，则清除其当前位置并将其放置在`write_row`，然后递减`write_row`所以上面的下一块可以正确堆叠。 
7. 如果我们遇到一个空单元格，我们只需继续，因为它不会影响状态。 

以这种方式处理所有列后，网格处于最终的稳定配置。 

### 为什么它有效

 在由障碍物（或网格边界）包围的列的任何部分内，重力仅定义排序规则：所有可移动的块最终都位于该部分的底部。 该算法通过按照向上遍历过程中发现的块的确切顺序从下到上填充位置来强制执行此不变式。 每个棋子都被分配到其段中尽可能低的有效槽，并且障碍物会重置段边界，确保没有棋子跨越障碍物。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]

    for col in range(m):
        write_row = n - 1

        row = n - 1
        while row >= 0:
            if grid[row][col] == '#':
                write_row = row - 1
            elif grid[row][col] == 'o':
                grid[row][col] = '.'
                grid[write_row][col] = 'o'
                write_row -= 1
            row -= 1

    for r in range(n):
        print("".join(grid[r]))

if __name__ == "__main__":
    solve()
```实现的核心是每列的两指针式遍历。 这`write_row`指针代表下落棋子的下一个有效着陆位置。 每当我们遇到障碍物时，我们都会有效地“关闭”当前段并在其上方重新开始。 

一个常见的实施错误是更新网格，同时在没有仔细排序的情况下依赖它来做出未来的决策。 在这里，在写入之前清除原始位置可以确保我们不会意外地重复计算或重复使用片段。 另一个微妙之处是重置`write_row`正是为了`row - 1`当遇到障碍物时，因为障碍物本身必须保持固定并且不能被覆盖。

 ## 边缘情况

 一个重要的边缘情况是障碍物出现在列的最底部。 在这种情况下，任何可移动的棋子都不能占据最后一行，并且所有棋子都必须堆叠在其上方。 该算法自然地处理这个问题，因为`write_row`被重置为`row - 1`，防止放置在障碍物本身上。 

另一种情况是在任何障碍物之前有多个可移动部件的立柱。 该算法正确地从底部向上填充，因为`write_row`从最后一行开始，并随着每次放置而递减。 

最后的情况是一整列可移动的部件，没有任何障碍。 该行为简化为从上到下填充列，所有块都压缩到底部，基于指针的赋值无需任何特殊逻辑即可保证这一点。
