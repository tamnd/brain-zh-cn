 ## 解决方案
 ## 问题理解

 我们在坐标平面上正好有四个不同的点。 它们三个都不共线。 我们需要确定这四个点中有多少属于所有四个点的凸包的边界。 

由于没有三点位于一条直线上，因此只有两种可能的几何配置。 要么所有四个点都是凸四边形的顶点，在这种情况下答案为 4，要么一个点严格位于由其他三个点形成的三角形内部，在这种情况下只有三个外部点属于凸包，答案为 3。 

坐标在 -100 到 100 之间，并且总是恰好有四个点。 这使得输入大小恒定，因此即使直接检查每个可能的配置也很容易足够快。 不需要针对大量点进行 O(n log n) 凸包实现。 小坐标范围也意味着每个叉积都适合普通整数算术。 无论如何，Python 整数具有任意精度。 

主要的边缘情况是，即使输入顺序完全任意，这四个点也可以形成凸四边形。 例如，```
0 0
3 3
0 3
3 0
```有答案`4`。 假设已经在边界周围给出输入点的解决方案可能会构造错误的多边形。 

另一个重要的情况是一个点严格位于其他三个点形成的三角形内。 例如，```
-1 -1
2 -1
2 2
1 0
```有答案`3`， 因为`(1, 0)`位于由前三个点形成的三角形内。 简单地计算不同点或将每个输入点视为外壳顶点的粗心解决方案将错误地打印`4`。 

这些保证排除了三个共线点，因此我们永远不必决定位于船体边缘中间的点是否属于边界。 例如，诸如以下的输入```
0 0
1 0
2 0
0 1
```不可能发生。 因此，正确的解决方案可以使用严格的方向测试，而无需处理零交叉产品。 

所有四个坐标都相等的输入也是不可能的，因为该语句保证没有两个点重合。 因此，不应将这种情况添加为算法的有效测试。 

## 方法

 直接的几何方法已经足够了，因为只有四个点。 我们可以依次选择每个点，并询问它是否位于其他三个点形成的三角形内。 候选点有四种选择，针对其他三个点测试一个点需要进行三次方向计算。 因此，整个暴力检查最多执行 12 次跨产品评估。 它的时间复杂度是 O(1)，对于这个问题来说并不算太慢。 

关键的观察结果是，没有三点共线的四点的几何形状受到极大限制。 如果一个点位于其他三个点组成的三角形内，则该点不能是凸包的顶点。 反之，如果没有一点位于其他三点构成的三角形内部，则所有四个点都必须是极值点，因此它们形成凸四边形。 

这让我们可以避免完全建造船体。 对于候选点 P 和由其他三个点形成的三角形 ABC，当 P 相对于所有三个有向边的方向具有相同的符号时，P 严格位于三角形内部。 我们可以计算 AB 与 AP、BC 与 BP、CA 与 CP 的叉积。 如果三个值全部为正或全部为负，则 P 位于内部。 

这里的暴力方法和最优方法都是恒定时间的。 不同之处在于，直接赫尔方法解决了比必要的更普遍的问题，而三角形包含观察使用了恰好有四个点的特殊事实。

 ## 算法演练

 1. 读取四个点并将它们存储为坐标对。 
2.对于每个点P，将其他三个点视为三角形的顶点A、B、C。 我们测试 P 是否严格位于该三角形内部，因为内部点正是未出现在凸包上的点类型。 
3. 计算 P 相对于三角形每条边的方向。 对于两个向量`(x1, y1)`和`(x2, y2)`，他们的叉积是`x1 * y2 - y1 * x2`。 它的符号告诉我们一个向量是在另一个向量的左边还是右边。 
4. 如果三个方向值都为正或都为负，则 P 严格位于 ABC 内部。 不存在共线三元组保证这些值都不为零。 
5. 如果在其他三个点形成的三角形内找到任何点，则打印`3`。 正是该点被排除在凸包之外。 
6. 如果没有点在这样的三角形内，则打印`4`。 每个点都是一个极值点，因此凸包有四个顶点。 

### 为什么它有效

 考虑没有三点共线的任意四个点。 如果一个点 P 位于其他三个点的三角形内，则包含所有四个点的最小凸多边形正是该三角形，因此三个输入点位于外壳边界上。 

如果没有点位于由其他三个点形成的三角形内，则假设船体的顶点少于四个，这是矛盾的。 由于有四个不同的点，其中一个点必须位于其他三个点形成的三角形内。 这与测试相矛盾。 因此所有四个点都是船体顶点，答案是 4。 

方向测试可以正确识别三角形内的点，因为严格位于三角形内的点位于三角形三个有向边中每一个的同一侧。 由于共线三元组是被禁止的，因此严格的内部情况和边界情况被明确地分开。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    """Cross product of AB and AC."""
    return (b[0] - a[0]) * (c[1] - a[1]) - \
           (b[1] - a[1]) * (c[0] - a[0])

def inside_triangle(p, a, b, c):
    x1 = cross(a, b, p)
    x2 = cross(b, c, p)
    x3 = cross(c, a, p)

    return (x1 > 0 and x2 > 0 and x3 > 0) or \
           (x1 < 0 and x2 < 0 and x3 < 0)

def solve():
    points = [tuple(map(int, input().split())) for _ in range(4)]

    for i in range(4):
        p = points[i]
        others = [points[j] for j in range(4) if j != i]

        if inside_triangle(p, others[0], others[1], others[2]):
            print(3)
            return

    print(4)

if __name__ == "__main__":
    solve()
```这`cross`函数计算由下式形成的三角形的有符号面积表达式`a`,`b`， 和`c`。 只有它的符号才重要。 正值表示 C 位于定向线 AB 的一侧，负值表示位于另一侧。`inside_triangle`针对所有三个有向边评估候选点。 方向循环选择为`AB`,`BC`， 和`CA`，因此三角形内的点给出了三个一致的符号。 通过检查三个正值或三个负值来处理三角形的两个可能方向。 

主循环尝试所有四个点作为可能的内部点。 列表理解精确选择其他三个点，这避免了依赖任何输入排序。 

没有浮点运算。 使用整数叉积比计算角度或线交点更简单、更可靠。 坐标在 -100 到 100 之间时，中间值很小，Python 的整数运算消除了任何溢出问题。

 ## 边缘情况

 处理任意输入顺序的情况是因为该算法从不假设连续的输入点形成外壳边缘。 为了```
0 0
1 1
0 1
1 0
```每个点都与其他三个点进行测试。 没有点位于由其他点形成的三角形内，因此算法打印`4`。 按输入顺序连接点并将该顺序视为多边形边界的方法可能会做出输入未提供的不必要的假设。 

内点情况直接通过三角形测试处理。 为了```
0 0
10 0
0 10
1 1
```重点`(1,1)`位于有顶点的三角形内部`(0,0)`,`(10,0)`， 和`(0,10)`。 三个叉积的符号都相同，所以`inside_triangle`返回true，答案是`3`。 事实是`(1,1)`接近对角线边缘不会导致精度问题，因为所有计算都使用精确整数。 

坐标边界情况```
-100 -100
100 -100
100 100
-100 100
```形成一个正方形，其四个角是船体顶点。 叉积保持精确整数，不涉及浮点比较，结果为`4`。 

最后，共线边界情况不需要特殊的分支，因为输入保证没有三个点共线。 在有效测试中，点不能恰好位于三角形边缘上。 因此，严格比较`> 0`和`< 0`精确地描述唯一相关的可能性，并且算法永远不必决定共线点是否应该算作外壳顶点。
