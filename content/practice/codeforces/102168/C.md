 ## 算法演练

 1.读取整个括号字符串并初始化`balance = 0`和`minimum = 0`。 变量`balance`表示当前前缀中左括号和右括号的数量之差。 
2. 从左到右扫描字符串。 添加`1`当当前字符是`(`并减去`1`当它是`)`。 
3.处理完每个字符后，更新`minimum`迄今为止达到的最小余额。 负值意味着相应的前缀包含的右括号多于左括号。 
4. 扫描后，如果`minimum`为非负数，输出`0`。 每个前缀已经有一个非负余额，并且总余额为零，因此序列是规则的。 
5.如果`minimum`为负，输出`(-minimum + 1) // 2`。 每次交换最多可以将坏前缀的余额增加 2，而贪婪修复正好可以实现该改进，因此这是最小交换次数。 

### 为什么它有效

 考虑一个前缀，其余额是全局最小值（m<0）。 每个有效序列必须将此前缀从 (m) 提高到至少零。 交换可以移动一个`(`从前缀后面移动到前缀内部`)`出，将前缀余额更改为 (2)。 因此，至少需要 (\lceil -m/2\rceil) 次交换。 

这么多的交换也足够了。 每当前缀变为负数时，后面必须有一个左括号，因为整个字符串具有相同数量的左括号和右括号。 交换这样的未来`(`与冒犯者`)`将两个头寸之间的所有余额增加 2。 重复此操作可以消除缺陷，所需的校正次数正是 (\lceil -m/2\rceil)。 该算法精确计算该下限，因此其答案是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    balance = 0
    minimum = 0

    for ch in s:
        if ch == '(':
            balance += 1
        else:
            balance -= 1

        if balance < minimum:
            minimum = balance

    print((-minimum + 1) // 2)

if __name__ == "__main__":
    solve()
```输入被读取为一个字符串，因为只有一个测试用例。 该字符串最多可以包含 (10^6) 个字符，因此`sys.stdin.readline`避免不必要的输入开销。 

扫描仅使用一个整数来维护前缀平衡。 不需要修改字符串，因为证明表明交换使用的确切位置不会影响操作数量，只有最差的前缀赤字才重要。`minimum`从零开始，而不是从一个大的正值开始，因为空前缀的余额为零。 这也使得已经有效的字符串，例如`(())`和`()()`自然会得出零的答案。 

表达式`(-minimum + 1) // 2`对正值执行整数上限除法。 例如，赤字 1 给出`1`，赤字 2 给出`1`，赤字三给出`2`。 Python integers do not overflow, so there is no special handling needed even at length (10^6).

 The final balance itself does not need to be checked. 该语句保证左括号和右括号的数量相等，因此在处理整个字符串后，余额必然为零。

## 边缘情况

 对于`)(`，余额为 (-1) 和 (0)。 最小值为 (-1)，因此公式给出`(-(-1) + 1) // 2 = 1`。 交换两个位置产生`()`。 仅最终平衡的解决方案将错过无效的第一个前缀。 

为了`))((`，余额为 (-1,-2,-1,0)，因此最小值为 (-2)。 公式给出`1`。 关键点是，一次掉期将前缀余额改变两倍，因此赤字二倍不需要两次单独的更正。 

为了`)))(((`，余额为 (-1,-2,-3,-2,-1,0)。 最小值为 (-3)，给出`(-(-3) + 1) // 2 = 2`。 这抓住了使用的常见错误`-minimum // 2`，这会向下舍入并错误地返回`1`。 

为了`()`重复500000次，平衡交替`1`和`0`， 所以`minimum`在整个百万字符输入中保持为零。 该算法对每个字符执行恒定量的工作并返回`0`。 这无需任何交换即可行使输入上限。 

为了`(())`，平衡进展通过`1,2,1,0`，永远不会变成负数。 因此，该算法在不尝试查找交换的情况下返回零，这证实了已经有效的序列是在没有特殊情况操作的情况下进行处理的。
