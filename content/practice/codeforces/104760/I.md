 ## 解决方案
 ## 问题理解

 我们得到了一张行星图，其中每个行星都通过双向直接路线与其他一些行星相连。 对于每个行星，我们只关心有多少条直接路径与它相关，这是它在图表中的度数。 

任务是计算有多少颗行星的度数位于从 P 到 Q 的给定区间内。 

因此输入描述了一个具有 N 个顶点和 M 个边的无向图。 每条边都会将两个端点的度数加一。 构建或处理此图后，我们计算每个顶点的度数并计算有多少个顶点落在所需范围内。 

约束允许最多 10^4 个行星和最多 10^5 个连接。 这个规模意味着 O(N + M) 解决方案很容易足够快。 任何以嵌套方式重新​​计算每个节点的邻接信息的操作（例如扫描每个顶点的所有边）在最坏的情况下会导致大约 10^9 次操作，并且不会在时间限制内运行。 

当行星完全没有联系时，就会出现一种微妙的边缘情况。 它的度数为零，因此如果 P 为零或区间包含零，则必须对孤立节点进行计数。 另一种边缘情况是当 M 等于 0 并且 N 很大时，这使得所有度数同时为零。 此外，P 和 Q 可以等于 1 或更大，因此每个节点的度数为零的图应正确生成输出零，除非 P 为零。 

## 方法

 解决该问题最直接的方法是通过扫描所有边来计算每个顶点的度数。 对于每个节点，我们可以迭代所有边并计算它作为端点出现的次数。 这会产生正确的度数，因为每次出现都对应一个入射边。 

然而，这种方法对每个顶点重复相同的扫描。 对于 N 个顶点和 M 个边，这会导致 O(NM) 工作，在最坏的情况下达到大约 10^9 次操作。 那太慢了。 

关键的观察是度计算不需要逐顶点扫描。 每条边恰好为两个顶点贡献一个单位。 因此，我们可以维护一个度数数组并每条边更新一次。 这将问题简化为对边缘列表的单次传递。 

一旦计算出度数，我们只需计算 [P, Q] 中有多少个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（扫描每个节点的边缘）| O(NM) | O(N) | 太慢了 |
 | 学位积累| O(N + M) | O(N) | 已接受 |

 ## 算法演练

 我们在读取边缘时增量计算度数。 

1. 创建一个大小为 N 的数组，初始化为零。 这将存储有多少条边接触每个行星。 
2. 读取每条边 (a, b)。 由于该图是无向的，因此将 Degree[a] 加 1，将 Degree[b] 加 1。 这直接对度的定义进行编码，而不需要邻接存储。 
3. 处理完所有边后，迭代从 1 到 N 的所有行星。 
4. 对于每个行星，检查 Degree[i] 是否位于 P 和 Q 之间（包括 P 和 Q）。 如果是，则增加答案计数器。 
5. 输出最终计数器。 

关键思想是每条边只处理一次，并且其贡献立即分配到两个端点。 

### 为什么它有效

 无向图中顶点的度定义为入射边的数量。 每条输入边仅向其每个端点贡献一次入射，而不向其他顶点贡献一次。 通过在输入处理过程中将两个端点加1，我们精确地累加了度的定义。 由于没有遗漏或重复计算超出其两个端点的边，因此生成的数组对于所有顶点都是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    deg = [0] * (n + 1)

    for _ in range(m):
        a, b = map(int, input().split())
        deg[a] += 1
        deg[b] += 1

    p, q = map(int, input().split())

    ans = 0
    for i in range(1, n + 1):
        if p <= deg[i] <= q:
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案使用按行星 id 索引的简单度数数组。 最重要的实现细节是我们根本不构建邻接表，因为只有度数才重要。 这避免了额外的内存开销并保持解决方案的线性。 

边界检查`p <= deg[i] <= q`必须包括两个端点。 这里相差一的错误很常见，特别是在解释区间是否包含在内时。 由于问题明确指出包含性，因此两种比较都必须是非严格的。

 ## 边缘情况

 当没有边缘时，每个行星的度数都为零。 该算法仍然将所有度数初始化为零并且不执行更新。 最后的循环计算有多少节点满足 P ≤ 0 ≤ Q，这是正确的，因为仅当间隔中存在零时，孤立节点才是有效候选节点。 

对于单节点图，完全跳过边上的循环。 次数保持为零，最终答案完全取决于区间是否包含零。 这证实了该解决方案不假设至少存在一条边。 

当所有节点高度连接时，例如完整的图，每个节点通过重复的对称更新累积度数N−1。 由于每个边缘恰好贡献两个增量，因此不会发生过度计数，并且即使在最大密度下过滤也保持正确。
