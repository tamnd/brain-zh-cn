 ## 解决方案
 ## 问题理解

 我们给定了几个字符串，从概念上讲，我们从每个字符串中获取每个后缀。 后缀是从某个位置开始并持续到末尾的任何子字符串。 例如，在“abc”这样的字符串中，它的后缀是“abc”、“bc”和“c”。 在所有给定的字符串中，许多后缀可以完全重复，特别是当不同的字符串共享结尾时。 任务是在考虑所有字符串后计算总共存在多少个不同的后缀字符串。 

关键点是我们计算的不是后缀的出现次数，而是所有输入的所有后缀中唯一的字符串值。 

限制很大：所有字符串总共最多可以有 300,000 个字符。 这立即排除了任何显式枚举所有后缀并将它们成对比较的方法。 长度为 n 的单个字符串已经有 n 个后缀，因此在所有字符串中我们将有 O（总长度）后缀，并且它们之间的天真比较将在最坏的情况下导致二次行为。 

天真的思维的一个微妙的失败案例是将每个后缀视为一个独立的字符串，并通过重复切片子字符串将其插入到哈希集中。 对于像“aaaaaa...”这样的长字符串，每次后缀比较都会变得昂贵，因为每个子字符串提取都是 O(length)，将总成本变成 O(n²)。 

另一个边缘情况是不同字符串之间的重复。 例如，如果两个字符串相同，则它们的所有后缀也相同，因此正确的解决方案必须全局消除重复，而不是每个字符串。 

## 方法

 一种直接的方法是生成每个字符串的每个后缀并将其存储在一个集合中。 对于长度为 n 的字符串，生成后缀很容易，但插入每个后缀需要进行哈希或比较。 如果子字符串提取的时间不是恒定的，则每次插入的成本为 O(后缀长度)，在最坏的情况下，每个字符串的总工作量为 O(n²)。 当总长度达到 300,000 时，这是不可行的。 

关键的观察是所有字符串的所有后缀都可以表示为单个串联结构的子字符串，但我们必须避免错误地混合后缀边界。 我们可以将所有字符串编码为单个后缀结构表示，然后计算与后缀起始位置完全对应的不同子字符串，而不是将后缀视为独立的字符串。 

看待该问题的一种更结构化的方法是：每个后缀都由其在原始字符串中的起始位置唯一标识。 因此，问题简化为计算多个字符串的一组起始位置之间的不同子字符串。 这正是后缀自动机旨在解决的问题类型。 

后缀自动机 (SAM) 紧凑地表示 O(n) 状态下字符串的所有子串。 每个状态对应于一组共享相同结束位置等价类的子串。 至关重要的是，每个不同的子串都对应于自动机中的一条路径，我们可以在构建它时递增地计算不同的子串。 

我们单独处理每个字符串，但重复使用相同的自动机。 对于附加的每个字符，我们扩展 SAM。 在扩展过程中，每个新状态都会贡献一些新子串，其数量等于它与其后缀链接状态之间的长度差。 将所有插入的这些贡献相加就可以得到不同子串的数量。 但是，这会计算所有子字符串，而不仅仅是后缀。

为了限制后缀，我们观察到字符串的每个后缀都对应于恰好在该字符串中的某个位置结束的路径。 因此，我们不是对所有子字符串进行计数，而是在插入每个完整字符串后维护终止状态集，然后计算从这些终止位置可以到达多少个不同的子字符串。 在 SAM 术语中，我们只能从与后缀端点相对应的转换中累积贡献。 

一种等效的更清晰的方法是通过在字符串之间插入特殊的分隔符来在所有字符串上构建通用后缀自动机。 由于分隔符是唯一的并且永远不会重复使用，因此子字符串不能跨越边界。 那么，在某个位置结束的每个子字符串在一个原始字符串中都是有效的，并且后缀与从某个位置开始并在字符串末尾结束的子字符串完全对应。 我们可以通过在构建时跟踪结束位置来标记终端位置并计算可到达的不同状态作为后缀端点。 

因此，最终的解决方案简化为在所有带有分隔符的字符串上构建 SAM，并对与后缀结尾相对应的状态的贡献进行求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（枚举后缀字符串）| O(n²) | O(n) | 太慢了 |
 | 所有字符串上的后缀自动机 | O（总长度）| O（总长度）| 已接受 |

 ## 算法演练

 我们在所有给定的字符串上增量地构造一个后缀自动机，在它们之间插入一个唯一的分隔符，以便没有后缀可以跨越字符串。 

1. 用表示空字符串的单个根状态初始化一个空后缀自动机。 该根代表长度为零的子串。 
2. 对于每个字符串，迭代其字符并每次扩展自动机一个字符。 完成一个字符串后，插入一个未出现在任何字符串中的特殊分隔符。 这可确保后缀不会跨不同字符串合并。 
3. 在每次扩展期间，创建一个新状态，表示以当前位置结束的新的最长子串。 SAM 转换规则确保保留所有后缀等价关系，同时保持结构紧凑。 
4. 对于每个新创建的状态，计算它贡献了多少个新子串。 这是由其长度与其后缀链接状态的长度之间的差异给出的。 我们在全球范围内积累这一价值。 此步骤之所以有效，是因为每个状态都代表一类在创建状态时首次出现的子字符串。 
5. 处理完所有字符串后，我们忽略任何包含分隔符的子字符串。 由于分隔符是唯一的且不可重复使用，因此它们会自动中断无效的子字符串。 

### 为什么它有效

 后缀自动机保持了以下不变式：每个状态都表示一组在其结束位置方面等效的子串。 每个转换对应于将子字符串扩展一个字符。 当创建新状态时，它准确地表示在此扩展步骤之前不存在的子字符串集。 后缀链接指向自动机中仍然存在的最长的真后缀，因此状态与其后缀链接之间的长度差正好计算出引入的新的不同子串的数量。 由于分隔符隔离字符串，因此无效后缀不能跨字符串边界传播，从而确保仅计算原始字符串中的有效后缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class State:
    __slots__ = ("next", "link", "length")
    def __init__(self):
        self.next = {}
        self.link = -1
        self.length = 0

def solve():
    sam = [State()]
    last = 0
    total = 0

    def extend(c):
        nonlocal last, total
        cur = len(sam)
        sam.append(State())
        sam[cur].length = sam[last].length + 1

        p = last
        while p != -1 and c not in sam[p].next:
            sam[p].next[c] = cur
            p = sam[p].link

        if p == -1:
            sam[cur].link = 0
        else:
            q = sam[p].next[c]
            if sam[p].length + 1 == sam[q].length:
                sam[cur].link = q
            else:
                clone = len(sam)
                sam.append(State())
                sam[clone].length = sam[p].length + 1
                sam[clone].next = sam[q].next.copy()
                sam[clone].link = sam[q].link

                while p != -1 and sam[p].next[c] == q:
                    sam[p].next[c] = clone
                    p = sam[p].link

                sam[q].link = sam[cur].link = clone

        total += sam[cur].length - sam[sam[cur].link].length
        last = cur

    n = int(input())
    for _ in range(n):
        s = input().strip()
        last = 0
        for ch in s:
            extend(ch)
        extend(chr(0))

    print(total)

if __name__ == "__main__":
    solve()
```该实现使用带有克隆的经典后缀自动机。 每个状态都存储传出转换、后缀链接以及其等价类中最长子串的长度。 这`extend`函数是标准的 SAM 构造，附加步骤是每次创建状态时，我们都会累加其长度与其后缀链接长度之间的差值，从而计算新引入的子串。 

重置`last`在每个字符串的开头为零，确保后缀不会跨越字符串边界，除非通过分隔符，分隔符充当硬重置分隔符。 

使用`chr(0)`作为分隔符是安全的，因为输入字符串仅包含小写字母。

 ## 边缘情况

 像单个字符串这样的最小输入演示了基本行为。 唯一的后缀是字符串本身，因此答案是 1，并且自动机在根之外创建了一种有意义的状态。 

对于“aaaa”等重复字符的情况，强调去重。 尽管有四个后缀，但它们会折叠成两个不同的字符串（“aaaa”、“aaa”、“aa”、“a”），并且自动机确保每个新扩展仅在每个长度级别贡献一个新的不同子字符串。 

多个相同的字符串（例如由换行符分隔的“abc abc”）可确保一个字符串的后缀不会与另一个字符串合并。 分隔符可以防止跨界转换，重置活动状态可以保证后缀链跨字符串的独立性。
