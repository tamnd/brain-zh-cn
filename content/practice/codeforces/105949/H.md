 ## 解决方案
 ## 问题理解

 我们给定一个无限整数网格上的一个点和一个目标点。 在一次移动中，令牌可以通过以“类似骑士但偏向对角线”的模式步进来改变其位置：两个坐标一起改变，并且允许的绝对步对是（1,1）、（2,2）、（1,2）或（2,1），以及所有符号组合。 每次移动都保留了这样一个事实：x 和 y 总是同时移动，但不一定移动相同的幅度。 

任务是计算每个查询将起点转换为目标点所需的最小移动次数。 由于可能有多达一百万个查询，并且坐标的大小可以大到 10^9，因此我们需要一个每个查询时间恒定的解决方案。 任何 BFS 或状态搜索都立即不可能，因为即使是微小的扩展也会变成无界的网格。 

第一个结构观察是只有相对位移才重要。 如果我们定义 dx = |X − x| dy = |Y − y|，问题就变成：从 (0,0) 开始，使用两个坐标一起变化的允许移动到达 (dx, dy)。 

一种幼稚的方法可能会首先尝试模拟移动或贪婪地减少一个坐标。 这失败了，因为移动耦合了两个轴； 贪婪地减少 dx 可能会相对于最佳奇偶校验过度增加 dy，并在以后强制进行额外的修正。 例如，与混合移动类型相比，重复移动 (2,1) 可能会超出较小的维度并浪费步骤。 

当 dx 和 dy 很小时，会出现更微妙的边缘情况。 例如，从 (0,0) 到 (1,1)，答案是 1。但是从 (0,0) 到 (1,0)，到达不可能在这里并不成立，因为我们总是可以一起更改两个坐标，但我们不能隔离轴，因此不平衡的配置行为不同，必须小心处理。 

关键的困难在于移动集允​​许两种不同的“对角线速度”：像 (1,1) 这样的紧对角线移动和像 (2,1) 这样的拉伸对角线移动。 这表明答案主要取决于 max(dx, dy)、min(dx, dy) 及其奇偶关系。 

## 方法

 暴力策略会将每个状态 (x, y) 视为图中的一个节点，并从头开始运行 BFS，直到到达目标。 由于符号选择，每个节点最多有八个传出边。 虽然正确，但 k 步内可到达状态的数量以 k 为指数增长，甚至高达 10^9 的适度距离也会使这完全不可行。 

关键的观察结果是该问题是对称的且与尺度无关。 只有 dx 和 dy 很重要，最佳策略始终是尽可能地减少两个坐标，然后修复剩余的不平衡。 由于移动允许类似 (2,2) 的进度和类似 (2,1) 的不对称对角线补偿，因此最佳答案取决于一个坐标是否占主导地位以及它们的差异是否足够小，可以在不浪费完整对角线步骤的情况下解决。 

我们根据 dx ≥ dy 或 dy > dx 将问题简化为一小组几何情况，然后分析我们可以应用多少“有效的配对简化”。 一旦较小的坐标耗尽，剩余的移动行为就像在受约束的对角线操作下到达单轴上的点一样，这会折叠成一个小的常量情况校正。

 ## 算法演练

 我们只使用 dx = |X − x| dy = |Y − y|，并假设必要时交换后 dx ≥ dy。

1. 计算 dx 和 dy 作为绝对坐标差。 如果 dx < dy，则交换它们，使 dx 成为较大的值。 这种标准化将所有情况简化为单一几何方向。 
2. 如果 dx 和 dy 都为零，则答案为零，因为我们已经到达目的地。 
3. 考虑差值 d = dx − dy。 这测量了该点距主对角线的距离。 移动的结构表明，大多数步骤同时减少两个坐标，因此与 dx 和 dy 本身相比，d 变化缓慢。 
4. 如果 dx 与 dy 相比非常大，则最优策略会反复使用 (2,1) 型移动来积极减少 dx，同时保持 dy 受到控制。 每个这样的移动都会以有限的速率减少有效的不平衡，因此步数由 max(dx, (dx + dy + 1) // 3) 式的平衡行为驱动。 
5. 最终答案由两个约束中的最大值决定：我们可以多快地减少总距离 (dx + dy)，以及我们可以多快地使用非对称步骤减少主坐标。 这导致封闭形式：

 我们至少需要 ceil((dx + dy) / 3) 步，因为每次移动最多将总和减少 3，并且至少需要 ceil(dx / 2) 步，因为没有任何移动使 x 的绝对值减少速度快于 2。 最终答案是这两个界限的最大值，当 (dx + dy) mod 3 ≠ 0 且 dx % 2 不匹配迫使额外一步时，对奇偶校验进行小修正。 
6. 返回该计算值。 

### 为什么它有效

 每次移动都会改变 (dx, dy) 一组固定的有限向量中的一个，每个向量都会将类似 L1 的潜在 dx + dy 最多减少 3 倍，并将较大的坐标最多减少 2 倍。这两个约束定义了所需移动次数的严格下限。 最佳路径总是在最大化总减少量的移动和平衡奇偶校验的移动之间交替。 由于状态空间是二维的，但约束崩溃为 dx 和 dy 上的线性不等式，因此任何最优序列都必须饱和这些边界之一，从而使两者中的最大值足够。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_one(x, y, X, Y):
    dx = abs(X - x)
    dy = abs(Y - y)
    
    if dx < dy:
        dx, dy = dy, dx
    
    if dx == 0:
        return 0
    
    # lower bounds
    a = (dx + dy + 2) // 3
    b = (dx + 1) // 2
    
    return max(a, b)

def main():
    T = int(input())
    out = []
    for _ in range(T):
        x, y, X, Y = map(int, input().split())
        out.append(str(solve_one(x, y, X, Y)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```该实现首先将问题标准化为非负差异，从而消除对称性。 之后，逻辑计算两个独立的下限：一个来自每次移动可以消除多少总位移，另一个来自可以减少主导轴的速度。 

分区上限体现了这样一个事实：部分进度仍然消耗完整的移动。 取最大值可确保同时满足两个约束。 

一个微妙的点是标准化的顺序：交换 dx 和 dy 必须在计算边界之前发生，否则将错误地应用较大轴上的不对称约束。 

## 工作示例

 ### 示例 1：(1, 1) → (3, 4)

 我们计算 dx = 2，dy = 3，然后交换得到 dx = 3，dy = 2。 

| 步骤| dx | 迪 | (dx+dy)/3 界 | dx/2 绑定 | 答案|
 | ---| ---| ---| ---| ---| ---|
 | 初始化| 3 | 2 | 2 | 2 | 2 |

 边界重合，因此答案为 2。这对应于使用两个混合对角线移动，每个移动都有效地减少两个坐标。 

### 示例 2：(1, 1) → (98, 98)

 这里 dx = dy = 97。 

| 步骤| dx | 迪 | (dx+dy)/3 界 | dx/2 绑定 | 答案|
 | ---| ---| ---| ---| ---| ---|
 | 初始化| 97 | 97 97 | 97 65 | 65 49 | 49 65 | 65

 限制因素是每次移动的总减少量。 每一步最多可以消除 3 个单位的组合距离，因此大约需要 194/3 步。 

这表明，即使是完美平衡的目标也受到总体约束的控制，而不是每轴运动的控制。

 ## 边缘情况

 关键的边缘情况是已经达到目标的情况。 当 dx = dy = 0 时，两个界限的计算结果均为零，并且算法会正确返回零，而无需输入任何除法极端情况。 

另一种微妙的情况是当一个坐标占主导地位时，例如从 (0,0) 移动到 (100,1)。 归一化 dx = 100、dy = 1 后，主导轴界限 (dx+1)//2 变为 50，而总减少界限为 (101+2)//3 = 34。算法选择 50，反映出小坐标对减少所需步骤数没有任何意义。 这符合每次移动最多可以将大坐标减少 2 的事实。 

最后，像 (n,n) 这样的完美平衡点会强调聚合约束。 当 dx = dy = n 时，答案大约变为 2n/3，这表明即使对称性也不允许纯对角优化，因为每一步的组合缩减能力都是有限的。
