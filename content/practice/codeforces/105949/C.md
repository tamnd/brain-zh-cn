 ## 解决方案
 ## 问题理解

 我们正在研究一个从 0 到 N 的整数演化的系统。从当前状态 x 开始，每一秒都会在其他任何事情发生之前给你一个决定。 

如果您选择被动选项，状态会在一秒后确定性地从 x 移动到 x − 1。 

如果您选择活动选项，您首先跳转到从特殊集合 S(x) 中统一选择的随机状态，并且只有在该跳转之后，您仍然应用相同的强制减少 1。 

集合 S(x) 由两个来源构建。 它包含 x 的每个约数，并且还包含仍位于 1 到 N 范围内的 x 的每个倍数。因此 S(x) 混合了“当前位置的因子”和“有界宇宙内的可达倍数”。 

目标是最小化从给定 x 开始最终达到状态 0 所需的预期秒数。 每个查询独立地请求这个最佳预期时间，但对于所有 x 来说，结构是相同的系统。 

约束达到 N，Q ≤ 100000。这立即意味着任何重新计算每个查询的转换或期望的解决方案都是不可行的。 状态空间是密集的，因此任何比大约 O(N log N) 总预处理更糟糕的事情都将在时间限制下开始失败。 

一个微妙的点是，在随机选择之后，过渡不会直接移动到 y，而是移动到 y − 1，因为在每一秒结束时强制递减。 这会将所有转换移一，并且是差一错误的最常见来源。 例如，从 x = 2 开始，选择除数转换可以在整秒后使您达到 1 或 0，具体取决于采样值。 

边缘情况出现在小 x 处。 当 x = 1 时，S(1) 仅包含 1，因此随机选择是退化的，并且两个操作实际上表现相似。 如果忘记 S(x) 始终非空，则 DP 递归可能会错误地假设无效状态。 

## 方法

 直接模拟将显式地对每个状态 x 的所有转换进行建模。 对于每个 x，我们可以计算 S(x)，然后模拟重复的选择，直到达到零，从而估计期望。 即使我们用动态编程代替模拟，朴素的结构仍然会以重复扫描大型转换集的方式重新计算期望。 由于 S(x) 包括所有除数和倍数，因此 x 上直至 N 的所有 S(x) 的总大小约为 N log N，并且每个状态的粗心重新计算会将其乘以 N，这太大了。 

关键的观察结果是，该过程是固定有向系统上的最短期望动态规划，并且每个状态只有两个可能的动作。 一个动作仅取决于先前的状态 x − 1，另一个动作取决于可预计算邻域 S(x) 的平均值。 这立即表明了一个前向 DP，其中 E[x] 仅取决于已经计算出的较小值。 

剩下的唯一困难是有效计算 S(x) 的平均值。 除数部分可以通过使用标准的筛式循环以 O(N log N) 总数枚举除数来累积。 通过迭代每个 x 的倍数，也可以以类似的调和级数复杂度来累积多重部分。 

一旦将每个 x 的 S(x) 作为列表预先计算出来，我们就可以将随机动作的期望值计算为已知 DP 值的简单平均值，因为在乘法情况下，所有目标要么是 y − 1，且 y ≤ x 要么 y < x。 

这通过预先计算的转换列表将问题简化为 1 到 N 的干净 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(N²) 或更差 | O(N) | 太慢了 |
 | 具有预计算 S(x) 的 DP | O(N log N) | O(N log N) | O(N log N) | O(N log N) | 已接受 |

 ## 算法演练

 我们将 E[x] 定义为从状态 x 开始达到 0 的最短预期时间。

我们按从 0 到 N 的递增顺序计算 E，以便所有依赖项在需要时都可用。 

1. 初始化 E[0] = 0，因为我们已经处于目标状态并且不需要时间。 
2. 通过收集所有除数和最多 N 的所有有效倍数，为从 1 到 N 的每个 x 预先计算 S(x)。这为每个状态构建了完整的可能随机目的地集。 
3. 对于从 1 到 N 的每个 x，计算被动操作的值。 这只是 1 + E[x − 1]，因为一秒钟过去了，状态确定性地移动到 x − 1。 
4. 对于主动操作，计算 S(x) 的预期值。 对于 S(x) 中的每个 y，整秒后的状态变为 y − 1，因此贡献为 E[y − 1]。 对这些值进行平均可以得出选择随机跳跃的预期成本。 
5. 取两个操作中的最小值并等效地分配 E[x] = 1 + min(passive_value − 1, active_value − 1)，或者更直接地一致地计算两个完整表达式，包括每秒的 +1。 

更清晰的公式是将这两个选项计算为每秒的全部成本，然后选择较小的一个。 

1. 计算所有 x 的 E[x] 后，通过打印 E[x] 直接回答每个查询。 

它的工作原理与单调依赖结构有关。 每个状态 x 仅依赖于状态 y − 1，其中 y ≤ x 对于除数，y ≤ x 对于倍数，因此所有依赖项都指向先前计算的 DP 值。 该系统在 DP 阶数方面没有循环，并且每个状态恰好评估两个确定性成本函数，因此选择局部最小值会产生全局最优期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    N, Q = map(int, input().split())
    
    divs = [[] for _ in range(N + 1)]
    mults = [[] for _ in range(N + 1)]
    
    for i in range(1, N + 1):
        for j in range(i, N + 1, i):
            mults[i].append(j)
            divs[j].append(i)
    
    S = [[] for _ in range(N + 1)]
    for x in range(1, N + 1):
        S[x] = divs[x] + mults[x]
    
    E = [0.0] * (N + 1)
    
    for x in range(1, N + 1):
        # option 1: do nothing
        cost_stay = 1.0 + E[x - 1]
        
        # option 2: random jump
        total = 0.0
        for y in S[x]:
            total += E[y - 1]
        cost_jump = 1.0 + total / len(S[x])
        
        E[x] = min(cost_stay, cost_jump)
    
    for _ in range(Q):
        x = int(input())
        print(E[x])

if __name__ == "__main__":
    main()
```DP数组E存储每个状态的最佳期望时间。 被动动作很简单，因为它只取决于前一个动作。 主动操作在 S(x) 上聚合，关键的实现细节是索引中的移一：由于操作后的强制递减，每个采样的 y 都会转换为 y − 1。 

div 和 mult 的构建确保 S(x) 的构建总量约为 O(N log N)，这足以满足 N 高达 100000 的需要。 

## 工作示例

 考虑一个 N = 3 的小实例。 

我们按如下方式构建 S 集。 并集后 S(1) = {1, 1, 2, 3} 概念上变为 {1, 2, 3}。 S(2) 包含除数 {1, 2} 和​​倍数 {2}，因此有效为 {1, 2}。 S(3) 包含除数 {1, 3} 和倍数 {3}，因此为 {1, 3}。 

我们按顺序计算E。 

| x| S(x) | 住宿费用 | 成本跳跃 | E[x] |
 | --- | --- | --- | --- | --- |
 | 1 | {1,2,3} | 1 + E[0] = 1 | 平均（E [0]，E [1]，E [2]）+ 1 | 分钟|
 | 2 | {1,2} | 1 + E[1] | 1 + E[1] 1 + 平均值(E[0],E[1]) | 分钟 |
 | 3 | {1,3} | 1 + E[2] | 1 + 平均值(E[0],E[2]) | 分钟|

 此跟踪显示每个状态如何仅依赖于先前计算的值，从而确认前向 DP 顺序是足够的。 

现在考虑一个退化情况 N = 1。 

| x| S(x) | 住宿费用 | 成本跳跃 | E[x] |
 | --- | --- | --- | --- | --- |
 | 1 | {1} | 1 + E[0] | 1 + E[0] 1 + E[0] | 1 + E[0] 1 |

 这两个动作是一致的，因为随机选择是强制的，这表明 DP 可以正确处理单例转换集。

 ## 边缘情况

 当 x = 1 时，S(1) 折叠成单例结构。 DP 计算 cost_stay = 1 + E[0] 和 cost_jump = 1 + E[0]，因为唯一的采样值 y = 1 映射到状态 0。两个选择都匹配，因此算法一致地分配 E[1] = 1，不会产生歧义。 

对于像 x = 12 这样的高度复合数，S(x) 由于许多除数和多个有效倍数而变得很大。 该实现仍然可以正确处理此问题，因为 y ≤ 12 所需的所有 E[y − 1] 值已在早期迭代中计算出来，因此平均值定义明确且稳定。 

在 N 附近的素数处，S(x) 由 {1, x} 加上几个倍数主导，并且 DP 通过与简单的线性回退 1 + E[x − 1] 进行比较，正确地平衡了跳跃是否有益。
