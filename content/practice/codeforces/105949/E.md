 ## 解决方案
 ## 问题理解

 我们给出了一个完整的有向图$n$标记顶点，其中每对顶点之间恰好有一个有向边，形成锦标赛。 在所有此类锦标赛中，我们需要精确计算有多少个锦标赛包含至少一个长度的有向简单循环$k$。 一个周期的长度$k$意味着我们可以选择$k$不同的顶点并对它们进行排序，以便每个连续的对都遵循有向边，并且最后一个顶点指向第一个顶点。 

输入由两个整数组成$n$和$k$。 输出是标记的锦标赛数量$n$至少包含一个这样的顶点$k$-循环，以 998244353 为模。 

一场锦标赛于$n$顶点有$2^{\binom{n}{2}}$可能的配置，因为每个无序对都贡献一个独立的二元方向选择。 这种增长速度非常快，因此任何解决方案都必须避免直接枚举图。 

这些约束表明任何依赖于迭代顶点子集或显式检查每个锦标赛内循环的解决方案都是不可能的。 即使处理单个锦标赛也是指数级的$n^2$，因此我们必须将视角从单个图表转向锦标赛的结构属性。 

一个幼稚的错误是尝试检查每一个$k$-顶点的子集并验证它是否包含有向循环。 对于固定子集，这是可以管理的，但是有$\binom{n}{k}$子集，对于$n$最多$10^5$。 

当认为“不$k$-cycle”可能表现得像“根本没有循环”，就像这种情况一样$k=3$。 为了$k=3$，唯一的无循环锦标赛是传递性锦标赛，它们的计数恰好是$n!$。 然而，对于较大的$k$，锦标赛可能包含三角形，同时仍避免更长的周期，因此结构更加复杂。 

作为一个具体的例子，当$n=3, k=3$，答案是$2^3 - 3! = 8 - 6 = 2$。 但对于$k=4$，4 个顶点上的锦标赛可能包含 3 个周期，但仍然没有 4 个周期，因此简单地减去非循环情况是不够的。 

## 方法

 蛮力视角是迭代所有锦标赛并检查是否存在$k$-循环存在。 由于有$2^{\binom{n}{2}}$在锦标赛中，在尝试任何周期检测之前这已经是不可行的。 

下一步就是要反转问题。 而不是计算包含以下内容的锦标赛$k$-cycle，我们计算那些不包含任何的$k$-循环并从锦标赛总数中减去。 

关键的结构洞察力是通过其紧密相连的组件来查看锦标赛。 每个锦标赛都可以唯一地分解为强连接组件的拓扑排序，其中组件之间的边始终指向一个一致的方向。 在每个组件内部，每个顶点都可以到达其他每个顶点，并且锦标赛的经典属性意味着任何强连接的锦标赛$m$顶点包含所有长度从 3 到 的有向循环$m$。 

这意味着一个关键的等价性：锦标赛没有长度的定向循环$k$当且仅当它至少不具有强连通分量$k$。 如果有这样一个组件，它会自动包含一个长度的循环$k$。 相反，如果所有组件的大小最多为$k-1$，那么没有循环可以跨越$k$顶点。 

因此，补数问题就变成了计算 SCC 大小均受以下限制的锦标赛：$k-1$。 

我们现在从结构上描述此类锦标赛。 每个锦标赛对应于 SCC 中顶点集的有序分区，其中每个块都是一个强连接的锦标赛。 在块之间，所有边根据顺序朝一个方向移动。 

让$g[m]$表示强关联锦标赛的数量$m$标记的顶点。 那么 SCC 分解具有区块大小的锦标赛数量$s_1, s_2, \dots, s_t$是：$$\frac{n!}{s_1! s_2! \cdots s_t!} \cdot g[s_1] g[s_2] \cdots g[s_t]$$我们总结了所有的成分$n$与每个$s_i \le k-1$。 

最后，答案是：$$2^{\binom{n}{2}} - \text{(number of tournaments with all SCC sizes } < k)$$剩下的任务就是计算$g[m]$高效。 这是通过对锦标赛不强关联的所有方式进行包含排除来完成的，利用非强锦标赛具有不平凡的削减这一事实$(S, V \setminus S)$所有边都指向一个方向。 这产生了一个标准的递归，可以计算为$O(n^2)$，然后组件尺寸的最终 DP 被截断为$k-1$，使卷积变得可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解锦标赛 |$O(2^{n^2})$|$O(1)$| 太慢了 |
 | SCC 分解 + DP 对组件尺寸的影响 |$O(nk)$或者$O(n \log n)$优化|$O(n)$| 已接受 |

 ## 算法演练

 我们分层构建解决方案，从全局计数开始，到结构化分解结束。 

1. 计算锦标赛的总数$n$顶点为$2^{\binom{n}{2}}$。 这代表了我们将从中减去的整个宇宙。 
2. 将目标重新表述为至少计算没有强相关规模组成部分的锦标赛$k$。 这将删除所有必须包含$k$-循环。 
3. 预计算$g[m]$，强关联锦标赛的数量$m$。 我们从所有锦标赛减去那些关联性不强的锦标赛中得出它。 
4. 计算$g[m]$，观察如果存在非平凡子集，则锦标赛不是强关联的$S$这样所有的边都来自$S$到$V \setminus S$。 我们通过包含源集的大小来枚举此类削减并减去贡献。 这仅基于较小的值产生递归$g$。 
5. 构建DP阵列$dp[i]$表示有效锦标赛的数量$i$所有 SCC 尺寸最多的顶点$k-1$。 初始化$dp[0] = 1$。 
6. 对于每个尺寸$i$，通过选择第一个SCC块的大小来扩展$s$从 1 到$k-1$，乘以：

 选择顶点的方法数量，

 强关联锦标赛的数量$s$顶点，

 以及剩余的安排方式$i-s$顶点。 
7. 将所有有效分解求和为$dp[n]$。 
8. 输出$2^{\binom{n}{2}} - dp[n]$。 

### 为什么它有效

 每场锦标赛都有一个独特的浓缩，形成按总顺序排列的强连接组件。 这种结构是刚性的：一旦 SCC 被固定，所有组件间的边缘都会被强制。 因此，对锦标赛进行计数可以简化为对 SCC 的有序序列进行计数，其权重由每个块内强连接锦标赛的数量给出。 将 SCC 大小限制为$k-1$完全强制不存在任何长度的循环$k$，因为任何较大的 SCC 都会自动包含这样的循环。 这使得补码计数精确而不是近似。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def solve():
    n, k = map(int, input().split())

    total = modpow(2, n * (n - 1) // 2)

    if k == 2:
        print(0)
        return

    max_s = k - 1

    # g[m] = strongly connected tournaments count
    g = [0] * (n + 1)
    g[0] = 1

    pow2 = [1] * (n * (n - 1) // 2 + 1)
    for i in range(1, len(pow2)):
        pow2[i] = pow2[i - 1] * 2 % MOD

    # precompute binomial via multiplicative formula
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = modpow(fact[n], MOD - 2)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    # compute g[m] via inclusion over non-strong tournaments
    for m in range(1, n + 1):
        total_m = pow2[m * (m - 1) // 2]
        bad = 0

        # subset S is "source side" in a cut
        for s in range(1, m):
            ways = C(m, s)
            ways = ways * pow2[s * (s - 1) // 2] % MOD
            ways = ways * pow2[(m - s) * (m - s - 1) // 2] % MOD
            bad = (bad + ways) % MOD

        g[m] = (total_m - bad) % MOD

    dp = [0] * (n + 1)
    dp[0] = 1

    for i in range(1, n + 1):
        for s in range(1, min(i, max_s) + 1):
            ways = C(i - 1, s - 1)
            ways = ways * g[s] % MOD
            ways = ways * dp[i - s] % MOD
            dp[i] = (dp[i] + ways) % MOD

    ans = (total - dp[n]) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先使用快速求幂计算锦标赛的总数。 然后，它构建组合的阶乘表，这是将顶点分割成 SCC 块所需的。 

数组`g[m]`是使用所有锦标赛中基于切割的减法来计算的，将强连接结构与那些允许方向分离的结构区分开来。 在那之后，`dp[i]`构建 SCC 块大小限制为以下的所有锦标赛$k$，使用标准有序集分区 DP。 

一个微妙的点是组合的使用$C(i-1, s-1)$，它将一个顶点固定为第一个 SCC 块的第一个元素，以避免对相同块结构的排列进行过度计数。

 ## 边缘情况

 当$k > n$，任何锦标赛都不能包含$k$-循环只是因为没有足够的顶点。 在这种情况下，DP 会计算所有锦标赛，减去它会产生零，这与每个锦标赛都会轻易避免这样一个循环的事实相匹配。 

什么时候$k = 3$，SCC 限制崩溃为要求所有组件的大小为 1，这仅强制传递锦标赛。 该算法正确地简化为减法$n!$从$2^{\binom{n}{2}}$，匹配非循环锦标赛的已知特征。 

为了$n = k$，DP 只允许一个块的大小$k$，其加权为$g[k]$。 由于任何强关联的锦标赛$k$顶点包含一个$k$-cycle，这可以正确计算那些对答案有贡献的配置，确保减法精确地删除存在此类组件的锦标赛。
