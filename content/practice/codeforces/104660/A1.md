 ## 解决方案
 ## 问题理解

 我们有一个大小为的正方形网格$n \times n$，用整数填充。 从这个网格中，我们需要计算三个值。 

首先，我们计算矩阵的迹，即主对角线上元素的总和，即位置$(1,1), (2,2), \dots, (n,n)$。 

其次，我们检查每一行以查看它是否包含任何重复值。 如果一行包含重复项，我们将其视为有问题。 我们想要的是无效排列的行数，因为它们至少包含一个重复元素。 

第三，我们对列执行相同的检查，计算有多少列包含重复项。 

输出只是这三个数字：跟踪、坏行数和坏列数。 

约束足够小，即使是$O(n^2)$遍历是微不足道的。 由于我们必须至少检查每个单元格一次来计算迹线并检测重复项，因此任何解决方案自然与单元格数量呈线性关系。 这使我们在最坏的情况下可以轻松完成几百万次操作。 

唯一微妙的边缘情况是如何检测重复项。 一种幼稚的方法可能会尝试重复对每一行和每一列进行排序，但在给定约束的情况下，这仍然会通过。 然而，最简洁的方法是在扫描时每行和每列使用一组。 

一个可能会导致粗心实现失败的小例子是，当一行包含重复值但也包含所有有效范围值时。 例如：

 输入：```
3
2 2 2
1 2 3
3 2 1
```即使值在范围内，第一行由于重复而无效。 正确的输出必须将其视为坏行。 

另一个微妙的情况是当行及其相应列中都存在重复项时； 两者必须独立计算。 

## 方法

 暴力方法将通过扫描对角线来计算轨迹，然后对于每一行和每一列，对其进行排序并检查相邻的重复项。 对每行成本进行排序$O(n \log n)$，对所有行和列执行此操作会导致$O(n^2 \log n)$。 和$n$最多几百个，这仍然可以接受，但没有必要。 

关键的观察是我们不需要排序，只需要唯一性。 这将问题转化为重复的成员资格检查，这可以使用哈希集在每行的线性时间内完成。 当我们扫描每一行时，我们将元素插入到集合中并立即检测重复项。 如果我们在读取输入时维护单独的集合或累积列值，这同样适用于列。 

这将整个计算减少到具有恒定时间插入的矩阵上的单次传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（行/列排序）|$O(n^2 \log n)$|$O(n^2)$| 已接受 |
 | 哈希集扫描 |$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 我们逐行处理矩阵，同时保持列状态。 

1. 将跟踪变量初始化为零。 还准备一组集合，每列一个，以跟踪每列中看到的值，以及坏行和坏列的计数器。 
2. 对于每一行$i$，创建一个空集来跟踪该行中的值，并创建一个指示该行是否有效的标志。 
3. 迭代每个元素$a[i][j]$。 将其添加到行集中； 如果它已经存在，则将该行标记为无效。 同时，将其添加到列中$j$的设定； 如果该列中已存在该列，则将该列标记为无效。 
4. 如果$i == j$，将值添加到跟踪累加器。 
5. 完成每一行后，如果该行无效，则增加坏行计数器。 
6. 处理完所有行后，计算有多少列集标记了重复项，或者在插入期间简单地跟踪无效列。 

更简单的实现避免维护列的完整集，而是通过每列维护一个布尔数组来指示它是否已被标记为无效，以及每列的可见值集。 

### 为什么它有效

 每行和每列都会检查一次是否有重复项，并且集合中的成员身份可确保立即检测到第一个重复出现的情况。 由于集合仅存储唯一值，因此任何重复都必然会在恒定的预期时间内触发冲突。 跟踪独立于该逻辑，并且直接根据对角线条目计算，因此重复检测的正确性不会影响它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    cols = [set() for _ in range(n)]
    bad_cols = [False] * n
    bad_rows = 0
    trace = 0

    for i in range(n):
        row = set()
        row_bad = False
        arr = list(map(int, input().split()))

        for j in range(n):
            val = arr[j]

            if i == j:
                trace += val

            if val in row:
                row_bad = True
            else:
                row.add(val)

            if val in cols[j]:
                bad_cols[j] = True
            else:
                cols[j].add(val)

        if row_bad:
            bad_rows += 1

    bad_cols_count = sum(bad_cols)
    print(trace, bad_rows, bad_cols_count)

if __name__ == "__main__":
    solve()
```该代码为每行和每列维护一个集合。 在单行的迭代中本地检测行重复。 当我们处理每个单元格时，会增量跟踪列重复，从而避免第二次遍历。 对角线条件进行内联检查，确保迹线在一次通过中累积。 

一个常见的实施错误是忘记将列标记为错误一次。 布尔数组确保同一列中的重复重复项不会增加计数。

 ## 边缘情况

 大小为 1 的最小矩阵测试算法是否正确地将单个元素行和列视为有效。 用于输入`1\n7\n`，行集仅包含一个元素，因此不会检测到重复项，并且列集的行为相同。 迹线只是 7，并且两个计数器都保持为零。 

完全恒定的矩阵，例如`2\n1 1\n1 1\n`触发每行和每列的重复检测。 行扫描将两行标记为无效，因为第二次插入到集合中会立即失败，并且在处理第二行时每列都会类似地看到重复。 该算法正确地将两个计数器递增两次。 

一种混合情况，其中只有一行包含重复项，例如`3\n2 2 2\n1 2 3\n3 1 2\n`，确认行和列逻辑是独立的。 第一行设置行标志，而列在这种特定排列中累积值而不触发重复条目，这表明列跟踪不受行级重复状态的影响。
