 ## 解决方案
 ## 问题理解

 有一个隐藏的整数$n$1 到 30000 之间。 

在一个实验中，我们提供了一组允许的步长$a_1,a_2,\dots,a_k$。 挖掘机器人从深度 0 开始并想要到达深度$n$。 它可以重复使用任何给定的步长。 机器人总是选择一条准确到达的路径$n$使用尽可能少的步骤。 实验返回最小步数。 目标是确定隐藏值$n$。 官方限制最多允许 20 个实验，总集大小最多为 250 个。 

关键的观察是这不是一个传统的算法问题。 我们正在设计审讯策略。 

自从$n \le 30000$，我们应该寻找一个其答案直接揭示的查询$n$。 挑战在于确保最小步长计算不能隐藏信息。 

一个常见的错误是选择几个大的步长并希望重建$n$从返回的最优值。 机器人正在解决一个优化问题，有很多不同的值$n$可以产生相同的答案。 

例如，使用集合$\{1,100\}$， 两个都$n=50$和$n=51$返回接近其值的答案，因为长度为 100 的步长不可用。 响应不唯一标识$n$。 

特殊价值$30000$也是一种边缘情况。 任何假设“所有数字都严格小于最大步长”的策略都必须显式处理最大可能的隐藏值。 

## 方法

 蛮力思维是提出许多问题并逐渐缩小可能值的范围。 例如，可以查询精心选择的步骤集并使用返回的最小移动次数作为信息。 这些方法很容易符合实验限制，但它们是不必要的。 

关键的观察结果是隐藏数量最多为 30000。 

考虑以下查询：$$\{1,30000\}$$如果$n < 30000$，不能使用长度为 30000 的步长，因为它会超出目标。 唯一可行的方法是到达$n$确切地说是使用$n$步长为1。 

因此返回的最小步数恰好是$n$。 

唯一剩下的情况是$n=30000$。 那么机器人可以以长度为 30000 的单步到达目标，因此答案变为 1。 

这完全确定了单次实验后的隐藏值：

 如果答案是1，那么$n=30000$。 

否则，答案本身等于$n$。 

该策略使用一个大小为 2 的查询，远低于每个限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 多信息查询 | 取决于策略| O(1) | O(1) | 不必要|
 | 单次查询`{1,30000}`| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.用集问实验`{1, 30000}`。 
2.读取返回的最小步数`m`。 
3.如果`m == 1`， 输出`30000`。 

仅当机器人使用长度为 30000 的单步时才会发生这种情况。 
4.否则输出`m`。 

什么时候`n < 30000`，长度为30000的步长是无法使用的，所以唯一可行的构造就是使用`n`单位步骤。 因此`m = n`。 

### 为什么它有效

 对于每个值$n < 30000$，任何包含长度为 30000 的步长的解都是不可能的，因为它立即超出了目标深度。 唯一允许的移动是长度为 1 的步，因此唯一的最小步数恰好是$n$。 

为了$n = 30000$，长度为 30000 的一步立即到达目标，给出答案 1。 

因此返回值是：$$m =
\begin{cases}
30000 & \text{encoded as } 1,\\
n & \text{for } n < 30000.
\end{cases}$$解码规则准确地重建隐藏值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

print("? 2 1 30000", flush=True)

m = int(input())

if m == -1:
    sys.exit(0)

if m == 1:
    print("! 30000", flush=True)
else:
    print(f"! {m}", flush=True)
```该查询仅包含两个步长。 

值 1 保证每个隐藏深度都是可达的。 选择值 30000 是因为它等于最大可能的隐藏深度。 任何较小的隐藏值根本无法使用该跳转。 

实现必须在每次输出后刷新，因为问题是交互式的。 接收`-1`表示无效交互，程序应按照交互协议立即终止。 

## 工作示例

 ### 示例 1

 假设隐藏深度为$n=23$。 

| 查询 | 返回值 |
 | ---| ---|
 |`{1, 30000}`| 23 | 23

 由于答案不是 1，所以我们输出 23。 

这演示了主要机制。 长度为 30000 的跳跃是不可用的，因此机器人正好需要 23 个单位步。 

### 示例 2

 假设隐藏深度为$n=30000$。 

| 查询 | 返回值 |
 | ---| ---|
 |`{1, 30000}`| 1 |

 答案等于 1，所以我们输出 30000。 

这是长度为 30000 的单次跳跃可以达到的唯一隐藏值。

 ## 边缘情况

 考虑最大可能的隐藏值：```
n = 30000
```查询是`{1,30000}`。 

机器人可以使用长度为 30000 的一次跳跃到达目标，因此返回的最小步数为 1。算法将此唯一响应映射回 30000。 

现在考虑低于最大值的最大值：```
n = 29999
```不能使用长度为30000的跳转。 每条有效路径全部由单元跳转组成，因此最小步数为 29999。算法直接输出 29999。 

这两种情况是唯一可能出现歧义的地方，回复的特殊处理`1`将其完全删除。
