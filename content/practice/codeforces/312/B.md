 ## 解决方案
 ## 问题理解

 两名弓箭手交替射击目标。 SmallR先射击并有概率命中$a/b$在每次拍摄时。 扎诺斯有概率命中$c/d$在每次拍摄时。 一旦有人击中了比赛的第一支安打，比赛就会结束，该玩家获胜。 

输入由四个整数组成$a, b, c, d$，它定义了两个命中概率：$$p=\frac{a}{b}, \qquad q=\frac{c}{d}$$我们必须计算 SmallR 最终获胜的概率。 

限制很小。 输入仅包含四个整数，答案是一个概率。 没有大的数据结构，没有图，也没有重复查询。 挑战完全是数学上的。 任何导出封闭式表达式的解决方案都会在恒定时间内运行。 

主要的困难是认识到游戏原则上可以永远持续下去。 简单的模拟无法枚举所有可能的序列，因为有无限多个轮次。 相反，概率必须表示为无限级数或通过递归求解。 

一个常见的错误是只考虑第一轮。 例如：```
1 2 1 2
```SmallR 立即命中概率$1/2$，但他也可以错过，Zanoes也可以错过，然后SmallR获得另一次机会。 正确答案是$2/3$， 不是$1/2$。 

当两个玩家的命中概率都非常小时，就会出现另一种微妙的情况：```
1 1000 1 1000
```比赛可能会持续很多轮，但总获胜概率仍然是明确的。 任何在固定轮数后截断过程的方法都有可能失去明显的概率质量。 

错误的第三个来源是忘记 SmallR 首先射击。 考虑：```
1 1 1 1
```两位球员都没有失手。 SmallR 在扎诺斯之前射击，所以他有概率获胜$1$， 不是$1/2$。 

## 方法

 最直接的方法就是列举SmallR能够获胜的所有方式。 

他第一次出手就能立即获胜。 他也可以在两名球员都错失一次，然后第二次尝试击中后获胜。 当两名球员都错失两次后，他可以获胜，然后第三次尝试击中，依此类推。 

这会产生无限和：$$p + (1-p)(1-q)p + ((1-p)(1-q))^2 p + \cdots$$每个术语都对应于 SmallR 最终获得第一个命中之前的特定数量的完全失败回合。 

蛮力版本实际上会评估本系列的许多术语。 它在数学上是正确的，因为每一项都代表一个不相交的获胜场景。 问题是级数是无限的。 之后截断$k$项引入了近似误差，并选择足够大的$k$是不必要的。 

关键的观察结果是该级数是几何的。 

让$$r=(1-p)(1-q).$$那么概率就变成了$$p + rp + r^2p + r^3p + \cdots.$$这正是几何级数$$p \sum_{i=0}^{\infty} r^i.$$自从$0 \le r < 1$，其总和为$$\frac{p}{1-r}.$$替换回来：$$\boxed{ \frac{p}{1-(1-p)(1-q)} }$$这个封闭式表达式在常数时间内给出了答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（许多术语的总和）| O(k) | O(1) | O(1) | 仅近似 |
 | 最优（几何级数）| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取四个整数$a, b, c, d$。 
2.计算SmallR的命中概率：$$p=\frac{a}{b}.$$3. 计算Zanoes的命中概率：$$q=\frac{c}{d}.$$4. 计算整轮失败的概率，这意味着两个玩家都失败了：$$r=(1-p)(1-q).$$这样一轮之后，游戏又回到与开始时完全相同的状态。 
5. 使用几何级数公式：$$\text{answer} = \frac{p}{1-r}.$$6. 以足够的精度打印结果。 

### 为什么它有效

 让$W$表示 SmallR 从一轮开始时获胜的概率。 

SmallR 有概率立即获胜$p$。 

如果 SmallR 未命中并且 Zanoes 也未命中，这种情况有概率发生$(1-p)(1-q)$，游戏回到原来的状态。 从那时起，SmalleR 最终获胜的概率再次为$W$。 

因此$$W=p+(1-p)(1-q)W.$$解决$W$：$$W\bigl(1-(1-p)(1-q)\bigr)=p,$$

$$W= \frac{p}{1-(1-p)(1-q)}.$$该算法准确地计算了这个数量，因此它必须返回正确的获胜概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, c, d = map(int, input().split())

p = a / b
q = c / d

ans = p / (1.0 - (1.0 - p) * (1.0 - q))

print(f"{ans:.12f}")
```该程序首先将分数转换为浮点概率。 然后它会计算两名玩家在整轮比赛中都失手的概率。 

公式$$\frac{p}{1-(1-p)(1-q)}$$直接应用。 Python的双精度浮点数足以满足所需$10^{-6}$准确性。 

打印小数点后十二位数字可以轻松满足误差容限。

import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    a, b, c, d = map(int, input().split())
    p = a / b
    q = c / d
    ans = p / (1.0 - (1.0 - p) * (1.0 - q))

# provided sample

# SmallR always hits

# Zanoes always hits if he gets a turn

# Equal small probabilities
out = float(run("1 1000 1 1000\n"))
expected = (1 / 1000) / (1 - (999 / 1000) * (999 / 1000))

# Both always hit

 ## 边缘情况

 ### SmallR 总是命中

 输入：```
1 1 1 2
```我们有$p=1$和$q=1/2$。 

该算法计算$$r=(1-1)\left(1-\frac12\right)=0,$$

$$\text{answer}=\frac{1}{1-0}=1.$$在扎诺斯获得射击机会之前，小屋很小，所以概率$1$是正确的。 

### 两名玩家的命中概率都很小

 输入：```
1 1000 1 1000
```一轮失败的概率为$$r=\frac{999}{1000}\cdot\frac{999}{1000}=0.998001.$$游戏通常会持续很多轮，但公式一次性总结了所有可能性：$$\text{answer} = \frac{0.001}{1-0.998001} \approx 0.500250125.$$不需要截断，因此不会丢失概率质量。 

### 两者总是命中

 输入：```
1 1 1 1
```该算法给出$$r=0, \qquad \text{answer}=1.$$粗心的解决方案可能会假设对称并返回$1/2$。 该公式正确地结合了 SmallR 首先射击并立即获胜的事实。
