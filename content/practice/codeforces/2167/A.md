 ## 解决方案
 ## 问题理解

 每个测试用例给我们四个棍子长度，我们想知道这四个棍子是否可以排列形成一个正方形的边界。 每根棍子都必须作为一个整体来使用，并且我们不允许对它们进行切割或变形，因此我们唯一的自由就是如何将每根棍子分配到正方形的一侧。 

正方形有四个长度相同的边。 由于我们没有组合木棍，因此每条边必须恰好对应于一根木棍，这意味着四个给定长度必须共同代表正方形的四个相等的边。 

这立即将任务减少到检查所有四个数字是否可以在重新排列后相等，甚至不需要重新排列，因为顺序并不重要。 

每个测试用例的约束很小，每个长度在 1 到 10 之间，但测试用例的数量可以多达 10^4。 这促使我们每个测试解决方案的复杂度为 O(1) 或 O(log n)，因为即使每个测试的线性扫描都是微不足道的，但任何涉及组合检查的事情都是不必要的。 

当有人试图变得过于灵活时，例如试图“配对”棍子或在心理上将它们组合起来，就会出现微妙的失败案例。 例如，使用输入`1 2 1 2`，人们可能认为配对相等的值有助于形成正方形的相对边。 但这是无效的，因为每一边都必须恰好是一根棍子，因此即使它们以平衡的方式出现，不相等的值也不能形成一个正方形。 

另一个误导性的案例是`1 1 5 5`。 它可能类似于矩形直觉，但正方形要求所有四个边都相等，所以这仍然是不可能的。 

## 方法

 一种强力解释是尝试将每根棍子分配到四个边之一，并检查是否可以形成有效的正方形。 然而，由于正方形的所有四个边必须相等，因此使用所有四个棍子的任何分配都会立即强制执行一个条件：所有选定的边长必须完全匹配。 

更一般的暴力想法是将棍棒的分配排列到两侧，但只有四根棍子，所以最多是 4 根！ = 24 种安排。 对于每个排列，我们检查所有边是否相等。 这已经是每个测试用例的持续工作，因此即使是简单的方法也足够了。 

关键的简化是认识到排列是无关紧要的。 由于所有四个边必须相同，因此唯一重要的属性是所有四个值是否相等。 排序是可选的，但即使不排序，我们也只是检查所有元素的相等性。 

这将问题简化为单一比较：最大值等于最小值，或者等效地所有值都相同。

 ## 算法演练

 1. 读取测试用例的四个棒长度。 我们将它们视为一个小的多重集，其中顺序无关。 
2. 检查四个值是否相等。 这可以通过将每个值与第一个值进行比较来完成。 
3. 如果每次比较都成功，则输出“YES”，因为所有木棍都可以作为正方形的相等边。 
4. 否则输出“NO”，因为至少一条边长不同，如果不切割或修改木棍，就不可能形成正方形。 

### 为什么它有效

 正方形边界恰好由四个等长的边组成。 由于每个输入棒必须用作单个边缘，因此唯一有效的配置是所有四个输入值都相同。 任何重新排列或分组都不能改变此约束，因为不允许合并棒。 因此，四种价值观的平等既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    if a == b == c == d:
        print("YES")
    else:
        print("NO")
```该解决方案独立读取每个测试用例并执行恒定时间比较链。 链式相等性检查`a == b == c == d`直接强制所有四个边都匹配的条件，避免任何排序或额外的数据结构。 

不需要特殊的排序或预处理，因为问题不依赖于排列，只依赖于相等。

 我们追踪两种输入：一种是正面的，一种是负面的。

 所有比较都成功，因此算法输出 YES。 这证实了正方形存在且所有边都相同的条件。 

### 示例 2：`1 2 1 2`| 步骤| 一个 | 乙| c | d | 检查结果 |

 第一个不等式已经失效了`a != b`，因此条件为假，输出为 NO。 这表明，除非所有值完全匹配，否则即使是平衡的频率分布也无关紧要。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

        a, b, c, d = map(int, input().split())
        out.append("YES" if a == b == c == d else "NO")

 ## 边缘情况

 一种微妙的情况是三根棍子相等而一根不同，例如`5 5 5 4`。 该算法依次比较：`a == b == c == d`失败于`c == d`，所以它正确输出NO。 这证实了部分均匀性不足。 

另一种情况是交替值，例如`2 3 2 3`。 即使多重集是平衡的，等式链也会立即失败`a == b`，产生NO。 这表明频率平衡并不重要； 需要结构平等。 

最大均匀情况如`10 10 10 10`干净地通过所有比较，确认边界值的行为与小值相同。
