 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和一个相应的成本数组。 对于数组中的每个位置，我们可以以一定的成本替换它的值，而我们不改变的位置保留其原始值。 执行任何更改后，我们将“下降”定义为值严格大于下一个值的位置。 目标是以最低成本消除所有掉落。 

该数组最多可以有 8000 个元素，最多可以有 5000 个测试用例。 所有测试用例的数组长度总和上限为 8000，因此我们处理的元素总数是适度的，这允许我们使用数组长度具有二次复杂度的算法。 每个元素和每个成本最多可达$10^9$，因此我们必须小心处理大数，并避免在具有固定宽度整数的语言中出现整数溢出。 

当数组已经非递减时，就会出现边缘情况。 在这种情况下，不需要任何成本。 另一种微妙的情况是替换除最佳元素之外的每个元素，例如当数组严格递减时。 只关注局部下降的粗心贪婪方法可能会付出过高的代价或无法找到全局最小值。 具有重复值的数组也需要小心处理，因为保留重复值可能比替换某些值以避免丢失更便宜。 

## 方法

 暴力方法会考虑要替换的每个可能的位置子集，计算成本并检查结果数组是否是非递减的。 子集的数量是$2^n$，即使对于$n=20$，所以暴力破解是完全不可行的。 

更结构化的方法认识到，在对潜在值进行排序或“压缩”之后，可以将问题重新构建为动态规划问题。 在每个位置，唯一重要的属性是我们选择的最终值以及达到该点的有效数组的最小成本。 如果我们从左到右迭代位置，对于当前位置的每个候选值，我们只需要考虑前一个位置不大于当前值的候选值。 这形成了一个标准的 DP 模式，其中$dp[i][v]$代表制作第一个的最低成本$i$元素不减，以值结尾$v$。 

为了提高效率，我们离散化数组值。 而不是考虑所有$10^9$可能的整数，我们只需要考虑原始数组中出现的值，因为任何最优替换都可以减少为原始数组中的值，而不会增加成本。 使用这个，我们可以实现DP$O(n^2)$每个测试用例通过维护前缀最小值来避免重新扫描所有以前的状态。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 离散化动态规划 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`和成本数组`c`。 记录长度`n`。 
2. 收集所有唯一值`a`并对它们进行排序。 这个排序的值列表称为`vals`，代表我们可以分配给任何位置的所有可能的最终值。 
3.初始化DP表`dp`有尺寸`n x len(vals)`， 在哪里`dp[i][j]`代表制作第一个的最低成本`i+1`元素非减，与`i`-第一个元素等于`vals[j]`。 
4. 填写第一行。 对于职位`0`，将其设置为的成本`vals[j]`是`0`如果`vals[j]`等于`a[0]`（不变），否则`c[0]`（我们替换它）。 
5. 迭代剩余位置`i = 1`到`n-1`。 对于每个候选值`vals[j]`在位置`i`，找到所有先前候选值中的最小成本`vals[k]`在哪里`vals[k] <= vals[j]`。 添加`c[i]`如果`vals[j] != a[i]`来计算重置成本。 
6. 使用前缀最小值数组来有效地查找最小值`k`价值观满足`vals[k] <= vals[j]`。 这避免了扫描每个候选者的所有先前状态，从而保持`O(n^2)`时间。 
7、处理完所有位置后，答案就是DP表最后一行的最小值，代表使全数组不减的最小成本。 

为什么有效：在每一步中，DP 都会保持以下不变量：`dp[i][j]`是制作第一个的最低成本`i+1`以非递减结尾的元素`vals[j]`。 通过考虑所有有效的先前值并添加重置成本，我们探索所有可行的转换，而不会错过任何最佳组合。 离散化确保我们只处理可管理数量的候选值，而前缀最小值确保我们有效地维护非递减约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        c = list(map(int, input().split()))
        
        vals = sorted(set(a))
        m = len(vals)
        
        dp = [0] * m
        for j in range(m):
            dp[j] = 0 if vals[j] == a[0] else c[0]
        
        for i in range(1, n):
            new_dp = [0] * m
            prefix_min = [0] * m
            prefix_min[0] = dp[0]
            for j in range(1, m):
                prefix_min[j] = min(prefix_min[j-1], dp[j])
            
            for j in range(m):
                cost = 0 if vals[j] == a[i] else c[i]
                new_dp[j] = prefix_min[j] + cost
            dp = new_dp
        
        print(min(dp))

if __name__ == "__main__":
    solve()
```代码首先将数组值离散化为`vals`。 第一行根据是否需要替换进行初始化。 对于每个后续位置，它构造一个前缀最小数组，以有效地强制执行非递减约束，同时添加替换成本。 最终的答案就是在最后一个位置可实现的最小成本。
