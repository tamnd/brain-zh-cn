 ## 解决方案
 ## 问题理解

 我们拥有一系列由渡轮航线连接的岛屿。 每条路线都有最低年龄要求，这意味着只有年龄至少达到路线要求值的人才能使用该路线。 对于每个叛乱分子，我们知道他们的年龄，并且必须选择两个岛屿：一个是叛乱分子居住的岛屿，另一个是他们的伴侣居住的岛屿。 伙伴永远不会移动，而叛逆者可以通过他们年龄允许的每一条渡轮路线。 

对于一个叛军来说，只有当叛军的起始岛屿和伙伴的岛屿属于同一连接组件且仅保留要求不超过叛军年龄的渡轮路线时，放置才无效。 我们需要计算每个反叛者的有效放置数量，并将这些独立选择相乘。 

输入尺寸很大。 这里可能有多达一百万个岛屿、二十万条渡轮航线和叛军。 为每个反叛者单独探索图表的解决方案将需要太多工作，因为相同的连接信息将被重新计算多次。 通过数十万个查询，我们需要全局处理图并有效地回答每个年龄阈值。 

困难的边缘情况来自于随着年龄的增长而变化的连接性。 例如，考虑：```
3 2 1
1 2 5
2 3 10
5
```5岁时，只有第一趟渡轮可以工作。 组成部分是`{1,2}`和`{3}`。 无效排序展示位置的数量为`2*2 + 1*1 = 5`，所以有效答案是`9 - 5 = 4`。 使用所有路线构建图表的粗心解决方案会错误地认为所有岛屿都是相连的。 

另一种情况是每个岛屿都连接起来时：```
3 3 1
1 2 1
2 3 1
1 3 1
10
```尺寸 3 中只有一个组成部分，因此每一种可能的放置方式都可以让叛逆者最终到达合作伙伴。 答案是`0`。 忘记这种情况通常会导致将叛军的起始岛屿视为安全地点。 

## 方法

 直接的解决方案是分别处理每个叛乱分子。 对于一个叛逆的年龄`H`，我们可以运行图遍历，同时忽略要求大于的每个渡轮`H`，标记可到达的岛屿，并计算该集合之外的岛屿。 这是正确的，因为它完全模拟了叛军的移动规则。 然而，为每个反叛者这样做可能需要`O(k(n+m))`时间。 和`k`和`m`大约`2 * 10^5`，这远远超出了可能的范围。 

关键的观察结果是，渡轮航线只有随着年龄的增长才变得可用。 如果我们按所需的年龄对所有渡轮路线进行排序，并按年龄递增的顺序处理反叛者，则图表仅通过添加边来演变。 这正是不相交集联合结构有用的情况。 

对于固定的年龄，假设连接的组件大小是`s1, s2, ...`。 不良有序岛对的数量为：```
s1^2 + s2^2 + ...
```因为当叛军和伙伴在同一组件内被选择时，他们无法准确地避开对方。 订购的展示位置总数为`n^2`，因此有效展示位置的数量为：```
n^2 - (s1^2 + s2^2 + ...)
```合并两个尺寸组件时`a`和`b`，贡献变化自`a^2 + b^2`到`(a+b)^2`。 保持这个值可以让我们立即回答每个查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k(n+m)) | O(n) | 太慢了 |
 | 最佳 | O((n+m+k) log m) | O((n+m+k) log m) | O(n+m+k) | 已接受 |

 ## 算法演练

 1. 按年龄要求对所有渡轮航线进行排序。 按年龄对所有叛军进行排序，同时记住他们原来的位置。 
2. 从每个岛屿各自不相交的集合组件开始。 最初，组件大小的平方和为`n`，因为每个组件都有尺寸一。 
3. 按照从最年轻到最年长的顺序处理叛逆者。 在回答年龄的叛逆之前`H`，合并每一条要求最多为`H`。 
4. 在合并期间，从维护的总和中删除两个旧的组件贡献，并添加合并组件的贡献。 如果元件尺寸为`a`和`b`， 更新：```
sum = sum - a^2 - b^2 + (a+b)^2
```1. 添加该年龄段所有可能的渡口后，叛军的有效位置为：```
n^2 - sum
```为那个叛逆者存储这个值。 

1. 将所有存储的值乘以模`10^9+7`因为每个叛逆者都会独立选择自己的两所房子。 

为什么它有效：

 在处理完要求最多为当前叛军年龄的所有边后，不相交的集合结构准确地代表了叛军可以到达的岛屿。 维护的平方大小总和对每个无效放置进行计数，因为同一组件内的每一对都是可访问的。 从所有可能的有序岛屿对中减去它，就剩下安全的位置。 由于每个反叛者的选择不会限制任何其他反叛者的选择，因此将这些计数相乘即可得出最终答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m, k = map(int, input().split())

    edges = []
    for _ in range(m):
        u, v, d = map(int, input().split())
        edges.append((d, u - 1, v - 1))

    ages = list(map(int, input().split()))

    edges.sort()
    queries = sorted((h, i) for i, h in enumerate(ages))

    parent = list(range(n))
    size = [1] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra = find(a)
        rb = find(b)
        if ra == rb:
            return
        if size[ra] < size[rb]:
            ra, rb = rb, ra

        nonlocal_sum[0] -= size[ra] * size[ra] + size[rb] * size[rb]
        parent[rb] = ra
        size[ra] += size[rb]
        nonlocal_sum[0] += size[ra] * size[ra]

    nonlocal_sum = [n]
    ans = [0] * k
    edge_ptr = 0
    total_pairs = n * n

    for h, idx in queries:
        while edge_ptr < m and edges[edge_ptr][0] <= h:
            _, u, v = edges[edge_ptr]
            union(u, v)
            edge_ptr += 1

        ans[idx] = total_pairs - nonlocal_sum[0]

    result = 1
    for x in ans:
        result = (result * x) % MOD

    print(result)

if __name__ == "__main__":
    solve()
```边列表排序一次，指针`edge_ptr`只会前进。 这意味着每条渡轮航线都会被考虑一次。 不相交的集合结构存储当前连接的组件，并且按大小并集加上路径压缩使每个操作的时间几乎恒定。 

变量`nonlocal_sum`表示当前年龄阈值的无效有序对的总数。 合并之前和之后都必须更新它，因为合并后两个旧组件不再存在。 减法是在更改父数组之前完成的，这样可以避免意外丢失原始组件大小。 

所有涉及岛屿对数量的计算都使用Python整数，因此不存在溢出问题。 最后的乘法减少模数`10^9+7`因为作业的数量可能非常大。

 ## 边缘情况

 当年龄小于每个渡轮要求时，不相交的集合仍然与每个岛屿分开。 为了`n=3`，这给出了无效对计数`3`，所以有效计数是`9-3=6`。 该算法自然会处理这个问题，因为没有边缘被合并。 

当多条渡轮路线连接同一岛屿时，只有第一次成功合并才重要。 后来的路线发现两个岛屿已经在同一个组件中，并且不执行任何操作。 这可以防止重复路由更改组件计数。 

当所有岛屿都连接起来时，维护的总和变为`n^2`。 答案变成零，因为每一个可能的反叛者和伙伴的位置都位于一个可到达的组件内。 

当几个叛军年龄相同时，他们都使用相同的 DSU 状态。 按年龄对查询进行排序意味着图表会针对该阈值构建一次，而不是为每个叛逆者单独重建。
