 ## 解决方案

 ## 问题理解

 我们得到了代表基里尔测量值的整数多重集。 所有值都非常紧密地聚集：每个值都位于长度最多为 2 的区间内，因此移位后，数据最多只包含三个可能的整数。 

Anya 必须构造另一个相同大小的多重集。 她的值必须与基里尔的值保持在相同的数值范围内，并且总和必须与基里尔的总和匹配，这相当于保留平均值，因为大小是固定的。 

在所有有效的构造中，我们被要求最小化有多少个值与多重匹配下的基里尔多重集一致。 换句话说，如果一个值在两个多重集中出现多次，则每个配对消耗一次出现，并且我们希望最小化此类配对的总数。 

范围宽度至多为2的约束是关键的结构限制。 这意味着标准化后，所有值都属于类似 {0, 1, 2} 的集合。 这将问题分解为在固定总和约束下在很小的字母表上选择频率。 

高达 100000 的输入大小排除了任何二次构造或任何以嵌套方式显式迭代所有赋值的方法。 该解决方案必须将决策空间减少为单个线性扫描或小状态空间上的常数因子优化。 

天真的尝试会尝试枚举 Anya 数组的所有排列或在检查总和条件时重新分配值的所有方法。 这会立即失败，因为如果在没有结构的情况下进行组合处理，即使将计数分布在三个值上也会导致呈指数级增长的配置。 

当尝试贪婪地分配值以避免本地匹配时，会出现更微妙的失败情况。 局部回避可以打破全局总和约束。 例如，如果基里尔的数组主要由零和一组成，那么盲目地避免 Anya 数组中的零可能会强制出现过多的一或二，从而破坏所需的总和。 

因此，正确的解决方案必须将该问题视为一个线性方程下的全局频率选择。 

## 方法

 暴力视角首先指出 Anya 的数组完全取决于她使用范围内三个可能值中每一个的次数。 如果我们将最小值表示为 L，则每个有效数组对应于为 L、L+1 和 L+2 选择计数，其总和为 n 并满足线性和约束。 

一个简单的解决方案会枚举所有总和为 n 的计数三元组，并检查哪些计数满足总和条件。 从概念上讲，这已经太慢了，但仍然可以管理，因为只有 O(n^2) 这样的三元组。 然而，如果直接通过重建或匹配模拟实现，评估每个配置并计算与基里尔阵列的重叠会导致 O(n^3) 行为。 

关键的观察结果是，在对值进行移位以使最小值变为零后，问题就简化为选择 Anya 使用多少个零、一和二，并遵循单个线性方程 n1 + 2*n2 = S'，其中 S' 是移位后的总和。 一旦n2确定，其他一切就确定了。 这将搜索空间从两个自由度压缩为一个自由度。 

第二个见解是，由于值域的大小是恒定的，因此可以使用频率计数在恒定的时间内计算任何候选的成本。 这允许在线性时间内迭代所有可能的 n2 值并选择最佳配置。

 | 数组的暴力枚举 | O(n^2) 或更糟 | O(n) | 太慢了 |
 | 频率+单参数扫描| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

我们首先确定基里尔数据的结构。 

1. 计算数组中的最小值 L，并通过减去 L 来移动所有值。经过此转换，所有值都位于 {0, 1, 2} 中。 这种标准化消除了绝对定位并使总和约束成为纯代数的。 
2. 计算移位阵列的频率f0、f1、f2。 还计算总和S'。 
3. 现在我们使用计数 y0、y1、y2 构建 Anya 的数组。 这些必须满足 y0 + y1 + y2 = n 和 y1 + 2*y2 = S'。 
4. 我们迭代 y2 从 0 到 n 的所有可行值。 对于每个 y2，计算 y1 = S' - 2*y2。 如果y1为负数或者超过n-y2，则该配置无效并被跳过。 
5. 对于每个有效对 (y1, y2)，计算 y0 = n - y1 - y2。 这完全确定了候选多重集。 
6. 对于每个候选者，计算与 Kirill 数组的匹配数：min(f0, y0) + min(f1, y1) + min(f2, y2)。 我们跟踪最小化该值的配置。 
7. 扫描完所有可能性后，输出最好的三元组并以任意顺序重建数组。 

我们只改变 y2 的原因是总和约束是线性的，并且一旦选择 y2 就唯一地固定 y1。 

### 为什么它有效

 基本的不变量是每个有效解恰好对应于单纯形 y0 + y1 + y2 = n 内的直线 y1 + 2*y2 = S' 上的一个整数点。 这将可行区域减少为一维候选集。 由于目标函数仅取决于计数并且在该离散域上呈分段线性，因此评估所有有效整数点可以保证找到全局最优值。 

没有任何局部决策会独立影响可行性，因为可行性仅取决于全局计数，而不取决于安排。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mn = min(a)
    a = [x - mn for x in a]

    f0 = f1 = f2 = 0
    for x in a:
        if x == 0:
            f0 += 1
        elif x == 1:
            f1 += 1
        else:
            f2 += 1

    S = f1 + 2 * f2

    best = float('inf')
    best_y0 = best_y1 = best_y2 = 0

    for y2 in range(n + 1):
        y1 = S - 2 * y2
        if y1 < 0 or y1 > n:
            continue
        y0 = n - y1 - y2
        if y0 < 0:
            continue

        cost = min(f0, y0) + min(f1, y1) + min(f2, y2)

        if cost < best:
            best = cost
            best_y0, best_y1, best_y2 = y0, y1, y2

    print(best)

    res = ([mn] * best_y0 +
           [mn + 1] * best_y1 +
           [mn + 2] * best_y2)

    print(*res)

if __name__ == "__main__":
    solve()
```实现首先对数组进行规范化，以便仅保留三个值。 频率阵列压缩了有关基里尔测量的所有必要信息。 对 y2 的可能值的循环探索与总和约束一致的所有有效分布。 

计算 y1 时必须小心，因为它是直接从方程导出的，可能会变为负数或超过 n。 在评估候选人之前必须检查这两个条件。 最终的重建与顺序无关，因此值只是以块的形式发出。

 ## 边缘情况

 当基里尔数组中的所有值都相同时，范围会折叠为单个值，并且唯一有效的构造是相同的多重集。 该算法处理此问题是因为归一化后，f1 和 f2 为零，并且仅存在一个可行的 y 配置，因此扫描返回零成本解决方案。 

当数组仅包含两个不同的值时，总和约束会强制采用窄带的可行 y 配置。 y2 上的循环仍然枚举所有有效的分割，并且最小匹配成本正确地将质量从主导值移开，以减少重叠，同时保留总和。 

当三个值的分布完美平衡时，多种配置会产生相同的总和。 该算法可能会遇到几个等成本的候选者，但由于它仅跟踪最小成本，因此任何有效的最佳解决方案都会被接受，从而在非唯一性下保持正确性。
