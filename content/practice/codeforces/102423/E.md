 ## 解决方案
 ## 问题理解

 大小为 n 的排列重新排列数字 1,…,n，以便每个数字恰好出现一次。 当放置在此处的值也是 i 时，位置 i 是一个固定点。 该任务给出 n、所需的固定点数量 m 和等级 k，并要求在恰好具有 m 个固定点的所有排列中按字典顺序排列第 k 个排列。 如果存在少于 k 个这样的排列，我们打印`-1`。 官方限制为1≤n≤50、0≤m≤n、1≤k≤10 18，时间限制为一秒。 

n 的小值具有欺骗性。 即使n=50，也有50！≈3.04×10 64 个排列，因此枚举排列是完全不可能的。 秩 k 的上限为 10 18，这意味着我们永远不需要区分大于 10 18 的计数。O(n 3 ) 附近的解决方案很容易足够小，而 n 中的任何阶乘或指数都被排除。 

在几种边界情况下，表面上合理的实现可能会失败。 为了`1 1 1`，唯一的排列是`1`，所以答案是`1`。 假设必须至少有两个位置需要重新排列的实现可能会错误地拒绝这种情况。 

为了`3 2 1`，答案是`-1`。 两个固定点只会留下一个位置和一个值，迫使最终位置也被固定。 因此，对于 n>1 来说，恰好 n−1 个固定点是不可能的。 简单地选择 m 个固定位置并排列其他所有内容的公式可能会意外地计算出具有附加固定点的排列。 

为了`3 0 3`，答案是`-1`。 三个元素的两个排列顺序是`231`和`312`，因此要求排名第三超出了可用的范围。 在选择值之前不计算整个块的贪婪构造可能会进入无效分支并最终失败，而不知道所请求的排名从未存在过。 

第三个样本，`5 3 7`，是另一个有用的边界情况。 它的答案是`2 1 3 4 5`。 前六个有效排列以`1`，而第七个开头是`2`。 仅检查候选是否可以完成而不计算其完成数量的贪心算法无法正确确定该排名。 官方的样本是`3 1 1 -> 1 3 2`,`3 2 1 -> -1`， 和`5 3 7 -> 2 1 3 4 5`。 

## 方法

 蛮力方法在概念上很简单。 生成 1,…,n 的每个排列，计算其固定点，保留那些恰好具有 m 的点，按字典顺序对它们进行排序，然后取第 k 个。 它是正确的，因为考虑了所有可能的排列，并且最终的排序正是所需的排序。 问题是排列的数量。 在最坏的情况下，生成和检查它们大约需要 n⋅n！ 基本位置检查。 对于 n=50，大约是 50⋅50！≈1.52×10 66 次检查，远远超出任何实际限制。 

有用的观察是我们不需要构造所有有效的排列。 为了确定答案的下一个元素，我们只需要知道每个可能的下一个值有多少个有效的完成。 如果最小候选者占的有效排列少于 k 个，我们可以跳过整个块并减少 k。 否则，该候选人必须是答案的一部分。 

剩下的问题是如何有效地计算这些完成情况。 一旦前缀被固定，一些剩余位置仍然可以接收它们自己的值，而其他位置则不能，因为该值已经被使用。 令 q 为剩余位置的数量，令 r 为其自身值仍然可用的剩余位置的数量。 这些 r 位置是唯一可以出现新固定点的位置。 我们可以使用三维动态规划递归来计算这种简化状态的排列。 

循环基于选择仍具有其自身可用值的 r 个位置之一。 如果它收到自己的值，我们就创建一个固定点。 否则，它的价值必须来自其他地方。 该替代值要么属于另一个特殊位置，从而破坏该位置变得固定的可能性，要么属于非特殊位置。 

蛮力之所以有效，是因为检查每个排列最终都会找到答案，但会失败，因为排列的阶乘数量很多。 观察到只有剩余位置的数量和剩余可能的定点对很重要，将计数问题减少到 O(n 3 )，之后字典序取消排序需要另一个 O(n 2 ) 状态转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n⋅n!) | O(n⋅n!) | 除了存储的答案之外，O(n) | 太慢了|
 | 最佳 | O(n 3 ) | O(n 3 ) | 已接受 |

 ## 算法演练

 1. 定义`dp[q][r][t]`作为当剩余q个位置和q个值时完成部分排列的方法的数量，这些位置中正好r个仍然有自己的可用值，并且剩余位置中正好需要t个固定点。 

第三个参数是仍然需要的固定点的数量，而不是已经构造的总数。 这使得 DP 独立于特定的前缀。 
2. 初始化空状态`dp[0][0][0] = 1`。 如果没有剩下的位置，则当还需要零个固定点时，恰好有一个有效的完成。 
3. 处理状态`r = 0`分别地。 剩余位置无法固定，因此唯一可能的目标是`t = 0`。 剩余 q 值的每个排列都是有效的，给出`q!`完成情况。 
4. 对于一个状态`r > 0`，选择一个仍具有自身可用价值的职位。 有三种可能性。 

如果该位置收到其自己的值，则会创建一个固定点。 新的状态是`(q-1, r-1, t-1)`。 

如果它接收到另一个特殊位置的自身值，则有`r-1`选择。 所选择的值消失了，因此其对应的位置不再能够被固定，同时所选择的位置本身也消失了。 新的状态是`(q-1, r-2, t)`。 

如果它接收到一个非特殊值，则有`q-r`选择。 只有选定的特殊位置消失，给出`(q-1, r-1, t)`。 

因此递归式是

 dp[q][r][t]=dp[q−1][r−1][t−1]+(r−1)dp[q−1][r−2][t]+(q−r)dp[q−1][r−1][t]。 
5. 将每个 DP 值限制为 10 18。我们仅将计数与 k 进行比较，k 的最大值为 10 18，因此区分 10 18 和更大的数字对答案没有影响。 上限还可以保持算术较小。 
6. 从位置 1 开始构造答案。最初每个值都未使用，因此所有 n 个位置都是可能的定点位置。 放`r = n`和`fixed = 0`。 
7. 在当前位置 i，按升序尝试每个未使用的值 v。 这个顺序正是字典顺序所要求的。 
8. 暂时想象一下选择v。如果v=i，则创建一个额外的固定点，并且可能的固定对的数量减少1。 

如果v=i，则当前位置消失，因此丢失一个可能的固定对。 如果 v>i，则值 v 属于未来位置并且也被删除，失去另一个可能的固定对。 因此

 r ′ =r−1−[v>i]

 对于 v  =i，而当 v=i 时 r ′ =r−1。 
9.让`need`是选择 v 后仍需要的固定点的数量。查询 DP 状态以获取剩余的 n−i 个位置。 如果该计数小于 k，则从此候选开始的每个排列都会出现在所需答案之前，因此从 k 中减去计数并尝试下一个值。 
10. 如果计数至少为 k，则提交 v，更新使用值集、定点计数，以及`r`，然后继续下一个位置。 
11. 如果没有候选能够包含所需的排名，则输出`-1`。 在实践中，这已经可以从最初的检测到`dp[n][n][m]`数数。 

关键的不变量是在处理位置 i 之前，`r`精确计算其自身值仍然可用的剩余位置，因此这些且只有那些位置可以成为固定点。 DP 通过考虑分配给一个特殊位置的值，对该简化状态的每次完成进行一次计数。 在贪婪构造过程中，每个跳过的候选者都代表一个完整的词典块，其大小是准确已知的，因此减去其大小可以保留 k 的解释为剩余后缀内所需的排名。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

LIMIT = 10**18

def solve_case(n, m, k):
    # dp[q][r][t]:
    # q remaining positions,
    # r positions whose own values are still available,
    # t fixed points still required.
    dp = [[[0] * (n + 1) for _ in range(n + 1)]
          for _ in range(n + 1)]

    dp[0][0][0] = 1

    # States with r = 0 have no possible fixed points.
    for q in range(1, n + 1):
        dp[q][0][0] = min(LIMIT, q * dp[q - 1][0][0])

    for q in range(1, n + 1):
        for r in range(1, q + 1):
            for t in range(0, q + 1):
                value = 0

                # The chosen special position becomes fixed.
                if t >= 1:
                    value += dp[q - 1][r - 1][t - 1]

                # It receives the own value of another special position.
                if r >= 2:
                    value += (r - 1) * dp[q - 1][r - 2][t]

                # It receives a value belonging to a nonspecial position.
                if q > r:
                    value += (q - r) * dp[q - 1][r - 1][t]

                dp[q][r][t] = min(LIMIT, value)

    if dp[n][n][m] < k:
        return "-1"

    used = [False] * (n + 1)
    answer = []

    r = n
    fixed = 0

    for i in range(1, n + 1):
        remaining = n - i

        for v in range(1, n + 1):
            if used[v]:
                continue

            is_fixed = (v == i)
            new_fixed = fixed + is_fixed

            if is_fixed:
                new_r = r - 1
            else:
                new_r = r - 1 - (v > i)

            need = m - new_fixed

            if need < 0 or need > remaining:
                ways = 0
            elif new_r < 0 or new_r > remaining:
                ways = 0
            else:
                ways = dp[remaining][new_r][need]

            if ways < k:
                k -= ways
                continue

            answer.append(v)
            used[v] = True
            fixed = new_fixed
            r = new_r
            break

    return " ".join(map(str, answer))

def main():
    n, m, k = map(int, input().split())
    print(solve_case(n, m, k))

if __name__ == "__main__":
    main()
```DP 在构建排列之前构建。 这`r = 0`row 被直接处理，因为当不可能存在固定点时，只要不再请求固定点，每个剩余排列都是可接受的，从而给出阶乘递推。 

为了`r > 0`，这三个项与递归中的三种情况完全对应。 周围的界限`r - 2`,`t - 1`，其余位置防止无效状态被访问或计数。 

施工期间，`used[v]`记录已经出现过的值。 的更新为`r`是微妙的。 什么时候`v == i`，当前固定对仅消失一次。 什么时候`v != i`，当前位置失去被固定的机会，并且如果`v > i`，它自己的未来地位也因为它的价值刚刚被消耗而失去了机会。 这就是为什么表达式是`r - 1 - (v > i)`。 

Python 整数不会溢出，但 10 18 的上限仍然有用，因为高于该阈值的所有计数对于排名比较都是等效的。 DP 使用从零开始的存储来存储剩余位置的数量，而排列本身的位置是从一开始的。 将这两个概念分开可以避免此解决方案中最常见的相差一错误。

 ## 边缘情况

 对于`1 1 1`，初始状态为`dp[1][1][1] = 1`。 唯一的候选者是价值`1`，创建所需的不动点并离开状态`(0,0,0)`。 DP 报告完成，所以答案是`1`。 除了正确的基本情况之外，单例排列不需要特殊处理。 

为了`3 2 1`，初始状态`dp[3][3][2]`为零。 递归自动捕捉结构原因：一旦创建了两个固定点，剩余位置就没有替代值并且也变得固定。 该算法因此打印`-1`在尝试构建排列之前。 

为了`3 0 3`，初始DP计数为2，对应`2 3 1`和`3 1 2`。 由于请求的排名是三并且`2 < 3`，算法立即报告`-1`。 该边界对于检查比较是否特别有用`count < k`， 不是`count <= k`。 

为了`5 3 7`，位置一的第一个候选者是`1`。 有六个以该值开头的有效补全，因此算法将 k 从 7 更改为 1 并拒绝整个前缀。 候选人`2`恰好有一个有效的完成，因此它被选中。 剩余的国家军队`1`在位置二和`3,4,5`进入自己的岗位，产生`2 1 3 4 5`。 这种情况既练习了字典顺序块跳跃，又练习了未来可能的固定点数量的更新。 

为了`50 50 1`，每个位置都必须固定。 DP 恰好有一个有效的完成，并且贪心过程在每个位置接受最小的可用值。 结果是恒等排列`1`通过`50`，确认允许的最大 n 不会引入任何阶乘大小行为。 

为了`5 4 1`，正好有四个固定点将强制第五个点也被固定。 DP 为此目标返回零，因此算法会拒绝它，而不会尝试格式错误的最终放置。 对于每个 n>1，这是一般的 m=n−1 不可能性情况。
