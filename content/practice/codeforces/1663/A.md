[CF 1663A - 谁测试过？](https://codeforces.com/problemset/problem/1663/A)

 **评级：** -
 **标签：** *特殊、表达式解析、树
 **求解时间：** 1m 14s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们有一组参与测试过程的参与者，其中每个参与者都与一个“测试者”关系相关联。 换句话说，每个人都指向测试他们的另外一个人，除了没有被任何人测试过的一个特殊的人。 因此，该结构形成一个有向图，其中每个节点根据解释精确地具有一个传出或传入约束，并且目标是识别满足不被任何其他参与者测试的条件的唯一参与者。 

更具体地说，想象每个参与者留下一个指针，指示谁负责测试他们。 如果我们在所有参与者中遵循这些指针，我们会得到一个结构，其中所有内容最终都通向某个地方，但只有一个参与者永远不会出现作为任何指针的目标。 那个参与者就是答案。 

对于线性扫描解决方案来说，约束足够小。 即使参与者数量达到典型的 Codeforces 限制，例如 2⋅10^5，我们也预计会在 O(n) 或 O(n log n) 内进行操作。 任何模拟重复遍历或为每个节点构建重型辅助结构的方法都会太慢。 该结构强烈表明关键操作是计算每个参与者被引用的次数。 

主要的边缘情况是结构最小时，例如单个参与者。 在这种情况下，根本没有参考资料，因此参与者就是答案。 当输入形成近循环结构（除了一个丢失的传入边缘之外）时，会出现另一种边缘情况； 假设树根或使用任意起点的简单遍历可能会失败，除非它明确跟踪传入计数。 

## 方法

 蛮力的想法是检查每个参与者并确定是否有人指向他们。 对于每个候选人，我们扫描整个关系列表并验证它是否显示为目标。 这是有效的，因为它直接匹配答案的定义，但它对每个参与者重复完整扫描。 对于 n 个参与者，这会导致 O(n^2) 检查，当 n 很大时，检查会变得太慢。 

关键的观察是，我们实际上不需要重新计算是否每个候选人都引用了某个人。 我们只需要知道每个参与者总共被引用了多少次。 如果我们计算一个频率数组，计算每个参与者被指向的次数，答案就是频率为零的索引。 

这将问题从重复的成员资格测试减少到单个聚合传递。 该结构本质上是从节点到入度计数的映射，我们正在搜索入度为零的唯一节点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 频率计数 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`cnt`大小为 n+1，带零，它将存储每个参与者被引用为测试人员目标的次数。 这种结构是必要的，因为我们需要对每个参与者进行恒定时间的更新和查询。 
2. 读取各个关系和增量`cnt[x]`对于参与者`x`谁正在接受某人的测试。 此步骤汇总有关每个参与者作为目标出现的频率的全局信息。 
3. 处理完所有关系后，扫描从 1 到 n 的所有参与者，找出计数仍为 0 的参与者。 这是在任何关系中都不会成为目标的参与者。 
4. 输出该参与者作为答案。 

### 为什么它有效

 每一种关系都会为目标参与者的计数贡献一个增量。 由于除一名参与者之外的每个参与者都保证至少作为目标出现一次，因此只有一个索引的计数为零。 计数过程保留有关结构的所有必要信息，同时丢弃与最终查询无关的排序详细信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    cnt = [0] * (n + 1)

    for _ in range(n - 1):
        u, v = map(int, input().split())
        cnt[v] += 1

    for i in range(1, n + 1):
        if cnt[i] == 0:
            print(i)
            return

if __name__ == "__main__":
    solve()
```该解决方案构建单个频率阵列并在读取输入时更新它。 第二遍只是找到未触及的索引。 关键的实现细节是确保我们增加每个关系的正确端点，因为反转这个方向会反转入度的含义并产生错误的结果。 

## 工作示例

 考虑一个小例子，参与者形成一条链，除了一个根之外。 

输入：```
5
1 2
2 3
4 3
5 4
```我们跟踪入度：

 | 步骤| 边缘 | cnt 数组（部分） |
 | ---| ---| ---|
 | 1 | 1 → 2 | cnt[2] = 1 |
 | 2 | 2 → 3 | cnt[3] = 1 |
 | 3 | 4 → 3 | cnt[3] = 2 |
 | 4 | 5 → 4 | cnt[4] = 1 |

 最终计数显示`cnt[1] = 0`，所以答案是1。 

这表明，即使在分支或聚合结构中，该方法也能正确识别没有传入边的唯一节点。 

现在考虑最小的情况：

 输入：```
1
```不存在任何关系，因此计数数组保持全零，并且返回唯一的参与者。 这证实了该算法自然可以处理简并输入。

 ## 边缘情况

 单节点情况是最脆弱的场景，因为没有需要处理的关系。 该算法可以正确处理它，因为频率数组在任何地方都保持为零并且返回唯一的索引。 

在线性链中，例如`1 → 2 → 3 → 4`，除了第一个节点之外的每个节点都只有一个传入边。 扫描正确地将节点 1 识别为唯一的零入度元素。 

例如，当多个节点指向单个节点时`1 → 3`和`2 → 3`，节点 3 的计数变得大于 1。 该算法不依赖于传入边的唯一性，仅依赖于零入度节点的存在，因此它仍然根据结构约束正确返回节点 1 或具有零传入引用的任何节点。
