 ## 解决方案
 # 问题理解

 该任务要求我们仅使用一个操作将一串企鹅地鼠图块转换为另一个字符串：选择一个位置并将每个字符反转从该位置到字符串末尾。 我们必须输出所选位置的序列，或者报告不存在序列。 原始问题约束允许长度最多为 1000 的字符串，最多需要 2000 次操作。 

转换失败的唯一原因是反转位置永远不会改变字符的多重集。 如果两个字符串中每个字母的数量不同，则任何反转顺序都无济于事。 由于长度只有 1000，二次方法仍然可以接受，但运算限制排除了许多不必要的长构造。 

一个常见的错误是只检查每个目标字符是否出现在源中的某个位置。 频率很重要。 例如，使用输入```
3
abc
abb
```正确的输出是`-1`因为第一个字符串有一个`c`当目标没有`c`。 如果粗心地只检查每个目标字母是否存在，就会错误地接受它。 

另一个边缘情况是字符串已经相等。 例如，```
1
m
m
```正确的输出是`0`。 产生无用的反转在数学上仍然有效，但它浪费了运算并使实现变得复杂。 

最后一个微妙的情况是重复的字符。 例如，```
4
aabc
cbaa
```包含的位置有多种可能的选择`c`。 选择任何匹配的事件都是有效的，因为相同的字符是可以互换的。 如果实现不正确地按值而不是按当前位置跟踪字符，则可能会移动错误的图块。 

## 方法

 思考该问题的一种强力方法是搜索可能的后缀反转，并尝试找到从起始字符串到目标字符串的路径。 这是正确的，因为每个有效的操作序列都在搜索空间中的某个位置表示。 然而，可能的状态数量是巨大的。 当长度为 1000 时，即使存储所有排列也是不可能的，并且尝试的操作序列呈指数增长。 

有用的观察是后缀反转可以将选定的字符移动到当前后缀的前面。 假设我们正在固定位置`i`从左到右。 之前的职位`i`已经是正确的并且绝不能再改变。 逆转开始于`i`正是这样做的，因为它在前面留下了前缀`i`未受影响。 

如果位置需要字符`i`目前处于位置`p`在未完成的后缀中，两次操作就足够了。 首先反转从以下位置开始的后缀`p`。 这会将所需的字符移动到末尾。 然后从以下位置开始反转后缀`i`。 所需的字符从后缀的末尾移动到该后缀的第一个位置，这正是`i`。 

蛮力方法之所以有效，是因为操作的强大程度足以重新排列字符。 它失败是因为它搜索一条路径而不是构建一条路径。 上面的观察将整个问题简化为贪婪的放置过程，其中每个位置最多需要两次操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 贪婪构造| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 计算两个字符串中每个字符的出现次数。 如果计数不同，则无法达到目标排列，因此输出`-1`。 反转仅排列位置，而不会创建或删除字符。 
2. 从左到右处理位置。 在步骤`i`, 之前的所有位置`i`已经包含了它们的最终字符，因此将来的操作只会触及剩余的后缀。 
3. 寻找任意位置`p`和`p >= i`其中当前字符等于位置的目标字符`i`。 
4. 如果`p`已经是`i`，无需任何操作。 正确的瓷砖已经就位。 
5. 否则，反转从以下位置开始的后缀`p`，然后反转从以下位置开始的后缀`i`。 第一次反转将所需的图块移动到剩余部分的末尾，第二次将其移动到前面。 
6. 继续，直到每个位置都固定好。 每个位置的操作次数最多为 2 次，因此永远不会超过 2000 次。 

为什么它有效：

 不变的是在处理位置之前`i`, 之前的每个位置`i`已经符合目标并且永远不会再改变。 后缀反转始于`i`不能影响那些较早的位置。 两次反转移动将所需的字符放置在`i`同时保留不变量，因此只要字符数允许，重复该过程最终会生成目标字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(input().strip())
    b = input().strip()

    if sorted(a) != sorted(b):
        print(-1)
        return

    ans = []

    for i in range(n):
        if a[i] == b[i]:
            continue

        pos = i
        while a[pos] != b[i]:
            pos += 1

        if pos != i:
            ans.append(pos + 1)
            a[i:pos + 1] = a[i:pos + 1][::-1]

            ans.append(i + 1)
            a[i:] = a[i:][::-1]

    print(len(ans))
    for x in ans:
        print(x)

if __name__ == "__main__":
    solve()
```第一个比较使用排序字符串，因为唯一不可能的情况是不同的字符多重集。 一旦检查通过，每个需要的字符都存在于剩余后缀中的某个位置。 

主循环一次修复一个索引。 寻找`pos`只查看尚未最终确定的位置，因此已经正确的字符永远不会受到干扰。 

Python中的两个切片反转直接模拟了两个后缀操作。 存储的索引是从 1 开始的，因为操作描述使用从 1 开始的位置。存储的操作的最大数量是`2 * (n - 1)`，符合所需的限制。

 ## 边缘情况

 对于不同的字符数，算法会在尝试任何操作之前停止。 例如：```
3
abc
abb
```频率比较发现`c`仅存在于第一个字符串中，因此它会打印`-1`。 

对于已经匹配的字符串：```
1
m
m
```循环发现唯一的位置已经正确，并将操作列表留空，产生`0`。 

对于重复字符：```
4
aabc
cbaa
```该算法搜索剩余的后缀`c`，在最后一个位置找到它，并应用两次反转。 自从两人`a`瓷砖是相同的，任何一种出现都是可以接受的，并且在每次放置后不变式仍然成立。
