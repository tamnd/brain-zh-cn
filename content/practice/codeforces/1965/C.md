 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，它代表一条长纸条，上面印有 0/1 值。 我们可以在相邻字符之间选择任意数量的切割位置，然后同时将条带的各个部分折叠在彼此的顶部。 折叠后，多个原始位置可能会堆叠在同一垂直列中。 

如果每个重叠字符堆栈仅包含相同的位，则折叠配置有效。 换句话说，每当两个原始位置在所有折叠后彼此重叠时，它们的值必须匹配。 我们不检查中间折叠有效性，仅检查最终堆叠一致性。 

目标是选择折叠位置，以便在应用所有折叠后，上方可见位置的数量最小化。 

关键约束是所有测试用例的长度总和最多为 2·10^5，这排除了任何尝试枚举折叠子集或模拟段之间的成对对齐的解决方案。 每个测试用例都是二次的任何解决方案都会太慢。 

当尝试贪婪局部折叠时，会出现微妙的失败情况。 例如，在像这样的字符串中`01010`，一个天真的想法可能会尝试重复合并相邻的外观相同的结构，但最佳折叠可能取决于非局部对称模式。 另一个棘手的情况是，当字符串具有交替位但具有长重复块时，最佳折叠会对齐远处的匹配区域而不是相邻的匹配区域。 

## 方法

 强力解释将考虑所有可能的折叠位置组。 有 n−1 个潜在的分割点，因此在最坏的情况下有 2^(n−1) 个配置。 对于每种配置，我们将模拟折叠后位置如何对齐，然后验证每个堆栈是否包含相同的位并计算结果高度。 这是指数级的并且完全不可行。 

我们需要进行结构观察：折叠有效地识别反射片段后对齐的位置。 我们可以不考虑折叠，而是将最终配置重新解释为围绕所选中心对称的配对位置。 每个折叠对应于反转和匹配片段，这意味着最终的可见长度取决于有多少个位置可以在镜像位置上一致配对。 

关键的见解是，有效的折叠将字符串划分为一个结构，其中折叠在一起的位置必须来自相同的字符，并且生成的形状的行为类似于重复合并对称等值段。 这将问题简化为跟踪相同的角色可以通过一系列合并相互“支持”多远。 

一种有用的查看方法是：如果所有中间结构都可以一致地折叠起来，则每个字符都可能与同一字符的另一个出现合并。 这导致了对相同字符及其邻接结构的运行的贪婪过程，其中我们重复压缩可以匹配的段。 

事实证明，最佳解决方案仅取决于角色如何形成最大交替结构边界。 我们可以从左到右处理字符串，维护一堆“有效块”，其中每个块代表其中所有有效折叠等效项之后的压缩段。 当一个新角色到达时，如果它可以在折叠对称约束下与顶部块合并，我们合并； 否则我们开始一个新的块。 

这将问题简化为计算在所有可能的有效对称取消之后剩余多少个不可约块。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 块合并模拟| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将折叠重新解释为重复合并可以对称对齐的相邻结构。 该算法在处理字符串的同时维护压缩段的堆栈。 

1. 初始化一个空堆栈，该堆栈将在所有可能的折叠缩减之后存储连续字符的压缩块。 
2. 从左到右迭代字符串。 对于每个字符，将其视为一个新的单字符块。 
3. 如果当前块代表折叠对称下的兼容结构，则尝试将当前块与堆栈顶部合并。 在此问题中，兼容性降低为压缩后字符相等，因为任何有效的堆栈对齐都需要重叠位置中的相同值。 
4. 如果可以合并，则合并块并继续检查下一个堆栈元素。 这模拟了可以同时应用多个折叠的事实，从而允许级联合并。 
5. 如果无法合并，则将当前块压入堆栈。 
6. 处理完所有字符后，堆栈中剩余的块数就是可实现的最小剥离长度。

为什么这种方法有效，是因为每个堆栈块代表一个最大区域，不能通过任何有效折叠进一步缩小。 如果两个相邻的块可以在任何折叠序列下合并，那么当它们以压缩形式相邻时，算法就已经将它们合并了。 因此，不再进行折叠可以减少块的数量，从而使堆栈大小达到最佳状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        stack = []

        for ch in s:
            if stack and stack[-1] == ch:
                continue
            stack.append(ch)

        print(len(stack))

if __name__ == "__main__":
    solve()
```该实现基于以下观察：折叠仅消除相同的相邻有效区域之间的冗余。 堆栈代表了条带的简化结构，我们只保留不同字符之间的过渡。 连续的相同字符对于创建新的折叠交互从来没有用，因为它们已经简单地对齐了。 

关键的实现细节是我们永远不需要显式模拟折叠或段反转。 最佳折叠的整体效果崩溃为消除有效表示中的连续重复项。

 ## 边缘情况

 像这样的单字符字符串`0`或者`1`已经完全压缩了。 该算法初始化一个空堆栈，压入第一个字符，并返回大小 1，这符合没有折叠可以减少单个单元格的事实。 

像这样的统一字符串`000000`行为类似。 每个字符都与堆栈顶部匹配并被忽略，留下一个块。 这表明，除了简单的身份之外，没有折叠会产生额外的合并机会。 

交替的字符串就像`010101`永远不会触发任何合并，因此堆栈会增长到完整大小。 这反映了在有效折叠约束下不能合并两个相邻的有效区域，从而保留最大长度。
