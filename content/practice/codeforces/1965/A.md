 ## 解决方案
 ## 问题理解

 我们有几个独立的游戏，每个游戏都由包含石子的堆列表定义。 两名玩家轮流进行。 移动包括选择一个整数$k$不超过最小的非空堆，然后同时减去$k$从每堆仍然非空的石头中取出石头。 任何堆到零的堆都会从游戏中消失。 

当所有牌堆都空了时游戏结束，无法移动的玩家就输了。 由于移动总是至少将最小的堆减少到零，因此活动堆的数量随着时间的推移严格减少，因此每场游戏最多结束$n$移动。 

任务是确定每个测试用例中第一个玩家是否在最佳玩法下强制获胜。 

约束允许最多$2 \cdot 10^5$所有测试用例的总桩数，因此任何解决方案在输入大小上都必须基本上是线性或线性算数的。 模拟每个动作的解决方案是不可能的，因为即使是单个游戏也可能有多达$10^5$桩，每次移动都会触及所有桩，从而导致二次行为。 

一种简单的方法是逐步模拟游戏。 对于每一轮，我们都会扫描所有桩，计算最小值，减去选定的桩$k$，并删除零。 这在约束下立即失败。 

另一种常见的失败情况是假设所有棋子的总和或总棋子的奇偶性决定获胜者。 例如，类似的配置$[1,7]$具有相同的总奇偶性$[2,6]$，但游戏结果有所不同，因为最小驱动移除的结构改变了强制移动的数量。 

## 方法

 蛮力的想法很简单：重复计算最小非空堆，选择一个合法的$k$，并模拟最优选择下的双方玩家。 即使我们尝试通过总是选择“明显”的举动来优化，例如$k = \min$，我们仍然面临一个分支博弈树，因为不同的值$k$可能会导致不同的堆消除。 这通常会导致状态数量呈指数级增长。 

关键的结构观察是最小值完全控制着动作的合法性。 如果当前最小值为$m$，然后选择任意一个$k < m$只需将所有桩向下移动$k$无需移除任何桩。 这永远不会改变堆大小的相对顺序，只会延迟终止。 当理性的玩家可以立即消除最小层时，他们永远不会喜欢延迟强制减少。 

所以最佳游戏总是使用$k = m$，当前最小值。 该举动会删除所有等于最小值的桩，并将其余桩减少恰好该值。 此后，下一个状态仅取决于下一个不同的堆值，而不取决于单个堆的重数是否相等。 

这将游戏变成了一个关于不同值序列的过程。 每一步都会删除一个对应于不同高度的“层”。 唯一保留下来的信息是存在多少个不同的级别。 

这将整个游戏简化为平价问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| 指数| O(n) | 太慢了 |
 | 排序 + 不同计数 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们将每个测试用例缩减为其一组不同的堆大小。 

1. 读取桩尺寸数组。 
2. 对数组进行排序，使相等的值变得相邻，从而轻松识别不同的值。 
3. 计算存在多少个不同的值。 
4. 如果计数为奇数，则宣布 Alice 为获胜者，否则宣布 Bob 为获胜者。 

我们只计算不同值的原因是每一步都会从游戏中删除一个不同的值级别。 每个值的内部多重性并不影响存在多少个决策“层”，只影响每一步有多少堆消失。 

### 为什么它有效

 游戏通过反复从所有活动堆中删除当前最小值来演变。 此操作每次移动都会消除至少一个不同值，并且不会创建新的不同值。 因此，该游戏相当于对不同桩高度列表的简单交替过程。 每一步都对应消耗一个等级。 消耗最后一关的玩家获胜，因此结果仅取决于关卡数是奇数还是偶数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        
        distinct = 1
        for i in range(1, n):
            if a[i] != a[i - 1]:
                distinct += 1
        
        if distinct % 2 == 1:
            out.append("Alice")
        else:
            out.append("Bob")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码依赖于排序将相等的堆大小分组在一起。 排序后，单个线性扫描会对值之间的转换进行计数。 每个过渡对应于游戏中一个新的独特“层”。 

最后的奇偶校验直接反映了棋步的交替结构：每一步棋都会删除一个不同的最低级别，因此此类级别的数量决定了谁会做出最后的棋步。

 我们追踪两个代表性案例的逻辑。 

### 示例 1：`3 3 3 3 3`排序后，数组仍然存在`[3]`在不同的价值观方面。 

| 步骤| 数组 | 不同计数|
 | ---| ---| ---|
 | 初始| [3,3,3,3,3] | 1 |

 计数为奇数，因此爱丽丝获胜。 

这符合直觉，因为爱丽丝可以通过选择一步移动所有石头$k=3$。 

### 示例 2：`1 7`| 步骤| 数组 | 不同计数|
 | ---| ---| ---|
 | 初始| [1,7]| 2 |

 计数是偶数，所以鲍勃获胜。 

Alice 移除第一层后（$k=1$），游戏会折叠成一堆尺寸为 6 的棋子，给鲍勃一个直接获胜的棋步。 

这表明第一步仅暴露了剩余的层数，当该数字为偶数时第二个玩家受益。

 ## 边缘情况

 最重要的边缘情况是所有桩都相同。 在这种情况下，只有一个不同的值，因此第一个玩家通过一次移动消除所有内容立即获胜。 该算法捕获了这一点，因为不同的计数器等于 1，从而使 Alice 成为获胜者。 

另一个微妙的情况是当堆形成完美交错的序列时，例如$[1,2,3,4]$。 尽管这些值是分散的，但每个值仍然只贡献一个不同的级别，因此结果仅取决于四个值的奇偶性，从而导致第二个玩家获胜。 

最后，具有重复值的情况与其他情况交错，例如$[1,100,2,99]$，不影响正确性。 排序会正确折叠重复项，并且只有转换才重要，因此算法正确地计算了四个不同的值并返回 Alice 的失败位置。
