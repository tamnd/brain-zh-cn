 ## 解决方案
 ## 问题理解

 我们得到一个数字网格$n$行和$m$列。 从每一行中，我们可以选择一些元素，但有严格的上限：在任何单行中，我们不能选择超过一半的元素，向下舍入。 在每行独立做出这些选择后，我们将所有选定的值相加。 在所有有效选择中，我们希望能被整除的最大可能总和$k$。 

所以结构是：每一行都是一个小型的“选择机器”，它产生一组可能的和，但前提是我们尊重每行对我们采用的元素数量的限制。 然后我们合并行，最后我们只关心总和模$k$，具体来说我们想要余数为零和最大值。 

约束以非常具体的方式严格：$n, m, k \le 70$并且值很小（最多 70）。 这立即排除了对整个矩阵的所有子集的指数暴力，因为这将涉及选择最多$70 \cdot 70 = 4900$元素，这是完全不可行的。 即使每行的暴力破解也是指数级的$m$，并且每行独立地这样做仍然会乘以太大的东西。 

约束的一个关键含义是每行结构和模数都很小。 这是行动态规划的经典信号，与模状态上的背包式 DP 相结合。 

一些容易出错的边缘情况：

 如果所有数字都很小并且不选择任何内容对于整除性都是最佳的，则答案可能为零。 例如，如果每个数字都有余数 1 mod k，并且选择任何数字都会破坏整除性，则正确答案为 0。 

如果一行只允许选取一个元素（当$m = 1$），那么每一行贡献 0 或该单个元素，并且解决方案简化为跨行的模块化子集选择。 

如果所有值都非常大但结构合理，因此选取许多元素会破坏“每行最多一半”约束，则独立选取每行最佳元素的天真的贪婪方法会失败，因为行间的模交互很重要。 

## 方法

 如果我们忽略约束，最直接的想法是独立考虑每一行并枚举该行的所有子集，这些子集尊重“最多选择”$m/2$“规则。对于每个子集，我们计算其总和，然后尝试组合所有行选择。这是正确的，因为它探索了每个有效的配置。

 然而，每一行都有$2^m$子集，并且与$m = 70$，这是一个天文数字。 即使按子集大小进行修剪也只会减少常数，而不是指数性质。 真正的问题不仅是每行爆炸，还包括组合行：处理一行后，我们需要将结果合并到总和和余数上的全局 DP 中，如果我们扩展完整子集枚举，这将变得不可行。 

关键的观察是行之间的唯一交互是通过总和模$k$。 在一行中，唯一的约束是我们选择了多少个元素。 这表明我们可以将每一行压缩为一个小的 DP 状态：对于所选元素的每个可能计数，最多可达$m/2$，我们跟踪所有可达到的模数$k$，我们只关心每个余数的最佳总和。 

这会将每一行转换为有界背包变体，然后我们将行与另一个 DP 的余数组合起来。 

因此，解决方案变成了一个两层 DP：首先处理每一行以计算其最佳贡献曲线，然后将行合并到全局余数 DP 中。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 |$O(n \cdot 2^m)$|$O(2^m)$| 太慢了 |
 | 行 DP + 全局模 DP |$O(n \cdot m^2 \cdot k)$|$O(k)$| 已接受 |

 ## 算法演练

 我们分两个阶段构建解决方案。 

首先，对于每一行，我们计算如果允许我们最多选择的话，可能的总和是多少$\lfloor m/2 \rfloor$该行中的元素。 我们不关心确切的子集，只关心按其值模分类的可实现总和$k$。 

我们对一行使用 DP 数组：`dp[c][r]`意味着通过精确挑选可以获得的最大金额`c`该行中的元素与求和模$k$等于`r`。 我们将所有状态初始化为不可能状态，除了`dp[0][0] = 0`。 

对于行中的每个元素，我们以相反的顺序更新此 DP`c`所以我们不会多次重用元素。 

处理一行后，我们将其压缩为单个数组`best[r]`，它存储该行可达到的最大总和以及余数`r`，尊重我们最多选择一半行的约束。 

然后我们将行逐一合并到全局 DP 中：`global[r]`存储迄今为止可实现的最大总和及其余数`r`。 

每一行就像一个“选项袋”，我们从它的选项中选择一个贡献`best`大批。 

步骤：

 1. 初始化`global`DP 与`global[0] = 0`和所有其他值都是不可能的。 
2. 对于每一行，构建一个`best`使用有界背包对元素计数进行模值数组。 
3.对于每一行，创建一个新的DP`next_global`初始化为不可能。 
4. 对于之前的每一个余数`r1`以及每行余数`r2`，更新：

 新余数$r = (r1 + r2) \mod k$新的总和是`global[r1] + best[r2]`。 
5. 更换`global`和`next_global`。 
6.答案是`global[0]`。 

这样做的原因是每一行都通过其对每个模类的最佳可实现贡献进行了全面总结。 一旦压缩，行就成为独立的选择块，并且全局 DP 正确地考虑了行选择的所有组合。 

不变量是在处理完第一个之后$i$行，`global[r]`仅使用总和等于的那些行来存储可实现的最大总和$r \mod k$。 该转换保留了正确性，因为我们枚举了下一行的所有有效贡献并将它们与所有先前的有效状态组合起来。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    limit = m // 2

    global_dp = [-10**18] * k
    global_dp[0] = 0

    for _ in range(n):
        row = list(map(int, input().split()))

        dp = [[-10**18] * k for _ in range(limit + 1)]
        dp[0][0] = 0

        for val in row:
            for c in range(limit - 1, -1, -1):
                for r in range(k):
                    if dp[c][r] < 0:
                        continue
                    nc = c + 1
                    nr = (r + val) % k
                    dp[nc][nr] = max(dp[nc][nr], dp[c][r] + val)

        best = [-10**18] * k
        for c in range(limit + 1):
            for r in range(k):
                best[r] = max(best[r], dp[c][r])

        new_global = [-10**18] * k
        for r1 in range(k):
            if global_dp[r1] < 0:
                continue
            for r2 in range(k):
                if best[r2] < 0:
                    continue
                nr = (r1 + r2) % k
                new_global[nr] = max(new_global[nr], global_dp[r1] + best[r2])

        global_dp = new_global

    print(global_dp[0])

if __name__ == "__main__":
    solve()
```第一个 DP 层是一个有界背包，“我们连续选取多少个元素”。 反向迭代结束`c`确保每个元素在每个行状态最多使用一次。 

第二层是跨行的标准模数背包。 小心的部分是用大负数初始化不可能的状态，以便无效的组合不会污染转换。 

## 工作示例

 ### 示例 1

 输入：```
1 4 3
1 2 3 4
```这里我们有一行，我们最多可以选择 2 个元素。 

我们计算行 DP：

 | c | 余数 0 | 余数 1 | 余数 2 |
 | ---| ---| ---| ---|
 | 0 | 0 | -inf| -inf|
 | 1 | -inf| 1 | 2 |
 | 2 | 4 | 5 | 6 |

 从这些状态中，我们取最好的余数，因此：

 最佳[0] = 4，最佳[1] = 5，最佳[2] = 6。 

然后我们选择最佳余数 0，即 4。 

这显示了行压缩如何捕获约束下的所有有效子集并直接产生最佳可行答案。 

### 示例 2

 输入：```
2 3 3
1 2 3
2 2 2
```每行最多允许 1 个选择。 

第 1 行最佳：

 不选任何内容给出 0 mod 3

 选择 1,2,3 给出值 1,2,3

 第 2 行最佳：

 0,2

 全局 DP 开头为 [0, -inf, -inf]。 

第 1 行之后：

 全局 = [3, 1, 2]

 第 2 行之后：

 我们将每个状态与 {0,2} 结合起来：

 余数 0 的最终最佳值变为 5 (3 + 2)

 此跟踪显示了跨行的模组合如何累积，同时保留每行的约束。

 ## 边缘情况

 一个微妙的情况是，什么都不选择是实现可分性的唯一方法。 例如，如果所有数字都使得任何选择都会产生余数不匹配，则算法仍会保留`global_dp[0] = 0`全程有效。 由于所有转换都需要改进总和，负初始化状态可防止无效组合覆盖它。 

另一种情况是，在半选择约束下，一行不能贡献任何有用的东西。 在这种情况下，`best`数组大部分仍为负，除了`best[0] = 0`，这意味着该行实际上没有贡献任何内容。 全局 DP 保持不变，这是正确的行为，因为通过选择零个元素始终允许跳过行。 

最后一个极端情况是$k = 1$。 每个总和都可以自动除以$k$，DP 退化为在每行约束下最大化总和。 该算法正确地分解为选择每行允许的最佳子集并对它们求和，因为所有余数都映射为零。
