 ## 解决方案
 ## 问题理解

 我们得到一个表示为二进制数组的书架。 值为`1`表示该位置有一本书，而`0`表示该位置为空。 

移动允许我们取出一整块连续的书，并将该块向左或向右移动一个位置到相邻的空白空间中。 目标是使所有书籍占据一个连续的段，并且它们之间没有空位。 

关键的观察结果是，书籍永远不需要移动到最左边和最右边现有书籍之间的区域之外。 该范围之外的空位置并不重要，因为间隙仅在分隔书籍时才重要。 

限制非常小。 测试用例最多有200个，每个书架的长度最多为50。$O(n^2)$解决方案很容易足够快。 这意味着挑战不是性能，而是认识到潜在的简化。 

有几种边缘情况很容易被误解。 

考虑：```
1 0 0 0 1
```答案是`3`， 不是`1`。 两本书之间有三个空位，每个空位最终都必须从它们之间消失。 

考虑：```
1 1 0 0 1
```答案是`2`。 

一个常见的错误是计算零组而不是单个零。 这里有一个间隙，但其中包含两个空位，因此需要两步。 

考虑：```
0 0 1 1 1 0 0
```答案是`0`。 

两边都有零，但书与书之间没有零。 粗心的实现会错误地计算全零`4`。 

考虑：```
1
```答案是`0`。 

一本书已经是一个连续的片段。 

## 方法

 思考问题的一种强力方法是模拟运动。 我们可以反复选择片段并移动它们，直到所有书籍变得连续。 由于可能有许多不同的移动顺序，因此完整的搜索必须探索书架的许多状态。 

虽然$n \le 50$，这样的状态空间方法是不必要的。 可能的书架配置数量呈指数级增长，使其成为一个没有吸引力的解决方案。 

突破来自于观察一个举动实际实现了什么。 

假设两本书之间有一个零：```
1 0 1
```为了消除这一间隙，其中一个书籍组必须移过该空位置。 无论哪一方移动，都需要移动一个零来实现这一点。 

现在考虑：```
1 0 0 1
```书之间有两个空位置。 一招最多可以消除内线这些位置中的一个。 最终两个零都必须消失，所以答案是`2`。 

这种模式具有普遍性。 唯一重要的位置是最左边的书和最右边的书之间的位置。 该区间内的每个零都代表一个不可避免的工作单元，并且每个这样的零都可以通过一次移动来消除。 

因此，最小移动次数就是第一个移动之间的零的数量。`1`和最后一个`1`。

 ## 算法演练

 1. 找到第一本书的位置，即第一次出现的位置`1`。 
2.找到最后一本书的位置，意思是最后出现的`1`。 
3. 检查这两个指数之间的每个位置（包括这两个指数）。 
4. 计算有多少个位置包含`0`。 
5. 输出计数。 

步骤 4 起作用的原因是每个内部零代表一个分隔书籍的间隙。 每个这样的间隙位置最终都必须通过在其上移动书籍来填补，并且一次移动可以恰好消除一个内部零。 

### 为什么它有效

 让第一本书处于位置`L`最后一本书位于位置`R`。 

区间外的任何书籍`[L, R]`根据定义不存在。 使所有书籍连续，里面的每个位置`[L, R]`目前包含`0`最终必须包含一本书。 

每次移动都会将连续的块移动一个位置，并可以减少内部空位置的数量`[L, R]`至多一个。 因此至少需要与内部零一样多的移动。 

相反，对于每个内部零，我们可以将相邻的块移向它并一次填充它。 重复这个过程可以使用同样多的移动消除所有内部零。 

由于下界和上限相同，因此最小移动次数等于第一本书和最后一本书之间的零数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        left = a.index(1)
        right = n - 1 - a[::-1].index(1)

        ans = 0
        for i in range(left, right + 1):
            if a[i] == 0:
                ans += 1

        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先找到最左边和最右边的书。 这些位置定义了唯一重要的间隔。 

然后循环计算该间隔内的零。 区间外的零将被忽略，因为它们不分隔任何书。 

一个微妙的细节是计算最后一次出现的`1`。 Python没有提供内置的反向索引操作，因此代码反转数组并找到第一个`1`那里。 将该位置转换回原始索引即可给出最右侧书籍的位置。 

另一个细节是扫描包括两个端点。 由于这些端点保证包含书籍，因此包含它们不会影响计数并避免差一错误。

 ## 边缘情况

 考虑：```
1
5
1 0 0 0 1
```第一本书位于索引 0 处，最后一本书位于索引 4 处。该区间内有三个零。 该算法计算所有三个并返回`3`。 计算间隙段而不是间隙单元的解决方案将错误地返回`1`。 

考虑：```
1
7
0 0 1 1 1 0 0
```第一本书位于索引 2 处，最后一本书位于索引 4 处。该算法仅检查位置 2 到 4，并且找不到零。 答案是`0`。 这正确地忽略了账簿范围之外的空头寸。 

考虑：```
1
3
1 0 0
```第一本书和最后一本书位置相同。 该区间仅包含一个单元格，即一本书。 零的个数是`0`，所以答案是`0`。 一本书已经形成了一个连续的片段。 

考虑：```
1
5
1 1 0 0 1
```相关区间是整个数组。 最外面的书之间出现两个零，因此算法返回`2`。 这与消除两个间隙所需的最少移动次数相匹配。
