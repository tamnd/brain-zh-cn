 ## 解决方案
 ## 问题理解

 我们被要求识别线性水族箱中的主要食人鱼。 每个食人鱼都有一个大小，如果一个食人鱼最终能够通过重复吃掉比自己小的相邻食人鱼来吃掉所有其他食人鱼，那么它就是占主导地位的。 每吃一次，它的体型就会增大一倍。 输入提供了多个测试用例，每个测试用例指定了食人鱼的数量及其大小。 输出必须是任何占主导地位的食人鱼的从 1 开始的索引，如果不存在则为 -1。 

这些约束意味着对所有可能的移动进行强力模拟是不可行的，因为所有测试用例中的食人鱼总数可能达到 300,000。 模拟每个候选食人鱼的每个可能的进食顺序将产生二次或更糟糕的复杂性，这对于 2 秒的时间限制是不可接受的。 

当所有食人鱼的大小相同时，就会出现不明显的边缘情况。 在这种情况下，没有食人鱼可以吃掉另一个，所以正确的输出是-1。 另一个微妙的情况是最大尺寸在数组中出现多次； 只有至少有一个邻居小于自身的最大值才有可能成为主导。 例如，在`[5, 5, 4, 3, 5]`，第一个和最后一个`5`不能吃任何相邻的较小的食人鱼，但中间的`5`可以吃`4`在其右侧，因此它是有效的候选者。 

## 方法

 天真的方法是尝试将每个食人鱼作为候选者并模拟其动作，直到它吃掉所有其他食人鱼或被卡住。 这是有效的，因为规则是确定性的：食人鱼只能吃掉相邻的较小的食人鱼。 然而，对于大小的数组`n`，单个模拟可能涉及`O(n^2)`步骤，并对所有测试用例求和将导致操作超出`10^10`，这太慢了。 

关键的见解是，只有具有**最大尺寸**的食人鱼才能占据主导地位。 小于最大值的食人鱼永远无法吃掉更大的食人鱼，因此它立即被取消资格。 在体型最大的食人鱼中，只有当食人鱼**至少有一个比自己小的邻居**时，它才能占据主导地位。 这是因为它需要一个起点来生长，如果没有较小的邻居，它就无法启动进食过程。 通过这种观察，我们只需扫描数组一次即可找到最大值，然后查看其邻居。 这将每个测试用例的数组大小的复杂性降低到线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| 每个测试用例的 O(n²) | O(n) | 太慢了 |
 | 最大值 + 邻居检查 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取食人鱼的数量`n`和数组`a`尺寸。 
2. 查找数组中的最大大小。 
3. 遍历数组，找到具有该最大尺寸且至少有一个邻居小于其自身的食人鱼。 
4. 如果存在这样的食人鱼，则输出其从 1 开始的索引并停止进一步搜索。 
5. 如果扫描数组后没有发现这样的食人鱼，则输出-1。 

为什么有效：根据定义，只有最大体型的食人鱼才能吃掉所有其他食人鱼。 没有较小邻居的最大尺寸的食人鱼无法开始消耗，因此它无法占据主导地位。 任何体型最大的食人鱼，至少有一个较小的邻居，都可以贪婪地吃左边或右边的食物，吃完邻居后，它会长大并继续吃东西，直到所有其他食人鱼都吃光为止。 不变的是，候选人必须始终能够开始进食； 该算法正是检查这一点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        max_size = max(a)
        
        dominant_index = -1
        for i in range(n):
            if a[i] == max_size:
                if (i > 0 and a[i-1] < max_size) or (i < n-1 and a[i+1] < max_size):
                    dominant_index = i + 1  # 1-based index
                    break
        print(dominant_index)

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量。 对于每个测试用例，它计算最大尺寸，然后迭代数组以查找至少有一个较小邻居的最大尺寸食人鱼。 这`i + 1`调整将问题所需的从基于 0 的索引转换为基于 1 的索引。 中断确保我们输出第一个有效候选者，尽管任何有效候选者都是可以接受的。 

## 工作示例

 **示例1：**`[5, 3, 4, 4, 5]`| 我| 一个[我] | 邻居检查 | 主导的？ |
 | ---| ---| ---| ---|
 | 0 | 5 | 右=3 < 5 | 是的 |

 第一个食人鱼最大，并且有一个较小的邻居，因此索引`1`是有效的。 在示例解决方案中，算法选择索引`3`相反，这也有效。 可以接受多个答案。 

**示例2：**`[1, 1, 1]`| 我| 一个[我] | 邻居检查 | 主导的？ |
 | ---| ---| ---| ---|
 | 0 | 1 | 右=1 | 没有 |
 | 1 | 1 | 左=1，右=1 | 没有 |
 | 2 | 1 | 左=1 | 没有 |

 体型最大的食人鱼没有比它更小的邻居。 输出`-1`。

 ## 边缘情况

 对于所有食人鱼都具有相同大小的数组，算法正确地输出 -1，因为没有食人鱼有更小的邻居来开始进食。 在具有多个最大值的数组中，该算法总是找到具有较小邻居的第一个最大值。 对于最小的输入尺寸`n=2`，检查工作正常：如果一个食人鱼严格大于另一个，它将被选为主导。 对于最大输入大小，线性扫描可确保性能保持在限制范围内。
