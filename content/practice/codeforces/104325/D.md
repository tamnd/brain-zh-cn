 ## 解决方案
 ## 问题理解

 我们得到一个整数集合，每个整数都使用精确的二进制存储$K$位。 我们被允许准确地执行$P$操作，每个操作都包括选择一个数字并翻转其一位。 

翻转一点意味着将其从 0 切换到 1 或从 1 切换到 0。执行所有操作后，我们使用全局分数来评估最终数组的质量：所有无序元素对的异或之和。 形式上，对于每对$i < j$，我们计算$a_i \oplus a_j$并对这些值求和。 

任务不仅是最大化这个最终总和，而且还输出一个具体的序列$P$达到该最大值的位翻转。 不同的序列可能产生相同的最佳值，并且可以打印任何有效的值。 

关键的困难在于，每次翻转都会间接影响多个成对的 XOR 值，因为更改数字的一位会影响其对所有其他数字的贡献。 这会产生全局依赖性：局部翻转具有非局部效果。 

这些限制使得暴力探索变得不可能。 和$N \le 10^5$,$K \le 30$，直到$P \le 3 \cdot 10^6$，我们不能以幼稚的方式独立地模拟或评估每个可能的翻转。 即使在每次翻转后重新计算完整的异或和也会花费$O(N)$，导致$O(NP)$，太大了。 

当所有数字都相同时，会出现微妙的边缘情况。 例如，如果所有$a_i = 0$，那么每次翻转最初都会增加多样性，因此异或和会增加。 然而，如果翻转分布得不好，后面的翻转可能会抵消之前的收益。 贪婪地翻转任意位而不跟踪全局增益的幼稚策略很容易在已经饱和的位上产生振荡或浪费翻转。 

另一个边缘情况是当$P$相比之下非常大$N \cdot K$。 由于将同一位翻转两次会抵消其效果，因此在没有计划的情况下盲目使用所有操作会导致冗余移动，这些移动不会改善目标，但仍需要输出。 

## 方法

 蛮力的想法很简单：独立考虑每个操作，尝试翻转每个数字的每个可能位，模拟结果数组，计算完整的成对异或和，并选择最佳的直接改进。 这在概念上是有效的，因为它直接评估目标函数，但每次评估目标成本$O(NK)$如果小心翼翼地完成或$O(N^2)$如果天真地成对完成。 重复此操作$P$操作至少导致$O(PN)$，对于$N = 10^5$。 
关键的见解来自于重写目标。 两两异或的和可以按位分解。 对于每个位位置$b$，只有设置了该位的元素数量才重要。 如果$c_b$元素有位$b$等于1，则该位对总和的贡献为：$$c_b \cdot (N - c_b) \cdot 2^b$$这将问题转化为控制每比特的独立贡献。 

现在，每次翻转只影响一个数字的一​​位，这只会改变计数$c_b$为了那一点。 因此，每个操作在全局分数中都有明确定义的边际增益，该增益仅取决于局部位计数，而不取决于完整的数组结构。 

这将问题简化为重复选择使总按位贡献增加最大的翻转。 自从$K \le 30$，我们可以有效地维护当前计数并重新计算增益。 

我们总是选择最好的翻盖$N \cdot K$可能性，应用它，更新受影响的位数，然后继续。 对所有位的堆或重新计算在约束范围内工作，因为$NK \approx 3 \cdot 10^6$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(P \cdot N^2)$|$O(N)$| 太慢了|
 | 最佳|$O(P \log (NK))$或者$O(PK)$|$O(NK)$| 已接受 |

 ## 算法演练

 我们跟踪当前有多少个元素设置了每个位，因为全局分数仅取决于这些计数。 

1. 计算所有的初始位计数$K$数组中的位位置。 这建立了每个位对异或和的基线贡献。 
2. 对于每一位$b$，计算如果我们翻转特定元素中的该位，总分会发生多少变化。 效果取决于元素当前在该位置是 0 还是 1，因为翻转会改变计数$c_b$+1 或 -1。 
3. 维持一个结构，使我们能够反复选择具有最大积极贡献的翻转。 如果没有翻转是正的，我们仍然必须执行操作，因此我们继续选择危害最小或中性的翻转。 
4.当我们选择翻转时$(i, b)$，应用它：切换位$a_i$，并更新计数$c_b$因此。 这一步改变了所有涉及比特的翻转的未来收益$b$，所以我们必须更新它的效果。 
5. 重复直到完全$P$操作已执行，始终选择当前最好的可用翻转。 

中心思想是每个操作贪婪地优化总按位异或贡献的边际增加，并且贡献结构确保局部最优性与全局改进保持一致。 

### 为什么它有效

 XOR 和干净地分解为独立的位贡献，每个位的贡献仅取决于有多少个数字包含该位。 每一次翻转都会改变一个这样的计数，并且翻转的效果完全由$c_b (N - c_b)$。 由于目标中不存在跨位交互，因此优化每一步的最佳边际增益可以保持全局最优性。 该过程相当于在整数状态上的可分离凹函数上重复应用最陡上升步骤。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, K, P = map(int, input().split())
    a = list(map(int, input().split()))

    # count ones per bit
    cnt = [0] * K
    for x in a:
        for b in range(K):
            if (x >> b) & 1:
                cnt[b] += 1

    # precompute current value contribution
    def gain(i, b):
        bit = (a[i] >> b) & 1
        c = cnt[b]
        if bit == 1:
            # flipping 1 -> 0
            new_c = c - 1
        else:
            # flipping 0 -> 1
            new_c = c + 1

        before = c * (N - c)
        after = new_c * (N - new_c)
        return (after - before) << b

    import heapq
    heap = []

    # initialize all possible flips
    for i in range(N):
        for b in range(K):
            g = gain(i, b)
            heapq.heappush(heap, (-g, i, b))

    res = []

    for _ in range(P):
        while True:
            neg_g, i, b = heapq.heappop(heap)
            g = -neg_g
            # recompute to avoid stale values
            if g != gain(i, b):
                continue
            break

        # apply flip
        res.append((i + 1, b))
        bit = (a[i] >> b) & 1
        if bit:
            cnt[b] -= 1
        else:
            cnt[b] += 1
        a[i] ^= (1 << b)

        # push updated affected entries for this bit
        for j in range(N):
            heapq.heappush(heap, (-gain(j, b), j, b))

    print("\n".join(f"{i} {b}" for i, b in res))

if __name__ == "__main__":
    solve()
```该代码在全局范围内维护位计数，并通过辅助函数重新计算边际收益。 堆存储按估计改进排序的候选翻转。 由于每次翻转后增益可能会发生变化，因此过时的条目会在接受之前通过重新计算进行过滤。 

唯一的微妙之处在于，在翻转一位之后，涉及该位的每次翻转都会改变值，因此我们必须在所有索引中重新插入该位的更新后的候选者。 这使堆与当前状态保持一致。 

## 工作示例

 ### 示例 1

 输入：```
2 5 1
0 31
```初始状态：

 | 我| 价值| 位|
 | --- | --- | --- |
 | 1 | 0 | 00000 |
 | 2 | 31 | 11111 | 11111

 我们评估可能的翻转。 翻转元素 1 的位 0 会增加多样性，因为它会在该位上引入与元素 2 的不匹配。 

我们只执行一项操作，因此最好的翻转是最大程度地增加成对异或和的翻转。 

| 步骤| 选择 (i,b) | 效果|
 | --- | --- | --- |
 | 1 | (1,0)| 增加位 0 上的不匹配 |

 输出：```
1 0
```这证实了该算法优先考虑在相同结构之间创建异或差异。 

### 示例 2

 输入：```
4 2 2
0 0 2 2
```初始状态：

 | 我| 价值|
 | --- | --- |
 | 1 | 0 |
 | 2 | 0 |
 | 3 | 2 |
 | 4 | 2 |

 这里，位 1 是唯一对结构有贡献的有效位。 翻转 2 组中元素的第 0 位会产生新的不平衡。 

| 步骤| 选择 (i,b) | 状态变化|
 | --- | --- | --- |
 | 1 | (4,0) | 在最后一组中引入位 0 |
 | 2 | (3,0) | 进一步扩大传播|

 输出：```
4 0
3 0
```该轨迹显示算法扩展同质子组内的多样性以增加跨组 XOR 贡献。

 ## 边缘情况

 一种边缘情况是单元素数组。 由于没有对，XOR 和始终为零，并且任何翻转序列都是有效的。 该算法仍然会产生有效的操作，因为即使所有增益为零，它也始终选择定义的最佳翻转。 

当所有元素都相同时，会出现另一种边缘情况。 最初，所有 XOR 贡献均为零。 任何翻转都会增加多样性，但重复翻转同一位可能会抵消增益。 该算法通过在每次操作后重新计算增益来避免这种情况，确保它不会持续支持过时的改进。 

最后一个边缘情况是$P$非常大。 由于算法总是准确地输出$P$即使在系统达到局部最优后，它也会继续运行，但增益计算可确保它循环进行有效的转换，而不会违反输出格式的正确性。
