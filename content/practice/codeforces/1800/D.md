 ## 解决方案
 ## 问题理解

 给定一个由小写拉丁字母组成的字符串，任务是计算通过删除任意两个连续字符可以形成多少个不同的字符串。 每个测试用例由长度至少为三的字符串组成。 输出只是通过删除每对可能的连续字母一次而产生的唯一字符串的数量。 

输入大小可以很大：最多$2 \cdot 10^5$所有测试用例中的字符。 这意味着尝试使用嵌套循环或重复字符串连接显式构造和比较所有可能的结果字符串的任何方法都可能太慢，因为每个字符串操作在字符串长度上可能是线性的。 首选解决方案是单次扫描字符串或每次操作使用恒定时间散列。 

一些边缘情况可能会导致粗心的解决方案陷入困境。 一种情况是所有字母都相同的字符串，例如“aaaa”。 删除的任何两个连续字母都会产生相同的字符串“aa”，因此答案必须是 1，而不是删除的次数。 另一种情况是字母交替出现，例如“ababab”。 某些删除会产生相同的字符串，因为删除重叠位置的字母会产生相同的结果。 解决方案必须避免重复计算出现多次的字符串。 

## 方法

 蛮力方法很简单：对于每个位置$i$在字符串中（最后一个除外），删除位置处的字符$i$和$i+1$并将结果字符串存储在一个集合中。 最后，集合的大小给出了不同字符串的数量。 这种方法是正确的，因为它枚举了所有可能的删除。 但是，如果字符串长度$n$取决于$2 \cdot 10^5$, 表演$O(n)$每个删除结果的字符串连接$O(n^2)$总时间，对于最大的输入来说太慢了。 

更快解决方案的关键见解是字符串可以由一对子字符串表示：删除的子字符串对之前的前缀和之后的后缀。 可以使用字符串切片来模拟删除字符并连接这些子字符串，但切片仍然有成本$O(n)$如果我们存储每个结果字符串，则每次操作。 为了将其整体降低为线性，我们可以使用结果字符串的一组哈希值。 Python 的不可变字符串和内置的集合哈希让我们将切片存储为唯一的对象。 我们不需要超出唯一性的完整字符串比较，因此存储切片元组或使用散列就足够且高效了。 通过迭代字符串一次，删除每个索引处的对，并将生成的子字符串插入到集合中，我们实现$O(n)$每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 对于 n ~ 10^5 来说太慢 |
 | 散列/切片集| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$和字符串$s$。 
2. 初始化一个空集合来保存删除两个连续字母得到的所有唯一字符串。 
3. 循环所有有效的起始索引$i$要删除的对数，从 0 到$n-2$。 在每次迭代时，通过连接该对之前的子字符串和该对之后的子字符串来构造结果字符串，即$s[:i] + s[i+2:]$。 
4. 将生成的字符串插入到集合中。 Python 的 set 会自动丢弃重复项，因此我们不需要手动检查是否相等。 
5. 循环之后，集合的大小就是不同字符串的数量。 打印这个号码。 
6. 对所有测试用例重复该过程。 

工作原理：该集合确保每个唯一的结果字符串都被计数一次。 通过迭代每个有效的删除，我们保证不会跳过任何可能的删除。 使用字符串切片可以保留正确的字符串内容，而不会重叠或丢失字符。 该方法保持了一个不变量，即该集合恰好包含通过删除当前迭代之前的两个连续字母而获得的所有字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    seen = set()
    for i in range(n - 1):
        new_s = s[:i] + s[i+2:]
        seen.add(new_s)
    print(len(seen))
```该解决方案首先读取测试用例的数量并对其进行迭代。 每个字符串都会被读取并去除换行符。 套装`seen`跟踪独特的结果。 该循环通过使用切片删除连续字符来生成每个可能的字符串，这在 Python 中非常高效，因为它避免了手动逐字符连接。 最后，为每个测试用例打印唯一结果的数量。 微妙之处在于使用`n-1`作为循环边界； 忘记这一点可能会尝试删除从最后一个字符开始的一对并引发错误。

 ## 边缘情况

 对于像“aaaa”这样的重复字母字符串，循环在每次删除时都会生成相同的字符串：删除前两个、中间两个或最后两个都会生成“aa”。 该集合正确地进行重复数据删除，并且算法打印 1。对于像“aaa”这样的短字符串，删除任意两个连续字母会生成单个字符串，算法会正确返回 1。具有交替字母的字符串（例如“ababab”）在删除对时会生成重叠结果，例如，删除位置 0-1 会生成“abab”，删除 1-2 也会生成“abab”。 该集合确保唯一
