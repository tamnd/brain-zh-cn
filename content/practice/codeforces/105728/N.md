 ## 解决方案
 ## 问题理解

 我们得到了二维平面上的一组点。 任务是计算一个圆上有多少个由四个点组成的不同组，这意味着存在某个圆，其边界穿过所有四个选定点。 

输入只是一个坐标列表。 输出是一个数字：使这四个点同循环的索引四元组的数量。 

限制很小，最多300分。 如果仔细实施，这会立即排除比大约立方时间更糟糕的情况。 所有四元组的 O(n^4) 枚举意味着在最坏的情况下检查大约 80 亿个组合，即使在优化的 C++ 中也已经处于边缘，而在 Python 中则太大了。 即使 O(n^3) 方法也需要注意，但如果每个步骤都是常数或对数，则可以接受。 

一些边缘情况对于正确性很重要。 

如果所有点都位于一个圆上，则四个点的每个组合都是有效的。 例如，如果 n = 5 并且所有点都在同一个圆上，则答案为 C(5, 4) = 5。仅检查随机三元组或假设圆很少见的简单方法会错过这种极端的聚类情况。 

如果没有四个点是同循环的，例如放置在一般位置且没有偶然的圆形结构的点，则答案必须为零。 任何依赖计算半径的浮点相等的方法都不得由于精度噪声而产生虚假匹配。 

另一个微妙的情况是多个不同的三元组定义同一个圆。 独立计算每个四元组而不按圆圈分组的方法会严重过度计数。 

## 方法

 一个直接的想法是枚举每组四个点并检查它们是否位于一个公共圆上。 给定四个点，可以使用行列式条件或基于角度的检查来测试同循环性，但对所有四元组执行此操作会导致 O(n^4)，即使对于 n = 300，这也太慢了。 

我们需要利用结构：一个圆是由任意三个不共线的点唯一确定的。 这将视角从“检查四元组”转变为“计算同一个圆上有多少点”。 

如果我们采用任何三个非共线点，它们恰好定义一个圆。 如果该圆包含该集合中的 s 个点，则该圆贡献 C(s, 3) 个不同的三元组，因为这些 s 点中的任何三个都会重建同一个圆。 

这给出了关键的重新参数化。 我们不是直接计算四元组，而是计算按其定义圆分组的三元组。 一旦我们知道每个圆有多少个三元组，我们就可以恢复其上有多少个点，并从中计算出它贡献了多少个四元组。 

对三元组的暴力破解的运行时间为 O(n^3)。 对于 n = 300，这大约是 2700 万次迭代，这是可行的。 主要挑战是确保定义同一圆的所有三元组都可靠地分组，这需要使用精确或仔细标准化的算术来稳定地表示圆（中心和半径）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过几何检查对四元组进行暴力破解 | O(n^4) | O(n^4) | O(1) | O(1) | 太慢了 |
 | 枚举三元组并按圆分组 | O(n^3) | O(n^3) | O(n^3) | O(n^3) | 已接受 |

 ## 算法演练

 我们将每个三元组的点转换为穿过它们的圆的规范表示，然后汇总每个圆对应的三元组数。

1. 迭代所有三元组点 (i, j, k)。 如果这些点共线，请跳过它们，因为它们没有定义有效的圆。 
2. 对于每个有效的三元组，计算外接圆。 这意味着计算穿过这三个点的唯一圆的中心及其半径。 可以使用垂直平分线交点找到中心，半径是从中心到三个点中任意一个的距离。 
3. 将此圆转换为可散列密钥。 在实践中，这意味着以归一化有理形式或经过仔细舍入的足够精确的浮动表示来表示中心坐标和平方半径。 
4. 维护一个字典，将每个循环键映射到生成它的三元组的数量。 处理完所有三元组后，该字典中的每个值都等于位于同一圆上的三元组的数量。 
5. 对于每个具有三重计数 m 的圆，计算该圆上有多少个点 s。 由于 s 中任何 3 个点的选择都会产生一个三元组，因此我们有恒等式 m = C(s, 3)。 求解这个三次关系即可找到 s。 
6. 一旦 s 已知，将 C(s, 4) 添加到答案中，因为该圆上的每个四元组点恰好贡献一个有效集合。 

正确性取决于以下事实：每组四个同循环点完全包含在一个圆内，因此在从圆群重建时仅计算一次。 

### 为什么它有效

 每个有效的同循环点四元组都位于唯一的圆上。 该圆在枚举步骤中准确地贡献了 C(s, 3) 个三元组，并且没有其他圆可以产生相同的三元组，因为三个不共线的点唯一地定义了一个圆。 这在圆和分组三元组之间创建了一对一的映射，并且从 C(s, 3) 重建 s 保留了计算 C(s, 4) 所需的所有组合信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict
from math import gcd

def norm_frac(a, b):
    if b < 0:
        a, b = -a, -b
    g = gcd(abs(a), abs(b))
    return (a // g, b // g)

def circumcircle(p1, p2, p3):
    x1, y1 = p1
    x2, y2 = p2
    x3, y3 = p3

    d = 2 * (x1*(y2 - y3) + x2*(y3 - y1) + x3*(y1 - y2))
    if d == 0:
        return None

    x1s, y1s = x1*x1 + y1*y1, x2*x2 + y2*y2, x3*x3 + y3*y3

    cx_num = (x1s * (y2 - y3) + x2s * (y3 - y1) + x3s * (y1 - y2))
    cy_num = (x1s * (x3 - x2) + x2s * (x1 - x3) + x3s * (x2 - x1))

    cx = norm_frac(cx_num, d)
    cy = norm_frac(cy_num, d)

    # radius squared from first point
    # keep as fraction
    dx = x1 * d - cx_num
    dy = y1 * d - cy_num
    r2_num = dx*dx + dy*dy
    r2_den = d*d
    r2 = norm_frac(r2_num, r2_den)

    return (cx, cy, r2)

def C4(s):
    return s * (s-1) * (s-2) * (s-3) // 24

def C3(s):
    return s * (s-1) * (s-2) // 6

def solve_s(m):
    s = 3
    while C3(s) < m:
        s += 1
    return s

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]

cnt = defaultdict(int)

for i in range(n):
    for j in range(i+1, n):
        for k in range(j+1, n):
            c = circumcircle(pts[i], pts[j], pts[k])
            if c is not None:
                cnt[c] += 1

ans = 0
for m in cnt.values():
    s = solve_s(m)
    ans += C4(s)

print(ans)
```实现的核心是三重枚举。 外接圆计算使用基于行列式的公式，避免显式求解线性系统并保持一切代数性。 

字典键必须唯一地表示一个圆。 这就是为什么中心和半径的平方存储为约分数。 标准化中的任何不一致都会错误地合并不同的圆或分割相同的圆，这两种情况都会中断计数。 

重建步骤使用恒等式 m = C(s, 3)。 由于 s 最多为 300，因此简单的线性搜索就足够了，并且避免显式求解三次方程。

 ## 边缘情况

 当三个点共线时，就会发生退化情况。 在这种情况下，外接圆计算会产生零行列式。 该算法显式地跳过此类三元组，确保它们不会破坏分组结构。 

另一种边缘情况是存在多个圆但共享公共子集中的许多点。 由于每个三元组都恰好分配给一个循环密钥，因此重叠子集不会干扰计数，并且每个循环仍然独立于其自己的三元组进行重建。 

最后，当坐标很大或几乎共线时，数值稳定性很重要。 使用简化的分数表示可以防止两个相同的圆因浮点舍入而被视为不同的圆，从而保持所有输入的正确性。
