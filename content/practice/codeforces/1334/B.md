 ## 解决方案

 ## 问题理解

 我们有一群人，每个人都有一些钱。 “富有”的人被定义为最终金钱数量至少达到阈值的人$x$。 

我们可以多次执行某个操作。 每个操作都会选择人员的任何子集，从该子集中获取所有资金，然后将其平均重新分配给相同的选定人员。 重新分配后，子集中的总和保持不变，但所有选定的人最终都会得到相同的值。 

任务是确定最终能够获得至少$x$执行任何此类操作序列后。 

约束条件意味着最多$10^5$人们跨越所有测试用例，所以我们需要一个$O(n \log n)$或者$O(n)$每个测试用例的解决方案。 任何模拟操作或直接考虑子集的方法都是不可行的，因为子集的数量是指数级的。 

一个关键的微妙之处在于，金钱可以在选定的群体内完美地转移，包括分数。 这意味着我们实际上可以在选定的群体之间任意重新分配总财富，但只能通过均衡操作。 

天真的直觉可能会建议反复将富人和穷人分组以平衡事物，但这种方法很容易被打破，因为它忽略了总和的全局守恒以及所有选定成员变得平等的约束。 

一些边缘情况凸显了这一困难：

 如果所有值都低于$x$，但他们的总平均值仍然低于$x$，那么任何手术都无法创造一个富有的人。 例如：

 输入：```
3 10
3 3 3
```即使将每个人分组，平均值也为 3，所以答案为 0。 

如果存在一个非常大的价值，那么最好将其传播给许多人，而不是将其集中。 

这些例子表明，关键的困难是选择一个其平均值可以被推高的子集$x$为尽可能多的人。 

## 方法

 蛮力的想法是尝试每个可能的人员子集并模拟操作动态。 对于每个子集，我们可以想象重新分配资金并检查至少有多少人可以到达$x$。 然而，子集的数量是指数级的，并且每次模拟都是线性的，导致不可能的结果$O(2^n \cdot n)$复杂。 

关键的观察是操作总是用其平均值替换所选子集。 因此，唯一重要的值是所选组的平均值，最终的配置相当于将人们划分为值等于组平均值的组。 

现在考虑我们想要什么：最大化最终价值至少为$x$。 如果一个团体最终至少具有价值$x$，那么它的总和必须至少是组大小乘以$x$。 这表明高价值人才可以通过汇集他人的多余力量来形成。 

考虑这个问题的标准方法是按降序对数组进行排序。 假设我们决定顶部$k$人们将变得富有。 为了支持这一点，我们尝试使用最大的可用价值来“资助”他们。 最好的策略是贪婪的：首先取最大值，然后检查它们的累积和是否足以维持至少$k \cdot x$。 

这将问题转化为检查，对于排序值的每个前缀，是否可以使该前缀至少全部$x$。 由于较高的值有助于满足要求，因此排序可确保我们始终首先考虑最有利的候选者。 

我们从最大到最小计算前缀和并找到最大的$k$使得最大的总和$k$元素至少为$k \cdot x$。 那$k$就是答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n \cdot n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(1)$额外 | 已接受 |

 ## 算法演练

 1. 按降序对数组进行排序，以便我们优先考虑储蓄最高的人。 这确保我们始终首先测试最有前途的候选人。 
2. 计算已排序数组的运行前缀和。 在步骤$k$，这个总和代表了顶层的可用财富总额$k$最富有的人。 
3. 对于每个$k$从 1 到$n$，检查条件是否满足$$\text{prefixSum}(k) \ge k \cdot x$$成立。 这检查我们是否可以重新分配足够的总财富来使所有$k$选定的人至少$x$。 
4. 追踪最大的$k$即满足条件。 该值是可实现的最大富裕人数。 

### 为什么它有效

 关键的不变量是任何最终配置$k$富有的人必须拥有这些方面的总财富$k$位置至少为$k \cdot x$。 由于运营保留了总金额，因此任何转型都无法增加任何选定群体内的可用财富。 

排序可确保我们始终选择最强的候选者来组建这样的团队。 如果连顶$k$最富有的人无法满足条件，则没有其他规模子集$k$可以，因为用较小的元素替换任何选定的元素只会减少总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))
        
        a.sort(reverse=True)
        
        total = 0
        ans = 0
        
        for i in range(n):
            total += a[i]
            k = i + 1
            if total >= k * x:
                ans = k
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先按降序对数组进行排序，以便我们首先评估最强的候选者。 前缀和`total`追踪当前顶级人群的累积财富。 在每一步中，我们都会将其与所需的阈值进行比较$k \cdot x$。 变量`ans`保留找到的最佳有效前缀长度。 

一个微妙的点是我们永远不需要显式地模拟重新分配。 这些操作仅在它们保留总和并允许在所选组内任意重新分配时才重要，这由前缀和条件完全捕获。

 ## 边缘情况

 对于一个单身的人来说$a_1 \ge x$，算法立即将其视为有效，因为前缀和等于要求。 

对于所有值都低于的输入$x$，前缀条件对于每个都失败$k$，因为总和无法达到$k \cdot x$。 排序不会改变此结果。 

对于高度倾斜的输入（例如一个大值和许多小值），前缀测试正确地限制了可以支持的人数，因为每增加一个人就会线性增加所需的阈值，同时只贡献很小的边际总和。
