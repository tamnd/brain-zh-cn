 ## 解决方案
 ## 问题理解

 我们被要求找到一个字符串的所有子串`t`“匹配”另一个字符串`s`根据平等的灵活定义。 通常，子字符串匹配`s`如果每个字符完全相等，但这里我们有一个排列`p`的数字`1`通过`26`允许替换：字符`c`在`s`可以匹配一个字符`d`在`t`如果它们相等，或者如果`d`字母表中正好是`p[idx(c)]`。 

输入给我们`p`作为 26 个整数，一个字符串`s`长度`n`，和一个字符串`t`长度`m`， 在哪里`2 ≤ n ≤ m ≤ 2⋅10^5`。 我们需要输出一个长度的二进制字符串`m - n + 1`，标记每个起始位置`t`和`1`如果那里的子字符串匹配`s`在置换映射下，以及`0`否则。 

这些限制意味着天真的`O(n * m)`方法会太慢，因为`n * m`可以达到 4⋅10^10 次操作。 我们必须利用按位表示、卷积或其他技术来减少所有移位中的每个字符比较`s`反对`t`。 

当出现不明显的边缘情况时`p`将一个字符映射到其自身。 例如，如果`p[1] = 1`和`s = "a"`，那么任意`"a"`在`t`直接匹配和通过排列匹配。 在排列之前忽略相等性的简单检查可能会导致计数过多。 另一个微妙之处是重复的字符`s`或者`t`。 如果`s = "aa"`和`p[1] = 2`， 和`t = "ab"`，那么第一个字符通过排列匹配，但第二个字符不匹配，因此应该拒绝该子字符串。 缺少这些区别会导致输出字符串中出现相差一的错误。 

## 方法

 蛮力方法很简单：对于`t`长度`n`，迭代每个字符，检查它是否等于中的相应字符`s`或通过匹配`p`。 这是正确的，因为它明确强制执行匹配规则，但它要求`O(n * (m - n + 1))`运营。 和`m ≈ 2⋅10^5`和`n ≈ 2⋅10^5`，这大约变成 4⋅10^10 次比较，远远超出了时间限制。 

关键的观察是与排列的匹配可以被数字编码。 我们可以将每个字符表示为一个 26 位掩码，指示它可以匹配哪些字母（它本身和`p_inv[c]`）。 通过创建数组`s`和`t`其中每个位置保存一个 26 位向量，我们可以将匹配检查减少为这些位向量的卷积。 对于每个字母，我们构建 0 和 1 的指示符数组，反向`s`的数组，并执行基于 FFT 的卷积`t`的数组。 卷积后，总和等于的位置`n`在我们灵活的定义下是完全匹配的。 这将时间复杂度降低到`O(26 * m log m)`，这对于输入约束是可行的。 

故事是这样的：蛮力对于小字符串有效，但对于大字符串则失败`m`因为重复的每个字符检查成本太高。 通过将匹配可能性编码为位向量并使用卷积，我们利用问题的结构（具体而言，独立的每个字母检查）来同时有效地计算所有移位的匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 太慢了|
 | 位掩码 + FFT 卷积 | O(26 * m log m) | O(26 * m log m) | O(26 * 米) | 已接受 |

 ## 算法演练

 1. 转换排列`p`通过排列将每个字符映射到其允许的匹配。 对于性格`c`， 定义`match[c]`作为一组字符`{c, d}`在哪里`d`是对应的字符`p[idx(c)]`。 这确保我们捕获直接平等和允许的替代。 
2. 为字符串初始化26个指标数组`s`和 26 为`t`。 对于每个角色`ch`从`'a'`到`'z'`，指标数组`s`有`1`在位置`s[i]`可以匹配`ch`和`0`别处。 同样，对于`t`，该数组有`1`在哪里`t[i] == ch`。 撤销`s`的数组为卷积做准备。 
3. 对每个字符的指示符数组执行基于 FFT 的卷积。 卷积计算每次移位的位置数`s`可以匹配`t`在该字符下。 对所有字符的结果求和。 
4. 对于每个起始位置`i`在`t`，如果卷积值之和等于长度`s`，将其标记为`1`; 否则，将其标记为`0`。 
5. 输出生成的二进制字符串。 

不变量是在每个卷积步骤中，字符的贡献`ch`准确计算位置`s`和`t`匹配或可以通过排列匹配。 对所有字符求和即可得出每个子字符串的总匹配计数。 仅完整匹配数等于的位置`|s|`是有效的事件，保证正确性。 

## Python 解决方案```python
import sys
import numpy as np
input = sys.stdin.readline

p = list(map(int, input().split()))
s = input().strip()
t = input().strip()
n = len(s)
m = len(t)

# map each letter to the set of allowed matches
match = [set() for _ in range(26)]
for i in range(26):
    match[i].add(i)
    match[i].add(p[i]-1)

res = np.zeros(m-n+1, dtype=int)

for ch in range(26):
    s_arr = np.array([1 if (ord(s[i])-97) in match[ch] else 0 for i in range(n)][::-1], dtype=int)
    t_arr = np.array([1 if ord(t[i])-97 == ch else 0 for i in range(m)], dtype=int)
    conv = np.fft.irfft(np.fft.rfft(s_arr, m+n-1) * np.fft.rfft(t_arr, m+n-1)).round().astype(int)
    res += conv[n-1:m]

print("".join(map(str,res)))
```该解决方案紧密遵循算法。 我们首先编码`s`和`t`到指标数组中。 倒车`s`对齐卷积索引，以便索引`i`结果对应于从以下位置开始的子字符串`t[i]`。 FFT 卷积在频率空间中相乘并使用以下方法转换回来`irfft`。 由于浮点不精确，舍入是必要的。 最后，将匹配的总和与`n`产生二进制输出。
