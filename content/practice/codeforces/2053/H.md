 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，每个整数都在 1 和最大值之间$w$。 该序列可以包含重复的数字，但我们可以执行任意次数的特殊操作：选择两个相等的连续元素，并将它们更改为我们喜欢的任意两个数字，只要它们不再相等即可。 我们的目标是在执行这些操作后最大化序列的总和，并报告达到该最大总和所需的最少操作数。 

第一个观察结果是，如果我们忽略操作约束，则最大化序列的总和是很简单的：每个元素理想情况下应该是$w$。 挑战来自于任何操作后两个连续元素都不可能相等的限制。 如果序列已经包含连续的重复项，我们不能简单地独立地增加这些元素而不应用操作。 每个操作将重复的对更改为两个不同的数字$[1, w]$。 最大化总和的最佳选择始终是选择可能的最大的两个不同数字，它们是$w$和$w-1$。 

限制条件很高。 数组长度$n$可以达到$2\cdot10^5$，以及测试用例的数量$t$可以是$10^5$，尽管所有测试用例中的数组元素总数受以下限制$10^6$。 这意味着我们不能天真地模拟操作，因为在最坏的情况下操作数量可能接近$n$并且反复迭代会太慢。 我们需要一个$O(n)$每个测试用例的解决方案。 

当序列已经严格交替时，就会出现不明显的边缘情况。 例如，如果$a = [1, 2, 1, 2, 1]$和$w = 2$，无需任何操作。 一个粗心的解决方案，盲目地试图增加每一个元素$w$可能会错误地计算非重复对的操作。 

例如，当重复的数字连续出现多次时，就会出现另一种棘手的情况$a = [3, 3, 3, 3]$和$w = 5$。 我们需要有效地配对连续的重复项：每次操作后，两个数字变得不同，如果我们不小心选择，可能会形成新的重复项对$w$和$w-1$。 

## 方法

 暴力方法很简单：重复扫描数组，每当发现连续的重复项时，应用操作将它们转换为两个最大的不同数字，$w$和$w-1$。 计算每个操作，然后重复，直到没有重复项为止。 这在原则上是正确的，但最坏情况的复杂度是$O(n^2)$因为单次传递可能会引入新的重复项，并且重复该过程可能需要长达$n/2$迭代。 

关键的见解是我们想要的最终数组是一个严格反单调的序列，这意味着每个连续的对都是不同的，并且每个元素是$w$或者$w-1$。 一旦我们知道了这一点，我们就可以通过计算原始序列中重复的连续对来直接计算操作数。 每个重复对只需要一次操作。 我们不需要按顺序模拟操作，因为任何重复的对都是独立的； 最大总和总是通过将每个重复对替换为来实现$w$和$w-1$，根据需要交替。 

这种观察将问题简化为扫描一次数组、检测重复项、求最大值和计数操作。 复杂度是线性的$n$每个测试用例，考虑到限制，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了|
 | 计算重复次数并最大化 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将总和初始化为零，并将运算计数初始化为零。 这些变量将跟踪可实现的最大总和以及所需的最小操作数。 
2. 从左到右迭代数组。 对于每个元素，如果它等于前一个元素，则增加操作计数。 这对每个连续的重复对恰好计数一次。 我们不模拟操作； 我们只是注意到它是需要的。 
3. 计数操作完成后，计算最大和。 如果$n = 1$，总和就是元素本身。 为了$n \ge 2$，最终序列中的每个元素应该是$w$或者$w-1$。 求和公式为$(n//2) \cdot (w + (w-1)) + (w \text{ if n is odd else 0})$，交替出现$w$和$w-1$以避免连续重复。 
4. 返回最大和以及运算次数。 

保证正确性的不变性是每个操作精确地修复一个连续的重复项，并且使用$w$和$w-1$确保不会引入新的重复项。 计算初始重复对可以给出所需操作的确切数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, w = map(int, input().split())
        a = list(map(int, input().split()))
        
        ops = 0
        for i in range(1, n):
            if a[i] == a[i-1]:
                ops += 1
        
        full_pairs = n // 2
        max_sum = full_pairs * (w + (w-1))
        if n % 2:
            max_sum += w
        
        print(max_sum, ops)

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量。 对于每个数组，它计算连续的重复项以确定操作数。 然后计算长度最大反单调数组的总和$n$使用$w$和$w-1$交替。 边缘情况，例如长度为 1 的数组，自然可以通过求和公式来处理。
