 ## 解决方案
 ## 问题理解

 我们有两个数组，`a`和`b`，每个长度`n`。 任务是计算最大乘积$$P = \prod_{i=1}^{n} \min(a_i, b_i)$$任何重新安排后`b`。 从概念上讲，您可以将其视为来自的配对元素`a`元素来自`b`使得每一对的贡献最大化。 初步计算后，我们被要求处理`q`增量修改，其中一个元素`a`或者`b`加 1，每次修改后，我们必须报告新的最大可能值`P`。 所有结果均取模`998244353`。 

限制条件很高：`n`和`q`每个可以达到 200,000，所有测试用例的总和可达 400,000。 暴力重新计算`P`每次修改后太慢，因为需要排序`b`并计算每个查询的乘积。 即使每个查询都进行排序，这也可能是$O(n \log n \cdot q) = O(4 \cdot 10^5 \cdot \log(2 \cdot 10^5))$在最坏的情况下，操作处于临界状态或缓慢。 我们需要一种能够高效更新而无需从头开始重新计算产品的解决方案。 

棘手的部分是配对：简单排序`a`和`b`当值动态变化时，独立地计算并且乘以最小值是不够的。 另一个微妙之处是乘积可能很大，因此每个乘法步骤都需要模运算以避免溢出。 边缘情况包括所有值都相等时、一个数组严格大于另一个数组时以及单个元素上累积多个修改时。 

粗心的方法会排序`b`一次并尝试保持配对固定索引； 这会失败，因为增加了值`a`或者`b`可以改变哪些元素应该配对以获得最大产品。 

## 方法

 天真的方法很简单。 对于初始数组，排序`a`并排序`b`，然后将最小的配对`a`与最小的`b`，下一个最小的与下一个最小的，依此类推。 这保证了每对中的最小值被最大化，因为任何偏差配对都较小`a`具有较大的`b`- 将减少最小值之一。 对于每个查询，我们将增量应用到`a`或者`b`，然后重新对数组进行排序并重新计算乘积。 最坏情况的时间复杂度是$O(q \cdot n \log n)$，对于最大的输入来说太慢了。 

关键的见解是为了最大化$$P = \prod \min(a_i, b_{\pi(i)})$$我们只需要知道每个不同值的计数`a`和`b`并维护一个支持有效递增值的结构，同时按排序顺序计算元素最小值的乘积。 排序`a`和`b`最初没问题，但是在每次增量之后，我们可以维护一个多重集或平衡 BST`b`这使我们能够快速调整产品，而无需完全重新计算。 具体来说，如果我们维持`b`按照排序顺序，可以通过删除旧值并插入新值来模拟增量操作。 同样对于`a`。 为了计算乘积，我们可以按顺序迭代，将最小的可用值配对`a`可用最小的`b`尚未使用过。 

另一个优化是我们只需要 **排序值**`a`和`b`在每个点。 如果我们维护每个值的计数（例如，通过计数器或字典）和前缀乘积结构，我们可以调整`a`或者`b`通过更新计数并重新计算最小贡献而不进行完整排序来增量地进行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q * n log n) | O(q * n log n) | O(n) | n、q 达到 2e5 时速度太慢 |
 | 最优（使用排序数组+增量更新） | O((n + q) log n) | O((n + q) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 数组排序`a`按非递减顺序。 的顺序`b`可以自由重新排列，所以排序`b`也按非递减顺序排列。 一对`a[i]`和`b[i]`对于每个`i`。 这保证了产品`P`被最大化，因为配对最小的`a`与最小的`b`防止浪费大量`b`在一个小`a`。 
2. 计算初始乘积`P`模数`998244353`。 迭代所有索引，相乘`min(a[i], b[i])`并在每一步取模。 
3. 保持两者`a`和`b`作为列表，对于每个增量操作：

 - 如果操作已开启`a[x]`， 增加`a[x]`1.
 - 如果操作已开启`b[x]`， 增加`b[x]`1.
 - 每次增量后，对受影响的数组重新排序。 由于只有一个元素发生变化，我们可以使用二分查找删除旧值并插入新值（`bisect`) 在 O(log n) 中。 
4. 使用新的排序数组重新计算乘积。 由于两个数组都保持排序，因此按元素配对仍然会给出最大乘积。 
5. 输出初始状态后和每次操作后的乘积。 

正确性得到保证，因为最佳配对始终是已排序的配对。 增加单个元素并将其重新插入到排序数组中可以保持与第 i 个最小元素配对的不变量`a`与第 i 个最小的`b`产生最大的`P`。 

## Python 解决方案```python
import sys, bisect
input = sys.stdin.readline
MOD = 998244353

def max_product(a, b):
    prod = 1
    for x, y in zip(a, b):
        prod = (prod * min(x, y)) % MOD
    return prod

t = int(input())
for _ in range(t):
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    a.sort()
    b.sort()
    ans = [max_product(a, b)]
    
    for _ in range(q):
        o, x = map(int, input().split())
        x -= 1
        if o == 1:
            old = a[x]
            a.pop(x)
            bisect.insort(a, old + 1)
        else:
            old = b[x]
            b.pop(x)
            bisect.insort(b, old + 1)
        ans.append(max_product(a, b))
    
    print(' '.join(map(str, ans)))
```代码排序`a`和`b`最初。 对于每个增量，它从列表中删除旧值并使用以下命令重新插入增量值`bisect.insort`，这使数组保持高效排序。 由于排序的配对策略，每次修改后计算乘积可确保结果最大。
