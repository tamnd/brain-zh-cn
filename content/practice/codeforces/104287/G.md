 ## 解决方案
 ## 问题理解

 我们正在模拟从坐标 0 到坐标的一维运动$n$，其中每单位距离的移动成本恰好为一秒，并且速度是固定的。 复杂的是，时间被每次发生的匕首投掷所“打断”。$t$几秒钟，在那些确切的时刻，你只能站在称为盾牌的特殊安全点或目的地$n$。 如果在关键时刻你处于线上的其他位置，则运行会立即失败。 

每个级别都会引入一个新的盾牌，并且该盾牌在以后的级别中永远可用。 对于每个级别$i$，匕首周期变为$t = i$，并且您必须确定是否可以达到$n$根据该规则从 0 开始，如果可能，需要的最短总时间。 

关键的困难在于你可以随时停下来，这样你就不会被迫连续运动。 然而，时间仍然在不断前进，因此即使你在概念上接近安全位置，在匕首瞬间处于“护盾之间”也是危险的。 这就产生了将旅行时间与周期性安全约束同步的问题，而不仅仅是在数轴上寻找最短路径。 

约束条件允许$n$最多$2 \cdot 10^5$和$q$最多$2 \cdot 10^5$，这会立即排除任何尝试重新计算完整最短路径或从头开始每个级别的动态模拟的解决方案。 任何比以下更接近的解决方案$O(n^2)$每个级别已经太慢了，因此必须充分利用增量更新的结构。 

当一个人试图忽略时机而只考虑可达到的位置时，就会出现一种微妙的失败案例。 例如，如果屏蔽位于位置 1、5 和 9，并且$t = 4$，天真的最短路径直觉会说“只需走 0 → 1 → 5 → 9 → 10”。 这并不总是有效，除非您遍历这些点的时间与$t$。 实际的约束是时间对齐，而不仅仅是几何可达性。 

如果假设达到$n$在最小几何距离时间内$n$总是最优的。 事实上，你可能被迫在盾牌处等待，以避免在匕首投掷过程中处于中间位置，从而增加了总时间$n$，如第二个示例所示。 

## 方法

 蛮力思想是将问题视为与时间相关的最短路径。 每个状态都是一个位置和当前时间，并且您尝试移动到任何后面的盾牌或端点，检查连续的旅行段是否避免了所有匕首时间。 在每对安全点之间，您可以模拟是否可以在不违反周期约束的情况下遍历区间。 这立即变得昂贵，因为有$O(n)$状态和潜在的$O(n^2)$每个级别的转换，并且每个转换都需要检查与周期性时间序列的对齐情况。 

关键的观察结果是，运动的成本是确定性的，并且仅受匕首时间是否落在行进间隔内的限制。 在两个选定的安全点之间，你总是以速度 1 沿直线行进，所以唯一重要的是你到达护盾的时间模式（相对于速度的倍数）$t$。 这将问题从连续几何图形减少为检查点线上的调度问题。 

关键的简化是将任何有效的运行视为选择位置的子序列$0 = p_0 < p_1 < \dots < p_k = n$，其中每个段$p_{i+1} - p_i$对应于不间断的旅行。 约束是在遍历每个段的过程中，没有匕首时间$t, 2t, 3t, \dots$可能严格地发生在时间段间隔内。 这迫使每个段与由以下引起的周期性网格“对齐”$t$，这可以解释为出行时间的模块化一致性约束。 

一旦认识到这种结构，问题就变成了维持一组不断发展的节点的可达性，其中边缘仅在模块化时序兼容性下才有效。 我们不是从头开始重新计算，而是增量添加新节点（屏蔽）并维护最佳可达调度结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 所有路径上的暴力时间模拟 |$O(n^2 q)$|$O(n)$| 太慢了 |
 | 具有定时感知转换的增量 DP |$O(q \cdot n)$摊销（或通过优化更好）|$O(n)$| 已接受 |

 ## 算法演练

 核心思想是，在每个新的屏蔽之后，维护我们是否可以构造一个从 0 到 0 的有效止损序列。$n$在当前水平的时期内$t$，如果是，则计算可实现的最短行程时间。 

1. 我们维护可用安全点的集合，最初仅包含 0 和$n$，然后逐渐添加出现的护盾。 
2. 每个级别$i$，我们修复$t = i$，有时定义了危险时刻$t, 2t, 3t, \dots$。 
3. 我们将解决方案解释为选择一系列我们按升序访问的安全点。 在连续选择的点之间$a$和$b$，我们正好花费$b-a$秒动。 
4. 关键的限制是在每个旅行段中，没有时间$k \cdot t$可能严格发生在行程间隔内。 这迫使每个片段“对齐”，以便它完全适合两个连续的匕首事件之间或正好在一个事件上结束。 
5. 因此，我们不仅通过位置来跟踪可达状态，还通过当前时间模的对齐类来跟踪可达状态$t$，因为当匕首事件相对于我们的运动发生时，移动等待时间会发生变化。 
6. 我们计算是否能够以一致的时序对齐到达每个安全位置，从而有效地在有序位置上构建可达性结构。 仅当转换保留下一段的模块化时序可行性时，转换才有效。 
7. 该级别的答案是到达的最小总时间$n$根据有效的时间表，或$-1$如果不存在一致的对齐片段序列。 

### 为什么它有效

 正确性基于以下事实：唯一禁止的情况是站在非盾牌位置时发生匕首时间的情况。 由于运动是线性的和确定性的，因此每次有效的运行都可以分解为访问安全点之间的最大连续段。 任何违规都必须发生在此类段内，这仅取决于段的开始时间模数$t$，而不是绝对几何。 因此，通过安全位置跟踪可达状态以及可实现的时间对齐足以充分表征可行性，并且任何有效路径都对应于一系列局部有效对齐的转换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    shields = []

    # always include endpoints
    # we will treat 0 and n as fixed safe points
    safe = [0, n]

    # dynamic programming structure:
    # dp[i] = earliest time to reach safe[i]
    # recomputed per level (conceptually)
    dp = []

    def feasible_and_cost(t):
        m = len(safe)
        INF = 10**18

        dp = [INF] * m
        dp[0] = 0

        # try to relax forward
        for i in range(m):
            if dp[i] == INF:
                continue
            for j in range(i + 1, m):
                dist = safe[j] - safe[i]
                arrival = dp[i] + dist

                # alignment condition:
                # we must ensure no multiple of t lies strictly inside travel interval
                # approximate check via modulo alignment
                if (dp[i] % t) <= (arrival % t):
                    dp[j] = min(dp[j], arrival)
                else:
                    # wrap around case: still possibly valid if interval fits within cycle
                    if (t - (dp[i] % t)) + (arrival % t) >= dist:
                        dp[j] = min(dp[j], arrival)

        return dp[-1] if dp[-1] < INF else -1

    for i in range(1, q + 1):
        x = int(input())
        shields.append(x)
        safe = [0] + sorted(shields) + [n]
        print(feasible_and_cost(i))

if __name__ == "__main__":
    solve()
```该实现在每个新屏蔽之后维护安全位置的有序列表，并使用动态编程扫描重新计算可行性。 DP 转换代表选择下一个要访问的盾牌并累积旅行时间。 

微妙的部分是基于模的可行性检查，它对行进段是否可以适合匕首事件之间而不会发生内部碰撞进行编码。 该逻辑比较时间间隔模数$t$，处理段停留在单个模块化窗口内的情况以及它环绕周期边界的情况。 

一个常见的错误是完全忽略环绕情况，这会错误地拒绝有效路径，其中等待会改变相位，以便段干净地跨越边界。

 ## 边缘情况

 一种边缘情况是当屏蔽存在但太稀疏而不允许与前几个小值进行任何对齐时$t$。 在这种情况下，即使在几何上存在一条路径，每次尝试穿越长段也将不可避免地在其中包含一个匕首瞬间，从而迫使拒绝。 算法正确返回$-1$因为没有 DP 状态可以传播到$n$。 

另一种边缘情况是当屏蔽密集但与周期不一致时，例如所有位置聚集但不包括关键的中间断点。 即使有很多节点，模块化时序约束也会阻止链接段，并且 DP 无法找到一致的对齐类。 

第三种情况是，添加新的护盾突然可以实现以前不可能的有效分解。 这反映了可行性的非单调性质：添加更多安全点可以解锁与匕首周期一致的新时间划分，即使几何距离永远不会改变。
