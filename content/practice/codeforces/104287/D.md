 ## 解决方案
 ## 问题理解

 我们被赋予了一个$N \times N$乘法表，其中每个单元格$(i, j)$包含产品$i \cdot j$。 因此，该表包含可以表示为两个数字的乘积的每个整数$1$和$N$，包含在内。 我们的任务是找到没有出现在该表中任何位置的最小正整数。 

思考该问题的另一种方法是，我们正在构建至少具有一个因子对的所有值的集合$(a, b)$这样$1 \le a, b \le N$，我们想要该集合中第一个缺失的整数。 

约束条件$N \le 10^5$立即排除任何显式构造表或枚举所有产品的尝试。 该表本身将包含$N^2$条目，最多可达$10^{10}$，远远超出了可以计算或存储的范围。 甚至迭代所有对$(i, j)$是不可能的。 

关键的边缘情况行为出现在小$N$，其中可表示数字的差距很容易看出。 为了$N = 3$，该表包含值$\{1,2,3,4,6,9\}$，最小的缺失数是$5$。 一种简单的方法，仅扫描$N^2$或假设所有数字达到$N^2$出现会错误地认为每个数字都被覆盖，即使对于非常小的数字也是错误的$N$。 

另一个微妙的陷阱是假设答案随着$N^2$。 现实中，有一次$N$很大时，许多小数字已经可以完全表示，并且第一个缺失的数字稳定在一个小边界附近，该边界取决于因子结构而不是表大小。 

## 方法

 暴力方法将显式生成所有产品$i \cdot j$为了$1 \le i, j \le N$，将它们存储在一组中，然后从$1$向上直到找到缺失的整数。 这在概念上是简单且正确的，因为它直接对表的定义进行建模。 

然而，生成表需要$O(N^2)$乘法和插入哈希集会增加额外的开销。 为了$N = 10^5$，这就变成了$10^{10}$的操作，远远超出了可行的限度。 即使对于最小的子任务，这种方法很快就会变得不切实际。 

关键的观察结果是我们实际上不需要构建该表。 我们只关心哪些小整数可以表示为范围内两个数字的乘积$[1, N]$。 对于一个号码$x$要出现在表中，它必须有一个除数$d \le N$这样$x/d \le N$以及。 这意味着除数及其配对商必须位于该范围内。 

现在考虑会发生什么$N$成长。 任意数量$x \le N$是微不足道的存在，因为$x = 1 \cdot x$。 对于略高于的数字$N$，它们可能会出现也可能不会出现，具体取决于它们是否具有范围内的因子对。 作为$x$增长，最终我们到达一个点，其中没有有效的因子对适合$[1, N]$，从那时起，第一个间隙出现。 

这将问题简化为向上扫描整数并检查每个整数是否至少有一个除数$d \le N$这样$x/d \le N$。 自从$x/d \le N$意味着$d \ge \lceil x/N \rceil$，我们只需要检查除数$\sqrt{x}$，并确保因子对的两边都在范围内。 

因为答案相对较小$N^2$，我们只需要测试数字达到上述合理限度$N$，通常约为$2N$或者在最坏的情况下稍微多一些。 每个号码都可以签入$O(\sqrt{x})$，给出的总复杂度很容易足够快。

 ## 算法演练

 我们迭代从以下位置开始的候选整数$1$，检查每个整数是否可以表示为一个乘积$a \cdot b$与两者$a$和$b$在$[1, N]$。 

1. 从候选值开始$x = 1$。 我们增加$x$一步一步，因为我们正在寻找最小的缺失值，所以任何间隙都必须按升序出现。 
2. 对于每个$x$，迭代可能的除数$d$从$1$最多$\sqrt{x}$。 停在平方根处的原因是每个因子对在该点之后对称重复。 
3. 当我们找到除数时$d$这样$x \bmod d = 0$，计算配对因子$q = x / d$。 此时我们有一个有效的分解$x = d \cdot q$。 
4. 检查两者是否$d \le N$和$q \le N$。 如果这个条件成立，$x$存在于乘法表中，我们可以将其标记为存在。 然后我们转向下一个候选人。 
5. 如果没有这样的除数产生有效的对，我们得出结论：$x$无法在表内形成并将其作为答案返回。 

### 为什么它有效

 一个数字出现在乘法表中当且仅当它至少有一次因式分解$x = a \cdot b$这两个因素都在于$[1, N]$。 该算法详尽地检查了所有因素对$x$恰好一次（通过除数最多$\sqrt{x}$），并验证是否有任何对符合允许的范围。 如果不存在有效对，则根据表构造的定义，$x$无法生成，使其成为按升序遇到时最小的缺失值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def in_table(x, n):
    r = int(math.isqrt(x))
    for d in range(1, r + 1):
        if x % d == 0:
            q = x // d
            if d <= n and q <= n:
                return True
    return False

def solve():
    n = int(input().strip())

    x = 1
    while True:
        if not in_table(x, n):
            print(x)
            return
        x += 1

if __name__ == "__main__":
    solve()
```辅助函数`in_table`对一个数字是否可以形成为允许范围内的两个整数的乘积的条件进行编码。 它使用平方根界限有效地检查所有除数对。 

主循环从 1 开始递增候选值，确保第一次失败是最小的缺失数。 终止是有保证的，因为一旦$x > N^2$，该范围内不能存在有效的因子对，因此循环最终必须中断。 

一个微妙的点是我们不需要任何预处理或存储结构。 每个数字都经过独立检查，正确性完全依赖于因式分解属性而不是表模拟。

＃＃＃ 案件$N = 2$输入：```
