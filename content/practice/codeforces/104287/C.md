 ## 解决方案
 ## 问题理解

 我们正在查看一系列$n$游戏的独立回合。 每轮只有一名玩家获胜。 托马斯是一位特殊的球员，还有$k$其他竞争对手，所以每一轮都有$k+1$可能的赢家。 

游戏的完整结果只是一个长度-$n$每个位置选择其中之一的序列$k+1$玩家成为该轮的获胜者。 在所有这些序列中，我们想要计算托马斯没有每轮都获胜的序列。 换句话说，我们排除了序列中的每个条目都是 Thomas 的单一退化情况。 

可能的序列总数为$(k+1)^n$，因为每轮都有$k+1$独立的选择。 唯一被禁止的配置是在所有配置中选择托马斯的配置$n$职位。 

限制非常小：$n \le 10$和$k \le 4$。 这立即告诉我们，即使是所有结果的简单枚举也是可行的，因为序列的最大数量是$5^{10} \approx 9.7 \times 10^6$，这是边界，但如果仔细完成，在优化的 Python 中仍然可以管理。 然而，结构很简单，无需枚举。 

一个微妙的边缘情况是$n = 1$。 在这种情况下，“托马斯横扫”意味着托马斯赢得了唯一一轮。 所以答案应该是除了单一配置之外的所有玩家。 那就变成了$k$，因为有$k+1$总共的选择，我们只排除了一个。 

另一个边缘情况是当$k = 0$，这意味着托马斯是唯一的球员。 唯一可能的结果是横扫，因此对于任何结果，答案都必须为零$n \ge 1$。 该公式必须自然地处理这个问题。 

## 方法

 思考这个问题最直接的方法是生成所有可能的获胜者序列。 对于每一轮，我们选择其中之一$k+1$玩家，形成深度树$n$具有分支因子$k+1$。 这正好产生$(k+1)^n$树叶。 对于每个叶子，我们检查每个位置是否都是托马斯，并减去那个无效的情况。 

这是正确的，因为它明确地构建了所有结果。 失败点是效率：即使在上限$n = 10$,$k = 4$，搜索空间增长到近千万个序列，递归或字符串构造中的任何额外开销都使其在严格限制下的 Python 中变得脆弱。 

关键的观察结果是各轮的结构完全一致。 每一轮都是独立的，条件“托马斯赢得所有回合”恰好对应一个序列。 因此，我们不需要枚举任何东西； 我们只需要从总数中减去该单一配置。 

所以答案很简单：$$(k+1)^n - 1$$蛮力显式地计算这两个部分，而优化的解决方案直接计算整个空间并删除唯一禁止的情况。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举|$O((k+1)^n \cdot n)$|$O(n)$| 太慢了 |
 | 直接配方|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取整数$n$和$k$。 这些定义了轮数和非托马斯玩家的数量。 
2. 计算可能结果的总数为$(k+1)^n$，因为每一轮独立地选择一个获胜者$k+1$竞争对手。 
3. 从总数中减去 1，以消除托马斯每轮获胜的单个无效结果。 
4. 输出结果值。 

唯一重要的推理步骤是认识到无效条件恰好对应于一种配置，而不是范围或子集。 这就是允许减法而不是包含排除或动态规划的原因。 

### 为什么它有效

 每个有效的游戏结果都唯一对应一个长度-$n$大小字母表上的序列$k+1$。 这种映射是双射的：每个序列精确定义一个结果，每个结果精确定义一个序列。 

“扫描”条件对应于每个位置都是 Thomas 的单个序列。 由于没有其他序列共享此属性，因此从总数中恰好删除一个会产生正确的答案。 轮次之间不存在可能产生额外禁止情况的重叠或相互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

total = pow(k + 1, n)
print(total - 1)
```该实现直接反映了数学简化。 内置的`pow`用于快速求幂，这对于如此小的约束是不必要的，但可以保持代码干净和安全。 

减 1 对于所有有效输入都是安全的，因为当$k \ge 0$和$n \ge 1$，我们总是有$(k+1)^n \ge 1$，并且平等仅发生在$k = 0$，结果正确地变为零。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    return str(pow(k + 1, n) - 1)

# provided samples
assert run("2 1\n") == "3"
assert run("10 3\n") == "1048575"

 ## 边缘情况

 最重要的边缘情况是当$k = 0$。 输入描述了只有 Thomas 存在的情况。 对于任何$n$，每一轮都必须是托马斯获胜，所以只有一个结果，而且总是横扫。 公式给出$(0+1)^n - 1 = 0$，这与推理直接相符。 

为了$n = 1$，问题简化为在其中选择一个获胜者$k+1$玩家。 这些选择之一是无效的（Thomas），所以结果应该是$k$。 公式给出$(k+1)^1 - 1 = k$，它完全对齐。 

对于较大的$n$，不会出现新的结构案例，因为各轮之间的独立性确保了没有交互效应。 每增加一轮只会使总空间成倍增加，并且禁止的配置仍然是单一的。
