 ## 解决方案
 ## 问题理解

 我们有一棵加权树，这意味着有$N$连接的节点$N-1$没有环的边，并且每条边都有一个非负权重。 我们必须从这棵树中选择两条路径，使它们不共享任何节点。 对于每条选定的路径，我们计算沿该路径的边权重之和。 最终得分是两条路径总和中的最小值，任务是在两条节点不相交路径的所有有效选择上最大化该得分。 

所以结构是：在树中选择两条简单的路径，确保它们是顶点不相交的，我们只关心平衡它们，以便较弱的路径尽可能强大。 

约束条件达到$5 \cdot 10^5$所有测试用例的节点总数，这立即排除了任何尝试枚举所有路径甚至所有路径对的解决方案。 甚至$O(N^2)$每个测试用例的方法都是不可能的，并且直接处理所有节点或边对的任何方法都超出了范围。 我们被迫对每个测试用例进行线性或近线性遍历。 

一个微妙的点是，“两条节点不相交的路径”并不意味着它们必须位于某个根的不同子树中。 它们可以位于树中的任何位置，只要它们的顶点不重叠即可。 这使得暴力路径配对特别危险。 

往往会打破天真的想法的边缘情况包括最佳路径非常不平衡的树，例如中间某处有重分支的长链，或者两条最佳路径共享高权重中心区域的树，从而迫使不相交约束占主导地位。 

例如，考虑一个简单的链：```
1 -2- 2 -2- 3 -2- 4
```如果我们选择路径（1到4），我们就不能选择任何其他路径，因此得分为0。但最佳解决方案是分成两条不相交的路径，如（1-2）和（3-4），每条路径的总和为2，得分为2。贪婪的最长路径方法在这里失败，因为它忽略了分区。 

另一个失败案例是以节点 1 为中心的星形，其中所有边都连接到叶子。 一种简单的方法可能会选择两个最重的边作为两条单边路径，这在这里是正确的，但是任何尝试构建长链的方法都会失败，因为不存在长链。 

## 方法

 蛮力思想从直接解释开始：枚举树中的所有简单路径，然后尝试每对节点不相交的路径并计算它们的总和的最小值，跟踪最大结果。 

在一棵树上，有$O(N^2)$简单的路径。 将它们配对已经给出$O(N^4)$最坏情况的组合。 即使进行了修剪，有效路径对的数量仍然太大。 瓶颈不是正确性，而是候选路径对的数量。 

关键的结构见解是，一旦我们删除一些分离结构，树中的两个节点不相交的路径必须位于不同的连接组件中，更重要的是，始终可以通过围绕“中心”区域的分解来解释最佳解决方案，在该区域中，树被分成独立的部分。 我们不再考虑任意的​​路径对，而是转变视角：我们想要找到一种方法来切割树，以便两条“最佳可能”路径存在于不相交的部分中，并且我们最大化较弱的路径。 

一个有用的重新表述是考虑源自某些根分解的路径候选：每个最佳对对应于选择两条不相交的路径，这意味着必须通过选择树中的分割点来避免它们的最高重叠。 这自然会导致最佳向下和最佳全局路径贡献的 DP 或基于重生的计算。 

该解决方案最终简化为针对每个节点计算最好的两个不相交的“高价值路径贡献”，这两个“高价值路径贡献”可以在该节点或之上分离的树的不同部分中形成。 这是通过计算最长的向下路径并仔细组合它们来完成的，同时确保我们永远不会在两条选定的路径上重复使用节点。 

核心思想是，每个有效的解决方案都可以表示为位于某个分解点的不同分支中的两条边不相交（因此顶点不相交）路径，并且通过考虑所有此类分割点并组合来自不同子树的最佳候选点来获得答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有路径+对）|$O(N^4)$|$O(N^2)$| 太慢了|
 | 树 DP / 重新扎根与最高贡献 |$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们以任意节点为树根。 目标是为每个节点计算完全位于其子树内的最佳路径贡献的信息，然后组合来自不同子子树的贡献。 

我们为每个节点维护从该节点开始到其子树的最佳向下路径总和。 这是标准的树DP：对于每个子节点，我们采用其最佳的向下路径并添加连接边。 

然而，单个向下路径是不够的，因为最终答案涉及两条不相交的路径，它们可能都位于不同的子树中，或者可能都是内部结构而不是根到叶路径。 

因此，在每个节点，我们还想知道可以从不同子子树中获取的最佳两个非重叠候选路径。 这是关键点：在一个节点处相遇的任何两个节点不相交的路径必须来自不同的子节点，因为共享子子树意味着共享节点。 

我们按如下方式进行。 

1. 以节点 1 为树根并计算邻接表。 
2. 执行 DFS，为每个节点计算从该节点开始的最佳下行路径。 该值表示从该节点开始并向下进入一个子子树的路径的最大总和。 我们限制为一个分支的原因是，任何进入节点并向下延伸的简单路径都必须恰好选择一个子方向。 
3. 在 DFS 期间，对于每个节点，在添加边权重后，收集来自其子节点的所有候选向下贡献。 这些表示从当前节点开始并延伸到不同子树的独立路径段。 
4. 在每个节点，我们对前几个子贡献进行排序或维护。 我们需要多个的原因是最终答案需要选择两条不相交的路径，在最好的情况下来自两个不同的子路径。 
5. 我们在每个节点计算两种类型的候选：第一，完全包含在其子树中的最佳单路径（已由向下 DP 捕获），第二，通过采用属于不同子树的两个最佳子贡献形成的最佳对。 它们的总和是独立的，因为它们不共享节点。 
6. 我们用两个选定路径和中的最小值更新全局答案。 这反映了这样一个事实：一旦我们选择了两条不相交的路径，分数就由较弱的路径决定，因此我们必须确保两条路径都尽可能强。 
7. 继续 DFS 遍历，以便每个节点聚合来自其子节点的信息，确保考虑树中的每个可能的分裂点。 

### 为什么它有效

 关键的不变量是每对有效的节点不相交路径都有一个唯一的最高公共祖先（在有根树中），并且在该祖先处，两条路径必须位于不同的子子树中。 我们的DP在每个节点处枚举了从不同子树中挑选两个不相交贡献的所有方法。 由于每个有效对都必须以这种方式在某个节点处分离，因此每个可行解都在其分裂点处表示。 向下的 DP 确保每个子树为此类组合贡献其最佳可能路径，因此不会错过更好的本地配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, w))
        g[v].append((u, w))

    ans = 0

    def dfs(u, p):
        nonlocal ans
        best_down = 0
        gains = []

        for v, w in g[u]:
            if v == p:
                continue
            child_down = dfs(v, u) + w
            gains.append(child_down)
            best_down = max(best_down, child_down)

        gains.sort(reverse=True)

        if len(gains) >= 2:
            ans = max(ans, gains[0] + gains[1])

        ans = max(ans, best_down)

        return best_down

    dfs(0, -1)
    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        out.append(str(solve()))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```该实现对每个测试用例使用单个 DFS。 关键结构是`dfs`函数，它返回从节点开始的最佳向下路径。 该值是通过取所有子项的向下贡献加上边缘权重的最大值来计算的。 

这`gains`列表收集所有子贡献，以便我们可以识别两个最好的独立分支。 使用排序是为了清楚起见，但实际上，运行前两个选择就足够了，而且速度更快。 

全局答案以两种方式更新：首先使用单个最佳向下路径，其次使用节点处最佳两个子贡献的总和，这对应于选择紧邻该节点下方发散的两条不相交路径。 

一个微妙的实现细节是，我们不能混合来自同一子树的路径，这是自然强制的，因为每个`child_down`源自不同的子边缘。 另一个重要的一点是，DFS 返回值只有一条路径，尽管答案取决于全局的两条路径。

该轨迹表明，最佳配置是在分支点局部确定的，而不是沿着长链确定的。

 ## 边缘情况

 一个关键的边缘情况是线性链。 在这样的结构中，每个节点至多有一个子贡献，因此没有节点形成一对有效的两个不相交分支路径。 该算法正确地仅更新单路径值，并且答案仍然由最佳可能的分割为两个单独的段来确定，这在链中减少为在中间切割一个边缘。 

另一个边缘情况是明星。 这里所有有效路径都是单边，正确答案就是两个最大边权重的总和。 DFS 收集根处的所有子贡献，并且该节点处的成对组合直接捕获最优解。 

最后，零权重树确保不会意外地优先考虑较长的结构路径。 由于所有贡献均为零，因此每个组合的评估都是相等的，并且无论结构如何，算法都会正确返回零。
