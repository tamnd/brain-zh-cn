 ## 解决方案
 ## 问题理解

 我们得到一个最多有 100 个顶点的有向图。 每个顶点都有一个值，表示探险者在一秒钟内处于该顶点时吸入的气体量。 该过程随着时间的推移而演变$k$秒。 最初，探索器从顶点 1 开始。 

每一秒都由两个耦合动作组成。 首先，探索器位于某个顶点，并根据数组的当前状态立即接收该顶点的气体值$a$。 之后，他可以停留或沿着有向边缘移动。 最后，整个数组$a$循环左移一个位置，这会在下一秒同时更改与所有顶点关联的气体值。 

目标是最大限度地减少探索者积累的总气体$k$秒。 

关键结构是时间以周期性方式影响权重：每一步之后，向量$a$旋转，所以顶点$i$并不总是具有相同的成本。 这使得该问题从根本上成为状态空间中的最短路径问题，其中包括位置和时间模$n$，但时间跨度非常大$k$最多$10^9$。 

的小限制$n \le 100$和$m \le 1000$强烈建议我们可以负担得起图表$n \times n$或者$n \times n \times n$状态，但不依赖任何东西$k$。 

第一个微妙的问题是，探索者被迫准确地采取$k$步，即使他提前到达“安全”区域。 第二个是允许停留在原地，因此必须隐式考虑自环。 第三，最佳策略取决于将图中的运动与循环数组的有利相位对齐，这意味着时间和位置紧密耦合。 

一个幼稚的错误是独立于时间对待每个顶点，假设贪婪地选择最小电流$a_i$。 这会失败，因为当前昂贵的顶点可能在几次旋转后变得便宜，并且探索者可以计划稍后到达。 

作为一个具体的失败，假设一个顶点现在很昂贵，但每次都变为零$n$步骤。 贪婪的策略会永远避免它，但最优策略可能会等待或在正确的时间通过它。 

另一个边缘情况是，停留是最佳的，只是因为等待将阵列旋转与未来的廉价状态对齐。 忽略“等待”边缘或将移动视为始终强制会破坏正确性。 

## 方法

 蛮力方法将完整状态建模为$(u, t)$， 在哪里$u$是顶点并且$t$是时间步长到$k$。 从每个州我们可以去任何邻居或停留，以及时间的费用$t$取决于$a[(u + t) \bmod n]$考虑轮换后。 

这在概念上是正确的但不可能，因为$k$取决于$10^9$，因此随着时间的推移扩展状态需要$O(nk)$状态和转换，太大了。 

关键的观察是阵列循环旋转，因此系统具有周期结构$n$。 后$n$步骤，阵列返回到其原始配置。 这表明时间可以被压缩模$n$，但我们不能简单地忽略全职，因为成本是每一步都会累积的。 

相反，我们将图扩展为表示时间模数的层$n$, 最多给予$n \times n = 10^4$州。 每个州都是$(u, t)$在哪里$t$是当前的旋转索引。 我们从每个状态过渡到所有邻居，确定性地更新时间层。 

然后我们运行最短路径$(1, 0)$，但这仅给出了任意长度路径的成本，而不是精确的$k$步骤。 为了准确执行$k$步骤中，我们使用一种标准技巧：计算此扩展状态图中的最短路径，然后通过 DP 对转换的幂进行模拟或组合，有效地将一个完整旋转周期上的运动视为状态上的类似矩阵转换。 

自从$n \le 100$，我们可以一步预先计算状态之间的最佳成本转换，然后使用二进制提升$k$步骤。 每个步骤转换都是 100 个状态层上的最小加 DP，因此每个乘法是$O(n^3)$，我们就这么做了$O(\log k)$次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 随着时间的推移暴力破解 |$O(k \cdot n \cdot m)$|$O(nk)$| 太慢了|
 | 分层DP + 矩阵求幂|$O(n^3 \log k)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们将问题重新解释为分层系统，其中每一层对应于气体阵列的旋转状态。 由于旋转是确定性的，因此在一步之后位置和图层都会发生可预测的变化。 

我们定义一个DP转移矩阵$T$尺寸的$n \times n$， 在哪里$T[i][j]$表示从顶点出发的最小成本$i$到顶点$j$在固定旋转状态下正好一秒。 因为允许停留，$i \to i$始终是有效的转换。 

然而，轮换改变了成本模式，所以我们实际上需要$n$不同的转换矩阵，每个旋转偏移一个。 这些矩阵循环每一步。 

然后，我们在整个周期内构建一个组合过渡$n$步骤，这使系统返回到原始成本配置。 可以使用每步矩阵的重复最小加乘法来计算该组合转换。 

之后，我们对这个循环转换取幂来处理$k // n$完整周期，然后应用剩余的$k \bmod n$单独步骤。 

### 步骤

 1. 构建$n$邻接感知成本矩阵$A_0, A_1, \dots, A_{n-1}$， 在哪里$A_t[i][j]$是到达顶点的成本$i$在时间偏移处$t$，加上过渡的可行性$j$。 这编码了移动和等待。 这是必要的，因为成本取决于当前的旋转状态。 
2. 定义最小加矩阵乘法以组合跨时间步长的转换。 这让我们可以将逐步的动态分解为更长的间隔。 
3. 按顺序将矩阵相乘$A_0 \circ A_1 \circ \cdots \circ A_{n-1}$获得全周期转移矩阵$C$。 这代表在一个完整的旋转周期内在顶点之间移动的最佳成本。 
4. 计算$C^{k // n}$在最小加代数下使用二进制求幂。 每个乘法合并两个全周期转换。 
5. 从初始状态向量开始$dp_0$， 申请$C^{k // n}$在所有完整周期后获得最佳成本。 
6. 处理剩余的$k \bmod n$通过顺序应用相应的步骤$A_t$矩阵按顺序排列。 
7. 答案是恰好经过之后所有结束顶点的最小值$k$步骤。 

### 为什么它有效

 每一步之后系统的状态仅取决于当前顶点和旋转偏移量，并且旋转偏移量随周期确定性地演化$n$。 这导致了有限自动机$n$阶段。 任意长度的路径$k$唯一地分解为完整循环加上余数。 由于最小加矩阵乘法精确地捕获了固定长度间隔上的最佳子结构，因此对全周期转换求幂可以保留重复段之间的最优性。 剩余的前缀是显式处理的，因此不会引入近似值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

def mat_mul(A, B, n):
    C = [[INF] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        for k in range(n):
            if Ai[k] == INF:
                continue
            Bik = B[k]
            aik = Ai[k]
            for j in range(n):
                v = aik + Bik[j]
                if v < C[i][j]:
                    C[i][j] = v
    return C

def mat_vec(A, v, n):
    res = [INF] * n
    for i in range(n):
        for j in range(n):
            val = v[j] + A[j][i]
            if val < res[i]:
                res[i] = val
    return res

n, m, k = map(int, input().split())
a = list(map(int, input().split()))
g = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    g[u-1].append(v-1)

# build per-step matrices
def build_matrix(offset):
    A = [[INF]*n for _ in range(n)]
    for u in range(n):
        cost = a[(u + offset) % n]
        for v in g[u]:
            A[u][v] = min(A[u][v], cost)
        A[u][u] = min(A[u][u], cost)
    return A

# initial dp
dp = [INF]*n
dp[0] = 0

cycle = None

# build cycle matrix
for t in range(n):
    M = build_matrix(t)
    if cycle is None:
        cycle = M
    else:
        cycle = mat_mul(cycle, M, n)

def mat_pow(M, exp):
    res = [[INF]*n for _ in range(n)]
    for i in range(n):
        res[i][i] = 0
    while exp:
        if exp & 1:
            res = mat_mul(res, M, n)
        M = mat_mul(M, M, n)
        exp >>= 1
    return res

full = k // n
rem = k % n

cycle_pow = mat_pow(cycle, full)
dp = mat_vec(cycle_pow, dp, n)

for t in range(rem):
    M = build_matrix(t)
    dp = mat_vec(M, dp, n)

print(min(dp))
```该代码构建了一个与时间相关的转换系统，其中每个顶点根据旋转相位具有不同的成本。 每个矩阵编码系统的一个步骤，包括移动和停留。 这些矩阵组成一个完整的循环，然后取幂以模拟大$k$。 

矩阵乘法写成min-plus形式：加法对应于累积气体，min对应于选择最佳路径。 向量乘法将转换应用于当前最著名的成本。 

求幂减少了对$k$从线性到对数，这是必要的$k$最多$10^9$。

 ## 边缘情况

 具有单个顶点的最小图测试算法是否正确处理自循环和不移动的重复旋转。 状态永远不会改变位置，所以答案只是该顶点的成本之和$k$旋转，并且 DP 应正确累积该旋转而不需要转换。 

具有相同成本的完全连接图会检查算法是否不会使转换过于复杂。 每一步都有相同的成本，因此任何路径都应该产生相同的总成本。 DP 不得通过矩阵构造引入人为的不对称性。 

在旋转测试随时间对齐后，只有一个顶点变得廉价的图。 正确的策略可能需要等待或循环以将进入时间与零成本阶段同步，并且分层DP必须捕获时间依赖性而不是将成本视为静态。
