 ## 解决方案
 ## 问题理解

 有$m$完整的套牌，每套都包含相同的内容$n$卡值。 将所有牌组混合在一起后，有$mn$实体卡牌总数，每个值都准确显示$m$次。 

亚历克斯随机采取$n$从这一大堆牌中取出牌，并将它们用作该技巧的工作牌组。 

然后，观众从该工作牌中随机选择一张牌，记住它的值，然后将其放回原处。 亚历克斯洗牌并随机抽一张牌。 假设亚历克斯没有施展任何魔法，只是随机均匀地抽牌，我们必须计算抽出的牌与记住的牌具有相同值的概率。 

输入包括$n$和$m$。 输出是一个浮点数，即技巧成功的概率。 

约束很小，仅达到$1000$，但有趣的部分是通过分析找到概率。 任何尝试枚举所有可能的方法$n$- 卡片选择是不可能的，因为此类选择的数量是$$\binom{mn}{n},$$即使对于中等值，它也会变得天文数字般大。 

一些边缘情况值得关注。 

什么时候$n=1$，工作牌组始终只包含一张牌。 观众选择那张牌，亚历克斯必须抽同一张牌，所以答案总是$1$。 例如：```
1 5
```正确的输出是：```
1
```包含因子的公式$mn-1$当分母除以零时$n=m=1$，因此这种情况必须单独处理。 

另一个容易犯的错误是假设每个值在工作台中最多出现一次。 例如：```
2 2
```选定的牌组可以是$\{A,A\}$，这使得成功成为必然。 忽略重复项会产生错误的概率。 

## 方法

 蛮力观点很有用，因为它揭示了我们实际需要的数量。 

假设特定的选定牌组包含计数$$c_1,c_2,\dots,c_n,$$在哪里$c_i$是值的副本数$i$， 和$$c_1+c_2+\cdots+c_n=n.$$观众选择价值$i$有概率$c_i/n$。 更换后，Alex 吸取价值$i$有概率$c_i/n$。 对于这个固定套牌，成功概率为$$\sum_{i=1}^{n}\frac{c_i}{n}\cdot\frac{c_i}{n} = \frac{1}{n^2}\sum_{i=1}^{n} c_i^2.$$强力解决方案将枚举每个可能选择的牌组，计算该数量，并对所有选择进行平均。 选择的数量是$\binom{mn}{n}$，这是完全不可行的。 

关键的观察是我们只需要期望值$$\sum c_i^2.$$所有卡的面值都是对称的。 让$X$是所选牌组中某一特定值的副本数。 

然后$$E\!\left[\sum_{i=1}^{n} c_i^2\right] = nE[X^2].$$所以答案就变成了$$\frac{E[X^2]}{n}.$$现在$X$服从超几何分布。 

有$mn$卡总数。 

确切地$m$其中有选定的值。 

我们画$n$牌。 

因此$$X \sim \text{Hypergeometric}(N=mn,\ K=m,\ n).$$对于超几何随机变量，$$E[X] = \frac{nK}{N},$$和$$\mathrm{Var}(X) = n\frac{K}{N} \left(1-\frac{K}{N}\right) \frac{N-n}{N-1}.$$替代$N=mn$和$K=m$,$$E[X]=1,$$和$$\mathrm{Var}(X) = \frac{(n-1)(m-1)}{mn-1}.$$自从$$E[X^2] = \mathrm{Var}(X)+E[X]^2,$$我们得到$$E[X^2] = 1+\frac{(n-1)(m-1)}{mn-1}.$$因此$$P = \frac{1}{n} \left( 1+\frac{(n-1)(m-1)}{mn-1} \right).$$这对于实施来说已经足够了。

 ## 算法演练

 1. 阅读$n$和$m$。 
2.特殊情况处理$n=m=1$。 

在这种情况下，只有一张牌存在，所以成功概率恰好是$1$。 
3. 计算$$\mathrm{Var}(X) = \frac{(n-1)(m-1)}{mn-1}.$$这是所选牌组中出现的固定值副本数量的方差。 

1. 计算$$E[X^2] = 1+\mathrm{Var}(X).$$的平均值为$X$等于$1$， 所以$E[X]^2=1$。 

1. 计算$$P=\frac{E[X^2]}{n}.$$根据对称性，期望值$\sum c_i^2$等于$nE[X^2]$。 

1. 将结果打印为浮点数。 

### 为什么它有效

 对于固定选择的牌组，成功概率等于$$\frac{1}{n^2}\sum c_i^2.$$总体答案是对所有随机牌组选择的这个数量的期望。 期望的线性让我们可以替换$n$对称项由$nE[X^2]$， 在哪里$X$计算单个值的副本。 自从$X$是超几何的，其均值和方差是准确已知的。 代入这些公式可得出准确的预期成功概率。 每一步都是等式，因此算法计算真实概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if n == 1 and m == 1:
        print(1.0)
        return

    var = (n - 1) * (m - 1) / (n * m - 1)
    ans = (1.0 + var) / n

    print(ans)

solve()
```推导后直接实现。 

唯一的特殊处理是$(n,m)=(1,1)$。 封闭式方差包含因子$mn-1$分母中，分母变为零。 从概率上来说，答案是微不足道的$1$因为只有一张卡存在。 

所有算术运算均以浮点形式执行。 所需精度仅为$10^{-6}$，所以标准Python`float`算术就足够了。 

不需要循环，因为整个解决方案简化为评估恒定大小的公式。

 ## 边缘情况

 考虑尽可能最小的输入：```
1 1
```存在的只有一张卡。 观众选择那张牌，亚历克斯则抽出同一张牌。 算法立即返回`1.0`在评估方差公式之前，避免除以零并产生正确的答案。 

考虑：```
3 1
```每个值都只存在一次。 所选牌组始终是三张不同牌的完整集合。 该算法计算$$\mathrm{Var}(X)=0,$$因为固定值肯定只会出现一次。 然后$$P=\frac{1}{3}.$$这与从三张不同的卡片中抽出记住的卡片的直观概率相匹配。 

考虑：```
1 5
```工作牌只包含一张牌，尽管一大堆牌中有五张该值的副本。 该算法计算$$\mathrm{Var}(X)=0, \qquad P=1.$$观众和亚历克斯被迫与同一张牌互动，因此成功是有保证的。 

最后，考虑重复很重要的情况：```
2 2
```粗心的解决方案可能会假设始终选择两个不同的值并回答$1/2$。 超几何计算正确地考虑了诸如$\{A,A\}$，这会增加概率。 结果的答案是$$\frac{2}{3},$$与示例输出匹配。
