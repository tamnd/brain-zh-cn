 ## 解决方案
 ## 问题理解

 我们得到一个整数多重集，它是通过采用两个序列（一个严格递增，一个严格递减）将它们的所有元素合并在一起，然后对结果进行打乱而创建的。 

合并数组内的原始顺序会丢失。 我们只知道出现的值。 我们的任务是重建任何有效的序列对，其组合元素与给定的数字完全匹配。 

关键要求是递增序列不能包含重复值，递减序列也不能包含重复值。 由于最终的多重集来自这两个序列的并集，因此每次出现的值都必须分配给这两个序列之一。 

输入大小达到$2 \cdot 10^5$。 任何尝试许多不同的分配或搜索可能性的解决方案都会立即被排除。 我们需要一些接近的东西$O(n \log n)$，这是涉及排序时的自然目标。 

一些边缘情况值得关注。 

考虑：```
3
5 5 5
```值 5 出现了 3 次。 一份副本可以放入递增序列，一份副本放入递减序列，但没有地方放置第三个副本。 由于两个序列都必须保持严格，因此同一序列中任何值都不能出现多次。 正确答案是：```
NO
```如果一个粗心的解决方案只检查是否存在重复项，那么就会忽略大于二的频率是不可能的。 

考虑：```
4
1 2 3 4
```每个值都出现一次。 正确的构造是将所有值放入递增序列并将递减序列留空：```
YES
4
1 2 3 4
0
```某些实现不必要地将每个值强制放入两个序列中，并且在唯一值上失败。 

另一个微妙的情况是：```
4
1 1 2 2
```存在一个有效的答案：```
Increasing: 1 2
Decreasing: 2 1
```递减序列必须严格按照递减顺序打印。 如果我们只是按升序收集重复值，我们将输出`1 2`，并没有减少。 

## 方法

 暴力方法会尝试将每个出现的事件分配给递增序列或递减序列，然后检查这两个序列是否可以排列以满足严格的排序要求。 

如果出现一个值$k$有时，每个副本都有任务选择。 即使对于适度的输入，这也会呈指数级增长。 和$n = 2 \cdot 10^5$，可能的分配数量是完全不可行的。 

问题的结构提供了更强有力的观察。 

由于两个序列都是严格的，因此一个值在每个序列中最多只能出现一次。 这意味着任何值总共最多可能出现两次。 当某个频率超过两次时，答案是不可能的。 

假设一个值只出现一次。 它可以安全地放入递增序列中。 

假设一个值正好出现两次。 一个副本必须进入递增序列，另一个副本必须进入递减序列。 别无选择。 

这完全决定了任务。 

对不同值进行排序后，我们将每个不同值的一个副本放入递增序列中。 这会自动产生严格递增的序列。 

每个出现两次的值都会为递减序列贡献一个额外的副本。 如果我们存储这些重复值并最终反转它们的排序顺序，结果就会严格递减。 

整个问题简化为计算频率和对不同值进行排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 读取所有数字并计算每个值的出现频率。 
2. 如果任何值出现两次以上，则打印`"NO"`并停止。 

一个值在递增序列中最多出现一次，在递减序列中最多出现一次，因此出现频率 3 或更多是不可能的。 
3. 按升序对所有不同的值进行排序。 
4. 通过对每个不同的值仅取一次来构建递增序列。 

由于值已排序且不同，因此序列是严格递增的。 
5. 对于频率恰好为 2 的每个值，将一个副本添加到第二个列表中。 

这些是无法保留在递增序列中的额外副本。 
6. 颠倒第二个列表。 

按升序收集重复值。 将它们反转会产生严格递减的序列。 
7. 打印`"YES"`并输出两个序列。 

### 为什么它有效

 每个出现频率为 1 的值都必须恰好出现在一个序列中，将其放入递增序列中绝不会产生冲突。 

每个频率为 2 的值必须为每个序列贡献一份副本。 将一份副本放入递增序列并将一份副本放入递减序列是唯一可能的有效分配。 

递增序列按升序包含每个不同值一次，因此它是严格递增的。 

递减序列恰好包含重复的值，每个值出现一次，按降序排列，因此它是严格递减的。 

由于每个事件都被分配一次，并且大于 2 的频率被拒绝，因此只要存在解，生成的序列就会形成原始多重集的有效分区。 

## Python 解决方案```python
import sys
from collections import Counter

input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

freq = Counter(a)

for cnt in freq.values():
    if cnt > 2:
        print("NO")
        sys.exit()

inc = []
dec = []

for x in sorted(freq):
    inc.append(x)
    if freq[x] == 2:
        dec.append(x)

dec.reverse()

print("YES")
print(len(inc))
if inc:
    print(*inc)
else:
    print()

print(len(dec))
if dec:
    print(*dec)
else:
    print()
```频率表是中心数据结构。 它会立即检测到某个值出现两次以上的不可能情况。 

递增序列是根据排序后的不同值构建的。 使用不同的值可以自动保证严格性。 

递减序列恰好包含那些出现两次的值。 顺序很重要。 在升序遍历过程中收集重复项会得到一个递增的列表，因此我们在打印之前将其反转。 

空序列被显式处理。 问题允许它们，所以当序列长度为零时，我们仍然打印所需的行。

# helper: run solution on input string, return output string
import sys
import io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    a = list(map(int, input().split()))

    freq = Counter(a)

    for cnt in freq.values():
        if cnt > 2:
            return "NO"

    inc = []
    dec = []

    for x in sorted(freq):
        inc.append(x)
        if freq[x] == 2:
            dec.append(x)

    dec.reverse()

    out = []
    out.append("YES")
    out.append(str(len(inc)))
    out.append(" ".join(map(str, inc)))
    out.append(str(len(dec)))
    out.append(" ".join(map(str, dec)))

    return "\n".join(out)

# sample
assert run("7\n7 2 7 3 3 1 4\n").startswith("YES")

# minimum size
assert run("1\n5\n") == "YES\n1\n5\n0\n"

# all equal, impossible
assert run("3\n7 7 7\n") == "NO"

# duplicates exactly twice
assert run("4\n1 1 2 2\n") == "YES\n2\n1 2\n2\n2 1"

# all distinct
assert run("5\n1 2 3 4 5\n") == "YES\n5\n1 2 3 4 5\n0\n"

# boundary style case
assert run("2\n0 200000\n") == "YES\n2\n0 200000\n0\n"

 ## 边缘情况

 考虑：```
3
5 5 5
```5 的频率为 3。在频率扫描期间，算法立即检测到大于 2 的计数并打印：```
NO
```这是正确的，因为两个严格序列最多可以包含任何值的两个副本。 

考虑：```
4
1 2 3 4
```所有频率都等于一。 

该算法构造：```
inc = [1, 2, 3, 4]
dec = []
```递减序列为空，这是问题明确允许的。 

考虑：```
4
1 1 2 2
```该算法构建：```
inc = [1, 2]
dec before reverse = [1, 2]
```反转后：```
dec = [2, 1]
```两个序列都是严格的，并且原始多重集中的每个出现都只使用一次。 

考虑：```
5
1 1 2 3 3
```该算法产生：```
inc = [1, 2, 3]
dec = [3, 1]
```递增序列仍然严格递增，递减序列仍然严格递减，并且所有五个原始出现都被考虑在内。 这证实了只要值不出现超过两次，重复的值就可以安全地共存。
