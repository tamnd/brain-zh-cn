 ## 解决方案
 ## 问题理解

 我们得到了一系列标记，但每个标记的主题都丢失了。 只有两个科目，我们确切地知道每个科目有多少分。 如果受试者 1 必须接收`a`标记，然后受试者 2 自动接收`b = n - a`标记。 

我们的任务是将每个分数分配给两个科目之一，以便两个科目平均值的总和尽可能大。 在所有最佳分配中，我们必须输出字典顺序最小的主题标签序列。 

平均值为：$$\frac{\text{sum of subject 1 marks}}{a} + \frac{\text{sum of subject 2 marks}}{b}$$标记本身很小，只有1到5个，但是标记的数量可以达到$10^5$。 这立即排除了对作业的任何指数搜索。 甚至$O(n^2)$在 Python 中这种规模已经存在风险了。 我们需要一些接近的东西$O(n \log n)$，通常建议排序或贪婪处理。 

棘手的部分是最大化总平均值并不是唯一的要求。 如果几个分配达到相同的最大值，我们必须选择字典顺序最小的分配。 只优化平均值而忽略平局决胜的解决方案可能会悄然失败。 

考虑这个例子：```
n = 4
a = 2
b = 2
marks = [5, 1, 5, 1]
```如果我们将两个 5 放入同一主题，则平均值变为：```
(5 + 5) / 2 + (1 + 1) / 2 = 5 + 1 = 6
```如果我们平均分配它们：```
(5 + 1) / 2 + (5 + 1) / 2 = 3 + 3 = 6
```两者都是最佳的。 但字典顺序上最小的分配更喜欢标记为较早的位置`1`。 仅按值排序的粗心贪婪策略可能会产生错误的排序。 

当一个物体比另一个物体小得多时，就会出现另一种微妙的情况：```
n = 5
a = 1
b = 4
marks = [1, 2, 3, 4, 5]
```最佳策略是将最大的标记放入较小的分母中，因为那里的每个点对最终表达式的贡献更大：```
5 / 1 + (1 + 2 + 3 + 4) / 4 = 5 + 2.5 = 7.5
```天真的“平衡主题”直觉在这里会严重失败。 

另外一个陷阱来自于同等分数。 认为：```
n = 5
a = 2
b = 3
marks = [4, 4, 4, 4, 4]
```每个作业都有完全相同的分数。 整个问题归结为产生字典顺序上最小的有效序列。 正确答案是：```
1 1 2 2 2
```因为我们希望尽早将位置分配给主题 1。 

## 方法

 暴力解决方案在概念上很简单。 我们尝试一切可能的选择`a`位置属于主题 1，计算两个平均值，并保留最佳分配。 因为有：$$\binom{n}{a}$$可能的任务，即使对于中等程度的人来说，这也变得完全不可行`n`。 例如，与`n = 40`和`a = 20`，可能性的数量已经超过$10^{11}$。 和`n = 10^5`，穷举搜索是不可能的。 

关键的观察来自于重写目标函数。 假设有一个标记`x`分配给科目 1。它对总分的贡献是：$$\frac{x}{a}$$如果将相同的标记分配给主题 2，则其贡献变为：$$\frac{x}{b}$$所以每个标记都独立贡献`x/a`或者`x/b`。 

这意味着问题实际上是在问：

 “哪些分数应该获得更大的系数？”

 如果`a < b`， 然后：$$\frac{1}{a} > \frac{1}{b}$$因此，较大的分数应该属于主题 1。如果`b < a`，那么较大的分数应该属于科目 2。 

这将问题转化为贪心排序问题。 较小的组应该获得最大的分数。 

之后，词典编纂要求就成为剩下的挑战。 假设科目 1 是较小的一组，应该获得最大的分数。 在同等分数中，为主题 1 提供较早的索引会产生按字典顺序排列的较小答案。 因此，当价值相同时，我们应该优先考虑较小的指数。 

如果受试者 2 是较小的一组，则情况相反。 由于我们希望较早的职位成为`1`只要有可能，我们就应该推迟给科目2分配位置。因此，在同等分数中，后面的索引应该分配给科目2。 

这个单一的决胜规则就是问题的全部微妙之处。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\binom{n}{a} \cdot n)$|$O(n)$| 太慢了|
 | 最优贪心 + 排序 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 阅读所有标记及其原始索引。 
2. 确定哪个主体的尺寸较小。 

较小的科目在目标函数中具有较大的系数，因此它应该获得最大的分数。 
3. 按值降序对标记进行排序。 

这将最有价值的标记放在第一位，这正是贪婪选择所需要的。 
4. 小心处理字典顺序中的相等值。 

如果主题 1 是较小的组，则在相等的值中我们按升序对索引进行排序。 较早的职位变为`1`，使最终序列按字典顺序更小。 

如果主题 2 是较小的组，则在相等的值中我们按降序对索引进行排序。 这会延迟分配`2`到更早的位置，再次按字典顺序最小化最终序列。 
5. 采取第一个`min(a, b)`将元素从排序顺序中取出并分配给较小的主题。 

所有剩余的位置都属于更大的主题。 
6. 按原始顺序构造最终答案数组并打印。 

### 为什么它有效

 目标函数是线性的：$$\sum \frac{x_i}{a} + \sum \frac{y_j}{b}$$每个分数独立获得任一系数`1/a`或者`1/b`。 较大的系数始终属于较小的主体规模。 因此，每个最佳解决方案都必须将最大的分数放在较小的主题上。 

一旦数值确定，无论排名如何，相同的分数贡献相同。 唯一剩下的自由是字典顺序。 将较早的索引分配给主题 1 可以最小化序列，因为`1 < 2`。 上述打破平局的规则正是实现了这一点，同时保持了最优​​性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a, b = map(int, input().split())
    t = list(map(int, input().split()))

    arr = []

    if a <= b:
        # Subject 1 is smaller
        for i, x in enumerate(t):
            arr.append((-x, i))

        arr.sort()

        ans = [2] * n

        for j in range(a):
            _, idx = arr[j]
            ans[idx] = 1

    else:
        # Subject 2 is smaller
        for i, x in enumerate(t):
            arr.append((-x, -i))

        arr.sort()

        ans = [1] * n

        for j in range(b):
            _, neg_idx = arr[j]
            idx = -neg_idx
            ans[idx] = 2

    print(*ans)

solve()
```解决方案首先将每个标记与其原始位置配对。 我们不能丢失索引，因为输出必须遵循原始顺序。 

两个分支对应哪个主题较小。 如果主题 1 较小，我们希望为其分配最大的分数。 排序依据`(-value, index)`给出关系的降序值和升序索引。 这会自动生成按字典顺序排列的最小分配。 

第二个分支稍微微妙一些。 当主题 2 较小时，我们仍然希望那里有最大的分数，但现在为主题 2 分配较早的位置会损害字典顺序，因为`2`大于`1`。 排序依据`(-value, -index)`使后来的同等位置首先被选择。 

答案数组完全使用较大的主题标签进行初始化。 然后我们精确地覆盖较小主题所需的位置数量。 

在排序中使用负值可以避免编写自定义比较器，并保持实现的简洁和快速。

 ## 边缘情况

 考虑所有标记都相同的情况：```
5
2 3
4 4 4 4 4
```每个作业都会产生相同的总平均值，因为所有值都相等。 算法进入分支`a <= b`, 排序依据`(value descending, index ascending)`，并将前两个位置分配给主题 1。输出变为：```
1 1 2 2 2
```这是字典顺序上最小的有效分配，因为最早的可能位置会收到标签`1`。 

现在考虑相反的不平衡：```
5
1 4
1 2 3 4 5
```主体 1 的大小为 1，因此其系数最大。 该算法分配单个最大值`5`对于主题1。任何其他选择都会降低客观价值。 生成的任务是：```
2 2 2 2 1
```最后，检查微妙的等值平局情况：```
4
2 2
5 1 5 1
```两个科目的大小相同，因此最大化分数并不关心哪 5 个去哪里。 按字典顺序排列的最小答案应将前面的 5 个分配给主题 1：```
1 2 1 2
```由于在选择主题 1 时，排序对相等值使用升序索引，因此算法会自动生成正确的排序。
