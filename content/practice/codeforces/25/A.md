 ## 解决方案
 ## 问题理解

 我们得到一个序列`n`自然数，其中`n`至少为 3，至多为 100，并且每个数字至多为 100。在这些数字中，除了一个数字外，所有数字都具有相同的奇偶性（偶数或奇数），并且恰好有一个数字不同。 我们的任务是确定这个“奇一”数字在序列中的位置，从 1 开始计算位置。 

问题的规模很小。 和`n`限制为 100，我们可以负担得起直接检查每个数字的算法，而不必担心效率。 主要困难不在于原始计算，而在于正确识别哪个数字打破了奇偶校验模式。 

当前几个数字没有明确确定多数奇偶校验时，就会出现微妙的边缘情况。 例如，如果序列是`3 2 7`，我们不能仅通过查看前两个数字就立即得出多数奇偶性的结论 - 需要仔细检查以确保我们选择真正不同的单个数字。 

## 方法

 最直接的方法是蛮力：对于每个数字，计算有多少个数字是偶数和多少个奇数，然后选择与大多数数字具有不同奇偶性的那个。 这种方法之所以有效，是因为我们保证只有一个数字是不同的。 为了`n`最多 100 个，这最多需要几百次操作 - 对于现代处理器来说微不足道 - 因此性能不是问题。 

允许更清晰的解决方案的关键见解是我们不需要检查整个序列来确定多数奇偶校验。 查看前三个数字就足够了。 如果这些数字中至少有两个具有相同的奇偶性，则该奇偶性为多数。 一旦我们知道了多数奇偶校验，我们就可以扫描一次序列以找到不同的数字。 这减少了不必要的检查，并使逻辑简单且健壮。

 ## 算法演练

 1.读取元素个数`n`以及数字的顺序。 我们需要列表中的数字，以便我们可以对它们进行索引。 
2. 通过对每个模 2 计算前三个数字的奇偶校验。这三个奇偶校验确定序列中的多数奇偶校验，因为它们中至少有两个必须匹配。 
3. 确定多数平价。 如果前三个数字中有两个或两个以上是偶数，则多数是偶数； 否则，大多数是奇数。 
4. 迭代完整的数字序列。 对于每个数字，计算其奇偶校验并将其与多数奇偶校验进行比较。 
5. 一旦我们找到一个奇偶校验与多数不匹配的数字，就输出它的位置（从 1 开始的索引）并终止。 这保证是具有不同奇偶校验的唯一编号。 

其原理：不变的是，只有一个数字与其他数字不同。 通过确定前三个数字的多数奇偶校验，我们保证扫描序列的其余部分将正确识别异常值而不会产生歧义。 由于输入保证确保了单一不同的奇偶性，因此我们永远不会冒误报的风险。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
nums = list(map(int, input().split()))

# determine majority parity from the first three numbers
first_three = nums[:3]
parities = [x % 2 for x in first_three]
majority_parity = 0 if parities.count(0) > 1 else 1

# find the index of the number with different parity
for i, num in enumerate(nums):
    if num % 2 != majority_parity:
        print(i + 1)
        break
```该代码首先对前三个元素进行切片以建立多数奇偶校验。 计算中的零`parities`检查有多少个是偶数。 然后，循环直接搜索违反多数奇偶校验的数字。 我们向索引添加 1，以将基于 0 的 Python 索引转换为问题所需的基于 1 的索引。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    first_three = nums[:3]

 ## 边缘情况

 如果异常值是第一个元素，例如，`3 2 4 6`，前三个奇偶校验是`[1, 0, 0]`，多数为偶数，迭代发现第一个元素不同并输出`1`。 

如果离群值在最后，则迭代继续到最后，正确输出`n`。 

如果异常值位于中间，例如，`1 1 2 1`，从前三个数字正确确定多数奇偶校验，扫描序列发现第三个元素不同。 

所有这些边缘情况都证实，使用前三个元素来确定多数奇偶校验就足够了，并且扫描循环始终识别违反多数奇偶校验的单个数字。
