[CF 1950A - 楼梯、山顶还是两者都不是？](https://codeforces.com/problemset/problem/1950/A)

 **评分：** 800
 **标签：** 实施
 **求解时间：** 1m 4s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们得到了三位数，`a`,`b`， 和`c`，并且必须对它们的关系进行分类。 

当值严格从左到右增加时，序列称为 **楼梯**，这意味着`a < b < c`。 

当中间值严格大于两个邻居时，序列称为**峰值**，这意味着`a < b`和`b > c`。 

如果两个条件都不满足，我们打印`"NONE"`。 

每个测试用例仅包含三个数字，最多有 1000 个测试用例。 由于每个分类只需要几次比较，因此每个测试用例的工作量是恒定的。 即使是简单的实现也只执行少量操作，因此效率永远不是问题。 

主要挑战是正确处理严格的不平等问题。 相等的值不满足任一定义。 

考虑输入：```
1
1 1 2
```正确答案是：```
NONE
```仅检查序列是否非递减的粗心实现可能会错误地将其分类为楼梯。 

另一个容易的错误是将局部最大值视为峰值而不验证左侧上升：```
1
3 2 1
```正确答案是：```
NONE
```虽然`2 > 1`，条件`3 < 2`是假的，所以这不是峰值。 

当所有值都相等时，会出现第三种边缘情况：```
1
0 0 0
```正确的输出是：```
NONE
```严格的增长和严格的峰值条件都不成立。 

## 方法

 最直接的方法是检查所有三个数字并测试它们是否满足定义。 由于问题本身使用不等式定义了阶梯和峰值，因此我们可以简单地评估这些不等式。 

暴力解决方案将检查每种可能的模式并相应地比较值。 由于每个测试用例恰好包含三位数字，因此它已经在恒定时间内运行。 即使有 1000 个测试用例，总工作量仍然很小。 

关键的观察是没有隐藏的结构可供发现。 这个问题纯粹是一个实施练习。 定义可以直接翻译成代码。 

首先检查是否`a < b < c`。 如果为真，答案是`"STAIR"`。 

否则，检查是否`a < b > c`。 如果为真，答案是`"PEAK"`。 

如果两个条件都不匹配，则答案必须是`"NONE"`。

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`a`,`b`， 和`c`。 
3. 检查是否`a < b < c`。 

这完全符合楼梯的定义。 
4. 如果前面的条件不成立，检查是否`a < b > c`。 

这完全符合峰的定义。 
5. 如果两个条件都不成立，则输出`"NONE"`。 

### 为什么它有效

 该问题为两个有效分类提供了完整的定义。 

序列是楼梯当且仅当`a < b < c`。 一个序列是峰值当且仅当`a < b > c`。 这些条件是互斥的，因为一个值不能同时满足`b < c`和`b > c`。 

该算法直接测试阶梯定义，然后直接测试峰值定义。 任何剩余的序列都不满足两个定义，必须分类为`"NONE"`。 由于每个可能的输入都恰好属于这些情况之一，因此该算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    a, b, c = map(int, input().split())

    if a < b < c:
        print("STAIR")
    elif a < b > c:
        print("PEAK")
    else:
        print("NONE")
```第一部分读取测试用例的数量。 

对于每个测试用例，读取三位数字并将其存储在`a`,`b`， 和`c`。 

条件`a < b < c`使用Python的链式比较语法。 相当于检查两者`a < b`和`b < c`。 

如果该条件失败，代码将测试`a < b > c`，这相当于检查两者`a < b`和`b > c`。 

顺序很重要，只是因为我们想打印单个答案。 实际上，这两个条件不可能同时成立。 

任何涉及相等值的情况都会自动归结为`"NONE"`因为这两个定义都需要严格的不平等。

 ## 边缘情况

 考虑：```
1
1 1 2
```算法检查`1 < 1 < 2`，这是错误的，因为`1 < 1`是假的。 然后它检查`1 < 1 > 2`，这也是假的。 输出是`"NONE"`。 这正确地处理了平等。 

考虑：```
1
3 2 1
```楼梯条件失败是因为`3 < 2`是假的。 峰值条件也失败，因为`3 < 2`是假的。 输出变为`"NONE"`。 这可以防止将递减序列错误地标记为峰值。 

考虑：```
1
0 0 0
```两者都不`0 < 0 < 0`也不`0 < 0 > 0`是真的。 算法打印`"NONE"`，它符合需要严格不等式的定义。 

考虑：```
1
2 5 5
```楼梯条件失败是因为`5 < 5`是假的。 峰值条件失败是因为`5 > 5`是假的。 结果是`"NONE"`。 这会发现一个常见的错误，即相等的相邻值被意外地视为有效。
