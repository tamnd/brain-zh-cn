 ## 解决方案
 ## 问题理解

 我们被要求生成一个由更大的棋盘图案组成的棋盘图案$2 \times 2$瓷砖。 每个图块要么完全充满角色`#`或完全充满`.`。 网格的大小由输入整数决定$n$，最终的网格具有尺寸$2n \times 2n`. The top-left $2 \times 2$ 瓷砖总是`#`，并且瓷砖在水平和垂直方向上以棋盘方式交替。 

例如，当$n=2$，网格是$4 \times 4$，以及左上角$2 \times 2$瓷砖是`#`。 它的右边邻居是`.`，下面的邻居是`.`，对角邻居是`#`。 

限制是适度的。$n$最多可以为 20，因此最大网格大小为$40 \times 40$，它足够小，我们可以在内存中构建整个网格并打印它。 时间复杂度不是这里的限制因素，但我们必须仔细遵守模式规则。 

可能导致幼稚实现失败的边缘情况包括$n=1$，其中网格只是$2 \times 2$。 粗心的方法可能会尝试交替单个细胞而不是$2 \times 2$块，产生错误的输出。 另一个潜在的错误来源是瓷砖未对齐，因此行或列在从一个瓷砖移动时不会保留交替图案。$2 \times 2$阻止到下一个。 

## 方法

 蛮力方法是迭代数据中的每一行和每一列。$2n \times 2n$网格，计算该特定单元格是否应该`#`或者`.`基于其行和列。 对于每个单元格，我们可以将行索引和列索引除以 2 来确定哪个$2 \times 2$它所属的图块，然后使用这些图块索引之和模 2 来确定字符。 这种做法是正确的，并且可以最大限度地$n=20$它导致$1600$每个测试用例的操作，可以忽略不计。 

关键的见解是我们不需要比这更复杂的东西。 该问题结构允许我们通过简单的整数除法和奇偶校验将每个单元直接映射到其图块。 不需要递归或动态编程。 每行都由两个相同字符的重复序列组成，因为每个图块跨越两列。 同样，每个图块跨越两行，因此行内容对于图块的第二行重复一次。 认识到$2 \times 2$瓷砖的性质使我们能够通过简单的嵌套循环有效地生成网格。

 ## 算法演练

 1.读取测试用例数量`t`。 循环每个测试用例。 
2. 对于每个测试用例，请阅读`n`并将网格大小计算为`2n`。 
3. 迭代`2n`使用索引的行`i`。 通过整数除法确定这是哪个水平平铺行：`tile_row = i // 2`。 
4. 为当前行初始化一个空字符串。 迭代一遍`2n`使用索引的列`j`。 通过整数除法确定这是哪个垂直平铺列：`tile_col = j // 2`。 
5. 计算奇偶校验`tile_row + tile_col`。 如果是偶数，则追加`#`到当前行字符串； 如果是奇数，则追加`.`。 这实现了交替平铺图案。 
6. 构建行字符串后，立即打印。 重复此操作，直到打印出测试用例的所有行。 
7. 不要在测试用例之间打印多余的空行。 

为什么有效：每个$2 \times 2$瓷砖由`(i//2, j//2)`。 对图块行索引和列索引求和并检查奇偶校验可确保相邻图块交替字符。 重复两行两列的每个图块字符会产生所需的`2x2`块。 不变的是网格中的每个位置都正确映射到其图块，从而映射到正确的字符。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    size = 2 * n
    for i in range(size):
        row = ''
        tile_row = i // 2
        for j in range(size):
            tile_col = j // 2
            if (tile_row + tile_col) % 2 == 0:
                row += '#'
            else:
                row += '.'
        print(row)
```我们首先读取测试用例的数量。 对于每种情况，我们将总网格大小确定为`2n`。 对于每一行`i`,`tile_row`识别哪个$2 \times 2$我们位于水平块中。内部循环使用逐个字符构建行`(tile_row + tile_col) % 2`来决定是否是`#`或者`.`。 这确保了正确的交替块。 行会立即打印，而不会将整个网格存储在内存中，尽管存储对于这种大小也很好。 使用整数除法和奇偶校验是有效构建棋盘图案的常用技术。
