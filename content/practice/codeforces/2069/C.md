 ## 解决方案
 ## 问题理解

 我们被要求计算一个数组中“美丽”子序列的数量，其中每个元素都是 1、2 或 3。一个美丽的子序列必须至少有三个元素，除了第一个元素之外的每个元素的左侧都必须有一个较小的元素，除了最后一个元素之外的每个元素都必须在其右侧有一个较大的元素。 换句话说，子序列必须在某处增加，在某处减少，确保它不是单调的。 输入提供多个测试用例，每个测试用例指定数组的长度和数组本身。 输出是美丽子序列的计数模 998244353。 

这些约束允许单个数组中最多包含 200,000 个元素，并且所有测试用例中总共允许包含 200,000 个元素。 这排除了任何显式检查每个可能子序列的方法，因为这将需要多达 2^200,000 次操作，这是不可行的。 元素只有 1、2 或 3 个这一事实表明利用这个小值范围的解决方案是可能的。 边缘情况包括最小长度为 3 的数组、具有所有相同值（没有漂亮的子序列）的数组以及仅存在单个递增-递减模式的数组。 

例如，如果数组是`[1, 1, 1]`，正确的输出是 0，因为没有元素大于第一个，因此没有子序列可以满足美观条件。 在不检查左小和右大条件的情况下计算子序列的简单方法会错误地计算这些子序列。 

## 方法

 蛮力方法迭代长度为三或以上的所有子序列，检查每个子序列的条件，并计算满足条件的子序列。 显式生成所有子序列需要 O(2^n) 时间，而检查每个子序列是否美观则需要 O(n) 次操作。 对于 n = 200,000，这太慢了。 

关键的见解是，由于值仅限于 1、2、3，因此我们可以通过跟踪以每个数字结尾的序列的计数以及在尊重美丽序列条件的同时扩展它们的方法来对子序列进行建模。 具体来说，一个漂亮的子序列必须在某处按顺序至少包含一个 1、一个 2 和一个 3。 这允许我们在扫描数组时跟踪长度为 1、2 和 3 的子序列的计数的动态编程方法。 每个元素都可以扩展现有的子序列或根据其值启动新的子序列。 这将问题从指数复杂度降低到每个测试用例 n 的线性复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(2^n) | O(2^n) | 太慢了|
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化三个计数器：`count1`对于以 1 结尾的子序列，`count12`对于以 2 结尾且出现过 1 的子序列，以及`count123`对于以 3 结尾且已出现 1 和 2 的子序列。全部从零开始。 这些计数器代表形成部分美丽序列的方式数量。 
2. 迭代数组中的每个元素。 对于等于 1 的元素，递增`count1`1，因为以 1 开头的新子序列可以从这里开始。 对于等于 2 的元素，递增`count12`经过`count1`因为每个以 1 结尾的子序列都可以通过这个 2 进行扩展。对于等于 3 的元素，递增`count123`经过`count12`因为形式1→2的每个子序列都可以通过这个3进行扩展，形成满足美感条件的子序列。 
3. 继续扫描阵列，更新计数如上。 每个计数器仅取决于先前的计数器，而不取决于完整的子序列列表。 模运算可确保计数不会溢出。 
4. 扫描阵列后，`count123`保存该数组中美丽子序列的总数。 

这是有效的，因为计数器增量地跟踪所有有效子序列，并通过元素扩展子序列的顺序隐式确保左小和右大条件。 每个长度为 3 或更长的美丽子序列都是通过以这种方式扩展较小的子序列来解释的。 长度超过 3 的序列会自动计数，因为计数器会累积附加附加元素的方式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        count1 = 0
        count12 = 0
        count123 = 0
        
        for x in a:
            if x == 1:
                count1 = (count1 + 1) % MOD
            elif x == 2:
                count12 = (count12 + count1) % MOD
            elif x == 3:
                count123 = (count123 + count12) % MOD
        
        print(count123)

if __name__ == "__main__":
    solve()
```计数器以保持不变的方式更新：`count1`计算可以扩展 2 的序列，`count12`计算可以扩展 3 的序列，并且`count123`计数完成了美丽的子序列。 模运算可防止溢出。 仅使用三个整数可确保 O(1) 空间。

 | 2 | 2 | 1 | 1 | 0 |
 | 3 | 3 | 1 | 1 | 1 |

 输出为 1，与预期输出相符。

 ## 边缘情况

 对于完全由 3 组成的数组，`[3,3,3]`，计数器保持不变`count1=0`,`count12=0`,`count123=0`，因此输出为 0。对于以 2 开头的数组，`[2,3,1]`,`count1`在看到 1 之前不会增加，因此错误开始的序列不计入在内
