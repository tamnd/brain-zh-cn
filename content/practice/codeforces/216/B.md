 ## 解决方案
 ## 问题理解

 我们可以将学生建模为无向图。 每个学生都是一个顶点，每对敌人都会产生一条边。 我们希望将剩下的学生分成两队，人数相等，这样一队内就不会有任何优势。 用图的术语来说，我们需要一个二分图，因为敌人最终必须始终处于相反的两侧。 

如果某个连接组件不是二分的，则必须从该组件中删除至少一名学生。 移除后，剩下的学生总数也必须是偶数，因为两队的人数必须相同。 

该图最多有 100 个顶点和 100 个边，因此即使相当慢的图算法也会通过。 在限制范围内，所有顶点的 DFS 或 BFS 都是微不足道的。 更有趣的部分是准确了解何时需要移除。 

每个学生最多拥有2个学位的条件严重限制了图结构。 每个连接的组件都是：

 - 一条路径，
 - 一个循环，
 - 或一个孤立的顶点。 

路径总是二分的。 偶循环也是二分循环。 奇数循环不是二分的，删除一个顶点会将其变成一条路径。 

一种微妙的边缘情况是孤立的学生。 考虑：```
3 0
```所有学生都是独立的，因此该图是二分图。 尽管如此，我们还是不能将 3 名学生分成相等的两队。 一名学生必须坐在外面，所以答案是`1`。 

另一个容易犯的错误是忘记了每个奇数周期都需要移除一次，即使剩余学生总数随后变为偶数。 

例子：```
3 3
1 2
2 3
3 1
```这是一个三角形。 该图不是二分图。 除去一名学生会在其他两名学生之间留下优势，这是有效的。 正确答案是`1`。 

一个更微妙的案例结合了这两个问题：```
6 3
1 2
2 3
3 1
```有一个大小为 3 的奇数环和三个孤立的顶点。 从循环中删除一个顶点后，总共有 5 个学生，这仍然是奇怪的。 另外一名学生也必须缺席。 正确答案是`2`。 

只计算奇数周期的粗心实现会错误地打印`1`。 

## 方法

 暴力方法会尝试删除所有学生子集。 对于每个子集，我们将检查剩余图是否是二分图以及剩余学生的数量是否为偶数。 由于有`2^n`子集，这很快就变得不可能了。 即使是为了`n = 100`，搜索空间非常大。 

图结构给出了更清晰的方向。 由于每个顶点的度数最多为 2，因此连接组件非常简单。 唯一有问题的结构是奇怪的循环。 

连接的二分组件始终可以用两种颜色着色，这意味着它的顶点可以分为两个无敌人的组。 一个奇怪的循环打破了这个属性，因为绕着循环走会迫使颜色发生矛盾。 

所以问题归结为两个观察结果：

 首先，每个奇数循环都会强制执行一次删除。 

其次，修复所有奇数环后，剩下的图是二分图。 如果剩下的学生人数是奇数，我们再任意删除一名学生，使总数为偶数。 

DFS 着色自然地检测奇数周期。 每当我们尝试用相反的颜色给相邻的顶点着色并发现冲突时，该连接的组件就不是二分的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * (n + m)) | O(2^n * (n + m)) | O(n + m) | 太慢了 |
 | 最佳 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 为图构建邻接表。 

每个学生都存储与他们相关的敌人列表。 
2. 维护一个初始化为的颜色数组`-1`。 

值为`-1`表示该顶点尚未被访问过。 颜色`0`和`1`用二分着色代表两支球队。 
3. 迭代所有顶点。 

每当发现未访问的顶点时，就从它启动 DFS。 
4. 在 DFS 期间，为相邻顶点分配交替颜色。 

如果邻居未被访问，则给它相反的颜色并继续 DFS。 
5. 如果我们找到一条边连接两个具有相同颜色的顶点，则连接的分量不是二分的。 

因为每个分量的最大度数为 2，这意味着该分量包含奇数环。 
6. 对于每个非二分分量，将答案加 1。 

从奇数循环中删除一名学生总是会破坏循环并将组件变成二分图。 
7. 处理完所有组件后，计算剩余的学生人数。 

如果`n - answer`为奇数，则答案加 1。 

剩下的学生必须分成相等的两队，因此人数必须是偶数。 
8. 打印最终答案。 

### 为什么它有效

 DFS 着色正确地表征了二分图。 当且仅当在双着色期间没有边连接具有相同颜色的顶点时，图才是二分图。 

由于这里每个连通分量的度数最多为 2，因此唯一可能的非二分结构是奇数循环。 从这样的循环中删除一个顶点会破坏循环并留下一条二分路径。 

修复所有奇数循环后，该图变为二分图。 任何二分图都可以分为两个无敌组。 唯一剩下的问题是平价。 如果剩余学生总数为奇数，则不可能获得相等的队伍，因此必须多移除一名学生。 

由于每个奇数周期至少需要一次删除，并且奇偶校验可能还需要一次删除，因此该算法会生成最小可能的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)

def dfs(start):
    stack = [start]
    color[start] = 0

    while stack:
        u = stack.pop()

        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                stack.append(v)
            elif color[v] == color[u]:
                return False

    return True

removed = 0

for i in range(1, n + 1):
    if color[i] == -1:
        if not dfs(i):
            removed += 1

remaining = n - removed

if remaining % 2 == 1:
    removed += 1

print(removed)
```邻接表紧凑地存储图并支持高效的遍历。 自从`n`和`m`很小，递归或迭代 DFS 都可以，但迭代 DFS 完全避免了递归深度问题。 

这`color`数组处理访问状态和二分着色。 未访问过的顶点停留在`-1`。 在遍历过程中，邻居总是使用 XOR 接收相反的颜色`1`。 

DFS 返回`False`一旦发现冲突边缘。 这立即告诉我们该组件包含一个奇数循环。 

一个微妙的细节是，我们对每个非二分组件精确计算一次移除。 由于每个顶点的度数最多为 2，因此连通分量不能包含多个独立的奇环。 在一般图表中，此快捷方式将失败。 

仅当所有奇数周期固定后才会进行奇偶校验调整。 从奇数循环中删除顶点会改变剩余学生的总数，因此之后必须检查奇偶性。

 ## 边缘情况

 考虑完全断开的情况：```
3 0
```DFS 独立访问每个顶点，并且从未发现着色冲突。`removed = 0`图形处理后。 自从`3`学生留下来，奇数，所以又删除了一名学生。 算法打印`1`。 

现在考虑一个三角形：```
3 3
1 2
2 3
3 1
```DFS颜色`1`和`0`,`2`和`1`， 和`3`和`0`。 加工边缘时`(3,1)`，两个端点都有颜色`0`，因此该分量是非二分分量。`removed`变成`1`。 其余学生平等`2`，这已经是偶数了。 最终答案是`1`。 

最后，考虑多个组件：```
8 5
1 2
2 3
3 1
4 5
6 7
```组件`{1,2,3}`是一个奇数循环，因此必须删除一名学生。 成分`{4,5}`和`{6,7}`是二分的，并且顶点`8`是孤立的。 去除一次后，`7`学生们留下来，仍然很奇怪。 该算法再删除一名学生并输出`2`。 

这证实了两个独立的移除来源：固定奇数周期和固定奇偶校验。
