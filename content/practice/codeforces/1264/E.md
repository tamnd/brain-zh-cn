 ## 问题理解

 我们获得了完整的锦标赛$n$每对球队只进行一场比赛并且每场比赛都有一个获胜者的球队。 其中一些结果已经确定。 任务是为所有剩余的比赛分配方向，以便最终的有向完整图最大化循环排序的获胜三元组的数量。 

“美丽三重”对应于定向 3 周期：对于三个不同的团队$A, B, C$，我们想要$A \to B$,$B \to C$， 和$C \to A$。 顺序很重要，因此每个有向循环都会贡献三个不同的有序三元组。 

这相当于在必须尊重某些固定边的锦标赛中最大化定向 3 周期的数量。 

限制因素$n \le 50$立即建议$O(n^3)$甚至$O(n^4)$推理是可以接受的，但是任何指数级的东西$n$不是。 该结构强烈暗示了对方向的全局优化，而不是局部贪婪决策，因为每条边都会影响许多三元组。 

一个微妙的问题是，部分信息可能已经强制某些周期或禁止某些局部结构。 例如，如果三角形已经有两条固定边形成路径$A \to B \to C$，然后选择$C \to A$完成一个循环并立即添加三个有序三元组，因此我们必须小心，不要在以后打破这样的机会。 

另一个边缘情况是完全固定的锦标赛。 在这种情况下，我们只是评估一个已知的结构，任何试图“改进”它的算法都不能修改边缘。 

## 方法

 关键的困难在于目标计数全局定向 3 个周期，但每条边都参与许多这样的三元组。 一种简单的方法会尝试剩余边缘的所有方向，即$2^{\text{empty edges}}$。 即使对于中等$n$，这是一个天文数字，因为直到$\binom{50}{2} \approx 1225$存在边缘。 

更结构化的观点来自于重写目标。 每个顶点三元组对答案贡献 0 或 3，具体取决于它是否形成有向循环。 所以我们实际上是在选择方向来最大化一致循环三角形的数量。 

现在考虑修复一种顶点顺序。 如果我们将锦标赛解释为排列加上每个前缀内的结构，我们自然会导致子集上的动态规划或基于排序的构造。 然而，子集 DP 是$O(n2^n)$，太大。 

关键的观察结果是，该问题相当于最大化有向 3 循环的数量，这也相当于最大化锦标赛中循环三角形的数量。 这可以转化为三元组上的最大重量反馈弧方向问题，并且这允许基于流的构造。 

我们为每个边缘方向分配一个二进制变量。 如果每个三元组形成一个环，则贡献 1，这是三个边上的局部条件。 这是一个经典的“锦标赛上局部三重势之和最大化”结构，可以通过将每对选择编码为节点状态并将每个三角形编码为约束超边来简化为最小割公式。 自从$n$很小，我们可以构建一个流网络$O(n^2)$节点和$O(n^3)$边（概念上），但我们通过使用标准约简来避免显式的三元组枚举：我们选择与最大化循环三角形一致的顶点排序，这对应于通过从最佳解决方案中的输出结构导出的势对顶点进行排序。 

官方方法中使用的构造性解决方案比完整的超图流程更简单：我们观察到，在最佳锦标赛中，可以排列顶点，以便对于每一对，方向由我们可以在尊重固定边的同时贪婪分配的分数确定。 然后，我们构建与最大评分顺序一致的任何完成，确保所有自由边都按该顺序从早到晚定向，反之亦然，具体取决于最大化循环一致性。 这将问题简化为计算与约束一致的最佳排序，这可以通过基于流的排序或迭代改进来完成。 

此约束范围最简单的可实现版本是将每对方向选择建模为变量，并通过子集上的最大权重传递闭包样式 DP 进行求解，但在子集上使用位掩码 DP 进行优化是不可能的$n=50$。 相反，我们使用已知的结果，即最大化循环三角形相当于在变换客观对称性后最大化排序表示中的后向边的数量。 这导致计算最小化非循环三元组的排序，可以使用从固定边导出的分数差贪婪地找到非循环三元组。 

最后，一旦我们确定了顶点的总顺序，我们就将每个自由边的方向与该顺序一致，同时尊重固定边。 固定边保证不会与最佳排序相矛盾，因为任何矛盾都会减少可实现的三角形数量，并且可以被吸收到分数调整中。 

这将问题简化为构建一致的排序以最大化二次得分，这可以使用成对排序变量的最小割公式来解决。

 ## 算法演练

 我们构建一个顶点排序，对接近最佳的锦标赛方向进行编码，然后将除固定约束之外的所有边的方向与该排序一致。 

1. 构建一个完整的图，其中每对$(i, j)$有一个权重，代表定向的益处$i \to j$而不是$j \to i$。 对于一个三角形$(i, j, k)$，每个一致的循环方向都会贡献固定的增益，因此这些成对权重总结了所有三元组的贡献。 这将全局三重计数减少为嵌入全局排序中的成对贡献。 
2. 构建一个流网络，其中每个顶点对应一个团队，并将成对排序决策编码为剪切选择。 剪切将顶点分成代表它们在最终排序中的位置的层。 
3. 每场固定比赛$u \to v$，强制执行一个约束$u$必须出现在之前$v$通过在流程图中添加无限容量边来进行排序。 这确保我们永远不会违反给定的结果。 
4. 求解最小割以获得产生偏序的分区。 通过重复选择约束允许最早按照切割结构引起的拓扑顺序放置的顶点来重建完整的排序。 
5. 顺序确定后，将每个剩余边缘按此顺序从早到晚定向，除非它已经固定。 由于构造，固定边缘保证一致。 
6. 输出生成的邻接矩阵。 

### 为什么它有效

 每个有向三角形仅当其三个边循环对齐时才会产生正向贡献，这仅取决于顶点三元组之间的相对排序约束。 流构造以任何切割对应于一致的全局方向的方式对成对决策进行编码。 无限容量边确保我们永远不会违反已经进行的比赛，而最小切割结构确保我们最大化编码为边权重的总三重贡献。 由于每个三角形都分解为其三个成对关系的贡献，因此优化切割可以全局优化循环三角形的总数。

import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    fixed = [[-1] * n for _ in range(n)]  # 1 if i->j, 0 if j->i

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        fixed[u][v] = 1
        fixed[v][u] = 0
