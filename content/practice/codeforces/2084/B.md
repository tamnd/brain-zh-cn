 ## 解决方案
 ## 问题理解

 给定一个正整数序列，我们需要确定是否可以在重新排列后将该序列分成两个连续的部分，使得第一部分中的最小值等于第二部分的最大公约数。 换句话说，我们可以任意重新排序数组，然后选择一个分割点，其中左段的最小值与右段的 GCD 匹配。 

输入保证高达$10^4$测试用例，每个都有$n$最多$10^5$整数，以及$n$所有测试用例最多是$10^5$。 整数本身可以非常大，最多可达$10^{18}$。 这立即排除了需要检查所有可能的分割或排列的算法。 任何解决方案迭代$O(n^2)$可能性会太慢。 我们必须找到一个$O(n)$或者$O(n \log n)$每个测试用例的方法。 

一个关键的边缘情况是所有元素都相等。 例如，如果序列是$[7,7,7]$，我们可以在任意位置之后进行分割，并且最小值和GCD都将为7，所以答案是“是”。 当最小值出现多次但不是所有剩余元素的除数时，会出现另一种微妙的情况。 例如，$[1,2,3]$如果 1 是左最小值且右 GCD 不是 1，则无法拆分以满足条件。仅检查某处是否存在全局最小值的粗心算法可能会失败。 

## 方法

 蛮力方法将尝试序列的所有排列和所有分割位置，计算左侧的最小值和右侧的 GCD。 这在理论上是有效的，因为任何正确的分割都必须满足给定的相等性，但在实践中，有$n!$排列，每一个都有$n-1$分裂，即使对于$n=10$。 

观察问题结构，我们注意到可以匹配右段 GCD 的左段最小值的唯一候选者是数组的全局最小值。 这是因为左段中的任何最小值都不可能小于全局最小值，并且任何正整数的 GCD 至多是其中最小的。 因此，如果存在分割，则该值$\min(left) = \gcd(right)$必须等于数组的总体最小值。 

鉴于此，我们可以简化问题：让$m$是数组的全局最小值。 那么任何不是 的倍数的元素$m$不能在正确的段中，因为该段的 GCD 必须等于$m$。 因此，解决方案简化为检查所有元素是否可被整除$m$删除其他元素后可以形成连续的右段。 如果是，我们可以对数组重新排序，使这些元素位于末尾，而左侧段包含所有剩余元素。 如果不是，分裂是不可能的。 

这一观察结果将问题从阶乘时间简化为线性时间检查，只需一次扫描即可确保最小值的所有非倍数都可以到达左侧段。 我们不需要动态计算任何 GCD，因为我们已经知道一组数字的 GCD 都可以被整除$m$至少是$m$，并且右段中的任何数字都必须是$m$。

 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和数组$a$。 
2. 计算全局最小值$m = \min(a)$。 这是两者的唯一候选值$\min(left)$和$\gcd(right)$。 
3. 验证数组中的所有元素都等于$m$或除以$m$。 任何不能被整除的元素$m$必须在左段。 
4. 划分所有倍数后$m$进入右段，其余进入左段，保留左侧最小值$m$正确的 GCD 是$m$以及。 如果假定的右段中的任何元素不能被整除$m$，输出“否”。 
5. 如果检查通过，则输出“Yes”。 

工作原理：该算法依赖于左段的最小值不能小于全局最小值，并且右段的 GCD 不能小于其中的最小数的不变式。 通过使全局最小值成为两者的候选者，任何违规（右段中的元素不能被整除）$m$）将使平等变得不可能。 重新排序可确保所有倍数$m$可以进入正确的段，同时保留条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd
from functools import reduce

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        m = min(a)
        if all(x % m == 0 or x == m for x in a):
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
```该解决方案首先计算线性时间内的全​​局最小值。 条件检查数组中的每个元素一次，验证整除性$m$。 使用`all()`是有效的，在第一次失败时停止。 Python 的整数类型可处理的值最多为$10^{18}$没有溢出。

 ## 边缘情况

 处理所有元素相等的边缘情况，因为全局最小值等于每个元素，因此整除性检查通过。 对于最小值为 1 的数组，所有元素都可以被 1 整除，因此任何分割都有效。 具有不能被最小值整除的单个元素的数组无法通过检查，产生正确的“否”。 该算法可以正确处理大数，因为 Python 整数会自动扩展而不会溢出。
