 ## 解决方案
 ## 问题理解

 我们给出了一个部分填充的长度排列$n$，其中一些条目为零，表示缺失的数字。 目标是用剩余的数字填充零$1$到$n$形成完整的排列。 一旦我们有了完整的排列，我们就定义了“美感”分数。 美妙之处在于函数的所有连续子数组的总和$f$，它代表该子数组上两人游戏的结果。 

在游戏中，乌龟先移动并想要最大化第一个元素，而小猪第二移动并想要最小化它。 轮到海龟时，他选择一个索引$i$并取代$c_i$最少为$c_i$和$c_{i+1}$，去除$c_{i+1}$。 Piggy 做了同样的事情，但是替换了$c_i$最大为$c_i$和$c_{i+1}$。 当子数组长度为 1 时游戏结束，并且$f(c)$是最后一个元素。 

限制条件允许$n$最多 5000 个和最多 1000 个测试用例，但所有测试用例的总和$n$所有测试用例最多为 5000 个。这意味着我们需要一个大致为$O(n^2)$每个测试用例最坏的情况，以及$O(n^3)$会太慢。 边缘情况包括完全为空的数组（全为零）、已完成的数组（无零）或中间有零的数组。 尝试所有可能的零填充的天真的方法会立即失败，因为有$n!$要考虑的排列。 

## 方法

 暴力方法会尝试一切可能的方法来填充零，然后计算$f(c)$对于每个子数组。 计算$f(c)$天真的需要模拟游戏，它本身与子数组的长度是线性的。 对所有子数组求和需要$O(n^3)$工作，并枚举所有填充物将成为缺失数字的阶乘。 这显然是不可行的。 

关键的洞察力是理解游戏机制。 对于任何子数组，Turtle 先移动，只能通过取最小值来减少数字，而 Piggy 可以通过取最大值来增加数字。 这让人想起列表上的“极小极大”游戏。 如果我们反转数组并计算每个数字的贡献作为子数组中的第一个元素，并进行交替的最小/最大操作，就会出现一种模式：如果数字按降序排序，Turtle 总是可以在从较大数字开始的子数组中获得更大的贡献。 这将问题简化为动态规划问题，其中对于给定的子数组，如果我们将最大的可用数字放置在 Turtle 受益最大的位置，则缺失数字的贡献将最大化。 

该解决方案使用动态规划来计算总和$f(c)$对于所有子数组，结合贪婪策略将缺失的数字放置在最大化总贡献的位置。 通过迭代所有子数组并将未知数视为变量来贪婪地填充，我们可以实现$O(n^2)$算法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（模拟所有排列）| O(n! * n^3) | O(n! * n^3) | O(n^2) | O(n^2) | 太慢了|
 | DP + 贪婪填充 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 首先，从给定的排列中提取缺失的数字。 将它们存储在按降序排列的列表中，因为当海龟首先移动时，较大的数字更能体现美感。 
2. 初始化一个2D数组`dp[i][j]`代表最大总和$f(c)$对于子数组`b[i:j+1]`。 最初，设置`dp[i][i] = b[i]`因为长度为 1 的子数组贡献了自己的值。 
3. 对于长度大于1的子数组，使用递推式：

 - 如果轮到海龟（按子数组的长度交替），他将选择应用后使值最大化的索引`min(c_i, c_{i+1})`。 对于填充的子数组，这相当于在考虑最佳播放时取两端的最小值。 
- 如果轮到小猪，他会选择使之后的值最小的索引`max(c_i, c_{i+1})`。 类似地，这简化为在最佳发挥下取两端的最大值。 
- 在实践中，由于游戏简化为极小极大结构，因此最优值`f(c)`是`c_1`如果 Turtle 首先在奇数长度数组上移动，或者`max/min`否则。 这允许计算`dp[i][j]`在给定的 O(1) 中`dp[i][j-1]`和`dp[i+1][j]`。 
4. 用剩余的最大数贪婪地在原数组中补零。 从左到右遍历数组； 如果出现零，则放置最大的可用数字。 这确保了 Turtle 从左侧开始受益于更多子阵列，从而增加了整体美感。 
5.填充后，迭代所有子数组并求和`f(c)`使用简化的极小极大递归。 将结果存储在`dp[i][j]`以避免重新计算。 
6. 总和`dp[i][j]`值以获得填充排列的整体美感。 

为什么有效：海龟总是先移动，因此左侧较大的数字会在更多子数组中产生更高的贡献。 Piggy 不能完全否定它们，并且极小极大结构确保用最大的可用数字填充零可以最大化所有子数组的总和。 DP 保证每个子阵列的最优贡献只被计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def compute_beauty(n, a):
    missing = sorted([x for x in range(1, n+1) if x not in a], reverse=True)
    b = a[:]
    idx = 0
    for i in range(n):
        if b[i] == 0:
            b[i] = missing[idx]
            idx += 1

    dp = [[0]*n for _ in range(n)]
    for i in range(n):
        dp[i][i] = b[i]

    for length in range(2, n+1):
        for i in range(n-length+1):
            j = i + length - 1
            if (length % 2) == 0:  # Piggy's turn (even)
                dp[i][j] = max(dp[i][j-1], dp[i+1][j])
            else:  # Turtle's turn (odd)
                dp[i][j] = min(dp[i][j-1], dp[i+1][j])

    total = sum(dp[i][j] for i in range(n) for j in range(i, n))
    return total

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(compute_beauty(n, a))
```我们首先识别缺失的数字并贪婪地放置它们。 DP表`dp[i][j]`商店`f(c)`对于每个子数组。 从 Turtle 开始的奇数长度子数组采用最小的可能选项，偶数长度子数组采用最大的选项。 最后总结一下一切`dp[i][j]`产生美丽。 边界处理是通过迭代从 2 到 n 的长度来仔细完成的。

 将缺失的数字 2 放在索引 1 处可以最大化海龟的优势。

 总和 = 3+2+1+2+1+3=12

 按降序填充可以达到最大的美感。
