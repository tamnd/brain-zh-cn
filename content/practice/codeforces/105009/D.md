 ## 解决方案
 ## 问题理解

 每个测试用例给出两个相同长度的数组。 您从左到右处理位置。 在位置`i`，你从值开始`a[i]`并可以选择将其乘以先前值的任何子集`a[1] ... a[i-1]`。 每个较早的值最多只能使用一次，您也可以选择不使用其中任何一个。 

选择这个子集并将所有内容相乘后，您只关心结果乘积的最后一位数字。 问题是能否准确得到这个数字`b[i]`作为个位数字。 

困难在于产品本身可能变得非常大，但只有最后一位数字很重要。 这立即表明所有计算都可以简化为算术模 10，并且可以通过标准化最后一位数字来处理负值。 

这些限制迫使我们走向`O(n)`或者`O(n log n)`每个测试用例的解决方案。 由于跨测试用例的元素总数可以达到`5 * 10^5`，任何显式尝试子集或探索指数组合的解决方案都会很快失败。 在最坏的情况下，即使每个测试用例都采用二次方法也太慢。 

一个微妙的点是乘以零会破坏之前的所有贡献。 如果任何先前的元素为零，则无论其他因素如何，最后一组可到达的数字都会折叠为单个值。 另一个微妙之处是，先前元素的不同子集可以通过多种方式生成相同的最后一位数字，因此我们实际上处理的是小型有限状态空间中的可达性，而不是子集上的组合。 

一个天真的错误是认为每个索引可以通过尝试先前元素的所有子集来独立解决。 为了`n = 2000`，这已经变得不可行了，因为`2^n`子集。 另一个不正确的简化是仅跟踪数字是否已作为先前的数字出现`a[i] % 10`，忽略乘法相互作用。 例如，有数字`2`和`5`可以访问`0`（因为`2 * 5 = 10`），仅存在模型会错过这一点。 

## 方法

 暴力解释很简单：对于每个索引，枚举先前元素的所有子集，乘以`a[i]`通过每个子集，计算最后一位数字，并检查是否有等于`b[i]`。 这是正确的，因为它直接遵循定义。 不过，每个位置都有`i - 1`之前的元素，所以这是`O(2^(i-1))`每个索引的工作量都会爆炸，超出任何可行的限制。 

关键的观察是我们从不需要完整的值，只需要模 10 的乘法。这将问题简化为处理数字的乘法半群`{0..9}`。 我们重复地乘以一个基数`a[i] % 10`通过先前看到的数字的子集乘积。 

我们不再考虑子集，而是动态地重新解释该过程。 在每一步中，我们都会维护可以使用先前元素的任何子集形成的所有可能的乘积 (mod 10)。 当新元素到达时，每个现有的可达数字可以保持不变或乘以新数字。 这是一个经典的“小状态空间上的子集闭包”，其中状态空间只有 10 个元素。 

这将问题转化为维护一个大小为 10 的位掩码，表示可以从已处理元素的子集中实现哪些最后的数字。 每个新数字都会通过将旧状态及其乘积与新数字合并来更新此掩码。 

然后我们可以通过检查是否回答每个查询`b[i]`可以通过乘以实现`a[i] % 10`与前缀中任何可到达的子集产品。

 ## 算法演练

 我们将每个前缀视为维护一个集合`S`可能的乘法结果模 10，可以使用先前元素的任何子集形成。 

1. 初始化`S = {1}`。 这代表产生乘积 1 的空子集。我们需要恒等式，因为不相乘不会改变该值。 
2. 对于每个索引`i`, 计算`x = a[i] % 10`。 如果`x`为负数，将其归一化为`[0, 9]`使用`(x + 10) % 10`。 这确保了模乘的一致性。 
3. 更新状态前，检查是否`b[i]`可以使用当前前缀来实现。 这意味着检查是否存在某些`s ∈ S`这样`(s * x) % 10 == b[i]`。 如果是，则输出`Y`，否则输出`N`。 
4. 通过考虑是否使用来更新可达集`a[i]`在未来的子集中。 对于每个现有状态`s`，我们可以保留它或通过乘以来扩展它`x`。 所以我们建立一个新的集合`S' = S ∪ { (s * x) % 10 for all s in S }`。 
5. 分配`S = S'`并继续。 

我们检查后更新的原因是`a[i]`在它自己的决定中不允许，只有前面的元素是允许的。 

### 为什么它有效

 不变量是处理后索引`i - 1`, 集合`S`恰好包含由任何子集形成的乘积的所有可能的最后一位数字`a[1..i-1]`。 更新步骤保留了正确性，因为每个子集`a[1..i]`要么排除`a[i]`（已经在`S`）或包含它（通过乘以捕获`x`与每一个元素`S`）。 由于模 10 的乘法是闭乘的，因此不会出现其他值。 这保证了成员资格查询`S`正确回答任何前缀子集产品的可达性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        # reachable last digits from subsets of processed prefix
        S = set([1])

        ans = []

        for i in range(n):
            x = a[i] % 10
            if x < 0:
                x += 10

            # query before updating with a[i]
            ok = False
            for s in S:
                if (s * x) % 10 == b[i]:
                    ok = True
                    break

            ans.append('Y' if ok else 'N')

            # update reachable set
            newS = set(S)
            for s in S:
                newS.add((s * x) % 10)

            S = newS

        out.append(''.join(ans))

    print('\n'.join(out))

if __name__ == "__main__":
    solve()
```该解决方案维护一组可实现的最后一位数字。 关键的实现细节是我们在插入之前使用当前前缀状态检查可行性`a[i]`，因为该问题只允许严格使用先前的元素。 然后，更新步骤扩展了未来指数的状态空间。 

Python 集合的使用是可以接受的，因为状态空间以 10 个可能的数字为界，因此每个集合操作实际上都是恒定时间。

 ## 边缘情况

 一个关键的边缘情况是零提前出现。 认为`a = [2, 0, 7]`。 加工后`2`，可达集是`{1, 2}`。 后`0`，每个涉及子集选择的产品包括`0`变成`0`，所以集合变成`{0, 1, 2}`但实际上未来的乘法将始终包括`0`作为主要吸收状态。 该算法正确地处理了这个问题，因为乘以`0`仅插入`0`，并且之前的所有状态仍然有效。 

另一个边缘情况是负数。 如果`a[i] = -19`，其位数为`9`。 使用模归一化可确保`-19 % 10`被视为`9`，保持正确性，因为最后一位算术忽略符号方向。 

最后，像许多一样重复数字`5`演示了指数子集计数折叠成模 10 的小循环结构。该算法从不显式跟踪子集，只跟踪可达残基，因此即使组合解释爆炸，它也能保持稳定。
