 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格，其中每个单元代表三种地形类型之一：可用的种植地、水源或不可用的封锁土地。 我们被要求计算有多少条高度恰好为两行的水平条是“有效的园艺条”。 

通过选择两个连续的行，然后选择这两行中的连续列段来定义条带。 在该矩形内，只允许种植土地和水源，因此不会出现阻塞的单元格。 此外，地带内的每个种植单元最多必须在曼哈顿距离内$k$来自整个网格中的至少一个水源单元（不一定位于带内）。 距离是在整个网格上测量的。 

一个关键的结构限制是没有两个水单元是垂直相邻的。 这可以防止列包含两个连续的孔，这在以后推理传播和范围覆盖时很重要。 

任务是计算所有满足这两个约束的高度为 2 的有效矩形。 

限制条件$n \le 2000$立即排除任何比粗略更糟糕的事情$O(n^2)$或者$O(n^2 \log n)$。 任何简单地枚举所有矩形并逐个单元检查距离的解决方案都会太慢，因为有$O(n^3)$可能的矩形，每个检查都是$O(n)$，导致$O(n^4)$。 

一个更微妙的限制是，距离取决于网格中任何位置的井，而不仅仅是带内的井。 这使得幼稚的子网格推理变得危险，因为条带的有效性取决于全局邻近信息。 

一些边缘案例暴露了常见的错误。 

如果某条带在网格中任何地方都没有水单元，但仍然有种植土地，则该条带无效，因为这些种植单元不能有距离$\le k$到任何水源。 例如，如果网格根本没有井并且$k \ge 1$，每条带子都不满足距离要求，因此答案为零。 

当种植单元靠近带外的井时，会出现另一种故障模式。 仅检查所选矩形内的孔的简单方法将错误地拒绝有效条带。 

最后，即使距离条件成立，包含被阻挡细胞的条带也会立即无效。 

## 方法

 暴力方法首先枚举每对相邻行，然后枚举每个可能的左右边界。 对于每个候选矩形，我们扫描其所有单元格，以确保不存在阻塞土地，并且每个种植单元格在曼哈顿距离内至少有一个水单元格$k$。 

这是正确的，但价格昂贵。 有$O(n^2)$行对的选择和$O(n^2)$柱段，生产$O(n^4)$矩形。 每个矩形最多包含$O(n^2)$在最坏的情况下，检查距离需要扫描所有水单元或计算每个查询的 BFS 距离。 这很快就超过了任何可行的运行时间。 

关键的观察是距离约束可以全局预先计算。 对于每个像元，我们可以使用多源 BFS 计算其到任何水源的最小距离。 经过这样的预处理后，条件“种植细胞在距离内”$k$” 变成一个恒定时间的查找。

 现在每个细胞都被标记为安全或不安全。 一条有效的条带必须满足两个独立的条件：它不包含被阻塞的细胞，并且每个种植细胞都是安全的。 

这将问题转化为对每对行的二进制矩阵中的所有全 1 子矩形进行计数，其中“一”表示允许该单元格（未阻塞，以及水或安全种植）。 

对于每一对行，我们将列压缩到指示有效性的二进制数组中，然后对所有条目都有效的连续段进行计数。 在这些部分中，我们还需要确保内部的任何种植单元都是安全的，但由于每个单元的安全性已经预先计算，因此这简化为简单的有效性检查。 

其余结构是标准的：对于每个行对，我们扫描列并计算最大连续有效段，然后添加每个段内的子数组数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^4)$|$O(n^2)$| 太慢了|
 | 最佳|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们首先将网格转换为距离约束已经解决的形式。 

1. 使用从所有水单元开始的多源 BFS 计算从每个单元到最近水源的最小曼哈顿距离。 每个水单元都以距离零进行初始化，并且 BFS 在四个方向上传播。 这是有效的，因为曼哈顿距离恰好对应于具有单位边的网格图中的最短路径长度。 
2. 如果每个单元格是水或者是 BFS 距离最大的种植地，则将每个单元格标记为“安全”$k$。 任何距离大于的种植单元$k$对于任何有效的条带都被视为无法使用。 
3. 现在考虑每对行$(r1, r2)$在哪里$r2 = r1 + 1$，因为条带必须正好是两行高。 对于每一对这样的列，我们从左到右处理列。 
4. 对于每一列$c$，检查两个单元格是否$(r1, c)$和$(r2, c)$可用（未被阻止）且安全。 如果任一被阻止或不安全，则将此列标记为对于当前行对无效。 
5. 现在我们在列上有一个二进制数组，指示哪些列可以参与该行对的有效条带。 我们扫描这个数组并找到有效列的最大连续段。 
6.对于每段长度$L$， 添加$L \cdot (L+1) / 2$答案，因为任何子段都对应于有效的水平条带。 
7. 对所有行对重复此操作并累加总数。 

关键思想是，一旦行对固定，列就变得独立，有效性就变成了一个简单的连续段计数问题。 

为什么它有效：

 BFS预处理确保每个种植单元已经知道它是否满足全局距离约束。 在此转换之后，有效性仅取决于局部细胞特性和不存在阻塞细胞。 由于每个条带都是高度为 2 的连续矩形，并且一旦行固定，列约束是独立的，因此每个有效条带完全对应于允许所有单元格的列子数组。 对最大有效段上的子数组进行计数可确保每个有效条带仅计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, k = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    INF = 10**9
    dist = [[INF] * n for _ in range(n)]
    q = deque()
    
    for i in range(n):
        for j in range(n):
            if grid[i][j] == 2:
                dist[i][j] = 0
                q.append((i, j))
    
    dirs = [(1,0), (-1,0), (0,1), (0,-1)]
    
    while q:
        x, y = q.popleft()
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if dist[nx][ny] > dist[x][y] + 1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))
    
    safe = [[False] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if grid[i][j] == 2:
                safe[i][j] = True
            elif grid[i][j] == 1 and dist[i][j] <= k:
                safe[i][j] = True
    
    ans = 0
    
    for r1 in range(n - 1):
        r2 = r1 + 1
        ok = [True] * n
        
        for c in range(n):
            if grid[r1][c] == 3 or grid[r2][c] == 3:
                ok[c] = False
            elif not safe[r1][c] or not safe[r2][c]:
                ok[c] = False
        
        c = 0
        while c < n:
            if not ok[c]:
                c += 1
                continue
            start = c
            while c < n and ok[c]:
                c += 1
            length = c - start
            ans += length * (length + 1) // 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```BFS 部分同时构建所有井的全局距离场，从而避免重新计算每个条带的距离。 这`safe`矩阵将距离约束压缩为布尔条件，这对于将问题简化为二维计数至关重要。 

行对循环强制执行条带高度约束。 在其内部，`ok`array 强制两行都可用并且满足安全约束。 最终扫描是经典的连续分段累积，其中每个最大分段贡献所有子分段。 

一个微妙的点是，无论距离如何，水细胞始终被认为是安全的，因为它们是有效性的来源。 另一个是被阻塞的单元格被单独处理并立即使列失效。

 ## 边缘情况

 没有井的网格展示了全局距离依赖性。 每个种植单元都不符合距离要求，因此每个条带都是无效的。 BFS 初始化不会产生可到达的源，从而使所有距离都是无限的，并且`safe`除孔外，矩阵在所有地方都变为假。 由于不存在井，因此不形成有效的段，并且正确的答案为零。 

所有有效性被单个阻塞单元破坏的条带显示了分段的工作原理。 该算法在预处理后独立处理每一列，因此单个无效列干净地将一个段分成两个独立的计数问题。 即使阻塞单元分布稀疏，这也可以防止过度计数并确保正确性。
