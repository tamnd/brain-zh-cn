 ## 解决方案
 ## 问题理解

 我们得到了一支足球队赛季的摘要。 每支球队都由五个数字来描述：他们赢了、平了、输了多少场比赛，以及他们在所有比赛中的总进球数和失球数。 问题不是重建赛季，而是推理这个总结是否可以准确地来自一组可能的个人比赛结果。 

每场比赛都会贡献一个有序的比分，例如 2-1 或 0-0。 从整个赛季的比赛中，我们可以计算胜、平、负以及总进球数和总进球数。 许多不同的匹配集合可能会产生相同的摘要。 任务是确定给定的摘要是否恰好允许对匹配结果进行一种或多种有效分解。 如果根本不存在分解，也被认为是无效的。 

一个关键的困难是输入并没有直接描述匹配的数量，但我们可以将其推断为 W + D + L。每个匹配恰好贡献一个结果类别，因此该部分是刚性的。 不确定性完全在于进球如何在与这些结果计数一致的比赛中分配。 

约束条件很大，测试用例多达 100000 个，值高达 10^9。 这立即排除了任何试图枚举匹配级别构造甚至目标动态规划的方法。 任何可行的解决方案都必须将每个测试用例减少为恒定时间或对数时间检查。 

当元组内部不一致时，会出现微妙的边缘情况。 例如，如果 W + D + L = 0 但目标非零，或者目标约束与可能的比赛结果相矛盾。 另一个棘手的情况是，相同的汇总统计数据可以通过结构不同的比赛分区来实现，特别是当目标可以在胜利和平局之间重新排列而不影响总数时。 

## 方法

 暴力解释是尝试构建所有可能的多组比赛，其胜、平、负次数与 W、D 和 L 匹配，总进球数与 G_f 和 G_a 匹配。 对于每个有效的构造，我们将检查它是否匹配相同的聚合状态。 这相当于将固定数量的比赛划分为标记的结果，然后在它们之间分配目标。 即使对于中等的 W + D + L，目标分布的分区数量也会组合增长。 即使对于小输入，这种方法也是不可能的，因为每次匹配都会引入多个整数自由度。 

关键的简化是停止从个体匹配的角度思考，而是从结构自由度的角度进行推理。 一场胜利贡献严格的正净胜球，平局贡献零，而失败则贡献负净胜球。 然而，目标本身比胜/平/负结构所暗示的更加灵活。 相同的W、D、L可以通过许多不同的内部分数分配来实现，只要赢是正的，输是负的，平局是零。 

总进球数约束 G_f 和 G_a 对所有比赛施加两个线性方程，但这些并不能唯一地确定如何在各个比赛之间分配进球，除非结构受到极大限制。 仅当分解没有内部自由时才会出现唯一性：每场比赛都必须强制进入与 W、D、L、G_f 和 G_a 兼容的精确得分线模式。

这将问题简化为检查系统是否承认多个有效的比赛级别分数分配。 决定性的观察是，当存在至少一场胜利或失败可以通过在比赛之间转移进球而不打破总数来调整时，就会出现模糊性。 除非配置“紧密”，否则就会发生这种情况，这意味着每场胜利都必须是强制方向上的 1-0 或 0-1，而每场平局都必须是 0-0，不能有任何懈怠来重新分配进球。 

因此，解决方案简化为检查进球总数是否完全由赢/平/负结构决定。 如果是的话，答案是独一无二的； 否则，存在多重分解。

 ## 算法演练

 我们独立处理每个测试用例并决定元组是否允许唯一的分解。 

1. 计算总匹配数为 N = W + D + L。如果 N 为零，则唯一有效的配置为空，唯一性完全取决于目标是否为零。 如果 G_f 和 G_a 都为零，则分解是唯一的。 否则的话，那是不可能的。 
2. 检查目标结构的可行性。 任何有效的一组比赛都必须在弱意义上满足 G_f ≥ 获胜次数和 G_a ≥ 失败次数，因为获胜需要在某处至少进一球，而失败则需要在某处至少丢一球。 如果违反这一点，则不存在任何分配。 
3. 确定绘图是否消耗所有自由度。 平局对两队的进球数相等，但如果允许进球，则可以通过多种方式进行分配。 如果 D > 0 并且 G_f 或 G_a 足够大以允许在匹配之间重新分配，则立即存在多个分解。 
4. 检查是否所有匹配都是强制的。 只有当每场比赛结果都有强制最低得分模式时，才会出现独特性：

 胜利必须全部为 1-0，

 损失必须都是0-1，

 平局必须全部是 0-0。 

在此约束下，总计必须满足：

 G_f = W 且 G_a = L。 
5. 如果两个等式都成立并且没有平局带来灵活性，则返回“Amazing”。 否则返回“下次好运”。 

### 为什么它有效

 关键的不变量是每种比赛类型都会贡献固定的最小进球贡献，但总进球数的任何松弛都会产生重新分配的自由度。 一旦 G_f 超过 W 或 G_a 超过 L，某些比赛就必须在强制最低进球数之外取得额外进球。 额外的容量可以在比赛之间转移，同时保留 W、D 和 L，这会产生至少两个不同的有效分解。 只有当两个目标总数完全匹配强制最小配置时，分解才是刚性的，保证了唯一性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        W, D, L, Gf, Ga = map(int, input().split())

        n = W + D + L

        # no matches
        if n == 0:
            if Gf == 0 and Ga == 0:
                out.append("Amazing")
            else:
                out.append("Better luck next time")
            continue

        # minimal forced goals assumption
        min_gf = W
        min_ga = L

        if Gf < min_gf or Ga < min_ga:
            out.append("Better luck next time")
            continue

        # uniqueness only when no slack exists
        if Gf == min_gf and Ga == min_ga:
            out.append("Amazing")
        else:
            out.append("Better luck next time")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实施遵循这样的理念：在任何一致的分解中，胜利至少贡献一个目标，失败至少贡献一个目标。 我们将提供的总数与这些强制最小值进行比较。 如果有任何多余的部分，则该多余部分可以在比赛之间重新分配，而不会影响 W、D 和 L，这立即意味着多个有效的构造。 

没有匹配的特殊情况会被显式处理，因为最小约束崩溃并且只有零目标有效。 

一个常见的错误是尝试仅使用 W + D + L 一致性而不强制执行目标可行性。 这允许将不可能的状态标记为有效。 另一个微妙的问题是忘记抽签根本不限制目标，这意味着任何非零抽签计数都会增加灵活性，除非一切都已经被平等所固定。

 ## 边缘情况

 像 W = D = L = 0 这样的零匹配情况很特殊，因为结构约束消失了。 如果目标也为零，则只有一种有效的分解：根本没有匹配项。 如果任一进球总数不为零，则无法分配比赛结果，因为每场比赛至少贡献零个进球，但在没有现有比赛的情况下无法产生非零总数。 

仅当目标与最小模式完全匹配时，只有胜利和失败的情况（例如 W = 2、L = 2）才是刚性的。 如果 Gf 或 Ga 较大，则至少一个匹配可以膨胀，同时在另一个匹配中进行补偿，从而创建多个有效结构。 

平局的情况会带来最强的歧义。 由于平局不会限制净胜球，因此通常可以在保留 W、D 和 L 的同时重新安排比赛中的任何正进球分配，除非总数已经完全固定在最小强制结构上。
