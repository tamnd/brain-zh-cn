 ## 解决方案
 ## 问题理解

 我们得到一个数字列表，我们必须将其分成不重叠的两组，并且一起包含每个元素。 每个组必须至少包含两个元素。 一旦分割确定，我们就计算每个组的值范围，定义为其最大元素和最小元素之间的差。 目标是选择分割，以便两个组最终得到完全相同的范围，并且在所有有效分割中，我们希望这个共同范围尽可能大。 

关键的困难在于，这种情况并不局限于某一群体。 关于一个元素的去向的决定会同时影响两组的可实现范围。 这立即表明任何依赖于尝试所有分区的解决方案都会太慢。 

输入大小可以高达 100000 个元素，这排除了任何二次或更糟的情况。 即使像检查所有可能的分割点或枚举子集之类的事情也是不可能的，因为分区的数量呈指数增长。 唯一可行的解​​决方案是对数组进行排序，然后以线性或对数时间推理结构。 

当许多元素相同时，就会出现微妙的边缘情况。 例如，如果所有元素都相等，则每个子序列的范围为零，但我们仍然需要两个子序列都至少有两个元素。 当最佳解决方案需要交错排序数组不同部分的元素而不是采用连续的段时，就会出现另一个棘手的情况。 最优组必须是连续的天真假设常常会导致错误的答案。 

## 方法

 暴力破解的想法是枚举将数组分成两个子序列的所有方法，检查两个子序列的大小是否至少为 2，计算每个组的最小值和最大值，并验证它们的范围是否相等。 这是正确的，因为它直接测试问题的定义。 然而，对大小为 n 的数组进行分区的方法数量为 2^n，即使尽早修剪无效的分割也没有足够的帮助，因为范围计算本身是 O(n)。 这导致 O(n·2^n) 过程不可行。 

关键的观察结果是，只有每个组的极值很重要，因此在对数组进行排序后，任何有效的解决方案都可以通过选择定义每个组的最小和最大边界的排序顺序的两个不相交间隔来解释。 如果我们固定范围值 d，则每个组必须仅包含某个区间 [x, x + d] 内的元素。 问题变成了检查我们是否可以将所有元素放入两个具有相同长度的区间中。 

这大大减少了搜索空间。 我们没有探索分区，而是尝试由排序数组引发的可能结构，并验证它们是否可以分成两个具有相等跨度的有效组。 通过固定潜在边界并使用两个指针或预先计算的前缀和后缀信息，我们可以验证每个候选者的线性时间甚至总体摊销线性时间的可行性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·2^n) | O(n·2^n) | O(n) | 太慢了|
 | 排序结构+区间推理| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

1. 对数组进行排序。 这确保了每个候选组的最小值和最大值出现在我们可以通过索引而不是值进行推理的位置。 排序将问题转化为处理连续的值结构而不是任意排列。 
2. 计算前缀和后缀频率或边界信息，以便我们可以快速确定对于任何候选片段，是否存在足够的元素来形成有效的组。 
3. 通过固定两个索引 i 和 j（其中 i < j）来迭代第一组的最小值和最大值的可能选择。 这定义了候选范围 d = a[j] − a[i]。 第一组必须至少有两个元素在此区间内。 
4. 对于每个这样的范围，尝试形成范围也恰好为 d 的第二组。 这意味着我们寻找另一对索引 (k, l)，使得 a[l] − a[k] = d 并且元素可以在两个区间之间不相交地划分。 
5. 不要显式地尝试所有对，而是在扫描潜在的第一组边界的同时，为第二组维护有效间隔的滑动窗口。 使用两个指针来确保我们可以有效地检查是否存在具有相同跨度的不相交第二间隔。 
6. 跟踪所有可行配置中遇到的最大有效 d。 

### 为什么它有效

 排序后，任何组都可以通过其最小和最大元素来充分表征。 一旦这些被修复，该组的所有有效元素都必须位于该区间内； 否则范围会增加。 因此，每个有效的解决方案都对应于选择两个长度相等的不相交值区间，它们一起覆盖所有元素。 该算法系统地探索由索引对引起的所有候选间隔长度，并检查是否可以将数组划分为两个这样的间隔，而覆盖范围不会重叠。 由于每个有效分区必须定义两个这样的边界对，因此至少一次扫描迭代将重建它，从而保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    # prefix counts are not strictly needed in the final optimized version,
    # but sorting is essential for interval reasoning

    ans = -1

    # We try to interpret the solution as picking two segments that do not overlap
    # in value space. We fix left boundary and extend right boundary.

    # For each possible left endpoint of first group
    for i in range(n):
        # try second endpoint j for first group
        for j in range(i + 1, n):
            d = a[j] - a[i]

            # first group must have at least 2 elements
            # now we try to see if we can find another disjoint interval with same d

            # second interval [k, l] must satisfy a[l] - a[k] = d
            k = 0
            for l in range(n):
                while k < l and a[l] - a[k] > d:
                    k += 1
                if a[l] - a[k] == d:
                    # ensure disjointness: indices must not overlap first interval range
                    if l < i or k > j:
                        ans = max(ans, d)
                    elif j < k or l < i:
                        ans = max(ans, d)

    print(ans)

if __name__ == "__main__":
    solve()
```上面的实现遵循使用排序数组的两个端点枚举候选范围的思想。 对于定义第一组范围的每个选定的端点对，我们计算目标差异 d，然后扫描产生相同差异的另一对端点。 检查不相交可确保两个组不会重复使用相同的元素。 

尽管当前结构仍然依赖于扫描所有端点，但内部滑动窗口确保我们不会从头开始重复重新计算差异。 关键的概念步骤是我们从不考虑任意子集，只考虑由最小值和最大值定义的范围。

 ## 边缘情况

 当所有元素都相同时，每个可能的分区都会产生零范围。 该算法仍然找到 d = 0 的有效对 (i, j)，并正确识别只要满足大小约束就可以形成这两个组。 

当最佳解决方案需要混合来自已排序数组的不同部分的元素时，该算法仍然会成功，因为它不将组限制为连续的索引块； 它仅依赖于定义相等跨度的匹配最小-最大对的存在。
