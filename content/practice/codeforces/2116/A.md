 ## 解决方案
 ## 问题理解

 我们被要求预测两位玩家（Gellyfish 和 Flower）之间的回合制决斗的获胜者。 每个玩家都有一个主角和一个骑士，每个人都有自己的生命值（HP）。 水母有`a`HP、花有`b`HP，水母的骑士有`c`HP，花之骑士有`d`惠普。 决斗以轮流交替进行。 在奇数轮中，水母的骑士可以直接攻击任一花，减少`b`，或花骑士，减少`d`。 在偶数轮中，花的骑士可以直接攻击水母的骑士，也可以以同样的方式攻击水母的骑士。 假设玩家处于最佳状态，这意味着他们会选择最大化获胜机会的行动。 

任务是在决斗开始前预测获胜者，而不是模拟每一种可能的攻击。 输入由多个测试用例组成，输出必须针对每个用例指示“Gellyfish”还是“Flower”会获胜。 

约束非常严格，以至于对所有攻击进行简单的模拟是不切实际的。 由于 HP 值可达$10^9$以及测试用例的数量最多$10^4$，模拟每一轮将花费太长时间。 我们需要对每个测试用例进行 O(1) 计算。 

当骑士的生命值非常低，或者主要玩家之一的生命值极低时，就会出现不明显的边缘情况。 例如，如果水母的生命值是1，而花的骑士还活着，那么无论水母做什么，下一回合花都会获胜。 反之，如果花的骑士生命值为1，而水母先攻击它，则花无法反击，水母获胜。 正确处理这些需要推理哪个骑士首先被移除以及这如何影响对主要玩家的攻击。 

## 方法

 暴力解决方案会逐轮模拟决斗，每次攻击减少目标生命值 1，轮流交替。 这在原则上是正确的，因为它完全模仿了游戏。 然而，在最坏的情况下，每个测试用例可能需要长达$10^9$如果两个骑士的生命值都很高并且没有玩家直接攻击主角，则采取步骤。 和$10^4$测试用例，这需要$10^{13}$经营活动，远远超出合理限度。 

关键的一点是，决斗完全取决于初始生命值和最佳攻击选择。 由于攻击对方的骑士会延迟对方攻击你的主角的时间，所以我们只需要考虑每个玩家能否在对方杀死对方的骑士之前消灭掉对方的骑士即可。 我们不需要模拟每一轮； 我们可以计算击败每个骑士所需的回合数，并将其与主要玩家的生命值进行比较。 如果一个骑士能够在攻击对方主玩家足够多的次数将其减少到0之前被消灭，则相应的主玩家是安全的。 否则，他们就会输。 

使用这个推理，我们可以计算出 Gellyfish 或 Flower 是否会在每个测试用例的 O(1) 时间内获胜。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每个测试用例 O(max(a,b,c,d)) | O(1) | O(1) | 太慢了|
 | 分析最优 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 确定回合顺序并认识到水母的骑士首先攻击。 这给了水母一个小小的主动优势。 
2、计算一下水母的骑士需要多少次攻击才能击败花的骑士：这简直就是`d`。 每次攻击都会使骑士的生命值减少 1。 
3.计算花的骑士需要多少次攻击才能击败水母的骑士：这是`c`。 
4. 为每个骑士决定最佳策略。 如果这能让他们保护自己的主角，每个人都会攻击对方的骑士直到其死亡。 如果直接攻击对手可以立即致命，那么应该优先考虑。 
5.判断水母是否能在花骑士将水母血量降为0之前消灭花骑士。计算决斗过程中花骑士可以攻击水母的次数。 如果水母的骑士杀死花的骑士的回合数少于花的骑士消耗水母生命值的回合数，则水母生存并获胜。 否则，花胜。 
6. 通过简单的比较来实现这个逻辑：花会赢当且仅当`a <= d`和`b > c`鉴于水母的先手优势。 否则，水母获胜。 

为什么有效：决斗结果完全取决于每个玩家消灭对方骑士或主要玩家的速度。 由于游戏是回合制的，每次攻击的固定伤害为 1，因此计算回合数并与主要 HP 进行比较即可得出确切的获胜者。 骑士被迫以最佳方式攻击以生存或保护他们的主人，使得问题可以简化为这些比较。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c, d = map(int, input().split())
        # Gellyfish attacks first
        # If Flower's knight dies first, Gellyfish wins
        # If Gellyfish's knight dies first, Flower wins
        # Gellyfish kills Flower's knight in d attacks
        # Flower kills Gellyfish's knight in c attacks
        # Each main HP check
        if a <= d and b > c:
            print("Flower")
        else:
            print("Gellyfish")

solve()
```第一行读取测试用例的数量。 每个测试用例都是独立处理的。 比较`a <= d and b > c`编码了这样的见解：如果花的骑士能够生存足够长的时间来杀死水母，并且水母的骑士不能立即威胁花，那么花就获胜。 否则的话，水母的主动就可以确保胜利。 使用整数比较可以避免模拟每次攻击，甚至可以有效处理非常大的 HP 值。
