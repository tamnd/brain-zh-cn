 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 在一项操作中，我们选择两个不同的位置，并将其中一个值替换为这两个值的 gcd。 

该过程可以根据需要重复多次。 目标是使数组中的每个元素相等，同时使用尽可能少的操作数。 

关键问题不是它是否可以做到，因为声明保证它总是可以做到。 挑战在于找到最少的操作数。 

限制异常小。 每个数组值最多为 5000，并且整个输入上的所有数组长度之和也最多为 5000。这立即表明涉及可能的 gcd 值的状态的算法是可行的。 由于 gcd 值永远不会超过 5000，因此值空间上的动态规划或最短路径样式解决方案是实用的。 

对数组进行强力搜索是不可能的，因为可访问数组的数量呈指数增长。 我们需要利用 gcd 运算的结构，而不是模拟所有可能性。 

有几种不明显的情况很容易导致错误的推理。 

考虑：```
3
2 2 2
```答案是`0`。 数组已经相等了。 任何自动尝试构造新 gcd 值的解决方案都会过度计数。 

考虑：```
3
2 4 6
```整个数组的 gcd 为`2`， 和`2`已经存在。 答案是`2`。 

我们可以转`4`进入`2`在一次操作中并且`6`进入`2`在另一个。 一个常见的错误是首先“创建”一个 gcd 值，即使它已经存在。 

考虑：```
3
6 10 15
```全局gcd为`1`，但没有元素等于`1`。 

答案并不简单`n-1 = 2`。 在我们传播价值之前`1`，我们必须首先创建一个`1`某处。 这种额外的成本是问题的核心难点。 

考虑：```
2
6 10
```全局gcd为`2`，但两个元素都不等于`2`。 

一次操作即可产生`2`从任一元素：```
6 -> gcd(6,10)=2
```给予`[2,10]`。 

第二次操作发生变化`10`进入`2`。 

答案是`2`， 不是`1`。 产生目标值和传播目标值是不同的任务。 

## 方法

 一个自然的暴力想法是将每个数组配置视为一个状态并执行 BFS 直到所有元素变得相等。 

这是正确的，因为每个操作都有单位成本，因此 BFS 会找到最小操作数。 

不幸的是，这是完全不可行的。 即使值很小，可能的数组数量也会呈指数增长`n`，并且每个州都有`O(n²)`可能的举动。 状态空间几乎立即爆炸。 

为了找到更好的东西，我们需要了解最终数组必须包含什么值。 

每个操作都会用 gcd 替换一个值。 Gcd操作只能减少数字，而不能增加数字。 因此，最终可以出现在各处的唯一值是整个数组的 gcd。 

让```
G = gcd(a1, a2, ..., an)
```最终的数组必须是：```
[G, G, ..., G]
```现在问题变得更加结构化。 

假设一个元素已经等于`G`。 然后该元素可以用作“源”。 任何其他元素都可以转换为`G`仅在一次操作中：```
x -> gcd(x, G) = G
```所以如果已经有`cnt`的出现次数`G`，我们只需要：```
n - cnt
```运营。 

有趣的情况是没有元素等于`G`。 

在我们能够传播之前`G`，我们必须首先创建一个`G`。 

这需要多少次操作？ 

观察当我们对单个位置重复应用 gcd 操作时会发生什么。 经过几次操作后，该位置成为数组元素的某个子集的 gcd。 

例如：```
gcd(a3, a7, a2, a5)
```可以通过将 gcd 重复带到一个位置来生成。 

因此，创建了第一个`G`相当于找到gcd为的最小子集`G`。 

如果子集有大小`k`，那么产生它的 gcd 就需要`k-1`运营。 

获得一份副本后`G`，我们还需要`n-1`更多操作来转换所有剩余头寸。 

总成本：```
(k - 1) + (n - 1)
= n + k - 2
```因此问题简化为找到 gcd 等于的最小子集大小`G`。 

由于每个数组值最多为 5000，因此我们可以对 gcd 值运行 DP。 

让：```
dp[g] = minimum subset size whose gcd is g
```对数组元素进行一一处理。 对于每个现有的 gcd 状态，要么使用当前元素启动一个新子集，要么扩展先前的子集。 

可能的 gcd 值的数量仅为 5000，使得这种方法非常高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 数组状态上的暴力破解 | 指数| 指数| 太慢了|
 | GCD 值上的 DP | O(n·V) 其中 V=5000 | O(V) | 已接受 |

 ## 算法演练

 1. 计算全局gcd`G`整个数组的。 
2. 计算有多少个元素已经等于`G`。 
3. 如果此计数为正，则返回`n - count`。 

剩下的每个元素都可以转化为`G`在一次操作中使用现有的`G`。 
4. 否则，计算 gcd 等于的最小子集大小`G`。 
5.维护一个DP数组，其中`dp[g]`存储获得gcd所需的最小选定元素数`g`。 
6. 对于每个数组元素`x`：

 开始一个新的子集，仅包含`x`。 

还扩展之前每个可到达的 gcd 状态`g`进入新的状态`gcd(g, x)`。 
7. 处理完所有元素后，让`k = dp[G]`。 

这是 gcd 等于目标值的最小子集大小。 
8. 创建第一个出现的`G`需要`k - 1`运营。 
9.一次一次`G`存在，转换所有剩余位置需要`n - 1`运营。 
10、退货：```
n + k - 2
```### 为什么它有效

 最终值必须是整个数组的 gcd，因为 gcd 操作永远不会增加值，并且每个最终元素必须除以每个原始元素。 

如果发生`G`已经存在，每个非`G`元素可以直接转换为`G`在一次操作中，不存在更快的解决方案，因为每个此类元素都必须至少修改一次。 

当没有出现`G`存在，某些操作序列必须创建第一个`G`。 在一个位置重复取 gcd 得到的任何值都等于原始元素子集的 gcd。 如果最小的子集有大小`k`，那么至少`k-1`组合这些元素需要进行操作，并且准确地说`k-1`操作就足够了。 

一份后`G`存在，每个剩余位置仍需要一次操作才能变为`G`，给另一个`n-1`运营。 

DP 计算每个可达 gcd 值的最小子集大小，因此它找到最佳的`k`。 结合这两个阶段可以得到最小可能的答案。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

MAXV = 5000
INF = 10**9

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    G = 0
    for x in a:
        G = gcd(G, x)

    cnt = sum(1 for x in a if x == G)

    if cnt > 0:
        print(n - cnt)
        continue

    dp = [INF] * (MAXV + 1)

    for x in a:
        ndp = dp[:]

        ndp[x] = min(ndp[x], 1)

        for g in range(1, MAXV + 1):
            if dp[g] == INF:
                continue

            ng = gcd(g, x)
            ndp[ng] = min(ndp[ng], dp[g] + 1)

        dp = ndp

    k = dp[G]
    print(n + k - 2)
```第一部分计算全局 gcd`G`。 

接下来我们计算有多少个元素已经相等`G`。 如果至少存在一个，答案是立即的。 每个其他元素都只需要一次操作，并且已经有一个可用的源值。 

第二个分支处理更困难的情况。 DP存储可以实现每个gcd值的最小子集大小。 

处理数字时`x`，有两种可能。 我们要么开始一个新的子集，仅包含`x`，或者我们附加`x`到先前形成的子集。 追加更改 gcd`g`到`gcd(g,x)`并将子集大小增加一。 

使用复制的数组`ndp`很重要。 就地更新 DP 将允许在一次迭代期间多次使用同一元素。 

在最后，`dp[G]`是 gcd 等于全局 gcd 的最小子集大小。 公式`n + k - 2`直接从上面的证明得出。 

所有值都保持在 5000 以下，因此 DP 状态空间很小。

 ## 边缘情况

 考虑：```
1
3
2 2 2
```全局gcd为`2`，并且所有三个元素都已经相等`2`。 

元素个数等于`G`是`3`，因此算法返回：```
3 - 3 = 0
```无需任何操作。 

考虑：```
1
3
2 4 6
```全局gcd为`2`。 

一个元素已经等于`2`， 所以：```
cnt = 1
```答案变成：```
3 - 1 = 2
```DP 阶段被完全跳过。 这避免了支付额外成本来创造已经存在的价值的常见错误。 

考虑：```
1
3
6 10 15
```全局gcd为`1`，但没有元素等于`1`。 

民主党发现：```
gcd(6,10,15) = 1
```并且没有更小的子集有 gcd`1`， 所以：```
k = 3
```答案是：```
3 + 3 - 2 = 4
```该算法正确地考虑了两个阶段：创建第一个阶段`1`，然后将其传播。 

考虑：```
1
2
6 10
```全局gcd为`2`。 

没有元素等于`2`。 

DP 找到大小的子集`2`谁的gcd是`2`， 所以：```
k = 2
```答案变成：```
2 + 2 - 2 = 2
```一次操作创建一个`2`，然后再进行一项操作来转换剩余元素。 这证实了目标值的产生和传播是分开计算的。
