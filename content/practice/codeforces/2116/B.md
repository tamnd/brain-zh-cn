 ## 解决方案
 ## 问题理解

 我们有两种排列`p`和`q`的数字`0...n-1`。 

对于每个职位`i`，我们必须评估所有指数对`(j, i-j)`这样`0 ≤ j ≤ i`，并计算$$2^{p_j}+2^{q_{i-j}}$$在所有这些候选者中，我们取最大值并将其存储在`r[i]`。 

直接值变得巨大，因为指数可以大到`n-1`，所以最终的答案需要模`998244353`。 

首先要注意的是，涉及的数字是 2 的幂。 两个的幂增长得如此之快，以至于在比较时$$2^a+2^b$$较大的指数完全占主导地位。 更正式地说，如果`a > c`， 然后$$2^a+2^b > 2^c+2^d$$无论值如何`b`和`d`。 

这意味着最大化总和相当于首先最大化该对中较大的指数，并且只有当这些较大的指数相等时我们才比较较小的指数。 

这些限制迫使我们利用这种结构。 总和为`n`所有测试用例最多是`10^5`。 一个`O(n^2)`算法将大致执行`10^{10}`最坏情况下的操作，远远超出了极限。 我们周围需要一些东西`O(n log n)`或者`O(n)`每个测试用例。 

一个微妙的点是候选对中的最大指数可能来自任一数组。 

考虑：```
p = [2,0,1]
q = [0,2,1]
```为了`i = 1`，候选人是```
j=0: (2,2)
j=1: (0,0)
```答案来自指数`2`，并且两个阵列的贡献相等。 任何仅跟踪一个数组中最大值的解决方案都会错过这种情况。 

另一个容易犯的错误是最大化`p[j] + q[i-j]`。 目标不是指数之和。 

例如：```
(5,0) -> 32+1 = 33
(3,3) -> 8+8 = 16
```虽然`5+0 < 3+3`，第一对要大得多，因为指数`5`占主导地位。 

## 方法

 暴力解法直接遵循定义。 

对于每个职位`i`, 迭代所有`j`从`0`到`i`, 计算$$2^{p_j}+2^{q_{i-j}}$$并保持最大值。 

这是正确的，因为它明确检查每个有效对。 问题在于复杂性。 对于一个测试用例，检查对的数量是$$1+2+\cdots+n = O(n^2)$$大致变成`5 × 10^9`操作时`n = 10^5`。 

为了做得更好，我们需要利用以下事实：`p`和`q`是排列。 

让$$M_i=\max\Big(\max_{0\le j\le i} p_j,\ \max_{0\le j\le i} q_j\Big)$$是出现在任一前缀中的最大指数`i`。 

任何最佳配对`r[i]`必须包含指数`M_i`。 

为什么？ 如果双方都没有贡献`M_i`，那么该候选中的最大指数严格小于`M_i`，以及一对包含`M_i`总是会更大。 

因为`p`和`q`是排列，每个指数只出现一次。 假设指数`M_i`出现在`p`在位置`posP[M_i]`。 

如果`posP[M_i] ≤ i`，那么包含该指数的唯一对是$$j = posP[M_i]$$这迫使另一个指数成为$$q_{i-posP[M_i]}.$$同样，如果`M_i`出现在`q`，唯一可能的匹配对是$$p_{i-posQ[M_i]}.$$所以对于每一个`i`，最多有两个候选者可以包含最大指数`M_i`。 

一旦确定了最大指数，比较就会减少到选择较大的第二指数。 因此我们只需要比较两个可能的值。 

这将问题转化为线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算两个模的幂`998244353`最多`100000`。 
2. 构建数组`posP`和`posQ`存储排列中每个值的位置`p`和`q`。 
3. 计算前缀最大值：`prefP[i] = max(p[0..i])`

`prefQ[i] = max(q[0..i])`4. 对于每个位置`i`, 计算$$M=\max(prefP[i],prefQ[i]).$$任何最优对必须包含指数`M`。 
5.如果`M`出现在前缀内`p`，设其位置为`k=posP[M]`。 

然后相应的候选者使用$$(M,\ q_{i-k})$$假如`k ≤ i`。 
6. 如果`M`出现在前缀内`q`，设其位置为`k=posQ[M]`。 

然后相应的候选者使用$$(p_{i-k},\ M)$$假如`k ≤ i`。 
7. 在有效候选项中，比较第二个指数。 由于两者包含相同的最大指数`M`，第二个指数越大，总和越大。 
8. 令所选对为`(M,S)`。 输出$$2^M + 2^S \pmod{998244353}.$$### 为什么它有效

 对于任意索引`i`， 让`M`是任一前缀中出现的最大指数`i`。 

每个最大指数小于的候选对`M`自动比任何包含以下内容的候选者更差`M`，因为二的幂严格按照其最大指数排序。 

由于每个指数在每个排列中恰好出现一次，因此只有两种可能的方式来形成包含`M`：利用它的出现`p`或使用它的出现`q`。 每个最佳解决方案都必须是这些候选解决方案之一。 

确定最大指数后`M`, 比较$$2^M+2^a$$和$$2^M+2^b$$减少到比较`a`和`b`。 该算法选择较大的第二个指数，因此它恰好选择最大值对。 

因此每一个`r[i]`计算正确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 100000

pow2 = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    pow2[i] = (pow2[i - 1] * 2) % MOD

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        q = list(map(int, input().split()))

        posP = [0] * n
        posQ = [0] * n

        for i, x in enumerate(p):
            posP[x] = i

        for i, x in enumerate(q):
            posQ[x] = i

        prefP = [0] * n
        prefQ = [0] * n

        prefP[0] = p[0]
        prefQ[0] = q[0]

        for i in range(1, n):
            prefP[i] = max(prefP[i - 1], p[i])
            prefQ[i] = max(prefQ[i - 1], q[i])

        ans = [0] * n

        for i in range(n):
            M = max(prefP[i], prefQ[i])

            best_second = -1

            k = posP[M]
            if k <= i:
                best_second = max(best_second, q[i - k])

            k = posQ[M]
            if k <= i:
                best_second = max(best_second, p[i - k])

            ans[i] = (pow2[M] + pow2[best_second]) % MOD

        print(*ans)

solve()
```位置数组是关键的实现细节。 它们让我们立即找到特定指数出现在任一排列中的位置。 

前缀最大值标识每个可用的最大指数`i`。 如果没有它们，我们将需要重复搜索前缀。 

对于固定的`i`，我们只检查包含指数的两种方法`M`。 相应的第二个指数直接从相反的数组中读取。 

答案是使用预先计算的 2 的模幂来重建的。 快速取幂的重复计算能力仍然可以接受，但预计算使每个查询的时间恒定。 

必须小心索引`i-k`。 支票`k <= i`保证该索引非负。

 ## 边缘情况

 ### 最大指数仅出现在一个数组的前缀中

 考虑：```
n = 2
p = [1,0]
q = [0,1]
```为了`i = 1`，最大可用指数是`1`，来自`p[0]`。 

该算法发现`posP[1]=0`，评估匹配伙伴`q[1]=1`，并得到`(1,1)`。 

答案是$$2^1+2^1=4.$$不需要扫描所有对。 

### 最大指数出现在两个前缀中

 考虑：```
n = 3
p = [2,0,1]
q = [0,2,1]
```为了`i = 2`, 指数`2`可以从两个阵列中获取。 

两位候选人分别是```
(2,1)
(1,2)
```两者都对应值`6`。 

该算法检查两次出现并保留较大的第二个指数，即`1`，产生正确的结果。 

### 最大指数支配所有较小的指数

 考虑：```
n = 3
p = [2,1,0]
q = [0,1,2]
```为了`i = 2`，候选人包括```
(2,2)
(1,1)
(0,0)
```虽然`(1,1)`有一对平衡的，它无法击败`(2,2)`因为指数`2`支配最大指数为的每个候选人`1`。 

当算法将注意力限制在包含最大可用指数的对时，该算法完全依赖于此属性。
