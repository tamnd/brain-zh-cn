 ## 解决方案
 ## 问题理解

 给定一个数字数组，我们可以将其分成几个不相交的组。 对于每个组，我们计算其中位数，分区的分数是这些中位数的总和。 任务是选择数组的一个分区，使总分最大化。 

关键的困难在于中位数取决于每个组的内部排序，而分区决策会影响哪些元素彼此交互。 因此，问题不仅仅是排序，而是理解分组如何以全局最优的方式改变中位数。 

如果数组大小达到 200000 左右，任何尝试所有分区的解决方案都立即不可能。 甚至枚举子集或分组决策也会呈指数增长。 这迫使我们寻求一种解决方案，将问题简化为最优组的结构表征，然后在排序后进行线性或线性算术计算。 

当考虑小群体时，会出现一种微妙的边缘情况。 例如，如果我们试图贪婪地组成两到三人的小组，我们可能会陷入困境：

 输入：

 n = 4

 a = [1, 2, 3, 4]

 如果我们分组为 [1,2] 和 [3,4]，中位数为 1 和 3，总共 4。 

但分组为 [1,2,3] 和 [4] 给出中位数 2 和 4，总共 6。 

一种将相邻元素配对的幼稚的本地策略错过了创建一个更大的结构化群体所带来的全局改进。 

核心问题是中位数的值相对于分组而言是高度非线性的，因此我们需要全局结构而不是局部启发式。 

## 方法

 暴力方法会尝试将数组的每个分区分组并计算每个组的中值。 即使我们固定一个排序数组并只考虑连续分割，划分 n 个元素的方法数量仍然是指数级的。 当 n = 40 时，这已经变得不可行，而当 n = 200000 时，则完全遥不可及。 

关键的观察结果是最优解的结构受到极大限制。 对数组进行排序后，我们可以根据元素对中位数的影响来推断元素如何在组之间分布。 所提供的分析得出三个重要的结构事实。 

首先，最多一个组可以具有负中位数，因为两个这样的组可以合并而不会减少中位数的总和。 其次，在中位数为正的组中，只有一组可以包含多个元素。 所有其他元素实际上都成为单例，贡献自己的价值作为中位数。 第三，一旦存在这样一个特殊的组，它的元素必须在排序数组中形成一个前缀，因为如果我们总是以一致的方式更喜欢较小的正数和较大的负数，则与外部元素交换元素只能提高或保持总和。 

这些结构约束将问题分解为一个简单的决策：选择已排序数组的前缀来形成一个特殊组，并将所有剩余元素视为单元素组。 对于每个前缀选择，我们可以使用前缀信息在 O(1) 中计算结果分数，因此通过扫描所有分割点获得最终答案。

 ## 算法演练

 ### 逐步过程

 1. 对数组进行非降序排序。 

排序是必要的，因为所有结构参数都依赖于全局比较元素，而中位数仅按排序顺序才可预测。 
2. 预先计算排序数组的前缀和。

这允许在评估候选分区时快速计算任意前缀和后缀的总和。 
3. 将每个位置 i 视为边界，其中前 i 个元素形成特殊组，其余元素是单例。 

从结构结果可以看出，只需要一个非平凡群，并且它必须是一个前缀。 
4. 对于固定的 i，计算前缀组的贡献。 

前缀的中位数仅取决于其排序的中间元素。 
5. 添加其余元素的贡献，每个元素充当一个单例组，其中位数是元素本身。 
6. 跟踪所有可能的分割点 i 的最大分数。 

### 为什么它有效

 正确性来自于任何最优划分都可以在不减少中位数之和的情况下转化为规范形式。 该规范形式恰好有一个非平凡的组，并且该组由按排序顺序的连续前缀组成。 每个其他元素都形成自己的单例组。 由于每个有效的最佳解决方案都对应于一个前缀分割，因此枚举所有前缀可以保证我们考虑最佳配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]

    def median(l, r):
        length = r - l
        return a[l + (length - 1) // 2]

    ans = -10**18

    for i in range(n + 1):
        if i == 0:
            ans = max(ans, pref[n])
            continue

        med = median(0, i)
        rest_sum = pref[n] - pref[i]
        ans = max(ans, med + rest_sum)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先对数组进行排序，以便所有中值推理都变成位置推理。 前缀和数组允许对特殊组之外的元素的贡献进行恒定时间评估，因为它们都表现为单例。 

对于每个分割点，使用前缀的中间索引来计算前缀组中值。 其余元素直接贡献为它们自己的值，这就是为什么它们的总和直接从前缀总和差中获取。 

一个常见的微妙之处是处理 i = 0 的情况。这对应于没有特殊的组，这意味着每个元素都是一个单例，因此答案只是所有元素的总和。

 ## 边缘情况

 ### 所有元素均为负数

 输入：

 n = 3

 a = [-5, -2, -1]

 排序为 [-5, -2, -1]。 该算法考虑所有前缀。 最好的结果来自于取 i = 0，给出总和 -8，或 i = 1 给出 -7。 最大值为-7。 

追踪：

 i = 0 给出 -8

 i = 1 给出中位数 -5 + 其余 -3 = -8

 i = 2 给出中位数 -5 + 其余 -1 = -6

 i = 3 给出中位数 -2

 该算法正确地处理了这个问题，因为它始终包含单例选项，从而防止强制分组而导致结果恶化。 

### 单个大正值和许多小负值

 输入：

 n = 4

 a = [-10, -9, -8, 100]

 排序：[-10, -9, -8, 100]

 最佳方案是隔离 100 个并避免在任何前缀组中稀释它。 扫描包括 i = 0，总共为 73，而任何前缀组都会减少 100 的贡献。 

前缀扫描确保算法永远不会强制将有益的异常值纳入次优组中。
