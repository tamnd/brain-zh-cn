 ## 解决方案
 ## 问题理解

 我们得到了平面上的一组点和一个目标区域。 任务是选择其中的三个点，使它们形成的三角形恰好具有所要求的面积，或者报告这样的三角形不存在。 使用两倍面积来比较面积，因为对于整数坐标，双倍面积始终是整数。 原问题最多有 2000 个点，目标区域最多为$2 \cdot 10^{18}$。 

界限立即排除了检查每个三元组。 有$O(n^3)$可能的三角形，这意味着周围$8 \cdot 10^9$检查最大输入大小。 即使常数因子非常小，这也太多了。 我们需要将搜索减少到大致二次工作，因为$2000^2$运营是可管理的。 

思考三角形的一个有用方法是将一侧固定为底。 一旦知道了底座的两个端点，也就知道了所需的高度。 剩下的任务就是找到一个点，该点与该基线的垂直距离恰好具有所需的值。 

当使用浮点几何时，粗心的实现可能会失败。 例如，如果目标加倍面积是`1`并且三角形的高度非常小，浮点舍入可能会错误地判定面积不精确。 输入坐标可以大到$10^9$，所以叉积可以达到大约$10^{18}$，并且必须使用整数运算。 

另一个常见的错误是忘记三角形可以位于所选底边的任一侧。 用于输入```
3 5
0 0
10 0
5 1
```加倍的面积是`10`，所以这个特定目标是不可能的。 仅搜索基数之上的点的方法在该点之下时也会错过有效解，因为那里的带符号叉积为负。 

## 方法

 蛮力方法是选取每个三重点，使用叉积计算加倍面积，并将其与目标进行比较。 这是正确的，因为每个可能的三角形都被明确检查。 问题是三元组的数量，大约是$n^3/6$。 为了$n=2000$，即数十亿次操作。 

关键的观察是，选择基地后，区域条件变成一维搜索。 如果基向量是$v$，双倍面积是两者之间叉积的绝对值$v$和第三点的向量。 我们需要一个距基线具有特定符号距离的点。 

困难的部分是维护按到当前基地的距离排序的点。 为每一对重新计算这个顺序又会太慢。 相反，我们通过所有可能的部分旋转底座。 当底面方向连续变化时，只有当旋转线与连接两点的线段平行时，两点的相对顺序才会发生变化。 由于我们按角度顺序处理所有点对，因此每次更改都只是在维护的顺序中交换两个相邻点。 这给出了一个$O(n^2 \log n)$解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n² log n) | O(n² log n) | O(n²) | 已接受 |

 ## 算法演练

 1. 创建所有有向点对，并按连接点对的线段的角度对它们进行排序。 扫描从水平方向开始，其中按到线的距离排序与按 y 坐标排序相同。 
2. 维护一个点数组，这些点按照距当前扫描线的有符号距离排序。 还存储该数组内每个点的位置，以便交换时间恒定。 
3. 对于按角度顺序排列的每个线段，使用当前顺序搜索第三个点。 对于一个基地从`a`到`b`，面积加倍的条件为：$$cross(b-a, c-a)=2S$$或具有相反符号的相同值。 因为点是按照这个值排序的，所以二分查找可以找到匹配的点。 

1. 处理完一个段后，在维护的顺序内交换该段的两个端点。 这会更新下一个扫描位置的顺序。 

交换足够的原因是，两点相对于旋转线交换顺序的唯一时刻是当该线与连接它们的线段平行时。 我们正是处理这些事件。 

为什么它有效：维护的排序始终是按距当前基线的有符号距离对点进行排序。 二分搜索是有效的，因为与固定基向量的叉积是线性变换，因此它保留了距离的排序。 扫描恰好在两个距离变得相等的时刻更新顺序，并且没有三个点共线，因此每个事件都是明确的。 一旦找到具有所需叉积的点，则通过构造满足三角形面积条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, S = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    target = 2 * S

    def cross(a, b, c):
        return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

    events = []
    for i in range(n):
        for j in range(i + 1, n):
            dx = pts[j][0] - pts[i][0]
            dy = pts[j][1] - pts[i][1]
            events.append((dy, dx, i, j))

    events.sort(key=lambda e: __import__("math").atan2(e[0], e[1]))

    order = sorted(range(n), key=lambda i: pts[i][1])
    pos = [0] * n
    for i, x in enumerate(order):
        pos[x] = i

    for _, _, a, b in events:
        lo, hi = 0, n
        while lo < hi:
            mid = (lo + hi) // 2
            c = order[mid]
            val = cross(a, b, c)
            if val < target:
                lo = mid + 1
            else:
                hi = mid

        if lo < n and cross(a, b, order[lo]) == target:
            c = order[lo]
            print("YES")
            print(*pts[a])
            print(*pts[b])
            print(*pts[c])
            return

        lo, hi = 0, n
        while lo < hi:
            mid = (lo + hi) // 2
            c = order[mid]
            val = cross(a, b, c)
            if val < -target:
                lo = mid + 1
            else:
                hi = mid

        if lo < n and cross(a, b, order[lo]) == -target:
            c = order[lo]
            print("YES")
            print(*pts[a])
            print(*pts[b])
            print(*pts[c])
            return

        pa, pb = pos[a], pos[b]
        order[pa], order[pb] = order[pb], order[pa]
        pos[a], pos[b] = pb, pa

    print("NO")

if __name__ == "__main__":
    solve()
```这`cross`函数是核心几何运算。 它返回两倍的有符号面积，这避免了所有浮点计算。 

扫掠阵`order`是算法中描述的动态结构。 这`pos`当需要交换当前基数的两个端点时，数组可以防止昂贵的搜索。 

二分搜索寻找三角形的两个可能的方向。 仅搜索一个标志会错过底座另一侧的三角形。 所有算术都保留在 Python 整数中，因此大坐标积不会溢出。 

## 工作示例

 对于第一个样本：```
3 7
0 0
3 0
0 4
```唯一的三角形面积是 24 的两倍，而不是 14。 

| 步骤| 基地| 所需交叉值 | 找到点| 结果 |
 | --- | --- | --- | --- | --- |
 | 1 | (0,0) 到 (3,0) | 14 或-14 | 无 | 继续 |
 | 2 | 其他对 | 14 或-14 | 无 | 否 |

 跟踪显示，检查每个碱基都没有找到匹配的高度。 

对于第二个样本：```
4 3
0 0
2 0
1 2
1 3
```目标面积翻倍为 6。 

| 步骤| 基地| 所需交叉值 | 找到点| 结果 |
 | --- | --- | --- | --- | --- |
 | 1 | (0,0) 到 (2,0) | 6 | (1,3) | 是 |

 叉积是$2 \cdot 3 = 6$，所以实际面积是3。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n² log n) | O(n² log n) | 有$O(n²)$基，每个基都执行二分搜索 |

 ## 边缘情况

 对于不可能的样本：```
3 7
0 0
3 0
0 4
```该算法检查每个可能的碱基。 基地`(0,0)`到`(3,0)`需要叉积为 14 的点，但第三点给出 12。其他两个碱基也失败，所以答案仍然存在`NO`。 

对于最小的有效三角形：```
3 1
0 0
1 0
0 1
```目标翻倍面积为2。以前两点为底，第三点给出叉积1？ 底座方向正确`(0,0)`到`(0,1)`给出叉积 2，因此二分查找找到它并返回`YES`。 

该算法可以处理两个方向，因为每个碱基都经过两个方向的测试`target`和`-target`，因此所选基线下方的三角形与其上方的三角形完全相同。
