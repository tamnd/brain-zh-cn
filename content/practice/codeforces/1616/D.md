[CF 1616D - 保持较高的平均值](https://codeforces.com/problemset/problem/1616/D)

 **求解时间：** 2m 24s
 **已验证：** 否

 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和一个目标值`x`。 任务是从该数组中选择尽可能多的元素，并对连续选定的元素进行约束：完全选择的长度至少为 2 的任何连续子数组必须具有至少平均值`x`。 同样，任何完全选择的长度子段的总和`k`必须至少是`k * x`。 始终可以选择单个元素，因为长度为 1 的子数组除外。 

输入提供多个测试用例。 每个案例由数组大小组成`n`、数组元素和整数`x`。 该数组可以长达 50,000 个元素，这意味着直接迭代所有子段的任何解决方案都将太慢，因为子段的数量呈二次方增长。 

当所有数字均为负数时，或者当`x`是负数，或者当数组元素是大正数和大负数的混合时。 例如，如果数组是`[10, -1, 10]`和`x = 5`，选择所有三个将违反子数组`[10, -1]`因为`10 + (-1) = 9 < 2 * 5 = 10`。 在这种情况下，不考虑连续总和的天真的贪婪选择最大数字将失败。 

当最佳选择不连续时，就会出现另一个微妙之处。 按值降序选取元素似乎很自然，但稍后选择较小的数字可能会打破子数组平均约束。 这暗示了一种结构，我们需要组合而不是单独地优先考虑高价值元素。 

## 方法

 强力方法将考虑数组的每个可能的子集，检查长度至少为二的所有完全选择的子段，并计算最大的可行选择。 对于长度的数组`n`， 有`2^n`子集。 即使是为了`n = 20`，这会慢得令人无法接受，更不用说`n = 50,000`。 蛮力原则上是有效的，因为它会尝试所有可能性，但它是不可行的，因为子集的数量呈指数增长。 

关键的见解是，当任何子数组的元素较大时，其总和约束都会较弱。 这建议按降序对数组进行排序，并尝试首先选择最大的元素。 如果我们从最大到最小处理元素，那么在每一步我们都可以维护所选元素的总和以及所选元素的计数。 第一个的平均数`k`元素只是总和除以`k`。 如果在某个时刻平均值跌破`x`，添加较小的元素永远不会改善它，所以我们停止。 这种观察将问题简化为排序后的贪婪策略：按降序选择元素，直到累积平均值低于`x`。 

该策略之所以有效，是因为子数组条件仅对完全选定的连续段重要。 排序确保我们选择的任何前缀都是可能的“最重”，并且该前缀的任何子段的平均值至少为前缀平均值。 如果前缀平均值满足`x`，它的所有连续子数组也将满足`x`。 因此，这种贪婪前缀方法既正确又高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了 |
 | 最优（贪心 + 排序）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`，数组`a`，和整数`x`。 
2. 排序`a`按降序排列。 这确保了选择前缀使总和最大化，这是维持平均约束的关键。 
3.初始化两个变量：`total_sum = 0`跟踪所选元素的总和，以及`selected_count = 0`跟踪我们可以选择多少个元素。 
4. 迭代已排序的数组。 对于每个元素`a[i]`，将其添加到`total_sum`并增加`selected_count`。 将当前平均值计算为`total_sum / selected_count`。 
5. 如果平均值低于`x`，不能包含最后添加的元素。 停止迭代。 可选择元素的最大数量为`selected_count - 1`。 否则，继续。 
6. 迭代完成后，输出测试用例所选元素的数量。 

这样做的原因是，排序前缀的任何连续子数组的总和至少与其长度成正比，因为从末尾删除元素只会增加剩余元素的平均值。 因此，如果总前缀平均值至少为`x`，每个长度为 2 或更多的连续子数组都满足原始约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        x = int(input())
        
        a.sort(reverse=True)
        total_sum = 0
        selected_count = 0
        
        for i in range(n):
            total_sum += a[i]
            if total_sum >= x * (i + 1):
                selected_count = i + 1
            else:
                break
        
        print(selected_count)

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 按降序对数组进行排序允许进行贪婪前缀检查。`total_sum >= x * (i + 1)`确保前缀的平均约束。 我们不需要检查所有子数组，因为如果前缀平均值满足平均值要求，则前缀属性保证所有连续子数组都满足平均值要求。
