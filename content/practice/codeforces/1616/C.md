 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并且允许我们自由地用任何实数替换元素。 目标是转换数组，以便保持非常强大的结构属性：每个子数组必须满足线性平均条件，将其总和仅与其端点联系起来。 

这个条件乍一看很复杂，但它强制执行了一个隐藏的形状约束。 如果将要求扩展到所有子数组，则实际上会强制每个连续段的行为就好像其值位于一条直线上一样。 当您比较重叠的子段时，任何线性偏差都会产生矛盾。 

所以任务不直接与求和有关。 它是关于必须固定多少个位置，以便通过修改最少的元素使数组成为全局线性的。 

输入规模较小，每个测​​试用例最多 70 个元素，最多 100 个测试用例。 这立即表明分段上的二次或三次解是可行的，但是任何试图天真地探索修改的所有子集的东西都会爆炸，因为子集的数量是$2^{70}$。 

当思考“固定价值观”时，会出现一个微妙的问题。 因为替换可以是任意实数，所以一旦我们决定哪些索引保持不变，则始终可以选择其余索引来适应一致的结构（如果存在）。 真正的困难是确定哪些索引子集可以保持不变，同时仍然形成有效的配置。 

一个天真的错误是假设当地条件就足够了。 例如，仅检查三元组或仅检查相邻约束会忽略全局不一致。 一个小例子，比如`[1, 2, 4, 7]`可能会通过局部检查，但全局会失败，因为没有一条线适合所有点。 

## 方法

 理解结构的关键是以更几何的方式重写条件。 该方程强制要求对于每个子数组，总和等于从线性函数采样值时得到的值。 这意味着数组的行为必须类似于以下形式的线性序列：$$a_i = x + (i - 1)d$$对于一些实数$x$和$d$。 

如果数组已经遵循该算术级数，则所有子数组都会自动满足该条件。 相反，任何违反算术级数的行为都会破坏某些段的属性。 

所以问题就简化为：改变元素的最小数量，使得结果数组成为算术级数。 

现在考虑如何解决这个问题。 如果我们选择两个位置$i < j$，那么这两个值确定了唯一的算术级数。 其他所有索引$k$必须满足：$$a_k = a_i + (k - i)\cdot \frac{a_j - a_i}{j - i}$$对于固定对$(i, j)$，我们可以计算有多少原始元素已经匹配这个进程。 其他一切都必须更换。 

暴力解决方案会尝试所有对$(i, j)$并检查所有指数的一致性，成本计算$O(n^3)$每个测试用例。 和$n = 70$，这已经很接近了，但在 Python 中通过修剪仍然是安全的。 然而，更直接的观察会有所帮助：最佳解决方案是位于由任意两个选定索引定义的单个算术级数上的最大点数。 

我们只需要最大化保留的元素即可； 答案是$n - \text{best alignment}$。 

核心见解是，进展完全由斜率决定，因此每一对都定义了一个候选解决方案，我们只需评估所有这些解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（检查所有子集）|$O(2^n \cdot n)$|$O(n)$| 太慢了 |
 | 基于对的级数枚举|$O(n^3)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 修复一对索引$i$和$j$， 在哪里$i < j$，并将它们视为定义目标算术级数。 

斜率由这两点唯一确定，这消除了构建序列其余部分时的歧义。 
2. 计算差异$d = (a_j - a_i) / (j - i)$。 这定义了每个索引步骤值应如何变化。 

我们使用实数算术，因为该问题允许实数替换。 
3. 初始化一个计数器，记录有多少元素与此级数匹配。 从所有指数开始，检查公式的一致性$a_k = a_i + (k - i)d$。 
4. 对于每个索引$k$，检查原始值是否已经符合级数。 如果是，我们保留它； 否则，就需要更换。 

每场比赛代表一个不需要修改的位置。 
5. 跟踪所有配对的最大匹配数$(i, j)$。 这表示在形成有效算术级数时可以保持不变的最大子集。 
6.答案是$n - \text{maximum matches}$。 

### 为什么它有效

 任何有效的最终数组都必须是算术级数，因为原始条件强制所有子段呈线性。 算术级数由任意两个不同点唯一定义，因此每个有效解对应于至少一对保持不变的索引。 

相反，如果我们固定一对并将其扩展为完整的级数，则每个位置要么已经适合，要么必须被替换，并且所得结构始终满足条件。 因此，搜索所有对可以保证我们考虑所有可能的有效最终配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n <= 2:
            print(0)
            continue

        best = 1

        for i in range(n):
            for j in range(i + 1, n):
                cnt = 0

                ai, aj = a[i], a[j]
                di = j - i

                for k in range(n):
                    # check collinearity without floating instability
                    # (a[k] - ai) * (j - i) == (a[j] - ai) * (k - i)
                    if (a[k] - ai) * di == (aj - ai) * (k - i):
                        cnt += 1

                best = max(best, cnt)

        print(n - best)

if __name__ == "__main__":
    solve()
```该实现通过交叉相乘而不是直接计算斜率来避免浮点精度问题。 这确保了使用整数进行精确比较，即使最终值允许为实数，这一点也很重要。 极端情况$n \le 2$是分开处理的，因为任何两点总是定义一个有效的级数。

 ## 边缘情况

 一个常量数组，例如`[5, 5, 5, 5]`已经满足条件，因为它是斜率为零的简并算术级数。 该算法正确地将所有索引计算为任何对的匹配，因此最好的是$n$，给出零运算。 

对于大小为 1 或 2 的小型数组，每个配置都是有效的，因为任何两个点都定义一条唯一的线。 在这些情况下，实现显式返回 0，从而避免不必要的计算并防止除以零或未定义的斜率处理。 

在多个不同算术级数部分拟合的情况下，例如`[1, 3, 2, 4]`，不同的对产生不同的候选线。 该算法探索所有这些，并自然地选择具有最大对齐的那个，确保始终实现最小替换计数。
