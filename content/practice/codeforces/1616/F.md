 ## 解决方案
 ## 问题理解

 我们得到一个小的无向图，其中每条边都应该涂上三种颜色中的一种。 一些边缘已经用颜色固定，而其他边缘则开始未着色，必须在中分配一个值`{1, 2, 3}`。 

该约束不是单个边或顶点的局部约束。 由成对连接的三个顶点形成的每个三角形都必须满足一个非常严格的规则：当您查看该三角形的三个边时，要么所有三种颜色都相同，要么所有三种颜色都不同。 禁止二等一异等混合模式。 

任务是决定我们是否可以将部分着色完成为完整有效的着色，如果可以，则输出一个这样的完成。 

该图的顶点很小，最多 64 个，边稀疏，最多 256 个。这已经表明，我们不希望以简单的方式依赖所有顶点三元组的重组合，而是利用结构一致性约束。 

一个关键的微妙之处是该条件仅适用于图中存在的三角形。 如果缺少某些边，则许多三元组的顶点都是不相关的。 这意味着约束稀疏但高度相互依赖。 

一种常见的故障模式是独立处理每个三角形。 例如，当一条边参与多个三角形时，局部贪婪地满足每个三角形可能会破坏一致性。 另一个微妙的问题是假设为每个连接的组件或每个顶点邻接列表独立分配颜色就足够了，这忽略了全局一致性。 

最小失败配置出现在重叠的三角形中。 假设边`(1,2)`,`(2,3)`,`(1,3)`形成一个三角形，并且`(1,3)`也参与了另一个三角形`(1,3,4)`。 修复第一个三角形的本地分配可能会与第二个三角形相矛盾。 

这种相互依赖是核心困难。 

## 方法

 一个蛮力的想法是为每个未着色的边分配三种颜色之一并检查所有三角形。 最多有 256 条边，因此搜索空间为`3^k`在哪里`k`是未着色边的数量。 即使我们通过尽早检查约束来进行修剪，这仍然是指数级的且不可行。 

约束的结构暗示了更强有力的东西：三角形不是任意约束，它们定义了代数一致性。 规则“全部相等或全部不同”正是称为 3 边着色的结构的签名，该结构与划分为三类一致，或者等效地，其行为类似于在隐藏顶点势下的大小为 3 的组中进行加法。 

关键的见解是将边缘颜色解释为顶点标签之间的差异`{0,1,2}`模 3。如果我们为每个顶点分配一个值`x[v] ∈ {0,1,2}`，那么我们可以将边缘颜色定义为`(x[u] - x[v]) mod 3`映射到`{1,2,3}`。 在这种结构下，每个三角形自动满足条件：

 如果所有顶点标签相等，则所有边的差异为 0，因此所有边具有相同的颜色。 如果所有顶点标签都是不同的，则所有成对差异覆盖所有三个残基，产生三种不同的颜色。 

对于具有足够约束的连接组件来说，反之亦然：任何符合三角形规则的有效着色都会引起这样的顶点势直至全局移位。 这减少了从边缘着色到顶点分配一致性的问题。 

因此任务变成：分配一个值`{0,1,2}`到每个顶点，使得每个预着色边缘强制执行差异约束。 然后传播这些约束并检测矛盾。 

我们现在可以使用顶点上的 BFS/DFS 来解决它，将边视为以下形式的约束：`x[v] = x[u] + d (mod 3)`在哪里`d`取决于边缘颜色。 

如果边未着色，则不会施加任何约束，但一旦分配了顶点，其颜色就确定了。 

边缘上的强力问题变成了顶点上的线性传播问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(3^m·n²) | O(3^m·n²) | O(n + m) | 太慢了 |
 | 最优（顶点上的约束传播）| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们首先将边约束转换为顶点标签上的模方程。 

1. 为每个顶点分配初始值“未分配”。 我们稍后将在中分配值`{0,1,2}`。 
2. 对于每个彩色边缘`(u, v, c)`，将颜色解释为端点之间的模差约束。 我们修复一个映射，例如：`1 → 0`,`2 → 1`,`3 → 2`，表示颜色代表模 3 的残基。 

我们强制执行两个方向：`x[v] = (x[u] + d) mod 3`和`x[u] = (x[v] - d) mod 3`。 

此步骤将边缘约束转换为小循环群上的线性方程。 
3. 对所有顶点运行 BFS 或 DFS。 每当我们遇到将标记顶点连接到未标记顶点的边时，我们都会使用约束分配邻居。 如果邻居已经被分配，我们验证一致性。 

任何矛盾都意味着方程组不一致，因此不存在有效的着色。 
4. 在约束图的每个连接组件内完全确定顶点值后，我们为边分配颜色：

 对于每条边`(u, v)`:

 - 计算`diff = (x[u] - x[v]) mod 3`- 转换回`{1,2,3}`5. 对于最初未着色的边缘，该计算值将成为其最终颜色。 
6. 按输入顺序输出所有边缘颜色。 

关键思想是，一旦顶点标签一致，三角形约束就会自动满足，因此我们从不显式检查三角形。 

### 为什么它有效

 不变的是，在 BFS 期间，每个指定的顶点值与所有先前处理的约束一致，这意味着所有彩色边都满足固定的模差方程。 因为每个三角形都由三个边组成，所以任何三角形周围的差值之和必须为零 mod 3，这保证了该三角形要么是单色的，要么是全彩虹的。 任何违反三角形结构的行为都意味着顶点分配中存在矛盾，BFS 在重新访问已分配的顶点时会检测到这一点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        edges = []
        adj = [[] for _ in range(n)]
        
        def to_diff(c):
            return c - 1  # map 1,2,3 -> 0,1,2
        
        for i in range(m):
            a, b, c = map(int, input().split())
            a -= 1
            b -= 1
            edges.append((a, b, c))
            if c != -1:
                d = to_diff(c)
                adj[a].append((b, d))
                adj[b].append((a, (-d) % 3))
            else:
                adj[a].append((b, None))
                adj[b].append((a, None))
        
        from collections import deque
        
        color = [-1] * n
        ok = True
        
        for i in range(n):
            if color[i] != -1:
                continue
            color[i] = 0
            q = deque([i])
            
            while q and ok:
                u = q.popleft()
                for v, d in adj[u]:
                    if d is None:
                        continue
                    if color[v] == -1:
                        color[v] = (color[u] + d) % 3
                        q.append(v)
                    else:
                        if color[v] != (color[u] + d) % 3:
                            ok = False
                            break
        
        if not ok:
            print(-1)
            continue
        
        res = []
        for a, b, c in edges:
            if c != -1:
                res.append(c)
            else:
                diff = (color[a] - color[b]) % 3
                res.append(diff + 1)
        
        print(*res)

if __name__ == "__main__":
    solve()
```该实现首先构建一个约束图，其中每个彩色边变成其端点之间的模方程。 BFS 分配顶点标签并立即检查一致性。 一旦标签被固定，每个未着色的边缘都会使用计算出的差异直接解析。 

一个常见的实现陷阱是在构建反向约束时忘记处理负差异的模归一化。 另一个微妙之处是，在 BFS 传播过程中，未着色的边缘会被忽略； 它们不施加约束，并且不得影响一致性检查。

 ## 边缘情况

 一个重要的边缘情况是强制矛盾的约束循环。 例如，如果边缘意味着`x1 = x2`,`x2 = x3`,`x3 = x1 + 1 mod 3`，BFS 将为前两条边分配一致的值，但在处理最后一条边时，它将重新访问已分配的顶点并检测不匹配。 算法正确输出`-1`因为不存在一致的顶点标记。 

另一种情况是断开连接的图，其中每个组件都有独立的约束。 BFS 从每个未访问的顶点重新启动，分配一个新的`0`基线。 这是可行的，因为解在全局变化下是不变的`{0,1,2}`，因此每个组件都可以独立锚定，而不影响跨组件的一致性。 

第三种情况是所有边缘均未着色。 BFS 分配所有顶点`0`，并且每条边都变成颜色`1`。 这很容易满足三角形条件，因为所有三角形都是单色的，表明该算法自然地处理缺乏约束的情况。
