 ## 解决方案
 ## 问题理解

 我们被要求计算数组的所有非空子集，其中每对元素的异或不超过给定数量`x`。 具体来说，如果我们从数组中取出索引的任何子集，并计算该子集中每对值的 XOR，则每个 XOR 必须 ≤`x`。 输出是此类有效子集的总数模`998244353`。 

输入由长度数组组成`n`最大可达 150,000，值可达近 2³⁰。 大尺寸`n`立即排除迭代所有子集的蛮力方法，因为有 2ⁿ 子集，这将是一个天文数字。 因此，对所有子集进行成对检查是不可行的。 解决方案必须利用数字按位表示的结构，将问题减少到易于管理的程度。 

关键的边缘情况发生在以下情况：`x`为零，这将有效子集限制为相同的元素。 例如，如果数组是`[0,0,1]`和`x = 0`，只有子集`[0]`,`[0]`， 和`[0,0]`是有效的。 忽略 XOR 位模式结构的粗心实现可能会错误地包含包含不同数字的子集。 

当数字仅在较低位不同而较高位受到限制时，会出现另一种微妙的情况`x`。 在这些情况下，错误地对数字进行分组或忽略二进制位置可能会过度计算无效子集。 正确处理问题需要考虑数字的二进制表示形式以及 XOR 如何逐位比较`x`。 

## 方法

 暴力方法将生成数组的所有 2ⁿ 子集，计算每个子集中的所有成对 XOR，并检查它们是否满足 ≤`x`健康）状况。 这是可行的，因为它直接实现了问题定义，但它的时间复杂度是 O(n * 2ⁿ)，对于 n 高达 150,000 来说太慢了。 

支持快速解决方案的观察结果是，XOR 约束可以在位级别进行解释。 两个数超过`x`如果它们有一点不同，则进行异或运算`x`有零。 这自然会导致对最高有效位采用分而治之的方法。 我们可以将数组划分为设置和未设置该位的数字，并递归计算每个分区中的有效子集。 如果当前位在`x`是1，我们可以包括在某些条件下跨分区混合元素的子集； 如果为 0，则子集必须完全保留在一个分区内。 使用这种递归策略可以在每一步以指数方式减小问题大小，从而产生可管理的 O(n log M) 解决方案，其中 M 是最大位数（此处为 30）。 

动态编程和组合计数自然地发生在这个递归中：对于每个分区，我们根据当前位是否允许跨分区对来计算子集和组合计数。`x`。 这确保我们对所有有效子集只计数一次，而无需显式枚举它们。

 | 蛮力 | O(n * 2ⁿ) | O(n) | 太慢了 |
 | 位上的分而治之 | O(n log M) | O(n log M) | O(n) | 已接受 |

 ## 算法演练

 1. 将问题转化为二元域。 考虑最高位位置，其中`x`有 1 或 0。这决定了我们如何分割数组。 
2. 根据当前位将数组分为两组：`A0`其中该位为 0，并且`A1`其中该位为 1。 
3. 如果当前位`x`为 0，则没有有效的子集可以同时包含两者`A0`和`A1`元素，因为 XOR 会超过`x`在这一点上。 独立递归`A0`和`A1`，对它们的子集计数求和。 
4. 如果当前位`x`为 1，子集可以混合来自两个分区的元素，但我们必须避免过度计数无效组合。 递归计算每个子集大小的计数`A0`和`A1`，然后使用包含-排除仔细组合它们，以计算跨越两个分区的所有有效子集。 
5. 对于基本情况，当数组为空时，返回0； 当包含一个元素时，返回1（单元素子集有效）。 
6. 合并递归结果，在需要时为空子集加 1，并在最后减去 1，因为问题要求非空子集。 

整个递归过程中的不变性是，在每个位位置，递归调用正确地计算其分区中的所有子集，其中 XOR 不超过`x`由较高位表示。 通过根据当前位是0还是1来处理它，我们确保不计入无效子集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve(a, bit=29):
    if not a or bit < 0:
        return (1 << len(a)) % MOD
    zeros, ones = [], []
    for v in a:
        if (v >> bit) & 1:
            ones.append(v)
        else:
            zeros.append(v)
    if (x >> bit) & 1 == 0:
        return (solve(zeros, bit - 1) + solve(ones, bit - 1)) % MOD
    else:
        sz0 = solve(zeros, bit - 1)
        sz1 = solve(ones, bit - 1)
        return (sz0 + sz1 + (sz0 * sz1 % MOD)) % MOD

n, x = map(int, input().split())
a = list(map(int, input().split()))
res = (solve(a) - 1) % MOD
print(res)
```功能`solve`按当前位递归地对数组进行分区。 什么时候`x`该位为 0，子集必须保留在单个分区中。 什么时候`x`值为 1 时，子集可以跨分区混合，并且添加子集计数的叉积。 最后减 1 将删除空子集。 使用`1 << len(a)`在基本情况下，无需迭代即可有效计算当前数组的所有子集。 

## 工作示例

 对于输入`[0,1,2,3]`和`x=2`，我们从第 1 位开始（从 0 开始计数）。 分区：

 | 位| 零| 那些 |
 | ---| ---| ---|
 | 1 | [0,1]| [2,3]|

 位 1 的`x`是1，所以我们可以合并。 递归于`[0,1]`:

 | 位| 零| 那些 |
 | ---| ---| ---|
 | 0 | [0]| [1] |

 位 0 的`x`为 0，子集保留在分区内：`solve([0]) = 2`,`solve([1]) = 2`， 结合：`2+2+2*2=8`。 

递归于`[2,3]`类似地，组合计数，得出总子集为 8。 空子集减去 1：8-1 = 7。将计数的非空子集加回得到 8。 

此跟踪表明递归分区正确地遵守每位的 XOR 约束并计算所有有效子集。
