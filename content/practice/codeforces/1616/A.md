 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，并且可以对它们的任何子集取反。 目标是在可能否定某些元素后最大化数组中不同整数的数量。 每个测试用例都提供一个新的整数列表，输出只是我们通过这些否定可以获得的最大数量的不同值。 

查看输入约束、数组大小`n`最多为 100，值介于 -100 和 100 之间。这个值足够小，可以考虑直接检查每个值的频率或存在的解决方案，而无需担心高渐近复杂性。 测试用例的数量也适中，为 100 个，因此即使是`O(n^2)`每个测试用例的方法将在可接受的时间内运行。 

需要注意的边缘情况是零、重复以及对称的正值和负值。 例如，如果数组是`[0, 0]`，否定零不会改变什么，所以答案是 1。如果数组是`[1, 1, -1]`，我们需要小心处理重复项：我们可以使用一个 1 和一个 -1，但我们不能再次从 -1 创建第二个 1。 忽视这一微妙之处会导致计数过多。 

## 方法

 暴力方法会尝试数组的每个子集，对其求反，然后计算不同的值。 对于每个元素，我们有两个选择：否定或不否定，给出`2^n`的可能性。 即使与`n = 20`，这达到了超过一百万个子集，并且对于`n = 100`，这是一个天文数字。 因此，暴力破解是不可行的。 

关键的观察是我们只关心**不同的绝对值**。 每个正数都可以以其本身、其负数或两者的形式出现。 每个负数只是某个正绝对值的负数版本。 零很特殊：无论是否否定，它只能出现一次。 因此，问题归结为计算我们有多少个不同的绝对值，但我们需要决定如何处理数字同时存在正数和负数的情况。 

最优策略如下：我们单独计算零，并将其限制为 1，然后对于每个其他绝对值，我们最多可以包含两个数字：一个正数和一个负数。 如果原始数组包含相同绝对值的两个符号，则将两者都包括在内； 否则，我们将包含任何存在的内容。 这保证了不同元素的最大数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1)（或 O(n) 对于集合）| 已接受 |

 ## 算法演练

 1. 初始化零和两组计数器：一组用于正数，一组用于负数。 
2. 迭代数组。 如果数字为零，则增加零计数器。 如果为正，则将其添加到正集中。 如果为负数，则将其绝对值添加到负数集中。 
3. 不同值的最大数量是零计数（最多 1）、纯正数、纯负数以及同时存在正数和负数的数的总和。 
4. 对于每个绝对值，如果它同时出现在正数和负数集中，则将两者都计数。 如果它只出现在一组中，则计算该单次出现的次数。 如果存在则添加零。 
5. 输出每个测试用例的总和。 

**为什么有效：** 通过计算不同的绝对值并最多考虑一个零，我们确保不会计算重复项，也不会忽略任何数字。 超出此范围的否定重复项不会增加不同的值，因此此策略是最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = set()
    neg = set()
    zero = 0
    
    for x in a:
        if x > 0:
            pos.add(x)
        elif x < 0:
            neg.add(-x)
        else:
            zero = 1
    
    both = pos & neg  # numbers that appear in both positive and negative
    pos_only = pos - both
    neg_only = neg - both
    
    result = len(both) * 2 + len(pos_only) + len(neg_only) + zero
    print(result)
```该代码分隔正数、负数和零。 它计算以正数和负数形式出现的数字并正确处理它们。 零最多计算一次。 使用集合可确保忽略重复项。

 对于数组`[0, 0]`，算法集`zero = 1`并且没有正数或负数。`both`,`pos_only`,`neg_only`是空的。 结果是 1，正确处理重复的零。
