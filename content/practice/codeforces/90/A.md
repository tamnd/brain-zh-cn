 ## 解决方案
 ## 问题理解

 索道每分钟发一趟缆车，颜色以固定周期重复：`red -> green -> blue -> red -> ...`每辆缆车最多可搭载两名学生，每次乘坐正好需要30分钟才能到达山顶。 

我们分为三组学生。 一组只乘坐红色汽车，另一组只乘坐绿色汽车，最后一组只乘坐蓝色汽车。 任务是计算每个学生到达顶部的最早时刻。 

关键细节是，出发时刻表是完全固定的。 我们无法重新排序颜色或加快任何速度。 唯一的选择是有多少学生登上每辆到达的缆车。 

限制很小，每个组的大小最多为 100。即使是直接模拟也很容易在时间限制内完成。 这意味着真正的挑战是清楚地认识到潜在的模式并避免相差很大的错误。 

粗心的实施很容易将出发时间与到达时间混淆。 例如：

 输入：```
1 0 0
```红色缆车准时到达`0`，但学生只在某个时间到达顶部`30`。 

正确输出：```
30
```另一个容易犯的错误是忘记每辆车载有两名学生。 考虑：

 输入：```
3 0 0
```红色汽车时不时出现`0, 3, 6, ...`第一辆红色汽车同时载有两名学生`0`，第二辆红色汽车当时载着剩下的学生`3`。 最终到达时间为`3 + 30 = 33`。 

正确输出：```
33
```像这样的天真的公式`r * 3 + 30`会错误地产生`39`。 

当一个或两个组为空时，还有一个微妙的边缘情况。 假设：

 输入：```
0 0 1
```蓝色汽车首先出现的时间`2`，不是时间`0`。 学生到达`2 + 30 = 32`。 

正确输出：```
32
```如果我们忘记不同的颜色从不同的偏移量开始，答案就会立即变得错误。 

## 方法

 最直接的方法就是逐分钟模拟缆车。 每分钟，我们都会使用以下方法确定到达的颜色`time % 3`。 如果该肤色的学生仍在等待，最多两人上车。 我们继续下去，直到每组都空了，答案就是当前时间加 30。 

这个模拟是正确的，因为时间表是确定的，每辆有用的汽车都应该总是贪婪地装满。 空座位永远不会有帮助，因为未来相同颜色的汽车只会晚点到达。 

尽管这种暴力解决方案在这里是完全可以接受的，但它仍然执行不必要的分分钟工作。 最坏的情况下，我们可能会模拟150分钟左右。 这仍然是微不足道的，但问题的结构允许直接的数学解决方案。 

关键的观察是每种颜色每三分钟定期出现一次：

 红色汽车出发地点：```
0, 3, 6, 9, ...
```绿色汽车发车地点：```
1, 4, 7, 10, ...
```蓝色车出发时间：```
2, 5, 8, 11, ...
```每辆车载两名学生，所以一组人数`x`需求：```
ceil(x / 2)
```其颜色的汽车。 

如果需要某种颜色`k`汽车，该颜色的最后出发时间是：```
offset + (k - 1) * 3
```其中偏移量是：```
red   -> 0
green -> 1
blue  -> 2
```出发后，车程还需要30分钟。 答案很简单，就是三种颜色中的最长到达时间。

 ## 算法演练

 1. 读取三个组的大小`r`,`g`， 和`b`。 
2. 对于每种颜色，计算需要多少辆缆车。 

由于每辆缆车最多载两名学生，因此所需车厢数量为：```
(x + 1) // 2
```这是整数上限除法`x / 2`。 
3. 计算每种颜色最后一班缆车的出发时间。 

红车准时出发`0`，绿色在`1`，和蓝色在`2`。 

如果需要某种颜色`k`汽车，最后一班出发时间为：```
offset + (k - 1) * 3
```因为连续的相同颜色的汽车间隔3分钟。 
4. 忽略零学生的颜色。 

它们对最终答案没有贡献。 
5. 在每个最后出发时间上加上 30 分钟即可获得到达时间。 
6.输出所有颜色中最大到达时间。 

只有当最慢的一组到达顶部时，整个组才完成。 

### 为什么它有效

 每种颜色都是独立运行的，因为学生只选择他们喜欢的颜色。 每种颜色的时间表都是固定且周期性的，因此运送所有学生的最早可能方法是立即填满所有可用的缆车。 

对于有需要的群体`k`游乐设施，这些游乐设施必须使用第一个`k`那种颜色的缆车。 任何延误只会导致最终抵达时间推迟。 由于乘车时间始终为 30 分钟，因此最大限度地缩短最后出发时间也会最大限度地缩短最后到达时间。 

采取不同颜色的最大值是可行的，因为所有团体同时且独立地旅行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    r, g, b = map(int, input().split())

    ans = 0

    groups = [
        (r, 0),  # red
        (g, 1),  # green
        (b, 2)   # blue
    ]

    for cnt, offset in groups:
        if cnt == 0:
            continue

        cars = (cnt + 1) // 2
        last_departure = offset + (cars - 1) * 3
        ans = max(ans, last_departure + 30)

    print(ans)

solve()
```解决方案直接遵循数学观察。 

变量`cars`计算一种颜色组需要多少辆缆车。 使用`(cnt + 1) // 2`是上限除以二的标准整数技巧。 

表达式：```
offset + (cars - 1) * 3
```计算该颜色的最终有用缆车的出发时间。 减一很重要。 如果只需要一辆缆车，则最后一次发车应恰好在初始偏移处发生。 

例如，对于一名蓝色学生：```
cars = 1
last_departure = 2 + (1 - 1) * 3 = 2
```这是正确的。 

最后，我们添加 30 分钟，因为每次骑行的行程时间都是固定的。

 ## 边缘情况

 考虑输入：```
1 0 0
```红学生按时间乘坐缆车`0`并到达`30`。 该算法计算：```
cars = 1
last_departure = 0
arrival = 30
```与真实过程完全吻合。 

现在考虑：```
3 0 0
```当时第一辆红色汽车`0`载着两名学生。 当时的第二辆红色汽车`3`带着剩下的学生。 最终到达的是：```
3 + 30 = 33
```该算法计算：```
cars = (3 + 1) // 2 = 2
last_departure = 0 + (2 - 1) * 3 = 3
answer = 33
```减一在`(cars - 1)`防止差一错误。 

最后，考虑：```
0 0 1
```蓝色汽车时不时出现`2, 5, 8, ...`当时唯一的学生会`2`并到达`32`。 

该算法计算：```
cars = 1
last_departure = 2
arrival = 32
```这确认颜色偏移处理正确。
