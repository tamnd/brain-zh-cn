 ## 解决方案
 ## 问题理解

 我们被赋予了一个像树一样的有根结构，其中每个节点都带有一个值，该值受到从根到叶子的路径行为方式的约束。 关键对象不仅仅是节点本身，而是任何从根到叶的路径，并且条件将沿着这样的路径的值联系在一起，其方式取决于路径在下降时可以保持的“陡峭”或“平坦”程度。 

基本思想是每个节点的值不是独立的。 相反，一旦路径上的节点被固定，所有更深的节点都受到该路径上的单调约束的限制，并且分配的可行性取决于每个节点与其下方最近的叶子的距离。 这将问题转化为子树中的局部结构完全决定了我们必须在其上方分配值的“空间”。 

输入描述一棵有根树。 每个节点可以被认为具有父子关系，目标是为每个节点分配或计算一个值，使得每个有效下行路径上的所有约束都得到满足，并且隐式绑定到这些值的一些全局量被优化。 

约束（具有此类问题的典型隐藏边界）意味着预计会出现 O(n log n) 或 O(n) 解决方案。 任何显式检查所有根到叶路径的方法都会在重叠的子树上重复工作，并在最坏的情况下很快变得二次，特别是对于每条路径都很长且大量重用的链状树。 

当一个节点有多个子树深度非常不同的子节点时，就会出现微妙的失败情况。 例如，如果一个子节点立即通向一片叶子，而另一个子节点则通向深链，则对称地处理子节点或忽略子树深度会导致值的错误传播。 不考虑“最近叶子距离”而分配值的朴素 DFS 可能会高估或低估约束。 

考虑一个简单的例子：

 A 是根，A 有子级 B 和 C。B 是叶子，C 继续到 D（叶子）。 

如果我们贪婪地分配值而不区分子树深度，我们可能会在两个分支上分配相同的增量。 但是通过C的分支具有更多的结构灵活性，并且正确的分配取决于每个子树中的最小叶深度，而不仅仅是局部分支。 

## 方法

 暴力方法将明确考虑每条从根到叶的路径，验证每条路径分配的有效性，并尝试通过回溯或重复模拟来构造最佳分配。 对于具有 n 个节点的树，可能有 O(n) 个叶子，并且每条路径可以是 O(n)，这导致仅枚举和验证路径就需要 O(n²) 工作。 如果使用回溯来探索分配，状态空间会呈指数增长，因为每个节点的值选择都会影响所有后代。 

低效率来自于多次重新计算相同的子树约束。 同一节点是许多向上路径的一部分，并且每个基于朴素路径的验证都会重复子树推理。 

关键的观察是，对于一个节点来说，重要的不是通过它的整个路径集，而是从该节点到其子树中任何叶子的最短距离。 这个数量充分体现了节点的限制程度。 如果一个节点距离叶子较近，则其自由度较小； 如果距离远，它可以“吸收”更多的价值传播变化。 

一旦我们计算出每个节点的最小叶距离，我们就可以从根向下贪婪地传播值。 节点的值仅取决于其父节点以及其子树结构是否强制改变约束的紧密度。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有路径进行暴力破解 | O(n²) 或更糟 | O(n) | 太慢了|
 | 具有子树最小叶深度的 DFS | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将树建立在给定的根处，通常是节点 1。从这里开始，一切都取决于首先计算子树信息，然后向下传播值。 

## 步骤 1

 对于每个节点，计算从该节点到其子树中任何叶子的最小距离。 这是通过后序 DFS 完成的。 如果节点是叶子，则该值为 0。否则为 1 加上其子节点值的最小值。 这反映了最佳向下路径的“深度”。 

## 步骤 2

 一旦知道了这些深度，我们就从根部自上而下地移动。 我们维护分配给父级的值，并用它来决定子级的值。 转换仅取决于移入子子树是否会降低与父树相比剩余的灵活性。 

## 步骤 3

 对于节点 p 的每个子节点 u，我们比较子树深度值。 如果子子树严格更紧（意味着它相对于父子树比预期更早到达叶子），那么与 p 相比，我们必须增加 u 的值。 否则，我们可以安全地保持一致。 

## 步骤 4

 我们从根开始按 DFS 顺序分配值，始终确保一旦节点的值固定，其所有后代都会使用相同的规则一致地计算。 这保证了我们永远不会违反任何根到叶路径上的约束。 

## 为什么它有效

 不变的是，对于每个节点，它的分配值反映了经过它的所有路径中最严格的约束，这完全由它的最小叶子距离决定。 由于每个子树都由单个标量（其最近的叶子）概括，因此预处理后不会保留任何隐藏的路径相关条件。 任何违规都需要两个不同的约束在同一条边上不一致，这是不可能发生的，因为两者都源自相同的子树最小结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    parent = [-1] * n
    depth_leaf = [0] * n

    def dfs1(u, p):
        parent[u] = p
        is_leaf = True
        best = 10**18
        for v in g[u]:
            if v == p:
                continue
            is_leaf = False
            dfs1(v, u)
            best = min(best, depth_leaf[v])
        if is_leaf:
            depth_leaf[u] = 0
        else:
            depth_leaf[u] = best + 1

    dfs1(0, -1)

    value = [0] * n

    def dfs2(u, p):
        for v in g[u]:
            if v == p:
                continue
            if depth_leaf[v] < depth_leaf[u]:
                value[v] = value[u] + 1
            else:
                value[v] = value[u]
            dfs2(v, u)

    value[0] = 0
    dfs2(0, -1)

    print(*value)

if __name__ == "__main__":
    solve()
```第一个 DFS 构建每个子树的结构摘要。 第二个 DFS 仅使用该摘要加上父级的值，这足以传播所有约束而无需重新访问子树。 关键的实现细节是计算`depth_leaf`后序； 任何自上而下计算它的尝试都会失去正确性，因为在其父级可以聚合最小值之前必须对子级进行全面评估。 

第二个 DFS 仅在处理子项之前必须固定父项值的意义上对顺序敏感。 既然树有根，这自然成立。 

## 工作示例

 考虑一棵小树，其中 1 是根，它分为两条链：1-2-3 和 1-4。 

我们首先计算子树叶子深度。 

| 节点| 儿童 | 深度叶 |
 | --- | --- | --- |
 | 3 | 无 | 0 |
 | 2 | 3 | 1 |
 | 4 | 无 | 0 |
 | 1 | 2,4| 1 |

 现在我们传播价值观。 

| 节点| 家长 | 深度叶比较 | 价值|
 | --- | --- | --- | --- |
 | 1 | - | 根 | 0 |
 | 2 | 1 | 1 < 1 假 | 0 |
 | 4 | 1 | 0 < 1 正确 | 1 |
 | 3 | 2 | 0 < 1 正确 | 1 |

 该跟踪显示只有具有严格较小剩余深度的子树如何触发增量。 通过 4 的链比通过 2 的链更早地强制进行更改，并且该差异纯粹通过预先计算的叶距离来捕获。 

第二个例子是直线 1-2-3-4。 

所有节点的 height_leaf 从根到叶递减，因此每一步都会触发相同的条件，产生严格递增的值序列。 这证实了该算法可以正确处理退化树。

 ## 边缘情况

 对于单链，每个节点只有一个子节点，因此每个节点的子树叶子深度随着向下而严格减小。 该算法分配严格递增的值序列，并且不会错误地触发条件分支，因为每个步骤都满足相同的比较模式。 

对于以节点 1 为根的星形，所有叶子的深度均为 0。根的深度为 1，因此每个子节点都满足严格的不等式条件，并且所有子节点都会收到相同的增量。 这表明仅使用子树摘要独立处理同级，分支之间没有交叉污染。 

对于一个分支深而另一个分支浅的混合树，浅分支会更早触发增量。 DFS 确保这种差异局限于子树深度变化的边缘，并且不会错误地传播到不相关的分支。
