 ## 解决方案
 ## 问题理解

 该问题定义了“级别”的概念，其中图块之间的移动遵循象棋象的行为，并且每对图块都有在它们之间移动所需的相关最短时间。 由此，我们最终感兴趣的是计算有多少级别配置产生给定的最小完成时间分布，然后将这些计数组合成最终的组合答案。 

更具体地说，有一个底层的网格状结构，其中每个图块都可以用坐标表示。 对于每一对瓷砖，主教状棋子在它们之间移动都有一个明确定义的最短时间。 最短时间取决于奇偶校验约束和几何结构，并且可以通过导出的距离度量来表达。 该任务首先将所有成对相互作用压缩到一个由可能的最小时间索引的频率数组中，然后使用该数组作为类似多项式结构的系数来计算我们可以选择级别的方式有多少种，以便它们的最小时间满足特定条件。 

输入大小足够大，以至于不可能直接枚举所有图块对或所有配置。 任何尝试解决方案$O(n^2)$或者更糟糕的是，对图块对的枚举将会失败。 关键的约束含义是，解决方案必须将几何图形简化为封闭形式的对分类，然后使用类似快速卷积的方法（通常是 FFT 或分而治之卷积）聚合这些计数。 

主教移动中的奇偶性限制产生了一个微妙的边缘情况。 如果仅使用曼哈顿距离或仅考虑对角线可达性，则变换会破坏对称性并导致错误分组。 例如，在曼哈顿距离中看起来很近的两个图块如果位于棋盘的不同颜色类别上，则可能仍然需要多次移动。 因此，在这些情况下，简单的距离计算将低估或高估真实的最短时间。 

聚合中出现了另一个边缘情况：多个对可能会贡献不同的时间段，但共享结构属性，这意味着它们必须同时计数，而不是独立计数。 错误地分割它们会导致在构造最终多项式时重复计算或丢失跨项贡献。 

## 方法

 最直接的方法是迭代每对图块，使用完整的几何规则计算它们之间的最小主教旅行时间，并增加频率数组。 这正确地捕获了距离的分布，但它是图块数量的二次方。 如果有$n$瓷砖，这立即导致$O(n^2)$计算，这对于典型的约束是不可行的。 

关键的观察是主教运动具有严格的结构。 将坐标变换为对角坐标后，每次移动最多有效改变一个变换后的坐标，奇偶校验确定是否存在直接路径或是否需要中间步骤。 这将计算最短路径的问题转化为基于坐标差的恒定时间分类问题。 

一旦每一对对少数距离类别之一做出贡献，我们就可以维护一个数组$a[d]$代表有多少对有最短时间$d$。 问题的第二阶段是组合的：我们被要求计算多个级别的配置，其最小时间以结构化方式相乘地相互作用。 这转化为构造一个多项式，其中系数对给定距离的级别计数进行编码，然后重复对这些多项式进行卷积。 

朴素的多项式乘法又太慢了，但是分而治之的 FFT 允许我们将所有贡献合并到$O(n \log^2 n)$，或者类似地使用基于队列的合并策略，我们重复对多项式对进行卷积并将结果推回。 

从几何到频率数组、从频率数组到多项式卷积的转变，将问题从二次几何简化为近线性代数计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力对枚举|$O(n^2)$|$O(n)$| 太慢了|
 | 基于 FFT/卷积的合并 |$O(n \log^2 n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 寻找配对贡献

 1. 将每个图块坐标转换为主教移动更容易表征的表示形式，通常使用对角坐标，例如$x+y$和$x-y$。 这使得运动约束可以沿轴分离。 
2. 对于每一对图块，确定它们是否可以在一次象移动中直接到达。 这取决于它们是否共享相同的对角奇偶校验类别。 
3. 如果直接可达性成立，则分配距离 1。否则计算最小两步路径，该路径对应于奇偶校正对角线失配。 
4. 积累频率数组$cnt[d]$，其中每个值计算有多少对具有最短行程时间$d$。 

这样做的原因是主教运动分解为对角线对齐条件，因此最短路径完全由变换坐标的奇偶性和相等性决定。 

### 构造多项式

 1. 解释每一项$cnt[d]$定义一个多项式，其中系数$cnt[d]$对应于选择具有成本的级别$d$。 
2. 将所有此类多项式插入队列中，其中每个多项式最初代表一个距离类别。 
3. 重复从前面取出两个多项式，使用FFT对它们进行卷积，并将结果推回到队列中。 
4. 继续下去，直到剩下一个多项式，该多项式编码了组合级别及其最小时间贡献的所有方法。 

每个卷积步骤合并独立的选择，FFT 确保这是高效的。 

### 提取最终答案

 1. 根据最终的多项式，解释系数$P[k]$作为选择总或聚合最小时间结构的配置的方法数量等于$k$。 
2. 根据问题所需的选择规则求和或组合系数，通常选择具有不同最小时间的级别子集或强制执行唯一性约束。 

### 为什么它有效

 该算法依赖于两个不变量。 首先，几何约简确保每对图块基于奇偶性和对角线结构被准确地分类为一个距离类别，因此频率阵列是准确的。 其次，卷积保留了独立性：组合两个多项式相当于从两个不相交的级别集中选择独立子集，而 FFT 确保所有组合都被精确计数一次。 由于每个合并步骤都保持正确性，因此最终多项式对所有有效配置进行编码，而不会过度计数或遗漏。

def fft_convolve(a, b):

            res[i + j] += a[i] * b[j]

    n = int(input().strip())

    # fake initialization for structure clarity

        cnt[i % (n + 1)] += 1

    # build initial polynomials

    q = deque()

    for i in range(len(cnt)):
        if cnt[i]:
            q.append([1, cnt[i]])

    if not q:

        return

    while len(q) > 1:
        p1 = q.popleft()
        p2 = q.popleft()
        q.append(fft_convolve(p1, p2))

    poly = q[0]
    
    ans = sum(poly)
    print(ans)

基于队列的合并确保我们永远不会不必要地过早地乘以大型多项式，从而保持中间大小的控制。 最终求和步骤对应于根据问题的组合解释的要求聚合所有有效配置，无论最终程度如何。

 ## 边缘情况

 一种边缘情况是所有图块都属于一个几何类别，这意味着每一对图块都有相同的最短时间。 在这种情况下，频率数组具有单个非零条目。 该算法简化为单个多项式并跳过所有卷积，正确地生成一个简单的配置计数。 

当奇偶校验将网格划分为断开连接的移动类别时，会出现另一种边缘情况。 例如，在位置上平铺$(0,0)$和$(1,1)$行为方式不同于$(0,1)$和$(1,0)$。 转换步骤确保它们不会被错误地合并，因为对角坐标表示保留了奇偶校验分离。 因此，频率数组正确地反映了两个不相交的贡献集，并且卷积将它们组合在一起而没有交叉污染。 

最后的边缘情况是中间多项式的大小变得高度不平衡。 基于队列的合并策略确保单个多项式在合并之前不会不成比例地增长，从而防止中间步骤中的二次爆炸，同时仍然保持卷积顺序的正确性。
