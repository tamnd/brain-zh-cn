 ## 问题理解

 该任务围绕应用标准舍入规则进行，这与我们在算术中学习的“舍入到最接近的整数”背后的想法相同，但在以文本或基于数字的形式给出的数字上实现。 该问题要求我们直接使用数字来操作数字，而不是进行浮点运算。 

实际上，输入可以解释为以 10 为基数编写的非负整数。目标是通过执行单个舍入操作来转换它：我们查看要删除的最低有效数字，确定它是否更接近较低值或较高值，并在需要时传播任何进位。 输出是此过程后得到的舍入数。 

关键的困难在于数字可能很大，因此无法安全地存储在某些语言中的内置整数类型中，即使可以，操作本身也是在结构上定义的数字而不是算术值。 

在实现不带进位传播的舍入时，会出现一个天真的但常见的错误。 例如，考虑像 1995 这样的输入。如果我们只是检查最后一位数字并将倒数第二位数字向上舍入而不处理级联进位，我们可能会错误地生成 1990 或 2005，而不是正确的 2000。另一种失败情况是当舍入级联跨越多个 9 时，例如 999，其中每个数字在舍入后都会发生变化，产生 1000。任何解决方案都必须正确处理这种连锁反应。 

另一个微妙的问题是假设只有最后一位数字很重要。 事实上，一旦四舍五入导致数字变成 10，它就会影响所有更高的数字，因此该过程本质上是迭代或向后传播的。 

## 方法

 暴力方法是将字符串转换为数字，使用算术规则执行舍入，然后将其转换回字符串。 这在概念上很简单：解释该值，计算舍入位置的余数，并进行相应调整。 这种方法的问题在于它依赖于本机整数或浮点表示。 对于大输入，转换本身可能会溢出或丢失精度，即使没有，它也会掩盖舍入所需的数字级传播行为。 

更强大的方法直接作用于数字数组。 关键的观察结果是，舍入仅取决于紧邻舍入边界右侧的数字，但舍入的影响可以向左传播。 这意味着我们可以从右到左模拟该过程，维护是否应该添加进位。 一旦我们决定一个数字向上舍入，如果它导致另一个进位，我们可能需要继续向左传播该增量。 

这将问题变成了从数字末尾开始的一次传递，我们要么提前停止，要么继续传播进位，直到问题解决。 这种结构确保了线性时间复杂度并避免了任何转换问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|

 ## 算法演练

 我们将数字视为字符列表，以便我们可以就地修改数字。

1. 从最右边的数字开始向左扫描，找到第一个需要四舍五入的位置。 这是在丢弃部分中触发 5 或更大值的第一个数字。 此步骤确定舍入改变数字的枢轴点。 
2. 一旦找到枢轴，我们设置一个进位来指示枢轴处的数字必须递增。 这表示在该位置进行四舍五入。 
3. 从枢轴向左移动，通过添加进位来更新每个数字。 如果一个数字变为 10，我们将其设置为 0 并保持进位为 1。否则，我们将进位重置为 0 并停止传播。 
4. 如果到达最高有效位后仍有进位，则插入一个新的前导数字 1。这可以处理 999 变为 1000 等情况。 
5. 主元右侧的所有数字均替换为零，因为四舍五入消除了它们的贡献。 

这样做的原因是舍入仅在一个位置引入单个单位的增加，任何级联效应纯粹是由于以 10 为基数的溢出造成的。 该算法保持了当前位置右侧的所有内容都已与舍入规则一致的不变量，并且任何时候都只能存在单个进位，表示未解决的溢出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = list(input().strip())
    n = len(s)

    # find first digit that causes rounding when looking from right
    pivot = -1
    for i in range(n - 1, -1, -1):
        if s[i] >= '5':
            pivot = i

    if pivot == -1:
        print("".join(s))
        return

    carry = 1

    # set all digits right of pivot to zero
    for i in range(pivot + 1, n):
        s[i] = '0'

    # propagate carry from pivot leftwards
    i = pivot
    while i >= 0 and carry:
        val = (ord(s[i]) - ord('0')) + carry
        if val == 10:
            s[i] = '0'
            carry = 1
        else:
            s[i] = str(val)
            carry = 0
        i -= 1

    if carry:
        s.insert(0, '1')

    print("".join(s))

if __name__ == "__main__":
    solve()
```该解决方案首先确定从右侧开始必须进行舍入的第一个位置。 该位置右侧的所有内容立即设置为零，因为这些数字在四舍五入后被丢弃。 

传播循环是关键部分。 它模拟在枢轴处添加一个单位并逐位处理溢出。 使用字符算术可以避免将整个字符串转换为整数，从而保证解决方案对于非常大的输入是安全的。 

一个微妙的点是，即使多个连续数字都是 9，我们也必须继续传播，因为每个数字都会变成 0 并继续进位。

 ## 边缘情况

 一个关键的边缘情况是整个数字由 9 组成。 在像 999 这样的输入中，舍入会强制每个数字重置为 0，并且必须创建一个额外的前导 1。 该算法通过允许进位在处理最高有效数字后保持活动状态来处理此问题，从而触发新数字的插入。 

另一种边缘情况是没有数字触发舍入。 在这种情况下，主元保持未设置状态，并且算法返回原始数字不变。 这可以避免不必要的修改并确保 120 或 5000 等输入的正确性。 

最后的边缘情况涉及一位数输入。 如果数字小于5，则数字保持不变。 如果是5或者更大，就会变成10，这就需要延长结果的长度。
