 ## 解决方案
 ## 问题理解

 该问题要求长度为 2 的二进制数组中所需的最少数量$n$满足一组前缀和后缀约束。 具体来说，对于每个长度的前缀$i$，个数必须至少为$\lceil i/k \rceil$，并且对于每个长度后缀也必须成立$i$。 输入由多个测试用例组成，每个测试用例给出$n$和$k$，输出是每个测试用例的一个整数，表示最小的个数。 

鉴于限制条件，$n$最多为 100 并且$t$最多 10,000，因此我们需要一个能够在接近恒定的时间内计算每个测试用例的解决方案。 数组的暴力枚举是不可行的，因为有$2^n$可能的数组。 问题的不明显部分来自重叠的前缀和后缀条件。 例如，一种简单的方法仅确保第一个$\lceil n/k \rceil$元素是可能违反后缀条件的元素。 小值$k$或者$k = 1$是边缘情况，因为它们迫使几乎所有元素都是 1，而$k \ge n$允许很少的。 

当出现具体的边缘情况时$k = 1$。 这里$\lceil i/1 \rceil = i$，所以每个前缀和后缀必须完全是 1，这意味着答案正是$n$。 另一个微妙的情况是当$n$是的倍数$k$; 的分布是均匀的，但如果$n$不能被整除$k$，上限操作在最后添加了额外的，我们必须仔细考虑。 

## 方法

 暴力方法将枚举所有长度的二进制数组$n$，检查每个前缀和后缀的个数是否满足$\lceil i/k \rceil$，并跟踪最小计数。 这是正确的，但在计算上是不可能的，因为它涉及$2^n$每个测试用例的数组。 和$n$达到100，这显然是不可行的。 

最佳方法来自于观察前缀和后缀条件都对前缀和后缀条件施加了统一的间距要求。 关键的见解是，最小数量取决于覆盖大小“块”所需的数量$k$。 如果我们想象将数组划分为连续的长度块$k$，每个块必须至少包含一个 1 来满足其最后一个元素的条件。 形式上，最小个数是$\lceil n/k \rceil$。 这确保了每个长度的前缀$i$有足够的，并且对称地，由于前缀和后缀中上限函数的对称性，如果我们从一端均匀地放置，则自动满足后缀要求。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$k$。 这些值定义了上限值函数的数组长度和块大小。 
2. 计算所需的最小数量作为上限$n/k$。 这会计算至少需要一个的块的数量。 
3. 为测试用例输出该值。 

推理是如果我们有$\lceil n/k \rceil$，我们可以以每个大小块的方式放置它们$k$至少包含一个。 这保证了前缀和后缀条件成立，因为任何前缀或后缀都可以跨越多个块，并且每个块至少贡献一个。 任何较少的数字都会留下一些没有 1 的块，从而违反了包含该块的前缀或后缀的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        # minimum number of ones is ceiling of n / k
        ans = (n + k - 1) // k
        print(ans)

if __name__ == "__main__":
    main()
```该解决方案读取所有测试用例，计算最小的测试用例：$(n + k - 1) // k$，这是在 Python 中计算整数除法上限并打印结果的标准方法。 上限至关重要，因为简单地使用整数除法会低估 1 的数量$n$不能被整除$k$。 

## 工作示例

 考虑输入$n = 3, k = 2$。 计算$\lceil 3/2 \rceil = 2$，我们输出 2。将两个 1 放置在任意位置，并且每个大小为 2 的块至少放置一个，即可满足前缀和后缀约束。 为了$n = 5, k = 2$,$\lceil 5/2 \rceil = 3$。 均匀分布三个可以确保每个前缀和后缀都有足够的。 

| n | k | 上限(n/k) | 输出|
 | ---| ---| ---| ---|
 | 3 | 2 | 2 | 2 |
 | 5 | 2 | 3 | 3 |

 这表明计算$\lceil n/k \rceil$直接产生最小数量，同时满足两个约束。

 ## 边缘情况

 对于$k = 1$，每个元素必须是一个。 输入$7 1$产生输出 7。$k = n$，任何地方一个就足够了。 输入$8 8$产生输出 1. 公式$(n + k - 1) // k$正确处理这两个极端。 什么时候$n$不能被整除$k$， 例如$n = 9, k = 5$，上限确保最后一个部分块被计数，产生 2 个，这满足前缀和后缀约束。
