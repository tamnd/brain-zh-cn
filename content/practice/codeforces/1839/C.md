 ## 解决方案
 ## 问题理解

 我们被要求使用一系列操作逐步构造一个二进制序列。 我们从一个空序列开始`b`并且，在每个`n`操作中，我们在某处插入一个零`b`并反转该位置之前的所有元素。 形式上，如果我们选择位置`p`，第一个`p`的元素`b`被翻转（0 变成 1，1 变成 0），然后在它们后面插入一个零。 毕竟`n`操作，我们想要`b`精确匹配给定的目标序列`a`。 

输入给出多个测试用例，每个测试用例都有一个序列`a`长度可达`10^5`，并且所有序列长度的总和限制为`10^5`。 这意味着我们的解决方案必须是线性的`n`对于每个测试用例，因为任何二次或简单的操作模拟都会执行`n^2`工作并超过 2 秒的时间限制。 

当第一个元素`a`是`1`。 由于第一个操作总是插入一个零并且在其之前不反转任何内容，因此`b`第一次操作后始终为零。 这使得任何以`1`不可能建造。 当存在交替模式时会出现另一种微妙的情况，例如`[0,1,0]`。 粗心的实现可能会尝试按顺序插入零而不考虑反转，并达到不再可调的序列。 

## 方法

 蛮力方法模拟`b`直接地。 对于每个操作，我们都会尝试每个可能的插入点`p`从`0`到`i-1`并反转第一个`p`元素。 这是正确的，但复杂性是`O(n^2)`每个测试用例因为每个反转都会触及`p`元素，并与`n`操作，这对于`n = 10^5`。 

关键的观察结果是反转起到了切换的作用。 而不是跟踪整个数组`b`，我们只需要知道当前的奇偶校验（翻转与否），并从末尾开始模拟效果`a`向后。 我们注意到最后一个操作在某个位置插入了一个零； 这个零对应于最右边的零`b`手术前。 通过向后迭代`a`并选择`p`根据当前翻转状态，我们可以确定每个操作，而无需模拟整个序列。 具体来说，我们维护一个标志`flip`和操作列表。 如果当前位与翻转状态下的预期零匹配，我们可以在末尾插入（`p = i-1`）。 否则，我们可能需要在插入之前翻转第一个元素。 这将复杂性降低到`O(n)`每个测试用例。 

暴力破解之所以有效，是因为它直接遵循操作定义，但对于大型程序来说太慢了`n`。 关于向后工作和跟踪翻转的见解将`O(n^2)`模拟成线性`O(n)`利用反演的累积性质进行构建。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 翻转跟踪（最佳）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从最后一个元素开始`a`并向后移动。 初始化翻转标志为`0`（尚未应用反转）和一个空列表`operations`。 
2. 对于每个索引`i`从`n-1`下降到`0`，查看当前翻转状态下的位。 如果设置了翻转标志，请考虑`1`作为`0`和`0`作为`1`。 
3. 如果当前位等于`0`在翻转下方，附加`i`作为位置`p`进行操作。 这会将零正确地放置在该位置，第一个`i`根据需要反转元素。 
4. 如果当前位等于`1`在翻转下，我们必须翻转第一个元素`b`首先（对应于`p = 0`），然后插入`i`。 附加`0`其次是`i`到操作列表，然后切换翻转标志。 
5. 反转最后的操作列表，因为我们向后构建了它。 
6. 如果第一个元素`a`是`1`，因为不可能而返回“NO”； 否则，返回“YES”和操作列表。 

为什么有效：在每一步中，我们都会在累积翻转下正确对齐最终的零。 通过向后迭代，我们总是知道必须实现的未来状态，并且翻转标志跟踪所有先前的反转。 这保证了在所有操作之后每个插入的零最终位于正确的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if a[0] == 1:
            print("NO")
            continue
        ops = []
        flip = 0
        for i in reversed(range(n)):
            cur = a[i] ^ flip
            if cur == 0:
                ops.append(i)
            else:
                ops.append(0)
                ops.append(i)
                flip ^= 1
        print("YES")
        print(" ".join(map(str, ops[::-1])))

if __name__ == "__main__":
    solve()
```该代码有效地读取多个测试用例。 对于每个序列，它首先检查从以下开始的简单不可能性情况`1`。 然后它从末尾向后构建操作列表，使用`flip`变量来模拟反转而不修改数组。 以相反顺序追加操作并在末尾反转可确保操作列表与正向顺序相对应。
