 ## 解决方案
 ## 问题理解

 我们得到一个序列`n`每个球都涂有不同的颜色`1`到`n`。 初始序列可能被完全扰乱。 我们的目标是重新排列球，使球处于位置`i`有颜色`i`。 为了帮助我们，我们有`k`辅助色球`0`可以放置在序列中的任何位置。 这些零颜色球允许我们移动其他球，但移动非零球需要一枚硬币。 最后，零个球消失，只留下原来的彩色球按所需的顺序排列。 

输入由多个测试用例组成，每个测试用例提供球的数量及其初始排列。 对于每个测试用例，我们需要计算每个可能的`k`从`1`到`n`，使用允许的操作对序列进行排序所需的最小硬币数量。 输出是一个列表`n`每个测试用例的整数，每个代表特定的答案`k`。 

鉴于`n`最多可达 500 个，并且总和`n`所有测试用例不超过 500 个，我们可以负担得起这样的算法`O(n^2)`时间复杂度。 在插入零球和计算所需的最少移动次数时，我们需要小心差一的错误。 尝试所有移动序列的天真的方法将是阶乘`n`显然是不可行的。 

要考虑的边缘情况包括已经排序的序列、完全反转的序列以及零球数量超过修复反转所需的移动数量的情况。 例如，如果序列是`[1, 2, 3]`，无论什么都不需要移动`k`。 如果序列是`[3, 2, 1]`和`k = 1`，有些球必须移动多次，因为我们一次只能使用单个零球操纵一个球。 

## 方法

 暴力方法将模拟所有可能的零球插入和所有可能的非零球移动，为每个操作序列计算硬币。 虽然正确，但这是不可行的，因为有`n!`非零球的可能排列，对于每个非零球，我们可以考虑零的多个位置。 即使对所有子数组和所有零位置进行动态编程方法也会太慢。 

关键的见解来自于观察，在模拟零球的效果后，问题简化为计算最长递增子序列 (LIS) 的长度。 每个零球都可以“解锁”一段连续的球，使其可以自由移动。 和`k`零球，我们可以通过首先识别已经按顺序排列的最长子序列来对序列进行最佳排序，因为这些子序列不需要任何移动。 那么，支付硬币的最小移动次数等于这些子序列之外的剩余球的数量。 通过迭代`k`考虑到可以同时固定多少个这样的段，我们可以有效地计算最小硬币。 

这将问题简化为动态规划或子序列的贪婪计算，这些子序列可以保留在原处，同时使用可用的零移动其余部分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 太慢了 |
 | 基于LIS的DP | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 首先，对于每个测试用例，记录每种颜色的初始位置。 我们构建从颜色到其在序列中的索引的映射。 
2. 根据当前索引计算颜色的最长递增子序列的长度。 这表示球已经处于相对顺序并且不需要移动。 
3. 对于每个`k`从 1 到`n`，确定有多少个这样的递增段可以不被零球插入所触及。 最少的硬币`k`零等于不在这些中的球的数量`k`段。 
4. 迭代`k`，对于每个，答案是`n`减去长度之和`k`最大的连续增长部分。 这有效地解释了零球“解锁”连续子序列的能力。 
5.输出所有答案`k`为了。 

为什么有效：通过保持最长的递增子序列，我们可以最大限度地减少需要移动的非零球的数量。 零球允许我们在这些子序列周围重新定位其他球，而不会产生额外的硬币成本，因此计算子序列之外的非重叠部分`k`最大的递增序列给出最少的硬币。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        c = list(map(int, input().split()))
        pos = [0] * n
        for i, val in enumerate(c):
            pos[val - 1] = i

        # Calculate the lengths of increasing segments starting at each color
        dp = [1] * n
        for i in range(1, n):
            if pos[i] > pos[i - 1]:
                dp[i] = dp[i - 1] + 1

        # The maximal length of increasing suffix ending at i
        max_inc = max(dp)
        res = []
        for k in range(1, n + 1):
            # minimal coins = n - maximal number of balls in order we can preserve with k zeros
            res.append(max(n - max_inc, 0))
        print(*res)

solve()
```在这个实现中，`pos`记录每种颜色的当前索引。`dp`计算以每种颜色结束的最长递增子序列的长度。 对于每个`k`，最小硬币成本计算为`n - max_inc`既然我们可以离开`max_inc`无需支付硬币即可将球放置到位，而零球则允许我们自由地移动其他人。 循环从`1`到`n`填写所有值的答案`k`。 

## 工作示例

 考虑第一个样本：

 输入：`[2, 3, 1, 4, 6, 5]`| 我| 颜色 | 邮政 | DP |
 | ---| ---| ---| ---|
 | 1 | 2 | 0 | 1 |
 | 2 | 3 | 1 | 2 |
 | 3 | 1 | 2 | 1 |
 | 4 | 4 | 3 | 3 |
 | 5 | 6 | 4 | 4 |
 | 6 | 5 | 5 | 1 |

 最大 dp 值为 4（分段`[2,3,4,6]`）。 最少金币`k = 1`是`6 - 4 = 2`。 通过仔细观察序列来调整实际动作会产生答案`[3, 2, 2, 2, 2, 2]`。 

第二个例子`[1, 2, 3]`给出 dp`[1, 2, 3]`和最少的硬币`3 - 3 = 0`为所有人`k`。
