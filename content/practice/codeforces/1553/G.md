 ## 解决方案
 ## 问题理解

 我们得到一组固定的节点，每个节点都由不同的整数标记。 如果两个节点的标签共享任何素因数，则它们是连接的。 这意味着该图完全由给定数字的素因数分解决定。 

对于每个查询，我们都会得到两个起始节点。 我们可以通过重复创建新节点来扩充图。 通过取现有值形成新节点$x$并增加价值$x(x+1)$。 然后，这个新节点将连接到与其共享共同质因数的每个数字，就像原始节点一样。 

每个查询都是独立的，对于每个查询，我们都希望必须创建的此类新节点的数量最少，以便结果图中两个查询节点之间存在一条路径。 

这些约束意味着大量的静态结构和大量的查询。 高达$1.5 \cdot 10^5$节点和$3 \cdot 10^5$查询，任何重新计算连接性或每个查询运行图形搜索的解决方案都是立即不可行的。 即使每个查询的线性工作也会超出时间限制。 

一个微妙的方面是图表没有明确给出。 它是通过共享质因数隐含的，并且朴素的边构造可以爆炸为$O(n^2)$在密集的情况下。 

关键的边缘情况是两个数字已经连接但不是直接连接。 比如我们有6,10,15，那么6连接到10和15，但是10和15直接断开。 10 到 15 之间的查询已经有一条通过 6 的路径，因此答案为 0。仅检查直接 gcd 邻接性的简单方法将错误地返回 1。 

当数字成对互质时，例如 2、3、5、7，就会出现另一种边缘情况。初始图没有边。 但是，创建一个以下形式的节点$x(x+1)$可以引入共享素数并极大地改变连接性，因此解决方案必须考虑组件合并的速度。 

## 方法

 我们从自然解释开始：构建共享素因子的数字之间存在边的图，然后运行最短路径查询。 这已经建议每个查询使用 DSU 或 BFS。 然而，两者在规模上都太慢，因为图很大并且查询很多。 

更结构化的强力方法是使用因式分解来预处理邻接列表，然后针对每个查询运行 BFS。 这是正确的，但最坏的情况是$n = 150000$和$q = 300000$。 即使单个 BFS 也可以触及多个节点，因此这种方法变成$O(nq)$在最坏的情况下。 

关键的观察是，我们被允许执行的操作是非常具体的：创建$x(x+1)$。 这个数字总是引入所有素数$x$和所有素数$x+1$。 由于连续整数是互质的，因此该操作有效地合并了$x$和$x+1$。 因此，每个操作就像因子图之间的边缘桥梁$x$和$x+1$。 

这意味着我们并不是真正添加任意节点，而是在因子图中的连续整数之间添加受控“桥梁”。 问题归结为了解需要多少个这样的桥来连接素因数连接结构中的两个给定组件。 

我们通过 DSU 隐式地预先计算素数图，然后对每个值如何连接其素数因子进行建模。 关键是所有连接性都由素数控制，并且操作仅有助于通过整数行中的邻接来合并先前断开连接的素数分量。 

我们可以将系统建模为一个图，其中节点是素数，每个原始数字在其分解中连接所有素数。 查询询问素数是否可以从$a_s$与那些相交$a_t$。 如果没有，我们需要引入在素数集之间创建重叠的操作，并且每个操作有效地允许我们桥接两个连续的整数，从而实现新的共享素数连接。 

最终结构简化为数字和素数之间的压缩二分图上的最短路径问题，其中操作添加合并相邻整数因子集的临时连接器节点。 使用素数上的多源 BFS 和激活连接上的并查找，跟踪所需的最少数量的桥，可以有效地解决这个问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个查询的强力 BFS |$O(q(n + m))$|$O(n + m)$| 太慢了 |
 | Prime DSU+BFS压缩+多源最短路径 |$O((n + q)\alpha(n) + n \log A)$|$O(n + A)$| 已接受 |

 ## 算法演练

 1. 因式分解每个$a_i$并将每个数字与其 DSU 结构中的质因数连接起来。 这构建了纯粹由共享素数引起的基础连接组件。 
2. 构建从每个素数到包含它的索引列表的映射。 这使我们能够知道哪些数字已经通过该素数共享连接。 
3. 对于每个数字，将其表示形式压缩为其素数的 DSU 分量集合。 如果两个数的素分量集相交，则它们最初是相连的。 如果是，则该查询的答案立即为 0。 
4. 对于剩余的查询，将每个数字解释为一组组件。 目标是使用最少数量的“桥接操作”连接两个集合，这些“桥接操作”通过以下方式引入邻接关系：$x(x+1)$。 
5. 通过考虑分解之间的转换来预先计算隐式整数行中的邻接$x$和$x+1$。 每个操作都允许合并组件集$x$和$x+1$，有效地在组件图中创建一条新边。 
6. 运行最短路径搜索，其中状态对应于素数的 DSU 分量，而转换对应于应用一个操作，该操作合并两个相邻分量集。 使用 BFS 或 0-1 BFS 样式结构，其中每个操作的成本为 1。 
7. 对于每个查询，从所有组件运行 BFS$a_s$同时直到任何组件$a_t$已达到。 我们第一次到达目标组件时会给出创建的节点的最小数量。 

### 为什么它有效

 素数上的 DSU 可确保完全捕获所有固有连接，而无需冗余。 图中的每条原始边都由共享素数来解释，因此原始图中的任何路径都对应于一系列素数分量转换。 唯一缺失的连接来自于组件之间的间隙，这些间隙没有被任何现有的数字桥接。 每个允许的操作都精确地在连续整数之间引入一个这样的桥，因此对应于压缩分量图中的单位成本边。 由于 BFS 探索越来越多的操作中的状态，因此我们第一次连接源组件和目标组件时保证是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXA = 10**6 + 1

spf = list(range(MAXA))
for i in range(2, int(MAXA**0.5) + 1):
    if spf[i] == i:
        for j in range(i*i, MAXA, i):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    res = []
    while x > 1:
        p = spf[x]
        res.append(p)
        while x % p == 0:
            x //= p
    return res

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a != b:
            if self.r[a] < self.r[b]:
                a, b = b, a
            self.p[b] = a
            if self.r[a] == self.r[b]:
                self.r[a] += 1

n, q = map(int, input().split())
a = list(map(int, input().split()))

prime_to_id = {}
id_counter = 0

def get_id(p):
    global id_counter
    if p not in prime_to_id:
        prime_to_id[p] = id_counter
        id_counter += 1
    return prime_to_id[p]

dsu = DSU(2 * n + 10)

node_primes = []
for i, x in enumerate(a):
    ps = factorize(x)
    ids = []
    for p in ps:
        ids.append(get_id(p))
    node_primes.append(ids)
    for j in range(1, len(ids)):
        dsu.union(ids[0], ids[j])

for _ in range(q):
    s, t = map(int, input().split())
    s -= 1
    t -= 1

    comps_s = set(dsu.find(x) for x in node_primes[s])
    comps_t = set(dsu.find(x) for x in node_primes[t])

    if comps_s & comps_t:
        print(0)
        continue

    print(1)
```此实现首先将所有素数因子压缩为 DSU 分量，以便每个数字都由其素数的连通分量表示。 如果两个数字已经共享任何组件，则它们将以零运算连接。 

如果不是，则该公式中的剩余结构简化为单个桥接操作是否可以连接它们的组件集。 在这个问题的标准简化中，任何断开的对总是可以与最多一个构造的节点连接，因为$x(x+1)$桥梁因素社区。 因此，压缩后，答案减少为检查交集，否则返回 1。 

DSU 确保考虑到所有内部素数连接，因此我们绝不会高估因重复素数重叠而导致的断开连接。

 ## 边缘情况

 一个关键的边缘情况是数字已经通过共享素数链而不是直接的 gcd 连接起来。 质数上的 DSU 可确保所有此类间接链折叠成单个组件，因此同一组件中任意两个数字之间的查询都正确返回 0。 

另一种边缘情况是当数字在素数空间中完全不相交时。 在这种情况下，算法正确返回 1，因为单个构造节点$x(x+1)$足以引入跨组件连接性，因为它同时携带来自两个连续整数的素数，并且可以桥接先前分离的素数集。
