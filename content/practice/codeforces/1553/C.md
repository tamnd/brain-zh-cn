 ## 解决方案
 ## 问题理解

 我们正在模拟两支足球队之间的点球大战，每队交替踢球，最多各罚五球，总共踢十球。 每次踢球要么成功（进球），要么失败，或者未知。 输入给出一个由十个字符组成的字符串，代表这些结果：“1”表示有保证的进球，“0”表示未进球，“？” 为了一个不确定的结果。 

如果一支球队的得分使得另一支球队在剩余的踢球时间内无法追上，那么裁判会提前结束点球大战。 我们的任务是确定**点球大战结束前所需的最少踢球次数**，同时考虑领先球队最乐观的结果和落后球队最坏的情况。 

限制很严格但可以管理。 每个字符串的长度固定为10，最多可以有1000个测试用例。 因为每个测试用例的总工作量可能是“？”数量的指数级。 如果我们尝试完全暴力，我们必须找到一种更智能的线性时间模拟。 边缘情况包括充满“？”的字符串 或允许比赛尽早结束的字符串，例如，`1111100000`可能会在第十次踢球之前结束。 

如果忽略交替踢球或假设提前终止只需要计算进球数而不考虑剩余的可能进球数，那么天真的方法可能会计算错误。 

## 方法

 蛮力方法考虑“？”的每种组合 为“1”或“0”。 十次踢，最多有$2^{10} = 1024$可能性，这对于单个字符串是可行的，但需要最多$10^3 \cdot 1024$跨所有测试用例的操作。 这可以运行，但我们可以做得更好并避免不必要的组合。 

关键的见解是我们不需要明确地需要每个结果。 我们可以**每个测试用例模拟两次枪战**。 首先，假设每个“？” 轮到第一队就是一个进球，每个“？” 第二队的回合是未命中； 这最大限度地减少了保证一线队早日获胜所需的踢球次数。 其次，对第二队做相反的事情。 在两次模拟之后，较少的踢球次数给出了真正的最小可能的提前终止。 

这一观察结果将问题从字符串长度的指数变为线性，$O(10)$每个测试用例，或者$O(10 \cdot t) = O(10^4)$总计，完全在时限之内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^10 * t) | O(2^10 * t) | O(1) | O(1) | 已接受但没有必要 |
 | 最佳模拟| O(10 * t) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化两个分数：`score1`对于第一支球队来说，`score2`对于第二队。 还要跟踪两支球队的剩余踢球次数。 
2.模拟“乐观一线队”场景的点球大战。 对于每一次踢球：

 1. 如果轮到第一队，如果是“1”或“？”，则算入球； 如果为“0”则计数 0。 
2、如果轮到第二队，只有为“1”才算进球； 对待 '？' 作为一个想念。 
3. 每次踢球后，检查一队的得分是否超过另一队的**最大可能剩余得分**。 如果是，则记录踢动指数并终止。 
3. 通过交换“？”的处理来重复模拟“乐观的第二队”场景 对于每个团队。 
4. 返回两次模拟记录的最小踢腿次数。 

为什么有效：裁判根据剩余的潜在最高分数停止点球大战。 模拟极端场景可确保我们找到保证终止的最早点，而与“？”的实际结果无关。 这保证了正确性，而无需枚举每个组合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_kicks(s: str) -> int:
    def simulate(s, first_opt=True):
        score1 = score2 = 0
        rem1 = rem2 = 5
        for i in range(10):
            if i % 2 == 0:  # first team
                if s[i] == '1' or (s[i] == '?' and first_opt):
                    score1 += 1
                rem1 -= 1
            else:  # second team
                if s[i] == '1' or (s[i] == '?' and not first_opt):
                    score2 += 1
                rem2 -= 1
            if score1 > score2 + rem2:
                return i + 1
            if score2 > score1 + rem1:
                return i + 1
        return 10

    return min(simulate(s, True), simulate(s, False))

t = int(input())
for _ in range(t):
    s = input().strip()
    print(min_kicks(s))
```功能`simulate`对单个极端场景进行建模。`first_opt`决定了当遇到“？”时我们倾向于哪支球队。 每次踢球后都会立即应用裁判逻辑，检查落后的球队是否仍然可以追上。 为了确保正确性，我们返回两个模拟之间的最小值。

 ## 边缘情况

 对于字符串`??????????`，模拟考虑了两种极端情况。 如果第一队总是得分“？” 而第二队总是失手，第一队早在踢6时就可以获胜。如果逆转，第二队也可以在6时获胜。算法返回6，这是正确的。 '?' 的交替处理 确保提前终止能够正确评估所有可能的结果，而无需进行全面枚举。
