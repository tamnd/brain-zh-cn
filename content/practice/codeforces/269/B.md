 ## 解决方案
 ## 问题理解

 我们得到了一系列沿着一条线排列的植物，每株植物都属于_m_个物种中的一个。 温室狭长，因此每种植物沿着这条线都有独特的位置，并且所有位置都严格递增。 目标是将这条线分成 _m_ 个连续部分，每个部分恰好有一个物种，从物种 1 到物种 _m_ 排序。 不在正确位置的植物必须重新种植，我们希望尽量减少重新种植的总数。 

输入为我们提供了 _n_ 种植物，每种植物都有一个物种标签和一个位置。 输出是一个整数：满足物种排序约束所需的最小重新种植数量。 

由于 _n_ 和 _m_ 的约​​束都高达 5000，检查每个可能的分段或排列的简单方法会太慢。 例如，迭代每个物种的所有植物子集可能会导致组合爆炸，使得 O(n^2·m) 解决方案几乎不可行，更糟糕的是不切实际。 

一个微妙的边缘情况是物种标签已经混合但只需要进行几次交换。 例如，输入：```
3 2
2 1
1 2
1 3
```我们只需要将第一株植物重新种植到其他植物的右侧即可。 天真的“不按顺序移动所有内容”的方法会计算过多，给出 2 而不是正确答案 1。 

当一个物种沿线有多个簇时，就会出现另一种边缘情况。 最佳解决方案可能会保留一些植物不变，同时重新种植维持从左到右顺序所需的最少数量。 

## 方法

 暴力方法尝试将 _m-1_ 边界放置在所有可能的位置。 对于每种配置，我们都会计算错误部分中的植物数量。 虽然原则上是正确的，但此方法检查 O(n^{m-1}) 可能的边界放置，并且对于 n、m 最多 5000 的情况不可行。 

关键的观察是我们只关心沿线物种的顺序，而不是确切的位置。 如果我们将物种序列编码为数组，那么问题就简化为寻找物种标签不递减的最长子序列。 任何不属于此序列的植物都必须重新种植。 这类似于经典的最长非递减子序列问题。 

一旦我们知道了这个子序列的长度，最小重植次数就是 n 减去子序列长度。 这样做的原因是我们可以移动剩余的植物以适应它们的正确部分，因为位置是实数并且没有两个占据相同的点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^{m-1}) | O(n^{m-1}) | O(n) | 太慢了 |
 | 最长非递减子序列| O(n·m) | O(米) | 已接受 |

 ## 算法演练

 1. 初始化一个动态编程数组`dp`大小为 _m+1_，其中`dp[i]`表示以物种 _i_ 结尾的最长子序列的长度。 
2. 按从左到右的顺序迭代植物。 对于每种植物的种类`s`， 更新`dp[s]`成为最大的`dp[s]`和`max(dp[1..s]) + 1`。 这捕获了可能以物种结束的最佳子序列`s`同时保持非递减的秩序。 
3. 在处理工厂时跟踪总体最大子序列长度。 
4. 迭代完所有植物后，最少重新种植次数为`n - max_length`， 在哪里`max_length`是最长非递减物种子序列的长度。 

为什么它有效：动态规划不变量保证`dp[s]`始终表示以物种结尾的最长子序列`s`到目前为止所看到的。 由于子序列遵循非递减物种顺序，因此必须移动该子序列之外的任何植物。 不存在更好的解决方案，因为移动更少的植物会违反从左到右的物种顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
species = [0] * n
for i in range(n):
    s, x = input().split()
    species[i] = int(s)

dp = [0] * (m + 2)  # dp[i] = length of longest non-decreasing subsequence ending with species i

for s in species:
    best = 0
    for i in range(1, s + 1):
        if dp[i] > best:
            best = dp[i]
    dp[s] = best + 1

max_length = max(dp)
print(n - max_length)
```此代码首先将所有植物读取到一个数组中。 这`dp`数组跟踪以每个物种结尾的最长非递减子序列的长度。 对于每个植物，我们找到最大值`dp`小于或等于其物种的物种间的值加1，更新`dp[s]`。 最后，重新种植的植物数量是总数减去最长子序列的长度。 

一个微妙的实现选择是使用`dp`尺寸的`m+2`以避免边界问题并迭代至`s`而不是`s-1`，因为当前物种本身可能会扩展先前的子序列。
