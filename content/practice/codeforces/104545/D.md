 ## 解决方案
 ## 问题理解

 我们给定一个长度序列$n$，其中每个位置都是集合中的固定数字$\{0,1,2\}$或缺失值标记为$-1$。 任务是计算通过替换每一个可以形成多少个完整序列$-1$带有一个数字$\{0,1,2\}$，在全局约束下：每三个连续元素之和必须恰好为 3。 

约束很强，因为它耦合了每个三元组$(a_i, a_{i+1}, a_{i+2})$。 一旦两个连续值被固定，第三个值就被强制。 这立即表明该序列不是逐个位置自由选择的； 相反，它的行为就像二阶递归，其中任何有效序列完全由其前两个值决定。 

输入大小达到$n = 10^6$，这消除了任何独立尝试所有分配甚至所有本地配置的方法。 任何解都必须是线性的$n$，因为即使$O(n \log n)$是可以接受的，但是$O(n^2)$是不可能的。 

当早期值缺失时，就会出现一个微妙的问题。 如果第一个和第二个元素都是$-1$，可能序列的数量不仅仅是局部分支问题，因为每个选择都会确定性地传播。 另一种失败情况是部分赋值稍后会产生矛盾，例如固定值与递归所暗示的内容不一致。 

关键的挑战不是构建序列，而是计算有多少初始种子与所有约束和固定位置一致。 

## 方法

 蛮力的想法很简单：对待每一个$-1$作为分支点并尝试所有分配$\{0,1,2\}$，然后检查全序列是否满足三重和条件。 这是正确的，因为它直接强制执行定义，但丢失条目的数量呈指数级增长。 在最坏的情况下，所有位置都等于$-1$，这变成了$3^n$，即使对于非常小的情况也是完全不可行的$n$。 

结构洞察力来自于重写约束。 从$$a_i + a_{i+1} + a_{i+2} = 3,$$我们得到$$a_{i+2} = 3 - a_i - a_{i+1}.$$这意味着一次$a_1$和$a_2$是固定的，整个序列是唯一确定的。 只有九个可能的起始对，因此我们只模拟九个确定性传播，而不是探索所有完整序列。 

唯一剩下的问题是与给定的部分填充数组的一致性。 对于每个候选起始对，我们生成完整序列并验证每个固定位置是否匹配。 如果是，则该候选人为答案贡献 1。 

这将问题从对所有完成的指数搜索减少到恒定数量的线性模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解所有馅料 |$O(3^n)$|$O(n)$| 太慢了 |
 | 尝试所有初始对并模拟 |$O(9n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 迭代所有可能的值$(a_1, a_2)$，其中每个可以是 0、1 或 2。总共有 9 个候选，每个候选代表一个可能的递归种子。 
2.对于每个候选对，构造一个长度的序列$n$。 相应地设置前两个值并使用规则向前传播$a_i = 3 - a_{i-1} - a_{i-2}$。 此步骤是必要的，因为三重和条件唯一确定每个下一个元素。 
3. 生成序列时，将每个计算值与输入数组进行比较。 如果输入有固定值（不是$-1$)，它必须完全匹配。 如果发生不匹配，请立即丢弃该候选，因为没有扩展可以修复违反的重复约束。 
4. 如果生成的完整序列没有矛盾，则将该候选视为有效。 
5. 对所有有效的起始对求和并输出总数。 

### 为什么它有效

 递归将问题转化为二阶线性约束系统。 任何有效序列都按索引顺序向前满足相同的确定性规则，因此每个解都由其前两个值唯一确定。 因此，枚举所有有效的序列相当于枚举所有有效的初始条件。 一致性检查确保仅对与部分观察值兼容的序列进行计数，因此不包括无效的重建。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    def valid(a1, a2):
        if a[0] != -1 and a[0] != a1:
            return False
        if n > 1 and a[1] != -1 and a[1] != a2:
            return False

        x0, x1 = a1, a2
        for i in range(2, n):
            x2 = 3 - x0 - x1
            if x2 < 0 or x2 > 2:
                return False
            if a[i] != -1 and a[i] != x2:
                return False
            x0, x1 = x1, x2

        return True

    ans = 0
    for a1 in range(3):
        for a2 in range(3):
            ans += valid(a1, a2)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案围绕一个辅助函数构建，该函数测试固定的起始对是否可以生成与输入约束一致的序列。 迭代应用递归，仅维护最后两个值，这避免了存储整个序列。 

一个微妙的细节是当计算值超出范围时早期拒绝$\{0,1,2\}$。 这是必要的，因为递归代数允许负值或大于 2 的值，但根据定义，此类序列是无效的。

 ## 边缘情况

 关键的边缘情况是前两个值未指定。 对于输入如：```
n = 3
-1 -1 -1
```该算法测试所有九个起始对。 每一对恰好生成一个有效序列，并且没有一个序列被约束过滤。 这导致答案为 9，这与应用约束之前每个初始选择都是独立的这一事实相符。 

另一种情况是早期矛盾。 为了：```
n = 3
0 0 0
```前两个值强制第三个值为 3，这违反了允许的范围。 每个起始对在传播过程中都会被拒绝，并且算法无需完整枚举即可正确返回 0。 

第三种微妙的情况是固定值出现较晚并强制拒绝。 如果序列在许多步骤中都是一致的，但单个位置与传播值不一致，则立即丢弃候选值。 这确保了无效序列永远不会部分贡献，从而保持计数的正确性。
