 ## 解决方案
 ## 问题理解

 我们得到一个代表一桌零食的小二进制网格，其中每个单元格要么是 1（奶酪球），要么是 0（coxinha）。 任务是精确选择一个轴对齐的矩形子网格并收集其中的所有零食，但限制为该矩形不得包含任何 coxinhas。 换句话说，矩形内每个选定的单元格都必须是 1。 

目标是最大化收集到的奶酪球的数量，这相当于最大化完全由 1 组成的子矩形的面积。 

约束 n × m ≤ 400 是关键的结构线索。 即使在最坏的情况下，这也是一个非常小的网格，它允许每个单元的解决方案是二次的或稍差的，而不会有超过时间限制的风险。 然而，它也暗示预期的解决方案并不是对所有矩形进行暴力破解，因为这仍然需要重复检查许多子矩阵，从而导致不必要的开销和尴尬的实现。 

枚举每个可能的矩形并验证是否是所有矩形的简单方法可能会在性能或实现复杂性方面悄无声息地失败。 例如，即使在 20 × 20 的网格上，也大约有 10^8 个矩形，检查每个矩形都需要额外的工作。 

对于幼稚的实现来说，一个更微妙的失败案例来自于矩形的错误验证。 假设我们选择一个矩形并仅检查其角或部分扫描：

 输入：```
3 3
1 1 1
1 0 1
1 1 1
```粗心的检查者可能仅通过检查边界来验证跨越整个网格的矩形，并得出结论它是有效的，从而错误地返回 9。正确的答案是 4，来自任何避开中心零的 2×2 子方格。 

这表明正确性取决于矩形内部的全局结构，而不仅仅是边界值。 

## 方法

 暴力破解的想法很简单：枚举由顶行、底行、左列和右列定义的所有可能的子矩形，并为每个子矩形扫描每个单元格以检查它是否包含零。 如果不是，请计算其面积并更新答案。 

这是有效的，因为它直接强制执行问题的定义。 然而，其成本增长太快。 有 O(n^2 m^2) 个矩形，在最坏的情况下每次验证成本为 O(nm)，导致理论上的 O(n^3 m^3) 界限。 即使 n × m ≤ 400，这在实践中也太慢了。 

关键的观察是，我们实际上不需要从头开始重新计算每个矩形的有效性。 相反，我们可以跨行重用结构。 如果我们修复底行，我们可以将网格压缩成直方图，其中每列存储有多少个连续的 1 在该行结束。 任何以该行结尾的全 1 矩形都将成为该直方图中的连续段。 然后，问题就变成了直方图中经典的最大矩形，通过单调堆栈有效地解决了。 

这将二维矩形搜索转换为一系列一维问题，每个问题都可以在每行线性时间内解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((nm)^2·nm) | O((nm)^2·nm) | O(1) | O(1) | 太慢了 |
 | 直方图 DP + 堆栈 | O(纳米) | O(米) | 已接受 |

 ## 算法演练

 我们逐行处理网格，维护一个表示连续网格的直方图高度的数组。 

1.初始化一个数组`height`大小为 m，带零。 对于每一列，该数组表示我们看到有多少个连续的列在当前行结束。 
2. 对于每一行，通过扫描列来更新直方图。 如果当前单元格为1，则递增`height[j]`1，否则将其重置为 0。此步骤将 2D 约束转换为垂直运行的 1D 表示。 
3. 对于更新的`height`数组，计算直方图中最大的矩形。 这是使用单调递增的索引堆栈来完成的。 当我们遇到小于栈顶的高度时，我们会重复弹出并计算区域，使用弹出的高度作为限制高度，当前索引作为右边界。 
4. 记录所有行中看到的最大面积。 
5.处理完所有行后，输出最大记录面积。 

关键的推理步骤是每个有效的全一矩形都有一个唯一的底行。 通过将每一行视为潜在的底部边界，我们确保每个矩形在直方图阶段只被考虑一次。 

### 为什么它有效

 在任意行 r，`height[c]`对以 r 结尾并在 c 列中不间断向上延伸的矩形的最大可能高度进行编码。 任何具有底行 r 的全 1 矩形都对应于连续的列段，其中所有高度至少为矩形高度。 直方图公式准确地捕获了这些约束，因此直方图中最大的矩形正是以第 r 行结束的最佳矩形。 由于每个矩形都有一些底部行，因此扫描所有行涵盖了所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def largest_histogram(heights):
    stack = []
    best = 0
    heights.append(0)
    
    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            left = stack[-1] if stack else -1
            width = i - left - 1
            best = max(best, height * width)
        stack.append(i)
    
    heights.pop()
    return best

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    height = [0] * m
    answer = 0
    
    for i in range(n):
        for j in range(m):
            if grid[i][j] == 1:
                height[j] += 1
            else:
                height[j] = 0
        
        answer = max(answer, largest_histogram(height))
    
    print(answer)

if __name__ == "__main__":
    solve()
```该实现保持滚动直方图`height`垂直累积连续的。 辅助函数使用强制增加高度的堆栈来计算每行线性时间的最佳矩形。 附加到直方图的哨兵零确保所有剩余的堆栈元素在计算结束时被刷新。 

唯一微妙的实现细节是在遇到零单元格时立即将列高重置为零，因为包含该单元格的任何矩形都将变得无效。

 ## 边缘情况

 完全为零的网格测试算法是否正确重置直方图高度而不是累积陈旧值。 当每一行都为零时，高度数组保持为零，并且直方图始终返回零，从而产生正确的答案。 

单行网格将问题简化为纯直方图。 该算法正确计算了最长的连续段，因为所有高度都是 0 或 1。 

完全填满的网格测试最大累积量。 每行都会增加所有直方图值，最后一行会生成一个直方图，其中整个宽度可使用最大高度，从而按预期产生 n × m。
