 ## 解决方案
 ## 问题理解

 我们得到了代表成分品质的一组数字。 我们必须将这些数字准确地分成`k`非空组，其中每个数字恰好属于一个组。 每组代表一道菜。 

菜肴的评分定义方式有点不寻常。 如果一道菜包含数值，则其得分是该菜中所有数值的总和再加上该菜中的最大值。 因此，如果一个组有元素，则最大的元素贡献两次，而所有其他元素贡献一次。 

目标是选择如何将数组划分为`k`分组，使所有菜肴得分的总和尽可能大。 

关键的困难在于分组决策会影响某个值是成为其组中的最大值还是仅成为常规贡献者。 由于每个组都会再次添加其最大值，因此组的结构比值的总和更重要。 

约束允许最多`2 * 10^5`元素，因此任何解决方案都必须接近线性或线性算数。 O(n^2) 甚至 O(nk) 样式的分组策略立即太慢，因为它可能需要迭代许多可能的分区或跟踪组计数和分配之间的转换。 

当所有值都相同时，会出现微妙的边缘情况。 例如，如果所有`a_i = 1`和`k = n`，每个元素都必须是单独的，答案就变成了`2n`。 天真的直觉可能表明，在这种统一的情况下，分组并不重要，但即便如此，“每组的额外最大值”仍然迫使每个单例组贡献额外的值。 

另一个重要的边缘情况是当`k = 1`。 那么所有元素都在一组中，答案很简单`sum(a) + max(a)`。 任何假设分裂总是有益的算法都会在这里失败。 

## 方法

 暴力解决方案将尝试将数组的每个可能的分区划分为`k`组。 对于每个分区，它将计算每个组的总和及其最大值，然后跨组求和。 分区的数量以组合方式增长，基本上由第二类斯特林数控制。 即使限制为连续分区也无济于事，因为该问题并不要求组是连续的。 

即使是跟踪有多少元素分配给多少组的动态编程方法也很快变得不可行，因为我们需要知道对于每个前缀和组计数，如何最佳地分配最大值。 状态空间变得太大`n`最多`2e5`。 

关键的见解是重新解释在团队中创造价值的因素。 每个元素通过所有组的总和对总数只贡献一次。 唯一的额外贡献来自于每个组最多增加一次的事实。 

因此，整个优化简化为最大化所选组最大值的总和。 因为我们正好有`k`组，我们需要选择`k`元素作为“小组领导者”，发挥各自小组的最大作用。 每个其他元素只会通过全局总和贡献一次。 

这意味着我们应该最大化`k`选择的元素作为最大值。 自然地，我们想要`k`数组中最大的元素，因为它们提供了最大可能的额外贡献。 其余`n-k`元素将只是正式成员贡献一次。 

因此，最终的答案就是所有元素的总和加上`k`最大的元素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 超指数| O(n) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(1) 到 O(n) | 已接受 |

 ## 算法演练

 1. 计算数组中所有元素的总和。 这表示基本贡献，其中每个元素都只计算一次，无论分组结构如何。 
2. 对数组进行降序排序。 这使我们能够轻松识别将作为组最大值候选的元素。 
3. 拿第一个`k`此排序顺序中的元素。 这些代表了元素的最佳可能选择，这些元素将贡献额外的时间作为组最大值。 
4. 将这些相加`k`元素到基本总和。 这说明了每组最大元素的额外贡献。 
5. 输出所得值作为可达到的最高总分。 

我们特意取最大的原因`k`元素的优点是每个组只贡献一个最大值，并且没有任何限制阻止将任何选定的元素分配为组的最大值。 由于组是任意的，因此我们始终可以将每个选定的最大值放入其自己的组中，并自由分配剩余元素。 

### 为什么它有效

 每个元素至少贡献一次，因此基线总和是固定的。 唯一的自由在于选择哪些元素成为最大值。 每个组恰好添加一个等于其最大值的额外贡献，因此我们正在有效地选择`k`元素获得与其价值相等的奖金。 独立地最大化这个奖金直接导致选择最大的`k`值，因为组之间没有耦合约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    total = sum(a)
    a.sort(reverse=True)
    
    bonus = sum(a[:k])
    print(total + bonus)

if __name__ == "__main__":
    solve()
```该解决方案首先计算所有成分的总和，这是不可避免的基本贡献。 然后，它按降序对数组进行排序，以便可以按线性顺序访问最大的元素。 

关键的一步是选择顶部`k`元素作为额外贡献的来源。 由于每个组只贡献一个最大值，因此我们可以将其视为为每个组分配一个“奖励槽”，并用最大的可用值填充这些槽可以最大化结果。 

其余元素不影响奖金项，仅通过基数做出贡献，因此排序后可以忽略。

 ## 边缘情况

 当`k = n`，每个元素必须形成自己的组。 该算法选择所有元素作为顶部`k`，因此奖金变为全额，产生`2 * sum(a)`，这与每个单例组贡献其元素两次的事实相符。 

什么时候`k = 1`，算法仅选择最大的元素作为奖励，给出`sum(a) + max(a)`。 这相当于将所有内容放在一组中，其中仅额外添加一个最大值。 

当所有值都相等时，说`[x, x, x]`和`k = 2`，算法仍然选择任意两个元素作为奖励贡献者，产生`3x + 2x = 5x`。 任何分区都会产生相同的结构，因为每个组最大值都是相同的，从而确认在平局情况下选择任意顶部元素的正确性。
