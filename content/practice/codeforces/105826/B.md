 ## 问题理解

 我们有一个正多边形`n`编号的顶点。 从第一个顶点开始，我们以固定步长重复移动`k`围绕多边形并绘制访问顶点之间的线段。 此过程到达的每个顶点都会被绘制。 任务是选择最小的有效值`k`使绘制的顶点数量尽可能少。 

输入仅包含顶点数。 输出是创建尽可能最小的访问顶点集的步长，并在所有最佳选择中选择最小的步长。 

重要的限制是`n`可以大到`10^10`，因此迭代所有可能步骤或所有顶点的解决方案是不可能的。 甚至一个`O(n)`算法可以执行多达百亿次运算，这远远超出了正常竞赛所允许的限制。 我们需要使用数论并使用除数`n`而不是多边形本身。 

一个常见的错误是假设大的一步总是画更少的点。 绘制顶点的数量仅取决于步骤如何与`n`，不在数字大小上`k`。 

例如，如果`n = 9`，选择`k = 8`看起来很大，但访问的顶点是：```
1, 9, 8, 7, 6, 5, 4, 3, 2
```所有 9 个顶点都已绘制，因此答案不是 8。正确答案是`3`，因为它访问：```
1, 4, 7
```并且只绘制 3 个顶点。 

另一个边缘情况是顶点数为素数。 为了`n = 7`，每个非零步骤都互质`7`，因此每个可能的步骤都会到达所有顶点。 最小有效步骤很简单`1`。 

## 方法

 最直接的方法就是尝试一切可能的方法`k`从`1`到`n - 1`。 对于每个步骤，我们可以模拟围绕多边形的运动，直到返回起始顶点并计算到达的不同顶点的数量。 这是正确的，因为它完全遵循绘画过程。 

问题是一次模拟可能需要长达`n`移动。 尝试所有`n - 1`可能的值给出了大约`n^2`运营。 和`n`达到`10^10`，这是完全不可行的。 

关键的观察是访问的顶点形成一个循环。 后`t`移动，当前顶点为：```
1 + t * k (mod n)
```当该序列中的两个位置的差值是以下值的倍数时，它们是相同的`n`。 本周期中唯一位置的数量恰好是：```
n / gcd(n, k)
```所以我们不需要模拟多边形，只需要最大化`gcd(n, k)`。 The painted count is smallest when this gcd is as large as possible.

 之间最大可能的gcd`n`以及适当的正向`k`是最大的真因数`n`。 如果`n`是合数，它的最小质因数是`p`，这个除数是`n / p`。 最小的`k`与此 gcd 也是`n / p`。 

如果`n`是质数，没有大于的真因数`1`，所以每一步都会绘制所有顶点。 最小可能的步骤是`1`。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(√n) | O(√n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`并判断它是否是素数或者找到它的最小素因数。 
2.如果`n`没有比它自己小的约数，它是素数。 每个可能的步骤都会访问每个顶点，因此返回`1`。 
3. 否则，让`p`是 的最小质因数`n`。 返回`n / p`，因为这是最大的真除数，并且给出了最大可能的 gcd`n`。 

为什么它起作用：运动总是创建一个周期，其长度由`gcd(n, k)`。 gcd 越大意味着循环中的顶点越少。 最大 gcd 是最大除数`n`小于`n`，产生它的最小步骤正是该除数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n % 2 == 0:
        print(n // 2)
        return

    d = 3
    while d * d <= n:
        if n % d == 0:
            print(n // d)
            return
        d += 2

    print(1)

if __name__ == "__main__":
    solve()
```该解决方案首先处理偶数，因为`2`是可能的最小质因数。 对于一个均匀的`n`，最好的步骤是`n / 2`。 

对于奇数，我们从以下位置开始搜索最小的奇数除数`3`。 我们只需要检查平方根`n`，因为如果`n`如果因子大于其平方根，则匹配因子较小。 

找到的第一个除数是最小的素因数。 返回`n / divisor`给出最大的真除数，这是所需的步骤。 如果找不到除数，`n`是素数，答案是`1`。 

不需要数组或访问集，因为整个多边形结构由 gcd 关系表示。

 ## 边缘情况

 对于`n = 9`，粗心的解决方案可能会选择最大可能的步骤和输出`8`。 相反，该算法会找到最小的因子`3`并返回`9 / 3 = 3`。 gcd 变为`3`，产生尽可能短的周期。 

为了`n = 7`，每个非零步都有gcd`1`和`7`。 绘制的顶点数始终为`7`，所以最小化步骤本身给出了答案`1`。 该算法到达除数搜索的末尾并正确处理这种素数情况。 

对于偶合数，例如`n = 12`，运动应该访问尽可能少的顶点。 最小的质因数是`2`，所以最大有用的 gcd 是`6`。 选择`k = 6`访问顶点`1`和`7`仅，这是最小的。
