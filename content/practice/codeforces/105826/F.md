 ## 解决方案
 ## 问题理解

 该问题描述了一只青蛙沿着绳子移动。 每个位置包含一个字符，并且字符属于以下三类之一：小写字母、大写字母或数字。 青蛙从第一个位置开始，想要到达最后一个位置。 一次跳跃最多可以让青蛙前进`k`位置，但青蛙只允许降落在与当前位置包含相同类别字符的位置上。 

任务是找到到达终点所需的最少跳跃次数，或者报告这是不可能的。 

输入给出字符串的长度、最大跳转长度和字符串本身。 输出是从第一个字符移动到最后一个字符所需的最小有效跳转次数。 

字符串长度可达20万。 这立即排除了重复尝试每条可能路径的解决方案，因为可能的路线数量可能呈指数级增长。 即使是检查每一对位置的方法也可以变得可行`n²`，这大约是上限 400 亿次操作，远远超出了正常时间限制所允许的范围。 

关键是青蛙只向右移动。 没有循环，因此我们可以按顺序处理仓位，并只保留对未来跳跃重要的信息。 

有几个案例很容易被忽视。 

如果第一个和最后一个字符有不同的类别，则答案是不可能的。 例如：```
5 3
aB123
```第一个字符是小写字母，最后一个字符是数字。 青蛙永远无法改变类别，所以正确答案是：```
-1
```粗心的实现可能只会检查末尾附近是否存在正确类型的某些位置，但这还不够，因为青蛙必须在整个路径中保留其类别。 

另一个棘手的情况是当正确的类别存在，但差距大于`k`。 

例子：```
6 2
aaabca
```第一个和最后一个字符都是小写字母，但小写位置是：`1, 2, 3, 6`从位置3到位置6的跳跃长度为3，太大了。 答案是：```
-1
```仅计算存在多少个有效位置的实现会错误地认为存在路径。 

最后的边缘情况是每个有用的跳跃恰好是允许的最大长度。 

例子：```
7 3
aaaaaaa
```青蛙会跳：`1 -> 4 -> 7`所以答案是：```
2
```使用严格的`< k`比较而不是`<= k`会在这里失败。 

## 方法

 解决该问题的直接方法是模拟所有可能的运动。 从每个可到达的位置，我们尝试距离内的每个下一个位置`k`，检查其字符是否属于同一类别，然后继续。 这是正确的，因为每一条可能的路径都被探索过。 

问题是工作量。 最坏的情况下，每个位置都可以尝试一下`k`下一个职位。 既然两者`n`和`k`可能接近 200,000，这大约变成`O(nk)`，太大了。 

有用的观察来自于所有跳跃都只会向前的事实。 我们不需要知道每条可能的路径。 我们只需要每个角色类别的最新可达位置的最佳答案。 

假设我们目前处于某种类别的位置。 同一类别的任何未来位置都可以从其后面最远的可到达位置到达，因为这给出了最大的剩余跳跃距离。 如果最远可达位置至少为`i - k`，则当前位置可达。 

这将问题转化为单次扫描。 从左向右移动时，我们保留三个类别中每个类别的最后可到达的位置。 每当我们遇到一个字符时，我们都会检查其类别的前一个可到达位置是否足够接近。 如果是，我们更新所需的跳跃次数并将该位置标记为可到达。 

这三个类别可以压缩为三种状态。 不需要映射或复杂的数据结构，因为字母组是固定的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(nk) | O(nk) | O(n) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将每个字符转换为三个类别标识符之一。 小写字母、大写字母和数字都有自己的状态。 这使得算法可以比较类别而不关心实际的字符。 
2. 从第一个位置开始。 它始终可以通过零跳转到达，因此将其存储为其类别的最新可到达位置。 
3. 从左到右扫描字符串。 对于每个职位，请查看同一类别中最近可到达的职位。 

如果该位置在`k`青蛙可以跳到当前字符后面的字符。 当前位置变为可到达。 
4. 当某个位置可到达时，更新到达该位置所需的跳跃次数。 通过获取前一个位置的答案并加一来找到最小跳跃计数。 

存储的可到达位置始终是其类别中最远的可能位置。 较远的可到达位置总是至少与较近的位置一样有用，因为它使青蛙有更多的距离可用于下一次跳跃。 
5. 处理完整个字符串后，检查最后一个位置是否可达。 如果没有，则打印`-1`。 

为什么它有效：

 不变的是，在处理字符串的任何前缀后，对于每个类别，我们存储青蛙可以到达的该前缀中的最远位置，以及到达那里所需的最小跳跃次数。 当我们处理新位置时，任何有效的先前跳转都必须来自同一类别。 最远可到达的位置是唯一重要的位置，因为如果它无法到达当前位置，则更早的位置也无法到达。 如果它可以到达当前位置，则使用它会给出尽可能少的跳跃次数。 这使得每个位置的不变量都成立，并保证最终答案是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    s = input().strip()

    def get_type(c):
        if 'a' <= c <= 'z':
            return 0
        if 'A' <= c <= 'Z':
            return 1
        return 2

    last = [-1, -1, -1]
    dist = [-1] * n

    dist[0] = 0
    last[get_type(s[0])] = 0

    for i in range(1, n):
        t = get_type(s[i])

        if last[t] != -1 and i - last[t] <= k:
            dist[i] = dist[last[t]] + 1
            last[t] = i

    print(dist[-1])

if __name__ == "__main__":
    solve()
```这`get_type`函数将每个字符减少到三种状态之一。 这避免了在整个算法中重复检查范围并保持主循环简单。 

这`last`数组存储每个类别的最远可达位置。 仅当位置可达时才需要更新它，因为无法到达的位置无助于将来的跳跃。 

距离数组存储到达每个位置所需的最小跳跃次数。 当我们找到有效的跳转时，当前的答案恰好比前一个可到达位置的答案多1。 

边界检查使用`<= k`因为跳跃的长度正好是`k`是允许的。 位置是从左到右处理的，因此不需要向后移动或重新访问状态。
