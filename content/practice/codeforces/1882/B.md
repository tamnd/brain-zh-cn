 ## 解决方案
 ## 问题理解

 我们有几组整数。 我们可以选择这些集合的任何子集（包括没有）并取所选集合的并集。 如果一个集合能够以这种方式形成，那么它就是_attainable_。 我们的任务是找到最大的可达到的集合，该集合**不等于**所有原始集合的并集。 输出应该是这样一个集合中的元素数量。 

每个测试用例最多给我们 50 个集合，每个集合最多包含 50 个从 1 到 50 的整数。约束很小，因此对集合元素的暴力破解技术是可行的，但暴力破解集合的所有可能子集是边界性的，因为这将是$2^n$可能性，已经结束$10^{15}$什么时候$n = 50$。 因此，我们需要一种更智能、更有建设性的方法，而不是明确地测试每个子集。 

非明显的边缘情况包括每组都是单例或只有一组的情况。 例如，如果只有一组$\{1,2,3\}$，唯一可达到的不等于完全并集的集合是空集，给出输出 0。另一个微妙之处是当集合以这样一种方式重叠时，删除任何一个集合仍然会给出完全并集； 在这种情况下，最大的非完全并集是通过取除一个集合之外的所有集合的并集来获得的。 

## 方法

 暴力方法是迭代给定集合的所有子集，计算它们的并集，并跟踪与所有集合的并集不匹配的最大并集的大小。 原则上这是可行的，因为并集运算是关联且单调的，但子集的数量呈指数增长（$2^n$），对于$n = 50$。 

解锁更有效解决方案的关键观察是，不是完全并集的最大可达到集合始终可以通过取所有集合**除一个**之外的并集来获得。 如果我们删除一个包含不属于任何其他集合的元素的集合，则生成的并集将恰好丢失这些元素，从而为我们提供最大的非完整并集。 如果所有集合都是剩余集合的并集的子集，则删除任何集合仍会给出完整的并集，然后答案是并集的大小减去一个元素，如果仅存在一个集合，则答案是零。 

这将问题简化为迭代每个集合，计算所有其他集合的并集，并获取这些并集的最大大小。 而不是$2^n$运营，我们只做$n$联盟，每个联盟最多包含 50 个元素。 将集合表示为数字 1-50 上的位掩码可以简化联合运算和大小计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * k) | O(2^n * k) | O(k) | 太慢了 |
 | 最优（不含一套） | O(n * k) | O(k) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$，组数。 
2. 读取每个集合并将其存储为 Python`set`或作为 50 位整数位掩码。 位掩码很方便，因为联合成为单个按位或运算。 
3. 计算所有的并集$n$套。 打电话给这个`full_union`。 
4. 初始化变量`best`到 0。这将跟踪可达到的集合的最大大小小于`full_union`。 
5. 每组$S_i$:

 - 计算所有集合的并集，除了$S_i$。 使用位掩码，这是`union_except_i = full_union & ~S_i`。 使用Python集，它是`union_except_i = full_union - S_i`仅适用于元素$S_i$或者`union_except_i = set().union(*[S[j] for j != i])`。 
- 计算元素的个数`union_except_i`并更新`best`如果更大。 
6.检查完所有组后，打印`best`对于测试用例。 

为什么有效：任何不等于完整并集的可达到集合必须从并集中至少省略一个元素。 删除一整组足以覆盖所有可能的遗漏，因为包含较少的组不能创建比以下更大的并集`full_union`。 因此，迭代每个集合并排除它可以保证我们找到以下可达到的最大大小`full_union`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        sets = []
        for _ in range(n):
            data = list(map(int, input().split()))
            sets.append(set(data[1:]))
        
        full_union = set()
        for s in sets:
            full_union |= s
        
        best = 0
        for i in range(n):
            union_except_i = full_union - sets[i]
            best = max(best, len(union_except_i))
        
        print(best)

solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`并将每个集合存储为 Python 集合。 我们计算所有集合的并集`|=`运算符，然后迭代，依次排除每个集合。 使用集合减法可确保我们仅删除当前集合特有的元素，这正是查找可达到的最大非完全联合的机制。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(t * n * k) | O(t * n * k) | 对于每个测试用例，我们计算`full_union`(O(n_k))，然后迭代排除每个集合 (O(n_k))。 k ≤ 50 且 n ≤ 50，因此每个测试用例的总操作数 ≤ 2500。 |
 | 空间| O(n * k) | 我们最多存储 n 组，每组大小为 k。 位掩码表示减少了空间，但对于这些约束来说不是必需的。 |

 这完全符合 2 秒的时间限制和 256 MB 的内存限制。
