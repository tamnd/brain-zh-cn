 ## 解决方案
 ## 问题理解

 我们有两种排列，一种是大小$n$和尺寸之一$m$，它们只是包含从 1 到$n$和 1 到$m$按某种顺序。 目标是使用特定操作将两种排列同时转换为其排序形式。 该操作允许我们在每个排列中选择一个索引，在该索引处分割排列，并交换枢轴元素周围的左右部分。 此操作可以根据需要应用多次，最多 10,000 次。 

输入提供排列的大小，$n$和$m$，以及初始排列本身。 输出是$-1$如果不可能同时对两种排列进行排序，或者实现排序数组的操作列表。 

主要挑战是同时对两种排列应用拆分和交换操作的约束。 对每个排列进行独立排序的简单方法可能行不通，因为每个操作都会影响两个数组。 的界限$n, m \le 2500$暗示着一个$O(n^2)$或者$O(m^2)$方法是可行的，但任何明显更糟糕的方法都会太慢。 边缘情况包括已经排序的数组、反向排序的数组或在不破坏同时操作规则的情况下无法对齐的排列。 

例如，如果$p = [2, 1]$和$q = [2, 1]$, 一项操作$i = j = 2$将交换最后一个元素的左右部分，直接生成排序数组。 忽略操作耦合的粗心方法可能会错误地尝试对它们进行独立排序，如果两个数组需要不同位置的主元，则可能会失败。 

## 方法

 暴力方法会尝试所有可能的对$(i, j)$进行操作，直到数组排序完毕。 这是可行的，因为每个排列都可以使用一系列这样的主元交换来排序。 如果我们不小心的话，最坏情况下的操作次数将是无限的，并且检查所有$i \times j$每一步的可能性都会慢得令人望而却步（$O(n m \cdot k)$为了$k$运营）。 

关键的见解来自观察枢轴操作是可逆的且高度灵活的。 任何排列都可以通过使用该元素当前位置的枢轴重复将最大剩余元素移动到其正确位置来排序。 因此，我们可以根据要放置元素的位置独立处理两个数组，但必须以一致的方式对齐所选的枢轴。 对于简单版本，重复选择需要正确放置在两个数组中的下一个元素就足够了，如果一个数组已经到达正确的位置，则可能会用简单的交换进行填充。 

这允许贪婪算法：选择每个排列的未排序前缀中的最后一个元素作为基准，执行交换，并继续直到两个数组都排序为止。 如果一个数组先于另一个数组达到正确的顺序，我们可以继续在已完成的数组中使用简单的交换而不更改其顺序，从而确保另一个数组继续进行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n*m)^k) | O((n*m)^k) | O(n+m) | 太慢了 |
 | 贪心枢轴排序 | O(n+m) 次操作 | O(n+m) | 已接受 |

 ## 算法演练

 1. 初始化一个空的操作列表。 保留指针$i$和$j$在我们想要正确放置的当前元素处$p$和$q$，从 1 开始。 
2. 同时$p$或者$q$未排序：

 1.找到等于的元素的位置$i$在$p$。 如果$i > n$，选择任何有效的主元（例如，$p_n$）。 
2.找到等于的元素的位置$j$在$q$。 如果$j > m$，选择任何有效的主元（例如，$q_m$）。 
3. 追加$(pivot\_p, pivot\_q)$到操作列表。 
4. 对两个排列应用主元交换。 这会将所选元素移动到其最终位置并对其余元素进行部分排序。 
5. 增量$i$和$j$当元素到达正确的位置时。 
3. 返回操作列表。 

为什么有效：每个枢轴操作都允许将至少一个元素放置到其正确的最终位置。 由于排列包含不同的整数，因此每个元素都有唯一的正确位置。 该算法在每一步中都取得进展，并且对已排序部分的简单操作不会破坏排序顺序，从而保证在$n + m$操作数远低于 10,000。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def pivot_sort(arr, target):
    pos = {v:i for i,v in enumerate(arr)}
    ops = []
    n = len(arr)
    for k in range(1, n+1):
        idx = pos[k]
        if idx == k-1:
            continue
        # perform pivot swap at idx
        left = arr[:idx]
        mid = arr[idx]
        right = arr[idx+1:]
        arr[:] = right + [mid] + left
        # update positions
        for i,v in enumerate(arr):
            pos[v] = i
        ops.append(idx+1)
    return ops

def main():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    q = list(map(int, input().split()))
    
    ops_p = pivot_sort(p, n)
    ops_q = pivot_sort(q, m)
    
    k = max(len(ops_p), len(ops_q))
    result = []
    for i in range(k):
        op_p = ops_p[i] if i < len(ops_p) else 1
        op_q = ops_q[i] if i < len(ops_q) else 1
        result.append((op_p, op_q))
    
    print(len(result))
    for a, b in result:
        print(a, b)

if __name__ == "__main__":
    main()
```该解决方案构建了元素位置图，以实现有效的枢轴选择。 然后，它独立地为每个数组生成枢轴操作，并通过用虚拟操作填充较短的列表来对齐它们。 每次枢轴后更新位置可以避免相差一的错误并确保正确性。
