 ## 解决方案
 ## 问题理解

 董事会有`N`行和`M`列。 机器人从细胞开始`(i, j)`并重复执行一个随机动作。 从内部单元来看，它有四种同样可能的选择：留在原地、向左移动、向右移动或向下移动。 在左边界，不可能向左移动，因此机器人只能在停留、向右和向下之间进行选择。 这同样适用于右边框对称。 

当机器人第一次到达最后一行时，该过程结束。 在此之前我们需要预期的移动次数。 

这不是最短路径问题。 机器人永远随机行为，直到它最终到达底行，因此我们想要的数量是对无限多次随机游走的期望。 

约束条件达到`1000 x 1000`，这立即排除了任何重复模拟转换直到收敛的状态空间方法。 一个简单的马尔可夫链公式将创建多达一百万个状态。 求解如此大小的密集线性系统是完全不可能的。 单行长度上的偶数立方时间`1000`已经太慢了。 

运动的结构是观察的关键。 机器人只能向下移动，不能向上移动。 这意味着对 row 的期望`r`仅取决于行`r + 1`，因此可以从下到上独立地处理行。 

一些边缘情况很容易被错误处理。 

如果机器人已经从最后一行开始，则答案恰好为零，因为它已经到达目标。 

例子：```
Input
3 5
3 2
```正确输出：```
0.0
```粗心的实现可能仍然会为这一行建立方程并产生正的期望。 

案例`M = 1`行为也不同。 只有一列，因此机器人可以停留或向下移动，每个都有概率`1/2`。 递归变得比一般的三对角系统简单得多。 

例子：```
Input
2 1
1 1
```预期步数为`2`，因为每次移动都有概率成功`1/2`。 

另一个微妙的问题来自边界概率。 内部单元有四种可能的移动，但边缘单元只有三种。 在任何地方重复使用相同的循环会在边界附近产生不正确的期望。 

例子：```
Input
2 2
1 1
```从`(1,1)`机器人只有三种选择：停留、向右、向下。 将其视为内部细胞会低估向下移动的可能性并给出错误的期望。 

## 方法

 一种直接的暴力想法是为每个单元定义一个方程。 让`E[r][c]`表示该单元格的预期剩余步骤。 对于每个状态我们写：```
E[state] = 1 + average(E[next states])
```这产生了一个线性系统，高达`10^6`变量。 一般高斯消去法大约需要`10^18`操作，完全不可行。 

即使迭代松弛方法也存在问题。 期望可以在网格中缓慢传播，并且收敛需要超过一百万个状态的多次完整传递。 

重要的结构观察是机器人永远不会向上移动。 一旦它离开一行，就永远不会回来。 因此，当前行仅取决于其下方已计算的行。 

假设我们已经知道 row 的所有期望`r + 1`。 然后对于行`r`，每个方程仅引用同一行内的单元格和下一行的常数。 这将问题转化为解决一维系统。 

对于内部柱：```
E[c] = 1 + (E[c-1] + E[c] + E[c+1] + below[c]) / 4
```重新排列：```
3E[c] - E[c-1] - E[c+1] = 4 + below[c]
```这是一个三对角线性系统。 此类系统可以通过前向消除和后向替换在线性时间内求解。 

我们不是求解所有单元上的一个巨大系统，而是每一行求解一个三对角系统。 由于有`N`行，每行都有`M`列，总复杂度变为`O(NM)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((NM)^3) | O((NM)^3) | O((NM)^2) | O((NM)^2) | 太慢了 |
 | 最佳 | O(NM) | O(M)| 已接受 |

 ## 算法演练

 1. 定义`dp[c]`作为列中剩余步骤的预期数量`c`在当前行下方的行中。 

最初，对于底行，每个期望都是零，因为机器人已经达到了目标。 
2. 处理来自`N - 1`向上至`1`。 

每行仅依赖于其正下方的行，因此自下而上的处理保证了所有需要的值都是已知的。 
3.如果`M = 1`，直接处理该行。 

机器人只有两种可能的动作：停留或向下移动。 

方程为：$E = 1 + \frac{E + below}{2}$重新排列给出：$E = 2 + below$4. 否则，为该行构建一个三对角系统。 

对于左边界：$2E_1 - E_2 = 3 + below_1$因为只有三个动作可用。 
5. 对于每个内部柱：$3E_i - E_{i-1} - E_{i+1} = 4 + below_i$6. 对于右边界：$2E_M - E_{M-1} = 3 + below_M$7. 使用前向消除法求解三对角方程组。 

从每个方程中消除左侧系数，以便每一行仅取决于其自身和下一个变量。 
8. 从右向左进行回代。 

这将恢复当前行的所有期望。 
9. 更换`dp`与新计算的行。 
10.处理到起始行后，输出起始列的期望`j`。 

### 为什么它有效

 关键的不变量是处理行时`r`, 行的期望`r + 1`已经是正确的和最终的。 

行的每个方程`r`直接来自期望值的定义：```
expected steps = 1 + expected future value
```行内唯一的未知数是相邻的列，这创建了一个三对角线性系统。 前向消除和后向替换精确地解决了这个系统，因此为该行计算的每个期望在数学上都是正确的。 由于行从不依赖于更高的行，因此从下到上的处理计算每个可达状态的确切期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    start_row, start_col = map(int, input().split())

    if start_row == n:
        print("0.0000000000")
        return

    dp = [0.0] * m

    for _ in range(n - 1, start_row - 1, -1):
        if m == 1:
            dp[0] += 2.0
            continue

        a = [0.0] * m
        b = [0.0] * m
        c = [0.0] * m
        d = [0.0] * m

        b[0] = 2.0
        c[0] = -1.0
        d[0] = 3.0 + dp[0]

        for i in range(1, m - 1):
            a[i] = -1.0
            b[i] = 3.0
            c[i] = -1.0
            d[i] = 4.0 + dp[i]

        a[m - 1] = -1.0
        b[m - 1] = 2.0
        d[m - 1] = 3.0 + dp[m - 1]

        for i in range(1, m):
            factor = a[i] / b[i - 1]
            b[i] -= factor * c[i - 1]
            d[i] -= factor * d[i - 1]

        ndp = [0.0] * m
        ndp[m - 1] = d[m - 1] / b[m - 1]

        for i in range(m - 2, -1, -1):
            ndp[i] = (d[i] - c[i] * ndp[i + 1]) / b[i]

        dp = ndp

    print(f"{dp[start_col - 1]:.10f}")

solve()
```该解决方案一次仅存储一行期望。`dp[c]`始终表示当前行下方的行已计算的期望。 

特殊处理为`M = 1`避免被零除并反映单柱板中不同的过渡结构。 如果没有这个分支，三对角结构将错误地引用不存在的邻居。 

数组`a`,`b`， 和`c`存储三对角系的左、中、右系数。`d`存储常数项。 这与标准 Thomas 算法布局相匹配。 

前向消除会修改现有系统。 处理后指标`i`，变量`E[i-1]`不再出现在后面的方程中。 

回代从右到左重建行。 顺序很重要，因为每个变量都取决于其右侧已计算的值。 

该循环精确处理来自`n - 1`下降到`start_row`。 无需计算起始位置上方的行，因为它们永远不会影响答案。

 ## 边缘情况

 考虑机器人已经在最后一行启动的情况。 

输入：```
3 5
3 2
```算法检查`start_row == n`在任何 DP 工作开始之前。 由于机器人已经到达目标行，因此预计剩余移动次数恰好为零。 

现在考虑单柱板。 

输入：```
2 1
1 1
```递归变为：$E = 1 + \frac{E + 0}{2}$求解给出：$E = 2$该实现通过直接更新来处理这个问题`dp[0] += 2`。 

最后，考虑边界行为。 

输入：```
2 2
1 1
```方程为：$2E_1 - E_2 = 3$

$-E_1 + 2E_2 = 3$求解产量：$E_1 = E_2 = 3$该算法为边缘单元构建这些精确的方程，因此可以正确计算期望，而无需像内部单元那样处理边界。
