[CF 1418B - 否定前缀](https://codeforces.com/problemset/problem/1418/B)

 **标签：** 贪心，排序
 **求解时间：** 2m

 ## 解决方案
 ## 问题理解

 我们有一个数组和第二个二进制数组，描述哪些位置被锁定，哪些位置被解锁。 

锁定仓位必须保持其原始价值。 解锁位置可以接收最初属于解锁位置的任何值。 换句话说，我们可以自由地排列未锁定索引上的值，但锁定的值将永远固定。 

选择这样的重新排列后，我们查看结果数组的前缀和。 让$k$是前缀和为负的最后一个位置。 如果每个前缀和都是非负的，那么$k=0$。 

我们的任务是产生任何有效的重新排列，使$k$尽可能小。 

从约束中观察到的关键是$n\le100$。 尽管这个数字很小，但解锁位置的数量也可能接近 100，并且尝试所有排列将需要最多$100!$可能性，这是完全不可能的。 

挑战在于了解哪种排列可以最小化最后一个负前缀。 

一个微妙的点是，我们没有被要求最大化非负前缀的数量。 我们只关心最后一个负前缀的位置。 有时，前缀必须保持负数，因为锁定的负值会较早出现并且无法更改。 

另一个容易犯的错误是认为前缀和的实际值在全球范围内都很重要。 唯一的自由来自于未锁定的位置，因此我们应该关注如何放置这些值，以便尽早使前缀尽可能大。 

考虑：```
a = [-8, 4, -2, -6, 4, 7, 1]
l = [ 1, 0,  0,  0, 1, 1, 0]
```第一个元素已被锁定，并且已经使第一个前缀为负。 我们无法解决这个问题。 最好的策略是尽早放置最大的可用解锁值，以便尽快从负余额中恢复。 

当每个仓位都被锁定时，会出现另一种边缘情况：```
a = [2, -3, 4, -1]
l = [1,  1, 1,  1]
```不允许重新排列。 答案必须与原始数组完全相同。 

第三种边缘情况是所有位置都解锁时：```
a = [0, 1, -4]
l = [0, 0,  0]
```最优的安排是：```
[1, 0, -4]
```首先放置较大的值可以最大化每个前缀总和并最小化负前缀可以持续的时间。 

## 方法

 暴力解决方案将收集未锁定位置上的所有值，生成每个可能的排列，重建数组，计算其前缀和，确定相应的值$k$，并保持最佳安排。 

这是正确的，因为它检查了每一个合法的重新安排。 不幸的是，如果有$m$解锁位置，需要$m!$排列。 即使是为了$m=15$，这已经远远超出了实际的极限。 

关键的观察是我们实际上并不关心特定的前缀。 我们关心的是尽早使前缀和变为非负数。 

假设我们只查看未锁定的位置。 如果有两个解锁位置$i<j$包含值$x<y$，然后放置$y$在较早的位置增加每个前缀和$i$继续前进$y-x$。 较大的值有助于以后放置较早的所有前缀。 

这与用于证明按降序排序可以最大化所有部分和的交换参数完全相同。 

对解锁值进行任意排列。 如果较早解锁的位置包含的值小于较晚解锁位置的值，则交换它们不会减少任何未来的前缀和。 重复这个过程最终会产生按降序排列的解锁值。 

这种安排同时最大化每个前缀和。 由于每个前缀都尽可能大，因此负前缀会尽早消失，从而最大限度地减少最后一个具有负前缀的位置。 

所以解决方案非常简单：

 1. 提取未锁定位置的所有值。 
2. 按降序排列。 
3. 从左到右遍历数组。 
4. 每当遇到未锁定的位置时，将下一个最大的可用值放在那里。 

### 比较

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(m!\cdot n)$|$O(m)$| 太慢了|
 | 最佳|$O(n\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 读取数组和锁状态数组。 
2. 收集所有未锁定仓位的值，即锁定值为0。 
3. 按降序排列此集合。 

最大的解锁值应该出现在最早的解锁位置，因为较早的位置有助于更多的前缀和。 
4. 从左到右扫描阵列。 
5. 每当遇到锁定位置时，保持其值不变。 
6. 每当遇到解锁位置时，从已排序的降序列表中取出下一个值并将其放置在那里。 
7. 输出结果数组。 

### 为什么它有效

 考虑两个未锁定的位置$i<j$。 如果值为$i$小于处的值$j$，交换它们会增加包含位置的每个前缀和$i$但还没有定位$j$，同时保留后面的前缀不变。 前缀和没有减少。 

因此，任何未按解锁位置降序排序的排列都可以通过这种交换来改进。 重复应用这个论点会导致降序排列。 

降序排列使所有合法重新排列中的每个前缀和最大化。 由于每个前缀和都尽可能大，因此前缀和不再为负的点会尽早出现。 因此得到的值是$k$是最小的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        l = list(map(int, input().split()))

        free = []

        for i in range(n):
            if l[i] == 0:
                free.append(a[i])

        free.sort(reverse=True)

        ptr = 0

        for i in range(n):
            if l[i] == 0:
                a[i] = free[ptr]
                ptr += 1

        print(*a)

solve()
```第一部分收集位于解锁位置的所有值。 

按降序排序实现了上面证明的贪婪选择。 最大的可用值始终分配给最早可用的解锁位置。 

重建阶段遍历原始数组。 锁定的位置保持不变。 未锁定的位置按顺序接收来自排序列表的值。 

不需要显式计算前缀和。 证明表明，最大化每个前缀和相当于最小化最后一个负前缀。 

所有值都适合 Python 整数，因此不必担心溢出。

 ## 边缘情况

 考虑每个仓位都被锁定的情况：```
n = 4
a = [2, -3, 4, -1]
l = [1, 1, 1, 1]
```解锁的集合是空的。 排序不执行任何操作，重构也不执行任何操作，算法输出原始数组。 这是唯一合法的答案。 

考虑每个位置都被解锁的情况：```
n = 3
a = [0, 1, -4]
l = [0, 0, 0]
```该算法提取所有值，将它们排序为：```
[1, 0, -4]
```并将它们放回原处。 任何其他布置给出的前缀和不大于该布置的相应前缀和。 

考虑强制否定前缀：```
n = 3
a = [-10, 8, 7]
l = [1, 0, 0]
```第一个值被锁定，因此第一个前缀始终是$-10$。 该算法将未锁定的值排序为：```
[8, 7]
```产量：```
[-10, 8, 7]
```前缀和变为：```
-10, -2, 5
```最后一个负前缀出现在位置 2。没有任何重新排列可以做得更好，因为最大的可用值已经尽早使用。 

最后，考虑重复的解锁值：```
n = 5
a = [3, 3, -1, -1, 2]
l = [0, 0, 0, 0, 1]
```排序产生：```
[3, 3, -1, -1]
```即使使用重复的值，重建仍然有效。 证明仅取决于相对顺序，而不取决于唯一性。
