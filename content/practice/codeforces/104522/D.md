 ## 解决方案
 ## 问题理解

 我们得到一个数组`a`长度`n`。 我们被允许改变它的一些元素。 经过这些更改后，我们希望该数组能够与另一个数组的存在兼容`b`长度`n+1`，其中的每个值`a`定义为中两个相邻值的最大值`b`。 

换句话说，每个`a_i`表示长度为 2 的线段的峰值`b`: 它必须等于`max(b_i, b_{i+1})`。 所以每`a_i`对两个相邻位置施加局部约束`b`，同时它要求这两个位置中至少有一个`b`实际上达到了这个最大值。 

任务是最小限度地修改`a`使得至少存在一个有效的`b`满足所有这些限制。 

重要的一点是我们不是在构建`b`明确地。 我们只关心是否有这样一个`b`调整尽可能少的元素后存在`a`尽可能。 

约束很大，测试用例的总长度可达`2⋅10^5`。 这排除了任何尝试模拟或搜索可能的结构的解决方案`b`明确地说，因为即使每次测试进行二次推理也会太慢。 每个测试用例的解决方案必须是线性的。 

当其中一个元素出现时，就会出现幼稚故障模式`a`与邻居相比“太大”了。 例如，如果一个元素严格大于它的两个邻居，它往往会对中间结构提出一个不可能的要求`b`，因为它必须同时支配两个相邻约束，同时仍然可以实现为共享边的最大值。 这些局部不一致正是我们需要检测和修复的。 

## 方法

 一种直接的方法是尝试构建`b`对于一个固定的`a`。 我们会对待每一个岗位`i`作为强制约束`(b_i, b_{i+1})`，然后尝试将值分配给`b`同时满足所有约束。 这成为一个全局约束满足问题`n+1`变量与`n`重叠的约束。 

这可以通过回溯或状态传播来解决，但约束之间的相互作用沿着整个数组传播。 在最坏的情况下，一对的每个决策都会影响所有未来的对，从而导致每个测试用例的指数分支或至少二次传播。 

关键的观察结果是该结构纯粹是本地的：每个`a_i`只连接两个相邻位置`b`。 因此，不要全局思考`b`，我们可以在本地推理每个`a_i`可以与邻居兼容。 

关键的简化是消除`b`完全并根据相邻元素之间的局部一致性重新解释可行性`a`。 一旦以这种方式重写，问题就减少到检测和修复本地违规，从而阻止任何一致的分配`b`。 

经过此转换后，可以使用其邻居在恒定时间内检查每个位置，并且我们只计算必须修改多少个位置才能消除所有违规。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力构建`b`| 指数| O(n) | 太慢了 |
 | 本地一致性检查`a`| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们以一种避免显式构建的方式重新解释条件`b`。 每个`a_i`对应于两个相邻位置的“峰值约束”`b`。 为了使这种结构保持一致，没有任何单个约束可以强制产生相邻约束无法支持的孤立值。 

关键的减少是不一致只出现在局部：在以下位置：`a_i`与两个相邻值相比太大`a`。 在任何有效的构造中，任何一方都不能支持这样的元素`b`，所以必须修改。 

我们按如下方式进行。 

1. 对于每个测试用例，读取数组`a`。 
2. 对于每个位置`i`，计算它可以从其邻居那里接收到的最强“支持”，这是其相邻值中较小的一个。 对于内部位置，这是`min(a_{i-1}, a_{i+1})`。 对于端点，我们将缺失的邻居视为在适当方向上无限许可。 
3. 检查是否`a_i`超出双方所能提供的支持。 如果`a_i`严格大于两个邻居，则没有有效的配置`b`无需修改即可实现该值`a_i`。 
4. 计算所有此类位置。 每一项都对应一个强制修改。 
5. 输出每个测试用例的总计数。 

### 为什么它有效

 有效的配置要求中的每个值`a`可以实现为共享边的最大值`b`。 如果一个元素`a_i`严格大于两个相邻约束，则`b`可以“托管”它而不违反重叠边缘结构的最大条件。 由于该峰值没有替代位置，因此恢复可行性的唯一方法是修改该元素。 

相反，如果`a_i`并不严格大于两个邻居，那么至少存在一个可以支持它的方向，这意味着我们总是可以将相应的约束定向为`b`始终如一。 这保证了精确修复局部不可能的位置就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    INF = 10**18
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        if n == 1:
            print(0)
            continue
        
        ans = 0
        
        for i in range(n):
            left = a[i - 1] if i - 1 >= 0 else INF
            right = a[i + 1] if i + 1 < n else INF
            
            if a[i] > left and a[i] > right:
                ans += 1
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案独立处理每个测试用例，并在恒定时间内检查每个位置。 对于边界元素，我们将缺失的邻居视为非限制性的，以便只计算真正的内部冲突。 

该实现依赖于单个线性扫描，并且不需要辅助结构。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            out.append("0")
            continue
        ans = 0
        INF = 10**18
        for i in range(n):
            left = a[i-1] if i-1 >= 0 else INF
            right = a[i+1] if i+1 < n else INF
            if a[i] > left and a[i] > right:
                ans += 1
        out.append(str(ans))
    return "\n".join(out) + "\n"

# provided sample
assert run("1\n4\n2 4 6 3\n") == "1\n"

# custom cases
assert run("1\n1\n100\n") == "0\n", "single element"
assert run("1\n3\n1 2 3\n") == "0\n", "monotone increasing"
assert run("1\n3\n3 2 1\n") == "0\n", "monotone decreasing"
assert run("1\n5\n1 5 1 5 1\n") == "2\n", "alternating peaks"

 ## 边缘情况

 对于`n = 1`，没有邻近约束，因此任何单一值总是可以通过选择来实现`b = [x, x]`。 该算法正确返回零，因为没有位置有两个邻居违反条件。 

对于严格单调数组，每个元素至少由一侧支持，因此没有元素严格大于两个邻居。 扫描产生零修改，符合一致的事实`b`总是可以通过沿着链传播值来构建。 

对于交替的高-低模式，局部峰值恰好出现在超过两个相邻峰值的高位置处，并且必须修改每个这样的峰值。 该算法精确计算这些位置，匹配消除不可行性所需的最小修复。
