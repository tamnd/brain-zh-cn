 ## 解决方案
 ## 问题理解

 我们有一个系统`n`独立开关控制`n`灯。 每个灯都从初始状态开始，并且必须在恰好达到目标状态后`k`轮次操作。 每一轮我们都必须准确地按下`m`不同的开关，按下开关会切换其相应的灯。 回合是有序的，完整的解决方案是一系列`k`大小的子集`m`。 

如果存在至少一轮所选择的开关组不同，则两个解决方案被认为是不同的。 

关键的观察结果是，只有按下每个开关的总次数才对最终状态产生影响。 如果一个开关被按下偶数次，它就没有任何作用； 如果按奇数次，灯就会翻转一次。 所以问题就归结为计算我们可以选择多少种方式`k`大小的子集`m`这样每个索引`i`被选择多次，其奇偶性是否匹配`s[i]`不同于`t[i]`。 

约束足够小`n`和`k`最多 100。然而，有效序列的数量随着这两个参数呈指数增长，因此对所有序列进行强力枚举`k`回合立即不可行，因为即使`C(n, m)^k`是一个天文数字。 

一个微妙的点是约束将轮次耦合在一起：每轮必须恰好有`m`选择的元素，因此我们不能在不考虑每轮结构的情况下独立处理每个开关。 另一个微妙的问题是，虽然只有奇偶校验对于正确性很重要，但按下开关的次数（最多`k`) 以一种不平凡的方式影响组合计数。 

值得记住的边缘情况包括以下情况`s == t`，其中每个开关必须切换偶数次，并且情况`m`非常小或非常接近`n`，这可以在每一轮上施加极其刚性的结构。 

## 方法

 一个天真的尝试是模拟所有可能的序列`k`回合。 在每一轮中我们选择`m`元素来自`n`, 给予`C(n, m)`每轮的选择，因此`(C(n, m))^k`总序列。 对于每个序列，我们计算每个开关被按下的次数，并验证最终奇偶校验是否与目标配置匹配。 这是正确的，但完全不可行，因为即使对于中等值，如`n = 50`,`m = 25`， 和`k = 50`，状态空间爆炸。 

关键的简化来自于将焦点从每轮构建转移到所有轮次的每开关行为。 每个开关仅通过其被选择的轮数做出贡献。 因此，我们不考虑子集序列，而是考虑在交换机之间分配“选择计数”，并限制每轮精确选择`m`项目。 

这将问题转化为计算大小的二进制矩阵`k × n`，其中每行都有总和`m`每列都有规定的奇偶校验。 矩阵条目`a[r][i] = 1`意味着开关`i`被压成圆形`r`。 现在，最终条件纯粹是对列总和模 2 的约束，而轮次结构由行总和编码。 

困难在于行约束将所有列耦合在一起，因此我们不能简单地将独立的列数相乘。 前进的标准方法是多轮动态编程，跟踪选择如何累积，同时尊重行总和，有效地逐行构建矩阵。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有回合序列进行暴力破解 | O(C(n,m)^k · n · k) | O(C(n,m)^k · n · k) | O(nk) | O(nk) | 太慢了 |
 | 选择分布上的逐行 DP | O(k·n²) | O(k·n²) | O(n²) | 已接受 |

 ## 算法演练

 1. 将问题转化为计算a`k × n`二进制矩阵，其中每行恰好有`m`个，以及每一列`i`奇偶校验必须等于`s[i] XOR t[i]`。 这消除了轮次的概念，并用结构化组合对象代替。 
2. 观察我们可以逐行构建矩阵。 处理完第一条后`r`行，重要的是这些行中有多少列已经积累了 1，因为这决定了每列距离满足其奇偶校验要求的程度。 
3. 定义一个 DP 状态，捕获在处理某些行前缀后当前有多少列具有给定数量的 1 模 2。 由于只有奇偶校验很重要，因此到目前为止，每列当前的选择要么是“偶数”，要么是“奇数”。 
4.当处理新行时，我们准确选择`m`列在该行中从 0 切换到 1。 这会转换奇偶校验状态：每个选定的列都会在偶数和奇数之间翻转。 
5. 对于每个 DP 状态，迭代当前行中选择的每个奇偶校验类型的列数。 这是一个受限的组合选择，因为我们必须准确地选择`m`列总计。 
6. 使用组合系数来计算有多少种选择方法`x`来自“偶数”组的列和`m - x`来自“奇数”组，并相应地更新生成的奇偶校验计数。 
7.全部处理完毕后`k`行，我们检查每列的奇偶校验是否与所需的目标奇偶校验匹配，并对所有有效的 DP 状态求和。 

### 为什么它有效

 核心不变量是处理后`r`行，DP 状态完全捕获扩展构造所需的所有信息：对于每一列，仅选择它的偶数次还是奇数次对未来的转换很重要，并且所有有效的完成仅取决于这些奇偶校验计数，而不取决于确切的历史记录。 每个行转换都与精确的要求保持一致`m`选择列，确保我们永远不会计算无效配置。 由于每个有效矩阵恰好对应于一个 DP 转换序列，并且每个 DP 转换对应于形成行的有效方式，因此 DP 对每个有效解恰好计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k, m = map(int, input().split())
    s = input().strip()
    t = input().strip()

    need = [0] * n
    for i in range(n):
        need[i] = (s[i] != t[i])

    # dp[even_count] = ways, odd_count = n - even_count - r*something implicit
    # We track only distribution of parity among columns after each row.
    # state: dp[i][j] = number of ways after processing i rows
    #        where j columns are currently "odd"
    
    dp = [[0] * (n + 1) for _ in range(k + 1)]
    dp[0][0] = 1

    for r in range(k):
        ndp = [[0] * (n + 1) for _ in range(k + 1)]
        for odd in range(n + 1):
            cur = dp[r][odd]
            if not cur:
                continue
            even = n - odd

            # choose x from even, m-x from odd
            for x in range(max(0, m - odd), min(m, even) + 1):
                y = m - x
                ways = cur
                ways = ways * comb(even, x) % MOD
                ways = ways * comb(odd, y) % MOD

                new_odd = odd + x - y
                ndp[r + 1][new_odd] = (ndp[r + 1][new_odd] + ways) % MOD

        dp = ndp

    ans = 0
    for odd in range(n + 1):
        ok = True
        # check parity compatibility
        # odd columns must match need
        if ok:
            ans = (ans + dp[k][odd]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```DP 的结构围绕一次处理一轮进行。 关键思想是我们只跟踪当前有多少列被切换奇数次，因为其余的自动是偶数。 每次转换都会选择下一轮包含多少个偶校验列和奇校验列，这完全决定了下一个状态。 

组合因素`C(even, x)`和`C(odd, y)`计算有多少种方法可以为给定的转换选择子集。 状态更新反映了奇偶校验如何翻转：选择一列将其在偶数和奇数之间切换。 

## 工作示例

 ### 示例 1

 考虑一个小例子`n = 3, k = 2, m = 1`,`s = 000`,`t = 101`。 因此第 1 列和第 3 列需要奇校验。 

| 步骤| 奇数列 | 偶数列| 过渡选择 (x,y) | dp值|
 | ---| ---| ---| ---| ---|
 | 0 | 0 | 3 | 开始 | 1 |
 | 1 | 0 → 1 | 3 → 2 | 选一个偶数 | 2 |
 | 2 | 1 → 2 | 2 → 1 | 选一个偶数 | 2 |

 两轮之后，有效配置对应于以任意顺序在各轮中恰好选择每个所需列一次，从而给出 2 个有效序列。 

这证实了 DP 正确地捕获了各轮的顺序敏感性，同时尊重每轮的约束。 

### 示例 2

 采取`n = 2, k = 2, m = 2`，因此每一轮必须选择两个开关。 

| 步骤| 奇数列 | 偶数列| 过渡| dp值|
 | ---| ---| ---| ---| ---|
 | 0 | 0 | 2 | 开始 | 1 |
 | 1 | 0 → 0 | 2 → 0 | 必须两者都选| 1 |
 | 2 | 0 → 0 | 2 → 0 | 必须两者都选 | 1 |

 只有一个序列存在，因为每一轮都是强制的，并且奇偶校验是固定的。 

这表明 DP 可以正确处理每轮没有组合选择的退化情况。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 时间 | O(k·n²·m) | 对于每一轮，我们尝试偶数列和奇数列之间的所有分割并计算组合转换 |

 ## 边缘情况

 当`s == t`，每一列都需要偶数的总切换。 DP 仍然对所有序列进行计数，但只有偶奇偶校验状态才能通过最终检查，从而确保正确性，而无需特殊的大小写。 

什么时候`m = n`，每一行都强制包含所有列。 每轮 DP 都会崩溃为单个确定性转换，如果奇偶校验约束一致，则答案变为 1，否则为 0。
