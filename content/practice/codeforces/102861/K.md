 ## 解决方案
 ## 问题理解

 我们得到了一个无向的友谊图。 每个顶点代表一个玩家，每条边代表一个友谊关系。 我们需要将玩家最多分成两组，这样对于每个玩家来说，属于同一组的朋友数量是奇数。 两组的实际名称并不重要，重要的是两名球员是否被放在一起。 

输入最多可提供 100 名玩家及其友谊边。 答案是`Y`如果将玩家分配到两个可能的组满足每个玩家的奇怪朋友条件，并且`N`否则。 

对玩家数量的小限制是对预期复杂性的关键观察。 对于 100 个变量，基于线性代数的算法是实用的。 暴力分配会尝试所有可能的拆分，这意味着最多检查 (2^{100}) 种可能性，远远超出任何程序可以处理的范围。 我们需要将图条件转换为最多有 100 个未知数的系统，其中高斯消去法足够快。 

在某些情况下，直觉方法可能会失败。 一个常见的错误是认为如果所有级别都是奇数，则将每个玩家放入一组应该总是有效的。 当某些顶点具有偶数度时，这是错误的。 例如：```
3 2
1 2
2 3
```中间的玩家有两个朋友，因此如果每个人都在同一组中，则该玩家会看到两个朋友，这是偶数。 正确的输出是`N`。 仅检查图的总度数的方法忽略了每个顶点都有其自己的条件这一事实。 

另一个棘手的情况是这两个组不需要都是非空的。 例如：```
2 1
1 2
```将两名玩家放入同一组后，每个玩家都会在该组中拥有一位朋友。 正确的输出是`Y`。 强制第二组非空的解决方案将错误地拒绝这种情况。 

第三种情况是存在多个有效分区时。 例如：```
4 4
1 2
2 3
3 4
4 1
```循环可以以多种方式分割，算法只需要找到一种有效的分配。 它不应该假设存在唯一的分区。 

## 方法

 直接暴力法是独立决定每个玩家的组。 对于每个 (2^P) 可能的分配，我们计算每个玩家有多少个相邻顶点具有相同的分配组。 如果所有计数都是奇数，则分区存在。 

这种方法是正确的，因为它会检查每个可能的分区。 然而，对于 (P=100)，分配数量为 (2^{100})，大约为 (1.27 \times 10^{30})。 即使检查一项作业只需要几次操作，这也是不可能的。 

问题的重要结构是条件仅取决于奇偶性。 我们不需要同一组中朋友的确切数量，只需要该数量是奇数还是偶数。 奇偶校验自然会导致算术模 2，其中每个值要么为零，要么为一。 

让 (x_i) 描述玩家 (i) 的组。 我们对这两组使用 (0) 和 (1)。 对于邻居（j），指示（j）是否与（i）在同一组中的值可以写为：

 [
 1 + x_i + x_j
 ]

 当计算以 2 为模时。当两个玩家具有相同的组值时，表达式为 1，否则为 0。 

对于玩家 (i)，将这个表达式添加到所有朋友上可以得到同组朋友数量的奇偶性：

 [
 deg_i + \sum_{j \in N(i)} x_j + deg_i \cdot x_i
 ]

 所有运算均以 2 为模。该值必须等于 1，因为同组好友的数量必须是奇数。 

重新排列给出线性方程：

 [
 \sum_{j \in N(i)} x_j + (deg_i \bmod 2)x_i = 1 + (deg_i \bmod 2)
 ]

 每个玩家贡献一个方程，每个玩家都是一个变量。 问题变成了检查 GF(2) 上最多 100 个线性方程组是否有解。 高斯消去法直接适用于此。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^P·P²) | O(2^P·P²) | O(P²) | 太慢了 |
 | 最佳| O(P3)| O(P²) | 已接受 |

 ## 算法演练

 1. 构建一个表示线性系统的二进制矩阵。 每一行对应一个玩家，每一列对应一个玩家的组变量。 最后一列存储等式右侧所需的值。 

如果玩家 (j) 是玩家 (i) 的好友，则变量 (x_j) 的系数为 1。 此外，如果玩家 (i) 的度数为奇数，则 (x_i) 的系数会因 (deg_i \cdot x_i) 项而发生切换。 
2. 对模 2 应用高斯消去法。找到当前列中包含 1 的行，并将其交换到当前枢轴位置。 

需要交换是因为枢轴可能出现在当前行下方，并且如果不向上移动它，则无法正确消除列。 
3. 使用数据透视行从每隔一行中删除当前变量。 

由于所有运算都是模 2，因此删除变量只是将数据透视表行与另一行进行异或。 这使矩阵值保持二进制。 
4. 排除后，检查每一行。 如果所有变量系数均为零但最终值为 1，则该方程是不可能的，因此不存在有效划分。 

这样的一行代表了一个矛盾，如（0 = 1）。 
5. 如果不存在矛盾，系统至少有一个组值的分配，所以答案是`Y`。 

为什么它有效：

 从图问题到方程的转换保留了我们需要的精确条件。 任何有效的划分都会产生满足每个方程的变量值，并且方程的任何解都会给出组值，其中每个玩家在同一组中都有奇数个朋友。 GF(2) 上的高斯消元法不会改变解集，它只是将方程转换为更简单的形式。 最后的矛盾检查将没有可能分区的系统与至少有分区的系统区分开来。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    P, F = map(int, input().split())
    adj = [[0] * P for _ in range(P)]
    deg = [0] * P

    for _ in range(F):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        adj[a][b] = 1
        adj[b][a] = 1
        deg[a] += 1
        deg[b] += 1

    mat = [[0] * (P + 1) for _ in range(P)]

    for i in range(P):
        for j in range(P):
            mat[i][j] = adj[i][j]
        if deg[i] % 2 == 1:
            mat[i][i] ^= 1
        mat[i][P] = 1 ^ (deg[i] % 2)

    row = 0
    for col in range(P):
        pivot = row
        while pivot < P and mat[pivot][col] == 0:
            pivot += 1

        if pivot == P:
            continue

        mat[row], mat[pivot] = mat[pivot], mat[row]

        for i in range(P):
            if i != row and mat[i][col]:
                for j in range(col, P + 1):
                    mat[i][j] ^= mat[row][j]

        row += 1

    for i in range(P):
        all_zero = True
        for j in range(P):
            if mat[i][j]:
                all_zero = False
                break
        if all_zero and mat[i][P]:
            print("N")
            return

    print("Y")

if __name__ == "__main__":
    solve()
```邻接矩阵仅存储两个玩家是否是朋友。 由于约束很小，使用 (P \times P) 矩阵可以使方程构造简单，并避免需要额外的图遍历逻辑。 

矩阵构造直接遵循导出的方程。 每段友谊都会为朋友的变量贡献一个系数。 对于具有奇数度的玩家，玩家自己的变量会收到一个额外的系数。 右侧计算为 (1 + deg_i) modulo 2。 

消除使用 XOR，因为加法和减法在模 2 算术中是相同的。 数据透视搜索会跳过当前无法用作数据透视的列，这是必要的，因为某些变量可能是自由变量。 

最终扫描仅检查不可能的行。 不包含变量但结果非零的行意味着系统需要错误的语句。 任何其他最终形式仍然至少有一项作业。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(P3)| 高斯消元法最多执行 P 个主元运算，每个运算可以更新长度为 P | 的 P 行。 
| 空间| O(P²) | 方程矩阵包含 P 行和 P+1 列 |

 对于 (P \le 100)，三次运行时间约为一百万个基本运算，这很容易在典型限制内。 内存使用量也很小，因为整个系统只包含大约一万个存储值。

 ## 边缘情况

 对于三名玩家的路径：```
3 2
1 2
2 3
```中间的玩家有二级。 简单地将每个人放在一起并不能满足该玩家的方程，因为同一组好友的数量将是两个。 在消除过程中，这显示为所有可变系数等于 0 且右侧等于 1 的行。 算法返回`N`。 

对于两个连接的玩家：```
2 1
1 2
```两名玩家可以属于同一组。 每个人只看到该组中的一个朋友。 线性系统有解，所以消去无矛盾地完成并返回`Y`。 

对于多个分区起作用的图：```
4 4
1 2
2 3
3 4
4 1
```该算法不会尝试选择特殊的分区。 它仅验证相应的方程是否一致。 由于简化矩阵没有不可能的行，因此存在一些分配，答案是`Y`。
