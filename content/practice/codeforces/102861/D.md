 ## 解决方案
 ## 问题理解

 人有两种圆形排列。 初始配对是逐位置进行的，因此位置`i`在一圈面的位置`i`在另一个圈子里。 在舞蹈过程中，每一步都恰好旋转一个圆圈。 旋转会更改两个圆之间的当前偏移。 仅当出现的每个偏移都是新的时，整个舞蹈才有效，因为看到相同的偏移两次意味着相同的对再次面对面。 

完整的舞蹈是由每一步之后的偏移顺序决定的。 旋转本身相当于在当前偏移中选择一个非零变化，因为每个非零变化模数`N`恰好对应于一个有效的旋转量。 

最后，最终的偏移量必须创建其年龄总和具有相同余数模的对`M`。 我们需要计算有多少个有效序列`K`非零变化以这些可接受的偏移量之一结束。 

输入大小是主要困难。`N`可以达到`10^6`，因此通过完整验证尝试每一对位置或每个可能的偏移的算法太慢。 最终计数部分必须接近线性`N`，以及舞蹈长度`K`可以大到`10^9`，所以我们无法模拟这些步骤。 

一些边缘情况很容易被忽略。 如果`K >= N`，有效的舞蹈不存在，因为初始偏移加上`K`以后的偏移量将至少包含`N+1`仅访问`N`可能的职位。 例如，与`N = 3`,`K = 3`，每三个移动序列都会重复一个偏移量，所以答案是`0`。 

最终偏移量永远不可能为零，因为偏移量零是起始状态。 例如，与`N = 3`,`K = 1`，如果只有原来的配对满足年龄条件，正确答案仍然是`0`， 不是`1`，因为如果不重复初始配对就无法达到该状态。 

多个有效的最终偏移量必须单独计算。 例如，如果第二个圆圈的两个不同的循环班次产生有效的年龄总和，则每个班次贡献其自己的舞蹈数量。 

## 方法

 直接方法将枚举所有可能的旋转序列。 每一步都有`N-1`可能的非零变化，所以这大致创建`(N-1)^K`的可能性。 即使对于小`K`，这增长得太快了。 更好的强力方法是枚举每个最后的班次并检查年龄条件是否成立，但检查一个班次的成本`O(N)`, 给予`O(N^2)`最坏情况下的时间对于`N = 10^6`。 

关键的观察结果是年龄条件仅取决于圆差。 假设最后一次轮班`s`是有效的。 那么对于每对相邻的女性位置，我们必须有`A[i] + B[i+s] = A[i+1] + B[i+1+s]`。 

重新排列给出`B[i+1+s] - B[i+s] = A[i] - A[i+1]`。 

左边是循环差分序列`B`，右边是一个固定模式，源自`A`。 因此，找到有效的移位就成为循环模式匹配问题。 

我们建立差异数组`B`并寻找差异模式`A`在差异数组的两个副本内。 Knuth-Morris-Pratt 算法在线性时间内找到所有匹配的起始位置。 

在找到有效的最终班次数量后，剩下的问题纯粹是组合问题。 有效长度的舞蹈`K`是一个序列`K+1`以 offset 开头的不同偏移量`0`。 如果`K < N`，固定最终的偏移叶子`K-1`中间偏移量可供选择和订购`N-2`职位。 每个有效非零最终移位的可能性数为`(N-2) * (N-3) * ... * (N-K)`这是`(N-2)! / (N-K-1)!`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((N-1)^K) | O((N-1)^K) | O(K) | 太慢了|
 | 检查每个班次 | O(N^2) | O(N^2) | O(1) | O(1) | 太慢了|
 | 最佳 | O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 计算女性的循环差异模式。 对于每个位置，存储`A[i] - A[i+1]`模数`M`。 这是每次有效的人员轮换都必须重现的模式。 
2. 计算男子的圆差数组。 对于每个位置，存储`B[i+1] - B[i]`模数`M`。 有效的最终轮班正是该差异序列与女性模式匹配的位置。 
3. 对复制一次的人差异数组运行 KMP。 每场比赛从以下位置开始`0`到`N-1`代表一个有效的最终班次。 重复的数组处理围绕圆末端的匹配。 
4、去掉最后班次的情况`0`，因为在舞蹈开始之前已经访问了初始偏移量。 
5. 如果`K >= N`， 输出`0`，因为有效的偏移序列不能包含超过`N`不同的状态。 
6.否则计算选择中间偏移的方式数量。 将该值乘以有效的最终班次数，并对结果取模`10^9+7`。 

为什么它有效：每个舞蹈都精确对应于循环偏移组中的一条路径。 有效性条件相当于访问不同的偏移量，因此在确定最终偏移量后，我们只需要对剩余访问过的偏移量的有序选择进行计数。 KMP 步骤准确地找到满足最终配对条件的移位，因为所有对和相等等于所有相邻差值相等。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def kmp_count(text, pattern, n):
    m = len(pattern)
    pi = [0] * m

    for i in range(1, m):
        j = pi[i - 1]
        while j and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j

    count = 0
    j = 0
    for i, x in enumerate(text):
        while j and x != pattern[j]:
            j = pi[j - 1]
        if x == pattern[j]:
            j += 1
        if j == m:
            start = i - m + 1
            if start < n:
                count += 1
            j = pi[j - 1]

    return count

def solve():
    N, M, K = map(int, input().split())
    A = [int(x) % M for x in input().split()]
    B = [int(x) % M for x in input().split()]

    if K >= N:
        print(0)
        return

    pattern = [(A[i] - A[(i + 1) % N]) % M for i in range(N - 1)]
    diff_b = [(B[(i + 1) % N] - B[i]) % M for i in range(N)]

    valid = kmp_count(diff_b + diff_b, pattern, N)

    if K == 1:
        ways = 1
    else:
        ways = 1
        for x in range(N - 2, N - K - 1, -1):
            ways = ways * x % MOD

    print(valid * ways % MOD)

if __name__ == "__main__":
    solve()
```KMP预处理构建了差异模式的失效函数。 这允许算法在不匹配后继续搜索，而无需从头开始，这就是线性复杂度的原因。 

重复的差异数组是必要的，因为循环匹配可能会跨越数组的末尾。 只从第一个开始`N`位置被计算在内，因为这些是实际的循环移位。 

乘积循环直接计算下降阶乘，而不是使用阶乘和模逆。 这避免了额外的模块化算术并且还处理`K = 1`情况自然。 

该程序从不自行构建舞蹈序列。 它只计算可能的最终偏移量并乘以那里的偏移订单数。

 ## 边缘情况

 当`K >= N`，算法立即返回零。 例如：```
3 100 3
1 2 3
4 5 6
```包括起始偏移在内，只有三种可能的偏移。 长度为三的舞蹈需要四种不同的偏移，这是不可能发生的。 

当唯一有效的配对是初始配对时，不得将其计算在内。 KMP阶段可以找到位移`0`，但组合阶段不允许返回到起始偏移量，因为所有访问的偏移量必须是不同的。 

当多个班次满足年龄条件时，算法会独立计算每个班次。 差异匹配步骤返回所有有效的循环起点，并且每个起点贡献相同数量的有效舞蹈历史，因为中间偏移的数量仅取决于`N`和`K`，而不是最终位置。
