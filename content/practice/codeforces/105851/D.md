 ## 解决方案
 ## 问题理解

 该任务是关于维护和查询有根树中的祖先关系。 给定一个连通的无环图，我们将一个节点解释为该结构的根。 每个查询都要求两个节点的最低公共祖先，这意味着位于两条根到节点路径上的有根树中的最深节点。 

更具体地说，将每个节点想象为层次结构中的一个点。 对于任意两个节点，它们到根的路径最终会合并。 向上移动时，它们的路径相遇的第一个节点就是查询的答案。 

输入可以理解为由其边跟随多个查询描述的树。 每个查询提供两个节点，输出是一个代表最接近它们的共享祖先的单个节点。 

此类问题的主要约束含义是树可能很大，通常最多有 10^5 个节点和类似数量级的查询。 为每个查询重新计算向上路径的解决方案将重复遍历长链，在最坏的情况下导致二次行为。 对于 10^5 个查询，即使每个查询的线性遍历也会变得太慢，因此我们需要一种预处理方法，将每个查询减少到对数或常数时间。 

在这种情况下，一些边缘情况很重要。 当一个查询节点是另一个节点的祖先时，答案通常是祖先节点本身。 例如，在以 1 为根的链 1-2-3-4 中，查询 (2, 4) 应返回 2。如果假设两个节点在比较之前必须同等提升，则简单的向上行走实现很容易会错过这一点。 

另一个边缘情况是倾斜树，其中结构退化为链表。 例如，1-2-3-4-5-6。 如果不进行预处理，重复的向上遍历将成为每个查询的最坏情况线性，这会破坏性能保证，即使正确性仍然存在。 

## 方法

 直接方法通过从两个节点向上走向根直到它们的路径相交来独立地处理每个查询。 这可以通过重复将一个节点移动到其父节点直到两个节点匹配深度，然后一起向上移动直到它们重合来实现。 这是有效的，因为在树中，到根的路径是唯一的，因此遇到的第一个共享节点是最低的共同祖先。 

正确性很简单，但效率低下来自于重复遍历。 每个查询可能需要退化树中的 O(n) 个步骤，并且对于许多查询，这会导致 O(nq)，当 n 和 q 都很大时，这太慢了。 

关键的观察是祖先查询在相同的结构上重复。 我们可以为每个节点预先计算大小为 2 的幂的“跳跃”，而不是逐步重新计算向上跳跃。 这将向上运动转化为对数跳跃。 一旦每个节点知道其第 1 个、第 2 个、第 4 个、第 8 个等祖先，我们就可以将节点提升到 O(log n) 的相同深度，然后同时提升它们，直到它们的祖先匹配。 

这种技术通常称为二元提升。 使用深度优先搜索或 BFS 对树进行一次预处理，以计算直接父代，然后动态编程构建更高的祖先。 然后通过从最高功率向下比较祖先来解决每个查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力向上行走| 每个查询 O(n) | O(n) | 太慢了 |
 | 二元提升| 每次查询 O(log n)，预处理 O(n log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 除非另有说明，否则我们假设树的根为节点 1。

1. 从边列表构建邻接表，以便我们可以高效地遍历树。 此步骤为遍历结构做好准备，无需重复边缘扫描。 
2. 从根开始运行深度优先搜索或广度优先搜索，以计算每个节点的深度和直接父节点。 在比较祖先之前，需要深度来对齐节点。 
3. 预先计算一个表，其中`up[v][k]`表示节点 v 的第 2^k 个祖先。通过遍历已知第一列，并使用递归填充更高的值`up[v][k] = up[up[v][k-1]][k-1]`。 这是可行的，因为 2^k 跳转可以分为两个 2^{k-1} 跳转。 
4.对于每个查询(u,v)，首先确保u是更深的节点。 如果没有，请交换它们。 这保证了提升逻辑的一致性。 
5. 向上提升较深的节点，直到两个节点处于相同深度。 这是通过检查深度差的位并应用相应的跳跃来完成的。 
6. 如果对齐后节点相等，则该节点就是 LCA，我们可以立即返回它。 这处理一个节点是另一个节点的祖先的情况。 
7. 否则，将两个节点同时从 2 的最高幂向下移动到零。 每当它们的 2^k 个祖先不同时，将两个节点提升到这些祖先。 这确保我们不会超出 LCA。 
8. 在此过程之后，两个节点都位于其最低公共祖先的下方，因此返回任一父节点都会给出正确的答案。 

正确性依赖于维持一个关键的不变量：在第 5 步之后，两个节点都处于相同的深度，在第 7 步之后，它们仍然位于 LCA 的不同子树中，但在它们之上共享相同的直接父链。 二进制提升表保证我们永远不会跳过真正的祖先，因为只有当祖先不同时才会进行跳跃。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

LOG = 20

def solve():
    n, q = map(int, input().split())
    g = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    up = [[0] * LOG for _ in range(n + 1)]
    depth = [0] * (n + 1)

    sys.setrecursionlimit(10**7)

    def dfs(v, p):
        up[v][0] = p
        for k in range(1, LOG):
            up[v][k] = up[up[v][k - 1]][k - 1]

        for to in g[v]:
            if to == p:
                continue
            depth[to] = depth[v] + 1
            dfs(to, v)

    dfs(1, 0)

    def lift(v, d):
        for k in range(LOG):
            if d & (1 << k):
                v = up[v][k]
        return v

    def lca(a, b):
        if depth[a] < depth[b]:
            a, b = b, a

        a = lift(a, depth[a] - depth[b])

        if a == b:
            return a

        for k in reversed(range(LOG)):
            if up[a][k] != up[b][k]:
                a = up[a][k]
                b = up[b][k]

        return up[a][0]

    out = []
    for _ in range(q):
        a, b = map(int, input().split())
        out.append(str(lca(a, b)))

    print("\n".join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from io import StringIO
    old_stdout = sys.stdout
    sys.stdout = StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdout = old_stdout
    return out.strip()

if __name__ == "__main__":
    solve()
```DFS 在一次遍历中构建深度和直接父节点，并同时填充每个节点的二进制提升表。 这`lift`函数根据高度差的位表示进行二进制跳转，避免了线性攀爬。 

这`lca`函数首先标准化深度，然后检查一个节点在对齐后是否成为另一个节点的祖先。 最终的向上同步提升循环是从高功率到低功率仔细编写的，以便我们在不跨越 LCA 的情况下最大化跳跃。 

一个微妙的实现细节是初始化`up[1][k]`和处理`0`作为空父母。 这可以防止提升超出根时出现索引错误。

 ## 边缘情况

 像 1-2-3-4-5 这样的倾斜链测试了最严重的结构退化。 该算法仍然在 O(n log n) 预处理中计算祖先，并且每个查询仅使用对数跳转，因此即使像 LCA(5, 1) 这样的查询也可以通过二进制步骤向上提升节点 5 来解析：5 → 3 → 1，正确收敛而无需触及每个中间节点。 

当一个节点是另一个节点的祖先时，例如链 1-2-3-4-5 中的 LCA(2, 5)，对齐步骤仅提升更深的节点。 提升后，立即触发相等性检查，返回2，而不进入最终的比较循环。
