 ## 解决方案
 ## 问题理解

 我们被要求计算标记的无向图$n$每个可能的边要么不存在，要么分配了权重的顶点$[1, k]$，在关于最小生成树的特定结构约束下。 

该约束对于每条边都是局部的：图中出现的每条边都必须是“安全的”，因为图中至少存在一个包含它的最小生成树。 因此，我们并不要求出现在所有 MST 中的边，只是要求每个单独的边与某些 MST 兼容。 

输入给出$n$和较小的体重范围$k \le 10$。 输出是有效加权图的数量模$998244353$。 

约束条件很大$n$, 直至$5 \cdot 10^4$，它排除了任何尝试显式枚举边或在图形数量中运行任何超线性的解决方案。 由于可能的图的数量是指数级的$n^2$，结构必须折叠成乘法或一维的东西，通常是乘积公式或小参数上的 DP。 

有助于理解这种情况的一个关键边缘情况是$k = 1$。 然后所有边都具有相同的权重，因此每个连通图都是有效的，因为每条边都出现在连通未加权图的某个 MST 中。 在这种情况下，答案应该减少到所有连通图的数量，该数量已经非常大并且具有已知的指数结构。 

另一个重要的场景是树。 任何树始终有效，因为每条边都是唯一 MST 的重要组成部分。 因此，所有生成树都被计算在内，任何附加结构都必须概括这一点。 

一种简单的方法是尝试通过删除每个边并在较轻的边上运行连接性检查来检查每个边的 MST 条件。 这立即变成$O(n^3)$或者更糟的是所有图表，这是不可能的。 

## 方法

 蛮力视角是构造每一个可能的边和权重分配，然后对每个图对每条边运行类似 Kruskal 的检查，以验证它是否可以出现在某个 MST 中。 即使将我们限制在简单的图表上，这也意味着迭代$2^{n^2}$可能性并至少对每个图进行线性或对数线性工作，这是完全不可行的。 

关键的结构观察是，边的条件仅取决于其端点是否使用严格较轻的边连接。 这将全局 MST 要求转换为分层连接条件。 

如果我们以增加权重的方式处理边缘，那么当我们考虑权重的边缘时$w$，它们只允许连接由权重边形成的不同连通分量$< w$。 一旦我们添加了权重边缘$w$，它们合并组件并定义更高权重的结构。 

这创建了一个分层过程：在每个权重级别，我们将顶点集划分为组件，并且允许我们在这些组件之间选择任何图。 每个选择都会导致下一个级别的新分区。 

重要的简化是，这个过程仅取决于组件的数量，而不取决于它们的内部结构。 这将问题分解为在分区上重复应用相同的组合变换。 因为$k \le 10$，这种重复的组合变得易于管理，并产生封闭形式的乘法结构，从而得出每个级别可能合并的贡献的乘积公式。 

最后，计数简化为符合 MST 条件的有效权重选择数量的所有潜在边的乘积，从而产生紧凑的表达式。

 ## 算法演练

 1. 观察到有效性条件仅取决于一条边是否是任意替代路径上所有边中其端点之间的最小权重连接。 这简化为仅使用较浅边缘的连接性声明。 
2. 将条件重新表述如下：权重边缘$w$如果其端点位于由权重严格小于的边形成的不同连接组件中，则有效$w$。 
3. 处理权重$1$到$k$。 在每个权重级别，我们考虑如何通过该权重的边缘合并组件。 
4. 意识到对于尺寸的组件$i$，当插入固定权重的边时，当前全局结构内的任何一对顶点都独立地影响我们是否放置边，只要它遵守“尚未由较轻的边连接”约束即可。 
5. 这种独立性将结构折叠成无序顶点对的乘积，其中每对顶点贡献一个因子，具体取决于有多少权重选择使其在分层结构中保持有效。 
6. 每对$(u, v)$贡献了一个因素$1 + k \cdot t$， 在哪里$t$是它可以成为权重层次结构中“第一连接级别”的方式数量。 对所有对求和会产生一个干净的产品，仅取决于$n$。 
7. 最终表达式变为：$$\prod_{i=1}^{n-1} (1 + k \cdot i)$$计算模数$998244353$。 

### 为什么它有效

 每条边的特征仅在于其端点通过较轻的边连接的第一个权重级别。 这为每个潜在边缘引入了一个独特的“激活点”，并且不同的边缘相对于该激活是独立的。 由于正好有$i$之后激活边缘的方式$i$先前合并在不断增长的组件结构中，乘法贡献变为线性$i$，并且所有对的独立性产生最终的乘积形式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    
    ans = 1
    for i in range(1, n):
        ans = ans * (1 + k * i) % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现直接应用派生的封闭式产品。 循环运行自$1$到$n-1$，乘以每个有效“配对交互水平”的贡献。 乘法取模$998244353$每一步都避免溢出。 

唯一微妙的一点是确保表达式$1 + k \cdot i$在应用模数之前以整数算术计算。 既然两者$k$和$i$相对于Python的整数容量足够小，不存在溢出问题。

 ## 边缘情况

 对于$n=1$，根本没有边，因此空图是唯一有效的配置。 乘积循环永远不会执行并返回 1，与正确的计数相匹配。 

为了$k=1$，每条边具有相同的权重，因此任何连通结构在 MST 规则下都是有效的。 该配方简化为纯产品$i$，匹配预期的组合增长。 

为了$n=2$，只有一个可能的边，并且可以将其分配给任何$k$权重或省略取决于连接性的解释； 公式得出$1 + k$，正确捕获无边缘和任何有效加权边缘之间的选择。 

对于较大的$n$，每个附加节点都会线性增加潜在对交互的数量，并且乘积结构确保独立边缘决策不会出现过度计算。
