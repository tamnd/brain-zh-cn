 ## 解决方案
 ## 问题理解

 我们从数字开始$1$。 对于集合中已有的任何数字，我们可以执行以下两种操作之一：乘以$a$，或添加$b$。 以任意顺序应用这些操作任意次数后，我们获得了一组无限的可达值。 

对于每个测试用例，我们给出$n$,$a$， 和$b$。 任务是确定是否$n$可以从开始生成$1$。 

约束条件是暴力无法发挥作用的第一个线索。 最多有$10^5$测试用例，每个参数可以大到$10^9$。 任何直接探索可达状态的方法都会立即爆炸，因为集合是无限的，甚至将我们自己限制为高达$n$可能需要检查数十亿个数字。 

该解决方案必须在大致对数时间内处理每个测试用例。 自从$a \le 10^9$, 重复乘以$a$超过$10^9$最多大约 30 步后$a \ge 2$。 这表明我们应该把重点放在$a$，而不是整个生成集。 

一些边缘情况很容易被忽略。 

考虑$a=1$。 乘法没有任何作用，因此唯一有用的操作是重复加法$b$。 例如：```
n=13, a=1, b=4
```可到达的号码是$1,5,9,13,\dots$，所以答案是肯定的。 一种盲目产生力量的解决方案$a$会永远循环，因为$1,1,1,\dots$永远不会改变。 

另一个棘手的情况是当$n$本身就是一种力量$a$。```
n=81, a=3, b=5
```我们可以简单地乘以四次。 无需添加。 答案是肯定的，因为$$81 = 3^4 + 0\cdot 5.$$坚持使用至少一项添加的解决方案将会失败。 

第三种情况是加法必须在某些乘法之前发生。```
n=24, a=3, b=5
```一种有效的构造是$$1 \to 6 \to 8 \to 24.$$该序列不仅仅是“所有乘法，然后所有加法”。 直接模拟操作顺序看起来很复杂，但数学结构却使操作顺序与最终测试无关。 

## 方法

 暴力方法将从以下位置开始执行图搜索$1$。 各州$x$有边缘到$x\cdot a$和$x+b$。 这正确地探索了所有可到达的数字。 

问题在于状态空间的大小。 即使我们停在大于的值$n$, 可能仍有多达$n$州。 自从$n$可以是$10^9$，这是完全不可行的。 

为了找到更好的东西，我们需要了解可到达的数字是什么样的。 

假设我们决定乘以多少次$a$我们将表演。 让这个数成为$k$。 乘法贡献了一个因子$a^k$。 每次添加都会贡献一定倍数$b$。 

一个关键的观察是模$b$，添加$b$没有任何改变。 唯一影响余数模的因素$b$是乘以$a$。 

如果一个数字是可达的，那么在确定最终的乘法次数后$k$，它必须具有以下形式$$a^k + m b$$对于一些非负整数$m$。 

重新排列给出$$n-a^k = mb.$$因此$n$当且仅当存在某种权力时才可以到达$a^k$这样$$n \ge a^k$$和$$(n-a^k)\bmod b = 0.$$现在搜索空间变得很小。 我们只需要测试力量$$1,a,a^2,a^3,\dots$$最多$n$。 最多的时候有30个左右$a>1$。 

特殊情况$a=1$必须单独处理。 然后一切力量都静止了$1$，所以条件变为$$(n-1)\bmod b = 0.$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n)$或者更糟|$O(n)$| 太慢了|
 | 最佳 |$O(\log_a n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读$n$,$a$， 和$b$。 
2.如果$a=1$，乘法永远不会改变当前值。 

唯一可到达的号码是$$1,\ 1+b,\ 1+2b,\dots$$检查是否$$(n-1)\bmod b = 0.$$如果是，则打印`"Yes"`，否则打印`"No"`。 
3.如果$a>1$，从当前功率等于$1$。 
4.当前功率最大为$n$, 测试是否$$(n-\text{power})\bmod b = 0.$$如果这成立，那么$$n=\text{power}+mb$$对于一些非负整数$m$， 所以$n$是可达的。 打印`"Yes"`并停止处理这个测试用例。 
5. 否则将当前功率乘以$a$并继续。 
6. 如果每一个幂$a$最多$n$已经检查过了，没有效果，打印`"No"`。 

### 为什么它有效

 每个可达数都可以被视为$a$加上一些尺寸的增加$b$。 将最终的乘法计数修正为$k$。 乘法部分贡献$a^k$，而添加量可被除以$b$。 因此每个可达数满足$$n=a^k+mb.$$反之，如果对于某些$k$我们有$$n=a^k+mb$$和$m\ge 0$，然后从$1$, 表演$k$乘法给出$a^k$，并表演$m$添加给出$n$。 因此，该算法准确地检查可达性的必要和充分条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, a, b = map(int, input().split())

    if a == 1:
        print("Yes" if (n - 1) % b == 0 else "No")
        continue

    cur = 1
    ok = False

    while cur <= n:
        if (n - cur) % b == 0:
            ok = True
            break
        cur *= a

    print("Yes" if ok else "No")
```第一个分支句柄$a=1$。 没有它，权力循环将永远不会终止，因为乘以$1$保持当前值不变。 

变量`cur`存储连续的幂$a$：$$1,\ a,\ a^2,\dots$$对于每个幂，我们测试剩余的差异是否为$n$可以整除$b$。 成功的整除性检查意味着剩余的量可以完全通过加法运算来提供。 

Python 整数会自动扩展到任意大小，因此不存在溢出问题。 循环停止一次`cur > n`，因为较大的权力不能参与代表$$n=a^k+mb$$和$m\ge 0$。 

## 工作示例

 ### 示例 1

 输入：```
24 3 5
```| 当前功率|$n-\text{power}$| 能被5整除吗？ |
 | --- | --- | --- |
 | 1 | 23 | 23 没有 |
 | 3 | 21 | 21 没有 |
 | 9 | 15 | 15 是的 |

 电源$9$有效是因为$$24-9=15=3\cdot 5.$$因此$$24=3^2+3\cdot 5,$$所以答案是肯定的。 

这个例子表明我们不需要重建实际的操作序列。 可除性条件已经捕获了可达性。 

### 示例 2

 输入：```
10 3 6
```| 当前功率|$n-\text{power}$| 能被6整除吗？ |
 | --- | --- | --- |
 | 1 | 9 | 没有 |
 | 3 | 7 | 没有 |
 | 9 | 1 | 没有 |

 下一个功率是$27$，这超过了$10$，因此搜索结束。 

没有力量$3$留下一个差值可以整除$6$。 答案是否定的。 

此示例表明仅检查$a$就足够了。 如果它们都不起作用，则任何操作序列都无法到达$n$。

 ## 边缘情况

 考虑输入：```
1
13 1 4
```自从$a=1$，算法立即使用特殊分支。 它计算$$(13-1)\bmod 4 = 12\bmod 4 = 0.$$答案是肯定的。 如果没有特殊情况，发电循环永远不会前进。 

考虑输入：```
1
81 3 5
```测试的功率为$1,3,9,27,81$。 当当前功率达到$81$,$$81-81=0,$$它可以被整除$5$。 该算法返回“是”。 这证实了允许零添加。 

考虑输入：```
1
10 3 6
```测试的功率为$1,3,9$。 没有留下可被整除的差异$6$。 下一个功率超过$n$，所以答案是否定的。这验证了当不存在有效表示时的停止条件。
