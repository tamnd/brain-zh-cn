 ## 解决方案
 ## 问题理解

 我们得到一个偶数大小的数字集合，具体来说每个测试用例有 2n 个整数。 任务是决定是否可以将这些数字分成 n 个不相交的对，使得每对由两个总和为奇数的数字组成。 

当一对数字中的一个为偶数而另一个为奇数时，和恰好为奇数。 因此，每个有效的配对必须将偶数与奇数匹配。 任何对都不能包含两个偶数或两个奇数。 

从约束来看，n 最多为 100，并且值很小，因此每个测试用例最多有 200 个数字。 这立即告诉我们，每个测试用例达到 O(n²) 的任何方法都足够快。 我们不会被迫进行复杂的优化，但我们仍然应该避免不必要的配对模拟。 

问题的关键结构不在于排列，而在于计算奇偶性。 唯一重要的是存在多少个偶数和奇数。 

这里的一个天真的错误是尝试在不检查全局可行性的情况下贪婪地实际构建对。 例如，尽管可以使用不同的配对顺序，但将第一个奇数与第一个偶数配对可能会在稍后失败。 另一个错误是认为至少有一个奇数和一个偶数就足够了。 当计数不平衡时，这种方法就会失败。 

天真的思维的一个具体失败案例是：

 输入：```
n = 2
array = [1, 3, 2, 4]
```有两个奇数和两个偶数。 这有效。 但如果我们稍微改变一下：```
n = 2
array = [1, 3, 5, 2]
```现在我们有 3 个奇数和 1 个偶数。 贪婪的尝试可能仍会配对 (1,2)，但赔率仍然不匹配，因此失败。 正确答案仅取决于计数。 

## 方法

 暴力方法会尝试枚举 2n 个元素的所有配对。 将 2n 个元素分成对的方法的数量是 (2n)！ / (2^n n!)，即使 n = 10，它的增长速度也非常快。每个分区都需要验证所有对的奇偶校验，这使得这完全不可行。 

关键的观察是每个有效对必须恰好包含一个偶数和一个奇数。 这意味着每个偶数都恰好与奇数配对，反之亦然。 因此，偶数的数量必须等于奇数的数量。 由于总元素为 2n，因此此条件相当于恰好有 n 个偶数和 n 个奇数。 

这将问题从组合配对简化为简单的频率检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力对枚举| O((2n)! ) | O((2n)! ) | O(2n) | O(2n) | 太慢了|
 | 计数奇偶校验 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们通过分析奇偶校验计数来独立解决每个测试用例。 

1. 读取 n 和 2n 个整数的列表。 
2. 计算有多少个数字是偶数，有多少个数字是奇数。 

数字的奇偶校验是通过检查 % 2 来确定的。 
3. 检查偶数元素的数量是否等于奇数元素的数量。 

这个条件是必要的，因为每个有效对恰好消耗一个偶数和一个奇数。 
4. 如果相等，则打印“Yes”。 否则，打印“否”。 

### 为什么它有效

 每个有效对必须包含一个偶数和一个奇数，因此每个配对恰好消耗每个奇偶校验类中的一个元素。 如果计数不同，则至少有一个元素将没有相反奇偶校验的有效伙伴。 相反，如果计数相等，我们总是可以将每个偶数与不同的奇数任意配对，因为除了奇偶校验之外，对值没有额外的限制。 这确立了相等奇偶计数的必要性和充分性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    
    even = 0
    odd = 0
    
    for x in arr:
        if x % 2 == 0:
            even += 1
        else:
            odd += 1
    
    print("Yes" if even == odd else "No")
```该解决方案独立地迭代每个测试用例。 关键的实现细节是我们从不尝试显式构造对。 我们只跟踪奇偶校验计数，这避免了不必要的复杂性并消除了排序问题。 

比较`even == odd`就足够了，因为总大小固定为 2n，因此相等自动意味着两者都恰好是 n。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []

    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))
        
        even = sum(1 for x in arr if x % 2 == 0)

 ## 边缘情况

 一种重要的边缘情况是所有数字都具有相同的奇偶校验。 

对于输入：```
n = 2
array = [2, 4, 6, 8]
```该算法计数偶数 = 4，奇数 = 0。由于它们不相等，因此输出“No”。 这符合推理，因为不存在形成任何有效对的奇数元素。 

另一种情况是完美平衡：```
n = 3
array = [1, 2, 3, 4, 5, 6]
```这里，偶数 = 3，奇数 = 3。算法打印“Yes”，并且存在有效的配对，例如 (1,2)、(3,4)、(5,6)。 这证实了奇偶条件的充分性。
