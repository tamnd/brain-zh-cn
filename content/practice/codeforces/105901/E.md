 ## 解决方案
 ## 问题理解

 我们得到一个无向图$n$顶点和$m$边缘。 每条边必须分配一种颜色，使用标记的颜色$1$到$m$，并且颜色可以跨边缘重复使用。 

该限制是顶点局部的：对于任何顶点$u$，如果你查看所有与$u$，那么任何固定颜色在这些入射边中最多可以出现两次。 因此，一个顶点可以接触相同的颜色一次或两次，但不能接触三次或多次。 

对于每个顶点$u$， 定义$f_u$作为其入射边缘之间出现的不同颜色的数量。 目标是将颜色分配给边，以便最小化所有顶点上这些值的总和。 

约束很大：所有测试用例的顶点和边的总数最多为$2 \cdot 10^5$。 这立即排除了任何二次方$n$或者$m$，并且还清楚地表明我们需要每个测试用例的线性或接近线性的构造。 任何重复处理每种颜色的邻接列表或模拟每个顶点大量簿记的颜色分配的解决方案都将无法生存。 

一个微妙的困难是“每个顶点每种颜色最多两条边”的约束并不像标准边缘着色或匹配。 在没有全局结构的情况下为每条边分配颜色的天真贪婪很容易陷入顶点累积太多不同颜色的情况，即使每种颜色都是局部有效的。 

例如，在以顶点为中心的星形中$u$对于 5 度，如果我们为所有边指定不同的颜色，我们得到$f_u = 5$，但约束允许配对边缘，以便单一颜色可以覆盖两个入射边缘，因此最好的可能是$f_u = 3$。 避免在中心重用的贪婪者将完全错过这种改进。 

真正的挑战是强制结构，使每个顶点尽可能“成对地重复使用颜色”，而不违反边缘的一致性。 

## 方法

 每个顶点的下界已由约束确定。 由于每种颜色在一个顶点最多可以出现两次，如果$d_u$边缘接触$u$，那么至少$\lceil d_u / 2 \rceil$需要颜色$u$。 将所有顶点相加得出目标的全局下限。 

所以问题就变成了：我们能否构造一个边缘着色，使得每个顶点都精确地达到这个界限？ 这意味着我们在每个顶点处完美地配对入射边，以便每对共享一种颜色。 

困难在于一致性。 如果我们在一个顶点任意配对边，则同一条边会参与两个端点的配对，并且这些配对必须全局一致，以便它们形成有效的颜色类。 

关键的想法是首先停止考虑颜色，而是在边缘上构建结构。 我们希望将边分组为连接的组件，其中每个组件稍后将变成单一颜色。 在每个组件内部，每个顶点的度数最多为 2，以便自动满足约束。 

这建议将边分解为路径和循环。 如果此分解的每个连接组件都是路径或循环，则为每个组件分配一种颜色是有效的：在任何顶点，每个组件最多贡献两个关联边，因此约束成立。 

现在的目标是构建这样的分解，同时确保在每个顶点，入射边以最佳方式配对。 强制执行此操作的标准方法是在每个顶点处任意本地配对边，然后将每对解释为两条边之间的连接。 在所有顶点执行此操作后，在该“边到边”结构中，每条边的度数恰好为 2，除了可能由奇数度数创建的端点之外。 这自然会在边缘处分裂成不相交的轨迹。 

每条生成的轨迹都恰好是一种颜色类别。 每个顶点属于与事件对一样多的轨迹，这与下界匹配$\lceil d_u / 2 \rceil$，因此目标被最小化。 

该结构是线性的，因为每条边在形成对和提取分量时都会被处理恒定的次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每条边贪婪 |$O(m \cdot n)$最坏的情况|$O(m)$| 太慢/结构错误|
 | 配对+分解成路径|$O(n + m)$|$O(n + m)$| 已接受 |

 ## 算法演练

 我们构建一个结构，其中使用顶点处的局部配对将边逐渐连接成链，然后将这些链提取为颜色类。 

1. 存储图的邻接列表，同时还要跟踪哪些边仍未使用。 

这是必要的，因为我们在配对边缘时会逐渐“消耗”边缘。 
2. 对于每个顶点$u$，获取其关联边列表并将它们任意配对：第一个与第二个，第三个与第四个，依此类推。 

这种配对是唯一强制执行最优性的地方。 每个顶点都会尝​​试将其边分组为尽可能多的对，以便每对可以稍后共享一种颜色。 
3. 对于每对边$(e_1, e_2)$在一个顶点处形成，在次级图中连接这两条边，其中节点是原始边。 

此步骤将问题从基于顶点的约束转换为边缘图，其中每个边缘节点的度数最多为 2。 配对可确保每条边最多参与每个端点一个连接。 
4. 处理完所有顶点后，边图分解为不相交的路径并在边上循环。 

每个连接的组件对应于一系列边，其中连续的边共享顶点对。 
5.遍历每个组件并为其分配唯一的颜色ID。 

由于组件是独立的，因此任何标签都是有效的。 该约束已经由结构保证。 
6. 输出分配给每个原始边缘的颜色。 

### 为什么它有效

 每个顶点$u$贡献其入射边的配对，因此每一对都会减少通过的不同“边组”的数量$u$。 每组恰好对应于边分解中的一个连通分量，即一种颜色。 

度数的顶点$d_u$可以准确地形成$\lfloor d_u / 2 \rfloor$成对，最多留下一条不成对的边。 每对都成为路径的一部分，剩余的边缘形成额外的端点。 因此，接触路径的数量$u$正是$\lceil d_u / 2 \rceil$，这是最小可能值$f_u$。 

由于每个颜色类都是边上的路径或循环，因此任何顶点都不能具有两个以上相同颜色的关联边，从而自动满足约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    
    edges = []
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        g[u].append((v, i))
        g[v].append((u, i))
    
    used_edge = [False] * m
    adj_edge = [[] for _ in range(m)]
    
    # pair edges at each vertex
    for u in range(n):
        lst = []
        for v, eid in g[u]:
            lst.append(eid)
        
        for i in range(0, len(lst) - 1, 2):
            e1 = lst[i]
            e2 = lst[i + 1]
            adj_edge[e1].append(e2)
            adj_edge[e2].append(e1)
    
    visited_edge = [False] * m
    color = [0] * m
    cur_color = 0
    
    for i in range(m):
        if not visited_edge[i]:
            cur_color += 1
            stack = [i]
            visited_edge[i] = True
            color[i] = cur_color
            
            while stack:
                e = stack.pop()
                for ne in adj_edge[e]:
                    if not visited_edge[ne]:
                        visited_edge[ne] = True
                        color[ne] = cur_color
                        stack.append(ne)
    
    print(*color)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```第一阶段构建一个隐式图，其节点是边。 每个顶点都在其入射边上提供局部完美匹配，这是通过简单地按顺序配对来实现的。 第二阶段在此边缘图上运行 DFS 来识别连接的组件，并且每个组件变成一种颜色。 

一个关键的实现细节是我们永远不需要显式模拟“路径”。 一旦建立了边之间的邻接，边上的标准图遍历就足够了。 另一个微妙之处是每条边最多添加到两个配对连接，因此辅助图的大小保持线性。 

## 工作示例

 ### 示例 1

 考虑一个三角形：边$(1,2), (2,3), (3,1)$。 

在每个顶点处，有两个入射边，因此每个顶点将它们直接配对。 这会在所有三个边缘上创建一个循环。 

| 步骤| 行动| 边缘连接 |
 | --- | --- | --- |
 | 配对 1 | (1,2)-(1,3) | (1,2)-(1,3) | e1 连接到 e2 |
 | 2 点配对 | (1,2)-(2,3) | e1 连接到 e3 |
 | 3 点配对 | (2,3)-(1,3) | (2,3)-(1,3) | e3 连接到 e2 |

 所有边都连接成一个组件，因此所有边都具有相同的颜色。 

这表明循环自然地分解为单一颜色类别。 

### 示例 2

 考虑一条路径：$1 - 2 - 3 - 4$。 

边缘是$e1=(1,2), e2=(2,3), e3=(3,4)$。 

| 顶点| 配对 |
 | --- | --- |
 | 1 | 无 |
 | 2 | （e1，e2）|
 | 3 | （e2，e3）|
 | 4 | 无 |

 这会在所有边缘上产生一条链，因此再次使用一种颜色。 

重要的观察是，即使边在不同的顶点局部配对两次，一致性自然会形成一条轨迹。

 ## 边缘情况

 关键的边缘情况是顶点具有奇数度数。 在这种情况下，一个入射边在该顶点处不成对。 该边缘仍然参与其另一个端点的配对，因此在全局范围内它成为路径的端点。 这确保了生成的组件仍然是有效路径，而不是破坏一致性。 

另一个边缘情况是断开连接的图。 由于配对纯粹是在每个顶点本地完成的，因此组件永远不会跨连接的组件进行交互，因此每个组件独立形成有效的轨迹并接收自己的颜色，而无需任何特殊处理。 

最后一个微妙的情况是多个顶点创建看起来矛盾的重叠配对。 该构造避免了冲突，因为边永远不会在同一顶点处配对两次，并且边图中的每个邻接都是对称的。 这保证了边缘上的 DFS 始终看到一致的无向结构，而不是有向冲突。
