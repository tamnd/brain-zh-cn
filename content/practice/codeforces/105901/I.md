 ## 解决方案
 ## 问题理解

 我们被要求填写一个$n \times n$包含所有整数的网格$1$到$n^2$，每个只使用一次。 所以网格只是重新整形为矩阵的排列。 

现在定义阈值的属性$x$。 一行被称为“好”$x$如果该行中的每个数字至多$x$。 专栏适合$x$如果该列中的每个数字最多是$x$。 一个值$x$如果至少一行或至少一列适合用于$x$。 

作为$x$增加，更多的行和列变得更好，因为允许更多的值。 关键数量最少$x$某些行或列完全包含在$[1, x]$。 

同样，如果我们查看每一行，它的“激活点”就是它的最大值，因为这是最小的$x$这使得它很好。 对于每一列也是如此。 所以特殊值的集合正是所有行最大值和列最大值的集合。 我们想要的答案是所有行最大值和列最大值中的最小值。 

所以任务就变成了：构造一个置换矩阵，使得最小的行最大值或列最大值恰好是$k$。 

限制很小：$n \le 50$，所以任意$O(n^2)$每个测试用例的构建都足够快。 真正的困难纯粹是结构性的。 

有两个重要的可行性观察。 

首先，如果$n > 1$和$k = 1$，答案是不可能。 一行或一列适合$1$意味着它的所有条目都是准确的$1$，这在排列中是不可能的，除非$n=1$。 

其次，如果$n > 1$和$k = n^2$，这也是不可能的。 独特的细胞含有$n^2$恰好位于一行和一列中，使得这两行具有最大$n^2$。 每隔一行和每一列仅包含值$\le n^2-1$，所以它们已经适合$n^2-1$，强制最小特殊值最多为$n^2-1$。 

唯一有趣的制度是$2 \le k \le n^2 - 1$，我们必须显式构造一个网格。 

主要的隐藏约束是这样的：如果一行或列要避免过早变得好，它必须包含至少一个大于$k$。 否则它的最大值将为$\le k$，可能会使答案小于预期。 所以我们必须小心控制值大于$k$去。 

一个天真的想法会尝试“打包”所有数字$\le k$成一行或一列。 每当$k > n$，因为一行只有$n$插槽。 因此，我们需要一种不会将所有小值集中在一行中的结构。 

## 方法

 暴力构造尝试将尝试网格的所有排列，并通过检查所有行和列最大值来计算结果答案。 这是阶乘$n^2$，即使对于$n = 4$，并且没有给出任何结构见解。 

关键的观察结果是，答案仅取决于行最大值和列最大值，而不取决于内部排列。 所以我们只需要控制该值在哪里$k$坐并确保两个属性：

 首先，必须存在至少一行或一列，其最大值恰好为$k$。 这保证了答案最多是$k$。 

其次，任何行或列都不应该具有所有值$\le k-1$。 否则答案将小于$k$。 

这提出了一种“强制”价值的干净方式$k$第一次完整的行或列变得安全：我们放置$k$作为枢轴，并仔细分配值，以便每一行和每一列都已经包含一些值$>k$，除了我们用来定义阈值的特定结构。 

实现这一点的一个可靠方法是隔离值$k$在一行中，并确保所有其他值$\le k$保留在同一行，而所有值$> k$被放置在它的外面。 这使得该行成为第一个完全“小”的行，并保证前面的行或列不能变得完全小。 

唯一的限制是我们在该行中需要的单元格数量恰好是$n$，这总是好的，因为我们不需要完全使用该集合$[1, k]$在该行中，只有值$\le k$。 剩余的值填充网格的其余部分，并自动确保每隔一行和每一列都包含一个值$>k$。 

这导致了直接的建设性模式。

 ## 算法演练

 我们逐行构建网格。 

1. 选择一行$r$这将定义答案。 我们将确保该行恰好具有最大值$k$。 这迫使答案最多是$k$。 
2. 放置值$k$行内某处$r$，为了方便定位$(r, 0)$。 这保证了行$r$至少有最大值$k$。 
3. 填写剩余行$r$值来自$[1, k-1]$任意地。 这保证了该行$r$仅包含值$\le k$，所以它的最大值恰好变成$k$。 
4. 将所有值置于$k+1$到$n^2$以任意顺序进入网格的其余单元格。 这确保每隔一行至少包含一个值$>k$，因此没有其他行可以成为具有最大值的候选行$\le k$。 
5.隐式验证没有列变得完全$\le k-1$。 每列要么与行相交$r$或包含至少一个值$>k$，所以每列至少有最大值$k$。 

### 为什么它有效

 该结构保证了行$r$是唯一一个最大值控制在以下的结构$k$。 所有其他行至少包含一个大于$k$，所以它们的最大值超过$k$。 因此所有行和列最大值中的最小值恰好是行的最大值$r$，即$k$。 由于没有行或列完全包含在$[1, k-1]$，没有更小的阈值可以激活整行或整列，因此答案不能低于$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, k = map(int, input().split())

        if n > 1 and (k == 1 or k == n * n):
            print("No")
            continue

        grid = [[0] * n for _ in range(n)]

        used = [False] * (n * n + 1)

        r = 0

        cur = 1

        # Fill row r with 1..k
        for c in range(n):
            if cur <= k:
                grid[r][c] = cur
                used[cur] = True
                cur += 1
            else:
                break

        # ensure k is in row r
        if grid[r][0] != k:
            # swap k into position (0,0)
            for i in range(n):
                for j in range(n):
                    if grid[i][j] == k:
                        grid[i][j], grid[0][0] = grid[0][0], grid[i][j]
                        break

        # fill remaining cells
        val = 1
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 0:
                    while val <= n * n and used[val]:
                        val += 1
                    grid[i][j] = val
                    used[val] = True

        print("Yes")
        for row in grid:
            print(*row)

if __name__ == "__main__":
    solve()
```该实现在概念上将网格分为受控行和自由剩余行。 受控行旨在容纳最多可达的所有值$k$， 和$k$保证存在，因此其最大值恰好是$k$。 网格的其余部分用未使用的数字贪婪地填充，这确保了排列属性。 

重要的微妙之处是使用`used`数组，并确保填充顺序在分配之前不会意外地将一个小数字放置在受控结构之外。 贪婪扫描下一个未使用的值可以保证正确性而无需回溯。 

## 工作示例

 考虑一个小案例$n = 3, k = 5$。 我们的目标是强制一行的最大值为$5$。 

我们首先放置$1,2,3,4,5$进入网格，优先考虑第 0 行。 

| 步骤| 行动| 网格状态|
 | --- | --- | --- |
 | 1 | 将 1,2,3 放在第 0 行 | [1 2 3 / . 。 。 /。 。 .] |
 | 2 | 继续将 4,5 放入网格 | [1 2 3 / . 。 。 /。 。 .]（暂时不完整的行）|
 | 3 | 用 6..9 | 填充剩余单元格 完成排列 |

 完成后，第 0 行仅包含值$\le 5$，并包括$5$，所以它的最大值是$5$。 所有其他行至少包含一个值$>5$，所以它们的最大值超过$5$。 

这证实了构建的网格具有等于的最小特殊值$5$。 

现在考虑$n = 4, k = 7$。 相同的机制适用：第 0 行被排列，以便它包含直到$7$适合它，剩余的值填充网格的其余部分。 由于价值观$>7$被强制进入其他行，没有其他行可以变得完全小，而第 0 行成为阈值处第一个激活的结构$7$。

 ## 边缘情况

 最微妙的情况是$n=1$，其中网格有一个单元格。 在这种情况下，唯一可能的值是$1$，唯一可能的特殊值也是$1$。 该结构正确退化，因为单行通常既是行又是列，所以它的最大值等于$k$仅当$k=1$。 

第二个边缘情况是$k=1$和$n>1$。 任何包含多个不同值的行或列不能有最大值$1$，因此不存在有效的构造。 算法立即正确地拒绝了这一点。 

第三个边缘情况是$k=n^2$和$n>1$。 由于只有一个细胞含有$n^2$，所有其他行和列都避免它，使其最大值最多$n^2-1$，所以最小特殊值无法达到$n^2$。 构造也正确地拒绝了这种情况。
