 ## 解决方案
 ## 问题理解

 我们被要求确定一个整数数组是否是 3SUM 封闭的，这意味着对于数组中每个不同元素的三元组，这三个元素的总和本身存在于数组中的某个位置。 输入由多个测试用例组成，每个测试用例指定数组的长度及其元素。 如果数组是 3SUM 闭合的，则输出为“YES”，否则输出为“NO”。 

约束允许最多$2 \cdot 10^5$所有测试用例中的总数组元素，这意味着任何比粗略更差的算法$O(n^2)$每个测试用例可能太慢。 直接考虑所有三元组的蛮力方法需要$O(n^3)$操作，这对于大型企业来说是不可行的$n$。 

要考虑的边缘情况包括具有所有相同元素的数组、仅具有零的数组以及同时包含大正数和负数的数组。 例如，$[0,0,0,0]$是普通的 3SUM 闭集，因为所有三元组的总和为 0，这在数组中。 具有三个以上不同非零元素的数组，例如$[-1, 2, -3, 4]$，可能会导致该属性失败，因为某些三重和落在数组之外。 必须仔细处理具有许多重复项或零的数组，因为计算不同值对于正确性至关重要。 

## 方法

 最简单的方法是迭代每个可能的索引三元组并检查它们的总和是否存在于数组中。 这是正确的，因为它直接实现了 3SUM-closure 的定义，但复杂度是$O(n^3)$，这是不可接受的，当$n$很大。 例如，$n=2 \cdot 10^5$大约需要$8 \cdot 10^{15}$运营。 

关键的观察结果是，具有超过三个不同非零元素的数组不能是 3SUM 闭合的。 每个不同的非零数字的三元组都会产生一个不一定存在于数组中的和。 因此，我们可以将数组减少到最多三个正数、三个负数和任意数量的零。 如果有超过三个正数或超过三个负数，则数组不能是 3SUM 闭的。 

一旦数组减少，问题就变得容易处理，因为不同的非零元素的数量最多为六个。 然后我们可以枚举所有元素三元组（考虑到零）并检查每个和是否存在于数组中。 由于考虑的元素总数最多为 7 个，因此该检查在以下情况下是可行的：$O(1)$每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了|
 | 优化还原+三重检查 | 过滤后每个测试用例为 O(1)，预处理为 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组$a$并将其转换为集合以进行快速成员资格查询。 
2. 将元素分为正数、负数和零。 仅保留最多三个最大的正值和最多三个最小的负值。 包括全零，因为它们不会增加不同和的数量。 这会将数组减少到最多七个元素。 
3. 从简化数组中生成不同元素的所有三元组。 对于每个三元组，计算其总和。 
4. 检查每个三元组的和是否存在于原始数组元素集中。 如果缺少任何总和，则输出“NO”。 
5. 如果所有三重和都存在，则输出“YES”。 

为什么有效：任何具有超过三个正数或三个负数的数组都会自动无效，因为某些三重和无法在数组中表示。 通过限制关键元素，我们保证检查所有三重和足以确认 3SUM 闭包。 这依赖于任何排除的元素都会产生已被数组外部的剩余三元组或总和覆盖的总和的不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from itertools import combinations

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a_set = set(a)
        
        pos = sorted([x for x in a if x > 0])
        neg = sorted([x for x in a if x < 0])
        zeros = [x for x in a if x == 0]
        
        if len(pos) > 3 or len(neg) > 3:
            print("NO")
            continue
        
        reduced = neg[:3] + zeros + pos[-3:]
        ok = True
        for triple in combinations(reduced, 3):
            if sum(triple) not in a_set:
                ok = False
                break
        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```该代码首先对数组进行分区，并将其缩减为关键元素。 使用集合允许$O(1)$会员支票金额。 缩减数组的组合确保了三元组的总数很小，因此枚举它们是有效的。

 ## 边缘情况

 全零的数组`[0,0,0,0]`产生 0 的三重和，全部存在于数组中。 平衡阵列`[-2,-1,0,0,0,1,2]`之所以有效，是因为在减少到最多三个负数、三个正数和零之后，所有三重和都存在。 超过三个正数或三个负数的数组，例如`[-5,-4,-3,-2,0,2,3,4]`，失败，因为一些三重和落在数组之外。 该算法通过限制约简集并显式检查所有三重和来正确识别这些情况。
