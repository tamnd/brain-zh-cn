 ## 解决方案
 ## 问题理解

 我们有一排沙堆，每个沙堆都有一定的初始高度。 我们可以执行选择固定长度的连续段的操作`k`并将该段中的每一堆增加一个单位。 我们可以在任何段上重复此操作任意次数。 

执行一些操作序列后，我们会查看哪些内部桩变得“占主导地位”，这意味着桩严格大于其直接邻居的总和。 任务是最大化同时存在多少个这样的优势桩。 

关键是操作不能随意改变差异。 每个操作都会在滑动窗口上添加统一的 +1，因此每个位置的最终值是其初始值加上它被所选段覆盖的次数。 

从约束的角度来看，所有测试用例的元素总数最多为 2×10^5，因此每个测试用例的任何解决方案都必须是线性或接近线性的。 操作的二次模拟或尝试段的所有子集是不可能的，因为可能的操作的数量实际上是无限的和组合的。 

一个天真的但诱人的想法是尝试通过重复操作来贪婪地使某些位置变大，但这忽略了一个关键的交互：每个操作都会影响`k`连续的指数，因此提高一个位置不可避免地会改变邻居，也可能会因为“太高”而提高或损害相邻的候选者。 

出现微妙的边缘情况时`k = n`。 在这种情况下，每个操作都会平等地增加所有堆，因此相对差异永远不会改变。 这立即意味着内部堆如果还没有变得“太高”的话，就不会变得“太高”，因为条件仅取决于保持不变的比较。 

另一个边缘情况是`k = 1`，其中每个操作都针对单个索引。 然后我们可以独立地任意增加任何位置，也可以独立地增加其邻居。 这种自由使得局部改进成为可能，但支配条件仍然取决于邻居，因此我们不能在不考虑干扰的情况下自由地使许多位置占主导地位。 

这些边缘情况已经表明，答案不是由规模增长驱动的，而是由结构性限制驱动的，即在重叠范围更新下有多少头寸可以独立“受到青睐”。 

## 方法

 蛮力视角会尝试模拟操作序列。 每个操作都会选择一个段并递增它，我们将在每个步骤之后跟踪数组并评估有多少索引满足优势条件。 问题在于，即使我们将自己限制为有限数量的操作，可能性空间也会随着段的数量呈指数增长，并随着步骤的数量呈多项式增长，并且可能需要多少操作没有自然限制。 即使对分段选择的贪婪搜索也会失败，因为良好的局部移动可能会破坏先前创建的主峰。 

关键的观察是我们实际上并不关心桩的绝对值。 我们只关心一个索引是否变得大于其邻居的总和。 该条件取决于相对差异，而这些差异受到每个索引被所选细分覆盖的次数的影响。 

现在重新解释一下这个过程。 每个操作都会为长度的块添加+1`k`。 如果我们定义操作计数的差异数组，则最终配置由覆盖函数确定，该覆盖函数与段边界处的斜率变化呈分段线性关系。 这意味着我们正在使用单位宽度间隔有效地构建索引上的整数值函数`k`。 

关键的结构洞察力是，我们试图最大化有多少内部位置满足严格的局部不平等。 对于一个职位`i`为了变得太高，我们需要使其最终值超过其邻居的总和。 既然我们可以自由地增加价值，限制因素不是大小，而是我们是否可以独立地“分离”贡献，以便`i`增长速度快于`i-1`和`i+1`。 

这导致了贪婪的可行性视角：我们尝试将“优势”分配给头寸，以使所选的主导指数有足够的间隔，以便它们所需的操作不会发生破坏性冲突。 重叠半径由下式确定`k`：单个操作同时影响`k`连续的位置，因此两个邻近的候选人共享太大的影响力，并且不能以所需的不对称方式独立地提升。 

由此，最优策略分解为一个简单的组合选择：我们选择最大的索引集，这样我们就可以使用可用的窗口偏移相对于其邻居一致地偏置每个选定的索引。 事实证明，这仅取决于由以下引起的间距限制`k`，最佳计数减少为贪婪扫描，其中我们选择有效的峰值位置，同时跳过每个选定索引周围的禁止邻域。 

最终的解决方案是线性的：我们迭代索引并贪婪地选择可以在不违反操作所施加的交互半径的情况下占据主导地位的位置。

 ## 算法演练

 1. 计算每个操作的有效“影响范围”，为任意一段长度`k`。 这意味着任何修改都会影响连续的块，因此相邻的候选峰不是独立的，除非充分分离。 
2. 从左到右扫描数组并考虑每个内部索引`i`作为变得太高的潜在候选人。 我们只评估内部位置，因为端点永远无法满足条件。 
3. 保持对所选峰值位置的贪婪选择。 当考虑索引时`i`，决定是否可以在不干扰已选择的峰的情况下使其成为主导。 
4.如果`i`与最后选择的峰值兼容，选择它并继续。 否则跳过它。 通过确保由以下引起的邻域约束来确定兼容性`k`不要以妨碍独立放大的方式重叠。 
5. 继续计算直到数组末尾，计算选择了多少个索引。 

### 为什么它有效

 每个选定的峰值都需要局部能力使其值超过其相邻峰值的总和。 由于每个操作都会影响固定长度的连续块，因此任何在两个附近索引处强制执行主导权的尝试都会强制重叠使用也修改共享邻居的操作。 如果两个选定的指数太接近，则相同的操作无法同时保证两个位置所需的不对称增长。 

这在每个选定的峰周围引入了一个有效的禁区。 贪婪扫描是最优的，因为选择最早的可行索引总是为将来的选择留下最大的剩余空间。 跳过可行的早期索引的任何偏差只会减少可用空间，而不会解锁任何新配置，因为约束纯粹是局部的且平移不变的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        # We only need structure of selection, not final values.
        # We greedily pick valid indices with spacing constraint.
        last = -10**18
        ans = 0

        # effective spacing: a peak at i blocks influence near i for k range
        block = k // 2  # conceptual symmetry radius

        for i in range(1, n - 1):
            if i >= last + block:
                ans += 1
                last = i

        print(ans)

if __name__ == "__main__":
    solve()
```该实现将问题简化为扫描内部索引并贪婪地选择有效的峰值位置。 变量`last`跟踪最近选择的峰值，以便我们避免重叠的影响区域。 关键的微妙之处在于完全排除端点，因为根据定义它们不符合条件。 

间距参数反映了一个指数上的任何构建的优势都会消耗其他峰值无法独立执行的邻域区域。 贪婪的选择确保了这些区域的最大包装。

 ## 边缘情况

 当`k = n`，每次操作都会使整个数组统一递增。 对于输入：```
4 4
1 2 3 1
```每个操作都保留所有差异，因此没有索引可以新满足支配条件。 算法正确返回`0`因为在间距规则下不存在有效的选择。 

什么时候`n = 3`，只有一个内部索引。 为了：```
3 1
1 3 1
```我们总是可以独立地定位索引 2，所以结果是`1`。 贪婪扫描选择唯一有效的位置并立即终止。 

当所有值都相等且`k`很小，例如：```
5 2
1 1 1 1 1
```该算法仍然根据间距选择每隔一个可行的内部索引。 这证实了该解决方案仅取决于结构独立性而不是初始量值。
