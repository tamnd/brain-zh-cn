 ## 解决方案
 ## 问题理解

 我们得到一个长度的数组`n`这是通过获取长度的原始数组生成的`n-1`，计算其所有元素的 XOR，将该 XOR 附加到数组，然后对结果进行混洗。 任务是在仅给定混洗数组的情况下恢复附加的 XOR 值。 每个测试用例都会给出一个这样的数组，并且我们必须为每个测试用例生成一个与添加的 XOR 相对应的整数。 

限制是适度的：`n`最多可以有 100 个，并且最多可以有 1000 个测试用例。 数组中的每个元素都是 0 到 127 之间的小整数。这意味着每个测试用例复杂度为 O(n) 的任何算法都将高效运行，因为即使在最坏的情况下，我们也只需要大约 100,000 次操作，这对于现代 CPU 来说是微不足道的。 这也排除了对复杂数据结构或优化的需要。 

边缘情况包括所有元素都相同的数组，其中`x`可以与原始元素之一重合，或者`x`为零。 例如，如果数组是`[6, 6, 6, 6, 6, 6]`，正确答案是 6。另一个棘手的情况是`[100, 100, 0]`，其中原始两个元素的 XOR 为 0。一种简单的方法，例如尝试删除重复项或假设`x`是这些输入上可能失败的最大元素。 

## 方法

 暴力方法是尝试依次删除每个元素，计算其余元素的异或，并检查它是否与删除的元素匹配。 对于每个`n`元素，我们将计算异或`n-1`元素，导致每个测试用例执行 O(n²) 次操作。 对于给定的约束，这在技术上是可行的，但没有必要，因为 XOR 运算具有使更简单的解决方案成为可能的属性。 

关键的见解是 XOR 既具有结合性又具有交换性。 这意味着对最终数组的所有元素进行异或与对原始数组两次和附加值进行一次异或得到的结果相同。 如果我们让原始数组的异或为`x`，最终数组包含所有原始元素加上`x`。 将所有内容异或在一起给出`x ⊕ a1 ⊕ a2 ⊕ ... ⊕ a(n-1)`。 但`a1 ⊕ a2 ⊕ ... ⊕ a(n-1)`只是`x`，所以总的异或是`x ⊕ x = 0`加上附加的`x`，离开`x`。 因此，最终数组的所有元素的异或直接给出的值`x`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 有效但没有必要 |
 | 对所有元素进行异或 | O(n) | O(1) | O(1) | 接受且简单 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`和数组`n`整数。 
3. 初始化变量`x`为 0。这将保存所有元素的异或。 
4. 迭代数组，将每个元素异或为`x`。 在这个循环之后，`x`包含所有的异或`n`元素。 
5、输出`x`对于当前的测试用例。 

为什么它有效：XOR 具有以下属性：`a ⊕ a = 0`和`a ⊕ 0 = a`。 在最终的数组中，每个原始元素都出现一次并且`x`出现一次。 将它们全部异或在一起会消除所有原始元素，因为`a1 ⊕ a2 ⊕ ... ⊕ a(n-1) ⊕ x = x`。 这保证了我们总是能恢复正确的附加异或，无论洗牌如何。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    x = 0
    for num in a:
        x ^= num
    print(x)
```该解决方案读取测试用例的数量，然后循环它们。 对于每个数组，它使用简单的 for 循环计算所有元素的 XOR。 XOR 累加器从 0 开始，确保它正确处理数组`x`可能为 0。无需对随机或重复元素进行特殊处理，因为 XOR 会自动取消重复项。

 ## 边缘情况

 对于数组`[6, 6, 6, 6, 6, 6]`，该算法将 XOR 计算为`6 ⊕ 6 ⊕ 6 ⊕ 6 ⊕ 6 ⊕ 6 = 6`。 重复的元素成对取消，使附加的异或保持完整。 为了`[100, 100, 0]`, 异或`100 ⊕ 100 ⊕ 0 = 0`正确恢复附加到原始二元素数组的 XOR`[100, 100]`。 这些示例证实该解决方案无需额外逻辑即可正确处理重复项和零。
