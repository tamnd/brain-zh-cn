 ## 解决方案

 ## 问题理解

 我们被要求构建一个编号$N \times N$使用所有整数的网格$1$到$N^2$，每个正好一次。 这种编号定义了棋子如何移动，但关键思想是移动不是任意的：在每一步，棋子都会在一次国际象棋移动中查看所有可到达的未访问单元，并始终选择分配编号最小的单元。 如果不存在这样的移动，它会传送到编号最小的未访问单元并支付 1 的成本。 

我们从标记为 1 的单元格开始模拟此过程两次，一次针对车，一次针对女王。目标是设计网格，使车支付的传送成本严格低于女王。 

移动规则有效地将棋盘变成动态显示的图形遍历，其中边缘取决于棋子类型。 车只能看到行和列的可见性，而皇后还可以看到对角线。 编号强加了强制遍历顺序，类似于隐式可见性图上的贪婪遍历。 

约束条件允许$N$最多 500 个，因此施工必须$O(N^2)$。 任何在许多候选板上模拟这两个部分的尝试都是不可能的，因为每个模拟都已经是$O(N^2)$，我们需要一个建设性的论证而不是检查。 

当出现一个微妙的问题时$N = 1$。 只有一个细胞，没有运动，也没有隐形传送，因此两者的成本都是零，严格的不平等是不可能的。 这是唯一立即不可能的情况。 

另一个隐藏的困难是，两个棋子都是从同一个单元开始的，早期数字的排序会严重影响它们是否“卡在”某个区域并被迫传送。 如果电路板结构不佳，则两个部件在大部分流程中都会表现相同，从而无法区分它们的成本。 

## 方法

 一种直接的方法是尝试许多随机或结构化网格并模拟车和皇后过程。 每次模拟都需要跟踪可到达的未访问单元并重复选择最小标签，这已经花费了$O(N^2 \log N)$具有优先级结构。 尝试多种构造是不可行的$N = 500$，因为即使是一次完整的模拟也已经处于临界状态。 

关键的观察结果是，车和皇后之间的差异完全来自连通性：皇后具有严格更多的边，因为对角线连接了更多的单元格。 如果我们能够强制出现一种情况，即车按照标签顺序保持单个连接的进程，而皇后经常被分成断开连接的可达组件，那么皇后将被迫更频繁地传送。 

这表明构建一个网格，其中车连接性与增加的标签全局一致，但由于对角线约束干扰贪婪顺序，皇后连接性很早就被“破坏”。 实现这一目标的一个简单方法是按行以蛇状顺序对网格进行线性化，确保车的运动几乎可以连续地跟随它，而皇后的对角线跳跃则被标签放置阻止，从而防止对角线邻接发挥作用。 

有效的经典结构是交替方向逐行填充网格。 这确保了连续的数字总是与车相邻。 车始终可以继续而无需传送，因为每个下一个数字都位于同一行或相邻行，并且车可以直接看到。 然而，皇后获得了对角捷径，导致它跳过预期的链，打破了单调的邻接结构，并在贪婪规则耗尽可访问的单元格后强制进行额外的传送。 

出现不对称的原因是车的运动与结构的邻接路径对齐，而皇后的运动引入了替代边缘，破坏了贪婪的可访问性排序。

 ## 算法演练

 我们构建网格，使数字沿行增加，每行交替方向。 

1.从空开始$N \times N$网格和一个初始化为 1 的计数器。该计数器代表下一个要分配的标签。 
2. 从上到下迭代行。 对于每一行，根据行索引的奇偶性决定遍历方向。 
3. 如果行索引是偶数，则从左到右填充连续的数字。 如果是奇数，则从右向左填写。 这会在整个网格上创建一条连续的蛇形路径。 
4. 将当前计数器值分配给每个访问过的单元格，并在每次分配后递增该值。 这确保了从 1 到$N^2$只使用一次。 

交替方向的原因是，它保证连续数字在车移动时始终边缘相邻，无论是在一行内水平还是在一行末尾和下一行开头之间垂直。 

### 为什么它有效

 贪心规则引起的车遍历遵循标签的自然单调增加。 由于车可以一次移动到达每一对连续的数字，因此车在离开起始区域后永远不需要传送。 

严格来说，皇后的步数更多，因此每一步的可达集都更大。 然而，在贪婪选择下，这种优势变成了劣势：皇后可能会沿对角线跳入与蛇排序不对齐的区域，这会破坏干净的顺序进程，并导致局部可到达的未访问单元的早期耗尽。 与车相比，这会导致额外的传送事件。 

实现严格的不平等是因为皇后的额外运动选项引入了对强制线性链的干扰，而车则干净利落地跟随它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
if n == 1:
    print(-1)
    sys.exit()

grid = [[0] * n for _ in range(n)]
num = 1

for i in range(n):
    if i % 2 == 0:
        for j in range(n):
            grid[i][j] = num
            num += 1
    else:
        for j in range(n - 1, -1, -1):
            grid[i][j] = num
            num += 1

for row in grid:
    print(*row)
```该解决方案首先处理简单的不可能的情况$N = 1$，任何建设都不会造成成本差异。 

然后使用简单的蛇形图案填充网格。 交替方向至关重要，因为它保证了连续数字跨行边界的相邻性。 如果不反转每隔一行，行之间的过渡将产生较大的跳跃，从而破坏车的连续性。 

最后，逐行打印网格。

 ## 边缘情况

 对于$N = 1$，算法立即输出-1。 这与不存在运动并且两个部分的成本相同为零的事实相匹配，因此严格的不平等不能成立。 

为了$N = 2$，蛇形填充在车相邻单元上产生完整的哈密顿路径。 车可以在不传送的情况下穿越，并且结构仍然有效，因为每个数字仍然是唯一分配的。 

对于较大的$N$，交替行反转可确保每对连续的数字在水平或垂直方向上保持与车相邻。 这保证了车永远不会打破贪婪链，因此该结构始终如一地根据需要将车和皇后的行为分开。
