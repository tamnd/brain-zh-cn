 ## 解决方案
 ## 问题理解

 我们得到一组数字和一个模数$m$。 任务是将所有数字重新排列成尽可能少的序列，其中每个序列必须满足局部兼容性规则：每当两个连续元素出现在同一序列中时，它们的总和必须能被$m$。 

因为我们可以在每个序列内任意排列元素，所以唯一真正的约束是元素如何根据其余数模数“适合”彼此相邻$m$。 如果两个数有余数$r$和$s$，那么它们可以恰好在某个顺序上相邻$r + s \equiv 0 \pmod m$。 这意味着每个余数$r$仅与其补集兼容$m - r$，而余数$0$只与自身兼容，并且当$m$是偶数，余数$m/2$也是自兼容的。 

目标是将所有元素拆分为最少数量的此类有效序列。 

约束条件$n \le 10^5$所有测试用例迫使我们远离任何显式尝试所有分区或构建序列的策略。 任何隐式考虑所有配对或尝试回溯的解决方案都会失败，因为搜索空间呈指数增长$n$。 问题的结构表明，只有余数的频率才重要，而不是元素的实际排列。 

朴素推理的一个微妙的失败案例是假设贪婪地配对互补余数总是最小化序列。 例如，如果我们尝试始终匹配尽可能多的$r$和$m-r$尽可能地然后在不考虑全局结构的情况下开始剩余的新序列，我们可能会高估所需的序列数量或构建无效的结构。 另一个常见的错误是独立处理每对余数，而不处理余数的特殊行为$0$和$m/2$。 

## 方法

 蛮力的想法会尝试实际地逐个构建序列。 我们可以重复选择一个未使用的元素，通过贪婪地选择任何兼容的未使用元素来扩展序列，并继续直到无法扩展，然后开始一个新序列。 这在原则上是正确的，因为我们明确遵守邻接规则。 然而，每个扩展都需要扫描兼容的未使用元素，在最坏的情况下，我们可能会多次重新访问元素。 这导致了二次行为，远远超出了当$n$达到$10^5$。 

关键的观察是邻接仅取决于余数，并且每个余数$r$仅与单个合作伙伴交互$m-r$。 这将问题简化为每个互补残基对的独立计数问题。 

对于固定对$(r, m-r)$，我们只关心每种类型存在多少个元素。 仅使用这两个残基的任何有效序列必须在它们之间交替。 这将问题转化为将两个多重集分割成最小数量的交替序列。 当我们意识到两个计数之间的不平衡迫使多个序列时，最佳结构就会出现，因为单个交替序列最多可以吸收计数之间一的差异。 

特殊残留物$0$并且，当$m$是偶数，$m/2$，行为不同，因为它们与自己配对。 对于这些，所有元素都可以放入单个序列中，因为任何邻接都是有效的。

 | --- | --- | --- | --- |
 | 暴力序列构造|$O(n^2)$|$O(n)$| 太慢了|
 | 基于频率的余数配对 |$O(n + m)$|$O(m)$| 已接受 |

 ## 算法演练

 我们首先将数组压缩为每个余数模的频率计数$m$。 

1. 计算数组`cnt`在哪里`cnt[r]`存储有多少个数字有余数$r$。 这会删除所有排序信息，并仅保留对邻接可行性重要的信息。 
2. 处理余数$0$。 如果`cnt[0]`是非零的，所有这些元素都可以放入一个有效的序列中，因为$0 + 0 \equiv 0 \pmod m$。 这贡献了 0 或 1 序列。 
3.如果$m$是偶数，处理余数$m/2$。 具有此余数的所有元素也是相互兼容的，因此如果它们存在，则可以将它们放入单个序列中。 这也最多贡献 1 个序列。 
4. 对于每个余数$r$从$1$到$m-1$，将其与$m-r$，但仅通过强制处理每对一次$r < m-r$。 对于每一对这样的组，我们决定需要多少序列来容纳这两个组。 
5. 一对$(r, m-r)$， 让$a = cnt[r]$和$b = cnt[m-r]$。 如果两者都为零，我们就跳过它。 否则，所需的最小交替序列数为$\max(1, |a - b|)$。 这抓住了这样一个事实：单个交替序列可以吸收尽可能多的平衡，任何剩余的不平衡都会迫使额外的序列。 
6. 将所有独立小组的贡献相加得出最终答案。 

### 为什么它有效

 一对上的每个序列$(r, m-r)$是一条交替链，并且在任何单链内，两个残基的计数之差最多为1。 因此，序列可以有效地“吸收”平衡对，并且只有过量的优势残基才会迫使新序列产生。 由于不同的残基对不会相互作用，因此独立优化每对残基会产生全局最优分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        
        cnt = [0] * m
        for x in a:
            cnt[x % m] += 1
        
        ans = 0
        
        if cnt[0] > 0:
            ans += 1
        
        if m % 2 == 0 and cnt[m // 2] > 0:
            ans += 1
        
        for r in range(1, m):
            s = m - r
            if r >= s:
                continue
            a1, a2 = cnt[r], cnt[s]
            if a1 == 0 and a2 == 0:
                continue
            ans += max(1, abs(a1 - a2))
        
        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先构建剩余频率，这是与可行性相关的唯一信息。 然后，它分别处理两个自兼容的残基类，因为它们的行为类似于独立的单组问题。 

循环结束$r$每个残基与其补体恰好配对一次。 表达式`max(1, abs(a1 - a2))`实现了交替序列的关键结构结果：即使是严重不平衡的一对仍然需要至少一个序列，并且每一个额外的不平衡单位都会迫使一个额外的序列。 

必须注意避免重复计算，确保$r < m-r$，否则每对都会被处理两次，答案就会被夸大。

 ## 边缘情况

 对于剩余的$0$，只要存在单个序列，算法就会正确分配该序列，因为所有此类元素都是相互兼容的。 即使有很多零，它们也不会强制多个序列，因为没有违反交替约束。 

对于剩余的$m/2$什么时候$m$是偶数，同样的道理也适用。 虽然它可能看起来像一个配对问题，但每一对相同的残基都是有效的，因此无论数量如何，所有元素都可以链接成一个序列。 

对于高度不平衡的互补对，表达式$\max(1, |a-b|)$确保即使当一个残基占主导地位时，至少形成一个可用重叠的序列，而剩余的多余部分被正确地强制进入单独的单序列或部分填充的序列。
