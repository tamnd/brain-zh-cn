 ## 问题理解

 我们给出了一组问题，每个问题都与复杂性、标签和分数相关。 的复杂性$i$第一个问题是$c_i = 2^i$，呈指数增长。 你从智商开始$0$并可以先选择任何问题。 解决一个问题后，如果它的标签不同并且复杂度的绝对差超过你当前的智商，你可能会转向另一个问题。 你的智商更新为这个新的差异，你获得的分数是两个问题分数的绝对差异。 任务是最大化您在任何解决问题的动作序列中可以获得的总分。 

限制是微妙的。 和$n \le 5000$每个测试用例和总计$n$在所有测试用例也以 5000 为界时，我们可以负担得起$O(n^2)$每个测试用例的操作仅此而已。 每个分数最多可达$10^9$，因此我们必须避免幼稚的迭代评分方法，这种方法会对所有潜在序列求和而不修剪无效的动作。 

边缘情况在这里尤为重要。 单个问题无法产生任何分数，因为移动需要两个不同的问题。 如果不满足 IQ 条件，相同标签或相同复杂性的问题可能会阻止转换。 例如，如果$n = 2$具有相同的标签和不同的复杂性，不存在有效的移动，产生零分。 

## 方法

 暴力方法会尝试从每个可能的初始问题开始枚举所有问题序列。 对于每个序列，我们都会跟踪智商并累积分数。 这种方法原则上有效，因为它直接对规则进行建模，但其复杂性是阶乘的$O(n!)$，这对于$n = 5000$。 

关键的观察是评分函数仅取决于成对的问题。 移动完全由以下定义：$|c_i - c_j|$和$|s_i - s_j|$，受到标签不等式的约束。 因此，我们可以将其建模为一个图，其中节点是问题，而边仅在移动有效时才存在。 每条边的权重等于获得的分数。 我们的目标是找到从任何节点开始的最大权重路径。 

我们可以通过注意到对于给定的标签对，在每个 IQ 级别上只有最大分数才重要来进行优化。 因为复杂性是 2 的幂，所以绝对差异是唯一的，并且明显差异的数量仅限于$O(n^2)$。 这种观察允许动态编程：维护一个由前一个问题的标签索引的 DP 表，并存储在该问题结束时可达到的最大分数。 迭代所有问题对一次就足以更新 DP 值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n!) | 太慢了|
 | 最佳 | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个DP数组`dp`尺寸的`n`， 在哪里`dp[i]`存储通过在问题处结束序列可获得的最大分数`i`。 最初全部`dp[i] = 0`因为尚未采取任何行动。 
2. 迭代所有问题对`(i, j)`和`i != j`：

 1. 检查标签是否不同：`tag[i] != tag[j]`。 
2. 计算复杂度差异`diff = abs(2^(i+1) - 2^(j+1))`。 
3.如果`diff > dp[i]`（当前 IQ 起始于`i`），从`i`到`j`是允许的。 
4. 更新`dp[j] = max(dp[j], dp[i] + abs(s[i] - s[j]))`。 
3. 测试用例的答案是最大值`dp`考虑完所有对之后。 

DP 之所以有效，是因为在每一步中，`dp[j]`始终存储结束于的有效序列可达到的最大分数`j`。 由于移动仅取决于复杂性和标签的差异，因此考虑每一对可以保证不会错过任何潜在的序列。 不变的是`dp[i]`对于结束于的序列是最佳的`i`在下一次迭代之前。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        tags = list(map(int, input().split()))
        scores = list(map(int, input().split()))
        
        dp = [0] * n  # dp[i]: max score ending at problem i
        
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                if tags[i] != tags[j]:
                    diff = abs((1 << (i + 1)) - (1 << (j + 1)))
                    if diff > 0:  # IQ condition: initial dp[i] can be treated as IQ
                        dp[j] = max(dp[j], dp[i] + abs(scores[i] - scores[j]))
        
        print(max(dp))

if __name__ == "__main__":
    solve()
```每次迭代都会考虑不同标签之间的有效移动。 我们利用指数性质`c_i = 2^i`直接使用位移位来有效地计算差异。 使用`dp`避免重新计算并确保我们始终选择解决任何问题的最佳序列。
