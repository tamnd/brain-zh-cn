 ## 解决方案
 ## 问题理解

 该问题要求三个正整数之和为给定数字$n$并且其最小公倍数不超过一半$n$。 输入给出了许多测试用例，每个测试用例指定一个整数$n$。 对于每个测试用例，输出必须是三个数字$a_1, a_2, a_3$这样$a_1 + a_2 + a_3 = n$和$\text{LCM}(a_1, a_2, a_3) \le n/2$。 

约束条件允许$n$一样大$10^9$直至$10^4$测试用例。 这排除了任何尝试迭代所有可能的三元组或天真的计算 LCM 以获得大数的算法，因为这至少需要$O(n^2)$使用暴力方法对每个测试用例进行操作，这太慢了。 我们需要一个能够在每个测试用例的恒定时间内直接计算数字的解决方案。 

当出现不明显的边缘情况时$n$很小或很奇怪。 例如，如果$n = 3$，唯一有效的三元组是$(1, 1, 1)$，因为所有数字都必须是正数。 什么时候$n$是偶数但不能被 4 整除，如果天真地分裂，选择相等的部分可能会违反 LCM 约束$n$进入$n/3, n/3, n/3$，因为 LCM 可能超过$n/2$。 

## 方法

 一种天真的暴力方法会尝试每一个可能的三元组$(a, b, c)$和$a + b + c = n$并检查是否$\text{LCM}(a, b, c) \le n/2$。 这是正确的，但效率极低，因为三元组的数量随$n$。 和$n$最多$10^9$，迭代偶数$O(n^2)$可能性是不可行的。 

关键的见解来自于我们只需要简单的数字来满足 LCM 条件的观察。 如果$n$是奇数，设置两个数等于 1，第三个数等于$n-2$保证$\text{LCM}(1, 1, n-2) = n-2$，小于$n/2$仅当$n=3$。 如果$n$是均匀的，分裂的$n$分成几乎相等的一半，同时调整奇偶校验，确保总和匹配$n$并且 LCM 保持在$n/2$。 具体来说，选择形式的三元组$(n/2, n/4, n/4)$或者$(n/2-1, n/2-1, 2)$满足所有足够大的条件$n$。 按分类$n$由于可以被 2 或 4 整除并且为奇数，我们可以在每个测试用例的恒定时间内生成三元组。

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$。 我们知道$k = 3$是固定的。 
2.如果$n$是奇数，选三元组$(1, (n-1)/2, (n-1)/2)$。 总和是$1 + (n-1)/2 + (n-1)/2 = n$，LCM 为$(n-1)/2$，小于$n/2$仅当$n=3$，但通过检查我们知道它始终满足允许值的约束。 
3.如果$n$能被4整除，选择$(n/2, n/4, n/4)$。 这些数字总和为$n$液晶模组是$n/2$，完全满足条件。 
4. 如果$n$是偶数但不能被4整除，选择$(n/2-1, n/2-1, 2)$。 总和是$(n/2-1) + (n/2-1) + 2 = n$，LCM 为$n-2$，它总是小于$n/2$。 这有效是因为$n/2$是奇怪的，所以$n-2 < n/2$很满意。 
5. 打印为每个测试用例选择的三元组。 

为什么有效：结构保证总和匹配$n$并且 LCM 通过使用重复数字或小值（如 1 或 2）来控制。对于可被 4 整除的偶数，将其分成两半和四分之一会准确产生最大元素$n/2$。 对于不能被 4 整除的偶数，两个几乎相等的数加上 2 可确保最大的数小于$n/2$。 奇数用一个 1 和两个相等的一半来处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if n % 2 == 1:
        print(1, n//2, n//2)
    elif n % 4 == 0:
        print(n//2, n//4, n//4)
    else:
        print(n//2 - 1, n//2 - 1, 2)
```第一行读取测试用例的数量。 对于每个测试用例，我们解析$n$和$k$。 我们基于奇偶性进行分支$n$以及是否$n$可以被 4 整除。使用整数除法可以确保我们得到三元组的整数。 直接为每个分支打印使解决方案变得简单并避免临时存储。
