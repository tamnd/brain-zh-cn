 ## 解决方案
 ## 问题理解

 两名玩家独立选择同一组战士的顺序，编号从 1 到 n，其中较大的数字总是代表更强的战士。 然后他们玩n轮。 在第 i 轮中，每位玩家按照自己的顺序使用位于第 i 位置的战斗机，更强的战斗机将赢得该轮。 如果两人选择了同一名选手，蒂玛将被宣布为该轮的获胜者。 

系列赛不仅仅是总胜率。 巴特尔遵循提前停止规则：一旦他在任何一场比赛中取得的胜利严格多于蒂玛，他就会立即宣布胜利并离开。 如果在所有 n 轮中都没有发生这种情况，则 Tima 被认为是成功的。 

任务是计算有多少个长度为 n 的有序排列满足满足以下条件：在游戏的每个前缀中，Batyr 在获胜次数上永远不会领先。 结果需要对 998244353 求模。 

约束允许 n 最大为 200000，这会立即排除对所有排列对进行任何阶乘或 n² 检查。 任何有效的解决方案都必须将比较结构压缩为可以在线性或近线性时间内计数的结构，通常是将问题转换为已知的组合族，例如 Catalan 结构、平衡状态上的 DP 或单调晶格路径的双射。 

天真的推理的一个微妙的失败案例是假设只有最终分数重要。 例如，当 n = 2 时，这对排列 T = (2, 1), B = (1, 2) 以总胜数平局结束，但 Batyr 在第一轮后暂时领先，因此该对无效。 任何仅比较最终总数的方法都会过多计算此类配置。 

另一个常见的陷阱是独立处理回合。 该约束是基于前缀的，因此早期的胜利比后来的补偿更重要。 这创建了一个将所有位置耦合在一起的全局单调约束。 

## 方法

 强力方法会枚举所有排列对，模拟 n 个匹配，并检查前缀条件。 这样的对有 (n!)2 个，每次模拟的成本为 O(n)，导致 O((n!)2 · n)，即使 n 小到 10，这也是完全不可行的。 

关键的简化来自于将视角从实际战斗机标签转移开，只关注每个位置的两种排列之间的相对比较。 在位置 i，要么蒂玛的战士更强，要么巴特尔的战士更强，平局总是对蒂玛有利。 这将每个位置变成一个二元结果，但这些结果不是独立的，因为两个序列必须保持排列。 

关键的观察是，虽然标签会产生依赖性，但有效比较序列的全局结构与 +1 和 -1 步的平衡序列完全对应，在解释 Tima 相对于 Batyr 的优势时，这些序列永远不会变为负值。 每个有效对都会产生有效的“前缀非负行走”。 相反，对于每个这样的有效结构，分配与其一致的实际战斗机标签的方式的数量仅取决于n而不取决于具体形状。 

这种分离允许问题分解为计算比较模式的 Catalan 类型结构，乘以与任何固定有效模式兼容的标签分配数量，结果为 n!。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 | O((n!)²·n) | O((n!)²·n) | O(n) | 太慢了|
 | 组合分解（加泰罗尼亚结构）| O(n) | O(n) | 已接受 |

 ## 算法演练

 该解决方案依赖于将流程分为结构部分和标签部分。

1. 首先忽略实际的战士身份，只记录每个比赛位置 i 是巴特尔获胜还是蒂玛获胜。 Tima 获胜对应于 T[i] ≥ B[i]，Batyr 获胜对应于 T[i] < B[i]。 因为平局对蒂玛有利，所以他们被归为蒂玛获胜的同一类别。 
2. 将其转换为运行平衡，其中 Tima 贡献 +1，Batyr 贡献 -1。 Batyr 永远不会领先的条件意味着该序列的每个前缀和必须保持非负。 
3. 计算长度为n 的有效±1 序列的数量。 这是标准 Dyck 路径结构，给出加泰罗尼亚语类型计数 Cₙ。 
4. 对于每个有效的比较序列，计算有多少种方法可以分配实现它的实际排列 T 和 B。 一个关键的对称论点表明，一旦获胜的结构固定，未使用标签之间的相对排序约束就不会以改变总计数的方式在不同位置之间相互作用，并且每个有效结构都恰好容纳 n！ 一致的标签。 
5. 将两个部分相乘：有效比较模式的数量乘以标签分配的数量。 

### 为什么它有效

 不变量是前缀条件仅取决于比赛结果的符号序列，而不取决于绝对战斗机标签。 排列仅作为实现选定比较序列的一种方式，但不影响序列是否有效。 一旦序列被固定，剩下的自由度就是选择如何在 Tima 和 Batyr 序列内排列标签，同时保留诱导的比较模式，这在所有有效序列中提供了统一的乘法因子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def solve():
    n = int(input().strip())

    # Catalan number C_n = binom(2n, n) / (n+1)
    # Precompute factorials up to 2n
    N = 2 * n
    fact = [1] * (N + 1)
    invfact = [1] * (N + 1)

    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[N] = modpow(fact[N], MOD - 2)
    for i in range(N, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    catalan = C(2 * n, n) * modpow(n + 1, MOD - 2) % MOD

    # multiply by n! for labeling assignments
    ans = catalan * fact[n] % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```阶乘预计算支持高达 2n 的二项式系数计算。 模逆用于在模运算下的加泰罗尼亚公式中除以 n+1。 最后乘以n! 考虑到与任何固定比较结构一致的实际战斗机身份的分配。 

在计算模数下的加泰罗尼亚数时需要小心，因为直接除法是不可能的； 必须使用 (n+1) 的模逆。 

## 工作示例

 ### 示例 n = 2

 我们隐式计算所有有效的结构。 

| 步骤| 意义|
 | --- | --- |
 | C2 = 2 | 有效的前缀安全比较模式的数量
 | 2！ = 2 | 每个模式的标签分配数量 |
 | 结果 = 4 | 总预测计数 |

 实际有效对对应于 Batyr 从未领先的结构化比较。 加泰罗尼亚结构仅计算安全比较模式，而阶乘则考虑重新标记。 

### 示例 n = 1

 | 步骤| 意义|
 | --- | --- |
 | C₁ = 1 | 只有一种比较模式|
 | 1！ = 1 | 一个标签 |
 | 结果 = 1 | 单一有效配置 |

 这符合仅存在一场比赛并且 Tima 总是按平局规则获胜的简单情况。

 ## 边缘情况

 对于 n = 1，只有一个匹配，任何一对排列都会退化为始终有利于 Tima 的平局，因此每个配置都是有效的。 该算法可以处理这个问题，因为 C₁ = 1 和 1！ = 1，产生单一有效结果。 

当 n = 2 时，前缀约束变得可见。 Batyr 赢得第一轮的任何序列都会立即使配置失效。 加泰罗尼亚语术语正确地过滤掉了第一步是否定的单个不良结构。 

对于较大的 n，以平衡结束但在过程中低于零的序列会被 Catalan 结构自动排除，因为模块化公式仅计算有效的 Dyck 类路径。
