 ## 解决方案
 ## 问题理解

 我们有一座摩天大楼，楼层编号从 1 层到非常大的层数，并且有几个人在不同楼层等待电梯。 每个人都有不同的起始楼层和不同的目的地楼层，并且没有两个楼层重叠。 电梯从一楼开始。 它可以直接从当前楼层移动到等待的人的起始楼层或已经在里面的人的目标楼层。 登机和下机是瞬时的，电梯可以同时承载所有人。 

目标是规划电梯的路线，以最大化从一楼到最后一个人到达目的地的总旅行时间。 每次移动消耗的时间等于当前楼层与下一层之间的绝对差，中间楼层被忽略。 

鉴于限制条件，`n`可以达到`10^5`每个测试用例，以及所有测试用例的总和`n`跨测试用例不超过`10^5`。 这立即排除了楼层序列的天真暴力排列，因为可能的排序数量随阶乘增长`n`。 每个测试用例最多需要线性或线性算数时间解。 

边缘情况很微妙。 其中一种情况是，一个人的起始楼层远远高于所有其他楼层。 基于“最近楼层优先”的天真贪婪选择可能会最小化第一步并无意中减少总时间。 同样，起始楼层和目的地楼层相距较远的人占据了总时间，因此忽略了之间的范围`s_i`和`f_i`可能会低估最大值。 

例如，输入：```
1
2
2 100
3 5
```一个天真的最近优先可能会去`1->2->3->5->100`时间为 2+1+2+95=100，但是更智能的序列`1->3->5->2->100`给出 2+2+3+98=105。 最大化时间取决于利用长跳。 

## 方法

 暴力方法是尝试访问起始楼层和目的地楼层的每种排列并计算总距离。 这是有效的，因为任何遵守登机和下机规则的路径都是有效的，并且总时间只是绝对差值的总和。 然而，随着`n`最多`10^5`， 有`(2n)!`序列，这在计算上是不可能的。 即使使用最近的未访问楼层的贪婪策略评估所有序列也不是最优的，因为它可能会错过增加总时间的较长跳跃。 

关键的观察结果是，每个人对总距离贡献一个固定的“跨度”：从起始楼层移动`s_i`到他们的目的地`f_i`是不可避免的。 为了最大化电梯的总行程，我们需要交错这些跨度以产生尽可能多的大跳跃。 按最大人数对人员进行排序`s_i`和`f_i`按降序排列可确保电梯首先进行最大的跳跃。 另一个等效的观点是考虑间隔`[min(s_i,f_i), max(s_i,f_i)]`并按最远端点排序，这迫使电梯提前行驶很长的距离，累积最大总时间。 

排序后，我们模拟电梯：在每一步，移动到距当前位置最远的未访问楼层（无论是等待者的起点还是乘客的目的地）。 这种贪婪排序之所以有效，是因为最优解总是首先使用最大的跳跃； 任何早期较小的跳跃都会减少以后可以达到的总距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有排列）| O((2n)!) | O((2n)!) | O(2n) | O(2n) | 太慢了|
 | 贪心区间排序| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取人数`n`及其起始楼层和目的地楼层。 
2.对于每个人，定义一个元组`(min(s_i, f_i), max(s_i, f_i))`。 这代表它们占据的间隔。 
3. 按最大端点降序对所有区间进行排序。 按最大值排序可确保首先考虑大的跳跃。 
4. 初始化1层电梯，并将total_time设置为0。 
5. 迭代排序后的区间。 对于每个间隔，如果电梯低于间隔的最小值，则移动到间隔的起点，否则直接移动到最远端。 增量`total_time`通过移动的距离。 
6. 一旦开始，始终移动到间隔的另一端（从`s_i`到`f_i`或反之亦然），将绝对差值添加到`total_time`。 
7. 继续，直到所有人员都被释放。 
8. 输出`total_time`。 

为什么有效：每个人的跨度`[s_i,f_i]`至少贡献`abs(s_i - f_i)`至总时间。 按最远端排序可确保电梯尽早进行最大长距离跳跃，而这不能通过任何其他序列来扩展。 在不违反登机限制的情况下，以后不能用较大的跳台取代较小的跳台。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        intervals = []
        for _ in range(n):
            s, f = map(int, input().split())
            intervals.append((min(s,f), max(s,f)))
        
        intervals.sort(key=lambda x: x[1], reverse=True)
        cur = 1
        total_time = 0
        for l, r in intervals:
            if cur <= l:
                total_time += r - cur
                cur = r
            elif cur >= r:
                total_time += cur - l
                cur = l
            else:
                # cur is between l and r
                total_time += max(r - cur, cur - l)
                cur = r if r - cur >= cur - l else l
        print(total_time)

if __name__ == "__main__":
    solve()
```每个部分对应于算法中的一个步骤。 按最大端点对间隔进行排序可以保证我们始终首先考虑最长的潜在跳跃。 当当前电梯位置在`l`和`r`，移动到最远的端点可以最大化累积时间。 边缘情况，例如`cur < l`或者`cur > r`直接通过简单的算术处理。
