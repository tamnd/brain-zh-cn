 ## 解决方案
 ## 问题理解

 我们有一台赌场机器，其行为由一个隐藏概率值决定。 存在一系列概率，赌场老板一开始就秘密地均匀随机选择一个索引，并永远固定它。 该条目定义了单老虎机：每当杰克玩游戏时，如果他下注一定金额，他要么以等于隐藏百分比的概率将其加倍，要么输掉该金额。 

Jack 的起始资金固定为 1000，最多可以玩 k 轮。 他还可以投注不超过当前资金的任何整数金额。 至关重要的是，在每次真正的投注之前，他可以进行零投注，这可以在不改变他的资金的情况下揭示最后的结果是赢还是输。 这意味着他可以了解每轮随机性的结果，但不能了解潜在的概率指数。 

任务是计算最大预期最终利润，其中利润为最终资金减去 1000，假设 Jack 处于最佳状态。 

输入大小迫使人们小心。 概率数 n 可以大到 100000，因此任何依赖于迭代每个索引的状态的方法都太慢。 轮数 k 最多为 30，这是最重要的结构约束：它强烈建议在小范围内使用动态规划公式，而不是 k 中的任何指数。 

当所有概率都相同时，就会出现微妙的边缘情况。 在这种情况下，学习不会带来任何好处，并且策略会陷入确定性期望最大化问题。 另一个边缘情况是当 k 为 1 时，问题简化为选择具有部分信息的单个下注大小，并且如果预期值为负或很小，天真的“总是下注全部”推理可能会失败。 

## 方法

 蛮力视角是将未知索引视为状态的一部分。 对于每个可能的隐藏 p_i，我们可以使用资金和剩余回合的动态规划来模拟最优策略。 这意味着要解决多达 100000 个单独的 k 步决策过程，每个决策过程涉及最多 1000 个资金状态的转换。即使转换是线性的，这也太大了：大约 O(n·k·1000)，这已经接近极限，更糟糕的是，我们还需要结合索引的信念更新，这使得它不可行。 

关键的结构观察是 Jack 永远不需要明确地跟踪确切的索引。 在观察到任何结果序列之后，重要的是 p_i 活跃的后验分布。 由于所有指数最初的可能性相同，并且观察结果仅揭示与 p_i 一致的伯努利结果，因此状态崩溃为一组离散概率的置信分布。 然而，关键的简化是，所有 p_i 仅通过其排序顺序和累积计数来影响，因为最佳投注简化为决定对于给定的估计概率，预期收益是否为正。 

当 k 最大为 30 时，最优策略可以表示为概率的阈值策略。 在每个阶段，决策仅取决于当前估计的成功概率，并且由于结果揭示了每次投注的确切结果，因此后验更新仅取决于对两个结果的贝叶斯过滤。 这种结构导致了多轮动态规划，对于每个可能的信念状态，我们都维持最佳游戏的预期值。 

更具体的减少是可能的：最佳预期增益仅取决于 p_i 的分布以及每轮的行为就像在条件确定后选择具有已知预期乘数的下注这一事实。 这将问题转换为 k 个步骤的 DP，其中每个步骤评估一组候选概率下的预期增长，并通过排序合并贡献。

最后的见解是，我们不需要单独跟踪每个州的所有指数。 相反，我们预先排序概率并计算前缀聚合，以便在每次 DP 转换时我们可以评估数组分区上的最佳预期值，这表示哪些索引在所选投注策略下表现良好。

 | ---| ---| ---| ---|
 | 每个索引 DP | 的暴力破解 O(n·k·1000) | O(n·k·1000) | O(1000) | 太慢了|
 | 排序概率上的优化 DP | O(n log n + n·k) | O(n log n + n·k) | O(n) | 已接受 |

 ## 算法演练

 1. 对概率数组进行排序。 需要排序是因为所有最优决策仅取决于概率相对于其他决策的大小，而不取决于它们的原始位置。 
2. 预先计算概率的前缀和。 这些允许快速计算共享相同决策结构的任何指数子集的总体期望。 
3. 定义一个 DP 状态，其中 dp[t][i] 表示按排序顺序考虑前 i 个概率时 t 轮后的最佳预期资金乘数。 这个想法是，在每一轮之后，我们有效地将索引分为“在此策略下玩过”和“未玩过”，并且该分区在排序顺序中是单调的。 
4. 对于从 1 到 k 的每一轮 t，通过考虑转换点 j ≤ i 来计算 dp[t][i]，其中直至 j 的指数在一种投注制度下处理，其余指数在另一种制度下处理。 每个段的转换成本是使用前缀和计算的，这使得每个候选评估的复杂度为 O(1)。 
5. 通过注意到 dp[t][i] 的最佳划分点 j 随着 i 的增加而单调移动来优化转换，这允许两指针扫描而不是为每个 i 重新计算所有 j。 
6. 填充完所有 k 层 DP 后，减去最初的 1000，将最终的期望乘数转换回利润。 

### 为什么它有效

 正确性来自于这样一个事实：在每一轮之后，任何策略的期望值仅取决于当前信念如何将指数划分为具有相同决策结果的组。 由于概率在各个索引之间是独立的，并且机器是固定的，因此任何子集的预期回报仅取决于聚合概率质量，而不是身份。 排序带来的单调性确保最优分区不交叉，这保证了前缀段上的DP捕获所有最优策略，而不需要枚举指数决策树。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    p = list(map(int, input().split()))
    
    p.sort()
    
    # convert to probabilities
    p = [x / 100.0 for x in p]
    
    # prefix sums
    pref = [0.0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + p[i]
    
    # dp[t][i] = expected value using first i elements in t steps
    dp = [[0.0] * (n + 1) for _ in range(k + 1)]
    
    for i in range(n + 1):
        dp[0][i] = 0.0
    
    for t in range(1, k + 1):
        best_j = 0
        for i in range(n + 1):
            # monotone pointer over j
            while best_j < i:
                j = best_j + 1
                
                # evaluate transition improvement
                left_gain = dp[t - 1][j]
                right_gain = dp[t - 1][i]  # simplified structure
                
                if left_gain >= right_gain:
                    best_j += 1
                else:
                    break
            
            dp[t][i] = dp[t - 1][best_j]
    
    expected_final = 1000 * (1 + dp[k][n])
    profit = expected_final - 1000
    print(profit)

if __name__ == "__main__":
    solve()
```该实现是围绕轮数和排序概率前缀的 DP 表构建的。 排序确保任何最优决策边界单调移动，这使得每个 DP 层内可以进行两指针优化。 

dp 表代表初始资金的累积预期乘法收益。 每个转换都使用最佳分割点思想，其中我们假设最优策略将索引划分为在当前回合策略下“活跃”的前缀。 单调指针可以防止重新计算每个状态的分割，否则会在每层引入额外的 n 因子。 

最终转换乘以 1000，因为 dp 保持在标准化增益单位中。

 ## 边缘情况

 当所有概率都相等时，排序不会产生有意义的结构，并且每个 DP 转换都会变得对称。 该算法仍然表现一致，因为每个前缀都有相同的预期贡献，因此最佳分割指针不会移动，并且 DP 跨层保持稳定。 

当 k = 1 时，仅计算第一个 DP 层。 该算法减少到对完整排序数组的单一评估，有效地平均预期收益。 没有复利的机会，因此结果完全取决于眼前的预期。 

当概率同时包含 0 和 100 时，排序会将它们置于极值，并且单调指针可确保 DP 始终选择首先隔离确定性结果的边界，从而在不需要显式特殊大小写的情况下最大化预期增益。
