 ## 解决方案
 ## 问题理解

 我们有一个长方形蛋糕，其尺寸为$w \times h \times d$。 目标是将这种固体精确地分成$n$较小的矩形块，大小相同。 唯一允许的操作是平行于蛋糕面的切割。 每个维度首先被分成等长的片段，这意味着最终的片段来自规则的 3D 网格。 

思考该过程的一个有用方法是我们选择沿每个轴需要多少个切片。 如果我们将宽度分成$a$等份，高度变为$b$部分和深度$c$部分，然后蛋糕就变成了$a \cdot b \cdot c$相同的块。 每个切割计数仅比沿该维度的线段数量少一，但问题直接要求沿每个轴的切割数量。 

关键约束是每次划分必须产生整数长度的段，因此每个选定的段数必须精确地划分相应的维度。 

输入大小可达$10^9$，这排除了任何枚举除数或尝试所有因子三元组的尝试$n$。 一个循环到的解决方案$n$甚至$10^6$在最坏的情况下，每个测试用例已经太慢了，所以我们需要直接的数论分解。 

当出现微妙的边缘情况时$n = 1$。 在这种情况下，不需要削减，所以答案应该是$0, 0, 0$。 另一个重要的情况是当$n$包含无法嵌入到因式分解中的质因数$w, h, d$，即使$n$本身很小。 例如，如果$w = h = d = 2$和$n = 8$，我们可以做$2 \times 2 \times 2$，但如果$n = 6$，除非整除条件正常失败，否则无法将因子分配到与维度对齐的三个有效整数分割中。 

主要困难不是组合数学，而是正确匹配分解$n$具有可用的三个维度的可分结构。 

## 方法

 一个天真的方法会尝试所有三元组$(a, b, c)$这样$a \cdot b \cdot c = n$。 对于每个三元组，我们检查是否$w$可以整除$a$,$h$经过$b$， 和$d$经过$c$。 这已经是个问题了，因为因子的数量是$n$不受小常数的限制； 在最坏的情况下，例如$n = 10^9$，迭代所有除数对仍然可能太慢，并且对于大约束重复执行此操作是不安全的。 

更深层次的结构是，问题完全是关于分配质因数$n$分成三个桶，每个桶对应一个维度。 然而，我们不能随意分配任意因素：每个维度都对我们可以分割它的次数施加了上限，因为每次切割都必须遵循整数段大小。 

因此，不要考虑因子三元组$n$，我们反转视角。 每个维度贡献最大可能的段数：$w$可以支持任意数量的分割部件$w$，类似地对于$h$和$d$。 我们想选择三个除数$a \mid w$,$b \mid h$,$c \mid d$这样$a b c = n$。 

这将问题变成了除数搜索，但我们可以通过预先计算每个维度的除数并将它们与除数对配对来有效地构建它$n$。 自从$w, h, d \le 10^9$，每个数字最多有大约$10^5$最坏的病态情况下的除数，但实际上我们只需要迭代除数$n$，其边界为$O(\sqrt{n})$。 

关键的观察是我们可以修复我们的分裂方式$n$进入$a \cdot b \cdot c$，但我们不是枚举所有三元组，而是修复两个因子并导出第三个。 然后我们只需要检查每个维度的整除性。 

这减少了枚举除数对的问题$n$，这是高效的，并测试三个维度的兼容性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力三倍因素 |$O(\tau(n)^2)$|$O(1)$| 太慢了|
 | 最佳除数对枚举 |$O(\sqrt{n})$|$O(1)$| 已接受 |

 ## 算法演练

 我们将任务重新解释为寻找整数$a, b, c$这样：$a \cdot b \cdot c = n$,$w \bmod a = 0$,$h \bmod b = 0$,$d \bmod c = 0$。 

然后我们稍后将片段转换为剪辑。 

1. 枚举所有除数$a$的$n$。 对于每一个这样的$a$, 计算$n / a$，我们称之为$m$。 此步骤是必要的，因为任何有效的第一维分割都必须消耗以下除数$n$。 
2. 对于每个除数$b$的$m$， 定义$c = m / b$。 这保证了$a b c = n$不需要第三个循环。 
3. 对于每个三元组$(a, b, c)$，检查是否$a$划分$w$,$b$划分$h$， 和$c$划分$d$。 这确保了每个维度都可以均匀地划分为所需数量的段。 
4. 如果有效，则通过返回将段计数转换为切割计数$a - 1, b - 1, c - 1$， 自从$k$细分市场需要$k - 1$削减。 
5. 如果穷尽所有除数对后不存在有效三元组，则输出$-1$。 

### 为什么它有效

 每个有效分区完全对应于沿每个轴选择的段计数。 由于切割被限制为轴对齐且均匀，因此每个尺寸独立地减少到选择其长度的除数。 产品约束$a b c = n$确保细胞总数与所需的片数相匹配。 枚举除数对$n$保证我们考虑每一个可能的乘法分解而没有冗余，并且检查维度的整除性增强了几何可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def get_divisors(x):
    small = []
    large = []
    i = 1
    while i * i <= x:
        if x % i == 0:
            small.append(i)
            if i * i != x:
                large.append(x // i)
        i += 1
    return small + large[::-1]

w, h, d = map(int, input().split())
n = int(input())

# try all factorizations n = a * b * c
i = 1
while i * i <= n:
    if n % i == 0:
        j = n // i

        # a = i, bc = j
        k = 1
        while k * k <= j:
            if j % k == 0:
                a, b, c = i, k, j // k
                if w % a == 0 and h % b == 0 and d % c == 0:
                    print(a - 1, b - 1, c - 1)
                    sys.exit(0)
            k += 1
    i += 1

print(-1)
```该代码执行因子三元组的受控枚举$n$。 外环固定第一维度因子$a$。 对于每个这样的选择，剩余的产品$n / a$分为两个因素$b$和$c$。 这避免了对所有三元组的三次搜索。 

可分割性检查确保每个维度都可以划分为相等的段。 减一会将段计数转换为切割计数，因为将一条线切割为$k$零件完全需要$k-1$削减。 

使用提前终止是因为任何有效的三元组就足够了，并且问题不需要枚举所有解决方案。

 ## 边缘情况

 最小的情况$w = h = d = 1, n = 1$产生单个块。 算法立即发现$a = b = c = 1$，并返回$0, 0, 0$，与不需要切割的事实相匹配。 

什么时候$n$是质数并且大于1，例如$n = 13$，唯一可能的因式分解是$13 \cdot 1 \cdot 1$。 该算法将尝试将质因子分配给每个维度，但如果没有$w, h, d$能被 13 整除，所有检查都失败，输出正确变为$-1$。 

在某一维度限制非常严格的情况下，例如$w = 1$，该算法有效地迫使$a = 1$。 任何尝试将更大的因素分配给$w$未通过整除性检查，尽早修剪无效分解并仅留下有效分配$h$和$d$。
