 ## 解决方案
 ## 问题理解

 我们在笛卡尔平面上有两组点：分散在山谷中的水泵和位于周围山上的水库。 每个合作社都想用一根直管连接它们的一对点，目标是看看这两条管道（一根连接两个泵，一根连接两个水库）是否有可能相交。 交叉点包括接触或重叠的线段。 

输入指定多个规划场景。 每个场景都提供了泵的数量及其坐标，然后是水库的数量及其坐标。 每个场景的输出是表示有效相交管道对的四个索引，如果不存在此类配置，则输出为 -1。 

主要限制是每个场景的水泵和水库的数量以及场景的数量。 由于所有场景的总点数限制为$2 \cdot 10^5$对于泵和蓄水池，一种简单的解决方案是根据所有对蓄水池检查所有泵对，可能涉及粗略的$O(n^2 m^2)$在最坏的情况下进行操作，这是完全不可行的。 因此，我们需要一种算法来避免枚举每个可能的对。 

边缘情况包括所有泵或所有蓄水池共线的情况。 例如，如果所有泵位于水平线上并且所有水库位于与该水平线平行的线上，则不可能有交叉。 如果不检查前两个泵和前两个水库的相对位置，粗心地选择它们可能会报告错误的交叉点。 

## 方法

 蛮力方法很简单。 对于每种情况，可以迭代每对泵，然后迭代每对水库，并检查两条线段是否相交。 这保证了正确性，但时间复杂度为$O(n^2 m^2)$每个场景，这是不可行的$n, m \le 10^5$和$t \le 10^5$。 

解锁更快解决方案的关键观察是，对于任何非共线的泵组和任何非共线的储液器组，始终存在连接段相交的两个泵和两个储液器的选择。 这来自几何事实，即如果选择最左边和最右边的泵以及最左边和最右边的储液器，则四个连接段对之一相交，或者这些组完全分开，在这种情况下，所有点都沿着公共轴共线。 这将问题简化为检查简单的交叉：选择沿 x 轴（或 y 轴，如果 x 相等）的每组极值点并尝试一次相交测试。 

这意味着我们不需要检查所有对。 在每种情况下，我们可以按 x 坐标对泵和水库进行排序，以找到每组的两个极值点，然后选取每个排序列表的第一个和最后一个点。 如果这四个点形成相交线段，则我们的配置有效。 如果泵或水库组严格垂直（所有 x 坐标相等）或水平（所有 y 坐标相等），则仅当另一组不严格平行和分离时才可能相交。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 m^2) | O(n^2 m^2) | O(n + m) | 太慢了|
 | 极值点| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 对于每个场景，读取泵和水库的坐标。 
2. 通过比较 x 坐标来识别最左边和最右边的泵。 如果存在平局，则选择最左边 y 最小、最右边 y 最大的泵。 
3. 同样，通过 x 坐标识别最左边和最右边的水库，并通过 y 坐标断开联系。 
4. 尝试将最左边的泵连接到最右边的泵，并将最左边的储液器连接到最右边的储液器。 如果这些线段相交，则输出它们的索引。 
5. 如果它们不相交，则反转其中一个储液器索引（将最左边的泵连接到最右边的泵，将最右边的储液器连接到最左边的储液器）并再次检查。 
6. 如果在任一配置中发现交集，则报告相应的索引。 否则输出-1。 

为什么它有效：通过选择极值点，我们保证如果有可能相交，它将发生在最外面的点之间。 这是有效的，因为任何一对泵和任何一对储罐没有沿着轴线严格分开，都会在这些极值组合之一中相交。 该算法将问题从组合枚举简化为少量恒定数量的交叉测试。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ccw(a, b, c):
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def intersect(p1, p2, q1, q2):
    d1 = ccw(p1, p2, q1)
    d2 = ccw(p1, p2, q2)
    d3 = ccw(q1, q2, p1)
    d4 = ccw(q1, q2, p2)
    if d1*d2 < 0 and d3*d4 < 0:
        return True
    if d1 == 0 and on_segment(p1, p2, q1):
        return True
    if d2 == 0 and on_segment(p1, p2, q2):
        return True
    if d3 == 0 and on_segment(q1, q2, p1):
        return True
    if d4 == 0 and on_segment(q1, q2, p2):
        return True
    return False

def on_segment(a, b, c):
    return min(a[0], b[0]) <= c[0] <= max(a[0], b[0]) and min(a[1], b[1]) <= c[1] <= max(a[1], b[1])

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        pumps = [tuple(map(int, input().split())) + (i+1,) for i in range(n)]
        m = int(input())
        reservoirs = [tuple(map(int, input().split())) + (i+1,) for i in range(m)]
        pumps.sort()
        reservoirs.sort()
        p1, p2 = pumps[0], pumps[-1]
        r1, r2 = reservoirs[0], reservoirs[-1]
        if intersect(p1, p2, r1, r2):
            print(p1[2], p2[2], r1[2], r2[2])
        elif intersect(p1, p2, r2, r1):
            print(p1[2], p2[2], r2[2], r1[2])
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```该解决方案读取所有点，附加它们的索引以进行输出，并按 x 坐标对每个集合进行排序。 这`intersect`函数处理所有一般和共线情况，而`on_segment`确保正确检测接触或重叠的段。 极值点保证如果存在交叉点，将通过这些组合检测到交叉点。
