 ## 问题理解

 我们被要求最大化基于输入数组的派生数组的“美感”。 输入数组`a`给出新数组的每个元素的上限`b`，其长度必须相同。 的每个元素`b`满足`1 ≤ b_i ≤ a_i`。 数组的美丽是通过对每个不同的值进行计算来计算的`x`在数组中，任意两次出现之间的最大距离`x`并对这些距离求和。 

例如，如果`b = [1, 2, 1, 2]`，之间的最大距离`1`s 为 2（`positions 1 and 3`）和之间的最大距离`2`s 为 2（`positions 2 and 4`），所以总的美丽度是 4。任务是选择 的值`b`最佳地最大化这个总和。 

约束条件允许`n`所有测试用例最多 200,000 个，因此任何解决方案都比`O(n log n)`每个测试用例可能会超时。 这排除了尝试所有可能的情况`b`数组，甚至天真地重复检查所有值的距离。 边缘情况包括所有元素都相等或严格递增的数组。 在这些情况下，如果算法不允许值出现在非连续位置，则幼稚的选择可能会低估最大的美感。 

## 方法

 蛮力方法会尝试每种组合`b_i`在其范围内并计算总体美感。 这在原则上是正确的，但组合的数量是指数级的，最多可达`a_1 * a_2 * ... * a_n`，对于任何非平凡的数组来说都太大了。 即使我们固定这些值，通过扫描所有对中每个不同值来天真地计算距离也是如此`O(n^2)`在最坏的情况下。 

关键的见解是单独处理每个值。 对于给定的数字`x`，当我们放置时，它可以贡献的最大距离发生`x`在允许的最早和最晚位置`a`。 由于每个`b_i`必须满足`1 ≤ b_i ≤ a_i`, 任意位置`i`在哪里`a_i ≥ x`是一个候选人`x`。 最大化`d_x(b)`，我们应该采取第一个和最后一个这样的位置。 这将问题简化为一次遍历数组来记录每个可能的最左边和最右边的位置`x`。 自从`x`范围只能达到`n`，这是有效的。 

另一个微妙之处在于我们希望最大化所有的总和`x`。 对于每个位置，我们只需要考虑放置最大允许值或延长距离的较小数字。 通过从左到右的贪婪扫描方式，我们可以有效地动态跟踪每个数字的最佳左右位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * n) | O(n^2 * n) | O(n) | 太慢了|
 | 贪心+两个指针| 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组`first_pos`和`last_pos`尺寸的`n+1`存储每个数字可能出现的最左边和最右边的索引。 填充它们`-1`来表示未初始化。 
2. 迭代数组`a`。 对于每个`i`和`a_i`，考虑每个数字`x`从 1 到`a_i`。 对于每个`x`， 如果`first_pos[x]`是`-1`，将其设置为`i`。 始终设置`last_pos[x]`到`i`。 这确保了对于每个有效的`x`，我们跟踪它可以放置的最早和最新位置。 
3. 初始化变量`beauty = 0`。 迭代所有数字`x`从 1 到`n`。 如果`first_pos[x] != -1`， 添加`last_pos[x] - first_pos[x]`到`beauty`。 这个总和是每个数字对总美的最大可能贡献。 
4. 打印或存储结果`beauty`对于每个测试用例。 

为什么有效：通过记录每个值所在的最左边和最右边的位置`x`如果可以合法放置，我们保证捕获该数字的最大可能距离。 所有数字的总和正确地说明了所有贡献，并且没有其他数字排列可以增加超出这些端点的距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        first_pos = [-1] * (n + 1)
        last_pos = [-1] * (n + 1)
        
        for i, val in enumerate(a):
            for x in range(1, val + 1):
                if first_pos[x] == -1:
                    first_pos[x] = i
                last_pos[x] = i
        
        beauty = 0
        for x in range(1, n + 1):
            if first_pos[x] != -1:
                beauty += last_pos[x] - first_pos[x]
        print(beauty)
```外循环有效地处理多个测试用例。 嵌套循环结束`x`从 1 到`a_i`确保我们记录所有数字的潜在位置，直至达到限制`a_i`。 减法`last_pos[x] - first_pos[x]`正是距离`x`。 初始化为`-1`防止计算不存在的数字。
