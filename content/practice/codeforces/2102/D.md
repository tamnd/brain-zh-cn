 ## 解决方案
 ## 问题理解

 我们在四个连续位置上有一个排列和一个允许的操作：$$[a_i,a_{i+1},a_{i+2},a_{i+3}] \rightarrow [a_{i+2},a_{i+3},a_i,a_{i+1}]$$从不同的角度来看，位于位置的元素$i$与交换$i+2$，以及位置处的元素$i+1$与交换$i+3$。 

任务不是决定目标排列是否可达。 我们必须找到在多次应用此操作后可以获得的字典顺序最小排列。 

所有测试用例的总长度最多为$2 \cdot 10^5$。 任何重复模拟操作或搜索状态空间的解决方案都是不可能的。 甚至$O(n^2)$在最坏的情况下，每个测试用例都会太慢。 我们周围需要一些东西$O(n \log n)$。 

第一个微妙的观察是每个元素总是停留在相同奇偶校验的位置上。 从位置 1 开始的元素只能移动到位置 3、5、7 等。 从位置 2 开始的元素只能移动到位置 4、6、8 等。 

一个常见的错误是得出这样的结论：我们可以简单地对奇数位置元素进行排序，并独立对偶数位置元素进行排序。 

考虑：```
n = 4
3 2 1 4
```奇数位置包含`[3,1]`，甚至位置包含`[2,4]`。 

对每个组进行排序可以得出：```
1 2 3 4
```但此配置无法访问。 唯一的操作产生：```
1 4 3 2
```缺少的成分是对两组内部应用的排列的奇偶约束。 

当排序的奇数组和偶数组需要不匹配的排列奇偶性时，会出现另一种容易错过的情况。 那么完全排序的合并是无法到达的，我们必须故意让一组变得稍微更糟，同时保持答案按字典顺序最小化。 

## 方法

 暴力方法会将每个排列视为一个图节点，并将每个操作视为一条边。 广度优先搜索最终会找到字典顺序最小的可达状态。 

这是正确的，因为每个可到达的排列都会被探索。 不幸的是状态空间包含$n!$排列。 即使是为了$n=10$，这已经完全不可行了。 

为了更快地获得某些东西，我们需要了解该操作实际上做了什么。 

获取当前位于奇数位置的元素的子序列并将其称为$O$。 在偶数位置上取子序列并调用它$E$。 

每个操作都会在内部执行一次相邻的交换$O$以及内部相邻的一个交换$E$同时地。 由于相邻交换生成整个对称组，因此我们可以任意重新排列奇数位置元素和任意偶数位置元素。 

然而，每个操作都为这两个组贡献了一次转置。 排列的奇偶性应用于$O$以及应用于的排列的奇偶性$E$总是一起改变。 

这意味着以下不变量成立：

 应用于奇数位置的排列和应用于偶数位置的排列必须具有相同的奇偶性。 

事实证明这是唯一的限制。 任何一对具有相等奇偶性的重排都是可以达到的。 

现在问题变成纯粹的组合问题。 

字典顺序最小的候选者是通过分别对奇数位置元素和偶数位置元素进行排序然后将它们合并回原来的位置来获得的。 

如果达到这些排序顺序所需的排列奇偶性相等，则该候选是可达的并且是最优的。 

如果奇偶校验不同，则无法联系到候选人。 我们必须改变一组的奇偶性。 最便宜的方法是交换已排序奇数组的最后两个元素或交换已排序偶数组的最后两个元素。 由于组已排序，因此更改最后两个元素会导致尽可能最小的字典损坏。 我们构造这两种可能性并选择较小的结果排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n!)$|$O(n!)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1.将奇数位置的元素提取到数组中`odd`并将偶数位置上的元素放入数组中`even`。 
2. 创建`odd_sorted`和`even_sorted`通过对这些数组进行排序。 
3. 计算变换后的排列的奇偶校验`odd`进入`odd_sorted`。 
4. 计算变换后的排列的奇偶校验`even`进入`even_sorted`。 
5. 如果两个奇偶校验相等，则合并`odd_sorted`和`even_sorted`返回交替位置并输出结果。 
6. 否则，创建两个候选答案。 

1.交换最后两个元素`odd_sorted`，然后合并。 
2. 交换最后两个元素`even_sorted`，然后合并。 
7. 输出字典顺序较小的候选者。 

最后两个元素的交换恰好翻转了一组的排列奇偶性。 由于奇偶校验不匹配恰好是一位，因此任一候选者都可以访问。 

### 为什么它有效

 每个操作在奇数位置子序列内执行一次转置，在偶数位置子序列内执行一次转置。 因此，两个导出排列的奇偶性始终相等。 

相邻转置产生所有排列，因此唯一的不变量是奇偶校验相等。 

分别对这两个组进行排序会产生尊重位置奇偶性的所有排列中字典顺序最小的排列。 如果其奇偶条件已经满足，则不存在更好的可达答案。 

当奇偶校验条件不成立时，我们必须改变一组的奇偶校验。 任何奇偶校验的改变都需要奇数排列。 从已排序的数组开始，通过交换其最后两个元素来获得按字典顺序排列的最小奇数排列。 这样做会尽可能晚地改变答案，从而最大限度地减少词典损坏。 比较奇数组修改和偶数组修改会产生最佳可达排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def permutation_parity(original, target_sorted):
    pos = {v: i for i, v in enumerate(target_sorted)}
    p = [pos[x] for x in original]

    n = len(p)
    vis = [False] * n
    parity = 0

    for i in range(n):
        if vis[i]:
            continue

        cur = i
        length = 0

        while not vis[cur]:
            vis[cur] = True
            cur = p[cur]
            length += 1

        parity ^= (length - 1) & 1

    return parity

def build(odd_vals, even_vals, n):
    res = [0] * n
    oi = 0
    ei = 0

    for i in range(n):
        if i % 2 == 0:
            res[i] = odd_vals[oi]
            oi += 1
        else:
            res[i] = even_vals[ei]
            ei += 1

    return res

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    odd = a[::2]
    even = a[1::2]

    odd_sorted = sorted(odd)
    even_sorted = sorted(even)

    p_odd = permutation_parity(odd, odd_sorted)
    p_even = permutation_parity(even, even_sorted)

    if p_odd == p_even:
        ans = build(odd_sorted, even_sorted, n)
    else:
        cand1_odd = odd_sorted[:]
        cand1_odd[-1], cand1_odd[-2] = cand1_odd[-2], cand1_odd[-1]
        cand1 = build(cand1_odd, even_sorted, n)

        cand2_even = even_sorted[:]
        cand2_even[-1], cand2_even[-2] = cand2_even[-2], cand2_even[-1]
        cand2 = build(odd_sorted, cand2_even, n)

        ans = min(cand1, cand2)

    print(*ans)
```该解决方案首先根据位置奇偶性拆分排列。 这是自然分解，因为操作永远不会在奇数位置和偶数位置之间移动元素。 

奇偶校验计算使用循环分解。 如果排列由长度循环组成$c_1,c_2,\dots$，其奇偶性等于$$(c_1-1)+(c_2-1)+\cdots \pmod 2.$$这让我们可以在线性时间内计算奇偶校验。 

重建步骤交替奇数位置列表和偶数位置列表中的元素。 由于Python使用从零开始的索引，索引`0,2,4,...`对应于原始问题中的奇数位置。 

最微妙的部分是奇偶校验情况。 交换排序组的最后两个元素会更改其奇偶性，同时导致尽可能小的字典顺序增加。

 ## 边缘情况

 考虑：```
4
3 2 1 4
```奇数位置包含`[3,1]`，甚至位置包含`[2,4]`。 

对两组进行排序可以得出：```
odd_sorted = [1,3]
even_sorted = [2,4]
```所需的排列奇偶性不同，因此这种合并排列是无法达到的。 

该算法交换一个已排序组的最后两个元素。 更好的候选人变成：```
1 4 3 2
```这正是可以达到的最优值。 

现在考虑：```
5
5 4 3 1 2
```排序后的奇数组和偶数组已经具有匹配的奇偶性。 无需修正。 该算法输出：```
2 1 3 4 5
```在所有可达排列中，按字典顺序排列是最小的。 

最后，考虑一个组只有两个元素的情况：```
4
4 1 3 2
```如有必要，奇偶校验修复操作会交换这两个元素。 该算法永远不会访问超出范围的位置，因为当$n \ge 4$，完全按照约束条件保证。
