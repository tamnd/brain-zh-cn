 ## 解决方案
 ## 问题理解

 我们被要求放置所有整数$0$到$n^2 - 1$进入一个$n \times n$网格，每个数字只使用一次。 构建网格后，我们考虑每个可能的子矩形并计算其 MEX，它是未出现在该子矩形内的最小非负整数。 目标是排列数字，使所有子矩形上的 MEX 值的总和尽可能大。 

思考这个问题的一个关键方法是，小的价值观具有不成比例的影响力。 一个子矩形至少贡献$k$仅当它包含来自的所有值时才求和$0$到$k-1$。 因此，小数字的放置几乎决定了一切，而大数字通常不会影响许多子网格的 MEX 值。 

输入由多个独立的测试用例组成，每个测试用例给出一个网格大小$n$。 全部的总和$n$跨测试用例最多 1000 个，所以我们可以负担得起$O(n^2)$每个测试用例的构建。 任何尝试显式评估子网格或计算每个子网格的 MEX 值的解决方案都是不可能的，因为有$O(n^4)$子矩形。 

天真的思维的一个微妙的失败案例是假设随机性或简单的按行填充就足够了。 例如，逐行填充$0,1,2,\dots$将小数字水平排列在一起，但忽略垂直紧凑性。 由于子矩形取决于两个维度，因此在两个轴上聚集小值比任何线性排序更重要。 

## 方法

 一个蛮力的想法是尝试所有的排列$n^2$数字并计算每种安排的 MEX 贡献总额。 即使我们可以计算出一种排列的分数$O(n^4)$，排列数为$(n^2)!$，这是完全不可行的。 

一旦我们重新解释增加 MEX 总和的因素，问题就变得容易处理。 每个整数$x$仅在包含所有数字的子矩形中做出积极贡献$0$通过$x$。 因此，为了最大化小值的贡献，我们希望它们出现在被尽可能多的子矩形覆盖的位置。 

位置处的单元格$(i,j)$正好包含在$i(n-i+1) \cdot j(n-j+1)$子矩形。 该值在网格中心最大化。 因此，最佳策略是将较小的数字放置在靠近中心的位置，将较大的数字放置在靠近边界的位置。 在所有网格中，重要的是我们从中心向外扩展的顺序，按照“覆盖贡献”递增的顺序分配数字。 

这导致了一种基于按距中心的距离对单元进行排序并贪婪地填充它们的构造：放置$0$在最“中心”的单元格中，那么$1$， 然后$2$， 等等。 这确保了数字的每个前缀都尽可能占据最有价值的区域，从而最大限度地增加包含小值的子矩形的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 |$O((n^2)! \cdot n^4)$|$O(n^2)$| 太慢了|
 | 中心向外贪婪放置 |$O(n^2 \log n)$或者$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们通过分配数字来构建网格$0$按“重要性”的降序排列向上到单元格，其中重要性是包含该单元格的子矩形的数量。 

1. 对于每个细胞$(i, j)$，计算其贡献$c(i,j) = i(n-i+1)\cdot j(n-j+1)$。 这测量了有多少个子矩形包含该单元格，因此它反映了它对于小数字的价值。 
2. 按降序对所有单元格进行排序$c(i,j)$。 如果两个单元格具有相等的值，则它们之间的任何顺序都可以，因为它们的贡献是对称的。 
3. 迭代排序列表并从以下位置开始赋值$0$，将每个下一个整数放入下一个最有价值的单元格中。 
4. 输出结果网格。 

我们明确计算覆盖范围的原因是 MEX 取决于有多少个子矩形同时包含所有小数字。 将少量数字放入高覆盖率单元格中可以最大化所有所需值一起出现的子矩形的数量。 

### 为什么它有效

 关键的不变量是在放置第一个之后$k$数，它们占据$k$具有最高子矩形覆盖率的单元格。 任何包含所有这些的子矩形$k$值必须与所有这些高覆盖率位置相交，因此最大化它们的单独覆盖率可以最大化贡献至少的子矩形的数量$k+1$墨西哥总和。 由于 MEX 总和可以分解为包含前缀的子矩形的计数$[0..x]$，以这种方式贪婪地优化每个前缀会产生全局最优的排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        cells = []
        for i in range(n):
            for j in range(n):
                # 1-indexed formula for subrectangle coverage
                x = (i + 1) * (n - i) * (j + 1) * (n - j)
                cells.append((x, i, j))
        
        cells.sort(reverse=True)
        
        grid = [[0] * n for _ in range(n)]
        
        val = 0
        for _, i, j in cells:
            grid[i][j] = val
            val += 1
        
        for row in grid:
            print(*row)

if __name__ == "__main__":
    solve()
```该构造计算每个单元格包含多少个子矩形。 这是关键的评分函数，因为它直接测量在那里放置一个小值影响子网格 MEX 的频率。 按此分数排序可确保首先填充中心单元格。 

该公式使用 1 索引坐标来避免差一错误：行中的单元格$i$（0-索引）是的一部分$(i+1)(n-i)$垂直线段端点的选择，对于柱也类似。 

一个常见的错误是忘记行和列的贡献是独立相乘的。 另一种方法是混合 0 索引和 1 索引公式，这会改变权重并破坏最佳排序。

 ## 边缘情况

 对于$n=1$，只有一个单元格和一个值。 该算法将覆盖率计算为$1$, 赋值$0$，并输出正确的平凡网格。 

对于甚至$n$，不存在单个中心小区，因此多个小区共享相同的最大覆盖范围。 该算法自然地处理这个问题，因为排序在关系下是稳定的，并且相等值之间的任何排序都不会影响正确性。 

对于大型$n$，覆盖率值可能会变大，但始终适合 Python 整数。 顺序保持一致，施工仍在进行$O(n^2 \log n)$，匹配约束无需修改。
