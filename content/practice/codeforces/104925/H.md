 ## 解决方案
 ## 问题理解

 我们得到一个带有指定源节点和汇节点的有向图。 我们不是选择一组离散的路径或整数流，而是为每条边分配一个实值流（可能为负），只要每个顶点的流守恒成立并且从源到汇的净流等于一个单位。 

成本模型是与经典最小成本流的关键背离。 每条边贡献的成本等于该边上流量的平方乘以正系数。 所以如果一条边承载流量$f_e$，它贡献$c_e f_e^2$到总成本。 目标是将一个单位的流量从节点 1 精确路由到节点 n，同时最小化这些二次边成本的总和。 

该图每个测试最多有 100 个顶点和 300 个边，并且多个测试用例的组合尺寸较小。 关键的含义是，任何立方体数量的顶点都可能是可接受的，但任何涉及流或路径的组合枚举的东西都是立即不可行的。 实值流和严格凸目标的存在表明解决方案将来自持续优化，而不是组合。 

一个微妙的方面是流量允许为负，这意味着我们不限于有向非循环的路由概念。 这将问题转化为由流守恒定义的线性子空间上的对称二次优化。 

一个天真的错误是考虑将单位流分割成路径并最小化路径上的总和。 但这失败了，因为分裂与平方边缘成本非线性相互作用。 

作为一种具体的失败案例，请考虑一个具有从 1 到 2 的两条平行边的图，两者的成本均为 1。通过一条边发送所有流会产生成本$1$。 平均分割给出每个边缘流$1/2$，因此成本变为$2 \cdot (1/4) = 1/2$，严格来说更好。 任何基于路径或不可分割的推理都会错误地建议成本 1 为最优。 

另一个常见的陷阱是假设最佳流量呈线性。 如果成本是线性的，那么解决方案将是最短路径。 在这里，凸性推动流量在多条路线上扩散，从根本上改变了结构。 

## 方法

 蛮力的观点是对待每个边缘流$f_e$作为变量并求解约束二次规划$m$变量和$n-1$线性约束。 直接写出它可以得到凸二次极小化：$$\min \sum c_e f_e^2 \quad \text{subject to } Af = b$$在哪里$A$编码流量守恒。 

直接数值解将尝试消除约束或应用通用凸求解器。 然而，完整 KKT 系统上的通用高斯消元法的大小大致为$m + n$，导致$O((n+m)^3)$每次测试的时间。 测试中总共有 400 个顶点和边，这仍然是边界，但只有在仔细实施并利用重用结构的情况下才可以接受。 

关键的观察结果是目标在边缘空间中是对角的，这意味着边缘之间不存在交叉项。 这使得 KKT 系统稀疏且结构化：它与图上的加权拉普拉斯系统完全对应。 这将问题转化为求解由基尔霍夫型定律导出的单个线性系统，其中边权重的行为类似于电阻$1/c_e$。 

一旦在物理上重新解释，每个边缘就像一个电阻器，其电导率与$c_e$，我们从源极注入一个单位的电流到汇极。 最佳流动正是电流，最小能量等于节点 1 和 n 之间的有效电阻，以对偶加权形式表示。 

因此，问题简化为求解拉普拉斯线性系统并提取由单元注入引起的电势差。

 ## 算法演练

 我们使用节点势重新解释流变量。 凸二次目标意味着最优性满足一阶条件：每个边流与其端点之间的电位差成正比。 

### 1.引入节点势

 分配潜力$x_u$到每个顶点。 对于边缘$u \to v$，最优性迫使流程满足$$f_{uv} = \frac{x_u - x_v}{2c_{uv}}.$$这来自于最小化$c_e f_e^2$关于$f_e$在与保护约束相关的拉格朗日乘子下。 

因素$2$与模归一化无关，稍后会被吸收。 

### 2.代入守恒定律

 在除源点和汇点之外的每个顶点，流守恒变为：$$\sum_{(u,v)} \frac{x_u - x_v}{c_{uv}} = 0.$$这正是一个加权拉普拉斯方程。 

### 3. 构建拉普拉斯系统

 构造矩阵$L$每条边的位置$u-v$我们增加重量$w = 1/c$。 然后：

-$L[u][u] += w$-$L[v][v] += w$-$L[u][v] -= w$-$L[v][u] -= w$然后我们修复：$$x_n = 0$$并在节点 1 处强制执行单位流注入，该节点成为右侧向量$b_1 = 1$,$b_n = -1$。 

### 4. 求解线性系统

 解决$L' x = b$拆下一行一列后（水槽接地）。 模运算的高斯消元法具有潜力。 

### 5. 计算答案

 一旦势能已知，能量就等于：$$\sum c_e f_e^2 = \sum \frac{(x_u - x_v)^2}{4c_e}.$$直接在所有边上计算。 

### 为什么它有效

 目标是严格凸的，约束是线性的，因此KKT条件是充分必要的。 平稳性条件将沿边二次惩罚转换为流与节点电位之间的线性关系。 这将系统折叠成拉普拉斯结构，该结构独特地表征了最佳流。 由于一旦参考节点固定，拉普拉斯系统就有唯一的解决方案，因此计算出的势与全局最小化器完全对应，并且所得流满足所有约束，同时最小化能量。

    L = [[0] * size for _ in range(size)]
    b = [0] * size

    def add_edge(u, v, c):
        w = 1 * modinv(c) % MOD
        if u != n:
            L[u-1][u-1] = (L[u-1][u-1] + w) % MOD

            L[v-1][v-1] = (L[v-1][v-1] + w) % MOD

            L[u-1][v-1] = (L[u-1][v-1] - w) % MOD

    for u, v, c in edges:
        add_edge(u, v, c)
