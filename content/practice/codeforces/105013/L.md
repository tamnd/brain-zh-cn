 ## 解决方案
 ## 问题理解

 有四名玩家，每个玩家恰好持有两张牌。 每张牌都有一个等级和花色。 在每场比赛中，每个玩家最终都会在第一轮中打出自己的两张牌中的一张，剩下的牌组成第二轮。 

该剧分两把戏进行。 在第一墩中，每个玩家选择他们的两张牌中的一张。 第一个玩家定义了主花色，只有与该花色相匹配的牌才有资格赢得该墩。 在这些合格的牌中，最高等级决定第一墩的获胜者。 如果玩家有一张牌不跟随主花，而他们确实有另一张牌跟随它，则该选择被视为无效，因为它违反了玩家必须能够在可能的情况下跟随的规则。 

第二把戏是用剩下的未使用的牌来玩的。 第一墩的获胜者将成为第二墩的主牌，并且紧随主花色之后的最高牌再次决定获胜者。 

根据指数奇偶性将选手分为两队：选手0和2属于高队，选手1和3属于杨队。 完整模拟的结果取决于哪支球队赢得第二局。 

中心任务不是模拟单一的固定玩法，而是考虑玩家选择第一张牌的所有有效方式，并确定高是否能保证有利的结果。 此外，还有一种特殊情况，即玩家的两张牌在点数和花色上都相同，这使得必须单独处理的退化但重要的获胜配置。 

如果存在有效的策略结构，使得无论规则下有效的玩法如何展开，Gao 都可以强制获胜，则输出为“Gao”，否则输出为“Yang”。 

即使没有明确说明，约束在结构上也很小，因为每个玩家只有两个选择。 第一轮选择的完整状态空间仅为$2^4 = 16$，并且每种配置都会导致对这两种技巧的确定性评估。 这立即排除了任何试图在没有修剪或结构的情况下以天真的方式对大型组合博弈树进行推理的方法，但也证实了枚举所有第一轮选择是完全可行的。 

主要的微妙之处在于第一招打法的有效性检查以及第二招对第一招结果的依赖性。 一个幼稚的解决方案可能会模拟单个贪婪分配，或者假设为每个玩家选择一张局部最优的卡牌就足够了，但这会失败，因为第一轮选择会影响合法性和第二轮结构。 

第二个微妙的问题是特殊的“对”情况，即玩家的两张牌是相同的。 在这种情况下，对称性会改变有效结果集，并允许立即获胜的配置，而这不会出现在通用模拟中。 

一个最小的陷阱例子是，当玩家拥有两张不同花色的牌时，只有一种选择保留了有效的跟花结构。 选择不正确可能会错误地建议有效的游戏状态，而实际上它违反了约束。 

## 方法

 直接的暴力方法是在第一墩中尝试对每个玩家两张牌中的一张进行所有可能的分配。 对于每个分配，我们检查分配在跟注约束下是否合法，确定第一墩的获胜者，然后使用剩余的牌模拟第二墩，并记录哪支球队获胜。 

由于每个玩家都有两个选择，因此$2^4 = 16$配置。 对于每种配置，计算这两个技巧是$O(4)$，因此完整的强力评估在复杂性上是微不足道的。 然而，真正的困难不是枚举，而是正确执行合法性约束：许多分配是无效的，因为玩家可能有一张应该打出的牌，但被忽略了。 

关键的观察是该问题不需要对指数决策树进行优化。 相反，它需要验证所有可能的第一轮结构，并确保每个有效的结构都能带来一致的团队结果。 这将问题转换为对所有掩模的有限验证，然后进行确定性模拟。 

第二个见解是，一旦第一个技巧被固定，第二个技巧就完全确定了，所以我们永远不需要进一步分支。 这将整个游戏折叠成每个掩模的两层评估。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | Brute Force（模拟所有没有结构的游戏）| O(2⁴·4) | O(1) | O(1) | 已接受 |
 | 掩模枚举+确定性模拟| O(16·4) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将每个玩家在第一个技巧中的选择视为 4 位掩码，其中每个位选择两张牌中的一张。 

1. 枚举第一轮牌的所有 16 种可能的分配方式。 每个作业代表了第一个技巧的候选玩法。 
2. 对于每项作业，根据跟随规则验证其是否合法。 我们将主花色固定为玩家 0 选择的牌的花色。 检查所有其他玩家，以确保如果他们在选择的牌中不遵循此花色，那么他们一定没有遵循该花色的有效替代方案。 当存在合法的跟牌时，这可以防止非法的“非同花”玩法。 
3. 如果分配无效，请立即丢弃它，因为它不会出现在有效的游戏中。 
4. 如果有效，则通过扫描所有跟风的玩家并选择其中最高排名来计算第一墩的获胜者。 该玩家成为第二墩的领导者。 
5. 使用剩余的牌（每个玩家未使用的牌）构建第二个技巧。 第二墩的花色来自第一墩获胜者的剩余牌。 
6. 从第一墩获胜者开始，按循环顺序模拟第二墩。 如果每个玩家可以打出主导花色中排名更高的牌，则他们会更新当前的获胜牌。 
7、确定第二局获胜者后，将获胜者索引映射到一个团队：玩家0和2组成高队，玩家1和3组成杨队。 
8. 记录这个结果是否对面具下的高有利。 如果任何有效的分配产生强制的高赢结构，答案就会变成“高”。 
9. 玩家持有两张相同牌的特殊情况需另行处理。 在这种情况下，检查是否存在一致的最高相同对结构来保证Gao优势。 

### 为什么它有效

 该算法依赖于这样一个事实：第一个技巧只有四个独立的二元决策。 每个合法的游戏状态都由这些分配中的一个完全捕获，一旦第一个技巧被修复，第二个技巧就是确定性的。 因此，正确性降低为所有可行初始状态的详尽覆盖。 由于无效状态被过滤掉，因此不可能的情况不会影响最终决策。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def winner_trick(cards, start, suit_pick):
    best = start
    best_rank = cards[start][suit_pick][0]
    suit = cards[start][suit_pick][1]

    for i in range(1, 4):
        idx = (start + i) % 4
        r, s = cards[idx][suit_pick]
        if s == suit and r > best_rank:
            best_rank = r
            best = idx
    return best

def simulate_second(cards, first_winner, choice_mask):
    used = choice_mask
    # remaining cards are flipped
    rem = [0 if (used >> i) & 1 else 1 for i in range(4)]

    start = first_winner
    best = start
    r, s = cards[start][rem[start]]
    best_rank = r
    suit = s

    for k in range(1, 4):
        i = (start + k) % 4
        r, s = cards[i][rem[i]]
        if s == suit and r > best_rank:
            best_rank = r
            best = i

    return best

def valid_mask(cards, mask):
    suit = cards[0][mask[0]][1]
    if cards[0][1 - mask[0]][1] == suit:
        pass

    for i in range(1, 4):
        chosen = mask[i]
        other = 1 - chosen
        if cards[i][chosen][1] != suit and cards[i][other][1] == suit:
            return False
    return True

def solve():
    cards = []
    for _ in range(4):
        a, b = input().split()
        cards.append([(int(a[0]), a[1]), (int(b[0]), b[1])])

    ok = False

    for mask in range(16):
        m = [(mask >> i) & 1 for i in range(4)]
        if not valid_mask(cards, m):
            continue

        first_winner = winner_trick(cards, 0, m[0])
        second_winner = simulate_second(cards, first_winner, mask)

        if second_winner % 2 == 0:
            ok = True

    # special pair case
    for i in range(4):
        if cards[i][0] == cards[i][1]:
            ok = True

    print("Gao" if ok else "Yang")

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```该解决方案将每个可能的第一招决策压缩为 4 位掩码。 合法性检查强制执行跟随约束，以便无效的游戏状态不会影响结果。 一旦掩码被接受，这两种技巧都会被确定性地模拟。 最后的奇偶校验将获胜者映射到高的团队中。 

特殊的同牌条件是单独处理的，因为它代表一种退化状态，其中跟随逻辑的行为不像正常分支，但仍然允许立即获胜配置。

 ## 边缘情况

 关键的边缘情况是当玩家有一张牌与主花色匹配而一张牌与主花色不匹配时。 如果算法在存在有效跟花的情况下错误地允许出非花牌，则会产生无效的胜牌。 掩码验证步骤通过拒绝存在后续替代方案但未被选择的任何配置来防止这种情况发生。 

另一个边缘情况是同一张卡的情况。 在没有明确检查的情况下，算法会将其视为正常的分支情况，但实际上它会破坏决策空间，并可以为高创造强制胜利。 最终检查确保此配置始终被单独考虑并正确分类。
