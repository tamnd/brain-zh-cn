 ## 解决方案
 ## 问题理解

 我们给定一个正整数$n$。 我们研究选择两个正整数的所有方法$p$和$q$这样他们的产品就可以划分$n$，另外还有$p \le q$。 对于每个有效对，我们计算一个值$r = \frac{p}{q}$。 任务是确定有多少个不同的理性值$r$可以出现在所有这样的对中。 

所以这个结构不是直接枚举除数，而是关于$n$以所有可能的方式，允许在不同的分解中重复，然后观察每个分解的两个部分之间的比率。 

该约束允许最多 2000 个测试用例，每个测试用例$n$可以大到$10^{10}$。 这立即排除了任何在没有额外结构的情况下以简单嵌套方式为每个测试用例枚举所有除数的方法。 一个典型的$O(\sqrt{n})$每个测试的因式分解是可以接受的，但任何接近的$O(n^{1/2} \cdot q)$必须仔细界定并有效实施。 

一个微妙的点是$p$和$q$不是独立选择的任意除数。 他们必须满足$pq \mid n$，这意味着它们的素数指数必须共同保持在指数预算内$n$。 一个天真的错误是将其视为选择任意两个除数$n$，这会超出无效对的计数，其中产品超过$n$。 

另一个常见的陷阱是假设比率$p/q$其行为类似于每个除数选择独立的除数比率。 素数指数之间的依赖关系是核心难点。 

## 方法

 暴力方法将枚举所有除数$n$，然后尝试所有对$(p, q)$并检查是否$pq \mid n$。 对于每个有效对，我们计算$p/q$并将其插入到集合中。 如果$d$是的约数$n$，这需要$O(d^2)$每个测试用例成对，并且检查可分性至少会增加恒定的开销。 自从$n$最多可以有大约$10^5$在最坏的情况下，这很快就在多个测试用例中变得不可行。 

关键的观察是条件$pq \mid n$是质因数的乘法。 如果我们写$$n = \prod p_i^{a_i},$$然后选择$p$和$q$对应于选择指数分割$x_i$和$y_i$这样$$x_i \ge 0, \quad y_i \ge 0, \quad x_i + y_i \le a_i.$$比率变为$$\frac{p}{q} = \prod p_i^{x_i - y_i}.$$这将问题转化为计算有多少个不同的指数向量$(x_i - y_i)$每个素数可以独立形成。 关键的简化在于，每个素数因子对最终乘积都有独立的贡献，因此不同比率的总数是每个素数可能的指数差的数量的乘积。 

对于带有指数的单个素数$a$，可实现值的集合$x - y$在下面$x + y \le a$结果是区间内的每个整数$[-a, a]$。 这意味着正好有$2a + 1$每个素数的选择。 

将这些贡献乘以所有素数即可得出答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对除数对的暴力破解 |$O(d^2)$每次测试 |$O(d)$| 太慢了|
 | 质因数指数 DP |$O(\sqrt{n})$每次测试 |$O(1)$额外 | 已接受 |

 ## 算法演练

 我们将问题简化为素因数分解和指数计数。 

1. 因式分解$n$进入其主要权力。 我们重复除以小整数，直到$\sqrt{n}$。 每次我们找到素数$p$，我们计算它的指数$a$。 此步骤是必要的，因为有效对的所有结构仅取决于这些指数。 
2. 对于每个素数指数$a$，计算该素数贡献的可能值的数量。 我们分析一下约束条件$x + y \le a$并考虑所有整数差异$x - y$。 可到达集合恰好是来自$-a$到$a$，所以这有助于$2a + 1$选择。 
3. 将所有贡献相乘。 每个素数独立作用，因此素数之间的组合形成选择的笛卡尔积。 
4. 输出每个测试用例的最终结果。 

### 为什么它有效

 正确性取决于两个结构事实。 一、条件$pq \mid n$在素数指数上完全分解，这意味着一对的可行性仅取决于每个素数指数的预算。 二、比例$p/q$与素数相乘，因此不同的素数在形成最终值时不会相互作用。 这种独立性确保每个有效的全局构造都唯一对应于独立的每个素数指数选择，并且每个素数有效差异的每个组合都会产生有效的全局比率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def factorize(n):
    factors = {}
    d = 2
    while d * d <= n:
        if n % d == 0:
            cnt = 0
            while n % d == 0:
                n //= d
                cnt += 1
            factors[d] = cnt
        d += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors

q = int(input())
for _ in range(q):
    n = int(input())
    f = factorize(n)
    ans = 1
    for a in f.values():
        ans *= (2 * a + 1)
    print(ans)
```因式分解步骤提取所有素数指数，这是其余计算所需的唯一信息。 循环除数直至$\sqrt{n}$是安全的，因为$n \le 10^{10}$。 

乘法步骤直接实现推导公式。 不存在超出处理范围的边界问题$n = 1$，其中因子列表为空，正确答案仍为 1。

 ## 边缘情况

 一个重要的边缘情况是$n = 1$。 这里没有质因数，因此因式分解步骤产生一个空集。 空集的乘积为 1，它正确对应于唯一可能的对$(1,1)$，给出比率 1。 

对于具体跟踪，输入$n = 1$:

 因式分解循环找不到除数，因此映射为空。 答案被初始化为 1 并且从未被修改。 输出为1。 

另一个边缘情况是当$n$是一个大素数。 然后因式分解产生一个指数$a = 1$，给出答案$2 \cdot 1 + 1 = 3$。 这些对应于$p/q \in \{1, p, 1/p\}$，匹配有效指数分割的完整枚举。
