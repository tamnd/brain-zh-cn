 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，两个玩家交替从中删除元素。 爱丽丝先开始。 每次玩家删除一个数字时，只有某些值实际上会影响他们的分数：爱丽丝仅从她选择的偶数中获得分数，而鲍勃仅从他选择的奇数中获得分数。 选择“错误的奇偶校验”仍然会删除该数字，但得分为零。 

当所有元素被消除后游戏结束，通过比较总分决定胜负。 

关键的困难在于，两个玩家都不仅仅是为自己贪婪地挑选。 每次移除都会影响未来的可用性，因此最佳游戏必须考虑剥夺对手的好机会以及最大化个人收益。 

测试用例中的输入大小最多达到 2·10^5 总元素。 这立即排除了所有可能的移动序列的任何模拟。 完整的博弈树方法将在每一步进行分支并逐级增长，这远远超出了可行的限制。 由于指数状态空间，即使是子集上的 DP 也是不可能的。 

重要的观察是，规则仅取决于数字是偶数还是奇数，并且仅取决于它对分数有贡献的值。 这意味着结构可以大大简化。 

当所有数字都属于一个奇偶校验类别时，就会出现一种微妙的边缘情况。 例如，如果所有数字都是奇数，那么爱丽丝永远不会获得任何东西，而鲍勃会收集他选择的所有东西。 尝试模拟“最佳阻止”的幼稚方法可能仍然错误地假设 Alice 可以干扰，但她无法在有意义的评分意义上改变 Bob 对奇数的访问。 同样，如果所有数字都是偶数，则鲍勃的分数始终为零。 

当最大的数字属于玩家的“错误”奇偶校验时，就会出现另一种边缘情况。 例如，爱丽丝选择一个大的奇数并不能帮助她得分，而是将其从鲍勃的潜在收益中删除。 这就产生了一种权衡，除非奇偶分离是明确的，否则仅靠价值贪婪方法可能会处理不当。 

## 方法

 暴力解决方案将模拟所有可能的动作。 在每一回合，玩家选择任何剩余的元素，根据奇偶性更新分数，然后递归。 这正确地模拟了游戏，因为它尝试了所有可能的决策路径。 然而，每个状态最多有 O(n) 个选择和深度 n，导致大约 n！ 可能的序列。 即使使用记忆化，状态空间也是具有回合信息的剩余元素的多重集，这是一个天文数字。 

关键的简化来自于认识到，只有当数字作为得分动作收集时，其实际值才重要。 否则，这只是一个阻挡之举。 这建议将数字分成两个独立的有序池：偶数和奇数。 每个玩家只能从这些池子之一中受益。 

现在，游戏变成了一场谁能更有效地从每个池中挑选的竞争。 由于两名玩家总是喜欢更高的得分机会，因此最佳游戏减少为考虑每个奇偶组内的排序顺序。 玩家有效地轮流消耗剩余的最佳可用值，但只有相关的奇偶性才有助于他们的得分。 

一个关键的结构见解是，所有决策都简化为选秀顺序，而最佳游戏相当于在轮流交替时按降序处理数字，得分更新取决于奇偶角色对齐。 

这完全消除了博弈树的复杂性，并用单个排序遍历代替。

 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最优（排序+贪心模拟）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

1. 将数组分为偶数和奇数，并将整个数组按降序排序。 

排序确保两个玩家总是首先面对最有价值的剩余选择，这是必要的，因为较低的值永远不会在以后变得更好。 
2. 初始化两个分数计数器：AliceScore 和 BobScore，均从零开始。 

这些仅跟踪有效收益，因为非得分动作仍会影响未来的可用性，但不会影响总数。 
3. 迭代排序后的数组，将每个位置视为严格交替的一个回合，从 Alice 开始。 

这反映了最佳的游戏结构：由于玩家每回合总是移除一个元素，因此回合顺序是固定的。 
4. 在 Alice 的回合中，如果当前数字是偶数，则将其添加到 AliceScore 中。 否则什么也不做。 

Alice 永远不会从奇数中受益，所以选择它们纯粹是防御性的。 
5. 在 Bob 的回合中，如果当前数字是奇数，则将其添加到 BobScore 中。 否则什么也不做。 

鲍勃以相反的奇偶性反映了爱丽丝。 
6. 处理完所有要素后，比较分数并据此宣布获胜者。 

重要的隐含思想是，无论奇偶偏好如何，最佳游戏总是按降序消耗数字。 任何偏差都会让对手在下一回合中获得更高的值，这绝对更糟糕，因为分数仅取决于收集的值而不是时间。 

### 为什么它有效

 不变量是，在 k 次移动之后，k 个最大的剩余数字已按照与最佳游戏一致的某种顺序被删除，并且没有玩家可以通过延迟或跳过更高值的数字来改善其结果。 由于评分仅取决于奇偶匹配选择的所有权，因此最佳策略简化为将每个排序元素确定性分配给一个回合，而不需要考虑替代分支。 

任何尝试获取较小数字而留下较大数字的尝试都会让对手在下一步行动中获得更大的数字，这只能增加对手的最佳得分或减少你自己的得分。 因此，贪婪排序在最优游戏下是稳定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        a.sort(reverse=True)
        
        alice = 0
        bob = 0
        
        for i, x in enumerate(a):
            if i % 2 == 0:
                if x % 2 == 0:
                    alice += x
            else:
                if x % 2 == 1:
                    bob += x
        
        if alice > bob:
            out.append("Alice")
        elif bob > alice:
            out.append("Bob")
        else:
            out.append("Tie")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案首先按降序对每个测试用例进行排序，以便首先解决最高值的选择。 然后循环使用索引奇偶校验交替轮流。 自 Alice 开始以来，偶数索引对应于 Alice，奇数索引对应于 Bob。 每个玩家只有当奇偶条件符合他们的计分规则时才累积分数。 

一个微妙的实现细节是我们没有显式地模拟删除。 排序数组隐式表示最佳播放下的删除顺序，因此索引遍历完全取代了有状态删除。 

## 工作示例

 ### 示例 1

 输入：```
4
5 2 7 3
```排序后的数组是`[7, 5, 3, 2]`。 

| 步骤| 转| 精选| 爱丽丝分数 | 鲍勃分数 |
 | ---| ---| ---| ---| ---|
 | 1 | 爱丽丝| 7 | 0 | 0 |
 | 2 | 鲍勃 | 5 | 0 | 5 |
 | 3 | 爱丽丝| 3 | 0 | 5 |
 | 4 | 鲍勃 | 2 | 0 | 5 |

 Alice 永远不会获得分数，Bob 则获得 5 分和 2 分。Bob 获胜。 

这表明大的奇数值对 Bob 比对 Alice 更有价值，并且按值排序可确保 Bob 在可能的情况下捕获它们。 

### 示例 2

 输入：```
3
3 2 1
```排序后的数组是`[3, 2, 1]`。 

| 步骤| 转| 精选| 爱丽丝分数 | 鲍勃分数 |
 | ---| ---| ---| ---| ---|
 | 1 | 爱丽丝| 3 | 0 | 0 |

 | 3 | 爱丽丝| 1 | 0 | 0 |

 两名选手均无所得，结果打成平局。 

这凸显了一种边界情况，即尽管比赛不平凡，但平局完全抵消了得分。

 ## 边缘情况

 完全偶数数组，例如`[2, 4, 6]`导致 Alice 收集所有值，无论顺序如何。 排序不会改变结果，但可确保确定性处理。 鲍勃的得分始终为零，因此爱丽丝以总和获胜。 

一个全奇数数组，例如`[1, 3, 5]`给鲍勃所有有效点，因为只有鲍勃从奇数选秀权中受益。 Alice 的动作仅删除元素，而不会影响得分，因此 Bob 在最终总和中占主导地位。 

像这样的混合数组`[10, 1, 9, 2]`演示值排序和奇偶校验分配之间的交互。 分选率`[10, 9, 2, 1]`，并且交替轮次根据轮次对齐将高值奇数分配给 Bob，将高值偶数分配给 Alice。 这证实了排序是预测结果所需的唯一结构性因素。 

单元素数组总是发给 Alice，因为她先移动。 如果元素是偶数，她就得分，否则游戏立即结束，鲍勃无法做出反应，使爱丽丝至少在所有情况下都不会失败。
