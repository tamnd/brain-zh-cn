 ## 解决方案
 # 问题理解

 给定一个有向图，其顶点为城市，根为城市 1（首都）。 对于每个城市$v$， 定义$d[v]$作为从城市 1 到城市的最短路径长度$v$。 这些距离是固定的，并且可以从图中隐式得知。 

波利卡普从某个城市出发$s$。 当站在城市$u$，他可以沿着任何出边移动$(u,v)$。 限制是在所有目的地没有较大 BFS 距离的移动中，这意味着$d[v] \le d[u]$，他在整个旅程中最多只能使用一个这样的动作。 

移动到严格更大的 BFS 级别，这意味着$d[v] > d[u]$，可以使用任意多次。 

对于每个起始城市$i$，我们必须确定从以下位置开始的某个有效旅程可以达到的最小 BFS 距离值$i$。 

该图最多可以包含$2 \cdot 10^5$所有测试用例的顶点和边。 任何从每个顶点开始单独的图搜索的解决方案都需要大约$O(n(n+m))$在最坏的情况下工作，这远远超出了极限。 总输入大小强烈表明每条边应该只处理恒定的次数。 

有几种情况使问题比标准最短路径问题更加微妙。 

考虑：```
1 -> 2 -> 3
^         |
|_________|
```BFS 距离为$0,1,2$。 从城市3开始，我们可以使用我们的单一非增移动$3 \to 1$，立即到达距离0。 只沿着边缘走向更大 BFS 级别的解决方案会错过这一点。 

考虑：```
1 -> 2 -> 3 -> 4
     ^         |
     |_________|
```该循环允许通过后沿进行后续改进。 如果我们以任意顺序处理顶点，动态规划值在需要时可能会不完整。 

考虑：```
1 -> 2
1 -> 3
2 -> 4
3 -> 4
4 -> 2
```顶点 4 具有到顶点 2 的后边。即使 4 在 BFS 树中更深，它仍然可以达到距离 1。仅向下传播信息的朴素 DFS 会计算出错误的答案。 

# 方法

 蛮力方法将为每个起始城市独立计算答案。 我们可以将状态建模为$(u, used)$， 在哪里`used`指示单个非增加移动是否已被花费。 从每个起始顶点，我们对这些状态运行图搜索并记录遇到的最小距离。 

这是有效的，因为状态图与问题规则完全匹配。 不幸的是有$2n$每次搜索的状态，我们将重复搜索$n$次。 复杂度变为$O(n(n+m))$，大约达到$4 \cdot 10^{10}$最坏情况下的操作。 

关键的观察结果来自 BFS 距离。 

让$d[v]$是距城市 1. 任意边的最短距离$(u,v)$属于两个类别之一。 

如果$d[v] > d[u]$，边缘在 BFS 级别上严格向前移动。 

如果$d[v] \le d[u]$，边缘是消耗单个允许异常的特殊类型。 

假设我们站在顶点$u$。 如果我们立即使用非增边$(u,v)$，那么我们可以立即获得距离$d[v]$。 如果我们取而代之的是向前优势$(u,v)$，我们仍然保留稍后的例外，因此可以从以下位置获得最佳答案$v$也可以从$u$。 

这表明动态规划递归。 

让`ans[u]`是从以下位置可获得的最小 BFS 距离$u$。 

最初，每个顶点至少可以立即停止，所以`ans[u] = d[u]`。 

对于边缘$(u,v)$：

如果$d[v] \le d[u]$，然后使用该边作为异常立即给出候选值$d[v]$。 

如果$d[v] > d[u]$，然后移动到$v$保留所有未来的选择，赋予候选人价值`ans[v]`。 

递归变为：$$ans[u] = \min \left( d[u], \min_{d[v]\le d[u]} d[v], \min_{d[v]>d[u]} ans[v] \right)$$现在，由前向边引起的图相对于 BFS 距离是非循环的，因为每个这样的边都严格增加$d$。 这意味着我们可以按照 BFS 距离降序计算答案，或者等效地使用首先处理更深层次的 DFS 记忆。 

这将图上的整个计算减少为一个 BFS 和一个基于 DFS 的 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n(n+m))$|$O(n+m)$| 太慢了|
 | 最佳 |$O(n+m)$|$O(n+m)$| 已接受 |

 # 算法演练

 1. 从城市 1 运行 BFS 并计算最短距离数组`dist`。 
2、创建DP阵列`ans`并将所有值初始化为`-1`。 
3. 定义`dfs(u)`作为从顶点可到达的最小 BFS 距离`u`。 
4. 开始于`best = dist[u]`因为波利卡普可能会立即停止。 
5. 检查每个出边`(u,v)`。 
6. 如果`dist[v] <= dist[u]`，该优势可以作为单一必杀技。 更新：$$best = \min(best, dist[v])$$异常会立即消耗，因此只有目的地距离很重要。 

1.如果`dist[v] > dist[u]`，移动在 BFS 层中进行。 更新：$$best = \min(best, dfs(v))$$异常仍然可用，因此每个选项都可以从`v`也可以从`u`。 

1. 将结果存储在`ans[u]`并归还它。 
2. 跑步`dfs(i)`对于每个顶点。 
3. 输出所有计算出的答案。 

### 为什么它有效

 BFS 距离将每条边划分为前向边或非递增边。 

非增加边正是可以消耗单个异常的移动类型。 在取得这样的边缘之后，未来的移动无法将答案改进到超出其端点已达到的最小 BFS 距离，因此递归使用`dist[v]`。 

前向边沿不消耗异常。 开始于`u`并且采取这样的边缘相当于从`v`所有选项仍然可用。 因此`ans[v]`是有效的候选人。 

由于前向边缘总是会增加 BFS 距离，因此递归依赖关系只会从较小的距离到较大的距离。 这些依赖关系之间不能存在循环，因此递归是明确定义的。 每个有效的旅程都是从停止、采用不增加的边缘或采用向前的边缘开始的。 递归考虑了所有三种可能性，因此产生的最小值正是最佳答案。 

# Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

t = int(input())

for _ in range(t):
    line = input().strip()
    while line == "":
        line = input().strip()

    n, m = map(int, line.split())

    g = [[] for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)

    dist = [-1] * n
    dist[0] = 0

    q = deque([0])

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    ans = [-1] * n

    def dfs(u):
        if ans[u] != -1:
            return ans[u]

        best = dist[u]

        for v in g[u]:
            if dist[v] <= dist[u]:
                best = min(best, dist[v])
            else:
                best = min(best, dfs(v))

        ans[u] = best
        return best

    for i in range(n):
        dfs(i)

    print(*ans)
```解决方案从首都的 BFS 开始。 这将计算问题所需的最短路径距离，并将每条边分类为递归使用的两个类别之一。 

DFS直接实现动态规划关系。 记忆数组`ans`保证每个顶点都被解决一次。 当一条边到达具有较大 BFS 距离的顶点时，递归会继续，因为异常仍然未使用。 当一条边到达相等或更小的距离时，异常可以立即被花费，所以只有`dist[v]`很重要。 

递归是安全的，因为依赖关系仅遵循严格递增的 BFS 级别。 这样的边不能形成环。 显式递归限制避免了长链上的堆栈溢出。

 # 边缘情况

 考虑一个仅由链组成的图：```
1 -> 2 -> 3 -> 4
```BFS 距离为`0 1 2 3`。 每条边都会进入更大的 BFS 级别。 DFS 递归永远不会找到不增加的边缘，因此每个答案都保持其自己的距离。 输出是：```
0 1 2 3
```考虑一个具有直接后边的图：```
1 -> 2 -> 3
^         |
|_________|
```距离是`0 1 2`。 在顶点 3 处，回到 1 的边满足`dist[1] <= dist[3]`，所以答案立即变为 0。这种改进通过递归传播，给出：```
0 0 0
```考虑一个包含同一 BFS 级别的顶点之间的边的图：```
1 -> 2
1 -> 3
2 -> 3
```距离是`0 1 1`。 边缘`2 -> 3`满足`dist[3] <= dist[2]`，所以它算作特殊动作。 该算法正确地以与后边缘相同的方式处理等距离边缘，从而防止错误地假设只有严格较小的距离才重要。 

考虑一个图表，其中最好的改进发生在几次向前移动之后：```
1 -> 2 -> 3 -> 4
          |
          v
          1
```顶点 2 无法直接达到较低的 BFS 级别。 它的最佳路径首先沿着前缘到达 3，然后使用特殊移动。 递归通过以下方式捕获了这一点`ans[3]`，它传播回`ans[2]`。 这正是 DP 必须使用的原因`ans[v]`前向边缘而不仅仅是本地信息。
