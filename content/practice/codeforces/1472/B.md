 ## 解决方案
 ## 问题理解

 我们有一系列糖果，每颗糖果重 1 克或 2 克。 爱丽丝和鲍勃想要平分糖果，以便他们每个人收到的总重量完全相同。 每个测试用例的输入给出了糖果的数量及其各自的重量。 如果可以公平分割，则输出简单地为“是”，否则输出为“否”。 

问题约束告诉我们每个测试用例的糖果数量，\(n\)，最多为 100，但最多可以有 10,000 个测试用例。 所有测试用例中的糖果总数不超过 100,000 个。 这意味着如果我们想适应 2 秒的时间限制，我们不能承受比每个测试用例 O(n) 更糟糕的事情，因为操作范围为\(10^8\)通常都很好，但是\(10^9\)在 Python 中可能会很紧张。 

因为糖果不能分开，所以出现了一个微妙的问题。 即使权重总和是偶数，也并不总是足以保证公平的分配。 例如，三颗糖果的重量分别为 2 克、1 克和 2 克，总和为 5，这是奇数，因此立即不可能。 粗心的解决方案可能只是检查总和是否为偶数，这在某些边缘情况下会失败，例如只有一颗重量为 2 的糖果或总和偶数的组合，但使用可用的 1 克和 2 克糖果无法平衡分布。 

边缘情况包括只有 1 克糖果、只有 2 克糖果、总重量为奇数，以及总重量为偶数但 1 克糖果数量为奇数的组合。 这些会影响形成两个相等子集的能力，因此我们必须仔细推理总和的奇偶性以及每种糖果类型的计数。 

## 方法

 暴力方法是尝试所有可能的糖果子集，并检查任何子集的总和是否为总重量的一半。 这相当于子集和问题。 对于 n=100 的单个测试用例，子集的数量为\(2^{100}\)，这是一个天文数字，因此完全不切实际。 即使使用动态编程方法来检查总权重除以 2 的总和也需要 O(n * sum(weights))，每个测试用例可能高达 200。 这是可以接受的，但我们可以通过简单的算术推理做得更好。 

关键的观察结果是只有两种糖果类型。 让\(c_1\)是 1 克糖果的数量，\(c_2\)是 2 克糖果的数量。 总重量为\(c_1 + 2 c_2\)。 为了公平分配，总数必须相等。 此外，如果总权重是偶数，那么挑战就减少到形成总和等于总数一半的子集。 因为我们只能选择整数的1克和2克糖果，总重量的一半，称之为\(S\)，必须可以使用以下组合来实现\(c_1\)那些和\(c_2\)两两。 只有当 S 是奇数并且没有 1 克糖果来调整奇偶性时，这才是不可能的。 换句话说，如果总重量是奇数，则答案为“否”。 如果总重量为偶数，则答案为“是”，除非 S 为奇数且没有 1 克糖果使其成为奇数，在这种情况下答案为“否”。 

这种见解允许使用 1 和 2 的计数对每个测试用例进行非常简单的 O(1) 检查。 我们不再需要迭代子集或使用动态编程。

 |---|---|---|---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取 n 和糖果重量列表。 
2. 数一下1克糖果的数量，\(c_1\)，以及 2 克糖果的数量，\(c_2\)。 这一步为我们提供了推理总和分布的关键数据。 
3. 计算总重量\(T = c_1 + 2 c_2\)。 如果\(T\)是奇数，输出“NO”，因为不可能公平分割。 
4. 如果\(T\)是偶数，计算总数的一半，\(S = T / 2\)。 这是两个子集之一的目标总和。 
5. 检查使用可用的 2 克糖果是否可以实现 S。 令k为S // 2和c_2中的最小值，即我们可以使用的2克糖果的最大数量而不超过S。 
6. 减去2克糖果所贡献的重量，\(2 k\)，来自S。如果剩余重量可以被1克糖果恰好覆盖，即如果S - 2 k ≤ c_1，则输出“YES”。 否则，输出“NO”。 

为什么有效：该算法保证了正确性，因为我们总是选择尽可能多的 2 克糖果，但不超过总数的一半，这减少了 1 克糖果覆盖的剩余金额。 因为权重只有 1 和 2，所以任何可达到的总和都是这两者的组合，所以这种贪心选择就足够了。 奇偶校验确保当总和为奇数时我们永远不会尝试不可能的分割。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_divide(weights):
    c1 = weights.count(1)
    c2 = weights.count(2)
    total = c1 + 2 * c2
    if total % 2 != 0:
        return "NO"
    half = total // 2
    # use as many 2s as possible without exceeding half
    max_twos = min(c2, half // 2)
    remaining = half - 2 * max_twos
    if remaining <= c1:
        return "YES"
    return "NO"

t = int(input())
for _ in range(t):
    n = int(input())
    weights = list(map(int, input().split()))
    print(can_divide(weights))
```该代码计算每个测试用例中 1 和 2 的数量。 它立即拒绝奇数总和。 对于偶数总数，它贪婪地用尽可能多的 2 克糖果填充总和的一半，并检查是否可以用 1 克糖果组成剩余的总和。 使用 min(c2, half // 2) 可以避免超出目标总和。 该解决方案可以有效地处理多个测试用例并避免不必要的迭代。
