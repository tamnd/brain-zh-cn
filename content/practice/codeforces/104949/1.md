 ## 解决方案
 ## 问题理解

 我们得到了一个飞机客舱的简化模型，其中座位按行排列，每行包含六个座位，从左到右索引。 每排中间是第三和第四座位之间的固定过道。 由于这种对称性，左侧的每个座位在同一排的右侧都有一个镜像对应的座位。 

一些座位已经被占用，并且只有当每个被占用的座位都有其镜像伙伴也被占用时，配置才被认为是有效的。 换句话说，对于每个已满的位置，过道对面的对称座位也必须已满。 如果这种对称性在任何地方被破坏，则该配置无效。 

任务是确定当前的座位安排是否满足这个对称条件。 

输入描述了多排座位，每排恰好包含六个位置。 输出是一个简单的二元决策，指示整个座位计划是否遵循镜像对称规则。 

这些约束意味着我们正在处理每行固定宽度的结构，因此任何检查每个座位的解决方案都直接在网格大小上以线性时间运行。 即使对于大量行，这仍然有效，因为每行仅贡献恒定数量的检查。 

主要边缘情况是当座位被占用但其镜像位置未被占用时。 例如，在单行中：

 输入：```
X . . . . .
```这是无效的，因为第一个座位已被占用，但其对称伙伴（第六个座位）是空的。 正确的配置需要两端匹配。 

另一个微妙的情况是当对称性在一行内成立但在多行上失败时。 每行必须独立满足条件； 全局正确性取决于所有通过的行。 

## 方法

 暴力破解的想法很简单：对于每一排的每个座位，检查其镜像座位是否也被占用。 这需要扫描所有行和每行的所有六个位置，并通过直接比较验证对称性。 由于每行的大小恒定，因此该方法的运行时间与行数呈线性关系。 

关键的观察结果是行之间没有交互。 对称约束对于每行来说都是完全局部的，因此我们永远不需要传播信息或维护超出单行的状态。 这消除了对复杂数据结构或贪婪决策的任何需要。 该问题简化为对固定索引对的直接验证检查。 

因为每排只有六个座位，所以我们可以对前三个位置进行硬编码或循环，并与它们的镜像对应位置进行比较。 该问题变成了一个简单的一致性检查，而不是一个搜索或优化问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力逐行对称性检查 | O(n) | O(1) | O(1) | 已接受 |
 | 与显式配对优化相同 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每一行，因为对称性永远不会跨行。 对于每一排，我们只需要比较围绕中心过道镜像的座位位置。 

1. 读取行数，然后将每行处理为长度为 6 的字符串。 每个字符代表座位是否有人或空着。 
2. 对于给定的行，将座位 0 与座位 5、座位 1 与座位 4、座位 2 与座位 3 进行比较。这些是唯一有意义的比较，因为它们只覆盖了所有镜像对一次。 
3. 如果任何对的占用状态不同，则立即断定配置无效。 我们可以提前停止，因为一次违规就会破坏全局对称性。 
4. 如果所有行都通过此检查，则配置有效。 

我们只检查三对的原因是每一行完全由这些镜像关系决定。 超出这些范围的检查会重复工作而不添加新信息。 

### 为什么它有效

 每行都是独立的，并且通过配对索引 j 和 5 − j 在行内严格定义对称性。 如果所有这样的配对在每一排中都匹配，则每个占用的座位都有其所需的镜像伙伴。 相反，如果任何一对不同，则该座位直接违反条件。 这使得检查对于正确性来说既必要又充分。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    for _ in range(n):
        row = input().strip()
        
        if row[0] != row[5]:
            print("NO")
            return
        if row[1] != row[4]:
            print("NO")
            return
        if row[2] != row[3]:
            print("NO")
            return
    
    print("YES")

if __name__ == "__main__":
    solve()
```该解决方案读取每一排并立即检查三个镜像座椅对。 提前退出很重要，因为一旦发现不匹配，就无需继续扫描剩余的行。 

索引是固定且安全的，因为每行都保证恰好有六个字符。 除了确保正确的字符串长度解析之外，不存在任何边界问题。

 第一行已经违反对称性，因为位置 0 已被占用，但位置 5 未被占用。 算法立即停止并输出NO。 

这表明在第一次检测到不一致时就提前终止。

 输入：```
2
X.. ..X
.XX XX.
```第 1 行：

 所有镜像对都匹配，因此通过。 

第 2 行：

 所有镜像对也都匹配。 

| 行| (0,5) | (1,4) | (2,3) | 结果 |
 | --- | --- | --- | --- | --- |

 这里第二行在最后一对处失败，因此完整输出为“否”。 

这表明即使早期的行有效，后面的违规仍然会使配置无效。

 ## 边缘情况

 一种微妙的边缘情况是，一行中只有一对破坏对称性，而其他对则正确。 例如：

 输入：```
1
X...X.
```检查对：

 0 vs 5 会立即失败，即使一旦存在违规，其他对就无关紧要。 该算法在第一个不匹配处正确停止并输出“否”。 

另一种情况是一个完全空的船舱：

 输入：```
4
......
......
......
......
```每次比较都会通过，因为所有对都相等。 该算法处理所有行并输出 YES，确认没有占用的座位仍然是有效的对称配置。
