 ## 解决方案
 ## 问题理解

 我们得到了 3D 空间中八个点的集合，但这些信息是故意不可靠的：在每个点内，三个坐标可能已被任意排列。 因此，每一行都为我们提供了三个整数的多重集，而不是固定的 (x, y, z) 顺序。 

任务是决定是否可以为每个点内的坐标分配一个顺序，以便所得的八个顶点在 3D 空间中形成一个完美的立方体。 如果可能的话，我们必须输出与给定的打乱行一致的立方体顶点的任何有效重建。 

关键的困难在于我们不仅仅是检查固定点上的几何条件。 我们同时选择每个点的坐标分配并验证全局刚性结构。 立方体约束将所有八个点耦合在一起，因此对各个点的局部推理是不够的。 

输入大小很小并且固定为八个点，这立即表明指数或基于排列的推理是可以接受的。 即使我们每个点独立尝试所有作业，我们最多也得到$3^8 = 6561$配置，并且实际上由于修剪对称性而更少。 这完全在时间限制之内。 

仅仅简单的几何检查是不够的，因为每条线内部的模糊性可能隐藏有效的立方体排列。 例如，这两行：

 输入：```
0 1 2
2 1 0
```可以以不同的坐标顺序表示相同的点分配。 将每条线视为固定点的粗心方法会拒绝有效的立方体或接受无效的立方体。 

另一种微妙的失败情况是当多个排列满足部分约束但只有一个全局分配形成一个立方体时。 例如，局部一致的边长度可能仍然无法在全局范围内生成恰好 12 条相等的边。 

因此，核心挑战是对坐标分配的搜索与立方体的几何验证相结合。 

## 方法

 暴力解决方案独立处理八个点中的每一个。 对于每个点，我们尝试其坐标的所有六种排列，因为每个点都是值的三重。 这会产生$6^8 = 1{,}679{,}616$最坏情况下的总作业量。 

对于每个完整的作业，我们检查所得的八个点是否形成一个立方体。 3D 空间中的立方体可以使用距离进行验证：在 28 个成对的平方距离中，有效的立方体必须恰好具有两个不同的值，一个对应于边，一个对应于对角线，并且具有正确的重数。 我们可以计算所有平方距离$O(8^2)$并验证计数。 

这种蛮力方法已经是边缘性的，但仍然可行，因为这里不需要 Python 优化，因为约束非常小。 

简化推理的关键观察是，问题首先不是关于几何，而是关于约束分配。 一旦坐标固定，立方体验证就是确定性的。 因此，问题简化为使用强大的结构过滤器搜索排列。 

我们不是试图预先巧妙地利用几何，而是依赖于搜索空间很小并且正确性来自于详尽探索的事实。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力排列 + 验证 |$O(6^8 \cdot 8^2)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将每个输入行建模为三个数字的列表，其顺序未知。 我们必须在所有点上一致地将它们分配给 x、y、z。 

1. 对于 8 个点中的每一个，生成其坐标的所有 6 种排列。 每个排列代表该点在 3D 空间中的可能位置。 此步骤枚举局部解释，而不致力于全局结构。 
2. 对这 8 个点执行深度优先搜索。 在每个级别，为当前点选择一种排列并继续前进。 这逐渐构建了一个由 8 个具体点组成的候选集。 
3. 当所有 8 个点都分配完毕后，计算所有成对平方欧氏距离。 对于 8 个点，有 28 个距离。 存储它们的频率。 
4. 验证这些距离是否与立方体的结构匹配。 在立方体中，顶点之间恰好有 3 种不同的距离：边、面对角线和空间对角线，但立方体本身的顶点之间只出现两种距离（非相邻顶点之间的边和对角线）。 正确的图案对应于 12 个相等的最小距离（边缘）和 12 个相等的较大面对角线距离，且比例一致。 
5. 如果找到有效的结构，则立即输出相应的指定坐标。 

搜索在第一个有效配置处停止。 

### 为什么它有效

 每个有效的立方体嵌入都对应于每个输入点的一个一致的排列分配。 DFS 枚举所有可能的分配，因此保证真实的多维数据集配置出现在搜索空间中（如果存在）。 距离检查是立方体几何形状直至刚性变换的完整表征，因此无效配置无法通过过滤器。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from itertools import permutations

def dist2(a, b):
    return (a[0] - b[0])**2 + (a[1] - b[1])**2 + (a[2] - b[2])**2

def is_cube(points):
    d = []
    n = len(points)
    for i in range(n):
        for j in range(i + 1, n):
            d.append(dist2(points[i], points[j]))

    d.sort()
    from collections import Counter
    c = Counter(d)

    if len(c) != 3:
        return False

    vals = sorted(c.items())  # (distance, count)

    # Cube should have 12 edges, 12 face diagonals, 4 space diagonals
    # between vertices: actually for 8 vertices:
    # edges: 12, face diagonals: 12, space diagonals: 4

    return sorted([cnt for _, cnt in vals]) == [4, 12, 12]

def dfs(i, chosen, perms, res):
    if i == 8:
        if is_cube(chosen):
            res.extend(chosen)
            return True
        return False

    for p in perms[i]:
        chosen.append(p)
        if dfs(i + 1, chosen, perms, res):
            return True
        chosen.pop()

    return False

def main():
    pts = [list(map(int, input().split())) for _ in range(8)]
    perms = [list(set(permutations(p))) for p in pts]

    res = []
    dfs(0, [], perms, res)

    for x in res:
        print(*x)

if __name__ == "__main__":
    main()
```该程序首先为每个点构造所有有效排列。 使用`set(permutations(...))`当坐标重复时避免重复。 

DFS 增量构建候选多维数据集。 一旦选择了所有八个点，`is_cube`函数使用成对平方距离验证结构。 

一个常见的实现陷阱是忘记定义立方体的是距离重数，而不是原始距离值。 另一种是假设轴对齐，这是无效的，因为立方体可以在空间中任意定向。

 ## 边缘情况

 当一个点的多个坐标相等时，如`0 0 0`或者`1 1 2`，排列集缩小。 该算法可以正确处理这个问题，因为`set(permutations(...))`删除重复项，确保 DFS 不会浪费时间探索相同的状态。 

当所有点都相同时，每个排列都会产生相同的配置。 距离检查产生全零，仅产生一个距离值，而不是所需的三计数结构。 验证者立即拒绝这一点。 

当一个有效的立方体存在但在空间中旋转时，轴对齐的直觉就会失败。 该解决方案不依赖于轴对齐，仅依赖于成对距离，因此自然地处理了旋转不变性。
