 ## 解决方案
 ## 问题理解

 我们有一个权重集合。 我们知道它们质量的多重集，但物理重量是无法区分的，所以我们不知道哪个物体有哪个质量。 我们可以向朋友提出一个请求：选择一些权重`k`和总质量`m`，并且朋友返回任意一组`k`质量总和为的物理重量`m`。 

看到返回的组后，有些物理重量可能有保证的质量。 任务是选择请求，使得已知精确质量的权重数量尽可能多。 

关键的困难在于朋友可以选择任何有效的组。 仅当我们查询的每个可能答案都为我们提供有关某些物理重量的相同信息时，组才有用。 

权重的数量最多为 100，每个质量最多为 100。这使得总可能质量最多为 10000。尝试所有子集的解决方案是不可能的，因为最多有$2^{100}$子集。 解决方案围绕$O(n^2 \cdot \text{sum})$是可行的，因为涉及所选权重的数量及其总质量的状态数量约为一百万。 

在很多情况下，看似合理的方法都会失败。 

假设权重为：```
4
1 2 2 4
```如果我们要求两个总质量为 4 的重物，则唯一可能的组是质量为 2 的一对重物。 答案是`2`，因为这两个物理重量变得已知。 

如果我们要求两个总质量为 5 的重量，则返回的重量对是质量为 1 和 4 的重量。 然而，返回的两个物理对象无法彼此区分，因此这两个对象不能被单独识别。 留下的两个重量都是质量二，因此再次只显示两个重量。 计算有效子集中的质量数而不是物理重量的解决方案将错误地回答 4。 

另一个边缘情况是所有权重具有相同的质量时：```
5
7 7 7 7 7
```甚至在提出任何问题之前，就已经知道每个物理重量的质量都是七，所以答案是`5`。 在进行查询后仅搜索唯一子集的方法将错误地找不到任何结果。 

第三种情况是只有两个不同的质量时：```
6
3 3 3 8 8 8
```询问一种类型的所有权重可以揭示所有权重的确切身份。 一旦选定的组已知，其余的重量必须具有其他质量。 答案是`6`。 

## 方法

 直接方法将枚举每个可能的查询`(k, m)`，然后检查可以回答该查询的每个子集。 这在概念上是有效的，因为答案是由朋友可能返回的所有可能的组决定的。 然而，子集的数量是指数级的。 100个权重可以有$2^{100}$可能的组，因此该方法甚至无法开始运行。 

有用的观察是，成功的查询必须识别具有相同质量的权重。 如果返回的组包含两个不同的质量，则该组内的物理对象通常无法分离。 例如，返回的包含质量一和质量四的对仅告诉我们这两个对象是`{1,4}`，而不是哪个对象是哪个。 

所以我们需要找到查询可以强制的最大数量的等质量权重。 考虑询问`k`总质量为的重量`k * w`。 如果具有此大小和总和的每个子集仅包含质量权重`w`，那么任何可能的答案都准确地揭示了那些`k`重量。 

剩下的任务是检查存在哪些大小和总和的组。 我们使用背包动态规划。 让`dp[c][s]`是包含的子集的数量`c`重量与总质量`s`。 对于质量值`w`出现的`cnt[w]`次，选择`k`这些权重正好给出`C(cnt[w], k)`可能的物理子集。 如果 DP 表示具有大小的子集总数`k`和总和`k*w`正是这个值，那么每个这样的子集仅由质量组成`w`。 这意味着`k`可以识别权重。 

一个或两个不同质量的特殊情况是单独处理的，因为单个查询可以完全分离两组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n^2 \cdot S)$|$O(n \cdot S)$| 已接受 |

 这里`S`是所有质量的总和，最多 10000。 

## 算法演练

 1. 计算出现了多少个不同的质量值。 如果最多有两个，请回答`n`立即地。 对于零、一种或两种可能的质量类型，一次查询始终可以区分每种物理重量。 
2. 建立一个动态规划表，计算每个可能的选定权重数量和每个可能的总质量存在多少个子集。 

状态仅存储判断查询是否具有唯一结构所需的信息。 我们不需要重建子集本身。 
3. 对于每个质量值`w`以及每一个可能的数字`k`具有该质量的权重，检查状态`(k, k*w)`。 

价值`dp[k][k*w]`计算可以通过请求返回的所有子集`k`总质量的重量`k*w`。 
4. 将此值与选择的方式数进行比较`k`之间的对象`cnt[w]`有质量的物体`w`，即`C(cnt[w], k)`。 

如果它们相等，则此查询的每个有效子集仅由质量组成`w`重量。 查询可以揭示`k`权重，所以更新答案。 
5.输出最大有效值`k`。 

为什么它有效：

 仅当返回的对象被迫属于单个质量类别时，查询才会显示各个权重。 如果有效子集包含多个质量类别，则至少两个物理对象保持可互换。 DP 计算每个候选查询的所有可能答案。 当该计数等于仅由一个质量值组成的子集的数量时，不存在其他类型的子集，因此每个可能的答案都显示相同的结果`k`对象。 检查每一个质量和每一个可能的情况`k`因此找到最好的可能查询。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    cnt = [0] * 101
    for x in a:
        cnt[x] += 1

    kinds = sum(1 for x in cnt if x)

    if kinds <= 2:
        print(n)
        return

    total = sum(a)

    dp = [dict() for _ in range(n + 1)]
    dp[0][0] = 1

    for x in a:
        for c in range(n - 1, -1, -1):
            if not dp[c]:
                continue
            target = dp[c + 1]
            for s, val in dp[c].items():
                target[s + x] = target.get(s + x, 0) + val

    comb = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        comb[i][0] = comb[i][i] = 1
        for j in range(1, i):
            comb[i][j] = comb[i - 1][j - 1] + comb[i - 1][j]

    ans = 1

    for w in range(1, 101):
        if cnt[w] == 0:
            continue
        for k in range(1, cnt[w] + 1):
            if dp[k].get(k * w, 0) == comb[cnt[w]][k]:
                ans = max(ans, k)

    print(ans)

if __name__ == "__main__":
    solve()
```频率数组记录了每个质量存在多少个权重。 早期返回处理可以通过一个查询分隔所有权重的情况。 

动态规划表存储为字典列表。 字典可以避免扫描不可能的和并保持实现紧凑，因为许多`(count, sum)`在中间步骤期间无法访问组合。 

更新向后迭代所选权重的数量。 这是标准的0/1背包技术：当前重量只能使用一次，并且不会意外地多次贡献给同一状态。 

组合表是用帕斯卡三角形计算的。 我们将 DP 计数与组合进行比较，而不是检查计数是否为 1，因为选择几个相等的物理权重会创建许多等效的有效子集。

 ## 边缘情况

 对于单个重量：```
1
5
```答案是`1`。 该算法立即通过两个或更少质量类型的条件来处理这个问题。 

对于所有相同的权重：```
5
7 7 7 7 7
```算法返回`5`在运行动态规划之前。 每个物体都已经有一个已知的质量，因此不需要查询来区分它们。 

对于两个不同的质量：```
6
3 3 3 8 8 8
```早期状况恢复`6`。 询问一个质量的所有重量，将另一个质量组作为补充，从而揭示每个物理对象。 

对于混合子集看起来很有吸引力的情况：```
4
1 2 2 4
```DP 发现选择总质量为 4 的两个重物恰好具有一种可能的质量成分，`{2,2}`。 它不计算`{1,4}`将情况设置为四个已知权​​重，因为返回组内的两个不同质量无法分配给单个对象。 答案依然存在`2`。
