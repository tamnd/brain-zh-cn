 ## 解决方案
 ## 问题理解

 我们得到一个正整数的多重集。 从这个集合中我们想要计算有多少个整数$x$具有以下性质：如果我们采取$x$与给定集合中的任意两个数字一起，这三个值始终可以形成一个非退化三角形。 

当两个较小边的总和严格大于最大边时，三倍长度正好形成一个有效的三角形。 所以对于任何选择的对$a_i, a_j$，值$x$必须在所有可能的排序中满足三角形不等式。 

要求很强烈：$x$必须与数组中的每一对一起使用，而不仅仅是至少一对。 这意味着$x$受到数组中最差的对的约束，即最难满足三角形不等式的对。 

输入尺寸可以达到$5 \cdot 10^5$，因此任何涉及检查所有对的解决方案都是立即不可行的。 二次方法需要大约$10^{11}$在最坏的情况下进行操作，远远超出了时间限制。 

微妙的边缘情况来自退化配置，其中许多值相等或非常小。 例如，如果数组包含$[1, 1]$，则没有正数$x$可以工作，因为$1, 1, x$需要$x < 2$和$x > 0$, 给予$x = 1$，但这也必须适用于较大数组中的所有对，当存在较大元素时，这很快就会崩溃。 

另一个重要的情况是当阵列高度不平衡时，例如$[1, 1000000000]$。 这里即使是中等值$x$可能会失败，因为与大元素的配对主导了三角形约束。 

## 方法

 我们从直接解释开始。 对于固定的$x$，我们需要检查所有对$(a_i, a_j)$。 对于每一对，我们测试是否$(x, a_i, a_j)$满足三角不等式。 由于有$O(n^2)$配对和潜在的许多候选者$x$，这会导致爆炸。 

我们不是遍历对，而是反转观点。 我们问：有哪些限制？$x$由一对$(a_i, a_j)$？ 

认为$a_i \le a_j$。 三角形条件为$(x, a_i, a_j)$减少为：$$x + a_i > a_j$$因为当以下情况时，其他不等式会自动满足正值$a_j$是三者中最大或第二大的元素。 这给出：$$x > a_j - a_i$$所以每一对都会产生一个下界$x$。 为了让所有对同时工作，$x$必须超过所有值的最大值$a_j - a_i$超过所有对。 

现在我们确定最差的一对。 最大差值$a_j - a_i$通过数组的全局最大值和全局最小值来实现。 因此最强的约束是：$$x > \max(a) - \min(a)$$这意味着每个整数$x$严格大于$\max(a) - \min(a)$是有效的。 

然而，这个问题也隐含地限制了$x$由集合本身。 预期的解释是$x$从没有明确上限的正整数中选择，但条件必须适用于中的所有对$a$。 由于没有上限限制，所有大于阈值的整数都是有效的，这将是无限的，因此唯一一致的解释是，我们正在计算可能的整数值，这些值使得所有三角形在与集合中的任意两个元素组合时都有效，但实际上这减少为在由所有对上的三角形不等式确定的有界可行区间内计算整数值。 

更精确的重新表述是观察对于固定$x$，三角形条件还要求：$$a_i + a_j > x$$对于所有对$(i, j)$，因为否则$x$becomes the largest side and violates the inequality. 这引入了一个上限：$$x < a_i + a_j$$对于所有对，因此：$$x < \min(a_i + a_j)$$最小对和是从数组的两个最小元素获得的。 让$m_1 \le m_2$是两个最小值。 然后：$$x < m_1 + m_2$$结合两个约束，有效$x$必须满足：$$\max(a) - \min(a) < x < m_1 + m_2$$所以答案就是这个区间内整数的个数。 

我们计算线性时间内的两个最小和两个最大元素并评估间隔长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解对 |$O(n^2)$|$O(1)$| 太慢了|
 | 最佳（最小/最大减少）|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 扫描一次数组，同时保持最小和次小值。 这是必要的，因为最严格的上限约束来自最小化$a_i + a_j$。 
2. 在同一次扫描中，保留最大和第二大的值，因为最严格的下限约束来自于元素之间差异的最大化。 
3. 计算下界$L = \max(a) - \min(a) + 1$。 严格的不等式成为起始整数边界。 
4. 计算上限$R = m_1 + m_2 - 1$， 自从$x$必须严格小于最小对和。 
5.如果$L > R$，返回 0，因为没有整数可以同时满足这两个约束。 
6.否则返回$R - L + 1$。 

这两个界限足够的原因是每个三角不等式涉及$x$并且两个数组元素折叠为涉及差的约束或涉及和的约束，并且两个极值完全由数组的极值元素确定。 

### 为什么它有效

 任意一对$(a_i, a_j)$贡献了两个约束：$x > |a_i - a_j|$和$x < a_i + a_j$。 第一个通过全局极值差最大化，第二个通过最小对和最小化。 由于这两个约束族在对上都是单调的，因此没有中间对可以产生比极端更严格的界限。 这将二次约束系统简化为两个标量边界，以充分表征可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # smallest and second smallest
    m1 = m2 = 10**18
    # largest and second largest
    M1 = M2 = -10**18
    
    for x in a:
        if x < m1:
            m2 = m1
            m1 = x
        elif x < m2:
            m2 = x
        
        if x > M1:
            M2 = M1
            M1 = x
        elif x > M2:
            M2 = x
    
    L = M1 - m1 + 1
    R = m1 + m2 - 1
    
    if L > R:
        print(0)
    else:
        print(R - L + 1)

if __name__ == "__main__":
    solve()
```该代码执行一次传递来提取定义所有约束的四个极值。 下界是从任意两个数组元素之间的最大差得出的，而上限是从两个元素的最小可能和得出的。 最终计数是结果区间中整数的数量。 

必须注意严格的不平等。 代码转换$x > M1 - m1$进入$M1 - m1 + 1$和$x < m1 + m2$进入$m1 + m2 - 1$，确保正确的整数计数，没有差一错误。

 ## 边缘情况

 完全均匀的数组，例如$[k, k, k]$产生$L = 0 + 1$和$R = 2k - 1$，因此可行区间变为所有正整数，直到$2k - 1$。 该算法可以处理此问题，因为两个极值都正确折叠为相同的最小值和最大值，从而产生严格但有效的边界。 

高度倾斜的数组，例如$[1, 1000000000, 1000000000]$产量$L = 999999999 + 1$和$R = 1 + 1000000000 - 1$，它变成空的。 该算法纯粹通过极值跟踪来检测这一点，而不需要推理中间对。 

近似排序的数组，例如$[2, 3, 4, 5]$产生一个小但非空的区间。 最小对和来自前两个元素，而最大差值来自端点，算法正确地隔离了它们，而不受内部结构的影响。
