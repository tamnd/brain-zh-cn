 ## 解决方案
 ## 问题理解

 爱丽丝有一个通过抛硬币创建的二进制字符串。 她没有给出字符串，而是只给出了每个相邻对出现的次数：`00`,`01`,`10`， 和`11`。 我们需要计算有多少个不同的二进制字符串可以准确地产生这四个计数。 答案取模`10^9+7`。 

这四个值描述了相邻字符之间的转换，因此相邻对的总数为`a+b+c+d`，并且字符串长度比该长度多一。 约束允许测试用例上的所有值的总和达到`5 * 10^5`，它排除了任何枚举字符串或执行与计数乘积成比例的工作的情况。 我们需要一个总输入大小接近线性的解决方案。 

错误的主要原因是忘记了起始字符和结束字符不是固定的。 例如，输入`1 1 1 1`有输出`4`。 一个粗心的解决方案，假设每个有效字符串都以`0`会错过以以下开头的字符串`1`。 

另一个边缘情况是当之间没有变化时`0`和`1`。 用于输入`3 0 0 0`，唯一可能的字符串是`0000`，所以答案是`1`。 仅基于对转换块进行计数的方法可能会意外除以零或假设存在交替运行。 

最后一个棘手的情况是不可能的过渡平衡。 用于输入`0 0 3 0`，答案是`0`。 有三个`10`过渡但没有`01`转换，这不可能发生在有限的二进制字符串中，因为从`1`到`0`最终必须匹配从`0`或稍后从`0`到`1`。 

## 方法

 直接方法将尝试构建每个可能的二进制字符串并检查其相邻对的计数。 一个长度的字符串`n`有`2^n`可能性，在这里`n`可以在附近`500001`，所以这是不可能的。 

有用的观察来自于观察运行。 二进制字符串由连续的相同字符组组成。 在一串零中，每个相邻的对都贡献一个`00`。 如果有`r0`零游程，零的总数为`Z`， 然后`Z-r0=a`， 所以`Z=a+r0`。 同样的想法给出`O=d+r1`对于一运行。 

价值观`b`和`c`确定存在多少次运行。 每一个`01`过渡从零运行到一运行，并且每个`10`过渡向后移动。 它们的差异告诉我们字符串是在同一侧还是在相对侧开始和结束。 

一旦知道了零游程和一游程的数量，剩下的任务就是计算将零游程和一游程分割成正长度游程的方法。 分裂`x`相同的项目放入`k`积极的团体可以在`C(x-1,k-1)`方式，给出了最终的公式。 

蛮力之所以有效，是因为它直接对所有可能的字符串进行建模，但会失败，因为字符串的数量是指数级的。 运行观察将每个有效字符串压缩为两个独立的组合，将问题简化为组合问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳| 每个总输入 O(a+b+c+d) | O(500000) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘和逆阶乘直至最大可能值，因为每个答案都是使用组合来表达的。 

我们使用它们通过模运算在常数时间内评估二项式系数。 
2. 检查之间的平衡`b`和`c`。 

数量`01`和`10`转换最多可以相差一。 如果差异较大，则不能存在任何字符串。 
3、办理案件`b = c = 0`。 

不同字符之间没有转换，因此字符串必须仅包含零或仅包含一。 计数决定这两种可能性之一是否有效。 
4、办理案件`b = c > 0`。 

该字符串以相同的字符开头和结尾。 有两种可能性。 

如果它开始于`0`， 有`b+1`零游程和`b`一跑。 贡献是：`C(a+b, b) * C(d+b-1, b-1)`如果它开始于`1`，角色互换：`C(a+b-1, b-1) * C(d+b, b)`添加两种可能性。 
5、办理案件`b = c+1`。 

该字符串开头为`0`并以`1`。 零游程和一游程都是`b`在数量上。 

答案是：`C(a+b-1, b-1) * C(d+b-1, b-1)`6. 处理对称情况`c = b+1`。 

该字符串开头为`1`并以`0`，给予：`C(a+c-1, c-1) * C(d+c-1, c-1)`为什么它有效：每个有效的二进制字符串都有一个独特的分解。 转换计数唯一地确定存在多少个零游程和一游程，除了以下情况下起始字符的选择：`b=c`。 这些公式将每个可能的 0 和 1 正分割计数到这些运行中，因此每个有效字符串都只计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    t = data[0]
    queries = []
    mx = 0
    idx = 1
    for _ in range(t):
        a, b, c, d = data[idx], data[idx + 1], data[idx + 2], data[idx + 3]
        idx += 4
        queries.append((a, b, c, d))
        mx = max(mx, a + b + c + d + 1)

    fact = [1] * (mx + 1)
    for i in range(1, mx + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (mx + 1)
    inv_fact[mx] = pow(fact[mx], MOD - 2, MOD)
    for i in range(mx, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    def comb(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

    ans = []

    for a, b, c, d in queries:
        if abs(b - c) > 1:
            ans.append("0")
            continue

        if b == 0 and c == 0:
            if a > 0 and d == 0:
                ans.append("1")
            elif d > 0 and a == 0:
                ans.append("1")
            else:
                ans.append("0")
            continue

        if b == c:
            x = b
            cur = comb(a + x, x) * comb(d + x - 1, x - 1)
            cur += comb(a + x - 1, x - 1) * comb(d + x, x)
            ans.append(str(cur % MOD))
        elif b == c + 1:
            x = b
            ans.append(str(comb(a + x - 1, x - 1) * comb(d + x - 1, x - 1) % MOD))
        else:
            x = c
            ans.append(str(comb(a + x - 1, x - 1) * comb(d + x - 1, x - 1) % MOD))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```首先收集输入，以便在预处理之前可以知道所需的最大阶乘大小。 由于所有组合都使用从相邻对总数导出的值，因此一个阶乘表足以满足每个测试用例。 

这`comb`对于无效选择，函数返回零。 当公式要求不可能的运行次数时，这就消除了单独检查的需要。 

这`b=c=0`分支在其他公式之前处理，因为这些公式包含诸如`C(x-1,x-1)`和`x=0`，这并不代表实际的无过渡情况。 

其余代码直接遵循运行计数案例。 公式使用模乘法`10^9+7`，Python 整数避免了溢出问题。

 ## 边缘情况

 对于`3 0 0 0`，算法进入无转移分支。 由于仅`00`对存在，字符串必须全为零。 零的个数是`4`，生产`0000`，所以答案是`1`。 

为了`0 0 3 0`，算法首先检查转移平衡。 之间的区别`b`和`c`是`3`，大于一。 一个二进制字符串不能再有三个`10`转变比`01`转换，所以答案是立即`0`。 

为了`1 1 1 1`，相等的转换计数意味着有两个可能的起始字符。 第一种情况将 0 分为两次运行，将 1 分为一次运行，而第二种情况则相反。 两个案例贡献`2`每个，给出正确的总数`4`。 

为了`0 2 1 0`，转换差为 1，因此字符串必须以 0 开头并以 1 结尾。 恰好有两个零游程和两个一游程，并且每个符号计数只有一个可能的正分割，恰好给出一个字符串。
