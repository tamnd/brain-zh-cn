 ## 解决方案
 ## 问题理解

 我们有一块长方形板，其尺寸为$n \times m$。 每个单元格都可以解释为我们可以放置棋子的位置，问题要求在来自骑士式攻击规则的移动限制下我们可以放置棋子的最大数量。 放置在一个单元上的棋子“控制”某些其他单元，任何有效的配置都必须确保两个放置的棋子不会互相攻击。 

运动的结构是关键的隐藏信息：攻击关系总是翻转网格的两个颜色类别之间的奇偶性。 这立即意味着二分结构，这意味着如果我们像棋盘一样给网格着色，那么每一步都会从一种颜色变为另一种颜色。 因此，任何完全放置在一个颜色类上的棋子集合都是自动安全的，因为同一类中的两个单元格不能互相攻击。 

输入由多个测试用例组成。 每个测试用例提供两个整数$n$和$m$，描述网格大小。 输出是每个网格上可以独立放置的最大棋子数量。 

约束没有明确显示，但参考代码中存在封闭式解决方案表明$n, m$可以很大，可能至少达到$10^9$或类似的。 这立即排除了任何模拟或图形构建。 任何解决方案都必须将网格简化为每个测试用例的恒定时间公式。 

当一维非常小时，就会出现主要的边缘情况。 一个天真的检查器，假设一个完整的棋盘着色结果，例如$\lceil nm/2 \rceil$对于薄板则失败。 例如，在一个$2 \times 3$板，一个朴素的公式给出 3，但仔细的放置规则只允许 4 或有时不同的结构行为，具体取决于攻击几何。 另一个脆弱的情况是$1 \times m$，棋盘退化成一条线，所有交互都消失了。 

## 方法

 一种直接的方法是将网格视为一个图，其中每个单元格都是一个节点，边代表有效的攻击。 然后我们尝试计算最大独立集。 原则上这是正确的，因为我们想要内部没有边的最大节点集。 

然而，构建这个图已经花费了$O(nm)$，并且运行任何标准算法以获得最大独立集是不可行的，因为即使是二分匹配公式也需要每个测试用例至少线性或超线性时间。 对于大型网格，这种方法会立即失效。 

关键的观察结果是攻击结构是高度规则的并且仅取决于相对坐标。 网格自然地分为两个奇偶类别，并且大多数交互仅跨越这些类别。 这表明在大多数情况下，采用一个奇偶校验的所有单元格给出了最佳答案，产生大约一半的网格，即。$\lfloor (nm+1)/2 \rfloor$。 

当两个维度至少为 3 时，这种方法非常有效。原因是网格“足够密集”，因此没有局部模式约束会打破二分界限。 

困难来自于小尺寸。 什么时候$n = 1$，根本不存在垂直相互作用，因此每个细胞都是独立的。 什么时候$n = 2$，棋盘变成一个 2 行条带，其中马的移动会以重复的模式产生局部冲突。 这会产生周期为 4 列的周期性最佳结构，产生每个宽度为 4 的块 4 个单元的重复最大模式，并对其余部分进行特殊处理。 

因此，解决方案简化为三种情况：平凡的线路情况、受约束的带状情况以及奇偶校验占主导地位的一般情况。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 阅读$n$和$m$，并在必要时交换它们，以便$n \le m$。 这减少了案例处理，因为所有公式仅依赖于较小的维度“高度”。 
2.如果$n = 1$， 返回$m$。 在单排中，任何棋子都不能攻击其他棋子，因为所有移动都需要垂直位移。 因此，每个单元格都可以被安全地占用。 
3.如果$n = 2$，使用沿列的块结构计算答案。 我们将板分成 4 列的部分。 每个完整的块贡献 4 块。 对于剩余的$m \bmod 4$列中，贡献遵循固定模式：1 列额外提供 2 个额外位置，2 列提供 4 个位置，3 列提供 4 个位置，4 列提供 4 个位置。这是由 2 行网格中的最佳局部打包产生的，其中攻击模式每四列重复一次。 
4. 如果$n \ge 3$， 返回$\lceil nm / 2 \rceil$。 这对应于填充棋盘着色的一种颜色类别。 由于所有攻击都交叉奇偶校验，因此没有两个选定的单元发生冲突，并且由于对称性，这是最大的。 

### 为什么它有效

 正确性依赖于保留二分性的骑士式移动的结构，以及只有窄网格才会产生破坏纯粹奇偶最优性的局部约束的事实。 为了$n \ge 3$，每个单元都有足够的邻域灵活性，没有本地配置可以迫使我们低于奇偶校验界限。 为了$n = 1$和$n = 2$，图太薄，局部重叠约束变成全局约束，产生周期性最优模式而不是简单的二分最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    if n > m:
        n, m = m, n

    if n == 1:
        print(m)
    elif n == 2:
        k = m // 4
        r = m % 4
        ans = k * 4 + min(4, r * 2)
        print(ans)
    else:
        print((n * m + 1) // 2)

t = int(input())
for _ in range(t):
    solve()
```第一步确保我们始终将较小的尺寸视为$n$，这简化了推理$n = 2$案件。 这$n = 1$分支直接处理退化线图。 

这$n = 2$计算对四列块上的重复最佳模式进行编码。 整个块乘以 4 反映了每个 2x4 段可以在最佳配置中容纳四个非攻击块。 余数调整使用`min(4, r * 2)`对部分块的预先计算的最佳值进行编码。 

最后的情况使用整数算术来计算$\lceil nm/2 \rceil$安全地作为`(n * m + 1) // 2`。

 ## 边缘情况

 的$n = 1$外壳是最脆弱的。 基于奇偶校验的简单解决方案会错误地输出$\lceil m/2 \rceil$，但实际上所有细胞都是独立的。 用于输入`1 7`，正确的输出是`7`，算法直接返回$m$，匹配单行中不存在攻击边的事实。 

这$n = 2$case 编码唯一不平凡的结构。 用于输入`2 5`，该算法计算一个完整块和一个余数：$4 + 2 = 6$。 一个天真的半网格假设会给出$\lceil 10/2 \rceil = 5$，这是完全错误的，因为交互模式比简单的二分着色允许更密集的堆积。 

为了$n \ge 3$， 例如`3 3`，算法返回$\lceil 9/2 \rceil = 5$。 跟踪执行确认没有触发特殊分支，并且二分结构控制答案，这与不再存在薄网格约束的事实相匹配。
