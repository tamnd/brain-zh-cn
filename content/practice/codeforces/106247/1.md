 ## 解决方案
 ## 问题理解

 24 小时数字时钟为我们提供了两个时刻（含）。 每个时钟读数显示为`HH:MM`，其中小时使用两位数字`00`到`23`分钟使用两位数字`00`到`59`。 

如果至少满足以下条件之一，则认为时间是美好的：

 小时值等于分钟值。 例子是`00:00`和`21:21`。 

分钟数字与小时数字正好相反。 例如，`21:12`。 

显示的四个数字形成连续递增的数字序列。 例如，`01:23`，其数字为`0,1,2,3`。 

我们必须计算在给定的开始时间和结束时间之间（包括两个端点）出现了多少美丽的读数。 

限制很小。 一天只包含`24 × 60 = 1440`可能的时钟读数。 即使我们检查间隔中的每一分钟并直接测试所有三个美容条件，工作量也可以忽略不计。 预期的解决方案是简单的模拟。 

错误的主要原因是正确解释美容规则。 

考虑一下时间`12:12`。```
12
12
```这很美好，因为小时等于分钟。 仅检查镜像条件的解决方案会错过它。 

考虑一下时间`20:02`。```
20
02
```这很漂亮，因为分钟数字与小时数字相反。 以数字方式处理值并删除前导零会错误地进行比较`20`和`2`。 

考虑一下时间`01:23`。```
01
23
```显示的四位数字分别是`0,1,2,3`，它们是连续递增的数字。 该规则适用于显示屏上的数字，而不是分别适用于小时和分钟的数值。 

最后的边缘情况是开始时刻和结束时刻相同。 该声明明确表示仅考虑单一读数。 

## 方法

 一个蛮力的想法是生成间隔内所有可能的时钟读数并测试它是否漂亮。 每次我们都可以提取四个显示的数字并直接评估三个条件。 

由于一整天的读数最多为 1440 个，因此即使采用暴力方法也只能执行几千次操作。 不需要组合学、动态规划或任何高级观察。 

关键的认识是搜索空间本身很小。 许多时钟问题需要巧妙的计数，因为时间跨越很大的范围，但这里整个有效读数的范围都适合一天。 逐分钟枚举在实践中已经是最佳选择。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举| 欧(1440) | O(1) | O(1) | 已接受 |
 | 最优枚举| 欧(1440) | O(1) | O(1) | 已接受 |

 在这个问题中，暴力解和最优解实际上是相同的。 

## 算法演练

 1. 将开始时间转换为单分钟索引：`start = h1 * 60 + m1`。 
2. 将结束时间转换为单分钟索引：`end = h2 * 60 + m2`。 
3. 迭代每一分钟`t`从`start`到`end`，包含在内。 
4. 恢复当前小时和分钟：`h = t // 60`,`m = t % 60`。 
5. 提取显示的四位数字：`h_tens`,`h_ones`,`m_tens`,`m_ones`。 
6. 检查小时是否等于分钟。 

如果`h == m`，读起来很美。 
7. 检查分钟数字是否与小时数字相反。 

这意味着：`h_tens == m_ones`和`h_ones == m_tens`。 
8. 检查四位数字是否构成连续递增的数字：`d1 + 1 == d2`,`d2 + 1 == d3`,`d3 + 1 == d4`。 
9. 如果至少有一个条件成立，则增加答案。 
10. 处理完整个间隔后，打印计数。 

### 为什么它有效

 该算法检查属于所需间隔的每个时钟读数，并准确应用定义中的三个美丽条件。 当且仅当至少满足一个条件时，读数才有助于得出答案。 由于每个符合条件的时间都会检查一次，并且不会检查间隔之外的时间，因此最终的计数正是漂亮读数的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

h1 = int(input())
m1 = int(input())
h2 = int(input())
m2 = int(input())

start = h1 * 60 + m1
end = h2 * 60 + m2

ans = 0

for t in range(start, end + 1):
    h = t // 60
    m = t % 60

    beautiful = False

    if h == m:
        beautiful = True

    ht = h // 10
    ho = h % 10
    mt = m // 10
    mo = m % 10

    if ht == mo and ho == mt:
        beautiful = True

    if ht + 1 == ho and ho + 1 == mt and mt + 1 == mo:
        beautiful = True

    if beautiful:
        ans += 1

print(ans)
```第一部分将输入时间转换为分钟索引。 这使得迭代变得简单，因为前进一分钟仅仅意味着将整数加一。 

在循环内部，使用除法和模运算重建当前小时和分钟。 

必须使用数字而不是整数反转技巧来检查镜像条件。 这可以避免前导零的问题，例如`20:02`。 

对于连续数字的情况，我们直接比较显示的四位数字。 该规则涉及时钟上的可见序列，而不是小时和分钟字段的数值。 

循环两端都包含在内，与语句完全匹配。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    h1 = int(input())
    m1 = int(input())
    h2 = int(input())
    m2 = int(input())

    start = h1 * 60 + m1
    end = h2 * 60 + m2

    ans = 0

    for t in range(start, end + 1):
        h = t // 60
        m = t % 60

        ok = False

        if h == m:
            ok = True

        ht, ho = divmod(h, 10)
        mt, mo = divmod(m, 10)

        if ht == mo and ho == mt:
            ok = True

        if ht + 1 == ho and ho + 1 == mt and mt + 1 == mo:
            ok = True

        if ok:
            ans += 1

    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    global input
    input = sys.stdin.readline

    out = io.StringIO()
    old = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = old
    return out.getvalue()
