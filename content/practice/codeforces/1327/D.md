 ## 解决方案

 ## 问题理解

 我们给出了一种排列，它定义了一个有向图，其中每个节点都只有一个出边。 每个索引都指向其排列下的图像，并且每个节点还带有一种颜色。 从一个节点开始，重复应用排列沿着一条最终循环的确定性路径行走，因为该结构是循环的不相交联合，其中有树馈入其中。 

我们关心的操作是多次应用排列。 如果我们应用它 k 次，我们就可以有效地沿着函数图沿着传出边缘跳跃 k 步。 我们被要求找到最小的 k，使得在排列 p 的 k 次方中，存在一个节点，其向前无限行走永远不会改变颜色，这意味着重复应用中的每一步都保留在相同颜色的节点内。 

重构后，我们想知道大小为 k 的重复跳跃何时使我们进入一个循环，该循环在原始颜色下沿着 p^k 引起的遍历是单色的。 

关键的困难在于，取排列的幂会改变循环的分解方式：长度为 L 的循环分裂为 p^k 中的 gcd(L, k) 个循环，每个循环对应于在原始循环中步进 k 个位置。 要求是这些诱导循环中至少有一个必须完全由相同颜色的节点组成。 

这些约束意味着测试的总大小最多为 2⋅10^5，因此每个测试的任何解决方案都必须接近线性或线性。 任何显式地重新计算排列幂或模拟每个 k 的游走的方法都会太慢，因为 k 可以大到 2⋅10^5 并且 T 高达 10^4。 

每次测试的简单 O(n^2) 或 O(n√n) 在最坏情况聚合下是边界或不可能的。 

当一个循环包含重复的颜色但不均匀时，就会出现微妙的失败情况。 例如，像 1→2→3→1 这样的颜色为 [1,2,1] 的循环包含局部匹配，但没有完整的单色循环。 检查邻接性或部分一致性的简单方法会错误地得出 k = 1 有效的结论，但实际上没有 k 产生完全单色的无限路径。 

## 方法

 直接的强力方法是计算 p^k 以增加 k，并检查是否有任何节点成为结果函数图中单色循环的开始。 对于每个 k，我们可以重新计算循环结构或模拟 k 步转换。 通过每次测试的二进制提升来计算 p^k 显式成本为 O(n log k)，并且检查结构又增加了 O(n)。 由于 k 本身可能会达到 n，因此这种方法退化为 O(n^2 log n)，这太慢了。 

关键的见解来自于理解 p^k 对循环的作用。 考虑长度为 L 的循环。在 p^k 中，我们在该循环中向前移动 k 步，因此我们仅访问与步长 k 模 L 一致的位置。 p^k 中的轨道对应于沿着原始循环以 k 模 L 为增量步进。该轨道形成一个循环，其节点正是那些索引 i、i+k、i+2k 等以 L 为模的索引。 

为了使这个诱导循环是单色的，沿着原始循环的算术级数中的所有节点必须共享相同的颜色。 因此，对于固定周期和起始位置，我们需要对于所有 t，c[i + t k] 是模 L 的常数。 

这将问题转化为分析每个周期的算术级数。 我们希望 k 最小，这样至少存在一个循环和一个起始偏移量，其中沿循环间隔 k 的所有节点都具有相同的颜色。

固定长度为 L 的循环。如果我们选择起始位置 i，则条件是对于所有 t，c[i] 等于 c[i + tk mod L]。 这意味着在该循环中通过步进 k 可到达的所有位置必须共享相同的颜色。 访问位置的集合正是k模L生成的子组，其大小为L / gcd(L, k)。 因此，我们需要存在一个以 gcd(L, k) 为模的残基类，使得该类中的所有位置都是相同颜色的。 

我们不是迭代 k，而是反转逻辑。 对于每个周期，我们考虑所有具有相同颜色的位置 i 和 j ，并计算它们沿周期的距离 d。 如果我们希望两个位置都位于步骤 k 的同一轨道上，那么 k 必须除以循环结构意义上的距离，或者更准确地说，k 必须与连接它们的子群结构兼容。 正确的减少成为循环上相同颜色节点之间距离的 gcd 约束。 

对于每个周期，我们固定一种颜色并收集该颜色的所有位置。 有效 k 的必要条件是 k 除以某个选定的单色子集中的循环长度为模的所有成对距离。 同样，对于选定的颜色，在一个周期内，我们获取所有出现的颜色并计算连续出现之间的圆形距离的 gcd。 任何有效的 k 必须除以该 gcd，并且有效的最小 k 是所有周期和颜色中此类 gcd 的最小值。 

因此，问题简化为将排列分解为循环，然后在每个循环内按颜色对索引进行分组并计算其位置的 gcd 约束。

 ## 算法演练

 1. 沿着p[i]将排列分解为不相交的循环，直到返回到访问过的节点。 这是必要的，因为 p^k 的行为在每个周期中都是独立的。 
2. 对于每个循环，按照遍历的顺序记下节点的顺序。 这使圆形结构线性化，因此距离变成阵列上的模差。 
3. 按颜色对周期中的位置进行分组。 对于每种颜色，收集其按循环顺序出现的索引。 
4. 如果某种颜色在一个循环中至少出现两次，则计算循环顺序中连续出现的所有循环距离，包括从最后一个到第一个的环绕距离。 取这些距离的 gcd。 该 gcd 捕获进入该颜色类所需的周期性。 
5. 跟踪所有颜色和周期获得的最小正 gcd。 该值是允许步长对齐循环内至少一种颜色的所有出现的最小 k。 
6. 输出最小k。 

按循环顺序仅计算相邻间隙的原因是循环集中的所有成对距离都减少为连续间隙的组合，并且 gcd 在这种分解下是不变的。 

### 为什么它有效

 在一个循环内，有效的 k 必须使 k 步的遍历保持在所有共享相同颜色的节点的子集中。 该子集必须在以循环长度为模加 k 的情况下闭合。 加法下的闭包强制子集恰好是残基类模 gcd(L, k) 的并集。 因此，位于循环中的所选颜色的所有元素必须与周期除以 k 的周期结构对齐。 出现次数之间的间隙的 gcd 恰好是与该颜色模式一致的最大周期，并且支持这种周期性步进的最小 k 是所有周期中此类 gcd 最小的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = [0] + list(map(int, input().split()))
    c = [0] + list(map(int, input().split()))

    vis = [False] * (n + 1)
    ans = 10**18

    for i in range(1, n + 1):
        if vis[i]:
            continue

        cycle = []
        x = i
        while not vis[x]:
            vis[x] = True
            cycle.append(x)
            x = p[x]

        m = len(cycle)

        pos_in_cycle = {cycle[i]: i for i in range(m)}

        color_groups = {}
        for idx in cycle:
            col = c[idx]
            color_groups.setdefault(col, []).append(pos_in_cycle[idx])

        for col, arr in color_groups.items():
            if len(arr) <= 1:
                continue

            arr.sort()
            for j in range(len(arr)):
                a = arr[j]
                b = arr[(j + 1) % len(arr)]
                dist = (b - a) % m
                if dist == 0:
                    dist = m
                ans = min(ans, dist)

    print(ans if ans != 10**18 else 1)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```该解决方案首先从排列中提取循环，因为所有约束都独立存在于循环内。 每个循环都存储为一个列表，并且反向映射给出循环内的位置，以便距离变成简单的模差。 

对于每个周期，节点按颜色分组。 对于出现多次的每个颜色组，我们按循环顺序计算连续出现之间的距离。 这些距离表示在任何有效步长 k 下必须一致的间隙。 取所有周期中所有此类距离的最小值，得到最小的 k，该 k 将至少一种颜色类别对齐到与步进兼容的周期结构中。 

一个常见的微妙之处是从最后一次出现到第一次出现的环绕间隙。 省略它会破坏循环结构并导致不正确的 gcd 约束。

 ## 边缘情况

 一种重要的边缘情况是一种循环，其中相同的颜色仅出现两次，但跨越了环绕边界。 例如，具有颜色 [1,2,3,1] 的循环 [1,2,3,4]。 颜色 1 的两次出现在位置 0 和 3，因此圆形距离为 1。该算法正确地包括了环绕距离，产生 k = 1 作为候选，这与步进 1 已经使这些节点在有效轨道上对齐这一事实相匹配。 

另一种边缘情况是一种颜色在一个周期中仅出现一次。 在这种情况下，不会从中生成任何约束，因为单个事件不能强制周期性。 算法自然会忽略它，正确性依赖于贡献最小有效 k 的其他周期或颜色。 

最后的边缘情况是多个周期提供不同的候选 k 值。 由于周期是独立的，因此答案必须是所有周期中的最小值。 该实现保持全局最小值，确保任何周期中的小型有效结构主导结果。
