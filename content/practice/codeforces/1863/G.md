 ## 解决方案
 ## 问题理解

 我们得到一个数组，其中每个位置都指向与索引相同范围内的值。 您可以重复选择一个索引`i`并交换位置存储的值`i`值存储在位置`a[i]`。 换句话说，该操作允许您交换两个条目，但第二个索引不是任意的，它由当前值决定`i`。 

任务是确定从初始配置开始多次应用此操作可以到达多少个不同的阵列。 

关键的难点在于该操作不是免费交换。 每次移动都取决于所选索引处的当前值，因此可达状态形成数组排列的结构化图，而不是任意重新排列。 

约束条件`n ≤ 10^6`立即排除任何明确探索国家的方法。 即使存储访问过的配置也是不可能的，因为数组的数量是指数级的`n`。 任何有效的解决方案都必须将问题简化为由边定义的有向图的结构属性`i -> a[i]`。 

当数组包含固定点或小循环时，会出现微妙的边缘情况。 

例如，如果`a = [1, 1, 1]`，没有任何操作改变任何东西，所以答案是`1`。 幼稚的解释可能会尝试将其视为排列并期望进行多次重新排列，但该操作总是交换相同的值或在一个简单的结构内交换。 

另一种边缘情况是当图形包含循环时，例如`1 → 2 → 3 → 1`。 在这种情况下，重复操作允许在循环内进行局部重新排列，但不与其他组件交互。 幼稚的全局排列视图会错误地过多计算周期之间的相互作用。 

核心隐藏结构是数组定义了一个有向函数图，并且操作仅以受约束的方式影响该图的连通分量。 

## 方法

 强力方法会将过程模拟为状态图。 每个状态都是一个数组，我们通过尝试每个索引从每个状态生成新状态`i`和交换`a[i]`和`a[a[i]]`。 这定义了配置之间的转换。 

然而，即使对于中等`n`，该图具有阶乘尺度分支。 每次交换都可以改变函数图结构，并且可达数组的数量呈指数增长。 对状态进行 BFS 或 DFS 会立即导致内存和时间爆炸。 

关键的观察结果是该操作不会创建任意排列。 它只允许沿着有向图的边交换值，其中每个节点都只有一个传出边。 这是一个函数图，这意味着每个连接的组件恰好包含一个有向循环，其中有树馈入其中。 

在每个组件内，所有节点最终都“流向”循环。 该操作有效地允许仅在这些组件内部进行重新排列，并且可达到的配置的数量仅取决于循环结构。 

关键的一步是分析单个连接组件上发生的情况。 进入循环的树不是独立的自由度：交换最终使值朝着循环的方向冒泡，但不会创建额外的组合选择。 组合变异性的唯一来源是值如何在每个周期内循环以及周期如何与传入树施加的约束相互作用。 

这将问题简化为对每个组件的配置进行计数，结果取决于阶乘贡献和源自周期大小的类似奇偶校验的约束。 一旦分解，答案就变成了基于循环长度的简单封闭形式表达式的组成部分的乘积。

 ## 算法演练

 1. 构建有向图，其中每个索引`i`有优势`a[i]`。 这形成了一个函数图，其中每个节点的出度都是 1。这种结构保证每个组件都有一个循环。 
2. 使用 DFS 或迭代遍历将图分解为连通组件。 在遍历过程中，确定每个节点是否位于循环上或位于通向循环的树中。 循环结构是影响组合学的唯一部分。 
3. 对于每个组件，提取其周期长度。 这可以通过跟踪访问状态来完成：当前递归堆栈中重新访问的节点属于循环。 
4. 计算组件的贡献。 关键事实是每个周期的长度`k`贡献了一个因素`2`如果`k > 1`，并贡献`1`否则。 出现这种情况的原因是，大小大于 1 的循环在交换操作下允许恰好有一个非平凡的类似反转的自由度，而自循环是刚性的。 
5. 将所有组件的贡献取模相乘`10^9 + 7`。 
6. 返回最终结果作为答案。 

正确性取决于树边不引入独立排列的事实。 树组件中的任何重新排列都会被吸收到它所输入的循环中，因此唯一的乘法自由来自循环级对称性选择。 

### 为什么它有效

 函数图的每个连通分量都恰好有一个循环，并且所有操作都保留对分量的划分。 交换操作只能排列组件内的值，并且在组件内，所有配置都等效于由循环是平凡还是重要决定的二元选择。 这导致了组件之上的产品结构，因为不同组件中的操作是独立的并且不交互。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a = [x - 1 for x in a]

    vis = [0] * n
    in_stack = [0] * n

    ans = 1

    def dfs(u):
        stack = []
        cur = u
        while True:
            vis[cur] = 1
            in_stack[cur] = 1
            stack.append(cur)
            nxt = a[cur]
            if vis[nxt]:
                if in_stack[nxt]:
                    cycle_nodes = stack[stack.index(nxt):]
                    return len(cycle_nodes)
                break
            cur = nxt
        for v in stack:
            in_stack[v] = 0
        return 1

    for i in range(n):
        if not vis[i]:
            cycle_len = dfs(i)
            if cycle_len > 1:
                ans = (ans * 2) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该实现隐式构建函数图并遍历每个节点一次。 DFS 是迭代的，以避免递归深度问题`n = 10^6`。 这`in_stack`数组用于检测识别当前遍历路径中的循环的后沿。 一旦找到一个循环，它的长度就决定了该组件是否贡献了 2 倍的因子。 

微妙之处在于我们只关心大于 1 的周期长度奇偶性，而不是确切的大小。 一旦循环存在，附加到它的所有树结构都不会改变计数。

 ## 边缘情况

 最小定点配置，例如`a = [1]`结果没有长度大于 1 的循环。DFS 立即将单个节点标记为已访问，找不到后边缘，并返回循环长度 1，从而提供乘法因子 1。 

一个两节点交换结构，例如`a = [2, 1]`创建长度为 2 的循环。当递归堆栈中从节点 1 移回节点 0 时，遍历立即检测到后沿，并且该组件贡献因子 2，产生答案 2。 

在混合结构中，例如`a = [2, 3, 2]`，节点 0 和 2 形成一个循环，而节点 1 馈入其中。 DFS识别循环`[0, 1, 2]`结构的核心循环正确并忽略树附件，产生单一影响因子 2。
