 ## 解决方案
 ## 问题理解

 每个学生小组只参加两节课。 对于一个小组，第一节课使用的教室不得超过第二节课使用的教室。 

我们确切地知道每个教室有多少个小组开始。 如果`Xi = 3`，那么正好三组在房间里上第一堂课`i`。 

我们还知道每个教室的总人数限制。 小组为课堂做出贡献`i`如果有第一课或第二课。 如果`Yi = 5`，那么最多有五个组可以使用房间`i`两堂课相结合。 

任务是计算存在多少个有效时间表。 组是不同的，因此将组 A 分配给`(1,3)`和B组`(2,2)`与交换这些分配不同。 

总组数为$$N = \sum Xi$$并且声明保证`N ≤ 1000`。 

教室数量最多为100个，容量也最多为100人。解决方案`O(M * N^2)`或者`O(M * N^3)`在 Python 中是现实的。 任何指数级的东西`N`立即不可能，因为`N`可以达到1000。 

问题的微妙部分是理解容量条件的真正含义。 

假设房间`i`有`Xi = 4`。 第一节课时，四个小组就已经占用了它。 如果房间容量为`Yi = 6`，只有另外两个小组可以在第二节课中使用它。 这正是意味着$$Yi - Xi$$较早开始的团体可能会在房间内结束`i`。 

这将问题转化为计算将小组从较小的教室转移到较大的教室的方法。 

有几种边缘情况很容易破坏简单的实现。 

考虑：```
2
1 0
1 0
```有一组从房间 1 开始。由于房间 2 不能包含任何人，因此该组也必须以房间 1 结束。正确答案是`1`。 

仅在所有分配后检查容量的粗心解决方案可能会意外允许`(1,2)`。 

另一个棘手的情况是：```
2
1 1
1 1
```仅从第一堂课开始，每个房间就已达到满负荷。 任何团体不得在不同的房间结束。 两组都被迫留在原地，所以答案是`2! = 2`，因为群体是不同的。 

仅计算分布而忘记组排列的 DP 将错误地返回`1`。 

另一个重要的边缘情况：```
3
2 0 0
2 2 2
```两组都从房间 1 开始。每组可能以房间 1、2 或 3 结束。答案是`3^2 = 9`。 

这里的团体是独立的，因为后面的房间仍然有空闲的容量。 任何试图贪婪地从左到右填充容量的方法都可能会意外地少算。 

## 方法

 蛮力解释很简单。 对于每个小组，选择大于或等于第一个教室的第二个教室，然后验证没有房间超过其容量。 

如果有`N`团体和`M`房间，每组最多可拥有`M`选择。 搜索空间大致为$$M^N$$这是无望的`N = 1000`。 

蛮力在概念上起作用的原因是约束是局部的。 每组只需要一个有效的结束房间，之后可以查看房间容量。 问题在于，群体通过共享能力进行互动，创造了巨大的组合状态空间。 

关键的观察结果是第一课的计数已经固定。 

对于房间`i`， 确切地`Xi`小组从那里开始。 因为至多`Yi`总共可以使用房间的团体数，第二节课在房间内的团体数量`i`但谁的第一堂课早一点正是$$Ci = Yi - Xi$$现在重新解释一下这个过程。 

小组从某个房间开始，要么呆在那里，要么向右移动。 每个房间`i`必须准确接收`Ci`来自较早房间的传入组。 

这变成了沿线的组合流问题。 

我们从左到右处理房间。 加工室时`i`，之前房间的一些小组仍然“开放”，这意味着他们还没有选择第二个教室。 让这个数成为`j`。 

房间`i`必须准确吸收`Ci`其中。 剩余的开放组继续向右移动。 然后`Xi`团体从房间开始`i`被添加到开放池中。 

这表明 DP 超过当前开放组的数量。 

剩下的挑战是组合计数。 如果`j`团体是开放的并且有房间`i`必须吸收`Ci`其中，有$$\binom{j}{Ci}$$选择哪些组在此结束的方法。 

转换之后，我们添加`Xi`新开的团体。 

由于组是不同的，因此我们还必须考虑每个房间中开始的特定组。 标记组的方式总数为$$N!$$DP 只计算开始和结束之间的结构匹配，假设组不可区分。 乘以`N!`恢复独特的群体身份。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(M^N)$|$O(N)$| 太慢了 |
 | 最佳DP |$O(M \cdot N^2)$|$O(N)$| 已接受 |

 ## 算法演练

 1. 计算组总数：$$N = \sum Xi$$1. 每个房间`i`，计算：$$Ci = Yi - Xi$$

`Ci`是来自较早房间且必须以房间结束的组数`i`。 

1. 定义一个DP，其中`dp[j]`意思是：

 处理多个房间后的方法数量，以便准确地`j`团体目前开放，但仍需要第二间教室。 

开放小组是指第一个教室已经确定，但第二个教室尚未选定的小组。 

1.初始化：```
dp[0] = 1
```在处理任何房间之前，没有任何组是开放的。 

1. 从左到右处理房间。 

假设当前房间有：

 -`need = Ci`-`start = Xi`对于每个州`j`：

如果`j < need`，过渡是不可能的，因为没有足够的开放组可以在此终止。 

否则：

 - 选择哪个`need`团体到此结束，
 - 将它们从开集中删除，
 - 添加`start`新的团体从这里开始。 

新的开放组数量变为：$$nj = j - need + start$$此转换的方式数量为：$$\binom{j}{need}$$所以：$$ndp[nj] += dp[j] \cdot \binom{j}{need}$$1. 所有房间处理完毕后，各组必须已结束。 

所以有效的答案是：$$dp[0]$$1. 乘以`N!`。 

民主党忽视了群体的身份。 每个结构解都准确对应`N!`为组分配不同的标签。 

所以最终的答案是：$$dp[0] \cdot N! \pmod{10^9+7}$$### 为什么它有效

 不变量是：

 处理完第一个之后`i`房间，`dp[j]`准确计算为所有结束房间位于第一间教室的小组决定第二间教室的方法数量`i`房间，同时离开`j`组未完成。 

每个未完成的小组必须在后面的房间结束，因为第二个教室不能向左移动。 

加工室时`i`， 确切地`Ci`未完成的组必须在那里终止。 选择大小的任意子集`Ci`有效，因为所有这些组都源自较早的房间。 不存在其他限制。 

每个有效时间表恰好对应一个DP转换序列，并且每个DP转换序列构造一个有效时间表。 这给出了时间表和计数状态之间的双射。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    m = int(input())
    x = list(map(int, input().split()))
    y = list(map(int, input().split()))

    n = sum(x)

    # factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    # combinations
    C = [[0] * (n + 1) for _ in range(n + 1)]

    for i in range(n + 1):
        C[i][0] = 1
        C[i][i] = 1

    for i in range(2, n + 1):
        for j in range(1, i):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    dp = [0] * (n + 1)
    dp[0] = 1

    for i in range(m):
        need = y[i] - x[i]
        start = x[i]

        ndp = [0] * (n + 1)

        for open_groups in range(n + 1):
            cur = dp[open_groups]

            if cur == 0:
                continue

            if open_groups < need:
                continue

            nxt = open_groups - need + start

            ways = C[open_groups][need]

            ndp[nxt] = (ndp[nxt] + cur * ways) % MOD

        dp = ndp

    ans = dp[0] * fact[n] % MOD
    print(ans)

solve()
```实现的第一部分构建阶乘和二项式系数。 自从`N ≤ 1000`，完整的帕斯卡三角形是完全可行的。 

DP 状态直接反映了演练中的数学解释。`open_groups`代表已经开始但仍需要第二间教室的团体。 

转换逻辑是关键部分：```
nxt = open_groups - need + start
```我们首先关闭`need`先前在当前房间中打开的组，然后从该房间添加新开始的组。 

组合乘数```
C[open_groups][need]
```计算哪些未完成的组在这里结束。 

最终乘以`fact[n]`很容易被错过。 没有它，民主党就会将群体视为无法区分的群体。 阶乘恢复不同的身份。 

另一个微妙的细节是答案必须是`dp[0]`。 处理所有房间后，任何未完成小组的状态都是无效的，因为不存在后面的房间来举办第二节课。

该迹线证实了阶乘乘数是必要的。

 ## 边缘情况

 再考虑一下：```
2
1 0
1 0
```1号房间有`need = 0`,2号房还有`need = 0`。 

处理完1号房间后，开放一组。 房间 2 不启动新组，也不接受传入组。 唯一有效的解释是房间 1 组已经在房间 1 结束。 

DP 正确地完成了一个有效的结构，并乘以`1!`仍然给`1`。 

现在检查：```
2
1 1
1 1
```每个房间都被自己的起始组完全占据。 

DP结构计数为`1`，因为不可能进行跨房间移动。 乘以`2!`给出`2`，正确地区分两组。 

最后：```
3
2 0 0
2 2 2
```房间 1 的两组可以独立选择其中任意一个结束房间`1,2,3`。 

DP 仅记录每个房间之后有多少组保持开放状态，而不是它们的确切组数。 二项式系数重建了所有的结构可能性，而最终的阶乘则恢复了不同的特性。 

这种组合正是该方法扩展到 1000 组而不失去正确性的原因。
