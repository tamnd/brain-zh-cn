 ## 解决方案
 ## 问题理解

 我们有一组木棒，每根木棒的长度都是正整数。 瓦西亚想要通过堆叠相同长度的钢筋来建造塔。 每个塔必须由长度相同的杆组成，但不同的塔可以有不同的长度。 目标是将所有酒吧建造成塔，同时最大限度地减少塔的数量并报告最高塔的高度。 

输入由柱数组成$N$(1 ≤ N ≤ 1000) 及其长度列表。 输出需要两个整数：单个塔中堆叠的最大条数和塔的总数。 

限制条件适中。$N$最多可达 1000，这使得算法的时间复杂度可达$O(N^2)$舒适地。 然而，由于长度是以 1000 为界的整数，我们可以利用它来有效地计算计数，而无需迭代所有柱对。 这暗示了频率计数方法而不是嵌套循环结构。 

非明显的边缘情况包括：

 1. 所有条形都有独特的长度。 例如，输入`5\n1 2 3 4 5`结果是 5 座塔，每座高度为 1。尝试“组合”钢筋的粗心方法将会失败。 
2. 所有条的长度相同。 输入`4\n7 7 7 7`应该产生一个高度为 4 的单塔。 
3.混合重复。 输入`6\n1 2 2 3 3 3`应该产生高度为 1、2 和 3 的塔，其中最高的塔高度为 3。不进行计数的简单排序可能会使如何有效计算塔的数量变得不那么明显。 

## 方法

 蛮力方法是明确地模拟建造塔。 我们可以迭代每个条并尝试将其放置在相同长度的现有塔上，或者启动一个新塔。 为了$N = 1000$，这涉及检查每个现有塔中的每个酒吧，可能会导致$O(N^2)$运营。 虽然这在这里是可行的，但当可以更直接地导出高度和计数时，它会变得不必要的复杂且容易出错。 

关键的见解是，最高塔的高度由任何条长度的最大频率决定，而塔的总数由不同长度的数量决定。 计算频率将问题转化为简单的数据传递。 通过存储每个长度存在多少条，最高的塔就是最大计数，塔的数量就是唯一长度的数量。 

“我们只需要计数，而不是显式的塔结构”这一观察结果将问题从模拟转化为计数问题，从而将复杂性从$O(N^2)$到$O(N)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N^2) | O(N^2) | O(N) | 有效但太过分了|
 | 最佳 | O(N) | O(L)，其中 L ≤ 1000 | 已接受 |

 ## 算法演练

 1. 初始化一个字典（或大小为1001的数组）来统计每个条长度的频率。 该结构将每个长度映射到该长度的条数。 
2. 迭代所有条长度。 对于每个长度，增加其在频率字典中的计数。 此步骤给出了条长度的完整分布。 
3. 通过查找频率字典中的最大值来确定最高塔的高度。 最大数量的相同条直接对应于最高的塔。 
4. 通过计算字典中存在的唯一长度的数量来计算塔的总数。 每个独特的长度恰好形成一座塔。 
5.输出最高塔的高度以及塔的总数。 

为什么有效：在每个点，算法都会保留每个条形长度的完整计数。 最高的塔不能超过最频繁长度的计数，并且每个不同的长度必须贡献至少一个塔。 没有任何信息丢失，因此最终答案是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

N = int(input())
lengths = list(map(int, input().split()))

# count frequencies
freq = {}
for l in lengths:
    if l in freq:
        freq[l] += 1
    else:
        freq[l] = 1

max_height = max(freq.values())
num_towers = len(freq)

print(max_height, num_towers)
```该解决方案首先使用有效地读取输入`sys.stdin.readline`。 频率词典`freq`存储每个长度的计数，我们直接计算最高塔的最大值。 字典中键的数量给出了不同塔的数量。 这可以避免任何相差一的错误或不必要的循环。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    N = int(input())
    lengths = list(map(int, input().split()))
    freq = {}
    for l in lengths:
        freq[l] = freq.get(l, 0) + 1
    return f"{max(freq.values())} {len(freq)}"

# provided sample
assert run("3\n1 2 3\n") == "1 3"

# all equal
assert run("4\n7 7 7 7\n") == "4 1"

# mixed repetitions
assert run("6\n1 2 2 3 3 3\n") == "3 3"

# minimum input
assert run("1\n5\n") == "1 1"

# maximum input with distinct values
assert run("1000\n" + " ".join(map(str, range(1,1001))) + "\n") == "1 1000"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 | 4\n7 7 7 7 | 7 7 7 7 | 4\n7 7 7 7 4 1 | 所有酒吧均相同，单塔 |
 | 6\n1 2 2 3 3 3 | 6 3 3 | 混合计数、最高塔计算 |
 | 1\n5 | 1\n5 1 1 | 1 最小尺寸输入 |
 | 1000\n1 2 3 ... 1000 | 1 1000 | 最大尺寸输入，全部不同 |

 ## 边缘情况

 用于输入`4\n7 7 7 7`，频率字典变为`{7:4}`。`max(freq.values())`最高的塔正确返回 4，并且`len(freq)`返回 1。除了计数之外不需要对各个柱进行迭代。 

用于输入`6\n1 2 2 3 3 3`, 字典`{1:1,2:2,3:3}`产生最高的塔高度为 3，塔的数量为 3。这证实了算法可以正确处理不同的重复，而无需额外的堆叠逻辑。
