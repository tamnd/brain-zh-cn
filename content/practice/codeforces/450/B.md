 ## 解决方案
 ## 问题理解

 该问题定义了一个线性序列$f_n$有两个初始值$x = f_1$和$y = f_2$，以及每六项重复一次的递归：$f_{n} = f_{n-1} - f_{n-2}$。 实际上，这创建了一个具有以下循环的序列：

 -$f_1 = x$-$f_2 = y$-$f_3 = y - x$-$f_4 = -x$-$f_5 = -y$-$f_6 = x - y$-$f_7 = f_1 = x$- 依此类推，每 6 个术语重复一次。 

输入提供整数$x$,$y$， 和$n$，我们被要求计算$f_n$模数$10^9 + 7$。 

约束表明$x$和$y$可以非常大（最多$\pm 10^9$）， 和$n$可以达到$2 \times 10^9$。 这意味着迭代计算序列从 1 到$n$这是不可行的，因为它可能需要数十亿次操作。 因此，需要一个利用 6 项重复模式的直接公式。 

一个微妙的边缘情况涉及负数。 因为我们必须返回模数结果$10^9 + 7$，负结果必须正确转换为相应的正模数。 

## 方法

 蛮力方法将从 1 迭代到$n$使用递归$f_n = f_{n-1} - f_{n-2}$计算每一项。 虽然这种方法在逻辑上是正确的，但对于大型企业来说并不实用。$n$， 因为$n$最大可达 20 亿，导致数十亿次算术运算。 

关键的见解是识别序列的 6 项循环行为。 一旦确定了循环，任何$f_n$可以直接使用余数计算$n \mod 6$。 这减少了问题$O(n)$运算至常数$O(1)$查找和算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 对于大 n 来说太慢 |
 | 基于周期的公式 | O(1) | O(1) | O(1) | O(1) | 接受且高效 |

 ## 算法演练

 1.首先根据初始值计算6项周期$x$和$y$。 顺序是$[x, y, y - x, -x, -y, x - y]$。 
2. 计算$n \mod 6$以确定循环内的位置。 由于序列是 1 索引的，因此通过减去 1 来调整索引：$index = (n-1) \mod 6$。 
3. 从该索引对应的循环中检索值。 
4. 将结果转换为范围$[0, 10^9 + 6]$使用模运算。 如果数字为负数，则添加$10^9 + 7$在取模之前。 
5. 返回最终值。 

为什么有效：序列的递归确保每 6 个连续项准确重复，因此计算$n \mod 6$无论有多大，都提供正确的术语$n$是。 使用模处理负值可以保证输出满足问题的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

x, y = map(int, input().split())
n = int(input())

seq = [x, y, y - x, -x, -y, x - y]
result = seq[(n - 1) % 6] % MOD
print(result if result >= 0 else result + MOD)
```此代码首先读取输入值$x$,$y$， 和$n$。 6个周期`seq`被构造，并通过访问适当的术语`(n - 1) % 6`考虑从 1 开始的索引。 模运算确保结果在正确的范围内，处理任何负值。 

## 工作示例

 对于输入：```
2 3
3
```计算序列：`[2, 3, 1, -2, -3, -1]`。 第三项（0-索引：2）是`1`。 模运算在这里很简单，所以输出是`1`。 

对于输入：```
2 3
8
```循环中的索引：`(8 - 1) % 6 = 1`。 序列中的第二项是`3`。 输出模数$10^9 + 7$是`3`。 

对于负结果的输入：```
2 3
5
```指数：`(5 - 1) % 6 = 4`。 第 5 项是`-3`。 模数转换：`-3 % (10^9 + 7) = 1000000004`。

 ## 边缘情况

 一种边缘情况涉及负数。 例如，$x = 2$,$y = 3$,$n = 5$。 第 5 项是`-3`。 使用未经调整的朴素模数可能会返回`-3`，但正确的输出是`1000000004`。 我们的实现增加了$MOD$如果结果是否定的，请正确处理。 

另一个边缘情况是当$n$非常大，例如$n = 2 \times 10^9$。 迭代计算是不可行的。 使用带有模数的基于周期的查找可将其减少到恒定时间。 

第三种边缘情况是当$n = 1$或者$n = 2$。 这些直接对应于初始值$x$和$y$。 我们的模索引`(n-1) % 6`正确返回第一个或第二个元素，没有任何差一错误。
