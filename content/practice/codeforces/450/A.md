 ## 解决方案
 ## 问题理解

 我们有一排孩子。 孩子`i`想要`a[i]`总共糖果。 每当孩子到达队伍的最前面时，他们都会收到准确的信息`m`糖果。 

如果孩子在分发后仍然没有收到足够的糖果，他们就会移到队伍的后面。 否则，他们将永久离开。 这个过程一直持续到没有孩子留下为止。 

任务是确定哪个孩子最后离开。 

限制非常小。 最多有 100 个孩子，每个孩子最多想要 100 颗糖果。 即使是直接模拟也很容易在时间限制内完成，因为糖果分发的总数很少。 尽管如此，还是有一个更清晰的观察，可以完全避免模拟队列。 

每个孩子的关键数量是他们在离开之前需要转多少圈。 如果一个孩子想要 7 颗糖果并且`m = 3`，他们需要到前面 3 次，因为收到糖果的顺序是 3、6、9。一般来说，孩子`i`需要$$\left\lceil \frac{a_i}{m} \right\rceil$$轮流。 

当几个孩子需要相同的圈数时，就会出现一种微妙的情况。 例如：```
3 2
4 4 4
```每个孩子需要轮两轮。 他们的最后离开是按照原来的顺序进行的，所以孩子 3 最后离开。 仅找到所需的最大匝数并返回第一次出现的解决方案将错误地输出 1。 

另一个容易犯的错误是错误地处理了精确的倍数`m`。```
2 3
3 4
```孩子 1 只需要转一圈，而不是两圈。 正确的圈数是 1 和 2，所以答案是 2。使用普通整数除法`a[i] // m`会产生不正确的结果。 

最后的极端情况是最小输入：```
1 100
1
```只有一个孩子，所以无论糖果数量多少，答案都是 1。 

## 方法

 一个简单的解决方案是完全按照描述模拟队列。 存储对`(child_index, remaining_candies)`。 反复去掉前面的孩子，减去`m`糖果，要么把它们送回家，要么把它们放在队列的最后。 

这个模拟是正确的，因为它确实遵循了这个过程。 在给定的约束下，它也足够快。 每个孩子最多可以要求$$\left\lceil \frac{100}{1} \right\rceil = 100$$轮次，所以队列操作总数最多也就10000次左右。 

然而，有一种更简单的方法来思考这个过程。 

孩子收到足够批次的尺寸后离开`m`。 唯一重要的是他们需要的访问次数：$$t_i = \left\lceil \frac{a_i}{m} \right\rceil$$需要更多探视的孩子在队列中停留的时间更长。 最后离开的孩子是具有最大值的孩子`t_i`。 

当多个子节点具有相同的最大值时，原行中较晚的子节点稍后离开。 他们在所有具有相同要求的早期孩子之后完成最后一次访问。 

这意味着我们只需要找到所需匝数最大的最后一个位置。

 ## 算法演练

 1. 阅读`n`,`m`，以及一系列糖果要求。 
2. 对于每个孩子，计算所需的轮数：$$t_i = \left\lceil \frac{a_i}{m} \right\rceil$$在整数算术中，这可以写成：$$t_i = \frac{a_i + m - 1}{m}$$使用楼层划分。 
3. 跟踪迄今为止看到的最大回合计数以及相应的子索引。 
4. 当某个孩子的回合数大于或等于当前最大值时，更新该孩子的答案。 

使用`>=`是必不可少的。 如果两个孩子需要相同的轮数，则后一个孩子会稍后离开，并且应该覆盖前一个答案。 
5. 处理完所有children后，输出存储的索引。 

### 为什么它有效

 对于每个孩子来说，`t_i`准确地表示该孩子在离开之前必须到达前面的次数。 

任何较小的孩子`t_i`严格地比具有更大的孩子更早离开`t_i`，因为他们在较少轮数的服务后完成。 

如果两个孩子有相同的`t_i`，它们的相对顺序永远不会改变。 在最后一次访问期间，最初队列中较晚开始的孩子也稍后到达该访问。 因此，在所有轮数最多的孩子中，原始顺序中的最后一个是最后一个回家的孩子。 

该算法显式地找到最大轮数的最后一次出现，这正是所需的子项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    best_turns = -1
    answer = -1

    for i, candies in enumerate(a, start=1):
        turns = (candies + m - 1) // m

        if turns >= best_turns:
            best_turns = turns
            answer = i

    print(answer)

solve()
```该解决方案仅对每个子项处理一次。 

表达式`(candies + m - 1) // m`计算上限`candies / m`使用整数运算。 这可以避免浮点运算并正确处理不精确倍数的值`m`。 

比较使用`>=`而不是`>`。 这是最重要的实施细节。 当两个孩子需要相同的轮数时，后一个孩子必须成为当前答案，因为该孩子离开得较晚。 

索引是通过以下方式生成的`enumerate(..., start=1)`因为问题是从 1 而不是 0 开始对孩子进行编号。

 ## 边缘情况

 考虑：```
3 2
4 4 4
```每个孩子都需要$$\left\lceil \frac{4}{2} \right\rceil = 2$$轮流。 该算法从左到右处理子级。 孩子 1 将最大值设置为 2。孩子 2 匹配最大值并成为答案。 Child 3 也匹配最大值并成为最终答案。 输出是：```
3
```与实际的队列过程相匹配。 

现在考虑：```
2 3
3 4
```回合数为：$$\left\lceil \frac{3}{3} \right\rceil = 1$$和$$\left\lceil \frac{4}{3} \right\rceil = 2$$该算法输出子 2。这种情况证实了`m`不得进行额外时间舍入。 

最后，考虑：```
1 100
1
```独生子女需要转一圈。 扫描仅访问一个元素并返回索引 1。由于不存在其他子元素，因此该子元素必然是最后离开的。
