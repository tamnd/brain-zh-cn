 ## 解决方案
 ## 问题理解

 我们被要求模拟从第一个元素开始沿着正整数数组行走。 每次移动可以向右移动一步，如果我们不在最后一个元素，则总是允许的；或者向左移动一步，只有当我们不在第一个元素并且前一个移动不是向左移动时才能完成。 每一步都会根据我们所在的数组元素的值增加运行分数。 总移动次数必须等于给定数字$k$，且向左移动的总数不能超过$z$。 任务是在准确之后最大化分数$k$移动。 

输入大小可以大到$n = 10^5$每个测试用例最多可以有$10^4$测试用例，总和$n$跨所有测试用例直至$3 \cdot 10^5$。 这排除了每个测试用例的线性复杂度更差的任何解决方案，因为$O(n^2)$或者$O(nk)$会导致$10^{9}$或更多操作，远远超出了2秒的时间限制。 

很容易错过的边缘情况包括数组，其中$z = 0$，强制所有移动向右，或者向左移动可能只有用一次或两次的数组，因为禁止过度向左移动，并且不允许连续两次向左移动。 例如，使用数组`[1, 100, 1]`,$k = 2$， 和$z = 1$，最优序列是右、左，得分为 1 + 100 + 1 = 102。总是先向右移动的天真的贪婪方法只会得到 1 + 100 = 101，从而错过了最优解。 

## 方法

 暴力方法将生成所有长度的序列$k$尊重左移约束并对相应的分数求和。 序列数量呈指数增长$k$，使得这对于给定的边界完全不可行。 

关键的见解是，向左移动的唯一好处来自于将向左移动与前一个向右移动配对，有效地形成最多可以重复的“左右对”$z$次。 每次向左移动之前都必须紧接着向右移动，因此我们只需要考虑在尽可能向右移动的同时可以执行多少次这样的配对。 此外，只有总和最大的对$a[i] + a[i+1]$很重要，因为重复使用最大的相邻对可以最大化左移动的增益。 

根据这一观察，最优策略减少为尝试从 0 到$z$。 对于每个候选的左移动次数，我们计算之后有多少个可用的右移动次数，并确定我们可以到达的最远索引。 然后，我们将总分计算为初始前缀加上重复的左右对的贡献之和，注意尊重允许的最大左移动数和总移动数$k$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^k) | O(2^k) | O(k) | 太慢了 |
 | 最佳 | O(n * z) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算数组的前缀和。 这使我们能够快速计算出一路移动到任意位置而无需左移动的总得分。 前缀和是此类累积和问题的标准，可减少重复加法$O(n)$到$O(1)$。 
2. 识别所有相邻对$a[i] + a[i+1]$因为到达索引后向左移动$i+1$允许您重复获得该对的总和。 跟踪每个索引观察到的最大对总和。 
3. 迭代左移动次数$lz$从 0 到$z$。 每次向左移动总共消耗两次移动：一次向右移动以到达新索引，一次向左移动返回。 因此，我们可以达到的最远索引$lz$向左移动是$k - 2 * lz$。 例如，如果$k = 7$和$lz = 2$，我们最初可以到达的最右边的位置是索引$7 - 4 = 3$。 
4. 对于每个$lz$，将分数计算为仅通过右移动可到达的最远索引的元素总和加上左右对贡献的总和。 左移动的总贡献是$lz * \text{maximum pair sum among visited positions}$。 
5. 记录所有选项的最高分$lz$。 这是该测试用例的答案。 

为什么有效：每次左移都严格用于从访问过的位置中可用的最大相邻对中受益。 尝试从 0 到 的所有左移动计数$z$保证我们在不违反约束的情况下考虑所有可行的策略。 前缀和有效地处理所有仅右移动。 这详尽地考虑了所有最佳组合，而不生成每个可能的序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, z = map(int, input().split())
        a = list(map(int, input().split()))
        prefix = [0] * n
        prefix[0] = a[0]
        for i in range(1, n):
            prefix[i] = prefix[i-1] + a[i]
        max_score = 0
        max_pair = 0
        for i in range(k + 1):
            if i < n - 1:
                max_pair = max(max_pair, a[i] + a[i+1])
            left_moves = min(z, i // 2)
            right_index = i - 2 * left_moves
            if right_index < 0:
                continue
            score = prefix[right_index] + left_moves * max_pair
            max_score = max(max_score, score)
        print(max_score)

if __name__ == "__main__":
    solve()
```代码首先计算前缀和，用于确定严格向右移动的分数。 变量`max_pair`跟踪潜在左移的最佳相邻总和。 对于每个可到达的位置`i`移动，它计算可能有多少向左移动（`left_moves`) 并计算总分。 该分数结合了最右侧索引的前缀总和以及左侧移动的贡献。 最后，打印所有可行左移计数的最大值。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * z) | 外循环运行到 k (~n)，对于左移贡献，内部计算为 O(1)； z ≤ 5 确保较小的因子。 |
 | 空间| O(n) | 前缀对大小为 n 的数组求和 |

 由于 z ≤ 5，因此实际上每个测试用例的 n 都是线性的。 所有测试用例的 n 总和≤ 3 * 10^5，在时间和内存限制内舒适地拟合。
