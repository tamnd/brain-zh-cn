 ## 解决方案
 ## 问题理解

 我们被要求在整数数组中找到“有趣的对”。 一对索引$(l, r)$如果子数组来自$l$到$r$长度为偶数，前半部分的异或等于后半部分的异或。 正式来说，如果$mid = \frac{l+r-1}{2}$，异或来自$l$到$mid$必须等于 XOR$mid+1$到$r$。 输入是最多包含 300,000 个整数的单个数组，每个整数小于$2^{20}$。 输出是此类有趣对的总数。 

因为$n$可以大到$3 \cdot 10^5$，对所有内容进行暴力检查$O(n^2)$子数组大约涉及$10^{10}$操作，远远超过一秒钟所能实现的。 这排除了所有对的简单迭代。 我们必须利用 XOR 的特性来降低时间复杂度。 

一个微妙之处是对偶数长度子数组的限制。 这意味着对于任何候选对$(l,r)$，我们可以计算$mid$作为$(l+r-1)//2$并确切地知道哪些元素属于左半部分和右半部分。 另一个棘手的问题是处理长度为 2 的子数组，该子数组虽小但有效； 不包括这些将会产生错误的结果。 

边缘情况包括长度为 2 的数组、所有元素都相等的数组以及包含零的数组，由于 XOR 为零，这些数组可能会产生有趣的对。 

## 方法

 暴力方法检查所有偶数长度的子数组，计算左半部分和右半部分的异或，并计算匹配数。 这是正确的，但涉及到$O(n^3)$操作，因为半个子数组上的每个 XOR 计算最多可能需要$O(n)$步骤。 为了$n = 3 \cdot 10^5$，这是不可行的。 

关键的见解是 XOR 具有前缀属性：$a[l] \oplus a[l+1] \oplus \dots \oplus a[r] = pref[r] \oplus pref[l-1]$如果$pref[i]$存储第一个的 XOR$i$元素。 使用它，可以计算任何子数组的 XOR$O(1)$。 这减少了天真的方法$O(n^2)$，这仍然太慢。 

另一个观察结果是，对于大小为 2 或 4 的偶数长度子数组，我们可以检查局部模式。 事实上，可以证明对于任何长度至少为 2 的子数组，如果$a_i = a_{i+1}$或者$a_i \oplus a_{i+1} \oplus a_{i+2} = a_{i+3}$，我们可以找到有趣的对。 利用这种模式，我们可以只扫描连续的三元组和四元组，从而将算法简化为$O(n)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 前缀异或| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 优化扫描 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化有趣对的计数器。 这将累积结果。 
2. 从第一个元素到倒数第二个元素迭代数组。 对于每个位置$i$，检查相邻对的异或。 如果$a[i] \oplus a[i+1] = 0$，递增计数器。 这计算了所有长度为 2 的有趣对。 
3. 对于长度为 4 的子数组，检查每个三元组是否重叠两半。 如果$a[i] \oplus a[i+1] = a[i+2] \oplus a[i+3]$，递增计数器。 这计算了所有长度为 4 的有趣对。 
4. 通过检查本地 XOR 等价性，对较大的子数组继续此模式。 观察到任何长度大于 4 的有趣对都可以分解为长度为 2 或 4 的重叠有趣对，这使我们能够避免显式枚举。 
5. 输出计数器作为有趣对的总数。 

为什么有效：XOR 属性$x \oplus x = 0$使我们能够有效地检测相等的一半。 所有偶数长度的子数组都会减少到本地检查长度 2 或长度 4，因为较长的模式将包含这些最小的有趣子数组。 这个不变量保证仅计算长度为 2 和 4 的模式即可捕获所有有效的有趣对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

count = 0

for i in range(n - 1):
    if a[i] == a[i + 1]:
        count += 1
    if i + 2 < n and a[i] ^ a[i + 1] == a[i + 2] ^ a[i + 3 if i + 3 < n else i + 2]:
        count += 1

print(count)
```第一个循环检查所有连续对以检测长度为 2 的有趣对。第二个检查考虑重叠四元组以检测长度为 4 的有趣对。XOR 运算符可以有效地计算相等性。 边界检查确保我们不会超过数组长度。 这种方法利用最小子数组属性来避免扫描所有可能的对。
