 ## 解决方案
 ## 问题理解

 我们有一个一维洞穴，分为`n`垂直列。 每根柱子都有一个天花板高度`h[i]`。 随着时间的推移，每列的天花板均匀下降：每一秒，每个正高度都会减少一。 一旦柱子达到零高度，它就会被完全堵塞。 

两个机器人从相对的两端开始：机器人 L 从列开始`1`，机器人 R 从列开始`n`。 时间以离散的步骤进行。 在每一秒开始时，我们首先应用全局高度减小。 如果机器人站在高度为零的柱子上，它会立即被压碎。 如果机器人之间严格存在任何零高度柱，它们将失去可见性并且过程结束。 如果它们还活着并且可以看到对方，并且不在同一列中，则恰好有一个机器人向另一个机器人迈出一步。 

我们被要求计算有多少对位置`(l, r)`和`l ≤ r`可以在机器人运动的某些有效序列下的某一秒开始时显示为配置，同时两个机器人都保持活动状态并始终保持在那一刻的可见性。 

一个关键的困难是移动不是任意的：每一步只有一个机器人移动，生存取决于每列在全局衰减下保持非零的时间长短。 这将空间运动与依赖于时间的“生命周期”约束结合起来。 

约束允许最多`n = 5 * 10^5`每次测试，还有测试的总和`5 * 10^5`。 这立即排除了任何对的二次枚举或任何根据运动选择进行分支的模拟。 即使是线性的每对或每起始位置的接近也太慢。 

一个简单的模拟会尝试从固定的位置启动机器人`(l, r)`并模拟所有可能的运动序列。 这种分支每秒都会发生，从而使可能性呈指数增长，甚至按时间限制进行​​修剪仍然会导致所有时间间隔内至少出现二次行为。 

一种微妙的边缘情况是由于零高度柱（而不仅仅是机器人位置）破坏了可见性。 例如，如果高度是`[1, 1, 1]`，然后一秒钟后全部变为零，并且跨越所有列的任何间隔都变得无效，即使机器人可能仍然在中间思维的端点处存在。 另一个问题是，生存取决于绝对时间：机器人可以在早期在某一列中表现良好，但同一列稍后就会变得致命。 任何将运动视为纯粹空间的方法都是错误的。 

## 方法

 蛮力观点是考虑每个区间`(l, r)`并询问是否存在一系列移动，使得机器人可以在某个同步时间步处于这些位置，同时保持活动并保持连接。 对于每个间隔，人们都会模拟所有可能的左/右移动序列，直到机器人相遇或一个死亡或可见性中断。 即使我们尝试优化每个模拟，每个间隔的状态数量也会随着之间的距离而增加`l`和`r`，并且有`O(n^2)`间隔，因此在最坏情况下总功是三次方。 

关键的结构观察是，唯一重要的是每个位置在全局衰减下存活多长时间，以及它如何与机器人达到配置所需移动的最大距离相互作用。 我们可以将这个过程重新解释为维护一个窗口，而不是模拟运动`[l, r]`随着时间的推移而扩展或移动，并受到窗口内最小高度的限制。 

关键的见解是翻转视角：而不是问机器人是否可以到达`(l, r)`，我们询问间隔多长时间`[l, r]`保持“可行”，这意味着内部的所有柱子在足够长的时间内保持积极状态，以支持机器人满足可见性限制的任何路径。 这将问题简化为由单调条件控制的有效间隔的两指针式计数。 

然后，我们可以固定右端点并移动左端点，同时保持间隔中的最小高度，因为可行性取决于该最小值是否足够大以维持机器人可能穿越该段所需的时间。 这自然会导致具有单调双端队列的滑动窗口以实现范围最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 最坏情况 O(n^3) | O(n) | 太慢了|
 | 带 RMQ（双端队列）的滑动窗口 | 每次测试 O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将任务重新定义为计数间隔`[l, r]`满足从间隔中最弱列的生存时间得出的可行性条件。 

1. 预先计算输入数组之外的显式结构，但维护一个可以有效回答当前窗口中的最小高度的数据结构。 我们使用单调双端队列来存储高度递增的索引，因此前面始终保存当前窗口中最小值的索引。 
2.初始化两个指针：`l = 1`，并迭代`r`从`1`到`n`。 对于每一个新`r`，我们将其插入双端队列，同时通过删除高度大于或等于的所有索引来保持单调性`h[r]`。 这确保双端队列代表候选最小值。 
3.插入后`r`，我们更新窗口`[l, r]`使其保持有效。 有效性条件来自这样的事实：如果最小高度`[l, r]`相对于间隔宽度太小，则机器人无法在洞穴塌陷或能见度破坏之前保持有效的运动顺序。 每当窗口变得无效时，我们就递增`l`并根据需要将其从双端队列中删除。 
4.对于每个固定`r`，一旦调整窗口，所有以`r`并从任意索引开始`[l, r]`是有效的。 因此我们添加`(r - l + 1)`到答案。 
5. 继续直到`r = n`，积累贡献。 

正确性取决于在每一步中保持窗口`[l, r]`是使间隔对于当前右端点可行的最小左边界。 任何更大的`l`只会缩短间隔，因此仍然可行，而任何更小的`l`会违反可行性约束。 

### 为什么它有效

 该过程仅取决于区间的两个属性：其长度和区间内的最小天花板高度。 最小高度决定了该段可以保持完全可穿越的时间长度，而长度决定了信息（机器人运动）从一端传播到另一端所需的时间。 这两个量对于窗口扩展来说是单调的：延长间隔只能减少最小值并增加所需的遍历时间。 这种单调性保证了一旦某个间隔对于固定的时间间隔变得无效`r`，左边界的任何进一步扩展都是不必要的，并且任何较小的间隔都是安全的，从而实现两指针结构而不会丢失任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))

        dq = deque()
        l = 0
        ans = 0

        for r in range(n):
            while dq and h[dq[-1]] >= h[r]:
                dq.pop()
            dq.append(r)

            while l <= r:
                mn = h[dq[0]]
                # feasibility condition derived from collapse vs traversal balance
                if mn >= (r - l + 1):
                    break
                if dq[0] == l:
                    dq.popleft()
                l += 1

            ans += (r - l + 1)

        print(ans)

if __name__ == "__main__":
    solve()
```代码维护了一个滑动窗口`[l, r]`以及该窗口中最小高度的双端队列。 双端队列的高度严格增加，因此前面始终代表最小值。 延长时`r`，我们通过删除不再是最小值的元素来强制单调性。 

内循环发生变化`l`直到条件满足`min(h[l..r]) ≥ (r - l + 1)`成立。 这是结构可行性条件：最小天花板高度必须足够大以维持跨间隔长度的相互作用。 每个索引最多进入和离开双端队列一次，指针`l`只向前移动，确保线性复杂度。 

答案累积了以每个结束的所有有效间隔`r`，因为一旦最小有效`l`发现，每个更紧的区间都是单调有效的。

 ## 边缘情况

 最小单列洞穴测试算法是否正确计算平凡间隔，而无需尝试任何移动逻辑。 

统一高度数组，例如`[k, k, k, ...]`确保窗口除了长度约束之外不会缩小，因此每个间隔都是有效的并且答案变成三角形。 该算法保持恒定的最小值并且仅扩展`r`，这保持了`l`固定为零。 

递减数组，例如`[n, n-1, ..., 1]`强迫多次违反条件`min ≥ length`，导致左指针频繁移动。 双端队列始终跟踪当前后缀最小值，并且每次移位都会准确删除损坏的约束点，从而防止无效间隔的过度计数。 

最后一个微妙的情况是当一个非常小的值位于大值的中间时。 双端队列确保它在包含时立即成为最小值，迫使`l`跳过它，这符合弱柱限制可行区间的想法，无论周围的高度如何。
