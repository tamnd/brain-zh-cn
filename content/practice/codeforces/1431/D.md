 ## 解决方案
 ## 问题理解

 我们的任务是在礼堂安排一系列讲座，每个讲座都将使用共享标记。 每个讲师都有个人容忍度：他们会拒绝使用已经使用过一定次数的记号笔，而要求更换一个新的。 我们的目标是选择能够最大化实际使用的不同标记数量的讲座顺序，同时仅在讲师要求时才更换标记。 

输入提供多个独立的测试用例。 对于每种情况，我们都会得到讲座的数量和代表每个讲师的容忍度的整数数组。 输出是最大化标记使用的讲师索引的顺序。 约束是适度的：最多 100 个测试用例，每个测试用例最多 500 个讲座，这意味着操作总数应该能够轻松地适应时间复杂度约为$O(n \log n)$或者$O(n^2)$每个测试用例。 

当多个讲师具有相同的容忍值或所有讲师的接受阈值非常低或非常高时，就会出现边缘情况。 例如，如果所有讲师的容差均为 1，则第一个讲座之后的每个讲座都会强制更换标​​记。 如果粗心的算法忽略了容差值的相对大小，它可能会按照不必要地减少使用标记数量的顺序来安排讲师。 

## 方法

 强力方法将考虑讲师的所有可能排列，模拟每个排列的讲座序列，并计算所使用的标记数量。 这种方法是正确的，但不可行，因为排列的数量呈阶乘增长，$n!$，即使对于$n = 10$。 

关键的见解是关注相对容差值。 仅当当前讲座的容差超过记号笔已使用的次数时，才需要更换记号笔。 为了最大限度地增加使用的标记数量，我们希望具有最低容差值的讲师尽早到来，因为他们会更快地触发替换。 具有较高容差值的讲师可以稍后安排，以延长当前标记的寿命。 

按照讲师容忍值的升序对讲师进行排序可以实现这一点。 这确保了我们在必要时更换标记，并且不会将讲座浪费在会立即被拒绝的标记上。 因为我们只需要遍历一次排序列表即可构建顺序，因此这种方法高效且简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 按容忍度贪婪排序 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取讲座数量和接受值数组。 
3. 将每个讲师的索引与其容差值配对，以便我们可以保留原始位置。 
4. 按公差值升序排列此配对列表。 
5. 提取排序后的索引作为讲座的顺序。 
6. 打印当前测试用例的结果顺序。 

为什么有效：通过始终将接受阈值较小的讲师放在第一位，我们确保每个标记在必须更换之前达到最大使用次数。 这种贪婪的方法保证了所使用的标记数量最大化，因为任何偏差（提前安排高容忍讲师）都无法增加标记的使用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        # pair index with value
        indexed = [(a[i], i + 1) for i in range(n)]
        # sort by acceptance value ascending
        indexed.sort()
        # extract order
        order = [idx for _, idx in indexed]
        print(' '.join(map(str, order)))

if __name__ == "__main__":
    solve()
```我们将每位讲师的容差与其从 1 开始的索引配对，以保留原始编号。 排序可确保我们尽可能高效地触发标记替换。 排序后提取索引给出所需的讲座顺序。 使用`sys.stdin.readline`确保快速输入处理，特别是对于多个测试用例。 

## 工作示例

 跟踪样本中的测试用例 1：

 输入数组：`[1, 2, 1, 2]`与索引配对：`[(1,1), (2,2), (1,3), (2,4)]`按容差排序：`[(1,1), (1,3), (2,2), (2,4)]`结果顺序：`[1,3,2,4]`| 步骤| 当前标记用途 | 下一位讲师 | 行动| 标记计数 |
 | ---| ---| ---| ---| ---|
 | 1 | 0 | 1 | 公差1，标记新| 1 |
 | 2 | 1 | 3 | 容差 1，标记使用过一次 -> 替换 | 2 |
 | 3 | 1 | 2 | 容差 2，标记使用一次 -> 继续 | 2 |
 | 4 | 2 | 4 | 容差 2，标记使用两次 -> 继续 | 2 |

 该轨迹表明，首先放置低容忍度讲师会触发必要的替换，而不会浪费早期标记。 

第二个测试用例`[2,3,1,3]`配对：`[(2,1),(3,2),(1,3),(3,4)]`，排序：`[(1,3),(2,1),(3,2),(3,4)]`， 命令：`[3,1,2,4]`实现最大的标记使用。

 ## 边缘情况

 如果所有讲师都具有相同的接受值，则任何顺序都有效。 该算法可以正确处理此问题，因为按容差排序保留了 Python 稳定排序中的相对顺序。 对于单个讲师，算法可以正确输出该讲师。 对于已经按升序或降序容差排序的序列，算法会适当地维持或反转顺序，确保使用最大标记而无需进行不必要的替换。
