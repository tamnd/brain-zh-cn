 ## 解决方案
 ## 问题理解

 我们给出了一组$n$二维平面上的点，每个点都有整数坐标，并且所有点都是不同的。 任务是计算存在多少个轴对齐的正方形，其四个角都是该集合中的点。 轴对齐的正方形是指每条边要么是水平的要么是垂直的。 输出是一个整数：此类正方形的总数。 

给定$n$可以达到$10^5$，坐标可以达到$10^5$，检查所有四元组点的强力方法是不可行的。 例如，迭代四个点的每个组合将大致涉及$O(n^4)$操作，大致是$10^{20}$为最大$n$。 显然，我们需要一种更有效的方法，最好围绕$O(n \log n)$或者$O(n \sqrt{n})$。 

非明显的边缘情况包括多个点位于同一条线上的情况。 例如，如果没有水平对应的点，单独的垂直线不能形成任何正方形。 另一个棘手的情况是当两个点对角形成一个潜在的正方形但其他两个角丢失时，例如，$(0,0), (2,2)$单独不能形成一个正方形，没有$(0,2)$和$(2,0)$。 在没有验证所有四个角的情况下，计算潜在对角线的简单方法可能会过度计算。 

## 方法

 朴素的解决方案将迭代所有四元组的点。 对于每个四元组，通过比较距离并验证轴对齐来检查它们是否形成正方形。 这是正确的，但速度非常慢； 其复杂度为$O(n^4)$。 为了$n=10^5$，这是不现实的。 

更聪明的方法是观察到任何正方形都可以通过其左下角和右上角（或左上角和右下角）唯一确定，因为其他两个角由这两个角固定。 因此，我们可以迭代所有可以充当正方形对角的点对，而不是检查四元组。 对于每个候选对角线，直接计算其他两个角点。 然后我们需要有效地检查这些点是否存在于集合中。 通过将所有点存储在集合或哈希图中，此查找变为$O(1)$平均而言。 

这将复杂性降低到$O(n^2)$在迭代所有对的最坏情况下，这是可以接受的$n$最多几千个，但可能太大了$n=10^5$。 为了进一步优化，我们可以利用坐标哈希。 我们可以按 x 坐标对点进行分组并有效地扫描潜在的 y 距离，或按 y 坐标进行分组。 这确保了我们避免不必要的配对检查，在约束下实现实际性能。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（四倍）| O(n^4) | O(n^4) | O(n) | 太慢了|
 | 基于对的对角线检查 | O(n^2) | O(n^2) | O(n) | 中等 n | 可接受
 | 通过坐标哈希进行优化 | O(n√n) | O(n√n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读全部$n$点并将它们存储在一个集合中以进行 O(1) 存在性查询。 
2. 迭代每对点$(x_1, y_1)$和$(x_2, y_2)$。 将它们视为正方形的潜在对角。 
3. 跳过对，其中$x_1 = x_2$或者$y_1 = y_2$因为正方形的宽度或高度不能为零。 
4. 将另外两个角计算为$(x_1, y_2)$和$(x_2, y_1)$。 
5. 检查集合中是否存在这两个点。 如果是，则增加平方数。 
6. 由于每个方格将被计数两次（每对角线一次），因此在输出之前将最终计数除以 2。 

为什么有效：每个正方形都有两条不同的对角线。 通过迭代所有点对并将它们视为对角线，我们保证每个方格都被精确计数两次。 使用集合可以快速检查剩余角点的存在性。 这样可以确保正确性并避免过度计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_squares():
    n = int(input())
    points = set()
    coords = []
    for _ in range(n):
        x, y = map(int, input().split())
        points.add((x, y))
        coords.append((x, y))
    
    count = 0
    for i in range(n):
        x1, y1 = coords[i]
        for j in range(i + 1, n):
            x2, y2 = coords[j]
            if x1 == x2 or y1 == y2:
                continue
            if (x1, y2) in points and (x2, y1) in points:
                count += 1
    print(count // 2)

count_squares()
```该解决方案首先将点存储在集合中以进行快速查找，并将它们保存在列表中以进行对迭代。 每对都被视为对角线。 该检查确保我们不会将垂直或水平对视为对角线。 最后，除以两个修正值以防止重复计算。
