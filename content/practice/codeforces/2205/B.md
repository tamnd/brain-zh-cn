 ## 解决方案
 ## 问题理解

 我们被要求帮助西蒙斯给他的朋友们分蛋糕。 更正式地说，对于给定数量的朋友$n$，我们需要找到最小的正整数$k$这样$k^n$可以整除$n$。 输入由多个测试用例组成，每个测试用例指定朋友的数量。 每种情况的输出都是最小值$k$满足整除条件。 

约束条件允许$n$一样大$10^9$测试用例数量最多为 100。任何尝试计算的算法$k^n$直接为所有人$k$最多$n$会太慢，因为大数的求幂是昂贵的并且迭代到$10^9$是不切实际的。 因此，挑战在于确定一种不需要暴力破解的方法。 

一个天真的方法会检查$k=1,2,3,\dots$并测试是否$k^n \mod n = 0$。 对于小$n$，这有效，但是对于$n\sim 10^9$，这将需要数十亿次迭代。 还，$1^n$始终为 1，当$n>1$，所以这是粗心实现的常见陷阱。 

另一个微妙的情况是当$n$是素数或素数的幂。 例如，$n=8$需要$k=2$因为$2^3 = 8$划分$2^8 = 256$。 对结构的误解$n$往往会导致高估$k$。 

## 方法

 暴力法迭代$k=1,2,3,\dots$并检查是否$n$划分$k^n$。 每次检查都涉及模幂，即$O(\log n)$。 在最坏的情况下，$k$可以大到$n$, 给予$O(n \log n)$。 为了$n \sim 10^9$，这太慢了。 

关键的见解来自因式分解。 让$n$有素因数分解$n = p_1^{a_1} p_2^{a_2} \dots p_m^{a_m}$。 拥有$k^n$可除以$n$, 每个素数$p_i$必须出现在$k^n$至少有指数$a_i$。 换句话说，多重性$p_i$在$k$必须至少是$\lceil a_i / n \rceil = 1$因为$a_i/n < 1$。 因此，最小$k$通过将不同的质因数相乘获得$n$。 

这将问题简化为质因数分解$n$，这对于给定的约束是有效的，因为$n \le 10^9$。 我们可以使用试除法进行因式分解$\sqrt{n}$，每个测试用例最多需要大约 31,622 次迭代。 不同素数相乘给出最小$k$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(1) | O(1) | 太慢了 |
 | 素数因式分解和乘积 | O(√n) | O(√n) | O(√n) | O(√n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$。 
3. 初始化质因数的空列表。 
4. 迭代$d$从 2 到$\sqrt{n}$。 如果$d$划分$n$， 添加$d$到主要因素列表。 然后划分$n$经过$d$如此反复，直到不能再整除为止。 这提取了最高功率$d$在$n$同时只记录不同的素数。 
5. 如果在循环之后$n>1$，它本身就是一个素因数，将其添加到列表中。 
6. 计算$k$作为所有不同质因数的乘积。 
7. 打印$k$。 

为什么它有效：每个素因数$n$必须出现在$k$， 否则$k^n$无法提供足够的素数倍数来除法$n$。 将每个不同的素数恰好包含一次会产生最小的$k$，因为增加更高的幂会不必要地增加$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def minimal_k(n):
    original_n = n
    k = 1
    for d in range(2, int(n**0.5)+1):
        if n % d == 0:
            k *= d
            while n % d == 0:
                n //= d
    if n > 1:
        k *= n
    return k

t = int(input())
for _ in range(t):
    n = int(input())
    print(minimal_k(n))
```该解决方案定义了一个函数`minimal_k`因式分解$n$并计算不同素数的乘积。 外循环读取所有测试用例。 使用`int(n**0.5)`确保试除法仅达到平方根。 内循环分为$n$重复乘以因子以消除所有幂，避免重复乘法。

 ## 边缘情况

 对于$n=2$，算法找到 2 作为唯一的素因数。 为了$n$主要的，$k=n$。 对于像 16 这样的素数的幂，算法找到 2，即不同的素数，这是正确的，因为$2^{16}$能被 16 整除。在每种情况下，不同素数的乘法产生最小$k$，证明基于分解的方法可以正确处理所有非明显的边缘情况。
