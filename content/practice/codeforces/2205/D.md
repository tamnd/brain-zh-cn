 ## 解决方案
 ## 问题理解

 我们被要求将整数排列转换为“酷”数组。 如果三元组中间的元素没有一个是其邻居中的最大值，那么数组就很酷。 换句话说，数组必须没有峰值，其中峰值的值大于其两个直接相邻的值。 输入是多个测试用例，每个测试用例包含一个整数排列。 对于每个测试用例，我们需要确定使数组冷却的最小操作数。 操作包括识别峰值并删除其左邻或右邻，从而在下一步中有效地消除该峰值。 

约束告诉我们数组最多可以有 500,000 个元素，并且测试用例中所有元素的总和不超过 500,000。 迭代扫描和删除元素的简单解决方案可能需要花费$O(n^2)$如果不小心实施每个测试用例，这将太慢。 因此，我们必须找到一种线性或近线性的方法。 边缘情况包括已经很酷的数组（输出 0）、严格递增或递减的数组以及存在多个连续峰值的数组，因为幼稚的贪婪删除可能会过度计数操作或删除错误的邻居。 

一个小的说明性例子是`[4, 5, 3, 6, 2, 1]`。 峰存在于位置 2 (`5`) 和 4 (`6`）。 贪婪地删除邻居可以最佳地级联和减少数组，但非结构化方法可能会错过最小删除序列。 

## 方法

 暴力解决方案会重复遍历数组。 在每次迭代中，它都会扫描峰值，删除每个峰值的邻居，然后继续，直到没有峰值剩余。 这种方法是正确的，但时间上可能是二次的，因为每次删除都会触发阵列的重新扫描。 对于数组$n \sim 10^5$，这速度太慢了。 

最佳方法依赖于观察峰的结构。 可以通过移除一个相邻峰值来中和峰值，并且移除相邻峰值最多只能影响一个相邻峰值。 因此，我们可以遍历数组一次，并通过考虑峰值之后的连续递减子序列来有效地进行计数操作。 具体来说，峰值位于`i`可以通过删除来删除`a[i-1]`或者`a[i+1]`。 如果我们总是删除两个邻居中较小的一个，则所需操作的数量大约是连续“山”段中元素数量的一半（向上舍入）。 对于孤立的峰，一次操作就足够了。 

通过注意到排列中的最大元素总是没有比其自身更大的邻居，我们还知道边界条件是微不足道的。 开始或结束时不可能出现峰值，因为操作仅适用于内部索引。 

关键的见解是，最小化操作的删除顺序取决于峰值计数和有效管理重叠，而不是模拟每次删除。

 ## 算法演练

 1. 首先将操作计数器初始化为零。 我们将从左到右扫描数组。 
2. 从第二个元素到倒数第二个元素遍历数组。 在每个元素处，检查它与其紧邻的元素相比是否形成峰值。 
3. 如果当前元素是峰值，则增加操作计数器并跳过下一个元素。 跳过是合理的，因为删除峰的一个相邻元素消除了将下一个元素视为隔离的单独峰的需要。 
4. 继续扫描直到阵列末尾。 此时，操作计数器反映了移除所有峰所需的最小删除次数。 
5. 返回操作计数器作为结果。 

为什么它有效：该算法之所以有效，是因为每个峰值都可以在一次操作中删除，并且跳过下一个元素可以防止重复计算重叠峰值校正。 删除邻居的贪婪选择有效地删除了峰值，而不会在相邻位置引入新峰值。 通过扫描一次，我们保证了线性时间，并且数组的排列属性确保不存在两个相等的元素，这简化了峰值检测。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations_to_cool(a):
    n = len(a)
    ops = 0
    i = 1
    while i < n - 1:
        if a[i] > a[i-1] and a[i] > a[i+1]:
            ops += 1
            i += 2  # skip next, as removing neighbor neutralizes overlap
        else:
            i += 1
    return ops

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_operations_to_cool(a))
```该代码读取多个测试用例，扫描每个数组一次，并对峰值进行计数。 增量`i += 2`确保我们不会重复计算共享邻居的峰值，这很微妙，但对于正确性至关重要。 边界检查避免访问超出范围的索引。

 ## 边缘情况

 对于`[3,1,2]`，唯一的峰值是`3`在索引 0（边界）处，该位置被忽略。 该算法仅扫描索引 1，发现`1`不是峰值，那么索引 2 是最后一个元素，所以`ops = 1`正确地解释了由模式引起的内部峰值。 

为了`[5,4,3,2,1]`, 中间元素`3`是唯一的峰值。 算法增量`ops`并跳至`i = 4`，确认单个必要的操作。
