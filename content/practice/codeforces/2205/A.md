 ## 解决方案
 ## 问题理解

 我们给出了一个排列`p`长度`n`。 一个索引`i`如果是第一次在该位置达到最大值，则称为丑陋。 更正式地说，`i`很丑如果`p[i]`等于最大值`p[1..i]`。 Simons 最多可以在数组中的任意两个位置之间执行一次交换。 我们的任务是输出一个排列`q`获得自`p`最多进行一次交换，从而最大限度地减少丑陋指数的数量。 

输入由多个测试用例组成。 每个测试用例提供`n`和数组`p`不同的整数`1`到`n`。 输出是一个排列`q`对于满足最小丑陋标准的每个测试用例。 

约束条件表明`n`最多可达 500 个，并且`t`最多 100 个。`n`小，甚至一个`O(n^2)`算法是可行的，但我们可以根据排列的性质和丑指数的定义找到线性时间解。 

一个幼稚的实现可能会尝试所有可能的交换并计算每个交换的丑陋索引，但这是不必要的。 边缘情况包括已经按降序排列的排列，其中第一个元素是最大的，或者已经是最佳排列，其中没有交换可以提高计数。 例如，`p = [3,1,2]`已经是最小的了，因为交换会增加丑陋。 

## 方法

 蛮力方法很简单：对于每个测试用例，迭代所有对`(i,j)`和`i<j`， 交换`p[i]`和`p[j]`，计算丑索引的数量，并跟踪具有最小计数的排列。 每次交换需要`O(n)`来算丑，所以总的时间复杂度是`O(n^3)`每个测试用例。 和`n = 500`，这大约是每个测试用例 1.25 亿次操作，根据常数因子，这可能勉强适合 1 秒，但这显然不是最理想的。 

最佳方法利用了这样一个事实：如果索引的值为运行最大值，则该索引是丑陋的。 为了减少丑陋，我们希望第一个元素是最大的，因为这样可以确保后续元素不会触发新的最大值，直到达到较小的数字。 一个简单的策略是找到最大元素`n`并将其放在数组的开头（如果尚不存在）。 将第一个元素与最大元素交换可以通过单个操作实现此目的。 如果最大值已经在开始时，则不需要交换。 这保证一开始只有一个丑陋的索引，从而最大限度地减少丑陋。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和排列`p`。 
3、找准定位`max_idx`的最大值`n`在数组中。 
4. 如果`max_idx`不是第一个位置，交换`p[0]`和`p[max_idx]`。 这确保了最大值在前，从而最大限度地减少丑陋的索引。 
5. 输出排列结果。 

为什么它有效：我们使用的属性是，如果索引是运行最大值的第一次出现，那么它是丑陋的。 通过将最大的元素放在第一个位置，我们保证第一个丑陋的索引位于位置1，并且在出现更大的数字之前没有其他索引可以丑陋，而更大的数字不存在。 这种策略是最优的，因为除了将最大的元素放在第一位之外，任何涉及较小元素的交换都无法减少丑陋。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    max_val = n
    max_idx = p.index(max_val)
    if max_idx != 0:
        p[0], p[max_idx] = p[max_idx], p[0]
    print(" ".join(map(str, p)))
```解法首先找到最大值的位置`p`。 如果它不在第一个位置，它将与第一个元素交换。 交换是安全的，因为每个测试用例允许一次。 我们使用`p.index(n)`这是`O(n)`，交换本身是`O(1)`。 这`print`语句输出每个测试用例的排列。 不使用数组之外的额外空间，并且边界条件如`n=1`自然会得到处理。

 ## 边缘情况

 对于`n = 1`，数组`[1]`只有一个元素并且是平凡最优的。 该算法检测到`max_idx = 0`，所以没有发生交换，输出是`[1]`。 

对于最大值已经是第一个的数组，例如`[3,2,1]`，算法保持排列不变。 交换任何其他元素都会增加丑陋索引的数量。 该算法正确地识别出初始排列是最优的，并且不执行不必要的操作。 

如果最大值位于最后一个位置，例如，`[1,2,3,4]`，算法交换`4`到第一个位置，给出`[4,2,3,1]`。 丑陋指数现在在位置 1 处最小化为 1，而任何其他交换都会在较早的位置留下多个丑陋指数。
