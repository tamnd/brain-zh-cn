 ## 解决方案
 ## 问题理解

 两个农民的奶牛必须以交替的顺序出现在线上。 一旦选择了第一头牛的顺序，整个顺序就固定了：

 要么`J N J N ... J N`或者`N J N J ... N J`。 

实际位置并不固定。 奶牛之间和墙壁附近可能有空的牢房。 

一次移动会选择一位农民的一些奶牛，然后将所有奶牛都朝同一方向移动一步。 仅当没有牛撞到墙壁并且没有牛落在被占用的位置上时，移动才是合法的。 

我们得到了生产线的长度和每个农民的奶牛数量。 在所有有效的位置中，我们必须计算有多少为农夫约翰获胜，假设最佳发挥并且约翰首先移动。 

约束是解决方案必须是组合的主要线索。 线长可达$10^6$，但测试文件的所有长度之和也最多为$10^6$。 这立即排除了任何分析单个游戏状态的尝试。 即使存储所有配置也是不可能的，因为有效放置的数量呈指数增长。 

唯一可行的方向是找到获胜和失败位置的简单特征，然后用组合数学来计算它们。 

一些边缘情况很容易被忽略。 

例如：

 输入```
1
2 1
```唯一有效的配置是：```
JN
NJ
```无论哪种配置，牛都无法移动，因此约翰立即失败。 正确答案是：```
0
```假设“除非棋盘已满，否则第一个玩家获胜”的幼稚方法将会失败。 

另一个重要案例是：

 输入```
1
3 1
```有效的配置是：```
JN_
_JN
N_J
J_N
```只有最后两个为约翰赢得了胜利。 正确答案是：```
2
```仅存在空单元格是不够的。 他们的位置很重要。 

最后一个微妙之处是游戏描述允许增加一些距离的移动，因此乍一看无限游戏似乎是可能的。 关键的博弈论观察是，最佳游戏完全取决于某些差距的平价。 一旦发现该结构，计数就变得易于管理。 

## 方法

 暴力解决方案将生成每个有效的配置，构建游戏图，并确定初始状态是否获胜。 

对于固定的交替顺序，配置本质上是放置$2n$牛之间$l$职位。 有$$\binom{l}{2n}$$这样的放置，并且有两种可能的交替顺序。 即使对于中等值，这个数字也是巨大的。 

例如，当$l=60$和$n=20$,$$\binom{60}{40}$$已经远远超出了我们所能列举的范围。 

蛮力方法在概念上是有效的，因为游戏是有限状态的，但在达到实际约束之前很久它就变得毫无用处。 

这一突破来自于对配对奶牛之间差距的观察。 

假设序列以约翰的牛开始：$$a_1 < b_1 < a_2 < b_2 < \cdots < a_n < b_n.$$定义$$g_i = b_i - a_i - 1.$$所以$g_i$是之间的空单元格数$i$-th John 牛和相应的 Nhoj 牛。 

这些间隙完全捕捉到了游戏。 

移动会精确地改变一些非零间隙$+1$或者$-1$。 关键的事实是差距的平价决定了获胜者：

 当且仅当每一个位置都处于亏损状态时$g_i$是均匀的。 

如果至少有一个间隙是奇数，约翰可以进入所有间隙都变为偶数的状态。 如果所有间隙都已经是偶数，那么每一个合法的动作都会产生一个奇数间隙。 

一旦游戏降低到这个平价标准，剩下的就是纯粹的计数了。 

我们计算所有有效的配置，然后减去间隙都是偶数的配置。

 ## 算法演练

 ### 1.修复一个交替顺序

 假设序列以约翰的牛开始：$$a_1 < b_1 < a_2 < b_2 < \cdots < a_n < b_n.$$相反的顺序贡献完全相同数量的配置，因此我们可以计算一个顺序并在最后乘以二。 

### 2. 定义重要差距

 对于每一对，$$g_i = b_i - a_i - 1.$$这些都是控制比赛的差距。 

还定义剩余的空段：$$x_0=a_1-1,$$

$$x_i=a_{i+1}-b_i-1 \quad (1\le i<n),$$

$$x_n=l-b_n.$$全部$x_i$和$g_i$是非负的。 

由于奶牛本身占据$2n$细胞，$$\sum x_i + \sum g_i = l-2n.$$让$$m=l-2n.$$### 3. 描述亏损头寸的特征

 当每个配置都丢失时$g_i$是均匀的。 

写$$g_i=2h_i.$$然后$$\sum x_i + 2\sum h_i = m.$$### 4. 计算丢失的配置

 让$$s=\sum h_i.$$然后$$\sum x_i = m-2s.$$这$h_i$是非负的并且有$n$其中。 

通过星星和酒吧，$$\#(h_1,\dots,h_n) = \binom{s+n-1}{n-1}.$$这$x_i$是非负的并且有$n+1$其中。 

再次通过星星和酒吧，$$\#(x_0,\dots,x_n) = \binom{m-2s+n}{n}.$$对于固定的$s$，因此丢失配置的数量是$$\binom{s+n-1}{n-1} \binom{m-2s+n}{n}.$$总结所有可能的情况$s$,$$L = \sum_{s=0}^{\lfloor m/2\rfloor} \binom{s+n-1}{n-1} \binom{m-2s+n}{n}.$$### 5. 统计所有配置

 对于一个交替订单，我们分配$m$之间的空单元格$$(n+1)+n = 2n+1$$非负变量。 

星星和酒吧给出$$\binom{m+2n}{2n} = \binom{l}{2n}.$$### 6. 计算答案

 对于一个订单，$$\text{winning} = \binom{l}{2n}-L.$$有两个对称交替的顺序，所以$$\text{answer} = 2\left(\binom{l}{2n}-L\right).$$所有算术均以模进行$998244353$。 

### 为什么它有效

 整个博弈可以通过间隙向量来表达$(g_1,\dots,g_n)$。 

一次移动会将选定的正间隙更改一个单位，因此每个更改的间隙都会翻转奇偶校验。 

如果所有间隙都是偶数，则每一步合法动作都至少产生一个奇数间隙。 这样的位置不能移动到另一个全偶位置。 

如果某个间隙是奇数，则每个奇数间隙都是正值。 将每个奇数间隙减一是合法的，并且会产生所有间隙均为偶数的状态。 

因此，每个非偶数位置都可以移动到全偶数位置，而每个全偶数位置只能移动到非偶数位置。 这完全符合输赢位置的定义。 

计数部分是正确的，因为每个有效位置都唯一对应于变量$x_i$和$g_i$，星条形计算所得方程的所有非负解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXL = 10**6 + 5

fact = [1] * MAXL
for i in range(1, MAXL):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * MAXL
inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)

for i in range(MAXL - 1, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

t = int(input())

for _ in range(t):
    l, n = map(int, input().split())

    m = l - 2 * n

    losing = 0

    for s in range(m // 2 + 1):
        ways_h = C(s + n - 1, n - 1)
        ways_x = C(m - 2 * s + n, n)
        losing = (losing + ways_h * ways_x) % MOD

    total_one_order = C(l, 2 * n)

    ans = (total_one_order - losing) % MOD
    ans = (2 * ans) % MOD

    print(ans)
```阶乘和反阶乘数组被预先计算一次，最多可达$10^6$，它涵盖了问题中所需的每个二项式系数。 

功能`C(n, r)`在恒定时间内评估组合。 

对于测试用例，`m = l - 2n`是空单元格的数量。 循环结束`s`直接执行亏损头寸公式：$$\sum \binom{s+n-1}{n-1} \binom{m-2s+n}{n}.$$第一个组合计算半间隙的分布$h_i$。 第二个计算剩余空单元格的分布$x_i$。 

然后通过从一个交替顺序的所有配置中减去失败的配置并为两个可能的起始农民乘以二来获得答案。 

最常见的实施错误是忘记了$n+1$变量$x_i$， 不是$n$。 使用错误的星条公式会将每个计数移动一位，甚至在小型测试中也会产生错误的答案。 

另一个容易犯的错误是忘记最后的乘法二。 上面的计数假设序列从约翰的牛开始。 相反的交替顺序贡献相同的金额并且必须包括在内。

import sys
import io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())

    tests = []
    max_l = 0

        l, n = map(int, input().split())
        tests.append((l, n))
        max_l = max(max_l, l)

    fact = [1] * (max_l + 5)
    for i in range(1, max_l + 5):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (max_l + 5)
    inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)

    for i in range(max_l + 4, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

    out = []

    for l, n in tests:
        m = l - 2 * n

        out.append(str(ans))

 ## 边缘情况

 考虑：```
1
2 1
```我们有$m=0$。 唯一可能的间隙值为$g_1=0$，这是偶数。 该算法计算：$$L=1, \qquad \binom{2}{2}=1.$$所以答案就变成了：$$2(1-1)=0.$$这符合游戏本身，因为两个玩家都不能移动。 

现在考虑：```
1
4 2
```奶牛占据了所有四个牢房。 再次$m=0$，因此每个间隙都被迫为零，从而均匀。 

该算法将每个配置都视为失​​败：$$L=\binom{4}{4}=1$$对于一个交替订单。 

相减后，获胜位置数为零。 这抓住了一个常见的错误，即假设仅交替顺序就可以创造获胜机会。 

最后，考虑：```
1
3 1
```这里$m=1$。 唯一失败的国家是那些$g_1=0$。 任何状态$g_1=1$有一个奇怪的差距并且正在获胜。 

求和正确产生：$$L=2,$$而配置总数是$$2\binom{3}{2}=6.$$因此：$$6-4=2$$获胜配置仍然保留，与样本完全匹配。
