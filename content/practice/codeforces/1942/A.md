 ## 解决方案
 ## 问题理解

 我们需要构造一个长度的数组`n`这样正好`k`其循环移位按非降序排序。 

循环移位选择某个位置作为数组的新开始，并将其余元素包裹起来。 例如，转变`[1, 2, 3]`是`[1, 2, 3]`,`[2, 3, 1]`， 和`[3, 1, 2]`。 

对于每个测试用例，我们给出`n`和`k`。 我们必须输出任何有效的数组，其排序循环移位的数量恰好是`k`，或输出`-1`如果不存在这样的数组。 

限制非常小。 全部的总和`n`值最多是`1000`，因此即使检查数组的所有移位也会很便宜。 挑战不在于效率，而在于发现一种能够准确产生所需数量的排序班次的结构。 

主要困难来自于理解排序循环移位的行为方式。 天真的尝试可能会尝试调整各个值，直到计数变为`k`，但循环移位的结构比最初出现的要严格得多。 

一个重要的边缘情况是`k = n`。 

例如：```
n = 4, k = 4
```数组`[1, 1, 1, 1]`之所以有效，是因为每个循环移位都是相同的，因此是排序的。 

另一个重要的边缘情况是`1 < k < n`。 

例如：```
n = 3, k = 2
```不存在有效的数组。 粗心的方法可能会尝试直接构造一个，但循环移位的基本特性使得这是不可能的。 

最后的边缘情况是`k = 1`。 

例如：```
n = 5, k = 1
```存在有效的答案。 我们需要一个恰好具有一次排序旋转的数组。 构造必须避免意外创建额外的排序班次。 

## 方法

 蛮力视角对于发现模式很有用。 

假设我们生成一些候选数组。 我们可以通过检查所有的来计算它的排序循环移位`n`旋转，并为每次旋转验证其元素是否不减。 这需要`O(n^2)`每个候选数组的工作。 

问题在于，暴力破解并没有告诉我们如何构建一个具有所需数量的已排序移位的数组。 搜索空间是巨大的。 

关键的观察来自于研究何时可以对循环移位进行排序。 

考虑一个不完全恒定的数组。 如果某个旋转已排序，则在该排序旋转中，恰好有一个位置可以使序列从最大值回绕到最小值。 该换行点唯一地确定排序旋转的起始位置。 

因此，非常量数组最多可以有一次排序循环移位。 

例如：```
[2, 3, 4, 1]
```仅从以下位置开始旋转`1`已排序：```
[1, 2, 3, 4]
```所有其他旋转都包含减少。 

获得多个排序旋转的唯一方法是每个元素都相等。 在这种情况下，每次旋转都是相同的，所以所有`n`旋转已排序。 

这立即表征了所有可能的答案：

 如果`k = n`，输出一个所有值都相等的数组。 

如果`k = 1`，输出恰好具有一次排序旋转的任何非常量数组。 

如果`1 < k < n`，答案是不可能。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个候选人 O(n²) | O(n) | 不是一个建筑 |
 | 最佳 | O(n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`。 
2.如果`k = n`， 输出`n`数量相等。 

每个循环移位都是相同的，因此所有`n`轮班已排序。 
3.如果`k = 1`， 输出：```
1 2 3 ... n
```这个数组是严格递增的，所以它的原始形式是排序的。 
4. 观察每个其他循环移位在第一个元素之后的某个位置开始并回绕到`1`在最后。 

由于较大的值出现在较小的值之前，因此无法对这些移位进行排序。 
5. 如果`1 < k < n`， 输出`-1`。 

任何非常量数组都不能有多个排序旋转，而常量数组则恰好具有`n`。 

### 为什么它有效

 排序循环移位只有两种可能的计数。 

如果所有元素都相等，则每次旋转都是相同的，并且所有`n`旋转已排序。 

否则，请考虑任何排序旋转。 在循环数组中必须有一个唯一的位置，序列可以从较大的值回绕到较小的值。 在该位置之后立即开始产生唯一可能的排序旋转。 因此，非常量数组最多可以有一个排序循环移位。 

这意味着可实现的值`k`正是`1`和`n`。 该构造针对这些情况输出有效的数组，并正确报告所有其他情况的不可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())

    if k == n:
        print(*([1] * n))
    elif k == 1:
        print(*range(1, n + 1))
    else:
        print(-1)
```第一个分支处理必须对每个循环移位进行排序的情况。 使所有元素相等可以保证每次旋转都是相同的。 

第二个分支处理需要恰好一个排序移位的情况。 严格递增数组已经有一个排序旋转，即它本身。 任何其他旋转都会环绕并将较大的数字放在较小的数字之前。 

最后一个分支涵盖了所有剩余的值`k`。 上面的证明表明没有任何数组可以实现这样的计数。 

实现很短，因为数学特征完全决定了答案。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())

        if k == n:
            ans.append(" ".join(["1"] * n))
        elif k == 1:
            ans.append(" ".join(map(str, range(1, n + 1))))
        else:
            ans.append("-1")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run("3\n2 2\n3 1\n3 2\n") == "1 1\n1 2 3\n-1"

# minimum size
assert run("1\n1 1\n") == "1"

# impossible middle value
assert run("1\n5 3\n") == "-1"

# all rotations sorted
assert run("1\n4 4\n") == "1 1 1 1"

# exactly one sorted rotation
assert run("1\n5 1\n") == "1 2 3 4 5"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1 1`|`1`| 尽可能小的实例 |
 |`5 3`|`-1`| 不可能的情况`1 < k < n`|
 |`4 4`|`1 1 1 1`| 每次旋转都必须排序 |
 |`5 1`|`1 2 3 4 5`| 恰好一个排序轮换 |

 ## 边缘情况

 考虑：```
1
1 1
```算法输入`k == n`分支，因为两个值都是`1`。 它输出：```
1
```正好有一个循环移位，而且是排序的。 

现在考虑：```
1
3 2
```该算法到达最后一个分支并输出：```
-1
```为什么这是正确的？ 如果所有元素都相等，则有`3`排序的轮换。 如果数组不是常量，则最多可以存在一次排序旋转。 计数为`2`是不可能的。 

最后考虑：```
1
5 5
```输出是：```
1 1 1 1 1
```每个循环移位都保持完全相同的数组，因此所有五次旋转都已排序。 准确地达到了所需的计数。
