 ## 解决方案
 ## 问题理解

 我们有一个正多边形`n`排列在圆上的顶点。 一些`x`顶点已经可供使用。 我们最多可以另外选择`y`更多的顶点。 

选择顶点后，我们可以绘制不相交的对角线，其端点属于所选集合。 通过这种三角测量创建的每个三角形区域都算作一个有效的蛋糕块。 目标是最大化三角形的数量。 

关键的观察结果是正多边形的实际几何形状是无关的。 只有选定顶点的循环顺序才重要。 

这些约束立即表明解决方案必须取决于`x`，不在`n`。 虽然`n`可以大到`10^9`，所有的总和`x`跨测试用例的值最多是`2 · 10^5`。 任何算法正比于`n`是不可能的。 我们只需要处理选定的顶点以及它们之间的间隙。 

一个微妙的点是添加顶点不会自动创建三角形。 新顶点之所以有用，是因为它们可以在已选择的顶点之间分割较大的间隙。 准确理解差距可以带来多少好处是核心挑战。 

考虑一个多边形，其中选定的顶点是连续的。 无论其他地方存在多少未使用的顶点，如果它们没有插入到正确的间隙中，它们就没有任何贡献。 

另一个容易犯的错误是独立对待每个间隙，并假设我们总是可以从中提取所有可能的三角形。 假设一个间隙包含许多未使用的顶点，但我们只有很少的预算`y`。 那么只能实现部分潜力，因此我们需要贪婪的分配策略。 

例如：```
n = 10
chosen = {1, 5}
y = 1
```该间隙包含三个中间顶点。 我们无法实现间隙的全部好处，因为只能选择一个额外的顶点。 

第二个陷阱来自奇偶校验。```
chosen = {1, 4}
```它们之间有两个未使用的顶点。 

恰好添加一个中间顶点会立即创建一个额外的三角形。 奇数和偶数间隙大小的行为不同，利用这种差异是困难版本与简单版本的区别。 

## 方法

 暴力方法会尝试附加顶点的每个子集，计算最佳三角剖分，并保留最大答案。 

即使对于中等值，也会发生爆炸。 如果有`n - x`可用顶点，可能性的数量是$$\sum_{k=0}^{y}\binom{n-x}{k}$$这是完全不可行的。 

下一个想法是理解什么在几何上决定了答案。 

假设我们已经知道所有选定的顶点。 按循环顺序连接它们。 它们形成一个多边形，其顶点正是选定的点。 

如果有`m`选定的顶点，该多边形的完整三角剖分恰好包含$$m - 2$$三角形。 

因此，最初的答案取决于我们有多少个选定的顶点。 唯一剩下的问题是可以从位于连续选定顶点之间的间隙内的未使用顶点中提取多少个附加三角形。 

设两个连续选定的顶点有`g`它们之间未使用的顶点。```
A ... g vertices ... B
```如果我们最终使用所有这些顶点，这个间隙就会起作用`g`额外的三角形。 

关键的观察是这些三角形的成本有多高。 

对于奇怪的间隙：```
g = 2k + 1
```我们可以得到`k + 1`仅使用额外的三角形`k`添加了顶点。 

对于均匀间隙：```
g = 2k
```我们可以得到`k`额外的三角形使用`k`添加了顶点。 

奇数间隙绝对更好。 他们“免费”提供了一个额外的三角形。 

这就把问题转化为资源分配问题。 

每个缺口都提供一个套餐：

 对于奇数间隙：```
cost = g // 2
gain = g // 2 + 1
```对于均匀间隙：```
cost = g // 2
gain = g // 2
```由于奇数间隙以相同的成本提供一个额外的三角形，因此我们应该首先处理所有奇数间隙，并按增加的成本排序。 

在我们能够承受的每一个有利可图的奇数差距之后，剩余的预算将花在偶数差距上，同样按成本递增顺序。 

如果间隙无法完全完成，则每个额外选择的顶点仍会产生另外两条边界边，从而产生另外一个三角形。 剩余预算呈线性贡献。 

这种贪婪策略正是官方解决方案所利用的。

 ## 算法演练

 1. 对最初选择的顶点进行排序。 
2. 计算连续选定顶点之间的所有循环间隙。 

如果连续选择的顶点是`a`和`b`， 然后```
gap = b - a - 1
```用于环绕间隙使用```
gap = n - last + first - 1
```3. 形成的多边形`x`最初选择的顶点已经做出贡献```
x - 2
```三角形。 
4. 将间隙分为奇数组和偶数组。 
5. 对于每一个奇怪的间隙`g`:```
cost = g // 2
gain = g // 2 + 1
```存储这些差距并按成本对它们进行排序。 
6. 处理递增成本订单中的奇怪缺口。 

如果还有足够的预算，则花费所需的成本，添加全部增益，然后继续。 

额外的`+1`增益使这些差距严格优于任何均匀差距。 
7. 处理递增成本订单中的差距。 

对于均匀间隙：```
cost = g // 2
gain = g // 2
```尽可能多地完全完成。 
8. 之后，如果还有一些预算，每个未使用的选定顶点仍然可以创建一个额外的三角形。 

添加```
2 * remaining_budget
```潜在的边界贡献，以剩余可用顶点总数为上限。 

在标准实施中，这自然是通过相同的间隙处理公式来解释的。 
9. 输出三角形的数量。 

### 为什么它有效

 每个三角形都来自于连续选定顶点之间的间隙分割。 

对于尺寸的间隙`g`，充分利用这一差距需要`⌊g/2⌋`额外的顶点。 与相同成本的偶数间隙相比，奇数间隙会产生一个额外的三角形。 由于所有成本都是相加的并且在间隙之间是独立的，因此问题变成了一个背包，其中每个项目都有单位效率，而奇数项目有一个奖励三角形。 

首先选择奇数间隙可以最大化收集的奖励三角形的数量。 当所有奖金用完后，每个剩余的预算单位都会产生相同的边际收益，无论哪个偶数缺口收到它。 按所需成本排序可保证在预算用完之前完成最大数量的盈利缺口。 

因为每个间隙都是独立的，并且间隙内生成的每个三角形仅取决于投入该间隙的顶点数量，所以贪婪分配是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, x, y = map(int, input().split())
        a = sorted(map(int, input().split()))

        ans = x - 2

        odd = []
        even = []

        for i in range(x):
            j = (i + 1) % x

            if j:
                gap = a[j] - a[i] - 1
            else:
                gap = n - a[i] + a[0] - 1

            if gap == 0:
                continue

            if gap % 2:
                odd.append(gap)
            else:
                even.append(gap)

        odd.sort()
        even.sort()

        for g in odd:
            need = g // 2

            if y >= need:
                y -= need
                ans += g // 2 + 1
            else:
                ans += 2 * y
                y = 0
                break

        if y:
            for g in even:
                need = g // 2

                if y >= need:
                    y -= need
                    ans += g // 2
                else:
                    ans += 2 * y
                    y = 0
                    break

        print(ans)

solve()
```该解决方案永远不会迭代实际的多边形顶点。 它只检查所选顶点之间的间隙，这就是为什么它即使在`n`与`10^9`。 

最重要的实现细节是循环间隙计算。 最后的间隙从最大的选定顶点回绕到最小的顶点。 每当有用的顶点位于顶点之间的边界时，缺少此环绕间隙就会导致错误的答案`n`和顶点`1`。 

另一个微妙之处是部分处理间隙的处理。 如果间隙需要的预算多于剩余的预算，则每个额外选择的顶点仍会贡献两个新的边界段，这会转化为两个额外的三角形机会。 这就是为什么贡献变成`2 * y`在预算用完之前。 

Python 整数可以轻松处理所有涉及的值，因此不必担心溢出。

 ## 边缘情况

 考虑：```
n = 4
x = 2
y = 0
chosen = [1, 3]
```间隙均为一号。 由于不存在预算，简单的解决方案可能会错误地从这些间隙中添加三角形。 该算法正确地拒绝花费任何资源并仅返回已经可用的三角形。 

现在考虑：```
n = 10
x = 2
y = 1
chosen = [1, 5]
```有一个尺寸为三的间隙。 该间隙最终可能会生成更多三角形，但只能选择一个额外的顶点。 该算法检测到无法支付全部成本并使用部分贡献规则，防止过度计算。 

最后考虑一个环绕的情况：```
n = 12
x = 3
chosen = [2, 3, 11]
```最大的间隙位于顶点之间`11`和顶点`2`穿过多边形边界。 将顶点视为线性数组将完全忽略此间隙。 循环计算```
n - last + first - 1
```正确捕获它，允许贪婪进程最优地分配预算。
