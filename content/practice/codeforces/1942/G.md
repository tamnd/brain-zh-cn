 ## 解决方案
 ## 问题理解

 这副牌包含四种牌。 抽 0 牌会消耗你手上的一张可玩牌并且不会给予任何回报。 一张抽 1 的牌会取代它本身。 抽2张牌会消耗一张牌并提供两张新牌，因此它会将您未来的抽奖能力增加一分。 还有 5 张特殊卡，目标是在卡住之前抽完所有卡。 

一开始，Bessie 抽出前 5 张牌。 此后她可以重复打出她手中当前的抽牌。 一张牌只能打一次。 如果在某个时刻没有剩余可玩的抽牌，则该过程结束。 

我们得到了抽 0、抽 1 和抽 2 牌的计数。 这副牌是随机均匀洗牌的。 我们必须计算最终抽出所有 5 张特殊牌的概率，并输出该概率模`998244353`。 

这些约束足够大，任何状态空间模拟都是没有希望的。 每一个`a`,`b`， 和`c`可以达到`2 · 10^5`，并且可能最多有`10^4`测试用例。 复杂度与牌组排列数量成正比的算法显然是不可能的，但即使是二次 DP`a`和`c`会超出限制。 由于所有的总和`a`,`b`， 和`c`跨测试用例最多每个`2 · 10^5`， 一个`O(a + c)`每个测试用例的解决方案都是可行的。 

有一些容易被忽视的案例。 

考虑`a = b = c = 0`。 这副牌只包含 5 张特殊牌。 Bessie 一开始就立即抽出所有 5 张牌，所以答案正是`1`。 

考虑`a = 1, b = 0, c = 0`。 这副牌包含一张 0 抽牌和五张特殊牌。 Bessie 抽取前 5 张牌，并且永远无法获得额外的牌。 除非抽 0 的牌出现在前 5 个位置中，并将一张特殊牌推到第 6 位置，否则她获胜。概率不是`1`，即使只有一张非特殊卡。 

另一个微妙之处是，抽 1 张牌不会改变 Bessie 未来可以使用的牌的数量。 粗心的解决方案可能会尝试将它们纳入 DP 状态，这会造成比必要的问题大得多的问题。 实际上它们与停止条件完全无关。 

## 方法

 暴力解决方案将枚举每副牌的顺序，模拟游戏，并计算有多少次洗牌导致获胜。 

模拟本身很容易。 保持当前手牌，重复打出可用的抽牌，当没有剩余时停止。 如果所有 5 张特殊牌都被看到，则洗牌成功。 

问题在于洗牌的次数。 甲板尺寸可以是大约`6 · 10^5`整个测试用例的总数。 即使对于很小的输入，排列的数量也会呈阶乘增长。 这种方法几乎立刻就变得不可能了。 

关键的观察结果是抽 1 卡对资源平衡没有任何贡献。 玩一张牌会消耗一张牌并抽取一张牌。 他们从不帮忙，也从不伤害。 

现在定义一个平衡：

 - 从平衡开始`5`，因为前 5 张牌是免费抽取的。 
- 抽2张牌有贡献`+1`。 
- 抽0卡有贡献`-1`。 
- 一张特殊卡也有贡献`-1`，因为它占用了一个抽奖位置但无法播放。 

当贝西从上到下翻开牌时，余额告诉我们还可以翻开多少张牌。 

该过程恰好在余额变为的第一个前缀处停止`0`。 

这将游戏转化为格路径问题。 

完全忽略抽1张牌。 剩下的卡牌中：

 -draw-2 变为`+1`- 绘制-0 变为`-1`- 特别成为`-1`我们从高处开始`5`。 

获胜牌组是指在第一次余额达到之前所有 5 张特殊卡都出现的牌组`0`。 

假设第一次点击`0`准确使用后发生`p`抽2张牌。 那么停止前缀必须包含：

 -`p`抽2张牌
 -`p + 5`负面卡

 由于所有 5 个特价商品必须已经看过，因此`p + 5`负面因素包括：

 - 所有 5 种特价商品
 - 正是`p`抽0张牌

 牌组的其余部分是任意的。 

剩下的任务就是计算选票路径。 我们需要序列数`p`上台阶和`p + 5`从高处开始的向下台阶`5`并击中`0`第一次出现在前缀的末尾。 

经典伯特兰选票/反射原理结果给出$$F_p = \frac{5}{2p+5}\binom{2p+5}{p}.$$选择这样的路径后，我们选择哪一条`p+5`负数位置包含 5 个特殊项，然后排列剩余的后缀。 

这直接导致了总和`p`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 甲板尺寸的阶乘| 指数| 太慢了 |
 | 最佳 |`O(min(a,c))`每个测试用例|`O(a+c)`预计算| 已接受 |

 ## 算法演练

 1. 忽略所有抽1牌。 

他们永远不会改变平衡。 删除它们可以保留影响可达性的每张卡的相对顺序。 
2.让余额第一次达到`0`准确地使用`p`抽2张牌。 

既然我们从平衡开始`5`，达到`0`需要净变化`-5`。 因此停止前缀恰好包含`p+5`负面卡。 
3. 强制所有 5 张特殊卡出现后再停止。 

其中`p+5`停止前缀中的负数位置，选择其中 5 个包含特价商品。 

计数是$$\binom{p+5}{5}.$$4. 计算有效的平衡路径。 

停止前缀包含`p`积极的步骤和`p+5`消极的步骤。 

平衡必须保持正值，直到最后一步。 

根据选票定理，$$F_p=\frac{5}{2p+5}\binom{2p+5}{p}.$$5. 排列剩余的卡片。 

停止前缀固定后，后缀包含：

 -`a-p`抽0张牌
 -`c-p`抽2张牌

 后缀排列的数量为$$\binom{a+c-2p}{a-p}.$$6. 对所有可行值求和`p`。 

既然我们需要`p`抽 0 张牌和`p`在停止前缀内抽 2 张牌，$$0 \le p \le \min(a,c).$$7. 除以非零卡序列的总数。 

忽略抽 1 张牌，序列总数为$$\frac{(a+c+5)!}{a!\,c!\,5!}.$$8. 简化公式并对其求模`998244353`。 

### 为什么它有效

 每个游戏状态完全由平衡性决定。 抽 2 会将未来的可达性增加 1，而抽 0 和特殊卡都会将其减少 1。 游戏恰好在余额为零的第一个前缀处结束。 

对于固定停止点，停止前缀必须包含相同数量的抽 0 牌和抽 2 牌，但由五张特殊牌造成的额外赤字 5 张除外。 选票定理精确计算那些余额从未更早达到零的前缀。 在负面步骤中选择特殊牌的位置可以保证在停止之前抽出所有特殊牌。 每副获胜牌只对应一个值`p`，并且每个计数的配置都会产生有效的获胜牌组。 因此，所有获胜牌组的总和只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXN = 400005

fac = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (MAXN + 1)
invfac[MAXN] = pow(fac[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fac[n] * invfac[r] % MOD * invfac[n - r] % MOD

def solve():
    t = int(input())

    for _ in range(t):
        a, b, c = map(int, input().split())

        total_inv = pow(
            fac[a + c + 5] * invfac[a] % MOD * invfac[c] % MOD * fac[5] % MOD,
            MOD - 2,
            MOD
        )

        good = 0

        for p in range(min(a, c) + 1):
            ballot = 5 * pow(2 * p + 5, MOD - 2, MOD) % MOD
            ballot = ballot * C(2 * p + 5, p) % MOD

            specials = C(p + 5, 5)
            suffix = C(a + c - 2 * p, a - p)

            good = (good + ballot * specials % MOD * suffix) % MOD

        ans = good * total_inv % MOD
        print(ans)

solve()
```实现直接遵循计数参数。 

阶乘表支持恒定时间二项式系数。 自从`a + c + 5`永远不会超过`400005`，一次全局预计算就足够了。 

变量`ballot`商店$$\frac{5}{2p+5}\binom{2p+5}{p},$$计算模数`MOD`。 除法是通过模逆来执行的。`specials`选择哪些负位置对应于特殊卡，而`suffix`排列停止前缀后剩余的卡片。 

数量`good`计算获胜的非零牌序列。 非零卡序列的总数为$$\frac{(a+c+5)!}{a!\,c!\,5!},$$所以我们最后乘以它的模逆。 

一个常见的错误是试图将抽1张牌保留在计数中。 它们永远不会影响平衡，因此这样做只会使组合变得复杂，并且通常会导致计数过多。

 ### 示例 1

 输入：```
1 1 1
```可能的值`p`是`0`和`1`。 

| p| 选票计数 | 选择特价| 后缀计数 | 贡献 |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | 1 | 2 | 2 |

 总获胜序列：$$2 + 30 = 32.$$总非零卡序列：$$\frac{7!}{1!\cdot1!\cdot5!}=42.$$可能性：$$\frac{32}{42} = \frac{16}{21}.$$这与样本相符。 

该迹线显示了总和如何自然地按余额首次达到零的位置划分。

        if r < 0 or r > n:

 ## 边缘情况

 第一个边缘情况是只包含特价商品的牌组。```
a = 0, b = 0, c = 0
```余额开始于`5`。 所有五张牌都会立即抽出，因此在该过程停止之前，每张特殊牌都会被看到。 式中，仅`p = 0`做出贡献。 答案就变成了`1`。 

第二种边缘情况是有额外的 0 抽牌，但没有 2 抽牌。```
a = 1, b = 0, c = 0
```唯一有效的值是`p = 0`。 停止前缀恰好由五个特殊符号组成。 如果 0 抽卡出现在任何特殊卡之前，则一张特殊卡将被推到停止点之外，贝西就输了。 计数公式给出概率`5/6`，它与直接参数匹配。 

第三种边缘情况是大量抽 1 牌。```
a = 0, b = 200000, c = 0
```余额永远不会改变，因为抽 1 卡的贡献为零。 贝西不断地抽完每张抽1张牌，最终抽到所有特价牌。 该算法甚至从未使用过`b`，这正确地反映了抽 1 卡对可达性没有影响的事实。 

最后一个微妙的情况是`a`和`c`非常不同。```
a = 200000, c = 0
```求和只允许`p = 0`。 不会生成无效项，因为范围是`0 .. min(a,c)`。 这避免了负二项式参数，并且即使在约束边界也能保持计算正确。
