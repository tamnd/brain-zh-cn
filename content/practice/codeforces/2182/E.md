 ## 解决方案
 ## 问题理解

 Monocarp 希望用有限的预算让尽可能多的朋友开心。 他有很多朋友和一套盒子。 每个盒子都有一个颜值，每个朋友都有三个要求：一个自己关心的最低盒子颜值，一个最低礼物价值，以及一个无论盒子都保证幸福的较高门槛礼物价值。 单果最多可以花`k`总共有硬币，每个盒子最多可以容纳一件礼物。 任务是在给定这些限制的情况下最大化满意的朋友数量。 

输入给出了多个测试用例。 对于每个测试用例，我们都会得到好友数量、盒子数量、可用硬币总数、每个盒子的美丽程度以及三个数字`x_i`,`y_i`， 和`z_i`为每一位朋友。 每个测试用例的输出是一个整数，表示可以使快乐的朋友的最大数量。 

制约因素很大。 一个测试用例中最多可以有 200,000 个朋友或盒子，并且`k`可以大到 10^15。 这立即排除了尝试所有可能的礼品盒分配或礼品价值组合的暴力方法。 考虑每对朋友和盒子的简单解决方案的复杂度为 O(n * m)，最多 4 * 10^10 次操作，并且不可行。 

需要小心处理的边缘情况包括所有盒子的美观程度太低，无法在不超支的情况下满足任何朋友的情况，或者预算仅够购买最低限度的礼物但不足以购买更高的门槛的情况。 当硬币足以满足所有要求时，就会出现另一个棘手的情况`y_i`值，但连一个都买不起`z_i`颜值，盒子美度不足。 例如，如果`k = 5`,`boxes = [1]`，并且有一个朋友有`x=2, y=3, z=6`，那么唯一买得起的礼物是`y=3`，但是盒子颜值太低，所以幸福得不到保证； 正确答案是`0`。 

## 方法

 蛮力方法将以所有可能的方式将每个盒子分配给朋友，计算满足该分配的幸福感所需的最低礼物，并检查预算是否满足`k`允许它。 这种方法之所以有效，是因为它考虑了所有可能性并保证了正确性。 然而，对于多达 200,000 个朋友和盒子，分配的数量是阶乘规模的，甚至尝试在简单的双循环中直接将朋友与盒子配对也会导致 O(n * m)，这太慢了。 

关键的见解是，朋友只关心两件事：要么盒子的美丽超出了他们的门槛`x_i`或者礼物价值至少为`z_i`。 礼物总能满足下限`y_i`以满足预算约束。 这使我们能够将问题视为盒子和朋友之间的匹配问题，我们的目标是使用更高的阈值来最大化快乐的朋友数量`z_i`必要时。 通过按相关阈值对盒子和朋友进行排序，并使用贪婪的双指针或二分搜索方法，我们可以有效地确定哪些朋友可以在不超出预算的情况下满足可用的盒子。 

具体来说，如果我们按照降序处理朋友`x_i`（盒子要求），并分配满足朋友要求的最高可用美容盒子`x_i`，那么任何一个我们不能用盒子满足的朋友都必须收到至少`z_i`如果预算允许。 全部的总和`y_i`保证适合`k`，所以我们只需要考虑价值为 的礼物的额外费用`z_i`。 排序允许 O(n log n + m log m) 效率，并且双指针或二分搜索确保我们贪婪地匹配框，而无需重新访问之前的决策。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n + m) | 太慢了|
 | 排序+贪心+两指针| O(n log n + m log m) | O(n log n + m log m) | O(n + m) | 已接受 |

 ## 算法演练

 1、将盒子美人数组按升序排序。 这允许使用双指针或二分搜索进行有效匹配。 
2. 对于每个朋友，确定是否可以满足他们的盒子要求。 为此，请按降序对好友进行排序`x_i`并跟踪哪些盒子可用。 
3. 迭代朋友并尝试分配最小的可用盒子，其美度至少为`x_i`。 将此框标记为已使用。 这可确保箱子不会被重复计算。 
4. 对于无法分配到合适箱子的朋友，请计算超出所需的额外金币`y_i`让他们开心（`z_i - y_i`）。 保持这些额外成本的运行总计。 
5. 如果额外费用总额超过`k - sum(y_i)`，停止给好友分配更高门槛的礼物。 到目前为止成功分配的朋友数量就是可实现的最大幸福感。 
6. 总和`y_i`总是 ≤`k`，因此在强制性最低礼物之后的任何剩余预算都可以用于支付这些额外费用。 

为什么有效：对盒子和朋友进行排序可确保每个朋友都匹配到最低限度的足够资源（盒子或额外的硬币）。 先处理最大的需求，避免了小盒美女被低要求的朋友消费，而高要求的朋友不满意的情况。 不变的是，所考虑的任何朋友都已与满足条件的框相匹配`x_i`或用额外的硬币来达到`z_i`。 由于盒子最多使用一次，并且额外的硬币会根据剩余预算进行检查，因此不会发生过度使用的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        boxes = sorted(map(int, input().split()))
        friends = []
        sum_y = 0
        for _ in range(n):
            x, y, z = map(int, input().split())
            friends.append((x, y, z))
            sum_y += y
        
        friends.sort(reverse=True)  # sort descending by x_i

        used = [False] * m
        happy = 0
        extra_needed = []

        j = m - 1  # pointer to the largest available box
        for x, y, z in friends:
            while j >= 0 and boxes[j] >= x:
                j -= 1
            if j < m - 1:
                happy += 1  # friend happy with a box
            else:
                extra_needed.append(z - y)

        extra_needed.sort()
        remaining = k - sum_y
        for cost in extra_needed:
            if remaining >= cost:
                remaining -= cost
                happy += 1
            else:
                break

        print(happy)

if __name__ == "__main__":
    solve()
```该代码有效地读取输入并独立处理每个测试用例。 好友按照降序排列`x_i`最大化首先满足最大需求的机会。 盒子经过分类，可以快速找到最低限度的足够美感。 这`extra_needed`array为不能满足盒子的朋友收取额外的硬币费用。 排序`extra_needed`确保我们从最小到最大的成本贪婪地花费预算，最大化快乐朋友的数量。
