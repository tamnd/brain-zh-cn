 ## 解决方案
 ## 问题理解

 我们得到一个由字符 0、2、5 和 6 组成的字符串。如果一个字符串包含子字符串，则该字符串被视为_新年字符串_`2026`某处或不包含子字符串`2025`根本不。 对于每个字符串，我们可以多次将任何字符更改为四个允许的字符之一。 我们的任务是计算使字符串成为新年字符串所需的此类字符替换的最小数量。 

每个测试用例提供字符串长度`n`和字符串`s`。 限制条件`4 ≤ n ≤ 20`直至`10^4`测试用例意味着字符串足够短，可以进行简单的暴力或组合检查，但测试用例的数量很高，因此我们需要一个对每个单独的字符串都有效的解决方案。 

当字符串已经部分包含时，会出现不明显的边缘情况`2025`或者`2026`。 例如，字符串`2025`不是新年字符串，并且需要至少进行一项更改。 替换最后一个`5`和`6`做到了`2026`，满足第一个条件。 另一个棘手的情况是`20252025`，其中包含`2025`两次。 仅仅改变最后一个字符是不够的； 我们需要最小的改变，要么引入`2026`或删除`2025`。 

## 方法

 天真的暴力方法是尝试所有可能的字符替换组合。 对于每个角色，我们可以尝试所有四种可能的替换，生成`4^n`可能的字符串。 为了`n = 20`，这产生了超过一万亿种可能性，这显然是不可行的。 

关键的观察结果是该问题仅限于短字符串。 唯一直接触发需求的子字符串是`2026`或者`2025`。 因此，我们不需要生成所有字符串； 我们只需要检查输入中每个长度为 4 的子字符串。 对于每个 4 长度的窗口，我们计算需要多少个字符更改才能使其准确`2026`。 所有窗口中这些值的最小值是满足第一个条件所需的最小更改数量。 

如果字符串包含`2025`，我们可以修改一些字符来打破`2025`或直接将出现的一个转换为`2026`（同时打破`2025`并满足第一个条件）。 这使得解决方案变得更加简单：迭代所有长度为 4 的子字符串，计算不匹配`2026`，并选择最小值。 因为`n ≤ 20`，这个检查最多需要`17 * 4 = 68`每个字符串的比较，这足够快`10^4`测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有替换）| O(4^n) | O(4^n) | O(n) | 太慢了|
 | 最优（检查长度为 4 的子串）| 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取字符串`s`和它的长度`n`。 
3. 初始化变量`min_changes`具有很大的价值。 这将存储所需的最少操作。 
4. 迭代所有长度为 4 in 的子串`s`。 对于每个子字符串，计算与目标字符串不同的字符数`2026`。 
5. 更新`min_changes`在所有子串中找到最小的不匹配。 
6. 如果字符串不包含`2025`根本没有，那么根据第二个新年字符串条件需要零更改。 
7. 输出每个测试用例的最少操作数。 

为什么它有效：通过检查所有长度为 4 的子字符串`2026`，我们保证如果有可能创建`2026`在变化最小的字符串中，我们会找到最优的数字。 对于不包含的字符串`2025`，该算法隐式返回零，因为不需要进行任何更改即可满足第二个条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    if "2025" not in s:
        print(0)
        continue
    
    min_changes = float('inf')
    for i in range(n - 3):
        substring = s[i:i+4]
        changes = sum(substring[j] != target for j, target in enumerate("2026"))
        if changes < min_changes:
            min_changes = changes
    print(min_changes)
```这段代码首先检查是否`2025`存在。 如果不是，则需要零更改。 否则，它会迭代每个 4 字符子字符串并计算与`2026`。`min_changes`确保我们找到最少的操作数。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|

 ## 边缘情况

 对于第二个条件已经有效的字符串，例如`0000`，算法检查`2025`。 由于它不存在，因此立即输出零。 对于有多个重叠的字符串`2025`，该算法检查长度为 4 的所有子字符串，并找到要创建的字符更改的最小数量`2026`，同时删除所有实例`2025`在该子字符串内。 对于已经包含的字符串`2026`, 不匹配`2026`将为零，因此输出为零，确认正确性。
