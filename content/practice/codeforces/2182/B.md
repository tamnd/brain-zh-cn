 **求解时间：** 1m 30s

 ## 解决方案
 ## 问题理解

 我们被要求帮助 Monocarp 在两个限制下烘烤分层蛋糕：每层的大小呈指数级增长，并且覆盖每层的巧克力必须在白色和深色之间交替。 顶层的大小始终为 1。下一层的大小为 2，接下来是 4，然后是 8，依此类推，每次都会加倍。 每层消耗与其大小相同的巧克力公斤数，而 Monocarp 的白巧克力和黑巧克力供应有限。 任务是确定他在不超过巧克力供应量的情况下可以建造的最大层数。 

输入提供了多个测试用例，每个测试用例指定了白巧克力和黑巧克力的数量。 每个测试用例的输出必须是一个整数：可能的最大层数。 自从`a`和`b`最多可以达到 10^6，并且最多可以有 10^4 个测试用例，任何算法在每个测试用例中都必须以大约 O(log N) 的速度运行，因为简单的线性迭代可以达到每个测试用例数百万次操作，并且总体上可以达到数十亿次。 

一个微妙的点是交替的巧克力需求。 一种天真的贪婪方法可能会开始分层添加白巧克力或黑巧克力，然后继续添加，直到一块巧克力用完。 但如果我们总是从白色开始，我们可能会错过从黑暗开始的最佳解决方案。 例如，如果`a = 1`和`b = 2`，从白色开始仅允许一层（尺寸 1），而从深色开始允许两层（1 深色，2 白色）。 当巧克力足以容纳几个小层但不足以容纳下一个大层时，就会出现另一种边缘情况。 该算法必须增量检查每一层并考虑两个起始选项。 

## 方法

 蛮力方法迭代各层，每次将大小加倍，并根据交替模式从相应的巧克力池中减去。 这是正确的，因为它直接模拟了蛋糕制作过程。 问题是，在最坏的情况下，层数可能最多为 20（因为当 k ≈ 19 时，几何级数 1 + 2 + 4 + ... + 2^k 的总和超过 10^6），因此这里暴力破解实际上足够快。 每个测试用例需要的迭代次数少于 20 次，在最坏的情况下总共需要 2_10^4_20 = 4*10^5 次操作，这完全在 2 秒的限制之内。 

关键的见解是我们只需要模拟两种可能的起始选择：从白色开始或从黑暗开始。 计算完两者后，我们取最大值。 每个模拟逐层进行，将层大小加倍并从相应的巧克力类型中减去，当下一层超出可用巧克力时停止。

 ## 算法演练

 1. 对于每个测试用例，读取白巧克力的数量`a`和黑巧克力`b`。 
2.初始化两个计数器，`count1`和`count2`，分别表示从白色开始或从深色开始的层数。 
3.为了`count1`，模拟从白色开始的蛋糕：

 1. 将当前图层大小初始化为1。 
2. 当当前层有足够的巧克力时：

 1. 从适当的巧克力类型中减去层的大小，交替放置每一层。 
2. 将图层大小加倍。 
3. 增加层数。 
4. 重复步骤 3`count2`，从黑巧克力开始。 
5. 返回最大值`count1`和`count2`作为此测试用例的答案。 

为什么有效：每次模拟都严格遵循层大小和巧克力交替的规则。 通过尝试两种起始巧克力，我们保证找到尽可能多的层数。 不变的是，在每一步，巧克力消耗量都不会超过可用供应量。 一旦完成，模拟就会停止，这正是蛋糕无法进一步扩展的时候。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_layers(a, b):
    def simulate(start_white):
        w, d = a, b
        layer = 1
        count = 0
        white_turn = start_white
        while True:
            if white_turn:
                if w >= layer:
                    w -= layer
                else:
                    break
            else:
                if d >= layer:
                    d -= layer
                else:
                    break
            layer *= 2
            white_turn = not white_turn
            count += 1
        return count
    
    return max(simulate(True), simulate(False))

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(max_layers(a, b))
```这段代码定义了一个助手`simulate`函数接受一个布尔值，指示第一层是否应该为白色。 它跟踪每种类型的剩余巧克力、当前层的大小，并交替使用巧克力。 尝试两种起始颜色后，它将返回最大层数。 的翻倍`layer`循环内确保指数增长。 边缘情况，例如只有一种类型的巧克力或非常小的供应量，自然由 while 循环处理。
