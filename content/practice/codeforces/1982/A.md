 ## 解决方案
 ## 问题理解

 在这个问题中，我们给出了一个足球比赛场景，迪马记住了两个分数：一个是他分心之前的分数，另一个是他回来时的分数。 每个分数由两支球队的进球组成。 比赛中，两支球队每次都会取得一个进球。 我们被要求确定在迪马缺席期间，两支球队是否有可能从未取得过相同的比分。 如果可能的话，输出应该是“YES”，否则输出应该是“NO”。 

分数是大整数，最多$10^9$，测试用例的数量最多可达$10^4$。 这排除了任何模拟每个进球的方法，因为这可能需要迭代数十亿个步骤。 相反，我们必须对可能的分数序列进行数学推理，而不需要明确地生成它们。 

非明显的边缘情况包括一支球队遥遥领先并继续得分而另一支球队根本没有得分的情况。 例如，如果初始分数是$0:2$最终得分为$5:2$，第一队可以连续五个进球，但比分从未相等。 模拟所有目标序列的粗心方法可能会错误地假设必须发生相等。 

## 方法

 暴力方法将尝试模拟从第一个得分到第二个得分的每个可能的得分序列。 这在理论上是正确的，因为任何一支球队的单球增量的任何序列都涵盖了所有可能性。 然而，这是完全不切实际的，因为进球数可能高达$10^9$，使得操作计数不可接受。 

简化问题的关键观察是，分数可以变得相等的唯一方法是，如果开始时球队之间的差异通过增量相交叉。 定义$d_1 = x_1 - y_1$和$d_2 = x_2 - y_2$。 如果$d_1$和$d_2$具有相同的符号（均为正或均为负）或其中一个为零，则有可能在分数不相等的情况下达到第二分数。 如果符号不同，在某些时候就不可能避免相等。 这将问题简化为对初始和最终差异的简单检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(最大(x2-x1, y2-y1)) | O(1) | O(1) | 太慢了 |
 | 基于符号的检查 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2.对于每个测试用例，读取Dima分心前后的分数，$(x_1, y_1)$和$(x_2, y_2)$。 
3. 计算差异$d_1 = x_1 - y_1$和$d_2 = x_2 - y_2$。 
4. 检查是否$d_1 \cdot d_2 > 0$或者$d_1 = d_2 = 0$。 这确保了分数永远不会越过零，这意味着永远不会出现平等。 
5. 如果条件为真，则打印“YES”。 否则，打印“NO”。 

为何有效：产品$d_1 \cdot d_2$为正保证两个差值具有相同的符号。 由于进球只会增加一支球队的得分，因此差值单调变化，并且永远不会超过零。 这确保了两队在中场休息期间永远不会得分相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x1, y1 = map(int, input().split())
        x2, y2 = map(int, input().split())
        d1 = x1 - y1
        d2 = x2 - y2
        if d1 * d2 > 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该解决方案使用快速 I/O 高效读取每个测试用例。 计算差值并检查符号是在恒定时间内完成的。 该逻辑避免了模拟评分序列，这是不可行的。

 ## 边缘情况

 考虑这样一种情况：一支球队进了很多球，而另一支球队却没有进球。 例如，从$0:1$并结束于$0:5$，差值始终为负，并且不会出现平局。 该算法计算$d_1 = -1$,$d_2 = -5$，产品为正，并正确输出“YES”。 

如果差值过零，例如$1:2$到$3:2$，算法计算$d_1 = -1$,$d_2 = 1$，产品为负，并正确输出“NO”。 这证实了微妙边界条件的正确性，而无需模拟每个分数。
