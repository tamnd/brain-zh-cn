 ## 解决方案
 ## 问题理解

 我们得到了一个代表山脉高度的数字网格，以及第二个网格，该网格将每个单元格分为两组之一。 一组被标记为有雪盖，另一组被标记为无雪盖。 任务是决定是否可以使下雪组中的值总和等于非下雪组中的值总和。 

唯一允许的操作是选择任何$k \times k$子矩阵并添加一个整数$c$到里面的每一个细胞。 的价值$c$每次都是独立选择的，可以是正数，也可以是负数。 重要的是，此操作同时影响两个组，只要子矩阵与它们重叠。 

因此，问题简化为询问我们是否可以使用这些平方更新在两组之间重新分配总“质量”。 

约束条件很大：最多$500 \times 500$每个测试用例最多$2.5 \cdot 10^5$细胞总数。 这立即排除了对所有子矩阵或每次操作推理的任何模拟。 任何解决方案的网格大小都必须接近线性或近线性。 

当出现一个微妙的点时$k = 1$。 然后每个单元格都是独立可调的，因此我们总是可以自由设置值并使两个总和相等。 这是一种特殊情况，答案总是“是”，除非两个群体在结构上都以微不足道的方式退化。 

第二个重要的边缘情况是其中一组为空时。 那么它的和被定义为零，那么问题就变成了我们是否可以强制另一组的和为零。 由于操作自由度很大，这完全取决于至少一项操作是否只能影响一组或结构是否强制耦合。 

一个天真的错误是假设我们总是可以独立地调整单个细胞。 这是错误的，当$k > 1$，因为更新是基于块的并且同时重叠许多单元格，从而在位置之间创建了约束。 

## 方法

 蛮力视角从思考每一个开始$k \times k$作为变量进行操作。 每个操作贡献$c \cdot ( \#\text{snowy cells in block} - \#\text{non-snowy cells in block})$为两个总和之间的差值。 如果每个可能的子矩阵都有一个变量，我们可以尝试求解一个强制最终差值为零的线性系统。 

这个表述是正确的，但完全不切实际。 有$(n-k+1)(m-k+1)$可能的子矩阵，最多可达$250{,}000$每次测试。 构建和解决这样一个系统将远远超出时间限制。 

关键的观察是我们不需要完整的线性系统。 每个操作都会影响一个连续的块，并且重叠结构允许取消。 我们不跟踪单个单元，而是只关心网格是否可以根据以下效果划分为独立的组件：$k \times k$更新。 

捕获此问题的标准方法是查看网格模数$k$在两个维度上。 每一个$k \times k$操作恰好影响一种残基类别模式，并且重复操作允许我们在共享相同模结构的所有单元之间转移调整。 这将问题简化为检查两组之间的差异是否可以表示为这些块效应的组合。 

最终条件简化为检查诱导的一致性$k \times k$-周期结构：在每个残基类模内$k$，雪域和非雪域单元之间的不平衡必须是全局可调的。 如果所有残差类别总体上是平衡的，我们可以构造操作来移动值，直到全局差异消失； 否则，至少有一个类会创建不变的障碍。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（子矩阵上的线性系统）|$O(nm \cdot nm)$|$O(nm)$| 太慢了 |
 | 残级分解|$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 1. 计算有雪和无雪总和之间的初始差异。 如果这个差异已经为零，我们立即成功，因为不需要任何操作。 此步骤隔离是否需要任何调整。 
2. 观察单个$k \times k$操作改变差异。 在选定的块内，每个雪细胞都做出贡献$+c$每个非雪细胞都贡献$-c$。 所以每个操作都有贡献$c \cdot (\text{snowy count} - \text{non-snowy count})$在那个街区里面。 
3.不是直接推理所有块，而是按坐标模对单元进行分组$k$。 每个细胞恰好属于一个残基类对$(i \bmod k, j \bmod k)$，以及每一个$k \times k$放置以结构化重复的方式与这些类交互。 这个周期性是核心约束结构。 
4. 对于每个残留类别$(r, c)$，计算该类中所有像元贡献的净不平衡，定义为雪天贡献减去非雪天贡献。 这将网格简化为$k \times k$不平衡的压缩表示。 
5. 检查所有这些残差类别不平衡是否是兼容的，因为它们的总数可以通过选择块系数来抵消。 该条件简化为所有残差“内部一致”，这意味着基本面的累积不平衡$k \times k$模式不得强加矛盾。 
6. 如果此周期结构中出现任何不一致，则得出结论：没有任何操作序列可以消除差异。 否则，建设性地，我们可以分配操作来取消每个残差贡献，所以答案是“是”。 

### 为什么它有效

 每个$k \times k$操作以在网格上按周期重复的方式移动质量$k$。 这创建了一个可达变换的线性空间，其基础完全由残差类模确定$k$。 初始差异向量必须位于这些变换的范围内才能消除。 残差聚合步骤将问题投影到该跨度上并检查成员资格。 如果投影成功，我们可以综合操作来消除不平衡； 如果失败，则不平衡位于不受任何允许的操作影响的不变方向。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        
        a = [list(map(int, input().split())) for _ in range(n)]
        typ = [input().strip() for _ in range(n)]
        
        diff = 0
        
        for i in range(n):
            row_t = typ[i]
            row_a = a[i]
            for j in range(m):
                if row_t[j] == '0':
                    diff += row_a[j]
                else:
                    diff -= row_a[j]
        
        if diff == 0:
            print("YES")
            continue
        
        if k == 1:
            print("YES")
            continue
        
        # build residue imbalance
        mod_sum = [[0] * k for _ in range(k)]
        
        for i in range(n):
            for j in range(m):
                r = i % k
                c = j % k
                if typ[i][j] == '0':
                    mod_sum[r][c] += a[i][j]
                else:
                    mod_sum[r][c] -= a[i][j]
        
        # key condition: all mod classes must balance globally
        # reduce to checking if all values equal modulo global scaling
        base = mod_sum[0][0]
        ok = True
        for r in range(k):
            for c in range(k):
                if mod_sum[r][c] != base:
                    ok = False
                    break
        
        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```该实现首先计算两种山脉类型之间的初始有符号差。 这是必要的，因为如果它已经为零，我们就可以避免不必要的结构检查。 

特殊情况$k = 1$尽早处理，因为每个单元都可以独立调节，从而使系统完全可控。 

该解决方案的核心是构建一个$k \times k$大批`mod_sum`，根据单元的位置模来聚合单元的签名贡献$k$。 这将网格压缩为其周期性结构。 

最后，我们检查所有残留细胞的行为是否相同。 这个相等条件确保没有残差类产生无法通过重复块操作消除的不可减少的不平衡。

 ## 边缘情况

 当$k = 1$，每个细胞都可以独立调节，因此任何不平衡都可以直接纠正。 该算法短路了这种情况，避免了不必要的结构分析。 

当整个网格是一个网格时$k \times k$块中，所有单元通过一个操作耦合。 残差检查折叠到单个自由度，因此可以通过选择来消除任何全局差异$c$适当地。 

当所有细胞都属于一种类型时，根据定义，相反的组的总和为零。 该算法正确地将不平衡视为纯粹的单方面，并检查是否可以通过统一块移位将其驱动至零，这取决于残差一致性而不是原始总和。
