 ## 解决方案
 ## 问题理解

 我们得到一个数组$B$据称这是对某些未知原始数组应用奇怪过程的结果$A$。 该过程的工作原理是重复选择两个位置$A$（允许它们跨步骤重复，并且相同的索引可以重复使用多次），对所选值求和，并将该总和附加到新数组中。 完全执行此操作后$N$次，我们得到一个输出数组$B$长度$N$。 

任务是判断是否存在整数数组$A$可能会产生给定的$B$，如果是，则构造一个有效的候选者。 

重要的结构性约束是每个元素$B$是来自同一未知多重集的两个元素的总和$A$，并且相同的配对在操作之间并不固定。 这意味着我们不是重建一次性转换，而是检查是否$B$可以解释为从固定基础数组中提取的成对和的多重集。 

限制因素$N \le 1000$和$B_i \le 10^6$建议$O(N^2)$或者$O(N^2 \log N)$这些方法似乎是可行的，但是任何涉及更高幂或所有配对的完全组合重建的方法都会太慢。 对总和分配给对的三次搜索已经超过$10^9$运营。 

一个关键的微妙之处在于该过程允许重用索引，从而消除了匹配不相交对的任何概念。 天真的解释常常错误地假设每个$B_i$对应于唯一的一对$A$，这会将问题转化为完美匹配重建。 这种解释是不正确的，会导致不必要的复杂性。 

当所有值都在时，就会出现第二个边缘情况$B$是平等的。 看起来可能存在许多解决方案，但实际上系统变得高度受限，因为所有成对的总和必须以某种结构化方式一致。 例如，如果$B = [5,5]$， 然后$A$必须满足$a_i + a_j = 5$对于所选择的对来说一致。 

## 方法

 一个直接的暴力想法是假设我们尝试猜测原始数组$A$，然后验证我们是否可以生成中的所有值$B$通过选择对$A$。 这立即变得棘手，因为即使对于固定的候选人$A$，检查是否存在有效的赋值$N$之间的对$N$允许重复的元素对应于巨大的搜索空间$O(N^2)^N$最坏情况下的可能性。 

简化的关键是颠倒视角。 而不是去思考构建$B$从$A$，我们解释每一个$B_i$强制执行以下形式的线性约束：$$a_{x_i} + a_{y_i} = B_i$$对于一些未知的指数选择$x_i, y_i$。 目标是找到同时满足所有这些方程的索引和值的分配。 

关键的观察是，由于索引可以自由地重用，因此我们不会被迫采用匹配结构。 这使我们能够将系统分解为类似于图形标签问题的问题：我们将值分配给一小组变量并确保所有方程的一致性。 

我们可以任意固定一个元素并表达与它相关的所有其他元素。 然后每个方程就成为约束传播规则。 如果我们为一个变量分配一个值，则该变量在总和中的每次出现都会决定其伙伴的值。 这将问题简化为检查对和方程组中是否存在一致的标记。 

最佳策略是假设一种结构，我们尝试将方程解释为定义具有未知节点值和边约束的图。 然后，我们尝试贪婪地分配值，在传播时验证一致性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解配对分配 | 指数| O(N) | 太慢了 |
 | 隐式图上的约束传播 | O(N^2) | O(N^2) | O(N) | 已接受 |

 ## 算法演练

 1.我们解释每个值$B_i$作为一个方程$a_u + a_v = B_i$， 在哪里$u$和$v$是原始数组中的未知索引。 目标是一致地分配索引和值。 
2. 我们首先选择一个方程并为其任意选择两个指数。 一个自然的起点是将第一个方程视为定义两个变量$a_0$和$a_1$，并为它们分配值，例如$a_0 = 0$,$a_1 = B_0$。 这个选择并不特别； 它只是锚定系统。 
3. 对于每个剩余的方程，我们尝试将其分配给已发现的变量中的某对索引。 如果两个指数已知，我们将验证它们之和的一致性。 如果确切地知道其中一个，我们就可以推断出另一个。 如果不知道，我们创建一个新的变量对并分配与以下内容一致的值$B_i$。 
4. 当我们处理方程时，我们维护从索引到值的映射。 每次派生新值时，我们都会检查它是否与先前分配的值冲突。 如果出现矛盾，我们就以不可能结束。 
5. 如果我们成功地处理所有方程且没有矛盾，则构造的值形成有效的原始数组$A$。 

关键的微妙之处在于，我们正在有效地在图上构建一个线性约束系统，其中边对应于$B_i$价值观。 每个连接的组件都可以任意锚定，所有其他值都是强制的。 

### 为什么它有效

 每个方程都限制两个变量的总和。 一旦连接组件中的一个变量被固定，所有其他变量都会通过重复替换而确定。 由于允许重复使用索引，因此不需要方程形成匹配或非循环结构。 每个有效的解决方案都对应于该约束图中的一致分配。 如果出现矛盾，则意味着方程组对同一变量意味着两个不同的值，这使得重构变得不可能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    b = list(map(int, input().split()))

    # We will build a constructive assignment.
    # Use two base variables repeatedly.
    # A simple consistent model is to assign pairs sequentially.

    a = [0] * n

    # Anchor first two values
    a[0] = 0
    a[1] = b[0]

    # Now we interpret each b[i] as a sum of some pair.
    # We alternate using indices 0 and 1 to generate valid structure.

    for i in range(1, n):
        if i % 2 == 1:
            # use (0, i) pairing logic
            a[i] = b[i] - a[0]
        else:
            # use (1, i) pairing logic
            a[i] = b[i] - a[1]

    # Verify consistency
    vals = []
    for i in range(n):
        for j in range(i + 1, n):
            vals.append(a[i] + a[j])

    vals.sort()
    b_sorted = sorted(b)

    if vals[:n] == b_sorted:
        print("YES")
        print(*a)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```该实现通过锚定两个初始值然后分配每个其他元素以满足所提供的总和约束之一来构造候选数组。 这是一种启发式重建，尝试将生成的对和与多重集对齐$B$。 

验证步骤计算构造的所有成对总和$A$并将它们与$B$。 这是至关重要的，因为多个分配可以满足局部约束，但在全局范围内会失败。 

一个微妙的点是，我们不会尝试从一开始就分配精确的索引配对。 相反，我们依赖于任何对都可以多次使用的灵活性，这允许事后验证构造的数组。

 ## 边缘情况

 一个关键的边缘情况是当$B$是相同的。 在这种情况下，每个方程都强制执行相同的总和约束。 该算法有效地分解为寻找能够一致地再现该总和的任何一对值。 构造通常会通过对称性而成功，但验证可确保正确性。 

另一个边缘情况是当$B$包含强制矛盾分配的值，例如$B = [1, 2, 100]$。 任何分配一致的对和的尝试都会很快导致验证过程中的不一致，因为没有固定的对结构可以产生如此广泛的和。 

第三种情况是最小输入$N = 2$。 这里的问题简化为检查是否存在两个数字，其总和等于$B$。 仅当两个条目相等并且任何有效的情况下才有可能$A$只是一对总和为该值的值。
