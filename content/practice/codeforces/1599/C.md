 ## 解决方案
 ## 问题理解

 我们被要求确定约翰尼必须研究多少张地图，以确保他最终在所研究的地图上玩的概率至少为$P$。 游戏流程如下：从$N$总共地图，随机呈现三张，每位玩家丢弃一张地图。 然后系统随机选择剩余地图中的一张作为游戏地图。 约翰尼希望最大限度地提高最终地图属于他研究过的地图的可能性。 

输入给我们$N$，地图总数，以及$P$，目标概率。 输出是地图的最小整数个数$k$这样如果约翰尼研究任何$k$地图，最终地图属于他的研究集的概率至少为$P$。 

限制条件适中：$N$取决于$10^3$， 和$P$是最多有四位小数的小数。 这意味着任何算法$O(N^2)$运营情况良好；$O(N^3)$仍然可以通过，但已接近上限。 必须小心处理概率以避免浮点精度问题，尤其是在与$P$诸如 0.0001 或 1.0 之类的值。 

当出现不明显的边缘情况时$P=1$。 即使约翰尼研究了几乎所有地图，系统仍然有可能选择他研究集之外的地图。 例如，与$N=7$和$P=1.0$，他必须研究6张地图。 研究较少的地图将导致最终地图未经研究，这违反了要求。 同样，当$P=0$，答案为 0，因为不需要研究地图即可满足零概率阈值。 

## 方法

 蛮力方法是迭代所有可能数量的地图$k$从 0 到$N$，并且对于每个$k$，计算选择所研究的地图的确切概率。 为此，我们可以枚举所示的三个地图的所有组合并模拟随机丢弃。 这对于正确性是有效的，但复杂性是$O(N^3)$因为对于每个三元组地图，我们必须评估结果。 为了$N=1000$，这给出了大约 10 亿次操作，这太慢了。 

关键的见解是概率函数是单调的：研究更多地图永远不会减少玩所研究地图的机会。 因此，我们只需要计算一次概率公式，作为$k$，并找到最小的$k$使得概率满足或超过$P$。 我们可以组合推理：如果约翰尼学习$k$地图，显示的随机三重地图存在三种情况：

 1. 研究所有三张地图。 
2. 两张研究过的地图，一张未研究过。 
3. 一张已研究过的地图，两张未研究过。 
4. 零研究地图。 

对于每种情况，我们可以计算最终地图属于他的研究集的概率，并根据选择地图的方式数量进行加权。 简化后，最终的概率公式简化为：$$\text{probability} = \frac{k}{N} + \frac{k}{N} \cdot \frac{k-1}{N-1}$$或者等效地，使用仔细的组合。 精确的推导涉及计算所显示的三张地图中有多少张被研究并使用统一丢弃假设。 

一旦我们有了公式，我们只需迭代$k=0$到$N$，计算每一步的概率，达到时停止$P$。 这是$O(N)$，完全可以接受$N \le 1000$。

 | ---| ---| ---| ---|
 | 蛮力 | O(N^3) | O(N^3) | O(1) | O(1) | 对于 N=1000 来说太慢 |
 | 组合公式| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读$N$和$P$来自输入。$N$是地图总数，$P$目标概率。 
2.如果$P = 0$，立即输出0。 无需研究地图即可满足零阈值。 
3. 迭代$k$从 1 到$N$。 在每一步中，计算系统选择的地图属于其中的概率$k$研究了地图。 概率计算为所研究的地图在两次丢弃中幸存并最终被选择的结果的比例。 
4. 检查计算的概率是否至少为$P$。 如果是，则打印$k$并停止迭代。 这$k$是最小的，因为我们从 1 向上递增。 
5.如果没有$k < N$满足概率（只有当$P=1$）， 输出$N-1$。 由于丢弃的随机性，系统永远无法保证 100% 的概率，除非约翰尼研究了除一张地图之外的所有地图。 

为什么它有效：概率函数的单调性确保一旦$k$达到概率≥$P$，全部较大$k$也会满足它。 因此，第一个$k$发现是最小的。 组合公式根据计算地图结果和随机选择来捕获正确的概率，因此不会错过任何情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    N, P = input().split()
    N = int(N)
    P = float(P)
    
    if P == 0:
        print(0)
        return
    
    for k in range(1, N+1):
        # probability formula: chance that at least one studied map survives
        prob = 1 - ((N-k)/N) * ((N-k-1)/(N-1)) * ((N-k-2)/(N-2)) if N >= 3 else 0
        if prob + 1e-9 >= P:  # floating point tolerance
            print(k)
            return

if __name__ == "__main__":
    main()
```公式`1 - ((N-k)/N)*((N-k-1)/(N-1))*((N-k-2)/(N-2))`计算显示的三张地图**没有**被研究的概率。 从 1 中减去得出**至少一张研究过的地图幸存下来**的概率。 我们添加了一个小 epsilon 来处理浮点舍入，确保我们不会低估。
