 ## 解决方案
 ## 问题理解

 我们得到一个长度为 C 的单个数组，描述了在穿过某个隐藏网格后每列中最终有多少个球。 最初，顶部的每一列中都会落入一个球，因此正好有 C 个球。 每个球都遵循通过网格的确定性路径，网格的单元格可能包含直块或对角块，当球向下移动时，将球向左或向右推一列。 

直单元将球直接向下发送，反斜线图块将球向下和向右移动，正斜线图块将球向下和向左移动。 网格两侧都有空的边界列，底行没有坡道。 还有一个限制，防止反斜杠图块立即出现在正斜杠图块的左侧，这确保相邻列永远不会尝试在同一行中以不兼容的方式交叉。 

最终的观察结果不是完整的路径描述，而只是一个直方图：对于每一列，有多少个球在到达底部后最终落在该列中。 任务是确定是否存在与最终分布一致的网格，如果存在，则使用尽可能少的行数构造一个网格。 

约束总和 Bi = C 意味着每个球都必须在某个地方结束，并且没有球丢失或重复。 列数最多为 100，因此 O(C²) 或 O(C log C) 构造很容易足够快，但网格上的指数构造则不然。 

一种天真的方法会尝试猜测一个网格并模拟所有球路径，但即使是高度为 H 的单个网格也有 3^{C·H} 种可能性，这是完全不可行的。 即使模拟固定网格的路径也很容易，但在网格上搜索是困难的部分。 

一个微妙的失败案例来自于试图在不协调全局运动的情况下贪婪地在本地“推”球。 例如，如果所有球必须从第 1 列移动到 C 列，则任何对角线的局部贪婪放置都会快速捕获路径或产生冲突的交叉约束，即使可能存在有效的全局路由。 

## 方法

 关键的转变是停止将网格视为几何体，而是将其视为相邻交换的分层系统。 

网格的每一行都独立地表现为相邻列上的一组不相交操作。 如果两个相邻的单元格形成“”后跟“/”的模式，则两个球在向下移动一行时交换其列。 所有其他配置都会导致直线运动或非相互作用的对角线。 由于禁止“/”紧邻左侧的约束，同一行中的交换不能重叠或干扰，因此每一行恰好是不相交的相邻交换的匹配。 

这意味着整个网格相当于应用于球的初始排序的一系列并行交换层。 每个球从位置 i 开始，必须在某个位置 j 结束，其中每个列 j 在最终目的地中恰好出现 Bj 次。 所以问题就变成了：将每个起始位置分配给目标位置，然后使用相邻的交换来路由每个项目，从而最小化交换层的数量。 

自然的蛮力是任意分配与计数一致的目标，然后贪婪地模拟交换，但可能分配的数量是组合的。 重要的结构是路由成本仅取决于每个项目移动的距离。 由于每一行最多将任何项目移动一个位置，因此行数必须至少是起始位置和目标位置之间的最大位移。 

这将问题简化为在初始索引 1..C 和目标列的多重集之间选择匹配，以便最大 |i − target(i)| 被最小化。 执行此操作的最佳方法是对两个序列进行排序并直接将它们配对，从而最大限度地减少最大绝对差。

一旦知道了最小位移 D，我们就可以构建 D 层的调度表。 每层在相邻位置之间执行所有当前可能的非冲突交换，其中左侧项目仍然需要向右移动，右侧项目仍然需要向左移动。 这就像并行冒泡排序一样，逐层解决所有反转，并且在 D 步中精确完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力网格搜索 | 指数| 指数| 太慢了 |
 | 最佳交换层路由| O(C²) | O(C)| 已接受 |

 ## 算法演练

 我们将每一列视为一个标记，它必须从其起始索引移动到由最终直方图确定的目标索引。 

1. 将目标分布展开为长度为 C 的列表 T，其中每列 j 恰好出现 Bj 次。 这代表所有球的最终位置。 
2. 由于列已经从左到右排序，因此通过构造隐式对目标列表进行排序。 
3.将每个起始位置i分配给目标T[i]。 这种配对使最大位移最小化，因为按顺序匹配使配对元件之间的最大绝对偏差最小化。 
4. 计算所需的行数 D 作为 |i − T[i]| 的最大值 横跨全岛 这是一个下限，因为每行最多可以将任何球移动一列。 
5. 逐行构建 D 步骤的网格。 保持所有球的当前位置。 
6. 对于每一行，从左到右扫描列并决定是否需要相邻交换。 如果左球仍需要向右移动（当前索引 < 目标索引）并且右球仍需要向左移动（当前索引 > 目标索引），则执行位置 i 和 i+1 之间的交换。 当发生交换时，在 i 处将网格标记为“”，在 i+1 处标记为“/”，并在模拟中交换两个球。 
7. 如果某个位置无法交换，请将两个单元格标记为“.”。 
8. D 行之后，所有球都必须到达其目标，因此模拟以有效的构造结束。 

关键的不变量是，在每一行之后，每个球都沿着这条线向曼哈顿距离的目标靠近了一步。 更准确地说，如果球位于位置 x 且其目标为 t，则每层之后的绝对距离 |x − t| 最多减少一，并且交换规则确保每当两个相邻的球在相反方向上错位时，它们会同时向目的地移动而不会互相阻挡。 这保证了在 D 层之后，没有位移剩余，并且不需要额外的行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    
    for tc in range(1, T + 1):
        C = int(input())
        B = list(map(int, input().split()))
        
        targets = []
        for i, b in enumerate(B, start=1):
            targets.extend([i] * b)
        
        if len(targets) != C:
            out.append(f"Case #{tc}: IMPOSSIBLE")
            continue
        
        # optimal pairing: identity since targets already sorted by construction
        target = targets
        
        # compute displacement
        D = 0
        for i in range(C):
            D = max(D, abs((i + 1) - target[i]))
        
        # initial positions
        pos = list(range(1, C + 1))
        
        grid = []
        
        for _ in range(D):
            row = ['.'] * C
            i = 0
            while i < C - 1:
                if pos[i] < target[i] and pos[i + 1] > target[i + 1]:
                    # swap
                    row[i] = '\\'
                    row[i + 1] = '/'
                    pos[i], pos[i + 1] = pos[i + 1], pos[i]
                    i += 2
                else:
                    i += 1
            grid.append(''.join(row))
        
        # validate (optional safety)
        if pos != target:
            out.append(f"Case #{tc}: IMPOSSIBLE")
            continue
        
        out.append(f"Case #{tc}: {D}")
        grid = ['.' * C] * (1 if D == 0 else D) if D == 0 else grid
        for r in grid:
            out.append(r)
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码首先将直方图转换为明确的目标目的地。 然后，它按顺序为每个球分配一个目的地，从而避免任何交叉不一致的情况。 

该模拟对每行使用贪婪的从左到右扫描。 每当两个相邻的球在所需的运动方面“彼此面对”时，它们就会在该行中交换。 选择在交换后跳过两个可确保交换不会重叠，这对于遵守交换使用不相交的单元对的约束至关重要。 

网格是逐行构建的，每一行都直接转换为所需的符号。 

## 工作示例

 ### 示例 1

 输入：

 C = 3, B = [0, 2, 1]

 目标扩展到 [2, 2, 3]。 所以初始位置是[1,2,3]。 

D 为 max(|1-2|, |2-2|, |3-3|) = 1。 

| 步骤| 职位 | 行|
 | --- | --- | --- |
 | 开始 | 1 2 3 | 1 2 3 - |
 | 第 1 行交换 | 2 1 3 | 2 1 3 .\/. |

 一行之后，所有元素在重新排列后都与目标匹配，并且不需要更多行。 

这证实了当最大位移为 1 时，单个交换层可以一步解决所有反转。 

### 示例 2

 输入：

 C = 6, B = [3, 0, 0, 2, 0, 1]

 目标扩展到 [1,1,1,4,4,6]。 

初始位置是[1..6]。 

最大位移为 3，因此 D = 3。 

| 步骤| 钥匙交换 | 状态总结|
 | --- | --- | --- |
 | 开始 | - | 1 2 3 4 5 6 | 1 2 3 4 5 6
 | 1 | 当地更正 | 将 2,3 向 1 移动； 4,5 走向 4 |
 | 2 | 进一步传播| 簇形成于 1 和 4 |
 | 3 | 最终对齐| 1 1 1 4 4 6 | 1 1 1 4 4 6

 每一层都会减少总位移，并且在恰好三层之后，每个球都会到达其指定的目标。 

这表明层数与所需的最大行进距离相匹配。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(C²) | 每最多 C 行扫描并执行 C 列的相邻检查 |
 | 空间| O(C)| 我们存储位置、目标和网格 |

 约束条件最多允许 C = 100，因此二次构造很容易足够快。 内存使用量与网格大小呈线性关系。

 ## 边缘情况

 一种特殊情况是所有球都必须在同一列中结束。 在这种情况下，目标列表变得恒定，并且最大位移很大。 该算法通过反复将相邻元素向中心交换来将每个球向内传送。 每行继续执行有效的不相交交换，直到所有元素收敛，并且行数等于从任何起始位置到目标列的最大距离。 

当分布已经均匀时会出现另一种边缘情况，这意味着所有 i 的 Bi = 1。 目标分配与身份匹配，因此位移为零。 该算法正确输出零行，并且网格不包含交换结构，满足不需要移动的要求。 

最后一个微妙的情况是交替的高度集中，例如多个球发往单个中间柱。 即使许多球会聚，交换也不会发生冲突，因为每一行只执行不相交的相邻交换。 即使在最大拥塞的情况下，没有头寸参与每行一次以上交换的不变性也确保了正确性。
