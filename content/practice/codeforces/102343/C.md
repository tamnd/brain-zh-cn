 ## 解决方案
 ## 问题理解

 床是一个轴对齐的矩形，其左下角是`(0, 0)`其右上角是`(W, L)`。 Anya 被建模为长度的线段`H`。 她的头是该段的一个端点，位于`(x, y)`，和角度`a`描述从她的头到脚的方向。 一个角为`0`指向右边，同时`90`指向上方，因此适用通常的数学约定。 

任务是确定整个部分是否位于床内。 允许接触边界，因此坐标精确的端点`0`,`W`,`0`， 或者`L`仍然有效。 

输入仅包含六个整数，其中`L`和`W`最多`500`,`H`最多`200`，并且头部坐标限制在床上。 这些界限很小，但真正的简化是结构性的，而不是计算性的。 没有需要处理的大型图形、数组或搜索空间。 恒定数量的算术运算就足够了。 

主要的边缘情况来自这样一个事实：头部保证在床内，但另一个端点不在床内。 例如，```
100 100 20
90 50 0
```给出第二个端点`(110, 50)`，所以答案是`NO`。 仅检查头部位置的粗心实现会错误地接受它。 

边界端点有效。 例如，```
100 100 20
80 50 0
```将第二个端点置于`(100, 50)`，正好在右边缘。 正确的输出是`YES`。 使用严格的不等式，例如`0 < x < W`会错误地拒绝它。 

方向可以指向向下或向左，因此只需添加`H * cos(a)`和`H * sin(a)`不考虑他们的迹象是另一个常见的错误。 例如，```
100 100 20
50 50 270
```结束于`(50, 30)`，在床里面。 正确的输出是`YES`。 

即使当一个水平或垂直投影看起来很大时，该段也可以对角线拟合。 例如，```
100 100 50
50 75 225
```大约结束于`(14.64, 39.64)`，所以两个端点都在内部，答案是`YES`。 

## 方法

 直接的几何方法可能会尝试检查 Anya 身体上的许多点，并检查每个点是否位于矩形内。 如果我们把身体离散成一厘米的块，最多有`H + 1 <= 201`点，所以这个版本实际上可以在限制内舒适地运行。 它的弱点是概念性的而不是实际性的：连续的线段包含无限多个点，检查有限样本本身并不能证明未采样的部分在内部。 

有用的观察结果是床是凸集。 两个端点位于凸集内的线段完全位于该集内。 矩形是凸的，所以我们根本不需要检查 Anya 身体的内部。 头部已经给出，因此只需要计算和检查脚部的端点。 

蛮力思想之所以有效，是因为它试图逐点验证整个片段，但这是不必要的，并且自然不会给出精确的连续证明。 凸性观察将整个问题简化为计算一个端点并执行四个坐标比较。 

终点由标准极坐标位移获得：`dx = H * cos(a)`

`dy = H * sin(a)`所以脚在`(x + dx, y + dy)`。 

由于三角函数使用弧度，因此必须首先将输入角度转换为`a * pi / 180`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 离散化段 | O(H) | O(1) | O(1) | 接受这些界限，但概念上没有必要 |
 | 检查第二个端点 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.阅读床的尺寸`L`和`W`, 安雅的身高`H`，以及头部位置`(x, y)`连同角度`a`。 已知头部本身位于床上，因此不需要单独的几何搜索。 
2. 将角度从度数转换为弧度。 蟒蛇的`math.sin`和`math.cos`期望弧度，因此直接使用角度值会产生完全不同的方向。 
3. 使用以下公式计算 Anya 的脚相对于头部的位移`H * cos(a)`水平和`H * sin(a)`垂直。 负值有效，因为 Anya 可能面朝左或面朝下。 
4、头部坐标加上位移，得到第二个端点`(fx, fy)`。 
5. 检查是否`fx`位于之间`0`和`W`以及是否`fy`位于之间`0`和`L`，使用包容性比较。 使用小的浮点容差是因为诸如`cos(90°)`近似表示而不是精确的零。 
6. 打印`YES`如果两个坐标都在各自的范围内。 否则打印`NO`。 

关键属性是，在整个算法中，我们只需要维护 Anya 线段的两个端点都在矩形内部的事实。 根据输入规范，头部位于内部，并且在最终坐标检查后，脚也位于内部。 由于矩形是凸形的，因此这两个端点之间的每个点也都在其内部。 因此，当计算出的第二个端点适合时，整个线段完全适合。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    L, W, H = map(int, input().split())
    x, y, angle = map(int, input().split())

    rad = math.radians(angle)

    foot_x = x + H * math.cos(rad)
    foot_y = y + H * math.sin(rad)

    eps = 1e-9

    if -eps <= foot_x <= W + eps and -eps <= foot_y <= L + eps:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```第一输入行给出矩形尺寸和线段长度。 第二行给出头部坐标和方向。`math.radians(angle)`执行所需的度数到弧度的转换。 端点计算直接根据长度向量的几何位移得出`H`。 

这些比较是包容性的，因为接触床边界仍然算作拟合。 容差可处理精确边界情况附近的浮点噪声。 例如，在数学上`cos(90°) = 0`，但计算值可以是一个很小的数字，例如`6.12e-17`。 

Python 中不存在整数溢出问题，并且浮点值很小，因为每个坐标和长度最多为几百。 操作的顺序也很重要：在调用之前必须转换角度`sin`和`cos`。

import sys
import io
import math

def solve():
    input = sys.stdin.readline

    L, W, H = map(int, input().split())
    x, y, angle = map(int, input().split())

    rad = math.radians(angle)

    foot_x = x + H * math.cos(rad)
    foot_y = y + H * math.sin(rad)

    eps = 1e-9

    if -eps <= foot_x <= W + eps and -eps <= foot_y <= L + eps:

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

 ## 边缘情况

 头在床内并不意味着 Anya 适合。 为了```
100 100 20
90 50 0
```位移为`(20, 0)`，所以脚位于`(110, 50)`。 x 坐标违反`0 <= x <= 100`，算法打印`NO`。 

必须接受精确的边界接触。 为了```
100 100 20
80 50 0
```脚在`(100, 50)`。 条件`foot_x <= W`完全满足，所以答案是`YES`。 小 epsilon 还可以保护此比较免受无害的浮点表示错误。 

圆下半部分的角度产生负垂直位移。 为了```
100 100 20
50 50 270
```终点在数学上是`(50, 30)`。 两个坐标都在矩形内，因此算法打印`YES`。 将角度视为总是产生积极的运动在这里会失败。 

对角线方向可以同时改变两个坐标。 为了```
100 100 50
50 75 225
```终点大约是`(14.64, 39.64)`。 两个坐标都保持在床内，并且凸度保证头部和脚之间的每个点也保持在内部。 答案是`YES`。 

最后，长度为零的段已经完全由其头部确定。 和```
1 1 0
0 0 0
```两个端点都是`(0, 0)`，位于床的左下角。 边界点有效，因此正确的输出是`YES`。
