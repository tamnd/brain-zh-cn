 ## 解决方案
 ## 问题理解

 我们被要求确定 Aryan 应该向 Harshith 请求的最小矩阵大小，以保证 Aryan 总能找到大小为 的子矩阵$a \times b$充满相同的数字。 Aryan 选择尺寸$n$和$m$，而 Harshith 选择中的实际元素$n \times m$矩阵，仅限于从 1 到$k$。 因为 Harshith 会采取最佳行动，所以他会尽力防止任何$a \times b$阻止统一。 我们的任务是挑选$n$和$m$这样无论 Harshith 如何填充矩阵，Aryan 总能找到一个均匀的子矩阵。 在所有可能的对中，我们想要字典顺序最小的一个。 

限制很严格。 每一个$a$,$b$， 和$k$可以达到$10^5$，并且可能最多有$10^4$测试用例。 我们必须设计一种算法，该算法在总和中线性工作$a+b+k$所有测试用例。 这排除了任何实际模拟矩阵或枚举子矩阵的方法。 相反，我们必须组合推理多少行和列足以保证获胜，而与矩阵内容无关。 

一个重要的边缘情况发生在$a=1$或者$b=1$。 在这种情况下，子矩阵简化为行或列。 粗心的方法可能会假设一个方形子矩阵，产生的答案大于必要的值。 另一个边缘情况是当$k=1$; any matrix works trivially. 为了$k>1$，我们需要足够的行和列来通过鸽巢原理强制重复。 

## 方法

 蛮力的想法是尝试所有可能的方法$n \ge a$和$m \ge b$然后看看是否存在 Harshith 的填充可以避免均匀子矩阵。 我们会检查每一个$a \times b$相等的子矩阵。 这种方法原则上是正确的，但行不通，因为$n$和$m$可能是$10^5$，给出大小的潜在矩阵$10^{10}$。 检查所有子矩阵是不可行的。 

关键的观察是这是一个组合问题。 考虑一个维度，比如行。 为了避免$a \times b$均匀子矩阵，Harshith可以安排每个数字最多出现一次$a-1$每个列块中的时间。 由于有$k$不同的数字，最小行数$n$这至少迫使$a$某些列中某些数字的重复是$n = k \cdot (a-1) + 1$。 根据鸽巢原理，如果你有$k$“桶”和$k(a-1)+1$物品，至少一桶有$a$项目。 同样的推理也适用于列：$m = k \cdot (b-1) + 1$。 这保证了无论 Harshith 如何填充矩阵，至少有一个$a \times b$均匀子矩阵。 从词典上看，$n$应该首先最小化，对应于这个公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·m·a·b) | O(n·m) | 太慢了 |
 | 组合（鸽笼）| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数$a$,$b$， 和$k$。 这些表示所需的统一子矩阵维度和每个单元格可能值的数量。 
2. 计算最小行数$n$使用鸽巢公式：$n = k \cdot (a-1) + 1$。 这确保了每一列中至少有一个数字重复$a$次，从而可以找到$a$相同的行。 
3. 计算最小列数$m$相似地：$m = k \cdot (b-1) + 1$。 这保证了至少有一个数字重复$b$在某些行块中的时间，产生$b$相同的列。 
4. 两者都采用$n$和$m$模数$10^9+7$以防止整数溢出。 这纯粹是为了输出格式，因为数字本身可能会超过$10^9+7$。 
5. 打印该对$(n, m)$对于这个测试用例。 

工作原理：该算法在行和列维度上都利用了鸽巢原理。 无论 Harshith 如何分配$k$价值观，有$k(a-1)+1$rows 确保至少出现某个数字$a$列中的时间，对于列也类似。 这保证了一个$a \times b$均匀子矩阵。 公式直接最小化$n$首先和$m$第二，给出字典顺序最小的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    a, b, k = map(int, input().split())
    n = (k * (a - 1) + 1) % MOD
    m = (k * (b - 1) + 1) % MOD
    print(n, m)
```该代码使用有效地读取多个测试用例`sys.stdin.readline`。 对于每个测试用例，它使用鸽笼公式计算行数和列数并取模$10^9+7$以适应输出范围。 计算后应用模运算，防止非常大的溢出$a$,$b$， 或者$k$。 该循环立即打印每个结果以避免存储大型数组，这一点很重要$t$可以达到$10^4$。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 10**9 + 7
    t = int(input())
    out = []
    for _ in range(t):
        a, b, k = map(int, input().split())
        n = (k * (a - 1) + 1) % MOD
        m = (k * (b - 1) + 1) % MOD
        out.append(f"{n} {m}")
    return "\n".join(out)
