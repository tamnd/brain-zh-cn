 ## 解决方案
 ## 问题理解

 我们有一张边长为正方形的台球桌$s$四个角有口袋。 在这张桌子上，$n$球严格放置在桌子内部的整数坐标处，而不是放置在边缘或角落上。 每个球在四个对角线方向之一以 45 度角同时射击，由向量指定$(d_x, d_y)$其中每个分量为 1 或 -1。 球的移动速度无限快，但遵循完美的弹性反射：当球撞击墙壁时，它会以相同的角度反弹回来。 我们需要计算有多少个球最终落入四个角中的任何一个。 

每个测试用例给出$n$球及其初始位置和方向向量。 输出是最终到达角落的球的数量。 

约束条件告诉我们$n$最多可达 1000 个$s$可以达到$10^9$。 总和$n$所有测试用例最多 1000 个。这意味着我们可以负担得起$O(n)$每个测试用例的解决方案，我们不需要一步步模拟球的运动，这对于$s$这么大。 所有坐标和方向都是整数，因此我们可以完全用整数算术进行推理。 

当球以经过几次反射后才到达角落的方式朝墙壁移动时，就会出现不明显的边缘情况。 例如，一个球在$(1,1)$移动$(1,-1)$在 2×2 的桌子上，从顶部和右侧的墙壁弹起，最终落在角落。 仅模拟第一个动作或假设没有反射的天真的方法会错误地错过这些球。 

## 方法

 蛮力方法是模拟每个球沿着其轨迹移动，从墙壁反射，直到它撞到角落或超过某个任意限制。 对于每次反射，我们都会更新其位置和方向。 然而，随着$s$一样大$10^9$，球在到达角落之前可能会弹跳很多次，所以这个模拟会太慢。 

关键的见解是，因为球沿 45 度角移动并且反射是完美的，所以它们在每个轴上的路径是周期性模数$2s$。 换句话说，我们可以通过将反射想象为桌子的延伸来“展开”桌子：一个球沿对角线移动穿过桌子的重复镜像副本，会击中沿其斜率 ±1 线的第一个角。 这将问题简化为一个简单的检查：对于从$(x, y)$有方向$(d_x, d_y)$，它最终会到达拐角当且仅当$(s - x) \cdot d_y = (s - y) \cdot d_x$模数$2s$。 进一步简化，因为坐标是整数，而且我们只有四个角，所以我们可以明确计算每个方向需要多少步才能到达墙壁，并检查反射次数是否准确地将其引导到角。 这可以使用简单的算术来完成，而无需循环位置。 

最佳解决方案计算每个球沿 x 和 y 的移动次数，直到沿两个轴达到 0 或 s，并检查它们是否在时间上重合。 由于运动是沿 1:1 斜率的对角线运动，因此如果沿 x 轴和 y 轴的反射次数均为偶数或均为奇数（对应于到达边界所需的反射奇偶性），则球会落在角落。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n*s) | O(1) | O(1) | 太慢了|
 | 反射奇偶校验| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$和$s$。 初始化盆栽球计数器。 
2. 对于每个球，读取其起始坐标$(x, y)$和方向$(d_x, d_y)$。 根据方向计算 x 和 y 方向上到最近墙壁的距离。 如果$d_x = 1$，到右墙的距离是$s - x$，否则到左墙的距离是$x$。 对于 y 来说也是如此。 
3. 计算沿 x 和 y 到达拐角需要多少次反射。 因为每次反射都会翻转方向，所以沿 x 到达拐角的总距离必须是以下的倍数$s$。 类似地沿着 y。 
4. 如果到达墙壁所需的沿 x 轴和 y 轴的反射次数具有相同的奇偶性，则球最终将到达角落。 在这种情况下增加计数器。 
5. 处理完所有球后，打印测试用例的计数器。 

关键的不变量是沿着每个轴，球在撞到墙壁后会改变方向。 当它第一次到达墙壁时，它的位置取模$s$匹配 0 或 s，并且由于运动为 45 度，因此沿 x 轴和 y 轴的时间必须与壁距离的某个整数倍重合。 检查奇偶校验可以保证拐角处的对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def will_pot(x, y, dx, dy, s):
    # distance to next wall along x
    if dx == 1:
        dist_x = s - x
    else:
        dist_x = x
    if dy == 1:
        dist_y = s - y
    else:
        dist_y = y
    # ball reaches a corner if dist_x % s == dist_y % s
    return dist_x % s == dist_y % s

t = int(input())
for _ in range(t):
    n, s = map(int, input().split())
    count = 0
    for _ in range(n):
        dx, dy, x, y = map(int, input().split())
        if will_pot(x, y, dx, dy, s):
            count += 1
    print(count)
```功能`will_pot`计算球方向上到墙壁的距离，并检查它是否与沿另一个轴的距离对齐。 由于球沿对角线移动，因此它们仅到达这些距离模全等的角点$s$。 这可以避免模拟反射并适用于$O(1)$每个球。
