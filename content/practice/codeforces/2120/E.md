 ## 解决方案
 ## 问题理解

 每个车道最初包含`a_i`汽车。 如果没有人移动，车道上的汽车每秒会离开一辆，因此车道的大小`x`贡献$$1+2+\dots+x=\frac{x(x+1)}2$$到彻底的愤怒。 

汽车可以变换车道。 移动的车辆被附加到另一条车道的后面，并受到额外处罚`k`。 由于变道是瞬时的并且随时可能发生，因此唯一重要的是每个车道中的最终汽车数量。 

假设最终车道尺寸为`b_1, b_2, ..., b_n`车辆总数相同时：$$\sum b_i = \sum a_i = S.$$等待时间贡献变为$$\sum \frac{b_i(b_i+1)}2.$$剩下的问题是有多少辆车必须实际移动。 

如果车道`i`结束于`b_i`汽车，最多`min(a_i,b_i)`原车可以留在那里。 其余的人必须离开或从其他地方抵达。 最少移动汽车数量为$$\sum \max(0,a_i-b_i).$$所以优化问题是$$\min \sum \left( \frac{b_i(b_i+1)}2 + k\max(0,a_i-b_i) \right).$$限制才是真正的挑战。 最多有`10^4`测试用例和总数`n`所有测试用例的总和是`2·10^5`。 单独车道尺寸达到`10^6`，因此汽车总数可能有`2·10^{11}`。 任何单独推理汽车的算法都是不可能的。 我们需要一个解决方案，其复杂性取决于`n`，而不是汽车总数。 

一些边缘情况很容易处理不当。 

考虑：```
1
1 100
5
```只有一条车道。 没有汽车可以移动到任何有用的地方。 答案很简单$$1+2+3+4+5=15.$$任何假设平衡总是有帮助的解决方案都会产生错误的结果。 

另一个微妙的情况是：```
1
2 1
1 1
```搬一辆车几乎不需要任何成本，但搬家仍然没有帮助。 保留配置会让人非常生气`1+1=2`。 任何移动都会产生车道尺寸`(0,2)`和成本`3+1=4`。 

另一个极端：```
1
2 100
10 0
```等待时间项更倾向于平衡，但移动损失是巨大的。 最佳方式使大多数汽车保持在原位。 仅最小化二次通道大小项的解决方案将会失败。 

## 方法

 蛮力的观点是选择最终的车道尺寸`b_i`并评估$$\sum \frac{b_i(b_i+1)}2 + k\sum \max(0,a_i-b_i).$$困难在于可能的向量的数量`(b_1,\dots,b_n)`固定金额`S`是天文数字。 即使对于适度的值，搜索空间也是遥不可及的。 

关键的观察是目标是可分离的。 定义$$g_i(b) = \frac{b(b+1)}2 + k\max(0,a_i-b).$$那么我们想要$$\min \sum g_i(b_i)$$受$$\sum b_i=S.$$这是一个经典的凸资源分配问题。 

想象一下修建车道`i`一次一辆车。 设增加其尺寸的成本为`t-1`到`t`是边际成本$$\Delta_i(t)=g_i(t)-g_i(t-1).$$简短的计算给出$$\Delta_i(t)= \begin{cases} t-k,& t\le a_i,\\ t,& t>a_i. \end{cases}$$对于每条车道，我们获得边际成本的递增序列：$$1-k,\;2-k,\;\dots,\;a_i-k,\;a_i+1,\;a_i+2,\dots$$选择最终尺寸相当于精确选择`S`所有这些序列的并集的边际成本项。 最小总成本通过取`S`最小的边际成本。 

现在问题变成：在无穷多个边际值中，求最小者的和`S`其中。 

边际值是单调的，因此我们可以二分搜索阈值`m`。 对于任何`m`，我们可以计算有多少个边际`≤ m`并计算所有边际的总和`< m`。 这将问题转化为标准的计数求和二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数为`n`和`S`| 指数| 太慢了 |
 | 最佳 |`O(n log M)`|`O(1)`额外 | 已接受 |

 这里`M`是关于`10^6`。 

## 算法演练

 1. 让`S = sum(a)`。 
2. 观察$$g_i(b) = \frac{b(b+1)}2 + k\max(0,a_i-b).$$总目标是这些独立车道成本的总和。 
3. 计算每个车道的边缘序列：$$\Delta_i(t)= \begin{cases} t-k,& t\le a_i,\\ t,& t>a_i. \end{cases}$$选择`b_i`意味着采取第一个`b_i`车道边际值`i`。 
4. 将问题重新解释为精确选择`S`所有车道序列的并集的边际值。 

最优解是`S`最小边际值。 
5. 二分查找整数阈值`m`。 

对于有尺寸的车道`a_i`：

 满足边际数`Δ ≤ m`是$$\min(a_i,m+k)+\max(0,m-a_i),$$负数被剪裁为零。 
6.让`C(m)`是边际总数`≤ m`。 

找到满足的最小阈值$$C(m)\ge S.$$等价地，$$C(m-1)<S\le C(m).$$7. 计算所有边际的数量和总和严格小于`m`。 

对于车道`i`：

 第一部分贡献$$c_1=\min(a_i,m+k-1),$$边际数，其总和为$$\frac{c_1(c_1+1)}2-kc_1.$$第二部分贡献$$c_2=\max(0,m-1-a_i)$$边际数，其总和为$$\sum_{t=a_i+1}^{a_i+c_2} t = \frac{c_2(2a_i+c_2+1)}2.$$8.让`cnt_less`是边际总数`< m`和`sum_less`他们的总和。 

我们还需要$$S-cnt\_less$$边际，全部都有价值`m`。 
9. 最小的和`S`边际数是$$sum\_less + (S-cnt\_less)\cdot m.$$10.添加常数项$$kS.$$这样就恢复了原来的客观值。 

### 为什么它有效

 对于每条车道，边际成本形成一个非递减序列。 任何可行的最终大小向量都对应于取每个序列的前缀，并且所选边缘的总数恰好是`S`。 

在所有的选择方式中`S`margins，最小总和是通过取全局最小值获得的`S`价值观。 二分查找确定边界值`m`分离选定和未选定的边缘。 计数公式准确确定有多少值低于该边界以及它们的总贡献是多少。 用价值填充剩余的位置`m`重建总和`S`最小的边际，这正是最优目标。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        S = sum(a)
        mx = max(a)

        def count_le(m):
            total = 0
            for x in a:
                c1 = min(x, max(0, m + k))
                c2 = max(0, m - x)
                total += c1 + c2
            return total

        lo = -k
        hi = max(mx, (S + n - 1) // n) + 2

        while lo < hi:
            mid = (lo + hi) // 2
            if count_le(mid) >= S:
                hi = mid
            else:
                lo = mid + 1

        m = lo

        cnt_less = 0
        sum_less = 0

        for x in a:
            c1 = min(x, max(0, m + k - 1))
            cnt_less += c1
            sum_less += c1 * (c1 + 1) // 2 - k * c1

            c2 = max(0, m - 1 - x)
            cnt_less += c2
            sum_less += c2 * (2 * x + c2 + 1) // 2

        marginal_sum = sum_less + (S - cnt_less) * m
        answer = k * S + marginal_sum

        ans.append(str(answer))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```二分查找找到阈值边缘值。 功能`count_le(m)`计算最多有多少边际成本`m`。 

下界是`-k`，这是最小可能的边际值（`1-k`）。 上限只需超过最终阈值即可。 一次`m`达到`max(a_i)`，每条车道贡献大致`m`边缘，所以边界附近`max(a_i)`就足够了。 

第二遍计算严格小于的所有边际值的确切贡献`m`。 其余所需边际必须全部相等`m`，由于定义属性$$C(m-1)<S\le C(m).$$Python 整数自动处理粗略的值`10^{17}`及以上，因此不会出现溢出问题。

 ## 边缘情况

 考虑：```
1
1 100
5
```二分搜索找到与单通道的六个边缘值相对应的阈值。 由于没有其他车道，因此每个选定的边缘都来自相同的序列。 算法返回$$1+2+3+4+5=15.$$无需特殊处理。 

现在考虑：```
1
2 1
1 1
```边缘序列是$$0,2,3,\dots$$两条车道。 两个最小的边际值是两个零，每个车道一个。 该算法准确地选择这些值并获得总成本`2`。 任何重新分配都需要选择更大的边际，并且无法改善结果。 

最后：```
1
2 100
10 0
```第一条车道有许多负值或小边际，因为移除汽车的成本极其昂贵。 通过二分搜索找到的阈值将大多数选定的边缘保留在原始车道内。 运动惩罚直接纳入边际值中，因此算法会自动避免过度的重新分配并返回真正的最优值。
