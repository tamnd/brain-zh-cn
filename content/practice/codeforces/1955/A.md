 ## 解决方案
 ## 问题理解

 马克西姆想买的正是`n`来自单一酸奶售价的商店的酸奶`a`burles，但有促销活动，提供两份酸奶`b`布尔斯。 对于每个测试用例，我们必须准确计算他可以花费的最小购买金额`n`酸奶。 输入指定多个测试用例，每个测试用例提供酸奶的数量`n`, 常规单价`a`，以及买二送一的促销价`b`。 每个测试用例的输出是一个表示最小总成本的整数。 

限制很小：`n`最多 100，价格最多 30。最多`10^4`测试用例，我们需要在恒定的时间内处理每个测试用例。 这排除了迭代的算法`n`对每个测试用例多次或执行复杂的搜索。 

边缘情况包括单独购买两份酸奶比促销活动更便宜的情况。 例如，如果`a = 5`和`b = 11`，那么分别以 10 伯尔的价格购买两杯酸奶比使用 11 伯尔的促销活动更好。另一个微妙的情况是，当`n`是奇数； 我们可能会购买尽可能多的双，并且需要单独处理最后一个酸奶。 

## 方法

 蛮力方法将尝试单个和促销对的所有可能组合，总和为`n`酸奶并计算每种组合的总成本。 这是可行的，因为我们可以从 0 迭代到`n//2`对，并通过添加剩余的单一酸奶来计算每个对的总成本。 为了最大`n = 100`，我们将为每个测试用例执行最多 50 次迭代。 和`10^4`测试用例，这会在最坏的情况下导致 500,000 次迭代，这是可行的但没有必要。 

关键的见解是注意到问题简化为一个简单的比较：对于每对酸奶，以促销价购买两个`b`只有当`b`小于`2 * a`。 否则，我们应该单独购买酸奶。 这一观察结果使我们能够使用一个公式计算最小成本：计算对的数量 (`n // 2`）和剩余的单打（`n % 2`），对于成对的，使用更便宜的`b`和`2 * a`。 单身的永远是`a`每个。 这将每个测试用例的解决方案减少为简单的算术，这是最佳的。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(n) | O(1) | O(1) | 可以接受但没有必要 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 我们将独立处理每一项。 
2. 对于每个测试用例，请阅读`n`,`a`,`b`。 这些代表购买的酸奶总量、单份酸奶价格以及两份酸奶的促销价格。 
3. 计算我们可以购买的酸奶数量为`n // 2`剩余的单一酸奶数量为`n % 2`。 
4. 对于成对的，使用较小的值计算成本`b`和`2 * a`，因为购买一对永远不应该超过单独购买两个的成本。 
5. 将配对数量乘以配对成本，并将剩余的单一酸奶乘以`a`并将它们相加得到总成本。 
6. 打印测试用例的结果。 

为什么有效：不变的是，对于任何两种酸奶，我们总是在促销和两次单次购买之间选择更便宜的选项。 由于每份酸奶都必须清点，所以剩下的单一酸奶要单独处理。 没有其他组合可以产生更小的总成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    pairs = n // 2
    singles = n % 2
    cost = pairs * min(2 * a, b) + singles * a
    print(cost)
```该代码读取测试用例的数量并在恒定时间内处理每个测试用例。 对于每个测试用例，它计算对和单个酸奶的数量，并使用`min`函数可以为配对选择更便宜的选项。 这种方法通过使用处理剩余的单打来避免相差一的错误`n % 2`。 计算简单，避免了不必要的循环。 

## 工作示例

 样本输入 1 的轨迹：

 输入：`2 5 9`变量：`n = 2`,`a = 5`,`b = 9`对：`2 // 2 = 1`单打：`2 % 2 = 0`配对成本：`min(2*5, 9) = 9`总成本：`1*9 + 0*5 = 9`输入：`3 5 11`变量：`n = 3`,`a = 5`,`b = 11`对：`3 // 2 = 1`单打：`3 % 2 = 1`配对成本：`min(2*5, 11) = 10`总成本：`1*10 + 1*5 = 15`这些痕迹表明，该算法正确地为配对选择了更便宜的选项，并处理了剩余的单身人士。

 ## 边缘情况

 对于`n = 1`和任何`b`，算法正确计算`singles = 1`和打印`a`，忽略促销。 对于奇数`n`喜欢`n = 3`,`pairs = 1`和`singles = 1`确保单独购买一份酸奶。 促销的时候`b`比单次购买两次要贵，`min(2*a, b)`选便宜的`2*a`。 什么时候`b`等于`2*a`，它仍然选择`2*a`，这是正确的。 这些情况证实了最小尺寸、奇数和边界促销价格方案的正确性。
