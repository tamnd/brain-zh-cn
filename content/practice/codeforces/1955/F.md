 ## 解决方案
 ## 问题理解

 我们被要求最大化鲍勃在与爱丽丝的重复异或游戏中可以获胜的游戏数量。 该游戏是在仅包含一、二、三和四的整数多重集上进行的。 如果所有剩余数字的 XOR 不为零，则 Alice 获胜； 否则，鲍勃获胜。 每局游戏结束后，裁判都会从多组中删除一个数字，然后用减少的组重复游戏，直到没有数字剩余为止。 问题是：考虑到开始时的一、二、三、四的计数，如果法官以最佳方式删除数字以有利于鲍勃，鲍勃可以获胜多少次？ 

每个测试用例提供四个整数，表示最初存在多少个 1、2、3、4 的副本。 输出是一个整数，即考虑到最佳移除后鲍勃可以赢得的最大游戏数。 

约束足够小，足以允许动态编程或贪婪模拟方法，因为每个计数最多为 200，因此数字总数最多为 800。测试用例的数量最多为 10^4，因此任何每个测试解决方案必须在每个测试用例的大约 O(1) 到 O(total_numbers) 时间内运行。 对所有移除序列进行强力模拟是不可行的，因为序列的阶乘数很多。 

当所有数字的异或最初为零时，就会出现一个重要的边缘情况。 在这种情况下，鲍勃立即获胜。 另一个棘手的情况是当数字都是偶数时，或者当某些数字在 XOR 模式中相互抵消时。 当法官可以策略性地删除数字以将失败的游戏变成鲍勃的胜利时，仅检查初始异或并错误地计算数字的幼稚方法将失败。 

## 方法

 暴力方法将尝试所有可能的删除序列并计算每个子序列的异或。 这显然是不切实际的：最多有 800 个数字，就有 800 个！ 序列。 即使对所有计数子集使用记忆化，状态空间也太大，因为有四个范围从 0 到 200 的计数，大约给出 201^4 = 1.6 * 10^9 状态。 

关键的观察结果是，XOR 完全由 1、2、3 和 4 计数的奇偶性决定。 1 到 4 之间的每个数字都可以表示为 2 位，XOR 表现为线性。 这极大地减少了有效状态空间：唯一相关的信息是每个数字总数的奇偶校验（奇/偶）。 因此我们可以关注模 2 的计数。 

我们还注意到，法官（Eve）可以选择删除哪个数字以最大化鲍勃的胜利。 这导致了贪婪策略：Eve 可以尽可能尝试强制 XOR 为零。 该解决方案简化为从奇偶性导出的公式：在给定当前多重计数集的情况下，计算当前 XOR 为零的游戏数量。 通过基于模 2 计数的仔细案例分析，我们可以计算出 Bob 获胜的次数，而无需模拟每个移除序列。

 ## 算法演练

 1. 计算游戏总数：将一、二、三、四的计数相加。 这是判断将去掉数字的圈数，也是异或计算的次数。 
2. 观察异或模式。 由于每个数字 ≤ 4，我们可以用其奇偶校验位来表示 XOR。 对于数字 1 到 4，跟踪总的异或就足够了，这相当于按其值加权的一、二、三和四的异或计数。 
3. 定义奇偶校验向量`(c1 % 2, c2 % 2, c3 % 2, c4 % 2)`。 当且仅当该奇偶校验向量异或为零时，多重集的异或为零。 Eve 的目标是最大化这种情况发生的次数。 
4. 计算 2 和 4 的总数。 数字 2 和 4 仅影响第二位。 如果2和4的和是偶数，则它们对异或的贡献为零； 否则，它是非零的。 同样，计算第一位的 1 和 3。 仅当两个位都为零时，异或才为零。 
5.使用公式`max_wins = min(total_even_bit_pairs, total_games)`。 该公式源自模拟具有最佳移除的游戏，但简化为奇偶推理。 关键是 Eve 总是可以删除在尽可能多的回合中保持异或为零的数字。 
6. 输出每个测试用例的最大计数。 

为什么有效：异或仅取决于奇偶性，法官总是可以选择数字来最佳地操纵这些奇偶性。 通过将问题简化为奇偶校验计数，贪婪策略给出了 Bob 可以利用的最大数量的零异或配置。 无论删除的顺序如何，Eve 都可以强制执行与公式预测的一样多的异或零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        p = list(map(int, input().split()))
        ones, twos, threes, fours = p
        total = sum(p)
        odd_count = (ones + threes) % 2
        even_count = (twos + fours) % 2
        # Compute maximum times Bob can win
        # Maximum Bob wins formula
        max_bob = (ones + twos + threes + fours) // 2
        # Adjust for parity trick
        if odd_count % 2 == 1 and total % 2 == 1:
            max_bob -= 1
        print(max_bob)

if __name__ == "__main__":
    solve()
```该代码读取测试用例的数量，然后为每个测试用例提取一、二、三和四的计数。 我们计算数字总数以及奇数和偶数类别的奇偶性。 最大获胜的公式结合了总数和奇偶校验调整，反映了鲍勃在给定最佳移除的情况下可以实现零异或的最大次数。
