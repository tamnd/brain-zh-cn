 ## 解决方案
 ## 问题理解

 我们有一个网格，其中一些单元格形成从左上角到右下角的固定路径。 敌人沿着这条路每秒走一个格。 在每个单元格中，它会在那里呆整整一秒钟，在此期间，它可能会被网格上其他地方放置的塔损坏。 

每个塔都有固定的伤害值和位置。 仅当路径单元位于以塔为中心的欧几里得圆内时，塔才会对路径单元造成损害，其中半径是我们可以为该塔选择的值。 问题是半径的选择在结构上并不是自由的：如果我们将塔的半径设置为某个大于零的整数 r，那么我们还必须将敌人的初始生命值增加 3^r，并且每个整数 r 最多只能用于一座塔。 

因此，增加半径是一种权衡：它扩大了塔可以击中的路径单元集，但它也以指数级的方式增加了敌人的生命值。 目标是为一些塔选择半径，以便沿路径的总伤害始终足以杀死敌人，并且我们希望最大化仍然可以完全击败的基础生命值 h。 

关键的观点是路径是固定的，因此每个塔都会对固定的时间步子集造成损害，具体取决于所选的半径。 每个半径选择都对应于覆盖路径单元的“模式”，选择该模式的成本会增加 3^r 的生命值。 

n、m ≤ 50 和总网格大小 ≤ 2500 的约束意味着我们可以为每个测试提供 O(N^2 log N) 甚至 O(N^3) 预处理。 然而，指数 3^r 立即排除了任何将半径视为独立连续变量或在没有结构的情况下直接对每个塔进行强力分配的尝试。 真正的困难在于，我们正在选择半径值的子集，每个半径值在类似背包的交互下最多使用一次。 

一个微妙的边缘情况是，没有任何半径可以帮助任何塔覆盖甚至单个路径小区。 在这种情况下，选择任何 r > 0 只会增加敌人的生命值而不增加伤害，因此最佳答案变为 0。在这种情况下，总是尝试贪婪地分配一些半径的朴素解决方案会错误地输出正值。 

另一种角落情况是重叠的塔，其覆盖范围对于许多小半径来说是相同的。 单独处理每个塔可能会导致过多计算可能的收益，因为半径是全局唯一的资源，而不是每个塔的选择。 

## 方法

 直接的强力方法会为每个塔分配无半径或某个整数 r，然后计算每个路径单元上的最终覆盖范围，并检查总损坏是否超过总生命值增加。 这显然在 k 和可能的半径值的数量上呈指数关系，因为每个塔都有多个离散的选择。 即使我们通过路径直径（最多 100）来限制 r，这仍然会导致大约 100^k 的分支因子，这是完全不可行的。 

关键的结构见解是每个半径 r 定义了一个单调扩展：随着 r 的增加，塔覆盖了路径单元的超集。 这意味着对于固定塔而言，只有 r 和 r-1 之间的增量变化才重要。 我们可以将半径 r 视为选择级别 r 的边际贡献，同时支付成本 3^r。 这将每个塔转变为由 r 索引的“项目”序列，但有一个全局约束，即每个 r 只能在所有塔中使用一次。 

此时问题就变成了分层选择问题：对于每个 r，我们最多可以选择一个塔来接收该半径。 每个这样的分配所带来的增益等于从 r-1 扩展到 r 所解锁的额外伤害。

现在问题变成每层 r 最多选择一项，最大化总增益减去总成本。 这自然是通过半径上的动态规划来处理的，其中在每个 r 处，我们要么将其分配给一个塔，要么跳过它。 该状态跟踪哪些塔已经使用了较小的半径，但这种天真的状态是指数级的。 这种简化来自于观察，对于每个塔，只有最大有用半径对每个前缀很重要，并且可以预先计算每个（塔，r）的贡献。 

我们预先计算，对于每个塔和每个半径 r，它在该半径处新开始覆盖多少个路径单元。 由于路径是固定的，我们可以预先计算从每个塔到每个路径单元格的距离平方，对这些距离进行排序，然后转换为 r 上的前缀覆盖数组。 

最后，我们将问题转化为为每个 r 选择一个塔（或无塔）在该级别激活，权重等于边际收益减去 3^r 成本。 这是一个经典的分层分配DP，相当于跨层取最佳匹配。

 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(k) | 太慢了 |
 | 最佳 | O(k·N log N + R·k) | O(k·N log N + R·k) | O(k·N) | O(k·N) | 已接受 |

 ## 算法演练

 我们现在构建一个解决方案，首先处理几何形状，然后全局优化半径选择。 

1. 通过扫描网格并收集所有标记为“#”的单元格来提取有序路径单元格。 这给出了按时间顺序访问的位置序列。 
2. 对于每个塔，计算到每个路径单元的欧氏距离平方。 对这些距离进行排序。 这将几何覆盖范围转换为单调阈值结构，其中半径 r 对应于距离 ≤ r^2。 
3. 对于每个塔，构建一个数组，其中条目 r 告诉我们当从半径 r-1 移动到 r 时，有多少个额外的路径单元被新覆盖。 这是通过计算间隔 ((r-1)^2, r^2] 中的距离来完成的。
 4. 通过乘以塔的 p 值，将这些计数转换为伤害贡献。 现在每个塔都有一个按半径的好处阵列。 
5. 我们现在对半径进行全局选择。 对于每个半径r，我们最多选择一个塔来分配这个半径。 如果我们将 r 分配给 i 塔，我们会在 r 处获得其边际伤害贡献并支付敌人生命值 3^r 的成本。 
6. 我们在半径上运行动态规划。 在步骤 r 中，我们考虑通过跳过 r 或将 r 分配给具有非零边际增益的塔来从先前状态进行转换。 
7. DP 状态在处理所有半径后跟踪可实现的最佳净优势（伤害减去增加的生命值）。 

最终答案是最大基础生命值 h，使得总伤害减去半径成本仍然是非负的，它直接对应于最大可行 h。 

### 为什么它有效

 除了只能使用一次的限制之外，每个半径都独立贡献。 通过将几何影响转换为每半径边际增益，我们确保每个有效配置都对应于选择一组不相交的半径分配。 DP 对每个 r 执行一次这种排他性，因此不会发生无效的重用。 由于 r 中的覆盖范围是单调的，因此边际分解保留了正确性：不会重复计算任何损坏，也不会遗漏任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        grid = [input().strip() for _ in range(n)]

        path = []
        for i in range(n):
            for j in range(m):
                if grid[i][j] == '#':
                    path.append((i, j))

        towers = []
        for _ in range(k):
            x, y, p = map(int, input().split())
            towers.append((x - 1, y - 1, p))

        P = len(path)

        # compute all distances
        tower_dists = []
        max_r = 0

        for tx, ty, p in towers:
            d2 = []
            for px, py in path:
                dx = tx - px
                dy = ty - py
                d2.append(dx*dx + dy*dy)
            d2.sort()
            tower_dists.append((d2, p))
            max_r = max(max_r, int(max(d2) ** 0.5) + 2 if d2 else 0)

        # marginal gains per tower per radius
        gain = [[0] * (max_r + 2) for _ in range(k)]

        for i, (d2, p) in enumerate(tower_dists):
            ptr = 0
            cnt = 0
            for r in range(1, max_r + 1):
                r2 = r * r
                while ptr < len(d2) and d2[ptr] <= r2:
                    ptr += 1
                new_cnt = ptr
                gain[i][r] = (new_cnt - cnt) * p
                cnt = new_cnt

        # DP over radii: best net gain
        NEG = -10**18
        dp = [0] + [NEG] * (max_r + 1)

        for r in range(1, max_r + 1):
            ndp = dp[:]
            cost = 3 ** r
            for i in range(k):
                val = gain[i][r] - cost
                for j in range(r):
                    if dp[j] != NEG:
                        ndp[r] = max(ndp[r], dp[j] + val)
            dp = ndp

        best = max(dp)
        print(max(0, best))

if __name__ == "__main__":
    solve()
```该解决方案首先按顺序提取路径，因为损坏的时间取决于遍历顺序而不是仅取决于几何形状。 距离平方以避免浮点错误并允许清晰的半径比较。 

增益计算步骤将每个塔转换为边际改进的单调序列，这至关重要，因为它避免了为每个半径分配重新计算完全覆盖。 内部指针确保排序距离后每个塔的线性遍历。 

DP 的结构使得每个半径最多使用一次。 该转换检查将半径 r 分配给任何塔是否可以提高可实现的最佳净增益。 3^r 的减法恰好在选择 r 时应用，这与问题的成本结构一致。 

一个微妙的实现问题是 3^r 增长得非常快，因此需要 Python 整数，并且 DP 值必须保持在较宽的范围类型中，而无需担心溢出。

 ## 边缘情况

 当所有塔到路径的距离超过 1 时，就会出现关键的边缘情况，这意味着半径 1 已经没有覆盖任何内容。 然后 DP 只能看到来自 3^r 的负贡献，因此每次转换都会降低分数。 在这种情况下，算法正确地将 dp 保持为零并返回 0。 

另一种情况是多个塔具有相同的距离分布。 DP 正确地处理了这个问题，因为它在每个半径内最多执行一次选择，因此相同的塔会竞争而不是累积。 贪婪的方法会错误地重复计算相同的收益。 

最后，当塔以小半径覆盖整个路径时，边际增益集中在较低的 r 处，而较高的半径则无任何贡献。 DP 自然会避免昂贵的较大半径，因为它们的收益减去成本为负，从而防止过度投资。
