 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格完全由三个值确定：左上角的单元格，以及控制向下和向右移动的两个固定增量。 向下移动一步总是会增加$c$，向右移动一步总是会增加$d$。 因此，一旦起始值固定，网格中的每个单元都可以表示为其坐标的线性函数。 

在概念上构建该网格后，我们将获得一组$n^2$任意顺序的整数。 任务是确定这个多重集是否可以恰好是给定的唯一定义的网格中出现的值的集合$n$,$c$， 和$d$。 我们不需要重建网格布局，只需验证这样的网格是否存在，其值与多重集完全匹配。 

这些约束迫使我们接近线性或$O(n^2 \log n)$每次测试最坏的情况。 由于所有测试用例的元素总数最多为$2.5 \cdot 10^5$，每次测试的排序或散列中的任何二次方都可以，但是尝试模拟所有可能的起始值或通过大量重新计算检查每个单元的一致性的任何方法都会太慢。 

一个天真的陷阱来自于认为数组的顺序很重要。 事实并非如此。 另一种微妙的故障模式是假设只有相对差异在本地才重要。 例如，当存在重复项或排序隐藏结构时，尝试验证行式或列式模式而不锚定网格会导致误报。 

考虑一个小的失败案例直觉：如果$n=2$,$c=1$,$d=2$，网格必须是$$\begin{pmatrix} x & x+2 \\ x+1 & x+3 \end{pmatrix}$$多重集必须恰好是$\{x, x+1, x+2, x+3\}$。 任何仅检查排序顺序中的邻接性的尝试都可能错误地接受不正确的多重集，其中间距正确但无法形成结构。 

## 方法

 暴力解释会尝试每一个可能的值$a_{1,1}$作为候选人的起点。 对于每个候选者，我们将使用递归关系构建整个网格，并将生成的多重集与给定数组进行比较。 由于值的范围可达$10^9$，起始值不以使得枚举可行的方式直接限制。 更糟糕的是，每项建设成本$O(n^2)$，并且对要尝试的候选者数量没有有意义的限制，使得这种方法完全不可行。 

关键的结构观察是网格完全由其最小元素决定。 因为两者$c$和$d$是积极的，每一步向下或向右都会严格增加价值。 这意味着网格中的最小元素必须是$a_{1,1}$，并且可以从中确定性地重建整个网格。 

一旦我们对数组进行排序，我们就可以尝试将最小值视为左上角。 从那里开始，网格的每个期望值都是唯一确定的。 唯一剩下的问题是多重集是否恰好包含这些值。 

关键的减少是将 2D 结构转变为 1D 验证问题：我们不是对几何进行推理，而是根据排序数组验证生成的期望值序列。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 暴力破解开始 | 指数/不可行| O(1) | O(1) | 太慢了|
 | 排序 + 验证构造 |$O(n^2 \log n)$| O(1) 额外 | 已接受 |

 ## 算法演练

 我们利用排序揭示了预期结构的事实。 

1.对数组大小进行排序$n^2$。 这给了我们一个候选排序，其中最小的元素被假设对应于$a_{1,1}$。 这是合理的，因为网格中的所有移动都会严格由于以下原因而增加值：$c, d \ge 1$。 
2.设最小元素为候选起始值$x$。 这唯一地修复了整个网格。 
3. 对于每个位置$(i, j)$，计算期望值：$$x + i \cdot c + j \cdot d$$这是从左上角重复应用递归直接得出的。 
4. 将每个计算值与同一索引处的排序数组进行比较（使用行优先遍历）。 如果发生任何不匹配，多重集就无法表示渐进正方形。 
5. 如果所有值完全匹配，则该数组有效。 

遍历时使用的顺序必须与排序数组一致。 由于构造和排序都强加了总排序，因此行主枚举与递增值对齐只是因为$c, d > 0$，确保两个维度上的单调增长。 

### 为什么它有效

 该结构在行和列方向上产生严格增加的网格。 这保证了网格值在按行优先顺序展平时形成严格递增的序列。 由于排序还会产生同一多重集的唯一递增排序，因此当且仅当多重集恰好是构造的网格时，两个序列必须一致。 这消除了有关放置的任何歧义：一旦最小的元素被固定，每个其他值都只有一个有效位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c, d = map(int, input().split())
        b = list(map(int, input().split()))
        
        b.sort()
        start = b[0]
        
        expected = []
        for i in range(n):
            for j in range(n):
                expected.append(start + i * c + j * d)
        
        expected.sort()
        
        if expected == b:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该解决方案首先对输入多重集进行排序。 这是至关重要的，因为网格的单调结构确保了展平时独特的递增顺序。 

然后，我们从最小值开始重建网格（如果网格有效）。 公式$start + i \cdot c + j \cdot d$直接通过重复应用行和列增量得出。 

最后，我们将生成的多重集与输入进行比较。 对两者进行排序可确保我们比较的是无序集合而不是位置布局。 

一个微妙的点是我们不会尝试猜测方向或排列。 严格的积极性$c$和$d$保证唯一的增加方向，因此没有替代安排可以满足约束。

 ## 边缘情况

 一个关键的边缘情况是输入数组中出现重复项时。 自从$c, d \ge 1$，真正的网格永远不会包含重复项，因此任何重复的数字都会立即使构造无效。 该算法自然地处理这个问题，因为排序会保留重复项，并且与生成的严格递增序列的比较将在第一个重复值处失败。 

另一个微妙的情况是最小的元素实际上并不正确$a_{1,1}$。 但是，由于网格在两个方向上严格递增，因此没有其他位置可以包含更小的值，因此最小的元素必须始终是正确的起点。 这消除了初始化中的任何歧义。 

最终的边缘情况很大$n = 500$，其中网格有 250,000 个元素。 该解决方案仍然是安全的，因为它只执行排序和线性生成，避免任何可能将其推入每个测试用例的二次行为的嵌套重新计算。
