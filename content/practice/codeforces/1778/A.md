 ## 解决方案
 ## 问题理解

 我们得到一个仅包含以下内容的数组`1`沙`-1`s。 任务是执行一项操作：选择两个连续的元素并翻转它们的符号。 完成此操作后，我们希望最大化所有数组元素的总和。 输入给出多个测试用例，每个测试用例都有其数组，输出应该是每个用例可实现的最大总和。 

这些约束表明数组可以很长，每个测试用例最多 100,000 个元素，并且所有测试用例的总数也限制为 100,000。 这告诉我们，任何复杂度比线性更差的算法`n`每个测试用例都会太慢。 

当数组拥有所有内容时，就会出现边缘情况`1`或全部`-1`s。 例如，如果数组是`[1,1,1,1]`，翻转任意两个元素都会减少总和，因此最佳的移动方式是将伤害最小化。 相反，如果数组是`[-1,-1]`，翻转它们会增加总和`-2`到`2`。 当数组包含混合但有一对连续的`-1`或`1`s 在末尾； 选择正确的一对可以产生最大的改善或防止下降。 

## 方法

 暴力方法会迭代每个索引`i`从`1`到`n-1`， 翻动`a[i]`和`a[i+1]`，计算总和并记录最大值。 这是正确的，因为它测试了所有可能性，但每个测试用例需要 O(n) 次操作，这在这个问题中是可以接受的，但没有必要。 由于总输入大小较小，朴素方法在这里起作用，但可以通过贪婪观察来简化。 

关键的见解是翻转一对连续的数字会改变总和，如下所示。 如果该对是`[x, y]`，翻转两者给出`-x - y`。 总和的变化是`(-x - y) - (x + y) = -2*(x + y)`。 为了最大化总和，我们想要`x + y`尽可能小，因为`-2*(x + y)`那么将会是最大的增幅。 两个元素的最小可能和是`-2`，当两者都为`-1`。 反之，最大的和是`2`（两个都`1`s)，如果翻转则减少总和。 因此，最优策略是检查是否存在一对`-1, -1`; 如果是，则翻转该对使总和增加 4。如果不存在这样的对，则翻转一对`1,1`或者`1,-1`将总和减少 4 或 0。 

鉴于对的可能性很小（`-1,-1`,`1,1`,`1,-1`,`-1,1`），我们可以贪婪地检查数组中的这些模式并应用相应的更改。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力翻转每一对| 每个测试用例 O(n) | O(1) | O(1) | 已接受但可以简化 |
 | 基于对和的贪婪 | 每个测试用例 O(n) | O(1) | O(1) | 被接受且更简单 |

 ## 算法演练

 1.读取测试用例的数量。 
2.对于每个测试用例，读取数组的长度`n`和数组`a`。 
3. 计算数组的初始和。 这是任何翻转之前的基线。 
4. 从第一个元素到倒数第二个元素迭代数组。 对于每个索引`i`，计算总和`a[i] + a[i+1]`。 
5. 如果这个金额是`-2`（两个都`-1`s)，然后翻转该对使总和增加 4。记录这是可能的最佳增加并打破循环，因为没有其他对可以提供更大的增加。 
6.如果没有`-1,-1`对，检查`1,1`成对； 翻转它们会使总和减少 4。如果只有`1,-1`或者`-1,1`对，翻转它们会将总和更改为 0。 
7. 将最佳可实现的增加或减少添加到初始总和中并输出结果。 

为什么有效：该操作仅影响两个连续的元素。 总和变化仅取决于这两个元素。 通过检查四个可能的对并选择最大化增加（或最小化减少）的一对，我们保证最佳总和。 由于数组只包含`1`和`-1`，这是仅有的四种配置，因此贪婪的选择是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        best_change = -float('inf')
        for i in range(n-1):
            pair_sum = a[i] + a[i+1]
            change = -2 * pair_sum
            if change > best_change:
                best_change = change
            if best_change == 4:  # maximum possible, can't do better
                break
        print(total + best_change)

if __name__ == "__main__":
    solve()
```该解决方案计算一次总和，迭代连续的对，计算翻转时的潜在变化，并保持最大可能的改进。 它短路一次`-1,-1`被发现，因为这给出了最大的增加。

 ## 边缘情况

 对于二元素数组`[1,1]`，唯一的操作就是翻转这两个元素。 初始总和为 2，翻转将总和更改为 -2。 该算法计算`pair_sum = 2`,`change = -4`，并将总和正确更新为-2。 为了`[ -1, -1 ]`，翻转将总和从 -2 增加到 2。具有交替符号的数组，例如`[1, -1, 1, -1]`总是产生`change = 0`，所以总和保持不变。 该解决方案可以正确处理所有此类边缘情况，因为它会检查每个连续的对并选择最大化净变化的一对。
