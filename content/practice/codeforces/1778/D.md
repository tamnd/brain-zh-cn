 ## 解决方案
 ## 问题理解

 两个长度相等的二进制字符串随着时间的推移而演变，但只有其中一个发生变化。 每次移动时，我们都会在所有索引中统一选择一个位置，并在该位置翻转第一个字符串的位。 第二根弦是固定的。 我们感兴趣的是第一个字符串第一次与第二个字符串相同需要多长时间，并且我们想要这个时间的期望值。 

重新构建该过程的一个有用方法是停止考虑绝对字符串，而只查看它们的不同之处。 如果我们定义一个包含索引的不匹配集，其中`a[i] != b[i]`，那么该过程只是索引子集上的随机游走，其中每一步都会翻转单个统一选择的索引的成员资格。 目标状态是空的不匹配集。 

因此，关键的输入参数是不匹配的初始数量，因为对称性确保仅它们的计数重要，而不是它们的位置。 令该数字为`k`。 

这些约束强制每个测试用例采用线性或近线性解决方案。 总和`n`所有测试用例的数量最多为一百万，因此任何每个用例 O(n) 或 O(total n log n) 的解决方案都是可以接受的。 任何尝试在子集上进行状态DP，甚至在不匹配计数上进行二次推理的尝试都是立即不可行的。 

一种天真的但诱人的方法是模拟该过程。 每一步都会翻转一个索引，然后我们检查字符串是否匹配。 然而，吸收之前的预期时间可以是任意大，并且蒙特卡罗模拟是无用的，因为答案必须精确地模一个大素数。 另一个常见的陷阱是尝试将不匹配视为独立的并计算每个位置的命中时间，这会失败，因为翻转一个索引可以以耦合的方式修复或重新引入其他地方的不匹配。 

一个显示非独立性的小例子是`a = 000`,`b = 111`。 所有三个位置都是不匹配的，但是修复一个不匹配会以一种取决于全局计数而不是位置标识的方式增加或减少状态。 任何按索引的分解都会失去正确性。 

## 方法

 蛮力观点是将过程建模为不匹配索引的所有子集集合上的马尔可夫链。 来自一个州`k`不匹配，每一步都选择其中之一`n`职位。 如果它选择了不匹配的位置，`k`减少一。 如果它选择了匹配的位置，`k`增加一。 所以转换仅取决于`k`，使其成为整数上的一维随机游走`0`到`n`具有吸收状态`0`。 

我们可以写出预期击中时间的标准线性方程`E[k]`，其中每个状态都满足涉及的递归`E[k-1]`,`E[k]`， 和`E[k+1]`。 直接求解这个系统每个测试用例的时间复杂度为 O(n)，这在规模上仍然太慢，但它已经揭示了关键结构：这是一个仅由计数决定的对称结构的生死链。 

关键的观察是，对称性让我们将系统折叠成封闭形式的表达式。 我们可以将这个过程解释为跟踪单个量，其期望仅取决于不匹配的数量，而不是求解所有方程。 一个经典的技巧是将递归转换为伸缩差异，揭示预期时间取决于通过选择不匹配与匹配位置的概率加权的类似谐波的总和。 

最终的封闭形式大大简化了：如果`k`是不匹配的数量，预期时间是$$\mathbb{E}[k] = n \cdot \sum_{i=1}^{k} \frac{1}{2i - 1}$$该表达式是通过消除线性系统并观察到每个归约步骤根据递减和递增转换之间的不平衡贡献一个倒数项而得出的。 该推导最终减少为对失配奇偶校验层的连续减少的预期等待时间求和。 

在计算上，这变成了奇数倒数的前缀和问题，计算一次直到最大可能值`n`，并在测试用例中重复使用。

 ## 算法演练

 我们预处理奇数分母上的类似谐波的值，直到最大值`n`。 

1. 计数不匹配`k`之间`a`和`b`。 这完全确定了状态，因为只有不匹配计数会影响转移概率。 
2. 预计算数组`H[i]`在哪里`H[i] = H[i-1] + inv(2*i - 1)`在模运算下。 这建立了错配减少的每个“层”的累积贡献。 
3. 对于每个测试用例，输出`n * H[k] mod M`。 乘以`n`来自按可用于翻转的索引总数缩放每步概率归一化。 

这种减少有效的原因是该过程仅通过不匹配的计数而演变，并且每次减少`k`到`k-1`贡献的术语与“有用翻转”相对于“有害翻转”发生的方式数量成反比。 

### 为什么它有效

 不匹配计数形成了一个生死链，其中的转换仅取决于我们选择一个好的索引（减少不匹配）还是一个坏的索引（增加不匹配）。 预期命中时间方程简化为具有可变系数的二阶线性递推。 通过定义前向差异来解决此递归问题，将其转换为赔率的伸缩总和。 这保证了任何路径分解都会崩溃到相同的确定性值，仅取决于`k`，所以最终的公式是精确且唯一的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    max_n = 0
    tests = []

    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()
        k = 0
        for i in range(n):
            if a[i] != b[i]:
                k += 1
        tests.append((n, k))
        max_n = max(max_n, n)

    inv = [0] * (2 * max_n + 2)
    for i in range(1, 2 * max_n + 2):
        inv[i] = modinv(i)

    H = [0] * (max_n + 1)
    for i in range(1, max_n + 1):
        H[i] = (H[i - 1] + inv[2 * i - 1]) % MOD

    out = []
    for n, k in tests:
        ans = n * H[k] % MOD
        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```解决方案首先将每个测试用例减少到一个整数`k`，不匹配计数。 这是唯一重要的状态变量。 

下一步是预先计算模逆`2n`，因为奇数倒数`1/(2i-1)`是必需的。 这在全局范围内完成一次，以避免重复求幂。 

然后我们构建一个前缀数组`H`累积奇数倒数。 每个条目汇总了所有失配减少层对该级别的贡献。 

最后，每个答案的计算时间复杂度为 O(1)：`n * H[k]`。 乘以`n`将标准化转移概率恢复到原始过程中的预期步数。 

一个微妙的实现点是逆表的构建是`2 * max_n`因为所需的最大奇数分母是`2n - 1`。 另一个是所有算术都必须保持模数`998244353`，因为直接分数无法表示。 

## 工作示例

 | --- | --- | --- | --- |

 输出是`1`，符合这样一个事实：一次翻转总是可以解决不匹配问题。 

这证实了基本情况，即在一次成功的移动后，链条立即吸收。 

### 示例 2

 输入：```

```这里不匹配发生在位置 2 和 3，所以`k = 2`。

该轨迹显示了第二个不匹配如何由于增加了实现减少过渡的机会而贡献了较小的边际预期成本。

 ## 边缘情况

 当`a`和`b`相同，不匹配计数为零，并且答案立即变为零，因为`H[0] = 0`。 该算法自然地处理这个问题，因为前缀数组从零开始，不需要进一步的计算。 

当各方立场不同时，`k = n`，该解评估完整的谐波奇数前缀。 递归解释仍然适用，因为每个步骤在递增和递减转换之间具有最大对称性，并且累积和占所有层。 

对于非常大的`n`，预计算确保所有逆运算都计算一次，并且每次测试的开销不会超过 O(1)。
