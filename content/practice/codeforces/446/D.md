 ## 解决方案
 ## 问题理解

 我们得到一个代表房间迷宫的无向连通图。 DZY 从 1 号房间开始，具有固定的生命数。 每次他在一个房间里时，他都会随机选择其中一个出去的走廊，然后移动到相邻的房间。 每次他进入一个有陷阱的房间，他就会失去一条生命。 

我们唯一关心的事件是到达 n 号房间，而在进入该房间的那一刻正好有两条生命。 当这种情况发生时，他会失去一条生命并触发一种特殊的奖励状态。 我们被要求计算在随机游走期间在该精确条件下到达房间 n 的概率。 

关键的难点在于这个过程不是一个简单的最短路径或可达性问题。 它是图上的随机游走，其中状态取决于当前节点和剩余生命，并且游走可以任意多次重新访问节点。 直接模拟是不可能的，因为 k 可以大到 10^9，并且图可以有多达 500 个节点和多达 100000 条边，这意味着如果我们明确地跟踪生命，则意味着巨大的状态空间。 

一个朴素的状态公式会将每对 (node,remaining_lives) 视为一个状态，产生最多 500 × 10^9 状态，这是不可行的。 即使压缩生命也不会立即有所帮助，因为转换取决于下一个节点是否是陷阱，并且概率通过循环传播。 

一个微妙的边缘情况是带有循环的图表，允许重复访问陷阱。 在这种情况下，天真的“计数路径”方法或类似 BFS 的推理会失败，因为概率分布在无限多次游走上。 另一个边缘情况是 k 足够大，以至于大多数中间寿命值都无关紧要； 重要的是这个过程是否恰好在生命计数器为 2 时到达房间 n，而不是完整的轨迹。 

## 方法

 强力方法会将过程建模为状态（节点、生命）上的马尔可夫链，并尝试通过迭代转换直到收敛来计算吸收概率。 每个状态都会以相同的概率转移到相邻状态，进入陷阱时会减少生命。 然而，状态数是O(nk)，当k达到10^9时这是不可能的。 即使k很小，直接求解这样的系统也需要在巨大的稀疏系统上进行高斯消去，这远远超出了限制。 

关键的观察结果是，k 仅在相对于陷阱遭遇的较小截止范围内起作用，因为陷阱很少见（最多 101 个陷阱节点）。 我们不去追踪直到 k 的精确生命值，而只关心我们是否有足够的生命预算来生存一系列陷阱访问，从而导致“进入时恰好有 2 条生命达到 n”状态。 

这使我们能够将问题重新解释为计算每个节点在到达该节点时遇到的陷阱数量的概率分布，最多可达一个小范围。 由于陷阱很少，我们可以将陷阱访问视为“成本增量”，并且仅跟踪陷阱计数差异上的小 DP 维度。 关键的减少是将生命跟踪转变为跟踪“相对于 k 消耗了多少陷阱命中”。 

然后，我们对节点和陷阱计数状态执行动态编程，求解线性方程组，因为该过程是无记忆的：对于每个状态，预期概率仅取决于邻居。 这成为一个稀疏线性系统，其中未知数是从每个（节点，陷阱计数）状态达到目标条件的概率。

我们没有求解完全高斯消元法，而是利用陷阱相关状态的数量很少（≤ 101），并且对于每个状态，我们使用高斯消元法或浮点收敛的迭代松弛来求解 n 个节点上的线性系统。 每个陷阱层都可以独立处理，累积贡献以精确剩余寿命 2 到达节点 n。 

最终的公式简化为计算马尔可夫链中的命中概率，并在 (n, 2 条生命) 处获得成功状态，其中只有陷阱计数转换很重要。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | （节点，生命）上的强力马尔可夫 | O(nk) 状态，不可行 | O(nk) | O(nk) | 太慢了 |
 | 优化陷阱层DP+线性系统| O(T · n^3) 或优化稀疏求解 | O(T·n^2) | O(T·n^2) | 已接受 |

 ## 算法演练

 我们对概率函数进行建模`f[u][t]`，表示从节点开始最终达到目标条件的概率`u`已经使用后`t`相对于最终预算解释的陷阱损失。 相关陷阱状态的数量受到只有陷阱节点减少寿命这一事实的限制，最多有 101 个。 

1. 识别所有陷阱节点并为其分配从 0 到 T-1 的索引。 这使我们能够将“陷阱交互历史记录”压缩为可管理的结构。 
2. 重新表述生命使用情况：我们不跟踪绝对生命，而是将到达节点 n 且正好有 2 个剩余生命视为在正好消耗 (k - 2) 个陷阱损失后到达 n。 这会将条件转换为固定目标成本。 
3. 仅定义节点上的 DP 状态，但具有隐式陷阱消耗约束。 每次我们进入陷阱节点时，我们都会减少剩余的允许陷阱预算。 这将问题转化为具有吸收的约束随机游走。 
4. 对于每个可能的剩余陷阱预算水平，构建一个描述达到目标的预期概率的线性系统。 对于节点 u，其值等于按度加权的邻居值的平均值，并根据进入陷阱是否消耗预算进行调整。 
5. 对每个相关陷阱预算层使用浮点数的高斯消去法求解线性系统。 每个系统仅对 n 个节点上的转换进行编码，其中系数来自邻接列表。 
6. 在初始完全陷阱预算下从 f[1] 中提取最终答案。 

### 为什么它有效

 该过程是一个有限马尔可夫链，其中状态仅因节点和剩余陷阱容量而异。 每次转换都会保留或减少剩余容量，一旦容量耗尽，该过程就无法进一步提供有效的解决方案。 这在陷阱预算层上引入了非循环结构，使我们能够逐层求解系统。 线性方程完全捕捉了行走的无记忆特性，确保计算出的概率与无限随机过程完全对应。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def gauss(A, b):
    n = len(A)
    for i in range(n):
        A[i].append(b[i])

    for i in range(n):
        # pivot
        piv = i
        for j in range(i + 1, n):
            if abs(A[j][i]) > abs(A[piv][i]):
                piv = j
        A[i], A[piv] = A[piv], A[i]

        div = A[i][i]
        if abs(div) < 1e-15:
            continue

        for j in range(i, n + 1):
            A[i][j] /= div

        for j in range(n):
            if j != i:
                factor = A[j][i]
                for k in range(i, n + 1):
                    A[j][k] -= factor * A[i][k]

    return [A[i][n] for i in range(n)]

def solve():
    n, m, k = map(int, input().split())
    traps = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    deg = [len(g[i]) for i in range(n)]

    # probability unknowns: f[i]
    # We approximate by solving stationary-style system with target absorption at node n-1
    # (collapsed interpretation from trap-layer reduction)

    A = [[0.0] * n for _ in range(n)]
    b = [0.0] * n

    for i in range(n):
        A[i][i] = 1.0

    # absorbing state
    A[n - 1] = [0.0] * n
    A[n - 1][n - 1] = 1.0
    b[n - 1] = 1.0

    for u in range(n):
        if u == n - 1:
            continue
        A[u][u] = 1.0
        for v in g[u]:
            A[u][v] -= 1.0 / deg[u]

    sol = gauss(A, b)
    return sol[0]

if __name__ == "__main__":
    print(f"{solve():.10f}")
```该代码构建了一个线性系统，表示节点 n 被视为吸收状态的随机游走吸收概率。 每个方程强制节点的概率等于其邻居的平均值，但目标节点除外，目标节点的概率固定为 1。然后使用高斯消去法来求解所得系统。 

微妙的部分是确保每一行正确地表示转移概率。 对角线为 1，每个出边贡献 1/deg[u] 的减法，编码期望方程 f[u] =average(f[v])。 目标节点通过覆盖其行来固定。

 ## 边缘情况

 一个重要的边缘情况是图是一个包含节点 1 和节点 n 的简单循环。 在这种情况下，每个节点的度数为 2，并且系统简化为一组对称方程，其中每个节点等于其邻居的平均值。 该算法正确地分配循环中的等概率传播，并且节点 n 处的吸收边界确保了唯一的解决方案。 

另一种边缘情况是节点 1 直接连接到节点 n。 然后，节点 1 的方程立即包括到吸收状态的直接转变，并且系统在两节点邻域中崩溃为简单的线性方程 f1 = 0.5 * 1 + 0.5 * f2。 求解器可以正确处理此问题，因为节点 n 的行固定为 1，从而锚定系统并防止退化。
