 ## 解决方案
 ## 问题理解

 我们正在处理一个非常大的有向步行计数问题，该问题的结构很严密，但太大而无法显式构建。 

有$2m$岛屿，DZY 从主节点开始。 从家里，他可以搬到岛上$i$在$a_i$不同的方式。 在第一个动作之后，他进行了精确的步行$t$岛屿之间的日子。 每天他要么留在当前的岛屿上，要么穿过一座桥到达另一个岛屿。 在每对有序的不同岛之间，存在多个并行的无向桥，其数量仅取决于索引之间的整除条件。 

任务是计算每个岛屿$i$，结束于的不同方式的数量$i$恰好在之后$t$从家开始的天数，然后返回所有这些计数的异或模$1051131$。 

关键的困难不是步行的定义本身，而是规模。$t$可以达到$10^{18}$，所以我们显然处于一个不可能随时间直接动态规划的状态。 图的结构必须引起一些代数简化，几乎肯定会引起大小空间中的矩阵求幂$2m \le 50$。 

一个天真的解释是将此视为最短或计数步行问题$50 \times 50$转移矩阵。 这已经表明$O(n^3 \log t)$或类似的方法，如果矩阵是稀疏的或结构化的，则这些方法是边界性的，但可以接受。 

一个微妙的陷阱是“停留”操作。 停留在每个节点引入权重为 1 的自循环，该自循环必须包含在转移矩阵中。 另一个微妙之处是边的多重性：桥的数量不是 0 或 1，而是取决于整除性，这意味着邻接权重是算术输入，而不是任意输入。 

最后，答案是对所有端点进行异或。 这可以防止我们丢弃中间值，并且强烈表明我们不需要每个中间值$ans[i]$独立且完全精确，但我们仍然必须首先计算它们，因为 XOR 是在最后应用的。 

## 方法

 如果我们忽略结构，自然模型是一个带权有向图$n = 2m \le 50$。 让$T$是一个转移矩阵，其中$T[u][v]$是从的移动方式的数量$u$到$v$一天之内，包括选择留下来。 

从家开始的第一次移动定义了一个初始向量$v_0$在哪里$v_0[i] = a_i$。 之后，每天都会将状态乘以$T$，所以之后$t$我们计算的天数$v_t = v_0 \cdot T^t$。 答案源自$v_t$。 

这将问题减少到最多计算大小的矩阵幂$50 \times 50$。 直接暴力很简单：乘以矩阵$t$次。 那成本$O(n^2 t)$，这是不可能的$t = 10^{18}$。 

矩阵求幂将其简化为$O(n^3 \log t)$，这大约是$50^3 \cdot 60$，轻松可行。 

真正重要的部分是构建$T$高效。 所有成对边缘计数的直接计算将是$O(n^2)$具有可除性检查，这对于$n = 50$。 重复定义$a_i$也是线性的并且可以生成$O(n)$。 

关键的见解是，一旦系统被写成线性变换，巨大的时间维度就会完全消失，取而代之的是矩阵代数中的重复平方。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 数天的暴力模拟 |$O(t \cdot n^2)$|$O(n^2)$| 太慢了 |
 | 矩阵求幂|$O(n^3 \log t)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 构造数组$a$使用给定的递归。 这给出了从家乡到每个岛屿的直接转移次数。 这一步是必要的，因为它定义了方式的初始分配。 
2. 构建转移矩阵$T$尺寸的$2m \times 2m$。 对于每个岛屿$i$，包括一个自循环$T[i][i] += 1$代表留下的选择。 
3. 对于每对不同的岛屿$u, v$, compute the number of bridges between them using the divisibility rule given in the problem. 将此值添加到两者$T[u][v]$和$T[v][u]$因为这些桥是无向的。 此步骤对所有可能的日常运动进行编码。 
4. 将初始状态解释为行向量$v$， 在哪里$v[i] = a_i$，因为我们第一次从家乡搬到岛上$i$在$a_i$方式。 
5. 计算$T^t$使用二进制求幂。 每个乘法构成一步转换，求幂压缩$t$转变为$O(\log t)$矩阵乘法。 
6. 乘法$v$经过$T^t$得到最终的分布$t$天。 
7. 计算所得向量模的所有条目的异或$1051131$。 

关键的不变量是之后$k$步骤、入口$v[i]$表示以岛屿为终点的不同有效步行的总数$i$恰好在之后$k$天。 每个矩阵乘法都保留了这种解释，因为它对每个有效路径的所有中间状态精确求和一次，并且求幂结构确保不会跳过或重复路径长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1051131

def mat_mul(A, B):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(n):
            if Ai[k] == 0:
                continue
            aik = Ai[k]
            Bk = B[k]
            for j in range(n):
                Ri[j] = (Ri[j] + aik * Bk[j]) % MOD
    return res

def mat_pow(M, e):
    n = len(M)
    R = [[0] * n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1
    while e:
        if e & 1:
            R = mat_mul(R, M)
        M = mat_mul(M, M)
        e >>= 1
    return R

def vec_mul(v, M):
    n = len(v)
    res = [0] * n
    for i in range(n):
        if v[i] == 0:
            continue
        vi = v[i]
        for j in range(n):
            res[j] = (res[j] + vi * M[i][j]) % MOD
    return res

def solve():
    m, t, s = map(int, input().split())
    n = 2 * m

    a = [0] * n
    for i in range(s):
        a[i] = int(input().split()[0])

    for i in range(s, n):
        a[i] = (101 * a[i - s] + 10007) % MOD

    T = [[0] * n for _ in range(n)]

    for i in range(n):
        T[i][i] = 1

    for u in range(n):
        for v in range(u + 1, n):
            cnt = 0
            a_uv = a[u]
            a_vu = a[v]
            for d in range(1, int(min(a_uv, a_vu) ** 0.5) + 1):
                if a_uv % d == 0:
                    if a_vu % d == 0:
                        cnt += 1
                    other = a_uv // d
                    if other != d and a_vu % other == 0:
                        cnt += 1
            T[u][v] += cnt
            T[v][u] += cnt

    Tt = mat_pow(T, t)

    v = a[:]
    v = vec_mul(v, Tt)

    ans = 0
    for x in v:
        ans ^= x % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该实现将过程分为三个阶段：$a$，构建转移矩阵，并应用快速求幂。 

矩阵乘法通过跳过零条目进行优化，这很重要，因为根据整除性，许多转换可能为零。 自循环初始化至关重要，因为忘记它会删除“停留”操作并错误地减少所有路径计数。 

最后的向量矩阵乘法是从初始后置状态到完整状态的最终传播$t$阶分布。

 ## 边缘情况

 一个微妙的情况是当$t = 0$。 在这种情况下，离开家后不会发生任何转变，因此结果必须等于初始分布$a_i$。 该算法可以正确处理此问题，因为当指数为零时，矩阵求幂会返回单位矩阵，因此$v \cdot I = v$，保持初始状态。 

另一种情况是当所有$a_i$是相同的。 那么每一对都具有相同的整除结构，并且转移矩阵变得高度对称。 该算法仍然有效，因为矩阵求幂在乘法下保留了对称性。 

最后，最坏情况的可分性结构发生在当许多$a_i$分享小因素。 除数计数循环正确地枚举每个除数对一次，确保并行桥不会重复计数，这对于转移矩阵中边权重的正确性至关重要。
