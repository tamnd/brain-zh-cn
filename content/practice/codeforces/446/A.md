 ## 解决方案
 ## 问题理解

 我们得到了一个数组，最多可达$10^5$整数。 我们可以选择任何连续的子数组，并且最多可以修改该子数组中的一个元素，将其替换为我们想要的任何整数。 目标是最大化子数组的长度，该子数组在执行最多一次修改后可以严格增加。 

关键细节是修改完全不受限制。 我们不受原始值的限制，我们可以选择任何整数，无论​​大还是小。 我们只关心子数组是否可以转化为最多一次变化的严格递增序列。 

约束条件$n \le 10^5$立即排除二次算法。 任何检查所有子数组的解决方案都需要大约$5 \times 10^9$最坏情况下的操作，远远超出了极限。 我们的目标应该是线性或接近线性的解决方案。 

一些边缘情况很容易被忽略。 

考虑：```
3
1 2 3
```答案是3。即使我们可以修改一个元素，我们也不必使用该修改。 假设只需要进行一项更改的解决方案将会失败。 

考虑：```
3
5 5 5
```答案是1.任意两个相邻元素违反严格增加。 通过一项修改，我们只能修复一个位置，因此长度为 2 或以上的子数组不能变为严格递增。 粗心的解决方案可能会假设每个违规都可以独立修复，并错误地返回 2。 

考虑：```
5
1 2 10 3 4
```答案是 4。我们可以将 10 更改为 2 到 3 之间的任何值，获得长度为 5 的严格递增段。替换值必须适合相邻元素之间这一事实至关重要。 仅仅统计违规行为是不够的。 

考虑：```
5
1 2 3 4 5
```答案是 5。一个常见的错误是只查看序列中断的地方。 如果根本没有中断，则整个数组已经有效。 

## 方法

 最直接的想法是检查每个子数组。 对于每个子数组，我们可以检查最多更改一个元素是否会使其严格增加。 

这种强力方法是正确的，因为它明确地测试了每个候选答案。 不幸的是有$O(n^2)$子数组。 即使我们在恒定时间内检查每个子数组，对于$n = 10^5$。 实际的实施会慢得多。 

为了获得更快的解决方案，我们应该查看严格递增游程的结构。 

假设我们知道，对于每个位置，以该位置结束的最长严格递增线段的长度以及从该位置开始的最长严格递增线段的长度。 

让：

-`L[i]`= 结束于的严格递增后缀的长度`i`-`R[i]`= 开始于的严格递增前缀的长度`i`这些数组可以在线性时间内计算。 

一旦我们有了它们，我们就可以提出一个更有针对性的问题：如果位置`i`是我们修改的元素，严格递增的线段可以通过该位置多长时间？ 

有两种可能性。 

首先，我们可以通过改变一个端点来扩展一个递增的段。 例如，如果段结束于`i - 1`有长度`L[i - 1]`，改变`a[i]`适当地允许我们将其扩展一个元素。 同样对于右侧使用`R[i + 1]`。 

其次，我们可以将左侧的一个递增线段与右侧的另一个递增线段连接起来。 仅当之间严格存在整数时，这才有可能`a[i-1]`和`a[i+1]`。 

因为值是整数，所以这样的值恰好存在于：$$a[i+1] - a[i-1] > 1$$当这个条件成立时，我们可以替换`a[i]`用一个合适的整数并将两个游程合并成一个更大的严格递增段。 

整个问题简化为评估线性时间内每个位置的这些可能性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取数组。 
2.如果`n = 1`，立即返回1。 
3. 构建数组`L`。`L[i]`存储以位置结束的最长严格递增连续段的长度`i`。 

如果`a[i] > a[i-1]`，则可以扩展该段并且：`L[i] = L[i-1] + 1`。 

否则：`L[i] = 1`。 
4. 构建数组`R`。`R[i]`存储从位置开始的最长严格递增连续段的长度`i`。 

如果`a[i] < a[i+1]`， 然后：`R[i] = R[i+1] + 1`。 

否则：`R[i] = 1`。 
5. 用现有最大的递增线段初始化答案。 

这简直就是`max(L)`。 
6. 对于每个位置`i`，考虑改变`a[i]`。 

如果`i > 0`，我们可以将左游扩展一个元素：`answer = max(answer, L[i-1] + 1)`。 
7. 如果`i + 1 < n`，我们可以将右游程扩展一个元素：`answer = max(answer, R[i+1] + 1)`。 
8.如果`0 < i < n-1`，检查左右游程是否可以合并。 

如果：`a[i+1] - a[i-1] > 1`那么它们之间严格存在某个整数。 

我们可能会更换`a[i]`具有这样的值并获得：`L[i-1] + R[i+1] + 1`作为合并长度。 
9. 将答案限制在最多`n`。 
10.输出答案。 

### 为什么它有效`L[i]`和`R[i]`捕获数组中每个最大递增运行。 任何最佳解决方案都会修改运行的终点或两次运行之间的位置。 

如果我们修改一个端点，最好的可能结果是将一侧恰好扩展一个元素，该元素被`L[i-1] + 1`和`R[i+1] + 1`过渡。 

如果我们修改内部位置，获得更长线段的唯一方法是连接以`i-1`随着开始运行的增加`i+1`。 当有效的替换值可以严格地放置在相邻值之间时，这种连接正是可行的。 条件`a[i+1] - a[i-1] > 1`既是必要的又是充分的。 

每个可能的最佳修改都属于这些情况之一，因此算法检查的最大值正是答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n == 1:
        print(1)
        return

    L = [1] * n
    for i in range(1, n):
        if a[i] > a[i - 1]:
            L[i] = L[i - 1] + 1

    R = [1] * n
    for i in range(n - 2, -1, -1):
        if a[i] < a[i + 1]:
            R[i] = R[i + 1] + 1

    ans = max(L)

    for i in range(n):
        if i > 0:
            ans = max(ans, L[i - 1] + 1)

        if i + 1 < n:
            ans = max(ans, R[i + 1] + 1)

        if 0 < i < n - 1 and a[i + 1] - a[i - 1] > 1:
            ans = max(ans, L[i - 1] + R[i + 1] + 1)

    print(min(ans, n))

if __name__ == "__main__":
    solve()
```第一遍计算在每个位置结束的增加的段。 第二遍计算从每个位置开始增加的段。 它们一起总结了数组中所有局部递增结构。 

主循环评估每个可能的修改位置。 将运行扩展一个元素相当于将当前值更改为极大或极小。 合并两次运行需要检查相邻值之间是否可以容纳有效整数。 

决赛`min(ans, n)`在大多数情况下在技术上是不必要的，但是当转换产生时将结果安全地保持在数组范围内`n + 1`。 

边界处理是实现中最微妙的部分。 数组末尾的位置无法合并两个游程，因为一侧不存在。 条件`i > 0`,`i + 1 < n`， 和`0 < i < n - 1`防止超出范围的访问。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 一次从左到右通过，一次从右到左通过，一次最终扫描 |
 | 空间| O(n) | 数组`L`和`R`每个商店`n`整数 |

 该算法仅对每个元素执行恒定量的工作。 和$n \le 10^5$，总操作次数很容易在时间限制内，并且内存使用量远低于256 MB。

 ## 边缘情况

 ### 单元素数组

 输入：```
1
10
```该数组已经严格递增，因为它只包含一个元素。 该算法在构造任何辅助数组之前立即返回 1。 

### 所有元素都相等

 输入：```
5
5 5 5 5 5
```我们得到：```
L = [1, 1, 1, 1, 1]
R = [1, 1, 1, 1, 1]
```由于相邻值相等，因此合并条件不会成功。 延长任一侧的长度都是 2，因此答案变为 2。 

这是一个常见的错误来源，因为答案不是 1。一次修改总是可以创建一对严格递增的对。 

### 间隙太小而无法合并

 输入：```
3
1 100 2
```在中间位置：```
a[2] - a[0] = 1
```不存在严格介于 1 和 2 之间的整数。合并转换被拒绝。 算法正确返回 2。 

### 整个数组已经在增加

 输入：```
5
1 2 3 4 5
```计算出的数组是：```
L = [1, 2, 3, 4, 5]
```最初的答案已经是 5。任何修改都不能产生比整个数组更长的段，因此最终结果仍然是 5。这验证了算法正确处理了不需要更改的情况。
