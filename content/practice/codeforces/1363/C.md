 ## 解决方案
 ## 问题理解

 游戏在一棵树上进行，树是一个无向、连通、无环图。 每个节点的编号从$1$到$n$，和一个节点$x$很特别。 两个玩家轮流移除叶节点，其中叶节点是只有一个邻居及其连接边的节点。 移除特殊节点的玩家$x$获胜。 阿尤什先行动，任务是确定哪位玩家在最佳发挥下获胜。 

输入将树描述为$n$节点和$n-1$边缘，然后是一些测试用例$t$。 输出是一个字符串，用于标识每个测试用例的获胜者。 节点数量$n$至多是$1000$，所以任何二次的算法$n$或更好的将有效运行。 

非明显的边缘情况包括特殊节点的情况$x$已经是一片叶子了，因为这样阿尤什就可以在第一回合将其移除并立即获胜。 另一个微妙的情况出现时$x$只有一个邻居，并且节点总数很少。 如果粗心的解决方案假设所有节点的度数至少为 2 或盲目地交替转弯而不检查周围的结构$x$，它会给出错误的结果。 

例如，考虑一棵树$n=3$,$x=1$和边$1-2$和$1-3$。 节点$2$和$3$是叶子。 Ayush 只能删除其中一项，之后$1$变成一片叶子，阿什什可以把它移走，赢得比赛。 这说明即使有一棵小树，周围的局部结构$x$决定结果。 

## 方法

 暴力方法可以明确地模拟游戏。 在每一轮，我们都会枚举所有当前的叶子，生成每个可能的移动结果的树，并递归计算下一轮的获胜者。 这种方法是正确的，因为它直接应用规则并探索所有游戏状态，但它的速度呈指数级缓慢$n$因为子树的数量增长很快，并且$n$最多可达 1000，使得这种方法不可行。 

最优方法利用了博弈完全由特殊节点的度决定的见解$x$以及节点总数的奇偶性。 如果$x$有学位$1$或者$0$，它是一片叶子或孤立的，所以阿尤什可以立即将其移除并获胜。 否则，游戏就相当于简单的回合制移除$n-1$节点，最后一步决定获胜者。 具体来说，如果$n$均匀时，阿尤什摘下最后一片叶子，获胜； 如果$n$奇怪的是，阿什什会摘下最后一片叶子并获胜。 这一观察将问题简化为检查程度$x$和奇偶性$n$，避免任何模拟。

 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取节点数$n$和特殊节点$x$。 
3. 构造树的邻接表$n-1$边缘。 
4. 计算特殊节点的度$x$。 
5.如果程度$x$是$1$或者$0$，阿尤什立即获胜，因为他可以在第一步将其移除。 
6. 否则，检查奇偶性$n$。 如果$n$相等，阿尤什获胜； 如果$n$很奇怪，阿什什赢了。 推理是，每次移动恰好删除一个节点，当剩余节点总数为 时，移动的玩家$1$获胜。 

为什么它有效：关键的不变量是获胜者取决于谁被迫删除最后一个节点。 如果$x$最初是一片叶子，阿尤什立即获胜。 否则，每次移动都会使节点数减少一个，因此奇偶校验$n$相对于第一次移动决定谁将删除最后一个节点。 该算法利用树结构，无需显式模拟。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        adj = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u].append(v)
            adj[v].append(u)
        if len(adj[x]) <= 1:
            print("Ayush")
        else:
            if n % 2 == 0:
                print("Ayush")
            else:
                print("Ashish")

if __name__ == "__main__":
    main()
```该解决方案首先有效地读取输入并构建树的邻接表。 检查`len(adj[x])`给出特殊节点的度，它直接决定立即获胜的情况。 奇偶校验打开`n`考虑了移动的交替$x$不是一片叶子。 循环处理多个测试用例可确保不同输入的正确性。 一个微妙的点是使用`n+1`用于匹配从 1 开始的节点索引的邻接。

 ## 边缘情况

 如果树由单个节点组成，则该节点自动成为叶子。 该算法通过检查来处理这个问题`len(adj[x]) <= 1`，正确报告阿尤什为获胜者。 

在 x 最初是叶子但 n > 1 的情况下，Ayush 立即获胜，并且邻接表正确显示`len(adj[x]) == 1`，触发适当的分支。 

对于以 x 作为度 >1 的中心节点的长链或树，n 的奇偶性决定结果。 使用基于 1 的索引构建邻接列表可确保度计算准确，并且模检查可以正确识别将删除最后一个节点的玩家。 这些边缘情况证实了结构逻辑和基于奇偶校验的逻辑均已正确实现。
