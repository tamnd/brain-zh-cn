 ## 解决方案
 ## 问题理解

 我们给出了一个深度的三角网格$n$。 底行包含一个单元格，其上方的每一行两侧都扩展一个单元格，因此顶行有$2n-1$细胞。 将球放入顶行的任何单元格中，然后确定性地逐行移动，直到它退出底行中的单个单元格下方。 

当球从行中的一个单元格移动时$r$向下到行$r+1$，它通常在同一列中继续。 然而，这个移动规则有两个修改。 首先，如果球位于行的左边界，则在下降之前将其向右移动一个单元格。 如果它位于右边界，则向左移动一个单元格。 其次，一些单元格包含传送带，当球到达这样的单元格时，它会立即在同一行内向左或向右移动一步，然后继续向下运动。 

任务是确定对于每个测试用例，顶行中的哪些起始位置最终导致球从底部单元格退出。 

结构体很大：$n$可以达到$10^5$，并且最多有$2 \cdot 10^5$每个测试用例的传送带总数，最多$10^4$测试用例。 这立即排除了任何为每个起始位置单独跟踪球的模拟，因为这会花费$O(n^2)$每个测试用例在最坏的情况下都远远超出了可行的限制。 

一个微妙的困难是运动不是简单的直线垂直下降。 每行都包含由传送带引起的局部水平扰动以及有效“折叠”路径的边界反射。 独立模拟每个起始位置的天真尝试会失败，因为单个路径可能涉及最多$n$行转换，并且有$O(n)$起点。 

当输送机反复推动球越过边界时，就会出现一种重要的边缘情况：

 例如，如果一行具有类似的传送带序列$c \rightarrow c+1$下一个单元有一个传送带$L$，如果不仔细建模，天真的单步解释可能会错误地处理链式运动。 另一个问题是边界交互，即使没有传送带，位于最左或最右也会修改下一列。 

## 方法

 直接的暴力方法将从顶行的每个起始单元模拟球。 每个模拟都会经历所有$n$行，在每个步骤中应用传送带移动和边界调整。 由于有$2n-1$起始位置，这成本$O(n^2)$最坏情况下的每个测试用例。 和$n = 10^5$，这变得完全不可行。 

关键的观察结果是该过程是有效的：行中的每个单元格$r$确定性地映射到行中的一个单元格$r+1$。 解决传送带和边界规则后，每一行定义一个函数$f_r$从该行中的列到下一行中的列。 因此，整个系统是一个组合：$$f_1 \circ f_2 \circ \cdots \circ f_{n-1}$$我们不是在每次开始时都模拟向前，而是反转视角。 底行有一个出口单元格，因此我们可以向后传播：确定行中的哪些单元格$n-1$可以到达出口，然后在哪排$n-2$，依此类推直至顶部。 每行都成为两层相同大小的段之间的映射问题，并且传送带仅在这些映射中创建局部修改。 

这将问题转化为在一系列按行功能转换中保持可达性，其中每行仅引入少量局部中断（每个传送带最多一个）。 该结构使我们能够独立处理行，并以每行的线性时间向上传播一组“好”位置。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 暴力模拟|$O(n^2)$|$O(1)$| 太慢了 |
 | 行式函数传播 |$O(n + m)$每次测试|$O(n)$| 已接受 |

 ## 算法演练

 我们从下到上处理每个测试用例，为每行维护哪些位置能够最终到达出口。 

1. 从底行开始。 唯一有效的端点是它的单个单元格，因此我们将其标记为可达。 
2. 一次向上移动一行。 在行$r$，我们想要确定哪些位置可以导致行中已知的可到达位置$r+1$。 这是通过反转移动规则来完成的：我们不是将状态向下推，而是向上拉可达性。 
3. 对于给定的行，首先合并传送带效果。 每个传送带定义从一列到同一行内的相邻列的局部移位。 这意味着在下降之前，状态可能会向左或向右转移一次。 
4. 应用传送带调整后，反向应用边界规则。 行边界的位置$r$对应于行中的移位条目$r+1$，因此当向后拉时，边界列将可达性分配到相邻的内部位置。 
5. 组合这些转换来计算 row 的新布尔数组$r$。 如果行中有任何有效的前任，则每个位置都标记为可达$r+1$可以到达出口。 
6. 重复直到到达顶行。 生成的布尔数组直接回答哪些起始位置成功。 

关键的想法是每一行仅在本地修改结构。 每个传送带仅影响一个单元，因此它们仅引入邻接的局部变化，并且边界规则是统一的。 这可以防止每行进行全局重新计算。 

### 为什么它有效

 在解决传送带和边界效应之后，每个单元格都有一个到下一行的正向过渡。 这使得系统成为一个分层有向图，其中每个节点的出度均为一。 当我们从下往上计算可达性时，我们实际上是在重复应用这些确定性转换的情况下有效地计算最终映射到终端节点的节点集。 由于行之间的每个转换都完全由局部规则捕获，因此反向传播可以保留每一层的正确性，而不会出现歧义或分支爆炸。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())

        # store conveyors per row
        left = {}
        right = {}

        for _ in range(m):
            r, c, d = input().split()
            r = int(r)
            c = int(c)
            if d == 'L':
                left[(r, c)] = 1
            else:
                right[(r, c)] = 1

        # dp over rows, bottom starts with single position
        # row i has length 2*(n-i)+1, but we only track reachable set
        cur = set([1])  # bottom row

        for r in range(n - 1, 0, -1):
            length = 2 * (n - r + 1) - 1
            new = set()

            # expand each reachable position upward
            for c in cur:
                # reverse boundary effect
                if c == 1:
                    nc = 2
                    new.add(nc)
                elif c == length:
                    nc = length - 1
                    new.add(nc)
                else:
                    new.add(c)

            # apply conveyors inversely
            final = set()
            for c in new:
                if (r, c) in left:
                    final.add(c - 1)
                elif (r, c) in right:
                    final.add(c + 1)
                else:
                    final.add(c)

            cur = final

        # top row size is 2n-1
        ans = ['0'] * (2 * n - 1)
        for c in cur:
            if 1 <= c <= 2 * n - 1:
                ans[c - 1] = '1'

        print(''.join(ans))

if __name__ == "__main__":
    solve()
```该解决方案为每行维护一组可到达的位置。 底行用其单个出口单元初始化。 然后，我们逐行向上传播可达性，首先消除边界效应，然后应用传送带逆。 最终组对应于顶行中的有效起始位置。 

必须注意行长度，因为每行都有不同数量的单元格。 的计算`length`确保边界行为在每个级别都得到正确应用。 

## 工作示例

 考虑一个小案例$n = 3$，其中底行有一个单元格，顶行有五个单元格。 

假设第 2 排有一个传送带从中间的单元格向右推动。 

我们跟踪可达到的职位：

 | 行| 当前可达集 | 边界反转后| 输送机后|
 | ---| ---| ---| ---|
 | 3 | {1} | {1} | {1} |
 | 2 | {1} | {2} | {3} |
 | 1 | {3} | {3} | {3, 4 取决于结构} |

 这显示了单个传送带如何向上移动可到达区域并传播到多个顶部位置。 

现在考虑一个没有传送带的情况$n = 4$。 由于仅应用边界反射，可达状态保持居中且对称。 可达集稳定在顶行中的单列，这表明在没有扰动的情况下确定性崩溃。

 ## 边缘情况

 关键的边缘情况是当可达状态恰好位于边界处并通过多行重复向上反射时。 在这种情况下，幼稚的实现可能会错误地将其保持固定，而不是在相邻位置之间交替。 

例如，与$n = 3$并且没有传送带，从底部单元开始，向上传播在位置之间交替$1$和$2$由于边界反射。 该算法通过在每一层应用边界反转来解决这个问题，确保捕获而不是压平振荡。 

当输送机位于边界附近时，会出现另一种边缘情况。 如果传送带将球推入边界单元，则下一行过渡会立即应用反射，从而产生两步位移。 传播模型通过将输送机运动和边界调整分为每行不同的阶段来正确地解释这一点。
