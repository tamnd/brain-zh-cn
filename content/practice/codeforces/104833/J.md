 ## 解决方案
 ## 问题理解

 我们得到了三角形排列的细胞$n$行。 底行有一个单元格，其上方的每一行对称扩展，以便顶行包含$2n - 1$细胞。 如果我们从左到右对顶行进行索引，这些位置将充当球的可能起点。 

落入起始单元的球会确定性地移动。 从单元格开始，它总是向下移动一行，但它也会根据位置约束水平移动：如果它位于行的左边界，则在下一行强制向右移动一步，如果位于右边界，则强制向左移动一步。 否则，它会继续直线向下，而不会发生水平变化。 当球到达包含洞的单元格时，它会立即消失并且不再继续。 如果它在所有行中都幸存下来，它最终会到达单个底部单元，然后通过其下方的出口退出。 

每个测试还提供三角形中孔位置的列表。 任务是确定对于顶行中的每个起始位置，从该位置开始的球是否在没有击中任何洞的情况下到达出口。 

约束条件很大：最多$10^4$测试用例，总计$n$最多$10^5$总孔数达到$2 \cdot 10^5$。 这立即排除了独立模拟每个起始位置的可能性。 简单的模拟会花费$O(n^2)$每次测试，这将远远超出限制。 

一个微妙的边缘情况来自靠近顶排的孔。 贪婪或逐行独立推理失败，因为每个起始位置的路径通过确定性弹跳行为全局耦合。 

例如，考虑一个小三角形，其中一个孔阻挡了底部附近的中央走廊。 两个相邻的起始位置可能共享其路径的长前缀，并且仅在末端附近发散，因此独立处理它们或单独重新计算路径会导致重复工作并可能导致 TLE。 另一个边缘情况是，当孔过早消除整个“通道”时，使许多起始位置相等，这种简单的方法仍然会单独重新计算。 

## 方法

 一种直接的方法是独立模拟每个起始位置。 从顶部单元格开始，我们模拟其向下的路径，在每一行应用左右边界反射并检查是否碰到了洞。 每次模拟费用$O(n)$，并且有$2n - 1$起始位置，所以单个测试是$O(n^2)$。 和$n$最多$10^5$总的来说，这是完全不可行的。 

关键的观察是行中的每个单元格$r$确定性地映射到行中的一个单元格$r+1$。 这意味着该结构不是分支图，而是逐层的功能图。 每个位置都有一个独特的后继者，因此来自不同起点的路径合并并向下形成不相交的“流线”。 

我们不是从上往下模拟，而是颠倒视角。 底部单元确定它是“安全”（通向出口）还是“阻塞”（它是一个洞或通向下面的洞）。 如果我们向上传播此信息，每个单元的安全性仅取决于其下一行中的单个子单元。 这将问题转换为网格上自下而上的动态规划，其中每个单元的出度为 1。 

边界反射是唯一的复杂因素。 这意味着水平映射不是线性的，但它仍然是固定的和确定性的：每个单元格在下面的行中都有唯一确定的下一个位置。 因此，我们可以为每个单元预先计算其下一个单元索引，然后从下到上运行反向DP。 

一旦我们知道哪个底部单元通向出口，我们就会向上传播“善良”：如果一个单元不是一个洞，那么它就是好的，并且它的下一个单元也是好的。 最后，我们读出顶行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$每次测试|$O(1)$额外 | 太慢了|
 | 最佳DP |$O(n + m)$每次测试|$O(n)$| 已接受 |

 ## 算法演练

 我们将三角形建模为有向分层图，其中每个单元格恰好指向下一行中的一个单元格。 

1. 我们首先表示哈希集或布尔数组中的所有漏洞$(r, c)$。 这允许恒定时间检查单元是否阻塞。 
2.对于每一行，我们确定与列的映射$c$在行中$r$到行中的一列$r+1$。 这种映射直接遵循几何形状：内部单元直接向下映射，而边界单元在向下之前向内移动。 这确保每个节点都有一个确切的传出边缘。 
3.我们定义一个DP数组`good[r][c]`意思是是否从单元格开始$(r,c)$最终到达出口而没有撞到洞。 
4. 初始化底行。 如果单个底部单元格不是一个洞，那么它就很好，因为到达它意味着立即退出。 
5. 从下到上处理行。 对于每个细胞来说，如果有一个洞，它就会立即损坏。 否则，当下面行中的唯一子单元格良好时，它就是良好的。 这是可行的，因为该过程是确定性的并且没有替代的转换。 
6. 填写DP后，通过阅读获得测试用例的答案`good[1][c]`对于所有有效的顶行位置。 

关键的不变量是`good[r][c]`正确表示从该单元格出口的可达性，假设行的正确性$r+1$。 由于每个单元格都会转换到下面的一个单元格，因此不会丢失任何情况：所有未来的行为完全由子状态捕获。 边界规则仅影响选择哪个孩子，而不是确切存在一个孩子这一事实。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())

        # total width is 2n - 1, but row r has 2r - 1 cells from bottom symmetry
        # we index rows 1..n, and each row r has 2*r - 1 cells

        holes = set()
        for _ in range(m):
            r, c = map(int, input().split())
            holes.add((r, c))

        # dp for current row
        # we build from bottom up
        dp = []

        # bottom row has 1 cell
        # dp[r][c] conceptually, but we compress per row
        dp_prev = [False] * (2 * n + 5)

        # bottom row (r = n, 1 cell at c=1)
        dp_prev[1] = (n, 1) not in holes

        # precompute row widths
        for r in range(n - 1, 0, -1):
            width = 2 * r - 1
            dp_curr = [False] * (2 * r + 5)

            for c in range(1, width + 1):
                if (r, c) in holes:
                    dp_curr[c] = False
                else:
                    # determine child position in row r+1
                    # geometry: center alignment implies shift by +1 except boundaries
                    if c == 1:
                        nc = 1
                    elif c == width:
                        nc = 2 * (r + 1) - 1
                    else:
                        nc = c + 1

                    dp_curr[c] = dp_prev[nc]

            dp_prev = dp_curr

        ans = []
        for c in range(1, 2 * n):
            ans.append('1' if dp_prev[c] else '0')

        print(''.join(ans))

if __name__ == "__main__":
    solve()
```代码中的核心思想是自下而上的传播。`dp_prev`总是代表原始三角形中的下一行，我们计算`dp_curr`使用已经计算的结果来获取当前行。 唯一微妙的部分是映射`nc`，编码球从行的确定性运动$r$到$r+1$。 一旦映射正确，剩下的就是一个简单的依赖链。 

边界处理是潜在错误的主要来源。 最左边和最右边的电池必须正确夹紧； 否则路径结构会中断并产生无效的转换。 另一个微妙之处是确保行宽度的计算一致为$2r - 1$，否则索引会漂移并且 DP 会错位。

 ## 边缘情况

 一个关键的边缘情况是当一个洞被放置在一个单元格中时，许多顶部位置都会流入其中。 在这种配置中，单个 DP 单元变为 false，并且该值通过所有依赖状态向上传播。 该算法自然地处理这一问题，因为每个状态仅依赖于一个子状态，因此单个故障会确定性地向上传播，而无需额外处理。 

另一种边缘情况是空穴占据边界单元时。 由于边界过渡向内夹紧方向，因此边缘处的孔可能会影响比直觉暗示的更大或更小的区域。 DP 仍然可以正确处理它，因为边界映射是直接在转换规则中编码的，因此除了正确的索引之外不需要特殊情况的推理。 

最后，底部单元被阻塞是全局故障条件。 由于每条路径都必须在那里结束，因此将其正确标记为不可达会强制其上方的每个 DP 状态通过相同的递归变为 false。
