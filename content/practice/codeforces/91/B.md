 ## 解决方案
 ## 问题理解

 我们有一个海象队列，其中索引顺序从尾部到头部。 对于该位置的每只海象`i`，我们想要找到最远的位置`j > i`这样前面的海象就更年轻了，这意味着`a[j] < a[i]`。 

如果不存在这样的海象，答案是`-1`。 

如果存在这样的海象，则不悦等于站在它们之间的海象数量，即：$$j - i - 1$$关键细节是我们不想要最近的年轻海象。 我们希望队列中最年轻的海象排在前面。 

队列长度可达`10^5`，所以二次解太慢。 一个简单的双循环会检查所有对`(i, j)`和`i < j`，大致变成`10^10`最坏情况下的操作。 这远远超出了 2 秒的限制。 我们周围需要一些东西`O(n log n)`或者`O(n)`。 

一些边缘情况很容易被错误处理。 

考虑年龄相同：```
4
5 5 5 5
```正确的输出是：```
-1 -1 -1 -1
```粗心的实现使用`<=`而不是`<`会错误地将同等年龄视为更年轻。 

另一个微妙的情况是，最远的年轻海象不是附近的最小值：```
5
10 9 8 7 6
```答案是：```
3 2 1 0 -1
```对于第一只海象，正确的选择是有年龄的海象`6`，不是第一只年龄较小的海象`9`。 

当年轻的海象仅在较大的值之后才存在时，会出现一种更棘手的情况：```
6
5 100 99 98 1 2
```对于年龄`100`，最年轻的海象是`2`最后，不是`1`。 答案取决于最远的有效指数，而不是最小年龄。 

## 方法

 暴力解法直接遵循定义。 对于每个职位`i`，扫描后面的每个位置`j > i`。 每当`a[j] < a[i]`，使用最远的索引更新答案。 

这是有效的，因为它明确地检查每个候选人。 逻辑简单且正确。 

问题是运行时间。 和`n = 10^5`，嵌套循环执行以下操作：$$\frac{n(n-1)}{2} \approx 5 \times 10^9$$最坏情况下的比较。 这太慢了。 

重要的观察是，我们只关心对于左边的人来说可能成为最年轻海象的位置。 

假设我们从右到左处理数组。 在向左移动时，我们维护一个包含后缀候选位置的结构。 

仅当某个位置的年龄小于最右侧看到的每个年龄时，该位置才有用。 这些位置形成了严格递减的年龄序列。 例如：```
10 8 5 3 50 45
```从右向左扫描产生候选最小值：```
45 at index 5
3 at index 3
```所有其他值都是无用的，因为更右边已经存在一个更小的值。 

现在考虑一些随着年龄增长的海象`x`。 在这些后缀最小值中，我们想要年龄小于的最远索引`x`。 

按存储顺序查看时，候选年龄严格递增，因此我们可以二分查找最后一个值`< x`。 

这将问题简化为：

 1. 从右向左扫描时建立后缀最小位置。 
2. 使用二分查找找到最年轻的海象。 

总复杂度变为`O(n log n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 创建一个名为的空列表`mins`。 

该列表将存储对`(age, index)`代表从右向左扫描时发现的后缀最小值。 
2. 从最后一个位置向第一个位置开始处理数组。 

在每一步中，已处理的位置都属于当前海象之前的后缀。 
3.针对当前年龄`a[i]`，内部二分查找`mins`。 

我们希望最右边的存储年龄严格小于`a[i]`。 由于内部储存的年龄不断增加`mins`，二分查找工作正常。 
4. 如果存在这样的元素，则计算不高兴度。 

假设匹配的存储位置是`j`。 答案是：$$j - i - 1$$5. 如果不存在更小的年龄`mins`， 店铺`-1`。 

这意味着前方没有更年轻的海象。 
6. 回答职位后`i`,决定是否将当前海象插入`mins`。 

仅当其年龄小于最后存储的最小值时才插入它。 在这种情况下，它会成为新的后缀最小值，并可能有助于未来的职位。 
7. 不需要逆序，因为答案直接写入结果数组中。 

### 为什么它有效

 关键的不变量是`mins`始终包含当前索引右侧位置的后缀最小值。 

如果某个位置不是后缀最小值，则某个更远的位置的年龄甚至更小。 越远的位置总是越好，因为问题需要最远的年轻海象。 

因此，每个非最小位置都可以安全地丢弃。 

储存的年龄严格增加`mins`，因为只有在从右到左扫描期间出现严格较小的值时，我们才会追加新元素。 该排序允许二分搜索。 

当我们二分查找最右边的年龄小于`a[i]`，我们获得了比当前海象更年轻的最远后缀最小值。 由于每个有用的候选者都必须是后缀最小值，因此这个位置正是正确的答案。 

## Python 解决方案```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = [-1] * n

    # stores (age, index)
    # ages are strictly increasing
    mins = []

    for i in range(n - 1, -1, -1):
        age = a[i]

        # find first age >= current age
        pos = bisect_left(mins, (age, -1))

        # elements before pos have smaller age
        if pos > 0:
            j = mins[pos - 1][1]
            ans[i] = j - i - 1

        # add new suffix minimum
        if not mins or age < mins[-1][0]:
            mins.append((age, i))

    print(*ans)

if __name__ == "__main__":
    solve()
```该解决方案从右到左扫描，因为每只海象只关心他前面的人。 在位置`i`, 后缀`[i+1 ... n-1]`已经被处理了。 

这`mins`数组以特殊顺序存储后缀最小值。 年龄在严格增加，而指数也在增加，因为我们向后看。 这种顺序使得二分查找成为可能。 

通话：```
bisect_left(mins, (age, -1))
```找到第一个存储的年龄至少为`age`。 该位置之前的所有内容的年龄都严格较小，这正是我们所需要的。 

最右边的较小元素给出了最远的有效海象。 自从`mins`包含按距离增加排序的后缀最小值，选择最后一个较小的元素会自动给出最大的索引。 

一个微妙的细节是插入条件：```
if not mins or age < mins[-1][0]:
```使用`<`而不是`<=`很重要。 同等年龄并不意味着更年轻，因此同等值不能成为新的后缀最小值。 

另一个容易犯的错误是不满公式。 该问题要求的是两个位置之间的海象数量，而不是距离本身。 这就是为什么我们计算：```
j - i - 1
```而不是`j - i`。

from bisect import bisect_left

def solve():

    n = int(input())
    a = list(map(int, input().split()))

    mins = []

    for i in range(n - 1, -1, -1):

    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample

 ## 边缘情况

 考虑所有相同的年龄：```
4
5 5 5 5
```从右向左扫描时，该结构最少只存储一个后缀`(5,3)`。 每个二分查找都要求严格小于`5`，但不存在。 该算法输出：```
-1 -1 -1 -1
```这个案例证实了同等年龄的处理是正确的。 

现在考虑一个严格递减序列：```
5
9 8 7 6 5
```除最后一头海象外，每头海象前面都有更年轻的海象。 最年轻的海象总是排在最后。 

答案变成：```
3 2 1 0 -1
```该算法成功是因为后缀最小值不断减小：```
(5,4), (6,3), (7,2), ...
```二分查找总是选择最远的有效索引。 

最后，考虑一个最小的年轻海象不是正确答案的情况：```
6
5 100 99 98 1 2
```对于随着年龄增长的海象`100`， 两个都`1`和`2`更年轻。 该问题要求最年轻的海象，即`2`在最后。 

不高兴的是：```
5 - 1 - 1 = 3
```后缀最小结构以距离递增的顺序存储位置，因此二分查找自然会选择最远的有效位置而不是最小的年龄。
