 ## 解决方案
 ## 问题理解

 我们得到了罐子的排列。 罐`i`终于应该站​​稳立场`i`，但目前的安排已被打乱。 

一项操作允许我们选择最多五个位置的任何子集，并任意排列这些位置内的 jar。 这些位置不需要是连续的。 任务不仅是对排列进行排序，而且是使用尽可能少的操作数来完成此操作，同时打印操作本身。 

有趣的是，一项操作的功能极其强大。 如果我们选择五个位置，我们可以在一次移动中对这五个罐子应用任何排列。 这意味着问题不在于模拟或本地交换。 这是关于了解每次手术可以消除多少混乱。 

输入大小达到`10^5`，因此任何搜索状态或尝试使用指数技术进行全局优化的方法都是不可能的。 甚至一个`O(n^2)`算法在 2 秒限制下是危险的。 我们需要接近线性时间的东西。 

排列结构立即暗示了循环分解。 每个排列都可以分成独立的循环，固定一个循环不会影响另一个循环。 由于一次操作最多可以任意重新排列五个选定的元素，因此自然的问题就变成了：一次可以修复多少个循环？ 

有几种边缘情况很容易破坏粗心的实现。 

一个周期的长度`1`已经是正确的并且必须被忽略。 例如：```
1
1
```答案是`0`。 盲目地将每个索引作为循环的一部分处理的有缺陷的实现可能会产生不必要的操作。 

最多长度的周期`5`可以通过一次操作来修复。 例如：```
5
2 3 4 5 1
```这是单个 5 周期。 我们选择所有五个位置并一步将它们旋转到正确的顺序。 

长周期是棘手的部分。 考虑：```
8
2 3 4 5 6 7 8 1
```这是一个周期的长度`8`。 一个天真的贪婪者独立地重复修复五个位置可能会意外地破坏已经正确的位置或使用太多操作。 最佳分解需要仔细地将循环分成多个块。 

另一个微妙的情况出现在长度周期上`6`。 由于我们最多只能操纵五个位置，因此不可能进行一次操作。 但两个操作就足够了：```
6
2 3 4 5 6 1
```假设每个周期都需要的解决方案`ceil(len / 5)`操作给出`2`，这里是正确的，但实际的构建很重要。 我们必须产生有效的运算，其组合对排列进行排序。 

问题最难的部分不是计数本身，而是构建精确达到最小值的操作。 

## 方法

 蛮力观点是直接思考排列的运算。 在每一步中，我们最多选择五个位置并进行一些重新排列。 由于大约有`O(n^5)`可能的子集以及每个子集的许多排列，分支因子立即爆炸。 即使是为了`n = 20`，这已经是无药可救了。 

一个稍微聪明的蛮力想法是独立处理循环。 假设一个循环有长度`k`。 由于一次操作最多可以重新排列五个位置，因此也许我们可以一次贪婪地修复最多五个放错位置的元素。 这在功能上有效，但不是最佳的。 长周期的不小心分解可能会浪费运营。 

关键的观察是一次操作可以完全解决任何长度最多为 5 的循环。 

走一个循环：```
(a1 -> a2 -> a3 -> ... -> ak -> a1)
```如果`k <= 5`，选择所有循环位置使我们能够一次性将每个罐子直接发送到正确的位置。 

这完全改变了问题。 我们不需要考虑任意排列，而只需要了解如何将长循环分解为更小的循环，每个循环都适合一个操作。 

假设一个循环有长度`k > 5`。 

对五个元素的一次操作可以将循环长度减少四倍。 原因是我们可以永久修复四个元素，而将其余元素保留在较小的循环内。 

例如，从长度的循环`8`：```
(1 2 3 4 5 6 7 8)
```我们可以提取一个 5 周期，涉及：```
(1 2 3 4 5)
```适当修复这些之后，剩下的无序就变成了一个长度的循环`4`。 

由此得出最优公式：```
operations = ceil((k - 1) / 4)
```因为每次操作最多可以消除一个周期中四个独立的错位。 

剩下的挑战是建设性的。 我们需要一种系统的方法来分割周期并打印有效的操作。 

标准技巧是递归归约。 虽然周期长度超过`5`，我们从循环中取出五个连续的顶点，应用一个操作来修复其中的四个，然后继续使用较小的残差循环。 

当剩余周期长度最多变为`5`，最后一项操作解决了这个问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取排列并将其分解为不相交的循环。 

我们维护一个访问过的数组。 从每一个未曾到过的位置开始，我们反复追踪`p[i]`直到回到起点。 
2. 忽略长度周期`1`。 

这些位置已经是正确的，不需要出现在任何操作中。 
3.对于每个长度最大的循环`5`，一次操作即可解决。 

假设循环是：```
c0 -> c1 -> c2 -> ... -> ck-1 -> c0
```我们选择这些位置并向后旋转罐子，以便每个罐子都移动到正确的位置。 
4. 对于周期长于`5`，在五个位置上重复提取操作。 

设当前周期为：```
[v0, v1, v2, ..., vm-1]
```我们采取：```
[v0, v1, v2, v3, v4]
```并执行修复操作`v1, v2, v3, v4`。 

经过此操作，剩余周期变为：```
[v0, v5, v6, ..., vm-1]
```所以它的长度减少了四。 
5. 继续，直到剩余周期长度变为最多`5`。 
6. 通过一次运算解决最后一个小循环。 
7. 打印所有操作。 

### 为什么它有效

 不变的是每个未完成的组件始终保持单个周期。 

对五个元素的每次操作都会从该循环中永久删除四个顶点。 这些顶点将永远固定并且不再参与。 

一个周期的长度`k`至少需要`ceil((k - 1) / 4)`操作，因为一项操作最多可以涉及五个元素，这意味着最多有四个新位置可以变得正确。 该算法通过每次将周期缩小四次来精确地实现这一界限。 

由于循环是独立的，因此最优地求解每个循环也会给出全局最优解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = [0] + list(map(int, input().split()))

    vis = [False] * (n + 1)
    ops = []

    def apply_cycle(cyc):
        k = len(cyc)

        pos = cyc
        target = cyc[1:] + cyc[:1]

        ops.append((k, pos[:], target[:]))

    for i in range(1, n + 1):
        if vis[i]:
            continue

        cur = []
        x = i

        while not vis[x]:
            vis[x] = True
            cur.append(x)
            x = p[x]

        m = len(cur)

        if m == 1:
            continue

        while m > 5:
            part = cur[:5]

            apply_cycle(part)

            cur = [cur[0]] + cur[5:]
            m = len(cur)

        apply_cycle(cur)

    print(len(ops))

    for k, b, c in ops:
        print(k)
        print(*b)
        print(*c)

if __name__ == "__main__":
    solve()
```第一部分使用排列边上的标准 DFS 式遍历将排列分解为循环。 每个索引都被访问一次，因此该部分是线性的。 

帮手`apply_cycle`将一个周期直接转换为一台机器操作。 假设循环是：```
[a, b, c, d]
```现在：```
p[a] = b
p[b] = c
p[c] = d
p[d] = a
```操作图：```
a -> b
b -> c
c -> d
d -> a
```它将每个罐子发送到正确的位置。 

最微妙的部分是缩小大周期。 获取前五个顶点后，该操作将永久修复其中四个顶点，同时第一个顶点仍与循环的其余部分保持连接。 更换：```
[v0, v1, v2, v3, v4, v5, ...]
```和：```
[v0, v5, ...]
```保留剩余的循环结构。 

一个常见的实施错误是反转映射的方向。 该语句将操作定义为“从位置 jar`bi`转到位置`ci`”。对于一个周期，我们必须将位置向前移动一次。

 另一个简单的错误是在后续操作中意外地包含已经固定的顶点。 收缩过程会自动避免这种情况，因为删除的顶点再也不会出现。

import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    p = [0] + list(map(int, input().split()))

    vis = [False] * (n + 1)
    ops = []

    def apply_cycle(cyc):
        k = len(cyc)

        pos = cyc
        target = cyc[1:] + cyc[:1]

        ops.append((k, pos[:], target[:]))

    for i in range(1, n + 1):
        if vis[i]:
            continue

        cur = []
        x = i

        while not vis[x]:
            vis[x] = True
            cur.append(x)
            x = p[x]

        if len(cur) == 1:
            continue

        while len(cur) > 5:
            ops.append((5, cur[:5], cur[1:5] + [cur[0]]))
            cur = [cur[0]] + cur[5:]

        apply_cycle(cur)

    out = [str(len(ops))]

    for k, b, c in ops:
        out.append(str(k))
        out.append(" ".join(map(str, b)))
        out.append(" ".join(map(str, c)))

    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

 ## 边缘情况

 考虑已经排序的排列：```
4
1 2 3 4
```每个周期都有长度`1`。 遍历访问每个节点，立即发现自环，并跳过它。 不添加任何操作。 输出正确：```
0
```现在考虑最小的非平凡循环：```
2
2 1
```循环是：```
(1 2)
```该算法应用一项操作：```
positions: 1 2
targets:   2 1
```罐子位置`1`移动到`2`，和罐子`2`移动到`1`。 排列立即排序。 

对于长周期：```
9
2 3 4 5 6 7 8 9 1
```循环分解给出：```
(1 2 3 4 5 6 7 8 9)
```该算法首先处理：```
[1 2 3 4 5]
```离开：```
[1 6 7 8 9]
```剩余周期现在有长度`5`，因此最后一项操作即可解决该问题。 总业务：```
2
```与下限匹配：```
ceil((9 - 1) / 4) = 2
```最后，考虑多个独立循环：```
7
2 1 4 3 6 7 5
```分解为：```
(1 2)
(3 4)
(5 6 7)
```每个循环在一次操作中独立求解。 这些操作不会干扰另一个循环，因为循环占据不相交的位置。
