 ## 解决方案
 ## 问题理解

 我们被要求找到可以包含两个相同大小的矩形的最小正方形$a \times b$。 矩形可以旋转、移动，并且必须完全保持在正方形内，且边与正方形平行。 输入为我们提供了多个测试用例，每个测试用例指定$a$和$b$，我们期望输出每种情况的最小正方形的面积。 

限制很小：$1 \le a, b \le 100$以及多达 10,000 个测试用例。 每个测试用例都是独立的，因此我们需要一种算法来在恒定时间内计算单个矩形对的最小平方。 由于矩形的最大可能边长为 100，因此正方形的最大边长为 200。任何在每个测试用例中以恒定时间检查所有配置的解决方案都将在时间限制内轻松运行。 

一个不明显的边缘情况是当矩形几乎是正方形时，例如$a=7, b=8$。 如果我们天真地尝试将两个矩形并排放置而不旋转，我们可能会高估正方形的大小。 另一个微妙的情况是$a = b$，其中旋转不会改变任何东西。 非常小的矩形，例如$a = b = 1$，说明如果两条边必须沿着同一轴对齐，即使是最简单的矩形也必须考虑将一条边加倍。 

## 方法

 蛮力方法是考虑将两个矩形放置在尺寸不断增大的正方形内的所有可能位置。 我们可以从矩形的较大边开始，增加正方形边，直到配置合适。 这是正确的但不必要的，因为约束允许我们进行数学推理。 在最坏的情况下，最大正方形边长为200，因此运算次数仍然可以接受，但比较繁琐。 

关键的见解是要认识到，最小正方形的边长等于矩形较大边的两倍，或者如果并排放置它们会产生更长的边，则等于两条边的总和。 更正式地说，如果我们取最大值$a$和$b$，称之为$M$，最小正方形边是$2M$如果我们沿着矩形的最大尺寸放置矩形，或者如果我们旋转以优化边的总和。 在代数上，最小平方边可以计算为$\max(2 \cdot \min(a,b), \max(a,b))$。 此公式涵盖所有放置位置：并排或堆叠，并考虑旋转。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每次测试 O(200*200) | O(1) | O(1) | 有效但没有必要 |
 | 最佳 | 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个有边的矩形$a$和$b$，计算长边和短边。 让`longer = max(a, b)`和`shorter = min(a, b)`。 这确保我们始终如一地处理轮换。 
2. 计算适合两个矩形所需的最小正方形边。 将它们沿着短边并排放置：将短边加倍即可得到`2 * shorter`。 将其与较长的边进行比较，因为正方形也必须沿着另一个维度适合。 取最大值：`square_side = max(2 * shorter, longer)`。 这保证了无论方向如何，正方形都可以适合两个矩形。 
3. 计算正方形的面积：`area = square_side ** 2`。 
4. 打印每个测试用例的面积。 

为什么它有效：我们考虑两种可能性：将矩形沿着其较长的边堆叠放置，或沿着其较短的边并排放置。 通过取最大值`2 * shorter`和`longer`，我们涵盖了这两种可能性，并确保正方形足够大，永远不会太小，永远不会不必要地大。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    longer = max(a, b)
    shorter = min(a, b)
    square_side = max(2 * shorter, longer)
    print(square_side * square_side)
```代码首先读取测试用例的数量。 对于每对边，它计算哪边较长、哪边较短以处理旋转。 然后计算最小正方形边并打印其面积。 使用`max(2 * shorter, longer)`很微妙，但确保方形边占两个矩形的最佳放置位置。 该解决方案避免了循环和不必要的检查，从而使每个测试用例的时间恒定。

 ## 边缘情况

 用于输入`1 1`，算法计算`longer = 1`,`shorter = 1`,`square_side = max(2*1, 1) = 2`，和面积`4`。 这可以正确处理最小的矩形。 

用于输入`100 1`，算法计算`longer = 100`,`shorter = 1`,`square_side = max(2*1, 100) = 100`， 区域`10000`。 它正确地选择较大的边作为正方形长度，而不是将较小的边加倍。
