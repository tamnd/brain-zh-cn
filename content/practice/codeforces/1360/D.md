 ## 解决方案

 ## 问题理解

 波利卡普想要准确地获得$n$铲子，但他不能混合不同的包装尺寸。 本店提供各种尺寸的套餐$1$通过$k$，一旦他选择了包裹尺寸$i$，每次购买的尺寸必须相同。 任务是选择最佳的包装尺寸，然后购买尽可能少的包装，使得铲子的总数恰好是$n$。 

换句话说，对于每个有效的包裹尺寸$i$，我们可以代表$n$作为相同项的总和$i + i + \dots + i$。 这只有在以下情况下才有可能：$i$划分$n$，在这种情况下，包的数量是$n / i$。 目标是最小化这个值$i \le k$那个鸿沟$n$。 

约束允许最多$10^9$对于两者$n$和$k$，最多有 100 个测试用例。 这排除了迭代所有包大小的任何方法$k$每个测试用例，因为这需要最多$10^11$最坏情况下的操作。 

天真的错误来自于尝试一切$i$从$1$到$k$。 例如，如果$n = 10^9$和$k = 10^9$，在时间限制内迭代所有候选者是不可能的。 

另一个微妙的边缘情况出现时$k \ge n$。 在这种情况下，选择$i = n$被允许并给出答案$1$。 一种粗心的方法，只检查除数$n$但忽略上限约束可能会错过这条捷径。 

## 方法

 蛮力的想法很简单：尝试每个包大小$i$从$1$到$k$，检查是否$i$划分$n$，并计算$n / i$。 答案是所有有效选择中的最小值。 这是正确的，因为它明确评估每个允许的配置。 

然而，这种方法执行$O(k)$每个测试用例的检查。 和$k$最多$10^9$，即使对于单个测试用例，这也是不可行的。 

关键的观察是我们不需要搜索所有值$i$。 最佳答案对应于$i$尽可能大，同时仍然分裂$n$，因为答案是$n / i$。 因此，我们想要最大的除数$n$不超过$k$。 

如果$k \ge n$，我们可以直接选取$i = n$，给出答案$1$。 否则，我们将自己限制为$n$最多是$k$。 最大的此类除数是在附近找到的大除数$\sqrt{n}$或除数与小补数配对。 

我们可以迭代所有的除数$n$最多$\sqrt{n}$，这是有效的，因为任何除数对$(d, n/d)$包含一个小值和一个大值。 我们跟踪不超过的最大有效除数$k$，并计算$n$除以它。 

这减少了扫描所有候选者的问题$k$最多只扫描$\sqrt{n}$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(k)$每次测试|$O(1)$| 太慢了 |
 | 最佳 |$O(\sqrt{n})$每次测试|$O(1)$| 已接受 |

 ## 算法演练

 1.如果$k \ge n$，立即返回$1$，因为选择封装尺寸$n$有效并使用单个包。 这是全局最小可能答案。 
2. 否则，将答案初始化为$n$，对应于最差的有效选择$i = 1$。 
3. 迭代所有整数$d$从$1$到$\lfloor \sqrt{n} \rfloor$。 每个$d$代表潜在的除数候选者。 
4.如果$d$划分$n$，同时考虑$d$和$n / d$作为有效的包装尺寸。 
5. 对于每个有效除数候选者$i$，检查是否$i \le k$。 如果是这样，请将答案更新为$\min(\text{answer}, n / i)$。 此步骤是合理的，因为选择封装尺寸$i$恰好导致$n / i$包。 
6. 检查所有除数对后，输出找到的最佳答案。 

### 为什么它有效

 每个有效的解决方案都对应于选择一个除数$i$的$n$和$i \le k$。 该算法枚举了所有的约数$n$，所以它不会错过任何可行的选择。 对于每个候选者，它计算所需的确切包数。 由于目标是最小化$n / i$, 最大化$i$约束下$i \mid n$和$i \le k$，保证最佳候选者位于枚举除数之中。 这确保了正确性，无需扫描非因数或以上值$\sqrt{n}$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        if k >= n:
            print(1)
            continue

        ans = n

        r = int(math.isqrt(n))
        for d in range(1, r + 1):
            if n % d == 0:
                if d <= k:
                    ans = min(ans, n // d)
                other = n // d
                if other <= k:
                    ans = min(ans, n // other)

        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先处理可能存在单个包的琐碎最佳情况。 除数循环确保检查所有候选包大小而不超过$\sqrt{n}$复杂。 每个除数对都经过仔细处理，检查两个元素，因为只有一个元素可能在限制范围内$k$。 

一个常见的实施陷阱是忘记检查两者$d$和$n/d$，这会错过有效的大除数。 另一个不处理$k \ge n$捷径，否则仍然有效，但可能会浪费时间或使逻辑不必要地复杂化。

 ## 边缘情况

 当$n = 1$，唯一可能的包大小是 1，因此无论大小如何，答案始终为 1$k$。 该算法立即处理这个问题，因为$k \ge n$或者因为除数循环包括$d = 1$，产生答案$1 / 1 = 1$。 

什么时候$k \ge n$， 例如$n = 50, k = 100$，算法触发提前返回。 这避免了不必要的除数计算，并直接产生最佳的单包解决方案。 

什么时候$n$是素数并且$k < n$， 例如$n = 999999733, k = 10$，唯一不超过的除数$k$是 1。循环找不到更大的有效除数，所以答案仍然存在$n$，对应于购买$n$包装尺寸 1。
