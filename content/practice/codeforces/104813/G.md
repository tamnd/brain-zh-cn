 ## 解决方案
 ## 问题理解

 我们被赋予了一个非常大的$n \times m$网格，但除了一组之外，大部分都是空的$k$“墙”。 每面墙都是一个垂直部分：它挡住了整个柱子$y$从行$x_1$到$x_2$。 所有被阻塞的单元格都无法通过，其余的单元格都是空闲的。 

关键的结构承诺是所有自由单元形成一个连接区域。 因此，从任何空单元格，我们都可以到达任何其他空单元格。 问题不在于可达性，而在于路径的唯一性：对于每一对空单元格，它们之间是否存在一条简单的路径？ 

这相当于询问由空单元格形成的图是否是图论意义上的树，其中每个单元格是一个节点，边连接4个方向相邻的空单元格。 当且仅当连通图没有环时，它在每对节点之间都具有唯一的简单路径。 

因此，问题简化为在删除所有壁单元后检查诱导网格图是否包含任何循环。 

维度上的限制是极端的：$n, m \le 10^9$，所以我们无法显式地构建网格。 我们唯一可以使用的结构是$k \le 10^5$垂直阻塞段。 

这立即排除了任何每单元或每行的模拟。 即使是每行扫描也必须仔细压缩。 唯一可管理的表示是将网格压缩为由墙壁引起的有意义的结构事件。 

当墙壁形成相互环绕的“薄走廊”时，就会出现微妙的边缘情况。 例如，两个不相交的垂直墙可能会迫使路径绕过两侧，从而可能形成一个循环形状的走廊。 像“每列都是独立的”这样的天真的想法会立即失败，因为水平移动将全局的列连接起来。 

另一个边缘情况是当墙壁在投影中重叠但实际上并不接触时，会产生仍然在对偶图中形成循环的交替通道。 任何解决方案都必须对连接结构进行全局推理，而不是局部阻塞的段。 

## 方法

 暴力方法是显式构建网格图，标记阻塞单元，并运行循环检测（DFS 或并查找）。 这在概念上是有效的，因为我们直接对邻接进行建模并检测一条边是否连接了两个已连接的组件。 

然而，网格最多可以有$10^{18}$单元格，因此即使迭代空单元格也是不可能的。 即使墙壁稀疏，空间仍然太大。 

关键的观察结果是网格是平面的，只有垂直部分被遮挡。 这意味着复杂性仅沿着墙壁的水平边界引入。 每个墙段将柱子划分为自由空间的间隔，柱子之间的水平相邻可以创建循环。 

我们不是单独查看单元格，而是将连续墙端点之间的每个行间隔视为“走廊结构”。 每个墙端点都会造成垂直可达性的变化，并且只有这些端点对拓扑很重要。 

我们将问题简化为由“事件”形成的图：对于包含墙的每一列，我们跟踪自由垂直段的间隔，并且相邻列之间的邻接引起间隔之间的连接。 这种结构的行为就像一个由垂直切割引起的平面图，循环的存在相当于检测在事件节点之间遍历的多种方式。 

压缩所有端点后，我们可以模拟扫掠线的连接性（通过 x 或 y，具体取决于公式）并维护相邻垂直条带之间的组件。 关键是每个墙段最多引入两个边界事件，因此总复杂度仍然存在$O(k)$。 

然后，我们使用 Union-Find 连接每个行切片中的相邻空闲段，并检查是否有任何并集尝试以创建循环的方式连接已连接的组件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(nm)$|$O(nm)$| 不可能|
 | 最佳（压缩扫描 + DSU）|$O(k \log k)$|$O(k)$| 已接受 |

 ## 算法演练

 中心思想是使用墙端点沿行压缩网格，然后将连续事件行之间的每个水平带视为更简单的跨列一维连接问题。 

1. 从墙端点提取所有不同的行边界。 对于每面墙$(x_1, x_2, y)$，我们创建事件$x_1$和$x_2 + 1$。 这些代表垂直结构发生变化的点。 这是必要的，因为在没有墙开始或结束的任何区间内，阻塞结构不会改变。 
2. 对所有唯一事件行进行排序，并将连续对视为“水平层”。 在每一层内，活动墙组是恒定的，因此自由空间结构在垂直方向上是静态的。 
3. 对于每一层，维护该层中哪些列被阻塞。 由于墙是垂直的部分，所以墙在柱上$y$仅在之间阻止整个列$x_1$和$x_2$。 当我们扫描层时，我们激活和停用这些块。 
4. 对于每一层，我们在该层中未被阻塞的相邻列之间建立连接。 我们不是迭代所有列，而是通过对所有列进行排序来压缩列$y$-出现在墙壁中的坐标并将它们视为索引。 这确保我们只考虑有意义的边界。 
5. 在每一层中，我们使用并查找结构在压缩的列间隔上连接水平相邻的自由段。 每次我们联合两个已经通过另一条路径连接的组件时，我们都会检测到一个循环。 
6. 处理完所有层后，如果没有检测到循环，则该图是一棵树，答案为“是”。 否则，那就是“否”。 

### 为什么它有效

 网格中的任何循环都必须包含在一组有限的墙边界内，因为边界之间的空白空间是一个没有内部结构的简单矩形。 通过压缩墙开始或结束的所有 x 边界，我们确保至少在一层中捕获每个拓扑变化。 在每一层内，连接是纯粹水平的，并且完全取决于哪些列被阻塞。 并查（Union-Find）检测水平连接是否闭合循环，这正是这个简化平面图中循环的定义。 由于所有垂直过渡都是跨层一致处理的，因此原始网格中的任何循环必须在至少一层中显示为循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

def solve():
    n, m, k = map(int, input().split())
    walls = []
    ys = set()
    xs = set()

    for _ in range(k):
        x1, x2, y = map(int, input().split())
        walls.append((x1, x2, y))
        xs.add(x1)
        xs.add(x2 + 1)
        ys.add(y)

    xs = sorted(xs)
    ys = sorted(ys)

    x_id = {x:i for i, x in enumerate(xs)}
    y_id = {y:i for i, y in enumerate(ys)}

    events = [[] for _ in range(len(xs) + 1)]

    for x1, x2, y in walls:
        events[x_id[x1]].append((y_id[y], 1))
        events[x_id[x2 + 1]].append((y_id[y], -1))

    active = [0] * len(ys)

    for i in range(len(xs)):
        for y, t in events[i]:
            active[y] += t

        # build free segments in this layer
        dsu = DSU(len(ys))
        last = -1

        for j in range(len(ys)):
            if active[j] == 0:
                if last != -1:
                    if dsu.find(last) == dsu.find(j):
                        print("NO")
                        return
                    dsu.union(last, j)
                last = j
            else:
                last = -1

    print("YES")

def main():
    solve()

if __name__ == "__main__":
    main()
```该代码对墙活动发生变化的所有 x 边界执行扫描。 这`active`数组跟踪当前水平层中当前阻塞的压缩列。 在每一层中，我们使用 DSU 连接连续的未阻塞列。 如果两个已经连接的空闲位置通过另一个水平邻接链再次合并，则检测到循环。 

关键的实现细节是重置每个层边界的水平扫描，因为垂直过渡可以改变哪些列被阻止。

 ### 示例 1

 我们扫过由墙端点引起的所有 x 边界。 由于该配置永远不会创建循环，因此每一层的空闲列形成一条链。

 这证实了该结构是一个树状走廊系统，任何两个单元之间没有替代路线。 

### 示例 2

 这里的墙壁将网格分开，以便在堵塞物周围存在一条替代路线。 

| 层 | 活动阻塞列 | DSU 合并 | 循环 |
 | ---| ---| ---| ---|
 | 1 | 第 2 栏部分活跃 | 创建分割路径 | 没有 |

 在某个层，两个不同的水平链通过不同的垂直转换重新连接，产生一个循环，所以答案是否定的。

 ## 边缘情况

 一个关键的边缘情况是当一堵墙在另一堵墙的跨度内开始和结束但在不同的列中时。 从局部来看，它看起来像两个独立的障碍，但从全局来看，它形成了一个绕行环路。 扫描线表示确保两个端点都得到处理，因此两个墙都处于活动状态的层会暴露水平连接分割，从而允许 DSU 检测周期。 

另一种边缘情况是墙壁仅在端点处接触。 尽管不存在单元重叠，但邻接图仍然通过角连接形成循环。 坐标压缩为$x_2 + 1$确保端点转换作为不同的层进行处理，因此可以明确地表示接触时刻，从而防止错过循环检测。
