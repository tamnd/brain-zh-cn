 ## 解决方案
 ## 问题理解

 我们得到一个最多有十个顶点的小型加权无向图。 权重描述了每对行星相互作用的强度。 我们被要求在顶点上分割固定数量的质量，正好一个单位，其中每个顶点 i 接收一个非负实值 eᵢ 并且所有值总和为 1。 

这些分配的目标是二次的。 每对顶点对两种分配都按比例贡献：如果两个行星 i 和 j 收到 eᵢ 和 eⱼ，则它们对分数的贡献为 eᵢ · eⱼ · wᵢⱼ。 总分是所有无序对的总分。 

因此，我们选择顶点上的概率分布，并最大化由权重矩阵定义的二次形式。 

小约束 n ≤ 10 立即表明对子集的指数或组合推理是可行的。 任何围绕 2ⁿ 状态的方法都是可能可以接受的。 然而，变量是连续的，因此如果没有结构洞察力，对实值赋值的暴力破解是没有意义的。 

微妙的困难在于，解空间是一个单纯形，并且目标是二次的，但由于任意权重，不一定是凸或凹的。 朴素的梯度或贪婪的分裂方法很容易陷入非全局最优的局部改进中。 

一些边缘情况值得牢记。 如果所有权重都为零，则任何分布都会给出零分。 如果恰好一条边的权重很大，则最佳解决方案将质量完全集中在其端点上。 如果权重均匀，则对称性意味着平均分配是最佳的。 当权重矩阵高度倾斜时，均匀分布质量的简单启发式方法将严重失败。 

## 方法

 蛮力视角首先注意到目标仅取决于概率质量在顶点之间的分配方式。 如果允许我们测试任意连续分配，则空间是无限的，因此不可能直接确定方向。 

关键的结构思想是，在最佳状态下，分布的支持很小。 直观上，如果我们固定包含所有概率质量的 k 个顶点的子集，则它们的最优分布是维度 k − 1 的单纯形上的约束二次优化问题。对于固定子集，这变成具有线性约束的标准二次规划，可以使用拉格朗日乘子求解并简化为线性系统。 

因此策略变为：猜测哪个顶点子集具有非零能量，计算该子集上的最优分布，并在所有子集中取最佳值。 

由于 n ≤ 10，枚举所有子集是可行的。 对于每个子集，我们解决一个小的约束优化问题。 拉格朗日条件得出，对于所有有效 i，梯度条件强制形成线性关系，从而产生具有 k 个未知数（包括乘数）的 k 个方程组。 

这减少了求解许多小型线性系统的连续优化。 

对子集的强力是指数级的，但每个解都是 k 的三次方，在这里 k 很小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解分配| 无限/不可行 | O(1) | O(1) | 不可能|
 | 子集枚举+拉格朗日系统 | O(2ⁿ·n3) | O(2ⁿ·n3) | O(n²) | 已接受 |

 ## 算法演练

 ### 最优思路：枚举支持集并求解KKT系统

 我们依赖这样一个事实：最优分布在顶点的某些子集 S 上得到支持，并且在 S 上，解满足一阶最优条件。 

#### 1. 迭代顶点的所有非空子集 S

 每个子集代表一个假设，即这些顶点恰好接收正能量。 这是有效的，因为任何最优解都位于单纯形的某个面上。

#### 2. 对于固定子集 S，制定优化

 我们最大化

 E = Σ_{i<j in S} eᵢ eⱼ wᵢⱼ

 满足 Σ eᵢ = 1 且 eᵢ ≥ 0。 

我们使用对称矩阵 A 重写二次形式，其中 Aᵢⱼ = wᵢⱼ 对于 i ≠ j 且 Aᵢᵢ = 0。然后

 E = ½ eᵀ A e。 

因子 ½ 与最大化无关。 

#### 3. 应用拉格朗日乘子条件

 我们形成：

 L(e, λ) = eᵀ A e − λ(Σ eᵢ − 1)

 对 eᵢ 求导可得：

 对于 S 中的所有 i，Σⱼ Aᵢⱼ eⱼ = λ。 

这意味着所有活动顶点在 A e 下具有相同的邻居加权和。 

这产生了一个线性系统：

 A_S e = λ 1

 与 Σ eᵢ = 1 一起。 

#### 4. 求解线性系统

 我们将 λ 视为未知数并求解 k + 1 维系统。 一种方法是增加矩阵并通过高斯消去法求解。 

如果解产生任何负 eᵢ，则该子集无效并被丢弃。 

#### 5. 计算目标值

 对于有效的解决方案，请直接使用二次公式计算 E 并跟踪所有子集的最大值。 

### 为什么它有效

 优化问题是单纯形上的二次规划。 任何全局最优值都必须满足 Karush-Kuhn-Tucker 条件。 这些条件强制所有活动变量的偏导数相等，从而将非线性优化转变为每个候选支持上的线性系统。 由于单纯形具有有限多个面，并且每个面对应一个子集，因此枚举子集可以保证我们检查包含全局最优值的区域。 可行性过滤确保只有有效的 KKT 点做出贡献，并且评估目标会选择最佳的一个。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    w = [list(map(float, input().split())) for _ in range(n)]

    best = 0.0

    # iterate over all subsets
    for mask in range(1, 1 << n):
        idx = [i for i in range(n) if (mask >> i) & 1]
        k = len(idx)

        # build linear system: A e = λ 1, sum e = 1
        # unknowns: e_0..e_{k-1}, λ
        m = k + 1
        a = [[0.0] * m for _ in range(m)]
        b = [0.0] * m

        # equations: Ae - λ1 = 0
        for i in range(k):
            ii = idx[i]
            for j in range(k):
                jj = idx[j]
                a[i][j] = w[ii][jj]
            a[i][k] = -1.0  # -λ
            b[i] = 0.0

        # constraint: sum e = 1
        for j in range(k):
            a[k][j] = 1.0
        a[k][k] = 0.0
        b[k] = 1.0

        # Gaussian elimination
        x = gauss(a, b)
        if x is None:
            continue

        e = x[:k]
        if any(v < -1e-9 for v in e):
            continue

        # compute energy
        val = 0.0
        for i in range(k):
            for j in range(i + 1, k):
                val += e[i] * e[j] * w[idx[i]][idx[j]]

        best = max(best, val)

    print("%.10f" % best)

def gauss(a, b):
    n = len(b)
    for i in range(n):
        # pivot
        p = i
        for j in range(i, n):
            if abs(a[j][i]) > abs(a[p][i]):
                p = j
        if abs(a[p][i]) < 1e-12:
            return None
        a[i], a[p] = a[p], a[i]
        b[i], b[p] = b[p], b[i]

        # normalize
        div = a[i][i]
        for j in range(i, n):
            a[i][j] /= div
        b[i] /= div

        for j in range(n):
            if j != i:
                factor = a[j][i]
                for k in range(i, n):
                    a[j][k] -= factor * a[i][k]
                b[j] -= factor * b[i]

    return b
```该代码迭代所有子集并构建一个编码该子集的 KKT 条件的线性系统。 高斯消元法求解分布和乘数。 通过检查否定性来拒绝任何不可行的解决方案。 

一个微妙的问题是，这里数值不稳定是可以容忍的，因为 n 很小并且可接受的误差为 1e-6。 另一个重要的细节是用小 epsilon 过滤负值，因为即使对于有效的解决方案，浮点消除也会产生微小的负噪声。

 ## 边缘情况

 权重全部为零的简并图会产生平坦的目标表面。 例如：```
3
0 0 0
0 0 0
0 0 0
```每个子集产生零能量，高斯消除仍然产生有效分布，但所有候选都为零。 该算法正确返回零，因为它跟踪初始化为 0.0 的最大值。 

一个强大的边缘情况，例如：```
2
0 1000
1000 0
```将所有质量均匀地施加到两个节点上。 子集 {0,1} 的 KKT 系统产生 e₀ = e₁ = 0.5，给出能量 250。子集 {0} 和 {1} 给出零，因此它们在最大化期间被丢弃为次优。 

一条边占主导地位的倾斜三角形证实子集机制不会过早地限制为完全支持。 仅包含主要端点的子集与整个集合正确竞争，高斯消除确保在缩小的面内找到最佳分割。
