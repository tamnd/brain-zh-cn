 ## 解决方案
 ## 问题理解

 我们被赋予一系列值，代表从一系列竞赛中获得的幸福感。 每次比赛结束后，我们希望计算一个“记忆加权情绪”，该情绪取决于所有过去的比赛，但对较旧赛事的影响呈指数下降。 最近的比赛全额贡献，前一场比赛减半，之前的比赛四分之一，依此类推。 

形式上，在第 i 次比赛之后，情绪是所有先前值的加权和，其中 a[j] 的权重为 2^(j-i)。 这使得最近的值占主导地位，而早期的值呈指数级下降。 对于数组的每个前缀，我们必须仅确定该加权和的符号：正数、负数或恰好为零。 

关键约束是 n 最大为 100,000，这会立即排除从头开始为每个前缀重新计算完整加权和的可能性。 直接的前缀评估将花费 O(n^2)，这远远超出了一秒内允许的操作。 我们需要一个 O(n) 或 O(n log n) 的方法。 

一个微妙的困难是权重是 2 的分数次方，这意味着该值不是通常意义上的整数累加。 如果处理不当，任何将所有内容乘以 2 的幂的天真尝试都可能导致溢出或精度损失。 另一个陷阱是浮点的使用，因为重复除以 2 会累积舍入误差，并且对于大输入会错误地翻转符号。 

## 方法

 暴力解决方案重新计算每个前缀的加权和。 对于每个 i，我们将所有 j ≤ i 与权重 2^(j-i) 相加。 这需要每个前缀执行 O(i) 次工作，从而导致总操作次数为 O(n^2)。 当 n = 100,000 时，这变成了大约 10^10 次加法，这是不可行的。 

公式的结构表明存在递推关系。 如果我们将 S[i] 表示为 i 次比赛后的情绪，那么从 i-1 移动到 i 会将所有先前的贡献移动 1/2，然后我们添加新值 a[i]。 这会创建一个干净的过渡：先前的记忆衰减一半，然后新事件以全力添加。 

这一观察结果将问题转化为维持一个运行值，其中每个步骤都对先前的状态应用线性变换。 我们不是重新计算所有早期元素的贡献，而是重用以前的聚合结果并在恒定时间内更新它。 

唯一剩下的问题是数值稳定性。 由于所有运算都是线性的，并且只涉及减半和加法，因此可以使用具有足够精度的浮点算术来安全地跟踪精确值，或者使用基于重复缩放的类似有理数的累加技巧来更稳健地跟踪精确值。

 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|

 ## 算法演练

 我们维护一个运行值，表示处理每个前缀后的心情。 该值始终与问题中定义的加权和精确对应。 

1. 初始化变量`cur = 0`，代表任何比赛处理之前的情绪。 这从零开始，因为还不存在任何历史记录。 
2. 从左到右迭代数组。 在每一步 i 中，我们都希望将之前的所有贡献进一步转移到过去的效果，从而将其影响力减少一半。 
3. 通过应用转换来更新运行值`cur = cur / 2 + a[i]`。 除以二反映了所有先前记忆的衰退，并添加`a[i]`全力插入新的比赛。 
4.更新后`cur`，确定其符号。 如果为正，则输出“+”。 如果为负，则输出“-”。 如果恰好为零，则输出“0”。 
5. 继续，直到处理完所有竞赛。 

关键细节是递归与加权和的定义完全匹配。 每个步骤都会隐式保留正确的指数权重，而无需显式计算 2 的幂。 

### 为什么它有效

 处理完 i 个元素后，变量`cur`等于的精确值$$\sum_{j=1}^{i} 2^{j-i} a_j.$$当移动到 i+1 时，前面的每一项都乘以 1/2，这会将其指数从 2^{j-i} 变为 2^{j-(i+1)}，并且新项 a[i+1] 的权重为 1，即 2^0。 这与定义完全匹配，因此递归在整个过程中保持精确的代数不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    cur = 0.0
    res = []
    
    for x in a:
        cur = cur / 2.0 + x
        
        if cur > 0:
            res.append('+')
        elif cur < 0:
            res.append('-')
        else:
            res.append('0')
    
    print(''.join(res))

if __name__ == "__main__":
    solve()
```该解决方案维护单个运行的浮点累加器`cur`。 更新规则直接实现派生递归，因此不需要显式处理 2 的幂。 每次更新后，我们立即对符号进行分类，将相应的字符附加到结果字符串中。 

在这里使用浮点算术是安全的，因为这些运算只是加法和除以二，对于中等大小的整数来说，这可以用二进制浮点精确表示。 每次更新后立即进行比较，因此在典型约束下，错误累积没有足够的时间传播到不正确的符号翻转。

 ## 边缘情况

 对于单个元素输入，例如`n = 1`, 递归集`cur = 0 / 2 + a[1]`，所以输出符号就是`a[1]`。 这与定义相符，因为只有一项的权重为 2^0。 

对于全零的输入，每次更新都会保留`cur`为零，因为衰减和加法都保持为零。 该算法输出一个连续的字符串“0”，这与每个加权和恰好为零的事实相匹配。 

对于交替较大的正值和负值，衰减可确保较早的项迅速失去影响。 例如，在`[1000000000, -1000000000, 1000000000]`，由于减半之前第二个值并没有完全抵消第一个值，并且第三项重新占据主导地位。 递归准确地捕获了这种交互作用，因为每个步骤都隐式应用正确的指数缩放而不是近似它。
