 ## 解决方案
 ## 问题理解

 我们得到了一个字符串集合，任务是在非常具体的兼容性规则下形成尽可能多的字符串对。 如果两个字符串共享非空后缀，则它们只能以有用的方式配对，并且配对的目的是最大化我们可以构建的此类不相交对的数量，以便每个字符串最多使用一次。 

问题的结构从根本上讲是关于单词之间的后缀关系。 如果您将每个字符串视为从右到左读取的内容，那么问题就变成了从末尾比较时尽可能晚地对“相遇”的字符串进行分组。 共享后缀越深，两个字符串的相关性就越强，但目标不是最大化相似性，而是最大化不相交的有效配对的数量。 

输入是字符串列表。 输出是一个整数，表示我们可以按照上述规则形成多少个有效对。 

这些限制意味着天真的成对比较方法将无法生存。 如果字符串数量最多为 10^5 个左右，并且每个字符串可能很长，则直接比较每一对字符串将导致后缀比较数量呈二次爆炸，这会立即变得太慢。 即使构建所有成对的最长公共后缀值也会超出时间限制几个数量级。 

一些边缘情况揭示了为什么贪婪的局部匹配在没有结构的情况下会失败。 例如，如果所有字符串都相同`["abc", "abc", "abc", "abc"]`，正确答案是 2 对。 如果不尊重全局分组，天真的贪婪方法可能会意外地以某种方式对字符串进行配对，从而阻止后缀层次结构中更深层次的更好的结构化配对。 

当后缀部分重叠时会出现另一种失败情况。 例如`["aba", "cba", "bba", "aba"]`。 局部相似的字符串可能会吸引早期的配对决策，但正确的解决方案取决于按完整后缀结构而不是浅匹配进行分组。 

关键的困难在于兼容性是分层的，而不是成对独立的。 

## 方法

 暴力策略将尝试计算每对字符串之间的最长公共后缀，然后尝试贪婪地匹配具有有效后缀关系的对。 这立即遇到两个问题。 首先，计算每对后缀相似度的成本为 O(L)，总体成本为 O(N^2 L)。 其次，即使这些值可用，选择最佳不相交对也是稠密图上的全局匹配问题，这需要通用的匹配算法，对于约束而言速度太慢。 

关键的观察是，如果我们反转所有字符串，后缀关系自然会形成树结构。 我们不考虑后缀，而是考虑反转字符串的前缀。 这会将问题转换为基于反向单词的字典树。 trie 的每个节点表示某个单词子集的公共后缀，并且共享该后缀的所有单词都包含在以该节点为根的子树中。 

一旦以这种方式看待问题，配对就成为每个子树内部的局部配对。 在任何节点，我们希望在其后代集中配对尽可能多的单词。 如果一个节点有多个子子树，则每个子树都会贡献许多“未配对的剩余字符串”，并且这些剩余字符串只有在它们在更高的祖先处相遇时才能配对。 

核心思想是对 trie 进行后序遍历，计算每个子树中剩余多少个未配对的字符串，并使用来自子节点的计数在每个节点上贪婪地匹配尽可能多的对。 这将全局配对问题简化为自下而上的不匹配项目流。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力配对匹配 | O(N^2·L) | O(N^2·L) | O(N^2) | O(N^2) | 太慢了|
 | Trie + 后序贪婪配对 | O(总字符数) | O(总字符数) | 已接受 |

 ## 算法演练

 我们使用反转的字符串构建一个特里树，以便后缀成为数据结构中的前缀。 

1. 将每个字符串反转后插入到 trie 中。 每个终端节点都会增加一个计数，指示有多少单词在该节点处结束。 这将按后缀结构对所有字符串进行分组。 
2. 从 trie 的根开始进行深度优先遍历。 在每个节点，我们将计算处理子节点后其子树中仍有多少个字符串未配对。 
3. 对于每个节点，收集其子节点返回的“未配对计数”。 这些表示共享当前后缀但仍然免费的字符串。 
4. 对当前节点处的所有子余数求和。 如果这个和是偶数，那么它们都可以在本地配对，所以没有任何东西向上传递。 如果它是奇数，则必须恰好有一个字符串保持不配对状态，并将传播到父节点。 
5. 每次我们在一个节点处组合剩余的字符串时，我们通过取子节点贡献的一半加上恰好在该节点处结束的任何字符串来计算我们在本地形成的对的数量。 
6. 将未配对字符串的数量（标准化形式为 0 或 1）向上返回给父级，同时累加全局配对总数。 

微妙之处在于，配对总是在 trie 中尽早完成，因为首先配对更深的字符串永远不会限制未来的可能性，而延迟配对只会增加将不匹配的字符串滞留在树中更高的风险。 

### 为什么它有效

 trie 在每个深度按后缀等价类对字符串进行分区。 在任何节点，其子树中的所有字符串都共享该节点表示的后缀，并且子树之外的字符串不能与它们共享更长的后缀。 这会产生严格的分离：子树内部的配对决策无法通过使用来自外部的字符串（除非通过父节点）来改进。

不变的是，在处理节点之后，算法最大化了完全在其子树内形成的对的数量，并且仅向上传递最小必要数量的不配对字符串。 由于每个配对都需要两个字符串，并且子树中的所有候选字符串在更深的后缀结构方面都是等效的，因此子树内的任何替代排列都无法在不违反可用性约束的情况下增加对的数量。 

## Python 解决方案```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

class Node:
    __slots__ = ("ch", "cnt")
    def __init__(self):
        self.ch = {}
        self.cnt = 0

def solve():
    n = int(input())
    root = Node()

    # build trie of reversed strings
    for _ in range(n):
        s = input().strip()[::-1]
        cur = root
        for c in s:
            if c not in cur.ch:
                cur.ch[c] = Node()
            cur = cur.ch[c]
        cur.cnt += 1

    ans = 0

    def dfs(node):
        nonlocal ans
        leftover = node.cnt

        for nxt in node.ch.values():
            leftover += dfs(nxt)

        ans += leftover // 2
        return leftover % 2

    dfs(root)
    print(ans)

if __name__ == "__main__":
    solve()
```trie 节点存储子转换以及有多少字符串恰好在该节点结束的计数器。 反转字符串可确保后缀变为前缀，从而使遍历自然聚合后缀等效的字符串。 

DFS 返回一个类似奇偶校验的值：子树中是否保留一个未配对的字符串。 每当两个可用字符串在节点处匹配时，全局答案就会通过整数除以 2 进行累加。 

一个常见的错误是尝试仅在叶节点进行贪婪匹配。 但这会失败，因为配对机会通常存在于多个分支汇聚的内部节点处。 另一个微妙的问题是忘记了以内部节点结尾的字符串也有助于配对容量，而不仅仅是叶节点。 

## 工作示例

 考虑输入：```
4
aba
cba
bba
aba
```我们反转字符串并将它们插入到 trie 中。 结构组后缀如`"aba"`和`"cba"`基于相反形式的共享前缀。 

在一个节点处`"aba"`出现两次，这两个立即形成一对。 来自其他分支的剩余字符串向上传播。 

| 节点| 碳纳米管| 儿童剩菜| 总计 | 结对 | 剩余物品退回 |
 | ---| ---| ---| ---| ---| ---|
 | 叶阿巴| 2 | 0 | 2 | 1 | 0 |
 | 其他叶子 | 各 1 个 | 0 | 1 | 0 | 1 |

 最终答案是 1 对，还有 1 串未使用。 

该跟踪显示了相同的字符串如何在本地配对而不干扰不相关的分支。 

现在考虑：```
6
aa
aa
a
a
aaa
aaa
```在这里，更深层次的后缀匹配占主导地位。 trie 将所有字符串分组为嵌套后缀链。 

在较深的节点处，`"aaa"`先配对，然后`"aa"`， 然后`"a"`取决于剩余的可用性。 

| 节点深度| 贡献 | 成对| 剩余|
 | ---| ---| ---| ---|
 | 最深（aaa）| 2 | 1 | 0 |
 | 中 (aa) | 2 | 1 | 0 |
 | 根级别 (a) | 2 | 1 | 0 |

 总对 = 3。 

这表明该算法始终先解决最具体的后缀匹配，然后再解决更广泛的后缀匹配。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(总字符数) | 每个字符在 trie 中插入一次，并在 DFS 中访问一次 |
 | 空间| O(总字符数) | Trie 为反转字符串的每个唯一前缀存储一个节点 |

 该算法非常适合约束条件，因为 trie 边的总数与字符串长度之和呈线性关系，从而避免了任何成对比较。 即使输入很大，每个字符也会被处理恒定的次数。

 ## 边缘情况

 对于像这样的单个短字符串`"a"`，trie 由一个计数为 1 的节点组成。DFS 返回剩余的 1，并且没有形成任何对，正确地生成 0。 

对于重复的相同字符串，例如`"aaaa"`出现偶数次时，所有副本都会在同一 trie 节点的本地配对中被消耗。 该算法立即形成对，而不会向上传播不必要的剩余部分。 

对于倾斜的后缀链，例如`"a"`,`"aa"`,`"aaa"`，该结构在 trie 中形成单个路径。 配对首先发生在最深的级别，确保优先考虑较长的后缀匹配，并且剩余传播正确地保留了更高节点的可行性。
