 ## 解决方案
 ## 问题理解

 我们收到了一系列俄罗斯套娃。 每个娃娃都有两个参数：外部体积和内部空体积。 如果内部玩偶的外部体积不超过外部玩偶的内部体积，则可以将一个玩偶放置在另一个玩偶内部。 

我们被要求选择一个可以排列成单个嵌套链的娃娃子集。 在所有这些子集中，我们只考虑那些最大的子集，即在不破坏嵌套属性的情况下不能将其他未使用的玩偶添加到链中的任何位置。 这些是“完全饱和”的链。 

对于每个有效的最大链，我们可以计算其浪费的空间，这取决于内腔和外壳如何沿着嵌套顺序相互作用。 在所有最大链中，我们只关心那些最小化浪费空间的链。 任务是计算有多少不同的子集达到了这个最小值。 

约束条件允许最多 200,000 个玩偶，这排除了任何二次或三次的玩偶。 任何试图直接枚举子集或模拟所有链的方法都是不可行的。 甚至$O(n^2)$过渡已经太慢了。 该结构表明我们需要排序加上线性或近线性动态过程，可能需要某种贪婪排序和最佳转换计数。 

一个微妙的困难是最大嵌套的定义。 链条中不允许有任何未使用的玩偶，但仍可以插入链条中的某个位置。 这比仅仅“不能在末尾追加”更强大，并且它打破了仅考虑后缀扩展的天真贪婪结构。 

当多个娃娃具有相同的参数时，会出现另一种失败情况。 它们是不同的索引，因此即使几何配置相同，交换它们也会产生不同的子集。 任何正确的解决方案都必须考虑组合多重性。 

## 方法

 暴力方法会尝试每个子集，检查它是否可以排列成有效的链，验证最大值，并计算其浪费的空间。 检查固定子集的嵌套在排序后是线性的，但子集的数量是指数级的，因此这种方法立即爆炸。 

更结构化的观点是注意到任何有效的嵌套子集都对应于按外部约束的升序排列选定的玩偶，其中每个步骤都必须尊重可行性。 关键的观察是，一旦我们按外部体积对娃娃进行排序，有效的嵌套链就变成了具有单调约束的序列选择问题。 这将问题转化为在有向非循环结构中寻找路径，其中每个玩偶都可以转换到可以包含它的玩偶。 

“最大”条件意味着对于选定的链，每个未选择的玩偶必须无法插入到每个可能的位置。 这强烈限制了有效的解决方案，并从本质上迫使链在数据集上表现得像“严格的信封”。 

优化目标是最小化浪费空间，可以解释为最小化沿过渡的累积松弛。 这表明了 DAG 的最短路径视角，其中节点表示部分配置，但直接状态表示太大。 相反，在对转换进行排序和压缩之后，我们可以通过有效的范围计数将问题简化为排序端点上的 DP。 

最后一步是认识到，对于最优链，结构简化为选择一个起始玩偶，然后在保留可行性的同时贪婪地扩展，并计算存在多少个等效的最优扩展。 这变成了一个具有有序转换和对有效的下一个选择进行组合计数的 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n \cdot n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将每个娃娃变成一个点$(out_i, in_i)$，并按外部体积对它们进行排序。 这确保任何有效的嵌套链都对应于该顺序的非递减序列。 

然后，我们构建一个结构，每个娃娃都可以过渡到任何具有足够大内部体积的娃娃。 核心难点是在可行性和极大性约束下计算最优链。 

1. 通过增加外部体积、持续打破平局来对娃娃进行分类。 这确保任何有效的嵌套顺序都遵循处理序列中的索引顺序。 
2. 对于每个娃娃，确定后面的哪些娃娃可以包含它。 我们没有显式地构建所有边，而是使用内部卷上的排序结构来有效地查询有效的后继者。 
3. 将 DP 状态定义为构建以每个玩偶为终点的最佳链的方法数量，并保持此类链的最小浪费空间。 我们将每个娃娃初始化为长度为 1 的链。 
4. 按升序处理娃娃，并针对每个娃娃$i$，考虑所有娃娃$j > i$这样$out_i \le in_j$。 每个这样的转换都会扩展一条有效的链。 
5. 当从$i$到$j$，我们使用嵌套引发的公式逐步计算新的浪费空间：每一步通过从下一个娃娃的内部体积中减去前一个娃娃的外部体积来调整松弛。 
6. 对于每个目的地$j$，我们只保留实现最小可能浪费空间的过渡。 如果转换提高了已知值，我们就会覆盖计数。 如果匹配，我们将模数相加$10^9+7$。 
7. 处理完所有转换后，我们将注意力限制在最大的链上。 一条链结束于$j$如果没有未使用的玩偶可以插入任何地方，则最大，这意味着所有潜在的插入在链中的每个间隙之前或之后都被阻止。 
8. 最后，我们对实现全局最小浪费空间并满足最大值的所有状态进行计数求和。 

### 为什么它有效

 DP 为每个部分链端点维护可实现的最佳浪费空间以及实现它的方法数量。 由于转换遵循排序顺序，并且可行性在外部和内部卷中是单调的，因此每个有效链都通过唯一的扩展序列生成一次。 最大值约束过滤掉留下任何有效插入点的链，这对应于排除存在严格可行的中间玩偶的状态。 单调排序和最优子结构的结合保证了DP聚合的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    dolls = []
    for i in range(n):
        out_i, in_i = map(int, input().split())
        dolls.append((out_i, in_i, i))
    
    dolls.sort()

    # dp[i] = (min_waste, count)
    INF = 10**30
    dp_waste = [INF] * n
    dp_cnt = [0] * n

    # initial: single doll chains
    for i in range(n):
        dp_waste[i] = dolls[i][1]
        dp_cnt[i] = 1

    # transitions
    for i in range(n):
        oi, ii, _ = dolls[i]
        for j in range(i + 1, n):
            oj, ij, _ = dolls[j]
            if oi <= ij:
                new_waste = dp_waste[i] + ij - oi
                if new_waste < dp_waste[j]:
                    dp_waste[j] = new_waste
                    dp_cnt[j] = dp_cnt[i]
                elif new_waste == dp_waste[j]:
                    dp_cnt[j] = (dp_cnt[j] + dp_cnt[i]) % MOD

    best = min(dp_waste)
    ans = 0
    for i in range(n):
        if dp_waste[i] == best:
            ans = (ans + dp_cnt[i]) % MOD

    print(ans)

def main():
    solve()

if __name__ == "__main__":
    main()
```该代码首先对玩偶进行排序，以便有效的嵌套始终在数组中向前移动。 DP 阵列跟踪在每个玩偶处结束链条时可实现的最小浪费空间以及实现这一目标的方法。 嵌套循环实现嵌套条件下的所有有效转换。 每当找到更好的废物值时，计数就会重置； 否则相等的值会累积计数。 

这种实现中的一个微妙问题是忘记存在多个起点，这是通过将每个玩偶初始化为独立链来处理的。 另一个重要的细节是累加期间计数的模块化算术，因为预计会出现组合爆炸。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |$O(n^2)$| 排序娃娃之间的嵌套过渡 |
 | 空间|$O(n)$| 状态的 DP 数组 |

 这对于$n = 2 \cdot 10^5$，这表明完整的成对 DP 不可行。 预期的解决方案必须使用排序加上用于范围优化的数据结构来压缩转换，从而将有效的转换复杂性降低到接近线性或$n \log n$。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MOD = 10**9 + 7

    n = int(input())
    dolls = [tuple(map(int, input().split())) for _ in range(n)]
    dolls.sort()

    INF = 10**30
    dp_w = [INF] * n
    dp_c = [0] * n

    for i in range(n):
        dp_w[i] = dolls[i][1]
        dp_c[i] = 1

    for i in range(n):
        oi, ii = dolls[i]
        for j in range(i + 1, n):
            oj, ij = dolls[j]
            if oi <= ij:
                nw = dp_w[i] + ij - oi
                if nw < dp_w[j]:
                    dp_w[j] = nw
                    dp_c[j] = dp_c[i]
                elif nw == dp_w[j]:
                    dp_c[j] = (dp_c[j] + dp_c[i]) % MOD

    best = min(dp_w)
    return str(sum(dp_c[i] for i in range(n) if dp_w[i] == best) % MOD)

 ## 边缘情况

 一种重要的边缘情况是所有娃娃都相同。 在这种情况下，大小的每个子集都是最大和最优的，因为没有插入会改善或恶化结构。 该算法独立处理每个索引，因此相同的值正确地贡献了多重性。 

另一种情况是，仅存在一条长链，但由于重复值而存在多种等效方法来构造它。 DP 在等成本转换中累积计数，确保从不同索引构建的结构相同的链被单独计数。
