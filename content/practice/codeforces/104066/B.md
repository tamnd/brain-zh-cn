 ## 解决方案
 ## 问题理解

 我们在平面上得到了一个几何设置。 有一个已知圆心和半径的固定圆，在该圆上有一个带有两个标记点的刚性“装置”。 关键的自由度是我们可以围绕圆的中心旋转该设备，这可以有效地围绕该中心旋转两个标记点，同时保持它们与圆的距离。 

除此之外，平面上还有一条固定的直线。 任务是确定我们是否可以旋转圆的标记配置，以便由两个标记点形成的线变得与给定的固定线平行。 

因此，真正的问题不在于圆本身，而在于由两点定义的线段在绕其公共中心刚性旋转后是否可以达到与给定线的方向相匹配的方向。 

输入描述了三个独立的几何对象。 首先，圆心和半径，定义枢轴和旋转机构。 其次，一条线以一般形式 ax + by + c = 0 给出，其中只有方向向量 (a, b) 重要。 第三，定义严格连接到圆中心的线段的两个点，这意味着它们围绕中心的相对角度可以改变，但它们距中心的距离是固定的。 

输出是一个简单的可行性决策：是否存在某个旋转角度使线段方向平行于给定的线。 

约束很小，所有坐标和系数都以 10^4 为界。 这立即排除了除基本三角学或矢量推理之外的繁重几何预处理或浮点精度技巧的任何需要。 每个测试用例进行恒定时间的几何检查就足够了。 

当两个标记点重合时，会出现微妙的边缘情况。 在这种情况下，“通过标记点的线”是不确定的。 盲目计算方向向量的简单实现会将其除以零或将其视为零向量，这可能会导致错误的结论。 例如，如果两个点相同，例如 (0, 0) 和 (0, 0)，则该线段没有方向。 在这种情况下，正确的输出取决于解释：由于无法形成任何线，因此不可能使其与任何非简并给定线平行，因此答案应该为“否”，除非问题允许简并并行性，而标准 CF 几何问题则不允许。 

另一个极端情况是给定线在方向表示中退化，例如当 a 和 b 都为零时。 这会使该行无效，但约束通常会确保这种情况不会发生。 尽管如此，稳健的推理应该完全忽略 c 并仅关注 (a, b) 作为方向向量。 

## 方法

 考虑这个问题的强力方法是模拟该段绕中心的旋转并检查所有可能的方向。 由于涉及连续旋转，因此可以离散角度并测试线段的许多候选方向。 从概念上讲，这可以通过扫描 0 到 2π 的角度并检查旋转矢量是否与给定线的方向对齐来实现。 

然而，这既不必要又不精确。 即使精细离散化，由于浮点粒度，它也有可能丢失精确对齐，并且正确性所需的样本数量也没有以干净的方式限制。 

关键的观察结果是，由两个标记点定义的线段具有固定的长度并围绕中心刚性旋转。 这意味着它的方向不是根据端点配置自由选择的； 相反，它跨越单个基向量的所有可能的旋转。 因此，唯一的问题是该线段的方向向量是否可以旋转到平行于(a,b)的方向。

当且仅当两个向量的角度因某种旋转而不同时，两个向量才能通过旋转变得平行，除非线段退化为单个点，否则这总是可能的。 平面中的旋转保留大小并且仅改变方向，因此任何非零向量都可以旋转以匹配任何其他方向。 

因此，问题就简化为检查该段是否是非退化的。 如果两个点不同，则存在有效的方向向量，并且我们始终可以旋转它以与线方向对齐。 如果它们重合，则不存在方向，答案是否定的。 

因此，整个几何体崩溃为简单的简并检查。

 ## 算法演练

 1. 读取圆参数、线系数、两点。 圆参数实际上并不用于计算，但它们在概念上建立了旋转中心。 
2. 计算两点形成的线段的方向向量为(dx,dy)=(x2−x1,y2−y1)。 该向量代表唯一有意义的几何自由度。 
3. 检查该向量是否为零。 如果dx = 0且dy = 0，则两点重合，且不存在有效方向，因此立即输出NO。 
4. 如果向量非零，则得出其可以旋转到平面内任何方向的结论，包括平行于直线方向 (a, b) 的方向。 输出是。 

步骤 4 背后的原因是任何非零 2D 向量都可以连续旋转所有角度，并且平行度仅取决于方向，而不取决于大小。 

### 为什么它有效

 不变的是，标记线段唯一重要的属性是其方向向量，绕中心旋转可以保留其长度，同时允许在整个圆上连续改变方向。 对于任何非零向量来说，可达方向的集合是整个单位圆。 因此，除非向量是简并的，否则任何给定线的匹配方向始终存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x0, y0, r = map(int, input().split())
    a, b, c = map(int, input().split())
    x1, y1 = map(int, input().split())
    x2, y2 = map(int, input().split())

    dx = x2 - x1
    dy = y2 - y1

    if dx == 0 and dy == 0:
        print("NO")
    else:
        print("YES")

if __name__ == "__main__":
    solve()
```该实现使逻辑保持最小，因为所有几何复杂性都已通过分析解决。 读取圆参数以匹配输入格式，但不进一步使用。 唯一关键的计算是两个标记点之间的差异。 

这里的一个常见错误是尝试使用斜率或浮点角度比较。 这是不必要的，因为问题简化为简单的非简并检查。

 ## 边缘情况

 当两个标记点相同时，算法检测到 dx = dy = 0 并立即输出 NO。 这可以防止任何未定义的方向概念，并避免将零向量视为具有任意方向。 

例如，如果输入为 (0,0) 和 (0,0)，则计算出的向量为 (0,0)。 该算法在简并检查处停止并返回“否”，而不尝试任何几何推理。 

如果点非常接近但不相同，例如 (0,0) 和 (0,1)，则向量仍然有效，并且算法正确地允许旋转。 这表明只有精确的相等才重要，而不是数字上的接近。
