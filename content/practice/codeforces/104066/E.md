 ## 解决方案
 ## 问题理解

 我们得到了形成一个故事的一系列单词，其中单词之间用单个空格分隔，并且每个单词仅由小写拉丁字母组成。 整个故事可以被视为一长串，但空格是特殊字符，将其分成单词边界。 

任务是回答有关该组合字符串内位置的查询。 每个查询都会给出完整故事字符串中的全局字符索引（包括字母，但通常会忽略问题陈述中描述的查询模型中的索引目的的空格），并且我们必须确定两件事：哪个单词包含该字符以及该字符在该单词中的位置。 

因此，核心转换是从串联表示中的线性索引转换为一对坐标：单词索引和该单词内的位置。 

约束表示最多 10^5 个单词和最多 5·10^5 个查询，总字符长度最多 10^6。 这立即意味着对单词或字符的任何每次查询线性扫描都太慢。 解决方案必须对结构进行一次预处理，并在恒定或对数时间内回答每个查询。 在最坏的情况下，每个查询的线性扫描将达到 5·10^11 次操作，这在 1 秒限制下是不可行的。 

一个幼稚但常见的错误是将空格视为普通字符，而忘记索引会跳过它们。 另一个微妙的问题是将前缀和映射到段时的离一索引，特别是当查询恰好命中单词之间的边界时。 

当单词长度为 1 或所有单词都很短时，就会出现边缘情况，从而导致边界频繁出现。 例如，如果故事是`"a b c"`，全局指数紧密映射，边界条件很重要。 精确指向单词最后一个字符的查询不得溢出到下一个单词。 

## 方法

 暴力破解的想法很简单：将整个故事连接成一个字符串，然后对于每个查询向前扫描，直到到达第 k 个字符。 虽然正确，但在最坏的情况下，每个查询需要 O(n) 工作，因为定位位置需要从头开始遍历或迭代单词，直到找到正确的段。 由于查询次数最多为 5·10^5，总长度最多为 10^6，这会退化为对同一前缀结构的重复扫描，从而导致重复工作。 

关键的观察结果是单词边界是静态的。 一旦我们知道了单词长度的前缀总和，每个查询就变成了对超过给定位置的第一个前缀的搜索。 这将问题转换为单调数组中的重复范围位置，如果按顺序处理查询，则可以通过二分搜索或更简单地通过两指针扫描来解决。 

由于总大小仅为 10^6，因此每个查询的前缀和加上二分搜索就足够且简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个查询的强力扫描 | O(n·m) | O(n) | 太慢了|
 | 前缀和+二分查找 | O(n + m log n) | O(n + m log n) | O(n) | 已接受 |

 ## 算法演练

 我们首先将单词序列转换为前缀结构，该结构描述每个单词在没有空格的扁平故事字符串中的开始和结束位置。 

我们维护一个数组`pref`， 在哪里`pref[i]`存储第一个字符的总数`i`字。 

然后每个查询就变成了对该数组的搜索问题。 

1. 构建一个字长数组。 每个单词都贡献其字符数。 
2. 构造前缀和，使得`pref[i]`是单词中的字符总数`[1..i]`。 这给出了单调递增序列。 
3.查询职位`x`，找到最小的索引`i`这样`pref[i] >= x`。 这标识了包含该字符的单词。 
4. 找到单词后，计算单词在单词内的位置：`x - pref[i-1]`。 

步骤 3 的正确性依赖于前缀和将全局字符串划分为与单词精确对应的连续不相交段的事实。 

直接二分查找就足够了，因为`pref`是严格增加的。 

### 为什么它有效

 每个单词在展平的故事字符串中占据一个连续的间隔，并且这些间隔不重叠。 前缀数组对每个间隔的右端点进行编码。 找到第一个超过或等于查询索引的前缀相当于找到包含该索引的区间。 由于间隔是连续且有序的，因此该映射是唯一且确定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    words = input().split()

    pref = [0] * (n + 1)
    for i in range(1, n + 1):
        pref[i] = pref[i - 1] + len(words[i - 1])

    def find_word(x):
        lo, hi = 1, n
        while lo < hi:
            mid = (lo + hi) // 2
            if pref[mid] >= x:
                hi = mid
            else:
                lo = mid + 1
        return lo

    for _ in range(m):
        x = int(input())
        i = find_word(x)
        prev = pref[i - 1]
        print(i, x - prev)

if __name__ == "__main__":
    solve()
```该实现将预处理和查询处理完全分开。 前缀数组在 O(n) 内构建一次。 每个查询都在单词边界上使用二分搜索。 

功能`find_word`仔细编写以避免差一错误。 条件`pref[mid] >= x`确保我们到达右边界不在查询索引之前的第一个单词。 

减法`x - pref[i - 1]`将全局位置转换为所选单词内的局部偏移量。

 ## 边缘情况

 关键的边缘情况是查询恰好落在单词的最后一个字符上。 在这样的故事中`"abc def"`，前缀和是`[3, 6]`。 查询`x = 3`必须映射到第一个单词，而不是第二个单词。 条件`pref[mid] >= x`确保向左边界字解决相等问题，防止意外溢出到下一个字。 

另一个微妙的情况是当所有单词的长度为 1 时。那么前缀和严格`1, 2, 3, ...`，并且二分搜索仍然必须正确地将每个查询映射到其确切的单词。 该算法会处理此问题，因为每个索引都匹配唯一的前缀值。 

最后，当只有一个单词时，每个查询都会简单地映射到单词 1，并且位置与查询索引相同。 该实现不需要特殊的大小写，因为前缀数组会正确退化为`[0, len(word)]`。
