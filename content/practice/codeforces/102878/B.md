 ## 解决方案
 ## 问题理解

 这个问题要求我们回答许多独立的问题。 在每个查询中，素数模`P`是固定的，我们定义一个值`f(i,r,P)`作为对的数量`(a,b)`模数`P`满足模方程涉及`a^r`,`b`， 和`b^2`。 最终的答案不是要求个体的价值观`f`; 它要求的产品是`Y`每个都提高到这些值`i`从`1`到`N`, 取模`10^9+7`。 

有用的第一个变换是组合指数。 自从$$\prod_{i=1}^{N}Y^{f(i,r,P)}=Y^{\sum_{i=1}^{N}f(i,r,P)},$$每个查询只需要找到一个指数，即所有指数的总和`f(i,r,P)`价值观。 

查询数量可达`100000`， 尽管`P`可以接近`10^9`。 循环所有模余数的解决方案`P`，甚至超过其中的很大一部分，都是不可能的。 我们需要一个仅依赖于小的算术属性的公式`P`,`r`， 和`N`。 限制`r <= 3`是关键线索，因为它允许我们在有限域中推理幂，而无需执行昂贵的计算。 

等式是$$a^r(b+b^2)^i \equiv b^i \pmod P.$$表达式退化的情况需要特殊处理。 如果`b=0`，两边都为零，所以每`a`作品。 如果`b=-1`， 然后`b+b^2=0`但`b^i`是非零，所以没有`a`作品。 对于所有其他值，我们可以除以：$$a^r \equiv (b/(b+b^2))^i.$$因为`b+b^2=b(b+1)`，这变成了$$a^r \equiv (b+1)^{-i}.$$所以问题就变成了计算一个值出现的频率`r`域的乘法群中的 次方。 

粗心的实施可能会忘记特殊值。 例如，如果`P=5`,`r=2`， 和`i=1`，输入查询包含模数`5`。 价值`b=0`贡献五个有效对，因为每个`a`作品。 如果我们只计算非零残基而忽略零，我们就会丢失这五对残基并得到错误的指数。 

另一个常见错误是处理不当`b=-1`。 为了`P=7`,`r=3`， 和`i=1`，选择`b=6`给出`b+b^2=0`， 尽管`b^i=6`，因此该值没有有效的对。 像对待它一样`b=0`case 会添加无效的解决方案。 

## 方法

 直接的方法是迭代所有可能的`b`，然后计算数量`a`满足方程的值。 对于固定的`b`，我们可以测试每一个`a`并检查一致性。 这是正确的，因为它准确地检查了`f`。 然而，单个查询可能需要大约`P^2`检查，这远远超出了当`P`接近于`10^9`。 

重要的观察是，在删除两个异常值之后`b=0`和`b=-1`, 剩下的每一个`b`恰好对应于一个非零域元素`x=b+1`不同于`1`。 解决方案的数量$$a^r=t$$在乘法群中仅由是否确定`t`属于以下子群`r`-th 权力。 

为了`r=1`，每个值都有一个根。 为了`r=2`，正好有一半的非零值是平方。 为了`r=3`，或者每个值都有唯一的立方根，当`3`不分开`P-1`，或者三分之一的值是立方体，并且每个立方体有三个根，当`3`划分`P-1`。 

这让我们可以计算所有可能的情况`b`仅使用奇偶性或整除性的值`i`。 

为了`r=2`， 如果`i`是偶数，每个非零`x`给出一个正方形，因为`x^i`是一个正方形。 如果`i`是奇数，只有 的平方值`x`工作。 

为了`r=3`， 如果`P-1`不能被整除`3`，立方体运算是一种排列，因此每个值都有效。 否则，只有每三个非零值是一个立方体。 该模式仅取决于是否`i`可以整除`3`。

 | --- | --- | --- | --- |
 | 蛮力 | O(P²N) | O(1) | O(1) | 太慢了|
 | 最佳 | 每个查询 O(log MOD) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算指数`E = sum(f(i,r,P))`而不是直接产品。 最终的答案是`pow(Y, E, 1e9+7)`。 
2. 手柄`r=1`。 每个非零`b`除了`-1`贡献一份有效的`a`， 和`b=0`贡献`P`有效对。 每个人的价值`i`因此是恒定的。 
3. 手柄`r=2`。 总有`P`解决方案来自`b=0`。 剩下的当中`P-2`值，数出有多少个`(b+1)^(-i)`是正方形。 什么时候`i`甚至所有价值观都有效。 什么时候`i`只有非零二次余数才为奇数。 
4. 手柄`r=3`。 再次，从`P`解决方案来自`b=0`。 如果`P-1`不能被整除`3`，每个非零值都是一个立方体。 否则，只有三分之一的非零值是立方体，并且只有当`i`不是的倍数`3`。 
5. 将贡献乘以具有每个属性的指数数量。 例如，不要迭代每个偶数`i`，计算有多少个偶数出现在`1..N`。 

为什么它有效：

 替换后`x=b+1`，每个有效的非零情况都会询问是否`x^{-i}`属于以下子群`r`-th 权力。 在循环群中，取逆不会改变子群中的成员资格，因此该问题相当于询问是否`x^i`是一个`r`次幂。 正方形和立方体的子组大小由下式固定`gcd(r,P-1)`，给出了上面使用的公式。 一切可能`b`恰好被一种情况覆盖，因此求和的指数是精确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve_query(Y, N, r, P):
    if r == 1:
        exp = N * (2 * P - 2)
        return pow(Y, exp, MOD)

    if r == 2:
        even = N // 2
        odd = N - even

        per_even = P + 2 * (P - 2)
        per_odd = P + (P - 3)

        exp = even * per_even + odd * per_odd
        return pow(Y, exp, MOD)

    if (P - 1) % 3 != 0:
        exp = N * (2 * P - 2)
    else:
        div3 = N // 3
        other = N - div3

        per_div3 = P + 3 * (P - 2)
        per_other = P + (P - 4)

        exp = div3 * per_div3 + other * per_other

    return pow(Y, exp, MOD)

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        Y, N, r, P = map(int, input().split())
        ans.append(str(solve_query(Y, N, r, P)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```该解决方案首先将乘积转换为单个模幂。 这就是代码永远不需要存储任何序列的原因`f(i,r,P)`价值观。 

为了`r=1`，指数对于每个都是恒定的`i`。 为了`r=2`，代码将奇数位置和偶数位置分开，因为平方属性完全随着指数的奇偶性而变化。 偶数索引的数量`1..N`是`N//2`，其余索引为奇数。 

为了`r=3`，代码首先检查立方体贴图是否是双射。 如果`P-1`不能被整除`3`，所有非零余数都是立方体。 否则，索引可除以`3`与其他指数的表现不同。 

所有算术都保留为整数。 Python 可以安全地处理较大的中间值，但只有模幂运算才需要最终的指数，该运算以对数时间运行。

        return pow(Y, N * (2 * P - 2), MOD)

 ## 边缘情况

 对于`b=0`，该算法包括固定`P`每个值中的有效对`f`。 例如，与`P=5`,`r=2`， 和`N=1`，该单个残基的贡献是五对，并且公式在计算剩余残基之前将其包括在内。 

为了`b=-1`，没有添加对。 替换`x=b+1`自然地删除了这种情况，因为它对应于`x=0`，它不属于正在计算的乘法组的一部分。 

什么时候`P-1`可以整除`3`，立方体计数变化。 例如，与`P=7`，只有三分之一的非零余数是立方体，并且索引可以整除`3`必须分开，因为`x^3`始终是一个立方体，而`x`其本身不一定是一。 该算法通过直接计算三的倍数来处理这个问题，而不是假设每个索引的行为都相同。 

什么时候`N`非常大，迭代自`1`到`N`这是不可能的。 该解决方案仅计算有多少个索引满足每个类别，例如偶数索引或三的倍数，因此运行时保持独立`N`。
