 ## 解决方案
 ## 问题理解

 我们有一个矩形卡罗姆表，其水平范围是从 (x=0) 到 (x=N)，垂直范围是从 (y=0) 到 (y=M)。 球从严格位于矩形内部的整数位置 ((x_0,y_0)) 开始。 每一秒它都会以当前速度矢量 ((v_x,v_y)) 移动。 当它到达垂直的墙壁时，(v_x) 的符号发生变化。 当它到达水平墙时，(v_y) 的符号发生变化。 撞到角落会改变两个迹象。 

任务是在 (S) 秒后找到球的精确整数位置。 输入包含最多 (10^4) 个独立模拟。 工作台尺寸、坐标、速度和时间都可以大到 (10^9)。 

(S) 的值较大，因此无法一次模拟一秒的运动。 单个测试用例可能需要 (10^9) 次更新，跨 (10^4) 个测试用例可能需要 (10^{13}) 次更新。 即使每模拟秒的工作量非常小，也会远远超出 1 秒的时间限制。 我们需要一个其成本不线性依赖于 (S) 的计算。 

最有用的结构事实是水平和垂直运动是独立的。 垂直墙仅变化 (v_x)，而水平墙仅变化 (v_y)。 我们可以分别求解([0,N])和([0,M])上的一维运动，然后将两个坐标组合起来。 

有几种边界情况可能会暴露简单实现中的错误。 首先，速度可以为负。 例如，与```
1
5 5 2 2 -3 0 1
```正确的位置是```
4 2
```因为球从 (x=2) 移动到 (x=-1)，在 (x=0) 处到达墙壁，只有在实际连续轨迹到达墙壁后才反射到 (x=1)。 由于请求的位置在时间 (1)，因此通过展开的轨迹获得正确的解释：(2-3=-1)，其反射位置为 (1)。 使用普通余数而不对负值进行归一化的公式可以产生负坐标。 

第二个陷阱正好在要求的时间到达墙壁。 考虑```
1
2 3 1 1 1 2 1
```在时间 (1) 时，球正好位于右上角，因此答案为```
2 3
```碰撞后速度会发生变化，但这不会在请求的时间之前将球移离角落。 一旦看到端点就进行反映，然后立即应用另一个移动的实现可能会引入相差一错误。 

第三种情况是拐角碰撞。 为了```
1
2 3 1 2 1 1 1
```球到达 ((2,3))，因此输出为```
2 3
```两个坐标必须使用自己的反射规则。 将拐角仅视为一次墙壁碰撞会导致一个速度分量的方向不正确，这在以后的查询中会变得可见。 

最后，零速度对于任一坐标都有效。 例如，```
1
2 2 1 1 0 1 3
```有输出```
1 2
```因为水平坐标永远不会改变，而垂直坐标在第一秒到达（2）然后反射。 

## 方法

 直接模拟完全遵循物理描述。 从 ((x_0,y_0)) 开始，我们每秒添加一次 ((v_x,v_y))。 每当坐标到达其两个边界之一时，我们就会反转相应的速度分量。 这是正确的，因为它执行与台球模型完全相同的转换。 

问题在于迭代次数。 在最坏的情况下 (S=10^9)，因此一个测试用例可能需要 (10^9) 模拟秒。 当 (T=10^4) 时，理论总数达到 (10^{13}) 次迭代。 模拟是正确的，但与约束条件根本不相容。 

关键的观察是反射的一维轨迹可以展开成一条直线。 想象一下用无限的副本序列替换间隔 ([0,N])：

 [
 [0,N], [N,2N], [2N,3N], \ldots
 ]

 并以交替方向继续它们。 球不会在墙壁上反射，而是直接穿过边界进入下一个副本。 将直线轨迹折叠回原始区间会得到完全相同的物理位置。 

(S) 秒后展开的水平坐标就是

 [
 p_x=x_0+v_xS。 
]

 实际的表坐标仅取决于 (p_x) 位于长度 (2N) 的周期内的位置。 定义

 [
 r_x=p_x\bmod 2N。 
]

 对于(0\le r_x\le N)，折叠位置为(r_x)。 对于(N<r_x<2N)，它是(2N-r_x)。 这会产生我们熟悉的弹跳粒子三角波。 

纵坐标与(M)的形式完全相同。 这将整个模拟简化为一些整数加法、模运算和比较。 负速度不需要特殊的物理情况，因为 Python 的模运算已经返回正模数范围 ([0,2N-1]) 内的值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 (O(S)) | (O(1)) | (O(1)) | 太慢了 |
 | 最佳| 每个测试用例 (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 计算展开的水平位置 (p_x=x_0+v_xS)。 我们在这里故意忽略反射，因为展开的模型让球继续沿直线穿过每面墙。 
2. 对(p_x)取模(2N)进行约简，得到(r_x=p_x\bmod 2N)。 从一堵墙到另一堵墙并返回的完整来回行程的长度为 (2N)，因此相隔 (2N) 的位置折叠到相同的物理坐标。 
3. 将 (r_x) 折回到桌子上。 如果(r_x\le N)，则物理坐标为(r_x)。 否则，轨迹位于周期的镜像一半内，因此物理坐标为 (2N-r_x)。 
4. 使用 (p_y=y_0+v_yS)、周期 (2M) 和折叠边界 (M) 垂直执行相同的计算。 
5. 打印结果 (x) 和 (y) 坐标。 这两个维度是独立的，因此它们单独计算的位置形成了球的最终位置。 

### 为什么它有效

 仅考虑水平坐标。 在实际表中，每次与 (x=0) 或 (x=N) 的碰撞都会反转水平速度。 在展开的表示中，我们没有反转速度，而是继续进入表格的反射副本。 将这些副本折叠回 ([0,N]) 会在真正的球撞到墙上时准确地反转表面方向。 一整对反射对应于 (2N) 的距离，因此采用展开坐标模 (2N) 保留了确定当前物理位置所需的所有信息。 相同的论证独立地适用于(y)。 这样两个折叠后的坐标就是(S)秒后真实球的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def position(start, velocity, length, seconds):
    unfolded = start + velocity * seconds
    period = 2 * length
    r = unfolded % period

    if r <= length:
        return r
    return period - r

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n, m, x0, y0, vx, vy, s = map(int, input().split())

        x = position(x0, vx, n, s)
        y = position(y0, vy, m, s)

        out.append(f"{x} {y}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```这`position`函数包含整个一维反射逻辑。 它首先在 (S) 秒后构造展开坐标。 不需要模拟单独的碰撞，因为所有碰撞都由周期性折叠操作来表示。 

模除数是表长度的两倍，而不是表长度本身。 使用 (N) 会错误地识别两个行进方向，因为到达 (x=0) 和到达 (x=N) 是轨迹的不同点。 

条件`r <= length`包括确切的墙壁位置。 这很重要，因为球可以在要求的时间准确地落在墙上。 在那一刻，无论碰撞后发生速度反转，它的位置仍然是壁坐标。 

Python 整数具有任意精度，因此 (v_xS) 之类的乘积不会溢出。 在具有固定宽度整数类型的语言中，应使用 64 位整数，因为乘积大约可以达到 (10^{18})。 

负速度不需要单独的分支。 例如，如果展开的坐标为 (-1)，周期为 (10)，Python 会计算 (-1\bmod 10=9)。 折叠 (9) 得到 (10-9=1)，这正是通过 (x=0) 反映点 (-1) 所获得的物理位置。

 ## 边缘情况

 第一个棘手的情况是负速度。 为了```
1
5 5 2 2 -3 0 1
```水平展开坐标为(2-3=-1)。 对于周期 (10)，归一化余数为 (9)。 由于(9>5)，折叠后的坐标为(10-9=1)。 (2) 纵坐标不变，故答案为`1 2`。 不需要负速度的特殊分支。 

第二种情况是在要求的时间恰好到达一堵墙。 为了```
1
2 3 1 1 1 2 1
```展开的坐标是（2）和（3）。 它们的余数也是（2）和（3），都等于它们各自的表长度。 因为折叠条件使用`<=`，结果正好是`2 3`。 速度反转影响后续运动，而不影响碰撞瞬间的位置。 

第三种情况是角碰撞：```
1
2 3 1 2 1 1 1
```两个展开坐标同时达到最大值。 水平结果为（2），垂直结果为（3），给出`2 3`。 由于每个坐标都是独立处理的，因此在实现中不需要特殊的极端情况。 两个速度分量都由它们各自的三角波公式隐式反映。 

第四种情况是零速度：```
1
2 2 1 1 0 1 3
```对于 (x)，展开的坐标仍为 (1)，因此水平结果始终为 (1)。 对于 (y)，展开的坐标为 (4)，周期为 (4)，余数为 (0)。 因此垂直结果为 (0)，因此准确的输出为`1 0`。 这说明了为什么零速度不需要特殊处理，尽管它也表明球可能在请求的时间位于边界上。 

错误的最后一个来源是将表长度与完整反射周期混淆。 对于宽度为 (5) 的表，一个水平周期中的位置序列具有以下形式

 [
 0,1,2,3,4,5,4,3,2,1,0。 
]

 循环长度为(10=2N)。 如果实现减少模 (N)，它会错误地将返回旅程的位置映射到去程旅程，并丢失由反射编码的方向信息。
