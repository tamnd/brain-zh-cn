 ## 解决方案
 ## 问题理解

 该任务要求我们创建一个可以充当有效安全密钥的正整数序列。 对于给定长度`n`，我们需要打印`n`数字，其中所有数字相加所获得的总值与所有数字相乘所获得的值完全相同。 每个数字必须保持正值且低于`10^9`。 法官接受任何满足方程式的序列，而不是一个特定的答案。 

输入包含多个独立的请求。 每个请求仅给出所需的序列长度，并且输出必须针对每个长度包含一个有效序列。 由于所有请求的长度总数可能达到数百万，因此解决方案必须只为每个生成的数字花费恒定的时间。 任何搜索可能值或尝试多种组合的方法很快就会变得不可能。 

关键的困难不是检查序列，因为那很容易。 困难在于建造一个。 一个天真的想法可能会尝试构建一组小数字并调整它们直到总和与乘积匹配，但即使对于单个大数字`n`，搜索空间巨大。 这些限制促使我们寻找一种直接生成答案的数学模式。 

一些边缘情况可能会破坏只考虑一般模式的实现。 为了`n = 1`，答案不能使用具有两个特殊数字的结构，因为没有空间容纳它们。 The correct input and output are:```
Input:
1

Output:
1
```单个数字必须等于它自己的和和乘积，所以只有`1`作品。 

另一个重要案例是`n = 2`。 粗心的实现可能会尝试打印`[2, n]`对于每一个`n`，但这里变成了`[2, 2]`，这恰好有效。 支票是：```
Input:
2

Output:
2 2
```总和是`4`并且该产品也是`4`。 

对于较大的值，这些值的放置很重要。 例如，与`n = 5`， 印刷`[1, 2, 3, 4, 5]`看起来合理但失败了，因为总和是`15`产品是`120`。 正确的构造给出：```
Input:
5

Output:
1 1 1 2 5
```总和是`10`产品是`10`。 

## 方法

 暴力解决方案会尝试猜测数字并测试它们的总和是否等于它们的乘积。 很容易验证候选人`O(n)`，但寻找候选人是问题。 如果我们尝试将每个位置的值达到某个限制，则可能性的数量将呈指数增长`n`。 随着总输出大小达到数百万个数字，即使每个测试用例的小搜索也太慢了。 

解开问题的观察结果是乘以`1`不执行任何操作，同时添加`1`只将总和加一。 这意味着我们可以自由地添加许多个来控制总和与乘积之间的差异。 

为了`n >= 2`，考虑放置`n - 2`并选择剩下的两个数字。 设这两个数字为`x`和`y`。 产品很简单`xy`因为所有的都消失了。 总和是：`(n - 2) + x + y`我们需要：`xy = (n - 2) + x + y`重新排列给出：`xy - x - y = n - 2`以一种有用的形式向两边加一：`(x - 1)(y - 1) = n - 1`可以进行非常简单的因式分解，因为`1 * (n - 1) = n - 1`。 这意味着我们可以选择`x = 2`和`y = n`。 序列变为：`1, 1, ..., 1, 2, n`现在产品是`2n`。 总和是`(n - 2) + 2 + n = 2n`，所以方程始终成立。

 ## 算法演练

 1.读取长度`n`所需的序列。 

如果`n`是`1`， 输出`1`立即地。 单个值必须满足`a = a`， 所以`1`是唯一可能的选择。 

1.如果`n`至少是`2`，创建一个序列，其中包含`n - 2`的副本`1`。 

这些值很有用，因为它们不会更改乘积，但允许每个插入值的总和恰好增长 1。 

1. 附加两个剩余值`2`和`n`。 

产品变成`2 * n`。 总和就是 1 的个数加上这两个值，即`(n - 2) + 2 + n = 2n`。 

1. 打印构建的序列。 

该构造仅使用正整数，最大值为`n`，在要求的限度内。 

为什么它有效：不变的是每个插入`1`保持乘积不变，同时将总和加一。 添加所有必需的值后，选择两个最终值，以便乘积与新的总和完全匹配。 等式不是通过反复试验找到的，而是由代数恒等式保证的`(2 - 1)(n - 1) = n - 1`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 1:
            ans.append("1")
        else:
            ans.append(" ".join(["1"] * (n - 2) + ["2", str(n)]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该代码处理唯一的异常长度，`n = 1`， 分别地。 对于所有其他情况，它都会构建列表并附加构造中的两个特殊值。 

表达式`["1"] * (n - 2)`准确创建所需数量的中性元素。 转换后附加最后两个值`n`为字符串，因为输出被组装为文本。 由于 Python 整数具有任意精度，因此不存在溢出问题。 

总工作量与总输出大小成正比。 这符合所有总和的要求`n`值可能很大。

 ## 边缘情况

 对于`n = 1`，该算法从不尝试创建`n - 2`因为那将是负面的。 就直接返回了`1`，它满足条件，因为和与积都是一。 

为了`n = 2`，该算法创建零并且仅附加`2`和`n`。 序列变为`2 2`。 该产品是`4`总和是`4`，因此无需额外逻辑即可覆盖边界情况。 

为了`n = 5`，该算法创建三个并附加`2`和`5`。 总和计算为`1 + 1 + 1 + 2 + 5 = 10`，而产品是`1 * 1 * 1 * 2 * 5 = 10`。 这说明了为什么 1 的数量必须精确`n - 2`。
