 ## 解决方案
 ## 问题理解

 我们有一个代理循环系统，索引为`0`到`N-1`。 售票机以确定的模式调度到达的公民：`i`第 -th 公民始终被发送给代理`(S + i·K) mod N`， 在哪里`S`是起始偏移量并且`K`是步长。 随着公民不断到达，这个公式会生成对代理指数的遍历，并定期重复，因为所有内容都取模`N`。 

从这次步行中，只有某些特工至少被拜访过一次。 这些是“活跃”的代理人。 关键的结构事实是访问集恰好是循环群模上的一个算术级数`N`，因此它形成一个循环，其大小仅取决于`gcd(K, N)`。 具体来说，不同访问代理的数量是`L = N / gcd(K, N)`。 

每个代理都有一个成本值`M[k]`。 如果代理处于活动状态，则其成本将添加到总成本中。 但目标不仅仅是最小化这个金额。 还有一个惩罚取决于有多少代理保持不活跃状态，因此最终得分结合了活跃代理的总和以及随着增长而增长的惩罚项`N - L`。 

任务是选择`S`和`K`最大限度地减少这一综合成本。 

输入大小最多允许`2 × 10^5`代理。 这立即排除了尝试所有对的任何解决方案`(S, K)`或为每个选择显式地模拟序列，因为这至少是二次或更糟。 甚至`O(N^2)`已经太大了，任何涉及每个候选步骤重新计算子集的事情都是不可行的。 

不明显的困难是，虽然序列定义很简单，但所访问节点的归纳集取决于算术结构（gcd 类），而不是连续的段或前缀。 一个天真的错误是假设访问的代理形成一个连续的块或仅依赖于`K`作为一个数字，这是错误的。 

一些边缘情况暴露了这些陷阱。 如果`K = N`，那么每一步都会返回相同的索引，因此只有一个代理处于活动状态，无论`S`。 如果`K = 1`，访问所有代理，给出`L = N`。 如果`N = 1`，每个选择都会崩溃到同一个代理，并且两个参数都变得无关紧要，但粗心的实现仍然可能除以零`gcd`处理或承担`L ≥ 2`。 

## 方法

 蛮力解释很简单：尝试每个有效的对`(S, K)`，模拟序列，收集所有访问过的代理，计算它们的总和，计算惩罚，并取最小值。 一对的模拟需要`O(N)`在最坏的情况下，在它循环之前，有`O(N^2)`对，导致`O(N^3)`全面的。 即使通过注意周期性来消除冗余，仍然留下太多配置需要枚举。 

转折点是认识到`S`不影响访问哪些索引，仅影响循环开始位置的移位。 访问集完全取决于`K`通过`gcd(K, N)`。 对于固定的`K`，访问集恰好是一个残差类模`g = gcd(K, N)`。 这意味着我们不是选择任意子集，而是将数组划分为`g`不相交的循环，每个循环收集索引`i, i+g, i+2g, ...`。 

所以不要考虑`(S, K)`，我们转向思考`g`，除数`N`。 对于每一个可能的`g`，我们可以确定数组如何分裂成`g`独立循环。 每个循环对应于选择一个起始残基类模`g`，并且该类中的所有节点都会被一起访问。 自从`S`选择起始偏移量，固定的最佳选择`g`就是成本最低的剩余类别。 

这将问题减少到迭代所有除数`N`，按模类对索引进行分组，计算每个类的总和，并使用以下方法评估成本表达式`L = N / g`。 

## 算法演练

 1. 计算所有除数`g`的`N`。 每个除数对应一个可能的值`g = gcd(K, N)`，因此是一个可能的访问结构。 这将问题从选择`K`选择循环结构尺寸。 
2. 对于每个除数`g`, 分区索引`0..N-1`进入`g`按其值模进行分组`g`。 每个组代表一个不同的循环，可以根据情况进行选择`S`。 
3. 对于每组，计算总和`M[i]`为所有人`i`在那个组里。 这表示该残留物类别进入活动周期时的总成本。 
4、为此`g`，选择总和最小的组，因为`S`可以移动起点来选择任意残基类循环。 
5. 计算`L = N // g`。 这是使用此 gcd 结构生成步行时的活动代理数量。 
6. 计算总成本为`min_group_sum + floor(N/2) * (N - L + 1)`。 
7.追踪最好的`g`和最佳残留等级指数。 转换回有效的`(S, K)`通过选择任意配对`K`这样`gcd(K, N) = g`， 例如`K = g`，并选择`S`作为所选残基类别的索引。 

### 为什么它有效

 步行定义为`(S, K)`将索引图划分为通过重复添加确定的循环`K mod N`。 循环结构的特点是`gcd(K, N)`，它固定了循环的数量和大小。 在每个循环结构中，`S`只选择哪个循环处于活动状态，而不选择结构本身。 因此优化超过`(S, K)`简化为选择除数`g`然后选择该分区内的最佳残基类别。 在这些 gcd 引起的分区之外不会发生任何配置，因此枚举除数是详尽的所有可能的行为。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def divisors(n):
    ds = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            ds.append(i)
            if i * i != n:
                ds.append(n // i)
        i += 1
    return ds

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # prefix sums per residue class will be computed on the fly per divisor
    best_cost = float('inf')
    best_s = 0
    best_k = 1

    divs = divisors(n)

    half = n // 2

    for g in divs:
        # compute sums for each residue class mod g
        sums = [0] * g
        for i, val in enumerate(a):
            sums[i % g] += val

        min_sum = min(sums)
        best_class = sums.index(min_sum)

        L = n // g
        cost = min_sum + half * (n - L + 1)

        if cost < best_cost:
            best_cost = cost
            best_s = best_class
            best_k = g

    print(best_s, best_k, best_cost)

if __name__ == "__main__":
    solve()
```代码首先通过除数枚举所有可能的 gcd 结构`N`。 对于每个结构尺寸`g`，它累积按残差类模分组的元素之和`g`。 该分组完全对应于通过步进形成的循环`K`那有`gcd(K, N) = g`。 

的选择`best_class`对应于选择`S`，因为移动起始位置仅选择哪个残基类别是第一个访问的循环。 

一个微妙的实现细节是，重新计算每个除数的余数和给出一个`O(N sqrt N)`解决方案，这是可以接受的`2 × 10^5`在带有紧密循环的Python中。 预先计算每个模类的前缀和是可能的，但这里的复杂性是不必要的。 

## 工作示例

 考虑一个小数组`N = 6`,`M = [5, 2, 5, 1, 3, 5]`。 

我们评估除数`g = 1, 2, 3, 6`。 

为了`g = 2`，残基类别为：

 | 索引 | 0 | 1 | 2 | 3 | 4 | 5 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 中号 | 5 | 2 | 5 | 1 | 3 | 5 |
 | 模 2 组 0 | 5 + 5 + 3 = 13 | 5 + 5 + 3 = 13 | | | | | |
 | 模组 2 组 1 | 2 + 1 + 5 = 8 | | | | | |

 为了这`g`，最好的班级总和是`8`, 给予`L = 6 / 2 = 3`。 

| 克| 最佳班级总和| 左 | 成本|
 | --- | --- | --- | --- |
 | 2 | 8 | 3 | 8 + 3*(6-3+1)=8+12=20 |

 这显示了按残基分组如何将选择问题简化为挑选一个周期。 

另一个例子是`g = 3`:

 团体有：

 - 模 3：(0,3) → 5 + 1 = 6
 - 模 3：(1,4) → 2 + 3 = 5
 - 模 3：(2,5) → 5 + 5 = 10

 最好的是`5`， 和`L = 2`。 

| 克| 最佳班级总和| 左 | 成本|
 | --- | --- | --- | --- |
 | 3 | 5 | 2 | 5 + 3*(6-2+1)=5+15=20 |

 两种配置的成本相同，表明多种最佳结构可以共存。 

这些痕迹证实该算法一致地评估由除数引起的循环分区，并在每个分区中选择最佳的残差类别。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N √N) | O(N √N) | 每个除数都通过扫描一次数组来计算余数和来处理 |
 | 空间| O(N) | 数组存储加上大小为g的临时分组数组|

 除数计数为`N`很小，并且每次传递都是线性的，因此总运行时间保持在限制范围内`2 × 10^5`。 内存使用量是线性的并且由输入数组主导。

 ## 边缘情况

 当`N = 1`, 只有一个除数`g = 1`。 残差类分组包含单个元素，因此算法选择它并计算`L = 1`。 处罚期限变为`floor(1/2) * (1 - 1 + 1) = 0`，输出很简单`M[0]`。 分组逻辑仍然有效，因为模索引正确地减少到单个存储桶。 

什么时候`g = N`，每个残基类恰好包含一个元素。 该算法将每个单独的代理评估为可能的活动单例循环。 最小总和很简单`min(M)`， 和`L = 1`。 这对应于一种极端情况，即步行永远不会移动并且只有一个代理处于活动状态。 

当所有`M[i]`相等，每个残基类别具有相同的总和。 然后，该算法仅根据惩罚项以及实现最大的任何除数进行有效选择`L`变得最优。 这会检查通过残基选择来打破平局并不重要，并且实现不会假设最小类的唯一性。 

如果`N`是素数，唯一的约数是`1`和`N`。 这迫使解决方案精确比较两个结构极端：全周期与孤立节点。 除数枚举中的任何错误都会立即显示在这里，因为中间`g`值不存在，错误的答案通常来自丢失的边缘结构。
