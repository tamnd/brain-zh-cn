 ## 解决方案
 ## 问题理解

 因为每个阀门的容量都是固定的$10^{18}$，阀门永远不会成为瓶颈。 塔中残留的任何水$i$巫师行动后总是可以完全移动到塔中$i+1$。 

这极大地改变了该过程的性质。 而不是去思考$n$单独的塔，我们可以认为水通过一条管道从左到右流动。 

让$a_i$是最初在位置添加的水$i$，并让$b_i$是那里可以生产的最大葡萄酒量。 

当进程到达塔时$i$，发生两件事：

 首先，一定量的水转化为酒，最多$b_i$。 

其次，所有剩余的水继续向右流动。 

每次更新后，我们必须重新计算生产的葡萄酒总量。 

限制才是真正的挑战。 两个都$n$和$q$一样大$5 \cdot 10^5$。 每次更新后都需要模拟整个过程$O(nq)$工作，大致是$2.5 \cdot 10^{11}$最坏情况下的操作。 那是完全不可行的。 

更新仅修改单个位置，这强烈表明我们需要一个支持点更新和快速重新计算答案的数据结构。 

当塔接收的水少于其向导可以处理的水时，就会出现微妙的边缘情况。 

考虑：```
a = [2]
b = [10]
```向导最多可以处理 10 升，但仅存在 2 升。 正确的酒量是 2 杯，而不是 10 杯。 

另一个重要的情况是水在到达后面的塔之前就被耗尽了。```
a = [3, 0]
b = [5, 5]
```1 号塔将全部 3 升转化为葡萄酒。 没有东西到达 2 号塔，所以答案是 3 而不是 8。 

第三种情况是早期的赤字由后来的盈余补偿。```
a = [0, 10]
b = [5, 0]
```1 号塔什么也没产生，因为还不存在水。 然后，塔 2 收到全部 10 升并生产 0 酒，因为它的巫师力量为 0。答案是 0。任何独立处理塔的方法都会错误地计算塔 1 的 5 升。 

## 方法

 蛮力解决方案直接模拟该过程。 

保持当前可用水量。 在塔楼$i$， 添加$a_i$， 转变$\min(\text{water}, b_i)$升入酒中，从水中减去该量，然后移至下一个塔。 

这个模拟是正确的，因为它完全遵循过程的规则。 其成本为$O(n)$每个查询。 和$5 \cdot 10^5$更新，最坏的情况变成$O(nq)$，太大了。 

为了更快地获得某些东西，我们需要用数学方法描述这个过程。 

让$D_i$是塔后剩余的水量$i$。 

最初：$$D_0 = 0$$在塔楼$i$，我们首先添加$a_i$升，然后取出最多$b_i$升。 

递归变为$$D_i = \max(0, D_{i-1} + a_i - b_i).$$定义$$d_i = a_i - b_i.$$然后$$D_i = \max(0, D_{i-1} + d_i).$$这是经典的反射前缀和递归。 

让$$S_i = \sum_{j=1}^{i} d_j.$$标准身份给出$$D_n = S_n - \min_{0 \le k \le n} S_k.$$最初存在的水总量为$$A = \sum a_i.$$在最后一座塔之后，正好$D_n$升仍未处理。 每隔一升就变成酒，所以$$W = A - D_n.$$将公式代入$D_n$,$$W = A - \Bigl(S_n - \min_{0 \le k \le n} S_k\Bigr).$$现在问题变成：

 维护一个数组$d_i=a_i-b_i$在点更新下，同时支持：$$S_n=\sum d_i$$和$$\min_{0\le k\le n} S_k.$$这正是存储线段和和最小前缀和的线段树可以做的事情。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n)$每次更新 |$O(1)$| 太慢了 |
 | 最佳 |$O(\log n)$每次更新 |$O(n)$| 已接受 |

 ## 算法演练

 ### 1.构建差异数组

 定义$$d_i = a_i - b_i.$$还维护$$A = \sum a_i.$$最终答案仅取决于$A$，总和$d$，以及最小前缀和$d$。 

### 2.构建线段树

 对于每个段存储两个值。 

第一个值是段总和。 

第二个值是该段内的最小前缀和。 

对于包含值的叶子$x$,$$\text{sum}=x,\qquad \text{minPref}=x.$$### 3. 合并两个子项

 假设左子存储$$(\text{sum}_L,\text{minPref}_L)$$和合适的儿童商店$$(\text{sum}_R,\text{minPref}_R).$$然后$$\text{sum} = \text{sum}_L+\text{sum}_R.$$组合段的前缀要么完全保留在左子节点内，要么消耗整个左子节点并继续进入右子节点。 因此$$\text{minPref} = \min\bigl( \text{minPref}_L, \text{sum}_L+\text{minPref}_R \bigr).$$### 4. 处理更新

 当位置$p$变化：

 更新$A$通过添加$x-a_p$。 

代替$$a_p \leftarrow x, \qquad b_p \leftarrow y.$$重新计算$$d_p = a_p-b_p$$并更新相应的线段树叶子。 

### 5.恢复答案

 让根包含：$$\text{totalSum}=S_n$$和$$\text{minPref}.$$包括空前缀的最小前缀是$$m = \min(0,\text{minPref}).$$然后$$D_n = S_n - m.$$最后，$$W = A - D_n.$$输出$W$。 

### 为什么它有效

 复发$$D_i=\max(0,D_{i-1}+d_i)$$跟踪塔后剩余的水量$i$。 

经典表示法$$D_i=S_i-\min_{0\le k\le i}S_k$$表明整个过程仅取决于最终的前缀和以及沿途遇到的最小前缀。 

线段树在点更新下准确地维护这些数量。 由于每一升最初的水要么变成酒，要么保留在$D_n$，酒的量总是$$A-D_n.$$因此，每个报告的答案都等于原始模拟的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.sum = [0] * (4 * self.n)
        self.mn = [0] * (4 * self.n)
        self._build(1, 0, self.n - 1, arr)

    def _build(self, idx, l, r, arr):
        if l == r:
            self.sum[idx] = arr[l]
            self.mn[idx] = arr[l]
            return

        mid = (l + r) // 2
        self._build(idx * 2, l, mid, arr)
        self._build(idx * 2 + 1, mid + 1, r, arr)
        self._pull(idx)

    def _pull(self, idx):
        left = idx * 2
        right = left + 1

        self.sum[idx] = self.sum[left] + self.sum[right]
        self.mn[idx] = min(
            self.mn[left],
            self.sum[left] + self.mn[right]
        )

    def update(self, pos, val):
        self._update(1, 0, self.n - 1, pos, val)

    def _update(self, idx, l, r, pos, val):
        if l == r:
            self.sum[idx] = val
            self.mn[idx] = val
            return

        mid = (l + r) // 2

        if pos <= mid:
            self._update(idx * 2, l, mid, pos, val)
        else:
            self._update(idx * 2 + 1, mid + 1, r, pos, val)

        self._pull(idx)

    def total_sum(self):
        return self.sum[1]

    def min_prefix(self):
        return self.mn[1]

def main():
    n, q = map(int, input().split())

    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    _ = input()  # c is irrelevant in easy version

    d = [a[i] - b[i] for i in range(n)]
    total_a = sum(a)

    seg = SegTree(d)

    ans = []

    for _ in range(q):
        p, x, y, z = map(int, input().split())
        p -= 1

        total_a += x - a[p]

        a[p] = x
        b[p] = y

        new_d = x - y
        seg.update(p, new_d)

        total_sum = seg.total_sum()
        mn_pref = min(0, seg.min_prefix())

        remaining = total_sum - mn_pref
        wine = total_a - remaining

        ans.append(str(wine))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    main()
```该实现直接反映了数学推导。 

数组`d`商店$a_i-b_i$。 每次更新只影响一个位置，因此线段树上的点更新就足够了。 

根的`sum`场是$S_n$。 根的`mn`field 是最小非空前缀和。 由于公式也允许空前缀，所以我们取`min(0, seg.min_prefix())`。 

价值```
remaining = total_sum - mn_pref
```正是$D_n$，水经过最后的塔后离开。 

那么答案就是```
wine = total_a - remaining
```这是节约用水的结果。 

所有算术都使用 Python 整数，因此$10^{18}$值不构成溢出风险。
