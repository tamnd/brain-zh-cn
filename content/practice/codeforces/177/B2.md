 ## 解决方案
 ## 问题理解

 我们从`n`鹅卵石。 

无论如何，如果我们目前有`x`鹅卵石，我们必须将它们排列成`a`长度相等的行`b`， 在哪里`a > 1`和`x = a · b`。 创建行后，我们仅保留一行并丢弃所有其他行。 鹅卵石的数量变为`b`。 

如果我们将卵石计数的序列表示为`c₁ = n, c₂, c₃, ..., cₖ = 1`那么下一个值必须是前一个值的真除数，因为`cᵢ = a · cᵢ₊₁`和`a > 1`。 

游戏的得分是该序列中所有值的总和。 我们必须最大化这个金额。 

输入包含单个整数`n`, 直至`10^9`。 这样的限制立即排除了对所有数字的任何动态编程，直到`n`，并且还排除了探索大型状态空间。 一个执行粗略的解决方案`O(√n)`工作很容易足够快，而接近`O(n)`不是。 

最重要的观察是，每一步都会用它的真因数之一替换当前数字。 不同的选择可能导致不同的序列长度和不同的总和。 

一些边缘情况值得关注。 

考虑`n = 2`。 

唯一合法的安排是`2 = 2 · 1`，所以顺序是：`2 → 1`答案是`3`。 

假设每个数字都有一个大于 1 的非平凡除数的粗心实现在这里会失败。 

考虑`n = 8`。 

可能的路径包括：`8 → 4 → 2 → 1`，总和 = 15`8 → 2 → 1`，总和 = 11`8 → 1`，总和 = 9

 最好的举措并不是最大程度的削减。 我们希望保持当前值尽可能大，因为每个访问过的数字都会对总和做出贡献。 

考虑`n = 13`。 

由于 13 是素数，唯一可能的移动是：`13 → 1`答案是`14`。 

任何假设复合因式分解步骤始终存在的解决方案都会产生不正确的结果。 

## 方法

 强力解决方案会将每个除数选择视为分支决策。 从当前值`x`，我们可以枚举所有真因数`d < x`，递归计算从以下位置开始的最佳分数`d`，并取最大值。 

这是正确的，因为每个合法游戏都对应于该递归树中的一条路径。 不幸的是，尽管`n ≤ 10^9`，递归探索许多重复状态和许多可能的除数链。 虽然对于这个特定限制来说状态空间并不是很大，但它比必要的要复杂得多。 

关键的观察来自于检查一个动作的实际作用。 

假设当前号码是`x`。 我们选择因式分解`x = a · b`和`a > 1`，并保留`b`。 

自从`b = x / a`，最大化直接贡献意味着`a`尽可能小。 的最小可能值`a`是最小的质因数`x`。 

让`p`是 的最小质因数`x`。 

那么最大可能的下一个状态是`x / p`。 

由于每个未来分数都是非负的，因此选择更大的下一个状态永远不会有坏处。 如果一个除数链从比另一个除数链更大的值开始，它已经立即获得额外分数，并且至少具有同样多的未来潜力。 

这意味着最佳策略始终是：

 来自`x`，除以它的最小质因数。 

对于素数，不存在非平凡除数，因此唯一的移动是直接`1`。 

游戏变得确定性。 我们反复除以最小的质因数，并将每个访问过的值添加到答案中。 

要实现这一点，我们只需要重复查找当前数字的最小质因数即可。 自从`n ≤ 10^9`, 试分割至`√x`就足够了。

 ## 算法演练

 1. 阅读`n`。 
2. 初始化答案`n`，因为起始值始终包含在分数中。 
3. 当当前值大于`1`，找到它的最小质因数。 
4. 如果试除时没有找到约数，则当前值为素数。 唯一合法的下一个状态是`1`。 添加`1`到答案并停止。 
5. 否则，将当前值除以其最小素因数。 
6. 将新值添加到答案中。 
7. 重复直到该值变为`1`。 

步骤 5 是最佳的原因是除以最小的质因数会产生最大可能的真除数。 由于所有未来的贡献都是正的，因此保持尽可能大的数量可以使总分最大化。 

### 为什么它有效

 对于任何当前值`x`，每一个合法的举动都会选择一个因素`a > 1`并移动到`x/a`。 

让`p`是 的最小质因数`x`。 每个有效因素`a`满足`a ≥ p`， 因此`x/a ≤ x/p`。 

所以`x/p`是最大可能的下一个状态。 

假设另一个动作选择了更小的下一个状态`y < x/p`。 直接的贡献已经更糟了，因为`y`较小。 未来的贡献无法弥补这种损失，因为从较大的数字开始总是留下至少同样多的可用动作，并且永远不会减少任何未来的分数。 

因此每个最优解必须选择`x/p`。 Applying the same argument after each move proves that repeatedly dividing by the smallest prime factor produces the unique optimal score.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def smallest_prime_factor(x):
    d = 2
    while d * d <= x:
        if x % d == 0:
            return d
        d += 1
    return x  # x is prime

def solve():
    n = int(input())

    ans = n
    cur = n

    while cur > 1:
        spf = smallest_prime_factor(cur)

        if spf == cur:
            ans += 1
            break

        cur //= spf
        ans += cur

    print(ans)

solve()
```辅助函数使用试除法找到最小素因数。 如果在到达之前没有找到除数`√x`，该数字是素数，并且该函数返回该数字本身。 

主循环维护当前的卵石数量。 每次迭代通过除以最小素因数来执行最佳移动。 结果值会添加到答案中，因为序列中的每个状态都会对分数产生影响。 

基本情况需要特殊处理。 当当前值为素数时，下一个也是最终状态是`1`。 我们添加最后的`1`并终止。 

所有算术都适合 64 位整数。 当许多大的中间值累积时，就会出现最大答案，但它仍然远低于 Python 的限制。

 ## 边缘情况

 ### 初始输入

 输入：```
13
```最小质因数搜索找不到除数`√13`，所以 13 是质数。 该算法添加了最终状态`1`并停止。 

顺序：`13 → 1`回答：`13 + 1 = 14`这可以正确处理没有可用复合移动的数字。 

### 最小有效输入

 输入：```
2
```该值已经是素数了。 该算法立即执行最终转换：`2 → 1`回答：`3`不会尝试除以不存在的较小素因数。 

### 素数的幂

 输入：```
8
```该算法重复除以 2：`8 → 4 → 2 → 1`回答：`8 + 4 + 2 + 1 = 15`这表明最优路径可能包含几个步骤，并且贪婪地保持每个阶段的最大可能除数自然会发现它。 

### 大合数

 输入：```
1000000000
```该算法重复除以最小素因数，多次迭代时该素因数为 2：`1000000000 → 500000000 → 250000000 → ...`每一步都保留最大的合法下一个值。 数量迅速减少，总工作量仍然受到试除法的限制，最多可达当前值的平方根。 最终答案是在要求的限度内计算出来的。
