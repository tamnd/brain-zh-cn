 ## 解决方案
 ## 问题理解

 We are given a square matrix of size _n_ × _n_, where _n_ is guaranteed to be an odd number. 矩阵的每个元素都是非负整数。 任务是计算“好”元素的总和，这些元素被定义为至少属于这四个类别之一的元素：主对角线、次对角线、中间行或中间列。 The middle row and column are uniquely defined because _n_ is odd. 输出是表示所有这些元素之和的单个整数，即使每个元素属于多个类别，也仅对每个元素进行一次计数。 

假设 _n_ 可以达到 101，则矩阵元素总数最多为 10201。任何复杂度为 O(n²) 或更小的算法都可以在 2 秒的时间限制下轻松执行。 This rules out the need for advanced optimization techniques; the problem is primarily about careful indexing to avoid double-counting elements that belong to multiple "good" sets.

 非明显边缘情况包括最小矩阵 (1×1)，其中每个元素都很好，以及较大矩阵，其中中心元素位于两条对角线以及中间行和列。 例如，在 3×3 矩阵中：```
1 2 3
4 5 6
7 8 9
```所有元素都很好，包括中心元素 5，它属于所有四个类别。 如果幼稚的实现独立处理每个类别而不跟踪重叠，则可能会意外地对其进行多次求和。 

## 方法

 蛮力方法很简单：迭代矩阵的每个元素，检查它是否属于四个类别中的任何一个，如果属于则求和。 这是正确的，但需要仔细处理以避免重复计算，特别是在矩阵的中心。 

最佳解决方案的关键观察是，因为 _n_ 是奇数，所以我们可以直接识别属于每个类别的索引。 The middle row and column both have index`n // 2`使用从零开始的索引。 主对角线具有行索引等于列索引的索引。 次对角线具有索引，其中行索引加上列索引等于`n - 1`。 我们可以迭代整个矩阵并添加一个元素（如果它满足这四个条件中的任何一个）。 因为条件集涵盖了所有可能的好元素，并且矩阵的大小很小，所以这是高效的并且避免了复杂的数据结构。

 ## 算法演练

 1. 从输入中读取整数_n_。 这定义了方阵的大小。 
2. 读取接下来的 _n_ 行来构建矩阵。 每行包含 _n_ 个整数。 
3. 计算中间索引`mid = n // 2`。 该索引标识中间行和中间列。 
4. 初始化变量`total = 0`积累良好元素的总和。 
5. Iterate over each element of the matrix using two nested loops: the outer loop for rows`i`和列的内循环`j`。 
6. 对于位置处的每个元素`(i, j)`，检查是否良好。 如果满足以下任何条件，则该元素是好的：`i == j`（主对角线），`i + j == n - 1`（次对角线），`i == mid`（中排），`j == mid`（中栏）。 
7. 如果该元素是好的，则将其值添加到`total`。 
8. 迭代完所有元素后，打印`total`。 

不变的是我们只将每个元素添加一次。 由于我们只检查条件并为每个元素添加一次，因此即使一个元素满足多个条件，它也会只求和一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
matrix = [list(map(int, input().split())) for _ in range(n)]

mid = n // 2
total = 0

for i in range(n):
    for j in range(n):
        if i == j or i + j == n - 1 or i == mid or j == mid:
            total += matrix[i][j]

print(total)
```该代码首先使用列表理解读取矩阵，并将每一行映射为整数。 它计算一次中间索引，然后使用嵌套循环迭代所有元素。 好元素的条件直接实现定义，确保没有元素被添加两次。 使用`i == j`和`i + j == n - 1`正确识别两条对角线，并且`i == mid`和`j == mid`捕获中心行和列。
