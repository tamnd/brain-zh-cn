 ## 解决方案
 ## 问题理解

 我们选择一个正整数值$x$，代表 Smart Beaver 所装“每个手提箱的礼物”数量。 手提箱总数是固定的：对于每个星球$i$，他正好携带$a_i$行李箱，所以行李箱总数是所有行李箱的总和$a_i$。 由于每个行李箱都装有$x$呈现，呈现总数呈线性关系$x$， 具体来说$x \cdot \sum a_i$。 

这次旅行是一系列行星的旅行。 在星球上$i$海狸以一种非常有条理的方式度过时间：第一天总是“自由”的一天，没有送礼物。 从第二天开始，他每天都准确地给出$b_i$呈现给每一位$b_i$公民，所以他消费$b_i^2$每天都有礼物。 他继续下去，直到他无法再完全提供第二天的礼物，这意味着他在最后一天停止，剩余的礼物至少仍然存在$b_i^2$。 

因此，每个行星贡献的天数仅取决于有多少个完整的“块”大小$b_i^2$适合其分配的礼物，加上抵达的第一天。 总旅行时间是这些每个行星持续时间的总和，我们想要计算有多少个正整数$x$使总时间准确$c$。 

这些限制很重要，因为$n$可以达到$10^4$和值高达$10^9$，所以任何尝试所有的解决方案$x$或模拟每个候选人是不可能的。 我们评估的函数是单调的$x$: 增加$x$永远不会减少度过的天数，因为更多的礼物只能延长或保留赠送礼物的能力。 这种单调性是允许二分搜索的关键结构。 

当行星在第一天之后贡献零礼物日时，就会出现边缘情况。 如果$a_i \cdot x < b_i^2$，那么海狸甚至无法在该星球上完成单个礼物日，因此停留时间恰好为 1 天。 这种阈值行为是幼稚浮点或整数除法推理经常失败的地方。 

另一个微妙的情况是当$a_i = 0$。 然后就没有礼物可用了，所以无论怎样，地球总是只贡献 1 天$x$。 任何除以的方法$a_i$会在这里失败。 

## 方法

 直接的方法是固定一个值$x$，计算所有行星的总天数，并检查它是否等于$c$。 对于每个星球，我们计算我们可以维持多少个完整的礼物日。 因为每天的花费$b_i^2$礼物，我们从$a_i x$呈现，第一个之后的额外天数是$\left\lfloor \frac{a_i x}{b_i^2} \right\rfloor$。 对所有行星求和就得出总行程长度。 

这可以正常工作，但需要迭代所有可能的$x$。 答案空间是无限的，但实际上我们需要搜索到函数超出的点$c$。 由于该函数大致线性增长$x$，对大范围进行强力扫描，例如$10^9$是不可行的。 

关键的观察结果是，总天数是$x$是单调非减的。 每学期$\left\lfloor \frac{a_i x}{b_i^2} \right\rfloor$仅当$x$跨越某些阈值。 这种结构允许我们二进制搜索最小和最大$x$准确地产生$c$天，然后计算整数范围。 

我们将问题简化为寻找单调函数$f(x)$并计算所有整数，其中$f(x) = c$，这就变成了寻找区间的边界，其中$f(x) \le c$和$f(x) < c+1$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解 x | O(maxX·n) | O(maxX·n) | O(1) | O(1) | 太慢了|
 | 对 x | 进行二分查找 O(n log X) | O(n log X) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们定义一个函数$f(x)$计算总行程持续时间。 

1.对于固定的$x$，计算所有行星的总天数。 每个行星贡献 1 个基准日，加上$\left\lfloor \frac{a_i x}{b_i^2} \right\rfloor$额外的天数。 这模拟了“第一天免费，然后重复赠送周期”的结构。 
2. 实现一个功能`calc(x)`迭代所有行星并累积该贡献。 我们必须使用 128 位安全算术或 Python 整数，因为$a_i x$可以达到$10^{18}$。 
3. 二分查找最小$x$这样`calc(x) >= c`。 这给出了行程至少为的第一个值$c$好几天。 
4. 二分查找最小的$x$这样`calc(x) > c`。 这给出了行程严格超过的第一个值$c$天。 
5.答案是整数的个数$x$在区间内$[L, R)$， 在哪里$L$是第一个位置至少$c$天和$R$是第一个位置超过$c$天。 如果$L > R - 1$，答案为零。 

一个特殊情况是当$calc(1) > c$，意味着即使是最小的$x$超出目标； 那么不存在解决方案。 

### 为什么它有效

 功能$f(x)$是单调非减的，因为增加$x$增加或保留$a_i x$，因此永远不会减少任何楼层划分项。 因此，集合$x$满意的$f(x) = c$始终是连续的整数段（可能为空）。 二分查找正确地识别了该段的边界，因此计算其长度即可给出有效值的准确数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, c = map(int, input().split())
a = []
b = []

for _ in range(n):
    ai, bi = map(int, input().split())
    a.append(ai)
    b.append(bi)

def calc(x):
    res = 0
    for i in range(n):
        res += 1
        if a[i] == 0:
            continue
        res += (a[i] * x) // (b[i] * b[i])
    return res

def f_leq(x):
    return calc(x) <= c

def f_lt(x):
    return calc(x) < c

def binary_search_first_true(check):
    lo, hi = 1, 10**18
    ans = hi + 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if check(mid):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1
    return ans

L = binary_search_first_true(lambda x: calc(x) >= c)
R = binary_search_first_true(lambda x: calc(x) > c)

if L > R - 1:
    print(0)
else:
    print(R - L)
```这`calc(x)`函数直接实现了每个星球的贡献公式。 乘法在除法之前完成，Python 的大整数可以防止固定宽度语言中出现的溢出问题。 

我们执行两次二分搜索：一次用于第一个$x$至少达到$c$，第一个超过的$c$。 答案是所得整数区间的大小。 

一个常见的陷阱是忘记每个星球至少有一天会做出贡献，即使没有送出礼物。 该基本术语必须始终添加在二分搜索逻辑之前。

 ## 边缘情况

 一个关键的边缘情况是当某些$a_i = 0$。 对于这样一个星球，贡献总是正好 1 天，无论$x$，因为从来没有送过礼物。 该算法通过跳过乘法来明确处理这个问题$a_i = 0$，确保不会出现分割伪影。 

另一个边缘情况是当$c$小于可能的最短行程时间。 由于每个行星至少贡献一天，因此最小总数为$n$。 如果$c < n$，两个二分查找都返回空范围，最终答案自然为零。 

最后一个微妙的情况是$x$非常大。 虽然$x$从概念上讲可以达到$10^{18}$，二分查找可以安全地限制它，因为一旦$calc(x)$超过$c$，进一步的增长是无关紧要的。 即使在最大输入范围下，这也可以防止溢出并保持计算稳定。
