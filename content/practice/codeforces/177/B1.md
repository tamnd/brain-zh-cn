 ## 解决方案
 ## 问题理解

 游戏开始于`n`鹅卵石。 每次移动，我们都必须将当前的卵石数量分成`a`大小相等的行`b`， 在哪里`a > 1`和`a * b = current`。 

创建行后，我们仅保留一行并丢弃所有其他行。 这意味着序列中的下一个数字变为`b`。 

如果当前值为`x`，下一个值必须是`x`， 因为`x = a * b`和`a > 1`。 当我们到达时游戏结束`1`。 

分数是过程中遇到的所有值的总和，包括起始值和最终值`1`。 我们必须最大化这个金额。 

输入由单个整数组成`n`， 和`n ≤ 10^9`。 如此小的输入大小可能看起来微不足道，但该值本身足够大，以至于任何探索所有可能的游戏序列的方法都是不可行的。 可能的除数链的数量快速增长，因此暴力枚举并不实用。 

关键的挑战是了解每一步应选择哪个除数以使最终总和最大化。 

一些边缘情况很容易被忽略。 

考虑`n = 2`。 

唯一有效的排列是两行一颗卵石，因此顺序是：`2 → 1`答案是`3`。 

假设每个数字都有一个大于 1 的非平凡真除数的解决方案在这里会失败。 

考虑`n = 8`。 

可能的链条包括：`8 → 4 → 2 → 1`， 分数`15`

`8 → 2 → 1`， 分数`11`

`8 → 1`， 分数`9`最佳选择不是最小的除数。 保持最大可能的真除数会得到更大的分数。 

考虑一个素数，例如`n = 13`。 

不存在除数，除了`1`，所以游戏必须立即变成：`13 → 1`答案是`14`。 

只搜索大于一的除数的粗心实现可能会错误地陷入困境。 

## 方法

 一种自然的暴力方法是将游戏视为对所有可能的除数链的搜索。 

对于当前值`x`, 每个真因数`d`的`x`是一个有效的下一个状态。 我们可以递归计算`best(x) = x + max(best(d))`超过所有真因数`d`。 

这是正确的，因为每个有效的游戏都对应于该除数图中的一条路径，并且递归探索了所有可能性。 

问题是可能的链的数量可能会变得很大。 虽然`n ≤ 10^9`，对所有除数选择的递归搜索是不必要的，并且比需要的要复杂得多。 

为了找到最佳策略，我们应该检查一步棋的真正作用。 

假设当前值为`x`。 任何有效的下一个值必须是`x`。 

如果我们比较两种可能的举动`d1 < d2`，然后选择`d2`立即为分数贡献更大的金额。 它还为我们留下了更多的数字，可以用来累积未来的分数。 

这表明，在所有真因数中，我们应该始终选择最大的一个。 

一个数的最大真因数是多少？ 

如果`p`是最小的质因数`x`，则最大真因数为：$$\frac{x}{p}$$例如：`12 → 6`

`18 → 9`

`45 → 15`做出这一举动后，完全相同的推理再次适用。 

这给出了一个非常简单的最优策略：重复除以最小的质因数。 

这个过程一直持续到我们到达`1`，并将每个中间值添加到答案中。 

自从`n ≤ 10^9`，通过试除找到最小的质因数`√n`够快了。

 | ---| ---| ---| ---|
 | 蛮力 | 除数选择数量呈指数增长 | O(深度) | 太慢了|
 | 最佳| O(√n) | O(√n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取初始值`n`。 
2. 初始化答案`n`，因为起始数字是分数的一部分。 
3. 当当前值大于`1`，找到它的最小质因数。 
4. 如果找不到约数，则当前数是质数。 它唯一有效的下一个状态是`1`。 
5. 否则，将当前数字除以它的最小质因数。 这会产生最大可能的真除数。 
6. 将新值添加到答案中。 
7. 重复直到当前值变为`1`。 
8. 输出累计答案。 

### 为什么它有效

 For any current value`x`，每个合法的下一个状态都是`x`。 

让`m`是 的最大真因数`x`。 所有其他合法的举动都会导致一些除数`d < m`。 

选择`m`立即增加比选择更多的分数`d`。 此外，所有未来值均可从`d`至多是`d`，而未来的值可以从`m`从较大的数字开始。 更换`d`经过`m`不能降低总分。 

因此，最优解必须始终选择最大的真因数。 

的最大真因数`x`通过除法得到`x`由其最小素因子。 在每一步重复这种贪婪的选择会产生最佳除数链，从而产生最大可能的分数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def smallest_prime_factor(x):
    d = 2
    while d * d <= x:
        if x % d == 0:
            return d
        d += 1
    return x

def solve():
    n = int(input())

    ans = n
    cur = n

    while cur > 1:
        p = smallest_prime_factor(cur)
        cur //= p
        ans += cur

    print(ans)

if __name__ == "__main__":
    solve()
```变量`ans`存储跑步分数。 

对于每个当前值，我们找到其最小素因数。 除以该因子会产生最大的真除数，这是最佳的下一步行动。 

当当前值为素数时，返回的最小素因数就是数字本身。 除以它给出`1`，完全符合素数只能直接移动到的游戏规则`1`。 

所有算术都适合 64 位整数。 重复除以时会出现最大可能的答案`2`，即使这样，总和也低于`2n`，这远远小于Python的限制。

 ## 边缘情况

 考虑最小输入：```
2
```最小的质因数是`2`，所以顺序是：`2 → 1`答案变成：`2 + 1 = 3`该算法自然地处理这个问题，因为素数除以它本身会产生`1`。 

考虑一个素数：```
13
```除数搜索未找到以下因子`√13`，所以最小的质因数取为`13`。 

序列变为：`13 → 1`答案是：`13 + 1 = 14`没有特殊情况需要。 

考虑一个素数幂：```
8
```该算法重复除以最小素因数：`8 → 4 → 2 → 1`分数是：`8 + 4 + 2 + 1 = 15`这证实了重复取最大真除数会产生最优链。 

考虑具有多个质因数的合数：```
12
```该算法产生：`12 → 6 → 3 → 1`分数：`12 + 6 + 3 + 1 = 22`替代链例如`12 → 4 → 2 → 1`只给出`19`。 最大真除数的贪心选择严格来说更好，说明了正确性论证。
