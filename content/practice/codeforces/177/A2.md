 ## 解决方案
 ## 问题理解

 We are given a square matrix of size _n_×_n_, where _n_ is guaranteed to be odd. 矩阵的每个单元格包含一个非负整数。 任务是对该矩阵的“好”元素求和。 An element is considered good if it lies on the main diagonal, the secondary diagonal, the middle row, or the middle column. Since the matrix is odd-sized, the middle row and middle column are well-defined: they are the row and column exactly in the center.

 输入给出 _n_ 后跟矩阵行。 The output is a single integer: the sum of all good elements. 由于某些元素可以多次计数（例如，中心单元格位于对角线和中间行/列），因此我们只需对每个单元格求和一次。 

这些限制是相当可控的。 当 _n_ 达到 101 时，迭代每个元素是可行的，因为 101×101 只是 10201 次操作，这对于 2 秒限制下的现代处理器来说是微不足道的。 不存在隐藏的性能缺陷； 正确性和仔细的索引是主要关注的问题。 

当 _n_ 最小（_n_ = 1）时，就会出现边缘情况。在这种情况下，单个元素是整个矩阵，应该只计数一次。 Another subtlety is avoiding double-counting the center element. 例如，在 3×3 矩阵中，中心元素属于两条对角线、中间行和中间列，但它应该只对总和贡献一次。 

## 方法

 蛮力法很简单：迭代矩阵中的每个单元格，检查它是否属于四个类别（主对角线、次对角线、中间行、中间列）中的任何一个，然后求和。 这种方法之所以有效，是因为 _n_ 很小。 除了存储矩阵之外，时间复杂度为 O(n²)，空间复杂度为 O(1)。 

稍微更优化的方法是预先计算好行和列的索引：中间行索引、中间列索引，然后仅迭代这些索引。 然而，由于我们还必须包括对角线元素，这些元素可能无法仅通过这些行/列索引来完全捕获，因此对于这个问题的大小来说，增益可以忽略不计。 The simplest, clearest solution is to iterate over the matrix and use a conditional check for good cells.

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n²) | 已接受 |
 | 优化索引 | O(n²) | O(n²) | 已接受但没有必要 |

 ## 算法演练

 1. Read _n_, the size of the matrix, and the matrix elements into a 2D list. 这是对输入的直接解析。 
2. 将中间行和中间列索引确定为`mid = n // 2`。 对于奇数_n_，整数除法可以正确识别中心。 
3. 初始化变量`total`积累良好元素的总和。 
4. 迭代每个单元格`(i, j)`矩阵的。 对于每个单元格，检查是否`i == j`（主对角线），`i + j == n - 1`（次对角线），`i == mid`（中行），或`j == mid`（中栏）。 
5. 如果单元格满足这些条件中的任何一个，则将其值添加到`total`。 重复计数不需要特殊处理，因为条件是 OR：任何匹配条件都会触发单个加法。 
6. 迭代完所有单元格后，打印`total`。 

关键的见解是，在所有好的标准中使用简单的 OR 条件可确保每个单元格都被精确计数一次，而不管类别是否重叠。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
matrix = [list(map(int, input().split())) for _ in range(n)]

mid = n // 2
total = 0

for i in range(n):
    for j in range(n):
        if i == j or i + j == n - 1 or i == mid or j == mid:
            total += matrix[i][j]

print(total)
```该代码将矩阵读入内存并在双循环中计算总和。 中的 OR 条件`if`语句优雅地捕获了所有好的元素，包括对角线和中间行/列，而无需多次计算任何元素。

def run(inp: str) -> str:

        for j in range(n):

 ## 边缘情况

 对于 1×1 矩阵，中心元素是唯一的元素。 该算法检查所有四个条件，全部为真，但由于每次迭代仅发生一次加法，因此总和是正确的：42。对于较大的奇数矩阵，中心元素出现在多个好类别中，但 OR 条件确保它只计算一次。 该算法对于重复计数、最小输入和标准奇数大小的矩阵具有鲁棒性。
