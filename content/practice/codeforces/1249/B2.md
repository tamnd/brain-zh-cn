 ## 解决方案
 ## 问题理解

 我们有一个系统，每个孩子最初持有一本独特的书，每天每本书都会根据排列传递给另一个固定的孩子。 一天之后，每本书都会移动一次； 两天后，它又按照同样的规则移动，依此类推。 

对于每个孩子，我们追踪的不是孩子本身，而是原本属于他们的书。 问题是：从第 0 天开始，经过多少天，该特定书籍首次回到其原始所有者的手中。 

关键的观点是将排列视为有向图，其中每个节点只有一个出边。 每个节点恰好指向另一个节点，并且由于它是一种排列，因此每个节点也恰好有一个传入边。 该结构完全分解为不相交的循环。 

这些约束很重要，因为所有查询的节点总数最多为 2 · 10^5。 任何模拟日常运动的解决方案在最坏的情况下都可能需要 O(n^2)，这远远超出了限制。 每个查询都需要线性的，最好是 O(n)，因为每个节点必须至少处理一次。 

一个幼稚的陷阱是独立模拟每个孩子的运动。 例如，在长度为 10^5 的循环中，逐步跟踪一本书已经花费了 10^5，并且对所有节点执行此操作会增加不必要的工作。 

另一个微妙的问题是误解方向。 书籍的移动遵循排列向前进行，但我们被问到原始书籍何时返回其原点，这对应于排列图中完成一个完整的循环。 

## 方法

 一个蛮力的想法是逐步模拟每个起始节点的时间。 对于固定节点 i，我们重复应用排列来查看其书本的去向，直到它返回到 i。 在最坏的情况下，每个节点需要 O(n) 步，并且对所有节点执行此操作会导致 O(n^2)。 当 n 达到 2·10^5 时，这变得不可行。 

关键的观察结果是排列分解为不相交的循环。 一旦进入一个循环，该循环中的每个节点都共享相同的返回时间：循环的长度。 这是因为应用排列会重复旋转循环内的位置，并且节点第一次返回自身正好是在一次完整旋转之后。 

因此，问题简化为查找有向图中的所有环，其中每个节点的出度为 1，并为每个节点分配其环的长度。 

这可以通过将节点标记为未访问并沿着排列执行遍历直到我们命中已访问的节点或关闭循环来完成。 循环中遇到的每个节点都被分配相同的值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（每节点模拟）| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 循环分解| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 维护一个所有节点都初始化为 false 的访问数组。 这可以防止重新处理已经属于已发现循环的节点。 
2. 从 1 到 n 迭代每个节点 i。 如果已经访问过，则跳过它，因为它属于先前处理的循环。 
3. 开始按照 i 的排列，将路径存储在临时列表中。 继续从当前节点x移动到p[x]，直到到达访问过的节点或返回到当前路径中的节点。 
4. 如果我们在当前路径中检测到先前未访问过的循环，则通过测量从该节点第一次出现到路径末尾的段来确定其长度。 该段恰好对应于一个周期。 
5. 为该循环段中的每个节点分配循环长度。 
6. 将循环中的所有节点标记为已访问，并继续处理下一个未访问的节点。

这种方法之所以高效，是因为每个节点都只被附加到路径一次并被分配一次。 

### 为什么它有效

 排列图的每个连通分量都是一个简单的有向循环。 从任意节点开始并重复应用排列，最终在恰好循环长度后返回到起始节点。 由于循环中的每个节点在旋转下都是对称的，因此该循环中所有节点的返回时间是相同的。 该算法显式地重建这些循环并一致地分配它们的长度，因此没有节点可以接收到不正确的值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        n = int(input())
        p = [0] + list(map(int, input().split()))
        visited = [False] * (n + 1)
        ans = [0] * (n + 1)

        for i in range(1, n + 1):
            if visited[i]:
                continue

            path = []
            cur = i

            while not visited[cur]:
                visited[cur] = True
                path.append(cur)
                cur = p[cur]

            cycle_start_index = 0
            for idx, node in enumerate(path):
                if node == cur:
                    cycle_start_index = idx
                    break

            cycle_nodes = path[cycle_start_index:]
            cycle_len = len(cycle_nodes)

            for node in cycle_nodes:
                ans[node] = cycle_len

        print(*ans[1:])

if __name__ == "__main__":
    solve()
```该实现通过沿着未访问的节点行走来遵循循环发现。 每个节点都被添加到路径一次，当我们检测到已返回到已处理的节点时，我们识别路径内的循环部分。 然后将循环长度分配给该循环中的所有节点。 

一个微妙的一点是，在进入节点时立即标记已访问的节点是安全的，因为每个节点都只有一个传出边缘。 即使我们后来遇到循环边界，路径仍然包含正确顺序的所有节点，使我们能够切出循环段。

 ## 边缘情况

 像这样的单元素循环`p[i] = i`处理得很自然，因为遍历在访问该节点一次后立即停止，产生的循环长度为 1。算法将 1 分配给该节点，与一天后该书已归其所有者这一事实相匹配。 

通过收集整个路径直到再次到达起始节点来处理完整排列循环，其中所有节点形成一个循环。 循环提取步骤正确地将完整路径分割成单个段，确保每个节点接收到等于 n 的相同长度。 

混合循环大小不会造成任何困难，因为访问标记可确保每个循环仅被发现一次。 切片步骤保证属于先前完成的循环的节点永远不会被重新考虑，从而防止重复或不正确的重叠。
