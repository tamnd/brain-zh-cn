 ## 解决方案
 ## 问题理解

 我们给出了几个独立的场景。 在每个场景中，都有一个代表学生技能水平的不同整数列表。 目标是将这些学生分成尽可能少的组，这样每个组中都不会包含两个技能相差正好一的学生。 

该限制是非常局部的：同一组内仅禁止差值恰好为 1 的对。 任何其他对都是允许的，即使它们的差异很大或很小但不等于 1。 

由此，任务变成了具有非常具体的邻接规则的整数分组问题。 如果我们将每个值想象为数轴上的一个节点，那么每个值仅与其直接邻居值减一和值加一“冲突”。 

每个查询都很小，最多有 100 名学生，技能值也以 100 为界。这立即排除了对大量优化或高级数据结构的任何需要。 即使每个查询的 O(n^2) 解决方案也足够快。 

经常误导天真的方法的主要边缘情况是假设只有连续的链才重要，而不考虑多个链之间的重叠如何迫使多个团队。 

例如，考虑值`[2, 3, 4]`。 一个天真的想法可能是认为我们只需要两个团队，因为我们可以轮流分配任务。 但由于 2 与 3 冲突，3 与 4 冲突，但 2 和 4 都可以，所以正确的分组取决于我们如何分配 3，它充当桥梁。 

另一个微妙的情况是断开的集合，例如`[1, 3, 5]`，根本不存在冲突，一个团队就足够了。 

关键的困难是正确识别有多少“冲突层”是由邻接约束强制的。 

## 方法

 考虑这个问题的一种蛮力方法是将学生逐一分配到团队中，在尊重约束的同时尝试每一种可能的安排。 对于每个学生，如果没有成员相差正好 1，我们会尝试将他们放入现有团队，否则我们将创建一个新团队。 这类似于贪婪的着色尝试，但如果天真地通过回溯来完成，它会探索指数可能性，因为每个分配都会影响未来的可行性。 

如果顺序不幸运，即使是没有结构的简单贪婪也可能会失败。 例如，按输入顺序插入而不考虑排序可能会导致不必要的新团队。 

关键的观察结果是约束仅取决于相邻的整数值。 如果我们对数组进行排序，我们就可以推断出数字如何通过连续的段进行交互。 任意值`x`仅与冲突`x-1`和`x+1`。 这意味着该问题相当于对一条线上的数字进行着色，其中边仅存在于连续整数之间。 

现在考虑需要多少个团队。 如果我们按值对数字进行分组，那么只有当存在连续整数链时，我们才会被迫分成多个团队。 在连续运行中，例如`[k, k+1, k+2, ..., k+m]`，每个数字与其邻居发生冲突，形成路径图。 路径图的色数为 2，但多个不相交的路径可以以全局仅需要 2 种颜色的方式重叠。 

这导致了一个更简单的观点：我们只需要知道集合中是否存在任何一对连续整数。 如果不存在这样的对，则所有值都是独立的，我们只需要 1 个团队。 如果至少存在一对这样的团队，那么我们正好需要 2 个团队，因为任何冲突链都可以通过沿着价值对等的交替分配来始终是 2 色的。 

所以整个问题归结为检查是否存在`x`使得两者`x`和`x+1`存在。

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力分配/回溯| O(n!) | O(n) | 太慢了|
 | 检查连续对 | 每个查询 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取查询的所有学生技能值并将它们存储在一组中以进行快速成员资格检查。 这是必要的，因为我们需要恒定时间查找来检查连续整数是否存在。 
2. 迭代每个值`x`并检查是否`x + 1`也存在于集合中。 这直接检测隐式图中是否存在至少一条冲突边。 
3. 如果我们找到这样的一对`(x, x+1)`，我们立即得出结论，至少需要两个团队。 这是因为这两个值不能共享一个团队，从而迫使分裂通过任何连接的链传播。 
4. 如果在检查所有值后不存在这样的配对，则没有任何约束处于活动状态，并且所有学生都可以放入一个团队中。 

### 为什么它有效

 这些值形成一个图，其中边仅存在于连续整数之间。 该图在构造上是二分图，因此它总是最多需要 2 种颜色。 1 种颜色就足够的唯一情况是根本没有边缘，这意味着输入中不存在两个连续的整数。 因此，检测至少一条边缘的存在就可以完全确定答案是1还是2。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

q = int(input())
for _ in range(q):
    n = int(input())
    a = list(map(int, input().split()))
    
    s = set(a)
    
    ans = 1
    for x in s:
        if x + 1 in s:
            ans = 2
            break
    
    print(ans)
```该解决方案依赖于一组来启用恒定时间检查值是否存在。 集合上的循环确保我们只检查唯一值，避免不必要的重复工作，即使问题陈述的输入中不存在重复项。 

关键的实现细节是提前退出：一旦找到单个相邻对，我们就停止，因为答案不能超过 2。

 ## 边缘情况

 对于没有连续整数的输入，例如`[1, 4, 7]`，算法构建了一个集合`{1, 4, 7}`并发现没有`x`在哪里`x+1`存在。 循环结束时没有触发条件，因此答案仍然是 1，与不存在限制的事实相匹配。 

对于完全连续的输入，例如`[5, 6, 7, 8]`，该集合包含多个相邻对。 该算法检测到`5-6`立即（或任何其他对，取决于迭代顺序），将答案设置为 2，然后停止。 这符合沿着链交替分配的需要，确认单个检查足以捕获整个结构。
