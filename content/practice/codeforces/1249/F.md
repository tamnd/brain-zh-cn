 ## 解决方案
 ## 问题理解

 我们有一棵树，其中每个顶点都带有正权重。 任务是选择一个顶点子集，使所选权重的总和最大化，但有严格的几何限制：任何两个选定的顶点必须大于$k$树中的边缘分开。 

同样，一旦我们选择了一个顶点，我们就“禁止”选择距离内的任何顶点$k$从它。 目标是将选定的顶点放置在树上，以便它们的成对距离都严格大于$k$，同时最大化总重量。 

约束条件$n \le 200$足够小，使得对节点上的状态进行二次或三次动态规划是可行的。 然而，朴素的子集枚举仍然是不可能的，因为$2^n$即使对于$n = 200$。 这推动我们走向树上的结构化 DP。 

一个微妙的点是，限制不是局部的边缘，它通过树中的距离传播。 这使得该问题与树上的经典独立集（对应于$k=1$）。 这里，所选节点的“禁区”是一个半径-$k$球在树上。 

当高权重节点聚集时，就会出现边缘情况。 例如，考虑一条链$1-2-3-4$和$k=2$。 选择节点1会禁止节点2和3，但节点4仍然有效。 局部最大值的贪婪选择可能会失败：在某些权重配置中，选择 2 和 4 比单独选择 1 给予更多权重，但选择 2 也会禁止 1 和 3，从而以非局部方式改变下游可行性。 

另一个边缘情况是当$k=0$。 那么就不存在任何限制并且可以选择所有节点。 总是强制执行父子排除的天真的 DP 会错误地低估。 

最后，当$k$很大（接近$n$），即使是两个节点也是不可能的，除非它们相距极远，因此最佳答案通常会退化为最大单个顶点。 正确的解决方案必须顺利地处理这种转变。 

## 方法

 暴力的想法是尝试所有顶点子集并通过计算所有成对距离来检查有效性。 即使距离是用 BFS 从每个节点预先计算的，检查子集仍然需要成本$O(n^2)$，并枚举子集成本$2^n$，大致导致$O(2^n \cdot n^2)$，这是不可行的。 

关键的观察结果是，就树距离而言，约束是局部的。 如果我们固定一个节点，它的禁区就是一个以距离为界的子树形邻域$k$。 这表明在 DP 中，状态必须记住我们与树上所选节点的“接近”程度。 

标准技巧是建立树的根并定义一个 DP，为每个节点跟踪它距最近选择的祖先的距离。 然而，存储到所有选定节点的精确距离太大。 相反，我们将其压缩为有界参数：从当前节点到其处理子树中最近选定节点的距离。 

这导致了节点上的 DP，其中每个状态表示是否选择了一个节点以及其子树或祖先中最近选择的节点有多远，上限为$k$。 自从$k \le 200$，我们可以维护一个大小为 DP 表$O(nk)$每个节点，通过树背包式转换组合子节点。 

合并步骤类似于多状态传播：在处理节点时，我们考虑它是否被选择，如果是，则考虑距离内的所有节点$k$在其子树中无法选择。 当未选择时，孩子们可以独立贡献更新的距离状态。 

这将全局距离约束转换为有根树上的局部转换。

 ## 算法演练

 我们以节点 1 为树的根，并为每个节点定义一个 DP 表$u$。 

让$dp_u[d]$表示子树中的最大权重$u$子树上方或内部最近选择的节点距离较远的情况下$d$， 在哪里$d$上限为$k$。 价值$d=0$方法$u$被选中，较大的值表示到最近选定节点的距离增加。 

我们自下而上传播信息。 

1.初始化各个节点$u$使用 DP 数组，其中所有状态都设置为负无穷大，但以下情况除外$u$被选中。 如果$u$被选择了，就贡献了$a_u$，并且所有子节点都必须尊重距离内没有节点$k$可以通过相互冲突的方式进行选择。 
2. 逐个处理子节点，将其 DP 表合并到当前节点的 DP 表中。 合并操作考虑当前 DP 和子 DP 的所有状态对，通过在向上移动时将距离值增加 1 来适当更新距离。 
3.如果子状态指示距离处的选定节点$d$，那么从父节点的角度来看，该节点位于远处$d+1$，上限为$k$。 这种转变至关重要，因为当向上移动一个边缘时，距离会恰好增加 1。 
4. 在合并过程中，我们通过丢弃两个选定节点最终相距较远的任何组合来确保可行性$\le k$。 这是通过在组合 DP 表时禁止违反距离阈值的状态来隐式强制执行的。 
5.处理完所有children后，我们最终确定$dp_u$考虑这两种情况：$u$选择或未选择，并将结果向上传播。 

最后，答案就是根节点所有状态中的最大值。 

### 为什么它有效

 DP 不变量是对于每个节点$u$,$dp_u[d]$正确地表示在子树内选择有效子集的最佳权重$u$，符合子树外最近选择节点距离较远的边界条件$d$。 每个子树在此边界约束下独立优化，并且合并子树保留了可行性，因为树中的距离是通过根路径唯一定义的。 由于每个选择冲突都必须通过最低的共同祖先，因此 DP 确保在其合并点检测到任何禁止对。
