 ## 解决方案
 ## 问题理解

 我们正在玩一个两人游戏$n \times n$棋盘。 你在轮到你的时候放了一只白车，计算机紧接着放了一只黑车，镜像你在主对角线上的移动，这意味着车在$(r, c)$被镜像到$(c, r)$。 如果你的棋步位于对角线上$(r = c)$，计算机就会跳过它的回合。 车不能互相攻击，因此新车不能与现有车共享任何行或列。 

输入指定多个测试用例。 每个测试用例都提供了电路板尺寸$n$, 已经进行的移动次数$k$，以及这些移动的坐标。 这些动作是有效的，这意味着它们满足无攻击规则和计算机的镜像规则。 目标是计算从当前棋盘状态继续游戏可获得的不同最终配置的总数。 

鉴于限制条件，$n$可以达到$3 \cdot 10^5$，并且可能最多有$10^4$测试用例。 任何显式检查每个方块或递归枚举所有可能放置的方法都会太慢，因为$O(n^2)$每个测试用例的操作是不可行的。 相反，我们必须将问题简化为组合计算，以避免显式生成所有棋盘状态。 

不明显的边缘情况包括许多剩余的空行和列具有重叠镜像约束的情况，或者移动位于对角线上并阻止镜像响应的情况。 幼稚的实现可能会由于不考虑镜像所施加的对称性而重复计算配置。 

## 方法

 蛮力方法是依次模拟每个移动，尝试放置不攻击任何其他车的白车的所有可能位置，然后放置镜像黑车。 这在概念上是正确的，但是递归分支的数量随着空行和空列的数量呈指数增长，这使得它对于大的情况不可行。$n$和$k$。 例如，即使$n = 10^3$，有以下顺序$10^6$需要考虑的方格，这远远超出了2秒时间限制的操作限制。 

关键的见解是，问题从根本上讲是关于计算空闲行和空闲列之间的匹配，并受到镜像规则的约束。 初始后$k$移动时，每个未占用的行和列要么是空闲的，要么是被现有车阻挡的。 如果一行$r$和列$c$两者都是免费的，可以将白车放置在$(r, c)$仅当$(c, r)$也是免费的，除非$r = c$。 每个放置都会将空闲行和空闲列的集合减少一到两个，具体取决于是否$r = c$。 这将问题简化为对来自空闲行和空闲列的集合的选择序列进行计数，这可以组合地完成。 

具体来说，让$R$是自由行的集合并且$C$初始移动后的一组空闲列。 让$x$是尚未放置车的行数，并且$y$是没有车的列数。 每个移动都可以被认为是配对一行和一列。 如果行和列不同，则占用两个位置（镜像对）。 如果行等于列，则只占用一个位置。 配置总数可以计算为选择的乘积，类似于阶乘，并针对镜像进行调整。

 | 蛮力 | O(2^n) | O(2^n) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化集合以跟踪哪些行和列已经被车占据，基于第一个$k$动作及其镜像位置。 对于每个初始动作$(r_i, c_i)$, 标记行$r_i$和列$c_i$如被占用。 如果$r_i \neq c_i$，也标记行$c_i$和列$r_i$就像镜面黑车所占据的那样。 
2. 计算剩余的空闲行和空闲列。 让`free_rows`是没有车的行数，`free_cols`没有车的列数。 
3. 初始化变量`result`到 1。这将存储可能的配置模数$10^9 + 7$。 
4. 迭代剩余的空闲行。 对于每个空闲行，计算它可以与多少列配对以形成有效的移动。 如果一行$r$和一列$c$都是免费的并且$r \neq c$，将车放置在$(r, c)$两者都占据$(r, c)$和$(c, r)$，将空闲行数和列数减少两倍。 如果$r = c$，只减一。 
5. 使用模运算计算每一步的选择乘积。 由于放置顺序仅与对称性相关，因此减少可用行列对的乘积可以正确计算所有不同的最终配置。 
6. 返回`result`模 $10^9 + 7`。 

保证正确性的不变性是，在每一步中，算法仅计算没有重复使用行或列的有效位置，并且遵守镜像规则。 选择的乘法考虑了所有的移动序列，并且因为我们从不重新访问占用的行或列，所以没有配置被计算两次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        row_occupied = set()
        col_occupied = set()
        for _ in range(k):
            r, c = map(int, input().split())
            row_occupied.add(r)
            col_occupied.add(c)
            if r != c:
                row_occupied.add(c)
                col_occupied.add(r)
        free_rows = n - len(row_occupied)
        free_cols = n - len(col_occupied)
        # Number of ways is product of choices for remaining rooks
        min_free = min(free_rows, free_cols)
        res = 1
        for i in range(min_free):
            res = res * (i + 1) % MOD
        print(res)

if __name__ == "__main__":
    solve()
```该解决方案首先标记已被初始移动和镜像放置占据的所有行和列。 然后，它计算剩余的空闲行和列的数量，取最小值以确定可以放置多少个额外的车，并计算该数字的阶乘模$10^9+7$。 阶乘考虑了所有可能的放置顺序，因为每个放置都会将可用行和列的集合减少一个。
