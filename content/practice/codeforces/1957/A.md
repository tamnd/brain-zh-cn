 ## 解决方案
 ## 问题理解

 我们得到了一组棍子，每根棍子的长度都是整数。 目标是使用这些棍子构建尽可能多的正多边形，但多边形的每一边必须恰好是一根棍子，并且不能重复使用棍子。 正多边形至少需要三条边长度相等。 因此，要形成边长为 的多边形`L`，我们至少需要三根棍子的长度`L`。 

输入由多个测试用例组成。 对于每个测试用例，我们知道有多少根可用的棍子及其各自的长度。 每个测试用例的输出是我们可以用给定的棍子形成的最大多边形数。 

限制很小：每个测试用例最多 100 根棍子，最多 100 个测试用例。 这意味着我们可以提供具有二次复杂度的解决方案`n`每个测试用例，但我们仍然应该更喜欢线性或近线性方法。 因为棍子的长度在 1 到 100 之间，所以我们还可以利用计数技术，而不是排序或更复杂的数据结构。 

当一定长度的木棒总数不足以形成最小的多边形时，就会出现微妙的边缘情况。 例如，如果我们有两根长度为 5 的棍子，则无法形成三角形，因此该长度的输出为零。 当可以由不同长度形成多个多边形时，会出现另一种边缘情况； 我们的解决方案必须最大化多边形的总数，而不仅仅是最大的多边形。 

## 方法

 一种蛮力方法是尝试所有可能的木棍子集来形成多边形。 对于长度至少为三的每个子集，我们将检查子集中的所有木棍是否具有相同的长度。 然后我们将递归地移除使用过的棍子并继续搜索。 这是正确的，但不可行，因为子集的数量呈指数增长`n`。 为了`n = 100`，迭代所有子集是完全不切实际的。 

关键的见解是，多边形只能由至少三根相同长度的棍子形成。 因此，我们可以根据棒的长度对棒进行分组，并计算每个长度有多少根棒，而不是检查任意子集。 我们可以用单一长度的棍子形成的最大多边形数只是计数除以三的整数除法。 通过对所有长度上的该值求和，我们得到了所有棒可以形成的多边形的最大数量。 

这种基于计数的方法之所以有效，是因为该问题允许独立于每个长度形成多边形，并且多边形之间不共享棍子。 我们不需要考虑混合长度，这极大地简化了解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 计数与除法| O(n + L) | O(L) | 已接受 |

 这里`L`是最大棒长度 (100)，与`n`。 

## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和棍子长度列表`a`。 
3.初始化频率数组`count`大小 101（覆盖长度 1 到 100）到零。 
4. 迭代所有棒，递增`count[length]`对于每根棍子。 
5. 初始化变量`polygons`为零。 
6. 对于 1 到 100 之间的每个可能的长度，通过整数除法计算该长度的木棍可以形成的多边形数量`count[length] // 3`并将其添加到`polygons`。 
7. 打印值`polygons`对于测试用例。 

为什么有效：每个多边形都需要三根或更多相同长度的木棍。 通过计算每个长度的木棍数量，我们可以直接计算每个长度存在多少个不重叠的三组。 对长度进行求和可确保所有棍子都得到最佳使用，而不会违反“禁止重复使用”规则。 由于我们从不混合长度，因此我们避免了任何复杂的子集选择的需要。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    sticks = list(map(int, input().split()))
    count = [0] * 101
    for stick in sticks:
        count[stick] += 1
    polygons = 0
    for length in range(1, 101):
        polygons += count[length] // 3
    print(polygons)
```该代码首先读取测试用例的数量。 对于每种情况，我们都会读取木棍的数量及其长度。 频率阵列`count`用于计算每个可能的长度存在多少根棍子。 通过将每个频率除以三，我们可以找到从该长度可以形成多少个多边形，并将所有长度的结果相加。 使用整数除法可以确保我们忽略无法完成多边形的剩余棍棒。 

微妙之处包括将计数数组初始化为大小 101 以考虑最大 100 的长度，并确保我们正确使用整数除法以避免分数多边形。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        sticks = list(map(int, input().split()))
        count = [0] * 101
        for stick in sticks:
            count[stick] += 1
        polygons = sum(c // 3 for c in count)
        print(polygons)
    return output.getvalue().strip()

 ## 边缘情况

 对于输入`2\n7 7`，该算法将 count 数组初始化为零，将 count[7] 递增两次，并计算`2 // 3`为零。 输出正确地为零，表明自动处理了不足的棍棒。 同样，对于`6\n6 6 6 6 6 6`，count[6] 为 6，并且`6 // 3`等于 2，产生两个多边形。 这证实了单长度和多长度贡献均被准确统计。
