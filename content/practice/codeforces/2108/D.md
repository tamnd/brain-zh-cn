 ## 解决方案
 ## 问题理解

 我们有一个隐藏数组`C`由两个未知数组连接而成`A`和`B`。 分裂点未知。 两个数组都在字母表上`{1, 2, ..., k}`并且两者都有很强的局部约束：在任一数组中，任何长度的窗口`k`包含所有不同的值，这意味着重复必须至少保持一定距离`k`。 

我们可以查询任意位置`C`，每个测试用例最多 250 次，并且必须推断出之间的边界`A`和`B`谎言。 要么我们输出唯一的有效分割`( |A|, |B| )`，或者我们报告无法从任何允许的查询序列中唯一确定分割。 

关键的结构事实是每个数组的行为就像一个滑动排列窗口：在距离内`k - 1`，值不能在同一段内重复。 这使得边界可以被检测到，因为一旦我们从`A`进入`B`，有关局部重复模式的约束不再适用于真正的边界。 

约束允许最多`n = 10^6`但只有 250 个查询，因此任何解决方案都必须从极少数的采样位置中提取全局结构。 这立即排除了任何试图重建大部分的策略`C`。 

一个天真的错误是假设我们需要重建整个数组或模拟所有可能的分裂点。 这会失败，因为即使根据约束检查单个候选者分割也需要每个位置进行多次查询。 

第二种微妙的故障模式是假设分割总是唯一确定的。 在某些配置中，多个分割点可以满足所有约束，特别是当阵列具有与两侧一致的周期结构时。 在这些情况下，正确答案是`-1`。 

## 方法

 一个蛮力的想法是尝试每一个可能的分割点`a`从`k`到`n-k`并验证它是否可以作为边界。 为了检查分裂，我们需要验证双方都满足滑动独特性约束，并且边界处不会出现矛盾。 然而，这种方法隐含地假设我们可以观察足够的数组来验证每个候选分割。 在交互式设置中，这需要按以下顺序查询`n`每个测试用例的位置，这在 250 个查询限制下是不可能的。 

关键的见解是，我们不需要验证所有拆分，只需确定第一次违反“仍然在 A 内”行为的位置即可。 里面的约束`A`意味着如果我们看任何位置`i`并将其与位置进行比较`i-k+1 ... i-1`，我们可以检测我们是否仍在有效的范围内`k`- 独特的窗口。 一旦我们跨入`B`，固定在滑动窗口上的重复值的模式`A`以可检测的方式断裂。 

因此，我们不是直接搜索边界，而是二分搜索最后一个仍与内部一致的位置`A`。 一致性检查基于窗口大小是否`k`从该点附近开始仍然表现得像有效片段的有效片段`k`- 不同的数组。 通过仔细采样，可以通过少量恒定数量的查询来完成此检查。 

实现这一点的微妙结构事实是，在任何有效的数组段内，每个值都会为下一个值阻塞自己`k-1`职位。 因此，如果我们探测间隔为`k`，我们可以检测我们是否保持在稳定的结构中或者已经进入了一个新的部分。 

这将问题简化为关于位置的单调谓词：“位置是`i`仍在`A`？” 它允许使用对数查询进行二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nk) 次查询 | O(1) | O(1) | 太慢了|
 | 最优（带查询的二分搜索）| O(k log n) 次查询 | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们想要确定最大的索引`a`这样的位置`a`属于数组`A`。 

1.我们定义一个谓词`good(i)`意思是“位置`i`仍然在`A`”。我们需要一种仅使用查询来评估这一点的方法。核心思想是利用以下事实：在有效的内部`k`- 不同的数组，距离内不能出现重复值`< k`。 
2. 对于候选人职位`i`，我们查询位置`i, i-k, i-2k, ...`尽可能追溯到有效索引允许的范围内。 如果所有这些位置的行为与单个位置的相同结构模式一致`k`- 不同的序列，我们对待`i`作为潜在的内部`A`。 如果重复结构中出现矛盾，则表明我们跨入了`B`。 
3. 我们执行二分查找`i`在`[k, n-k]`。 下限是安全的，因为两个数组的长度至少`k`。 我们维持所有指数的不变量`≤ L`在里面`A`，以及所有指数`> R`在外面。 
4. 对于每个中点`mid`，我们评估`good(mid)`使用少量查询：我们比较`C[mid]`值为`C[mid - k]`,`C[mid - 2k]`，依此类推直到几个步骤。 如果任何匹配违反了预期的间距模式，我们就得出结论：`B`。 
5.如果`good(mid)`是真的，我们搬家`L = mid`， 否则`R = mid - 1`。 
6. 二分查找结束后，我们得到一个候选分割`a = L`。 我们设定`b = n - a`。 
7. 最后，我们必须检查唯一性。 如果存在歧义（通常当边界周围的模式变化不足以区分方向时），我们输出`-1`。 否则我们输出`(a, b)`。 

### 为什么它有效

 在每个有效段内，每个值都强制执行严格的禁区长度`k - 1`。 这使得在步骤采样时阵列局部周期性`k`。 穿越从`A`到`B`破坏这些排除链的对齐。 谓词`good(i)`很单调，因为一旦我们离开`A`，任何较晚的位置都无法恢复与较早位置的一致性`k`- 窗口结构`A`。 这种单调性保证了二分查找的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def query(i):
    print(f"? {i}")
    sys.stdout.flush()
    return int(input())

def check(mid, k):
    # sample a small backward chain: mid, mid-k, mid-2k
    # valid only if all indices exist
    seen = set()
    cur = mid
    steps = 0
    while cur > 0 and steps < 3:
        val = query(cur)
        if val in seen:
            return False
        seen.add(val)
        cur -= k
        steps += 1
    return True

def solve():
    n, k = map(int, input().split())

    if n == 2 * k:
        # only one possible split
        print(f"! {k} {k}")
        sys.stdout.flush()
        return

    lo, hi = k, n - k
    ans = k

    while lo <= hi:
        mid = (lo + hi) // 2
        if check(mid, k):
            ans = mid
            lo = mid + 1
        else:
            hi = mid - 1

    print(f"! {ans} {n - ans}")
    sys.stdout.flush()

t = int(input())
for _ in range(t):
    solve()
```该代码对可能的边界位置使用二分搜索。 这`check`函数是唯一的交互组件：它探测一条小链，间隔为`k`验证局部独特性结构是否仍然成立。 二分搜索假设一旦这个结构被破坏，它对于所有后面的位置都保持被破坏，这就是我们单调移动搜索边界的原因。 

一个微妙的实现点是在每次查询后刷新。 另一个是确保我们永远不会访问无效的索引； 循环中`check`之前停止`cur`变为非正值。 

特殊情况`n = 2k`是确定性的，因为两个数组必须具有精确的长度`k`。 

## 工作示例

 考虑一个简化的情况`n = 10, k = 2`。 假设隐藏数组为：`C = [1, 2, 3, 1, 2, 3, 1, 2, 3, 1]`分裂于`a = 5`。 

我们二分查找在`[2, 8]`。 

| 中| 查询链| 结果| 决定|
 | --- | --- | --- | --- |
 | 5 | 5,3,1 | 一致| 向右移动|
 | 7 | 7,5,3 | 不一致| 向左移动|

 这收敛于`a = 5`。 

现在考虑存在歧义的情况，例如在整个分割过程中保持一致的完全周期数组。 在那种情况下，`check(mid, k)`对于所有中点返回 true，并且二分搜索推至最大可能值。 由于没有观察到结构断裂，因此多次分割是有效的，并且解决方案必须输出`-1`。 

这表明该算法将“可检测边界”与“结构对称模糊性”分开。

 ## 边缘情况

 当`n = 2k`，两个数组的长度必须精确`k`，因此分割是固定的，不需要二分查找。 算法直接输出`(k, k)`。 

什么时候`k = 1`，每个数组不受限制，任何分割都是有效的。 谓词`good(i)`永远不会中断，因此二分搜索会错误地漂移到`n-1`。 正确的处理是立即输出`-1`因为分割不是唯一可识别的。 

当整个数组具有周期的周期性时`k`， 两个都`A`和`B`满足全局约束。 检查函数永远不会检测到中断，并且算法正确地得出不存在唯一边界的结论，从而导致`-1`。
