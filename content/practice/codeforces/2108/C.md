 ## 问题理解

 Neo 面临着一排按钮，每个按钮都标有一个正整数权重。 他想要按下所有按钮，使得按下的按钮的重量顺序永远不会增加。 尼奥本人无法移动，但他可以创建按下按钮并向左或向右移动的克隆体，激活它们触及的任何未按下的按钮。 面临的挑战是确定按非增加的权重序列按下所有按钮所需的最小克隆数量。 

输入由多个测试用例组成。 对于每种情况，我们都知道按钮的数量及其重量。 每种情况的输出都是一个数字，代表所需的最少克隆数。 

这些约束允许每个测试用例最多有 200,000 个按钮，所有用例总共有 200,000 个按钮。 这排除了任何尝试所有可能的订单或模拟每个可能的克隆运动的简单解决方案，因为 O(n²) 方法将执行多达 4 × 10^10 次操作，这远远超出了 2 秒的时间限制。 我们需要一种每个测试用例的运行时间大致为 O(n log n) 或 O(n) 的方法。 

当许多按钮具有相同的权重或当较大的权重分散以致贪婪的单遍克隆策略失败时，就会出现不明显的边缘情况。 例如，使用输入`5 3 2 4 1`，在 4 和 5 处创建克隆比仅从最大值开始要好，因为它允许多个克隆并行工作并避免阻塞较小的序列。 总是选择最左边最大按钮的粗心方法可能会低估克隆的最小数量。 

## 方法

 暴力方法将尝试模拟在每个按钮处创建克隆并将其移动到按下按钮，同时尝试维持非递增顺序的所有可能序列。 虽然原则上是正确的，但这需要检查印刷机的所有排列并跟踪多个克隆，从而导致阶乘复杂性。 即使将其简化为贪婪模拟，一次移动一个克隆也会导致 O(n²) 行为，这对于 n 高达 2 × 10⁵ 来说太慢了。 

关键的观察是，我们可以将问题建模为将按钮序列拆分为几个非递增子序列。 每个克隆可以通过从左向右移动来处理一个子序列。 克隆的最小数量等于覆盖所有按钮所需的此类子序列的最小数量。 如果我们反转权重，这相当于找到严格递增序列的最小数量。 这直接映射到称为耐心排序方法的经典算法技术，该技术用于计算最长非递减子序列（LNDS）。 当贪婪地将每个权重分配给它可以扩展的第一个合适的子序列时，克隆的数量等于最长链的长度，这可以通过堆或多重集有效地实现。 

直觉是，每当一个按钮无法在不违反非递增顺序的情况下附加到任何现有克隆的序列时，我们就需要一个新的克隆。 否则，我们会扩展现有克隆的序列。 这类似于将权重排列到最少数量的非递增堆栈中。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n²) | O(n) | 太慢了|
 | 耐心排序/非递增子序列| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空列表`piles`代表每个克隆处理的序列。 每堆都存储该克隆所压的最后一个重量。 
2. 从左到右迭代按钮权重。 对于每个重量，尝试将其放在最后重量大于或等于当前重量的最左边的一堆上。 如果存在这样的一堆，则将其顶部值替换为当前重量。 
3. 如果没有堆可以容纳当前重量，则用该重量创建一个新堆。 每堆对应一个单独的克隆。 
4.处理完所有按钮后，堆的数量正好是所需的最小克隆数量。 

工作原理：每一堆代表由单个克隆处理的一系列按钮按下操作。 通过始终将下一个重量放在最左边的兼容堆上，我们确保每个堆保持不增加，并且仅在必要时创建新堆以保证堆的总数最少。 这是可行的，因为问题简化为计算覆盖数组的非递增序列的最小数量，如果我们反转比较方向，这正是最长递增子序列的长度。 

## Python 解决方案```python
import sys
import bisect
input = sys.stdin.readline

def min_clones(weights):
    piles = []
    for w in weights:
        # find the first pile where top >= w
        idx = bisect.bisect_right(piles, w)
        if idx < len(piles):
            piles[idx] = w
        else:
            piles.append(w)
    return len(piles)

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_clones(a))
```功能`min_clones`实现非增子序列划分。 我们使用`bisect_right`在堆顶列表中查找顶部≥当前重量的第一堆。 如果存在这样的一堆，我们将其顶部值替换为当前权重以扩展该克隆的序列。 否则，我们开始一堆新的。 使用`bisect`确保每个权重的插入时间为 O(log n)，总时间为 O(n log n)。 

必须注意不平等`bisect_right`，因为我们正在构建非增序列； 反转比较方向可确保桩保持正确。 未能扭转不平等会导致克隆计数不正确。
