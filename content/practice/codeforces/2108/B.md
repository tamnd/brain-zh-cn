 ## 解决方案
 ## 问题理解

 我们被要求构造一个数组`n`正整数，其按位异或恰好是`x`并最小化数组的总和。 我们不输出数组本身，而是返回元素的总和。 输入由多个测试用例组成，每个测试用例给出一对`(n, x)`在哪里`n`是所需的数组长度并且`x`是目标异或。 每个测试用例的输出是一个整数：可能的最小总和或`-1`如果不存在数组。 

限制因素很大：`n`可以大到 10^9 并且`x`最多 10^9，我们最多可以有 10^4 个测试用例。 这立即排除了任何显式构造数组、迭代所有可能性、甚至存储长度数组的解决方案`n`。 相反，我们必须使用 XOR 和正整数的属性对总和进行数学推理。 

非明显的边缘情况包括以下情况`n = 1`或者`x = 0`。 例如，如果`n = 1`和`x = 0`，不可能用正整数满足条件，所以输出必须是`-1`。 另一个微妙的情况是当`n = 2`和`x = 0`。 由于两个相等数的 XOR 为零，因此数组`[1, 1]`工作并给出总和`2`。 粗心的实现可能会忽略这些小值`n`并错误地假设一般公式。 

## 方法

 蛮力方法将尝试生成所有组合`n`XOR 等于的正整数`x`然后选择总和最小的组合。 对于小`n`和`x`，这可行，但复杂性呈指数级增长`n`并很快变得不可行。 即使是为了`n = 20`， 有`2^20`要考虑的子集。 

关键的见解来自于对 XOR 运算与求和最小化的结合的理解。 最简单的正整数是`1`s，所以尝试用以下内容填充数组是很直观的`1`并调整最后一两个元素以实现目标异或。 如果`n = 1`，唯一的选择是`[x]`如果`x > 0`。 如果`n = 2`，该数组可以是`[1, 1 ⊕ x]`如果`x != 0`。 为了`n >= 3`，总是可以使用大多数来构造一个有效的数组`1`最多调整两个元素以实现异或。 

这导致每个测试用例的计算量为 O(1)。 我们不构造数组，而是直接计算总和：

 - 对于`n = 1`，总和是`x`如果`x > 0`， 否则`-1`。 
- 为了`n = 2`，总和是`x + 0`如果`x != 0`， 否则`2`。 
- 为了`n >= 3`，总和是`x + (n-1)`因为我们可以使用`(n-3)`一个加上两个调整为匹配异或的数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和`x`。 
3.如果`n = 1`，检查是否`x > 0`。 如果是，则打印`x`作为最低金额； 否则打印`-1`因为没有正数等于`0`。 
4.如果`n = 2`，检查是否`x = 0`。 如果是，则最小总和为`2`使用`[1, 1]`。 如果`x > 0`，最小总和是`x + 0 = x`使用`[1, 1 ⊕ x]`。 
5.如果`n >= 3`， 使用`(n-3)`一个和两个数字来调整异或`x`。 这确保了最小金额。 总和是`(n-3) + adjusted pair sum`。 最简单的公式是`(n-1) + x`。 
6. 输出计算出的总和。 

工作原理：多个数的异或可以通过两个数字轻松调整，以实现任何目标异或。 使用 1 可以最小化总和，因为每个大于 1 的正整数都会增加总和。 为了`n = 1`和`2`，特殊情况单独处理以尊重积极性约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    if n == 1:
        print(x if x > 0 else -1)
    elif n == 2:
        if x == 0:
            print(2)
        else:
            print(x + 1)
    else:
        print(x + n - 1)
```第一个条件正确处理单元素情况，确保我们不会输出零。 第二个处理双元素数组，使用 1 作为基数并通过 XOR 调整另一个元素。 最后一种情况推广到更大的情况`n`利用这样的见解：任何 XOR 都可以通过最多两个调整元素来实现`1`s。 这避免了显式构造任何数组。

 ## 边缘情况

 对于`n = 1, x = 0`，算法正确输出`-1`。 为了`n = 2, x = 0`，它输出`2`这对应于`[1, 1]`。 对于大型`n`，公式`x + n - 1`无需迭代或构造数组即可正确处理总和。 为了`n = 2`和`x > 0`，总和是`x + 1`，这确保了正性和正确的异或。 关键的不变量是 XOR 始终可以使用除基本数字之外的最多两个数字来调整。
