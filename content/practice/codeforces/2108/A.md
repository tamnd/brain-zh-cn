 ## 解决方案
 ## 问题理解

 我们得到从 1 到 n 的数字排列，然后我们测量每个元素偏离其原始位置的距离。 对于每个位置 i，我们取该位置的值与 i 本身之间的绝对差，并将其在整个数组上求和。 这会为该排列生成一个整数分数。 

任务不是计算单个排列的该值，而是考虑长度为 n 的所有可能的排列并确定可以出现多少个不同的总分数。 

关键对象不是排列本身，而是类似距离的度量的可实现值的集合。 每个排列都会重新排列相同的整数多重集，因此总和受到全局可能的位移量的限制。 

对于多个测试用例，约束允许 n 最多为 500。 任何显式枚举排列的解决方案都是不可能的，因为即使对于 n = 10，排列数量也已经是 3,628,800。 这完全排除了暴力生成的可能性。 该解决方案必须依赖于这些绝对差异如何变化的结构特性。 

当 n 非常小时，会出现微妙的边缘情况。 当 n = 1 时，只有一种排列，并且值始终为 0，因此答案必须是 1，而不是 0。当 n = 2 时，只有两个值可能，即 0 和 2，这表明该函数不一定会产生连续的整数，但仍会形成一个结构化集合。 

## 方法

 蛮力的想法很简单：生成每个排列，计算绝对差之和，将结果插入到集合中，然后返回其大小。 这是正确的，因为它直接遵循定义。 然而，它需要迭代 n! 排列并计算每个排列的 O(n) 总和，从而导致 O(n · n!) 运算。 当 n = 10 后，这几乎立即变得不可行。 

关键的观察是，我们不是单独研究排列，而是研究可能的总位移值的范围。 表达式 Σ|p_i − i| 称为总位移或距恒等式的斯皮尔曼尺尺距离。 一个关键的结构事实是，交换元素会以受控增量的方式影响总和，并且可实现的值集最终会形成最高可达最大值的所有偶数，其中一些奇偶校验约束取决于 n。 

更准确地说，最小值是0（恒等排列），最大值是通过反转数组来实现的。 可以通过使用互换以可预测的步骤调整总成本来逐渐纠正反向排列来获得中间值。 和的奇偶性取决于 n 是偶数还是奇数，但无论如何，不​​同值的数量结果仅取决于 n 并遵循 n 中的简单二次表达式。 

通过分析我们可以对称地移动元素多远，可以得出最终的闭合形式。 位置之间的每次交换都会对总和产生受控变化，并且可达集填充 0 到最大值之间某个奇偶校验范围的所有整数。 对这些值的计数简化为对算术级数长度的计数，从而得出最终公式：

 对于偶数 n：

 不同值的数量为 n² / 4 + 1

 对于奇数 n：

 不同值的数量为 (n² + 3) / 4

 这简化为统一的表达式：

 ⌊n² / 4⌋ + 1

 因此，问题减少为每个测试用例的恒定时间计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·n!) | O(n·n!) | O(n!) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 读取每个测试用例的 n。 这定义了排列大小并确定了可能值的整个结构。 
2. 计算 n × n。 这表示总位移能力的规模，因为每个位置最多对总和贡献 O(n)。 
3. 使用整数除法将该值除以 4。 这对应于计算有多少不同的“步骤”适合完整的可实现的值范围，该范围围绕恒等排列对称。 
4. 加 1 以包含零位移排列。 这确保了身份排列的值被计算在内。 

每个步骤直接对应于将排列距离的结构压缩到单个算术范围中。 唯一重要的步骤是认识到可达值在奇偶校验类中形成连续的集合。 

### 为什么它有效

 函数 f(p) 测量恒等排列的总位移。 交换两个元素以受控和增量的方式改变总和，并且任何排列都可以通过一系列交换转换为任何其他排列。 关键的结构特性是，这些交换使我们能够在固定间隔内实现每个可行的总位移，但只能以符合奇偶校验约束的增量步进。 结果，这组可实现的值形成了一个算术级数，从 0 开始，到最大位移结束，并且恰好包含一个奇偶校验类别。 计算该级数中的元素就简化为计算其长度，该长度仅取决于 n。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    print(n * n // 4 + 1)
```代码直接实现了派生的封闭形式。 n 最大为 500 时，乘法 n * n 是安全的，因为结果很适合 Python 整数。 整数除以 4 捕获该范围内可实现值的密度。 +1 表示零值排列。 

该解决方案避免了任何排列构造，并且完全依赖于不同值的数量仅取决于 n 的结构结果。 

## 工作示例

 ### 示例 1

 输入：

 n = 2

 我们评估所有排列：

 | 排列| f(p) | f(p) |
 | --- | --- |
 | [1, 2] | 0 |
 | [2, 1] | 2 |

 不同的值为 {0, 2}。 

对于 n = 2，公式得出 2² // 4 + 1 = 1 + 1 = 2。 

这证实了即使在最小的非平凡大小下，这些值也不是连续的整数，但仍然遵循算术结构。

这表明仅出现偶数值并且范围已完全填充。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        out.append(str(n * n // 4 + 1))
    return "\n".join(out)

 ## 边缘情况

 当 n = 1 时，只有一种排列。 该算法计算 1 * 1 // 4 + 1 = 1，这正确计算了唯一可实现的值 0。 

对于 n = 2，计算得出 4 // 4 + 1 = 2。这两个排列产生值 0 和 2，与预测匹配。 

对于较大的 n（例如 500），该公式仍然直接适用，不会出现 Python 中的溢出问题。 该结构不依赖于枚举或组合生成，因此性能保持不变。 

这些情况证实最小和最大输入都由相同的算术表达式统一处理。
