 ## 解决方案
 ## 问题理解

 我们有一棵树`n`节点和多轮两人游戏。 在每一轮中，一颗棋子从一个节点开始。 玩家交替移动，将石头移动到未激活的邻居并将该邻居标记为已激活。 不能移动的玩家就输了。 每轮结束后，所有节点都会重置为非活动状态。 我们被要求，对于每个起始节点，确定第一个玩家罗恩获胜还是赫敏获胜，假设两者都发挥最佳。 

输入是由以下定义的树`n-1`边缘，然后是`t`回合的起始节点。 输出是`t`每行都是“罗恩”或“赫敏”。 这个问题具有挑战性，因为`n`最大可达 2×10^5，因此简单地模拟所有回合会太慢。 关键是树结构和最佳游戏规则允许适用于所有回合的预计算。 

不明显的边缘情况包括从叶节点开始、从树的质心开始以及本质上是路径的树。 例如，如果树是一条长度为 3 的笔直路径，并且石头从一片叶子开始，则第一个玩家获胜，但从中间开始可能会改变结果。 

## 方法

 一种简单的方法是递归地模拟每一轮：从起始节点开始，枚举所有可能的动作，将节点标记为激活，并确定当前玩家是否可以强行获胜。 原则上这是正确的，但递归中每次移动需要 O(n) 时间，并且总体上可能需要 O(2^n) 时间，这对于`n`最多 2×10^5。 

最佳方法利用了**树上的博弈值**的结构，特别是公平博弈的斯普拉格-格伦迪定理。 每个节点都可以分配一个 Grundy 编号，表示从该节点开始的游戏状态。 对于树来说，节点的 Grundy 数是其子节点的 Grundy 数的异或加一。 由于我们只需要知道奇偶性即可确定获胜者（非零表示第一个玩家获胜），因此可以简化解决方案：计算从根或起始节点到叶子的距离，并计算沿路径的移动。 如果从起始节点到叶子的距离之和在特定数量意义上具有奇数长度，则第一个玩家获胜。 

更具体地说，获胜者可以通过起始节点的深度模 2 和树的结构来确定：如果起始节点位于所有到叶子的路径上的节点总数为奇数的位置，则 Ron 获胜；如果起​​始节点位于所有到叶子的路径上的节点总数为奇数的位置，则 Ron 获胜； 否则，赫敏获胜。 这允许每个起始节点进行 O(n) 预处理和 O(1) 查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 朴素模拟 | O(n·2^n) | O(n·2^n) | O(n) | 太慢了 |
 | 树游戏分析（Grundy）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取整数`n`和`t`。 
2. 建立树的邻接表`n-1`边缘。 
3. 使用 BFS 或 DFS 计算从任意根开始的每个节点的深度。 这里的深度对应于从根到该节点的移动次数。 
4. 从根开始计算整个树的奇偶校验值：所有叶子的深度的异或。 这捕获了整个游戏的数量。 
5. 每轮读取起始节点`u_i`。 通过适当地对预先计算的值进行异或来确定其有效数量。 如果非零，罗恩获胜； 否则，赫敏获胜。 
6. 相应地输出“Ron”或“Hermione”。 

关键的见解是每个节点的 Grundy 数仅取决于其下方的子树，并且树上的博弈相当于沿着不相交子树的数计算。 

为什么有效：子游戏的异或是公正游戏的标准。 激活限制确保移动仅沿着未访问的路径进行，因此一旦进行移动，每个子树都是独立的。 从根计算深度并正确使用奇偶校验表示第一个玩家可用的选项。 这个不变量保证了所有起始位置的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def main():
    n, t = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u - 1].append(v - 1)
        adj[v - 1].append(u - 1)

    depth = [0] * n
    def dfs(u, parent):
        for v in adj[u]:
            if v != parent:
                depth[v] = depth[u] + 1
                dfs(v, u)
    dfs(0, -1)

    total_nimber = 0
    for d in depth:
        total_nimber ^= d

    starts = list(map(int, input().split()))
    result = []
    for s in starts:
        s_idx = s - 1
        if (total_nimber ^ depth[s_idx]) != 0:
            result.append("Ron")
        else:
            result.append("Hermione")
    print("\n".join(result))

if __name__ == "__main__":
    main()
```DFS 计算所有节点相对于节点 0 的深度。`total_nimber`代表所有深度的异或并捕获整个游戏的数量。 对于每个起始节点，我们根据节点的深度调整数量。 如果非零，则第一个玩家可以强制获胜。 边缘情况（例如从叶子或根开始）自然会得到处理。

 ## 边缘情况

 如果树是一条笔直的路径，而石头从一端开始，那么第一个玩家总是可以沿着路径移动以取得胜利。 从中间开始，将树分成两条路径，第一个玩家的移动由每条路径的数字的异或决定。 DFS 正确计算两种情况的深度，确保准确的第一玩家获胜检测。 如果树是星形的，叶子不能交换位置，因此从中心或叶子开始会自动产生与算法计算的相同的输出。
