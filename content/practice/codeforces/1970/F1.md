 ## 解决方案
 ## 问题理解

 我们被要求在矩形网格上模拟简化的魁地奇比赛。 场地包含来自两支球队的球员、两支球队的球门以及一枚鬼飞球。 每个玩家可以向四个方向之一移动，抓住鬼飞球（如果它在他们的牢房上），然后将其扔掉。 每当一名球员将鬼飞球射向对方球队的球门时，即可得分。 如果一名球员在自己的球门内得分，则另一队获得分数。 每次得分后，鬼飞球立即重置到中心。 游戏提供了一系列的动作，我们必须输出进球何时发生以及最终的得分。 

输入网格很小，最多99×99，步数可以达到10000。 每个动作都保证是有效的，因此我们不需要处理无效的动作。 因此，我们的任务是忠实地模拟所有动作，跟踪谁携带鬼飞球，检查进球事件，并以正确的顺序打印它们以及最终得分。 

边缘情况包括多个玩家从同一个牢房开始，在自己的球门内得分，以及鬼飞球在接住后立即被扔进球门。 简单的模拟必须在每一步仔细更新球员和球的位置。 

## 方法

 这里的暴力方法是可行的，因为网格和移动次数都很小。 我们可以维护从玩家 ID 到位置的映射，跟踪鬼飞球的位置和载体，并按顺序处理每个动作。 对于移动动作，我们更新玩家的坐标。 为了接住，我们将鬼飞球标记为携带。 对于投掷，我们将其放置在当前单元格上。 每次移动后，我们都会检查鬼飞球是否击中球门并相应更新得分。 考虑到限制，这种方法是正确的并且足够快，T 次移动需要 O(T) 时间。 

不存在渐近更快的方法，因为必须处理每个动作以确定得分事件，并且约束允许这种直接模拟。 我们避免任何过早的优化，例如事件批处理或预计算路径，因为主要的挑战是仔细的簿记而不是算法的复杂性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 直接模拟 | O(T)| O(N*M + P) | 已接受 |

 ## 算法演练

 1. 解析网格并存储所有球员和目标的位置。 为鬼飞球的位置以及是否携带它保留一个单独的变量。 
2. 将两队的分数初始化为零。 
3. 对于从 0 到 T-1 的每个操作，提取执行该操作的实体和操作类型。 如果是移动，则更新实体的坐标。 如果成功，则将玩家标记为携带鬼飞球并清除鬼飞球的网格位置。 如果是投掷，则将鬼飞球放在玩家当前的单元格中，并将其标记为不再携带。 
4. 每次行动后，如果鬼飞球正中目标，则确定哪队得分。 如果进球属于对方球队，则该球员的球队获得一分。 如果进球属于同一队，则另一队得分。 打印带有当前步骤索引的事件。 
5. 得分后，将鬼飞球重置到网格中心，并将其标记为未携带。 
6. 完成所有操作后，以格式打印最终得分`FINAL SCORE: r b`。 

工作原理：该算法保持了鬼飞球要么在场上要么由玩家携带的不变性。 每个动作和目标都按时间顺序处理。 通过在每次行动后立即更新位置并检查进球，我们可以正确捕获得分事件的顺序和最终结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    grid = []
    players = {}
    goals_red = set()
    goals_blue = set()
    quaffle_pos = None
    quaffle_carrier = None

    for i in range(N):
        row = input().split()
        for j, cell in enumerate(row):
            if cell.startswith('R') and cell[1].isdigit():
                players[cell] = (i, j)
            elif cell.startswith('B') and cell[1].isdigit():
                players[cell] = (i, j)
            elif cell == 'RG':
                goals_red.add((i, j))
            elif cell == 'BG':
                goals_blue.add((i, j))
            elif cell == '.Q':
                quaffle_pos = (i, j)
        grid.append(row)

    T = int(input())
    actions = [input().split() for _ in range(T)]

    score_red = 0
    score_blue = 0

    center = ((N-1)//2, (M-1)//2)

    for t, act in enumerate(actions):
        entity = act[0]
        move = act[1]

        if move in 'UDLR':
            x, y = players[entity]
            if move == 'U':
                x -= 1
            elif move == 'D':
                x += 1
            elif move == 'L':
                y -= 1
            elif move == 'R':
                y += 1
            players[entity] = (x, y)
            if quaffle_carrier == entity:
                quaffle_pos = (x, y)
        elif move == 'C':
            # catching Quaffle
            quaffle_carrier = entity
            quaffle_pos = None
        elif move == 'T':
            # throwing Quaffle
            x, y = players[entity]
            quaffle_pos = (x, y)
            quaffle_carrier = None

        # check for scoring
        if quaffle_pos is not None:
            if quaffle_pos in goals_red:
                if entity[0] == 'R':
                    score_blue += 1
                    print(f"{t} BLUE GOAL")
                else:
                    score_red += 1
                    print(f"{t} RED GOAL")
                quaffle_pos = center
                quaffle_carrier = None
            elif quaffle_pos in goals_blue:
                if entity[0] == 'B':
                    score_red += 1
                    print(f"{t} RED GOAL")
                else:
                    score_blue += 1
                    print(f"{t} BLUE GOAL")
                quaffle_pos = center
                quaffle_carrier = None

    print(f"FINAL SCORE: {score_red} {score_blue}")

solve()
```### 实施演练

 我们为玩家维护字典并设定目标以便快速查找。 鬼飞球由其位置的元组和跟踪载体的变量表示。 每个动作都会更新位置或进行适当的移动。 每次动作后，我们都会立即检查鬼飞球是否击中球门。 进球后将鬼飞球重置到中心可确保后续操作正确地继续模拟。 计算中心时仔细索引和整数除法可以避免差一错误。
