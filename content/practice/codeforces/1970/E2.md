 ## 解决方案
 ## 问题理解

 该问题描述了哈利·波特沿着小径在一组小屋和一个中央湖泊之间移动的场景。 每个小屋都有许多长短小径连接到湖泊。 每天，哈利都会进行两次移动：首先从他当前的小屋到湖边，然后从湖边到可能不同的小屋。 问题是这两个移动中至少有一个必须沿着一条短路径进行。 该问题询问移动序列的总数`n`天，从舱 1 开始，取模`10^9 + 7`。 

输入给出舱室数量`m`和天`n`，后面跟着两个数组`s`和`l`尺寸的`m`指定每个小屋的短径和长径的数量。 每个`s_i`和`l_i`最多为 1000，并且`m`最多为 100。`n`可以大到 10^9。 这立即排除了任何幼稚的模拟`n`因为每天的循环需要多达十亿次迭代，远远超出了 1 秒的运行时间。 

当机舱的短路径为零时，就会出现边缘情况。 假设哈利开始在这样的小屋里`s_i = 0`和`l_i > 0`。 在任何一天，他都必须使用至少一条短途路线，这可能迫使他只能前往允许短途路线的小屋。 另一个微妙的情况是当`s_i = 0`和`l_i = 0`对于一些小屋。 该算法必须正确处理无法进出小屋的情况。 

## 方法

 一种强力方法会尝试通过枚举从每个小屋到湖泊并返回的所有有效路径来模拟每一天，并按照至少一条路径必须较短的规则进行过滤。 每天大约有`O(m^2)`的可能性，所以对于`n`天这变成`O(m^2)^n`，这对于大的情况来说是完全不可行的`n`。 

关键的见解是，这个问题本质上是一个马尔可夫过程：系统的状态是哈利在一天开始时所在的小屋，序列的数量是通过乘以每天的转换计数来确定的。 这自然适合动态规划或矩阵求幂方法。 具体来说，如果我们构造一个`m x m`矩阵`T`在哪里`T[i][j]`是从小屋出发的路线数`i`到客舱`j`一天之内，则之后的序列总数`n`天数是第一行的总和`T^n`。 这里，`T^n`是矩阵提升到`n`次方，可以使用二进制求幂来有效计算`O(m^3 log n)`时间。 

蛮力方法在概念上是有效的，因为它枚举了所有可能性，但对于大的情况会失败`n`。 观察到问题可以简化为日常转换矩阵，使我们能够有效地计算大幂，同时尊重问题约束和模运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((m^2)^n) | O((m^2)^n) | O(m^2) | 太慢了 |
 | 矩阵求幂| O(m^3 log n) | O(m^3 log n) | O(m^2) | 已接受 |

 ## 算法演练

 1. 计算每日转移矩阵`T`。 对于每对客舱`(i, j)`，计算从`i`到`j`在一天之内。 这是两个动作序列的总和`(cabin -> lake -> cabin)`满足至少一条短路径的规则。 具体来说，对于客舱`i`到`j`，计数为`s_i*(s_j + l_j) + l_i*s_j`。 第一个术语说明从短路径开始，第二个术语说明从长路径开始但通过短路径到达。 
2. 实现快速矩阵求幂计算`T^n`模数`10^9 + 7`。 使用二进制求幂：在减半的同时重复对矩阵求平方`n`，并乘以累加结果`n`很奇怪。 
3. 初始化代表起始舱室的向量。 由于 Harry 从 1 号小屋开始，这个向量是`[1, 0, 0, ..., 0]`。 
4. 将起始向量乘以`T^n`获得每个舱室的最终计数`n`天。 对所有条目求和即可得到序列总数。 
5. 返回总模数`10^9 + 7`。 

为什么它有效：中的每个条目`T^n`计算从一个小屋到另一个小屋的所有有效序列`n`天。 二进制求幂可确保正确性，因为每个平方步骤都会正确计算转移矩阵的乘积，从而保留有效路径的总数。 模数确保不会发生整数溢出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mult(A, B):
    m = len(A)
    C = [[0]*m for _ in range(m)]
    for i in range(m):
        for j in range(m):
            for k in range(m):
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
    return C

def mat_pow(mat, power):
    m = len(mat)
    res = [[int(i==j) for j in range(m)] for i in range(m)]
    while power:
        if power % 2:
            res = mat_mult(res, mat)
        mat = mat_mult(mat, mat)
        power //= 2
    return res

def solve():
    m, n = map(int, input().split())
    s = list(map(int, input().split()))
    l = list(map(int, input().split()))
    
    T = [[0]*m for _ in range(m)]
    for i in range(m):
        for j in range(m):
            T[i][j] = (s[i]*(s[j]+l[j]) + l[i]*s[j]) % MOD
    
    T_n = mat_pow(T, n)
    result = sum(T_n[0]) % MOD
    print(result)

solve()
```这`mat_mult`函数将两个矩阵相乘取模`10^9 + 7`。`mat_pow`使用二进制求幂计算幂。 在`solve`，我们读取舱室计数并使用从每天至少一条路径必须较短的规则导出的公式构建转换矩阵。 最后一步对第一行求和`T^n`获取从小屋 1 开始的序列。
