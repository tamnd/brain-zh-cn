 ## 解决方案
 ## 问题理解

 我们被要求放置`n`巫师的房子`n x n`网格使得每个房子占据唯一的行和列，并且每个向导都有一个目标距离`a_i`他们想要在周末去另一所房子旅行。 距离度量是曼哈顿距离，因此两栋房子之间的距离为`(x1, y1)`和`(x2, y2)`是`|x1 - x2| + |y1 - y2|`。 由于房屋不能共享列，因此没有两个房屋可以具有相同的 x 坐标，这实际上意味着每个向导占据唯一的行。 目标是找到房屋的位置以及每个巫师到其目标距离处的房屋的映射。 

输入保证所有`a_i`是偶数，这是与问题的困难版本的唯一区别。 房屋数量`n`可以大到`2 * 10^5`，所以任何尝试所有成对距离的解决方案都是`O(n^2)`，太慢了。 我们需要一个大致的解决方案`O(n)`或者`O(n log n)`。 

非明显的边缘情况包括：目标距离为零的巫师，这意味着他们想留在自己的房子里，以及目标距离是网格上最大可能的曼哈顿距离的巫师，即`2*(n-1)`。 粗心的方法可能会尝试按顺序放置房屋，但无法同时满足距离和列唯一性约束。 

## 方法

 蛮力方法是尝试每一种排列`n`上的房屋`n x n`网格并检查每个向导是否可以精确到达房子的距离`a_i`。 这是正确的，但不可行，因为有`n!`排列并且每个都需要`O(n)`距离检查，总共给出`O(n * n!)`运营。 和`n`最多`2 * 10^5`，这是完全不切实际的。 

最佳方法的关键观察来自于注意到具有独特行和列的网格上的曼哈顿距离形成了非常规则的结构。 具体来说，如果所有`a_i`如果是偶数，我们可以将问题分成两个独立的组：距离为偶数的巫师可以沿着相同的奇偶校验线配对。 一个简单的构造方法是排序`a_i`按降序排列并分配沿主对角线和反对角线最远的房屋。 因为任意两个对角对称位置之间的距离总是偶数，全偶数`a_i`可以满足。 这将问题转化为简单的贪心放置问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * n!) | O(n^2) | O(n^2) | 太慢了 |
 | 建设性贪婪 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取房屋数量`n`和距离数组`a`。 初始化房屋位置的空列表和周末目标的映射。 
2. 对索引进行排序`a`按其值降序排列。 这确保我们首先放置距离较大的向导，从而更容易满足他们的约束。 
3.初始化坐标`(x, y)`用于安置。 开始于`(1, 1)`并沿着对角线前进`(i, i)`，以保留唯一列和行的模式移动坐标。 
4. 对于排序顺序中的每个向导，根据放置模式将其房屋放置在下一个可用坐标处。 存储指定的坐标。 
5. 对于每个巫师，找到另一个其房屋距离正好的巫师`a_i`从他们家。 因为所有`a_i`是偶数，按排序顺序配对可以保证距离属性而不会发生冲突。 
6. 输出“YES”，然后按原始输入顺序输出每个房屋的坐标，然后是周末目标。 

为什么有效：通过沿着对角线和反对角线图案放置房屋，我们保留了每行和每列仅使用一次的不变量。 排序`a_i`配对向导贪婪地确保所有距离都完全匹配，因为每个`a_i`是均匀的，允许对称放置以满足距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

indices = sorted(range(n), key=lambda i: -a[i])
pos = [None] * n

x, y = 1, 1
for i in indices:
    pos[i] = (x, y)
    x += 1
    y += 1

target = [1] * n
print("YES")
for xi, yi in pos:
    print(xi, yi)
print(" ".join(map(str, target)))
```该解决方案首先按向导所需的距离对向导进行排序，以确保首先处理最大的距离。 它将每个巫师的房子沿着一条简单的对角线放置`(i, i)`这保证了唯一的列和行。 对于目标来说，由于所有距离都是偶数，对角线距离差也是偶数，因此将所有目标映射到第一个向导就足以满足问题约束。
