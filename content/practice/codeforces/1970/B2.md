 ## 解决方案
 ## 问题理解

 我们被要求放置$n$巫师的房子$n \times n$网格使得每个巫师都可以在规定的曼哈顿距离到达另一个巫师的房子$a_i$，并且没有两栋房子共用同一根柱子。 这个中等版本的不同之处在于$a_1 = 0$，这意味着第一个巫师必须有一座距离自己为零的房子。 

输入由整数组成$n$和一个数组$a$长度$n$和$0 \le a_i \le n$。 如果不存在放置，则输出为 NO，或者后面跟着 YES$n$房屋的坐标和一个数组，指示每个巫师可以在所需距离访问哪个巫师。 允许多个正确的放置。 

因为$n$可以达到$2 \cdot 10^5$时间限制为2秒，算法比$O(n \log n)$可能太慢了。 尝试所有可能的坐标对的任何幼稚方法，这将是$O(n^2)$，将会超时。 主要困难来自于满足曼哈顿距离要求，同时保持列唯一性约束。 

边缘情况包括琐碎的放置$a_i = 0$为所有人$i$，这迫使所有巫师只能“拜访自己”，并且有些情况下$a_i = n$，需要最大可能的距离。 当距离需要沿网格呈锯齿形图案时，沿对角线的天真贪婪放置可能会失败，因此算法必须系统地考虑距离，而不是假设线性图案有效。 

## 方法

 暴力方法是枚举所有$n!$房屋可能放置在不同的列上，并为每一列检查向导是否可以在所需的距离找到目标。 这是可行的，因为第一个条件（没有列重叠）减少了可能的放置，但阶乘增长使得这对于大型$n$。 

关键的观察是两点之间的曼哈顿距离$(x_i, y_i)$和$(x_j, y_j)$可以写成$|x_i - x_j| + |y_i - y_j|$。 由于所有 x 坐标必须不同，因此我们可以任意固定 x 坐标（例如，1 到 n）并专注于 y 坐标。 按巫师与第一个巫师所需的距离对巫师进行排序可以实现建设性的放置：我们可以任意放置第一个巫师，然后将巫师放置在与第一个巫师的曼哈顿距离等于的位置$a_i$。 如果多个向导共享相同的距离，则可以将它们沿对角线或反对角线排列，以保持列中的唯一性。 问题归结为将网格分割成可以容纳所有距离的两条对角线。 这将复杂性降低到$O(n)$因为我们只计算坐标并检查距离一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 建设性的对角线放置| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 为第一个向导分配一个固定位置，例如，$(1, 1)$。 因为$a_1 = 0$，它们自动满足距离要求。 
2. 将剩余的巫师分成两组：那些与第一个巫师的距离可以通过增加 x 和减少 y（沿一条对角线移动）来表示的组，以及那些沿另一对角线移动的组。 这确保了列的唯一性。 
3. 初始化沿对角线的指针。 对于每个向导$i$，将它们放置在坐标处$(x, y)$这样$|x - 1| + |y - 1| = a_i$。 这可以通过迭代从 2 到 n 的可能 x 值并相应地计算 y 来完成。 
4. 跟踪哪个向导被分配到哪个距离，以便我们可以为每个向导填充“visit”数组。 如果有多个位置满足距离，则选择第一个可用的位置。 
5. 放置所有向导后，检查所有 x 坐标是否不同。 如果发生冲突，则输出NO； 否则，输出 YES 以及坐标和访问数组。 

为什么它有效：保持的不变量是第一个向导的位置是固定的，并且每个后续向导都沿着保持曼哈顿距离同时避免列碰撞的路径放置。 因为网格有$n$列和所有向导都分配有不同的 x 坐标，保证唯一性。 对角线放置确保总和$|x - x_1| + |y - y_1|$匹配每个$a_i$确切地。 这种建设性的方法避免了回溯或猜测，给出了线性时间解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if a[0] != 0:
        print("NO")
        return
    
    positions = [(1, 1)]
    used_cols = {1}
    # Two pointers for filling diagonals
    x_up, y_up = 2, 1
    x_down, y_down = 1, 2
    visit = [1]  # 1-based indexing
    
    for i in range(1, n):
        d = a[i]
        # Try first diagonal (increasing x, decreasing y)
        if x_up <= n and 1 <= d - (x_up - 1) + 1 <= n and (d - (x_up - 1) + 1) not in used_cols:
            y = d - (x_up - 1) + 1
            positions.append((x_up, y))
            used_cols.add(x_up)
            x_up += 1
            visit.append(1)
        # Otherwise, second diagonal (decreasing x, increasing y)
        elif y_down <= n and 1 <= d - (y_down - 1) + 1 <= n and (d - (y_down - 1) + 1) not in used_cols:
            x = d - (y_down - 1) + 1
            positions.append((x, y_down))
            used_cols.add(x)
            y_down += 1
            visit.append(1)
        else:
            print("NO")
            return
    
    print("YES")
    for x, y in positions:
        print(x, y)
    print(" ".join(map(str, visit)))

if __name__ == "__main__":
    solve()
```该解决方案首先固定第一个向导的位置。 采用两种对角线策略来分散后续房屋而不会发生柱冲突。 每个分配都会针对可用列进行验证，如果无法放置任何分配，算法会提前停止并显示“否”。
