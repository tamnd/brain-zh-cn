 ## 解决方案
 ## 问题理解

 我们得到一个仅由左括号和右括号组成的字符串。 该字符串保证是一个平衡的括号序列，这意味着“(”的总数与“)”的数量匹配，并且字符串的每个前缀至少有与“)”一样多的“(”。 我们的目标是产生一个称为平衡洗牌的新序列，其定义是根据每个字符之前的前缀平衡对字符进行排序，并通过先出现较晚的字符来打破平局。 

输入最多可达 500,000 个字符，因此任何扫描或排序的解决方案$O(n \log n)$是可以接受的，但是$O(n^2)$方法会太慢。 这排除了在嵌套循环中重复计算前缀平衡的任何暴力方法。 

要考虑的边缘情况包括完全嵌套的序列，例如“(((((())))))”，以及完全交替的序列，例如“()()()()”。 在嵌套序列中，多个字符可能共享相同的前缀平衡，因此通过减少位置来打破平局规则变得至关重要。 在交替序列中，前缀余额仅移动±1，这测试了算法在排序时是否正确保留相对顺序。 

## 方法

 暴力方法从字面上遵循问题描述：对于每个字符，计算其前缀平衡，创建一个三元组列表`(balance, position, character)`，然后使用给定的标准对此列表进行排序。 这是正确的，因为它完全遵循平衡洗牌的定义。 然而，排序步骤需要$O(n \log n)$表的创建需要$O(n)$，这是可以接受的，但更仔细的解决方案可以通过注意前缀余额是 0 到 n 之间的整数来避免构建显式表。 这允许我们使用计数排序方法。 

优化的关键见解是，由于余额在每一步增加或减少 1，因此余额的范围是有界的。 我们可以为每个可能的余额创建一个桶，从左到右扫描时将字符追加到桶中，然后按照余额递增的顺序输出桶中的字符。 当多个角色的平衡性相同时，将它们按照出现顺序相反的顺序添加，可以通过降低位置来打破平局。 这一观察减少了排序开销并产生了线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（显式表+排序）| O(n log n) | O(n log n) | O(n) | 已接受 |
 | 最优（按余额进行桶排序）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化变量`balance`为零以在我们扫描字符串时跟踪前缀余额。 
2. 创建一个字典或列表列表，其中每个键或索引对应于一个可能的余额，以存储出现在该余额处的字符。 
3. 从左到右扫描输入字符串。 对于每个字符：

 a. 记录当前`balance`并将该字符追加到相应的桶中。 

b. 如果字符是“(”，则递增`balance`; 如果是“)”，则递减`balance`。 
4. 扫描后，按余额递增的顺序迭代存储桶。 在每个桶内，以相反的顺序输出字符以满足平局规则。 
5. 连接字符以形成平衡的随机播放字符串并打印它。 

工作原理：该算法保持不变式，即每个字符在应用之前都存储在与其前缀余额相对应的存储桶中。 按余额对存储桶进行排序可确保具有较小前缀余额的字符在输出中较早出现。 反转每个桶中的字符可以通过减少位置来保留平局打破规则。 这再现了正式平衡洗牌定义的确切效果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)
balance = 0
# The maximum possible balance is n
buckets = [[] for _ in range(n + 1)]

for i, ch in enumerate(s):
    buckets[balance].append(ch)
    if ch == '(':
        balance += 1
    else:
        balance -= 1

result = []
for b in range(n + 1):
    # Reverse to respect decreasing position for tie-break
    result.extend(reversed(buckets[b]))

print(''.join(result))
```该代码首先扫描输入并根据其前缀平衡将每个字符分配到一个存储桶。 递增或递减`balance`确保正确的存储桶分配。 反转每个存储桶可确保如果多个字符共享相同的平衡，则原始字符串中较晚出现的字符会排在前面，从而符合平局打破规则。

 ## 边缘情况

 对于像“((()))”这样的输入，算法将第一个“(”分配给存储桶 0，第二个分配给存储桶 1，第三个分配给存储桶 2。“)”字符分配给存储桶 3,2,1。 反转每个桶会产生“() (())”，它可以保持平衡并通过在同一平衡中采用先出现的字符来正确应用平局打破规则。 对于最小输入“()”，bucket[0] 接收“(”，bucket[1] 接收“)”，并且输出与输入相同，表明该算法处理边界情况没有错误。
