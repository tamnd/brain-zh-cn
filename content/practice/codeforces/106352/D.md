 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，每个整数代表兹维罗波利斯的一名“工人”。 对于每个工人，我们必须从同一列表中选择不同的合作伙伴，以便最大化特定的交互分数。 

两个数字之间的分数$x$和$y$是根据它们的二进制表示来定义的。 我们查看所有位位置$i$，然后我们计算有多少个索引同时满足条件$x$和$y$在位置上有连续的$i$和$i+1$。 换句话说，对于每对相邻的位，我们检查两个数字是否在同一位置包含模式“11”，并计算有多少个这样的位置匹配。 

任务是，对于每个元素$a_i$，寻找另一个索引$j \neq i$最大化该分数，并输出该最大值。 

约束是解决方案的关键驱动因素。 元素数量最多可达$10^6$，所以任何关于数组的二次方都是不可能的。 即使对每个元素的所有其他元素进行线性扫描也会导致$10^{12}$最坏情况下的操作。 同时，每个值最多$10^6$，所以二进制表示很小，只有20位左右。 这强烈建议采用基于位掩码的解决方案，其中每个数字的“结构”比其大小更重要。 

当存在多个相同值时，会出现微妙的边缘情况。 由于工作人员无法与自己配对，因此如果所有出现的值都相同，我们必须确保我们仍然选择另一个副本（如果存在），否则我们必须回退到不同的合作伙伴。 

例如，如果数组是$[3, 3, 3]$，那么对于每个索引，最佳搭档是另外 3 个，答案是$F(3,3)$，不为 0 或未定义。 

另一个极端情况是当所有数字都不同并且在二进制结构中非常稀疏时，因此重叠处都是零。 在这种情况下，每个答案都应该正确为 0。 

## 方法

 直接方法尝试每一个可能的对$(i, j)$。 对于每一对，我们通过扫描所有位位置并检查两个数字是否包含连续的数字来计算分数。 由于每个数字最多有大约 20 个相关位位置，因此单次比较很便宜，但有$O(n^2)$对，对于$n = 10^6$。 这导致大约$10^{12}$结对评估，这在时间限制内是不可能的。 

关键的观察结果是分数仅取决于相邻设置位的模式。 对于每个数字，我们可以将其编码为位掩码，其中位$i$如果位置为 1$i$和$i+1$均设置为原始号码。 这将问题转化为纯粹的位掩码相似性任务：对于每个掩码，我们需要另一个掩码来最大化公共设置位的数量。 

因此，我们不再使用原始数字，而是将每个数字转换为$a_i$进入派生掩码$g(a_i)$。 然后分数就变成了简单的设置位数$g(a_i) \& g(a_j)$。 

现在的任务是：对于每个掩码，在集合中找到另一个使交集大小最大化的掩码。 由于位宽较小（20左右），我们可以采用子集动态规划的思想。 

我们预先计算输入中存在哪些掩码，然后对子集进行推理。 主要思想是对每个可能的子集进行预先计算$S$，是否存在至少一个其派生掩码包含的数字$S$。 然后，对于固定的查询掩码$A$，与另一个掩码的任何公共交集对应于某个子集$S \subseteq A$这也包含在其他一些面具中。 

然后我们搜索最大的子集$S$，因为最大化交集大小相当于最大化$S$。 

这将问题从成对比较减少到子集上的结构化搜索，这可以使用 20 位空间上的 SOS 动态编程来处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2 \cdot 20)$|$O(1)$| 太慢了|
 | 面具上的 SOS DP |$O(2^m \cdot m)$,$m \le 20$|$O(2^m)$| 已接受 |

 ## 算法演练

 让$m \approx 20$是导出掩码中位位置的最大数量。 

1. 转换每个数字$a_i$变成面具$g_i$，其中位$k$如果两个位都被设置$k$和$k+1$是 1 在$a_i$。 这将每个数字压缩成一个结构签名，该结构签名完全确定所有成对分数。 
2. 统计每个掩码的频率。 这是为了处理一个号码可以与另一个相同号码配对的情况。 
3. 构建数组`exist[S]`指示是否至少有一个输入掩码等于$S$。 
4. 在超集上运行 SOS DP 进行计算`sup[S]`，输入中包含的掩码数量$S$。 这使我们能够快速检查候选交叉模式是否确实出现在某个有效伙伴内部。 
5. 定义`good[S]`为真，如果$S$可以用作具有至少一个伙伴掩码的有效交叉模式。 最初这是`sup[S] > 0`。 
6. 定义`best[S]`作为子集的最大大小$T \subseteq S$这样`good[T]`是真的。 这是使用子掩码 DP 计算的，该子掩码 DP 将最佳值从较小的掩码传播到较大的掩码。 
7. 对于每个查询掩码$A$，答案是`best[A]`，除非最佳子集等于$A$本身，并且这个精确的掩码仅在输入中出现一次。 在这种情况下，我们必须排除自配对，因此我们回退到内部的下一个最佳有效子集$A$。 

正确性来自于两个掩码之间的任何公共交集本身就是两个掩码的子集这一事实。 因此，每个有效分数完全对应于查询掩码的某个子集，并且最大化分数相当于找到至少一个其他元素可实现的最大此类子集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXB = 20
MAXM = 1 << MAXB

n_and_rest = sys.stdin.read().strip().split()
n = int(n_and_rest[0])
a = list(map(int, n_and_rest[1:]))

# Step 1: build derived masks g(x)
def build_mask(x):
    res = 0
    for i in range(MAXB - 1):
        if (x >> i) & 1 and (x >> (i + 1)) & 1:
            res |= 1 << i
    return res

freq = [0] * MAXM
masks = []

for x in a:
    g = build_mask(x)
    masks.append(g)
    freq[g] += 1

# Step 2: superset DP to compute sup[S]
sup = freq[:]
for i in range(MAXB):
    for mask in range(MAXM):
        if (mask >> i) & 1 == 0:
            sup[mask] += sup[mask | (1 << i)]

# Step 3: good masks
good = [sup[i] > 0 for i in range(MAXM)]

# Step 4: best submask DP
best = [-1] * MAXM
for mask in range(MAXM):
    if good[mask]:
        best[mask] = bin(mask).count("1")

for i in range(MAXB):
    for mask in range(MAXM):
        if mask & (1 << i):
            if best[mask ^ (1 << i)] > best[mask]:
                best[mask] = best[mask ^ (1 << i)]

# Step 5: answer queries
res = []
for i, g in enumerate(masks):
    ans = best[g]

    # handle self-exclusion if needed
    if ans == bin(g).count("1") and freq[g] == 1:
        # try to find second best by temporarily ignoring full mask
        tmp = g
        best_full = best[g]
        best_without = -1

        # recompute only over submasks of g
        s = tmp
        sub = s
        while True:
            if good[sub] and sub != tmp:
                best_without = max(best_without, bin(sub).count("1"))
            if sub == 0:
                break
            sub = (sub - 1) & s

        ans = best_without

    res.append(str(ans))

print(" ".join(res))
```该实现遵循以下思想：将每个数字压缩为 20 位结构掩码，然后使用超集 DP 来确定哪些交集模式是可行的。 子掩码 DP 步骤将可行性转化为每个掩码最佳得分表，因此每个查询都变成直接查找。 

唯一微妙的部分是当掩码只出现一次时排除自配对。 这种情况通过扫描查询掩码的子掩码来单独处理，这是可行的，因为掩码大小最多为 20 位。 

## 工作示例

 考虑示例：

 从数字导出的输入掩码会产生小的位模式，并且 DP 构建所有可行的交集子集。 对于像这样的面膜`g = 0101`，该算法检查所有子集，例如`0101`,`0100`,`0001`,`0000`并选择其他元素中存在的最大的。 

第二个例子：

 让数字产生掩码：```
A = 1100
B = 1010
C = 1000
```为了`A`，子掩码是`1100`,`1000`,`0100`,`0000`。 如果`1000`存在于另一个掩码中，即使完全重叠 2 不可能，答案也变为 1。 

对于每个元素，DP 确保我们始终选择最大的可实现重叠。

 ## 边缘情况

 一种重要的边缘情况是，掩码的最佳伙伴是其本身，但只存在一个副本。 在这种情况下，算法的原始 DP 将错误地允许自配对。 后备子掩码扫描可确保我们明确排除完整掩码并搜索下一个最佳子集，从而保持正确性。 

另一个边缘情况是所有掩码都为空时。 然后每个交集都为零，并且 DP 正确地将所有最佳值保留为零，因为空掩码始终是有效子集并且始终存在于数据集中。 

最后一种情况是存在多个相同的掩码。 然后自配对变得有效，因为存在另一个事件，并且频率检查允许满分子集保留答案而不进行修改。
