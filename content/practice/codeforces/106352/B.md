 ## 解决方案
 ## 问题理解

 我们得到了一系列彩弹，每个彩弹的特征都是它飞行的时刻和垂直位置（墙上的一排）。 墙有高度`h`，行从下到上编号。 每个彩弹仅在其给定时间存在并且只影响一行。 

在某个选定的开始时间`t0`，固定高度的屏蔽`w`放置覆盖行`[1, w]`。 之后，每一秒它都会向上移动一行，所以在时间`t0 + k`它覆盖行`[1 + k, w + k]`。 一旦到达最上面的有效位置`[h - w + 1, h]`，它会在那里停留一秒钟，然后消失。 如果在准确的时间，彩弹所在的行位于护盾覆盖的当前间隔内，则彩弹被阻挡。 

任务是选择`t0`最大限度地增加被阻挡的彩弹数量。 

输入大小可达`n = 10^5`，行坐标和时间达到`10^9`。 这立即排除了任何尝试模拟屏蔽的每个可能的启动时间或生命周期的每一秒的解决方案。 二次或偶数`O(n log n)`每个候选人针对所有候选人的策略会太慢。 

一个关键的困难是每个彩弹约束都耦合了时间和行：它是否被阻止取决于其时间和所选开始时间之间的线性关系。 

一些边缘情况很重要。 

一种是多个彩弹同时发生但在不同的行。 例如，如果在某个时间`t = 5`我们有行`1, 2, 10`和`w = 2`，只能覆盖连续的两行，因此最多可以阻止两行，而不能阻止全部三行。 

另一个是当`w = h`。 在这种情况下，无论位置如何，护盾都会覆盖整个网格一秒钟，因此答案就变成简单地计算与任何有效护盾存在间隔一致的始终存在的彩弹数量，事实上，如果我们对齐，每个彩弹都可以被阻挡`t0`与它的时间。 

第三个微妙的边缘情况是排序：盾牌随着时间确定性地移动，因此让它“传送”或在中间位置固定多秒的错误解释会导致方块计数过多。 

## 方法

 暴力方法会尝试所有可能的开始时间`t0`从所有彩弹射击时间的集合中。 对于每位候选人`t0`，我们逐秒模拟盾牌的移动，并检查每个彩弹，看看它当时是否被覆盖。 这在概念上是有效的，因为一旦屏蔽行为是完全确定的`t0`是固定的，所以正确性不是问题。 

问题是性能。 如果我们尝试`O(n)`可能的`t0`值，对于每个值，我们扫描所有`n`彩弹射击，我们已经得到了`O(n^2)`，这远远超出了极限`n = 10^5`。 更直接地，模拟屏蔽范围可达`h`步骤是不可能的，因为`h`可以达到`10^9`。 

关键的观察是每个彩弹都会对有效`t0`价值观。 对于彩弹射击`(t, s)`要被阻挡，盾牌必须覆盖行`s`在某个时间`t`，这意味着：```
1 + (t - t0) <= s <= w + (t - t0)
```重新排列两个不等式给出有效区间`t0`该彩弹所涵盖的值。 所以每个彩弹都成为数轴上的一段`t0`。 

一旦完成这个转换，问题就简化为寻找一个点`t0`位于最大间隔数之内。 这是一个经典的间隔最大重叠问题，可以通过对端点进行排序和扫描来解决。 

微妙的一点是，我们还需要尊重护盾仅存在有限的秒数。 然而，这个约束自然地由区间推导编码，因为在有效范围之外，不等式只会产生空区间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟全部开始 | O(n²) | O(1) | O(1) | 太慢了|
 | 区间变换+扫线 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ### 密钥转换

 1. 对于每个彩弹射击`(t, s)`，得出范围`t0`使其被阻止的值。 

当时的盾牌`t`覆盖行`[1 + (t - t0), w + (t - t0)]`。 我们要求：```
1 + (t - t0) <= s <= w + (t - t0)
```解决这两个不等式可以得到：```
t - s + 1 <= t0 <= t - s + w
```所以每个彩弹都变成了一个间隔`[L, R]`关于可能的开始时间的时间表。 
2. 收集所有彩弹射击的所有此类间隔。 每个有效`t0`对应于选择屏蔽轨迹的垂直对齐。 
3. 我们想要`t0`在于这些间隔的最大数量，相当于最大间隔重叠。 
4. 将每个间隔转换为两个事件：+1 at`L`, -1 在`R + 1`。 
5. 按坐标对所有事件进行排序，然后从左到右扫描以保持连续总和。 
6. 跟踪运行总和的最大值； 这就是答案。 

### 为什么它有效

 每个彩弹独立贡献一个条件`t0`。 单个`t0`当该彩弹位于其派生区间内时，该彩弹准确有效。 因此，计算有多少个区间包含给定的`t0`就是精确地计算有多少个彩弹被阻挡。 扫描线找到最大重叠点，该点直接对应于最佳开始时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, h, w = map(int, input().split())

events = []

for _ in range(n):
    t, s = map(int, input().split())
    L = t - s + 1
    R = t - s + w
    events.append((L, 1))
    events.append((R + 1, -1))

events.sort()

cur = 0
best = 0

for x, delta in events:
    cur += delta
    if cur > best:
        best = cur

print(best)
```实现的核心是区间转换步骤。 每个彩弹射击都会转化为一系列开始时间`t0`它被阻塞的地方。 排序事件端点上的扫描线会累积同时满足的此类约束的数量。 

一个微妙的细节正在使用`R + 1`对于负面事件。 这确保了间隔在两端都被视为包含在内，同时仍然与整数扫描逻辑兼容。 如果没有这种转变，相差一的错误就会错误地计算出恰好位于护盾覆盖范围边界上的彩弹。 

另一点是我们从未明确使用`h`。 尽管它定义了屏蔽路径的物理约束，但它被隐含地尊重，因为导出的不等式已经编码了可行性。

 ## 边缘情况

 关键的边缘情况是彩弹在给定的秒内恰好位于防护罩的下边界或上边界。 区间推导包括两个边界，因此此类彩弹必须被视为有效。 如果我们在转换约束时使用严格的不等式，这些情况将被错误地丢弃。 

当导出的间隔超出可行的时间范围时，会出现另一种边缘情况。 例如，早期非常高的行会产生负值`L`。 这不是问题，因为整数上的扫描线自然可以处理无界范围； 这些间隔只是比其他间隔开始得早。 

最后，多个重叠的彩弹在相同的`(t, s)`值产生相同的间隔。 扫描正确地计算了重数，因为每个重数都会贡献一个单独的 +1 事件，从而确保重复项的正确聚合。
