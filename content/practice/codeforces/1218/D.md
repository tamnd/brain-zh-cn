 ## 解决方案
 ## 问题理解

 我们得到一个无向图，其中每条边代表两个行星之间的虫洞并具有修复成本。 目标不是构建具有最小权重总和的经典生成树，而是选择边的子集，使图与首都保持连接，同时最小化一个非常不同的目标：所选边权重的按位异或。 

一旦我们选择了一组连接所有顶点的边，我们就计算它们的权重的异或。 在所有有效的连接选择中，我们想要尽可能小的 XOR 值。 找到最小值后，我们还需要计算有多少个不同的边子集达到该最小值，模 1e9 + 7。 

输入大小立即排除了直接枚举子集或生成树的可能性。 对于多达 100,000 条边，任何考虑所有边子集的方法都是不可能的。 即使对顶点子集进行动态规划也是不可行的。 

该结构更接近图生成树问题，但成本函数仅取决于边上的异或，而不是它们的总和。 这强烈表明 GF(2) 上的线性代数将会出现，因为 XOR 的行为类似于二进制向量空间中的加法。 

当图形具有生成边权重 XOR 组合的循环时，就会出现微妙的边缘情况。 例如，如果我们有一个边为 1、2、3 的循环，那么我们可以通过切换整个循环来选择任何不同的子集，并且 XOR 以可预测的线性方式变化。 简单的生成树方法会忽略这种灵活性并错过替代的 XOR 值。 

另一种边缘情况是当存在多个产生相同异或的生成树时，这可能发生在具有冗余循环的图中。 正确计算这些需要了解循环空间维度，而不是枚举树。 

## 方法

 直接的强力策略将尝试图中的所有生成树，计算它们的边的异或，并跟踪最小值。 即使忽略正确性问题，稠密图中的生成树数量也是 N 的指数级，即使对于稀疏图，生成树的数量也会变得非常大。 这使得暴力破解变得不可行。 

关键的观察是任何连接的生成子图都可以分解为生成树加上一组额外的循环边。 所选边集的 XOR 等于生成树的 XOR 加上循环的 XOR 贡献。 每个循环都会引入对 GF(2) 的线性约束：添加或删除循环的所有边会按固定值翻转 XOR。 这意味着所有可实现的 XOR 值形成由循环 XOR 生成的线性空间。 

我们可以选择任何生成树作为基础并计算其异或值。 然后，对于每个非树边，我们形成一个基本循环并计算该循环的异或。 每个这样的循环异或充当比特上线性基础中的基础向量。 使用 GF(2) 上的高斯消去法，我们可以构建循环异或的线性基础。 

构建基础后，我们通过使用基础向量贪婪地消除最高位，将初始生成树异或减少到最小可能值。 实现这一最小值的方法数量取决于基础中存在多少个独立的零贡献，这对应于循环空间中的自由选择的数量。 

因此最终答案数为$2^{k}$， 在哪里$k$是不影响最小化异或状态的基向量的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(M)| 太慢了 |
 | 最优（周期内的线性基础）| O(M α(N) + B²) | O(B) | 已接受 |

 ## 算法演练

 我们首先使用生成树减少图结构，然后将剩余的边视为异或变换的生成器。 

1. 使用 DFS 或 DSU 构建图的任意生成树。 执行此操作时，如果需要，请记录父关系以及从根到每个节点的异或距离。 目标是拥有一个无循环连接所有节点的基础结构。 
2. 对于不在生成树中的每条边，计算其形成的环的 XOR 值。 这是通过沿树的端点之间的异或距离加上边权重来完成的。 该值表示该边在替换树结构的一部分时如何修改总 XOR。 
3. 将每个周期的 XOR 值插入位的线性基础中。 该基础代表通过切换周期可实现的所有异或变化。 插入遵循从最高位到最低位的标准贪婪按位缩减，确保基向量的独立性。 
4. 计算初始生成树边的 XOR，作为应用循环变换之前的基本 XOR 值。 
5. 使用线性基减少该基 XOR。 对于从最高位到最低位的每个基向量，如果进行异或运算会减少当前值，则应用它。 这种贪婪地最小化结果是因为在二进制 XOR 最小化中较高位在字典顺序上占主导地位。 
6. 计算有效解决方案的数量。 每个未用于减少 XOR 的基向量对应于一个自由的二进制选择。 如果基的秩为 r 并且图有 m 个边和 n 个顶点，则自由分量的数量为$m - n + 1 - r$，并且每个贡献因子为 2。 

### 为什么它有效

 图中的每个周期都对应于边缘上的二元向量，指示切换该周期时哪些边缘翻转。 这些向量在 GF(2) 上形成向量空间。 任何生成连通子图与固定生成树的不同之处在于添加了这些循环向量的子集。 

这意味着所有可能的 XOR 值的集合恰好是一个仿射空间：固定基 XOR 加上循环 XOR 向量的所有线性组合。 线性基约简正确地找到了该空间中的最小代表，并且代表的数量恰好对应于零空间的大小，即$2^{\text{cycle dimension} - \text{rank used for reduction}}$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXB = 20  # since W <= 1e5

def insert_basis(basis, x):
    for b in reversed(range(MAXB)):
        if not (x >> b) & 1:
            continue
        if basis[b] == 0:
            basis[b] = x
            return
        x ^= basis[b]

def reduce_xor(basis, x):
    for b in reversed(range(MAXB)):
        if basis[b] and (x ^ basis[b]) < x:
            x ^= basis[b]
    return x

def main():
    n, m = map(int, input().split())
    
    g = [[] for _ in range(n + 1)]
    edges = []

    for _ in range(m):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))
        edges.append((u, v, w))

    parent = [0] * (n + 1)
    depth_xor = [0] * (n + 1)
    visited = [False] * (n + 1)

    stack = [1]
    visited[1] = True
    tree_edges = set()

    # build spanning tree + xor distances
    while stack:
        u = stack.pop()
        for v, w in g[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                depth_xor[v] = depth_xor[u] ^ w
                tree_edges.add((u, v, w))
                stack.append(v)

    basis = [0] * MAXB

    tree_xor = 0

    edge_in_tree = set(tree_edges)

    for u, v, w in edges:
        if (u, v, w) in edge_in_tree or (v, u, w) in edge_in_tree:
            tree_xor ^= w
        else:
            cycle_val = depth_xor[u] ^ depth_xor[v] ^ w
            insert_basis(basis, cycle_val)

    min_xor = reduce_xor(basis, tree_xor)

    rank = sum(1 for x in basis if x)

    # number of free cycle edges is m - n + 1
    free = (m - n + 1) - rank
    if free < 0:
        free = 0

    ans_cnt = pow(2, free, MOD)

    print(min_xor, ans_cnt)

if __name__ == "__main__":
    main()
```DFS 构建一棵有根生成树，并为每个节点分配距根的异或距离，这允许使用两个端点和一个边权重在恒定时间内计算任何循环值。 线性基函数对循环 XOR 值进行运算，而不是原始边缘，这是使问题呈线性的关键变换。 

计数部分依赖于将循环空间维度与实际影响最小化的约束等级分开。 只有不用于减少异或的独立循环才有助于多重有效构造。

该迹线显示了循环边缘 (2-3,4) 如何在不影响连接性的情况下更改 XOR 空间。

 ## 边缘情况

 对于单节点图，没有边，因此没有环。 该算法构造一个空基，初始异或为零。 由于不存在选择，因此单向输出成本为零。 

在纯树中，恰好有 n - 1 条边，并且没有环边。 基础仍然是空的，因此不可能进行任何转换。 答案很简单，就是对树中所有边进行异或，计数为一。 

在具有许多冗余循环的图中，多个非树边会生成相关的 XOR 值。 高斯消除确保只有独立的循环向量保留在基础中。 这可以防止通过过度计数的方式来减少 XOR。 

在像三角形这样的完全连接的小图中，每条边都对循环空间有贡献，但只存在一个独立的循环。 该算法正确地将所有循环效应折叠成单个基向量，从而保持最小化和计数的正确性。
