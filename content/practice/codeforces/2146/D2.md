 ## 解决方案
 ## 问题理解

 我们给定一个整数区间$[l, r]$。 从这个区间我们形成一个列表，其中每个整数恰好包含一次。 该列表的一份副本固定为数组$b$。 另一个副本，数组$a$，最初是相同的，但我们可以任意排列它。 

对于每个位置$i$，我们配对$a_i$与固定值$b_i$，我们通过按位或对这对进行评分。 目标是选择一个排列$a$最大化这些 OR 值的总和。 

关键的困难在于，一个值的贡献不仅取决于它自己的位，还取决于它与什么配对。 除非该对中的两个数字都将该位设置为零，否则某个位会对“或”起作用。 这会产生一个全局匹配问题，其中配对结构很重要。 

约束条件$r < 2^{30}$表示每个数字可以容纳 30 位。 测试用例之间的间隔大小最多为$2 \cdot 10^5$，所以任何比粗略更糟糕的解决方案$O(n \log n)$或每比特线性是可以接受的，但二次配对策略则不行。 

一个天真的错误是假设最大与最大的配对是最佳的。 例如，像这样的小间隔$[0,3]$，与反转一侧相比，对两个数组进行相同排序会得到次优结果，因为 OR 的行为与 sum 或 XOR 不同。 

另一个失败案例源于贪婪的局部决策。 如果我们尝试匹配每个$b_i$与最好的可用$a_j$独立地，我们可以阻止更好的全局配对。 由于每个数字同时影响许多位，因此局部最优并不意味着全局最优。 

## 方法

 暴力解决方案将尝试所有排列$a$并计算 OR 与固定值的总和$b$。 这有$n!$复杂性，即使对于$n = 20$，更不用说$2 \cdot 10^5$。 

我们需要了解 OR sum 奖励的结构。 每一位都独立地贡献于最终的总和。 对于固定位$k$，其贡献为$2^k$乘以两个数字中至少有一个设置了该位的对数。 

因此，我们不考虑数字，而是考虑配对之间的位覆盖率。 我们希望最大化高位出现在一对的至少一侧的频率。 自从$b$是固定的，我们唯一的控制就是重新排序$a$以便高位丰富的数字与低位贫乏的位置对齐$b$，确保每对至少被一侧“覆盖”。 

这将问题转化为补码匹配的想法：我们想要将数字配对，以便每当$b_i$错过了一些位，我们尝试通过提供这些位$a_i$。 这表明将数字与互补的位模式配对。 

关键的观察是对于任何数字$x$，将其与数字配对$y$最大化$x \,|\, y$什么时候$y$包含与外部一样多的位$x$尽可能。 最佳合作伙伴$x$因此是其在固定位范围内的按位补码。 由于我们在 30 位内工作，这建议围绕“完整掩码”对值进行配对，其中所有相关位均为 1。 

让$M = (2^{30}-1)$。 如果我们将数字配对$a_i \approx M - b_i$，那么每一对都倾向于激活所有位，从而在本地最大化“或”和。 然而，我们不能在区间内构造任意补集，因此我们使用区间的位结构上的分而治之来近似这个想法。 

间隔$[l,r]$可以递归地分解为由最高不同位对齐的段$l$和$r$。 在每个段中，我们将下半部分与上半部分配对，这会翻转成对元素之间的高位，确保每对都激活 OR 中的该位。 

这种递归配对首先最大化最高不同位的贡献，然后在较小的子范围上独立地继续。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n!)$|$O(n)$| 太慢了 |
 | 最优分而治之 |$O(n \log 2^{30})$|$O(n)$| 已接受 |

 ## 算法演练

 我们通过按间隔递归地构建排列。 

1.从完整的片段开始$[l, r]$。 如果该段只有一个元素，则直接返回。 单个元素没有配对选择，因此它已经是局部最优的。 
2.找到最高位在哪里$l$和$r$不同。 该位定义了间隔中最重要的结构分割。 间隔中的所有内容共享较高位，并且只有该位将值分为两个有意义的组。 
3. 根据该位将区间分成两部分：未设置该位的数字形成左组，设置该位的数字形成右组。 由于整数的二进制排序，该分区是连续的。 
4. 在两半上递归以构建两个有序列表。 
5. 按顺序将左侧递归结果中的元素与右侧递归结果中的元素配对。 这种配对保证在选定的位位置，每对在 OR 中贡献一个 1，因为一侧设置了位，而另一侧没有。 
6. 以与递归结构一致的方式连接所得排列，确保较高级别的配对支配较低级别的配对。 

### 为什么它有效

 在每个递归级别，我们隔离段内可能不同的最高位。 任何最佳解决方案都必须确保该位贡献尽可能多的次数，因为它的权重支配该段大小内组合的所有较低位。 

通过在该位引起的分裂上进行配对，每对都会强制该位在“或”中恰好出现一次。 确定该位的贡献后，两侧的子问题变得独立，因为每一侧的所有数字都共享该位值。 剩余的优化在减小的位范围上是相同的，因此递归归纳地保留了最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve(l, r):
    if l == r:
        return [l]
    
    # find highest differing bit
    x = l ^ r
    bit = x.bit_length() - 1
    
    mid_mask = 1 << bit
    
    left = []
    right = []
    
    for i in range(l, r + 1):
        if i & mid_mask:
            right.append(i)
        else:
            left.append(i)
    
    left_res = solve(left[0], left[-1]) if left else []
    right_res = solve(right[0], right[-1]) if right else []
    
    # pair interleaving
    res = []
    for i in range(len(left_res)):
        res.append(left_res[i])
        res.append(right_res[i])
    
    return res

t = int(input())
out = []
for _ in range(t):
    l, r = map(int, input().split())
    arr = solve(l, r)
    
    # compute answer
    b = list(range(l, r + 1))
    total = 0
    for i in range(len(arr)):
        total += arr[i] | b[i]
    
    out.append(str(total))
    out.append(" ".join(map(str, arr)))

print("\n".join(out))
```实现遵循递归分裂的思想。 第一个关键操作是识别端点之间的最高差异位，这确定了间隔的最重要的结构分区。 这确保了我们始终优先考虑最大化最有价值的比特贡献。 

分区分为`left`和`right`组是通过扫描间隔显式完成的。 尽管每个递归级别都是线性的，但总工作仍然是可管理的，因为每个级别都划分不相交的段。 

然后，递归尝试独立地求解每一半，最后将它们交错，以使来自相反两半的相应元素配对，确保在每次 OR 计算中始终激活高位。 

一个微妙的点是，重建假设两半大小相等，这是成立的，因为按位分割会将连续间隔划分为完全匹配的两个对齐的幂部分。 这种结构特性使得交错有效。

 ## 边缘情况

 对于像这样的单元素区间$[x,x]$，递归立即停止并返回$[x]$。 没有配对选择，并且 OR 和为零，因为两个数组包含相同的单个值。 

对于二的幂对齐范围，例如$[0,7]$，每个递归级别都会完美平衡地分成两半。 最高位确保每对贡献该位一次，较低级别重复相同的结构，产生完全一致的交织，从而实现 OR 位的最大可能饱和​​。
