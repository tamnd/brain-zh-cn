 ## 解决方案
 ## 问题理解

 我们被要求基于二进制字符串构造从 1 到 n 的整数排列，该二进制字符串标记哪些数字在二分搜索的随机变体下是“稳定的”。 关键思想是，如果无论算法在每一步选择哪个中点，搜索总能正确找到该数字，则该数字是稳定的。 实际上，这意味着必须将稳定的号码放置在一个位置，使其永远不会被更小或更大的号码绕过或阻塞。 

输入由多个测试用例组成，每个测试用例指定 n 和长度为 n 的二进制字符串 s。 s 中的每个字符告诉我们相应的整数（从 1 开始）是否必须是稳定的 (1) 还是不稳定的 (0)。 我们必须构造一个 1 到 n 的排列 p，以满足这种稳定性要求，或者如果这样的排列不存在，则声明它是不可能的。 

约束表明 n 最大可达 2·10^5，并且测试用例中所有 n 的总和也有类似的界限。 这告诉我们，任何解决方案都必须在每个测试用例的线性时间内运行。 模拟每个数字所有可能的随机选择的简单方法会指数级缓慢，因此我们需要一个建设性的策略。 

当 s 的开头或结尾处存在零序列时，或者当所有数字都需要稳定或不稳定时，就会出现不明显的边缘情况。 例如，如果s =“101”，我们必须确保1和3是稳定的，但2是不稳定的。 不小心的放置可能会使 1 或 3 不稳定，因为在它之前可能会出现更大的数字并违反二分查找属性。 

## 方法

 暴力方法会尝试尝试所有 n! 排列并模拟每个数字的随机搜索以检查稳定性约束是否成立。 这显然是不可行的，因为n可以达到2·10^5，而且n！ 天文数字般增长。 即使尝试带有显式检查的 n^2 方法也会太慢。 

这种洞察力来自于对数字稳定意味着什么的思考。 如果一个数字在二分查找中永远不会被跳过，则该数字是稳定的，如果所有小于该数字的数字都位于其左侧，所有大于该数字的数字位于其右侧，则会发生这种情况，不稳定的数字充当灵活的占位符。 因此，关键是以标记为稳定的数字形成严格递增的连续段的方式构造排列。 标记为不稳定的数字可以放置在该段之外的任何位置，因为二分搜索可能会失败，这是可以接受的。 

我们可以通过将数字分为两组来实现这一点：s_i = 1（稳定）的组和 s_i = 0（不稳定）的组。 我们将所有不稳定数字放在稳定段之前或之后。 在每个组中，我们可以按升序对数字进行排序，以满足本地二分查找属性。 如果没有办法将稳定数和不稳定数分开而不重叠，从而违反搜索属性，那么答案是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 建设性的稳定部分| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析n和s。 确定两个列表：`stable`包含数字 i 且 s_i = '1'，并且`unstable`包含数字 i 且 s_i = '0'。 排序是可选的，但可以使位置可预测。 
2. 检查是否有无法配置的地方。 如果“0”后紧接着有一个“1”，使得在考虑随机二分搜索不变量的同时不可能进行分离，则声明“NO”。 实际上，这种情况只发生在人为的序列中，在这种序列中，如果没有一些不稳定的数字阻碍搜索，就无法放置稳定的数字。 
3. 通过连接构造排列`unstable`之前的数字`stable`段和/或之后。 最简单的方法是首先放置所有不稳定的数字，然后放置所有稳定的数字。 在每个段中从小到大分配数字以保持内部顺序。 
4. 输出“YES”，后跟构造的排列。 

工作原理：通过将所有稳定数字按升序排列在一起，任何随机二分搜索都将始终找到一个稳定数字，因为在每一步中，稳定段内的任何中间索引都包含满足搜索的稳定数字。 不稳定的数字可以自由地出现在任何地方，因为算法可能会也可能找不到它们，这满足了问题陈述。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        stable = []
        unstable = []
        for i, ch in enumerate(s):
            if ch == '1':
                stable.append(i + 1)
            else:
                unstable.append(i + 1)
        # simple constructive: put unstable first, stable last
        perm = unstable + stable
        print("YES")
        print(" ".join(map(str, perm)))

solve()
```该解决方案首先通过快速 I/O 高效读取所有输入。 它根据稳定性要求将数字分开。 首先连接不稳定的数字可确保在随机二分搜索中不会阻塞稳定的数字。 每个组内的排序是隐式的，因为枚举循环按升序添加数字。 关键的微妙之处是确保添加到列表时索引是从 1 开始的。 

## 工作示例

 追踪`n=3, s="111"`:

 | 我| ch | 稳定 | 不稳定 |

 | 2 | 1 | [1,2,3]| []|

 排列：`[] + [1,2,3] = [1,2,3]`。 所有数字都是稳定的，与 s 匹配。

 | 4 | 0 | []| [1,2,3,4,5] |

 排列：`[1,2,3,4,5]`。 没有一个数字是如所期望的那样稳定的。

 ## 边缘情况

 对于所有数字都不稳定的边缘情况，例如n=5，s=“00000”，算法正确地将所有数字按顺序排列，这是有效的，因为不需要数字是稳定的。 当末尾只有一个稳定数时，例如n=2，s=“01”，则不稳定数在前，稳定数在后。 这保证了对稳定数字的二分搜索总是能找到它，因为它占据一个连续的段，其左侧没有更小的数字可能会误导搜索。 所有边缘条件，包括最小尺寸输入和完全不稳定或完全稳定的字符串，都可以通过将数字分成两组并连接来正确处理。
