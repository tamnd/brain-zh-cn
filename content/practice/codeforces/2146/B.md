 ## 解决方案
 ## 问题理解

 我们得到了几个整数集合，其中每个集合都可以被视为来自该范围的“标签束”$1$到$m$。 我们想要选择这些集合的一些子集，以便在合并所有选定的集合后，来自的每个数字$1$到$m$至少出现一次。 

问题不是要计算到底有多少个有效选择，而只是确定是否存在至少三个不同的有效选择。 

选择是给定集合的任何子集，包括空集（如果它已经涵盖了所有内容）（这在这里是不可能的，除非$m = 0$，因此实际上我们只关心涵盖所有值的非空选择）。 

这些约束迫使我们以线性或近线性行为的方式进行思考。 所有集合中的元素总数最多为$2 \cdot 10^5$，因此任何检查每个元素恒定次数的解决方案都是可行的。 然而，任何试图直接枚举子集甚至推理所有集合组合的行为都是立即不可能的，因为$n$可以达到$5 \cdot 10^4$。 

一个关键的结构点是有效选择的数量在很大程度上取决于覆盖范围的冗余。 如果每个数字都只包含一组，那么选择就会急剧崩溃。 如果覆盖范围重叠，有效选择的数量会以组合方式爆炸。 

一些边缘场景说明了该结构：

 如果有一些数$x$没有出现在任何集合中，那么任何选择都不会有效。 例如，如果$m=3$并且没有集合包含$2$，答案立即是“NO”。 

如果每个数字恰好出现在一个集合中并且所有集合都是不相交的，那么如果每个集合包含唯一元素，则该集合将成为强制性的。 如果存在有效的封面，则有效选择的数量将缩减为恰好 1。 

另一方面，如果所有集合都是相同的并且已经涵盖了所有数字，则任何子集都是有效的，给出$2^n - 1$有效的非空选择，当$n \ge 2$。 

真正的困难是在没有明确计数的情况下描述有效封面数量何时至少为 3 个。 

## 方法

 一个蛮力的想法是尝试集合的每个子集并检查它是否涵盖所有数字。 这是正确的，但立即不可行，因为有$2^n$子集，甚至检查每个子集的覆盖范围也会花费$O(m)$，导致指数时间。 

关键的观察是，我们实际上并不需要了解所有有效的封面，只需要了解是否至少有三个。 这表明答案取决于该结构在选择集合时是否具有至少三个“自由度”，同时仍然覆盖所有元素。 

如果我们考虑必要性，问题就会大大简化。 有些集合是强制的：如果一个集合包含其他集合不包含的值，则该集合必须包含在每个有效的解决方案中。 这些强制组降低了灵活性。 

现在想象一下，我们识别出单个集合唯一涵盖的所有元素。 每一个这样的元素都强制包含该集合。 包括所有强制集后，其余集仅贡献冗余覆盖。 

如果在考虑强制结构后，我们仍然可以自由地选择至少两个独立的可选选择，那么我们可以形成至少三个不同的有效子集。 否则，所有有效的解决方案最多会分解为两种配置。 

标准解决方案中使用的一个关键简化是，有效方法的数量至少为三种，除非集合系统受到极大限制：要么没有有效覆盖，要么解决方案是唯一的，要么恰好有两种可能性。 仅当覆盖结构本质上是线性的时才会发生这种情况，这意味着每个元素都受到最小重叠的严格约束。 

我们没有显式地模拟所有依赖关系，而是将问题简化为检查覆盖范围中是否存在足够的冗余，以便在贡献相同元素的集合之间至少存在两个独立的“交换选择”。 

这导致了一个简单但强大的减少：我们跟踪需要多少个集合，以及有多少个元素是唯一支持的。 如果结构强制几乎所有集合，答案是“否”； 否则，灵活性保证至少三个有效选择。

 | 最佳 |$O(L)$|$O(m)$| 已接受 |

 ## 算法演练

 1. 首先，计算每个值$x \in [1, m]$有多少组包含它。 

这告诉我们该实例是否可行。 如果某个值出现零次，则任何选择都无法覆盖它，因此答案立即为“否”。 原因是无论子集选择如何，覆盖都是不可能的。 
2. 对于每个值$x$，确定它是否是“关键”，这意味着它恰好出现在一组中。 

这些值强制该设置包含在每个有效的解决方案中。 
3. 标记由于至少包含一个临界值而强制的所有集合。 

这些集合不能被排除在任何有效的配置中。 
4. 检查强制集是否已经涵盖了以下所有值$1$到$m$。 

如果不这样做，那么就根本没有有效的选择，因为即使是必要的集合也无法涵盖所有​​内容。 
5. 如果覆盖范围有效，计算剩余的非强迫组数。 

这些代表了构建不同有效解决方案的灵活性。 
6. 如果剩余可选选项的数量至少为两个，从而影响覆盖范围，那么我们可以通过切换这些可选集的包含来生成至少三个不同的有效子集。 否则，该结构最多会折叠为两个有效配置，因此答案为“否”。 

### 为什么它有效

 核心不变量是，任何恰好出现在一组中的元素都会修复该组在所有有效覆盖中的存在。 一旦包括了所有这样的强制集，剩下的问题就变成了覆盖是否至少有两个独立的冗余。 如果只有一种方法可以在不破坏完整性的情况下调整覆盖范围，则最多存在两个有效子集（包括或排除该单个冗余组件）。 一旦有两个独立的可选组件，组合就已经产生了至少三个不同的有效覆盖。 

这将全局子集计数问题减少为元素及其唯一支持的局部依赖结构问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n, m = map(int, input().split())
        
        sets = []
        freq = [0] * (m + 1)
        
        for _ in range(n):
            tmp = list(map(int, input().split()))
            k = tmp[0]
            arr = tmp[1:]
            sets.append(arr)
            for x in arr:
                freq[x] += 1
        
        # If any element is missing, impossible
        for x in range(1, m + 1):
            if freq[x] == 0:
                out.append("NO")
                break
        else:
            # find forced sets
            forced = [False] * n
            
            for i in range(n):
                for x in sets[i]:
                    if freq[x] == 1:
                        forced[i] = True
                        break
            
            # check coverage of forced sets
            covered = [False] * (m + 1)
            for i in range(n):
                if forced[i]:
                    for x in sets[i]:
                        covered[x] = True
            
            ok = True
            for x in range(1, m + 1):
                if not covered[x]:
                    ok = False
                    break
            
            if not ok:
                out.append("NO")
            else:
                # count optional sets
                optional = sum(1 for i in range(n) if not forced[i])
                if optional >= 2:
                    out.append("YES")
                else:
                    out.append("NO")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码首先构建每个元素的频率计数。 此步骤至关重要，因为它标识了唯一覆盖的元素，这些元素直接确定强制集。 

下一个循环将包含唯一出现的元素的任何集合标记为强制的。 一旦确定了这些，我们就仅使用这些强制集来模拟覆盖范围，以确保它们足以覆盖整个宇宙。 

最后，我们计算有多少组仍然是可选的。 如果至少有两个可选集，我们可以在单个刚性结构之外构建多个不同的有效选择，保证至少三个有效配置。 

一个微妙的实现细节是在检测到缺失元素时提前终止。 这避免了不必要的处理，并在不存在解决方案时确保正确性。

 ## 边缘情况

 一个关键的边缘情况是每个元素都只出现一次。 在这种情况下，每组都变得被迫，没有变化的余地。 例如，使用集合`{1}, {2}, {3}`超过`m=3`，算法将所有集合标记为强制，并立即发现没有可选选择，产生“NO”。 

另一个边缘情况是所有集合都相同并且已经涵盖了所有内容。 例如，五份`{1,2,3}`。 没有唯一支持的元素，因此没有任何内容是强制的，并且所有集合都是可选的。 由于至少有两个可选集，因此答案变为“是”，这与存在许多不同子集的事实相匹配。 

当覆盖完成但在强制后只有一组仍然可选时，会出现最后一个微妙的情况。 那么只存在两种配置：包含或排除该单个灵活集，同时保留覆盖范围约束。 由于要求至少有三个不同的选择，因此在该配置中答案仍然必须是“否”。
