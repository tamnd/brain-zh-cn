 ## 解决方案
 ## 问题理解

 该问题描述了一个火山坑，表示为$n \times m$网格，其中每个单元存储该点与零时刻的岩浆水平相比高出多少。 值为零的单元已经处于岩浆水平，这意味着它们立即被淹没。 

随着时间的推移，岩浆开始以每毫秒 1 毫米的速度均匀上升。 随着时间的推移，有效岩浆液位会增加，因此任何高度小于或等于当前岩浆液位的单元都会被淹没。 

龙蛋被放置在特定的细胞上$(x, y)$，我们想要确定岩浆首次到达该单元的确切时刻。 然而，岩浆不一定需要通过其自身的高度直接到达该单元。 如果周围的岩石形成障碍，岩浆必须沿着从外部熔岩区域到蛋位置的任何路径通过最低的障碍“溢出”。 由于外边界已经是熔岩，岩浆总是可以从那里开始，通过越来越低的约束向内传播。 

关键的解释是，接触蛋的时间是由从边界（初始熔岩区域）到蛋细胞的任何路径上的最小可能“最大高度障碍”决定的。 换句话说，每条路径都有一个限制高度，由该路径上的最大像元值定义，并且我们希望路径能够最小化该最大值。 

约束允许最多$10^3 \times 10^3$网格大小，即一百万个单元。 这立即表明任何解决方案$O(n^2 \log n)$或者$O(n^2)$是可以接受的，但是类似的事情$O(n^2 \cdot n)$或者每个查询重复 BFS/DFS 会太慢。 

一种简单的方法可能会尝试模拟逐毫秒上升的岩浆或每个时间阈值的洪水填充。 这是不可能的，因为答案可能是$10^9$，并且每个模拟步骤都需要扫描网格，从而导致无界$O(10^9 \cdot nm)$过程。 

第二个天真的想法是，对于卵细胞，尝试从边界开始的所有路径并计算沿每条路径的最大高度。 然而，枚举所有路径是指数级的，即使对于小网格也是不可行的。 

一个更微妙的错误方法是假设我们只需要卵细胞本身的高度。 这会失败，因为蛋可能被一圈较高的岩石包围，而岩浆必须首先上升到该环上方，然后才能到达它。 

具体的失败案例是：```
0 2 0
2 1 2
0 2 0
```如果蛋位于中心，则其值为 1，但岩浆无法到达它，直到它上升到 2，因为周围的障碍物阻止了访问。 一个幼稚的“just take a[x][y]”答案会输出 1，这是不正确的； 正确答案是2。 

## 方法

 蛮力观点将网格视为加权景观，其中相邻单元之间的每次移动都受到迄今为止遇到的最高海拔的限制。 从任何边界单元，我们尝试到达卵细胞，同时跟踪沿路径的最大高度。 在所有可能的路径中，我们想要最小化这个最大值的路径。 

这是一个经典的极小极大路径问题。 强力解决方案将枚举从边界到目标的所有路径，计算每条路径的最大像元值，并在这些最大值上取最小值。 网格中的路径数量大致呈指数增长$O(4^{nm})$在最坏的情况下，这完全不可行。 

关键的见解是，这相当于图中的最短路径问题，其中每个节点都是一个网格单元，但路径成本不是相加的。 相反，路径的成本是沿其的最大边权重（像元高度）。 这将问题转化为寻找一条最小化所遇到的最大权重的路径，这可以使用 Dijkstra 算法的变体自然地解决，其中松弛使用`max(current_cost, next_cell_value)`而不是加法。 

我们同时从所有边界单元开始，因为岩浆源自外部。 每个边界单元的初始成本等于其高度。 然后我们向内传播，总是首先扩展具有最小电流的已知“洪水水平”的单元。 这确保了当我们第一次到达细胞时，我们已经找到了将其暴露于上升岩浆的最佳方法。 

这实际上是网格图上的最小最大最短路径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了|
 | 极小极大迪杰斯特拉 |$O(nm \log nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 我们将每个网格单元视为图中的一个节点。 在相邻小区之间移动并不存在传统意义上的成本； 相反，每个节点贡献其高度作为约束。 

1. 初始化所有边界单元的优先级队列，因为这些边界单元在时间零时已经与岩浆相邻。 每个边界单元的插入成本等于其高度。 这代表岩浆影响该细胞的最早时间。 
2. 维护距离数组`dist[i][j]`，其中每个值存储从边界到达该像元所需的最小可能最大高程。 最初，除了边界单元之外，所有值都是无穷大。 
3. 反复从优先级队列中提取当前成本最小的信元。 这确保我们始终首先扩展最有前途的“最低障碍”区域。 
4. 对于每个提取的单元，尝试松弛其四个邻居。 对于邻居，计算候选成本为`max(current_cost, grid[nx][ny])`。 这代表岩浆必须穿过的最高岩石才能通过这条路径到达邻居。 
5. 如果该候选成本小于邻居先前已知的成本，则更新它并将其推入优先级队列。 
6. 继续，直到处理完所有可到达的细胞或直到卵细胞完成。 
7. 答案是`dist[x][y]`。 

正确性来自于这样一个不变量：每当一个单元从优先级队列中弹出时，我们就已经找到了从边界到达它所需的最小可能的最大障碍。 任何替代路径都会使用相同或更高的中间最大值，因此无法改善结果。 

这是可行的，因为优先级队列总是按照瓶颈值增加的顺序扩展状态，确保在节点最终确定后不存在更好的路径。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    x, y = map(int, input().split())
    x -= 1
    y -= 1

    grid = [list(map(int, input().split())) for _ in range(n)]

    INF = 10**18
    dist = [[INF] * m for _ in range(n)]
    pq = []

    # all boundary cells start from outside lava
    for i in range(n):
        for j in range(m):
            if i == 0 or j == 0 or i == n - 1 or j == m - 1:
                dist[i][j] = grid[i][j]
                heapq.heappush(pq, (dist[i][j], i, j))

    dirs = [(1,0), (-1,0), (0,1), (0,-1)]

    while pq:
        cost, i, j = heapq.heappop(pq)

        if cost != dist[i][j]:
            continue

        if i == x and j == y:
            print(cost)
            return

        for di, dj in dirs:
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < m:
                nc = max(cost, grid[ni][nj])
                if nc < dist[ni][nj]:
                    dist[ni][nj] = nc
                    heapq.heappush(pq, (nc, ni, nj))

def main():
    solve()

if __name__ == "__main__":
    main()
```该解决方案使用来自所有边界单元的多源 Dijkstra 初始化，因为岩浆起源于外层的任何地方。 每个松弛步骤都会更新到达邻居的最已知瓶颈值。 

一个微妙的实现细节是我们从不将移动成本视为累加。 使用`max(cost, grid[nx][ny])`是必不可少的； 用加法替换它会完全破坏模型，因为高度代表阈值，而不是累积距离。 

另一个重要的点是当目标单元格被弹出时提前退出。 由于Dijkstra保证了成本的非递减顺序，所以当我们第一次弹出卵细胞时，我们已经找到了它的最优值。

 ## 边缘情况

 一种重要的边缘情况是，由于与高度为零的边界熔岩相邻，蛋在零时间已经被有效地淹没。 在这种情况下，算法立即从边界传播开始，并且卵细胞的计算成本可能已经为零。 优先级队列会提前弹出它，无需额外处理即可生成正确答案。 

另一种边缘情况是完全封闭的盆地，其中鸡蛋被逐渐升高的墙壁包围。 在这种情况下，算法确保成本随着穿过每一层而逐渐增加。 即使存在具有不同势垒轮廓的多条路径，最小最大传播也保证选择尽可能低的最大值。 

最后一个微妙的情况是，多个边界路径通向具有不同中间最大值的同一单元。 堆可能会为同一个节点推送多个条目，但是`if cost != dist[i][j]`Guard 确保过时状态被忽略，防止错误更新并在重复松弛下保持正确性。
