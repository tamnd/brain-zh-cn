 ## 解决方案
 ## 问题理解

 将每个单位正方形视为底部位于高度的垂直柱`h[i][j]`其水平面积恰好是`1`。 选择一个常见的水平水面，只有当柱子的底部位于该水面以下时，柱子才提供水。 

重要的是水量。 如果水面有高度`x`，然后是底部高度的单元格`h`包含`max(x - h, 0)`水的单位。 由于每个单元格都有面积`1 dm²`，这个高度也是它的体积（以升为单位）。 

示例表明所需答案是这个水位`x`，从公共参考底部向上测量。 对于第一个样品，将表面置于高处`3`给出底部位于高处的六个单元格中每个单元格的一单位水`2`，总体积为`6`。 对于第二个样本，表面高度`6`给出深度`5, 4, 3, 2, 1`高于五个具有高度的单元格`1, 2, 3, 4, 5`，其总和为`15`。 

矩阵最多包含`1000 × 1000 = 10^6`细胞。 读取整个矩阵已经需要单元数量的线性时间，因此适当的解决方案应该接近`O(nm)`。 由于每个高度最多为`100`，我们的可能水位范围也极小。 一种方法，花费另一个因素`nm`对于每个可能的水平将执行大约`10^8`单元操作，在一秒的限制下，这是不必要的昂贵的。 

体积可以大到`10^9`，因此实现必须使用至少能够保存该值的整数类型。 Python 整数具有任意精度，因此溢出不是问题。 

有几种边界情况可以欺骗直接实现。 考虑```
1 1 1
1
```唯一的列有底部高度`1`，所以水面必须达到高度`2`包含一升。 正确答案是`2`。 一个粗心的实现使用`x - h`不考虑表面是否高于底部可能会对较低的候选级别产生负面贡献。 

另一个有用的案例是```
1 3 3
1 1 1
```在高处`2`，每列包含一升，所以答案是`2`。 三个相等的柱必须全部贡献，而不仅仅是一个代表高度。 

最后，考虑```
2 2 4
1 3
1 3
```在高处`2`，有底的两列`1`每个包含一升，而底部的柱子`3`不含水。 总数正好是`2`，所以高度`2`还不够。 在高处`3`，下面的两列各包含两升，另外两列包含零，给出`4`。 正确答案是`3`。 这发现了一个常见的错误：一旦表面达到最大值，就将每个细胞视为被淹没，或者对底部正好位于表面的柱进行计数。 

## 方法

 最直接的解决办法就是尝试所有可能的水位。 对于候选人身高`x`，扫描每个单元格并添加`max(x - h[i][j], 0)`到音量。 如果所得体积等于`v`，我们找到了答案。 

这种蛮力是正确的，因为固定水位下的物理体积恰好是所有柱内水高度的总和。 该问题保证存在整数答案，并且高度最多为`100`，因此只有少量的候选级别需要测试。 

问题是重复扫描。 有 100 万个单元格和多达大约 100 个候选级别，最坏的情况大约是`10^8`细胞评估。 每次评估都会进行减法、比较和加法，这对于一秒钟的竞赛限制来说太多了。 

有用的观察是高度范围很小。 我们实际上不需要在阅读后单独记住每个单元格。 我们可以计算每个底部高度有多少个单元格。 

让`cnt[h]`是底部位于高度的单元格的数量`h`。 在水位`x`，所有单元格`h < x`贡献`x - h`，而细胞与`h >= x`贡献为零。 因此体积是```
volume(x) = Σ cnt[h] * (x - h), for h < x
```只有`100`的可能值`h`，因此在构建频率阵列后，我们可以在每个级别的恒定时间内评估每个可能的水位。 整个解决方案需要`O(nm + H)`， 在哪里`H = 100`。 

理解相同想法的更通用方法是观察体积函数是单调的。 提高水面永远不会减少体积。 然而，在这个问题中，高度界限非常小，以至于扫描可能的级别比实现二分搜索或排序更简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(nmH)`|`O(1)`| 在最坏的情况下太慢|
 | 最佳 |`O(nm + H)`|`O(H)`| 已接受 |

 ## 算法演练

 1. 创建数组`cnt`在哪里`cnt[h]`存储有多少个单元格具有底部高度`h`。 最大高度为`100`，所以一个大小的数组`101`就足够了。 
2. 读取每个矩阵值`h`并增加`cnt[h]`。 我们只需要每个高度的频率，因为具有相同底部高度的单元格对于每个可能的水位表现相同。 
3. 尝试水位`1`通过`101`。 对于候选人级别`x`，计算每个高度贡献的体积`h < x`作为`cnt[h] * (x - h)`。 高地`h >= x`贡献为零，因为它们的底部位于或高于水面。 
4. 一旦计算出的体积等于`v`， 输出`x`。 该问题保证存在有效的整数水位，因此搜索将找到一个。 
5. 在第一个匹配级别后停止。 体积函数不减为`x`增大，且所需体积对应的物理水位在问题保证下是唯一的。 

### 为什么它有效

 对于任何固定水位`x`，底部位于高度的单元格`h`恰好包含`x - h`水的单位，当`h < x`，否则不加水。 按底部高度对单元格进行分组不会改变此计算，因为同一组中的每个单元格具有完全相同的贡献。 因此，计算出的总和正是该水位的总水量`x`。 

该算法检查可以包含所需体积的每个可能的整数级别。 由于该语句保证整数答案并且不会溢出，因此计算出的体积恰好是该级别`v`必须找到并归还。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, v = map(int, input().split())

    # h is at most 100.
    cnt = [0] * 101

    for _ in range(n):
        for h in map(int, input().split()):
            cnt[h] += 1

    # Try every possible integer water level.
    # Level 101 is enough because the maximum bottom height is 100.
    for x in range(1, 102):
        volume = 0

        for h in range(1, x):
            volume += cnt[h] * (x - h)

        if volume == v:
            print(x)
            return

if __name__ == "__main__":
    solve()
```实现的第一部分在读取矩阵时构建频率数组。 这可以避免存储多达一百万个个人身高，从而使内存占用量非常小。 

第二部分列举了候选水位。 对于一个级别`x`，循环故意停止在`x - 1`，因为一个单元格`h == x`其底部正好位于水面上，因此含水量为零。 包括它会添加`cnt[x] * 0`，所以任一边界在数学上都是安全的，但是使用`range(1, x)`直接表达条件。 

上限是`101`。 由于每个底部高度最多为`100`，上面的一个表面`100`是所有柱子都被淹没后唯一剩下的可能性。 该问题保证了答案存在并且浴缸不会溢出，所以这个范围就足够了。 

Python 的任意精度整数也使体积计算即使在中间乘积很大时也是安全的。 在具有固定宽度整数的语言中，64 位整数将是合适的类型。

 ## 边缘情况

 第一个边缘情况是单个单元格。 为了```
1 1 1
1
```候选人级别`1`产生量`0`，因为底部正好位于表面。 处于水平`2`，细胞贡献`2 - 1 = 1`，匹配所需的体积。 算法返回`2`，因此平等边界处理正确。 

第二个边缘情况是完全平坦的浴缸：```
1 3 3
1 1 1
```处于水平`1`，体积为零。 处于水平`2`，所有三个单元贡献一个单位，给出`3`。 频率数组包含`cnt[1] = 3`，因此该算法将其计算为`3 × (2 - 1)`无需单独处理细胞。 

第三个边缘情况包含尚未淹没的单元格：```
2 2 4
1 3
1 3
```处于水平`2`，只有两个高度-`1`细胞贡献、产生`2`。 两人身高——`3`细胞的贡献为零，因为它们的底部高于水面。 处于水平`3`，下面的两个单元各包含两个单元，产生所需的体积`4`。 这就是为什么条件必须是`h < x`，而不是为每个单元格添加有符号的值。 

提供的示例在复制的声明中暴露了一个单独的问题。 第二个样本与标准柱高模型一致并给出了水位`6`。 第一个样品的基质和体积给出了水位`2`在同一模型下，而提供的输出表示`3`。 由于没有对给定的单一解释`h`值使两个示例保持一致，因此在提交之前应验证原始法官的确切坐标约定。 一旦约定被固定，频率计数技术仍然是中心解决方案，因为任何候选级别的体积仍然完全由列高的分布决定。
