 ## 解决方案
 ## 问题理解

 我们得到一个表示为邻接矩阵的有向图，其中每个顶点都有到其他顶点的边，但没有顶点到其自身有循环。 除了图表之外，我们还给出了一条路径`p`作为顶点索引的序列。 该路径可能会重新访问顶点，因此不能保证它是简单的。 序列中每对连续的顶点对应于图中的一条现有边。 

目标是找到给定路径的最短子序列，该子序列保留起始顶点和结束顶点，并且使得该子序列的连续顶点之间的路径始终是图中的最短可能路径。 换句话说，我们需要沿路径的关键检查点的最小列表，该列表仍然允许我们通过在这些检查点之间采用最短路径来重建原始路径。 

该图最多可以有 100 个顶点，因此运行全对最短路径等算法是可行的，因为它们的复杂度约为`n^3 = 10^6`，这是可以接受的。 路径`p`可以非常长，最多 10^6 个元素，这排除了任何检查每对位置的解决方案`p`很天真的，因为这大约需要 10^12 次运算。 

当同一对顶点之间存在多个最短路径时，会出现微妙的边缘情况。 例如，考虑一个带有顶点的三角形图`1-2-3-1`。 如果给定的路径是`1 2 3 1`，子序列`1 3`无效，因为来自的最短路径`1`到`3`直接就是`1-3`，与原来的路径不一样。 一种粗心的方法，只是选择`1`在这种情况下，最后一个顶点可能会失败。 

另一种边缘情况是路径重复访问同一顶点。 例如，在所有节点都连接且路径为的图中`1 2 3 2 4`，如果跳过中间节点会改变最短路径，我们必须确保不会删除它们。 

## 方法

 暴力解决方案将考虑给定路径的每个可能的子序列并检查它是否良好。 对于每个子序列，我们将验证子序列中连续顶点之间的最短路径是否与原始路径的段匹配。 这种做法原则上是正确的，但不可行。 对于长度的路径`m`, 最多有`2^m`子序列，并且每个子序列都需要最短路径检查，从而导致组合爆炸。 

解锁有效解决方案的关键观察是我们不需要考虑所有子序列。 如果我们使用 Floyd-Warshall 预先计算所有对的最短路径距离，我们就可以线性扫描路径。 对于每个顶点`p[i]`，我们检查距子序列中最后一个选定顶点的距离`p[i+1]`。 如果这个距离等于我们要跳过的边数，那么跳过中间顶点是安全的； 否则，我们必须包括`p[i]`在我们的后续中。 这是有效的，因为子序列必须仅保留检查点，以便最短路径重建与原始路径匹配。 

这将问题简化为路径的线性扫描以及从所有对最短路径矩阵中进行恒定时间距离查找。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m * n^2) | O(2^m * n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | O(n^3 + m) | O(n^3 + m) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 将邻接矩阵转换为距离矩阵，其中`dist[i][j]`如果有一条边来自`i`到`j`否则为无穷大。 放`dist[i][i] = 0`为所有人`i`。 
2. 运行Floyd-Warshall 算法来计算所有对的最短路径距离。 对于每个顶点`k`，更新每一对`(i,j)`作为`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`。 此后，`dist[i][j]`包含从最短路径的长度`i`到`j`。 
3. 用路径的第一个顶点初始化子序列。 让`last`是该顶点在路径中的索引。 
4. 从第二个顶点开始迭代路径。 对于每个`i`，检查最短距离是否为`p[last]`到`p[i]`等于`i - last`。 如果是，则继续； 如果没有，请包括`p[i-1]`在子序列中并设置`last = i-1`。 
5. 循环结束后，追加最后一个顶点`p[m-1]`到后续。 

为什么它有效：不变的是子序列总是以一个顶点结束，这样从它到路径段中下一个顶点的最短路径等于我们要跳过的边数。 这保证了子序列的重构路径与原始路径逐段匹配，同时跳过尽可能多的中间顶点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = int(1e9)

n = int(input())
dist = [[INF] * n for _ in range(n)]

for i in range(n):
    line = input().strip()
    for j, c in enumerate(line):
        if c == '1':
            dist[i][j] = 1
    dist[i][i] = 0

# Floyd-Warshall for all-pairs shortest paths
for k in range(n):
    for i in range(n):
        for j in range(n):
            if dist[i][j] > dist[i][k] + dist[k][j]:
                dist[i][j] = dist[i][k] + dist[k][j]

m = int(input())
p = list(map(lambda x: int(x)-1, input().split()))

result = [p[0]]
last = 0

for i in range(1, m):
    if dist[p[last]][p[i]] < i - last:
        result.append(p[i-1])
        last = i-1

result.append(p[m-1])
print(len(result))
print(' '.join(str(x+1) for x in result))
```该代码首先读取邻接矩阵并将其转换为适合 Floyd-Warshall 的距离矩阵。 这`INF`value 确保未连接的顶点得到正确处理。 路径`p`转换为从零开始的索引。 在主循环中，我们跟踪子序列中最后包含的顶点，并仅在跳过会破坏最短路径属性时追加顶点。 最后，子序列以基于 1 的索引打印，以匹配输入格式。
