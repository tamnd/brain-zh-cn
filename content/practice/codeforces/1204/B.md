 ## 解决方案
 ## 问题理解

 我们给定一个长度`n`正整数数组，但数组不是任意的。 其中的每个值都必须满足严格的结构规则：每个数字要么是`1`，或者它是一个偶数，其一半也存在于数组中的某处。 这意味着每个值都可以通过重复除以二来追踪，直到我们达到`1`，并且该链上的所有中间值也必须存在于数组中。 

除了结构性限制之外，我们还被告知了一些关于多样性的信息。 该数组必须包含`l`和`r`独特的价值观，包容性。 我们没有被要求构造这样一个数组，只是为了确定所有有效数组中其元素的最小和最大可能总和。 

约束足够小`n`最多 1000 个，不同值的数量最多 20 个。这立即表明我们不是在探索任意值空间；而是在探索任意值空间。 有效数字的结构受到极大限制。 每个有效数字都属于从以下位置开始的双链`1`，因此值看起来像 2 的幂，但允许重复。 

一个微妙的点是，“除以二的闭包”强制任何有效的不同值集成为从`1`。 如果我们包括`8`， 然后`4`,`2`， 和`1`也必须在场。 这消除了任何不规则的组合，例如`{1, 2, 8}`没有`4`。 

边缘情况出现时`l`和`r`严格限制不同值的数量。 例如，如果`l = r = 1`，唯一可能的数组是全一，因为任何更大的值都会引入额外的所需元素。 另一个角落是当`n`很大但是`r`很小，迫使小数字大量重复。 

尝试枚举所有有效值子集并分配重数的简单方法很快就会变成组合方法，因为大小高达 20 的子集数量仍然很大，并且分配计数会增加另一个指数层。 二次幂的结构使得贪婪构造成为可能。 

## 方法

 暴力方法会尝试选择一组满足闭包规则的有效不同值，然后分配`n`它们之间的位置，并计算所得的总和。 对于每个候选集，我们将确保如果有一个数字`x`包含在内，所有值`x/2, x/4, ..., 1`也包括在内。 即使我们将自己限制在有效的链上，我们仍然需要考虑每个值出现的次数。 

可能的有效链的数量很小，因为任何有效的不同集完全由其最大元素决定，但重数分布仍然灵活。 分布的强力枚举会导致指数复杂度`n`，大致按照分区的顺序`n`跨越最多 20 个值，这是不可行的。 

关键的观察是我们只关心序列的前缀`1, 2, 4, 8, ...`。 如果我们固定不同值的数量`k`，那么最优值集被强制：它必须是`{1, 2, 4, ..., 2^(k-1)}`。 除了该前缀的长度之外，没有选择结构的自由。 

一旦我们确定了一组值，总和就取决于我们分配每个值的次数。 由于较大的值在总和上更“昂贵”，因此通过将尽可能多的元素分配给最大允许值来获得最大总和，同时尊重我们仍然必须保持链有效。 最小总和则相反：我们更喜欢尽可能小的值，但我们仍然必须确保存在足够的不同值。 

这将问题简化为尝试所有可能的方法`k`在`[l, r]`，并且对于每个`k`，计算强制链下最佳可能的最小和最大总和`{1, 2, ..., 2^(k-1)}`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | n 及其子集的指数 | 指数| 太慢了 |
 | 最佳 | O(r) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们预先计算 2 的幂序列，因为每个有效值都来自该序列。 

1. 对于每个可能的不同值数量`k`从`l`到`r`，我们构建规范的值集`v_i = 2^(i-1)`为了`i`从`1`到`k`。 这是由可分性约束强制的，因为任何有效的结构都必须是前缀链。 
2.对于固定的`k`，我们确定如何分配`n`其中出现的`k`值，同时保持有效性。 该约束不会限制超出允许重复的计数，因此只要所有分布都满足，任何分布都是有效的`k`如果需要，值至少出现一次。 
3. 为了最小化总和，我们首先将尽可能多的元素分配给最小值。 这是一个贪婪的填充过程：我们放置每个所需值的一次出现以满足唯一性，然后将剩余的槽分配给最小值`1`。 
4. 为了使总和最大化，我们做相反的事情。 我们分配每个所需值的出现一次，然后将剩余的槽分配给最大值`2^(k-1)`。 
5. 我们计算每个结果的总和`k`，跟踪所有有效的全局最小值和最大值`k`。 

关键细节是，固定前缀长度后，问题变得线性，因为成本结构是单调的：较大的幂总是支配较小的幂，因此贪婪分配在两个方向上都是最优的。 

### 为什么它有效

 闭包属性强制所有有效的不同值集形成加倍序列的前缀。 一旦这个前缀长度固定，就没有额外的结构选择，只有多重性分配。 由于对总和的所有贡献都是线性的并且按大小排序，因此最优性来自于将计数贪婪地分配到最小值或最大值，具体取决于我们是最小化还是最大化。 任何重新排列都无法改善结果，因为在更小值和更大值之间交换任何质量单位都会严格改变固定方向的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, l, r = map(int, input().split())

    # precompute powers of two up to 20 (safe upper bound)
    pw = [1]
    for _ in range(1, 25):
        pw.append(pw[-1] * 2)

    min_ans = float('inf')
    max_ans = 0

    for k in range(l, r + 1):
        # construct values 1,2,4,...,2^(k-1)
        vals = pw[:k]

        # MINIMUM: put one of each, rest go to 1
        min_sum = sum(vals)
        min_sum += (n - k) * vals[0]

        # MAXIMUM: put one of each, rest go to largest
        max_sum = sum(vals)
        max_sum += (n - k) * vals[-1]

        min_ans = min(min_ans, min_sum)
        max_ans = max(max_ans, max_sum)

    print(min_ans, max_ans)

if __name__ == "__main__":
    solve()
```该代码首先构建 2 的幂，以便我们可以直接索引所需的值。 对于每个可能的不同计数`k`，它假设唯一有效的结构是第一个`k`两个人的权力。 然后，它计算每个值出现一次的基线总和。 从那里开始，它分配剩余的`n - k`元素的最小值或最大值取决于我们是最小化还是最大化。 

一个常见的错误是忘记每个不同值必须至少出现一次，这就是为什么在分配额外值之前基线总和恰好包含每个值之一。

 ## 边缘情况

 当`l = r = 1`，结构崩溃到只有值`1`，因为任何较大的值都会强制添加额外的不同元素。 该算法处理这个问题是因为`k = 1`产生一个单值列表`[1]`，最小值和最大值都变为`n`。 

什么时候`k`很大，比如`k = 20`，值呈指数增长，因此即使一次包含大幂也会在总和中占主导地位。 贪心分配确保额外的元素总是分配给`1`或者`2^(k-1)`，无需任何组合推理即可正确捕获极值行为。 

如果`n`等于`k`，没有额外的元素要分配，答案只是第一个元素的总和`k`两个人的权力。 该实现处理这个问题是因为`(n - k)`变为零，只留下基本总和。
