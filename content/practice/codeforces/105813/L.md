 ## 解决方案
 ## 问题理解

 我们有两个相同大小的隐藏排列，称它们为$a$和$b$。 我们没有直接看到它们，而是得到了两个派生数组，它们对两个排列如何在相反方向上相互组合进行编码。 

对于每个职位$i$，第一个数组给出的值$a$在位置$b_i$，第二个数组给出的值$b$在位置$a_i$。 换句话说，每个数组都是通过其他排列的“交叉查找”。 任务是重建任意一对排列$a$和$b$与这些约束一致，或者确定不存在这样的对。 

阅读此内容的一个有用方法是每个索引同时参与两个未知的双射。 一个双射告诉它映射到哪里$b$，另一个告诉它映射到哪里$a$。 输入不直接给出任何映射，仅在每个索引处评估它们的成分。 

约束足够大，任何解决方案都必须接近每个测试用例的线性或线性对数，因为所有测试用例的总输入大小达到$2 \cdot 10^5$。 任何尝试猜测排列或强力分配的尝试都会立即失败，因为即使$O(n^2)$行为已经超出限制几个数量级。 

一个微妙的困难是输入不会直接将结构暴露为单个图的边。 相反，它给出了两个相互依赖的未知排列图像，并且两者必须同时保持一致。 

一个小的健全性检查已经揭示了失败案例。 如果两个数组相同，并不自动意味着$a = b$。 例如，当两个数组都是$[1]$，答案是微不足道的，但当它们更长时，一致性仍然可能会被破坏，具体取决于周期如何相互作用。 另一种误导性的情况是，两个数组都是具有相同循环结构的排列，但移位方式导致不可能进行一致的因式分解。 将每个数组独立地视为排列重构问题的天真的尝试将忽略这些交叉约束并产生不正确的结果。 

## 方法

 直接的暴力策略会尝试将值分配给$a$和$b$迭代地。 对于每个索引，我们可以猜测$b_i$，然后推导$a_{b_i}$，并向前传播约束。 这很快就会变成一个回溯问题，分支因子高达$n$，并且每个选择都会影响全局的两个排列。 在最坏的情况下，这会退化为探索阶乘多项分配，因为每个值放置都会限制多个未来的放置。 即使进行剪枝，传播也太弱，因为每个方程连接两个未知函数，而不仅仅是局部位置。 

关键的观察是停止思考$a$和$b$作为数组，而是将它们视为公共集合上的双射。 限制因素$$p[i] = a[b[i]], \quad q[i] = b[a[i]]$$暗示$p$和$q$不是独立的对象。 它们通过未知的排列共轭。 具体来说，申请$a$后$b$产量$p$，在申请时$b$后$a$产量$q$。 这种对称性迫使一个强大的结构条件：$p$和$q$必须具有相同的循环结构。 

原因是共轭保留了循环分解。 如果两个排列通过元素的重新标记相关联（这正是未知的$a$和$b$做），那么它们的周期长度必须匹配。 这将问题从“构造两个排列”减少为“匹配循环分解并一致地重新标记循环内的元素”。 

一旦我们分解两者$p$和$q$成循环，每个循环$p$必须对应于一个循环$q$相同长度的。 在每对匹配的循环中，我们可以自由选择元素如何对应，并且这种对应关系决定了两者$a$和$b$本地。 然后通过将这些循环级映射拼接在一起获得全局解决方案。 

这将问题变成了受控的重新标记任务，而不是函数方程系统。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分配$a, b$| 指数| O(n) | 太慢了|
 | 循环分解+匹配| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.构造给定的两个数组$p$和$q$从输入。 这些代表了组合效果$a \circ b$和$b \circ a$。 
2. 分解$p$进入不相交的循环。 每个索引恰好属于一个周期，因为$p$是一个排列。 记录循环以及其中每个元素的位置。 
3. 分解$q$以同样的方式进入不相交的循环。 
4. 组循环$p$和$q$通过它们的长度。 仅当对于每个长度，循环数在$p$等于循环数$q$。 如果失败，则不存在一致的重新标记。 
5. 对于每对匹配的长度相等的循环，选择它们的元素之间的对应关系。 一种一致的方法是将它们按循环顺序对齐，映射$k$循环中的第一个元素$p$到$k$- 中配对循环的第一个元素$q$。 
6. 使用此对应关系来定义$a$和$b$。 一旦我们决定了每个元素在一种排列下的位置，方程$p[i] = a[b[i]]$和$q[i] = b[a[i]]$在每个循环内唯一确定另一个映射。 
7. 填充完所有循环后，输出构建的排列。 

步骤 5 和 6 的基本思想是，在一个周期内，一切都表现得像一个旋转系统。 一旦我们决定了两个周期之间的起始对齐，映射的其余部分将由组合的一致性强制执行。 

### 为什么它有效

 每个排列都可以被视为循环的不相交并，并且共轭排列仅重命名循环内的元素而不改变循环长度。 自从$p = a \circ b$和$q = b \circ a$，两者都代表在不同坐标系中观察到的相同结构作用。 等长的匹配循环重建了这些坐标系之间隐藏的重新标记。 一旦循环对应关系确定，方程就会确定每个循环内唯一一致的转变，从而防止歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    q = list(map(int, input().split()))

    def get_cycles(arr):
        n = len(arr)
        vis = [False] * n
        cycles = []
        pos_in_cycle = [-1] * n

        for i in range(n):
            if not vis[i]:
                cur = []
                v = i
                while not vis[v]:
                    vis[v] = True
                    pos_in_cycle[v] = len(cur)
                    cur.append(v)
                    v = arr[v] - 1
                cycles.append(cur)
        return cycles

    cp = get_cycles(p)
    cq = get_cycles(q)

    from collections import defaultdict, deque
    mp = defaultdict(deque)
    mq = defaultdict(deque)

    for c in cp:
        mp[len(c)].append(c)
    for c in cq:
        mq[len(c)].append(c)

    a = [-1] * n
    b = [-1] * n

    for length in mp:
        if len(mp[length]) != len(mq[length]):
            print("NO")
            return

        while mp[length]:
            c1 = mp[length].popleft()
            c2 = mq[length].popleft()

            k = len(c1)
            for i in range(k):
                u = c1[i]
                v = c2[i]
                a[v] = c1[(i + 1) % k] + 1
                b[u] = c2[i] + 1

    if any(x == -1 for x in a) or any(x == -1 for x in b):
        print("NO")
        return

    print("YES")
    print(*a)
    print(*b)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该代码首先为两个派生排列构建循环分解。 关键的实现细节是显式维护循环列表，因为仅索引到位置映射不足以控制两个独立循环系统之间的对齐。 

每个循环中的分配步骤是最容易发生错误的地方。 映射必须是循环的，因此下一个元素始终以循环长度为模。 这里任何相差一的错误都会立即破坏排列的有效性。 

该结构确保每个元素在两个中都被精确分配一次$a$和$b$，因为每个节点在两个分解中都属于一个循环。 

## 工作示例

 ### 示例 1

 考虑一个小的一致情况，其中两个派生排列形成一个循环：

 输入：```
n = 3
p = [3, 1, 2]
q = [2, 3, 1]
```循环分解：

 | 步骤| p 循环 | q 循环 |
 | --- | --- | --- |
 | 1 | (1 → 3 → 2 → 1) | (1 → 2 → 3 → 1) |

 我们匹配唯一的循环$p$与唯一的循环$q$。 位置对齐给出：

 -$1 \leftrightarrow 1$-$3 \leftrightarrow 2$-$2 \leftrightarrow 3$从这个对齐方式来看，$a$和$b$成为一致的循环移位，产生有效的排列。 

该轨迹证实，一旦周期匹配，重建直到旋转都是确定的。 

### 示例 2

 考虑不可能匹配的情况：```
n = 2
p = [1, 2]
q = [2, 1]
```| 步骤| p 周期 | q 周期 |
 | --- | --- | --- |
 | 1 | (1)(2) | (1 → 2 → 1) |

 这里$p$有两个长度为 1 的循环，而$q$有一个长度为 2 的循环。不可能按循环长度进行配对，因此算法会立即拒绝。 

这说明了为什么循环结构是决定性的不变量。

 ## 边缘情况

 当$n = 1$，两个数组都很简单$[1]$。 循环分解在两个排列中产生一个固定点，并且它们直接匹配，产生$a = b = [1]$。 

当所有周期都是不动点时，$p$和$q$分解成$n$长度为 1 的循环。该算法将它们一对一配对，并且每个元素都是独立分配的，以保持有效性。 

当给定长度的周期计数不同时，算法会提前停止。 这对应于结构不相容性，无法重新标记来修复，因为缀合不能改变循环类型。 

当循环很长但内部未对齐时，位置配对可确保一致性，因为循环中每个元素的后继元素都会以所选对齐方式为模进行保留。
