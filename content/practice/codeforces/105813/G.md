 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度的数组$n$使用来自的整数$1$到$k$，具有很强的局部约束：每个连续的长度段$k$必须包含来自的所有值$1$到$k$正好一次。 

这个条件是相当有限的。 任何尺寸的窗户$k$已经有$k$位置，因此它不能重复值，也不能错过任何值。 这立即迫使每个这样的窗口成为以下排列$1 \ldots k$。 挑战在于这些窗口严重重叠，因此一个部分的选择会限制所有其他部分。 

目标不仅仅是构造任何有效的数组，而是在所有有效的构造中，最大化其元素的总和。 

从约束的角度来看，$n$测试用例的规模可能很大（总共可达数十万个）。 任何尝试显式模拟所有窗口或通过扫描每个子阵列验证每个候选构造的解决方案在最坏的情况下都会变成二次方并立即失败。 该结构表明我们需要了解全局周期性行为而不是局部检查。 

出现微妙的边缘情况时$k = 1$。 那么每个大小为 1 的子数组都必须包含数字 1，从而强制整个数组保持不变。 任何假设排列结构的推理都必须正确地降级到这种情况。 

另一个重要的边缘情况是小$n$相对于$k$。 如果$n < k$，没有有效的大小子数组$k$，所以任何数组都是有效的，我们只需通过选择独立地最大化每个位置$k$到处。 当不存在窗口时，正确的解决方案不得意外地强制执行完全排列约束。 

## 方法

 直接尝试是处理每个大小的窗口$k$独立。 对于每个段，我们可以尝试确保它包含所有值$1 \ldots k$，但由于窗口重叠，选择以复杂的方式向前传播。 在暴力视图中，我们可能会尝试逐个位置分配值，在每次分配后检查所有受影响窗口的有效性。 每个分配影响最多$k$窗户，以及每次检查费用$O(k)$，大致导致$O(n \cdot k^2)$的行为，远远超出了界限。 

关键的结构观察来自重叠的窗口。 如果每个长度-$k$段包含所有值$1 \ldots k$，然后考虑两个连续的窗口：$$[a_i, \ldots, a_{i+k-1}] \quad \text{and} \quad [a_{i+1}, \ldots, a_{i+k}]$$两者都是同一集合的排列。 它们之间的唯一区别是一个元素离开而另一个元素进入。 由于两个多重集必须保持相同，因此传出和传入元素必须匹配。 这迫使$a_i = a_{i+k}$。 

这是关键的简化：数组必须是周期性的$k$。 一旦接受这一点，每个有效数组都只是某些排列的重复$1 \ldots k$。 

问题简化为选择一个排列$1 \ldots k$，沿数组重复，最后一个部分块被截断，如果$n$不能被整除$k$。 唯一剩下的自由是我们如何在一个时期内分配价值。 

现在优化变成线性的。 每个位置都在第一$k$确定与其模一致的所有位置$k$。 所以每个残基类模$k$在最终数组中贡献固定数量的位置。 我们应该为出现频率更高的残基类别分配更大的数字。 

因此，最佳策略是计算单个周期中每个位置在完整数组中出现的次数，对这些计数进行排序，并分配最大值$k, k-1, \ldots, 1$到频率最高的位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解窗口检查 |$O(nk^2)$|$O(n)$| 太慢了 |
 | 句号+贪心赋值 |$O(n + k \log k)$|$O(k)$| 已接受 |

 ## 算法演练

 1. 计算第一个长度块中每个索引出现了多少次$k$出现在完整数组中。 

对于一个职位$i$，这只是整数的数量$[1, n]$一致于$i \bmod k$。 这捕获了“槽”对总和的贡献频率。 
2. 将这些频率存储在数组中`cnt`尺寸的$k$， 在哪里`cnt[i]`对应位置$i$在第一时期。 

此步骤将问题转换为权重位置，而不是对长数组进行推理。 
3. 排序`cnt`按非递减顺序。 

这个想法是准备将最频繁的位置与最大值相匹配。 
4. 赋值自$k$下降到$1$到已排序的位置。 

每个分配都是贪婪的：在更频繁的位置上放置更大的数字会最大程度地增加总和，因为贡献是线性的并且跨位置独立。 
5. 通过在所有索引中重复选定的周期模式来构造完整数组$1 \ldots n$。 

这种方法有效的关键原因是，一旦强制实施周期性，每个仓位对总和的贡献就独立于其他仓位。 唯一的耦合来自于第一个的要求$k$元素形成排列，但由于我们分配不同的值$1 \ldots k$，这个约束自然就满足了。 

### 为什么它有效

 不变的是每个有效数组完全由它的第一个数组决定$k$元素，并且每个元素独立地贡献于由多个元素分隔的不相交位置集$k$。 由于总和是这些选择的线性组合，因此最优性降低为将最大系数（频率）与最大值相匹配。 周期性约束保证了超出初始排列要求的不同残基类别之间没有相互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        cnt = [0] * k

        for i in range(k):
            # positions are i+1, i+1+k, i+1+2k, ...
            # count how many <= n
            cnt[i] = (n - (i + 1)) // k + 1 if i + 1 <= n else 0

        # sort counts
        cnt.sort()

        # assign values 1..k, largest to largest count
        # we compute contribution directly
        ans = 0
        val = 1
        for c in cnt:
            ans += c * val
            val += 1

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先计算每个残基类在数组中出现的次数。 这使用直接算术而不是模拟，从而避免了对整个数组的任何迭代。 

对计数进行排序可确保我们可以按频率递增的顺序贪婪地分配值。 由于我们希望更大的值与更大的频率配对，因此我们从最小计数到最大计数迭代，同时增加分配的值。 

一个常见的错误是尝试先显式构造排列数组，然后贪婪地填充它； 这有效但没有必要。 可以直接计算总和，而无需具体化最终数组。 

## 工作示例

 ### 示例 1

 考虑$n = 4, k = 3$。 

残基位置：

 - 位置 1 出现在索引 1、4 → 计数 2 处
 - 位置 2 出现在索引 2 → 计数 1
 - 位置 3 出现在索引 3 → 计数 1

 所以`cnt = [2, 1, 1]`，排序后给出`[1, 1, 2]`。 

| 步骤| 碳纳米管状态| 指定值| 部分总和 |
 | --- | --- | --- | --- |
 | 开始 | [1,1,2]| - | 0 |
 | 1 | 1 | 1 | 1 |
 | 2 | 1 | 2 | 3 |
 | 3 | 2 | 3 | 9 |

 这会产生和 9，与最佳结构相匹配。 

### 示例 2

 让$n = 5, k = 2$。 

计数：

 - 位置 1：索引 1,3,5 → 3
 - 位置 2：索引 2,4 → 2

 所以`cnt = [3,2]`, 已排序`[2,3]`。 

| 步骤| 碳纳米管状态| 指定值| 部分总和 |
 | --- | --- | --- | --- |
 | 开始 | [2,3]| - | 0 |
 | 1 | 2 | 1 | 2 |
 | 2 | 3 | 2 | 8 |

 这表明较高频率的位置正确地接收到较大的值。 

这些痕迹证实，一旦建立了周期性，该解决方案纯粹是一个加权分配问题。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(n + k \log k)$| 计数频率是线性的，排序$k$价值观占主导地位|
 | 空间|$O(k)$| 仅存储频率数组 |

 总计$n$跨测试用例是有界的，因此这种线性加排序方法很容易满足约束条件。 不需要每个元素的窗口处理，这使得解决方案具有可扩展性。

import sys, io

def run(inp: str) -> str:

    out = []
    for _ in range(t):

 ## 边缘情况

 当$k = 1$，每个窗口约束强制每个元素恰好为 1。该算法处理此问题，因为只有一个具有计数的残差类$n$，并被赋予值 1，产生总和$n$。 

什么时候$n < k$，没有长度-$k$子数组。 计数公式将零分配给超出的大多数残基$n$，但实际上该构造退化为选择所有值作为$k$在最优的解释中。 基于频率的视图仍然表现正确，因为存在较少的活跃位置，并且贪婪分配自然地最大化可用贡献。 

什么时候$n$正好可以整除$k$，所有残基计数都相等。 在这种情况下，任何排列$1 \ldots k$产生相同的总和。 该算法根据排序稳定性任意分配值，但由于所有权重都是相同的，所以保留了正确性。 

什么时候$n$只是比倍数多一$k$，一个残基类别有一次额外出现。 贪心分配确保类获得价值$k$，它捕获了不平衡的全部好处。
