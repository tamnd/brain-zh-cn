 ## 解决方案
 ## 问题理解

 我们有一面长方形的墙，尺寸为$2m \times 2n$，以整数网格的原点为中心。 每个单位方格由整数坐标标识$(x, y)$在这个矩形内。 

单元格的值定义为$\max(|x|, |y|)$。 这将整个网格划分为同心方形“环”。 所有具有相同值的单元格位于同一个环上，围绕中心形成一个闭合循环。 

瓦片是一组相连的单元格，只有当其中的每个单元格完全位于单个环内时才允许使用瓦片。 因此，一块图块不能从一个环跨越到另一个环，但它可以占据其环内的任何连接形状，包括带孔的形状，只要保留连接性即可。 

如果存在至少一对单元，它们在一个平铺中一起在一个平铺中但在另一个平铺中被分成不同的平铺，则两个平铺被认为是不同的。 

我们需要计算存在多少个这样的有效平铺，取模$10^9 + 7$，对于最多$10^4$测试用例，与$m, n \le 10^6$。 

主要的约束含义是我们无法模拟网格或为每个测试用例构建任何显式结构。 一切都必须简化为闭式函数$m$和$n$，可在常数时间内计算。 

当网格最小时会出现关键的边缘情况，例如$m = n = 1$，其中整个$2 \times 2$网格形成一个环。 在这种情况下，任何解决方案都必须考虑 4 个周期内的所有连接分区。 每个细胞独立行为的天真假设会导致计数过多，因为连接性约束将沿周期的选择耦合起来。 

另一个微妙的问题是每个环都是循环的而不是线性的。 将环视为路径会错误地禁止循环的最后一个边缘和第一个边缘之间的连接“环绕”。 

## 方法

 强力解释是单独考虑每个环，并枚举将其单元划分为连接组件的所有可能方法。 由于每个组件必须位于一个环内，因此不同的环不会相互作用，因此总答案是环上的乘积。 

在一个环内，结构是一个简单的循环图，其顶点是该层中的单元格。 一种简单的方法会尝试将该循环的所有分区枚举到连接的归纳子图中。 这相当于考虑所有将循环分割成连续块的方法。 这种分区的数量随着环的大小呈指数增长，甚至对于单个环的长度也是如此$O(m+n)$，暴力破解是行不通的。 

关键的观察结果是，在一个循环中，边的子集唯一地确定了连接组件的划分。 如果我们独立地决定是否对每条边进行切割，则每个生成的连接组件将自动成为有效的图块，因为连接性在每个段内都被精确保留。 

因此，每个环的长度$L$贡献$2^L$可能的方式。 

对所有环求和，每个单元都属于一个环，因此环长度之和等于网格单元总数，即$4mn$。 这将整个问题简化为计算$2^{4mn} \bmod (10^9+7)$。 

蛮力在概念上是有效的，因为它将问题简化为独立的边缘决策，但它在计算上失败了，因为显式建模环或枚举每个环的配置在网格大小上是线性的，并且对于大输入是不可能的。 观察到每个环都是一个循环，其中切割完全表征了平铺，将所有内容压缩为单个指数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个环的暴力枚举| 指数| O(百万) | 太慢了 |
 | 循环边独立性减少| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 观察每个单元格恰好属于由下式确定的一个级别：$\max(|x|, |y|)$。 这将网格划分为不相交的环。 
2. 认识到在一个环内，邻接形成一个简单的循环图。 每个单元沿着该环的边界遍历恰好有两个邻居。 
3. 将环内的有效平铺重新表述为将循环图划分为连接的组件。 每个组件对应于循环中的一个连续段。 
4. 将循环的每个边与二元选择相关联：要么“切割”该边（结束图块边界），要么不“切割”该边。 这确保连接的组件恰好是最大的未切割线段。 
5. 计算长度环内的配置$L$作为$2^L$，因为每个边子集都对应一个有效的分区。 
6. 对所有环的贡献求和。 由于环是不相交的并且覆盖了所有单元格，因此总指数是网格中单元格的数量，即$4mn$。 
7. 计算$2^{4mn} \bmod (10^9+7)$使用快速模幂。 

正确性依赖于以下不变性：每种切割配置都会生成连接组件的唯一分区，并且每个有效分区恰好对应于一种切割模式。 任何配置都不会违反连接性，因为删除循环中的边无法创建除预期片段之外的断开片段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

t = int(input())
for _ in range(t):
    m, n = map(int, input().split())
    exp = (4 * m * n) % (MOD - 1)
    print(mod_pow(2, exp))
```该实现将整个几何图形简化为幂运算。 唯一的微妙之处是使用费马小定理来减少指数模$10^9+6$，因为模数是素数。 

## 工作示例

 我们跟踪两种情况下指数和最终值的计算。 

### 示例 1：$m = 1, n = 1$| 步骤| 价值|
 | --- | --- |
 | 网格尺寸|$2 \times 2$|
 | 细胞| 4 |
 | 指数$4mn$| 4 |
 | 结果 |$2^4 = 16 \bmod MOD$|

 这显示了任何减少之前的原始周期无关解释。 

### 示例 2：$m = 3, n = 1$| 步骤| 价值|
 | --- | --- |
 | 网格尺寸|$6 \times 2$|
 | 细胞| 12 | 12
 | 指数$4mn$| 12 | 12
 | 结果 |$2^{12} = 4096$|

 这证实了缩放任一维度只会通过单元格数量线性增加指数。 

该痕迹表明，一旦认识到循环分解，平铺的所有结构复杂性都会消失。

## 测试用例```python
import sys, io

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        m, n = map(int, input().split())
        out.append(str(mod_pow(2, 4 * m * n)))
    return "\n".join(out)

# sample-like sanity checks

 ## 边缘情况

 当$m = n = 1$，网格减少到长度为 4 的单个周期。该算法将其解释为$4mn = 4$，生产$2^4$。 这符合四个循环边中的每一个都可以独立地被切割或不被切割的想法，从而产生所有有效的连接分区。 

当一维为1而另一维较大时，结构变成一个长矩形边界，有许多嵌套环。 每个环仍然独立贡献，并且总指数仍然恰好是矩形中的单元格数量。 该算法不区分内环和外环，因为所有环都被吸收到全局计数中$4mn$，确保对细长网格的一致处理。
