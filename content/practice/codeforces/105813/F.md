 ## 解决方案
 ## 问题理解

 我们得到一个无向图，其边要么是彩色的`R`或者`B`。 

如果图中存在某些步行，其边缘颜色（按顺序读取）与字符串的字符完全匹配，则该字符串称为可步行。 行走可能会重新访问顶点和边。 

对于每个测试用例，我们必须输出一个**不可**可行走的最短字符串。 如果每个可能的字符串都超过`{R,B}`适合步行，我们打印`-1`。 

该图最多可以包含`2·10^5`所有测试用例的顶点和边。 任何显式构建自动机子集或检查给定长度的所有字符串的解决方案都是没有希望的。 即使检查所有长度为 30 的字符串也已经需要超过 10 亿个候选者。 

挑战在于利用二进制字母表的特殊结构。 

一个微妙的点是，最短的禁止字符串不一定是重复多次的单一颜色。 

考虑：```
1 --R-- 2
```字符串`RR`不适合步行，但是`R`是。 最短的答案是`RR`。 

另一个容易犯的错误是假设如果两种颜色都出现在某个地方，那么每个长度为 1 的字符串都是可步行的，我们只需要检查更长的长度。 

例子：```
1 --R-- 2

3 --B-- 4
```两个都`R`和`B`可以步行，但是`RB`不是。 没有步行可以从红色分量切换到蓝色分量。 正确答案的长度为 2。 

第三个陷阱是错误地处理循环。 

如果图形包含颜色模式以正确方式永远重复的步行，则任意长的字符串就成为可能。 检测到这种情况正是区分`-1`有限答案案例中的案例。 

## 方法

 蛮力观点首先是有用的。 

假设我们想知道一个字符串是否可行走。 我们可以将每个顶点视为可能的当前位置。 读取每个字符后，我们沿着相应颜色的边缘移动。 这只是 NFA 的模拟。 

这立即建议按照 BFS 顺序逐级检查字符串，并在第一个不可步行的字符串处停止。 

问题是候选字符串的数量。 有`2^k`长度的字符串`k`。 即使最短的禁止字符串长度只有 40，也已经意味着大约一万亿个候选者。 

所以我们需要一个完全不同的视角。 

关键的观察是用于二元步行问题的美丽组合引理。 

定义无限周期模式```
RRBBRRBBRRBB...
```及其四个循环移位：```
RRBBRRBB...
RBBRRBBR...
BBRRBBRR...
BRRBBRRB...
```称这四个周期串为`P0, P1, P2, P3`。 

一个经典的结果是：

 如果所有四个长度-`k`这些周期字符串的前缀是可步行的，那么**每个**长度的二进制字符串`k`是步行的。 

这彻底改变了问题。 

而不是检查所有`2^k`字符串，我们只需要了解这四个周期序列中每一个的最长可步行前缀。 

现在图结构变得很重要。 

创建对应于循环内位置的四个相状态```
R -> R -> B -> B -> R -> ...
```对于每个原始顶点`v`，创建四个副本`(v,0)...(v,3)`。 

若相`p`期待颜色`c`，然后每个原始颜色边缘`c`变成有向过渡```
(u,p) -> (v,(p+1) mod 4)
(v,p) -> (u,(p+1) mod 4)
```这个新图中的有向路径完全对应于遵循来自特定阶段的周期序列。 

如果这个有向图包含一个环，那么某个周期序列可以永远延伸。 重复该循环会生成任意长的前缀，并且引理意味着每个二进制字符串都是可步行的。 答案是`-1`。 

否则该图是 DAG。 

在 DAG 中，一个阶段的最长可步行前缀就是从该阶段的任何节点开始的最长有向路径。 

一旦我们知道了这四个最大长度，就可以从最大可步行前缀最小的阶段获得最短的禁止字符串。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解字符串 | 指数| 指数| 太慢了 |
 | 相图 + DAG DP | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 构建有向图`4n`节点。 
2. 使用相位模式：```
phase 0 -> R
phase 1 -> R
phase 2 -> B
phase 3 -> B
```1. 对于每个原始边`(u,v,color)`以及预期颜色等于的每个相`color`， 添加：```
(u,phase) -> (v,next_phase)
(v,phase) -> (u,next_phase)
```1. 在此有向图上运行拓扑过程。 
2. 如果拓扑过程没有删除所有节点，则该图包含有向环。 输出`-1`。 
3. 否则按逆拓扑顺序处理节点并计算：```
dp[x] = longest number of edges in a path starting from x
```1. 对于每个阶段`p`，计算：```
best[p] = max(dp[(v,p)])
```在所有原始顶点上`v`。 

1.让```
p = argmin(best[p])
```该阶段的最长可步行前缀的长度`best[p]`，因此最短的不可行走前缀的长度为：```
L = best[p] + 1
```1.输出第一个`L`从相位开始的周期序列的特征`p`。 

### 为什么它有效

 构造的相图恰好编码了一个周期族的弦。 

长度有向的路径`t`同相开始`p`对应于颜色序列为第一个的步行`t`从 Phase 开始的周期字符串的字符`p`。 

如果相图包含循环，则该周期族具有任意长的可步行前缀。 周期长度是四的倍数，因为相位以模四前进。 重复循环会为所有四个移位产生任意长的前缀，这通过引理意味着每个二进制字符串都是可步行的。 

如果相图是非循环的，则最长路径计算给出每个移位的最大可步行前缀长度。 对于某些移位失败的第一个前缀长度恰好是`best[p] + 1`。 引理保证这也是某些二进制字符串变得不可行走的最小长度。 因此，构造的周期前缀是有效的最短答案。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

PAT = "RRBB"

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n, m = map(int, input().split())

        N = 4 * n
        g = [[] for _ in range(N)]
        indeg = [0] * N

        for _ in range(m):
            u, v, c = input().split()
            u = int(u) - 1
            v = int(v) - 1

            for p in range(4):
                if PAT[p] == c:
                    np = (p + 1) & 3

                    a = u * 4 + p
                    b = v * 4 + np
                    g[a].append(b)
                    indeg[b] += 1

                    a = v * 4 + p
                    b = u * 4 + np
                    g[a].append(b)
                    indeg[b] += 1

        q = deque(i for i in range(N) if indeg[i] == 0)
        topo = []

        while q:
            v = q.popleft()
            topo.append(v)

            for to in g[v]:
                indeg[to] -= 1
                if indeg[to] == 0:
                    q.append(to)

        if len(topo) != N:
            out.append("-1")
            continue

        dp = [0] * N

        for v in reversed(topo):
            best = 0
            for to in g[v]:
                cand = 1 + dp[to]
                if cand > best:
                    best = cand
            dp[v] = best

        phase_best = [0] * 4

        for phase in range(4):
            mx = 0
            for v in range(n):
                mx = max(mx, dp[v * 4 + phase])
            phase_best[phase] = mx

        phase = min(range(4), key=lambda p: phase_best[p])
        length = phase_best[phase] + 1

        ans = []
        for i in range(length):
            ans.append(PAT[(phase + i) & 3])

        out.append("".join(ans))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```该图有`4n`节点，因为每个原始顶点对于内部的每个位置都被复制一次`RRBB`循环。 

拓扑排序有两个目的。 它检测循环并提供 DAG 中最长路径 DP 所需的排序。 

DP 将路径长度存储在边中，而不是顶点中。 由于字符串长度`L`正好对应于遍历`L`彩色边缘，这就是我们需要的数量。 

最终答案长度为`best + 1`， 因为`best`是最大可步行前缀长度。 下一个字符是步行性失败的第一个点。

 ## 边缘情况

 考虑一个没有边的图：```
1 0
```没有非空字符串是可行走的。 相图没有边，因此每个 DP 值都为零。 该算法输出长度为一的周期前缀，例如`R`。 这是正确的。 

考虑一个仅包含红色边的图：```
3 3
1 2 R
2 3 R
3 1 R
```任何以以下开头的周期序列`B`最大可步行前缀长度为零。 算法立即返回`B`，这是最短的禁止字符串。 

考虑两个不相连的单色分量：```
4 2
1 2 R
3 4 B
```单个`R`和一个单一的`B`两者都适合步行。 然而，任何需要颜色切换的字符串都是不可能的。 DP 发现每个周期移位都有最长的可步行前缀长度为 1，从而产生长度为 2 的禁止字符串，例如`RB`。 这解决了仅检查单个颜色的常见错误。 

循环情况由拓扑排序处理。 如果相图包含有向循环，则算法输出`-1`，认识到存在任意长的周期前缀，因此每个二进制字符串都是可步行的。
