 ## 问题理解

 我们得到一个写成数字字符串的大整数，并要求我们构造另一个整数$n$这样一个非常具体的属性成立：考虑可以通过删除一些数字来形成的所有整数$n$同时保留顺序，并获取所有这些结果数字的集合。 从这个集合中，我们计算不以十进制形式出现的子序列值的最小非负整数。 该值必须等于给定的目标$x$。 

重新表述该任务的一种有用方法是，数字的子序列对应于我们可以提取的所有可能的数字字符串，并且我们感兴趣的是哪些整数可以由至少一个这样的数字子序列表示。 目标是设计一个数字，其“缺失的可表示整数”（在子序列意义上）恰好是$x$。 

的约束条件为$x$是结构是基于数字而不是基于数字幅度的第一个信号。 自从$x$最多可以有$10^4$数字，我们显然不是在处理值的算术属性，而是在处理数字存在模式。 任何解决方案都必须在输入表示的长度上以大致线性的时间运行，因为任何数字大小都是二次方的$10^4$或更大的值不符合典型限制。 

一个微妙的点是，这里的子序列的长度没有限制：任何数字子集都是有效的，因此即使非常大的数字也是可能的。 这立即表明答案是由哪些数字至少出现一次来控制的，而不是由它们以复杂的组合方式排列来控制。 

一种重要的边缘情况是子序列中的前导零是否重要。 它们不会影响子序列的有效性，但会影响集合中是否存在数字的数值解释。 例如，具有数字“0”和“1”允许将 0 和 1 形成子序列，但不能形成更高的数字，除非所需的数字以正确的顺序和多重性存在。 

第二个边缘情况是“数字子序列”和“整数子序列”之间的混淆。 该问题将子序列定义为解释为整数的数字字符串，这意味着“01”和“1”在 MEX 计算上下文中实际上是相同的整数表示形式。 将它们视为不同字符串的天真的方法会计算过多。 

## 方法

 暴力解释将尝试模拟候选数的所有子序列$n$，将每个转换为整数，插入到集合中，然后计算 MEX。 即使对于多个长度$L$，这会产生$2^L - 1$子序列，即使对于$L = 40$。 指数爆炸使得这个方向无法使用。 

关键的观察结果是子序列仅取决于其中存在哪些数字$n$，而不是它们在第一次出现之后出现的次数。 任何至少出现一次的数字都可以在子序列中任意使用，但存在是二元的：可用或不可用。 这减少了控制数字可用性模式的问题，以便整数$0, 1, \dots, x-1$都可以表示为子序列，而$x$不是。 

现在考虑一下对于小整数意味着什么$k$显示为子序列。 它要求每一位数字$k$出现在$n$足够的数量并且按照与形成该数字序列一致的顺序。 对于单位数字，这会折叠为：digit$d$出现在$n$当且仅当$d$是有代表性的。 对于多位数字，我们始终可以通过确保所有数字都出现并排列来增强可表示性$n$以足够灵活的方式。 

官方解决方案思路中使用的构造是确保除了一位特殊数字之外的所有数字都存在$n$。 如果正好是数字$d$缺失，则其十进制表示形式包含的每个整数$d$作为子序列变得不可能。 然后，MEX 会受到排除哪个数字的严格控制。 

因此，任务简化为选择要排除的数字，以便所有整数$0 \dots x-1$仍然具有代表性，但是$x$不是。 自从$x$本身是一个十进制字符串，不包括出现在$x$保证$x$不能形成子序列。 为了最大限度地提高正确性，我们排除了最小的数字$x$无效，但构造允许灵活性，因此直接的贪婪方法有效。 

因此，最佳结构是包含除一位之外的所有数字的数字，并按递增顺序排列，以避免任何阻碍子序列形成的排序约束。 这确保仍然可以形成所有所需的较小整数，同时强制$x$由于缺少数字而失败。

 ## 算法演练

 1. 转换输入字符串$x$转换为它包含的一组数字。 这使我们能够推断出在构造的数字中必须避免哪些数字。 
2. 选择一个不存在的数字$x$，或者如果所有数字都出现，请选择任何将阻止形成的数字$x$当从构造数中排除时。 此步骤确保$x$不能形成子序列。 
3. 构建$n$作为数字的串联$0$通过$9$，跳过所选的排除数字。 顺序是固定的并递增，以便所有较小的数字组合在结构上保持可用。 
4. 将构造好的数字直接作为字符串输出。 

这种构造足够的原因是子序列仅取决于数字是否存在，而不取决于重复结构。 一旦除了一位之外的所有数字都出现，就可以通过在序列中选择适当的位置来形成避免丢失数字的任何整数。 

### 为什么它有效

 不变的是构造后，除了排除的数字之外的每个数字至少出现一次$n$。 任何可表示为子序列的整数都必须仅使用可用的数字，因此每个包含排除数字的数字都是不可能的，而所有避免它的数字仍然是可构造的。 由于 MEX 被定义为第一个无法表示的整数，并且排除的数字确保了$x$是第一个此类失败，产生的 MEX 等于$x$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = input().strip()

        used = set(x)

        # find a digit to exclude; if possible pick one not in x
        exclude = None
        for d in "0123456789":
            if d not in used:
                exclude = d
                break

        # if all digits appear, exclude '0' (any choice works in construction)
        if exclude is None:
            exclude = "0"

        res = []
        for d in "0123456789":
            if d != exclude:
                res.append(d)

        print("".join(res))

if __name__ == "__main__":
    solve()
```该代码独立处理每个测试用例，并构建一个缺少一个仔细选择的数字的数字字符串。 关键的实现细节是排除选择不需要深度优化； 任何有效的缺失数字都保证正确的 MEX 结构。 

一个微妙的实现点是处理所有数字都出现在$x$。 在这种情况下，排除任何数字仍然可以保证$x$无法形成，因为构造的数字中至少缺少一位所需的数字。 这可以保持结构的稳健性，而无需位置推理。

```我们计算数字集$x$，即 {1}。 我们可以排除数字 0。

### 示例 2

 输入：```

```数字集为 {1, 0}。 如果可能的话，我们必须排除 x 之外的数字，否则选择安全的后备方案。 

| 步骤| x | 的数字集 排除数字 | 构建 n |
 | --- | --- | --- | --- |
 | 1 | {0,1} | 2 | 013456789 |

 这里数字 2 被删除，但数字 0 和 1 保留，因此 10 以内的小整数仍然可以形成子序列。 缺失的数字可防止较大的结构超出所需的 MEX 阈值。 

这表明该构造对于排除哪一个非必要数字并不敏感，只关心至少删除一个数字。

 ## 边缘情况

 当$x$仅包含一位数字，算法仍然排除不同的数字，这保证了构造的数字至少缺少一位数字。 子序列集仍然足够丰富以形成所有所需的较小值，同时确保定义 MEX 的受控间隙。 

什么时候$x$包含所有数字 0-9，没有数字可基于缺席而安全排除$x$。 后备排除仍然有效，因为删除任何数字都会破坏至少一个可能的表示路径$x$，确保它不能形成为$n$，保持 MEX 构造的正确性。 

什么时候$x$有重复的数字，逻辑上没有任何变化，因为只有存在才重要。 该算法完全忽略了多重性，这与子序列形成行为一致。
