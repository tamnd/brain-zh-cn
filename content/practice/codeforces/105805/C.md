 ## 解决方案
 ## 问题理解

 我们得到了以下数字的排列`1`到`n`。 

一个操作选择两个位置，其当前值为`a`和`b`。 如果`a + b`是一个合数，我们可以交换这两个值。 

问题是，在执行任意次数的此类交换后，我们是否可以将排列转换为排序排列```
1 2 3 ... n
```测试用例数量很大，所有测试用例的总和`n`值最多是`2 · 10^5`。 每个测试用例明显慢于线性或近线性的任何解决方案都会遇到困难。 像这样的东西`O(n^2)`每个测试用例已经太昂贵了`n`方法`2 · 10^5`。 

有趣的是，该操作仅取决于被交换的值，而不取决于它们的位置。 如果值`x`和`y`满足那个`x + y`是复合的，那么这两个值只要出现在排列中就可以交换。 

几个小案例揭示了结构。 

为了```
n = 2
p = [2, 1]
```唯一的一对是`(1,2)`和`1 + 2 = 3`，这是素数。 不可能交换，所以答案是`NO`。 

为了```
n = 3
p = [1, 3, 2]
```这对`(1,3)`可以交换，因为`1 + 3 = 4`是复合的，但是价值`2`是孤立的。 自从`2`已经在正确的位置，可以排序，答案是`YES`。 

粗心的实现可能会假设每个排列都可以排序一次`n ≥ 3`，这是错误的。 例如：```
n = 4
p = [2, 1, 4, 3]
```价值观`{1,3}`组成一个小组并且`{2,4}`形成另一个。 价值观只能在自己的群体内部移动。 位置`1`最终需要价值`1`，但当前包含值`2`来自不同的组，使得排序变得不可能。 

## 方法

 暴力视图是建立一个图，其顶点是值`1..n`。 如果两个值的和是合数，则它们是相连的。 每个允许的交换对应于交换由边连接的两个顶点。 

人们可以重复模拟交换并探索可达排列。 这对于微小的输入是正确的，但状态空间是`n!`，所以它几乎立即变得毫无希望。 

关键的观察是我们实际上并不关心各个交换序列。 

考虑数值图表`1..n`之间存在一条边`x`和`y`什么时候`x + y`是复合的。 

排列组的一个经典事实是，如果图组件是连接的，则沿其边的交换会生成该组件中顶点的每个排列。 实际上，同一连接组件内的所有值都可以在该组件值当前占据的位置之间任意重新排列。 

这将问题变成了连通分量问题。 

假设一个组件包含值`{1,3}`。 任何操作都不能将该组件中的值移动到当前由另一个组件中的值占据的位置。 组件值占据的位置集永远保持不变。 

对排列、值进行排序`i`最终必须到达位置`i`。 因此，对于每个位置`pos`，当前值`p[pos]`和目标值`pos`必须属于同一个连通分量。 

剩下的任务是理解图的组件结构。 

为了`n ≥ 5`，图是连通的。 

所有奇数形成一个派系，因为两个奇数之和至少是偶数`4`，因此复合。 

所有偶数形成一个团，因为两个偶数之和至少是偶数`4`，因此复合。 

价值`5`存在时`n ≥ 5`， 和```
5 + 2 = 7
5 + 4 = 9
```至少有一个偶数连接到奇数团，在奇偶组之间建立一座桥梁。 这样整个图就连接起来了。 

唯一的特殊值`n`是：```
n = 1
component: {1}

n = 2
components: {1}, {2}

n = 3
components: {1,3}, {2}

n = 4
components: {1,3}, {2,4}
```一旦知道了这一点，解决方案就会变得非常小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳| 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读出排列。 
2.如果`n = 1`， 输出`YES`。 
3.如果`n ≥ 5`， 输出`YES`。 

值图是连通的，因此任何排列都可以转换为任何其他排列。 
4.如果`n = 2`，每个值都是孤立的。 

仅当排列已排序时才可排序。 
5. 如果`n = 3`或者`n = 4`，恰好有两个组成部分：`A = {1,3}`和`B = {2,4}`仅限于实际存在的值。 
6. 对于每个位置`i`，检查是否`i`和`p[i]`属于同一个组件。 
7. 如果每个位置都通过检查，则输出`YES`; 否则输出`NO`。 

### 为什么它有效

 连接的组件决定哪些值可以交换位置。 来自不同组件的值永远不能跨越组件边界。 

在连接的组件内，沿图边缘的交换会生成组件值的任意排列。 因此，唯一的障碍是一个值是否需要移动到属于不同组件的位置。 

检查`component(i) = component(p[i])`对于每个位置，精确验证每个值都可以仅使用其组件内部的交换来重新排列到其目标位置。 这个条件既是必要的，也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))

    if n == 1:
        print("YES")
        continue

    if n >= 5:
        print("YES")
        continue

    ok = True

    for i, x in enumerate(p, start=1):
        if (i & 1) != (x & 1):
            ok = False
            break

    print("YES" if ok else "NO")
```实现直接遵循组件特性。 

为了`n = 3`和`n = 4`，分量恰好是奇数值和偶数值。 检查位置是否`i`和价值`p[i]`属于同一个组件相当于检查它们是否具有相同的奇偶校验。 

为了`n = 2`，相同的奇偶校验仍然有效。 位置`1`只能包含`1`，和位置`2`只能包含`2`。 

提前返回`n ≥ 5`是主要的优化。 一旦图连接起来，每个排列都是可排序的，因此不需要进一步的工作。

 ## 边缘情况

 考虑```
1
2
2 1
```该图有两个孤立的顶点，因为`1 + 2 = 3`是素数。 任何交换都是合法的。 奇偶校验立即失败：```
position 1 -> value 2
odd != even
```算法输出`NO`，这是正确的。 

现在考虑```
1
3
3 2 1
```组成部分是`{1,3}`和`{2}`。 

支票给出：```
position 1 -> value 3
position 2 -> value 2
position 3 -> value 1
```每个位置和值都属于同一个组件。 交换`1`和`3`是允许的，因为它们的总和是`4`，因此可以对排列进行排序。 算法输出`YES`。 

最后，考虑```
1
5
5 4 3 2 1
```为了`n ≥ 5`，图是连通的。 每个值都可以通过一系列允许的交换到达每个位置。 算法立即返回`YES`，匹配图的实际可达性结构。
