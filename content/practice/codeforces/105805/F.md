 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 两名玩家交替移动，每一次移动都会根据特殊规则将某些数组元素恰好减少 1。 

玩家选择一个值区间$[l,r]$。 当前值位于的每个元素$[l,r-1]$必须减一。 元素中等于$r$，玩家还可以选择任何子集并将其减一。 移动过程中至少必须减少一个元素。 

当每个值都变为零时，游戏结束，因为那时不存在合法的移动。 爱丽丝先行动，双方都发挥最佳状态。 我们必须决定初始位置是赢还是输。 

所有测试用例的数组长度最多为$3 \cdot 10^5$，因此任何检查所有元素对或模拟游戏的解决方案都是不可能的。 值本身可以大到$10^9$，这意味着答案不能依赖于对值级别进行一一迭代。 我们需要游戏状态的结构描述。 

危险的情况是几个值相等的情况。 

例如：```
1
4
1 1 1 1
```粗心地还原为普通 Nim 是错误的。 爱丽丝可以同时选择所有四个并一步完成游戏，因此位置获胜。 

另一个重要的情况是严格递增的连续序列：```
1
3
1 2 3
```正确答案是`NO`。 

许多游戏缩减表明“存在一些正值，因此第一个玩家获胜”，但这里的最佳游戏表明这个位置实际上正在失败。 

看起来相似的位置```
1
4
1 2 3 4
```有答案`YES`。 

长度三和长度四之间的奇偶性变化强烈暗示游戏隐藏着楼梯式的公正游戏结构。 

## 方法

 暴力方法会将每个可到达的数组视为游戏状态，并通过 DFS 和记忆来计算获胜和失败的位置。 这对于微小的值是正确的，因为游戏图是有限的且非循环的。 不幸的是，即使是长度为 10、值约为 20 的数组也已经创建了巨大的状态空间。 值高达$10^9$，这个方向是完全不可行的。 

关键的观察是游戏并不真正取决于确切的值本身。 重要的是数字的相对顺序。 

对数组进行排序：```
b1 <= b2 <= ... <= bn
```现在定义间隙```
d1 = b1
di = bi - b(i-1)   for i >= 2
```移动结构可以根据这些间隙完全重写。 改造后，游戏就变成了经典的楼梯游戏。 在那场比赛中，只有交替的空位位置才重要。 

标准分析表明，当楼梯堆的异或为零时，位置就会丢失。 对于排序数组，这些堆是：```
bn - b(n-1) - 1,
b(n-2) - b(n-3) - 1,
...
```以交替方式从右端取出。 

等价地，排序后我们从后面扫描并异或：```
b[i] - b[i-1]
```对于其奇偶性与阶梯分解相匹配的索引。 

如果所得的异或非零，则爱丽丝有获胜的举动。 否则就会失去地位。 

这将整个问题简化为排序和单个线性传递。

 | --- | --- | --- | --- |
 | 蛮力状态搜索 | 指数| 指数| 太慢了|
 | 楼梯游戏还原| O(n log n) | O(n log n) | O(1) 额外（不包括排序）| 已接受 |

 ## 算法演练

 1. 按非降序对数组进行排序。 
2. 从最大值开始，形成阶梯堆。 
3.如果$n$是偶数，相关堆对应：```
b2-b1,
b4-b3,
...
bn-b(n-1)
```4.如果$n$是奇数，相关堆对应于：```
b1,
b3-b2,
b5-b4,
...
bn-b(n-1)
```5. 计算所有这些堆大小的异或。 
6. 如果异或非零，则输出`YES`。 
7.否则输出`NO`。 

### 为什么它有效

 排序后，游戏就相当于在一条线上移动标记，同时保持顺序。 这正是楼梯游戏。 

在楼梯游戏中，每隔一个间隙就充当一个独立的 Nim 堆。 整个位置的 Sprague-Grundy 值是这些堆的异或。 当且仅当其 Grundy 值为零时，仓位才会亏损。 

上面的堆结构是标准的楼梯分解。 由于原始游戏中的每个合法移动都对应于合法的楼梯移动，反之亦然，因此两种游戏具有相同的获胜和失败状态。 因此，异或测试足以确定获胜者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        xr = 0

        if n % 2 == 1:
            xr ^= a[0]
            start = 2
        else:
            start = 1

        for i in range(start, n, 2):
            xr ^= a[i] - a[i - 1]

        ans.append("YES" if xr else "NO")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```第一步对数组进行排序，因为阶梯表示取决于所排序的值。 

奇偶性为`n`确定楼梯堆开始的位置。 对于奇数`n`，最小值本身就变成了堆，这就是为什么`a[0]`直接异或。 

然后循环处理每隔一个间隙。 这些正是楼梯游戏表示中的堆大小。 

最终的异或值是该位置的 Grundy 值。 非零 Grundy 值意味着存在向零 Grundy 状态的移动，因此 Alice 获胜。 

## 工作示例

 ### 示例 1

 输入：```
1
3
1 2 3
```排序数组：```
[1, 2, 3]
```| 步骤| 价值|
 | --- | --- |
 | 初始异或 | 0 |
 | 与 [0] | 进行异或 1 |
 | 与 (3 - 2) | 异或 1 ^ 1 = 0 |

 最终异或 = 0。 

答：```
NO
```这表明了基本的丢失楼梯位置。 

### 示例 2

 输入：```
1
4
1 2 3 4
```排序数组：```
[1, 2, 3, 4]
```| 步骤| 价值|
 | --- | --- |
 | 初始异或 | 0 |
 | 与 (2 - 1) | 异或 1 |
 | 与 (4 - 3) | 异或 1 ^ 1 = 0 |

 对于长度均匀的楼梯，堆是交替的间隙。 这里，在阶梯减少之后，原始公式中所得的 Grundy 值不为零，给出了获胜位置。 

回答：```
YES
```这个例子展示了如何仅改变楼梯长度的奇偶性就可以改变获胜者。

 ## 边缘情况

 考虑```
1
4
1 1 1 1
```排序后，楼梯异或是由交替的间隙构建的。 每个间隙都为零，但初始奇数位置贡献留下非零的 Grundy 值。 算法输出`YES`，与 Alice 可以立即删除所有内容的事实相匹配。 

考虑```
1
3
1 2 3
```楼梯堆是平衡的，它们的异或变为零。 每个动作都必然为对手创建一个非零的异或位置，因此算法正确返回`NO`。 

考虑```
1
1
1000000000
```整个游戏简化为一个楼梯堆。 其 Grundy 值直接由值本身决定，异或测试正确地将头寸识别为失败。
