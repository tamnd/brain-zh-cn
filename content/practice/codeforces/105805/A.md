 ## 解决方案
 ## 问题理解

 我们给定一个正整数$n$。 对于每个测试用例，我们必须计算有多少个整数$x$满足$$x + (x \bmod n) = n.$$输入最多包含$10^4$测试用例，以及每个值$n$可以大到$10^{18}$。 我们只需要输出有效整数的个数$x$对于每个测试用例。 

尺寸为$n$立即排除任何逐一尝试候选值的方法。 甚至检查所有值$0$到$n$当$n$可以达到$10^{18}$。 解决方案必须来自于对方程进行代数运算，直到可以在恒定时间内计算出答案。 

一些边缘情况很容易被忽略。 

例如，当$n = 2$,```
x = 1 -> 1 + (1 mod 2) = 2
x = 2 -> 2 + (2 mod 2) = 2
```正确答案是 2。粗心的实施可能只会注意到$x=n$并返回1。 

对于$n = 3$,```
x = 3 -> 3 + (3 mod 3) = 3
```没有其他值起作用，所以答案是 1。这表明额外的解决方案仅出现在偶数值$n$。 

为了$n = 1$,```
x = 1 -> 1 + (1 mod 1) = 1
```答案仍然是1。任何公式都必须正确处理尽可能小的输入。 

## 方法

 最直接的想法就是尝试一切可能$x$, 计算$x \bmod n$，并检验方程是否成立。 

为什么我们可以限制自己$x \le n$？ 因为$x \bmod n$是非负的，所以如果$x > n$， 然后$$x + (x \bmod n) > n,$$永远不能满足方程。 

这种暴力方法是正确的，但是对于$n = 10^{18}$大约需要$10^{18}$检查，这是完全不可行的。 

关键的观察是，一旦我们编写，模运算就变得简单$x$商余数形式：$$x = qn + r,
\qquad 0 \le r < n.$$然后$$x \bmod n = r.$$代入方程可得$$qn + 2r = n.$$现在的问题纯粹是算术问题。 

自从$qn \le n$, 商$q$只能是0或1。 

如果$q = 1$， 然后$$n + 2r = n,$$所以$r = 0$，给出解$$x = n.$$如果$q = 0$， 然后$$2r = n.$$只有当$n$是均匀的。 在那种情况下，$$r = \frac{n}{2},$$和$$x = \frac{n}{2}.$$没有其他值$q$是可能的，因此我们已经完全表征了所有解决方案。 

每一个$n$有解决方案$x=n$。 甚至值$n$还有一种额外的解决方案，$x=n/2$。

 ## 算法演练

 1. 读取值$n$。 
2. 检查是否$n$是奇数还是偶数。 
3.如果$n$为奇数，输出1。 

唯一的解决办法是$x=n$。 
4.如果$n$为偶数，输出2。 

解决方案是$x=n$和$x=n/2$。 

### 为什么它有效

 写作$x$作为$qn+r$将原方程变换为$$qn+2r=n.$$因为$0 \le r < n$，商不能超过1。案例$q=1$总是产生$x=n$。 案例$q=0$恰好在以下时间产生第二个解决方案$n$是均匀的。 这些是唯一可能的情况，因此算法会计算每个有效的解决方案，并且不会错过任何一个。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    if n % 2 == 0:
        print(2)
    else:
        print(1)
```实现直接遵循数学特征。 

我们唯一需要的操作是检查奇偶校验$n$。 什么时候$n$是奇数，解集只包含$x=n$。 什么时候$n$是偶数，$x=n/2$成为第二个有效的解决方案。 

Python 整数轻松支持高达$10^{18}$，因此不存在溢出问题。 每个测试用例的运行时间是恒定的。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append("2" if n % 2 == 0 else "1")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue()

# provided sample

 ## 边缘情况

 考虑：```
1
2
```该算法检测到 2 是偶数并输出 2。 

两种解决方案是：```
x = 1
x = 2
```仅检查的解决方案$x=n$会错误地返回 1。 

现在考虑：```
1
3
```该算法检测到 3 是奇数并输出 1。 

使用导出的方程$$qn + 2r = n,$$案件$q=0$需要$2r=3$，它没有整数解。 仅有的$x=3$遗迹。 

最后，考虑：```
1
1
```算法输出 1。 

确实，$$1 + (1 \bmod 1) = 1.$$偶数分支不会被触发，因此最小的输入被正确处理。
