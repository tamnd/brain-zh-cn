 ## 解决方案
 ## 问题理解

 该情况描述了两部可能到达一楼弗拉德的电梯之间的决定。 每部电梯都有不同的移动规则，目标是确定在 Vlad 按下呼叫按钮后哪一部最快返回 1 层。 

第一部电梯最初停在某个楼层`a`。 一旦被呼叫，它立即开始向 1 层移动。它的行程时间纯粹是当前位置到目的地之间的距离，所以它需要的时间是`|a - 1|`。 

第二部电梯的行为有所不同。 从楼层开始`b`目前正在走向地板`c`。 如果 Vlad 呼叫它，它不会立即前往 1 楼。相反，它首先继续（或完成）当前的移动`c`，并且只有在达到`c`它是否开始向 1 楼移动。这意味着它的总时间是从`b`到`c`，加上从`c`到`1`，即`|b - c| + |c - 1|`。 

任务是比较每个测试用例的这两个到达时间，并确定第一部电梯是否更快，第二部电梯更快，或者它们花费的时间相同。 

约束允许最多`10^4`测试用例，下限值高达`10^8`。 这立即排除了任何逐步的运动模拟。 每个测试必须在恒定时间内处理，因为即使 O(t log n) 也将是不必要的开销，并且由于楼层差异的大小，O(t * 距离) 是不可能的。 

当一部电梯已有效位于 1 楼时，会出现微妙的边缘情况。例如，如果`a = 1`，第一部电梯的运行时间为零。 同样，如果`b = 1`，第二部电梯仍必须完成其当前移动到`c`在返回之前，所以即使它从 1 楼开始，它也永远不会是即时的。如果人们假设起始位置单独决定立即可用性，那么这种不对称性很容易被误解。 

## 方法

 强力解释将按时间步长模拟每个电梯的运动。 对于第一部电梯来说，这是微不足道的，它只是从`a`到`1`。 对于第二部电梯，人们可能会尝试模拟其朝向`c`首先，然后朝向`1`，逐步更新位置。 

这在概念上可行，但完全不可行。 楼层之间的距离可达`10^8`，因此即使是逐步模拟单个测试用例也可能需要花费`10^8`运营，以及跨`10^4`测试用例这变得非常大。 

关键的观察结果是，两台电梯都以恒定速度移动，并且除了距离之外不与任何约束相互作用。 这将整个问题简化为计算总路径长度。 第一部电梯贡献了来自`a`到`1`。 第二部电梯提供了一条固定的两段路径`b`到`c`进而`c`到`1`。 一旦表示为距离，比较就变成了简单的算术检查。 

我们不再优化过程，我们只是比较从数轴上的几何图形导出的两个标量值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(t·最大距离) | O(1) | O(1) | 太慢了|
 | 直接距离计算 | O(t) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取三个整数`a`,`b`， 和`c`。 这些定义了第二个电梯的起始位置和强制中间目标。 
2. 计算第一部电梯的到达时间为`t1 = abs(a - 1)`。 这直接代表它不间断地移动到1层。 
3. 计算第二部电梯的到达时间为`t2 = abs(b - c) + abs(c - 1)`。 这编码了它必须首先完成其运动的规则`c`，然后继续1。 
4. 比较`t1`和`t2`。 如果`t1 < t2`，第一部电梯严格来说更快，因此输出`1`。 
5. 如果`t2 < t1`，第二个电梯严格来说更快，所以输出`2`。 
6. 如果两个时间相等，则输出`3`因为这两种选择是等效的。 

比较背后的原因是，这两个表达式都完全捕获了确定性运动下的总行程时间。 超出这些距离不存在隐藏状态、延迟或分支路径。 

### 为什么它有效

 该系统可以建模为在一维数轴上以恒定速度运动。 一旦发出呼叫，每台电梯的行为都会定义固定的路径长度。 由于行进时间与距离成正比，并且电梯之间没有相互作用，因此最小化到达时间相当于最小化总路径长度。 该算法是正确的，因为它精确地比较了这些路径长度，而无需近似或模拟。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())

    t1 = abs(a - 1)
    t2 = abs(b - c) + abs(c - 1)

    if t1 < t2:
        print(1)
    elif t2 < t1:
        print(2)
    else:
        print(3)
```第一次计算`t1`编码从第一部电梯到目标楼层的直接距离。 第二次计算`t2`明确遵守第二部电梯必须首先到达的约束`c`在到达 1 之前，这就是为什么它被分成两个绝对差，而不是一个与 1 的直接距离`b`到`1`。 

比较逻辑是问题决策规则的直接翻译。 每个分支都是互斥的并且集体详尽的，确保每个测试用例只有一个有效输出。

import sys, io

def run(inp: str) -> str:

    from collections import deque

 ## 边缘情况

 当`a = 1`，第一部电梯的成本为零，因为它已经在目的地楼层。 该算法计算`t1 = abs(1 - 1) = 0`，因此任何非零第二个电梯路径都将正确丢失。 

什么时候`b = 1`，第二部电梯仍然会产生成本，因为它必须首先到达`c`。 例如，与`a = 5, b = 1, c = 10`，我们得到`t1 = 4`和`t2 = 9 + 9 = 18`，因此尽管第二部电梯从 1 楼开始，但第一部电梯仍被正确选择。 

当`c = 1`，第二部电梯的第二段路程变为零，但它仍然支付`b`到`1`。 例如，`a = 10, b = 5, c = 1`给出`t1 = 9`,`t2 = 4 + 0 = 4`，所以第二部电梯获胜，因为它的强制路线实际上在到达目标楼层后立即结束`c`。
