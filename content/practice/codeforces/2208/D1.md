 ## 解决方案
 ## 问题理解

 我们给出了一个有向图的二元可达矩阵$n$节点。 矩阵告诉我们，对于每个有序对$(i, j)$, 是否节点$i$可以到达节点$j$通过有向边。 生成该矩阵的底层图保证是无向树的有向版本，这意味着原始结构完全具有$n-1$边，没有循环，但每个边都被任意分配一个方向。 

任务是判断是否存在无向树结构$n$节点及其边的方向分配，以便生成的可达性矩阵与给定的矩阵完全匹配。 如果存在，我们必须构造一棵有效的树和方向。 

关键对象不仅仅是树，还有它的传递可达性结构。 在有向树中，可达性完全由方向模式决定。 一些方向产生一个有根结构，其中每个节点都到达一个子树，而其他方向则创建更分散的可达性模式。 矩阵对这个闭包进行编码，而不仅仅是直接边缘。 

每个测试的约束都很小，$n \le 500$，但最多有$10^4$测试总立方和界限。 这表明任何$O(n^3)$每次测试都是可以接受的，但是任何比立方体更糟糕的东西都会破裂。 特别是，从头开始重新计算许多候选树的可达性太慢，但使用 Floyd 风格或基于 BFS 的检查来验证单个候选树就可以了。 

一个微妙的边缘情况是多个节点相互到达。 在有向树中，相互可达性意味着它们位于同一个强连接组件中，只有当它们之间的每条边都是双向时才会发生这种情况，这在树中是不可能的，因为边是单向的。 因此任何大于 1 的 SCC 都会立即变得可疑。 另一种失败模式是将矩阵解释为任意可达性而不是树引起的闭包； 许多矩阵满足传递性，但由于缺少结构稀疏性而不能来自树。 

## 方法

 强力的观点是尝试同时重建树结构及其方向。 人们可以尝试猜测根，将边缘向外定向，然后检查所得的可达性是否与矩阵匹配。 这已经失败了，因为有根的向外树产生了一个非常具体的结构：可达性对应于祖先-后代关系，并且只有子树中的节点是可达的。 尝试所有根和所有可能的树结构本质上是指数级的，因为标记树的数量是$n^{n-2}$，甚至检查每个候选人都会涉及$O(n^2)$可达性验证，给出不可行的搜索空间。 

关键的观察是可达性矩阵已经编码了由某些方向引起的偏序。 如果节点$i$可以到达节点$j$，那么在任何有效的构造中，$j$必须位于“下游区域”$i$在定向树中。 这建议从可达性包含的角度进行思考：每个节点对应于它所控制的一组节点。 

现在考虑有向树的结构。 如果我们修复一个节点$r$，并将边缘定向为远离它，则可达性集是嵌套的：如果$u$比更接近根$v$， 然后$v$的可达集是$u$的可达集。 这种嵌套属性成为我们可以测试的主要结构签名。 

关键的见解是，有效节点可以通过其可达性向量的集合包含来排序。 一旦排序，此包含顺序中的相邻节点对应于底层树中的潜在父子关系。 这减少了从全局重建到局部邻接恢复的问题。 

一旦我们解释了每一行$s_i$作为可达节点的位集，我们可以定义该节点$u$可以是节点的父节点$v$如果$s_v \subset s_u$并且没有中间节点$w$这样$s_v \subset s_w \subset s_u$。 这正是包含引起的偏序集中的覆盖关系。 由于底层结构是树，因此这些覆盖关系恰好形成$n-1$如果矩阵有效，则有边。 

重建该候选树后，我们根据可达性集将每条边从超集定向到子集，并最终验证重新计算的可达性与输入匹配。

 ## 算法演练

 我们对待每一行$s_i$作为描述哪些节点可到达的整数位掩码或字符串$i$。 

1. 对于每对节点$i, j$，计算是否$s_i$是一个超集$s_j$， 意义$j$可以从以下位置到达$i$。 这为我们提供了基于可达性包含的节点的偏序结构。 这一步是必要的，因为没有给出直接邻接，只有传递闭包。 
2. 按照可达节点数降序对节点进行排序。 到达更多节点的节点在方向层次结构中处于“较高”位置。 这种排序近似于包含：较大的集合往往是祖先。 
3.对于每个节点$v$, 寻找父母$u$这样$s_v \subset s_u$并且没有节点$w$和$s_v \subset s_w \subset s_u$。 我们按此顺序选择最接近的严格超集。 这确保我们只连接覆盖关系，避免违反树极简性的捷径。 
4.添加有向边$u \rightarrow v$。 方向是一致的，因为如果$u$达到一切$v$达到加上更多，然后$u$必须位于上方$v$在可达性层次结构中。 
5. 搭建完成后$n-1$边，使用每个节点的 BFS/DFS 重新计算可达性，并与给定的矩阵进行比较。 如果出现任何不匹配，则输出“No”。 

### 为什么它有效

 当通过正确的方向层次结构解释时，有向树中的可达性集形成包含在内的层流族。 每个节点的可达集对应于结构的假设有根表示中的一个子树。 原始树中的父子关系与该包含偏序集中的覆盖关系完全对应。 因为树没有循环并且确切地说$n-1$边，如果矩阵有效，则该偏序集的覆盖图本身必须是一棵树。 任何违反传递性或缺少中间包含的行为都会破坏此属性并在验证过程中被捕获。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = [input().strip() for _ in range(n)]

    # precompute reachability sets as bitsets (integers)
    reach = []
    for i in range(n):
        mask = 0
        for j in range(n):
            if s[i][j] == '1':
                mask |= 1 << j
        reach.append(mask)

    def is_subset(a, b):
        return (a | b) == b

    parent = [-1] * n

    # try to assign parent as minimal strict superset
    for v in range(n):
        best = -1
        for u in range(n):
            if u == v:
                continue
            if is_subset(reach[v], reach[u]):
                if best == -1:
                    best = u
                else:
                    # choose tighter superset
                    if is_subset(reach[u], reach[best]):
                        best = u
        parent[v] = best

    # validate we got a tree
    if parent.count(-1) != 1:
        print("No")
        return

    # build adjacency
    g = [[] for _ in range(n)]
    edges = []
    root = parent.index(-1)

    for v in range(n):
        if v == root:
            continue
        u = parent[v]
        if u == -1:
            print("No")
            return
        g[u].append(v)
        edges.append((u, v))

    # recompute reachability
    def dfs(start):
        stack = [start]
        vis = [0] * n
        vis[start] = 1
        while stack:
            x = stack.pop()
            for y in g[x]:
                if not vis[y]:
                    vis[y] = 1
                    stack.append(y)
        return vis

    for i in range(n):
        got = dfs(i)
        for j in range(n):
            if (got[j] == 1) != (s[i][j] == '1'):
                print("No")
                return

    print("Yes")
    for u, v in edges:
        print(u + 1, v + 1)

t = int(input())
for _ in range(t):
    solve()
```该构造依赖于将每个可达性行编码为位掩码，因此子集检查变成快速的按位操作。 父选择扫描严格的超集并选择包含的最接近的超集，这试图重建偏序集中的直接覆盖关系。 构建完候选树后，进行完整的可达性验证以确保正确性，这是可行的，因为$n \le 500$并且运行DFS$n$次。 

一个微妙的点是确保根的唯一性。 根是可达集最大的节点，通常是包括其自身在内的所有节点，并且它不应该有严格的超集。 如果出现多个这样的节点，构造就会变得不一致并被拒绝。 

## 工作示例

 考虑一个小案例$n = 4$:

 输入矩阵：```
1000
1110
0110
0011
```这里我们将行转换为可达集：

 | 节点| 可达集|
 | ---| ---|
 | 1 | {1} |
 | 2 | {1,2,3} |
 | 3 | {2,3} |
 | 4 | {3,4} |

 节点 2 具有最大的集合，因此它成为根。 由于 {2,3} ⊂ {1,2,3}，节点 3 最好连接在节点 2 下，节点 1 也适合，但跳跃太大。 节点 4 附加在节点 3 下，因为它的集合包含在 {2,3} 中，但在没有中间结构的情况下不直接包含在 {1,2,3} 中。 

由此产生的边形成链状结构 2 → 3 → 4，并具有额外的分支 2 → 1，具体取决于最小超集选择。 

第二个例子：```
100
010
001
```每个节点仅到达其自身，因此所有集合都是相同的单例。 不存在严格的包含，因此不可能进行有效的父分配，并且算法正确地拒绝这种情况。

 ## 边缘情况

 关键的边缘情况是两个节点具有相同的可达性行。 在这种情况下，两者都不是对方的严格超集，因此两者都不能成为父集。 该算法正确地失败了，因为没有有效的树可以在不引入循环或双向结构的情况下编码相同的非平凡可达性。 

另一种边缘情况是星形可达性模式，其中一个节点可以到达所有其他节点，但其他节点无法相互到达。 这里最大的行成为根，所有其他行直接附加在它的下面，因为每个都是根的严格子集。 该构造自然会产生一颗有效的星星。 

第三种情况涉及不一致的传递性，例如当$i$达到$j$,$j$达到$k$， 但$i$没有达到$k$。 DFS 验证会立即检测到这一点，因为任何树方向的可达性都必须是与构造的边一致的传递闭包，并且不匹配会强制拒绝。
