[CF 930C - Teodor 不是骗子！](https://codeforces.com/problemset/problem/930/C)

 **求解时间：** 1m 52s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 m 的直线上的整数段的集合。 每个段都会覆盖其内部的每个整数点，包括端点。 对于每个整数位置 x，我们可以计算有多少段覆盖它； 将此值称为 cnt(x)。 

Sasha 可以询问一些选定的位置 x，并且对于每个位置，他都会收到 cnt(x)。 然而，他没有被告知总共存在多少个片段。 Teodor 声称不存在被所有线段覆盖的点，这意味着不存在 cnt(x) 等于线段总数的 x。 萨莎最初并不相信这一说法，并试图通过询问点来收集证据。 

关键的微妙之处在于 Sasha 不需要重建段集。 他只需要决定他收到的答案是否强制得出 Teodor 一定在撒谎的结论，或者是否仍然可能存在与所有答案一致的另一种有效的线段配置，其中某个点被所有线段覆盖。 

我们被要求计算 Sasha 可以查询的不同点的最大数量，这样，即使在收到所有 cnt(x) 值之后，Sasha 仍然不可能确定 Teodor 在撒谎。 

约束 n、m 最大为 100000 意味着任何解决方案都必须大致为 O(m log m) 或 O(m)。 任何涉及检查所有点对或重新计算每个查询的覆盖范围的操作都会太慢，因为在最坏的情况下 m^2 将是 10^10 次操作。 

一种天真的解释会尝试模拟与观察到的计数一致的不同段配置，但这很快就会变得棘手，因为 cnt(x) 值本身并不能唯一地确定全局结构。 

一种微妙的边缘情况是所有点都具有相同的覆盖范围。 例如，如果每个 cnt(x) 等于 1，那么无论存在多少段，观察所有点都不会产生矛盾，因为段的总数是未知的。 这正是第一个样本中的情况，其中所有位置都是对称的。 

另一个重要的边缘情况是，有一个位置的覆盖范围严格最高，而所有其他位置的覆盖范围都较小。 在这样的配置中，如果在查询中省略该唯一峰值，则该独特峰值将成为可用于推断不一致的信息，这在某些情况下限制了答案。 

## 方法

 强力方法将考虑查询点的每个可能的子集，并针对每个子集尝试确定观察到的 cnt 值是否与没有点位于所有段中的假设相矛盾。 对于每个子集，我们需要推断是否存在一些假设数量的片段和排列与所有观察结果相匹配，同时仍然允许在某个替代世界中存在完整的交点。 这很快就会在点的数量上呈指数级增长，因为有 2^m 个可能的查询集，甚至检查单个集也需要推理段重叠的全局一致性。 

关键的观察是，Sasha 的知识从根本上仅限于他在查询点中观察到的最大覆盖值。 由于他不知道n，因此他无法直接检查一个值是否等于段总数。 唯一重要的结构信息是是否有一个独特的位置实现整个线路的全球最大覆盖。

如果最大覆盖值出现至少两次，则没有单个点可以通过被覆盖最多来唯一区分。 在这种情况下，删除或丢失任何点子集都不允许 Sasha 分离出一个独特的信息位置，从而导致矛盾。 然而，如果恰好在一个位置达到最大值，那么该点就变得特殊：它是唯一可以合理地对应于与答案一致的替代解释中的通用交叉点的候选点。 这种不对称性使安全查询的数量减少了一个。 

这将整个问题简化为计算线路的覆盖范围并检查最大值的重数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 | O(2^m·m) | O(2^m·m) | O(米) | 太慢了 |
 | 前缀和+最大频率检查| O(n + m) | O(米) | 已接受 |

 ## 算法演练

 1. 构建一个大小为 m + 2 的数组 diff，初始化为零。 对于每个段 [l, r]，递增 diff[l] 并递减 diff[r + 1]。 这对覆盖范围变化进行编码，而不是显式标记每个覆盖点。 
2. 使用位置 1 到 m 上的前缀和将 diff 转换为实际覆盖范围数组 cnt。 在每个位置 x，cnt(x) 是直到 x 的 diff 值的运行总和。 这重建了线性时间内覆盖每个点的段数。 
3. 扫描cnt数组，确定最大覆盖值mx。 
4. 计算有多少个位置达到了这个最大值mx。 
5. 如果该计数至少为 2，则输出 m，这意味着可以查询所有位置，而无需给出足够的结构来证明矛盾。 
6. 如果最大值恰好出现一次，则输出 m − 1，因为必须有效排除一个位置，以避免揭示唯一识别的覆盖峰值。 

### 为什么它有效

 cnt 数组完全捕获 Sasha 从查询中收到的所有信息。 唯一可以从中推断出的全局结构是其最大值的形状。 如果最大覆盖范围由多个位置共享，则不会在结构上区分单个查询点，因此任何查询子集都无法隔离唯一的决定性见证。 如果恰好存在一个最大值，则该点是唯一一个其值不能被替代一致配置“替换”而不影响全局可行性的位置，这会强制任何最大安全查询集避免丢失这种模糊性。 这将决策完全减少到最大值的多重性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
diff = [0] * (m + 3)

for _ in range(n):
    l, r = map(int, input().split())
    diff[l] += 1
    diff[r + 1] -= 1

cnt = [0] * (m + 1)
cur = 0
mx = 0

for i in range(1, m + 1):
    cur += diff[i]
    cnt[i] = cur
    if cur > mx:
        mx = cur

freq = 0
for i in range(1, m + 1):
    if cnt[i] == mx:
        freq += 1

print(m if freq >= 2 else m - 1)
```该实现使用差异数组来避免显式标记每个段内的每个覆盖点。 这是至关重要的，因为在最坏的情况下直接打标会降低到 O(nm)。 

前缀累积在单次传递中重建精确的覆盖范围。 在计算 cnt 时，同时跟踪最大值以避免额外扫描，但为了清晰和正确性，仍使用第二遍来计算其频率。 

最终决定仅取决于最大覆盖值是否唯一。

 ## 边缘情况

 所有段都相同的情况（例如覆盖整个范围的单个段）会产生恒定的覆盖范围数组。 该算法通过发现每个位置都达到相同的最大值来处理这个问题，从而得出完整的答案 m，这与没有位置具有唯一信息的事实相匹配。 

具有单个点段的情况，如 [1,1]，也会产生一个简单共享的单个最大值，再次产生 m。 由于无法将结构与部分查询区分开来，因此 Sasha 无法获得决定性的信息。 

一个位置被覆盖的次数多于其他任何位置的配置会导致一个独特的最大值。 在这种情况下，算法输出 m − 1，反映必须排除一个位置以避免破坏可区分性，并且前缀和构造通过 cnt 的单次扫描正确识别该唯一峰值。
