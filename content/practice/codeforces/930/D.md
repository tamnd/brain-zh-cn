 ## 解决方案

 ## 问题理解

 我们得到一组黑色标记，放置在不同的整数网格点处。 还有一个白色标记，其起始位置不固定。 游戏以交替回合进行：白色首先移动，并且在每一回合中，玩家将他们控制的每个标记沿四个基本方向之一移动一个单位。 关键的不对称性在于，白色令牌作为一个整体移动，而每个黑色令牌每回合都可以在任何方向独立移动。 

如果假定两名棋手都发挥最佳状态，则黑棋可以从该配置开始强制获胜，则认为白棋输了。 任务是计算有多少个整数网格点可以作为白棋的初始位置，使得黑棋有获胜策略。 

输入大小高达 100000 个黑点，因此任何尝试模拟游戏玩法或独立考虑每个白色起始位置的解决方案都将立即失败。 对点对的二次甚至接近二次的方法已经太大了，因为网格本身跨越了 200001 x 200001 个可能的位置，使得任何直接状态枚举都不可行。 

允许白色令牌在黑色令牌上开始这一事实产生了微妙的边缘情况。 这意味着初始重叠是有效状态。 例如，如果所有黑色标记都聚集在一个小区域中，则该区域内的许多白色起始位置的行为与外部的行为不同。 基于距离的天真直觉可能会失败，因为黑色标记独立移动，并且每回合都可以重塑威胁区域的几何形状。 

另一个棘手的情况是黑色标记对称排列。 例如，如果黑色标记位于原点周围的十字形状上，则丢失的白色位置集不是圆形或菱形，而是取决于由极端投影形成的曼哈顿距离包络线。 这排除了朴素的欧几里得推理。 

## 方法

 暴力方法将尝试评估每个候选的白人起始位置，黑人是否可以强行获胜。 即使将候选者限制在黑色位置或边界框整数点，这仍然涉及大网格和两人动态过程。 每次评估都需要模拟许多回合，其中黑色标记分支为独立的运动，从而导致方向和位置的指数分支。 即使经过严格修剪的搜索也会退化为与可到达状态空间的大小成正比的东西，而可到达状态空间的大小太大了。 

关键的观察结果是，问题不在于单个令牌轨迹，而在于黑色令牌引起的几何优势区域。 由于黑棋每回合都会移动所有棋子，并且可以独立选择方向，因此黑棋可以以每棋子每步的单位速度，有效地向各个方向向外“扩大影响力”。 这将配置转变为 L1 几何中的多源扩展过程。 

我们没有模拟游戏，而是将其重新解释为遏制问题。 如果白色令牌始终能够避免被不断扩大的黑色影响力所困，那么它就能生存下来。 白色的失败区域对应于黑色最终可以“覆盖”所有逃逸方向的点。 这减少了对黑色影响可以传播多远以及哪些初始白色位置位于保证捕获区域内的理解。

一个关键的简化来自于运动的对称性。 由于两名玩家每回合移动一个单位，因此游戏取决于曼哈顿度量的相对距离。 黑边有效地定义了 L1 几何中的凸区域，该区域由黑点的极端投影确定。 损失区域的边界由四个极值方向引起的菱形包络线形成：最大化和最小化 x+y 和 x−y。 

一旦识别出这四个极值，就可以根据每个网格点是否位于半平面的诱导交点内部，在恒定时间内对每个网格点进行分类。 答案变成由这些极值定义的旋转矩形（菱形对齐框）内的整数点数。 

因此，问题从网格上的博弈论简化为计算从黑色令牌投影导出的简单几何区域中的格点。

 ## 算法演练

 我们将黑色配置减少为定义影响边界的四个极值。 

1. 计算所有黑点上 x + y 的最小值和最大值。 这捕获了东北-西南对角线方向的最远范围。 这样做的原因是网格中的移动保留了 x + y 扩展前沿的奇偶结构。 
2. 计算所有黑点上 x − y 的最小值和最大值。 这捕获了西北-东南对角线约束。 与步骤 1 一起，这充分描述了黑色扩展的 L1 边界包络。 
3. 将这四个值转换为对候选白色起点 (x, y) 的约束。 有效的失败区域点必须满足由这些边界引起的所有不等式，这意味着它位于两个对角线带的交点内。 
4. 将生成的几何区域转换为整数格点的计数。 由于该区域在旋转坐标 (u = x+y, v = x−y) 中轴对齐，因此计数简化为计算矩形中整数对 (u, v) 的数量，然后在尊重奇偶校验约束的同时映射回来。 
5. 调整奇偶校验：并非所有 (u, v) 对都对应于整数 (x, y)。 只有 u 和 v 具有相同奇偶校验的对才有效。 这使得有效计数减半，并根据边界对齐进行修正。 

### 为什么它有效

 每个黑色标记定义一个波前，该波前在所有四个方向上每转扩展一个单位。 在L1距离下，这些波前线性组合：t步后所有可达点的并集正是从极端投影导出的约束的交集。 由于黑色标记独立移动，因此没有交互约束限制这种扩展，这意味着只有极值几何才重要。 丢失区域恰好是白色可以无限期地避免被这些扩展的波前包围的点的补充，这完全由四个极值捕获。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    min_s = float('inf')
    max_s = -float('inf')
    min_d = float('inf')
    max_d = -float('inf')
    
    for _ in range(n):
        x, y = map(int, input().split())
        s = x + y
        d = x - y
        min_s = min(min_s, s)
        max_s = max(max_s, s)
        min_d = min(min_d, d)
        max_d = max(max_d, d)
    
    # transform bounds
    # valid region in (u, v) = (x+y, x-y)
    # u in [min_s, max_s], v in [min_d, max_d]
    # count integer (x,y) equivalent to counting valid parity pairs
    
    def count(a, b):
        if a > b:
            return 0
        return b - a + 1
    
    total_uv = count(min_s, max_s) * count(min_d, max_d)
    
    # half of these correspond to integer (x,y)
    # parity adjustment: u and v must have same parity
    def count_same_parity(a1, a2, b1, b2):
        # count u in [a1,a2], v in [b1,b2] with same parity
        def count_parity(l, r, p):
            # numbers in [l,r] with parity p
            first = l if l % 2 == p else l + 1
            if first > r:
                return 0
            return (r - first) // 2 + 1
        
        u_even = count_parity(a1, a2, 0)
        u_odd = count_parity(a1, a2, 1)
        v_even = count_parity(b1, b2, 0)
        v_odd = count_parity(b1, b2, 1)
        
        return u_even * v_even + u_odd * v_odd
    
    print(count_same_parity(min_s, max_s, min_d, max_d))

if __name__ == "__main__":
    solve()
```该实现将所有黑点压缩到两个对角坐标系中。 变量`s = x + y`和`d = x - y`对两条自然 L1 对角线进行编码。 这些值的极值定义变换空间中的边界矩形。 

辅助函数`count_parity`计算给定奇偶校验的有多少个整数位于某个范围内，这是必需的，因为只有匹配的奇偶校验对`(u, v)`对应变换后的整数网格坐标。 最终的表达式结合了偶-偶和奇-奇的组合。 

这里的一个常见错误是完全忘记奇偶校验约束，这会导致计算量增加大约两倍，并在类似棋盘的配置上产生不正确的结果。

 ## 边缘情况

 具有单个黑色标记的最小配置直接演示了边界定义。 如果唯一的点是 (0,0)，则所有极值都会塌陷为零，从而产生单个有效的变换单元。 该算法自然地处理这个问题，因为所有范围都变为长度一并且奇偶校验计数正确减少。 

拉伸的水平线或垂直线表明只有对角线极值才重要。 例如，点 (0,0)、(10,0)、(20,0) 在 x−y 中产生紧边界，但在 x+y 中产生宽边界，并且该算法无需任何特殊外壳即可正确反映膨胀各向异性。 

完全对称的方形配置强调奇偶校验处理。 正方形所有四个角上的点在变换空间中产生相等的偶数和奇数分布。 如果没有奇偶校验校正，计数将加倍，但实现的分割确保了整数网格原像的精确计数。
