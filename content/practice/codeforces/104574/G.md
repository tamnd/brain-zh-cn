 ## 解决方案
 ## 问题理解

 我们得到一个有向函数图：每个 iguana i 都有一个指向 p[i] 的出边，因此每个节点都恰好有一个确定性的下一个位置。 Iguana 1 很特别，因为它永远不会移动，它保持固定在节点 1，我们将其解释为路径最终可能终止的汇点。 

每只鬣蜥在每个​​时间步都重复地遵循其输出边缘。 因此，在时间 t，iguana i 在 p 处对 i 应用了 t 次。 一些鬣蜥最终到达节点 1，而另一些鬣蜥则永远不会到达，因为它们陷入了不包含 1 的循环中。 

任务是计算能够到达节点 1 的鬣蜥从时间 0 开始实际到达那里的预期时间。该期望统一针对最终到达 1 的鬣蜥集合，并且鬣蜥 1 本身包含在到达时间 0 中。 

直接读取表明，我们正在处理有向图中的距离，其中每个节点的出度都是 1，但只有能够达到 1 的节点才重要，并且我们必须将它们的距离平均为 1。 

约束很大：测试用例的节点总数最多为 2×10^5。 这排除了任何通过逐步向前行走来独立模拟每只鬣蜥的解决方案，因为在最坏的情况下（例如长链），这可能会花费 O(N^2)。 

当循环存在时，会出现微妙的边缘情况。 循环中任何不包含 1 的节点永远不会到达目的地，必须完全排除。 另一个边缘情况是在长前缀之后最终进入这样的循环的节点； 即使它们的前缀路径一开始看起来像是有效的路由，也必须将它们排除在外。 

例如，考虑 1 → 2 → 3 → 2。节点 2 和 3 永远不会达到 1，因此只有节点 1 计数且答案为 0。无法正确检测循环的朴素 DFS 会错误地分配有限距离。 

另一种情况是一条长链输入 1，如 5 → 4 → 3 → 2 → 1。所有节点的贡献距离分别为 0,1,2,3,4，期望是它们的平均值。 任何为每个节点单独重新计算路径的解决方案都有重复遍历同一条链的风险。 

## 方法

 该结构是一个函数图，其中每个节点只有一个出边。 自然的强力方法是通过重复遵循 p[i] 直到达到 1 或检测到循环，来计算每个节点到达节点 1 所需的步数。 

这在概念上是有效的，因为每条路径都是确定性的。 然而，在最坏的情况下，图可以是长度为 N 的单链或长度为 N 的循环。如果我们独立地重新计算每个节点的游走，则每次游走都需要 O(N)，导致总操作为 O(N^2)，这对于 2×10^5 节点来说太慢了。 

关键的观察是，一旦循环被移除，这就是一个反向树问题。 在函数图中，每个连通分量恰好包含一个循环。 只有包含节点 1 的组件是相关的。 在该组件内部，我们可以反转边并将其视为一棵以 1 为根的树。在此反转图中，所有可以达到 1 的节点都位于 1 的反向可达集合中。 

一旦我们将自己限制在可以达到 1 的节点上，那么从节点到 1 的距离就是它在反向 BFS 树中的深度。 因此，任务简化为计算未加权图中从节点 1 开始但在反向边上的所有最短距离。 

然后，我们对所有可到达节点上的这些距离进行平均。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个节点的蛮力行走 | O(N^2) | O(N^2) | O(1) | O(1) | 太慢了 |
 | 从 1 反转图 BFS | O(N) | O(N) | 已接受 |

 ## 算法演练

 我们通过将函数图转变为反向邻接结构并从节点 1 开始执行 BFS 来解决该问题。

1. 构建一个反向邻接表，其中对于每个 i，我们将 i 添加到 rev[p[i]]。 这会翻转运动方向，向后移动对应于“谁可以一步到达该节点”。 这是必要的，因为我们需要到节点 1 的距离。 
2. 从节点 1 开始在反转图上运行 BFS。 我们分配 dist[1] = 0 并将其推入队列。 
3. 从队列中弹出节点。 对于每个节点 u，迭代 rev[u] 中的所有 v。 如果 v 尚未被访问过，则设置 dist[v] = dist[u] + 1 并推送 v。这确保我们以越来越多的步数向外扩展以达到 1。 
4. BFS 完成后，只有被访问过的节点才是能够到达节点 1 的节点。我们计算访问过的节点上所有 dist 值的总和，并统计访问过的节点数。 
5.答案是总和/计数。 

我们可以安全地忽略未访问的节点的原因是，反转图上的 BFS 准确地捕获了节点 1 的可达性。任何未访问的节点都位于环中或反向与 1 断开的组件中，这意味着它无法到达原始图中的 1。 

### 为什么它有效

 BFS 保证当节点 v 第一次被分配一个距离时，该距离是达到 1 所需的最短反向边数，这恰好对应于 v 达到 1 所需的前向步数。由于每条边都有单位权重，因此 BFS 层会匹配精确的步数。 被访问节点的集合正是距离为 1 的有限节点的集合，因此根据过程的定义排除其他节点是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        p = list(map(int, input().split()))
        
        rev = [[] for _ in range(n + 1)]
        for i in range(1, n + 1):
            rev[p[i - 1]].append(i)
        
        dist = [-1] * (n + 1)
        q = deque([1])
        dist[1] = 0
        
        while q:
            u = q.popleft()
            for v in rev[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)
        
        total = 0
        cnt = 0
        for i in range(1, n + 1):
            if dist[i] != -1:
                total += dist[i]
                cnt += 1
        
        print(total / cnt)

if __name__ == "__main__":
    solve()
```实现直接遵循 BFS 公式。 反向邻接表是在线性时间内构建的。 BFS 确保每个节点都被处理一次，并且 dist[i] 存储到达节点 1 所需的确切步骤数。 

唯一微妙的一点是确保无法到达的节点不包含在平均值中。 这是通过检查 dist[i] != -1 来处理的。 另一个重要的细节是在最后使用浮点除法，因为答案预计为实数。 

## 工作示例

 ### 示例 1

 输入：```
3
5
5 2 3 1 4
```我们构建边：1→5、2→2、3→3、4→1、5→4。 反向边有：5←1、2←2、3←3、1←4、4←5。 

BFS 从 1 开始。 

| 步骤| 节点| 距离 | 新到达 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 4 |
 | 2 | 4 | 1 | 5 |
 | 3 | 5 | 2 | 1（已看过）|

 节点 2 和 3 无法从 1 反向到达，因此被排除在外。 

距离：节点 1 = 0、节点 4 = 1、节点 5 = 2。平均值 = (0 + 1 + 2) / 3 = 1。 

这表明只有反向可达集中的节点有贡献。 

### 示例 2

 输入：```
3
3
1 2 3
```每个节点都指向自身或形成简单的自循环。 

反向图的每个节点都指向自身。 

广度FS：

 | 步骤| 节点| 距离 | 新到达 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 无 |

 仅节点 1 可达。 答案是 0 / 1 = 0。 

这表明不涉及 1 的孤立循环被正确排除。

 ## 边缘情况

 一种边缘情况是只有节点 1 可以到达其自身。 在这种情况下，BFS 恰好访问一个节点，分母为 1，产生 0。该算法自然地处理这一问题，因为 dist[1] = 0 并且没有计算其他节点。 

另一个边缘情况是与 1 断开的纯循环。例如 2 → 3 → 2。来自 1 的反向 BFS 永远不会到达这些节点，因此它们被完全排除。 这可以防止错误的无限循环，并避免除以零的问题，因为节点 1 始终被计数。 

第三种情况是长链馈入 1。例如 4 → 3 → 2 → 1。BFS 从根开始按升序正确分配距离 0,1,2,3。 平均值是在所有四个节点上计算的，符合“可达鬣蜥”的定义。
