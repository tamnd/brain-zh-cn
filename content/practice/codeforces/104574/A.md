 ## 解决方案
 ## 问题理解

 我们有两张相同的矩形纸，每张的尺寸$M \times N$。 我们可以使用与边平行的直线切割将每张纸切割成较小的轴对齐矩形。 切割后，所有从两张纸上得到的碎片都可以自由地重新排列和旋转（隐式地，因为在从碎片形成新的矩形时，方向并不重要），并且我们希望将它们组装成一个尺寸的目标矩形$P \times Q$。 

与许多瓷砖问题不同，我们不需要使用所有材料。 形成目标矩形不需要的任何剩余部分都保持未使用，我们必须计算它们的总面积。 如果根本不可能构造目标矩形，我们输出“IMPOSSIBLE”。 

关键的观察是，唯一真正的限制来自总可用面积。 每个初始矩形贡献$M \cdot N$，所以我们一起有$2MN$单位平方的材料价值。 由于允许任意轴对齐切割，因此每个矩形都可以一直细化为单位正方形，这意味着我们实际上有$2MN$独立的 1x1 单元格，只要满足面积约束，就可以重新排列成任何矩形形状。 

限制因素$M, N, P, Q \leq 1000$意味着所有计算都适合 32 位整数，因此我们无需担心 Python 中的溢出。 该解决方案必须在每个测试用例中以恒定的时间运行。 

一个常见的错误是过度考虑几何约束，例如尝试匹配纵横比或模拟切割策略。 例如，人们可能会错误地假设，因为我们一开始只有两个矩形，所以目标必须以某种方式与$M$或者$N$。 这会导致错误的拒绝，例如：

 输入：```
4 4
5 3
```简单的几何方法可能会失败，因为 5 不能整除 4，反之亦然，但正确答案是有效的，因为我们只关心总面积。 

另一个失败案例是：

 输入：```
2 2
3 3
```这里，总面积是 8，而目标面积是 9，因此即使形状看起来相似也是不可能的。 

## 方法

 暴力思维会尝试模拟两个矩形的所有可能的切割模式，递归地分割它们并尝试组装目标矩形。 这种情况很快就会爆发，因为每次切割都会增加碎片的数量，并且每个碎片都可以通过多种方式再次划分。 即使我们将切割限制为整数坐标，矩形的分区数量在两个维度上都会呈指数增长，使得这种方法即使对于$M, N \leq 1000$。 

关键的见解是切割自由度消除了结构约束。 由于我们可以沿着网格线重复切割，每个$M \times N$矩形可以简化为$MN$单位平方。 有了两个矩形，我们实际上就有了一组$2MN$单位平方。 一旦降低到这个水平，形成目标矩形的唯一剩余要求是具有足够的总单位正方形。 

这将整个问题简化为简单的面积比较。

 ## 算法演练

 1. 计算总可用面积为$2 \cdot M \cdot N$。 这表示我们在任意切割后可以从两个矩形中提取的单位正方形的最大数量。 
2. 计算所需面积为$P \cdot Q$。 这是形成目标矩形所需的单位正方形的确切数量。 
3. 将所需面积与可用面积进行比较。 如果所需面积超过可用面积，则无法构造目标矩形，因为任何重新排列或切割策略都无法创建比现有材料更多的材料。 
4. 如果可以施工，则将剩余面积计算为$2MN - PQ$，对应于形成目标后未使用的单位方块。 

### 为什么它有效

 因为任意直线切割允许我们将两个初始矩形细分为 1x1 单位单元格，所以原始几何形状不会对这些单元格的总数施加任何限制。 任何具有整数边长的矩形只是相同晶胞的不同排列。 由于重新排列不受限制，因此可行性仅取决于是否存在足够的小区来覆盖目标区域。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    M, N = map(int, input().split())
    P, Q = map(int, input().split())

    total = 2 * M * N
    need = P * Q

    if need > total:
        print("IMPOSSIBLE")
    else:
        print(total - need)

if __name__ == "__main__":
    solve()
```该解决方案读取两个矩形并直接计算总可用面积和所需面积。 关键的实现细节是将所有内容保留在整数运算中，而不进行任何几何模拟。 仅在可行性检查后才执行减法，以避免产生负剩余值。

 ## 边缘情况

 一种边缘情况是目标与原始矩形之一完全匹配。 例如，如果$M=N=5$和$P=5, Q=5$，算法计算总面积$50$, 所需面积$25$，并返回$25$。 这相当于只使用一半的材料，这是有效的，因为允许使用剩余的材料。 

另一种边缘情况是目标面积等于总可用面积。 如果$M=N=3$和$P=3, Q=6$，总面积为$18$并且需要的面积也是$18$。 该算法输出 0，意味着没有浪费任何东西。 这证实了完全利用是干净地处理的，无需特殊分支。 

最后一种边缘情况是当一个维度相对于原始矩形非常大时，例如$M=N=1000$,$P=1$,$Q=1$。 该算法仍然可以正确工作，因为它只比较面积，结果变为$2 \cdot 10^6 - 1$，这是有效的。
