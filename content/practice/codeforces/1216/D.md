 ## 解决方案
 ## 问题理解

 我们得到了一系列剑类型，每种类型在被盗后都有一些剩余数量。 对于每种类型$i$，值$a_i$告诉我们地下室里还有多少把这种类型的剑。 

最初，每种类型都有相同的未知数量$x$。 然后有一定数量的人$y$进入后，他们每个人都选择了一种类型并准确地偷了$z$那种类型的剑。 这意味着对于任何类型$i$，被盗剑的数量是$z$，取决于有多少人选择了该类型。 

所以对于每种类型$i$，我们可以写：$$a_i = x - k_i \cdot z$$在哪里$k_i \ge 0$是偷窃类型的人数$i$，以及所有的总和$k_i$在所有类型上都是$y$。 

我们不知道$x$,$y$， 或者$z$。 我们的任务是确定$z$和$y$， 在哪里$z$是一个正整数并且$y$被最小化，同时仍然与所有给定的一致$a_i$。 

约束条件$n \le 2 \cdot 10^5$和$a_i \le 10^9$意味着任何解必须接近线性或$O(n \log n)$。 任何事情都尝试一切可能$z$或为每个候选人模拟多个配置将不起作用。 

当所有$a_i$是平等的。 在这种情况下，仅凭差异就无法检测到盗窃行为，并且存在多种解释，包括$y = 0$。 然而，该问题保证至少有一对$a_j \ne a_k$，这确保存在有意义的差异结构并避免完全简并。 

当最优的情况出现时，会出现另一种边缘情况$z$不等于任何$a_i$或直接它们之间的差异，而是从差异的 gcd 导出。 一个天真的尝试$z = \min(a_i)$或者$z = \max(a_i)$会失败，因为正确的$z$受所有差异的一致性而非绝对值的约束。 

## 方法

 蛮力策略是猜测$z$，并为每个候选者模拟必须有多少人偷剑才能变换一些未知的统一初始值$x$进入观察到的多重集$a$。 对于固定的$z$，我们会尝试通过选择一个候选者来调整所有值$x$（通常$\max a_i$或略高于它）并计算大小的步长$z$每种类型都需要。 这很快就会变得昂贵，因为$z$范围可达$10^9$，即使我们限制候选者，也要验证每个候选者的一致性$z$仍然需要扫描全部$n$元素。 这导致$O(n \cdot Z)$或者充其量$O(n \sqrt{A})$，这太慢了。 

关键的观察是价值观之间的所有差异都是结构化的。 如果我们确定一个候选最大值$x = \max(a_i) + t$，那么每个$x - a_i$必须能整除$z$。 这意味着所有差异$a_{\max} - a_i$必须共享一个公约数结构。 因此，有效$z$必须除掉之间的所有差异$a_{\max}$以及所有其他元素。 

这导致了关键的简化：而不是搜索$z$，我们计算：$$g = \gcd(a_{\max} - a_i \text{ for all } i)$$每个有效$z$必须划分$g$，问题的结构意味着选择$z = g$产生尽可能少的人数$y$。 一次$z$是固定的，最优的$x$是$a_{\max}$，因为任何更高的$x$只会增加所有计数，而不会减少所需操作的总数。 

对于这个固定的$z$, 每种类型$i$贡献：$$\frac{a_{\max} - a_i}{z}$$到总人数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n \cdot \max a_i)$|$O(1)$| 太慢了 |
 | 最佳|$O(n \log A)$|$O(1)$| 已接受 |

 ## 算法演练

 我们现在逐步构建解决方案。 

1. 找出所有值中的最大值$a_i$。 叫它$mx$。 这代表了原始未触及值的自然候选者$x$，因为任何类型都不能超过原始数量。 
2. 计算所有差异$d_i = mx - a_i$。 这些差异表示相对于最大剩余堆栈从每种类型中删除了多少。 
3. 计算所有非零的最大公约数$d_i$。 如果所有值都相等，则 gcd 将为零，但该问题保证至少存在一个差异。 
4. 设置$z$等于这个gcd。 这确保了每种类型的每个移除计数都是以下的整数倍$z$，这是必需的，因为每个人都精确地删除了$z$剑。 
5. 计算$y$作为所有类型的总和$d_i / z$。 这计算了有多少人必须贡献所有类型的清除。 

为什么它有效：

 所有有效的解决方案都必须尊重每个$d_i$可分解为大小相等的块$z$。 这迫使$z$划分每一个$d_i$，因此它必须除以它们的 gcd。 选择完整的 gcd 最大化$z$，这最小化了所需块的总数，因为$y$成反比于$z$。 该结构确保一次跨类型的独立性$z$是固定的，因此将捐款求和得出尽可能少的人数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import gcd

n = int(input())
a = list(map(int, input().split()))

mx = max(a)

g = 0
for x in a:
    g = gcd(g, mx - x)

y = 0
for x in a:
    y += (mx - x) // g

print(y, g)
```实现首先读取数组并识别最大值，该最大值充当参考基线。 gcd 计算会累积与该最大值的所有差异； 用零初始化 gcd 是安全的，因为$\gcd(0, x) = x$，允许第一个差异设置比例。 

第二个循环通过将每个差值除以最终的 gcd 来计算所需操作的总数。 整数除法是安全的，因为 gcd 保证了整除性。 输出打印$y$首先，其次是$z$，匹配问题要求。 

一个常见的实施陷阱是使用最小值而不是最大值作为参考点。 这打破了可分性结构，因为差异可能会变得消极或不一致。 另一个微妙的问题是忘记了 gcd 必须包含所有元素，而不仅仅是相邻的差异。

这证实了所有移除都可以一致地分组为大小为 3 的块，并且使用更小的块$z$会迫使更多的人，增加总人数。

 ## 边缘情况

 一种边缘情况是所有值都相同。 在这种情况下，每个差异都为零，并且 gcd 崩溃为零。 该算法产生$y = 0$和$z = 0$，这反映出一定没有发生盗窃事件。 该约束保证至少有一对不相等，因此大多数官方解决方案不需要特殊处理，但从概念上讲，这是模型的退化边界。 

当差异的 gcd 为 1 时，会出现另一种边缘情况。这迫使$z = 1$，这意味着每把失踪的剑都对应一个单独的人。 该算法自然地处理这个问题，因为整数除以 1 保留了所有差异，并且总和简单地变成了相对于最大值的总损失。
