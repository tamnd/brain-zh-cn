 ## 解决方案
 ## 问题理解

 我们有一排房间，编号为`1`到`n`。 

每个房间最终都必须连接到互联网。 有两种方法可以实现这一目标。 

房间可以直接连接，支付的费用等于其索引。 连通房`i`直接成本`i`。 

部分房间标有`'1'`在输入字符串中。 这些房间可以安装 Wi-Fi 路由器。 在房间里放置路由器`i`还花费`i`，但它不是只服务于它本身，而是覆盖了间隔中的每个房间`[i-k, i+k]`，剪裁到走廊边界。 

目标是选择一些路由器和一些直接连接，以便覆盖每个房间，同时最大限度地降低总成本。 

首先要注意的是，路由器的成本出奇的便宜。 房间里有路由器`i`费用与直接连通房完全相同`i`，但它可能免费覆盖许多其他房间。 这表明只要路由器有用，它就可以取代多个直接连接。 

约束条件`n ≤ 2 · 10^5`才是真正的挑战。 任何尝试所有路由器子集的算法都是不可能的。 甚至一个`O(n²)`动态程序将执行`4 · 10^10`最坏的情况下操作，远远超出了时限。 我们需要一些接近的东西`O(n log n)`。 

一个微妙的点是路由器可能会重叠。 一个房间可以被多个路由器覆盖，但我们只关心它是否至少连接过一次。 诸如“始终放置最便宜的可用路由器”之类的天真的贪婪策略会失败，因为稍微昂贵的路由器可能会覆盖更大的区域。 

考虑：```
5 2
00100
```房间里的路由器`3`覆盖每个房间。 成本`3`。 

正确答案：```
3
```直接连接所有房间需要花费`15`，因此单独处理路由器和直接连接将错过最佳解决方案。 

另一个容易犯的错误是忘记某些房间无法托管路由器。```
3 1
000
```任何路由器都不能放置在任何地方。 唯一的解决办法是：```
1 + 2 + 3 = 6
```输出：```
6
```假设每个位置都可以托管路由器的解决方案将错误地返回较小的值。 

边界附近出现了一种更微妙的情况。```
5 2
10000
```房间有路由器`1`覆盖房间`[1,3]`， 不是`[−1,3]`。 走廊的剪报结束很重要。 不正确的间隔处理通常会导致第一个和最后几个房间出现相差一的错误。 

## 方法

 暴力的观点是从左到右处理房间，并决定每个房间是否应该直接连接或通过某个路由器连接。 

假设我们在前缀上定义一个 DP。 对于房间`i`，我们可以搜索覆盖范围包括的所有路由器`i`并尝试一切可能性。 困难在于路由器会同时影响许多未来的房间。 跟踪所有可能的覆盖状态会迅速爆炸。 即使更仔细地执行检查所有先前的位置也会导致`O(n²)`过渡，这对于`n = 200000`。 

关键的观察结果是，这实际上是前缀上的最短路径式 DP。 

让`dp[i]`是连接房间的最低成本`1..i`。 

如果房间`i`直接连接，则：```
dp[i] = dp[i-1] + i
```有趣的部分是路由器。 

假设位置有一个路由器`p`。 

其覆盖区间为：```
[L, R]
```在哪里```
L = max(1, p-k)
R = min(n, p+k)
```如果我们决定为该路由器付费，那么所有房间`L..R`立即连接。 覆盖该区间之前的成本恰好是`dp[L-1]`，并在付款后`p`硬币我们立即获得前缀的有效状态`R`。 

这给出了一个过渡：```
dp[R] = min(dp[R], dp[L-1] + p)
```这已经类似于状态线上的最短路径。 

剩下的挑战是，在从左到右扫描时，一些路由器转换在到达其右端点之前变得可用。 我们需要一种方法来有效维护当前可以覆盖当前房间的所有路由器。 

标准解决方案使用优先级队列。 当我们从左到右处理位置时，每个路由器都会贡献一个候选值：```
dp[L-1] + p
```它对其覆盖范围内的每个房间仍然有效。 堆保留最小的活动候选者。 然后：```
dp[i] = min(
    dp[i-1] + i,
    best active router candidate
)
```每个路由器进入和离开堆一次，产生一个`O(n log n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力DP | O(n²) | O(n) | 太慢了 |
 | 基于堆的DP | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 定义`dp[i]`作为连接房间所需的最低成本`1..i`。 
2. 设置`dp[0] = 0`。 
3. 对于每个路由器位置`p`，计算其覆盖区间：```
L = max(1, p-k)
R = min(n, p+k)
```4. 按左端点对路由器进行分组`L`。 

当我们到达位置时`L`，路由器变为可用。 
5. 扫仓`i`从`1`到`n`。 
6. 计算前`dp[i]`，将左端点等于的每个路由器插入优先级队列`i`。 

对于这样的路由器，存储：```
value = dp[L-1] + p
```连同它的右端点`R`。 

该值表示在覆盖的时间间隔之前支付所有费用然后安装此路由器的总成本。 
7. 从堆中删除右端点小于的所有路由器`i`。 

这些路由器不再覆盖房间`i`。 
8. 连接房间`i`直接地：```
dp[i] = dp[i-1] + i
```9.如果堆不为空，则最小堆值对应最便宜的路由器覆盖空间`i`。 

更新：```
dp[i] = min(dp[i], heap_min_value)
```10.继续直到位置`n`。 
11. 输出`dp[n]`。 

### 为什么它有效

 在位置`i`，房间的每个有效解决方案`1..i`必须以两种方式之一结束。 

任一房间`i`是直接连接的。 在这种情况下，前面的房间形成了前缀的最佳解决方案`i-1`, 给予成本`dp[i-1] + i`。 

或房间`i`属于该位置某个路由器的覆盖区间`p`。 如果该路由器开始覆盖`L`，然后是之前的所有房间`L`必须已经以最佳方式连接，成本`dp[L-1]`。 付费`p`路由器完成包含的整个间隔`i`, 给予成本`dp[L-1] + p`。 

该堆恰好包含其间隔当前覆盖的所有路由器`i`，因此最小堆值是最好的基于路由器的转换。 取直接连接过渡和最佳路由器过渡之间的最小值，考虑连接房间的每种有效方式`i`。 通过增加前缀的归纳法，`dp[i]`对于每一个都是最优的`i`， 包括`dp[n]`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from heapq import heappush, heappop

def solve():
    n, k = map(int, input().split())
    s = input().strip()

    add = [[] for _ in range(n + 2)]

    for p in range(1, n + 1):
        if s[p - 1] == '1':
            L = max(1, p - k)
            R = min(n, p + k)
            add[L].append((R, p))

    dp = [0] * (n + 1)
    heap = []

    for i in range(1, n + 1):
        for R, p in add[i]:
            heappush(heap, (dp[i - 1] + p, R))

        while heap and heap[0][1] < i:
            heappop(heap)

        dp[i] = dp[i - 1] + i

        if heap:
            dp[i] = min(dp[i], heap[0][0])

    print(dp[n])

solve()
```预处理阶段计算每个路由器的覆盖间隔。 路由器按其左端点分组，因为当扫描到达其覆盖的第一个房间时，路由器就变得可用。 

堆存储对`(candidate_cost, right_endpoint)`。 当路由器变为活动状态时，候选成本已完全计算：```
dp[L-1] + p
```一个常见的错误是稍后尝试重新计算该值。 过渡取决于`dp[L-1]`，不在当前位置。 

每当过期路由器的右端点落在当前房间之前时，它们就会被删除。 清理之后，堆中剩余的每个路由器都会覆盖空间`i`。 

直连过渡始终可用：```
dp[i-1] + i
```堆最小值给出了最便宜的路由器转换。 取两者中的最小值即可得到最佳前缀值。 

所有成本都可以轻松地用 Python 整数表示。 最大可能的答案大致是：```
1 + 2 + ... + 200000
```这是关于`2 · 10^10`，完全在 Python 的整数范围内。

 ## 边缘情况

 考虑：```
3 1
000
```不存在路由器。 在整个扫描过程中堆保持为空。 DP 反复使用：```
dp[i] = dp[i-1] + i
```生产：```
1, 3, 6
```最终的答案是`6`，正是直接连接每个房间的成本。 

现在考虑：```
5 2
10000
```房间里的路由器`1`仅涵盖房间`[1,3]`。 

当扫掠到达房间时`4`，路由器仍然处于活动状态，但不再覆盖空间`5`过期后。 该算法在正确的时刻将其从堆中删除，因为它存储的右端点是`3`。 

由此产生的最优策略为：```
router at 1  -> cost 1
direct room 4 -> cost 4
direct room 5 -> cost 5
```全部的：```
10
```等等，我们可以做得更好：```
router at 1 covers rooms 1..3
direct room 4
direct room 5
```成本：```
1 + 4 + 5 = 10
```DP 精确计算该值，因为在 room 之后`3`，路由器转换消失，仅保留直接转换。 

最后，考虑：```
5 10
00100
```路由器的标称间隔为：```
[-7, 13]
```剪裁后变成：```
[1, 5]
```路由器插在房间里`1`并且在房间之前永不过期`5`。 堆不断提供成本`3`，所以 room 中的每个前缀`3`继续获得价值`3`。 算法正确返回`3`，展示了对超出两个走廊边界的间隔的正确处理。
