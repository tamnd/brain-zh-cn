 ## 解决方案
 ## 问题理解

 我们得到了一系列罐头，每个罐头都有一个耐用值。 瓦西亚必须对所有罐子射击一次，但击倒一个罐子所需的射击次数取决于已经击倒的罐子数量。 具体来说，如果罐头具有耐用性$a_i$瓦西娅已经击倒了$x$罐头，他需要$a_i \cdot x + 1$开枪摧毁那个罐头。 目标是确定使射击总数最小化的射击顺序，并报告最小总数和一个有效顺序。 

输入由罐数组成$n$（最多 1000）及其耐久性值$a_i$（最多 1000 个）。 这些界限表明算法$O(n^2)$或更快的速度是可以接受的，但是任何尝试所有的算法$n!$排列是不可行的，因为$1000!$是一个天文数字。 

当多个罐子具有相同的耐用性时，就会出现边缘情况。 最佳顺序可能不是唯一的，但无论首先选择哪个等效罐，总的射击次数都应该相同。 另一个微妙的点是，最小的总数可能需要从最小的耐久度开始，如果不仔细推理，这可能是不直观的。 

## 方法

 暴力方法会尝试罐头的每一种排列，计算每个订单的射击总数，并选择最小值。 这是正确的但完全不切实际，因为$n!$增长速度比任何可行的计算都快$n = 1000$。 为了$n = 10$，这已经需要 3,628,800 个检查。 

关键的见解是认识罐头的成本函数，$a_i \cdot x + 1$，随着已经被击倒的罐子数量线性增长。 因此，如果后期射击，罐头耐久度的影响就会被放大。 为了最大限度地减少总量，我们希望高耐用性的罐子能够尽可能小$x$尽可能地，这意味着更早地拍摄它们。 相反，耐久性低的罐子可以延迟，因为它们的贡献随着增加而增长得更慢。$x$。 这种观察导致了一种贪婪的方法：按照耐用性的降序对罐头进行排序，然后按该顺序进行射击。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最优（贪婪的耐久性）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读$n$和耐久性数组$a$。 的每个元素$a$与其原始索引配对以跟踪拍摄顺序。 
2. 按耐用性降序对配对列表进行排序。 这确保了如果延迟则需要更多注射的罐头可以更早地注射。 
3. 初始化已射击罐数的计数器，$x = 0$，以及一个累积总镜头的变量，$total = 0$。 
4. 迭代已排序的罐子。 每个罐头都具有耐用性$a_i$，将所需的镜头计算为$a_i \cdot x + 1$。 将其添加到$total$并增加$x$一个。 
5. 从排序对中提取原始索引以形成拍摄顺序。 
6. 打印$total$以及拍摄顺序。 

工作原理：该算法保证每个罐子的成本乘以所有具有相同或更高耐用性的罐子中先前被击倒的罐子的尽可能少的数量。 这保持了不变式，即没有其他排列可以产生更小的总数，因为稍后放置更高的耐用性会增加其加权贡献，这是次优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

# Pair durability with original indices
cans = [(a[i], i + 1) for i in range(n)]
# Sort by descending durability
cans.sort(reverse=True, key=lambda x: x[0])

total = 0
order = []

for x, (dur, idx) in enumerate(cans):
    total += dur * x + 1
    order.append(idx)

print(total)
print(' '.join(map(str, order)))
```该解决方案使用有效地读取输入`sys.stdin.readline`。 持久性与原始索引的配对保留了排序后的映射。 排序键确保递减的耐用性。 总镜头在循环中累积，其中`x`自然地跟踪已射击的罐子数量。 最后，按照排序后的拍摄顺序输出索引。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    cans = [(a[i], i + 1) for i in range(n)]
    cans.sort(reverse=True, key=lambda x: x[0])
    total = 0
    order = []
    for x, (dur, idx) in enumerate(cans):
        total += dur * x + 1
        order.append(idx)
    return f"{total}\n{' '.join(map(str, order))}"

 ## 边缘情况

 对于相同耐用性的罐头，该算法保留了正确性，因为它们的顺序不会影响总数。 例如，输入`3 1 1 1`无论顺序如何，总共产生 6 个。 踪迹：

 | 步骤| x| 可以（dur，idx）| 已添加镜头 | 总计 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | (1,1) | 1 | 1 |
 | 1 | 1 | (1,2) | 2 | 3 |
 | 2 | 2 | (1,3) | 3 | 6 |

 较高耐用性罐头先行的不变量很容易得到满足，并且输出仍然有效。
