 ## 解决方案
 ## 问题理解

 我们得到了一系列菜肴，每道菜都包含一些克鱼和一些克肉。 对于每道菜，品尝者都会消耗固定的食物总量，但他可以选择从该菜中吃多少鱼和多少肉。 如果剩余的鱼和肉相同，则在品尝后，两道菜被认为是相同的。 目标是选择品尝者从每道菜中吃多少鱼和肉，以便最大限度地减少不同菜肴的数量。 

每个测试用例都提供了菜肴的数量、每道菜的初始鱼和肉的数量以及品尝者必须吃的总克数。 输出需要品尝后最少数量的不同菜肴，以及品尝者的实际饮食计划。 

约束条件允许所有测试用例中总共最多有 200,000 道菜肴，每道菜肴的鱼和肉数量最多为 100 万。 比较所有菜肴对所吃食物的所有可能分配的幼稚方法会太慢，因为可能性的数量呈二次方增长`n`。 品尝者必须尊重每道菜的界限，所以`0 <= fish eaten <= a_i`和`0 <= meat eaten <= b_i`，如果总吃的量可能会产生棘手的边缘情况`m_i`小于任一分量。 例如，如果一道菜有`(2, 2)`克鱼和肉以及`m_i=3`，品尝者必须将鱼和肉分开吃 3 克。 如果我们选择`(3, 0)`或者`(2, 1)`我们随意改变剩下的盘子，选择错误的分配可能会阻止多个盘子崩溃到相同的最终状态。 

不明显的边缘情况包括零鱼或零肉的菜肴，或者当`m_i`完全等于强制执行特定分配的组件之一。 比如说一道菜`(0, 5)`和`m_i=3`只能有`(0, 3)`吃完，离开`(0, 2)`在后面。 忽略这些界限的粗心实现可能会产生无效结果。 

## 方法

 蛮力方法是枚举品尝者吃每道菜的所有可能方式，生成所有可能的方式`(remaining_fish, remaining_meat)`配对并数出不同的最终菜肴。 这是可行的，因为最终的品种是由这些对决定的，但对于大的情况则失败了`n`因为每道菜最多有`m_i + 1`的可能性，产生指数搜索空间。 和`n`最多2*1​​0^5，这是不可能的。 

关键的观察是，为了最大限度地减少不同菜肴的数量，我们希望尽可能多的菜肴最终得到相同的剩余鱼和肉。 每道菜都有一个可以吃多少鱼的可行范围：`max(0, m_i - b_i)`到`min(a_i, m_i)`。 那么剩下的鱼就是`a_i - eaten_fish`剩下的肉是`b_i - eaten_meat = b_i - (m_i - eaten_fish)`。 如果我们选择`eaten_fish`在这个可行的范围内，所得到的`(remaining_fish, remaining_meat)`可以沿整数晶格中的直线取值。 

这种见解使我们能够将问题视为为剩余的鱼找到一个位于所有菜肴的可行间隔内的单一值（如果可能的话）。 具体来说，计算所有菜肴的最小和最大剩余鱼数（`a_i - min(a_i, m_i)`和`a_i - max(0, m_i - b_i)`），然后取这些范围的交集。 该交集内的任何值都可以用作所有菜肴的剩余鱼，保证一种的最少种类。 如果交集为空，则最小品种为两个：为一半菜肴选择可行范围内的一个值，为其余菜肴选择另一个值。

 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每道菜，计算品尝后可以剩余的最少和最多鱼。 品尝者至少可以吃`max(0, m_i - b_i)`鱼，最多`min(a_i, m_i)`鱼。 剩下的鱼是`a_i - eaten_fish`，给出一个可行的区间`[a_i - min(a_i, m_i), a_i - max(0, m_i - b_i)]`。 
2. 获取所有这些间隔并计算所有菜肴的交集。 让`low`是所有区间下界的最大值，并且`high`是所有上限的最小值。 
3.如果`low <= high`，对于所有菜肴来说，剩余的鱼都存在一个共同的值。 选择`remaining_fish = low`并将每道菜吃掉的鱼计算为`a_i - remaining_fish`。 然后`eaten_meat = m_i - eaten_fish`。 剩下的菜品都是相同的，所以最小品种是 1。 
4.如果`low > high`，间隔不相交。 使用自己的时间间隔为每道菜单独选择一条可行的剩余鱼。 最小品种至少为 2。一个简单的策略是为每道菜选择下限。 剩下的盘子最多会塌陷成两种不同的图案。 
5. 输出最少品种以及品尝者的饮食计划`(eaten_fish, eaten_meat)`每道菜。 

为什么有效：通过表示每道菜的可行剩余鱼间隔并将它们相交，我们确保选择一个对所有菜肴同时有效的值。 这保证了品尝者吃得准确`m_i`每道菜和其余菜肴都可以制作相同，从而最大限度地减少品种。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        input()  # blank line between test cases
        n = int(input())
        a, b, m = [], [], []
        for _ in range(n):
            ai, bi, mi = map(int, input().split())
            a.append(ai)
            b.append(bi)
            m.append(mi)

        low = -1_000_000_000
        high = 1_000_000_000
        for i in range(n):
            min_remain_fish = a[i] - min(a[i], m[i])
            max_remain_fish = a[i] - max(0, m[i] - b[i])
            low = max(low, min_remain_fish)
            high = min(high, max_remain_fish)

        res = []
        if low <= high:
            remaining_fish = low
            for i in range(n):
                eaten_fish = a[i] - remaining_fish
                eaten_meat = m[i] - eaten_fish
                res.append((eaten_fish, eaten_meat))
            print(1)
        else:
            for i in range(n):
                eaten_fish = a[i] - (a[i] - min(a[i], m[i]))
                eaten_meat = m[i] - eaten_fish
                res.append((eaten_fish, eaten_meat))
            print(2)
        for x, y in res:
            print(x, y)

if __name__ == "__main__":
    solve()
```该解决方案首先解析输入并将菜肴信息存储在列表中。 计算每道菜的可行余鱼区间，并确定区间的交集。 如果存在共同的价值观，则选择它； 否则，将使用简单的后备。 品尝者的饮食计划是根据这些选择的剩余鱼量得出的。 注意尊重每道菜的界限，并确保所吃食物的总和等于`m_i`。
