 ## 解决方案
 ## 问题理解

 我们被要求模拟数轴上蚱蜢的运动。 蚱蜢从某个整数坐标开始$x_0$并在离散的分钟内进行跳跃。 每一步跳跃距离增加 1：第一次跳跃为 1，第二次跳跃为 2，第三次跳跃为 3，依此类推。 跳跃的方向由当前位置的奇偶性决定：如果蚱蜢处于偶数坐标，则向左跳跃；如果处于偶数坐标，则向左跳跃； 如果它位于奇数坐标，它会向右跳转。 任务是在准确之后确定最终坐标$n$跳跃。 

输入很大：$x_0$可以达到$10^{14}$绝对值，并且$n$也可以达到$10^{14}$。 这排除了任何幼稚的跳跃模拟，因为逐一迭代将需要最多$10^{14}$操作，这远远超出了一秒时间限制的可接受限制。 相反，我们需要确定一种模式或公式，使我们能够有效地计算最终位置。 

一个关键的观察是，跳跃方向仅取决于当前位置的奇偶校验，并且距离是连续整数。 这表明多次跳跃的效果可以通过分析奇数和偶数的累积和来确定，或者通过考虑模 4 的净效应来确定。要观察的边缘情况包括从 0 开始、负坐标、非常大$n$， 和$n = 0$没有跳跃的地方。 

例如，开始于$x_0 = 0$和$n = 2$给出序列：从左跳 1 到 -1（偶数 -> 左），从右跳 2 到 1（奇数 -> 右）。 简单的模拟适用于小型$n$，但对于大的情况失败$n$。 

## 方法

 蛮力方法很简单：迭代跳跃次数$n$，根据奇偶性确定方向，并更新位置。 这适用于小型$n$，但自从$n$可以达到$10^{14}$，时间复杂度$O(n)$是完全不可行的。 

最佳方法取决于检测运动中的重复模式。 我们注意到，四次连续跳跃的效果在净位移方面形成了一个循环，具体取决于起始奇偶校验。 例如，从偶数开始，前四次跳跃改变位置$-1, +2, -3, +4$按顺序，导致净位移+2。 同样，该模式每四次跳转重复一次。 通过减少$n$模 4 并分别对完整周期求和，我们可以在每个测试用例的恒定时间内计算出最终位置。 

暴力模拟之所以有效，是因为它正确遵循基于奇偶校验的跳转规则，但在以下情况下会失败：$n$非常大。 通过观察跳跃形成可预测的四步模式，我们可以计算最终坐标，而无需模拟每次跳跃。

 ## 算法演练

 1. 读取测试用例的数量并迭代每一对$(x_0, n)$。 如果$n = 0$，结果立即$x_0$因为没有发生跳跃。 
2.确定起始位置的奇偶性$x_0$。 如果$x_0$为偶数时，我们将使用“偶数开始”跳跃模式； 如果是奇数，则为“奇数开始”模式。 
3. 计算四次跳跃的完整循环数：$k = n // 4$。 每个周期的净位移为+2 或-2，具体取决于起始奇偶校验。 
4. 计算剩余跳跃的位移：$r = n \% 4$。 根据循环模式枚举剩余的移动，并将它们对总位移的贡献相加。 
5. 将完整循环的累积位移相加，余数跳转到初始位置，得到最终坐标。 

工作原理：以 4 为模的跳跃序列会生成位移的重复模式。 起始位置的奇偶性决定了第一次跳跃的方向，进而确定了后续三次跳跃的符号模式。 通过将跳跃分组为四个周期，我们将潜在的大量操作减少为简单的算术计算。 这种不变性奇偶性决定了跳跃方向，并且四次连续跳跃产生固定的净运动，确保了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def final_position(x, n):
    if n == 0:
        return x
    parity = x % 2
    cycles = n // 4
    remainder = n % 4
    pos = x
    if parity == 0:
        pos += cycles * 2
        if remainder == 1:
            pos -= n
        elif remainder == 2:
            pos += 1
        elif remainder == 3:
            pos += n + 1
    else:
        pos -= cycles * 2
        if remainder == 1:
            pos += n
        elif remainder == 2:
            pos -= 1
        elif remainder == 3:
            pos -= n + 1
    return pos

t = int(input())
for _ in range(t):
    x0, n = map(int, input().split())
    print(final_position(x0, n))
```代码首先检查是否存在零跳转。 然后，它计算奇偶校验并计算有多少个完整的四跳转周期以及剩余的跳转次数。 它分别应用循环和剩余跳跃的位移。 根据起始奇偶校验正确处理符号。 这些操作纯粹是算术运算，确保每个测试用例的时间恒定。
