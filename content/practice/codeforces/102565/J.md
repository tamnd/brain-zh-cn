 ## 解决方案
 ## 问题理解

 我们有一个以加权图表示的城市。 每栋房子都是一个有固定坐标的顶点，每条路都是一条边，其权重就是这条路上行驶的人数。 我们需要为雕像选择一个整数点。 仅当道路的两个端点房屋都在一定距离内时，道路才会贡献其重量`R`从那时起。 答案是从一个雕像位置可见的最大道路总重量。 

坐标具有特殊的形状。 可以有很多房屋和道路，最多`100000`每个，以及`y`坐标可以大到`10^9`。 扫描平面上所有可能的点的解决方案是不可能的。 甚至扫描所有可能的`y`值不起作用，因为范围很大。 唯一的小尺寸是`x`房屋的坐标，仅限于`0..100`。 

超出这个范围的雕像不需要考虑。 如果候选点有`x < 0`，将其移至`x = 0`保持不变`y`协调并且只会减少到所有房屋的距离。 同样的论点适用于`x > 100`。 因此，总是存在一些最佳答案`0 <= x <= 100`，仅留下 101 条可能的垂直线可供检查。 

有些细节很容易出错。 同一房屋之间的多条道路必须独立处理，因为它们的重量都很重要。 光有房子还不够，路有贡献，两端都必须看到雕像。 例如：```
2 1 1
0 0
2 0
1 2 5
```正确的输出是：```
0
```一座雕像位于`(1,0)`是距离`1`来自两所房子？ 其实第二个房子就是距离`1`，但第一栋房子也是距离`1`，所以这个例子会输出`5`。 危险的情况是只有一个端点接近时：```
2 1 1
0 0
3 0
1 2 5
```正确的输出是：```
0
```仅检查一个端点的粗心解决方案会错误地计算道路。 

另一个边缘情况是一条道路的可见性区间对于所选的道路来说是空的。`x`。 这两座房子可能各自可见，但它们的垂直范围可能不重叠。 这样的路一定不能加。 

## 方法

 直接的解决办法就是尝试每一个可能的雕像点。 对于每个点，我们检查每条道路，如果两个端点足够近，则添加其权重。 这是正确的，但候选点的数量是无法枚举的，因为`y`坐标可达`10^9`。 

更好的蛮力使用小的`x`范围。 对于每一个`x`从`0`到`100`，我们可以计算哪个整数`y`职位工作。 单个房屋贡献的间隔为`y`固定值`x`。 如果水平距离是`dx`，则剩余垂直距离为：$$\sqrt{R^2-dx^2}$$所以房子对于所有整数都是可见的`y`在：$$[y_i-dy, y_i+dy]$$对于道路，我们使两个端点间隔相交。 每条有效道路都成为当前垂直线上的加权区间。 那么问题就变成了寻找区间的最大加权重叠。 

剩下的挑战是做得足够快。 只有 101 条垂直线，因此要针对每条道路进行处理`x`是可以接受的。 对于每个`x`，我们创建扫描事件。 一个区间`[l,r]`将其重量添加到`l`并将其删除于`r+1`。 对所有事件进行排序并扫描它们，可以得出该事件的可见旅行者的最大数量`x`。 

蛮力之所以有效，是因为几何形状在固定后变成一维`x`，但如果我们保留所有可能的情况，它就会失败`y`坐标。 小坐标范围使我们能够检查每个可能的垂直切片。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 太大| O(1) | O(1) | 太慢了|
 | 最佳 | O(101 * (N + M) log M) | O(101 * (N + M) log M) | O(101N) | 已接受 |

 ## 算法演练

 1. 预先计算，针对每个房屋和每个可能的雕像`x`坐标从`0`到`100`，房子可以看到雕像的垂直间隔。 该间隔存储为房屋周围的半高`y`协调。 如果房屋水平距离太远，则该间隔被标记为无效。 
2. 对于每个可能的雕像`x`，处理所有道路。 对于一条路`(a,b)`计算两个预先计算的垂直间隔的交集。 如果交叉口非空，则创建两个扫描事件：在间隔的底部添加道路权重，并在顶部之后减去它。 
3. 按事件的顺序对事件进行排序`y`协调并按顺序扫描它们。 维持当前覆盖当前道路权重的当前总和`y`协调。 本次扫描期间达到的最大值是本次扫描的最佳雕像位置`x`。 
4. 保留所有 101 个可能答案中的最大答案`x`价值观。 

为什么有效：对于固定的`x`，每一条可见的道路都恰好对应于一个连续的有效整数区间`y`坐标。 扫描线计算这些间隔所覆盖的最大总重量，这正是该垂直线上的最佳雕像位置。 由于存在最佳雕像位置`x`之间`0`和`100`，检查所有这些行涵盖了所有可能的最佳值。 

## Python 解决方案```python
import sys
import math
from array import array

input = sys.stdin.readline

def solve():
    N, M, R = map(int, input().split())

    xs = [0] * N
    ys = [0] * N
    for i in range(N):
        xs[i], ys[i] = map(int, input().split())

    edges = []
    for _ in range(M):
        a, b, p = map(int, input().split())
        edges.append((a - 1, b - 1, p))

    reach = []
    r2 = R * R

    for x in range(101):
        cur = array('i', [-1]) * N
        for i in range(N):
            dx = x - xs[i]
            rem = r2 - dx * dx
            if rem >= 0:
                cur[i] = math.isqrt(rem)
        reach.append(cur)

    ans = 0

    for x in range(101):
        events = []
        rx = reach[x]

        for a, b, p in edges:
            ra = rx[a]
            if ra < 0:
                continue
            rb = rx[b]
            if rb < 0:
                continue

            low = max(ys[a] - ra, ys[b] - rb)
            high = min(ys[a] + ra, ys[b] + rb)

            if low <= high:
                events.append((low, p))
                events.append((high + 1, -p))

        events.sort()

        cur = 0
        best = 0
        i = 0
        while i < len(events):
            y = events[i][0]
            while i < len(events) and events[i][0] == y:
                cur += events[i][1]
                i += 1
            if cur > best:
                best = cur

        if best > ans:
            ans = best

    print(ans)

if __name__ == "__main__":
    solve()
```这`reach`表仅存储每个房屋和每个可能的垂直半径`x`。 使用`array('i')`保持这个表紧凑，因为这些值最多是`10000`。 

主循环修复一尊雕像`x`并将每条道路转换为区间`y`轴。 区间交集使用`max`在下界和`min`在上限上。 这是检查两个端点很重要的部分。 

扫描事件使用`high + 1`而不是`high`因为坐标是整数。 在下一个整数处添加删除事件会恰好删除其最后一个有效位置之后的间隔。 

所有权重和总和都使用 Python 整数，因此可能的总总体不会溢出。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(101 * (N + M) log M) | O(101 * (N + M) log M) | 101条垂直线每条最多处理所有道路和类别`2M`事件。 |
 | 空间| O(101N + M) | 存储可见性表和一个事件列表。 |

 常数因子很小，因为`x`维度只有 101 个可能的值。 该算法避免了对巨大的依赖`y`坐标范围。

 ## 边缘情况

 当一条道路有两个单独可见但其间隔不重叠的端点时，算法会拒绝它，因为相交测试需要`low <= high`。 这可以防止计算实际上无法从某一点看到雕像的道路。 

当多条道路连接同一对房屋时，每条边都会创建自己的一对清扫事件。 扫描会添加所有权重，因此不会丢失任何流量。 

当最佳位置恰好位于观察圈的边缘时，整数间隔计算会保留它，因为间隔端点是包含在内的。 使用`r + 1`删除正确地保留了这个边界。
