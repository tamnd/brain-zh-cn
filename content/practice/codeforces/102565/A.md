 ## 解决方案
 ## 问题理解

 我们可以将工件视为有向图的顶点。 一对`x -> y`意味着神器`x`可以跟随神器`y`构建咒语时。 咒语只是一条包含至少两个不同顶点的有向路径。 

关键的观察结果是，朋友不需要拥有整条路径。 如果两件神器出现在同一条定向路径上的任何位置，拥有这两件神器就足以让朋友重新创建完整的咒语。 用图的术语来说，如果两个顶点之一可以到达另一个顶点，则两个顶点不能同时被放弃。 

任务是找到最大可能的顶点集，使得两个选定的顶点都不会通过任一方向的可达性连接。 这是可达关系的最大反链。 

该图最多包含 3000 个顶点和 20000 个有向边。 检查每个工件子集的解决方案是不可能的，因为有 23000 种可能的选择。 即使是重复检查每对顶点的算法也必须仔细设计，因为可达性关系是全局的，而不仅仅是基于原始边。 对于 3000 个顶点，立方体预处理已接近实际极限，而完全排除任何指数形式的情况。 

有几个细节可能会破坏一个更简单的解决方案。 首先，直接边缘是不够的。 一对工件之间可能没有边缘，但在较长的路径上仍然存在冲突。 

例如：```
3 2
1 2
2 3
```正确答案是`1`。 仅检查直接边缘的粗心解决方案可能会选择伪影`1`和`3`，但是神器`1`达到神器`3`，所以这两个工件不能共存。 

其次，循环需要特殊处理。 考虑：```
3 3
1 2
2 3
3 1
```正确答案是`1`。 每个工件都可以到达其他所有工件，因此最多可以选择一个工件。 将图视为普通 DAG 而不压缩强连接组件会错过这一点。 

第三，孤立的工件始终是有效的选择。 例如：```
4 1
1 2
```正确答案是`3`。 文物`3`和`4`不参与任何咒语，如果仔细选择，两者都可以与边缘的一个端点一起赠送。 仅计算边中出现的顶点的解决方案会低估答案。 

## 方法

 直接方法将尝试所有可能的工件集并验证它是否包含冲突对。 这是正确的，因为有效答案恰好是没有通过可达性相关的顶点对的子集。 然而，子集的数量呈指数级增长，因此它甚至无法处理几十个工件。 

不太极端的暴力首先计算可达性，然后贪婪地添加工件，同时避免冲突。 这个想法的问题在于，最大的有效集合不一定可以通过贪婪排序获得。 该结构是部分有序集的结构，其中局部选择可能会阻碍更大的最终解决方案。 

有用的转换来自于查看图结构。 首先，同一强连接组件内的顶点是相互可达的，因此我们最多可以从每个组件中保留一个工件。 在收缩每个强连接组件之后，剩下的图就是一个 DAG。 此 DAG 中的可达性定义了偏序。 

现在的问题变成了寻找 DAG 中最大的反链。 迪尔沃斯定理给出了一个等效的公式：最大反链的大小等于覆盖所有顶点所需的最小链数。 对于 DAG，这可以计算为：

 答案=C−最大匹配

 哪里`C`是SCC压缩后的节点数。 匹配建立在二分图上，该二分图包含每个 DAG 节点的两个副本。 我们从左侧副本添加一条边`u`到右侧的副本`v`每当`u`可以达到`v`。 

蛮力失败是因为它试图推理所有可能的独立集。 通过观察冲突形成偏序，我们可以用标准最大匹配计算来替换问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2 N ⋅N 2 ) | O(2 N ⋅N 2 ) | O(N 2 ) | 太慢了 |
 | SCC + 传递闭包 + 匹配 | O(N 3 +V 2 V ​ ) | O(N 2 ) | 已接受 |

 ## 算法演练

 1. 使用 Tarjan 算法计算有向图的强连通分量。 

一个强连接组件内的每一对顶点都可以相互到达，因此朋友永远不会从同一组件收到两个工件。 压缩后，每个组件代表一种可能的选择。 
2. 构建压缩 DAG。 

每个强连接的组件都成为一个节点。 如果两个不同组件之间存在原始边，则在相应的 DAG 节点之间添加一条边。 

压缩图没有环，这使得可达性更容易处理。 
3. 计算每对组件之间的可达性。 

因为组件的数量最多为3000个，所以基于bitset的DAG遍历就足够了。 以逆拓扑顺序处理组件并合并传出邻居的可达集。 

经过这一步，我们就确切地知道哪些组件对不能同时被选择。 
4. 创建迪尔沃斯定理使用的二分图。 

创建每个组件的左右副本。 对于每对`(u, v)`在哪里`u`可以达到`v`，从左侧副本添加一条边`u`到右侧的副本`v`。 

匹配代表有多少个节点可以合并到链中。 
5. 在此二分图上运行 Hopcroft-Karp 最大匹配。 

应用该定理后不匹配的分量的数量就是最大反链的大小。 
6. 输出值：

 组件数量−最大匹配尺寸

 为什么它有效：

 SCC 压缩后，每个剩余节点代表一组，其中不可能选择多个顶点，因此每个组件最多贡献一个工件。 压缩图是一个 DAG，可达性定义了偏序。 有效答案正是该偏序的反链，因为没有选定的组件可以到达另一个选定的组件。 

迪尔沃斯定理指出，最大反链大小等于最小链分解大小。 对于 DAG，最小链分解是通过获取节点数并减去可达性二分图中的最大匹配来计算的。 因此，该算法准确地返回可以安全赠送的最大文物数量。
