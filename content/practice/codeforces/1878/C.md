 ## 解决方案
 ## 问题理解

 问题是我们能否准确地选择`k`集合中不同的整数`{1, 2, ..., n}`使得它们的总和等于`x`。 每个测试用例提供三个整数：`n`，我们可以选择的数字的上限；`k`，我们必须选择的元素数量； 和`x`，目标总和。 如果这样的选择是可能的，则输出应该是“YES”，否则输出应该是“NO”。 

约束表明`n`可以大到 200,000 并且`x`最大可达 400 亿，测试用例可达 10,000 个。 穷举所有组合的尝试是不可行的，因为 k 元素子集的数量与`n`和`k`。 因此，我们需要一个在每个测试用例的恒定或线性时间内工作的解决方案。 

容易被忽视的边缘情况包括总和小于最小可能总和的情况`k`元素，或大于最大可能的总和。 例如，如果`n = 5`,`k = 3`， 和`x = 3`，三个不同数字的最小和是`1 + 2 + 3 = 6`，所以答案一定是“NO”。 同样，如果`x`超过了总和`k`最大数量在`{1..n}`，这是不可能的。 

## 方法

 蛮力方法是生成所有组合`k`之间的数字`1`和`n`并检查其中任何一个的总和是否等于`x`。 这是正确的，但非常慢：组合的数量是`C(n, k)`，对于最大值`n`和`k`可以超过10^150，远远超出可行的计算。 

关键的见解是认识到最小总和`k`不同的数字始终是第一个数字的总和`k`自然数，`1 + 2 + ... + k = k*(k+1)/2`。 同样，最大和是最大的和`k`数字，`n + (n-1) + ... + (n-k+1) = k*(2n - k + 1)/2`。 如果`x`小于最小总和或大于最大总和，答案立即为“否”。 否则，可以选择中间的数字来精确达到`x`。 这为每个测试用例提供了恒定时间的检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C(n,k)) | O(C(n,k)) | O(k) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`,`k`， 和`x`。 
2. 计算最小可能的总和`k`不同的数字为`min_sum = k*(k+1)//2`。 这个总和使用第一个`k`正整数。 
3. 计算最大可能总和：`max_sum = k*(2*n - k + 1)//2`。 这个总和使用最大的`k`整数来自`1`到`n`。 
4. 比较`x`和`min_sum`和`max_sum`。 如果`x`位于区间之外`[min_sum, max_sum]`，输出“否”。 
5. 否则，输出“YES”。 

为什么有效：任何外部金额`[min_sum, max_sum]`无法获得，因为元素不同且以 1 为界，并且`n`。 从第一个开始可以达到区间内的任何总和`k`数量和逐渐增加的元素来接近`x`不超过`n`。 该算法利用此属性而无需显式构造序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, k, x = map(int, input().split())
        min_sum = k * (k + 1) // 2
        max_sum = k * (2 * n - k + 1) // 2
        if x < min_sum or x > max_sum:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    main()
```该代码读取测试用例的数量，然后通过计算最小和最大总和来处理每个测试用例`k`元素。 比较检查是使用整数完成的，通过使用 Python 的任意精度算术来避免溢出。 这可以避免任何大的陷阱`x`值最大为 4*10^10。 边缘情况与`k = 1`或者`k = n`会自动处理，因为公式仍然会产生正确的最小和最大总和。

 ## 边缘情况

 对于`n = 1, k = 1, x = 1`,`min_sum`和`max_sum`两者都等于 1，因此算法正确输出“YES”。 为了`n = 1, k = 1, x = 2`,`x`超过`max_sum = 1`，所以输出“NO”。 为了`k = n`，总和自动检查是否`x`等于所有数字的总和。 大的`n`和`k`与大`x`由于 Python 整数而被正确处理。 这确保了所有边缘情况都得到统一处理。
