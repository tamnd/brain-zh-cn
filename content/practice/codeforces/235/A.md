 ## 解决方案
 ## 问题理解

 我们被要求选择三个不大于 _n_ 的正整数，以使它们的最小公倍数最大化。 整数不必不同，因此如果有助于实现更大的 LCM，我们可以重复数字。 输入是单个整数_n_，最大可达一百万。 输出是一个整数，即 [1,_n_] 范围内三个整数的最大可能 LCM。 

这里的关键是要理解，当数量很大并且尽可能互质时，LCM 增长最快。 如果三个最大的数字有共同因数，那么简单地将它们相乘可能会失败。 例如，如果 _n_ 是偶数，则采用 _n、n-1、n-2_ 通常有效，因为它们大多是互质的，但如果 _n_ 本身是偶数，则采用 _n_ 本身是偶数，则采用 _n_、n-1、n-3_ 可能会产生比 _n、n-1、n-2_ 更大的 LCM，因为 _n_ 和 _n-2_ 共享因子 2。 

这些限制意味着我们需要比尝试每个三元组更快的解决方案。 当 _n_ 达到 10^6 时，暴力检查所有 O(n3) 三元组将大约需要 10^18 次操作，这是不可行的。 即使 O(n²) 也大约是 10^12，仍然太大。 这排除了朴素枚举。 边缘情况包括非常小的_n_（例如1、2、3），其中我们可以选择的最大数字受到限制，并且我们需要正确处理重复的数字。 

## 方法

 蛮力方法是考虑每个 1 ≤ a, b, c ≤ n 的三元组 (a, b, c)，计算它们的 LCM，并跟踪最大值。 这是有效的，因为它保证我们考虑每一种可能的组合。 然而，对于 n = 10^6，我们将计算大约 10^18 个 LCM，这远远超出了实际计算。 

最佳方法利用两个观察结果。 首先，最大 LCM 几乎总是涉及该范围内的最大数字，因为 LCM 与互质数相乘，并且随着数字的大小而增长。 其次，只需要检查 n 周围的几个三元组 - 我们可以考虑数字 n、n-1、n-2、n-3 和 n-4，并从这个小集合中取出所有三元组。 这将组合数量减少到最多 10 个，这对于评估来说很简单。 

我们还需要小心处理小_n_。 对于 n ≤ 2，我们不能取三个不同的数字，因此我们重复选择数字。 对于 n = 1，唯一的选择是 (1, 1, 1)。 对于 n = 2，最佳三元组是 (2, 1, 1)。 当n≥3时，上述策略可靠。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 如果 n 为 1，则返回 1，因为唯一的三元组是 (1, 1, 1)。 如果 n 为 2，则返回 2，对应于三元组 (2, 1, 1)。 这些是明确的基本情况。 
2. 对于n ≥ 3，构建由五个最大整数组成的候选集：n、n-1、n-2、n-3 和n-4。 该集合很小但足以生成最大可能的 LCM。 
3. 枚举该候选集中三个数字的所有组合。 对于每个三元组，计算 LCM。 跟踪最大值。 
4. 返回找到的最大 LCM。 

这样做的原因是，与使用从 n 到 n-4 的数字相比，包含任何小于 n-4 的数字都无法产生更大的 LCM。 较小的数量会降低总体规模并增加共享因子，从而降低 LCM。 

## Python 解决方案```python
import sys
import math
from itertools import combinations
input = sys.stdin.readline

def lcm(a, b):
    return a * b // math.gcd(a, b)

def lcm3(a, b, c):
    return lcm(a, lcm(b, c))

def solve():
    n = int(input())
    if n == 1:
        print(1)
        return
    if n == 2:
        print(2)
        return
    candidates = [n, n-1, n-2, n-3, n-4]
    max_lcm = 0
    for a, b, c in combinations(candidates, 3):
        max_lcm = max(max_lcm, lcm3(a, b, c))
    print(max_lcm)

solve()
```代码定义了一个助手`lcm`对于两个数字，并且`lcm3`对于三个数字，链接`lcm`来电。 我们显式处理 n = 1 和 n = 2，然后构建较大 n 的候选集。 使用`itertools.combinations`，我们有效地检查所有三元组并保留最大值。 n-4 的选择确保我们涵盖所有潜在的高 LCM 三元组，包括 n 为偶数且跳过一个数字会增加互素性的情况。

 ## 边缘情况

 对于 n = 1，算法立即返回 1，因为唯一可能的三元组是 (1,1,1)。 对于 n = 2，候选集 [2,1,-1,...] 仅使用正数 2,1 并根据需要重复。 负数将被忽略。 对于 n ≥ 3，候选选择确保我们始终包含最大化 LCM 的数字，同时避免可能降低互素性的 2 或 3 的倍数。 例如，n = 8 导致候选 [8,7,6,5,4]，并且算法正确地从 (8,7,6) 找到最大 LCM 336。
