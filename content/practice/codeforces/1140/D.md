 ## 解决方案
 ## 问题理解

 给定一个正多边形`n`标记的顶点`1`通过`n`按逆时针顺序。 目标是将这个多边形划分为不重叠的三角形，以使所有三角形的“权重”之和最小化。 三角形的权重是其三个顶点标签的乘积。 输出是一个整数，是所有可能的三角剖分中可实现的最小总和。 

约束条件允许`n`最多 500 个。由于可能的三角剖分数量呈指数增长`n`，任何显式尝试所有三角剖分的算法都会太慢。 2 秒限制内的操作上限大致为`10^8`，这意味着暴力枚举所有三角剖分是完全不可行的。 我们需要一种系统的方法来避免重新计算重叠的子问题。 

对于已经是三角形的多边形，会出现微妙的边缘情况。 例如，`n = 3`产生一个带有权重的三角形`1 * 2 * 3 = 6`。 一个简单的实现假设`n > 3`并尝试进一步分区将产生索引错误或添加不必要的操作。 矩形或四边形出现另一种边缘情况（`n = 4`），其中对角线的选择会影响总和。 如果我们取一个有顶点的矩形`1,2,3,4`，沿对角线切割`1-3`给出总重量`1*2*3 + 1*3*4 = 6 + 12 = 18`，而对角线`2-4`给出`1*2*4 + 2*3*4 = 8 + 24 = 32`。 该算法必须系统地探索这些选项，而不是依赖启发式方法。 

## 方法

 暴力方法会尝试每一种可能的三角剖分，对每个三角形的顶点标签的乘积求和并选择最小值。 这在原则上是正确的，因为它明确地考虑了每个配置。 然而，三角剖分的数量`n`-gon 由下式给出`(n-2)`-th 加泰罗尼亚数，呈指数增长（`C_18 > 10^6`,`C_20 > 10^7`），所以即使`n = 20`已经太大而无法用简单的递归来处理。 

关键的见解是该问题表现出重叠的子问题和最优子结构。 多边形的任何三角剖分都可以看作是在两个不相邻的顶点之间选取一条对角线，将多边形分割成两个较小的子多边形，然后递归地对它们进行三角剖分。 这允许动态编程，我们计算每个连续顶点子序列的最小三角剖分权重。 每个三角形仅贡献一次权重，并且每个子多边形的最小值可以在递归调用中重复使用。 

这将时间复杂度降低到`O(n^3)`和空间复杂度`O(n^2)`。 为了`n = 500`,`n^3 = 125*10^6`操作，这完全符合 Python 解决方案的 2 秒限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(C_n) 指数 | O(1) | O(1) | 太慢了 |

 ## 算法演练

 1. 将多边形顶点表示为数组`[1, 2, ..., n]`。 定义DP表`dp[i][j]`存储由顶点形成的多边形的最小三角剖分权重`i`到`j`包容性，假设`i < j`。 
2. 初始化基本情况。 对于任何少于 3 个顶点的线段 (`i+1 >= j`),`dp[i][j] = 0`，因为一条线或单个顶点不能形成三角形。 
3. 迭代从 3 到 的所有子多边形长度`n`。 对于每个长度`l`，考虑所有起始索引`i`和`j = i + l - 1`。 这保证了我们考虑给定大小的每个连续多边形。 
4. 对于每个子多边形`i`到`j`,尝试每一个可能的顶点`k`严格之间`i`和`j`作为三角形的第三个顶点`(i, k, j)`。 DP 递推式为：```
dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j] + i*k*j)
```这里，`dp[i][k]`和`dp[k][j]`是由对角线创建的左右子多边形的最小三角剖分权重`(i, j)`。 
5、填写DP表后，答案为`dp[1][n]`，整个多边形的最小权重。 

为什么有效：每个三角剖分都可以表示为一系列带有对角线的三角形选择。 递归确保对于每个子多边形，我们考虑其末端的每个可能的三角形，并存储最小值。 不会遗漏任何配置，因为循环会迭代所有有效的配置`k`。 不变的是`dp[i][j]`始终包含顶点的最小三角剖分权重`i..j`一旦它被填满。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

# vertices are labeled 1..n
dp = [[0]*(n+1) for _ in range(n+1)]

# length of sub-polygon
for length in range(3, n+1):
    for i in range(1, n-length+2):
        j = i + length - 1
        dp[i][j] = float('inf')
        for k in range(i+1, j):
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j] + i*k*j)

print(dp[1][n])
```DP表`dp`被初始化为零。 嵌套循环通过增加子多边形大小来填充它，确保在计算时`dp[i][j]`, 条目`dp[i][k]`和`dp[k][j]`已经计算出来了。 我们使用`float('inf')`以确保适当的最小化。 产品`i*k*j`计算三角形权重。
