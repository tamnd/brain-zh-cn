 ## 解决方案
 ## 问题理解

 伊万的侦探书的结构是每一页都介绍一个谜团，而该谜团的解决方案将在后面的一页中揭晓。 具体来说，我们有一个整数列表，其中$i$第一个整数$a_i$告诉我们解决页面上介绍的谜团的页面$i$。 伊万每天从第一个未读的页面开始按顺序阅读，但他无法在“神秘链条”的中间停下来。 他不断地阅读，直到他遇到的每一个谜题都得到解答。 任务是确定他需要多少天才能完成这本书。 

输入足够小$n$可以达到$10^4$，所以算法可达$O(n)$或者$O(n \log n)$将在 2 秒的时间限制内舒适地运行。 完整地重复遍历这本书的二次算法可以达到$10^8$操作，这有超时的风险。 

边缘情况可能很微妙。 例如，如果所有谜团都在同一页上立即得到解释，则伊万每天读一页。 为了$n=5$和$a = [1,2,3,4,5]$，每天一个单页，产生5天。 假设 Ivan 每天总是阅读多页的粗心方法会在这里产生错误的答案。 另一个棘手的情况是最后一页解释了之前的所有谜团，例如，$a = [5,5,5,5,5]$; 伊万必须在一天内读完所有五页。 

## 方法

 蛮力方法明确地模拟了伊万的阅读。 从第 1 页开始，按顺序继续阅读，直到解决了遇到的每个谜团后才停止。 将每个停止点视为新的一天。 这种方法是正确的，因为它直接遵循阅读规则，但如果天真的实施并重复检查未解之谜，它的效率可能会很低。 最坏情况的复杂度可以达到$O(n^2)$当每个页面引用一个遥远的页面时，因为每天可能需要从未读页面的开头扫描以检查所有先前的谜团。 

最佳方法的关键观察是，每一天，伊万都会从第一个未读的页面开始阅读，直到当天任何谜题所需的最远的页面。 形式上，在按顺序迭代页面时，维护最远的页面$max_page$需要阅读该书才能解决迄今为止遇到的所有谜团。 当当前页面索引超过时Ivan停止$max_page$。 增加天数，然后从下一个未读页面继续。 这是有效的，因为停止条件恰好是当前连续段中的所有谜团都得到解决时。 这将算法简化为通过页面的单个线性传递，给出$O(n)$时间复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n^2) | O(n^2) | O(1) | O(1) | 对于大 n 来说太慢 |
 | 最大页面跟踪 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`days`到 0。这将计算 Ivan 有多少次阅读会话。 
2. 设置指针`i`0，代表当前未读页索引。 
3.同时`i < n`:

 1. 初始化`max_page`到`a[i] - 1`因为我们需要从零开始的索引。 
2. 初始化一个指针`j = i`跟踪当天的页面。 
3.同时`j <= max_page`:

 1. 更新`max_page = max(max_page, a[j] - 1)`。 这确保了伊万继续阅读，直到当天的所有谜团都得到解决。 
2. 增量`j`1.
 4. 增量`days`自从伊万完成一天的阅读以来，增加了 1。 
5. 移动`i`到`j`，下一个未读页。 
4. 打印`days`。 

为什么它有效：该算法保持了不变式`max_page`这始终是伊万必须阅读的最远的一页，以解决他迄今为止遇到的所有谜团。 通过扩展`max_page`每当后面的页面需要进一步阅读时，该算法都会确保在一天结束时不会留下任何未解之谜。 每个页面只被访问一次，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

days = 0
i = 0
while i < n:
    max_page = a[i] - 1
    j = i
    while j <= max_page:
        max_page = max(max_page, a[j] - 1)
        j += 1
    days += 1
    i = j

print(days)
```外循环提前了第二天的开始，而内循环则延伸到最远的未解之谜。 细微之处包括调整`a[i]`从零开始的索引和更新`max_page`增加之前`j`。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    days = 0
    i = 0
    while i < n:
        max_page = a[i] - 1
        j = i
        while j <= max_page:
            max_page = max(max_page, a[j] - 1)
            j += 1
        days += 1
        i = j
    return str(days)

# Provided sample
assert run("9\n1 3 3 6 7 6 8 8 9\n") == "4", "sample 1"

# Minimum input
assert run("1\n1\n") == "1", "single page"

# All explained immediately
assert run("5\n1 2 3 4 5\n") == "5", "all pages self-explained"

# All explained at the last page
assert run("5\n5 5 5 5 5\n") == "1", "all explained on last page"

# Sequential chunks
assert run("6\n2 2 4 4 6 6\n") == "3", "two-page chains"

 ## 边缘情况

 对于所有谜团都在同一页上解决的场景，算法正确地识别出阅读必须继续到该页。 和`a = [5,5,5,5,5]`,`i=0`,`j=0`， 和`max_page=4`。 内循环将 j 从 0 迭代到 4，在一天内读取所有页面。 不变量`j <= max_page`确保没有一天提前结束。 类似地，对于自我解释的页面，算法通过设置来处理单页日`max_page = a[i]-1`，所以这一天立即结束。 这些痕迹证实该算法正确处理两个极端情况。
