 ## 解决方案
 ## 问题理解

 给定一个正整数数组，我们可以选择一个正移位值$x$。 将每个元素移动相同的量后，我们希望每对结果数字都是互质的。 

等价地，我们将数组变换为$b_i = a_i + x$。 要求是对于任意两个不同的指数，两个移位值的公约数不大于 1。任务是确定是否至少存在一个这样的移位。 

重要的是我们没有被要求构建$x$，只是为了确定存在。 这通常表明条件可以简化为输入的结构属性，而不是对大整数进行搜索。 

约束表明$n \le 100$每次测试和值高达$10^{18}$。 这立即排除了任何迭代可能的方法$x$， 自从$x$大小不受限制。 它还表明推理必须依赖于原始数字之间的关系，而不是它们的绝对大小。 

天真的推理的一个微妙的失败案例是假设选择一个大的$x$总是使数字互质。 这是错误的，因为移位保留了差异：如果两个数字在移位后同时可以被某个素数整除，则该素数会创建一个禁止的 gcd。 另一个陷阱是只关注成对差异$a_i - a_j$直接，因为移位后的 gcd 结构在单独的差异下并不是不变的。 

## 方法

 关键的观察结果来自于以更结构化的方式重写 gcd 条件。 如果两个移位后的数共享一个素数$p$，那么两者$a_i + x$和$a_j + x$可以被整除$p$。 这意味着：$$a_i \equiv a_j \equiv -x \pmod p$$因此，移位后共享素数的所有数字必须落入相同的余数类模$p$。 

这将问题转化为控制哪些素数可以同时除以移位值。 而不是去思考$x$，我们考虑它如何迫使所有数字以潜在素数为模进入特定的同余类。 

一种有用的方法是将一个元素固定为参考并表达与其相关的所有内容。 让我们来挑选$a_1$。 如果我们想要$\gcd(a_1 + x, a_i + x) = 1$，那么任何质数都不能整除两者。 假设有一个素数$p$除两个移位值。 然后划分它们的差异：$$(a_i + x) - (a_1 + x) = a_i - a_1$$所以任何坏素数都必须除以一些差值$a_i - a_1$。 这是关键的减少：只有出现差异的素数才重要。 

现在结构简化了。 如果一个素数$p$划分任何差异，那么我们必须避免选择$x$这样所有的值都落在相同的残差类模中$p$。 保证成功的唯一方法是确保整个阵列中不会发生这种不可避免的对齐。 

预期解决方案中使用的决定性简化更加强大：如果数组包含重复项，则答案立即不可能。 如果$a_i = a_j$，那么对于任意$x$，我们得到$a_i + x = a_j + x$，所以它们的 gcd 就是数字本身，总是大于 1。这已经阻止了有效性。 

如果所有值都是不同的，我们总是可以构造一个$x$这避免了由素数除法差异引起的所有有限多个禁止同余。 自从$n$很小，这个构造论证保证存在而无需明确找到它。 

因此，条件分解为一个简单的检查：是否存在重复项。

 ## 算法演练

 1. 读取每个测试用例的数组，并检查是否有任何值出现多次。 此步骤直接测试唯一保证失败的障碍，无论$x$。 
2. 如果存在重复项，则立即断定不存在有效的移位，因为相同的值在移位后保持相同，从而强制执行非单位 gcd。 
3. 如果所有元素都不同，则得出结论，合适的$x$存在。 原因是，如果没有重复引起的强制 gcd，我们总是可以选择避免所有共享素数约束的转变。 

## 为什么它有效

 移位后唯一不可避免的 gcd 大于 1 的情况发生在两个移位后的值相同时，这恰好发生在原始值相同时。 任何其他 gcd 条件都取决于差异中素数的整除性，并且可以通过适当选择来避免这些条件$x$因为禁止残数的集合是有限的并且不覆盖所有整数。 因此，重复是唯一的障碍。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        if len(set(a)) < n:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```实施直接遵循特征描述。 唯一重要的步骤是使用一组来有效地检测重复项。 不需要算术操作，因为该理论将问题完全简化为唯一性。

 ## 边缘情况

 完全相等的数组，例如`[7, 7, 7]`是最强的失败案例。 任何轮班后$x$，所有值都变得相同，因此每一对的 gcd 都等于移位后的值。 该算法立即检测重复项并输出“否”，无需对值进行任何计算。 

近似重复的数组，例如`[1, 2, 1]`行为方式相同。 即使只有一个值重复，也足以引发矛盾，因为两个相同的移位值始终共享其全部值作为 gcd。 

一个完全不同的数组，例如`[1, 2, 3]`统一处理：集合大小等于$n$，因此算法输出 YES，无需推理实际的 gcd 计算。
