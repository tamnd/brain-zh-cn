 ## 解决方案
 ## 问题理解

 我们正在查看范围内的所有整数$N$到$M$。 对于每个整数$x$在这个范围内，我们将其“变异性”定义为分裂的方式数量$x$相同的物品放入相同卡车的车队中，以便每辆卡车携带相同数量的物品，并且所有物品都被使用。 

有效的车队仅取决于使用的卡车数量。 如果我们选择$k$卡车，那么每辆卡车必须准确运载$x/k$项，所以这只有在以下情况下才有可能$k$划分$x$。 因此，可变性为$x$正好是正因数的个数$x$，通常表示为$d(x)$。 

任务是计算总和$$\sum_{x=N}^{M} d(x)$$在哪里$N, M$可以大到$10^{12}$，因此迭代每个数字是不可能的。 

该约束意味着任何依赖于间隔中每个整数处理的算法在最坏的情况下都会立即太慢，因为间隔长度本身可以达到$10^{12}$。 甚至$O(\sqrt{x})$每个数字是不可行的。 

一个关键的边缘情况是当$N = M$，我们必须计算单个潜在大数的除数计数。 另一个是当$N = 1$，因为每个整数至少贡献一个除数，并且累积增长很快。 

一种循环所有的天真的方法$x$并计算除数$\sqrt{x}$会执行大约$$O((M-N+1)\sqrt{M})$$操作，远远超出了限制。 

## 方法

 蛮力的想法很简单：对于每个数字$x$在范围内，通过检查所有候选者来计算有多少个整数可以整除它$\sqrt{x}$。 这是正确的，因为每个除数对都出现在该范围内。 然而，这会失败，因为范围大小是无界的并且可以达到$10^{12}$，甚至使得迭代数字变得不可能。 

我们需要不同的视角。 而不是修复$x$计算它的除数，我们扭转观点：固定一个潜在的除数$d$，并计算其中有多少个数字$[N, M]$可以被整除$d$。 每次$d$除一个数$x$，它恰好贡献了 1$d(x)$。 所以每一对$(x, d)$和$d \mid x$对最终答案贡献一次。 

交换总和：$$\sum_{x=N}^{M} d(x) = \sum_{d \ge 1} \#\{x \in [N,M] : d \mid x\}$$现在，使用楼层除法可以轻松计算内部项：$$\# = \left\lfloor \frac{M}{d} \right\rfloor - \left\lfloor \frac{N-1}{d} \right\rfloor$$唯一剩下的问题是对所有的求和$d$最多$M$还是太大了。 关键的观察结果是商函数$\lfloor M/d \rfloor$在区间内是分段常数$d$。 我们不是逐一迭代，而是跳过商保持固定的范围。 这减少了不同值的数量$\lfloor M/d \rfloor$到关于$O(\sqrt{M})$，类似地对于$\lfloor (N-1)/d \rfloor$。 

我们处理这些范围并在区块中累积贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O((M-N+1)\sqrt{M})$|$O(1)$| 太慢了|
 | 除数重新索引 + 谐波跳跃 |$O(\sqrt{M})$|$O(1)$| 已接受 |

 ## 算法演练

 我们通过扫描分组间隔中的除数值来计算总和，其中楼层除法结果保持不变。 

1. 将答案初始化为 0。我们将累加所有可能除数的贡献。 
2. 设置指针$d = 1$。 这代表我们正在评估的当前除数。 
3.同时$d \le M$，计算值$$a = \left\lfloor \frac{M}{d} \right\rfloor, \quad b = \left\lfloor \frac{N-1}{d} \right\rfloor$$这些代表了多少倍$d$位于$[1,M]$和$[1,N-1]$。 
4. 对此的贡献$d$是$a - b$。 将其添加到答案中。 计算范围内有多少个数字可以被整除$d$。 
5. 确定最大范围$d$为此，两者$a$和$b$保持不变。 这是通过计算下一个断点来完成的：$$d' = \min\left(\frac{M}{a}, \frac{N-1}{b} \text{ (if } b > 0)\right)$$我们可以安全地从$d$到$d'$因为所有中间除数在贡献结构中的行为都是相同的。 
6. 设置$d = d' + 1$并重复。 

每次跳转都会跳过贡献相同的除数值的整个区间，从而避免线性迭代。 

### 为什么它有效

 每次出现除数关系$(d \mid x)$处理除数时只计算一次$d$。 按恒定下限值进行分组可确保在该范围内产生相同乘法结构的所有除数都聚集在一起，而不会遗漏或重复。 分解将二维计数问题转换为对除数贡献的一维扫描。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    
    def count_leq(x, d):
        return x // d

    ans = 0
    d = 1

    while d <= M:
        q1 = M // d
        q2 = (N - 1) // d

        # find next d where M//d or (N-1)//d changes
        if q1 == 0:
            r1 = M
        else:
            r1 = M // q1

        if q2 == 0:
            r2 = M
        else:
            r2 = (N - 1) // q2 if N > 1 else M

        nd = min(r1, r2)

        ans += (q1 - q2) * (nd - d + 1)

        d = nd + 1

    print(ans)

if __name__ == "__main__":
    solve()
```该实现维护运行除数索引并压缩商值恒定的范围。 关键细节是计算两者的下一个断点$M // d$和$(N-1) // d$，确保我们不会错过贡献行为的转变。 

必须小心$N = 1$， 在哪里$N-1 = 0$，因为楼层划分的行为不同； 代码通过保护第二个断点来隐式处理这个问题。

 ## 边缘情况

 当$N = 1$， 期限$(N-1)$变为零，因此每个除数都有贡献$\lfloor M/d \rfloor$。 该算法处理这个问题是因为整数除以任何$d$第二项给出零，因此贡献可以正确地减少到计算倍数$[1, M]$。 

什么时候$N = M$，循环有效地计算单个数字的除数函数。 该算法不依赖于范围长度，并且仍然仅处理大约$\sqrt{N}$除数块，正确地求和所有贡献。 

什么时候$M$非常大但除数很少，该算法仍然执行高效，因为它迭代除数块而不是数字，并且楼层除法的结构确保不会错过贡献。
