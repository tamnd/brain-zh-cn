 ## 解决方案
 ## 问题理解

 我们得到一个连通结构$N$标记节点，其中输入中的每一对描述两个节点之间的无向链接。 该结构保证是一棵树，因此它恰好具有$N-1$边缘且无循环。 

鲍勃想把这棵树变成一条简单的直链。 直链是一种节点形成单一简单路径的配置：恰好两个节点有一个邻居，而每个其他节点恰好有两个邻居。 最终的结构也必须保持连接并且不能分支。 

允许的操作是以所选节点为中心的本地重新布线步骤$A$。 如果$A$当前已连接到某个邻居$B$, Bob 可以分离边缘$A-B$并连接$A$到另一个节点$C$。 所有其他连接$A$保持不变，边缘$B$失去与$A$尽管$C$获得新的连接$A$。 

目标是找到将给定树转换为同一节点集上的任何简单路径所需的此类重新布线操作的最少数量。 

约束条件$N \le 3 \cdot 10^5$意味着我们需要一个$O(N)$或者$O(N \log N)$解决方案。 任何尝试模拟转换或搜索可能路径的方法都会失败，因为即使是单个操作序列也可以以多种方式分支，并且可能的目标路径的数量是以下因素的阶乘：$N$。 

当树已经是一条路径时，就会出现关键的边缘情况。 例如，如果输入形成一个像这样的链$1 - 2 - 3 - 4$，无需任何操作，答案为零。 如果尝试“本地固定度数”的幼稚方法没有认识到所有节点都已经满足路径的度数约束，则它仍然可能执行不必要的移动。 

另一个重要的场景是星形树。 例如，节点$1$与所有其他人相连。 在这里，“只修复叶子”的贪婪直觉失败了，因为将高度中心转换为 2 度需要重新分配多个边缘，并且每次移动仅移动一个连接。 

## 方法

 强力解释将尝试重复模拟所有可能的重新布线操作，并检查图形何时成为路径。 即使我们贪婪地选择高度高的节点并尝试减少分支，每个状态都有很多可能的选择$A$,$B$， 和$C$。 这在边缘重新连线序列上创建了指数搜索空间，使其不可行$N = 3 \cdot 10^5$。 

关键的观察是我们实际上不需要明确地跟踪结构变化。 目标结构受到极大限制：每个节点最终的度数最多为 2，度数之和固定为$2(N-1)$。 这意味着初始树中度数大于 2 的任何节点都必须“摆脱”其额外的度数，直到达到 2。 

现在考虑单个操作的作用。 我们占据优势$A-B$并将其移至$A-C$。 节点$A$保持其度数不变，但节点$B$失去一级和节点$C$获得一个学位。 这意味着每个操作都会将一个度数单位从一个节点传输到另一个节点。 

这将问题重新定义为平衡多余的度数。 每个度数大于 2 的节点的盈余等于$\deg(v) - 2$。 每个操作都可以从某个度数至少为 3 的节点中恰好删除一个单位的剩余，前提是我们将边附加到不会创建新剩余的节点。 因为我们总是可以选择$C$在此过程中，度数小于 2 的节点中，每次操作都可以安全地将总剩余减少 1。 

因此，最小操作数恰好是所有节点的初始剩余总和。

 | ---| ---| ---| ---|
 | 暴力模拟| 指数| O(N) | 太慢了|
 | 学位剩余计数| O(N) | O(N) | 已接受 |

 ## 算法演练

 我们计算初始树中每个节点的度数，并对每个节点超出目标度数 2 的程度进行求和。 

1. 读取树并构建邻接表以计算每个节点的度。 这给出了每个节点当前拥有的邻居的确切数量。 
2. 将答案变量初始化为零。 这将累积必要的重新布线操作的总数。 
3. 对于每个节点$v$，计算其盈余为$\max(0, \deg(v) - 2)$。 将这个盈余添加到答案中。 这表示必须从该节点“移开”多少条边。 
4. 输出累加和作为最终答案。 

此过程背后的原因是，每个剩余单位对应于一个连接，必须将其重新定位到远离具有太多关联边的节点。 由于每个操作恰好将一个连接从高度节点移动到另一个节点，因此每一单位剩余都需要一次操作。 

### 为什么它有效

 树以固定的总度数开始，最终配置是一条路径，其中所有内部节点的度数为 2，端点的度数为 1。任何高于 2 度的节点都必须精确丢失其多余的边。 每个操作都会将一个节点的度数减少 1，同时将另一个节点的度数增加 1，因此，只要我们避免在目的地创建新的多余度数，每个操作中所有节点的多余度数总数就会正好减少 1。 因为在最优序列期间总是有足够的度数小于 2 的节点来吸收传入边，所以总的初始剩余既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    deg = [0] * (n + 1)

    for _ in range(n - 1):
        a, b = map(int, input().split())
        deg[a] += 1
        deg[b] += 1

    ans = 0
    for i in range(1, n + 1):
        if deg[i] > 2:
            ans += deg[i] - 2

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案完全由学位会计驱动。 邻接表仅用于计算度数； 之后不需要结构操作。 减 2 反映了这样一个事实：有效路径恰好允许两个度数为 1 的端点以及度数为 2 的所有其他节点，因此只有超出 2 的部分才会出现问题。 

一个微妙的点是，度数为 1 的节点已经与路径端点兼容，并且不应该对答案做出贡献。 度数恰好为 2 的节点已经与内部路径位置兼容。 仅超过 2 度的节点强制操作。

 ## 边缘情况

 单节点输入没有边，因此每个节点都满足路径条件。 该算法计算零度并产生零剩余，这与没有任何操作是有意义或不需要的事实相匹配。 

纯粹的路径，例如$1 - 2 - 3 - 4$将度 2 分配给内部节点，度 1 分配给端点，从而在各处产生零剩余。 该算法正确地不执行任何操作，因为没有节点超过度数 2。 

星形图揭示了主要的转换负担。 中心节点有度$N-1$，所以它的盈余是$N-3$。 该算法准确地输出这个数字，反映出中心的每个额外边缘必须在单独的操作中移走，并且没有任何操作可以一次删除多个这样的多余边缘。
