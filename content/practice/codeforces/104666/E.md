 ## 解决方案
 ## 问题理解

 我们在平面上有一个直墩，由穿过原点和第二个点的线定义$(A, B)$。 我们可以选择这条无限线上的任意点作为烧烤架的位置。 在该选定点周围，有固定半径的圆形烟雾云$R$出现。 每艘船都是平面上的一个固定点，如果一艘船位于该圆内或该圆上，则该船被视为“警报”。 

任务是在码头上选择一个点，使圆圈覆盖的船只数量最大化。 

从几何角度来看，这是一个受约束的中心选择问题：我们不能随意将圆放置在平面上的任何位置，只能沿着一条固定的线放置，并且我们希望该线上的位置能够最大化距离内的点数$R$。 

约束条件很大，最多可达$3 \cdot 10^5$船。 任何重新计算每个可能的码头位置的距离或尝试直接离散化候选中心的方法都会失败。 即使是天真的$O(N^2)$扫过双船的速度太慢了。 

一个更微妙的问题是数值稳定性。 码头由任意坐标定义，船只可以位于较大坐标范围内的任何位置。 依赖重复几何计算的解决方案必须避免在比较距离和间隔端点时出现精度漂移。 

当船只远离码头时，就会出现边缘情况。 例如，如果所有船都比$R$从线本身来看，无论我们将圆心放在码头的什么位置，都无法覆盖任何船只，答案为零。 不过滤这些情况的粗心实现仍然可能会生成无效间隔并产生不正确的重叠。 

另一个边缘情况是当船正好处于一定距离时$R$从移动中心到线上的单个简并位置。 这些情况产生的间隔会折叠到一个点，并且错误地将它们视为空间隔将丢失有效答案。 

## 方法

 蛮力的想法是在码头上选择一个候选点并计算有多少艘船落在距离内$R$。 如果我们沿线采样许多点，或者尝试将所有船只投影到线上作为候选中心，我们可以通过直接距离检查来计算答案。 从概念上讲，这是可行的，因为最佳圆心必须位于被覆盖的船组发生变化的“关键”位置，通常与涉及以船为中心的圆边界的几何事件对齐。 

然而，这种方法太慢了。 如果我们尝试每对船来生成候选转换，我们会得到$O(N^2)$候选人。 即使评估单个候选人的成本$O(N)$，导致$O(N^3)$在最坏的情况下。 甚至将评估降低到$O(1)$使用预处理并不能解决候选位置的爆炸问题。 

关键的观察是我们可以扭转观点。 我们不是选择一个中心并检查它覆盖哪些船，而是固定一艘船并询问：这艘船将覆盖码头上中心的哪些位置？ 

修一艘船$P$。 中心$C$必须满足$|C - P| \le R$。 自从$C$被约束在一条线上，此条件成为沿该线的单个参数的区间约束。 每艘船都会贡献一段有效的中心位置。 最终的答案是重叠间隔的最大数量。 

因此，将所有船只投影到码头线上并将每个圆收缩为沿该线的区间后，几何问题就简化为一维区间重叠问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力采样/对生成|$O(N^2)$到$O(N^3)$|$O(N)$| 太慢了|
 | 间隔投影+扫线 |$O(N \log N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们将 2D 几何图形转换为与桥墩对齐的 1D 坐标系。 

### 1.沿桥墩建立坐标系

 我们将码头视为一条穿过的无限线$(0,0)$和$(A,B)$。 我们定义一个方向向量$d = (A,B)$并将其归一化为单位向量$u$。 这让我们可以用单个标量参数来表示码头上的任何点$t$，其中位置是$P(t) = (0,0) + t \cdot u$。 

执行此步骤的原因是所有有效的烧烤位置都位于这条线上，因此将问题简化为单个参数会删除一个几何自由度。 

### 2. 预先计算每艘船的垂直距离和投影

 对于每艘船$X_i = (x_i, y_i)$，我们计算它在直线上的投影以及它到直线的垂直距离。 

垂直距离决定了船是否可以被覆盖。 如果这个距离超过$R$，那么以该线为中心的圆都无法到达它。 

如果船可以到达，我们还计算它的投影坐标$t_i$沿线。 

### 3.将每条船转换为线上的一个区间

 对于固定中心位置$t$，到船的距离分解为垂直和平行分量。 垂直分量是固定的。 沿线剩余的允许半径变为：$$\Delta_i = \sqrt{R^2 - d_{\perp}^2}$$所以中心必须满足：$$t \in [t_i - \Delta_i,\; t_i + \Delta_i]$$每条船都成为实线上的一个区间。 

这是关键的转换：2D 圆形约束变为 1D 线段约束。 

### 4. 扫过所有区间的线

 我们收集所有区间端点。 每个起点都会为覆盖范围增加+1，每个终点都会减去-1。 对端点进行排序和扫描可在任何点产生最大重叠。 

我们注意对端点进行一致的处理，以便包含正好位于边界上的船。 

### 为什么它有效

 该算法依赖于这样一个事实：桥墩上的每个有效中心位置恰好对应于实线参数上的一个点$t$，每条船精确定义了一组$t$它所涵盖的值。 因此，覆盖范围是随时间间隔累加的，并且最大化覆盖的船只数量相当于找到具有最大间隔重叠的点。 投影后船只之间不再存在几何相互作用，因此不存在可能使减少无效的隐藏依赖性。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    N, R, A, B = map(int, input().split())

    # direction vector of pier
    dx, dy = A, B
    norm = math.hypot(dx, dy)
    ux, uy = dx / norm, dy / norm

    events = []

    for _ in range(N):
        x, y = map(int, input().split())

        # projection coordinate onto pier
        tx = x
        ty = y

        t = tx * ux + ty * uy  # dot product gives projection

        # perpendicular distance via cross product magnitude
        cross = abs(tx * dy - ty * dx) / norm

        if cross > R:
            continue

        span = math.sqrt(R * R - cross * cross)

        l = t - span
        r = t + span

        events.append((l, 1))
        events.append((r, -1))

    events.sort()

    cur = 0
    best = 0

    for _, v in events:
        cur += v
        best = max(best, cur)

    print(best)

if __name__ == "__main__":
    solve()
```该实现首先使用归一化方向向量沿着码头构建正交基。 然后使用点积将每艘船沿该方向映射到标量坐标。 垂直距离是使用叉积除以线范数来计算的，这避免了显式构造旋转坐标系。 

每艘船仅在几何可达的情况下才贡献一个间隔，这意味着垂直距离不超过半径。 否则它会被安全地忽略。 

扫描线使用排序的端点，其中左端点增加活动计数，右端点减少活动计数。 这次扫描期间的最大前缀和对应于烧烤的最佳位置。 

一个微妙的实现细节是浮点稳定性。 使用`math.hypot`一致的归一化避免了较大的相对误差$A, B$很大。 关于容差的声明保证允许标准双精度，无需额外的 epsilon 处理。

 ## 边缘情况

 如果所有船只都远离码头线，则每个垂直距离超过$R$，并且该算法不生成间隔。 然后，扫描不会看到任何事件并返回零，这与线上的任何位置都无法到达任何船只的事实相匹配。 

当一艘船正好停在远处时$R$从直线上看，它的区间收缩为一个点。 在扫描线中，这显示为同一坐标处的起点和终点，从而有助于在该精确中心位置正确重叠，而无需特殊处理。 

当多艘船共享相同的投影坐标但不同的垂直距离时，它们的间隔在同一区域周围严重重叠。 扫描正确地累积了所有贡献，因为每个间隔在投影后都是独立的。
