 ## 解决方案
 ## 问题理解

 我们得到一个整数`n`并要求评估交替总和$$-1 + 2 - 3 + 4 - 5 + \dots + (-1)^n n.$$每一项的符号取决于它的位置。 奇数被减去，偶数被添加。 输出是该总和的最终值。 

约束是问题的关键部分。 的价值`n`可以大到$10^{15}$。 迭代的直接模拟`1`到`n`需要多达一万亿次迭代，这在一秒的时间限制内是完全不可能的。 甚至$10^8$运算已经太多了，所以我们需要一个数学公式来在常数时间内计算答案。 

一个常见的错误是奇偶性处理不当`n`。 

考虑：

 输入：```
1
```总和很简单`-1`，所以正确的输出是：```
-1
```假设每一对都做出贡献的粗心实现`1`并返回`n/2`会错误地产生`0`。 

另一个边缘情况出现时`n`很奇怪。 

输入：```
5
```总和是：$$-1 + 2 - 3 + 4 - 5 = -3.$$正确的输出是：```
-3
```如果我们使用偶数公式`n`如果不单独处理奇数，我们会错误地返回`2`。 

最大允许值也值得关注。 

输入：```
1000000000000000
```答案是：```
500000000000000
```具有固定大小整数类型的语言在这种规模的某些问题中可能会溢出。 Python 整数会自动扩展，因此不需要特殊处理。 

## 方法

 最直接的解决方案是完全按照书面形式计算总和。 我们从零开始，迭代从`1`到`n`，减去奇数，加上偶数，然后打印结果。 

这种方法是正确的，因为它逐项遵循定义。 问题是它的运行时间。 什么时候`n = 10^{15}`，该算法将执行大约一万亿次迭代。 这样的计划永远不会在期限内完成。 

表达式的结构给了我们一个更好的想法。 查看连续的对：$$(-1 + 2) = 1$$

$$(-3 + 4) = 1$$

$$(-5 + 6) = 1$$每个完整的奇偶对都准确贡献`1`。 

什么时候`n`是偶数，所有数字都分成对。 有`n/2`成对出现，所以答案很简单：$$\frac{n}{2}.$$什么时候`n`很奇怪，第一个`n-1`数字形式`(n-1)/2`完整对，贡献：$$\frac{n-1}{2}.$$最后剩余的期限是`-n`， 所以：$$\frac{n-1}{2} - n = -\frac{n+1}{2}.$$这给出了恒定时间的解决方案。

 ## 算法演练

 1.读取整数`n`。 
2. 检查是否`n`是均匀的。 
3.如果`n`为偶数，输出`n // 2`。 

每个奇偶对都贡献精确`1`，并且有`n/2`这样的对。 
4.否则，输出`-(n + 1) // 2`。 

第一个`n-1`数字形成完整的对，最终的未配对项是`-n`。 

### 为什么它有效

 对于每个奇数`k`, 连续项`-k`和`k+1`贡献：$$-k + (k+1) = 1.$$什么时候`n`是偶数，整个序列恰好由`n/2`这样的对，总共给出`n/2`。 

什么时候`n`很奇怪，第一个`n-1`条款形式`(n-1)/2`其贡献为的对`(n-1)/2`。 剩余期限为`-n`，生产$$\frac{n-1}{2} - n = -\frac{n+1}{2}.$$这些公式与原始总和完全匹配，因此算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 0:
    print(n // 2)
else:
    print(-(n + 1) // 2)
```该程序从阅读开始`n`。 

奇偶性为`n`完全决定了答案。 对于偶数值，每个数字都属于一个完整的对，并且每个对都有贡献`1`，所以我们打印`n // 2`。 

对于奇数值，一个负项在最后仍然不成对。 封闭式结果为`-(n + 1) // 2`。 

该实现仅使用整数算术。 Python 的任意精度整数可以安全地处理高达或更高的值$10^{15}$。

 ## 边缘情况

 考虑尽可能最小的输入：```
1
```该算法检测到`n`是奇数并计算：$$-\frac{1+1}{2} = -1.$$输出是：```
-1
```这与原始总和相匹配，其中仅包含一项。 

现在考虑一个奇值，其中一项仍然不成对：```
5
```该算法计算：$$-\frac{5+1}{2} = -3.$$实际总和是：$$-1+2-3+4-5=-3.$$结果完全匹配。 

最后，考虑最大奇数输入：```
999999999999999
```该算法计算：$$-\frac{999999999999999+1}{2} = -500000000000000.$$不执行迭代，因此运行时间保持恒定。 Python 的整数算术可以安全地处理该值，立即生成正确的答案。
