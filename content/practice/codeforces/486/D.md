 ## 解决方案
 ## 问题理解

 我们有一棵树，其中每个顶点都有一个整数值。 如果一组顶点非空，形成树的连通子图，并且集合内的最大和最小值之差不超过，则视为有效。`d`。 

任务是计算存在多少个这样的连接顶点集。 

该树最多包含 2000 个顶点，每个值最多为 2000 个。2000 个顶点的限制足够小，因此`O(n²)`或者`O(n² log n)`解决方案是现实的，但顶点数量呈指数增长是不可能的。 由于具有 2000 个顶点的树有 1999 个边，因此从每个顶点运行 DFS 是完全可行的。 

困难的部分是避免重复计算。 连接集可能包含许多具有相同最小值的顶点。 如果我们简单地枚举满足值限制的连通子集，则可以多次发现同一集合。 

考虑一个小例子：```
d = 0

1 -- 2
values: [5, 5]
```有效的集合是`{1}`,`{2}`， 和`{1,2}`。 

如果我们尝试计算以每个最小值顶点为根的连通子集，那么`{1,2}`将从顶点 1 开始计数一次，然后从顶点 2 开始再计数一次。 

当较大的连通分量内存在多个相等的最小值时，会出现另一种微妙的情况：```
1 -- 2 -- 3
values: [1, 1, 2]
d = 1
```套装`{1,2,3}`是有效的。 任何未建立唯一代表性最小顶点的计数方案都会对该集合进行多次计数。 

第三种边缘情况是`d = 0`。 那么每个有效的集合必须完全由具有相同值的顶点组成。 该算法必须自然地减少对连接的单色子集的计数。 

## 方法

 暴力解决方案将枚举顶点的每个子集，检查它是否连接，并验证最大值减去最小值是否最多`d`。 

有`2^n`子集。 即使是为了`n = 40`，这已经太大了，而实际限制是2000。暴力破解的方法是完全行不通的。 

树结构提出了不同的视角。 假设我们选择一个顶点，而不是直接枚举子集`r`它将作为集合的最小值顶点。 

任何有效的集合都计入`r`必须满足两个条件。 

首先，集合中的每个顶点的值必须介于`a[r]`和`a[r] + d`。 

其次，在具有精确值的顶点之间`a[r]`，我们需要一个打破平局的规则，以便每个有效组只计算一次。 

树上的一种非常常见的技术是计算包含可区分根的连通子图。 一旦根被固定，树DP就可以计算包含该根的所有连接的子集。 

对于选定的根`r`，让我们只允许其值位于区间内的顶点```
[a[r], a[r] + d]
```并且另外禁止任何顶点```
a[v] = a[r] and v < r.
```这个打破平局的规则使得`r`所有具有最小值的顶点中索引最小的顶点。 

现在每个有效集合都只有一个代表根：

 如果有效集合具有最小值`m`，查看集合内其值等于的所有顶点`m`。 让`r`是其中最小的索引。 处理时会计算该集合`r`，并且由于平局限制，对于所有其他最小值顶点，它将被拒绝。 

一旦允许的顶点被固定，我们需要计算包含以下内容的连接子集：`r`在允许顶点的诱导树内部。 

这是一个标准的树DP。 对于每个顶点`u`， 定义`dp[u]`作为 DFS 子树内连接子集的数量`u`包含`u`。 

为了每个孩子`v`，我们可以：

 1. 不要从孩子身边拿走任何东西。 
2. 附加由以下计数的任何连接子集`dp[v]`。 

因此，孩子的贡献是`(dp[v] + 1)`， 和```
dp[u] = ∏ (dp[v] + 1).
```root 贡献的答案`r`是`dp[r]`。 

对每个顶点重复此 DFS 即可给出最终答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 最佳| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 读取树和值。 
2. 迭代每个顶点`r`并将其视为有效集合的可区分最小顶点。 
3. 加工时`r`, 一个顶点`v`如果满足以下条件，则允许：

 -`a[v] >= a[r]`-`a[v] <= a[r] + d`- 如果`a[v] == a[r]`， 然后`v >= r`最后一个条件是平局规则。 
4. 从以下位置开始运行 DFS`r`。 
5. 对于每个访问过的顶点`u`，计算包含的连接子集的数量`u`并完全位于 DFS 子树内。 
6. 对于每个允许的儿童`v`，递归计算`dp[v]`。 
7. 组合子项时，要么忽略该分支，要么附加由 计数的连接子集之一`dp[v]`。 将当前结果乘以`(dp[v] + 1)`。 
8. 将所得产品存储为`dp[u]`。 
9. DFS完成后，添加`dp[r]`到全球的答案。 
10. 对所有根重复并输出模数之和`10^9 + 7`。 

### 为什么它有效

 修复任何有效的连接集`S`。 

让`m`为其最小值。 的顶点之间`S`有价值`m`，选择最小的索引`r`。 

处理根时`r`，每个顶点`S`满足```
m ≤ a[v] ≤ m + d,
```并且没有值的顶点`m`索引小于`r`。 因此每个顶点`S`是允许的。 

自从`S`已连接并包含`r`，DFS DP 仅有一种构造方法。 

现在考虑任何其他根`x`。 

如果`a[x] > m`， 然后`x`不能是最小值`S`。 

如果`a[x] = m`和`x > r`， 然后`r`处理时被平局打破规则禁止`x`， 所以`S`无法形成。 

因此，每个有效集合都只计数一次，并且每个计数的集合都是有效的。 这确定了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

d, n = map(int, input().split())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

sys.setrecursionlimit(10000)

answer = 0

for root in range(n):
    base = a[root]

    def dfs(u, parent):
        res = 1

        for v in g[u]:
            if v == parent:
                continue

            if a[v] < base or a[v] > base + d:
                continue

            if a[v] == base and v < root:
                continue

            res = (res * (dfs(v, u) + 1)) % MOD

        return res

    answer = (answer + dfs(root, -1)) % MOD

print(answer)
```外循环选择代表性的最小顶点。 变量`base`存储它的价值。 

DFS只遍历满足值区间约束的顶点。 与根具有相同值但索引较小的顶点也被排除。 这是防止重复计数的关键决胜条件。 

返回值`dfs(u, parent)`是包含的连通子集的数量`u`并仅使用下面 DFS 子树中的顶点`u`。 

对于每个孩子来说，只有两种选择。 要么我们忽略整个分支，贡献`1`，或者我们连接包含子项的有效连接子集之一，贡献`dp[child]`。 将这些选择乘以孩子们的数量就得到了总数。 

由于每个乘法都是模数执行的`10^9 + 7`，避免溢出。

 ## 边缘情况

 考虑：```
0 2
5 5
1 2
```有效的集合是：```
{1}
{2}
{1,2}
```当root时`1`已处理，两个顶点都被允许并且`{1,2}`被计算在内。 

当root时`2`已处理，顶点`1`被排除是因为它具有相同的值和较小的索引。 套装`{1,2}`无法再次出现。 最终答案是正确的`3`。 

考虑：```
0 2
1 2
1 2
```唯一有效的集合是`{1}`和`{2}`因为里面的价值差异`{1,2}`等于`1`，这超过了`d=0`。 

对于根`1`, 顶点`2`位于允许的区间之外`[1,1]`。 

对于根`2`, 顶点`1`位于允许的区间之外`[2,2]`。 

每个 DFS 恰好贡献一个单例集，产生答案`2`。 

考虑：```
1 3
1 2 2
1 2
2 3
```有效的连接集是：```
{1}
{2}
{3}
{1,2}
{2,3}
{1,2,3}
```区间限制允许所有顶点为根时`1`被选中。 DP 正确生成包含该根的每个连接集。 根源`2`和`3`仅贡献最小值为的集合`2`。 每个有效集合都只出现一次，因为代表性最小顶点是唯一的。
