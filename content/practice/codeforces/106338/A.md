 ## 问题理解

 我们给出一个由具有尺寸的单位立方体组成的长方体块$a \times b \times c$。 该块内的每个单位立方体都有一些暴露在外表面上的面，具体取决于它所在的位置：角、边缘、面或完全内部。 任务是计算在绘制整个块的外部后总共绘制了多少个单位立方体面。 

输入由三个维度组成，输出是一个整数，描述所有单位立方体上绘制的面的总数。 每个立方体贡献的涂漆面数量等于其位于块外表面上的边数。 

问题的结构完全是几何的，但计算简化为仔细计算有多少个立方体属于每个类别：角、边、面和内部。 

约束足够小，以至于$O(1)$预计公式。 任何迭代所有立方体的方法都会缩放为$O(abc)$，一旦任何维数超过几千，这就变得不可行。 即使在$100 \times 100 \times 100$，这已经是一百万个立方体，对于更大的隐藏测试它会失败。 

主要困难不是计算而是组合。 面临的挑战是在不重复计算的情况下正确分类所有立方体，并处理一个或多个维度等于 1 的退化情况。这些情况完全改变了几何形状，将面折叠成线或单个点，以及假设完整 3D 结构的简单公式将被破坏。 

一个常见的错误是使用标准$2(ab + bc + ca)$直接表面积公式，它可以正确计算面数，但在块实际上是 2D 或 1D 的退化情况下，与问题的每立方体面计数解释不匹配。 

## 方法

 暴力方法显式构建块并检查每个立方体。 对于位置处的每个立方体$(i, j, k)$，我们计算它的六个面中有多少个位于边界上。 如果$i$是 1 或$a$， 或者$j$是 1 或$b$， 或者$k$是 1 或$c$，那么每个这样的条件都会贡献一张彩绘脸。 对所有立方体求和直接给出答案。 这是正确的，因为它完全遵循定义，但它要求$abc$迭代，一旦维度变得适度大，迭代就会变得太慢。 

关键的观察是立方体可以通过结构对称性进行分组。 我们没有迭代所有立方体，而是将它们分为少量类型：角、边、面内部立方体和完全内部立方体。 每种类型贡献固定数量的绘制面，我们只需要计算属于每种类型的立方体数量即可。 

当一个或多个维度等于 1 时，情况就会变得复杂。在这种情况下，通常的 3D 结构会折叠成矩形或线段，分类也会发生变化。 通常是边立方体的立方体在简并几何中可能会变成角立方体。 这迫使我们根据有多少维等于 1 来分别处理情况。 

一旦我们根据单位维度的数量划分情况，计数就变成了纯粹的算术。 每个配置都有一个固定的立方体类别分解，总的绘制面是一个加权和。

 ## 算法演练

 我们通过根据有多少维等于 1 将几何体分成不同的情况来解决这个问题，因为每种情况都会改变立方体之间的邻接结构。 

首先，我们检查三个维度是否都为 1。在这种情况下，只有一个立方体，并且所有六个面都暴露出来。 答案很简单，就是6。 

接下来，我们考虑两个维度恰好为 1 的情况。该结构折叠成单行立方体。 只有两个端点的行为与内部立方体不同。 每个端点立方体都有 5 个暴露面，因为它只缺少沿线方向的两个面，而所有其他立方体都有 4 个暴露面。 总数是通过分别对端点贡献和内部贡献求和来计算的。 

然后我们处理一维恰好为 1 的情况。该块变成立方体的扁平矩形。 这个矩形的角有 4 个暴露的面。 边界上而非角上的立方体有 3 个暴露的面。 内部立方体有 2 个外露面。 我们使用基于矩形尺寸的简单组合公式对每个类别进行计数。 

最后，当所有维度都大于1时，我们使用完整的3D分解。 有 8 个角立方体，每个角立方体有 3 个面。 边立方体位于块的 12 条边上（不包括角），每个边都有 2 个面。 面内部立方体位于除边之外的表面上，每个面贡献 1 个面。 内部立方体贡献 0。我们使用网格维度上的包含-排除来计算计数。 

每种情况都会产生一个封闭形式的表达式，无需迭代。 

### 为什么它有效

 块中的每个立方体都属于一个结构类别，该类别由边界处的坐标数量决定。 这些类别对整个立方体集进行划分，没有重叠。 由于每个类别都有固定数量的暴露面孔，因此总数是类别大小的线性组合。 案例分割确保简并不会扭曲分类，即使维度崩溃也能保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c = map(int, input().split())

    if a == 1 and b == 1 and c == 1:
        print(6)
        return

    # count how many dimensions are 1
    ones = (a == 1) + (b == 1) + (c == 1)

    if ones == 2:
        # line of cubes
        n = max(a, b, c)
        # two endpoints + interior
        if n == 1:
            print(6)
        else:
            # endpoints: 5 faces each, interior: 4 faces each
            print(2 * 5 + (n - 2) * 4)
        return

    if ones == 1:
        # rectangle a x b (assuming c == 1 or permuted)
        if c == 1:
            x, y = a, b
        elif b == 1:
            x, y = a, c
        else:
            x, y = b, c

        if x == 1 and y == 1:
            print(6)
            return

        if x == 1 or y == 1:
            n = max(x, y)
            print(2 * 5 + (n - 2) * 4)
            return

        corners = 4
        edges = 2 * (x - 2) + 2 * (y - 2)
        interior = (x - 2) * (y - 2)

        print(corners * 4 + edges * 3 + interior * 2)
        return

    # full 3D case
    corners = 8
    edges = 4 * (a - 2 + b - 2 + c - 2)
    faces = (a - 2) * (b - 2) + (b - 2) * (c - 2) + (c - 2) * (a - 2)
    interior = (a - 2) * (b - 2) * (c - 2)

    ans = corners * 3 + edges * 2 + faces * 1 + interior * 0
    print(ans)

if __name__ == "__main__":
    solve()
```该实现直接反映了案例分割。 第一个分支隔离了单立方体简并情况，因为后面的公式至少假设了一定程度。 第二个分支将一维结构简化为一条线，并与内部立方体分开计算端点。 第三个分支通过显式计算角、边界带和内部单元来处理矩形，这避免了通过构造重复计算边缘。 

最后一个分支使用完整的 3D 组合分解。 每个术语对应一个几何类别：角贡献三个面，因为正好有三个坐标位于边界上，边贡献两个，因为它们正好位于两个面上，面内部立方体贡献一个，而内部立方体不贡献任何内容。 计数表达式直接来自沿每个轴减去边界层。

 ## 边缘情况

 用于输入`1 1 1`，该块是一个立方体，每个面都是暴露的。 该算法立即匹配完全简并分支并返回 6，而无需输入任何假设更大结构的几何分解。 

用于输入`5 1 1`，该结构变成由五个立方体组成的直线。 该算法检测两个单位维度并将其视为一维情况，生成两个具有 5 个面的端点和三个每个具有 4 个面的内部立方体，与正确的总数相匹配。 

用于输入`2 3 1`，该块折叠成一个矩形。 该算法明确地将几何图形重新解释为二维网格，并正确分离角点、边缘和内部单元，确保边缘立方体不会被重复计算为角点。 

用于输入`3 3 3`，所有类别都存在。 该算法使用包含-排除计数独立计算每个类，确保每个立方体都被精确分配一个类别，并且最终总和中不会发生重叠。
