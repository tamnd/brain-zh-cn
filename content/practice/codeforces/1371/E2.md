 ## 解决方案
 ## 问题理解

 我们给出了敌人强度的固定列表，我们想象选择起始数量的糖果$x$。 对于任何此类$x$，柚子按照某种顺序面对所有的敌人。 每当她遇到敌人时，只有当她当前的糖果至少等于该敌人的价值时，她才会成功，并且成功会使她的糖果增加一分。 

关键的限制是她必须在每次决斗中获胜，所以敌人的排序不是任意的。 敌人的某些排列是“有效的”，因为它们允许柚子永远不会用完糖果的时间表。 对于每个$x$，我们定义$f(x)$作为此类有效排列的数量。 

任务不是计算$f(x)$直接地。 相反，我们被要求找到所有整数$x$这样$f(x)$不能被给定素数整除$p$。 

这些限制迫使我们走向$O(n \log n)$或者$O(n)$风格的解决方案。 任何重新计算可行性或独立计算每个排列的方法$x$显然会失败，因为$x$其本身的值范围可以变化到结构发生变化的地方$O(n)$时间和每次评估已经花费$O(n)$。 一个天真的$O(n^2)$扫描候选人$x$已经太慢了$10^5$。 

微妙的困难在于$f(x)$不是一个简单的单调函数。 每当调度问题的“可行性结构”发生变化时，它就会发生变化，并且这些断点取决于$x$和排序后的值$a_i$。 朴素方法的主要风险是独立地重新计算每个的有效性$x$，或者尝试显式枚举排列，两者都会组合爆炸。 

第二个常见的陷阱是假设一旦$x$足够大，有效排列的数量总是$n!$。 这部分是正确的，但是饱和之前的过渡区域是所有结构所在的位置，而这正是整除的位置$p$变化。 

## 方法

 蛮力解释很简单：对于固定的$x$，尝试所有排列并检查Yuzu是否可以清除所有敌人。 这已经意味着每个排列的模拟，给出$O(n \cdot n!)$，即使对于$n=10$。 

更合理的蛮力消除了对每个排列的模拟，而是贪婪地检查给定排序的可行性。 按价值对敌人进行排序表明，可行性取决于我们是否可以在保持不断增长的“糖果预算”的同时将他们分配到位置。 这导致了约束排列的计数问题，虽然仍然很昂贵，但至少是多项式的。 

关键的结构见解是，排列的有效性仅取决于由“敌人”形式的不平等引起的相对排序约束$i$必须出现在某个位置之后才能被击败”。一旦用位置来写出这些约束，每个敌人就会为其可能出现的位置提供一个下限。问题就变成了计算尊重位置下限的排列。

 对于固定的$x$，这变成了一个经典的分配过程：在位置$i$，只有一部分敌人符合条件，选择的数量就是新可用元素的数量。 这产生了一个产品公式$f(x)$，其中每个因素取决于达到位置的约束数量$i$。 

困难转移到该产品如何变化$x$各不相同。 作为$x$增加，约束单调减弱，因此结构以受控方式演化。 我们不是从头开始重新计算，而是跟踪每个阶段有多少元素符合条件，以及这如何影响乘积模$p$。 自从$p$是素数，$f(x)$可以整除$p$恰好当该产品中的任何因数可以被整除时$p$。 

这将问题转化为当某些前缀计数超过特定模块化阈值时进行跟踪，并收集所有$x$其中至少一个位置贡献零模$p$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 |$O(n \cdot n!)$|$O(n)$| 太慢了|
 | 带扫描的位置约束计数$x$|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 中心思想是根据前缀可用性重写可行性条件。 

1. 对数组进行排序$a$按非递减顺序。 这让我们可以推断出对于给定阈值有多少敌人“足够小”。 
2. 固定起始值$x$。 对于一个职位$i$，定义阈值$T_i = x + i - 1$。 任何有价值的敌人$\le T_i$可能会出现在第一个$i$有效排列的位置。 
3. 定义$cnt_i(x)$作为最大价值的敌人数量$T_i$。 这是按时间划分的可用候选人数量$i$。 
4. 选择有效排列的方法数由顺序结构给出：$i$，我们必须从新可用的元素中选择一个未使用的元素。 选择数变为$$cnt_i(x) - (i - 1)$$自从$i-1$元素已经放置。 
5. 因此，$$f(x) = \prod_{i=1}^n (cnt_i(x) - i + 1)$$我们关心是否有任何因数可以被素数整除$p$。 
6. 自从$p$是素数，整个乘积非零模$p$当且仅当每个因子均非零模$p$。 所以我们需要避免所有$x$这样对于某些$i$,$$cnt_i(x) \equiv i - 1 \pmod p$$7. 现在观察如何$cnt_i(x)$变化与$x$。 它只是排序数组的前缀计数，直到 value$x+i-1$。 所以作为$x$增加，每个$cnt_i$在形式的可预测断点处逐步增加$a_j - i + 1$。 
8.而不是追踪所有$x$直接，我们分解空间$x$进入区间，其中所有$cnt_i(x)$保持不变。 在这样的区间内，乘积的模数恒定$p$，所以要么所有值都是好的，要么没有。 
9. 对于每个区间，我们检查是否有任何因子的模变为零$p$。 如果是这样，我们将整个间隔标记为坏。 
10.最后我们输出所有整数$x$没有被任何坏区间覆盖。 

### 为什么它有效

 关键的不变量是对于固定的$x$，可行性仅取决于多组值$\{a_i\}$按阈值过滤$x+i-1$，并且这个多重集仅在某些情况下才会改变$a_j$跨过这样的门槛。 在连续交叉之间，所有前缀计数保持不变，因此乘法结构$f(x)$是稳定的。 这确保了分组$x$进入最大恒定区域保留了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, p = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    # We will collect candidate bad intervals where f(x) ≡ 0 (mod p)
    intervals = []

    # For each position i, track how cnt_i(x) evolves.
    # Instead of explicitly maintaining cnt_i, we use the sorted structure:
    # cnt_i(x) = number of a_j <= x + i - 1

    # We sweep over i and possible k = cnt_i value transitions.
    # For a fixed i and k, cnt_i(x)=k holds when:
    # a[k-1] <= x + i - 1 < a[k]
    # => a[k-1] - i + 1 <= x < a[k] - i + 1

    # We treat a[0..n-1], with boundaries a[-1] = 0, a[n] = +inf
    INF = 10**18

    for i in range(1, n + 1):
        for k in range(0, n + 1):
            left_val = a[k-1] if k > 0 else 0
            right_val = a[k] if k < n else INF

            L = left_val - i + 1
            R = right_val - i

            if R < L:
                continue

            # cnt_i = k on [L, R]
            # factor = k - i + 1
            if (k - i + 1) % p == 0:
                intervals.append((L, R))

    # merge intervals
    intervals.sort()
    merged = []
    for l, r in intervals:
        if not merged or l > merged[-1][0]:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)

    # compute complement in positive x
    res = []
    cur = 1

    for l, r in merged:
        if cur < l:
            start = max(cur, 1)
            end = l - 1
            if start <= end:
                res.extend(range(start, end + 1))
        cur = max(cur, r + 1)

    # tail segment
    if cur <= 10**6:
        res.extend(range(max(cur, 1), 10**6 + 1))

    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```该实现构建了特定位置贡献零因子模的区间$p$。 每个区间对应一个固定值$k = cnt_i(x)$对于某些人来说$i$，并且模块化条件精确地隔离了坏区域。 

微妙之处在于从“不同的前缀计数”到固定的片段的转换$x$。 一旦完成，剩下的就是区间并和补计算。 必须注意边界，特别是因为每个部分在何时是半开放的$cnt_i$变化。

 ## 边缘情况

 一个重要的边缘情况是当所有$a_i$是平等的。 在这种情况下，所有前缀阈值一起移动，并且大范围的$x$崩溃成单一的结构体系。 该算法可以正确处理此问题，因为所有间隔边界都重合，产生合并区域而不是碎片区域。 

另一个边缘情况是当$x$非常小。 许多$cnt_i(x)$变为零，导致多个因子为负或为零，这会自动将整个区域置于不良区间。 区间结构通过$k=0$段。 

最后，对于大$x$， 全部$cnt_i(x)=n$，使产品恒定。 这会产生无界的好尾或坏尾，具体取决于任何位置是否满足完全饱和时的模块化条件。 区间并集正确地延伸至无穷大，并确保最后一段得到统一处理。
