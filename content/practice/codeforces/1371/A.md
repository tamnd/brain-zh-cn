 ## 解决方案
 ## 问题理解

 我们有一组长度从 1 到$n$，每个长度一根棍子。 Rocher可以将任意两根木棍连接起来，形成一根新的木棍，其长度为两根木棍的长度之和，同时去除原来的木棍。 目标是确定最终具有相同长度的木棍的最大数量。 输入提供多个值$n$，对于每个我们必须计算一个整数答案。 

约束条件允许$n$一样大$10^9$最多有 1000 个测试用例。 这立即排除了任何显式模拟棒连接的算法，因为这样的模拟需要$O(n)$或者$O(n \log n)$每个测试用例的操作，很容易超过$10^9$整体运营情况。 

不明显的边缘情况发生在$n$非常小，例如1或2。对于$n = 1$，只有一根棍子，所以答案显然是1。对于$n = 2$，木棍为 1 和 2。将它们连接起来会产生一根长度为 3 的木棍，因此任何给定长度的木棍都只有一根； 答案仍然是1。当$n = 3$，木棍分别为 1、2 和 3。我们可以将 1 和 2 连接起来形成 3，得到两根长度为 3 的木棍，因此答案变为 2。认识到这种模式至关重要，因为它揭示了一种数学结构，使我们无需模拟即可直接计算答案。 

## 方法

 蛮力方法将枚举所有可能的棒组合序列，跟踪每个所得棒长度的计数，然后确定任何长度的最大频率。 虽然正确，但这是不可行的，因为$n = 10^9$有$2^{10^9}$可能的组合，这远远超出了计算极限。 

The key insight comes from the fact that we want as many sticks of equal length as possible, and combining two sticks always produces a larger stick. 考虑所有棍子的总和：$S = 1 + 2 + \dots + n = n(n+1)/2$。 为了最大化相同长度的木棍数量，我们需要目标木棍长度$L$大约是这个总和的一半或更少，因为如果$L$太大了，我们只能做一根棍子。 另一个观察结果是，如果我们从两端对称地配对木棍，就像反复组合最小和最大的木棍一样，我们自然会产生多根长度大致相同的木棍。 这种模式引出了一个简单的公式：相同长度的木棍的最大数量是$\lfloor (n+1)/2 \rfloor$。 小例子证实了这一点：$n = 3$,$(3+1)//2 = 2$，与观察到的答案相匹配。 为了$n = 4$,$(4+1)//2 = 2$，也符合预期输出。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 我们将迭代每个测试用例。 
2. 对于每个测试用例，读取整数$n$，Rocher 拥有的棍棒数量。 
3. 使用公式计算等长木棍的最大数量$(n+1)//2$。 这是有效的，因为第一个$(n+1)//2$棍子可以与剩余的棍子配对以创建长度的重复项，并且对于任何奇数根棍子，一根棍子可能保持未配对状态，这不会减少重复项的数量。 
4. 输出测试用例的结果。 

为什么它有效：公式$(n+1)//2$是由将最小和最大的木棍配对然后向内移动而产生的。 每对都有助于形成相同长度的棍子，这使得计数最大化。 该操作不需要模拟每种组合，并且算术公式是从最大相等棒的数量始终大约是一半的不变量推导出来的$n$四舍五入。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    print((n + 1) // 2)
```代码首先读取测试用例的数量。 对于每个$n$，它直接计算$(n+1)//2$并打印结果。 使用整数除法可确保我们自动向下舍入，从而正确处理奇数和偶数$n$。 没有数组或循环$n$需要，这使解决方案保持快速且内存高效。

 ## 边缘情况

 对于$n = 1$，算法输出$(1+1)//2 = 1$，这是正确的，因为只有一根棍子存在。 为了$n = 2$，输出是$(2+1)//2 = 1$，反映连接两根棍子只留下一根给定长度的棍子。 对于大奇数$n$喜欢$999999999$,$(999999999+1)//2 = 500000000$，匹配从配对模式得出的等长棒的理论最大数量。 每个边缘情况都得到正确处理，因为该公式可推广到小型和大型$n$没有分支。
