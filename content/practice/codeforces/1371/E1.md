 ## 解决方案
 ## 问题理解

 我们被要求找到所有正整数$x$这样，如果柚子开始$x$糖果，有多种方法可以按顺序击败所有敌人（敌人的排列），以便她始终至少拥有与当前对手一样多的糖果。 每次决斗如果她赢了，她就会额外获得一颗糖果。 敌人的糖果数量以数组形式给出$a$，我们要考虑一个素数$p$使得一个正整数$x$如果有效排列的数量是“好”$f(x)$**不能被整除$p$**。 输出是按升序排列的所有这些好的整数以及它们的计数。 

输入尺寸允许$n \le 2000$和$a_i \le 2000$。 这明确地排除了暴力破解所有排列，因为$n!$排列变得太大，超过$10^{5000}$在$n=2000$。 相反，该解决方案必须在相对于$n$，理想情况下$O(n^2)$。 输出保证最多为$10^5$整数，因此即使存储所有好的整数也是可行的。 

一个不明显的边缘情况是，所有敌人的糖果都比一个小敌人高。$x$。 例如，如果$n=3$,$a=[5,5,5]$， 和$p=2$，那么对于$x=1$或者$x=2$或者$x=3$没有有效的排列，所以$f(x)=0$可以整除$p$。 粗心的实施可能会忽视这样一个事实：$x$值小于最小值$a_i - n + 1$不能产生任何有效的排列。 

另一个微妙的情况是当多个连续$x$值产生相同数量的有效排列。 好的整数总是从一些最小的整数开始连续的$x$，这允许扫描方法。 

## 方法

 一种幼稚的方法是枚举每个候选人的敌人的每种排列$x$，并计算让柚子赢得每场决斗的排列数。 虽然这会产生正确的$f(x)$，其复杂度为$O(n! \cdot n)$，这是无望的$n=2000$。 即使增量地生成组合也无法扩展。 

关键的见解是有效排列的数量仅取决于敌人的排序顺序。 让我们排序$a$按升序排列。 那么，对于一个候选人$x$, 柚子每一步可以击败的敌人数量$i$只是数量$a_j$小于或等于$x + i - 1$。 使用这个，我们可以预先计算每一步可以击败的敌人数量，产生一个计数列表$c_i$。 有效排列模数的总数$p$然后可以使用组合公式计算$f(x) = \prod_{i=1}^n c_i$。 因为$p$是素数，一旦乘积取模我们就可以停止$p$为零。 这将复杂性降低到$O(n^2)$, 可行的$n \le 2000$。 

蛮力在概念上很简单，但不可行。 最佳方法利用敌人的排序数组，在​​每一步计算可行的敌人，并检查整除模数$p$高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 太慢了 |
 | 最佳 | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1.对敌人的糖果进行排序$a$按升序排列。 这保证了任何可行的排列都必须从面对最弱的敌人开始。 
2. 确定尽可能少的起始糖果$x_\text{min}$作为$\max(0, \min(a_i) - n)$。 低于此值无法赢得所有决斗。 
3. 对于每位候选人$x$从$x_\text{min}$最多$x_\text{max} = \max(a_i)$：

 1.初始化一个数组$c$长度$n$， 在哪里$c[i]$计算柚子可以击败的剩余敌人数量$i$第-次决斗。 
2. 对于$i = 0$到$n-1$, 计算敌人的数量$a_j$满意的$a_j \le x + i$。 
3. 减法$i$从这个计数来计算之前决斗中已经遇到的敌人。 
4. 计算所有的乘积$c[i]$模数$p$。 如果乘积取模$p$是非零，那么$x$很好。 
5.收集所有好东西$x$值并按升序输出。 

为什么有效：排序可确保在每一步中我们首先考虑剩下的最弱的敌人。 计数$c[i]$捕获每次决斗中可用的准确选择数量，同时尊重之前的选择。 将它们相乘即可得到有效排列的数量。 当被整除时，模算术停止计算$p$发生，保持效率。 这保证了所有候选人的正确性和完整性$x$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, p = map(int, input().split())
a = list(map(int, input().split()))
a.sort()

min_x = max(0, min(a) - n)
max_x = max(a)

good_x = []

for x in range(min_x, max_x + 1):
    c = []
    for i in range(n):
        count = 0
        for j in range(n):
            if a[j] <= x + i:
                count += 1
        c.append(count - i)
    prod = 1
    for v in c:
        prod = (prod * v) % p
        if prod == 0:
            break
    if prod != 0:
        good_x.append(x)

print(len(good_x))
print(' '.join(map(str, good_x)))
```解决方案首先要对敌人进行分类。 候选循环$x$值的边界为$x_\text{min}$和$x_\text{max}$。 内部循环在每个决斗步骤中计算可能的敌人。 模块化产品有效地确定是否$f(x)$可以整除$p$无需计算巨大的阶乘。 小心地减去已经使用的敌人以避免重复计算，并且逐步计算模块化乘积以短路零。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, p = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()
    min_x = max(0, min(a) - n)
    max_x = max(a)
    good_x = []
    for x in range(min_x, max_x + 1):
        c = []
        for i in range(n):
            count = sum(1 for val in a if val <= x + i)

            if prod == 0:

    return f"{len(good_x)}\n{' '.join(map(str, good_x))}"
