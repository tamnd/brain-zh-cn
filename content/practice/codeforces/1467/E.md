 ## 解决方案
 ## 问题理解

 我们有一棵树，其顶点带有值。 我们可以选择任何顶点作为根。 一旦根被固定，每条从根开始并在某个后代结束的简单路径就成为根到节点的路径。 

如果每个这样的根到节点路径都包含成对不同的值，则该根被称为独特的。 一个值可以在树中出现多次，但是从根开始的单个路径不允许两次遇到相同的值。 

任务是计算有多少个顶点可以作为独特的根。 

第一个观察结果是，该条件仅取决于生根后的祖先-后代关系。 如果存在包含两个具有相同值的顶点的根到节点路径，则根无效。 

该树最多包含$2 \cdot 10^5$顶点。 任何在每个顶点扎根树并分别检查所有路径的解决方案都是没有希望的。 即使每个顶点只有一个 DFS，也需要$O(n^2)$工作，就在身边$4 \cdot 10^{10}$最坏情况下的操作。 我们需要一些接近线性或$O(n \log n)$。 

棘手的部分是改变根会改变全局的祖先关系。 对于某些根，一对等值顶点可能位于相同的根到节点路径上，但对于其他根则不然。 

考虑一条链：```
1 -- 2 -- 3
values: 5 7 5
```以顶点 1 为根生成路径$1 \to 2 \to 3$，其中两次包含值 5，因此顶点 1 无效。 

以顶点 2 为根给出路径$2 \to 1$和$2 \to 3$。 两者都不包含重复值，因此顶点 2 有效。 

在某些固定根中仅检查一次等值对的解决方案将错过这种区别。 

另一个微妙的情况是多个顶点共享相同的值。```
1
|
2
|
3
|
4

values: 1 2 1 1
```冲突不仅仅存在于相邻的等值顶点之间。 每对等值顶点都会产生限制。 忽略其中一些会导致有效根的计数过多。 

最后的边缘情况是所有值都不同。 那么每个根都是有效的，因为没有路径可以包含重复的值。 答案一定是$n$。 

## 方法

 蛮力的想法很简单。 对于每个顶点$r$，树根位于$r$，执行 DFS，维护当前在根到当前路径上的值集，并验证没有值重复。 如果出现重复，$r$没有特色。 

这是正确的，因为它直接检查定义。 不幸的是，每个根都需要$O(n)$工作，并且有$n$根。 总复杂度变为$O(n^2)$，对于$n=2\cdot10^5$。 

为了获得更快的解决方案，我们需要准确了解根何时无效。 

修复任意根，例如顶点 1。考虑两个顶点$u$和$v$具有相同的值。 

一根$r$生根后，如果$r$，这些顶点之一成为另一个顶点的祖先。 然后路径从$r$更深一层包含该值的两个副本。 

那么问题就变成了：

 对于每个等值对$(u,v)$，确定所有根$r$为此$u$和$v$当树的根位于$r$。 

我们不是单独测试根，而是标记因每个冲突对而无效的所有根。 

关键的观察是对于固定对$(u,v)$，坏根集合有一个非常简单的子树结构。 

认为$u$是的祖先$v$在顶点 1 处的固定根中。 

让$c$是...的孩子$u$位于路径上$u$到$v$。 

如果新的根位于子树内（$c$）， 然后$u$和$v$最终在不同的分支中，并且没有一个成为另一个的祖先。 

对于每个其他根位置，$u$仍然是一个祖先$v$，在某些根路径上创建副本。 

因此子树外部的所有根（$c$）很糟糕。 

如果在固定根中两个顶点都不是另一个顶点的祖先，则令$w=\mathrm{LCA}(u,v)$。 

然后$u$和$v$当新根位于子树内部时，恰好与祖先相关（$u$) 或子树($v$）。 

这些又是子树更新。 

剩下的挑战是有效地处理所有等值对。 可能有$O(n^2)$如果许多顶点共享一个值，则这样的对。 

关键的减少是在 DFS 期间处理值，并且仅生成涉及具有相同值的最近祖先的约束。 这将问题转化为线性更新次数。 

公认的解决方案使用 DFS 以及值出现堆栈和子树上的差异数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(n)$| 太慢了|
 | 最佳|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 树在顶点 1 处任意生根。 

执行 DFS 来计算 Euler 巡演进入和退出时间、父指针和子树范围。 这些范围让我们将子树更新表示为欧拉阶上的间隔更新。 

对于每个值，跟踪当前 DFS 路径上具有该值的最新顶点。 

在DFS过程中，访问顶点时$v$，检查当前 root-to- 上是否已经出现相同的值$v$小路。 
具有相同值的最近祖先是$u$，然后子树外部的每个根从$u$到$v$无效。 

这是从前面讨论的祖先案例得出的。 子子树保留之外的任何根$u$多于$v$，在根路径上产生重复的值。 

向整个树添加一个无效标记，并从该子树中减去一个无效标记。 使用欧拉间隔，这成为范围更新。 

接下来，我们必须处理一个顶点的多个后代共享其值的情况。 

对于每个顶点$u$，收集其子树包含另一个值出现的所有子项$a_u$。 

如果两个不同的子子树都包含该值，则这些子树中的任何一个子树内的任何根都将无效。 扎根在那里使得一个事件成为另一个事件的祖先。 

这些子树区域也通过范围更新进行标记。 

对于每个值，该实现存储每个子树中出现的次数并向上传播信息。 每当检测到冲突时，相应的子树区间就会收到更新。 

累积所有更新后，对欧拉阶执行前缀累积。 

当一个顶点的最终无效计数为零时，它就是一个独特的根。 

计算这样的顶点。 

### 为什么它有效

 每个违规都来自出现在单个根到节点路径上的两个等值顶点。 

对于任何值，请考虑 DFS 期间生成的最接近的等值祖先关系。 每个可能的重复值路径都由这些祖先-后代冲突之一表示。 更新规则精确地标记了在重新生根后保留这种祖先关系的根。 

第二个更新系列处理由相同值的不同子分支中的事件引起的冲突。 这些正是重新扎根将一个事件变成另一个事件的祖先的根源。 

每个无效根都被至少一个冲突标记，并且每个标记对应于一条真正的重复值路径。 因此，当且仅当所有根到节点路径包含不同值时，根接收计数为零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    tin = [0] * n
    tout = [0] * n
    parent = [-1] * n
    timer = 0

    sys.setrecursionlimit(1 << 20)

    def dfs0(v, p):
        nonlocal timer
        parent[v] = p
        tin[v] = timer
        timer += 1
        for to in g[v]:
            if to != p:
                dfs0(to, v)
        tout[v] = timer

    dfs0(0, -1)

    diff = [0] * (n + 1)

    def add_subtree(v, x):
        diff[tin[v]] += x
        diff[tout[v]] -= x

    def add_all(x):
        diff[0] += x
        diff[n] -= x

    last = {}
    bad_child = [set() for _ in range(n)]

    def dfs1(v, p):
        prev = last.get(a[v], -1)
        last[a[v]] = v

        if prev != -1:
            cur = v
            while parent[cur] != prev:
                cur = parent[cur]

            add_all(1)
            add_subtree(cur, -1)

            bad_child[prev].add(cur)

        for to in g[v]:
            if to != p:
                dfs1(to, v)

        if prev == -1:
            del last[a[v]]
        else:
            last[a[v]] = prev

    dfs1(0, -1)

    for v in range(n):
        if len(bad_child[v]) >= 2:
            for ch in bad_child[v]:
                add_subtree(ch, 1)

    cur = 0
    ans = 0

    euler_to_vertex = [0] * n
    for v in range(n):
        euler_to_vertex[tin[v]] = v

    val = [0] * n
    for i in range(n):
        cur += diff[i]
        val[euler_to_vertex[i]] = cur

    for v in range(n):
        if val[v] == 0:
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```第一个 DFS 计算欧拉环间隔。 每个子树都成为一个连续的段$[tin,tout)$，这让我们可以在恒定时间内执行子树更新。 

第二个 DFS 为每个值维护当前在递归堆栈上最近出现的值。 当出现重复值时，我们会识别导致新出现的较早出现的子项。 “整个树减去子子树”的更新是通过全局间隔更新和补偿子树减法来实现的。 

这`bad_child`结构记录顶点的哪些子分支包含相同值的另一个出现。 DFS 完成后，任何其值出现在至少两个不同子分支中的顶点都会创建额外的禁止根区域。 这些子树间隔被添加到差异数组中。 

最后，扫描欧拉阶将差异数组转换为实际的无效计数。 计数为零的顶点正是有效根。 

最微妙的部分是识别直接位于祖先出现下方的子代。 使用最近的等值祖先可以保证每个冲突都被处理一次。 另一个容易犯的错误是忘记子树更新是半开区间$[tin,tout)$; 使用包含端点会产生相差一的错误。

 ## 边缘情况

 考虑单个顶点：```
1
10
```只有一条根到节点的路径，由单个顶点组成。 不能出现重复的情况。 DFS 不执行冲突更新，所有计数器保持为零，答案为 1。 

考虑一条链：```
3
1 2 1
1 2
2 3
```重复值出现在两端。 在 DFS 期间，第二次出现将第一次发现为等值祖先。 此更新标记了使它们与祖先相关的根。 顶点 2 位于豁免子树中并且保持未标记。 输出为 1。 

考虑所有不同的值：```
4
1 2 3 4
1 2
1 3
1 4
```不存在等值对。 差异数组永远不会从零开始变化。 每个顶点收到的无效计数为零，产生答案 4。 

考虑多个相等的值：```
4
7 7 7 7
1 2
2 3
3 4
```每个根都创建一条包含重复值 7 的路径。DFS 为每个重复出现生成冲突更新，并且每个顶点都会累积正无效计数。 答案变成0，与定义相符。
