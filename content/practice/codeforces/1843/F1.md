 ## 解决方案
 ## 问题理解

 我们有一棵正在生长的树，代表鄂木斯克地铁，其中每个车站的权重为`1`或者`-1`。 该树最初有一个编号为`1`有重量`1`。 然后，我们执行一系列事件：添加一个新站点作为现有站点的子站点，或者查询从站点出发的路径上是否存在连续的路段`1`到另一个车站`v`其权重总和正好等于某个整数`k`。 

由于树在车站扎根`1`我们只查询从以下位置开始的路径`1`，每个查询的路径只是沿着从根到目标节点的唯一路线的节点序列。 每个查询询问该序列是否存在总和精确的连续子段`k`。 

该问题最多允许`2 * 10^5`所有测试用例的总事件。 检查每个查询的所有子段的强力方法将需要每个查询 O(n²) 时间，这太慢了。 我们需要每个查询一个 O(n) 或更好的解决方案，最好利用前缀和的属性。 关键边缘情况包括空子段（其总和为`0`）和完全由以下组成的路径`1`或`-1`s，这限制了可实现的金额。 

## 方法

 最简单的方法是，对于每个查询，从节点重建路径`1`到目标节点，然后检查该路径的所有可能的连续子段，看看它们的总和是否等于`k`。 这涉及迭代 O(n) 个节点，然后迭代 O(n) 个子段，从而导致每个查询的 O(n²) 时间复杂度。 高达`2 * 10^5`事件，这将需要 O((2 * 10^5)²) 次操作，这是不可行的。 

关键的观察是我们只需要沿路径可实现的最大和最小总和。 每个节点贡献之一`+1`或者`-1`，因此总路径和位于区间内`[min_sum, max_sum]`， 在哪里`min_sum`是总和`-1`s 在路径的开头连续获取，并且`max_sum`是总和`1`s 是连续拍摄的。 因为所有的权重都是`1`或者`-1`，之间的任意整数`min_sum`和`max_sum`可以作为一些连续子段的总和来实现。 这将每个查询减少为一个简单的检查：`k`之间`min_sum`和`max_sum`？ 构建路径并维护前缀和允许使用预先计算的累积和在每个查询的 O(1) 中计算这些边界。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次查询 O(n²) | O(n) | 太慢了 |
 | 前缀和间隔检查 | O(n) 树构建后每个查询的 O(1) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个列表`weights`存储每个站的重量。 初始化一个列表`cumulative`存储从根到每个节点的累积和。 开始于`weights[1] = 1`和`cumulative[1] = 1`。 
2. 维持`parent`数组来了解每个节点的父节点。 如有必要，需要跟踪从任何节点到根的路径。 
3. 对于“+”事件，添加一个新节点作为`v_i`有重量`x_i`。 放`cumulative[new_node] = cumulative[v_i] + x_i`。 存储新节点的父节点。 
4. 对于“？” 事件与`u = 1`，路径只是从根到的节点序列`v_i`。 整个路径的总和是`cumulative[v_i]`。 
5. 计算沿路径的任何连续子段的最大可能总和。 由于权重仅`-1`或者`1`，最大和是路径和本身，如果所有`1`包含 s，最小值为个数的负数`-1`是。 这可以计算为`min_sum = -count(-1)`和`max_sum = count(1)`。 
6. 如果`k`位于之间`min_sum`和`max_sum`，输出“是”； 否则，输出“No”。 包括一个特殊情况，其中`k = 0`，这总是可以通过选择空子段来实现。 

为什么有效：前缀和技巧保证沿路径的最小和最大和之间的任何整数都是可以实现的。 由于所有权重均为 ±1，因此沿连续子段的可实现总和集在此区间内是连续的。 累积总和允许每个查询的 O(1) 时间复杂度进行此检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        parent = [0, 0]  # parent[1] = 0
        weights = [0, 1]  # weights[1] = 1
        count_plus = [0, 1]  # cumulative sum of +1 weights
        count_minus = [0, 0]  # cumulative sum of -1 weights
        node_id = 1
        
        for _ in range(n):
            parts = input().split()
            if parts[0] == '+':
                v, x = int(parts[1]), int(parts[2])
                node_id += 1
                parent.append(v)
                weights.append(x)
                count_plus.append(count_plus[v] + (x == 1))
                count_minus.append(count_minus[v] + (x == -1))
            else:
                u, v, k = int(parts[1]), int(parts[2]), int(parts[3])
                # Path from 1 to v
                max_sum = count_plus[v] - count_plus[u - 1]  # all 1s
                min_sum = -count_minus[v] + count_minus[u - 1]  # all -1s
                if min_sum <= k <= max_sum:
                    print("Yes")
                elif k == 0:
                    print("Yes")
                else:
                    print("No")

if __name__ == "__main__":
    solve()
```在这个解决方案中，`count_plus`和`count_minus`跟踪数量`1`沙`-1`沿着从根到每个节点的路径。 对于每个查询，检查是否`k`位于内`[min_sum, max_sum]`确保正确性。 空路径情况由以下方式处理`k == 0`。 这`parent`数组用于维护树结构，尽管在这个简单的版本中，`u = 1`，因此追踪路径很简单。
