 ## 解决方案
 ## 问题理解

 该问题对代表鄂木斯克地铁系统的生长树结构进行建模。 树中的每个节点都是一个站点，从权重 +1 的站点 1 开始。 新站被一一添加，每个都连接到现有站，并且每个站的权重为+1或-1。 随着添加站点的同时，查询也会到达，询问两个站点之间的路径上是否存在连续的节点段，其权重总和正好等于给定整数$k$。 段可以为空，在这种情况下总和为 0。 

输入在站添加和查询之间交替进行。 输出必须回答每个查询“是”或“否”。 

限制很严格。 事件数量$n$可以达到$2 \cdot 10^5$每个测试用例，并且所有测试用例的总数不超过$2 \cdot 10^5$。 这意味着为每个查询迭代整个路径的简单方法太慢：最坏的情况$O(n^2)$算法将执行$10^{10}$操作，远远超过了2秒的时间限制。 我们需要更接近的东西$O(n \log n)$每个测试用例。 

不明显的边缘情况包括完全为 +1 或 -1 的路径，即所需的路径$k$超过路径上所有节点权重之和，查询其中$u = v$。 例如，如果路径是 1 → 2 → 3，权重为 [+1, -1, +1]，则查询要求$k = 2$应该返回“Yes”，因为子路径 1 → 3 的总和为 +1，因此只有子路径 1 → 1 或 3 → 3 的总和可以为 +1，这表明算法必须仔细处理所有连续的子路径。 

## 方法

 暴力解决方案将定位查询节点之间的路径，然后检查每个连续的子段以查看其总和是否等于$k$。 为了构建路径，可以从两个节点回溯到它们的最低共同祖先 (LCA)。 每条路径最多可以有$O(n)$节点，并检查所有子段是$O(n^2)$每个查询。 和$10^5$查询，这在计算上是不可行的。 

关键的见解是所有节点权重要么是+1，要么是-1。 此限制意味着任何路径的总和都在整数范围内$[-L, L]$， 在哪里$L$是路径的长度。 然后，问题简化为“具有±1个元素的连续序列的子集和”的变体，可以使用前缀和有效地解决。 沿路径的前缀和允许我们检查是否$k$可以通过任何连续的子段获得：索引的子路径总和$i$到$j$是$prefix[j] - prefix[i-1]$。 因此，如果我们将前缀和存储在一个集合中，查询就变成检查是否$prefix[j] - k$存在于集合中。 

树结构需要一种快速方法来计算沿任意路径的前缀和。 使用欧拉游览或重光分解 (HLD)，我们可以将路径线性化为数组。 然而，给定±1权重，知道沿路径的最小和最大可能总和就足够了。 让$len$是路径长度，$pos$+1 节点的数量，以及$neg$-1 节点的数量。 那么最大和就是$pos - neg$最小值是$-neg + pos$。 此范围内且具有正确奇偶校验（与节点数量相同的奇偶校验）的任何整数都可以作为连续子路径和来实现。 这极大地简化了查询处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次查询 O(n²) | 每个查询 O(n) | 太慢了 |
 | 前缀和 + ±1 路径边界 | 总共 O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化树，节点 1 的权重为 +1。 跟踪从根开始的父项、深度和前缀总和。 
2. 对于每个“+”事件，添加一个新节点。 存储其父项、权重，并计算其前缀和：`prefix[node] = prefix[parent] + weight`。 
3. 对于每个“？” 查询：

 a. 计算之间的路径`u`和`v`使用 LCA。 

b. 让`sum_path`是总和`u`到`v`沿着路径。 

c. 让`len_path`是该路径上的节点数。 

d. 计算可实现的最小和最大子路径总和：`min_sum = -count_negative`和`max_sum = count_positive`。 

e. 如果`k`在于`[min_sum, max_sum]`和`(k - min_sum) % 2`匹配路径奇偶校验，输出“Yes”，否则输出“No”。 
4. 使用二进制提升或深度数组在每个查询的 O(log n) 中高效计算 LCA。 

正确性如下，因为每个 ±1 和的子段都是连续的，并且可实现的和范围内的任何整数都可以形成为连续的子路径。 奇偶校验确保仅在 ±1 步长的情况下就可以得出某个整数之和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        parent = [0, 0]  # 1-indexed; parent[1] = 0
        weight = [0, 1]  # weight[1] = 1
        depth = [0, 0]   # depth of root is 0

        # For prefix sums from root
        prefix = [0, 1]

        # For LCA
        LOG = 20
        up = [[0]*LOG for _ in range(n+2)]  # up[node][i] = 2^i-th ancestor
        up[1][0] = 0

        nodes = 1
        events = []
        for _ in range(n):
            parts = input().split()
            events.append(parts)

        for parts in events:
            if parts[0] == '+':
                v, x = int(parts[1]), int(parts[2])
                nodes += 1
                parent.append(v)
                weight.append(x)
                depth.append(depth[v] + 1)
                prefix.append(prefix[v] + x)
                up.append([0]*LOG)
                up[nodes][0] = v
                for i in range(1, LOG):
                    up[nodes][i] = up[up[nodes][i-1]][i-1] if up[nodes][i-1] else 0
            else:
                u, v, k = int(parts[1]), int(parts[2]), int(parts[3])
                # find lca
                def lca(a, b):
                    if depth[a] < depth[b]:
                        a, b = b, a
                    for i in range(LOG-1, -1, -1):
                        if depth[a] - (1 << i) >= depth[b]:
                            a = up[a][i]
                    if a == b:
                        return a
                    for i in range(LOG-1, -1, -1):
                        if up[a][i] != up[b][i]:
                            a = up[a][i]
                            b = up[b][i]
                    return parent[a]

                anc = lca(u, v)
                len_path = depth[u] + depth[v] - 2*depth[anc] + 1
                sum_path = prefix[u] + prefix[v] - 2*prefix[anc] + weight[anc]

                # Max and min achievable subpath sums along ±1 path
                max_sum = (len_path + sum_path)//2
                min_sum = (len_path - sum_path)//2 * -1

                if min_sum <= k <= max_sum:
                    print("Yes")
                else:
                    print("No")

if __name__ == "__main__":
    main()
```该代码首先设置父级、权重、深度和前缀和的数组。 二进制提升通过`up`允许高效的 LCA 计算。 对于每个查询，路径长度和总和用于计算最大和最小可实现的子路径总和。 检查`k`根据这个范围来确定答案。
