 ## 解决方案
 ## 问题理解

 我们得到两个代表超级英雄名字的小写字符串。 如果每个元音都可以变成任何其他元音，并且每个辅音都可以变成任何其他辅音，则允许转换。 

实际的字母并不重要。 重要的是每个位置是否包含元音或辅音。 例如，`'a'`可以成为`'u'`因为两者都是元音，并且`'b'`可以成为`'z'`因为两者都是辅音。 元音永远不可能变成辅音，辅音永远不可能变成元音。 

任务是确定是否可以使用这些规则将第一个名称转换为第二个名称。 

字符串的长度最多为 1000，非常小。 即使是多次扫描字符串的算法也很容易足够快。 唯一重要的是正确执行转换条件。 

一个重要的观察结果是，改变字符永远不会改变字符串长度。 每个操作都会将一个字符替换为同一类别的另一个字符。 如果两个名字的长度不同，答案立即是“否”。 

有一些容易被忽略的边缘情况。 

考虑：```
a
bb
```正确答案是：```
No
```仅比较元音/辅音计数的粗心解决方案可能会错误地接受它。 长度相等是强制性的。 

考虑：```
ab
cd
```正确答案是：```
No
```第一个位置是元音与辅音。 尽管两个字符串总体上都包含一个元音和一个辅音，但位置很重要。 

考虑：```
ae
io
```正确答案是：```
Yes
```字母不同，但每个位置都是元音与元音。 

考虑：```
code
java
```正确答案是：```
No
```在某些位置，一个字符串包含辅音，而另一个字符串包含元音。 

## 方法

 思考这个问题的一种暴力方式是模拟每个字符是否可以更改为另一个字符串的相应字符。 对于每个位置，我们可以询问源字符和目标字符是否属于同一类别。 如果任何立场违反了这个规则，转型就不可能。 

由于每个字符串最多有 1000 个字符，因此直接检查每个位置只需要 1000 次比较。 这已经够快了。 

关键的见解是一封信的实际身份并不重要。 转换规则允许任何元音变成任何元音，任何辅音变成任何辅音。 这意味着每个字符都可以简化为一位信息：元音或辅音。 

经过这样的观察，问题就变得非常简单了。 首先验证长度是否相等。 然后逐位置扫描两个字符串。 在每个索引处，检查两个字符是否都是元音或都是辅音。 如果不是，转型是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 在这个问题中，自然的暴力方法已经是最佳的，因为输入大小很小并且每个字符必须至少检查一次。 

## 算法演练

 1. 读取两个字符串。 
2. 如果它们的长度不同，则输出`"No"`并停止。 

转换仅替换字符。 它从不插入或删除字符。 
3. 创建包含元音的集合`{a, e, i, o, u}`。 
4. 迭代字符串的所有位置。 
5. 对于每个位置，确定第一个字符串中的字符是否是元音以及第二个字符串中的字符是否是元音。 
6. 如果一个字符是元音，另一个是辅音，则输出`"No"`并停止。 

在允许的操作下，这样的位置是绝对不能改变的。 
7. 如果整个扫描完成后没有发现不匹配，则输出`"Yes"`。 

### 为什么它有效

 当每个位置都可以独立变换时，变换才是有效的。 

在任何位置都只有两种可能：元音或辅音。 元音可以变成任何元音，辅音可以变成任何辅音。 因此，当且仅当两个角色属于同一类别时，位置才是可变换的。 

如果字符串的长度不同，则任何替换序列都无法使它们相等。 如果长度相等并且每个位置都有匹配的类别，我们就可以在每个位置选择合适的替换，得到目标字符串。 这些条件都是充分必要的，所以算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
t = input().strip()

if len(s) != len(t):
    print("No")
    sys.exit()

vowels = set("aeiou")

for a, b in zip(s, t):
    if (a in vowels) != (b in vowels):
        print("No")
        break
else:
    print("Yes")
```第一个检查处理唯一的全局限制：长度必须匹配。 

这`vowels`set 允许常量成员资格检查。 对于每对字符，表达式```
(a in vowels) != (b in vowels)
```当一个字符是元音而另一个字符是辅音时，这正是正确的。 一旦找到这样的位置，答案就是`"No"`。 

这`for-else`这里施工方便。 这`else`仅当循环完成且未遇到`break`，意味着每个位置都满足所需条件。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    s = input().strip()
    t = input().strip()

    if len(s) != len(t):
        print("No")
        return

    vowels = set("aeiou")

    for a, b in zip(s, t):
        if (a in vowels) != (b in vowels):
            print("No")
            return

    print("Yes")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample

# custom cases

assert run("aeiou\nuoiea\n") == "Yes", "all vowels"
assert run("b\nz\n") == "Yes", "single consonants"
assert run(("a" * 1000) + "\n" + ("e" * 1000) + "\n") == "Yes", "maximum length"
