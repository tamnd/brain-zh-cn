 ## 解决方案
 ## 问题理解

 我们从一系列严格增加的问题复杂性开始。 集合的不平衡性定义为排序后两个相邻元素之间的最大差异。 

我们最多可以插入一个附加问题。 新问题必须具有复杂性`d_i + f_j`，我们从模型数组中选择一个值，从函数数组中选择一个值。 

任务是在插入最多一个这样的值后最小化最终的不平衡。 

原始数组已经排序，这非常有用。 不平衡仅取决于相邻间隙，因此整个问题实际上是控制最大间隙。 

这些约束立即排除了对所有可能插入的暴力破解。 在所有测试用例中，`m`和`k`每个总和可以是`2 * 10^5`，所以周围可能有`4 * 10^10`可能的配对`(d_i, f_j)`。 任何显式生成所有总和的算法都是不可能的。 

数组`a`本身要小得多，总尺寸`10^5`，所以我们应该期待一个围绕以下差距的解决方案`a`，并非围绕所有生成的值。 

有几种容易被忽略的边缘情况。 

假设最大的间隙出现多次。```
a = [1, 5, 9]
gaps = [4, 4]
```即使我们将一个间隙完美地分成两个较小的部分，另一个间隙的大小`4`仍然存在。 答案永远不能低于`4`。 仅优化一个选定间隙的粗心实现将错误地返回`2`。 

另一个棘手的情况是不可能插入最大间隙。```
a = [1, 10]
d = [100]
f = [100]
```唯一可构造的值是`200`，位于间隙之外`[1, 10]`。 添加它不会改变原始间隙，所以答案仍然存在`9`。 

选择最佳生成值时还存在一个微妙的边界问题。 如果最大的差距是`[L, R]`，那么理想的插入值就在中点附近`(L + R) / 2`。 但最接近的可实现总和可能略低于或略高于这个中点。 仅检查一侧可能会错过最佳值。 

例子：```
L = 10, R = 20
possible sums = {14, 16}
```使用`14`给出最大间隙`6`， 尽管`16`给出最大间隙`6`以及。 在许多情况下，一侧绝对更好，因此必须仔细检查目标周围的两个邻居。 

## 方法

 蛮力的想法很简单。 对于每对`(d_i, f_j)`，构造值`x = d_i + f_j`。 将其插入已排序的数组中，计算新的最大相邻间隙，并保留最小答案。 

这是有效的，因为不平衡定义仅取决于最终的排序顺序。 一旦插入的值固定，结果就是确定的。 

问题在于规模。 在最坏的情况下，我们会检查：```
m * k = 2 * 10^5 * 2 * 10^5 = 4 * 10^10
```可能的值。 即使在重新计算间隙之前，这也已经远远超出了时间限制。 

关键的观察结果是插入数字只会影响一个间隙。 

假设插入的值介于`a[i]`和`a[i+1]`。 所有其他相邻的差异保持不变。 只有差距```
a[i+1] - a[i]
```被替换为```
x - a[i]
and
a[i+1] - x
```这立即改变了观点。 我们不考虑所有位置，而只关心现有的最大差距。 

为什么？ 因为所有其他间隙已经存在并且保持不变，除非我们将其插入其中。 如果当前最大间隙为`mx`，那么插入后，每个未触及的间隙仍然存在。 

现在考虑两种情况。 

如果最大的间隙至少出现两次，则始终有一个副本不受影响。 答案已经固定在`mx`。 

否则有一个独特的最大差距。 只有这样插入才能改善答案，因为分割这个间隙可能会减少全局最大值。 

假设唯一的最大差距是`L`和`R`。 

如果我们插入值`x`在这个区间内，新的最大缺口贡献为```
max(x - L, R - x)
```该表达式在以下情况下最小化：`x`尽可能接近中点。 

那么问题就变成了：

 寻找可构建的价值`d_i + f_j`最接近`(L + R) / 2`。 

这就是排序和二分查找的用武之地。 

我们对数组进行排序`f`。 对于每一个`d_i`，我们想要：```
d_i + f_j ≈ midpoint
```这意味着：```
f_j ≈ midpoint - d_i
```使用二分查找排序`f`，我们可以有效地测试最近的候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(mk + nk) | O(mk + nk) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n + m log k + k log k) | O(n + m log k + k log k) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 计算数组中所有相邻的间隙`a`。 
2.找到最大的差距`mx`和第二大差距`second`。 

第二大差距很重要，因为在分割最大差距后，其他所有差距仍然保持不变。 

1.数数有多少次`mx`出现。 

如果至少出现两次，则立即返回`mx`。 

即使我们减少了一次出现，另一个相同的间隙仍会保持不变。 

1. 设唯一最大差距为`L = a[pos]`和`R = a[pos + 1]`。 

只有在这个区间内插入才能改善答案。 

1. 数组排序`f`。 

我们将在其中进行二分搜索。 

1. 对于每个值`d_i`，计算目标：```
target = (L + R) / 2 - d_i
```我们想要一个值`f_j`这样`d_i + f_j`尽可能接近间隙的中点。 

1. 使用二分查找`f`找到第一个不小于的值`target`。 

检查此位置和前一个位置。 

最接近的可实现总和可能位于中点的两侧。 

1. 对于每个候选总和`x = d_i + f_j`:

 1. 忽略它，如果`x`并不严格在里面`(L, R)`。 
2. 计算插入后的最大间隙：```
new_max = max(
    second,
    x - L,
    R - x
)
```1. 最小化所有候选人的答案。 
2. 如果间隙内不存在有效插入，则答案保持不变`mx`。 

### 为什么它有效

 每一次插入都会影响一个相邻的间隔。 所有其他差距永远保持不变。 

如果最大间隙出现多次，则更改一个副本无法减小全局最大值，因为另一个相同的间隙仍然存在。 

当最大差距是唯一的时，唯一有用的操作就是分割该差距。 任何在其外部的插入都不会影响最大的间隙。 

固定区间内`[L, R]`，由此产生的最大局部间隙变为：```
max(x - L, R - x)
```当以下情况时，该数量最小化：`x`最接近中点。 因为每个可构造的值都有形式`d_i + f_j`，二分查找最接近的`f_j`对于每个`d_i`检查所有最佳候选人。 

该算法检查每个潜在的最佳插入并计算准确的结果不平衡，因此找到的最小值是正确的。 

## Python 解决方案```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n, m, k = map(int, input().split())
        
        a = list(map(int, input().split()))
        d = list(map(int, input().split()))
        f = list(map(int, input().split()))
        
        gaps = []
        mx = -1
        pos = -1
        
        for i in range(n - 1):
            g = a[i + 1] - a[i]
            gaps.append(g)
            
            if g > mx:
                mx = g
                pos = i
        
        cnt = gaps.count(mx)
        
        if cnt >= 2:
            print(mx)
            continue
        
        second = 0
        for g in gaps:
            if g != mx:
                second = max(second, g)
        
        L = a[pos]
        R = a[pos + 1]
        
        f.sort()
        
        ans = mx
        mid = (L + R) / 2
        
        for dv in d:
            target = mid - dv
            
            idx = bisect_left(f, target)
            
            for j in [idx - 1, idx]:
                if 0 <= j < k:
                    x = dv + f[j]
                    
                    if L < x < R:
                        cur = max(second, x - L, R - x)
                        ans = min(ans, cur)
        
        print(ans)

solve()
```第一部分计算所有相邻间隙并确定最大的间隙。 我们还存储它发生的位置，因为稍后我们需要精确的间隔边界。 

尽早返回重复的最大间隙至关重要。 如果没有它，算法将浪费时间搜索永远无法改善答案的插入。 

变量`second`存储最大的不受影响的间隙。 分割唯一的最大间隙后，该值自动成为最终答案的一部分。 

二分查找部分是核心优化。 对于每个`d_i`，我们得出理想的匹配值`f`。 自从`f`已排序，`bisect_left`给出最接近的较大候选者。 前一个索引可能更接近，因此必须检查两者。 

严格条件：```
L < x < R
```很重要。 如果`x`等于`L`或者`R`，实际上没有发生分裂，原始差距保持不变。 

Python 整数可以安全地处理这里的所有值，因为它们支持任意精度。 在具有固定宽度整数的语言中，`L + R`应使用 64 位算术。

 ## 边缘情况

 考虑重复的最大间隙情况：```
a = [1, 5, 9]
```差距是`[4, 4]`。 

即使我们插入`3`之间`1`和`5`，间隙变为：```
2, 2, 4
```不平衡状况依然存在`4`。 

算法检测到最大间隙出现多次并立即返回`4`。 这避免了仅减少一份副本的错误尝试。 

现在考虑一个不可能的插入：```
a = [1, 100]
d = [200]
f = [300]
```唯一可构造的值是`500`，位于外面`(1, 100)`。 

该算法检查：```
if L < x < R
```并拒绝该候选人。 由于不存在有效的分割，因此答案保持等于原始间隙`99`。 

最后，考虑边界敏感的中点情况：```
a = [10, 20]
d = [5]
f = [4, 6]
```可能的插入是`9`和`11`。 

中点是`15`。 

二分搜索检查目标周围的两个相邻位置。 有效插入`11`造成差距`1`和`9`，给出答案`9`。 

如果我们只检查下邻居或只检查上邻居，在类似情况下我们可能会错过最佳候选者。
