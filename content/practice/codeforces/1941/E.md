 ## 解决方案
 ## 问题理解

 每排河流都可以独立处理。 沿着选定的行，我们希望在某些列中放置支撑，以便第一列和最后一列始终包含支撑，并且两个相邻支撑之间跳过的单元格数量最多为`d`。 

如果支撑放置在柱上`j1`和`j2`，间隙条件为：$$|j_1 - j_2| - 1 \le d$$这相当于：$$|j_1 - j_2| \le d + 1$$在立柱处安装支撑`j`成本`a[i][j] + 1`。 

对于每一行，我们都需要尽可能小的桥梁成本。 After that, we must choose`k`桥梁成本总和最小的连续行。 

该结构自然地分为两个子问题：

 1. 计算单行的最佳桥接成本。 
2. 找出所有连续组的最小总和`k`行。 

这些约束在很大程度上影响了解决方案。 所有测试用例的单元总数最多为`2 * 10^5`，因此预计输入大小接近线性。 对列的二次算法会失败，因为单行可能包含`2 * 10^5`列。 甚至`O(m * d)`当`d`很大。 

棘手的部分是一排桥梁的建设。 粗心的贪婪方法会失败，因为现在选择最便宜的附近支撑可能会在以后迫使许多昂贵的支撑。 

考虑这一行：```
0 1 100 1 0
```和`d = 1`。 

不能直接从列跳转`1`到专栏`5`因为支撑之间的距离会跳过 3 个单元格。 最佳解决方案必须使用中间支撑。 

另一个微妙的情况出现时`d`非常大。 

例子：```
0 5 7 2 0
```和`d = 10`。 

现在仅第一个和最后一个支撑就已经满足距离条件，所以答案很简单：```
1 + 1 = 2
```有缺陷的实现仍然可能会强制不必要的中间支持。 

另一个容易出现的差一陷阱来自距离定义。 该问题将距离定义为跳过的单元格，而不是绝对列差。 

如果`d = 1`，支持最多可能不同`2`在列索引中。 

例如：```
0 4 0
```和`d = 1`。 

柱上的支撑`1`和`3`有效，因为它们恰好跳过一个单元格。 

解决方案使用`|j1 - j2| <= d`会错误地拒绝这一点。 

## 方法

 暴力破解的想法是简单的动态规划。 

让`dp[j]`是在柱上放置支撑的最低成本`j`。 然后：$$dp[j] = cost(j) + \min(dp[t])$$在哪里`t`范围涵盖所有之前可以连接到的支撑位置`j`。 

由于支持最多可以相差`d + 1`在列索引中：$$j - (d+1) \le t < j$$对于每一列，我们扫描所有有效的先前列并取最小值。 

这给出：$$O(m \cdot d)$$排一排的时间。 

在最坏的情况下，`d`可以是`m`，所以这就变成了`O(m^2)`。 和`m = 2 * 10^5`，这是完全不可行的。 

关键的观察结果是，转换仅要求滑动窗口内的最小值。 

对于柱`j`，我们需要：$$\min(dp[j-d-1], \dots, dp[j-1])$$作为`j`增加时，该范围也会向右滑动。 滑动窗口最小问题正是单调队列有效解决的。 

我们维护一个包含候选列的双端队列，而不是每次都重新计算最小值`dp`价值观。 前面总是存储最小的有效值`dp`。 

这将每行的复杂性从二次降低到线性。 

在计算出每行的最佳桥接成本后，第二阶段就很容易了。 我们需要的最小总和`k`连续行成本，这是另一个滑动窗口。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·m·d) | O(米) | 太慢了 |
 | 最佳 | O(n·m) | O(米) | 已接受 |

 ## 算法演练

 1. 对于每一行，创建一个 DP 数组，其中`dp[j]`表示最后安装的支撑位于柱上时的最低总成本`j`。 
2. 初始化第一列。 

第一个支持是强制性的，其成本为：$$a[i][1] + 1 = 1$$所以：$$dp[0] = 1$$1. 维护一个单调双端队列，存储候选者之前的位置。 

双端队列保存的索引`dp`值正在增加。 前面总是包含最小值`dp`当前可到达的列中。 
2. 从左到右处理列。 

对于柱`j`，如果索引太远，则从前面删除索引：$$idx < j - (d + 1)$$因为那些支撑物无法再连接到`j`。 

1. 计算转变。 

之前最好的支持是在双端队列前面：$$dp[j] = dp[best] + a[i][j] + 1$$1. 将当前列插入双端队列。 

虽然背面有一个`dp`值大于或等于`dp[j]`，将其删除。 这样的职位永远不会再有用，因为当前的职位既便宜又新。 
2.排完后，储存`dp[m-1]`作为该行的最小桥梁成本。 
3. 一旦知道所有行成本，计算以下的最小总和`k`使用滑动窗口的连续行。 
4. 输出最小的窗口和。 

### 为什么它有效

 DP 是正确的，因为每个有效的桥都以列结尾`j`必须来自之前的一些远处的支持`d + 1`。 递归会检查所有这些可能性并选择最便宜的一种。 

双端队列始终包含当前位置的有效前一列，按最小顺序排列`dp`留在前面。 由于无效位置会立即被移除，并且主导位置会从后面被丢弃，因此双端队列最小值始终是正确的。 

由于每列最多进入和离开双端队列一次，因此总工作量保持线性。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n, m, k, d = map(int, input().split())
        grid = [list(map(int, input().split())) for _ in range(n)]

        row_costs = []

        for row in grid:
            dp = [0] * m
            dp[0] = 1

            dq = deque([0])

            for j in range(1, m):
                while dq and dq[0] < j - (d + 1):
                    dq.popleft()

                best = dq[0]
                dp[j] = dp[best] + row[j] + 1

                while dq and dp[dq[-1]] >= dp[j]:
                    dq.pop()

                dq.append(j)

            row_costs.append(dp[-1])

        current = sum(row_costs[:k])
        answer = current

        for i in range(k, n):
            current += row_costs[i]
            current -= row_costs[i - k]
            answer = min(answer, current)

        print(answer)

solve()
```第一阶段独立计算每行的最佳桥接成本。`dp[j]`如果我们在柱上放置支撑，则存储最小总成本`j`。 由于第一列必须始终包含支撑，`dp[0] = 1`。 

双端队列存储用于转换的候选先前列。 处理柱前`j`，我们删除距离太远而无法合法连接的列。 

过渡：```
dp[j] = dp[best] + row[j] + 1
```使用最小可到达的先前状态。 

单调性通过以下方式保持：```
while dq and dp[dq[-1]] >= dp[j]:
    dq.pop()
```这使得双端队列增加`dp`值，所以前面总是最优的。 

一个微妙的细节是有效性条件：```
dq[0] < j - (d + 1)
```桥最多允许跳跃`d`细胞，这意味着支持最多可能不同`d + 1`在索引中。 

第二阶段使用标准的行成本滑动窗口。 由于我们只需要连续的行，因此前缀总和或滚动总和都可以。

 ## 边缘情况

 考虑不需要中间支持的情况。 

输入：```
1
1 5 1 10
0 9 9 9 0
```第一个支撑位于第 1 列，最后一个支撑位于第 5 列。它们的差值为 4，因此跳过的单元格等于 3，即在`d = 10`。 

在 DP 期间，第 5 列可以直接从第 1 列过渡，因为：```
5 - 1 <= d + 1
```算法正确返回：```
1 + 1 = 2
```现在考虑一下差一陷阱。 

输入：```
1
1 3 1 1
0 100 0
```第 1 列和第 3 列的支持恰好跳过一个单元格，因此它们是有效的。 

DP窗口大小为`d + 1 = 2`，这允许这种转变。 该算法计算：```
1 + 1 = 2
```使用窗口大小的错误实现`d`会错误地强制昂贵的中间支撑。 

最后，考虑贪婪选择失败的情况。 

输入：```
1
1 6 1 1
0 1 100 1 100 0
```局部贪婪策略可能会选择第 2 列的廉价支持，然后被迫进入第 4 列，最后进入第 6 列。 

相反，DP 会评估每个可到达的先前支持并找到全局最优链。 双端队列保证这些转换得到有效处理而不会丢失正确性。
