 ## 解决方案
 ## 问题理解

 我们得到一系列水平线段，这些线段依次到达长度为一维的板上$d$。 每个段代表一个垂直下落的块，直到它接触地面或接触先前放置的某个块的顶部。 一旦它接触到某物，它要么永久附着，要么触发连锁反应，可能会擦除一些现有的块。 

关键规则取决于几何包含。 一块$a$据说完全覆盖了方块$b$如果$a$跨越超集区间：$l_a \le l_b \le r_b \le r_a$。 当一个新的方块落地时，它首先会下落，直到接触到已经存在的东西。 在接触的那一刻，两种情况出现了分歧。 如果它接触到它没有覆盖的方块，它就会粘在那里并成为结构的一部分。 相反，如果它接触的所有块都被它完全覆盖，那么那些被覆盖的块将被擦除，并且下落的块继续下降，直到它再次粘住或继续擦除。 

微妙之处在于，“接触”是纯粹的垂直堆叠，而“覆盖”则是纯粹的水平堆叠。 一个块可以在几何上与许多其他块重叠，但只有那些完全包含在其间隔中的块才有资格蒸发。 

我们必须在线处理区块。 每次插入后，我们都会报告总共剩余多少个块。 

限制因素$n, d \le 10^5$意味着任何解必须接近线性或$O(n \log n)$。 任何模拟新块与所有现有块之间交互的方法都会直接面临二次行为的风险，因为一个块可能会在更新过程中与许多其他块交互。 我们执行的操作必须支持快速范围查询和间隔更新。 

当每个新块跨越大部分范围时，显式跟踪所有现有块并重复检查哪些块被触摸或覆盖的简单模拟会立即失败，因为每次插入都可能扫描大部分活动块。 

当块部分重叠现有结构时，就会出现天真的贪婪推理的非明显失败案例。 例如，如果块$A=[1,3]$， 然后$B=[2,4]$， 然后$C=[1,4]$，天真的直觉可能表明$C$总是删除它重叠的所有内容。 然而，$C$只会蒸发它在接触时实际覆盖的块，无论接触发生在地面还是中间块都会改变相互作用。 对“第一次接触”的依赖使得局部推理变得不够充分。 

## 方法

 核心难点在于，每个区间插入既可以修改现有结构的范围，又取决于当前分层的几何形状。 然而，垂直过程可以用一种更简单的方式重新解释。 

我们不是模拟下落物理，而是将最终结构跟踪为一组不相交的“活动块”，它们代表每次操作后的当前稳定堆栈。 每个块要么作为最终结构的一部分保留下来，要么被完全覆盖它的后续块删除，同时也能够通过接触链到达它。 

关键的观察是，重要的不是垂直堆叠历史，而是新插入的间隔是否可以“桥接”现有结构，而不会被未覆盖的接触点阻挡。 当且仅当一个块在覆盖它并且能够在不遇到未覆盖的障碍物的情况下到达它的后续间隔内没有被完全移除时，该块才能生存。 

这可以转化为维护分段上的动态结构，在其中我们跟踪“最顶层的活动层”并有效地确定一个区间是否可以完全干净地覆盖。 

解决这个问题的标准方法是在坐标轴上维护一棵线段树，用于存储当前位置是否被活动块覆盖，以及允许我们识别间隔在被相同块标识覆盖方面是否一致的结构。 如果整个区间当前被同一个块（或空）覆盖，则新块可以覆盖它； 否则它会附着并停止。 

同样，我们维护一个具有延迟传播的线段树，它存储覆盖每个位置的当前“顶部块 ID”。 对于一个新块$[l, r]$，我们查询该区间中的所有位置当前是否具有相同的顶部块 id。 如果是，则意味着它将统一附加并可以覆盖该区域。 如果不是，则意味着它将遇到异质结构，因此将在第一次接触时粘住，不会造成删除。 

我们还维护幸存块的计数。 当一个块完全覆盖一个区域时，我们会减少与被覆盖的 id 相对应的不同幸存块的数量。 

关键的见解是，只有当新块完全且均匀地控制一个区域时，才会发生汽化。 任何混合接触都会阻止进一步向下传播，并将相互作用减少为简单的附着。 

这将问题简化为线段树上的范围查询和范围分配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟|$O(n^2)$|$O(n)$| 太慢了|
 | 具有延迟传播的线段树 |$O(n \log d)$|$O(d)$| 已接受 |

 ## 算法演练

 1.在坐标范围上构建线段树$[1, d]$，其中每个节点存储该区间是由单个块id统一覆盖还是混合覆盖。 这是快速检测新块是否与现有结构干净地交互所必需的。 
2. 对于每个传入的块$[l_i, r_i]$，查询线段树以确定整个区间当前覆盖范围是否均匀。 这告诉我们该块是否会向下传播（均匀）或在第一次接触时立即停止（非均匀）。 
3. 如果间隔不均匀，我们将块视为第一次接触时附着。 在这种情况下，它不会删除任何完全覆盖的结构，因此幸存块的数量保持不变。 
4. 如果间隔是均匀的，我们就识别出覆盖它的当前块id。 这意味着新块完全覆盖该区域。 我们减少该旧块的幸存计数（如果存在），因为它已被完全擦除。 
5. 然后我们更新线段树$[l_i, r_i]$，将新块 id 指定为整个区间的顶部覆盖 id。 这代表汽化后新的稳定层。 
6. 处理完每个块后，我们输出当前幸存块的数量。 

关键的不变量是每个线段树节点正确表示覆盖其线段的最顶层块的身份，或者如果该线段内多个块不同则表示混合状态。 这确保了对某个区间的任何查询都能准确反映该区间是否是同质的。 同质性正是一个块充分向下相互作用并可能蒸发先前块所需的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (4 * n)
        self.lazy = [0] * (4 * n)

    def push(self, v):
        if self.lazy[v]:
            self.tree[v*2] = self.lazy[v]
            self.tree[v*2+1] = self.lazy[v]
            self.lazy[v*2] = self.lazy[v]
            self.lazy[v*2+1] = self.lazy[v]
            self.lazy[v] = 0

    def update(self, v, l, r, ql, qr, val):
        if ql <= l and r <= qr:
            self.tree[v] = val
            self.lazy[v] = val
            return
        self.push(v)
        m = (l + r) // 2
        if ql <= m:
            self.update(v*2, l, m, ql, qr, val)
        if qr > m:
            self.update(v*2+1, m+1, r, ql, qr, val)

        if self.tree[v*2] == self.tree[v*2+1]:
            self.tree[v] = self.tree[v*2]
        else:
            self.tree[v] = -1

    def query(self, v, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.tree[v]
        self.push(v)
        m = (l + r) // 2
        res = None
        if ql <= m:
            res = self.query(v*2, l, m, ql, qr)
        if qr > m:
            right = self.query(v*2+1, m+1, r, ql, qr)
            if res is None:
                res = right
            elif res != right:
                return -1
            elif res == -1:
                return -1
        return res if res is not None else -1

def solve():
    n, d = map(int, input().split())
    st = SegTree(d)
    alive = set()
    res = []

    for i in range(1, n+1):
        l, r = map(int, input().split())
        cur = st.query(1, 1, d, l, r)

        if cur == -1:
            res.append(len(alive) + 1)
        else:
            if cur != 0:
                alive.discard(cur)
            alive.add(i)
            st.update(1, 1, d, l, r, i)
            res.append(len(alive))

    print("\n".join(map(str, res)))

if __name__ == "__main__":
    solve()
```线段树维护每个区间内最顶层块的标识。 值 0 表示空地，而正整数表示完全分配该段的最后一个块的 id。 查询函数检查间隔是否均匀。 如果不统一，则块会附加而不删除任何内容。 

套装`alive`跟踪当前存活的块 ID。 当一个块覆盖一个区域时，先前的统一所有者将被删除。 更新会在整个时间间隔内分配新的块 ID，确保将来的查询看到正确的顶部结构。 

微妙之处在于，只有完全一致的间隔才会触发删除。 混合间隔对应于首次接触阻塞，从而完全防止汽化。

 ## 边缘情况

 一个关键的边缘情况是每个间隔都相同。 在这种情况下，每个新块都会完全覆盖以前的结构。 线段树始终报告统一的覆盖范围，因此每次插入都会恰好删除一个旧块并替换它。 系统始终正确地维护单个幸存块。 

另一个边缘情况是当间隔形成阶梯图案时，例如$[1,2], [2,3], [3,4], \dots$。 每个新块仅部分重叠以前的块，从而产生不均匀的覆盖查询。 该算法在这里从不执行删除，因为没有任何间隔在其跨度上是完全一致的。 这正确地保留了所有块。 

最终的边缘情况是一个完全嵌套的序列，例如$[1,10], [2,9], [3,8], \dots$。 每个新块都会看到均匀的覆盖范围，直到它缩小活动区域。 线段树确保每次覆盖都是一致的，并防止部分不一致，因此随着时间的推移，嵌套会折叠成单个主导块。
