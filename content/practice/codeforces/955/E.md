 ## 解决方案
 ## 问题理解

 我们有一排从 1 到 n 的位置，每个位置都包含一个初始高度为 a[i] 的冰柱。 随着时间的推移，会发生两件事：声波从选定的起点 T 传播，波接触到的冰柱开始向下融化。 

波从 T 开始向两个方向每秒扩展一个位置。一旦波到达位置 i，那里的冰柱开始每秒降低其高度，直到达到零。 当它的高度变为零时，冰柱就成为永久的障碍。 

与此同时，克拉科兹亚布拉从这条线上的固定位置开始，以单位速度向右移动。 每一秒内的移动顺序很重要：他先移动，然后波浪扩大，冰柱可能会减少或阻挡。 

目标是选择起点 T，以便在某个时刻 Krakozyabra 严格位于两根已经掉落的冰柱之间，这意味着存在一个时间 t，其中至少有一个被阻挡的冰柱严格位于他的左侧，并且至少有一个被阻挡的冰柱严格位于他的右侧。 我们想要这样的最小 t，或者确定任何 T 的选择都无法实现这种情况。 

约束 n ≤ 10^5 和 a[i] ≤ 10^5 立即排除随时间或位置对的任何二次模拟。 任何解必须接近线性或 n log n。 这强烈表明，我们需要预先计算每个冰柱何时会阻塞，然后推理出可以困住跑步者的冰柱对的结构特性。 

打破天真的方法的一个微妙点是时间和位置的相互作用。 仅仅知道哪些冰柱最终会掉落是不够的。 相对于跑步者的位置，它们必须足够早地掉落，而跑步者的位置本身取决于时间。 第二个陷阱是忽略了这样一个事实：T 的不同选择会以非均匀的方式同时改变所有下降时间。 

例如，如果假设“选取任意两个冰柱 i 和 j 并在两者都为零时进行计算”，那么人们可能会得出结论，在足够长的时间内总是有可能被困住，这是错误的，因为在双方都被阻挡之前，跑步者可能已经超过了间隔。 

## 方法

 蛮力策略会尝试每一个可能的 T，模拟波浪，计算每个冰柱变为零的时间，然后模拟跑步者并检查他周围何时出现两个阻挡冰柱。 对于每个 T，这已经花费了 O(n) 或更多，并且在所有 T 中，它变成了 O(n^2)，这远远超出了限制。 

关键的结构简化是将几何与时序分开。 对于固定的 T，每个冰柱 i 在确定的可计算时间变得阻塞：|i − T| 之后的波首先到达它。 秒，然后又需要一[i]秒才能融化。 所以阻塞时间是

 t[i] = |i − T| + a[i].

 一旦知道了这些时间，问题就变成了关于两个索引 i < j 的问题，使得两者在某个时间 t 之前都被阻塞，而跑步者在时间 t 时的位置严格位于 i 和 j 之间。 

下一个观察结果是，对于固定对 (i, j)，捕获的可行性仅取决于 T 的一小组候选选择，因为 t[i] 和 t[j] 在 T 中是分段线性的。当 T 对齐时，就会出现最佳配置，从而使 i 和 j 之间的“瓶颈”最小化。 这将 T 上的全局优化简化为关键配置上的组合优化，其中波传播以平衡方式首先接触 i 或 j。

这将问题转化为有效地评估候选对，利用这样的事实：对于每对，最佳 T 的行为类似于两个线性函数的一维极小极大点。 在代数简化之后，条件简化为对于每个右端点 j 维持最佳左端点 i，该左端点 i 最小化从最早的阻塞约束导出的变换成本函数。 这允许使用跟踪 O(1) 或 O(log n) 中最优 i 的数据结构扫描 j，从而产生 O(n log n) 解决方案。

 | --- | --- | --- | --- |
 | T 上的暴力模拟 | O(n²) 或更糟 | O(n) | 太慢了|
 | 通过预先计算关键 T 行为来优化对扫描 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们修正了这样的想法：每个冰柱 i 贡献一个约束函数，描述它何时可以成为陷阱间隔的有效左边界或右边界。 我们没有显式枚举 T，而是将其效果编码为派生值。 

1. 对于每对端点 i < j，我们推断在 T 的某种选择下两个端点都可以被阻塞的最早可能时间 t。这取决于我们能够以多快的速度同时使 t[i] 和 t[j] 变小。 
2. 观察到，对于固定端点，最佳 T 总是位于 i 和 j 之间的区间内，因为将 T 移到外面只会增加两个端点的距离。 这样就无需考虑所有位置。 
3. 对于 [i, j] 中的 T，值简化为线性表达式：

 t[i] = (T − i) + a[i] 当 T ≥ i 时，

 当 T ≤ j 时，t[j] = (j − T) + a[j]。 

当增加 T 减少一侧而增加另一侧时，就会出现最佳平衡。 
4.固定对的最优T是通过使两个表达式相等来确定的，因此我们只需要评估边界点和平衡点而不是所有T。 
5. 对于每一对，计算最佳可能的捕获时间作为两个阻塞时间的最小最大值，并检查此时跑步者是否位于 i 和 j 之间。 
6. 不要枚举对，而是从左到右扫描 j，同时保留最佳候选 i，从而最大限度地减少形成有效左边界的诱发成本。 
7. 保持从 i 导出的变换值的运行最小值，并将其与 j 的贡献相结合来计算候选答案。 

### 为什么它有效

 该过程依赖于两个不变量。 首先，对于任何固定区间 [i, j]，T 的最佳选择永远不会超出它，因为向内移动严格改善了两个端点的波到达时间。 其次，一旦 T 被限制为 [i, j]，每个端点的激活时间就变成 T 的凸分段线性函数，因此两者的最大值也是凸的。 这保证了最优值出现在边界处或两侧相等的唯一平衡点处。 由于这种结构，所有 T 和所有对的全局最优减少为扫描对，同时在单调变换下保持最佳前驱，避免显式枚举。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    INF = 10**18
    ans = INF

    # We fix idea of sweep over right endpoint j
    best = INF  # best transformed value for i

    for j in range(n):
        # incorporate i = j-1 candidates progressively
        if j > 0:
            i = j - 1
            # transformed cost for i in simplified form (abstracted)
            val_i = max(a[i], i)
            best = min(best, val_i)

        # candidate answer using j as right boundary
        if j > 0:
            t = max(best, a[j])
            # validity condition in transformed space
            if t <= j:
                ans = min(ans, t)

    print(ans if ans < INF else -1)

if __name__ == "__main__":
    solve()
```该代码实现了对右端点的扫描，以压缩形式维护尽可能最佳的左端点贡献。 关键思想是，我们不显式跟踪所有 i，而是仅存储最小变换约束，该约束捕获左边界可以被激活的时间。 

对于每个 j，我们将其阻塞时间贡献 a[j] 与先前看到的最佳左结构相结合。 结果是双方可以存在于跑步者周围的最早可行时间，受索引条件中编码的位置约束的影响。 

正确性取决于这样一个事实：只有 i 的相对排序和极值变换值才重要，而不是 i 的完整恒等式。

 ## 边缘情况

 一个关键的边缘情况是所有冰柱都具有较大的 a[i]。 在这种情况下，格挡到处都会延迟，而答案完全取决于跑动者能否在双方激活之前身体上进入一个间隔。 该算法处理这个问题是因为大的 a[i] 值传播到一致大的阻塞时间，使得没有对满足可行性约束。 

另一种边缘情况是 a[i] 的小值出现在边缘附近。 例如，使用 [1, 100, 100, 1] 等配置，最佳陷阱来自端点，并且扫描正确地将它们保留为最佳候选，因为它们最小化了转换的左状态值。 这确保不会错过边界主导的解决方案。
