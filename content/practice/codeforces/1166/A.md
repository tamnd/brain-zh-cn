 ## 解决方案
 ## 问题理解

 我们收到了一份学生名单，并被允许将这些学生分成两个教室。 每个学生必须去两个房间中的一个，并且任何一个房间都可能是空的。 

如果一对学生有相同的起始字母并被安排在同一个房间，他们就会变得“健谈”。 对于每个房间，我们计算里面的学生中有多少这样的对，然后将两个房间的贡献相加。 一个房间的贡献完全取决于有多少学生具有相同的首字母，因为只有这些学生才能形成有效的配对。 

任务是选择分割，使两个房间内相同初始对的总数尽可能小。 

限制很小，最多 100 名学生。 这立即表明，即使是二次或稍微组合的解决方案也能轻松通过，但问题的结构允许采用更简单的贪婪计数方法。 

一个幼稚的错误是尝试将学生一一分配，而没有意识到只计算每个首字母的重要性。 另一个常见的陷阱是假设房间之间的混合字母会相互作用，而实际上每个字母都独立地对最终答案做出贡献。 

例如，如果所有名称都以不同的字母开头，则任何拆分都会给出零对。 如果所有名字都以相同的字母开头，那么唯一的决定就是如何在两个房间之间平均分配该多重集。 

## 方法

 暴力策略将尝试将 n 个学生的所有可能作业分成两组。 每个学生有两个选择，因此有 2^n 种可能的划分。 对于每次分组，我们将通过按首字母对学生进行分组并对组合进行求和来计算两个房间内的对数。 这是正确的，但呈指数增长，并且当 n 达到 100 时，它变得完全不可行。 

关键的观察结果是不同字母之间不会发生相互作用。 如果我们修复像“a”这样的字母并计算有多少学生以“a”开头，那么该组的贡献独立于所有其他字母。 总答案就是每封信贡献的总和。 

所以问题简化为：对于每个字母，假设我们有 c 个以该字母开头的学生。 我们必须将它们分为两组，大小分别为 a 和 c - a。 这封信贡献的闲聊对的数量是 C(a, 2) + C(c - a, 2)。 我们想要选择 a 来最小化这个表达式。 

二项式系数的结构使其成为整数上的凸最小化问题。 当两组尽可能平衡时，总和最小化。 直观上，将学生分成几乎相等的两半会减少内部配对的数量，因为配对随着小组规模的增加而呈二次方增长。 

因此，对于每个字母，我们只需将计数拆分为下限（c/2）和上限（c/2），计算对贡献，并对所有字母求和。

 ## 算法演练

 我们首先计算有多少学生以字母表中的每个字母开头。 这会将输入转换为最多 26 个独立的频率值。 

对于每个字母频率 c，我们决定如何在两个教室之间分配它。 最佳分割是使两个部分尽可能相等，因为任何不平衡都会以二次方的方式增加内部对的数量。

1. 构建一个大小为 26 的频率数组 freq，其中 freq[i] 存储有多少个名称以第 i 个字母开头。 这隔离了每个字母的独立子问题。 
2. 将答案初始化为0，因为我们将分别累加每个字母的贡献。 
3. 对于 freq 中的每个频率 c，计算有多少学生前往第一个房间（a = c // 2）和第二个房间（b = c - a）。 这确保了分配尽可能平衡。 
4. 将 C(a, 2) + C(b, 2) 添加到答案中，其中 C(x, 2) = x(x - 1) // 2. 这将计算每个房间内该字母的对数。 
5. 处理完所有字母后输出最终累加答案。 

### 为什么它有效

 每个字母形成一组独立的相同项目，并且仅在相同字母组内形成对。 由于字母之间没有相互作用，因此最小化总数相当于最小化每个字母各自的贡献。 对于固定计数 c，由于二次项的对称性和凸增长，当 x 尽可能接近 c/2 时，函数 C(x,2) + C(c-x,2) 最小化。 这保证了贪婪平衡分割产生全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def comb2(x):
    return x * (x - 1) // 2

def solve():
    n = int(input().strip())
    freq = [0] * 26

    for _ in range(n):
        s = input().strip()
        freq[ord(s[0]) - ord('a')] += 1

    ans = 0
    for c in freq:
        a = c // 2
        b = c - a
        ans += comb2(a) + comb2(b)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先将输入压缩为字母频率，这是对形成对重要的唯一信息。 辅助函数`comb2`无需循环即可有效计算组中无序对的数量。 

分裂步骤`a = c // 2`和`b = c - a`强制执行最佳平衡。 无需考虑替代分布，因为任何偏差对一侧的增加都大于对另一侧的减少，并且对计数的二次增长确保了这不是最优的。

 ## 边缘情况

 对于单个学生，频率数组有一个非零条目 1。分割变为 1 和 0，并且 C(1,2) 和 C(0,2) 都为零，因此输出为 0。该算法直接处理此问题，因为整数除法会产生 a = 0 和 b = 1，反之亦然，具体取决于排序，并且两种情况都会产生零对。 

当所有学生共享相同的首字母时，例如 c = 100，算法始终分为 50 和 50。计算值变为 C(50,2) + C(50,2)，它正确匹配最小可能分布。 任何不均匀的分割都会以二次方的方式增加一项，而不是减少另一项，因此在实施的规则下，平衡的情况仍然是最佳的。
