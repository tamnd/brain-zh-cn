 ## 解决方案
 ## 问题理解

 我们正在尝试构造一个长度的字符串$k$可以重新排列成矩形网格$n$行和$m$列，使得每行和每列包含所有五个元音：a、e、i、o、u 至少一次。 

构造规则确定了字符串如何映射到网格中：我们从左到右逐行填充。 所以第一个$m$字符构成第 1 行，下一行$m$形成第 2 行，依此类推。 一旦放入这个网格中，我们就不允许重新排列字符，因此最终的网格结构完全由字符串决定。 

关键要求非常严格：每行必须包含所有五个元音，每列也必须包含所有五个元音。 这立即迫使两个维度$n$和$m$至少为 5，否则一行或一列不可能包含所有元音。 

输入只是整数$k$，并且我们必须决定对于任何因式分解是否存在这样的网格$k = n \cdot m$，如果是，则输出任何有效的有效字符串。 否则输出-1。 

约束条件$k \le 10^4$意味着我们可以安全地尝试所有除数$k$在$O(\sqrt{k})$，因为最多存在大约 100 名候选人。 任何平方项$k$没有必要，但仍处于可接受的范围； 任何指数都是无关紧要的。 

主要的微妙之处在于该条件对于行或列来说并不是独立的。 一个天真的尝试可能会确保行包含所有元音，但列将失败，除非构造是仔细周期性的。 

一些边缘情况突出了结构：

 当$k = 7$，没有因式分解产生两者$n \ge 5$和$m \ge 5$，所以即使答案是不可能的$k$不小。 

什么时候$k = 25$，我们可以取$n = 5, m = 5$，并构造一个有效的网格。 

核心挑战是了解什么结构可以同时保证行和列的完整性。 

## 方法

 一个蛮力的想法是尝试每一个因式分解$k = n \cdot m$，并为每一对尝试构建一个网格。 对于每个候选网格，我们可以尝试随机填充或通过回溯来确保每一行和每一列都包含所有五个元音。 然而，即使对于单个固定对，搜索空间也是巨大的：每个单元格有 5 个选择，因此网格数为$5^{nm}$，即使对于中等尺寸也是完全不可行的。 

关键的观察结果是“每行包含所有元音”的要求已经强制了一个强大的结构：每行必须包含至少 5 个不同的字符，所以$m \ge 5$。 同样，每列的高度必须至少为 5，所以$n \ge 5$。 这将问题简化为寻找因式分解$k = n \cdot m$与两者$n \ge 5$和$m \ge 5$。 

一旦存在这样的因式分解，我们就可以构造一个周期性的 5×5 元音模式并将其平铺在网格上。 5x5 拉丁风格的循环结构确保每行和每列包含所有元音一次，并且在 5 的倍数上重复它可以保留该属性。 网格的其余部分只是这个基本结构的重复。 

所以问题完全归结为数论：$k$有一个除数$m$使得两者$m \ge 5$和$k/m \ge 5$？ 

如果是，我们构建网格； 否则，我们输出-1。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（网格搜索）| 指数$O(5^{k})$|$O(k)$| 太慢了|
 | 除数 + 构造 |$O(\sqrt{k})$|$O(k)$| 已接受 |

 ## 算法演练

 我们想要找到一个有效的矩形大小，然后以结构化的方式填充它。 

1. 迭代所有除数$m$的$k$。 对于每个除数，计算$n = k / m$。 我们只关心两个都存在的对$n \ge 5$和$m \ge 5$，因为较小的尺寸使得不可能将所有五个元音放在一行或一列中。 
2. 一旦找到这样的一对，我们就将其固定为网格尺寸。 此步骤是合理的，因为任何有效的解决方案都必须对应于某些因式分解$k$。 
3. 使用元音循环移位构建 5x5 基本模式。 这个想法是排列元音，使得每一行都是“aeiou”的旋转，并且每一列也循环所有元音。 
4. 将这个 5x5 块扩展为$n \times m$通过重复模 5 的行和列来网格。具体来说，单元格$(i, j)$元音分配基于$(i \bmod 5, j \bmod 5)$。 
5、将网格逐行压扁成长度的字符串$k$。 

如果没有找到有效的因式分解，我们返回 -1。 

### 为什么它有效

 该结构保证每一行都包含在长度为 5 的循环中重复五个元音的排列。由于每一行都是由相同的循环结构构建的，因此每一行至少包含一次所有元音。 这同样适用于列，因为列模式在循环移位之前都是相同的。 周期性确保扩展基本 5x5 结构可以保持行方向和列方向的完整性，无论重复多少个块。 

不变量是任何行或列中的每 5 个连续位置都包含元音的排列，并且该属性在重复下保留。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input().strip())
    
    vowels = "aeiou"
    
    # find valid factorization n x m
    n = m = -1
    for i in range(5, int(k**0.5) + 1):
        if k % i == 0:
            j = k // i
            if j >= 5:
                n, m = i, j
                break
            if i >= 5:
                n, m = j, i
    
    if n == -1:
        print(-1)
        return
    
    # build grid using cyclic pattern
    grid = []
    for i in range(n):
        row = []
        for j in range(m):
            row.append(vowels[(i + j) % 5])
        grid.append(row)
    
    # flatten
    res = []
    for i in range(n):
        res.extend(grid[i])
    
    print("".join(res))

if __name__ == "__main__":
    solve()
```该代码首先选择一个有效的因式分解$k$。 它只接受两边都至少为 5 的尺寸，因为较小的尺寸会立即违反行或列必须包含所有五个元音的要求。 

网格构造使用对角循环移位：入口$(i, j)$是由$(i + j) \bmod 5$。 这确保了向右或向下移动以固定排列的元音循环，从而保证了每行和每列的覆盖。 

最后，网格按行优先顺序展平，匹配问题的输入到网格的映射。 

## 工作示例

 ### 示例 1：k = 7

 两边都至少为 5 的情况下，不存在 7 的因式分解。唯一的对是 (1,7) 和 (7,1)，两者均无效。 

| 步骤| n | 米 | 有效的？ | 行动|
 | --- | --- | --- | --- | --- |
 | 检查 1×7 | 1 | 7 | 没有| 行太小|
 | 检查 7×1 | 7 | 1 | 没有| 列太小 |

 该算法找不到有效的网格并输出 -1。 这符合要求，因为单个行或列不能包含所有五个元音。 

### 示例 2：k = 25

 我们可以选择$n = 5, m = 5$。 

| 我| j | (i+j)%5 | 信|
 | --- | --- | --- | --- |
 | 0 | 0 | 0 | 一个 |
 | 0 | 1 | 1 | 电子|
 | 0 | 2 | 2 | 我|
 | 0 | 3 | 3 | 哦|
 | 0 | 4 | 4 | 你|

 第 0 行已包含所有元音。 每隔一行都是这一行的循环移位。 

同样的模式也适用于列，因为列$j$也是跨行循环移位。 

长度为 25 的扁平字符串在构造上是有效的。

 ## 边缘情况

 对于$k = 1$，算法立即无法找到任何两边均≥ 5 的除数对，因此返回 -1。 这是正确的，因为单个字符甚至不能满足一行要求。 

对于像这样的素值$k = 11$，唯一的因式分解是 (1,11) 和 (11,1)，两者均无效。 除数扫描可以清楚地检测到这一点。 

对于复合值，例如$k = 30$，我们可以选择$5 \times 6$。 该构造使用 5 循环模式，并且行和列完整性都成立，因为两个维度都超过或等于 5，从而允许两个方向上的完整循环。
