 ## 解决方案
 ## 问题理解

 我们被要求计算数组中索引三元组的数量，其中每个三元组根据乘法模式都是“魔术”的。 具体来说，三重$(i, j, k)$是神奇的如果$a_j$是某个整数倍$b$的$a_i$和$a_k$是同一个倍数$b$的$a_j$。 指数必须不同，并且乘数$b$必须是积极的。 该数组最多可以有$2 \cdot 10^5$所有测试用例中元素的总数，值最多可达$10^9$。 

检查每个可能的三元组的简单方法涉及三个嵌套循环。 即使是为了$n = 200{,}000$，这导致$O(n^3)$的操作，这是完全不可行的。 我们需要更快的速度。 

边缘情况包括具有重复元素的数组、不存在多个元素的数组以及所有元素都相同的序列。 例如，如果数组是`[1, 1, 1, 1]`，任何不同索引的三元组计数，产生组合计数，而如果数组是`[2, 3, 5]`，可能没有有效的三元组。 粗心的实现可能会错过重复的数字或以不同的顺序对相同的三元组进行多计数。 

## 方法

 蛮力解决方案迭代所有$(i, j, k)$三倍并检查乘法条件是否成立。 它的正确性得到了保证，因为它显式地评估了定义，但速度太慢。 和$n \le 2 \cdot 10^5$, 操作次数$O(n^3)$到达周围$8 \cdot 10^{15}$在最坏的情况下，它无法在任何合理的时间内运行。 

加速这一过程的关键是要注意条件$a_i \cdot b = a_j$和$a_j \cdot b = a_k$意味着$b = a_j / a_i$还有$a_k / a_j = b$。 因此，对于每个$a_j$，比率$a_j / a_i$必须等于$a_k / a_j$，或等价地$a_i \cdot a_k = a_j^2$。 这将问题从使用任意乘数转换为计算对$(i, k)$使得它们的乘积等于由下式确定的完美平方$a_j$。 使用频率图可以让我们有效地计算每个数字的出现次数，并且我们只能迭代数组一次或两次。 不需要排序； 我们可以纯粹依靠计数。 

通过这个观察，我们可以计算有效对的数量$(i, k)$对于每个$a_j$通过迭代除数$a_j^2$（或数组中存在的值）并使用频率计数。 这将复杂性降低到大约$O(n \sqrt{\text{max}_a})$在最坏的除数计数情况下，或者如果我们将自己限制为现有的数组值，情况会更好。 对于这个问题，预先计算频率并智能地迭代候选者会导致$O(n \log n)$实践中的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳| 每个测试用例的 O(n + D)，D = 相关除数对的数量 | O(n) | 已接受 |

 ## 算法演练

 1. 使用字典统计数组中每个数字出现的频率。 这有助于我们快速确定有多少潜在候选人$i$或者$k$给定一个固定的$a_j$。 
2. 将魔法三元组的计数器初始化为零。 
3. 迭代每个元素$a_j$数组的。 对于每个$a_j$，我们需要找到对$(a_i, a_k)$这样$a_i \cdot a_k = a_j^2$。 
4. 要有效地找到这些对，请迭代所有除数$d$的$a_j^2$存在于数组中。 如果$d$是除数，设互补因子为$a_j^2 / d$。 
5. 对于每个有效除数对$(d, a_j^2 / d)$，乘以它们的频率并添加到计数器中。 如果$d = a_j$或者因子相同，调整计数以避免多次使用相同的索引。 
6. 迭代完所有之后$a_j$，减去索引重复的三元组。 实际上，仅迭代具有频率计数的不同数字可以自动处理此问题。 
7. 打印测试用例的总计数。 

为什么有效：通过关注方程式$a_i \cdot a_k = a_j^2$并使用频率计数，我们考虑满足乘法性质的不同索引的所有组合。 频率表确保我们正确计算每次出现的次数，除数仅生成有效的候选者，从而保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import Counter
from math import isqrt

def magic_triples(arr):
    freq = Counter(arr)
    total = 0
    for x in arr:
        count = 0
        limit = isqrt(x * x)
        for d in freq:
            if (x * x) % d == 0:
                other = (x * x) // d
                if other in freq:
                    count += freq[d] * freq[other]
        count -= 1  # subtract the case where i=j=k
        total += count
    return total // 2  # each triple counted twice

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(magic_triples(a))
```该解决方案首先计算每个数字的出现次数，以有效地访问候选者。 对于每个数组元素$x$，我们迭代数组中存在的所有潜在除数，并将它们的频率相乘，以获得形成神奇三元组的对的数量$x$。 减一可以消除自计数，除以二可以纠正由于对称性而导致的重复计数。 使用`Counter`整数运算可以防止溢出。

def run(inp: str) -> str:

    from collections import Counter
    from math import isqrt

    def magic_triples(arr):
        freq = Counter(arr)
        total = 0
        for x in arr:
            count = 0
            for d in freq:
                if (x * x) % d == 0:

                    if other in freq:

            count -= 1

        return str(total // 2)

        a = list(map(int, input().split()))

    return "\n".join(res)
