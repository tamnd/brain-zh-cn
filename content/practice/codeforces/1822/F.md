 ## 解决方案
 ## 问题理解

 我们有一棵以顶点 1 为根的树，其中每条边的长度都相同。 树的“成本”就是最远的顶点距当前根的距离。 由于所有边都具有相同的权重，因此该成本只是树的高度乘以边的长度。 

不同的是，我们可以移动根部，但只能沿着边缘移动，一次移动一步。 每次移动都会将根移动到相邻的顶点并花费固定数量的硬币。 经过任意次数的此类移动后，我们从新的根再次评估树成本，并减去总移动成本。 目标是选择使最终利润最大化的根移动序列。 

输入是一棵树，因此任何一对顶点之间都没有循环并且只有一条简单路径。 这种结构至关重要，因为每个根部运动实际上都是在这棵树上行走。 

这些约束强制采用线性或近线性解决方案。 由于测试用例中总共有多达 200,000 个顶点，任何从头开始重新计算每个可能根的距离的解决方案都会失败。 即使每个候选根的 BFS 或 DFS 也会导致二次行为，这远远超出了可接受的范围。 

当贪婪地思考时，就会出现一个微妙的问题。 一个天真的想法是不断将根部移向树的更深部分以增加高度。 这会失败，因为每次移动都有成本，并且增加深度并不一定会增加根的整体偏心率。 

另一个常见的陷阱是假设最佳最终根必须是直径的质心或中点。 这还不够，因为我们不是选择静态根，而是付费步行到它。 

真正的困难在于，移动成本取决于所采取的路径，而树成本仅取决于最终的根。 

## 方法

 强力解释是考虑每一个可能的根移动序列。 从给定的根开始，我们尝试移动到任何邻居，递归地探索所有状态，并计算所得的利润。 这立即爆炸了，因为状态空间本质上是树上的所有游走，而树的深度是指数级的。 

即使我们将自己限制在最终的根位置，我们仍然需要计算每个节点到最远节点的距离（其偏心率）。 使用 BFS 或 DFS，该部分的每个节点的复杂度已经是 O(n)，从而导致每个测试用例的复杂度为 O(n²)。 

关键的观察是我们永远不需要显式模拟所有运动路径。 移动根的成本与遍历的边数成正比，因此如果我们固定最终的根，则移动成本恰好是树中从 1 到该根的距离乘以 c。 

所以问题简化为选择一个节点 v 来最大化：

 利润(v) = 偏心率(v) * k - 距离(1, v) * c

 现在这是对节点的树 DP 式优化，其中每个节点需要两个量：距原始根的距离及其偏心率。 

通过 DFS 或 BFS 可以直接计算到根 1 的距离。 偏心率需要经典的树技巧：两次 BFS 遍历。 首先找到直径的一个端点，然后从中找到最远的节点，然后计算距两个端点的距离。 任何节点的偏心率是其到两个直径端点的距离的最大值。 

一旦这些值被预先计算，评估每个节点就变成线性的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 路径上的暴力破解 | 指数| O(n) | 太慢了 |
 | 计算偏心率 + 评估所有根 | O(n) | O(n) | 已接受 |

 ## 算法演练

1. 从节点 1 运行 BFS/DFS 来计算 dist1[v]，即从原始根到每个节点 v 的距离。这捕获了将根移动到 v 的总成本，因为每次移动都是一条边，成本为 c。 
2. 通过从任意节点（通常是节点 1）运行 BFS 来查找树直径的一个端点。将此端点称为 a。 
3. 从 a 运行 BFS 来计算距离 da[v]。 然后找到距离a最远的节点，称之为b。 
4. 从 b 运行另一个 BFS 来计算距离 db[v]。 
5. 对于每个节点 v，计算其偏心率 max(da[v], db[v])。 这是可行的，因为在树中，距 v 最远的节点始终是直径端点之一。 
6. 对于每个节点 v，将候选利润计算为 ecc[v] * k - dist1[v] * c。 
7. 返回所有节点上的最大值。 

我们可以将偏心率计算限制为直径端点的原因是，在一棵树中，所有最长的路径都经过直径，因此任何最远的节点都必须位于其端点之一。 

### 为什么它有效

 该算法清楚地分离了两种相互竞争的效果：移动根沿着树边缘具有线性成本，而收益仅取决于新根距离最远叶子的距离。 这两个量都是基于路径的，并且可以使用 BFS 距离来完全捕获。 直径端点提供了一个限制所有偏心率的全局结构，确保不会错过任何节点的最远距离。 因为每个可能的最终状态都由一个节点唯一表示，并且每个这样的节点只被评估一次，所以最大计算值是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def bfs(start, adj):
    n = len(adj) - 1
    dist = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

t = int(input())
for _ in range(t):
    n, k, c = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    dist1 = bfs(1, adj)

    a = max(range(1, n + 1), key=lambda x: dist1[x])
    da = bfs(a, adj)
    b = max(range(1, n + 1), key=lambda x: da[x])
    db = bfs(b, adj)

    ans = 0
    for v in range(1, n + 1):
        ecc = max(da[v], db[v])
        ans = max(ans, ecc * k - dist1[v] * c)

    print(ans)
```第一个 BFS 修复了到达任何潜在最终根的成本。 第二次和第三次 BFS 计算定位直径端点，从而可以在恒定时间内导出每个节点的偏心率。 

最后的循环直接评估每个可能的根。 k 和 c 的乘法始终保持为整数运算，避免了精度问题。 

一个微妙的实现细节是，我们不会从每个节点重新计算 BFS，因为这将是二次的。 相反，我们重用直径结构，这将偏心率计算减少到线性时间。

 ## 边缘情况

 星形树是直觉可能失败的最明显例子。 中心具有最小的偏心率，但运动成本为零，而叶子具有最大的偏心率，但运动成本较高。 该算法正确评估两者并根据净利润进行选择。 

在路径图中，每个节点都位于直径上，因此偏心率等于到一个端点或另一个端点的距离。 BFS-from-diameter-ends 方法正确地为每个节点分配最远距离，而不需要每个节点的 BFS。 

当 k 比 c 小时，移动根永远没有好处。 该算法仍然可以处理这个问题，因为 dist1 * c 项主导所有增益，并且最大值自然出现在节点 1 处。
