 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们可以删除任何元素子集，同时保留剩余元素的相对顺序。 删除后，我们必须保留至少两个元素，并且通过查看所有相邻对并取其中的最大乘积来评估结果数组。 目标是选择保留哪些元素，以使最大相邻乘积尽可能大。 

关键细节是，删除允许我们“连接”任何两个最初不相邻的幸存元素。 所以问题不在于原始邻居，而在于选择任何一对索引$i < j$删除之间的所有内容并最大化后变得连续$a_i \cdot a_j$。 

约束允许最多$2 \cdot 10^5$测试用例中的元素总数，这立即排除了所有对或所有子序列的任何二次探索。 显式尝试所有对或模拟删除的解决方案会太慢，因为单个测试用例可能已经需要大约$10^{10}$最坏情况下的操作。 

当仅考虑原始数组中的相邻元素时，会出现微妙的故障模式。 例如，在像这样的数组中$[1, 100, 2]$，最佳邻接积为$100$，但是删除后我们可以选择$[1, 2]$要得到$2$，哪个更糟，或者$[100]$无效。 然而，更有趣的情况涉及跳过元素来连接最初不相邻的遥远的大值。 

另一个边缘情况是负数。 只考虑大绝对值的简单方法会失败，因为乘积取决于符号，并且最大乘积可能来自两个负数。 

## 方法

 蛮力的想法很简单：考虑每个大小至少为 2 的子集，计算其最佳相邻乘积，并跟踪最大值。 即使我们限制自己在删除后检查对，我们仍然有效地考虑所有索引对$(i, j)$和$i < j$，因为任何这样的对都可以通过删除其间的元素来变得相邻。 对于每一对，我们计算$a_i \cdot a_j$并取最大值。 

这立即变成$O(n^2)$每个测试用例，当它太大时$n$达到$2 \cdot 10^5$。 

关键的观察是删除使我们能够完全忽略结构。 任何两个选定的元素都可以变得相邻，因此最终答案只是所有对的最大乘积$i < j$。 这将问题简化为选择最佳对，而不是排列顺序。 

一旦认识到这一点，任务就变成寻找数组中两个数字的最大乘积。 唯一的微妙之处在于符号：最大乘积可以来自两个最大的正数，也可以来自两个最小（最大的负数）数。 

因此，我们只需要跟踪四个候选值：两个最大值和两个最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 扫描一次数组，同时维护迄今为止看到的两个最大值和两个最小值。 

我们维持这些极端情况是因为任何最佳对都必须来自这些边界情况之一。 
2. 对于每个元素$x$，更新最大对$(max1, max2)$以便$max1 \ge max2$，并类似地更新最小对$(min1, min2)$以便$min1 \le min2$。 

这确保我们始终保留做出积极和消极贡献的最佳候选人。 
3. 处理完所有元素后，计算两个候选答案：$max1 \cdot max2$和$min1 \cdot min2$。 
4. 返回这两个值中的最大值。 

我们分为这两种情况的原因是乘法在符号变化下的表现不同。 大的正值直接使乘积最大化，而大的负值相乘时可以产生大的正乘积。 

### 为什么它有效

 任何最优解仅取决于两个选定的指标$i < j$。 由于删除后任何对都可以变得相邻，因此问题简化为选择两个元素以最大化它们的乘积。 最好的这样的对必须来自极值：两个最大的数字或两个最小的数字。 任何内部值都不能胜过这些组合，因为在正确的配对情况下，用更极端的值替换所选元素总是会改进或保持乘积的绝对贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # initialize extremes
        max1 = max2 = -10**30
        min1 = min2 = 10**30
        
        for x in a:
            # update max pair
            if x > max1:
                max2 = max1
                max1 = x
            elif x > max2:
                max2 = x
            
            # update min pair
            if x < min1:
                min2 = min1
                min1 = x
            elif x < min2:
                min2 = x
        
        ans = max(max1 * max2, min1 * min2)
        print(ans)

if __name__ == "__main__":
    solve()
```该实现在一次传递中跟踪两个最大和两个最小值。 初始化使用非常大的哨兵值来确保正确更新，即使所有数字均为负数或均为正数。 

两个候选产品之间的最终比较至关重要，因为它捕获了正对优势和负对优势。

 ## 边缘情况

 当数组同时包含大的正数和大的负数时，就会出现一种棘手的情况。 例如，$[-100, 1, 2, 3, 4]$。 该算法跟踪两个极端，因此最大对变为$4 \cdot 3 = 12$，而最小对不具有竞争力，因为只有一个大的负值。 

为了$[-5, -6, 2]$，跟踪值以 max1 = 2、max2 = -5 和 min1 = -6、min2 = -5 结束。 该算法评估$2 \cdot -5 = -10$和$(-6) \cdot (-5) = 30$，正确选择负对。 

在有零的情况下，例如$[0, -1, -2]$，零自然包含在最大跟踪中，但不干扰最小对，确保正确答案来自$(-1) \cdot (-2)$。
