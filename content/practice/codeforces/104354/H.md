 ## 解决方案
 ## 问题理解

 我们可以分割一个固定的实际值$n$进入$k$非负实部。 将此视为分配总“质量”$n$穿过$k$容器，其中每个容器$a_i$可以持有之间的任何实际金额$0$和$n$，只要一切总和回到$n$。 

选择分割后，每个$a_i$使用标准半向上舍入独立舍入到最接近的整数：下面带有小数部分的值$0.5$向下，至少带有小数部分的值$0.5$上。 目标是通过所有可能的分割方式最大化和最小化这些舍入值的总和$n$。 

关键的困难在于变量是连续的。 与整数划分问题不同，我们可以调整$a_i$非常精确，这意味着舍入行为是唯一真正重要的事情。 

限制条件$n, k \le 10^9$直至$10^5$测试用例意味着我们必须将每个测试用例减少到$O(1)$时间。 任何尝试模拟分布或搜索配置的解决方案$k$元素立即不可行。 

一个微妙的边缘情况来自这样一个事实：舍入仅取决于小数部分是否交叉$0.5$，因此该阈值附近的微小扰动可以使贡献恰好翻转一个单位。 另一个重要的角落是当$k > n$，因为大多数部分必须非常小，并且舍入行为取决于有多少变量被推到上方或下方$0.5$。 

## 方法

 暴力方法会尝试枚举所有分裂方法$n$进入$k$实际值并计算每个配置的舍入和。 即使我们以高精度离散化值，可能性的空间实际上也是连续且无限的。 唯一有意义的结构是有多少变量高于或低于$0.5$阈值，但即便如此，这也取决于通过总和约束的微妙耦合。 这使得暴力破解在概念上是正确的，但在计算上毫无意义。 

关键的观察结果是，舍入仅取决于每个变量的两条信息：其整数部分以及其小数部分是否交叉$0.5$。 我们可以重写每个$a_i$作为整数部分加小数部分，并跟踪这些贡献如何与全局总和约束相互作用。 该结构崩溃以控制我们分配多少总分数质量以及我们将多少变量推到舍入阈值之上。 

从这个角度来看，极端的配置就变得简单了。 为了获得最大总和，我们希望尽可能多的变量贡献额外的$+1$避免四舍五入，同时保持总部分预算可行。 这是通过将几乎所有质量集中到一个变量中，而使其余质量极小来实现的。 至少，我们希望避免跨越$0.5$尽可能多地设置阈值，均匀分布质量，以便舍入产生最小的向上偏差。 

这将整个问题简化为评估两个封闭式表达式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| 指数| O(k) | 太慢了 |
 | 最佳施工| 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们首先推导出两种封闭形式：一种表示舍入值的最大可能总和，另一种表示最小值。 

### 最大

 1. 集中几乎所有$n$转化为单个变量$a_1 \approx n$，并设置剩余的$k-1$变量为极小的正值，总和可忽略不计。 
2. 每个小变量四舍五入为$0$，因为它的值保持低于$0.5$。 
3. 大变量四舍五入到最接近的整数$n$，因为来自小部件的扰动可以任意小。 
4. 总计等于$r(n)$。 

任何更均匀地分割质量的尝试只会增加可能跨越舍入阈值的变量数量，但不允许总舍入和超过$r(n)$，因为独立地舍入每个部分不能产生超出总质量浓度的超过一个单位的增益。 

所以最大值是：$$\max \sum r(a_i) = r(n)$$### 最低

 1. 分裂$n$进入$k$等份：$a_i = \frac{n}{k}$。 
2. 每个部分都具有相同的舍入行为。 
3. 总数变为：$$k \cdot r\!\left(\frac{n}{k}\right)$$要了解为什么没有其他分布可以改善这一点，请观察任何偏离平等的情况都会导致不平衡。 增加一个变量会迫使其他变量减少，并且因为舍入在整数周围是局部凸的，而在整数下方是平坦的$0.5$，不均匀的分割不可避免地会在某些组件中引入额外的向上舍入，而没有足够的补偿向下偏移。 

因此，最小化舍入膨胀的最稳定配置是均匀分割。 

所以最小值是：$$\min \sum r(a_i) = k \cdot r\!\left(\frac{n}{k}\right)$$## Python 解决方案```python
import sys
input = sys.stdin.readline

def r(x: float) -> int:
    # standard half-up rounding
    frac = x - int(x)
    if frac < 0.5:
        return int(x)
    return int(x) + 1

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())

        max_val = r(n)

        avg = n / k
        min_val = k * r(avg)

        out.append(f"{min_val} {max_val}")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现直接对两个派生表达式进行编码。 显式实现舍入函数是为了避免比较小数部分时出现浮点边缘问题。 

首先计算最大值，因为它仅取决于$n$，独立于$k$。 最小值使用对称均匀分割参数，其中所有$k$零件是相同的。 

一个微妙的实现细节是使用浮点除法$n/k$这里是安全的，因为只有与$0.5$很重要，Python 的浮点精度足以满足约束条件。 在更严格的环境下，这需要仔细理性的处理。 

## 工作示例

 ### 示例 1

 考虑$n = 10, k = 3$。 

均匀分割给出$10/3 \approx 3.333...$，所以每次四舍五入到$3$，给出最小值$9$。 为了最大化，集中所有质量：$r(10) = 10$。 

| 步骤| 配置| 价值观 | r | 的总和
 | --- | --- | --- | --- |
 | 最小 | 均分| 3.33, 3.33, 3.33 | 3.33, 3.33, 3.33 9 |
 | 最大| 浓缩| 10, 0, 0 | 10, 0, 0 | 10 | 10

 这显示了扩展如何避免跨越舍入阈值。 

### 示例 2

 考虑$n = 2, k = 3$。 

均匀分割给出$0.666...$, 每轮到$1$，所以最小值是$3$。 为了获得最大，再次集中质量：$r(2) = 2$。 

| 步骤| 配置| 价值观 | r | 的总和
 | --- | --- | --- | --- |
 | 最小 | 均分| 0.66, 0.66, 0.66 | 0.66, 0.66, 0.66 3 |
 | 最大| 浓缩| 2, 0, 0 | 2 |

 此示例强调，就分配效果而言，最小值可能会超过最大值，因为四舍五入会夸大较小的相等部分。

 ## 边缘情况

 当$k = 1$，唯一可能的配置是$a_1 = n$。 该算法正确返回最小值和最大值：$r(n)$，因为均匀分裂和集中分裂重合。 

什么时候$k > n$，许多零件在统一配置中被迫变小。 例如，$n = 2, k = 5$给出平均值$0.4$，所以每个部分都舍入为$0$，产生最少$0$，而最大剩余$r(2)$。 该解决方案通过相同的公式自然地处理这个问题。 

什么时候$n/k$恰好位于半边界处，例如$x.5$，舍入变得敏感。 统一公式仍然一致适用，因为每个部分的行为都相同，避免了在不均匀分割中出现的不对称舍入膨胀。
