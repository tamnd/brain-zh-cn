 ## 解决方案
 ## 问题理解

 我们得到一个非负整数序列。 从这个序列中我们必须准确选择$k$元素，同时保留其索引的相对顺序。 一旦我们选择了这些$k$值时，我们会查看所选值之间的所有成对绝对差异。 

有两个量很重要：所选集合中任何对之间的最小差异，以及所选集合中任何对中的最大差异。 我们将这两个值相乘，目标是选择大小的子集$k$最大限度地减少该产品。 

如果我们将所选值排序为$b_1 \le b_2 \le \dots \le b_k$，那么最大的两两差异就是$b_k - b_1$。 最小的成对差异是其中的最小值$|b_{i+1} - b_i|$。 所以目标变成最小化$$(\min_{i} (b_{i+1} - b_i)) \cdot (b_k - b_1).$$输入大小可达$5 \times 10^5$，所以任何解决方案都比$O(n \log n)$不会通过。 甚至$O(n^2)$对所有子集的构造是完全不可能的，因为可供选择的方法数量太多$k$元素是组合的。 

一个微妙的问题是，最优子集在原始数组中并不明显连续，但它完全由排序后值的相对顺序控制。 另一个隐藏的陷阱是假设只有范围很重要。 如果范围非常小的子集包含非常小的内部间隙，那么它仍然可能很糟糕，这会严重影响产品。 

一个小的说明性失败案例是当值聚集在一起但包含一对非常紧密的值并且以其他方式分散值时。 贪婪的“取最接近值”方法可能会选择一个非常小的间隙，但会意外地增加范围，从而使产品比稍宽但更均匀的选择更糟糕。 

## 方法

 暴力解决方案将枚举大小的所有子集$k$，计算排序后的选定值，然后评估最小相邻差值和范围。 这是正确的，但立即失败，因为子集的数量是$\binom{n}{k}$，这是指数级的，即使对于中等程度也是不可行的$n$。 

关键的结构观察是，一旦对值进行排序，最佳子集的行为就像这个排序数组上的滑动窗口。 当所有选定元素按排序顺序位于连续块中时，任何选定子集的范围都会最小化。 如果子集跳过其最小或最大跨度内的元素，则用内部跳过的元素替换外部元素只能缩小范围，而不会以有助于产品的方式恶化最小间隙。 这推动解决方案仅考虑连续的长度段$k$在已排序的数组中。 

一旦我们修复了一个窗口$k$连续排序的元素，范围固定为端点之间的差异。 剩下的任务是有效地计算每个窗口内的最小相邻差异。 这可以通过滑动窗口多重集或跟踪相邻间隙的平衡结构来维持。 

所以我们将问题简化为扫描所有大小的窗口$k$按排序顺序并根据两个维护量评估产品：窗口范围和最小相邻间隙。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 |$O(\binom{n}{k} \cdot k \log k)$|$O(k)$| 太慢了 |
 | 排序滑动窗口|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 最优策略

 1. 按非降序对值数组进行排序。 排序后，任一候选子集对应选择$k$此有序列表中的元素。 
2. 考虑每个连续的长度块$k$在已排序的数组中。 每个块代表一个候选集，其范围只是其最后一个元素和第一个元素之间的差异。 这个限制是有效的，因为任何最优解都可以转换为连续的块而不增加目标。 
3. 对于每个窗口，将范围计算为$a[r] - a[l]$在哪里$r = l + k - 1$。 
4. 维护一个跟踪当前窗口内相邻元素之间差异的结构。 对于开始于$l$， 这些都是$a[i+1] - a[i]$为所有人$i \in [l, r-1]$。 
5. 使用多重集（或平衡结构）来存储这些相邻间隙。 对于每个窗口移动，删除离开窗口的间隙并插入进入窗口的新间隙。 
6. 对于每个窗口，最小间隙是多重集中的最小元素，并且范围是直接已知的。 计算他们的乘积并更新答案。 

### 为什么它有效

 正确性依赖于排序后两个链接的单调行为。 首先，当子集按排序顺序连续时，任何子集的范围都会最小化，因为极值之间的任何跳过元素只能缩小跨度（如果包含）。 其次，对于一组固定的$k$排序后的元素，最小相邻差完全决定了最小成对间隙。 因此，一旦我们将注意力限制在连续的窗口上，我们就不会失去任何可以改善目标的候选者，并且我们只会对每个有效配置进行一次评估。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from bisect import bisect_left
from collections import deque
import heapq

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    if k == 2:
        # special case: min gap = max gap = difference
        ans = float('inf')
        for i in range(n - 1):
            d = a[i+1] - a[i]
            ans = min(ans, d * d)
        print(ans)
        return

    # compute adjacent differences
    diff = [a[i+1] - a[i] for i in range(n - 1)]

    # multiset via heap + lazy deletion
    import collections
    cnt = collections.Counter()

    heap = []

    def add(x):
        cnt[x] += 1
        heapq.heappush(heap, x)

    def remove(x):
        cnt[x] -= 1

    def clean():
        while heap and cnt[heap[0]] == 0:
            heapq.heappop(heap)

    # initial window
    for i in range(k - 1):
        add(diff[i])

    ans = float('inf')

    for l in range(n - k + 1):
        r = l + k - 1

        clean()
        min_gap = heap[0]
        range_val = a[r] - a[l]
        ans = min(ans, min_gap * range_val)

        if r == n - 1:
            break

        # slide window
        remove(diff[l])
        add(diff[r])

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先对数组进行排序，将所有候选子集对齐到单个线性结构中，其中范围易于计算。 数组`diff`存储相邻间隙，它们是任何窗口内最小成对差异的唯一候选者。 

推拉窗过去了`diff`完全对应于滑动尺寸-$k$阻塞已排序的数组。 堆用于有效地维护最小间隙，而计数器执行延迟删除，因为否则堆删除不是直接的。 

特殊情况$k=2$是单独处理的，因为在这种情况下，乘积简化为单个差的平方，并且我们只需要排序数组中的最小相邻对。

 ## 边缘情况

 关键的边缘情况是所有值都相同。 该算法自然地处理这个问题，因为所有相邻差异都为零，因此每个窗口产生零乘积，答案为零。 

另一个边缘情况是$k=2$，问题归结为最小化$(a_j - a_i)^2$。 代码通过在排序后扫描相邻差异来显式处理此问题，这保证了找到全局最小差异。 

最后，具有极端离群值的情况（例如单个非常大的值与聚集的小值混合）证实排序加窗口正确地隔离了包含离群值是否有益。 在此类窗口中，范围会变大，并且产品会立即反映这一点，从而防止意外选择不稳定的子集。
