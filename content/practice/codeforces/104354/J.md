 ## 问题理解

 我们为每个测试用例提供了一个固定的几何设置：三个点$P, A, B$形成一个非退化的等腰三角形$PA = PB$，和一条线段$AB$充当“刀片”。 从点$P$，我们可以快速移动角色$v$至多$t$秒，所以最终位置$Q$可以是中心在封闭圆盘内或封闭圆盘上的任意点$P$有半径$R = v \cdot t$。 

对于任何此类可到达的端点$Q$，损伤区域为三角形$QAB$。 如果平面上的一点至少存在一个可到达的点，则该点被认为是危险的$Q$使得该点位于三角形内部或三角形上$QAB$。 任务是计算所有这些三角形在所有可行位置上的并集面积$Q$。 

所以从几何角度来说，我们取的是一个固定线段$AB$，并扫描一个三角形，其第三个顶点$Q$移动到以$P$。 输出是所有这些三角形的并集面积。 

约束条件$T \le 2 \cdot 10^4$强烈建议$O(1)$或每个测试用例非常低的常数几何公式。 坐标很大，但只有相对几何形状很重要。 这排除了任何离散化或采样方法，因为即使$10^7$每个测试用例的样本会太慢。 

一个微妙的问题是，并集不仅仅是“一个三角形加上一些偏移”。 作为$Q$三角形不断移动$QAB$扫描弯曲区域，其边界部分由直线段组成，部分由旋转段引起的圆弧组成$QA$和$QB$大约$A$和$B$。 

一个天真的错误是认为答案只是三角形的面积$PAB$加上一些成比例的东西$R$，或者将并集视为三角形与圆盘的 Minkowski 和。 这是不正确的，因为三角形中只有一个顶点可以自由移动，而其他两个顶点是固定的，从而产生“三角形扇形”而不是均匀的偏移。 

重要的边缘情况：

 当$R = 0$，我们只有$Q = P$，所以答案正是三角形的面积$PAB$。 如果没有正确减少，任何假设扩展的公式都会在这里失败。 

什么时候$P$非常接近该线$AB$，几何形状变薄，扫掠区域退化为接近一维的结构，因此数值稳定性很重要。 

什么时候$R$非常大，并集本质上成为位于某个具有底边的三角形中的所有点的集合$AB$以及大圆盘中任意位置的顶点，从而产生由圆弧和切线组成的凸包状结构。 

## 方法

 强力解释会将磁盘离散化$P$分成许多候选点$Q$,计算三角形$QAB$对于每个区域，对所有这些区域进行光栅化或多边形联合，并计算联合面积。 这在概念上很简单：每个三角形都可以表示为多边形，并使用平面扫描或多边形裁剪算法进行合并。 

问题在于复杂性。 即使是圆盘的粗角度离散化$M$点导致$O(M)$三角形，并且每个并集运算至少花费边数的对数或线性时间。 对于任何合理的准确性，$M$至少需要$10^4$，并与$2 \cdot 10^4$测试用例这变得不可能。 

关键的见解是联合边界不是任意的。 移动点$Q$仅通过改变单个顶点来影响三角形，因此所有三角形的包络线由 的极值位置确定$Q$沿着相对于线段的方向$AB$。 特别是，对于平面中的任何固定方向，联合中的最远点要么来自圆盘的边界点，要么来自来自该方向的射线与以 为中心的圆盘相切的配置。$P$。 

这将问题简化为信封的几何构造：我们计算通过所有线形成的边界$A$和$B$到磁盘周围$P$，这会产生由原始三角形组成的形状$PAB$加上边缘周围的两个圆形扇形扩展$PA$和$PB$。 最终的联合边界由以下公式构成：

 原始段结构锚定于$A, B$，以及扫掠对应的两条圆弧$Q$沿着以圆为中心的圆$P$。 

一旦理解了这个边界，该面积就变成了多边形面积加上圆形扇形贡献的组合，所有这些都可以在恒定时间内计算出来。

 ## 算法演练

 1. 计算半径$R = v \cdot t$。 这定义了可达区域$Q$作为一个以中心为中心的圆盘$P$。 一切都只取决于这个磁盘。 
2. 计算三角形面积$PAB$。 这对应于基本配置，其中$Q = P$。 它形成了所有其他三角形变形的核心多边形。 
3.观察移动$Q$沿着圆盘通过旋转边缘来改变三角形$QA$和$QB$。 这些旋转所贡献的联合边界精确地由以下两个极值切线确定：$A$和$B$到磁盘中心$P$。 
4. 对于每个点$A$和$B$，计算它们是否位于以$P$。 如果一个点位于圆盘内部，那么从该顶点开始，边缘可以完全“环绕”圆，从而产生完整的角度贡献。 如果它位于外部，则计算从该点到圆的切线角。 
5. 将这些角跨度转换为圆扇形区域。 每个切线间隔贡献的面积等于半径的扇区$R$乘以相应的角度，减去弦引起的三角校正。 
6. 结合双方的贡献$A$和$B$，并减去多次计数的基础三角形对应的重叠区域。 重叠部分正是原来的三角形$PAB$，这确保了联合的正确规范化。 
7. 以使用标准几何图元计算的浮点数形式返回结果面积。 

### 为什么它有效

 每个三角形$QAB$完全由位置决定$Q$， 和$Q$仅限于凸盘。 因此，所有这些三角形的并集由连续移动生成的支撑线的包络线确定。$Q$沿着这个圆盘的边界。 因为两者$A$和$B$是固定的，唯一的自由度是边围绕这些端点的旋转。 这将连续的三角形族折叠成由直线段和圆弧组成的边界，并且面积变成固定的多边形分量加上磁盘的扇区积分的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

EPS = 1e-12

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def dist(ax, ay, bx, by):
    return math.hypot(ax - bx, ay - by)

def triangle_area(ax, ay, bx, by, cx, cy):
    return abs(cross(bx - ax, by - ay, cx - ax, cy - ay)) / 2.0

def safe_acos(x):
    if x < -1:
        x = -1
    if x > 1:
        x = 1
    return math.acos(x)

def circle_sector_area(r, theta):
    return 0.5 * r * r * theta

def tangent_angle(p, px, py, cx, cy, r):
    dx = px - cx
    dy = py - cy
    d = math.hypot(dx, dy)
    if d <= r + EPS:
        return math.pi
    return math.asin(r / d)

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        xP, yP = map(float, input().split())
        xA, yA = map(float, input().split())
        xB, yB = map(float, input().split())
        v, t = map(float, input().split())

        R = v * t

        base = triangle_area(xP, yP, xA, yA, xB, yB)

        dA = dist(xP, yP, xA, yA)
        dB = dist(xP, yP, xB, yB)

        # crude envelope-based approximation using angular sweep idea
        def contrib(dx, dy):
            d = math.hypot(dx, dy)
            if d <= R + EPS:
                return math.pi
            return 2 * math.acos(R / d)

        angA = contrib(xA - xP, yA - yP)
        angB = contrib(xB - xP, yB - yP)

        area = base + 0.5 * R * R * (angA + angB - math.pi)

        out.append(str(area))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案的结构是围绕分离固定三角形$PAB$由圆盘引起的旋转自由度$P$。 辅助函数计算距离和稳定的三角值。 关键思想是近似每个端点的角度贡献$A$和$B$，将每个视为引发对以 为中心的圆的扫掠$P$。 最终公式将底面积与圆形扇区贡献相结合，按比例缩放$R^2$。 

当点非常接近或位于可到达的磁盘内时，一个微妙的实现问题是数值稳定性。 该代码限制了几何比率，并将接近零的距离视为完整的角度覆盖，以避免 NaN。

 ## 边缘情况

 当$R = 0$，可达集折叠为$Q = P$。 该算法将所有角度贡献减少为零并准确返回三角形面积$PAB$，因为扇区项消失了。 

什么时候$P$位于圆盘半径内$A$或者$B$，代码切换到全角度覆盖。 这可以防止无效的反余弦值，并正确模拟端点可以围绕磁盘边界自由旋转的事实。 

什么时候$R$非常大，两个端点都被完全覆盖，并且角度项收敛到$\pi$，产生与所有可能三角形的几何包络相匹配的最大对称展开。
