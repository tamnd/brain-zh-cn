 ## 解决方案
 ## 问题理解

 该字符串包含小写字母，目标是对其进行修改，直到出现的每个字母都具有完全相同的频率。 一项操作将一个现有字符更改为任何其他小写字符。 任务是找到所需的此类更改的最少数量。 

例如，如果一个字符串有计数`a = 5`,`b = 2`， 和`c = 1`，我们可以通过将某些字母转换为其他现有字母来删除它们，或者创建新字母。 最终字符串可以包含任意数量的不同字符，但剩余的每个字符必须具有相同的计数。 

输入包含多个独立的字符串。 测试用例的数量可以大到`10^5`，并且所有字符串长度的总和也最多为`10^5`。 这意味着解决方案在总输入大小方面必须接近线性。 尝试多次修改或扫描所有可能的转换字符串的解决方案是不可能的，而每个字符执行少量工作的方法则很容易适合。 

有少数情况需要护理。 如果所有字符已经具有相同的频率，则不需要进行任何操作。 对于输入：```
1
aabb
```答案是`0`，因为这两个字母已经出现了两次。 一种总是尝试将所有内容合并为一个字符的方法将错误地返回`2`。 

具有一个字符的字符串是另一种边界情况：```
1
aaaa
```答案是`0`。 该字符串已经恰好有一个不同的字符，并且满足条件，因为所有不同的字符，仅意味着`a`，具有相同的频率。 

一个不太明显的情况是，最佳答案引入了与原始字符串不同数量的不同字符。 为了：```
1
aba
```答案是`1`。 我们可以改变`b`进入`a`并得到`aaa`，或者换一个`a`进入`c`并得到`abc`。 仅尝试平衡当前存在的字母的解决方案将错过添加或删除不同字符的可能性。 

## 方法

 一种直接的方法是猜测不同字符的最终数量、将保留的字母以及它们的目标频率。 对于每个猜测，我们可以计算有多少字符已经与所需的最终排列匹配，并更改其余的字符。 这是正确的，因为考虑了每种可能的最终状态，但可能状态的数量太多了。 

关键的观察结果来自于这样一个事实：只有 26 个可能的小写字母。 最终不同字符的数量必须是字符串长度的约数，因为如果有`k`字符和每个出现`x`次，那么`k * x = |S|`。 自从`k`不能超过26，我们只需要检查极少数的可能性。 

假设我们选择`k`最终字符。 他们所需要的频率是`|S| / k`。 具有当前频率的所选字符`c`最多可以贡献`min(c, |S| / k)`保持不变的字符。 如果我们保留的字符的频率超过目标频率，则必须更改多余的副本。 如果它的副本较少，我们必须使用其他角色的更改来创建额外的副本。 

对于固定的`k`，最好的选择是选择`k`具有最大贡献的信件。 计算出可以保持不变的最大仓位数后，剩下的仓位正是我们需要的操作。 

暴力破解之所以有效，是因为它检查了可能的最终配置，但它失败了，因为它将 26 个字母视为创建了一个巨大的搜索空间。 只有不同字母的最终数量才重要的观察结果将问题简化为最多检查 26 个案例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 可能的最终状态数量呈指数增长 | O(26) | 太慢了|
 | 最佳| 每个字符串 O(26 × 26) | O(26) | 已接受 |

 ## 算法演练

 1. 统计字符串中每个小写字母出现的频率。 由于字母大小是固定的，因此只需要 26 个计数器。 
2. 尝试所有可能数量的最终不同字符`k`从`1`到`26`。 忽略值`k`不会除以字符串长度，因为否则相等的频率不能总和为总长度。 
3. 对于有效的`k`，计算目标频率`need = length / k`。 对于每个字母，如果该字母是最终字母之一，则计算其当前出现的次数可以保持不变`k`字母。 这个值是`min(current_frequency, need)`。 
4、对这26个贡献值进行排序，取最大的`k`其中。 这些代表了最好的`k`保留在最终字符串中的字母。 
5. 不变头寸的数量是这些选定贡献的总和。 此选择所需的操作是`length - unchanged_positions`。 保留所有有效值中的最小值`k`。 

为什么它有效：对于任何选定的最终字符数，每个最终字符都必须恰好具有`need`发生。 一个字符不能保存超过`need`保留较少的位置永远不会有好处，因为另一个角色可以使用这些保留的位置。 选择最大的`k`贡献给出了在该目标下可以保持不变的最大职位数。 由于检查了每个可能的有效最终字符数，因此找到的最小答案是真正的最佳答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        s = input().strip()
        n = len(s)

        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - ord('a')] += 1

        best = n

        for k in range(1, 27):
            if n % k != 0:
                continue

            need = n // k
            keep = []

            for c in cnt:
                keep.append(min(c, need))

            keep.sort(reverse=True)
            unchanged = sum(keep[:k])

            best = min(best, n - unchanged)

        ans.append(str(best))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```频率数组存储输入的完整状态，因为只有字母计数会影响答案。 循环结束`k`检查最终字母表的所有可能的大小。 无法整除字符串长度的值将被跳过，因为它们无法形成相等的组。 

对于每个有效的`k`，代码无需修改即可构建每个字母可以贡献的金额。 排序将最有用的字母放在前面，因此取第一个`k`值给出了要保留的最佳字符集。 答案是总长度减去这些保留的位置。 

不存在索引问题，因为每个字符都转换为以下值：`0`到`25`。 Python 整数也消除了对溢出的任何担忧，尽管实际值很小。 

## 工作示例

 对于字符串`aba`:

 | k | 目标频率| 贡献| 不变| 运营|
 | ---| ---| ---| ---| ---|
 | 1 | 3 | 2, 1, 0, ... | 2 | 1 |
 | 3 | 1 | 1, 1, 0, ... | 2 | 1 |

 最好的答案是`1`。 跟踪表明，最佳结果不需要保留与原始字符串相同数量的不同字符。 

对于字符串`abbbc`:

 | k | 目标频率| 贡献| 不变| 运营|
 | ---| ---| ---| ---| ---|
 | 1 | 5 | 3, 1, 1, 0, ... | 3 | 2 |
 | 5 | 1 | 1, 1, 1, 0, ... | 1, 1, 1, 0, ... 3 | 2 |

 答案是`2`。 保留一个字符需要更改其他两个字母，而保留三个不同的字符则需要减少出现频率`b`并创建丢失的副本。

 ## 边缘情况

 对于`aabb`，算法检查`k = 1`和`k = 2`。 什么时候`k = 2`，目标频率为`2`，两个字母都有贡献`2`，并且所有四个位置保持不变。 答案是`0`，避免将字符串强制为一个字符的错误。 

为了`aaaa`，只有一个字母存在，但是`k = 1`有效，因为长度可以被一整除。 目标频率为`4`，这封信贡献了所有四个位置。 算法返回`0`。 

为了`aba`，该算法考虑了两者`k = 1`和`k = 3`。 和`k = 1`，最好的贡献是两个不变`a`人物。 和`k = 3`，最好的贡献是`a`和一个`b`，留下一个缺失的角色来创建。 两种选择都需要一次操作，所以最终的答案是`1`。 

为了`abbbc`，有效的选择是`k = 1`和`k = 5`。 第一个选择保留三个`b`字符并更改其余两个。 第二种选择保留每个可用字符的一个副本，并更改​​两个位置以创建丢失的字母。 两者都会导致两个操作，这证实了该算法可以处理删除字符和添加字符同样好的情况。
