 ## 解决方案
 ## 问题理解

 我们正好有`N`左括号和`N`右括号，因此每个有效答案都是长度为常规的括号序列`2N`。 在所有这样的序列中，我们只需要计算那些不能通过取某个长度的字符串获得的序列`N`并连续写两次。 

一个字符串被称为`N`-周期性，当其前半部分和后半部分相同时。 例如，与`N = 2`, 字符串`)()(`是周期性的，因为前两个字符`)(`被重复，同时`)(()`不是。 

任务不是构建序列。 我们只需要对计数求模`10^9 + 7`。 

约束条件`N <= 1000`并且测试用例的数量最多为`1000`告诉我们一个`O(N)`或者`O(N log N)`预处理方法就足够了。 生成括号序列的解决方案是不可能的，因为常规括号序列的数量是加泰罗尼亚数，并且呈指数增长。 即使对于中等规模的`N`，枚举变得太大。 

主要的边缘情况来自于将重复部分的长度与括号对的数量混淆。 为了`N = 1`，唯一的正则括号序列是`()`。 它不能分成两个相等的非空半部分，所以答案是`1`。 总是减去一个周期序列的粗心解决方案会错误地输出`0`。 

另一个重要的情况是当`N`很奇怪。 例如，使用输入`N = 3`，正则括号序列的总数为`5`。 周期序列需要前半部分的长度`3`包含相同数量的左括号和右括号。 这是不可能的，因为奇数长度的字符串不能具有相同数量的括号。 正确答案是`5`，以及一种粗心的方法，假设每个`N`创建一个更小的加泰罗尼亚减法将是错误的。 

最后一个边界情况是当`N`是均匀的。 为了`N = 4`，规则序列的计数为`Catalan(4) = 14`。 周期序列就是将一定长度的规则序列重复形成的序列`4`, 给予`Catalan(2) = 2`无效序列。 答案是`12`。 忘记重复的一半本身必须平衡会减去太多的字符串。 

## 方法

 直接的方法是生成每个正则括号序列`N`对，检查是否是周期性的，并计算不是周期性的。 这是正确的，因为它准确地检查了所需的集合。 然而，规则括号序列的数量是`Catalan(N)`，近似为指数。 为了`N = 1000`，甚至表示答案空间也是不可能的，所以暴力破解是行不通的。 

有用的观察来自于观察周期性正则括号序列必须是什么样子。 假设一个有效的序列`S`有长度`2N`并且是`N`-周期性的。 然后它的形式是`T + T`， 在哪里`T`有长度`N`。 

因为整个序列是平衡的，所以总括号平衡为`T + T`必须为零。 因此第一个副本的余额具有一定的价值`x`，第二个副本贡献了另一个`x`, 给予`2x = 0`。 因此`x = 0`，这意味着前半部分已经包含相同数量的左括号和右括号。 

现在考虑有效性。 整个序列的每个前缀必须至少具有与右括号一样多的左括号。 第一个副本`T`是整个字符串的前缀，所以里面的每个前缀`T`必须有效。 自从`T`余额也为零，`T`本身是一个规则的括号序列。 

这给出了一对一的关系。 每一个`N`-周期性正则括号序列对应长度的正则括号序列`N`，并且这样的序列仅存在于`N`是均匀的。 如果`N = 2k`，周期序列的数量为`Catalan(k)`。 

正则括号序列的总数`N`对是`Catalan(N)`，所以最终的答案是：`Catalan(N) - Catalan(N / 2)`什么时候`N`是均匀的。`Catalan(N)`什么时候`N`很奇怪。

 ## 算法演练

 1. 预先计算阶乘和逆阶乘`1000`。 加泰罗尼亚数可以使用组合公式计算：`Catalan(n) = C(2n, n) - C(2n, n + 1)`这相当于：`Catalan(n) = (2n choose n) / (n + 1)`。 

预先计算这些值可以立即回答每个查询。 
2. 对于每个有值的查询`N`，从正则括号序列的总数开始，即`Catalan(N)`。 

这会在删除周期性序列之前对每个可能的有效序列进行计数。 
3.如果`N`是偶数，减去`Catalan(N / 2)`。 

唯一被删除的序列正是那些前半部分本身就是常规括号序列的序列。 
4.如果`N`是奇数，不要减去任何东西。 

奇数长度的一半不能包含相同数量的左括号和右括号，因此不存在周期性正则序列。 
5. 打印取模后的结果值`10^9 + 7`。 

为什么它有效：

 该解决方案背后的不变性是每个无效序列都有唯一的前半部分。 被视为周期性的序列必须是该一半的两个相同的副本。 为了使整个字符串是规则的，一半的余额必须为零，并且它的每个前缀都必须有效。 这些正是半场成为常规括号序列的条件。 因此，周期序列是通过较小的加泰罗尼亚数精确计数的，减去它们就可以删除所有不需要的序列。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

MOD = 10**9 + 7

MAX_N = 1000

fact = [1] * (2 * MAX_N + 5)
for i in range(1, len(fact)):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (2 * MAX_N + 5)
inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)
for i in range(len(inv_fact) - 1, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def comb(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

catalan = [0] * (MAX_N + 1)
for i in range(MAX_N + 1):
    catalan[i] = (comb(2 * i, i) - comb(2 * i, i + 1)) % MOD

def solve():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        cur = catalan[n]
        if n % 2 == 0:
            cur -= catalan[n // 2]
        ans.append(str(cur % MOD))
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```预处理部分构建阶乘和逆阶乘，因此可以在模数下在恒定时间内计算组合。 所需的最大加泰罗尼亚索引是`1000`，但是计算`Catalan(1000)`需要`C(2000, 1000)`，因此阶乘最多存储`2000`。 

查询处理直接遵循数学结果。 它首先获取常规括号序列的总数。 什么时候`N`是偶数，重复的一半按加泰罗尼亚数计算`N / 2`成对并被删除。 

模减法最后处理为`% MOD`因为去除周期序列后中间值可能会变成负值。

 ## 边缘情况

 对于`N = 1`，算法计算`Catalan(1) = 1`。 自从`N`是奇数，它不会减去任何东西。 结果是`1`，匹配唯一的序列`()`。 

为了`N = 3`，有效序列的总数为`Catalan(3) = 5`。 该算法检查奇偶校验并发现`3`是奇数，因此计数保持不变。 这处理了不存在长度为 3 的有效前半部分的情况。 

为了`N = 4`，算法开始于`Catalan(4) = 14`。 由于长度是偶数，因此减去`Catalan(2) = 2`。 这两个序列代表所有可能的重复一半，留下`12`非周期性正则括号序列。 

对于非常大的允许值，例如`N = 1000`，该算法从不自行构建序列。 它仅使用预先计算的组合值，因此避免了实际括号字符串数量的指数增长。
