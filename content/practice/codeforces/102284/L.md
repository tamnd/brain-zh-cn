 ## 解决方案
 ## 问题理解

 有 (n) 名学生，每个学生说出 (k) 种可能的饮料中的一种。 Andrew 正好有 (\lceil n/2\rceil) 个包。 每个套餐包含两个半份，因此一个套餐最多可以满足两个学生，并且这两个学生必须要求相同的饮料。 

安德鲁可以自由选择每个包装中包含的饮料。 我们的目标不是让每个学生都高兴，而是最大限度地增加实际提供所需饮料的学生数量。 

假设 (c) 学生要求某种特定的饮料。 为了满足所有这些要求，安德鲁需要 (\lceil c/2\rceil) 包该饮料。 两个有相同要求的学生可以共用一个包裹，而一组人数奇怪的学生则需要一个包裹，其中一半未使用。 

主要的困难在于，每一种请求数量为奇数的饮料所消耗的半包量都比学生建议的多。 我们需要选择要满足的饮料，以便所需包的总数不超过 (\lceil n/2\rceil)。 

约束足够小，(O(nk)) 已经可以接受，因为 (n) 和 (k) 都至多为 (1000)。 然而，问题的结构给出了 (O(n+k)) 解。 我们只需要每次请求饮料的频率以及奇数频率的数量。 

在两种简单的情况下，粗心的解决方案可能会失败。 首先，学生人数为奇数并不意味着每个奇数饮酒小组都会引发问题。 例如，```
1 1
1
```有一名学生和一个包裹，所以答案是（1）。 剩下的半包可以简单地由安德鲁拿走。 

更有趣的情况是几个奇怪大小的群体。 考虑```
4 4
1
2
3
4
```每杯饮料都要求一次。 套餐只有两份，四名学生最多只能有两人拿到自己想要的饮料。 正确答案是（2）。 简单地将所有请求相加的解决方案会错误地声称所有四个请求都可以得到满足。 

(n) 的奇偶性也很重要。 为了```
5 3
1
3
1
1
2
```请求计数为 (3,1,1)。 一共有三个包。 我们可以用两包饮料（1）来满足三个学生，用一包饮料（2）或饮料（3）来满足多一个学生。 答案是（4），而不是（3）。 

## 方法

 直接的蛮力方法是决定安德鲁将在晚上的选择中包括哪些饮料类型。 对于 (k) 种饮料的每个子集，我们可以计算需要多少包。 如果饮料 (i) 被请求 (c_i) 次并且被选中，则花费 (\lceil c_i/2\rceil) 包并贡献 (c_i) 个满意的学生。 我们保留打包成本最多为 (\lceil n/2\rceil) 的最佳子集。 

这种蛮力是正确的，因为每种可能的饮料类型选择都被明确考虑。 问题是子集的数量。 它们有 (2^k) 个，并且 (k=1000) 已经有 (2^{1000}) 个可能性。 即使每个子集的成本保持在恒定时间内，搜索也将毫无希望。 扫描每个子集的所有 (k) 种饮料类型的简单实现将执行 (O(k2^k))，大约为 (1000\cdot2^{1000})，这远远超出了任何实际限制。 

有用的观察结果是，每个饮料组都具有非常特殊的成本与价值关系。 如果 (c) 是偶数，那么

 [
 \left\lceil\frac c2\right\rceil=\frac c2,
 ]

 因此，满足这些学生的费用正好是一半的套餐。 如果 (c) 是奇数，则

 [
 \left\lceil\frac c2\right\rceil=\frac{c+1}{2}。 
]

 因此，与理想成本 (c/2) 相比，每个奇数组都会引入一个额外的包。 

令 (O) 为请求计数为奇数的饮料类型的数量。 如果我们试图让每个人都满意，则所需的包裹数量将是

 \frac{n+O}{2}。 
]

 我们只有 (\lceil n/2\rceil) 个包。 多余的部分正是必须处理的奇数组的数量。 

我们可以考虑从满意的学生集中删除学生，而不是选择任意子集。 从奇数组中删除一名学生会将该组更改为偶数组，从而将奇数组的数量减少 1 个。 从同一组中删除另一名学生会让事情再次变得奇怪，因此在我们试图解决包裹短缺问题时这样做没有任何好处。 

对于偶数 (n)，数字 (O) 是偶数。 我们需要删除 (O/2) 个学生，每个 (O/2) 个奇数组中删除一名学生。 对于奇数(n)，(O)是奇数，并且一个奇数组可以使用剩余的单个半包。 我们只需要删除 ((O-1)/2) 名学生。 

这给出了一个直接的公式。 对于偶数 (n)，答案是

 [
 n-\压裂O2。 
]

 对于奇数 (n)，答案是

 [
 n-\frac{O-1}{2}。 
]

 同样，我们可以将必须牺牲的学生数量计算为 (\lfloor O/2\rfloor)，因为 (O) 的奇偶性与 (n) 的奇偶性相同。 因此答案很简单

 [
 \boxed{n-\left\lfloor\frac O2\right\rfloor}。 
]

 整个问题现在已简化为计算频率并计算其中有多少是奇数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解饮料子集 | (O(k2^k)) | (O(k)) | 太慢了|
 | 计算频率和奇数组 | (O(n+k)) | (O(k)) | 已接受 |

 ## 算法演练

 1. 创建数组`cnt`大小为 (k+1)，其中`cnt[x]`将存储有多少学生请求饮料 (x)。 计算频率就足够了，因为学生的身份和排序不会影响包裹的分发方式。 
2.读取所有(n)个请求并增加相应的频率。 在此步骤之后，整个输入由（k）个值（c_1，c_2，\ldots，c_k）表示。 
3. 计算有多少个频率是奇数。 拨打这个号码`odd`。 与同等规模的偶数组相比，每个这样的组都需要额外的半包装。 
4. 计算`odd // 2`。 这是必须不满意的学生的最低数量。 将奇数组配对解释了这个值：必须从每对奇数组中删除一名学生，以便可以使用可用的包来处理这两个组。 
5、输出`n - odd // 2`。 (n)的奇偶校验已经确定了一个奇数组是否可以使用单个剩余的半包，因此不需要额外的特殊情况。 

为什么它有效。 假设请求计数为 (c_1,\ldots,c_k)，其中 (O) 为奇数。 如果我们满足每个学生的要求，则所需包的数量为((n+O)/2)。 我们的预算是 (\lceil n/2\rceil)，因此每一对奇数组恰好创建一个超额需求包。 从这样一组中的一组中删除一名学生可以使该组均匀并删除一个多余的单位。 因此至少必须牺牲 (\lfloor O/2\rfloor) 名学生。 我们可以通过从每对奇数组中的一组中选择一名学生来实现这一点。 在这些删除之后，当 (n) 为奇数时，最多保留一个奇数组，这适合单个部分使用的包。 因此下界是可以实现的，答案正是 (n-\lfloor O/2\rfloor)。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    cnt = [0] * (k + 1)

    for _ in range(n):
        drink = int(input())
        cnt[drink] += 1

    odd = sum(c & 1 for c in cnt)

    print(n - odd // 2)

if __name__ == "__main__":
    solve()
```数组`cnt`存储每次饮料的频率。 由于饮料编号在 (1) 和 (k) 之间，因此直接索引比使用字典更简单、更快速。 

表达式`c & 1`检查频率是否为奇数。 它相当于`c % 2`，但使奇偶校验操作变得明确。 将这些值相加即可得出证明中的数字 (O)。 

最终的表达`n - odd // 2`处理 (n) 的两个奇偶校验。 当 (n) 为偶数时，`odd`必然是偶数，所以`odd // 2`正是必须删除的学生人数。 当 (n) 为奇数时，`odd`必然是奇数，整数除法给出 ((O-1)/2)，留下一个奇数组来使用单个剩余的半包。 

除了分配之外，没有涉及饮料数量的索引技巧`k + 1`元素，因此饮料 (k) 可以安全地表示。 对于这些约束，Python 整数也不存在溢出问题。

 ## 边缘情况

 最小可能的输入是```
1 1
1
```有一个包裹和一名学生。 学生收到包裹的一半，而安德鲁则保留另一半。 唯一的频率是 (1)，所以`odd = 1`和`odd // 2 = 0`。 该算法输出（1），这是最优的。 

当所有学生点相同的饮料时，只有一个频率，并且当 (n) 为奇数时，该频率恰好为奇数。 例如，```
5 2
1
1
1
1
1
```给出`odd = 1`，所以答案是（5）。 两个套餐可以满足四名学生的需求，第三个套餐可以满足第五个学生的需求，另一半留给安德鲁。 

在有许多奇数群的情况下，主要公式很重要。 为了```
6 6
1
2
3
4
5
6
```所有六个频率都是奇数，所以`odd = 6`。 答案是（6-6/2=3）。 一共有三个包，每个满足的单例请求都需要一个包。 从六种饮料中选择三种可以让三个学生满意。 

最后，奇数 (n) 边界与偶数 (n) 情况不同。 为了```
5 3
1
2
3
1
1
```频率为 (3,1,1)，给出`odd = 3`。 该算法仅删除`3 // 2 = 1`学生和回报 (4)。 原因是，在满足三个学生的饮料要求（1）后，额外的一包可以满足任何一个单独的要求。 剩下的单身汉，正是那个无法满足的学生。 最终包裹中未使用的一半是安德鲁的，这是在学生人数为奇数时允许的。
