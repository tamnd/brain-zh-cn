 ## 解决方案
 # 问题理解

 这是一个仅输出的构造问题。 没有输入，因为任务不是处理数据，而是打印两组生物优势，从而创建非常具体的概率关系。 

我们需要创建第一个法师的多组优势和第二个法师的多组优势。 当两个法师随机选择正确的`k`生物，第一个法师一定更有可能获胜`k = 1`和`k = 3`，而第二个法师则更有可能获胜`k = 2`。 

限制很小。 每组可以包含 3 到 10 个生物，并且每个强度必须在 1 到 10 之间。这意味着预期的解决方案不是执行期间的算法搜索。 我们只需要发现一种有效的构造并打印它。 提交的程序可以简单地输出固定数字。 

微妙的部分是平局会导致比赛重新开始。 最终获胜者的概率并不是仅由第一次比较决定的。 如果第一位法师有概率赢得单轮`W1`，以概率输掉`W2`，并与概率相关`T`，然后在删除重复的平局后，获胜者比较变为`W1`相对`W2`。 因此，我们只需要获胜结果的数量大于失败结果的数量即可获得所需的值`k`。 

一个常见的错误是只比较平均强度。 仅平均强度并不能决定获胜者，因为随机子集分布很重要。 例如，使用示例想法：```
3
1 2 3
3
2 2 2
```第一个法师有机会获胜`k = 1`，但是对于`k = 3`双方总数相等，因此比赛为平局。 该构造需要同时控制所有三个子集大小。 

## 方法

 解决此类输出问题的强力方法是枚举所有可能的集合，计算概率`k = 1`,`k = 2`， 和`k = 3`，并在找到有效对时停止。 由于每个集合最多有 10 个元素，并且强度范围从 1 到 10，因此这样的搜索可以离线进行。 然而，将搜索放入提交的解决方案中是不必要的，并且比实际任务大得多。 对所有大小为 10 的多重集的简单枚举将粗略地考虑`C(19,10)`双方的可能性，在检查组合之前已经给出了数十万个候选者。 

有用的观察是我们不需要复杂的分布。 三生物结构就足够了。 对于三个生物来说，`k = 3`只是总金额的比较。 我们可以通过给第一组更大的总数来让第一个法师获胜。 同时，对于`k = 2`，可能的对与总数密切相关，因为每对都是总数减去一个生物。 这让我们让第一法师的最强对出现的次数太少了。 

成功构建的是：```
First mage: 1 7 8
Second mage: 5 5 5
```为了`k = 1`，第一位法师有两个比5强的生物和一个比5弱的生物，因此他在单一生物比较中获胜更多。 

为了`k = 2`，第一个法师的对子和为 8、9 和 15。第二个法师的对子和始终为 10。第一个法师输了两次，赢了一次。 

为了`k = 3`，总数为 16 和 15，因此第一个法师获胜。 

暴力破解的想法之所以有效，是因为搜索空间足够小，足以进行发现，但最终的解决方案可以简化为打印这一经过验证的结构。

 ## 算法演练

 1. 打印第一个法师的集合为`1 7 8`。 总力量为16，大于第二个法师的总力量，在选择所有生物时提供所需的优势。 
2. 打印第二个法师的集合为`5 5 5`。 其固定值使得子集比较易于控制，因为每个选择都具有相同的强度。 
3. 验证所需的三个案例。 对于一个生物，第一位法师有两个获胜值。 对于两个生物，第一个法师的配对总和大多低于第二个法师的固定配对总和。 有了三个生物，第一法师的总数就更大了。 

这种结构起作用的原因是，相同的三个数字对单个生物和成对生物产生相反的行为。 高值有助于`k = 1`，但是将这些高值结合起来会使第一个法师只剩下一对非常强的对，从而造成损失`k = 2`。 总数仍然足够高，足以获胜`k = 3`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    print(3)
    print("1 7 8")
    print(3)
    print("5 5 5")

if __name__ == "__main__":
    solve()
```该程序不会读取任何内容，因为输入故意为空。 它直接打印上面找到的两个生物集。 

前两行描述了第一个法师的收藏，接下来的两行描述了第二个法师的收藏。 没有循环或计算，因为该问题只需要一个有效的见证人。 

小输出格式也是不存在溢出或边界问题的原因。 所有值均在允许范围内。

 ## 边缘情况

 第一个边缘情况是当所有选定的生物具有相同的总强度时`k = 3`。 像这样的构造`1 2 3`相对`2 2 2`失败，因为两个总数都是 6。游戏永远不会产生胜利者`k = 3`。 提交的构造避免了这种情况，因为`1 + 7 + 8 = 16`和`5 + 5 + 5 = 15`。 

第二种边缘情况仅依赖于平均强度。 第一个法师的平均数在最终构建中更高，但仅凭这一事实并不能解释`k = 2`结果。 实际的对总和是`8`,`9`， 和`15`，因此三个选择中的两个会输给固定值`10`。 仅检查总数的粗心解决方案会错过此行为。 

第三个边缘情况是平局。 如果胜负次数相同，重复回合不会产生优势。 在这里，为了`k = 1`，有两个获胜比较和一个失败比较。 为了`k = 2`，有一个获胜比较和两个失败比较。 不存在改变结果的隐藏等式。
