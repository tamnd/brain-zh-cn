 ## 解决方案
 ## 问题理解

 我们有四根横杆，它们将成为桌子的四条腿。 它们的长度决定了桌面四个角的高度，因为每条腿都从地板延伸到表面。 问题是我们是否可以将这四个高度放置在某个矩形的角上，以便一个平坦的桌面平面穿过所有四个端点。 

矩形上方的平面具有特殊的结构。 如果我们观察四个角，高度沿着两个矩形方向独立变化。 这意味着四个角的高度不能是任意的。 任务是决定是否可以排列给定的四个数字来满足该几何条件。 输出是`YES`如果存在这样的安排并且`NO`否则。 

每个条的长度可以大到$10^9$，但只有四个栏。 值的大小排除了依赖于尝试可能的长度或使用基于坐标的模拟的方法。 由于元素的数量是固定的，因此解决方案应该依赖于四个值的数学属性，而不是搜索大的状态空间。 对恒定数量的排列进行排序或检查很容易在限制范围内。 

主要的边缘情况来自于假设钢筋必须具有相同的长度或者只有相等的钢筋对才能工作。 粗心的实现可能会错过有效的倾斜表或接受无效的集合。 

例如，输入`1 3 2 2`应该产生`YES`。 可以放置四个高度，使对角的总和相等：$1+3=2+2$。 仅接受四个相等值或两对相等值的解决方案将错误地拒绝这种情况。 

另一种情况是`1 2 3 10`，这应该产生`NO`。 最小值和最大值之和为$11$，而中间值的总和为$5$。 没有任何放置可以使对角和匹配，因此没有平面可以通过所有四个端点。 

案例`5 5 5 5`应该产生`YES`。 平坦桌面只是倾斜桌面的一种特殊情况，因此需要非零斜率会错误地拒绝此输入。 

## 方法

 直接的方法是尝试将四个条形分配给四个矩形角的所有可能的分配。 只有$4! = 24$排列。 对于每个排列，我们可以检查相对的角是否具有相同的总高度。 这是可行的，因为每个有效的矩形放置都对应于这些分配之一，因此尝试所有这些分配不会错过解决方案。 

蛮力方法已经足够快了，因为 24 次检查是恒定的工作量。 然而，它隐藏了底层结构。 真正的观察是，矩形上任何平面的四个角高度始终满足简单的等式。 

假设矩形角有高度$x_1, x_2, x_3, x_4$，其中对角配对。 跨一个矩形方向移动会增加相同的高度，跨另一方向移动也会增加相同的高度。 这四个值可以表示为：$$c,\quad c+a,\quad c+b,\quad c+a+b$$第一个值和最后一个值的总和为：$$c + (c+a+b) = 2c+a+b$$剩余两个值的总和为：$$(c+a)+(c+b)=2c+a+b$$所以两个对角的和一定相等。 将四个值排序后$a \leq b \leq c \leq d$，唯一可能的对角配对是最小的与最大的以及两个中间值在一起。 条件变为：$$a+d=b+c$$这在排序后给出了直接的常数时间解。 

强力方法之所以有效，是因为搜索空间仅包含 24 种可能的布局，但上面的等式将所有这些检查压缩为一个比较。 几何约束变成排序值的算术属性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(4!) | O(1) | O(1) | 已接受，但不必要的搜索 |
 | 最佳| O(4 log 4) | O(4 log 4) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取四个条的长度并对其进行排序。 令排序后的值是$a, b, c, d$。 排序无需考虑所有可能的位置，因为在任何有效的排列中，最小值和最大值必须形成一对相反的对。 
2. 检查是否$a+d=b+c$。 这会在对值排序后比较两个可能的对角总和。 如果它们相等，则可以将四个高度排列为矩形的角，并用一个平面接触它们。 
3. 打印`YES`当等式成立且`NO`否则。 这个等式既是必要的也是充分的，因此不需要额外的几何图形来验证。 

为什么它有效：

 对于放置在矩形上的任何平面，角高度的形式为$c, c+a, c+b, c+a+b$。 对角的总和总是相等，因此每个有效表都必须满足排序相等性$a+d=b+c$。 相反，如果等式成立，则选择排序后的值作为$a,b,c,d$按该顺序放置在矩形周围。 相邻角之间的差异定义了沿两个矩形方向的一致变化，因此通过所有四个点存在一个平面。 该条件准确地描述了有效表的特征。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = list(map(int, input().split()))
    a.sort()

    if a[0] + a[3] == a[1] + a[2]:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```该解决方案读取四个高度并对它们进行排序，以便可以在不考虑单独放置的情况下检查几何关系。 该比较在一侧使用最小值和最大值，在另一侧使用两个中间值。 

Python 整数处理的值可达$2 \times 10^9$没有任何溢出问题，即使输入值本身可以达到$10^9$。 不存在索引边界问题，因为数组始终包含恰好四个数字。 

运算顺序很重要，因为该公式依赖于排序位置。 检查原始订单只会测试一个任意位置，并可能拒绝有效的安排。

 ## 边缘情况

 输入`1 3 2 2`演示了为什么不需要相等的对。 排序后，值变为`1,2,2,3`。 算法检查$1+3=2+2$，这是真的，所以它返回`YES`。 相应的桌面是倾斜的，因为高度并不全部相等。 

输入`1 2 3 10`表明安排无效。 排序给出`1,2,3,10`，算法检查$1+10=2+3$。 自从`11`不等于`5`，所需的平面不存在，所以答案是`NO`。 

输入`5 5 5 5`演示平板案例。 排序使值保持不变，等式两边相等`10`。 该算法接受它，因为水平表面只是一个斜率为零的平面。
