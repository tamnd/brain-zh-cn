 ## 解决方案
 ## 问题理解

 我们得到一个过程，最终产生一个计数向量$n$恰好之后的奖品类型$k$回合。 在每一轮中，都会选择两种不同的类型。 在这两种类型之间，我们确定性地将本轮奖励分配给当前奖励较少的类型； 如果两者的计数相同，则通过选择较小的索引来打破平局。 

毕竟$k$轮次后，我们查看最终的计数向量。 我们对随机对选择的序列不感兴趣，只对最终计数向量可能出现在某些对选择序列下感兴趣。 在所有这些可达向量中，我们计算有多少个满足没有类型接收超过的约束$m$奖品。 如果两个向量至少有一个坐标不同，则认为两个向量不同。 

所以真正的问题是：有多少个不同长度的整数向量$n$, 总结为$k$，可以通过这个过程产生，在每个坐标最多为$m$。 

限制很大：两者$n$和$k$可以达到$10^6$。 这立即排除了任何试图枚举状态或模拟过程的方法。 即使为每个候选显式存储完整向量也太大了，并且任何状态依赖于$n \times k$是不可行的。 唯一可行的方向是将问题简化为封闭组合形式，可以在输入大小的大致线性时间内进行评估。 

贪婪规则的作用经常使天真的推理感到困惑。 人们可能会怀疑它对可达向量施加了不平凡的结构约束，而不仅仅是总和约束。 然而，在此过程中，规则仅确定在给定的配对选择序列期间如何分配每个单独的单元。 除了精确分配的可行性之外，它不会在最终计数之间强加额外的全局耦合$k$跨单位$n$具有上限的类型。 

容易被误解的边缘情况包括以下情况$m = 0$，其中唯一可能的向量全为零，因此需要$k = 0$，以及情况$m \ge k$，其中上限变得无关紧要，并且所有组成$k$进入$n$部分有效。 

## 方法

 暴力解释将尝试模拟所有可能的序列$k$对选择。 每一步都会选择其中的一对$\binom{n}{2}$的可能性，所以有$\binom{n}{2}^k$序列。 对于每个序列，我们模拟贪婪分配$O(k)$，导致总共$O(k \cdot \binom{n}{2}^k)$，即使对于很小的输入来说，这也是一个天文数字。 这显然是不可能的。 

关键的简化是完全忘记过程并专注于最终目标。 每个奖项最终都会分配给一种类型，因此输出只是一个分布$k$相同的项目放入$n$贴有标签的垃圾箱。 我们施加的唯一限制是任何垃圾箱都不能超过容量$m$。 贪婪选择规则不会消除这种形式的任何可行计数向量：对于任何有效的有界组合，都存在一些实现它的配对选择序列。 

这将问题简化为经典的有界整数组合计数：计算整数解的数量$$x_1 + x_2 + \dots + x_n = k,\quad 0 \le x_i \le m.$$这是系数$x^k$在$(1 + x + x^2 + \dots + x^m)^n$，可以通过删除上限约束使用包含-排除来解决。 

我们对待每一次违规行为$x_i \ge m+1$通过移动变量和交替符号。 这导致了涉及二项式系数的标准公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 配对过程的暴力模拟 | 指数为$k$|$O(n)$| 太慢了|
 | 有界组合的组合学 |$O(n)$预计算 |$O(n)$| 已接受 |

 ## 算法演练

 我们使用包含-排除计算有界组合的数量。 

1. 将最终状态解释为赋值$k$相同的项目放入$n$贴有标签的垃圾箱，其中每个垃圾箱$i$有能力$m$。 这将过程转换为计数整数解$x_1 + \dots + x_n = k$和$0 \le x_i \le m$。 
2. 从非负解的无约束计数开始。 如果没有上限，解的数量为$\binom{k+n-1}{n-1}$。 这是标准的星形和条形结果。 
3. 通过排除至少一个变量超过的解来引入上限$m$。 对于固定子集$i$变量被迫至少为$m+1$, 减去$i(m+1)$从总和中计算剩余的非负解。 
4. 对超出界限的变量数量应用包含-排除。 最终公式变为$$\sum_{i=0}^{\lfloor k/(m+1)\rfloor} (-1)^i \binom{n}{i} \binom{k - i(m+1) + n - 1}{n - 1}.$$1. 预先计算阶乘和逆阶乘至少达到$n+k$以便所有二项式系数都可以在$O(1)$。 直接计算总和。 
2. 返回取模结果$998244353$。 

关键的计算步骤是当顶部参数变为负值时仔细处理二项式系数； 这些项被视为零并被跳过。 

### 为什么它有效

 包含-排除结构通过纠正由于允许箱超出容量而导致的过量计数来精确地枚举分配。 对于违规箱的每个子集，每个配置都被计数一次，并且交替符号取消所有无效配置，同时保留有效配置一次。 由于每个有效的有界组合对应于至少一个对选择序列，并且该过程不限制超出容量约束的可行性，因此组合模型匹配可达集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def main():
    n, k, m = map(int, input().split())

    max_n = n + k + 5

    fact = [1] * (max_n)
    invfact = [1] * (max_n)

    for i in range(1, max_n):
        fact[i] = fact[i - 1] * i % MOD

    invfact[max_n - 1] = modinv(fact[max_n - 1])
    for i in range(max_n - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    def C(a, b):
        if a < 0 or b < 0 or a < b:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    ans = 0
    limit = k // (m + 1)

    for i in range(limit + 1):
        rem = k - i * (m + 1)
        term = C(n, i) * C(rem + n - 1, n - 1) % MOD
        if i % 2 == 1:
            term = -term
        ans = (ans + term) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    main()
```该代码预先计算阶乘一次，最多可达$n + k$，这足以满足星条表达式中所需的所有二项式系数。 包含-排除循环仅迭代至$k/(m+1)$，因为选择超过那么多满溢的垃圾箱将迫使剩余总和为负数。 

组合函数`C(a, b)`通过返回零来安全地处理无效参数，这自然会修剪不可能的包含-排除项。 交替符号在累加答案时直接实现。

 ## 边缘情况

 一个关键的边缘情况是当$m = 0$。 唯一有效的向量是全零，只有当$k = 0$。 在包含排除公式中，所有带有$k > 0$自然消失，因为每个箱的贡献必须为零，并且组合系数变为零。 

另一个边缘情况是当$m \ge k$。 在这种情况下，没有坐标可以超出界限，因此包含-排除之和折叠为单项$i = 0$，给出标准的星形和条形结果$\binom{k+n-1}{n-1}$。 

什么时候$n = 1$，问题简化为检查是否$k \le m$。 该公式也能正确归约，因为只有一个 bin 并且只有一个候选向量存在当且仅当它遵循边界时。
