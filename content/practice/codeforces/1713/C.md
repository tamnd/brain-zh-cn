 ## 解决方案
 ## 问题理解

 我们被要求构造一个数字的排列$0$到$n-1$这样对于每个索引$i$，该索引处的值与索引本身的总和是完全平方。 换句话说，对于每一个$i$,$p_i + i = k^2$对于某个整数$k$。 输入由多个测试用例组成，每个测试用例指定一个整数$n$，并且对于每个$n$我们必须输出一个有效的排列或者用$-1$。 

约束条件告诉我们$n$可以大到$10^5$，以及所有的总和$n$所有测试用例的上限也为$10^5$。 这意味着任何解决方案都必须大致有效$O(n)$每个测试用例，因为一个天真的$O(n^2)$方法将执行高达$10^{10}$在最坏的情况下，操作速度太慢了。 

边缘情况很微妙。 小值$n$， 例如$1$或者$2$，必须明确处理，因为在下一个完全平方下对索引进行分组的逻辑可能会失败。 当出现另一个棘手的情况时$n$本身是完全平方数或略小于一：选择不超过的最大完全平方数$n-1 + (n-1)$需要仔细处理索引边界。 

## 方法

 蛮力方法会尝试所有排列$[0, 1, \dots, n-1]$并检查是否$p_i + i$是一个完美的正方形。 这种做法原则上是正确的，但也存在一些问题$n!$排列，即使对于$n = 10$。 即使为每个索引生成所有子集也太昂贵了。 

关键的观察结果是完美平方的间隔越来越远，我们希望将每个索引与一个值配对，使得总和是平方。 从最大的索引开始倒推通常会有所帮助。 如果我们从最大的索引开始$i = n-1$，我们可以找到最大的正方形不超过$i + (n-1)$， 分配$p_{n-1}$作为该平方和之间的差异$i$，并通过减少索引继续填充数组。 因为完全平方和指数之间的差异单调递减，这保证了我们只使用每个数字一次。 该方法有效地按降序“填充”连续方块之间的块。 

最优方法通过重复识别最大平方来构建排列$s^2$这样$s^2 \ge i$，并填充从当前位置到$s^2 - i$以相反的顺序。 这种贪婪策略确保每个$p_i + i$是一个正方形并且没有重复的数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 贪心建设| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`p`尺寸的`n`所有元素均未设置。 设置当前索引`i`到`n-1`，数组的最后一个位置。 
2. 虽然`i >= 0`，找到最大的整数`s`这样`s^2`大于或等于`i`。 这是我们将用于当前块的完美正方形。 
3. 计算`start = s^2 - i`。 这是索引中应该出现的值`i`使`p[i] + i = s^2`。 
4. 从索引处填充数组`start`到`i`以相反的顺序。 具体来说，分配`p[j] = start + (i - j)`为了`j`从`i`下降到`start`。 这确保了该块中的所有数字都是不同的，并且它们与索引的总和等于`s^2`。 
5. 更新`i`到`start - 1`并对其余索引重复该过程。 
6. 所有索引填满后，输出数组`p`。 

为什么它有效：保持不变的是每次我们填充一个块时，分配的所有数字都是不同的并且适合所需的索引范围。 从最大索引开始工作可确保相同的数字永远不会被分配两次。 每项任务都保证`p_i + i`等于所选的完美平方，满足“良好数组”属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = [-1] * n
        i = n - 1
        while i >= 0:
            s = math.isqrt(i)
            square = s * s
            start = square - (i - square)
            start = max(0, 2*s*s - i - 1) if square < i else square - i
            for j in range(i, start - 1, -1):
                p[j] = square - j
            i = start - 1
        print(*p)

if __name__ == "__main__":
    solve()
```该解决方案使用整数平方根来找到每个块的最大完美平方。 反向填充数组可确保每个数字只分配一次，同时保持完全平方和属性。 必须注意边界条件：`start`指数不得低于零，否则将使用负指数。 

## 工作示例

 考虑`n = 3`。 我们从`i = 2`。 最大的不小于2的正方形是`2^2 = 4`。 然后`start = 4 - 2 = 2`。 网络分配`p[2] = 4 - 2 = 2`。 移至`i = 1`。 最大的平方 ≥ 1 是`1^2 = 1`。 然后`start = 1 - 1 = 0`。 网络分配`p[1] = 1 - 1 = 0`和`p[0] = 1 - 0 = 1`。 最终数组：`[1, 0, 2]`。 

为了`n = 4`, 开始于`i = 3`。 最大平方 ≥ 3 是`2^2 = 4`。 起始索引`start = 4 - 3 = 1`。 充满`p[3] = 1`,`p[2] = 2`,`p[1] = 3`。 其余的`i = 0`，最大平方= 0，分配`p[0] = 0`。 最终阵列`[0,3,2,1]`。 

这些痕迹表明该算法正确识别每个块的最大正方形并反向填充数字以维持排列属性。

 ## 边缘情况

 对于`n = 1`，数组`[0]`微不足道地满足`p_0 + 0 = 0`，这是一个完美的正方形。 算法集`i = 0`，找到平方 = 0，赋值`p[0] = 0`。 输出是`[0]`。 

为了`n = 2`，我们必须处理索引中的第一个块`1`。 ≥ 1 的最大平方为 1。 起始索引`start = 1 - 1 = 0`。 网络分配`p[1] = 0`和`p[0] = 1`。 输出`[1,0]`，正确满足完全平方和。 这表明该算法可以正确处理小数组，而不会跳过或重复数字。
