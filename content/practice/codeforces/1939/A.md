 ## 解决方案
 ## 问题理解

 我们在 2D 平面上得到一组点，并要求我们通过按顺序连接这些点来绘制折线。 每个点必须仅用作所绘制多段线的顶点一次，并且根据问题的几何规则，所得线段不得创建无效的自相交。 输出不是数值而是结构，通常是点的排序或如何连接它们的描述。 

从概念上讲，任务是将点排列成简单的多边形链。 关键的困难在于点的任意排序几乎总是会产生线段交叉，因此核心约束隐藏在几何图形中而不是输入格式中。 

约束足够大，任何尝试所有排列的解决方案都立即不可能。 即使 n 的值适中，也会使阶乘探索无法使用，因为 2e5 左右的 n 已经意味着一个天文数字般巨大的搜索空间。 这迫使确定性构造的运行时间大约为 O(n log n) 或 O(n)。 

一些边缘情况往往会打破简单的方法。 如果多个点共享相同的 x 坐标，则纯水平排序策略可能会折叠成重叠的垂直段，根据几何规则的严格性，这些垂直段可能被解释为无效。 如果点共线，任意排序可能会导致退化重叠，在某些解释中仍然被视为不正确。 另一种微妙的情况是，当点形成“之字形”形状时，仅按一个坐标排序会产生在局部结构中并不立即明显但在全局中出现的交叉。 

## 方法

 蛮力的想法很简单：尝试点的所有可能顺序，按该顺序连接它们，并检查是否发生任何线段相交。 这是有效的，因为它直接强制执行条件，但正确性是以枚举所有 n 阶乘排列为代价的。 即使 n = 10，这也已经变得不切实际，超出这个范围就完全不可行。 

关键的观察是我们实际上不需要搜索所有排列。 我们只需要一个单一的排序来保证多边形链不相交。 这将问题从组合搜索简化为几何结构。 解决此类问题的标准技巧是利用一个坐标系中的单调排序。 如果我们按 x 坐标按字典顺序对点进行排序，并使用 y 坐标来打破平局，我们将获得一个从左到右稳定进行的序列。 这种单调性确保边不会在 x 方向上“环回”，这是朴素排序中交叉的主要原因。 

一旦点以这种方式排序，连接连续的点就会产生一条尊重平面中全局排序的链。 任何潜在的交叉都意味着违反排序顺序，这是不可能的。

 ## 算法演练

1. 读取所有点，如果需要进行输出重建，则将它们与原始索引一起存储。 这是必要的，因为该问题通常期望我们以特定顺序输出索引或坐标。 
2. 按 x 坐标对点进行排序。 如果两个点共享相同的 x 坐标，则使用 y 坐标断开连接。 这确保了平面上所有点的严格总排序。 
3. 从左到右遍历排序后的列表，并按顺序输出点作为所需的多边形链。 每个连续的对形成一个段。 
4. 从概念上解释这些片段是按顺序绘制的。 该结构保证没有路段需要在先前使用的 x 区域上“折返”，这是交叉点的主要来源。 
5. 以问题所需的格式输出结果序列，通常是索引或坐标。 

为什么有效：排序顺序会在 x 方向上产生单调链。 两个线段之间的任何交集都意味着两对点违反了沿 x 轴的全局排序，这与排序相矛盾。 这表明构造的折线在所需意义上是简单的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    for i in range(n):
        x, y = map(int, input().split())
        pts.append((x, y, i + 1))

    pts.sort()  # lexicographic by x, then y

    # output order of indices
    print(*[p[2] for p in pts])

if __name__ == "__main__":
    solve()
```实现的核心是字典排序。 Python 的元组排序自然地处理所需的平局打破，无需额外的代码。 唯一微妙的一点是确保我们保留原始索引，因为大多数构造性几何问题需要引用原始输入点而不是打印坐标。 

## 工作示例

 ### 示例 1

 假设输入点为：

 (2, 3), (1, 5), (3, 1)

 按 x 再按 y 排序后，顺序变为：

 | 步骤| 排序顺序 |
 | ---| ---|
 | 排序后| (1,5) → (2,3) → (3,1) |

 然后我们按这个顺序连接它们。 没有线段可以相交，因为每个步骤在 x 坐标中严格向右移动，因此链永远不会水平对折。 

这证实了折线在 x 中单调前进的不变量。 

### 示例 2

 考虑具有共享 x 坐标的点：

 (1, 1), (1, 4), (2, 2), (2, 5)

 排序后：

 | 步骤| 排序顺序 |
 | ---| ---|
 | 排序后 | (1,1) → (1,4) → (2,2) → (2,5) |

 即使存在垂直对齐，通过 y 进行平局也可确保顺序一致。 生成的链仍然从 x = 1 移动到 x = 2，而不反转方向，因此不会发生交叉。 

这表明相等的 x 值不会破坏结构。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque
    input = sys.stdin.readline

    n = int(input())
    pts = []
    for i in range(n):
        x, y = map(int, input().split())
        pts.append((x, y, i + 1))
    pts.sort()
    return " ".join(str(p[2]) for p in pts)

 ## 边缘情况

 关键的边缘情况是所有点共享相同的 x 坐标。 在这种情况下，忽略二次排序的简单方法可能会以任意顺序输出它们，从而可能产生退化重叠。 通过字典顺序排序，顺序完全由 y 坐标决定，因此链保持有效且一致。 

当点在 x 坐标上左右交替时，会出现另一种边缘情况，例如 (1,0)、(3,1)、(2,2)、(4,3)。 遵循输入顺序的天真贪婪行走会导致来回之字形移动，从而引入交叉。 排序通过在 x 中强制执行单一全局方向来消除这种不稳定性，因此无论输入顺序如何，构造的链都变得单调且安全。
