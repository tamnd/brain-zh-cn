 ## 解决方案
 ## 问题理解

 我们被要求计算树中交叉点子集的数量，这样，如果我们准确地将子集中的交叉点声明为危险的，则树中没有简单路径包含三个或更多危险交叉点。 输入是一棵树$n$节点，定义为$n-1$边，输出是“好”子集的数量模$998\,244\,353$。 给出多个测试用例，求总和$n$在所有情况下可达$3 \cdot 10^5$，所以我们需要一个在每棵树上大致以线性或接近线性时间运行的解决方案。 

一个天真的方法是生成所有$2^n$节点子集并检查树中每条路径的条件。 当以下情况时，这立即变得不可行$n$甚至是 20 因为$2^{20} = 10^6$子集并检查树中的所有路径需要$O(n^2)$运营。 为了$n$最多$3 \cdot 10^5$，暴力破解是完全不可能的。 

不明显的边缘情况包括树是链。 在长度为 4 的链中，包含两个中间节点和一个端点的子集形成在某条路径上具有三个危险交叉点的集合。 这表明当一个节点有多个危险的邻居时就会出现问题，这表明节点度数及其在树中的位置会影响子集的计数方式。 

## 方法

 暴力解决方案之所以有效，是因为可以根据所有路径检查任何子集。 失败点是子集的指数增长与二次路径检查相结合。 我们需要一种方法来计算好的子集而不枚举它们。 

关键的见解是利用树结构。 在树中，任何路径都是由其端点唯一确定的，因此对路径上具有三个危险节点的子集进行计数可减少为对形成长度至少为 3 的路径的节点进行计数。 如果一个节点有两个或多个同样危险的邻居并通过该节点连接，则可能会发生危险配置，因为这将创建一条具有三个危险交叉点的路径。 这一观察结果自然导致了一种动态编程解决方案，该解决方案将计数从叶子向上传播。 

我们可以为每个节点定义三种状态：它不危险，它是危险的但不与子树中任何其他危险节点相邻，或者它是危险的并且形成危险节点“对”的一部分。 使用这些状态，我们可以递归地计算以每个节点为根的子树的有效子集的数量。 乘以子节点的贡献并正确组合状态可确保子树中的路径不具有两个以上的危险节点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了 |
 | DP 树状态 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将树表示为邻接表。 这允许从任何节点到其子节点的高效遍历。 
2.定义递归DP函数`dfs(node, parent)`返回三个计数：`dp0`对于节点不危险的子集，`dp1`对于节点危险但孤立的子集，以及`dp2`对于其中节点与危险子节点形成对的一部分的子集。 
3. 对于叶节点，`dp0 = 1`因为空集是有效的，`dp1 = 1`因为仅将叶子标记为危险是有效的，并且`dp2 = 0`因为它没有孩子可以组成一对。 
4. 对于内部节点，初始化`dp0 = dp1 = 1`和`dp2 = 0`。 遍历每个孩子并递归获取孩子的`dp0, dp1, dp2`。 按如下方式更新计数：乘以`dp0`经过`(child.dp0 + child.dp1 + child.dp2)`因为非危险节点可以有任何有效的子子集，所以乘以`dp1`经过`(child.dp0 + child.dp1)`因为单个危险节点不能有一个子节点对`dp2`，并乘以`dp2`经过`(child.dp0 + child.dp1)`但也增加了组合的贡献`dp1`该节点的`dp1`的孩子来解释形成一对。 
5.处理完所有children后，返回tuple`(dp0, dp1, dp2)`对于节点。 好组的总数是`dp0 + dp1 + dp2`在根部。 
6. 应用模数$998\,244\,353$每次操作时避免溢出。 

为什么有效：这三种状态形成了所有有效子集的完整划分。 组合逻辑确保子树中的任何路径最多有两个危险节点，因为`dp2`准确跟踪可以形成长度为 2 且带有危险节点的路径的对。 将子项的贡献相乘可以正确计算所有有效配置，而不会重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        edges = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            edges[u - 1].append(v - 1)
            edges[v - 1].append(u - 1)

        def dfs(u, parent):
            dp0, dp1, dp2 = 1, 1, 0
            for v in edges[u]:
                if v == parent:
                    continue
                c0, c1, c2 = dfs(v, u)
                new_dp2 = (dp2 * (c0 + c1 + c2) + dp1 * c1) % MOD
                dp1 = (dp1 * (c0 + c1)) % MOD
                dp0 = (dp0 * (c0 + c1 + c2)) % MOD
                dp2 = new_dp2
            return dp0, dp1, dp2

        result = sum(dfs(0, -1)) % MOD
        print(result)

solve()
```该代码首先读取测试用例的数量，然后为每棵树构建邻接列表。 递归函数`dfs`遍历树，计算三个 DP 状态。 更新会仔细跟踪组合，以避免具有三个危险节点的路径。 我们将根部的 DP 状态相加，以获得良好集合的总数并打印结果。
