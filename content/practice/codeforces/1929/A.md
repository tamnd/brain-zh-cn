 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们可以按任意顺序重新排列其元素。 

特定排列的美感被定义为连续元素之间的差异之和：$$(a_2-a_1)+(a_3-a_2)+\cdots+(a_n-a_{n-1})$$我们的任务是选择能够产生尽可能最大美感的排序。 

输入包含多个测试用例。 对于每个测试用例，我们接收数组元素，并且必须在重新排列它们后输出可实现的最大美感。 

限制非常小。 数组长度最多为100，测试用例最多为500个。 甚至一个$O(n^2)$解决方案很容易足够快。 挑战不在于性能，而在于认识隐藏在美丽公式中的数学简化。 

一个常见的错误是认为安排本身很重要。 例如，可以尝试交替放置小数字和大数字：```
1 100 2 99
```并计算$$(100-1)+(2-100)+(99-2)=98$$这看起来很大，但并不是最佳的。 更简单的安排，```
1 2 99 100
```给出$$(2-1)+(99-2)+(100-99)=99$$当所有值都相等时，会出现另一种边缘情况：```
5 5 5
```每个差异都为零，所以答案一定是：```
0
```如果粗心地假设答案总是肯定的，那么这里就会失败。 

第三个重要的情况是最小数组大小：```
2
1 10
```美丽就是简单$10-1=9$，因为只有一个连续的差异。 

## 方法

 强力解决方案将生成数组的每个排列，计算其美度，并保留最大值。 

这是有效的，因为它直接检查每个可能的排列。 对于长度的数组$n$， 有$n!$排列。 即使是为了$n=10$，这已经是 3,628,800 种排列。 自从$n$可以是100，暴力破解是完全不可能的。 

关键的观察来自于扩展美容公式：$$(a_2-a_1)+(a_3-a_2)+\cdots+(a_n-a_{n-1})$$所有中间条款取消：$$-a_2+a_2,\quad -a_3+a_3,\quad \ldots$$仅保留第一个和最后一个元素：$$a_n-a_1$$这意味着任何安排的美感仅取决于其第一个和最后一个元素。 

一旦问题减少到最大化$$a_n-a_1,$$答案就显而易见了。 我们应该将最小值放在前面，将最大值放在最后。 那么美丽就变成了$$\max(a)-\min(a).$$没有其他排列可以做得更好，因为没有元素小于最小值，也没有元素大于最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取数组。 
2. 找到数组的最小元素。 
3. 找到数组的最大元素。 
4. 输出最大值和最小值之差。 

这样做的原因是美容公式总是包含以下内容：$$a_n-a_1.$$为了最大化该数量，我们将最小值放在开头，将最大值放在末尾。 

### 为什么它有效

 美的表达是一个伸缩总和。 每个内部元素恰好出现两次：一次带有正号，一次带有负号。 这些贡献相互抵消。 

因此，任何排列的美感都等于最后一个元素减去第一个元素。 通过选择全局最大值作为最后一个元素、全局最小值作为第一个元素来获得最大可能值。 他们的区别正是$\max(a)-\min(a)$，这是可实现的最大的美丽。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max(a) - min(a))
```实现直接遵循数学观察。 

对于每个测试用例，数组都会被读取一次。 Python 的内置`max()`和`min()`函数扫描数组并返回最大值和最小值。 他们的差异就是答案。 

不存在棘手的边界条件。 长度为 2 的数组很自然地起作用，因为答案只是较大元素和较小元素之间的差异。 具有相同值的数组也可以工作，因为最大值和最小值相等，产生零。 

这些值可以大到$10^9$，但 Python 整数可以轻松处理它们，而无需担心溢出。 

## 工作示例

 ### 示例 1

 输入数组：```
2 1 3
```| 步骤| 价值|
 | --- | --- |
 | 最低 | 1 |
 | 最大| 3 |
 | 回答 | 3 - 1 = 2 |

 输出：```
2
```这体现了核心思想。 尽管可以进行多次重新排列，但最大的美感只是最大值和最小值之间的差异。 

### 示例 2

 输入数组：```
100 54 80 43 90
```| 步骤| 价值|
 | --- | --- |
 | 最低 | 43 | 43
 | 最大| 100 | 100
 | 回答 | 100 - 43 = 57 | 100 - 43 = 57

 输出：```
57
```一种最佳的安排是：```
43 54 80 90 100
```谁的美丽在于$$(54-43)+(80-54)+(90-80)+(100-90)=57.$$该迹线证实只有最小值和最大值才重要。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans.append(str(max(a) - min(a)))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out
