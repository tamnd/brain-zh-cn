 ## 解决方案
 ## 问题理解

 我们有一个$n \times n$网格。 每个单元恰好属于两个对角线方向中的每个对角线方向的一个对角线。 该问题计算两个方向，因此网格总共包含$2n-1$一种类型的对角线和$2n-1$另一种类型的对角线，总共$4n-2$对角线。 

我们希望对尽可能少的细胞进行着色，同时至少制作$k$这些对角线包含一个彩色单元格。 如果对角线上至少有一个彩色单元格，则认为该对角线被覆盖。 

输入给出了几个测试用例。 对于每个测试用例，我们都会收到网格大小$n$以及所需数量$k$覆盖的对角线。 我们必须输出需要着色的最小数量的单元格。 

这些约束立即表明答案必须用一个简单的公式来计算。 网格尺寸可达$10^8$，这使得任何实际构建网格的方法都是不可能的。 如果对每个测试用例都进行迭代，那么即使迭代所有对角线也会太昂贵。 由于最多可以有$1000$测试用例时，目标复杂度本质上是每个用例的恒定时间。 

一个微妙的点是，单一颜色的单元格最多可以覆盖两条对角线，每个方向各一条。 粗心的解决方案可能会假设每个彩色单元格总是贡献两条新的对角线，但当几乎所有对角线都已被覆盖时，这种情况在临近结束时就不再成立。 

考虑$n=2$,$k=3$。 有$6$总对角线。 一个彩色单元格最多可以覆盖$2$对角线，因此需要两个单元格。 正确答案是$2$， 不是$\lceil 3/2 \rceil = 2$纯属巧合。 我们需要一个证据来证明这在总体上仍然有效。 

另一个边缘情况出现时$k$非常接近最大值。 例如，$n=3$,$k=10$。 网格正好有$10$对角线。 答案是$6$， 不是$5$。 理论上，五个单元格最多可以覆盖十条对角线，但由于中心单元格是唯一同时位于两条最长对角线上的单元格，因此覆盖最后剩余的对角线需要一个额外的单元格。 网格的建设性结构很重要。 

## 方法

 强力的观点是将每个单元格视为覆盖两条对角线。 我们可以将对角线建模为需要覆盖的对象，并搜索覆盖对角线至少达到的最小单元集$k$。 这本质上是一个集合覆盖问题$n \times n$网格。 

即使对于中等值$n$， 有$n^2$细胞。 和$n$一样大$10^8$，网格包含$10^{16}$细胞，因此任何单独检查细胞的算法都是完全不可行的。 

关键的观察是网格的中心反对角线恰好包含$n$细胞。 该反对角线上的每个单元格都属于不同的主对角线。 同时，它们都属于同一个反对角线。 

如果我们沿着这条反对角线对单元格进行着色，每个新着色的单元格通常会贡献两条先前未覆盖的对角线：一条新的主对角线和公共反对角线。 第一个彩色单元格覆盖两条对角线。 同一反对角线上的每个附加单元都恰好多了一条新对角线，因为共享反对角线已经被覆盖。 

这让我们涵盖了所有$2n$与这些相关的对角线$n$细胞精确地使用$n$有色细胞。 更重要的是，直到$2n$覆盖对角线，每对对角线都可以用一个单元格获得。 因此，对于$k \le 2n$，答案很简单$\lceil k/2 \rceil$。 

毕竟$2n$该结构的对角线被覆盖，每个剩余的未覆盖的对角线都需要一个额外的单元。 有$4n-2-2n = 2n-2$这样的对角线。 因此，对于$k > 2n$，我们首先花费$n$要覆盖的单元格$2n$对角线，然后每个剩余的所需对角线增加一个单元格。 

得出公式$$\text{answer}= \begin{cases} \left\lceil \frac{k}{2}\right\rceil, & k\le 2n \\ n + (k-2n), & k>2n \end{cases}$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$或者更糟|$O(n^2)$| 太慢了 |
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读$n$和$k$。 
2. 检查是否$k \le 2n$。 
3.如果是，则返回$\lceil k/2 \rceil$。 在整数算术中，这是$(k+1)//2$。 
4. 否则，使用$n$覆盖第一个单元格$2n$对角线。 
5. 计算还需要多少条额外的对角线：$$k - 2n.$$6. 剩余的每条对角线都需要一个额外的彩色单元格，因此返回$$n + (k-2n).$$### 为什么它有效

 一个彩色单元格最多可以覆盖两条对角线。 尽管$k \le 2n$，我们总是可以选择单元格，以便每个彩色单元格贡献两条新的对角线，使得$\lceil k/2 \rceil$既可实现又最佳。 

反对角线结构正好达到$2n$使用覆盖对角线$n$细胞。 那些之后$2n$对角线已耗尽，每个剩余的未覆盖对角线只能将每个添加的单元格的计数增加一。 因此，每增加一个所需的对角线就会花费一个额外的彩色单元。 该公式既匹配下界又匹配显式构造，因此是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())

    if k <= 2 * n:
        print((k + 1) // 2)
    else:
        print(n + (k - 2 * n))
```直接按照公式执行即可。 

第一个分支处理每个彩色单元格可以排列以覆盖两条新对角线的区域。 使用`(k + 1) // 2`执行上限除法而不进行浮点运算。 

第二个分支对应第一个分支的情况`2 * n`对角线已经被覆盖使用`n`细胞。 每增加一个所需的对角线就会多花费一个单元格，因此我们添加`k - 2 * n`到`n`。 

所有计算都适合 64 位整数。 Python 整数是无界的，因此不存在溢出问题。

import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())

        if k == 4 * n - 2:
            ans.append(str(2 * n - 1))
        else:
            ans.append(str((k + 1) // 2))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    out = sys.stdout.getvalue()

    sys.stdout = backup_stdout

    return out

 ## 边缘情况

 考虑：```
1
2 6
```这里$k = 4n-2$。 必须覆盖所有对角线。 算法进入特殊情况并返回：$$2n-1 = 3$$输出：```

```一个普通的天花板划分会产生$\lceil 6/2 \rceil = 3$这里也是如此，但对于更大的网格，区别就变得至关重要。 

考虑：```
1
3 9
```我们有：$$4n-2 = 10$$自从$k \neq 10$，该算法使用$$\left\lceil \frac{9}{2} \right\rceil = 5.$$输出：```
5
```这会检查紧邻最大值下方的边界。 下限仍然可以实现，因此不需要特殊处理。 

考虑：```
1
3 10
```现在$k$等于对角线的总数。 算法返回$$2n-1 = 5.$$输出：```
5
```这是通用下界参数需要调整的独特情况。 精确覆盖每条对角线需要$2n-1$细胞，特殊情况正确捕获。
