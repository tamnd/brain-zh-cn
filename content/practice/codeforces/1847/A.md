 ## 解决方案
 ## 问题理解

 该问题要求我们将一系列村民（每个村民都有一个数字怀疑级别）准确地划分为`k`以最小化这些组的总“力量”的方式划分连续的组。 一个群体的权力被定义为该群体中连续村民之间的绝对差异之和。 例如，一组`[1, 4, 2]`有权力`|1-4| + |4-2| = 3 + 2 = 5`。 一个只有一个村民的小组权力为零。 

输入给出了多个测试用例。 每个测试用例包括`n`, 村民人数,`k`、所需组的数量和一个数组`a`的怀疑级别。 输出是将村民精确划分为三等分后的最小权力总和`k`连续的组。 村民必须保持原来的秩序； 我们无法对它们重新排序。 

限制很小：`n`最多可以是 100，`k`至多是`n`，每个怀疑级别最多为 500。由于`n`很小，每个测​​试用例的运行时间为 O(n log n) 甚至 O(n²) 的解决方案是可行的。 然而，我们需要有效地处理多达 100 个测试用例。 

一个重要的边缘情况是所有村民都有相同的怀疑程度，例如`[5, 5, 5, 5]`。 那么绝对差值全部为零，并且任何分组的总功率为零。 另一个微妙的情况是当`k = n`，这意味着每个村民都在一个单例组中； 这里总功率始终为零。 

## 方法

 天真的方法是尝试所有可能的放置方式`k-1`村民之间的割裂。 对于每个配置，我们计算每个结果组的功效并对它们求和。 这是正确的，但计算量很大，因为有`C(n-1, k-1)`选择削减的方式，增长迅速`n`和`k`。 即使与`n=100`，这太慢了。 

关键的观察结果是，没有任何切割的整个阵列的总功率是所有连续绝对差的总和，即`sum(|a[i+1]-a[i]| for i in range(n-1))`。 如果我们必须将数组分成`k`组中，我们所做的每次切割都会从总功率中精确地消除一个绝对差异，即切割两侧两个元素之间的差异。 因此，要最小化后的总功率`k-1`削减，我们应该删除最大的`k-1`连续的差异。 

这将问题简化为简单的贪婪策略：计算所有连续差异，按降序对它们进行排序，然后减去最大的总和`k-1`与总和的差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n-1, k-1) * n) | O(C(n-1, k-1) * n) | O(n) | 太慢了 |
 | 因差异而贪婪| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`k`，然后读取数组`a`的怀疑级别。 
2. 计算连续村民之间的绝对差异，`diff[i] = |a[i+1]-a[i]|`为了`i=0`到`n-2`。 这些代表了对邻近村民总权力的贡献。 
3. 计算没有削减的总功率作为所有元素的总和`diff`。 这是消除任何差异之前的起始总数。 
4. 排序`diff`数组按降序排列。 最大的差异是如果保持不变的话对总功率贡献最大的差异。 
5. 删除`k-1`通过从总功率中减去它们的总和来获得最大差异。 这模拟放置`k-1`削减以打破这些最大差异的群体。 
6. 输出所得的总功率。 

为什么它有效：不变的是任何削减都会从总数中恰好删除一个连续的差异。 为了最小化总功率，我们希望消除最大的差异。 排序确保我们可以选择顶部`k-1`有效地差异化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        # compute consecutive differences
        diff = [abs(a[i+1] - a[i]) for i in range(n-1)]
        total = sum(diff)
        
        # remove largest k-1 differences
        diff.sort(reverse=True)
        total -= sum(diff[:k-1])
        print(total)

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 为了清晰和快速，使用列表理解来计算差异。 按降序排序可确保顶部`k-1`差异很容易从总数中减去。 最终的打印语句输出每个测试用例的最小总功率。 

## 工作示例

 输入示例：```
4 2
1 3 5 2
```计算差异：`[2, 2, 3]`总金额：`2 + 2 + 3 = 7`我们需要`k=2`组，因此删除最大差异`3`最小化功率：`7 - 3 = 4`第二个例子：```
6 3
1 9 12 4 7 2
```差异：`[8, 3, 8, 3, 5]`总金额：`8 + 3 + 8 + 3 + 5 = 27`消除`k-1 = 2`最大的差异`8 + 8 = 16`最小化功率：`27 - 16 = 11`这与预期的输出相匹配。

 ## 边缘情况

 当`k = n`，每个村民都是一个单独的群体。 删除的差异是`n-1`最大的，这就是所有的差异。 总功率为零。 什么时候`k = 1`，没有删除任何差异，因此总功率是所有连续差异的总和。 该算法可以正确处理具有重复元素的数组、具有交替高点和低点的数组以及最小和最大组计数。
