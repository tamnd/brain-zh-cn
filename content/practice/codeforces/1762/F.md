 ## 解决方案
 ## 问题理解

 我们被要求计算数组中“好对”的数量。 一对位置$(l, r)$如果我们可以从索引中移动就很好$l$到$r$通过沿着索引序列在数组中向前跳跃，其中每个连续对最多相差$k$。 简单来说，你可以把数组中的每个数字看成一块垫脚石，只要石块之间的差值最多为$k$。 我们的任务是计算允许有效步进路径的所有可能的起始和结束位置。 

输入包含多个测试用例，每个测试用例都有一个长度的数组$n$最多$5 \cdot 10^5$，以及所有的总和$n$跨测试用例也受$5 \cdot 10^5$。 这排除了任何算法$O(n^2)$每个测试用例，因为在最坏的情况下我们会达到$2.5 \cdot 10^{11}$3秒内完成的操作是完全不可能的。 一个$O(n \log n)$或者$O(n)$方法是必要的。 

很容易破坏简单实现的边缘情况包括具有所有相同元素的数组、具有严格递增或递减值的数组，以及$k = 0$。 例如，使用数组`[1,1,1]`和$k = 0$，每个子数组都很好，答案是 6。仅检查连续元素的粗心方法会丢失像这样的对`(1,3)`。 

## 方法

 蛮力方法是迭代所有对$(l,r)$并检查每一对是否存在有效的连接序列$l$到$r$。 这原则上是有效的，因为它直接对好对的定义进行建模，但它是$O(n^2)$每个测试用例。 和$n$最多$5 \cdot 10^5$，这显然是不可行的。 

关键的见解是，如果我们可以从索引转向$i$索引$j$，然后之间的所有连续索引$i$和$j$保持绝对差异$\le k$可以折叠成一个连续的“好片段”。 一旦我们确定了从每个索引开始的最大范围，我们就可以在不违反的情况下向前移动$|a[i] - a[i+1]| \le k$，我们可以使用简单的算术公式计算从该索引开始的好对的数量，而不是枚举每对。 

具体来说，我们从数组的左侧维护一个滑动窗口，一直延伸到右端，直到满足条件$|a[r] - a[r-1]| \le k$失败。 每个扩展一次添加多个好对，避免$O(n^2)$成本。 这将问题转化为$O(n)$每个测试用例，因为每个索引最多被访问两次：一次作为左指针，一次作为右指针。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 滑动窗| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$,$k$，和数组$a$。 我们将独立处理每个数组。 
2. 初始化结果计数器`res`为零。 这将累积好对的数量。 
3.初始化两个指针，`l = 0`和`r = 0`。 指针`l`代表候选好片段的左端，并且`r`表示在保持的情况下可到达的最远索引$|a[r] - a[r-1]| \le k$。 
4. 迭代数组`l`从 0 到$n-1$。 处理前，扩展`r`尽可能同时`r < n`和$|a[r] - a[r-1]| \le k$（为了`r > l`）。 这确保了`[l, r)`形成一个连续的好段。 
5. 好对的数量起始于`l`正是`r - l`。 将其添加到`res`。 
6. 增量`l`并重复。 自从`r`永远不会向左移动，总运行时间是线性的。 
7.处理完数组后，打印`res`。 

为什么它有效：该算法维护一个连续的段`[l, r)`其中任意一对`(l, x)`为了`x`在`[l, r-1]`保证是好的。 这个不变量成立是因为条件$|a[i] - a[i+1]| \le k$沿线段具有传递性。 通过计数`r - l`对于每个`l`，我们将所有好的对恰好枚举一次，而不会重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    res = 0
    r = 0
    for l in range(n):
        if r < l:
            r = l
        while r + 1 < n and abs(a[r+1] - a[r]) <= k:
            r += 1
        res += r - l + 1
    print(res)
```外循环迭代段的每个潜在左端。 内部 while 循环扩展`r`只要数组允许，同时尊重`k`-差异条件。 支票`if r < l: r = l`确保右指针永远不会落后于左指针。 计数`r - l + 1`正确地添加所有好的对开始于`l`。
