 ## 解决方案
 ## 问题理解

 我们被要求考虑顶点编号从 1 到$n$，其中每条边都有权重$1$或者$-1$。 如果对于每个顶点，与该顶点相关的所有边的权重的乘积等于，则称一棵树为好树$-1$。 任务是，给定$n$，计算沿边距顶点的距离总和$1$到顶点$n$在所有好树上，模$998{,}244{,}353$。 

输入是单个整数$n$，输出是一个整数，表示这个和模$998{,}244{,}353$。 

约束条件$1 \le n \le 5 \cdot 10^5$立即排除显式生成所有树，因为有$n^{n-2} \cdot 2^{n-1}$总边权重树。 即使是为了$n = 10^3$，这个数字是一个天文数字。 因此，任何解决方案都必须使用组合或代数推理，而不是暴力枚举。 

非明显的边缘情况包括$n = 1$，其中唯一的树没有边，因此总和为零。 当出现另一个微妙之处时$n = 2$，其中唯一的边必须有权重$-1$，给出总和$-1$模数$998{,}244{,}353$。 任何生成树的幼稚尝试都将无法扩展或正确应用“好树”条件。 

## 方法

 暴力方法会尝试枚举所有$n^{n-2}$树木和所有$2^{n-1}$边权重分配，检查每个顶点的“良好”条件，然后求和$d(1,n)$对于那些通过的人。 这种方法显然是不可行的，因为即使$n=20$大致产生$20^{18} \cdot 2^{19} \approx 10^{26}$的可能性。 

关键的见解是我们根本不需要生成树。 普吕弗序列的一个众所周知的组合结果告诉我们，有$n^{n-2}$标记的树木。 为边分配权重，使每个顶点的关联积为$-1$每个顶点恰好引入一个线性约束。 这导致了一个简单的奇偶观察：$n = 1$，答案为零； 为了$n \ge 2$，正好有一条边需要有权重$-1$沿着从 1 到$n$，其余的可以自行安排。 使用模算术和组合公式计算这些可能性给出$O(1)$的幂公式$2$和$-1$。

 ## 算法演练

 1.读取整数$n$来自输入。 
2. 定义模数$MOD = 998244353$处理大量数据。 
3.如果$n = 1$，打印 0 并返回，因为没有边缘。 
4. 否则，计算$-1$模数$MOD$作为$MOD - 1$。 这说明了从 1 到 1 的路径上唯一的边$n$必须做出贡献$-1$于一切善树中。 
5. 计算$2^{n-2} \mod MOD$。 这表示在不违反“好树”属性的情况下独立分配剩余边权重的方法数量。 
6. 将步骤 4 中的值乘以步骤 5 中的值并取模$MOD$以获得最终答案。 
7. 打印结果。 

为什么有效：每棵好树都会沿着 1 贡献一条路径总和$n$正是$-1$乘以所有其他独立权重分配。 独立作业的数量为$2^{n-2}$。 这个不变量对于任何$n \ge 2$，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input().strip())
    if n == 1:
        print(0)
        return
    # The only edge along 1->n must be -1
    ans = (MOD - 1) * pow(2, n - 2, MOD) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```解决方案如下$n$安全使用`.strip()`，处理边缘情况$n = 1$，并使用`pow`具有有效模幂的三个参数，避免溢出。

 | n | 模组 | 计算| 回答 |

 为了$n = 4$：

 | n | 模组 | 计算| 回答 |

 | 4 | 998244353 | (-1) * 2^2 % MOD | 998244353 - 4 = 998244349 |

 这些表表明，该公式捕获了边缘分配的多重性，同时确保路径 1→n 做出贡献$-1$。

 ## 边缘情况

 关键的边缘情况是$n = 1$和小$n$价值观像$2$和$3$。 为了$n = 1$，没有边，因此总和为零。 为了$n = 2$，唯一的边有权重$-1$，模 998244353 得到 998244352。该算法通过条件检查和模运算正确处理这些。 该公式自然延伸至大$n$由于独立边权重分配的乘法特性，避免了显式枚举。
