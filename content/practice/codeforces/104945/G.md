 ## 解决方案
 ## 问题理解

 每道菜都有两个属性：味道评分和摆盘评分。 每个人还有两个偏好，它们充当这两个相同属性的权重。 一个人通过使用自己的权重对菜肴的味道和摆盘价值进行加权求和来评估菜肴。 任务是为每个人确定哪道菜使该评价最大化。 如果多个菜品达到相同的最佳值，则必须选择指数最小的菜品。 

直接阅读表明每个人都可能评估每道菜，而评分函数是两个变量的简单线性表达式。 这立即将问题置于几何设置中：每个盘子都是平面上的一个点，每个人定义一个方向，我们在该方向上投影所有点，并取最大点积。 

限制很大，多达50万菜品、50万人。 任何检查所有菜肴和人对的方法都需要大约 2.5 × 10^11 次评估，这远远超出了可行的极限。 即使对所有菜肴进行每人线性扫描也会太慢。 

关键微妙之处在于，菜和人都生活在同一个二维空间，评价是点积。 这种结构可以实现几何优化，而不是强力比较。 

一些边缘情况需要小心。 首先，关系必须通过最小索引来解决，因此仅跟踪最大值的解决方案还必须保持索引排序。 

其次，退化的方向很重要。 如果一个人的体重是（0，P），那么只有电镀很重要； (T, 0) 类似。 任何几何变换都不能假设两个坐标都严格为正。 

第三，如果尝试标准化为浮点斜率，就会出现精度陷阱； 整数运算的比较必须保持精确。 

## 方法

 暴力解决方案评估每个人的每道菜。 对于权重为 (T, P) 的人 l，我们计算所有 k 的 T·t_k + P·p_k 并取最大值。 这是正确的，因为它直接实现了定义。 然而，其成本为 O(NM)，在最坏的情况下需要 2.5 × 10^11 次乘法和加法，因此无法使用。 

关键的观察是，每道菜都是一个点（t_k，p_k），每个人都在这些点上定义一个线性函数。 该问题简化为在一组静态 2D 点上回答许多最大点积查询。 这是一个经典的几何查询问题，其中预处理点的凸包可以实现有效的最大投影查询。 

关键的见解是，对于任何固定方向 (T, P)，一组点上 Tt + Pp 的最大值出现在凸包的极值点处。 内部点永远不可能是最优的，因为它们是边界点的凸组合，因此不能超过外壳顶点在任何线性方向上实现的最大值。 

因此，我们首先计算所有碟点的凸包。 按 x 坐标对点进行排序并构造上下壳后，我们获得了代表所有潜在最佳菜肴的多边形。 然后，每个查询都简化为找到该凸多边形的顶点，从而最大化与给定方向向量的点积。 由于凸多边形上的点积沿着其顶点按循环顺序是单峰的，因此我们可以根据顺序使用三元搜索或旋转指针方法来预先计算和回答查询。 

为了支持快速查询，我们可以在 O(N log N) 中预先计算外壳，然后在 O(log H) 中回答每个查询，其中 H 是外壳大小，对凸多边形顶点使用三元搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(NM) | O(1) | O(1) | 太慢了|
 | 凸包 + 查询搜索 | O(N log N + M log N) | O(N log N + M log N) | O(N) | 已接受 |

## 算法演练

 ## 步骤 1：将菜肴表示为点

 每个盘子 k 表示为 2D 空间中的一个点 (t_k, p_k)。 这将评估重新定义为使用查询向量计算点积。 

## 步骤 2：计算碟点的凸包

 按字典顺序对所有点进行排序，并使用单调堆栈构建上下船体。 凸形状内部的点将被丢弃。 

此步骤是正确的，因为任何线性目标都会在极值点处的凸集上达到最大值。 内点永远不可能在所有方向上占主导地位。 

## 步骤3：为循环查询准备外壳

 按顺序存储外壳顶点，形成凸多边形。 确保顺序一致（顺时针或逆时针）。 

## 步骤4：将每个人作为方向查询进行处理

 对于每个具有权重 (T, P) 的人，将其解释为方向向量。 我们必须找到最大化 T·x + P·y 的船体顶点。 

## 步骤 5：对凸多边形使用三元搜索

 由于凸多边形上的点积沿其顶点是单峰的，因此对外壳索引应用三元搜索。 在每个中点比较时，评估点积并丢弃较差的一面。 

如果点积相等，则通过比较指数来处理平局。 

##第六步：输出结果

 返回最佳船体顶点对应的菜的索引。 

### 为什么它有效

 凸包恰好包含那些不能表示为其他点的凸组合的点。 由于目标函数是线性的，因此任何内部点总是受各个方向上的某个边界点支配。 凸多边形上的线性函数的最大值必须出现在顶点处。 因此，将搜索空间限制为外壳顶点可以保持正确性。 沿船体边界的点积的单峰性确保三元搜索正确找到全局最大值而不会丢失局部最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def dot(p, q):
    return p[0] * q[0] + p[1] * q[1]

def convex_hull(points):
    points.sort()
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def best_vertex(hull, v):
    n = len(hull)
    l, r = 0, n - 1

    def f(i):
        return dot(hull[i], v)

    while r - l > 3:
        m1 = l + (r - l) // 3
        m2 = r - (r - l) // 3
        if f(m1) < f(m2):
            l = m1
        else:
            r = m2

    best = l
    for i in range(l, r + 1):
        if f(i) > f(best) or (f(i) == f(best) and hull[i][2] < hull[best][2]):
            best = i
    return hull[best][2]

def main():
    N, M = map(int, input().split())
    points = []
    for i in range(N):
        t, p = map(int, input().split())
        points.append((t, p, i + 1))

    hull = convex_hull(points)

    for _ in range(M):
        T, P = map(int, input().split())
        print(best_vertex(hull, (T, P)))

if __name__ == "__main__":
    main()
```实现首先使用标准单调链方法计算凸包。 每个点都保留其原始索引，以便可以毫不含糊地处理平局决胜。 

查询函数对船体执行三元搜索。 目标函数被评估为与查询向量的点积。 对最后几个候选者的最终线性扫描确保了三元搜索停止细化的小区间内的正确性。 

一个微妙的点是打破平局的规则。 当两个菜肴产生相同的分数时，必须选择指数最小的一个，因此当点积匹配时，实现会比较原始指数。

 ## 边缘情况

 当所有碟形天线位于平面上的一条直线上时，就会出现关键的边缘情况。 在这种情况下，每个点都是凸包的一部分，算法简化为扫描所有顶点。 对于与线对齐的查询方向，多个点可以并列。 该实现通过跟踪原始索引并选择最小的索引来解决此问题，确保确定性输出。 

另一种边缘情况是当一个人的权重向量与一个轴完全对齐时，例如 (T, 0)。 在这种情况下，点积仅取决于 t_k，而最佳菜肴就是口味得分最高的菜肴。 凸包仍然包含所有候选者，并且三元搜索可以正确评估极端 x 值所在的端点。 

最后一种情况涉及非相邻外壳顶点的重复最优值。 三元搜索可能会停止在包含多个相等候选者的小区间内，但该区间上的最终线性扫描可保证检查所有内容并选择最小索引。
