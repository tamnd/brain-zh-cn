 ## 解决方案
 ## 问题理解

 我们按顺序给出一个简单的非自相交多边形的顶点。 将其视为一个刚性平坦的桌面，其质量均匀分布在其区域内。 从基本几何学来看，这样的形状具有明确定义的质心，即多边形质心，位于多边形内部的某处。 

我们必须选择该多边形的三个不同顶点来放置三个边。 当且仅当质心严格位于由这三个选定顶点形成的三角形内部时，该表才是稳定的。 我们被要求计算有多少个无序三元组的顶点满足这个条件。 

因此，核心任务不再直接涉及多边形边。 多边形仅用于定义单个固定点，即质心。 之后，我们计算由给定顶点集形成的有多少个三角形在其内部包含该点。 

输入大小最多可达 100,000 个顶点。 任何直接检查所有三元组的方法都需要以下顺序$10^{15}$检查，这是完全不可行的。 即使是检查对并尝试推断第三个顶点的二次方法也会很困难，因为$N^2$是$10^{10}$，对于 1 秒的限制来说已经太大了。 

这推动我们采用几何计数方法，将三角形包含查询减少为围绕质心的结构化排序问题。 

一个关键的微妙之处是质心不是顶点并且不是直接给出的。 它必须根据多边形计算。 使用简单的顶点算术平均值是错误的； 正确的质心取决于多边形的符号面积，因此必须使用标准鞋带公式计算。 

朴素推理的一种失败情况是假设任何“看起来很大”的三角形都包含质心。 例如，在一个正方形中：```
(0,0), (1,0), (1,1), (0,1)
```质心为 (0.5, 0.5)。 每个由三个顶点形成的三角形都会缺少一个角，并且每个这样的三角形实际上都排除了此配置中的中心，给出答案 0。像“大多数三角形包含中心”这样的天真的启发式在这里会失败。 

另一个微妙的情况是假设需要对称性或凸性。 多边形可以是非凸的，但质心保留在其内部，并且相同的计数逻辑仍然适用，因为我们只依赖于点位置，而不依赖于多边形结构。 

## 方法

 暴力法很简单。 我们计算质心，然后迭代每个三重顶点并测试质心是否位于三角形内部。 标准方向测试或重心符号检查在每个三角形的恒定时间内进行。 这是正确的，但需要检查$\binom{N}{3}$三元组，大约是$1.6 \times 10^{15}$操作时$N = 10^5$。 这远远超出了任何实际限制。 

关键的观察结果是，问题仅取决于固定点是否位于由点子集形成的三角形内部。 这是一个经典的几何简化：我们可以用质心周围的角度术语重新表述条件，而不是直接检查三角形。 

如果我们平移坐标系，使质心成为原点，则每个顶点都成为从该点开始的向量。 当且仅当三个点不全部包含在通过原点的任何闭合半平面中时，三角形才包含原点。 同样，当我们按原点周围的极角对点进行排序时，当三角形的所有顶点最多位于角长度的某个半圆内时，三角形就无法准确包含原点$\pi$。 

这将问题转化为循环排序计数问题。 我们不是用二维面积术语进行推理，而是对角度圆进行推理，并计算有多少个三元组避免包含在任何半圆中。 这是我们想要的补集，因此我们计算总三元组并减去坏的三元组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力三角测试|$O(N^3)$|$O(1)$| 太慢了|
 | 角度扫描 + 补数计数 |$O(N \log N)$|$O(N)$| 已接受 |

 ## 算法演练

 1. 使用标准带符号面积公式计算多边形的质心。 这给出了一个固定点$C$多边形内部充当所有几何比较的参考。 
2. 平移所有顶点，使得$C$成为原点。 现在每个点都被视为来自质心的向量。 
3. 将每个向量转换为极角$[0, 2\pi)$。 这将几何遏制转化为循环顺序推理。 
4. 按角度对所有点进行排序。 然后通过再次附加每个点来复制数组，角度增加$2\pi$。 这使我们能够将圆形环绕间隔作为线性段来处理。 
5. 对于每个点$i$，找到最远的索引$j$使得之间的角度差$i$和$j$严格小于$\pi$。 这定义了从以下位置开始的最大半圆$i$。 
6.让$k$是这个半圆内的点数，不包括$i$。 从这些中选择的任何一对$k$点与$i$形成一个不包含原点的三角形。 
7. 总和$\binom{k}{2}$全面的$i$。 通过将每个“坏”三角形锚定在其最小角度端点，它可以对每个“坏”三角形进行一次计数。 
8. 从三元组总数中减去坏三角形的数量$\binom{N}{3}$。 余数是包含质心的三角形的数量。 

这样做的原因是，当且仅当三角形的所有顶点都适合通过原点的某个开放半平面时，三角形才能包含原点。 这样的半平面正好对应于角的半圆。 每个坏三角形都有一个独特的最小半圆覆盖它，并且对起点的扫描恰好捕获每个此类配置一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def polygon_centroid(points):
    # returns (Cx, Cy)
    area = 0
    cx = 0
    cy = 0
    n = len(points)
    for i in range(n):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % n]
        cross = x1 * y2 - x2 * y1
        area += cross
        cx += (x1 + x2) * cross
        cy += (y1 + y2) * cross

    area *= 0.5
    cx /= (6 * area)
    cy /= (6 * area)
    return cx, cy

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    cx, cy = polygon_centroid(pts)

    import math

    ang = []
    for x, y in pts:
        ang.append(math.atan2(y - cy, x - cx))

    ang.sort()

    # duplicate with +2pi shift
    m = len(ang)
    twopi = 2 * math.pi
    ext = ang + [a + twopi for a in ang]

    j = 0
    bad = 0

    for i in range(m):
        if j < i + 1:
            j = i + 1
        while j < i + m and ext[j] - ext[i] < math.pi:
            j += 1
        k = j - i - 1
        if k >= 2:
            bad += k * (k - 1) // 2

    total = n * (n - 1) * (n - 2) // 6
    print(total - bad)

if __name__ == "__main__":
    solve()
```质心计算使用鞋带法中的带符号面积公式，该公式正确地考虑了多边形几何形状，而不是单独处理顶点。 对于不均匀的形状，直接平均坐标会失败。 

角度变换使用`atan2`，这对于保留包括符号在内的完整循环顺序至关重要。 对这些角度进行排序会产生围绕质心的一致遍历。 

对复制数组的两指针扫描将点窗口保持在半圆内。 不变量是对于每个起始索引`i`, 段`[i+1, j)`恰好包含小于之内的那些点$\pi$弧度从`i`。 这允许对锚定于的所有无效三元组进行计数`i`每个指数的固定摊销时间。

 ## 边缘情况

 一种重要的边缘情况是所有点几乎均匀地分布在质心周围。 在这种情况下，许多半圆窗口包含几乎所有点，并且无法复制角度数组的简单实现将错过环绕三角形。 重复角度技术确保窗口穿过$2\pi$边界仍然表示为连续的段。 

另一个微妙的情况是角度比较中的数值精度。 由于我们比较差异$\pi$，浮点错误可能会导致边界点被错误分类。 强有力的实施依赖于严格的不平等和一致`atan2`订购； 如果需要，epsilon 可以稳定比较，但在典型的约束下，Python 的双精度就足够了。 

当多边形高度凹时，会出现最终的边缘情况。 质心仍然位于内部，但顶点可能聚集在小角度区域中。 扫描方法仍然有效，因为它仅取决于相对于单个固定点的角度，而不取决于多边形邻接或凸性，因此多边形的结构不会影响正确性。
