 ## 解决方案
 ## 问题理解

 我们有一个无限网格，其行和列从 1 开始。通过绕着越来越大的正方形的边界走动，单元格被连续的整数填充。 任务是找到包含给定数字 n 的单元格的坐标。 

重要的观察是填充不是任意的。 完成边长为 k 的正方形后，正好填充了 k² 个单元格。 这意味着每个数字都属于一个正方形层，主要的挑战是快速找到该层，然后定位其边界内的位置。 

n的值可以大到10^8，因此模拟填充过程是不可能的。 即使是 O(√n) 模拟也是不必要的，因为答案仅取决于正方形层和一些算术运算。 该解决方案必须使用 64 位整数运算在恒定时间或接近恒定时间内工作。 

一个常见的错误是使用浮点平方根。 对于接近 10^⁸ 的值，浮点计算可能会错误舍入并将 n 放入错误的层中。 例如，一个恰好是正方形的数字，例如 16，必须属于 4 x 4 边界。 粗心的实现可能会计算出稍小的平方根，并将其视为属于前一层，从而产生错误的坐标。 

另一个边缘情况是最小的可能值。 用于输入`1`，答案是`1 1`。 假设该层具有先前方块的代码将失败，因为第一层没有先前的单元格。 

另一个重要的边界是层的末端。 例如，数字`9`是 3 x 3 平方的最后一个值。 它的坐标是`1 3`。 如果实现使用严格比较而不是包含比较，则可以将该值移动到下一层。 

## 方法

 直接的方法是逐个单元地构建螺旋。 从第一个单元格开始，我们继续沿着方形边界移动并计数，直到到达 n。 这是正确的，因为它完全遵循数字的书写顺序。 然而，最大的输入包含高达 10^8 的值，因此访问的单元格数量也可能在 10^8 左右。 这种模拟不可能在任何实际时间内完成。 

螺旋结构提供了更快的方法。 边长为 k 的正方形恰好包含 k² 个单元，因此包含 n 的层是最小的 k，其中 k² 至少为 n。 一旦知道了这一层，第一个 (k-1)2 数字就已经在我们身后了。 剩余的偏移量告诉我们 n 位于当前方形边界上的位置。 

边界方向仅取决于 k 是奇数还是偶数。 在奇数层中，新的正方形从左下角开始向右移动，然后沿着右侧向上移动。 在偶数层中，它从右上角开始向下移动，然后沿着底部向左移动。 这让我们可以在不访问任何其他单元格的情况下计算答案。

 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 找到最小整数 k，使得 k² 至少为 n。 这是包含 n 的方形边框的边长。 该边界之前的单元格数量为`(k - 1)²`，因此层中的每个数字都可以通过其与该值的偏移量来识别。 
2. 计算`offset = n - (k - 1)²`。 偏移量介于 1 和`2k - 1`，因为方形边框恰好添加了那么多新单元格。 
3. 如果k为奇数，则从左下角开始处理边界。 当偏移量最多为k时，数字位于最底行，因此行为k，列为偏移量。 否则，数字位于右列，从底部向上移动，因此行减少，而列保持 k。 
4. 如果k是偶数，则从右上角开始处理边界。 当偏移量最大为k时，数字位于右列，因此行是偏移量，列是k。 否则，数字位于底行，向左移动，因此行保持 k，而列减少。 

为什么它有效：

 每层 k 恰好包含将前一个正方形从边长 k-1 延伸到边长 k 的单元格。 该算法首先识别这个独特的层，因为所有较小的层都包含精确的`(k-1)²`单元格和当前层在 k² 处结束。 在图层内部，由于边界遍历顺序是固定的，因此偏移量唯一确定了位置。 由于边界上的每个可能位置都被恰好覆盖一次，因此计算出的坐标必须与 n 的位置匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    k = int(n ** 0.5)
    while k * k < n:
        k += 1
    while (k - 1) * (k - 1) >= n:
        k -= 1

    offset = n - (k - 1) * (k - 1)

    if k % 2 == 1:
        if offset <= k:
            row = k
            col = offset
        else:
            row = 2 * k - offset
            col = k
    else:
        if offset <= k:
            row = offset
            col = k
        else:
            row = k
            col = 2 * k - offset

    print(row, col)

if __name__ == "__main__":
    solve()
```层计算找到第一个足够大以包含 n 的正方形。 使用校正循环是因为初始平方根来自浮点运算，并且输入范围足够大，可能会出现舍入误差。 

偏移计算将全局数字转换为仅在一个方形边框内的位置。 这避免了对早期层大小的任何依赖。 

奇偶校验控制遍历方向。 奇数和偶数正方形大小具有相反的起始角，因此使用错误的分支将镜像整个正方形的答案，并在大约一半的输入上失败。 

Python 整数具有任意精度，因此即使 k² 等中间值可以接近 10^⁸，也不存在溢出问题。

 ## 边缘情况

 用于输入`1`，算法发现 k = 1 且 offset = 1。由于 k 为奇数且偏移量位于前 k 个单元格内，因此它将值放置在第 1 行、第 1 列。这避免了尝试访问不存在的先前方格。 

用于输入`9`，算法发现 k = 3，因为 9 恰好是一个正方形。 偏移量为 5，因为八个单元属于先前层。 由于 k 为奇数且偏移量大于 k，因此该数字与 row 位于右侧列`2 * 3 - 5 = 1`, 给予`(1,3)`。 这确认了精确的平方值已分配给正确的图层。 

用于输入`16`，算法移动到 k = 4 的下一层。偏移量为 7，超出了右侧的前四个单元格。 剩余的移动是沿着底行，给出列`2 * 4 - 7 = 1`和第 4 行。答案是`(4,1)`，新边框的第一个单元格。
