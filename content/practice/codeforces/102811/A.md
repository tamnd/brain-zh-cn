 ## 解决方案
 ## 问题理解

 街道上每隔一段时间就有公交车站。 如果第一个车站位于位置 0，那么接下来的每个车站都正好远 K 米，因此它们的位置是 K 的倍数。Sveta 已经从街道的起点走了 N 米，并且想知道她必须步行到达任何公交车站的最短距离。 

输入包含停靠点 K 之间的间隔以及 Sveta 距起点 N 的当前距离。输出是从位置 N 到 K 倍数位置的最小距离。 

K 和 N 的值可以大到 2 * 10^9。 这立即排除了模拟街道或一一检查每一站的可能性。 在最坏的情况下，可能有数十亿次可能的停止，甚至 O(N) 解决方案也需要太多的操作。 该解决方案必须仅使用恒定数量的算术运算。 

主要的边缘情况来自恰好位于止损位置或非常接近间隔开始的位置。 在这些情况下，总是前进到下一站的粗心解决方案将会失败。 

例如，输入：```
5
10
```停靠点位于位置 0、5、10、15 等。 Sveta 已经到达终点站，因此正确答案为 0。仅计算到下一站距离的解决方案将错误地返回 5。 

另一种边界情况是最近的车站是前一个车站而不是下一个车站。 例如：```
10
14
```最近的停靠站是 10 和 20。距离是 4 和 6，因此答案是 4。始终向上舍入的解决方案将返回 6。 

最后一种情况是 Sveta 位于第一个非零停止点之前：```
100
1
```最近的车站是 0 和 100。答案是 1。街道的起点必须被视为有效的公交车站。 

## 方法

 一种直接的方法是生成每个公交车站位置并比较其与斯维塔的距离。 从位置 0 开始，我们可以检查 0、K、2K、3K 并继续，直到距离大于当前最佳答案。 

这种方法是正确的，因为每个可能的目的地都会被检查。 然而，对于给定的限制来说，它太慢了。 如果 K 为 1，N 为 2 * 10^9，则在到达 Sveta 的位置之前需要停止 20 亿次。 具有数十亿次迭代的循环无法在时间限制内完成。 

有用的观察结果是，Sveta 的位置仅取决于 K 的最接近倍数。她前面的公交车站的距离为 N 除以 K，向下舍入，乘以 K。下一站正好是其后 K 米。 无需检查任何其他站点，因为所有其他站点都较远。 

问题变成除以 K 后求余数。如果 N = q * K + r，则 r 是到前一站的距离，而 K - r 是到下一站的距离。 我们只需要这两个值中较小的一个。 当 r 为零时，Sveta 已经停止，答案为零。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N/K) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算 N 除以 K 的余数。该余数是从 Sveta 的位置到前一个公交车站的距离，因为每个车站位置都是 K 的倍数。 
2. 如果余数为零，则输出零。 Sveta 正好站在公交车站上，所以不需要移动。 
3. 否则，将余数与K减去余数进行比较。 第一个值是到前一站的距离，第二个值是到下一站的距离。 较小的就是所需的步行距离。 

只检查两个距离的原因是连续的公交车站围绕着 Sveta 的当前位置。 其他每一站都比这两站更远。 

工作原理：每个公交车站都有一个 K 倍数的位置。对于任何位置 N，整数除法将 N 分成 K 的前一个倍数和剩余偏移量。 前一站恰好是剩余路程，下一站恰好是间隔中未使用的部分。 由于这是仅有的两个最接近 N 的停靠点，因此选择较小的距离始终会给出正确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    K = int(input())
    N = int(input())

    remainder = N % K

    if remainder == 0:
        print(0)
    else:
        print(min(remainder, K - remainder))

if __name__ == "__main__":
    solve()
```输入被读取为两个整数，因为问题在不同的行上给出了 K 和 N。 顺序很重要，因为 K 定义了停靠点之间的间距，而 N 定义了 Sveta 的位置。 

表达式`N % K`给出到前一个公交车站的距离。 Python 整数不会溢出，因此可以安全地处理约束中的最大值。 

零余数检查避免了不必要的比较，并直接处理 Sveta 已经停止的情况。 对于所有其他情况，将比较两个可能的方向。 该实现不使用舍入或浮点运算，这避免了精度误差和差一错误。

 ## 边缘情况

 对于输入：```
5
10
```余数是`10 % 5 = 0`。 该算法立即返回 0，因为 Sveta 正好停止。 这处理了不需要向任一方向移动的情况。 

对于输入：```
10
14
```余数是`14 % 10 = 4`。 上一站距离4米，下一站距离6米。 该算法选择 4，这是正确的最短路径。 

对于输入：```
100
1
```余数是`1 % 100 = 1`。 前一站是街道起点 0 号位置，距离仅 1 米。 下一站距离为 99 米，因此算法返回 1。 

对于输入：```
10
15
```余数是`5`。 两个相邻的车站距离酒店均有 5 米。 最小运算返回5，正确处理两个方向距离相同的情况。
