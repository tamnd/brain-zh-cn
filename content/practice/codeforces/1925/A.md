 ## 解决方案
 ## 问题理解

 我们被要求在前 k 个小写字母上构建一个字符串，以便由这 k 个字母形成的每个可能的长度为 n 的字符串作为子序列出现在其中的某个位置。 子序列意味着我们可以从构造的字符串中删除字符而无需重新排序剩余的内容，并且仍然可以获得目标字符串。 

关键要求非常严格：我们不仅仅是嵌入一些模式，而是所有 kⁿ 可能的长度为 n 的序列。 由于n和k都最多为26，因此在最坏的情况下所需的字符串总数已经是天文数字，但构造的字符串可以大量重用结构，因为子序列可以以灵活的方式重叠。 

输出也必须尽可能短。 这迫使我们避免冗余结构，因为任何不必要的字符重复只会增加非最佳的机会。 

一种简单的方法会尝试显式确保每个长度为 n 的字符串显示为子序列。 人们可能会尝试连接所有 kⁿ 字符串，或者贪婪地附加缺失的字符串。 这会立即失败，因为 kⁿ 呈指数增长，即使对于像 n = 10、k = 2 这样的小输入，所需的字符串也将变得不可行。 

更微妙的失败来自于模式的贪婪串联，例如重复“abc ...”。 这可能包括许多子序列，但它不能保证覆盖长度 n 的所有组合。 例如，当 k = 2 且 n = 2 时，字符串“abab”不包含“bb”作为子序列，因此它已经不够了。 

问题的结构表明我们需要一种通用结构，隐式编码所有序列而不枚举它们。 

## 方法

 暴力策略会枚举所有 kⁿ 字符串，并尝试将它们合并成子序列关系下的最短超序列。 这本质上是指数集上的最短常见超序列问题。 甚至表示状态空间也变得不可能，因为每个长度为 n 的字符串都会产生约束，并且合并它们需要指数时间和内存。 

关键的见解是扭转观点。 我们不是考虑明确地覆盖所有长度为 n 的序列，而是构造一个字符串，允许我们通过位置“路由”任何选择序列。 如果我们重复仔细选择的结构，我们可以通过按顺序选择字符的出现来确保可以嵌入任何所需的序列。 

最佳构造出人意料地简单：按顺序从 k 个字母字母表开始，然后重复 n 次。 这会产生一个字符串，其中每个字母都出现在每个“层”中，允许我们通过始终从连续层中获取出现次数来选择长度为 n 的任何序列。 

为什么这有效与后续灵活性有关。 稍后重复中字符的每次出现都可以代表任何所需字符串中的下一步。 通过确保每个深度都有 k 个选择，我们可以避免一个选择阻碍另一个选择的冲突。 

最小性源于以下事实：每个所需的字符串至少需要按顺序分布 n 个出现，并且每个位置有 k 个选择，我们无法在不失去分离子序列位置的能力的情况下进一步压缩层。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| O(kⁿ·n) | O(kⁿ) | 太慢了 |
 | 分层结构| O(nk) | O(nk) | O(nk) | O(nk) | 已接受 |

 ## 算法演练

1. 构建由前 k 个字母按递增顺序组成的基本字母字符串。 这在单个“级别”提供了所有可用符号。 
2. 准确地重复该基本字符串 n 次并连接结果。 每次重复都充当一个新层，其中子序列可以向前推进一步。 
3. 输出结果字符串。 

每次重复都是必不可少的，因为子序列必须能够从严格晚于第 (i-1) 个字符的位置中选取目标字符串的第 i 个字符。 如果没有重复的层，我们就无法保证排序约束。 

### 为什么它有效

 任何长度为 n 的目标字符串都可以通过将其第 i 个字符映射到重复分层结构中该字符的第 i 次出现来嵌入。 由于每一层都包含所有 k 个字母，因此我们永远不会被迫重复使用相同的出现两次，并且跨层的排序保证了子序列条件。 这建立了从目标字符串中的位置到构造字符串中的位置的单调映射。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    base = ''.join(chr(ord('a') + i) for i in range(k))
    print(base * n)
```该解决方案为每个测试用例构建一次字母前缀并重复 n 次。 唯一的微妙之处是确保我们独立地处理每个测试用例，因为 n 和 k 都不同。 

正确性完全取决于维护每个重复块中的完整字母表。 任何排列或减少字母表的尝试都会破坏映射任意序列的能力。

 构造：“abcabcabc”

 | 步骤| 目标人物| 选择的位置 |

这表明排序纯粹是通过块​​索引来处理的，而不是通过块内的字符顺序来处理的。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(nk) | O(nk) | 构造 k 长度的基本字符串并重复 n 次 |
 | 空间| O(nk) | O(nk) | 结果输出字符串的大小 |

 这些约束允许每个测试最多 26 个字符和 26 次重复，因此每个测试用例的输出大小最多为 676 个字符，这在限制内计算和打印很简单。

 ## 边缘情况

 对于 k = 1，结构简化为重复单个字符 n 次。 每个长度为 n 的字符串都是唯一确定的，因此结果基本正确，因为唯一可能的字符串是重复的单个字母。 

对于 n = 1，要求将前 k 个字母中的每个字符包含为子序列。 该结构成为字母串本身，因此每个字符都直接出现。 

对于较大的 k 和 n，分层重复可确保子序列不会竞争位置，因为每一层都是独立的并且完全包含字母表。 这可以防止不同目标序列之间的任何排序冲突。
