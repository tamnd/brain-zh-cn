 ## 解决方案
 ## 问题理解

 我们有一个图表`n`孩子们。 仅有的`m`配对被标记为朋友，并且每个友谊边都有一个初始权重`f`。 

老师表演得很到位`k`短途旅行。 在每次旅行期间，从所有可能的对中均匀随机地选择一对无序的孩子。 同一对可能会被选择多次，因为每次选择都是独立的。 

如果所选对是友谊边，则会发生两件事：

 首先，该边的当前友谊值有助于得出此游览的答案。 

其次，游览结束后，该边的好感度加一，影响以后的游览。 

如果所选对不是友谊边，则其贡献为零并且永远不会改变。 

我们必须计算所有的预期总贡献`k`短途旅行。 答案是一个有理数。 我们被要求输出它的模数`10^9+7`，这意味着将分子乘以分母的模逆。 

图本身是稀疏的。 在所有测试用例中，友谊边的总数最多为`10^5`，而总的旅行次数最多为`2·10^5`。 这立即排除了对所有可能的友谊值状态的任何模拟。 可能的历史数量呈指数增长`k`。 

关键的挑战是友谊价值观随着时间的推移而演变。 如果之前已经选择过，那么友谊优势就会变得更有价值。 乍一看，这会在偏移之间产生依赖性，但期望使我们能够比直接概率状态模拟所建议的更积极地分离过程。 

一些边缘情况值得关注。 

考虑一个没有友谊边的图：```
n = 100
m = 0
k = 24
```每个选定的对贡献为零。 答案恰好是零。 任何除以友谊边数或假设至少一个友谊的公式都必须处理这种情况。 

考虑最小的非平凡图：```
n = 2
m = 1
k = 3
f = 5
```可能的对只有一对，因此每次都会选择它。 贡献是：```
5 + 6 + 7 = 18
```独立对待每次游览并始终使用原始友谊值的解决方案将错误地产生`15`。 

另一个微妙的情况是当友谊值不同时：```
n = 3
m = 2
edges:
(1,2) = 100
(2,3) = 1
```未来选择产生的预期增长仅取决于选择友谊边的频率，而不取决于它们的初始权重。 错误地混合这两种效果通常会导致重复计算。 

## 方法

 蛮力方法将对整个随机过程进行建模。 

每次旅行我们都会选择其中一个`C(n,2)`对。 如果它是友谊优势，它的价值就会增加。 进程的状态是当前友谊值的向量。 一步之后有很多种可能的状态，两步之后更多，而之后`k`国家的数量变得巨大。 

即使我们只跟踪每个友谊边被选择了多少次，状态空间大小也大约是最多的整数组合的数量`k`之中`m`边缘，这是完全不可行的。 

蛮力的想法是正确的，因为它完全遵循过程，但在达到问题极限之前很久就变得不可能了。 

解锁解决方案的观察结果是期望的线性。 

不要跟踪整个州，而是一次专注于一次旅行。 

让```
T = C(n,2)
```是可能对的总数。 

假设一条边以友谊值开始`f`。 

如果我们现在正在旅行`i`（0-索引），该边的值等于```
f + (# times this edge was selected during previous i excursions)
```先前选择的预期数量很容易计算。 

每次旅行都会以概率选择这条边```
1 / T
```独立。 

其中第一`i`偏移，该边被选择的预期次数是```
i / T
```因此，偏移时该边缘的预期值`i`是```
f + i/T
```以及在偏移时选择边缘的概率`i`又是```
1/T.
```因此，在偏移期间该特定边缘的预期贡献`i`是```
(1/T) · (f + i/T).
```总结所有友谊边给出```
(Σf)/T + m·i/T².
```现在将所有短途旅行的总和`i = 0 ... k-1`。 

第一项变为```
k·Σf / T.
```第二项变为```
m/T² · Σi
= m/T² · k(k-1)/2.
```这已经是最终的公式了。 

整个概率过程分解为两个聚合值：```
S = Σf
```和```
m.
```有关图表的其他信息并不重要。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | k 的指数 | 指数| 太慢了 |
 | 最佳 | 每个测试用例 O(m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`m`， 和`k`。 
2. 计算```
T = n(n-1)/2
```这是无序子对的总数。 
3.读取所有友谊边并积累```
S = Σf.
```单个端点永远不会出现在最终公式中，只有初始友谊值的总和才重要。 
4. 计算初始友谊值的预期贡献：```
k · S / T.
```每次旅行都会以概率选择特定的友谊边缘`1/T`。 
5. 计算友谊价值增加产生的预期贡献：```
m · k(k-1)/2 / T².
```游览用`i`，每条友谊边缘都有预期的额外价值`i/T`，并对所有边和所有偏移求和产生该项。 
6. 将两项模相加`10^9+7`。 
7. 使用模逆`T`和`T²`来代表各部门。 

### 为什么它有效

 对于任何友谊边，其当前值等于其初始值加上之前被选择的次数。 

先前选择的次数是独立指标变量的总和。 根据期望的线性度，其后的期望`i`早期的游览正是`i/T`。 

期望不要求边缘值与在偏移时选择边缘的事件之间独立`i`，因为我们直接计算```
E[ value × indicator ]
```作为```
(1/T) × E[value].
```当前偏移的指示器独立于确定当前值的所有早期偏移。 

将所有友谊边缘和所有短途旅行的这些期望相加，就可以准确得出预期的总贡献。 由于每次变换都保持期望相等，因此最终公式是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())

    for _ in range(t):
        n, m, k = map(int, input().split())

        s = 0
        for _ in range(m):
            a, b, f = map(int, input().split())
            s = (s + f) % MOD

        T = n * (n - 1) // 2

        invT = pow(T % MOD, MOD - 2, MOD)
        invT2 = invT * invT % MOD

        part1 = (k % MOD) * s % MOD * invT % MOD

        pairs_sum = (k % MOD) * ((k - 1) % MOD) % MOD
        pairs_sum = pairs_sum * pow(2, MOD - 2, MOD) % MOD

        part2 = (m % MOD) * pairs_sum % MOD * invT2 % MOD

        ans = (part1 + part2) % MOD
        print(ans)

solve()
```直接按照推导公式实现。 

变量`s`存储所有初始友谊值的总和。 由于最终表达式中只出现总和，因此我们永远不需要存储各个边。`T`是可能的无序对的数量。 素数模除法是使用模逆来实现的。 自从```
T²
```出现在第二项中，我们计算`invT`一次并平方。 

数量```
k(k-1)/2
```可能非常大，因此每次乘法都以模进行`MOD`。 

一个常见的错误是使用以下方法计算第二项`k(k+1)/2`。 正确的求和是```
0 + 1 + ... + (k-1),
```这等于`k(k-1)/2`。 

另一个常见的错误是忘记只有友谊边缘才能获得价值。 第二项相乘的因子是`m`，而不是对的总数。

 ## 边缘情况

 ### 没有友谊边缘

 输入：```
1
5 0 10
```我们有：```
S = 0
m = 0
```公式变为```
10·0/T + 0 = 0.
```没有一对对做出任何贡献，所以答案正确为零。 

### 只有一对可能

 输入：```
1
2 1 4
1 2 3
```这里`T = 1`。 

公式给出：```
4·3 + 1·(4·3/2)
= 12 + 6
= 18.
```实际的值序列是：```
3, 4, 5, 6
```其总和也是`18`。 

### 巨大的友谊价值

 输入：```
1
3 1 1
1 2 1000000000
```答案应该很简单```
1000000000 / 3.
```模算术可以正确处理这个问题，因为所有除法都是使用模逆来执行的。 不会发生溢出，因为 Python 整数是无界的，并且所有最终计算都会减少模数`10^9+7`。
