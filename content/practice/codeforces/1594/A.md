 ## 解决方案
 ## 问题理解

 我们被要求表示一个给定的正整数$n$作为某个时间间隔内连续整数的总和$[l, r]$，其中两个端点都是整数并且$l < r$。 区间可以扩展到负数，因此我们不限于正数序列。 任务是构造任何这样的区间，其连续总和等于$n$。 

以更结构化的方式重写要求，我们需要找到无限整数行的一段，使得算术级数从$l$并结束于$r$总和正好等于$n$。 段的长度不是固定的，不同的测试用例可能需要完全不同的段长度。 

关键的限制是$n$可以大到$10^{18}$，并且最多有$10^4$测试用例。 这立即排除了任何尝试按时间间隔搜索或增量模拟总和的方法。 任何解都必须计算$l$和$r$直接在每个测试用例的恒定时间内进行。 

一种幼稚的方法会尝试修复$l$，然后延伸$r$同时跟踪金额。 这可能需要迭代到$O(\sqrt{n})$每个测试用例或更糟取决于策略，这在这种规模下是不可行的。 

一个更微妙的问题是间隔可以过零并包含负数。 例如，表示像 2 这样的小正数可能需要使用$[-1, 2]$。 这打破了分段必须为正或以零为中心的任何直觉。 

主要的隐藏挑战是认识到我们不需要有界或独特的表示。 任何有效的连续区间都有效，这表明存在建设性公式而不是搜索。 

## 方法

 蛮力的想法是尝试每一个可能的起点$l$在合理的范围内并计算部分总和，直到我们达到或超过$n$。 对于每个$l$，我们会增加$r$并计算总和$l + (l+1) + \dots + r$。 即使我们巧妙地限制搜索，候选者的数量$l$的顺序是$O(\sqrt{n})$，并且对于每个我们可以执行另一次线性扫描。 这会导致最坏情况的复杂性远远超出可接受的限制$n$达到$10^{18}$。 

关键的观察是连续段的总和可以用代数表达。 总和来自$l$到$r$是一个算术级数：$$S = \frac{(l + r)(r - l + 1)}{2}$$我们可以自由选择该段的长度。 这种自由使我们能够强制建立一个始终有效的结构。 

标准技巧是确定一个方便的长度并求解起点。 如果我们选择线段长度$k = r - l + 1$， 然后：$$n = \frac{k(2l + k - 1)}{2}$$重新排列：$$2n = k(2l + k - 1)$$如果我们修复$k$，我们可以解出$l$:$$l = \frac{2n/k - k + 1}{2}$$目标是选择一个$k$这保证了解决方案的完整性和存在性。 

更简单的构造路径完全避免了整除推理：选择$k$作为二除法的最大幂$2n$。 这确保了除掉 2 的所有因数后，剩余的表达式允许整数恢复$l$。 这是可行的，因为我们只需要一种有效的表示，而不是全部。 

一次$k$选择后，我们直接计算$l$， 进而$r = l + k - 1$。

 ## 算法演练

 1. 对于每个测试用例，从给定值开始$n$并从概念上考虑将其加倍以与$2n$。 这很有用，因为算术级数的求和公式自然会引入除以 2 的过程，并且预先清除它可以避免以后进行分数推理。 
2. 计算$k$，最大的二元幂$2n$。 此步骤隔离了最大“干净”段长度，以便在以后除以 2 时保持完整性。我们选择 2 的幂的原因是它们完全控制二进制结构中的分母行为，这与整数整除 2 的行为相匹配。 
3.一次$k$确定后，计算起点$l$使用重新排列的等差数列公式：$$l = \frac{2n/k - k + 1}{2}$$这确保了构造的段恰好具有所需的总和。 
4. 将端点计算为$r = l + k - 1$。 这保证了段长度恰好是$k$。 
5、输出$l$和$r$作为此测试用例的答案。 

### 为什么它有效

 正确性取决于每个算术段和可以写为$k(2l + k - 1)/2$。 通过选择$k$吸收 2 的所有因数$2n$，我们确保剩余的表达式$2l + k - 1$变为整数。 这保证了$l$由公式计算得出的结果是积分。 由于我们显式构造$r$从$l$，该段有效，代入求和公式可以精确重建$n$。 该算法不依赖于猜测，仅依赖于和公式的受控因式分解和代数求逆。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x = 2 * n
        
        k = 1
        while x % 2 == 0:
            x //= 2
            k *= 2
        
        # now x is odd part of 2n, k is highest power of 2
        # reconstruct l using derived formula
        # original 2n = k * x
        l = (x - k + 1) // 2
        r = l + k - 1
        
        print(l, r)

if __name__ == "__main__":
    solve()
```该代码独立处理每个测试用例，并且完全以整数算术工作。 循环提取两个的幂计算最大的$k$划分$2n$。 之后公式直接重构$l$， 和$r$由固定长度得出。 

一个微妙的点是所有算术都保持在 64 位安全范围内，因为即使在$10^{18}$，乘以 2 并除以 2 的幂都在范围内。 除法步骤是通过构造精确的，因此不存在浮点风险。 

## 工作示例

 ### 示例 1：$n = 6$我们计算$2n = 12$。 

| 步骤| x| k | l 计算| r |
 | ---| ---| ---| ---| ---|
 | 初始化| 12 | 12 1 | - | - |
 | 除以 2 | 6 | 2 | - | - |
 | 除以 2 | 3 | 4 | - | - |
 | 停止| 3 | 4 | (3 - 4 + 1)/2 = 0 | 3 |

 结果间隔是$[0, 3]$。 其总和为$0 + 1 + 2 + 3 = 6$，确认正确性。 

### 示例 2：$n = 25$我们计算$2n = 50$。 

| 步骤| x| k | l 计算| r |
 | ---| ---| ---| ---| ---|
 | 初始化| 50 | 50 1 | - | - |
 | 除以 2 | 25 | 25 2 | - | - |
 | 停止| 25 | 25 2 | (25 - 2 + 1)/2 = 12 | 13 |

 间隔为$[12, 13]$。 然而，这太短了，无法清楚地说明结构，因此检查总和：$12 + 13 = 25$，完全匹配。 

这些迹线表明该方法通过二次幂分解自动调整段长度。

 ## 边缘情况

 一个重要的边缘情况是$n = 1$。 该算法产生$2n = 2$， 所以$k = 2$， 和$l = (1 - 2 + 1)/2 = 0$,$r = 1$。 该段$[0, 1]$总和正确为 1，并且该公式在最小输入时不会收支平衡。 

另一种情况是当$n$是 2 的大幂。 例如$n = 2^{30}$。 然后$2n$具有很大的二次幂因子，使得$k$非常大。 计算出的$l$变为零，区间从 0 延伸到$k-1$，正确地求和为$n$因为算术结构与二进制缩放完全一致。 

第三种情况是当$n$很奇怪。 这里$2n$只有二​​分之一，所以$k = 2$。 这迫使解决方案始终返回长度为 2 的线段，通常围绕$n/2$，即使不再存在分解也能确保正确性。
