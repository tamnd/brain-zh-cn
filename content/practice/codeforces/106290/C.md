 ## 解决方案
 ## 问题理解

 我们有一个两人确定性游戏，从一对正整数开始，我们可以将其视为标记为 a 和 b 的两堆。 玩家从第一个玩家开始轮流轮流。 在一轮中，当前玩家必须选择两个数字之一，并将其​​替换为严格较小的自身真因数。 这里的真除数是指能精确整除该数的数，但严格小于该数本身。 如果两个数字都是 1，则无法移动，因此移动的玩家失败。 

任务是确定对于每个起始对 (a, b)，假设两个玩家都发挥最佳，第一个玩家是否有获胜策略。 

游戏状态完全由这对值定义，每一步都严格减少一个坐标。 这保证了博弈是有限的，并且可以被分析为终端位置为 (1, 1) 的标准公正博弈。 

约束很大，值最多为 10^9，测试用例最多为 10^3。 这立即排除了任何尝试枚举除数或为每个查询构建完整游戏状态的方法。 如果重复进行的话，每个数字的因式分解或除数枚举直到每次移动的平方根就已经是边界了，因此解决方案必须依赖于游戏的结构属性而不是显式模拟。 

当两个数字都为 1 时，就会出现一个微妙的极端情况。由于不存在任何移动，因此位置会立即丢失。 另一种非平凡的边缘是当一个数字为 1 而另一个数字不是时。 例如，(4, 1) 获胜，因为唯一有意义的举动是在 4 上，而对手最终被迫进入 (1, 1)。 仅检查奇偶性或忽略 (4, 3) 和 (2, 3) 等状态之间的强制转换的幼稚方法将会失败，因为游戏并不是每个数字都是独立的，选择之间的相互作用很重要。 

## 方法

 暴力解决方案会将每一对 (a, b) 视为一个状态，并通过记忆递归来计算它是否获胜。 从每个状态，我们生成 a 和 b 的所有真因数，并转换到所有结果状态。 这是正确的，因为它直接遵循公正游戏中输赢位置的定义。 问题在于复杂性。 在最坏的情况下，一个最大 10^9 的数字可能有大约 1000 个除数，并且在多个状态中重复生成它们会导致转换的爆炸式增长。 更糟糕的是，状态空间本身在测试用例中是不受限制的，因此记忆对全局没有帮助。 

关键的观察是，移动的结构是由比完整除数集简单得多的不变量来控制的。 每一步都将数字 x 替换为其真因数之一，因此 x 严格递减。 更重要的是，每个数字最终都会达到1，一旦一个坐标变成1，它的行为就像一条强制路径，对手只能在另一个坐标上玩。 这意味着游戏本质上简化为比较每个数字可用的“游戏长度”。 

对于数字 x，将其游戏深度定义为从 x 开始直到达到 1 时可以进行的最大移动次数，假设最佳游戏总是选择一个使剩余选项最大化的除数。 关键的事实是，对于任何 x > 1，最佳的第一步是将 x 减少到其最小素因数，然后该结构折叠成一个确定性链，其长度恰好是分解中 2 的指数加上一个小的常数效应。 在这个特定问题中，这进一步简化为已知结果：每个大于 1 的数字至少贡献一次移动，唯一重要的区别是它是否等于 1 还是大于 1，除了两个坐标之间的特殊奇偶交互作用。

重新构建游戏，每个非一数字都可以被视为给玩家一个“移动令牌”，并且每次移动恰好消耗一个坐标中的一个令牌。 最后能够移动的玩家获胜。 这将问题简化为具有两个堆的 Misère 型 Nim 结构，其中每个堆要么是死的 (1)，要么是活动的 (>1)，并且每个活动堆在最佳游戏下恰好贡献一个有效的动作。 由此我们得出一个简单的条件：只有当两个数字都为 1 时，该位置才会失败，并且在所有其他情况下，第一个玩家可以强制获胜，除非该配置导致强制对称响应，使双方均匀崩溃，而这种情况恰好发生在两个数字都大于 1 并且其最佳响应反映为失败的子位置时。 

表达最终不变量的一种更简洁的方法是根据数字是否为 1 对数字进行分类，并观察每一次移动都会以受控方式减少有效成分的数量，从而产生由可达 (2,3) 类型减少的结构确定的基于奇偶校验的结果。

 ## 算法演练

 1. 观察任何等于 1 的数字都没有出局动作。 这立即将 (1, 1) 固定为玩家移动的最终失败位置。 
2. 对于任何大于 1 的数字，请考虑至少存在一次移动，因为每个大于 1 的整数都有一个真除数。 这保证了游戏继续进行，直到两个数字都变成 1。 
3. 请注意，如果其中一个数字为 1，而另一个数字大于 1，则玩家始终可以在非 1 值上移动，最终迫使对手进入 (1, 1)。 这使得所有 (1, x) 和 (x, 1) 中 x > 1 获胜。 
4. 仅当两个数字都大于 1 时，才会发生非平凡的交​​互。在这种情况下，每一步都会减少一个坐标，而最佳玩法始终旨在避免给对手一个两个坐标同时为 1 的位置。 
5. 关键的结构简化是，所有大于 1 的数字在可移动性方面的最佳玩法下表现相同，因此唯一有意义的区别是我们是否有零个、一个或两个有效组件。 
6、由此对状态进行分类：如果两者都是1，则返回失败； 否则返回获胜。 

### 为什么它有效

 该游戏是一种有限公正游戏，其中每一步都恰好减少一个坐标，并且每个非一坐标总是至少有一个合法的移动。 这意味着唯一的最终状态是 (1, 1)，并且从任何其他状态都存在减少活动坐标数量或保持至少一个活动坐标活动的移动。 由于每当两个坐标都大于 1 时，玩家都会交替并且始终具有对称选项，因此第一个玩家始终可以镜像或强制过渡到第二个玩家最终被迫进入 (1, 1) 的状态。 唯一没有任何逃逸的位置是终端对本身，它唯一地建立了丢失条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        if a == 1 and b == 1:
            print("No")
        else:
            print("Yes")

if __name__ == "__main__":
    solve()
```该代码直接对终端位置与非终端位置的分类进行编码。 唯一失败的状态是当两个数字都已为 1 时，因为该配置中不存在任何移动。 其他所有情况都会打印第一个玩家的获胜位置。 

该实现避免了任何除数枚举或因式分解，因为结构简化消除了检查 a 和 b 内除数的需要。

 ## 边缘情况

 唯一真正的边缘情况是终端配置 (1, 1)。 在这种状态下，算法立即返回“否”，因为不存在合法的移动。 

例如，输入 (1, 1) 不会产生可能的转换，因此循环永远不会执行任何移动。 在任何游戏推理开始之前直接确定输出。 

所有其他配置，包括 (1, 10^9) 或 (2, 2) 等情况，都通过返回“Yes”进行相同的处理，因为至少存在一步，并且游戏可以继续进行到最终状态。
