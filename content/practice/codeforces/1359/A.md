 ## 解决方案
 ## 问题理解

 我们有一个甲板包含`n`卡，其中`m`是小丑。 卡片均匀分布在`k`玩家，所以每个玩家都会收到准确的`n / k`牌。 

分数仅取决于小丑的分布方式。 假设一名玩家最终拥有最多的小丑。 让`x`是该玩家手中的王牌数量，让`y`成为所有其他玩家中小丑数量最多的。 获胜者的得分是`x - y`。 如果多个玩家并列最大小丑数，则分数变为`0`。 

我们可以自由想象使获胜者得分最大化的小丑分布。 任务是计算最大可能得分。 

限制很小。 最多有 500 个测试用例，`n ≤ 50`。 即使效率相当低的方法也可以在限制内轻松运行。 尽管如此，问题的结构还是导致了一个直接的数学解决方案，该解决方案在每个测试用例的恒定时间内运行。 

第一个微妙的情况发生在小丑数量少于玩家手牌容量时。 

例子：```
n = 8, m = 3, k = 2
```每个玩家可以持有`4`牌。 一名玩家可以拿走所有`3`小丑，不给其他玩家留下任何东西。 答案是`3`，不是由均匀分布的小丑衍生出来的。 

当小丑数量超过一名玩家所能容纳的数量时，就会出现第二种微妙的情况。 

例子：```
n = 8, m = 7, k = 2
```一个玩家最多可以持有`4`小丑，因为他们的手只包含`4`牌。 给予一名球员后`4`小丑，还有`3`小丑离开了。 剩下的小丑必须交给其他玩家，所以分数是`4 - 3 = 1`。 

粗心的解决方案只会返回`min(m, n/k)`会错误地返回`4`。 

另一个重要的情况是剩余的小丑平分给其他玩家。 

例子：```
n = 12, m = 9, k = 3
```获胜者获得`4`小丑。 剩下五个小丑。 为了尽量减少最强的对手，我们尽可能将他们均匀地分布在两名玩家中。 一名对手必须收到`ceil(5/2) = 3`小丑。 分数是`4 - 3 = 1`。 

在这里使用楼层划分会错误地产生`4 - 2 = 2`。 

最后，当根本没有小丑时：```
n = 42, m = 0, k = 7
```每个人的小丑数为零，因此每个人都打平，得分为`0`。 

## 方法

 蛮力思维首先会问如何在玩家之间分配小丑。 我们可以枚举每一个可能的分布`m`小丑对面`k`玩家同时遵守手牌大小限制`n/k`。 对于每个分布，我们可以计算获胜者的分数并保留最大值。 

这在概念上是有效的，因为分数仅取决于小丑计数。 问题在于有效分布的数量以组合方式增长。 尽管实际的限制很小，但这种方法无法扩展并且完全忽略了游戏的结构。 

关键的观察是获胜者的小丑数量应该首先最大化。 由于每个玩家只持有`n/k`卡牌，任何玩家都不能拥有超过`n/k`小丑。 因此，最好的获胜者将获得```
x = min(m, n/k)
```小丑。 

如果所有小丑都适合一只手，这意味着`m ≤ n/k`，那么剩下的玩家收到零个小丑，答案很简单`m`。 

有趣的情况是，一些小丑在填满获胜者的手牌后仍然存在。 让```
remaining = m - x
```这些小丑必须分布在其他小丑中`k - 1`玩家。 

为了最大化分数，我们希望最强的对手拥有尽可能少的小丑。 最好的策略是将剩余的小丑尽可能均匀地分布在其他玩家中。 

如果`remaining`小丑分布在`k - 1`玩家中，最大的对手小丑数量是```
ceil(remaining / (k - 1))
```使用整数运算：```
(remaining + k - 2) // (k - 1)
```最终得分为```
x - ceil(remaining / (k - 1))
```这将整个问题简化为一些算术运算。

 | 蛮力 | 指数为`m`和`k`| 指数| 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算获胜者可以获得的最大小丑数量：```
x = min(m, n / k)
```任何玩家都不能持有超过`n/k`牌，因此没有玩家可以持有超过那么多的小丑。 
2. 计算给获胜者尽可能多的王牌后还剩下多少张王牌：```
remaining = m - x
```3. 将剩余的小丑分配给其他人`k - 1`玩家尽可能均匀。 

最强的对手将会有```
y = ceil(remaining / (k - 1))
```小丑。 
4. 返回```
x - y
```因为这正是获胜者的分数。 

### 为什么它有效

 当获胜者收到更多小丑时，获胜者的分数会增加，而当对手收到更多小丑时，获胜者的分数会减少。 

给予少于`min(m, n/k)`小丑对获胜者永远没有帮助，因为从获胜者身上移除的每个小丑要么降低`x`直接或保持不变但仍然存在于其他地方。 因此最优解总是最大化`x`。 

一次`x`是固定的，唯一剩下的目标是最小化最大的对手小丑数量。 在所有分布中`remaining`小丑对面`k - 1`对于玩家来说，通过尽可能均匀地分配他们来实现尽可能小的最大负载。 最大负载正好是`ceil(remaining / (k - 1))`。 

由于两个部分都是独立最优的，因此所得分数是可达到的最高分数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())

        max_jokers = min(m, n // k)
        remaining = m - max_jokers

        opponent = (remaining + k - 2) // (k - 1)

        ans.append(str(max_jokers - opponent))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```第一个计算找到获胜者可能拥有的最大小丑数量。 手的大小限制使得`n // k`绝对上限。 

变量`remaining`跟踪必须分配给其他玩家的小丑。 

表达式```
(remaining + k - 2) // (k - 1)
```不使用浮点运算来计算上限除法。 这是最容易出现错误的地方。 当剩余的小丑没有平均分配时，使用普通的楼层分配会低估最强的对手。 

所有算术都可以轻松地适合 Python 整数。 约束很小，但即使对于更大的值，该公式仍然是安全的。

 ## 边缘情况

 考虑：```
1
8 3 2
```我们计算`x = min(3, 4) = 3`。 没有小丑留下来，所以`remaining = 0`。 最强的对手有`0`小丑。 答案是`3 - 0 = 3`。 

这处理了所有小丑都适合一个玩家的情况。 该算法立即识别出没有对手可以接收小丑。 

考虑：```
1
8 7 2
```我们计算`x = min(7, 4) = 4`。 剩下三个小丑。 由于只有一名对手，该对手必须接收所有剩余的三个小丑。 该算法计算```
y = ceil(3 / 1) = 3
```并返回`4 - 3 = 1`。 

这证实了手牌大小的限制得到了遵守，并且剩下的小丑仍然很重要。 

考虑：```
1
12 9 3
```我们计算`x = 4`,`remaining = 5`， 和```
y = ceil(5 / 2) = 3
```答案就变成了`1`。 

这是经典的天花板划分案例。 任何使用楼层划分的解决方案都会错误地产生`2`。 

考虑：```
1
42 0 7
```我们计算`x = 0`,`remaining = 0`， 和`y = 0`。 答案是`0`。 

该算法自然地处理根本没有小丑的情况，产生预期的平局得分。
