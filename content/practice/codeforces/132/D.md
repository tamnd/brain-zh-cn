 ## 解决方案
 ## 问题理解

 我们被要求将二进制给出的正整数表示为 2 的幂之和，并可以选择使用负幂，以使项总数最小化。 形式上，我们希望将数字写为以下形式的表达式之和`+2^x`或者`-2^x`。 输入是一个长度高达 1,000,000 的二进制字符串，这立即告诉我们数字本身可能非常大，我们无法迭代所有整数值。 输出首先是最小总和中的项数，然后是明确的每项。 

挑战来自于最大限度地减少术语数量。 一种简单的方法是将每个 1 位表示为`+2^x`，产生的项数等于二进制表示中 1 的数量。 虽然这是正确的，但这通常不是最小的。 例如，二进制`1111`（十进制15）可表示为`+2^4 - 2^0`，只给出两项而不是四项。 

边缘情况包括类似的数字`1000`（十进制 8），其中朴素方法已经是最小的，或者长串 1 的数字，例如`11111`（十进制 31），其中分组和使用更高幂的进位可减少项数。 粗心的方法会忽略进位传播，并且总是每 1 位发出一项，从而导致解决方案不理想。 

大的输入长度意味着我们需要一个与二进制字符串的长度成线性的算法，因为二次或更高的方法将超过 2 秒的时间限制。 

## 方法

 暴力方法很简单：迭代二进制字符串，对于设置为 1 的每个位，添加`+2^x`到术语列表。 这会产生与 1 数量相等的项数。 这是正确的，但可能远非最小。 对于长度为二进制的字符串`n`当所有位设置为 1 时，朴素方法会产生`n`条款。 和`n`最多 1,000,000，这对于最小化和输出大小来说都是不切实际的。 

关键的见解是将二进制表示视为以 2 为基数的数字，并像加法一样考虑“进位”。 如果我们有连续的 1，将它们翻转为 0 并在下一个更高的幂上添加 +1 会减少项总数。 这有效地利用了身份`2^k + 2^k + ... + 2^k (r times) = 2^(k+1) + ...`根据需要带有进位和否定项。 

最佳算法从最低有效位到最高有效位处理二进制数，只要将 1 串分解为更少的项，就会保持向前传播的“进位”。 在每一步中，我们都会决定是否应该保留一个位，产生一个负项，或者贡献一个进位。 这会将字符串迭代一次时的项总数减少到理论最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 正确但不是最小 |
 | 最佳 | O(n) | O(n) | 正确且最小 |

 ## 算法演练

 1. 从输入中读取二进制字符串并将其反转以从最低有效位到最高有效位进行处理。 反转简化了添加进位时的索引处理。 
2. 将进位变量初始化为 0，并将项初始化为空列表。 进位代表未决的`+2^k`或者`-2^k`调整到下一个更高位。 
3. 迭代每个位索引`i`。 将当前位和进位相加即可得到该位置的有效值。 该值可以是 0、1、2 或 3，具体取决于该位和任何先前的进位。 
4. 如果有效值为0或1，则不需要负项。 如果有效值为1，则附加`+2^i`到术语列表。 将进位设置为 0。 
5. 如果有效值为2，则相当于`0`在当前位置，进位为`+1`到下一个更高位。 不要为该位添加术语； 增量进位。 
6. 如果有效值为3，则相当于`1`在当前位置，进位为`+1`到下一个更高位。 附加`-2^i`以抵消额外的`2^i`和增量进位。 
7.处理完所有位后，如果还有剩余进位，则追加`+2^len(binary_string)`来处理它。 
8. 输出每项后面的项总数。 术语的顺序并不重要。 

这里的不变性是，在每一步中，当前位、前一进位和发出的决定的组合`+2^i`或者`-2^i`保证所有发出项加上进位的总和等于原始数。 这可以防止多算或遗漏任何位的贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

binary = input().strip()[::-1]  # reverse to process LSB to MSB
n = len(binary)
carry = 0
terms = []

for i in range(n):
    bit = int(binary[i])
    val = bit + carry
    if val == 0:
        carry = 0
    elif val == 1:
        terms.append(f"+2^{i}")
        carry = 0
    elif val == 2:
        carry = 1
    elif val == 3:
        terms.append(f"-2^{i}")
        carry = 1

if carry:
    terms.append(f"+2^{n}")

print(len(terms))
print("\n".join(terms))
```该代码首先反转二进制字符串，以便索引`i`对应于`2^i`。 我们迭代每一位，将其与之前操作中的任何进位相结合。 案例为`val`处理所有可能性：不需要项、附加正项、传播进位或附加负项和进位。 对剩余进位的最终检查可确保数字的正确性，例如`1111`传播额外的力量。 

## 工作示例

 输入样本`1111`（十进制 15）：

 | 索引 (i) | 位| 携带| 有效值| 行动| 条款 | 新携带|
 | ---| ---| ---| ---| ---| ---| ---|
 | 0 | 1 | 0 | 1 | +2^0 | +2^0 | 0 |
 | 1 | 1 | 0 | 1 | +2^1 | +2^1 | 0 |
 | 2 | 1 | 0 | 1 | +2^2 | +2^2 | 0 |
 | 3 | 1 | 0 | 1 | +2^3 | +2^3 | 0 |

 这产生 4 项。 应用套利策略：

 | 索引 (i) | 位| 携带| 有效值| 行动| 条款 | 新携带 |
 | ---| ---| ---| ---| ---| ---| ---|
 | 0 | 1 | 0 | 1 | -2^0 | -2^0 -2^0 | -2^0 1 |
 | 1 | 1 | 1 | 2 | 携带 1 | | 1 |
 | 2 | 1 | 1 | 2 | 携带 1 | | 1 |
 | 3 | 1 | 1 | 2 | 携带 1 | | 1 |
 | 4 | 0 | 1 | 1 | +2^4 | +2^4 | 0 |

 这会产生最优的 2 项：`+2^4, -2^0`。 

另一个输入`1010`（十进制 10）：

 | 索引 | 位| 携带| 有效值| 行动| 条款 | 携带|
 | ---| ---| ---| ---| ---| ---| ---|
 | 0 | 0 | 0 | 0 | 无 | | 0 |
 | 1 | 1 | 0 | 1 | +2^1 | +2^1 | 0 |
 | 2 | 0 | 0 | 0 | 无 | | 0 |
 | 3 | 1 | 0 | 1 | +2^3 | +2^3 | 0 |

 生产`+2^1, +2^3`，这是最小的。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 我们对每个位只处理一次，循环内的每个操作都是 O(1)。 |
 | 空间| O(n) | 我们存储术语列表，在最坏的情况下最多可以有 n+1 个术语。 |

 这符合 n ≤ 1,000,000 的时间和内存限制。
