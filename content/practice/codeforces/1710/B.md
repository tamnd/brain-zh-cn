 ## 解决方案
 ## 问题理解

 我们被要求沿着无限整数线模拟降雨累积。 每天降雨集中在特定位置，强度随距离线性衰减。 Formally, if it rains at position`x_i`有强度`p_i`，则位置处的降雨量`j`增加了`max(0, p_i - |x_i - j|)`。 如果任何位置累积超过`m`降雨量单位。 

不同的是，我们可以取消一天的降雨。 对于每一天，我们都需要检查取消当天的降雨是否可以防止洪水。 我们的输出是一个二进制字符串，其中`1`如果当天的降雨消除，则表示不会发生洪水，并且`0`表明洪水仍然存在。 

限制很严格：天数`n`最多可达 200,000，并且总和`n`所有测试用例也是 200,000 个。 位置和强度最高可达 10^9。 这立即排除了任何迭代头寸的幼稚模拟，因为有效头寸可以分布在很大的范围内。 我们无法分配大小为 10^9 的数组，并且为每个整数位置单独计算降雨量会太慢。 

简单的解决方案可能失败的边缘情况包括重叠降雨（在交叉点处实现最大累积量）、强度非常小的日子紧邻极大强度的日子，以及洪水发生在降雨覆盖范围边缘的情况。 例如，如果位置 1 和位置 10 下了两次降雨，强度为 5，则位置 5 的累计降雨量为 1 + 1 = 2。如果`m = 2`，仅考虑降雨中心的粗心解决方案可能会错过边缘累积。 

## 方法

 蛮力方法在概念上很简单：对于每一天，模拟取消该天后的所有降雨量累积。 这涉及迭代受所有剩余降雨影响的每个整数位置，求和贡献，并检查是否有任何位置超过`m`。 虽然这在理论上是正确的，但当位置可以大到 10^9 时，它就变得不可行，因为雨接触的位置数量与强度之和成正比。 即使我们尝试仅迭代受降雨影响的位置，重叠高强度降雨的最坏情况仍然需要每个测试用例进行数百万次操作。 为了`n = 2*10^5`在多个测试用例中，这超出了时间限制。 

关键的见解是避免明确地迭代位置。 每次降雨都会产生一个两侧斜率为 1 的“金字塔”。 总降雨量是分段线性函数，斜率仅在这些金字塔的边界发生变化：`x_i - p_i`和`x_i + p_i`。 这使我们能够使用斜率变化的前缀和来模拟累积。 我们可以计算最大降雨量，而无需模拟每个位置，方法是对边界点进行排序，累积计算坡度变化，然后重建相对于降雨次数的线性时间内的最大累积降雨量。 

一旦我们掌握了最大累积降雨量和发生洪水的“危险区域”，我们就可以单独检查每天的降雨量。 如果降雨导致的位置超过`m`，它是删除的候选者。 否则，与洪水无关。 这减少了从模拟数十亿个头寸到管理头寸的问题`O(n)`事件并执行线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 总和(p_i)) | O(最大范围) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，将所有降雨存储为`(x_i, p_i)`元组并按位置对它们进行排序。 排序是可选的，但可以简化处理边界。 
2. 对于每次下雨，计算受影响的最左和最右位置：`l_i = x_i - p_i`和`r_i = x_i + p_i`。 每个边界代表降雨函数斜率的变化。 
3. 将金字塔贡献转换为斜率变化事件。 在`l_i`，斜率增加 1。`x_i`，斜率减小 2。`r_i + 1`，斜率再次增加 1。 这构建了总降雨量的分段线性函数。 
4. 按位置排序处理事件，保持运行坡度和累积降雨量。 在每个边界处，通过将坡度乘以距前一个边界移动的距离来更新当前降雨量。 记录遇到的最大降雨量。 
5. 识别“溢流”量：累积降雨量超过的任意位置`m`。 对于每一天，检查其金字塔是否有助于溢出头寸。 这可以通过将当天的降雨影响间隔与溢流发生的范围进行比较来完成。 如果删除这一天，则消除所有降雨量高于以上的位置`m`，将这一天标记为`1`。 否则，将其标记为`0`。 
6. 通过连接所有天的结果来构建输出字符串。 

工作原理：基于坡度的事件处理可重建所有关键位置的精确累积降雨量，而无需迭代整条线。 每个事件对应于总降雨量变化斜率的边界。 通过仅检查与溢出有关的间隔，我们将问题简化为检查间隔和洪水区域之间的重叠，从而保证正确性，而无需模拟整个字段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        rains = []
        for _ in range(n):
            x, p = map(int, input().split())
            rains.append((x, p))
        
        events = []
        for x, p in rains:
            events.append((x - p, 1))
            events.append((x, -2))
            events.append((x + p + 1, 1))
        events.sort()
        
        max_rain = 0
        cur_rain = 0
        slope = 0
        prev_pos = events[0][0]
        overflow_left = float('inf')
        overflow_right = float('-inf')
        
        for pos, delta in events:
            cur_rain += slope * (pos - prev_pos)
            slope += delta
            if cur_rain > m:
                overflow_left = min(overflow_left, pos)
                overflow_right = max(overflow_right, pos)
            prev_pos = pos
        
        result = []
        for x, p in rains:
            if x + p < overflow_left or x - p > overflow_right:
                result.append('1')
            else:
                result.append('0')
        print(''.join(result))

if __name__ == "__main__":
    solve()
```该代码单独处理每个测试用例。 我们首先将每次降雨转换为坡度变化事件，并按位置对它们进行排序。 运行坡度变量重建了事件之间的累积降雨量，从而可以识别溢流区域。 最后，我们检查每天对这些区域的贡献，以确定消除降雨是否可以防止洪水。 使用斜率事件可以避免模拟每个位置，考虑到可能的坐标范围很大，这一点至关重要。
