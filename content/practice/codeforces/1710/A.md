 ## 解决方案
 ## 问题理解

 我们被要求给一个$n \times m$网格使用$k$色素，每种色素都能给有限数量的细胞着色。 如果每个细胞与其四个环形邻居中的至少三个共享其颜色，则图片被认为是美丽的。 环形邻居环绕网格的边缘，因此第一行和最后一行或列被视为相邻。 任务是确定是否可以在满足该邻域条件的同时分配尊重颜料限制的颜色。 

输入由多个测试用例组成。 对于每种情况，我们都会收到$n, m, k$以及颜料容量列表$a_1, a_2, \dots, a_k$。 如果存在美丽的颜色，则输出应为“是”，否则输出应为“否”。 

界限$3 \le n,m \le 10^9$使得无法模拟网格或直接检查邻居。$k \le 10^5$以及所有的总和$k$超过测试用例也受$10^5$，所以我们必须高效地处理颜料。 每个$a_i$可以很大，最多可达$10^9$，因此准确的计数很重要。 粗心的解决方案可能会假设网格始终可以均匀着色，或者无法处理一个维度为奇数的情况，这会影响条纹或块的平铺方式。 

当任一维度为奇数时，就会出现微妙的边缘情况。 在这种情况下，安排一个模式以使每个单元格具有三个相同颜色的邻居可能会失败。 例如，一个$3 \times 3$网格不能用成对的水平条纹填充而不留下不匹配的单元格。 另一种边缘情况是所有颜料单独不足以覆盖行或列的至少一半。 天真的贪婪赋值可能会错误地声明着色是可能的。 

## 方法

 蛮力方法将尝试明确地构建网格并检查邻居，以所有可能的方式填充单元格，同时尊重颜料计数。 这种方法对于小型企业来说是正确的$n$和$m$但显然不可行$n, m$最多$10^9$因为操作的数量是$O(n \cdot m)$。 

关键的见解是认识到美丽的图片所需的规律性。 每个细胞至少需要三个相同颜色的邻居。 这意味着细胞必须在水平或垂直方向形成均匀的条纹。 对于水平条纹，每行必须由两个或多个块中的颜色组成，并且每个块中的单元格数量必须能被 2 整除，以一致地覆盖整行。 同样，对于垂直条纹，沿列的块必须能被 2 整除。 

一旦我们知道每一行或每一列必须平铺成对的相同颜色单元，问题就减少到检查颜料计数是否可以划分为半行（或列）的倍数，考虑奇偶性。 如果至少一个维度是偶数，则条纹的划分就很简单。 如果两个维度都是奇数，则这是不可能的，因为我们无法将奇数长度的行或列成对平铺。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n*m) | 太慢了|
 | 最佳 | 每个测试用例的 O(k) | O(k) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n, m, k$以及颜料限量列表$a_1, \dots, a_k$。 
2. 如果两者都$n$和$m$是奇怪的，立即输出“否”，因为漂亮的图案需要沿至少一个维度配对。 
3. 否则，选择较大的尺寸进行条纹。 不失一般性，假设沿行有水平条纹，如果$n$是均匀的。 
4. 计算所选维度需要多少对单元格。 如果是水平条纹，则对数为$m // 2$每行总计$(m // 2) * n$对。 
5. 将可用色素细胞总数以 2 的倍数求和，忽略奇数剩余部分。 如果颜料对的总和至少为所需对的数量，则输出“是”。 否则，输出“否”。 
6. 重复相同的检查是否可以沿列出现垂直条纹（如果$m$是偶数），但我们只需要一个方向就能成功。 
7. 确保仔细处理整数除法和奇偶校验：只有成对的单元才能形成一致的条纹。 

为什么它有效：该算法之所以有效，是因为美丽的条件要求每个细胞与三个邻居共享其颜色。 只有当细胞沿一维形成至少长度为二的条纹时，才会发生这种情况。 通过计算每种颜料可以提供多少对，并将其与所需的对数进行比较，我们可以在不模拟网格的情况下确定可行性。 不变的是，每个选定的条带方向必须具有大小为 2 的块中的所有单元，确保所有单元满足三邻居要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        a = list(map(int, input().split()))

        if n % 2 == 1 and m % 2 == 1:
            print("No")
            continue

        def check(dim1, dim2):
            total_pairs = 0
            for cells in a:
                total_pairs += cells // 2
            required_pairs = (dim1 * (dim2 // 2))
            if total_pairs >= required_pairs:
                return True
            return False

        if n % 2 == 0:
            if check(n, m):
                print("Yes")
            else:
                print("No")
        else:
            if check(m, n):
                print("Yes")
            else:
                print("No")

if __name__ == "__main__":
    solve()
```该解决方案可以有效地读取输入，检查奇数网格的立即不可能性，并计算颜料计数是否足以进行条纹平铺。 分成对可确保细胞拥有所需的邻居。 使用函数`check`allows symmetric handling of horizontal and vertical stripe possibilities.

 ## 工作示例

 跟踪样本 1 输入`4 6 3\n12 9 8`：

 | 步骤| n | 米 | 颜料| 总对数 | 所需对 | 结果 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 4 | 6 | [12,9,8] | (12//2 + 9//2 + 8//2) = 6+4+4=14 | 4*(6//2)=4*3=12 | 4*(6//2)=4*3=12 14 >= 12 → 是 |

 对数之和超过了所需对数，因此美丽的画面是可能的。 

Trace Sample 2 input`3 3 2\n8 8`：

 | 步骤| n | 米 | 颜料| 总对数 | 所需对 | 结果 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 3 | 3 | [8,8]| 8//2 + 8//2 = 4+4=8 | 不能条纹 3x3（均为奇数）| 没有 |

 该算法正确地识别了奇数网格的不可能性。
