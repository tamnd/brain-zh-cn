 ## 解决方案

 ## 问题理解

 我们得到一排干草堆，每堆都装有一定数量的干草堆。 在一次移动中，我们可以从一堆干草堆中取出一个干草堆，并将其转移到它的近邻之一。 这个过程最多可以重复`d`日，而每一天我们也可能选择什么也不做。 

目标是在最多之后使第一堆尽可能大`d`这样的举动。 

这个问题之所以微妙，是因为移动干草堆并不是隐形传送。 每个干草堆都必须物理地穿过相邻的堆，因此从位置移动草捆的成本`i`定位`1`正是`i - 1`天，假设我们一步步向左移动。 这立即表明，并非所有干草堆在期限内都具有同等价值。 

输入由多个独立的场景组成。 对于每一个，我们必须在最多之后计算第一堆的最佳可能最终值`d`移动。 

限制很小：`n, d ≤ 100`，且每堆高度也较小。 这意味着我们可以毫无顾虑地对每个测试用例进行二次甚至三次推理。 任何试图贪婪地模拟日常运动的解决方案也是可行的，但我们应该小心，不要使某些事情过于复杂化，从而简化为简单的局部最优规则。 

一个常见的错误是假设我们应该尽可能从最近的非零堆中提取数据。 这种直觉很接近但不完整。 真正的限制是，每堆只能贡献有限数量的干草堆，具体取决于有多少干草堆可以物理达到索引`1`之内`d`步骤。 

第二个陷阱是在几天内贪婪地模拟运动。 这可能会失败，因为多个干草堆竞争相同的路径容量，并且简单的模拟可能会浪费来回移动干草堆的移动，而不会提高最终计数。 

## 方法

 蛮力的想法是模拟所有可能的移动序列`d`天。 每天，我们都会挑选一堆并向左或向右移动一个单位。 即使对于很小的输入，状态空间也是巨大的，因为每天都会分支`O(n)`选择，大致给出`O(n^d)`的可能性。 即使进行了修剪，这个问题很快就会变得棘手。 

我们需要一个不同的视角：我们不应该模拟随着时间的推移的运动，而应该推断有多少干草堆最终会到达索引`1`在有限的旅行预算内。 

每个干草堆位于以下位置`i`有助于堆`1`只要我们能把它向左移动`i-1`次。 由于每一步都要消耗一天的时间，所以条件很简单`i - 1 ≤ d`。 这意味着，如果每堆干草堆在可到达的范围内，则它会独立贡献所有干草堆，否则不贡献任何东西。 

不同堆之间不存在相互作用惩罚，因为移动一个干草堆不会阻塞另一个干草堆； 唯一的限制是时间。 因此，最优的策略是从所有能达到索引的堆中取出所有的东西`1`之内`d`移动。 

这将问题简化为可到达位置上的简单前缀和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n^d) | O(n^d) | O(n) | 太慢了 |
 | 基于距离的求和| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于索引处的每一堆`i`，计算其到第一堆的距离为`i - 1`。 这代表将一捆干草堆转移到一堆所需的最少移动次数`1`。 
2. 将此距离与可用天数进行比较`d`。 如果`i - 1 ≤ d`，那么该堆中的每个干草堆最终都可以移至堆中`1`。 
3. 如果满足条件，则添加全部值`a[i]`到答案。 
4. 如果不满足条件，则完全忽略该堆，因为其任何干草堆都无法在限定时间内到达第一个位置。 
5. 将所有桩的贡献相加并输出结果。 

关键思想是每个干草堆都是独立的。 我们并不是选择行动的顺序；而是选择行动的顺序。 我们只是检查在时间限制内完成其路径的可行性。 

### 为什么它有效

 每个干草堆的行为就像一个单位，需要固定的移动成本等于其距堆的距离`1`。 由于移动不是排他性的，因此限制了超出全球预算的时间的并行使用`d`，可行性仅取决于每个单独的单元是否符合该预算。 延迟或重新安排行动没有任何好处，因为每个行动的成本和效果都是相同的，因此最佳解决方案只是所有独立可行贡献的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, d = map(int, input().split())
    a = list(map(int, input().split()))
    
    ans = 0
    for i in range(n):
        if i <= d:
            ans += a[i]
    
    print(ans)
```该实现直接对距离观测进行编码。 指数`i`已经代表了距桩的距离`1`在从零开始的索引中，所以我们只需检查是否`i`是在允许的天数之内。 

不需要模拟。 通过扫描一次数组并对有效贡献求和，可以在线性时间内处理每个测试用例。 

一个常见的实施错误是差一索引。 自堆`1`对应索引`0`，正确的距离正是`i`， 不是`i + 1`。

 ## 边缘情况

 一个关键的边缘情况是当`d = 0`。 在这种情况下，不可能移动，所以只能堆`1`可以做出贡献。 该算法处理这个问题是因为只有索引`0`满足`i ≤ 0`。 

另一种情况是当`d`相比之下非常大`n`。 在这里，每一堆都变得可以到达，正确的答案就是所有干草堆的总和。 该循环自然包括所有索引。 

最后，当第一堆是空的但远处的堆里有干草时，该解决方案仍然可以正常工作，因为它没有假设任何关于初始的信息`a[1]`; 它仅根据距离累积可达到的贡献。
