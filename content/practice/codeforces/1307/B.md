 ## 解决方案
 ## 问题理解

 兔子从飞机的原点出发，想要准确地降落在该点$(x, 0)$。 他通过一系列跳跃来移动，每次跳跃可以有任何方向，但其长度必须与输入中给出的允许值之一匹配。 相同的跳跃长度可以重复使用任意次。 

任务是确定所需的最小跳跃次数，以便兔子能够准确地停在 x 轴上的目标点上。 

关键的困难在于，虽然目的地位于一条线上，但兔子可以在二维空间中移动。 这意味着他可以在中间步骤中“浪费”垂直位移并在以后进行纠正，这使得问题从根本上讲是矢量加法而不是简单的一维算术。 

这些限制因素推动$O(n)$每个测试用例解决方案最多，因为所有测试用例中允许的跳跃长度总数最多为$10^5$。 任何试图模拟跳跃组合或显式探索几何的方法都太慢，因为可能的序列数量随着答案呈指数增长。 

一个天真的错误是假设最好的策略总是重复使用最大的跳跃或贪婪地分解$x$作为允许长度的总和。 这会失败，因为方向自由度允许多个较短的跳跃组合成较长的净位移。 

例如，如果允许的长度是$[1, 3]$和$x = 4$，贪心会建议$3 + 1$，但最佳解决方案是 2 个长度为 3 的跳跃，以一定角度排列，以便它们的水平投影总和恰好为 4。 

另一个微妙的失败案例是假设只有在某些情况下才可能使用单跳$a_i = x$。 这是不正确的，因为两个或多个矢量步骤可以形成等于$x$即使没有单次跳跃可以与之匹敌。 

该问题简化为推理需要多少给定长度的向量才能在一条线上实现目标合成幅度。 

## 方法

 蛮力的想法是将每个允许的长度视为一个向量，并尝试所有可能的跳跃序列到某个深度$k$，检查目标是否可以形成。 每个步骤都涉及选择其中之一$n$长度和方向角，这使得状态空间连续且无限。 即使离散化，组合数量的增长大致如下$n^k$，即使对于非常小的情况也变得难以管理$k$。 这种方法很快就变得不可行。 

关键的观察是，我们实际上并不关心单独的方向，只关心每次跳跃对到达 x 轴有多少“净位移能力”。 长度的跳跃$a$最多可以贡献$a$在 x 方向上，通过组合不同角度的多次跳跃，我们始终可以对它们进行排列，使它们的垂直分量相互抵消，同时最大化水平贡献。 

本质上的简化是，最优策略总是以一种有效的方式使用跳跃，其行为类似于选择长度的子集，其总和（作为可用的最大投影）可以覆盖$x$，但还有一个额外的几何事实，即最大跳跃的任何剩余不匹配都可以使用两次跳跃而不是多次跳跃来纠正。 

这导致了一个经典的结构：如果有的话，我们要么需要一次跳转$a_i = x$，否则我们将问题简化为覆盖$x$使用每个段最多可以贡献最大可用跳跃的段。 如果我们表示$M = \max(a_i)$，那么每次跳跃贡献最多$M$最优安排中的横向进展，因此我们至少需要$\lceil x / M \rceil$跳跃。 然而，这并不总是很紧，因为如果我们使用第二大跳跃，我们可能会减少超调低效率。 精确的最优解仅取决于是否$x$可整除或最多可以使用两次跳转来精确表示； 正确的简化是答案始终是：

 - 1（如果有）$a_i = x$- 否则$\left\lceil \frac{x}{\max(a_i)} \right\rceil$，但进行调整，以便如果$x \le 2 \cdot \max(a_i)$，答案是 2（因为两次跳跃始终足以使用三角形几何构造最大长度两倍的任何位移）

 这会产生基于最大可用跳跃的直接贪婪分类。

 ## 算法演练

 1.读取所有允许的跳跃长度并确定最大值$M$。 该值代表任意方向最强的单步位移能力。 
2. 检查允许的长度是否等于目标长度$x$。 如果是这样，答案立即为 1，因为单次跳跃可以直接沿 x 轴定向以准确到达目的地。 
3. 如果没有单跳匹配$x$，考虑两次跳跃是否足够。 最多两个长度的向量$M$总是可以排列，使它们的结果位于半径圆盘内的任何地方$2M$，表示任意目标距离$x \le 2M$只需两步即可实现。 
4.如果$x > 2M$，那么即使是最佳对齐的跳跃也无法在小于$\lceil x / M \rceil$步骤，因为每个步骤最多贡献$M$净水平进度。 
5. 根据这些情况返回计算出的最小值。 

### 为什么它有效

 每次跳跃都是一个向量，其对最终位移的贡献受其长度限制。 每次移动所需方向的最大可能贡献是$M$，并且几何学保证两个向量始终可以定向以实现半径内的任何结果$2M$。 这会创建一个紧密的分区：目标高达$2M$最多需要两次跳跃，较大的目标需要堆叠最大效率的跳跃，使得$\lceil x/M \rceil$不可避免的。 任何替代布置都不能超出这些几何界限。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))
        
        mx = max(a)
        
        if x == 0:
            print(0)
            continue
        
        if x in a:
            print(1)
            continue
        
        # two jumps are enough if target is within twice max reach
        if x <= 2 * mx:
            print(2)
        else:
            # otherwise we need ceil(x / mx)
            print((x + mx - 1) // mx)

if __name__ == "__main__":
    solve()
```该解决方案首先提取允许的最大跳跃长度，因为这决定了任何单个动作可以为达到目标做出的最强可能贡献。 

直接相等检查$x$处理一次跳转就足够的情况。 这很重要，因为即使存在几何组合，直接匹配始终是最佳的。 

下一个分支使用这样的几何事实：最多两个长度向量$M$可以实现任意位移$2M$，因此该范围内的所有目标都可以通过两步来实现。 

最后，当目标超过$2M$, 每次跳跃贡献最大$M$沿 x 轴有效进展，因此我们退回到带有上限的简单除法。

 ## 边缘情况

 当$x$恰好等于允许的长度之一，算法立即返回 1。对于输入$n=3, x=5, a=[2,5,7]$, 支票`x in a`触发且输出为 1。任何仅依赖于最大值组合的方法都会错误地尝试多步构造。 

什么时候$x$与最大值相比较小，例如$x=6$和$a=[10, 12]$，条件$x \le 2M$确保输出为 2。算法在这里不会尝试除法，因为几何构造保证两个向量是足够的，即使朴素的算术表明存在超调问题。 

什么时候$x$很大，比如$x=100$和$a=[30, 40]$，算法回落到上限除以 40，产生 3。这对应于重复使用最大长度跳转，因为两次跳转不能超出$2M = 80$，使得额外的步骤不可避免。
