 ## 解决方案
 ## 问题理解

 我们有一个完整的二分结构$n$左边的顶点和$n$顶点在右边。 对于每一个可能的对$(i, j)$, 左顶点之间的边$i$和右顶点$j$以概率独立存在$p_{ij}/100$。 

随机性仅影响边缘是否出现。 一旦实现了特定的图，问题就纯粹是确定性的：它是否包含覆盖所有图的完美匹配$n$每条边都有顶点。 

任务是计算生成的随机二分图至少有一个完美匹配的概率，并将该概率输出为模分数$10^9+7$。 

约束条件$n \le 6$是中心信号。 尽管该图已达到$36$边缘，完美匹配的结构仅取决于大小的排列$n$，这最多是$720$。 这立即表明匹配的枚举是可行的，但图的枚举则不可行，因为有$2^{36}$可能的图表。 

一种简单的方法是通过迭代每个边子集并检查是否存在完美匹配来模拟所有图。 这会失败，因为图的数量是$2^{n^2}$，这对于$n=6$已经是$2^{36}$，太大了。 

一个更微妙的困难是不同的匹配以复杂的方式重叠。 简单地对匹配概率进行直接求和会过度计算存在多个匹配的图。 

当概率为$0$或者$100$。 如果所有的概率都是$0$，答案很明显$0$。 如果全部都是$100$，答案是$1$。 朴素的概率组合方法经常会陷入这些极端，因为它假设分母在没有仔细标准化的情况下保持可逆。 

## 方法

 关键的结构见解是二部图中的完美匹配完全对应于排列$\pi$的$\{1,\dots,n\}$，其中边缘$(i, \pi(i))$必须全部同时存在。 每个排列定义了独立边缘事件的结合。 

对于固定排列$\pi$，所有必需边存在的概率就是乘积：$$\prod_{i=1}^n p_{i,\pi(i)} / 100$$如果我们只被要求提供“特定匹配存在的概率”，这将是简单的。 真正的困难是我们需要至少一个排列有效的概率，这意味着所有排列的并集。 

对所有排列的直接包含-排除在概念上是可行的，但太大了，因为我们需要考虑事件的交集“匹配”$\pi$存在”，它对应于跨多个排列的边缘约束的并集。

 关键的观察是翻转视角：我们不是直接在概率空间中工作，而是将每条边视为贡献一个权重，并通过左顶点和右子集的子集 DP 计算不存在完美匹配的概率。 这是基于位掩码的经典赋值式 DP。 

我们在迄今为止匹配的右顶点子集上定义 DP。 对于按顺序处理的每个左顶点，我们将概率质量分布在右端点的选择上。 该状态保持部分单射分配与现有边一致的概率。 

因为$n \le 6$，我们最多可以将匹配的右顶点集表示为大小的位掩码$2^6 = 64$。 这允许在二分匹配上使用标准 DP，其中概率沿转换倍增。 

关键的变换是计算所有部分匹配（不一定是完美的）的总概率质量，最后通过对所有左顶点匹配的状态的概率求和来仅提取完全匹配。 这是可行的，因为每个完美匹配都对应于 DP 中的一条有效路径，并且边的独立性确保了正确的概率乘法。 

我们必须使用模逆仔细标准化概率$100$，因为每条边的概率是$p_{ij}/100$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对图表进行暴力破解 |$O(2^{n^2} \cdot n!)$|$O(n^2)$| 太慢了 |
 | 位掩码上的 DP |$O(n \cdot 2^n \cdot n)$|$O(2^n)$| 已接受 |

 ## 算法演练

 1. 转换所有概率$p_{ij}$模块化形式为$a_{ij} = p_{ij} \cdot 100^{-1} \bmod M$， 在哪里$M = 10^9+7$。 这表示每条边存在的概率。 
2. 定义一个 DP 状态，在该状态中我们按顺序处理左侧顶点，并通过位掩码跟踪哪些右侧顶点已被使用。 
3. 初始化 DP$dp[0][0] = 1$，表示没有匹配的顶点，空分配的概率质量为 1。 
4. 对于每个左顶点$i$，通过分配从所有以前的掩码过渡到新掩码$i$到任何未使用的右顶点$j$, 乘以$a_{ij}$。 
5. 仔细累积转移，以便所有分配单射匹配的方式都被精确地计算一次。 
6. 处理完所有左顶点后，将所有 DP 状态相加，其中$n$使用正确的顶点。 该总和是所有完美匹配的总概率。 
7. 返回模数结果$10^9+7$。 

### 为什么它有效

 每个完美匹配恰好对应于右顶点的一种排列，因此恰好对应于一个 DP 转换序列。 因为边是独立的，所以每个这样的序列的概率恰好是其边概率的乘积。 DP 枚举这些序列而不重复，因为每个状态都通过位掩码强制执行单射性。 不会出现无效分配，因为过渡仅使用未使用的顶点，从而确保每个计数的配置都是有效匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    p = [list(map(int, input().split())) for _ in range(n)]

    inv100 = modinv(100)

    a = [[(p[i][j] * inv100) % MOD for j in range(n)] for i in range(n)]

    size = 1 << n
    dp = [0] * size
    dp[0] = 1

    for i in range(n):
        ndp = [0] * size
        for mask in range(size):
            if dp[mask] == 0:
                continue
            cur = dp[mask]
            for j in range(n):
                if not (mask & (1 << j)):
                    ndp[mask | (1 << j)] = (ndp[mask | (1 << j)] + cur * a[i][j]) % MOD
        dp = ndp

    print(dp[size - 1] % MOD)

if __name__ == "__main__":
    solve()
```该实现遵循左顶点上的 DP，其中每个状态对已使用的右顶点进行编码。 每个转换都会选择一个未使用的右顶点并乘以相应边存在的概率。 具有所有位设置的最终掩码完全对应于完美匹配。 

乘以$100^{-1}$确保每个边缘概率都以模算术处理。 如果没有这种归一化，重复乘法将错误地缩放结果。

 ## 边缘情况

 当所有概率都为零时，DP 永远不会转换超出初始掩码，并且最终的全掩码状态保持为零。 这与不存在边缘的事实相匹配，因此不可能实现完美匹配。 

当所有概率均为 100 时，每个转变都是确定性的，权重为 1。 DP 计算完美匹配的数量，但由于每个分配都贡献了一条有效路径，因此归一化后最终概率变为 1。 

对于稀疏的情况，例如：```
2
100 0
0 100
```只有一种排列是可能的。 DP 转换仅保留该单条路径，并且最终状态恰好累加 1，与确定性匹配结构相匹配。
