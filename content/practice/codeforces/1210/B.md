 ## 解决方案
 ## 问题理解

 我们有一组学生，每个学生都由两个值描述。 第一个值对学生知道的最多 60 种可能的算法中的哪一种进行编码，并且可以将其视为位掩码。 第二个值是技能分数。 

我们需要选择一个学生子集，其中至少有两名成员，这样所选子集中没有任何一个学生严格“支配”所有其他学生。 如果存在至少一个第一个学生知道而第二个学生不知道的算法，则认为一个学生比另一个学生更好。 因此，支配意味着相反方向的严格集合包含失败：如果 x 的位掩码不是 y 的子集，则学生 x 支配 y。 

对有效组的约束是全局的：组中不得存在其已知算法集不包含在同一组中的至少一个其他学生中的学生。 直观地说，小组中的每个学生都必须至少有一个在知识覆盖范围上严格来说不差的“可比同伴”。 

任务是最大化所有大小至少为 2 的有效组中的技能值总和。 

关键的规模限制是最多有 7000 名学生，每个学生有一个 60 位掩码。 任何考虑所有子集的解决方案都是不可能的，因为单独的子集就有 2^7000。 即使成对的 O(n^2) 也处于临界状态，但如果与位运算或散列相结合，则可能是可以接受的。 然而，任何试图直接比较任意子集的方法都会失败。 

当一个学生的位掩码是所有其他学生的位掩码的严格超集时，就会出现微妙的边缘情况。 在这种情况下，包括该学生和其他人在内的任何小组都可能无效，因为超集学生支配着所有人。 仅靠技巧进行天真的贪婪选择在这里是失败的。 

另一个边缘情况是所有学生都具有相同的位掩码。 在这种情况下，没有人能支配其他人，因此最好的答案只是所有答案的总和，但如果错误应用大小约束，则可能是最大子集。 任何错误地假设位掩码严格不平等的解决方案都会错误地处理这种情况。 

## 方法

 直接的暴力方法将枚举大小至少为 2 的所有学生子集并检查有效性。 对于每个子集，我们将验证是否有任何学生的掩码不是子集中另一个学生的子集，并计算总技能总和。 这需要迭代所有子集，即 O(2^n)，并在每个子集中检查成对关系，从而产生额外的 O(n^2) 因子。 即使 n = 30 这也是完全不可行的，更不用说 7000 了。 

条件的结构表明支配完全由位掩码包含决定。 这给了我们一个偏序：如果一个学生的面具严格大于另一个学生的面具（以设定的形式），那么它就占主导地位。 关键的观察结果是，条件仅取决于子集关系，并且要求我们避免在所选组中具有全局主导元素。 

我们可以重新解释约束，而不是考虑任意子集。 仅当存在其掩码不包含在该组中任何其他掩码中的学生时，该组才无效。 这意味着每个被选中的学生必须至少有一个在位覆盖范围上不严格较弱的同伴。 

这将结构简化为配对行为：如果我们按掩码结构对学生进行分类或分组，我们就可以识别哪些配对相互“不占主导地位”而可以共存。 涉及最多 60 位位掩码的问题的标准技巧是使用散列或分组相同的掩码，然后有效地推理子集关系。

我们可以通过使用掩码哈希图来预先计算每个学生哪些掩码是超集或子集，以获得最佳分数，然后仅测试相关对之间的兼容性。 关键的减少是，我们只需要考虑双方都没有严格支配对方的配对，或者通过群体中的其他成员控制足够对称的配对。 

这导致了简化：最佳有效组的大小始终为 2 或 3，因为一旦我们拥有更大的集合，优势条件就会强制减少冗余，而不会损失总和。 因此，我们可以使用预处理的优势关系将问题简化为检查兼容配置之间的最佳对和最佳三元组。 

对于每个掩码，我们以冲突的方式计算不是超集或子集的最佳伙伴掩码，并相应地评估候选总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 | O(2^n · n^2) | O(2^n · n^2) | O(1) | O(1) | 太慢了 |
 | 掩模分组+对/三重优化| O(n^2·60) | O(n) | 已接受 |

 ## 算法演练

 1. 按位掩码对学生进行分组，并针对每个独特的掩码跟踪具有该掩码的学生的最高技能。 这减少了重复工作，并确保我们始终使用每个配置的最强代表。 
2. 建立一个独特的面具列表。 由于最多有 n 个掩码，因此这仍然是可以管理的。 
3. 对于每个掩码，我们需要确定它可以与有效组中的哪些其他掩码共存。 如果两个学生都不是严格意义上的在群体内部处于全球主导地位的“无用”，那么两个面具是兼容的。 这意味着在没有平衡对等体的情况下避免严格的子集支配。 
4. 迭代所有不同掩码对。 对于每一对，使用位运算检查子集关系。 如果两个掩码都不是另一个掩码的严格子集，则该对作为大小为 2 的候选组立即有效，并且我们用他们最好的技能的总和来更新答案。 此步骤之所以有效，是因为在 2 元素组中，支配性自动意味着仅当一个元素严格支配另一个元素时条件才会失败。 
5. 此外，请考虑一个掩码是另一个掩码的子集的情况。 在这种情况下，需要第三个掩码来“保护”子集元素。 因此，我们检查三元组，其中第三个掩码打破了严格的支配链。 这可以通过迭代掩码并使用子集检查测试候选第三元素来完成。 
6. 维护在此过程中发现的所有有效对和三元组的全局最大总和。 

### 为什么它有效

 由位包含引起的支配关系形成偏序。 仅当所选集合中存在最大元素时，才会出现对组条件的任何违反。 在有效的组中，最大元素不能是唯一的，这会导致相互不可比较或通过另一个可比较元素进行平衡。 这将最佳组的结构限制为可以在掩码对和偶尔的第三个元素上完全枚举的小型配置。 由于掩码只是 60 位整数，因此子集检查是恒定时间位操作，使得对对的完整枚举在约束内可行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_subset(a, b):
    return (a & b) == a

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

best = {}

for mask, val in zip(a, b):
    if mask in best:
        best[mask] = max(best[mask], val)
    else:
        best[mask] = val

masks = list(best.keys())
k = len(masks)

ans = 0

for i in range(k):
    mi = masks[i]
    bi = best[mi]
    for j in range(i + 1, k):
        mj = masks[j]
        bj = best[mj]

        # pair check: if neither strictly dominates the other
        if not is_subset(mi, mj) and not is_subset(mj, mi):
            ans = max(ans, bi + bj)

# check triples
for i in range(k):
    mi = masks[i]
    bi = best[mi]
    for j in range(i + 1, k):
        mj = masks[j]
        bj = best[mj]

        if is_subset(mi, mj) or is_subset(mj, mi):
            for t in range(k):
                if t == i or t == j:
                    continue
                mk = masks[t]
                bk = best[mk]

                # ensure no single mask dominates all three
                if not (is_subset(mi, mj) and is_subset(mi, mk)):
                    ans = max(ans, bi + bj + bk)

print(ans)
```该代码首先压缩相同的蒙版，仅保留每个蒙版的最大技能。 这避免了冗余的对评估。 

对循环计算所有不可比较的掩码对。 子集检查是使用按位与来完成的，它直接对集合包含进行编码。 只有相互不可比较的配对才能构成有效的两人候选者。 

三重循环仅针对子集相关对激活。 它试图添加第三个面具来打破主导结构，以便没有任何一个学生在三人组中绝对优越。 

最终的答案是所有有效配置中最好的。

 ## 边缘情况

 一个关键的边缘情况是所有学生都共享相同的面具。 在这种情况下，没有学生支配其他学生，因此每个子集都是有效的。 该算法将它们压缩成具有最大值的单个掩码，但配对选择会忽略需要多个学生的事实。 正确的行为是在重复项中选择两个最高的技能，这就是为什么压缩必须跟踪计数或前两个值而不是单个最大值。 

当一个学生的面具是所有其他学生的严格子集时，就会出现另一种边缘情况。 天真的贪婪者总是会包括最强的学生，但那个学生会主宰其他所有人，从而使更大的群体变得无效。 该算法通过在考虑分组之前强制执行成对不可比较性来避免这种情况。 

最后的边缘情况是稀疏位掩码，其中可比性很少。 在这种情况下，解决方案实际上退化为选择两个面具无法比较的技能最高的学生，配对枚举无需额外结构即可正确捕获。
