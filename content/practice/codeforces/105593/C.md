 ## 解决方案
 ## 问题理解

 我们得到了一系列村庄，这些村庄最初之间没有道路。 每个测试用例描述两个数字，即村庄数量和可修建的最大道路数量。 

目标是使用最多允许数量的道路连接村庄，使得任何两个村庄之间的最大最短路径距离尽可能小。 如果我们不能让整个村庄都通上可用的道路，答案是不可能的。 

这里的关键对象是修路后生成的图的直径：任何一对节点之间以边数表示的最大距离。 由于所有道路均未加权，因此距离只是最短路径上的边数。 

约束范围非常大，最多有10^5个测试用例，n和m的值最多为5×10^8。 这立即排除了任何每次测试的模拟或图形构建。 每个测试用例的任何解决方案都必须是 O(1)，仅依赖于算术推理。 

一种简单的方法会尝试显式地构建一个图并在不同的边位置下测试其直径。 即使是贪婪的构建也已经太慢了，因为在这种规模下构建邻接结构或运行 BFS 是不可能的。 

当 m 略小于连接所有节点所需的最小值时，就会出现微妙的失败情况。 例如，如果 n = 4 且 m = 2，我们最多可以连接一条链中的三个节点，并留下一个孤立的节点，因此该图是断开的，并且不存在有限直径。 如果粗心的解决方案在放置 m 个边后假设连通性，则会错误地输出有限答案，而不是认识到不可能性。 

## 方法

 暴力思维模型是考虑一条一条地添加边，并在每次添加后重新计算直径。 这适用于小图，因为每条边都会在本地更改最短路径，并且每个节点的 BFS 可以重新计算距离。 然而，每次评估的成本已经为 O(n(n + m))，并且这里 n 本身可以高达 5 × 10^8，甚至无法存储图。 

关键的简化是认识到只有连通图的结构才重要，而不是村庄的具体标签。 对于 n 个节点和 m 个边，最小化最大距离的最佳配置始终是使用额外边增强的树状结构。 超出 n − 1 的额外边只能缩短距离，但限制因素是是否可以实现连接。 

一旦图被连接起来，距离最有效的结构就是星形配置，其中一个中心节点连接到许多其他节点。 这会最小化直径：星形的直径为 2，只有当图形变得完整时，添加更多边才能将其进一步减小到 1。 

所以问题归结为检查两种制度。 首先，m 是否足够大以连接所有节点，这需要 m ≥ n − 1。其次，在具有额外边的连通图中，在给定冗余 m − (n − 1) 的情况下，可以强制直径小到多小。 每个额外的边都可以通过有效地添加捷径来缩短最长路径，并且极值结构变得越来越密集，直到变得完整。 

关键的观察是直径为 1 的图是完全图，需要 n(n − 1) / 2 条边。 n − 1 和该阈值之间的任意数量的边都会生成一个连通图，其最佳最小直径为 2。低于 n − 1 时，这是不可能的。

 ## 算法演练

 ### 最优推理步骤

1. 通过验证 m 是否至少为 n − 1 来检查图是否可以与可用边连接。这是任何连接结构所需的最小边数，因为 n 个节点上的连接图必须至少有一个生成树。 
2. 如果 m < n − 1，则立即输出 −1，因为一些村庄必须保持孤立，并且无法定义所有对上的有限最大距离。 
3. 如果图形可以连接，请考虑直径可以做得多小。 仅当每对节点都直接连接时，直径才可能为 1，这恰好需要 n(n − 1) / 2 条边。 
4. 如果 m 达到此完整图阈值，则输出 1，因为每个节点都与其他每个节点相邻。 
5. 否则，输出 2，因为任何不完备的连通图总是可以被组织起来使得最长的最短路径至多为 2，并且没有任何构造可以保证直径 1。 

### 为什么它有效

 该论证依赖于极值图结构。 连通图总是包含生成树，因此基线是直径至少为 2 的树，除非它是单个节点或完整结构。 添加边只能通过引入捷径来缩短最短路径，但在每对都直接连接之前，总会存在至少一对顶点，其最短路径使用中间节点，迫使直径至少为2。消除所有中间路径的唯一方法是直接连接每对，它唯一对应于完整的图。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())

        if m < n - 1:
            out.append("-1")
            continue

        # number of edges in complete graph
        max_edges = n * (n - 1) // 2

        if m == max_edges:
            out.append("1")
        else:
            out.append("2")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个检查使用生成树下限强制连接。 第二个与完整图阈值进行比较，这是所有成对距离都崩溃为 1 的唯一情况。其他一切都落入中间状态，其中连接是可能的，但不够密集以消除长度为 2 的最短路径。 

一个常见的错误是假设一旦图连接起来，答案总是 2。这几乎是正确的，但错过了完整的图边缘情况，即直径进一步折叠。

 ## 边缘情况

 对于 n = 2 的情况，该行为将两个阈值折叠在一起。 当有一条边时，图是完整的并且直径为 1，而当边数为零时，图是断开的并且是不可能的。 该算法清楚地处理了这个问题，因为 n − 1 等于 1 并且 n(n − 1)/2 也等于 1。 

对于接近完整的图，例如 n = 5 和 m = 9，结构是连通的并且非常密集，但仍然缺少至少一条边。 该算法正确地将其分类为直径 2，因为仍然存在至少一对未直接连接的顶点，迫使长度为 2 的路径通过中间节点。
