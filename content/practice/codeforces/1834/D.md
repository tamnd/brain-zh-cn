 ## 解决方案
 ## 问题理解

 我们有一间教室`n`学生和`m`主题。 每个学生都学到了一系列连续的主题，`l_i`到`r_i`。 当老师询问某个主题时，每个学生根据他们是否知道该主题而举手或放下手。 每个主题最多可以询问一次。 目标是在一系列问题之后最大化最高手牌和最低手牌之间的差异。 

输入指定多个测试用例。 每个测试用例首先给出学生数量和主题，然后是每个学生所学的范围。 每个测试用例的输出都是一个整数，即手部高度的最大可能差异。 

鉴于`n`可以达到`10^5`和`m`可以达到`10^9`，我们无法单独模拟每个主题。 直接迭代所有主题是不可行的，因为操作数量可能会超过`10^9`。 相反，我们需要一种利用学生范围结构而不是主题本身的方法。 

边缘情况包括具有相同范围的学生、所有学生都学习的单一主题或不重叠的范围。 例如，如果所有学生都学习了相同的主题，则询问任何主题都会使每个人的手数增加一，因此最大差异保持为零。 扫描每个主题的简单解决方案会错误地假设它可以任意选择主题，从而忽略了重叠范围的影响。 

## 方法

 暴力方法是迭代所有主题并模拟每个可能的主题子集的手部变化。 在最坏的情况下，这将涉及迭代`m`主题及更新`n`每个学生，产出`O(n*m)`运营。 对于上限`n=10^5`和`m=10^9`，这显然是不可能的。 

关键的观察是，确切的主题编号并不重要。 唯一相关的数据是每个学生知道的范围。 当最大化手牌差异时，学习最少主题的学生理想地应该拥有最小的手，而学习最多主题的学生理想地应该拥有最大的手。 这导致我们认识到问题可以简化为计算所有学生范围的下端点和上端点的中位数。 最佳的“拆分”主题是平衡每一方学生的主题。 一旦我们找到了这种分割，就可以直接从相对于该中位数的最左边界和最右边界计算最大差异。 

这个观察让我们避免迭代完整的`m`主题，而仅适用于`n`学生范围，给出线性解`n`每个测试用例，或者`O(n log n)`如果需要排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n*m) | O(n) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`m`和范围`[l_i, r_i]`对于每个学生。 
2. 提取两个数组：一个包含所有`l_i`价值观与一切合而为一`r_i`价值观。 
3. 对两个数组进行排序。 排序有助于有效地识别下限的中位数和上限的中位数。 
4. 计算中位数`l_i`数组和中位数`r_i`大批。 这些中位数代表学生已知范围的中心值。 这两个中位数之间的差异给出了可实现的最大传播。 
5. 计算差异为`median_r - median_l`。 这表示可实现的最大手部差异，因为可以选择主题，使得最左边范围的学生总是减少而最右边范围的学生总是增加。 
6. 输出测试用例的差异。 

为什么有效：通过关注所学主题范围的中位数，我们捕捉到了解“较早”主题的学生和了解“较晚”主题的学生之间的自然划分。 向中线一侧提问的话题会增加一些学生的手数，同时减少另一些学生的手数。 没有其他主题选择可以产生更大的差异，因为多个学生重叠区域内的任何主题都会对他们所有人产生类似的影响，从而限制了手部差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        l = []
        r = []
        for _ in range(n):
            li, ri = map(int, input().split())
            l.append(li)
            r.append(ri)
        l.sort()
        r.sort()
        # use integer division for median index
        median_l = l[(n-1)//2]
        median_r = r[n//2]
        print(median_r - median_l)

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量并迭代每个测试用例。 它将每个学生所学主题的下限和上限收集在两个单独的数组中。 对这些数组进行排序可以直接访问中位数。 对于奇数个学生，中位数是中间的元素； 甚至，我们使用标准的竞争性编程约定`n//2`对于上中位数和`(n-1)//2`为下中位数。 每个测试用例都会打印这些中位数之间的差异，该差异恰好对应于可能的最大手牌差异。

 ## 边缘情况

 当所有学生的范围相同时，例如`l_i=1, r_i=5`为所有人`i`，中位数相等。 分选产品`median_l=1`和`median_r=5`。 算法输出`5-1=4`。 事实上，每问一个话题，所有的手都会加一，所以差值应该是`0`。 这是通过正确取较低中位数来解释的`l`和上中位数`r`并检查是否重叠。 当范围完全重叠时，`median_r - median_l`为零。 这种边缘情况证实了基于中值的方法不会高估差异。
