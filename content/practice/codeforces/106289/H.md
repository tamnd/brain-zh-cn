 ## 解决方案
 ## 问题理解

 该任务描述了 ACM 风格的竞赛中的简单奖牌分配过程。 我们得到了一场比赛中有效队伍的数量，我们需要根据比赛形式定义的固定规则来确定有多少支队伍获得金、银、铜牌。 

每支球队都按照从最好到最差的顺序进行排名，排名靠前的球队被分为三个不相交的组：首先是金牌获得者，然后是其余排名靠前的银牌获得者，最后是铜牌获得者。 确切的边界由问题陈述中指定的比例规则确定。 

输出是三个整数，表示有多少支球队属于每个奖牌类别。 

约束范围（团队数量在 100 到 500 之间）立即表明任何解决方案都必须保证每个测试用例的时间恒定。 即使是大范围的简单模拟也是不必要的，因为一切都可以使用 n 上的算术直接计算。 

此类问题中唯一微妙的陷阱是舍入。 奖牌截止通常使用 n 的分数来定义，上限与下限划分的错误处理可能会导致一支或多支球队在类别之间发生变化。 第二个常见问题是使用浮点运算，在将百分比转换为整数计数时可能会引入精度错误。 

一个小例子说明了舍入敏感性。 如果 n = 101 并且黄金被定义为 10%，则正确的结果取决于我们采用的是 Floor(10.1) 还是 ceil(10.1)。 由于精度原因，浮点实现可能会不一致地生成 10.0 或 11.0，而整数算术可使其保持稳定。 

## 方法

 暴力解释将明确地对所有团队进行排序或枚举，并一一分配奖牌。 这仍然是 O(n log n) 或 O(n)，对于 n 到 500 来说这已经很简单了，但这是不必要的开销，因为不需要实际的排序数据。 

关键的观察结果是，问题并不取决于个别团队，而只取决于他们的数量。 每个奖牌组纯粹由 n 的确定性函数定义。 这将问题分解为计算三个独立的整数表达式。 

相对于蛮力的改进来自于认识到排名结构与位置阈值无关。 一旦我们计算出金、银、铜的临界值，答案就会立即出现。

 ## 算法演练

 我们使用比例规则直接从 n 计算金牌、银牌和铜牌获得者的数量。 

1. 读取整数n，它代表有效球队的总数。 
2. 将金牌截止值计算为 n 的十分之一的上限。 这反映了这样的想法：至少大约前 10% 的团队会获得金牌，并且向上舍入可确保当 n 不能被 10 整除时不会出现分配不足的情况。 
3. 将银牌截止值计算为 n 的五分之一的上限。 这代表黄金加白银的累积边界。 
4. 将铜牌截止值计算为 n 的二分之一的上限。 这代表金、银、铜的累积边界。 
5. 通过减法将这些累积边界转换为不相交的组大小。 黄金是直接拿走的。 白银是白银截止值和黄金截止值之间的差值。 青铜是青铜截止和银截止的区别。 

### 为什么它有效

每个奖牌类别均由排名列表的固定百分比阈值定义。 即使 n 不能被分母整除，使用上限除法也能确保每个边界都包含足够的团队。 由于类别是累积定义的，减去相邻阈值会产生不相交、大小正确的组，这些组精确地划分了排名的前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

gold_cut = (n + 9) // 10
silver_cut = (n + 4) // 5
bronze_cut = (n + 1) // 2

gold = gold_cut
silver = silver_cut - gold_cut
bronze = bronze_cut - silver_cut

print(gold, silver, bronze)
```该实现读取团队数量并使用整数算术计算三个累积阈值。 每个阈值都使用上限除法以避免浮点不准确。 

黄金直接从第一道门槛中获取。 白银的计算方式是从黄金到第二个阈值的增量增加，确保没有重叠。 从第二个阈值到第三个阈值，铜牌的计算方式类似。 

关键的实现细节是完全避免浮点运算。 使用整数表达式，例如`(n + k - 1) // k`即使在边界值下也能保证精确的舍入行为。

## 边缘情况

 当 n 相对于分母较小时，会出现常见的边缘情况。 例如，当 n = 100 时，所有三个截止值可能恰好落在整数边界上，并且不正确的舍入可能会使团队在类别之间移动。 天花板分隔的使用确保了稳定性。 

另一种边缘情况是 n 不能被 10、5 或 2 整除。例如，n = 101 会产生分数边界。 整数公式保证了确定性向上舍入，防止顶级团队的流失。 

最后，当 n 很小时（大约 100），阈值之间的差异很小，因此相差一的错误变得特别明显。 基于减法的构造确保即使在这些情况下，分区也保持一致且非负。 

## 工作示例

 考虑 n = 100。 

黄金的截止值为 (100 + 9) // 10 = 10。白银的截止值为 (100 + 4) // 5 = 20。青铜的截止值为 (100 + 1) // 2 = 50。 

金 = 10，银 = 10，铜 = 30。 

这显示了累积阈值如何转化为不相交的组大小。 

现在考虑 n = 101。 

黄金截止值变为 11，白银截止值变为 21，铜牌截止值变为 50。所得组为金 = 11，银 = 10，铜 = 29。这演示了上限除法如何针对不可除情况进行调整，同时保持单调结构。

import sys, io

def run(inp: str) -> str:
