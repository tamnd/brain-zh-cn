 ## 解决方案
 ## 问题理解

 我们给出了长度的排列$n$，这是一个由 1 到 1 之间的不同整数组成的数组$n$按某种顺序排列。 任务是计算包含特定模式（称为 21435 子序列）的连续子数组（间隔）的数量。 具体而言，如果我们可以选择五个索引，则子数组是锯齿状的$i_1<i_2<i_3<i_4<i_5$在子数组中，使得这些位置的值满足$a_{i_2} < a_{i_1} < a_{i_4} < a_{i_3} < a_{i_5}$。 每个测试用例的输出是一个整数：锯齿状子数组的总数。 

约束条件给了我们总和$n$跨越最多的所有测试用例$10^6$。 这意味着任何具有复杂性的算法$O(n^2)$每个测试用例或更高的速度会太慢，因为即使是单个测试用例$n \approx 10^5$会导致$10^{10}$操作，这远远超出了 5 秒限制的可接受范围。 因此，我们需要一个大致线性或线性算术的算法$n$。 

不明显的边缘情况包括非常小的数组。 例如，如果$n<5$，没有子数组可以包含 21435 子序列，因此答案为零。 已经按升序或降序排序的数组也将具有很少的锯齿状间隔，有时甚至为零，因为在单调序列中不可能实现所需的峰和谷的交替。 

## 方法

 蛮力方法会迭代所有$\frac{n(n+1)}{2}$可能的子数组，并针对每个子数组检查 21435 模式的所有索引五元组。 检查一个子数组的长度$k$成本$O(k^5)$，所以总复杂度是$O(n^7)$在最坏的情况下。 这显然是不可行的。 

关键的见解是 21435 形态在相对值方面具有“固定的本地配置”。 自从$n$对于线性扫描来说足够小，但对于完整的组合检查来说不够，我们可以查看长度恰好为 5 的所有子数组，因为最小的锯齿状间隔是长度 5。如果长度为 5 的任何间隔满足 21435 模式，则包含它的所有较大间隔也是锯齿状的。 这意味着我们可以扫描长度为 5 in 的所有模式$O(n)$时间，然后使用简单的算术计算每个模式“覆盖”了多少个间隔。 由于排列是不同的，因此比较减少为检查位置而不是复杂的相等性。 

进一步的简化来自于注意到可以使用单调堆栈方法或有界窗口扫描有效地找到 21435 子序列：对于每个可能的中间元素（21435 中的“1”），我们可以维护其左侧的最大值和右侧的最小值，并验证模式是否存在。 一旦我们确定了可以作为有效 21435 的最左边和最右边的位置，我们就可以使用组合学计算有多少个区间包含这些位置：对于最左边的位置$L$和最右边的$R$， 有$L \cdot (n-R+1)$包含完整模式的子数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^7)$|$O(1)$| 太慢了|
 | 最佳|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和排列数组。 初始化一个变量`total_jagged`为零。 我们将在这里累积锯齿状间隔的计数。 
2.如果$n<5$，立即返回 0。任何区间都不能包含 21435 子序列。 
3. 扫描数组以查找满足 21435 模式的所有长度为 5 的连续段。 对于每个这样的五元组，记录最左边和最右边的位置。 
4. 对于每个识别的五元组，计算有多少个区间包含它。 设最左边的索引为$L$最右边的索引是$R$。 包含它的区间数为$(L) \cdot (n-R+1)$，因为间隔可以从 1 到$L$并从任意位置结束$R$到$n$。 
5. 将所有已识别五元组的计数求和为`total_jagged`。 输出`total_jagged`。 

原理：每个包含至少一个长度为 5 且具有 21435 模式的五元组的区间都是锯齿状的。 通过枚举五元组的所有可能位置并计算包含它们的间隔，我们可以精确计算所有锯齿状间隔。 因为排列是不同的，所以没有任何模式会被错误地重复计算：重叠的五元组自然会正确地贡献于包含它们的区间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_21435(sub):
    # Check if a list of length 5 matches 21435 pattern
    return sub[1] < sub[0] < sub[3] < sub[2] < sub[4]

def count_jagged(n, a):
    if n < 5:
        return 0
    total = 0
    # Iterate over all 5-length windows
    for i in range(n - 4):
        window = a[i:i+5]
        if is_21435(window):
            total += (i+1) * (n - (i+4))
    return total

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(count_jagged(n, a))

if __name__ == "__main__":
    main()
```该解决方案直接实现了对包含 21435 模式的所有子数组进行计数的逻辑。 功能`is_21435`是明确的，减少了差一错误的可能性。 使用长度为5的固定窗口简化了索引，公式`(i+1) * (n-(i+4))`正确计算包含五元组的所有间隔。
