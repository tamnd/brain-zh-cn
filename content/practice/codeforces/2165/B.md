 ## 解决方案
 ## 问题理解

 我们得到了一组整数，我们可以将其视为一袋弹珠，其中每个弹珠都有一个由数字表示的颜色。 任务是生成一个新的多重集`s`首先将原始多重集划分为任意数量的非空子集，然后从每个子集中选择其模式之一（在该子集中出现最频繁的数字）。 结果多重集`s`由这些选定的模式组成。 我们需要计算有多少个不同的多重集`s`可以这样生成。 

输入由多个测试用例组成。 对于每种情况，我们都会得到尺寸`n`多重集和元素本身。 每个元素都保证位于`1`和`n`。 输出是不同多重集的数量`s`模数`998,244,353`。 

限制因素至关重要。 全部的总和`n`跨测试用例最多 5000 个。这意味着即使我们总共可以有 5000 个元素，我们也不会处理非常大的数据集。 然而，我们必须小心组合爆炸。 显式尝试每个分区的简单方法会尝试枚举大小的贝尔数`n`，它会超指数增长并且是不可行的。 甚至`n=20`可以产生数百万个分区。 

当所有元素都相等时，就会出现边缘情况。 例如，如果`a = [1,1,1]`，每个分区都有相同的模式，这大大减少了计数。 相反，当所有元素都不同时，每个非空子集都可以产生不同的多重集。 粗心的算法可能会重复计算多重集或无法尊重模式多重性。 

## 方法

 暴力方法枚举了多重集的所有可能的划分。 对于每个分区，我们从子集中计算所有可能的模式选择并收集生成的多重集。 虽然这种方法原则上是正确的，但对于`n > 10`因为集合的分区数量增长速度快于`2^n`。 每个分区还需要计算其子集的模式，这会增加额外的开销。 

加速这一过程的关键见解来自于观察，即考虑到原始多重集中的频率，问题可以简化为计算每个元素在任何子集中作为众数出现的次数。 考虑每个数字的出现频率`a`。 让`cnt[x]`是数字的计数`x`。 每个数字都可以对生成的多重集做出贡献`s`从零次到其频率的任意位置。 然后，问题就简化为计算所有数字中这些贡献的组合。 

动态编程自然适合这里。 让`dp[i][j]`表示精确生成多重集的方法数量`j`使用第一个元素`i`不同的数字并考虑每个数字可以作为众数出现的所有方式。 我们迭代每个数字的所有计数并更新 DP 表，确保我们隐式考虑所有分区。 由于总和为`n`很小，一个DP表的大小`n × n`是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(贝尔(n) * n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 动态规划| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘和模逆直到最大值`n`允许快速计算二项式系数。 我们需要组合来计算选择元素形成子集的方法。 
2. 对于每个测试用例，计算多重集中每个不同数字的频率`a`。 让`cnt[x]`是数字的频率`x`。 
3.初始化一个DP数组`dp`和`dp[0][0] = 1`。 这里`dp[i][j]`将存储形成大小多重集的方法数量`j`使用第一个`i`不同的数字。 
4. 迭代每个不同的数字`x`随频率`f = cnt[x]`。 对于每个可能的总大小`j`从`n`降到零，更新`dp[j+k]`为所有人`k`从`1`到`f`通过添加`dp[j] * C(f, k)`模数`998244353`。 这说明选择`k`号码的副本`x`作为来自其频率的模式。 
5. 处理完所有数字后，将所有数字相加`dp[j]`为了`j >= 1`获取非空多重集的总数。 
6. 输出求和模`998244353`。 

**为什么有效：** 每个数字都根据其对最终多重集的可能贡献进行独立考虑。 通过迭代所有计数并通过 DP 组合它们，我们隐式地考虑了原始多重集的所有分区，而无需显式枚举它们。 DP 不变量是`dp[j]`始终表示大小多重集的计数`j`由迄今为止处理的数字组成。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

# Precompute factorials and inverses
MAXN = 5000 + 5
fact = [1] * MAXN
inv_fact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i-1] * i % MOD

inv_fact[MAXN-1] = pow(fact[MAXN-1], MOD-2, MOD)
for i in range(MAXN-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    from collections import Counter
    cnt = Counter(a)
    dp = [0] * (n+1)
    dp[0] = 1
    for f in cnt.values():
        ndp = dp[:]
        for j in range(n+1):
            if dp[j] == 0:
                continue
            for k in range(1, f+1):
                if j+k <= n:
                    ndp[j+k] = (ndp[j+k] + dp[j] * comb(f, k)) % MOD
        dp = ndp
    print(sum(dp[1:]) % MOD)
```该代码首先预先计算阶乘和模逆，以实现高效的二项式系数计算。 对于每个测试用例，它都会计算数字的频率，初始化 DP 数组，并迭代所有数字以填充 DP 表。 最后，它将所有非空多重集计数相加。
