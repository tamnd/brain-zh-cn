 ## 解决方案
 ## 问题理解

 我们有一个整数数组，我们可以选择两个不同的元素，同时将一个元素加 1，将另一个元素减 1。我们可以根据需要多次执行此操作。 任务是确定在这些操作的任何序列之后可以使数组元素相等的最大数量。 

关键是解释这个操作的作用。 每个操作都会保留数组的总和，因为将一个数字加 1 并将另一个数字减 1 会抵消。 所以，总和是不变的。 同时，此操作允许值的“重新分配”：大的数字可以减少，而较小的数字可以增加。 这表明当数组在某个目标值周围尽可能平衡时，将出现最大数量的相等元素。 

该数组最多可包含 100,000 个元素，值的大小最多为 10,000。 这排除了任何对动作的暴力模拟，因为这可能需要长达$10^9$如果我们尝试重复应用操作，请执行以下步骤。 

边缘情况包括元素全部相等的数组、仅包含一个元素的数组或两个元素相差超过 1 的数组。例如，一个数组`[2, 1]`不能完全相等，因为它们的和是 3 并且没有整数`x`这样`2x = 3`对于这两个元素。 正确处理此类情况需要考虑数组和整数除法属性的总和，而不仅仅是比较各个元素。 

## 方法

 一种天真的方法会尝试模拟每对可能的操作，调整元素以使其相等，直到没有进一步的操作有帮助。 这在原则上是正确的，因为该操作保留了总和并将值移向彼此。 但在最坏的情况下，每次移动仅将两个元素更改 1。如果数组包含 100,000 个值为 10,000 的元素，这可能需要数十亿次操作，这太慢了。 

简化问题的洞察力来自于观察两件事。 首先，数组的总和没有改变。 其次，如果我们想要`k`元素等于某个整数`x`， 然后`k * x`必须小于或等于总和，否则将没有足够的总和来分配。 由此我们可以看出，相等元素的最大数量与数组大小的和的最大公约数密切相关，但实际上，我们只需要检查和是否能整除`n`或不。 如果总和可以除以`n`，我们可以使所有元素等于`sum // n`。 如果没有，我们能做的就是`n - 1`元素相等，因为一个元素必须吸收其余元素。 

这里的故事是，蛮力之所以有效，是因为每个操作都朝着平等的方向发展，但因为操作太多而失败。 观察到总和是不变的并且相等需要整数值，这让我们可以将其简化为基于整除性的简单检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n * 最大(a)) | O(n) | 太慢了 |
 | 基于最优数学 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算数组中所有元素的总和。 这代表了我们可以重新分配的总“资源”。 
2. 检查总和是否能被元素个数整除`n`。 如果是，那么我们可以使所有元素等于`sum // n`。 这是可行的，因为每个操作都会保留总和，而整数除法可确保存在精确的目标值。 
3. 如果总和不能被整除`n`，那么不可能使所有元素相等。 在这种情况下，我们能做的最好的就是`n - 1`元素相等。 剩余的元素将吸收剩余的元素。 这遵循鸽巢原理：`n-1`元素可以精确平衡，留下一个额外的元素。 
4. 根据整除性检查打印结果。 

为什么它有效：不变量是数组的总和。 任何有效操作序列都会保留该总和，因此相等元素的目标值必须满足`k * x <= sum`对于整数`x`。 可整除性确保总和可以平均分配； 否则，必须有一个元素占据剩余部分。 没有其他配置可以产生更多相同的元素，因为增加超过`n - 1`元素将违反总和约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

total = sum(a)

if total % n == 0:
    print(n)
else:
    print(n - 1)
```该代码首先读取元素的数量和数组。 它计算总和，然后检查整除性`n`。 直接使用整数除法是不必要的，因为我们只需要知道和是否能整除。 这`n - 1`回退处理单个余数阻止完全相等的情况。 由于 Python 自动处理大整数，因此不存在边界问题。

import sys, io

def run(inp: str) -> str:

 ## 边缘情况

 如果数组只有一个元素，则总和可轻松整除`n=1`，算法正确输出 1。对于两个元素相差 1 的数组，例如`[2, 1]`，总和 3 不能被 2 整除，因此算法输出 1，这是正确的。 对于所有元素相等的数组，总和可整除，因此输出为`n`。 该算法自然地处理负数和零，因为求和逻辑统一适用于整数。
