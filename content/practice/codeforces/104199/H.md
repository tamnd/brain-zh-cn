 ## 解决方案
 ## 问题理解

 我们得到一个密钥，它是一个 n 位字符串，并且要求我们在一组数字约束下找到与其兼容的所有可能的 n 位房间号。 每个房间号也是一个长度为 n 的字符串，由数字 0 到 9 组成，并且允许使用前导零，因此我们实际上是在数字序列而不是数值的空间中工作。 

该约束将房间号的相邻数字链接到钥匙的数字。 对于从 1 到 n-1 的每个位置 i，房间的第 i 个数字和第 (i+1) 个数字之和以 10 为模，必须等于钥匙的第 i 个数字。 此外，还有一个环绕条件：钥匙的最后一位数字等于房间的第一位数字和最后一位数字之和，并且模 10。 

因此，密钥定义了数字上的模线性方程组，其中每个方程恰好涉及两个相邻的房间数字，最后一个方程连接序列的两端。 任务是枚举同时满足所有这些约束的所有数字序列。 

n 最大为 100000 的约束立即排除了任何独立地在数字上分支的方法。 完全枚举 10^n 种可能性是不可能的，甚至任何在每个位置分支而不进行强力修剪的解决方案都会失败。 该结构表明，一旦选择了前缀，序列的其余部分就被确定或受到严格约束，这是减少搜索空间的关键。 

模运算会产生微妙的边缘情况，导致反向传播中出现歧义。 例如，给定 x + y == k (mod 10)，知道 y 可以唯一确定 x 模 10，但前提是我们正确处理环绕值。 使用直接减法而不进行模归一化的粗心实现将产生负数或不正确的分支。 

另一个边缘情况是涉及第一个和最后一个数字的循环约束。 如果仅强制执行线性链约束并忽略与最终方程的一致性，则可能生成局部满足所有相邻约束但全局失败的序列。 

## 方法

 一种强力策略是尝试所有可能的房间号并根据限制验证每个房间号。 对于每个候选字符串，我们检查 n-1 个相邻约束加上一个环绕约束，为每个候选字符串提供 O(n) 验证。 由于有 10^n 个候选者，即使对于非常小的 n，这也是完全不可行的。 

关键的观察结果是，约束形成模 10 的线性递推。如果我们固定房间的第一个数字，那么第二个数字必须满足形式为 a1 + a2 == k1 (mod 10) 的第一个方程，一旦选择了 a1，它就将 a2 限制为模 10 的一个可能值。 继续这个过程，下一个数字是与前一个数字唯一确定的。 这意味着第一个数字的每次选择都会生成一个候选序列。 

然而，由于涉及最后一位数字和第一位数字的循环约束，并非每个初始选择都会产生有效的完整解决方案。 相反，我们生成通过选择第一个数字而导出的所有序列，确定性地传播，然后过滤那些满足最终模块化条件的序列。 

这将问题从对所有数字的指数枚举减少到最多 10 个候选，每个候选的构造时间为 O(n)，从而得到总的 O(10n) 解决方案。

 | 蛮力 | O(10^n·n) | O(10^n·n) | O(n) | 太慢了 |

 ## 算法演练

 我们将这种关系解释为前向递归。 根据 a[i] + a[i+1] == k[i] (mod 10)，一旦已知 a[i]，我们就可以计算 a[i+1]。

1. 尝试房间第一个数字从 0 到 9 的每个可能值。每个选择都定义了一条潜在的解决方案路径，因为一旦起点固定，系统就是确定性的。 
2. 对于选定的第一个数字，使用第一个键约束计算第二个数字。 我们将方程重新排列为 a[i+1] eq k[i] - a[i] (mod 10)，并归一化到 0 到 9 的范围内。此步骤确保我们保持在有效的数字值内。 
3. 从位置 2 向前迭代到 n-1，重复应用递归以确定每个下一个数字。 在每一步中，前一个数字和关键数字完全确定下一个数字，因此初始化后不会发生分支。 
4. 构建完整序列后，验证最终的环绕约束 a[n] + a[1] eq k[n] (mod 10)。 只有满足此条件的序列才是有效的房间号。 
5. 收集所有有效序列并输出。 

关键的结构思想是固定一个变量后方程组是三角形的。 每个方程消除一个自由度，链式结构防止中间位置的独立选择。 

### 为什么它有效

 每个相邻约束强制执行从一个数字到下一个数字的确定性转换。 这意味着一旦初始数字固定，所有后续数字都通过重复应用模减法来唯一确定。 唯一剩下的自由度是起始数字的选择，因此解空间从 10^n 个候选序列压缩到最多 10 个候选序列。 最终的环绕约束充当全局一致性检查，确保循环依赖性不与传播的值相矛盾。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    k = input().strip()

    res = []

    for start in range(10):
        a = [0] * n
        a[0] = start

        ok = True

        for i in range(n - 1):
            # a[i] + a[i+1] ≡ k[i] (mod 10)
            need = (int(k[i]) - a[i]) % 10
            a[i + 1] = need

        # check final constraint: a[n-1] + a[0] ≡ k[n-1]
        if (a[n - 1] + a[0]) % 10 == int(k[-1]):
            res.append("".join(map(str, a)))

    print(len(res))
    for r in res:
        print(r)

if __name__ == "__main__":
    solve()
```实现直接遵循递归解释。 我们将候选房间号存储在一个数组中，并从左到右填充。 模减法`(int(k[i]) - a[i]) % 10`是避免负数并确保所有情况下正确性的关键细节。 

最终检查显式强制执行循环约束，这是前向递归未捕获的唯一条件。

 ## 边缘情况

 一种边缘情况是 n = 2，其中递归的行为不像长链，而是折叠成两个方程，都涉及同一对数字。 在这种情况下，可以根据两个约束直接检查每个数字选择，并且该算法仍然有效，因为它有效地构建了该对并立即验证了循环条件。 

对于输入：```
2
00
```尝试 start = 0 给出序列 00，它满足 a1 + a2 == 0 和 a2 + a1 == 0。这对于所有数字都成立，产生十个有效的解决方案。 该算法正确地枚举了所有这些，因为前向构造仍然产生一致的对，并且最终检查相当于第一个约束。 

另一种边缘情况是没有起始数字满足循环约束。 在这种情况下，结果列表仍为空。 该算法自然会处理这个问题，因为没有序列通过最终检查，因此输出正确为 0，无需额外处理。 

第三种情况是模减法在环绕后产生零。 例如，如果 k[i] = 0 且 a[i] = 7，则计算出的下一个数字变为 (0 - 7) mod 10 = 3。这可以避免负数并确保所有值保持有效数字，这对于所有输入的正确性至关重要。
