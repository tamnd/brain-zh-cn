 ## 解决方案
 ## 问题理解

 我们可以将情况建模为有向图$N$节点，每人一个节点。 每人$i$为自己的房间保留一把钥匙，并将第二把钥匙存放在该人的房间中$c_i$。 有向边$i \to c_i$抓住了访问的想法$c_i$的房间解锁了取回钥匙的能力$i$。 一旦有人可以进入他们的房间，他们就可以立即收集那里存储的所有密钥，并继续通过图表向前传播访问权限。 

这创建了一个可达性系统，其中访问沿着有向边缘传播，但仅在目标节点变得可达时才变为活动状态。 这个过程很单调：一旦可以联系到一个人，他们就会通过解锁更多钥匙来永久贡献其向外的影响力。 

对于每个人$i$，我们要计算初始密钥被删除的最少人数，以便$i$从剩余的未锁定集合开始，将无法再到达。 同样，我们要求最小数量的起始节点，其删除会破坏最终可能到达的所有可能路径$i$。 

约束条件允许$N$最多$10^5$，这立即排除了任何模拟移除集或每个节点运行图形搜索的方法。 一个简单的解决方案，从头开始重新计算每个的可达性$i$根据不同的清除费用$O(N^2)$或者更糟，这远远超出了 10 秒内可以运行的范围。 我们需要对图进行结构分解，以便我们在接近线性的时间内回答所有节点。 

当图表包含长依赖链或循环时，会出现微妙的边缘情况。 例如，在一个简单的循环中$1 \to 2 \to 3 \to 1$，在任意位置删除单个密钥会破坏全局传播。 相比之下，在链中$1 \to 2 \to 3 \to 4$，节点 4 依赖于长级联，并且更难以隔离。 任何正确的解决方案都必须区分分支结构和循环结构，而不仅仅是局部程度。 

## 方法

 蛮力的想法是测试每个人$i$独立。 对于固定的$i$，我们尝试移除不同的人群并模拟是否$i$仍然可以从一些初始的未锁定房间中到达。 这会退化为在带有删除的有向图上重复运行可达性过程，在最坏的情况下会探索$O(N)$每个模拟的节点和要求$O(N)$如果我们尝试逐步增加移除人员的数量，则每个节点的模拟数。 这至少导致$O(N^3)$最坏情况下的行为。 

关键的观察是该图不是任意的。 每个节点都有一个出边，因此该结构是一个函数图：每个连接的组件都由一个有向循环组成，其中有树馈入其中。 一旦我们以这种方式看待它，可达性就完全由循环结构和通向循环的节点深度决定。 

关键的转变是停止考虑任意移除集，而是考虑子图中存在多少个可以到达的独立入口点$i$。 由于每个节点都有一个出边，任何路径最终都会陷入一个循环，并且所有影响都会通过该循环进行漏斗。 仅当进入其可到达组件的所有可能的入口路由都被阻止时，节点才变得不可到达，这减少了对功能图结构中其上方存在多少“独立访问源”的计数。 这些源对应于反向图中的强连接结构根，并且问题归结为该函数依赖系统中的计算优势。 

这允许使用反向边和处理节点以从 SCC 收缩导出的拓扑有意义的顺序进行线性时间分解。 一旦压缩成组件的 DAG，每个节点的答案取决于有多少组件在不共享公共依赖根的情况下仍然可以到达它。 这成为由凝结图引起的树状结构的计数问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(N^3)$|$O(N)$| 太慢了|
 | 功能图+SCC+DP|$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们将有向图转换为每个强连接组件都是单个节点的结构，从而生成 DAG。 

1. 计算由边形成的图的强连通分量$i \to c_i$。 由于每个节点的出度为 1，因此可以使用标准 DFS 或基于迭代堆栈的 SCC 分解在线性时间内完成此操作。 SCC 重要的原因是，在一个循环内，所有节点都是可相互访问的，因此它们表现为可访问的单个单元。 
2. 将每个SCC 收缩为单个超级节点。 对于每一个边缘$i \to c_i$，如果端点属于不同的组件，则在这些组件之间创建有向边。 生成的图是一个类似森林的 DAG，其中每个组件最多有一个传出边缘。 
3. 将组件图反转，得到边代表“可用于解锁”的结构。 现在，每个组件聚合了最终可以为其提供密钥的所有组件。 
4. 对于每个组件，计算在这个反向 DAG 中有多少个独立的根组件可以到达它。 这是通过 DAG 上的 DP 按拓扑顺序完成的。 根组件是在原始组件图中没有传入边的组件。 每个这样的根代表一个独立的密钥起始源。 
5. 任何节点的答案是反转组件图中能够到达其 SCC 的根组件的数量。 这是可以启动访问以最终解锁该节点的独立方式的数量。 要使节点不可访问，必须删除所有这些源，因此最小删除次数等于此计数。 

### 为什么它有效

 SCC收缩后，系统变成一个DAG，其中每个节点代表最大的相互可到达的人的集合。 来自外部的任何访问路径必须源自根组件并沿着定向边缘向下流动。 每个根组件代表一个不相交的“访问源”，并且由于该图是函数图，因此这些源不会以创建超出组件可达性的新独立路径的方式合并。 

因此，当且仅当至少一个根组件具有到该节点的路径时，该节点才是可达的。 要完全阻止可达性，必须禁用每个此类根。 必须移除密钥的最小人数恰好是可以到达节点 SCC 的不同根组件的数量，因为每个根都贡献一条独立的可解锁性链，不能被另一个根取代。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def kosaraju(n, g, gr):
    sys.setrecursionlimit(10**7)
    visited = [False] * n
    order = []

    def dfs1(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs1(to)
        order.append(v)

    for i in range(n):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * n

    def dfs2(v, c):
        comp[v] = c
        for to in gr[v]:
            if comp[to] == -1:
                dfs2(to, c)

    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            dfs2(v, cid)
            cid += 1

    return comp, cid

def solve():
    it = iter(sys.stdin.read().strip().split())
    out = []

    while True:
        try:
            n = int(next(it))
        except StopIteration:
            break

        c = []
        for _ in range(n):
            c.append(int(next(it)))

        g = [[] for _ in range(n)]
        gr = [[] for _ in range(n)]

        for i in range(n):
            g[i].append(c[i])
            gr[c[i]].append(i)

        comp, k = kosaraju(n, g, gr)

        indeg = [0] * k
        cg = [[] for _ in range(k)]

        for i in range(n):
            for j in g[i]:
                if comp[i] != comp[j]:
                    cg[comp[i]].append(comp[j])
                    indeg[comp[j]] += 1

        from collections import deque
        q = deque([i for i in range(k) if indeg[i] == 0])

        reach = [0] * k
        for i in q:
            reach[i] = 1

        topo = []
        while q:
            v = q.popleft()
            topo.append(v)
            for to in cg[v]:
                indeg[to] -= 1
                if indeg[to] == 0:
                    q.append(to)

        for v in topo:
            for to in cg[v]:
                reach[to] += reach[v]

        ans = [0] * n
        for i in range(n):
            ans[i] = reach[comp[i]]

        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案首先构建函数图，并使用 Kosaraju 算法将其压缩为强连接组件。 此步骤是必要的，因为循环代表相互可达性，并将它们视为单个单元可以消除依赖关系传播中的歧义。 

收缩后，分量图是非循环的，因此我们可以按照拓扑顺序对其进行处理。 基于入度的队列构造有效的排序。 我们用可达性计数 1 来初始化每个源组件，因为每个源组件都代表一个独立的访问起点。 

传播步骤累积有多少源组件可以到达每个组件。 这直接成为该组件中每个节点的答案。

 ## 边缘情况

 紧循环如`1 2 0`折叠成一个强连接的组件。 在这种情况下，每个节点都具有相同的可达性，因此算法在 SCC 收缩后为所有节点分配相同的值。 传播步骤分配单个单位到达计数，并将其映射回节点产生统一的输出。 

混合结构如`0 -> 1 -> 2`2 处的自循环形成一棵树，馈入循环 SCC。 SCC 步骤仅合并循环，留下链指向的 DAG。 根计数传播确保链中的所有节点继承与其所依赖的周期相同数量的源。 这可以防止上游节点的计数不足，因为它们的可达性由循环入口点决定。
