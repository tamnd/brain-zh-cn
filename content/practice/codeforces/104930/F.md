 ## 解决方案
 ## 问题理解

 我们被赋予了一个$N \times M$网格，其中每个单元格包含一个二进制值。 值 1 表示图块当前已翻转，0 表示图块已经正确。 唯一允许的操作是选择一个单元格$(R, C)$，然后从左上角切换子矩形中的每个单元格$(1,1)$到$(R,C)$。 每个此类操作都会翻转该前缀矩形中的所有位。 

任务是确定使整个网格变为全零所需的此类前缀矩形翻转的最小数量。 

关键的结构细节是每个操作都会影响锚定在左上角的单调区域。 这立即意味着前面的行和列中的单元格会影响后面必须发生的事情，因为翻转$(R,C)$影响所有职位$(i,j)$和$i \le R$和$j \le C$。 

鉴于$N, M \le 3000$，网格最多可包含 900 万个单元。 任何尝试在网格上显式模拟每个操作的解决方案都会太慢。 甚至$O(N^2 M^2)$是不可能的，甚至$O(NM \min(N,M))$必须小心避免，除非它是线性的。 

一个天真的但自然的想法是重复扫描网格，找到 1，应用翻转来修复它，然后继续。 这会失败，因为单次翻转会更改较大的前缀区域并强制重新计算许多单元。 即使仔细实施，在最坏的情况下这也会变成三次方。 

假设局部贪婪逐行或逐列独立地起作用，就会产生一个微妙的陷阱。 例如，考虑一个网格，其中右下角的翻转几乎影响所有内容。 如果我们逐行处理而不考虑先前操作中累积的奇偶校验，我们可能会错误地假设单元格已经固定，而实际上它还没有固定。 

主要困难是每个单元都受到其选择的所有操作的影响$(R,C)$在两个维度上都占据主导地位。 这会产生 2D 奇偶校验累积问题。 

## 方法

 强力策略是重复定位当前为 1 的任何单元格，并在该单元格的坐标处应用翻转。 每次翻转都会切换一个前缀矩形，因此每次操作后我们必须重新计算许多单元的状态或维护完整的差异结构。 

在最坏的情况下，每次操作都可能影响$\Theta(NM)$细胞，我们可能会执行$\Theta(NM)$操作，导致$\Theta(N^2 M^2)$工作，这是完全不可能的。 

关键的见解是停止从“修复细胞”的角度思考，而是从“运营的贡献”的角度思考。 每次操作在$(R,C)$为前缀矩形中的每个单元提供二进制切换。 所以每个细胞$(i,j)$被所有操作完全翻转$R \ge i$和$C \ge j$。 

这意味着最终值$(i,j)$仅取决于东南地区所选业务的平价。 如果我们从右下角到左上角处理网格，我们可以贪婪地决定每个单元格是否需要操作：在位置$(i,j)$，一旦较大指数的所有贡献都固定下来，我们就可以确定是否需要翻转$(i,j)$修正当前值。 

这将问题简化为维护 2D 奇偶校验结构，在该结构中我们以相反的顺序扫描并跟踪影响每个位置的翻转次数。

 | ---| ---| ---| ---|
 | 蛮力 |$O(N^2 M^2)$|$O(NM)$| 太慢了 |
 | 最佳 |$O(NM)$|$O(NM)$| 已接受 |

 ## 算法演练

 我们将每个选定的操作视为切换前缀矩形，但我们不是向前模拟，而是向后重建答案。 

1. 创建二维数组`grid`存储初始值。 
2. 创建二维数组`flip`初始化为 0，它跟踪处理过程中间接影响每个单元的操作数的奇偶校验。 
3. 从右下角到左上角遍历网格，即行索引递减，每行内列索引递减。 
4. 在每个单元格$(i,j)$，计算其当前有效值：$$current = grid[i][j] \oplus flip[i][j]$$这表示在所有先前决定的操作之后单元格当前是否被翻转。 
5. 如果`current == 1`，我们必须执行一个操作$(i,j)$，因为这是影响该单元格以及将来依赖它的所有单元格的唯一剩余方式。 我们增加答案。 
6. 当我们在以下位置应用操作时$(i,j)$，我们需要反映它对所有细胞的影响$(x,y)$和$x \le i$和$y \le j$。 我们没有直接更新所有这些，而是​​使用 2D 差异式奇偶校验更新，以便将来访问的单元正确地看到其影响。 
7. 继续，直到处理完所有细胞。 所选操作的累积计数就是答案。 

关键的想法是，以相反的顺序处理可以确保当我们决定时$(i,j)$, 所有细胞$(x,y)$和$x > i$或者$y > j$已经最终确定，因此未来的操作不会影响它们。 

### 为什么它有效

 该算法保持了当我们处于位置时的不变性$(i,j)$，值`flip`正确表示该区域中选择的所有操作的奇偶贡献$(x,y)$和$x > i$或者$y > j$。 由于每次操作$(R,C)$仅影响两个维度上索引小于或等于的单元格，按降序处理可确保未来的决策不会追溯性地改变已处理单元格的正确性。 

因此，每当我们在考虑了所有已知的翻转后发现一个单元格为 1 时，我们就被迫在该确切位置选择一个操作。 任何替代放置都无法在不影响已固定位置的情况下纠正它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    # 2D difference array for parity
    diff = [[0] * (m + 2) for _ in range(n + 2)]

    def get(i, j):
        return diff[i][j]

    # prefix XOR reconstruction on the fly
    for i in range(n - 1, -1, -1):
        row_acc = 0
        for j in range(m - 1, -1, -1):
            row_acc ^= diff[i][j]
            diff[i][j] = row_acc ^ diff[i + 1][j] ^ diff[i + 1][j + 1] ^ diff[i][j + 1]

    # We rebuild a cleaner model: use BIT-like sweep
    # Simpler and correct greedy reconstruction:

    bit = [[0] * (m + 2) for _ in range(n + 2)]

    def add(i, j):
        for x in range(i, 0, - (x & -x)):
            for y in range(j, 0, - (y & -y)):
                bit[x][y] ^= 1

    def query(i, j):
        res = 0
        x = i
        while x > 0:
            y = j
            while y > 0:
                res ^= bit[x][y]
                y -= y & -y
            x -= x & -x
        return res

    ans = 0

    for i in range(n - 1, -1, -1):
        for j in range(m - 1, -1, -1):
            cur = grid[i][j] ^ query(i + 1, j + 1)
            if cur == 1:
                ans += 1
                add(i + 1, j + 1)

    print(ans)

if __name__ == "__main__":
    solve()
```该代码使用 2D 奇偶校验上的 Fenwick 树（通过 XOR 实现）来维护影响每个前缀的所选操作的数量。 查询返回影响单元格的翻转次数，并且我们始终按相反的字典顺序评估单元格，以便将来的操作永远不会干扰已经处理的决策。 

XOR 的使用至关重要，因为每个操作都会切换状态而不是递增状态。 Fenwick 结构确保每次更新和查询都在$O(\log N \log M)$，保持总体复杂性可控。 

一个微妙的实现细节是离一索引：Fenwick 树是从 1 开始的，因此我们在查询或更新时总是将索引移动 +1。

 ## 边缘情况

 完全零网格在该算法下是稳定的，因为每个计算的有效值都为零，因此不会触发任何操作。 遍历访问所有单元格，但从不激活更新。 

在不存在先前翻转的情况下，在访问的第一个单元格处以相反顺序处理完全填充的网格。 该算法在右下角触发单个操作，该操作会传播到概念模型中的整个网格，即使中间推理将其视为纠正所有剩余的网格。 

单细胞网格直接显示基本不变量。 如果单元格为1，则强制执行一次操作； 如果为0，则不需要。 该算法在没有任何边界复杂性的情况下干净地减少，确认了索引移位的正确性。
