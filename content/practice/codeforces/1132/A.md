 ## 解决方案
 ## 问题理解

 我们有四种类型的括号字符串，每种长度为 2：“((”、“()”、“)(”和“))”。 输入提供了我们拥有的每种类型的数量。 我们的任务是确定是否可以按某种顺序连接所有这些字符串以形成有效的常规括号序列。 如果我们在括号之间插入“+”和“1”，则常规括号序列可以表示有效的算术表达式。 示例包括“(())”或“()()”。 像“))(”或“)((”这样的序列是无效的，因为无法正确匹配左括号和右括号。

 每个字符串恰好贡献两个字符，因此最终序列的总长度是计数总和的两倍。 关键的观察结果是，每种类型的字符串对左括号和右括号的“平衡”的影响不同。 “((”将余额增加 2，“()”保持中立，“)(”先减少然后增加余额，“))”将余额减少 2。 

约束允许计数最多$10^9$，因此任何尝试显式生成序列或模拟串联的解决方案都会太慢。 我们必须纯粹使用算术和不变量进行推理，而不是构建序列。 

一个重要的边缘情况是当以“)”开头或以“(”结尾的字符串数量超过可匹配的数量时。例如，如果我们有一个“)(”而没有“((”，则不可能将其放置在任何地方而不在某个时刻产生负余额。另一种边缘情况是所有计数为零时；空序列是规则的。正确处理这些边界条件对于通过所有测试至关重要。

 ## 方法

 暴力方法会尝试尝试字符串的所有排列并检查连接序列是否规则。 这在原则上是正确的，因为它探索了所有可能性，但是排列的阶乘增长使得即使对于非常少量的字符串也是不可行的。 计数高达$10^9$，尝试排列是不可能的。 

最佳方法依赖于维持支架平衡。 每个正则括号序列必须满足两个条件。 首先，左括号的总数必须等于右括号的总数。 其次，从左到右扫描，运行余额（开盘减去收盘）绝不能为负。 这两个条件可以直接根据计数计算出来，而无需模拟每个字符串。 

具体来说，我们检查“((”的数量加上“)(”的数量是否等于“))”的数量加上“((”的数量。这确保总余额为零。为了满足非负运行余额，“)(”和“((”之间的差在任何时候都不能超过1，因为“)(”是唯一可以减少序列中间余额的字符串。这导致了简洁的规则：“((”的计数和“((”的计数)之间的绝对差 “))”最多只能是一个，如果至少有一个“)(”，我们需要一个对应的“((”来开始。

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（尝试所有排列）| O((cnt1+cnt2+cnt3+cnt4)!) | O(1) | O(1) | 太慢了 |
 | 基于余额的检查| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取四种字符串类型的计数：$cnt1, cnt2, cnt3, cnt4$。 这些对应于“((”、“()”、“)(”和“))”。 
2. 将左括号总数计算为$2*cnt1 + cnt2 + cnt3$总右括号为$2*cnt4 + cnt2 + cnt3$。 验证它们相等。 如果不是，则输出 0，因为常规序列需要相同数量的左括号和右括号。 
3. 检查余额要求。 唯一棘手的字符串是“)(”，因为它以右括号开头。我们必须确保在任何“)(”之前至少有一个“((”，以避免在开始时出现负运行余额。如果$cnt3 > 0$和$cnt1 = 0$，输出0。 
4. 检查“((”和“))”计数之间的差异。 如果$|cnt1 - cnt4| > 1$，输出 0，因为我们无法保持运行余额非负。 
5. 如果所有条件都满足，则输出1。 

保持的不变性是，在串联序列中的每个点，“(”减“)”的运行平衡永远不会为负，并以零结束。 这保证了规则的括号序列，而不需要模拟串联。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

cnt1 = int(input())
cnt2 = int(input())
cnt3 = int(input())
cnt4 = int(input())

# check if total number of opening and closing brackets are equal
total_open = 2*cnt1 + cnt2 + cnt3
total_close = 2*cnt4 + cnt2 + cnt3

if total_open != total_close:
    print(0)
elif cnt3 > 0 and cnt1 == 0:
    # cannot start with ")("
    print(0)
elif abs(cnt1 - cnt4) > 1:
    # balance at ends is off by more than 1
    print(0)
else:
    print(1)
```该解决方案首先检查总余额，这保证最终序列具有匹配的括号。 然后，它处理棘手的“)(”字符串的边缘情况，并确保纯开“((”和纯闭“))”字符串之间的差异不会违反非负运行平衡。每个条件直接对应于常规括号序列的属性。

 ## 边缘情况

 当至少有一个“)(”但没有“((”时，算法返回0。对于输入`0 0 1 0`,`cnt3>0`和`cnt1=0`触发检查。 如果我们尝试将“)(”放在开头，则会立即出现负余额。算法会检测到这一点并正确输出 0。

 当纯开字符串和纯闭字符串之差超过1时，如`10 0 0 12`，算法输出 0，因为最终序列在某些时候需要比允许的更多的左括号，从而违反了非负运行平衡不变量。
