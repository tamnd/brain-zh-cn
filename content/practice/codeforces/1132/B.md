 ## 解决方案
 ## 问题理解

 我们有一套巧克力棒，每块都有自己的价格。 购物者想要所有的酒吧，但有一些折扣优惠券可供选择。 每张优惠券允许购买固定数量的酒吧，但在该选择范围内，最便宜的酒吧是免费的。 任务是确定对于每张优惠券，如果优惠券得到最佳应用并且以全价购买剩余的金条，则总成本最低。 

输入由柱数组成`n`，他们各自的价格`a_i`, 优惠券数量`m`，以及优惠券的大小`q_i`。 输出是一个数组`m`整数，其中每个整数是最佳使用相应优惠券时的最低付款额。 

约束条件允许`n`多达30万。 这立即排除了任何尝试每张优惠券的巧克力棒的所有组合的暴力方法，因为`C(n, q)`组合增长。 即使对每个优惠券进行简单迭代也会太慢，因此我们需要一种可以线性或近线性扩展的方法`n`。 

当所有巧克力棒具有相同的价格时，就会出现不明显的边缘情况。 例如，如果`n = 3`，酒吧是`[5, 5, 5]`，并且优惠券允许`q = 2`，选择的最佳条形可以是任意对。 产出仍必须仅考虑支付该对中最昂贵的费用。 假设条形图不同的粗心方法可能会产生错误的计算。 

另一个微妙的情况是当优惠券允许时`q = n`酒吧。 在这里，所有酒吧都选择了折扣，所有酒吧中最便宜的是免费的。 实现必须在没有索引错误的情况下处理这个问题。 

## 方法

 暴力方法很简单：对于每个优惠券，枚举所有可能的尺寸子集`q_i`，将选定柱的价格（不包括最便宜的）相加，然后添加其余柱的总和。 这可以正常工作，但最坏情况下每张优惠券的复杂度为 O(n 选择 q)。 当 n 高达 300,000 时，这是不可行的，因为即使是适度的 q 值也会产生天文数字般的大量组合。 

关键的见解是，对于每张优惠券，我们希望最大化折扣。 折扣是所选套餐中最便宜的酒吧的价格。 因此，为了最小化总成本，我们应该选择`q_i`优惠券最贵的酒吧。 支付除最便宜的以外的所有费用可以最大化从总额中扣除的金额。 这使我们能够将问题简化为按降序对所有条形进行排序，并使用前缀和来快速计算顶部的总和`q_i`酒吧。 总成本等于所有柱的总和减去顶部最便宜的柱`q_i`。 

这将解决方案从组合转换为 O(n log n + m)，其中 O(n log n) 用于排序，O(m) 用于使用预先计算的前缀和计算每个优惠券的结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m * C(n, q)) | O(m * C(n, q)) | O(n) | 太慢了 |
 | 最佳 | O(n log n + m) | O(n log n + m) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`, 价格数组`a`,`m`，以及优惠券大小的数组`q`。 这些代表金条的数量、它们各自的价格、优惠券的数量以及每张优惠券影响的金条数量。 
2. 对数组进行排序`a`按降序排列。 这确保了最昂贵的酒吧在开始时。 排序至关重要，因为最佳优惠券选择始终包括最昂贵的金条，以最大限度地提高折扣。 
3. 计算排序数组的前缀和。 索引处的前缀和`i`代表第一个的总和`i+1`最贵的酒吧。 这允许恒定时间查询顶部的总价`k`酒吧。 
4. 计算所有柱的总和。 这将用于通过减去优惠券中的免费条来计算每张优惠券的最终付款。 
5. 对于每个优惠券尺寸`q_i`，最优策略是选择顶部`q_i`酒吧。 其中，最便宜的柱（尺寸排序子集中的最后一个）`q_i`）是免费的。 总成本为所有金条的总和减去最便宜的金条。 
6. 按顺序打印每张优惠券的结果。 

保证正确性的不变量是，对于任何优惠券，通过选择最大的折扣来最大化折扣`q_i`酒吧。 没有任何替代的巧克力棒子集能产生更大的折扣，因为任何价格较低的巧克力棒都会降低免费巧克力的价值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
m = int(input())
q = list(map(int, input().split()))

a.sort(reverse=True)
prefix_sum = [0] * n
prefix_sum[0] = a[0]
for i in range(1, n):
    prefix_sum[i] = prefix_sum[i-1] + a[i]

total_sum = prefix_sum[-1]

results = []
for x in q:
    free_bar = a[x-1]  # cheapest among the top x bars
    cost = total_sum - free_bar
    results.append(str(cost))

print('\n'.join(results))
```该解决方案首先对巧克力棒进行排序并构造一个前缀和数组。 这`total_sum`捕获所有条形的总和。 对于每张优惠券，顶部的最后一个栏`q_i`从总金额中减去巧克力棒即可算出免费巧克力。 该算法通过使用预先排序的数组来避免重新计算。
