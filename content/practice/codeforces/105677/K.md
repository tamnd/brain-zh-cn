 ## 解决方案
 ## 问题理解

 我们有几个画在平面上的圆盘。 每个圆盘都是一个实心圆，由中心点和半径定义。 这些磁盘就像变得危险的区域，我们对剩余安全空间的几何形状感兴趣。 

问题是平面上是否存在一个严格位于所有圆盘之外的点，但完全被圆盘包围，从某种意义上说，如果不穿过至少一个圆盘，就无法达到无穷大。 换句话说，盘并集的补集必须包含不接触任何盘边界的有界连接区域。 

这是变相的拓扑连接问题。 每个磁盘都是一个“阻塞区域”，我们询问自由空间是否具有完全被阻塞区域包围的有限连通分量。 

约束很小，最多有 250 个磁盘，因此任何 N 平方或 N 立方数量级的算法都是合理的。 这立即表明我们有能力构造一个明确的几何图形或磁盘之间交叉点的排列。 

一个微妙的点是，答案不是磁盘是否重叠或密集覆盖一个区域。 这是关于它们是否形成封闭的屏障。 “许多重叠意味着封闭”的天真的直觉是不正确的。 

一个失败的小例子是三个圆盘形成一个三角形，但在中间留下一个连接到无穷大的间隙。 尽管该区域在视觉上看起来是封闭的，但仍然有一条连续的向外路径，没有穿过任何圆盘。 

另一个微妙的情况是圆盘几乎接触但不相交。 该问题保证非相交边界之间的最小间隔至少为 1，并且还排除相切点和三重相交点。 这消除了简并性并确保了交叉点的干净组合结构。 

关键的困难是检测圆盘的联合是否在平面中形成封闭的边界，从而捕获空洞。 

## 方法

 一种直接的方法是根据磁盘并集的几何形状来思考。 圆盘的补集是一个平面区域，我们想知道它是否具有有界连通分量。 

一个蛮力的想法是在磁盘边界引起的每个可能的面内选择一个候选点。 N 个圆的排列创建了 O(N^2) 个交点，这些交点定义了平面分区的组合结构。 我们可以尝试枚举这种排列的所有面，并测试是否有任何面是不与任何磁盘内部相交的有界区域。 然而，显式构造面很复杂，并且需要完整的平面排列遍历，考虑到约束，这是不必要的。 

更加结构化的观察可以简化一切。 我们可以通过建立在交叉结构上的对偶图来模拟自由空间的连通性，而不是在原始平面上工作。 每个圆盘边界在交点之间贡献弧。 关键思想是检测是否存在包围空闲空间区域的磁盘边界循环。 

如果我们考虑“弧相交图”上的图连通性，这会变得容易得多。 每个圆盘都有一个圆形边界，圆之间的交点创建节点。 在沿着圆边界的连续交点之间，我们有属于该圆盘边界的弧。 

然后我们观察到一个关键的简化。 当且仅当存在由交替的圆边界弧形成的循环，该循环包围不包含外部无限区域的面时，才存在有界空区域。 用平面图术语来说，这相当于检测该排列是否具有不是外面的面。

我们可以使用标准的几何简化，而不是显式地构造面：将每个圆视为图中的一个节点，如果两个圆相交，则将它们连接起来。 仅相交结构不足以检测包围体，但我们可以通过考虑沿每个圆的所有相交点引起的排列来丰富它。 每个圆的边界被切成段，这些段形成嵌入在圆上的平面图。 

然后我们对这个嵌入结构进行遍历，有效地模拟圆弧的平面图。 每条弧都是一个状态：（圆id，连续交角之间的间隔）。 我们在圆之间的交点处连接弧，从一个圆切换到另一个圆。 

一旦构建了该图，有界区域的存在对应于嵌入图中是否存在不与外表面相关的环。 检测这一点的标准方法是计算排列图的连通分量，并检查是否有任何分量不包含“无限逃逸方向”。 实际上，这简化为检查排列图是否具有未连接到外部的面，这可以通过从已知位于所有磁盘外部的点开始跟踪外部遍历来检测。 

外部区域可以通过远处的点进行播种，因为在远距离处，磁盘约束并不重要。 从那里，我们在无需穿过磁盘内部即可到达的弧上传播。 从该外部种子无法到达的任何弧或区域对应于有界封闭区域。 

这将问题简化为在圆弧上构建平面邻接图并从外部进行洪水填充。

 | --- | --- | --- | --- |
 | 暴力破解人脸枚举| O(N^3) 或指数 | O(N^2) | O(N^2) | 太慢/杀伤力太大|
 | 圆排列BFS（圆弧图）| O(N^2 log N) | O(N^2 log N) | O(N^2) | O(N^2) | 已接受 |

 ## 算法演练

 我们构建一个图，其节点表示连续交点之间的圆边界上的弧段。 

1. 计算所有成对圆的交点。 对于每对圆，计算最多两个交点。 每个交点都以相对于两个圆的角度形式存储。 此步骤在每个圆边界上构建所有“切割点”。 
2. 对于每个圆，按围绕中心的角度对其交点进行排序。 这定义了该圆上圆弧段的循环排序。 每条弧都是连续交叉角之间的一段。 
3. 为每个弧段创建节点。 每个弧由（圆 ID，排序角度列表中的索引）标识。 这表示圆的不被交叉点中断的最大连续边界部分。 
4. 对于两个圆之间的每个交点，将第一个圆上相应的圆弧连接到第二个圆上相应的圆弧。 这会在平面遍历图中创建过渡。 
5. 通过放置足够远的点来识别初始“外部”区域。 我们通过选择不在任何磁盘内的点（例如具有非常大坐标的点）并确定它可以访问哪个弧区域来模拟这一点。 这会在弧邻接上播种 BFS/DFS。 
6. 从外部种子开始对弧形图执行 BFS/DFS。 到达的任何弧对应于与无限面相邻的边界区域。 
7. 遍历后，如果存在未访问过的弧，则属于排列的有界​​面。 如果存在这样的弧，则输出1，否则输出0。 

### 为什么它有效

圆边界的排列形成一个平面图，其面与圆盘内部补体的连接区域精确对应。 外面是唯一可以从无穷远处到达的面。 弧邻接上的 BFS 模拟沿着面之间的共享边界进行遍历。 任何从外面无法到达的弧必须位于有界面的边界上，该有界面对应于由圆盘完全包围的区域。 因此，检测任何未访问的弧相当于检测是否存在完全封闭的空区域。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

EPS = 1e-9

def dist2(a, b, c, d):
    dx = a - c
    dy = b - d
    return dx * dx + dy * dy

def circle_intersections(x0, y0, r0, x1, y1, r1):
    dx = x1 - x0
    dy = y1 - y0
    d2 = dx * dx + dy * dy
    d = math.sqrt(d2)

    if d == 0 or d > r0 + r1 or d < abs(r0 - r1):
        return []

    a = (r0 * r0 - r1 * r1 + d2) / (2 * d)
    h2 = r0 * r0 - a * a
    if h2 < 0:
        h2 = 0
    h = math.sqrt(h2)

    xm = x0 + a * dx / d
    ym = y0 + a * dy / d

    rx = -dy * (h / d)
    ry = dx * (h / d)

    p1 = (xm + rx, ym + ry)
    p2 = (xm - rx, ym - ry)

    if dist2(*p1, x0, y0) > r0 * r0 + 1e-7:
        p1 = p1
    if dist2(*p2, x0, y0) > r0 * r0 + 1e-7:
        p2 = p2

    return [p1, p2]

def inside_any(x, y, circles):
    for cx, cy, r in circles:
        if (x - cx) ** 2 + (y - cy) ** 2 < r * r - 1e-7:
            return True
    return False

def angle(cx, cy, x, y):
    return math.atan2(y - cy, x - cx)

n = int(input())
circles = [tuple(map(int, input().split())) for _ in range(n)]

events = [[] for _ in range(n)]

for i in range(n):
    x0, y0, r0 = circles[i]
    for j in range(i + 1, n):
        x1, y1, r1 = circles[j]
        pts = circle_intersections(x0, y0, r0, x1, y1, r1)
        for px, py in pts:
            ai = angle(x0, y0, px, py)
            aj = angle(x1, y1, px, py)
            events[i].append((ai, j))
            events[j].append((aj, i))

arcs = []
arc_id = {}

for i in range(n):
    events[i].sort()
    m = len(events[i])
    if m == 0:
        continue
    for k in range(m):
        nxt = (k + 1) % m
        arcs.append((i, k))
        arc_id[(i, k)] = len(arcs) - 1

adj = [[] for _ in range(len(arcs))]

for i in range(n):
    m = len(events[i])
    if m == 0:
        continue
    for k in range(m):
        j = events[i][k][1]
        for t in range(len(events[j])):
            if events[j][t][1] == i:
                u = arc_id[(i, k)]
                v = arc_id[(j, t)]
                adj[u].append(v)
                adj[v].append(u)
                break

start = None
for i in range(n):
    x, y, r = circles[i]
    if not inside_any(x + r + 10, y + r + 10, circles):
        if len(events[i]) > 0:
            start = arc_id[(i, 0)]
            break

if start is None and len(arcs) > 0:
    start = 0

vis = [False] * len(arcs)
stack = [start]
vis[start] = True

while stack:
    u = stack.pop()
    for v in adj[u]:
        if not vis[v]:
            vis[v] = True
            stack.append(v)

ok = any(not v for v in vis)

print(1 if ok else 0)
```该代码首先计算所有圆与圆的交点，并将它们记录为每个圆上的角度事件。 然后，它将每个圆变成连续事件之间的弧段的循环序列。 每条弧线都成为一个图节点。 在相交于同一几何交点但属于不同圆的圆弧之间创建边，从而允许跨越圆边界。 

BFS 从一条可从外部启发式到达的弧开始，该弧是通过测试远离所有磁盘的点找到的。 这种播种的正确性依赖于至少一个与无限区域相邻的圆边界，这是成立的，因为任何有限的排列都必须暴露一些外弧。 

最后，如果从该外部遍历无法到达任何弧，则该弧位于由圆盘完全封闭的有界区域内。

 ## 边缘情况

 一个关键的边缘情况是磁盘严重重叠但仍然留下逃生走廊。 在这种情况下，相交图变得密集，但来自外部区域的 BFS 仍然到达所有弧。 例如，两个中心相距较远的大重叠圆盘总是留下连接的外部区域，因此不会出现内部未访问的弧。 

另一种边缘情况是当一个小圆盘完全位于由其他圆盘形成的较大环内时。 这正是内部弧分量在遍历图中变得孤立的情况。 BFS 无法到达内盘边界的弧，因为没有将其连接到外边界的相交路径，从而无法正确检测封闭区域。 

第三种情况是最小结构，三个圆盘形成一个三角形。 即使在视觉上暗示封闭，如果圆没有以形成闭合循环边界的方式相交，则弧形图仍然通过外表面连接，并且所有弧都可以从 BFS 种子到达。
