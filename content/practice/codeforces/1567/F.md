 ## 解决方案
 ## 问题理解

 我们给出了一个尺寸的网格$n \times m$其中一些单元格标有`X`其余均未标记`.`。 标记的单元格永远不会位于网格的边界上。 我们的任务是用 1 或 4 填充每个未标记的单元格，然后用其相邻未标记单元格的总和填充每个标记的单元格。 此外，每个标记单元格的最终值必须能被 5 整除。如果不存在赋值，我们必须输出`NO`; 否则，我们会生成任何有效的填充网格。 

输入约束$1 \le n, m \le 500$建议$O(n \cdot m)$解决方案是可行的。 任何类似的东西$O((n \cdot m)^2)$会有太慢的风险，因为$500^2 = 250{,}000$很好，但是$500^4$是不可想象的。 256 MB 的内存限制可以轻松容纳网格和辅助数组的存储。 

一种简单的方法可能会尝试对所有未标记单元格 1 和 4 的每种组合，并检查标记单元格的可分性。 这失败了，因为即使是一个适度的 10×10 网格也有$2^{100}$组合，这是一个天文数字。 

不明显的边缘情况包括仅具有一两个未标记邻居的标记单元。 例如，完全被标记单元包围的标记单元必须为 0。另一种情况是标记单元与四个未标记单元相邻。 并非所有 1 和 4 的组合都能得到 5 的倍数； 我们需要确保邻接金额是可行的。 粗心的贪婪分配可能会创建像 3 或 6 这样的标记单元总和，并且无法通过相邻分配来纠正。 

## 方法

 强力方法是迭代所有可能的 1 或 4 到未标记单元格的分配，并检查标记单元格的总和。 每个未标记的单元格有两个选项，给出$2^{u}$的可能性$u$未标记的细胞。 验证步骤包括扫描标记的单元格并对相邻单元格求和。 这在原则上是正确的，但对于具有超过 20 个未标记单元的网格来说变得不可行。 

关键的见解是每个标记单元与未标记单元的子集相邻，并且模 5 的和必须为 0。问题简化为 2-sat 式约束：相邻未标记单元的值可以表示为可以采用两种状态的变量，并且它们模 5 的和的奇偶性必须满足该约束。 具体来说，如果我们以棋盘图案绘制未标记的单元格，则每个标记的单元格都有两个相邻的一种颜色和两个另一种颜色的相邻单元格（或者在边缘上更少，但边缘永远不会有标记的单元格），因此我们可以为这两种颜色分配值，使得所有总和都可以被 5 整除。自然的选择是在棋盘图案中为未标记的单元格交替分配 1 和 4。 那么每个标记的单元格都有一个可被 5 整除的和：两个 1 和两个 4 的总和为 10，可被 5 整除。如果标记的单元格只有一个邻居，则 1+4 = 5 仍然有效。 

这个观察让我们贪婪地构建解决方案$O(n \cdot m)$没有回溯的时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n*m)) | O(2^(n*m)) | O(n*m) | 太慢了 |
 | 最佳 | O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 创建一个二维数组来存储输出网格。 使用 -1 作为占位符初始化所有未标记的单元格。 
2. 以棋盘形式为未标记的单元格赋值：如果行索引和列索引之和为偶数，则赋值为 1；如果行索引和列索引之和为偶数，则赋值为 1； 如果是奇数，则分配 4。这保证了与未标记单元相邻的任何标记单元的邻居总和为 5 的倍数。 
3. 迭代网格中的每个单元格。 如果该单元格已标记，则计算所有相邻未标记单元格的总和。 由于我们知道未标记的单元格交替分配 1 和 4，因此该总和会自动被 5 整除。用该总和填充标记的单元格。 
4. 输出`YES`并逐行打印填充的网格。 如果有一个标记的单元格的邻居数为零，则其总和为 0，可以被 5 整除，因此不需要特殊处理。 

工作原理：棋盘分配确保对于任何未标记邻居的配置，标记单元周围的数字总和始终是 5 的倍数。此不变量成立，因为 1+4 = 5，并且邻居的任意组合中的多个 1 和 4 的总和会产生可被 5 整除的总和。无需进一步回溯或 2-sat 求解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]
ans = [[0]*m for _ in range(n)]

for i in range(n):
    for j in range(m):
        if grid[i][j] == '.':
            ans[i][j] = 1 if (i+j) % 2 == 0 else 4

directions = [(-1,0),(1,0),(0,-1),(0,1)]

for i in range(n):
    for j in range(m):
        if grid[i][j] == 'X':
            s = 0
            for dx, dy in directions:
                ni, nj = i+dx, j+dy
                if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == '.':
                    s += ans[ni][nj]
            ans[i][j] = s

print("YES")
for row in ans:
    print(' '.join(map(str,row)))
```每个未标记的单元格都直接使用索引奇偶校验来分配一个值，确保棋盘图案。 填充标记单元格时，我们仅对相邻的未标记单元格求和。 边界受到尊重，因此不会发生超出范围的错误。 此方法不需要显式检查整除性，因为棋盘属性保证总和可被 5 整除。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    ans = [[0]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '.':
                ans[i][j] = 1 if (i+j) % 2 == 0 else 4
    directions = [(-1,0),(1,0),(0,-1),(0,1)]
    for i in range(n):

                s = 0
                for dx, dy in directions:
                    ni, nj = i+dx, j+dy

                        s += ans[ni][nj]
                ans[i][j] = s
    output = ["YES"] + [' '.join(map(str,row)) for row in ans]
    return '\n'.join(output)
