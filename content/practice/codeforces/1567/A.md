 ## 解决方案
 ## 问题理解

 我们有一个宽度为 2 行的网格$n$完全覆盖于$1 \times 2$骨牌。 每个多米诺骨牌可以垂直放置，覆盖每行中的一个单元格，也可以水平放置，覆盖同一行中的两个相邻单元格。 Alice 向我们展示了网格的其中一行，表示为长度的字符串$n$带有字符“L”、“R”、“U”、“D”。 “L”和“R”表示水平多米诺骨牌的左半部和右半部，而“U”和“D”表示垂直多米诺骨牌的上半部和下半部。 我们的任务是重建网格的另一行，使用相同的字符编码生成相同长度的字符串。 

限制很小：$n \le 100$和$t \le 5000$，所以即使是一个$O(n)$每个测试用例的解决方案将足够有效。 主要挑战不是效率，而是正确解释多米诺骨牌的放置并将一行转换为另一行，同时遵守平铺规则。 

边缘情况出现在短网格、完全充满垂直多米诺骨牌或交替水平多米诺骨牌的网格中。 例如，如果给定的行是`"U"`，另一行必须是`"D"`; 尝试推断单列网格中水平多米诺骨牌的粗心解决方案将会失败。 类似地，如果输入是`"LR"`，两行都保留`"LR"`，并且解决方案必须避免修改它们。 

## 方法

 一种简单的方法是尝试模拟将所有多米诺骨牌放置在网格上，然后匹配给定的行，通过反复试验重建丢失的行。 这可能涉及二维阵列并检查每个可能的方向。 虽然原则上是正确的，但它是多余的，因为问题完全由简单的映射规则决定：给定行中的每个单元格唯一地确定另一行中的单元格。 暴力方法之所以有效，是因为它确保了与多米诺骨牌规则的一致性，但它会浪费时间构建不必要的状态，并且更容易出现实现错误。 

关键的见解是输入行中的每个字符直接定义另一行中的相应字符：如果我们看到“U”，那么下面的单元格一定是“D”，反之亦然； 如果我们看到“L”，则同一行右侧的单元格是“R”，并且相应的行完全匹配，因为水平多米诺骨牌只占据一行。 通过这种观察，我们可以在线性时间内迭代字符串，根据简单的映射替换每个字符。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每个测试用例 O(n)，总体 O(n*t) | O(n) | 已接受但没有必要 |
 | 直接映射 | 每个测试用例 O(n)，总体 O(n*t) | O(n) | 已接受、干净且最佳 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$和字符串$s$代表一行。 
3. 为另一行初始化一个空列表，我们将逐个字符构建该列表。 
4. 迭代字符串$s$使用索引从左到右$i$。 
5.如果$s[i]$是“U”，将“D”附加到另一行。 如果$s[i]$是“D”，附加“U”。 
6. 如果$s[i]$是“L”，将“L”附加到另一行并跳过下一个字符（必须是“R”），因为水平多米诺骨牌覆盖了同一行中的两个单元格。 如果$s[i]$是“R”，跳过它，因为它已经被前面的“L”处理过。 
7. 循环结束后，将列表连接成字符串并输出。 

工作原理：输入行的每个单元格唯一标识另一行中的相应单元格。 垂直多米诺骨牌颠倒“U”和“D”，而水平多米诺骨牌则原样复制。 该算法保留多米诺骨牌平铺规则，并为任何有效输入生成有效的其他行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    res = []
    i = 0
    while i < n:
        if s[i] == 'U':
            res.append('D')
            i += 1
        elif s[i] == 'D':
            res.append('U')
            i += 1
        elif s[i] == 'L':
            res.append('L')
            res.append('R')
            i += 2
        else:  # s[i] == 'R'
            i += 1  # already handled
    print(''.join(res))
```该代码首先读取测试用例的数量，然后迭代每个字符串。 垂直多米诺骨牌通过交换“U”和“D”来转换，水平多米诺骨牌通过复制“L”和“R”作为一对来转换。 在“L”之后跳过“R”可确保我们不会重复计算单元格。 这可以正确处理两行，而无需构建完整的二维网格。

def run(inp: str) -> str:

    output = io.StringIO()
    sys.stdout = output

    for _ in range(t):
        n = int(input())
        s = input().strip()
        res = []
        i = 0
        while i < n:
            if s[i] == 'U':
                res.append('D')
                i += 1
            elif s[i] == 'D':
                res.append('U')
                i += 1
            elif s[i] == 'L':
                res.append('L')
                res.append('R')
                i += 2
            else:  # s[i] == 'R'
                i += 1
        print(''.join(res))
    return output.getvalue().strip()

 ## 边缘情况

 对于单单元垂直多米诺骨牌式输入`"U"`，算法附加`"D"`直接，正确处理一格的宽度。 对于连续的水平多米诺骨牌，例如`"LLLL"`，循环对于每个“L”增加 2，确保没有“R”被重复计算，并且输出正确地交替“LR”。 对于按顺序具有多个垂直多米诺骨牌的输入，“U”和“D”之间的交换分别应用于每个单元格，以保持正确的对应关系。 这些行为确认该解决方案可以处理最小和最大覆盖场景。
