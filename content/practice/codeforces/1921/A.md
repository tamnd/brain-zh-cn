 ## 解决方案
 ## 问题理解

 我们在二维坐标平面上得到了一个正方形的四个顶点。 这些点以任意顺序呈现，因此我们不知道哪个点是左下角、右上角等。 

该正方形有两个特殊属性。 它的边平行于坐标轴，并且它的面积严格为正。 因为边是轴对齐的，所以正方形的顶点必须使用两个不同的 x 坐标和两个不同的 y 坐标。 边长就是两个 x 值之间的距离，它等于两个 y 值之间的距离。 

对于每个测试用例，我们必须计算正方形的面积。 

限制很小。 最多有 100 个测试用例，每个测试用例仅包含 4 个点。 每个测试用例执行几十个操作的任何算法都将立即运行。 效率不是这里的挑战。 挑战在于识别顶点随机排序隐藏的几何结构。 

一个常见的错误是假设点按有用的顺序到达。 考虑：```
1 2
4 5
1 5
4 2
```前两个点是对角，而不是相邻的角。 计算连续输入点之间的距离会产生错误的边长。 

另一个微妙的情况是坐标为负数时：```
-1 1
1 -1
1 1
-1 -1
```边长不是从最大坐标值获得的。 我们必须计算最大和最小 x 值之间的差，给出`1 - (-1) = 2`。 

粗心的实现也可能会尝试使用任意点对之间的欧几里德距离。 例如：```
17 11
17 39
45 11
45 39
```对角线长度远大于边长。 对角线求平方不会得出面积。 正确的边长是`45 - 17 = 28`，所以面积是`28² = 784`。 

## 方法

 强力解决方案将检查所有点对并确定哪些对形成正方形的边缘。 由于只有四点，因此有六对。 我们可以找到最小的非零水平或垂直距离并将其用作边长。 这是有效的，因为输入保证描述一个有效的轴对齐正方形。 

尽管这种方法已经足够快，但它比必要的更复杂。 我们正在解决一个几何问题，其结构比一般的正方形检测问题简单得多。 

关键的观察结果是，轴对齐的正方形恰好具有两个不同的 x 坐标和两个不同的 y 坐标。 边长很简单：```
max(x) - min(x)
```由于图形保证是正方形，因此相同的值也等于：```
max(y) - min(y)
```一旦我们知道了边长，面积就是它的平方。 

这将问题转化为从四个点中提取最小和最大 x 值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 渐近复杂度是相同的，因为每个测试用例的输入大小是固定的，但最佳方法更清晰，并且直接使用轴对齐正方形的几何形状。 

## 算法演练

 1. 阅读当前测试用例的四点。 
2. 将所有 x 坐标存储在列表中。 
3. 计算最小和最大 x 值。 
4. 计算边长为`max_x - min_x`。 

由于正方形是轴对齐的，因此每个顶点正好位于两条垂直线之一上。 它们的间隔是边长。 
5. 将面积计算为`side_length * side_length`。 
6. 输出面积。 

### 为什么它有效

 对于轴对齐的正方形，左侧和右侧位于两个不同的 x 值上。 每个顶点都属于这两条垂直线之一。 它们之间的水平距离恰好是正方形的边长。 

因为保证输入形成一个有效的正方形，`max(x) - min(x)`始终为正值并且等于正方形的边长。 将该值平方即可得到面积。 不需要其他几何计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    xs = []

    for _ in range(4):
        x, y = map(int, input().split())
        xs.append(x)

    side = max(xs) - min(xs)
    print(side * side)
```该解决方案读取每个测试用例的四个点并仅保留它们的 x 坐标。 由于正方形保证轴对齐，因此边长由最左边和最右边顶点之间的水平距离确定。 

使用`max(xs) - min(xs)`避免对输入顺序的任何依赖。 无论顶点是顺时针、逆时针还是完全打乱排列，极值 x 值都保持不变。 

所有算术都适合标准整数类型。 坐标范围的大小最多为 1000，因此最大可能的边长为 2000，最大可能的面积为 4,000,000。

 ## 边缘情况

 考虑正方形：```
1
0 0
1 0
0 1
1 1
```x 值为`[0, 1, 0, 1]`。 该算法计算`max_x = 1`,`min_x = 0`，给出边长`1`。 面积为`1`。 这是可能的最小有效正方形，因为面积必须为正。 

考虑一个完全负坐标的正方形：```
1
-3 -3
-1 -3
-3 -1
-1 -1
```x 值为`[-3, -1, -3, -1]`。 边长变为`-1 - (-3) = 2`，面积为`4`。 减法会自动正确处理负值。 

考虑一个打乱的输入顺序：```
1
4 5
1 2
4 2
1 5
```这些点未在边界周围列出。 该算法忽略排序并仅使用极端 x 值。 它发现`max_x = 4`和`min_x = 1`，产生边长`3`和面积`9`。 

考虑允许的最大坐标分布：```
1
-1000 -1000
1000 -1000
-1000 1000
1000 1000
```边长为`1000 - (-1000) = 2000`，面积为`4,000,000`。 计算仍然是简单的整数减法和乘法，完全在限制范围内。
