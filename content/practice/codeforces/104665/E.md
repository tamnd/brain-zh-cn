 ## 解决方案
 ## 问题理解

 我们得到了偶数个排列，且长度都相同。 每个排列代表一个循环对象：我们可以将其旋转任意次数，这意味着我们可以选择其元素的任何循环移位。 当经过一定次数的旋转后，排列变成从 1 到 s 的排序序列时，就认为排列已解决。 

关键在于排列不是独立的。 我们必须将它们配对，并且在每一对中，两种排列总是同时经历相同的旋转。 应用于一个的轮换会自动应用于其伙伴。 对于每一对，我们可以选择如何旋转，但两个阵列一起移动。 

对于单个排列，解决它意味着存在将其转变为恒等排列的旋转。 这相当于说排列是恒等式的循环移位。 

对于一对，我们选择一个旋转计数，将其应用于两者，然后检查两者中的哪一个已排序。 目标是将排列配对，以使可解排列的总数最大化。 

约束很小：N 最多为 1000，每个排列的长度最多为 1000。如果每次比较都很昂贵，则这排除了任何对旋转的二次每对模拟以及所有对之间的重匹配。 然而，N 足够小，经过仔细预处理的 O(N^2) 构造是合理的。 

一种简单的方法是尝试所有配对并模拟每对是否可以解决 0、1 或 2 个排列。 这立即变成 N 的阶乘，即使 N = 20 也是不可行的。 

如果试图贪婪地配对单独看起来“易于修复”的排列而不考虑共享旋转兼容性，则会出现一种更微妙的故障模式。 两个排列可以单独求解，但在同一位移下不能同时求解。 

## 方法

 核心观察是旋转仅与循环等效有关。 对于每个排列，我们关心哪些移位将其转变为恒等排列。 由于身份是固定的，每个排列对应于一组“好移位”，即解决它的旋转。 

如果我们固定一个引用，假设我们将旋转 0 视为同一位置，那么对于每个排列，我们可以计算将其第一个元素（或任何锚点）对齐到 1 的唯一移位，并验证所有位置的一致性。 更稳健的是，我们计算使排列等于恒等的所有移位； 这是零或一个值，具体取决于排列是否是恒等循环移位。 

然而，由于所有排列都是 1..s 的任意排列，因此大多数排列根本无法单独求解。 排列在旋转下可解的唯一方法是它是否恰好是恒等数组的循环旋转。 这意味着它的形式必须是 [k, k+1, ..., s, 1, ..., k-1]。 

因此，每个排列要么贡献一个有效的旋转（单个移位值），要么不贡献任何一个。 

现在考虑一对。 假设两个排列分别具有有效的移位值 x 和 y。 如果我们将它们配对，我们选择单个旋转 r。 旋转 r 后，如果 r 等于 x 模 s，则置换 A 求解；如果 r 等于 y 模 s，则置换 B 求解。 所以：

 - 如果 x == y，则两者都已解决。 
- 否则，最多可以解决该对中的一个。 

这将问题减少到用有效移位值或无效（-1）标记的配对索引。 无效的无论配对如何都无法解决，因此它们的贡献为零。

因此，我们希望最大化两个元素共享相同移位值的对的数量。 每对都贡献 2 个已解出的密码。 如果我们将有效与无效配对，则其他所有内容每对最多贡献 1，但无效不能变为有效，因此这些对贡献 0 或 1，具体取决于解释。 由于无效排列永远无法解决，它们总是贡献 0，因此我们应该尽可能避免将它们与有效排列配对，但配对结构会强制完全匹配。 

最佳策略是按移位值分组。 对于每个移位值c，如果存在cnt[c]排列，我们可以形成floor(cnt[c]/2)对，每个对产生2个已解的值，贡献2*floor(cnt[c]/2)。 未配对的有效贡献为 0，因为他们的伙伴不能共享相同的班次。 

这变成了一个简单的计数问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力配对+模拟| O(N!) | O(N) | 太慢了|
 | 按轮班分组| O(N·s) | O(N) | 已接受 |

 ## 算法演练

 1、对于每个排列，判断其是否是恒等排列的循环旋转。 
2. 如果是，则计算其旋转偏移 r，即将其映射回排序顺序的移位。 
3. 计算产生每个有效 r 的排列数。 
4. 对于每个 r，将具有相同 r 的排列配对在一起。 
5. 每对贡献两个已解出的密码，因此添加 2 * (count[r] // 2)。 
6. 对所有r求和得到最终答案。 

### 为什么它有效

 每个排列最多有一个旋转来解决它，因为恒等排列在循环移位下是刚性的。 因此，每个可解的排列恰好属于由其所需移位定义的一个等价类。 当且仅当两个排列需要相同的移位时，才可以在单个共享旋转下同时求解两个排列。 因此，类内配对是最佳的，因为跨类配对不能增加可解元素的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    cnt = {}

    for _ in range(n):
        data = list(map(int, input().split()))
        s = data[0]
        p = data[1:]

        # find rotation that makes p sorted [1..s]
        pos1 = p.index(1)
        shift = (s - pos1) % s

        ok = True
        for i in range(s):
            if p[(pos1 + i) % s] != i + 1:
                ok = False
                break

        if ok:
            cnt[shift] = cnt.get(shift, 0) + 1

    ans = 0
    for v in cnt.values():
        ans += (v // 2) * 2

    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先通过锚定在 1 的位置并检查顺序一致性来识别每个排列是否是恒等式的循环移位。 变量`shift`对将排列与排序顺序对齐的旋转进行编码。 

我们只存储有效班次的数量。 无效排列将被忽略，因为无论配对如何，它们都无法解决。 

最后，我们在每个班次类别中累积对，为每对添加两个已解决的排列。 

一个微妙的实现细节是我们不尝试显式配对； 我们只计算频率。 这避免了对排序的任何依赖，并确保每个类的聚合时间为 O(1)。
