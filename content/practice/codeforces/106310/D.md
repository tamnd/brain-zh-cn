 ## 解决方案
 ## 问题理解

 游戏由三个机器人按固定顺序进行：吸尘器、水壶和扬声器。 他们一个接一个地叫出四位数字，但玩家可能必须尝试几个数字才能做出有效的移动。 该协议包含说出的每个数字，包括失败的尝试，并以`0`。 

如果一个数字有四个非零的不同数字，并且之前没有作为成功数字出现过，并且除了第一次成功移动之外，其第一位数字与上一个成功数字的最后一位数字相匹配，则该数字是有效的。 失败的尝试会给当前机器人扣分，同一个机器人会继续尝试，直到说出有效的数字。 在输入有效数字后，轮到下一个机器人。 

任务是计算每个机器人尝试了多少次以及受到了多少次处罚。 第一个值包括成功和不成功的尝试，因为每个说出的数字都是一次移动尝试。 

语句中没有明确限制输入大小，但协议可以包含许多行。 由于必须检查每一行，因此自然目标是对输入进行单次传递。 任何重复扫描整个历史记录中每个数字的解决方案都可能变成二次的，并且是不必要的。 线性模拟就足够了，因为规则仅取决于先前的成功号码和已使用的成功号码的集合。 

一些细节可能会破坏粗心的实施。 第一个说出的号码没有之前的号码限制。 例如：```
1234
2345
0
```第一个数字被接受，第二个数字也被接受，因为`2`跟随的结束数字`1234`。 在接受第一步之前需要先前的数字的解决方案会错误地拒绝`1234`。 

仅在成功移动时才禁止重复数字。 例如：```
1234
4567
4567
0
```前两个数字有效。 第三次尝试无效，因为`4567`已经成功使用，所以输出是：```
2 0
1 1
0 0
```如果先前的尝试失败，将每个说出的号码标记为已使用的解决方案也会错误地拒绝后来的有效号码。 

每行之后转弯并不总是改变。 例如：```
1234
5678
6789
0
```后`1234`和`5678`, 议长的尝试`6789`无效，因为之前的成功号码结尾为`8`，因此议长会受到惩罚并保持轮流直到出现有效数字。 

## 方法

 最直接的方法是模拟游戏。 对于每个说出的号码，检查它是否满足所有规则。 如果无效，则增加当前玩家的罚分，并保持该玩家不变。 如果有效，则增加玩家的成功移动计数，将数字添加到已使用的集合中，更新最后一位数字，然后切换到下一个玩家。 

这种直接模拟已经是最佳方法。 重要的观察结果是游戏状态非常小。 为了判断下一个号码是否有效，我们只需要最后一个成功号码的结束数字、之前成功号码的集合以及当前玩家的索引。 无需重建游戏历史或展望未来。 

总工作量与协议中的行数成正比。 对于哈希集，检查某个数字是否被使用需要平均恒定时间，因此整个解决方案是线性的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k²) | O(k) | 对于大型协议来说太慢 |
 | 模拟套装| O(k) | O(k) | 已接受 |

 ## 算法演练

 1. 读取所有数字直到终止零并按顺序处理它们。 当前玩家以吸尘器开始，由索引表示`0`。 
2. 对于每个说出的数字，首先假设它是无效的并检查每条规则。 该号码必须有四位数字，不包含零，没有重复的数字，不在已接受的数字集中，并且在存在先前的有效数字时与前一个结束数字匹配。 
3、如果号码无效，则对当前玩家加一罚分。 玩家指数不会改变，因为同一个机器人必须不断尝试。 
4. 如果该数字有效，则增加当前玩家的移动计数并将该数字添加到已使用的集合中。 更新最后一个成功号码的结束数字并使用循环顺序切换播放器。 
5. 协议结束后，打印吸尘器、水壶和扬声器存储的统计数据。 

模拟期间的不变性是，存储的状态准确地描述了真实游戏的位置：当前玩家是轮到的玩家，使用的集合仅包含成功的数字，并且保存的最后一位数字属于最后一次成功的移动。 因为每一条新线都是从这个状态来判断的，所以每一个决定都符合原来的规则。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    stats = [[0, 0] for _ in range(3)]
    used = set()

    player = 0
    last_digit = -1
    has_previous = False

    for line in sys.stdin:
        s = line.strip()
        if s == "0":
            break

        stats[player][0] += 1

        ok = True

        if len(s) != 4:
            ok = False
        else:
            if '0' in s:
                ok = False
            elif len(set(s)) != 4:
                ok = False

        if ok and s in used:
            ok = False

        if ok and has_previous and int(s[0]) != last_digit:
            ok = False

        if ok:
            used.add(s)
            last_digit = int(s[-1])
            has_previous = True
            player = (player + 1) % 3
        else:
            stats[player][1] += 1

    print(*stats[0])
    print(*stats[1])
    print(*stats[2])

if __name__ == "__main__":
    solve()
```数组`stats`为每个机器人存储两个值。 第一个值计算该机器人说出的每个数字，而第二个值仅计算失败的尝试。 当前玩家存储为索引`0`到`2`，这使得改变匝数成为一个简单的模运算。 

套装`used`仅包含成功的号码。 这很重要，因为失败的尝试不会消耗数字。 变量`has_previous`将第一个有效移动与所有后续移动分开，避免与不存在的先前数字进行错误比较。 

在更改任何状态之前执行验证检查。 有效的数字会更新已使用的集合和之前的结束数字，而无效的数​​字只会更改惩罚计数器。 此顺序可防止失败的尝试影响未来的移动。

 ## 边缘情况

 第一步很特别，因为之前没有成功的号码。 输入时：```
1234
2345
0
```该算法开始于`has_previous = False`，因此它会跳过第一个数字比较。`1234`被接受，前一个数字变为`4`， 和`2345`被接受是因为它开始于`2`。 

对于重复成功的号码：```
1234
4567
4567
0
```前两行输入`used`放。 当演讲者说`4567`，该数字在集合中找到，因此议长受到处罚并保持轮流。 议长未来的号码仍会正常检查。 

对于不应改变游戏状态的无效尝试：```
1234
5670
6789
0
```吸尘器成功播放`1234`。 水壶尝试`5670`，这是无效的，因为它包含零，因此水壶会受到惩罚。 下一个号码`6789`仍然被判断为水壶动作，并且因为它开始于`6`，就被接受了。 失败的尝试不会影响之前的数字或已使用的数字。
