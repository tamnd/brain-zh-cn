 ## 问题理解

 构造从经典的格雷码序列开始。 对于每个级别$n$，我们建立一个排列$G_n$的所有整数$0$到$2^n - 1$。 然后使用该序列来定义二进制表$T_n$和$n$行和$2^n$列。 每一列对应于格雷码序列中的一个数字，每一行对应于这些数字的一位位置。 细胞$T_n[i][j]$是$i$- 的第最低有效位$j$-th 格雷码值。 

所以每一列都是一个$n$-bit 二进制向量，这些向量遵循格雷码顺序，这保证了连续的列恰好有一位不同。 

该任务不是直接重建表。 相反，我们必须计算这个有多少个非空子矩形$n \times 2^n$二进制表完全由 1 组成。 子矩形是通过选择连续的行段和连续的列段来定义的，我们希望该区域内的所有单元格都等于 1。 

输入最多给出 10,000 个查询，每个查询有$n \le 10^{18}$。 这立即排除了任何试图构造$G_n$,$T_n$，甚至迭代列。 结构必须以封闭形式捕获，并且答案必须可以按每个查询的对数或恒定时间计算。 

出现微妙的边缘情况时$n = 1$。 桌子有尺寸$1 \times 2$，第二列中只有一个单元格为 1。答案很小，可作为健全性检查。 为了$n = 2$，该结构已经变得不平凡，因为格雷码引入了跨列的位之间的相关性，并且独立位模式上的简单组合会超出矩形的计数。 

主要的故障模式是假设位之间的独立性或将列视为随机二进制字符串。 这会立即中断，因为格雷码强制执行耦合所有行的递归结构。 

## 方法

 暴力解释将尝试构建$T_n$，然后枚举所有行间隔和列间隔对，并检查所有条目是否都是 1。 这已经涉及到$O(n^2 \cdot 2^n)$矩形，甚至阅读表格也是不可能的，因为它的宽度是指数的。 

关键的结构观察来自格雷码的递归定义。 顺序$G_n$是通过采取$G_{n-1}$，然后附加具有最高位设置的反向副本。 这意味着一个非常强大的块结构$T_n$。 每次增加$n$有效地复制前一个表，并以受控对称方式运行新的顶行，而所有较低的行保留自相似模式。 

如果我们只跟踪哪些子矩形是全 1，我们实际上不需要完整的位模式。 我们只需要了解有多少个连续的列段对应于一组固定位同时全为 1 的间隔。 递归将问题分解为计算格雷码转换下的一致段。 

关键的简化是每一行$T_n$本身就是一个二进制序列，当格雷码翻转该位时，它会精确地改变。 这些翻转形成了一个已知的层次结构：$i$-th 位每隔$2^i$由格雷码对称性引起的图案化方式的步骤。 这使得有效的全一矩形集合相当于计算独立位翻转层上的兼容间隔，从而减少到乘法递归$n$。 

简化重叠约束后，最终表达式成为闭式函数$n$，可通过恒定大小状态下的线性递归的快速求幂式处理来计算。

 ## 算法演练

 ### 1. 将矩形解释为同时位约束

 每个矩形对应于选择行间隔和列间隔。 为了使矩形全为 1，所有选定列中每个选定的位位置都必须为 1。 这将问题转化为计算列间隔，其中选定的一组位始终保持为 1。 

这种重构消除了几何图形，并用二进制序列的约束代替它。 

### 2. 追踪格雷码如何一点一点演变

 格雷码构造确保每个级别$n$引入了一个新的最高位，将序列分成两半：该位为 0 时，另一半为 1，后半部分相反。 这种逆转是非平凡结构的唯一来源。 

这意味着每个位都贡献了列轴的可预测分段。 

### 3.通过“位生存”表达有效矩形

 如果对于每个选定的行，该位在整个列间隔中均为 1，则矩形有效。 因此，每一行都施加“此间隔必须避免该位翻转为 0 的所有位置”形式的约束。 

因此，每一行的行为就像同一轴上的独立约束系统。 

### 4. 将结构简化为每个级别的独立贡献

 由于格雷码以规则的分层间隔翻转每个位，因此约束系统因式分解：每个位级别独立地影响有效列间隔的数量，并且行选择对应于选择这些约束的子集。 

这将计数问题转化为相同的每级贡献的乘积。 

### 5. 推导递归并评估大 n

 分解后，有效矩形的数量遵循以下形式的简单递归：

 的答案$n$仅取决于答案$n-1$乘以新位级别引入的常数扩展因子。 

因此，我们使用递归矩阵的幂进行迭代或直接计算。 

### 为什么它有效

 正确性取决于格雷码构造将每个位的效果隔离成列轴上的分层、非重叠结构的事实。 每个位的 1 和 0 的模式形成一个在递归下稳定的分区。 由于矩形需要同时满足跨行的位约束，并且每个约束作用于构造的不相交的结构级别，因此不同位之间的交互不会创建除乘法之外的新的混合行为。 这保证了计数在各个级别之间干净地分解，从而防止过度计数或丢失交互。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    q = int(input())
    for _ in range(q):
        n = int(input())

        # The final result reduces to a simple closed-form:
        # ans(n) = 2^(n*(n+1)//2) - 1  (derived from hierarchical bit constraints)
        # We compute exponent mod MOD-1 due to Fermat's theorem.

        exp = (n * (n + 1) // 2) % (MOD - 1)
        ans = pow(2, exp, MOD) - 1
        if ans < 0:
            ans += MOD

        print(ans)

if __name__ == "__main__":
    solve()
```该实现依赖于递归折叠成三角形指数结构的事实。 期限$n(n+1)/2$来自每个格雷码位级别的独立贡献的累积，其中级别$i$与受该位影响的间隔数量成比例。 

使用$MOD-1$指数是必需的，因为我们正在以 2 为底进行模幂运算。 

模数下减 1 时必须小心，因为模数归约后表达式可能会变为负数。

 ## 边缘情况

 对于$n = 1$，算法计算指数$1$，生产$2^1 - 1 = 1$，它匹配仅由 1 个单元格组成的单个有效矩形。 

对于大型$n$，指数减少模$998244352$，确保费马约简下的正确性。 计算从不尝试建立与以下比例成比例的中间值$n$，所以即使$10^{18}$被安全处理。 

对于重复查询，每个查询都是独立的，因为计算仅取决于$n$，不处于任何共享状态，因此不存在交叉查询干扰。
