 ## 问题理解

 我们在一个序列中恰好有四个整数，每个整数都在 1 到 1000 之间。目标是确定该序列是否形成算术级数或几何级数。 如果是这样，我们必须计算级数的下一个元素。 如果序列不符合任一模式，或者下一个数字不是整数，则返回 42。 

算术级数由连续项之间的恒定差定义。 对于四个元素$a_1, a_2, a_3, a_4$, 差异$a_2-a_1$,$a_3-a_2$， 和$a_4-a_3$必须人人平等。 几何级数由连续项之间的恒定比率定义。 对于非零元素$b_1, b_2, b_3, b_4$，比率$b_2/b_1$,$b_3/b_2$， 和$b_4/b_3$必须全部相等，且比率不能为 0 或 1。 

约束很小：恰好是四个数字，每个数字都以 1 和 1000 为界。这意味着任何通过少量算术运算检查差异或比率的算法都将立即运行。 微妙之处在于边缘情况，尤其是当比率不是整数、序列包含重复数字或简单除法引入浮点错误时。 

一些不明显的边缘情况包括像 [2, 2, 2, 2] 这样的序列，它既是算术又是几何的，算术差为负的序列，像 [1, 2, 4, 8] 这样的具有整数比的几何序列，以及像 [1, 3, 9, 28] 这样的序列，两者都不匹配。 此外，像 [1, 2, 4, 8] 这样的序列将生成下一个元素 16，但是像 [1, 2, 4, 9] 这样的序列应该返回 42，因为比率 9/4 不等于之前的比率。 

## 方法

 蛮力方法很简单：计算算术的连续差和几何的连续比率。 检查所有差值是否相等或所有比率是否相等。 如果成立，则计算下一个元素。 如果两者都失败，则返回 42。这对于四个元素来说在恒定时间内有效。 

幼稚的实现必须小心地处理整数运算。 对于几何级数，除法必须精确。 使用浮点除法是有风险的，因为 Python 中的 3/2 是 1.5，并且等式检查可能会因舍入而失败。 在比较之前我们必须检查每个除法是否产生一个整数
