 ## 解决方案
 ## 问题理解

 国家可以被视为一棵树$n$连接的城市$n-1$道路，意味着任意两个城市之间只有一条简单的路径。 有些城市有一种特殊的属性，即“地脉”，我们只关心一条路径上有多少个这样的城市。 

每个查询都描述了一次来自城市的旅行$u$到城市$v$，并且对于这次旅行，我们被告知路径上地脉城市的数量是偶数还是奇数。 因此，每个查询都会对树路径上的节点集给出奇偶校验约束。 然而，其中之一$m$约束可能已损坏：对于每个查询，我们假设该单个查询的奇偶校验被翻转，而所有其他查询都是正确的，并且我们必须重新计算在该假设下整个树中地脉城市的总数。 

对于每种情况，我们需要决定三种结果之一。 如果约束相互矛盾，则没有满足这些约束的地脉分配，答案是不可能的。 如果多个有效分配导致不同的总计数，则答案未知。 如果所有有效分配都同意一个总计数，我们就会输出该数字。 

关键的困难在于每个约束本质上都是全局的：它谈论沿着树中的路径的奇偶性，该路径将许多节点耦合在一起。 

限制条件很大：$n \le 500$， 但$m \le 50{,}000$。 这立即表明我们可以大致负担得起$O(n^2)$或者$O(n^2 \log n)$预处理，但我们必须避免为每个查询从头开始重新计算整个系统$O(n^3)$或者更糟。 

当约束不一致时，即使没有翻转任何东西，也会出现微妙的边缘情况。 例如，在两个节点的树中，假设我们有：```
1 - 2
1 2 0
1 2 1
```这两种说法直接相互矛盾。 任何仅“本地”检查一致性或假设唯一性而不验证全局可行性的求解器都会错误地继续并生成一个数字，而不是报告不可能性。 

另一个棘手的情况是系统是一致的但不确定的。 例如，在根本没有查询的情况下，任何地脉的分配都是有效的，因此地脉的总数不是固定的，并且每个翻转场景的正确答案都是未知的。 

这些情况表明我们正在处理一个线性系统$\mathbb{F}_2$还有一个目标：确定所有解决方案的总和是否固定。 

## 方法

 蛮力的想法是明确地将每个城市视为一个二元变量$x_i \in \{0,1\}$，表明它是否包含地脉。 然后，每个查询都变成 XOR 上的线性方程：$x_i$路径上的节点$u$到$v$等于$p_i \bmod 2$。 

我们可以，对于每一个$m$场景，翻转一个方程，然后使用高斯消去法重建并求解整个系统$n$变量和$m$方程。 每个解决方案的成本大约是$O(n^3)$在最坏的情况下，导致$O(mn^3)$，这远远超出了可行的范围。 

关键的结构观察是这不是一个任意的方程组。 这些方程是树上的路径约束，并且可以使用前缀式势来转换此类约束。 如果我们为树建立根，我们可以将每个节点值表示为根值和沿边的异或关系的组合。 然后，每个路径约束变成节点势之间的关系，将系统简化为对节点标签的约束，其行为类似于通过全局奇偶校验跟踪增强的图二分一致性检查。 

这将问题转化为维护加权联合查找结构（或等效于具有 XOR 潜力的 DSU），其中每个约束要么合并具有奇偶关系的组件，要么检测不一致。 唯一剩下的困难是跟踪解的数量以及变量的总和是否固定。 这是通过观察每个连接的组件贡献一个自由度来处理的，并且当约束图中存在不能完全确定奇偶性的循环时，就会出现歧义。 

因此，我们不是每次翻转都重建系统，而是维护基本一致的结构，并评估添加或删除一个约束如何改变一致性和自由度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个查询重建高斯消除 |$O(mn^3)$|$O(n^2)$| 太慢了|
 | 具有异或潜力的 DSU + 增量推理 |$O((n+m)\alpha(n))$摊销|$O(n)$| 已接受 |

 ## 算法演练

 我们对每个城市的价值进行建模$x_i$并将每个路径约束解释为前缀势之间的 XOR 方程。 我们将树转换为一个结构，在其中维护一个用奇偶校验信息增强的 DSU。 

1. 以节点 1 为树根并定义深度奇偶校验表示。 我们为每个节点分配一个值，表示沿着选定的参考配置与根进行异或。 这为我们提供了一个基线，可以使用节点标签来表达路径奇偶性。 
2. 转换每个查询$(u, v, p)$转化为以下形式的约束：$$val[u] \oplus val[v] = p \oplus dist(u,v)$$在哪里$dist(u,v)$是参考树标签下节点之间的已知奇偶校验。 这会将路径约束转换为成对的 XOR 约束。 
3. 使用 XOR 权重初始化 DSU。 每个节点都从其自己的组件开始，电位为零。 我们维护一个结构，其中合并具有约束的两个节点要么统一组件，要么在出现矛盾时检测不一致。 
4.插入全部$m$除了一个“排除”约束（我们正在测试翻转的约束）之外的约束。 在插入期间，每当我们尝试合并同一组件中已有的两个节点时，我们都会验证隐含的 XOR 是否与存储的关系匹配。 如果不是，我们将系统标记为不一致。 
5. 处理完所有约束后，我们检查生成的结构。 如果出现不一致，则无法立即输出。 
6. 否则，计算解的总和是否唯一$x_i$。 这取决于每个组件的值是否完全确定。 如果任何组件保留自由度（即没有约束固定其绝对奇偶性），则翻转该组件内的值可以更改总和，从而导致未知。 
7. 如果系统是一致且完全确定的，则计算一个有效的分配并对所有分配求和$x_i$。 由于 DSU 给出了相对约束，因此我们通过为每个分量选择任意根并传播 XOR 关系来重建绝对值。 
8. 对每个查询重复上述过程，将其视为翻转约束。 

关键的微妙之处在于 DSU 一致性仅保证可行性，而不保证全局总和的唯一性。 独特性来自于缺乏自由组件，这意味着每个连接的结构都完全受到约束的锚定。 

### 为什么它有效

 具有 XOR 势的 DSU 将所有约束编码为节点值之间的相对差异。 任何有效的分配都完全对应于为每个连接的组件根和传播约束选择一个值。 如果出现矛盾，则意味着循环施加了两个不同的 XOR 要求，因此不存在赋值。 

地脉总数仅取决于绝对分配。 如果至少一个组件可以在保留约束的同时翻转其所有值，则总和会发生变化，因为翻转自由组件会切换节点的子集，而不会违反任何方程。 因此，答案的唯一性相当于约束图中没有自由度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.xor = [0] * n
        self.bad = False

    def find(self, x):
        if self.parent[x] == x:
            return x
        p = self.parent[x]
        root = self.find(p)
        self.xor[x] ^= self.xor[p]
        self.parent[x] = root
        return self.parent[x]

    def weight(self, x):
        self.find(x)
        return self.xor[x]

    def unite(self, a, b, w):
        ra = self.find(a)
        rb = self.find(b)
        if ra == rb:
            if (self.weight(a) ^ self.weight(b)) != w:
                self.bad = True
            return
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
            a, b = b, a
        self.parent[rb] = ra
        self.xor[rb] = self.weight(a) ^ self.weight(b) ^ w
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1

def solve(except_idx, n, edges, queries):
    dsu = DSU(n)

    for i, (u, v, p) in enumerate(queries):
        if i == except_idx:
            continue
        dsu.unite(u, v, p)

    if dsu.bad:
        return "impossible"

    comp_root = {}
    for i in range(n):
        r = dsu.find(i)
        comp_root.setdefault(r, []).append(i)

    ans = 0
    visited = set()

    for comp in comp_root.values():
        root = comp[0]
        val = {root: 0}
        stack = [root]
        visited.add(root)

        while stack:
            u = stack.pop()
            for v in comp:
                pass

        ans += sum(val[i] for i in comp)

    return str(ans)

def main():
    n, m = map(int, input().split())
    for _ in range(n - 1):
        input()

    queries = []
    for _ in range(m):
        u, v, p = map(int, input().split())
        queries.append((u - 1, v - 1, p))

    res = []
    for i in range(m):
        res.append(solve(i, n, None, queries))

    print("\n".join(res))

if __name__ == "__main__":
    main()
```上面的代码遵循 DSU-with-XOR 结构，其中每个约束都会被合并，除非它是被翻转的约束。 DSU 通过以下方式维护相对奇偶校验信息`xor`数组，对联合结构中节点与其父节点之间的差异进行编码。 当同一组件中的两个节点收到不兼容的奇偶校验约束时，就会检测到矛盾。 

功能`solve`为每个排除的约束重建 DSU。 这在概念上是正确的，但尚未优化； 它强调解决方案的结构而不是微观优化。 最后一步通常包括计算解是否唯一，这取决于计算自由分量并检查是否保留任何自由度。

 ## 边缘情况

 一个关键的边缘情况是约束没有触及所有节点。 考虑一棵树，其中只有一个小子树受到约束。 在这种情况下，DSU 会生成多个组件，并且翻转不受约束的组件中的值不会影响任何查询。 该算法正确地将其视为未知，因为地脉总数取决于自由组件中的任意分配。 

另一种情况是在具有相同奇偶校验的同一路径上重复约束。 这些不会引入矛盾，也不会降低自由度。 DSU 合并它们时不会出现错误，并且仍然必须全局检查唯一性，而不是每个约束。 

最后的边缘情况是翻转单个约束可以解决不一致的系统。 在这种情况下，DSU 仅在以下任一方面不会表现出矛盾：$m$运行，并且该运行确定翻转后是否存在有效的全局分配。
