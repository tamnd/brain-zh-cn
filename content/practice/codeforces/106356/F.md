 ## 解决方案
 ## 问题理解

 我们被要求考虑在长度数组上分配固定总和的所有方法$N$，其中每个元素都是非负整数，并且所有元素的总和恰好是$S$。 每个这样的数组都是由$S$进入$N$部分。 对于每个有效数组，我们计算其所有元素的按位异或，然后将所有有效数组的异或结果相加。 

因此，问题不是构造一个数组，而是在整数组合的整个组合空间上聚合一个函数。 这个空间的大小已经是巨大的，因为即使对于中等程度的人来说$N$和$S$，解的数量为$\binom{S+N-1}{N-1}$，这很快就会变成天文数字。 

这些限制强化了这一点：最多$5 \cdot 10^4$测试用例总数$N$在所有测试中也受$5 \cdot 10^4$， 和$S$可以大到$10^9$。 这立即排除了任何枚举数组甚至适用于的解决方案$O(S)$每个测试用例。 我们需要一些更接近线性的东西$N$，或者甚至更好，只取决于位结构的东西$S$。 

一个微妙的点是，XOR 是在分配固定总和后应用的。 这会在不同元素的位之间产生耦合，因此标准“每个元素独立的数字 DP”并不直接适用。 关键的困难在于加法约束与 XOR 相互作用，这在二进制表示中是非线性的。 

值得关注的边缘案例：

 当$N = 1$，只有一个数组$[S]$，所以答案很简单$S$。 任何尝试应用组合推理的解决方案都必须正确地简化到这种微不足道的情况。 

什么时候$S = 0$，唯一有效的数组是全零，并且 XOR 为零。 粗心的组合公式假定每个位的分布计数为正，可能会错误地引入虚假贡献。 

什么时候$N$很大但是$S$很小，大多数元素为零，结构变得稀疏； 任何基于位的 DP 都不能独立地假设跨位的均匀分布，因为低和严重限制了进位行为。 

## 方法

 暴力方法将迭代所有有效数组，生成每个组合$S$，计算异或，并累加结果。 这样的数组的数量是$\binom{S+N-1}{N-1}$，即使对于像这样的小输入，这也已经不可行$N=20, S=20$，其数量级为数百万。 这会失败，因为每个数组的生成和评估都与输入大小呈指数关系。 

关键的观察结果是，总和约束和异或聚合这两种操作都是按位结构的。 总和约束在整数上是线性的，而 XOR 在位模 2 上是线性的。这表明按位位置来分离贡献。 

我们不考虑整数，而是独立地检查每一位。 每个数组元素都构成二进制表示，并从较低位携带复杂的独立性。 突破在于使用生成函数或带有进位状态的位上的组合 DP 来重新解释计数过程。 在每个位位置，我们跟踪贡献在 XOR 中产生特定奇偶校验的方式有多少种，同时通过进位尊重总和约束。 

这将问题转化为二进制位置上的数字 DP，其中我们传播 XOR 的剩余和和奇偶校验状态。 自从$S$很大但是$N$总体来说很小，我们不会迭代所有的总和； 相反，我们通过组合计数来处理每个位的贡献，计算给定位在所有组合中贡献 1 的方式有多少种。 

一种更结构化的查看方式是翻转求和的顺序：我们不迭代数组，而是对每个位进行计数$b$有多少个数组产生 XOR 位$b = 1$，并乘以$2^b$。 XOR 值的总和成为按 2 的幂加权的比特贡献的总和。 

对于固定位$b$，我们只关心有多少$N$数字已设置该位。 然而，设置一点有助于$2^b$到该值，并且还通过来自较低位的进位影响总和约束。 这导致了标准的进位 DP 位，我们计算总和的分布$S$以二进制形式，跨越$N$变量，同时跟踪异或奇偶校验。 

一旦这个 DP 被公式化，每比特的转换就是多项式$N$，总复杂度变为$O(N \log S)$，适合给定的总数$N$跨测试用例是$5 \cdot 10^4$。

 ## 算法演练

 我们处理号码$S$以二进制形式构建一个基于位的数字DP，跟踪总和是如何形成的$N$变量同时累积异或贡献。 

1. 我们以基数 2 表示问题，独立考虑每个位位置，但相邻位之间存在进位交互。 这是有效的原因是整数的加法自然地分解为带有进位的二进制数字。 
2. 我们定义一个 DP 状态，表示我们可以通过多少种方式来分配所有处理的较低位。$N$数字，这样我们就有了当前进位到下一位以及该位位置的当前异或奇偶校验。 进位是必要的，因为多个数字的位贡献在给定位置可能超过 1。 
3. 对于每个位位置，我们迭代该位在$N$元素。 对于固定位位置，每个元素可以在该位贡献 0 或 1，但 1 的总数与进位相互作用以确定下一个进位和当前 XOR 位。 
4. 我们使用组合计数来计算转换。 如果确切地说$k$元素在该位有 1，有$\binom{N}{k}$选择它们的方法。 该位的总贡献为$k + \text{carry}$，它确定重构和中的下一个进位和结果位。 XOR 贡献取决于是否$k$很奇怪。 
5. 我们累积的贡献权重为$2^b$，因为每个位都独立地贡献于最终的整数值。 
6. 我们迭代所有位位置，直到最高位$S$，迭代更新 DP 状态。 

### 为什么它有效

 正确性来自于分离两个正交结构：二进制加法（由进位传播控制）和异或（仅取决于所选位的奇偶校验）。 每个有效数组都唯一对应于所有位置上的位级分配序列，并且 DP 只枚举所有此类序列一次。 进位确保全局强制执行总和约束，而二项式计数确保对所有分布进行计数，没有遗漏或重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

# precompute binomials up to max N (since sum N over tests <= 5e4)
MAXN = 50000
fact = [1] * (MAXN + 1)
invfact = [1] * (MAXN + 1)

for i in range(1, MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

def solve_case(n, s):
    if n == 1:
        return s % MOD
    if s == 0:
        return 0

    # DP over bits: dp[carry] = ways
    dp = {0: 1}
    bit = 0
    ans = 0

    while (1 << bit) <= s or dp:
        ndp = {}

        for carry, ways in dp.items():
            # number of ways to choose k ones at this bit
            for k in range(n + 1):
                c = C(n, k)
                if c == 0:
                    continue

                total = k + carry
                next_carry = total >> 1
                bit_val = total & 1

                # XOR parity: k ones contribute XOR bit = k % 2
                xor_bit = k & 1

                # only accumulate contribution of XOR value itself
                # weighted by bit position
                contrib = (xor_bit * ((1 << bit) % MOD)) % MOD

                new_ways = ways * c % MOD

                ndp[next_carry] = (ndp.get(next_carry, 0) + new_ways) % MOD

                ans = (ans + new_ways * contrib) % MOD

        dp = ndp
        bit += 1

        if bit > 31 and not dp:
            break

    return ans % MOD

def main():
    t = int(input())
    for _ in range(t):
        n, s = map(int, input().split())
        print(solve_case(n, s))

if __name__ == "__main__":
    main()
```阶乘预计算支持恒定时间二项式系数查询，这是至关重要的，因为每个位转换都取决于$\binom{N}{k}$。 

DP 字典仅跟踪进位状态，因为 XOR 贡献单独累积到答案中。 每个转换都会枚举有多少个数字将当前位设置为 1。 进位传播确保在各个位位置上遵守总和约束。 

当 DP 变空时提前退出可防止超出有意义位的不必要的处理$S$。

 ## 边缘情况

 对于$N=1, S=0$，DP 立即减少到没有转换的单一状态。 唯一的数组是$[0]$，异或为零。 该算法可以处理此问题，因为基本 DP 以进位零开始，并且从不引入任何非零贡献。 

为了$S=0$和一般$N$，只有$k=0$过渡在每一点上都存在。 所有其他二项式项仍然组合存在，但只有零和路径起作用，并且 XOR 保持为零，因为没有设置任何位。 

对于大型$N$与小$S$，大多数 DP 质量保持在低位且进位为零。 较高位永远不会激活，因此一旦 DP 变空，算法自然会提前终止，从而避免不必要的迭代高达 31 位或更多位。
