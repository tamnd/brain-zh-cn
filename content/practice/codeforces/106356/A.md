 ## 解决方案
 ## 问题理解

 我们得到一个一维的房间走廊，编号从 1 到 n。 粒子从固定的室 i 开始。 从任何房间，它都可以尝试向左或向右移动恰好 a 步或恰好 b 步。 每个移动只有在落在走廊内时才会成功，否则会被忽略并且粒子保持在原位。 

随着时间的推移，粒子可以执行任何有效的移动序列，混合两个步长和两个方向。 问题不是逐步模拟运动，而是确定从起始位置可以到达哪些房间。 最终的输出是 [1, n] 中根本无法到达的房间的数量。 

n 最大为 10^9 的约束立即排除了对位置的任何模拟。 所有房间的 BFS 或 DP 都是不可能的，因为即使存储访问过的状态也会超出内存。 由于最多可以有 10^5 个测试用例，因此每个测试必须在常数或对数时间内解决。 

当仅考虑本地可达性时，会出现微妙的失败案例。 例如，如果 n = 10、i = 5、a = 4、b = 6，人们可能会错误地认为粒子只能到达附近的几个位置，因为跳跃很大。 实际上，组合移动会创建一个可到达位置的网格，并且一些相距较远的房间仍然可以通过线性组合到达。 

当其中一个步长以另一个步长为模为零或当 a 和 b 共享大 gcd 时，会出现另一种边缘情况。 例如，如果 a = 2 且 b = 4，则实际上只能进行偶数偏移，并且即使两个移动单独看来都很灵活，一半的走廊也变得无法到达。 

核心困难是认识到可达集是由算术结构而不是图探索控制的。 

## 方法

 如果我们尝试直接解决这个问题，我们会将每个室视为图中的一个节点，并将其连接到±a和±b可到达的位置。 然后我们将从 i 开始运行 BFS 或 DFS。 这可以正确计算可达性，但在最坏的情况下，走廊的大小为 10^9，因此即使探索一小部分节点也是不可行的。 该图是隐式的，但仍然具有巨大的状态空间。 

关键的观察结果是，每次移动都以+a、-a、+b 或-b 的方式改变位置。 这意味着任何可到达位置与起始位置 i 的差值是 a 和 b 的整数线性组合。 换句话说，如果我们让 x 可达，那么对于整数 k1 和 k2，x - i 必须可表示为 k1·a + k2·b。 

经典数论结果告诉我们，a 和 b 的所有整数组合恰好形成 gcd(a, b) 的倍数。 因此可到达的位置形成一个等差级数：

 i + t·g，其中 g = gcd(a, b)，只要位置保持在 [1, n] 范围内。 

因此，问题简化为计算 [1, n] 中有多少个整数位于与 i 模 g 相同的残差类中。 一旦我们知道了这个集合，其他的事情就很简单了。 

蛮力会失败，因为它明确地探索状态，而最优解决方案将整个运动系统压缩为单个不变量：gcd 控制连接性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解 BFS/DFS | 每次测试 O(n) | O(n) | 太慢了|
 | GCD算术推理| 每次测试 O(log min(a,b)) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 计算 g = gcd(a, b)。 该值表示通过以任意顺序组合两个移动可以生成的最小步长。 任何可达到的位移必须是 g 的倍数。 
2. 确定起始位置模 g 的残基类别。 每个可到达的位置都必须满足 x == i (mod g)，因此我们将走廊限制为一个算术级数。 
3. 计算 [1, n] 中有多少个数字满足此同余。 第一个有效位置是最小的 x ≥ 1，使得 x == i (mod g)，然后每 g 步出现另一个有效位置。 
4. 使用简单算术计算此计数：找到 [1, n] 中的第一个有效位置 f，然后计算 n 内有多少个 f + k·g 形式的项。 
5. 答案是不可到达房间的数量，即 n 减去可到达计数。 

步骤 3 起作用的原因是，可达集在同余类中不是任意的，它在边界内完全填充它。 一旦剩余类别中的一个位置可以到达，只要我们留在走廊内，该类别中的所有其他位置都可以到达。 

### 为什么它有效

 运动系统精确地生成由 a 和 b 生成的整数的加法子群。 该子群是 g·Z，其中 g = gcd(a, b)。 因此，可到达位置之间的所有差异的集合是固定的并且独立于路径结构。 这将问题转化为计算与有界区间相交的一维算术级数中的格点。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    q = int(input())
    out = []
    for _ in range(q):
        n, i, a, b = map(int, input().split())
        
        g = math.gcd(a, b)
        
        # first reachable position >= 1 in the same residue class
        # as i modulo g
        r = i % g
        
        # find first x in [1, n] such that x % g == r
        first = r if r != 0 else g
        
        if first < 1:
            first += g
        
        if first > n:
            out.append(str(0))
            continue
        
        reachable = (n - first) // g + 1
        unreachable = n - reachable
        out.append(str(unreachable))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```代码首先计算两个步长的gcd，这完全确定了可达残基类结构。 变量 r 捕获起始位置的同余类。 然后，我们构建走廊内与该残基类别匹配的第一个有效位置。 

一旦知道了起点，计算可到达的位置就是一个简单的算术级数计数。 除法 (n - first) // g 计算在 n 之前适合多少次大小为 g 的完整跳转。 

当 i 能被 g 整除时，在处理模算术时需要小心。 在这种情况下，r 变为零，但有效残基类别对应于 g，而不是 1 索引系统中的 0。 这就是代码将 r == 0 映射到 g 的原因。 

## 工作示例

 ### 示例 1

 输入：

 n = 9，i = 3，a = 3，b = 6

 这里 g = gcd(3, 6) = 3。可达集必须保持在与 3 mod 3 全等的位置，这意味着所有位置。 所以每个房间都是可以到达的。 

| 步骤| 价值|
 | --- | --- |
 | 克| 3 |
 | 残留物 | 0（视为 3）|
 | 第一| 3 |
 | 可达 | (9 - 3)//3 + 1 = 3 |
 | 无法到达 | 9 - 3 = 6 | 9 - 3 = 6

 这表明，尽管跳跃看起来有限制性，但 gcd 将结构折叠成完整的算术级数。 

### 示例 2

 输入：

 n = 15，i = 10，a = 1，b = 17

 这里 g = 1，所以每个整数在界限内都是可达的。 

| 步骤| 价值|
 | --- | --- |
 | 克| 1 |
 | 残留物 | 0（视为 1）|
 | 第一| 1 |
 | 可达 | 15 | 15
 | 无法到达 | 0 |

 这表明，无论其他跳跃如何，步长大小为 1 都会立即使整个走廊可达。

 ## 边缘情况

 当 n = 1 时，算法正确返回零个不可到达的室，因为无论移动规则如何，单个位置始终可以从自身到达。 

对于 a 和 b 共享较大 gcd 的情况，例如 a = 100、b = 150，可到达位置以 50 为步长跳跃。如果 n = 200 且 i = 10，则范围中的第一个可到达位置可能是 10 或移动 50 的倍数，并且算法正确地与残基类对齐，并且仅计算边界内的有效倍数。 

当 i 小于 g 或 i == 0 mod g 时，将残差零映射到 g 的归一化步骤确保我们仍然在走廊中选择有效的代表。 这可以防止差一错误，否则残差类算术会建议位置 0，而该位置在域中不存在。
