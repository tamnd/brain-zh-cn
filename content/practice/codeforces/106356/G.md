 ## 解决方案
 ## 问题理解

 我们有一个生成整数序列的系统，其中每个整数代表一个编码为位掩码的基因组。 每个位指示是否存在特定的遗传标记。 

进化规则是确定性的。 前两个基因组固定为$a$和$b$。 之后，每个新基因组都是从前两个基因组构建而来，只保留两者中出现的遗传标记，这正是按位与运算。 

所以顺序是：$g_1 = a$,$g_2 = b$，并且对于$t \ge 3$,$g_t = g_{t-1} \,\&\, g_{t-2}$。 

对于每个查询，我们必须计算$g_t$对于可能非常大的$t$, 直至$10^8$，并且最多可以有$10^5$独立实验。 

约束的关键含义是我们无法逐步模拟序列。 每个查询的简单重复模拟将是线性的$t$，这立即是不可行的。 即使每个测试用例，存储或迭代最多$10^8$步骤在时间和记忆上都是不可能的。 

出现微妙的边缘情况时$t = 1$或者$t = 2$，其中递归不适用。 另一个重要的情况是当$a$或者$b$为零，因为 AND 运算会快速折叠位并可能产生立即变为零并保持为零的序列。 

## 方法

 蛮力解释很简单：我们模拟递归直到达到时间$t$。 每个步骤都会计算前两个值的按位与，这是一个$O(1)$对 32 位整数的操作。 然而，自从$t$可以大到$10^8$，这导致$O(t)$每个查询，并且在最坏的情况下$10^5$查询最多需要$10^{13}$操作，这远远超出了任何可行的限制。 

关键的观察结果是，按位与在很强的意义上是单调的：一旦一个位在最后两个状态中的任何一个状态下变为零，它就永远不会重新出现。 每个位独立演化，对于每个位位置，我们有效地在两个初始位上运行相同的递归$a_i, b_i \in \{0,1\}$。 

因此，我们不考虑整数，而是分析单个位的位置。 对于每一位，我们得到一个由前两位的 AND 定义的二进制序列。 只有四种可能的初始配置$(a_i, b_i)$，并且每个都会导致非常短的瞬态：

 如果两者均为 1，则所有未来项仍为 1。如果其中一项为 0，则序列在第一个 AND 步骤处或之后立即折叠为 0，并永远保持为 0。 更准确地说，在时间 3 我们计算$a_i \& b_i$，之后一切都保持不变，因为相同值的重复 AND 是稳定的。 

这意味着对于每个独立的位，序列稳定在$g_3 = a \& b$，并且对于所有$t \ge 3$，该值是恒定的。 因此，整个问题简化为一个观察结果：在第三项之后，序列不再改变。

 ## 算法演练

 1. 阅读$a$,$b$， 和$t$对于每个查询。 这些定义了初始的两个状态和我们必须评估的时间索引。 
2.如果$t = 1$， 返回$a$直接因为序列定义固定了第一项而无需计算。 
3.如果$t = 2$， 返回$b$直接因为同样的原因。 
4.对于任何$t \ge 3$, 计算$a \& b$。 这对应于定义中时间步骤 3 形成的基因组。 
5. 为所有返回该值$t \ge 3$，因为进一步的进化不会改变结果。 

为什么它有效：

 递归仅使用按位 AND，它是幂等且关联的。 一旦我们计算出$g_3 = a \& b$，下一步就变成了$g_4 = g_3 \& g_2$。 但$g_2 = b$， 和$g_3 = a \& b$， 所以$g_4 = (a \& b) \& b = a \& b$。 相似地，$g_5 = g_4 \& g_3 = (a \& b) \& (a \& b) = a \& b$。 所以序列立即锁定在一个固定点$t = 3$，之后保持不变。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    for _ in range(T):
        a, b, t = map(int, input().split())
        if t == 1:
            out.append(str(a))
        elif t == 2:
            out.append(str(b))
        else:
            out.append(str(a & b))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案直接对稳定性特性进行编码。 唯一的分支已开启$t$，将两个基本情况与稳定状态分开。 的计算$a \& b$是常数时间，依赖于 Python 的原生整数按位运算。

 ## 边缘情况

 当两者$a$和$b$为零，每一步都为零。 算法返回$a$为了$t=1$,$b$为了$t=2$， 和$a \& b = 0$为所有人$t \ge 3$，完全匹配常数零演化。 

什么时候$a = b$，序列应保持该值不变。 为了$t \ge 3$，我们计算$a \& a = a$，因此所有步骤的输出都是一致的。 

什么时候$t = 1$或者$t = 2$，任何计算都不应干扰重现。 该算法显式返回初始值，避免了 AND 规则的错误过早应用。 

当位完全不同时，例如$a = 8$和$b = 4$，第三项变为零并保持为零。 算法正确输出$a \& b = 0$为所有人$t \ge 3$，匹配所有共享遗传标记的立即丢失。
