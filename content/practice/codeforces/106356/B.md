 ## 解决方案
 ## 问题理解

 我们有几个素数。 对于每个素数$p$，我们可以在其十进制表示形式前面放置一位或多位十进制数字。 结果数字是所选前缀和的串联$p$。 

我们的目标是生成一个前缀，使结果数字复合，同时使用尽可能少的前缀数字。 如果最小长度的多个前缀有效，则其中任何一个都是可以接受的。 

关键的观察来自于约束$p$。 每个输入数字都是 10 到 10 之间的素数$10^8$， 所以$p$永远不等于 2、3 或 5。特别是，$p \bmod 3$总是 1 或 2。 

粗心的方法可能会尝试许多前缀并测试结果数字的素数。 这对于小输入是有效的，但它完全忽略了问题的结构。 

考虑$p = 11$。 

如果我们在前面加上数字 1，我们会得到 111。$111 = 3 \times 37$，结果是复合的。 

答案仅使用一位前置数字，因此它已经是最佳的。 

另一个例子是$p = 13$。 

前面加上 2 得到 213，并且$213 = 3 \times 71$。 

同样，一位数字就足够了。 

最重要的边缘情况是认识到不允许使用零前置数字。 即使原始数字是素数，我们也必须在前面添加至少一位数字。 因此，最小可能的答案长度是 1，而不是 0。 

## 方法

 暴力解决方案将尝试所有一位数前缀，然后尝试所有两位数前缀，依此类推，直到找到合数。 对于每个候选者，它将构建串联数字并运行素性测试。 

这是有效的，因为最终某些前缀必须产生一个合数。 问题是素性测试会重复多次，最多可达$10^5$测试用例。 尽管结果数字不是很大，但没有必要进行重复的素性检查。 

关键的观察是我们实际上不需要搜索。 

让$k$是 的位数$p$。 如果我们在前面添加一个数字$d$，新的数字是$$N = d \cdot 10^k + p.$$自从$10 \equiv 1 \pmod 3$,$$10^k \equiv 1 \pmod 3.$$因此$$N \equiv d + p \pmod 3.$$因为$p$是大于3的素数，$p \bmod 3$是 1 或 2。 

如果$p \bmod 3 = 1$， 选择$d = 2$。 

然后$$N \equiv 2 + 1 \equiv 0 \pmod 3.$$如果$p \bmod 3 = 2$， 选择$d = 1$。 

然后$$N \equiv 1 + 2 \equiv 0 \pmod 3.$$所得数可被 3 整除且大于 3，因此一定是合数。 

由于单个数字始终有效，因此前置数字的最小可能数量始终为 1。

 ## 算法演练

 1. 读取素数$p$。 
2. 计算$p \bmod 3$。 
3.如果$p \bmod 3 = 1$,输出数字`2`。 

连接后的数字可以被 3 整除，因为$2 + 1 \equiv 0 \pmod 3$。 
4. 否则，$p \bmod 3 = 2$，所以输出数字`1`。 

连接后的数字可以被 3 整除，因为$1 + 2 \equiv 0 \pmod 3$。 

### 为什么它有效

 让$k$是 的位数$p$。 加上前缀数字后$d$，新的数字是$$N = d \cdot 10^k + p.$$自从$10^k \equiv 1 \pmod 3$,$$N \equiv d + p \pmod 3.$$我们的选择$d$保证$d + p \equiv 0 \pmod 3$。 因此$N$能被3整除。 

因为$N$包含至少两位数字且大于 3，能被 3 整除意味着$N$是复合的。 

一位数字前缀始终存在，并且任何解决方案都不能使用少于一位数字，因为不允许在前面添加零数字。 因此产生的答案始终是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    p = int(input())

    if p % 3 == 1:
        print(2)
    else:
        print(1)
```该解决方案仅使用残留物$p$模 3。 

当$p \equiv 1 \pmod 3$, 数字`2`使连接后的数字能被 3 整除。 

当$p \equiv 2 \pmod 3$, 数字`1`做同样的事情。 

无需构建最终数字。 的位数$p$永远不需要计算，因为同余$$10^k \equiv 1 \pmod 3$$对于每一个都成立$k$。 

该实现在每个测试用例中以恒定的时间运行，并避免所有素性测试。
