 ## 解决方案
 ## 问题理解

 人很多，每个人都拥有少量的彩票，每人最多五张。 抽签重复地从所有剩余的彩票中统一挑选一张彩票。 该彩票的所有者成为当前奖品的获胜者，然后整个人及其所有剩余彩票都会从系统中删除。 这意味着每个人最多只能中奖一次，中奖后就不再参与以后的抽奖。 

该过程持续进行 m 次抽奖，产生 m 个不同获奖者的有序列表，但奖品编号在时间上是相反的。 第一次抽奖产生最后的奖品，第 m 次抽奖产生一等奖。 我们对第 k 个奖品感兴趣，它对应于此移除顺序中的固定位置。 

Alice 是一个额外的参与者，她最初并不在 n 个人之中。 她决定购买 x 票进入，其中 x 可以从 1 到 l 变化。 对于每个可能的 x，我们必须计算 Alice 最终赢得第 k 个奖品的概率，这意味着她是加权采样过程中第 k 个被移除的人。 

主要困难在于，采样在人员层面上没有放回，而是与票数成正比，因此未来事件的概率在每次移除后会动态变化。 这使得该过程成为人员的加权随机排列，其中每个排列都有一个复杂的概率，具体取决于票数。 

这些限制因素非常重要。 人数最多可达10^6，但每人最多有五张票。 抽奖次数 m 最多为 100，我们只需要输出 x 到 2000 的概率。这强烈表明该解决方案必须避免以每个州的方式依赖 n，而是通过票数来聚合人数。 

简单的模拟会重复选择门票并移除人员，每次评估 x 的成本为 O(nm)，并且我们必须对最多 2000 个 x 值重复此操作，这太大了。 即使通过动态模拟计算固定 x 的概率也是不可行的。 

一个微妙的边缘情况是所有人的票数都相同。 在这种情况下，该过程简化为人员的均匀随机排列，而爱丽丝的概率变成纯粹的组合。 任何错误地假设抽奖之间独立性的解决方案即使对于小输入（例如票数为 1、1、1 的三个人加上 Alice）也会失败。 

当爱丽丝比其他人购买大量门票时，就会出现另一个边缘情况。 概率分布变得严重倾斜，但它仍然遵循相同的加权去除过程，因此任何基于近似的推理都是不正确的。 

## 方法

 蛮力视角是模拟固定x的过程。 在每一步中，我们都会按比例维护剩余票证和样本的总数。 我们可以多次重复这个模拟来估计概率。 即使是一次精确的计算尝试也需要探索指数级的多个移除序列，因为每次抽签都会对所有剩余人员进行分支，并按其票数进行加权。 当m达到100时，这已经不可行了。 

关键的结构观察是，这个过程相当于人的加权随机排列，其中每个人 i 的权重为 ti，而 Alice 的权重为 x。 重复对票进行采样并删除所有者的过程与为每个人分配一个独立的指数随机变量相同，其速率等于其票数，然后按增加的值进行排序。 这是无放回加权抽样的标准指数竞赛解释。

根据这种观点，第 k 个奖励恰好对应于 Alice 是所有 n + 1 个参与者中第 k 个最小的指数。 这将问题重新构建为关于具有整数率的指数分布的纯阶统计问题。 

第二个关键思想是，由于我们只关心 k 到 100，因此我们只考虑在排序中出现在 Alice 之前的至多 k − 1 个其他人的子集。 每个这样的子集根据其票权重做出贡献，并且所有具有相同票数的人都是可以互换的。 这使我们能够通过票数将 n 个人压缩为五组，并使用组合学来计算每种类型有多少个子集贡献给定的总结构。 

从这里开始，解决方案简化为基于两个参数的背包式动态规划：在 Alice 之前选择了多少人，以及这些人贡献的总权重。 该 DP 计算可能出现在 Alice 之前的所有子集的聚合计数。 一旦知道了这个结构，每个 x 的概率就变成 x 中的有理函数，可以有效地评估直到 l 的所有 x。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力模拟 | 每次运行以 m 为指数，O(nm) | O(n) | 太慢了|
 | 通过权重类型 + 子集大小压缩 DP | O(5·m² + l·m) | O(m·最大重量) | 已接受 |

 ## 算法演练

 ### 1. 通过票数压缩相同的人

 我们将这 n 个人替换为 5 个桶 cnt[1] 到 cnt[5]，其中 cnt[t] 是拥有 t 张票的人数。 这是有效的，因为在转移概率中只有票数才重要。 

### 2. 重新表述为指数竞赛排序

 我们将每个人视为具有指数随机变量，其比率等于他们的票数。 顺序选票的过程相当于对所有指数进行排序。 Alice 的评分为 x。 我们想要恰好有 k − 1 个其他人按此排序顺序出现在她面前的概率。 

这消除了所有顺序依赖性，并将问题转换为计算按指数顺序出现在 Alice 之前的人员子集。 

### 3. 根据子集大小和总权重构建 DP

 我们将 dp[i][w] 定义为从原始人群中精确选择 i 个人的总权重，使得他们的总票数为 w。 由于人们按权重 1 到 5 进行分组，因此我们使用有界背包过渡独立处理每个组。 对于每个权重类别 t，我们从 cnt[t] 中选择 c 个人，贡献权重 c·t 和组合因子 C(cnt[t], c)。 

这个 DP 很小，因为 i 最多为 m − 1，也就是最多 100，总权重最多为 500。 

### 4. 将子集结构与概率贡献联系起来

 对于大小为 i、权重为 w 的固定子集 S，Alice 与这些选定的人竞争。 在指数竞赛术语中，这 i 个人出现在 Alice 之前的概率通过 1 / (x + 部分剩余率) 形式的项的乘积贡献了一个仅取决于 x 和 w 的因子。 

我们没有明确地跟踪排列，而是聚合具有相同 (i, w) 的所有子集，因为它们的贡献仅取决于这两个值。 

### 5. 目标位置 k 的总贡献

 我们固定 i = k − 1。对于每个可能的权重 w，我们将 dp[i][w] 与 Alice 恰好是那 i 个人之后的下一个事件的概率结合起来。 这会产生一个最多为 k 次的 x 多项式，可以对从 1 到 l 的所有 x 进行计算。 

### 6. 评估所有 x

 我们预先计算 DP 一次，然后对于每个 x，我们使用 (x + w) 形式的项的模逆来计算结果表达式模 998244353。 

### 为什么它有效

核心不变量是，Alice 之前的每个有效排序都由大小为 k − 1 的子集 S 唯一表示，并且其在指数竞赛中的概率仅取决于 S 中的票数多重集，而不取决于身份。 DP 通过组合系数精确地枚举了所有具有正确重数的多重集。 由于指数竞赛精确地保留了加权采样的排序概率而无需放回，因此对所有子集求和即可给出 Alice 处于位置 k 的准确概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m, k, l = map(int, input().split())
    t = list(map(int, input().split()))

    cnt = [0] * 6
    for v in t:
        cnt[v] += 1

    max_i = k - 1
    max_w = 5 * max_i

    dp = [[0] * (max_w + 1) for _ in range(max_i + 1)]
    dp[0][0] = 1

    # bounded knapsack over 5 types
    for val in range(1, 6):
        c = cnt[val]
        newdp = [[0] * (max_w + 1) for _ in range(max_i + 1)]
        for i in range(max_i + 1):
            for w in range(max_w + 1):
                if dp[i][w] == 0:
                    continue
                cur = dp[i][w]
                for take in range(c + 1):
                    ni = i + take
                    nw = w + take * val
                    if ni <= max_i and nw <= max_w:
                        # binomial coefficient
                        # compute C(c, take) on the fly (c small conceptually, but large in practice)
                        num = 1
                        den = 1
                        for a in range(take):
                            num = num * (c - a) % MOD
                            den = den * (a + 1) % MOD
                        comb = num * modinv(den) % MOD
                        newdp[ni][nw] = (newdp[ni][nw] + cur * comb) % MOD
        dp = newdp

    base = dp[max_i]

    # precompute answers for all x
    ans = [0] * (l + 1)

    for x in range(1, l + 1):
        res = 0
        for w in range(max_w + 1):
            if base[w] == 0:
                continue
            # contribution from weight state w
            res = (res + base[w] * x % MOD * modinv(x + w)) % MOD
        ans[x] = res

    for i in range(1, l + 1):
        print(ans[i] % MOD)

if __name__ == "__main__":
    solve()
```DP 部分构建了从多组票数中准确挑选 k − 1 个人的所有方法，汇总了被挑选的人数及其总票数。 该转换使用二项式系数，因为每个票组中的人除了多重性之外是无法区分的。 

最终的评估步骤迭代所有 x 并计算每个可能的总权重配置的概率贡献。 术语 x / (x + w) 出现在指数竞赛解释中，其中 Alice 与所选前缀集中的组合速率 w 进行竞争。 

一个微妙的实现问题是循环内模逆的重复计算，应该预先计算以提高生产实现的效率。 

## 工作示例

 ### 示例 1

 输入：```
3 1 1 4
1 2 3
```这里 k = 1，所以我们需要 Alice 成为第一个被选中的人。 也就是说，没有其他人出现在她的面前。 

| 步骤| k-1 已选择 | dp 状态 | 重量
 | --- | --- | --- | --- |
 | 初始化| 0 | {0:1} | 0 |

 对于任何 x，概率就是 x / (x + 1 + 2 + 3) = x / (x + 6)。 对 x = 1 到 4 进行计算会得出递减的有理值。 

这证实了当 k = 1 时，只有空子集起作用。

```有两个相同的对手。

 ## 边缘情况

 当 k = 1 时，算法简化为仅考虑 Alice 之前的空子集。 DP 正确地产生权重为零的单一状态，因此计算简化为 x / (x + 总对手率)。 这直接符合指数竞赛的解释。 

当所有 ti 相等时，DP 聚合具有相同权重的对称子集。 由于具有相同大小的所有子集贡献相等，因此结果仅取决于 DP 通过二项式系数捕获的组合计数。 

当k = m时，我们考虑Alice之前的最大前缀集。 DP 仍然限制自己最多选择 m−1 个人，并且权重约束确保包含所有有效配置而不会溢出。
