 ## 解决方案
 ## 问题理解

 我们有一排用数组表示的炸药`E`。 位置有爆炸物`i`仅当其前面某处至少有一种爆炸物且其后某处至少有一种爆炸物时才能激活。 任务是添加满足此条件的爆炸物的额定值。 

输入给出了爆炸物的数量，然后从左到右给出了它们的等级。 输出是不在线两端且被其他爆炸物包围的所有位置贡献的总评级。 

约束条件`n <= 100`非常小。 直接模拟或重复检查已经足够快了，因为即使是`O(n^2)`解决方案只能执行大约一万个操作。 然而，问题的有趣之处在于认识到这种情况，而不是将其过于复杂化。 小界限也意味着我们不需要高级的数据结构或优化。 

评级可以大到 1000，因此最终的总和可以达到大约 100000。Python 整数可以轻松处理这个问题，并且不需要特殊的溢出处理。 

一个常见的错误是忘记第一个和最后一个炸药永远不会爆炸，因为缺少一侧。 例如：```
Input:
3
5 8 2
```正确的输出是：```
8
```中间的炸药两边都有邻居，而两端则没有。 仅检查数组是否具有多个元素的粗心实现可能会错误地包含端点。 

另一个边缘情况是一条少于三个炸药的生产线：```
Input:
2
5 10
```正确的输出是：```
0
```两种炸药都没有左侧和右侧。 错误地循环整个数组并访问不存在的邻居的实现可能会失败或意外地对端点进行计数。 

## 方法

 最直接的方法是检查每一个爆炸物，并询问两侧是否有东西。 对于每个位置，我们可以扫描它之前和之后的元素。 如果两次扫描都发现至少一种爆炸物，我们会将其评级添加到答案中。 这是正确的，因为爆炸的条件正是数组中某处存在左右邻居。 

这种方法的问题在于它会重复工作。 当检查许多位置时，一次又一次地重新发现左右两侧的相同信息。 在最坏的情况下，每个位置都会对几乎整个数组进行扫描，大致给出`n * n`运营。 

关键的观察结果是，该条件根本不依赖于其他爆炸物的值。 这仅取决于职位。 除第一个和最后一个位置之外的每个位置自动在其左侧至少有一个元素，在其右侧至少有一个元素。 这将问题从重复检查条件转变为简单地对数组的中间部分求和。 

蛮力方法之所以有效，是因为它直接测试每种爆炸物的规则，但由于花费时间重新发现相同的位置信息而失败。 只有端点无效的观察结果将问题简化为单次通过有效范围。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 接受这些限制，但没有必要 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取爆炸物的数量及其等级。 阵列顺序很重要，因为条件取决于爆炸物的位置。 
2. 将答案初始化为零。 我们只需要一个运行总和，因为每个爆炸物都是独立考虑的。 
3. 迭代索引中的位置`1`索引`n - 2`。 这些位置正是在它们之前至少有一个元素并且在它们之后至少有一个元素的位置。 
4. 将每个访问过的位置的评级添加到答案中。 每个访问过的位置都仅通过其位置满足爆炸条件。 
5. 打印累计金额。 

为什么它有效：

 唯一不符合要求的位置是阵列的两端。 第一个位置的左侧没有炸药，最后一个位置的右侧没有炸药。 其他每个位置至少有一个较小的索引和至少一个较大的索引，因此每个中间元素都必须贡献其评级。 该算法对这些中间元素进行精确求和，并精确排除无效端点，这证明结果是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    e = list(map(int, input().split()))

    ans = 0
    for i in range(1, n - 1):
        ans += e[i]

    print(ans)

if __name__ == "__main__":
    solve()
```输入存储在列表中，因为我们需要直接访问位置。 循环开始于`1`而不是`0`因为第一个炸药不能爆炸。 之前就停止了`n - 1`因为最后的炸药也不能爆炸。 

什么时候`n`是`1`或者`2`，范围`range(1, n - 1)`是空的。 这自然会给出零答案，而不需要单独的边界条件。 

该代码仅存储输入数组和一个整数累加器。 求和运算顺序不会在 Python 中产生任何溢出问题。

 对于第一个样本：```

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个中间炸药都会被访问一次 |
 | 空间| O(1) 不包括输入存储 | 处理过程中仅使用答案变量 |

 和`n <= 100`，在时间限制内很容易得到线性解。 即使效率较低的二次方法也会通过，但线性方法直接反映了条件的结构并避免了不必要的检查。

def solve(data):

 ## 边缘情况

 对于端点情况：```
Input:
3
5 8 2
```循环从索引处开始`1`并以索引结束`1`，所以只有值`8`已添加。 该算法从不考虑索引`0`或索引`2`，符合端点不能爆炸的规则。 输出是`8`。 

对于二元情况：```
Input:
2
5 10
```循环变成`range(1, 1)`，其中不包含位置。 答案保持为零，正确处理双方都没有炸药的情况。 

对于单个炸药：```
Input:
1
100
```没有可能的中间位置。 循环不执行，输出为`0`。 这可以防止出现差一错误，即尽管没有邻居，但唯一的元素可能会被计算在内。
