 ## 问题理解

 该建筑是一组独立的二维地图的集合，每一层都有一个。 每张地图都是一个包含可步行单元、墙壁和楼梯单元的网格。 不同楼层上具有相同字母的楼梯代表这些位置之间的连接。 目标是选择一楼的任何起始单元并到达最后一层的任何单元，同时最大限度地减少必须转换成门的壁单元的数量。 

重要的细节是运动本身是自由的。 穿过已经开放的牢房、穿过楼梯或穿过已经被切割的墙壁，在切割完成后都不需要任何费用。 唯一被最小化的资源是作为路线一部分进入的不同壁单元的数量，因为每个这样的单元都需要一次激光切割。 

总输入大小以 100 层为界，每层最多包含 100 x 100 的网格。 这使得整栋大楼最多有一百万个单元。 尝试许多可能的路径或对墙壁的所有子集执行搜索的解决方案是不可能的，因为状态空间将呈指数增长。 需要线性或近线性图遍历。 一百万个节点虽然很大，但对于处理每个节点和边缘恒定次数的算法来说是可以管理的。 

有几个细节可能会破坏原本合理的解决方案。 从一楼的任何地方开始都很重要，因为强制搜索从一个特定的空单元格开始可以产生更大的答案。 即使存在一些楼梯，楼层也可能没有通往顶层的路径，因此必须显式处理无法到达的状态。

## 方法

 一种直接的方法是模拟穿过建筑物的可能旅程。 我们可以将每个可能的玩家位置视为一种状态，并反复探索移动，试图找到一条使用最少削减的路径。 这是正确的，因为每项法律行动都有代表。 然而，使用对所有移动均等对待的普通最短路径算法忽略了进入墙壁和进入空单元格之间的关键区别。 探索切割墙的所有可能组合甚至更糟糕。 在最坏的情况下，可能有大约一百万个单元，这使得任何存储许多替代子集或路径的方法都是不可能的。 

有用的观察是，这已经是一个最短路径问题，但边缘只有两种可能的成本。 搬入空的牢房、楼梯或已有的位置的成本为零。 搬入墙壁单元需要花费一美元，因为它消耗一次激光切割。 因此，该图具有二元边权重，这意味着 0-1 BFS 可以有效地找到最短路径。 

该图不需要显式构建。 每个网格单元都是一个节点。 四个相邻单元格创建移动边缘，楼梯单元格为其他楼层上的同一字母创建额外的零成本边缘。 由于起始位置可以是一楼的任何位置，因此该楼层的每个单元格都从距离零开始。 

蛮力方法之所以有效，是因为它探索了所有合法的运动，但因为可能的状态和路径的数量太大而失败。 观察到每次转换的成本要么为零，要么为一，这让我们可以用基于双端队列的遍历来代替昂贵的一般最短路径探索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 可能的切割数量呈指数增长 | 指数| 太慢了 |
 | 最佳 | O(V + E) | O(V) | 已接受 |

 ## 算法演练

 1.读取每一层并存储网格。 阅读时，收集每个楼梯字母的坐标。 稍后需要这些坐标，因为穿过匹配的楼梯是零成本的过渡。 
2. 为每个单元格创建一个距离数组，并将底层的每个单元格初始化为距离零。 所有其他单元一开始都是无法访问的。 这模拟了最佳选择起始位置的事实。 
3. 使用双端队列运行 0-1 BFS。 处理一个单元格时，尝试所有四个相邻单元格。 进入墙壁时，距离会增加 1，而进入任何其他单元格时，距离会增加 0。 如果新距离改善了已知距离，则更新它并将单元格放置在双端队列的前面（进行零成本移动）或放在后面（进行成本一移动）。 
4. 处理楼梯单元时，以零成本移动到不同楼层上相同楼梯字母的所有其他出现处。 这些过渡代表走楼梯。 
5. 搜索结束后，检查顶层的所有牢房。 其中最小的距离就是答案。 如果每个顶层单元格仍然无法到达，则报告无法穿越该建筑物。 

为什么它有效：

 0-1 BFS 保持与 Dijkstra 算法相同的最短路径排序，但利用权重仅为 0 或 1 的事实来避免优先级队列。 每时每刻，双端队列都会存储按当前最短已知距离排序的单元格。 只有在考虑了所有更便宜的可能性之后，单元才会最终确定。 由于每个可能的移动都由具有精确切割成本的边表示，因此为目标楼层找到的第一个最短距离就是所需的门的最小数量。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    f = int(input())
    floors = []
    stairs = {}

    for floor in range(f):
        r, c = map(int, input().split())
        grid = []
        for i in range(r):
            row = list(input().strip())
            grid.append(row)
            for j, ch in enumerate(row):
                if ch.isalpha():
                    stairs.setdefault(ch, []).append((floor, i, j))
        floors.append((r, c, grid))

    ids = []
    index = 0
    for floor, (r, c, _) in enumerate(floors):
        cur = []
        for i in range(r):
            row = []
            for j in range(c):
                row.append(index)
                index += 1
            cur.append(row)
        ids.append(cur)

    n = index
    dist = [10**9] * n
    q = deque()

    for i in range(floors[0][0]):
        for j in range(floors[0][1]):
            idx = ids[0][i][j]
            dist[idx] = 0
            q.append(idx)

    rev = [None] * n
    for f_id, (r, c, _) in enumerate(floors):
        for i in range(r):
            for j in range(c):
                rev[ids[f_id][i][j]] = (f_id, i, j)

    used_stairs = set()

    while q:
        cur = q.popleft()
        floor, r, c = rev[cur]

        current_distance = dist[cur]

        grid = floors[floor][2]
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < floors[floor][0] and 0 <= nc < floors[floor][1]:
                nxt = ids[floor][nr][nc]
                weight = 1 if grid[nr][nc] == '#' else 0
                nd = current_distance + weight
                if nd < dist[nxt]:
                    dist[nxt] = nd
                    if weight == 0:
                        q.appendleft(nxt)
                    else:
                        q.append(nxt)

        ch = grid[r][c]
        if ch.isalpha() and ch not in used_stairs:
            used_stairs.add(ch)
            for nf, nr, nc in stairs[ch]:
                nxt = ids[nf][nr][nc]
                if current_distance < dist[nxt]:
                    dist[nxt] = current_distance
                    q.appendleft(nxt)

    ans = 10**9
    top = f - 1
    for i in range(floors[top][0]):
        for j in range(floors[top][1]):
            ans = min(ans, dist[ids[top][i][j]])

    if ans == 10**9:
        print("DAMN, THE ABSCONDER ABSCONDS AGAIN!")
    else:
        print(ans)

if __name__ == "__main__":
    solve()
```输入解析阶段存储每个楼层并记录楼梯位置。 楼梯字典允许找到楼梯过渡，而无需重复扫描每个楼层。 

这`ids`数组转换三维位置`(floor, row, column)`到单个索引中。 这使得距离数组紧凑，并允许双端队列存储整数而不是元组。 每当处理状态时，反向映射都会恢复坐标。 

BFS 初始化将底层的每个单元放入距离为零的双端队列中。 这是处理起始位置选择的部分。 将初始队列限制为一个单元可以解决另一个问题。 

仅当目的地是墙时，邻居松弛才使用成本 1。 该算法不会阻挡墙壁单元，因为进入一个单元就意味着切开一扇门并使该位置可用。 

楼梯优化`used_stairs`是一个性能细节。 一旦楼梯字母的所有单元都已松弛，再次处理同一楼梯就无法改善任何结果。 如果没有这种优化，多次出现的楼梯可能会重复添加相同的零成本转换。 

Python 整数是无界的，因此不必担心溢出。 唯一需要的边界检查是四种可能的网格移动。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(V + E) | 每个单元和每个运动边缘都会被处理恒定的次数。 |
 | 空间| O(V) | 距离数组、映射和双端队列存储与单元格数量成比例的信息。 |

 最大的建筑可能有大约一百万个单元。 O(V + E) 遍历是合适的，因为边的数量只是单元格数量的一个很小的常数倍。 内存使用量保持在限制范围内，因为该算法仅存储紧凑数组和映射。
