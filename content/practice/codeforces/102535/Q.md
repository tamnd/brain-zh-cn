 ## 解决方案
 ## 问题理解

 输入包含两个正整数集合。 第一个集合包含的可能值`k`，第二个包含可能的碱基`b`。 对于通过从每个集合中选择一个值形成的每个可能的对，我们需要确定该对是否很酷。 答案是满足条件的对的数量。 

这个条件看起来像是重复计算数字和，但关键是基数的数字根`b`仅由模余数确定`b - 1`。 对于正整数`x`，其基数`b`数字根是来自的唯一值`1`到`b - 1`具有相同的余数`x`模数`b - 1`，余数为`0`代表为`b - 1`。 

限制足够大，不可能检查每一对。 最多可以有`300000`每组中的值，放弃`9 * 10^10`可能的对。 输入大小的二次方法无法在两秒内完成。 因为每个值最多都是`10^6`，预期的解决方案必须利用值的数字结构，而不是迭代所有对。 

一个常见的错误是模拟每次乘法的数字和。 这既不必要又危险。 例如，与`k = 6`和`b = 8`，序列基于值`0, 6, 12, 18, ..., 42`，但唯一相关的信息是这些值如何取模`7`。 

另一个边缘情况是当`b = 2`。 这里`b - 1 = 1`，并且每个整数与`1`。 该序列仅包含`f_2(0)`和`f_2(k)`，所以每一个`k`形成一个有效的对。 尝试除以的实现`b - 1`不考虑这种情况可能会失败。 

最后一个边缘情况是`k`和`b - 1`共享一个因素。 例如：```
Input:
1 1
6
4
```这里`b - 1 = 3`。 这些值基于乘以`6`模数`3`，因此每个非零位置都会折叠到相同的数字根。 正确的输出是`0`。 仅检查几个生成值的解决方案可能会错误地假设该模式是排列。 

## 方法

 直接的解决方案是尝试每一对`(k, b)`。 对于每一对，它将计算值`f_b(0), f_b(k), ..., f_b((b - 1)k)`并检查所有数字是否来自`0`到`b - 1`恰好出现一次。 这是正确的，因为它直接遵循定义。 然而，最大的输入可以包含`300000`双方的价值观，创造了`90000000000`对。 即使忽略检查每个序列的成本，对的数量也已经远远超出了可能的范围。 

有用的观察来自于用模运算代替数字根。 让`m = b - 1`。 该序列包含`f_b(ik)`为了`0 <= i <= m`。 为了`1 <= i <= m - 1`，这些值恰好是`ik mod m`，以及最后一个值`f_b(mk)`是`m`因为余数为零。 

乘以`k`模数`m`产生每个残基一次当且仅当`k`有乘法逆模`m`。 这恰恰发生在`gcd(k, m) = 1`。 最初的问题简化为计算对，其中：`gcd(k, b - 1) = 1`。 

剩下的任务是回答许多互质查询。 对于固定值`x = b - 1`，设其不同素因数为`p1, p2, ...`。 一个值`k`如果它至少能被这些素数之一整除，则无效。 包含-排除给出有效的数量`k`价值观：`|K| - count(multiples of p1) - count(multiples of p2) + count(multiples of p1*p2) ...`任何低于一百万的数字的不同质因数的数量都很小，因此这个子集枚举速度很快。 我们预先计算有多少个值`K`使用频率数组可以被每个可能的除数整除`K`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O( | K | * |
 | 最佳 | O(MAX + | B | * 2^ω) |

 这里`ω`是不同质因数的数量`b - 1`。 对于100万以下的数字，`ω`最多是七个。 

## 算法演练

 1. 为中的所有值构建频率数组`K`。 然后计算，对于每个整数`d`, 有多少个值`K`可以被整除`d`。 这使得包含-排除查询可以立即请求倍数计数，而不是扫描所有`K`。 
2. 预先计算每个数字的最小质因数`10^6`。 这允许每个值`b - 1`可以快速分解。 
3. 对于每个基地`b`在`B`， 放`x = b - 1`并因式分解`x`分解为其不同的素因数。 只有不同的质数才重要，因为我们只关心一个数是否至少与一个数共享一个质因数`x`。 
4. 对这些素因数使用包含-排除。 对于素数的每个子集，计算其乘积。 如果子集大小为奇数，则减去中的值的数量`K`可以被该乘积整除。 如果子集大小是偶数，则将其添加回去。 
5. 将结果计数添加到答案中。 每个计数值恰好对应于与当前碱基的一对冷对。 

为什么它有效：

 对于一个基地`b`，数字根的序列恰好是乘以时的排列`k`对所有残基进行模置换`b - 1`。 当乘数与模互质时，乘法运算就是模留数的排列。 因此，这对情侣在什么时候就很酷`gcd(k, b - 1) = 1`。 

包含-排除步骤精确计算以下值`k`不包含任何质因数`b - 1`。 这些正是 gcd 等于 1 时的值，因此每个碱基都会贡献正确数量的酷对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    K = list(map(int, input().split()))
    B = list(map(int, input().split()))

    MAXV = 10**6

    freq = [0] * (MAXV + 1)
    for x in K:
        freq[x] += 1

    divisible = [0] * (MAXV + 1)
    for d in range(1, MAXV + 1):
        s = 0
        for j in range(d, MAXV + 1, d):
            s += freq[j]
        divisible[d] = s

    spf = list(range(MAXV + 1))
    for i in range(2, int(MAXV ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factorize(x):
        res = []
        while x > 1:
            p = spf[x]
            res.append(p)
            while x % p == 0:
                x //= p
        return res

    ans = 0

    for b in B:
        x = b - 1
        primes = factorize(x)

        bad = 0
        cnt = len(primes)

        def dfs(pos, prod, bits):
            nonlocal bad
            if pos == cnt:
                if bits:
                    if bits & 1:
                        bad += divisible[prod]
                    else:
                        bad -= divisible[prod]
                return
            dfs(pos + 1, prod, bits)
            dfs(pos + 1, prod * primes[pos], bits + 1)

        dfs(0, 1, 0)
        ans += len(K) - bad

    print(ans)

if __name__ == "__main__":
    solve()
```频率数组存储原始集合`K`以支持除数计数的形式。 嵌套循环计算`divisible[d]`，这是元素的数量`K`可除以`d`。 

最小素因子数组是标准筛优化。 而不是在因式分解时尝试所有可能的除数`b - 1`，它会重复删除最小的素因数。 仅存储不同的因子，因为重复幂不会影响两个数字是否互质。 

递归函数枚举不同质因数的子集。 这`bits`value 记录了选择了多少个因子。 奇数大小的子集表示应删除的数字，而偶数大小的非空子集则被添加回来。 空子集将被忽略。 

Python 整数不会溢出，并且递归深度最多为 7，因为低于 100 万的数字不能有多个不同的素因数。

 ## 边缘情况

 对于`b = 2`，模数为`1`。 因式分解不返回素数，因此包含-排除不会将任何值标记为无效。 该算法将每个值相加`K`，这与每个正整数互质的事实相匹配`1`。 

对于值，其中`k`与以下因素共享一个因素`b - 1`，包含该因子的素数子集将删除它们。 例如，与`k = 6`和`b = 4`，模数为`3`。 质因数列表为`[3]`，以及倍数的计数`3`包括`6`，因此被排除。 

对于大输入，该算法从不比较每个`k`与每一个`b`。 它只处理中的碱基`B`，并且每个都使用自己的一小组质因数。 这样就避免了不可能的事情`|K| * |B|`对枚举。
