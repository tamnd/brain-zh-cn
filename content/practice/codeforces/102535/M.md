 ## 解决方案
 ## 问题理解

 对手的路线可以被视为一个二进制字符串，其中`O`表示当前活跃的 Mook 且`E`意思是被击败的温顺。 每次 Kim 到达活跃的 Mook 时，一分钟过去，该位置就会变成`E`，以及翻转回之前的每个位置`O`。 反转器可以让我们在任何战斗开始之前精确反转初始线的一个连续部分。 我们需要选择反转，以便清除线路所需的总分钟数尽可能小。 

关键的观察是战斗过程不是任意模拟。 如果我们将最左边的字符权重分配为1，下一个字符权重为2，下一个权重为4，依此类推，一次战斗操作就与从这个二进制数中减一完全相同。 最左边的`O`其作用类似于最低有效设置位：它变为 0，所有较小的位变为 1。 战斗总数就是这个二进制数的值。 

输入最多包含 35000 个字符串，但它们的总长度仅为 500000。这排除了尝试所有可能的反转，因为子字符串可能有大约 n² 个选择。 即使是模拟每个选择的战斗过程的解决方案也是不可能的，因为字符串表示的数字可能呈指数级大。 我们需要对每个测试用例采用线性或近线性方法。 

一个常见的错误是按原始从左到右的顺序优化字符串。 权重向右增长，因此原始字符串的右侧影响最大。 另一个错误是忘记反转仍必须使用一次。 允许长度为 1 的段，这意味着保持字符串不变。 

例如，使用输入`E`，没有 Mook，所以答案是`0`。 总是寻找有利逆转的方法可能会因为假设必须发生变化而失败。 用于输入`O`，答案是`1`，因为需要一场战斗，逆转也无济于事。 用于输入`EOOE`，原值为`6`，但反转最佳片段给出`EEOO`，其值为`3`。 将原始顺序视为最重要一侧的方法会错误地选择。 

## 方法

 一种直接的方法是尝试每个可能的间隔，将其反转，计算所得的二进制值，并保留最小值。 有 O(n²) 个间隔。 即使反转和评估一个区间被优化到 O(1)，对于 n = 500000 来说，候选者的数量已经太大了。蛮力是正确的，因为它会检查 Reversinator 的每一种可能的使用，但搜索空间是问题所在。 

有用的转换是查看正常表示法中的二进制数。 反转原始字符串。 在这种反向表示中，第一个字符是最高有效位。 反转原始字符串中的一个段仍然只是反转这个新字符串中的一个段。 任务变成找到通过一次子串反转可获得的按字典顺序最小的二进制字符串。 

对于二进制字符串，最好的反转很容易描述。 如果第一个后面没有零，则字符串已经尽可能小了。 否则，第一个位置包含`1`应该收到一个`0`，移动零的唯一方法是反转到最后一个零。 任何较小的结尾都会使第一个改变的位置变得更糟，而任何较早的开始都会保持领先不变`1`。 

反转后，我们只需要计算得到的二进制数模`10^9`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 反转输入字符串。 这改变了表示方式，使得普通的词典比较与战斗计数的数字比较相匹配。 
2. 查找第一个出现的`1`在反转的字符串中。 这是我们第一个可以减少数量的地方。 
3. 查找最后一次出现的`0`在反转的字符串中。 这是可以移动到最早有用位置的最远的零。 
4.如果第一个`1`出现在最后一个之前`0`，反转该区间。 这会将零置于第一个可以改进的重要位置。 
5. 将生成的二进制字符串转换为模数`10^9`从左到右扫描并重复将当前值加倍。 

工作原理：反转的字符串是普通的二进制表示形式，因此按字典顺序使其变小与使战斗计数变小完全相同。 第一个不同的位决定结果。 反转只能通过将零移到一个或多个零上来改善字符串。 最早的一个后跟最新的零给出了第一个不同位置的最大可能的改进，之后反转自动修复剩余的顺序。 如果这样的对不存在，则每个可能的反转都会保持第一个有效位不变或使其变大。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9

def solve_case(s):
    s = s[::-1]

    first_one = -1
    last_zero = -1

    for i, c in enumerate(s):
        if c == '1' and first_one == -1:
            first_one = i
        if c == '0':
            last_zero = i

    if first_one != -1 and last_zero > first_one:
        s = s[:first_one] + s[first_one:last_zero + 1][::-1] + s[last_zero + 1:]

    ans = 0
    for c in s:
        ans = (ans * 2 + (c == '1')) % MOD
    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        s = input().strip()
        out.append(str(solve_case(s)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```第一次转型，`s[::-1]`，是中心简化。 它将不寻常的战斗过程变成了普通的二进制算术。 

寻找`first_one`和`last_zero`一次扫描即可完成。 如果`first_one`不是之前`last_zero`，没有将零向更有效的位置移动，因此字符串保持不变。 

切片反转是安全的，因为它仅应用一次。 最后的循环永远不会构造二进制字符串表示的大整数。 它只保留模余数`10^9`，这可以避免溢出并适用于最大长度。 

## 工作示例

 对于`EOOE`，反向表示开始为`EOOE`。 

| 字符串状态 | 第一的`1`| 最后的`0`| 行动| 价值|
 | ---| ---| ---| ---| ---|
 | EOOE | 1 | 3 | 反转位置 1 到 3 | 平等就业机会 |
 | 平等就业机会 | - | - | 转换二进制值 | 3 |

 反转将最后的零移动到最有效的位置。 这说明了为什么字符串的原始方向会产生误导。 

为了`OOE`，其反转表示为`EOO`。 

| 字符串状态 | 第一的`1`| 最后的`0`| 行动| 价值|
 | ---| ---| ---| ---| ---|
 | 环氧乙烷 | 1 | 2 | 反转位置 1 到 2 | 环氧乙烷 |
 | 环氧乙烷 | - | - | 转换二进制值 | 3 |

 这里，反转不会提高该值，因为两个受影响的位都已经处于最佳顺序。 该算法正确地允许强制逆转没有明显的效果。

 ## 边缘情况

 对于`E`，反转后的字符串不包含`1`， 所以`first_one`保持未设置状态。 该算法跳过反转并评估零值，产生`0`。 

为了`O`，有一个`1`但没有`0`，因此无法将较小的位移到前面。 该算法保持字符串不变并返回值`1`。 

为了`EOOE`，原来的战斗次数并不少。 将字符串反转为`EOOE`，算法找到第一个`1`在索引 1 和最后一个`0`在索引 3 处，反转该部分，并获得`EEOO`。 二进制值变为`3`，匹配最优结果。 

对于仅包含`O`字符，例如`OOOOOOOOOO`，每个可能的反转都会产生相同的字符串。 该算法检测零的缺失并直接计算二进制值，无需进行不必要的操作。
