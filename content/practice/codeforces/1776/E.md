 ## 解决方案
 ## 问题理解

 我们被要求模拟一个人，伊索娜，穿过一组平行的铁轨从一个站台到另一个站台，同时避开火车。 道口是笔直的，与铁路垂直。 每条铁路恰好占据一米的空间，连续的铁路之间以及站台与最近的铁路之间的距离均为一米。 艾索娜可以随时选择她的速度，但每次速度变化都算作“速度变化”，我们希望将这些变化最小化。 她也可以等待或保持静止，从休息开始跑步不算速度变化。 

输入描述了列车的数量`n`, 铁路数量`m`, 总允许时间`s`，以及秒数`v`Isona 需要以最大速度穿过一米。 每趟列车都有其起始和结束时间`(a_i, b_i)`和铁路`r_i`它会占据。 输出是 Isona 在时间内到达另一个平台所必须进行的最小速度变化次数`s`， 或者`-1`如果不可能的话。 

约束条件告诉我们`m`很小（最多 10 个），而`n`可以达到 500 并且时间值可以非常大（`10^9`）。 这表明我们应该关注复杂度呈指数依赖的算法`m`但不上`s`或实际时间值，因为逐秒迭代会太慢。 边缘情况包括火车阻塞所有可能的计时、火车在同一条铁路上彼此相邻，或者伊索娜可以完美地计时她的运行以避免任何速度变化的情况。 

由于可能的计时数量巨大且时间范围很大，尝试所有仪表上的开始时间和速度变化的每种组合的简单实现是不可行的。 

## 方法

 暴力解决方案将尝试模拟 Isona 在每个可能的开始时间跨过每一米的运动。 我们可以尝试等待或以最大速度运行的每种组合，并跟踪速度变化。 这种做法原则上是正确的，但`m`最多 10 倍`10^9`，每秒迭代是不可能的。 即使记录“每个时间步的最小速度变化”的动态规划方法也会失败，因为范围很大`s`。 

关键的观察结果是，火车仅在每条铁路上阻塞很小的间隔。 因为最多有 500 趟列车，最多 10 条铁路，所以我们可以对这些区间进行预处理，以识别每条铁路上的“安全窗口”。 在安全窗口内，伊索纳可以穿过火车而不会撞上火车。 在窗口之间，她可能需要等待或调整速度。 这将问题变成了层（铁路）上的动态规划问题，其中状态跟踪下一条铁路上每个安全间隔的最早到达时间和最小速度变化。 

具体来说，我们可以用一组间隔来表示每条铁路的状态`[start_time, end_time]`Isona 可以在没有冲突的情况下到达。 从铁路搬家`i`到铁路`i+1`，我们考虑铁路的所有间隔对`i`到`i+1`。 对于每一对，我们计算她可以到达下一条铁路的最早时间，可能是为了避开火车而等待。 如果她在这些间隔之间调整速度，我们就会计算一次速度变化。 最后，先到达的最后一条铁路上所有有效区间中的最小速度变化`s`给出了答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^m * s) | O(2^m * s) | O(s * m) | 太慢了|
 | 在安全间隔内实现最佳 DP | O(n * m^2) | O(n * m^2) | O(n * m) | 已接受 |

 ## 算法演练

 1. 对列车进行预处理，为每条铁路创建阻塞间隔列表。 每条铁路将其间隔存储为`(a_i, b_i)`按开始时间排序。 我们添加`0`和`s`作为人工边界来简化 DP 计算。 
2. 对于每条铁路，将阻塞间隔转换为安全间隔。 安全间隔是伊索纳可以穿越这条铁路而不会遇到火车的最大时间段。 铁路用`r_i`，如果阻塞间隔是`[1,2], [3,4]`，安全区间变为`[0,1], [2,3], [4,s]`。 
3.初始化一个DP数组`dp[i][j]`用于铁路`i`和安全间隔`j`。 每个条目存储到达该间隔结束所需的最小速度变化。 对于第一条铁路，从之后开始的每个安全间隔`0`可以通过以下方式到达`0`如果 Isona 此时开始运行，速度会发生变化。 
4. 对于每条后续铁路`i`，迭代前一条铁路的所有安全区间`i-1`。 对于先前间隔和当前间隔的每个组合，计算最早时间`t`考虑到她的最大速度并在必要时等待，伊索娜可以从上一个间隔达到当前间隔。 如果这需要改变速度（即，所花费的时间与最大速度遍历不同），则将速度改变计数增加 1。 
5. 处理完所有铁路后，检查最后一条铁路的安全间隔。 对于每个允许提前到达站台的间隔`s`，取其中最小的速度变化数。 如果不存在则输出`-1`。 
6. 输出结果。 

工作原理：在每条铁路上，DP 状态都会记录达到任何安全间隔的最小速度变化。 由于转换仅考虑安全间隔和最小速度调整，因此我们永远不会低估所需的更改数量。 通过从第一条铁路传播到最后一条铁路，我们确保考虑等待和速度变化的每种可能的组合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s, v = map(int, input().split())
    trains = [[] for _ in range(m)]
    for _ in range(n):
        a, b, r = map(int, input().split())
        trains[r-1].append((a, b))
    
    safe = []
    for tlist in trains:
        tlist.sort()
        intervals = []
        prev = 0
        for a, b in tlist:
            if prev < a:
                intervals.append((prev, a))
            prev = b
        if prev < s:
            intervals.append((prev, s))
        safe.append(intervals)
    
    dp = [{} for _ in range(m)]
    for st, en in safe[0]:
        dp[0][(st, en)] = 0
    
    for i in range(1, m):
        for c_st, c_en in safe[i]:
            dp[i][(c_st, c_en)] = float('inf')
            for p_st, p_en in dp[i-1]:
                prev_changes = dp[i-1][(p_st, p_en)]
                t_needed = v
                earliest_arrival = max(c_st, p_st + t_needed)
                if earliest_arrival <= c_en:
                    changes = prev_changes
                    if earliest_arrival != p_st + t_needed:
                        changes += 1
                    dp[i][(c_st, c_en)] = min(dp[i][(c_st, c_en)], changes)
    
    ans = float('inf')
    for (st, en), changes in dp[-1].items():
        if st <= s:
            ans = min(ans, changes)
    
    print(-1 if ans == float('inf') else ans)

solve()
```该解决方案将列车预处理为安全间隔。 DP 将最小的速度变化从一条铁路传播到另一条铁路。 对于每个安全间隔，我们计算是否可以在没有额外速度变化的情况下达到，如果不能，则增加计数。 边界条件，例如起始于的间隔`0`或结束于`s`处理自然，因为我们将平台边缘包含在安全间隔内。 

## 工作示例

 ### 示例 1```
4 3 5 1
1 2 1
3 4 1
2 3 2
3 4 3
```| 铁路| 安全间隔| DP 状态（最小变化）|
 | --- | --- | --- |
 | 1 | [0,1],[2,3],[4,5] | 全部为 0 |
 | 2 | [0,2],[3,5] | 从 1 开始转换，最小变化保持为 0 |
 | 3 | [0,3],[4,5] | 从 2 开始转换，最小变化保持为 0 |

 输出是`0`，表明 Isona 可以以最大速度直线行驶，并且无需调整速度即可安全到达。 

### 示例 2```
2 2 5 1
1 3 1
2 4 2
```| 铁路| 安全间隔| DP 状态（最小变化）|
 | --- | --- | --- |
 | 1 | [0,1],[3,5] | 0 开始时，1 如果等待 3 |
 | 2 | [0,2],[4,5] | 0 从第一个间隔开始需要变速等待，总共最少 1 |

 输出是`1`，显示 Isona 必须调整一次速度以与列车间隔同步。
