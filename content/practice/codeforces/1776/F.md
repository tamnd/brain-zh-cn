 ## 解决方案
 ## 问题理解

 我们得到一个连通的无向图。 每条边都必须分配给一个公司。 

假设公司`c`拥有所有有颜色的边`c`。 着色必须满足两个条件。 

第一个条件是不允许任何一家公司拥有连接的跨越网络。 对于每种颜色，仅由该颜色的边形成的图形必须被断开。 

第二个条件要强得多。 就拿任意两家公司来说吧。 如果我们保留属于这两家公司中任何一家的所有边，则生成的图必须是连接的。 

我们可以自由选择公司数量`k`，只要`k ≥ 2`。 

该图最多有 50 个顶点，所有顶点的总和`n`跨测试用例最多为 5000 个。这些限制很小。 挑战不在于算法的复杂性，而在于找到一种始终有效的结构。 

最危险的错误是只专注于使每种颜色断开连接。 那部分很容易。 困难的部分是保证每对颜色形成一个连通图。 

考虑一条路径`1-2-3`。 

如果我们给边缘上色`(1,2)`带有颜色 1 和边缘`(2,3)`如果使用颜色 2，则每个单独的颜色都会断开连接。 但是，如果我们引入没有任何用处的第三种颜色，则某些颜色对可能无法连接图形。 成对连接性要求是全局性的，并且必须适用于每对颜色。 

另一个简单的陷阱出现在完整的图表上。 

认为`n = 3`并且所有三个边都存在。 如果我们将与顶点 1 相关的所有边着色为颜色 1，并将其余边着色为颜色 2，则仅连接颜色 1，这违反了第一个条件。 

完整图是主体结构唯一需要特殊调整的情况。 

## 方法

 暴力思维会尝试分配颜色，然后验证条件。 

对于最多 1225 个边的图，即使在两种颜色之间进行选择也已经创建了`2^m`的可能性。 每次分配后检查连接性很容易，但搜索空间非常大。 

关键的观察是我们不需要很多颜色。 

想象一下选择一个顶点`u`。 Give one color to every edge incident to`u`，并为每个其他边赋予第二种颜色。 

如果我们只使用两种颜色，那么第二个要求就变得微不足道了。 只有一对颜色，即`{1,2}`，并且它们一起包含原始图的每条边。 由于原始图是连通的，因此该对也是连通的。 

现在我们只需要确保每种颜色都断开连接。 

颜色 2 不包含边缘接触`u`，所以顶点`u`是孤立的。 颜色2自动断开。 

颜色 1 是一颗以`u`。 每当存在一些不相邻的顶点时，该颜色就会断开连接`u`，因为该顶点的颜色 1 的度数为零。 

这立即解决了每个不完全图。 选择度数小于的顶点`n-1`。 

唯一剩下的情况是完整的图。 

在完整图中，每个顶点都与其他顶点相邻，因此前面的论证失败了。 我们需要一种额外的颜色。 

选择一个顶点`u`。 

给出一个入射边`u`颜色 1.

 给出所有其他与`u`颜色 2.

 给每个剩余的边缘颜色 3。 

现在每种颜色都断开连接：

 颜色 1 仅包含一条边缘。 

颜色 2 是一颗缺少一片叶子的星星。 

颜色 3 不包含与`u`。 

任意一对颜色都是相连的：

 颜色 1 和 2 包含所有与`u`，形成跨越星。 

颜色 1 和 3 连接`u`通过唯一的颜色 1 边，而颜色 3 包含其余顶点上的完整图形。 

颜色 2 和 3 是对称的。 

这样就彻底解决了问题。

 ## 算法演练

 1. 读取图并计算每个顶点的度数。 
2. 检查某个顶点是否`u`度数严格小于`n-1`。 
3. 如果存在这样的顶点，则使用`k = 2`。 

将颜色 1 分配给每个与`u`。 

将颜色 2 分配给每隔一条边。 

颜色 2 已断开连接，因为`u`没有 color-2 边缘。 

颜色 1 断开，因为至少有一个顶点不与颜色 1 相邻`u`，因此该顶点没有颜色 1 的边。 
4. 否则图表就完整了。 
5. 使用`k = 3`。 
6. 选取任意顶点，例如顶点 1。 
7. 在与顶点 1 相关的边中，选择一条边并将其着色为 1。 
8. 用颜色 2 为与顶点 1 相交的每隔一条边着色。 
9. 用颜色 3 为所有剩余边缘着色。 
10. 按照原始输入顺序输出颜色。 

### 为什么它有效

 对于非完全图，选择的顶点`u`至少有一个非邻居。 color-1 图仅由接触的边组成`u`，从而使非邻居被孤立。 2 色图不包含边接触`u`， 所以`u`本身是孤立的。 两种颜色均已断开。 

由于只有两种颜色，任何两种颜色的并集就是原始图，它是连通的。 

对于完整的图，颜色 1 包含一条边并且是断开的。 颜色 2 是部分星形，并且已断开连接，因为颜色 1 边缘的一个端点未接收到颜色 2 边缘。 颜色 3 不包含与顶点 1 相关的边，因此顶点 1 是孤立的。 

对于颜色对的连接：`1 ∪ 2`包含与顶点 1 相关的每条边，形成生成星形。`1 ∪ 3`包含顶点上的完整图`{2,3,...,n}`以及将顶点 1 连接到完整图的一条边。`2 ∪ 3`是类似的。 

因此，每个必需的条件都成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, m = map(int, input().split())

        edges = []
        deg = [0] * (n + 1)

        for _ in range(m):
            u, v = map(int, input().split())
            edges.append((u, v))
            deg[u] += 1
            deg[v] += 1

        u = -1
        for v in range(1, n + 1):
            if deg[v] < n - 1:
                u = v
                break

        if u != -1:
            print(2)

            ans = [2] * m
            for i, (a, b) in enumerate(edges):
                if a == u or b == u:
                    ans[i] = 1

            print(*ans)

        else:
            print(3)

            ans = [3] * m
            first_edge = -1

            for i, (a, b) in enumerate(edges):
                if a == 1 or b == 1:
                    first_edge = i
                    break

            ans[first_edge] = 1

            for i, (a, b) in enumerate(edges):
                if i == first_edge:
                    continue
                if a == 1 or b == 1:
                    ans[i] = 2

            print(*ans)

solve()
```第一部分计算度数。 度数小于的顶点`n-1`立即证明该图不完整。 

在非完整情况下，接触所选顶点的每条边都接收颜色 1。所有其他边保持颜色 2。用 2 初始化整个答案数组，然后覆盖关联边是最简单的实现。 

在完整图的情况下，我们使用三种颜色。 我们找到与顶点 1 相关的一条边，并将其保留为颜色 1。与顶点 1 相接触的所有其他边都变为颜色 2。其余的边保持颜色 3。 

一个微妙的点是我们必须保持原始输入顺序的颜色。 输出是指`i`-th 输入边，因此我们将所有边存储在列表中，并按边索引分配颜色。

from collections import deque

def check(n, edges, k, colors):
    assert 2 <= k

    def connected(allowed):
        g = [[] for _ in range(n)]
        for (u, v), c in zip(edges, colors):
            if c in allowed:
                u -= 1
                v -= 1
                g[u].append(v)
                g[v].append(u)

        while q:
            x = q.popleft()
            for y in g[x]:
                if not vis[y]:
                    vis[y] = True
                    q.append(y)

        return all(vis)

    for c in range(1, k + 1):
        assert not connected({c})

    for a in range(1, k + 1):
        for b in range(a + 1, k + 1):
            assert connected({a, b})

 ## 边缘情况

 考虑三个顶点的完整图：```
1
3 3
1 2
1 3
2 3
```每个顶点都有度数`n-1 = 2`，所以图就完整了。 算法进入三色分支。 

与顶点 1 相关的一条边的颜色为 1，另一条边的颜色为 2，其余的边的颜色为 3。 

如果我们在这里错误地使用了双色结构，则颜色 1 将形成连接的跨越星形并违反要求。 特殊的完整图分支避免了这个问题。 

现在考虑：```
1
4 5
1 2
1 3
2 3
2 4
3 4
```顶点 1 的度数为 2，小于`n-1 = 3`。 

所有与顶点 1 相关的边都变为颜色 1。其余边变为颜色 2。 

顶点 4 与顶点 1 不相邻，因此它在颜色 1 中是孤立的。顶点 1 在颜色 2 中是孤立的。两种颜色都是不连通的，而它们的并集是原始连通图。 

这正是建筑所利用的财产。
