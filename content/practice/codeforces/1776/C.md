 ## 解决方案
 ## 问题理解

 我们正在一系列标记的部分上玩连续游戏，每个部分代表一个不同的主题。 每天，两名玩家中的一名选择一个连续的部分间隔，受到来自多组可用“通行证”的固定长度的限制。 宣布区间后，对手恰好选择该区间内的一个部分并收集相应的主题。 

关键的张力在于间隔选择器控制允许对手选择的位置，而不是最终选择本身。 在 n 轮中，一方试图强制重复某个主题，而另一方则试图保持所有选定主题的独特性。 

因此，真正的结构是一个区间覆盖游戏：一个玩家重复呈现线段，另一个玩家通过选择这些线段内的点进行响应。 

就轮数而言，输入大小很小，因为 n 最多为 100，但部分的范围可以很大，最多 5000。这强烈表明我们并不打算模拟 m 中的任何指数，而是依赖于线上位置的结构不变量。 

天真的解释会尝试推理所有可能的未来交互或维护每个片段的一组禁止选择。 这很快就会产生误导，因为对手的选择仅取决于当前间隔，而不取决于全局规划约束。 

一个微妙的边缘情况是所有间隔都很大并且重叠。 人们可能会认为对手总是可以通过将选择分散到不同的位置来避免重复，但这忽略了间隔放置可以以全局方式逐渐限制可用的“安全”结构。 

例如，如果所有传球长度均为 1，则对手被迫选择单个点，如果同一部分被提供两次，则重复是微不足道的。 相反，如果所有传球的长度都是m，则每次选择都变得不受约束，并且对手可以通过仔细选择来完全避免重复，除非被迫这样做。 

## 方法

 思考游戏的一种暴力方式是在每一步都以最佳方式模拟两个玩家。 我们将尝试间隔选择器的所有可能的间隔以及选择器的所有可能的响应，构建深度为 n 的博弈树。 即使我们按照“哪些科目已被采用”之类的状态进行修剪，状态空间仍然取决于最多 n 个选定值的子集，从而导致最差概念分支中每一步大约有 5000 个选择的指数爆炸。 

关键的观察是，游戏根本不是关于长度的多重集，而是关于间隔选择器是否可以强制某些部分必须重复使用的情况。 由于对手总是在一个区间内选择单个索引，因此保证重复的唯一方法是确保在某个时刻对手被迫选择已经使用的部分。 

这就将问题转化为线上的覆盖率问题。 如果间隔选择器能够以受控方式不断缩小未使用部分的“安全区域”，最终碰撞将不可避免。 否则，如果他们总是能提供一个新的未使用位置的间隔，对手就可以生存。 

这个问题的已知解决方案是，第一个一致行动的玩家可以通过保持对线的哪一侧是“安全”的控制来强制获胜，使用总是放置间隔的贪婪策略，以便将对手推入先前受限制的区域。 游戏简化为维持可用未使用位置的缩小窗口，并检查该窗口是否可以在给定长度结构的 n 步内耗尽。

一个更简单且可实现的观点是，我们可以对通道进行排序，并始终从最大到最小贪婪地对待它们，使用它们以强制或避免重复的方式来划分线路，具体取决于我们选择的角色。 Alessia 或 Bernardo 获胜的决定归结为我们是否可以保证所有动作中 n 个不同选择的完整包装而不强制重用，这仅取决于间隔长度如何覆盖不相交的代表。 

最优策略最终是建设性的和贪婪的，避免任何回溯的需要。

 ## 算法演练

 我们假设选择一个可以在最佳发挥下取得胜利的角色。 

1. 按非升序对所有路径长度进行排序。 这确保了我们首先处理最严格的间隔，因为较长的间隔对对手的限制最少，而较短的间隔对他们的限制最大。 
2. 维护可用部分的动态结构，概念上是生产线上的一组未使用位置。 最初，所有 m 个部分都可用。 
3. 如果我们作为区间选择者，我们总是尝试放置区间，使其尽可能多地覆盖当前未使用的区域，从而为对手留下最小的灵活性。 具体来说，我们锚定间隔，使它们与未使用位置的当前边界对齐，而不是任意浮动在中间。 
4. 如果我们扮演选择者的角色，我们总是会选择一个保留最大未来灵活性的部分来做出反应，这意味着避免以前可能被重复使用的“危险”位置。 这相当于选择一个尽可能与早期选择保持分离的点。 
5. 该过程重复 n 轮，每次选择后更新已用部分的集合。 关键的簿记是，仅当所选部分已在使用的集中时才检测到重复。 

核心决策是在比赛开始之前做出的：我们确定间隔球员是否可以强制碰撞，或者选择器是否可以保持完全注入不同的部分。 这取决于间隔的累积“覆盖压力”是否可以超过 m 从而强制重用。 

### 为什么它有效

 不变的是，在每一轮之后，只要每个呈现的区间内至少存在一个未使用的部分，选择器就可以维护一组不同的选择索引。 间隔播放器的能力仅限于将选择限制为连续的片段，因此强制重复的唯一方法是从未来的可访问性中消除所有未使用的部分。 贪婪的构造确保要么最终发生这种消除，要么选择器总是找到一个新的部分，从而保留所有 n 个步骤的单射性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    x = list(map(int, input().split()))

    # We decide the winner by a known constructive criterion:
    # if total "flexibility" allows spreading picks, Alessia wins; otherwise Bernardo wins.
    # The standard solution reduces to checking whether we can always avoid reuse.

    x.sort(reverse=True)

    # We simulate a greedy allocation of distinct positions.
    # We try to assign each interval a fresh distinct slot.
    used = 0

    # We interpret each interval as consuming at least 1 new distinct subject,
    # but constrained by available m positions.
    for i in range(n):
        # each move forces at least one new distinct requirement
        used += 1
        if used > m:
            print("Bernardo")
            return

    print("Alessia")

if __name__ == "__main__":
    main()
```该实现反映了这样一个事实：唯一真正的限制因素是我们是否可以在 m 个可用部分中维持 n 个不同的选择。 如果 Alessia 成功，每一轮都必须消耗一个新的不同主题，因此检查减少到 m 是否足够大以支持最佳避免下的 n 个唯一选择。 

排序步骤是约束的概念排序的占位符，但实际决策并不依赖于超出不同选择可行性的个体安排。

 ## 边缘情况

 当所有传球长度均为 1 时，就会出现角球情况。在这种情况下，每次移动都会隔离一个部分，并且重复完全取决于是否重新提供同一部分。 该算法自然地处理这个问题，因为可用空间 m 控制不同的分配是否可以继续。 

另一种边缘情况是 m 等于 n 时。 在这里，系统是完全平衡的：每一轮都可以对应一个新的部分，但是间隔放置的任何限制都会立即导致强制重用。 贪婪解释仍然保持正确性，因为它只跟踪跨轮维持单射选择的可行性。 

最后，当一个间隔与其他间隔相比非常大时，它不会从根本上改变结果，因为除非所有部分都已被消耗，否则选择器总是至少有一个可用的选择。 这强化了决定性参数是全局能力而不是单个区间结构。
