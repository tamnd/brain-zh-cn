 ## 解决方案
 ## 问题理解

 该任务要求我们确定法官是否有可能在给定消息时间线的情况下在一天内至少遛她的狗男孩两次。 每次步行正好需要 120 分钟，不能与其他步行重叠，并且裁判在步行期间不会发送消息。 输入由多个测试用例组成，每个测试用例都提供自午夜以来严格递增的消息时间列表（以分钟为单位）。 如果可以围绕消息进行至少两次不重叠的 120 分钟步行，则每个测试用例的输出为“是”，否则为“否”。 

一个关键的观察结果是一天有 1440 分钟，因此可用的总时间是有限的。 由于每次步行需要 120 分钟，两次步行需要 240 分钟的空闲时间。 消息时间将一天划分为可以步行的时间段。 如果连续消息之间或一天的开始/结束之间的任何间隔至少为 120 分钟，则可以在那里散步。 我们需要检查是否存在至少两个这样的间隔且不重叠。 

边缘情况包括消息很少、消息紧密堆积在一起或可能从午夜开始或在一天的最后一刻结束的步行的情况。 例如，如果消息出现在 0、1、2、3、4 分钟，则从 5 到 1440 的剩余时间足以安排两次步行。 相反，如果消息位于 0、120、240、…、1320，则可能无法容纳 120 分钟的步行。 

问题的限制非常轻微。 每个测试用例最多有100条消息，并且测试用例最多有100个。 这使得每个测试用例解决方案的任何 O(n) 都可以在时间限制内顺利运行。 我们可以迭代消息时间并计算间隙，而不必担心性能。 

## 方法

 暴力方法会尝试从一天中的每一分钟开始进行 120 分钟的步行，并检查它是否与任何消息重叠。 这将涉及每个测试用例检查多达 1440 个开始时间，并且对于每个开始时间，迭代所有消息以检查冲突。 在最坏的情况下，每个测试用例大约会产生 1440 * 100 = 144,000 次操作，这是可行的，但效率低下。 

最佳方法观察到唯一相关的时间是连续消息之间的间隔和一天的边缘。 每条消息将一天分为几个时段：从午夜到第一条消息、消息之间、从最后一条消息到一天结束。 我们只需要测量这些间隙，看看是否至少有两个间隙的长度为 120 或更大。 通过迭代消息列表并检查间隔的长度，我们可以在 O(n) 时间内解决每个测试用例。 我们的见解是，在足够大的间隙内的任何地方放置行走总是有效的，因为消息在行走过程中不会移动。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(1440 * n) | O(n) | 可以工作，但速度太慢 |
 | 间隔检查| O(n) | O(1) | O(1) | 接受且简单 |

 ## 算法演练

 1. 首先读取测试用例的数量，`t`。 这告诉我们需要分析多少个单独的时间表。 
2. 对于每个测试用例，读取消息数量`n`以及消息时间列表`a`。 该列表正在严格增加。 
3. 初始化计数器`walkable_intervals`为零。 这将跟踪消息之间存在多少个 120 分钟间隔。 
4. 计算从午夜到第一条消息的第一个时间间隔。 如果此间隔至少为 120 分钟，则增加`walkable_intervals`。 
5. 迭代连续的消息对。 对于每对`(a[i], a[i+1])`,检查间隔`a[i+1] - a[i]`。 如果此间隙至少为 120 分钟，则增加`walkable_intervals`。 
6. 检查从最后一条消息到当天结束的最终间隔。 如果`1440 - a[-1]`至少为 120，增量`walkable_intervals`。 
7. 统计完所有区间后，如果`walkable_intervals`至少为2，输出“YES”； 否则，输出“NO”。 

为什么有效：该算法是正确的，因为它只考虑没有消息的最大连续周期。 任何 120 分钟的步行都必须完全符合这些时间段之一。 通过计算长度至少为 120 的周期，我们可以直接计算可能有多少次不重叠的行走。 两个或多个这样的时间段保证可以发生两次行走。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    walkable = 0
    
    # Check interval before first message
    if a[0] >= 120:
        walkable += 1
    
    # Check intervals between messages
    for i in range(n - 1):
        if a[i+1] - a[i] >= 120:
            walkable += 1
    
    # Check interval after last message
    if 1440 - a[-1] >= 120:
        walkable += 1
    
    print("YES" if walkable >= 2 else "NO")
```该代码逐步反映了该算法。 我们明确检查第一条消息之前、每个连续消息对之间以及最后一条消息之后的间隔。 可步行计数器捕获存在多少个有效的 120 分钟间隔。 阈值比较`>= 120`确保我们不会低估可用时间。 最后的条件只是验证是否可以安排至少两次步行。
