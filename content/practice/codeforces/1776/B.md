 ## 解决方案
 ## 问题理解

 我们被要求将一组乐高得宝 (LEGO Duplo) 积木放置在沿 x 轴的一维线上，约束条件是每块积木占据地面上的 2×2 正方形且高度为 1。紫色积木必须处于给定高度`h`在特定的 x 坐标处，我们可以在较低的 z 坐标处放置额外的支撑砖来支撑它们。 每一块不在地面上的砖块都必须以覆盖其底部的正面积的方式放置在其下方的砖块上。 目标是尽量减少所需的这些额外砖块的数量。 

输入给出`n`，紫色砖块的数量，它们的共同高度`h`，以及它们的 x 坐标的排序列表。 输出是一个整数：所需的额外砖块的最小数量。 如果`h`为零，不需要额外的砖块，因为紫色砖块已经在地上了。 否则，我们需要考虑紫色砖块之间的间隙以及较低级别的砖块如何一次支撑多于一块紫色砖块。 

一个微妙的点是每个砖块的宽度为 2，因此砖块以 x 坐标为中心`x`跨度`[x-1, x+1]`在 x 轴上。 这意味着两块砖块以`x_i`和`x_{i+1}`可能会部分重叠，如果`x_{i+1} - x_i < 2`。 由于输入保证`x_i + 1 < x_{i+1}`，每块紫色砖块之间的距离至少为 2，因此它们永远不会重叠。 这是最佳支撑它们的关键：如果放置正确，单个支撑砖可以覆盖连续的紫色砖。 

边缘情况包括所有紫色砖块都在地面上时（`h=0`），高处有一块紫色砖块`h`，以及精确间隔为距离 2 的砖块，这需要小心处理以避免计算不必要的支撑砖块。 

## 方法

 暴力方法会尝试模拟逐层堆叠砖块，检查每个 z 级别的每个可能位置是否有重叠。 对于每块紫色砖块，可以尝试在其下方的每个整数 x 坐标处放置支撑砖块，直到到达地面。 这将涉及迭代潜在的巨大 x 范围，直至`10^9`和高度可达`10^9`。 显然，这是不可行的，因为`n`虽然最多只有 300 个，但坐标范围却很大。 我们不能迭代位置； 我们必须直接处理紫色砖块的位置。 

关键的观察是每块砖的宽度为 2，并且每块紫色砖必须由下面的一块砖支撑，该砖的 2 单元底部与其自身重叠。 支撑砖的最小数量取决于我们如何在每个下层用单个支撑砖覆盖连续的紫色砖。 因为`x_i + 1 < x_{i+1}`，列表中连续的任何紫色砖块至少相距 2 个单位，因此，如果放置最佳，一块砖有时可以覆盖两个相邻的紫色砖块。 

我们可以用贪心或动态编程方法来形式化它。 定义一个段`[x_i-1, x_i+1]`对于每块紫色砖块。 然后，在每一层，我们可以用底部也跨越 2 个单位的支撑砖块覆盖尽可能多的连续紫色砖块。 由于砖块高度一致，每一层都可以独立堆叠，因此支撑砖块的最小数量减少为计算单个 2 单元砖块无法覆盖的紫色砖块之间的间隙数量。 对于身高`h`，我们将此计数乘以`h`因为每块紫色砖块的高度`h`需要`h`其下方有多层支撑。 这种见解将问题简化为基于连续 x 坐标之间间隙的简单算术计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n*h) | O(n*h) | 太慢了，不可行|
 | 间隙计数/贪心| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.如果`h`为零，则不需要支撑砖。 立即返回0。 
2. 计算紫色砖块的连续 x 坐标之间的差异：`gaps[i] = x[i+1] - x[i]`。 
3、大于2的间隙，超过2的每单位距离，至少需要一块额外的支撑砖。具体来说，对于间隙`g`，我们需要`g-2`支撑砖块以在每一层桥接它。 正好 2 的间隙不需要额外的砖块，因为单个 2 单元砖块可以覆盖两块紫色砖块。 
4. 将所有间隙所需的支撑砖加起来。 令这个总和为`needed_per_layer`。 
5. 乘法`needed_per_layer`经过`h`计算达到紫色砖块高度所需的层数。 
6.输出额外砖块的总数。 

为什么有效：通过关注砖块的 x 投影并利用固定宽度 2，我们将 3D 堆叠问题简化为 1D 间隙覆盖问题。 每层都是独立的，因为下面的砖块支撑相同的跨度，并且每层所需的砖块数量完全由紫色砖块之间的距离决定。 乘以`h`考虑垂直堆叠。 这保证了支撑砖块的最少数量，因为任何较小的配置都会留下一些紫色砖块不受支撑。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, h = map(int, input().split())
x = list(map(int, input().split()))

if h == 0:
    print(0)
    exit()

additional_bricks = 0
for i in range(n - 1):
    gap = x[i+1] - x[i]
    if gap > 2:
        additional_bricks += gap - 2

print(additional_bricks * h)
```该代码首先检查地面上有紫色砖块的小情况。 然后它迭代连续的紫色砖块，计算间隙，并计算每个间隙需要多少支撑砖块。 最后，它将计数乘以`h`用于垂直堆叠并打印结果。 这`gap - 2`公式确保砖块仅填充紫色砖块之间未覆盖的空间。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, h = map(int, input().split())
    x = list(map(int, input().split()))
    if h == 0:
        return "0"
    additional_bricks = 0
    for i in range(n - 1):
        gap = x[i+1] - x[i]
        if gap > 2:
            additional_bricks += gap - 2
    return str(additional_bricks * h)

# provided samples
assert run("4 0\n2 7 11 13\n") == "0", "sample 1"
assert run("4 2\n2 7 11 13\n") == "10", "custom for h=2"

# custom cases
assert run("1 5\n10\n") == "0", "single brick needs no support"
assert run("2 3\n1 4\n") == "3", "two bricks spaced by 3 units, 3 layers"
assert run("3 1\n2 5 8\n") == "3", "three bricks spaced by 3 units each, 1 layer"
assert run("3 0\n1 2 3\n") == "0", "height zero, no additional bricks"
