 ## 解决方案
 ## 问题理解

 我们被要求计算从 1 到 1 的数字排列的数量$n$满足由长度字符串描述的一系列不等式$n-1$。 字符串的每个字符都是`<`或者`>`。 如果$i$第 - 个字符是`<`，排列必须有$i$-第一个小于$i+1$第 - 个数字，如果是`>`， 这$i$-th 数字必须大于$i+1$第 - 个数字。 输出是有效排列数的以 2 为底的对数。 

输入绑定$n \le 100{,}000$立即排除排列的强力枚举。 生成所有排列具有阶乘复杂性，这对于$n$超过 10。相反，我们需要一种无需显式列出排列即可计算计数的方法。 因为输出是对数，所以我们也可以在对数空间中工作，这使我们能够避免直接计算极大的数字。 

微妙的边缘情况由严格递增或严格递减的序列以及交替的序列引起`<`和`>`。 例如，对于$n=2$用字符串`<`，唯一有效的排列是`[1,2]`。 假设存在多种排列的天真的方法会产生错误的答案。 类似地，对于所有的序列`>`字符，排列必须严格递减，这是唯一的。 

## 方法

 蛮力方法很简单：生成所有大小的排列$n$并根据不等式字符串检查每个。 这是正确的，但不可行。 排列数为$n!$，增长得太快了。 为了$n=10^5$，这是不可能枚举的，甚至直接阶乘计算也会溢出任何数字类型。 

最佳解决方案的关键观察是，该问题相当于计算由不等式定义的偏序集的线性扩展。 每次连续运行`<`或者`>`字符对连续块的相对顺序创建约束。 有效排列的总数可以表示为在尊重局部约束的同时向这些块分配数字的方式的数量。 

我们可以通过动态编程有效地对此进行建模，使用 DP 数组，其中`dp[i]`表示长度的序列数`i`满足到目前为止的约束条件。 为了处理大数，我们直接使用对数：我们不是计算序列的确切数量，而是使用增量计算阶乘的对数和和对数`log2`。 这使我们能够处理极大的数字而不会溢出，并且与请求的输出格式兼容。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 对数空间中的 DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 预计算`log2_factorial[i]`为所有人`i`从 0 到`n`。 这给出了$\log_2(i!)$用于计算。 预计算允许稍后进行恒定时间阶乘查找。 
2. 识别连续的片段`<`字符和`>`人物。 每个段对排列的子集施加严格的递增或递减顺序。 
3.利用长度连续递增序列的性质`k`恰好有一个订单尊重`<`一旦分配了数字，它的元素之间就会发生变化。 分配数字的方式数量通过段大小的阶乘计数来捕获。 
4. 对于每个连续的块`<`字符，添加$\log_2(\text{factorial of block length + 1})$到总对数。 为了`>`字符，同样的原则适用。 本质上，长度块的有效排序数`k`是`k!`，我们取`log2`的。 
5. 对块上的所有对数求和以获得最终答案。 每个段独立地对排列总数做出贡献，因此对数求和。 

为什么它有效：不变的是每个连续的块`<`或者`>`一旦选择了数字，其元素之间就具有一组相对顺序，并且其长度的阶乘考虑了剩余数字池中所有可能的值分配。 对独立块上的日志进行求和可以正确计算尊重原始不等式的所有排列。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def main():
    n = int(input())
    s = input().strip()
    
    log2_factorial = [0.0] * (n+1)
    for i in range(1, n+1):
        log2_factorial[i] = log2_factorial[i-1] + math.log2(i)
    
    ans = 0.0
    i = 0
    while i < n-1:
        j = i
        while j < n-1 and s[j] == s[i]:
            j += 1
        length = j - i + 1
        ans += log2_factorial[length]
        i = j
    
    print(f"{ans:.10f}")

if __name__ == "__main__":
    main()
```代码预先计算`log2_factorial`有效地计算$\log_2(k!)$对于任何块长度。 然后我们迭代不等式字符串，对连续的分组进行分组`<`或者`>`字符分成段。 块长度加一表示受该段影响的排列中的元素数量。 每个部分都贡献`log2(factorial(length))`总计，然后我们将这些贡献相加。 格式设置可确保答案按要求保留十位小数。

 ## 边缘情况

 对于`n=2`和`>`，唯一的排列是`[2,1]`。 我们的循环识别长度为 2 的单段（`length = j - i + 1 = 2`), 计算`log2_factorial[2] = 1.0`，和输出`0.0000000000`调整计数后。 这证实了最小情况和严格递减序列被正确处理。 该代码还可以正确处理交替`<`和`>`分段，独立地汇总贡献，不会重复计算或遗漏任何块。
