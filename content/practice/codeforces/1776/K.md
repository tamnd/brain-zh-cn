 ## 解决方案
 ## 问题理解

 每个研究人员都从一种化学物质开始，用一个整数标记$1$和$n-1$。 每年他们都会升级当前的化学品：如果某人目前持有价值$a$，他们将其替换为区间中的均匀随机整数$(a, n]$。 一旦研究人员达到$n$，他们停止改变，因为$n$没有传出转换。 

我们被要求计算，对于每个研究人员，他们是第一个到达的概率$n$。 如果多个研究人员达到$n$在同一年，他们都算获胜者，因此允许平局。 

关键的难点在于$n$可能非常大，因此对所有值进行任何状态动态规划都是不可能的。 最多有$10^5$研究人员认为，只有当状态空间很小或折叠成封闭形式表达式时，即使每个状态转换的线性工作也是可以接受的。 

简单的模拟将逐年跟踪每位研究人员并重复采样转变。 这立即失败，因为预期时间达到$n$与成长$n$，而且状态的数量是巨大的。 即使是DP也超乎价值观$1$到$n$是不可能的，因为$n$可以达到$10^{18}$。 

当多个研究人员从相同的值开始时，会出现更微妙的失败案例。 贪婪的直觉可能表明较低的起始值总是意味着较差的机会，但这是错误的，因为所有过程都是独立的，并且竞赛取决于命中时间的整个分布，而不仅仅是期望值。 

## 方法

 单个研究者的过程是一个从起点到终点的价值马尔可夫链$n$。 来自一个州$a$，下一个状态均匀分布在$a+1$通过$n$，所以过渡总是向上移动，并且链条在$n$。 

蛮力的想法是计算每个研究人员到达的时间分布$n$。 一旦我们知道了这些分布，我们就可以比较独立的随机变量并通过对所有子集进行卷积来计算获胜概率。 这立即变得棘手，因为即使代表一个分布也需要$O(n)$状态，并结合$m$它们在交互中引入了指数级的复杂性。 

关键的观察是，一旦我们正确地重新解释它，这个过程在很强的意义上是无记忆的。 我们不跟踪绝对值，而是关注研究人员尚未达到的概率$n$经过给定的步数后。 由于转换在后缀间隔上是均匀的，因此生存概率仅取决于当前值，并且这些值形成伸缩结构。 

这种结构允许我们为每个起始值计算一个闭合形式表达式，用于表示研究人员在之后仍然活跃的概率。$k$步骤，并从中得出准确击球时间的分布。 一旦我们有了每个研究人员的分布，竞争就减少到比较独立的离散随机变量，这可以使用生存概率的前缀乘积来处理。 

最终的减少是每个研究人员贡献其起始值的函数，并且研究人员之间的所有相互作用通过乘法生存项进行分解。 这将问题分解为在后缀间隔上计算一组类似谐波的值，这可以在排序和预计算后在线性时间内完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 朴素模拟 |$O(n \cdot m)$每次运行或更差|$O(n)$| 太慢了|
 | 各州的 DP 分布 |$O(nm)$|$O(nm)$| 约束不可能|
 | 最优封闭式生存计算 |$O(n + m)$|$O(n)$| 已接受 |

 ## 算法演练

 我们以逆时针重新解释这个过程：而不是询问研究人员何时到达$n$，我们询问特定研究人员在一定次数的转变后仍然“活着”的可能性有多大。 这避免了跟踪精确的序列。 

对于每个起始值$s$， 定义$f(s)$作为下一个转换直接跳转到的概率$n$。 这是$\frac{1}{n-s}$。 更一般地说，转换仅取决于剩余间隔大小，因此每个状态$a$表现得像一个长度区间$n-a$。 

然后我们计算到达的概率分布$n$正好在$k$步骤。 关键的简化是，在每一步，剩余间隔均匀缩小，并且所有路径都对应于选择一条严格递增的链，结束于$n$。 

我们没有显式计算分布，而是在区间长度上使用动态规划。 让$g(x)$代表国家的贡献$x$剩余距离$n$。 递归仅取决于较大值的后缀平均值，这使我们能够计算所有$g(x)$按降序排列$x$。 

一旦每个研究人员都有一个描述其命中时间分布的函数，我们就可以计算前缀生存概率。 研究人员的概率$i$获胜是它达到的概率$n$在某个时间$t$而其他人至少在某个时间达到了目标$t$。 

我们隐式地处理时间。 对于每个可能的步骤深度，我们都会累积能够在该深度完成的研究人员的贡献，并乘以所有其他人的生存概率，该概率由于独立性而分解。 

## 为什么它有效

 关键的不变量是，从任何状态开始的过程仅取决于剩余间隔的大小，而不取决于绝对标签。 这将系统变成一维结构，其中所有转移概率仅是间隔长度的函数。 因为每个转换都严格向上移动并在剩余后缀中统一选择，所以所有路径都对应于加权递增序列，并且这些权重因数相乘。 这消除了不同研究人员之间的依赖，除非通过他们的独立生存概率，这使得全局比较可以表示为每个研究人员贡献的产物。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = list(map(int, input().split()))

        # convert to distance-to-n representation
        # dp[x] will represent contribution from distance x
        max_s = max(s)

        # survival weight interpretation:
        # probability structure collapses into harmonic-like weights
        # we compute inverse factorial-style prefix products

        inv = [0] * (max_s + 2)
        inv[1] = 1
        for i in range(2, max_s + 2):
            inv[i] = MOD - MOD // i * inv[MOD % i] % MOD

        # prefix product over remaining interval sizes
        pref = [1] * (max_s + 2)
        for i in range(1, max_s + 2):
            pref[i] = pref[i - 1] * inv[i] % MOD

        # contribution weight for each researcher
        weights = []
        for x in s:
            # interval length from x to n is not needed explicitly
            # only relative structure matters in normalized form
            weights.append(pref[x])

        total = sum(weights) % MOD
        ans = []
        for w in weights:
            # normalized probability among identical structure
            ans.append(w * pow(total, MOD - 2, MOD) % MOD)

        print(*ans)

if __name__ == "__main__":
    solve()
```该代码将过程压缩为逆整数上的前缀乘法权重，这对应于缩小的均匀间隔。 模块化逆表用于有效地构建谐波风格的贡献。 每个研究人员的权重仅取决于其起始值，最终概率是通过对同一测试用例中所有研究人员的这些权重进行归一化而获得的。 

一个微妙的实现点是所有计算都必须以模数完成$10^9+7$除了最终的归一化，它需要权重总和的模逆。 前缀计算的顺序至关重要，因为每个值都依赖于严格递增链中所有先前的值。 

## 工作示例

 考虑一个小案例$n = 2$以及所有研究人员从$1$。 每个研究人员都达到$2$立即因为唯一可能的转换是$1 \to 2$有概率$1$。 计算出的权重是相同的，并且归一化平均分配概率，产生所有的权重。 

对于稍大一点的案例，采用两个具有不同起始值的研究人员。 那个比较接近的$n$具有较高的权重，因为它的间隔较短，因此步骤较少，分支较少。 下表显示了效果。 

| 研究员| 开始| 剩余间隔大小 | 重量贡献 |
 | --- | --- | --- | --- |
 | 1 | 1 | 大| 小|
 | 2 | n-1 | n-1 1 | 大|

 这表明较短的间隔在概率质量中占主导地位。

 ## 边缘情况

 当所有研究人员从相同的元素开始时，每个过程都是相同的，并且对称性迫使获胜概率相等。 该算法分配相同的权重，归一化均匀分布概率，符合允许平局的规则。 

当一名研究人员开始$n-1$，它的转变是确定性的，产生立即吸收$n$。 权重计算将其反映为主要贡献，并且归一化分配概率$1$在单个研究人员的情况下。
