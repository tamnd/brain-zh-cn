 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，表示比赛中评分的变化。 所有这些变化的总和恰好为零，这意味着在任何修改之前，收益和损失完全平衡。 

任务是将每个值独立地转换为“减半”版本。 对于每个原始值$a_i$，我们只能选择地板或天花板$a_i / 2$。 如果$a_i$是偶数，两个选择一致，所以结果是固定的。 如果$a_i$奇怪的是，我们恰好有两个相差一的候选人。 

困难不在于单独选择每个值，而在于协调这些局部选择，以便最终的变换序列之和仍然为零。 

总是将所有内容向下舍入或向上舍入的幼稚方法会立即打破全局约束。 如果我们总是采取地板，每个奇数正数与其对应的负数相比都会失去额外的质量，并且总和会漂移到零以下。 如果我们总是取 ceil，总和就会漂移到零以上。 该约束迫使我们仔细平衡舍入“额外半个单位”的去向。 

当所有数字均为奇数或正数和负数严重倾斜时，就会出现边缘情况。 例如，如果数组是`[1, 1, -2]`，天真的地板给了`[0, 0, -1]`总和为`-1`而不是`0`，而朴素的天花板给出`[1, 1, -1]`总和为`1`。 尽管每个元素单独有效，但两者都违反了要求。 

关键的挑战是每个奇数都会产生 ±0.5 的模糊度，并且必须对它们进行分配，以便抵消总的校正。 

## 方法

 如果我们忽略舍入约束，自然的想法是计算$a_i / 2$并一致地舍入一切。 这给了我们一个基本序列$b_i = \lfloor a_i / 2 \rfloor$。 这对于每个元素始终有效，但其总和不保证为零。 

当我们定义以下错误时，错误的结构就会变得清晰：$$b_i^{(0)} = \left\lfloor \frac{a_i}{2} \right\rfloor$$对于甚至$a_i$，这是准确的。 对于奇数值：

 - 如果$a_i > 0$，地板相对于真实的一半来说太小了0.5。 
- 如果$a_i < 0$，floor也太小，但“太小”意味着更负面，因此其效果在符号贡献上有所不同。 

更具体地说，每个奇数都有一个自由单位：我们可以选择将其下限值增加 1（切换到 ceil）。 这使得总和恰好增加了 1。 

那么问题就变成了：我们从一个基线总和开始，我们需要决定对某些索引是否加+1，使总和恰好为零。 

令基线为所有楼层。 设其总和为$S$。 每次我们为奇数元素选择上限而不是下限时，总和就会增加 1。我们需要准确选择$-S$合格指数之间的此类调整。 

缺少的微妙之处在于确保可行性：可用奇数元素的数量必须足以将总和调整到范围内。 问题给出的条件保证了这一点始终成立。 

这将问题转化为独立 +1 增量上的简单校正分布问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（尝试所有地板/天花板组合）|$O(2^k)$|$O(n)$| 太慢了 |
 | 最优（基线+校正分布）|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们分两个阶段构建答案：默认分配阶段和受控修正阶段。 

1. 计算$b_i = \lfloor a_i / 2 \rfloor$对于所有元素。 
2. 计算总和$S = \sum b_i$。 
3. 确定所有索引$a_i$很奇怪。 
4. 每个这样的索引都允许增加$b_i$如果需要的话加 1。 
5. 现在我们需要通过精确分配来确定总和$-S$增量。 
6. 迭代奇数索引并对它们应用 +1$b_i$值，直到校正量耗尽。 
7. 输出结果数组。 

关键的决定是第 6 步：我们不关心选择哪些奇怪的元素，只关心我们恰好消耗了所需的校正预算。 任何分布都有效，因为每个增量对总和具有相同的影响。 

### 为什么它有效

 不变的是初始化后，每个元素都处于其最小允许值。 仅通过将选定的奇数位置增加 1 即可从此基线达到任何有效的解决方案，并且每次增加都会将总和精确地改变 +1，而不违反每个元素的约束。 由于所需的总调整恰好是基线总和与零之间的差值，并且每次调整都是单位大小且独立适用的，因此在问题保证可行性的情况下，校正单位的贪婪消耗不会超调或下调。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]

    b = [x // 2 for x in a]
    s = sum(b)

    need = -s

    # collect indices where we can add +1 safely (odd numbers)
    odd_idx = []
    for i, x in enumerate(a):
        if x % 2 != 0:
            odd_idx.append(i)

    for i in odd_idx:
        if need == 0:
            break
        # applying ceil instead of floor adds +1
        b[i] += 1
        need -= 1

    print(*b)

if __name__ == "__main__":
    solve()
```实现直接遵循构造逻辑。 整数除法`x // 2`在 Python 中正确生成正整数和负整数的下限行为，这在这里至关重要。 然后，我们计算基线距零的距离，并使用可用的奇数位置来修复它。 

循环结束`odd_idx`是安全的，因为每次调整都会将剩余的不平衡减少一个单位。 问题保证确保我们永远不会用完符合条件的指数。

def run(inp: str) -> str:

    import sys

    a = [int(input()) for _ in range(n)]

 ## 边缘情况

 一种微妙的情况是所有数字都是偶数。 在这种情况下，每个值在减半后都是固定的，因此由于原始约束，基线之和已经为零。 该算法计算`need = 0`并且不执行任何调整，使数组保持不变，这是正确的。 

另一种情况是所有数字都是奇数。 然后每个指标都可以进行修正。 由于初始不平衡必须是整数，并且每次校正都精确调整 1，因此循环只是在所有指数之间任意分配校正，直到恢复平衡，永远不会耗尽容量。 

更具欺骗性的情况会出现严重扭曲的负面因素，例如`[-1, -1, 2]`。 基线产生`[ -1, -1, 1 ]`总结为`-1`，因此需要进行一次修正。 只有奇数索引是前两个，将其应用于任一索引都会产生有效的平衡结果。
