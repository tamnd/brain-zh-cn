 ## 解决方案
 ## 问题理解

 我们得到了进入隧道的汽车的时间线和离开隧道的相同汽车的单独的时间线。 每辆车在每个列表中只出现一次，因此两个序列都是同一组标识符的排列。 

在隧道内，只能间接检测到超车。 如果一辆车较晚进入但较早退出，则认为它肯定超过了另一辆车。 任务是统计有多少辆汽车至少有一个这样的“倒车伙伴”，这意味着它们至少负责一次强行超车事件。 

输入提供两种大小排列$n$。 第一个描述了进入顺序，第二个描述了退出顺序。 输出是至少一对中充当“后进入、先退出”元素的汽车数量。 

约束条件$n \le 10^5$排除所有汽车对的任何二次成对比较。 一个天真的$O(n^2)$检查所有对将涉及最多$10^{10}$比较，远远超出了时间限制。 我们需要对问题进行线性或近线性变换。 

当根本没有汽车违反顺序时，就会出现微妙的边缘情况。 例如，如果进入和退出命令相同，则任何车辆都不会被罚款。 即使在这种完全一致的情况下，将“位置之间的任何不匹配”误解为违规的幼稚方法也会错误地计算汽车数量。 另一个棘手的情况是，当每辆车都相对于退出顺序严重倒置时，在这种情况下，多辆车可能会被罚款，但即使每辆车参与许多倒置对，它仍然应该只被计算一次。 

## 方法

 暴力解决方案检查每对汽车$(i, j)$。 对于每一对，我们确定是否有人较晚进入并较早退出。 如果是这样，我们会将后来进入的车辆标记为罚款。 这直接根据定义起作用并且是正确的，因为它显式地测试了所有反转条件。 

然而，这种方法需要检查所有$\binom{n}{2}$对。 每张支票都是$O(1)$，所以总复杂度是$O(n^2)$。 和$n = 10^5$，这是完全不可行的。 

关键的观察是我们实际上不需要检查所有对。 相反，我们可以使用位置来对齐两个序列。 如果我们将每辆车映射到退出顺序中的索引，那么进入序列就变成了退出位置的数组。 那么问题就变成了：确定索引$i$这样就存在后面的索引$j > i$具有较小的值。 换句话说，我们正在寻找数组具有“未来最小违规”的位置。 

这将问题简化为扫描转换后的数组并检查每个元素是否大于其右侧的某个元素。 我们可以通过维持从右侧看到的最小值来有效地做到这一点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 构建从汽车 ID 到其在退出顺序中的位置的映射。 这让我们可以用其出口索引替换入口序列中的每辆车，将问题转换为单个数值数组。 超车的结构仅取决于出口的相对顺序，因此这种转换保留了所有条件。 
2. 构造数组`pos`在哪里`pos[i]`是当时进入的汽车的出口位置$i$。 这将问题转换为查找后面的元素较小的索引。 
3. 遍历`pos`从右到左，同时保持迄今为止所见的最小出口位置。 该值代表“比左边的人更早退出”的最佳候选值。 
4. 对于每个索引$i$， 比较`pos[i]`具有最小后缀值。 如果`pos[i]`较大，说明有车按进场顺序排在它之后，先退出，所以这辆车必须被罚款。 
5. 统计所有此类索引并返回结果。 

### 为什么它有效

 将条目顺序映射到退出位置后，违规恰好对应于数组中的反转：较早的条目比后面的条目具有更大的退出索引。 从右向左扫描保持了后缀最小值是所有后来进入的汽车中最早退出的不变式。 如果当前元素大于这个最小值，则保证存在后进先出的汽车，这符合确定超车事件的定义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    pos = [0] * (n + 1)
    for i, car in enumerate(b):
        pos[car] = i

    arr = [pos[car] for car in a]

    mn = n + 1
    ans = 0

    for i in range(n - 1, -1, -1):
        if arr[i] > mn:
            ans += 1
        mn = min(mn, arr[i])

    print(ans)

if __name__ == "__main__":
    solve()
```解决方案首先构建出口位置图`pos`，它将每个汽车 id 转换为其出口索引。 然后它将输入序列转换为`arr`，其中比较变成纯粹的数字。 

变量`mn`存储从右侧到目前为止看到的最小退出索引。 这很重要，因为它代表了后来进入的汽车中最早退出的汽车。 如果当前车辆在此最小值之后退出，则意味着至少有一辆后来的车辆发生明确的反转。 

条件`arr[i] > mn`是算法的核心，直接编码超车规则。

 ## 边缘情况

 当进入和退出顺序相同时，变换后的数组将严格递增。 后缀最小条件永远不会触发，因此答案为零。 该算法正确地维护了这一点，因为每个元素始终小于或等于未来的最小值。 

当退出顺序相对于进入完全相反时，每个较早的进入都有许多具有较小退出索引的较晚进入。 后缀最小值提前变为零并保持在那里，导致每个足够大的元素都被计数，正确地将大多数汽车标记为罚款。 

当只有一对在本地反转时，例如在其他排序排列中的单个交换，只有交换之前的元素将超过后面的后缀最小值。 扫描精确地隔离了该位置，确保不会出现过度计数。
