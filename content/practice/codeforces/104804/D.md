 ## 解决方案
 ## 问题理解

 我们得到一个包含有限多重令牌集的袋子。 这些令牌中，有的是特殊的“骑士”令牌，其余的是普通令牌。 玩家从这个袋子中统一随机抽取固定数量的代币，无需更换。 

任务是计算至少一个抽取的标记是骑士的概率。 

更具体地说，我们正在对大小的子集进行采样$m$来自一个大小的宇宙$n$，具体在哪里$k$元素被标记为成功（骑士）。 每个尺寸子集$m$是同样有可能的。 我们想要所选子集与骑士集合相交的概率。 

限制非常小：$n \le 20$和$m \le 20$。 这立即表明组合枚举或使用二项式系数的直接计算是完全足够的。 不需要近似、模拟或渐近优化组合。 

出现微妙的边缘情况时$m \ge n$。 在这种情况下，每个令牌都会被抽取，因此概率变为 1，如果$k > 0$，或 0 如果$k = 0$。 另一个极端情况是$k = 0$，当不存在骑士时，不管怎样，概率都为 0$m$。 在另一个极端，如果$k \ge 1$和$m = n$，答案正好是1。 

简单的蒙特卡洛模拟会收敛得太慢并引入精度问题。 另一个常见的错误是假设抽取的独立性，这是不正确的，因为抽样是没有放回的。 

## 方法

 蛮力方法是枚举大小的所有子集$m$从$n$元素，检查每个子集是否至少包含一名骑士，并计算有多少是有效的。 子集总数为$\binom{n}{m}$，在最坏的情况下在附近最大化$n = 20, m = 10$, 给予$\binom{20}{10} = 184,756$。 这个值足够小，可以直接进行暴力破解，所以正确性是立竿见影的。 

然而，暴力破解隐藏了问题的真正结构。 关键的观察是，我们不需要考虑个人安排，只需计算抽签中包含多少个骑士即可。 与直接计算有利子集不同，计算补集事件更简单：绘制零骑士。 该事件对应于选择所有$m$代币来自$n-k$非骑士令牌。 这将问题简化为单一组合比率。 

概率变为：$$P(\text{at least one knight}) = 1 - \frac{\binom{n-k}{m}}{\binom{n}{m}}$$按照惯例$\binom{a}{b} = 0$什么时候$b > a$。 

这种变换完全避免了枚举子集，并用评估一些二项式系数来代替问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举|$O(\binom{n}{m} \cdot m)$|$O(m)$| 已接受但没有必要 |
 | 补集+组合学|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 ### 逐步计算

 1. 读取整数$n$,$k$， 和$m$。 它们分别定义了总池数、成功数量和样本大小。 
2、先处理小事。 如果$k = 0$，由于不存在成功元素，因此立即返回 0。 如果$m \ge n$，如果返回 1$k > 0$，否则为 0。这可以避免以后出现无效的组合表达式。 
3. 计算非骑士代币的数量，即$n - k$。 这代表“仅限安全”池。 
4. 计算只抽到非骑士的概率，即：$$\frac{\binom{n-k}{m}}{\binom{n}{m}}$$该比率反映了选择所有$m$专门来自非骑士的物品。 
5. 用 1 减去该值即可得到至少一名骑士存在的概率。 
6. 以足够的精度打印结果，通常至少有 8 位小数，以满足 1e-4 精度要求。 

### 为什么它有效

 该算法划分了所有可能的$m$- 大小的子集分为两个不相交的类别：包含至少一名骑士的类别和不包含任何骑士的类别。 这两个事件覆盖了整个样本空间，没有重叠。 补充事件“没有选择骑士”更容易计数，因为它将选择完全限制为尺寸的缩小子集$n-k$。 由于大小的所有子集$m$等概率，概率恰好是有利子集计数的比率，保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import comb

def solve():
    n, k, m = map(int, input().split())

    if k == 0:
        print("0.0")
        return

    if m >= n:
        print("1.0")
        return

    total = comb(n, m)
    if n - k < m:
        no_knight = 0
    else:
        no_knight = comb(n - k, m)

    ans = 1.0 - no_knight / total
    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```该实现直接依赖于 Python 的内置组合函数，该函数对于这些约束是稳定且精确的。 早期退出处理退化情况，否则二项式系数将为零或在天真的意义上未定义。 

唯一的微妙之处是确保案件的正确处理$n-k < m$，无法选择的地方$m$非骑士，使得“没有骑士”的概率为零。

 ## 边缘情况

 一种重要的边缘情况是没有骑士时。 用于输入`5 0 3`，该算法在任何组合之前立即返回 0。 任何忘记这一点的基于公式的实现仍然可以计算比率，但存在划分工件或不必要的计算的风险。 

另一种情况是当拉伸尺寸等于袋子尺寸时，例如`5 2 5`。 补集概率变为零，因为如果至少存在一个骑士，则无法避免选择骑士。 该算法正确触发`m >= n`分支并返回 1。 

当非骑士太少而无法满足抽签规模时，就会出现第三种情况。 例如，`6 4 4`只剩下2名非骑士了。 计算`comb(2,4)`被视为零，正确地暗示每次有效抽签都必须包含一名骑士，产生概率 1。
