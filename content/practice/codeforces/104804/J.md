 ## 解决方案
 ## 问题理解

 我们给出一个连通的无向图，其中$N$顶点和$N$边缘。 每条边代表两个岛屿之间的双向渡轮路线。 即使边的数量等于顶点的数量，图也保证保持连接。 

任务是确定哪些轮渡路线可以安全删除，同时仍保持图表连接。 如果删除一条路线后，每个岛屿仍然可以通过剩余路线到达其他所有岛屿，则该路线被认为是安全的。 

用图的术语来说，我们被要求找到所有不是桥的边。 桥是一条边，删除它会断开图的连接。 由于我们希望在删除选定的边后保持连接性，因此那些不是桥的边正是有效的答案。 

约束条件很大，有$N \le 10^5$。 这立即排除了任何尝试删除每个边缘并使用 DFS 或 BFS 运行完整连接检查的方法，因为这会花费$O(N^2)$在最坏的情况下，远远超出可接受的限度。 解通常必须是线性或接近线性的$O(N)$或者$O(N \log N)$。 

微妙的边缘情况来自循环和多循环结构的存在。 因为该图正好有$N$边 且相连，则必须至少包含一个环。 如果图是单循环，则删除任何边仍然会留下连接所有节点的路径。 在这种情况下，每条边都是有效的。 如果图形包含桥，则只有循环内的边仍然有效。 

一个天真的陷阱是假设删除循环中的任何边缘总是安全的，而不验证该循环是否是依赖于该边缘进行连接的更大结构的一部分。 例如，在形状像由一条边连接的两个循环的图中，该连接边是一座桥，即使它位于循环分量之间。 

## 方法

 直接的暴力方法是独立测试每个边缘。 对于每条边，我们将其删除并从任何节点运行 DFS 或 BFS 以检查所有节点是否仍然可达。 这可以正确识别边缘是否是桥，因为移除后的连接直接对该属性进行编码。 

然而，每次连接检查的成本$O(N)$，我们执行它的目的是$N$边缘，给予$O(N^2)$总时间。 和$N = 10^5$，这变成了$10^{10}$的操作，这是不可行的。 

关键的观察结果是，问题简化为识别无向图中的桥。 这是一个经典的结构属性，可以使用具有发现时间和低链接值的 DFS 在线性时间内计算。 这个想法是在 DFS 遍历期间使用后边跟踪每个节点的最早可到达的祖先。 如果一条边无法到达其父子树的任何祖先，那么它就是一座桥。 

这在这里特别有效，因为图保证是连通的并且具有精确的$N$边，但寻桥算法并不依赖于这一事实。 它适用于任何无向图$O(N + M)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（移除边缘 + BFS）|$O(N^2)$|$O(N)$| 太慢了 |
 | DFS 低链路桥查找 |$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们通过使用带时间戳的 DFS 遍历查找所有桥来解决该问题。 

1. 为图构建邻接列表，存储每条边的标识符（索引）。 我们需要边 ID，因为必须区分多条边，即使顶点可能重复。 
2. 维护数组`tin`和`low`， 在哪里`tin[v]`是节点的时间$v$在 DFS 中首先被访问，并且`low[v]`是最小的`tin`可从 到达$v$使用零个或多个树边，后跟最多一个后边。 我们跟踪这一点的原因是为了检测子树是否可以在不使用给定边缘的情况下向上“逃逸”。 
3. 从任意节点运行 DFS，因为图已连接。 当我们访问节点时分配递增的时间戳。 
4. 在从节点进行 DFS 期间$v$，探索每个邻居$to$。 如果`to`是 DFS 中的父级，跳过它以避免琐碎的回溯。 
5. 如果`to`未访问过，递归DFS进去，然后更新`low[v] = min(low[v], low[to])`。 返回后检查是否`low[to] > tin[v]`。 如果这个成立，那么边缘$(v, to)$是一座桥，因为子树的根位于`to`无法到达任何祖先$v$不使用此边缘。 
6. 如果`to`已被访问且不是父边，更新`low[v] = min(low[v], tin[to])`。 这记录了提高可达性的后沿。 
7. DFS完成后，所有从未标记为桥的边正是删除后保持图连通的边，因此我们输出它们。 

### 为什么它有效

 DFS 树将边划分为树边和后边。 根为的子树$to$删除边后仍与图的其余部分保持连接$(v, to)$当且仅当它的后边缘到达某个祖先$v$。 这`low`value 捕获了可达到的最高祖先。 如果`low[to]`严格大于`tin[v]`，那么子树中没有后边到达$v$或以上，意味着与图的其余部分的唯一连接是边$(v, to)$。 这正是桥的定义，因此这个条件既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
adj = [[] for _ in range(n)]

edges = []

for i in range(n):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append((v, i))
    adj[v].append((u, i))
    edges.append((u, v))

tin = [-1] * n
low = [0] * n
vis = [False] * n
is_bridge = [False] * n
timer = 0

def dfs(v, pe):
    global timer
    vis[v] = True
    tin[v] = low[v] = timer
    timer += 1

    for to, eid in adj[v]:
        if eid == pe:
            continue
        if tin[to] == -1:
            dfs(to, eid)
            low[v] = min(low[v], low[to])
            if low[to] > tin[v]:
                is_bridge[eid] = True
        else:
            low[v] = min(low[v], tin[to])

dfs(0, -1)

res = []
for i in range(n):
    if not is_bridge[i]:
        u, v = edges[i]
        res.append((u + 1, v + 1))

print(len(res))
for u, v in res:
    print(u, v)
```该实现使用带有全局计时器的标准递归 DFS 来分配发现时间。 每条边都通过其索引进行跟踪，以便我们稍后可以将其标记为桥或不桥。 数组`is_bridge`存储必须从输出集中删除哪些边。 

一个微妙的细节是在 DFS 中使用边 ID 处理父边`pe`。 这可以防止错误地将直接 DFS 树边缘视为后边缘。 另一个重要的细节是递归深度，因为$10^5$节点需要增加递归限制。 

最后，由于图保证连接，因此来自节点 0 的单个 DFS 调用就足够了。 

## 工作示例

 ### 示例 1

 输入：```
4
2 1
2 3
2 4
1 3
```我们从节点 1 开始构建 DFS（内部索引为 0）。 遍历顺序和低链接更新的行为如下。 

| 步骤| 节点| 锡 | 低| 检测到桥 |
 | ---| ---| ---| ---| ---|
 | 访问 1 | 0 | 0 | 0 | 没有 |
 | 访问 2 | 1 | 1 | 1 | 没有 |
 | 访问 3 | 2 | 2 | 2 | 没有 |
 | 后沿 (2-0) | 2 | 2 | 0 | 没有 |
 | 完成 2 | 1 | 1 | 0 | 没有 |
 | 访问 4 | 3 | 3 | 3 | 没有 |
 | 完成 DFS | - | - | - | 边 2-4 是桥候选检查 |

 循环 1-2-3 内的边保持安全，而形成替代连接的边则被保留。 结果匹配除充当组件的唯一分隔符的边缘之外的所有边缘。 

输出：```
3
1 2
2 3
3 1
```这表明属于循环的边幸存下来，而任何删除断开子树的边都将无法满足低链接条件。 

### 示例 2

 输入：```
3
1 2
2 3
3 1
```这是一个简单的循环。 

| 步骤| 行动| 低比较| 桥？ |
 | ---| ---| ---| ---|
 | DFS遍历| 所有访问过的节点 | 后边缘无处不在| 没有 |

 每个节点都有一个指向 DFS 树中较早节点的后边缘，因此每个节点`low[to]`变得等于某个祖先，永远不会超过`tin[v]`。 因此没有边满足桥接条件。 

输出：```

2 3
3 1
```这证实了在纯循环中，每个边缘都可以安全地移除。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline
    sys.setrecursionlimit(10**7)

    n = int(input())
    adj = [[] for _ in range(n)]
    edges = []

    for i in range(n):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, i))
        adj[v].append((u, i))
        edges.append((u, v))

    tin = [-1] * n
    low = [0] * n
    is_bridge = [False] * n
    timer = 0

    def dfs(v, pe):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, eid in adj[v]:
            if eid == pe:
                continue
            if tin[to] == -1:
                dfs(to, eid)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    is_bridge[eid] = True
            else:
                low[v] = min(low[v], tin[to])

    dfs(0, -1)

    out = []
    for i in range(n):
        if not is_bridge[i]:
            u, v = edges[i]
            out.append((u+1, v+1))

    return str(len(out)) + "\n" + "\n".join(f"{u} {v}" for u, v in out)

 ## 边缘情况

 纯循环是最简单的边缘情况。 在这样的图中，每个节点都有一条通往其他每个节点的替代路线，以避免任何单边。 在 DFS 期间，每个节点都会找到较早祖先的后边缘，因此`low`值崩溃到尽可能的最小值，防止触发任何桥接条件。 该算法正确地将所有边缘标记为安全。 

恰好具有一条附加边的树状结构是另一种重要情况。 考虑一条线$1-2-3-4-5$加上额外的边缘$2-4$。 线上的边大部分是桥，但弦在节点 2、3、4 周围创建了一个循环。DFS 检测到该循环内的边不符合桥条件，而外边仍然满足桥条件。 输出正确地仅包括非桥边缘。 

最后一个微妙的情况是当一个顶点有多个连接形成重叠循环时。 该算法自然地处理这个问题，因为`low`值传播最小可达祖先，确保子树中任何位置的任何替代路径都可以防止沿该路径的所有边的桥接分类。
