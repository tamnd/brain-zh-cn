 ## 问题理解

 我们在平面上得到三个点，每个点都由整数坐标描述。 保证这些点不在同一条直线上，因此它们形成一个有效的三角形。 任务是构造穿过所有三个点的唯一圆并计算其半径。 

从几何角度来说，这是要求由三个顶点定义的三角形的外接半径。 输出是一个实数，即外接圆的半径，以足够的精度打印。 

约束很小：坐标是绝对值最多为 1000 的整数。这立即告诉我们，如果小心处理，任何涉及成对距离或面积的算术在浮点中都是安全的。 无需担心超出标准 64 位安全性的整数溢出问题，并且由于我们只处理一个三角形，因此没有性能压力。 

主要的微妙故障案例来自退化或数值不稳定的配置，而不是性能。 

第一种边缘情况是三角形几乎退化，这意味着这些点非常接近共线。 尽管该问题保证非共线性，但面积可能非常小，这会放大除以面积的公式中的浮点误差。 

例如，考虑以下几点：```
(0, 0)
(1000, 1)
(2000, 2)
```这是严格不允许的，因为它们是共线的，但接近共线的有效情况如下：```
(0, 0)
(1000, 1)
(2000, 3)
```产生一个非常大的外接圆半径。 任何除以三角形面积的公式都必须小心处理小分母。 

另一个问题是平方距离与实际距离的错误使用。 如果解决方案在中间步骤中忘记了平方根或混合了平方和非平方数量，它将默默地产生错误的缩放。 

## 方法

 强力几何方法将尝试通过找到两条边的垂直平分线的交点来明确构造外接圆。 每个平分线都是一条线，因此我们计算中点、斜率，然后求解 2x2 线性系统。 这是正确的并且概念上简单，但它引入了垂直线的多重划分和特殊情况。 当坡度很大或几乎相等时，它还存在数值不稳定的风险。 

更稳健的见解是完全避免显式构造圆心。 相反，我们使用三角形外接圆半径的直接公式。 如果三角形有边长$a$,$b$,$c$，和面积$S$，那么外接圆半径是$$R = \frac{abc}{4S}.$$这是关键的简化。 三角形结构仅通过距离和面积就为我们提供了所需的一切，避免了坐标几何边缘情况，例如垂直平分线相交。 

我们使用欧几里德距离计算边长，并使用两条边的叉积计算面积。 叉积直接给出两倍的面积，这样就不需要海伦公式并减少数值误差。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 垂直平分线| O(1) | O(1) | O(1) | O(1) | 由于精度和特殊情况而存在风险 |
 | 距离+面积公式| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读三点$A(x_1, y_1)$,$B(x_2, y_2)$， 和$C(x_3, y_3)$。 它们在平面中定义了一个三角形。 
2. 计算边长$a = BC$,$b = CA$， 和$c = AB$使用欧几里德距离。 每个都被计算为坐标差平方的平方根。 这是必要的，因为外接圆半径公式取决于实际的几何长度，而不是平方值。 
3. 计算三角形面积$ABC$使用叉积：$$S = \frac{1}{2} |(B - A) \times (C - A)|.$$叉积给出了两倍的有符号面积，并且无论方向如何，取绝对值都可以确保正值。 
4. 使用以下方法计算外接圆半径：$$R = \frac{a \cdot b \cdot c}{4S}.$$该公式来自标准三角形几何，避免显式求解圆心。 
5. 打印$R$具有足够的浮点精度，通常至少有 5 到 10 位小数才能满足要求。 

### 为什么它有效

 三角形的外接圆由其三个顶点唯一确定。 公式$R = \frac{abc}{4S}$由三角形面积与其外接圆之间的关系推导出来。 叉积根据坐标正确计算出精确的几何面积，欧几里德距离给出了精确的边长。 由于所有计算都是直接从三角形的几何不变量导出的，因此无论坐标顺序或方向如何，任何一致的实现都必须产生相同的半径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def dist(x1, y1, x2, y2):
    return math.hypot(x1 - x2, y1 - y2)

x1, y1 = map(int, input().split())
x2, y2 = map(int, input().split())
x3, y3 = map(int, input().split())

a = dist(x2, y2, x3, y3)
b = dist(x1, y1, x3, y3)
c = dist(x1, y1, x2, y2)

cross = abs((x2 - x1) * (y3 - y1) - (y2 - y1) * (x3 - x1))
area = cross / 2.0

R = (a * b * c) / (4.0 * area)

print(R)
```实现直接遵循算法结构。 这`math.hypot`使用函数代替手动平方和平方根，因为它在数值上更加稳定，并且避免了中间平方时的溢出或精度损失。 

叉积是根据源自第一个点的两个向量计算的。 这避免了任何角度计算或三角函数的需要。 除以 2 将平行四边形区域转换为三角形区域。 

最终公式完全按照推导出来应用。 划分由$4 \cdot area$是安全的，因为该问题保证了非共线性，因此面积严格为正。

 ## 边缘情况

 近乎退化的三角形是主要的应力情况。 例如：```
0 0
1000 1
2000 3
```该算法计算非常小的叉积，从而导致很大的半径。 这些步骤仍然表现正确，因为面积是直接从行列式公式导出的，该公式在整数运算下保持稳定，直到最终除法。 

计算过程如下。 叉积非零，因此面积为正。 边长通常通过欧几里德距离计算。 最后的除法放大了结果，但不会破坏正确性，只是精度可能需要仔细的浮点处理。 

这证实，只要排除共线性，即使三角形变得非常薄，该方法也是稳健的。
