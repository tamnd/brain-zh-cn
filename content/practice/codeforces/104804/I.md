 ## 解决方案
 ## 问题理解

 给定一个数组，我们首先形成该数组的所有前缀和。 如果数组是`a`，然后我们构建一个新序列`s`在哪里`s[i]`是第一个的总和`i`元素。 之后，我们考虑此前缀和序列中所有不同元素对并将它们相乘。 任务是计算所有此类成对乘积的总和，然后对结果取模`M`， 在哪里`M`保证是 2 的幂。 

所以输入是一个整数数组和一个模数。 输出是一个数字，代表所有的总和`i < j`的`s[i] * s[j]`, 减少模数`M`。 

约束条件允许`N`最多 30000。对前缀和的二次扫描太大，因为在最坏的情况下将涉及大约 4.5 亿次乘法。 这在优化的 C++ 中已经处于边缘，并且在 Python 中显然是不可接受的。 这立即推动我们对表达式进行线性或近线性变换。 

模数是 2 的幂也是一个强烈的结构暗示。 这意味着我们正在有效地进行固定宽度整数算术，其中溢出行为对应于位掩码。 这通常允许使用整数恒等式进行简化，而不必担心除法或模逆。 

一些边缘行为值得关注。 

如果`N = 1`，不存在前缀和对，因此答案必须为零。 错误地初始化累加器或假设至少存在一对累加器的幼稚实现很容易产生垃圾。 

如果所有元素都为零，则所有前缀和都为零，因此答案必定为零。 这会捕获意外使用部分产品而不进行零检查的实现。 

如果前缀和变大（高达 3e8），中间乘积可能会超过 32 位范围，因此任何依赖固定宽度整数而没有适当注意的方法都会在没有大整数的语言中溢出。 Python 在这里是安全的，但公式推导仍然很重要。 

## 方法

 蛮力的想法很简单。 我们计算所有前缀和`s[i]`，然后迭代所有对`(i, j)`和`i < j`, 乘法和累加`s[i] * s[j]`。 这是正确的，因为它完全符合定义。 然而，它需要存储所有前缀和并大致执行`N^2 / 2`乘法。 和`N = 30000`，这太慢了。 

关键的观察是我们实际上不需要枚举对。 我们想要的表达，$$\sum_{i < j} s_i s_j$$是序列上的标准对称和。 可以使用恒等式重写$$\left(\sum s_i\right)^2 = \sum s_i^2 + 2 \sum_{i < j} s_i s_j.$$如果我们可以计算前缀和及其平方和，那么这会将成对和转换为可在线性时间内计算的值。 

那么问题就简化为在线维护前缀和。 我们甚至不需要显式存储整个前缀数组。 我们可以计算`s[i]`即时保存所有前缀和的运行总计以及它们的平方的运行总计。 

一旦我们有了这两个累加器，我们就可以使用上面的恒等式重建答案。 除以 2 是安全的，因为模数是 2 的幂，因此 2 的模逆在该系统中以位移位的形式存在。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N²) | O(N) | 太慢了 |
 | 最佳 | O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们从左到右处理数组，同时保持当前的前缀和。 

1. 开始于`pref = 0`,`sum_pref = 0`， 和`sum_sq = 0`。 这些表示当前的前缀和、迄今为止看到的所有前缀和的总和以及它们的平方和。 
2. 对于每个元素`a[i]`， 更新`pref += a[i]`。 这会产生以位置结束的前缀和`i`。 
3. 将这个新的前缀和添加到`sum_pref`。 这会跟踪$\sum s_i$。 
4. 加上前缀和的平方`sum_sq`。 这维持了$\sum s_i^2$。 
5.处理完所有元素后，计算`total = sum_pref * sum_pref`。 这等于$(\sum s_i)^2$。 
6. 使用提取成对贡献`pair_sum = (total - sum_sq) // 2`。 
7.最后减少`pair_sum`模数`M`，注意始终如一地掩盖或减少`M`是二的幂。 

为什么每个步骤都是有效的，源于增量地维护精确的前缀和。 我们永远不需要完整的数组`s`，仅运行聚合。 

### 为什么它有效

 正确性取决于和平方的代数分解。 扩展$(\sum s_i)^2$产生所有对角线项$s_i^2$每个非对角线对两次。 减去对角项就得到了所需数量的两倍。 由于每对都恰好出现一次`i < j`，除以二得出所需的总和。 由于每个前缀和在运行累加器中只计算一次，因此不会遗漏或重复任何项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    pref = 0
    sum_pref = 0
    sum_sq = 0

    for x in a:
        pref += x
        sum_pref += pref
        sum_sq += pref * pref

    total = sum_pref * sum_pref
    pair_sum = (total - sum_sq) // 2

    print(pair_sum % m)

if __name__ == "__main__":
    solve()
```实现直接遵循派生的身份。 前缀总和增量更新以避免存储整个前缀数组。 两个累加器跟踪必要的对称统计数据。 最后的减法隔离了交叉项，并且整数除以二是安全的，因为保证表达式在除法之前是偶数。 

一个微妙的点是，所有算术都是用 Python 整数完成的，因此溢出不是问题。 模数仅在最后应用，因为中间值需要完全精确以保持身份的正确性。

 ## 边缘情况

 对于`N = 1`，算法集`pref`到单个元素，但只有一个前缀和，所以`sum_sq`等于`sum_pref^2`， 制作`(total - sum_sq)`零和除法后的输出零。 这正确地匹配了任何一对的缺失。 

对于像这样的数组`0 0 0`，每个前缀和保持为零。 两个都`sum_pref`和`sum_sq`始终保持为零，因此最终表达式的计算结果为零，无需任何特殊处理。 

对于较大的值，例如`a = [1, 2, 3, 4]`，前缀和增长为`1, 3, 6, 10`。 该算法将它们的平方和总和分别精确地累加一次，并且恒等式确保这四个值中的每对乘积在重构的表达式中都被精确地计算一次，从而确认没有排序或索引问题影响正确性。
