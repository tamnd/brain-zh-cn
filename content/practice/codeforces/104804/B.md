 ## 解决方案
 ## 问题理解

 我们正在模拟坐在固定周期中的四名球员之间非常结构化的选秀过程。 每一轮，每个玩家都会从公共池中取出一个骑士令牌，直到池耗尽为止。 唯一的区别是比赛顺序不是固定的：在每一轮四轮选秀之后，顺序会循环轮换，所以无论谁先成为最后一个，每个人都向前移动一个位置。 

伊戈尔首发到位$k$，我们想要确定他在$n$代币用完。 

输入由两个值组成。 第一个是可用的相同令牌的总数，第二个是伊戈尔在四名玩家中的回合顺序中的初始位置。 输出只是 Igor 设法获取令牌的轮数。 

约束条件非常小，有$n \le 100$，因此即使直接模拟每个选择也足够了。 渐进复杂度方面不需要优化，甚至$O(n)$或者$O(n \cdot 4)$行为是微不足道的。 

一个微妙的点是，球员的轮换并没有改变每个球员在四个动作的完整循环中仍然只执行一次的事实。 轮换只是排列每个位置的人员，而不是出现的频率。 因此，每个球员在每轮四次选秀中仍然会出现一次。 唯一的复杂之处在于，伊戈尔的身份以可预测的循环模式在各个位置之间移动。 

除了小的边界检查之外，没有任何有意义的边缘情况，例如$n = 1$，其中只有第一个位置起作用一次，或者$k = 4$，其中 Igor 在第一个周期的最后开始。 

## 方法

 直接模拟是最直接的解释。 我们维护一个由四位玩家组成的数组，代表当前的顺序。 对于每个令牌，我们将位于顺序前面的玩家分配给他们一个令牌，然后在每四次选择后轮换顺序。 这是正确的，因为它准确地反映了游戏规则。 

然而，模拟旋转是不必要的。 关键的观察是，每轮整轮后的轮换只是改变身份，但并没有改变每个球员每轮只有一个选秀权的事实。 在任何连续的四步棋中，四名玩家中的每一位都恰好出现一次。 因此，在所有$n$代币中，Igor 出现的次数仅取决于发生了多少完整轮或部分轮，而不取决于内部轮换结构。 

这将问题简化为简单的周期性计数任务。 由于每组 4 个选秀权都会向每个球员分配一个选秀权，因此伊戈尔在每个完整的 4 组选秀权中获得一个选秀权，如果他的位置位于剩余的不完整组内，则可能会额外获得一个选秀权。 

强力方法将模拟每个拾取和旋转阵列，这会花费每次拾取的恒定工作量，但包括管理状态转换的开销。 优化的视图删除了所有状态并将所有内容简化为循环算术。

 ## 算法演练

 1. 计算有多少个完整的四轮选秀$n$。 这是$n // 4$。 每一轮都保证伊戈尔恰好有一个选秀权。 
2. 将这些全面贡献添加到 Igor 的答案中。 这形成了基线计数。 
3. 计算余数$n \% 4$，代表不完整的最后一轮（如果有）。 
4.检查Igor的位置是否$k$落在第一个范围内$r$一轮的位置。 如果是的话，伊戈尔将获得额外的选秀权。 
5. 输出累计总数。 

关键思想是，在四次移动的每个循环中，位置 1 到 4 都只使用一次，因此最后部分循环中的唯一问题是在循环结束之前是否已到达 Igor 的位置。 

### 为什么它有效

 该系统的行为就像一个长度为 4 的重复赛程表，其中保证每个玩家在每个完整周期中恰好出现一次。 轮次之间的轮换会排列身份，但保留每个身份每个周期出现一次的不变性。 因此，伊戈尔的出场总数仅取决于存在多少个完整周期加上他是否被安排在最终周期的不完整后缀中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

full = n // 4
rem = n % 4

ans = full

if k <= rem:
    ans += 1

print(ans)
```代码直接实现了循环分解。 整数除以 4 计算完整轮数，每一轮都为伊戈尔贡献了一个保证选秀权。 余数捕获部分回合，比较`k <= rem`检查 Igor 的位置在该未完成的部分中是否仍然有效。 

不需要模拟，也不需要玩家轮换的明确表示，因为轮换不会影响每个周期的频率。

这证实了余数逻辑正确地捕获了部分循环参与。

 ## 边缘情况

 对于$n = 1$，算法计算$full = 0$,$rem = 1$。 如果$k = 1$，条件$k \le rem$成立，因此结果为 1。这与仅发生一次选秀且位置 1 的 Igor 立即选秀的事实相符。 

为了$n = 4$，我们得到一个完整的周期，没有剩余。 每个球员，包括伊戈尔，无论$k$，恰好收到一个选秀权。 公式返回$1$因为$full = 1$和$rem = 0$，因此不会发生额外的添加。 

对于以下情况$k = 4$，只有其余部分重要。 如果$n \mod 4 < 4$，伊戈尔只有到达第四位才在最后的部分循环中做出贡献。 否则他只能收到全周期的贡献。
