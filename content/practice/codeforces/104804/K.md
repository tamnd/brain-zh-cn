 ## 解决方案
 ## 问题理解

 我们有一家印刷厂，它将纸张长度分成一系列连续的片段。 每个段代表一个页面计数范围，每个范围的每页成本是固定的。 如果作业在某个范围内，则可以按照每页的成本进行打印，但有一个问题：客户可以用额外的空白页填充文档，以使总页数变为大于或等于原始长度的任何值，然后选择涵盖该填充尺寸的范围。 

目标是从一份准确的文档开始$k$页数，并可选择将其增加到任何更大的数字，然后选择一个其间隔完全包含最终页数的段。 成本是段成本乘以所选页数，因为成本是每页的。 任务是最小化总付款，或确定没有段可以容纳任何可行的填充长度。 

输入的结构很重要：段按递增顺序给出，它们从 1 开始完全划分数轴，没有间隙，也没有重叠。 这意味着每个正整数页数都属于一个段。 

这些约束促使我们寻求线性或接近线性的解决方案。 和$n \le 10^5$， 任何$O(n^2)$尝试所有选择或模拟每个段的填充决策的策略立即太慢。 关键的隐藏约束是$k \le 10^9$，这会阻止在页面上构建显式数组或 DP。 

当人们假设最佳片段就是包含以下内容的片段时，就会出现天真的错误：$k$。 这是不正确的，因为填充允许移动到后面的段，而每页的成本可能要小得多。 

当一个段紧随其后开始时，会出现另一个微妙的故障情况$k$，并且更便宜的部分存在于更右边。 例如，如果段成本随后显着下降，则最佳策略是将页数增加到超过$k$直到到达更便宜的部分。 

最后，很容易忘记我们在填充后选择的是单个段，而不是混合段。 

## 方法

 蛮力方法会尝试每个部分作为最终选择。 对于每个段$[a_i, b_i]$，我们会检查是否可以通过填充到达它，这意味着我们需要$b_i \ge k$。 如果是这样，我们可以选择任何一个$x \in [\max(k, a_i), b_i]$，成本变为$x \cdot c_i$。 段内的最佳选择始终是最小的可行选择$x$，因为成本随页数线性增长。 因此，对于每个段，我们将计算：$$x_i = \max(k, a_i), \quad \text{cost}_i = x_i \cdot c_i$$并取所有有效段中的最小值。 

这是正确的，但已经$O(n)$，这很好。 然而，结构中隐藏着一个更重要的观察结果：段是连续且排序的，因此我们可以一次性处理它们，同时保持最佳答案。 关键思想是，我们永远不需要重新访问早期的段，并且对于给定的范围，我们永远不需要考虑当前段以外的内容。$k$。 

真正的微妙之处在于，由于允许填充，因此有效的决策与位置无关$k$最初是谎言。 我们本质上是选择一个断点$x \ge k$，然后支付$x \cdot c(x)$， 在哪里$c(x)$是区间内的分段成本函数。 

由于该函数在段上是分段常数，并且在每个段内是线性的，因此检查每个段一次就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 事实上，“最佳”解决方案与正确制定的​​干净的蛮力解决方案相同，但使用区间逻辑仔细实施。 

## 算法演练

 1. 初始化变量`answer`作为无穷大。 这将跟踪所有有效选择的最低可能成本。 
2. 迭代每个段$[a_i, b_i]$有成本$c_i$。 由于段是不相交的并且涵盖所有整数，因此每个可能的最终页计数恰好属于一个段，因此每个段必须恰好被考虑一次。 
3. 检查该段是否可以使用。 由于我们只能增加页数，因此任何最终页数必须至少为$k$。 如果$b_i < k$，该段不能包含任何可行的最终大小并被忽略。 
4. 如果该段可用，则确定其中的最佳页数。 最小可行页数是$\max(k, a_i)$，因为我们不能低于$k$由于填充，我们不能低于段起点。 
5. 计算成本为$\text{pages} \times c_i$。 这在段内是最佳的，因为增加页面只会线性增加成本。 
6.更新全局最小答案。 
7. 处理完所有段后，如果答案从未更新，则输出$-1$。 否则输出计算出的最小值。 

### 为什么它有效

 关键的不变量是每个可行的最终页数恰好属于一个段，并且在一个段内，成本函数在页数上是单调的。 这使得段内的最佳选择始终是最左边的可行点。 由于每个有效的最终状态都由一个段和其中的一个选择来表示，因此扫描所有段并采取最佳局部最优值可以保证全局最优值。 不存在超出可行性条件的跨部门交互$b_i \ge k$，因为填充只会增加页数，并且不会在不考虑段的情况下强制跳过该段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    ans = 10**30

    for _ in range(n):
        a, b, c = map(int, input().split())

        if b < k:
            continue

        x = max(a, k)
        if x <= b:
            ans = min(ans, x * c)

    print(-1 if ans == 10**30 else ans)

if __name__ == "__main__":
    solve()
```该解决方案一次性处理各个段，仅保留迄今为止的最佳答案。 关键细节是计算`x = max(a, k)`，它正确地模拟了两个约束：填充不能减少到以下$k$，并且我们必须保持在段边界内。 

支票`b < k`过滤不能包含任何有效最终大小的段。 第二个条件`x <= b`确保填充后我们仍然保留在段内。

 ## 边缘情况

 一个关键的边缘情况是当$k$位于段内较远的位置，但最佳移动是向前跳跃。 例如，如果后面的段的成本要小得多，则填充应该跳过中间昂贵的段。 该算法处理这个问题是因为它从不限制包含以下内容的段的选择：$k$，它独立评估每个分段。 

另一种边缘情况发生在$k$比所有的都大$b_i$除了最后一段。 在这种情况下，只有最后一段贡献候选者，并且算法正确地返回其中的值或$-1$如果连它都无法容纳$k$。 

第三种情况是当最优值正好在$a_i$而不是$k$。 公式`max(a, k)`确保我们永远不会错误地选择低于任一约束的值，因此即使在以下情况下，左边界逻辑仍然正确$k$很小。
