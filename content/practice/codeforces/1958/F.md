 ## 解决方案
 ## 问题理解

 我们正在研究一个非常受限的网格：只有两行和大量列。 起点是左上角的单元格，目标是右下角的单元格。 移动仅限于向右或向下，这意味着任何有效路径必须在顶行停留一段时间，精确地下降到底行一次，然后继续向右，或者可能执行一些尊重网格边界的等效操作。 

由于网格只有两行，因此从起点到终点的每条路径都具有非常严格的结构。 路径完全由发生单一向下移动的列决定。 如果路径永远不会向下移动，则它无法到达目标单元格，因此每个有效路径必须恰好选择它切换行的一列。 

该任务引入了障碍：我们精确选择 k 个单元格进行阻止，不包括开始和结束单元格。 阻塞单元格会删除所有经过它们的路径。 对于每个可能的值i，我们必须计算有多少种方法来选择k个被阻塞的单元格，使得剩余的有效路径的数量恰好为i。 

约束条件很大，n 高达 200,000。 这会立即排除任何尝试枚举阻止的配置或显式模拟每个配置的路径的解决方案。 任何方法都必须将问题简化为封闭形式的组合计数结构，理想情况下是 n 的线性或近线性。 

当 k 足够大时，即使阻塞少量列也可以完全隔离网格的某些部分，就会出现微妙的边缘情况。 例如，如果 k 阻塞列中除端点之外的每个单元格，则该列可能完全消除潜在的“切换点”。 另一个边缘情况是当 k 最小时：如果 k = 0，则每列仍然可用，并且路径数量最大化并等于 n，因为每列代表一个可能的切换点。 

一种简单的方法是尝试选择 k 个被阻止的单元格，然后重新计算有多少列仍然有效作为切换点。 这会失败，因为从被阻止的单元格到路径计数的映射是高度非线性的：阻止单个单元格仅影响一条潜在路径，但当多个单元格位于同一列时，组合会强烈相互作用。 

## 方法

 关键的简化来自于理解路径在 2 行网格中的行为方式。 每个有效路径对应于选择第 j 列，使得该路径在第 1 行上向右移动直到第 j 列，然后向下移动，然后在第 2 行上继续向右。因此，恰好有 n 个可能的规范路径，每列一个。 

但是，如果单元格 (1, j) 或 (2, j) 被阻塞，则列 j 将变得不可用。 如果其中任何一个被阻塞，则该切换点就会被破坏。 因此，路径的数量恰好是两个单元保持畅通的列数。 

因此，问题简化为在 2n − 2 个合格单元格（不包括开始和结束）中选择 k 个被阻止的单元格，并计算结果配置有多少种方式使 i 列完全完好无损。 

如果一列的两个单元格都没有被阻塞，那么我们将其定义为“好”。 如果一列不好，它就不会贡献任何路径。 因此，路径的数量等于好列的数量。 

现在问题变成：选择 k 个单元格，以便恰好 i 列保持完全不变。 

如果 i 列完全不受影响，那么在这些列中我们不会阻挡任何内容，这意味着所有 2i 个单元格都保持不被选择。 剩余的 n − i 列是“损坏的列”，其中至少有一个单元格被阻挡。 

现在，我们将问题转化为选择哪些列是完全干净的以及 k 个块如何在剩余列中分配。

对于 n-i 个损坏的列中的每一个，存在三种可能性：仅块顶部单元、仅块底部单元或同时块。 这会为每列创建一个本地计数结构。 阻塞单元的总数为 k，这强制在这些列之间施加分区约束。 

这变成了具有生成函数的独立列上的经典分布问题。 每列贡献一个多项式，其中 x 计算被阻止的单元格数量：

 每个损坏的色谱柱都会产生：

 1 + 2x + x^2，其中 1 对应于不阻塞任何内容（如果列应该损坏则不允许），因此实际损坏的列必须贡献 (2x + x^2)。 

清洁色谱柱贡献 1。 

因此，对于固定的 i，我们需要 x^k 的系数：$$\binom{n}{i} (2x + x^2)^{n-i}$$现在展开：$$(2x + x^2)^{n-i} = x^{n-i} (2 + x)^{n-i}$$因此 x^k 的系数变为：

 我们需要：$$x^{n-i} \cdot x^{k-(n-i)}$$这意味着 k ≥ n − i，并且我们减少到 (2 + x)^{n-i} 中 x^{k-(n-i)} 的系数。 

现在这很简单：$$(2 + x)^{n-i} = \sum_{j=0}^{n-i} \binom{n-i}{j} 2^{n-i-j} x^j$$所以最终答案：$$\binom{n}{i} \binom{n-i}{k-(n-i)} 2^{(n-i)-(k-(n-i))} = \binom{n}{i} \binom{n-i}{k-n+i} 2^{2(n-i)-k}$$我们只对有效的 i 求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解块集 | O(C(2n,k)) | O(C(2n,k)) | O(1) | O(1) | 太慢了 |
 | 组合公式 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算高达 2n 的阶乘和逆阶乘，以实现快速二项式系数评估。 这是必需的，因为我们重复计算以素数为模的组合。 
2. 迭代 i 从 0 到 n 的所有可能值，将 i 解释为完全无阻塞的列数。 i 的每个选择都会将列分为干净组和损坏组。 
3. 如果 i 列是干净的，则选择它们$\binom{n}{i}$方式。 这修复了哪些列贡献路径。 
4. 设 t = n − i 为损坏柱的数量。 这些是我们放置块的唯一列。 
5. 每个受损的柱会贡献 1 个或 2 个被阻止的细胞，具体取决于我们是阻止一个细胞还是两个细胞。 我们现在需要将 k 个块分布在 t 列上，使得每列至少贡献 1 个块，因此我们减去 t 并解决减少的分配问题。 
6. 定义 r = k − t。 这是除了每个损坏的柱放置一个块之外的“额外块”的数量。 如果 r 为负或大于 t，则这种配置是不可能的。 
7. 在 t 个损坏的列中选择 r 列来接收第二个块。 这有助于$\binom{t}{r}$。 
8. 每种配置都贡献一个因子$2^{t-r}$，对应于列中的单个块是放置在顶部还是底部单元格上。 
9. 将所有贡献相乘：$\binom{n}{i} \binom{t}{r} 2^{t-r}$。 

### 为什么它有效

 关键的不变量是，每个有效的阻塞配置都唯一对应于一个三元组：选择干净的列，选择哪些损坏的列接收一个或两个阻塞单元，以及对于接收恰好一个块的每一列，选择哪一行被阻塞。 一旦修复了干净列和损坏列的分区，这些选择就是独立的。 这消除了列之间的所有交互，并将全局约束“恰好 k 个块”减少为每列附加约束，该约束通过在 t 个相同的槽之间分配偏移量 r 来处理。 没有配置被计算两次，因为每个阻塞单元模式唯一地确定哪些列是干净的以及每个损坏列包含多少个块。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())

    maxv = 2 * n
    fact = [1] * (maxv + 1)
    invfact = [1] * (maxv + 1)

    for i in range(1, maxv + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[maxv] = modpow(fact[maxv], MOD - 2)
    for i in range(maxv, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    res = [0] * (n + 1)

    for i in range(n + 1):
        t = n - i
        r = k - t
        if r < 0 or r > t:
            continue
        ways = C(n, i) * C(t, r) % MOD
        ways = ways * modpow(2, t - r) % MOD
        res[i] = ways

    print(*res)

if __name__ == "__main__":
    solve()
```阶乘预计算支持恒定时间二项式系数查询，这是必要的，因为 i 上的循环针对所有列运行。 求幂处理二进制选择，即为每个“单块”损坏列在每一行中放置一个块。 r 上的边界检查确保我们只计算块的有效分布。 

一个常见的陷阱是忘记每个损坏的列必须至少包含一个被阻塞的单元格，这就是为什么 r 被定义为 k − (n − i)。 另一个常见的错误是混淆了第二个块选择是对应于 2^r 还是 2^{t-r}； 正确的解释是，只有恰好有一个块的列才贡献因子 2。

 ## 边缘情况

 当 k = 0 时，没有单元格被阻塞，因此每一列都保持有效。 该算法设置 t = n − i 和 r = −t，立即拒绝除 i = n 之外的所有情况。 这会产生一个配置，与所有 n 条路径都保留的事实相匹配。 

当 k 非常大，接近 2n − 2 时，大多数色谱柱必定会损坏。 约束 r = k − t 确保我们只计算可以分布所需数量的块的配置，从而防止过度计算不可能的密集块模式。 

当 i = n 时，所有列都是干净的，因此 t = 0 且 r = k。 这会强制 k = 0，否则配置无效，符合直觉：如果存在任何块，则至少有一列被破坏并且路径减少。
