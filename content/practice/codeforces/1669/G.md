 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格$n \times m$由空细胞、石头和障碍物组成。 石头用“*”表示，空单元格用“.”表示，障碍物用“o”表示。 目标是模拟重力：每块石头都会尽可能地落下，直到它击中网格底部、另一块已经落下的石头或障碍物。 一旦所有棋子都落定，我们必须输出网格的最终配置。 

网格大小限制为最多 50 行 50 列，最多可以有 100 个测试用例。 由于细胞总数最多为$50 \times 50 = 2500$对于每个测试用例，即使是简单的每个单元模拟也足够快。 然而，粗心的实施仍然可能在某些配置中产生错误的结果，例如当石头堆放在障碍物上方或多个石头落入同一列时。 如果我们自上而下迭代并立即将石头移动到空单元格中，我们就有“覆盖”或跳过石头的风险，从而产生不正确的最终布局。 一个具体的小例子是一个柱子`.*.*o.`。 如果我们自上而下处理，第一个“*”会掉落，但第二个“*”可能会错误地穿过第一个固定的石头，除非我们正确处理计数。 

边缘情况包括只有障碍物的柱子、只有石头的柱子、障碍物上方堆叠的多个石头以及单行网格。 正确处理这些情况需要我们计算石子落地的位置，而不是单独移动它们，以免与同一列中的其他石子发生冲突。 

## 方法

 一种蛮力方法是重复遍历网格中的每个单元格，一次将石头向下移动一步，直到没有石头可以移动为止。 这种方法是正确的，因为每块石头只能落下有限的步数，但效率很低：对于一根高度的柱子$n$，一块石头可以移动到$n$步骤，并与$n \times m$细胞，这给出$O(n^2 m)$每个测试用例的操作。 和$n = m = 50$，最坏的情况是每个测试用例大约 125,000 次操作，这仍然是可行的，但当存在更直接的方法时是不必要的。 

关键的观察是每一列都可以独立处理。 我们可以计算障碍物之间的石头数量，然后将它们“扔”到最低的可用位置，而不是一步一步地移动石头。 障碍物充当自然分隔符，将每列分成几段。 对于每个段，我们将计数的石头放置在该段的底部，并用空单元格填充其余部分。 这种方法将工作量减少到每列一次通过，从而提供了简单的$O(nm)$该算法易于实现并避免了简单模拟的陷阱。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（逐步）| O(n^2 m) | O(n^2 m) | O(纳米) | 可以接受但没有必要 |
 | 按列计数 | O(n·m) | O(纳米) | 最佳，已接受|

 ## 算法演练

 1. 从左到右独立地遍历每一列。 将每一列视为垂直的单元格数组。 
2. 对于每一列，将石头计数器初始化为零。 该计数器跟踪当前段（障碍物之间或从底部到障碍物）中的石子数量。 
3. 从底行迭代到顶行。 如果遇到石头，则增加计数器并暂时用空“.”替换单元格。 如果遇到障碍，则处理当前段。 
4. 当处理一段时（无论是遇到障碍物还是到达柱子顶部），用计算出的石子数量从底部填充该段。 将石头放置在该段内尽可能最低的位置，并用空单元格填充上面的剩余单元格。 将石头计数器重置为零。 
5. 继续向上直到列的顶部，确保最后一段（从最后一个障碍物或底部到顶部）以相同的方式处理。 
6. 处理完所有列后，网格代表施加重力后的最终状态。 

此方法之所以有效，是因为我们保持了一个不变量：在处理一列期间的任何时刻，当前行下方的所有棋子都已放置在其最终位置。 通过计算石子并将它们放置在每个部分中最低的可用位置，我们尊重障碍物和先前放置的石子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]

    for col in range(m):
        stones = 0
        for row in range(n-1, -1, -1):
            if grid[row][col] == '*':
                stones += 1
                grid[row][col] = '.'
            elif grid[row][col] == 'o':
                for k in range(1, stones+1):
                    grid[row+k][col] = '*'
                stones = 0
        for k in range(stones):
            grid[k][col] = '*'

    for row in grid:
        print(''.join(row))
```外循环处理多个测试用例。 将网格读入列表列表中允许就地修改。 通过从下到上迭代每一列，对石头进行计数，然后在遇到障碍物或列顶部后放置。 最后的嵌套循环打印更新后的网格。 小心处理索引可确保棋子正确放置，而不会覆盖障碍物。

 - 第 1 行“.”，石头=0
 - 第 0 行“*”，石头=1，标记为“.”
 - 到达顶部，将剩余的石头放在第 0 行

 结果列：```

Row 4: *
Row 3: o
Row 2: .
Row 1: .
Row 0: *
```这演示了障碍物如何分裂分段以及石头如何落在其分段的最低位置。
