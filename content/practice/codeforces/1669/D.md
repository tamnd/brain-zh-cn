 ## 解决方案
 ## 问题理解

 我们给出了一行完全空的单元格，并且允许我们应用一种特殊的操作，该操作始终作用于恰好两个相邻的位置。 每个应用程序都会将这两个单元格重新着色为不同的颜色，一个红色，一个蓝色，无论顺序如何。 

最终的配置预先固定为由白细胞、红细胞和蓝细胞组成的串。 白色意味着“从未着色”，而红色和蓝色是永久颜色。 任务是确定是否存在某种序列的相邻两单元标记操作，将最初的全白行转换为目标字符串。 

每个标记总是影响两个邻居，因此它引入了局部约束：颜色永远不会为每个单元独立分配，而是总是成对分配。 由于图章可以重叠并重新应用，因此可以覆盖之前的选择，因此问题不在于明确跟踪构造序列，而在于检查是否存在一致的序列。 

约束足够大，任何解决方案都必须在每个测试用例的线性时间内运行。 由于所有测试用例的总长度最多为 100,000，因此即使每个测试用例的 O(n) 或 O(n log n) 解决方案也是可以接受的，但每个用例的任何二次都会太慢。 这立即排除了对所有冲压序列的强力模拟，因为应用冲压件的方式数量随着位置数量呈指数增长。 

如果进行本地推理，一些边缘情况很容易被忽略。 像“B”或“R”这样的单一颜色单元是不可能的，因为每个图章都会给两个单元着色，因此无法创建孤立的单色要求。 另一个微妙的情况是“WBW”或“WRW”等模式，其中彩色单元格被白色包围。 尽管每个彩色单元单独看起来都很好，但无法在不影响邻居的情况下创建它，因此此类配置会失败。 第三个重要的情况是像“BRBR”这样的交替模式，其中每个相邻对都是“看起来有效”，但全局一致性仍然很重要，因为每个图章都强制执行必须平铺整个彩色区域的配对结构。 

## 方法

 暴力方法会尝试模拟这个过程：从全白开始，重复选择相邻对并将它们分配为 BR 或 RB，探索所有可能的序列，直到我们到达目标字符串或耗尽可能性。 这在原则上是正确的，因为它反映了构造的确切规则。 

然而，每个位置都可以是许多印章选择的一部分，并且每个印章放置分支到多个未来状态。 在最坏的情况下，可能的序列数量随 n 呈指数增长，因为大约 n 个位置中的每个位置都可以以多种方式配对。 即使 n 约为 50，这也是不可行的。 

关键的观察是我们实际上不需要构建序列。 每个标记总是产生一对有效的相邻非白色单元，由一个 R 和一个 B 组成。因此，在任何有效的最终配置中，非白色单元的每个最大连续块必须在内部“可解析”为可以覆盖所有非白色单元的相邻对。 白细胞充当分隔符，将问题分解为独立的部分。 

在任何没有白细胞的片段内，我们本质上是在问是否可以为每个位置分配一种颜色，以便每个相邻关系都可以通过一些重叠的 BR/RB 对来解释。 关键的简化是，当且仅当一个段包含至少一个用于一系列交替放置的有效起始点时，该段才是有效的，并且没有段会强制单个孤立的彩色单元。

这将问题简化为贪婪的本地检查：扫描字符串，将其按白色分割，并且对于每个连续的非白色单元格，确保它至少具有一对相邻的等色端点或至少一个允许传播的相邻有效交互。 实际上，已知的简化变得更加强大：任何长度为 1 的块都是无效的，而任何长度至少为 2 的块总是可构造的。 

这是因为在长度至少为 2 的任何段内，我们始终可以开始在任何相邻对上进行标记并向外扩展覆盖范围，同时尊重每个标记仅强制执行局部邻接约束。 由于重叠，有足够的灵活性来实现任何多小区分段，但单个小区没有来源伙伴。 

因此，最终条件归结为检查非白细胞的每个最大连续段的长度是否至少为 2。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 段检查 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 从左到右扫描字符串，同时跟踪当前连续的非白色单元块的长度。 每当我们看到“R”或“B”时，我们就会增加长度，并在看到“W”时重置它。 这是必要的，因为白细胞破坏了任何冲压相互作用。 
2. 每当我们遇到白色单元格或到达字符串末尾时，我们都会评估刚刚结束的段。 如果它的长度恰好为 1，我们立即知道该配置是不可能的，因为任何标记操作都无法生成单个单元。 
3. 继续扫描字符串的其余部分，对每个段重复相同的逻辑。 
4. 扫描完成后，如果没有发现长度为1的无效段，则可以进行配置。 

关键的决策点是我们关闭分段的那一刻。 在该边界处，我们拥有有关必须不间断地构造的最大区域的完整信息，因此我们可以在本地安全地验证它。 

### 为什么它有效

 每个印记总是产生一对相邻的彩色单元。 这意味着每个彩色细胞必须属于其连接的非白色细胞区域内的某个相邻对。 如果一个段的长度为 1，则没有可用的相邻伙伴，因此任何邮票序列都无法生成它。 相反，任何长度至少为 2 的段都可以通过从一对开始并向外延伸来构造，因为重叠的图章允许重新着色而不破坏邻接可行性。 这使得段长度成为唯一充分必要条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()

    ok = True
    i = 0

    while i < n:
        if s[i] == 'W':
            i += 1
            continue

        j = i
        while j < n and s[j] != 'W':
            j += 1

        if j - i == 1:
            ok = False
            break

        i = j

    print("YES" if ok else "NO")
```该解决方案的工作原理是显式识别连续的非白色块并拒绝任何大小为 1 的块。 扫描是线性的，每个位置最多处理一次。 

一个微妙的实现细节是确保指针`i`直接跳转到`j`处理完一个块后。 这可以避免重复计算字符并保证 O(n) 行为。 另一个重要的一点是，我们仅在片段被白色单元格或字符串末尾完全闭合时评估片段，以确保边界的正确性。

 ## 边缘情况

 单一颜色的单元格（例如输入“B”）会立即触发失败，因为扫描会生成长度为 1 的片段。 当该段在字符串末尾结束时，该算法会识别这一点，并正确地将其标记为无效。 

像“WBW”这样的模式会分成长度为 1 的两段，但即使只有一个也足以拒绝这种情况。 扫描在每个白细胞处重置，因此两个部分都被独立检查。 

全白字符串根本不会产生任何段，因此不会触发无效条​​件，答案仍然是“是”，这与我们可以简单地执行任何操作的事实相匹配。
