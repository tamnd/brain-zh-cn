 ## 解决方案
 ## 问题理解

 每个测试用例都会给出一个代表 Codeforces 用户评分的整数，任务是将评分分为四个固定间隔之一，每个固定间隔对应一个划分编号。 

该映射纯粹是基于阈值的。 非常低的评级（包括负面评级）属于第 4 级。随着评级的增加，它会跨越两个中间等级，然后达到最高评级的第 1 级。 输出不是计算，而是从数字在整数行的有序分区中的位置导出的标签。 

测试用例数量限制很大，最多可达一万个。 每个测试用例都是独立的，只需要恒定的工作量，因此唯一可行的解​​决方案是在 O(1) 时间内处理每个输入的解决方案。 任何涉及排序或重复扫描的事情都将是不必要的开销，但在技术上在限制范围内仍然是可能的； 然而，它在概念上不匹配并且比需要的要慢。 

这个问题的唯一微妙之处来自于边界处理。 划分边界包含在内，因此精确等于 1400、1600 和 1900 的值必须正确放置在较高的划分带中。 一个典型的错误是不一致地使用严格的不等式，这可能会将边界值转移到错误的划分中。 例如，由于以下原因，将 1400 视为第 4 组：`< 1400`检查而不是`<= 1399`导致分类不正确。 

## 方法

 强力解释是按顺序明确检查每个划分间隔并测试成员资格。 由于只有四个范围，即使是简单的方法也能保持每个测试用例的时间恒定。 人们可以想象将范围成对存储并迭代它们，检查评级是否落入每个区间。 这是正确的，因为间隔的数量是固定的并且很小，因此每个测试用例的最坏情况工作仍然是恒定的。 

然而，问题的结构比一般区间隶属度更简单。 这些区间在数轴上是连续且有序的，因此我们根本不需要迭代或数据结构。 从最低阈值到最高阈值的直接比较链就足够了。 一旦我们检测到正确的条带，我们就可以立即返回相应的划分标签。 

关键的观察结果是，评级空间被划分为由三个切点定义的四个单调区域：1400、1600 和 1900。这将问题转化为简单的阈值分类问题，我们只需要按升序与这些切点进行比较。

 ## 算法演练

 1.读取测试用例的数量。 这决定了我们将执行多少个独立分类。 
2. 对于每个评级，将其与定义顶级划分的最小阈值进行比较。 如果评级至少为 1900，则它必须属于第 1 类，因为不存在更高的边界。 
3. 如果评级低于 1900，请检查它是否至少为 1600。如果是，则它位于第二高段，因为它保证不会达到 Division 1。 
4. 如果评级低于 1600，请检查它是否至少为 1400。这标识了第三个等级，因为更高的可能性已被排除。 
5. 如果不满足上述条件，则评级最多为 1399，属于第 4 级。 

检查的顺序很重要，因为每个条件都会消除数轴的前缀。 一旦条件成功，后续检查就无关紧要，并且不得推翻该决定。 

### 为什么它有效

 评级线被划分为四个不相交的区间，其并集涵盖所有整数。 每个条件检查对应于排除较高间隔后这些间隔之一的成员资格。 由于检查是从最高阈值到最低阈值进行的，因此每个评级都恰好分配给一个部门，并且由于包含边界定义，不可能出现重叠或间隙。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    r = int(input())
    
    if r >= 1900:
        print("Division 1")
    elif r >= 1600:
        print("Division 2")
    elif r >= 1400:
        print("Division 3")
    else:
        print("Division 4")
```该解决方案独立读取每个评级并应用固定的比较顺序。 第一个条件处理顶部间隔，并且每个后续分支仅在排除所有较高范围后才处理下一个较低范围。 这确保了正确性，而无需显式编码间隔端点。 

一个常见的错误是颠倒检查顺序，例如测试`r >= 1400`第一的。 除非仔细保护，否则这会将所有较高评级错误地划分为 3 级或更低级别。 降序排列可以防止这种错误分类。

 ## 边缘情况

 负面评级表明最低范围从零延伸到无限负面。 对于像这样的输入`-1`, 支票`r >= 1900`,`r >= 1600`， 和`r >= 1400`全部失败，正确的分类是第 4 类。 该算法自然会处理这个问题，因为最后的 else 分支捕获了更高阈值未覆盖的所有内容。 

1400、1600 和 1900 等边界值至关重要，因为它们恰好位于除法转换上。 例如，1400 必须通过`r >= 1400`检查，确保第 3 部分，而 1399 未通过所有更高的检查并落入第 4 部分。条件的严格排序保证了正确的放置，而不需要显式的间隔端点。
