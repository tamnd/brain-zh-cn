 ## 解决方案
 ## 问题理解

 我们得到了一个短字符串的集合，每个字符串都由小字母表中的两个小写字母组成。 任务是计算有多少无序索引对对应于“几乎相同”的字符串，因为它们在一个位置上完全不同。 

如果两个字符串的两个字符之一匹配而另一个位置不同，则这两个字符串将贡献答案。 例如，`"ab"`和`"ac"`仅第二个位置不同，因此它们是有效的。 但`"ab"`和`"cd"`两个位置不同，所以它们不是。 同样，相同的字符串，例如`"aa"`和`"aa"`也无效，因为它们在零位置上不同。 

输入大小可能很大，测试用例中总共最多 100000 个字符串。 这立即排除了任何二次成对比较方法，因为在最坏的情况下，比较每对将需要大约 10^10 次操作。 相反，解决方案必须依赖于结构聚合，使用频率计数或散列将问题减少到每个测试用例的线性时间。 

幼稚推理的一个微妙的失败案例是重复计算或丢失对称性。 例如，如果我们尝试通过更改一个字符并独立计算每个位置的匹配来匹配字符串，我们可能会意外地对对进行两次计数，一次从每个端点开始。 如果我们试图“固定一个位置并按另一个位置分组”而不仔细分离，就会出现另一个问题，从而导致两个位置不同的混合情况。 

## 方法

 暴力解决方案检查每对字符串并逐个字符进行比较。 由于每个字符串的长度为 2，因此每次比较都是恒定时间，我们直接测试是否正好有一个位置不同。 这是正确的，因为它明确强制执行该条件。 然而，由于每个测试用例 n 高达 100000，这导致大约 n²/2 的比较，这远远超出了可行的限制。 

关键的观察结果是，对于两个字符串在一个位置上恰好不同，它们必须在一个位置上一致而在另一个位置上不同。 这表明将情况分为两个独立的模式。 要么第一个字符匹配而第二个字符不同，要么第二个字符匹配而第一个字符不同。 

这种结构允许我们使用频率图来计算有效对。 如果我们固定第一个字符，那么在共享该第一个字符的所有字符串中，我们只需要计算有多少个具有不同的第二个字符。 类似地修复第二个字符。 困难在于避免重复计算：如果我们小心地减去相同的对，则每个有效对在两个视图之一中都会被精确计数一次。 

我们通过对字符串进行分组并使用完整字符串标识和部分投影的频率计数来干净地处理这个问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 频率分组| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将每个字符串视为一对字符`(a, b)`并在这些对上建立频率表。 

1. 对于每个测试用例，读取所有字符串并计算每个确切字符串出现的次数。 这使我们可以直接访问存在多少相同的对。 
2. 建立一个仅以第一个字符作为键的频率表，计算以每个字母开头的字符串有多少个。 这允许推理共享第一个位置的对。 
3. 同样构建一个以第二个字符为键的频率表，计算有多少个字符串以每个字母结尾。 
4.对于共享相同第一个字符的每个字符串组，通过第二个字符频率的组合间接计算有多少个与不同第二个字符存在的交叉对。 
5. 对共享相同第二个字符的组进行对称计算。 
6. 减去对应于相同字符串的贡献，以确保排除零位置不同的对，并且不会错误地包括两个位置不同的对。 
7. 累积所有组的结果。 

最终答案来自于以避免与相同字符串重叠的方式组合“相同的第一个字符，不同的第二个”贡献和“相同的第二个字符，不同的第一个”贡献。 

### 为什么它有效

 每对有效的字符串必须在一个坐标中精确匹配。 这意味着每个有效对都被唯一地分类为两个不相交类别之一：共享第一个字符的对或共享第二个字符的对，但不能同时共享两者。 基于频率的计数使用分组计数的组合来枚举每个类别中的所有对，并且排除相同的字符串确保不会引入无效对。 由于每个有效对都只有一个匹配坐标，因此只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        freq = {}
        f1 = {}
        f2 = {}

        arr = []
        for _ in range(n):
            s = input().strip()
            arr.append(s)
            freq[s] = freq.get(s, 0) + 1
            f1[s[0]] = f1.get(s[0], 0) + 1
            f2[s[1]] = f2.get(s[1], 0) + 1

        ans = 0

        for s, c in freq.items():
            a, b = s
            # pairs with same first char but different second
            ans += c * (f1[a] - c)
            # pairs with same second char but different first
            ans += c * (f2[b] - c)

        print(ans // 2)

if __name__ == "__main__":
    solve()
```该解决方案维护三个频率图。 一个跟踪完整的字符串计数，而另外两个跟踪每个字符位置的投影。 对于每个不同的字符串，我们计算它与共享第一个字符但第二个字符不同的字符串形成的对数，对于第二个字符也是如此。 每对都计算两次，从每个端点计算一次，这就是最终结果除以二的原因。 

关键的实现细节是使用减法`f1[a] - c`和`f2[b] - c`，这会从考虑中删除相同的字符串，以便只有不同的对应字符串才会起作用。

 ## 边缘情况

 关键的边缘情况是所有字符串都相同。 在这种情况下，两个位置频率计数都与完整频率匹配，因此每次减法都会取消所有内容，结果为零，这正确地避免了对相同对进行计数。 

另一个重要的情况是当字符串在两个字母的所有组合中完美平衡时，例如`"ab", "ac", "db", "dc"`。 在这里，每一对都在一个位置上不同，并且在减半之前，该公式自然会对每个端点的所有交叉组合进行一次计数。 

最后，当 n 为 1 时，所有频率差立即归零，并且不会发生无效访问或意外负贡献，因为所有表达式都具有以下形式`c * (f - c)`变成零。
