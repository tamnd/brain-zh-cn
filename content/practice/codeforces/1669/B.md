 ## 解决方案
 ## 问题理解

 该问题要求我们找到数组中至少出现三次的任意数字。 我们给出了多个测试用例，并且对于每个测试用例，都提供了一个整数数组。 整数保证介于 1 和数组大小之间。 我们的任务是如果存在这样的数字，则输出一个；如果没有数字达到 3 的频率，则输出 -1。 

这些约束表明测试用例的数量可以高达 10,000 个，并且所有测试用例的数组大小总和不超过 200,000。 这意味着每个测试用例多次迭代数组或执行嵌套循环的任何解决方案都可能变得太慢。 因此，我们需要一种每个测试用例线性通过的方法，或者每个测试用例最多 O(n log n) 的方法。 

可能导致简单解决方案失败的边缘情况包括元素少于三个的数组，其中任何值都不可能出现三次。 例如，一个数组`[1, 2]`应立即返回-1。 另一个微妙的情况是当多个数字出现三次时； 该问题允许任何有效数字，因此我们只需要识别一个。 所有元素都相同的数组，例如`[5, 5, 5, 5]`，必须正确返回该值。 

## 方法

 暴力方法将迭代从 1 到 n 的每个可能值，并计算其在数组中出现的次数。 此方法是正确的，因为它显式检查所有元素，但在最坏的情况下，如果 n 为 200,000，单独计算每个数字会导致 O(n^2) 运算，在考虑到约束的情况下，这太慢了。 

最佳方法是使用频率计数器一次性计算所有数字。 这利用了这样一个事实：我们只需要知道计数是否达到三，而不是超过三的确切计数。 使用字典或大小为 n+1 的预分配数组（因为所有值都在 1 和 n 之间）让我们可以在 O(n) 时间内跟踪每个测试用例的频率。 一旦任何数字达到三，我们就可以立即打印它并停止进一步处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 频率计数器| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 
2. 对于每个测试用例，读取 n 和 n 个整数的数组。 
3. 初始化频率计数器。 如果使用列表，请分配 n+1 个零来跟踪从 1 到 n 的计数。 
4. 迭代数组中的每个数字。 增加频率计数器中的计数。 
5. 一旦数字达到三，就打印该数字并停止处理当前的测试用例。 
6. 如果到达数组末尾且没有任何数字达到 3，则打印 -1。 

该算法之所以有效，是因为频率计数器确保我们准确跟踪每个数字出现的次数。 通过在计数达到三时立即检查，我们保证打印任何有效的输出，而无需进行不必要的计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))
        freq = [0] * (n + 1)
        found = False
        for num in arr:
            freq[num] += 1
            if freq[num] == 3:
                print(num)
                found = True
                break
        if not found:
            print(-1)

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`并初始化一个列表`freq`计算每个数字的出现次数。 当数字达到a时立即中断
