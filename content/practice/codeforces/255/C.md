 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，并要求找到形成几乎算术级数的最长子序列。 在这种情况下，如果存在整数，则序列几乎是算术级数$p$和$q$这样第一个元素是$p$并且每个后续元素交替增加$+q$和$-q$。 形式上，对于子序列$a_1, a_2, \dots, a_k$，关系$a_i = a_{i-1} + (-1)^{i-1} \cdot q$必须坚持$i > 1$。 

输入提供$n$，原始序列的长度，以及序列本身，有约束$1 \le n \le 4000$和每个元素$1 \le b_i \le 10^6$。 输出是能够满足这种交替级数性质的最长子序列的长度。 

自从$n$最多 4000，任何复杂度以上的解决方案$O(n^2)$很可能会超过时间限制。 显式尝试所有子序列的简单方法将是指数级的且不可行。 边缘情况包括具有重复数字的序列、最佳子序列由分布在数组中的交替值组成的序列，以及每个元素简单地形成一个级数的非常短的序列。 

幼稚的实现可能会错误地假设任何连续的差异都有效，或者第一个差异定义了整个子序列而不检查交替符号，这在像这样的序列上会失败`10, 20, 10, 20, 30`。 

## 方法

 暴力方法将枚举每个可能的子序列并测试它是否符合交替规则。 对于每个子序列，我们将检查所有连续的对，看看它们是否遵循$+q, -q, +q, \dots$。 这原则上是正确的，但需要检查$2^n$子序列，这对于$n = 4000$。 

关键的观察结果是，问题可以简化为指数对的动态规划。 如果我们修复子序列的最后两个元素，则差异$q$被确定为它们之间差异的一半（因为$a_2 - a_1 = q$,$a_3 - a_2 = -q$， 所以$a_3 - a_1 = 0$如果重复或$2q$如果交替的话）。 这建议为每个索引存储以给定差值结束的最长有效子序列的长度，使用哈希映射来有效地存储 DP 状态。 

我们可以迭代每一对$(i, j)$和$i < j$并计算潜力$q = (b[j] - b[i]) // 2$如果差异是偶数。 使用字典，我们跟踪可以结束于的子序列的长度$j$有差异$q$。 这允许$O(n^2)$解决方案，它完全符合限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | DP 成对 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.初始化一个DP字典数组，`dp`， 在哪里`dp[j][q]`表示以索引结尾的最长算术子序列的长度`j`有差异`q`。 
2. 迭代所有对`(i, j)`和`i < j`。 对于每一对，计算差异`d = b[j] - b[i]`。 
3. 只考虑差异`d`这样`d`可被 2 整除。这确保了交替差`q`是一个整数，计算公式为`q = d // 2`。 
4. 如果已经有一个以`i`有差异`q`，通过包括来扩展它`b[j]`。 否则，开始一个长度为 2 的新子序列，其中包含`b[i]`和`b[j]`。 
5. 保留全局变量`ans`跟踪所有找到的最大长度`dp[j][q]`。 
6. 迭代所有对后，`ans`包含最长的几乎算术级数子序列的长度。 

工作原理：每个 DP 状态都正确捕获以给定索引结尾且具有给定交替差值的子序列的最大长度。 通过按索引顺序迭代对，我们确保构建的任何子序列的索引严格递增，满足子序列要求。 该映射可防止对相同差异进行重复重新计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
b = list(map(int, input().split()))

dp = [{} for _ in range(n)]
ans = 1

for j in range(n):
    for i in range(j):
        diff = b[j] - b[i]
        if diff % 2 != 0:
            continue
        q = diff // 2
        dp[j][q] = dp[i].get(q, 1) + 1
        ans = max(ans, dp[j][q])

print(ans)
```在这个解决方案中，`dp`是一个字典数组，这避免了分配完整的`n x n`数组并只允许稀疏存储发生的差异。 我们初始化`ans`为 1，因为最小子序列长度是任何单个元素。 这`if diff % 2 != 0`确保仅整数`q`考虑值，避免无效序列。 这`get(q, 1)`如果不存在，则调用启动长度为 2 的新子序列。

    sys.stdin = io.StringIO(inp)

    ans = 1
    for j in range(n):
        for i in range(j):

            ans = max(ans, dp[j][q])
