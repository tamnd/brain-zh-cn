 ## 解决方案
 ## 问题理解

 格雷格以固定的重复顺序进行练习。 第一个练习训练胸部，第二个训练二头肌，第三个训练背部，然后再次重复该模式：胸部、二头肌、背部，依此类推。 

我们得到一个数组，其中位置的值`i`告诉我们格雷格执行了多少次重复`i`此序列中的第 -th 练习。 任务是在汇总分配给哪个肌肉群的所有练习后，确定哪个肌肉群获得最大的总重复次数。 

限制非常小。 练习次数最多为 20 次，每次重复次数最多为 25 次。即使是简单的模拟也很容易足够快。 不需要高级的数据结构或优化技巧。 对阵列进行简单的线性扫描已经完全符合限制。 

唯一微妙的部分是将每个练习分配给正确的肌肉群。 由于该模式每三个练习重复一次，因此位置模 3 确定目标肌肉。 粗心的实现很容易将映射移一，因为编程中的数组索引通常是从零开始的。 

考虑这个输入：```
3
10 1 20
```正确的总数是：

 - 胸部 = 10
 - 二头肌 = 1
 - 后退 = 20

 所以答案是`back`。 

如果有人使用`i % 3`如果基于单一的思维不正确，他们可能会将第一个练习映射到二头肌而不是胸部，并产生错误的结果。 

另一个容易犯的错误是忘记了序列是循环继续的。 

例子：```
5
1 2 3 4 5
```任务是：

 - 胸部：练习 1 和 4 → 1 + 4 = 5
 - 二头肌：练习 2 和 5 → 2 + 5 = 7
 - 背部：练习 3 → 3

 正确答案是`biceps`。 

仅单独处理前三个位置的有缺陷的实现将在此处失败。 

## 方法

 蛮力的想法是明确模拟格雷格的锻炼。 对于每个锻炼位置，确定它属于哪个肌肉群，并将其重复次数添加到该肌肉的总数中。 处理完所有练习后，比较三个总数并打印最大的一个。 

这已经在限制范围内完美运行。 我们最多处理 20 个数字，所以总的工作量很小。 

效率较低的暴力版本可以重复构建肌肉名称的循环序列，然后分别计算每组的重复次数。 即使这样仍然会通过，因为输入很小，但它引入了不必要的工作和复杂性。 

有用的观察结果是，运动类型完全取决于指数模 3：

 - 索引 0, 3, 6, ... 属于胸部
 - 指数 1, 4, 7, ... 属于二头肌
 - 索引 2, 5, 8, ... 属于后面

 一旦我们认识到这种重复结构，解决方案就变成具有三个累加器的单个线性传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取整数`n`以及重复的数组。 
2. 创建三个变量来存储胸部、二头肌和背部的总重复次数。 
3. 使用从零开始的索引迭代数组。 
4. 对于每个索引：

 - 如果`i % 3 == 0`, 将数值添加至宝箱
 - 如果`i % 3 == 1`，将值添加到二头肌
 - 否则，将值添加到后面

 模运算之所以有效，是因为练习模式每三个位置重复一次。 
5. 完成所有练习后，比较三个总数。 
6. 打印总数最大的肌肉名称。 

### 为什么它有效

 每项练习都属于一个肌肉群，并且分配遵循长度为 3 的固定循环。 模运算将所有索引正确划分为这三组。 在扫描期间，每个重复计数仅添加一次到正确的总数中。 循环结束后，三个累加器代表每个肌肉群的完整训练量。 选择其中的最大值即可得到所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

chest = 0
biceps = 0
back = 0

for i in range(n):
    if i % 3 == 0:
        chest += a[i]
    elif i % 3 == 1:
        biceps += a[i]
    else:
        back += a[i]

if chest > biceps and chest > back:
    print("chest")
elif biceps > chest and biceps > back:
    print("biceps")
else:
    print("back")
```程序首先读取输入数组。 三个累加器变量跟踪每个肌肉群的总重复次数。 

循环按顺序处理练习。 由于Python使用从零开始的索引，索引`0`对应第一个练习，就是扩胸。 因此`i % 3 == 0`映射到胸部而不是二头肌。 

模数模式每三个指数重复一次，与锻炼周期完全匹配。 

最后，程序比较总数并打印最大的一个。 该问题保证了答案是唯一的，因此我们不需要处理联系。

 ## 边缘情况

 考虑尽可能最小的输入：```
1
7
```唯一的练习是第一个，所以属于胸肌。 循环期间：

 - 索引 0 →`0 % 3 == 0`- 胸部变为7

 最终总数为：

 - 胸部 = 7
 - 二头肌 = 0
 - 返回 = 0

 该算法正确打印：```
chest
```现在考虑循环重复多次的情况：```
5
1 2 3 4 5
```处理步骤：

 - 索引 0 → 胸部 += 1
 - 指数 1 → 二头肌 += 2
 - 索引 2 → 返回 += 3
 - 索引 3 → 胸部 += 4
 - 索引 4 → 二头肌 += 5

 最终总计：

 - 胸部 = 5
 - 二头肌 = 7
 - 后= 3

 输出是：```
biceps
```这证实了基于模的分配在前三个练习之后继续正确地进行。 

最后，考虑一个暴露了相差一错误的情况：```
3
10 1 20
```正确的映射：

 - 第一个练习 → 胸部
 - 第二个练习 → 二头肌
 - 第三个练习 → 背部

 总计变为：

 - 胸部 = 10
 - 二头肌 = 1
 - 后退 = 20

 正确的输出是：```
back
```如果有人因为基于 1 的混淆而意外地将索引 0 视为二头肌，则所有总数都会错误地移动。 所提出的算法通过自始至终使用一致的从零开始的索引来避免这种情况。
