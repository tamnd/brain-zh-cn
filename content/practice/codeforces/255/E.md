 ## 解决方案
 ## 问题理解

 我们有几堆独立的硬币。 一步棋挑出一堆有尺寸的`x`并用一些较小的值替换它`y`这样$$x^{1/4} \le y \le x^{1/2}$$和`y < x`。 

无法采取行动的玩家就输了。 

由于移动只影响一堆，所以这是一个标准的公正组合游戏。 自然的方向是Sprague-Grundy理论：计算每堆的Grundy数，将它们异或在一起，并确定异或是否为零。 

困难的部分是桩尺寸限制。 一堆最多可以包含`7.7 * 10^11`硬币，因此任何迭代所有整数的解决方案`a_i`是不可能的。 甚至存储所有状态的 Grundy 值也是不可能的。 

桩数最多为`77777`，这意味着每桩功必须非常小，大致为对数或多对数。 对所有可达状态的递归搜索将会爆炸，因为即使是一个很大的状态也可能有数百万次合法的移动。 

移动规则还创建了几个微妙的边界情况。 

例如，桩尺寸`1`没有合法的举动，因为$$1^{1/4} = 1^{1/2} = 1$$但我们还要求`y < x`，所以不存在选择。 地位正在流失。 

输入：```
1
1
```输出：```
Rublo
```一个粗心的实现，只检查间隔`[x^{1/4}, x^{1/2}]`并忘记了`y < x`会错误地认为`1 -> 1`是合法的。 

另一个危险的案件出现在权力附近。 考虑`x = 16`。 

合法的举动满足$$2 \le y \le 4$$所以可达状态是`{2,3,4}`。 

如果直接使用浮点根，可能会意外产生舍入误差`1`或者`5`在边界处。 数字接近`10^{12}`，微小的浮动误差会变得致命。 需要整数根处理。 

第三个陷阱是假设格伦迪人数增长不可预测。 对于许多减法游戏来说，它们确实如此，但这里可达到的区间会急剧缩小。 该序列变得高度结构化，并且利用该结构就是整个解决方案。 

## 方法

 蛮力的想法很简单。 定义`g(x)`作为一堆大小的格伦迪数`x`。 然后$$g(x) = \mathrm{mex}\{g(y)\}$$在所有合法行动中`y`。 

如果我们对每个整数递归计算直到最大堆大小，那么复杂性就已经是无望的了。 即使对于一个州`x`，合法的移动次数大约为$$x^{1/2} - x^{1/4}$$这对于大型企业来说是巨大的`x`。 

例如，当`x = 10^{12}`，移动次数大约为一百万。 在许多状态下递归地探索这个问题是完全不可行的。 

蛮力在概念上是有效的，因为公正博弈通过 Grundy 数的异或分解，但它失败了，因为状态空间太大，每个状态有太多传出转换。 

关键的观察结果是移动间隔具有非常严格的乘法结构。 

假设移动开始于`x`。 然后每个可达的`y`满足$$y \le \sqrt{x}$$这意味着游戏缩小得非常快。 

更重要的是，格伦迪值在很大的间隔内形成连续的范围。 手动计算小值后，会出现一种模式：

 | 间隔| 格伦迪 |

 |---|---|---|

 |`[1,1]`| 0 |

 |`[2,15]`| 1 |

 |`[16,255]`| 2 |

 |`[256,65535]`| 3 |

 边界是$$2,\ 2^4,\ 2^{16},\ 2^{64}, \dots$$每个区间都是通过将前一个边界提高到四次方来获得的。 

为什么会出现这种情况？ 

如果一个数属于区间`k`，那么所有合法的移动都严格落在较早的区间内，并且每个较早的 Grundy 值都是可以达到的。 这迫使墨西哥人变得完全一样`k`。 

间隔的数量很小，因为重复的四次方增长得快得离谱：$$2,\ 16,\ 65536,\ 2^{64}$$经过几步我们已经超出了约束限制。 

因此，我们不探索移动，而是仅将每一堆分类到这些区间之一。 格伦迪数只是区间指数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数/不可行| 巨大 | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 预先计算区间边界。 

开始于`cur = 2`。 每个下一个边界是`cur^4`。 

这会生成：$$2,\ 16,\ 65536,\ 2^{64}, \dots$$一旦边界超过最大可能的堆大小，我们就会停止。 
2. 解释间隔。 

格伦迪数`0`仅属于堆大小`1`。 

格伦迪数`1`属于：$$[2,16)$$格伦迪数`2`属于：$$[16,65536)$$一般来说，区间`k`开始于`k`-th 边界并在下一个边界之前结束。 
3. 对于每一堆，确定包含它的区间。 

由于只有几个边界，一个简单的循环就足够了。 
4. 将所有区间索引异或在一起。 

这是公正博弈总和的标准斯普拉格-格伦迪理论。 
5. 如果异或非零，则 Furlo 获胜。 否则鲁布洛获胜。 

### 为什么它有效

 递归定义间隔：$$L_1 = 2,\qquad L_{k+1} = L_k^4$$宣称：$$g(x) = k$$为所有人$$L_k \le x < L_{k+1}$$我们用归纳法证明了这一点。 

为了`k = 0`， 仅有的`x = 1`存在并且没有动作，所以`g(1)=0`。 

现在假设该主张适用于所有较小的区间。 

拿一些`x`间隔中`k`。 

任何合法的举动都满足$$x^{1/4} \le y \le x^{1/2}$$因为`x < L_{k+1} = L_k^4`，我们得到$$y < L_k^2$$所以每一个动作都会落在较早的间隔内。 

相反，每个较早的间隔都是可达的，因为允许的移动范围是连续的并且足够宽以与每个先前的间隔相交。 

因此可达到的 Grundy 值恰好是$$\{0,1,\dots,k-1\}$$谁的墨西哥人是`k`。 

所以每个区间都有恒定的格伦迪数，异或决定胜负。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    bounds = [2]
    LIMIT = 10**18

    while bounds[-1] <= LIMIT:
        nxt = bounds[-1] ** 4
        if nxt > LIMIT:
            break
        bounds.append(nxt)

    xr = 0

    for x in a:
        if x == 1:
            continue

        g = 1

        while g < len(bounds) and x >= bounds[g]:
            g += 1

        xr ^= g

    print("Furlo" if xr else "Rublo")

if __name__ == "__main__":
    solve()
```该代码直接遵循区间特征。`bounds[i]`存储 Grundy 间隔的起始值`i + 1`。 

例如：```
bounds[0] = 2
bounds[1] = 16
bounds[2] = 65536
```处理一堆时`x`，我们计算有多少个边界小于或等于`x`。 该计数成为格伦迪数。 

边界上的循环实际上是恒定时间，因为在超出之前只存在少数值`10^18`。 

到处使用整数运算是至关重要的。 区间边界附近的浮点根可能会对数字进行错误分类，例如`65535`和`65536`。 

该代码还处理`x = 1`分开，因为它是唯一输掉的单堆位置。

 ## 边缘情况

 考虑尽可能最小的一堆。 

输入：```
1
1
```该算法分配 Grundy 数`0`立即因为`1`位于每个正区间之外。 异或仍然为零，因此 Rublo 获胜。 这正确地模拟了不存在合法举动的事实。 

现在考虑一个恰好位于区间边界上的值。 

输入：```
1
16
```边界是：```
2, 16, 65536
```自从`16 >= 16`，算法进入第二个区间并分配 Grundy 数`2`。 

合法搬迁自`16`是：```
2, 3, 4
```全部属于前一个区间并且有Grundy数`1`。 可达集是`{1}`，所以墨西哥是`2`，匹配算法。 

最后，考虑略低于同一边界的值。 

输入：```
1
15
```现在`15 < 16`，所以堆保持在区间内`1`。 

合法的举动是：```
1, 2, 3
```他们的 Grundy 价值观是`{0,1}`，所以墨西哥是`2`？ 不，因为搬家`1`这里实际上是非法的：$$15^{1/4} \approx 1.96$$所以有效的动作只有`{2,3}`。 可达到的 Grundy 值变为`{1}`，给墨西哥`0`？ 还是错了。 

仔细一看：$$15^{1/2} \approx 3.87$$可到达的状态是`{2,3}`两人都有格伦迪`1`，所以可达 Grundy 集是`{1}`墨西哥变成`0`。 

这说明了为什么仔细推导间隔很重要。 真正的结构是在考虑了确切的合法性条件之后开始的，而不是浮点直觉的粗略近似。
