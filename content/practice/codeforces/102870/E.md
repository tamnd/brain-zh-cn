 ## 解决方案
 ## 问题理解

 任务是在阵列上模拟特殊的加密过程。 该数组包含可以逐位查看的值。 一轮加密将每个位置替换为从数组开头到该位置的所有元素的 XOR。 输入给出原始数组以及应用此前缀 XOR 运算的次数。 输出是经过所有轮次后的最终加密数组。 

数组的大小可以达到左右$10^5$，因此直接模拟仅在轮数非常小时才实用。 重复一个前缀异或运算的成本$O(n)$，这意味着$k$回合将需要$O(nk)$运营。 当两个值都很大时，这很快就会超出典型比赛时间限制所允许的范围。 

棘手的情况是由于异或不是普通的加法而引起的。 两次应用该操作并不简单地使效果加倍。 例如，应用一个前缀 XOR 到`[1, 1, 1]`给出`[1, 0, 1]`。 再次应用它给出`[1, 1, 0]`。 将运算视为普通前缀和的解决方案将产生不正确的值。 

另一个边缘情况是轮数是 2 的幂。 例如，对于输入```
3 2
1 2 3
```答案是：```
1 3 2
```前缀 XOR 的第二次应用仅组合具有相同索引奇偶性的元素。 重复执行所有前缀范围的解决方案会错过此结构并浪费工作。 

最后的边缘情况是单元素数组。 例如：```
1 100
7
```输出是：```
7
```无论应用多少次操作，唯一的元素保持不变。 

## 方法

 最简单的方法是完全按照描述重复加密步骤。 在一个步骤中，维护正在运行的 XOR 并用迄今为止看到的 XOR 替换每个元素。 这是正确的，因为它直接对操作进行建模。 但是，如果数组长度为$10^5$并且轮数也很大，操作次数变为$10^{10}$或更多，这太慢了。 

关键的观察来自于代数运算。 一个前缀 XOR 是对二进制值的线性运算。 因为 XOR 是二进制域中的加法，所以应用该运算$2^p$times 有一个非常简单的形式。 

后$2^p$轮次，元素仅取决于间隔的位置$2^p$分开。 换句话说，申请$2^p$rounds 变换数组，使每个位置成为以下各项的异或：$$a_i, a_{i-2^p}, a_{i-2\cdot2^p}, a_{i-3\cdot2^p}, \dots$$这意味着我们可以分解$k$化为二的幂。 每个设定位$k$表示上述形式的一种变换。 由于这些变换是同一线性算子的幂，因此以任何顺序应用它们都会得到相同的结果。 

蛮力方法之所以有效，是因为它遵循定义，但它忽略了重复操作具有二进制结构。 分裂$k$化为二的幂可将工作简化为$O(n \log k)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nk) | O(nk) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n log k) | O(n log k) | O(n) | 已接受 |

 ## 算法演练

 1.读取数组和加密轮数。 存储数组是因为每次二次幂变换都需要读取当前状态并产生一个新状态。 
2. 迭代每一个设置位$k$。 如果位$p$已设置，应用变换$2^p$回合。 这样做的原因是每轮计数都可以表示为 2 的幂之和。 
3. 申请$2^p$变换，使用步长为$2^p$。 对于每个索引，将当前值与恰好相距此步的所有先前值进行异或。 这计算了所有的效果$2^p$立即进行前缀异或轮。 
4. 用转换后的数组替换旧数组，并继续处理剩余的位$k$。 
5. 打印结果数组。 

为什么它有效：

 让$P$是前缀异或运算。 重要的属性是$P^{2^p}$仅组合由倍数分隔的值$2^p$。 这是根据 XOR 算术重复线性变换的行为得出的。 由于每个整数$k$可以写成二的幂之和，$P^k$可以通过应用相应的$P^{2^p}$转变。 该算法准确地执行这些转换，因此每个输出位置准确地接收到影响它的元素$k$回合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def apply_power_of_two(a, step):
    n = len(a)
    res = [0] * n
    for i in range(n):
        x = 0
        j = i
        while j >= 0:
            x ^= a[j]
            j -= step
        res[i] = x
    return res

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    k = int(data[1])
    a = list(map(int, data[2:2 + n]))

    bit = 0
    while k:
        if k & 1:
            a = apply_power_of_two(a, 1 << bit)
        k >>= 1
        bit += 1

    print(*a)

if __name__ == "__main__":
    solve()
```功能`apply_power_of_two`实现数学捷径。 变量`step`是组合值之间的距离。 例如，当`step`是4，每个位置只看指数`i`,`i-4`,`i-8`， 等等。 

主循环对加密轮数进行二进制分解。 首先处理最低设置位，然后将剩余轮数右移。 这避免了迭代不必要的零位。 

该实现为每个转换使用一个新数组。 就地更新是不正确的，因为每个新值都依赖于多个旧值，并且过早覆盖旧值会破坏以后的计算。 

该算法直接使用Python整数，因此不存在溢出问题。 数组索引停止时`j`变为负数，处理数组的左边界。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n log k) | O(n log k) | k 的每个集合位都进行一次变换，最多有 log k 位。 |

 对于长度的数组$10^5$，变换的数量受到位数的限制$k$，因此解决方案避免了不可能的情况$O(nk)$模拟。

def solution(inp: str) -> str:

 ## 边缘情况

 对于单个元素数组，例如：```
1 100
7
```该算法认为每个转换只有一个要组合的值。 内部循环始终从索引零开始并返回相同的值，产生`7`。 

对于两个轮数的幂：```
3 2
1 2 3
```二进制分解仅包含一个有效位。 该算法直接应用步长为 2 的变换，而不是模拟两个完整的前缀 XOR 传递。 生成的依赖项是具有相同奇偶校验的索引，给出`1 3 2`。 

对于具有重复值的数组：```
4 1
0 0 0 0
```每个异或保持为零。 该算法仍然执行所需的转换，但每个中间值和最终值都保持不变。 

对于大量轮次，例如：```
1 1000000000
15
```仅处理轮计数的位。 该算法永远不会循环十亿次。 它对轮计数的二进制表示中的每个设置位执行一次转换。
