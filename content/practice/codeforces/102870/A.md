 ## 解决方案
 ## 问题理解

 该任务描述一排相邻的建筑物，其中每个建筑物都有高度和宽度。 由于建筑物相互接触，它们的正面形成了一条连续的天际线。 我们需要在该天际线内放置一个矩形广告，广告的高度和宽度垂直于原始建筑物的高度，并找到最大的可能区域。 输入给出每个建筑物的高度和宽度，输出是该矩形的最大面积。 

主要困难来自于建筑物的宽度并不相同。 一个矩形可以覆盖多个连续的建筑物，但其高度受到这些建筑物中最矮的建筑物的限制。 如果我们尝试建筑物的每个间隔，我们将需要检查最多$O(n^2)$间隔。 和$n$达到$100000$，这意味着大约$10^{10}$间隔检查，这远远超出了典型比赛时间限制所允许的范围。 该算法必须接近线性。 

在一些边缘情况下，粗心的实施可能会失败。 如果一栋建筑物是最高的，则答案可能来自仅使用该建筑物。 例如：```
1
7 3
```正确的输出是：```
21
```仅检查成对建筑物的方法会错过单个建筑物内的矩形。 

另一个棘手的情况是当几座相邻的建筑物具有相同的高度时。 例如：```
3
5 2
5 3
5 4
```正确的输出是：```
45
```可以使用整行，因为每个建筑物都支持高度$5$。 将相等高度视为单独且从不合并它们的实现可能会丢失总宽度并产生较小的答案。 

当最短的建筑物位于最后时，就会出现最后一个常见错误。 例如：```
3
4 2
4 2
1 10
```正确的输出是：```
16
```最好的矩形使用前两个建筑物的高度$4$和宽度$4$。 仅在看到较短建筑物时计算面积但忘记在扫描后处理剩余堆栈的解决方案将错过该矩形。 

## 方法

 直接的方法是考虑每组连续的建筑物。 对于每个间隔，我们计算该间隔内的总宽度和最小高度。 由该间隔形成的矩形的面积等于最小高度乘以总宽度。 这是正确的，因为每个可能的矩形必须完全适合某些连续的建筑物组，并且其高度不能超过该组中最矮的建筑物。 

然而，这检查了太多的间隔。 和$n=100000$, 大致可以有$n(n+1)/2$不同的间隔，大约是$5 \times 10^9$。 即使计算每个间隔是恒定时间，这仍然太慢。 

关键的观察是我们不需要显式测试每个区间。 当建筑物变得比以前的建筑物矮时，较高的建筑物将无法再延伸到当前位置。 此时，我们知道每个较高建筑物的最大宽度可能是限制高度。 

这正是单调堆栈处理的情况。 堆栈按高度递增的顺序存储建筑物。 不是单独存储每个原始建筑物，而是合并具有相同高度的连续建筑物，因为它们的行为始终相同：相同的高度可以覆盖它们的组合宽度。 

暴力方法之所以有效，是因为每个可能的矩形都由某个区间表示。 它失败是因为它反复重新计算有关重叠间隔的信息。 单调堆栈通过仅处理每个建筑物恒定的次数来消除这种重复。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从左到右阅读建筑物并维护一堆对。 每对存储一个高度以及具有该高度的连续建筑物所覆盖的总宽度。 

堆栈按高度递增的顺序保持。 这意味着堆栈中剩余的每个高度仍然有机会进一步向右延伸。 

1、对于当前建筑物，首先以自身的宽度作为当前正在处理的宽度。 

如果堆栈顶部的高度大于当前建筑物的高度，则该较高的高度无法继续超过此点。 将其从堆栈中删除并使用该高度计算矩形。 该矩形的宽度是当前累积的宽度，因为所有移除的建筑物都是连续的，并且所有建筑物的高度至少与移除的高度一样高。 

1. 继续移除较高的建筑物，直到堆叠为空或顶部高度不大于当前高度。 

删除较高的块后，其宽度将添加到当前宽度。 这使得当前建筑物与之前所有较短或相等的区域结合起来。 

1. 如果堆栈顶部与当前建筑物的高度相同，则合并宽度。 

相等的高度表示相同的可能矩形高度，因此将它们保留为单独的堆栈条目只会使后续计算变得复杂。 

1. 如果没有相等的高度可合并，则将当前高度及其累加宽度压入堆栈。 
2. 处理完所有建筑物后，移除所有剩余的堆叠条目并使用累积宽度计算其面积。 

最终位置之后没有更矮的建筑，因此每个剩余的高度都可以延伸到天际线的尽头。 

为什么它有效：

 堆栈的不变性是相等高度合并后高度严格增加。 每个条目代表一组连续的建筑物，其中该高度是迄今为止看到的最小高度。 当出现一座较短的建筑物时，每个被移除的较高高度都会在右侧找到第一个较小的边界。 此时的累积宽度恰好是该高度可用的最大宽度。 由于每个建筑物都被推入一次并弹出一次，因此会评估每个可能的限制高度，因此不会错过最大面积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    buildings = [tuple(map(int, input().split())) for _ in range(n)]

    stack = []
    ans = 0

    for h, w in buildings:
        cur_w = w

        while stack and stack[-1][0] > h:
            ph, pw = stack.pop()
            cur_w += pw
            ans = max(ans, ph * cur_w)

        if stack and stack[-1][0] == h:
            stack[-1] = (h, stack[-1][1] + cur_w)
        else:
            stack.append((h, cur_w))

    cur_w = 0
    while stack:
        h, w = stack.pop()
        cur_w += w
        ans = max(ans, h * cur_w)

    print(ans)

if __name__ == "__main__":
    solve()
```堆栈存储`(height, width)`对而不是指数。 由于宽度是输入的一部分，因此基于索引的直方图解决方案不太方便。 累积的宽度是重要的信息，因为最终的矩形面积取决于水平覆盖范围。 

建筑物上的循环处理较短建筑物封闭先前矩形的所有情况。 条件使用`>`而不是`>=`因为相等的高度应该合并而不是删除。 这可以避免将一个矩形分割成几个较小的块。 

最后的清理循环是必要的，因为某些矩形在天际线结束之前仍然有效。 忘记这一步就会丢失最大矩形在最后一座建筑物结束处的答案。 

Python 整数可以处理最大可能的区域，因为最大高度和总宽度都最多约为$10^{10}$相乘时，在 Python 的整数范围内。

 ## 边缘情况

 对于单体建筑案例：```
1
7 3
```该建筑物被推入堆栈。 清理时，以累积宽度去除`3`、产地`7 * 3 = 21`。 该算法可以处理这种情况，因为最终的清理处理的是从未遇到过较小建筑物的矩形。 

对于相同高度：```
3
5 2
5 3
5 4
```第一栋建筑创造了`(5,2)`。 第二栋建筑具有相同的高度，因此堆栈条目变为`(5,5)`。 第三个将其扩展为`(5,9)`。 在清理过程中，该区域变为`5 * 9 = 45`。 合并规则保留全部可能的宽度。 

对于最小建筑物最后的边界情况：```
3
4 2
4 2
1 10
```两人身高`4`建筑物合并成`(4,4)`。 当高度`1`出现时，堆栈移除高度`4`并评估面积`4 * 4 = 16`。 最后一座建筑无法改善答案，因此结果保持不变`16`。 这说明了为什么较短的建筑物会触发矩形评估。
