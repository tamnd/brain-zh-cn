 ## 解决方案
 ## 问题理解

 该问题按照不规则多边形的边界出现的顺序给出了它们的顶点。 每个顶点都有整数坐标。 任务是计算该多边形所包围的精确面积并打印结果。 输入不描述网格形状或单元格集合。 它是一个几何边界，因此点的顺序很重要，因为每个点都连接到下一个点，最后一个点又连接回第一个点。 

顶点数量足够小，O(n) 解就是预期的方向。 任何尝试每对顶点、构建许多三角形或重复执行几何检查的算法都会增加不必要的工作。 尽管坐标值可能很大，但多边形顶点都是整数，因此在最终除以二之前可以使用整数运算来精确表示面积。 

一个常见的错误是从一开始就使用浮点几何。 大坐标会使浮点累加失去精度，特别是当许多正负叉积相互抵消时。 另一个错误是忘记多边形可以有以 0.5 结尾的小数面积。 

考虑一个有顶点的三角形：```
3
0 0
1 0
0 1
```正确的输出是：```
0.5
```仅将区域存储为整数的实现将错误地输出`0`。 

另一种边缘情况是多边形，其点按顺时针方向而不是逆时针方向列出：```
4
0 0
0 1
1 1
1 0
```有符号面积变为负值。 实际的几何面积是正数，所以在格式化答案之前必须取绝对值。 

第三种情况是退化多边形：```
3
0 0
1 1
2 2
```所有点都在同一条线上，所以封闭的面积是`0`。 正确的鞋带实现自然可以处理这个问题，因为所有跨产品贡献都会取消。 

## 方法

 最简单的方法是将多边形分割成三角形。 人们可以选择第一个顶点作为固定点，并计算由它和两个相邻顶点形成的每个三角形的面积。 这是正确的，因为任何简单的多边形都可以分为三角形。 然而，粗心的实现可能会重复计算几何关系或搜索有效的对角线，从而产生不必要的复杂性。 

关键的观察是多边形区域不需要显式构造三角形。 鞋带公式直接将边界转化为叉积之​​和。 对于每条边`(x_i, y_i)`到`(x_{i+1}, y_{i+1})`，我们添加`x_i * y_{i+1} - x_{i+1} * y_i`。 该总和的最终绝对值是多边形面积的两倍。 

该公式之所以有效，是因为每条边都以原点贡献了三角形的有符号面积。 当所有边界边合并时，外部区域会取消，仅保留多边形内部。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力三角形构造| O(n²) | O(1) | O(1) | 太慢而且没必要 |
 | 鞋带配方| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 按给定顺序读取所有多边形顶点。 必须保留顺序，因为多边形的边是由连续的顶点定义的。 
2. 迭代每个顶点并将其与循环中的下一个顶点配对。 对于最后一个顶点，下一个顶点是第一个顶点。 添加交叉产品贡献`x_i * y_next - x_next * y_i`到一个连续的总和。 
3. 取累计和的绝对值。 该符号仅表明顶点是顺时针还是逆时针列出。 
4. 通过将加倍的区域除以二来格式化结果。 如果该值为奇数，则该区域有`.5`小数部分。 

原理：鞋带总和恰好是多边形有符号面积的两倍。 每个有向边贡献一个相对于原点的三角形区域。 添加所有这些签名贡献会删除多边形外部的区域并保留内部。 取绝对值消除了对遍历方向的依赖，因此算法始终返回真实的几何面积。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return

    it = iter(data)
    n = int(next(it))

    points = []
    for _ in range(n):
        x = int(next(it))
        y = int(next(it))
        points.append((x, y))

    area2 = 0

    for i in range(n):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % n]
        area2 += x1 * y2 - x2 * y1

    area2 = abs(area2)

    if area2 % 2 == 0:
        print(area2 // 2)
    else:
        print(str(area2 // 2) + ".5")

if __name__ == "__main__":
    solve()
```输入部分存储顶点，因为鞋带公式需要循环顺序。 将点保留在列表中还可以使从最终顶点回到第一个顶点的环绕边变得简单，并避免边界错误。 

主循环计算双倍符号面积。 Python 整数不会溢出，这在这里很有用，因为坐标乘法可以比原始坐标范围大得多。 

输出逻辑完全避免浮点。 由于计算值是面积的两倍，因此偶数值表示整数面积，奇数值表示以`.5`。

 ## 边缘情况

 对于分数三角形的情况：```
3
0 0
1 0
0 1
```该算法计算双倍面积`1`。 由于它是奇数，因此打印`0.5`。 不需要浮点计算。 

对于颠倒的顶点顺序：```
4
0 0
0 1
1 1
1 0
```因为遍历是顺时针方向，所以鞋带总和变为负值。 绝对值将面积增加一倍`-2`到`2`，产生正确答案`1`。 

对于退化多边形：```
3
0 0
1 1
2 2
```交叉产品的贡献相互抵消。 最终面积翻倍为`0`，所以算法正确打印`0`。 

对于大坐标，每次乘法都是使用整数算术执行的。 Python 会自动处理所需的精度，因此中间计算不会出现舍入误差。
