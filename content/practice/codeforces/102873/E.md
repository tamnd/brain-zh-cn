 ## 解决方案
 ## 问题理解

 我们得到一个字符串`s`包含小写英文字母和另一个字符串`t`长度为二。 目标是计算有多少对位置`(L, R)`产生一个子串`s[L..R]`其中包含`t`它内部的某个地方作为连续的部分。 不同的选择`L`和`R`即使结果文本相同，也会单独计数。 

长度为`s`可以达到`200000`，因此检查每个可能的子字符串是不可能的。 这种大小的字符串大约有`n(n+1)/2`子串，大约有 200 亿个`n`是`200000`。 任何单独检查每个子串的方法都远远超出了一两秒的竞赛解决方案所能承受的范围。 我们需要一个线性或接近线性的算法。 

棘手的部分是我们没有计算出现的次数`t`。 我们正在计算至少包含一次出现的较大子字符串。 一个常见的错误是找出每一个出现的`t`并添加从它延伸的子字符串的数量。 每当一个子字符串包含多次出现时，就会重复计数`t`。 

例如，考虑：```
s = ababa
t = ab
```的出现情况`ab`从位置开始`0`和`2`。 像这样的子串`ababa`包含两次出现，因此独立于每次出现计算贡献将计算两次。 正确答案是`10`，因为除了那些不包含的子串之外的每个子串`ab`发生次数应该只计算一次。 

另一种边缘情况是模式从未出现：```
s = abcdef
t = gh
```正确的输出是`0`。 仅计算可能的结束位置而不验证模式是否存在的方法可能会意外添加无效子字符串。 

最后的边界情况是模式出现在最开始或最后的时候：```
s = abc
t = ab
```正确的输出是`2`，对应于`ab`和`abc`。 仅对出现后的字符进行计数的解决方案可能会忘记在出现之前开始或恰好在出现时结束的子字符串。 

## 方法

 直接的方法是枚举每个子字符串并检查它是否包含`t`。 有`O(n^2)`子串，检查一个子串需要最多`O(n)`在最坏的情况下工作，给予`O(n^3)`运营。 即使通过字符串搜索改进检查步骤仍然存在问题`O(n^2)`子串，对于它来说已经太大了`n = 200000`。 

关键的观察是`t`长度只有二。 我们不需要知道子字符串的全部内容。 我们只需要知道其中是否出现了特定的相邻对。 

假设我们从左到右扫描字符串。 对于每个结束位置`R`，我们想知道有多少个起始位置`L`制作`s[L..R]`有效的。 如果最近出现的`t`结束于或之前`R`从位置开始`last`，然后每个子串结束于`R`和`L <= last`包含该事件。 正好有`last + 1`这样的起始位置。 

这将问题转化为在扫描时维持一个值。 每当我们看到两个字符模式在当前位置结束时，我们都会更新出现的最新起始位置。 每个位置都会贡献以该位置结尾的有效子字符串的数量。 

暴力破解之所以有效，是因为每个子字符串都可以独立检查，但会失败，因为子字符串太多。 只有最近发生的事件才重要的观察结果让我们能够计算在恒定时间内以每个位置结尾的所有有效子字符串。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n2) 或 O(n3) 取决于检查方法 | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从左到右扫描字符串并保留`last`，最近出现的起始索引`t`。 最初，没有发现任何情况，因此`last = -1`。 
2. 每个位置`i`,检查子串是否`s[i-1..i]`等于`t`。 如果是的话更新一下`last = i - 1`。 这存储了最右边的出现，可以帮助以或之后结尾的子字符串`i`。 
3.添加`last + 1`到答案。 价值`last + 1`代表所有可能的起始位置`0`通过`last`。 每一个开头都会创建一个以以下结尾的子字符串`i`其中包含最新出现的`t`。 
4.处理完所有位置后，输出累计答案。 

为什么它有效：

 对于固定的结束位置`i`, 一个子串`s[L..i]`当且仅当它包含以下情况时才有效`t`其起始位置至少为`L`。 最右边的事件结束时间不晚于`i`是最容易使用的，因为它具有最大的起始索引。 如果这种情况开始于`last`，那么每一个`L <= last`有效，同时每个`L > last`也不能包括任何较早发生的情况。 因此确切地说`last + 1`子串结束于`i`是有效的，并且将所有结尾的数量相加即可计算出每个有效对`(L, R)`正好一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()
t = input().strip()

last = -1
ans = 0

for i in range(n):
    if i > 0 and s[i - 1:i + 1] == t:
        last = i - 1
    ans += last + 1

print(ans)
```变量`last`表示目标对的最新有用出现。 仅当当前字符完成出现时才会更新，因此它始终描述当前右端点的最佳可能出现。 

更新后会累积答案，因为以当前索引结尾的出现可以立即使以该结尾的子字符串有效。 切片`s[i - 1:i + 1]`仅在以下情况下评估`i > 0`，防止第一个字符之前的无效访问。 

Python 整数自动处理最大答案。 有效对的数量可以是`n²`，它比 32 位整数大得多。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个字符都被处理一次，并且每次检查都需要恒定的时间。 |

import io

 ## 边缘情况

 对于`s = "abcdef"`和`t = "gh"`，算法永远不会更新`last`，所以仍然是`-1`。 每个位置加零，产生`0`。 这处理丢失模式的情况，因为没有结束位置具有有效的子字符串。 

为了`s = "abc"`和`t = "ab"`，当出现`i = 1`， 环境`last = 0`。 答案收获`1`为了`ab`。 在`i = 2`,`last`仍然是`0`，添加另一个`1`为了`abc`。 最终的答案是`2`，包括超出出现范围的子字符串。 

为了`s = "ababa"`和`t = "ab"`，出现次数从索引处开始`0`和`2`。 该算法取代`last`和`2`当第二次出现时。 从那时起，在该点之后结束的每个子字符串都会计入所有从索引开始的位置`2`，因此包含两次出现的子字符串仅计算一次。
