 ## 解决方案
 ## 问题理解

 我们有一排胡萝卜，每根胡萝卜都有一个大小。 两只兔子从这一行的两端开始。 只有当兔子到达的下一个胡萝卜至少与它刚刚吃掉的胡萝卜一样大时，它才能继续向内移动。 两只兔子可以选择自己的移动顺序，因此目标是在两只兔子无法再继续之前最大限度地吃掉多少种不同的胡萝卜。 问题要求最大计数。 

第一个兔子仅依赖于数组的最长非递减前缀。 如果前几根胡萝卜是`1 2 2 5`，它可以吃掉所有的东西，因为每一个动作都是允许的。 第二只兔子从另一边看有对称条件：从右到左看，被吃掉的序列一定是非减的，这意味着从左到右看，剩余的后缀一定是非增的。 

约束条件`n <= 2 * 10^5`排除了模拟兔子移动的每种可能的顺序。 任何尝试多种移动组合的方法都很容易变得二次或更糟，并且周围`4 * 10^10`操作将远远超出限制。 我们需要线性扫描，因为它只处理整个数组恒定的次数。 

棘手的情况是两只兔子的可到达部分接触或重叠。 一个常见的错误是单独数两只兔子，结果不小心把同一个胡萝卜数了两次。 例如：```
Input
5
2 2 2 2 2
```正确的输出是：```
5
```两只兔子都能够到每根胡萝卜，但中间的胡萝卜不会被数两次。 答案是可以覆盖的不同胡萝卜的数量。 

另一种边界情况是一只兔子立即停止。 例如：```
Input
4
5 1 1 1
```正确的输出是：```
4
```左边的兔子只吃第一个胡萝卜，因为下一个更小。 正确的兔子可以吃掉整个后缀`1 1 1`。 假设两只兔子总是贡献多于一根胡萝卜的解决方案在这里会失败。 

最后一种情况是可到达部分由递减跳跃分隔开：```
Input
5
1 3 2 3 1
```正确的输出是：```
4
```左边的兔子到达了前两根胡萝卜，右边的兔子到达了最后两根胡萝卜。 中间的胡萝卜是任何一只兔子都够不到的。 

## 方法

 直接的方法是模拟两只兔子。 我们可以从左端点开始，反复移动，直到下一个胡萝卜满足条件。 我们可以从正确的端点做同样的事情。 这正确地识别了每只兔子可能吃的每根胡萝卜，因为一旦兔子的起始边固定，其路径就是确定的。 

全面模拟可能的移动顺序的问题在于，它将兔子之间的交互视为有许多有意义的选择。 事实上，唯一重要的信息是每只兔子能到达的最远位置。 左边的兔子总是声明一个前缀，右边的兔子总是声明一个后缀。 

简化问题的观察结果是，只有当两只兔子都想要相同的胡萝卜时，移动的顺序才重要。 我们可以让左边的兔子获取其可达前缀中的每一个胡萝卜，而右边的兔子获取其可达后缀中的每一个胡萝卜。 最大答案就是这两个范围的并集的大小。 

所有移动顺序的暴力模拟可以有指数级的多种可能性，因为在任何时刻，任何一只兔子都可能移动。 甚至跟踪许多状态也是不必要的，因为可到达的间隔完全描述了游戏。 最佳解决方案通过两次扫描找到两个边界并将它们组合起来。

 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.从左侧开始扫描，找到最后一个索引`left`那属于第一只兔子的道路。 从吃的第一根胡萝卜开始。 当下一个胡萝卜大于或等于当前胡萝卜时继续移动。 最终索引是可达前缀的末尾。 
2.从右侧开始扫描，找到第一个索引`right`那属于第二只兔子的道路。 从最后吃掉的胡萝卜开始。 当从兔子的角度来看下一个胡萝卜大于或等于当前的胡萝卜时，向左移动。 按照数组顺序，这意味着前一个元素必须大于或等于当前元素。 
3. 左边的兔子可以吃掉区间内的所有胡萝卜`[0, left]`，而正确的兔子可以吃掉区间内的所有胡萝卜`[right, n-1]`。 如果这些间隔重叠，则重叠仅计算一次。 
4. 计算两个区间并集的大小。 如果`left < right`，区间是分开的，答案是`(left + 1) + (n - right)`。 否则，它们会重叠并覆盖整个部分`0`到`n - 1`，所以答案是`n`。 

为什么有效：运动规则使每只兔子的路径都是固定的。 左边的兔子无法跳过阻挡它的胡萝卜，因此它吃的所有东西都必须在一个最大前缀内。 同样的推理为正确的兔子给出了一个最大后缀。 任何最优游戏只能使用这两个区域的胡萝卜，并且通过适当选择移动顺序可以完全消耗这两个区域。 计算它们的联合就可以准确地给出吃掉的不同胡萝卜的最大数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    left = 0
    while left + 1 < n and a[left + 1] >= a[left]:
        left += 1

    right = n - 1
    while right - 1 >= 0 and a[right - 1] >= a[right]:
        right -= 1

    if left < right:
        ans = left + 1 + (n - right)
    else:
        ans = n

    print(ans)

if __name__ == "__main__":
    solve()
```第一个循环找到左边兔子的确切停止点。 比较使用`a[left + 1] >= a[left]`因为兔子正在从左向右移动，并且需要下一个胡萝卜至少与前一个一样大。 

第二个循环看起来类似，但向后运行。 条件是`a[right - 1] >= a[right]`因为兔子正在向较小的指数移动。 这相当于说它吃的顺序在兔子的运动方向上是非递减的。 

最终的计算处理兔子之间唯一的相互作用。 如果`left < right`，兔子有不相交的可达部分。 否则，它们的路径会相遇或交叉，并且它们一起可以覆盖两个端点之间的每根胡萝卜。 

除了输入数组之外，该实现仅使用几个整数变量。 Python 整数对于这些值不存在溢出问题，并且运算次数是线性的。

 ## 边缘情况

 对于全平等的情况：```
5
2 2 2 2 2
```左侧扫描到达索引`4`因为每一个动作都是被允许的。 右扫描到达索引`0`出于同样的原因。 间隔重叠，因此算法返回`n = 5`而不是将两个长度相加并产生无效答案。 

对于提前停止的情况：```
4
5 1 1 1
```左侧扫描保留在索引处`0`因为`1`小于`5`。 右侧扫描移动到索引`1`因为`1 1 1`从右到左有效。 间隔`[0,0]`和`[1,3]`是分开的，所以答案是`1 + 3 = 4`。 

对于重叠的情况：```
5
1 2 3 4 5
```左边的兔子到达索引`4`，右边的兔子到达索引`0`。 两个范围完全重叠，因此算法返回`5`。 独立计算两个范围将错误地返回`10`。 

对于分离的情况：```
5
1 3 2 3 1
```左侧扫描在索引处停止`1`，而右侧扫描在索引处停止`3`。 两只兔子可以吃的姿势`0,1,3,4`，给出正确答案`4`。 该算法从不包含索引`2`因为两条单调路径都不能穿过阻挡它的水滴。
