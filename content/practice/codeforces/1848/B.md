 ## 解决方案
 ## 问题理解

 我们有一个线性桥，表示为一系列木板颜色。 维卡在第一块木板之前开始，想要到达终点。 她只能在选定的一系列相同颜色的木板上行走，每次她从一个选定的木板走到下一个时，她可能必须穿过未选择的木板的间隙。 步长的大小正是连续选定位置之间跳过的木板的数量，目标是最小化最大的此类跳过。 

还有一个额外的转折。 在行走之前，维卡最多可以将一块木板重新涂成任何颜色，从而有效地修改单个位置的阵列。 她也可能选择不重新粉刷任何东西。 

任务是选择一种颜色和该颜色的位置子序列（可能在一次修改之后），使得连续选择的位置（包括开始和结束边界）之间的最大间隙最小化。 

答案是由所选颜色的出现引起的间隙的极小极大问题。 如果我们修复一种颜色，它的出现会将数组分成多个段，最差的段决定了该颜色作为步行路径的“危险”程度。 

这些约束意味着我们必须在所有测试用例中处理最多 2⋅10^5 个木板。 每个测试用例都是二次的任何解决方案都将立即失败。 对于每种情况，我们都需要一种接近线性或线性算术的方法，并且总体上是理想的线性方法。 

天真的尝试会尝试每种颜色和每个可能的重绘位置，重新计算间隙，并评估最大步长。 这将重复扫描数组并轻松达到 O(n^2)。 

当所有木板都具有相同的颜色时，就会出现微妙的边缘情况。 那么根本不存在间隙，所以答案为零。 另一种情况是当颜色完全交替时，即使是最佳的子序列仍然会产生不可避免的大间隙，除非重新绘制桥接它们。 

## 方法

 蛮力透视是固定颜色，收集其所有位置，并计算仅在这些位置上行走所引起的最大间隙。 无需重新绘制，这很简单。 问题在于重绘操作：我们可以在任何位置额外插入一次所选颜色，从而有效地将一个大间隙分成两个较小的间隙。 

如果我们对每种颜色和每个可能的插入位置进行模拟，我们将重复重新计算间隙结构。 对于每种颜色，维护所有间隙值并测试所有可能的分割点会导致每个候选间隙的工作量为 O(n)，在最坏的情况下变为 O(n^2)。 

关键的观察是，对于固定颜色，感兴趣的结构是其间隙数组：连续出现之间的距离，包括距数组边界的边缘。 无需重新绘制颜色的答案就是最大间隙。 通过一次重新绘制，我们可以将任何间隙分成两部分，只有当该间隙是唯一的瓶颈时才减少最大值。 

这将问题简化为评估对于每种颜色，通过最佳地插入一个额外的出现可以将最大间隙减少多少。 插入最好放置在最大间隙内，尽可能均匀地分割它，这样它的贡献就变成了上限（间隙/2）。 所有其他差距保持不变。 因此，对于每种颜色，我们只需要其间隙多重集及其最大值和第二最大值。 

我们可以一次性计算每种颜色的所有位置，计算 O（出现次数）中的间隙，并保持最好的两个最大值。 全局答案是所有颜色中可实现的最佳最大间隙的最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

1. 将列表中每种颜色的索引分组。 这是必要的，因为间隙结构仅取决于相对位置，而不是重复对整个阵列进行绝对扫描。 
2. 对于每种颜色，通过添加虚拟端点 0 和 n+1 来构建增强位置列表。 它们代表第一块木板之前的起点和最后一块木板之后的终点，因此边界处的间隙会得到统一处理。 
3. 计算连续位置之间的所有间隙。 每个间隙代表从一次出现的颜色移动到下一次出现的颜色时跳过的木板数量。 
4. 找出最大间隙gmax 和第二大间隙g2。 这两个值决定了一次重新绘制后的最佳结果，因为只能分割一个间隙。 
5. 如果我们不重新绘制，则该颜色的成本为 gmax。 如果我们重新绘制，我们选择将最大间隙分成两部分，将其减少到 ceil(gmax / 2)。 新的最差间隙变为 max(g2, ceil(gmax / 2))。 
6. 计算每种颜色的最佳值，并取所有颜色的最小值。 
7. 输出所有颜色中的最小值。 

### 为什么它有效

 对于固定颜色，任何有效的行走策略都对应于按顺序选择该颜色的所有出现，可能会由于重新绘制而通过人为插入的出现来增强。 这一插入点只能影响连续出现的一个间隔，因此只能分割一个原始间隙。 最佳分割始终以最大间隙为目标，因为减少任何较小的间隙并不会提高最大值。 因此，最优解仅取决于两个最大间隙，使结构完全可压缩。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        c = list(map(int, input().split()))

        pos = [[] for _ in range(k + 1)]
        for i, x in enumerate(c, start=1):
            pos[x].append(i)

        ans = n

        for color in range(1, k + 1):
            if not pos[color]:
                continue

            arr = [0] + pos[color] + [n + 1]

            gaps = []
            for i in range(1, len(arr)):
                gaps.append(arr[i] - arr[i - 1] - 1)

            if len(gaps) == 0:
                ans = 0
                continue

            gmax = max(gaps)
            g2 = 0
            for g in gaps:
                if g != gmax:
                    g2 = max(g2, g)

            best = max(g2, (gmax + 1) // 2)
            ans = min(ans, best)

        print(ans)

if __name__ == "__main__":
    solve()
```代码在一次通过中对每种颜色的位置进行分组，确保线性预处理。 对于每种颜色，它都会构建一个边界增强位置列表，以便在无需特殊外壳的情况下处理端点间隙。 然后，它计算一次遍历中的所有间隙，并提取最大和第二大间隙而不进行排序，这使每种颜色的处理在出现次数上保持线性。 

一个微妙的点是处理出现零次或一次的颜色。 如果出现次数为零，则颜色无关紧要。 出现一次时，间隙包括整个前缀和后缀，并且该公式仍然正确适用，因为单个间隙列表正确地代表了桥的两侧。

 ## 边缘情况

 像单色桥一样`[1,1,1,...]`不产生间隙。 该算法构造位置`[0,1,2,...,n,n+1]`，其中所有内部间隙均为零，因此 gmax 和 g2 均为零，产生答案零。 

一种颜色出现一次就会产生两个边界间隙。 例如`[2,1,1,1,3]`对于颜色 2 产生位置`[0,1,5]`和差距`[0,3]`。 最大间隙被正确处理为完整段长度。 

高度交替的阵列会产生许多小但频繁的间隙。 该算法仍然只跟踪每种颜色的最大间隙，确保正确处理，而无需模拟每条路径。
