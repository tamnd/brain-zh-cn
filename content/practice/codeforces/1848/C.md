 ## 解决方案
 ## 问题理解

 我们得到两个数组，分别代表一组商品的旧价格和新价格。 Vika 重复计算这些数组的相应元素之间的绝对差，交换数组，然后重复该过程。 目标是确定此迭代过程是否最终会将旧价格数组的所有元素减少到零。 如果这对数组达到这样的状态，每个测试用例都要求我们回答“是”，否则回答“否”。 

这些约束意味着每个测试用例最多可以有 10^5 个项目，最多可以有 10^4 个测试用例，但所有测试用例的项目总数上限为 10^5。 这告诉我们，我们必须在大致线性的时间内处理每个数组，因为二次算法太慢了。 

当旧数组最初全为零时，会出现不明显的边缘情况。 在这种情况下，无论新数组如何，该对都非常乏味。 当新数组的元素小于相应的旧数组值但并非所有差异都将旧数组减少为零时，会出现另一种微妙的情况。 如果我们尝试直接模拟每个操作的过程，我们可能会误判这些配置或超出时间限制。 

## 方法

 暴力方法显式地模拟数组转换。 在每个步骤中，它都会计算一个新数组作为绝对差，然后交换数组。 这是有效的，因为它直接对问题进行建模。 然而，在长度为 10^5 的数组的最坏情况下，每次操作都是 O(n)，并且迭代次数也可能是 O(n)，因为差异会缓慢减小。 这导致每个测试用例的时间复杂度为 O(n^2)，在给定输入范围的情况下，这太慢了。 

加速解决方案的关键见解来自于观察操作保留最大差异结构。 具体来说，该过程可以解释为重复地从数组中的所有元素中减去最小元素以最大公约数为模。 更具体地说，当且仅当旧数组的所有元素不超过新数组的相应元素，并且差异一致，使得没有元素小于排序顺序中的前一个元素时，数组才变得无趣。 通过对两个数组进行排序，并检查每个旧价格元素不超过其对应的新价格元素，并且它们之间的差异不递减，我们可以确定排序后线性时间内的迟钝度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组的长度，然后读取旧价格数组和新价格数组。 
2. 如果旧数组已全为零，则输出“YES”并继续。 这可以处理琐碎的边缘情况。 
3. 对两个数组进行排序。 排序允许我们以结构化的方式比较元素，并确保差异检查在数组中保持一致。 
4. 计算已排序数组的相应最大元素之间的初始差。 这个差异将作为后续检查的参考。 
5. 从最大元素到最小元素进行迭代。 对于每个头寸，计算新价格和旧价格元素之间的差异。 
6. 如果差值为负，则运算不能产生零； 输出“NO”并停止。 
7. 如果任何差异相对于参考增加，则输出“NO”，因为差异模式将违反钝度条件。 
8. 如果所有检查均通过，则输出“YES”。

为什么有效：对数组进行排序可确保我们将相应位置与正确的大小关系进行比较。 参考差异捕获传播到较小元素的最大允许减量。 通过按降序检查差异，我们保证该操作可以将旧数组单调减少到零，而不会产生负值或违反差异结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        if all(x == 0 for x in a):
            print("YES")
            continue
        a.sort()
        b.sort()
        diff = b[-1] - a[-1]
        if diff < 0:
            print("NO")
            continue
        ok = True
        for i in range(n):
            if b[i] - a[i] > diff or b[i] - a[i] < 0:
                ok = False
                break
        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```该代码首先处理全零旧数组的简单情况。 排序对于确保比较差异的一致性至关重要。 使用最大元素设置参考差，然后检查所有位置的一致性和非负性。 使用 Python 的快速 I/O 可以避免大输入量带来的开销。

 ## 边缘情况

 当旧数组已全为零时，解立即输出 YES，无需进一步计算。 对于旧元素超过相应新元素的数组，算法会识别出负差值并输出“否”。 对于旧值和新值相等的数组，引用差异为零，并且所有检查都通过，结果为“是”。 每个案例都尊重差异的单调性，并确保正确评估暗度条件。
