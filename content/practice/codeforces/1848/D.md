 ## 解决方案
 ## 问题理解

 我们被要求最大化 Vika 从她在化妆品店的奖金系统中获得的总折扣。 她目前拥有`s`奖金并将使`k`更多购买。 每次购买时，她可以享受相当于当前奖金数量的折扣，也可以将奖金增加当前总数的最后一位数字。 目标是计算她可以在之后获得的最大折扣总和`k`购买。 

输入是多个测试用例。 每个测试用例给出`s`和`k`，它可能非常大：`s`最多$10^9$和`k`最多$10^9$。 这立即排除了任何单独模拟每次购买的方法，因为简单的模拟将涉及最多$10^9$每个测试用例的操作，这远远超出了几秒钟内可以运行的范围。 

边缘情况包括初始奖金为零（所有折扣均为零）以及奖金最后一位数字为零的情况。 例如，如果`s = 0`或者`s = 10`，增加奖金不会增加最后一位数字，因此奖金的顺序可能会停滞。 另一个棘手的情况是购买数量`k`非常大：简单的迭代会超时，我们需要推理最后一位数字的模式以加快计算速度。 

## 方法

 暴力方法是模拟每次购买，要么采用折扣，要么将奖金增加最后一位数字。 对于每一步，我们都会检查哪个选择可以最大化最终的折扣。 虽然这适用于小型`k`， 为了`k`最多$10^9$这种方法需要$O(k)$每个测试用例的操作都是不切实际的。 

关键的见解是最后一位数字的序列遵循重复模式，因为添加最后一位数字是确定性操作，并且最后一位数字的范围是 0-9。 一旦我们观察到最后一个数字序列，我们就可以用它来计算在折扣变得最佳之前我们可以增加多少次。 本质上，我们将问题简化为一个算术序列：一旦最后一位数字不为零，每次购买的奖金增量就是恒定的，因此我们可以计算我们可以执行多少增量`k`购买，使用公式求和，并得出最终折扣。 

对于每个最后一位数字`d`在`1..9`，之后的奖金`m`增量遵循带有步长的算术序列`d`。 我们可以计算我们可以采取的完整步数，直到达到`k`购买，然后将剩余的购买直接添加为折扣。 在确定最初的最后一位数字后，这将每个测试用例的 O(k) 方法变为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k) | O(1) | O(1) | 对于大 k 来说太慢 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，提取`s`和`k`。 如果`s`为零，则总折扣为零。 我们可以立即输出0并继续。 
2. 计算最后一位数字`s`。 如果为零，则采取更多增量不会增加奖金。 我们应该享受折扣`k`次，总折扣为`s * k`。 
3. 否则，最后一位数字`d = s % 10`是非零的。 计算在获得最终折扣之前我们可以执行多少增量是最佳的。 如果我们将增量数表示为`m`，每次增量都会增加奖金`d`，形成序列`s, s + d, s + 2d, ..., s + md`。 
4. 这些的总折扣`m`增量是从开始的算术序列的总和`s + d`最多`s + m*d`。 这可以使用算术序列之和的公式来计算：`sum = m/2 * (2*s + (m+1)*d)`如果我们对 m 个增量求和。 
5. 计算增量步骤的最大折扣后，添加任何剩余购买的折扣，如果`m < k`。 对于大型`k`，我们可能只需要考虑序列稳定之前的固定步数，因为最后一位数字变为零后，所有后续折扣都将被取消。`s + m*d`。 
6. 输出每个测试用例计算出的总折扣。 

关键属性是最后一位数字决定重复算术序列。 一旦最后一位数字为零，进一步的增量不会改变奖金，因此我们可以立即获取所有剩余的折扣。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_total_discount(s, k):
    if s == 0:
        return 0
    total = 0
    while k > 0:
        last_digit = s % 10
        if last_digit == 0:
            total += s * k
            break
        # Determine how many steps we can take before last digit repeats or becomes 0
        m = min(k, 10)  # last digit cycles every at most 10 steps
        total += m * s + last_digit * (m * (m - 1) // 2)
        s += last_digit * m
        k -= m
    return total

t = int(input())
for _ in range(t):
    s, k = map(int, input().split())
    print(max_total_discount(s, k))
```该解决方案首先检查是否`s`为零。 while 循环处理算术级数，最多使用 10 步，因为最后一个数字序列每 10 次加法就会重复一次。 公式`m * s + last_digit * (m*(m-1)//2)`正确地总结增量折扣`m`购买。 加工后`m`步骤，我们更新`s`并减少`k`因此。

 ## 边缘情况

 如果`s = 0`和`k`很大，所有折扣都是零。 该算法立即返回零。 

如果`s`例如以零结尾`s = 10`，所有增量均为零。 该算法乘以`s`经过`k`一步即可获得全额折扣。 

如果`k`非常大并且`s`最后一位数字非零，算法使用算术公式最多循环 10 次，然后在常数时间内取剩余折扣。 这确保了解决方案即使对于上限也是有效的`k`。
