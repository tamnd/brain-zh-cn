 ## 解决方案
 ## 问题理解

 给定一个整数列表，我们想要决定是否可以分配另一个相同长度的列表，例如$b_1, b_2, \dots, b_n$，这样每个给定的数字$a_i$可以表示为两个值之间的差异$b$。 用于差异的指数不依赖于$i$，并且相同$b$元素可以任意多次重复使用。 

所以要求不是这样的$a_i = b_{i} - b_{i+1}$或任何类似的结构。 相反，每个$a_i$只需要出现在所有成对差异的多重集中的某个位置$b_j - b_k$。 

重构后，我们问是否可以放置$n$顶点上的数字以及每个给定值$a_i$，找到标签完全不同的两个顶点$a_i$。 

约束条件$n \le 10$是关键信号。 任何尝试显式搜索涉及排列的赋值的解决方案$b$，或者尝试构造$b$以确定性方式贪婪地进行，可能会过于僵化。 相反，这是一个足够小的宇宙，对结构选择的指数搜索是可行的。 

一个微妙的问题是，同样的$a_i$可以在不同的表示中多次使用。 另外，多个$a_i$可以映射到同一对索引$b$，因为允许重复使用。 

打破朴素推理的边缘情况通常来自于假设一个固定的结构$b$。 例如，如果所有$a_i$非零且不同，人们可能会尝试将它们作为相邻差异放置在排序数组中$b$，但这失败了，因为差异是全球性的，而不是局部性的。 

当人们假设线性链中的传递性时，会出现另一种失败情况：如果$b_1 - b_2 = x$和$b_2 - b_3 = y$，然后自动$b_1 - b_3 = x + y$，这可能会引入输入中不存在的不需要的差异。 任何构造都必须容忍额外的差异，但必须保证至少存在所需的差异。 

## 方法

 蛮力视角始于我们可以自由选择值的观察$b$，以及每个约束$a_i = b_j - b_k$相当于选择一个有序对$(j, k)$并强制两个未知数之间的线性相等。 

一种极端的方法是猜测哪对的整个结构$(j,k)$对应于每个$a_i$，然后求解方程组$b$。 每个选择要么引入一个约束$b_j = b_k + a_i$或造成不一致。 此类分配的数量约为$n^{2n}$，因为每个$n$值可以映射到任何有序对。 即使与$n \le 10$，这已经太大了。 

关键的观察是我们实际上并不关心个体的结构$b$。 重要的是我们是否可以嵌入所有$a_i$进入一个潜在差异系统。 如果我们解释每个约束，用图形术语思考$b_j - b_k = a_i$作为有向边$k$到$j$有重量$a_i$，那么一致性意味着该有向加权图中的每个周期的总权重必须为零。 

由于我们可以自由选择每个端点的两个端点$a_i$，我们正在有效地决定如何构建一个图$n$边缘上$n$顶点，其中每条边都有规定的权重，但我们可以选择它的端点。 任何树结构总是安全的，因为它可以通过贪婪地分配势来满足。 唯一危险的结构是循环，它施加了总和约束。 

这减少了问题，确保我们可以安排边缘，以便我们形成的唯一循环的总重量为零。 因为我们控制一切，所以我们可以进一步简化：我们只需要确保值的多重集可以划分为形成单个循环的集合（其总和必须为零），而其他所有内容都可以作为树或自循环附加。 

自循环对应于选择$j = k$，这会强制该值为零。 所以零是微不足道的，不会限制结构。 

最终的归约变成纯粹的组合：我们需要确定数组中是否存在总和为零的非空子集。 该子集可以排列成一个循环，并且所有剩余元素可以以树状方式附加，而不会引入矛盾。 

因为$n \le 10$，我们可以直接检查所有子集。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有配对分配进行暴力破解 |$O(n^{2n})$|$O(n)$| 太慢了|
 | 索引的子集和 |$O(2^n \cdot n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们关注子集和解释。 

1. 对于每个测试用例，读取数组$a$。 根据所有值是否为零来分离逻辑。 如果所有值都为零，则答案立即为“是”，因为每个约束都可以实现为自循环$b_j - b_j = 0$。 
2. 枚举所有索引子集$0$到$2^n - 1$。 每个子集代表一个候选组$a_i$我们试图在一个周期中实现的价值观。 
3. 对于每个子集，计算所选子集的总和$a_i$。 如果总和不为零，则该子集无法形成一致循环并被丢弃。 
4. 如果子集的和为零并且非空，则它始终可用。 如果它只包含一个元素，则它必须为零，因为单边沿循环仅通过自循环才有效。 
5. 如果找到任何有效子集，则输出 YES。 如果不存在，则输出NO。 

它之所以有效，是因为约束如何转化为潜在的差异。 任何有效的构造$b$导出一个图，其中每个$a_i$对应于有权重的有向边$a_i$。 在任何周期中，伸缩差异都会迫使总和为零。 相反，如果我们选择总和为零的任何边集，我们可以通过在循环周围分配增量顶点势来将它们实现为循环，然后将剩余的边附加为树，这不会引入循环约束。 由于树总是允许一致的潜在分配，因此可行性完全降低到寻找零和子集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if all(x == 0 for x in a):
            print("YES")
            continue

        found = False

        for mask in range(1, 1 << n):
            s = 0
            cnt = 0
            for i in range(n):
                if mask >> i & 1:
                    s += a[i]
                    cnt += 1

            if s == 0:
                if cnt >= 2:
                    found = True
                    break
                if cnt == 1 and s == 0:
                    found = True
                    break

        print("YES" if found else "NO")

if __name__ == "__main__":
    solve()
```该解决方案迭代索引的所有子集，并检查有效循环所需的总和条件是否成立。 全零的特殊情况避免了不必要的枚举，但不是严格要求的。 

子集循环构造所选组的总和和大小。 大小检查确保单例子集仅在值为零时通过，这与自循环解释相匹配。

 ## 边缘情况

 包含零的单元素数组由全零快捷方式处理。 对应的是选择$b_1 = 0$，唯一可能的区别是$0$。 

单个非零元素总是会失败，因为使用一个变量，单个值的差异不可能是非零的； 任何差异都需要至少两个不同的索引。 

总和为零但除了全集和为零之外没有子集的混合数组仍然有效，因为全集本身形成有效的循环候选。 

具有重复值的数组不会改变行为，因为子集选择仅取决于总和，而不取决于元素的标识。
