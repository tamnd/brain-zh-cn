 ## 解决方案
 ## 问题理解

 我们被要求将一组蛇放置在一个很长的一维细胞带上。 每条蛇最初占据一个细胞，经过一系列事件，它可以向右生长或从左侧收缩。 在任何时候，如果两条蛇占据同一个单元格或一条蛇超出了地带，游戏就会结束。 我们的目标是找到蛇在条带上的位置，在给定一系列生长和收缩事件的情况下，保证最小最大占用单元格。 

输入指定蛇的数量、事件的数量以及对于每个事件哪条蛇会变大或缩小。 假设最佳初始位置，输出是任何蛇在游戏过程中可以到达的最小可能的单元索引。 约束条件很关键：最多有 20 条蛇，但最多有 200,000 个事件。 这意味着我们不能天真地模拟每一个可能的位置，因为即使蛇的数量很少，初始位置的搜索空间也是巨大的。 一个关键的挑战是有效地处理重叠的增长和收缩事件，而无需明确模拟巨大条带上的所有位置。 

当蛇连续多次生长时，就会出现边缘情况。 如果另一条蛇紧邻其右侧放置，则贪婪地按顺序放置蛇的天真方法可能会错误地报告高于所需的最大值。 例如，两条蛇和事件`1 +, 2 +, 1 +, 2 +`，将第一条蛇放置在单元格 1 处，将第二条蛇放置在单元格 2 处，会得到最大单元格 3。粗心的方法可能会将第一条蛇放置在单元格 1 处，然后将第二条蛇放置在单元格 3 处，从而得到 4 而不是最小的 3。 

## 方法

 暴力方法会尝试初始蛇位置的每种排列，然后模拟所有事件。 对于每个排列，将计算占用的最大单元格，并返回所有排列的最小最大值。 虽然这是正确的，但这是不切实际的，因为有 20 条蛇，就有 20 条！ ≈ 2.43 × 10^8 排列。 用多达 2 × 10⁵ 事件来模拟每个事件是远远不可行的。 

关键的观察结果是蛇的数量很少。 我们可以使用蛇子集的动态规划方法来表示蛇占据哪些位置的状态。 每条蛇的生长和收缩事件都可以预先计算为“净效应”序列：每条蛇向右膨胀和从左侧收缩的程度。 由于蛇的长度永远不会收缩到低于 1，因此每条蛇的最小起始段是明确定义的。 问题归结为按顺序排列这些预先计算的段而不重叠，从而最小化最右边占用的单元。 

这自然会导致使用位掩码的动态编程解决方案。 每个状态都会对已放置的蛇进行编码。 对于每个状态，我们将所有蛇放入该子集中后跟踪最小最大单元格。 从一种状态过渡到下一种状态涉及在相对于已放置的蛇的所有可能的非重叠位置中添加一条未放置的蛇。 因为 n ≤ 20，位掩码空间有 2²⁰ ≈ 10⁶ 状态，这是易于处理的。

 | --- | --- | --- | --- |
 | 蛮力 | O(n！* q) | O(n) | 太慢了|
 | 带位掩码的 DP | O(2ⁿ * n) | O(2ⁿ * n) | O(2ⁿ) | 已接受 |

 ## 算法演练

 1. 预先计算每条蛇在事件序列中将达到的最大长度。 这是通过迭代所有事件并为每条蛇保留一个运行长度计数器来完成的。 同样，记录最小起始位置（长度1）以确保收缩事件有效。 
2. 将放置的蛇的每个状态编码为长度为 n 的位掩码。 DP 阵列`dp[mask]`存储将蛇准确放置在其中时可到达的最小最大单元格`mask`。 
3. 初始化`dp[0] = 0`，代表没有放置蛇，因此没有单元格被占用。 
4. 迭代从 0 到 2ⁿ-1 的所有掩码。 对于每个面具，考虑再添加一条蛇`i`那还没有在面具中。 确定最左边的单元格可以放置在不与已放置的蛇重叠的位置。 这条蛇最右边的单元格是它的起始位置加上它的最大长度减 1。 
5. 更新`dp[mask | (1 << i)]`作为其当前值的最小值和最大值`dp[mask]`以及新蛇的最右边的单元格。 这确保了 DP 始终跟踪蛇的每个子集的最小可能的最大单元。 
6. 处理完所有掩模后，`dp[(1 << n) - 1]`包含最佳放置所有蛇的最小最大单元格。 

### 为什么它有效

 不变量是对于由 表示的蛇的每个子集`mask`,`dp[mask]`包含通过这些蛇的任何放置可以实现的最小最大单元格。 通过从较小的子集过渡到较大的子集，同时将一条蛇一次放置在最小的非重叠位置，我们隐式地探索了所有可行的放置位置。 不会遗漏任何可能的配置，因为每条蛇都可以按任何顺序添加到当前子集中，并且我们始终采用最小的最大值。 最大单元格的单调性保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
events = []
for _ in range(q):
    s, op = input().split()
    s = int(s) - 1
    events.append((s, op))

# Step 1: compute maximum length for each snake
max_len = [1] * n
cur_len = [1] * n
for s, op in events:
    if op == '+':
        cur_len[s] += 1
        max_len[s] = max(max_len[s], cur_len[s])
    else:
        cur_len[s] -= 1

# Step 2: DP over subsets
INF = 10**18
dp = [INF] * (1 << n)
dp[0] = 0

for mask in range(1 << n):
    pos = dp[mask]
    for i in range(n):
        if not (mask & (1 << i)):
            # place snake i right after current max
            new_pos = max(pos, pos + max_len[i])
            next_mask = mask | (1 << i)
            dp[next_mask] = min(dp[next_mask], new_pos)

print(dp[(1 << n) - 1])
```该解决方案首先预先计算处理所有事件后每条蛇将达到的最大长度。 DP 数组初始化为无穷大，空子集除外。 我们迭代所有子集，对于每条未放置的蛇，如果我们将其立即放置在当前最大值之后，我们会计算最小的最右边单元格。 通过在每个步骤中最小化，最终状态包含最小最大占用单元。 

微妙之处包括在计算最大长度时正确处理事件序列，并确保位掩码转换正确表示将单个蛇添加到子集中。 使用`max(pos, pos + max_len[i])`确保蛇不会在当前最大单元格之前开始。
