 ## 解决方案
 ## 问题理解

 我们正在处理一副纸牌，其中只有一张特殊纸牌（小丑）的相对位置很重要。 最初小丑坐在位置`m`在一行`n`牌。 然后我们执行一系列操作。 每个操作选择一个位置`a_i`在当前牌组中，取出该位置的牌，并将其插入到最顶部或最底部。 

小丑本身永远不会直接移动，但只要从它前面移走一张牌或在它前面插入一张牌，它的位置就会间接改变。 在每次操作之后，我们不会被要求提供小丑的单个最终位置，而是询问小丑可能占据多少个不同的位置，具体取决于每一步将所选卡移动到顶部或底部的所有选择。 

因此，状态不是一副牌，而是一组不断增长的可能的牌。 我们只跟踪所有这些可能的结果，每次操作后小丑可能处于哪个索引，并输出该集合的大小。 

约束是这里的关键信号。 甲板尺寸`n`可以大到 10^9，因此我们无法模拟牌组或维护按位置索引的显式结构。 每个测试的操作数总计最多为 2·10^5，这迫使每个测试解决方案在最坏的情况下为 O(q) 或 O(q log q)。 任何涉及重建数组或模拟排列的事情都是立即不可能的。 

主要的微妙之处在于每个操作分支为两种可能性，因此超过 2^q 配置的朴素状态爆炸是完全不可行的。 即使跟踪小丑的完整位置集也需要 O(n) 内存，这也是不可能的，因为 n 很大。 

一些故障模式出现在天真的推理中。 

一个常见的错误是假设小丑的位置始终是一个刚刚扩大的区间。 例如，如果小丑开始于`m=3`在一个小牌组中，当我们在它周围反复移动牌时，很容易假设它的可能位置仍然是一个连续的部分，而不仔细维护受可以从左或右移动的元素数量影响的边界。 

另一个错误是独立对待每个操作，忽略了这样一个事实：早期的操作已经确定了移动的元素可能最终位于小丑的哪一侧，并且这种积累是不对称的。 

第三个错误是每一步只模拟一个贪婪的选择（总是推到前面或总是推到后面），这低估了真正可到达的位置，因为两种选择都会在相反的方向上影响小丑。 

## 方法

 蛮力的想法很简单：维护整个牌组，并在每次操作时分支成两个牌组，一个牌组中所选元素位于前面，另一个牌组位于后面。 对于每个生成的牌组，跟踪小丑的位置。 经过 q 次操作后，收集所有可能的小丑位置。 

这在原则上是正确的，因为它探索了每个有效的选择序列。 然而，每次操作都会使状态数量加倍。 在 q 操作之后，我们有 2^q 个状态，即使对于 40 左右的 q，这也是不可能的。 这里 q 可以达到 2·10^5，因此这种方法立即失败。 

关键的观察是，我们实际上从不关心这副牌的完整排列，只关心有多少元素可以出现在小丑之前或之后。 仅当所选位置在某种实现中位于其左侧或右侧时，每个操作才会影响小丑，唯一重要的是有多少位置可以在所有可能的分支上“跨越”小丑。 

我们不跟踪完整的排列，而是跟踪可能位于小丑左侧的元素的可能数量范围。 每个操作都会根据删除的元素在不同场景中是否位于任一侧来扩大或缩小此范围，并且在前面或后面插入会以可预测的方式改变相对顺序。 

核心归约是小丑的可能位置总是形成一个连续的区间，我们只需要维护它的左右端点即可。 每个操作都会在 O(1) 中更新这些端点，具体取决于删除的索引在当前不确定性区间内是严格位于左侧、严格位于右侧还是可能两者都位于。 

这将问题从指数状态爆炸减少到维持间隔边界的线性扫描。

 | 蛮力 | O(2^q·n) | O(2^q·n) | O(2^q·n) | O(2^q·n) | 太慢了|
 | 最佳 | O(q) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们保持一个间隔`[L, R]`代表每次操作后小丑的所有可能位置。 

1. 初始化间隔为`[m, m]`因为最初小丑处于固定位置。 
2.对于每个带有索引的操作`a`：

 我们考虑所选位置是否位于所有可能的小丑位置的左侧、右侧，或者由于先前的不确定性而可能重叠。 由于我们只跟踪位置，因此我们将其解释为是否`a`可能会影响小丑之前的元素数量。 
3. 如果保证移除的位置严格位于小丑区间的左侧，则移除该卡会减少所有场景中小丑之前的元素数量，因此两个边界都左移 1。 
4、如果保证严格正确，那么去掉它在任何场景下都不会影响joker的位置，所以`[L, R]`保持不变。 
5. 如果根据配置它可以位于两侧，则一个分支将其视为左侧，另一个分支将其视为右侧。 这会导致区间两边都扩大 1：`L = max(1, L-1)`和`R = min(n, R+1)`。 
6. 更新间隔后，这一步的答案很简单`R - L + 1`。 

### 为什么它有效

 关键的不变量是，在每次操作之后，所有可能的小丑位置的集合都可以精确地表示为连续的区间。 每个操作仅更改单个元素的相对顺序，这可以将小丑的排名在任一方向上最多移动一位，具体取决于该元素是在其之前还是之后。 因为所有分支选择仅通过将该元素移动到极端而有所不同，所以所有产生的排列都会崩溃为对小丑等级的至多两个极端影响，并且中间值始终可以通过早期步骤的一致选择来实现。 这可以防止可达集合内出现间隙，确保始终保留间隔结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, q = map(int, input().split())
        a = list(map(int, input().split()))

        L = R = m

        for x in a:
            if x < L:
                L = max(1, L - 1)
                R = max(1, R - 1)
            elif x > R:
                continue
            else:
                L = max(1, L - 1)
                R = min(n, R + 1)

            print(R - L + 1, end=" ")
        print()

if __name__ == "__main__":
    solve()
```该实现保持滚动间隔`[L, R]`可能的小丑位置。 这三种情况直接对应于删除的索引是否始终位于所有可能的百搭位置之前、始终之后或模糊定位。 更新规则一致地调整两个端点，以保持覆盖所有可达状态的不变性。 

一个微妙的细节是边界钳位使用`max(1, ...)`和`min(n, ...)`，因为小丑位置不能离开牌组。 另一个微妙的点是更新是对称的：当删除的位置肯定是左边时，两个端点都会向左移动，因为所有配置都会丢失小丑之前的一个元素； 同样，模糊性会在两个方向上扩大间隔。

 ## 边缘情况

 一种重要的边缘情况是小丑从位置 1 或 n 开始。 在这种情况下，任何扩张尝试都必须受到限制。 例如，从`m = 1`并且应用不明确的操作不应允许间隔缩小到 1 以下。更新规则`L = max(1, L - 1)`确保了这一点。 

另一种情况是所有操作都严格位于当前间隔的右侧。 例如，如果`m = 2`和所有`a_i`很大，间隔永远不会改变。 假设每个操作都会影响小丑的简单模拟会错误地扩大范围。 

最后一种情况是当间隔已经跨越整个牌组时重复不明确的操作。 一次`[L, R] = [1, n]`，进一步的扩展不应改变它。 夹紧与`min(n, R + 1)`保证稳定性并防止溢出超出有效位置。
