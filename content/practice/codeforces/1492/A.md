 ## 解决方案
 ## 问题理解

 我们有三名游泳运动员，他们在自己固定的时间里反复游过游泳池并返回。 第一个游泳者采取`a`分钟完成一次往返，第二次`b`分钟，第三分钟`c`分钟。 你到达泳池`p`开始后几分钟，目标是确定必须等待多少分钟，直到至少一名游泳者再次到达泳池左侧。 

输入给出了多个独立的测试用例。 对于每个，我们给出四个整数`p`,`a`,`b`， 和`c`。 这些值中的每一个都可以大到 10^18，这意味着任何迭代每个游泳者返回时间的蛮力模拟都是不可行的。 我们需要一种直接处理这些大数的方法。 

当您恰好在游泳者位于左侧的同一时刻到达，或者等待时间比某些游泳者的时间长时，就会出现不明显的边缘情况。 例如，如果`p = 10`和`a = 2, b = 5, c = 10`，您恰好在第三个游泳者在那里的时间到达，因此等待时间应该是`0`。 一个粗心的解决方案，只检查未来的倍数而不考虑相等性，会错误地报告积极的等待。 

## 方法

 一种暴力方法是生成每个游泳者截至目前的所有返回时间`p`及以上，然后向前扫描查找第一个大于或等于的时间`p`。 这在原则上是正确的，但很快就变得不切实际，因为`p`可以是 10^18 和句点`a, b, c`也可以很大。 迭代数百万或数十亿步太慢。 

关键的观察结果是，每个游泳运动员的返回时间形成一个从零开始的算术序列，步长等于其周期。 求下一次返回时间不小于`p`，我们可以用数学方法计算它而不是迭代。 对于有经期的游泳者`x`，下次返回时间之后`p`是最小的倍数`x`大于或等于`p`。 如果`p`可以整除`x`，下一个返回是`p`本身。 否则的话，就是`(p // x + 1) * x`。 一旦我们确定了每个游泳者的下一次返回时间，等待时间就是最短的`(next_return_time - p)`跨越所有三名游泳运动员。 

这将问题从迭代潜在的巨大序列减少为每个游泳者的恒定时间算术计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(p / 分钟(a, b, c)) | O(1) | O(1) | 太慢了|
 | 算术计算| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`p`,`a`,`b`， 和`c`。 
3. 每个游泳时段`x`在`[a, b, c]`，计算下一次游泳者位于左侧的时间，不早于`p`。 如果`p`可以整除`x`，下一次是`p`。 否则，计算`next_time = ((p // x) + 1) * x`。 
4. 计算每个游泳者的等待时间：`next_time - p`。 
5. 测试用例的答案是三位游泳者的最短等待时间。 
6. 打印每个测试用例的结果。 

为什么它有效：算术保证我们找到每个游泳者周期的第一个倍数不小于`p`。 减法`p`给出准确的等待时间。 对所有游泳者取最小值可以确保我们找到最早到达的游泳者。 由于支持最大 10^18 的整数算术，因此不需要近似值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def next_arrival(p, x):
    if p % x == 0:
        return p
    return ((p // x) + 1) * x

t = int(input())
for _ in range(t):
    p, a, b, c = map(int, input().split())
    wait_times = [next_arrival(p, a) - p,
                  next_arrival(p, b) - p,
                  next_arrival(p, c) - p]
    print(min(wait_times))
```功能`next_arrival`干净地处理下一个倍数的计算，避免出现差一错误`p`可以被游泳者的周期整除。 主循环使用有效地读取输入`sys.stdin.readline`并以整数算术执行所有计算，确保非常大的值的正确性。

 ## 边缘情况

 如果你恰好在游泳者位于左侧时到达，`p % x == 0`确保等待时间为零。 例如，使用输入`p=10`和`a=2`,`b=5`,`c=10`，第三位游泳者的计算给出`next_time = 10`， 和`next_time - p = 0`。 所有游泳者正确输出的最小值`0`。 

当所有周期都大于`p`， 例如`p=5`和`a=b=c=10`，计算得出`next_time = 10`对于所有人来说，等待时间是`5`，正确反映您必须等到第一个游泳者返回。 

该方法一致地处理与游泳者周期相关的到达时间的所有组合。
