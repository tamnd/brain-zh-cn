 ## 解决方案
 ## 问题理解

 我们以非递减顺序给出四个整数，我们需要从三个单独的区间中选择三个长度。 第一个长度必须来自第一个间隔，第二个长度必须来自第二个间隔，第三个长度必须来自第三个间隔。 选择这三个值后，我们必须确保它们能够形成一个面积非零的三角形。 

有边长的三角形$x, y, z$当且仅当三角形不等式严格时存在正面积：$x + y > z$,$x + z > y$， 和$y + z > x$。 因为这些值是按排序间隔选择的，其中$x \le y \le z$总是可以通过构造实现，唯一有意义的约束变成$x + y > z$。 

输入大小方面的约束很小，最多 1000 个测试用例，因此每个测试用例的恒定时间构造就足够了。 每个值可以大到$10^9$，这排除了任何依赖于枚举区间内候选者的方法。 

天真的尝试会尝试间隔中的所有三元组。 对于每个涉及的测试用例$(b-a+1)(c-b+1)(d-c+1)$组合可能是巨大的，最多可达$10^{27}$在最坏的情况下。 这显然是不可能的。 

一个更微妙的陷阱是假设选择任意边界值总是有效，例如选择$x=a$,$y=b$,$z=c$。 这可能会失败，当$a + b \le c$，产生退化或无效的三角形。 示例结构表明区间内需要灵活性。 

## 方法

 暴力方法会枚举所有有效的三元组$x, y, z$在各自的范围内并检查三角形状况。 从概念上讲，这是可行的，因为每个有效组合都经过测试，但组合数量随着间隔大小成倍增长。 由于每个间隔可以跨越$10^9$，搜索空间变得非常大并且立即不可行。 

关键的观察结果是，三角形条件仅取决于与最大边相比的两个较小边的总和。 因为$y$夹在其他两个间隔之间，调整$y$提供了满足不等式的最直接的控制。 目标是使$x + y$只是大到足以超过$z$，并且由于我们可以在间隔内自由选择，因此选择边界附近彼此接近的值就足够了。 

一个建设性的策略出现了：选择$x$尽可能大的范围内$[a, b]$， 挑选$y$尽可能大的范围内$[b, c]$，并选择$z$内尽可能小$[c, d]$。 这推动了总和$x + y$向上同时保持$z$最小，最大化满足严格不平等的机会。 如果此选择失败，则在间隔之间的重叠区域内稍微移动值始终允许调整，并且问题保证存在解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O((b-a)(c-b)(d-c))$|$O(1)$| 太慢了|
 | 贪婪构造|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取四个整数$a, b, c, d$。 这些定义了三个独立的范围$x, y, z$。 
2. 构建$x = b$。 这个选择的地方$x$在其范围的上限，最大化对三角不平等的潜在贡献。 
3. 构建$y = c$。 这同样会最大化第二边，同时尊重其允许的间隔。 
4. 构建$z = c$。 这可以最大限度地减少第三边，同时仍保持在其间隔内，这有助于满足$x + y > z$。 
5、输出$x, y, z$。 

微妙的想法是我们不需要寻找微妙的平衡。 区间的结构已经确保将前两个变量向上推而最后一个变量向下推以产生有效的配置。 

### 为什么它有效

 施工保障$x = b \le c = y = z$或者至少$x \le y \le z$直到相等的情况，但关键条件是$x + y > z$。 自从$x \ge b$和$y \ge b$，它们的总和至少为$2b$， 尽管$z \le d$但我们特别将其锚定在$c$，范围之间的中点边界。 该问题的保证确保在这些间隔内始终存在一种配置，其中两个较早段的总和超过第三个段。 通过在其范围的上限处对齐两个值，在其范围的下限处对齐第三个值，我们迫使不等式成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    
    x = b
    y = c
    z = c
    
    print(x, y, z)
```代码直接实现了贪心构造。 每个测试用例独立处理，不需要辅助存储。 的选择`b, c, c`将变量与间隔的自然断点对齐。 

一个微妙的点是，虽然这看起来几乎微不足道，但它依赖于重叠边界确保可行性的事实。 任何替代的有效构造也可以工作，但是这个构造是稳定的并且避免了代码内部的边缘推理。 

## 工作示例

 ### 示例 1

 输入：```
1 3 5 7
```我们计算：

 | 步骤| x| y | z | 检查 |
 | ---| ---| ---| ---| ---|
 | 初始| - | - | - | 间隔定义|
 | 分配| 3 | 5 | 5 | 建筑应用|
 | 验证 | 3 | 5 | 5 | 3 + 5 > 5 | 3 + 5 > 5

 不等式成立是因为$3 + 5 = 8 > 5$。 该三角形是有效且非退化的。 

### 示例 2

 输入：```
1 1 1 10
```| 步骤| x| y | z | 检查 |
 | ---| ---| ---| ---| ---|
 | 分配| 1 | 1 | 1 | 边界建设|
 | 验证 | 1 | 1 | 1 | 1 + 1 > 1 | 1 + 1 > 1

 即使在所有区间都在左侧塌陷的极端情况下，该构造仍然会产生一个有效的三角形，因为任何正等边形成一个看似退化但有效的正面积三角形条件，通过一侧比较的严格不等式来满足。 

这表明，即使范围很小，在共享边界上对齐值也能保持可行性。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    
    t = int(input())
    out = []
    for _ in range(t):
        a, b, c, d = map(int, input().split())
        x, y, z = b, c, c
        out.append(f"{x} {y} {z}")
    return "\n".join(out)

 ## 边缘情况

 考虑所有区间在单个点崩溃的极端情况，例如：```
1 1 1 1
```算法输出$1, 1, 1$。 三角形条件成立，因为$1 + 1 > 1$。 没有选择不同值的自由，并且构造仍然满足有效性。 

另一种情况是间隔很远时：```
1 2 100 1000
```该算法产生$2, 100, 100$。 这里$2 + 100 > 100$，因此即使最后一个间隔很远，也存在有效的三角形。 该构造之所以有效，是因为中间值和右侧值与最小可行边界对齐，从而防止间隙打破不平等。
