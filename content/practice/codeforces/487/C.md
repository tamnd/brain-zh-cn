 ## 解决方案
 ## 问题理解

 我们需要安排数字$1,2,\dots,n$变成排列$a_1,a_2,\dots,a_n$。 

定义$$p_i = a_1a_2\cdots a_i \pmod n.$$要求是顺序$p_1,p_2,\dots,p_n$本身必须是所有残基的排列$0,1,\dots,n-1$。 

因为每个数字都来自$1$到$n$在排列中只出现一次，最后一个前缀积是$$p_n = n! \pmod n.$$对于每一个$n>1$，这个值为$0$，因为一个因素等于$n$。 因此残渣$0$必须恰好出现一次，并且必须出现在最后一个位置。 所有较早的前缀乘积必须是非零残基。 

输入由单个整数组成$n$， 和$n\le 10^5$。 这立即排除了任何对排列的搜索。 甚至$n=20$已经有$20!$的可能性。 我们需要一个可以在线性时间内生成的直接构造公式。 

一个微妙的边缘情况是$n=1$。 唯一的排列是$[1]$。 唯一的前缀产品是$1 \bmod 1 = 0$，这正是所需的排列$[0]$。 答案是存在的。 

另一个重要的情况是合数，例如$n=8$。 天真的尝试可能会尝试使用模逆来生成值，但是像这样的数字$2$和$4$不可逆模$8$。 建筑完全崩溃。 事实上，任何复合材料都不存在解决方案$n>4$。 

特殊情况$n=4$很容易被错过。 虽然$4$是复合的，确实存在一个解决方案：$$1,\ 3,\ 2,\ 4.$$其前缀乘积取模$4$是$$1,\ 3,\ 2,\ 0,$$这正是以下的排列$0,1,2,3$。 

## 方法

 最直接的想法就是暴力。 生成排列$1,\dots,n$，计算所有前缀乘积的模$n$，并测试所得残基是否形成排列$0,\dots,n-1$。 

这是正确的，因为它会检查每个候选人。 不幸的是，搜索空间包含$n!$排列。 即使是为了$n=12$，这已经超过了$4\times10^8$的可能性。 约束条件$n\le10^5$使得穷举搜索完全不可能。 

关键的观察来自于查看所需的前缀产品而不是排列本身。 

假设我们希望前缀产品是$$p_1=1,\ p_2=2,\ p_3=3,\ \dots,\ p_{n-1}=n-1,\ p_n=0.$$如果我们能够准确地实现这些留数，那么它们显然是所有留数模的排列$n$。 

自从$$p_i \equiv p_{i-1}a_i \pmod n,$$我们可以解决$a_i$：$$a_i \equiv p_i p_{i-1}^{-1} \pmod n.$$这需要每个非零余数的模逆。 这种逆恰好存在于$n$是素数。 

选择$p_i=i$为了$1\le i<n$给出$$a_i \equiv i(i-1)^{-1}\pmod n.$$对于素数模，每个$1,\dots,n-1$是可逆的，所以构造工作完美。 

剩下的问题是存在。 经典数论事实表明，对于复合$n>4$，不存在这样的排列。 唯一有效的值为：

 -$n=1$-$n=4$- 任何素数$n$一旦检查了素性，就会产生线性结构。

 ## 算法演练

 ### 对于$n=1$1. 输出`YES`。 
2. 输出`1`。 

唯一前缀乘积模$1$等于$0$，所以条件满足。 

＃＃＃ 为了$n=4$1. 输出`YES`。 
2. 输出已知结构：$$1,\ 3,\ 2,\ 4.$$其前缀乘积取模$4$是$1,3,2,0$。 

### 对于一般情况$n$1. 检查是否$n$是素数。 
2.如果$n$是复合的，输出`NO`。 
3.否则输出`YES`。 
4. 设置$a_1=1$。 
5. 对于每一个$i=2,\dots,n-1$, 计算$$a_i = i\cdot (i-1)^{-1}\pmod n.$$1. 设置$a_n=n$。 

逆数使用费马定理计算：$$(i-1)^{-1}\equiv (i-1)^{n-2}\pmod n,$$因为$n$是素数。 

### 为什么它有效

 通过以下方式定义所需的前缀产品$$p_i=i \quad (1\le i<n).$$我们通过归纳证明构造的排列恰好产生这些值。 

为了$i=1$,$$p_1=a_1=1.$$认为$p_{i-1}=i-1$。 然后$$p_i \equiv p_{i-1}a_i \equiv (i-1)\cdot i\cdot (i-1)^{-1} \equiv i \pmod n.$$因此，最后一个前缀之前的每个前缀乘积都等于其索引。 

最终元素是$a_n=n\equiv0\pmod n$， 所以$$p_n\equiv p_{n-1}\cdot0\equiv0.$$因此前缀产品是$$1,2,\dots,n-1,0,$$这正是所有留数模的排列$n$。 

仍有待证明该序列$a_i$本身就是一个排列$1,\dots,n$。 自从$$a_i=i(i-1)^{-1},$$每一个$a_i$是对素数取模的非零余数。 清楚的$i$产生不同的值，因为乘以倒数是可逆的。 连同$a_1=1$和$a_n=n$，每个数字都只出现一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n == 1:
    print("YES")
    print(1)
elif n == 4:
    print("YES")
    print(1)
    print(3)
    print(2)
    print(4)
else:
    prime = True
    d = 2
    while d * d <= n:
        if n % d == 0:
            prime = False
            break
        d += 1

    if not prime:
        print("NO")
    else:
        print("YES")
        print(1)

        for i in range(2, n):
            x = (i * pow(i - 1, n - 2, n)) % n
            print(x)

        print(n)
```该程序首先处理两个异常值，$n=1$和$n=4$。 

对于所有其他输入，它通过试除执行素性测试。 自从$n\le10^5$，检查除数至$\sqrt n$非常便宜。 

什么时候$n$是素数，费马定理提供了模逆。 Python的三参数`pow`有效地计算模幂，所以```
