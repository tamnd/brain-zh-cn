 ## 解决方案
 ## 问题理解

 我们有一张尺寸为 _n_ × _m_ 的长方形桌子，桌子上装满了传送带。 每条传送带要么指向上方（`^`）， 左边 （`<`），或右（`>`）。 桌子周围是用餐座位，按逻辑编号为行`0`和`n+1`和列`0`和`m+1`。 当一块面包被放在传送带上时，它会根据传送带的方向沿着传送带移动，直到到达桌子外面的座位。 如果面包进入传送带内的循环，它永远不会到达座位，我们必须将其报告为陷入无限循环。 

该表通过动态更新`q`两种类型的查询。`A x y`要求我们模拟面包`(x, y)`并报告其最终位置或`-1 -1`如果无限循环。`C x y c`更改传送带`(x, y)`到一个新的类型`c`。 

限制因素很大：`n`可以达到100,000，同时`m`最多 10 个。查询数也最多 100,000 个，其中最多 10,000 个更改查询。 这排除了从每个查询的表开头天真地模拟面包移动的情况，因为在最坏的情况下我们会执行`O(n*q)`步骤，可能达到10^10次操作，远远超出了时间限制。 另一方面，小`m`暗示我们可以有效地利用列式结构。 

当皮带在一列或两列中形成小环时，就会出现微妙的边缘情况。 例如，带有向上和向下指向的皮带的两排立柱可以无限期地捕获面包。 另一种情况是当面包直接在出口座位附近开始时； 它立即离开。 不检测循环的简单代码将永远循环。 

## 方法

 蛮力方法模拟了面包每一次的运动`A`一步步查询。 对于每个查询，我们都会跟踪传送带，直到它离开桌子或检测到循环。 可以使用访问集来完成检测循环，标记在单个模拟期间访问过的单元。 虽然正确，但这可能会花费`O(n*q)`在最坏的情况下并且会失败`n`和许多疑问。 

关键的观察结果是，列中的运动大部分是垂直的，因为传送带要么向左、向右或向上移动。 和`m`最多 10 个，我们可以预先计算每个单元格中一块面包最终会离开桌子或进入一个循环。 该预计算可以使用从顶行向下的动态编程来完成。 复杂度与`O(n*m)`最初构建此表。 然后，当传送带发生变化时，我们只需要重新计算受影响的列，这是高效的，因为`m`很小，最多有 10,000 个变化。 

最佳方法依赖于每个单元格的存储`(x, y)`，它的“退出点”`(tx, ty)`或循环标记。 对于每个`A`查询时，我们只需返回存储的结果，并且对于`C`查询时，我们重新计算受影响列中的退出点，仅在必要时传播更新。 这可能会减少每个查询的时间`O(n)`到`O(m)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*q) | O(n*q) | O(n*m) | 太慢了 |
 | 最佳| O(n_m + q_m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 阅读表格尺寸`n`,`m`和查询数量`q`。 将表存储为字符串列表。 
2. 初始化一个`exit`大小数组`n x m`存储每个位置的退出单元或`(-1, -1)`如果它导致循环。 
3. 定义递归函数`dfs(x, y)`计算退出`(x, y)`：

- 如果`(x, y)`位于表外，返回`(x, y)`立即地。 
- 如果`(x, y)`已经计算在`exit`，返回存储的值。 
- 标记`(x, y)`作为“访问”来检测周期。 
- 计算下一个单元格`(nx, ny)`基于输送机类型。 
- 递归调用`dfs(nx, ny)`。 
- 如果递归调用返回`(-1, -1)`， 标记`(x, y)`作为循环和返回的一部分`(-1, -1)`。 
- 否则，将退出存储在`exit[x][y]`并归还它。 
4. 预先计算`exit`通过运行数组`dfs(x, y)`在所有细胞上。 
5. 对于每个查询：

 - 如果是的话`A x y`，输出预先计算的退出点`exit[x-1][y-1]`。 
- 如果是的话`C x y c`，更新表并使受影响列中的出口无效。 重新计算`exit`该列中所有行的值使用`dfs`。 
6.返回全部结果`A`按顺序查询。 

正确性依赖于每个单元格要么有最终出口要么被标记为循环的一部分的不变量。 更新传送带仅影响其上方同一列中的单元格，而我们的`dfs`传播确保我们在每次更改后始终计算出正确的退出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

n, m, q = map(int, input().split())
table = [list(input().strip()) for _ in range(n)]
exit_pos = [[None]*m for _ in range(n)]
visiting = [[False]*m for _ in range(n)]

def dfs(x, y):
    if x < 0:
        return (0, y+1)
    if x >= n:
        return (n+1, y+1)
    if y < 0:
        return (x+1, 0)
    if y >= m:
        return (x+1, m+1)
    if visiting[x][y]:
        return (-1, -1)
    if exit_pos[x][y] is not None:
        return exit_pos[x][y]

    visiting[x][y] = True
    c = table[x][y]
    if c == '^':
        nxt = dfs(x-1, y)
    elif c == '<':
        nxt = dfs(x, y-1)
    else:  # '>'
        nxt = dfs(x, y+1)
    visiting[x][y] = False
    exit_pos[x][y] = nxt
    return nxt

# Initial computation
for i in range(n):
    for j in range(m):
        if exit_pos[i][j] is None:
            dfs(i, j)

for _ in range(q):
    parts = input().split()
    if parts[0] == 'A':
        x, y = int(parts[1])-1, int(parts[2])-1
        tx, ty = exit_pos[x][y]
        print(tx, ty)
    else:
        x, y, c = int(parts[1])-1, int(parts[2])-1, parts[3]
        table[x][y] = c
        # Invalidate and recompute column
        for i in range(n):
            exit_pos[i][y] = None
        for i in range(n):
            dfs(i, y)
```DFS 确保通过以下方式正确检测周期`visiting`。 我们必须增加递归限制，因为`n`最多可达 10^5，否则堆栈递归可能会溢出。 更新传送带时，我们仅使列无效以最大程度地减少重新计算。 

## 工作示例

 **样品1**

 输入：```
2 2 3
>>
^^
A 2 1
C 1 2 <
A 2 1
```追踪第一个`A 2 1`：

 | 步骤| 位置 | 输送机| 下一页 | 评论 |
 | --- | --- | --- | --- | --- |
 | 1 | (2,1) | ^ | (1,1) | 向上移动 |
 | 2 | (1,1) | > | (1,2) | 向右移动 |
 | 3 | (1,2) | > | (1,3) | 离开餐桌 |

 输出：`1 3`后`C 1 2 <`，表变为：```
> <
^^
```跟踪第二个`A 2 1`：

 | 步骤| 位置 | 输送机| 下一页 | 评论 |
 | --- | --- | --- | --- | --- |
 | 1 | (2,1) | ^ | (1,1) | 向上移动 |
 | 2 | (1,1) | > | (1,2) | 向右移动 |
 | 3 | (1,2) | < | (1,1) | 向左移动，循环 |

 输出：`-1 -1`这证实了我们的周期检测有效并且退出传播是准确的。 

**定制样品**```
3 2 2
>^
^^
><
A 3 1
C 3 2 ^
A 3 1
```第一的`A 3 1`退出于`(0,1)`; 改变后`(3,2)`到`^`，第二个查询可能会导致循环，说明正确的重新计算。
