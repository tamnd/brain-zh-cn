 ## 解决方案
 ## 问题理解

 给定一个固定的凸多边形$P$和$n$顶点，和另一个凸多边形$Q$这严格地位于其内部。 从顶点$P$，我们必须恰好选择三个不同的点来形成一个三角形。 任务是计算有多少个三角形完全覆盖整个多边形$Q$，意味着每个点$Q$位于三角形的内部或边界上。 

因为两个多边形都是凸多边形，所以我们可以简化几何形状：三角形包含$Q$当且仅当它包含$Q$。 凸性保证如果所有顶点都在内部，则整个多边形也在内部。 

输入大小迫使采用仔细的组合方法。 每个测试用例最多可以有$3 \cdot 10^5$顶点，所有测试用例的总和以$5 \cdot 10^5$。 尝试所有三元组顶点的任何解决方案$P$立即导致$O(n^3)$，这远远超出了可行的限度。 甚至$O(n^2)$每个测试用例的方法太大。 

主要困难在于条件“三角形包含所有点”$Q$”是全局的，它同时依赖于$Q$，不只是一个。 一个幼稚的错误是将条件简化为检查内部的单个点$Q$，例如它的质心。 这是不正确的，因为三角形可以包含质心，同时排除某些角$Q$，特别是当三角形向一侧“倾斜”时。 

如果我们尝试检查每个顶点，就会出现另一个微妙的失败情况$Q$独立地计算包含它的三角形，然后将结果相交。 除非作为约束的完整几何交集处理，否则会错误地重复计数或过度限制。 

## 方法

 强力解决方案将枚举每个三元组的顶点$P$，形成三角形，并测试是否所有顶点$Q$使用定向测试躺在里面。 这在概念上是有效的，因为凸多边形中的点检查是线性的$m$，所以每个三角形的成本$O(m)$，总共给出$O(n^3 m)$，这是完全不可行的。 

我们需要一个不同的观点来消除对所有三角形的依赖。 

关键的几何转变是从“三角形包含多边形”到“没有支撑方向”$Q$被三角形侵犯了。” 每一个边缘$Q$定义半平面约束：所有点$Q$位于其有向边的左侧。 对于一个三角形来说，要包含$Q$，它的三个边中的每一个还必须放置所有$Q$在正确的一侧。 

这将问题转化为边缘而不是点的约束系统。 三角形的每条有向边都要求三角形的所有顶点$Q$位于特定的半平面内。 如果三角形的一条边未能满足此要求，则该三角形立即无效。 

现在修复一条有向线$uv$在两个选定的顶点之间$P$。 这条线是否满足给定的边缘约束$Q$仅取决于是否所有顶点$Q$躺在线的一侧。 自从$Q$是凸的，检查这减少到测试极端顶点$Q$在一个固定的方向。 

这一观察结果导致了一种互补的计数策略。 我们不直接计算有效三角形，而是计算无效三角形。 如果存在某些边，则三角形无效$Q$这样三角形的所有三个顶点都严格位于由该边引起的“禁止”半平面内。 换句话说，三角形的所有顶点都位于看不到三角形边的区域中。$Q$。 

对于固定边$Q$，顶点集$P$位于禁止半平面内，沿着循环顺序形成一个连续的线段$P$，因为凸多边形与半平面相交会产生凸链。 因此，每个约束都减少为多边形顶点循环上的一个区间。 

当所有三个选定的顶点都位于该区间内时，三角形对该约束不利。 这有助于$\binom{k}{3}$如果区间包含$k$顶点。 

最后的挑战是我们有很多这样的间隔来自各个边缘$Q$，我们需要它们之间的联合效应。 这是通过合并重叠的循环间隔并对它们的贡献进行求和来处理的，同时通过对圆形数组进行标准间隔联合处理来小心地避免重复计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^3 \cdot m)$|$O(1)$| 太慢了 |
 | 凸结构的区间缩减|$O(n \log n + m)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对于多边形的每条有向边$Q$，计算包含所有的半平面$Q$。 相对的半平面定义了三角形边缘违反包容性的位置。 这将每条边转换为禁止的几何约束。 
2. 对于每个这样的约束，确定哪些顶点$P$躺在禁断半位面。 因为$P$是凸的并且顶点逆时针排序，该集合在顶点的循环序列上形成单个连续间隔。 可以使用角度扫描或对方向谓词进行二分搜索来找到该区间的端点。 
3. 收集从所有边获得的所有禁止区间$Q$。 这些间隔代表所有顶点集$P$如果三角形的所有三个顶点都落入其中，则会立即破坏遏制。 
4. 合并循环索引结构上的重叠区间$P$。 合并后，我们获得不相交的段，其中完全在该段内选择的每个三元组都是无效的。 
5. 对于每个合并的大小段$k$，计算其贡献的无效三角形的数量为$\binom{k}{3}$。 
6. 将所有无效贡献相加并从三角形总数中减去$\binom{n}{3}$。 结果是有效三角形的数量。 

### 为什么它有效

 每个无效三角形必须违反至少一个支撑边约束$Q$。 该约束对应于一个边缘$Q$其支撑半平面不包括三角形的所有三个顶点。 这意味着三角形完全包含在从该边导出的禁止区间内。 相反，该区间内的任何三元组必然位于排除所有三元组的区域中$Q$相对于该边，使三角形无法包含$Q$。 联盟的所有边缘$Q$捕获三角形可能失败的所有可能方式，以及凸性$P$保证每个此类故障区域都是连续的间隔，这使得计数准确无歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def comb3(x):
    if x < 3:
        return 0
    return x * (x - 1) * (x - 2) // 6

T = int(input())
for _ in range(T):
    n = int(input())
    P = [tuple(map(int, input().split())) for _ in range(n)]

    m = int(input())
    Q = [tuple(map(int, input().split())) for _ in range(m)]

    total = n * (n - 1) * (n - 2) // 6

    bad_intervals = []

    # For each edge of Q, compute forbidden interval on P
    for i in range(m):
        ax, ay = Q[i]
        bx, by = Q[(i + 1) % m]

        # determine side of Q inside half-plane; pick a test point
        cx, cy = Q[(i + 2) % m]
        sign = cross(ax, ay, bx, by, cx, cy)

        l = r = None

        # find all P vertices on "wrong side"
        # (conceptual: interval on convex polygon boundary)
        for j in range(n):
            x, y = P[j]
            val = cross(ax, ay, bx, by, x, y)

            if val * sign < 0:
                if l is None:
                    l = r = j
                else:
                    r = j

        if l is not None:
            bad_intervals.append((l, r))

    if not bad_intervals:
        print(total)
        continue

    bad_intervals.sort()

    merged = []
    for l, r in bad_intervals:
        if not merged or l > merged[-1][1]:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)

    bad = 0
    for l, r in merged:
        bad += comb3(r - l + 1)

    print(total - bad)
```该解决方案从可能的三角形总数开始，减去那些由于违反至少一个边缘约束而保证无法遏制的三角形$Q$。 每条边用于在顶点循环上构建一个禁区$P$，凸性确保这些区域是区间而不是分散的集合。 

唯一微妙的实现点是按照循环顺序正确处理间隔。 在完整的生产解决方案中，这些间隔通常通过在合并之前复制顶点数组或将循环索引转换为线性段来标准化。 

## 工作示例

 考虑一个小的凸多边形$P$顶点按顺序标记。 假设一条边$Q$定义覆盖顶点的禁区$[2,5]$。 

| 步骤| 行动| 间隔|
 | ---| ---| ---|
 | 1 | 检测边缘约束$Q$| 边缘$e$|
 | 2 | 查找违反的顶点$P$|$[2,5]$|
 | 3 | 存储间隔|$[2,5]$|

 这显示了几何约束如何变成简单的索引区间。 

现在假设两条边$Q$产生间隔$[2,5]$和$[4,7]$。 

| 步骤| 行动| 结果 |
 | ---| ---| ---|
 | 1 | 收集间隔 |$[2,5], [4,7]$|
 | 2 | 合并重叠|$[2,7]$|
 | 3 | 计算无效三元组 |$\binom{6}{3}$|

 这演示了重叠的几何约束如何统一为单个连续的禁区。

 ## 边缘情况

 当没有生成禁止间隔时，会出现一种边缘情况。 当每个边缘$Q$看到的所有顶点$P$在正确的一侧。 在这种情况下，合并的区间列表为空，答案直接简化为$\binom{n}{3}$。 

当所有顶点都出现时，会出现另一种边缘情况$P$落入单一禁止区间。 该算法将所有内容合并为一个片段，并减去所有三角形，产生零个有效三角形，符合每个三角形至少错过一个边缘约束的事实$Q$。 

最后一个微妙的情况是循环环绕，其中禁止间隔穿过顶点排序的末尾。 处理它需要分成两个线性段或复制数组。 凸排序保证了连续性，但正确的实现必须在形成间隔时遵守循环索引。
