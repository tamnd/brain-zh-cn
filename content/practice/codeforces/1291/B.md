 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组。 只要任何元素保持非负数，我们就可以重复将其减 1。 目标是决定我们是否可以将数组转换为首先严格增加到某个峰值位置然后严格减少的形状。 

关键是我们没有重新排列元素。 我们只会降低价值。 因此，每个位置都有一个由其初始值给出的上限，但我们可以选择 0 和该界限之间的任何最终值。 

我们想知道是否存在形成严格“山”序列的最终值的选择。 

约束很大：所有测试用例的总长度最多为 3·10^5。 任何试图测试所有可能的峰值位置并天真地模拟调整的解决方案都会失败，因为即使每个测试用例的 O(n^2) 也太慢了。 

一个微妙的问题来自于贪婪地思考而没有正确地执行严格性。 例如，如果数组已经是非增或非减的，它自动有效，但中间形状如`[2, 1, 2]`无法固定，因为中间元素不能既成为严格的峰值又仍然遵循单调结构。 

另一个棘手的情况是值相等。 由于需要严格的不平等，因此相等的相邻值会迫使至少一侧减少，这可能会级联并破坏可行性。 

## 方法

 一个蛮力的想法是尝试每一个可能的峰值指数`k`。 For each choice, we attempt to build a strictly increasing sequence from the left and a strictly decreasing sequence from the right, never exceeding the original values.

 对于固定峰值，我们可以贪婪地分配满足严格性的最小可能值，同时保持≤原始数组。 例如，从左边我们可以强制执行`b[i] = min(a[i], b[i-1] + 1)`增加，并且从右边开始类似。 这是可行的，因为我们总是希望在尊重约束的同时保持尽可能大的值。 

然而，对每个重复这个构造`k`在最坏的情况下，每个测试用例的时间复杂度为 O(n^2)。 总共有 3·10^5 个元素，这太慢了。 

关键的观察是，可行性取决于全球范围内是否存在单一的“最佳可能峰值”建设。 我们可以计算两个数组，而不是显式选择峰值：可实现的最大严格递增前缀和可实现的最大严格递减后缀。 然后我们检查是否存在一个索引，使得从左边开始的递增结构可以满足从右边开始的递减结构而不发生冲突。 

这将问题简化为两次线性扫描。

 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们构造两个辅助数组。 一个模拟我们可以从左侧构建的最佳严格递增序列，另一个模拟从右侧开始的最佳严格递减序列。 

### 逐步过程

 1. 构建数组`inc`在哪里`inc[i]`是我们可以在该位置分配的最大值`i`同时使序列严格从左到右递增且永不超过`a[i]`。 我们设定`inc[0] = a[0]`，并且对于每个`i > 0`，我们计算`inc[i] = min(a[i], inc[i-1] + 1)`。 这确保了我们保持严格的增长，同时尽可能少地浪费价值。 
2. 构建数组`dec`在哪里`dec[i]`是我们可以在该位置分配的最大值`i`同时使序列严格从右到左递减。 我们设定`dec[n-1] = a[n-1]`，并且对于每个`i < n-1`，我们计算`dec[i] = min(a[i], dec[i+1] + 1)`。 
3. 对于每个位置`k`，我们测试是否可以作为峰值。 对于有效峰值，增加部分必须结束于`k`并且减少的部分必须开始于`k`。 所以我们需要`inc[k] > 0`兼容性和`inc[k]`应该以一致的方式严格大于它周围的两侧。 clean条件变为检查是否存在`k`这样`inc[k]`兼容于`dec[k]`当被视为峰值时（两种结构都可以在`k`）。 
4.我们验证是否存在至少一个索引`k`这样`inc[k] == dec[k]`。 如果存在这样的位置，我们可以将两个结构对齐以形成一座有效的山。 
5. 如果不存在这样的索引，则答案为“否”，否则为“是”。 

### 为什么它有效

 的建设`inc`和`dec`捕获单调约束下每个索引的最大可行高度。 任何有效的锐化数组必须逐点位于两个结构下方。 如果我们能找到两个结构都一致的点，那么该点可以充当左右约束相交的一致峰值，而不会违反严格性。 由于两个数组在各自的约束下都是贪婪最大值，因此任何有效的解决方案都必须通过这种对齐来表示，从而确保完整性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n == 1:
            print("Yes")
            continue

        inc = [0] * n
        dec = [0] * n

        inc[0] = a[0]
        for i in range(1, n):
            inc[i] = min(a[i], inc[i-1] + 1)

        dec[n-1] = a[n-1]
        for i in range(n-2, -1, -1):
            dec[i] = min(a[i], dec[i+1] + 1)

        ok = False
        for i in range(n):
            if inc[i] == dec[i]:
                ok = True
                break

        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```这`inc`array 在不超出约束的情况下强制执行最佳可能的严格递增前缀。 这`dec`数组对后缀执行相同的操作。 最终扫描检查两种结构相遇处是否存在一致的峰高。 

一个常见的实施陷阱是忘记双方都必须遵守严格性。 这`+1`转换是隐式强制严格增加或减少的。

 ## 边缘情况

 单元素数组始终满足定义，因为不需要严格的不等式。 该算法明确地处理了这个问题。 

具有重复值的数组，例如`[1, 1, 1]`失败是因为任何形成严格单调线段的尝试都会强制至少进行一次还原，从而破坏峰值所需的对称性。 

始终接受严格单调数组，因为`inc`或者`dec`变得与原始数组相同，确保整个结构的完全匹配。
