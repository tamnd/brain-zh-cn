 ## 解决方案
 ## 问题理解

 给定一个数字字符串，我们可以删除其中的一些数字，同时保持剩余数字的相对顺序。 目标是形成一个非空子序列，表示一个同时满足两个条件的数字：其数字之和为偶数，并且该数字的最后一位为奇数，这意味着该数字本身不能被 2 整除。 

操作空间是纯粹的子序列，因此输入的结构是固定顺序的，并且可以选择删除。 我们不允许对数字重新排序或引入新的数字，因此唯一的灵活性在于选择索引的子集。 

对测试用例总长度的约束足够小，每个测​​试用例的任何线性或近线性贪婪策略就足够了。 在最坏的情况下，每个测试用例都是二次的解决方案已经可以接受，但是子序列上的任何指数形式都是不可能的，因为对于 n 高达 3000 的情况，它会爆炸为 2^n。 

当字符串根本没有奇数位时，就会出现微妙的边缘情况。 在这种情况下，每个子序列都以偶数结束，因此数字始终是偶数，这违反了数字本身必须是奇数的要求。 当我们选择奇数最后一位数字但无法在不丢失最后一位数字的情况下调整数字和的奇偶性时，会出现另一个失败情况，这迫使我们仔细选择而不是天真贪婪地选择所有数字。 

## 方法

 暴力方法会尝试所有子序列，计算它们的数字和，并检查结果数字是否以奇数结尾。 从概念上讲，这是可行的，因为每个有效答案都是一个子序列，因此穷举搜索可以保证找到一个子序列（如果存在）。 然而，子序列的数量呈指数增长，特别是 2^n，并且当 n 达到 3000 时，这是完全不可行的。 

关键的观察结果是，该条件仅取决于两个属性：数字和的奇偶性和最后一位数字的奇偶性。 我们不关心数值本身或字典序最优性。 这意味着我们只需要构造以奇数数字结尾的任何子序列，同时确保所有选定数字的总和为偶数。 

这立即建议首先修复最后一位数字。 由于数字必须是奇数，因此最后选择的数字必须是 {1, 3, 5, 7, 9} 之一。 一旦最后一位数字被固定，我们只需要决定包含哪些前面的数字以使总和奇偶校验均匀。 这将问题简化为选择具有奇偶校验约束的子集，该问题始终可以通过累加数字直到满足奇偶校验条件来贪婪地处理。 

如果我们从右边向后工作，尝试可能的奇数结尾候选并贪婪地在它们之前获取尽可能多的有用数字，那么构造就会变得简单。

 ## 算法演练

 我们通过尝试选择一个有效的最后一个数字，然后在它之前构建一个前缀来构造一个答案。

1. 从右向左扫描字符串，找到所有数字为奇数的位置。 每个这样的位置都是答案最后一位数字的候选者。 我们必须考虑它们，因为最终的数字必须是奇数。 
2. 对于每个候选的最后一个位置，我们尝试从其左侧的数字构建有效的前缀。 我们维护我们选择的数字的运行总和奇偶性。 目标是使所选数字（包括最后一位数字）的总和为偶数。 
3. 我们从字符串的开头迭代到所选最后一个数字之前。 我们贪婪地包含数字，但我们只对控制奇偶校验感兴趣。 我们跟踪模 2 的总和。 
4. 处理完所有前面的数字后，我们检查添加最后一位数字是否会产生偶数总和。 如果不是，我们会尝试通过删除前面一位翻转奇偶校验的数字来进行调整。 由于删除一位数字会改变其值模 2 的奇偶性，因此我们只需要确保前缀中至少存在一个奇数位，如果需要可以将其排除。 
5. 如果找到有效的配置，我们立即输出构造的子序列。 如果没有奇数结尾的选择有效，我们输出-1。 

这样做的原因是唯一的全局约束是总和的奇偶校验和最后一位数字约束。 一旦最后一位数字被固定，所有剩余的数字仅通过其奇偶性起作用，因此除了是否包含它们之外，我们永远不需要推理它们的确切值或位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    odd_positions = [i for i, ch in enumerate(s) if (ord(ch) - 48) % 2 == 1]

    if not odd_positions:
        print(-1)
        return

    for last in reversed(odd_positions):
        total = 0
        prefix_digits = []

        for i in range(last):
            d = ord(s[i]) - 48
            total += d
            prefix_digits.append(s[i])

        last_digit = ord(s[last]) - 48
        total += last_digit

        if total % 2 == 0:
            ans = ''.join(prefix_digits) + s[last]
            if ans and ans[0] != '0':
                print(ans)
                return
        else:
            found = False
            for i in range(last - 1, -1, -1):
                if (ord(s[i]) - 48) % 2 == 1:
                    adjusted = prefix_digits[:i] + prefix_digits[i+1:] + [s[last]]
                    print(''.join(adjusted))
                    found = True
                    break
            if found:
                return

    print(-1)

if __name__ == "__main__":
    solve()
```该代码首先收集所有可能的奇数结尾位置，因为最后一位数字必须是奇数。 对于每个候选者，它计算前缀和并检查奇偶校验条件是否已经成立。 如果是的话，我们直接输出。 否则，它会尝试通过从前缀中删除奇数位来进行小修正，从而翻转奇偶校验并修复条件。 

一个微妙的实现细节是，除了打印最终答案之外，我们在探索过程中从不构造完整的子序列。 这避免了重复字符串连接中的二次开销。 另一个重要的一点是，我们从右到左迭代候选者，因为后面的位置往往会在前缀中保留更多的灵活性。

 ## 边缘情况

 关键的边缘情况是字符串仅包含偶数位。 对于像这样的输入`2468`，没有有效的最后一位数字选择，因此算法立即返回 -1，而不尝试构造。 

另一种情况是唯一的奇数位位于最后。 在这种情况下，必须选择前缀来单独满足奇偶校验。 该算法处理此问题是因为它考虑最后一位数字并计算空或完整前缀的前缀总和，从而正确评估可行性。 

第三种情况是存在多个奇数位但只有一个允许奇偶校验对齐。 对候选者的反向迭代确保我们尝试所有可能性，并且返回第一个成功的构造，而不需要全局优化。
