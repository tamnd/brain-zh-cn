 ## 解决方案
 ## 问题理解

 我们有一个矩形网格$n$行和$m$列，我们必须使用多米诺骨牌完全平铺它，每个多米诺骨牌正好覆盖两个相邻的单元格。 每个单元格必须恰好属于一个多米诺骨牌，因此网格被完全划分为成对的邻居。 

在平铺的所有多米诺骨牌中，正是$k$必须水平放置，这意味着它们连接左侧和右侧的单元，而所有剩余的多米诺骨牌都是垂直的，连接顶部和底部的单元。 由于每个多米诺骨牌覆盖两个单元，因此多米诺骨牌的总数固定为$\frac{nm}{2}$，因此垂直多米诺骨牌的数量被迫为$\frac{nm}{2} - k$。 

输出不仅仅是有效性决策。 我们还必须构造一个显式平铺，通过为每个多米诺骨牌分配一个字母来表示，以便同一多米诺骨牌的两个单元共享一个字母，并且来自不同多米诺骨牌的相邻单元不得共享一个字母。 这些字母只是多米诺骨牌组件的标识符，而不是有意义的值。 

约束很小：两个维度都最多为 100，并且最多有 10 个测试用例。 这排除了对平铺的任何指数搜索或回溯，因为即使是大小为 100 x 100 的单个网格也将具有天文数字般的多米诺骨牌分解数量。 解决方案必须与单元数量呈线性关系，并且通常只需经过几次网格。 

一个关键的结构约束是奇偶性：多米诺骨牌平铺总是将单元配对，但水平和垂直放置与网格几何形状的相互作用不同。 这会造成即使存在平铺也无法获得所需数量的水平多米诺骨牌的情况。 

当尝试逐行进行贪婪水平放置而不检查每行或每列的奇偶校验时，会出现微妙的失败情况。 例如，在一个$2 \times 3$网格与$k = 0$，人们可能会尝试垂直填充所有内容，但每一列都有奇数高度，因此仅垂直平铺是不可能的。 正确的答案仍然是“否”，因为网格的结构阻止了纯粹的垂直分解。 

另一种边缘情况出现在奇数尺寸的网格中。 在一个$3 \times 3$在网格中，任何平铺都必须以受约束的方式混合方向，并且盲目地交替方向可能会迫使剩余的不匹配的单元格。 

## 方法

 一个天真的尝试是将其视为网格图中的匹配问题，其中每个单元格都是一个顶点，边连接相邻的单元格。 我们想要完美匹配$k$水平边缘。 强力方法将枚举所有完美匹配并计算水平边缘，甚至进行回溯，尝试递归地配对相邻的空闲单元。 匹配的数量呈指数增长$nm$，所以即使$4 \times 4$网格已经产生了太多的配置需要探索。 

关键的观察是我们实际上不需要搜索匹配。 我们只需要一种结构化的平铺，并且我们可以自由地确定性地构建它。 网格是二分的，因此我们可以将其平铺为固定模式$2 \times 2$块或行对，然后局部调整块内的方向以控制我们创建的水平多米诺骨牌数量。 

一个特别有用的观点是将网格分组为垂直的行对。 在每对行内，每列都会贡献一个垂直多米诺骨牌或水平多米诺骨牌，具体取决于我们如何在行间或行内配对单元格。 这会将全局约束转换为水平边缘的每行对预算。 

该结构简化为决定，对于每个相邻的行对，我们在该条带内放置多少个水平多米诺骨牌，确保所有条带的总和等于$k$。 每个条带可以独立实现任意偶数个水平多米诺骨牌，最多可达$m$，然后我们将这些条带缝合在一起。 

这就把问题转化为分布问题$k$跨越独立的块，之后每个块都以确定性的交替模式填充。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 首先，我们检查是否可以通过将网格简化为行对来构建。 如果$n$很奇怪，最后一行必须小心处理，在这种情况下，只有列内的垂直多米诺骨牌是可能的。 这立即限制了该行中可以存在的水平多米诺骨牌数量，因为水平多米诺骨牌无法容纳在那里。 
2. 我们一次构建两行网格。 每对连续行被视为高度为 2、宽度为水平的条带$m$。 在这样的条带内，我们可以自由决定放置位置。 
3. 对于每个条带，我们决定要放置多少个水平多米诺骨牌。 我们贪婪地分配最多$m$每条水平多米诺骨牌，但我们确保永远不会超过剩余的$k$。 
4. 在选定的条带内，我们将水平多米诺骨牌放置在不相交的列对中。 例如，列$0-1$,$2-3$等。每一对都消耗一个水平多米诺骨牌，并被分配一个唯一的字母。 
5. 条带中未用于水平放置的任何剩余列将在条带内垂直填充，将顶部和底部单元配对。 
6. 如果列数为奇数，则条带中的最后一列不能形成水平多米诺骨牌，因此它必须是垂直的。 
7. 重复上述操作，直到处理完所有条带。 最后，如果我们没有准确地使用$k$水平多米诺骨牌，构造无效。 

### 为什么它有效

 每个$2 \times m$条带在平铺结构方面是独立的：一条条带中的水平多米诺骨牌永远不会干扰另一条带。 在条带内，水平或垂直配对列始终会产生有效的完美匹配。 由于每个单元都属于一个条带，并且每个条带都完美平铺，因此全局平铺是有效的。 该结构确保每个条带的水平多米诺骨牌计数得到精确控制，因此满足总和约束而不会发生冲突。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())

        grid = [[''] * m for _ in range(n)]
        used = 0
        cur = ord('a')

        ok = True

        for i in range(0, n, 2):
            if i + 1 >= n:
                # last single row: only vertical dominos possible
                if k != 0:
                    ok = False
                    break
                for j in range(0, m, 2):
                    if j + 1 >= m:
                        ok = False
                        break
                    c = chr(cur)
                    grid[i][j] = c
                    grid[i][j + 1] = c
                    cur += 1
                continue

            # we have a 2-row strip: i and i+1
            for j in range(m):
                if k == 0:
                    break

                if j + 1 < m and k > 0:
                    # try horizontal domino inside strip
                    c = chr(cur)
                    grid[i][j] = c
                    grid[i][j + 1] = c
                    used += 1
                    k -= 1
                    cur += 1
                else:
                    break

            # fill remaining cells in this strip vertically
            for j in range(m):
                if grid[i][j] == '':
                    if i + 1 >= n:
                        ok = False
                        break
                    c = chr(cur)
                    grid[i][j] = c
                    grid[i + 1][j] = c
                    cur += 1

        if not ok or k != 0:
            print("NO")
        else:
            print("YES")
            for row in grid:
                print(''.join(row))

if __name__ == "__main__":
    solve()
```该代码使用递增字母来分配多米诺骨牌身份。 每个放置要么在行对内分配一个水平对，要么垂直填充一列。 变量`k`仅当我们明确放置水平多米诺骨牌时才会消耗，确保精确控制所需的数量。 

一个微妙的点是，我们永远不允许在奇数高度网格的最后一行进行水平放置，因为该行不能支持水平多米诺骨牌。 该约束由行对循环结构隐式强制执行。

这表明完整的条带可以实现任何$k \le m$。 

＃＃＃ 例子：$n=3, m=2, k=1$我们将前两行作为条处理，最后一行单独处理。 

| 步骤| 行| 行动| k | 网格状态|
 | --- | --- | --- | --- | --- |

 最后一行仅强制垂直配对，并且因为$k$已经满意了，构建成功。 

这演示了剩余行如何限制方向灵活性。

 ## 边缘情况

 一个关键的边缘情况是当$n$很奇怪。 在这种情况下，最后一行没有伙伴，因此该行中的每个单元格都必须是垂直多米诺骨牌的一部分。 该算法通过从不尝试在最后一行中水平放置并且仅在可能的情况下将其向下配对来处理此问题； 否则，当结构不允许完全覆盖时，它会拒绝配置。 

另一个边缘情况是当$m$a 内为奇数$2 \times m$条。 最后一列不能是水平多米诺骨牌的一部分，因此它必须垂直配对。 该结构自然地将其留作垂直分配，确保不会留下无效的半多米诺骨牌。 

当出现进一步的边缘情况时$k = 0$。 该算法跳过所有水平放置并直接垂直填充每一列，从而产生干净的按列平铺。 这证实了该结构正确地退化为纯粹的垂直匹配，而不需要超出跳过条件的特殊套管。
