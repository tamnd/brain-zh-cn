 ## 解决方案
 ## 问题理解

 波利卡普需要准确支付`n`burles 仅使用价值 1 burles 和 2 burles 的硬币。 让`c1`是 1-burle 硬币的数量，`c2`是 2-burle 硬币的数量。 

付款必须满足：$$c_1 + 2c_2 = n$$在所有有效的求和方法中`n`，我们希望两种硬币类型的数量尽可能平衡。 换句话说，我们必须尽量减少：$$|c_1 - c_2|$$对于每个测试用例，我们需要输出一对最优的`(c1, c2)`。 

测试用例数量可达10000个，`n`可以大到`10^9`。 任何对单个测试用例尝试多种可能性的解决方案都会立即引起怀疑。 即使是线性扫描`n`一个测试用例需要多达十亿次迭代，这远远超出了时间限制。 我们需要一个直接的数学公式来在恒定时间内计算出答案。 

如果我们只考虑方程而忘记平衡要求，一些边缘情况很容易处理不当。 

考虑`n = 1`。```
1
```唯一有效的付款是：```
1 0
```盲目地将金额分成相等部分的公式可能会意外产生负值或无法满足总和。 

考虑`n = 2`。```
2
```正确答案是：```
0 1
```差别是 1。相等的计数是不可能的，因为一枚硬币贡献 1，而另一枚硬币贡献 2。 

考虑`n = 5`。```
5
```最佳答案是：```
1 2
```粗心的做法可能会选择`(3,1)`因为它的和也是 5，但它的差是 2 而不是 1。 

有趣的情况发生在`n`不能被 3 整除。这些余数决定哪种硬币类型可以获得额外的硬币。 

## 方法

 一个简单的暴力解决方案会尝试每一个可能的值`c2`从 0 到`n/2`。 对于每个选择，我们可以计算：$$c_1 = n - 2c_2$$并评估`|c1 - c2|`。 差异最小的一对就是答案。 

这是有效的，因为每笔有效付款都对应于一个选择`c2`，因此检查所有可能性可以保证找到最佳值。 

问题在于规模。 什么时候`n = 10^9`，该循环将为单个测试用例执行大约 5 亿次迭代。 对于多达 10,000 个测试用例，运行时变得完全不可行。 

关键的观察结果来自于查看等式：$$c_1 + 2c_2 = n$$如果`c1`和`c2`完全相等，假设两者都等于`x`， 然后：$$x + 2x = 3x = n$$所以完美平衡的解决方案会分裂`n`分成三等份。 这立即表明两个计数应尽可能接近`n/3`。 

让：$$n = 3k + r$$在哪里`r`是 0、1 或 2。 

当`r = 0`，分割是完美的：$$c_1 = k,\quad c_2 = k$$什么时候`r = 1`，我们还需要一个额外的毛刺`3k`。 额外提供一枚 1-burle 硬币会使总数恰好增加 1，同时尽可能保持计数平衡：$$c_1 = k+1,\quad c_2 = k$$什么时候`r = 2`，我们还需要两个额外的字节`3k`。 额外给予一枚 2-burle 硬币，总数正好增加 2：$$c_1 = k,\quad c_2 = k+1$$这产生了直接的恒定时间解决方案。

 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取值`n`。 
2. 计算：$$k = n // 3$$这是平衡的基本金额，因为一枚 1 伯勒硬币和一枚 2 伯勒硬币总共贡献 3 伯勒。 
3. 计算：$$r = n \bmod 3$$余数告诉我们在形成平衡底座后还剩下多少节。 
4. 如果`r = 0`， 输出：$$c_1 = k,\quad c_2 = k$$该金额可以精确地整除为相等的数量。 
5.如果`r = 1`， 输出：$$c_1 = k+1,\quad c_2 = k$$添加一枚额外的 1-burle 硬币会使总数恰好增加 1，并使差异保持最小。 
6. 如果`r = 2`， 输出：$$c_1 = k,\quad c_2 = k+1$$添加一枚额外的 2-burle 硬币会使总数恰好增加 2，并使差异保持最小。 

### 为什么它有效

 该方程自然地将硬币分成由一枚 1-Burle 硬币和一枚 2-Burle 硬币组成的对。 每个这样的平衡对贡献 3 个字节。 如果`n = 3k`， 然后`k`配对已经形成准确的数量并且计数相等。 

当余数为 1 时，再添加 1 个 burle 的唯一方法是将 1-burle 硬币的数量增加 1。 当余数为 2 时，在保持最接近平衡的同时恰好再添加两个 burle 的唯一方法是将 2-burle 硬币的数量增加 1。 

结果计数总是满足`c1 + 2*c2 = n`，任何其他有效的解决方案都会使计数相距更远。 因此产生的对最小化`|c1 - c2|`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())

    k = n // 3
    r = n % 3

    if r == 0:
        c1, c2 = k, k
    elif r == 1:
        c1, c2 = k + 1, k
    else:
        c1, c2 = k, k + 1

    print(c1, c2)
```实现直接遵循数学推导。 

变量`k`代表平衡的碱基分布。 每组 3 个 burles 可以用每种类型的一枚硬币来表示，因此`n // 3`给出此类平衡组的最大数量.

 余数决定了额外的价值必须去往何处。 剩余的 1 只能通过额外一枚 1-burle 硬币来补充。 剩余的 2 可用一枚额外的 2-burle 硬币来补充。 

不存在溢出问题，因为 Python 整数处理的值远大于`10^9`。 唯一微妙的一点是根据余数将多余的硬币分配到正确的面额。 交换这些情况仍然可以满足总和，但不会最小化差异。
