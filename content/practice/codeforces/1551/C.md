 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中，我们收到一个单词列表，并且我们希望选择尽可能多的单词，以便所选子集满足特定的不平衡条件。 

通过查看所有选定单词的字母频率来评估该条件。 字母之中`a, b, c, d, e`，我们希望找到一个字母，使其在所选单词中出现的总次数严格大于所有其他字母组合出现的总次数。 

另一种看待这一问题的方法是想象我们选择一些单词，然后计算每个字母在全局中出现的次数。 我们正在寻找一个“主导”字母表中其余字母的字母。 

任务不是最大化单词内的任何内容，而是选择使这种主导地位成为可能的单词子集，同时保持子集尽可能大。 

约束很大：所有测试用例的总单词数最多为 2 · 10^5，总字符长度最多为 4 · 10^5。 这排除了尝试所有子集或重复重新计算每个候选子集的字符计数的任何解决方案。 任何每个测试用例的解决方案在总输入大小上都必须接近线性或线性对数。 

一个天真的想法是尝试单词的每个子集，但这在 n 中是指数级的并且立即不可行。 即使尝试对子集进行排序或重新计算每个前缀的完整频率表也会太慢。 

一种更微妙的失败模式来自于贪婪地获取所有单词：当没有一个字母在全局中占主导地位时，这显然会失败。 例如，平衡的单词，如`"abcde"`所有字母的贡献均等，无论占据多少字母，都无法占据主导地位。 

另一个微妙的问题是假设我们应该选择单词中所选字母频繁出现的单词。 仅此还不够，因为条件取决于_与所有其他字母组合的全局比较_，而不仅仅是局部最大化单个字母。 

## 方法

 关键的困难在于，条件在字母计数上是全局的，但决策是在单词级别做出的。 这意味着将每个单词简化为它对候选字母“有帮助”或“有害”的程度。 

修改一封信，说`x`。 对于一组选定的单词，我们想要：```
count_x > sum of counts of all other letters
```重写这个，我们为每个单词定义一个相对于`x`:```
score(word, x) = (# of x in word) - (# of non-x letters in word)
```如果我们对选定的单词求和，则条件变为：```
total_score(x) > 0
```因此，对于固定字母，每个单词都成为单个整数贡献。 我们希望选择尽可能多的单词，使其总分为正。 固定字母的最佳策略是贪婪的：按分数按降序对单词进行排序，并在运行总和保持正数的情况下采用前缀。 

最终答案是所有 5 个字母中最好的结果。 

这是有效的，因为一旦我们修复了目标字母，问题就变成了在前缀和的单调约束下的最大大小前缀选择。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 对于五个字母中的每一个`a`到`e`，将其视为候选主导字母。 

这将问题简化为检查该字母是否可以支配其余字母。 
2. 对于每个单词，计算其对所选字母的贡献分数：计算该字母的出现次数减去所有其他字母的出现次数。 

这会将每个单词转换为一个整数值，表示其对该字母的有用性。 
3. 按此分数对所有单词进行降序排序。 

这确保我们首先考虑最有益的单词，从而最大限度地延长前缀保持正数的时间。 
4. 遍历排序列表并维护运行总和。 继续扩展前缀，只要添加下一个单词即可使总和严格为正数。 

一旦总和变为非正数，我们就停止。 
5. 记录这封信可达到的最大字数。 
6. 对所有五个字母重复此操作，并取其中的最大结果。 

### 为什么它有效

 对于固定字母，变换将原始约束简化为独立贡献总和的线性不等式。 任何最佳选择必须首先由边际效益最高的单词组成； 否则，将较低分数的单词与较高分数的单词交换只会增加总和或保持其不变，而不会减小大小。 此交换参数保证最佳有效子集对应于排序顺序的前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(words):
    best = 0

    for target in "abcde":
        vals = []
        for w in words:
            c = 0
            for ch in w:
                if ch == target:
                    c += 1
                else:
                    c -= 1
            vals.append(c)

        vals.sort(reverse=True)

        s = 0
        cnt = 0
        for v in vals:
            if s + v <= 0:
                break
            s += v
            cnt += 1

        best = max(best, cnt)

    return best

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        words = [input().strip() for _ in range(n)]
        print(solve_case(words))

if __name__ == "__main__":
    main()
```该代码遵循前面描述的减少。 每个单词都会转换为相对于当前目标字母的分数。 排序确保我们始终优先考虑最有力支持主导条件的单词。 前缀积累直接强制执行严格的积极性要求。 

一个微妙的细节是停止条件`s + v <= 0`。 当添加一个单词会破坏严格的支配地位时，我们必须立即停止，因为由于排序顺序，任何其他单词都不会更好。 另一个重要的一点是分别重新计算每个字母的分数，因为最佳子集在很大程度上取决于哪个字母被选为主要字母。

 ## 边缘情况

 一个关键的边缘情况是每个单词都完美平衡，例如`"abcde"`。 对于这样的输入，每个字母的贡献相等，因此每个分数都是零。 该算法对零进行排序并立即停止，因为第一次加法已经违反了严格的正性。 

另一种边缘情况是当所有单词都由单个重复字母组成时，例如`"a", "a", "a"`。 对于目标字母`a`，每个分数都是正数，因此所有单词均被采纳。 对于其他字母，所有分数均为负数，产生零个选择。 最大值正确地成为完整计数。 

第三种情况是混合优势，其中一个单词强烈支持一个字母，但轻微损害它的整体，强制排序效果。 排序步骤确保这些单词被正确放置，并且前缀规则可以防止无效的选择出现在序列的后面。
