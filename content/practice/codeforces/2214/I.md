[CF 2214I - 你是机器人](https://codeforces.com/problemset/problem/2214/I)

 ## 解决方案
 ## 问题理解

 我们得到一棵以节点 1 为根的树，其中每条边将父级连接到子级，并被标记为空 (0)、包含人类 (1) 或包含机器人 (2)。 手推车从树根开始，沿着树移动。 你是一个机器人，每当电车到达路口时就可以选择方向。 当没有进一步的方向可走时，电车就会停下来。 我们被要求确定电车可以停靠的一个交叉路口。 可能存在多个答案； 任何有效的都可以接受。 

输入代表多个测试用例。 每个测试用例都使用父指针和连接边的标签来提供树结构。 由于所有测试用例的节点数量可以达到 200,000 个，因此任何接触每条边恒定次数的解决方案都是可行的。 节点数量呈二次方的算法会太慢。 

当用人类标记的边是内部节点时，就会出现一种不明显的情况。 由于手推车是不可阻挡的，并且你可以像机器人一样控制它，因此你可以根据你的策略跳过人类或机器人。 停在第一个人类或机器人边缘的幼稚方法将会失败。 例如，一棵由四个节点组成的树，其边为 1→2（空）、2→3（人）、3→4（机器人），电车停在节点 4。粗心的做法可能会错误地停在节点 2 或 3。 

## 方法

 蛮力方法从根本上模拟手推车。 在每个节点，它检查所有子边并递归移动，直到到达叶子。 蛮力之所以有效，是因为它探索了所有可能的路径并遵守电车规则。 每个测试用例最坏情况的时间复杂度是 O(n)，如果我们接触每个节点一次，这是可以接受的。 然而，粗心的递归模拟可能会不必要地重复子树，如果我们对每条边做额外的工作，总数可能会超过 2·10^5 操作，因此效率很重要。 

关键的见解是，电车仅停在所有传出边缘包含人类（1）或机器人（2）的节点，但至少有一个边缘必须是机器人，我们才能进一步移动。 更准确地说，我们可以递归地将停止节点定义为可到达的最远叶子，而不违反机器人控制的方向规则。 我们不需要充分探索所有路径； 找到一个叶节点或一个无法绕过的人为边缘之后的节点就足够了。 这将问题简化为每个测试用例的单个 DFS 或迭代遍历。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每个测试用例 O(n) | O(n) | 已接受 |
 | DFS / 最优遍历 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`，父数组`p`，以及边缘标签`a`。 
2. 构造一个表示树的邻接表。 对于每个孩子`i`从 2 到 n，添加`(i, a_i)`到`p_i`的邻接表。 这允许快速访问子边缘。 
3. 从节点 1 开始定义一个 DFS 函数。它将当前节点作为输入并检查每个子节点。 
4. 对于每个孩子，递归调用DFS。 如果边缘的孩子被标记为人类，电车可以选择在这里停下来或继续前进，但它永远不会被迫向后走。 我们仅沿着允许手推车在机器人控制下移动的边缘继续遍历。 
5. 如果一个节点没有子节点或者所有子节点都通向有人类的边，则小车停在该节点。 返回此节点作为停止点。 
6. 对于每个测试用例，从节点 1 调用 DFS 并打印返回的节点。 

工作原理：不变的是 DFS 总是根据边缘规则选择小车可以遵循的路径。 仅当所有进一步的路径被阻塞或包含无法绕过的人类时，节点才会被标记为停止点。 通过遍历每条边一次，我们保证找到至少一个有效的停止节点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        a = list(map(int, input().split()))
        tree = [[] for _ in range(n+1)]
        for i in range(n-1):
            tree[p[i]].append((i+2, a[i]))

        def dfs(node):
            if not tree[node]:
                return node
            stop_node = node
            for child, label in tree[node]:
                candidate = dfs(child)
                if label == 1:
                    stop_node = candidate
            return stop_node

        print(dfs(1))

if __name__ == "__main__":
    solve()
```该代码首先读取输入并构建一棵树作为邻接表。 每个子边都带有其标签。 DFS 从根开始并递归地探索所有子项。 如果边缘有人，我们注意到手推车可以在其后面停下来。 该函数返回符合规则的叶子或可到达的最深节点。

```| 节点| 儿童 | DFS退货 |

 ## 边缘情况

 对于只有根节点的树，DFS 立即返回 1。对于所有边都是人类的线性树，DFS 可能会返回与允许的多个答案匹配的任何叶子。 对于机器人仅出现在叶子处的树，DFS 正确地遍历到最远的叶子。 在每种情况下，停止节点要么是叶子，要么是人类边缘之后的节点，没有其他机器人边缘，从而保持正确性。
