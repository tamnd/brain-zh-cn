 ## 解决方案
 ## 问题理解

 每个参与者从飞机上的一个固定点开始，我们被要求选择一个集合点，以便每个参与者从他们的起点到这个共享目的地经过相同的欧几里德距离。 起始位置是固定的，但我们可以自由选择目的地和共同旅行距离。 

从几何角度来说，这意味着我们正在寻找一个点$E(x_e, y_e)$这样所有给定的点都位于以$E$，具有相同的半径$d$。 任务是判断这样的圆是否存在，如果存在，则输出其圆心和半径。 

约束允许最多$10^5$点，因此任何比较所有对或以简单方式重新计算每个点几何形状的解决方案在经过一些预处理后都必须保持线性。 坐标是小整数，但答案需要浮动精度高达$10^{-6}$，这将解决方案推向直接几何计算而不是组合搜索。 

一些边缘情况打破了天真的推理。 如果所有点都相同，则正确答案很简单：中心是该点并且距离为零。 如果正好有两个点，则有无限多个有效中心，因此选择中点是可行的。 当点由于共线性而几乎但不完全共圆时，会发生更微妙的失败：例如，像 (0,0)、(1,0)、(2,0) 这样的三个共线点不能位于具有与所有三个不同点等距的有限中心的圆上，因此答案必须为“否”，即使任何两点推理都会错误地表明“是”。 

## 方法

 暴力解释会尝试猜测中心$E$并验证所有距离是否匹配。 由于中心在平面上是连续的，因此不能直接枚举。 另一个天真的想法是选择每一对点并从中构造一个候选圆心，然后针对所有点进行验证。 对于每一对，我们可以尝试推导出一个使距离相等的中心，但是$O(n^3)$在最坏的情况下进行几何检查，这对于$n = 10^5$。 

关键的观察是，如果这样一个点$E$对于所有点都存在，那么它也必须满足三个非共线点的任何子集的条件。 三个不共线的点唯一确定一个圆，因此如果我们能找到一个有效的三元组，那么它的外心一定就是答案。 一旦我们计算出这个候选中心，剩下的唯一工作就是验证每个点与它的距离是否相同。 

如果所有点共线，则正半径的圆不能穿过两个以上不同的点，因此唯一可能的有效配置是所有点重合时。 这种堕落成为一种单独的检查。 

这将问题简化为从最多三个点找到稳定的几何构造，然后进行线性验证。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力中心猜测 | O(n3) | O(1) | O(1) | 太慢了 |
 | 3点+验证的圆心| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 扫描点并检查所有点是否相同。 如果是，答案是立即的：中心就是该点并且距离为零。 这是每个配置都分解为单个简单解决方案的唯一情况。 
2. 找到两个不同的点。 如果不存在，则返回 YES，以该单点为中心且距离为零。 
3. 尝试找到不共线的三个点。 使用向量的叉积来检测共线性，因为如果三个点形成的三角形的符号面积为零，则它们位于一条直线上。 
4. 如果不存在这样的三元组，则所有点共线但不相同，因此不存在有效的圆心。 返回编号
 5. 使用标准垂直平分线交集公式计算第一个非共线三元组的外心。 这给出了穿过这三个点的唯一圆心。 
6. 计算该中心到任一输入点的距离； 这成为候选半径。 
7. 验证所有点：重新计算它们到中心的距离并确保所有值在数值公差范围内匹配$10^{-6}$。 如果出现任何偏差，则拒绝。 

### 为什么它有效

 圆是由三个不共线的点唯一确定的。 如果所有点都存在有效解，则三个非共线点的任何子集都必须位于同一个圆上，因此必须共享相同的外心。 构建步骤会找到唯一的候选者。 验证步骤确保没有其他点违反约束，从而排除意外对齐或简并配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def circumcenter(ax, ay, bx, by, cx, cy):
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-18:
        return None

    ax2ay2 = ax * ax + ay * ay
    bx2by2 = bx * bx + by * by
    cx2cy2 = cx * cx + cy * cy

    ux = (ax2ay2 * (by - cy) + bx2by2 * (cy - ay) + cx2cy2 * (ay - by)) / d
    uy = (ax2ay2 * (cx - bx) + bx2by2 * (ax - cx) + cx2cy2 * (bx - ax)) / d
    return ux, uy

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]

if n == 1:
    x, y = pts[0]
    print("YES")
    print(f"{x:.6f} {y:.6f} 0.000000")
    sys.exit()

all_same = all(p == pts[0] for p in pts)
if all_same:
    x, y = pts[0]
    print("YES")
    print(f"{x:.6f} {y:.6f} 0.000000")
    sys.exit()

x0, y0 = pts[0]
x1, y1 = None, None
for x, y in pts:
    if x != x0 or y != y0:
        x1, y1 = x, y
        break

if n == 2:
    cx = (x0 + x1) / 2
    cy = (y0 + y1) / 2
    d = ((x0 - cx) ** 2 + (y0 - cy) ** 2) ** 0.5
    print("YES")
    print(f"{cx:.6f} {cy:.6f} {d:.6f}")
    sys.exit()

found = False
ax, ay = pts[0]
bx = by = cx = cy = 0

for i in range(1, n):
    for j in range(i + 1, n):
        x2, y2 = pts[i]
        x3, y3 = pts[j]
        cross = (x2 - ax) * (y3 - ay) - (y2 - ay) * (x3 - ax)
        if abs(cross) > 1e-12:
            bx, by = x2, y2
            cx, cy = x3, y3
            found = True
            break
    if found:
        break

if not found:
    print("NO")
    sys.exit()

center = circumcenter(ax, ay, bx, by, cx, cy)
if center is None:
    print("NO")
    sys.exit()

cx0, cy0 = center
dx = pts[0][0] - cx0
dy = pts[0][1] - cy0
d = (dx * dx + dy * dy) ** 0.5

for x, y in pts:
    dx = x - cx0
    dy = y - cy0
    dist = (dx * dx + dy * dy) ** 0.5
    if abs(dist - d) > 1e-6:
        print("NO")
        sys.exit()

print("YES")
print(f"{cx0:.6f} {cy0:.6f} {d:.6f}")
```该代码首先处理点集结构崩溃的退化情况。 单个点或相同点立即产生零半径解。 对于两个点，选择中点，因为它保证到两个端点的距离相等。 

核心部分寻找非退化三角形。 叉积测试确保我们不会尝试从共线点计算外心，这在数值上不稳定并且在几何上无效。 一旦找到有效的三元组，外心公式就会计算唯一的中心。 

最后，该解决方案根据计算的半径验证所有点。 此步骤至关重要，因为它可以防止在仅点子集存在有效圆的情况下出现误报。

 ## 边缘情况

 当所有点都位于一条直线上但又不相同时，就会发生微妙的故障情况。 例如，(0,0)、(1,0)、(2,0)。 该算法搜索非共线三元组但未能找到，从而触发 NO 输出。 这是正确的，因为没有有限圆可以通过三个不同的共线点。 

另一种重要的情况是，除了一个异常值形成有效圆之外，多个点都相同。 从有效三元组计算出的外心确保中心仍然正确，并且验证步骤捕获由异常值引入的不一致。 

最后的边缘情况是当点非常接近共线时浮点不稳定。 叉积阈值可防止选择不稳定的三元组，并且最终的距离检查与公差可确保小的数值漂移不会导致错误的拒绝。
