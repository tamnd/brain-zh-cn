 ## 解决方案
 ## 问题理解

 我们被要求在整数网格上显式构造一个恰好有六个顶点的凸多边形，使其面积恰好是给定的整数$S$。 我们唯一的自由就是选择坐标； 其他一切，包括凸性、有序性和完整性，都是固定的。 

关键的困难在于我们没有优化或计算任何东西。 我们被迫“设计”一个面积可控且精确的几何形状，同时仍然保持所有顶点整数并确保多边形保持凸形。 

约束条件$S \le 10^9$立即告诉我们，任何构造都必须是线性的，或者每个测试用例的最坏时间都是恒定的。 我们无法搜索或迭代候选多边形。 一切都必须来自封闭形式的几何构造。 

此类任务中的一个微妙陷阱是假设任何整数面积三角形都可以简单地扩展到六边形。 如果我们任意插入额外的点而不保留凸性或不确保它们位于边缘上，我们很容易破坏多边形结构。 另一种故障模式是尝试将面积分布在多个组件上并意外引入自相交，即使面积计算仍然匹配，这也会使凸性无效。 

因此，真正的挑战是构造一个凸六边形，其面积易于计算并且可以精确调整为$S$，同时确保所有六个顶点仍然是格点。 

## 方法

 一个天真的想法是直接搜索形成面积凸多边形的六个整数点$S$。 这是没有希望的，因为坐标范围内候选六元组的数量是天文数字，即使检查每个候选的凸性和面积也会超出任何时间限制。 

更结构化的想法是从面积可控的已知形状开始，例如三角形，然后将其转换为六边形。 困难在于，添加顶点通常会改变形状，除非添加的点恰好位于现有边上。 

这一观察导致了关键的简化：如果我们构造一个具有整数面积的凸三角形$S$，那么我们可以通过插入额外的共线点来安全地细分其边缘。 这些点不会改变多边形的几何形状或面积，但它们会增加顶点数量，同时保留凸度。 这正是我们所需要的：一种将三角形“膨胀”为六边形而不修改其面积的方法。 

剩下的任务是确保三角形的边上有足够的整数格点，以便我们可以放置三个额外的不同顶点。 

因此，我们构建一个直角三角形，其顶点选择为使两条边轴对齐。 这保证了这些边上有许多整数点，从而可以轻松选择额外的顶点。 

三角形定义为：$$A(0,0), \quad B(S,0), \quad C(0,2)$$其面积为：$$\frac{S \cdot 2}{2} = S$$现在我们通过沿边插入整数点来将这个三角形丰富为六边形：

 - 开$AB$，我们可以插入多个点，例如$(1,0), (2,0)$- 在$CA$，我们可以插入$(0,1)$- 边缘$BC$保持不变

 所有插入点都位于三角形边缘上，因此保留了凸性并且面积保持不变。 

这恰好产生了六个不同的顶点。

 ## 算法演练

 ### 关键思想

 我们构造一个具有精确面积的三角形$S$，然后通过用格点分割边将其转换为六边形。 

### 步骤

 1. 固定三个点形成直角三角形：$$A(0,0), \quad B(S,0), \quad C(0,2)$$这确保了该区域准确无误$S$。 
2. 列出边上所有整数点$AB$。 由于它是水平的，因此所有点$(x,0)$对于整数$x \in [0,S]$躺在上面。 
3. 选择两个中间点$AB$， 例如：$$P_1(1,0), \quad P_2(2,0)$$这些将成为额外的顶点。 
4. 选择边缘上的一个整数点$CA$，它是垂直的：$$P_3(0,1)$$5. 按顺序沿三角形边界行走构建多边形：$$(0,0) \to (1,0) \to (2,0) \to (S,0) \to (0,2) \to (0,1)$$6. 按顺序输出这六个点。 生成的多边形是凸多边形，因为所有插入点都位于凸三角形的边界边缘上，因此不会引入新的转弯。 

### 为什么它有效

 不变量是每个添加的点都位于凸三角形的边界段上。 凸多边形在边细分下仍然是凸的，因为边细分不会改变多边形的支撑线或引入超过的新角度$180^\circ$。 该区域被保留，因为我们没有改变几何区域，只是细化其边界表示。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

S = int(input().strip())

# Triangle vertices
A = (0, 0)
B = (S, 0)
C = (0, 2)

# Subdivide edges to get 6 vertices
P1 = (1, 0)
P2 = (2, 0)
P3 = (0, 1)

# Construct convex boundary walk
points = [
    A,
    P1,
    P2,
    B,
    C,
    P3
]

for x, y in points:
    print(x, y)
```前三个点位于三角形的底边，保留了一条直的水平线段。 重点$(S,0)$关闭底座。 然后我们移动到$(0,2)$，顶部顶点，最后插入$(0,1)$在隐式返回起点之前在垂直边缘上。 此顺序遵循三角形边界的顺时针遍历。 

一个微妙的实现细节是排序必须遵循边界，而不仅仅是所选点的顺序。 这些点的任何排列都可能存在自相交或凸排序不正确的风险。

 ## 边缘情况

 对于非常小的值$S$，该构造仍然可以正确运行，因为三角形仍然有效并且所有添加的点都位于有效的边线段内。 例如，当$S = 3$，三角形变为$(0,0),(3,0),(0,2)$，以及插入的点$(1,0),(2,0),(0,1)$沿着边界保持清晰和有序。 凸结构没有改变，因为没有引入新的转角，只是边缘细化。
