 ## 解决方案
 ## 问题理解

 我们被要求为一组学生构建多个座位计划，其中每个计划都是学生座位的完整分配。 每个计划本质上是从 1 到 n 的数字排列，因为每张桌子必须仅使用一次，并且每个学生必须恰好占用一张桌子。 

在 m 种不同的考试中，我们必须生成 m 种不同的排列。 还有一个额外的限制，即不允许学生在连续两次考试中坐在同一张桌子上，这意味着对于每个 i，位置 i 的值在连续排列之间必须不同。 

因此，任务是构造长度为 n 的 m 个排列，使得每个排列都是 {1, ..., n} 上的双射，连续排列在每个位置都不同，并且所有排列都是成对不同的。 

约束 n、m ≤ 1000 意味着 O(nm) 构造是可行的，但涉及排列的阶乘或指数枚举的任何操作都是不可能的。 关键的困难不是生成排列，而是确保在“连续天之间没有固定位置”的约束下存在足够的排列。 

当 m 相对于 n 较大时，会出现微妙的故障情况。 对于较小的 n，根本没有足够的排列可以避免在至少一个位置上匹配先前的排列。 例如，当 n = 4 且 m = 30 时，强力排列或循环简单移位将不可避免地重复或违反邻接约束。 

一种幼稚的方法可能会尝试贪婪地生成排列，同时检查所有先前的排列。 这样做会失败，因为它变得太慢，而且因为缺乏全局结构，即使存在有效的构造，它也会过早陷入困境。 

## 方法

 一个蛮力的想法是逐个生成排列，对于每个新排列，尝试所有可能性，直到我们找到一个在每个位置都与之前的排列不同并且与任何先前的排列都不相同的排列。 每个候选者都需要检查 O(n) 中所有先前的排列，并且可能有 n！ 候选人。 即使将我们限制在系统生成上，搜索空间也太大了，最坏情况的行为也会呈阶乘增长。 

关键的观察是我们实际上并不需要任意排列。 我们只需要一组结构化的排列，其中连续排列随处不同。 具有此属性的自然结构是基本排列的循环移位，但即使循环移位也只能给出 n 个排列，并且它们不允许连续排列之间的任意转换。 

更强大的构造是在排列及其逆排列之间交替，然后应用受控交换来生成其他排列。 核心思想是确保每个新的排列都是通过固定的变换从前一个排列导出的，从而保证每个位置的变化。 

如果我们从排列的角度思考，我们需要一个集合，其中应用固定的排列变换重复生成一个序列。 最简单的这种变换是排列空间中的旋转，但是我们必须确保从一步移动到下一步时没有元素保持固定在其位置。 这导致使用类似混乱的转换，其中我们确保位置 i 映射到所有 i 的下一个排列中的不同值。 

对于 n ≥ 2，我们可以构造一个基本排列，然后重复应用值的循环移位。 这保证了每个元素在下一步中移动到不同的位置。 然而，如果我们继续超过 n 个步骤，我们将返回到原始排列，这意味着我们在一个循环中最多只能获得 n 个不同的有效状态。

因此，可行性取决于是否 m ≤ n。 如果 m > n，我们就无法避免重复或违反约束，因为在单个一致变换下，n 个元素上的任何全循环结构的大小最多为 n。 

当 m ≤ n 时，我们可以使用单个数组的循环移位构造所有所需的排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m · n · n!) | O(m · n · n!) | O(n) | 太慢了 |
 | 循环移位构造| O(m·n) | O(n) | 已接受 |

 ## 算法演练

 1. 从恒等排列 [1, 2, 3, ..., n] 开始。 这代表了第一次考试安排，并满足每个学生坐在独特的桌子上的要求。 
2. 对于接下来的每次检查，通过将前一个排列旋转一个位置来构造下一个排列。 这意味着最后一个元素移到前面，所有其他元素向右移动。 这可以确保每个学生相对于之前的考试更换考台，因为没有位置保留其之前的值。 
3. 重复此过程，直到生成 m 个排列或我们检测到 m 超过 n。 循环性质确保在 n 次移位后，我们返回到原始排列。 
4. 如果 m 大于 n，则输出 IMPOSSIBLE，因为在不违反约束的情况下，循环无法产生超过 n 个不同的有效排列。 
5. 否则，输出所有生成的排列。 

轮换足够的原因是每个元素在下一个排列中都会改变其位置，因此“连续考试中没有同一张桌子”约束会自动满足。 

### 为什么它有效

 每个排列都是通过固定循环移位从前一个排列获得的。 循环移位是连续应用之间没有固定点的双射，这意味着对于每个索引 i，排列 t 中位置 i 的值移动到排列 t+1 中的不同索引。 这保证了邻接约束。 由于变换的阶数为 n，因此所有生成的排列都是不同的，直到循环结束，这恰好在 n 步之后发生。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if m > n:
    print("IMPOSSIBLE")
    sys.exit()

perm = list(range(1, n + 1))

print("POSSIBLE")
for _ in range(m):
    print(*perm)
    perm = [perm[-1]] + perm[:-1]
```该代码首先使用界限 m ≤ n 检查可行性。 如果违反，它会立即打印 IMPOSSIBLE。 否则，它从恒等排列开始并重复应用右旋转。 

旋转步骤是关键操作：将最后一个元素移动到前面可确保确定性转换，其中每个位置都会改变其占用者。 这避免了任何回溯或碰撞检查的需要。 

该循环恰好运行 m 次，生成每个所需的考试配置。

 ## 边缘情况

 对于 n = 1 和 m = 1，该算法输出单个排列 [1]，它基本上满足所有约束，因为没有连续的对违反规则。 

对于 n = 2 和 m = 2，旋转在 [1, 2] 和 [2, 1] 之间交替，并且每次转换都会更改两个位置，从而完全满足约束。 

对于m超过n的情况，例如n = 4、m = 30，算法立即拒绝。 由于大小为 n 的有限循环结构，尝试继续将强制重复先前的排列，这将违反所有日常安排必须不同的要求。 

对于 n = 3 和 m = 1，该算法仅输出恒等排列，该排列是有效的，因为不存在连续比较。
