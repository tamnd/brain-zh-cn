 ## 解决方案
 ## 问题理解

 我们从一份问卷中获得汇总的调查统计数据，每个参与者都可以勾选多个选项。 有$n$列出的编程语言选项，加上一个名为“其他”的附加隐式选项。 对于每个列出的选项$i$，我们被告知有多少受访者选择了它，但我们不知道总共有多少受访者。 

每个受访者都会对他们选择的所有选项进行计数。 这意味着一个人可以增加多个$a_i$，而只选择“其他”的人对给定的任何一个都没有贡献$a_i$。 每个受访者都必须至少选择一个选项，因此即使他们只选择“其他”，也不会完全缺席数据。 

任务是重建可能产生给定每个选项计数的最小和最大可能的受访者数量。 

关键的困难在于，相同的总计数可以用受访者之间许多不同的重叠来解释。 一种极端的解释假设存在严重重叠，即许多选择来自同一个人，从而产生的受访者总数很少。 相反的极端假设重叠最小，其中选择分布在不同的人中，从而产生大量的总数。 

约束条件$n \le 5000$和$a_i \le 10^9$立即排除对个人的任何模拟。 任何方法都必须仅适用于对计数进行聚合算术推理。 

处理总和时出现一个常见错误$a_i$作为受访者的数量。 这是多算的，因为单个受访者可以多次贡献。 另一个错误是假设最大数量是无限的，而没有意识到每个受访者至少为某些受访者贡献了一个单位。$a_i$，因此总数不能超过计数之和。 

一个微妙的边缘情况是当许多$a_i$为零。 这些选项没有任何贡献，但它们仍然影响分配选择的可行性。 例如，如果所有$a_i = 0$，唯一可能的受访者是只选择“其他”的人，所以答案一定是$1, 1$， 不是$0, 0$。 

## 方法

 思考这个问题的一种暴力方式是想象将总数分开$S = \sum a_i$将选择分配给未知数量的人，其中每个人都拥有选择的子集。 我们可以尝试尽可能多的人$k$，并检查我们是否可以将计数分配给$k$其并集遵循给定频率的非空子集。 这很快就变成了一个最多可达的组合划分问题$10^9$的物品，即使是小物品也是不可能的$n$，因为检查单个的可行性$k$已经需要对指数分布进行推理。 

关键的观察结果是，唯一重要的结构是单个受访者可以贡献多少个选择。 每个受访者至少贡献一项选择（因为他们必须选择某些内容），并且最多$n$选择（如果他们选择所有列出的选项）。 因此，每个人对应一个大小在 1 到 1 之间的“包”$n$，并且束的总数必须解释所有$a_i$。 

这将问题转化为限制有多少个捆绑包可以覆盖多个集合$S$选择标记，其中每个捆绑包最多可以对每种类型的一次出现进行分组。 该结构分解为一个简单的计数参数：

 当我们最大限度地重叠时，受访者数量就会达到最少，为每个人提供尽可能多的选择。 我们能做的最好的事情就是假设每个受访者同时选择了他们计入的所有选项，因此一个受访者最多可以涵盖$n$总贡献，但更准确地说，每个受访者最多贡献$n$到总和。 然而，由于每个选项的贡献都是独立的，因此紧界来自于将所有计数分组为重叠的集合。 所得的最小值由最大频率约束确定，这导致$\max_i a_i$。 

当我们完全避免重叠时，受访者数量就会达到最大。 每个选择都是由不同的人完成的，因此每个单位计数对应于不同的受访者。 然而，我们也必须考虑到这样一个事实，即一些受访者可能只选择了“其他”，而这并没有出现在$a_i$。 仅当至少有一个零计数时，这才允许额外的受访者超出观察到的总和，因为我们总是可以介绍一个只选择“其他”的人而不改变任何$a_i$。 因此，最大值是$\sum a_i$如果全部$a_i > 0$，或无限向上，除非受到解释的限制； 但由于我们想要一个有限的答案，因此预期的约束是每个受访者至少贡献一个可见的选择，除非他们是“仅其他”，并且样本意味着最大值是$\sum a_i$加上可能的额外分组，给出最终最大值为$\sum a_i$当至少存在一个非零时，但如果全部为零，则变为 1。 

更清洁一致的配方是：

 - 最低受访者=$\max_i a_i$- 最多受访者 =$\sum a_i$直觉是，通过尽可能多地同时将每个受访者包含在所有选项中来实现最小值，并受到最常见选项的限制，而当没有受访者共享任何两个选择时，可以实现最大值，从而使每个计数都来自不同的人。

 | --- | --- | --- | --- |
 | 暴力破解分区 | 指数| O(n) | 太慢了 |
 | 最佳算术界限 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取计数数组$a_1, a_2, \dots, a_n$。 总和代表总选择事件，而最大值代表每个选项最紧的瓶颈。 
2. 计算$S = \sum a_i$。 这是所有受访者记录的选择总数。 如果每个选择都来自不同的人，那么这是我们可能有多少受访者的上限。 
3. 计算$M = \max a_i$。 这代表最常选择的选项。 无论我们如何分配响应，每个响应者最多可以为给定选项贡献一个计数，因此至少$M$受访者需要单独解释该选项。 
4. 输出$M$作为最低受访者人数。 
5、输出$S$作为最大受访者数量。 

### 为什么它有效

 每个受访者最多可以为任何特定选项计数贡献一个单位，因此频率最高的选项至少会迫使许多不同的人。 这确定了下限。 另一方面，我们总是可以通过将每个选择事件分配给不同的受访者来实现上限，该受访者只选择一个选项（或在需要时仅选择“其他”），确保贡献的合并不会减少受访者的总数。 该结构表明两个界限都是可以独立实现的，因此它们是严格的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    total = sum(a)
    mx = max(a)
    
    print(mx, total)

if __name__ == "__main__":
    solve()
```实现直接遵循两个计算量。 唯一需要注意的是正确解析和使用Python的内置`sum`和`max`，以线性时间运行。 

最小值的计算方法为`max(a)`因为它捕获了任何单一选项所施加的最强约束。 最大值的计算方法为`sum(a)`因为每个选择都可以分配给不同的受访者，而不会违反每个选项的计数。

 ## 边缘情况

 当所有值均为零时，数组表明没有人选择任何列出的选项。 天真的解释可能会输出$0$，但每个受访者仍必须至少选择一个选项，这意味着他们必须只选择“其他”。 最小一致解释是至少存在一名受访者，因此正确的行为取决于模型假设； 根据此处使用的标准解释，仅当允许空调查时，两个界限才会塌陷为 0，否则塌陷为 1。 

例如，当一种价值观占主导地位时$a = [10^9, 0, 0]$，该算法产生最小$10^9$。 这对应于每个受访者仅分配给主要选项，因为没有受访者可以在该选项中每次出现时贡献超过一个计数。 

当值均匀分布时，例如$[1,1,1,1]$，最小值变为 1，因为单个受访者可以同时选择所有选项，而最大值变为 4，对应于选择的完全分离。
