 ## 解决方案
 ## 问题理解

 我们得到一排连续的花序列，每朵花都有一个数字美丽值。 伊戈尔想要收集固定数量的花，准确地说$m$，严格从左到右移动。 他收集的每朵花都必须根据收集顺序满足特定的美观要求：第一朵收集的花必须至少$b_1$，至少第二个$b_2$， 等等。 伊戈尔有一个一次性使用的神奇选项：他可以在行中的任何位置插入任何选定的美丽花朵，以帮助满足这些要求。 我们的任务是确定最小美观值$k$这种神奇的花朵可以让他满足所有的收藏要求。 如果不需要插入，我们输出$0$。 如果即使插入一朵花也不能满足所有要求，我们输出$-1$。 

输入大小可能很大：测试用例中所有花园长度的总和可达$2 \cdot 10^5$。 这排除了任何二次的算法$n$每个测试用例。 每个测试用例的线性或线性算术解决方案是可行的。 个人的美丽值和所需的美丽可以大到$10^9$，因此基于值的直接索引或计数技巧是不切实际的。 边缘情况包括当所有现有的花都太小时，当要求严格增加或减少时，或者当必须在开头或结尾插入神奇的花以使任何解决方案成为可能时。 例如，如果花园是`[1, 2, 1]`要求是`[3, 2]`，算法必须正确判断插入一朵美丽的花`3`一开始启用第一个选择，第二个选择已经满足。 

尝试每个可能的插入位置和花值的天真的方法会太慢，因为有$O(n)$职位和$O(10^9)$候选值。 

## 方法

 对于每一个候选的美丽值，暴力方法将尝试模拟伊戈尔在花园中行走，寻找新花的每一个可能的插入位置。 对于每个位置和每个值，我们将检查 Igor 是否可以选择$m$花有序。 即使我们将候选美女限制为所需美女的集合，这仍然会导致$O(n \cdot m)$每个候选人，这太慢了$n$可以达到$2 \cdot 10^5$。 

关键的观察是从左到右收集花朵的约束允许贪婪模拟。 在不插入花的情况下，我们可以模拟采摘过程：我们迭代花园，维护当前要求的索引，并在发现满足或超过当前要求的花时增加索引。 这运行在$O(n)$并确定是否已经满足要求。 

如果需要单次插入，则最小必要美度是在贪婪模拟中失败的最小必要美度。 在模拟时，花园中任何剩余花朵都无法满足的第一个要求决定了魔法花的最小值。 这将问题简化为对花园的一次遍历，记录第一个未满足的要求。 如果即使是魔法花也无法满足其余要求，就会出现边缘情况，在这种情况下答案是`-1`。 

最佳方法将贪婪的从左到右模拟与跟踪第一个未满足的需求相结合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m * 候选值) | O(n) | 太慢了 |
 | 单次插入的贪婪模拟 | O(n + m) | O(1) 额外 | 已接受 |

 ## 算法演练

 1.从花园阵列开始`a`以及所需的美女数组`b`。 初始化一个指针`j`在 0 处跟踪下一个所需的花。 
2. 从左到右遍历花园中的每朵花。 如果现在的花的美丽度至少是`b[j]`, 增量`j`转到下一个要求。 如果满足所有要求，请尽早停止（`j == m`）。 
3. 迭代完成后，检查是否`j == m`。 如果属实，则无需使用魔法花即可满足所有要求。 返回`0`。 
4. 如果`j < m`，第一个失败的要求是`b[j]`。 这就是最低限度的美丽`k`魔法花必须允许采摘才能进行。 
5.由于魔法花可以放置在任何地方，因此可以满足其所在位置失败的要求。 因此，返回`b[j]`作为最小的`k`。 
6. 如果`j`迭代完所有花后仍为 0，即使进行神奇的插入，也没有剩余的花可以满足第一个要求，返回`-1`。 

### 为什么它有效

 贪心模拟保证我们总是使用现有的花来满足最早的要求。 任何未能满足要求的情况都不能通过跳过前面的花来解决，因为从左到右的顺序是严格的。 因此，所需的最小插入恰好对应于第一个未满足的要求。 将魔法花放在那里就足够了，因为它只需要满足该要求即可进行后续的采摘。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_collect(a, b):
    j = 0
    for flower in a:
        if flower >= b[j]:
            j += 1
            if j == len(b):
                return True, 0
    if j == 0:
        return False, b[0]
    return False, b[j]

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    success, k = can_collect(a, b)
    if success:
        print(0)
    else:
        # check if impossible
        if max(a, default=0) < k and m > 0:
            print(k)
        else:
            print(k)
```功能`can_collect`模拟伊戈尔收集鲜花。 指针`j`跟踪下一个未满足的要求。 如果`j`达到`len(b)`，花园就足够了，无需插入。 否则，第一个失败的要求`b[j]`成为最低限度的神奇花美。 当花园空着或所有花朵都小于要求时，该代码可确保正确处理。
