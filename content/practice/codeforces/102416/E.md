 ## 解决方案
 ## 问题理解

 我们有多达 100 个球形保护区。 星舰 (i) 的中心为 ((x_i,y_i,z_i)) 和半径 (r_i)。 我们必须选择一些星舰，使其原始球体的内部不会重叠。 相切是允许的，因为两个球体的中心之间的距离恰好是其半径之和，因此被认为是不相交的。 

选择一艘星舰后，其职责从半径（r_i）扩展到半径（3r_i）。 展开的球体可以自由重叠。 它们的结合必须覆盖至少一个原始球体所覆盖的每一点。 

输出是星舰索引的任何有效子集。 一个`NO`语句允许答案，但实际上几何形状为我们提供了每个输入的构造，因此算法永远不需要打印`NO`。 

约束 (n\le100) 使得 (O(n^2)) 解在一秒内变得微不足道。 坐标和半径最多为 (10^4)，因此平方距离最多约为 (3\cdot10^8)，并且涉及半径平方的表达式也在 Python 整数和普通 64 位整数内安全。 我们仍然应该比较距离的平方而不是计算平方根，因为比较只需要整数运算。 

微妙的部分是脱节和覆盖之间的相互作用。 如果集合是以任意顺序构建的，则仅选择不相交球体的最大集合是不够的。 考虑一个半径为 (1) 的小球体与一个半径为 (100) 的大球体相交。 如果先选择小球体，则可能会阻止选择大球体，而小球体三倍扩展的区域远不足以覆盖大球体。 

例如，考虑```
2
0 0 0 1
100 0 0 100
```这两个球体相切，因此两者都可以选择，并且正确答案可以包含两者。 危险的情况是稍微重叠：```
2
0 0 0 1
99 0 0 100
```半径 1 的球体和半径 100 的球体重叠，因为 (99<101)。 如果我们先选择小球体，那么我们就会丢弃大球体。 它的扩展半径只有(3)，显然无法覆盖原来的大球体。 首先处理最大半径可以避免这种错误。 

相切是另一种边界情况。 为了```
2
0 0 0 1
2 0 0 1
```中心之间的距离为(2=r_1+r_2)，因此两个球体都可以选择。 粗心的实现使用`<=`当决定两个领域是否冲突时，会错误地拒绝第二个领域。 

相同的球体提供了另一种有用的边缘情况：```
2
5 5 5 7
5 5 5 7
```它们的距离为零，因此只能选择一个。 无论选择哪一个，都会有一个半径为 (21) 的扩展球体，覆盖两个原始球体。 错误地处理半径顺序中的相等不会破坏证明，但将重合球体视为不相交会产生无效答案。 

## 方法

 直接的暴力策略是枚举 (n) 艘星舰的每个子集并测试它是否是有效的选择。 有 (2^n) 个子集。 即使我们使用更强的条件，即每个原始球体必须包含在一艘选定星舰的三倍膨胀球体中，检查一个候选子集也需要 (O(n^2)) 时间：我们可以将每个原始球体与每个选定球体进行比较。 在 (n=100) 时，这给出 (O(2^{100}n^2))，在最坏情况下大约为 (1.3\cdot10^{34}) 对检查。 那是完全不可行的。 

蛮力的想法之所以有效，是因为问题实际上要求我们在原始球体的交图中找到一个独立的集合，同时保留扩展后的覆盖范围。 障碍在于一般的最大独立集问题是指数的。 

关键的几何观察是我们不需要最大独立集。 我们只需要任何一个独立的集合，其扩展的范围涵盖了一切。 从最大半径到最小半径处理球体，并在与所有先前保留的球体不相交时贪婪地保留球体。 

假设球体 (i) 被拒绝。 它与一些已选择的球体 (j) 相交。 由于我们按半径递减顺序处理，(r_j\ge r_i)。 交集给出

 [
 d(c_i,c_j)<r_i+r_j。 
]

 取球体 (i) 内的任意点 (p)。 它到 (j) 中心的距离最多为

 [
 d(c_j,p)\le d(c_j,c_i)+r_i
 <r_j+2r_i
 \le3r_j。 
]

 因此，球体 (i) 的每个点都位于先前选择的球体 (j) 的半径 (3r_j) 球体内部。 

这就是通过减小半径进行加工的全部原因。 被拒绝的球体始终不大于导致其被拒绝的球体，这将重叠不等式变为所需的因子三。 

暴力搜索会尝试所有可能的子集，因为它无法识别安全的选择。 半径排序准确地为我们提供了该信息：每当球体被拒绝时，先前选择的球体都保证足够大，使其三倍膨胀完全覆盖被拒绝的球体。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(2^n n^2)) | (O(n)) | (O(n)) | 太慢了|
 | 通过减小半径贪心| (O(n^2)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 读取所有球体并保留其原始索引。 按半径递减对它们进行排序。 相等半径可以按任何确定性顺序处理，因为证明只需要 (r_j\ge r_i)。 
2. 维护选定球体的列表。 最初它是空的。 考虑球体 (i) 时，将其中心与每个已选择的球体 (j) 进行比较。 
3. 当两个球体的中心距离至少为 (r_i+r_j) 时，两个球体恰好不相交。 通过比较避免平方根

 [
 d^2\ge(r_i+r_j)^2。 
]

 如果这适用于每个选定的球体，请将 (i) 添加到答案中。 允许相等，因为相切球体被认为是不相交的。 

1. 如果球体 (i) 与任何选定的球体相交，则拒绝它。 由于所选球体已提前处理，因此相交球体的半径至少为 (r_i)。 
2. 处理完所有球体后，输出选定的索引。 构造总是会产生有效的答案，所以`NO`永远不会达到。 

### 为什么它有效

 不变的是，在处理半径排序顺序的任何前缀之后，所有选定的球体都是成对不相交的，并且来自该前缀的每个被拒绝的球体完全被某些选定球体的三倍扩展区域覆盖。 

仅当球体与先前选择的每个球体不相交时，成对不相交才直接从接受球体得出。 对于覆盖范围，考虑拒绝的球体 (i) 并令 (j) 为与其相交的选定球体。 由于 (j) 已较早处理，因此 (r_j\ge r_i)。 对于 (i) 内的任意点 (p)，

 [
 d(c_j,p)
 \le d(c_j,c_i)+d(c_i,p)
 < (r_i+r_j)+r_i
 = r_j+2r_i
 \le3r_j。 
]

 因此 (i) 的每个点都属于 (j) 的扩展球体。 选定的球体会覆盖自身，因为它们的扩展半径大于其原始半径。 因此，每个原始保护点仍然受到保护。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    spheres = []

    for idx in range(1, n + 1):
        x, y, z, r = map(int, input().split())
        spheres.append((x, y, z, r, idx))

    # Larger spheres must be considered first.
    spheres.sort(key=lambda s: (-s[3], s[4]))

    selected = []

    for x, y, z, r, idx in spheres:
        disjoint = True

        for j in selected:
            x2, y2, z2, r2, _ = j

            dx = x - x2
            dy = y - y2
            dz = z - z2

            dist2 = dx * dx + dy * dy + dz * dz
            limit = r + r2

            # Tangency is allowed, so equality means disjoint.
            if dist2 < limit * limit:
                disjoint = False
                break

        if disjoint:
            selected.append((x, y, z, r, idx))

    print(len(selected))
    print(*[s[4] for s in selected])

if __name__ == "__main__":
    solve()
```输入循环将坐标、半径和原始索引存储在一起。 原始索引是必要的，因为输出是根据星舰在输入中的位置来引用星舰，而不是根据排序后的位置来引用星舰。 

排序键使用`-r`，因此较大的半径优先。 第二个组成部分，即原始索引，仅使等半径处理具有确定性。 该证明适用于相等半径中的任一阶。 

对于每个候选球体，内部循环仅检查已选择的球体。 如果其中一个具有重叠的内部，则该候选者将被拒绝。 该比较使用平方距离，因此不涉及浮点运算。 

严格比较`dist2 < limit * limit`是必不可少的。 什么时候`dist2 == limit * limit`，球体相切，并且问题明确允许选择两者。 使用`<=`会错误地拒绝切线球体。 

Python 整数具有任意精度，因此不存在溢出问题。 即使在固定宽度 64 位算术中，给定的边界也会使这些平方值轻松落在范围内。 

输出始终包含至少一个球体，因为排序顺序中的第一个球体没有任何冲突。 更一般地说，校样表明所选集始终满足覆盖条件，因此打印`NO`是不必要的。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(n^2)) | 在最坏的情况下，将每个球体与之前选择的每个球体进行比较 |

 ## 边缘情况

 与另一个球体相切的球体不得视为相交。 为了```
2
0 0 0 1
2 0 0 1
```选择第一个球体。 第二个具有平方中心距 (4)，而半径的平方和也是 (4)。 拒绝的条件是严格不平等，因此也选择第二个球体。 最终扩展的区域覆盖了两个原始球体。 

重合或重叠的球体的处理方式不同。 为了```
2
5 5 5 7
5 5 5 7
```中心距的平方为 (0)，半径和的平方为 (196)。 第二个球体被拒绝。 由于两个球体相同，因此第一个选定的球体的扩展半径为 (21)，它覆盖了两个原始半径为 7 的区域。 

最重要的排序边缘情况是一个小球体与一个大得多的球体重叠：```
2
0 0 0 1
3 0 0 2
```首先考虑并选择半径为 2 的球体。 那么半径为 1 的球体将被拒绝，因为中心距 (3) 小于 (2+1=3)？ 这里的等式实际上意味着球体相切，因此也被选中。 要证明严格重叠，请改用```
2
0 0 0 1
2 0 0 2
```现在中心距为(2<3)，因此小球体被拒绝。 对于那个小球体中的任何点，它到大球体中心的距离最多为 (2+1=3)，正好是扩展半径 (3\cdot2=6)，并且有大量的空闲空间。 大球体的膨胀将其完全覆盖。 

最后，即使存在多个其他选定的球体，也可能会因为一个选定的球体而拒绝球体。 该算法不需要识别最佳覆盖球体。 第一个相交的选定球体就足够了，因为半径排序保证了该球体至少与被拒绝的球体一样大。 这一事实提供了三倍覆盖率证明，也是贪婪构造在没有任何回溯的情况下仍然有效的原因。
