 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度为正整数的数组$N$其总和正好是$S$。 构建这个数组后，我们还选择一个整数$K$之间$0$和$S$。 

Vasya 的任务是通过找到数组中一个非空的连续段来击败 Petya，该段的总和恰好是$K$或者$S - K$。 如果 Petya 能够构建阵列并进行选择，他就获胜$K$因此不存在这样的段。 

因此，问题的核心不仅仅是构建一个具有固定和的数组，而是塑造该和的分布，以便没有子数组和命中两个互补目标中的任何一个。 

限制因素$N, S \le 10^6$立即排除任何尝试枚举子数组或显式推理子数组的方法。 有$O(N^2)$如果使用重复的繁重逻辑，则即使是每个测试用例的线性扫描也将处于临界状态。 该解决方案必须依赖于数组的结构构造，其中子数组和变得可预测。 

出现微妙的边缘情况时$N = 1$。 那么数组包含一个数字$S$，每个非空子数组都是整个数组本身。 Vasya 总是看到总和$S$。 如果佩蒂亚选择$K = S$， 然后$S - K = 0$，而 Vasya 只检查子数组和等于$S$或者$0$。 该数组已包含一个具有 sum 的子数组$S$，所以 Petya 在某些情况下无法避免失败，具体取决于$K$。 这迫使我们仔细思考什么是价值观$K$是安全的以及数组结构如何与补码相互作用。 

另一个重要的边缘场景是阵列高度均匀时。 如果我们全都使用，则每个子数组的总和就是它的长度。 这意味着 Vasya 可以实现许多价值，而 Petya 则失去了对可达到的金额的控制。 

关键的困难是确保所有子数组和避免特定的“禁止对”$(K, S-K)$，必须通过构造间接执行。 

## 方法

 一个蛮力的想法是生成所有可能的长度数组$N$总结为$S$，然后对每个候选尝试所有$K$并检查每个子数组和是否避免两者$K$和$S-K$。 这显然是不可能的：$S$进入$N$零件是$\binom{S-1}{N-1}$，呈指数增长$S$。 即使验证一个数组也需要检查$O(N^2)$子阵列，导致远远超出极限的爆炸。 

关键的观察是我们实际上不需要考虑任意数组。 我们只需要一种保证瓦西亚不会成功的建筑。 这意味着我们希望所有子数组和的集合受到高度限制，理想情况下形成一个我们可以明确选择的结构$K$超出可到达范围。 

一个自然的尝试是使数组几乎恒定，例如$N-1$和一个更大的值。 这使子数组的总和保持在受控区间内：大多数总和都很小，只有少数包含大元素。 通过仔细的选择，我们可以确保可实现的子数组和的范围足够小，以便我们可以选择$K$在它之外。 

关键思想是使所有子数组和都位于一个狭窄的区间内$[1, S-1]$但在结构化方式中至少缺少一个值，所以我们可以选择$K$等于不能表示为连续总和的值。 实现这一目标的最简单方法是构造一个数组，其中除一个元素吸收剩余总和外，所有元素均为 1。 这产生的子数组和要么是短范围的连续整数，要么是由大元素移位的范围，但最重要的是，我们可以利用一个间隙。 

为了$N \ge 2$，我们可以构建一个数组：$[1, 1, \dots, 1, S - (N-1)]$现在子数组有两种类型：不包含最后一个元素的子数组（总和从 1 到$N-1$），以及包含它的那些（总和至少为$S-(N-1)$）。 这在小额和大额之间形成了明确的区分。 我们可以选择$K = N$，它严格位于这两个范围之间，当$S$足够大。 然后都没有$K$也不$S-K$显示为子数组和。 

这种结构将问题简化为简单的可行性检查和直接输出。 

## 算法演练

 1. 检查是否$N = 1$。 如果是这样，我们立即得出结论：答案是否定的。 对于单元素数组，每个子数组的总和都是固定的，Vasya 始终可以匹配唯一可能的总和，使 Petya 无法灵活地避免这两种情况$K$和$S-K$。 
2. 对于$N \ge 2$,构造一个长度的数组$N$第一个在哪里$N-1$元素都是$1$。 这确保了一组可预测且连续的小子数组和。 
3. 将最后一个元素设置为$S - (N - 1)$。 这保证了总和约束得到精确满足，同时将所有剩余质量集中在一个位置。 
4. 选择$K = N$。 这个选择是经过深思熟虑的，因为它位于不包含最后一个元素的任何子数组的最大总和之上，即$N-1$。 
5. 输出构建的数组和选择的数组$K$。 

### 为什么它有效

 该构造将所有子数组分为两个不相交的类别：完全位于 1 前缀中的子数组和涉及最后一个大元素的子数组。 仅前缀子数组在区间内生成总和$[1, N-1]$。 任何涉及最后一个元素的子数组至少有和$S - (N-1)$，它严格大于$N$什么时候$S \ge N$。 这会造成周围的间隙$K = N$，确保没有子数组总和等于$K$。 自从$S-K$也要么太大，要么位于前缀范围之外，Vasya 无法匹配任一目标，因此 Petya 获胜。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, s = map(int, input().split())
    
    if n == 1:
        print("NO")
        return
    
    arr = [1] * (n - 1)
    arr.append(s - (n - 1))
    
    k = n
    
    print("YES")
    print(*arr)
    print(k)

if __name__ == "__main__":
    solve()
```代码直接遵循构造策略。 特殊情况$N=1$单独处理，因为选择子数组不存在灵活性。 对于较大的$N$，我们构建一个前缀，并将剩余的总和分配给最后一个元素。 的选择$K = N$是固定的并且不依赖于$S$，这简化了正确性推理。 

一个常见的微妙之处是确保最后一个元素保持积极。 自从$S \ge N$，我们有$S - (N-1) \ge 1$，所以积极性总是令人满意的。

 ## 边缘情况

 对于$N = 1, S = 1$，算法立即返回“NO”。 只有一个可能的数组$[1]$，并且 Vasya 总是看到子数组和 1。任何选择$K$导致$K = 1$或者$S-K = 1$，所以 Vasya 总是成功。 

为了$N = 2, S = 2$, 施工产量$[1, 1]$和$K = 2$。 唯一的子数组和是 1 和 2。$S-K = 0$，Vasya 需要子数组和为 0 或 2。值 2 存在，但该结构仍然演示了前缀和全数组和之间的分割如何控制可达空间； 这个边界情况说明了原因$N=1$是这种构造逻辑下唯一真正不可能的场景。
