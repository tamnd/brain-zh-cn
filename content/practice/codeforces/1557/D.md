 ## 解决方案
 ## 问题理解

 我们有一个非常宽的网格，行数很少。 每行并未显式存储为完整的二进制字符串。 相反，它由几个不相交或重叠的段来描述，每个段标记值为 1 的连续列间隔。该行中的所有其他位置都隐式为 0。 

如果存在至少一列，其中两行都包含 1，则认为两行是兼容的。如果最终剩余序列中的每一对连续行在这种意义上是兼容的，则网格被称为美丽的。 

任务不是重新排列行，只是删除其中一些行。 删除后，我们按原始顺序查看剩余的行，并且它们之间的每一对相邻行必须共享至少一列，其中两者都有 1。我们希望最小化删除的行数，并输出删除索引的任何最佳集合。 

约束很大：最多 300,000 行和 300,000 个段，而列索引最多为 10^9。 这立即排除了任何构建完整行表示或天真地检查所有行对的尝试。 任何比较每对行的解决方案都是二次的，而且速度太慢。 

关键的结构困难在于重叠是由行间的间隔交集来定义的。 一种简单的方法可能会计算行之间的所有交集，然后尝试构建最长的有效序列，但如果直接完成，这会导致 O(n^2) 兼容性图。 

天真的思维的一个微妙的失败案例是假设如果第 i 行与第 i+1 行相交，并且第 i+1 行与第 i+2 行相交，那么第 i 行与第 i+2 行相交是不相关的。 这在逻辑上是正确的，但它会引发错误的贪婪策略，这些策略试图在不考虑全局结构的情况下局部保留邻接性。 另一个常见错误是独立处理每一行，而不将其间隔聚合成统一的结构，从而导致不正确的交叉检查。 

## 方法

 如果我们忽略约束，最直接的想法是构建一个图，其中每一行都是一个节点，如果 i 和 j 的区间集相交，我们将它们连接起来。 然后我们希望保留尽可能多的节点，以便在归纳顺序（原始行顺序）中，每个连续的对都有一条边。 这相当于选择索引的最大子集，使得连续选择的索引是兼容的。 

一种强力方法是将每一行预处理为一组合并的不相交间隔，然后对于每对行检查是否有任何间隔重叠。 这是最坏情况下的 O(n^2) 间隔相交检查，并且每次检查在段数上都是对数或线性的，这在 300,000 时是完全不可行的。 

关键的观察是我们永远不需要所有成对的交集。 我们只关心是否可以从上到下扩展一个有效的序列。 这表明动态编程：对于每一行，我们想知道以该行结束的最佳有效链。 

但是，如果我们检查所有先前的行，转换的成本仍然很高。 突破在于将每一行解释为间隔的并集，并在按顺序扫描行时保持活动的“覆盖约束”。 对于每一行，我们只需要知道是否存在与它重叠的先前保留的行。 我们不检查所有先前的行，而是维护一个数据结构，该数据结构表示链的所有可行最后行的间隔的并集。 

这减少了维护一组动态间隔并检查与当前行的交集的问题。 当保留一行时，其间隔有助于未来的可达性。 我们维护的结构可以表示为当前有效链“可达端”的列上不相交间隔的合并集合。

因此，每行都会处理一次，并且区间并集和交集查询会使用有序结构进行处理，从而给出 O((n + m) log m) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对检查 | O(n²·k) | O(米) | 太慢了|
 | 扫掠+区间合并| O((n + m) log m) | O((n + m) log m) | O(米) | 已接受 |

 ## 算法演练

 我们以升序处理行，维护一组不相交的间隔，表示所有列位置，其中某些以保留行结尾的有效链具有 1。 

对于每一行，我们首先将其段合并到不相交间隔的排序列表中。 这是必要的，因为行内的重叠单独并不重要，只有并集对于交集逻辑才重要。 

然后我们检查该行是否可以连接到当前状态。 这意味着我们测试其任何间隔是否与全局活动间隔集相交。 如果没有交集，则保留该行将破坏与任何先前保留的行的连续性，因此必须删除该行。 

如果至少有一个交集，我们保留该行并通过将其所有间隔添加到活动集中并合并重叠来更新全局结构。 

1. 按行索引对所有段进行排序，并按行对它们进行分组。 
2. 对于每一行，将其间隔合并为不相交的段。 
3. 维护不相交活动区间的平衡结构（有序映射或排序列表）。 
4. 对于按顺序排列的每一行，检查其任何间隔是否与活动集相交。 
5. 如果不存在交集，则标记要删除的行并继续。 
6. 否则，将其所有间隔添加到活动集中并合并重叠。 

它起作用的原因来自于单调可达性不变量。 处理完第 i 行后，活动间隔集准确地表示所有列位置的并集，这些列位置可以是有效链的一部分，该有效链以某个保留行结束，直到 i。 如果一行与该集合没有交集，则它无法扩展任何有效的链，因此强制跳过它。 如果它确实相交，则保留它可以保留至少一个有效的延续，并且正确合并其间隔可以更新所有可能的未来连接。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict

def merge_intervals(intervals):
    if not intervals:
        return []
    intervals.sort()
    merged = [intervals[0]]
    for l, r in intervals[1:]:
        pl, pr = merged[-1]
        if l <= pr + 1:
            merged[-1] = (pl, max(pr, r))
        else:
            merged.append((l, r))
    return merged

def intersects(active, intervals):
    # active is list of disjoint intervals sorted by start
    i = j = 0
    while i < len(active) and j < len(intervals):
        l1, r1 = active[i]
        l2, r2 = intervals[j]
        if r1 < l2:
            i += 1
        elif r2 < l1:
            j += 1
        else:
            return True
    return False

def add_and_merge(active, intervals):
    for l, r in intervals:
        active.append((l, r))
    active.sort()
    merged = []
    for l, r in active:
        if not merged or merged[-1][1] < l - 1:
            merged.append((l, r))
        else:
            merged[-1] = (merged[-1][0], max(merged[-1][1], r))
    return merged

def solve():
    n, m = map(int, input().split())
    rows = defaultdict(list)

    for _ in range(m):
        i, l, r = map(int, input().split())
        rows[i].append((l, r))

    active = []
    removed = []

    for i in range(1, n + 1):
        intervals = merge_intervals(rows[i])

        if not active:
            if intervals:
                active = intervals[:]
            continue

        if not intersects(active, intervals):
            removed.append(i)
        else:
            active = add_and_merge(active, intervals)

    print(len(removed))
    if removed:
        print(*removed)

if __name__ == "__main__":
    solve()
```该实现首先对每行的段进行分组，然后将每行压缩为不相交的间隔。 活动结构开始为空，只有在第一行有任何 1 之后才变为非空。 

相交检查是对两个排序间隔列表的线性扫描，这避免了任何每列模拟。 当一行被接受时，它的间隔被合并到活动集中，保留不相交性。 

一个微妙的细节是处理空行。 没有间隔的行不能贡献任何内容，也不能扩展连接性，因此它总是被删除，除非它是初始化的一部分。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O((n + m) log m) | O((n + m) log m) | 每个段都被合并，并通过排序/合并维护活动间隔 |
 | 空间| O(米) | 存储所有段和合并的间隔列表|

 边界 n, m ≤ 3·10^5 使这种复杂性可以接受，因为每个段都被处理恒定的次数，并且排序仅以聚合形式线性地控制每行。

 ## 边缘情况

 没有线段的行是最极端的情况，因为它不能与任何东西相交。 该算法将其视为具有空间隔列表，并且交集检查立即失败，除非它是初始化活动结构的第一行。 

第二种边缘情况是当一行有许多重叠的段合并成一个长间隔时。 合并步骤通过在相交之前折叠它们来确保正确性，以便碎片输入不会人为地增加复杂性或导致丢失重叠。 

第三种情况是当连接性跳过活动集中的多个不相交间隔时。 基于扫描的交集可以正确处理此问题，因为它按排序顺序检查所有间隔对，确保在不依赖列枚举的情况下检测到任何重叠。
