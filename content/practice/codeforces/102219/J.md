 ## 解决方案
 ## 问题理解

 正好有五个板块，由`A`,`B`,`C`,`D`， 和`E`。 五个输入线中的每一行给出两个板之间的一种关系，例如`A<B`或者`D>B`。 该关系告诉我们两个板块中哪一个较小。 

任务是找到所有五个盘子从小到大的排序，以满足每个给定的比较。 如果多个排序满足所有比较，则任何一个都是有效的。 如果比较相互矛盾，则不存在有效的排序，我们将打印`impossible`。 

输入大小故意很小。 总是有五个顶点和五个比较边，因此即使是检查每个可能排序的算法也只有`5! = 120`候选人。 这意味着阶乘搜索对于实际问题是完全安全的。 更有趣的算法解释是将比较视为有向图并执行拓扑排序。 由于该图只有五个顶点和五个边，因此这里需要恒定的时间，并且如果问题推广到更多的板，则缩放效果也会更好。 

粗心的实施可能会以多种方式失败。 首先，矛盾可能形成循环。 例如，```
A<B
B<C
C<A
D<E
A<D
```没有答案，因为前三个关系要求`A<B<C<A`。 仅记录本地比较而不检查全局一致性的方法仍然可以打印排序。 

其次，一块板可以有多个指向它的约束。 例如，```
A<B
C<B
D<B
E<B
A<C
```需要`A<C<B`， 尽管`D`和`E`可以出现在之前`B`相对于另一个不受约束的板的任一位置。 正确的算法必须在放置板之前考虑所有传入的约束，而不是独立处理每个比较。 

第三，多余的比较不应造成麻烦。 例如，```
A<B
B<C
A<C
D<E
A<D
```包含`A<C`即使它已经暗示了`A<B<C`。 正确的拓扑排序只保留两条边。 它不需要区分直接约束和其他约束的后果。 

## 方法

 最直接的解决办法就是暴力破解。 生成全部`5! = 120`的排列`A`,`B`,`C`,`D`， 和`E`。 对于每个排列，计算每个板的位置并检查所有五个比较。 满足每个关系的第一个排列是有效答案。 如果 120 个排列全部失败，则约束条件是矛盾的。 

这种方法是正确的，因为五个不同板的每种可能的排序在排列中只出现一次。 如果存在有效的顺序，暴力最终会检查它。 如果没有一个排列满足所有五种关系，则不存在有效的排序。 

对于这个问题，暴力破解一点也不慢。 在最坏的情况下它最多执行`120 * 5 = 600`关系检查，加上生成排列的小开销。 因此，一秒钟的时间限制是非常慷慨的。 不止于此的原因是约束的结构为我们提供了更通用的解决方案。 

关键的观察是每个比较都可以变成有向边。 如果`A<B`， 然后`A`必须出现在之前`B`，所以我们添加一条边`A -> B`。 如果`A>B`，我们改为添加`B -> A`。 我们现在需要对顶点进行排序，其中每个边都从较早的顶点指向较晚的顶点。 这正是有向图的拓扑排序。 

当有向图没有有向环时，它恰好具有拓扑排序。 卡恩的算法为我们提供了我们需要的两部分。 它重复选择入度为零的顶点，将其放置在答案中的下一个，并删除其出边。 如果删除所有五个顶点，则所得序列满足每次比较。 如果在删除所有顶点之前过程卡住，则剩余顶点属于或依赖于一个循环，因此约束是不可能的。 

蛮力法之所以有效，是因为只有 120 种可能的排列方式，但随着盘子数量的增加，它会变成阶乘。 通过比较形成有向无环图，我们可以用线性时间图算法代替枚举。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(5! * 5)`|`O(5)`| 已接受此问题 |
 | 拓扑排序|`O(V + E)`|`O(V + E)`| 已接受 |

 这里`V=5`和`E=5`，因此最佳方法实际上是给定输入的恒定时间。 

## 算法演练

 1. 创建一个有向图，每个板有一个顶点。 对于每次比较，将边缘从较小的板定向到较大的板。 例如，`D>B`变成`B -> D`。 方向代表每个有效答案必须遵循的顺序。 
2. 计算每个板的入度。 入度告诉我们当前需要有多少个板块在该板块之前。 入度为零的板没有未解决的前驱板，因此可以安全地放置下一个。 
3. 将每个零度数板放入队列中。 可能有多个这样的板，因为输入不一定确定唯一的顺序。 其中任何选择都是有效的。 
4. 重复从队列中删除一个车牌并将其附加到答案中。 对于从该板到另一个板的每条边，将目标的入度减一。 如果该入度变为零，则将目的地添加到队列中。 移除出边表示将当前板固定在其位置并满足其约束。 
5. 处理队列后，检查有多少车牌添加到答案中。 如果所有五个都已处理，则答案是有效的排序顺序。 如果处理的数量少于 5 个，则该图包含一个循环，并且比较是矛盾的，因此打印`impossible`。 

关键的不变量是，在所有先前选择的板被移除后，放入答案中的每个板的入度为零。 因此，指向该板的每个约束都已得到满足，因此将其放置在下一个不会违反输入比较。 如果算法处理每个板，则每个边缘从较早选择的板到较晚选择的板。 如果它无法处理每个板，则循环会阻止至少一个剩余板达到入度零，从而证明不存在有效的排序。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    graph = [[] for _ in range(5)]
    indegree = [0] * 5

    for _ in range(5):
        s = input().strip()
        a = ord(s[0]) - ord('A')
        b = ord(s[2]) - ord('A')

        if s[1] == '<':
            u, v = a, b
        else:
            u, v = b, a

        graph[u].append(v)
        indegree[v] += 1

    q = deque()

    for v in range(5):
        if indegree[v] == 0:
            q.append(v)

    order = []

    while q:
        u = q.popleft()
        order.append(u)

        for v in graph[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                q.append(v)

    if len(order) != 5:
        print("impossible")
        return

    print(''.join(chr(v + ord('A')) for v in order))

if __name__ == "__main__":
    solve()
```该图使用索引`0`通过`4`为了`A`通过`E`。 将字符转换为整数使邻接表和入度数组变得简单。 

对于每个输入关系，较小的板被分配给`u`和更大的盘子`v`，给予边缘`u -> v`。 对于诸如这样的关系`A>B`，代码反转字符并存储`B -> A`， 因为`B`在尺寸递增的订购中必须先到。 

初始队列包含入度为零的每个顶点。 这些正是目前不需要在另一个板块之后出现的板块。 然后该算法遵循卡恩的拓扑排序过程。 

最终长度检查至关重要。 队列变空并不自动意味着答案已完成。 如果存在循环，则该循环中的所有顶点都保留正入度，因此队列可能为空，而某些板仍处于未处理状态。 比较`len(order)`和`5`准确地捕捉到了这种情况。 

Python 中不存在整数溢出问题，也不存在有意义的边界问题，因为顶点和边的数量是固定的。 输入恰好包含五个比较，因此读取约束的循环必须恰好执行五次。 

## 工作示例

 对于示例 1，比较变为以下有向边：`B -> D`,`D -> A`,`E -> C`,`B -> A`， 和`C -> B`。 

初始入度为`A=2`,`B=1`,`C=1`,`D=1`， 和`E=0`。 仅有的`E`可以先选择。 

| 步骤前排队| 已选择 | 移除后的度数 | 回答 |
 | ---| ---| ---| ---|
 |`E`|`E`|`A=2, B=1, C=0, D=1, E=0`|`E`|
 |`C`|`C`|`A=2, B=0, C=0, D=1, E=0`|`EC`|
 |`B`|`B`|`A=1, B=0, C=0, D=0, E=0`|`ECB`|
 |`A,D`|`A`|`D=0`|`ECBA`|
 |`D`|`D`| 全部处理完|`ECBAD`|

 确切的顺序可以取决于零入度顶点的排队顺序。 样本输出是`ECBDA`，而上面的轨迹给出了`ECBAD`，这也是有效的，因为两者`A`和`D`在适当的点变得可用，并且约束只需要`D<A`。 如果我们选择`D`前`A`，我们获得样品订购`ECBDA`。 

对于示例 2，前三个关系形成一个循环：`B -> E`,`E -> A`， 和`A -> B`。 

剩下的比较是`C -> B`和`D -> B`。 

| 步骤前排队| 已选择 | 剩余相关度 | 回答 |
 | ---| ---| ---| ---|
 |`C, D`|`C`|`B=3`|`C`|
 |`D`|`D`|`B=2`|`CD`|
 | 空 | 无 |`A=1, B=2, E=1`|`CD`|

 后`C`和`D`被删除，三个顶点`A`,`B`， 和`E`仍然形成一个循环。 它们中没有一个可以达到零入度，因此队列变空，仅处理了五个板中的两个。 算法打印`impossible`。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(V + E)`| 每块板均处理一次，并且每个比较边缘均检查一次。 |
 | 空间|`O(V + E)`| 邻接表、入度数组、队列和答案仅包含五个顶点和五个边。 |

 对于这个问题，`V=5`和`E=5`，因此该算法仅执行恒定数量的操作。 它远低于一秒的时间限制，并且与 256 MB 限制相比，使用的内存可以忽略不计。 更重要的是，如果固定数量的板被更大的图表取代，那么相同的实现将保持高效。

 ## 边缘情况

 直接矛盾是用一个循环来表示的，而不一定是用具有相反关系的两个相同的板来表示。 考虑：```
A<B
B<C
C<A
D<E
A<D
```该图包含`A -> B -> C -> A`。 最初，`D`也许可以处理其他顶点，但最终循环顶点仍保持正入度。 由于无法选择任何一个，因此输入答案的顶点少于五个，并且算法会打印`impossible`。 仅检查每个单独比较是否有效的方法可能会忽略这种全局矛盾。 

当一个板有多个前任板时，会出现第二种边缘情况：```
A<B
C<B
D<B
E<B
A<C
```这里`A`必须先于`C`，并且两者都必须先于`B`。 另外两个板块也必须先于`B`，但它们的相对位置并未完全受到约束。 卡恩算法会等待所有传入的边到达`B`在选择之前已将其删除。 这正是入度所代表的意思，所以`B`永远不会意外地出现得太早。 

冗余比较也需要保留，而不是被视为拒绝输入的原因。 例如：```
A<B
B<C
A<C
D<E
A<D
```关系`A<C`已经暗示了`A<B<C`，但它仍然是有效边。 什么时候`A`处理后，两个出边都会被独立移除。 的入度为`C`仅在其两个传入边都被考虑后才达到零。 无论冗余信息如何，结果订单都是有效的。 

最后，固定输入大小本身就是一个边界条件。 总是有正好五个顶点和正好五个比较，因此没有空图，也没有需要处理的一板情况。 该实现精确读取五行并检查五个顶点，匹配问题的固定边界，而不会引入不必要的一般情况机制。
