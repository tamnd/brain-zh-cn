 ## 解决方案
 ## 问题理解

 我们有一个（N \times N）方格。 每个单元格包含一个点（代表空白区域）或四个箭头之一：`>`,`<`,`^`， 和`v`。 旋转会改变单元格的位置和每个箭头指向的方向。 

输入给出网格和左右旋转的序列。 我们需要在按给定顺序应用每次旋转后打印网格。 由于网格是正方形的，因此每向同一方向旋转四次，网格就会恢复到原来的方向。 

网格最多可包含 (1000 \times 1000 = 10^6) 个单元格。 读取或写入网格已经需要 (O(N^2)) 工作，因此比 (O(N^2)) 差得多的算法是不可取的。 旋转序列的长度最多为 100，这意味着每次旋转重复扫描整个网格可能需要最多 (100 × 10^6 = 10^8) 个单元操作。 对于 Python 中的 1 秒限制来说，这已经很大了，特别是因为每个操作都涉及索引和构建另一个网格。 

主要的边缘情况是轮换位置是不够的。 箭头本身必须旋转。 例如，与```
1 R
>
```正确的结果是```
v
```因为向右旋转会使向右的箭头向下。 仅将角色移动到新坐标的解决方案将错误地离开`>`不变。 

另一个容易犯的错误是方向映射向后。 对于右旋转，周期为`>`到`v`,`v`到`<`,`<`到`^`， 和`^`到`>`。 对于左旋转，循环沿相反方向进行。 例如，```
1 L
>
```必须产生```
^
```第三种边缘情况是旋转取消的序列。 为了```
2 LR
>.
..
```第一次旋转是顺时针，第二次是逆时针旋转，所以最终的网格与原始网格完全相同：```
>.
..
```一个粗心的实现，只计算旋转次数，而不考虑它们的方向，可能会导致这样的序列错误。 

最后，同一方向的四次旋转没有净效果。 例如，```
1 RRRR
<
```产生`<`再次。 这种周期性是减少工作量的关键。 

## 方法

 最直接的解决方案是模拟每次旋转。 对于当前网格中的每个字符，我们计算其新位置和新箭头方向，然后将其放入新的（N \times N）网格中。 顺时针旋转将行 (r)、列 (c) 处的单元格映射到行 (c)、列 (N-1-r)。 逆时针旋转将其映射到行 (N-1-c)、列 (r)。 相应的箭头同时旋转。 

这种强力方法是正确的，因为每个单独的变换都与一个物理旋转完全匹配。 问题在于重复工作量。 如果 (N=1000) 并且旋转字符串的长度为 100，则我们可以为每次 100 次旋转处理 (10^6) 个单元格，从而给出 (10^8) 个单元格变换。 网格只有一百万个单元，因此基本上没有必要对其进行一百次完整的遍历。 

有用的观察是旋转仅组成四个可能的方向。 右旋转为 (+1)，而左旋转为 (-1)，模 4。我们可以首先处理整个旋转字符串并计算 0 到 3 范围内的一个值 (k)。该值告诉我们最终网格是否应保持不变、向右旋转一次、旋转 180 度或向左旋转一次。 

例如，序列`RRL`具有净旋转（1+1-1=1），因此相当于单次右旋转。 顺序`LRRLL`具有净旋转（-1+1+1-1-1=-1），因此相当于左旋转一圈。 

一旦净旋转已知，我们只需扫描网格一次并直接构建最终方向。 蛮力之所以有效，是因为每个单独的旋转都很容易模拟，但当一遍又一遍地处理相同的数百万个单元时，就会失败。 平方旋转的周期性使我们可以用四种变换之一替换整个序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(N^2 \lvert S\rvert)) | (O(N^2 \lvert S\rvert)) | (O(N^2)) | 在最坏的情况下太慢|
 | 最佳| (O(N^2 + \lvert S\rvert)) | (O(N^2 + \lvert S\rvert)) | (O(N^2)) | 已接受 |

 这里（S）是旋转字符串。 

## 算法演练

 1. 读取 (N) 个旋转字符串和 (N) 个网格行。 必须存储网格，因为最终表示可以将每个原始单元格放置在不同的位置。 
2. 启动一个变量`turns`为零。 对于每一个`R`，添加一个，并且对于每个`L`，减一。 以 4 为模减少结果。结果值表示在所有旋转组合完成后有关旋转序列的唯一重要信息。 
3.如果`turns == 0`，输出原始网格。 没有单元格需要转换，因为总旋转是 360 度的倍数。 
4. 如果`turns == 1`，直接创建顺时针旋转。 原始细胞`(r, c)`移动到`(c, N - 1 - r)`。 其箭头也变为顺时针旋转的方向。 
5.如果`turns == 2`，将网格旋转 180 度。 原始细胞`(r, c)`移动到`(N - 1 - r, N - 1 - c)`。 每个箭头都会变为相反的方向。 
6. 如果`turns == 3`，将结果视为逆时针旋转一圈。 原始细胞`(r, c)`移动到`(N - 1 - c, r)`，并且箭头逆时针旋转。 
7. 打印结果行。 每个原始单元格都被精确分配了一个目的地，因此生成的网格仍然存在（N \times N）。 

方向变换可以用一个小的查找表来表示。 对于顺时针旋转，`>`变成`v`,`v`变成`<`,`<`变成`^`， 和`^`变成`>`。 每次旋转时该点保持不变。 使用查找表可以避免一长串的特殊情况，并使四个方向的转换变得明确。 

### 为什么它有效

 不变量是在处理旋转字符串的任意前缀后，`turns`精确描述当前网格相对于原始网格的方向，以四个四分之一圈为模。 右旋转贡献 (+1)，左旋转贡献 (-1)，因此添加这些值可以保留实际的组合方向。 

最后，只有四种方向是可能的。 对于这四个方向中的每一个，该算法都使用该旋转的精确坐标变换，并将匹配的方向变换应用于每个箭头。 因此，每个原始单元在所有请求的旋转之后都精确地到达其应有的位置，其方向也与物理旋转相匹配。 因此，输出与一次执行一个旋转相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def rotate_char(ch, turns):
    if ch == '.':
        return '.'

    if turns == 1:
        return {
            '>': 'v',
            'v': '<',
            '<': '^',
            '^': '>'
        }[ch]

    if turns == 2:
        return {
            '>': '<',
            '<': '>',
            '^': 'v',
            'v': '^'
        }[ch]

    if turns == 3:
        return {
            '>': '^',
            '^': '<',
            '<': 'v',
            'v': '>'
        }[ch]

    return ch

def solve():
    n, rotations = input().split()
    n = int(n)

    grid = [input().rstrip('\n') for _ in range(n)]

    turns = 0
    for ch in rotations:
        if ch == 'R':
            turns += 1
        else:
            turns -= 1

    turns %= 4

    if turns == 0:
        sys.stdout.write('\n'.join(grid) + '\n')
        return

    ans = [['.'] * n for _ in range(n)]

    for r in range(n):
        for c in range(n):
            ch = grid[r][c]
            ch = rotate_char(ch, turns)

            if turns == 1:
                nr = c
                nc = n - 1 - r
            elif turns == 2:
                nr = n - 1 - r
                nc = n - 1 - c
            else:
                nr = n - 1 - c
                nc = r

            ans[nr][nc] = ch

    sys.stdout.write('\n'.join(''.join(row) for row in ans) + '\n')

if __name__ == "__main__":
    solve()
```输入被读取`readline`，根据竞争性编程输入的需要。 每行仅删除其换行符，因此点和箭头字符保持不变。 

这`turns`变量将完整的旋转序列压缩为四种状态。 Python 的模运算可以正确处理负值，因此左旋转次数多于右旋转次数的序列仍会生成 0 到 3 之间的值。 

坐标公式是方阵的标准变换。 对于顺时针旋转，`(r, c)`变成`(c, n - 1 - r)`。 对于 180 度，两个坐标都会被反射。 对于逆时针旋转，`(r, c)`变成`(n - 1 - c, r)`。 

答案存储为可变列表列表，因为必须分配各个目标单元格。 原始网格保持不变，这可以防止一个已经旋转的单元格被用作另一变换的源。 

不存在整数溢出问题，因为唯一的算术涉及以 1000 为界的索引。边界表达式`n - 1 - r`也是故意的。 使用`n - r`将产生一个等于`n`什么时候`r`为零，即在网格之外。 

字符转换与单元格的位置无关。 点仍然是点，而每个箭头无论出现在哪里都遵循相同的旋转周期。 

## 工作示例

 ### 示例 1

 输入是：```
3 R
>v>
...
<^<
```旋转序列包含一个`R`，因此顺时针旋转四分之一圈的净次数为 1。 

| r | c | 原创| 目的地`(nr, nc)`| 旋转|
 | ---| ---| ---| ---| ---|
 | 0 | 0 |`>`|`(0, 2)`|`v`|
 | 0 | 1 |`v`|`(1, 2)`|`<`|
 | 0 | 2 |`>`|`(2, 2)`|`v`|
 | 2 | 0 |`<`|`(0, 0)`|`^`|
 | 2 | 1 |`^`|`(1, 0)`|`>`|
 | 2 | 2 |`<`|`(0, 2)`|`^`|

 完整的网格还包含未更改的点和所有其他转换的单元格。 最终结果是：```
^.v
>.<
^.v
```该迹线演示了中心不变量：每个源坐标准确地接收由顺时针矩阵旋转指示的目的地，而其箭头旋转相同的量。 

### 示例 2

 输入是：```
3 L
>v>
...
<^<
```这里的旋转序列包含一个`L`， 所以`turns = -1 mod 4 = 3`。 因此该算法使用逆时针坐标变换。 

| r | c | 原创| 目的地`(nr, nc)`| 旋转|
 | ---| ---| ---| ---| ---|
 | 0 | 0 |`>`|`(2, 0)`|`^`|
 | 0 | 1 |`v`|`(1, 0)`|`>`|
 | 0 | 2 |`>`|`(0, 0)`|`^`|
 | 2 | 0 |`<`|`(2, 2)`|`v`|
 | 2 | 1 |`^`|`(1, 2)`|`<`|
 | 2 | 2 |`<`|`(0, 2)`|`v`|

 最终的网格又是：```
^.v
>.<
^.v
```该示例非常有用，因为它表明顺时针和逆时针变换可能会为对称输入生成相同的最终图像。 该算法仍然可以正确地区分这两个操作。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(N^2 + \lvert S\rvert)) | (O(N^2 + \lvert S\rvert)) | 旋转串被扫描一次，然后每个网格单元被变换一次。 |
 | 空间| (O(N^2)) | 输入网格和输出网格均包含 (N^2) 个单元格。 |

 对于 (N \le 1000)，网格最多包含一百万个单元。 超过一百万个单元的单次传递适合 1 秒的限制，而一亿个转换的强力上限则不必要地昂贵。 对于百万字符网格及其输出表示，内存使用量也轻松低于 256 MB。

## 边缘情况

 对于单单元网格，位置旋转没有明显的效果，因为单元格没有其他地方可以移动。 箭头仍然需要旋转。 和```
1 R
>
```该算法计算`turns = 1`, 地图`(0, 0)`到`(0, 0)`，和变化`>`到`v`，生产```
v
```同样的情况与`L`产生`^`。 这捕获了正确旋转矩阵坐标但忘记旋转内容的实现。 

要取消旋转，请考虑```
2 LR
>.
..
```累加值为(1-1=0)，所以`turns`取模 4 后变为零。算法立即打印原始网格：```
>.
..
```仅执行最终字符映射或计算旋转次数而不考虑其方向的解决方案将在此失败。 

对于四个相同的旋转，考虑```
1 RRRR
<
```累加的值为4，变成0模4。原来`<`打印不变。 这就是旋转序列总是可以压缩为四种状态的原因。 

对称网格可以隐藏坐标错误，因此测试所有单元格都包含相同字符的网格很有用。 和```
2 R
vv
vv
```顺时针旋转每改变一次`v`到`<`，但上面提供的测试使用全等网格，其空间对称性使得位置变换不可见。 字符变换仍然独立地应用于每个单元格，因此对称排列不会导致坐标冲突或遗漏。 

在最大边界处，(N=1000) 给出一百万个单元。 该算法在读取旋转序列后仅执行一次变换，因此其主要工作仍然是 (O(10^6))。 当序列长度为100时，重复旋转实现可以达到(10^8)次变换，这是通过减少序列模四来避免的精确性能问题。
