 ## 解决方案
 ## 问题理解

 每个测试用例使用其宽度描述具有直角的四边形状`w`和身高`h`。 由于每个这样的形状都已经是矩形，所以唯一的问题是它的两个维度是否相等。 A square has the same width and height, while a non-square rectangle has different dimensions.

 For every test case, we print`YES`什么时候`w == h`，因为形状可以是正方形，并且`NO`否则。 

The dimensions are positive integers between`1`和`1,000,000`。 Even at the largest possible values, comparing two integers is a constant-time operation, so the numerical size of`w`和`h`不会造成任何算术困难。 影响运行时间的唯一因素是测试用例的数量，并且解决方案应该处理每个测试用例一次。 执行与面积成正比的工作的解决方案，例如迭代所有`w * h`单位位置，可能需要最多`10^12`一个测试用例的迭代次数，完全不适合 1 秒的限制。 

有一些小情况可能会暴露粗心的实现。 最小尺寸为`1 1`，这必须产生`YES`; 特别处理小尺寸的实现可能会意外地拒绝它。 几乎相等的一对，例如`5 6`必须产生`NO`，因为需要精确相等，而不是近似相等。 尺寸的顺序在几何上并不重要，所以`6 5`还生产`NO`， 尽管`1000000 1000000`产生`YES`。 最后，最大边界处的相等维度仍然完全有效，因此不需要特殊的溢出或边界处理。 

## 方法

 字面上的蛮力方法可以想象从其单位单元构造矩形并检查其几何形状是否形成正方形。 对于一个`w × h`矩形，需要检查最多`w * h`职位。 在最大尺寸下，这变成`1,000,000 × 1,000,000 = 10^12`单个测试用例的单元操作。 该方法在概念上是正确的，因为完整的形状恰好包含`w * h`单位单元，但它通过重建已经直接在二维中编码的信息来解决几何问题。 

关键的观察结果是，正方形的定义恰好满足了我们所需的条件：它的宽度和高度必须相等。 无需检查内部、计算面积、测量对角线或枚举可能的边。 两个输入整数包含所有相关信息，因此一次相等比较就可以完全确定答案。 

蛮力之所以有效，是因为检查整个形状最终会揭示它的两个维度是否匹配，但它失败了，因为它的性能达到`10^12`不必要的操作。 平方等于的观察结果`w == h`将整个测试用例减少为一个恒定时间比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(w × h) | O(1) | O(1) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`T`，因为必须对每种形状做出相同的独立决策。 
2. 对于每个测试用例，读取其宽度`w`和身高`h`。 这两个值完整地描述了我们关心的区别。 
3.比较`w`和`h`。 如果相等则输出`YES`，因为宽度和高度相等正是正方形的定义条件。 
4. 如果不同，则输出`NO`，因为宽度和高度不相等的矩形不可能是正方形。 
5. 继续，直到全部`T`测试用例已经过处理，为每个输入形状生成一个答案。 

### 为什么它有效

 每个处理的测试用例的不变量很简单：输出是`YES`恰好当两个维度相等时。 正方形必须具有相等的宽度和高度，因此相等足以满足所需的分类。 相反，如果尺寸不同，则该形状不能有四个相等的边，并且不是正方形。 由于每个测试用例都是使用这种精确条件进行评估的，因此该算法无法对有效输入进行错误分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    w, h = map(int, input().split())
    print("YES" if w == h else "NO")
```第一行写着`T`，它决定了接下来有多少个独立的测试用例。 循环完全运行`T`次，因此每个形状都会收到一个答案，并且不会处理额外的输入。 

在循环内部，`w`和`h`被解析为整数。 条件表达式直接实现算法：相等产生`YES`，并且不平等产生`NO`。 

没有边界计算、维度循环或数组索引，因此不存在差一问题。 Python 整数也具有任意精度，尽管这里不需要，因为维度最多为`1,000,000`。 使用`sys.stdin.readline`即使有很多测试用例，也能提供高效的输入处理。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(T)| 每个`T`测试用例需要一次比较。 |
 | 空间| O(1) | O(1) | 仅存储当前宽度和高度。 |

 最大尺寸为`1,000,000`对最优解决方案执行的工作量没有影响。 即使`T`如果很大，算法在每个测试用例中仅执行恒定量的工作，这很容易满足 1 秒的时间限制，并且使用的内存可以忽略不计。 

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline
    t = int(input())

    for _ in range(t):
        w, h = map(int, input().split())
        print("YES" if w == h else "NO")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return output

 ## 边缘情况

 可能的最小形状是`1 × 1`。 输入```
1
1 1
```给出`w = 1`和`h = 1`，所以比较`w == h`为 true，输出为`YES`。 假设一个正方形的尺寸必须大于一的粗心实现在这里会失败。 

尺寸仅相差一的矩形仍然不是正方形。 为了```
1
5 6
```该算法比较`5`和`6`，发现它们不相等，并打印`NO`。 不涉及公差，因此尺寸接近的事实不会改变分类。 

两个维度可以以任一顺序出现。 为了```
1
6 5
```比较再次错误，产生`NO`。 该算法不需要对维度进行归一化`min`和`max`，因为平等不受其顺序的影响。 

最后，最大有效尺寸不需要特殊处理。 和```
1
1000000 1000000
```两个值相等，因此算法立即打印`YES`。 和```
1
1000000 999999
```值不同，因此打印`NO`。 由于该解决方案从不乘以维度或执行与其大小成比例的任何操作，因此这些边界情况的工作量与`1 × 1`。
