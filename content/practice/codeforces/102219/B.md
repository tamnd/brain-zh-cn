 ## 解决方案
 ## 问题理解

 每个测试用例使用其宽度描述一个四边形状`w`和身高`h`。 由于所有角都已经是直角，因此将正方形与普通矩形区分开的唯一问题是两条边长是否相等。 

对于特定形状，所需的输出为`YES`什么时候`w == h`，因为宽度和高度相等使矩形成为正方形。 当两个值不同时，输出为`NO`。 

尺寸是介于`1`和`1,000,000`。 上限足够小，单个整数比较是微不足道的，但它也告诉我们没有理由执行几何模拟或枚举可能的边长。 测试用例的数量是独立处理的，因此有用的目标是每个用例的恒定工作量，给出用例数量的线性时间。 即使有很多测试用例，`O(T)`该解决方案仅对每个形状执行一次比较，而对每个形状执行多达一百万次操作的方法在一秒的限制下很快就会变得过于昂贵。 

第一个边缘情况是尽可能小的正方形。 用于输入`1 1`，正确的输出是`YES`。 如果一个粗心的实现检查两个维度是否都大于一，就会错误地拒绝它，即使正方形的边长可以为一。 

另一种边缘情况是尺寸仅相差一个的矩形。 用于输入`7 8`，输出是`NO`。 意外使用条件的代码，例如`abs(w - h) <= 1`会错误地接受这个形状。 平等必须是精确的。 

无论形状是正方形，尺寸的方向都不会改变。 用于输入`3 10`，答案是`NO`，同样如此`10 3`。 除了比较宽度和高度之外，以不同方式处理宽度和高度的解决方案可能会引入不必要的方向依赖性。 

最后，最大值必须正常工作。 用于输入`1000000 1000000`，答案是`YES`。 这些值很适合 Python 整数，因此不需要特殊的数字处理。 

## 方法

 解决该问题的一种蛮力方法是尝试从`1`通过`max(w, h)`并询问该候选者是否可以是该形状的公共边长。 如果候选值的两个维度都相等，则形状为正方形。 如果所有候选人都已筋疲力尽，那就不是了。 

此方法是正确的，因为具有尺寸的正方形`w`和`h`恰好有一个可能的公共边长，即`w = h`。 然而，它可以执行高达`1,000,000`候选人检查单个测试用例。 穿过`T`情况下，最坏情况的工作是`1,000,000T`检查。 当答案已经直接编码在两个输入值中时，该问题并没有提供花费那么多时间的有用理由。 

关键的观察是没有隐藏的几何体需要重建。 当宽度和高度相同时，具有四个直角的四边形正是正方形。 蛮力方法之所以有效，是因为它最终会间接测试相等性，但观察到相等性本身就是完整的条件，让我们可以用一次比较替换多达一百万个检查。 

结果算法读取每一对`(w, h)`，比较两个整数，并打印`YES`如果它们相等并且`NO`否则。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(T * max(w, h))`, 直至`1,000,000T`检查|`O(1)`| 太慢了|
 | 最佳 |`O(T)`|`O(1)`| 已接受 |

 ## 算法演练

 1.读取测试用例数量`T`。 每个测试用例代表一个独立的形状，因此用例之间不需要共享信息。 
2. 对于每个测试用例，请阅读`w`和`h`。 这是确定矩形是否为正方形的两条边长。 
3.比较`w`和`h`。 如果`w == h`，两个维度具有相同的长度，这正是矩形是正方形所需的定义条件。 
4. 打印`YES`当比较为真且`NO`否则。 不需要其他几何计算，因为输入已经保证形状有四个直角。 

### 为什么它有效

 对于每个处理的形状，算法都会检查成为正方形的充分必要条件。 如果`w == h`，矩形具有相等的宽度和高度，因此它是一个正方形，并且算法打印`YES`。 如果`w != h`，它的两条边长不同，所以它不可能是正方形，算法打印`NO`。 由于每个测试用例都是直接根据这个精确条件决定的，因此该算法不会产生错误的分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        w, h = map(int, input().split())

        if w == h:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```第一行读作`t`，它精确控制处理多少对维度。 这与输入格式相匹配，并防止程序意外读取超出测试用例的内容。 

在循环内部，`w`和`h`被解析为整数。 唯一的决定是平等测试`w == h`，直接实现算法演练中正方形的定义属性。 

该代码不需要特殊的边界条件`1`或者`1,000,000`。 两者都是普通的整数值，Python 处理它们时不会溢出。 也不存在相差一的问题，因为该算法不会迭代维度或使用范围。 每个测试用例都需要一次比较和一次输出。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 最小尺寸的正方形是`1 1`。 算法读取`w = 1`和`h = 1`, 评估`1 == 1`为真，并打印`YES`。 边长不要求大于一，因此这正确地接受了可能的最小正方形。 

对于几乎相等的矩形`7 8`，算法评估`7 == 8`作为假和打印`NO`。 基于差异较小的粗心解决方案可能会错误地将其分类为正方形，但正方形需要精确相等，而不是近似相等。 

对于反向尺寸，例如`10 3`，算法评估`10 == 3`作为假和打印`NO`。 同样的结果会发生在`3 10`。 由于正方形条件在宽度和高度上是对称的，因此它们的顺序对分类没有影响。 

对于最大平方`1000000 1000000`，比较结果为 true 并产生`YES`。 为了`1000000 999999`，它评估为 false 并产生`NO`。 这些情况证实了上边界是直接处理的，没有溢出、迭代限制或特殊情况。
