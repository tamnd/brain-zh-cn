 ## 解决方案
 ## 问题理解

 每个测试用例使用其宽度描述具有直角的四边形状`w`和身高`h`。 由于每一个这样的形状都已经是一个矩形，唯一的问题是它是否是一种特殊的、两条边长相等的矩形。 

如果`w == h`，形状是正方形，所以所需的答案是`YES`。 如果两个尺寸不同，则形状是普通矩形，所以答案是`NO`。 

尺寸是介于`1`和`1,000,000`。 这些值本身足够小，可以轻松地放入 Python 整数中，因此不存在溢出问题。 更重要的是，维度的实际大小根本不需要影响算法。 该决定仅取决于一次相等比较，为每个测试用例提供恒定的工作。 即使测试用例的数量很大，对测试用例的线性扫描也是自然的限制，因为必须读取每对维度并进行分类。 

边缘情况很简单，但仍然值得明确处理。 可能的最小正方形是`1 1`，这必须产生`YES`。 检查维度是否大于一的粗心实现可能会错误地拒绝它。 

形状可以具有非常大的尺寸，同时仍然是正方形。 例如，`1000000 1000000`产生`YES`。 即使平等是最重要的，意外使用小的固定界限或特殊对待最大值的实现也会失败。 

尺寸的顺序并不重要。 例如，`3 7`和`7 3`都是矩形并且都产生`NO`。 比较例如`w < h`或者`w > h`单独并不能确定形状是否是正方形，因为任何一种排序都是可能的。 

最后，仅相差一的维度仍必须被拒绝。 为了`5 6`，正确的输出是`NO`。 使用离一条件的实现，例如`abs(w - h) <= 1`会错误地将其分类为正方形。 

## 方法

 强力解决方案可以将矩形想象为单位单元的集合，并在决定它是否是正方形之前检查整个形状。 对于一个`w × h`矩形，这意味着检查`w * h`细胞。 这种方法是正确的，因为尺寸完全决定了矩形网格，因此在处理每个单元格后，我们可以比较结果的宽度和高度。 然而，两个维度都等于`1,000,000`，这正好需要`1,000,000,000,000`一个测试用例的单元检查。 这远远超出了一秒竞赛程序所能达到的效果。 

蛮力之所以有效，是因为它最终处理了描述形状的所有信息，但它失败了，因为几乎所有工作都是无关紧要的。 平方条件不依赖于任何单个单元格。 它直接取决于两条边的长度。 观察到，当矩形的宽度等于高度时，它就是正方形，从而将整个问题简化为一个整数比较。 

对于每个测试用例，请阅读`w`和`h`，比较它们，然后打印`YES`当它们相等并且`NO`否则。 没有尺寸迭代，也没有几何构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个测试用例 O(w × h) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`T`，因为必须对每个形状独立做出相同的决定。 
2. 对于每个测试用例，读取宽度`w`和身高`h`。 
3.比较`w`和`h`。 相等正是长方形成为正方形的数学条件，因此不需要其他几何计算。 
4. 打印`YES`如果`w == h`; 否则打印`NO`。 每个测试用例只产生一个输出行，保留输入形状和答案之间所需的对应关系。 

### 为什么它有效

 该算法依赖于正方形的定义属性：其宽度和高度相等。 对于每个测试用例，如果算法打印`YES`， 然后`w == h`，因此该形状具有相等的边长并且是正方形。 如果打印出来`NO`， 然后`w != h`，所以边长不同，形状不可能是正方形。 这两种情况涵盖了每对可能的正维度，因此算法无法对有效输入进行错误分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        w, h = map(int, input().split())
        print("YES" if w == h else "NO")

if __name__ == "__main__":
    solve()
```第一行读作`t`，它精确控制处理多少对维度。 这避免了依赖文件结束行为并匹配输入格式。 

在循环内部，`map(int, input().split())`将二维直接转换为整数。 Python 整数安全地处理给定的最大值`1,000,000`，因此不需要特殊的数字类型或溢出处理。 

条件表达式执行算法中描述的相同比较。 不存在涉及维度循环的边界情况，因此没有需要管理的相差一条件。 平等比较也处理`1 1`和`1000000 1000000`正确无特殊情况。 

使用`sys.stdin.readline`遵循所要求的快速输入模式。 对于这个特定问题，与大多数竞争性编程任务相比，输入解析已经很小，但当存在许多测试用例时，该方法是合适的。

 ## 边缘情况

 对于最小尺寸形状，输入`1 1`使算法进行比较`1 == 1`，这是真的，所以它打印`YES`。 没有几何原因排除边长为 1 的正方形，并且算法在没有特殊条件的情况下正确接受它。 

对于最大尺寸的正方形，输入`1000000 1000000`还生产`YES`。 无论值的数值大小如何，比较仍然是恒定时间整数运算，因此上限不会造成性能或正确性问题。 

对于相差一的维度，输入`5 6`给出`5 == 6`，这是假的，所以输出是`NO`。 该算法不会将“几乎相等”的维度与相等的维度混淆，从而避免了常见的差一错误。 

对于反转尺寸，`7 3`产生`NO`因为`7 != 3`， 和`3 7`还生产`NO`因为`3 != 7`。 正方形在任一方向上具有相同的尺寸，因此没有理由使用`min`和`max`在比较之前。 

该算法通过相同的不变量处理每个边缘情况，即`YES`当两条边长相同时，将准确打印。 不需要额外的几何计算或特殊情况分支。
