 ## 解决方案
 ## 问题理解

 每个巴士排正好有两个座位。 我们有好几个家庭，还有家人`i`包含`a_i`人们。 

一个人在两种情况之一下会感到快乐。 他们坐在同一家庭成员旁边，或者单独占据一排，另一个座位空着。 

我们必须让每个人都上车，并最大限度地增加快乐的人数。 

限制非常小。 每个家庭人数最多10人，`n`最多 100 个，测试用例最多 1000 个。 甚至一个`O(n)`或者`O(n log n)`解决方案绰绰有余。 挑战不在于性能，而在于找到正确的计数参数。 

一个常见的错误是专注于明确地构建座位安排。 答案可以直接从一些计数中计算出来。 

考虑输入```
1
2 2
3 1
```3 号家庭贡献一对同族和 1 个剩下的人。 我们可以让两人坐在一起，然后剩下的两个人必须共用一排。 正确答案是 2，而不是 3。将每个奇怪的剩余人都视为快乐的贪婪策略会高估。 

另一个棘手的情况是```
1
4 5
1 1 1 1
```根本没有家庭对。 我们有四个人，五排，所以每个人都可以单独坐着。 答案是 4。任何只计算同族对的方法都会错误地返回 0。 

第三种边缘情况是```
1
2 3
3 3
```每个家庭贡献一对和一个剩下的人。 我们得到了两对快乐的人，立即给了 4 个快乐的人。 剩下的两个人必须分享剩下的一排，所以两个人都不高兴。 答案是4。剩下的人不会因为有空位而自动感到高兴。 

## 方法

 暴力解决方案会尝试枚举座位安排并评估有多少人最终感到满意。 即使排数很少，可能的座位分配数量也会呈爆炸式增长。 由于人们可以通过家庭成员来区分，并且行可以以多种方式排列，因此这很快就变得不可行。 

关键的观察是幸福仅来自两种行模式。 

第一个模式是包含同一家族的两个成员的行。 这样的一排创造了两个幸福的人，并且完全使用了一排。 由于两个家庭成员坐在一起总是比分开坐要好，因此应该使用所有可能的同家庭成员。 

对于一个大家庭来说`a_i`，我们可以形成`a_i // 2`这样的对。 对所有家庭求和得出```
pairs = Σ(a_i // 2)
```每对都贡献了两个快乐的人。 

放置完所有这些配对后，每个家庭最多还剩下一个未配对的成员。 让```
odd = Σ(a_i % 2)
```是剩余人数。 

未使用的行数是```
free_rows = r - pairs
```因为每一对家庭占据一整排。 

现在只关注剩下的人。 如果剩下的人独自吵架，他们会很高兴。 如果两个剩下的人坐在一起，谁都不高兴，因为他们来自不同的家庭。 

最初，我们可以将一个剩下的人放入每个空闲行中，从而创建`free_rows`快乐的人。 如果剩余的人多于空闲的行，那么每一个额外的剩余人都必须坐在其中一个快乐的单身人士旁边。 当这种情况发生时，以前幸福的单身人士就会失去幸福。 每多一个人，剩下的人的快乐数就减少一。 

这直接导出最终的计数公式。

 ## 算法演练

 1. 计算`pairs = Σ(a_i // 2)`。 

每对这样的人都可以一起占据一排，并贡献两个快乐的人。 
2. 开始回答`ans = 2 * pairs`。 

这些幸福的人是有保证的。 
3. 计算`odd = Σ(a_i % 2)`。 

这些是在所有可能的同族配对形成后留下的人。 
4. 计算`free_rows = r - pairs`。 

自从`Σ a_i ≤ 2r`，我们总是有`pairs ≤ r`。 
5.如果`odd ≤ free_rows`，每个剩下的人都可以单独坐着。 

添加`odd`到答案。 
6. 否则，在每个空闲行中放置一个剩余的人。 

这给出了`free_rows`最初快乐的人。 

有`odd - free_rows`额外的人仍然没有座位。 他们每个人都必须坐在其中一个单身人士旁边，从而摧毁一个以前幸福的人。 

快乐的剩菜数量变成```
free_rows - (odd - free_rows)
= 2 * free_rows - odd
```将该值添加到答案中。 

### 为什么它有效

 每个包含两个人的幸福行必须包含同一家庭的成员。 将一对可能的家庭分成不同的行永远不会增加幸福感，因为最好的选择是让他们中的最多一个人作为单身人士幸福。 因此，使用所有可用的家庭对始终是最佳选择。 

当所有配对都用完后，剩下的每个家庭最多贡献一个人。 无法创建额外的同系对。 让这些人变得快乐的唯一方法就是独自坐着。 每个空闲行最多可以支持一个快乐的单身人士。 每当第二个剩下的人被插入到这一行中时，就会失去一个快乐的人。 上式精确地计算了该效应，证明了算法的最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, r = map(int, input().split())
    a = list(map(int, input().split()))

    pairs = sum(x // 2 for x in a)
    odd = sum(x % 2 for x in a)

    ans = 2 * pairs
    free_rows = r - pairs

    if odd <= free_rows:
        ans += odd
    else:
        ans += 2 * free_rows - odd

    print(ans)
```第一个循环计算可以形成多少个同族对。 每对这样的人都会立即贡献出两个快乐的人。 

第二个计数跟踪还有多少未配对的人。 这些人是唯一幸福尚未确定的人。`free_rows`是尚未被家庭对占据的行数。 最后一个分支处理两种可能的情况。 要么每个剩下的人都有自己的行，要么剩下的人比可用的行多，并且一些单身人士必须配对在一起。 

对于大值不需要特殊处理，因为所有数字都很小。 表达式`2 * free_rows - odd`在有效状态下永远不会为负，因为公交车上的总人数。

 ## 边缘情况

 考虑```
1
2 2
3 1
```我们有`pairs = 1`,`odd = 2`， 和`free_rows = 1`。 

该算法开始于`ans = 2`。 自从`odd > free_rows`，它添加了`2 * 1 - 2 = 0`。 最终答案是2。一个剩下的人最初可以独自坐着，但第二个剩下的人必须加入这一排并消除单身幸福。 结果是正确的。 

考虑```
1
4 5
1 1 1 1
```我们有`pairs = 0`,`odd = 4`， 和`free_rows = 5`。 

自从`odd <= free_rows`，每个人可以单独占据一排。 该算法返回 4。这可以正确处理根本没有家庭对的情况。 

考虑```
1
2 3
3 3
```我们有`pairs = 2`,`odd = 2`， 和`free_rows = 1`。 

该算法计算```
ans = 2 * 2 = 4
happy leftovers = 2 * 1 - 2 = 0
```最终答案为 4。剩下的两个人不可能都高兴，因为只剩下一排，所以他们必须坐在一起。 计数与最佳座位安排完全匹配。
