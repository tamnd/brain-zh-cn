 ## 解决方案
 ## 问题理解

 我们被要求计算用已经预先分配的某些单元格填充整数网格的方法数量，以使网格“美丽”。 如果对于由四个角定义的任何矩形，角值的异或等于零，则网格是漂亮的。 此条件相当于说沿行和列的 XOR 模式必须满足线性约束：每个单元格由其行和列标签最多为常数的 XOR 确定。 

输入给出了多个测试用例。 对于每个测试用例，我们从部分填充的网格开始$n \times m$和$k$预先指定的值。 然后我们执行$q$更新，每次更新都会为之前未填充的单元格分配一个值。 每次分配后，我们必须报告网格模数的有效完成次数$10^9 + 7$。 更新是累积的。 

限制条件很高：$n$和$m$可以达到$10^5$每个，并且最多可以有$10^5$填充单元格和更新。 尝试迭代所有可能完成的简单方法是不可能的，因为未填充单元格的数量很容易超过$10^5$，每个单元格的搜索空间可达$2^{30}$。 Therefore, we need an approach that operates in roughly linear time with respect to the number of filled or updated cells.

 A subtle aspect is the XOR condition itself. For a small grid, it is easy to verify by brute force. 例如，在一个$2 \times 2$三个角填充为的网格`0, 1, 1`，最后一个单元格被迫`0`满足异或规则。 任何忽略这一点的算法都会过多计算完成次数。 当给定值矛盾时会出现另一种边缘情况。 例如，如果左上角的单元格是`0`，右上角是`1`，左下角是`1`，右下角是`1`，没有有效的完成，因此正确的计数为零。 算法必须有效地检测不一致之处。 

## 方法

 暴力方法会迭代所有未填充的单元格并尝试从 0 到$2^{30}-1$同时检查所有矩形约束。 这是正确的，但完全不可行。 高达$10^5$未填充的单元格，这将涉及$2^{30 \times 10^5}$可能性，显然不可能。 即使尝试通过枚举矩形天真地解决 XOR 约束也需要$O(n^2 m^2)$超过时间限制的操作。 

关键的观察结果是，XOR 条件导致了一个线性系统$\text{GF}(2)$对于每一位独立。 我们可以将每个单元格的值建模为行和列变量的总和，$A_{i,j} = R_i \oplus C_j$， 在哪里$R_i$和$C_j$是代表行的 XOR 贡献的未知数$i$和列$j$。 每个填充的单元格给出一个线性方程$R_i$和$C_j$。 这减少了在插入新方程的情况下维护线性 XOR 方程组的问题。 

由于每个位都是独立的，因此我们对系统求解 30 次，每个位一次。 每个系统都是稀疏的：每个方程恰好包含两个变量。 这种结构允许我们将问题表示为一侧为行，另一侧为列的二部图，如果存在方程则连接一条边$R_i \oplus C_j = value$。 每个连接分量的自由变量数量为 0 或 1，具体取决于我们是否检测到矛盾。 解的总数为$2^{\text{number of free variables}}$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^{nm})$|$O(nm)$| 太慢了 |
 | 最优（线性代数+DSU）|$O((n+m+q) \cdot 30)$|$O(n+m)$| 已接受 |

 ## 算法演练

 1. 将网格表示为具有行节点的二部图$R_i$和列节点$C_j$。 每个填充的单元格$(i,j)$定义一个方程$R_i \oplus C_j = value$对于整数值的每一位。 单独对待每一位。 
2. 为每个连接的组件维护一个具有奇偶校验的不相交集并集 (DSU)。 每个节点（行或列）都属于一个组件，奇偶校验跟踪从节点到组件根的路径的异或。 
3. 对于每个填充单元或更新，对于从 0 到 29 的每个位，将边缘添加到具有给定奇偶校验的 DSU。 如果两个节点已经连接，请检查奇偶校验是否一致。 如果不是，则将系统标记为无法解决。 
4. 插入状态的所有边后，计算至少有一个未分配变量的连接分量的数量。 每个这样的组件都贡献一个自由变量。 解的总数为$2^{\text{number of free variables}}$模数$10^9 + 7$。 
5.输出初始状态后和每次更新后的结果。 

工作原理：具有奇偶校验的 DSU 在每个连接的组件内维护 XOR 约束。 如果出现矛盾，则无法进行分配。 每个组件可以独立自由地选择一个变量，所有其他变量由路径奇偶性决定。 增量处理每个更新可确保我们始终了解当前的解决方案数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.rank = [0]*n
        self.xor = [0]*n
        self.size = [1]*n
        self.bad = [False]*n
    
    def find(self, x):
        if self.p[x] != x:
            orig = self.p[x]
            self.p[x] = self.find(self.p[x])
            self.xor[x] ^= self.xor[orig]
        return self.p[x]
    
    def union(self, x, y, val):
        xr, yr = self.find(x), self.find(y)
        px = self.xor[x]
        py = self.xor[y]
        if xr == yr:
            if (px ^ py) != val:
                self.bad[xr] = True
            return
        if self.rank[xr] < self.rank[yr]:
            xr, yr = yr, xr
        self.p[yr] = xr
        self.xor[yr] = px ^ py ^ val
        self.bad[xr] |= self.bad[yr]
        if self.rank[xr] == self.rank[yr]:
            self.rank[xr] += 1

def solve_case(n, m, k, q, cells, updates):
    total = n + m
    dsu_bits = [DSU(total) for _ in range(30)]
    answers = []

    def add_cell(r, c, val):
        for b in range(30):
            bit = (val >> b) & 1
            dsu_bits[b].union(r, n + c, bit)

    for r, c, v in cells:
        add_cell(r-1, c-1, v)

    def count_solutions():
        res = 1
        for dsu in dsu_bits:
            free = 0
            seen = set()
            valid = True
            for i in range(total):
                root = dsu.find(i)
                if dsu.bad[root]:
                    valid = False
                    break
                if root not in seen:
                    seen.add(root)
                    free += 1
            if not valid:
                return 0
            res = res * pow(2, free - len(seen), MOD) % MOD
        return res

    answers.append(count_solutions())

    for r, c, v in updates:
        add_cell(r-1, c-1, v)
        answers.append(count_solutions())
    return answers

def main():
    t = int(input())
    for _ in range(t):
        n, m, k, q = map(int, input().split())
        cells = [tuple(map(int, input().split())) for _ in range(k)]
        updates = [tuple(map(int, input().split())) for _ in range(q)]
        ans = solve_case(n, m, k, q, cells, updates)
        for a in ans:
            print(a)

if __name__ == "__main__":
    main()
```该解决方案实现了具有奇偶校验的 DSU，以有效处理 XOR 约束。 30 位整数的每一位都被单独处理。 每个连接的组件代表一组具有约束的变量。 并集操作更新奇偶校验并标记矛盾。 计算解决方案涉及计算每个组件中自由变量的数量。 仔细处理根奇偶校验可确保正确性。
