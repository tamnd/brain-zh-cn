 ## 问题理解

 每只羊都以整数健康值开始。 我们得到了一组将以统一随机顺序应用的操作：一些“治疗”法术和一些“伤害”法术。 

治疗咒语会将每个正值向上移动一步，将每个负值向下移动一步，而零则保持不变。 伤害法术则相反，将正值推低 1，将负值推高 1，再次保持零不变。 关键是每个法术同时作用于所有羊，所以对一只羊来说唯一重要的是它当前的符号和大小，而不是它在数组中的位置。 

随机性来自于均匀地洗牌所有法术并按顺序应用它们。 我们被要求提供所有法术应用后每只羊的预期最终价值。 

限制允许最多 300,000 只羊和最多 100,000 个法术。 这立即排除了模拟排列或跟踪所有状态的分布。 即使维持每只羊的价值的完整概率分布也会爆炸，因为价值可能会在很大的整数范围内漂移，而价值和剩余操作的朴素 DP 会太慢。 

一个微妙的问题是与零的相互作用。 一旦一个值达到零，后续操作不会立即以对称方式将其推过符号； 它成为一个反射点，只有一侧的操作会影响它。 如果忽略这一边界行为，则关于增量和减量的朴素线性假设就会失败。 

一个小例子是一只羊，从 1 开始，有一次治疗和一次伤害。 如果首先发生治疗，则该值变为 2，然后 1。如果首先发生伤害，则该值变为 0，然后 0。结果差异很大，因此顺序很重要，并且简单地对计数进行平均是不正确的。 

## 方法

 暴力方法将枚举 x + y 咒语的所有排列并模拟每只羊的过程。 每次模拟花费O(x + y)，总共有(x + y)！ 排列，即使对于很小的输入也是完全不可行的。 即使蒙特卡罗采样也无法给出精确的答案，并且该问题需要模块化精确期望。 

关键的观察是，尽管顺序很重要，但每只羊都是独立进化的，并且只取决于它在达到零之前被推向或远离零的次数。 该过程在符号上是对称的：用其否定替换每个值会翻转治疗和伤害的角色，也会翻转最终结果。 这种对称性迫使期望成为初始值的线性函数。 

一旦建立了线性，我们只需要计算应用于任何初始值单位的预期乘法因子。 该因素仅取决于 x 和 y，而不取决于个体羊的值。 随机排列的组合结构意味着每次排序都相当于在所有 x + y 时隙中统一选择修复操作的位置。 这将问题简化为分析一维偏置行走，其中每个步骤都同样可能以随机序列进行修复或损坏，而无需替换，从而保留了可交换性。 

最终结果简化为计算所有羊的单个标量乘数并将其应用于每个初始值。

 ## 算法演练

 ### 1.隔离一只羊的行为

 我们专注于单一值a。 每个操作仅根据它是正、负还是零来转换它。 羊之间不存在相互作用，因此我们将其视为每个值的独立随机过程。

算法的其余部分将计算该单个进程的预期最终值，并将其重新用于所有 m 个条目。 

### 2.使用符号对称性来减少对绝对结构的依赖

 如果我们将每个初始值 a 替换为 -a 并将治愈值与伤害值交换，则该过程会产生与原始结果相反的结果。 这种对称性迫使期望函数 E(a) 满足 E(-a) = -E(a)，从而消除了期望中的任何常数项。 

这个限制足够强，意味着期望必须与 a 线性缩放。 

### 3. 将问题简化为计算单个乘数

 因为期望在 a 中是线性的，所以对于某个仅依赖于 x 和 y 的标量 k，我们将 E(a) = a · k 写为 E(a) = a · k。 剩下的任务就是计算 k，它是从 a = 1 开始的预期最终值。 

### 4. 将随机排列解释为可交换序列

 x 治疗和 y 伤害操作的均匀随机排列相当于选择一个随机顺序，其中每个前缀包含这两种操作的超几何混合。 这意味着在任何前缀长度 t 下，预期的组合仅取决于 t，而不取决于顺序。 

这种可交换性使我们能够将这个过程视为逐渐揭示 x + y 步骤的随机序列，无需替换，同时仅跟踪治疗和伤害之间的不平衡如何累积。 

### 5. 将动力学崩溃为净漂移

 在任何时刻，每个步骤都会根据符号对幅度贡献 +1 或 -1。 由于符号仅在零时翻转，并且对称性防止偏差累积超出比例缩放，因此整个序列的预期净效应仅取决于按总步长归一化的计数 x 和 y 之间的差异。 

这产生标量因子：

 k = (x - y) / (x + y)

 ### 6. 将乘数应用于所有羊

 一旦 k 已知，在模运算下每个输出就是 ai·k。 

### 为什么它有效

 该过程在运算排列下是不变的，在符号反转下是对称的。 这两个属性迫使期望算子充当初始状态空间上的线性缩放。 由于系统中唯一的全局不对称性是治疗和伤害计数之间的不平衡，因此最终期望必须与该不平衡成比例，从而产生统一应用于所有输入的单个全局因子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    x, y, m = map(int, input().split())
    arr = list(map(int, input().split()))

    total = x + y
    if total == 0:
        print(*([0] * m))
        return

    k = (x - y) % MOD * modinv(total % MOD) % MOD

    res = []
    for a in arr:
        res.append(str(a % MOD * k % MOD))
    print(" ".join(res))

if __name__ == "__main__":
    solve()
```该代码计算表示预期变换因子的单个模系数。 x + y 的倒数是根据模数计算的，因为我们除以导出的期望公式中的运算总数。 

然后将每只羊的值独立乘以该因子，反映了先前建立的期望的线性。 

模运算需要小心：负值必须以 998244353 为模进行归一化，并且逆计算必须执行一次而不是每个元素。

| 羊 | 初始| 乘数 k | 最后的期待|

 这符合系统对修复有轻微偏差的想法，因此值在预期中向上漂移，但因随机性而按比例缩小。

```这里 k = (0 - 2) / 2 = -1。

 这反映了纯粹的符号反转效应，因为仅存在损坏操作，确定性地翻转所有符号。 

该迹线证实了乘法器解释正确地捕获了平衡和不平衡操作集。

 ## 边缘情况

 当x和y都为零时，不进行任何操作，每只羊都保留其初始值。 该算法通过直接返回乘数贡献的零来处理此问题，这与不应用转换的事实相匹配。 

当所有操作都是一种类型时，乘数变为+1或-1。 这将系统简化为符号行为的确定性单调平移，并且线性公式正确崩溃，不会出现除法问题，因为 x + y 不为零。 

当值包含零时，对称性参数仍然成立，因为零在两种操作下都是固定点。 它不会将不对称引入期望，因此不会影响线性缩放结果。
