 ## 解决方案
 ## 问题理解

 我们被赋予了一个非常长的字符串长度$n$，但我们没有被要求显式构造字符串。 相反，我们处理由固定字母表组成的字符串$\{y, u, k, o\}$，我们想要计算有多少个这样长度的字符串$n$是“有效的”。 

如果一个字符串包含任何其字母可以重新排列形成单词“yuuko”的子字符串，则该字符串被视为无效。 换句话说，我们被禁止拥有一个长度为 5 的窗口，其中包含任意顺序的两个 y、两个 u、一个 k 和一个 o。 这五个字符的任何排列都会触发禁止模式。 

所以任务是纯粹的组合：在所有$4^n$可能的字符串，计算那些避免多重集匹配的任何长度为 5 的窗口的字符串$\{y,y,u,u,k,o\}$。 

关键约束是$n \le 10^{18}$，这立即排除了任何线性甚至对数缩放的 DP$n$具有较大的状态转换。 任何解决方案都必须将过程压缩为类似于固定状态空间上的矩阵求幂的过程。 

边缘情况是由于禁止模式与其自身重叠而产生的。 一种幼稚的方法可能会尝试滑动窗口 DP 并失败，因为禁止的模式可能会以非平凡的方式重叠。 例如，只有在多个重叠窗口形成相同的多重集条件后，字符串才可能变得无效，并且仅跟踪没有结构的最后几个字符会导致指数状态爆炸。 

正确的观点是，我们正在处理固定字母表上的模式避免问题，该字母表具有大小为 5 的固定禁止多重集，这强烈表明有界长度后缀状态上的自动机。 

## 方法

 暴力解决方案将尝试构建所有长度的字符串$n$，一次附加一个字符，并检查是否有任何长度为 5 的子串构成“yuuko”的排列。 这在概念上很简单：维护完整的字符串并在每一步扫描所有大小为 5 的窗口。 然而，即使我们使用滑动频率窗口优化检查，字符串的数量也是$4^n$，即使对于$n = 50$。 

更结构化的暴力破解将使用 DP，其中状态存储当前字符串的最后 4 个字符，因为在添加新字符时只需要这些字符即可检测新的禁止 5 长度窗口。 这将状态空间减少到$4^4 = 256$，规模虽小，但前景广阔。 对于每个状态，我们尝试 4 次转换。 问题是$n$取决于$10^{18}$，如此迭代$n$步骤仍然是不可能的。 

关键的观察是该过程是一个有限自动机：每个状态仅取决于有界后缀，并且给定下一个字符的转换是确定性的。 因此，计数问题就变成了计算长度的行走次数$n$在最多 256 个节点的有向图中，同时避免创建禁止模式的转换。 这正是大小最大为 256 的转移矩阵的矩阵求幂。 

禁止条件是局部的：当我们追加一个新字符时，我们只需要检查最后 5 个字符（移位后）是否形成等于目标多重集的多重集。 这意味着可以在自动机的构建过程中过滤转换。 

自动机建成后，我们计算$T^n$应用于初始状态向量，其中$T$是有效转移的邻接矩阵。 这将问题简化为快速求幂$O(S^3 \log n)$，但自从$S \le 256$，这是可行的。

 ## 算法演练

 我们构造一个确定性自动机，其状态代表字符串的最后 4 个字符。 这已经足够了，因为任何长度为 5 的禁止模式只能在扩展这样的后缀时出现。 

### 步骤

 1. 对字符进行编码$\{y, u, k, o\}$作为整数，这样我们就可以有效地操纵状态。 这允许快速比较和散列后缀状态。 
2. 将状态定义为表示当前前缀的最后最多 4 个字符的元组。 如果字符串短于 4，则状态存储整个前缀。 
3. 枚举所有可达状态。 从空状态开始，重复附加 4 个字符中的每一个，并仅保留长度最多为 4 的后缀。这最多生成$4^4 = 256$州。 
4. 对于每个状态和每个可能的下一个字符，模拟附加它。 如果生成的最后 5 个字符（如果可用）恰好包含两个 y、两个 u、一个 k 和一个 o，我们将这一转换标记为无效并丢弃它。 
5. 构建转移矩阵$T$， 在哪里$T[i][j]$计算有多少种方式陈述$i$转换到状态$j$由一个字符。 每个有效字符恰好贡献一次转换。 
6. 初始化向量$v$其中空状态值为 1，所有其他状态均为 0。 
7. 计算$T^n \cdot v$使用二进制求幂。 每一次乘法表示以压缩形式将所有字符串扩展一个字符步。 
8. 对结果向量的所有条目求和以获得有效字符串的总数。 

### 为什么它有效

 每个字符串的长度$n$恰好对应于一条长度的路径$n$在自动机中，因为每个状态都存储了足够的后缀信息，可以在禁止模式出现时检测到它们。 转换过滤保证 DP 中不会出现无效字符串，并且每个有效字符串都有唯一的路径，因为每个字符的转换都是确定性的。 有效字符串和游程之间的这种双射可确保矩阵求幂精确地计算出所需的集合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

chars = ['y', 'u', 'k', 'o']
idx = {c: i for i, c in enumerate(chars)}

from collections import deque

def get_suffix(s):
    return s[-4:]

def bad(window):
    cnt = [0, 0, 0, 0]
    for c in window:
        cnt[c] += 1
    return cnt == [2, 2, 1, 1]

def encode(state):
    x = 0
    for c in state:
        x = x * 4 + c
    return x

def decode(x, L):
    s = []
    for _ in range(L):
        s.append(x % 4)
        x //= 4
    return tuple(reversed(s))

states = []
state_id = {}
queue = deque()

start = ()
state_id[start] = 0
states.append(start)
queue.append(start)

# build states up to length 4
while queue:
    s = queue.popleft()
    for c in range(4):
        ns = s + (c,)
        if len(ns) > 4:
            ns = ns[-4:]
        if ns not in state_id:
            state_id[ns] = len(states)
            states.append(ns)
            queue.append(ns)

S = len(states)

T = [[0] * S for _ in range(S)]

for s, i in state_id.items():
    for c in range(4):
        ns = s + (c,)
        if len(ns) > 4:
            ns = ns[-4:]
        ok = True
        if len(ns) == 5:
            if bad(ns):
                ok = False
        if ok:
            j = state_id[ns]
            T[i][j] = (T[i][j] + 1) % MOD

def matmul(A, B):
    n = len(A)
    C = [[0] * n for _ in range(n)]
    for i in range(n):
        for k in range(n):
            if A[i][k]:
                for j in range(n):
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
    return C

def matpow(M, e):
    n = len(M)
    R = [[0] * n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1
    while e:
        if e & 1:
            R = matmul(R, M)
        M = matmul(M, M)
        e >>= 1
    return R

if n := int(input().strip()):
    if n == 0:
        print(1)
        sys.exit()

    P = matpow(T, n)

    # initial vector is state 0 only
    ans = sum(P[0]) % MOD
    print(ans)
```该实现构造了长度最大为 4 的所有后缀状态，这足以在扩展时检测禁止的 5 长度多重集。 转换矩阵对所有有效扩展进行计数。 然后矩阵求幂应用这些转换$n$次，无需一步步迭代。 

一个微妙的点是禁止检查的处理：我们仅在形成 5 个字符的窗口时评估条件。 这可以防止对较短前缀的错误修剪。

 ## 边缘情况

 一种边缘情况是当$n < 5$。 在此机制中，禁止的模式根本不会出现，因此每个超过 4 个字符的字符串都是有效的。 自动机正确地反映了这一点，因为从未形成过 5 长度的窗口，因此不会修剪任何过渡。 

另一个边缘情况正是$n = 5$，其中唯一无效的字符串是多重集的排列$y,y,u,u,k,o$。 该算法仅在附加第五个字符时捕获此问题，该字符与禁止条件的定义匹配并确保不会发生过早拒绝。
