 ## 解决方案
 ## 问题理解

 我们得到了一个用户名列表，我们想要计算有多少个无序的用户名对可以被视为彼此的“帐户变体”。 

如果两个用户名具有相同的长度，并且每个位置的每个字符在固定的等效规则下都可以被视为相同，则认为它们是兼容的。 该规则定义所有字母不区分大小写，此外还允许一些特殊替换：字符`a`,`A`， 和`@`是可以互换的，并且字符`o`,`O`， 和`0`是可以互换的。 在不区分大小写的字母匹配下，其他所有内容都表现正常，而数字则保持不变，除了特殊情况`0`。 

因此，核心任务是确定在所有用户名中，将每个字符串转换为其规范标准化形式后，有多少对变得相同。 

输入大小使我们远离用户名之间的任何二次比较。 由于名称多达 100,000 个，总长度为 500,000 个字符，即使比较每一对，在最坏的情况下也需要大约 10^10 个字符检查，这远远超出了 2 秒的限制。 这立即表明每个用户名必须在线性时间内独立处理，然后使用频率结构进行聚合。 

当不同的原始字符串在标准化后变得相同时，会出现微妙的边缘情况。 例如，`c@t`和`cat`应被视为相同，因此即使原始字符串不同，它们也会贡献一对有效的字符串。 另一个陷阱是忘记了特殊的映射`0`到`o`和`@`到`a`，如果仅应用大小写折叠，则会破坏等效性。 

## 方法

 最简单的方法是比较每对用户名，并检查它们在给定映射下是否逐个字符相等。 对于每一对，我们将扫描字符串，动态标准化每个位置，然后进行比较。 这在逻辑上是有效的，因为它直接编码相似性的定义。 

然而，如果有 n 个用户名，这会导致大约 n²/2 次比较。 每次比较可能需要 O(L) 时间，其中 L 是平均字符串长度，总体最坏情况为 O(n²L)，当 n 为 10^5 时，这太慢了。 

关键的观察结果是，等价定义了所有可能字符串的分区：每个用户名都属于一个规范化形式，并且两个用户名当且仅当它们共享该形式时才是有效对。 这减少了从成对比较到计数频率的问题。 一旦每个字符串被转换成它的规范表示，我们只需要计算每个规范字符串出现的次数，然后对每个频率组内的组合求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对检查 | O(n²·L) | O(1) | O(1) | 太慢了 |
 | 归一化 + 频率计数 | O（总长度）| O(n) | 已接受 |

 ## 算法演练

 1. 对于每个用户名，逐个字符构建其规范化版本。 此步骤是必要的，因为等价仅取决于位置变换，而规范化使等价字符串相同。 
2. 对于用户名中的每个字符，将其转换为规范符号。 字母映射为小写。 人物`@`被映射到`a`， 和`0`被映射到`o`。 如果适用，所有其他字符在小写转换后保持不变。 这保证了任何两个等效字符在转换后变得相同。 
3. 将每个规范化的用户名存储在哈希映射中，计算它出现的次数。 这会将所有等效的用户名分组在一起，而无需显式的成对比较。 
4. 处理完所有用户名后，迭代频率图。 对于每个大小为 f 的组，将 f · (f − 1) / 2 添加到答案中。 这会计算组内所有无序对的数量。 
5. 输出最终累加和。 

### 为什么它有效

 规范化函数定义了字符的等价关系，因此按位置扩展到字符串。 当且仅当它们的规范化形式相同时，两个字符串在问题定义下是等效的。 这意味着每个有效对必须位于相同标准化字符串的单个频率桶内，并且该桶内的每个对都是有效的。 计数公式 f·(f − 1) / 2 精确地枚举了每个桶内的所有无序对，确保完整性，不会重复计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def normalize(s: str) -> str:
    res = []
    for ch in s.strip():
        if ch.isalpha():
            res.append(ch.lower())
        elif ch == '@':
            res.append('a')
        elif ch == '0':
            res.append('o')
        else:
            res.append(ch)
    return ''.join(res)

def solve():
    n = int(input())
    freq = {}

    for _ in range(n):
        s = input().strip()
        ns = normalize(s)
        freq[ns] = freq.get(ns, 0) + 1

    ans = 0
    for v in freq.values():
        ans += v * (v - 1) // 2

    print(ans)

if __name__ == "__main__":
    solve()
```实现的核心是标准化功能。 它直接强制所有等价性，以便主逻辑永远不必再次推理特殊情况。 这种分离可以防止细微的错误，例如以不一致的方式混合大小写折叠和数字替换。 

该字典累积完全规范化用户名的频率。 由于 Python 字符串是可散列的，因此此步骤非常高效并且完全符合内存限制。 

最后，将组合公式独立地应用于每个组，这避免了重复计算并确保无序对恰好被计算一次。

 ## 边缘情况

 一种重要的情况是用户名仅因映射到字母的特殊字符而不同。 例如：

 输入：```
2
a@
aa
```标准化将两者变成`aa`，因此它们形成大小为 2 的单个组。该算法通过 2 · 1 / 2 正确地计算出一对。 

另一个案例涉及`0`到`o`与大写字母组合的映射：

 输入：```
3
o0O
oo
o
```标准化后：```
o0O -> ooo
oo  -> oo
o   -> o
```这里我们得到大小为 1、1 和 1 的组，因此不会形成任何对。 这证实了规范化是严格的，并且只有相同的全长匹配才会起作用。 

最后的边缘情况是所有用户名在标准化后都相同但原始形式不同。 基于频率的方法正确地将它们聚合到一个组中，确保对所有有效组合进行计数，而不会丢失交叉变体对。
