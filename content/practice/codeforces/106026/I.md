 ## 解决方案
 ## 问题理解

 我们在平面上给出了三个固定的凸多边形。 每个多边形代表一个必须放置三个点质量之一的区域。 群众的立场不是固定的； 对于每个查询，我们可以选择每个相应多边形内部或边界上的任何点。 

每个质量都按比例贡献其值，因此我们关心的最后一点是三个所选位置的加权质心。 对于查询点，我们必须决定是否可以从每个多边形中选取一个点，使其加权平均值恰好等于该查询坐标。 

因此，从几何角度来说，每个多边形都是点质量的一组可行位置。 质心是每组中一个具有固定正系数的点的线性组合。 问题是目标点是否位于该线性组合的图像中。 

约束很大：每个多边形最多可以有 500,000 个顶点，并且最多有 500,000 个查询。 这立即排除了整个多边形上的任何每次查询的几何构造。 任何重新计算交集、三角剖分或枚举每个查询的边的操作都会超时。 

关键的困难在于，查询是在线进行的，并且基于 XOR 的解码取决于到目前为止有多少答案是“是”。 这种依赖性意味着预处理必须完全独立于查询，并且查询处理必须严格对数或恒定时间。 

一个微妙的边缘情况来自凸简并和质量缩放。 如果一个多边形非常小，甚至有效范围内只有一个点，则质心会塌陷到较低维度的约束。 对于由于不对称质量约束而实际上无法到达的点，假设每个多边形内部都具有完全 2D 自由度的朴素解算器将错误地回答“是”。 

## 方法

 强力解释会尝试直接模拟定义。 对于每个查询，我们将在每个多边形中选取任意点，并尝试求解是否可以满足质心的线性方程。 即使我们离散化多边形或尝试对顶点进行推理，这也是不可行的：每个多边形最多有 5e5 个顶点，并且可行区域是连续的，因此枚举是不可能的。 

关键的观察是凸性将每个多边形变成凸集，并且质心操作是线性映射。 凸集的加权和又是凸集。 更具体地说，如果我们定义集合$P_A, P_B, P_C$，那么所有可达到的质心的集合是：$$G = \frac{m_A P_A + m_B P_B + m_C P_C}{m_A + m_B + m_C}$$这是凸集的闵可夫斯基和，然后进行缩放。 由于缩放不会改变成员资格查询，因此问题简化为检查点是否位于单个凸多边形中：$$S = m_A P_A + m_B P_B + m_C P_C$$因此，我们需要计算缩放下三个凸多边形的闵可夫斯基和。 一个关键的简化是凸多边形的标量乘法只是缩放坐标，并且凸多边形的明可夫斯基和仍然是凸的，并且可以通过合并它们的边缘方向来计算。 

每个凸多边形可以用按角度排序的边向量来表示。 通过合并这些循环边序列，可以在相对于总顶点的线性时间内构建凸多边形的 Minkowski 和，类似于合并两个凸包。 

构造所得凸多边形后，每个查询使用三角形方向上的二元搜索或边界角度上的三元搜索，在对数时间内减少为凸多边形中的点测试。 

因此，问题从连续选择的几何构造转变为静态凸包构造加上点包含查询。

 ## 算法演练

 1. 按每个多边形相应的质量缩放该多边形。 多边形的每个顶点$P_i$乘以$m_i$。 这将质心条件转换为没有分数系数的纯闵可夫斯基和问题。 
2. 计算三个缩放凸多边形的 Minkowski 和。 这是通过首先计算两个多边形的总和，然后添加第三个多边形，或在一次传递中合并所有三个边缘方向序列来完成的。 因为多边形是凸的，所以边缘方向的角度是单调的。 
3. 合并边方向时，在每个多边形中维护一个跟踪当前边矢量的指针。 在每一步中，在三个当前候选者中选择最小角度边缘向量，并推进该多边形的指针，将该向量添加到运行总和多边形中。 
4. 所得到的顶点求和序列形成代表所有可能的缩放质心的最终凸多边形的边界。 
5. 对于每个查询，根据之前的“是”答案，使用 XOR/添加规则对坐标进行解码。 此步骤纯粹是实现细节，但必须在几何检查之前完成。 
6. 使用方向上的二分搜索来针对构造的多边形对解码的查询点执行凸多边形内点测试，以找到该点所在的扇区。 

步骤 3 的正确性取决于以下事实：凸多边形边在循环排序时对应于方向角的单调级数。 凸多边形的明可夫斯基和保留了这种单调结构，因此按角度进行贪婪合并永远不会错过边界边缘。 

### 为什么它有效

 质心的可达集是按正常数缩放的凸集的闵可夫斯基和。 凸集的闵可夫斯基和是凸的，它们的边界由边界方向的和组成。 由于每个多边形都是凸的，因此其边缘方向序列按角度循环排序。 当组合这些序列时，通过合并这些角度排序的序列来获得结果边界，这精确地构造了和集的支持函数。 这保证了不会遗漏任何内部点或边界点，并且每个可行的质心对应于构造的多边形内部的一个点。 

凸多边形中的点隶属度就足够了，因为凸性确保如果一个点可以作为边界支持和的凸组合实现，那么它必须位于所构造的外壳的内部或边界中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def read_poly(n):
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    return pts

def scale(poly, m):
    return [(x * m, y * m) for x, y in poly]

def cross(a, b):
    return a[0] * b[1] - a[1] * b[0]

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

def minkowski(A, B):
    n, m = len(A), len(B)

    def edges(P):
        return [(P[(i + 1) % len(P)][0] - P[i][0],
                 P[(i + 1) % len(P)][1] - P[i][1]) for i in range(len(P))]

    EA, EB = edges(A), edges(B)
    i = j = 0
    res = []

    cur = (A[0][0] + B[0][0], A[0][1] + B[0][1])
    res.append(cur)

    while i < n or j < m:
        eA = EA[i % n] if i < n else (0, 0)
        eB = EB[j % m] if j < m else (0, 0)

        if j >= m or (i < n and cross(eA, eB) >= 0):
            cur = (cur[0] + eA[0], cur[1] + eA[1])
            i += 1
        else:
            cur = (cur[0] + eB[0], cur[1] + eB[1])
            j += 1
        res.append(cur)

    return res

def point_in_convex(poly, p):
    def orient(a, b, c):
        return cross(sub(b, a), sub(c, a))

    n = len(poly)

    if orient(poly[0], poly[1], p) < 0:
        return False
    if orient(poly[0], poly[-1], p) > 0:
        return False

    l, r = 1, n - 1
    while r - l > 1:
        mid = (l + r) // 2
        if orient(poly[0], poly[mid], p) >= 0:
            l = mid
        else:
            r = mid

    return orient(poly[l], poly[l + 1 if l + 1 < n else 0], p) >= 0

mA, mB, mC = map(int, input().split())

A = read_poly(int(input()))
B = read_poly(int(input()))
C = read_poly(int(input()))

A = scale(A, mA)
B = scale(B, mB)
C = scale(C, mC)

AB = minkowski(A, B)
ABC = minkowski(AB, C)

q = int(input())
t = 0

for _ in range(q):
    x0, y0 = map(int, input().split())

    if x0 < 0:
        x = x0 + t
    else:
        x = x0 ^ t

    if y0 < 0:
        y = y0 + t
    else:
        y = y0 ^ t

    if point_in_convex(ABC, (x, y)):
        print("YES")
        t += 1
    else:
        print("NO")
```该实现首先按每个多边形的质量进行缩放，将系数嵌入到几何中，以便质心计算成为一个简单的隶属度问题。 Minkowski 函数通过比较叉积来合并边缘向量，这可以有效地比较它们的角度顺序，而无需显式计算角度。 

凸点检查使用标准的基于扇形的二分搜索。 它首先验证查询点是否位于第一个顶点定义的角扇区内，然后缩小该点必须位于其中的三角形范围。 

一个微妙的实现问题是处理 Minkowski 合并中的循环索引。 该算法假设多边形按逆时针顺序给出，因此边向量形成循环序列。 如果违反此假设，则跨积排序将中断，并且合并的外壳将变得无效。 

## 工作示例

 考虑使用小多边形的简化轨迹来说明行为。 

输入由三个单个三角形（每个三角形已缩放）和一个查询组成。 

| 步骤| 行动| 状态|
 | --- | --- | --- |
 | 解码| 初始 t = 0 | 查询不变|
 | 规模| 多边形乘以质量| A、B、C 比例|

 | 合并 ABC | 添加 C | 最终的凸多边形|

 对于 YES 查询，假设该点位于凸包内。 二分搜索识别出一个楔形，其中该点始终位于所有对角线的同一侧，因此最终的三角形测试成功。 

对于 NO 查询，当该点位于由第一条和最后一条顶点射线形成的边界之外时，第一个方向测试立即失败。 这演示了凸包结构如何允许早期拒绝而无需完全遍历。

 ## 边缘情况

 当所有多边形退化为单个点时，就会出现一种重要的边缘情况。 在这种情况下，闵可夫斯基和会塌缩成一个点，并且只有那个点是可以达到的。 该算法自然地处理这一问题，因为边列表变空，并且合并的外壳恰好包含一个顶点。 

当一个多边形具有重复的共线顶点时，会出现另一种微妙的情况。 由于边缘向量可能包括零或重复的方向，因此叉积比较必须容忍相等。 实现使用`>= 0`确保沿平坦边缘的确定性合并。 

最后的边缘情况是 XOR 解码依赖于先前的“是”答案。 更新计数器时出错`t`仅在打印后才会取消同步所有后续查询。 正确的行为是更新`t`在做出“是”决定后立即执行，以便下一个查询使用正确的加密状态。
