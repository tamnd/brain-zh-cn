 ## 解决方案
 ## 问题理解

 我们有一行学生，每个学生都与一个感兴趣的主题相关联，用一个整数表示。 线路的干扰被计算为具有相同主题的相邻学生对的数量。 老师可以调换学生的位置$i$与学生处于对称位置$n-i+1$，并且该操作可以重复任意次。 目标是使用这些对称交换来重新排列线路，以最大限度地减少总干扰。 

输入由多个测试用例组成。 对于每个测试用例，我们都会收到学生人数$n$和一个数组$a$长度$n$， 在哪里$a_i$是的主题$i$第-个学生。 我们将为每个测试用例输出可实现的最小干扰。 

鉴于$n$可以达到$10^5$所有测试用例的总和不超过$2\cdot 10^5$，任何具有复杂性的解决方案$O(n^2)$每个测试用例太慢。 因此，我们需要一个线性或近线性的解决方案，$O(n)$或者$O(n \log n)$，每个测试用例。 

不明显的边缘情况包括所有学生都有相同主题的数组，最初会导致最大的干扰。 另一个微妙的情况是当数组是对称或接近对称时，其中一些交换是多余的。 例如，如果$a = [1, 2, 1, 2]$，任何交换都不会改变相邻重复项为零的事实。 在不考虑邻接性的情况下计算交换的粗心方法可能会高估或低估干扰减少量。 

## 方法

 简单的方法枚举所有允许交换的序列，计算每个序列后的干扰，并选择最小值。 这在原则上是正确的，但在计算上是不可行的，因为每个学生都可能多次交换他们的镜子位置。 为了$n$学生们，交换序列的数量是指数级的$n/2$，明显超过时限。 

关键的见解是对称交换将数组分成对$(i, n-i+1)$，并且每对内的交换仅影响直接邻居。 因此，我们可以关注**连续相等元素的块**。 最佳策略是通过确保每个对称对内的序列尽可能交替来最小化每个块的长度。 对于任何连续相同元素的块，最小扰动与$\lfloor \text{length}/2 \rfloor$，因为每次交换最多只能破坏一对相等的邻居。 这将问题简化为扫描数组、计算相同主题的运行次数以及将其一半长度的底数相加。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n/2) * n) | O(2^(n/2) * n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将干扰计数器初始化为零并设置指针$i = 0$来遍历数组。 
2. 虽然$i < n$：

 1. 识别当前块的连续相等元素，从$i$。 让$j = i$。 
2. 增量$j$直到$a[j] \neq a[i]$或者$j = n$，有效求出块的长度$L = j - i$。 
3. 将干扰计数器增加$\lfloor L/2 \rfloor$。 对称对内的每次交换都可以破坏一个邻接关系，并且地板会占用剩余的未配对元素。 
4. 移动$i$到$j$处理下一个块。 
3.遍历数组后，输出扰动计数器。 

为什么有效：对称交换允许一对中的任何元素$(i, n-i+1)$进行交换。 因此，每次运行相同的主题都可以在对约束内进行最佳重新排列。 相邻重复项的最小数量恰好是所有块的总和$\lfloor \text{length}/2 \rfloor$，因为这是允许交换可以破坏的最大邻接数。 这确保了所有块配置的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def minimal_disturbance(a):
    n = len(a)
    res = 0
    i = 0
    while i < n:
        j = i
        while j < n and a[j] == a[i]:
            j += 1
        length = j - i
        res += length // 2
        i = j
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(minimal_disturbance(a))
```该解决方案遍历数组一次，计算连续的相同元素并对它们的半长度求和。 内部 while 循环仅遍历每个元素一次，因此算法以线性时间运行。 边界条件处理正确：当一个块到达数组末尾时，$j = n$，以及计算$\lfloor L/2 \rfloor$仍然成立。

 输出：`1`。 第一个区块`[1,1,1]`贡献`3//2 = 1`扰乱； 其余元素是单例块，贡献为零。 

输入示例：`a = [2, 1, 1, 2, 2, 4]`| 步骤| 我| j | 一个[i：j] | 长度| 资源 |

 | 4 | 5 | 6 | [4] | 1 | 2 |

 输出：`2`。 这与示例相匹配，确认了多个块的正确处理。
