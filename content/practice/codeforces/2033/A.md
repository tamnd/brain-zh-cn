 ## 解决方案
 ## 问题理解

 我们被要求确定回合制游戏的获胜者，其中两名玩家从位置零开始沿着数轴移动一个点。 樱子总是向左移动，并在她的回合中增加奇数个单位：-1、-5、-9，依此类推。 Kosuke 向右移动相同的奇数序列：3、7、11 等。一旦点移出区间，游戏就结束。`-n`到`n`。 我们的任务是确定在点退出此间隔之前哪个玩家做出最后有效的移动。 

输入给出多个独立的游戏，每个游戏由一个整数定义`n`。 输出应该是每场比赛中最后移动的玩家的名字。 界限很小：`t`最多 100 个游戏，以及`n`最多 100。这允许算法在每场比赛中以最坏的 O(n) 运行，甚至直接的移动模拟也能快速完成。 

边缘情况出现的值非常小`n`。 例如，如果`n=1`，移动顺序为-1（樱子）、3（小介）。 在樱子迈出第一步之后，`x=-1`处于间歇期内，因此比赛继续进行。 Kosuke 的下一步行动加 3，采取`x`至 2，超过`n=1`。 小介是最后一个在界内移动的玩家，所以他获胜。 在这种情况下，天真的差一计算或忘记移动符号会产生错误的答案。 

## 方法

 最简单的方法是模拟每个游戏`n`。 开始于`x=0`并轮流迭代，交替玩家。 转弯时`i`， 添加`2*i-1`朝着正确的方向。 一旦采取下一步行动就停止`x`外部`[-n, n]`。 这适用于给定的约束，因为每次移动的幅度和大小都会增加`n`很小，因此每个游戏的迭代次数大致以 的平方根为界`2*n`（因为奇数之和近似为二次）。 每场比赛最坏情况下的操作远低于 100 次，因此这是可行的。 

然而，我们可以观察到一种模式。 如果我们将棋子分为樱子的负步和浩介的正步，则每一边的累积和形成奇数序列。 让`S = sum_{k=1}^{m} (2k-1)`是第一个的累积和`m`移动。 这总是`m^2`。 游戏基本上继续进行，直到剩余的累积总和超过`n`或者正确的累计总和超过`n`。 因此，我们可以预先计算哪个累积平方首先超过，而不是模拟每一步`n`对于每一方。 累计总金额超过的玩家`n`下一个输了，另一位玩家做出了最后的有效动作。 这将问题简化为简单的整数运算。

 | 最优累积和分析| 每场比赛 O(1) | O(1) | O(1) | 已接受且干净|

 ## 算法演练

 1.读取游戏数量`t`。 初始化一个空的结果列表。 
2. 对于每个游戏，请阅读`n`。 初始化位置变量`x = 0`和一个移动计数器`i = 1`。 
3. 而绝对值`x`是在`[-n, n]`,确定当前移动量`2*i - 1`。 如果`i`是奇数，减去它（樱子向左移动）。 如果`i`是偶数，则相加（Kosuke 向右移动）。 更新后`x`, 增量`i`。 
4. 什么时候`x`首先移动到区间之外`[-n, n]`，最后一个有效的动作是由前一个玩家做出的。 如果`i`是平局，樱子做出了最后一步有效的棋步。 如果`i`奇怪的是，小介做出了最后一步有效的棋步。 
5. 将获胜者姓名添加到结果列表中。 
6. 处理完所有游戏后，打印结果。 

为什么有效：移动的幅度和交替方向单调增加。 通过更新`x`依次，我们保持不变式`x`反映了点的真实位置。 那一刻`x`超过`[-n, n]`，我们知道最后一个有效的动作是上一个回合，保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
results = []

for _ in range(t):
    n = int(input())
    x = 0
    i = 1
    while True:
        move = 2*i - 1
        if i % 2 == 1:
            x -= move
        else:
            x += move
        if abs(x) > n:
            winner = "Sakurako" if i % 2 == 1 else "Kosuke"
            results.append(winner)
            break
        i += 1

print("\n".join(results))
```该代码首先读取游戏数量。 对于每个游戏，它都会将点初始化为零并一一模拟移动。 移动幅度为`2*i-1`。 樱子在奇数回合向左移动，小介在偶数回合向右移动。 当点离开边界时，我们检查轮到谁并记录获胜者。 这种方法仔细地处理了符号和转牌奇偶性，它们是差一错误的容易来源。
