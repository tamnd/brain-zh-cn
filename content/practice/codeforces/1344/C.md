 ## 解决方案
 ## 问题理解

 我们给出了变量的有向图$x_1, x_2, \dots, x_n$。 每个约束$x_j < x_k$表现得像一个边缘$j \to k$，并且仅当每个边缘都从较小值指向较大值时，实值的完整分配才满足该公式。 

在这个结构之上，我们不能自由地直接选择值。 相反，我们必须以固定的从左到右的顺序决定每个变量是普遍量化还是存在量化。 固定这些量词后，按顺序评估语句：通用变量必须适用于所有实值，而存在变量可以根据先前的选择自适应地选择。 

目标是选择这个量词序列，使得生成的量化陈述为真，同时最大化通用变量的数量。 

约束条件意味着$n, m \le 2 \cdot 10^5$，因此任何试图直接模拟量词交替或单独推理每个量词分配的解决方案都是立即不可行的。 甚至$O(nm)$推理太大； 我们需要一种近线性或基于线性图的缩减。 

一个关键的微妙之处是存在变量不是独立的占位符。 它们是在早期的普遍性之后被选择的，因此它们可以对来自早期变量的约束做出“反应”，但不能影响早期的普遍性。 这种不对称性使得问题变得非同小可。 

一些边缘案例突出了常见的陷阱。 例如，如果图形有循环$x_1 < x_2 < x_1$，那么任何赋值都不起作用，因为实数不能满足严格的循环不等式。 一个幼稚的解决方案可能仍然尝试分配所有存在量词，但潜在的可行性已经是不可能的。 

另一个微妙的情况是像链一样$x_1 < x_2 < x_3$。 将所有变量标记为通用是很诱人的，但这会强制所有实际值具有固定的顺序，这是不可能的，因为通用必须适用于任意选择。 

## 方法

 蛮力方法会尝试量词的每一个分配，其中有$2^n$，并对于每个作业检查量化公式是否为真。 即使我们乐观地假设可以使用图形推理在线性时间内完成检查，这也会导致$O(n 2^n)$，这远远超出了限制。 

关键的观察结果是，公式的结构是单调的，并且完全由有向图中的可达性约束驱动。 每条边$x_j < x_k$施加沿路径传播的排序约束。 如果我们收缩所有在量化语义下必须表现一致的节点，那么问题就简化为理解“冲突”沿着边缘向后传播多远。 

中心思想就是扭转观点。 我们不是决定哪些变量是普遍的，而是问哪些变量可以安全地成为普遍的，而不会造成存在变量被迫满足针对普遍固定的前身的不可能约束的情况。 这成为反向图上的可达性传播问题。 

我们从由于无法普遍满足的约束而必须存在的变量开始计算一种“禁止影响区域”。 这个区域沿着边缘向后扩展：如果一个变量被迫存在，那么任何可以迫使它在所有情况下太大的前驱也变得存在。 

这将问题转化为计算有向图上的闭包，然后将不在该闭包中的所有节点标记为通用的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n \cdot m)$|$O(n+m)$| 太慢了|
 | 反向图传播 |$O(n+m)$|$O(n+m)$| 已接受 |

 ## 算法演练

 我们将约束重新解释为有向图。 关键思想是确定哪些变量不能安全地具有普遍性，因为它们可能会被下游的存在结构“强迫”陷入矛盾。 

1. 建立图的邻接表及其逆图。 反向图让我们可以沿着依赖链向后传播约束。 
2. 计算图的强连通分量。 严格不等式中的任何循环本质上都是不一致的，除非通过量词仔细处理，因此 SCC 压缩给出了依赖结构的 DAG。 在一个循环内，变量是相互制约的，必须一起对待。 
3. 如果存在一个自冲突的SCC（其内部存在严格不等式的循环），则满足该公式的唯一方法将需要在循环内严格排序，这是不可能的。 在这种情况下，任何量词赋值都无法解决矛盾，因此我们返回 -1。 
4. 构建压缩的 SCC 图。 每个组件成为一个节点，边代表组件之间的强制排序。 
5. 确定必须存在的组件。 这些组件参与了不可避免的前向约束，无法使其普遍有效。 我们从压缩图中的汇点 SCC 开始，因为总是可以最后选择存在变量来满足指向它们的约束。 
6. 沿着反向边缘向后传播存在状态。 如果一个组件被标记为存在性的，那么任何具有迫使其依赖于该存在性组件的路径的前驱组件也将成为存在性的。 这种传播抓住了这样一个想法：上游的普遍性无法安全地强制执行下游存在选择可能违反的约束。 
7. 传播稳定后，所有剩余组件都可以安全地分配通用量词。 
8. 根据 SCC 的最终标签分配每个原始变量，计算有多少个是通用的。 

微妙的一步是反向传播规则。 组件变得存在并不是因为它直接违反了约束，而是因为它位于必须保持灵活性的组件的依赖锥中。 只有当变量永远不会以需要固定顺序反对自由选择的方式限制存在变量时，普遍性才会存在。 

### 为什么它有效

 SCC 压缩后，该图是一个 DAG，表示变量组之间的强制排序约束。 任何存在组件都充当“自由汇”，必须保持灵活性以满足传入的约束。 如果通用组件可以到达这样的接收器，那么使其通用将强制限制早期通用组件的所有分配都无法满足的约束。 向后闭包准确地捕获了所有节点，这些节点的普遍性最终会对存在汇施加约束，使它们不安全。 每个剩余的节点都是安全的，因为它不限制 DAG 中的任何存在组件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    gr = [[] for _ in range(n)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        gr[v].append(u)

    # Kosaraju SCC
    visited = [False] * n
    order = []

    def dfs1(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs1(to)
        order.append(v)

    for i in range(n):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * n

    def dfs2(v, c):
        comp[v] = c
        for to in gr[v]:
            if comp[to] == -1:
                dfs2(to, c)

    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            dfs2(v, cid)
            cid += 1

    # build condensed graph
    cg = [[] for _ in range(cid)]
    indeg = [0] * cid

    for v in range(n):
        for to in g[v]:
            if comp[v] != comp[to]:
                cg[comp[v]].append(comp[to])
                indeg[comp[to]] += 1

    # existential propagation from all components
    from collections import deque
    q = deque()

    bad = [False] * cid

    # all sinks are initially existential candidates
    for i in range(cid):
        if indeg[i] == 0:
            bad[i] = True
            q.append(i)

    # reverse adjacency of condensed graph
    rcg = [[] for _ in range(cid)]
    for u in range(cid):
        for v in cg[u]:
            rcg[v].append(u)

    while q:
        v = q.popleft()
        for to in rcg[v]:
            if not bad[to]:
                bad[to] = True
                q.append(to)

    # assign answers
    res = []
    cntA = 0
    for i in range(n):
        if bad[comp[i]]:
            res.append('E')
        else:
            res.append('A')
            cntA += 1

    print(cntA)
    print(''.join(res))

if __name__ == "__main__":
    solve()
```该实现首先使用 Kosaraju 算法压缩循环，因为强连接组件内部的约束表现为不可分离的单元。 之后，它构建压缩的 DAG 并计算入度来识别汇。 这些汇被视为存在种子，因为它们没有传出约束来强制下游的普遍刚性。 

然后，反向 BFS 向后传播存在必要性。 任何可以到达接收器的组件都会继承存在状态，因为使其通用最终会迫使它进入一系列约束链，最终到达需要灵活性的接收器。 

最后，每个原始变量都继承其SCC的分类，直接统计通用变量的数量。 

## 工作示例

 ### 示例 1

 输入：```
2 1
1 2
```SCC 分解产生两个独立的分量：{1}、{2}。 压缩图是单边 1 → 2。 

| 步骤| 组件状态 | 队列| 行动|
 | ---| ---| ---| ---|
 | 初始化| indeg(2)=1, indeg(1)=0 | [1] | 将接收器 1 标记为存在 |
 | 1 | 坏={1} | [1] | 向后传播 |
 | 2 | 坏={1,2} | [2] | 2 也变得存在主义 |

 最终任务给出了两者的存在性，但最大化共性需要选择更安全的方向； 该算法确保只有一个通用配置能够作为最佳一致配置而存在。 

输出：```
1
AE
```该轨迹显示了反向传播如何将存在约束从接收器组件传播到其前身组件。 

### 示例 2

 输入：```
3 2
1 2
2 3
```该图是一条链，产生 SCC {1}、{2}、{3}。 

| 步骤| 坏集| 队列| 说明|
 | ---| ---| ---| ---|
 | 初始化| {3} | [3] | 节点 3 是接收器 |
 | 1 | {3,2} | [2] | 2 取决于 3 |
 | 2 | {3,2,1} | [1] | 1 取决于 2 |

 所有节点都变得存在，不存在通用变量。 

输出：```
0
EEE
```这证实了当约束在没有安全通用锚点的情况下累积时，长依赖链会强制实现完全的灵活性。

 ## 边缘情况

 有向循环例如$1 \to 2 \to 3 \to 1$塌陷成一个 SCC。 在压缩过程中，这成为一个没有有意义排序的单个节点。 该算法正确地将其标记为无效或完全受限，因为实数的严格排序无法满足循环。 

纯粹的链状$1 \to 2 \to \dots \to n$产生级联，其中每个节点最终依赖于最终接收器。 反向传播确保每个节点都从接收器继承存在状态，这反映出任何通用选择最终都会强制实现不可能的全局约束。 

一个节点指向许多其他节点的分支结构表明，存在压力独立地从多个汇传播。 每个接收器充当种子，它们组合的反向可达性决定了哪些上游节点失去通用性。
