 ## 解决方案
 ## 问题理解

 会议中的每场讲座都有两种可能的时间表，具体取决于选择的地点。 如果我们选择场地 A，则每场讲座都遵循其 A 间隔。 如果我们选择地点 B，则每个讲座都遵循其 B 间隔。 关键的限制是，只有在所选场地下，这些间隔在时间上不重叠的情况下，参与者才能参加一组讲座。 

如果一套讲座的可行性取决于场地的选择，那么它就会出现问题。 换句话说，存在一组讲座，它们在一个地点形成有效的非重叠时间表，但在另一个地点则不可能在没有重叠的情况下安排。 

任务是确定这样的集合是否存在。 如果不存在这样的“场地敏感”集合，我们输出 YES，否则输出 NO。 

输入大小最多可达 100,000 个讲座。 任何试图检查所有子集的解决方案都是立即不可能的，因为这将是指数级的。 即使成对检查所有子集也是不可行的，因为子集的数量为 2^n。 这促使我们推理区间排序的结构特性，而不是显式子集枚举。 预计 O(n log n) 左右的基于排序的解决方案。 

仅考虑成对重叠会产生一个微妙的问题。 仅检查任何一对讲座是否会改变场地之间的重叠状态是不够的。 一对可能会在重叠和不重叠之间翻转，但仍然不会创建见证集，除非它影响全局排序约束。 

典型的失败直觉是将问题视为独立比较两个区间图并检查边缘差异。 这忽略了这样一个事实：该属性取决于同一子集中非重叠间隔的一致排序的存在。 

## 方法

 蛮力方法将尝试考虑讲座的每个子集，并检查它在两个场所还是仅在一个场所是否独立（不重叠）。 对于每个子集，我们将通过排序和贪婪检查重叠来测试 A 和 B 中间隔调度的可行性。 每个子集已经是 O(n log n)，导致 O(2^n n log n)，这远远超出了可行的限制。 

关键的见解是停止从子集的角度思考，而是关注由间隔引起的排序约束。 对于固定场地，选择非重叠间隔的子集对应于按照按结束时间排序定义的总顺序选择链。 贪心算法产生规范最大兼容集。 

现在考虑什么会使子集“场地敏感”。 这意味着 A 和 B 之间的间隔之间的相对排序约束不同，且无法全局协调。 如果两个间隔必须以一种方式排序以避免 A 中的重叠，但在 B 中需要相反的排序，则包含这两者的任何子集都会产生不可调和的约束。 

这导致了减少：我们只需要检查是否存在一对间隔，它们按结束时间的相对顺序不一致，从而破坏了两个场地之间的传递性。 经过仔细的重新表述后，条件简化为检查是否可以找到两个区间，其 A 排序和 B 排序导致区间嵌套结构中的矛盾。 这相当于验证A端排序和B端跟踪可行性是否保持一致的单调结构。 

一种更简洁的查看方法是按 A 结束时间对间隔进行排序，并跟踪可行链的最大 B 开始； 如果在贪婪构造过程中我们违反了一致性约束，我们就会检测到一对冲突的对，形成对场地敏感的见证人。 

这通过排序和本地一致性检查将问题减少到一次扫描。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对子集的暴力破解 | O(2^n · n log n) | O(2^n · n log n) | O(n) | 太慢了|
 | 排序+贪心一致性检查 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们将每个讲座转换为两个区间表示，但我们主要使用一个场地引起的排序进行推理，并验证另一个场地的一致性。 

1. 按会场 A 的结束时间对所有讲座进行排序。这会为 A 创建规范的时间表排序，因为 A 中的任何最佳非重叠子集都遵循此顺序。 
2. 按此顺序浏览讲座，同时保持 B 场地下最早的整理结构和跟踪兼容性。 
3. 维护一个代表场地 A 的假设贪婪链中最后选择的讲座的变量。这确保我们始终考虑 A 中的最大兼容序列。 
4. 对于按排序顺序的每个讲座，确定其是否可以扩展当前的A-可行链。 如果可以，我们尝试将其集成，同时检查它是否违反了 B 中相对于先前选择的讲座的排序约束。 
5. 关键的检查是在 A 的贪婪链中选择这个讲座是否会强制 B 中出现与非重叠可行性相矛盾的不同排序。 如果观察到这样的矛盾，我们立即得出结论，存在场地敏感集。 
6. 如果我们处理完所有讲座而没有发现矛盾，我们就得出结论，每个子集在两个场地上的行为都是一致的。 

### 为什么它有效

 按A结束时间排序的贪婪链代表了场地A中所有可行独立集的规范结构。A中任何可行的子集都可以嵌入到这条链中，而不失一般性。 

如果存在场地敏感集，则必须存在一个涉及两个讲座的最小见证人，这两个讲座在 A 最优链中的相对位置是兼容的，但其 B 间隔结构迫使出现重叠矛盾。 通过扫描 A 顺序并逐步检查 B 一致性，我们确保任何此类最小冲突对在相关时都能被检测到。 这避免了丢失更大的子集交互，因为任何更大的矛盾都会崩溃为贪婪结构中连续候选者之间的局部顺序违规。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = []
    for i in range(n):
        sa, ea, sb, eb = map(int, input().split())
        a.append((sa, ea, sb, eb))

    # sort by A ending time
    a.sort(key=lambda x: x[1])

    # we track last chosen interval's B end
    last_b_end = -10**18

    for sa, ea, sb, eb in a:
        # greedy choice in A: take interval if it doesn't overlap in A-chain sense
        # but we simulate selection by A-end ordering, so we only care about B consistency
        if sb > last_b_end:
            last_b_end = eb
        else:
            # overlap in B while still compatible in A-chain ordering implies conflict structure
            return print("NO")

    print("YES")

if __name__ == "__main__":
    solve()
```代码首先按照场地 A 中的结束时间对间隔进行排序，固定用于在 A 中构建最大非重叠链的规范排序。`last_b_end`跟踪该链中选定间隔中场地 B 的最新完成时间。 如果一个新的区间不能在不与之前的选择重叠的情况下放置在 B 中，但由于贪婪结构而仍然与 A 的排序兼容，我们会检测到不一致并输出 NO。 

微妙之处在于我们从不显式构建子集。 相反，我们将搜索空间压缩为单个贪婪链，该贪婪链捕获两个区间系统之间的所有结构冲突。 

## 工作示例

 ### 示例 1

 输入：```
2
1 2 3 6
3 4 7 8
```已按 A 结束时间排序：间隔 1 在 2 结束，间隔 2 在 4 结束。 

| 步骤| 间隔 | 最后_b_结束 | 行动|
 | ---| ---| ---| ---|
 | 1 | [1,2], [3,6] | -inf| 选择，last_b_end = 6 |
 | 2 | [3,4], [7,8] | 6 | 7 > 6，选择，last_b_end = 8 |

 没有出现冲突，因此输出为 YES。 

这证实了 A 中的贪婪链在 B 中也是一致的。 

### 示例 2

 考虑：```
3
1 3 1 10
2 4 2 3
5 6 4 5
```按A结束时间排序后：

 区间为 (2,4)、(1,3)、(5,6)。 

| 步骤| 间隔 | 最后_b_结束 | 行动|
 | ---| ---| ---| ---|
 | 1 | [2,4], [2,3] | -inf| 选择，last_b_end = 3 |
 | 2 | [1,3], [1,10] | 3 | 1 ≤ 3 所以冲突 → 否 |

 这显示了 A 顺序允许选择但 B 强制重叠的情况。

 ## 边缘情况

 当两个间隔在 A 中不相交但在 B 中严重重叠时，就会出现最小边缘情况。当第二个间隔到达且 B 开始不超过当前跟踪的 B 结束时，算法会检测到这种情况。 

例如：```
2
1 2 1 10
3 4 2 3
```按A结束时间排序后，选择第一个区间，设置`last_b_end = 10`。 第二个区间有`sb = 2`，不大于10，立即触发NO。 这正确地捕获了 A 允许两者同时 B 强制重叠。 

当间隔在 A 中交错但在 B 中完全可分离时，会出现第二种边缘情况。A 中的贪婪链确保我们只提交在真正的独立集合中可行的结构； 如果 B 也遵循此顺序，则不会检测到矛盾，并且输出仍为 YES。
