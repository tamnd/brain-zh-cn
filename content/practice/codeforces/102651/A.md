 ## 解决方案
 ## 问题理解

 两支球队进行未知场次的比赛。 获胜者获得三分，平局双方获得一分，失败则不得分。 我们只知道第一队和第二队的最终积分。 任务是确定这个分数是否可以实现，如果可以，找到一种方法，使用尽可能少的比赛次数将比赛分为第一队获胜、平局和第二队获胜。 

让`a`为第一队的最终得分，`b`为第二队的最终成绩。 答案必须包含三个值：第一队赢了多少场比赛，平局了多少场，第二队赢了多少场。 如果没有匹配序列可以产生分数，我们输出`-1`。 

分数可以大到`10^9`，因此尝试模拟比赛或迭代可能的比赛数量是不可能的。 即使是一个大小的环`a`或者`b`可能需要十亿次迭代。 该解决方案必须使用评分系统的算术属性并在恒定时间内完成。 

几种边界情况可能会破坏简单的解决方案。 例如，输入```
0
1
```没有答案。 分数之间的差异是`-1`，但是每场比赛都会将分差改变三的倍数，所以这个分数不可能出现。 

另一种情况是：```
2
2
```正确的输出是：```
0 2 0
```粗心的方法可能会尝试用胜利来代表两队得分，因为每场胜利三分似乎很有效，但在这场比赛中，如果不给对手零分，任何一支球队都无法获胜。 两队打平是两队各取两分的唯一途径。 

案例```
3
0
```必须产生：```
1 0 0
```仅首先搜索平局的方法可能会错过单场胜利已经给出了最少比赛次数的准确分数。 

## 方法

 直接暴力法会尝试第一队的所有可能的胜局和平局次数，然后检查是否可以从剩余的比赛中得出第二队的得分。 既然分数可以达到`10^9`，在最坏的情况下，这样的搜索将需要多达数十亿次迭代。 该方法在逻辑上是正确的，因为它枚举了可能的匹配组合，但它无法满足限制。 

有用的观察来自于分数差异。 让`x`成为一线队获胜，`y`是平局，并且`z`成为第二队获胜。 最终得分满足：```
3x + y = a
y + 3z = b
```减去这些方程就可以消除平局：```
3x - 3z = a - b
```所以：```
x - z = (a - b) / 3
```两队得分之差必须能被三整除。 检查完该条件后，剩下的任务就是选择胜负次数。 

为了最小化比赛总数，我们应该最大化可以取代平局的胜利数量。 一场胜利为一支球队贡献三分，而平局只为每支球队贡献一分，因此尽可能多地利用胜利来减少比赛次数。 

如果第一队有分数优势，我们保留第一队所需的额外胜利，并最大化第二队的胜利。 第二队最多可以拥有`b // 3`获胜。 相反的情况是对称的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(最大(a, b)) | O(1) | O(1) | 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算分数差`a - b`。 如果不能被三整除，则输出`-1`。 两支球队之间的分数差距仅由胜利造成，每场胜利都会将分差恰好改变三分。 
2. 计算`k = (a - b) / 3`。 该值代表第一队比第二队多赢了多少场比赛。 正值表示第一队有额外胜利，负值表示第二队有额外胜利。 
3.如果`k`是非负数，让第二支球队赢得尽可能多的比赛。 放`z = b // 3`，因为第二队每次获胜都会消耗第二队得分中的 3 分。 第二队的剩余积分变为平局：`y = b - 3z`。 那么第一支队伍需要`x = z + k`获胜以保持所需的差异。 
4.如果`k`为负数，进行镜像计算。 通过设置让第一支球队赢得尽可能多的比赛`x = a // 3`。 剩余积分变为平局，第二队获胜`z = x - k`。 
5、输出`x`,`y`， 和`z`。 

为什么它有效：

 分差方程修正了两队获胜次数之间的差异。 该算法永远不会改变这种差异。 在将最大可能的胜场数分配给没有所需优势的球队之后，剩余的积分总是少于三分，因此只能通过平局来产生。 该结构产生有效的分数。 由于每次用胜利代替平局都会减少比赛数量，因此最大化胜利会减少比赛总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())

    diff = a - b

    if diff % 3 != 0:
        print(-1)
        return

    k = diff // 3

    if k >= 0:
        z = b // 3
        y = b - 3 * z
        x = z + k
    else:
        x = a // 3
        y = a - 3 * x
        z = x - k

    print(x, y, z)

if __name__ == "__main__":
    solve()
```第一部分检查唯一不可能的条件。 Python 整数不会溢出，因此值接近`10^9`在整个计算过程中都是安全的。 

什么时候`k`为正数时，代码首先会获得尽可能多的第二队胜利。 这是关键的最小化步骤，因为这些胜利取代了几场平局，同时保留了所需的分数差异。 第二队剩余积分正好是平局数。 

什么时候`k`是否定的，同样的想法也适用于交换的球队。 表达式`z = x - k`有效是因为`k`是负数，因此它增加了第二支球队所需的额外胜利。 

除法使用整数楼层除法。 除去所有可能获胜后的余数总是`0`,`1`， 或者`2`，这是有效的抽奖次数。 零分数不需要特殊处理，因为公式自然会产生零匹配。

import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    def solve():
        input = sys.stdin.readline
        a = int(input())
        b = int(input())

        diff = a - b

        if diff % 3 != 0:
            return "-1"

        k = diff // 3

        if k >= 0:
            z = b // 3
            y = b - 3 * z
            x = z + k
        else:
            x = a // 3
            y = a - 3 * x
            z = x - k

        return f"{x} {y} {z}"

    ans = solve()
    sys.stdin = old_stdin
    return ans

assert solution("2\n2\n") == "0 2 0", "only draws"

 ## 边缘情况

 对于`0`和`1`，算法计算`diff = -1`。 自从`-1`不能被三整除，它返回`-1`立即地。 这可以处理由任何获胜组合都无法创造的差异所导致的不可能得分。 

为了`2`和`2`，差异为零，因此两支球队的胜场数必须相同。 该算法消除了所有可能的胜利`a // 3 = 0`并留下两分作为平局。 它输出`0 2 0`，它使用尽可能少的匹配数。 

为了`3`和`0`，相差三，所以`k = 1`。 第一队必须比第二队多赢一场。 第二队没有得分，给予`z = 0`和`y = 0`，结果是`x = 1`。 该算法避免产生不必要的平局并返回尽可能小的锦标赛。
