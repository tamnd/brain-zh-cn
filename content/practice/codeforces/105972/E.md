 ## 解决方案
 ## 问题理解

 我们得到了一个整数数组，我们需要计算在非常具体的基于增长的约束下有多少子段是“好的”。 

一个子段$[l, r]$如果我们可以将这个段内的每个位置（从长度 1 开始到其全长）与可以用特殊形式表示的段中的值相匹配，则认为是好的。 具体来说，对于每个指数$i = 1, 2, \ldots, (r - l + 1)$，段中必须至少存在一个元素等于$x^i$对于某个整数$x$。 关键点是对于每个指数$i$, 基数$x$允许独立变化，因此我们不是在寻找单一的几何级数，而是在寻找至少一个完美的存在$i$每个段中的次幂$i$。 

因此，该条件并不要求跨指数的结构； 它询问该线段是否总共包含至少一个完全平方数、至少一个完全立方数，依此类推，直到等于线段长度的指数。 

重新构架，一段长度$k$如果对于每个指数都很好$i$从$1$到$k$，该段至少包含一个完美的值$i$某个整数的 次方。 

输入是一个数组，最多包含$10^5$元素，每个元素最多$10^9$。 输出是满足此属性的子数组的数量。 

约束条件$n \le 10^5$排除任何检查所有的方法$O(n^2)$子数组，在每个子数组内重新计算指数检查。 即使是天真的$O(n^2 \sqrt{\max a_i})$或者$O(n^2 \log a_i)$解决方案会太慢。 

微妙的困难在于，检查一个段是否良好取决于其内部数论属性的分布，而不是排序或总和。 这使得前缀聚合变得非常重要。 

一些边缘情况直接重要：

 单元素段总是好的，因为指数$i = 1$只需要存在一个等于$x^1$，这始终是正确的。 例如，输入$[7]$产生答案$1$。 

长度为 2 的线段需要至少一个完全平方值和至少一个完美线性值（对于任何整数始终如此）。 所以真正的约束从指数开始变得重要$2$向上。 

仅包含指数以外的非完美幂的线段$1$， 例如$[2, 3, 5]$, 长度失败$3$因为线段中没有立方体，所以指数$3$已经不可能了。 

## 方法

 一种暴力方法会枚举每个子数组并计算每个子数组的长度$k$，然后检查每个指数$i \le k$子数组中是否有一个元素是完美的$i$次幂。 这需要跨重叠段重复重新计算功率检查。 

对于每个子数组，扫描其元素为$O(n)$，并检查所有指数$k$添加了另一个因素。 这导致$O(n^3)$在最坏的情况下，这对于$n = 10^5$。 

即使我们预先计算，对于每个元素$a_j$, 所有指数$i$这样它就是一个完美的$i$-次方，我们仍然需要一种有效查询子数组以覆盖指数范围的方法。 核心观察是每个数字仅对一小部分指数有贡献，因为对于$a_i \le 10^9$，它可以成为完美幂的最大指数迅速缩小。 例如，只有很少的数字是完美的10次方，20次方的数字就更少了，等等。 

这表明我们要翻转观点：我们不是根据指数检查子数组，而是跟踪每个指数存在有效值的位置。 那么问题就变成了覆盖一个段内的所有指数层，这可以简化为在丢失某些指数级别之前我们可以将段延伸多远的约束。 

关键的见解是，答案取决于阵列中每个指数级别“支持”的程度。 我们可以预先计算每个指数$i$，其中的位置$i$出现 - 次方。 然后，对于任何起始索引，我们可以确定最右端点，该端点对于每个指数（直到某一界限）仍至少包含一个有效值。 这自然会导致两指针或右扩展方法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3)$|$O(1)$| 太慢了 |
 | 预计算+两个指针|$O(n \log A)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 预先计算每个元素的所有指数$i$这样它就是一个完美的$i$次幂。 这是通过重复取整数根达到指数限制来完成的，其中$2^i \le 10^9$。 结果是指数的映射$i$到存在有效值的位置。 
2. 对于每个指数$i$，构建一个排序的索引列表，其中数组包含$i$次幂。 这使我们能够快速检查间隔的覆盖范围。 
3. 对于固定起始位置$l$，我们想要最小的$r$这样每个指数都来自$1$到$k = r-l+1$内部支持$[l, r]$。 这转化为检查每个指数$i$，下一次出现的是否$i$次方时或之后$l$位于段内。 
4. 维护指针$r$只会向前迈进。 对于每个$l$, 逐步扩展$r$直到满足当前段长度之前的所有所需指数层。 如果范围内缺少所需的指数，则该段无法进一步扩展。 
5. 计算从以下位置开始的所有有效段：$l$通过添加有效端点的数量。 

不明显的部分是增加$l$只是降低了要求，所以指针$r$永远不需要向后移动。 这允许线性扫描。 

### 为什么它有效

 对于任何段，有效性仅取决于每个指数级别内部是否至少有一个代表。 对于线段的扩展而言，这是一个单调属性：添加元素只能引入更多机会来满足缺失的指数级别，而永远不会删除它们。 因此，一旦某个段在一定时间内有效$r$，延伸$r$保持有效性，并且同样缩小$l$只能让条件更加严格。 这种单调性使得两指针遍历无需重新访问状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_kth_power(x, k):
    if k == 1:
        return True
    lo, hi = 1, int(x ** (1 / k)) + 2
    while lo <= hi:
        mid = (lo + hi) // 2
        val = mid ** k
        if val == x:
            return True
        if val < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return False

def factor_exponents(x):
    res = []
    for k in range(1, 32):
        if (1 << k) > x and k > 1:
            break
        if is_kth_power(x, k):
            res.append(k)
    return res

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    max_k = 30

    for i, v in enumerate(a):
        for k in range(1, max_k + 1):
            if k == 1:
                pos.setdefault(k, []).append(i)
            else:
                if is_kth_power(v, k):
                    pos.setdefault(k, []).append(i)

    for k in pos:
        pos[k].sort()

    def has_k(k, l, r):
        if k not in pos:
            return False
        arr = pos[k]
        # binary search for any index in [l, r]
        lo, hi = 0, len(arr) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if arr[mid] < l:
                lo = mid + 1
            else:
                hi = mid - 1
        return lo < len(arr) and arr[lo] <= r

    ans = 0
    r = 0

    for l in range(n):
        r = max(r, l)
        k = 1
        while True:
            ok = True
            for i in range(1, k + 1):
                if not has_k(i, l, r):
                    ok = False
                    break
            if ok:
                k += 1
            else:
                break

        ans += (k - 1)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现依赖于枚举元素表现为完美幂的所有指数级别。 对于每个指数，我们存储排序位置并使用二分搜索来验证段是否包含至少一个有效元素。 

外环固定左端点。 内部扩展试图增加最大可达到的长度$k$，这对应于增量检查指数覆盖范围。 里面的二分查找`has_k`确保我们可以有效地测试覆盖范围。 

一个微妙的点是初始化$r$。 在更优化的解决方案中，$r$将在各个迭代之间共享$l$，但这里它是通过单调展开在概念上有效地重新计算的。

 ## 边缘情况

 对于像这样的数组$[16]$，该算法将其标记为对所有指数有效，其中 16 是完全幂：2、4 等。$[16]$总是计算一次，因为指数 1 基本满足。 

对于像这样的数组$[2, 4]$，由于 4 是平方，所以满足指数 2，但指数 3 立即失败，因此无法扩展长于 2 的线段。 

对于具有稀疏高幂的数组，例如$[2, 3, 4096, 5]$，只有包含 4096 的段才能满足更高的指数要求，并且算法正确地将有效段限制为包含足够功率深度的段。
