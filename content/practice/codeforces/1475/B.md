 ## 解决方案
 ## 问题理解

 我们得到一个数字$n$，我们想知道是否可以通过将一些 2020 和一些 2021 相加来构建它。 

如果我们选择$a$2020 年的副本和$b$2021 的副本，则结果值为$$2020a + 2021b$$任务只是判断是否存在非负整数$a$和$b$产生给定的$n$。 

输入最多包含$10^4$测试用例。 每个值$n$至多是$10^6$。 由于可能有很多测试用例，因此我们需要一个基本上每个查询时间恒定的算法。 对于每个测试用例仅执行少量算术运算的方法是理想的。 

一些边缘情况很容易被忽略。 

考虑：```
1
2020
```正确答案是：```
YES
```因为2020年允许一份。 错误地要求两个数字至少出现一次的解决方案将会失败。 

考虑：```
1
2019
```正确答案是：```
NO
```因为每个可用的数字都至少是 2020。任何正组合都必须至少是 2020。 

考虑：```
1
2021
```正确答案是：```
YES
```因为单2021年有效。 

一个更微妙的情况是：```
1
4040
```正确答案是：```
YES
```自从$4040 = 2020 + 2020$。 如果粗心的解决方案只在 2021 年之前检查整除性，就会错误地拒绝它。 

关键的挑战是找到一个数学特征来避免搜索许多组合。 

## 方法

 最直接的方法就是暴力破解。 我们可以尝试所有可能的 2021 数字。 假设我们选择$b$2021 年的副本。剩余价值是$$n - 2021b$$如果余数为非负且可被 2020 整除，那么我们就找到了有效的表示。 

这种方法是正确的，因为每一种可能的表示都恰好对应于一个值$b$，我们检查所有这些。 

问题是效率。 为了$n = 10^6$，可能值的数量$b$大致是$$\frac{10^6}{2021} \approx 495.$$即使这个值实际上对于这个问题来说已经足够小了，所以暴力解决方案将会通过。 但有一个更清晰的观察，可以将整个问题简化为一些算术运算。 

重写表达式：$$n = 2020a + 2021b$$自从$2021 = 2020 + 1$,$$n = 2020a + (2020+1)b$$

$$n = 2020(a+b) + b$$让$$k = a+b.$$然后$$n = 2020k + b.$$划分时$n$到 2020 年：$$n = 2020 \left\lfloor \frac{n}{2020} \right\rfloor + (n \bmod 2020).$$与之前的表格相比，我们看到$b$必须等于余数。 

余数固定：$$b = n \bmod 2020.$$商为：$$k = \left\lfloor \frac{n}{2020} \right\rfloor.$$自从$a = k-b$，我们需要$$k \ge b.$$将商和余数代入得到一个非常简单的条件：$$\left\lfloor \frac{n}{2020} \right\rfloor \ge n \bmod 2020.$$如果这个不等式成立，那么答案是肯定的。 否则，答案是否定的。

 ## 算法演练

 1.读取数值$n$。 
2. 计算商：$$q = n // 2020$$这代表了最大可能值$a+b$。 
3. 计算余数：$$r = n \% 2020$$任何有效的表示都必须准确使用$r$2021 年的副本。 
4. 检查是否$$q \ge r.$$如果为真，那么我们可以选择$b=r$和$a=q-r$，均为非负数。 
5、输出`"YES"`当不等式成立时，否则输出`"NO"`。 

### 为什么它有效

 每个表示都可以写成$$n = 2020(a+b) + b.$$除以 2020 后的余数是唯一确定的，因此任何有效的表示都必须具有$$b = n \bmod 2020.$$商给出$$a+b = n // 2020.$$对于有效的解决方案，$a$必须是非负数：$$a = (n // 2020) - (n \bmod 2020) \ge 0.$$这个条件既是必要的，也是充分的。 如果成立，我们可以显式构造$a$和$b$。 如果失败，则没有非负选择$a$存在。 因此算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        q = n // 2020
        r = n % 2020

        if q >= r:
            ans.append("YES")
        else:
            ans.append("NO")

    sys.stdout.write("\n".join(ans))

solve()
```实现直接遵循数学推导。 

商`q`表示如果将每个 2021 年视为 2020 年再加上 1，则表示总任期数。余数`r`表示需要多少个额外的 1，这正是 2021 的数量。 

验证的唯一条件是是否存在足够的总条款来容纳这些`r`2021 年的副本。这正是支票`q >= r`。 

不存在溢出问题，因为最大值`n`只是$10^6$，远低于 Python 的整数限制。 该实现仅对每个测试用例执行整数除法、取模和比较。
