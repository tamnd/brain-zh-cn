 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并且 Polycarp 将一个数组定义为漂亮的，如果对于每对不同的元素，一个可以除另一个。 换句话说，对于所有$i \ne j$， 任何一个$a_i$划分$a_j$或者$a_j$划分$a_i$。 任务是删除尽可能少的元素以使数组变得漂亮。 

输入由多个测试用例组成。 每个测试用例都提供数组的长度和数组元素本身。 每个测试用例的输出是一个整数：必须删除的元素的最小数量。 

约束条件允许$n$最多$2 \cdot 10^5$和元素值高达$2 \cdot 10^5$。 检查所有对的可整性的简单方法需要$O(n^2)$每个测试用例的操作，这在上限是不可行的，因为$n^2$可能是$4 \cdot 10^{10}$。 因此我们需要一个大致的算法$O(n \log n)$或者$O(n \sqrt{m})$在哪里$m$是最大值，以有效处理最大的输入。 

一个微妙的边缘情况是存在相同数量的多个副本。 例如，$[2,2,8]$已经很美了，因为所有的双$2$s 彼此分开，并且$2$划分$8$。 任何不能正确处理重复项的算法都可能错误地删除元素。 另一种情况是当所有元素都是没有公倍数的素数时，例如$[3,5,7]$; 最佳解决方案是删除除一个元素之外的所有元素。 

## 方法

 蛮力方法检查每一对并尝试贪婪地删除违反整除性的元素。 这是正确的，但太慢了。 对于每个元素，需要验证与所有其他元素的整除性$n-1$元素，产生$O(n^2)$每个测试用例。 This becomes unacceptable when$n$方法$2 \cdot 10^5$。 

关键的观察是，如果数组由某个基数的倍数组成，那么它就会变得漂亮。 我们可以计算每个数字，而不是检查所有对$x$数组中有多少个数字可以被整除$x$或倍数$x$。 如果我们为每个潜在的基数计算以它的倍数结尾的美丽子集的最大大小，则要删除的最小元素是$n$减去这个最大子集大小。 

这将问题转化为一种筛法：我们从小到大迭代数字，并累积可被每个数字整除的数字计数。 然后我们跟踪可以形成整除链的最大数字数。 我们的见解是，一个数字只能通过其倍数来帮助形成一个漂亮的数组，因此我们不需要检查所有对，只需检查每个数字的倍数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳| O(n + m log m) | O(n + m log m) | O(米) | 已接受 |

 这里，$m$是最大数组元素值（$2 \cdot 10^5$）。 筛子确保我们有效地处理每个数字及其倍数。 

## 算法演练

 1. 使用频率数组计算数组中每个数字的出现次数`freq`大小达到最大元素$2 \cdot 10^5$。 这使我们能够知道每个数字出现了多少次。 
2. 初始化一个`dp`相同大小的数组，其中`dp[x]`表示以数字结尾的美丽子集的最大大小`x`。 最初，`dp[x] = freq[x]`因为子集只包含`x`重复`freq[x]`时光是平凡的美丽。 
3. 迭代所有数字`x`从 1 到`max_val`。 对于每个数字，迭代其倍数`k*x`。 更新`dp[k*x] = max(dp[k*x], dp[x] + freq[k*x])`。 这会沿倍数传播最大链大小。 
4. 处理完所有数字后，求出其中的最大值`dp`对应于最大的美丽子集。 要删除的元素的最小数量是`n - max(dp)`。 

这样做的原因是，通过从较小的数字迭代到较大的数字并沿倍数传播计数，我们正在有效地构建尽可能最大的可分链。 每个数字都会对其倍数链做出贡献，而不会违反整除性要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    MAX_A = 2 * 10**5
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = [0] * (MAX_A + 1)
        for num in a:
            freq[num] += 1

        dp = freq[:]
        for x in range(1, MAX_A + 1):
            if dp[x] == 0:
                continue
            for k in range(2, (MAX_A // x) + 1):
                dp[k * x] = max(dp[k * x], dp[x] + freq[k * x])
        print(n - max(dp))

if __name__ == "__main__":
    solve()
```第一部分有效地读取输入。`freq`计算每个数字的出现次数。`dp`从每个数字的计数开始，代表仅该数字的平凡美丽子集。 嵌套循环沿倍数传播链大小。 最后，`n - max(dp)`给出所需的移除数量。

 ## 边缘情况

 对于数组`[3,5,7]`,`freq`将每个计数为 1。最初`dp[3]=1`,`dp[5]=1`,`dp[7]=1`。 没有倍数进一步传播。 最大的美丽子集大小为 1，移除量 =`3-1=2`。 这演示了处理不同数字之间不可整除的数组。 

为了`[2,2,8]`,`dp[2]=2`,`dp[4]=0`,`dp[8]=1`。 传播自`2`,`dp[4]=2`,`dp[8]=3`。 最大链尺寸为 3
