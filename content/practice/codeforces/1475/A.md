 ## 解决方案
 ## 问题理解

 我们被要求确定给定的整数是否$n$有一个大于一的奇数除数。 换句话说，我们想知道是否存在奇数$x > 1$划分$n$均匀。 如果$n$能被这样的数整除，答案是“YES”； 否则，为“否”。 

输入由多个测试用例组成，每个测试用例都有一个整数$n$。 最大可能$n$可以达到$10^{14}$，这远远超出了尝试每个数字的天真的方法的限制$n$作为潜在的除数。 鉴于最多可以有$10^4$测试用例，任何线性的方法$n$会太慢。 我们需要在每个查询的对数或恒定时间内工作的东西。 

边缘情况包括小数和 2 的幂。 例如，如果$n = 2$，没有大于 1 的奇数约数，所以答案一定是“NO”。 如果$n = 3$，它本身就是一个大于一的奇数，所以答案是“YES”。 对于二的幂，例如$n = 16$，所有约数也是二的幂，因此是偶数； 这些应该返回“NO”。 在幼稚的实现中，将 2 的幂误认为具有奇数除数是一个常见的错误。 

## 方法

 蛮力方法是检查从 3 到$n$（跳过偶数）看它是否能整除$n$。 这是有效的，因为如果任何数字整除$n$，它是一个奇数除数。 然而，最坏的情况发生在$n = 10^{14}$，大致要求$5 \cdot 10^{13}$分区检查，这是完全不可行的。 这显然超出了时间限制。 

关键的观察是一个整数$n$当且仅当它是 2 的幂时，没有大于 1 的奇数除数。 二的幂是以下形式的数字$2^k$，并且它们的所有约数本身都是 2 的幂，这意味着除了 1 之外它们都是偶数。任何其他数字$n$要么本身具有奇数因子，要么可以分解为奇数乘以 2 的幂。 这种见解将问题简化为检查是否$n$是二的幂。 

使用按位技巧可以有效地检查一个数字是否为 2 的幂。 对于正整数$n$， 如果$n \& (n-1) == 0$， 然后$n$是二的幂。 这是可行的，因为二的幂在二进制中恰好设置了一位。 否则，该数字有一个大于 1 的奇数因子，我们返回“YES”。

 ## 算法演练

 1.读取测试用例数量$t$。 这定义了我们需要顺序处理多少个数字。 
2. 对于每个测试用例，读取整数$n$。 我们将检查是否$n$有一个大于一的奇数除数。 
3. 应用按位二次幂测试：计算$n \& (n-1)$。 如果这等于零，$n$是 2 的幂，我们输出“NO”，因为它没有大于 1 的奇数除数。 
4. 如果$n \& (n-1)$不为零，输出“YES”。 这表明$n$不是 2 的纯幂，这意味着它有一个大于 1 的奇数除数。 

为什么它有效：二的幂是唯一所有非平凡除数都是偶数的整数。 通过检查二进制表示，按位技巧可以直接识别该属性。 任何未通过检查的数字都必须包含奇数因子，这保证了奇数除数大于 1。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n & (n - 1) == 0:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    main()
```该代码首先使用有效读取所有输入`sys.stdin.readline`。 我们循环遍历每个测试用例并应用按位检查。 使用`n & (n-1)`很关键； 一种朴素的模方法，例如`n % 2`或者迭代除数会超出时间限制。 该代码可以正确处理非常大的数字，因为 Python 整数是任意精度的。

 ## 边缘情况

 该算法正确处理尽可能小的数字。 为了$n = 2$，按位测试返回零，产生“NO”。 对于奇数，例如$n = 3$或者$n = 9$，测试失败，正确识别存在大于 1 的奇数除数。 对于二的幂，即使是非常大的幂，例如$n = 2^{40}$，检查尺度无需循环或递归，保证了速度和正确性。 不存在差一错误，因为按位运算精确地检测了 2 的幂的一位模式。
