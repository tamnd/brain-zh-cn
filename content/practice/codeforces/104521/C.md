 ## 解决方案
 ## 问题理解

 我们得到了一组小熊猫，但我们只知道每对熊猫之间的距离，而不是知道它们在直线上的位置。 另外，我们还得到了数轴上实际坐标的排序列表。 任务是决定哪只熊猫去哪个坐标，以便所有成对距离与指定坐标之间的绝对差相匹配。 

换句话说，在给定位置上存在未知的 pandas 排列，使得对于每对 pandas，输入矩阵中的距离等于其指定点之间的几何距离。 我们必须恢复任何有效的分配。 

约束足够严格，每个测试用例的二次重建是可以接受的，但是任何三次重建或涉及每个三重节点的重复重计算都会失败。 所有 n 的总和最多为 1000，这立即表明每个测试用例的 O(n^2) 是安全的，而 O(n^3) 在技术上也是可接受的，但在 Python 中是不必要的和有风险的。 

对称性产生了一个微妙的问题。 如果配置有效，则沿线颠倒整个顺序会产生另一个有效的解决方案。 这意味着没有唯一的答案，任何一致的重建就足够了。 第二个微妙之处是距离本身并不能直接显示坐标，只能显示相对顺序。 

一个天真的错误是假设根据与 pandas 1 的距离对 pandas 进行排序会产生正确的顺序。 只要 panda 1 不是线段的端点，此操作就会失败。 

例如，假设三只熊猫位于坐标0、5、10处，而熊猫1位于坐标5处，则与熊猫1的距离均为5，因此无法区分哪一侧是左哪一侧。 天真的排序会错误地折叠结构或任意破坏关系，从而违反其他成对距离。 

## 方法

 暴力方法会尝试通过尝试所有排列并检查距离矩阵是否与引入的绝对差相匹配来将 pandas 分配到位置。 这在概念上很简单：对于每个排列，验证所有成对距离。 光是验证就花费了O(n^2)，而且有n个！ 排列，这使得这种方法即使对于 n = 10 也是完全不可行的。 

关键的结构见解是，一旦我们确定了两个端点，线度量空间上的点就完全确定了反射和平移。 如果我们选择一个端点 A，距离它最远的点必须是相反的端点 B。一旦这两个锚点固定，每个其他点沿着该轴都有一个唯一的坐标，可以纯粹根据距离计算。 

这样做的原因是，在真正的线度量中，端点之间的路径是唯一的，并且所有其他点都位于该线上。 距离关系强制对该线上进行一致的投影。 

这将问题从组合分配简化为确定性坐标重建，然后进行排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!·n^2) | O(n!·n^2) | O(n) | 太慢了|
 | 端点重构| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 我们利用这些点恰好位于一条直线上的事实。 

## 算法演练

 1. 选择任意一只熊猫，为了方便起见，选择熊猫 0，然后使用距离矩阵找到距离它最远的熊猫。 将此称为 panda A。距离直线度量中任意点最远的点必须是端点之一，因为端点使偏心率最大化。 
2. 从 A 开始，再次扫描所有 pandas，找到与 A 距离最大的 pandas，将其称为 B。这保证了 A 和 B 是直线的两个端点。 
3. 将 A 和 B 视为定义轴。 对于每个 panda i，使用以下公式计算其坐标

x[i] = (d[A][i] - d[B][i] + d[A][B]) / 2。 

该表达式来自求解方程组 |x[i] - x[A]| 和 |x[i] - x[B]| 假设 A 和 B 是直线的极值。 
4. 根据计算出的坐标对 pandas 进行排序。 这将恢复它们在线上从左到右的顺序，直至数值稳定。 
5. 将排序后的 pandas 按顺序分配给给定的排序位置 p1 < p2 < ... < pn。 输出对应的索引。 

### 为什么它有效

 正确性取决于这样的事实：在一维度量空间中，任何点 i 都位于端点 A 和 B 之间的唯一线段上，因此它的位置完全由它到 A 和 B 的距离决定。导出的坐标公式相当于将 i 投影到 A 和 B 定义的轴上。一旦坐标与所有成对距离一致，对它们进行排序就必须符合真实的几何顺序，因为真实位置 p 已经沿着同一轴排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        d = [list(map(int, input().split())) for _ in range(n)]

        if n == 1:
            print(1)
            continue

        A = 0
        for i in range(n):
            if d[0][i] > d[0][A]:
                A = i

        B = A
        for i in range(n):
            if d[A][i] > d[A][B]:
                B = i

        dab = d[A][B]

        coords = []
        for i in range(n):
            x = (d[A][i] - d[B][i] + dab) / 2
            coords.append((x, i + 1))

        coords.sort()

        ans = [0] * n
        for i in range(n):
            ans[i] = coords[i][1]

        print(*ans)

if __name__ == "__main__":
    solve()
```该实现首先构建每个测试用例的距离矩阵。 然后，它通过选择距任意起点最远的节点来识别端点 A，并通过最大化距 A 的距离来识别端点 B。 

直接应用坐标公式，无需除以 2 之外的整数舍入技巧。由于保证输入是有效的线度量，因此所有中间值都是一致的，并且除法产生整数。 

最后，通过这些重建的坐标进行排序会产生正确的排序，该排序会直接映射到排序的位置上。 

一个常见的实现陷阱是跳过端点 B 的第二次扫描。如果没有两个端点，坐标就会变得不明确，并且排序会退化为不正确的聚类。 

## 工作示例

 考虑一个小配置，其中 pandas 位于隐藏位置 0、3、7。距离矩阵对这些差异进行编码。 

我们选择 A 作为距离任意节点最远的节点，假设 A 对应位置 0。那么 B 就成为位置 7 处的节点。 

| 步骤| 一个 | 乙| d[A][i] | d[A][i] | d[B][i] | d[B][i] | 坐标 x[i] |
 | ---| ---| ---| ---| ---| ---|
 | 初始化| 0 | - | - | - | - |
 | 选择A| 0 | - | 最大从 0 | - | - |
 | 选择B | 0 | 2 | - | 最大 A | - |
 | 计算 i=0 | 0 | 2 | 0 | 7 | 0 |
 | 计算 i=1 | 0 | 2 | 3 | 4 | 3 |
 | 计算 i=2 | 0 | 2 | 7 | 0 | 7 |

 这证实了坐标重建了原始排序。 

现在考虑一种对称情况，其中端点的解释相反。 计算出的坐标只是翻转符号或移位，但反向排序保持相同，这仍然有效。 

| 步骤| 一个 | 乙| 坐标（未排序）| 排序顺序 |
 | ---| ---| ---| ---| ---|
 | 端点选择| 右端| 左端| 反转值 | 颠倒顺序|

 这表明该算法可以容忍反射。

 ## 边缘情况

 当所有 pandas 等距时，多个 pandas 可以共享相对于非端点枢轴的相同距离模式。 基于端点的重建避免了这种歧义，因为端点始终具有唯一的最大偏心率。 

在选择中点作为初始参考的小三点线上，按距离进行简单排序会失败，因为两侧看起来是对称的。 端点策略通过从四肢锚定，迫使坐标系不对称来解决这个问题。 

当n = 1时，算法必须短路，因为不需要端点选择或划分，并且需要直接输出单个panda来保证正确性。
