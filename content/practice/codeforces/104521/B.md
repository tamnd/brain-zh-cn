 ## 解决方案
 ## 问题理解

 我们正在构建一个长度为的二进制字符串`n`，我们希望它与其相反的部分完全不同`k`职位。 对于每个位置`i`，我们比较字符`i`角色处于镜像位置`n-i+1`。 每一个不匹配都会对分数贡献一分，该问题将其称为回文性。 

关键的观察是位置是对称配对的：位置`i`总是与`n-i+1`。 所以这个字符串实际上是由独立的镜像对组成的，除了中间的字符`n`很奇怪。 每对贡献之一`0`（如果双方都匹配）或`2`（如果它们不同），因为一端的不匹配自动意味着另一端的不匹配。 

这立即限制了`k`甚至是可能的。 由于每个不匹配对都会产生两个差异，`k`必须是偶数，且不能超过`n`因为只有`n`职位总计。 什么时候`n`很奇怪，中间的字符永远不会促成回文，因为它与自身匹配。 

天真的尝试会尝试通过贪婪地放置不匹配甚至暴力破解所有二进制字符串并检查分数来构造字符串。 那会爆炸`2^n`，这对于`n`最多`2·10^5`。 另一种常见的错误方法是尝试独立翻转各个位置，忘记翻转是通过镜像对耦合的。 这会导致过度计数或不可能的配置`k`与配对贡献很奇怪或结构上不相容。 

边缘情况出现时`k`很奇怪，没有任何建筑存在。 另一个是当`k`大于`n`，这也是不可能的，因为即使所有对完全不匹配最多也只能产生`n`跨职位计数不匹配。 

## 方法

 暴力破解的观点是生成每个长度的二进制字符串`n`，计算其反向，并计算不匹配的位置。 这可以正确识别有效答案，但需要付出代价`O(n·2^n)`即使对于中等程度的人来说，这也远远超出了任何限制`n`。 

关键的结构见解是字符串分解成镜像对`(i, n-i+1)`。 每对行为独立并做出贡献`0`或者`2`到分数。 因此，问题归结为精确选择`k/2`配对使不相等，而其余部分保持相等。 一旦看到这一点，构建就变得直接了：我们只需要在每对中分配值来强制匹配或不匹配。 

这减少了从字符串的指数搜索到对的线性构造的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·2^n) | O(n·2^n) | O(n) | 太慢了|
 | 结对建设| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 检查是否`k`是有效的。 如果`k`为奇数，立即输出`NO`因为每次不匹配都会产生成对的位置，因此不可能出现奇数总数。 如果`k > n`，也输出`NO`。 
2. 通过设置将目标转换为pair形式`pairs = k / 2`。 我们制作的每一对都对分数贡献了 2，所以我们需要`pairs`不匹配的对称对。 
3.初始化一个长度的数组`n`充满`'0'`。 这提供了一个干净的基线，其中所有对当前都匹配且贡献为零。 
4. 迭代第一个`n/2`镜像对。 对于每对`(i, n-i-1)`，如果我们仍然需要不匹配的对，则分配`s[i] = '0'`和`s[n-i-1] = '1'`，消耗一单位的不匹配预算。 
5. 如果没有剩余不匹配预算，则保持剩余对相同（`'0'/'0'`），保持零贡献。 
6. 如果`n`是奇数，保留中间元素为`'0'`因为它不影响分数。 
7. 输出构造好的字符串。 

### 为什么它有效

 每个镜像对都是独立的，其对回文性的贡献固定为`0`或者`2`。 通过准确选择`k/2`对不同，我们构造一个配置，其总不匹配计数恰好是`k`。 不同对之间没有相互作用，因此贪婪地从左到右分配不匹配不会违反可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        if k % 2 == 1 or k > n:
            print("NO")
            continue

        s = ['0'] * n
        need = k // 2

        i, j = 0, n - 1
        while i < j and need > 0:
            s[i] = '0'
            s[j] = '1'
            need -= 1
            i += 1
            j -= 1

        print("YES")
        print("".join(s))

if __name__ == "__main__":
    solve()
```在此实现中，构造循环仅在对称对上运行，确保我们永远不会意外修改奇数长度字符串中的中间元素。 变量`need`强制执行不匹配对的确切数量，一旦达到零，所有剩余的对保持相同。

    t = int(data[0])
    idx = 1
    out = []
    for _ in range(t):
        n = int(data[idx]); k = int(data[idx+1]); idx += 2

            s[j] = '1'
            need -= 1
            i += 1
            j -= 1
        out.append("YES")
        out.append("".join(s))
    return "\n".join(out)

 ## 边缘情况

 当`n = 1`，没有镜像对，因此任何不匹配计数必须为零。 该算法自然会拒绝任何积极的`k`因为它至少需要一对。 

什么时候`k = 0`，构造循环永远不会运行，使字符串完全对称。 这正确地产生了零回文性。 

什么时候`k = n`，所有可能的对都被用作不匹配，循环填充直到耗尽。 如果`n`为奇数，中间元素无关，不影响有效性，因此该构造仍然成立。 

这些案例证实该算法能够一致地处理极端情况和奇偶校验约束。
