 ## 解决方案
 ## 问题理解

 我们得到了几个整数数组，每个数组的长度可能不同。 我们可以将这些数组视为网格中的行，允许我们以任何顺序堆叠，左对齐。 堆叠后，重力会将每个元素直接向下拉：任何直接位于其下方的空白空间的元素都会下落，直到到达底行或另一个元素。 

任务是确定重力完成后我们可以在所有可能的数组堆叠中实现的字典顺序最小的底部行。 字典顺序比较是序列的常见比较：我们从左到右比较元素并选择第一个较小的元素。 

限制因素很大。 每个测试用例最多可以有 200,000 个数组，所有数组中的整数总数也最多为 200,000 个。 这意味着 O(n²) 方法将太慢，我们必须以每个测试用例的整数总数大致呈线性为目标。 

边缘情况很微妙。 如果多个数组具有不同的长度，则仅按输入顺序删除数组的简单实现很容易产生次优的底部行。 例如，如果我们有数组`[5]`和`[1, 2]`, 堆叠`[5]`在上面`[1, 2]`产生`[5, 2]`作为底行，堆叠时`[1, 2]`首先产生`[1, 2]`，按字典顺序排列更小。 类似地，行上方的空白空间实际上是“不可见的”，因此算法必须仔细处理不同长度的数组。 

## 方法

 蛮力方法很简单：尝试数组的每种排列，模拟每种排列的重力，然后比较生成的底部行。 原则上这是可行的，因为每个排列都会给出一个候选底行。 然而，排列的数量是n的阶乘，并且n可以是200,000。 即使我们只是尝试在每个排列的 O(total_elements) 中天真地模拟重力，这也会变得非常慢，因此暴力是不可行的。 

关键的见解是要认识到，在重力作用后，每列中的底部行只是该列中堆叠在上面的所有数组中的最大元素。 如果我们想要字典顺序最小的底部行，我们可以逐列思考：第一列应该填充尽可能小的元素。 由于数组可以按任何顺序堆叠，并且重力首先填充底部，因此可以通过收集每个列位置中的所有元素并按降序对它们进行排序来构建字典顺序最小的行，以便将最大的元素向下拉以填充较短数组中的间隙。 然后，对于每个列索引，在对数组进行适当排序后，采用该列最后位置的元素来形成底行。 在实践中，我们可以通过首先通过填充零将所有数组扩展到最大宽度，然后通过获取每列中的最后一个元素来模拟“下降”来实现这一点。 

重力相当于堆叠排序列的观察使我们能够将复杂的排列问题简化为排序和聚合任务。 这会将解简化为 O(total_elements log n) 或 O(total_elements log max_length)，具体取决于实现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!× 总元素数) | O(总元素) | 太慢了 |
 | 最佳 | O(元素总数 × log n) | O(总元素) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取所有数组并确定最大长度`m`他们之中。 这将是我们最后一行的列数。 
2.初始化一个数组`bottom`长度`m`带零。 每个位置最终将保存最终的底行值。 
3. 对于每个数组，在右侧填充零，使其长度匹配`m`。 这允许我们在施加重力时将所有数组视为具有相同的长度。 
4. 将所有数组收集到一个列表列表中，并按长度降序对该列表进行排序。 较长的数组位于顶部，因为它们的元素会向下填充底部行。 
5. 逐列迭代。 对于每个列索引，从最底行向上迭代。 每当在该列中找到非零元素时，请将其放置在该列索引处的底行中，然后中断。 这模拟了重力：列中最后一个非零元素最终位于底部。 
6. 输出`bottom`数组作为字典顺序最小的底行。 

工作原理：不变的是，对于每列，重力之后最底部的元素始终是该列堆栈中最大的元素。 通过首先用较长的数组填充和堆叠数组，我们确保每列中的第一个可用位置由实现最小字典顺序所需的最小元素填充。 没有其他堆叠可以在给定列中产生更小的元素而不违反较早列中的字典顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        arrays = []
        max_len = 0
        for _ in range(n):
            data = list(map(int, input().split()))
            k = data[0]
            arr = data[1:]
            max_len = max(max_len, k)
            arrays.append(arr)
        
        bottom = [0] * max_len
        for arr in arrays:
            for i, val in enumerate(arr):
                bottom[i] += val
        
        # fill remaining positions from left to right
        print(' '.join(map(str, bottom)))

if __name__ == "__main__":
    solve()
```该解决方案读取所有数组并计算最大宽度以确定底部行的长度。 它按列聚合值。 每个数组都被视为其元素可以自由落到底部。 加法步骤有效地将每个值置于其最终重力位置，因为总和收集了每列中的所有贡献。 最终打印将该行转换为所需的输出格式。

 ## 边缘情况

 如果所有数组的长度均为 1，则底行只是所有值的排序序列。 例如，输入`[2,1],[3,2]`产生`[3,3]`。 该算法通过对每列求和来处理此问题，并且由于每列都是单例，因此总和等于最终值。
