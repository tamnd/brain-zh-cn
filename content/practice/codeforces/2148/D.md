 ## 解决方案
 ## 问题理解

 我们得到了一系列字段，每个字段都包含一定数量的蒲公英。 我们可以选择访问这些字段的顺序，并且每个字段只访问一次。 在田野中移动时，我们维护一个二进制状态机，即割草机，它以关闭状态启动。 

在处理某个字段之前，我们检查该字段中蒲公英的数量是奇数还是偶数。 如果是奇数，割草机就会翻转其状态。 在这种可能的翻转之后，如果割草机打开，我们会清除该田地中的所有蒲公英并获得其全部价值。 如果关闭，则该场不会做出任何贡献。 

任务是选择田地的排序，使收集到的蒲公英总数最大化。 

所有测试用例的 n 约束总和最多为 2 × 10^5。 这意味着任何比每个测试用例的线性更差或比每个元素的线性更差并且开销很大的解决方案都将陷入困境。 每个测试用例排序一次或每个元素进行恒定数量的簿记的解决方案是可以接受的。 

当所有数字都是偶数时，会出现微妙的边缘情况。 在这种情况下，割草机永远不会翻转，因为奇偶校验永远不会改变。 从一开始，每个字段都会被跳过，并且答案始终为零。 另一个角点是当恰好有一个奇值时。 该单个奇数值决定了整个序列中唯一的状态转换，因此排序变得高度受限。 

## 方法

 一种直接的方法是尝试字段的所有排列并模拟割草机过程。 对于每个排列，我们保持当前状态，迭代字段，遇到奇数时翻转，并在割草机打开时累积收集的蒲公英。 这是正确的，因为它直接反映了规则。 然而，有n！ 排列，每次模拟的成本为 O(n)，导致每个测试用例需要 O(n · n!) 次操作，即使 n 小到 15，这也是完全不可行的。 

关键的观察是，对于状态转换唯一重要的是奇偶性，而不是大小。 每个奇数值都会翻转割草机，而偶数则不会。 这意味着奇偶校验事件的顺序完全决定了割草机何时打开或关闭。 仅当我们处于开启状态时，实际值才重要。 

我们可以将问题重新解释为选择一个顺序来控制翻转何时发生，从而控制割草机何时打开。 如果我们查看所有奇数值，每个奇数值都会翻转一次状态。 这表明该结构取决于我们如何相对于大值排列奇数。 

考虑这个问题的一个有用方法是将奇数和偶数分开。 即使值也不会影响状态，因此它们可以放置在任何地方，而无需更改翻转模式。 然而，奇数值定义了一系列切换。 如果我们将访问奇怪的田地视为切换事件，则割草机会在奇怪的情况下交替关闭和打开。 

为了最大化增益，我们希望将尽可能多的大值放置在割草机打开的段中。 由于事件不会扰乱状态，因此它们最好用作盈利细分市场中的“填充物”。 

最佳结构简化为决定如何开始奇数值序列。 如果我们从奇数田地开始，割草机首先翻转并启动，这意味着直到下一个奇数田地的所有后续田地都将根据奇偶校验计数成为收集的候选者。 这导致了一种贪婪的策略，我们以最大化初始激活的方式放置奇数元素，并保持割草机对高价值片段的操作。

最后的简化是，我们只需要决定奇数值之间的最佳前缀排列：一旦放置了第一个奇数，我们就通过确保在割草机打开时尽可能频繁地访问它们来最大化所有剩余值的贡献。 这导致排序和基于奇偶校验结构的贪婪累积。

 ## 算法演练

 1. 将数组分为奇数和偶数。 偶数值不会改变割草机状态，因此它们的唯一作用是在割草机已启动时做出贡献。 
2. 按降序对所有值进行排序。 这确保了每当割草机启动时，我们都会优先考虑首先获得最大的可用贡献。 由于偶数不影响奇偶性，因此它们的位置可以自由交错。 
3. 计算有多少个奇数。 这决定了在任何完整排序中发生多少次状态翻转。 
4. 如果没有奇数，则立即返回 0，因为割草机永远不会启动。 
5. 否则，关键的决定是选择第一个奇数出现的时间。 尽早放置最大的奇数，以便尽快启动割草机，从而从后续值中实现最大积累。 
6. 第一次激活后，割草机在每个奇数上交替状态。 我们通过迭代排序值并在遇到奇数时切换状态来贪婪地模拟这种情况。 
7. 当割草机处于开启状态时，将当前值添加到答案中。 

### 为什么它有效

 改变割草机状态的唯一机制是遇到奇数值，并且无论位置如何，每个奇数值都恰好贡献一次切换。 这使得任何排列的切换数量都是固定的，只有它们的顺序很重要。 通过尽早放置较大的值并确保第一次切换尽早发生，我们可以最大限度地增加割草机打开时评估的高值段的数量。 由于偶数保留状态并且不干扰切换，因此它们充当可自由移动的重量，可以吸收到最佳可用的分段中，而不会改变可行性。 这减少了控制贪婪排序序列中奇偶校验转换的问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # sort descending so we always consider large values first
        a.sort(reverse=True)
        
        odd_count = sum(x % 2 for x in a)
        
        if odd_count == 0:
            print(0)
            continue
        
        on = False
        ans = 0
        
        for x in a:
            if x % 2 == 1:
                on = not on
            if on:
                ans += x
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先按降序对所有字段进行排序，确保如果割草机处于活动状态，我们首先优先考虑较大的贡献。 然后，我们对奇数元素进行计数，以处理无法激活的退化情况。 

主循环模拟以这种贪婪顺序访问字段。 每个奇数值都会在考虑贡献之前翻转割草机状态，从而完全匹配问题规则。 如果割草机在翻转后启动，则会添加全部价值。 

微妙的一点是循环内的操作顺序：奇偶校验必须在添加值之前进行，因为问题表明割草机在切割之前切换。

 ## 边缘情况

 当所有值都为偶数时，割草机永远不会翻转状态。 该实现通过奇数零计数尽早检测到这一点并直接返回 0，从而避免从未激活状态的任何错误累积。 

当恰好存在一个奇数时，排序会将其置于较大的值之间，但第一次遇到该奇数会翻转状态，之后的所有内容都保持一致。 该跟踪确保恰好发生一次激活，并且所有后续贡献仅取决于该单个转换。 

当所有值都是奇数时，每一步都会翻转状态。 排序遍历产生交替贡献，其中最佳排序相当于在交替奇偶校验上最大化前缀和，并且模拟正确地捕获了这种交替，而不需要额外的结构。
