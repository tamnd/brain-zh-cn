 ## 解决方案
 ## 问题理解

 我们正在沿着时间线模拟一个非常简单的运动过程，每分钟农夫约翰要么停留在健身房的当前一侧，要么跑到另一侧。 每次他选择跑步，他都会获得一分。 不同之处在于，在某些固定的分钟内，“音频系统”迫使他在该分钟开始时位于健身房的特定一侧。 

我们从 0 边的 0 分钟开始。时间以离散的步长前进，直到 m 分钟，并且在每分钟边界，我们可以翻转边或停留。 然而，有些分钟受到限制：在 a_i 分钟，位置必须等于 b_i。 这些约束是按时间顺序排列的。 

目标是最大化我们选择奔跑的次数，这正是我们翻转的次数，同时不违反任何强制位置。 

该结构本质上是一条带有强制检查点的时间路径。 在两个连续的约束之间，我们可以自由地翻转任意多次，但只有奇偶性才重要，因为翻转两次会抵消。 

这些约束意味着所有测试中的 n 最大可达 2×10^5，而 m 最大可达 10^9。 这立即排除了任何每分钟的模拟。 任何解决方案在最坏的情况下每个测试用例都必须在 O(n) 或 O(n log n) 内工作，并且最好是线性的。 

当约束迫使不可能的转变时，就会出现微妙的边缘情况。 例如：

 输入：```
1
2 5
2 0
2 1
```在第 2 分钟，我们需要同时站在双方。 这是不可能的，因此不存在有效的时间表。 忽略约束之间冲突的天真贪婪会错误地继续并过多计算翻转次数。 

另一种边缘情况是约束稀疏时：```
1
1 10
5 1
```我们从 0 开始，必须在第 5 分钟到达 1 边，但在其他方面有完全的自由。 幼稚的方法可能只计算强制转换，而忽略了我们可以在约束之前和之后振荡。 

关键的困难是将检查点之间的自由度与强制奇偶校验更改正确地结合起来。 

## 方法

 强力解释会模拟从 0 到 m 的每一分钟，跟踪两种可能的状态并尝试停留和翻转。 这在概念上是正确的：每一分钟我们都会在两个状态之间分支，但是每当我们遇到强制约束时，我们就会过滤掉无效状态。 

然而，这会导致每个测试用例的复杂度为 O(m)，这是不可能的，因为 m 最多可达 10^9。 即使不使用结构来压缩状态仍然会让我们陷入困境，因为转换依赖于长间隔的奇偶校验。 

关键的观察是，在连续的约束时间之间，只有两件事重要：所需的端点状态以及我们是否需要奇数或偶数翻转来连接它们。 由于每次翻转都会切换一侧并只贡献一个点，因此在一个间隔内最大化点数可以减少使用尽可能多的翻转，同时尊重奇偶性。 

对于任意长度为L的区间，如果其内部没有约束，我们可以每分钟翻转一次，得到L个点。 唯一的限制是产生的奇偶校验必须与下一个强制状态匹配。 如果奇偶校验不匹配，则与最大值相比，我们恰好丢失了一次翻转，因为我们必须通过在某处跳过一次翻转来进行调整。 

因此，问题简化为处理连续的约束对并计算每个段中可以进行多少次翻转，同时确保端点的一致性。

 ## 算法演练

 我们按时间递增顺序处理约束，将它们视为固定检查点。 我们还包括一个在时间 0 处状态为 0 的隐式检查点，以及一个在时间 m 处没有强制状态的最终检查点。 

1. 将最后已知位置初始化为时间 0 处的 0 边，初始答案为 0。这表示起始条件。 
2. 按顺序迭代每个约束。 对于时间 t 且所需边 s 的约束，请考虑从前一个约束时间 p 到 t 的间隔。 
3. 计算区间长度 L = t - p。 在 L 步的自由间隔内，我们可以通过每分钟翻转来获得 L 点。 
4. 检查是否满足端点要求：从前边 prev_side 开始，经过 L 步，需要在 s 边结束。 这要求翻转的奇偶校验匹配（prev_side XOR（翻转次数 % 2）= s）。 
5. 如果 prev_side == s，我们可以以偶数次翻转结束。 最优策略是每分钟翻转一次，所以我们取L点。 
6. 如果 prev_side != s，我们必须以奇校验结束。 我们仍然希望尽可能多地翻转，但我们必须将计数恰好减少 1 来修复奇偶校验。 所以我们取L-1分。 
7. 将 prev_side 更新为 s 并继续。 
8. 处理完所有约束后，类似地处理从最后一个约束时间到 m 的最后一段，但没有强制端点。 

关键的想法是，除了奇偶性之外，每个部分都独立运行，并且奇偶性调整最多花费每个部分一次失败的翻转。 

### 为什么它有效

 除了所需的开始和结束奇偶校验之外，约束之间的每个间隔都是独立的。 在长度为 L 的自由间隔内，每分钟都有一次潜在的翻转，贡献 +1 分。 唯一的限制是翻转总数必须是偶数还是奇数。 

由于翻转总是有益的，因此最佳策略是在每一可能的分钟进行翻转，但如果需要的话，可能保留一分钟来纠正奇偶校验。 跳过多次翻转没有任何好处，因为任何额外跳过的翻转只会降低分数，而不会影响第一次校正之后的奇偶性。

这创建了一个严格的结构：每个段仅根据端点兼容性贡献 L 或 L − 1 点，并且段之间没有全局交互可以改善结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    constraints = []
    for _ in range(n):
        a, b = map(int, input().split())
        constraints.append((a, b))

    ans = 0
    prev_t = 0
    prev_side = 0

    for t_i, s_i in constraints:
        L = t_i - prev_t

        if prev_side == s_i:
            ans += L
        else:
            if L > 0:
                ans += L - 1
            else:
                ans += 0

        prev_t = t_i
        prev_side = s_i

    L = m - prev_t
    ans += L

    print(ans)
```该代码处理每个约束间隔一次，根据奇偶校验是否对齐来累积贡献。 

我们从不明确模拟翻转。 相反，我们将每个间隔视为一个块，并决定是否由于奇偶校验不匹配而丢失一次潜在的翻转。 最后一段没有强制终点，因此我们总是采取所有可用的移动。 

必须注意零长度间隔。 当 L = 0 时，即使奇偶校验不匹配，我们也不会减去任何内容，因为该段中不可能进行任何移动。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        constraints = [tuple(map(int, input().split())) for _ in range(n)]

        ans = 0
        prev_t, prev_s = 0, 0

        for t_i, s_i in constraints:
            L = t_i - prev_t
            if prev_s == s_i:
                ans += L
            else:
                ans += max(0, L - 1)
            prev_t, prev_s = t_i, s_i

        ans += m - prev_t
        out.append(str(ans))

    return "\n".join(out)

 ## 边缘情况

 一个重要的边缘情况是当两个约束同时或连续出现时，会产生长度为零的段。 在这种情况下，算法计算出 L = 0，因此无论所需边是否匹配，它都没有任何贡献。 例如：```
1
2 5
2 0
2 1
```时间 2 周围的两个片段的长度都为零，因此该时间间隔的答案仍为 0。 该算法不会尝试使用负调整或额外调整来“修复”奇偶校验，因为没有时间执行任何翻转。 

另一种边缘情况是约束一致但稀疏，例如：```
1
1 10
5 1
```从 0 到 5，我们有 L = 5，并且需要在第 1 边结束，因此我们恰好丢失了一个潜在的翻转，得到 4。从 5 到 10，我们得到完整的 5，总共 9。算法自然地通过仅在第一段中应用单个奇偶校验校正来处理这个问题。 

最后一个微妙的情况是当 m 很大并且根本没有约束时。 那么算法不处理任何片段，直接返回m，体现了我们可以不受限制地每分钟翻转一次。
