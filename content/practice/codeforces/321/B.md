 ## 解决方案
 ## 问题理解

 我们有两套卡片，一套属于二郎，一套属于夏尔。 二郎的卡牌有两种类型，攻击型和防御型，每种都有强度值。 夏尔的牌更简单：她的每一张牌都是一张具有给定强度的攻击牌。 

夏尔的游戏方式是，以她想要的任何顺序最多选择她的每张牌一次，并且可以选择提前停止。 每张选定的卡牌要么在没有卡牌剩余的情况下直接对二郎造成伤害，要么首先摧毁二郎的一张卡牌，并可能根据该卡牌的类型造成更少的伤害。 攻击型敌方卡牌要求夏尔的力量至少是他们的，并且他们会根据他们的力量来减少伤害。 防御型卡牌需要严格的不平等，并且在被摧毁时不会造成任何伤害。 

目标是选择夏尔卡牌的顺序和子集，并将它们与二郎卡牌进行最佳配对，以使总累积伤害最大化。 

限制很小，每边最多有 100 张牌。 这立即表明 O(n^2) 或 O(n^3) 解决方案是可行的，但如果不仔细修剪，双方大小呈指数增长的任何情况仍然是危险的。 

一个关键的微妙之处是夏尔可以随时停止。 这意味着并非每张卡牌都必须使用，过早使用弱卡牌可能会浪费以后潜在的高价值直接伤害。 另一个微妙之处是防御卡不能同等地被摧毁，这会产生严格的配对限制，从而影响排序决策。 

天真的贪婪方法常常会失败，因为选择首先摧毁哪张敌方卡牌会改变夏尔剩余卡牌的可用“未来价值”。 例如，在较弱的防御卡上尽早使用强大的夏尔卡可能会浪费随后潜在的大量直接伤害。 

## 方法

 对这个问题的暴力观点是考虑 Ciel 卡片的所有排列以及分配每张已用卡片“直接攻击”或“销毁一张有效的 Jiro 卡”的所有可能方法。 对于每一步，我们都会选择要瞄准哪张 Jiro 卡，或者如果没有剩余卡，则跳至直接伤害。 这导致状态爆炸：在每一步我们都有 O(n) 目标选择和 O(m) 排序选择，导致阶乘增长远远超出可行。 

如果我们观察到 Ciel 的卡片是控制交互顺序的唯一资源，而 Jiro 的卡片可以被认为是在有限制的情况下消耗的物品，那么该结构就变得易于管理。 关键思想是将二郎的卡牌视为固定的多重集，并在切换到纯粹的直接伤害之前考虑我们摧毁了多少张卡牌。 

如果我们修复了要销毁的二郎卡牌的子集，那么夏尔的最佳策略是每次销毁时使用足够小的卡牌，并保留大卡牌以在最后造成直接伤害。 这自然会导致对已经移除的攻击和防御卡的数量进行排序和动态编程。 

核心转变是将这个过程视为以最大化总奖励的方式逐步将 Ciel 的卡与 Jiro 的卡配对，其中每个配对都有成本（可能减少 Jiro 伤害）和可行性约束。 

这导致了一个DP公式，即从每种类型中删除了多少张Jiro卡以及使用了多少张Ciel卡，始终选择最佳的下一步行动。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列和分配 | O(m!·分支) | O(m + n) | 太慢了 |
 | DP 超过已用卡牌和剩余敌人 | O(n²·米) | O(n·m) | 已接受 |

 ## 算法演练

 我们将 Jiro 的卡分为两个排序数组：攻击卡和防御卡。 让 A 对攻击强度进行排序，D 对防御强度进行排序。

我们还按升序对 Ciel 的卡片进行排序，因为较早使用较小的卡片可以让我们为更高价值的操作保留更强的卡片。 

我们定义了一个 DP 状态来跟踪有多少张攻击卡和防御卡已经被摧毁，以及我们使用了多少张 Ciel 卡。 我们没有明确跟踪已使用的卡片，而是按顺序迭代 Ciel 的卡片并决定如何使用每张卡片。 

我们维护一个 DP 表，其中 dp[i][j] 表示处理 Ciel 的一些卡牌前缀后可达到的最大伤害，摧毁了 i 个攻击卡和 j 个防御卡。 

我们一张一张地处理夏尔的卡片。 

1. 将次郎的攻击卡A和防御卡D按从小到大的顺序排列。 
2. 将夏尔的卡片S按升序排列。 
3. 初始化一个用-inf填充的DP数组，除了dp[0][0] = 0。 
4. 对于每张强度为 x 的 Ciel 卡，接下来计算一个新的 DP 表。 
5. 对于每个状态 (i, j)，考虑三个操作：

 1. 跳过该卡，保留 dp[i][j]。 
2. 如果 x ≥ A[i]，则用它杀死下一张攻击卡 A[i]。 这增加了奖励 x - A[i]。 
3. 如果 x > D[j]，则用它杀死下一张防御卡 D[j]。 这增加了 0 奖励。 
6. 相应地转换到下​​一个状态。 
7. 处理完所有卡片后，答案是所有状态上的最大 dp[i][j]。 

我们只按排序顺序考虑下一张攻击或防御卡的原因是，将更强的夏尔卡分配给较弱的敌人总是比为更强的敌人保留它更糟糕，因为奖励取决于减法，而可行性与强度是单调的。 

### 为什么它有效

 DP 不变量是，处理前 k 张 Ciel 卡后，dp[i][j] 正确表示使用这 k 张卡摧毁 i 张攻击卡和 j 张防御卡可实现的最大可能伤害。 任何最佳策略都可以重新排列，以便按照所需强度的递增顺序获取被摧毁的敌方卡牌，因为在较弱和较强的目标之间交换任务不会降低可行性，如果方向错误，也不会提高回报。 这种排序特性确保 DP 永远不会错过最佳配对结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    
    atk = []
    dfn = []
    
    for _ in range(n):
        t, x = input().split()
        x = int(x)
        if t == "ATK":
            atk.append(x)
        else:
            dfn.append(x)
    
    c = [int(input()) for _ in range(m)]
    
    atk.sort()
    dfn.sort()
    c.sort()
    
    INF_NEG = -10**18
    
    dp = [[INF_NEG] * (len(dfn) + 1) for _ in range(len(atk) + 1)]
    dp[0][0] = 0
    
    for x in c:
        ndp = [[INF_NEG] * (len(dfn) + 1) for _ in range(len(atk) + 1)]
        
        for i in range(len(atk) + 1):
            for j in range(len(dfn) + 1):
                if dp[i][j] == INF_NEG:
                    continue
                
                cur = dp[i][j]
                
                # skip
                if cur > ndp[i][j]:
                    ndp[i][j] = cur
                
                # attack next ATK
                if i < len(atk) and x >= atk[i]:
                    val = cur + (x - atk[i])
                    if val > ndp[i+1][j]:
                        ndp[i+1][j] = val
                
                # attack next DEF
                if j < len(dfn) and x > dfn[j]:
                    if cur > ndp[i][j+1]:
                        ndp[i][j+1] = cur
        
        dp = ndp
    
    ans = 0
    for i in range(len(atk) + 1):
        for j in range(len(dfn) + 1):
            ans = max(ans, dp[i][j])
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP 明确跟踪有多少张攻击卡和防御卡被移除。 这些转变反映了游戏规则：攻击移除贡献价值，而防御移除仅提供可行性。 跳跃过渡至关重要，因为提前停止总是允许的。 

防御卡的严格不平等是通过使用来处理的`x > dfn[j]`而不是`>=`。 攻击卡使用`>=`，匹配允许平局的规则。

 ## 边缘情况

 一个关键的边缘情况是夏尔的卡牌强度与防御卡牌完全匹配。 例如：

 输入：```
1 1
DEF 0
0
```民主党强制执行`x > DEF`，所以这个转换是无效的。 唯一可用的动作是跳过或稍后尝试直接伤害，结果为 0。 

另一种情况是所有次郎卡都是防御且所有夏尔卡都相等。 该算法正确地避免了非法转换，并确保不计算部分配对，仅计算有效的未来直接损坏（如果有）。 

最后一个微妙的情况是夏尔的牌多于需要。 DP 允许跳过，因此额外的卡片永远不会减少答案，从而保留最佳的停止行为。
