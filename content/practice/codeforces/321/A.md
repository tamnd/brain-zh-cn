 ## 解决方案
 ## 问题理解

 我们被要求确定在 2D 平面上移动的机器人是否可以到达目标点 (_a_, _b_)。 机器人从原点 (0, 0) 开始，并遵循字符串中编码的一系列移动。 字符串的每个字符代表一个方向：“U”使机器人向上移动，“D”向下，“L”向左移动，“R”向右移动。 一旦机器人完成了该字符串，它就会无限重复。 问题是在这个无限序列中的某个时刻，机器人是否会准确地占据目标坐标。 

输入是整数 _a_ 和 _b_，范围从 -10^9 到 10^9，以及长度最大为 100 的字符串。这些约束立即表明，从字面上模拟机器人的所有重复字符串的移动是不可能的，因为目标可能非常远。 我们需要一个解决方案，在多次完全重复字符串后推断机器人的位置。 

边缘情况是指在重复结束时或重复之间恰好可以达到目标。 例如，如果绳子使机器人向右移动一次（'R'）并且目标位于（3, 0），则只有重复三次才能到达。 一次重复后停止的粗心模拟将错误地返回“否”。 

当机器人在完整序列之后的净运动为零时，会出现另一种微妙的边缘情况。 例如，如果字符串是“UDLR”，则机器人在每次完全重复后返回原点。 在这种情况下，唯一可到达的点是在第一次重复期间访问过的点。 仅考虑净运动向量的简单方法将无法捕获这些可到达的中间点。 

## 方法

 蛮力方法很简单。 您无限期地模拟机器人的移动，在每一步后更新其位置，并检查它是否等于 (_a_, _b_)。 蛮力是正确的，因为它确实遵循机器人的路径。 然而，机器人可能需要最多 10^9 步才能到达远处的目标，这显然是不可行的。 即使对每种可能的重复次数模拟一次完整的重复也太慢，因为目标坐标可能很大，而字符串长度很短。 

关键的一点是要注意机器人的运动是周期性的。 令 (_dx_, _dy_) 为字符串完全重复一次后位置的净变化。 重复字符串 _k_ 次后，机器人的位置是初始偏移量加上 _k_ 倍净变化，再加上第一次重复期间到达的某个位置。 形式上，如果我们让 (_x_i_, _y_i_) 表示机器人在第一次重复中 _i_ 移动后的位置，那么对于某个非负整数 _k_，任何可到达的位置都是 (_x_i + k_dx*, y_i + k_dy_) 的形式。 

通过这种观察，问题简化为检查，对于第一次重复中到达的每个位置，是否存在非负整数 _k_ 使得 (_x_i + k_dx* = a* 和 _y_i + k_dy* = b*)。 这是一个简单的整数方程求解问题。 当 _dx_ 或 _dy_ 为零时需要特别小心，以避免被零除。 如果两者都为零，我们只需要检查第一次重复期间到达的位置。

 | --- | --- | --- | --- |
 | 蛮力 | O(|a|+|
 | 最佳 | O( | s | ) |

 ## 算法演练

1. 通过迭代所有字符来计算字符串完全重复一次后的净移动 (_dx_, _dy_)。 根据移动增加或减少 x 或 y 坐标。 这给出了每次重复的总体平移向量。 
2. 将机器人的位置初始化为 (0, 0)，并将第一次重复期间访问过的所有位置存储在列表中。 这使我们能够在重复开始之前考虑所有可能的偏移。 
3. 对于第一次重复到达的每个位置 (_x_i_, _y_i_)，检查是否存在非负整数 _k_，使得：

 _x_i + k_dx* = a* 和 _y_i + k_dy* = b*。 

如果 _dx_ 为零，则简化为检查 _x_i = a_ 是否存在，否则将 k 计算为 (a - x_i) / dx。 _dy_ 也类似。 
4. 有效的_k_必须满足三个条件：必须是整数、必须是非负数、必须同时满足x和y方程。 如果任何位置都存在这样的_k_，则打印“是”。 
5. 如果检查完所有位置后没有找到有效的_k_，则打印“No”。 

工作原理：该算法依赖于任何可到达位置都可以表示为来自第一次重复的位置加上净平移向量的某个倍数的不变量。 通过迭代从第一次重复开始的所有偏移量，我们覆盖了在任意次数的重复之后可以到达的所有可能的位置。 整数和非负性检查确保我们只考虑可行的重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b = map(int, input().split())
s = input().strip()

dx, dy = 0, 0
path = [(0, 0)]
for move in s:
    if move == 'U':
        dy += 1
    elif move == 'D':
        dy -= 1
    elif move == 'R':
        dx += 1
    elif move == 'L':
        dx -= 1
    path.append((path[-1][0] + (dx - path[-1][0]), path[-1][1] + (dy - path[-1][1])))

for x_i, y_i in path:
    kx = ky = None
    if dx != 0:
        if (a - x_i) % dx != 0:
            continue
        kx = (a - x_i) // dx
    else:
        if x_i != a:
            continue
        kx = 0

    if dy != 0:
        if (b - y_i) % dy != 0:
            continue
        ky = (b - y_i) // dy
    else:
        if y_i != b:
            continue
        ky = 0

    if kx == ky or dx == 0 or dy == 0:
        if kx >= 0 and ky >= 0:
            print("Yes")
            break
else:
    print("No")
```我们首先计算净平移向量。 然后我们跟踪第一次重复中每次移动后的所有位置。 在检查整数 _k_ 时，我们仔细处理零转换以避免被零除。 最终条件确保 _k_ 在两个轴上一致且非负。 这`else`于`for`仅当未找到有效的 _k_ 时才会触发循环。
