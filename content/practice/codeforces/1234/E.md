 ## 解决方案
 ## 问题理解

 我们给定一个序列`x`长度`m`。 对于每个值`i`从`1`到`n`，我们构造一个特殊的排列：`p_i = [i, 1, 2, ..., i-1, i+1, ..., n]`此排列与恒等排列的不同之处仅在于值`i`已经移到前面了。 

对于每个排列，我们必须计算连续元素之间的总距离`x`当在该排列中查看这些元素时。 如果两个相邻值`x`占据职位`a`和`b`在排列中，他们贡献`|a-b|`到答案。 

任务是为每个排列输出这个值`p_1, p_2, ..., p_n`。 

The constraints are the first thing that drives the solution. 两个都`n`和`m`可以达到`2·10^5`。 有`n`不同的排列，每个答案取决于`m-1`相邻对来自`x`。 直接计算大约需要`n·m`，这变成了关于`4·10^10`最坏情况下的操作。 两秒钟内这是完全不可能的。 

排列的结构非常特殊。 每个排列都是通过将一个值恰好移动到第一个位置来从恒等式获得的。 这意味着大多数位置保持不变，当我们从一个排列索引移动到另一个排列索引时，只有一小部分距离受到影响。 

一些边缘情况很容易被错误处理。 

考虑：```
3 3
2 2 2
```每个相邻对都是`(2,2)`，无论排列如何，其距离始终为零。 正确的输出是：```
0 0 0
```假设相邻值不同的解决方案可能会错误地引入更新。 

考虑：```
4 2
1 4
```答案为`p_1`是`|1-4|=3`。 为了`p_4`，位置变为`(2,1)`，给出距离`1`。 当一个端点等于移动的元素时，距离会发生巨大变化。 

考虑：```
5 2
2 3
```该对永远不会包含很多值，但每个答案仍然取决于移动的元素相对于间隔的位置`[2,3]`。 任何只更新端点而忽略区间效应的方法都会产生错误的答案。 

核心挑战是理解单个相邻对如何同时对所有排列做出贡献。 

## 方法

 暴力解决方案很简单。 对于每一个排列`p_i`，计算每个值的位置，然后迭代`m-1`相邻对的`x`并对相应的距离求和。 

排列中的位置函数`p_k`是：

-`pos(k)=1`-`pos(v)=v+1`为了`v<k`-`pos(v)=v`为了`v>k`使用这个公式，可以在恒定时间内评估每个距离。 不幸的是我们还有`n`排列和`m-1`对，导致`O(nm)`工作。 两个参数都等于`2·10^5`，运算次数在四百亿左右。 

关键的观察是总答案是相邻对的总和`x`。 

我们没有固定排列并评估每一对，而是颠倒了观点。 取一对相邻的`(a,b)`并确定其贡献在所有排列中如何变化。 

让```
g_k(a,b) = |pos_k(a)-pos_k(b)|
```在哪里`k`是移到前面的值。 

对于大多数值`k`，距离在恒等排列中保持不变。 仅当`k`等于一个端点或位于两个端点之间距离是否发生变化。 

这意味着单个对仅影响排列索引的一个区间。 由于只有`m-1`对，我们可以独立处理每一对并将其效果累积到差异数组中。 

恒等排列的答案很容易计算：```
base = Σ |x_i - x_{i+1}|
```然后，对于每个相邻对，我们计算其贡献与所有相关排列的基本答案的差异有多大。 可以使用范围更新来添加这些更改。 

整个问题变成了排列索引上的区间加法问题`k`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(纳米) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n + m) | O(n) | 已接受 |

 ## 贡献公式的推导

 假设`a < b`。 

在恒等排列中，贡献是```
b-a
```现在考虑移动价值`k`到前面。 

如果`k=a`， 然后```
pos(a)=1
pos(b)=b
```贡献变成```
b-1
```与底座的区别：```
(b-1)-(b-a)=a-1
```如果`k=b`， 然后```
pos(a)=a+1
pos(b)=1
```贡献变成```
a
```不同之处：```
a-(b-a)=2a-b
```如果`a<k<b`， 然后```
pos(a)=a+1
pos(b)=b
```贡献变成```
b-a-1
```不同之处：```
-1
```对于所有其他`k`，贡献保持不变。 

因此一对贡献：```
a-1          at k=a
-1           for a<k<b
2a-b         at k=b
0            elsewhere
```这个紧凑的描述就是整个解决方案。 

## 算法演练

 1. 计算恒等排列的答案。 

让```
ans = Σ |x_i - x_{i+1}|
```每个排列答案都将从这个值开始，然后接受修正。 
2. 创建大小不同的数组`n+3`。 

我们将存储与身份答案相关的所有更改。 
3. 处理每一个相邻的对`(u,v)`在`x`。 

如果`u=v`，贡献始终为零，不需要更新。 
4.让`a=min(u,v)`和`b=max(u,v)`。 

导出的公式仅取决于有序端点。 
5.添加点更新`k=a`。 

修正是`a-1`。 
6.添加点更新`k=b`。 

修正是`2*a-b`。 
7.添加范围更新`(a,b)`。 

每个排列索引严格介于`a`和`b`收到`-1`。 

这是移动值位于两个端点之间的间隔，将它们的距离减少一。 
8. 处理完所有对后，使用前缀和将差异数组转换为实际校正。 
9. 对于每一个`k`从`1`到`n`， 输出```
base + correction[k]
```### 为什么它有效

 对于每对相邻的值，我们显式地计算其距离与恒等排列相比的精确变化。 上面的推导耗尽了移动值的所有可能位置`k`。 

一对仅在三种情况下做出贡献：`k`等于左端点，当`k`等于右端点，或者当`k`严格地位于他们之间。 更新规则精确地编码了这些情况。 

因为总答案是所有相邻对的贡献之和，所以线性允许我们独立地添加所有对校正。 累积所有更新后，存储校正以进行排列`k`等于每对贡献变化的总和，这正是`f(p_k)`和身份答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def add_range(diff, l, r, val):
    if l > r:
        return
    diff[l] += val
    diff[r + 1] -= val

def solve():
    n, m = map(int, input().split())
    x = list(map(int, input().split()))

    base = 0
    diff = [0] * (n + 3)

    for i in range(m - 1):
        u = x[i]
        v = x[i + 1]

        if u == v:
            continue

        a = min(u, v)
        b = max(u, v)

        base += b - a

        diff[a] += a - 1
        diff[a + 1] -= a - 1

        if a + 1 <= b - 1:
            add_range(diff, a + 1, b - 1, -1)

        diff[b] += 2 * a - b
        diff[b + 1] -= (2 * a - b)

    cur = 0
    res = []

    for k in range(1, n + 1):
        cur += diff[k]
        res.append(str(base + cur))

    print(" ".join(res))

solve()
```该解决方案首先计算身份排列答案。 这是所有其他答案的基础。 

对于每个相邻对，我们应用之前导出的三个校正规则。 点更新被实现为差异数组内长度为一的范围更新。 间隔`(a,b)`接收范围更新`-1`。 

差异数组至关重要。 没有它，更新之间的每个索引`a`和`b`将使算法呈二次方。 差异数组将每个间隔修改转化为持续的工作。 

一个微妙的细节是更新`k=b`。 其值为`2a-b`， 不是`a-b`或者`a-1`。 这直接来自于当`b`本身被移动到前面。 

另一个容易犯的错误是处理相等的连续值。 什么时候`u=v`，距离始终为零。 派生公式假定不同的端点，应完全跳过。 

所有算术都适合 64 位整数。 最大答案约为`m·n`， 大约`4·10^10`。

 ## 边缘情况

 考虑：```
3 3
2 2 2
```每个相邻对都有相同的端点。 该算法立即跳过每一对，因为`u == v`。 不应用任何更新，基本答案保持为零，并且每个排列答案都为零：```
0 0 0
```现在考虑：```
5 2
1 5
```基本答案是`4`。 对于这对`(1,5)`, 区间`(1,5)`收到`-1`，所以排列`2,3,4`全部失去一个单位。 在`k=5`，特殊端点校正有助于`-3`，给出答案`1`。 输出变为：```
4 3 3 3 1
```这验证了正确的端点更新`2a-b`处理正确。 

最后考虑：```
5 2
2 3
```基本答案是`1`。 

更新内容是：```
k=2 : +1
k=3 : +1
```端点之间不存在间隔。 答案变成：```
1 2 2 1 1
```这会检查边界情况，其中`b=a+1`，确保间隔更新不会意外应用于空范围。
