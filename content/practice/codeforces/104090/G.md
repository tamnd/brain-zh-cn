 ## 解决方案
 ## 问题理解

 给定一个无向连通简单图$G$。 从此图中，考虑使用所有的所有连接子图$n$顶点并且恰好包含$n-1$边缘。 任何这样的子图必然是一个生成树$G$，因为它是连接的，非循环的（因为边等于$n-1$)，并且跨越所有顶点。 

问题是问是否存在一棵树$T$使得每一个生成树$G$结构上相同于$T$直到重新标记顶点。 换句话说，无论你选择哪棵生成树$G$，它们都必须同构为无根树。 

输出是每个测试用例的简单决策，如果给定图的所有生成树彼此同构，则为“是”，否则为“否”。 

约束允许最多$10^5$测试用例总计$n$和$m$跨测试最多$10^6$。 这迫使每个测试用例都有一个线性或近线性的解决方案。 任何枚举生成树或对每个边选择执行大量组合推理的方法都是不可能的，因为即使单个图也可以具有指数级数量的生成树。 

一个天真的尝试是生成多个生成树（例如通过删除 DFS 生成树中的不同边）并检查它们之间的图同构性。 即使是树的图同构也可以在线性时间内检查，但密集图中的生成树数量仍然是指数级的，因此这种方法立即失效。 

另一个天真的方向是假设“小循环变化”不会影响结构，但在存在分支的图中直觉会失败。 例如，在带有一个循环和一个叶子的图中，删除循环边的不同选择可能会改变分支在生成的树中的位置，并且如果其他地方存在更复杂的分支，则可以以非同构的方式改变树的形状。 

## 方法

 第一个观察结果是，我们不是在比较任意子图，而是在比较生成树。 生成树的结构完全由图的循环空间控制。 树之外的每条额外边都会引入至少一个循环，并且每个循环都会引入灵活性：删除不同的循环边会产生不同的生成树。 

如果图已经是一棵树，则只有一个生成树，因此条件成立。 

如果图中恰好包含一个环，则通过从该环中恰好删除一条边来形成每棵生成树。 结构的其余部分保持固定。 这会产生一个树族，其不同之处仅在于删除了单个循环的哪条边。 由于循环可以在任何位置“打开”到路径中，因此所有生成的树都是同构的：循环成为一条路径，并且循环顶点的所有附件都保持附加在沿着该路径的相应位置，直到重新标记。 

当图表包含多个独立循环时，困难就开始了。 对于两个循环，有多个独立的选择要删除的边，不同的组合可以改变全局分支模式。 这通常会产生沿路径具有不同程度分布或分支点不同排列的生成树，这些生成树无法通过任何同构来协调。 

查看边界的一种有用方法是通过边缘计数。 连通图与$n-1$边缘是一棵树。 和$n$边，它是单环的。 拥有超过$n$边缘，它至少有两个循环，这正是非同构生成树开始出现的地方。 

因此，条件简化为检查图是树还是简单循环。

 ## 算法演练

 关键思想是根据图在树之外有多少“额外”边以及该额外结构是否恰好形成一个简单循环来对图进行分类。 

### 步骤

 1. 计算边数$m$和顶点$n$。 如果$m = n - 1$，图已经是一棵树了，所以只有一棵生成树。 我们可以立即输出“YES”。 
2.如果$m = n$，该图恰好有一个超出树结构的额外边，这意味着它是单循环的。 在这种情况下，验证每个顶点的度数恰好为 2。此条件确保图是一个简单循环，没有任何附加分支。 
3. 如果图是一个简单的循环，那么删除任何边总是会产生一条路径$n$顶点。 由于所有生成树都是相同大小的路径，因此它们都是同构的，因此我们输出“YES”。 
4. 在所有其他情况下，图要么具有分支结构，要么具有多个循环。 这保证了至少存在两个具有不同结构属性的生成树，因此我们输出“NO”。 

### 为什么它有效

 一棵树只有一个生成树，因此它简单地满足该条件。 简单循环是唯一具有一个循环且没有分支的连通图，在这种情况下，所有生成树在重新标记之前都是相同的路径。 任何附加循环或任何与循环不兼容的度顶点的存在都会在生成树中引入结构不对称性，从而允许至少两个非同构结果。 这将所有图干净地划分为“至多一个循环和统一结构”与“结构多样的生成树”。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        n, m = map(int, input().split())
        deg = [0] * (n + 1)

        for _ in range(m):
            u, v = map(int, input().split())
            deg[u] += 1
            deg[v] += 1

        if m == n - 1:
            out.append("YES")
        elif m == n:
            ok = True
            for i in range(1, n + 1):
                if deg[i] != 2:
                    ok = False
                    break
            out.append("YES" if ok else "NO")
        else:
            out.append("NO")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现仅依赖于每个测试用例的度计数和边计数。 关键的决策点是区分树和简单循环。 度检查确保单循环情况是纯循环而不是带有附加树的循环。 

一个微妙的点是条件$m = n$仅靠这一点是不够的。 图表与$n$如果存在附有树的循环，则边仍然可以有分支。 这些附件会创建度数大于 2 的顶点或叶子，这会立即破坏所有生成树保持同构所需的统一循环结构。

 ## 边缘情况

 单个顶点图没有边并且只有一个生成树，因此它必须返回“YES”。 该算法将其分类为$m = n - 1$，立即通过。 

纯循环是典型的正案例$m = n$。 每个顶点的度数为 2，因此度数检查成功，输出为“YES”。 每棵生成树都是一条路径，因此不存在结构变化。 

具有单个额外叶子的循环引入了度为 3 的顶点。算法在度扫描期间检测到这一点并拒绝它。 生成树的不同取决于删除的循环边，从而沿着生成的路径为叶子产生不同的附着位置，这证实了非同构。 

具有多个循环的图必然有$m > n$，并立即被拒绝。 在此类图中，不同的生成树的分支结构可能不同，因为循环独立相互作用，产生非同构结果。
