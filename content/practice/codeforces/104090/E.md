 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，并且我们可以使用非常具体的块操作重复地重新排列它。 每个操作选择两个分割点，将数组分割成三个连续的非空段。 之后，我们旋转这些片段，使最后一个片段移动到前面，中间保持原位，第一个片段移动到末尾。 

换句话说，如果排列被视为$A | B | C$，该操作将其转换为$C | B | A$，其中两个外部段必须非空，中间段也必须非空。 

目标不是对排列进行精确排序，而是使用最多使用字典顺序使其尽可能小$2n+1$此类操作。 这里按字典顺序最小意味着我们希望最终的排列与排序序列匹配$1, 2, \dots, n$，因为在可以获得的所有排列中，这是最小可能的顺序。 

约束条件$n \le 1000$和总计$\sum n \le 1000$表明即使每个测试用例的二次构造也是可以接受的，但只有当操作数是线性时，每个操作的任何三次或大量模拟都可以。 由于我们最多可以$2n+1$操作中，任何对每个元素执行恒定或分摊恒定工作量的策略都是可以接受的。 

一种天真的解释会尝试模拟任意重新排列并贪婪地寻求改进操作。 失败的原因是操作空间太大：每一步都有$O(n^2)$的选择$(x, y)$，并且评估所有效果导致$O(n^3)$行为。 

当贪婪方法试图通过暴力移位来放置最小的剩余元素时，就会出现微妙的失败情况。 例如，如果我们尝试将元素 1 放在前面，然后递归地修复后缀，我们很容易破坏先前固定的结构，因为该操作全局旋转三个块，而不是局部旋转。 这意味着本地“修复”策略不保留前缀。 

关键的困难在于该操作是全局的并且以受控方式可逆，因此我们必须设计一种能够增量构建目标排列的结构，同时保持强大的结构不变量。 

## 方法

 暴力心理模型是将操作视为任意重新排序三个连续块的方法。 如果我们枚举所有可能的分裂并进行模拟，我们可以探索一个巨大的状态空间。 然而，分支因子是二次方$n$，即使是浅层搜索也很快变得不可行。 

重要的结构观察是，此操作足够强大，可以将任何元素从内部移动到任一端，但它始终保留中间部分的内部顺序。 这意味着我们实际上可以“提取”段并将它们重新插入到数组的另一侧。 

这提出了一种建设性的策略：我们不是尝试局部固定位置，而是通过重复将正确的下一个元素放入其最终位置来从一侧构建排列，同时确保剩余的未固定部分保持连续。 

关键的见解是我们可以使用块旋转来模拟从右到左的受控插入排序。 在每一步中，我们隔离应该到达当前位置的元素，将其旋转到位，并保持当前位置之外的后缀已经固定并且不会再次受到干扰的不变量。 

这将问题从全局重排搜索减少到段旋转的确定性序列。

 ## 算法演练

 我们从右到左构建排列，固定位置$i$使其最终包含价值$i$。 

我们维护当前的工作数组，并且在每一步中我们确保后缀$[i+1, n]$已经是正确的了。 

### 步骤

 1. 从$i = n$下降到$1$，将位置从右到左视为一一固定。 这个方向确保一旦后缀正确，以后的操作就可以通过始终严格对前缀进行操作来避免干扰它。 
2. 对于每个$i$，定位位置$pos$有价值的$i$在当前数组中。 由于我们正在处理排列，因此这个位置是独一无二的。 
3.如果$pos = i$，不执行任何操作并继续，因为该元素已经位于正确的位置。 
4. 否则，我们需要转移价值$i$定位$i$。 我们首先隔离包含该元素的段。 我们选择一个拆分，将$pos$进入操作的外部部分之一。 目标是一次将元素移动到数组的前面或后面。 
5. 一旦元素到达末端，我们执行另一个操作将其旋转到位$i$，同时保留已经固定的后缀。 这是有效的，因为可以选择操作的中间部分来排除所有已经固定的位置。 
6. 重复此过程，直到所有位置都固定。 由于每个元素移动固定次数，因此操作总数保持线性。 

### 为什么它有效

 关键的不变量是完成迭代后$i$, 后缀$[i, n]$正是$[i, i+1, \dots, n]$，并且未来的操作不会触及大于或等于的指数$i$。 这是可以保证的，因为每次旋转都会被选择，以便固定后缀始终完全放置在操作的中间段内，该中间段保持不变。 

每个操作仅操作一个前缀段，每一步有效地将活动区域缩小至少一个元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        p = list(map(int, input().split()))
        
        pos = [0] * (n + 1)
        for i, v in enumerate(p):
            pos[v] = i
        
        ops = []
        
        def apply(x, y):
            # x, y are lengths of first and middle parts
            # segments: [0:x], [x:n-y], [n-y:n]
            # becomes: [n-y:n], [x:n-y], [0:x]
            nonlocal p, pos
            a = p[:x]
            b = p[x:n-y]
            c = p[n-y:]
            p = c + b + a
            for i, v in enumerate(p):
                pos[v] = i
            ops.append((x, y))
        
        for i in range(n, 0, -1):
            if pos[i] == i - 1:
                continue
            idx = pos[i]
            
            # bring i to front
            if idx != 0:
                apply(idx, 1)
            
            # now i is at front, move it to position i-1
            if i - 1 > 0:
                apply(i - 1, 1)
        
        print(len(ops))
        for x, y in ops:
            print(x, y)

if __name__ == "__main__":
    solve()
```该实现保留一个显式数组并在每次操作后更新位置。 这`apply`函数直接模拟三部分旋转。 尽管这不是最优化的表示，但约束足够小，可以重新计算位置$O(n)$每次操作都是安全的。 

关键的微妙之处在于，我们始终确保被固定的元素首先移动到前面，然后旋转到其最终位置。 这种两步方法保证我们不会干扰已经固定的后缀。

 ## 边缘情况

 一种边缘情况是排列已经排序。 该算法立即发现每个$i$已经就位并且不执行任何操作，因为位置检查`pos[i] == i - 1`跳过所有步骤。 

另一个边缘情况是完全反转的排列。 每个元素都必须重复地被带到前面，但因为我们总是在每次操作后重建位置，所以我们永远不会丢失索引的跟踪，并且每个元素最终都会冒泡到位。 

第三种情况是元素在已经固定的后缀位置之间交错。 该不变量确保一旦后缀被固定，它就永远不会包含在任何未来操作的第一个或最后一个段中，因此它在整个过程中保持稳定。
