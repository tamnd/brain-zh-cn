 ## 解决方案
 ## 问题理解

 我们被要求在上构建一棵树$n$顶点标记为$1$到$n$这样对于连接顶点的每条边$u$和$v$和$u < v$, 顶点$u$出现在之前$v$在给定的排列中$p$。 同样地，树中任何顶点的父节点都必须出现在较早的位置$p$如果我们考虑以最小顶点为根的树，那么它比孩子更重要。 该排列保证了每个数字$1$到$n$只发生一次，因此不存在重复项。 

输入包含多个测试用例，每个测试用例都有一个排列。 输出需要首先说明这样的树是否可能，如果可能，则提供其边缘。 每条边必须满足相对于的排序约束$p$。 

约束表明$n$可以达到$2 \cdot 10^5$和总和$n$在所有测试用例中也达到$2 \cdot 10^5$。 这排除了任何明确检查所有可能树的解决方案，因为即使是中等程度的树也呈指数级增长。$n$。 每个测试用例都需要一个线性或线性算术解决方案。 

边缘情况包括最小元素不是第一个的排列，或者跳跃的序列，使得没有一致的树可以满足“较早的元素”$p$必须更小”规则。例如，如果$p = [3,1,2]$，最小的顶点 1 在 3 之后，因此不可能在遵守顺序的情况下将 3 附加到任何比它小的顶点。 在这种情况下，总是贪婪地将顶点附加到最后添加的顶点的粗心实现可能会产生无效的树。 

## 方法

 蛮力方法是尝试连接每一对$(u, v)$和$u < v$和$u$发生在之前$v$在$p$，然后尝试从这些对中组装一棵树。 这是有效的，因为每个有效边都必须满足以下顺序$p$。 然而，构建所有有效边并检查连通性是$O(n^2)$，这对于$n \sim 10^5$。 即使对所有候选边缘进行深度优先搜索或联合查找也太慢，因为大约有$O(n^2)$候选人。 

关键的见解是按顺序处理排列，并尝试将每个顶点附加到比其自身小的最近的前一个顶点。 如果某个顶点不存在这样的前置顶点，则无法形成树。 通过使用像双端队列这样的数据结构或从左到右的简单线性扫描，我们可以维护一组可以充当父节点的候选顶点集。 每个顶点都有一个带有较小标签的父节点，保证了树的属性。 这将问题简化为基于排列顺序的贪婪构造，给出$O(n)$每个测试用例。 

贪婪的想法之所以有效，是因为在一棵树上$n$顶点，除根之外的每个顶点都只有一个父顶点。 排序条件允许父顶点是之前出现的任何较小顶点$p$。 如果不存在这样的顶点，则在不违反条件的情况下无法连接该顶点。 父子关系可以在保持连通性的同时贪婪地分配，因为树只需要$n-1$边缘。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n²) | 太慢了 |
 | 贪心建设| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和排列$p$。 构造从顶点标签到其索引的映射$p$以便快速访问。 这有助于我们确定任意两个顶点的顺序$O(1)$。 
2. 检查第一个元素是否$p$是 1。如果不是，则不可能满足该规则，因为最小顶点不能有比其自身小的父顶点。 在这种情况下，打印“否”并继续。 
3. 初始化一个列表来存储边，并初始化一个堆栈来跟踪可以充当父节点的顶点。 将第一个顶点作为根候选推入堆栈。 
4. 从第二个元素到最后一个元素迭代排列。 对于每个顶点$v$，从堆栈中弹出顶点，直到找到一个顶点$u$小于$v$。 连接$v$对此$u$并推$v$到堆栈上。 如果没有这样的$u$存在，不可能满足约束条件； 输出“否”。 
5. 如果循环完成，则输出“Yes”，后跟收集的边沿。 

为什么它起作用：堆栈为即将到来的顶点维护一系列潜在的父节点，按它们在中的出现排序$p$。 通过始终将顶点连接到最近的较小的先前顶点，我们确保每条边都遵循排列顺序。 由于每个顶点都连接一次且仅一次，因此我们形成一棵树$n-1$边缘。 堆栈保证我们始终选择有效的父级，并且弹出较大的顶点可确保树条件成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        pos = [0]*(n+1)
        for i, x in enumerate(p):
            pos[x] = i
        
        if p[0] != 1:
            print("No")
            continue
        
        edges = []
        stack = [p[0]]
        
        possible = True
        for v in p[1:]:
            while stack and stack[-1] > v:
                stack.pop()
            if not stack:
                possible = False
                break
            edges.append((stack[-1], v))
            stack.append(v)
        
        if possible:
            print("Yes")
            for u, v in edges:
                print(u, v)
        else:
            print("No")

if __name__ == "__main__":
    solve()
```解决方案首先读取测试用例的数量和每个排列。 我们将顶点标签映射到位置以进行恒定时间排序检查。 第一个元素必须为 1 才能充当根。 堆栈跟踪最近的有效父节点，弹出较大的顶点以维持顺序条件。 边缘会随着我们的操作而附加，以确保连接性和正确性。 如果在任何时候不存在有效的父级，我们会立即检测到不可能性。
