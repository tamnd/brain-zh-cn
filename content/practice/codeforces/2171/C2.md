 ## 解决方案
 ## 问题理解

 我们被要求在两个整数数组上模拟两人游戏，`a`和`b`，每个长度`n`。 玩家轮流：Ajisai 在奇数回合移动，Mai 在偶数回合移动。 在玩家的回合中，他们可以交换当前元素`a[i]`和`b[i]`或保持原样。 Ajisai 的目标是最大化数组中所有元素的异或`a`最后，Mai 希望最大化所有元素的异或`b`。 后`n`回合中，我们必须确定哪位玩家能够以最佳发挥保证获胜，或者游戏结果是否平局。 

输入大小允许每个测试用例最多 200,000 个元素，值最大为 10^6。 这意味着任何迭代所有可能的交换（2^n 可能性）的解决方案都是不可行的。 因此，我们必须找到一种使用位级推理或贪婪决策的解决方案，而不是暴力枚举。 

当数组相同或包含许多零时，会出现微妙的边缘情况。 例如，如果`a = [0, 0]`和`b = [0, 0]`，两个玩家都不能通过交换来增加他们的 XOR，所以游戏是平局。 另一个棘手的情况是，当一个玩家的最佳交换增加对手的 XOR 值超过自己的值时； 天真的贪婪策略可能会选择局部最大移动而不考虑对手的反击。 

## 方法

 最简单的方法是尝试所有 2^n 种交换组合。 每个元素都有两个状态（交换或未交换），我们将计算每个组合的最终异或，以查看哪个玩家获胜。 这是正确的，但速度慢得令人绝望：对于 n = 2 * 10^5，我们甚至无法迭代 2^n 种可能性中的一小部分。 

关键的见解是 XOR 在每个位上的行为都是独立的。 单独考虑每个位的位置。 玩家对指数的决定`i`只能影响该索引处该位的异或。 由于 Ajisai 控制奇数索引，Mai 控制偶数索引，因此我们可以计算出每个位有多少个`1`s 存在于奇数索引处，有多少存在于偶数索引处。 该位的最终异或将是`1`如果数量`1`数组中该位的 s 是奇数。 

每个玩家都想做到这一点`1`在他们的数组中和`0`对方阵中。 这相当于每个位上的“Nim 游戏”的变体。 经过仔细推理，从最高顺序开始的第一个不同的位决定了获胜者：如果数组中该位的 1 计数（考虑交换选项）满足一定的奇偶校验条件，则控制奇数索引的玩家获胜；否则，控制奇数索引的玩家获胜。 否则，偶数指数玩家可以强行获胜。 如果在这种决定性的方式上没有任何差别，那么比赛就是平局。

 ## 算法演练

 1. 初始化所有测试用例的循环。 对于每个测试用例，请阅读`n`,`a`， 和`b`。 
2. 对于从最高位（值不超过 10^6 的第 20 位）到最低位（第 0 位）的每个位位置，分别计算奇数索引位置和偶数索引位置设置了该位的元素数量。 让`odd`是奇数索引处的计数并且`even`在偶数指数处。 
3. 如果两者都`odd`和`even`是偶数，该位贡献`0`两个玩家的异或，不影响结果。 继续下一点。 
4. 如果至少有一项`odd`或者`even`奇怪的是，这一点却是决定性的。 判断第一个玩家（Ajisai）是否可以强制异或`1`在他们的阵列上。 如果平价有利于奇数指数玩家，则 Ajisai 获胜。 如果它有利于偶数指数玩家，Mai 获胜。 
5. 如果扫描所有位后没有找到决定性位，则游戏平局。 

为什么有效：每位的异或都是独立的。 玩家的动作只能在他们控制的索引处切换位。 通过从最高位向下进行分析，我们可以从不同的最高有效位中确定获胜者，因为在异或比较中，较高位优先于较低位。 计数产生不同奇偶性的第一位定义了获胜策略。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        winner = "Tie"
        for bit in reversed(range(21)):  # 0..20 for numbers up to 10^6
            odd = even = 0
            for i in range(n):
                if (a[i] >> bit) & 1:
                    odd += 1 if i % 2 == 0 else 0
                    even += 1 if i % 2 == 1 else 0
                if (b[i] >> bit) & 1:
                    odd += 1 if i % 2 == 0 else 0
                    even += 1 if i % 2 == 1 else 0
            if odd % 2 == 0 and even % 2 == 0:
                continue
            if odd % 2 == 1 and (odd % 4 == 1 or even % 2 == 0):
                winner = "Ajisai"
            else:
                winner = "Mai"
            break
        print(winner)

if __name__ == "__main__":
    solve()
```该解决方案循环测试用例，对每个索引奇偶校验处的设置位进行计数，并检查具有决定性奇偶校验的最高位。 使用基于 0 的索引可确保奇数轮和偶数轮与问题陈述匹配（Ajisai：奇数轮 → 偶数索引）。 微妙之处包括位的顺序（最高的在前）以及一致地处理基于 0 的索引。
