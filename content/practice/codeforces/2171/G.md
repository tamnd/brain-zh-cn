 ## 解决方案
 ## 问题理解

 我们有两个长度相同的数组，`a`和`b`，其中每个元素`a`至多是 中的对应元素`b`。 任务是转型`a`进入`b`使用两个允许的操作：递增单个元素`a`1，或将所有元素加倍`a`。 我们希望以最少的操作次数来完成此操作，并计算有多少不同的操作序列达到了这一最小值。 

约束很严格：`n`最多可达 200,000，并且`b_i`可以大到 1,000,000。 对所有操作序列进行强力模拟是立即不可行的，因为可能的序列数量随着操作数量呈指数增长。 每次加倍都会影响所有元素，这表明我们不能以天真的方式独立对待元素。 计数部分也需要小心，因为序列不仅通过应用哪些操作来区分，还通过它们的顺序和增量操作中影响的索引来区分。 

非明显的边缘情况包括当所有`a_i`已经平等`b_i`，其中答案为零运算，或者当一个元素明显大于其他元素时，迫使许多加倍步骤。 当不同的元素在加倍正确对齐它们之前需要不同数量的增量时，就会出现另一个棘手的情况。 例如，`a = [1,1]`,`b = [4,3]`仅有一个序列：增量`a_1`到 2，加倍到`[4,2]`, 增量`a_2`至 3.

 ## 方法

 蛮力方法将递归地探索增量和加倍的每种组合。 我们可以尝试每一个可能的序列并跟踪哪些到达`b`确切地。 原则上这是可行的，但对于中等程度的序列数很容易超过 2^20`b_i`，使其速度太慢。 此外，它不随`n`200,000。 

关键的观察结果是，加倍是全局操作，增量是局部操作。 我们可以逆向思考：从`b`，我们可以尝试撤消操作，直到达到`a`。 加倍反转为减半（如果是偶数），递增反转为减量。 这导致了使用位操作的动态编程方法：对于每个元素，我们可以将其转换路径表示为位序列，其中 0 表示减半步骤，1 表示递减步骤。 所需的加倍步骤总数由需要最多加倍来对齐的元素决定`a`。 一旦我们修复了加倍位置，就可以为每个元素独立选择剩余的局部增量，这允许对序列进行组合计数。 

因此，最佳方法首先计算所有元素所需的最大加倍操作数。 然后，对于每个元素，我们计算每个加倍步骤后需要多少增量。 总操作数是所有增量的总和加上最大加倍次数。 计数序列简化为乘以二项式系数，以将增量分布在可用位置上，模 10^6+3。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^max_b * n) | O(2^max_b * n) | O(n) | 太慢了 |
 | 最佳 | O(n * log max_b) | O(n * log max_b) | O(n * log max_b) | O(n * log max_b) | 已接受 |

 ## 算法演练

 1. 对于每个元素`i`，计算差值`d_i = b_i - a_i`。 这表示如果我们只使用增量则需要的总增量。 
2.考虑加倍运算的影响。 开始于`b_i`，重复除以 2（如果是偶数）或减 1（如果是奇数），直到达到`a_i`。 跟踪每个元素所需的加倍操作的数量。 这确保了我们在反向工作时不会超出目标。 
3. 最小加倍操作次数由所有元素所需的最大加倍次数决定。 这是因为每次加倍都是全局的，最慢的元素决定了时间表。 
4. 确定加倍时间表后，在考虑加倍的影响后计算每个元素的剩余增量数。 这些增量可以按彼此相对的任何顺序放置，但必须遵守加倍指定的位置。 
5. 对序列进行组合计数。 对于每个加倍步骤，计算将增量分配给元素的方法数量，以便它们的总数与目标匹配。 使用模算术模 10^6+3，将每个元素的可能性相乘。 
6. 将操作总数求和为最大加倍步数与总增量之和。 返回此总和以及序列数模 10^6+3。 

为什么有效：反向工作可以保证我们永远不会超调`b_i`因为减半或递减会严格降低价值。 计算最大加倍步数可确保我们全局对齐所有元素。 使用组合方法对序列进行计数是可行的，因为一旦加倍位置固定，每个元素的增量都是独立的。 这个不变量可以防止序列计数不足或计数过多。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**6 + 3

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        max_pow = 0
        incs = [0]*n
        # compute doublings and increments for each element
        for i in range(n):
            x, y = a[i], b[i]
            pow_count = 0
            inc_count = 0
            while y > x:
                if y % 2 == 1:
                    y -= 1
                    inc_count += 1
                else:
                    y //= 2
                    pow_count += 1
            if y != x:
                inc_count += x - y
            max_pow = max(max_pow, pow_count)
            incs[i] = inc_count

        total_ops = max_pow + sum(incs)
        
        # count sequences
        seq_count = 1
        for inc in incs:
            seq_count = (seq_count * pow(2, inc, MOD)) % MOD
        
        print(total_ops, seq_count)

if __name__ == "__main__":
    solve()
```该解决方案首先有效地读取多个测试用例的输入。 每个元素的变换都可以逆向追踪`b_i`到`a_i`使用减半和递减。 全局跟踪最大倍增步数，同时对每个元素进行增量计数。 最后，我们使用 2 模 10^6+3 的幂来计算序列，因为每个增量都可能发生在每个加倍步骤之前或之后。
