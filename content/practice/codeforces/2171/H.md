 ## 解决方案
 ## 问题理解

 该任务要求我们构造一个长度的数组`n`严格递增的整数，全部由`m`，使得特定分数最大化。 分数是以下总和`v(i, a_i)`从`i=2`到`n`， 在哪里`v(b, x)`是最大的力量`k`这样`b^k`划分`x`。 本质上，对于每个位置`i`从 2 开始，我们希望该位置的元素尽可能被整除`i`。 

我们得到了多个测试用例。 每个测试用例给出`n`和`m`。 约束条件允许`n`和`m`最多 200,000，但所有的总和`m`测试用例的值也以 200,000 为界。 这个限制表明我们需要一个每个测试用例大约为 O(m log m) 或 O(n log n) 的解决方案； 在最坏的情况下，任何 O(n*m) 都会太慢。 

非明显的边缘情况包括以下场景：`n`等于`m`，这意味着数组必须包含从 1 到`m`。 另一个棘手的情况发生在`m`是一个很小的数字但是`n`很大，因此数组被迫连续选取几乎所有数字。 在这种情况下，幼稚的贪婪选择可能会低估最佳指数和，因为在数组后面取最大的可整除数可以产生更高的总分。 

一个小例子：`n=3, m=6`。 一个幼稚的方法可能会选择`[1,2,3]`。 这`v`值是`v(2,2)=1`和`v(3,3)=1`，总和是2。但是选择`[1,2,6]`给出`v(2,2)=1`,`v(3,6)=1`，sum 仍然是 2。这表明有时应该将最大元素推到后面的位置以获得更好的整除性。 

## 方法

 蛮力方法考虑每个严格递增的数组`a`之内`[1, m]`并计算分数。 有`C(m, n)`这样的数组，对于每个数组，计算总和需要`n`可分性检查。 即使预先计算了幂，其组合也会爆炸，远远超出了可行的极限。 

关键的见解是`v(b, x)`最大化时`x`可以被最大可能的幂整除`b`。 对于每个`i`在`[2, n]`，贡献`i`总和是最高的`k`这样`i^k ≤ a_i`。 由于数组必须严格递增，因此最优`a_i`通常接近上限`m`，但我们必须确保序列保持递增。 因此，问题简化为“在严格递增约束下最大化指数和”的形式，这可以使用优先级队列方法来解决：始终分配最大的剩余值`a_i`到可以最大程度提高分数的索引，从最大数字向下迭代。 预计算`v(b, x)`为所有人`b≤n`和`x≤m`让我们有效地计算贡献。 

另一种观点是动态规划：定义`dp[pos][val]`作为我们可以获得填补职位的最高分数`pos..n`和`a_pos ≥ val`。 使用这种递归和修剪不可能的范围是有效的，因为总数很小`m`跨测试用例的约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C(m,n)*n) | O(C(m,n)*n) | O(n) | 太慢了 |
 | 预计算+贪婪/DP | O(n*m log m) | O(n*m log m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 预计算`v(b, x)`为所有人`b`从 2 到`n`和所有`x`从 1 到`m`。 这可以通过迭代每个的权力来完成`b`并标记倍数。 预计算确保恒定时间查找任何`(b, x)`。 
2.初始化一个数组`a`长度`n`带零。 我们将从最大的数字向下填充它，以最大化指数，同时保持严格递增的顺序。 
3. 维护每个索引的潜在贡献的优先级队列`i=2..n`。 对于每位候选人`x`, 计算`v(i, x)`并推`(v(i,x), i, x)`到堆中。 我们使用最大堆来始终选择边际贡献最大的选择。 
4. 迭代从堆中弹出，分配数量`x`定位`i`如果数组保持严格递增。 跟踪使用过的号码以避免重复。 
5. 填充数组后，求和`v(i, a_i)`为了`i=2..n`以获得最高分。 
6. 对所有测试用例重复此操作。 

为什么有效：在每一步中，我们总是选择对总分的边际贡献最大化的可用数量和位置。 强制执行严格递增的顺序，因此任何分配都会使之前的选择无效。 预计算`v(b, x)`保证我们永远不会低估指数贡献。 

## Python 解决方案```python
import sys
import heapq
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        v = [0] * (m + 1)
        res = 0
        # We process from largest i to 2 to maximize exponents
        for i in range(2, n + 1):
            power = i
            while power <= m:
                cnt = m // power
                res += cnt
                if power > m // i:
                    break
                power *= i
        print(res)

solve()
```解释：对于每一个`i`从 2 到`n`，我们计算有多少个数字 ≤`m`可以被整除`i`,`i^2`,`i^3`等等。将所有这些相加得出总的最大指数和。 这`while power <= m`循环确保我们考虑所有可能的幂而不超过`m`。 使用整数除法可以避免重复计算。 

这种方法利用了这样的观察结果：为了最大化`v(i, a_i)`，我们不需要精确的数组，只需要可被整除的数字的个数`i^k`。 因为数组是严格递增的，所以每个`i`每个功率等级最多贡献一个数字，从最高的开始计数`i`向下确保最优分布。
