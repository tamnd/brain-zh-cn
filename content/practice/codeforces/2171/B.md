 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组，其中一些条目标记为`-1`，代表空格。 我们的任务是用非负整数替换每个空格，以最小化连续元素之间的差值之和的绝对值。 形式上，如果我们定义`b[i] = a[i+1] - a[i]`对于所有有效的`i`，我们想要最小化`|sum(b)|`填空后。 此外，在达到此最小值的所有数组中，我们想要字典顺序最小的数组。 

第一个观察结果是差异数组的总和`b`简直就是`a[n] - a[1]`。 这简化了问题：与尝试单独优化每个差异不同，对绝对和重要的唯一数字是填充所有空白后数组的第一个元素和最后一个元素之间的差异。 

约束告诉我们`n`最多可以有 200,000 个，并且最多可以有 10,000 个测试用例。 这意味着任何复杂度低于每个测试用例 O(n) 的方法都会太慢。 我们需要线性扫描策略，避免嵌套循环或空白位置上的指数枚举。 

当所有元素都是时，就会出现微妙的边缘情况`-1`。 在这里，我们可以选择全零来获得零差和，并且这种选择在字典顺序上也是最小的。 另一种情况是只有第一个或最后一个元素为空时：将其设置为零可能在字典顺序上是最小的，但如果两端都是固定的，我们就无法将差值和降低到端点的绝对差以下。 

## 方法

 一种天真的方法会枚举所有可能的填充`-1`职位。 对于每个空白，我们可以尝试所有非负整数直到某个合理的界限（例如，10^6），计算结果`b`数组，并跟踪绝对和。 这对于小型数组可以正确工作，但对于 n = 2 * 10^5 来说速度慢得令人绝望。 操作计数以组合方式爆炸。 

关键的见解是`b`仅取决于`a[n] - a[1]`。 这意味着中间元素的选择不会影响最小可能的总和。 为了达到最小的金额，我们想要`a[1]`和`a[n]`考虑到约束条件，尽可能接近。 如果任一端点为空白，则将其设置为零有助于最小化总和和字典顺序。 对于中间的空白，字典顺序最小的选择是零。 一旦我们最佳地选择了端点，用零填充所有剩余的空白就会产生最小的绝对和和最小的字典序数组。 

这一观察结果将最初看起来需要仔细差异分析的问题简化为具有局部决策的简单线性传递。

 | 蛮力 | O(10^6^n) | O(10^6^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取当前测试用例的数组。 识别第一个和最后一个非`-1`元素。 如果所有元素都是`-1`，我们可以将所有内容设置为零并返回差值和为零。 
2. 对于数组中的每个空白元素，确定其值：

 - 如果第一个元素是`-1`，将其设置为零。 这最小化了绝对总和并且按字典顺序最小化。 
- 如果最后一个元素是`-1`，将其设置为零。 出于同样的原因，它减少了`|a[n] - a[1]|`。 
- 中间的任何其他空白都设置为零，以实现字典顺序最小数组。 
3. 填完所有空格后，计算差值之和，即`a[n] - a[1]`。 
4. 返回该和的绝对值以及填充的数组。 

工作原理：根据连续差值之和等于最后一个元素与第一个元素之间的差值的性质，用零填充中间元素不会改变总和。 通过调整端点来最小化绝对差异，并且按字典顺序，零是最小的。 因此，该算法保证了最小总和和最小字典顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Replace all -1 with zeros initially
        for i in range(n):
            if a[i] == -1:
                a[i] = 0
        
        # Minimal absolute sum is last - first
        min_abs_sum = abs(a[-1] - a[0])
        
        print(min_abs_sum)
        print(" ".join(map(str, a)))

solve()
```在代码中，我们首先替换所有`-1`条目为零。 这会自动处理字典最小化，因为零是最小的非负整数。 计算最小绝对和只是填充数组的最后一个元素和第一个元素之间的差。

 ## 边缘情况

 当所有元素都为`-1`，数组是`[0,0,...,0]`。 绝对和为零，并且实现了词典编排最小性，因为零是最小的整数。 当只有一个端点为空时，将其设置为零会减少绝对总和并保留字典顺序。 当不存在空格时，绝对和就是`abs(a[n]-a[0])`并且不需要任何改变。 该算法通过一次线性扫描正确处理所有这些场景。
