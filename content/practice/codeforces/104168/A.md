 ## 解决方案
 ## 问题理解

 我们给定一个正整数$n$，并且我们考虑所有因素对$(x, y)$这样$x \cdot y = n$与两者$x$和$y$正整数。 对于每一对，我们计算绝对差$|x - y|$，并且我们想要所有有效因子对的最大可能值。 

输入最多包含$2 \cdot 10^5$测试用例，每个测试用例都有一个整数$n$最多$10^9$。 这立即排除了任何通过扫描最多来尝试所有因素对的方法$n$，因为那太慢了。 即使枚举每个测试用例的所有除数也必须高效，因此任何解决方案都必须大致运行$O(\sqrt{n})$每次测试或更好。 

一个微妙的点是，这对$(x, y)$和$(y, x)$因为绝对值是等价的，所以我们只需要考虑除数$\sqrt{n}$。 

一个天真的错误是假设最大差异来自某个“随机”因子对，而不系统地检查除数。 例如，如果$n = 36$，可能的对包括$(1,36)$,$(2,18)$,$(3,12)$,$(4,9)$,$(6,6)$。 最大差异显然来自$(1,36)$, 给予$35$。 只检查连续除数或仅检查最接近的因子对的粗心方法会错过这一点。 

另一个常见的误解是认为最好的一对总是在附近$\sqrt{n}$。 这是错误的，因为接近性可以最大化产品的稳定性，而不是差异性。 在这里我们想要相反的目标。 

## 方法

 暴力方法将通过检查每个整数来生成所有因子对$x$从$1$到$n$，测试是否$x \mid n$，然后计算$y = n / x$。 这是正确的，因为它明确枚举了所有有效对并评估目标。 然而，这需要$O(n)$每个测试用例，变成$2 \cdot 10^5 \times 10^9$在最坏的情况下，这是不可行的。 

关键的观察是因子对以对称形式出现$\sqrt{n}$。 每个除数$x \le \sqrt{n}$定义一个独特的合作伙伴$y = n/x$。 所以我们只需要迭代到$\sqrt{n}$，这大大减少了搜索空间。 

一旦我们考虑除数$x$，该对是固定的，贡献是$|x - n/x|$。 我们只是跟踪所有这些对的最大值。 

除了有效的除数枚举之外，不需要更深层次的组合结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n)$每次测试 |$O(1)$| 太慢了 |
 | 除数枚举 |$O(\sqrt{n})$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 对于给定的$n$，将答案变量初始化为零。 这将存储所有因子对中找到的最佳绝对差异。 
2. 迭代$i$从$1$到$\lfloor \sqrt{n} \rfloor$。 我们只考虑$i$作为候选因素。 
3.如果$i \cdot i = n$， 然后$i$是完美平方根因子对$(i, i)$，它的差异为零，因此不会改善答案。 
4.如果$i \mid n$，计算配对除数$j = n / i$。 现在我们有了一个有效的因子对$(i, j)$。 
5. 计算$|i - j|$如果该值大于当前最大值，则更新答案。 
6. 循环结束后，输出找到的最佳值。 

重要的推理步骤是仅检查$\sqrt{n}$保证我们只看到每个除数一次，并且每个除数唯一地确定其互补伙伴。 

### 为什么它有效

 每个因子对$(x, y)$和$x \cdot y = n$有一个元素不超过$\sqrt{n}$。 因此，迭代所有$i \le \sqrt{n}$那个鸿沟$n$一次性枚举所有不同的对。 由于目标仅取决于对而不是排序，因此不会错过任何候选者，并且不会出现重复影响正确性。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        best = 0
        
        r = int(math.isqrt(n))
        for i in range(1, r + 1):
            if n % i == 0:
                j = n // i
                if i != j:
                    diff = j - i
                    if diff > best:
                        best = diff
        
        print(best)

if __name__ == "__main__":
    solve()
```该解决方案使用整数平方根来限制循环。 对于每个除数$i$，我们计算它的伙伴$j$并仅在以下情况下评估差异$i \neq j$。 该条件避免了完美平方的冗余零更新，尽管包含它们不会影响正确性。 

一个微妙的实现细节是使用`math.isqrt`而不是浮点平方根以避免精度问题。 自从$n \le 10^9$，整数平方根安全且快速。

## 测试用例```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        best = 0
        r = math.isqrt(n)
        for i in range(1, r + 1):
            if n % i == 0:
                j = n // i
                if i != j:
                    best = max(best, abs(i - j))
        out.append(str(best))
    return "\n".join(out)
