 ## 解决方案
 ## 问题理解

 我们有一圈怪物，每个怪物都有一个能量水平。 怪物按照固定的顺时针顺序攻击它们的邻居：怪物 1 攻击怪物 2，怪物 2 攻击怪物 3，依此类推，最后一个怪物攻击第一个怪物。 攻击会通过攻击者的能量来减少邻居的能量，但能量永远不会低于零。 我们被要求确定哪些怪物在经过极大量的攻击后仍然具有正能量，具体是$10^{100}$重复这个过程。 

输入由多个测试用例组成。 每个测试用例指定怪物的数量$n$和初始能量水平$a_1, a_2, \dots, a_n$。 攻击稳定后，输出应该列出具有正能量的怪物。 自从$n$可以达到$2 \cdot 10^5$每个测试用例和所有测试用例的总和最多为$2 \cdot 10^5$，任何比每个测试用例的线性复杂度更差的解决方案都可能太慢。 模拟$10^{100}$直接回合是不可能的； 我们必须找到一种无需迭代即可预测最终能级的方法。 

非明显的边缘情况包括怪物能量非常低而其邻居能量高的场景。 例如，如果$a = [1, 10]$，第一只怪物在第一次攻击时不能将第二只怪物的能量降低到9以下，但在重复的回合中，第二只怪物的能量会逐渐减少直至为零。 另一个边缘情况是当所有怪物的能量为零时：输出应该为零怪物。 粗心的实施可能会忘记攻击的循环性质，导致对第一个或最后一个怪物的计算错误。 

## 方法

 暴力方法很简单：模拟每个攻击回合，根据邻居的攻击更新每个怪物的能量。 每轮结束后，检查能量水平是否发生变化。 如果它们停止变化，则模拟已稳定。 这种方法原则上是正确的，但不可行，因为所需的轮数可能是巨大的，特别是当$n$并且能量很大。 即使每个测试用例进行一百万轮也太慢了。 

关键的观察是，每个怪物的最终能量仅取决于其自身的初始能量和它从前一个怪物受到的最大伤害。 对于索引处的怪物$i$，经过很多轮之后，它的能量不能超过其邻居攻击后剩余的能量。 更正式地说，怪物的稳定能量$i$是其能量超过前一个怪物能量的部分，下界为零。 换句话说，如果我们知道每个怪物$a_i$和它的左邻居$a_{i-1}$，无限轮后可能的最小能量为$\max(0, a_i - a_{i-1})$，假设攻击以最佳方式传播。 诀窍是选择一个起点，以便传播捕获循环依赖关系。 

一旦我们旋转圆圈，从能量差异最小的怪物开始，考虑到它的前一个怪物，计算就变得简单了：怪物的最终能量是比前一个怪物多的能量。 对圆圈求和，我们可以计算出每个测试用例的线性时间内哪些怪物存活下来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n × max(a_i)) | O(n × max(a_i)) | O(n) | 太慢了 |
 | 通过能量传播实现最优 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 识别初始能量最小的怪物，因为这将在循环传播中充当稳定的锚点。 选择最小的能量可以让我们减少需要调整的怪物数量并简化循环依赖。 
2. 旋转阵列，使这个最小的怪物成为概念线性阵列中的“第一个”。 这种轮换是概念性的； 物理上，我们可以使用指数模$n$。 
3. 计算每个怪物的最终能量，即其能量超过前一个怪物能量的部分。 使用公式$\text{final}_i = \max(0, a_i - a_{i-1})$，处理指数模$n$以保护圆圈。 这一步确保我们正确捕获前一个怪物攻击的效果，因为在无限轮之后，怪物保留的能量不能超过其邻居攻击后剩余的能量。 
4.收集所有最终能量大于零的怪物。 这些是之后幸存的怪物$10^{100}$回合。 
5. 按升序输出存活怪物的数量及其指数。 

为什么它有效：关键的不变量是，在无限轮之后，没有怪物可以保留比其前任攻击后剩余的能量更多的能量。 通过从最小怪物开始，我们可以防止任何可能在圆周上传播的下溢。 max(0, ...) 公式确保负能量被限制为零。 这保证了正确性，因为任何其他旋转都会产生相同的结果或超出计算能量，这在攻击规则下是不可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        min_a = min(a)
        min_idx = a.index(min_a)
        
        # Rotate array to start from min energy monster
        rotated = a[min_idx:] + a[:min_idx]
        final_energy = [0] * n
        final_energy[0] = rotated[0]
        
        for i in range(1, n):
            final_energy[i] = max(0, rotated[i] - rotated[i-1])
        
        # Recover original indices for output
        result_indices = []
        for i, val in enumerate(final_energy):
            if val > 0:
                result_indices.append((i + min_idx) % n + 1)
        
        print(len(result_indices))
        if result_indices:
            print(' '.join(map(str, sorted(result_indices))))

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量并迭代它们。 对于每个测试用例，它都会识别具有最小能量的怪物来锚定循环计算。 然后它使用与前一个怪物的差异来计算最终能量值。 索引被转换回原始数组，并按顺序打印幸存的怪物。 

微妙的实现选择包括索引转换的模运算和使用 max(0, ...) 将能量钳位为零。 当映射回基于 1 的索引时，相差一错误很常见。
