 ## 解决方案
 ## 问题理解

 我们得到了一个多重集$2n$卡片，其中每个数字来自$1$到$n$总共出现两次。 这些牌平分给两名玩家，即你和 Nene，所以你们每个人都持有$n$牌。 我们只得到你的手； Nene 的手牌被隐含地确定为每个值的剩余副本。 

游戏收益为$2n$轮流，在你和内内之间交替，从你开始。 每回合包括从当前手牌中选择一张牌，如果该值之前已经出现在桌子上，则可以选择得分，然后将牌永久放置在桌子上。 

该表只记录某个值以前是否见过，而不记录它出现了多少次。 因此，每个值最多为每个玩家贡献一次得分机会，特别是在第二次整体发挥该值时。 

Nene 的最佳玩法有两个层次的目标：她首先最大化自己的得分，而在所有此类策略中，她最小化你的最终得分。 

任务是计算在给定两手初始牌的情况下，您可以保证自己获得的最大点数。 

约束条件$\sum n \le 2 \cdot 10^5$意味着任何解决方案都必须接近每个测试用例的线性。 每个测试用例的任何二次方都会失败。 这排除了模拟所有有效的游戏演变或尝试将两个玩家的策略建模为完整的游戏树。 

一个微妙的一点是，你手中的值的顺序很重要，但只能通过频率结构来实现。 一个天真的错误是假设每个值独立地贡献一些东西，比如“如果我有两个副本，我就得到 1 分”。 这是错误的，因为内内可以控制命令来阻止或延迟得分机会。 

另一种失败模式来自于忽略交互：持有两个副本的值并不自动安全。 例如，如果 Nene 在您之前玩了第二个副本，她就可以领取该分数。 

## 方法

 暴力方法会尝试用递归或游戏状态来模拟游戏。 在每一步中，两名玩家都会选择一张牌，内内的选择取决于未来的结果。 该状态包括哪些牌留在双手中以及哪些值已出现在桌子上。 这创造了一个巨大的分支因子：高达$n!$每个玩家可能的订单。 即使有记忆，状态空间也包括卡片和表历史的子集，这是指数级的并且远远超出了可行的限制。 

关键的简化来自于观察，对评分唯一重要的是每个值第二次出现的相对时间。 每个值最多为任一玩家贡献一分，特别是先玩第二个副本的人。 

现在重新解释这个过程：每个值$x$有两次出现，一次出现在你的手中，一次出现在 Nene 的手中（或者两者都在你的手中，或者两者都在她的手中）。 第一次播放某个值时不会执行任何操作。 第二次决定谁得分，取决于是你还是内内。 

因此，每个值的行为就像“两个代币的竞赛”，其中第二步决定了该点的所有权。 

现在考虑一个您持有两份副本的值。 您最终肯定会同时参加这两种比赛，因此您可以控制第一次和第二次出场。 这意味着 Nene 永远不会根据该值得分，但只有当 Nene 在您第二次玩之前已经玩过至少一份副本时，您才能获得一分。 然而，由于内内是敌对的，她可以安排她的比赛以最大限度地破坏。 

正确的观点是根据你持有的副本数量对价值进行分类：

 - 0 份：与您无关。 
- 1 份：有争议的价值。 
- 2 个副本：Nene 控制动态的潜在强制点。 

关键的观察是，最佳游戏减少为贪婪地匹配“机会”，你可以在 Nene 最佳地使用自己的机会之前强制第二次出现。 

更具体的重新表述是，答案仅取决于有多少个值恰好出现在您的手中。 这些是 Nene 可以控制这两种情况发生的唯一值，从而防止您可靠地确保第二次激活。 出现两次的值完全在您的控制之下，但它们仍然受到时间限制，并且出现一次的值将充当最佳计划中的干扰点。 

这导致了贪婪的配对想法：您尝试最大化值的数量，以确保您在 Nene 之前播放第二次出现。 

最后的简化是，答案等于出现次数允许您在诱导排序中“超过” Nene 的值的数量，这减少为计算有多少个值在您手中恰好出现一次，然后除以最佳抵消效果后的 2。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 数一下每个值在你手中出现了多少次。 由于每个值总共出现两次，我们可以将 Nene 的计数隐式推断为$2 - \text{your count}$。 这将问题转化为频率分析而不是游戏模拟。 
2. 根据您持有的副本数量对每个值进行分类。 我们只关心您是否拥有 0、1 或 2 份副本。 具有 0 个副本的值永远不会直接影响您的分数。 
3. 观察具有两份副本的值与具有一份副本的值的行为不同。 如果你持有两个副本，你就可以控制两个位置，但内内的最佳发挥仍然会影响你是否得分，因为得分取决于第一个出现是否已经出现在桌子上。 
4. 跟踪您仅一次保存了多少个值。 这些是“灵活的交互点”，Nene 可能会在这些点上引发时间冲突。 
5. 核心贪婪结构出现：每个具有单个副本的值都可以被认为需要一个“对手干扰槽”来拒绝你得分。 由于内内发挥最佳，她利用轮流尽可能有效地阻止这些机会。 
6. 对这些单次出现值进行最佳配对，有效地将对抗性调度下的安全得分机会数量减少一半。 
7. 最终答案是在取消效果后您仍然可以强制获得第二个外观优势的值的数量。 

### 为什么它有效

 游戏简化为控制第二次出现的顺序。 每个值在其第二次出现时恰好贡献一个潜在点，并且较早强制第二次出现的玩家决定所有权。 由于两名玩家都采取最佳行动，并且 Nene 拥有完美的知识，因此您无法完全控制的任何价值都表现为可以被窃取或无效的共享资源。 

不变的是，在每次移动之后，唯一重要的剩余信息是哪些值在桌子上恰好出现过一次，以及哪个玩家更接近触发第二次出现。 贪婪的计数确保我们始终将内内的最佳阻挡能力与你脆弱的单打相匹配，只留下不可避免的得分机会。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = [0] * (n + 1)
        for x in a:
            freq[x] += 1
        
        single = 0
        for i in range(1, n + 1):
            if freq[i] == 1:
                single += 1
        
        print(single // 2)

if __name__ == "__main__":
    solve()
```该代码首先为您的手牌构建一个频率数组。 由于值在范围内$1$到$n$，数组就足够了，而且比字典更快。 提取的关键统计数据是仅出现一次的值的数量。 

输出公式`single // 2`来自在最佳对抗性调度下对这些单例值进行配对。 整数除法反映了这样一个事实，即每对易受攻击的值都可以被 Nene 使用她的一个回合有效地破坏，只留下其中的一半作为保证可实现的点。 

一个常见的实施错误是尝试模拟转弯或跟踪表状态。 这是不必要的，并且会导致不正确的贪婪逻辑，因为实际的游戏仅取决于频率结构，而不是顺序。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = [0] * (n + 1)
        for x in a:
            freq[x] += 1
        single = sum(1 for i in range(1, n + 1) if freq[i] == 1)

 ## 边缘情况

 当$n = 1$，总共只有一个值出现两次，因此您的手牌中恰好包含一个副本，而 Nene 则包含另一个副本。 该算法计算出你手上的零个单子，产生零，这与第二名总是输掉这一点的事实相匹配。 

当你手中的所有值都是不同的时，每个值都是一个单例。 该算法贪婪地将它们配对，产生大约一半的保证点。 这与 Nene 总是可以反映你的尝试并通过最佳排序窃取一半机会的想法相匹配。 

当所有值在你的手牌中出现两次时，Nene 就没有这些值。 单例计数为零，因此答案为零。 即使你控制了所有卡牌，得分仍然需要第二次出现时间，而内内可以通过确保她永远不会提供对你有利的早期事件来完全延迟你的得分。
