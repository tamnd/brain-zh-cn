 ## 解决方案
 ## 问题理解

 我们给定一个圆`n`怪物，每个都有初始能量水平`a_i`。 他们的编号是从`1`到`n`，并且每个怪物在一轮中同时攻击其顺时针邻居。 当怪物拥有能量时`x`用能量攻击邻居`y`，邻居的新能量变为`max(0, y-x)`。 攻击不会减少攻击者的能量。 内内将施展“攻击你的邻居”法术的次数达到天文数字，有效`10^100`，这保证了过程稳定——一旦模式重复，怪物的能量就不会进一步减少。 

任务是识别稳定后仍具有非零能量的所有怪物。 输出必须列出此类怪物的数量及其指数。 

这些约束足够严格，足以排除简单的模拟。 每个测试用例最多可以有`2*10^5`怪物，所有测试用例的总和是`2*10^5`。 蛮力方法模拟`10^100`回合是不可能的。 我们需要一种在每个测试用例的线性时间内工作的方法。 边缘情况包括所有怪物从零能量开始，单个怪物的最大能量被零包围，或者围绕圆圈传播减少的均匀能量水平。 

由于循环索引，简单的模拟还会面临相差一错误的风险。 例如，最后一个怪物攻击第一个怪物，因此需要仔细的模运算以避免跳过或重复计算攻击。 

## 方法

 暴力解决方案将重复应用该咒语，直到所有变化稳定为止。 每轮需要 O(n) 时间，因为每个怪物攻击一次。 即使稳定发生在`O(n)`轮，这导致每个测试用例的复杂度为 O(n^2)，这对于上限来说太慢了`2*10^5`。 

关键的观察是，每个怪物的最终能量仅取决于它自己的能量和它左边邻居的能量，因为在很多轮之后，怪物的能量会因为它的前一个怪物的重复攻击而减少，直到它不能进一步减少为止。 具体来说，怪物的最终能量`i`是`max(0, a[i] - a[i-1])`从最弱的怪物开始进行一定的轮换。 这是因为初始能量最小的怪物永远不会减少到零以下，并形成稳定的“起点”。 一旦我们选择了这个枢轴，我们就可以计算绕圆的一次线性传递中的每个最终能量。 

线性时间解决方案之所以有效，是因为能量减少过程是单调的：每次攻击要么减少邻居，要么使其为零。 能量不会增加，因此系统会快速收敛到无需模拟所有回合即可计算的固定点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(n^2) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 找出初始能量最小的怪物。 它的索引成为枢轴，因为这个怪物永远不会减少到零以下，并且可以作为稳定的起点。 选择任何其他怪物可能需要额外的旋转才能达到稳定状态。 
2. 从枢轴开始，按循环顺序遍历怪物。 对于每个怪物`i`，计算其最终能量为`max(0, a[i] - a[previous])`， 在哪里`previous`是本次遍历中紧随逆时针方向（左邻居）的怪物。 这确保我们以正确的顺序考虑所有减少。 
3.收集所有最终能量为正的怪物。 存储它们的索引（从 1 开始）以用于输出。 
4. 按升序打印剩余怪物的数量及其索引。 

其原理：不变量是稳定后，每个怪物的能量仅减少其自身初始能量和从其邻居传播的能量中的最小值。 通过选择最小能量怪物作为枢轴，我们保证没有怪物的能量被错误地减少到零以下，并且减少传播自然地尊重循环依赖性。 由于每个能量只计算一次，因此会产生正确的最终状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # find index of minimum element
        min_val = min(a)
        pivot = a.index(min_val)
        
        res = [0] * n
        prev = a[pivot]
        # traverse in circular order starting from pivot
        for i in range(1, n+1):
            idx = (pivot + i) % n
            res[idx] = max(0, a[idx] - prev)
            prev = a[idx]
        
        remaining = [i+1 for i, val in enumerate(res) if val > 0]
        print(len(remaining))
        if remaining:
            print(*remaining)

if __name__ == "__main__":
    solve()
```在代码中，我们首先读取测试用例的数量。 对于每个测试用例，我们都会找到能量最小的怪物作为枢轴。 然后我们计算单次循环遍历中的稳定能量。 最后，我们收集能量非零的怪物的指数。 模运算可确保循环访问而不会出现差一错误。 通过仅存储最终能量，我们避免了不必要的空间和计算。

 ## 边缘情况

 如果所有怪物都以零能量开始，则主元选择正确地识别任何零，并且所有计算的最终能量都为零。 用于输入`0 0`，遍历产生`[0, 0]`， 导致`0`剩余的怪物。 如果一只怪物拥有被零包围的极高能量，它就会因为邻居的攻击而幸存下来
