 ## 解决方案
 ## 问题理解

 我们给定一个大小为的方阵$n \times n$最初用零填充。 Nene 可以执行两种类型的操作：将整行设置为排列$1$通过$n$或者将整个列设置为这样的排列。 目标是最大化所有矩阵条目的总和，最多使用$2n$运营。 

关键的观察是每个操作都允许我们放置数字$1$通过$n$在行或列中。 应用排列后任何单行或单列中的数字总和始终为$\frac{n(n+1)}{2}$因为来自的整数之和$1$到$n$不随订单而改变。 因此，矩阵的总和取决于哪些条目被后续操作覆盖。 如果我们小心地将最大的数字放在不被覆盖的位置，我们就可以最大化总和。 

限制条件适中：$n$上升到$500$和总和$n^2$所有测试用例不超过$5 \cdot 10^5$。 这使我们能够使用$O(n^2)$每个测试用例的算法不超过时间限制。 小的$n$bound 还允许我们显式地构造运算，而不仅仅是计算总和。 

非明显的边缘情况包括$n = 1$，其中唯一的数字是$1$， 和$n = 2$，其中多种策略可以实现相同的最大总和，但需要仔细选择行和列排列，以避免用较小的数字覆盖较大的数字。 

## 方法

 暴力方法会尝试行和列操作的所有可能组合以最大化总和。 每个操作都是一个排列$n$数，并且有$n$行和$n$可供选择的列。 对于每个操作，我们将计算结果矩阵的总和。 这种方法原则上是正确的，但不切实际：即使对于$n=10$，每行的排列数为$10!$并且有$2n$行/列，使得总组合达到天文数字。 

关键的见解是，通过将最大的数字放入矩阵中而不覆盖它们来最大化总和。 由于每一行和每一列都可以独立设置，因此简单的贪心策略就可以发挥作用。 对于奇数$n$，我们可以应用一种模式，首先用递增的排列填充所有行，然后用相同的排列填充所有列，但旋转以对齐主对角线中最大的数字。 这确保每个单元在至少一次操作中接收尽可能大的数字。 对于甚至$n$，行和列排列的简单交替模式可确保不会覆盖不必要的数字。 

这将问题简化为建设性的贪婪算法：将排列分配给行和列，使得最大的数字占据尽可能多的不同单元格。 这保证了最大总和$2n$运营。

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$。 初始化一个操作计数器并准备一个列表来存储它们。 
2. 创建基本排列$p = [1, 2, \dots, n]$。 
3. 对于行$i = 1$到$n$，附加一个类型1操作：分配排列$p$划船$i$。 这确保每行包含从 1 到$n$。 执行此步骤后，每一行的总和为$\frac{n(n+1)}{2}$，总和是$n \cdot \frac{n(n+1)}{2}$。 
4. 对于列$i = 1$到$n$，附加一个类型2操作：分配排列$p$到专栏$i$。 为了避免覆盖主对角线中最大的数字，请将排列移动$i-1$列的位置$i$。 这会将最大的数字沿对角线对齐，同时用较小的数字填充剩余的条目。 
5. 计算总和$s$矩阵为$s = n \cdot \frac{n(n+1)}{2}$。 输出$s$和操作列表，不超过$2n$运营。 

为什么有效：每行和列的操作保证该行或列包含所有数字$1$到$n$。 通过在填充行后仔细排序列排列，我们确保最大的数字占据不同的单元格而不被覆盖。 由于每行和每列的总和是固定的，并且使用排列来最佳地对齐大数，因此总和最大化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = n * (n + 1) // 2 * n  # sum of all rows initially filled
        ops = []

        perm = list(range(1, n + 1))
        for i in range(1, n + 1):
            ops.append((1, i, perm[:]))  # type 1, row i
        for i in range(1, n + 1):
            shifted = perm[i-1:] + perm[:i-1]  # rotate to align diagonals
            ops.append((2, i, shifted))

        print(s, len(ops))
        for op in ops:
            print(op[0], op[1], *op[2])

if __name__ == "__main__":
    solve()
```该解决方案为每行和每列构造一个排列。 行操作确保每一行包含从 1 到$n$。 列运算移动排列以最大化对角线上的总和。 旋转排列可防止覆盖行操作已放置的最大数字。 边界条件如$n=1$处理很自然，因为排列对于单个元素来说是自动正确的。
