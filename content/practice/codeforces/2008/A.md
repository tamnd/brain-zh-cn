 ## 解决方案
 ## 问题理解

 我们被要求决定是否可以为由一定数量的一和二组成的数组中的每个元素分配正号或负号，以使总和为零。 每个测试用例提供两个整数，$a$和$b$，代表数组中有多少个1和2。 输出是简单的“是”或“否”，具体取决于是否存在这样的符号分配。 

鉴于限制条件，$0 \le a,b < 10$，我们知道数组大小非常小。 这意味着即使是尝试所有可能的符号分配的强力解决方案也会快速运行，因为分配的总数为$2^{a+b}$，不能超过$2^{18} = 262{,}144$在最坏的情况下。 然而，这个问题有一个结构，允许我们进行数学推理，而无需枚举每个作业。 

当一种类型的数字缺失或数量较少时，就会出现边缘情况。 例如，如果$a=0$和$b=1$，数组是`[2]`并且没有办法达到零。 另一个微妙的情况是当存在像这样的组合时$a=1$和$b=1$，其中数组的总和为奇数 (1+2=3)，并且不能分成相等的正贡献和负贡献。 这些小的奇/偶和是解决方案的关键。 

## 方法

 简单的暴力方法会迭代每个元素的“+”和“-”符号的所有可能组合。 对于每个组合，它将计算总和并检查它是否等于零。 这是可行的，因为考虑了每个可能的符号分配，但即使数组长度很小，它也是矫枉过正且缺乏洞察力。 

关键的观察来自于分析和与奇偶性。 每个 1 贡献 +1 或 -1，每个 2 贡献 +2 或 -2。 要达到总和为零，总和必须为偶数，因为所有数字都是整数，并且有符号整数的总和必须精确平衡。 如果$2b + a$（所有符号都为正时的和）是奇数，没有办法分成相等的两部分。 此外，如果有两个，则只能将它们分割为 2 的倍数。这意味着，如果$b$是奇数，我们需要至少两个1来补偿才能达到零； 否则，这是不可能的。 如果$b$是偶数，任意数量的 1 都可以配对或以零和形式省略。 

这种洞察力使我们能够立即决定答案，而无需迭代。 这将为每个测试用例生成一个恒定时间的解决方案。

 ## 算法演练

 1. 对于每个测试用例，读取整数$a$和$b$代表 1 和 2 的计数。 
2. 如果所有数字的总和，$a + 2b$，是奇数，立即打印“No”。 奇数和永远不能分成两个带有正号和负号的相等和。 
3.如果$b$是偶数，打印“Yes”。 偶数总是可以分成+2 和-2 对。 然后可以类似地配对或以互补的方式相加以保持零和。 
4. 如果$b$是奇数，检查是否$a \ge 2$。 两个可以补偿单个未配对的两个，因此如果 $a \ge 2" 则打印“Yes”。否则，打印“No”。
 5. 对所有测试用例重复此操作。 

这样做的原因是每个配置都可以简化为总和是否均匀以及我们是否可以使用 1 来配对不平衡的两个。 无需枚举各个符号分配，因为奇偶校验规则完全确定可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    total = a + 2 * b
    if total % 2 != 0:
        print("No")
    elif b % 2 == 0:
        print("Yes")
    else:
        print("Yes" if a >= 2 else "No")
```该解决方案首先计算所有正数的总和。 如果这个总数是奇数，+ 和 - 的组合不能产生零，所以我们打印“No”。 如果总数是偶数，我们检查二的个数。 即使是两个人也总是可以完美平衡。 如果两个的数量是奇数，我们需要至少两个与剩下的两个配对，否则零和是不可能的。 这实现了算法演练中描述的精确推理。

 ## 边缘情况

 用于输入`0 0`，总和为 0。算法打印`Yes`因为空数组的总和为零，这是正确的。 用于输入`1 1`，总和为 3（奇数），因此算法打印`No`。 为了`2 1`，总和是 4（偶数），一二是奇数，但是`a >= 2`，所以它打印`Yes`。 所有这些示例都证实奇偶校验和配对逻辑正确处理边缘情况。
