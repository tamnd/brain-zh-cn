 ## 解决方案
 ## 问题理解

 我们得到从 1 开始的无限自然数序列。Polycarp 精确地执行特殊的移除操作$x$次。 每个操作都会删除位于多个位置的所有数字$y$在当前序列中。 经过这些操作，我们想要找到最终的数字$k$最终序列中的第 - 个位置，或者确定少于$k$剩下的数字。 

输入提供多个测试用例。 每个测试用例给出$x$,$y$， 和$k$。 数字$x$和$y$可以大到$10^{12}$，这意味着任何显式构造序列或模拟所有删除的方法都是不可能的。 输出是每个测试用例的一个整数，代表$k$第 - 个剩余数字，或$-1$如果序列太短。 

主要挑战是有效处理极大的序列。 一个简单的模拟会尝试最多$10^{12}$运算，这在计算上是不可行的。 需要对每次操作删除多少数字以及数字最终在哪里进行仔细的数学推理。 

边缘情况出现时$y=1$，因为每个操作都会删除所有剩余的数字，并且当$k$太大以至于序列在到达它之前就已经耗尽了。 例如，如果$x=1$,$y=1$,$k=1$，剩余序列为空，答案必须是$-1$。 如果$x$很大但是$k$相对于移除数量来说很小，答案存在并且可以使用公式计算。 

## 方法

 蛮力方法很简单：维护一个数字数组并迭代删除每个数字$y$第-个元素$x$次。 这正确地模拟了操作，但每次删除都是按长度序列进行的$n$成本$O(n)$时间，并重复$x$次导致$O(x \cdot n)$，这对于$n, x$最多$10^{12}$。 

关键的观察是，之后$x$操作时，剩余数字的位置遵循一定的模式。 具体来说，每次操作都会从每个数字中删除一个数字$y$连续的数字。 如果我们将序列的最终长度表示为$n_{\text{final}}$，然后每个操作都会缩放原始序列中数字的有效索引。 使用这个，我们可以对我们必须跳过才能到达的原始数字的数量进行建模$k$最终序列中的第 - 个数字。 

形式上，如果我们表示$z$作为之前删除的数字的数量$k$-th 个数，我们可以推导出线性丢番图关系：$$\text{remaining numbers} = \text{original number} - \text{number of removed multiples of } y$$利用这个关系，我们可以有效地确定$k$-第一个数字通过对原始序列进行二分搜索，而不模拟每次删除。 二分查找检查原始序列中当前候选数是否至少离开$k$之后的数字$x$拆除作业。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(x * n) | O(x * n) | O(n) | 对于 n, x 来说太慢了$10^{12}$|
 | 二分查找 + 数学 | O(log(k * y * x)) | O(log(k * y * x)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$x$,$y$,$k$。 
2. 定义函数`count_remaining(n)`如果我们考虑第一个，则返回剩余元素的数量$n$执行后的自然数$x$移除操作：$$\text{remaining} = n - x \cdot \left\lfloor \frac{n-1}{y} \right\rfloor$$该公式来自以下事实：每次删除大约删除$n//y$数字，并做到这一点$x$倍倍增此效果。 
3. 初始化二分查找边界：`low = 1`,`high = k * y * x`。 上限是保守的； 在最坏的情况下，每次删除都会跳过一个数字$y$职位。 
4. 执行二分查找：

 - 计算`mid = (low + high) // 2`。 
- 如果`count_remaining(mid) >= k`， 放`high = mid`。 
- 否则，设置`low = mid + 1`。 
- 重复直到`low == high`。 
5. 二分查找后，`low`是原始序列中的最小数字，使得至少$k$之后剩余的数字$x$搬迁。 
6. 如果`count_remaining(low) < k`， 输出`-1`; 否则输出`low`。 

为什么它有效：公式`count_remaining(n)`严格递增于$n$。 二分查找利用这种单调性来找到最小的数字$n$即满足条件。 正确性来自于将移除建模为以下倍数$y$，二分查找确保我们准确地落在$k$-第 剩余数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(x, y, k):
    # function to compute number of remaining elements after x removals in first n numbers
    def count_remaining(n):
        return n - x * ((n - 1) // y)
    
    low, high = 1, k * y * x
    while low < high:
        mid = (low + high) // 2
        if count_remaining(mid) >= k:
            high = mid
        else:
            low = mid + 1
    return low if count_remaining(low) >= k else -1

t = int(input())
for _ in range(t):
    x, y, k = map(int, input().split())
    print(solve_case(x, y, k))
```该解决方案为剩余数字定义了一个辅助函数，然后对原始数字位置应用二分搜索。 的选择`high = k * y * x`保证解在界限内，避免无限搜索。 由于任意精度，在 Python 中处理大整数是安全的。
