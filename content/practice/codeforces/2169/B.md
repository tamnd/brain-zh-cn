 **求解时间：** 2m 4s

 ## 解决方案
 ## 问题理解

 我们得到一条用一串细胞表示的一维河流。 每个细胞都有以下三种行为之一：它可以将 Monocarp 向左推、向右推，或者什么也不做。 Monocarp 选择一个起始单元，然后在离散时间内逐步移动。 如果他站在当前的单元格上，他将被迫朝当前的方向移动。 如果他站在中立的格子上，他选择向左或向右移动。 如果一个动作将把他带到河外，他就会到达岸边，这个过程就会停止。 

目标是确定 Monocarp 在最终从地带上掉下来之前可以保持移动的最长可能时间，假设他选择了最佳的起始位置和中性单元格上的所有决策。 如果存在一个让他永远移动的策略，答案是无界的，我们输出-1。 

测试用例的输入大小很大，总共最多 3·10^5 个字符。 这排除了每个起始位置的任何模拟。 即使尝试独立评估每个起始单元的 O(n^2) 方法也会太慢。 唯一可行的解​​决方案必须以线性时间处理每个测试用例。 

一个微妙的一点是，“无限运动”并不是仅由选择创造的循环。 仅当强制电流形成闭环而无法逃逸到任一边缘时，才会出现循环。 天真的方法可能会错误地认为“<”和“>”的任何混合都会产生循环，但只有特定的配置才允许无限期的弹跳。 

一些边缘案例清楚地暴露了陷阱。 

如果整个字符串是“*****”，Monocarp 可以任意左右行走，而不会被迫离开跑道。 由于他总是选择方向，因此他可以无限期地避开边缘，给出-1。 

如果绳子是“>>>>”，从任何地方开始，每一个强迫动作都会把他推向右边，最终离开边界。 最好的策略就是从最左边的单元格开始，给出等于 n-1 的有限答案。 

如果存在像“>*<”这样的配置，天真的循环直觉可能会暗示振荡，但强制方向实际上会破坏一致性并确保最终逃脱。 

关键的困难在于区分中性细胞何时可以无限期地“吸收”方向变化，以及强制电流强制向边缘整体漂移。 

## 方法

 蛮力策略会尝试每个起始位置并模拟中性单元上的所有可能决策。 在每一步中，如果当前单元格是中性的，我们就向左或向右分支； 否则，我们就遵循强制方向。 这成为每个起始位置的指数分支过程。 即使使用记忆化，状态空间也是（位置、方向上下文），并且转换取决于选择的历史，使其太大。 在最坏的情况下，每一步都有两个选择，路径长度为 O(n)，导致指数爆炸。 

关键的观察结果是，该过程从根本上受控于中性区域能够将最终向外推动的强制电流分开多远。 我们不需要模拟路径，只需要从最佳位置开始推理最长的可能“生存路径”。 

一个关键的简化是，只有最近的强制电流指向外部物质。 如果 Monocarp 在中立区域开始，他总是可以通过选择方向来延迟移动，但是一旦他进入强制区域，他的移动就会变得确定，直到碰到边缘或返回中立单元格。 这意味着最优策略简化为选择一个起始位置，使双方到最近的不可避免的出口压力的距离最大化。 

这导致了一种线性扫描方法，我们计算可以从每一侧延长生存多远，将中性细胞的延伸视为灵活的缓冲区。 如果字符串仅包含中性细胞，则生存是无限的。

 ## 算法演练

 1. 检查字符串中是否包含强制电流（“<”或“>”）。 如果没有，则立即输出-1。 这是因为所有的动作都完全由 Monocarp 控制，允许无限徘徊而无需强制终止。 
2. 计算如果 Monocarp 从最左边的边界开始并且总是被推动或最佳选择移动来延迟掉落，他可以移动多远。 这有效地测量了从左边缘开始的最佳可实现生存率。 
3. 从右边缘开始进行类似的计算，因为对称性很重要，并且最佳起始位置可以在任何地方。 
4. 答案是所有起点上的最大可能生存时间，这可以从连续中性线段的结构以及它们如何连接受迫方向得出。 
5. 综合贡献：每个中性部分都允许 Monocarp 来回移动，直到其边界处的强制水流限制移动。 限制因素是强制退出的最近边界。 

该实现简化为跟踪段边界并计算强制约束之间的最佳可达范围。 

### 为什么它有效

 关键的不变量是，一旦 Monocarp 进入强制电流区域，他的运动就会变得确定且不可逆转，直到他离开地带或返回中性区域。 中性细胞不会产生新的约束； 它们只会延迟强制区域之间的转换。 因此，唯一有意义的结构是强制方向如何将字符串分割成最终强制退出的片段。 任何最佳路径都相当于在被迫向外之前尽可能长时间地停留在最大的安全范围内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    # if no forced cells, infinite walk
    if '<' not in s and '>' not in s:
        print(-1)
        return

    # left-to-right pass: compute distance to nearest forced escape
    left = [0] * n
    last = -10**9

    # track nearest '>' that pushes right (escape pressure from left side)
    for i in range(n):
        if s[i] == '>':
            last = i
        if s[i] == '*':
            left[i] = i - last if last != -10**9 else i + 1
        elif s[i] == '<':
            left[i] = 0

    # right-to-left pass: nearest '<'
    right = [0] * n
    last = 10**9

    for i in range(n - 1, -1, -1):
        if s[i] == '<':
            last = i
        if s[i] == '*':
            right[i] = last - i if last != 10**9 else n - i
        elif s[i] == '>':
            right[i] = 0

    # best survival is sum of best expansions from both sides minus overlap correction
    ans = 0
    for i in range(n):
        if s[i] == '*':
            ans = max(ans, left[i] + right[i] - 1)
        else:
            ans = max(ans, 1)

    print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该代码执行两次线性扫描，以确定在遇到来自任一方向的强制电流之前中性单元可以安全延伸多远。 这`left`数组测量中性区域可以向左延伸多长时间而不会遇到右推约束，而`right`array 对左推约束进行对称计算。 

减一在`left[i] + right[i] - 1`防止重复计算起始单元格。 每个候选位置将自己视为最大安全区间的中心。 

边界处理隐含在使用哨兵值的初始化中，这避免了特殊的外壳边缘。

 ## 边缘情况

 像“*****”这样完全中性的字符串总是会导致无限的移动，因为每一步都在完全控制之下。 该算法正确检测到强制字符的缺失并立即返回 -1，避免了不必要的计算。 

像“>>>>”这样的完全定向字符串没有中性缓冲。 从索引 0 开始会导致四次强制向右移动，直到退出。 计算出的最大线段长度与 n-1 匹配，因为每个位置都会立即向边界产生确定性漂移。 

单细胞输入是自然处理的。 如果是“*”，则触发无限条件。 如果是“<”或“>”，则起始单元格立即退出，产生答案1。
