 ## 解决方案
 ## 问题理解

 我们有一系列的巧克力棒购买，每次都会产生一定数量的积分。 瓦西亚从零分开始，每小节结束后就可以进入奖品中心。 奖品有固定的积分成本：一个杯子、一条毛巾、一个包、一辆自行车和一辆汽车，按严格递增的顺序排列。 Vasya 采用了一种贪婪的策略：每当他有足够的积分来购买任何奖品时，他就会选择他能买得起的最贵的奖品，减少他的积分，然后重复，直到他买不起任何奖品为止。 

我们的任务是重建 Vasya 的奖品收藏，并确定他处理完所有巧克力棒后剩余的积分。 

输入给出`n`（最多 50），每个条的分数 (`p_i`最多 10^9），以及五个奖项的费用（严格递增，最多 10^9）。 小的`n`允许我们直接模拟该过程而不用担心性能。 大点值意味着我们必须避免基于数组的 DP 或假设小整数的计数方法。 

边缘情况包括 Vasya 的积分与奖品成本完全匹配的情况，或者他可以一次支付多个奖品并且必须重复应用贪婪选择的情况。 例如，如果 Vasya 获得 10 分且奖品费用`[2,4,10,15,20]`，他应该立即选择包，而不是购买多个较小的物品，并且每次购买后必须正确计算剩余积分。 

## 方法

 蛮力方法是简单的模拟。 从零分开始，然后为每个巧克力棒添加其分数。 然后，在当前积分至少是最便宜的奖金成本的同时，重复找到 Vasya 可以负担的最昂贵的奖金，增加其计数，并从积分中减去其成本。 对所有酒吧继续此操作。 

这种方法是正确的，因为它直接遵循 Vasya 的贪婪策略。 自从`n`最多50个，奖品只有5个，重复兑换积分的内循环最多运行`n * max_points / min_cost`次。 即使对于大点值，最大迭代次数也受到贪婪减法序列的限制，实际上，每条柱最多进行几次迭代。 

因为约束很小，所以不需要更快的渐近解决方案，但关键的见解是，贪婪策略使我们始终能够选择最大的可负担的奖励，而不考虑较小的奖励序列 - 问题保证了这种方法是最优的。

 ## 算法演练

 1. 初始化一个列表`count`大小为 5 到 0，代表 Vasya 收集的每个奖品的数量。 初始化`points`为零。 
2. 按时间顺序迭代每个巧克力棒。 将其点添加到`points`。 
3.同时`points`至少是最便宜奖品的成本：

 a. 从最贵到最便宜的顺序迭代奖品。 

b. 找到成本小于或等于的最昂贵的奖品`points`。 

c. 增加相应的计数。 

d. 减去奖品成本`points`。 
4. 处理完所有巧克力棒后，打印每个奖品的数量，然后打印剩余的数量`points`。 

这是有效的，因为不变量是在每个内循环之后，Vasya 无法获得任何奖励，除非可能在从下一个巧克力棒中添加更多分数之后。 在每个决策点，选择最昂贵的负担得起的奖励可以保证贪婪策略与问题描述相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
points_list = list(map(int, input().split()))
prizes = list(map(int, input().split()))  # a, b, c, d, e
count = [0] * 5
points = 0

for p in points_list:
    points += p
    while points >= prizes[0]:
        for i in range(4, -1, -1):
            if points >= prizes[i]:
                count[i] += 1
                points -= prizes[i]
                break

print(' '.join(map(str, count)))
print(points)
```外循环为每个条形添加分数。 内循环重复应用贪婪策略，直到 Vasya 无法再购买任何奖品为止。 从最贵到最便宜的迭代确保我们始终首先选择最大的奖金。 使用`break`内循环保证每次迭代只购买一个奖品，正确模拟 Vasya 的连续交换。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())

    prizes = list(map(int, input().split()))
    count = [0]*5
    points = 0
    for p in points_list:
        points += p
        while points >= prizes[0]:
            for i in range(4, -1, -1):
                if points >= prizes[i]:
                    count[i] += 1
                    points -= prizes[i]
                    break
