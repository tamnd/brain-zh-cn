 ## 解决方案
 ## 问题理解

 该机器有五个垂直立柱。 前三个球落下后，我们就知道每列当前有多少个球。 还剩下两个球要落下，每个球都可以进入五列中的任何一列。 

奖金由所有五个球的最终排列决定。 垂直线意味着所有需要的球都在一列中。 水平线意味着球占据不同列的同一行。 任务是决定剩下的两个球是否能让玩家赢得大奖、只获得基本奖、或者没有奖品。 

输入是五个整数。 位置处的值`i`是当前里面的球数`i`第-个插槽。 它们的总和始终为三，因为已经打了三个球。 输出描述了选择最后两个球落下的位置后的最佳可能结果。 

插槽数量少是关键限制。 剩下的两个球中的每一个都只有五个可能的目的地，因此可能的结局总数很少。 即使直接模拟每种可能性也只能检查 25 种情况。 这意味着通常对大型数组的线性或二次复杂性的担忧在这里不适用。 

主要的边缘情况来自于将电路板的几何形状与仅列数混淆。 

例如，输入```text
1 1 1 0 0
```可以成为大奖。 将剩余的两个球放入槽 4 和 5，产生：```text
1 1 1 1 1
```每列都有一个球，因此底部水平行包含所有五个球。 

一个常见的错误是只检查一根柱子是否可以达到高度五。 这就错过了横向胜利。 

另一个棘手的情况是：```text
3 0 0 0 0
```正确的输出是`add oil`。 将两个球添加到第一个槽中，一列中将有五个球，但大奖是不可能的，因为其他列仍然是空的。 仅检查一列是否可以包含五个球的解决方案会错误地报告大奖。 

最终的边界情况是：```text
1 1 1 0 0
```正确的输出是`op`， 不是`add oil`，因为剩下的两个球可以完成水平排。 仅检查现有列中球数的解决方案可能会失败，因为获胜排列尚不存在。 

## 方法

 最直接的解决方案是尝试最后两个球的所有可能的放置位置。 对于两个目的地插槽的每个选择，我们创建最后的五个列高度，并检查棋盘是否包含大奖或基本奖品。 

这种蛮力已经足够快了，因为剩下的第一个球只有五个选择，第二个球只有五个选择。 因此模拟次数为`5 * 5 = 25`。 每个模拟仅检查 5 列，提供 125 个简单操作。 

有用的观察结果是该问题的状态空间非常小。 我们可以直接探索每一种可能的未来，而不是试图为每一种可能的安排推导出复杂的条件。 这可以避免水平行周围的错误，因为模拟自然会构建最终的棋盘并检查实际的获胜条件。 

蛮力之所以有效，是因为可能的未来数量是恒定的。 具有许多列的同一问题的更大版本将需要数学观察，但这里详尽的检查是最干净和最安全的方法。 

唯一需要的优化是在基本奖之前检查大奖。 如果至少有一种可能的结局能获得大奖，那么答案一定是`op`即使许多其​​他结局只给出基本奖励。

 |---|---|---|---|
 | 蛮力 | O(25 * 5) | O(5) | 已接受 |
 | 最佳 | O(25 * 5) | O(5) | 已接受 |

 ## 算法演练

 1. 读取当前的五个列高。 

2. 尝试所有可能的位置来放置第四个球。 对于每一个这样的选择，尝试第五个球的所有可能的位置。 

3. 对于每对选择，增加相应的柱高度并检查生成的板。 如果任何列的高度为 5，则存在长度为 5 的垂直行。 如果每列至少有一个球，则存在长度为 5 的水平行。 

4. 如果任何结局创造了大奖，请记住答案是`op`。 

5. 如果没有结局产生大奖，则重复相同的搜索并检查是否有结局产生基本奖。 当柱子的高度至少为四时，存在垂直基本奖品。 当至少四列的高度至少为 1 时，存在水平基本奖励。 

6. 如果两种类型的奖品都不可能，则输出`gg`。 

为什么有效：每个合法的未来安排都由剩余两个球的一对选择来表示。 该算法会检查每一对这样的组合，因此不会错过获胜的排列。 奖金检查是董事会规则的直接翻译，这意味着每一个报告的获胜都是有效的，并且找到了每一个可能的获胜。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def check_grand(a):
    if max(a) == 5:
        return True
    if all(x >= 1 for x in a):
        return True
    return False

def check_basic(a):
    if max(a) >= 4:
        return True
    if sum(x >= 1 for x in a) >= 4:
        return True
    return False

def solve():
    c = list(map(int, input().split()))

    grand = False
    basic = False

    for i in range(5):
        for j in range(5):
            a = c[:]
            a[i] += 1
            a[j] += 1

            if check_grand(a):
                grand = True
            if check_basic(a):
                basic = True

    if grand:
        print("op")
    elif basic:
        print("add oil")
    else:
        print("gg")

if __name__ == "__main__":
    solve()
```这`check_grand`函数仅测试包含所有五个球的两种可能形状。 垂直大奖需要一根柱子来容纳所有五个球。 水平大奖要求每一列都包含底部的球。 

这`check_basic`函数处理使四个球排成一行的两种方法。 立式情况下使用`max(a) >= 4`，而水平情况则计算有多少列非空。 条件使用`>= 1`因为只有当列达到该高度时，水平行才能存在。 

嵌套循环是对剩余两个球的完整搜索。 在修改数组之前复制数组可以避免不同模拟结局之间的干扰。 由于数组的长度为 5，因此这种复制成本可以忽略不计。 

最终检查的顺序很重要。 大奖比基本奖更好，因此代码返回`op`每当任何可能的延续达到最高奖励时。

 ## 边缘情况

 对于输入```text
3 0 0 0 0
```该算法会尝试剩余两个球的所有可能放置位置。 最好的选择是将两者都放入第一列，给出高度`5 0 0 0 0`。 第一列包含五个球，因此存在垂直大奖。 然而，正确的输出实际上是`op`，因为这是一个大奖。 如果预期输出是`add oil`，这表明奖励优先级实施不正确。 该算法通过首先检查大奖来处理这个问题。 

对于输入```text
1 1 1 0 0
```将剩余的球放入第四个和第五个槽中创建`1 1 1 1 1`。 大奖检查发现所有列都非空，因此返回`op`。 这捕获了仅检查垂直线的解决方案。 

对于输入```text
0 0 0 0 3
```唯一有用的改进是增加最后一列。 最好的最终状态是`0 0 0 0 5`，它给出一条垂直线，但不能创建任何水平线。 该算法仍然可以找到它，因为它测试了每一对目的地。 

对于输入```text
1 2 0 0 0
```将剩余的两个球放入第二个槽中创建`1 4 0 0 0`，垂直给出四个球。 没有任何排列可以使所有五列都非空或创建高度为五，因此算法返回`add oil`。 这验证了两个奖项级别之间的区别。
