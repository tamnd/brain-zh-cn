 ## 解决方案
 ## 问题理解

 每个人都有一个阈值$a_i$。 他们的决定完全取决于最终到电影院的人数。 

假设准确地说$k$人们走了。 

一个有门槛的人$a_i$当且仅当他们的行为符合他们的规则时才会高兴：

 如果他们去的话，至少必须有$a_i$其他与会者，所以我们需要$k-1 \ge a_i$。 

如果他们呆在家里，人数一定少于$a_i$其他与会者，所以我们需要$k < a_i$。 

我们必须计算有多少种不同的出勤组合同时让每个人都感到高兴。 

这些限制立即表明我们无法检查每个子集。 即使是为了$n=40$，已经有超过一万亿个子集，这里$n$可以达到$2 \cdot 10^5$跨测试用例。 任何指数解都是不可能的。 由于所有测试用例的总大小仅为$2 \cdot 10^5$， 一个$O(n \log n)$每个测试用例的解决方案是完全安全的，同时$O(n^2)$在最坏的情况下会太慢。 

主要困难在于幸福取决于参加者的总数，而不是个人的独立选择。 幼稚的实现很容易错过这种全局依赖性。 

考虑输入：```
2
1 1
```如果只有一个人去，那么与会者会看到$0$其他参加者，少于$1$，所以他们不高兴。 未出席的人看到$1$参加者，至少是$1$，所以他们也不高兴。 正确答案是2，对应“所有人都去”和“没人去”。 

另一个微妙的情况是：```
3
0 0 0
```只要出席人数至少为 0，任何阈值为 0 的人都必须出席，这始终是正确的。 唯一有效的选择是三个人都走。 粗心的解决方案可能会认为每个子集都有效，因为阈值很小。 

第三种边缘情况是：```
3
2 2 2
```除非有至少两名其他参加者，否则任何人都不能参加。 唯一有效的配置是“每个人都去”和“没人去”，给出答案 2。这表明两个极端可以同时有效。 

## 方法

 蛮力的想法很简单。 枚举每个人的子集，计算有多少人参加，并检查每个人是否对该出席人数感到满意。 这是正确的，因为它直接测试定义。 

问题是子集的数量。 有$2^n$的可能性。 为了$n=200000$，这是难以想象的大，所以我们需要一个完全不同的观点。 

关键的观察结果是，有效的出勤集完全由其大小决定。 

准确地假设$k$人们参加。 

任何参加者必须满足：$$a_i \le k-1$$任何呆在家里的人都必须满足：$$a_i > k-1$$这两种情况将人们分为两类。 每个人都与$a_i \le k-1$必须参加，并且每个人$a_i > k-1$必须呆在家里。 

这意味着出席人数设置不再是任意的。 一次$k$是固定的，则集合是唯一确定的。 

让我们对阈值进行排序。 

如果确切地说$k$人们参加，然后排序后，第一个$k$值最多必须是$k-1$，并且所有剩余值必须大于$k-1$。 

按排序顺序变成：$$a_k \le k-1$$和$$a_{k+1} > k-1$$使用从 1 开始的索引。 

每个值$k$满足这些不等式正好贡献了一组有效的出勤率。 

排序后，我们只需要测试所有$k$从$0$到$n$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n2^n)$|$O(1)$| 太慢了|
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 按非降序对阈值数组进行排序。 
2. 考虑每一个可能的出席人数$k$从$0$到$n$。 
3.为了$k=0$，没有人参加。 仅当每个阈值严格为正时，这才有效。 按排序顺序，这意味着$a_1 > 0$。 
4. 对于$k=n$，大家都参加。 仅当每个阈值最多为$n-1$，由于输入限制，这始终为真。 因此$k=n$始终有效。 
5. 对于$1 \le k \le n-1$，检查是否：$$a_k \le k-1$$和$$a_{k+1} > k-1.$$6. 如果两个条件都成立，则将答案加一。 
7. 输出总计数。 

### 为什么它有效

 固定一个值$k$。 

任何人最多有门槛$k-1$必须参加，因为呆在家里会让他们不高兴。 任何阈值大于的人$k-1$必须呆在家里，因为参加会让他们不高兴。 

正确的有效配置$k$参与者存在当且仅当存在$k$阈值最多为的人$k-1$。 排序后，这相当于说第一个$k$值最多为$k-1$其余值大于$k-1$。 

每当这些不平等存在时，出席人数都是唯一确定的，每个人都很高兴。 每当他们失败时，至少有一个人必须违反他们的条件。 因此，每个有效的出勤集都只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        cur = 0

        if a[0] > 0:
            cur += 1

        for k in range(1, n):
            if a[k - 1] <= k - 1 and a[k] > k - 1:
                cur += 1

        cur += 1  # k = n is always valid

        ans.append(str(cur))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```排序数组是中心数据结构。 一旦阈值被排序，检查是否准确$k$人们应该参加成为职位之间的边界测试$k$和$k+1$。 

案例$k=0$需要单独处理，因为边界之前没有元素。 仅当所有阈值均为正数时才没有人参加，这按排序顺序意味着最小值为正数。 

循环处理所有内部值$1 \le k \le n-1$。 使用从零开始的索引，$a[k-1]$是第一个中最大的阈值$k$人们和$a[k]$是剩下的人中最小的门槛。 

案例$k=n$始终有效。 每个阈值都满足$a_i \le n-1$根据输入的定义，每个人都可以参加而不违反他们的要求。 

一个常见的差一错误是与$k$而不是$k-1$。 条件指的是 _other_ 参加者的数量，所以当$k$人们参加，每个参加者都清楚地看到$k-1$其他的。
