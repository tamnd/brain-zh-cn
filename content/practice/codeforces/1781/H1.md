 ## 解决方案
 ## 问题理解

 我们得到了一栋大楼$h$地板和$w$每层都有窗户，形成网格$h \times w$。 每个窗户都可以打开或关闭，但最多两个永久关闭的破损窗户除外。 我们需要计算有多少不同的光图案可以作为信号发送到一艘船。 如果两个图案可以水平或垂直移动成为另一个，则认为两个图案是相同的。 根本没有开灯的配置是无效的。 

输入由多个测试用例组成。 每个测试用例都会给出建筑物的尺寸、破损窗户的数量，以及如果有破损窗户的话，它们的位置。 输出是不同信号的数量模$998{,}244{,}353$。 

限制很小：$h, w \le 40$，最多有两扇破窗户。 所有测试用例的单元总数最多为 1600。这表明只要我们小心地避免冗余工作，单元数量上具有指数复杂性的任何解决方案对于这些边界都是可行的。 

边缘情况包括所有窗户都正常工作、只有一两个破损的窗户、只有单行或单列、以及整个网格太小而无法容纳班次。 枚举所有的天真的方法$2^{h\cdot w}$子集通常是不可行的，但这里的小尺寸允许一些组合技术。 破碎的窗口引入了不对称性：否则在转换下等效的配置可能会被阻止。 

## 方法

 强力方法将生成窗口的所有子集，删除包含损坏窗口的子集，然后通过将其尽可能向上和向左移动来标准化每个子集。 通过将规范化集存储在哈希集中，我们可以计算独特的模式。 为了$h\cdot w \approx 1600$，这需要迭代$2^{1600}$配置，这是一个天文数字。 暴力破解之所以有效，是因为我们可以通过翻译来定义相等性，但会失败，因为配置的数量呈指数级增长。 

关键的见解是利用少量的破损窗口和平移不变性。 如果没有破窗，不同图案的数量是$(h+1)(w+1)-1$：我们可以选择从网格中的任何原点开始的矩形灯块，移动到任何位置，只要它非空即可。 对于一个破损的窗口，只有当该块包含破损的窗口时，才可以阻止该图案。 对于两个破碎的窗户，它们的相对位置决定了哪些块是被禁止的。 我们可以枚举灯光矩形的所有可能的左上角偏移，减去包含破损窗口的偏移，并使用包含-排除有效地计算不同信号的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^{h\cdot w})$|$O(2^{h\cdot w})$| 太慢了 |
 | 包含-排除/组合|$O(h^2 w^2)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$h$,$w$,$k$，以及破碎的窗口坐标（如果有）。 为了简单起见，将坐标调整为基于 0 的索引。 
2. 将不同信号数量的计数器初始化为零。 
3. 迭代由高度定义的所有可能的灯光矩形$rh$和宽度$rw$， 和$1 \le rh \le h$和$1 \le rw \le w$。 每个矩形代表某个连续块中的灯光图案。 
4. 对于每个矩形，迭代其左上角可以放置的所有可能位置。 有$(h-rh+1) \times (w-rw+1)$这样的职位。 这说明了平移不变性：同一矩形的任何移位都被视为相同的模式。 
5. 对于每个矩形位置，检查它是否覆盖了破损的窗口。 如果是这样，请将其丢弃。 如果不是，则增加计数。 这确保了禁止的位置被排除在计数之外。 
6. 迭代所有矩形大小和位置后，计数代表此测试用例的所有有效模式。 应用模数$998244353$。 
7. 输出计数。 

工作原理：通过迭代所有可能的矩形大小并考虑它们的放置偏移，我们生成每个独特的配置，直到平移一次。 破碎的窗口消除了无效模式，而无需重复计算。 包含排除原则是隐式处理的，因为每个矩形放置都会检查损坏窗口的约束，从而防止多次计算重叠的禁止配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        h, w, k = map(int, input().split())
        broken = set()
        for _ in range(k):
            r, c = map(int, input().split())
            broken.add((r-1, c-1))
        total = 0
        for rh in range(1, h+1):
            for rw in range(1, w+1):
                count = 0
                for r0 in range(h - rh + 1):
                    for c0 in range(w - rw + 1):
                        ok = True
                        for (br, bc) in broken:
                            if r0 <= br < r0+rh and c0 <= bc < c0+rw:
                                ok = False
                                break
                        if ok:
                            count += 1
                total = (total + count) % MOD
        print(total)
        
if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量并初始化一组用于损坏的窗口。 对于每个矩形大小，它通过检查矩形内是否有损坏的窗口来计算有效位置。 在高度和宽度上使用嵌套循环可以有效地枚举所有独特的翻译模式。 最后应用模数以防止溢出。 从 0 开始的索引简化了比较。

 ## 边缘情况

 对于带有破损灯的单个窗口网格，算法正确地返回 0，因为没有矩形可以避免破损的单元格。 对于两个损坏的窗口，该算法会检查每个矩形放置的两个损坏的单元格，排除覆盖其中任何一个的任何矩形。 避免这两种情况的矩形只被计数一次，证明了平移不变计数的正确性。 模数确保大额金额
