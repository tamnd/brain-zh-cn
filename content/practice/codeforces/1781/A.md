 ## 解决方案
 ## 问题理解

 我们在一个形状像盒子的长方形房间内工作。 地板上的一点标记笔记本电脑所在的位置，天花板正上方的一点标记投影仪悬挂的位置。 电缆必须连接这两点，但它只能沿着房间的表面移动，这意味着它可以在地板、墙壁和天花板上移动，并且它必须始终遵循与盒子边缘平行的方向。 

任务是计算在这些限制下笔记本电脑和投影仪之间的最短电缆长度。 电缆无法穿过盒子的内部，因此任何路径都必须由位于长方体表面上的轴对齐线段组成。 

关键约束是几何约束而不是组合约束。 我们实际上是在 3D 盒子表面上找到位于相对面上的两点之间的最短曼哈顿式路径。 

每个测试用例的输入大小都很小，最多 10^4 个用例，因此必须在恒定时间内解决每个用例。 这排除了表面上的任何图形搜索或模拟。 解决方案必须来自于认识到只有少数固定数量的候选表面展开才重要。 

当两个点的水平投影在一个坐标中对齐时，会出现一种微妙的边缘情况。 在这种情况下，多个候选路径会折叠成相同的几何形状，并且假设不同坐标的简单公式可能会过多计算或错过最佳路线。 

## 方法

 暴力视图将长方体表面视为一个图：边和面上的每个点都是一个节点，并且允许沿面移动，但具有曼哈顿成本。 人们可以将表面离散成网格并运行最短路径算法。 这在原则上是正确的，但是状态的数量随着离散化分辨率的增加而增加，甚至不需要粗离散化，因为端点是连续坐标。 这使得暴力无法使用。 

关键的观察结果是，盒子表面上两点之间的最佳路径始终对应于将两个相邻面展开为一个平面。 一旦展开，路径就变成两个平面点之间的曼哈顿直线距离。 只有恒定数量的有意义的展开，每个展开都对应于选择电缆穿过的一对相邻面。 

对于地板点 (a, b, 0) 和天花板点 (f, g, h)，最佳路径始终包括从地板向上垂直墙壁移动，然后穿过天花板。 最短路径仅取决于我们是否经过左墙、右墙、前墙或后墙，这转化为几个绝对差表达式。 

这将问题简化为评估一小组候选曼哈顿距离并取最小值。

 | ---| ---| ---| ---|
 | 曲面图搜索| O(∞ 离散化) | O（大）| 太慢了 |

 ## 算法演练

 我们首先观察到任何有效的路径都必须从地板移动到墙壁，然后可能穿过那堵墙，最后到达天花板。 由于移动仅限于面上的轴对齐边缘，因此每条路径都对应于选择“退出”地板矩形的方向。

1. 计算地板平面中的水平间距，即 |a - f| 和|b - g|。 这些表示两个点的投影沿两个地板轴的距离有多远。 
2. 考虑使用与矩形边缘对齐的墙壁在地板和天花板之间移动的四种可能方式。 每个选择都对应于围绕盒子一侧的路径布线。 
3. 对于每条候选路线，将 3D 路径转换为 ​​2D 曼哈顿距离表达式。 每条路线贡献一个水平差、一个垂直差和高度 h 的总和。 
4. 评估所有候选表达式并取最小值。 

我们只需要恒定数量的表达式的原因是，任何最短的表面路径必须对应于两个相邻面的一次展开，并且只有四个这样的展开通过单个墙边界连接地板到天花板。 

### 为什么它有效

 从地板到天花板的任何有效表面路径必须恰好穿过墙壁从 z = 0 到 z = h 的一个垂直过渡。 一旦该过渡点固定在盒子的边缘上，每个面上的路径的其余部分就是一条曼哈顿直线段。 最小化所有可能的墙壁边缘减少了对一组恒定配置的比较，并且没有任何内部绕行可以改善平坦表面上的曼哈顿路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        w, d, h = map(int, input().split())
        a, b, f, g = map(int, input().split())

        dx = abs(a - f)
        dy = abs(b - g)

        # four candidate surface routes
        ans = min(
            dx + b + g + h,
            dx + (d - b) + (d - g) + h,
            dy + a + f + h,
            dy + (w - a) + (w - f) + h
        )

        print(ans)

if __name__ == "__main__":
    solve()
```该实现预先计算水平差异并评估四种几何配置。 每个表达式对应于选择房间的四个垂直边之一作为地板和天花板之间的过渡表面。 添加的项如 b + g 或 (d - b) + (d - g) 表示在垂直穿过高度 h 之前从这些点步行到选定的墙边缘。 

一个常见的错误是忘记过渡可以发生在四堵墙上的任何墙上，而不仅仅是投影中最近的一堵墙。 另一种方法是假设曼哈顿直接距离加上高度，当两个点比朴素投影建议的更接近不同的墙时，这种假设就会失败。 

## 工作示例

 我们从样本集中追踪两个案例。 

### 示例 1

 输入：w=55、d=20、h=29、a=23、b=10、f=18、g=3

 | 表达| 价值|
 | ---| ---|
 | dx + b + g + h | 5 + 10 + 3 + 29 = 47 |
 | dx + (d-b) + (d-g) + h | 5 + 10 + 17 + 29 = 61 |
 | dy + a + f + h | 7 + 23 + 18 + 29 = 77 |
 | dy + (w-a) + (w-f) + h | 7 + 32 + 37 + 29 = 105 |

 最小值为 47。 

这证实了通过最近的水平投影到一侧墙上的路由主导了所有替代方案。 

### 示例 2

 输入：w=20、d=10、h=5、a=1、b=5、f=2、g=5

 | 表达 | 价值|
 | ---| ---|
 | dx + b + g + h | 1 + 5 + 5 + 5 = 16 |
 | dx + (d-b) + (d-g) + h | 1 + 5 + 5 + 5 = 16 |
 | dy + a + f + h | 0 + 1 + 2 + 5 = 8 |
 | dy + (w-a) + (w-f) + h | 0 + 19 + 18 + 5 = 42 |

 最小值为 8。 

这显示了 b 等于 g 的退化情况，使得垂直对齐无关并允许直接墙过渡。

 ## 边缘情况

 当两个点在一个轴上共享相同的投影时，某些候选路线会崩溃并且多个表达式变得相等。 该算法自然地处理这个问题，因为绝对差变为零，并且最小值仍然选择有效的壁路径。 

当一个点已经接近边界时，涉及该墙的表达式显着减少，并且最小值正确地选择了该侧。 该公式结构确保不会考虑穿过内部的无效捷径，因为每个候选者都明确强制通过墙壁和垂直过渡进行表面遍历。
