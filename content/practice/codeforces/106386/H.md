 ## 解决方案
 ## 问题理解

 我们得到一个带有加权节点的有向图。 每个节点代表一个滑冰元素，每个元素都有一个分数。 一条有向边从$x$到$y$意味着您可以执行元素$y$紧接在元素之后$x$。 性能是在该图上行走，其中每一步都遵循有向边，并且行走可以从任何节点开始。 

关键在于，重复相同的元素在第一次出现后不会增加任何分数。 所以如果我们多次访问一个节点，只有第一次访问才贡献它的价值； 所有后续访问贡献为零。 

任务是选择一条有效的路径，使沿路径遇到的不同节点值的总和最大化。 

该图可以很大，最多可达$10^5$节点和$2 \cdot 10^5$边缘。 任何尝试枚举路径或对步行执行指数探索的解决方案都将立即失败。 甚至$O(n^2)$在最坏的情况下，方法太大，因为图可能足够密集，导致遍历模式大量重复。 

一个微妙的困难是允许循环，事实上它们是“重新访问”节点的唯一方法。 但是，重新访问节点仅在有助于到达尚未收集的新节点时才有用。 一旦收集了一个区域中所有可到达的有价值的节点，继续循环就没有任何好处。 

一个容易犯的错误是假设这是最长路径问题或 DAG DP 问题。 但这会失败，因为循环是允许的并且很有用。 另一个常见的错误是压缩强连接组件，但随后错误地处理结果图，特别是如果人们忘记了在 SCC 内，所有节点都是相互可达的，并且可以按任何顺序收集，而无需重新访问，而不会产生任何成本。 

例如，如果我们有一个循环$1 \to 2 \to 3 \to 1$，正确的行为是从该循环中的任何位置开始都可以收集所有三个值。 简单的路径 DP 可能只计算一个遍历方向，而忽略了整个组件实际上可以自由遍历。 

## 方法

 暴力的想法是模拟从每个节点开始的所有可能的行走，维护一组已收集其值的已访问节点。 在每一步中，我们都会沿着任何传出边缘移动，并添加节点的值（如果之前没有见过）。 这是正确的，因为它直接匹配流程的定义。 

故障点是状态空间。 单独访问的集合有大小$2^n$，并且对于每个状态，最多有$n$可能的下一步行动。 即使限制为可达状态，具有循环的图中的不同路径的数量也是无限的，因为在决定前进之前游走可以循环任意多次。 这使得直接模拟变得不可能。 

关键的观察结果是图表内的循环在内部并不重要。 一旦进入强连接组件，您就可以在其中自由遍历并收集该组件中的每个节点，而无需担心顺序。 唯一有意义的结构是这些组件如何相互连接。 

这将问题简化为强连通分量的有向无环图。 在每个组件内，我们可以对所有节点值求和，因为一旦我们进入它，我们就可以收集其中的所有内容。 在组件之间，我们受到凝结 DAG 的限制，因此我们有效地在该 DAG 中选择一条路径，使组件权重之和最大化。 

这将问题转化为 DAG 上的最长路径问题，其中节点权重是 SCC 值的总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 步行中的蛮力 | 指数| 指数| 太慢了|
 | SCC 压缩 + DAG 上的 DP |$O(n + m)$|$O(n + m)$| 已接受 |

 ## 算法演练

 1. 计算图的强连通分量。 每个节点都分配有一个组件 ID。 此步骤对可相互访问的节点进行分组，这很重要，因为在这样的组内，排序约束不再限制总收集。 
2. 对于每个组件，通过将其内部所有节点权重相加来计算其总值。 这是有效的，因为一旦遍历进入组件，它就可以在内部遍历并最终访问所有节点。 
3. 构建压缩图，其中每个 SCC 成为单个节点。 对于每个原始边缘$u \to v$，如果组件不同，则在其组件代表之间添加有向边。 
4. 由于 SCC 凝聚总是产生有向无环图，因此计算组件的拓扑顺序。 
5. 在 DAG 上运行动态规划。 让$dp[c]$是在组件处可实现的最大总价值$c$。 全部初始化$dp[c]$与组件自己的总和，因为我们可以从任何地方开始。 
6. 按拓扑顺序遍历组件。 对于每条边$c \to d$， 更新$dp[d]$作为$dp[d] = \max(dp[d], dp[c] + value[d])$。 此转换表示从相互可到达的节点的一个区域移动到另一区域，并在到达时收集目标组件中的所有节点。 
7. 答案是所有 dp 状态中的最大值。 

正确性依赖于这样一个事实：一旦输入一个组件，它的所有节点都可以被收集而不会受到惩罚，并且除了通过传出边之外，离开它不能提供任何附加值。 由于 SCC 收缩消除了所有内部排序约束，因此每个有效行走都与 DAG 中的路径完全对应。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    val = list(map(int, input().split()))
    
    g = [[] for _ in range(n)]
    gr = [[] for _ in range(n)]
    
    for _ in range(m):
        x, y = map(int, input().split())
        x -= 1
        y -= 1
        g[x].append(y)
        gr[y].append(x)

    # Kosaraju: first pass order
    vis = [False] * n
    order = []

    def dfs1(u):
        vis[u] = True
        for v in g[u]:
            if not vis[v]:
                dfs1(v)
        order.append(u)

    for i in range(n):
        if not vis[i]:
            dfs1(i)

    # second pass: assign components
    comp = [-1] * n
    comps = []

    def dfs2(u, idx):
        comp[u] = idx
        comps[idx].append(u)
        for v in gr[u]:
            if comp[v] == -1:
                dfs2(v, idx)

    for u in reversed(order):
        if comp[u] == -1:
            comps.append([])
            dfs2(u, len(comps) - 1)

    k = len(comps)

    comp_sum = [0] * k
    for c in range(k):
        s = 0
        for u in comps[c]:
            s += val[u]
        comp_sum[c] = s

    dag = [set() for _ in range(k)]
    indeg = [0] * k

    for u in range(n):
        for v in g[u]:
            cu, cv = comp[u], comp[v]
            if cu != cv and cv not in dag[cu]:
                dag[cu].add(cv)
                indeg[cv] += 1

    topo = []
    stack = [i for i in range(k) if indeg[i] == 0]
    while stack:
        u = stack.pop()
        topo.append(u)
        for v in dag[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                stack.append(v)

    dp = comp_sum[:]

    for u in topo:
        for v in dag[u]:
            if dp[v] < dp[u] + comp_sum[v]:
                dp[v] = dp[u] + comp_sum[v]

    print(max(dp))

if __name__ == "__main__":
    solve()
```代码的前半部分执行 Kosaraju 算法来识别强连通分量。 正向 DFS 产生整理顺序，而反向图 DFS 分配组件。 这是必要的，因为 SCC 内部的可达性对称性允许安全地折叠循环。 

后半部分构建凝结图。 每个组件使用一个集合以避免重复的边，因为多个原始边可以连接同一对组件。 如果没有重复数据删除，入度和 DP 转换仍然有效，但会浪费时间并存在冗余更新的风险。 

DP 阶段是 DAG 上的最长路径计算，用组件和进行初始化，因为每个组件作为起点都是自给自足的。 该转换添加了完整的目标组件值，因为输入它允许完整收集。

 ## 边缘情况

 全循环图是最重要的极端情况。 如果所有节点均可相互访问，则该算法将所有内容压缩到一个 SCC 中并返回所有值的总和。 任何不压缩 SCC 的基于路径的 DP 都会错误地将重新访问视为无效或不正确地重复计数。 

另一个边缘情况是具有多个断开连接的组件的图。 每个组件都成为自己的 SCC，并且由于 DP 独立地初始化每个组件，因此该算法正确地允许从任何地方开始，而无需人工源节点。 

最后一个微妙的情况是，最佳路径较晚进入循环，然后通过不同的节点退出。 SCC收缩确保进入循环立即授予所有值，因此模拟部分遍历没有任何好处； DP 通过原子地处理整个组件，正确地避免了计数不足。
