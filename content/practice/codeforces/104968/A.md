 ## 解决方案
 ## 问题理解

 披萨被表示为大小的方形网格$N \times N$，其中每个单元格包含一个字母字符。 在这些字符中，只有两个符号对我们来说很重要：大写“P”和小写“p”。 这些字符中的每一个出现都代表披萨的该单元格上放置了一个意大利辣香肠。 所有其他字母都是无关的装饰。 

任务是扫描整个网格并计算总共有多少意大利辣香肠。 由于每个细胞最多只能贡献一份意大利辣香肠，因此答案很简单，就是包含“P”或“p”的细胞数量。 

约束条件$N \leq 100$表示网格最多有$10^4$细胞。 即使是对所有细胞进行直接扫描也非常便宜。 对每个单元检查一次的解决方案已经是最佳方案； 任何比线性扫描更复杂的东西都是不必要的。 

主要的边缘情况主要与输入解释有关，而不是算法难度。 网格保证准确无误$N$的行$N$每个字符，但如果假设以空格分隔标记或忘记换行符处理，粗心的输入解析仍然可能会出错。 

例如，如果$N = 1$网格是：```
P
```答案是 1。如果：```
a
```答案是 0。如果：```
p
```答案也是 1。一个常见的错误是只检查大写“P”而忘记小写“p”，这会错误地输出 0 表示有效的意大利辣香肠。 

## 方法

 最直接的方法是迭代网格中的每个单元格并检查字符是“P”还是“p”。 这是可行的，因为每个单元格都是独立的，并且为总计数贡献固定值 1 或 0。 总结这些贡献给出了最终答案。 

稍微天真的心理模型可能会将网格视为字符串的集合，并使用子字符串搜索或重复扫描来重复搜索“P”或“p”的出现。 这对于总输入大小仍然是线性的，但是在字符串操作和重复传递相同数据方面引入了不必要的开销。 在最坏的情况下，它仍然可以触及所有$N^2$多次使用字符，这是可以避免的。 

关键的简化是认识到空间关系并不重要。 没有分组、没有邻接、也没有变换。 每个角色独立决定是否增加答案。 这将问题分解为对输入的单次传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解重复扫描| O(N^2) 到 O(N^3) | O(1) | O(1) | 太慢/不必要|
 | 单程计数| O(N^2) | O(N^2) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取整数$N$，它决定网格中的行数和列数。 这设置了我们将处理的字符总数。 
2. 将计数器变量初始化为零。 该变量累积扫描期间遇到的意大利辣香肠的数量。 
3. 迭代每个$N$行。 每行都是一个长度的字符串$N$，代表披萨网格的一个水平切片。 
4. 对于当前行中的每个字符，检查它是否等于‘P’或‘p’。 如果匹配，则将计数器加一。 此步骤是合理的，因为每个匹配的单元格都贡献了一份意大利辣香肠。 
5. 处理完所有行和所有字符后，输出计数器的最终值。 

### 为什么它有效

 该算法依赖于有效字符和对答案的贡献之间的直接一对一映射。 每个网格单元都被检查一次，并且每个单元独立地贡献 0 或 1。由于单元之间没有重叠或相互作用，因此将局部贡献相加即可得出全局总数。 在整个扫描过程中保持的不变量是计数器等于迄今为止看到的意大利辣香肠细胞的数量，因此在终止时它等于网格中的总计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    cnt = 0

    for _ in range(n):
        row = input().strip()
        for ch in row:
            if ch == 'P' or ch == 'p':
                cnt += 1

    print(cnt)

if __name__ == "__main__":
    solve()
```该解决方案将每一行作为原始字符串读取并逐字符迭代。 使用`strip()`确保换行符不会干扰处理，这是网格问题中差一错误的常见来源。 该条件显式检查大写和小写形式，以防止丢失匹配。 

当发现有效字符时，计数器立即更新，因此不需要中间存储或网格预处理。

 ## 边缘情况

 一种微妙的情况是网格仅包含小写字母而没有大写“P”。 对于输入：```
2
pp
pp
```扫描处理每个字符并为每个“p”递增，产生 4。仅检查大写“P”的有缺陷的实现将返回 0，但正确的逻辑对称地处理这两种情况。 

另一种情况是最小网格：```
1
P
```该循环运行一次，看到匹配项，然后返回 1。相同的逻辑还处理：```
1
z
```没有增量发生并且输出保持为 0。这证实了即使在网格折叠成单个单元格的边界处，算法也表现一致。
