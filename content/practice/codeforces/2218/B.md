 ## 解决方案
 ## 问题理解

 我们得到了正好七个整数。 任务是否定其中的六个 - 将它们乘以`-1`- 并保持 1 不变，然后计算总和。 我们希望通过选择要否定的六个来获得最大的总和。 从概念上讲，每个数字都可以产生正向或负向贡献，具体取决于我们是否翻转它。 由于只有七个数字，因此只有七种可能的方法来选择不被否定的数字。 

限制非常小。 每个数字都介于`-67`和`67`，并且最多有`6767`测试用例。 这意味着任何在恒定时间内处理单个测试用例的算法都将高效运行，即使在输入上限下也是如此。 边缘情况包括所有数字均为正数、全部为负数或最大绝对值可能为正数或负数的混合数。 例如，如果所有数字都是正数，则不对最大正数求反将使总和最大化，因为对它求反会减去最大的金额。 

对于七个数字来说，尝试对六个数字的所有子集进行求反的简单方法是可行的，但理解潜在的模式会更好。 我们需要确定哪个数字不被否定以使总和最大化。 

微妙边缘情况的一个例子是`a = [1, 2, 3, 4, 5, 6, 7]`。 否定六个数字并离开`7`未求反产生总和`-1-2-3-4-5-6+7 = -14`。 离开`1`未否定的产物`1-2-3-4-5-6-7 = -26`。 如果大多数数字为正数，则通过将最小值保留为负数来获得最大值。 另一个例子是`a = [-1, -2, -3, -4, -5, -6, -7]`。 否定六并离开`-1`给出`1+2+3+4+5+6-7 = 14`。 离开`-7`给出`1+2+3+4+5+6-7 = 14`。 原则是，如果全部为负数，则保持绝对值最小的数不变，如果全部为正数，则保持最大的数不变，得到最大和。 

## 方法

 暴力方法每次都会枚举六个数字的所有子集来求和并计算总和。 这样的子集恰好有七个，因为选择六个进行否定相当于选择一个离开。 计算每个子集的总和需要对七个数字进行求和，从而得到总共`7*7 = 49`每个测试用例的操作。 这是非常小的和可行的，但我们可以更仔细地推理来避免这种情况。 

关键的观察结果是，对七个数字中的六个进行否定相当于对除 1 之外的所有数字进行否定。 因此，对于每个测试用例，我们只需要考虑将每个数字保留为非负数并对转换后的数组求和。 自离开后的总和`a[i]`未求反等于所有其他数字之和的负数加上`a[i]`，问题简化为计算一次所有数字的总和，然后对于每个候选者，计算`sum_except_i = total_sum - a[i]`和候选总和`candidate_sum = -sum_except_i + a[i] = -total_sum + 2 * a[i]`。 这七个值中的最大值就是答案。

 ## 算法演练

 1. 对于每个测试用例，将七个整数读入列表中`a`。 
2. 计算列表的总和，`total_sum = sum(a)`。 
3. 初始化变量`max_sum`到一个非常小的数字，例如`-inf`。 
4. 对于每个数字`a[i]`在列表中，计算不取反所获得的总和。 这是`candidate_sum = -total_sum + 2 * a[i]`。 
5.如果`candidate_sum`大于`max_sum`， 更新`max_sum`。 
6. 检查完所有七个数字后，`max_sum`包含对六个数字求反后可能的最大和。 输出它。 

为什么有效：对七个数字中的六个求负相当于对除 1 之外的所有数字求负。 计算`-total_sum + 2 * a[i]`有效地给出总和，而无需为每个选择物理创建一个新数组。 迭代所有七种可能性可以保证我们考虑每一个有效的选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a = list(map(int, input().split()))
    total_sum = sum(a)
    max_sum = -float('inf')
    for x in a:
        candidate = -total_sum + 2 * x
        if candidate > max_sum:
            max_sum = candidate
    print(max_sum)
```该代码首先读取测试用例的数量，然后迭代每个测试用例。 它将输入行转换为整数并计算总和。 该循环计算使每个数字不被求反的候选总和并跟踪最大值。 使用`-total_sum + 2 * x`避免创建新数组并确保计算准确。 的初始化`max_sum`到负无穷大可以正确处理全负数组。
