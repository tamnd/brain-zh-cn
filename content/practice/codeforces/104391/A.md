 ## 解决方案
 ## 问题理解

 我们得到了排列成一条线的一系列能量单元值。 我们需要提供的机器有一个固定的完美二叉树结构$K$层，所以它包含$2^{K-1}$底部的叶子和总共$2^K - 1$节点。 

任务是切割数组$N$细胞准确地$2^{K-1}$连续的非空段。 每个段按从左到右的顺序分配给一个叶节点。 叶子的值是其段的总和。 每个内部节点都取其两个子节点的总和，因此一旦叶段固定，每个节点的值就确定了。 

有一个耦合结构的约束：对于每个内部节点，其左子树和右子树的总值之间的绝对差不得超过$D$。 由于每个子树对应于一个连续的叶子块，并且每个叶子对应于数组的一个连续段，因此每个节点都有效地比较两个连续子数组的和。 

输出是选择产生有效叶段的切割的方法数量，其中有效性完全由所有内部节点是否满足差异约束来定义。 

约束足够小$K \le 9$，所以叶子的数量最多为$2^8 = 256$， 和$N \le 300$。 这立即排除了任何指数的情况$N$或切割配置的数量。 然而，它确实允许$O(K \cdot N^3)$风格动态规划，因为$N^3 \approx 27 \cdot 10^6$在Python中只要仔细实现是可行的。 

一个微妙的边缘情况来自这样一个事实：内部节点值仅取决于数组的固定间隔的总和。 如果错误地假设子树值取决于段内部的分组方式，则可能会使问题变得过于复杂并引入不必要的状态。 关键的观察是对于覆盖区间的任何节点$[l, r]$，其总价值始终为$\sum_{i=l}^r A_i$，与该区间如何进一步分割无关。 

如果试图将其视为通用分区 DP 而不考虑固定的二叉树结构，则会出现另一种失败情况。 随机分组片段会破坏叶子所需的从左到右的对应关系，并且会过多计算无效配置。 

## 方法

 蛮力方法会尝试各种放置方法$2^{K-1} - 1$之间切入$N-1$间隙，这已经给出了$\binom{N-1}{2^{K-1}-1}$的可能性。 为了$N = 300$而且多达256个段，这是一个天文数字，完全不可行。 

即使我们生成所有分区，对于每个分区，我们都需要构建完整的二叉树，计算所有节点总和，并验证每个内部节点的约束。 这至少增加了$O(N + 2^K)$每个分区都工作，这使得情况变得更糟。 

关键的简化来自于首先修复树结构。 一旦我们按照从左到右的顺序将段分配给叶子，唯一的自由就是我们切割数组的位置。 树的内部结构是固定的，不依赖于实际值。 这允许我们将每个节点视为在数组的连续间隔上进行操作。 

这导致了树节点和数组间隔上的动态规划公式。 对于每个节点，我们计算存在多少种有效的方法来划分给定的区间$[l, r]$精确地转换为该子树所需的叶子数。 在每个内部节点，我们尝试区间的每个可能的分割点，并结合左右子节点的解决方案，使用预先计算的区间和检查约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解分区 | 指数为$N$| O(N) | 太慢了 |
 | 区间树 DP |$O(N^3 \cdot 2^K)$|$O(N^2 \cdot 2^K)$| 已接受 |

 ## 算法演练

 我们将计算建立在二叉树的顶部，并将每个节点与其子树中固定数量的叶子相关联。 该数字始终是 2 的幂，由其深度决定。 

然后，我们定义一个 DP 状态，捕获在给定的数组段上可以实现节点的多种方式。 

1. 预先计算前缀和，以便任何区间和$\sum_{i=l}^r A_i$可以在常数时间内查询。 这是必需的，因为节点约束仅取决于区间总和。 
2.定义递归DP函数$dp(node, l, r)$，表示子数组有效划分方式的数量$[l, r]$精确地计算出叶子的数量`node`，尊重该子树内的所有约束。 
3.如果`node`是一片叶子，整个区间$[l, r]$形成一个段，因此只有一种有效的方法。 此级别不适用任何约束，因为叶子没有子节点。 
4.如果`node`是内部的，我们将其叶集分为左子叶集和右子叶集。 我们尝试每一个可能的分割点$t$这样$l \le t < r$。 这个选择决定了左孩子的操作$[l, t]$和右边的孩子$[t+1, r]$。 
5. 对于每个分割点$t$，我们计算：$$dp(left, l, t) \times dp(right, t+1, r)$$但前提是满足约束条件：$$\left| \sum_{i=l}^{t} A_i - \sum_{i=t+1}^{r} A_i \right| \le D$$6. 对所有有效分割点求和$t$获得$dp(node, l, r)$。 
7.最终答案是$dp(root, 1, N)$，其中根对应于完整的树。 

### 为什么它有效

 每个 DP 状态完全对应于选择定义固定子树间隔内的叶段的切割位置。 递归强制每个子树使用一个连续的子数组，并且节点上的每个分割恰好对应于数组中的一个分区点。 由于每个节点约束仅取决于固定的区间和，因此分割的有效性与更深层次的决策无关，因此子问题保持独立和相乘。 这可确保不会对任何配置进行两次计数，并且不会排除任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

MOD = 10**9 + 7

def solve():
    N, K, D = map(int, input().split())
    A = list(map(int, input().split()))

    # prefix sums
    pref = [0] * (N + 1)
    for i in range(N):
        pref[i + 1] = pref[i] + A[i]

    def seg_sum(l, r):
        return pref[r] - pref[l]

    # number of leaves in each node at each depth
    # we build structure explicitly: full binary tree
    size = 1 << (K - 1)

    # build tree nodes by index:
    # node 1 is root, children 2*i and 2*i+1
    # total nodes up to 2^K - 1
    max_nodes = (1 << K)

    from functools import lru_cache

    @lru_cache(None)
    def dp(node, l, r):
        # number of leaves under this node
        depth = (node.bit_length() - 1)
        # leaf nodes are those at depth K-1, but easier:
        # node index >= 2^(K-1) are leaves
        if node >= (1 << (K - 1)):
            return 1

        res = 0
        left_child = node * 2
        right_child = node * 2 + 1

        for t in range(l, r):
            if abs(seg_sum(l, t) - seg_sum(t, r)) <= D:
                res += dp(left_child, l, t) * dp(right_child, t, r)
        return res % MOD

    ans = dp(1, 0, N)
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```该实现依赖于对对的记忆$(node, l, r)$。 每个状态代表一个应用于固定区间的固定子树结构。 叶子条件是通过节点索引范围来检测的，这是有效的，因为树是一个完整的二叉堆表示。 

转换枚举每个可能的分割点并使用前缀和检查约束。 乘法结合了独立的左子树和右子树配置。 

一个常见的微妙错误是忘记相同的间隔可以在不同 DP 状态的不同节点之间重复使用，这使得记忆对于效率至关重要。

 ## 边缘情况

 一个关键的边缘情况是当$D = 0$。 在这种情况下，每个内部节点都要求其左子树和右子树之和完全相等。 DP 仍然有效，因为约束检查在每个分割点变成严格相等的过滤器。 如果分割不能产生等间隔和，则立即丢弃。 

另一种情况是当$K = 1$。 只有一个叶子，因此整个数组必须形成一个段。 DP 正确处理了这个问题，因为根也是叶节点，并且返回 1，没有任何分裂。 

当多个不同的分割配置导致较高节点上的间隔总和相同但较低级别的分区不同时，会出现更微妙的情况。 DP 能够正确区分它们，因为每个状态不仅与区间相关，还与树中的节点相关，从而确保结构上不同的分解被单独计数。
