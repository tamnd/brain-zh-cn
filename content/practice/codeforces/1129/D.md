 ## 解决方案
 ## 问题理解

 我们被要求计算有多少种方法可以将给定的整数数组分割成连续的非空段，以便在每个段中只出现一次的整数数量不超过给定的阈值$k$。 从概念上讲，每个段都是“隔离的”，因为它最多可以容忍$k$独特的单身人士。 例如，在数组中`[1,1,2]`和$k=1$, 段`[1,1,2]`是有效的，因为`2`出现一次，在限制之内，但是一个段`[1,2]`将是无效的，因为两者`1`和`2`恰好出现一次，超过$k$。 

输入提供数组大小$n$，阈值$k$，以及数组元素本身。 输出是一个数字：有效分段的总数模$998244353$。 

给定$n$可以大到$10^5$，任何解大约超过$O(n \log n)$或者$O(n \sqrt n)$可能太慢了。 这是一种尝试每一种可能的分割的简单方法，其中的分割数量呈指数级增长（$2^{n-1}$），显然是不可行的。 关键边缘情况涉及所有元素都相同的数组，这通常满足条件，或者包含许多不同元素仅出现一次的数组，其中有效段可能非常短。 例如，输入`[1,2,3]`和$k=1$迫使我们在每个元素之后进行分割，只产生`[1],[2],[3]`作为有效段。 粗心的实现可能会在不检查单例计数的情况下错误地组合元素。 

## 方法

 暴力方法会尝试所有可能的方法将数组划分为连续的段。 对于每个分段，我们将计算每个分段中恰好出现一次的整数，并检查它们是否超过$k$。 While this approach is correct, the number of segmentations grows exponentially with$n$- 关于$2^{n-1}$可能性 - 这是完全不可行的$n$最多$10^5$。 

关键的观察结果是，片段的有效性仅取决于其内容，特别是有多少元素恰好出现一次。 这适合动态规划方法：我们可以定义`dp[i]`作为长度前缀的有效分段数$i$。 然后对于每个`i`，我们考虑所有可能的先前分割点`j`并检查该段是否`a[j..i-1]`是有效的。 我们可以通过维护满足单例约束的最后一段的滑动窗口来优化这一点。 使用两个指针和频率图，我们可以动态更新仅出现一次的元素的计数。 这将内部循环减少为每个元素的摊销 O(1) 次操作，从而给出 O(n) 解决方案。 

蛮力方法和最优方法可以比较如下：

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 滑动窗口+DP| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个`dp`大小数组`n+1`在哪里`dp[i]`存储以索引结尾的前缀的有效分段数`i-1`。 放`dp[0] = 1`因为空前缀有一个简单的分段。 
2. 使用频率字典来跟踪每个整数在当前滑动窗口中出现的次数。 维护只出现一次的整数的计数。 
3. 保持左指针`l`指示以当前位置结束的有效段的最早可能开始`r`。 移动`l`向前传输，同时该段中的单例数量`[l..r]`超过`k`。 
4. 对于每个`r`从 0 到 n-1，更新频率图`a[r]`。 如果频率变为 1，则增加单例计数。 如果变为 2，则减少单例计数。 
5、调整后`l`为了满足单例约束，当前段`[l..r]`是有效的。 添加`dp[l]`到`dp[r+1]`计算所有以以下结尾的分段`r`。 
6.最后，`dp[n]`给出以 998244353 为模的有效分段总数.

 为什么它有效：DP 不变量是`dp[i]`总是计算长度前缀的所有有效分段`i`。 滑动窗口保证我们永远不会包含超过`k`单例，所以每次更新`dp[r+1]`正确地扩展了先前的有效分段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    dp = [0] * (n + 1)
    dp[0] = 1
    
    freq = {}
    singletons = 0
    l = 0
    
    for r in range(n):
        val = a[r]
        freq[val] = freq.get(val, 0) + 1
        if freq[val] == 1:
            singletons += 1
        elif freq[val] == 2:
            singletons -= 1
        
        while singletons > k:
            left_val = a[l]
            freq[left_val] -= 1
            if freq[left_val] == 1:
                singletons += 1
            elif freq[left_val] == 0:
                singletons -= 1
                del freq[left_val]
            l += 1
        
        dp[r + 1] = (dp[r + 1] + dp[l]) % MOD
        if r > 0:
            dp[r + 1] = (dp[r + 1] + dp[r]) % MOD

    print(dp[n] % MOD)

if __name__ == "__main__":
    main()
```频率图更新跟踪有多少个整数恰好出现一次，滑动窗口移动左指针`l`直到当前段有效。 这`dp`数组通过扩展先前的有效前缀来累积有效分段。 使用模数可确保不会溢出。 

## 工作示例

 ### 示例 1

 输入：`3 1`带数组`[1, 1, 2]`。 

| r | 我| 频率 | 单身人士 | DP |
 | ---| ---| ---| ---| ---|
 | 0 | 0 | {1:1} | 1 | dp[1]=1 | dp[1]=1 |
 | 1 | 0 | {1:2} | 0 | dp[2]=2 | dp[2]=2
 | 2 | 0 | {1:2,2:1} | 1 | dp[3]=3 | dp[3]=3 |

 跟踪显示单例计数从未超过 1，并且`dp`累积有效的分割`[1],[1],[2]`,`[1,1],[2]`， 和`[1,1,2]`。 

### 自定义示例

 输入：`4 2`带数组`[1,2,3,2]`。 

| r | 我| 频率 | 单身人士 | DP |
 | ---| ---| ---| ---| ---|
 | 0 | 0 | {1:1} | 1 | dp[1]=1 | dp[1]=1 |
 | 1 | 0 | {1:1,2:1} | 2 | dp[2]=2 | dp[2]=2
 | 2 | 0 | {1:1,2:1,3:1} | 3 -> l 移至 1，freq={2:1,3:1}，singletons=2 | dp[3]=dp[1]=1 |
 | 3 | 1 | {2:2,3:1} | 1 | dp[4]=dp[1]+dp[3]=1+1=2 |

 这演示了滑动窗口调整`l`当单例数超过`k`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个元素最多进入和退出滑动窗口一次，更新频率为O(1)。 |
 | 空间| O(n) |`dp`大小数组`n+1`最多存储频率图`n`独特的元素。 |

 给定`n <= 10^5`，O(n) 次操作很容易满足 3 秒的时间限制，并且空间适合 256 MB。
