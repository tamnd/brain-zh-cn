 ## 解决方案
 ## 问题理解

 我们有一个环形火车网络`n`站，编号从 1 到`n`。 一列火车按顺序从一个车站开往下一个车站，并在一个又一个车站后循环回到车站 1`n`，每次移动正好花费 1 秒。 在这个网络上，有`m`糖果放置在特定的车站，每个车站都有不同的目的地。 火车可以一次装载任意数量的糖果，但在任何车站，它在移动前只能装载**每站一颗糖果**。 卸载是瞬时的。 我们的目标是计算每个车站从该车站出发的火车将所有糖果运送到各自目的地所需的最短时间。 

关键限制是`n`最多 5,000 个并且`m`最多 20,000 个。 一个简单的模拟是，我们尝试每个起始站并逐步移动火车，这将涉及`O(n * m)`每轮的操作可能达到数十亿步，对于 2 秒的时间限制来说太慢了。 这立即表明我们需要一种更具分析性或贪婪性的方法，而不是字面模拟。 

一个微妙的点来自于有多种糖果的车站。 如果一个车站有多个糖果运往其他车站，则每次只能装载一颗，因此火车可能需要绕多个回合才能完全清空该车站。 如果粗心地假设一个车站的所有糖果都可以一次性拿走，就会低估总的配送时间。 

当后来的车站的糖果缠绕在环形网络上时，就会出现另一种边缘情况。 例如，车站的糖果`n`去往站1的不能线性处理； 火车必须穿过环绕线，这会影响时间计算。 未能正确处理模运算将产生错误的答案。 

## 方法

 蛮力方法将模拟从每个车站出发的火车。 每次启动时，我们都会一秒一秒地迭代火车的旅程，从当前车站装载一颗糖果（如果有剩余），移动到下一站，并在到达目的地时卸载糖果。 虽然逻辑上是正确的，但这种方法可以扩展为`O(n * m)`对于每个起始站，仅一次起始就可能导致 5,000 * 20,000 = 1 亿步。 为所有人运行它`n`站将其进一步乘以 5 亿次操作，这太慢了。 

关键的见解是火车的运动是严格循环的，唯一的限制是每个车站每次访问装载一颗糖果。 对于每个站`i`，**从i站送出所有糖果**的时间可以计算为所有持有糖果的站所需要的最长时间。 如果一个站`s`有`k`发往其他地方的糖果，当火车第一次到达时可以领取第一颗糖果`s`，下一个循环的第二个，依此类推。 从车站送出最后一颗糖果的时间`s`是时候到达`s`加`(k-1) * n`额外循环的秒数加上距离`s`到达每个糖果的目的地。 

这将问题简化为迭代所有糖果站，计算每个糖果的最大交付时间，然后在所有站上取最大值。 这会产生一个`O(n + m)`如果我们预先计算每个站的糖果数量及其目的地，则可以找到解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m * n) | O(n * m * n) | O(米) | 太慢了 |
 | 最佳 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1.初始化一个数组`candies_at`尺寸的`n`为每个站点存储运送每个糖果的距离列表。 距离以模计算`n`作为`(b_i - a_i + n) % n`。 
2. 对于每个糖果，将其距离添加到相应站点的列表中`candies_at`。 如果一个站点有多个糖果，它们的距离会单独存储。 
3.初始化一个数组`result`尺寸的`n`存储每个可能的起始站的最小总交货时间。 
4. 迭代每个起始站`start`从 1 到`n`。 对于每个站`s`有糖果，计算如果火车在`start`。 计算初始距离`d`从`start`到`s`模数`n`， IE。，`(s - start + n) % n`。 
5. 对于车站`s`和`k`糖果，其糖果的交货时间计算为`d + (k-1) * n + max_distance_to_destination`， 在哪里`max_distance_to_destination`是糖果之间最远的距离`s`。 该公式考虑了每次循环拾取多颗糖果所需的循环遍历以及从拾取到交付的距离。 
6. 跟踪给定起始站的所有站点之间的最大交货时间，并将其存储在`result[start]`。 
7. 打印`result`作为输出。 

其原理：不变的是，总的配送时间由糖果配送时间最长的车站决定，如果需要的话，会考虑等待多个循环。 通过计算每个站点的最长时间并取最大时间，我们捕获了从任何站点出发所需的真正最短时间。 模块化算术确保环绕被正确处理，并且`(k-1) * n`术语说明同一站有多种糖果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
candies_at = [[] for _ in range(n)]

for _ in range(m):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    dist = (b - a + n) % n
    candies_at[a].append(dist)

result = []

for start in range(n):
    max_time = 0
    for station in range(n):
        if not candies_at[station]:
            continue
        d = (station - start + n) % n
        k = len(candies_at[station])
        max_dist = max(candies_at[station])
        time_needed = d + (k - 1) * n + max_dist
        if time_needed > max_time:
            max_time = time_needed
    result.append(str(max_time))

print(" ".join(result))
```代码首先读取输入并存储每个站糖果的相对递送距离。 外环考虑每个可能的起始站。 对于每个有糖果的车站，它会计算从该车站运送所有糖果所需的时间，同时考虑到火车的循环运行和每次访问一颗糖果的限制。 所有站的最大值就是该起点的答案。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + m) | 每个糖果都会被处理一次来计算距离，并且每个站点每次开始都会迭代一次 |
 | 空间| O(n + m) | 列出每个车站的商店糖果距离 |

 和`n=5000`和`m=20000`，该解决方案每个外循环执行约 25,000 次操作，很容易满足 2 秒的限制。
