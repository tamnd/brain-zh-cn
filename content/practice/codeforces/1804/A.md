 ## 解决方案
 ## 问题理解

 国王从网格的原点开始，想要到达目标单元格`(a, b)`。 与普通国王不同，它只能垂直或水平移动一步，或者留在原地。 不寻常的限制是同一动作不能连续使用两次。 

如果国王这一秒向右移动，下一秒就无法向右移动。 如果跳过这一秒，则无法跳过下一秒。 

对于每个测试用例，我们需要达到目标所需的最短秒数。 

坐标很小，绝对值最多100，测试用例多达10000个。 这立即表明解决方案应该是一个简单的数学公式。 甚至一个`O(|a|+|b|)`每个测试的模拟都可以，但有一个直接的恒定时间答案。 

棘手的部分是了解限制如何影响运动。 粗心的解决方案可能会假设答案只是曼哈顿距离`|a|+|b|`，但是只要只需要朝一个方向移动，这种方法就会失败。 

考虑：```text
a = 0, b = -6
```国王需要左走六步。 由于连续两次向左移动是被禁止的，因此必须在它们之间插入一些东西：```text
L S L S L S L S L S L
```这需要 11 秒，而不是 6 秒。 

另一个微妙的情况是两个坐标需要相同的移动量：```text
a = 4, b = 4
```我们可以交替：```text
R U R U R U R U
```不需要额外的几秒钟。 答案是8。 

第三个重要的情况是当一个坐标占主导地位时：```text
a = 7, b = -8
```交替进行 7 次水平移动和 7 次垂直移动后，还剩下 1 次垂直移动。 由于最后一个移动已经是垂直的，我们必须在最后一个垂直移动之前插入一个额外的动作。 答案变成 15 而不是 14。 

## 方法

 蛮力方法会将状态建模为：

 - 当前位置
 - 之前的动作

 然后执行BFS，直到达到目标。 

棋盘仅包含 201 × 201 个单元，并且有 5 个可能的先前动作，因此状态空间很小。 这实际上可以在给定的范围内解决问题。 

然而，BFS 正在解决一个比必要的问题大得多的问题。 坐标虽小，但移动限制却有着非常规则的结构。 我们可以直接得出答案。 

让：```text
x = |a|
y = |b|
```认为`x ≥ y`。 

我们可以交替水平和垂直移动`y`回合：```text
H V H V ... H V
```这消耗了所有`y`垂直移动和`y`水平移动。 

现在仅：```text
x - y
```水平移动仍然存在。 

如果最后一次移动是垂直的，则可以立即执行剩余的第一个水平移动。 此后，每个额外的水平移动都需要一个分隔符，因为禁止相同的连续移动。 

对于剩余的水平移动：```text
k = x - y
```他们的成本是：```text
1 + 2(k - 1) = 2k - 1
```什么时候`k > 0`。 

结合一切：```text
2y + (2k - 1)
= 2y + 2(x-y) - 1
= 2x - 1
```每当`x > y`。 

如果`x = y`，完美的交替是可能的，答案很简单：```text
2x
```这产生了一个非常紧凑的公式：```text
if x == y:
    answer = 2x
else:
    answer = 2 * max(x, y) - 1
```### 方法比较

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 关于位置和先前动作的 BFS | O（电路板尺寸）| O（电路板尺寸）| 已接受但没有必要 |
 | 数学公式| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取目标坐标`(a, b)`。 

2. 计算：```text
   x = |a|
   y = |b|
   ```只有所需的水平和垂直移动的数量才重要。 

3.设：```text
   m = max(x, y)
   n = min(x, y)
   ```4. 如果`m == n`， 输出：```text
   2m
   ```我们可以在两种移动类型之间完美地交替。 

5.否则输出：```text
   2m - 1
   ```把较小的方向用尽后，较大的方向还需要额外的动作。 除了第一个动作之外的每一个额外动作都需要一个分离动作。 

### 为什么它有效

 只要两个方向都可用，最佳策略总是交替移动方向。 这会在两秒内使用一次水平移动和一次垂直移动，没有浪费动作。 

当较小方向的所有移动被消耗完后，只剩下一种移动类型。 可以立即采取剩余的第一个动作，因为前一个动作是相反的类型。 同一类型的每一个后续动作都需要一次分离动作。 使用料斗就足够了，因此不需要更大的成本。 

因此导出的公式与最小可能时间完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        a, b = map(int, input().split())

        x = abs(a)
        y = abs(b)

        if x == y:
            ans.append(str(2 * x))
        else:
            ans.append(str(2 * max(x, y) - 1))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```实现直接遵循数学推导。 

取绝对值消除了对方向的任何依赖。 从限制的角度来看，向左移动的行为与向右移动完全相同。 上、下也是同样的道理。 

唯一的分支是两个所需的移动计数是否相等。 当它们相等时，完美的交替是可能的。 否则较大的计数决定答案。 

不存在溢出问题，因为坐标以 100 为界。

 ## 边缘情况

 考虑：```text
1
0 1
```国王向左或向右走一步，立即到达。 该算法计算：```text
max = 1
min = 0
answer = 2×1−1 = 1
```这是正确的。 

考虑：```text
1
5 5
```每个动作都可以与其他类型的动作交替：```text

```该算法返回：```text

```与最佳序列长度相匹配。 

考虑：```text
1
0 6
```仅存在一种移动类型。 需要五个分隔符：```text

```该算法返回：```text

```这正是最优构造中的移动次数。
