 ## 解决方案
 ## 问题理解

 我们得到一个循环图$n$标记的顶点$0$到$n-1$。 循环中的每条边都有一种颜色，红色或蓝色。 对于任意两个顶点$i$和$j$，我们想知道是否存在一条从$i$到$j$沿着循环，使得边缘颜色的序列形成回文。 该路线可能会重新访问顶点，并且允许在每一步顺时针或逆时针行驶。 

输入给出了多个测试用例。 每个测试用例提供$n$和一个长度的字符串$n$代表循环中边的颜色。 任务是如果循环中的每对顶点都承认回文路线，则输出“YES”，否则输出“NO”。 

鉴于$n$可以达到$10^6$和总和$n$所有测试用例不超过$10^6$，一个直接检查每对顶点的解决方案（这将是$O(n^2)$）是不可行的。 解必须是线性的$n$每个测试用例，可能通过利用循环的结构和回文的性质。 

一个微妙的边缘情况是当循环具有交替颜色时，例如，“RBRBRB”与偶数$n$。 在这种情况下，对于某些顶点对来说，回文路线可能不存在。 另一种边缘情况是当所有边具有相同的颜色时 - 那么任何序列都是平凡的回文，即使路线重新访问顶点。 粗心的方法可能会尝试天真地检查所有对或忽略重新访问顶点的路线的需要。 

## 方法

 暴力方法会尝试检查每对顶点$(i,j)$并尝试建立一条回文路线。 对于每一对，可以模拟顺时针或逆时针运动并尝试匹配边缘颜色。 这种方法原则上是正确的，但需要检查$O(n^2)$对，并且模拟路径可能需要长达$O(n)$每对的步骤。 这导致$O(n^3)$在最坏的情况下，这太慢了。 

关键的观察是，对于任意两个顶点之间存在的回文路线，循环必须至少包含一个位置，其中两个连续的边具有相同的颜色。 如果存在这样的位置，那么就可以使用该“镜像点”构建一条回文路线：从$i$沿一个方向到镜像点，然后从镜像点到$j$相反，反映边缘颜色。 如果循环没有相同颜色的连续边，则边严格交替，并且对于偶数长度的循环，某些对不能形成回文路线。 换句话说，问题简化为检查是否存在至少一对具有相同颜色的连续边缘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和边缘颜色字符串$c$。 
2. 检查是否$n=3$。 如果$n=3$，任何 3 个顶点的循环都允许回文路线，因此打印“YES”并继续。 这处理最小循环边缘情况。 
3.从顶点0开始循环迭代到$n-1$，比较每条边$c_i$与下一个边缘$c_{(i+1)\bmod n}$。 
4. 如果至少一对连续边具有相同的颜色，则为此测试用例打印“YES”，因为该对为回文路线提供镜像点。 
5. 如果迭代完成后没有找到相同颜色的连续边缘，则打印“NO”。 

工作原理：镜像点确保任何路径都可以在两个方向上延伸以匹配回文属性。 如果没有连续的边沿相同，则循环完美交替。 在交替循环中，某些顶点对不能具有回文路线，因为边缘颜色不能对称反映，特别是当循环长度为偶数时。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        c = input().strip()
        found = False
        for i in range(n):
            if c[i] == c[(i+1)%n]:
                found = True
                break
        print("YES" if found else "NO")

solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`对于大型测试用例。 对于每个测试用例，我们迭代一次循环，并使用模算术检查连续边缘以环绕循环。 变量`found`标记镜像点的存在。 如果存在，则可以实现回文性质； 否则，输出为“NO”。 

一个微妙的点是使用`(i+1) % n`处理从最后一个边缘到第一个边缘的环绕，这对于正确检查循环连续性至关重要。 

## 工作示例

 输入样本`"5\nRRRRB"`：

 | 我| c[i] | [i+1] | c[i+1] 平等的？ |
 | --- | --- | --- | --- |
 | 0 | 右 | 右 | 是的 |

 我们在 i=0 处找到连续的相等边，因此输出“YES”。 

输入样本`"6\nRBRBRB"`：

 | 我| c[i] | [i+1] | c[i+1] 平等的？ |
 | --- | --- | --- | --- |
 | 0 | 右 | 乙| 没有 |
 | 1 | 乙| 右 | 没有 |
 | 2 | 右 | 乙| 没有 |
 | 3 | 乙| 右 | 没有 |
 | 4 | 右 | 乙| 没有 |
 | 5 | 乙| 右 | 没有 |

 没有连续的边相等，因此输出“NO”。 该跟踪证实了某些顶点对的交替循环失败。

 ## 边缘情况

 最小周期$n=3$会自动处理，因为任何三个边总是允许回文路由。 长度相等的交替循环说明了为什么连续相等边缘的存在至关重要。 像“RBRBRB”这样长度为6的循环没有连续的相等边，因此没有镜像点进行反射，产生“NO”。 该算法通过迭代边缘模来正确识别这一点$n$并检查是否相等。 所有边缘都相同的循环立即返回“YES”，这涵盖了统一颜色的情况。
