 ## 解决方案
 ## 问题理解

 我们被要求最大化以全零开头的整数数组的加权和。 数组有长度$n$并收到$m$初始操作，每个操作将数组的前缀或后缀加 1。在这些操作之后，Kevin 可以执行任意数量的附加前缀或后缀添加。 对于给定的目标值$v$，一个元素贡献其相应的权重$c_i$当且仅当其价值等于$v$。 任务是计算每个$v$从 1 到$V$，如果凯文继续保持最佳状态，可实现的最大美感。 

约束表明$n$和$m$可以大到$2\cdot 10^5$，因此任何迭代所有可能的操作序列的解决方案都是不可能的。 此外，$V$最多可达 2000 且总和$V^2$所有测试用例仅限于$4 \cdot 10^6$，表明具有复杂性的算法$O(n V)$是可以接受的。 

边缘情况包括长度为 1 的数组、所有权重都相等的数组，或者初始操作已经将某些元素推到超出范围的情况$V$。 如果没有正确考虑已经超出目标的元素，幼稚的实现可能会误判美感$v$并且不能减少。 

## 方法

 暴力方法在概念上很简单：模拟构建数组的初始操作$a$，那么对于每个$v$从 1 到$V$，尝试添加前缀和后缀的所有序列以准确达到$v$在每个索引处。 这种方法是正确的，但完全不可行，因为加法序列的数量呈指数增长$n$以及添加的数量。 即使我们限制自己尝试每个索引一次操作，最坏情况的复杂性是$O(n^2 V)$，对于$n \sim 2 \cdot 10^5$。 

关键的观察是，任意数量的前缀和后缀添加都可以表示为要添加到连续范围的非负整数。 具体来说，让我们定义$a_i$初始操作后。 使$a_i$确切地$v$，Kevin 必须进行额外的添加，以便$a_i + \text{additional}_i = v$。 由于前缀和后缀添加会影响范围，因此任何操作选择都对应于选择要增加的连续范围。 这将问题简化为最大权重总和$c_i$在一个范围内使得$a_i \le v$并且可以增加到$v$。 

正式地，让$d_i = v - a_i$。 一个元素$i$可以为美丽做出贡献，如果$d_i \ge 0$。 那么可实现的最大美感就是以下各项的最大总和：$c_i$在某些元素范围内，其中相应的$d_i$是非负的。 由于任何连续范围都可以使用前缀和后缀添加来递增，因此我们可以选择索引的任何连续子序列，其中$d_i \ge 0$并添加必要数量的操作以使它们准确地达到$v$。 这使我们能够计算答案$O(n)$每个值$v$使用 Kadane 算法的变体。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * V) | O(2^n * V) | O(n) | 太慢了|
 | 最佳 | O(nV)| O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组$a$具有长度的零$n$。 迭代通过$m$初始操作。 对于索引处类型 L 的每个操作$x$，将索引 0 处的差异数组增加 1 并在索引处递减$x$by 1. 对于索引处类型 R 的每个操作$x$, 在索引处递增$x-1$并在索引处递减$n$。 将差异数组转换为实际数组$a$通过取前缀和。 此步骤有效地模拟了 O(n + m) 中的所有初始操作。 
2. 对于每个目标值$v$从 1 到$V$, 计算$d_i = v - a_i$。 如果$d_i < 0$， 元素$i$无法到达$v$对美的贡献为零。 否则其重量$c_i$可用于求和。 
3. 应用最大子数组和算法$c_i$仅限于索引，其中$d_i \ge 0$。 从运行总和为零开始，迭代数组：if$d_i < 0$，将运行总和重置为零； 否则，添加$c_i$到运行总和并跟踪遇到的最大总和。 
4. 步骤 3 中找到的最大和就是这个问题的答案$v$。 对所有人重复$v$从 1 到$V$。 

这是有效的，因为任何连续的索引范围都可以调整以达到$v$使用前缀和后缀添加。 步骤 1 中的差异数组确保我们遵循初始操作。 最大子数组和确保我们最优地选择索引子集，以最大化美观而不逾越$v$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, V = map(int, input().split())
        c = list(map(int, input().split()))
        diff = [0]*(n+1)
        for _ in range(m):
            op, x = input().split()
            x = int(x)
            if op == 'L':
                diff[0] += 1
                diff[x] -= 1
            else:
                diff[x-1] += 1
                diff[n] -= 1
        a = [0]*n
        curr = 0
        for i in range(n):
            curr += diff[i]
            a[i] = curr

        result = []
        for v in range(1, V+1):
            max_beauty = 0
            curr_sum = 0
            for i in range(n):
                if a[i] > v:
                    curr_sum = 0
                else:
                    curr_sum += c[i]
                    if curr_sum > max_beauty:
                        max_beauty = curr_sum
            result.append(str(max_beauty))
        print(' '.join(result))

if __name__ == "__main__":
    solve()
```该解决方案首先在初始操作后使用差异数组构造数组，以有效地处理前缀和后缀增量。 然后对于每个值$v$，它通过迭代元素来计算最大美度，跳过那些已经超过的元素$v$，并使用运行总和来跟踪最佳连续子序列。 这避免了显式模拟额外的操作，并确保每个操作都具有最佳的美感$v$。 

## 工作示例

 ### 示例 1，第一个测试用例

 初始数组$a = [0,0,0]$。 操作：

 | R 3 | [1,1,2]|
 | L 1 | [2,1,2]|

 目标$v = 1$：$d = [-1,0,-1]$，只有索引 2 可以贡献，sum = 2。 

目标$v = 2$：$d = [0,1,0]$，连续子序列[2,3]可以递增，sum = 6。 

### 示例 2，第三个测试用例

 数组$a = [0,0,0,0,0]$，初始操作修改为$a = [3,2,2,1,1]$。 为了$v = 3$：

 | 我| a_i | d_i | c_i 贡献 |

 | 1 | 3 | 0 | 1 |
 | 2 | 2 | 1 | 1 |
 | 3 | 2 | 1 | 1 |
 | 4 | 1 | 2 | 1 |
 | 5 | 1 | 2 | 1 |

 非负的最大连续和$d_i$是3（指数1-3），美丽=3。
