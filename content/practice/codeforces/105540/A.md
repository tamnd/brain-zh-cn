 ## 解决方案
 ## 问题理解

 我们有一个矩形网格$n$行和$m$列。 每个单元格不是单个字符而是固定长度的短字符串$k$。 因此网格中的每个位置都存储一个“单词”，并且网格中的所有单词都应该遵循非常严格的模式。 

网格中只有一个特殊的单元格。 所有其他$n \cdot m - 1$单元格包含完全相同的字符串，而特殊单元格与该公共字符串至少有一个字符不同。 网格保证恰好包含一个这样的异常值，我们的任务是通过输出它的行和列来定位它。 

结构很重要：我们不是比较单个字符，而是比较整个长度块$k$。 输入格式连接所有$m \cdot k$每行字符，因此我们必须在推理之前重建每个单元格。 

约束条件$n, m \le 200$至多意味着$40{,}000$细胞，和$k \le 10$使得提取每个代币变得便宜。 这立即排除了比对所有细胞进行线性扫描更复杂的事情，因为即使$O(nm \cdot k)$操作是微不足道的。 

比较每对细胞的简单方法是$O((nm)^2 \cdot k)$，在最坏的情况下会进行数十亿次比较，并且是不必要的。 

一些边缘情况值得隔离。 

如果奇数单元格仅在其字符串的最后一个字符上有所不同，则逐个字符的全局频率检查仍然可以正确检测到它，但简单的全字符串散列方法必须确保没有冲突或格式错误。 

如果$k = 1$，问题就退化为在网格中寻找唯一元素，其中除了一个条目之外的所有元素都是相同的。 任何假设多字符字符串的方法仍必须处理这种情况，而不会出现特殊的大小写错误。 

如果异常字符串在视觉上与常见字符串相似，但只有一个字符不同，则行式或列式部分扫描仍然可以正确隔离它，但前提是对完整标记而不是前缀进行比较。 

## 方法

 蛮力的想法很简单。 我们重建每个细胞串并将每个细胞串与所有其他细胞串进行比较。 对于每个候选单元格，我们计算网格中存在多少个相同的字符串。 字符串恰好出现一次的单元格就是答案。 

这是有效的，因为该问题保证了唯一的异常值。 然而，它变得太慢了，因为比较所有对需要$O((nm)^2 \cdot k)$运营。 和$nm = 40{,}000$，这导致大约$1.6 \times 10^9$比较，这超出了典型的限制。 

关键的观察是我们不需要成对比较。 由于所有正常细胞都是相同的，因此正确的字符串至少出现两次。 奇数只出现一次。 这将问题转化为频率识别任务。 

因此，我们不是比较结构，而是将每个单元压缩为单个标识符（其完整字符串）、存储计数并定位唯一出现的位置。 这将问题简化为线性扫描加上散列或字典计数。 

输入字符串布局的结构也很重要：每行都是串联的$m$长度块$k$，因此正确的解析至关重要。 一旦解析，一切都会简化为标准频率问题$nm$项目。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对比较 |$O((nm)^2 \cdot k)$|$O(1)$| 太慢了 |
 | 频率计数（哈希图）|$O(nm \cdot k)$|$O(nm)$| 已接受 |

 ## 算法演练

 我们通过将每个单元格视为字符串标记并计算出现次数来解决该问题。 

1. 阅读$n, m, k$。 这些定义了存在多少单元以及每个单元串有多大。 
2. 对于每一行，读取长度的完整串联字符串$m \cdot k$。 稍后我们会将其切成块。 
3. 将每一行分成$m$子串，每个长度$k$。 每个子串代表位置处的一个网格单元$(i, j)$。 
4. 将每个单元格字符串插入到哈希映射（或字典）中，以跟踪它出现的次数。 这样做的同时，还要存储其第一次出现的位置。 
5. 处理完所有单元格后，扫描频率图并找到恰好出现一次的字符串。 这就是异常细胞。 
6. 输出与该唯一字符串对应的存储坐标。 

我们在插入期间存储坐标的原因是，稍后重新计算位置将需要再次遍历网格，这是不必要的。 

### 为什么它有效

 根据问题定义，所有非特殊单元都是相同的，因此它们在频率图中贡献相同的密钥。 特殊单元格至少有一个字符不同，这保证了它形成一个不同的密钥。 由于只有一个这样的单元格，因此其频率恰好为 1，而所有其他单元格的频率至少大于或等于重复项数 1。 唯一性约束确保选择中没有歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m, k = map(int, input().split())
    
    freq = {}
    pos = {}
    
    for i in range(n):
        row = input().strip()
        for j in range(m):
            cell = row[j * k:(j + 1) * k]
            if cell not in freq:
                freq[cell] = 0
                pos[cell] = (i + 1, j + 1)
            freq[cell] += 1

    for cell, cnt in freq.items():
        if cnt == 1:
            r, c = pos[cell]
            print(r, c)
            return

if __name__ == "__main__":
    main()
```实现的主要细节是仔细切片：每个单元格从索引开始$j \cdot k$并结束于$(j+1)\cdot k$。 这里的相差一错误是最常见的错误来源。 

我们还确保在存储输出坐标时，行索引从从零开始转换为从一开始。

 ## 边缘情况

 关键的边缘情况是特殊单元格仅因其他相同字符串内的单个字符而不同。 在这种情况下，基于前缀的分组将失败，但全字符串散列可以正确地将其分开。 

另一种情况是唯一单元格出现在第一行或第一列中。 由于我们在第一次遇到时存储位置，因此即使稍后处理重复项，我们也可以正确捕获坐标。 

最后一种情况是所有单元格看起来几乎相同，但不可打印的 ASCII 字符有所不同。 因为我们将字符串视为原始字节序列，所以频率计数仍然可靠并且不受字符语义的影响。
