 ## 解决方案
 ## 问题理解

 迷宫是用极坐标绘制的，以中心为起点。 只要我们不穿过或接触墙壁，就可以在任何方向上连续移动。 目标是确定是否存在至少一条从中心开始并达到任意大半径的连续路径，有效地逃离由墙壁形成的外部边界。 

每个壁都是圆形的或径向的。 圆形墙阻止给定角段沿固定半径的运动。 对于给定的径向段，直壁阻止沿固定角度的运动。 这些墙将平面划分为相连的区域，我们需要检查包含原点的区域是否连接到无穷大。 

这从根本上来说是平面细分中的连接问题。 每面墙的作用就像几何图中的一条边，墙之间的交叉点创建了运动选择分裂的顶点。 

半径最多为 20 的限制至关重要。 这意味着所有结构都集中在非常小的径向范围内，尽管角结构可能很密集。 每次测试最多 5000 堵墙，进行 20 次测试，任何以朴素方式显式构建所有几何相交的方法仍然可以通过，但前提是它避免了二次成对相交处理。 

当墙壁在一定半径的角度方向上形成完整的封闭体时，会出现微妙的边缘情况。 例如，即使没有一个单独跨越完整的 360 度，相同半径的多个圆弧也可以共同形成完整的屏障。 类似地，直线段可以组合形成径向分隔器，阻止所有方向的逃逸。 独立检查每堵墙的幼稚方法会错过这些组合封闭。 

另一个问题是环绕角度。 从 350° 到 10° 的圆形墙实际上跨越了 0° 边界，将角度视为线性间隔而不进行模块化处理会破坏正确性。 

## 方法

 一个蛮力的想法是将墙壁之间的每个交叉点视为图形节点，然后沿着墙壁连接相邻的线段并尝试从中心进行洪水填充。 每对墙都可能相交，由于墙的数量多达 5000 个，最坏情况下相交的数量可能达到数千万。 即使生成邻接也变得太慢，因为每面墙必须在每个交叉点处分成多个段。 

这种方法是正确的，因为迷宫是平面图，并且平面中的连通性与区域之间的图连通性完全对应。 然而，明确构建该安排的成本太高。 

关键的观察结果是径向坐标非常小。 可能的半径级别只有 20 个，这意味着连续平面可以离散为分层图。 每层对应于整数半径之间的圆环。 在每一层内部，墙壁仅限制角运动。 直壁充当层内的角屏障，而圆形壁充当层之间的径向屏障。 

一旦我们以这种方式重新解释问题，任务就减少到在跨层的角度间隔之间建立连接。 每一层都变成一个圆弧段图，每面墙都对连接转换提供约束。 然后我们检查第 0 层中的原点节点是否可以到达半径 20 之外的任何无界外部状态。 

这将问题转化为最多具有约 20 个径向层和 O(n) 角度约束的图连接任务，可以通过排序和区间扫描而不是几何交集枚举来处理。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 全几何图形构建 | O(n² + k²) | O(n² + k²) | O(n²) | 太慢了|
 | 分层径向角图缩减 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将每面墙转换为径向层或角段之间过渡的约束。 圆形壁以特定的角度间隔阻止沿半径的运动，而直壁则阻止沿两个半径之间的角度的运动。 
2. 将所有角度归一化为 [0, 360) 上的一致表示。 对于环绕 0° 的圆形墙，将它们分成两个间​​隔。 这确保所有角度约束都成为标准间隔。 
3. 对于 r 和 r+1 之间的每个径向层，收集由穿过该层的直壁引起的所有角度阻挡段。 每个直壁在该径向带内贡献一个阻挡角间隔。 
4. 对这些角度间隔进行排序并合并重叠部分。 合并后，我们得到每层的最大阻挡区域。 
5. 检查任意层的遮挡角区间是否完全覆盖圆。 如果在任何半径带上，阻挡角的并集覆盖 360°，则该层将成为一个闭合环，并且阻挡逃逸到其之外。 
6. 此外，圆形墙壁会产生放射状切口。 对于每个半径 r，圆弧都会产生阻止角段，防止从层 r−1 穿过到 r。 我们将这些视为必须进行类似检查以实现完整角度覆盖的障碍。 
7、从最里面的区域开始，模拟向外逐层遍历。 如果我们能够通过每个径向边界而不遇到完全闭合的角度障碍，那么逃脱是可能的。 
8. 如果超出最大半径且没有被阻挡，则输出 YES。 否则输出NO。 

### 为什么它有效

 该算法之所以有效，是因为从原点到无穷远的每条有效路径都必须单调地穿过径向层。 由于半径沿任何逃逸路径严格增加，因此 r 和 r+1 之间的每次过渡都必须通过某个未被墙壁阻挡的角扇区发生。 通过将几何体折叠成每层的角度覆盖范围，我们准确地保留了可能交叉的条件。 任何层的完全角度覆盖都意味着乔丹曲线状的屏障将内部和外部区域断开，使逃脱变得不可能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def norm(a):
    a %= 360
    return a

def add_interval(intervals, l, r):
    if l <= r:
        intervals.append((l, r))
    else:
        intervals.append((l, 360))
        intervals.append((0, r))

def merge(intervals):
    if not intervals:
        return []
    intervals.sort()
    res = []
    cur_l, cur_r = intervals[0]
    for l, r in intervals[1:]:
        if l <= cur_r:
            cur_r = max(cur_r, r)
        else:
            res.append((cur_l, cur_r))
            cur_l, cur_r = l, r
    res.append((cur_l, cur_r))
    return res

def covered(intervals):
    total = 0
    for l, r in intervals:
        total += r - l
    return total >= 360

def solve():
    n = int(input())
    layers = [[] for _ in range(21)]

    for _ in range(n):
        parts = input().split()
        t = parts[0]
        if t == 'S':
            r1, r2, th = map(int, parts[1:])
            # straight wall blocks angle th between r1 and r2
            for r in range(r1, r2):
                layers[r].append((norm(th), norm(th)))
        else:
            r, a, b = map(int, parts[1:])
            add_interval(layers[r], a, b)

    for r in range(1, 21):
        intervals = layers[r]
        merged = merge(intervals)
        if covered(merged):
            print("NO")
            return

    print("YES")

if __name__ == "__main__":
    solve()
```直壁分布在它们相交的所有径向层中，因为它们充当与半径无关的角阻挡器。 圆形墙直接放置在其半径处，作为有角度的阻挡弧。 收集每层的所有约束后，合并间隔可揭示该半径处的圆是否完全密封。 

关键的实现细节是分割圆弧的环绕间隔，因为如果不这样做，就会错误地低估阻塞覆盖范围。 另一个微妙之处是将直墙视为零宽度的角度切割； 虽然它们是线，但为了连接，它们仍然充当其段中所有半径的该角度的阻挡者。

 ## 边缘情况

 一个关键的边缘情况是穿过 0° 边界的圆形墙。 例如，350°到10°的墙必须分成两个区间； 否则，天真的合并会看到一个很小的段，而不是一个大的阻塞弧。 正确的解释是将其视为覆盖大部分圆的两个区间。 

另一个边缘情况是多个直墙仅在合并后才累积到完全覆盖。 它们单独地阻挡了孤立的角度，但总的来说它们可以弥补所有剩余的间隙。 合并步骤确保在检查完全覆盖之前正确组合邻接。 

第三种情况是没有墙直接覆盖某个层，但相邻层之间的组合阻止了任何向上的径向遍历。 分层聚合确保每个径向过渡都是独立验证的，因此部分局部开口不会错误地暗示全局逃逸。
