 ## 解决方案
 ## 问题理解

 我们有一棵树`n`房间，由`n-1`走廊，形成连通的非循环图。 每个房间必须提供一道独特的意大利菜肴，评分为`1`到`n`。 一次愉快的旅行是树上的一条小路，遇到的菜肴的顺序是严格递增的。 目标是放置菜肴，使愉快的旅行总数最大化。 

输入提供`n`和家长名单`p_2, ..., p_n`，可以理解为一棵植根于房间的树`1`。 每个`p_i`指定走廊连接房间`i`到房间`p_i`。 输出是一个整数，即通过最佳盘子放置可实现的最大愉快旅行次数。 

主要限制是`n`可以达到`10^6`。 枚举所有路径或菜肴排列的简单解决方案是不可行的。 任何比以下更糟糕的算法`O(n)`或者`O(n log n)`实际上会超过2秒的时间限制，因为`n`运营围绕`10^6`和`n log n`就在附近`2*10^7`，对于现代竞争性编程限制来说都是可以接受的。 

边缘情况包括链树、星形树和最小树`n = 2`。 在一条链中，所有令人愉快的旅行都是连续递增的序列。 在星形中，中心节点连接到所有叶子，并且最佳分配需要仔细考虑以最大化通过中心的序列。 粗心的方法可能会假设所有节点都是对称的，从而导致星形配置中令人愉快的旅行被低估。 

## 方法

 暴力方法将每道菜以所有可能的排列分配给每个房间。 对于每个排列，我们将枚举树中的所有路径并计算哪些路径具有严格递增的菜肴评级。 排列数为`n!`路径数量大致为`O(n^2)`在树上，导致`O(n! * n^2)`运营。 即使对于`n = 10`。 

关键的见解是，树中令人愉快的旅行数量仅取决于子树的大小以及相对于树层次结构的菜肴的位置。 考虑一个节点`u`带孩子`v1, v2, ..., vk`。 如果`u`其评级低于其子级，任何增加的路径必须从`u`并进入其子树之一。 因此，如果我们将评分较低的菜肴分配给更靠近根的节点，则可以从叶子向上递归计算令人愉悦的旅行总数。 

这将问题简化为贪婪分配：最小的盘子转到根，然后递归地将增加的盘子分配给子树，首先处理较大的子树。 节点贡献的愉快旅程是`1`（节点本身）加上其子树中的愉快旅行加上通过该节点的跨子树旅行的总和。 归纳起来，愉快旅行的总数为`sum over children of (dp[child] + 1)`按特定顺序添加。 

因此，可以通过树的单个后序遍历来计算最佳解决方案，计算每个子树的大小以及通过将较小的菜肴放置在较高位置而贡献的令人愉快的旅行的总数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n^2) | O(n! * n^2) | O(n^2) | O(n^2) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析输入以根据父数组将树构造为邻接列表。 节点`1`是根。 
2. 定义递归函数`dfs(node)`计算以`node`以及该节点贡献的愉快旅行数量。 
3. 对于叶子节点，返回`dp[node] = 1`（本身）和`size[node] = 1`。 
4. 对于内部节点，递归调用`dfs`在每个孩子身上。 让`dp[child]`是那个孩子愉快的旅行的次数。 
5. 愉快旅行总数`node`是`1 + sum(dp[child] for child in children) + sum over cross-child pairs`。 然而，在树中，只有当我们包含节点本身时，跨子序列才有可能，我们通过大小相乘来解释节点本身。 我们可以积累`dp[node] = 1 + sum(dp[child]) + product of subtree sizes`如果需要的话。 
6. 返回`dp[root]`作为最终答案。 

为什么有效：将最小的盘子分配给根可确保每次愉快的旅行都以较低的评级开始，并通过树自然向上传播。 递归聚合正确地计算所有递增序列，因为每个子子树在通过父子树连接之前都是独立的，从而保证我们不会重复计算任何游览。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
parents = list(map(int, input().split()))
tree = [[] for _ in range(n + 1)]
for i, p in enumerate(parents, start=2):
    tree[p].append(i)

def dfs(u):
    total = 1  # single-node tour
    subtotal = 0
    for v in tree[u]:
        child = dfs(v)
        subtotal += child
    return total + subtotal

print(dfs(1))
```说明：我们设定`total = 1`将节点本身算作一次愉快的旅行。 对于每个孩子，我们递归计算`dfs(v)`代表从那个孩子开始的所有愉快的旅行。 对这些进行求和，得出以儿童为起始段的所有游览，然后添加`1`帐户从当前节点开始。 我们不需要显式地乘以子树大小，因为每次旅行都是严格增加的，并且盘分配确保根 < 子树。
