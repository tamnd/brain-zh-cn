 ## 解决方案
 ## 问题理解

 我们有`n`人们坐在圆桌旁，编号为`1`到`n`。 最初的座位是自然顺序`[1, 2, 3, …, n]`绕桌子顺时针旋转。 我们以排列的形式给出了所需的座位顺序`p`。 我们的任务是使用允许的最小交换次数来达到这种排列。 交换只能发生在坐在一起的两个人之间，但有限制，我们不能交换人`x`和`x+1`为了`1 ≤ x ≤ n-1`。 唯一跨越“禁止邻接”的交换是在人与人之间`n`和人`1`因为桌子是圆形的。 

输入指定多个测试用例。 对于每个，我们收到`n`和长度的排列`n`。 输出是达到所需循环顺序的最小交换次数。 

约束告诉我们`n`可以大到 200,000 并且总和`n`所有测试用例的数量限制为 200,000。 这有效地排除了每个测试用例复杂性低于 O(n) 的任何解决方案。 简单地模拟交换是不可行的，因为单独移动每个人可能需要 O(n²) 操作。 当所需的排列是恒等排列的旋转版本时，或者当数字按降序排列时，就会出现边缘情况。 粗心的模拟可能会由于忽略表的循环性质或禁止的交换而错误地计算交换。 

## 方法

 暴力方法是直接模拟交换。 开始于`[1, 2, …, n]`，我们会尝试仅使用允许的交换将每个人带到他们的目标位置。 这种方法是正确的，因为交换是可逆的，并且由于之间的循环交换，任何排列都是可达的`1`和`n`。 然而，在最坏的情况下，单独移动元素需要 O(n²) 操作，这对于`n`最多200,000。 

最佳解决方案的关键见解是将表视为排列循环问题。 让`pos[i]`是 person 的当前索引`i`。 每个人都希望处于与前任相对应的位置。 既然我们不能交换`x`和`x+1`，目标排列中的每个递增连续序列都已经遵守“不能交换”规则，并且不需要内部重新排序。 因此，问题简化为识别最长的连续递增子序列（带环绕）并计算有多少元素相对于它是无序的。 不在此序列中的每个人都必须使用唯一允许的环绕交换进行移动，这可以算术计数而不是模拟计数。 

这一观察结果通过避免显式交换模拟将复杂性从 O(n²) 降低到 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于排列`p`,建立一个数组`pos`在哪里`pos[i]`是人的索引`i`在`p`。 这使我们能够快速检查目标排列中任意两个人的相对位置。 
2. 遍历所有来自`1`到`n-1`并计算最长连续递增序列的长度`p`尊重原始编号。 具体来说，对于`i`从 2 到`n`， 如果`pos[i] > pos[i-1]`，那么人`i`正确放置在之后`i-1`在排列中。 否则，连续序列结束。 维持一个`max_len`存储最长的序列。 
3. 最少需要的交换次数为`n - max_len`。 这是因为最长的连续递增子序列不需要内部交换，并且必须使用允许的交换将剩余的每个人移动到位。 
4. 输出每个测试用例的结果。 

这样做的原因是每次交换一次只能将一个人移动到正确的序列中。 通过识别最大已排序序列，我们可以最大限度地减少所需交换的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        pos = [0] * (n + 1)
        for i, x in enumerate(p):
            pos[x] = i
        max_len = 1
        cur_len = 1
        for i in range(2, n + 1):
            if pos[i] > pos[i - 1]:
                cur_len += 1
                max_len = max(max_len, cur_len)
            else:
                cur_len = 1
        print(n - max_len)

if __name__ == "__main__":
    solve()
```解决方案首先构建`pos`，将每个人映射到他们的位置。 这对于检查连续数字时的恒定时间查找至关重要。 然后它跟踪`cur_len`增加指数，更新`max_len`根据需要。 最后的减法`n - max_len`直接产生最小交换计数。 通过索引可以避免差一错误`pos`从 1 开始，所有算术都使用整数索引，因此不存在溢出问题。

 ## 边缘情况

 对于完全相反的排列`[n, n-1, ..., 1]`，算法正确找到`max_len = 1`和输出`n - 1`互换。 对于已经排序的排列`[1, 2, ..., n]`,`max_len = n`输出是`0`。 在轮换情况下，例如`[3, 1, 2]`，根据位置，最长的连续递增序列被正确识别为长度 1 或 2，并且输出与最小交换计数匹配。 该算法本质上考虑了禁止邻接，因为它只计算排列索引中已经按递增顺序排列的元素。
