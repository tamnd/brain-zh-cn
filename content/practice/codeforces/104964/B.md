 ## 解决方案
 ## 问题理解

 我们有一排建筑物，每个建筑物都必须接收一个放置在某个整数高度的传感器。 用于建筑$i$，选择的高度$d_i$被限制在它自己的区间内$[a_i, b_i]$。 一旦选择了所有高度，配置的成本就是相邻传感器之间的总绝对差，沿线求和，因此$|d_1-d_2| + |d_2-d_3| + \dots + |d_{n-1}-d_n|$。 任务是选择有效的高度来最小化这个总数。 

该结构是顺序的：每个决策仅通过绝对差异与其直接邻居交互。 不存在连接非相邻位置的全局约束，但一个位置的选择会间接影响所有未来成本，因为它会影响我们距下一个间隔的距离。 

输入大小将我们推向每次测试的线性或近线性行为。 总和$n$所有测试的结果是$10^6$，所以任何超过的解决方案$O(n \log n)$每个测试都有由于重复的繁重转换而超时的风险。 内存很简单，因为我们只需要大小的数组$n$。 

一个天真的陷阱是假设我们可以独立选择$d_i$作为里面的任何值$[a_i, b_i]$从左到右贪婪地最小化局部差异。 当局部最优选择迫使稍后进行大幅跳跃时，这种方法就会失败。 

例如，考虑间隔：$$[0, 10], [5, 5], [0, 10]$$如果我们贪心地挑选$d_1 = 0$， 然后$d_2 = 5$， 然后$d_3 = 0$，我们得到成本$5 + 5 = 10$。 但如果我们选择$d_1 = 5$， 然后$d_2 = 5$， 然后$d_3 = 5$，成本为$0$。 第一步的选择决定了未来的转型能否扁平化。 

因此，关键的困难在于每个位置必须在接近先前的选择和自己允许的区间之间取得平衡。 

## 方法

 蛮力观点是考虑在每个位置$i$，我们可以选择任意整数$[a_i, b_i]$，并且我们希望最小化成对成本的全局总和。 这表明了动态规划的定义：让$dp[i][x]$是达到该位置的最小成本$i$如果我们以价值结束$x$。 从所有可能的先前过渡$x$对每一个可能的电流$y$导致$$dp[i][y] = \min_{x \in [a_{i-1}, b_{i-1}]} dp[i-1][x] + |x-y|.$$即使我们离散化值，间隔大小也可能很大，最多可达$10^9$，使得无法明确计算。 即使我们压缩值，在最坏的情况下，转换也是二次的。 

关键的观察是我们永远不需要完整的功能$dp[i][x]$。 重要的是，从前一个区间到具有绝对值成本的新区间的转变可以通过将_最佳代表点向前推_来概括。 在任何一步中，前缀的最佳配置$1..i-1$可以概括为单个值$d_{i-1}$，因为一旦我们确定了位置的最终选择值$i-1$，未来只取决于那个终点，而不取决于我们如何到达它。 

乍一看这并不明显，但从成本是独立边缘贡献的总和这一事实可以看出。 对于固定的$d_{i-1}$，最优的$d_i$只是最接近的值$d_{i-1}$里面$[a_i, b_i]$， 因为$|d_{i-1}-d_i|$独立于未来的步骤被最小化。 

因此，全局问题分解为重复地将前一个值投影到下一个区间。

 ## 算法演练

 我们从左到右处理建筑物，保持前一个建筑物的选定高度。 

1. 从第一栋建筑开始。 中的任何值$[a_1, b_1]$是有效的。 我们挑选$d_1 = a_1$因为没有之前的成本需要考虑。 
2. 对于每一个下一个建筑物$i$，比较之前选择的高度$d_{i-1}$与间隔$[a_i, b_i]$。 
3.如果$d_{i-1}$位于区间内，我们设置$d_i = d_{i-1}$。 这使得过渡成本为零，并且没有理由离开，因为它对未来的步骤没有帮助。 
4. 如果$d_{i-1} < a_i$，我们设置$d_i = a_i$。 这是距左边界最近的可行点，最小化$|d_{i-1}-d_i|$。 
5. 如果$d_{i-1} > b_i$，我们设置$d_i = b_i$。 这对称地最小化了从上方到间隔的距离。 
6. 累计成本$|d_{i-1} - d_i|$在每一步。 

该算法构建有效序列，同时始终选择与前一个序列最接近的可行值。 

### 为什么它有效

 在每一步中，唯一的贡献涉及$d_i$这取决于未来，这是下一个区别$|d_i - d_{i+1}|$。 然而，一旦我们到达步骤$i$，区间内的任何值都同样可用于未来的步骤，并且未来的区间只关心当前位置，而不关心我们如何到达那里。 因此，最小化直接过渡距离不会牺牲未来的最优性。 最佳结构简化为重复地将先前的值投影到下一个允许的区间，因为任何偏差只会增加当前的成本，而不会提高未来步骤的可行性或灵活性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        d = [0] * n
        d[0] = a[0]
        total = 0

        for i in range(1, n):
            if d[i - 1] < a[i]:
                d[i] = a[i]
            elif d[i - 1] > b[i]:
                d[i] = b[i]
            else:
                d[i] = d[i - 1]

            total += abs(d[i] - d[i - 1])

        print(total)
        print(*d)

if __name__ == "__main__":
    solve()
```该解决方案保留运行中选择的值，并且仅在其超出当前间隔时对其进行调整。 成本是逐步积累的。 关键的微妙之处在于相等的情况很重要：如果前一个值恰好位于区间内，我们必须保持它不变以保持零成本转换。

```## 边缘情况

 一种边缘情况是所有间隔在一个点重叠。 例如：```
n = 4
a = [5, 5, 5, 5]
b = [5, 5, 5, 5]
```每一步都充满力量$d_i = 5$。 该算法立即锁定唯一可行的值，并在每次转换时累积零成本。 没有歧义，因为投影总是返回相同的点。 

另一种情况是当间隔严格递减时，每个步骤都会强制进行边界跳跃：```
a = [0, 10, 20]
b = [0, 10, 20]
```这里，前一个值总是在右侧的下一个区间之外，因此我们重复向下投影到每个区间的右端点，累积确定性步骤成本。 贪心规则总是选择最近的边界，因此每个转移成本等于相邻间隔之间的精确间隙，匹配最优解，因为没有中间选择可以减少以后的距离。
