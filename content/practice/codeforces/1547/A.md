 ## 解决方案
 ## 问题理解

 我们正在研究一个无限网格，允许在四个方向上移动：上、下、左、右，每个方向花费一步。 我们有三个特殊的单元格：起始单元格、目标单元格和无法踩踏的禁止单元格。 任务是计算从起点到目标所需的最短移动次数，而不会落在禁止单元上。 

如果不存在禁止单元，则答案将只是起点和目标之间的曼哈顿距离，因为在自由移动的网格中，最短路径始终是水平和垂直间隔的总和。 

最多 10^4 个测试用例的约束迫使我们避免每个查询进行任何图形搜索。 网格上的 BFS 会太慢，因为即使坐标以 1000 为界，网格在概念上也是无界的，并且 BFS 复杂性取决于探索的区域，而不是输入大小。 每个测试用例我们需要一个 O(1) 公式。 

当禁止单元恰好位于 A 和 B 之间的曼哈顿直线路径上时，就会出现关键的边缘情况。例如，如果 A 为 (1,1)、B 为 (1,5)、F 为 (1,3)，则直接垂直路径被阻塞。 简单的曼哈顿距离计算将返回 4，但真正的答案是 6，因为我们必须绕道 F。另一个微妙的情况是当 F 不在 A 和 B 之间的任何最短路径走廊上时； 那么答案保持不变。 

## 方法

 没有障碍，问题就微不足道了。 两个网格点之间的最短路径就是曼哈顿距离，计算为 x 坐标的绝对差加上 y 坐标的绝对差。 这是可行的，因为每条最佳路径都必须进行那么多的水平和垂直移动，并且这些移动的任何排列都是有效的。 

引入单个禁止单元只能以非常有限的方式改变事物。 答案与曼哈顿距离不同的唯一情况是，从 A 到 B 的每条最短路径都被迫经过 F。当 A、B 和 F 位于同一行或列段且 F 位于它们之间时，就会发生这种情况。 在这种情况下，任何最短路径都会踩在 F 上，因此我们必须绕道而行，这正好增加了两个额外的步骤。 

如果 F 不在曼哈顿意义上由 A 和 B 形成的几何线段上，我们仍然可以通过稍微调整移动顺序来实现曼哈顿距离，这样我们就永远不会落在 F 上。这是可能的，因为总有至少一条替代的最短路径可以避免单个偏离路径点。 

因此，解决方案简化为计算曼哈顿距离，然后检查 F 是否阻挡 A 和 B 在直线段上的直接对齐。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 网格上的强力 BFS | 每个查询 O(N)（实际上无界） | O(N) | 太慢了 |
 | 曼哈顿+封锁检查| 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算 A 和 B 之间的曼哈顿距离作为基本答案。 这代表忽略障碍物的最短可能路径。 
2. 检查A 和B 是否水平或垂直对齐。 如果它们不以这种方式对齐，则没有一个点可以强制所有最短路径通过 F，因此基本答案仍然有效。 
3. 如果 A 和 B 共享相同的 x 坐标，则任何最短路径仅垂直移动。 在这种情况下，检查 F 是否也位于同一垂直线上，并且其 y 坐标严格位于 A 和 B 的 y 坐标之间。 
4. 如果 A 和 B 共享相同的 y 坐标，请执行水平对齐的对称检查。 
5. 如果在任一情况下 F 恰好位于 A 和 B 之间的路段上，则将答案增加 2 以考虑绕行被阻塞单元格的情况。

绕行成本正好为 2，因为避免直线上中间单元格被阻塞的最小方法是让开一个单元，绕过它，然后返回到原来的线。 

### 为什么它有效

 网格中的最短路径完全通过选择水平和垂直移动的顺序来确定。 如果单个阻塞单元位于保持最佳长度的每条单调路径上，则它只能使所有最短路径无效。 仅当路径限制为单个行或列段时才会发生这种情况。 在此配置之外，我们始终可以重新排序移动，以便绕过禁止单元，而无需增加总路径长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    xA, yA = map(int, input().split())
    xB, yB = map(int, input().split())
    xF, yF = map(int, input().split())

    ans = abs(xA - xB) + abs(yA - yB)

    if xA == xB == xF:
        if min(yA, yB) < yF < max(yA, yB):
            ans += 2

    if yA == yB == yF:
        if min(xA, xB) < xF < max(xA, xB):
            ans += 2

    return ans

t = int(input())
out = []
for _ in range(t):
    input()
    out.append(str(solve()))

print("\n".join(out))
```该实现直接计算曼哈顿距离，然后如果禁止单元严格位于共享轴上的 A 和 B 之间，则应用恒定时间校正。 测试用例之间的空行被显式消耗，因为输入格式包含它。 

一个常见的实施错误是忘记严格的不平等检查。 如果 F 等于 A 或 B，则它不应触发任何绕行逻辑，因为该问题保证了不同的小区，但即使放宽该假设，端点也不会以相同的方式阻塞最短路径。 

## 工作示例

 考虑 A = (1,1)、B = (3,3) 和 F = (2,2) 的情况。 曼哈顿距离为 4。单元格未水平或垂直对齐，因此不应用任何校正。 

| 步骤| x 条件 | y 条件 | 更正| 答案|
 | --- | --- | --- | --- | --- |
 | 初始化| - | - | 0 | 4 |

 这表明对角线移动情况不受不在强制走廊上的单个障碍物的影响。 

现在考虑 A = (2,5)、B = (2,1)、F = (2,3)。 曼哈顿距离为 4。由于所有点共享 x = 2 并且 F 位于 y = 5 和 y = 1 之间，因此每条直接垂直最短路径都经过 F。 

| 步骤| 对齐| F 之间 | 更正| 答案|
 | --- | --- | --- | --- | --- |
 | 初始化| 垂直| 是的 | +2 | 6 |

 这证实了绕行规则，即路径必须向一侧移动一步并返回，长度恰好增加 2。

 ## 边缘情况

 一种重要的情况是 A 和 B 对齐但 F 位于线段之外。 例如A = (1,1)、B = (1,5)、F = (1,10)。 该算法检查严格的不等式，因此不应用任何校正，答案仍然是 4。这是正确的，因为我们可以在不触及 F 的情况下向上路由路径。 

另一种情况是当 x 或 y 中保持对齐但 F 与一个端点重合时。 该问题保证了不同的点，但即使没有，端点也不会强制绕道，因为路径从那里开始或结束。 

最后一种情况是 A 和 B 未对齐，即使 F 与其中之一共享坐标。 曼哈顿路径总是可以重新排列以避免 F，同时保留长度，因此不需要校正。
