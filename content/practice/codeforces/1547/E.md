 ## 解决方案
 ## 问题理解

 给定一个一维长度的条带$n$。 该条带上的某些位置装有空调，每个空调都固定在已知的坐标上，并且每个位置都会产生自己的基础温度。 每个其他单元都会继承一个由其与所有空调的距离决定的温度：对于每个空调，对单元的贡献是其基础温度加上与该单元的绝对距离，最终温度是所有此类贡献中的最小值。 

因此，每台空调就像一个源，当我们远离它时，它会“辐射”线性增加的温度。 对于线上的每个位置，我们希望所有这些线性增长函数中的最小值。 

输入大小最多允许$3 \cdot 10^5$所有测试用例的总单元格。 任何试图通过独立扫描所有调节器来计算每个细胞答案的解决方案的执行效果可达$O(nk)$测试用例中的操作，退化为$9 \cdot 10^{10}$在最坏的情况下也是不可行的。 这立即排除了每个单元的暴力破解。 

一个关键的结构细节是每台空调都具有 V 形功能$t_i + |a_i - x|$。 最终答案是这些 V 形的下包络线。 

幼稚推理的一个常见失败案例是仅错误地计算最近的空调。 例如，如果两个调节器位于位置 1 和 100，且温度相似，则中间的单元会受到两者的影响，并且当基础温度显着差异时，最小值不一定是原始距离中最接近的单元。 

另一种微妙的边缘情况是当一台空调距离很远但基础温度却小得多时。 贪婪的仅最近位置方法在这里失败，因为它忽略了垂直偏移。 

## 方法

 蛮力方法独立评估每个细胞。 对于固定位置$i$，它检查所有调节器并计算$t_j + |a_j - i|$，取最小值。 这是正确的，因为它直接遵循定义。 成本来自于对所有的人重复这个计算$n$细胞，给予$O(nk)$在最坏的情况下每个测试用例的操作，当两者都时太慢$n$和$k$很大。 

关键的观察结果是，每个调节器定义了一条线上的函数，而答案是每个点上这些函数的最小值。 我们没有将其视为独立查询，而是将其重新解释为折线图上的多源最短路径问题：每个调节器都是具有初始距离的源$t_i$，向左或向右移动每步都会增加 1 的成本。 这正是图上的最短路径，其中每个节点都以权重 1 连接到其邻居。 

这种结构允许多源 BFS 或类似 Dijkstra 的传播。 由于所有边权重均为 1，因此我们可以立即初始化所有源，并使用双端队列或优先级队列逻辑按距离递增顺序向外传播。 最佳的简化是，这成为经典的“线上多源最短路径”，在对源进行排序后减少为线性扫描。 

我们从左到右、从右到左进行处理，因为每个方向独立计算该侧调节器的最佳贡献。 最终的答案是这两次扫描中的最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nk)$|$O(1)$| 太慢了|
 | 二次传播 |$O(n + k)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将这条线视为影响力从每个调节器向外传播的东西，并且我们分别从两个方向计算最小值。 

1.初始化一个数组`ans`尺寸的$n$与无穷大。 这代表迄今为止未知的最佳温度。 
2.对于每个位置的空调$a_i$， 放`ans[a_i] = t_i`。 这说明了这样一个事实：从源头来说，成本正是其基础温度。 
3. 从左向右扫动。 保持来自左侧的最佳可能值。 在位置$i$，最好的左边影响是要么从护发素开始新鲜$i$，或将之前的最佳成绩延长+1。 我们更新`ans[i] = min(ans[i], ans[i-1] + 1)`。 此步骤确保我们捕获所有向左向右传播的调节器的效果。 
4.从右向左对称扫动。 保持从右侧传播。 在位置$i$， 更新`ans[i] = min(ans[i], ans[i+1] + 1)`。 这可确保右侧调节器正确影响左侧。 
5.输出最终结果`ans`大批。 

每次扫描使用简单的 +1 过渡的原因是移动一个单元格会使距离恰好增加 1，因此每一步都能正确模拟绝对距离扩展。 

### 为什么它有效

 每个调节器定义一个在两个方向上均匀扩展的距离场。 从左到右的传递计算从任何源开始经过一系列右移动的所有路径的最小值，而从右到左的传递对左移动执行相同的操作。 由于从源到单元的任何最佳路径在离开源后在一个方向上都是单调的，因此必须通过这两个扫描之一完全捕获它。 取两个方向的最小值即可重建所有方向的完整包络$t_i + |a_i - x|$功能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    INF = 10**18

    for _ in range(q):
        input()
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        t = list(map(int, input().split()))

        ans = [INF] * n

        for i in range(k):
            ans[a[i] - 1] = t[i]

        for i in range(1, n):
            ans[i] = min(ans[i], ans[i - 1] + 1)

        for i in range(n - 2, -1, -1):
            ans[i] = min(ans[i], ans[i + 1] + 1)

        print(*ans)

if __name__ == "__main__":
    solve()
```初始化步骤将所有空调直接放入阵列中。 从左到右的扫描正确地模拟了每一步增加一的影响传播。 从右到左扫描可以纠正最佳源位于右侧的情况。 使用大`INF`确保未初始化的单元不会错误地支配最小值。 

一个常见的实施错误是忘记将位置转换为从零开始的索引。 另一个微妙的问题是在传播过程中覆盖而不是取最小值，这会错误地丢弃更好的路径。

 ## 边缘情况

 最小的单空调案例，例如$n=1, k=1$位置 1 直接初始化数组，并且传播不会改变它，从而确认简并输入的正确性。
