 ## 解决方案
 ## 问题理解

 我们得到一个正整数的循环数组。 在每一步中，我们将每个元素替换为其自身及其右邻居的最大公约数，并在最后环绕。 任务是计算直到数组中的所有元素都相等所需的最小步骤数。 如果所有元素都相等，则答案为零。 

输入给出了多个测试用例。 每个测试用例提供数组长度$n$和数组元素。 我们必须为每个测试用例输出一个整数：稳定之前的最小步骤。 

限制因素很大。$n$可以达到$2 \cdot 10^5$以及所有的总和$n$跨测试用例也受$2 \cdot 10^5$。 这立即排除了任何简单地模拟每个步骤的解决方案，因为每个步骤都需要$O(n)$如果数组元素不相关，时间和步数可能会很大。 二次方法可能需要以下量级$n^2$每个测试用例的操作，这太慢了。 

很容易错过的边缘情况包括所有元素最初都相同的数组、具有许多小素数的数组或只有一个元素与其他元素不同的数组。 例如，如果数组是`[42, 42, 42, 42]`，答案为零。 如果数组是`[2, 3, 2]`，简单的模拟可能会假设稳定发生的速度比实际发生的速度要快，因为 GCD 过程可以缓慢传播。 

## 方法

 最直接的方法是逐步模拟阵列。 对于每一步，我们计算每个元素与其邻居的 GCD 并更新数组。 这是正确的，但可能非常慢。 在最坏的情况下，它需要与数组中的最大元素一样多的步骤，并且每一步都是$O(n)$。 如果$n$是$2 \cdot 10^5$，这样可以达到$10^{10}$运营。 

关键的观察结果是该过程在 GCD 下是单调的。 数组只能减少或保持不变，唯一可能的稳定值是整个数组的 GCD 的约数。 如果我们计算整个数组的 GCD，最终的稳定值必须等于这个 GCD。 这意味着我们不需要模拟所有中间值； 我们只需要计算出每个元素与最终 GCD 的传播距离有多远。 

由于操作是局部的（每个元素取决于其自身及其邻居），因此我们可以将数组视为“好”和“坏”元素的循环字符串，其中“好”元素等于最终的 GCD。 最大步数等于“坏”元素的最长连续段的长度。 这是因为每次迭代 GCD 值都会沿着数组传播一步。 这种见解将问题简化为计算圆形数组中的连续段。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n * 最大(a_i)) | O(n) | 对于大 n 来说太慢 |
 | 通过 GCD 进行分段传播 | O(n) | O(n) | 高效、被接受|

 ## 算法演练

 1. 计算整个数组的 GCD。 让这成为`target`。 这是阵列将稳定到的值。 
2. 将数组转换为二进制数组，其中每个元素是`0`如果它等于`target`（已经很好了）或者`1`否则（需要 GCD 传播）。 
3. 要处理数组的循环性质，请将此二进制数组与其自身连接起来。 这使我们能够考虑环绕末尾的片段。 
4. 求最长连续线段的长度`1`s。 每一步都会将任何连续段的长度从两端减少 1。 因此，如果从两端模拟，所需的步数上限为该线段长度的一半，但更简单地说，因为该过程是循环的，并且每一步都是从最近的好元素开始传播，所以步数等于该线段的长度。 
5. 返回连续“坏”段的最大长度。 如果数组已经全部正常，则最大长度为零，并且我们正确地输出零。 

### 为什么它有效

 每次迭代都会将每个“坏”元素与最近的“好”元素的距离减少一。 由于 GCD 仅沿邻居传播，因此稳定最慢的元素是距任何“好”元素最远的元素。 通过跟踪圆形阵列中“坏”元素的最大连续段，我们捕获了最坏情况的传播距离。 这保证了正确的步数。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        g = a[0]
        for x in a[1:]:
            g = math.gcd(g, x)
        
        if all(x == g for x in a):
            print(0)
            continue
        
        # mark bad elements (1 if != g)
        bad = [1 if x != g else 0 for x in a]
        # handle circularity
        bad = bad + bad
        max_len = cur = 0
        for v in bad:
            if v == 1:
                cur += 1
                max_len = max(max_len, cur)
            else:
                cur = 0
        print(max_len)

solve()
```该代码首先计算数组的 GCD。 如果所有元素都匹配此 GCD，则打印零。 然后它构造一个二进制数组，将非 GCD 元素标记为 1。将该数组与其自身连接起来可处理圆段。 最后，我们扫描找到最长的连续 1 段，它代表所需的最大步数。
