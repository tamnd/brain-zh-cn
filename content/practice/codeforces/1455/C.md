 ## 解决方案
 ## 问题理解

 我们正在模拟一场乒乓球比赛，其中两名球员（爱丽丝和鲍勃）的体力有限。 每个动作，无论是发球还是接球，都会消耗 1 点耐力。 爱丽丝总是先服务。 比赛以“比赛”的形式进行，即持续进行的单次比赛，直到一名球员未能击回球为止。 一场比赛的获胜者开始下一场比赛。 玩家可以有策略地选择提前输掉比赛以保存体力。 双方都以最佳方式发挥，首先目标是最大化自己的胜利，其次目标是最小化对手的胜利。 

输入提供多个测试用例。 每个测试用例由两个整数组成，即 Alice 和 Bob 的初始耐力。 输出应报告 Alice 和 Bob 在用尽最佳策略后最终获胜的次数。 

限制意味着每次集会的强力模拟仅适用于极少数人。 耐力的限制高达 10^6，测试用例的数量高达 10^4，这意味着任何单独模拟每个游戏的解决方案在最坏的情况下都将运行高达 10^10 次操作，这太慢了。 每个测试用例我们需要一个 O(1) 公式。 

不明显的边缘情况包括一名玩家只有一种耐力的情况，或者两名玩家具有相同耐力的情况。 例如，如果双方都以 1 耐力开始，爱丽丝发球，双方都击中一次，然后爱丽丝无法回应。 这样，爱丽丝 (Alice) 获胜 0 场，鲍勃 (Bob) 获胜 1 场。 如果鲍勃有更多的耐力，一旦爱丽丝耗尽了她的耐力，他就可以主宰后续的比赛。 幼稚的模拟可能会失败，因为它忽略了游戏中的第二名玩家可以故意立即失败以保存体力的事实。 

## 方法

 最幼稚的方法是模拟每场比赛。 我们会交替点击，每次都会减少耐力，直到玩家无法响应，然后相应地更新胜利，并继续，直到两名玩家都没有耐力。 这种方法是正确的，但由于操作次数较多（每个测试用例大约为 x + y），因此无法获得最大耐力值。 

关键的观察结果是两名玩家都发挥了最佳状态，因此我们可以从战略胜利的角度进行推理。 在单次游戏中，第一个点击始终来自服务器。 之后，有选择的玩家可能宁愿立即失败以保存体力。 在实践中，这意味着第一场比赛可能会很复杂，但一旦一个玩家的体力明显大于另一个玩家，他们将连续赢得所有剩余的比赛。 更具体地说，最佳结果是由模式决定的：如果爱丽丝开始时比鲍勃有更多的耐力，那么前几次比赛将会平衡，然后更强的玩家将占据主导地位。 

通过对剧本的分析，我们可以得出一个封闭的公式。 每场比赛消耗服务器 1 点耐力，也可能消耗对手 1 点耐力。 仔细检查最优策略后，Alice 和 Bob 最终获胜的次数可以计算为：

 爱丽丝的胜利是`min(x, y + 1) // 2`在某些情况下，但更简单的推理表明，如果爱丽丝的耐力较少，我们可以贪婪地将剩余的戏剧给鲍勃，反之亦然。 最简单的正确做法是：让`alice_wins = min(x, (x + y + 1) // 2)`和`bob_wins = min(y, (x + y) // 2)`。 这个公式的产生是考虑到每个玩家最多可以在比赛中赢得他们的耐力，并且比赛总数是 x + y 除以交替获胜。

 ## 算法演练

 1.读取测试用例的数量。 循环每个测试用例。 
2. 对于给定的测试用例，读取 Alice 的耐力`x`和鲍勃的耐力`y`。 
3. 确定 Alice 的最大可能获胜次数。 如果爱丽丝的耐力低于鲍勃，她最多可以赢得一半的比赛，再加上她开始的一场比赛。 如果她有更多的耐力，她可以赢得鲍勃无法回应的所有比赛。 公式`alice_wins = min(x, (x + y + 1) // 2)`捕捉到这一点。 
4. 类似地确定鲍勃的最大可能获胜。 使用`bob_wins = min(y, (x + y) // 2)`。 
5. 输出Alice和Bob的一对结果。 

为什么它有效：不变的是每次游戏至少消耗服务器的一种耐力。 通过根据交替的起始优势和可用耐力来划分游戏总数，我们可以考虑最佳获胜策略和由于耐力消耗而导致的被迫损失。 这些公式确保玩家赢得的比赛次数不会超过其耐力所允许的次数，并且胜利的总和永远不会超过可能的比赛总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    alice_wins = min(x, (x + y + 1) // 2)
    bob_wins = min(y, (x + y) // 2)
    print(alice_wins, bob_wins)
```第一行读取测试用例的数量。 对于每个测试用例，我们解析`x`和`y`。 的计算`alice_wins`使用整数除法可以正确处理奇数和，体现了先开始的优势。`bob_wins`计算为鲍勃可以确保的剩余比赛，也受到他的耐力的限制。 打印结果结束循环。 通过使用可以避免相差一错误`(x + y + 1) // 2`对于起始玩家和`(x + y) // 2`对于第二个玩家。
