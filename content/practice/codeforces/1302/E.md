 ## 解决方案
 ## 问题理解

 我们给定一个长度为的二进制字符串$n$，但每个位置不是固定的，而是作为随机位独立生成：它变成$1$有概率$p = \frac{a}{b}$和$0$有概率$1 - p$。 

生成字符串后，我们可以对其多次应用特定操作。 每个操作都是这样工作的：我们选择一个索引作为“中心”，然后选择至少一个其他索引，使得所有选定的“其他”索引都具有与中心相反的位。 然后我们同时翻转所有选定的位。 

如果从一个位集开始，存在一系列这些操作，最终将每个位至少翻转一次（相当于，我们可以通过允许的操作完全“激活”所有索引），则该位集被称为有效。 

任务是计算随机生成的位集有效的概率，并将其输出为模下的模分数$1{,}234{,}567{,}891$。 

限制条件非常大：$n$可以达到$10^9$，因此任何尝试枚举配置、模拟操作或根据索引子集使用组合的解决方案都是不可能的。 唯一可行的方向是封闭式表达$n$, computed using fast exponentiation.

 这个问题的一个微妙之处在于，随机性遍及所有位集，但有效性条件仅取决于位分布的全局结构，而不取决于局部模式。 这强烈表明我们统计的结构性案例数量很少。 

One edge case is when all bits are identical. 在这种情况下，甚至无法启动任何操作，因为没有相反值的索引与所选中心配对。 例如，对于$n = 3$, 字符串`000`和`111`立即被卡住。 

一个天真的错误是假设任何非常量字符串都是有效的。 对于小例子来说，这似乎是合理的，因为同时拥有 0 和 1 总是会给你至少一种可能的操作。 然而，如果存在隐藏的连接约束，这种直觉就会失败，但在这个问题中，操作足够灵活，任何混合配置都可以逐步扩展。 

## 方法

 蛮力的想法是生成所有$2^n$位集并模拟每一个是否“令人惊叹”。 即使忽略状态的指数数量，每个模拟都涉及一系列操作，其长度不受任何有用的方式限制，因此即使对于微小的情况，这种方法也是完全不可行的。$n$。 

关键的简化来自于注意到，一旦两个值都存在，该操作就非常强大。 如果一个位集至少包含一个`0`以及至少一个`1`，那么我们总是可以选择一个中心和一个相反的组，并使用重复操作在整个数组中传播翻转。 操作的确切顺序并不重要，因为只要两个值都存在于数组中的某个位置，我们就可以继续继续。 

阻止所有进展的唯一配置是位集统一的情况。 在这种情况下，没有有效的第一步，因此该过程从一开始就是不可能的。 

所以问题归结为计算：$$\mathbb{P}(\text{bitset is not all 0 and not all 1})$$那是：$$1 - \mathbb{P}(\text{all 0}) - \mathbb{P}(\text{all 1})$$由于位是独立的：$$\mathbb{P}(\text{all 1}) = \left(\frac{a}{b}\right)^n,\quad
\mathbb{P}(\text{all 0}) = \left(\frac{b-a}{b}\right)^n$$所以答案变成了一个涉及求幂的简单模块化表达式。

 ## 算法演练

 我们想要计算生成的位集不是单色的概率。 

1. 将概率转换为模算术形式。 我们代表$p = a \cdot b^{-1}$模数$M$，并且类似地$1-p = (b-a) \cdot b^{-1}$。 
2. 计算$b^n$模数$M$使用快速求幂。 这代表分母贡献。 
3. 计算$a^n \bmod M$，对应于全一情况的分子。 
4. 计算$(b-a)^n \bmod M$，对应于全零情况的分子。 
5. 结合两种不良情况：$$\text{bad} = a^n + (b-a)^n \pmod M$$6. 通过除以进行归一化$b^n$，这是使用模逆完成的：$$\text{bad} \cdot (b^n)^{-1}$$7. 减去 1 即可得到最终答案。 

### 为什么它有效

 关键的属性是执行操作序列的唯一障碍是两个位值的缺失。 如果 0 和 1 都存在，则每个操作都会保留这样一个事实：我们仍然可以选择一种类型的中心和至少一个相反的元素，因此进度永远不会停滞。 因此，无效配置集完全崩溃到两个极端的统一情况，并且概率变成简单的排除计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1234567891

def mod_pow(a, e):
    res = 1
    a %= MOD
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, a, b = map(int, input().split())

inv_b = pow(b, MOD - 2, MOD)

p_num = a % MOD
q_num = (b - a) % MOD

a_n = mod_pow(p_num, n)
b_n = mod_pow(b % MOD, n)
q_n = mod_pow(q_num, n)

inv_b_n = pow(b_n, MOD - 2, MOD)

bad = (a_n + q_n) % MOD
bad = bad * inv_b_n % MOD

ans = (1 - bad) % MOD
print(ans)
```该实现显式地将分子和分母处理分开。 关键的微妙之处在于我们从不直接计算$(a/b)^n$，因为模除法必须通过逆来处理。 另一个重要的细节是计算两者$a^n$和$(b-a)^n$在模数下独立，确保我们在归一化之前不会失去精度。

 ## 边缘情况

 最重要的边缘情况是位组完全一致。 例如，使用输入`n = 4, a = 0`，每个生成的字符串是`0000`。 该算法计算$a^n = 0$,$(b-a)^n = b^n$，因此坏概率变为 1，最终答案为 0，这与不可能进行任何操作的事实相匹配。 

另一个边缘情况是当$a = b$，意味着每一位始终为 1。计算变得对称：$(b-a)^n = 0$，并且有效性概率再次为 0。 

最后，当$n = 1$，每个字符串都是平凡均匀的，因此答案始终为 0。该公式清楚地处理了这个问题，因为两项在归一化后直接减少到 1，产生零结果。
