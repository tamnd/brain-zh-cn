 ## 解决方案
 ## 问题理解

 我们得到了几个重量，每个重量都是一个正整数，代表我们可以放置在天平左盘上的质量。 在右边的盘上，我们可以放置任何我们想要识别重量的产品。 假设天平是精确的，我们可以进行任意多次称重。 

关键思想是，使用一组固定的权重，不一定可以唯一地识别每个目标权重。 某些重量可能会产生不明确的平衡结果，其中不同的产品重量可能会导致相同的平衡结果序列。 任务是确定最大的整数值`p`这样每个产品的重量都来自`1`最多`p`可以使用这些重量和重复称重来唯一地识别。 

看待该问题的一种更具结构性的方法是，权重通过带符号的组合定义可表示值的系统。 每次权重都可以有效地进行比较，其行为就像从`{-1, 0, 1}`对于每个重量。 核心问题是，在不与整数的可表示性发生冲突的情况下，这种有符号表示可以扩展多远。 

约束条件`n ≤ 2 * 10^5`立即排除任何试图显式模拟所有可实现总和的方法，因为即使枚举子集也会呈指数增长。 即使对所有可达值进行动态规划也会失败，因为权重会上升到`10^9`，使得任何密集范围 DP 都不可行。 

当权重太稀疏或退化时，就会出现微妙的边缘情况。 例如，如果只有一个权重`[5]`，那么我们根本无法唯一地确定任何权重`1`到`4`，因为我们无法使用任何权重组合来清楚地表示它们。 本例中的正确答案是`0`，尽管天真的解释可能表明我们可以测量 5 的倍数。 

另一个极端情况是权重很大但增量很小，例如`[1, 3]`。 在这里我们可以区分权重`4`，但不一定超出，因为超出该点，表示在可实现的平衡结果方面开始重叠。 

## 方法

 强力解释将尝试模拟在多次称重中将每个重量分配给左盘、右盘或未使用的所有可能的方式，并检查哪些产品重量仍然是唯一可识别的。 这很快就会变得棘手，因为每个重量每次称重都有三种状态，甚至一次称重就已经产生了`3^n`配置。 在允许多次权衡的情况下，状态空间进一步扩大，即使对于中等程度的人来说也无法探索`n`。 

关键的见解是，除了给定权重的有符号组合之外，多重权重并不会从根本上增加表征能力。 每个权重都贡献一个固定的“分辨率范围”，系统的行为就像构建一个可以存储数字的数字基础`-1, 0, 1`。 限制因素是我们能否连续覆盖整数线而在可表示性上没有间隙。 

如果我们对权重进行排序，我们可以按升序处理它们并保持最大连续范围`[0, p]`可以被唯一地表示。 每个新的重量要么会扩大这个范围，要么会产生一个差距。 如果我们目前可以表示所有值`p`，然后是一个新的权重`x`只有当`x ≤ p + 1`。 否则，会出现间隙`p + 1`，使得无法唯一地表示该值，并且该过程停止。 

这将问题转化为对排序权重的贪婪扫描，同时保持可表示值的可达前缀。

 | 所有称重的暴力枚举 | 指数| 指数| 太慢了|

 ## 算法演练

 1. 按非降序对权重数组进行排序。 这使我们能够按照它们可以扩展可表示范围的顺序来处理它们。 
2. 初始化变量`p = 0`，表示当前可以唯一确定的最大权重值。 
3. 迭代每个权重`x`按排序顺序。 在每一步中，我们都会检查该权重是否可以扩展连续的可表示范围。 

推理是，如果我们已经可以唯一地确定直到`p`，那么下一个缺失值是`p + 1`。 新的权重必须能够“桥接”或覆盖下一个值以扩展系统。 
4. 如果`x > p + 1`，我们立即停下来。 这意味着存在一个间隙`p + 1`不能由先前权重或当前权重的任何组合来填充，因此超过这一点，唯一性就失效了。 
5. 否则，我们更新`p = p + x`。 此步骤反映了添加新权重将可实现的可区分总和的范围精确地扩展了`x`，因为所有先前可表示的值现在都可以移动并与该权重组合。 
6.处理完所有权重后，输出`p`。 

保持的不变量是，在迭代期间的任何点，中的每个整数`[0, p]`可以使用带有符号组合的处理后的权重来唯一地表示。 排序顺序确保当我们尝试延长此间隔时，不会丢失填补空白所需的较小的未处理权重。 如果出现间隙，它是永久性的，因为较大的权重无法产生较小的可表示增量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

a.sort()

p = 0
for x in a:
    if x > p + 1:
        break
    p += x

print(p)
```排序步骤至关重要，因为贪婪论证依赖于始终首先尝试扩展最小的缺失可表示值。 如果不进行排序，过早出现的大重量可能会错误地膨胀`p`并隐藏阻碍进一步进展的差距。 

条件`x > p + 1`是关键边界检查。 它检测当前权重何时太大而无法填充最小的无法达到的值，该值始终是`p + 1`。 任何替代检查的实现`p`或使用不同的不等式在差距恰好是一个单位的情况下会失败。

 ## 边缘情况

 当只有一个重量大于`1`，算法立即停止于`p = 0`因为`x > p + 1`。 用于输入`5`，扫描立即停止并输出`0`，符合没有更小的值可以被唯一隔离的事实。 

当所有权重都是相同的小值时，例如`1`，范围线性增长。 每一步都满足条件`1 ≤ p + 1`，因此区间确定性地扩展，产生的最终答案等于`n`。 

当有效前缀后出现间隙时，例如`1, 2, 10`，算法处理`1`和`2`达到`p = 3`，然后检测`10 > 4`并停止。 该迹线证实，最小的缺失可表示值决定了所有未来的可行性，并且较大的权重无法修复早期的差距。
