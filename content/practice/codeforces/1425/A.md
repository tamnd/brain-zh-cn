 ## 解决方案
 ## 问题理解

 问题是两人硬币游戏。 有一堆$N$金币。 玩家从查内克先生开始轮流进行。 在一个回合中，玩家可以拿走一枚硬币，或者如果这堆硬币包含偶数个硬币，则可以拿走该堆硬币的一半。 每个玩家都贪婪地行动，以在游戏结束时最大化他们收集的硬币总数。 任务是计算如果两个玩家都发挥最佳状态，查内克先生可以获得的最大硬币数量。 

输入包括$T$测试用例，每个用例指定一个整数$N$，初始硬币数量。 每个测试用例的输出是 Chanek 先生可以收集的最佳硬币数量。 限制条件允许$T$最多$10^5$和$N$最多$10^{18}$。 这消除了任何递归或迭代模拟每个动作的方法$N$，因为简单的模拟可能需要多达$10^{18}$每个测试用例的操作。 

非明显的边缘情况包括小$N$， 特别$N = 1$或者$N = 2$。 如果$N = 1$，查内克先生只是拿走了唯一的一枚硬币。 为了$N = 2$，立即拿走一半会产生一枚硬币，但首先​​拿走一枚硬币会迫使对手做出特定选择，这表明最佳策略取决于$N$不仅仅是它的大小。 

## 方法

 蛮力方法是依次模拟游戏。 在每一回合中，我们都会考虑两种选择：拿一枚硬币，或者如果硬币数量是偶数，则拿一半。 假设对手做出最佳反应，我们将递归计算 Chanek 先生的最大硬币数。 虽然这适用于小型$N$，每个递归调用分支为两种可能性，产生指数时间复杂度。 为了$N$靠近$10^{18}$，这变得完全不可行。 

简化问题的关键是要注意每个玩家最大化自己的硬币时的最佳游戏模式。 如果硬币数量是偶数，那么拿一半绝对比拿一枚好，因为这比拿一枚硬币多，留给对手的硬币更少。 如果数字是奇数，唯一的选择就是拿一枚硬币。 “偶数时一半”和“奇数时一个”之间的这种交替创建了一个可预测的递归序列。 我们可以直接使用函数计算 Chanek 先生的最大硬币数$f(n)$交替转弯并应用最佳移动，而无需模拟每个转弯。 

最终的解决方案使用整数运算有效地利用了这种递归模式，这允许相对于$N$，而不是线性或指数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(2^N) | O(2^N) | O(N) 递归 | 太慢了|
 | 最优递归模式 | O(log N) | O(1) 迭代 / O(log N) 递归 | 已接受 |

 ## 算法演练

 1. 定义一个函数$f(n, turn)$代表 Chanek 先生可以收集的最大硬币，如果$n$硬币还剩下，如果$turn = 0$，否则轮到对手了。 
2.如果$n = 0$，返回 0，因为没有剩余硬币。 
3.如果$turn = 0$（轮到查内克先生），选择最大化他的硬币的举动。 如果$n$是偶数，取一半比取一更好，因为$\frac{n}{2} > 1$。 如果$n$奇数，拿一枚硬币。 递归调用$f$剩余的硬币和对手的回合。 
4. 如果$turn = 1$（轮到对手），假设他们也采取最佳行动来最大化他们的硬币，这最小化了查内克先生的未来收益。 如果$n$平局，对方各占一半； 如果奇怪，他们就拿一个。 递归调用$f$给查内克先生和剩下的硬币。 
5. 使用循环将递归模式转换为迭代方法：重复模拟减半或减法，直到堆为零，交替谁“控制”每一步的增益。 
6. 只计算 Chanek 先生轮到的硬币的总和。 

为什么它有效：不变的是，在序列中的每个偶数步骤（查内克先生的回合），我们仅根据最佳移动添加硬币，而在每个奇数步骤，对手将查内克先生的收益最小化。 通过在 Chanek 先生的回合中尽可能选择一半并模拟对手获取允许的最大值，我们保证总和是最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_coins(n):
    chanek = 0
    turn = 0  # 0 for Chanek, 1 for opponent
    while n > 0:
        if turn == 0:
            if n % 2 == 0:
                take = n // 2
            else:
                take = 1
            chanek += take
        else:
            if n % 2 == 0:
                take = n // 2
            else:
                take = 1
        n -= take
        turn ^= 1
    return chanek

T = int(input())
for _ in range(T):
    N = int(input())
    print(max_coins(N))
```功能`max_coins`交替遍历该堆。 查内克先生要么拿走偶数堆的一半，要么拿走奇数堆的一半，而对手则模拟最佳玩法，以最大限度地减少查内克的收益。 使用整数除法可确保大的正确性$N$没有溢出。

 ## 边缘情况

 对于`N = 1`，查内克干脆拿走了唯一的硬币。 该算法计算`take = 1`，添加到 Chanek 的总数，减少`n`到 0，并终止，给出输出 1。对于`N = 2`，Chanek 在他的回合中拿走 1（因为这比让对手拿走一半更好），对手拿走剩余的 1，Chanek 以 1 结束。该算法正确地处理了这个问题，因为它应用了奇偶规则，并在每次硬币减少时交替轮流一次，尊重最佳移动。 对于非常大的 N，例如$10^{18}$，循环执行大约 60 次迭代 (log2(10^18))，Python 中的整数算术可以正确处理大数。
