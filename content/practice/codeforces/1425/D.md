 ## 解决方案
 ## 问题理解

 该问题给出了二维网格上的一组点，每个点代表一条蛇，其权重称为危险级别。 我们选择恰好 M 条不同的蛇作为攻击目标。 每个选定的目标定义了一个以该蛇为中心的方形影响区域，切比雪夫距离 R 内的所有其他蛇也会被杀死。 策略的最终结果是至少一个选定目标杀死的所有蛇的集合，该策略的得分是所有被杀死的蛇的危险值总和的平方。 

关键的难点在于，M个目标的不同选择会产生重叠的杀伤区域，而得分取决于这些区域的联合，而不是独立于单个目标。 任务是计算挑选 M 条不同目标蛇的所有可能方法的分数总和。 

约束 N ≤ 2000 和 M ≤ N 意味着直接枚举大小为 M 的所有子集是不可能的，因为在最坏的情况下，单独的子集大约为 2×10^600。 即使是列举成对或三对蛇之间的相互作用也必须小心控制。 这促使我们采用一种公式，即我们汇总贡献而不是枚举组合。 

当 R = 0 时，会出现微妙的边缘情况。在这种情况下，每条选定的蛇只会杀死自己，因此重叠完全消失。 预先计算邻域并假设非重叠影响的简单方法仍然有效，但任何假设空间扩展的逻辑都必须正确退化为单小区覆盖。 

另一个重要的边缘情况是当所有蛇都密集地聚集在彼此距离 R 内时。 然后，任何选定的蛇都会杀死几乎所有其他蛇，并且只要 M ≥ 1，联合就变得独立于选择哪个子集。尝试将网格分解为独立区域的算法在这里将失败，因为依赖关系变成全局的。 

## 方法

 蛮力策略很简单：枚举 M 条蛇的所有子集，计算它们的 R 邻域的并集，对并集内的危险值求和，求平方，然后累加结果。 对于每个子集，通过扫描所有 N 条蛇来计算并集的成本为 O(N)，并且存在 C(N, M) 个子集，这使得总复杂度呈指数级增长，即使对于小 N 也是完全不可行的。 

关键的观察结果是，得分仅取决于每条蛇是否被至少一个选定的中心覆盖。 这使我们能够扭转观点：我们考虑对每条蛇的影响，而不是迭代选定的中心。 如果每条蛇位于至少一个选定中心的距离 R 内，则它会将其重量贡献给总重量。 

这将问题转化为计算所有 M 个中心子集上每个子集并集的总贡献的平方。 扩大正方形会引入蛇之间的成对相互作用，这可以通过计算有多少子集使两条蛇都被覆盖来处理。 

对于任意两条蛇 i 和 j，两者都被杀死的条件取决于是否至少有一个选定的中心位于 i 的距离 R 内，对于 j 也是如此。 这自然会导致为每条蛇定义其可能中心的邻域集。 那么事件“蛇 i 被杀死”对应于从其邻域中选择至少一个元素。 对于对，我们需要与两个邻域相交的子集。 

这将问题转化为集合交叉点上的计数问题，可以通过相对于邻域的重叠结构对中心进行分类来处理。 由于 N 很小，我们可以预先计算邻接：对于每个 i，其中 j 位于 i 的距离 R 内。 然后我们可以使用包含-排除和组合预计算导出与给定集合相交的子集的计数。

最终的计算简化为在仔细定义的独立选择区域上使用二项式系数对各个蛇的贡献和成对重叠进行求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C(N, M) · N) | O(C(N, M) · N) | O(N) | 太慢了|
 | 最佳| O(N² + N³ log N) 或更好的组合 | O(N²) | 已接受 |

 ## 算法演练

 我们首先将每条蛇的邻域定义为切比雪夫距离 R 内的所有蛇，包括它自己。 这是通过直接比较坐标在 O(N²) 中计算得出的。 

接下来，我们介绍该过程的二进制解释。 选定的一组 M 中心会产生覆盖所有蛇的覆盖指示器。 总分是被覆盖的蛇的权重总和的平方，因此我们将其扩展为单条蛇和有序蛇对的总和。 

这给出了两个组成部分：来自被覆盖的单个蛇的贡献，以及来自被覆盖的成对蛇的贡献。 

我们分别计算两者。 

对于蛇 i 的个体贡献，我们计算有多少个中心子集与其邻域相交。 该补充选择完全在其邻近区域之外的 M 中心。 因此，有效子集的数量为 C(N, M) 减去 C(N - |N(i)|, M)，其中 N(i) 是邻域大小。 

在考虑了平方结构之后，每个这样的子集在展开中贡献 B_i 平方。 

然后我们处理配对贡献。 对于蛇 i 和 j，我们需要与邻域 N(i) 和 N(j) 相交的子集。 使用包含-排除，我们计算所有子集减去那些缺失的 N(i)，减去那些缺失的 N(j)，加上那些同时缺失的子集。 这些项中的每一项都在邻域并集的补集上简化为二项式系数。 

最后，我们将 B_i * B_j 乘以覆盖 i 和 j 的子集数量求和。 

我们预先计算阶乘和逆阶乘以快速评估组合。 

## 为什么它有效

 平方的展开将几何并集问题转换为覆盖指标的代数问题。 每个子集独立地影响给定蛇是否被覆盖，并且覆盖事件仅取决于子集是否与固定邻域集相交。 这从决策过程中删除了空间几何，并用组合交集计数代替，组合交集计数在包含排除下稳定并且可以准确评估。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

N, M, R = map(int, input().split())
snakes = [tuple(map(int, input().split())) for _ in range(N)]

# precompute factorials
fact = [1] * (N + 1)
invfact = [1] * (N + 1)

for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[N] = pow(fact[N], MOD - 2, MOD)
for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, k):
    if n < 0 or k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def inside(i, j):
    return max(abs(snakes[i][0] - snakes[j][0]),
               abs(snakes[i][1] - snakes[j][1])) <= R

# neighborhood sizes
sz = [0] * N
for i in range(N):
    for j in range(N):
        if inside(i, j):
            sz[i] += 1

# precompute union sizes for pairs
union_sz = [[0] * N for _ in range(N)]

for i in range(N):
    for j in range(N):
        if i == j:
            union_sz[i][j] = sz[i]
        else:
            cnt = 0
            for k in range(N):
                if inside(i, k) or inside(j, k):
                    cnt += 1
            union_sz[i][j] = cnt

total = C(N, M)

# contribution from singles and pairs via expansion
ans = 0

# precompute coverage counts
cover_i = [0] * N
for i in range(N):
    cover_i[i] = (total - C(N - sz[i], M)) % MOD

# pair inclusion-exclusion
for i in range(N):
    for j in range(N):
        if i == j:
            continue
        both = (total
                - C(N - sz[i], M)
                - C(N - sz[j], M)
                + C(N - union_sz[i][j], M)) % MOD
        ans = (ans + both * snakes[i][2] % MOD * snakes[j][2]) % MOD

# diagonal terms
for i in range(N):
    ans = (ans + cover_i[i] * snakes[i][2] % MOD * snakes[i][2]) % MOD

print(ans % MOD)
```阶乘预处理可以实现二项式系数的恒定时间计算，这是至关重要的，因为我们重复查询每对蛇的组合。 

邻域计算直接使用切比雪夫距离，精确匹配方形爆炸区域。 

配对处理对邻域使用包含-排除，确保重叠的杀伤区域不会被重复计算。 

一个常见的陷阱是忘记平方展开式在代数展开式中包含有序对，这就是为什么在组合结果之前分别处理 i 和 j 的原因。

 ## 边缘情况

 当 R = 0 时，每个邻域仅包含蛇本身。 该算法正确归约，因为 sz[i] = 1 并且联合大小很小，因此包含-排除崩溃为简单的二项式计数。 

当所有蛇彼此之间的距离 R 以内时，每个邻域都等于整个集合。 在这种情况下，所有对的 sz[i] = N 且 union_sz[i][j] = N。 补集的二项式项变为零，这意味着大小 M 的每个子集都覆盖了所有蛇，因此每种策略都会产生相同的分数。 成对公式彻底退化为计算所有有序对，这与扩展的正方形结构相匹配。
