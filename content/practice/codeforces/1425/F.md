 ## 解决方案
 ## 问题理解

 我们有一个未知的数组$A_1, A_2, \dots, A_N$， 在哪里$A_i$是笼子里火烈鸟的数量$i$。 

唯一可用的操作是要求连续段的总和。 表单的查询$(L,R)$回报$$A_L + A_{L+1} + \cdots + A_R$$的限制是$L < R$。 

我们最多被允许$N$查询并且必须准确地重建数组的每个元素。 

尽管最初的任务是交互式的，但一旦我们理解了策略，实施就很简单了。 挑战是设计一组最多$N$唯一确定所有值的范围总和查询。 

约束足够小，存储整个数组是微不足道的。 真正的限制是查询预算。 由于仅$N$允许提问，任何需要的策略$O(N^2)$甚至$2N$查询是不可能的。 

关键的观察是该数组包含$N$未知值，所以我们需要粗略地$N$独立方程。 问题变成了一个由极差和构建的小型线性方程组。 

一个常见的错误是尝试使用相邻的和来一一恢复元素。 例如，查询$$(1,2), (2,3), (3,4), \dots$$只给出$N-1$方程。 这还不足以唯一地确定$N$未知数。 

考虑$N=3$。 

假设我们知道$$A_1+A_2=5$$和$$A_2+A_3=7.$$两个数组$[0,5,2]$和$[1,4,3]$满足这些方程。 该解决方案并不唯一。 

另一个微妙的情况是某些值为零。 

例如，$$[0,0,5].$$重建方法不得依赖于正值或除法。 我们需要涉及加法和减法的纯代数恒等式。 

## 方法

 一个蛮力的想法是查询每一对或许多重叠范围，直到有足够的信息可用。 这当然有效，因为范围总和决定了数组，但它很快就超出了查询限制。 询问所有相邻的金额已经成本$N-1$查询仍然无法唯一确定数组。 为每个位置询问额外的范围需要$O(N)$额外的查询，超出预算。 

问题的结构建议将每个查询答案视为线性方程。 

前三个要素很特殊。 如果我们知道$$S_{12}=A_1+A_2,$$

$$S_{13}=A_1+A_2+A_3,$$

$$S_{23}=A_2+A_3,$$那么我们有三个带有三个未知数的方程。 

将第一个和第三个方程相加得出$$S_{12}+S_{23}=A_1+2A_2+A_3.$$减法$S_{13}$正好离开$A_2$:$$A_2=S_{12}+S_{23}-S_{13}.$$一次$A_2$已知，$$A_1=S_{12}-A_2,$$和$$A_3=S_{23}-A_2.$$因此，只有三个精心选择的查询才能完全确定前三个笼子。 

之后，恢复剩余的值就变得很容易。 询问$$(1,i)$$对于每一个$i \ge 4$。 

令返回的总和为$$P_i=A_1+A_2+\cdots+A_i.$$因为我们已经知道前缀和$i-1$,$$A_i=P_i-P_{i-1}.$$我们对前三个元素使用三个查询，对其余每个元素使用一个查询：$$3+(N-3)=N.$$这完全符合允许的预算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N²) 次查询或更多 | O(N) | 不可能|
 | 最佳| O(N) 查询 | O(N) | 已接受 |

 ## 算法演练

 1.查询范围的总和$(1,2)$,$(1,3)$， 和$(2,3)$。 拨打电话寻找答案$s_{12}$,$s_{13}$， 和$s_{23}$。 
2. 使用恢复第二个值$$A_2=s_{12}+s_{23}-s_{13}.$$这有效是因为$A_1$和$A_3$取消。 

1. 恢复$$A_1=s_{12}-A_2$$和$$A_3=s_{23}-A_2.$$现在前三个元素已经被准确地知道了。 

1. 计算$$pref=A_1+A_2+A_3.$$这等于到位置三的前缀和。 

1. 对于每个位置$i$从$4$到$N$,查询范围$(1,i)$。 
2. 设答案为$cur$。 自从$cur$等于前缀和$i$,$$A_i=cur-pref.$$1. 更新$$pref=cur.$$现在前缀和通过$i$已知并可用于下一个位置。 

1. 重建所有值后，输出整个数组。 

### 为什么它有效

 前三个查询形成一个完整的线性系统$A_1$,$A_2$， 和$A_3$。 导出的公式可以唯一地恢复这些值。 

对于以后的每一个位置$i$，查询$(1,i)$通过返回前缀和$i$。 该算法保持不变式`pref`等于前缀和$i-1$。 减去这两个连续的前缀和正好得到$A_i$。 由于在重建前三个元素后不变式最初为真，因此它对于每一步都保持为真。 每个数组元素只恢复一次，因此最终答案是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ask(l, r):
    print("?", l, r, flush=True)
    return int(input())

def main():
    n = int(input())

    s12 = ask(1, 2)
    s13 = ask(1, 3)
    s23 = ask(2, 3)

    a = [0] * n

    a[1] = s12 + s23 - s13
    a[0] = s12 - a[1]
    a[2] = s23 - a[1]

    pref = a[0] + a[1] + a[2]

    for i in range(4, n + 1):
        cur = ask(1, i)
        a[i - 1] = cur - pref
        pref = cur

    print("!", *a, flush=True)

if __name__ == "__main__":
    main()
```代码的第一部分获取求解前三个值所需的三个方程。 公式为`a[1]`直接来自消除$A_1$和$A_3$。 

在那之后，`pref`存储已经重建的前缀和。 每个查询`(1, i)`返回更大的前缀和。 连续前缀和之间的差值正是新元素。 

索引值得关注。 数组使用从零开始的索引存储，而查询则使用从一开始的索引。 位置`i`问题中对应的是`a[i - 1]`在代码中。 

另一个细节是冲水。 交互式法官在查询发送之前不会对其进行处理。 使用`flush=True`保证查询立即到达法官。

def reconstruct(arr):
    n = len(arr)

    s12 = arr[0] + arr[1]
    s13 = arr[0] + arr[1] + arr[2]
    s23 = arr[1] + arr[2]

    ans = [0] * n

    ans[1] = s12 + s23 - s13
    ans[0] = s12 - ans[1]
    ans[2] = s23 - ans[1]

        cur = sum(arr[:i + 1])

    return ans

 ## 边缘情况

 ### 最小尺寸数组

 采取$$[2,5,7].$$三个初始查询已经确定了所有值：$$s_{12}=7,\quad s_{13}=14,\quad s_{23}=12.$$然后$$A_2=7+12-14=5,$$

$$A_1=7-5=2,$$

$$A_3=12-5=7.$$不需要额外的查询。 

### 包含零的数组

 采取$$[0,0,5,0].$$前三个方程变为$$s_{12}=0,\quad s_{13}=5,\quad s_{23}=5.$$恢复给出$$A_2=0,\quad A_1=0,\quad A_3=5.$$查询$(1,4)$回报$5$。 由于当前的前缀和已经是$5$,$$A_4=5-5=0.$$该方法从不假设积极性。 

### 大的相等值

 采取$$[1000,1000,1000,1000].$$第一个查询返回$$2000,\ 3000,\ 2000.$$恢复给出$$A_2=1000,\quad A_1=1000,\quad A_3=1000.$$前缀查询$(1,4)$回报$4000$，产生$$A_4=4000-3000=1000.$$仅使用加法和减法，因此不存在数字问题。
