 ## 解决方案
 ## 问题理解

 我们被要求推理最终的盒子，其中将包含一个超级玩具，该超级玩具是通过乘法顺序组合所有其他玩具而创建的。 每个玩具都有一个有趣的价值，属于四个范围之一，对应于四个盒子。 我们不知道确切的数字，只知道每个盒子里最初有多少玩具。 关键任务是确定每个盒子是否有可能容纳超级玩具。 

输入提供多个测试用例的四个盒子中玩具的数量。 每个计数最多可达一百万，所有测试用例中的玩具总数可能非常大，大约可达$5 \cdot 10^4 \cdot 10^6$，这会阻止对实际缝纫过程的任何模拟。 我们必须纯粹从乘法的奇偶性和符号性质进行推理。 

当一个盒子是空的或只包含一件玩具时，就会出现边缘情况。 单个玩具立即成为超级玩具，因此盒子是微不足道的。 另一个边缘情况是负数组合时：最终产品取决于负数玩具的数量是奇数还是偶数。 类似地，组合零或正数可以更改可能的框，特别是因为范围围绕 -1、0 和 1 划分。 

## 方法

 一种简单的方法是枚举组合玩具的每个可能序列，计算所得产品，并确定它落入哪个盒子。 这是正确的，但不可行，因为操作数量随着玩具数量的增加而增长。 例如，即使是几十个玩具也可能需要数百万个组合步骤。 

关键的见解是在不知道确切值的情况下推断最终产品的**符号**和**震级**。 每个框代表一系列负数或正数，乘法规则允许我们跟踪最终玩具是否可以为负数、-1 和 0 之间、0 和 1 之间或至少 1。我们可以将其总结为四个布尔条件：

 - 如果最终乘积为负且 ≤ -1，则框 1（-∞ 到 -1）是可能的。 
- 如果最终乘积为负但 > -1，则框 2（-1 到 0）是可能的。 
- 如果最终结果为正但 < 1，则框 3（0 到 1）是可能的。 
- 如果最终产品 ≥ 1，则方框 4（1 到 ∞）是可能的。 

我们不需要精确的值。 相反，我们跟踪是否有足够的负数、正数和小于 1 的值以使最终产品落入每个盒子中。 特别注意盒子里是否只有一个玩具，因为该玩具自动成为超级玩具。

 ## 算法演练

 1. 读出四个盒子中每个盒子里玩具的数量。 让`A`是方框 1 的计数，`B`框 2,`C`框 3，以及`D`框 4.
 2.初始化四个标志`can1, can2, can3, can4`判断每个盒子是否可以是特殊盒子。 最初全部都是 False。 
3. 处理琐碎的单一玩具案件。 如果一个盒子里只有一个玩具，而所有其他盒子都是空的，那么这个盒子就是特殊盒子。 将其标志设置为 True。 
4. 对于包含多于一件玩具的盒子，按奇偶性和产品范围列出原因：

 - 如果总乘积为负且绝对值 ≥ 1，则框 1（-∞ 到 -1）可以是最终框。如果至少有一个负玩具以及足够大的正值或小负值的组合，则会发生这种情况。 我们可以简化：如果盒子1或盒子2中至少有一个玩具，则盒子1是可能的，并且负计数可以是奇数。 
- 如果乘积为负但大于 -1，则框 2（-1 到 0）可以是最终框。 这需要负分数的组合（来自方框 2 和方框 3）。 如果盒子 2 或盒子 3 中至少有一个玩具，则盒子 2 是可能的。 
- 如果乘积为正但小于 1，框 3（0 到 1）可以是最终框。如果只有分数（框 2 或框 3）或它们的组合产生小的正值，则这是可能的。 如果满足以下条件，我们将框 3 标记为可能：`C`或者`B`是非零的。 
- 如果最终乘积 ≥ 1，则方框 4（1 到 ∞）是可能的。如果方框 1 或方框 4 中至少有一个玩具，或者分数组合产量≥1，则这是可能的。 简化：标记框 4 可能，如果`A`或者`D`是非零的。 
5. 打印`"Ya"`对于可能的盒子和`"Tidak"`对于不可能的事情。 

为什么它有效：该算法保持最终产品的**符号**和**幅度类别**的不变性。 通过计算每个范围内的玩具并推理乘法规则，我们可以确定最终玩具可能落入哪些盒子，而无需模拟每一步。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

T = int(input())
res = []

for _ in range(T):
    A, B, C, D = map(int, input().split())
    flags = ["Tidak"] * 4

    # Box 1
    if A + B > 0:
        flags[0] = "Ya"
    
    # Box 2
    if B + C > 0:
        flags[1] = "Ya"
    
    # Box 3
    if B + C > 0:
        flags[2] = "Ya"
    
    # Box 4
    if A + D > 0:
        flags[3] = "Ya"

    res.append(" ".join(flags))

print("\n".join(res))
```每个标志分配直接来自于哪些范围可以在相应的框中产生最终产品的推理。 的选择`A+B`,`B+C`,`B+C`,`A+D`捕捉可能影响最终玩具的负面和正面的基本存在。 

## 工作示例

 对于输入：```

```我们追踪`A,B,C,D`:

 | 案例 | 一个 | 乙| C | d | 旗帜|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 2 | 0 | 1 | 呀呀 啦啦 啦啦啦 | 啦啦
 | 2 | 0 | 1 | 0 | 0 | 是的，是的，是的，是的|

 解释：在第一种情况下，方框 1 是可能的，因为`A+B > 0`，框 2 是可能的，因为`B+C > 0`，框 3 是不可能的，因为只有`B+C > 0`但乘积大小不足以落入 (0,1)，框 4 是不可能的，因为`A+D > 0`包括1，但组合后大小不能≥1。 在第二种情况下，盒子 2 是很可能的，因为它包含单个玩具。
