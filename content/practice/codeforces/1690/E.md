 ## 解决方案
 ## 问题理解

 我们有偶数件货物，每件都有重量，我们需要将它们包装成对。 一对的成本是通过将其权重之和除以固定数字来计算的$k$，并向下舍入到最接近的整数。 我们的目标是以最大化所有包的总成本的方式创建对。 每个测试用例都提供了货物的重量和价值$k$。 我们必须返回每个测试用例的最大总成本。 

这些限制条件使我们能够$2 \cdot 10^5$所有测试用例中的总商品。 这排除了尝试所有可能配对的任何方法，因为配对方式的数量$n$项目按阶乘增长。 具体来说，暴力配对大致是$O((n-1)!!)$，即使对于$n = 20$。 

当所有权重都可以被整除时，就会出现微妙的边缘情况$k$，或者当所有的都小于$k$。 例如，与$a = [2, 2, 2, 2]$和$k = 3$，天真的配对可能会意外地减少达到倍数的包数量$k$，产生次优的总成本。 另一个棘手的情况是有许多零或小于$k/2$; 粗心的搭配可能会浪费这些小物品，而这些小物品本可以与更大的重量搭配，以最大限度地提高地板分配收益。 

## 方法

 暴力方法将枚举所有配对并计算总和$\lfloor (a_i + a_j)/k \rfloor$。 虽然这保证了正确的答案，但配对的阶乘数对于$n = 2 \cdot 10^5$。 

关键的见解来自于考虑每个包模的贡献$k$。 每个项目$a_i$可以写成$a_i = q_i \cdot k + r_i$， 在哪里$q_i = a_i // k$是对总额的保证贡献，并且$r_i = a_i \% k$是可能与另一个余数结合形成另一个倍数的剩余部分$k$。 这将问题简化为以最大化附加倍数的数量的方式配对余数$k$。 

一旦我们对余数进行排序，我们就可以使用两指针策略。 将最小余数与最大余数配对。 如果他们的总和至少是$k$，我们形成一个新的附加套餐价值； 否则，将较小的余数向前移动。 这种贪婪策略确保我们最大化剩余部分的额外贡献，而不会将高剩余部分浪费在低剩余部分上。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 排序+两指针| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$k$，以及权重列表$a$。 
2. 通过整数除法计算每一项的保证贡献$q_i = a_i // k$并对它们求和以初始化总成本。 
3. 计算余数$r_i = a_i \% k$对于每个项目并将它们存储在列表中。 
4. 按升序对余数列表进行排序。 
5.初始化两个指针：$i = 0$一开始，$j = n-1$在最后。 
6. 虽然$i < j$:

 - 检查是否$r_i + r_j \ge k$。 如果为 true，则将总成本增加 1 并将两个指针向内移动 ($i += 1, j -= 1$），形成一个生成额外单元的包。 
- 如果总和小于$k$，将较小的余数指针向前移动（$i += 1$），因为将其与任何较大的余数配对只会产生更少或相等的额外价值。 
7. 循环结束后，输出总成本。 

为什么有效：每个项目都贡献其保证倍数$k$。 通过对最小和最大的余数进行排序和配对，我们最大化了超过的对的数量$k$，因为如果与另一个较小的余数配对，任何较小的余数都会被浪费。 该策略确保捕获剩余部分的每一个潜在的额外贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        total = sum(x // k for x in a)
        remainders = [x % k for x in a]
        remainders.sort()
        
        i, j = 0, n - 1
        while i < j:
            if remainders[i] + remainders[j] >= k:
                total += 1
                i += 1
                j -= 1
            else:
                i += 1
        print(total)

if __name__ == "__main__":
    solve()
```该代码首先使用整数除法计算保证贡献。 对余数进行排序使我们能够有效地配对极值。 两指针方法保证我们不会错过任何可以生成额外单位而无需重复计算的组合。 当总和太低时，向前移动较小的余数可以防止浪费配对尝试。
