 ## 解决方案

 ## 问题理解

 两只兔子从数轴上的不同整数位置开始，并以离散时间步长同时移动。 左边的兔子从位置开始`x`，右兔子从位置开始`y`， 和`x < y`。 每一秒，左边的兔子向右移动固定的距离`a`，而右边的兔子向左移动固定的量`b`。 

问题是是否存在非负整数时间`t`这样两只兔子在恰好之后占据相同的位置`t`移动，如果是这样，则最小的这样`t`。 

我们不跟踪连续运动，只跟踪每秒后的离散位置。 这意味着我们正在寻找从它们的运动导出的线性方程的整数解。 

约束允许最多 1000 个测试用例，位置和步长最大为 10^9。 这立即排除了随着时间的推移进行的任何模拟。 即使会议发生，也可能要经过数十亿步，并且逐秒模拟会太慢。 

当兔子从未相遇时，即使它们的距离在某个时刻变小，也会出现一个微妙的问题。 一个幼稚的实现可能会假设，如果一只兔子抓住或超过了另一只，则一定发生了会议，但事实并非如此，除非它们同时落在同一位置。 

当两只兔子以相同的速度移动时，会出现另一种失败情况。 如果`a == b`和`x != y`，距离永远不会改变，所以他们永远不会见面。 仅检查运动方向或相对速度的简单方法可能会错过这一点。 

## 方法

 暴力模拟将逐步推进两个位置，直到它们相遇或距离开始长时间增加。 时`t`，位置是：

 左边的兔子：`x + t * a`右边的兔子：`y - t * b`我们检查它们是否相等。 这是正确的，但在最好的情况下可能需要最多 O((y - x) / (a + b)) 个步骤，而在最坏的情况下可能需要无限的步骤，因为它们永远不会相遇。 当值达到 10^9 时，这是不可行的。 

关键的观察是我们正在求解整数线性方程。 我们想要：`x + t * a = y - t * b`重新排列给出：`y - x = t * (a + b)`因此，只有当初始距离能被组合速度整除时，才存在解。 如果它能被整除，商就给出了见面的确切时间。 否则，它们永远不会以整数时间步长对齐。 

这将问题从动态模拟减少到每个测试用例的单个算术检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| 最坏情况 | O((y - x)/(a + b)) O(1) | O(1) | 太慢了|
 | 代数约简| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立解决每个测试用例。 

1. 计算兔子之间的初始距离为`d = y - x`。 这表示它们在零时刻的距离有多远。 整个问题归结为确定何时可以准确地弥补这一差距。 
2. 计算每秒组合关闭速度为`s = a + b`。 每过一秒，差距就会缩小`a + b`因为一只兔子向右移动，另一只兔子向左移动。 此步骤捕获运动的对称性。 
3. 检查是否`d`可以整除`s`。 如果不是，则没有整数时间`t`使位置完全一致。 这是因为间隙以固定整数增量缩小，因此只能在 的倍数处精确地达到零。`s`。 
4. 如果可整除，计算`t = d // s`。 这是双方地位平等的第一个时刻。 
5、输出`t`对于测试用例，或者`-1`如果整除失败。 

### 为什么它有效

 关键的不变量是，每一秒之后，兔子之间的距离正好减少`a + b`。 从距离开始`d`， 后`t`秒距离是`d - t(a + b)`。 当该表达式等于零时，会议恰好发生。 由于所有项都是整数，因此唯一可能的解决方案是`d`是的倍数`a + b`，对应的商就是第一个有效的会议时间。 在不满足该方程的情况下，不存在它们相遇的中间状态，因为两个位置都是线性且同步演化的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y, a, b = map(int, input().split())
        d = y - x
        s = a + b
        if d % s == 0:
            print(d // s)
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```该实现直接反映了导出的方程。 距离`d`每个测试用例计算一次，并且组合速度`s`代表每秒差距缩小的速度。 可分性检查是核心决策点。 如果失败，则不存在整数时间对齐，因此我们立即返回`-1`。 如果成功，整数除法给出准确的会议时间。 

计算时必须小心`d = y - x`为了避免负值。 由于输入保证`x < y`，这是安全的，但仍然增强了正确性。

 时`t = 2`，位置是`0 + 2*2 = 4`和`10 - 2*3 = 4`。 他们恰好相遇。 

这证实了该公式正确地捕获了同时收敛。

 输入：`0 10 3 3`| 步骤| d = y - x | s = a + b | d % s | 行动|

 ## 边缘情况

 当`a == b`，组合速度为`2a`，并且距离只能以偶数步缩小。 如果初始间隙是奇数，算法会正确返回`-1`因为没有整数步可以用偶数减量桥接奇数距离。 例如，`x = 0, y = 1, a = 1, b = 1`给出`d = 1`,`s = 2`，并且无法整除，这符合它们对称弹跳并且从不重合的事实。 

当差距小于组合速度时，除法逻辑仍然成立。 例如`x = 1, y = 3, a = 1, b = 2`给出`d = 2`,`s = 3`，不可整除，所以答案是`-1`。 尽管兔子很快就靠近了，但它们却没有完全落在一起，而是超调了，算法直接捕捉到了这一点。
