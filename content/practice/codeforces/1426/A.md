 ## 解决方案
 ## 问题理解

 该问题要求我们找到一栋布局稍微不寻常的建筑物中给定公寓的楼层号。 第一层始终有两套公寓，随后的每一层都有相同数量的公寓，由下式给出$x$。 公寓号码从$1$位于一楼，并随着您向上移动而依次增加。 给定公寓号码$n$以及每层公寓的数量$x$在第一个之后，任务是计算哪一层楼包含公寓$n$。 

输入由多个测试用例组成，对于每个测试用例，我们给出$n$和$x$。 限制很小——$n$和$x$至多是$1000$，并且最多可以有$1000$测试用例。 这表明任何运行在$O(t)$或者$O(t \cdot 1)$每个测试用例是完全可以接受的。 由于每个测试用例的操作都是简单的算术计算，因此不存在超出时间限制的风险。 

需要注意的边缘情况是一楼的公寓，特别是$n = 1$或者$n = 2$。 总是对后续楼层应用公式的粗心实施可能会错误计算这些情况。 另一个潜在的陷阱是当$n$正好落在两层楼之间的边界处。 例如，如果$x = 3$, 公寓$3$,$4$， 和$5$占据二楼，所以是一套公寓$n = 5$必须正确识别为位于二楼，而不是三楼。 

## 方法

 简单的方法是一层一层地模拟，计算公寓数，直到到达$n$。 从一楼的两间公寓开始，然后添加$x$下一层的公寓，增加楼层计数器，直到当前楼层包含公寓$n$。 虽然这是正确的，但对于简单算术问题来说有点冗长，并且对于约束来说是不必要的。 

最佳方法使用一个简单的公式。 如果$n \le 2$，公寓位于一楼。 否则，减去一楼的公寓并计算需要多少个完整的后续楼层。 这可以表示为$(n - 3) // x + 2$，使用整数除法。 理由是$n - 2$公寓保留在一楼之后。 除以$x$给出第一层之上的附加楼层数，然后我们添加$1$占一楼。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 模拟 | 每个测试用例 O(n) | O(1) | O(1) | 正确但不必要 |
 | 公式| 每个测试用例 O(1) | O(1) | O(1) | 最佳并被接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$和$x$。 
3. 检查是否$n$是$1$或者$2$。 如果是，则输出楼层$1$直接地。 
4. 否则，减去$2$从$n$占一楼。 
5. 计算额外楼层的数量：$(n - 3) // x + 2$。 减法为$1$该部门内部确保正确的地板四舍五入的精确倍数$x$。 
6. 输出计算出的楼层数。 

原理：该公式将公寓分为一楼两层，然后是连续的楼层$x$。 整数除法可确保属于部分填充的最后一层的任何公寓正确舍入到该楼层号。 边缘情况$n \le 2$分开处理以避免负分。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        if n <= 2:
            print(1)
        else:
            # subtract first floor, then compute which floor
            floor = (n - 3) // x + 2
            print(floor)

if __name__ == "__main__":
    solve()
```第一个条件处理一楼的边缘情况。 对于所有其他公寓，减去$3$并添加$2$公式中的公寓号与楼层号正确对齐。 整数除法可确保将楼层末尾的公寓计入正确的楼层。 

## 工作示例

 输入示例：```
n = 7, x = 3
```减去一楼：```
n_remaining = 7 - 2 = 5
```计算额外楼层：```
(7 - 3) // 3 + 2 = 4 // 3 + 2 = 1 + 2 = 3
```结果与预期输出相符。 另一个例子：```
n = 1, x = 5
```由于 n <= 2，因此返回第一层。 

| n | x| 楼层计算| 输出|
 | --- | --- | --- | --- |
 | 7 | 3 | (7-3)//3+2 = 3 | 3 |
 | 1 | 5 | 一楼 = 1 | 1 |

 ## 边缘情况

 关键的边缘情况是当$n$落在一楼。 该解决方案正确识别公寓$1$和$2$就像在地板上一样$1$。 另一种微妙的情况发生在$n$恰好降落在第一层之后的最后一个公寓； 整数除法公式会自动将其放置在正确的楼层上。 例如，$n = 5$,$x = 3$：减去一楼（2间公寓）→剩余3间公寓。 然后$(5-3)//3 + 2 = 2$正确识别2楼。
