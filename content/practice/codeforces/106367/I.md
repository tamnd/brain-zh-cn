 ## 解决方案
 ## 问题理解

 我们得到一行$n$沿着河流以递增的坐标放置灯$x_1 < x_2 < \dots < x_n$。 旅行者从灯 1 出发并想要到达灯$n$。 每盏灯$i$，有两种方法可以继续前进。 

第一个选项是本地步骤：从$i$到$i+1$并支付固定费用$a_i$。 这就像一条沿着链的标准路径。 

第二个选项是长距离“萤火虫跳跃”：从当前灯开始$i$，您可以直接跳到任何后面的灯$j > i$。 这需要花费$b_i + (x_j - x_i)^2$。 费用取决于您的出发地点、着陆地点以及每个位置的罚金$b_i$。 不过这个特殊的跳转最多只能用$k$整个旅程总共次数。 

目标是最小化到达灯的总耐力成本$n$，混合普通的相邻动作，最多$k$二次成本长跳。 

这些限制非常重要。 所有测试用例中的灯总数最多为$2 \cdot 10^5$， 尽管$k \le 200$。 这立即排除了任何二次方$n$每个测试用例或尝试显式考虑所有路径。 任何解决方案都必须处理$n$几乎线性并使用较小的值$k$作为主要优化轴。 

对所有状态和所有灯对之间的转换进行简单的动态编程将涉及如下转换：$i \to j$为所有人$i < j$，生产$O(n^2)$每层的行为，这太慢了。 

如果我们试图在每一步贪婪地决定是否使用萤火虫跳跃，就会出现一种微妙的失败模式。 跳跃成本取决于未来的位置，因此局部良好的跳跃可以阻止全局更好的结构。 例如，从$i$到$j$由于体积大，可能看起来很贵$(x_j-x_i)^2$，但它可以让我们在未来以更便宜的价格跳跃。 这种对全局结构的依赖迫使采用 DP 表述。 

## 方法

 一个直接的表述是定义$dp[t][i]$作为到达灯的最低成本$i$准确地使用$t$萤火虫跳跃。 

来自州$(t, i)$，我们有两种过渡类型。 我们可以步行到$i+1$有成本$a_i$，或者我们可以使用萤火虫跳跃$i$对任何$j > i$，将跳跃计数增加到$t+1$并支付$b_i + (x_j - x_i)^2$。 

如果我们逐字展开的话，每一层$t$涉及所有对的转换$i < j$，这导致$O(n^2)$每层的工作量和$O(kn^2)$全面的。 和$n = 2 \cdot 10^5$，这是完全不可行的。 

关键结构是跳跃成本可以重写为分离的形式$i$和$j$。 扩大正方形给出$$(x_j - x_i)^2 = x_j^2 - 2x_i x_j + x_i^2.$$所以过渡变成$$dp[t][i] + b_i + x_i^2 + x_j^2 - 2x_i x_j.$$对于固定$t$和固定目标$j$， 期限$x_j^2$是恒定的。 剩下的表达式是最小值$i$的线性函数$x_j$，其中每个$i$定义一条带斜率的线$-2x_i$并拦截$dp[t][i] + b_i + x_i^2$。 这将每一层变成凸包技巧查询问题。 

因此，每一层都分两个阶段工作。 首先我们计算$dp[t]$沿着链条仅使用步行过渡。 然后我们使用所有状态$i$在层$t$构建一组行并查询所有行$j$，产生候选值$dp[t+1][j]$。 最后，我们再次在层内传播行走过渡$t+1$。 

这将每层减少到具有单调凸包的线性时间（因为$x_i$已排序），给出$O(n)$每层和$O(nk)$全面的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力 DP 总体$i, j, t$|$O(kn^2)$|$O(kn)$| 太慢了|
 | 每层凸包 DP |$O(kn)$|$O(n)$| 已接受 |

 ## 算法演练

 我们逐层处理firefly的使用，处理每个值$t$分别地。 

1. 初始化$dp[0][1] = 0$和所有其他值作为无穷大。 这表示从灯 1 开始，不使用任何跳转。 
2. 对于每一层$t$从$0$到$k$，首先沿着链向前传播步行过渡。 对于每个$i$，我们放松$dp[t][i+1]$使用$dp[t][i] + a_i$。 这确保了在相同数量的萤火虫跳跃中，我们考虑了所有可能的相邻移动序列。 
3. 步行传播后，我们从所有位置构建凸包结构$i$在层$t$。 各位置$i$贡献一条线代表开始萤火虫跳跃$i$。 该行是通过重写成本得出的，以便查询仅取决于$x_j$。 坡度为$-2x_i$截距是$dp[t][i] + b_i + x_i^2$。 
4. 我们处理目标职位$j$按递增顺序$x_j$。 对于每个$j$，我们查询凸包以找到最好的先前$i$，并计算候选值$dp[t+1][j]$。 此步骤捕获所有可能的单一萤火虫跳跃，结束于$j$。 
5.应用所有跳跃后，我们再次在层内传播行走过渡$t+1$，因为通过跳跃到达某个位置后，我们仍然可以向前走而不消耗额外的跳跃。 
6. 重复直到所有$k$层层处理，最后返回$dp[t][n]$全面的$t \le k$。 

正确性取决于运动类型之间的分离：步行保留跳跃的次数，而萤火虫过渡将其精确增加 1。 每层首先完全稳定行走，然后应用从该稳定状态开始的所有可能的跳跃，确保不会错过任何交互。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        x = list(map(int, input().split()))
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        dp = [INF] * n
        dp[0] = 0

        def walk(dp):
            for i in range(n - 1):
                if dp[i] + a[i] < dp[i + 1]:
                    dp[i + 1] = dp[i] + a[i]

        walk(dp)

        for _t in range(k):
            # build lines from current dp
            lines = []
            for i in range(n):
                if dp[i] < INF:
                    m = -2 * x[i]
                    c = dp[i] + b[i] + x[i] * x[i]
                    lines.append((m, c))

            # convex hull for min queries, slopes decreasing since x increasing => m decreasing
            hull = []

            def bad(l1, l2, l3):
                m1, c1 = l1
                m2, c2 = l2
                m3, c3 = l3
                return (c3 - c1) * (m1 - m2) <= (c2 - c1) * (m1 - m3)

            for line in lines:
                while len(hull) >= 2 and bad(hull[-2], hull[-1], line):
                    hull.pop()
                hull.append(line)

            def query(xv):
                l, r = 0, len(hull) - 1
                while l < r:
                    mid = (l + r) // 2
                    def f(line):
                        m, c = line
                        return m * xv + c
                    if f(hull[mid]) <= f(hull[mid + 1]):
                        r = mid
                    else:
                        l = mid + 1
                return hull[l][0] * xv + hull[l][1] if hull else INF

            ndp = [INF] * n

            for j in range(n):
                best = query(x[j])
                if best < INF:
                    ndp[j] = min(ndp[j], best + x[j] * x[j])

            dp = ndp
            walk(dp)

        print(dp[-1])

if __name__ == "__main__":
    solve()
```DP 数组存储每个灯的最佳成本，并通过迭代隐式编码固定数量的萤火虫跳跃。 在每个松弛阶段之后应用行走阶段，以确保沿着链的单调传播。 

每个萤火虫层都转换为一组线性函数，查询步骤评估每个目标坐标的最佳前驱。 二次项被仔细分割，以便仅在查询后添加，匹配原始成本的代数变换。 

船体内部的二分搜索依赖于由增加引起的单调斜率$x_i$，这保证了凸包的正确性。 

## 工作示例

 考虑一个带有三盏灯的小案例，其中一次跳跃是有益的。 

我们采取$x = [0, 2, 5]$,$a = [3, 100]$,$b = [1, 1]$,$k = 1$。 

### 第 0 层（无跳跃）

 | 我| 步行前的 dp[i] | 行动| 步行后 dp[i] |
 | --- | --- | --- | --- |
 | 1 | 0 | 开始 | 0 |
 | 2 | 信息 | 0 + 3 | 3 |
 | 3 | 信息 | 3+100| 103 | 103

 这表明纯步行主导了初始可达性。 

### 萤火虫层

 我们从每个州都建立线路。 

| 我| dp[i] | dp[i] | 线斜率| 拦截|
 | --- | --- | --- | --- |
 | 1 | 0 | 0 | 1 |
 | 2 | 3 | -4 | 3 + 1 + 4 = 8 |
 | 3 | 103 | 103 -10 | 103 + 1 + 25 = 129 |

 每次查询这些行$x_j$由于二次节省，提高了到后面点的可达性。 

计算后$dp[1]$，我们再次传播步行，允许任何改进的位置以廉价的方式向前延伸。 

该轨迹显示单次跳跃如何重塑整个剩余路径，而贪婪的局部决策将无法捕获该路径。

 ## 边缘情况

 一个关键的边缘情况是所有最优路径完全避免萤火虫跳跃。 在这种情况下，每个 DP 层应该简单地复制沿链的最短路径。 该算法处理此问题是因为凸包仍将正确构建，但没有候选者会击败仅行走传播，因此值保持不变。 

另一个边缘情况是，单个极其有益的跳转几乎跳过整个数组。 例如，如果$x_1$和$x_n$距离很近，但中间点很远，二次结构使直接跳跃成为最佳选择。 DP 正确地捕获了这一点，因为所有可能的起点都包含为线，并且在$x_n$评估每个候选人的开始。 

第三种情况是当$k = 0$。 该算法仍然有效，因为跳过了萤火虫层上的循环，只留下步行 DP。 这退化为简单的前缀松弛$a_i$，这正是正确的行为。 

最后一个微妙的情况是，多个萤火虫跳跃以非直观的方式链接在一起。 基于层的 DP 强制每次跳转将层索引恰好增加 1，从而确保所有多跳转策略都干净地组成，而不会混合部分转换。
