 ## 解决方案
 ## 问题理解

 有$n$参加奥林匹克运动会的参与者。 每位参与者$i$从固定时间开始形成算术级数：第一个从时间开始$0$，第二次$x$，第三个在$2x$，依此类推，所以参与者$i$开始于$(i-1)x$。 

每个参与者的花费都是准确的$t$分钟写比赛，所以参与者$i$完成时间$(i-1)x + t$。 

当参与者完成后，我们会查看当时还有多少其他参与者仍在参与比赛。 如果参与者已经开始但尚未完成，则被认为是活跃的。 参与者的“不满”$i$是时间间隔与时间重叠的其他参与者的数量$(i-1)x + t$。 

任务是计算所有参与者的总不满情绪。 

约束条件非常大，$n$最多$2 \cdot 10^9$。 这立即排除了任何单独模拟参与者或逐对检查重叠的解决方案。 甚至一个$O(n)$解决方案会太慢，因为它需要数十亿次操作。 

时间结构也是统一的：所有参与者都有相同的间隔长度$t$，并且开始均匀间隔$x$。 这种强烈的规律性表明重叠计数仅取决于相对位置，而不取决于个体模拟。 

当间隔间隔主导持续时间时，会出现微妙的边缘情况。 如果$t < x$，那么在结束时没有参与者与任何未​​来的参与者重叠。 

例如，如果$x = 10$,$t = 3$， 和$n = 5$，每个参与者在下一个参与者开始之前就完成了，所以答案是$0$。 简单的模拟可能仍会尝试计算重叠部分，但经过昂贵的工作后却找不到任何重叠部分。 

另一个边缘情况是当$t$相比之下非常大$x$。 然后，每个参与者与许多后来的参与者重叠，可能几乎是所有参与者，并且总和在结构上呈二次方增长，尽管它必须在恒定时间内计算。 

## 方法

 直接模拟将为每个参与者计算$i$, 有多少个间隔重叠时间$(i-1)x + t$。 这需要扫描所有其他参与者，检查他们的开始时间是否早于该时间，结束时间是否晚于该时间。 这产生$O(n^2)$最坏情况的行为，因为对于每个$n$我们可能扫描到的参与者$n$其他的。 和$n$最多$2 \cdot 10^9$，这是不可能的。 

关键的观察结果是结构完全均匀。 每个参与者的间隔长度相同$t$，并且起始点间隔均匀。 因此，我们可以将条件转换为指数上的不等式，而不是推理各个区间。 

参加者结束时$i$，我们只关心参与者$j > i$，因为由于相同的持续时间和严格更早的开始时间，较早的参与者此时已经完成。 在后来的参与者中，仅那些在 之前或结束时间开始的参与者$i$贡献。 

这将问题简化为计算有多少个索引位于固定大小的滑动窗口中，该滑动窗口由适合的起始步骤数决定$t$， IE。$\lfloor t / x \rfloor$。 

一旦进行了这种简化，答案就变成了简单分段线性函数的封闭形式和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 封闭式计数|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 让$k = \left\lfloor \frac{t}{x} \right\rfloor$。 该值表示有多少个完整的起始间隔大小$x$适合持续时间$t$。 

1. 重写参与者在结束时间重叠的条件$i$。 参加者$j$如果他们的区间涵盖$(i-1)x + t$。 这给出了两个不等式：$j > i$和$(j-1)x \le (i-1)x + t$。 
2. 通过减去来简化第二个不等式$(i-1)x$，产生$(j-i)x \le t$。 由于所有值都是整数，因此变为$j - i \le k$。 
3. 结合两个约束。 参与者的有效贡献者$i$正是那些$$i < j \le i + k$$与有效范围相交$1 \le j \le n$。 

1. 将其转换为计数：$$\text{discontent}_i = \min(k, n - i)$$因为最多有$k$未来的参与者在范围内，但也最多$n - i$实际剩余参与者。 

1. 总和$i$:$$\sum_{i=1}^{n} \min(k, n-i)$$1. 将总和分成两个区域。 为了$i \le n-k$，该值始终为$k$。 为了$i > n-k$，它从$k-1$下降到$0$。 
2. 计算：

 如果$k \ge n$，那么所有项都是$n-i$, 给予$\frac{n(n-1)}{2}$。 

否则：$$(n-k)\cdot k + \frac{k(k-1)}{2}$$### 为什么它有效

 该算法依赖于这样一个事实：完成时的重叠仅取决于相对索引距离，而不是绝对时间。 每个参与者最多看到一个“窗口”$k$后来参与者依然活跃。 由于开始时间间隔均匀，因此每个窗口的形状都相同$i$，刚刚转移。 这种不变性将动态重叠问题转化为确定性算术和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    x = int(input().strip())
    t = int(input().strip())

    k = t // x

    if k == 0:
        print(0)
        return

    if k >= n:
        print(n * (n - 1) // 2)
        return

    ans = (n - k) * k + k * (k - 1) // 2
    print(ans)

if __name__ == "__main__":
    solve()
```实现的核心是简化为单个参数$k$。 一次$k$是计算出来的，所有行为都是在没有模拟的情况下确定的。 这两个分支处理“重叠窗口”是否大于整个参与者范围。 算术公式直接来自对常数前缀和尾部递减求和。 

必须小心整数除法：$k = t // x$是有效的，因为所有参数都是整数，我们只需要仍然适合内部的完整移位的最大整数$t$。

 ## 边缘情况

 当$k = 0$，算法立即返回零。 这对应于$t < x$，这意味着每个参与者在任何后来的参与者开始之前就完成了。 用于输入$n=5, x=10, t=3$，我们得到$k=0$，并且每个不满值都为零，因为在结束时间没有间隔重叠。 

什么时候$k \ge n$，每个参与者都会看到所有后来的参与者在结束时间仍然处于活动状态。 为了$n=4, x=1, t=100$，我们得到$k=100 \ge n$，所以答案就变成了$4 \cdot 3 / 2 = 6$。 这与参与者 1 看到其他 3 个、参与者 2 看到 2 个、参与者 3 看到 1 个、参与者 4 没有看到这一事实相匹配。 

什么时候$k = n-1$，结构从恒定行为平稳过渡到三角形行为。 为了$n=4, x=1, t=3$，我们得到$k=3$，贡献是$3,2,1,0$，正确求和为$6$。 这将检查常量前缀和递减后缀之间分割的正确性。
