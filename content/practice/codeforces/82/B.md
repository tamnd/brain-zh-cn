 ## 解决方案
 ## 问题理解

 我们得到了一些隐藏的不相交集的所有成对并集。 原始集本身并未显示。 

假设隐藏集合是$S_1, S_2, \dots, S_n$。 对于每对$i \neq j$，我们得到了集合$S_i \cup S_j$。 这些联合被打乱了，所以我们不知道哪对产生了哪条线。 

原始集合是成对不相交的，这是关键的结构属性。 每个数字都属于一个隐藏集合。 

我们的任务是重建原始集合的任何有效集合。 

约束足够小，我们可以承担输入线数量的二次工作。 有$n(n-1)/2$工会，以及$n \le 200$，所以最多大约 20,000 行。 每行最多包含 200 个整数。 一个$O(m^2)$所有联合的算法已经变得不舒服了，因为$m \approx 20{,}000$，进行数亿次比较。 我们需要利用不相交并集的结构，而不是将每一对与其他每一对进行匹配。 

最危险的边缘情况是某些隐藏集合仅包含一个元素时。 那么包含该元素的每个联合与其他集合仅相差一个值。 

例如：```
n = 3
A = {1}
B = {2}
C = {3,4}
```工会是：```
{1,2}
{1,3,4}
{2,3,4}
```尝试仅从频率推断集合的粗心方法很容易错误地合并单例集合。 

另一个微妙的情况出现时$n=2$。 那么只有一个并集，即两个隐藏集的并集。 将该联合划分为两个非空子集的任何分区都是有效的。 

例子：```
2
3 1 2 3
```一个有效的答案是：```
1 1
2 2 3
```假设存在足够的信息来唯一标识每个原始集合的解决方案在这里将失败。 

第三个陷阱是假设每个原始集合都直接出现在输入中的某个位置。 从来没有。 每条线始终是两个不同集合的并集。 

考虑：```
A = {1,2}
B = {3}
C = {4}
```输入联合：```
{1,2,3}
{1,2,4}
{3,4}
```套装`{1,2}`从未明确出现，但仍然必须重建。 

## 方法

 暴力策略会尝试将所有数字划分为隐藏组，并验证生成的成对并集是否与输入匹配。 即使我们只考虑将每个值分配给其中一个$n$集，搜索空间呈指数增长。 由于有多达 200 个不同的数字，不可能进行详尽的重建。 

蛮力思想在概念上仍然有用，因为它暴露了输入的主要属性：每个数字总是与其自身隐藏集合的所有元素一起传播。 

假设一些原始集合是：$$S = \{a,b,c\}$$每个工会包含`a`还包含`b`和`c`，因为并集是由整个集合组成的。 反之亦然。 来自不同隐藏集合的元素并不总是一起出现，因为存在一个包含一组但不包含另一组的并集。 

这一观察结果将问题转化为分组任务。 

对于每个值$x$，收集包含的所有联合行的索引$x$。 当且仅当这些集合相同时，两个数字属于同一隐藏集合。 

为什么这有效？ 

如果$x$和$y$属于同一原始集合，则每个并集要么包含两者，要么都不包含。 它们的出现模式是相同的。 

如果它们属于不同的集合，则考虑由包含以下内容的集合形成的并集：$x$和一些与无关的第三组$y$。 该联盟包含$x$但不是$y$。 他们的模式不同。 

所以隐藏集正是相同出现模式的等价类。 

唯一的例外是$n=2$。 只有一个联合行，因此每个数字都出现在完全相同的一组行中。 我们无法唯一地区分原始集合。 任何非空分区都可以。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳|$O(M \cdot K)$|$O(M \cdot K)$| 已接受 |

 这里$M = n(n-1)/2$是联合行的数量，并且$K$是所有行中的整数总数。 

## 算法演练

 1. 读取所有联合行并为每行分配一个索引。 

我们需要这些索引，因为核心思想是比较每个值出现的位置。 
2. 对于每个整数值$x$，建立一个线索引列表，其中$x$发生。 

例子：```
value 7 -> [0, 3, 5]
value 2 -> [1, 2, 4]
```这些出现模式唯一地标识隐藏集。 
3. 按相同的出现模式对值进行分组。 

我们可以使用一个字典，其键是行索引的元组。 

以这种方式产生的每个组都对应于一个原始隐藏集。 
4、特殊情况处理$n=2$。 

只有一个联合行，因此每个值都具有相同的模式。 我们无法唯一恢复原始分区。 

由于接受任何有效的分区，因此将一个数字放入第一组中，将所有剩余的数字放入第二组中。 
5.输出所有重建的组。 

### 为什么它有效

 每条联合线都是通过两个完整的隐藏集形成的。 

如果两个数字属于同一隐藏集，则它们总是一起出现在每个联合行中。 它们的出现模式是相同的。 

如果两个数字属于不同的隐藏集，则至少存在一条包含其中一个数字但不包含另一个数字的联合线。 它们的发生模式不同。 

因此，出现模式的相等性与属于同一隐藏集完全相同。 按这些模式分组可以正确重建所有原始集。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    n = int(input())

    m = n * (n - 1) // 2

    lines = []
    occ = defaultdict(list)

    for idx in range(m):
        arr = list(map(int, input().split()))
        vals = arr[1:]

        lines.append(vals)

        for x in vals:
            occ[x].append(idx)

    # Special case: n = 2
    if n == 2:
        all_values = sorted(occ.keys())

        print(1, all_values[0])

        second = all_values[1:]
        print(len(second), *second)
        return

    groups = defaultdict(list)

    for x, pattern in occ.items():
        groups[tuple(pattern)].append(x)

    result = list(groups.values())

    for group in result:
        print(len(group), *group)

if __name__ == "__main__":
    solve()
```第一部分读取每个数字出现的所有联合行和记录。 字典`occ`将一个值映射到包含该值的行索引列表。 

关键的实现细节是保留索引的顺序。 由于行是按顺序处理的，因此每个出现列表都会自动排序。 这使得元组可以安全地用作字典键。 

特殊情况`n == 2`需要单独处理。 如果没有它，所有值都会崩溃为一组，因为只有一条联合线。 问题陈述接受任何有效的重构，因此将一个值与其余值分开就足够了。 

分组阶段是解决方案的核心。 当两个数字的出现元组匹配时，它们被准确地放入同一重构集中。 

不需要对组进行排序，因为输出可以按任何顺序排列。 

## 工作示例

 ### 示例 1

 输入：```
4
3 2 7 4
3 1 7 3
3 5 4 2
3 1 3 5
4 3 1 2 4
2 5 7
```假设隐藏集合是：```
{7}
{2,4}
{1,3}
{5}
```发生模式：

 | 价值| 出现在行中 | 图案|
 | --- | --- | --- |
 | 2 | 0, 2, 4 | (0,2,4) | (0,2,4) |
 | 4 | 0, 2, 4 | (0,2,4) | (0,2,4) |
 | 1 | 1, 3, 4 | (1,3,4) |
 | 3 | 1, 3, 4 | (1,3,4) |
 | 5 | 2、3、5 | (2,3,5) |
 | 7 | 0, 1, 5 | (0,1,5) | (0,1,5) |

 将相等的模式分组给出：

 | 图案| 重建集 |
 | --- | --- |
 | (0,2,4) | (0,2,4) | {2,4} |
 | (1,3,4) | {1,3} |
 | (2,3,5) | {5} |
 | (0,1,5) | (0,1,5) | {7} |

 该迹线展示了关键不变量。 来自同一隐藏集合的元素总是共享完全相同的出现模式。 

### 示例 2

 输入：```
2
3 1 2 3
```只有一条联合线。 

发生模式：

 | 价值| 图案|
 | --- | --- |
 | 1 | (0,)|
 | 2 | (0,)|
 | 3 | (0,)|

 所有模式都是相同的，因此重建并不唯一。 

该算法单独处理这个问题并可能输出：```
1 1
2 2 3
```该跟踪说明了为什么仅使用一般分组逻辑是不够的$n=2$。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(K)$| 每个出现的整数都会被处理一次 |
 | 空间|$O(K)$| 事件列表和分组存储|

 这里$K$是所有联合行的整数总数。 

和$n \le 200$，总输入大小足够小，这种线性处理很容易满足时间限制。 内存使用量也很小，因为每个事件仅存储一次。

 ## 边缘情况

 考虑最小的有效输入：```
2
2 1 2
```只有一条联合线。 两个数字出现在完全相同的位置：

 | 价值| 图案|
 | --- | --- |
 | 1 | (0,)|
 | 2 | (0,)|

 一般分组逻辑会错误地生成单个集合`{1,2}`。 该算法检测到`n == 2`并手动创建两个非空集。 

现在考虑单例隐藏集：```
3
2 1 2
2 1 3
2 2 3
```隐藏的集合是`{1}`,`{2}`,`{3}`。 

图案：

 | 价值| 图案|
 | --- | --- |
 | 1 | (0,1) |
 | 2 | (0,2) | (0,2) |
 | 3 | (1,2) |

 所有模式都是不同的，因此每个单例都可以正确重建。 

最后，考虑不相等的集合大小：```
3
3 1 2 3
3 1 2 4
2 3 4
```隐藏的集合是`{1,2}`,`{3}`,`{4}`。 

图案：

 | 价值| 图案|
 | --- | --- |
 | 1 | (0,1) |
 | 2 | (0,1) |
 | 3 | (0,2) | (0,2) |
 | 4 | (1,2) |

 价值观`1`和`2`具有相同的发生模式，因此它们被分组在一起。 单例集保持独立，因为它们的模式不同。
