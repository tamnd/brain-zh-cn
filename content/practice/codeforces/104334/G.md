 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串的集合，每个字符串的长度$M$，每个字符串代表结果的完整分配$M$事件。 在一种解释中，$j$-th 位为 1 表示事件$E_j$处于“拯救”状态，0表示“灾难”。 所以输入实际上是一组$N$不同的完整作业$M$布尔变量。 

隐藏的结构是这些$N$分配不是任意的。 它们被定义为一些未知约束集的封闭。 每个约束来自选择两个索引$i, j$以及四种“知识类型”之一，其中每种类型都禁止恰好一种值的组合$(E_i, E_j)$。 例如，类型1禁止同时成为灾难，类型4禁止同时成为救赎，另外两种禁止对称地混合情况。 因此，每个约束恰好删除两个变量的四个可能的值对之一，留下三个允许的对。 

我们被要求确定是否存在这样的成对约束的多重集，其满足分配的集合正是给定的集合$N$二进制字符串，如果是，则输出一种有效的结构。 

的限制$N, M \le 2000$意味着我们不能尝试任何指数分配或约束子集。 该结构表明我们正在根据解空间本身的行为重建变量对上的关系结构。 

一个关键的观察结果是，每个约束都是二元关系，它恰好消除了四个可能对中的一个。 这意味着每一个约束都相当于禁止一个“角落”$2 \times 2$真值表。 此类约束定义了一系列成对一致性条件，并且解集是在列对上的投影行为下闭合的约束的交集。 

立即打破简单推理的天真的边缘情况是$M=1$。 在这种情况下，不存在变量对，因此不存在约束。 唯一可能的集合是所有字符串$\{0,1\}$或单个字符串。 如果我们被给予$N=2$并且两个字符串都是“0”和“1”，则有效； 如果我们给出任何其他组合，我们无法使用对约束来表示它。 尝试总是为每个不同位构建约束的粗心方法会错误地引入无效结构。 

另一个微妙的情况是所有字符串中的两列都相同。 任何构造都必须将它们视为在约束下可互换的； 否则，试图强制区分它们可能会消除有效的解决方案。 

## 方法

 蛮力的想法是考虑所有可能的多重约束集$\binom{M}{2}$成对和所有 4 种类型。 即使是单个大小约束集$K$导致由相交定义的解空间$K$本地排除。 可能的约束多重集的数量是天文数字，甚至验证一个候选集也需要检查所有候选集的一致性$N$作业。 这种方法显然在微小的情况下是不可行的$M$。 

相反，关键的见解是扭转观点。 我们不是构造约束并推导解空间，而是从给定的解空间开始并推断哪些列对必须表现一致。 

每个约束仅影响两列，并且恰好禁止四对模式之一。 所以如果我们看任意一对列$(i, j)$，观察对的集合$(S_k[i], S_k[j])$所有字符串中必须恰好是该对的禁止模式的补集，或者如果没有对其施加任何约束则所有四个模式的补集。 由于每个约束仅删除一个模式，因此该结构意味着对于每一对列，允许的观察对集必须为大小 3 或大小 4，而不能更小或任意。 

这将问题简化为检查每个列对并确定是否存在与数据集一致的唯一禁止对。 如果一对列从未表现出特定的组合，则该缺失的组合可以解释为为该对选择适当的知识类型的效果。 如果缺少多个组合，或者缺少的模式不对应于有效的约束类型，则不存在构造。 

一旦我们确定了每一对的禁止模式，我们只需为每个缺失模式的出现每对输出一个约束。 界限$2M^2$保证即使我们最多输出每对恒定数量的约束，我们也会保持在限制范围内。

 ## 算法演练

 我们独立地处理每个列对并重建它是否强制执行约束。 

1. 对于每对索引$(i, j)$，扫描所有字符串并记录四对中的哪对$(0,0), (0,1), (1,0), (1,1)$出现。 这为我们提供了一个 4 位掩码，描述了观察到的数据集下该对的可行性。 
2. 如果所有四种模式都出现，则该对不需要任何约束。 我们没有为这对输出任何内容。 原因是没有任何单一的禁止模式可以解释观察到的自由度，因此该对在任何有效的构造中都不受约束。 
3. 如果恰好出现了 3 个模式，则恰好缺少一个模式。 该缺失的模式对应于四种知识类型之一。 我们将缺失的一对转换为适当的约束类型并输出一个约束$(i, j)$。 类型由四种组合中缺少哪一种来确定。 
4. 如果出现的模式少于三种，我们立即断定不可能。 原因是单个成对约束仅删除一个模式，因此任何构造都不可能禁止同一对上的两个或多个模式。 
5.处理完所有对后，我们输出所有构造的约束。 

正确性取决于约束对对独立起作用的事实，并且每个约束完全对应于禁止该对上的一个二进制分配。 

### 为什么它有效

 每个约束恰好删除一对固定变量上的四种可能分配中的一个。 因此，在任何有效的构造中，一对观察到的投影集必须等于四对的完整集合减去分配给该对的禁止模式的并集。 由于约束不会以改变本地禁止的对值的方式在不同对之间相互作用，因此每个对都可以独立重建。 最多缺少一个模式的条件对于可表示性来说既是充分必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    N, M = map(int, input().split())
    S = [input().strip() for _ in range(N)]

    # mask[i][j] stores seen pairs as 4-bit mask
    # bit 0: 00, bit 1: 01, bit 2: 10, bit 3: 11
    mask = [[0] * M for _ in range(M)]

    for s in S:
        for i in range(M):
            bi = ord(s[i]) - 48
            row = mask[i]
            for j in range(i + 1, M):
                bj = ord(s[j]) - 48
                row[j] |= (1 << (bi * 2 + bj))

    res = []

    for i in range(M):
        for j in range(i + 1, M):
            m = mask[i][j]
            if m == 0b1111:
                continue
            # if fewer than 3 patterns, impossible
            if m & (m - 1) == 0:
                print(-1)
                return

            # find missing pattern
            full = 0b1111
            miss = full ^ m
            if miss & (miss - 1):
                print(-1)
                return

            # decode miss into type
            # 00 -> type 1, 01 -> type 2, 10 -> type 3, 11 -> type 4
            if miss == 1:
                t = 1
            elif miss == 2:
                t = 2
            elif miss == 4:
                t = 3
            else:
                t = 4

            res.append((i, j, t))

    print(len(res))
    for i, j, t in res:
        print(i, j, t)

if __name__ == "__main__":
    main()
```该解决方案为每对列构建成对兼容性掩码。 每个掩码记录四个可能的分配中的哪一个出现在给定的字符串中。 填充掩码后，我们独立地解释每一对：要么它完全不受约束，要么它恰好缺少一个分配，我们将其转换为约束类型。 任何缺少多个分配的对都会立即无效，因为单个允许的约束无法消除同一对上的多个模式。 

实现中的一个微妙之处是将对编码为 4 位掩码。 映射$(0,0)\to 1$,$(0,1)\to 2$,$(1,0)\to 4$,$(1,1)\to 8$确保每个观察到的组合恰好切换一位。 这使得联合操作的时间恒定。

 ## 边缘情况

 关键的边缘情况是所有字符串都相同。 在这种情况下，每对列只有一个观察到的模式。 掩码仅包含一位，因此算法会检测到多个丢失的模式并立即拒绝。 这是正确的，因为除非所有变量都是固定的，否则任何单个二元约束都只能允许在所有对之间全局进行一次赋值，而该构造不会对此进行编码。 

另一种边缘情况是一对列显示所有四种组合。 该算法正确地输出该对没有约束。 这反映出不需要局部限制，任何强制约束的尝试都会人为地减少解空间。 

最后，恰好缺少两个模式的情况会被立即拒绝。 这是算法中最强的一致性检查，可以防止构建不可能的约束集，从而过度限制一对超出单个知识规则可以表达的范围。
