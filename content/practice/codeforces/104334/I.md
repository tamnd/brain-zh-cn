 ## 解决方案
 ## 问题理解

 我们在平面上得到一个点系统，其中每个点都是一个关节，两个关节之间的每个连接都是一个杆，其长度一旦选择就固定。 每个条形也有一种颜色，并且在相同颜色的条形中我们最多只能保留一个。 

只要遵守“每种颜色一个”限制，我们就可以自由删除任意数量的条形。 选择剩余的钢筋后，我们将结构想象为平面上的几何框架。 杆固定其端点之间的距离，但只要所有选定的距离保持不变，整个结构仍然可以连续变形。 我们要求计算的数量是描述所有此类变形所需的独立连续参数的数量，在选择柱的所有有效方法上最大化。 

输入描述了一个最多有 200 个关节和最多 1000 个边的图。 每条边连接两个关节并带有颜色标签。 同一对顶点之间可以存在多条边，但除了颜色之外，它们将被独立处理。 

“每种颜色最多一条边”的约束是中心约束。 如果没有它，我们将处于经典的平面杆框架设置中。 有了它，我们就可以在分区约束下选择一个子图。 

输出是一个整数，是在最佳选择边之后这种框架的配置空间的最大可能维度。 

约束足够小，不可能对边缘进行指数子集搜索。 甚至$2^{1000}$甚至$2^{200}$远远超出了可行性。 任何有效的解决方案都必须在多项式时间内进行推理并利用强大的结构：几何形状不是任意的，并且自由度仅取决于所选图的组合刚性属性。 

一个微妙的点是，删除边缘永远不会降低自由度。 它只是放宽了限制。 这意味着我们不是在寻找最小值，而是在同等程度地寻找边缘选择，以最大化我们可以施加的独立约束数量，同时尊重颜色限制。 

另一个重要的边缘情况是许多边在不同顶点之间共享相同的颜色。 一种天真的方法可能会选择所有这些，但这违反了规则并且也高估了约束。 

第二个微妙的情况是图表包含循环。 在这种情况下，并非所有边缘都是独立的约束，因此即使忽略颜色，简单地最大化边缘计数也是不正确的。 

## 方法

 如果我们忽略颜色和几何刚性理论，第一个尝试将是认为每个选定的边都会贡献一个约束，因此我们应该简单地选择尽可能多的边，同时遵守每种颜色一个的规则。 这将问题简化为选择最大数量的不同颜色，这是微不足道但错误的：它忽略了图中循环的冗余。 三角形在平面中的三个边之间仅具有两个独立的约束，因此计算边数会高估真实的约束。 

更仔细的强力方法将针对每种颜色枚举我们选择的边缘（或没有边缘），然后使用刚性分析计算所得框架的真实自由度。 即使我们可以快速计算刚性，选择的数量也是颜色数量的指数级，所以这是不可行的。 

关键的观察结果是，重要的不是任何特定嵌入的几何形状，而是平面刚性的组合概念。 在平面中，由边缘引起的约束的行为类似于称为拉曼刚度拟阵的拟阵。 如果一组边从未过度约束超出拉曼边界的任何顶点子集，则该边集是独立的。 独立边的最大数量直接决定约束的等级，从而决定自由度的数量。 

这将问题转化为选择在刚度拟阵中独立的最大尺寸边集，并附加一个限制，即我们最多可以从每个颜色类中获取一条边。 这正是两个拟阵的交集：刚性拟阵和颜色上的分区拟阵。 

拟阵交集提供了多项式时间算法来查找最大公共独立集。 一旦我们获得最大独立边数$k$，自由度为$2N - k$，因为每个独立的边缘都会从环境中移除一个维度$2N$顶点坐标的维空间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 颜色选择上的蛮力 | 指数| O(N + M) | 太慢了|
 | 拟阵交集（刚度+颜色）| O(M·N²) | O(M + N²) | 已接受 |

 ## 算法演练

 我们将问题简化为找到同时颜色有效且与刚度无关的最大边集。 

### 1. 将边建模为两个约束中的候选边

 我们将每条边视为属于两个系统的元素。 一种系统强制规定任何两个选定的边都不能共享相同的颜色。 另一个强制平面刚度独立性，这意味着所选边的子集不会过度约束超出拉曼极限的任何顶点子集。 

最终目标是在两个约束下最大化所选边的数量。 

### 2.定义分区拟阵（颜色）

 我们认为对于每种颜色，最多可以选择一条边。 这是一个标准的分区拟阵：每个颜色类贡献容量一。 

这个约束很容易在局部检查，但在全局上相互作用是刚性的，因此贪婪选择是不够的。 

### 3.定义刚度拟阵

 如果一组边与拉曼无关，则该边是有效的。 直观上看，没有子图$k$顶点可能包含多个$2k - 3$边缘，除了琐碎的小情况。 该条件准确地捕获了约束在通用平面框架中何时独立。 

我们没有明确检查所有子图，因为这将是指数级的。 相反，我们依靠拟阵交集来隐式地强制独立性。 

### 4. 运行拟阵交集

 我们从一组空的边开始。 我们反复尝试在保持这两个约束的同时添加边缘。 

当一条边违反刚性独立性时，我们尝试将其与先前选择的边沿拟阵交换图中的交替路径“交换”。 这个过程是拟阵交集的标准过程：它要么找到一种在增加大小的同时保持可行性的方法，要么证明当前集合是最大的。 

该算法在以下各项之间交替：

 - 尚未选择边缘，
 - 当前选择的边，

 同时尊重拟阵约束。 

每次增强都会将所选边缘集的大小增加一。 

### 5. 将结果转换为自由度

 一旦我们获得了最大可行边集的大小$k$，配置空间的维数为：$$\text{DOF} = 2N - k$$因为我们从$2N$自由坐标，每个独立的条都会删除一个自由度。 

### 为什么它有效

 刚度拟阵准确地捕获了通用嵌入平面中哪些距离约束是独立的。 分区拟阵捕获颜色限制。 拟阵交集保证所得到的边集同时相对于两个约束是最大的。 由于每个独立边都会将维度精确地减少一，因此最终维度纯粹由该最大独立集的大小决定，与任何特定的嵌入无关。

## 工作示例

 ### 示例 1

 输入：```
3 3
0 1 0
0 2 1
1 2 2
```我们有一个三角形，其中所有边都有不同的颜色。 由于颜色限制允许，因此可以选择所有三个边缘。 

| 步骤| 选定的边缘 | 独立尺寸|
 | --- | --- | --- |
 | 开始| ∅ | 0 |
 | 添加 (0,1) | {(0,1)} | 1 |
 | 加 (0,2) | {(0,1),(0,2)} | 2 |
 | 加 (1,2) | {(0,1),(0,2),(1,2)} | 2 |

 最后一条边不会增加平面刚度的独立性，因为它在 2D 中封闭了一个循环。 所以$k = 2$，给出自由度$= 6 - 2 = 4$。 

这表明循环并不能提供完全独立的约束。 

### 示例 2

 输入：```
4 4
0 1 0
1 2 1
2 3 2
0 3 3
```这是一个有四个顶点的循环。 

| 步骤| 选定的边缘 | 独立尺寸|
 | --- | --- | --- |
 | 开始| ∅ | 0 |
 | 添加 (0,1) | {(0,1)} | 1 |
 | 加 (1,2) | {(0,1),(1,2)} | 2 |
 | 加 (2,3) | {(0,1),(1,2),(2,3)} | 3 |
 | 添加 (0,3) | {(0,1),(1,2),(2,3),(0,3)} | 3 |

 同样，最终的边缘是相关的，因此它不会增加排名。 

这证实了该算法跟踪独立性而不是原始边缘计数。

 ## 边缘情况

 一种重要的边缘情况是所有边缘共享相同的颜色。 在这种情况下，只能选择一条边，因此该结构几乎完全不受约束。 该算法可以处理此问题，因为分区拟阵立即将选择限制为单个代表性边缘，并且刚性约束永远不会饱和。 

另一个边缘情况是具有不同颜色的完全连接的三角形。 简单的边缘计数方法会假设三个约束，但刚性拟阵正确地将其减少为两个独立的约束。 拟阵交集过程自然拒绝第三个相关约束。 

第三种情况是断开连接的图，其中每个组件独立运行。 刚度拟阵单独处理组件，最终尺寸通过全局正确累积组件之间的自由度$2N - k$关系。
