 ## 解决方案
 ## 问题理解

 我们得到一行细胞，每个细胞要么最初包含兔子，要么是空的。 在每个操作中我们可以选择一个正整数移位$K$，然后所有细胞并行行动。 

每个被占用的单元将其兔子的一部分保留在原位，同时准确地发送另一部分$K$位置向右。 如果该目的地超出最后一个单元格，则不会发送任何内容。 由于任何非空细胞仍然能够维持兔子的生存，并且繁殖实际上是无限制的，因此唯一重要的是一个细胞是否至少可以到达一次，而不是它包含多少只兔子。 

因此，每个操作的行为就像全局“可达性扩展”：每个当前可达的单元格将自己标记为再次可达，并且还标记该单元格$i+K$只要该索引存在，就可以访问。 

目标是选择一系列此类转变$K_1, K_2, \dots$这样按顺序应用它们后，每个单元格都变得可访问。 我们希望所需的操作次数最少，或者确定这是不可能的。 

字符串长度最多为 40，这立即表明任何依赖于探索状态或可达配置集的解决方案都是可行的。 然而，只有当操作数量非常小时，操作数量呈指数级增长才可行。 这促使我们进行结构表征，而不是对所有序列进行模拟。 

当某些空单元格左侧没有初始占用单元格时，就会出现关键边缘情况。 由于移动仅向右，因此无论如何选择班次，都永远无法到达这样的单元格。 例如，如果字符串是`0100`，第二个单元格永远无法影响第一个单元格，因此第一个单元格永远无法到达。 正确的输出是`-1`。 

另一个微妙的情况是所有单元格最初都已被占用。 那么就需要零操作，因为不需要扩展任何东西。 总是执行至少一项操作的简单实现会在这里错误地进行计数。 

## 方法

 一种直接的方法是模拟所有可能的操作序列。 每个操作都允许选择任何正数$K$，并且在每次操作之后，可到达位置的集合都会以确定性的方式发生变化。 原则上，我们可以对可达单元的子集执行 BFS，其中每个状态都会尝试所有可能的$K$。 然而，即使状态空间只有$2^{40}$，分支因子很大，因为$K$范围最多可达 40 个，并且操作序列可能很长。 这会导致可能的操作序列激增并很快变得不可行。 

关键的观察是中间状态的确切值是无关紧要的。 重要的是通过重复的“转移和分支”操作，可达性可以从最初的可达性传播多远。 

每次操作均带班次$K$有效地允许每个可到达的位置$i$创建一个新的可达到的位置$i+K$。 经过多次操作后，如果某个位置距某个初始占据位置的距离可以表示为所选移位的总和，则可以到达该位置，其中每个移位沿着传播路径最多可以使用一次。 这将问题变成了一个经典的可表示性问题：我们需要一个正整数的多重集，以便所有所需的距离都可以表示为子集和。 

从建设性的角度来看，如果我们选择转变$K_1, K_2, \dots, K_t$，那么任何可达到的位移都是这些值的子集和。 通过精心选择的移位，我们可以表示来自$0$达到最大值。 用少量数字最大化覆盖范围的最佳方法是使用 2 的幂，这会生成连续间隔中的所有子集和。 

因此，问题简化为找到任何单元格从其左侧最近的初始占用单元格需要移动的最大距离。 一旦我们知道这个最大距离$D$，我们需要最小的$t$这样我们就可以表示来自$0$到$D$使用子集和$t$数字，这是在以下情况下实现的$2^t - 1 \ge D$。

 ## 算法演练

 1. 从左到右扫描字符串，同时跟踪左侧最近的已占用单元格。 对于每个位置$i$,记录最接近的索引$j \le i$这样细胞$j$被占用。 
2. 如果在任何时候一个单元格的左侧都没有被占用的单元格（包括它自己），则该问题是不可能的。 当第一个被占用的单元格不在位置 1 或第一个单元格之前有间隙时，就会发生这种情况。 在这种情况下，返回$-1$。 
3. 对于每个位置$i$，计算距离$i - j$， 在哪里$j$是其左侧最近的占用位置。 
4.让$D$是所有位置上的最大距离。 
5.如果$D = 0$，所有单元格均已可达，因此返回 0。 
6. 否则找到最小的$t$这样$2^t - 1 \ge D$，并返回$t$。 

此步骤起作用的原因是每个操作都会添加一个新的移位值，可以在传播过程中选择采用或跳过该值，因此之后$t$每个初始位置的操作都可以到达可表示为子集和的所有偏移量$t$数字。 选择二的幂是最佳的，因为它可以最大化给定数量的运算的整数覆盖前缀。 

### 为什么它有效

 任何操作序列都定义一组移位值$K_1, \dots, K_t$。 可到达的位置是通过在每一步选择是否使用移位来确定的，这形成了这些值的子集和结构。 因此，可达位移恰好形成所选位移的子集和闭包。 

为了满足每一个需要的位移，我们只需要保证最大的需要的位移$D$位于可表示的范围内。 由于可实现的最大连续范围$t$当它们是 2 的幂时，就会出现正整数，从而提供覆盖范围$[0, 2^t - 1]$，直接跟随最小操作数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    prev = -1
    max_dist = 0

    for i in range(n):
        if s[i] == '1':
            prev = i
        else:
            if prev == -1:
                print(-1)
                return
            max_dist = max(max_dist, i - prev)

    if max_dist == 0:
        print(0)
        return

    t = 0
    cap = 0
    while cap < max_dist:
        t += 1
        cap = (1 << t) - 1

    print(t)

if __name__ == "__main__":
    solve()
```该实现跟踪左侧最近的占用单元格。 这直接强制了可达性约束，而不需要模拟操作。 

关键的微妙之处在于早期的不可能检查：如果我们在任何 1 出现之前看到 0，则永远无法到达该位置，因为所有运动都是严格向右的。 

第二个重要部分是计算所需的最大距离。 一旦知道了这一点，剩下的工作就只剩下找出需要多少个二进制数字来覆盖该范围了。

 ## 边缘情况

 当第一个字符是`0`，算法立即检测到不可能性，因为没有向左传播的源。 运行扫描显示`prev = -1`在索引 0 处，因此函数返回`-1`在任何距离计算之前。 

当所有字符都`1`，最大距离永远不会增加到零以上，因为每个单元本身都有一个初始源。 计算出的`max_dist`保持为0，直接导致输出`0`，正确避免不必要的操作。 

当恰好有一个时`1`，比如说在位置 0`100000`，后面的每个位置的距离都等于其索引。 最大距离变为$n-1$，并且算法正确地将其转换为表示该范围所需的位数，反映了跨越整行所需的移位操作的数量。
