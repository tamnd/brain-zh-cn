 ## 解决方案
 ## 问题理解

 我们得到了一个矩形的字符网格。 “三位一体”是通过首先选择该网格的任何正方形子区域，然后选择该正方形内位于或严格位于该正方形对角线一侧的所有单元格来形成的。 对角线可以是主对角线，也可以是反对角线。 过滤后，我们保留生成的三角形区域。 如果该区域中的所有单元格都包含相同的字符，并且该区域至少包含三个单元格，则它被视为一个有效的三位一体。 

任务是计算在两个对角线方向上所有可能的方形子网格中存在多少个这样的有效三角形区域。 

网格大小可以大到 1000 x 1000，这意味着最多有 100 万个单元。 尝试所有正方形子区域的简单方法将涉及以下顺序：$O(n^3)$或者更糟糕的平方组合，并且明确检查每个组合会太慢，可能会超过$10^{12}$运营。 这立即表明我们不能直接枚举所有方块，而必须以更聚合的方式计算贡献。 

定义中的一个微妙之处是，不同的正方形可以在网格中生成相同的几何三角形，但如果它们来自不同的正方形选择，它们仍然被认为是不同的。 所以我们计算的是配置，而不是独特的形状。 

当平方最小时就会出现边缘情况。 1 x 1 或 2 x 2 正方形不会产生有效的三位一体，因为生成的三角形区域将包含少于三个单元。 另一个边缘情况是当一个正方形完全均匀时，因为它最大化了潜在的有效三角形，并且任何计数错误往往会严重过度计数。 

## 方法

 一种直接的方法是迭代所有$O(N^2 M^2)$可能的正方形，对于每个正方形，检查两个对角线方向，然后验证生成的三角形区域中的所有单元格是否相等。 即使我们预先计算前缀和以进行字符相等性检查，我们仍然面临迭代过多的方格，并且方格子矩阵本身的总数在 1000 x 1000 网格中已经太大。 

关键的观察是，每个有效的三位一体完全由其沿对角线的顶点结构决定。 我们没有考虑完整的正方形，而是重新解释了结构：将单元固定为三角形的一部分，我们可以在两个垂直方向上扩展，直到出现不匹配。 对于固定的起始单元和选定的方向（对应于两条对角线之一），最大三角形大小取决于我们在保持统一字符约束的同时可以延伸多远。 

这将问题转化为计算每个单元格在每个对角线方向上有效的正方形大小。 我们不是枚举正方形，而是使用类似动态编程的沿对角线传播来计算最大延伸长度，然后将所有单元的贡献相加。 

主要的结构简化是有效性仅取决于沿对角线和反对角线的局部一致性，这使我们能够预先计算两个方向上的最大同质“臂”。 一旦知道这些臂长，每个单元就会贡献一些有效三角形，其数量等于这些长度的函数。

 ## 算法演练

 我们将问题分为处理两个方向：基于主对角线的三角形和基于反对角线的三角形。 两种情况都是对称的，因此我们描述一种情况并将相同的逻辑应用于另一种情况。 

1. 对于每个单元格，计算我们可以沿着定义对角线方向的正方形的两个垂直方向将相同字符的正方形延伸多远。 这是通过网格上的动态编程来完成的。 关键思想是为每个单元格预先计算沿行和列以该单元格结束或从该单元格开始的最长的相同字符，然后组合这些约束以确保平方一致性。 
2. 构建一个 DP 表，为每个单元格存储左上角位于该单元格且所有单元格都相同的正方形的最大可能边长。 这是经典的最大平方问题，但在概念上进行了扩展以反映对角对称约束。 
3. 对于每个单元和每个方向，该单元贡献的有效三位一体的数量取决于从该单元开始可以形成多少个正方形尺寸。 如果最大正方形尺寸为$k$，然后它贡献从 2 到$k$，并且每个这样的正方形对于所选的对角线方向恰好产生一个有效的三位一体。 
4. 对所有单元格和两个对角线方向的这些贡献求和。 

基本计算简化为标准最大平方 DP 并结合定向预处理，以确保候选平方中的所有单元格都相同。 

### 为什么它有效

 该算法之所以有效，是因为每个有效的三位一体都唯一对应于正方形和对角线方向的选择，并且在每个正方形内，“所有单元格相等”的条件相当于要求每个单位子正方形扩展保持一致。 DP 保证如果一个正方形的大小$k$在给定锚点处有效，则锚定在那里的所有较小方块也有效，并且不会计算任何无效方块，因为任何不匹配都会立即破坏 DP 扩展。 这在计数的 DP 状态和有效的三位一体之间创建了干净的一对一映射。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    def count_orientation():
        dp = [[1] * m for _ in range(n)]
        res = 0

        for i in range(n):
            for j in range(m):
                if i > 0 and j > 0 and g[i][j] == g[i-1][j] == g[i][j-1] == g[i-1][j-1]:
                    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
                else:
                    dp[i][j] = 1

                res += max(0, dp[i][j] - 1)

        return res

    def count_antiorientation():
        dp = [[1] * m for _ in range(n)]
        res = 0

        for i in range(n):
            for j in range(m - 1, -1, -1):
                if i > 0 and j + 1 < m and g[i][j] == g[i-1][j] == g[i][j+1] == g[i-1][j+1]:
                    dp[i][j] = min(dp[i-1][j], dp[i][j+1], dp[i-1][j+1]) + 1
                else:
                    dp[i][j] = 1

                res += max(0, dp[i][j] - 1)

        return res

    print(count_orientation() + count_antiorientation())

if __name__ == "__main__":
    solve()
```该实现使用两次传递。 每次传递都会计算一个标准最大平方 DP，一次用于法线对角线方向，一次用于镜像方向。 递归检查 2 × 2 块是否均匀； 如果是这样，则正方形可以扩展一层。 

关键的微妙之处在于求和`dp[i][j] - 1`。 值 1 对应于不贡献任何有效三位一体的简并正方形，而较大的正方形贡献锚定在该单元格的所有较小的有效三位一体大小。 

反对角版本是通过反转列遍历来实现的，以便 DP 仍然引用已经计算的状态。
