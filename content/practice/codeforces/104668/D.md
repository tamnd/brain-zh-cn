 ## 解决方案
 ## 问题理解

 我们正在模拟具有垂直约束的一维追踪。 

经过最初的延迟后，飞盘被扔出。 从那一刻起，它以恒定速度水平移动，同时从给定高度开始在重力作用下下落。 只有当飞盘仍在空中时，并且只有当飞盘的高度足够低，狗可以通过跳跃来够到飞盘时，它才可以被抓住。 

稍后，狗从原点开始，可以立即以固定的最大水平速度向左或向右移动，还可以执行垂直跳跃到固定的高度阈值。 狗接住飞盘后，立即以相同的水平速度返回原点。 我们测量从时间零到狗返回原点的总时间。 

关键的决定是选择狗遇到飞盘的确切时间。 该选择决定了会议位置和最终返回成本，因此目标是选择一个可行的会议时刻，最大限度地减少总完成时间。 

输入定义了两条轨迹。 飞盘的轨迹取决于其发射时间、初始高度、水平速度和重力。 狗的轨迹取决于其开始时间和水平速度，而垂直约束仅限制何时可以拦截。 

约束允许值高达一百万，因此任何逐步采样时间的方法都是不可能的。 即使是超过几毫秒的密集模拟也会太慢，因为相关时间范围可以扩展到大约一百万，并且我们需要高达 1e-4 的连续精度。 

最微妙的失败案例来自于忽视可行性窗口。 

第一个边缘情况是试图在飞盘足够低之前接住飞盘。 如果飞盘从 160 高度开始，狗只能跳到 40 高度，那么即使水平位置匹配，早期拦截也是不可能的。 

第二个边缘情况是在飞盘落地后试图接住飞盘。 着陆后，飞盘不再满足预期的“空气捕捉”条件，如果我们允许超过该点，模型就会破裂。 

第三种边缘情况是忽略同步。 如果飞盘在水平方向上比狗快得多，那么狗可能永远无法抓住它，除非我们尊重速度和启动延迟之间的不等式。 

## 方法

 蛮力方法会考虑许多候选者的会议时间，计算每次飞盘的位置和高度，检查狗是否可以到达该位置，并计算总返回时间。 由于时间是连续的，这需要以非常精细的分辨率离散化时间以满足所需的精度。 在高达 10^6 毫秒且精度为 1e-4 的范围内，这会导致大约 10^10 次评估，这是不可行的。 

一旦我们观察到，一旦集合点由物理确定，最终成本是集合时间的线性函数，结构就变得更简单。 飞盘的位置在时间上是确定的，因此狗的返回距离也由该时间决定。 这将问题简化为选择满足所有约束的最小可行时间。 

可行性由三个独立条件决定。 首先，狗在开始之前无法接住，飞盘在抛出之前无法接住。 其次，飞盘必须在狗的垂直范围内，这意味着它的高度最多为 Hd 的时间窗口。 第三，水平可达性要求狗在给定启动延迟和速度的情况下，能够在时间 t 之前到达飞盘的 x 坐标。 

一旦表达了这些约束，最优解就是满足所有这些约束的最早时间。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解时间模拟 | O(T / ε) | O(1) | O(1) | 太慢了|
 | 基于约束的封闭形式| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算狗最早可能行动的时间，即Td，以及飞盘最早存在的时间，即Tf。 任何有效的会议都必须在两者之后举行。 
2. 计算飞盘何时变得可以垂直捕捉。 它的高度是一条从 Hf 开始的向下抛物线。 求解 Hf - (t - Tf)^2 / 2 ≤ Hd，得出 t ≥ Tf + sqrt(2(Hf - Hd))。 这是飞盘最早可以跳跃的高度。 
3. 计算飞盘何时仍在空中。 当 Hf - (t - Tf)^2 / 2 = 0 时，它落地，即 t = Tf + sqrt(2Hf)。 任何有效的捕获时间都必须严格保持在这一点之前。 
4. 计算水平范围约束。 在时间 t 时，飞盘处于 x_f = Vf (t - Tf) 处。 狗在 Td 处开始移动，最多可以覆盖 Vd (t - Td)。 因此我们要求 Vf (t - Tf) ≤ Vd (t - Td)。 重新排列给出 t 的线性不等式，根据 Vf 是否小于、等于或大于 Vd 产生阈值时间。 
5. 取所有下限的最大值：Tf、Td、垂直捕获阈值和水平可行性阈值。 这是物理上可能捕获的最早时间。 
6. 计算会面位置 x = Vf (t - Tf)。 
7. 计算总时间为 t + x / Vd，因为狗在接住后立即以恒定速度返回。 

### 为什么它有效

 每个可行解都对应一个单一的相遇时间t，一旦t确定，所有空间量就被唯一确定。 这些约束定义了有效时间的闭合区间。 总完成时间随 t 线性增加，因为捕获之前的等待时间和返回距离都随时间向前扩展。 因此，超出最早可行时间的任何延迟都会严重恶化结果，并且以后的配置都无法改善结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    Tf, Vf, Hf, Td, Vd, Hd = map(float, input().split())

    # time bounds from start conditions
    t = max(Tf, Td)

    # vertical constraint: frisbee must be low enough to reach
    if Hf > Hd:
        t = max(t, Tf + math.sqrt(2.0 * (Hf - Hd)))

    # frisbee must still be in air
    t = min(t, Tf + math.sqrt(2.0 * Hf))

    # horizontal feasibility: Vf*(t-Tf) <= Vd*(t-Td)
    # solve for t
    if abs(Vf - Vd) < 1e-12:
        if Vf > Vd:
            return print("inf")  # unreachable case in theory
    else:
        rhs = Vf * Tf - Vd * Td
        denom = Vf - Vd
        if denom > 0:
            t = max(t, rhs / denom)
        else:
            t = max(t, rhs / denom)

    x = Vf * (t - Tf)
    ans = t + x / Vd

    print("%.10f" % ans)

if __name__ == "__main__":
    solve()
```该实现首先通过合并时间约束来构建最早的可行会议时间。 垂直约束使用弹丸高度方程的反函数。 水平约束被简化为 t 的线性不等式。 选择t后，直接计算飞盘位置，最终答案加上返回时间。 

重新排列不等式时必须小心，因为符号取决于 Vf 是否大于 Vd。 浮点精度就足够了，因为最终答案只需要1e-4以内的绝对误差。

 ## 边缘情况

 一个关键的边缘情况是当狗变得可用后垂直约束激活。 在这种情况下，忽略高度阈值会导致选择不可行的早期会议时间，而飞盘仍然太高。 

另一个边缘情况是飞盘在水平方向上比狗更快。 不等式会改变方向，并且无法处理符号变化会导致选择狗永远无法到达拦截点的时间。 

第三种边缘情况是飞盘即将落地时。 如果计算的可行时间超过着陆时间，则解决方案必须限制在有效间隔或完全拒绝该区域，否则模型会产生物理上不可能的捕获事件。
