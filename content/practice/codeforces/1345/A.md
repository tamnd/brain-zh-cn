 ## 解决方案
 ## 问题理解

 我们被要求确定是否可以根据特殊的设计来组装拼图块网格。 每件作品恰好有三个标签和一个空白。 这些部件可以以任何方向旋转。 如果我们可以填充一个解决方案$n \times m$网格，使得每个选项卡都沿着共享边缘适合空白。 

输入由多个测试用例组成。 每个测试用例提供两个整数，$n$和$m$，指定网格中的行数和列数。 如果在这些条件下可以解决难题，则输出应为“YES”，否则输出应为“NO”。 

考虑到约束条件$1 \le n,m \le 10^5$直至$1000$测试用例中，我们无法模拟拼图或尝试单独放置每个部分。 任何操纵每个单元的强力算法都需要$O(n \cdot m)$操作，可以达到$10^{10}$在最坏的情况下。 这超出了实际的时间限制，因此我们需要一种数学或组合方法。 

当网格非常窄或非常小时，就会出现不明显的边缘情况。 例如，一个$1 \times m$或者$n \times 1$网格的行为与较大的网格不同，因为边缘的部分不需要所有边都匹配。 具体来说，一个$1 \times 3$网格是可解的，而$100000 \times 100000$网格不是，尽管两者都是矩形，因为每块只有一个空白不能满足内部约束。 忽略奇偶校验或内部连接的粗心方法将错误地为大方形网格输出“YES”。 

## 方法

 蛮力方法是尝试以所有方向放置碎片，并检查每对相邻的碎片和空白是否匹配。 这对于小网格来说是正确的，但是操作计数是$O(n \cdot m)$每个测试用例。 在最大限制下，这将需要$10^{10}$操作，在时间限制内是不可行的。 

关键的洞察力来自于观察作品的结构。 每件作品都有一个空白和三个标签。 在任何大于$2 \times 2$，某些棋子必然在不同一侧有多个邻居，从而产生冲突。 例如，正方形网格中的一个棋子有四个邻居，需要四个空格才能匹配，但它只有一个。 因此，唯一可解的网格要么是一维的（单行或单列），要么是$2 \times 2$每一块都可以满足所有邻居的正方形。 

这个问题简化为一个简单的检查：如果网格是单行或单列，它总是可以解决的，因为每个部分只需要匹配行或列上的一个邻居。 如果两个维度都是偶数且等于 2，则$2 \times 2$平方是可解的。 所有其他配置都是不可能的，因为至少一个棋子的邻居数量多于空白棋子。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 太慢了 |
 | 数学/观察| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取整数$n$和$m$。 
3.如果有的话$n = 1$或者$m = 1$，打印“YES”，因为单行或单列始终可以组装。 
4.否则如果$n = 2$和$m = 2$，打印“YES”，因为$2 \times 2$网格允许每个部分匹配所有邻居。 
5. 否则，打印“NO”，因为没有配置满足内部制表符到空白的约束。 

正确性来自于每件作品恰好有一个空白的不变量。 任何有多个邻居的棋子都需要比可用的更多的空白。 仅单行、单列，并且$2 \times 2$平方尊重这个不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n == 1 or m == 1:
        print("YES")
    elif n == 2 and m == 2:
        print("YES")
    else:
        print("NO")
```该解决方案使用快速输入有效地读取所有测试用例。 条件检查直接实现上面导出的数学观察。 使用`or`允许任何一维网格，并且相等检查处理$2 \times 2$边缘情况。 所有其他输入都会在恒定时间内被拒绝。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 or m == 1:
            print("YES")
        elif n == 2 and m == 2:
            print("YES")
        else:
            print("NO")
    return out.getvalue().strip()

# Provided samples
assert run("3\n1 3\n100000 100000\n2 2\n") == "YES\nNO\nYES", "sample 1"

assert run("1\n3 2\n") == "NO", "non-square small rectangle"

 ## 边缘情况

 最小的网格，$1 \times 1$，由`n == 1`条件并输出“YES”。 对于狭窄但长的网格，例如$1 \times 100000$，算法仍然输出“YES”，因为每块只有一个邻居。 这$2 \times 2$square 触发第二个条件。 像这样的大正方形$100000 \times 100000$失败是因为每块一个空白的不变性不能满足内部邻居的要求。 每个边缘情况都直接与条件检查之一匹配，保证正确性。
