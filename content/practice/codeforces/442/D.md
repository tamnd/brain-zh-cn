 ## 解决方案
 ## 问题理解

 树从单个根顶点开始。 每个操作都会向现有顶点添加一个新叶子。 每次添加后，我们必须计算以下数量的最小可能值。 

我们给树的边缘上色。 具有相同颜色的边必须形成一条连通路径，并且任何顶点都不能有两个以上相同颜色的入射边。 对于任何顶点，查看从该顶点到根的路径并计算该路径上出现的不同颜色的数量。 着色的成本是所有顶点的最大此类计数。 我们希望成本尽可能最低。 

输入不描述静态树。 它描述了插入序列。 如果`p[i] = v`，然后顶点`i + 1`被附加为新的孩子`v`。 每次插入后，我们输出当前树的最优成本。 

最大的困难是约束`n ≤ 10^6`。 每次插入后重新计算任何实质性内容的解决方案将立即被排除。 甚至`O(height)`如果每次插入的工作发生得太频繁，则可能会很危险。 总功必须非常接近线性。 

有几种容易出错的方法。 

考虑一个有两个叶子子节点的根：```
1
├─2
└─3
```答案是`2`， 不是`1`。 一种颜色不能同时延续到两个分支。 一旦路径分成两个同样困难的子树，任何着色都需要一个额外的颜色级别。 

现在考虑一条链：```
1
└─2
   └─3
      └─4
```答案依然是`1`。 单一颜色可以覆盖整个链条。 计算深度或高度会错误地产生`4`。 

另一个微妙的情况是：```
1
├─2
│  └─4
└─3
```答案是`2`， 不是`3`。 只有一根树枝很深。 重枝上使用的颜色可以继续穿过根部，因此难度不会增加，除非有至少两个同样困难的枝条。 

这些示例指向一个递归量，该量取决于最大的子值以及有多少子值达到该最大值。 

## 方法

 暴力的观点是在每次插入后构建树并从头开始重新计算最佳着色。 

一个有用的观察是每个颜色类都是一条路径。 当一条路径到达分支顶点时，它最多可以继续通过一个子节点。 所有其他子子树必须开始一个新的颜色段。 这导致对树的递归优化。 

如果我们在每次插入后从头开始计算每个节点的最优值，那么最坏的情况就会变成二次。 一棵具有一百万次插入的树使得这完全不可行。 

关键的见解是，最优成本正是有根树的霍顿-斯特拉勒数。 

让`f(v)`是植根于的子树的最优成本贡献`v`。 

对于一片叶子来说，`f(v) = 1`。 

对于内部节点，令`m`是其子代中的最大值。 

如果只有一个孩子有价值`m`，那么最佳颜色路径可以继续通过该子项，因此：```
f(v) = m
```如果至少有两个孩子有价值`m`，那么一种额外的颜色级别是不可避免的：```
f(v) = m + 1
```这正是斯特拉勒重现。 

动态部分变得更加容易，因为斯特拉勒数只会增加。 在一棵树上最多有`10^6 + 1`顶点，斯特拉勒数永远不会超过`21`，自从获得价值`k`至少需要`2^(k-1)`树叶。 

子值在整个过程中仅更改少量次。 这给出了几乎线性的总更新计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n log n) 摊销，log n ≤ 21 | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 1. 对于每个顶点，存储其当前的 Strahler 值`val[v]`。 
2. 对于每个顶点存储`mx[v]`，其子代中最大的 Strahler 值。 
3. 对于每个顶点，维护当前有多少个子节点具有每个可能的值。 由于最大可能值最多为`21`，一个小的固定范围就足够了。 
4. 当一个新的叶子被创建时，它的值为`1`。 
5. 将叶子附加到其父级。 从父母的角度来看，一个孩子是有价值的`1`已经出现了。 
6. 更新父级的计数器并重新计算其值。 

如果`mx`是最大的子值并​​且`cnt[mx]`是达到该目标的儿童数量，那么：```
val = 1                         if mx = 0
val = mx                        if cnt[mx] = 1
val = mx + 1                    if cnt[mx] ≥ 2
```7. 如果父项的值没有改变，则停止。 上面的一切都无法改变。 
8. 如果父项的值从`old`到`new`，移至其父级。 对于该祖先，一个孩子的价值从`old`到`new`。 
9. 重复，直到值保持不变或达到根。 
10.处理插入后，输出`val[root]`。 

之所以有效，是因为价值只会增加。 在树的整个生命周期中，一个顶点最多可以移动大约二十个不同的值，因此传播更新的总数很小。 

### 为什么它有效

 Strahler 递归精确地捕获了着色约束。 

颜色路径最多可以继续通过一个子子树。 如果有一个独特的最难的孩子，则最佳路径会继续通过它，并且不需要额外的颜色级别。 如果有两个或多个最难的子级，则只有其中一个可以继承当前的颜色路径，从而强制在下面的某个位置使用另一个颜色级别。 这会将所需的值增加一。 

维护的计数器始终代表子值的当前多重集。 每次更新都会准确修改一个子贡献，因此从这些计数器重新计算父项可以保留重复性。 仅当值更改时才进行传播就足够了，因为祖先仅​​依赖于子值。 因此每次插入后的根值正是最优的着色成本。 

## Python 解决方案```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    max_nodes = n + 2
    MAXR = 22  # Strahler number never exceeds 21 for n <= 1e6

    parent = array('I', [0]) * max_nodes
    val = bytearray(max_nodes)
    mx = bytearray(max_nodes)

    cnt = array('I', [0]) * (max_nodes * MAXR)

    val[1] = 1

    ans = []

    for node, par in enumerate(p, start=2):
        parent[node] = par
        val[node] = 1

        v = par
        old_child = 0
        new_child = 1

        while v:
            base = v * MAXR

            if old_child:
                cnt[base + old_child] -= 1

            cnt[base + new_child] += 1

            if new_child > mx[v]:
                mx[v] = new_child

            old_val = val[v]

            m = mx[v]
            if m == 0:
                new_val = 1
            else:
                new_val = m + (cnt[base + m] >= 2)

            if new_val == old_val:
                break

            val[v] = new_val

            old_child = old_val
            new_child = new_val
            v = parent[v]

        ans.append(str(val[1]))

    sys.stdout.write(" ".join(ans))

if __name__ == "__main__":
