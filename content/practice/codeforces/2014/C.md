 ## 解决方案
 ## 问题理解

 我们被要求确定必须向镇上最富有的人额外添加多少黄金，以使严格超过一半的人口变得不快乐。 每个人的幸福取决于他们的财富是否低于城镇平均财富的一半。 输入由多个测试用例组成，每个测试用例提供人数及其财富列表。 输出是罗宾汉出现所需的最低额外金币，如果不可能出现则为-1。 

考虑到约束条件，我们看到`n`最多可以达到200,000，并且测试用例的总和也上限为200,000。 这排除了任何涉及通过强力检查额外黄金的所有可能值的方法，因为这可能涉及迭代大范围的总和。 我们需要一种方法，能够在基本上线性的时间内有效地计算每个测试用例所需的额外黄金`n`。 

当人口非常小时，就会出现微妙的边缘情况。 为了`n = 1`，不可能有超过一半的人不快乐，所以答案一定是-1。 同样，如果所有财富都是平等的，或者最富有的人已经如此之高，以至于没有人低于平均水平的一半，那么额外的黄金可能为零。 仔细处理浮点除法很重要，因为我们将个人财富与平均值的一半（一个实数）进行比较。 

## 方法

 一种幼稚的方法是尝试逐步增加最富有者的财富，并每次重新计算平均数和不快乐数，直到一半以上的人口不快乐为止。 这是可行的，因为它直接实现了定义，但速度非常慢。 范围为`x`可能非常大（高达数十亿），并且每次重新计算平均和不高兴计数都需要 O(n) 次操作，因此整体复杂度可能是 O(n * max(x))，这是不可接受的。 

关键的观察结果是，随着最富有的人获得黄金，不快乐的人数只会增加。 不快乐的情况是线性的`x`因为新的平均值是`(sum + x)/n`我们比较每个`a_i`到`(sum + x)/(2n)`。 对于任何个人`i`，不等式`a_i < (sum + x)/(2n)`可以明确地解决`x`。 因此，要让一半以上的人感到不幸福，只需关注`ceil(n/2)`最大的非最富有的财富。 我们可以计算一个阈值`x`对于每个人变得不快乐的地方，然后采取这些阈值的最大值。 这导致了无需迭代搜索的封闭式解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大(x)) | O(n) | 太慢了 |
 | 封闭式阈值| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取人数`n`以及财富清单`a`。 计算总财富`total`。 
2.找到最大的财富`max_a`及其索引。 这是将获得额外黄金的最富有的人。 
3. 计算所需的不快乐人数：`ceil(n/2)`。 
4. 将除最富有的人之外的所有其他财富按升序排列。 我们专注于`ceil(n/2)`最小的人可能会不快乐。 
5. 对于这些人中的每一个，计算最少的额外金币`x_i`要求他们的财富严格低于新平均水平的一半。 解决不等式`a_i < (total + x)/(2n)`为了`x`要得到`x_i = max(0, 2 * n * a_i - total + 1)`。 这`+1`确保严格的不平等。 
6.取最大值`x_i`在这些被选中的人之中。 如果为负数，则返回0； 如果是正数，则返回。 如果不可能（人口太少），则返回-1。 

之所以正确，是因为最富有的人添加额外的黄金会增加平均水平，从而使以前处于边缘的人不高兴。 通过确定必须变得不快乐的人的最大阈值，我们保证严格超过一半的人不快乐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            print(-1)
            continue
        
        total = sum(a)
        max_val = max(a)
        idx = a.index(max_val)
        
        others = a[:idx] + a[idx+1:]
        others.sort()
        
        unhappy_needed = (n + 1) // 2
        selected = others[:unhappy_needed]
        
        x_needed = 0
        for val in selected:
            x_i = 2 * n * val - total + 1
            x_needed = max(x_needed, x_i)
        
        print(max(0, x_needed))
        
if __name__ == "__main__":
    solve()
```该解决方案使用快速 I/O 读取输入来处理大型案例。 它单独处理单人边缘情况。 这`2 * n * val - total + 1`公式来自直接解决严格的不平等，并取最大值确保所有需要的人都变得不快乐。

 ## 边缘情况

 当`n = 1`，不可能有超过一半的人口不幸福。 该算法正确返回-1。 当最富有的人已经非常富有，添加零黄金就足够了时，该公式会产生一个非正的 x，我们将其剪裁为零。 当所有人都拥有平等的财富时，可能不可能让一半以上的人不高兴，并且该公式再次根据情况返回零或-1。 在所有情况下，排序可确保我们选择正确的人数来跟踪不幸福感。
