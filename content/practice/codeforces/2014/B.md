 ## 解决方案
 ## 问题理解

 这棵树每年都会长出新叶。 当年$i$，它生长$i^i$树叶。 叶子不会永远停留。 当年创作的一片叶子$i$保留在树上的确切时间$k$年，意味着它存在于几年中$i, i+1, \dots, i+k-1$。 

对于给定年份$n$，我们需要确定当前树上的叶子总数是偶数还是奇数。 

一年中生长的叶子$i$今年仍然存在$n$当且仅当$$i \le n \le i+k-1.$$重新排列给出$$n-k+1 \le i \le n.$$自年份开始于$1$, 当年可见的叶子$n$来自区间$$\max(1, n-k+1), \dots, n.$$这些约束是直接模拟不可能的第一个线索。 两个都$n$和$k$可以大到$10^9$，并且最多可以有$10^4$测试用例。 在最坏的情况下，任何需要多年迭代的解决方案都需要数十亿次操作。 

答案只问叶子总数是否为偶数。 这意味着我们只关心奇偶校验，而不关心实际的叶子数量。 这一观察将一个巨大的数字算术问题变成了一个简单的计数问题。 

一个常见的错误是尝试计算诸如 10^9^{10^9} 之类的值。 这些数字大得难以想象，而且完全没有必要，因为奇偶校验仅取决于值是奇数还是偶数。 

另一个容易犯的错误是忘记了只有最后一个$k$年贡献。 例如：```
n = 5, k = 2
```仅有岁月$4$和$5$事情。 使用所有年份$1$通过$5$会产生错误的答案。 

第三种微妙的情况发生在$k=1$。 然后只有一年$n$做出贡献。 例如：```
n = 1, k = 1
```这棵树正好有$1^1=1$叶子，很奇怪，所以答案是`NO`。 

## 方法

 暴力解决方案将识别每年谁的叶子还活着，计算$i^i$，求和，并检查最终总数的奇偶性。 

活跃年份是$$n-k+1,\dots,n.$$即使我们忽略了巨大的规模$i^i$，这种方法需要迭代至$10^9$年。 和$10^4$测试用例中，操作计数变得完全不可行。 

关键的观察是奇偶校验比实际值简单得多。 

考虑$i^i$。 

如果$i$是偶数，那么$i^i$是均匀的。 

如果$i$是奇数，那么$i^i$很奇怪。 

所以奇偶性为$i^i$恰好是$i$。 

叶子计数的总奇偶性仅取决于有多少奇数年贡献。 每个偶数年贡献偶数，不影响奇偶性。 

活动间隔包含$$[n-k+1,\, n].$$如果该区间内的奇数个数为奇数，则叶子总数为奇数。 如果该区间内的奇数个数为偶数，则为偶数。 

现在我们只需要连续区间内奇数个数的奇偶性。 

任意两个连续整数中，正好有一个是奇数。 这意味着奇数计数的奇偶校验仅取决于间隔长度$k$。 

如果$k$是偶数，区间正好包含$k/2$奇数和$k/2$偶数。 答案取决于是否$k/2$是偶数还是奇数。 

还有一个更简单的观察。 让$$S = \sum_{i=n-k+1}^{n} i^i.$$模数$2$,$$S \equiv \sum_{i=n-k+1}^{n} i.$$和的奇偶性等于奇数项的奇偶性。 在任意长度区间$k$，奇数的计数恰好是奇数，当$k \bmod 4$是$1$或者$2$，甚至恰好在什么时候$k \bmod 4$是$0$或者$3$。 

通过检查最后一年可以得出更清晰的推论$n$。 由于只有奇偶校验很重要，因此可接受的解决方案简化为计算间隔中的奇数。 由此产生的奇偶校验仅取决于$k$。

 ## 算法演练

 1. 对于每个测试用例，确定叶子仍然存在的年份间隔：$$[n-k+1,\; n].$$2. 观察$i^i$具有相同的奇偶性$i$。 替换每个术语$i^i$通过其平价贡献。 
3. 计算区间内有多少个奇数。 
4. 如果奇数个数为偶数，则输出`YES`因为总叶子数是偶数。 
5.否则输出`NO`。 

计算奇数个数的方便公式$1$通过$x$是$$\left\lfloor \frac{x+1}{2} \right\rfloor.$$所以奇数的个数$[L,R]$是$$\left\lfloor \frac{R+1}{2} \right\rfloor - \left\lfloor \frac{L}{2} \right\rfloor.$$只有这个计数的奇偶性才重要。 

### 为什么它有效

 每个偶数底数产生偶数次方，每个奇数底数产生奇数次方。 模数$2$, 每一项$i^i$行为完全像$i$。 

因此，总叶子数的奇偶性就是贡献叶子的奇数年数量的奇偶性。 该算法精确计算活动间隔的该数量。 如果奇数贡献者的数量为偶数，则叶子总数为偶数。 如果数量为奇数，则叶子总数为奇数。 由于每一步都会保留奇偶校验，因此算法始终会产生正确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
ans = []

for _ in range(t):
    n, k = map(int, input().split())

    l = n - k + 1

    odd_count = (n + 1) // 2 - (l // 2)

    if odd_count % 2 == 0:
        ans.append("YES")
    else:
        ans.append("NO")

print("\n".join(ans))
```第一步计算活动间隔$[n-k+1,n]$。 这些正是叶子存活的年份
