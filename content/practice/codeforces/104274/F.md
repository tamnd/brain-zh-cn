 ## 解决方案
 ## 问题理解

 我们正在处理一个隐藏的长度为二进制的数组$N$。 恰好有两个位置包含值 1，所有其他位置都包含 0。我们无法直接看到该数组。 相反，我们可以提出以下形式的查询：给我子段中的值的总和$[L, R]$。 每个答案都告诉我们两个隐藏的有多少个位于该段内。 

我们的任务是使用最多 50 个这样的范围和查询来识别索引所在的两个索引。 

关键的限制是$N$可以大到$10^6$，因此任何单独检查每个位置的方法都会太慢。 线性扫描需要$N$最坏情况下的查询，大大超出限制。 50 个查询的交互限制强烈建议采用对数策略，通常涉及二分搜索与精心设计的范围查询相结合。 

如果试图使用前缀和上的朴素二分搜索来独立定位这两个位置，而不考虑这两个位置对每个查询都有贡献的事实，就会出现微妙的失败情况。 例如，假设它们位于位置 3 和 10。如果我们尝试使用前缀和找到第一个，一切正常。 但是，如果我们尝试使用相同的逻辑查找第二个而不排除第一个找到的位置，则此后的每个查询仍然会受到已知位置的污染，并且二分查找条件变得不一致。 即使每个单独的查询都是正确的，这也会导致错误的分支和错误的答案。 

## 方法

 暴力破解的想法很简单：查询每个位置，直到找到返回 1 的两个索引。这是正确的，因为每个查询都会隔离一个位置，但它需要$N$最坏情况下的查询。 和$N = 10^6$，这立即超出了 50 个查询的限制，使其不可行。 

一个更结构化的想法是使用前缀和。 如果我们可以直接要求总和$[1, i]$，那么我们可以二分查找第一个前缀和为 1 的位置，即最左边的球。 这是可行的，因为前缀和是单调的。 找到第一个位置后$p_1$，可以通过排除找到第二个位置$p_1$来自未来的范围总和。 一旦我们可以模拟忽略已知索引的查询，其余结构再次表现得像单个隐藏结构，从而允许另一次二分搜索。 

关键的观察结果是，范围查询与一个索引的知识相结合足以模拟第二个索引的干净的二进制搜索空间。 每个查询都可以通过减去已知位置是否位于范围内来调整。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(N)$查询 |$O(1)$| 太慢了|
 | 调整查询的二分搜索 |$O(\log N)$查询 |$O(1)$| 已接受 |

 ## 算法演练

 我们维护对查询函数的访问，该函数返回任何段中隐藏的数量。 

### 第 1 步：找到第一个球

 我们对范围进行二分搜索$[1, N]$。 对于中点$mid$，我们要求总和$[1, mid]$。 如果答案至少为 1，则第一个球位于左半区，否则位于右半区。 我们缩小搜索范围，直到隔离出确切的索引$p_1$。 

正确性来自这样的事实：在第一次出现 1 时，前缀对具有单个已知阈值从 0 到 1 转换的二进制数组进行求和。 

### 第二步：准备寻找第二个球

 我们现在知道一个位置$p_1$。 对段的每个后续查询$[L, R]$可以解释为：$$\text{true\_sum}(L, R) = \text{query}(L, R) - [p_1 \in [L, R]]$$此修正消除了已发现的球的贡献。 

### 步骤 3：使用修改后的二分查找找到第二个球

 我们再次二分查找$[1, N]$。 对于每个中点$mid$，我们计算调整后的前缀和$[1, mid]$。 如果调整后的总和至少为 1，则第二个球位于左半区； 否则它位于右半部分。 这隔离了第二个位置$p_2$。 

这一调整可确保搜索行为就像数组中仅存在一个未知的 1 一样。 

### 步骤 4：输出两个位置

 我们按升序输出两个发现的索引。 

### 为什么它有效

 在二分搜索的每个阶段，决策谓词仅取决于前缀中是否至少有一个未见过的球。 在去除已发现位置的贡献后，该结构精确地简化为单 1 问题。 这保留了谓词的单调性，从而保证了二分搜索的正确性。 由于每个阶段隔离一个唯一的位置，因此该算法不能返回重复项或错过有效索引。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ask(l, r):
    print("?", l, r)
    sys.stdout.flush()
    return int(input().strip())

def find_one(exclude=-1):
    l, r = 1, n
    while l < r:
        mid = (l + r) // 2
        res = ask(l, mid)
        if exclude != -1 and l <= exclude <= mid:
            res -= 1
        if res >= 1:
            r = mid
        else:
            l = mid + 1
    return l

n = int(input().strip())

# find first position
p1 = find_one()

# find second position with exclusion
def ask_adj(l, r):
    res = ask(l, r)
    if l <= p1 <= r:
        res -= 1
    return res

l, r = 1, n
while l < r:
    mid = (l + r) // 2
    if ask_adj(l, mid) >= 1:
        r = mid
    else:
        l = mid + 1

p2 = l

if p1 > p2:
    p1, p2 = p2, p1

print("!", p1, p2)
sys.stdout.flush()
```该解决方案将交互分离到一个小的包装函数中`ask`，这确保每个查询都立即刷新。 第一个二分搜索使用原始前缀查询来定位一个球。 之后，通过减去已知位置的贡献来纠正每个查询，有效地恢复干净的单目标搜索空间。 第二个二分查找在结构上是相同的，但是在这个调整后的查询函数下运行。 

必须注意排除逻辑。 仅当已知索引位于查询范围内时才必须进行减法，否则调整将错误地减少计数并破坏单调性。 

## 工作示例

 考虑一个大小的数组$10$在位置上有隐藏的$3$和$7$。 

### 找到第一个位置

 我们对前缀和执行二分搜索：

 我们在位置 3 处汇聚。 

这表明前缀和由于单调增加而正确地隔离了第一次出现。

 现在$p_1 = 3$。 

| 步骤| 查询 | 原始回复 | 调整后的反应| 决定|

 ## 边缘情况

 一种边缘情况是两个球相邻。 在这种情况下，前缀查询从 0 变为 1，然后立即变为 2，但二分查找仅检查前缀和是否至少为 1，因此它仍然正确地隔离第一个索引，而不会被第二个索引混淆。 

另一种边缘情况是在第二次搜索期间第一个找到的索引恰好位于查询范围的边界。 排除逻辑确保仅在相关时才删除其贡献。 例如，如果$p_1 = 5$我们查询$[1,5]$，原始答案可能是 1 或 2，具体取决于包含内容，但精确减去 1 可以保留正确性并保持二元谓词单调。
