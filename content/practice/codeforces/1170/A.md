 ## 解决方案
 ## 问题理解

 每个查询给我们两个数字，每个查询隐藏一个由三个未知正整数构建的简单结构$a$,$b$， 和$c$。 从这三个值我们可以形成三个成对的和：$a+b$,$a+c$， 和$b+c$。 输入保证我们显示的两个数字对应于这三个和中的任何两个，但我们不知道缺少哪一对。 

任务是重建一个有效的三元组$(a,b,c)$可以产生给定的两个和。 在所有有效的三元组中，我们必须选择一个使总和最小的一个$a+b+c$，并且如果存在具有相同最小总数的多个，则其中任何一个都是可以接受的。 

每个查询都是独立的，因此必须对每对和从头开始重复重建过程。 

约束足够小，可以在恒定时间内解决每个查询。 最多可进行 1000 个查询，每个查询只需进行少量算术运算，任何$O(q)$或者$O(q \log q)$方法很容易就足够了。 重要的是重建的正确性，而不是优化。 

当两个给定的总和相等时，会出现微妙的边缘情况。 例如，如果输入是$x = y = 2$，很容易假设对称，但实际重建仍然需要确保所有变量保持正整数。 另一种边缘情况是当其中一个隐藏整数非常小（可能为 1）时，如果处理不当，就会影响分解的可行性。 

## 方法

 一个直接的暴力想法是猜测三个总和中的哪一个缺失，然后尝试解决所得到的系统。 如果我们假设我们知道所有三个成对的和，我们可以使用标准线性代数恢复变量：$$a = \frac{(a+b) + (a+c) - (b+c)}{2}, \quad
b = \frac{(a+b) + (b+c) - (a+c)}{2}, \quad
c = \frac{(a+c) + (b+c) - (a+b)}{2}.$$暴力版本将尝试丢失总和的所有可能性以及哪个输入值对应于哪个成对和的所有排列。 由于只有三个成对和，这导致每个查询的案例数量恒定，因此即使是简单的枚举也足够快。 

关键的见解是我们实际上不需要枚举任何东西。 问题的结构确保可以通过将两个给定总和中较大的一个视为表示两个最大变量加上适当重复的最小变量的总和来重建正确的配置。 一旦我们意识到最小总和要求强制一致的分配，其中最小值为 1，在标准化构造中，问题就会分解为一个简单的固定公式。 

我们可以不失一般性地假设两个给定总和中较小的一个对应于涉及最小变量的一对。 如果我们将最小的变量设置为1，我们可以直接通过减法重构另外两个，保证正数和最小总和。

 ## 算法演练

 我们有两个数字$x$和$y$，其中两个$(a+b, a+c, b+c)$。 我们需要产生任何有效的三重最小化$a+b+c$。 

### 步骤

 1. 阅读$x$和$y$。 我们首先确定哪个较小，哪个较大。 让$s = \min(x,y)$和$l = \max(x,y)$。 

这种区别很重要，因为较小的总和更有可能对应于涉及最小变量的对。 
2. 假设最小的变量是$c = 1$。 

这一选择最大限度地减少了总和并确保了正性而不失一般性，因为任何有效的解决方案都可以缩小到最小元素为 1 的解决方案，同时保持与给定总和的一致性。 
3. 使用$c = 1$，解释较小的总和$s$作为$a + c$，所以我们设置：$$a = s - 1$$这保证了$a > 0$因为$s \ge 2$。 
4. 解释较大的总和$l$作为$b + c$，所以我们设置：$$b = l - 1$$5、输出$(a, b, c)$。 这个三元组满足两个输入和：$a + c = s$和$b + c = l$。 

### 为什么它有效

 该构造强制将最小值固定为 1，从而最小化总和$a+b+c$。 一旦最小的变量被固定，每个给定的和唯一地确定其他两个变量。 因为我们一致地分配这两个总和，因为涉及$c$，我们保证有效性。 任何替代分配要么会增加最小变量，要么会与积极性产生不一致，因此它不能产生更小的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

q = int(input())
for _ in range(q):
    x, y = map(int, input().split())
    s = min(x, y)
    l = max(x, y)

    c = 1
    a = s - 1
    b = l - 1

    print(a, b, c)
```该代码在恒定时间内独立处理每个查询。 关键的实现细节是我们修复的标准化步骤$c = 1$，这避免了关于哪个和对应于哪个对的任何歧义。 

减 1 是安全的，因为两个输入总和至少为 2，确保所有重建值保持正值。

## 测试用例```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    q = int(input())
    out = []
    for _ in range(q):
        x, y = map(int, input().split())
        s = min(x, y)
        l = max(x, y)
        a = s - 1
        b = l - 1
        c = 1
        out.append(f"{a} {b} {c}")
    return "\n".join(out)

 ## 边缘情况

 当两个给定的总和相等时，算法将两者设置为$a$和$b$为相同的值。 用于输入$2,2$，我们计算$a = b = 1$,$c = 1$，产生完全对称的三元组。 这满足两个约束，因为所有成对总和等于 2。 

当两个总和相距很远时，例如$2$和$10^9$，构造仍然将较小的总和分配给$a+c$并且较大的到$b+c$。 和$c=1$，我们得到$a=1$和$b=10^9-1$，都是正数，并且两个原始和都被精确保留。
