 ## 解决方案
 ## 问题理解

 我们有一份学生名单，每个学生都有一定的编程技能水平。 任务是把这些学生最多分为`k`小组，使学生总数最大化。 每个团队必须“平衡”，这意味着同一团队中的两名学生在技能上的差异不能超过 5 个。 未分入团队的学生将被排除在计数之外。 

输入大小最多允许 5000 名学生，这意味着任何比 O(n²) 更差的算法都可能太慢，特别是如果我们考虑尝试所有可能的学生子集。 技能值本身可能很大，高达 10⁹，但实际技能值并不像它们的相对差异那么重要，因为团队的形成取决于差异，而不是绝对值。 

一个简单的解决方案可能会考虑每个团队的所有学生子集，但这会导致组合爆炸。 当学生都紧密聚集（允许组成一个大团队）或当许多学生分布广泛时，就会出现边缘情况，迫使小团队或没有团队。 例如，如果`n = 5, k = 2, a = [1, 2, 15, 15, 15]`，最佳方法形成一个小团队`[1,2]`和一支庞大的团队`[15,15,15]`，共 5 名学生。 仅按顺序建立团队的粗心贪婪方法可能会因形成次优的早期团队而错过全局最优。 

## 方法

 蛮力方法将尝试将所有可能的学生分为最多`k`组。 为了检查每个团队的有效性，我们将验证子集中最小和最大技能之间的差异不超过 5。这种方法之所以有效，是因为它正确地计算了平衡子集，但组合数量增长为 2ⁿ，这对于 n = 5000 来说是完全不可行的。 

关键的见解是按技能对学生进行分类。 一旦排序，任何有效的团队都必须由连续的学生组成，因为在技能较高的学生之前添加技能较低的学生会违反技能差异约束。 这使我们能够将该问题视为区间划分的变体。 那么，动态规划自然适合：让`dp[i]`代表第一组中平衡团队中学生的最大数量`i`学生。 对于每个职位，我们都会考虑组建一个以该学生为终点的团队，并在技能差异允许的范围内向后延伸。 

我们可以通过两个指标来优化团队组建： 对于学生`i`，找到最远的`j`向左，这样之间的技能差异`a[i]`和`a[j]`最多为 5。这告诉我们最大可能的平衡团队结束于`i`。 然后，`dp[i]`是不包括的最大值`i`（采取`dp[i-1]`）或包括团队`[j..i]`并将其添加到`dp[j-1]`。 尊重限制`k`团队，我们使用辅助 DP 维度或跟踪形成的团队数量。 由于团队数量最多为 5000 个，如果我们按照技能递增的顺序贪婪地处理团队，那么简单的一维 DP 就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2ⁿ * n) | O(2ⁿ * n) | O(n) | 太慢了 |
 | 最优（排序+DP+两个指针）| 最坏情况为 O(n²)，但每次指针前进实际上为 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对学生技能数组进行排序。 这可确保最大差值 ≤ 5 的任何连续段都是有效团队。 排序还允许我们有效地使用两个指针。 
2.初始化一个DP数组`dp`长度`n+1`， 在哪里`dp[i]`存储第一组中平衡团队中学生的最大数量`i`学生。 放`dp[0] = 0`。 
3. 对于每个学生`i`从 1 到`n`, 使用指针`j`从数组的开头开始找到最左边的学生，这样`a[i] - a[j] <= 5`。 这确定了最大的团队结束于`i`。 
4. 更新`dp[i]`作为之间的最大值`dp[i-1]`（不包括学生`i`） 和`dp[j-1] + (i - j + 1)`（与来自以下国家的学生组成团队`j`到`i`）。 
5. 重复直到`i = n`。 最终的答案是`dp[n]`，可以放置在平衡团队中的最大学生人数。 

为什么有效：排序保证任何有效的团队都对应于连续的子数组。 DP 循环检查以 结束的团队的所有可能的左端点`i`有效地使用两指针方法。 每个`dp[i]`存储第一个的最优解`i`学生，确保之前做出的决定得到最佳采纳。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort()

dp = [0] * (n + 1)
j = 0

for i in range(1, n + 1):
    while a[i - 1] - a[j] > 5:
        j += 1
    # max between not using this student or using the largest valid team ending here
    dp[i] = max(dp[i - 1], dp[j] + (i - j))

print(dp[n])
```这段代码首先对技能进行了排序。 变量`j`是以学生结束的有效团队的两点左边界`i`。 DP 数组累积了包含的最佳学生数量。 这`while`循环确保我们缩小左边界，直到团队变得有效。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()
    dp = [0] * (n + 1)
    j = 0
    for i in range(1, n + 1):
        while a[i - 1] - a[j] > 5:
            j += 1
        dp[i] = max(dp[i - 1], dp[j] + (i - j))
    return str(dp[n])

# provided sample
assert run("5 2\n1 2 15 15 15\n") == "5"

# minimum input
assert run("1 1\n10\n") == "1"

# all equal
assert run("4 2\n5 5 5 5\n") == "4"

# sparse skills
assert run("5 2\n1 10 20 30 40\n") == "1"

# max k less than optimal splits
assert run("6 3\n1 2 3 4 12 13\n") == "6"
