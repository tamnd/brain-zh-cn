 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，一个序列`0`沙`1`s，我们被要求将其划分为连续的子字符串，以便子字符串稍后可以重新排列以形成排序的二进制字符串，这意味着所有`0`s出现在所有之前`1`s。 任务是尽量减少此类碎片的数量。 每块必须包含连续的字符，并且不能跳过或重复使用任何字符。 

例如，字符串`11010`可以切成三块`11`,`0`,`10`。 将它们重新排列为`0`,`10`,`11`给出`00111`，一个排序的字符串。 这是最优的； 少于三块无法实现排序序列。 

输入大小允许字符串最大长度为 500，以及最多 500 个测试用例。 检查每个可能的分区的简单解决方案将是字符串长度的指数，这是完全不可行的。 任何方法都必须在每个字符串上运行大约 O(n) 或 O(n^2) 才能轻松满足 2 秒的限制。 

边缘情况包括已排序的字符串、具有所有相同字符的字符串或只有一个字符的字符串`0`或者`1`不合适。 一个简单的实现，只计算之间的转换`0`和`1`可能会在类似的模式上失败`0101`，其中最佳切割计数更加微妙。 

## 方法

 暴力方法将尝试每一种可能的切割，然后检查结果片段的某些排列是否已排序。 对于长度为 n 的字符串，有 2^(n-1) 个可能的切割位置。 每次排列检查都会花费额外的时间，因此整体复杂度呈指数级增长，并且对于 n 达到 500 时完全不切实际。 

减少问题的关键是要注意所需的最小块数与连续块的数量密切相关。`0`沙`1`s 及其顺序。 具体来说，字符串最多可以分为三部分以形成一个排序字符串：其中一个包含前缀`1`s 在任何之前`0`, 中间一块覆盖`01`转换，以及一个后缀`0`s 之后任何`1`。 这是通过分析模式得出的：

 - 如果字符串已经排序（`000...111`），单件就足够了。 
- 如果恰好有一个`01`或者`10`过渡乱了，两块就够了。 
- 如果有多个`01`和`10`过渡以非平凡的交​​替模式发生，需要三个部分。 

因此，我们可以通过计数来解决这个问题`01`和`10`转换并应用简单的案例区分，而不是探索所有分区。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n!) | O(2^n * n!) | O(n) | 太慢了 |
 | 最佳 | 每个字符串 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取二进制字符串`s`对于每个测试用例。 
2. 初始化两个标志：`has01`和`has10`，它跟踪字符串是否包含`01`图案或`10`图案。 
3. 从左到右迭代字符串。 对于每对连续字符：如果`s[i] == 0`和`s[i-1] == 1`， 放`has10 = True`; 如果`s[i] == 1`和`s[i-1] == 0`， 放`has01 = True`。 
4.循环结束后，确定最小块数：如果都没有`has01`也不`has10`为 True，则字符串已排序，返回 1。如果只有一个为 True，则返回 2。如果两者都为 True，则返回 3。 

为什么有效：该算法本质上是识别是否存在混合运行`0`沙`1`需要分离才能实现排序的字符串。 如果只有一种类型的过渡，则一次剪切就足够了。 如果两种转变都存在，我们需要更复杂的三部分重新排列。 这种方法捕获所有边缘情况并保证最小的削减而无需详尽的枚举。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    has01 = has10 = False
    for i in range(1, len(s)):
        if s[i-1] == '0' and s[i] == '1':
            has01 = True
        elif s[i-1] == '1' and s[i] == '0':
            has10 = True
    if not has01 and not has10:
        print(1)
    elif has01 and has10:
        print(3)
    else:
        print(2)
```该解决方案读取测试用例的数量，然后对于每个字符串，检查相邻对以检测`01`和`10`过渡。 这些标志直接映射到最小切割计数。 使用`strip()`确保没有换行符干扰字符串处理。 使用`has01`和`has10`避免不必要地计算多个转换； only the presence matters.

    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output

    for _ in range(t):
        s = input().strip()
        has01 = has10 = False
        for i in range(1, len(s)):
            if s[i-1] == '0' and s[i] == '1':
                has01 = True
            elif s[i-1] == '1' and s[i] == '0':
                has10 = True
        if not has01 and not has10:
            print(1)
        elif has01 and has10:
            print(3)
        else:
            print(2)
    return output.getvalue().strip()

# Provided samples

 ## 边缘情况

 该算法正确处理单字符字符串。 为了`s = "1"`，不存在任何跃迁，所以`has01 = has10 = False`，输出为 1。对于像这样的字符串`0101`，第一个`01`套`has01 = True`，下一个`10`套`has10 = True`，导致输出3。已经排序的字符串，例如`0000`或者`1111`，永远不会触发任何一个标志，正确生产 1 件。 两者的检测`01`和`10`确保我们捕获需要三部分的不平凡的交替模式，如果我们只计算转换而不区分它们的类型，就会失败。
