 ## 解决方案
 ## 问题理解

 该任务要求我们读取小整数对并按排序顺序输出每对：首先是较小的数字，然后是较大的数字。 每个测试用例由两个整数组成，$x$和$y$，并且输入以数字开头$t$代表我们需要处理多少个这样的对。 输出必须包含每个测试用例相应的排序对。 

约束非常严格：两个整数都在 0 到 9 之间，并且最多可以有 100 个测试用例。 因为数字很小，所以我们不需要复杂的数据结构或排序算法。 该算法只需要确定两个整数中哪个较小，哪个较大，每个测试用例进行一次比较。 

当两个整数相等时，会出现不明显的边缘情况。 例如，如果输入对是$3$和$3$，输出必须是$3 3$。 一种幼稚的方法，仅在以下情况下进行交换$x > y$此处工作正常，但忘记相等情况或尝试基于减法的技巧可能会导致不正确的结果。 另一个较小的边缘情况是当两个数字都为零时，这也需要输出$0 0$。 

## 方法

 在这种情况下，暴力方法已经是最佳选择。 对于每一对，您比较$x$和$y$。 如果$x > y$，你交换它们； 否则，请保持原样。 此方法是正确的，因为每对只有两个元素，并且一次比较就足以对它们进行排序。 最坏情况输入（有 100 个测试用例）的操作计数是 100 次比较，这是微不足道的。 

不需要更先进的技术，例如完全排序，因为问题的规模和结构使得单一比较方法既简单又高效。 关键的见解是认识到对两个数字进行排序只是比较和条件分配，大型排序机器将是不必要的开销。

 ## 算法演练

 1.读取整数$t$代表测试用例的数量。 这设置了我们将执行的迭代次数。 
2. 对于每个测试用例，读取两个整数$x$和$y$。 
3. 比较两个整数。 如果$x > y$，交换它们的值。 这保证了$x$始终是较小或相等的数字。 
4. 打印$x$和$y$按顺序排列，用空格隔开。 这是所需的输出格式。 
5. 对所有测试用例重复步骤 2-4。 

为什么它有效：整个算法中保持的不变性是，在比较和可能的交换之后，该对的第一个数字永远不会大于第二个数字。 由于输出规范仅要求该对处于非递减顺序，因此该不变量确保了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    if x > y:
        x, y = y, x
    print(x, y)
```代码首先读取$t$使用`input()`。 循环完全运行$t$次，每次迭代处理一个测试用例。`map(int, input().split())`解析每行的两个整数。 有条件交换确保较小的数字优先，并且`print(x, y)`正确输出它们。 由于 Python 本身处理小整数，因此不需要特别考虑边界或溢出。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        if x > y:
            x, y = y, x
        print(x, y)

 ## 边缘情况

 当两个数相等时，例如`3 3`，算法对它们进行比较。 既然条件`x > y`为 false，则不会发生交换。 打印输出保留`3 3`，这是正确的。 对于输入`0 0`，应用相同的逻辑，保持第一个数字永远不会大于第二个数字的不变性。 对于最大边界输入，例如`9 0`，交换保证了输出`0 9`。 该算法能够一致地处理所有场景，因为它依赖于单一、简单的比较。
