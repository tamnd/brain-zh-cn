 ## 解决方案
 ## 问题理解

 给定两个长度相等的二进制序列，`s`和`t`。 Vanya 可以执行特定操作`s`重复：他从位置选择一个连续的子数组`l`到`r`，并且对于每个位置`i`在该子数组中，替换`s[i]`和`s[i] XOR s[i - l + 1]`。 目标是确定是否可以使用任意数量的这些操作来转换`s`进入`t`。 

第一个关键观察结果是该操作在位上完全是线性的。 当且仅当存在至少一个时，每一位都可以被翻转`1`在可以通过 XOR 传播的前缀中。 如果第一个元素是`0`，它永远不会直接影响后面的位。 反之，如果至少有一个`1`在`s`，我们可以通过适当的操作传播它来翻转其他位。 

输入约束允许最多的序列`2·10^5`每个测试用例的位数，并且跨测试用例的所有序列长度的总和也最多为`2·10^5`。 这意味着我们需要一个`O(n)`每个测试用例的解决方案。 任何尝试直接模拟操作的解决方案，尤其是通过嵌套循环，都会太慢。 边缘情况出现时`s`全为零或序列长度为 1，因为在这些情况下不可能进行异或传播。 

尝试模拟操作的粗心实现可能会在输入上失败，例如`s = 0`和`t = 1`，因为没有任何操作可以将单个零更改为一。 

## 方法

 蛮力方法将尝试模拟所有可能的异或运算`(l, r)`反复配对，直到`s`等于`t`。 原则上这是可行的，因为操作是确定性的并且仅限于有限的位置。 不过，大致有`O(n^2)`每个操作成对，并且可能有许多重复操作，导致最坏情况的复杂性`O(n^3)`或者更糟。 对于最大的约束（`n ≈ 2·10^5`），这是完全不可行的。 

关键的见解是每一位`s`如果至少有一个，则只能通过 XOR 影响后面的位`1`在它之前。 具体来说，索引处的操作`i`只能翻转一个`0`到`1`（或反之亦然）如果存在至少一个`1`在前缀中`s[0..i-1]`。 因此，只有当`s`全部为零并且`t`至少包含一个`1`。 否则，游戏是“有趣的”，因为我们可以建设性地传播现有的游戏来匹配`t`。 

这将问题简化为一个简单的检查：如果`s`全部为零并且`t`不是，打印“否”。 如果第一个元素`s`等于第一个元素`t`并且至少有一个`1`某处`s`，或者如果序列相同，则打印“Yes”。 这种方法是`O(n)`每个测试用例并且在时间限制内舒适地适合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取长度`n`和序列`s`和`t`。 
2.如果`s`等于`t`已经，输出“是”并继续。 无需任何操作。 
3. 数一下数量`1`进入`s`。 如果没有（`count_1 == 0`） 和`t`至少包含一个`1`，输出“否”。 将零翻转为一是不可能的。 
4. 否则，检查第一位是否`s`是`0`和第一点`t`是`1`。 如果是，则输出“No”，因为第一个位置永远不能从`0`到`1`没有先前的传播。 
5. 在所有其他情况下，输出“Yes”。 至少有一个`1`传播并达到任何所需的配置`t`。 

为什么它有效：不变的是任何位置`i`仅当存在至少一个时才可以翻转`1`在前缀中`s[0..i-1]`。 通过计数`1`s 并检查第一个元素，我们捕获了阻止的所有约束`t`从可实现的。 其余部分由异或传播的构造性质保证。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    q = int(input())
    for _ in range(q):
        n = int(input())
        s = input().strip()
        t = input().strip()
        
        if s == t:
            print("Yes")
            continue
        
        if '1' not in s:
            if '1' in t:
                print("No")
            else:
                print("Yes")
            continue
        
        if s[0] == '0' and t[0] == '1':
            print("No")
        else:
            print("Yes")

if __name__ == "__main__":
    main()
```该解决方案首先检查相等性以立即处理简单的情况。 计数为`1`进入`s`标识是否可以进行任何异或运算。 对第一位的检查可确保尊重无法更改的位置。 所有步骤都运行在`O(n)`每个测试用例。

 ## 边缘情况

 一个关键的边缘情况是当`s`开始于`0`和`t`开始于`1`。 例如，`s = 0xxxx`和`t = 1xxxx`。 在这种情况下，任何操作都无法更改第一位`0`到`1`，因为 XOR 取决于前一个。 该算法正确返回“否”。 另一个边缘情况是当`s`恰好有一个`1`位于第一位之后，并且`t`需要翻转较早的位。 该解决方案之所以有效，是因为对于此传播检查来说，只有第一位很重要； 一旦有一个，任何后面的位都可以传播`1`。
