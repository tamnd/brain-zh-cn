 ## 解决方案
 ## 问题理解

 我们得到一个网格，其中已经包含从 1 到$n \cdot m$恰好一次，以某种任意顺序排列。 任务是使用同一组数字构建另一个相同维度的网格，以便没有数字保留在其原始单元格中。 每个值都必须重复使用一次，但每个位置必须接收与以前不同的值。 

这从根本上来说是一种全局重排约束，而不是局部重排约束。 每个单元格强加一个单一的禁止选择，即其原始值，但所有其他值都是允许的。 困难不在于为单个单元格选择值，而在于确保全局分配仍然使用每个数字一次。 

每个测试用例的约束都很小，$n, m \le 10$，但最多可以有$10^3$测试用例。 所有测试的元素总数最多为$5 \cdot 10^4$，所以一个$O(nm)$或者$O(nm \log nm)$每次测试的构建就足够了。 每个测试用例的任何二次方仍然会通过，但不需要不必要的复杂性。 

出现微妙的失败情况时$n \cdot m = 1$。 对于只有一个单元格的情况，唯一可能的分配是原始值，这违反了条件。 所以根据定义，这种情况是不可能的。 

另一种结构边缘情况是当网格非常小但不是 1 时。任何构造都必须确保全局排列有效性，因此简单的局部交换可能会意外地重用值或留下固定点。 

## 方法

 一个蛮力的想法是生成所有排列$n \cdot m$数字并检查是否有任何排列避免相对于原始网格的固定点。 这在概念上很简单：我们尝试每种可能的分配并逐个单元地验证约束。 然而，排列的数量呈阶乘增长，即使对于像这样的中等大小，这也立即变得不可行$10!$或者$20!$，并且完全不可能$50{,}000$测试中的总元素。 

关键的观察是我们实际上并不需要复杂的排列。 我们只需要任何混乱，即没有元素保留在其原始位置的排列。 由于所有值都是不同的，因此我们可以将网格展平为列表，确定性地重新排列它，然后将其映射回来。 

一种简单而有效的构造是将展平的阵列旋转一个位置。 如果我们按行优先顺序列出元素$a[0], a[1], \dots, a[k-1]$，然后定义$b[i] = a[(i+1) \bmod k]$。 这保证了每个元素都会远离其原始索引，除非$k=1$。 旋转保留双射并仅使用每个数字一次。 

唯一失败的时候是$k = 1$，因为旋转将单个元素映射到其自身。

 | ---| ---| ---| ---|
 | 蛮力 |$O((nm)!)$|$O(nm)$| 太慢了 |
 | 旋转施工|$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 1. 读取网格并将其按行优先顺序展平为单个列表。 这将 2D 约束转换为 1D 排列问题，而不改变值的结构。 
2.让$k = n \cdot m$。 如果$k = 1$,立即输出$-1$因为不存在有效的重排。 没有其他值可以放置在唯一的单元格中。 
3. 通过将每个元素向前移动一位来构造一个新列表：对于每个索引$i$,从位置赋值$(i+1) \bmod k$。 这确保了所有元件的循环运动。 
4. 将结果列表重新整形为$n \times m$矩阵并以行优先形式输出。 

### 为什么它有效

 该构造是所有元素的循环排列。 每个元素都会移动到不同的索引，因为每个位置都会接收循环中的下一个元素，并且在长度大于 1 的循环中没有映射到自身的索引。 由于映射是双射的，因此每个数字在输出中只出现一次，并且由于每个元素都会移动，因此没有位置保留其原始值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out_lines = []

    for _ in range(t):
        n, m = map(int, input().split())
        arr = []
        for _ in range(n):
            arr.extend(map(int, input().split()))

        k = n * m
        if k == 1:
            out_lines.append("-1")
            continue

        shifted = arr[1:] + arr[:1]

        idx = 0
        for i in range(n):
            row = shifted[idx:idx + m]
            out_lines.append(" ".join(map(str, row)))
            idx += m

    print("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```该解决方案首先展平矩阵，使索引变得线性，从而简化排列逻辑。 特殊情况检查$k = 1$是必要的，因为任何排列都被迫固定唯一的元素。 

关键的实现细节是基于切片的旋转`arr[1:] + arr[:1]`，它执行一步循环移位。 这保证了任何大于 1 的尺寸的有效混乱，而不需要显式的位置跟踪。 

最后，逐行重建列表，保留所需的输出格式。

 ## 边缘情况

 结构上唯一危险的情况是网格仅包含一个元素。 在这种情况下，展平会产生一个单值数组，而循环移位将返回相同的数组。 该算法显式检查这一点并立即返回 -1。 

对于 1×1 输入：```
1
1
```产量趋平`[1]`。 旋转步骤将产生`[1]`，违反条件。 尺寸检查可以防止这种情况并确保正确性。 

所有其他情况的长度至少为 2，并且循环移位总是会产生混乱，因为在长度大于 1 的完整循环下没有索引保持固定。
