 ## 解决方案
 ## 问题理解

 给定一个正整数数组，我们想知道是否可以选择三个不同的元素，其总和以数字 3 结尾。换句话说，如果我们将所选元素表示为$a_i$,$a_j$， 和$a_k$， 然后$(a_i + a_j + a_k) \mod 10 = 3$。 输入由多个测试用例组成，每个测试用例指定数组大小和元素本身，如果存在这样的三元组，则输出为“YES”，否则输出为“NO”。 

约束允许最多$2 \cdot 10^5$所有测试用例的总元素。 一个简单的三重嵌套循环会检查$O(n^3)$每个测试用例的组合，这显然是不可行的，因为$n^3$可以达到$10^{15}$最坏情况下的操作。 甚至$O(n^2)$对于最大的阵列来说，方法会太慢。 因此，我们需要一种避免直接迭代每个可能的三元组的策略。 

出现一个微妙之处是因为总和只涉及最后一位数字。 例如，在数组中$[11, 12, 13]$，所有三元素三元组模 10 的和仅由数字确定$[1, 2, 3]$。 这表明我们可以将问题简化为使用每个元素的最后一位数字而不是它们的完整值，这大大减少了不同可能性的数量。 另一个需要考虑的边缘情况是存在多个相同的数字。 例如，一个数组$[10, 10, 10]$总和为 30，以 0 结尾，而不是 3。粗心的实现可能会错误地认为使用重复的数字总是有帮助，但索引必须不同。 

## 方法

 暴力解决方案很简单：迭代三个不同索引的每个组合，并检查它们的总和是否以 3 结尾。这种方法保证是正确的，因为它显式测试了所有可能性，但由于以下原因，它对于大型数组会失败$O(n^3)$复杂。 例如，与$n = 2000$，这大约需要$1.3 \cdot 10^9$检查，这超出了典型的时间限制。 

关键的见解是只有每个数字的最后一位数字会影响结果。 由于数字范围从 0 到 9，我们可以将数组缩减为每个最后一位数字最多出现 3 次的列表。 没有必要使用三个以上具有相同最后一位数字的数字，因为任何有效的三元组最多可以使用三个副本来形成。 这将候选元素的数量减少到最多 30 个。 在减小的尺寸下，我们可以安全地应用三重嵌套循环，因为$30^3 = 27,000$每个测试用例的操作是可以接受的。 

该解决方案的故事是这样的：蛮力可以工作，但由于数组大小很大，速度很慢。 通过观察问题只关心最后一位数字，我们可以安全地丢弃冗余数字并将数组减小到可管理的大小，而不会丢失任何有效的三元组。 这使我们能够有效地将简单性和正确性结合起来。

 ## 算法演练

 1. 对于每个测试用例，读取数字数组。 
2. 使用模 10 将每个数字转换为其最后一位数字。 
3. 建立一个列表，每个最后一位数字最多包含三个数字。 此步骤确保我们不会丢失任何总和为最后一位数字 3 的三元组，因为使用三个以上相同数字无法创建新的模 10 之和。 
4. 枚举缩减列表中的所有三元组。 对于每个三元组，计算其元素的总和以 10 为模。 
5. 如果任何三元组之和为以 3 结尾的数字，则立即对该测试用例输出“YES”并移至下一个。 
6. 如果在检查所有可能性后没有找到有效的三元组，则输出“NO”。 

工作原理：每个最后一位数字的总和可能为 3 的三个数字的组合保证最多包含每个最后一位数字的三个实例。 通过每个数字仅保留三个元素，我们不会删除任何候选三元组。 模运算确保我们只关注每个数字的相关部分，并且迭代缩减集中的所有三元组保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        digits = [[] for _ in range(10)]
        for num in a:
            d = num % 10
            if len(digits[d]) < 3:
                digits[d].append(d)
        
        candidates = []
        for lst in digits:
            candidates.extend(lst)
        
        found = False
        m = len(candidates)
        for i in range(m):
            for j in range(i+1, m):
                for k in range(j+1, m):
                    if (candidates[i] + candidates[j] + candidates[k]) % 10 == 3:
                        found = True
                        break
                if found:
                    break
            if found:
                break
        
        print("YES" if found else "NO")

solve()
```该解决方案首先按最后一位数字对数字进行分组，并将每组截断为三个元素。 这确保了保留所有可能的最后一位三元组，同时保持候选集较小。 然后，三重嵌套循环显式检查模 10 的和，避免索引出现任何偏一错误。 在正确的时刻使用模可以防止大数的整数溢出问题。
