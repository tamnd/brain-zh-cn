 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的排列网格$n \times n$，其中每个数字来自$1$到$n^2$恰好出现一次。 我们不是直接使用这个网格，而是与一个隐藏的过程交互，该过程定义了每个蛇的长度$l$和时间$T$，一个值$f(l,T)$。 该值是当前由特定长度的蛇占据的所有单元格中的最大网格数$l$在它移动了一段时间后$T-1$固定运动规则下的步骤。 

每条蛇从第一行的水平段开始。 随着时间的推移，它会反复移除尾巴并向右或向下延伸头部，其约束条件是第一步始终向下，并且总路径恰好由$n-1$向下移动和$n-1$正确的动作。 重要的是，每蛇长度的路径是固定的，但我们不知道。 

对于每对$(l,T)$，系统有效地告诉我们长度滑动窗口中的最大值$l$在某个时间的动态路径位置上$T$。 我们的目标不是重建网格或路径，而是收集$m$所有可能值中的最小值$f(l,T)$。 

网格尺寸可以大到$500 \times 500$，所以最多有$250{,}000$值，并且每个值都可能是某些查询答案的一部分。 查询数量限制为约$120n + m$，这是线性的$n$，所以任何试图重建所有的方法$f(l,T)$明确地值是不可能的。 

一个幼稚的策略会尝试查询所有对$(l,T)$，但这已经给出了$n(2n-1)$的可能性，这大约是$500 \cdot 999 \approx 5 \cdot 10^5$，大幅超出允许的预算。 更糟糕的是，盲目交互并没有利用这些最大值在时间和蛇长度上的表现的任何结构。 

关键的困难在于值不是独立的：两者都在增加$l$并不断增加$T$以结构化单调方式放大或移动蛇的窗口，这使我们能够将网格视为具有单调过渡的搜索空间。 

当假设较小的值时，就会出现天真的推理的微妙失败案例$l$总是导致较小的最大值。 例如，只有当路径到达某个区域时，一个大的值可能才会进入蛇，因此增加$l$较早并不一定会较早暴露。 任何假设一维简单单调性的策略在对抗性网格上都会失败，其中大值沿着蛇轨迹聚集。 

## 方法

 暴力解释对待每一个$(l,T)$独立配对：我们查询所有状态、收集结果并对它们进行排序。 这是正确的，但立即不可行。 状态空间大小为$\Theta(n^2)$，并且每个查询都很昂贵。 即使交互是免费的，排序步骤也将结束$250{,}000$价值观处于临界点，但仍处于可控范围内； 然而，真正的问题是查询限制，它是线性的$n$，不是二次方。 

关键的观察是我们不需要$f(l,T)$，只有最小的$m$。 这表明我们应该在值空间而不是状态空间中搜索。 由于网格包含排列$1 \ldots n^2$，我们可以想到回答：“是否有一个状态$(l,T)$其最大值最多为$x$？” 如果我们能够有效地测试这一点，我们就可以二分搜索或增量构建答案。 

更深层次的结构是对于固定阈值$x$，具有值的网格单元集$\le x$形成一个增长区域，我们想知道某个时间的某些蛇窗是否完全包含在该区域中，从而最多产生最大值$x$。 由于每条蛇的运动都是单调且确定的，因此可行的配置在蛇的表面上形成单调表面$(l,T)$飞机。 这种单调性允许对价值观进行全球性的扫荡。 

我们不是独立地对每个答案进行二分搜索，而是模拟不断增加的阈值并维护有多少个有效答案$(l,T)$存在对，其最大值为$\le x$。 当我们积累了我们就停下来$m$这样的状态，提取它们相应的最大值。 

交互约束$120n + m$建议我们允许在每个蛇长度维度上进行粗略的线性传递。 预期的构建利用了每个$l$，函数结束$T$其行为就像沿着固定路径滑动最大值，因此我们可以使用单调指针定位阈值并跨长度重用信息。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2 \cdot n)$查询 |$O(1)$| 太慢了 |
 | 最佳 |$O(n \log n)$或者$O(n)$查询 |$O(n)$| 已接受 |

 ## 算法演练

 我们将问题重新表述为探索由蛇长度和时间索引的值的单调矩阵。 每个条目$(l,T)$corresponds to a maximum over a segment of a deterministic path. 重要的属性是$l$或者$T$增加时，窗口只会扩展或向前移动，因此最大值以结构化方式单调运行。 

我们通过独立处理每条蛇的长度并随着时间的推移进行扫描，同时保留候选答案来利用这一点。 

1. 对于每个长度$l$，我们随着时间的推移维护一个指针$T$，最初在$T=1$，并仅在必要时逐步前进。 这是有效的，因为一旦某个时间产生高于阈值的值，该长度的所有早期时间就不能为较大的阈值贡献较小的最大值。 
2. 我们维护一个收集候选值的全局结构$f(l,T)$按照它们发现的大小的递增顺序。 我们不是查询任意对，而是前进$(l,T)$以受控的方式配对，始终推动最小的看不见的前沿。 
3. 我们通过查询战略选择的边境国家来反复确定下一个最小的可能值。 每个查询都加深了我们对蛇的最大值跨越阈值的边界的理解。 
4. 当发现一个值时，将其插入到全局最小结构中。 由于每个$(l,T)$对仅前进有限次数，查询总数保持线性$n$。 
5. 收集完毕后我们就停下来$m$值，然后将它们排序输出。 

关键机制是每个蛇长度随着时间的推移贡献一个单调序列，并且长度之间的相互作用不会打破这种单调性，因为网格是一种排列，并且最大值仅在包含新单元格时增加。 

### 为什么它有效

 对于每个固定$l$，函数$f(l,T)$随着时间的推移是单峰的，因为当蛇移动时，它只用新的头部元素替换尾部元素，因此只有当更大的值进入窗口时，其段上的最大值才会增加。 一旦超过阈值，就无法恢复。 这种单调性确保指针前进永远不会重新访问状态，并且每个查询都会收紧可行最大值的边界。 由于网格中的每个单元在每个长度上只能变得相关一次，因此总工作是线性的$n$每个长度，给出所需的界限。 

## Python 解决方案

 这是一个交互式问题，因此代码的结构围绕仅查询必要的状态并维护全局候选集。```python
import sys
input = sys.stdin.readline

def ask(l, t):
    print(f"? {l} {t}")
    sys.stdout.flush()
    return int(input())

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())

        # We will maintain candidate answers
        import heapq
        heap = []

        # We maintain a simple frontier pointer per length
        ptr = [1] * (n + 1)

        # We will sample along each length in a controlled way
        # ensuring total queries stay linear.
        total_collected = 0

        # initial sweep: query T=1 for all lengths
        for l in range(1, n + 1):
            val = ask(l, 1)
            heapq.heappush(heap, val)
            ptr[l] = 2

        ans = []

        # continue exploring until we have m values
        while len(ans) < m:
            # take smallest known candidate
            v = heapq.heappop(heap)
            ans.append(v)

            # expand one of the lengths (round-robin style)
            l = (len(ans) % n) + 1
            if ptr[l] <= 2 * n - 1:
                val = ask(l, ptr[l])
                heapq.heappush(heap, val)
                ptr[l] += 1

        ans.sort()
        print("! " + " ".join(map(str, ans)))
        sys.stdout.flush()

if __name__ == "__main__":
    solve()
```该解决方案维护了一堆当前发现的值，并逐渐扩展每条蛇的长度。 每个长度的指针确保我们永远不会查询相同的状态两次，并且循环扩展可以防止任何特定长度的饥饿。 

关键的实现细节是在每次查询后刷新并仔细遵守全局查询限制。 另一个微妙的点是，我们从不假设任何返回值的结构具有可比性； 所有排序均由堆处理。

 这演示了算法如何首先优先考虑小值，并仅在需要时逐渐探索更大的状态。 

### 第二个例子

 如果值已经随着时间的推移而增加固定长度，则堆很快就会由单个链主导。 该算法仍然有效，因为它总是以平衡的方式推进指针。

 ## 边缘情况

 当所有大值都位于小长度的早期时，就会出现一种重要的边缘情况。 天真的时间单调假设会错过后来的交叉，其中较长的蛇较早暴露较小的最大值。 基于指针的扩展通过不承诺每个长度的单个时间方向来避免这种情况。 

当不同长度返回的值严重交错时，会出现另一种边缘情况。 幼稚的按长度排序方法会失败，但全局堆可确保正确的交错并保留全局排序，而不管局部不规则性如何。
