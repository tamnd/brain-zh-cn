 ## 解决方案
 ## 问题理解

 我们被要求处理正整数序列。 对于任意连续的子序列$b$一个序列的$a$，有一个成本的概念：它是最后一个元素的上限$b$除以所有元素中的最小值$b$。 那么对于任意序列$c$，我们定义$f(c)$作为通过划分可获得的最小成本总和$c$到一个或多个连续的子数组中。 目标是计算所有连续的子序列$a$，总和$f(b)$。 

输入由多个测试用例组成，每个测试用例都有一个长度可达的序列$4 \cdot 10^5$，以及总和$n$所有测试用例不超过$4 \cdot 10^5$。 鉴于我们可能需要考虑所有连续的子序列，一个朴素的方法$O(n^3)$接近我们计算的地方$f(b)$对于每个子序列都是不可行的。 甚至$O(n^2)$每个测试用例都会太慢，因为$n^2$可以达到$1.6 \cdot 10^{11}$。 这强烈暗示我们需要一个$O(n \log n)$或者$O(n)$每个序列的方法。 

例如，当元素变化很大时，就会出现一个重要的边缘情况$[1, 10^{18}]$。 不正确处理整数除法和上限的粗心解决方案会错误计算成本。 另一个微妙之处是，最佳划分可以将序列分割成多个段以降低成本。 例如，$[3,1,4]$应分区为$[3,1],[4]$以最小的成本，而不是保持完整。 

## 方法

 蛮力方法将生成每个连续的子序列$b$的$a$并计算$f(b)$使用动态规划。 对于长度的子序列$k$，一个天真的 DP 会考虑每个分割点，给出$O(k^2)$每个子序列。 因为连续子序列的个数是$\frac{n(n+1)}{2}$，这导致$O(n^3)$总体而言，这显然是不可能的$n \sim 4 \cdot 10^5$。 

关键的观察是$f(b)$有一个特定的结构：如果我们从左到右处理一个子序列，则最佳划分由遇到的最小元素和最后一个元素决定。 让我们表示为$dp[x]$以位置结束的子序列的最小总成本$i$用最少的元素$x$。 当我们迭代时，新元素要么扩展现有段，要么开始一个新段。 使用单调堆栈或映射来跟踪候选最小值，我们可以合并具有相同最小值的区间以保持状态较小。 关键的见解是，尽管有许多连续的子序列，但可能的最小值的集合相对有限，允许$O(n \log n)$每个序列的处理。 

这导致我们从左到右迭代的算法，更新从当前段最小值到总成本总和的映射。 对于每个新元素，我们考虑开始一个新段或扩展现有段。 我们通过更新上限划分和合并相同的最小值来合并成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个空结果变量以累加所有子序列的总和。 
2. 从左到右迭代序列。 对于每个位置，维护一个将段最小值映射到累积成本总和的字典。 
3. 对于当前元素，考虑扩展所有先前的段：计算新的最小值并使用上限除法更新成本。 如果新的最小值已存在于地图中，则保留较小的成本。 
4. 还可以考虑仅使用当前元素开始一个新段； 成本为1。 
5. 处理当前元素后，将结束于该元素的段的所有最小成本相加，并添加到全局结果中。 
6. 继续，直到处理完所有元素。 

为什么它有效：不变的是地图在位置$i$包含，对于结束于的段的每个可能的最小值$i$，该细分市场可实现的最低总成本。 扩展或开始新的段可以保持正确性，因为我们总是为每个可能的段最小值选择最小的上限划分成本。 合并重复的最小值可确保地图保持紧凑。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

for _ in range(int(input())):
    n = int(input())
    a = list(map(int, input().split()))
    total = 0
    prev = {}
    for val in a:
        curr = {}
        # start a new segment with just val
        curr[val] = 1
        # extend all previous segments
        for mn, cost in prev.items():
            new_mn = min(mn, val)
            new_cost = cost + (val + new_mn - 1) // new_mn
            if new_mn in curr:
                curr[new_mn] = min(curr[new_mn], new_cost)
            else:
                curr[new_mn] = new_cost
        total += sum(curr.values())
        prev = curr
    print(total)
```第一个循环处理多个测试用例。 这`prev`字典保存以前一个元素结束的所有段最小值的最小成本。 对于每个新值，我们要么扩展一个段（更新最小值和成本），要么开始一个长度为 1 的新段。`(val + new_mn - 1) // new_mn`运算在不使用浮点运算的情况下实现除法的上限，避免了大整数的精度问题。
