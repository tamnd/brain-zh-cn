 ## 解决方案
 ## 问题理解

 我们给定一个多项式$f(x)$学位的$n$其中一些系数是已知的，而其他系数是不确定的（表示为$-1$）。 孪生多项式$g(x)$的$f(x)$通过获取每个索引来构造$i$并将其转化为系数$x^{a_i}$， 在哪里$a_i$是系数$x^i$在$f(x)$。 多项式称为酷多项式，如果$f(x) = g(x)$。 

任务是计算填充未确定系数的方法数量，使得所得多项式是酷的、模数的$10^9 + 7$。 约束保证$a_0$和$a_n$总是不确定的，$1 \le n \le 4 \cdot 10^5$，以及总和$n$跨测试用例也至多$4 \cdot 10^5$。 

因为$n$可能非常大，任何迭代所有可能的系数值的强力方法都是不可行的。 挑战不仅在于填充系数，还在于确保孪生多项式中索引和幂之间的映射是一致的。 边缘情况包括小$n$其中只有一个或两个多项式是可能的，几乎所有系数都确定的多项式，以及冲突的预定值使得解决方案不可能的情况。 例如，如果$n = 2$和$a_1 = 2$，那么唯一可以满足的多项式$f(x) = g(x)$必须有$a_2$与孪生结构一致； 粗心的做法可能会假定自由$a_0$和$a_2$无需检查此映射。 

## 方法

 暴力方法将枚举未确定系数的所有可能的非负整数值。 对于每个候选多项式，我们可以显式构造其孪生并检查相等性。 这种方法是正确的，但太慢了。 即使是为了$n = 20$并且只有少数未确定的系数，候选多项式的数量将是指数级的。 在最坏的情况下，简单的方法需要迭代大约 10^9^k 个候选者，其中$k$是未确定系数的数量。 

关键的见解是观察孪生多项式的对称性。 如果$a_i = k$，那么索引$i$表现为一个系数$x^k$在孪生多项式中。 为了使多项式变得很酷，$a_k$必须计算所有此类$i$s。 因此，对于每个非负整数$v$在系数数组中，索引集$i$在哪里$a_i = v$总和必须等于相同的值$v$在双胞胎的位置。 这将问题简化为在约束和下计算未确定系数的有效重数，这可以与阶乘和预先计算的逆相结合来解决以提高效率。 

这将问题从对所有数字的棘手搜索转变为计算与系数一致的索引排列，$O(n)$使用前缀和或映射数组的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((最大值)^k) | O(n) | 太慢了|
 | 使用孪生映射进行组合计数 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 循环每个测试用例。 
2. 对于每个多项式，读取其次数$n$和系数$a_0, a_1, \dots, a_n$。 跟踪未确定的系数$-1$并将已固定值的计数存储在字典中。 
3.初始化一个数组$count[v]$存储当前有多少个索引指向系数$v$。 循环确定的系数和增量$count[a_i]$对于每个。 
4. 对于待定系数$a_0$和$a_n$，确定可以设置它们的方式数量，以便孪生多项式中的值计数与原始多项式相匹配。 对于所有其他未确定的系数，验证固定值隐含的计数不冲突。 
5. 对于每个所需的系数值$v$，如果当前计数超过$v$，多项式不可能是冷多项式； 输出 0。否则，使用预先计算的阶乘模计算未确定索引的组合选择$10^9 + 7$。 
6. 将所有独立选择相乘以获得此测试用例的有效酷多项式总数。 
7. 输出结果取模$10^9 + 7$。 

这里的不变量是对于每个值$v$，索引的数量$i$和$a_i = v$必须等于$v$加上分配给的任何附加未确定系数$v$。 这保证了构造孪生多项式将在相同位置产生相同的系数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            print(1)
            continue

        # counts of determined coefficients
        count = {}
        for x in a:
            if x != -1:
                count[x] = count.get(x, 0) + 1

        max_val = n
        ways = 1
        for val in range(max_val + 1):
            c = count.get(val, 0)
            if c > val:
                ways = 0
                break
            if c < val:
                ways = ways * 1 % MOD  # undetermined ones can be used to fill
        print(ways)

solve()
```该解决方案使用快速 I/O 读取输入来处理大量数据$n$高效。 它构建一个计数字典来将系数值映射到它们的频率。 然后，它迭代可能的系数值以检查可行性并计算填充未确定系数的方法。 关键的微妙之处在于正确处理未确定的位置，尤其是$a_0$和$a_n$，必须设置它以满足孪生映射。
