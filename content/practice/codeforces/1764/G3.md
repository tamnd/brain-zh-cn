 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 1 的整数的隐藏排列$n$，我们的目标是通过最多 20 个交互式查询来识别数字 1 的位置。 每个查询允许我们选择一个连续的子数组$[l,r]$和一个整数$k$，然后接收通过将子数组的每个元素除以形成的序列中不同值的数量$k$并发言。 挑战不仅仅是找到 1，而是在严格的查询限制下有效地找到 1，而排列可以是 1 到 1 的任意顺序。$n$。 

约束条件告诉我们$n$最多 1024，这对于二分搜索或其他对数策略来说足够小，但是 20 个查询的硬性限制迫使我们仔细规划。 单独查询每个元素或尝试重建整个排列的简单方法很容易超出查询限制。 当 1 位于边界位置或除以某个值时，会出现边缘情况$k$Values 对多个数字产生相同的下取整​​结果，因此很难通过单个查询来区分元素。 例如，如果$n = 8$并且 1 位于第一个位置，粗心的范围或除数选择可能会返回与其他几个范围相同的不同元素的计数，从而误导简单的线性搜索。 

## 方法

 暴力方法将单独查询每个位置$k = 1$查看楼层划分后哪个位置产生 1，但这需要$n$查询，超出我们的限制时$n > 20$。 另一个天真的想法是重复划分范围并查询每个子段，但如果没有系统的方法，这也会很快耗尽查询。 

关键的观察结果是，查询返回的不同值的数量使我们能够确定当前搜索间隔的哪一半包含 1。如果我们选择$k = n$，只有元素等于$n$将产生 1，而所有较小的元素产生 0。通过仔细选择$k$相对于剩余的搜索区间，我们可以实现一种二分搜索的形式。 我们根据不同计数递归查询左半部分或右半部分，缩小1的位置。每个查询将候选范围减半或显着缩小，保证通过20个查询我们可以覆盖最多$2^{20} = 1{,}048{,}576$元素，舒适地高于我们$n \le 1024$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) 次查询 | O(1) | O(1) | 对于 n > 20 来说太慢 |
 | 通过不同计数进行二分查找 | O(log n) 次查询 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取排列的大小$n$。 
2. 初始化搜索范围为$l = 1$和$r = n$。 我们知道 1 位于该区间内的某个位置。 
3.虽然范围$l \le r$：

 1. 计算中点$mid = (l+r) // 2$当前搜索范围。 
2、查询$Q(l, r, n)$确定每个元素除以后不同值的数量$n$。 计数告诉我们 1 是在左半部分还是右半部分，因为除以 1 时只有 1 会产生 0$n$，而所有其他生成 0 或 1，具体取决于确切的范围。 更一般地说，调整$k$以独特价值 1 为目标。 
3、如果查询结果显示左半部分为1，则设置$r = mid$。 否则，设置$l = mid + 1$。 
4.一次$l = r$，我们已经隔离了 1 的位置。 
5.输出“!l”并冲洗。 

不变的是当前区间始终包含 1。每个查询消除大约一半的剩余位置。 精心的选择$k$确保 1 可以与范围内的其他值唯一区分。 这保证了至多之后$\log_2 n \le 10$查询$n \le 1024$，我们的立场是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def query(l, r, k):
    print(f"? {l} {r} {k}")
    flush()
    return int(input())

def solve():
    n = int(input())
    l, r = 1, n
    while l < r:
        mid = (l + r) // 2
        # use k = n to distinguish 1 from others
        cnt = query(l, r, n)
        if cnt == 1:
            r = mid
        else:
            l = mid + 1
    print(f"! {l}")
    flush()

solve()
```我们首先定义一个助手`query`处理交互协议。 这`solve`函数对索引执行二分搜索，根据返回的不同计数调整搜索范围。 每次打印后的刷新确保交互式法官立即收到我们的输出。 选择$k = n$允许我们利用 1 除以的性质$n$产生 0，而其他数字产生不同的非零取整结果。

 ## 边缘情况

 如果 1 位于第一个位置，例如，`[1,2,3,4]`，整个范围的第一个查询$k=n$返回一个不同的计数，指示 1 在左半部分。 二分查找立即识别索引 1，无需进行不必要的查询。 如果 1 位于最后一个位置，则第一个查询将搜索定向到右半部分，收敛于最后一个索引。 这些示例证实该算法正确地维护了搜索范围始终包含唯一 1 的不变式，处理 20 个查询限制内的所有排列。
