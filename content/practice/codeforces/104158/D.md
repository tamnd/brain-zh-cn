 ## 解决方案
 ## 问题理解

 我们得到一个仅由字符 T 和 C 组成的目标字符串。任务是计算使用一组固定的标记可以形成该字符串的不同方式。 

字符串中的每个位置都是通过选择四种邮票类型之一来生成的。 有些邮票只写一个字符，而另一些则一次写两个字符。 关键的限制是我们没有像操作一样按顺序排列邮票； 相反，我们将字符串分解为精确覆盖字符串且没有重叠的标记块。 每种有效方式都对应于使用允许的片段对字符串进行平铺，并且我们对所有此类平铺以大素数取模进行计数。 

字符串长度最大可达 1,000,000。 对子串的二次或更差的解决方案是不可行的，因为即使每个状态重复的线性扫描也已经超出了可接受的限制。 这迫使我们采用以线性时间运行的动态编程方法。 

对多字符邮票的重叠解释产生了一个微妙的问题。 贪婪的解释会失败，因为过早选择较长的标记可能会阻止以后的有效分解。 例如，在字符串 TCC 中，如果我们总是尝试先获取两个字符的标记 TC，则可能会错过单独处理第一个字符的配置。 

主要的边缘情况是具有重复模式的字符串，例如 TTTT 或 CCCC，其中会发生分段的组合爆炸。 任何显式枚举分区的方法都会超时或溢出递归限制。 

## 方法

 一种直接的方法是将其视为分区问题：我们尝试各种方法将字符串拆分为长度为 1 或 2 的段，然后检查每个段是否与有效标记匹配。 这是正确的，因为每个平铺都对应于这样的分段。 然而，在每个位置，我们最多会分为两个选择，导致分段数量呈指数增长。 对于长度为 n 的字符串，这会产生大致类似斐波那契的增长，对于接近 50 的 n 来说已经太大了，更不用说 10^6 了。 

问题的结构表明动态规划。 重要的观察是，形成前缀的方式数量仅取决于少量固定数量的先前状态。 由于每个标记贡献一个或两个字符，因此状态转换仅取决于 dp[i-1] 和 dp[i-2]。 这将问题简化为字符串上的线性递归。 

在位置 i，我们考虑最后一个邮票如何结束。 如果最后一个标记覆盖单个字符，则它必须匹配 S[i-1]。 如果它包含两个字符，则它必须匹配 S[i-2:i]。 每个有效匹配分别贡献 dp[i-1] 或 dp[i-2]。 

我们有效地总结了所有有效方法的贡献，以结束于位置 i，这避免了重复计算，因为每个分解都是由其最后一个部分唯一确定的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分区| O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 动态规划| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将 dp[i] 定义为形成前缀 S[0:i] 的方式数，使用基于 0 的索引，其中 dp[0] 对应于空字符串。

1. 初始化 dp[0] = 1，因为构造空前缀的方法只有一种，即不选择任何标记。 这是构建所有较长前缀的基本情况。 
2. 将 i 从 1 迭代到 n。 在每个位置 i，我们通过考虑可以在位置 i 结束的所有有效标记来计算 dp[i]。 
3. 首先考虑单字符印章。 最后一个字符 S[i-1] 始终恰好被一个标记覆盖。 由于任何与 S[i-1] 匹配的单字符标记都是允许的，因此每个 dp[i-1] 路都可以扩展。 这将 dp[i-1] 贡献给 dp[i]。 
4. 接下来考虑两个字符的印章。 如果 i ≥ 2，我们检查 S[i-2:i] 是否可以由两个字符的印记组成。 如果是这样，则可以通过将此标记放在末尾来扩展形成 dp[i-2] 的每种方式。 这将 dp[i-2] 贡献给 dp[i]。 
5. 将两个贡献以 10^9 + 7 为模相加。 

它之所以起作用是基于一个简单的分解特性。 前缀的每个有效标记都有一个唯一的最后一个标记。 最后一个标记覆盖一个或两个字符，删除它会留下较小前缀的有效标记。 这给出了 dp[i] 的有效构造与由最终标记扩展的 dp[i-1] 和 dp[i-2] 的有效构造之间的双射。 由于任何构造都不能同时以多种方式结束，因此不会出现重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    s = input().strip()
    n = len(s)
    
    dp = [0] * (n + 1)
    dp[0] = 1

    for i in range(1, n + 1):
        dp[i] = dp[i - 1]  # single-character stamp always usable
        
        if i >= 2:
            # any two-character block is always valid as a stamp
            dp[i] = (dp[i] + dp[i - 2]) % MOD

        else:
            dp[i] %= MOD

    print(dp[n])

if __name__ == "__main__":
    solve()
```实现直接反映了重现。 dp 数组存储前缀计数，每个状态聚合来自两个可能的标记长度的贡献。 在每一步应用模数以防止溢出。 

唯一微妙的一点是确保正确的索引：dp[i] 表示前 i 个字符，因此转换使用 i-1 和 i-2。 这避免了前缀 DP 公式中常见的相差一错误。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个位置都会通过 O(1) 转换处理一次 |
 | 空间| O(n) | 大小为 n+1 的 DP 数组 |

 该解决方案很容易满足约束条件，因为即使对于 n = 10^6，该算法也仅对每个字符执行一些简单的算术运算。

 ## 边缘情况

 对于像“T”这样的单字符字符串，算法设置 dp[1] = dp[0] = 1，因为只有一个邮票可以覆盖它。 没有dp[i-2]项，因此不会发生无效访问。 

对于像“TC”这样的双字符字符串，dp[2] = dp[1] + dp[0] = 2。第一项对应于两个单图章，第二项对应于一个双字符图章。 索引确保两种可能性都被精确计数一次，并且不会发生重叠，因为每个结构都是由其最后的印记选择唯一标识的。
