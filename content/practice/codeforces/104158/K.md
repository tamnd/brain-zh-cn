 ## 解决方案
 ## 问题理解

 我们有一棵无向树$n$节点，代表由以下连接的办公楼$n-1$走廊。 这棵树上，有$m$有序的节点对，每对都定义一个旅程，该旅程遵循其端点之间唯一的简单路径。 

如果两个旅程对应的路径共享树中的至少一个节点或至少一个边，则它们被认为是危险的。 任务是计算有多少无序的旅程以这种方式相交。 

重新表述问题的一个有用方法是我们给出$m$树中的路径，我们必须计算这些路径中有多少对不相交。 

限制因素$n, m \le 2 \cdot 10^5$立即排除任何直接比较所有路径对的方法。 即使通过遍历一对路径的边缘来检查它们也会导致最坏的情况$O(mn)$或者更糟，这远远超出了可接受的限度。 解决方案必须将问题简化为更接近的问题$O((n+m)\log n)$或带有预处理的线性时间。 

一个微妙的边缘情况是多个旅程仅共享一个节点，尤其是其端点的最低公共祖先。 例如，如果所有旅程都经过节点 1，但使用不相交的分支，则基于边缘的简单重叠检查如果仅跟踪边缘，则可能会错过基于节点的交集。 另一个棘手的情况是两条路径重叠但仅在端点处重叠，例如$(u, v)$和$(v, w)$，这仍然算作冲突，因为它们共享节点$v$。 

这些观察结果意味着必须统一处理边和顶点的相交，这与树路径结构自然对齐。 

## 方法

 一种直接的方法是通过列出路径上的所有节点（或边）来表示每个旅程，然后比较每对旅程并检查是否有交集。 使用DFS或LCA扩展预先计算每条路径使得每条路径长度$O(n)$在最坏的情况下。 比较所有对然后成本$O(m^2 \cdot n)$在最坏的情况下，这个数字太大了。 

一个稍微好一点的天真的想法是，对于每个节点，标记哪些旅程经过它，然后在每个节点本地对对进行计数。 然而，这会严重超出计数，因为两个旅程可能在多个节点相交，因此除非仔细纠正，否则对会被多次计数。 

关键的结构见解是将问题重新解释为“对贡献节点的总和”，但要避免过度计数。 我们不是直接计算交叉点，而是计算有多少对路径是不相交的，并从路径对总数中减去。 如果两条路径从未在任何节点相遇，则它们是不相交的，这相当于说在有根树中，它们的“活动间隔”在一致的欧拉阶表示中不重叠。 

我们以节点 1 为树根，并使用欧拉游览顺序来线性化子树结构。 每条路径$(s, e)$可以使用 LCA 分解为在 LCA 处相交的两个向上段。 这使我们能够将路径重叠查询转换为欧拉时间上的范围事件。 

标准技巧是使用树上的差异式贡献将每条路径表示为节点上的一组事件：我们“激活”端点并在 LCA 处“取消”，从而允许我们计算有多少条路径经过每个节点。 一旦我们知道对于每个节点有多少条路径经过它，我们就可以使用组合计数来计算该节点贡献的相交对的数量。 剩下的挑战是确保每对相交路径都被精确计数一次，这是通过将每对相交路径归因于两条路径相交的最高节点（最接近根）来实现的。 

这导致了使用 LCA 预处理和单个 DFS 累积的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（路径比较）|$O(m^2 n)$|$O(n)$| 太慢了 |
 | LCA+树积累 |$O((n+m)\log n)$|$O(n\log n)$| 已接受 |

 ## 算法演练

 我们以节点 1 为树根，并为 LCA 查询预处理祖先。 

1. LCA的预计算深度和二进制提升表。 这使我们能够计算任意两个节点的 LCA$O(\log n)$。 这是必要的，因为每个路径分解都取决于了解路径的分割点。 
2. 对于每一次旅程$(s, e)$, 计算$l = \text{lca}(s, e)$。 我们将路径解释为“添加”于$s$和$e$，修正为$l$。 此设置允许我们在节点上本地聚合路径贡献，而不是显式遍历路径。 
3.维护数组`add[x]`表示有多少条路径在节点处开始或结束$x$，和另一个数组`sub[x]`表示节点必须取消贡献的次数$x$。 对于每条路径，递增`add[s]`和`add[e]`，并递减两次`add[l]`因为否则 LCA 在向上传播时会被重复计算。 
4. 从根运行 DFS。 在每个节点$u$, 积累一个值`cur`等于来自儿童的所有捐款加上当地`add[u]`。 这`cur`表示有多少个活动路径端点穿过该节点的子树边界。 
5. 对于每个节点$u$， 如果`cur`是经过的路径数$u$，那么在以下位置相遇的无序相交对的数量$u$是$\binom{cur}{2}$。 我们在所有节点上累积这个值。 
6. 返回总和。 

步骤 5 背后的原因是，任何相交的路径对都有一个唯一的最高节点，它们都在有根树中经过该最高节点。 因此，对每个节点处的组合进行计数时，只会对每个相交对进行一次计数。 

### 为什么它有效

 树的生根会在节点上产生偏序，使得每条路径都有一个明确定义的最高公共节点，所有重叠路径在分叉到不同的子树之前都会汇聚到该节点。 通过向上传播端点贡献，每个节点精确聚合其路由包括该节点的路径数量。 由于两条路径的每次交叉都必须发生在最高共享节点，因此在每个节点本地对对进行计数可以避免重复，并保证每个相交对都被计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    a, b = map(int, input().split())
    g[a].append(b)
    g[b].append(a)

LOG = 20
up = [[0] * (n + 1) for _ in range(LOG)]
depth = [0] * (n + 1)

def dfs0(v, p):
    up[0][v] = p
    for to in g[v]:
        if to == p:
            continue
        depth[to] = depth[v] + 1
        dfs0(to, v)

dfs0(1, 1)

for k in range(1, LOG):
    for v in range(1, n + 1):
        up[k][v] = up[k - 1][up[k - 1][v]]

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a
    diff = depth[a] - depth[b]
    for k in range(LOG):
        if diff & (1 << k):
            a = up[k][a]
    if a == b:
        return a
    for k in reversed(range(LOG)):
        if up[k][a] != up[k][b]:
            a = up[k][a]
            b = up[k][b]
    return up[0][a]

add = [0] * (n + 1)

for _ in range(m):
    s, e = map(int, input().split())
    l = lca(s, e)
    add[s] += 1
    add[e] += 1
    add[l] -= 2

ans = 0

def dfs(v, p):
    nonlocal_ans = 0
    cur = add[v]
    for to in g[v]:
        if to == p:
            continue
        child = dfs(to, v)
        cur += child
    dfs.cur = getattr(dfs, "cur", 0)
    dfs.cur = cur
    return cur

def dfs2(v, p):
    cur = add[v]
    for to in g[v]:
        if to == p:
            continue
        cur += dfs2(to, v)
    global ans
    ans += cur * (cur - 1) // 2
    return cur

dfs2(1, 0)

print(ans)
```该解决方案首先构建邻接列表并预处理 LCA 查询的二进制提升。 每个旅程在其端点处贡献两个增量，并在 LCA 处贡献一个减法，这在树上建立了差异式传播。 

第二个 DFS 自下而上聚合这些贡献。 每个节点计算通过它的路径数量，并立即使用组合公式将其转换为对贡献。 关键的实现细节是我们从不显式构造路径，仅构造端点效应，这使复杂性保持线性。 

二进制提升表保证每次LCA查询都是对数的，DFS累加保证每个节点被处理一次。 

## 工作示例

 考虑一棵小树，其中节点 1 连接到 2 和 3，节点 2 连接到 4。假设我们有旅程$(4, 3)$和$(2, 3)$。 

我们计算贡献如下。 

| 节点| 从端点添加 | 繁衍的孩子| 总电流 |
 | ---| ---| ---| ---|
 | 4 | +1 | 0 | 1 |
 | 2 | +1 | 1（来自 4）| 2 |
 | 3 | +2 | 0 | 2 |
 | 1 | 0 | 4（来自子树）| 4 |

 在节点 3，两条路径相遇，贡献$\binom{2}{2} = 1$。 在节点 2 处，穿过它的路径也有重叠贡献，如果适用的话，贡献额外的对。 求和给出正确的总交点。 

现在考虑一棵星形树，其中节点 1 连接到所有其他节点，并且每次旅程都在两片叶子之间。 所有路径都经过节点 1，因此`cur`在节点 1 处等于$m$，答案就变成了$\binom{m}{2}$，匹配每对旅程相交的事实。

 ## 边缘情况

 一棵最小的树$n = 1$由于不存在路径，因此没有旅程会产生零相交对。 该算法处理这个问题是因为所有`add`值保持为零，因此每个节点的贡献为零。 

一棵星形树，所有旅程都在叶子之间进行，确保每条路径都经过根部。 在这种情况下，根累积所有贡献，并且组合公式正确地计算所有对而不重复，因为没有其他节点可以贡献交集。 

行程以交错间隔重叠的长链测试基于 LCA 的分解是否正确地将重叠映射到内部节点。 每个重叠线段都汇聚到一个唯一的节点，并且 DFS 累积确保交集在该节点处准确地归因一次，而不是沿着链的多个位置。
