 ## 解决方案
 ## 问题理解

 对于每个整数$n$，我们被要求寻找除数$d$具有比平常更强的属性：不仅必须$d$划分$n$， 但$d^k$还必须分$n$。 在所有这些除数中，我们为每个除数取最大的一个$n$。 计算出每个数字的值后$1$最多$N$，我们对它们求和。 

因此，任务不是直接列出除数，而是为每个数字提取最大整数$k$-次方仍然符合该数字。 “最大有效除数”取决于$n$是分布式的，因为除数的幂会乘以它的质因数分解中的指数。 

约束条件允许$N$直到大约$5 \times 10^7$，这排除了尝试使用试除法独立分解每个数字的任何情况。 甚至$O(N \sqrt{N})$或者$O(N \log N)$具有大量常量会太慢。 唯一可行的方向是在近线性时间内预先计算所有数字的算术结构并重用它。 

出现微妙的边缘情况时$k$很大。 如果$k$超过中的每个素数指数$n$，那么没有素数能够在约束条件下幸存下来$k \cdot \text{exp}(d,p) \le \text{exp}(n,p)$，所以唯一有效的除数是$1$。 例如，如果$k=10$，那么对于$n=72=2^3\cdot 3^2$，每个指数除以$10$变为零，所以答案是$1$。 试图以数​​字方式“近似根”的简单方法不会自然地捕获指数的这种离散崩溃。 

## 方法

 蛮力解释很简单。 对于每个$n$, 枚举所有除数$d$，检查是否$d^k$划分$n$，并跟踪最大值。 这是正确的，但是生成除数已经花费了大约$O(\sqrt{n})$每个数字，并验证条件会增加更多分解工作。 全面的$n \le N$，这远远超出了可接受的范围。 

关键的观察是条件$d^k \mid n$纯粹是素数指数的乘法。 如果$$n = \prod p^{a_p}, \quad d = \prod p^{b_p},$$然后$$d^k = \prod p^{k b_p}.$$所以约束变为$k b_p \le a_p$， 意义$b_p \le \left\lfloor \frac{a_p}{k} \right\rfloor$。 这消除了所有组合搜索：最优$d$通过缩小每个指数来唯一确定$n$由一个因素$k$。 

所以问题归结为计算，对于每个$n \le N$, 数量$$f(n) = \prod p^{\lfloor v_p(n)/k \rfloor}.$$然后我们求和$f(n)$全面的$n$。 

该结构与筛法兼容。 如果我们预先计算最小素因数，我们可以以对数或接近恒定的时间因式分解每个数字并计算$f(n)$逐渐地。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力除数和检查 |$O(N \sqrt{N})$|$O(1)$| 太慢了 |
 | SPF 筛 + 每个数字因子变换 |$O(N \log N)$或附近$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 计算依赖于一种快速分解每个整数的方法，这是通过预先计算每个数字的最小质因数来实现的。 

1. 构建数组`spf`在哪里`spf[x]`存储最小素数除法$x$。 这是使用筛式工艺完成的。 此步骤确保稍后可以通过重复剥离其最小素因子来对每个数字进行因式分解。 
2.初始化一个数组`f`尺寸的$N$， 在哪里`f[n]`将存储最大的$k$- 快乐除数$n$。 我们将使用其因式分解独立计算每个条目。 
3. 对于每个整数$n$从$1$到$N$，使用因式分解`spf`大批。 在提取质因数时，维护一个字典或指数计数的临时列表$n$。 此步骤非常有效，因为每次划分都会快速减少数量。 
4. 对于每个素数$p$带指数$a$在$n$, 计算$a // k$。 这是$p$在所得的除数中。 
5. 重建$f(n)$通过乘法$p^{a // k}$对其因式分解中的所有素数进行分解。 这给出了唯一的最大除数，其$k$次方除法$n$。 
6. 添加$f(n)$变成一个运行的全局总和。 
7. 处理完所有数字后输出最终的和。 

这样做的关键原因是约束$d^k \mid n$在素数上完全分解，并且最大化每个素数独立发生。 一旦指数被独立固定，就只有一个有效的最大除数，因此对每个数字求和就足够了，不会出现任何重叠问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_spf(n):
    spf = list(range(n + 1))
    for i in range(2, int(n ** 0.5) + 1):
        if spf[i] == i:
            step = i
            start = i * i
            for j in range(start, n + 1, step):
                if spf[j] == j:
                    spf[j] = i
    return spf

def solve():
    N, k = map(int, input().split())

    if k > 60:
        print(N)
        return

    spf = build_spf(N)

    total = 0

    for x in range(1, N + 1):
        n = x
        res = 1

        while n > 1:
            p = spf[n]
            cnt = 0
            while n % p == 0:
                n //= p
                cnt += 1

            exp = cnt // k
            if exp:
                res *= p ** exp

        total += res

    print(total)

if __name__ == "__main__":
    solve()
```筛子构造最小质因数，以便每个整数可以通过重复除以进行因式分解`spf[n]`。 在分解过程中，我们聚合每个素数的指数计数，然后立即通过除以来减少它们$k$。 只有在这种减少中幸存下来的素数才会对重建的除数做出贡献。 

捷径`if k > 60: print(N)`反映没有整数达到$10^{18}$- 在典型约束条件下，标度范围的质指数超过 60； 在这个问题的背景下，它充当了一种安全的优化，因为即使$2^{60}$已经超过了指数缩减的行为上限，使得所有贡献都崩溃为$1$。 在更严格的实现中，这可以通过始终运行完整逻辑来替代。

 ## 边缘情况

 当$k$非常大，每个指数除以$k$变为零。 例如，使用输入$n=18, k=10$，我们有$18 = 2^1 \cdot 3^2$，并且两个指数都崩溃为零，所以结果是$1$。 该算法自然地处理这个问题，因为整数除法`cnt // k`对于每个素数产生零，对重建没有贡献。 

什么时候$n$是一个纯质数幂，例如$n = p^{100}$，行为变得可见。 如果$k=3$，指数减少为$33$，算法重构$p^{33}$。 筛因式分解可确保指数只计算一次，因此不会发生重复或过度计算。
