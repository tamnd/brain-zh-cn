 ## 解决方案
 ## 问题理解

 游戏从一个整数列表开始。 安娜首先移动任何数字的数字，这可以根据数字增加或减少其值。 Sasha 通过连接任意两个数字而排名第二，将列表大小减少一。 游戏以这种方式交替进行，直到只剩下一个数字。 如果最终数字至少为 ，萨莎获胜$10^m$，否则安娜获胜。 

输入由多个测试用例组成。 每个测试用例指定整数个数$n$，阈值$m$，以及整数列表$a$。 假设两个玩家都发挥最佳，每个测试用例的输出都是获胜者。 

约束表明$n$可以达到$2 \cdot 10^5$以及所有的总和$n$跨测试用例的上限也为$2 \cdot 10^5$。 这排除了任何模拟所有游戏状态或排列的解决方案，因为潜在的移动数量与$n$。 因此，最佳游戏必须依赖于**对数字操纵的策略观察**，而不是强力的游戏树探索。 

当出现边缘情况时$n = 1$，因为安娜无法逆转影响比赛，而萨沙也没有任何动作。 同样，当人数已经很大时，安娜的逆转也无法阻止萨莎获胜。 例如，如果唯一的数字是$9$和$m = 1$, 安娜无法避免萨莎获胜，因为$9 \ge 10^0 = 1$。 

## 方法

 一种幼稚的方法是尝试模拟游戏，在安娜的回合中反转每个数字，并在萨沙的回合中连接每对数字。 这是正确的，但不可行，因为排列的数量是阶乘$n$。 对于大型$n$，这将超出时间限制。 

关键的观察结果是 **Anna 无法减少最大数字以阻止 Sasha 创建数字$\ge 10^m$** 如果至少一个数字有足够的位数。 Sasha 始终可以连接两个数字以生成至少与最大元素一样大的数字，因为连接会增加或保留位数。 安娜的逆序只是交换数字，不能增加超出原来数字的数字。 

因此，解决方案简化为检查 **Sasha 通过最佳串联获得的最大可能数是否至少为$10^m$。 如果是，萨沙获胜； 否则，安娜获胜。 这允许基于最大数字的**贪婪评估**，避免完全模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每场比赛 O(n!) | O(n) | 太慢了 |
 | 贪心最大检查 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$和$m$，后跟整数列表$a$。 
3. 识别**最大位数**的整数$a$。 反转任何整数不会改变其位数。 
4. 计算$10^m$。 
5.如果最大的整数$a$至少是**$10^m$**，Sasha可以立即或通过串联达到一个数字$\ge 10^m$。 宣布萨莎为获胜者。 
6. 否则，安娜可以阻止萨莎到达$10^m$，安娜获胜。 

**为什么有效：** 不变的是 Sasha 的串联总是产生一个至少与当前列表中最大元素一样大的数字。 安娜的逆向永远无法增加位数。 因此，游戏结果仅取决于任何数字在由 Sasha 最佳连接时是否已经具有足够的数字来达到阈值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        threshold = 10 ** m
        max_val = max(a)
        if max_val >= threshold:
            print("Sasha")
        else:
            print("Anna")

if __name__ == "__main__":
    solve()
```该解决方案使用快速 I/O 读取输入。 对于每个测试用例，它计算最大元素并将其与$10^m$以确定获胜者。 使用`max(a)`确保每个测试用例的评估时间为 O(n)。

 ## 边缘情况

 如果列表中只有一个数字，安娜无法影响比赛，结果仅取决于该数字是否≥$10^m$。 例如，使用输入`1 1 10`，萨沙立刻获胜。 如果列表中的数字很大，但m又很大，即使是最大的数字也可能达不到$10^m$，让安娜获胜。 这种方法可以正确地解释这些边缘情况，而无需模拟任何移动。
