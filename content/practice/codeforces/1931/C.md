 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们想让所有元素相等。 我们最多可以执行一项操作，其中包括选择一个连续的子数组并将其所有元素设置为某个值。 操作的成本等于我们选择的子数组的长度。 我们的目标是尽量减少这一成本。 

输入由多个测试用例组成。 每个测试用例都给出数组大小和数组本身。 我们必须输出每个测试用例的最小成本。 

限制因素很大。 该数组最多可达$2 \cdot 10^5$元素，并且最多可以有$10^4$测试用例。 所有测试用例的元素总数不超过$2 \cdot 10^5$。 这意味着每个测试用例超过线性时间的任何解决方案都可能太慢。 检查所有可能子数组的简单暴力方法是二次的$n$，这是不可接受的。 我们需要一种线性或近线性的方法。 

边缘情况包括已经统一的数组、长度为 1 的数组以及多个元素已经重复但不连续的数组。 例如，在`[8, 8, 8, 1, 2, 8, 8, 8]`，最佳选择并不是立即显而易见的，因为重复的 8 由不同的值分隔。 总是选择相同值的最长连续运行的简单方法在这里会失败。 

## 方法

 暴力方法将迭代我们可以将数组设置为的每个可能值，并且对于每个值，尝试每个子数组以查看设置它是否会产生统一数组。 评估每个子数组的成本与其长度成正比，大致有$O(n^2)$子数组。 这导致$O(n^3)$与迭代所有候选值相结合的操作。 这原则上是正确的，但对于问题约束来说太慢了。 

更快解决方案的关键洞察是关注每个候选值已经出现的位置。 我们可以计算数组中不等于所选值的段数。 如果我们巧妙地扩展子数组，每个这样的段都可以被一次操作“覆盖”。 由于我们只允许进行一项操作，因此最小成本等于我们需要覆盖的最长延伸的长度，以覆盖候选值的所有差异。 更正式地说，可以将数组视为由候选值分隔的块序列。 每个块都必须被覆盖，但是我们可以选择在一次操作中覆盖多个块。 一种贪婪的方法出现了：我们反复跳过候选值并计算非候选值的连续段的长度，选择所有候选值中的最小长度。 

这一观察结果将问题从考虑所有子数组减少到迭代每个唯一值的位置，从而为我们提供了有效的线性扫描解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组并记录唯一值集。 这些是最终统一值的唯一候选者。 
2. 初始化变量`min_cost`到一个很大的数字，这将跟踪在候选人中找到的最小成本。 
3. 对于每个候选值`v`，从左到右扫描数组。 每次我们遇到一个不等于的元素`v`，计算连续元素直到下一个`v`或数组末尾。 每个这样的连续段对所需操作的数量贡献 1。 
4. 候选人费用`v`是非候选段的数量，因为每个段必须被覆盖一次。 由于操作成本等于段的长度，并且问题允许选取任何子数组，因此我们选择最小数量的段作为覆盖单个操作中的所有差异的最小可能成本。 
5. 更新`min_cost`如果这位候选人给出的总成本较小。 
6.检查完所有候选后，输出`min_cost`。 

为什么有效：通过单独处理每个候选值并计算非候选值的连续块，我们确定了必须覆盖的最小段。 由于我们可以在单个操作中选择任何连续的子数组进行覆盖，因此非候选块的最小数量直接对应于最小成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            print(0)
            continue
        unique_vals = set(a)
        min_cost = n  # maximal cost is n
        for v in unique_vals:
            i = 0
            cost = 0
            while i < n:
                if a[i] != v:
                    cost += 1
                    while i < n and a[i] != v:
                        i += 1
                else:
                    i += 1
            min_cost = min(min_cost, cost)
        print(min_cost)

if __name__ == "__main__":
    solve()
```我们迭代每个唯一值，因为只有这些值才能成为最终的统一值。 对非候选值的连续段进行计数可确保我们仅在必要时应用该操作。 内部循环正确地跳过等于候选的元素以避免重复计算。 使用`min`跨候选人确保我们找到最佳选择。 处理`n == 1`作为一种特殊情况，可以防止不必要的计算并避免差一错误。
