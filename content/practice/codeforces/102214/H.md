 ## 解决方案
 ## 问题理解

 该问题要求我们考虑 (n) 节课，其中 (i) 课占用时间间隔 ([l_i,r_i])。 当两个课程不重叠时，它们是兼容的。 允许触摸一个端点，因此 ([1,3]) 和 ([3,5]) 是兼容的。 

我们必须取消一节课。 目标是找到取消的每节课程，使所有剩余课程成对不重叠。 输出是此类课程的数量，后面是按升序排列的索引。 原始 Codeforces 问题被列为 31C，Schedule，具有 (n \le 5000)、(l_i,r_i \le 10^6)、2 秒时间限制和 256 MB 内存。 

界限 (n \le 5000) 是关键约束。 (O(n^2)) 算法最多执行约 2500 万对检查，这对于编译语言来说是合理的，并且在优化的 Python 中仍然可以管理。 在最坏的情况下，(O(n^3)) 算法大约需要 (5000^3/2 = 62.5) 十亿次配对比较，这远远超出了限制。 因此，我们需要避免针对每个可能取消的课程单独检查每一对。 

思考问题最有用的方法是找出实际冲突的教训对。 如果没有冲突的配对，则可以取消任何课程。 如果存在冲突对，则只有当课程属于每个冲突对时才可以取消课程。 

端点情况很容易处理不当。 用于输入```
2
1 3
3 5
```正确的输出是```
2
1 2
```因为课程只涉及时间 3. 使用的粗心实施`r >= l`因为重叠条件会错误地将它们视为冲突。 

另一个重要的情况是存在多个冲突但有一个教训：```
3
1 10
2 3
4 5
```正确的输出是```
1
1
```第 1 课和第 2 课有冲突，第 1 课和第 3 课也有冲突。 删除第 1 课就消除了这两个冲突。 删除任何一个简短的教训都会使其他冲突完好无损。 仅找到一对冲突并返回其两个端点的解决方案将错误地输出课程 1 和课程 2。 

当计划已经有效时，会出现最终的边界情况：```
3
1 2
2 4
4 7
```正确的输出是```
3
1 2 3
```每对都是兼容的，因为允许接触端点。 由于该问题需要取消一次，因此每一课都是有效的选择。 

## 方法

 直接暴力方法考虑了所有可能取消的教训。 对于每个候选者，它会检查剩余 (n-1) 节课程中的每一对，并检查它们的时间间隔是否重叠。 这是正确的，因为当没有剩余的对相交时，生成的计划完全有效。 然而，一个候选者需要 (O(n^2)) 次比较，并且有 (n) 个候选者，需要 (O(n^3)) 时间。 对于 (n=5000)，在最坏的情况下，这大约是 (625) 十亿对检查。 

问题的结构让我们避免重复几乎所有这些工作。 对于每个可能的取消，我们不必询问一对是否重叠，而是可以首先确定哪些对在原始时间表中重叠。 假设有 (m) 个冲突对。 如果课程 (i) 被取消，则包含 (i) 的冲突对就会消失。 因此，当 (m) 个冲突对中的每一对都包含 (i) 时，消除就精确地起作用。 

这给出了一个非常简单的计数标准。 对于每一课，计算有多少个冲突对包含它。 如果冲突对的总数为 (m)，则当冲突计数为 (m) 时，课程 (i) 就是有效取消。 

我们可以通过检查每个无序对一次来找到所有冲突对。 只有 (O(n^2)) 个这样的对，因此这符合约束条件。 我们甚至不需要存储这些对。 我们只需要冲突的总数，以及每节课有多少冲突涉及到它。 

这两种方法可以进行如下比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^3)) | (O(n)) | (O(n)) | 太慢了 |
 | 最佳| (O(n^2)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 读取所有课程间隔并将其开始和结束时间及其原始索引存储在一起。 
2. 创建数组`conflicts`在哪里`conflicts[i]`计算有多少其他课程与第 (i) 课重叠。 还维护`total_conflicts`，重叠无序对的总数。 
3. 检查每对课程 (i<j)。 它们恰好重叠`l[i] < r[j] and l[j] < r[i]`。 

这种严格的比较使得共享端点的间隔兼容。 当该对重叠时，递增`total_conflicts`,`conflicts[i]`， 和`conflicts[j]`。 
4. 处理完所有配对后，检查每一课 (i)。 如果`conflicts[i] == total_conflicts`，将其索引添加到答案中。 

原因是取消 (i) 恰好删除了那些包含 (i) 的冲突对。 当且仅当每个冲突都包含 (i) 时，所有冲突都会消失。 
5. 打印有效索引的数量，然后按升序打印索引本身。 由于我们检查了索引 1 到 (n) 的课程，因此收集的索引已经具有所需的排序。 

### 为什么它有效

 考虑所有冲突的课程对的集合。 设其尺寸为(m)。 取消课程 (i) 只能影响包含 (i) 的冲突，因此确切地说`conflicts[i]`冲突的对消失了。 当所有（m）个冲突对消失时，剩余的时间表没有重叠。 因此，教训（i）是一个有效的答案，恰好在`conflicts[i] = m`。 

如果（m=0），则每节课的冲突计数为零，因此每节课都被正确接受。 如果 (m>0)，则相同的等式精确地确定了参与每次冲突的教训。 因此，该算法准确地输出所有有效的取消。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    intervals = [tuple(map(int, input().split())) for _ in range(n)]

    conflicts = [0] * n
    total_conflicts = 0

    for i in range(n):
        li, ri = intervals[i]
        for j in range(i + 1, n):
            lj, rj = intervals[j]

            # The intervals overlap only if neither one ends
            # at or before the other one starts.
            if li < rj and lj < ri:
                total_conflicts += 1
                conflicts[i] += 1
                conflicts[j] += 1

    answer = [
        i + 1
        for i in range(n)
        if conflicts[i] == total_conflicts
    ]

    print(len(answer))
    print(*answer)

if __name__ == "__main__":
    solve()
```间隔列表完全按照给定的方式存储输入，因此原始课程索引只是其从零开始的位置加一。 不需要对间隔进行排序，这也意味着输出顺序是自然而然的。 

嵌套循环使用`i + 1`作为起点`j`，因此每个无序对都被检查一次。 重叠条件使用严格的不等式。 例如，`[1,3]`和`[3,7]`都不满足`1 < 7`和`3 < 3`在一起，因此它们被正确地视为不重叠。 

对于每个冲突对，该对的两个端点都会收到一个冲突计数。 如果一课涉及五个不同的冲突对，则其计数器变为 5。 如果这些是唯一的冲突，则总计数器也会变为 5，因此该课程是有效的取消。 

Python 整数具有任意精度，因此不存在溢出问题。 事实上，冲突对的最大可能数量仅为 (\binom{5000}{2}=12,497,500)，这对于普通整数算术来说已经足够小了。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(n^2)) | 每对无序的课程都会检查一次。 |
 | 空间| (O(n)) | (O(n)) | 每节课的间隔和一个冲突计数器都会被存储。 |

 对于 (n=5000)，配对循环最多检查 12,497,500 对。 这是给定约束的预期规模，并且比暴力 (O(n^3)) 方法所需的大约 625 亿次比较要小得多。 内存使用量与课程数量成线性关系。

 ## 边缘情况

 对于端点接触，请考虑```
2
1 3
3 5
```配对测试评估`1 < 5`确实如此，但是`3 < 3`为 false，因此该对不计为冲突。 总冲突计数为零，两个课程的冲突计数都为零，输出为```
2
1 2
```这就是为什么使用严格的不等式而不是`<=`是必不可少的。 

对于一个常见的相互矛盾的教训，请考虑```
3
1 10
2 3
4 5
```成对的`(1,2)`和`(1,3)`冲突，同时`(2,3)`没有。 冲突计数为`[2,1,1]`冲突总数为`2`。 只有第 1 课的冲突计数等于总数，因此输出为```
1
1
```删除第 1 课可以同时消除这两个冲突。 

对于已经有效的时间表，请考虑```
3
1 2
2 4
4 7
```每对要么完全位于下一对之前，要么接触端点。 因此，冲突总数为零。 由于每节课也都是零冲突，因此每个指标都满足`conflicts[i] == total_conflicts`，生产```
3
1 2 3
```对于密集冲突图，考虑 5000 个相同的区间`[1,2]`。 每对都会发生冲突，因此有 12,497,500 个冲突对。 每节课有 4,999 人参加。 自从`4999 != 12497500`，没有任何一堂课可以自行消除所有冲突，正确答案是零。 该算法无需构建大量冲突对即可处理此问题，因为它仅存储总计数和每节课的一个事件计数。
