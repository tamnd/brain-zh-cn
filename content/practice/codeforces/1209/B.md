 ## 解决方案
 ## 问题理解

 这个问题中的每个灯的行为就像一个二进制开关，随着时间的推移翻转其状态。 您将获得一个初始配置，其中每个灯要么打开，要么关闭。 之后，每个灯都遵循自己的周期规则：它以特定的时间偏移开始切换，并继续以固定的时间间隔切换。 

具体来说，每个灯都有一个周期`a_i`和起始偏移量`b_i`。 从时间开始`b_i`，灯光翻转状态每`a_i`秒。 所以它的切换时间形成一个算术级数：`b_i, b_i + a_i, b_i + 2a_i, ...`。 在这些切换事件之间，其状态保持不变。 

任务是确定在所有整数时刻同时处于“开”状态的灯的最大数量。 

约束很小，最多有 100 个灯光和非常小的周期（最多 5 个）。 这立即表明长期模拟是可行的。 即使我们模拟大量的秒数，系统最终也必须重复，因为每个光都是周期性的，周期长度很小。 整个系统以所有单个周期的最小公倍数为界的周期重复，这里最多是`lcm(1,2,3,4,5) = 60`。 这使得在有界窗口上进行暴力模拟就足够了。 

一个微妙的边缘情况是初始状态和第一次切换之间的交互。 在时间 0 开始“打开”的灯将保持打开状态，直到在时间第一次切换`b_i`。 如果`b_i = 1`，一秒后立即翻转； 如果`b_i > 1`，它在多个步骤中保持稳定。 任何假设切换在时间 0 立即开始的解决方案都会错误地计算早期时刻。 

另一个边缘情况是假设单调行为。 灯不只是简单地打开并保持打开或关闭状态； 它们可以翻转多次，并且活动灯的峰值数量可能会在几个周期后出现，而不是在开始附近。 

## 方法

 解决这个问题的直接方法是逐秒模拟系统，统计每一时刻有多少盏灯亮着。 对于每一次`t`，我们通过检查截至该时间发生的切换次数来确定每个灯的状态。 由于每个灯都会按可预测的算术时间翻转，因此我们可以通过计算之前或此时发生的切换事件来计算其状态`t`。 如果该数字是偶数，则灯保持其初始状态； 如果奇数，它就会翻转。 

此模拟是正确的，因为它明确地模拟了每个灯光的定义。 然而，天真的担忧是运行时：如果我们模拟一个很大的时间范围，比如 10^6 或更多，我们可能会担心性能。 但这里系统重复的周期最多为60，所以我们只需要模拟最多60秒。 

关键的观察是整个配置的周期性。 每个光仅取决于对其周期取模的时间，并且所有周期都受到小整数的限制。 因此，完整的配置会在一个小的全局周期后重复，这意味着我们只需要评估该周期内的所有状态并取最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 无时间限制的全时模拟 | O(T · n) 其中 T 大 | O(1) | O(1) | 有风险/不必要|
 | 长达 60 秒的基于周期的模拟 | O(60·n) | O(60·n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算安全模拟范围。 由于所有周期最多为 5 个，系统会在 60 秒内重复，因此我们只模拟从 0 到 59 的时间。这保证了我们捕获所有可能的配置。 
2.对于每一次`t`在此范围内，计算有多少盏灯亮着。 这需要当时独立评估每个灯。 
3. 对于给定的灯光，确定到目前为止发生了多少次切换`t`。 这是`max(0, (t - b_i) // a_i + 1)`如果`t >= b_i`，否则为零。 如果这个数字是偶数，则灯保持其初始状态； 如果奇数，它就会翻转。 
4. 将计算出的状态与输入字符串中的初始状态进行比较，并确定此时灯是否亮起`t`。 
5. 在所有时刻保持全局最大值。 

检查长达 60 秒的原因是，所有状态变化仅取决于对小周期取模的余数，因此在完整的最小公倍数周期之后，每个灯都经历了整数个完整周期并返回到之前的配置。 

### 为什么它有效

 每个光都演化为周期除以 60 的确定性周期函数。整个系统状态是此类周期函数的向量。 因此，组合系统具有由各个周期的最小公倍数界定的重复周期。 评估一个完整周期可保证所有灯光的每种可能配置至少被观察一次，因此该窗口上的最大值是真正的全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def state_at(t, init, a, b):
    if t < b:
        return init
    if a == 0:
        return init
    flips = (t - b) // a + 1
    return init ^ (flips % 2)

def solve():
    n = int(input())
    s = input().strip()

    init = [1 if c == '1' else 0 for c in s]
    a = []
    b = []

    for _ in range(n):
        ai, bi = map(int, input().split())
        a.append(ai)
        b.append(bi)

    ans = 0

    for t in range(0, 61):
        cur = 0
        for i in range(n):
            if state_at(t, init[i], a[i], b[i]):
                cur += 1
        ans = max(ans, cur)

    print(ans)

if __name__ == "__main__":
    solve()
```功能`state_at`直接根据定义对切换逻辑进行编码。 它计算按时间发生了多少次切换`t`并使用奇偶校验来判断初始状态是否已翻转。 

外层循环结束`t`仅限 61 级台阶，安全地覆盖了整个循环空间。 内循环独立检查每个灯，累积活动灯的数量。
