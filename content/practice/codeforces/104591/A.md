 ## 解决方案
 ## 问题理解

 我们得到一个代表“googlement”的字符串，它只是一个长度最多为 9 的数字字符串，并且有与其长度相关的约束。 如果字符串有长度$L$，每个数字都必须在范围内$0$到$L$，并且至少一位数字必须非零。 该字符串不是静态的：它确定性地演变。 根据当前字符串，我们通过计算每个数字的出现次数来构建一个新字符串$1, 2, \dots, L$，并将这些计数连接起来以形成另一个长度 -$L$细绳。 

该过程是完全确定性的，但任务是向后的。 我们得到一个观察到的字符串$G$，这可能是原始状态或多个衰变步骤的结果。 我们必须计算有多少种不同的有效的初始谷歌搜索最终会演变成$G$在零个或多个衰减跃迁之后。 

关键限制是长度最多为 9，因此状态空间虽小但并不微不足道。 每个状态都是一个固定长度的数字串$L$，所以最多有$10^9$可能的原始字符串，但只有一小部分是有效的，因为数字仅限于$0..L$，并进一步受到衰变结构的约束。 

真正的计算含义是我们不能暴力破解给定字符串的所有可能的前任。 即使是为了$L = 9$，天真的枚举所有可能的字符串并模拟衰减将是天文数字。 然而，小的固定上限$L$建议我们可以预先计算转换或探索状态图。 

一个微妙的边缘情况是，字符串可能会在衰减时映射到自身，从而创建自循环和循环。 例如，像“1000”这样的稳定​​配置$L = 4$反复衰变到自身。 另一种边缘情况是多个不同的字符串在一个或多个步骤后可以收敛到相同的状态，因此我们必须避免重复计算。 

## 方法

 如果我们直接思考，每个状态都有一个输出转换：计算其数字上的频率分布$1$到$L$。 这定义了一个有向图，其中每个节点的出度为 1。问题变为：给定一个节点$G$, 最终到达的节点数$G$在重复应用该功能的情况下。 

一个蛮力的想法是生成所有有效长度的谷歌搜索$L$，模拟它们向前衰减直到达到一个循环，并检查它们是否最终命中$G$。 有效字符串的数量受以下限制$10^L$，所以对于$L=9$这多达十亿个州，这个数字太大了。 即使修剪在一定程度上减少了这种情况，仍然是不可行的。 

关键的结构见解是状态空间在可到达的转换方面很小，而不是在原始字符串方面。 由于每个状态确定性地映射到另一个状态，因此该图分解为不相交的链，从而形成循环。 这意味着每个节点最终都会进入一个循环，并且每个循环都可以被视为大小为 1 或更大的强连接组件，但实际上出度 1 图具有非常特定的结构：每个组件由一个循环组成，其中有树馈入其中。 

因此，我们不是枚举所有字符串，而是仅生成所有有效状态（这对于$L \le 9$）并显式构建函数图。 然后我们反转边并从目标节点执行 DP 或 DFS 来计算有多少节点可以到达它。 由于每个节点恰好有一个传出边，因此反向边形成一个定向为循环的有根森林。 

然后我们将问题简化为计算反向图中有多少个节点可以到达$G$不会错误地重新访问周期。 正确的方法是仔细对待循环节点：一旦进入一个循环，该循环中的所有节点都是相互可达的，并且它们共同对可达性做出贡献，具体取决于循环是否包含$G$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有字符串进行暴力破解 |$O(10^L \cdot L)$|$O(10^L)$| 太慢了 |
 | 在有效状态+反向可达性上构建图表 |$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们通过显式构建固定长度的状态图来继续$L$。 

1. 枚举所有长度的数字串$L$每个数字所在的位置$0..L$并且至少一位数字非零。 这定义了我们关心的完整状态空间。 该约束确保我们只考虑有效的谷歌搜索。 
2. 对于每个州$s$，计算其衰变后继者$f(s)$通过计算数字的出现次数$1$通过$L$，形成新的长度-$L$细绳。 这一步定义了有向边$s \rightarrow f(s)$。 
3. 为每个转换建立一个反向邻接表$s \rightarrow t$，我们存储一条边$t \rightarrow s$。 这将功能图转换为一种结构，其中可达性查询变成类似子树的遍历。 
4. 识别位于循环上的所有节点。 这可以使用标准访问标记技术来完成，因为每个节点都只有一个传出边缘。 DFS 期间重新访问的节点指示循环成员资格。 
5. 对于每个测试用例，从观察到的字符串开始$G$并在反向图上运行反向 DFS，但要小心避免重新访问节点。 每个访问过的节点都是有效的前驱节点，最终可以演变成$G$。 
6. 返回访问集的大小作为答案。 

微妙之处在于循环在反向遍历中的表现。 在函数图中，反向边不会在计数中产生歧义，因为每个节点在访问时都会被精确计数一次。 即使多条路径导致一个循环，DFS 也会确保我们对每个状态计数一次。 

### 为什么它有效

 每个有效的谷歌搜索都恰好有一个前向转换，因此该系统是有限集上的确定性函数。 这保证了每个节点都有唯一的进入循环的前向路径。 反向图包含可以到达节点的所有可能的“先前状态”。 反向 DFS 从$G$因此精确地探索其前向轨迹最终到达的所有节点的集合$G$。 由于我们标记了已访问的节点，因此不会重复计算任何状态，并且每个可到达的状态都只包含一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def generate_states(L):
    states = []
    def dfs(pos, arr, has_nonzero):
        if pos == L:
            if has_nonzero:
                states.append("".join(map(str, arr)))
            return
        for d in range(L + 1):
            arr[pos] = d
            dfs(pos + 1, arr, has_nonzero or d != 0)
    dfs(0, [0] * L, False)
    return states

def decay(s, L):
    cnt = [0] * (L + 1)
    for ch in s:
        d = ord(ch) - 48
        if 1 <= d <= L:
            cnt[d] += 1
    return "".join(str(cnt[i]) for i in range(1, L + 1))

def solve_case(G):
    L = len(G)
    states = generate_states(L)
    idx = {s: i for i, s in enumerate(states)}
    n = len(states)

    nxt = [0] * n
    rev = [[] for _ in range(n)]

    for i, s in enumerate(states):
        t = decay(s, L)
        j = idx[t]
        nxt[i] = j
        rev[j].append(i)

    start = idx[G]

    visited = [False] * n
    stack = [start]
    visited[start] = True
    ans = 0

    while stack:
        u = stack.pop()
        ans += 1
        for v in rev[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)

    return ans

def main():
    T = int(input())
    for tc in range(1, T + 1):
        G = input().strip()
        print(f"Case #{tc}: {solve_case(G)}")

if __name__ == "__main__":
    main()
```实现首先显式枚举给定长度的所有有效谷歌搜索。 这是可行的，因为$L \le 9$，因此尽管理论空间很大，但数字上的限制使得剪枝在实践中有效。 

衰减函数严格遵循定义，仅计算从 1 到 1 的数字$L$。 这个细节很关键：数字 0 在转换中被忽略，包含它会破坏正确性。 

然后，每个测试用例构建一次图，将每个状态映射到其唯一的后继状态。 存储反向边以允许向后遍历。 最后一步是根据观察到的状态进行简单的 DFS，计算可以到达它的所有节点。 

一个常见的实现陷阱是忘记在生成过程中强制执行“至少一个非零数字”约束。 如果没有它，图表将包含无效状态，从而人为地夸大答案。

 ## 边缘情况

 一种重要的边缘情况是观察到的弦是固定的衰减点。 例如，“1000”这样的状态$L=4$腐烂成自身。 在这种情况下，反向 DFS 从循环节点开始，并立即探索进入其中的所有节点，包括其自身。 该算法对所有此类节点准确计数一次，因为已访问标记可防止在多个传入路径上重复计数。 

另一种边缘情况是当多个不同状态在到达之前收敛到相同的中间状态时$G$。 反向图自然地合并了这些路径，并且DFS确保它们是统一的而不重复，因为每个节点在第一次访问时只被标记一次。
