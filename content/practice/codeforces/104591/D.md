 ## 解决方案
 ## 问题理解

 我们给定了一个矩形画布，但坐标可能非常大，因此我们应该将其视为限制在一个巨大盒子内的无限网格。 有些单元格已经固定了亮度值。 每对边缘相邻单元的亮度差异最多为常数 D。任务是为所有剩余单元分配值，以便满足所有约束。 如果可能的话，我们希望最大化所有单元格值的总和。 

查看此问题的一个有用方法是将其视为网格上的图形问题。 每个单元格都是一个节点，边连接上、下、左、右邻居。 该约束表示沿着每条边，函数为 D-Lipschitz，这意味着该值在任一方向上的跳跃幅度都不能超过 D。 

约束的第一个重要含义是任何两个固定单元都已经提出了一致性要求。 如果沿着任意路径从一个固定像元移动到另一个固定像元，则每一步最多可以将值更改 D，因此总差值不能超过 D 乘以曼哈顿距离。 如果两个给定值违反了这一点，则根本不可能完成。 

天真的直觉是，一旦一致性成立，我们就可以向外“传播”约束并贪婪地赋值。 这已经暗示可行性是关于距离一致性，而最优性是在不打破 Lipschitz 约束的情况下将值推得尽可能高。 

R 和 C 达到 1e9 的限制立即排除了任何每单元网格处理。 我们甚至无法明确地触摸大多数细胞，因此解决方案必须依赖于曼哈顿距离引起的几何结构。 

当固定单元间接冲突时，会出现微妙的边缘情况。 例如，两个固定点可能不是邻居，但仍然通过中间区域强制不兼容的约束。 另一种边缘情况是可行性全局成立，但来自一个源的局部贪婪传播稍后超出了另一个固定约束。 

真正的挑战是网格在组合意义上是连续的，我们需要推理全局距离场而不是显式遍历。 

## 方法

 暴力方法会将其视为网格图上的约束传播问题。 从所有固定单元开始，我们可以运行多源 BFS 或最短路径计算，维护所有源引起的每个单元的上限和下限。 每个固定单元 Bi 强制距离 d 处的任何单元 v 必须满足 Bi - D·d ≤ v ≤ Bi + D·d。 交叉所有这些约束给出了每个像元的可行区间，我们将分配该区间中的最大值以使总和最大化。 

这在原则上是正确的，但它立即失败，因为网格尺寸巨大。 即使对于 R 和 C 达到 200，BFS 也可以，但这里 R 和 C 达到 1e9，所以即使存储网格也是不可能的，更不用说访问每个单元格了。 强力推理表明，答案完全由基于距离的函数的几何包络决定。 

关键的观察结果是，每个固定单元在网格上定义了一个“圆锥体”：其影响是函数 Bi 减去或加上 D 乘以曼哈顿距离。 每个像元的最终可行值是这些锥体的交集。 最佳分配是取在所有约束下仍然有效的最高值，该值对应于所有上锥体的最小值。 

因此，我们不再逐个单元地思考，而是转而考虑平面上的函数：

 每个固定点在 (x, y) 上贡献一个分段线性函数，最终答案取决于这些函数的下包络线。 这减少了从网格遍历到曼哈顿距离变换的几何分析的问题。

一旦我们使用旋转坐标 u = x + y 和 v = x - y 重新解释曼哈顿距离，每个约束就变成了 u 和 v 中两个线性函数的最大值。这将问题转化为维持少量半平面诱导线性表面的下包络，这可以在变换空间中通过凸包样式推理来处理。 构建此结构后，可以通过扫描所得分区来计算网格总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 网格上的强力 BFS | O(RC) | O(RC) | 不可能|
 | 变换坐标上的几何包络 | O(N log N) 或 O(N log N + 区域) | O(N) | 已接受 |

 ## 算法演练

 我们将解决方案分为可行性检查和几何表示优化阶段。 

1.首先，我们验证给定的固定单元格是否符合Lipschitz约束。 对于每对固定单元 i 和 j，我们计算它们的曼哈顿距离并检查是否 |Bi - Bj| ≤ D·dist(i, j)。 如果任何一对违反了这一点，答案立即是不可能的。 这是有效的，因为任何有效的完成都意味着约束沿着任何路径都成立，并且曼哈顿距离是网格图中的最短路径长度。 
2.接下来，我们将每个固定单元重新解释为对每个其他单元同时生成两个约束。 一种约束限制了上面的值，另一种约束限制了下面的值：

 Bi - D·dist(p, i) ≤ value(p) ≤ Bi + D·dist(p, i)。 

每个像元处的真实可行值必须位于所有固定像元上所有此类间隔的交集处。 
3. 由于我们想要最大化总和，因此对于每个单元格，我们将始终选择交集允许的最大值。 这意味着我们只需要计算全局上包络线：

 U(p) = (Bi + D · dist(p, i)) 的 i 上的最小值。 
4. 现在，我们使用旋转坐标 u = x + y 和 v = x - y 重写曼哈顿距离。 然后：

 |x-xi| + |y - yi| = max(|u - ui|, |v - vi|)。 

这将每个候选函数转换为 u 和 v 中两个线性函数的最大值：

 Bi + D·dist 成为 (u, v) 上一组仿射表达式的最小值。 
5. 因此，每个固定点在 2D 中贡献恒定数量的线性约束，并且 U(u, v) 成为变换的 2D 空间中 O(N) 平面的下包络线。 平面排列将网格划分为单个固定点主导最小值的区域。 
6. 我们使用 u 和 v 坐标中排序事件的扫描来计算由这些线性函数引起的排列。 在每个区域内，U 是线性的，因此我们可以使用算术级数公式将其对相应子矩形的贡献求和。 
7. 最后，我们对网格中所有单元格的 U(x, y) 求和。 由于区域在变换空间中是轴对齐的，因此每个区域都贡献一个可数的矩形区域，使我们能够计算总和，而无需迭代各个单元。 

### 为什么它有效

 每个可行的分配都以 U 为界，因为 U 在每个点都强制执行来自所有固定源的最强约束。 同时，处处选择 U 满足所有 Lipschitz 约束，因为每个分量函数 Bi + D · dist(p, i) 本身就是 D-Lipschitz，并且 D-Lipschitz 函数的最小值仍然是 D-Lipschitz。 因此，U 既可行又逐点最大，并且最大化总和可简化为在网格上积分此包络。

 ## 边缘情况

 一个关键的边缘情况是两个固定单元在坐标上相距很远，但在亮度上相差太大。 即使它们不相邻，它们仍然会使实例变得不可能，因为没有中间分配可以弥合斜率 D 内的间隙。可行性检查通过比较 |Bi - Bj| 直接捕获这一点。 D 倍曼哈顿距离，防止以后任何错误的“修复”尝试。 

另一种微妙的情况是，所有固定单元格都是一致的，但其中一个单元格位于迫使网格上出现急剧梯度的区域。 在这种情况下，朴素传播可能局部满足约束，但全局失败，而包络公式确保每个点同时遵守来自所有源的最强约束。 

当 N = 1 时，会出现最终的边缘情况。这里，解决方案简化为单个距离锥，并且最佳分配只是用 Bi + D 倍距离结构填充网格。 该算法自然地处理这个问题，因为包络是由单个函数定义的，因此不会出现交叉或冲突。
