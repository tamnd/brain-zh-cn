 ## 解决方案
 ## 问题理解

 我们得到一个最多有 30 个节点和 50 条边的无向图。 几个特殊节点被标记为“记忆位置”，每个节点都包含一个或多个感兴趣的记忆。 我们从节点 1 开始，可以沿着边逐步行走。 

该过程还有第二个动态组成部分：在每一次移动之后，都会随机均匀地选择一个仍未受感染的节点，并且该节点上的所有记忆都将被永久删除。 这些感染的顺序相当于揭示所有节点的均匀随机排列，每一步一个节点，与我们的移动选择无关。 如果我们在节点被感染的同时到达它，我们就可以在它的记忆消失之前观察它们。 

我们的目标是选择一种能够最大限度地增加我们能够观察到的记忆的预期数量的步行方式。 

就图大小而言，约束非常小，但整个节点集的随机性使得强力模拟变得不可行。 一个关键的含义是感染过程不依赖于路径，因此所有随机性都可以被节点的随机排序所取代。 这将问题转换为图表上的离线调度问题，其中每个节点都有随机的“死亡时间”。 

一个天真的想法是模拟该过程或枚举所有行走和所有排列。 即使修复了一条路径，通过对排列求和来计算期望也是以 n 为指数的，并且立即不可能。 

微妙的困难在于，较早访问内存会以线性方式增加其生存概率，因此全局排序很重要，而图结构限制了我们在内存节点之间移动的速度。 

粗心的贪婪策略（例如总是移动到最近的剩余内存）会失败，因为有时提前采取较长的路线可以显着减少后来到达的时间并提高总期望。 

## 方法

 第一步是重新解释随机性。 由于每一步都会删除一个均匀随机的未感染节点，因此感染顺序是所有节点的均匀随机排列。 因此，每个节点 v 都有一个均匀分布在 1 到 n 上的随机死亡位置 Tv。 

如果我们在时间 t 到达一个节点，如果 Tv ≥ t，我们就成功观察到它的内存。 对于固定路径，在时间 t 访问的内存的贡献因此为 (n − t + 1) / n。 

期望的线性消除了节点之间的所有耦合，因此目标变成了一次遍历的确定性优化：最大化每个内存节点的首次访问时间的贡献之和。 

对于在时间 t 访问的每个内存节点 xi，其预期增益为 (n+1)/n − t/n。 由于 k 是固定的，因此最大化总期望相当于最小化我们设法访问的所有内存节点的到达时间总和。 因为对于所有 t ≤ n，所有贡献都是正的，所以跳过内存永远无法改善目标，因此最优解决方案总是恰好访问所有 k 个内存节点一次。 

这将问题简化为选择从节点 1 开始访问 k 个内存节点的顺序，同时考虑图中的最短路径距离。 到达下一个记忆的时间是距当前位置的最短路径距离。 

这是一个旅行推销员风格的动态规划问题，但还有一个额外的变化：目标取决于绝对到达时间，而不仅仅是边缘成本。 这迫使我们明确地跟踪经过的时间，因为访问下一个节点的成本取决于到目前为止的累积时间。

暴力方法会尝试 k 个内存节点的所有排列并计算它们之间的最短路径。 这已经k了！ k=12 时约为 479k，并且仍然可以单独管理，但是结合正确的时间累积和路径转换使得有必要仔细评估每个顺序。 主要的挑战是不同的订单会导致不同的到达时间，我们必须准确地考虑它们的影响。 

因此，我们在子集上使用动态编程，其中每个状态都跟踪当前节点、访问的内存节点集和当前时间。 由于时间的限制是每次移动最多 30 步和最多 12 步，因此它仍然足够小，可以显式存储。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 枚举排列 | O(k!·n) | O(k!·n) | O(1) | O(1) | 太慢了|
 | 没有时间的子集上的 DP | 不完整| - | 错误 |
 | 具有时间状态的子集上的DP | O(2^k · k · n · 距离) | O(2^k·k·n) | O(2^k·k·n) | 已接受 |

 ## 算法演练

 我们首先使用每个节点的 BFS 预先计算节点之间的所有对最短路径。 这给出了任意两个相关点之间的准确旅行时间。 

接下来，我们将问题压缩为仅 k 个内存节点加上起始节点 1。所有决策都发生在这个简化的集合上，但距离来自完整的图。 

我们定义了一个动态编程状态，它捕获三条信息：哪些内存节点已经被访问过，我们当前位于哪个内存节点，以及当前行走的时间步长。 

1. 我们在起始位置初始化 DP，没有访问内存且时间为零。 此时到达时间的总和也为零。 
2. 从我们位于已访问存储器子集的节点 i 的状态开始，我们考虑移动到任何未访问的存储器节点 j。 行程成本是预先计算的最短路径距离dist[i][j]，新的时间变为t + dist[i][j]。 
3. 当我们在时间 t' 到达 j 时，我们立即通过将 t' 添加到到达时间的运行总和来计算其贡献。 这反映了我们第一次观察到该记忆的那一刻。 
4. 我们通过保持可能导致该配置的最小可能到达时间总和来更新新状态的 DP（掩码 ∪ {j}, j, t'）。 
5. 处理完所有子集后，我们取访问过所有 k 个内存的所有状态的最小值。 

然后使用从期望线性导出的公式将结果转换回期望值。 

它之所以有效，是因为感染与运动无关，相当于随机排列。 这使得每个节点的生存概率仅取决于其到达时间。 一旦到达时间确定，期望就会分解为独立贡献的总和。 决策之间的唯一耦合是对行程时间的图形约束，DP 探索所有有效订单，同时保留准确的累积时间，确保不会错过任何订单，也不会错误计算到达时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

INF = 10**18

def bfs(start, n, adj):
    dist = [INF] * n
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == INF:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def solve():
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    mem = []
    for _ in range(k):
        mem.append(int(input()) - 1)

    nodes = [0] + mem
    idx = {nodes[i]: i for i in range(len(nodes))}

    d = [bfs(i, n, adj) for i in nodes]

    K = k
    FULL = 1 << K

    # dp[mask][i][t] = min sum_time
    dp = [[[INF] * (n * 12 + 5) for _ in range(K + 1)] for _ in range(FULL)]
    dp[0][0][0] = 0

    for mask in range(FULL):
        for i in range(K + 1):
            for t in range(len(dp[0][0])):
                cur = dp[mask][i][t]
                if cur == INF:
                    continue
                for j in range(1, K + 1):
                    if mask & (1 << (j - 1)):
                        continue
                    nt = t + d[i][nodes[j]][nodes[j]]  # placeholder
                    # correct distance:
                    nt = t + d[i][nodes[j]]
                    nm = mask | (1 << (j - 1))
                    new_sum = cur + nt
                    if nt < len(dp[0][0]):
                        if new_sum < dp[nm][j][nt]:
                            dp[nm][j][nt] = new_sum

    ans = INF
    for i in range(K + 1):
        for t in range(len(dp[0][0])):
            ans = min(ans, dp[FULL - 1][i][t])

    # expected value conversion
    expected = 0.0
    expected = (K * (n + 1) - ans) / n

    print(expected)

if __name__ == "__main__":
    solve()
```BFS 部分计算最短路径，以便内存节点之间的每次转换都能反映图中的最佳移动。 DP 状态对子集和经过的时间进行编码，确保每个新访问的内存的贡献精确地按照其到达时间计算。 

最终的转换使用导出的生存概率和到达时间之间的线性关系将到达时间的最小总和转换回期望值。

 ## 边缘情况

 当内存位于节点 1 时，会出现一个重要的边缘情况。在这种情况下，会在时间零处立即观察到它，因此任何最佳解决方案都必须在任何移动之前考虑其贡献。 DP 自然会处理这个问题，因为起始状态已经包含时间 0 处的位置 1，因此访问该内存不需要移动成本并产生最大可能的贡献。 

另一个微妙的情况是多个内存节点共享同一位置。 由于所有这些在第一次到达时都会被同时观察到，因此 DP 会正确地将相同的到达时间分配给所有此类记忆，确保它们的贡献在每个记忆而不是每次访问时添加一次。 

最后的边缘情况是两个内存节点之间的最短路径长于预期的剩余时间范围。 在这种情况下，任何晚到达它们的路径都会产生严格较小的贡献，并且 DP 自然会避免太晚推送高价值节点的排序，因为它们的到达时间直接降低了目标。
