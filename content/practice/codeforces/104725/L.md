 ## 解决方案
 ## 问题理解

 我们有一个整数变量的小系统。 变量最多有6个，每个变量代表游戏中角色的一个属性，每个属性可以是0到K之间的任意整数。 

除了这些变量之外，还有多达 100 名评委。 每个法官都会查看两个不同的属性，并检查涉及这两个值的简单线性条件。 如果满足条件，则该评委将给出固定分数。 条件始终采用“两个选定属性的线性组合最多是一个阈值或至少是一个阈值”的形式，其中每个系数限制为 -1、0 或 1。 

任务是为所有属性选择值，以使所有满意的评判分数的总和最大化。 

关键结构是每个约束仅依赖于两个变量，并且每个变量的域大小很小。 这立即表明，即使约束看起来像一个小的约束满足问题，我们也可以枚举分配。 

这些约束使得暴力破解变得可行，因为搜索空间大小最多为 (K+1)^n。 当 n ≤ 6 且 K ≤ 8 时，每个变量最多有 9 个值，因此赋值总数为 9^6 = 531441。对于每个赋值，我们最多可以评估 100 个约束，在最坏的情况下给出大约 5 × 10^7 次操作，这在具有严格实现的 Python 中是可以接受的。 

一个微妙的边缘情况是任何分配都可能无法满足约束。 在这种情况下，他们根本不应该做出贡献。 另一个微妙的情况是，根据系数，不等式可能始终为真或始终为假，因此解决方案不得假设约束是“平衡的”或有意义的。 

## 方法

 一种幼稚的解释是将其视为对具有成对约束的整数变量的一般优化，并尝试通过约束传播或贪婪赋值来解决它。 这一方向失败了，因为变量之间不存在单调结构，也没有独立性：更改一个变量会影响涉及它的所有约束。 

然而，小领域改变了一切。 由于每个变量只有 9 个可能的值，而且变量也只有 6 个，所以我们可以直接枚举所有可能的赋值。 对于每个作业，我们在恒定时间内评估每个判断条件。 

蛮力之所以有效，是因为搜索空间足够小，可以完全探索，但如果变量数量或域大小很大，它就会失败。 由于观察到 n 很小，因此将原本困难的优化问题转换为直接枚举问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| O((K+1)^n·m) | O((K+1)^n·m) | O(1) | O(1) | 已接受 |
 | 优化 DP / 贪婪（不需要）| 没有明确定义| O(1) | O(1) | 不必要|

 ## 算法演练

 我们枚举所有可能的 n 个属性值分配，并计算每个分配的分数。

1. 生成所有元组 (A1, A2, ..., An)，其中每个 Ai 的范围从 0 到 K。这是对状态空间的完整搜索，确保不会遗漏任何候选解。 
2. 对于每项作业，将跑步分数初始化为零。 该分数代表所有评委对此特定配置的总贡献。 
3. 迭代所有 m 个判断器。 每个判断引用两个索引 i 和 j 以及一个条件类型 op。 
4. 对于每个判断，计算线性表达式 a * Ai + b * Aj。 如果op为0，则检查该值是否小于或等于d。 如果op为1，检查它是否大于或等于d。 
5. 如果满足条件，则将 v 添加到当前作业的分数上。 
6.处理完本次作业的所有评委后，如果当前分数较大，则更新全局最高分数。 
7. 处理完所有作业后，输出找到的最高分数。 

其有效的关键原因是每个可能的作业都会被评估一次，并且评分函数在给定作业的情况下是完全确定的。 不同的分配之间没有交互作用，因此全局最优必须出现在枚举集中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, K = map(int, input().split())
    cons = []
    for _ in range(m):
        i, j, op, a, b, d, v = map(int, input().split())
        i -= 1
        j -= 1
        cons.append((i, j, op, a, b, d, v))

    best = 0
    A = [0] * n

    def dfs(idx):
        nonlocal best
        if idx == n:
            score = 0
            for i, j, op, a, b, d, v in cons:
                val = a * A[i] + b * A[j]
                if op == 0:
                    if val <= d:
                        score += v
                else:
                    if val >= d:
                        score += v
            if score > best:
                best = score
            return

        for x in range(K + 1):
            A[idx] = x
            dfs(idx + 1)

    dfs(0)
    print(best)

if __name__ == "__main__":
    solve()
```该实现对所有分配使用深度优先枚举。 数组 A 存储当前的部分赋值。 一旦分配了所有变量，代码就会在一次传递中评估所有约束。 

一个常见的陷阱是忘记输入中的索引是从 1 开始的，因此必须将它们转换为从 0 开始的索引。 另一个微妙的点是确保 A 在递归中重用而不是重新创建，这避免了不必要的开销。

 第一个示例对应于具有三个变量和五个约束的情况。 一个有效的分配是 A1 = 1、A2 = 0、A3 = 1，这会产生 12 分的总分。评估通过对照此固定向量检查每个约束并仅对满足的约束求和来进行。

 ## 边缘情况

 常见的边缘情况是无法满足约束。 在这种情况下，无论分配如何，它都没有任何贡献。 该算法自然会处理这个问题，因为它仅在条件评估为 true 时添加 v。 

另一种情况是总是满足约束。 例如，如果 a = 0、b = 0、op = 0 并且 d ≥ 0，则每个赋值都满足它。 蛮力评估仍然对所有状态进行一致的计数，因此它只是成为每个分数的恒定相加。 

第三种情况是最优解依赖于变量的极值。 由于枚举明确包含从 0 到 K 的所有值，因此边界最优值始终包含在搜索空间中，因此不需要特殊处理。
