 ## 解决方案
 ## 问题理解

 我们得到了一个大型有向完整图结构，该结构并不需要显式处理。 完整的图表包括$K$相同的块，每个块包含$n$城市。 在每个街区内，每对有序的不同城市都有一条有向道路，因此每个街区都是一个没有自环的完全有向图。 跨块，结构是相同的，意思是块$t$是块 1 的移位副本。 

根据一系列内容删除一个块内的一些有向边$m$禁止对。 因为所有块都是相同的，每当有边$u \to v$当块 1 中的边被移除时，每个块中相应的边也被移除。 

删除后，要求我们准确选择$nK - 1$剩余图中的有向边并将其标记为“快速道路”，以便仅使用这些选定的边，每个城市都可以到达其他城市。 换句话说，选定的边必须形成一个有向结构，保证所有边的完全可达性$nK$节点。 

任务是计算以 998244353 为模存在多少个这样的选择。 

一个关键的观察结果来自于尺寸限制。 城市数量达$nK$， 在哪里$K$可以大到$10^8$。 这立即排除了任何显式构建或迭代所有城市或边缘的算法。 一切都必须简化为仅取决于本地块大小的结构$n$，加上组合推理$K$。 

出现微妙的边缘情况时$m = 0$，意味着每个区块都是一个完整的锦标赛（完整的有向图）。 在这种情况下，内部结构是最大对称的，答案完全取决于如何解释块间连接模式。 另一个边缘情况是，当删除使块内的某些节点在传出或传入结构方面部分隔离时，这可能会影响最终选择的图是否可以满足全局可达性约束。 

一种简单的方法会尝试枚举所有跨越有向结构$nK$节点，相当于计算约束下的有向生成树或树状结构。 即使对于中等$nK$，这会组合爆炸。 

## 方法

 直接尝试会将任务解释为选择$nK-1$边形成一个结构，确保每个节点都可以到达所有其他节点。 在强连通有向图中，必要条件是存在至少一个有向跨越结构，例如扎根于某处的树状结构。 然而，这里我们没有给出一个一般的图表，而是一个固定的重复模式$n$-节点模板已复制$K$次。 

如果我们忽略结构，我们可能会尝试计算有向生成树的数量$nK$删除后的节点。 这已经太大了，因为矩阵树定理需要一个$(nK)\times(nK)$拉普拉斯算子，不可能$K$最多$10^8$。 

关键的结构见解是，除了全局要求之外，所有块都是相同且独立的。 每个块的行为就像一个模板图$n$节点。 完整的图表本质上是这个模板的放大图$K$。 任何有效的全局结构都必须尊重这种重复：一个块内的选择决定所有块中的选择。 

这种对称性将问题简化为了解一个块上存在多少个有效的“局部配置”，然后将该结构提升到整个块上$K$相同的副本。 全局连接性要求迫使块之间的流向单一的全局方向，将问题分解为计算模板内根状结构的选择，然后跨块将它们相乘地组合。 

一旦减少，问题就变成了在约束有向完整图中计算跨越树状结构$n$节点，然后提升或组合该结构$K$带有简单组合因子的副本，说明如何将全局根放置在$K$相同的块。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力结束$nK$-图| 指数| 指数| 太慢了|
 | 分块分解+局部计数 |$O(n^3)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们将问题简化为计算单个块上定义的有向图中的跨越树状结构。 

1. 建立邻接结构$n$-节点模板图。 最初，每个有序对$u \ne v$是一条边，然后删除$m$禁止的有向边。 这代表单个块的内部连接性。 我们隔离一个区块的原因是所有$K$块的行为相同，因此所有组合结构都是从该模板导出的。 
2. 构造用于定向生成树计数的拉普拉斯矩阵。 对于每个节点$i$，将对角线入口设置为其出度，并且对于每条边$i \to j$，在矩阵位置减1$(i, j)$。 该矩阵编码了如何通过矩阵树定理对以节点为根的跨越树状结构进行计数。 
3. 使用拉普拉斯矩阵的辅因子行列式计算以固定节点为根的有向生成树的数量。 这给出了在一个块内定向内部结构的有效方法的数量，以便它可以充当最终全局结构中的连接组件。 
4. 从一个区块扩展到$K$块。 由于除了全局连接性要求之外，所有块都是相同且独立的，因此最终的结构可以被视为选择一个独特的“根块”来锚定全局可达性。 有$K$该根块的选择以及每个块内的内部跨越结构必须有效。 
5. 将有效内部结构的数量乘以根块的选择数量。 这将产生最终计数模 998244353。 

### 为什么它有效

 分解依赖于这样一个事实：该图是相同模板的笛卡尔重复。 任何全局有效的集合$nK-1$当块收缩时，确保可达性的边缘必须限制为跨越树状结构。 由于所有块都是相同的，唯一的全局自由度是哪个块充当结构根。 一旦根块被固定，所有内部配置都是相同生成树计数的独立且相同的副本。 这种不变性保证了计数中不会出现跨块不对称。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def det(mat):
    n = len(mat)
    res = 1
    for i in range(n):
        pivot = -1
        for j in range(i, n):
            if mat[j][i] != 0:
                pivot = j
                break
        if pivot == -1:
            return 0
        if pivot != i:
            mat[i], mat[pivot] = mat[pivot], mat[i]
            res = -res
        inv = pow(mat[i][i], MOD - 2, MOD)
        res = res * mat[i][i] % MOD
        for j in range(i, n):
            mat[i][j] = mat[i][j] * inv % MOD
        for j in range(i + 1, n):
            factor = mat[j][i]
            if factor:
                for k in range(i, n):
                    mat[j][k] = (mat[j][k] - factor * mat[i][k]) % MOD
    return (res % MOD + MOD) % MOD

def solve():
    n, m, K = map(int, input().split())
    
    bad = set()
    for _ in range(m):
        u, v = map(int, input().split())
        bad.add((u - 1, v - 1))

    # build Laplacian for directed graph
    L = [[0] * n for _ in range(n)]

    for i in range(n):
        outdeg = 0
        for j in range(n):
            if i != j and (i, j) not in bad:
                outdeg += 1
        L[i][i] = outdeg

    for i in range(n):
        for j in range(n):
            if i != j and (i, j) not in bad:
                L[i][j] = (L[i][j] - 1) % MOD

    # remove last row/col for cofactor
    M = [row[:-1] for row in L[:-1]]
    ways = det(M)

    # K identical blocks, choose root block
    print(ways * (K % MOD) % MOD)

if __name__ == "__main__":
    solve()
```该代码首先对禁止边进行编码，然后构建剩余有向模板图的拉普拉斯算子。 跨越植根于固定节点的树状结构的拉普拉斯计数减少的决定因素。 这是一个块的核心组合量。 

最终乘以$K$反映了选择哪个块作为全局结构根，因为所有块都是对称副本。 行列式例程执行模块化高斯消除，仔细跟踪行交换和模块化逆。 

一个微妙的实现细节是，所有算术都必须以 998244353 为模执行，并且透视必须通过检查有效的透视行来避免被零除。 矩阵大小最多为$n-1 \le 299$，这对于$O(n^3)$消除。

 ## 边缘情况

 一种边缘情况是在模板内删除节点的所有传出边缘。 例如，如果$n=2$和边缘$1 \to 2$被移除后，节点 1 没有出边。 拉普拉斯算子具有零行结构，并且行列式变为零。 该算法正确地输出零，反映出不可能形成任何跨越树状结构。 

另一种情况是当$m=0$，因此每个节点都具有完全连接。 拉普拉斯算子成为一个完整的有向图矩阵，其中每个节点都有出度$n-1$。 行列式计算产生完整有向图中有根生成树的经典计数，并乘以$K$只是考虑了根块的选择。 这个例子表明，对称性是纯粹通过线性代数处理的，不需要特殊的外壳。
