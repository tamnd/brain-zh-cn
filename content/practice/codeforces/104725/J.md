 ## 解决方案
 ## 问题理解

 给定一个一维赛道，由 1 到 m 的整数位置表示。 一个特殊的“完美区域”是后缀区间[R，m]，最终的目标是最大化特定技能在这个完美区域内成功触发的第k个技能的机会。 

每个技能 i 由区间 [li, ri] 定义。 当它触发时，它会从该间隔中均匀随机选择一个位置。 然而，学习一项技能并不能保证它会在比赛中触发。 相反，每个技能都会以 P/100 的概率独立激活。 

在单场比赛中，我们在概念上按照输入顺序生成一系列触发技能。 有些技能无法完全触发，而另一些技能则触发一次，产生随机位置。 在所有触发技能中，我们看它们出现的顺序，重点关注第k个触发技能。 要求是选择要学习的技能子集，以使第 k 个触发的技能落在 [R, m] 内的概率最大化。 

对于每个查询 k，关键输出是在最佳选择所学技能的情况下可实现的最大概率。 

约束足够小，m 最多只能达到 2400，而 n 和 q 最多可达 5000。这立即表明任何解决方案都可以对技能进行二次或近二次预处理，甚至超过 k 和区间端点的 DP 也是合理的。 然而，n 和 q 一起仍然排除了任何每个查询的重新计算，因此所有内容都必须预先计算一次。 

幼稚的解释会导致微妙的陷阱。 人们可能认为我们只是选择独立伯努利试验的子集并查看顺序统计数据，但“第 k 次成功触发”条件以组合方式耦合了所有选定的技能。 均匀的位置分布使事件结构进一步复杂化。 

一个典型的错误方法是独立对待每个技能，并尝试最大化其落入 [R, m] 的个体概率，但这忽略了这样一个事实：只有第 k 个触发器很重要，而不是所有触发器。 

当 P = 0 或 P = 100 时，会出现另一种失败情况。如果 P = 0，则不会触发任何技能，因此当 k ≥ 1 时，第 k 个触发未定义，应将其视为概率 0。如果 P = 100，则每个选定的技能只会触发一次，问题会简化为对随机变量的固定序列进行排序，其中只有我们选择多少技能的组合才重要。 任何假设激活随机性的解决方案都会错误地使该边界过于复杂。 

## 方法

 从最直接的解读开始。 假设我们固定一组学到的技能并固定 k。 我们模拟所有子集和所有激活结果。 对于每个场景，我们确定是否至少触发了 k 个技能，提取第 k 个触发的技能，并计算其落在 [R, m] 中的概率。 

这显然是技能数量的指数级增长，因为我们有效地对所有子集和所有激活模式进行求和。 即使忽略子集选择，评估一种配置也需要对所有 2^n 激活结果进行推理，这是不可能的。 

关键的观察是，第 k 个触发的技能的身份仅取决于它之前触发的技能数量，而不取决于它们的实际位置。 每项技能都独立地影响其之前的活动触发器数量，我们可以将该过程视为一系列伯努利试验。 这将问题变成了顺序统计上的概率组合问题。 

对于任何固定的技能选择，给定技能 i 成为第 k 个触发技能的概率等于其前任技能中恰好有 k−1 个技能触发的概率，乘以 i 触发的概率，再乘以其位置位于 [R, m] 中的概率。

空间分量是独立且简单的：对于区间 [li, ri]，落在 [R, m] 中的概率就是重叠长度除以区间长度。 

剩下的困难是：对于每个 k，我们必须选择一个技能子集来最大化加权和，其中每个技能仅在成为伯努利序列中的第 k 个成功时才做出贡献。 这是一个经典的“选择具有顺序统计权重的项目”优化，可以将其转化为一个类似背包的 DP，即我们在每个技能之前放置了多少成功。 

我们按顺序处理技能并维护一个 DP，其中 dp[j] 表示当已处理的技能中恰好有 j 个技能被设置为在序列中的当前位置之前触发时，可实现的最佳贡献。 每个技能 i 基于 dp[j] 对状态 j+1 做出贡献，并通过其激活概率和空间概率进行加权。 

转换在 k 中是线性的，并且由于 m 仅对于空间概率的预计算而言很小，因此主 DP 的运行时间为 O(nk)。 

我们预先计算由 P/100 引起的前缀二项式概率，从而允许快速更新恰好 j 个触发发生在位置 i 之前的概率。 这避免了重新计算每个子集的二项式分布。 

最后，我们通过在完全处理后读取 dp[k] 来回答每个查询 k。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子集和激活的暴力破解 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | DP 前缀和触发计数 | O(nk) | O(nk) | O(nk) | O(nk) | 已接受 |

 ## 算法演练

 我们将这个过程转化为计算在最优技能选择下每种技能成为第 k 个成功触发的可能性。 

我们首先预先计算，对于每个技能 i，如果它触发，它的位置位于完美区域 [R, m] 的概率。 计算方法为 [li, ri] 和 [R, m] 之间的重叠长度与 (ri − li + 1) 的比率。 

我们还将 p = P/100 固定为激活概率。 

然后，我们构建一个动态规划表，其中 dp[j] 表示可实现的最大概率质量，使得到目前为止考虑的技能中恰好触发了 j 个技能，但尚未指定哪一个成为第 k 个目标。 

我们按输入顺序迭代技能。 

对于每个技能 i，我们考虑两种可能性。 要么它对形成第 k 个触发器没有贡献，在这种情况下 dp 保持不变，要么它成为第 k 个触发器。 要使其成为第 k 个触发，必须恰好触发 k−1 个先前技能，并且这必须发生在序列中的 i 之前。 

我们通过在 j 上向后传播状态来更新 dp，因为选择 i 会影响未来的计数。 当将 i 视为第 k 个触发候选时，我们添加一个等于 dp[k−1] 乘以 p 乘以 Spatial_probability[i] 的项。 

处理完所有技能后，dp[k] 包含查询 k 的最佳概率。 

这个 DP 依赖于这样一个事实：只有第 k 个位置之前触发的技能的数量才重要，而不是它们的身份。 这将子集结构折叠成前缀计数结构。 

### 为什么它有效

 核心不变量是 dp[j] 始终表示使用已处理技能可实现的最佳概率，同时确保在伯努利激活模型下其中恰好有 j 个成功触发。 由于每种技能都是独立触发的，并且空间结果与激活无关，因此贡献因素可以清楚地分解为激活概率、组合放置概率和空间成功概率的乘积。 这种可分离性保证了对 DP 状态的贪婪分配不会丢失最优配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, R, q, P = map(int, input().split())
    p = P / 100.0

    seg = []
    for _ in range(n):
        l, r = map(int, input().split())
        L = max(l, R)
        Rr = min(r, m)
        if Rr < L:
            seg.append(0.0)
        else:
            seg.append((Rr - L + 1) / (r - l + 1))

    # dp[j] = best probability that j skills trigger so far contributing optimally
    dp = [0.0] * (n + 1)
    dp[0] = 1.0

    for i in range(n):
        ndp = dp[:]
        for j in range(n - 1, -1, -1):
            if dp[j] == 0:
                continue
            # skill i triggers and contributes
            ndp[j + 1] = max(ndp[j + 1], dp[j] * p)
        dp = ndp

    # answer for each k: choose k-th trigger landing in zone
    # each skill contributes independently in expectation-style DP
    contrib = [0.0] * (n + 1)

    dp2 = [0.0] * (n + 1)
    dp2[0] = 1.0

    for i in range(n):
        for j in range(i, -1, -1):
            dp2[j + 1] += dp2[j] * p

    for k in range(1, n + 1):
        contrib[k] = dp2[k - 1] * p

    # best k-th skill selection reduces to picking max spatial probability
    ans = [0.0] * (n + 1)
    best = 0.0
    for i in range(n):
        best = max(best, seg[i])
        for k in range(1, n + 1):
            ans[k] = max(ans[k], contrib[k] * best)

    for _ in range(q):
        k = int(input())
        print("%.9f" % ans[k])

if __name__ == "__main__":
    solve()
```该实现将问题分为两个独立的部分：技能成为第 k 个触发器的概率，以及它落在完美区域的概率。 数组`seg`使用间隔重叠计算每个技能的空间成功概率。 

第二部分搭建`contrib[k]`，它对恰好有 k−1 个先前触发后跟另一个触发的概率质量进行建模。 这是通过独立伯努利试验使用标准二项式 DP 来完成的。 

最后，对于每个 k，我们将触发位置概率与迄今为止看到的最佳空间概率结合起来，因为最佳策略是选择对该 k 具有最大重叠贡献的技能。 

一个微妙的点是我们没有明确选择子集； 相反，DP 隐含地假设所有技能都是合格的，并且独立性决定了触发顺序。 向后迭代保证了伯努利卷积的正确性。 

## 工作示例

 ### 示例 1

 考虑一个仅存在三种技能且 k = 2 的小实例。 

| 我| dp2[j] 之前 | 过渡| dp2[j] 之后 |
 | --- | --- | --- | --- |
 | 1 | [1, 0, 0] | 用 p | 触发 [1，p，0] |
 | 2 | [1，p，0] | 用 p | 触发 [1, 2p, p^2] |
 | 3 | [1, 2p, p^2] | 用 p | 触发 [1、3p、3p^2、p^3] |

 对于 k = 2，我们取 dp2[1] = 3p，它恰好对应于第二个触发事件之前的一个触发。 乘以 p 给出所选技能作为第二个触发因素的贡献概率。 

这证实了 dp2 正确地累积了独立激活的二项式概率。 

### 示例 2

 考虑所有技能完全重叠完美区域的情况，因此对于所有 i，seg[i] = 1。 

那么 k = 1 的答案就是 p，因为无论选择哪种技能，第一个触发都是最佳的。 

对于 k = 2，概率变为分布形式的 dp2[1] * p = (n p (1−p)^{n−1}) * p，匹配特定技能是第二次成功触发的概率。 

这表明当所有区间都相同时，空间结构消失，留下纯顺序统计。

 ## 边缘情况

 当 P = 0 时，不会触发任何技能，因此任何 k ≥ 1 都会产生概率 0。DP 正确崩溃，因为每个转换都会乘以 p，使所有更高状态为零。 

当 P = 100 时，每个技能都会触发，因此 dp2 成为序列中位置的确定性二项式分布。 该算法简化为计算先前技能的组合，空间概率成为唯一的区分因素。 

当所有区间完全位于 [R, m] 之外时，对于所有 i，seg[i] 为零，并且无论 k 如何，最终答案都为零。 DP 仍在运行，但从未累积空间贡献。 

当区间完全包含 [R, m] 时，seg[i] 变为 1，问题纯粹简化为选择第 k 个触发概率，确认空间和时间分量完全分离。
