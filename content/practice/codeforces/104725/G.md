 ## 解决方案
 ## 问题理解

 我们正在模拟两支类似神奇宝贝的战士有序队伍之间的回合制决斗。 每个队伍都是一个单位队列，任何时候只有每个队伍的最前面的单位处于活动状态。 两名玩家轮流轮流，从爱丽丝开始。 每回合，主动单位只选择一个动作：物理攻击、魔法攻击或具有能量消耗和固定伤害的终极技能。 

物理和魔法攻击造成的伤害会根据对手相应的防御力而减少，而终极伤害会造成固定的真实伤害，但需要积累能量。 能量从零开始，在该单位每次使用物理或魔法攻击后增加一，并在使用终极技能时消耗。 该单位在攻击后移动到其队伍的后面。 如果一个单位将对手的生命值降低到零或以下，对手当前的单位将立即被下一个活着的单位取代。 

战斗将持续进行，直到一个团队耗尽神奇宝贝或完成 K 整轮，其中一轮被定义为爱丽丝的移动随后是鲍勃的移动。 如果K回合后双方均未获胜，则结果为平局。 

输入大小达到每边 100,000 个 Pokémon，K 达到 1,000,000，而所有统计数据都大到 10^8。 这立即排除了任何在所有 K 轮中处理单个能量或逐轮状态转换的模拟。 即使 O(K) 也是可以接受的，但任何依赖于每个神奇宝贝内部战斗状态的每个动作模拟的东西，如果它天真地重新计算决策，就会太慢。 

关键的微妙之处在于，每个单位的行动选择仅取决于其当前的能量和对手当前的统计数据。 然而，对手也会随着时间的推移而变化，因此双方所有技能的每回合重新计算仍然是 O(K)，这很好，但是重新计算更深层次的状态转换或显式地模拟每个动作的每个能量增量是不必要的开销。 

一个常见的故障案例来自于对单元开关之间的能量积累管理不善。 例如，如果神奇宝贝切换进来，它的能量就会重置为零。 忘记这一点会导致最终使用时间不正确。 

另一个微妙的问题是打破平局。 当多个动作造成相同伤害时，必须选择物理或魔法而不是终极。 如果忽略此规则，实施可能会错误地浪费能量或产生不同的损坏序列。 

最后，必须谨慎处理“回合限制”条件。 游戏在 K 个完整的对棋步结束后结束，而不是 K 个单独的棋步结束，因此半轮停止会导致错误的结果。 

## 方法

 蛮力的想法很简单：完全按照描述模拟每个动作。 在每个回合，通过评估对手当前活跃单位的物理、魔法和终极伤害，计算活跃神奇宝贝的最佳行动。 施加伤害、更新生命值、管理能量，并在神奇宝贝晕倒或完成动作时轮换神奇宝贝。 

这是有效的，因为规则是完全确定性的和局部的。 每个决定仅取决于当前的统计数据和能量。 然而，代价是我们每回合重新计算三个伤害值，并在可能的 2K 回合中维持状态转换。 由于 K 可以达到 10^6，如果仔细完成，这在 Python 中仍然是可行的，但隐藏的问题不是每回合的计算，而是如果简单地使用列表和删除来实现团队转换和重复对象操作的低效处理。 

如果试图用不必要的结构重新计算“最佳攻击”或频繁重建队列，则会出现进一步的低效率。

关键的观察是，每一回合在结构上都是独立的：我们只需要每一侧当前的前端神奇宝贝，以及指向剩余队列的指针。 我们永远不需要重温过去的状态。 因此，我们可以维护数组的索引，而不是使用昂贵的队列操作。 

这将模拟简化为具有恒定时间转换的 O(K) 简单算术运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 使用列表操作进行暴力模拟 | O(K·n/a) | O(K·n/a) | O(n + m) | 太慢了 |
 | 优化的基于指针的模拟 | O(K) | O(n + m) | 已接受 |

 ## 算法演练

 我们维护两个代表每个团队的数组和一个指示当前活动神奇宝贝的指针。 每个神奇宝贝还会追踪其剩余生命值和当前能量。 

在每一个回合，我们都会计算活跃神奇宝贝的最佳动作。 

1.读取Alice和Bob队列中最前面的神奇宝贝，以及它们当前的HP和能量。 
2. 物理伤害计算为 max(0, A − 对手物理防御)。 
3. 将魔法伤害计算为 max(0, B − 对手魔法防御)。 
4. 将最终伤害计算为 W，但前提是能量 ≥ E； 否则视为不可用。 
5. 选择伤害最大的动作。 如果物理或魔法与终极技能有联系，则根据需要优先选择物理或魔法而非终极技能。 
6.对对手当前生命值造成伤害。 
7.如果使用物理或魔法，能量增加1； 如果使用终极，则将能量减少 E。 
8.如果对手HP≤0，则将对手指针前进到下一个神奇宝贝并重置该神奇宝贝的HP和能量状态。 
9. 交换回合并重复，直到完成 K 轮或一支队伍耗尽。 

这种结构背后的原因是，能量和生命值的演变仅取决于当前的相互作用对，因此我们永远不需要超出每个神奇宝贝当前状态的历史跟踪。 

它起作用的原因是，在任何时刻，整个游戏状态都由两个活跃的神奇宝贝及其剩余队列完整描述。 所有转变都是马尔可夫式的：未来的结果仅取决于当前状态，而不是如何达到的。 由于每个操作都会确定性地更新此状态，因此逐步对其进行模拟可以保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, K = map(int, input().split())

    A = []
    for _ in range(n):
        h, a, b, c, d, e, w = map(int, input().split())
        A.append([h, a, b, c, d, e, w])

    B = []
    for _ in range(m):
        h, a, b, c, d, e, w = map(int, input().split())
        B.append([h, a, b, c, d, e, w])

    i = j = 0
    a_hp, a_en = A[0][0], 0
    b_hp, b_en = B[0][0], 0

    def best(att, defn, en):
        Aatk, Batk, Cdef, Ddef, Ecost, W = att[1], att[2], att[3], att[4], att[5], att[6]
        phys = max(0, Aatk - defn[3])
        mag = max(0, Batk - defn[4])
        ult = W if en >= Ecost else -1
        if phys >= mag and phys >= ult:
            return phys, 0
        if mag >= phys and mag >= ult:
            return mag, 1
        return ult, 2

    for round_id in range(K):
        if i >= n or j >= m:
            break

        dmg, typ = best(A[i], B[j], a_en)
        b_hp -= dmg
        if typ == 0 or typ == 1:
            a_en += 1
        else:
            a_en -= A[i][5]

        if b_hp <= 0:
            j += 1
            if j < m:
                b_hp, b_en = B[j][0], 0
            else:
                break

        if i >= n or j >= m:
            break

        dmg, typ = best(B[j], A[i], b_en)
        a_hp -= dmg
        if typ == 0 or typ == 1:
            b_en += 1
        else:
            b_en -= B[j][5]

        if a_hp <= 0:
            i += 1
            if i < n:
                a_hp, a_en = A[i][0], 0
            else:
                break

    if i >= n and j >= m:
        print("Draw")
    elif j >= m:
        print("Alice")
    else:
        print("Bob")

if __name__ == "__main__":
    solve()
```该实现为每个团队维护两个指针，并明确地保留活跃的 HP 和能量。 这`best`函数封装了决策规则，比较当前约束下所有三个可能的损坏值。 

一个微妙的细节是，最终的可用性取决于能量，否则将被视为无效并受到负伤害，因此永远不会被选择。 打破平局的方法是在比较中将物理和魔法排在终极之前。 

模拟循环在每一轮中交替 Alice 和 Bob，遵守 K 轮的截止时间。 

## 工作示例

 考虑一个小场景，每一方都有一只神奇宝贝。 

爱丽丝有一个单位，生命值为 10，物理值为 5，魔法值为 1，防御值为 0，能量消耗为 2，终极值为 10。鲍勃拥有对称属性。 

开始时两个能量都为零。 

| 转 | 攻击者| 选择的行动| 之前的能量 | 伤害| 惠普后|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 爱丽丝| 身体 | 0 | 5 | 鲍勃 5 |
 | 2 | 鲍勃 | 身体 | 0 | 5 | 爱丽丝5 |
 | 3 | 爱丽丝| 身体 | 1 | 5 | 鲍勃 0 |

 鲍勃晕倒后，爱丽丝立即获胜。 

该迹线表明能量积累正确地影响了后来的转弯，但不影响早期的决策。 

现在考虑这样一种情况，只有在重复攻击后才可以使用终极技能，从而强制切换最佳选择。 终极伤害高但成本高的单位最初会依赖物理或魔法攻击，直到达到能量阈值，此时如果它占主导地位，决策功能就会转向终极。

 ## 边缘情况

 一个关键的边缘情况是当前任神奇宝贝晕倒后切换到神奇宝贝。 它的能量必须重置为零。 如果能量被意外转移，它可能会立即错误地使用终极技能，产生夸大的伤害并破坏模拟。 

另一个边缘情况是，由于高防御，物理和魔法造成的伤害都为零。 在这种情况下，只有当极限值严格大于零并且能量允许时，仍然可以选择极限值。 否则，重复的零伤害转弯仍然会增加能量，最终实现大招的使用。 

最后的边缘情况是提前终止，当一支队伍在中轮用完神奇宝贝时。 模拟必须立即停止，而不是继续 Bob 的回合，否则它可能会访问无效索引并破坏结果。
