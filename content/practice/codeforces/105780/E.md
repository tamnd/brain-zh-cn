 ## 解决方案
 ## 问题理解

 花园是一个`n x n`网格。 有些细胞已经含有花。 在此过程中，细胞可以获得花朵，或者成对的细胞可以通过地下隧道连接起来。 当一组花通过正常网格邻接或通过地下隧道连接时，它们属于同一花蕾。 

对于每一个萌芽，我们都需要两个价值观。 第一个是`f`，内部花细胞的数量。 第二个是`c`，触及萌芽的地下隧道数量。 这个萌芽贡献的能量是`max(f - sqrt(c), 0)`。 每次操作后，任务是计算所有芽的这些值的总和。 

这些限制足够小，允许在每次操作后重建整个连接结构。 网格最多有`10000`细胞，并且最多有`1000`运营。 解决方案围绕`1000 * 10000`运算量仅为约千万个基本运算，因此不需要复杂的动态连接结构。 每次更新后从头开始扫描网格的解决方案是可以接受的，而单独模拟每个可能的萌芽或重复搜索所有单元对的方法将不必要地昂贵。 

主要的实施陷阱是围绕连接和计数隧道。 花细胞可以通过一系列地下隧道或相邻的花细胞连接到另一朵花，因此仅检查直接邻居会给出错误的结果。 例如：```
2 1
10
01
2 0 0 1 1
```添加隧道后，两朵花形成一朵花蕾。 答案是`2 - sqrt(1)`， 不是`2`，因为地下连接有助​​于`c`。 

另一个微妙的情况是重复插花。```
2 1
10
00
1 0 0
```牢房里已经有一朵花，所以花园不会改变。 不检查当前状态而增加花数的粗心实现会导致计数过多。 

最后的边缘情况是一个有很多隧道但很少有花朵的萌芽状态。```
2 1
10
00
2 0 0 0 1
```土细胞在地下与花细胞相连，但它不算作花。 萌芽已`f = 1`和`c = 1`，所以贡献是`0`。 将每个连接的细胞都算作一朵花会产生错误的结果。 

## 方法

 最直接的方法是在每次查询后维护花园并重新计算所有芽。 我们可以将每个网格单元建模为一个顶点。 相邻单元格通过正常的网格边缘连接，地下操作添加额外的边缘。 每次更新后，我们对所有单元格运行不相交集并集，连接相邻单元格和所有地下连接。 然后，对于每个结果组件，我们计算有多少个单元格包含花朵以及有多少个地下边缘属于它。 

这是可行的，因为单元和操作的数量都很小。 最坏情况的表现大致如下`1000`重建。 每次重建都会触及`10000`细胞，关于`20000`网格邻接性检查，最多`1000`地下边缘。 这在极限之内。 

更先进的动态连接解决方​​案将在隧道和花朵发生变化时维护组件，但这里没有必要。 关键的观察是整个状态空间足够小，重建更简单、更安全。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(d * n²) | O(d * n²) | O(n²) | 如果通过重复的图搜索来实现太慢 |
 | 重建 DSU | O(d * (n² + d)) | O(n²) | 已接受 |

 ## 算法演练

 1. 存储每个单元格当前是否有花，并存储已添加的每个地下连接。 这些操作只是添加，所以我们永远不需要删除信息。 
2. 在每次查询之后，创建一个新的不相交集并集结构，其中包含所有`n * n`细胞。 最初每个细胞都是分开的。 我们重建是因为网格的总尺寸很小。 
3. 连接每对水平或垂直相邻的单元格。 这代表正常的网格连接。 我们包含所有细胞（包括泥土细胞）的原因是，未来的花朵可以出现在任何细胞上，而地下或网格连接是细胞本身的属性。 
4. 连接每个地下连接的两个端点。 这会添加由 Karp 操作创建的额外路径。 
5. 遍历每个单元并计算每个 DSU 组件内的花单元的数量。 只有花细胞有助于`f`。 
6. 遍历每个地下连接并将其计入其组件内。 因为每条地下边都已合并到 DSU 中，所以两个端点具有相同的代表，因此每条边都属于一个芽接。 
7. 对于每个包含花的组件，添加`max(f - sqrt(c), 0)`到答案。 打印产生的能量。 

工作原理：DSU 不变量是，当两个单元通过所有当前可用路径连接时，它们具有完全相同的代表。 由于每个网格邻接点和地下隧道在计数之前都会合并，因此每个萌芽都由一个 DSU 组件表示。 计算组件内的花朵数量给出正确的结果`f`，并计算该组件中的地下边缘给出了正确的`c`。 最终的求和将能量公式独立地应用于每个芽，因此结果正是所需的花园能量。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, d = map(int, input().split())
    total = n * n

    flowers = []
    for _ in range(n):
        s = input().strip()
        flowers.extend(ch == '1' for ch in s)

    tunnels = []

    def idx(x, y):
        return x * n + y

    def compute():
        parent = list(range(total))
        size = [1] * total

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            a = find(a)
            b = find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]

        for i in range(n):
            for j in range(n):
                cur = idx(i, j)
                if i + 1 < n:
                    union(cur, idx(i + 1, j))
                if j + 1 < n:
                    union(cur, idx(i, j + 1))

        for a, b in tunnels:
            union(a, b)

        flower_count = [0] * total
        for i, has_flower in enumerate(flowers):
            if has_flower:
                flower_count[find(i)] += 1

        tunnel_count = [0] * total
        for a, b in tunnels:
            tunnel_count[find(a)] += 1

        ans = 0.0
        for i in range(total):
            if flower_count[i]:
                ans += max(flower_count[i] - math.sqrt(tunnel_count[i]), 0.0)

        return ans

    out = []
    for _ in range(d):
        q = list(map(int, input().split()))
        if q[0] == 1:
            flowers[idx(q[1], q[2])] = True
        else:
            tunnels.append((idx(q[1], q[2]), idx(q[3], q[4])))

        out.append(f"{compute():.10f}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```这`flowers`数组使用扁平索引存储每个网格单元的当前状态。 扁平化避免了重复存储坐标对，使 DSU 操作更加直接。 

这`compute`功能重建连接。 第一个联合循环添加正常的网格边缘，第二个联合循环添加所有地下隧道。 排序不会影响最终组件，因为 DSU 仅代表连接性。 

两个计数阵列是分开的，因为花朵和隧道代表不同的数量。`flower_count`计算细胞数，同时`tunnel_count`计算地下连接。 混合它们会产生不正确的平方根项值。 

最后的循环仅考虑至少具有一朵花的组件。 完全由泥土制成的组件不会形成芽，也不会做出任何贡献。

 ## 边缘情况

 重复插花不会产生新花。 在输入中```
2 1
10
00
1 0 0
```细胞`(0,0)`已被占用。 该算法将值设置为`True`再次重建相同的组件结构，产生能量`1`。 

连接先前分离的细胞的隧道必须合并它们的芽。 为了```
2 1
10
01
2 0 0 1 1
```DSU 连接两个花细胞。 组件中有一个地下边缘，因此`f = 2`和`c = 1`, 给予`2 - sqrt(1) = 1`。 

接触泥土的隧道不会增加花朵数量。 为了```
2 1
10
00
2 0 0 0 1
```该组件包含一朵花和一条地下隧道。 其值为`max(1 - sqrt(1), 0) = 0`，算法通过独立计数花朵和隧道获得。
