 ## 解决方案
 ## 问题理解

 这朵花生长在`d`维整数网格。 它从原点开始，每秒沿着一个坐标轴精确移动一个单位。 该方向必须始终沿着该轴远离原点。 任务是计算在确切的时间之后可能有多少种不同的增长决策序列`t`秒。 如果两个序列在​​任何时刻选择不同的轴或不同的方向，那么它们就是不同的。 

输入给出维数和增长步数。 输出是这些步骤的有效有序序列的数量，取模`998244353`。 

约束条件允许两者`d`和`t`一样大`200000`。 二次解需要大约`4 * 10^10`最坏情况下的操作，远远超出了极限。 最终的解决方案必须接近线性，因此我们需要避免使用嵌套循环跟踪单个秒或维度。 

棘手的部分是理解单个坐标会发生什么。 一旦第一次选择坐标，它就会变成正值或负值。 该坐标上的每一次增长都只有一个可能的方向，因为向零移动是被禁止的。 从未使用过的坐标不会提供任何方向选择。 

一些边缘案例暴露了常见的错误。 

对于一维和一秒：```
Input:
1 1

Output:
2
```唯一的坐标可以正增长也可以负增长。 假设每个轴只有一个方向的解决方案将错误地返回`1`。 

对于二维和一秒：```
Input:
2 1

Output:
4
```花可以选择任一尺寸和任一符号。 仅计算最终位置会给出相同的答案，但对于更大的示例，不同的增长订单可以达到相同的最终点。 该问题要求不同的历史，而不是不同的结束坐标。 

对于三个维度和三秒：```
Input:
3 3

Output:
126
```使用两次的坐标只有两个可能的方向历史，而不是四个。 一旦选择了第一个标志，所有未来在该坐标上的移动都会被强制。 

## 方法

 直接方法会尝试模拟所有可能的生长历史。 每一秒最初都有`2d`选择，尽管随着坐标固定，可用选择的数量略有减少，但可能的历史数量仍然呈指数增长。 为了`t`秒，这大约是`(2d)^t`，即使对于非常小的输入也无法使用。 

有用的观察来自于分离每个坐标上所做的选择。 假设精确选择了一个特定坐标`k`整个过程中的次数。 如果`k = 0`，有一种可能的行为：坐标从未被触及。 如果`k > 0`，恰好有两种可能的行为：所有选定的移动都向正方向移动，或者所有选定的移动都向负方向移动。 

剩下的问题是步骤是全局排序的。 如果坐标`i`被选中`c_i`次，这些步骤在所有步骤中的位置`t`时刻可以选择：$$\frac{t!}{c_1!c_2!\cdots c_d!}$$方式。 

这导致指数生成函数。 对于一个维度，贡献为：$$1 + 2\frac{x}{1!} + 2\frac{x^2}{2!} + 2\frac{x^3}{3!}+\cdots$$这是：$$1+2(e^x-1)=2e^x-1$$为了`d`维度，我们需要的系数是`x^t`在：$$(2e^x-1)^d$$二项式定理将其转化为可以直接计算的和：$$(2e^x-1)^d
=
\sum_{i=0}^{d}
\binom di 2^i(-1)^{d-i}e^{ix}$$系数为`x^t`在`e^{ix}`是`i^t/t!`。 原计数公式乘以`t!`，因此阶乘消失：$$\text{answer}
=
\sum_{i=0}^{d}
(-1)^{d-i}\binom di2^ii^t$$现在问题已简化为维度上的单个循环。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((2d)^t) | O((2d)^t) | O(t) | 太慢了|
 | 最佳| O(d) | O(d) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘和逆阶乘`d`。 该公式需要二项式系数，单独计算每个系数会太慢。 
2. 迭代每个可能的值`i`从`0`到`d`。 价值`i`表示展开时选择多少个维度来贡献指数项`(2e^x-1)^d`。 
3. 对于每个`i`，计算：$$(-1)^{d-i}\binom di2^ii^t$$并将其添加到答案中。 二项式系数选择哪些维度做出贡献`2e^x`，而符号和功率则来自剩余的`-1`项和指数系数。 

1. 对最终结果进行模归一化`998244353`并打印它。 

为什么它有效：

 生成函数独立地对每个维度进行建模。 系数为`x^t/t!`记录了分发方式`t`维度之间的有序矩，而因子`2`对于每个使用的尺寸记录两个可能的符号。 将一维生成函数提升为`d`th 次方结合了所有维度。 二项式展开不会改变计数对象，它只是提供了一种更快的方法来提取所需的系数。 由于每一个可能的历史都恰好对应于该展开式中的一项，并且每项都代表有效的历史，因此该公式对每个答案恰好计数一次。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

MOD = 998244353

def solve():
    d, t = map(int, input().split())

    fact = [1] * (d + 1)
    for i in range(1, d + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (d + 1)
    inv_fact[d] = pow(fact[d], MOD - 2, MOD)
    for i in range(d, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    ans = 0
    pow_two = 1

    for i in range(d + 1):
        comb = fact[d] * inv_fact[i] % MOD * inv_fact[d - i] % MOD
        term = comb * pow_two % MOD
        term = term * pow(i, t, MOD) % MOD

        if (d - i) & 1:
            ans -= term
        else:
            ans += term

        ans %= MOD
        pow_two = pow_two * 2 % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```阶乘数组允许在恒定时间内计算每个二项式系数。`inv_fact`是使用费马小定理构建的，因为模数是素数。 

循环直接遵循公式。`pow_two`商店`2^i`递增，避免重复求幂。 价值`pow(i, t, MOD)`使用模二进制求幂有效地处理大指数。 

案例`i = 0`自然处理。 由于约束条件有`t >= 1`,`0^t`是`0`，因此该术语没有任何贡献。 没有必要特殊情况。 

所有加法均按模减少`MOD`每次迭代后。 Python 整数不会溢出，但保持值减少可以避免不必要的增长，并使实现接近数学公式。

 ## 边缘情况

 对于：```
1 1
```唯一的坐标被选择一次。 花可以移动到`1`或者`-1`，所以答案是`2`。 式中，仅`i = 1`术语生存，给予`2`。 

为了：```
2 1
```有四种可能的第一步：沿着任一维度的正向或负向。 该算法计算：$$(-1)^2\binom20 0^1
+
(-1)^1\binom21 2(1^1)
+
(-1)^0\binom22 4(2^1)$$变成：$$-4+8=4$$为了：```
3 3
```一个坐标选择三次并不会产生八种可能性。 第一步选择其符号，接下来的两步是被迫的。 生成函数使用系数`2x^3/3!`，仅正确地为该坐标提供两个符号选择。 

对于大输入，例如：```
12345 67890
```该算法从不构造路径或状态。 它仅在维度上执行线性传递，这就是为什么尽管有大量可能的增长历史，它仍然可行。
