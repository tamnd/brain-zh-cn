 ## 解决方案

 ## 问题理解

 我们得到了一个整数序列，这些整数序列来自在隐藏的矩形网格上行走。 网格按行优先顺序填充：第一行包含连续的数字，然后下一行紧随其后继续，依此类推。 如果网格有`x`行和`y`列，然后是位置的单元格`(i, j)`包含值`(i-1)·y + j`。 每个数字都来自`1`到`x·y`恰好出现一次。 

我们看到一条路径作为一系列值`a1, a2, ..., an`。 每个值对应于该未知网格中的唯一单元格，并且序列中的连续值保证来自网格中边缘相邻的单元格。 任务是判断是否存在任意对`(x, y)`这样这条路径在该解释下是有效的，如果是，则构建一个有效的网格大小。 

关键的困难在于从数字到坐标的映射取决于`y`，这是未知的。 改变`y`改变值被分割成行的方式，因此序列中的邻接性成为对隐藏参数的约束，而不是固定的图遍历问题。 

这些约束促使我们寻求线性或近线性的解决方案。 对于多达 200000 个元素，任何尝试所有可能的网格宽度或在嵌套循环内重复重新计算坐标的方法都太慢。 我们需要从每个转换中提取约束并逐步组合它们。 

当解决方案假设两个数字之间只能进行一种移动时，就会出现微妙的失败情况。 例如，如果我们看到`8 → 9`，天真的解释可能会假设水平相邻总是有意的，但是如果`y = 1`，同样的过渡是垂直的。 当像这样的一对时，会发生另一种失败情况`1 → 2`假设总是水平的，但如果`y ≥ 2`，根据布局，它可能仍然是垂直的。 这种模糊性迫使我们在每一步中都必须一致地考虑这两种解释。 

## 方法

 一个蛮力的想法是尝试所有可能的值`y`从`1`到`max(a[i])`，重建每个选择的坐标，并验证序列中的每个步骤是否对应于有效的移动。 这在概念上是有效的，因为每个`y`唯一定义了网格结构，但速度太慢。 每次检查都是线性的`n`，以及范围`y`最多可以达到 10^9，这使得这完全不可行。 

关键的观察是我们永远不需要显式地模拟所有网格。 对于任何固定的`y`, 每个数字`a`映射到坐标`( (a-1)//y, (a-1)%y )`。 两个连续值在曼哈顿距离中必须相邻且恰好为一。 这个条件转化为算术约束`y`。 

一对`(u, v)`，邻接只能通过两种方式实现。 它们要么垂直相邻，这意味着它们位于同一列并且相差完全相同`y`，或者它们水平相邻，这意味着它们位于同一行并且相差完全相同`1`，不跨越行边界。 因此，每一对都施加了一组允许的值`y`，并且正确答案必须位于所有这些允许集合的交集内。 

我们不是直接跟踪复杂的几何条件，而是将每个转换减少为对候选者的约束检查`y`从序列差异中得出的值。 最重要的候选人来自垂直转型，其中`|u - v|`直接等于`y`。 这为我们提供了一组小的、可管理的潜在宽度。 然后可以在线性时间内验证每个候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力战胜一切| O(maxA·n) | O(1) | O(1) | 太慢了 |
 | 不受约束的候选测试| O(n·k) 其中 k ≤ n | O(n) | 已接受 |

 ## 算法演练

 ### 算法演练

 1. 从连续差异中提取所有候选网格宽度。 对于每个相邻对`(a[i], a[i+1])`, 计算`|a[i] - a[i+1]|`并尽可能收集`y`。 这是有效的，因为网格中的任何垂直移动都必须与尺寸的跳跃完全对应`y`。 
2. 对于每位候选人`y`，使用行主解码重建每个值的坐标`(a-1)//y`和`(a-1)%y`。 此步骤将序列转换为候选网格中的显式行走。 
3. 检查序列中的每个连续对是否对应于有效的移动。 如果坐标之间的曼哈顿距离恰好为 1，则移动有效。 
4. 如有候选人`y`通过整个序列的验证，计算`x`作为遇到的最大行索引加一，因为行在计算中是零索引的。 
5、输出`YES`以及第一个有效的`(x, y)`找到一对。 如果没有候选人工作，输出`NO`。 

### 为什么它有效

 每个有效的解决方案都必须分配固定的宽度`y`这在所有转换中都是一致的。 任何垂直移动力`y`等于两个单元格之间的值差，因此如果发生垂直移动，至少有一个这样的差值必须与真实宽度匹配。 即使路径仅使用水平移动，测试候选宽度仍然涵盖所有结构上一致的解释，因为水平邻接一旦完全确定`y`是固定的。 重建步骤确保没有不一致的宽度能够通过验证，因为即使是单个无效邻接也会破坏曼哈顿距离条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def check(a, y):
    coords = []
    for v in a:
        v -= 1
        coords.append((v // y, v % y))
    for i in range(len(a) - 1):
        r1, c1 = coords[i]
        r2, c2 = coords[i + 1]
        if abs(r1 - r2) + abs(c1 - c2) != 1:
            return False
    return True

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n == 1:
        print("YES")
        print(1, 1)
        return

    candidates = set()

    for i in range(n - 1):
        d = abs(a[i] - a[i + 1])
        if d > 0:
            candidates.add(d)

    candidates.add(1)

    for y in candidates:
        if y <= 0:
            continue
        if check(a, y):
            mx = 0
            for v in a:
                mx = max(mx, (v - 1) // y)
            print("YES")
            print(mx + 1, y)
            return

    print("NO")

if __name__ == "__main__":
    solve()
```该实现首先从绝对差中收集所有可能的网格宽度。 然后通过将每个值解码为其网格坐标并验证邻接性来测试每个候选宽度。 检查函数是核心：它确保每一步都对应于该宽度引起的网格图中的单个边缘移动。 

行计算`(v-1)//y`和列计算`(v-1)%y`是行优先填充规则的直接翻译。 看到的最大行索引决定了所需的最小高度。 

一个常见的错误是假设每个差异都对应一个有效宽度。 这并不完全正确，但最终的验证步骤会过滤掉无效的候选者，因此不会保留不正确的宽度来输出。

为了`y = 2`，坐标为：

    return "NO\n"

 ## 边缘情况

 单元素路径对于任何网格都有效，并且算法正确返回最小`1 × 1`配置，因为不存在邻接约束。 

像这样的路径`1 → 2`适用于多个网格宽度，并且候选生成正确地包含有效宽度，例如`y = 2`，它会生成一个单行网格，其中移动是水平的。 

之字形序列，例如`1 → 3 → 2 → 4`强制算法选择同时对齐水平和垂直过渡的宽度。 测试`y = 2`满足所有约束，而无效候选者在邻接检查期间失败。 

小网格中的完全密集遍历可确保正确处理行换行，因为跨行边界的转换会立即使验证期间不正确的宽度失效。
