 ## 解决方案
 ## 问题理解

 我们在平面上有 2n 个格点，每个格点代表一颗星星。 在原始天文结构的某个地方，存在一个特殊的点，即月球，它具有整数坐标，这样恒星就可以被分成 n 对，具有非常严格的几何特性：对于每一对，穿过两颗恒星的线也穿过月球。 每对线都产生了不同的线，但所有这些线都相交于一个公共点，即月球。 

在现代输入中，我们只能看到 2n 个星坐标。 配对丢失，月亮也消失了。 任务是重建任何可能是月球的整数坐标，或者证明不存在这样的点。 

从几何角度来看，隐藏结构很强大：所有 2n 个点必须配对，以便每对都定义一条通过单个固定点的线。 这相当于说每颗星星都位于通过公共中心的 n 条线上的一条线上，并且每条线恰好包含两颗星星。 

坐标范围很大，绝对值高达 10^6，并且 n 可以大到 2600，因此任何尝试显式测试所有配对或所有候选中心的方法都是不可能的。 结构必须单独从点集中提取。 

一个关键的困难是配对是未知的，因此我们无法直接重建线条。 另一个微妙的问题是，许多几何候选构造可以为交点生成有理坐标，但答案需要是完整的并且与所有输入点不同。 

一个天真的想法是选择两个点并假设它们的中点或交叉点结构决定了月球，但这很快就会失败，因为正确的配对是未知的，并且不同的配对会产生不同的候选交叉点。 

关键的边缘情况是对称性。 如果配置高度对称，则多个候选中心可能在几何上看起来有效，但只有一个与所有配对一致。 另一种失败模式是假设围绕猜测的中心按角度任意配对或排序无需首先识别该中心即可工作。 

## 方法

 强力解释将尝试猜测月球，然后验证这些点是否可以配对成共线三元组（每对都有月球）。 对于固定的候选中心M，我们可以将每个点变换为M的方向向量，并检查所有向量是否可以与相同的方向（相反的射线）配对。 这需要对方向向量进行排序或散列并验证多重性。 

问题是候选中心未知。 可能的整数坐标空间很大，每个方向都有 10^6 的边界，因此不可能枚举候选坐标。 即使将候选限制为输入点或对的中点，仍然留下 O(n^2) 的可能性，这太大了。 

关键的观察是正确的中心受到差异对称性的严重限制。 假设真正的中心是 C。对于任何正确的对 (A, B)，我们有 C 位于线段 AB 扩展上，这意味着向量满足 C = A + B - C 重新排列意味着 A + B = 2C。 因此每个有效对的总和都是相同的向量 2C。 

这将问题转换为：将点划分为对，使得对和恒定。 该常数是 2C。 所以如果我们猜测一对（A，B），那么2C = A + B是固定的，C也是确定的。 剩下的任务是验证所有其他点是否可以配对以使总和等于 A + B。 

这极大地减少了问题：我们不是直接搜索 C，而是尝试通过将一个选定点与每个其他点配对来形成候选和。 对于每个这样的候选者 C，我们检查归纳规则下是否存在完整的有效配对。

使用多重集补集的散列来验证步​​骤是有效的：对于每个点 P，其所需的伙伴是 Q = (2C - P)。 如果所有点都可以唯一匹配，并且没有点错误地匹配自身，那么我们就有了一个有效的解决方案。 

复杂性来自于尝试 O(n) 个候选中心（固定一个点并尝试将其与另一个代表配对），并且每次验证的成本为 O(n log n) 或 O(n)（使用哈希）。 对于 n 高达 2600 的情况，这是可以接受的。

 | --- | --- | --- | --- |
 | 暴力配对/中心枚举 | O(exp(n)) | O(exp(n)) | O(1) | O(1) | 不可能|
 | 尝试从一个固定锚点候选 | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 我们使用以下事实：对于某些有效对 (A, B)，正确的中心必须满足 2C = A + B。 我们尝试所有 A 固定、B 变化的可能性。 

1. 将A点固定为第一对中的潜在参与者。 

这确保我们将候选结构锚定到真实结构而不是任意猜测。 
2. 对于每个其他点 B，计算候选中心 C = (A + B) / 2，或者等效地使用 S = A + B 作为所需的常数和。 

我们通过直接使用整数和来避免浮点问题。 
3. 对于每个候选和 S，尝试验证所有点是否可以配对以使 P + Q = S 成立。 

这编码了所有线都经过单个中心的几何要求。 
4. 构建所有点的频率图。 以任意顺序迭代点，对于每个仍未使用的点 P，计算 Q = S - P。 
5.如果Q在多重集中不可用或者已经耗尽，则立即丢弃该候选S。 
6. 如果我们成功匹配所有点，则输出对应的中心C = S / 2。 

我们可以安全地贪婪地将 P 与 S - P 匹配的原因是，每个有效的解决方案都会在总和约束下强制进行完美的对合配对，因此只要保持一致性，顺序并不重要。 

### 为什么它有效

 所有有效配置都意味着对之间的向量和恒定：对于每对 (A, B)，A + B = 2C。 相反，如果我们找到一个值 S，使得多组点可以划分为总和为 S 的对，则定义 C = S / 2 可以保证所有线都经过 C，因为每对关于 C 对称。从单个锚点 A 导出的对 S 的搜索就足够了，因为至少有一个正确的对必须包含 A，并且该对生成真实的和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(2 * n)]
    
    from collections import Counter

    def try_sum(Sx, Sy):
        cnt = Counter(pts)
        for x, y in pts:
            if cnt[(x, y)] == 0:
                continue
            cnt[(x, y)] -= 1
            tx, ty = Sx - x, Sy - y
            if cnt[(tx, ty)] == 0:
                cnt[(x, y)] += 1
                return None
            cnt[(tx, ty)] -= 1
        
        return (Sx // 2, Sy // 2)

    # try all candidates using point 0 paired with others
    for i in range(1, 2 * n):
        sx = pts[0][0] + pts[i][0]
        sy = pts[0][1] + pts[i][1]
        res = try_sum(sx, sy)
        if res is not None:
            cx, cy = res
            # ensure center is not a star
            if (cx, cy) not in pts:
                print("Yes")
                print(cx, cy)
                return

    print("No")

if __name__ == "__main__":
    solve()
```该代码固定一个参考点并迭代所有可能的伙伴以生成候选和。 对于每个候选点，它构建一个频率计数器，并贪婪地将每个未使用的点与其总和下的补码进行匹配。 如果在任何时候缺少补集，则候选者无效。 

最终检查确保计算的中心本身不是问题陈述所要求的恒星之一。 

一个微妙的实现细节是，我们总是在搜索补集之前递减计数，这可以防止意外地将一个点与其自身配对，除非多重性允许。 这确保了退化对称情况下的正确性。

 ## 边缘情况

 一种故障模式是由于部分对称而存在多个候选中心，但只有一个允许完全配对。 该算法会尝试涉及固定锚点的所有配对，因此任何有效的配置都必须在这些尝试中包含正确的候选总和。 如果尝试对称但无效的中心，则贪婪配对在第一个不匹配的补集处失败，从而防止错误接受。 

另一种情况是当一个点在候选和下是它自己的补集时，意味着 S = 2P。 该实现正确地处理了这个问题，因为在检查其伙伴之前点计数会递减，确保自配对仅在存在至少两个相同的点时成功，这是不可能的，因为所有点都是不同的。 

最后，真实中心位于凸包之外的情况可以自然处理，因为计算不依赖于关于位置的几何假设，仅依赖于代数配对一致性。
