 ## 解决方案
 ## 问题理解

 该问题描述了一排石头，每种颜色为红色、绿色或蓝色，由字符串表示`s`字符“R”、“G”和“B”。 Squirrel Liss 从第一块石头开始，执行由第二个字符串给出的一系列基于颜色的指令`t`。 每条指令都对应一种颜色：如果莉丝当前所在的石头与指令的颜色相匹配，她就会向前移动一颗石头。 否则，她就留在原地。 我们被要求在执行所有指令后计算 Liss 的最终位置，位置编号从 1 开始。 

这些字符串很短，每个字符串最多 50 个字符，因此可以直接模拟指令，而无需担心时间限制。 每条指令仅需要一次比较和增量（如果适用）。 50 条指令和 50 颗宝石，最多会执行 50 次操作，在 2 秒的时间限制下可以忽略不计。 

当多个指令与当前宝石颜色不匹配时，就会出现微妙的边缘情况。 例如，如果`s = "RGB"`和`t = "GGG"`，Liss 永远不会离开石头 1。另一个潜在的陷阱是正确处理基于 1 的索引； 天真的从零开始的数组处理可能会导致差一错误。 

## 方法

 暴力方法直接模拟利斯的动作。 我们从一个变量开始`pos = 0`对于第一块石头（内部计算从零开始）。 对于每条指令，我们检查是否`s[pos]`与指令相符。 如果是这样，我们就增加`pos`。 这正确地模拟了规则并且易于实现。 比较的次数等于长度`t`，所以在最坏的情况下，我们执行50次操作，这是可以接受的。 

不需要更复杂的算法，因为输入大小非常小。 关键的见解是这是一个纯粹的模拟问题； 没有预计算、数据结构或贪婪策略可以提高性能。 最佳解决方案与暴力模拟相同，但必须仔细处理从 1 开始的输出。

 ## 算法演练

 1. 初始化变量`pos = 0`代表利斯当前的宝石指数（从零开始）。 此选择简化了 Python 中的字符串索引。 
2. 迭代每个字符`instruction`在字符串中`t`。 每个字符代表一个颜色指令。 
3. 对于每个`instruction`，检查是否`s[pos]`匹配它。 这模拟了只有当指令与宝石颜色匹配时 Liss 才会移动的规则。 
4. 如果有匹配，则递增`pos`一个。 否则，不执行任何操作并继续执行下一条指令。 
5.处理完所有指令后，输出`pos + 1`从从零开始的位置转换为从一开始的位置。 

为什么它有效：该算法保持了以下不变式：`pos`始终代表利斯当前的宝石指数。 每条指令均按顺序应用，并且仅在允许时才发生移动。 因为我们按顺序迭代指令，所以不会错误地跳过或重复任何动作。 最终输出正确地从内部从零开始的索引转换为问题从一开始的编号。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
t = input().strip()

pos = 0  # zero-based index

for instruction in t:
    if s[pos] == instruction:
        pos += 1

print(pos + 1)
```该解决方案首先读取并删除两个字符串以删除任何尾随换行符。 这`pos`变量从 0 开始跟踪当前位置。for 循环迭代每条指令，执行单个相等检查和可选增量。 最后，结果被打印为从 1 开始的索引。 注意仅在匹配的指令上递增，这避免了相差一的错误。

该跟踪显示与当前宝石颜色不匹配的重复指令被正确忽略。
