 ## 解决方案
 ## 问题理解

 我们有一个$n \times m$顶点网格。 如果两个顶点共享一条边，或者它们是同一单位正方形的对角，则它们是相连的。 换句话说，每个单元格贡献了正方形的所有四个边加上两条对角线。 

一些顶点已经用颜色 1 到 4 着色。其他顶点未着色，用 0 表示。我们必须为每个未着色的顶点分配颜色，以便每条边连接不同颜色的顶点。 如果不存在这样的完成，我们打印`0`。 

每个网格的维度可以达到1000，因此可能有多达一百万个顶点。 任何检查每对顶点的解决方案都是不可能的。 即使是与图边数成比例的算法也必须小心，因为图包含数百万条边。 我们需要一个非常简单的规则，可以在网格上以线性时间进行检查和应用。 

关键的挑战是理解该图的结构。 乍一看，它看起来像是一个大型图形着色问题，这通常很困难。 事实证明，该图形的几何形状强制形成独特的 4 色图案。 

当两个预着色的相邻顶点已经违反着色规则时，就会出现微妙的边缘情况。 

例子：```
2 2
11
00
```第一行中的两个顶点由水平边连接并且具有相同的颜色。 没有完成可以解决这个问题。 正确的输出是：```
0
```另一种容易错过的情况是预着色顶点与唯一可能的颜色模式不一致。 

例子：```
2 2
10
00
```这是可以解决的，因为我们可以重命名四种图案颜色，以便左上角位置接收颜色 1。 

但是：```
2 2
12
00
```可能可解也可能不可解，具体取决于颜色 1 和 2 的位置是否与四种图案颜色的单个全局排列兼容。 局部贪婪分配会错误地接受一些不一致的输入。 

当几个彩色顶点单独看起来有效但共同强制产生矛盾的映射时，就会出现第三种边缘情况。 

例子：```
2 3
100
003
```每个彩色顶点都可以与某种图案颜色相匹配。 只有同时考虑这两个约束时，矛盾才会出现。 该算法必须验证图案类和实际颜色之间的单一全局对应关系。 

## 方法

 暴力的观点是将其视为具有四种颜色的图形着色问题。 每个未着色的顶点可以接收四个值之一，并且我们必须满足所有边缘约束。 

即使对于一个$10 \times 10$网格这变得无望了。 一百个顶点已经给出$4^{100}$可能的任务。 标准回溯或约束传播无法处理包含多达一百万个顶点的网格。 

这一突破来自于对一个单位正方形的研究。 它的四个角都是成对连接的。 正方形包含四个边和两条对角线，因此这四个顶点形成一个完整的图$K_4$。 

一个$K_4$需要四种不同的颜色。 

考虑顶点位置的奇偶性：$$(i \bmod 2,\; j \bmod 2)$$恰好有四种奇偶校验类别：$$(0,0),\ (0,1),\ (1,0),\ (1,1)$$属于不同奇偶校验类别的任何两个顶点在某些情况下一起出现时都是相邻的$2 \times 2$正方形。 由于每个正方形都必须使用所有四种颜色，因此顶点的颜色仅取决于其奇偶校验类别。 

这意味着每个有效的着色都具有以下形式：

 | 平价类| 指定颜色 |
 | --- | --- |
 | (0,0) | (0,0) |$p_0$|
 | (0,1)|$p_1$|
 | (1,0)|$p_2$|
 | (1,1) |$p_3$|

 在哪里$(p_0,p_1,p_2,p_3)$是颜色的排列$1,2,3,4$。 

整个问题变成：找到与每个预着色顶点一致的四种颜色的排列。 

只有$4! = 24$排列。 对于每个排列，我们可以检查所有预着色的顶点。 如果一个排列满足每个约束，我们就可以立即生成整个网格。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解图着色|$O(4^{nm})$| 指数| 太慢了 |
 | 枚举 24 个奇偶校验颜色映射 |$O(24 \cdot nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 1. 对四个奇偶校验类别进行编号：$$(0,0),(0,1),(1,0),(1,1)$$使用该值`(row % 2) * 2 + (col % 2)`。 
2. 枚举所有24种颜色排列`1,2,3,4`。 
3. 对于选定的排列，将其解释为分配给每个奇偶校验类别的颜色。 
4. 扫描每个已包含颜色的单元格。 

如果该奇偶校验类的排列所需的颜色与给定颜色不同，则该排列不起作用。 
5. 如果所有预先着色的单元都符合该排列，则保留该排列并停止搜索。 
6. 如果没有排列存在，则打印`0`。 
7. 否则构建答案网格。 

对于每个位置，计算其奇偶校验类并输出由所选排列分配的颜色。 

### 为什么它有效

 每个$2 \times 2$平方引起$K_4$，所以它的四个角必须有四种不同的颜色。 四个奇偶校验类在每个中恰好出现一次$2 \times 2$正方形。 因此，每个奇偶校验类必须始终在整个网格中接收固定的颜色。 

因此，任何有效的着色都是分配给四个奇偶校验类别的颜色的排列。 该算法检查所有此类排列。 如果满足每个预先着色的顶点，则所得着色在任何地方都有效，因为每个正方形包含四个奇偶校验类各一次，因此所有四种颜色各一次。 如果没有排列满足给定的单元格，则不存在有效的着色。 

## Python 解决方案```python
import sys
from itertools import permutations

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    answer_perm = None

    for perm in permutations("1234"):
        ok = True

        for i in range(n):
            row = g[i]
            for j in range(m):
                if row[j] == '0':
                    continue

                cls = (i & 1) * 2 + (j & 1)
                if perm[cls] != row[j]:
                    ok = False
                    break

            if not ok:
                break

        if ok:
            answer_perm = perm
            break

    if answer_perm is None:
        print(0)
        return

    out = []
    for i in range(n):
        cur = []
        for j in range(m):
            cls = (i & 1) * 2 + (j & 1)
            cur.append(answer_perm[cls])
        out.append("".join(cur))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一部分读取网格并存储给定的颜色。 

核心观察编码为`cls = (i & 1) * 2 + (j & 1)`，它标识四个奇偶校验类别之一。 每个有效的着色必须为每个类别分配一种固定颜色。 

The loop over`permutations("1234")`尝试所有 24 种可能的分配。 对于每个预先着色的单元格，我们检查排列是否准确地预测给定的颜色。 单个不匹配会立即拒绝该排列。 

一旦找到有效的排列，构建答案就很简单了。 每个单元格都会收到与其奇偶校验类别相对应的颜色。 

一个常见的实现错误是混淆了检查阶段和构造阶段之间的奇偶校验类编号。 两者必须使用完全相同的公式。

 ## 边缘情况

 考虑：```
2 2
11
00
```顶行顶点是相邻的。 任何有效的着色都需要相邻顶点上有不同的颜色。 在排列检查期间，单元格位于`(0,0)`部队等级`(0,0)`着色`1`， 尽管`(0,1)`部队等级`(0,1)`着色`1`。 由于每个排列都使用四种不同的颜色，因此没有排列可以满足这两个约束。 算法打印`0`。 

考虑：```
2 2
10
00
```细胞`(0,0)`属于班级`(0,0)`并且需要颜色`1`。 许多排列满足这个要求。 该算法找到一个并用其他三种颜色填充剩余的奇偶校验类。 存在并产生了有效答案。 

考虑：```
2 3
100
003
```第一个彩色单元格将一个奇偶校验类别固定为颜色`1`。 第二个彩色单元格将另一个奇偶校验类别固定为颜色`3`。 有些排列同时满足两者，而另一些排列则仅满足其中一个。 通过根据相同的排列检查所有固定单元，该算法强制执行单个全局映射。 如果存在兼容映射，则找到它； 否则每个排列都会被拒绝，答案是`0`。 

这些案例说明了中心不变量：每个奇偶校验类必须具有一种全局一致的颜色，并且每个有效的解决方案恰好是这些类的 24 种可能的颜色分配之一。
