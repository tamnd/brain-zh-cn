 ## 解决方案
 ## 问题理解

 我们有一个矩形网格`n`行和`m`列。 水平线和垂直线的每个交叉点（每个“节点”）都被着色为黑色或白色。 此外，网格中的每个单位正方形都绘制了对角线。 我们被要求计算由三个白色节点形成的所有三角形作为顶点，使得三角形的每条边都沿着网格的水平线、垂直线或对角线，并且没有边经过黑色节点。 面积为零的三角形（简并三角形）被排除在外。 

输入提供`n`和`m`其次是`n`长度的字符串`m`组成`0`沙`1`s，其中`0`表示一个白色节点并且`1`表示黑色节点。 输出是有效三角形的数量。 

约束允许网格最大为 400×400，这意味着最多有 160,000 个节点。 检查每个白色节点三元组的简单方法将尝试大约 160,000 次选择 3 = 10^15 操作，这显然是不可行的。 任何解决方案都必须避免迭代所有三元组。 相反，我们需要利用网格的结构来有效地识别有效的三角形。 

不明显的边缘情况包括具有整行或整列黑色节点的网格。 例如，中间有黑行的 3×3 网格将防止沿对角线出现许多三角形。 另一个棘手的情况是使用全白网格：计数快速增长，索引或处理对角线中的任何差一错误都会产生错误的结果。 2×2 全白网格恰好有 4 个由单个正方形的对角线形成的三角形，但忽略对角线连通性的简单方法将报告零。 

## 方法

 暴力方法将枚举所有白色节点的三元组，并检查它们是否沿着允许的线形成三角形以及每条边是否没有黑色节点。 每次检查都需要沿着潜在的三角形边行走，给出 O((n*m)^3) 数量级的操作计数。 这对于 n、m 不超过 400 来说是不可行的。 

允许更快解决方案的关键观察是问题中的所有三角形都是“网格对齐”：它们的边要么是水平的，要么是垂直的，要么遵循两个对角线方向。 因此，任何三角形都必须包含在由同一行或同一列上的两个节点形成的矩形中，或者包含在沿对角线的直角三角形中。 这大大减少了候选三角形的数量。 

我们可以分别在四个方向上处理网格：水平、垂直和两个对角线方向。 对于每个节点，我们预先计算沿每个方向直到该节点存在多少个连续的白色节点。 然后，对于每个单位正方形或对角线段，我们可以通过组合预先计算的计数来计算将其用作边的三角形的数量。 这将复杂性从 O((n_m)^3) 降低到 O(n_m)，因为每个节点根据其预先计算的方向长度贡献恒定数量的三角形。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n*m)^3) | O((n*m)^3) | O(n*m) | 太慢了|
 | 最佳 | O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 解析网格并将其表示为 2D 布尔数组`white[i][j]`在哪里`True`表示一个白色节点。 
2. 预先计算从左到右四个方向上连续的白色节点的数量（`horiz[i][j]`），从上到下（`vert[i][j]`），从左上角到右下角的对角线（`diag1[i][j]`），以及从右上角到左下角的对角线（`diag2[i][j]`）。 对于每个单元格，如果节点为白色，则其在某个方向上的计数为 1 加该方向上的前一个节点； 否则，它为零。 这样可以快速获取可形成三角形边的最大线段长度。 
3. 迭代网格中的每个单位方块。 每个正方形可以使用其对角线和边构成多个三角形。 使用预先计算的方向长度来计算沿水平垂直边和沿对角线的直角三角形。 具体来说，对于沿水平边和垂直边的直角三角形，以给定节点为直角的三角形的数量等于`(horiz[i][j]-1) * (vert[i][j]-1)`。 
4. 对于对角三角形，考虑由对角线形成的正方形。 使用对角线作为斜边的三角形必须在对角线上的白色节点处有两个顶点。 使用`diag1`和`diag2`数组，计算具有该对角线方向的有效三角形的数量。 
5. 对所有节点的所有四个方向的贡献求和。 这给出了有效三角形的总数。 

原理：与网格对齐的每个三角形要么沿轴成直角，要么沿对角线成直角。 通过预先计算线段长度，我们可以有效地计算所有三角形，而无需枚举顶点三元组。 每个三角形仅计数一次，因为迭代将每个直角节点或对角斜边节点视为计数的“锚点”。 不能遗漏任何三角形，并且不会计算无效三角形，因为包含黑色节点的任何边在预计算数组中的长度为零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [list(map(int, list(input().strip()))) for _ in range(n)]
white = [[cell == 0 for cell in row] for row in grid]

horiz = [[0]*m for _ in range(n)]
vert = [[0]*m for _ in range(n)]
diag1 = [[0]*m for _ in range(n)]
diag2 = [[0]*m for _ in range(n)]

for i in range(n):
    for j in range(m):
        if white[i][j]:
            horiz[i][j] = 1 + (horiz[i][j-1] if j>0 else 0)
            vert[i][j] = 1 + (vert[i-1][j] if i>0 else 0)
            diag1[i][j] = 1 + (diag1[i-1][j-1] if i>0 and j>0 else 0)
            diag2[i][j] = 1 + (diag2[i-1][j+1] if i>0 and j<m-1 else 0)

total = 0
for i in range(n):
    for j in range(m):
        if white[i][j]:
            total += (horiz[i][j]-1)*(vert[i][j]-1)
            total += (diag1[i][j]-1)*(diag2[i][j]-1)

print(total)
```我们首先读取网格并将其预处理为白色节点的布尔数组。 接下来，我们计算连续白色节点的四个方向计数。 计算三角形时，方向计数减一，因为线段长度为 1 不能形成三角形边。 组合`(horiz[i][j]-1)*(vert[i][j]-1)`计算所有与当前节点成直角的直角三角形。 相似地，`(diag1[i][j]-1)*(diag2[i][j]-1)`计算沿对角线的三角形。
