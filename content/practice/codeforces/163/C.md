 ## 解决方案
 ## 问题理解

 我们被要求计算安东从移动的传送带上拾取巧克力的概率。 皮带有一个直可见的长度部分`l`并在地板下循环，使皮带总长度`2*l`。 皮带以恒定速度移动`v1`安东飞快地跑在它上面`v2`，所以他相对于地板的绝对速度是`v1 + v2`。 巧克力位于传送带上的某些位置`0`到`2*l`。 当安东开始跑步时，皮带可以进行任何旋转，这意味着每块巧克力相对于他的位置都是均匀随机的。 

输出要求，对于每个`i`从`0`到`n`，安东恰好收集到的概率`i`巧克力。 传送带顶部的每块巧克力都有可能触及，具体取决于安东开始跑步时其位置。 传送带下半部分的巧克力是无法到达的，除非它们在安东的运行范围内旋转到顶部，这仅取决于上半部分的长度和安东相对于传送带的速度。 

鉴于限制条件，`n`最多可达 100,000，并且`l`,`v1`， 和`v2`可以达到10^9。 这排除了任何模拟安东运动或以精细增量迭代所有可能的皮带旋转的方法。 我们需要一个线性或线性算数的解`n`。 

不明显的边缘情况包括巧克力位置`0`或者恰好在`l`。 例如，如果巧克力位于`0`，如果安东立即开始，他总是会接住它。 如果一块巧克力在`l`，如果安东启动得太晚，就会无法到达。 忽略巧克力是位于上半部分还是下半部分的简单解决方案将产生错误的概率。 

## 方法

 蛮力方法会考虑传送带的每个可能的起始位置，模拟安东跑步，并计算他拾起的巧克力数量。 这是正确的，但效率低下。 为了`n = 10^5`和连续的皮带位置，操作计数将难以管理，大约`O(n * l)`如果离散化，则为步骤。 

关键的见解是，安东的相对速度决定了覆盖顶部的固定时间，并且由于传送带的初始旋转是均匀随机的，因此拾取每块巧克力的概率仅取决于它是否位于长度段内`v2*l / (v1 + v2)`在上半部分。 通过对巧克力进行分类并应用长度滑动窗口`v2*l / (v1 + v2)`，我们可以有效地计算概率。 这将问题简化为沿着排序数组在移动窗口中计算巧克力的数量，即`O(n)`排序后。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n*l) | O(n) | 太慢了 |
 | 最优（两个指针）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取输入值：巧克力的数量`n`, 顶部长度`l`, 皮带速度`v1`, 安东的速度`v2`，以及职位`a`巧克力。 
2. 将所有巧克力映射到上半部分：如果巧克力位于下半部分（`a_i >= l`), 减少其位置模`l`来表示其在旋转期间出现在顶部的外观。 这样可以对所有巧克力进行统一处理。 
3. 对映射的巧克力位置进行排序以允许滑动窗口计算。 
4.计算有效可达距离`d = l * v2 / (v1 + v2)`。 这是安东位于输送机顶部时相对于皮带的距离。 
5、初始化一个两指针窗口：左指针指向第一块巧克力，右指针随着左右巧克力之间的距离小于而展开`d`。 
6. 对于每个左指针，计算窗口中巧克力的数量，并将相应的概率桶增加分数`window_length / l`。 
7. 向右移动左指针，并相应调整右指针。 这可以有效地对所有窗口进行计数，而无需冗余计算。 
8. 通过顶部总长度对概率进行归一化`l`确保它们的总和为 1。 

工作原理：滑动窗口确保可到达长度的每个连续段都被精确计数一次，并且排序保证窗口按顺序覆盖所有巧克力。 通过将下半部巧克力映射到上半部位置，我们可以正确模拟传送带的所有旋转。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, l, v1, v2 = map(int, input().split())
a = list(map(int, input().split()))

top_chocs = []
for x in a:
    if x < l:
        top_chocs.append(x)
    else:
        top_chocs.append(x - l)

top_chocs.sort()
probabilities = [0.0] * (n + 1)
d = l * v2 / (v1 + v2)

j = 0
for i in range(n):
    while j < n and top_chocs[j] - top_chocs[i] < d:
        j += 1
    count = j - i
    probabilities[count] += (top_chocs[i+1] - top_chocs[i]) / l if i+1 < n else (l - top_chocs[i]) / l

probabilities[0] = 1.0 - sum(probabilities[1:])
for p in probabilities:
    print(f"{p:.20f}")
```该解决方案将所有巧克力位置映射到传送带的上半部分。 排序确保我们可以有效地计算连续的可到达巧克力。 两指针方法在可触及的巧克力上保持一个滑动窗口。 通过检查最后一个巧克力段来仔细处理边界条件。

 ## 边缘情况

 对于位置 0 处的巧克力，d = l/2，根据皮带旋转可以部分到达。 滑动窗口会将其包含在第一个窗口中，添加与段长度成比例的概率。 如果所有巧克力都位于下半部分，则将它们映射回顶部可确保在旋转过程中正确计数。 处理巧克力处于精确到达边缘的情况是因为不等式使用`< d`而不是`<= d`。
