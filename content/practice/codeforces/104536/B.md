 ## 解决方案
 ## 问题理解

 我们得到了一个实值变换功率的方格。 在一次操作中，我们选择一行或一列，并在操作之前用算术平均值替换该行中的每个条目。 重复此操作会逐渐改变网格，因为更新的值会立即影响未来的平均值。 

目标不是使网格均匀或最小化全局变化，而是在任意数量的此类平均操作之后最大化网格中任何位置存在的最小值。 

关键的困难在于运营在全球范围内互动。 更改一行会影响与其相交的列，反之亦然，因此值以耦合方式而不是独立方式在网格中传播。 

约束 n 高达 1000 意味着最多 100 万个单元。 任何显式模拟操作序列的方法都是不可行的，因为即使是单个操作也是 O(n)，并且有意义的序列的数量是无限的。 因此，问题的结构必须分解为封闭形式的表征，而不是模拟。 

当网格已经具有统一的行或列时，会出现微妙的边缘情况。 例如，如果所有条目都相同，则任何操作序列都会保留该值，因此答案就是该数字。 天真的解释可能仍然尝试模拟和累积浮点漂移，由于精度损失而产生不正确的结果。 另一种失败情况是假设只有行操作或列操作很重要； 交替使用它们可以严格增加最小值，如示例所示。 

## 方法

 暴力视图首先想象应用于行和列的操作序列。 每个操作都会用其平均值替换一条线，因此在 k 次操作之后，每个单元格都是原始值的加权平均值，其中权重取决于所选线的顺序。 人们可以尝试枚举所有序列，甚至模拟固定数量的步骤，直到收敛。 

从概念上讲，这是可行的，因为该过程在松散意义上是单调的，值往往会平滑，但它会立即组合崩溃。 每一步都有 n 个选择，并且在稳定之前可能有很多步骤，从而导致指数或无界行为。 

关键的观察是最终状态不是任意的。 每个操作都会用等于其平均值的统一值替换行或列，这意味着一旦选择了行或列，它就变得完全同质。 随着时间的推移，这迫使系统采用一种配置，其中所有行和列都处于相同的全局平衡值。 

这将问题简化为确定可以在全球范围内执行的最佳稳定值。 由于行和列都是平均运算符，因此重复应用本质上是计算一个固定点，其中每行平均值和每列平均值等于相同的值。 该固定点必须是网格的全局平均值，因为平均操作保留了所有单元格的总和。 每个操作都会用其平均值替换一条线，这不会改变该线的总和，因此不会改变网格的总和。 

因此，总和是不变的，并且在最终状态下，所有 n² 个单元格必须等于相同的值。 该值必须是初始总和除以 n²。 由于这种配置可以通过样本构造中的交替行和列操作来实现，因此它是最佳的。

 ## 算法演练

1. 计算网格中所有元素的总和。 这捕获了任何操作下唯一不变的量。 
2. 观察到每个操作都用其平均值替换行或列，这保留了该行或列的总和，从而保留了全局总和。 
3. 由于总和是固定的，因此最大化所有单元格的最小值的唯一方法是使所有单元格相等，因为任何不平衡都会迫使最小值更小。 
4. 唯一可能的完全平衡配置是每个单元等于total_sum / (n * n) 的配置。 
5. 输出该值作为答案。 

### 为什么它有效

 网格在线性平均变换的操作下演化。 每个操作都会保留所有条目的总和，因此全局总和是一个不变量。 任何最终配置都被限制为与初始网格具有相同的总和。 仅当所有元素都相等时，最小元素才会最大化，因为任何与相等的偏差都必然会引入至少一个低于系统平均值的元素。 因此，最佳配置是均匀网格，其值等于保留的平均值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    total = 0
    for _ in range(n):
        row = list(map(int, input().split()))
        total += sum(row)

    ans = total / (n * n)
    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```该解决方案在 O(n²) 时间内读取网格并累加总和。 除了运行总数之外，不会存储任何中间状态，从而保持内存恒定。 

关键的实现细节是最后使用浮点除法。 整数除法会失去精度，过早舍入可能会达不到所需的误差容限。 以足够的小数精度打印可确保满足相对误差范围。

 ## 边缘情况

 当 n = 1 时，网格包含单个单元格。 对其唯一行或列的任何操作都会将其替换为其自己的平均值，即相同的值。 该算法计算total_sum / 1，因此输出与输入完全匹配。 

对于统一网格（例如所有条目均为 5），每个操作都保持均匀性。 计算出的总和为 5 * n²，除以 n² 得到 5。这符合对常数序列求平均不会改变它的不变量。 

对于高度倾斜的网格，例如一个大值被小值包围，重复平均可以均匀地分布质量。 例如，在其他位置值为 100 和 0 的 2x2 网格中，总和保留为 100，最终统一值变为 25。行或列平均的任何序列都会收敛到相同的约束，从而确认不变量完全确定答案。
