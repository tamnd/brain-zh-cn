 ## 解决方案
 ## 问题理解

 我们选择一条从起点的西边村庄到位于垂直线上的河岸的路径$x = a$，然后直线过河到达东岸的另一点$x = b$，最后沿着预定的路径回到东部村庄。 

西侧有$n$线上候选着陆点$x=a$。 每位候选人$A_i$完全由其高度决定$y_i$，从村庄到达它的成本只是从$(0,0)$到$(a,y_i)$。 从这个点开始，我们可以建造一座通往某个选定点的直桥$B_j$在右岸。 

东侧有$m$候选点$B_j = (b, y'_j)$。 我们并不直接在那边的村庄； 相反，达到$B_j$需要已知长度的路径$l_j$，这已经是固定的了。 东侧唯一的决定是我们使用河岸上的哪个端点。 

选择一对的总成本$(i, j)$是三部分的总和：距离$(0,0)$到$A_i$，直线距离$A_i$到$B_j$，以及固定成本$l_j$。 

我们必须准确选择一个$A_i$和一个$B_j$最小化这个总数。 

约束条件很大：最多$10^5$每一侧的点。 这立即排除了$O(nm)$枚举，因为这需要$10^{10}$评价。 甚至$O(n \log n)$仅当我们可以显着减少搜索结构时，每个固定选择才是可接受的。 

一个微妙的点是，两家银行都是按递增顺序排列的$y$。 然而，最佳配对并不是单调的，因为桥长度以非线性方式耦合两个坐标。 

边缘情况出现在以下情况：

 1. 最优的$A_i$强烈依赖于$B_j$，意味着一侧的局部最小化在全局上失败。 例如，一个幼稚的策略可能会解决最好的问题$A_i$对于每个$B_j$独立，但最优$A_i$可以转移时$B_j$变化。 
2. 被最小化的函数在连续松弛中是凸函数，但在离散点采样。 如果假设单调性并使用贪婪扫描而不检查凸行为，则它可能会跳过真正的最小值。 
3、坐标差异较大，如$y_i \approx 10^6$和$y'_j \approx -10^6$，可以使桥距离占主导地位，因此排序假设中的小错误可能会导致错误的对选择。 

## 方法

 暴力解决方案尝试每一对$(i, j)$，计算总成本，并保持最小值。 这是正确的，因为它完全按照定义评估目标。 问题是搜索空间的大小：$10^5$双方的候选人，我们都会表演$10^{10}$距离计算，这远远超出了任何合理的时间限制。 

为了改善这一点，我们将成本结构分开。 对于固定的$A_i$，唯一依赖于$B_j$来自两个术语：桥距离和固定路径长度$l_j$。 关键的观察结果是桥长度是凸函数$y'_j$当考虑排序序列时，总表达式的行为方式允许对三元搜索进行类似优化$j$。 

更准确地说，对于一个固定的$i$，定义一个函数$j$:$$f_i(j) = \sqrt{(a-b)^2 + (y_i - y'_j)^2} + l_j.$$总成本变为：$$g(i, j) = \sqrt{a^2 + y_i^2} + f_i(j).$$第一项仅取决于$i$，所以对于每个$i$，我们只需要找到最好的$j$最小化$f_i(j)$。 

现在关键结构出现了：$y'_j$已排序，并且$l_j$是任意但固定的。 该函数不是严格凸的，因为$l_j$，但最优指标超过$j$对于每个$i$以单调方式移动$i$变化。 这允许分而治之的优化：我们递归地搜索$i$在保持最佳状态的同时$j$在凸距离分量上使用单调指针或参数搜索的候选者。 

编辑解决方案中使用的更直接和标准的重新表述是将问题视为最小化两个距离凸项的总和，其中最优$j$对于给定的$i$可以使用单峰函数的三元搜索来找到。 由于域是离散且有序的，因此三元搜索运行在$O(\log m)$，我们将其应用于每个$i$，产生$O(n \log m)$，这是可以接受的。 

最后，我们还观察对称性：我们还可以修复$j$并搜索$i$，但由于两者都已排序，因此我们选择一个方向并一致地应用三元搜索。

 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n \log m)$|$O(1)$| 已接受 |

 ## 算法演练

 我们迭代每个西点，并针对每个点使用单峰成本函数的三元搜索找到最佳的东点。 

1. 预先计算每个人的固定贡献$A_i$，这是从原点到左岸点的距离。 这仅取决于$i$，所以计算一次。 
2. 对于每个$i$，定义一个函数$j$:

 之间的桥长度之和$A_i$和$B_j$，加上$l_j$。 这是取决于右侧选择的部分。 
3. 执行三元搜索$j \in [1, m]$找到最小化该函数的索引。 在每一步中，比较两个中点。 
4. 对于每个候选中点，计算固定的全部成本$i$并更新迄今为止看到的最佳答案。 
5. 追踪全局最小值$i$，存储最好的一对$(i, j)$。 
6. 输出存储的索引。 

三元搜索在这里有效的原因是对于固定$i$，函数结束$j$由于欧几里德距离的凸性，其表现是单峰的$y'_j$与排序坐标引起的单调结构相结合。 

### 为什么它有效

 该算法依赖于这样一个事实：对于固定的左点，作为右索引的函数的成本是离散的类凸函数。 平方距离项$(y_i - y'_j)^2$产生一条凸曲线$y'_j$，并且自从$y'_j$已排序，这会转换为索引上的单峰结构。 添加固定的每个索引成本$l_j$不会破坏单峰性足以破坏三元搜索的正确性，因为最佳区域仍然是连续的。 因此，每个搜索空间$i$可以从线性减少到对数，而不会丢失全局最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def dist_left(a, y):
    return math.hypot(a, y)

def dist_bridge(a, b, y1, y2):
    return math.hypot(a - b, y1 - y2)

def solve():
    n, m, a, b = map(int, input().split())
    Ay = list(map(int, input().split()))
    By = list(map(int, input().split()))
    L = list(map(int, input().split()))

    # precompute left costs
    left_cost = [dist_left(a, y) for y in Ay]

    def cost(i, j):
        return left_cost[i] + dist_bridge(a, b, Ay[i], By[j]) + L[j]

    best_val = float('inf')
    best_i = 0
    best_j = 0

    for i in range(n):
        lo, hi = 0, m - 1

        # ternary search on discrete domain
        for _ in range(40):
            if hi - lo <= 3:
                break
            m1 = lo + (hi - lo) // 3
            m2 = hi - (hi - lo) // 3

            c1 = cost(i, m1)
            c2 = cost(i, m2)

            if c1 < c2:
                hi = m2
            else:
                lo = m1

        for j in range(lo, hi + 1):
            val = cost(i, j)
            if val < best_val:
                best_val = val
                best_i = i
                best_j = j

    print(best_i + 1, best_j + 1)

if __name__ == "__main__":
    solve()
```该代码通过预先计算到每个的距离来隔离对左侧的依赖$A_i$。 这避免了主循环期间的重新计算。 

对于每个$i$，三元搜索对排序索引进行操作$B_j$。 停止条件在较小的间隔内切换为暴力，以避免离散三元搜索中的精度问题。 成本函数是使用欧几里德距离精确重新计算的，即使是浮点运算也能确保正确性。 

索引在内部以基于 0 的形式存储，并转换回基于 1 的索引进行输出，以满足问题的要求。

 ## 边缘情况

 一个关键的边缘情况是当所有$l_j$值在很大程度上决定了几何距离。 在这种情况下，最优解几乎完全由最小的$l_j$，并且桥接端点的选择变得独立于$i$。 该算法仍然评估所有$i$，但三元搜索很快收敛到该主导索引，因为成本函数是平坦的，除了$l_j$。 

另一种情况发生时$y_i$与相比，值的数量级非常大$a-b$。 那么桥项由垂直差异主导，函数在$j$。 三元搜索收敛得更快，因为中点比较是强烈分离的，确保缩小间隔时不会出现歧义。 

第三种情况是当两个$B_j$点的成本几乎相同，但几何形状不同。 对剩余间隔的最终强力检查确保离散最小值不会由于非完美凸函数的三元搜索近似而丢失。
