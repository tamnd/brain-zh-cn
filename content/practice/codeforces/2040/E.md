 ## 解决方案
 ## 问题理解

 我们得到一棵树，一个无向连通的无环图，其中`n`以顶点为根的顶点`1`。 机器人从某个顶点开始`v ≠ 1`并向根移动。 奇数步是确定性的：机器人总是沿着最短路径向顶点移动一步`1`。 偶数步允许选择：我们可以支付一枚硬币来强制向根方向确定性移动，或者让机器人随机移动到任何相邻顶点。 我们从`p`硬币，并且必须决定何时花费它们。 目标是计算机器人到达顶点的最小预期步数`1`。 

输入由多个测试用例组成，每个测试用例提供一棵树和多个查询。 每个查询指定一个起始顶点和硬币数量。 输出是单个整数模`998244353`，以模分数的形式表示预期的步骤数。 

约束告诉我们顶点的数量`n`在测试用例中不超过`2000`，所有测试用例的顶点总和也是`2000`。 查询数量`q`每个测试用例最多`2000`。 这意味着`O(n^2)`每个测试用例的解决方案都是可行的，但是任何事情`O(n^3)`或更高可能太慢。 小约束还允许使用分数和动态编程进行精确算术，而无需担心内存限制。 

一个不明显的边缘情况是`p`等于 0 或机器人距根仅一步。 例如，如果机器人从与`1`和`p = 0`，机器人在奇数步上确定性地移动，但第一个偶数步可能会引入随机性。 正确处理这个问题需要理解只有强制硬币才会影响预期值； 不考虑硬币支出的天真平均可能会给出错误的答案。 

## 方法

 蛮力方法用给定数量的硬币模拟机器人从起始顶点开始的所有可能的移动序列。 我们将递归地枚举每个步骤，考虑向根移动或随机向相邻顶点移动的概率。 每个分支都会乘以概率并对预期步数求和。 这适用于非常小的树，但分支因子呈指数增长，因为没有硬币的每个偶数步都会将路径数乘以当前节点的度数。 对于一棵树来说`2000`节点，暴力破解会产生最多`2^n`路径，这是不可行的。 

关键的观察结果是树结构对根施加了自然排序。 对于每个顶点，有根树中都有一个唯一的父顶点。 奇数步是确定性的，因此我们只需要计算偶数移动的预期步数。 在均匀的步骤中，最佳策略是要么支付硬币来确定性地移动，要么接受随机移动的期望值。 如果我们定义`f[v][c]`作为从顶点开始到达根的预期步数`v`和`c`硬币可用，我们可以使用动态规划。 叶到根计算确保每个顶点的期望值仅取决于其子节点和父节点。 概率需要分数算术，但是使用模逆可以让我们计算所有模数`998244353`。 

这个故事是，暴力破解会失败，因为概率呈指数级增长。 认识到奇数步骤是确定性的，并且只有偶数步骤才能创建期望值，让我们可以将问题简化为 DP`(vertex, coins)`对。 树结构和有限的硬币数量使得这个`O(n^2)`可行的。

 ## 算法演练

 1. 以顶点为树根`1`并计算所有顶点的父关系和子列表。 这确保每个顶点都知道它确定性地移向哪个顶点。 
2. 对于每个顶点`v`和硬币数量`c`， 定义`dp[v][c]`作为到达根的最小预期步数。 初始化`dp[1][c] = 0`为所有人`c`因为机器人已经在根部了。 
3. 按照从叶到根的 BFS 或 DFS 顺序处理顶点。 对于一个顶点`v ≠ 1`，第一步是奇怪的。 机器人确定性地移动到其父级`u`。 所以，`dp[v][c]`开始于`1 +`来自父级的期望值，占下一个偶数步。 
4. 在偶数步中，计算两个选项：花费一枚硬币确定性地向根移动（`dp[parent][c-1] + 1`）或允许随机移动。 随机移动的期望值是所有相邻顶点的平均值`w`的`dp[w][c] + 1`，按概率加权`1/degree(v)`。 DP值`dp[v][c]`是这两个选项中的最小值。 
5. 避免分数模`998244353`，使用模逆进行计算。 例如，如果一个顶点有`k`邻居，随机移动的期望值乘以`k^{-1} mod 998244353`。 
6. 对于每个查询`(v_i, p_i)`， 输出`dp[v_i][p_i]`。 

这是有效的，因为 DP 确保我们考虑所有最佳的硬币支出策略。 不变的是`dp[v][c]`始终存储从以下位置开始的最小预期步数`v`和`c`硬币，从孩子到父母计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())
        edges = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            edges[u].append(v)
            edges[v].append(u)

        parent = [0] * (n + 1)
        children = [[] for _ in range(n + 1)]
        degree = [0] * (n + 1)

        def dfs(u, p):
            parent[u] = p
            for v in edges[u]:
                if v == p:
                    continue
                children[u].append(v)
                dfs(v, u)
        dfs(1, 0)

        max_coins = n
        dp = [[0] * (max_coins + 1) for _ in range(n + 1)]

        for u in range(2, n + 1):
            for c in range(max_coins + 1):
                degree[u] = len(edges[u])

        for u in range(2, n + 1):
            for c in range(max_coins + 1):
                # Odd step: move to parent
                # Even step: choose min of paying or random
                if c > 0:
                    pay = (1 + dp[parent[u]][c - 1]) % MOD
                else:
                    pay = MOD
                deg = len(edges[u])
                rand_sum = sum((1 + dp[v][c]) % MOD for v in edges[u]) % MOD
                rand = rand_sum * modinv(deg) % MOD
                dp[u][c] = min(pay, rand)

        for _ in range(q):
            v_i, p_i = map(int, input().split())
            print(dp[v_i][p_i] % MOD)

if __name__ == "__main__":
    solve()
```该解决方案首先构建树和父数组。 DP 阵列`dp[v][c]`跟踪预期的步骤。 模逆处理除以节点度数来计算随机移动的期望值。 花费硬币或让机器人随机移动之间的最小值决定了最佳选择。 每个查询的答案都在`O(1)`使用预先计算的 DP 表。
