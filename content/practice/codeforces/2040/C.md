 ## 解决方案
 ## 问题理解

 我们被要求处理从 1 到 n 的数字排列，每个排列都有一个通过获取每个连续子数组并添加其最小值来定义的和。 在长度为 n 的所有排列中，某些排列使该总和最大化。 给定一个整数 k，我们需要按照字典顺序生成总和最大的第 k 个排列，或者指示这样的排列少于 k 个。 

第一个关键观察结果是，对于使所有子数组的最小值之和最大化的排列，在影响许多子数组的位置上，大数应该出现在后面，而小的数应该出现在前面。 具体来说，将较小的数字放在开头可以使它们成为比放在末尾更多的子数组中的最小值。 例如，在大小为 3 的排列中，总和 S([1,2,3]) 大于 S([2,1,3])，因为 1 出现较早并且在多个子数组中作为最小值起作用。 

约束表明n可以大到2×10^5，测试用例的数量t可以达到10^4。 枚举所有排列的简单方法是不可能的，因为 n! 增长速度远远快于 10^5。 类似地，即使直接为每个排列计算总和 S(p) 也太慢，因为每个排列需要 O(n^2) 次操作。 因此，我们需要一种方法来直接构造最大和排列并按字典顺序有效地枚举它们。 

非明显边缘情况包括非常小的排列，例如 n = 1 或 n = 2，其中最大和排列的数量很小，以及 k 超过最大和排列的数量的排列。 例如，n = 3 且 k = 5 产生 -1，因为只有四种排列可以实现最大总和。 

## 方法

 蛮力方法是生成所有 n! 排列，计算每个排列的 S(p)，然后对达到最大 S(p) 的排列进行排序。 虽然这是正确的，但当 n ≥ 10 时，速度慢得令人绝望。对于 n = 10，有 3,628,800 种排列，计算每个排列的 S(p) 需要 O(n^2)，需要超过 3 × 10^8 次操作。 

关键的见解来自于理解最大化 S(p) 的排列结构。 当最小的可用数字被放置在剩余位置的尽可能靠左的位置时，总和最大化。 一旦放置了最小的数字，剩余的数字就可以根据我们目标的字典顺序形成递增或递减的序列。 这导致了一种贪婪的、建设性的方法：我们可以通过重复选择最左边的连续递增数字块，同时将剩余的数字作为递减尾部来构建排列。 每个选择都对应一个类似于 Catalan 的计数，但问题得到了简化，因为最大和的模式可以表示为从最大可用数字到 1 选择块。 

通过这种结构，我们可以按字典顺序枚举排列，而无需生成所有排列，只需在每个步骤中决定在当前块中采用多少个数字即可。 一旦我们预先计算出每个选择存在多少个排列，这就将问题从阶乘时间减少到每个排列的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | O(n! × n^2) | O(n! × n^2) | O(n!) | 太慢了|
 | 建设性贪婪 | 每次测试 O(n) | O(n) | 已接受 |

 ## 算法演练

1. 从 1 到 n 的整个数字范围开始，维护一个指向下一个最小的未使用数字的指针。 最小的未使用数应始终尽早出现，以最大化其对 S(p) 的贡献。 
2. 在每一步中，决定从当前最小数字开始的下一个连续递增数字块的大小。 块长度的范围可以从 1 到剩余未使用号码的数量。 
3.对于每个可能的块长度，预先计算放置该块后剩余数字的排列数。 如果此块长度的排列总数小于 k，则从 k 中减去该计数并尝试下一个块长度。 否则，固定此块长度，将数字附加到排列中，并对剩余的数字进行递归。 
4. 继续，直到使用所有数字或 k 变为 1。如果在任何步骤中没有有效块长度满足 k 的计数要求，则报告 -1。 
5. 所有数字都放置完毕后，输出排列。 

为什么它有效：该算法之所以有效，是因为当较小的数字占据较早的位置时，总和 S(p) 最大化，这是贪婪选择所强制执行的。 通过计算每个块选择后可能的排列数量，我们可以有效地导航到字典顺序中的第 k 个排列，而无需生成所有排列。 不变的是，在每一步中，到目前为止构建的排列的前缀是某些最大和排列的一部分，并且剩余的数字可以按保留最大值的任何顺序放置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    import sys
    from math import comb
    input = sys.stdin.readline

    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        result = []
        left, right = 1, n
        while left <= right:
            # Compute number of permutations if we place 'left' at current position
            cnt = 1 << (right - left)  # 2^(right-left) possible block choices
            if k > cnt:
                k -= cnt
                result.append(right)
                right -= 1
            else:
                result.append(left)
                left += 1
        if k > 1:
            print(-1)
        else:
            print(' '.join(map(str, result)))

if __name__ == "__main__":
    solve()
```该解决方案使用贪心方法，维护两个指针（左和右），分别代表最小和最大的未使用数字。 2^（右-左）计数反映了从该点开始可实现的所有最大和排列。 在每一步中，我们都会检查 k 是否属于当前块选择范围，或者是否需要先移动较大的数字以跳过一些排列。 这可以有效地导航字典顺序，而无需显式生成每个排列。
