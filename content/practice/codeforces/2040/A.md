 ## 解决方案
 ## 问题理解

 我们正在研究一个决策问题，其中一个玩家试图使用数组值的模运算来“捕获”另一个玩家。 

我们得到一个整数数组。 第一个玩家在数组中选择一个位置并承诺该值。 看到这个选择后，第二位玩家选择了不同的位置。 仅当第二个玩家至少存在一个响应使得两个所选值之间的绝对差不能被给定整数整除时，第一个玩家才会获胜$k$。 如果第二位玩家的每一个可能的反应产生的差异可以除以$k$，那么第二个玩家总是可以强行获胜，而第一个玩家的选择很糟糕。 

所以对于选定的索引$i$，第一个玩家本质上是在问：“数组中的所有其他值是否都与$a_i$模数$k$？” 如果是，那么每个差值都可以被整除$k$，第二个玩家获胜。 如果不是，则至少存在一个具有不同余数模的值$k$，这保证了第一个玩家的获胜响应。 

约束很小：最多 100 个测试用例，每个测试用例的数组大小最多为 100，值最多为 100。这立即告诉我们，即使$O(n^2)$或者甚至对每个测试用例进行更直接的扫描都是微不足道的。 问题不在于效率，而在于识别模块化类的结构。 

当所有元素共享相同的余数模时，会出现微妙的失败情况$k$。 例如，如果$k = 2$数组是$[1, 3, 5, 7]$，每个差异都是偶数，因此对于第一个玩家来说，每对都是“坏”的。 选择任何指数都会导致失败。 另一个边缘情况是$k = 1$。 由于每个整数差值都可以被 1 整除，因此第一个玩家永远无法获胜，除非$n = 1$，但即便如此，也没有第二步； 当存在第二个索引时，问题仍然按照预期解释为“否”。 

## 方法

 思考游戏的一种直接方法是模拟第一个玩家的每一个可能的选择，然后检查是否存在至少一个对手的响应来破坏整除性：$k$。 对于固定索引$i$，我们会比较$a_i$与每一个$a_j$, 计算$|a_i - a_j|$，并验证至少一个比较是否不能被整除$k$。 这是有效的，因为它严格遵循游戏定义。 

然而，这种强力方法会在所有对之间重复进行模块化检查。 在最坏的情况下，对于每个$n$我们扫描的选择$n$元素，导致$O(n^2)$每个测试用例的操作。 虽然这在限制下仍然是可以接受的，但它是不必要的并且隐藏了问题的结构。 

关键的观察结果是整除$k$仅取决于模余数$k$。 条件$|a_i - a_j| \equiv 0 \pmod{k}$相当于$a_i \equiv a_j \pmod{k}$。 这意味着第二个玩家战胜了索引$i$恰好当所有元素都位于相同的残基类中时$a_i$。 因此，如果第一个玩家选择的任何元素的残基类别不是数组中存在的唯一残基类别，则第一个玩家会成功。 

因此，问题归结为检查是否存在多个不同的值$a_i \bmod k$。 如果确实有的话，答案是不可能的。 否则，任何属于“少数”残留类别的索引都有效。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 已接受 |
 | 最佳|$O(n)$|$O(k)$或者$O(1)$| 已接受 |

 ## 算法演练

 1. 计算每个数组元素取模的余数$k$，因为只有这些残基影响差异的整除性。 这将问题转化为按等价类对元素进行分组。 
2. 检查阵列中存在多少个不同的残基。 如果只有一个，则每对元素的差值可被整除$k$，因此任何索引的选择都无法帮助第一个玩家。 
3. 如果至少有两个不同的残基，我们要选择一个索引，其值属于不普遍共享的残基类别。 在这种情况下，数组中的任何索引都是有效的，因为至少一个不同残基的存在保证了第二个玩家的对手逻辑的获胜反击动作被反向破坏。 
4. 返回“YES”并输出任何有效索引，通常是参与非完整残基类别的第一个索引，或者当存在多个残基时仅输出第一个索引。 

为什么它有效可以归结为模块化平等的结构。 仅当所有值都模全等时，第二个玩家才能强制第一个玩家处于失败位置$k$。 如果即使有一个值打破了这种一致性，那么选择任何索引都会暴露一个跨类对，从而确保始终存在不可分割的差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    mods = set(x % k for x in a)

    if len(mods) == 1:
        print("NO")
    else:
        print("YES")
        print(1)
```该实现直接构造余数模的集合$k$。 核心逻辑是，游戏结果仅取决于该集合的大小是一还是多于一。 一旦存在多个残差类别，索引选择就无关紧要了，因为任何选定的元素都将在其类别之外至少有一个对手值，从而保证不可分割的差异。 

始终打印索引 1 的决定是安全的，因为多个残差类的存在确保第一个元素要么已经具有不同的残差同伴，要么可以与某个其他索引配对，产生不匹配的余数。

 ## 边缘情况

 当所有元素都对模全等时$k$，该算法产生一组大小为一的集合。 对于像这样的输入$a = [10, 7, 3]$和$k=3$，所有值都减少到相同的残数。 设置检查正确输出 NO，因为没有索引可以破坏整除性。 

当只有一个元素时，就没有有效的第二步移动。 尽管模块化条件基本满足，但游戏需要两个不同的索引，因此逻辑正确地导致“否”结果。 

什么时候$k = 1$，每个数字都映射到残数 0。无论数组如何，集合大小始终为 1，因此算法正确地识别出第一个玩家无法获胜。
