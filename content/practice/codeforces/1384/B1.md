 ## 解决方案

 ## 问题理解

 Koa 需要穿过一排海洋单元从位置 0（海岸）移动到位置 n+1（岛屿）。 每个中间位置i都有固定的基础深度d[i]，但水位不是静态的。 相反，潮汐会添加一个与时间相关的偏移量，每 2k 秒循环一次：它从 0 线性增加到 k，然后减少回 1。 

在任意整数秒t，如果Koa站在位置x，则该位置的有效深度为d[x]加上t时刻的潮汐值。 Koa 可以每秒留在原地或向右移动一步，时间总是前进。 如果有效深度不超过阈值 l，她只能安全地站在海洋单元上。 在牢房之间移动时，她在过渡期间是安全的，因此只有到达时间才重要。 

任务是确定是否存在允许她到达岛屿的一系列等待和移动。 

约束很小，n、k 最多为 100，并且最多 100 个测试用例，因此 O(n^3) 或 O(n^2 k) 方法是可以接受的。 然而，位置和时间之间的相互作用使得贪心推理变得危险，因为潮汐只取决于时间，而不取决于位置，因此同一个单元格可能在某一时刻是安全的，但不久之后就会不安全。 

当一个单元只是偶尔安全时，就会出现一种常见的微妙故障情况。 例如，如果某个位置仅在潮汐下降阶段才变得安全，则在单元格安全后立即采取的幼稚策略将失败，因为到达时间可能与安全阶段不一致。 

另一个棘手的情况是，为了与未来的安全窗口同步，需要在较早的单元中停留太长时间。 贪婪的“尽快行动”策略会失败，因为它忽略了时间对齐约束。 

## 方法

 强力方法将问题建模为成对的状态图（位置、时间 mod 2k）。 对于每个状态，如果下次目标单元格安全，Koa 可以停留或前进。 这保证了正确性，因为它探索了所有有效的调度，但状态空间为 n × 2k，每个状态最多有两次转换，在最坏的情况下，每次测试大约有 40,000 个状态。 在这里这是可以接受的，但如果我们观察结构，这仍然是不必要的。 

关键的见解是我们不需要考虑任意的​​时间演化；我们不需要考虑任意的​​时间演化。 只有每个位置的最早到达时间很重要。 如果我们在某个时间 t 到达位置 x，那么任何较晚的到达时间都会更糟，因为它只会使潮汐相位向前移动，可能会降低可行性。 因此，我们跟踪到达每个位置的最短时间。 

一旦我们计算出到达位置 i 的最早时间，我们就可以贪婪地模拟在 i 处等待，直到有可能在某个有效时间移动到 i+1。 潮汐的周期性使我们能够在 O(k) 内测试每个出发时间的可行性，因此总体上我们可以有效地向前过渡。 

问题归结为迭代位置，并为每个位置找到我们可以安全出发到下一个位置的最早时间。

 ## 算法演练

 我们定义一个函数来检查在给定位置 i 和时间 t，Koa 是否安全：d[i] + p[t mod 2k] ≤ l。 

我们维护一个数组 best[i]，表示我们可以安全到达位置 i 的最早时间。 最初，best[0] = 0，因为 Koa 在时间 0 时从海岸开始。 

我们逐个位置进行处理，尝试从 best[i] 计算 best[i+1]。

1. 从 best[0] = 0 开始，因为 Koa 在零时间从岸边开始，没有任何限制。 
2. 对于从 0 到 n 的每个位置 i，尝试计算 i+1 处的最早有效到达时间。 
3. 对于候选到达位置 i 的时间 t，我们考虑 Koa 可以离开 i 的所有可能时间 t' ≥ t。 在时间 t' 时，Koa 可以移动到 i+1，因此我们必须确保位置 i 在 t' 时是安全的，位置 i+1 在 t'+1 时也是安全的。 
4. 为了找到最早可行的 t'，我们从 best[i] 开始向前扫描。 对于每个时间步长，我们检查：

 d[i] + p[t mod 2k] ≤ l 是否成立。 

这是必需的，因为 Koa 在等待时必须保持活着。 
5. 当我们找到时间t'使得位置i在t'处是安全的时，我们测试她是否可以移动到i+1，意思是：

 d[i+1] + p[(t'+1) mod 2k] ≤ l。 
6. 如果两个条件都成立，我们设置 best[i+1] = t'+1 并移动到下一个位置。 
7. 如果在合理的有界范围内不存在这样的 t'（最多需要 2k 个阶段，因为该模式每 2k 重复一次），我们得出结论，运动是不可能的。 

### 为什么它有效

 关键的不变量是，对于每个位置 i，best[i] 是 Koa 可以安全站立在那里的最短时间。 任何较晚的到达时间只能更差或相当，因为潮汐状态在时间上纯粹是周期性的，因此延迟不会引入较早时间在一个周期内尚未暴露的新的有利相位。 因此，仅从长度为 2k 的一个完整周期内的最早到达时间向前检查就足以确定下一位置的可达性。 

这将无限时间过程减少为每个边的有界循环可行性检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, l = map(int, input().split())
        d = [0] + list(map(int, input().split()))
        
        # precompute tide pattern
        p = list(range(k)) + list(range(k - 2, 0, -1)) if k > 1 else [0, 1]
        if k == 1:
            p = [0, 1]
        period = len(p)
        
        INF = 10**18
        best = [INF] * (n + 2)
        best[0] = 0
        
        def safe(i, t):
            return d[i] + p[t % period] <= l
        
        ok = True
        
        for i in range(n + 1):
            if best[i] == INF:
                ok = False
                break
            
            tcur = best[i]
            found = False
            
            # search within one cycle window
            for dt in range(period * 2):
                t = tcur + dt
                if not safe(i, t):
                    continue
                if i + 1 <= n:
                    if d[i + 1] + p[(t + 1) % period] <= l:
                        best[i + 1] = min(best[i + 1], t + 1)
                        found = True
                        break
                else:
                    best[i + 1] = t + 1
                    found = True
                    break
            
            if not found and i != n + 1:
                ok = False
                break
        
        print("Yes" if best[n + 1] != INF else "No")

if __name__ == "__main__":
    solve()
```该实现显式地构建潮汐周期，然后逐个位置向前传播最早到达时间。 内部循环检查从当前最佳到达时间开始的有限时间窗口，确保我们至少捕获潮汐阶段的完整重复。 这`safe`函数封装了固定时间的约束检查。 

一个微妙的点是，我们总是在时间 t 检查位置 i 的安全性，并在时间 t+1 检查位置 i+1 的安全性。 这符合 Koa 在整数倍上必须是安全的规则，并且只有秒之间的转换才重要。

 ## 边缘情况

 一个关键的边缘情况是单元格只是偶尔安全。 该算法通过向前扫描整个潮汐周期来处理这个问题，确保即使错过了第一个安全时刻，也能找到下一个重复时刻。 这可以防止过早拒绝。 

另一种情况是 Koa 必须在较早的位置等待以调整未来的阶段。 由于 best[i] 是最早到达时间，因此算法自然会将等待视为扫描的一部分，而不是强制立即移动。 

最后的边缘情况是当 k = 1 时，潮汐每秒交替一次。 p 的构造通过产生正确的最小周期 [0, 1] 显式地处理了这个问题，即使在最小周期设置中也确保相位正确性。
