 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们希望按非降序对其进行排序。 问题是我们不能任意交换元素。 相反，我们有一个可用的复杂操作：取出第一个元素，将其移动到末尾，然后将其向左冒泡，只要它小于其直接前一个元素。 从概念上讲，这就像旋转数组并让移动的元素向左“滑动”，直到找到相对于它传递的元素的正确位置。 目标是确定对数组进行排序的最小操作数，或者如果无法实现排序则报告不可能性。 

该数组最多可以包含 200,000 个元素，并且多个测试用例中所有数组大小的总和不超过 200,000。 这将我们的解决方案限制为线性或线性时间复杂度； 任何二次方都会太慢。 例如，尝试简单地模拟每个操作可能需要花费`O(n^2)`每个数组的时间，这是不可行的。 

微妙的边缘情况包括已经排序的数组（零操作）、第一个元素是最大的数组并且除非多次删除否则会阻止排序，以及具有重复元素的数组，其中交换受到“严格大于”条件的限制。 说明朴素模拟失败的一个小例子是`[4, 3, 1, 2]`。 如果您只是尝试向前移动每个元素而不考虑全局顺序，您可能会得出结论，它可以一次性排序，而正确的答案是不可能的，因为`3`和`1`无法通过允许的操作来修复。 

## 方法

 蛮力方法实际上会模拟该操作：重复将第一个元素移动到末尾，然后将其冒泡回来，直到它适合为止。 每次操作后，检查数组是否已排序。 这是可行的，因为操作是确定性的，并且每个应用程序都以定义的方式更改数组。 然而，最坏情况下的操作次数可以达到`n`每个元素，导致`O(n^2)`每个测试用例。 和`n`到200,000，这太慢了。 

最佳方法的关键见解是认识到该操作本质上允许我们将已经按顺序排列的数组的任何前缀移到后面。 如果我们从尾部向后思考数组，则已经排序且非递减的最长后缀不能被以后的操作触及； 只有元素才能移动。 因此，最小操作数由该排序后缀之前的未排序前缀的长度确定。 如果未排序的前缀包含大于已排序后缀的第一个元素的任何元素，则排序将变得不可能，因为该操作无法在不违反“严格大于”规则的情况下将元素插入后缀的中间。 

因此，问题简化为从末尾识别最长的非递减后缀，并检查剩余的前缀是否可以按顺序移到后面而不发生冲突。 如果是，则操作次数等于前缀的大小； 否则，排序是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1、对于给定的数组，从末尾开始扫描，寻找最长的非递减后缀。 初始化一个指针`i = n-2`并向后移动只要`a[i] <= a[i+1]`。 此后，`i+1`标记已排序后缀的开始。 
2、检查该后缀之前的前缀是否可以在不违反操作规则的情况下“旋转”到最后。 具体来说，该操作允许每个元素向左冒泡，直到它不再小于其前一个元素。 这相当于检查前缀是否是非递增的，因为数组的第一个元素最终必须到达该前缀的末尾。 
3. 计算需要的操作次数，这正是未排序前缀的长度。 这是排序后缀之前的元素数量。 
4. 如果在任何时候我们检测到前缀中的某个元素大于已排序后缀的开头并且无法正确插入，则输出`-1`。 

为什么有效：该操作允许每个前缀元素移动到后面，同时尊重相对顺序。 不变的是，一旦元素进入排序后缀，它就会保持在正确的相对位置。 因此，确定最长的排序后缀可以告诉我们最小安全点； 它之前的所有内容都必须通过操作移动，并且它们的数量等于前缀的大小。 前缀中的任何违规都意味着某些元素永远不会符合规则，从而保证了不可能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations_to_sort(a):
    n = len(a)
    i = n - 2
    while i >= 0 and a[i] <= a[i + 1]:
        i -= 1
    if i == -1:
        return 0  # already sorted
    prefix_length = i + 1
    
    # Check if the prefix is non-increasing
    for j in range(prefix_length - 1):
        if a[j] < a[j + 1]:
            return -1
    return prefix_length

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(min_operations_to_sort(a))
```功能`min_operations_to_sort`首先从末尾查找排序后的后缀。 如果整个数组已排序，则返回零。 然后，它检查未排序的前缀以确保它不增加。 如果不是，前缀中的某些元素将违反操作的“冒泡直到严格大于”条件，从而无法进行排序，因此我们返回`-1`。 否则，操作次数等于前缀长度，因为每个元素必须旋转一次才能到达其正确位置。
