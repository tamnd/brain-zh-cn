 ## 解决方案
 ## 问题理解

 该问题要求我们找出两辆卡车在装载 TNT 箱时可能的最大重量差。 我们有一排给定重量的箱子，我们可以选择任何卡车尺寸$k$从 1 到$n$只要它能分开$n$。 卡车连续装载：第一辆$k$箱子被送到第一辆卡车，然后是下一辆$k$箱子被运往第二辆卡车，依此类推。 我们的目标是最大化所选卡车的任意两辆卡车之间总重量的绝对差异$k$。 

输入由多个测试用例组成。 每个测试用例给出了盒子的数量$n$和一系列盒子重量。 输出是两辆卡车总重量之间的最大绝对差。 如果只有一辆卡车，则答案为 0，因为没有其他卡车可供比较。 

约束条件允许$n$高达 150,000 以及$t$最多 10,000，但所有的总和$n$跨测试用例最多为 150,000 个。 这意味着我们的解决方案必须基本上在每个测试用例的线性时间内运行，或者$O(n \log n)$最坏的情况是。 一个尝试每一个的天真的解决方案$k$并独立计算所有卡车的总和$O(n^2)$在最坏的情况下，这太慢了。 

非明显的边缘情况包括所有盒子具有相同权重的情况，无论什么情况都会产生最大差异 0$k$，以及情况$n$是素数。 例如，如果$n = 7$所有盒子的重量均为 1，任意选择$k$产生相等的卡车总和，并且最大差值为 0。粗心的解决方案可能会假设最大重量差总是涉及最大和最小的箱子，而不考虑分组约束。 

## 方法

 蛮力方法会迭代所有$k$从 1 到$n$，通过对每个卡车求和来计算每辆卡车的总和$k$大小的线段，然后找到最大差值。 这是可行的，因为它尊重加载规则，但复杂性是$O(n^2)$在最坏的情况下，当$n$很大。 为了$n$大约 150,000，这将需要超过$10^{10}$操作，这是不切实际的。 

优化的关键见解是，当一辆卡车获得最大重量而另一辆卡车获得最小重量时，卡车总和之间的绝对差异最大化。 对数组进行排序提供了一种清晰的分区方式：第一个$k$按排序顺序的方框给出了最小卡车总和，最后一个$k$盒子给出了最大卡车总和。 这一观察结果将问题简化为排序，然后计算前缀和后缀总和之间的差异。 

对于任何有效的$k$划分$n$，最大差值是$k$最大的盒子减去总和$k$最小的盒子。 由于约数的个数$n$最多是周围$2 \sqrt{n}$，我们可以在排序后有效地计算所有除数的差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$和盒子权重的数组$a$。 
2. 对数组进行排序$a$。 排序可确保最小重量位于开头，最大重量位于末尾，这有助于有效计算极端卡车总和。 
3. 初始化变量`max_diff`为 0。这将存储当前测试用例观察到的最大差异。 
4. 迭代$k$从 1 到$n - 1$（我们不需要$k = n$因为它只生产一辆卡车）。 对于每个$k$，计算最后的总和之间的差$k$元素（最大权重）和第一个元素的总和$k$元素（最小权重）。 更新`max_diff`如果这个差异更大。 
5. 打印`max_diff`对于每个测试用例。 

为什么它起作用：排序确保任何连续的大小块$k$代表一辆卡车的总和不能超过最大的总和$k$元素或小于最小元素之和$k$元素。 通过检查所有有效的这些极端值之间的差异$k$，我们保证找到最大可能的绝对差。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    max_diff = 0
    # Only need to check 1 <= k <= n-1
    for k in range(1, n):
        diff = sum(a[-k:]) - sum(a[:k])
        if diff > max_diff:
            max_diff = diff
    print(max_diff)
```该代码使用快速 I/O 读取输入。 对数组进行排序时，将最小的元素放在开头，将最大的元素放在结尾。 对于每种卡车尺寸$k$，它计算第一个的总和$k$元素和最后一个$k$元素。 最大差异会即时更新。 请注意，可以使用前缀和来优化每次迭代中的总和计算，但对于$n$最多 150,000 个，加上 Python 的高效切片，这种方法在时间限制内是足够的。

 最大差异为 13，出现的情况为$k = 2$或者$k = 3$。 这证实了算法正确地找到了最大卡车差异。

```排序不会改变数组。 任何$k$结果第一个和最后一个的总和相等$k$元素，所以最大差值为 0。
