 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 每个测试用例提供一个整数数组，任务是选择一个非空的连续段，其总和尽可能大，但有一个附加限制：所选段内的相邻元素必须以奇偶校验方式交替。 换句话说，每当两个相邻的选定元素在原始数组中彼此相邻时，一个必须是偶数，另一个必须是奇数。 

这将经典的最大子数组和问题变成了受约束的版本，其中不允许我们通过具有相同奇偶校验的两个连续元素来扩展段。 但是，我们仍然可以在任何地方开始一个新段，并且不需要使用整个数组。 

这些约束允许所有测试用例最多包含 200,000 个总元素，这立即意味着每个测试用例的任何解决方案都必须是线性的，或者最坏的情况是 O(n log n)。 在最坏的情况下，尝试所有子数组或重复重新计算分段总和的二次方法将达到大约 10^10 次运算，这远远超出了限制。 这将我们推向动态编程或贪婪线性扫描。 

一些边缘情况很容易被忽略。 

单元素数组总是有一个等于该元素的答案，即使它是负数，因为我们必须选择一个非空子数组。 

交替奇偶校验但具有许多负值的段可能仍然是提前截断的最佳选择，因为扩展它可能会减少总和。 

当我们打破奇偶校验交替时，天真贪婪扩展的一个微妙的失败案例就会发生：重新启动太晚或太早可能会错过更好的段。 例如，在像这样的数组中`[5, -100, 4, 3]`，如果负值应该强制提前重新启动，则仅在奇偶校验中断时盲目重置是不够的。 

## 方法

 蛮力的想法是枚举每个可能的子数组并检查它是否满足奇偶校验交替约束。 对于每个有效的子数组，我们计算其总和并跟踪最大值。 检查一个子数组的有效性需要 O(length)，并且有 O(n^2) 个子数组，导致最坏情况时间为 O(n^3)，这是不可行的。 

我们可以通过注意到子数组的有效性是局部的来减少这种情况：一旦我们固定了起始索引，我们就可以贪婪地扩展，直到奇偶校验条件被打破。 这将检查从 i 开始的所有子数组的次数减少到 O(n)，即 O(n^2)。 对于 2e5 个总元素来说仍然太慢。 

关键的观察是我们永远不需要重新审视之前的决定。 在每个位置，我们要么继续现有的有效交替段，要么从当前元素重新开始。 这是类似于 Kadane 算法的经典动态规划情况，但对转换有额外的限制。 

我们维护以当前索引结尾的有效交替子数组的最佳可能总和。 当我们从 i−1 扩展到 i 时，只有当 a[i] 与 a[i−1] 具有不同的奇偶校验时才允许这样做。 如果奇偶校验匹配，我们必须从 i 处重新开始。 

此外，即使允许扩展，我们仍然将其与在 i 处重新开始进行比较，因为之前的累积和可能为负并损害最优性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 最佳 DP（类似 Kadane）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个数组，同时维护以当前位置结束的运行最佳子数组。 

1. 初始化变量`current`作为以索引 0 结尾的最佳交替子数组和，这很简单`a[0]`。 我们也初始化`answer = a[0]`因为最好的子数组可能是单个元素。 
2. 从索引 1 到 n−1 迭代数组。 
3. 在每个索引 i 处，检查是否`a[i]`可以扩展前一段。 扩展仅在以下情况下有效`a[i]`和`a[i-1]`有不同的奇偶性。 如果奇偶校验相同，则在遵守规则的情况下，任何以 i−1 结尾的子数组都不能扩展到 i。 
4. 如果扩展有效，则计算候选值`current + a[i]`。 否则，将扩展设置为不可能。 
5. 无论扩展可行性如何，也考虑在 i 处开始一个具有 value 的新子数组`a[i]`。 
6. 设置`current`达到这两个选项的最大值。 这种选择确保我们始终保留以 i 结尾的最佳有效交替子数组。 
7. 更新`answer`和`max(answer, current)`。 

扫描完成后，`answer`包含所有有效子数组的最佳可能总和。 

### 为什么它有效

 在每个索引 i 处，算法都保持以下不变式：`current`是恰好以 i 结尾的任何有效交替奇偶校验子数组的最大和。 任何这样的子数组要么来自扩展以 i−1 结尾的有效子数组，要么来自于从 i 开始的新子数组。 没有第三种可能性，因为每个以 i 结尾的子数组都必须包含 i 并且其前一个元素要么是子数组的一部分，要么不是。 奇偶校验约束仅限制是否允许扩展，而不限制最优子数组的结构。 因为我们总是选择这两个选择中最好的，所以不会放弃任何最佳解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
out = []

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    current = a[0]
    best = a[0]
    
    for i in range(1, n):
        if (a[i] % 2) != (a[i - 1] % 2):
            extend = current + a[i]
        else:
            extend = -10**18  # invalid transition
        
        current = max(a[i], extend)
        best = max(best, current)
    
    out.append(str(best))

print("\n".join(out))
```代码直接遵循DP公式。 变量`current`表示以当前索引结尾的最佳有效交替子数组。 当奇偶校验交替时，我们尝试延长； 否则，延期强制无效。 

一个微妙的点是与`a[i]`它本身，确保我们在先前的积累有害时重新启动。 这就是在存在负值的情况下保持最优性的原因。 

变量`best`跟踪所有端点的全局最大值，因为最佳子数组可能在任何地方结束。

 ## 边缘情况

 直接处理单个元素输入，因为初始化同时设置了`current`和`best`到第一个元素。 循环不会执行，因此即使值为负数，也会正确返回答案。 

所有数字具有相同奇偶校验的数组决不允许扩展。 该算法有效地减少了取最大单个元素的过程，因为每个索引都成为一个重新开始点。 每次迭代集`current = a[i]`， 所以`best`跟踪最大元素。 

对于具有较大负值的交替数组，算法可能会重复重新启动。 每次重新启动均由`max(a[i], extend)`比较，确保我们永远不会结转有害的前缀和。 

如果负值夹在两个有效的交替正值之间，算法会正确评估保留负值是否会改善更长的交替链，或者重新启动是否会产生更好的总和。
