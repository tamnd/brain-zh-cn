 ## 解决方案
 ## 问题理解

 我们被要求分析一个简单的整数两人游戏。 游戏从一个数字开始$n$。 Vanya 首先移动，每个玩家都可以在自己的回合中将数字增加或减少 1。 如果 Vanya 在移动之后数字能被 3 整除，则立即获胜。如果 Vanya 在 10 步移动（每次 5 回合）后未能获胜，则 Vova 获胜。 目标是确定对于给定的起始数$n$，假设双方都发挥最佳状态，哪位玩家将获胜。 

输入由多个测试用例组成，每个测试用例都有一个整数$n$范围从 1 到 1000。$t \le 100$，操作总数并不多。 约束足够小，如果有必要，我们可以探索每一个可能的移动序列，但存在更聪明的方法，因为游戏的获胜条件完全取决于能被 3 整除。 

当出现不明显的边缘情况时，$n$已经能被3整除。在这种情况下，Vanya不能在不立即让Vova反应的情况下增加或减少，但他仍然先走，所以他不能做出保持数字能被3整除的举动； 他必须尝试调整它。 另一个微妙之处是加或减 1 会交替取模 3 的余数。例如，如果$n \% 3 = 1$，Vanya 可以通过减 1 直接移动到 3 的倍数。这些模数考虑因素决定了最佳玩法。 在不认识这种模块化模式的情况下模拟移动的幼稚方法可能会错误地预测获胜者。 

## 方法

 暴力方法将枚举最多 10 步的所有移动序列，在玩家之间交替，并检查 Vanya 移动后是否有任何序列导致 3 的倍数。 由于每次移动都有两个选择，因此最坏情况下的序列总数为$2^{10} = 1024$每个测试用例。 这是可行的，但没有必要，因为游戏完全由数字模 3 决定。 

关键的见解是获胜者完全由剩余的人决定$r = n \% 3$。 如果$r = 0$，Vanya 无法立即获胜，因为任何 ±1 步都会导致$r = 1$或者$2$。 如果$r = 1$或者$2$，Vanya 可以在第一回合中通过减或加 1 立即移动到 3 的倍数。 10 步限制的其余部分无关紧要，因为 Vanya 要么立即获胜，要么无法在一步内达到 3 的倍数。 这将问题简化为简单的模检查。

 | 最佳 | O(t) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取整数$n$。 
3. 计算余数$r = n \% 3$。 
4. 如果$r = 0$，打印“第二”。 这是因为万尼亚无法使$n$第一步就被 3 整除，所以 Vova 最终获胜。 
5. 如果$r = 1$或者$2$，打印“第一”。 万尼亚可以立即调整$n$±1 使其能被 3 整除，即刻获胜。 

工作原理：这里的不变量是关于当前整数的唯一相关信息是其模 3 的余数。每次移动都会将余数移动 ±1。 Vanya 首先移动，因此如果可能的话，他可以选择一个移动来命中 0 模 3。 如果他不能，就意味着余数已经是0，他不能立即获胜。 由于允许的移动次数 (10) 大于 1，并且双方都发挥最佳状态，因此模 3 的余数完全决定了结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    r = n % 3
    if r == 0:
        print("Second")
    else:
        print("First")
```该解决方案可以有效地读取输入`sys.stdin.readline`对于多个测试用例。 对于每个数字，它会计算模 3 的余数，从而直接确定获胜者。 不需要额外的状态或模拟，这避免了差一错误或不正确的移动计数。

 ## 边缘情况

 如果`n`可以被 3 整除，例如`n = 3`， 然后`n % 3 = 0`。 根据我们的算法，它输出“Second”。 轨迹：Vanya 的第一步既可以增加也可以减少`n`2或4。两者都不能被3整除，因此Vova可以做出最佳反应并最终在10步之内获胜。 该算法无需模拟所有动作即可正确预测此结果。 

如果`n = 1000`,`n % 3 = 1`，Vanya 可以减 1 得到 999，可以被 3 整除。输出是“First”。 这证实了模检查可以处理范围内的大数，并表明解决方案可以扩展到上限约束。
