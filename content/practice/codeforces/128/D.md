 ## 解决方案
 ## 问题理解

 给我们一组数字，并询问是否可以将它们排列成一个圆圈，以使每对相邻的数字恰好相差一。 从概念上讲，这意味着每个数字都是一个循环上的一个顶点，并且相邻数字之间的绝对差必须为 1。输入由元素数量组成，后跟元素本身。 如果存在这种圆形排列，则输出简单地为“YES”，如果不存在，则输出为“NO”。 

约束很重要：元素的数量$n$可以达到$10^5$，并且值本身可以达到$10^9$。 这排除了任何尝试显式构造所有排列的解决方案，这将是阶乘时间。 我们需要一种线性或近线性的方法。 

一些边缘情况很容易使简单的解决方案失败。 例如，如果所有数字都相同，则邻居之间的差异将为零，而不是一，因此输出必须为“NO”。 如果数字形成简单的递增或递减序列，例如`1 2 3 4 3 2`，可以将它们对称排列以满足圆形条件。 另一个棘手的情况是当一个数字出现两次以上但不是序列的端点时； 例如，`1 2 2 3 3 3`无法形成有效的圆，因为`3`必须与两个相邻`3`s 至少一次，违反了差异条件。 

## 方法

 暴力方法很容易描述：生成数字的所有排列并检查每个排列的循环差异条件。 这在原则上是正确的，因为它实际上测试了每种可能的安排，但复杂性是$O(n!)$，这对于$n$最多$10^5$。 

关键的见解来自于观察相邻差异恰好为一的序列的属性。 任何有效的排列实际上都是形成“山”或“谷”模式的连续整数序列（可能有重复），因为每个数字必须与其相邻数字恰好相差一。 这意味着多重集可以分为严格递增段和严格递减段，每个数字最多出现两次，除了最小值和最大值只能出现一次。 中间出现两次以上的数字将迫使两个相同的邻居，这违反了差异要求。 

根据这一观察，最佳方法出现了：计算每个不同数字的出现次数。 如果任何数字出现两次以上，或者在阻止圆圈闭合的配置中最大值或最小值出现两次，则答案为“否”。 否则，我们可以通过首先放置严格递增的唯一数字序列直到最大值，然后将剩余的数字按降序附加回最小值来排列数字。 这保证了每个相邻对都相差一个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 使用字典计算多重集中每个不同数字的频率。 这让我们可以立即识别是否有任何数字出现两次以上。 如果是，则打印“NO”并停止。 
2. 找出最小和最大数字。 这些定义了潜在连续序列的边界。 
3. 验证序列中间的数字是否出现超过两次。 如果一个数字出现两次，则一份副本将进入递增段，另一份将进入递减段。 最小值和最大值只能出现一次，以避免在圆闭合时出现重复的邻居。 
4. 如果所有检查都通过，则打印“YES”，因为可以通过首先按升序排列数字（每个数字出现一次），然后按任何重复项的降序排列来构造有效的循环序列。 

为什么有效：该算法依赖于相邻数字必须相差一的属性。 通过先升后降的顺序排列数字，序列中的每对邻居都相差一个，违反这一点的唯一方法是数字出现两次以上或错误地出现在边界处。 通过计算频率并检查最小值和最大值，我们确保不会出现非法邻居。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import Counter

n = int(input())
a = list(map(int, input().split()))
freq = Counter(a)

# if any number appears more than twice, impossible
if any(v > 2 for v in freq.values()):
    print("NO")
    sys.exit(0)

nums = sorted(freq.keys())

# if min or max appears twice, impossible
if freq[nums[0]] == 2 or freq[nums[-1]] == 2:
    print("NO")
    sys.exit(0)

print("YES")
```该解决方案读取数组，计算频率，并立即消除数字出现两次以上或最小值/最大值出现两次的不可能情况。 对键进行排序有助于概念化“山”结构，但我们不需要显式地构造序列，因为条件保证了可行性。

## 测试用例```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    freq = Counter(a)
    if any(v > 2 for v in freq.values()):
        return "NO"
    nums = sorted(freq.keys())
    if freq[nums[0]] == 2 or freq[nums[-1]] == 2:
        return "NO"
    return "YES"

# Provided sample
assert run("4\n1 2 3 2\n") == "YES", "sample 1"

# Custom cases
assert run("3\n5 5 5\n") == "NO", "triple identical"
assert run("3\n1 2 3\n") == "YES", "simple consecutive"
assert run("5\n1 2 3 4 5\n") == "YES", "all consecutive unique"
assert run("6\n1 2 2 3 3 4\n") == "YES", "duplicates in middle"
assert run("4\n1 1 2 2\n") == "NO", "min duplicated"

 ## 边缘情况

 当所有数字都相同时，例如`5 5 5`，算法正确识别出某个数字出现两次以上并返回“NO”。 对于简单的递增序列，例如`1 2 3`，算法确认所有频率均为一，最小值和最大值仅出现一次，并输出“YES”。 对于最小值或最大值出现两次的边缘情况，例如`1 1 2 2`，算法标记不可能性，避免任何无效的循环邻接。 每个案例都通过频率检查和排序键检查直接处理，保证正确性。
