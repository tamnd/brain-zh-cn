 ## 解决方案
 ## 问题理解

 我们有一块 8 × 8 的板。 玛丽亚从左下角开始，安娜永久留在右上角，还有几个雕像占据了其他牢房。 

比赛按回合进行。 玛丽亚首先移动，然后每个雕像同时向下移动一排。 棋盘下方移动的雕像将永远消失。 

玛丽亚可以移动到 8 个相邻牢房中的任何一个，也可以留在原地。 她无法搬进目前有雕像的牢房。 她移动后，雕像向下移动。 如果任何雕像落在玛丽亚的牢房上，她就会立即失败。 如果玛丽亚到达安娜的牢房，她立即获胜。 

董事会非常小。 只有 64 个单元格，雕像以完全确定的方式移动。 最多 8 次雕像移动后，每个雕像都会从棋盘上掉落，因此游戏的危险阶段是短暂的。 这意味着我们可以直接搜索所有可到达的游戏状态。 

主要的困难是董事会随着时间的推移而变化。 现在安全的位置在雕像移动后可能会变得不安全。 仅检查当前板配置的粗心搜索将接受非法状态。 

一个微妙的边缘情况是，玛丽亚搬进一个现在空着的牢房，但在雕像移动后会立即被占用。 

例子：```
.......A
........
........
........
........
........
.S......
M.......
```正确输出：```
LOSE
```玛丽亚无法安全地向上移动，因为在雕像移动后，第 6 排的雕像将下降到她的位置。 一个天真的 BFS 只在雕像移动之前检查棋盘，会错误地认为该移动是合法的。 

当玛丽亚存活足够长的时间以至于所有雕像都消失时，另一个棘手的情况出现了。```
.......A
SSSSSSSS
........

```正确输出：```

```玛丽亚可以简单地避免危险，直到雕像从棋盘上掉下来。 之后，棋盘就永远空了，并且可以保证到达安娜。 人为地过度限制搜索深度的实现可能会错误地拒绝这种情况。 

第三个常见错误是忘记玛丽亚可能留在原地。```
.......A
........
........
........
........
........
S.......
M.......
```正确输出：```
WIN
```立即移动是危险的，但等待一转会让雕像向下移动并消失。 仅考虑 8 个方向移动的解决方案会错过有效的获胜策略。 

## 方法

 最直接的想法就是暴力模拟。 玛丽亚每次最多有 9 个选择，包括 8 个相邻单元格加上保持不动。 我们可以递归地尝试每一个可能的移动序列，同时模拟每轮雕像的移动。 

从概念上讲，这是可行的，因为棋盘很小，而且游戏的演变是确定性的。 问题在于移动序列的数量呈指数增长。 20圈后已经有大约$9^{20}$可能的路径，这是完全不可行的。 

关键的观察结果是棋盘状态仅取决于时间。 无论玛丽亚的行为如何，雕像总是以相同的方式向下移动。 由于棋盘只有 8 行，最多 8 回合后所有雕像都会消失。 

这完全改变了问题。 我们不需要探索任意长度的移动序列，我们只需要跟踪：

 1.玛丽亚目前的位置。 
2. 当前时间步长。 

每个时间步最多有 64 个可能的位置。 有意义的状态总数很小，大约$64 \times 9$。 

这自然会导致 BFS 或 DFS 优于状态$(row, col, time)$。 从一种状态开始，我们尝试所有 9 个移动，在雕像移动之前和之后检查目的地是否安全，然后继续。 

重要的见解是双重安全检查：

 1. 玛丽亚当前无法进入包含雕像的牢房。 
2. 雕像下降后，玛丽亚也不能留在包含雕像的牢房中。 

如果没有第二个条件，搜索将接受玛丽亚在移动后立即被压碎的位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(9^T) | O(9^T) | O(T)| 太慢了|
 | 状态上的最优 BFS/DFS | O(64×9×9)| O(64 × 9) | 已接受 |

 ## 算法演练

 1. 阅读最初的 8 × 8 棋盘。 
2. 存储初始配置的所有雕像位置。 
3. 定义函数`safe(r, c, t)`检查细胞是否`(r, c)`当时没有雕像`t`。 

雕像最初位于`(sr, sc)`将在`(sr + t, sc)`后`t`移动。 如果`sr + t >= 8`，那个雕像消失了。 
4.从Maria的初始位置开始BFS`(7, 0)`在某个时间`0`。 
5. 对于每个州`(r, c, t)`，首先检查当前cell是否已经处于不安全状态`t`。 

如果现在有雕像占据当前位置，则该状态无效，应跳过。 
6. 如果玛丽亚到达`(0, 7)`， 返回`"WIN"`。 
7. 尝试所有 9 种可能的操作：

 1. 朝 8 个方向之一移动。 
2. 留在原地。 
8. 对于每个候选人职位`(nr, nc)`:

 1. 忽略盘外的位置。 
2.忽略当时被雕像占据的单元格`t`。 
3、忽略当时会被占用的单元格`t + 1`。 

第二个条件阻止玛丽亚立即踏上雕像。 第三个可以防止她在雕像移动后被压碎。 
9. 推送有效的下一个状态`(nr, nc, min(t + 1, 8))`进入队列。 

我们将时间限制在 8 步，因为 8 步之后所有雕像都消失了，棋盘再也不会改变。 
10. 如果 BFS 完成但未到达 Anna，则返回`"LOSE"`。 

### 为什么它有效

 任何时刻，未来的棋盘配置完全由时间决定。 BFS 探索 Maria 在每个时间步可以占据的每个可到达的安全位置。 

仅当目标单元在雕像移动之前和之后都是安全的时，才会添加过渡。 这完全符合游戏规则。 

由于每个可能的合法移动序列都在状态图中表示，因此只要存在一条获胜路径，BFS 就会找到一条获胜路径。 如果 BFS 无法联系到 Anna，则不存在任何法律策略。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

DIRS = [
    (-1, -1), (-1, 0), (-1, 1),
    (0, -1),  (0, 0),  (0, 1),
    (1, -1),  (1, 0),  (1, 1)
]

def solve():
    board = [input().strip() for _ in range(8)]

    statues = []

    for r in range(8):
        for c in range(8):
            if board[r][c] == 'S':
                statues.append((r, c))

    def safe(r, c, t):
        for sr, sc in statues:
            nr = sr + t
            if nr < 8 and nr == r and sc == c:
                return False
        return True

    q = deque()
    q.append((7, 0, 0))

    visited = set()
    visited.add((7, 0, 0))

    while q:
        r, c, t = q.popleft()

        if not safe(r, c, t):
            continue

        if (r, c) == (0, 7):
            print("WIN")
            return

        nt = min(t + 1, 8)

        for dr, dc in DIRS:
            nr = r + dr
            nc = c + dc

            if not (0 <= nr < 8 and 0 <= nc < 8):
                continue

            if not safe(nr, nc, t):
                continue

            if not safe(nr, nc, t + 1):
                continue

            state = (nr, nc, nt)

            if state in visited:
                continue

            visited.add(state)
            q.append(state)

    print("LOSE")

solve()
```解决方案首先收集初始雕像位置。 由于雕像运动是确定性的，因此我们不需要为每个时间步显式重建棋盘。 

这`safe`函数计算单元格在给定时间是否空闲。 它不是重复模拟运动，而是直接从原始行中得出每个雕像的位置。 

BFS 状态包括时间，因为同一个董事会单元可能在某一时刻是安全的，但后来却是致命的。 治疗`(r, c)`单独访问时会错误地合并不同的游戏情况。 

安全检查的顺序很重要。 我们首先在雕像移动之前验证目的地是否空闲，然后在雕像下降后验证目的地是否仍然空闲。 缺少第二次检查是此问题中最常见的错误。 

时间限制为 8 点，因为之后所有雕像都会消失。 如果没有这个上限，BFS 可以永远继续生成等效的未来状态。
