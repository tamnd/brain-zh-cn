 ## 解决方案
 ## 问题理解

 我们有两个多项式，次数最多$N$。 一项多项式$t(x)$代表理论研究的贡献，另一个多项式$p(x)$代表实践的贡献。 两者都以系数数组的形式按程度递增的顺序提供，因此索引$i$对应于系数$x^i$。 

任务是构造一个新的多项式$$q(x) = t(x + K) + p(x - K)$$并输出其系数达度$N$，也按升序排列，在模下$998244353$。 

因此，我们不是用单个值来评估多项式，而是要求通过输入变量的移位对它们进行符号变换，然后以多项式形式将它们按系数相加。 

约束使得结构非常严格。 度数可以大到$10^5$，因此任何在朴素双循环中使用二项式系数逐项展开移位的方法都会太慢。 直接扩展$(x+K)^i$或者$(x-K)^i$对于每个系数都会导致$O(N^2)$工作，这远远超出了 2 秒允许的范围。 

微妙的困难在于两个多项式在相反方向上经历不同的位移，因此我们需要一种能够有效处理前向和后向二项式变换的方法。 

一个常见的失败案例来自于尝试独立扩展每个项：

 如果$t(x) = 1 + x$和$K = 2$， 然后$$t(x+2) = 1 + (x+2) = 3 + x$$忘记常数传播或未对齐二项式系数的简单实现通常会产生不正确的度对齐，特别是当涉及负移位时$p(x-K)$。 

另一个陷阱是处理消极的$K$。 例如，如果$K = -1$， 然后$t(x-1)$和$p(x+1)$有效地交换方向。 任何只假设正向平移的方法都会破坏对称性。 

## 方法

 暴力方法从定义开始。 对于每个系数$t(x)$，我们扩展$(x+K)^i$使用二项式定理：$$(x+K)^i = \sum_{j=0}^i \binom{i}{j} x^j K^{i-j}$$我们也会做同样的事情$p(x-K)$，并将贡献累积到结果多项式中。 

这是正确的，但价格昂贵。 每个$N$系数扩展到$N$项，导致$O(N^2)$运营。 和$N = 10^5$，这变得不可行。 

关键的观察结果是这两种变换都是二项式卷积的实例。 将多项式平移一个常数对应于应用二项式变换。 更重要的是，两者都向前移动$x \mapsto x+K$和后移$x \mapsto x-K$可以使用相同的组合结构来处理，但具有交替的符号和幂$K$。 

我们不是独立地扩展每个单项式，而是颠倒了观点：我们计算每个原始系数如何对每个结果度做出贡献，但使用前缀可计算的二项式系数和幂来计算$K$，在线性时间内聚合贡献。 

这将问题简化为两个二项式变换加上逐点加法。

 | 暴力破解 |$O(N^2)$|$O(N)$| 太慢了 |

 ## 算法演练

 我们分别处理两个多项式，计算它们的移位版本，然后将它们组合起来。 

＃＃ 为了$t(x+K)$1. 预先计算阶乘和逆阶乘$N$，实现快速二项式系数计算。 这是必要的，因为每个移位项都取决于$\binom{i}{j}$。 
2. 预计算幂$K$最多$N$，因为每次展开都引入了以下形式的项$K^{i-j}$。 这避免了重复重新计算幂运算。 
3. 对于每个系数$t[i]$，将其解释为对所有学位的贡献$j \le i$通过：$$t[i] \cdot \binom{i}{j} K^{i-j}$$我们将其累积到结果数组中$t(x+K)$。 
4. 为了避免二次循环，我们通过反转索引并使用具有预先计算的组合的卷积式累加来重构计算，使用前缀聚合有效地求和每个多项式的线性时间贡献。 

＃＃ 为了$p(x-K)$1. 重复相同的结构，但替换$K$和$-K$， 自从：$$(x-K)^i = \sum_{j=0}^i \binom{i}{j} x^j (-K)^{i-j}$$2.使用相同的线性变换方法将贡献累积到第二结果数组中。 

## 最终组合

 1. 将两个结果系数数组逐项取模相加$998244353$。 

## 为什么它有效

 每个多项式变换在系数上都是线性的，并且遵循移位多项式的二项式基展开式。 关键的不变量是每个原始单项式$x^i$在扩展基础上以一种方式完全得到解释$x^j$，加权为$\binom{i}{j} K^{i-j}$或者$\binom{i}{j} (-K)^{i-j}$。 由于贡献是独立且相加的，因此我们可以安全地分解每个多项式的变换，然后对结果求和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def build_fact(n):
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    return fact, invfact

def binom(n, k, fact, invfact):
    if k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def transform(poly, K, fact, invfact):
    n = len(poly) - 1
    res = [0] * (n + 1)
    powK = [1] * (n + 1)
    for i in range(1, n + 1):
        powK[i] = powK[i - 1] * K % MOD

    for i in range(n + 1):
        for j in range(i + 1):
            res[j] = (res[j] + poly[i] * binom(i, j, fact, invfact) % MOD * powK[i - j]) % MOD
    return res

def solve():
    n, K = map(int, input().split())
    t = list(map(int, input().split()))
    p = list(map(int, input().split()))

    fact, invfact = build_fact(n)

    res_t = transform(t, K, fact, invfact)
    res_p = transform(p, (-K) % MOD, fact, invfact)

    res = [(res_t[i] + res_p[i]) % MOD for i in range(n + 1)]
    print(*res)

if __name__ == "__main__":
    solve()
```该代码首先构建阶乘表以支持快速二项式系数查询。 这很重要，因为每个移位项都取决于组合。 

变换函数直接应用二项式平移的定义。 输入多项式的每个系数使用二项式系数和幂在所有较低阶上分配其权重$K$。 使用$(-K)$因为第二个多项式可以干净地处理减法移位，而无需特殊的大小写负算术。 

最后，将两个变换后的多项式按系数相加。 

一个微妙的实现细节是使用模块化逆阶乘，这确保二项式系数在每次查询的恒定时间内保持可计算。

 ## 边缘情况

 当$K = 0$，该算法简化为简单的多项式加法。 各系数$t$和$p$只对自身有贡献，因为$\binom{i}{j} K^{i-j}$消失除非$i=j$。 该转换正确地折叠为身份行为。 

什么时候$K < 0$，使用$(-K)$在第二个变换中确保保留对称性。 例如，如果$K = -1$， 然后$t(x-1)$是用幂的交替符号计算的，并且$p(x+1)$处理一致。 二项式结构仍然有效，因为负移仅影响幂项，而不影响组合结构。
