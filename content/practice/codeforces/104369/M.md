 ## 解决方案
 ## 问题理解

 我们给出一个凸多边形，由其顶点按逆时针顺序描述。 任务是选择两个不同的顶点并在它们之间绘制一个弦，但并非每对都被允许：弦必须实际上将多边形分割成两个区域，并且两个生成的部分仍必须具有非零面积。 该限制实际上意味着我们正在切断弦每侧多边形的非退化“帽”。 

进行这样的切割后，我们获得由沿边界的连续顶点加上所选弦形成的两个凸多边形。 对于每个生成的多边形，我们将其直径定义为其内部任意两点之间的最大欧几里得距离，对于凸多边形而言，该直径始终通过一对顶点来实现。 目标是最小化生成的两个多边形的直径平方和。 

输入大小足够小，以至于每个测试的二次或近二次解都是合理的，因为所有测试用例的顶点总数最多为 5000。这会立即排除每个测试用例最坏情况下的任何立方体，但允许 O(n^2) 或 O(n^2 log n) 全局方法。 

尝试所有顶点对并从头开始重新计算两侧直径的简单方法已经很昂贵，但真正的瓶颈是重新计算直径：对每个子多边形进行扫描会将其整体推向 O(n^3) 。 

微妙的边缘条件来自无效切割。 如果两个选定的顶点相邻，则“分割”会退化为单个多边形和线段，这违反了两个生成的多边形必须具有正面积的要求。 类似地，当线段太大时，在边界情况下仅切除一侧的两个顶点也会退化为另一侧面积为零的三角形。 具体来说，在具有循环索引的顶点的多边形中，仅当两条弧都包含至少三个顶点时，i 和 j 之间的切割才有效。 

例如，在正方形中，选择相反的顶点是可行的，但选择相邻的顶点根本不会分割多边形。 在五边形中，选择一侧仅留下两个顶点的顶点会产生退化区域，并且必须排除这种分裂。 

## 方法

 蛮力的想法很简单。 我们尝试每对顶点 i 和 j，将它们解释为弦，将多边形分成由该弦引起的两个顶点链，并通过检查其中的所有顶点对来计算每个链的直径。 由于对于大小为 k 的子多边形，每个直径计算都是 O(k^2)，因此如果直接实现，在最坏的情况下会变成 O(n^4)，这是远远不可行的。 

我们可以分两步改进这一点。 首先，我们观察到任何凸多边形的直径都是由一对顶点来实现的，因此我们只需要顶点对之间的距离，而不需要任意内部点。 其次，对于连续顶点的任何固定间隔，我们可以增量地维持其直径：当将间隔扩展一个顶点时，我们只需将新顶点与该间隔中所有先前的顶点进行比较。 

这导致了一个动态规划公式，我们为每个区间 [l, r] 预先计算其中任意一对顶点之间的最大距离。 一旦我们有了这个表，任何候选子多边形的直径都可以在 O(1) 中得到答案。 第二个子多边形也是一个连续的链，但它环绕数组，因此我们通过复制顶点序列来处理它。 

现在，问题简化为枚举所有有效弦并组合两个预先计算的间隔直径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力重新计算直径 | O(n^4) | O(n^4) | O(1) | O(1) | 太慢了 |
 | 区间DP+枚举| 每次测试 O(n^2) | O(n^2) | O(n^2) | 已接受 |

## 算法演练

 我们将多边形顶点视为长度为 n 的数组 P。 

我们还预先计算所有顶点对之间的平方欧几里德距离，因为所有直径计算都依赖于它们。 

然后，我们按间隔构建 DP 表：dp[l][r] 存储子数组 P[l..r] 内任何一对顶点之间的最大平方距离。 

1. 对所有 l 初始化 dp[l][l] = 0，因为单个点的直径贡献为零。 
2. 填充 dp 以增加间隔长度。 对于每个区间 [l, r]，我们首先结转 dp[l][r-1]，因为完全在 [l, r-1] 内的任何最佳对仍然有效。 
3. 然后我们尝试所有涉及新端点 r 的对。 对于 [l, r-1] 中的每个 i，我们计算距离(P[i], P[r]) 并用这些值中的最大值更新 dp[l][r]。 这确保了间隔中的每一对都被恰好考虑一次。 

此后，dp[l][r] 给出任何连续线段的直径平方。 

第二个挑战是切割多边形会创建环绕线段。 为了解决这个问题，我们复制该数组，形成大小为 2n 的 P'。 从 j 到 i（环绕）的任何循环段都成为 P' 中的连续段，特别是 [j, i+n]。 

现在我们枚举所有有效的弦 (i, j)，且 i < j，确保两侧至少有 3 个顶点，这意味着 j - i 至少为 2，最多为 n - 2。 

对于每个有效和弦，我们计算两个值：

 使用 dp 计算线段 [i, j] 的直径，

 以及在重复数组上使用 dp 的互补循环段的直径。 

我们在所有选择中取这两个值之和的最小值。 

关键的不变量是 dp 正确地表示每个连续区间内的最大成对距离，并且由弦产生的每个有效多边形块精确对应于原始数组或加倍数组中的一个连续区间。 由于每个可能的和弦都会被考虑一次，并且两个结果片段都会被精确评估，因此不会遗漏任何配置，也不包含无效的分割。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    def dist2(a, b):
        dx = a[0] - b[0]
        dy = a[1] - b[1]
        return dx * dx + dy * dy

    # duplicate for circular intervals
    pts2 = pts + pts

    N = 2 * n
    d = [[0] * N for _ in range(N)]

    # DP for interval diameters on doubled array
    for i in range(N):
        for j in range(i + 1, N):
            d[i][j] = dist2(pts2[i], pts2[j])

    dp = [[0] * N for _ in range(N)]

    for l in range(N - 1, -1, -1):
        for r in range(l, N):
            if l == r:
                dp[l][r] = 0
                continue
            best = dp[l][r - 1]
            pr = pts2[r]
            for i in range(l, r):
                best = max(best, d[i][r])
            dp[l][r] = best

    INF = 10**30
    ans = INF

    for i in range(n):
        for j in range(i + 1, n):
            len1 = j - i + 1
            len2 = n - (j - i)
            if len1 < 3 or len2 < 3:
                continue

            d1 = dp[i][j]
            d2 = dp[j][i + n]
            ans = min(ans, d1 + d2)

    print(ans)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该解决方案首先在 DP 转换期间隐式构建平方距离表，确保恒定时间的几何查询。 双倍数组上的 dp 表是核心结构，它允许将环绕段统一视为间隔。 

枚举循环通过检查线段长度来小心地强制切割的有效性，这是至关重要的，因为如果没有它，退化多边形将错误地贡献零或误导的直径。 

最终答案累加了两个独立计算的区间直径的最小和。

 ## 边缘情况

 当弦在一侧恰好留下两个顶点时，就会出现临界边缘情况。 在这种情况下，生成的“多边形”退化为线段并且是不允许的。 该算法通过在评估 dp 值之前检查段长度来显式处理此问题，因此此类情况永远不会进入答案计算。 

另一个微妙的情况是数组边界附近的环绕段。 如果不复制顶点列表，循环间隔将被分成两个人为的段，并且计算的直径将不正确。 通过使用双倍数组，每个有效的循环段都变成一个连续的区间，并且 dp 可以正确评估其直径，而无需特殊的套管。
