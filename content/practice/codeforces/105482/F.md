 ## 解决方案
 ## 问题理解

 我们有一个无向图`n`地点。 英雄从地点开始`1`，避难所位于位置`n`，而阿利奥斯已经占领了`k`地点。 

Alioth 的移动方式并不像单个角色。 它蔓延开来。 如果某个位置在某个时间被占用`t`，它永远被占据并开始进一步传播。 用图的术语来说，Alioth 到达某个顶点的时间就是距任何最初占据的顶点的最短距离。 

我们被允许在地点之间建造额外的隧道。 我们的目标是添加尽可能多的隧道，同时仍然允许英雄严格早于阿利奥斯到达避难所。 如果两个人同时到达某个地点，英雄就会失败。 

输入给出初始图表和受感染位置集。 输出是可以建造的新隧道的最大数量。 如果无论我们做什么都无法生存，我们必须打印`-1`。 

该图最多包含`10^5`顶点和`2·10^5`边缘。 任何试图单独推理所有可能的附加边的解决方案都会太慢，因为完整的图大致包含`n²/2`边缘。 我们需要一种可以在线性或近线性时间内检查的表征。 

最危险的边缘情况是当避难所已经邻近感染地点时。 

例子：```
4 5 1
3
1 4
3 4
4 2
1 3
3 2
```Alioth 从顶点开始`3`。 避难所是顶点`4`，并且已经有一个边缘`3-4`。 阿利奥斯一步就到达了避难所。 即使英雄使用直接边缘到达避难所，他们也需要一步，产生平局。 正确答案是：```
-1
```粗心的解决方案可能会认为添加更多边缘总是可以帮助英雄，但额外的边缘也可以帮助 Alioth。 

另一个重要的情况是避难所不靠近任何感染地点。 

例子：```
3 1 1
2
1 3
```我们可以添加边缘`1-2`，但我们不能添加边缘`2-3`。 英雄可以使用直接优势`1-3`一步就能到达，而阿利奥斯则需要两步才能到达避难所。 答案是：```
1
```## 方法

 暴力方法会尝试推断哪些缺失的边可以被添加，哪些必须保持缺失。 最多有$$\frac{n(n-1)}2$$可能的边，大约是`5·10^9`什么时候`n = 10^5`。 即使迭代所有潜在的边也是不可能的。 

关键的观察是英雄只需要一条安全路线。 由于我们可以自由添加隧道，因此最佳路线是显而易见的：连接`1`直接到`n`如果该边尚不存在，则一举移动。 

英雄在时间开始`0`在顶点`1`并按时到达避难所`1`。 

为了使这个计划发挥作用，阿利奥斯必须到达顶点`n`严格在时间之后`1`。 由于 Alioth 通过最短路径传播，这意味着从每个受感染顶点到`n`必须至少是`2`。 

什么可以让 Alioth 达到`n`一步到位？ 恰好是受感染顶点和`n`。 

这立即给出了最优图的整个结构。 

如果受感染的顶点已连接到`n`在最初的图表中，无论我们稍后添加什么，Alioth 都会一步到达避难所。 生存是不可能的，所以答案是`-1`。 

否则，我们可以添加每个缺失的边，除了那些直接连接受感染顶点的边`n`。 

这些禁边是唯一能够缩短阿利奥斯到达避难所时间的区域，至少`2`准确地`1`。 

让`k`是受感染顶点的数量。 在完整的图中有$$\frac{n(n-1)}2$$边缘。 我们必须准确排除`k`边缘，即`(infected, n)`。 

所以有效的最终图中的最大边数是$$\frac{n(n-1)}2 - k.$$由于该图已经包含`m`边，附加隧道的最大数量为$$\frac{n(n-1)}2 - k - m.$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n²) | 太慢了 |
 | 最佳 | O(m + k) | O(n) | 已接受 |

 ## 算法演练

 1. 读取被感染的顶点并将其标记在布尔数组中。 
2. 读取所有现有边。 
3. 读取边缘时，检查一个端点是否为避难所`n`并且另一个端点被感染。 
4. 如果存在这样的边缘，则打印`-1`。 

阿利奥斯已经一步就可以到达避难所了。 英雄不可能严格地早于这个时间到达。 
5. 否则计算$$\text{complete} = \frac{n(n-1)}2.$$6. 最终的图可能包含除`k`受感染顶点和避难所之间的边。 
7. 新隧道的最大数量等于$$\text{complete} - k - m.$$8. 打印该值。 

### 为什么它有效

 如果受感染的顶点与避难所相邻，阿利奥斯会及时到达避难所`1`。 从英雄起始位置出发的任何路线都需要至少移动一步，因此英雄的最佳到达时间也是`1`。 条件很严格，生存是不可能的。 

假设没有受感染的顶点与避难所相邻。 构造一个包含除`k`禁边`(infected, n)`。 

英雄们直接从`1`到`n`一步之遥。 

阿利奥斯无法到达`n`一步完成，因为从受感染顶点到每条边`n`缺席。 因此阿利奥斯到达`n`不早于时间`2`。 

英雄准时到来`1`，这严格来说是更早的。 

任何不属于该形式的附加边`(infected, n)`不会减少阿利奥斯抵达下方避难所的时间`2`，因此可以安全地添加所有此类边。 该图是最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
infected = list(map(int, input().split()))

bad = [False] * (n + 1)
for v in infected:
    bad[v] = True

impossible = False

for _ in range(m):
    u, v = map(int, input().split())

    if u == n and bad[v]:
        impossible = True
    if v == n and bad[u]:
        impossible = True

if impossible:
    print(-1)
else:
    total_edges = n * (n - 1) // 2
    answer = total_edges - k - m
    print(answer)
```第一部分将所有受感染的顶点存储在布尔数组中，因此成员资格检查是恒定时间的。 

在读取边缘时，我们只关心一个条件：避难所是否已经与受感染的顶点相邻。 不需要图遍历。 

如果存在这样的边缘，答案是立即`-1`。 

否则，我们计算完整图的大小并减去`k`将受感染顶点连接到避难所的永久禁止边。 该图已经包含`m`边，所以剩余的计数正是仍然可以建造的隧道的数量。 

所有算术都使用 64 位大小的值。 在Python中，整数是无界的，因此不存在溢出风险。 的最大值`n(n-1)/2`是关于`5·10^9`，无论如何都很舒服。

 ## 边缘情况

 再考虑一下：```
4 5 1
3
1 4
3 4
4 2
1 3
3 2
```避难所是顶点`4`。 自缘`3-4`已经存在且顶点`3`被感染后，阿利奥斯及时到达避难所`1`。 

英雄不能比时间做得更好`1`，因为任何运动都需要至少一次边遍历。 

该算法在扫描输入时检测受感染的避难所边缘并立即返回：```
-1
```现在考虑：```
3 1 1
2
1 3
```没有感染者庇护所边缘。 该算法计算：```
complete = 3
forbidden = 1
existing = 1
answer = 1
```英雄们使用的是直接路线`1 -> 3`一步之遥。 阿里奥必须先走`2 -> 1 -> 3`，这需要两个步骤。 满足严格的不等式，因此输出是正确的。
