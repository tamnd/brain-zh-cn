[CF 323A - 黑白立方体](https://codeforces.com/problemset/problem/323/A)

 **求解时间：** 1m 57s

 ## 解决方案
 ## 问题理解

 我们被要求使用黑色和白色两种颜色，并具有特定的局部邻居条件，为尺寸为 _k_ × _k_ × _k_ 的较大立方体内的每个小立方体着色。 每个小立方体必须恰好有两个相同颜色的相邻立方体。 邻居被定义为共享一个面的立方体，因此每个内部立方体最多有六个邻居，而边缘立方体和角立方体的邻居较少。 

输入是一个整数 _k_，即立方体的边长。 输出要么是 _k_ 层的序列，显示哪些小立方体是黑色或白色，或者如果不存在满足相邻条件的颜色，则输出为 -1。 每层都表示为 _k_ × _k_ 矩阵。 

对 _k_ 的约束最多为 100。由于立方体总数随着 _k³_ 增长，任何在恒定时间内单独检查每个立方体的算法都是可以接受的，因为 100³ = 1,000,000 是可行的。 然而，尝试所有可能的着色的简单方法将涉及 2^(k3) 种可能性，这是一个天文数字，因此不可能使用蛮力。 

边缘情况在这里很微妙。 例如，当 _k_ = 1 时，没有解，因为单个立方体不能有两个相同颜色的邻居。 对于_k_ = 2，每个立方体最多只有三个邻居，因此也不可能满足确切的两个邻居要求。 这些较小的 _k_ 值需要明确的推理。 当 _k_ ≥ 3 时，立方体具有足够的内部结构来潜在地满足约束。 

## 方法

 暴力方法会尝试将黑色或白色分配给每个立方体，然后检查所有邻居计数。 原则上这是可行的，因为它可以正确验证邻居条件，但其时间复杂度为 O(2^(k3) × k3)，即使对于较小的 k，这也是完全不可行的。 

关键的见解是注意邻居的排列方式。 每个立方体需要恰好两个相同颜色的邻居。 如果着色是在条纹层中完成的，则可以实现这一点：沿一个轴交替颜色，同时沿其他两个轴保持一致的图案。 一个简单而正确的模式是二维的“棋盘”，跨层延伸。 对于 _k_ ≥ 3，存在一种构造，其中层中的每个立方体在其层中都有两个相同颜色的邻居，并且垂直堆叠确保满足要求。 对于 _k_ = 1 或 2，不存在这样的模式，因为立方体太小而无法满足二邻域条件。 

通过在每一层中仔细选择二维交替图案，并在每一层中重复，我们可以保证每个立方体恰好看到两个相同颜色的邻居，满足约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(k3) × k3) | O(2^(k3) × k3) | O(k³) | 太慢了 |
 | 建设性模式| O(k³) | O(k³) | 已接受 |

 ## 算法演练

 1. 从输入中读取整数_k_。 立即检查是否 _k_ < 3。如果是，则打印 -1，因为大小为 1 或 2 的立方体无法满足二邻条件并终止。 
2. 初始化一个大小为 _k_ × _k_ × _k_ 的 3D 数组来存储每个立方体的颜色。 我们将逐层填充这个数组。 
3. 对于 z 从 0 到 k-1 索引的每一层，构造一个 2D _k_ × _k_ 矩阵。 使用以下公式交替棋盘图案中的颜色：if (x + y + z) % 2 == 0, 分配 'w'（白色）； 否则，分配“b”（黑色）。 这里，x和y是层中的行索引和列索引。 额外的 + z 确保垂直方向的立方体也满足邻居条件。 
4. 构建完所有层后，连续打印它们。 每层由k行k个字符组成，多余的空行可以忽略。

工作原理：棋盘图案确保在任何平面中，每个立方体都恰好有两个相同颜色的邻居，并且通过沿 z 轴移动图案，垂直邻居也满足精确两个要求。 不变量是每个立方体都被两个相同颜色的立方体包围，满足问题条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

k = int(input())

if k < 3:
    print(-1)
    sys.exit()

for z in range(k):
    for x in range(k):
        row = []
        for y in range(k):
            if (x + y + z) % 2 == 0:
                row.append('w')
            else:
                row.append('b')
        print(''.join(row))
```代码的每一部分都直接对应于算法。 早期检查 k < 3 可以处理无法解决的小情况。 嵌套循环遍历每一层和每个单元格，根据坐标总和分配颜色。 模数确保颜色交替。 打印是逐行完成的。

 ## 边缘情况

 当 k = 1 时，算法立即返回 -1。 立方体不能有两个邻居，因此该解决方案是正确的。 对于 k = 2，检查也会触发 -1； 每个立方体最多有三个邻居，因此不存在精确的二解。 当 k ≥ 3 时，算法以 3D 棋盘图案分配颜色，这保证每个立方体的两个邻居具有相同的颜色。 k = 3 的执行确认内部立方体、边缘立方体和角立方体都满足邻居要求。
