 ## 解决方案
 ## 问题理解

 我们给出一个正整数序列，都在 1 到 7 之间，并且序列的长度可以被 3 整除。 Xenia 希望将此序列划分为每组三个数字的组，以便在每个组中，数字严格增加，并且每个数字除下一个数字。 输出是这些三元组的列表，如果不存在这样的分区，则输出为 -1。 

约束告诉我们 n 可以大到 99999，这排除了尝试序列中所有可能的三元组的任何算法，因为这将涉及一次选择 n 个元素的组合（三个）并检查整除性，从而导致大约 n3 次操作。 由于当 n 接近 10⁵ 时，n3 的数量级为 1015，因此这是完全不可行的。 我们需要一种线性或至多 O(n) 的方法。 

之所以会出现不明显的边缘情况，是因为并非 1 到 7 之间的所有数字都可以在有效的三元组中共存。 例如，三个 1 不能形成三元组，因为 1,1,1 不是严格递增的。 类似地，像 5 这样的数字不能出现在任何三元组中，因为不存在仅使用数字 1-7 以 5 结尾的 a 除 b 除 c 形式的序列。 另一个棘手的情况是计数不匹配：如果 2 多于 1，则无法为所有 2 形成三元组 1,2,x。 

一个具体的失败示例是输入`6\n1 1 1 2 2 2`。 1和2不能组合起来满足严格递增和整除条件，因此正确的输出是-1。 

## 方法

 蛮力方法是生成三个元素的所有组合，并检查条件 a<b<c 以及 a 除 b 除 c 是否成立。 对于每个有效的三元组，我们将元素标记为已使用并继续，直到所有元素都分组。 这种方法原则上是正确的，但它涉及一次选择三个 n 元素的组合，即 O(n3)，对于 n 高达 10⁵ 来说太慢了。 

关键的观察结果是数字被限制在 1-7 的范围内。 这使得不同数字的总数非常小。 我们可以计算每个数字的出现次数，然后尝试仅从有效序列中组装三元组。 通过列出满足约束 (1,2,4)、(1,2,6)、(1,3,6) 的所有可能的三元组，我们看到只有这些组合可以出现。 如果任何数字的计数与这些三元组所需的计数不匹配，则不可能找到解决方案。 

因此，最佳方法是贪婪计数方法：计算 1 到 7 的出现次数，检查计数是否允许形成所需的三元组，然后使用计数输出三元组。 这将复杂度降低到 O(n)，因为我们只需要遍历列表一次来计数，然后输出三元组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 计数+贪心| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算从 1 到 7 的每个整数在序列中出现的次数。 我们将其存储在一个数组中`cnt`在哪里`cnt[i]`表示数字 i 的计数。 
2. 检查不可能的数字。 如果出现任何不属于有效三元组的数字，例如 5 或 7，我们可以立即返回 -1。 
3. 根据可行的三元组验证计数。 唯一有效的三元组是 (1,2,4)、(1,2,6) 和 (1,3,6)。 1 的计数总和必须等于 n/3，并且每个 1 必须恰好使用一次。 同样，计数 2、3、4 和 6 必须满足三元组隐含的关系：

 - 每个 2 都是 (1,2,4) 或 (1,2,6) 的一部分。 
- 每个 3 必须与 (1,3,6) 中的 6 配对。 
- 4 和 6 的计数必须足以涵盖所有三胞胎。 
- 5和7无效。 
4. 使用贪婪方法构造三元组。 首先使用以下方法形成尽可能多的 (1,2,4) 三元组`min(cnt[1], cnt[2], cnt[4])`，然后与剩余的 1、2 和 6 形成 (1,2,6) 三元组，然后与剩余的 1、3 和 6 形成 (1,3,6) 三元组。 
5. 如果在形成三元组后任何计数仍不为零，则返回 -1。 否则，输出所有三元组。 

不变的是，在每一步中，我们只用可用的数字形成一个有效的三元组，确保每个数字只使用一次。 由于计数完全确定了分区是否存在，因此保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

cnt = [0] * 8
for x in a:
    cnt[x] += 1

# impossible numbers
if cnt[5] > 0 or cnt[7] > 0:
    print(-1)
    sys.exit()

triplets = []

# form (1,2,4) as much as possible
k = min(cnt[1], cnt[2], cnt[4])
for _ in range(k):
    triplets.append((1,2,4))
    cnt[1] -= 1
    cnt[2] -= 1
    cnt[4] -= 1

# form (1,2,6)
k = min(cnt[1], cnt[2], cnt[6])
for _ in range(k):
    triplets.append((1,2,6))
    cnt[1] -= 1
    cnt[2] -= 1
    cnt[6] -= 1

# form (1,3,6)
k = min(cnt[1], cnt[3], cnt[6])
for _ in range(k):
    triplets.append((1,3,6))
    cnt[1] -= 1
    cnt[3] -= 1
    cnt[6] -= 1

# if any leftover numbers, impossible
if sum(cnt) != 0:
    print(-1)
else:
    for t in triplets:
        print(*t)
```第一部分计算出现次数并立即拒绝任何无效数字。 贪心步骤确保我们以有效的序列形成三元组，而不会留下剩余部分。 检查剩余计数的总和可确认没有未分配的数字。
