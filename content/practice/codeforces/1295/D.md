 ## 解决方案
 ## 问题理解

 我们正在与固定数量的人合作$a$和一个类似模数的界限$m$。 对于每个整数移位$x$在范围内$[0, m-1]$，我们看一下数字$a + x$并将其最大公约数与$m$相对于原始值$\gcd(a, m)$。 任务是计算有多少个班次准确地保留了该 gcd 值。 

更具体地说，想象一下滑动一个整数窗口，从$a$并将其移动所有可能的偏移量小于$m$。 对于每个转变，我们计算数字与$m$就共享素因数而言。 我们想知道这种对齐方式保持不变的频率是多少。 

限制很大：两者$a$和$m$可以达到$10^{10}$，并且最多有 50 个测试用例。 任何迭代所有的解决方案$x$是不可能的，因为它需要最多$10^{10}$每个测试用例的操作。 这立即排除了对所有班次的强力枚举。 

当出现微妙的边缘情况时$a$与以下所有素因数共享或不共享任何素因数$m$。 例如，当$a$互质于$m$，gcd 始终为 1，并且许多移位可能会保留这一点。 相反，当$a$共享一个大的gcd$m$，转移很容易破坏共享的可分性，并且关于“随机稳定性”的天真的推理失败了。 

第二个微妙之处是 gcd 仅取决于素因子重叠，而不取决于大小。 所以尽管$a+x$连续变化，仅当被素数整除时，gcd 行为才会变化$m$变化。 

## 方法

 暴力方法检查每一个$x$从 0 到$m-1$，计算$\gcd(a+x, m)$，并将其与$\gcd(a, m)$。 这是简单且正确的，但它需要$O(m \log m)$每个测试用例。 自从$m$可以是$10^{10}$，这远远超出了可行的限度。 

关键的观察是，该条件仅取决于$m$划分$a+x$。 让$g = \gcd(a, m)$。 我们想要：$$\gcd(a + x, m) = g.$$这相当于要求：

 1. 的每个素因数$g$仍须分$a+x$。 
2. 没有额外的素因数$m/g$允许分割$a+x$。 

让我们重写$m = g \cdot m'$， 在哪里$\gcd(g, m') = 1$。 那么我们需要：$$\gcd(a+x, m') = 1.$$这是因为所有共同的因素$g$已经通过构造固定了，任何额外的共享因素都将来自$m'$，必须完全避免。 

所以问题归结为计算整数$a+x$在区间内$[a, a+m-1]$使得它们与$m'$。 自从转移以来$a$不改变周期结构，而是计算整数$y$在完整的残差系统模中$m'$与 互质$m'$，适当重复。 

关键的简化是有效值$x$与数字完全对应$a+x$与 互质$m'$。 在任何完整的剩余循环模$m'$，互质残基的数量是$\varphi(m')$。 由于区间长度正好是$m$，即$g \cdot m'$，每个残基类模$m'$准确地出现$g$次。 因此答案就变成了：$$g \cdot \varphi(m').$$我们计算$g = \gcd(a, m)$， 放$m' = m / g$， 因素$m'$，计算欧拉 totient，然后相乘。

 | ---| ---| ---| ---|
 | 蛮力 |$O(m \log m)$|$O(1)$| 太慢了|
 | 最佳 |$O(\sqrt{m})$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 1. 计算$g = \gcd(a, m)$。 

这隔离了部分$m$已经保证可以分割$a$，在对比下将保持稳定。 
2. 定义$m' = m / g$。 

这会删除目标 gcd 已经“解释”的所有质因数。 
3. 将条件简化为计数$a+x$这样$\gcd(a+x, m') = 1$。 

这是因为匹配完整的 gcd 需要避免任何超出范围的额外共享因素$g$。 
4.因素$m'$使用试除法最多$\sqrt{m'}$。 

计算欧拉 totient 需要每个质因数。 
5. 计算欧拉 totient：$$\varphi(m') = m' \cdot \prod_{p \mid m'} \left(1 - \frac{1}{p}\right)$$每个不同的素数恰好删除了能被它整除的数字的分数。 
6. 返回最终答案为：$$g \cdot \varphi(m').$$乘以$g$反映每个有效的残基类模$m'$完全重复$g$整个长度间隔内的次数$m$。 

### 为什么它有效

 关键的不变量是 gcd 条件仅取决于是否$a+x$引入任何新的素因数$m'$。 一旦我们删除共享部分$g$，其余条件变为纯互质$m'$。 在完整的周期内取模$m'$，互质残基由欧拉总数精确计数，区间结构保证了这些残基的均匀重复。 这确保了不依赖于具体值$a$，仅在其 gcd 上$m$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def phi(n: int) -> int:
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

def solve():
    t = int(input())
    for _ in range(t):
        a, m = map(int, input().split())
        g = 0
        import math
        g = math.gcd(a, m)

        m_prime = m // g
        print(g * phi(m_prime))

if __name__ == "__main__":
    solve()
```该解决方案首先提取之间的稳定 gcd 分量$a$和$m$，然后将问题简化为纯互质计数$m'$。 总计算是通过试除法使用标准素因数分解来实现的，这在约束下是足够的$m \le 10^{10}$。 

一个微妙的点是我们从不枚举$x$。 所有结构都是通过模块化周期性和乘法计数来捕获的，这完全避免了对大范围的依赖。

```我们计算$g = \gcd(4, 9) = 1$， 所以$m' = 9$。 

现在我们计算$\varphi(9)$。 主要因素是$3$， 所以：$$\varphi(9) = 9 \cdot (1 - 1/3) = 6.$$最终答案是$1 \cdot 6 = 6$。

 ## 边缘情况

 一种边缘情况是当$a$与 互质$m$。 例如$a = 7, m = 11$。 然后$g = 1$，所以答案就变成了$\varphi(11) = 10$。 该算法正确地计算了完整余数系统中除 11 的单个倍数之外的所有数字。 

另一个边缘情况是当$a$共享大部分因素$m$。 为了$a = 10, m = 20$，我们得到$g = 10$,$m' = 2$， 和$\varphi(2) = 1$。 结果变为 10，与只有一个模 2 的残基类有贡献这一事实相符，在该时间间隔内重复 10 次。 

最后一个边缘情况是$m$是素数。 然后$g$是 1 或$m$，但自从$a < m$，我们总是得到$g = 1$，答案是$m - 1$，匹配仅素数的倍数被排除在互质残基之外的事实。
