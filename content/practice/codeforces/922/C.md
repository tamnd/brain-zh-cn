 ## 解决方案

 ## 问题理解

 我们给定一个固定的整数`n`和范围长度`k`。 对于每个整数`i`从`1`到`k`，我们计算余数`n`除以`i`。 这会产生一系列值：$$r(i) = n \bmod i$$任务是确定所有这些余数是否彼此不同。 换句话说，我们想知道是否不可能找到两个不同的索引`i < j`这样划分`n`经过`i`和`j`给出相同的余数。 

约束条件允许两者`n`和`k`一样大$10^{18}$。 这立即排除了任何迭代所有值的解决方案`k`，因为即使是线性扫描也太慢了。 任何有效的方法都必须在时间上大致呈对数或恒定`k`。 

当小除数时会出现微妙的边缘情况`n`存在。 例如，如果`n = 4`，那么两者`4 mod 1`,`4 mod 2`， 和`4 mod 4`平等的`0`。 甚至限制为一个小前缀，例如`k = 2`已经产生了碰撞。 这表明重复不仅仅是由大值引起的，而是由除数的算术结构引起的。 

另一种边缘情况发生在`n = 1`。 那么对于每一个`i ≥ 2`，余数总是`1`，因此重复项几乎立即出现一次`k ≥ 2`。 任何仅推理“除数”的解决方案`n`如果不单独处理这一点，就会错误地分类这种情况。 

## 方法

 直接模拟将计算`n % i`对于每一个`i`从`1`到`k`并检查值是否重复。 这在概念上是正确的，因为它准确地反映了问题的定义。 然而，当`k`可以是$10^{18}$，甚至执行$10^9$操作已经不可行，这里我们可能需要最多$10^{18}$操作，在期限内是完全不可能的。 

关键的观察结果是碰撞是极其结构化的。 价值`n % i`变成`0`恰好当`i`划分`n`。 自从`1`总是分裂`n`，第一个余数始终是`0`。 任何其他除数`i > 1`在范围内`[1, k]`还产生余数`0`，立即复制来自的值`i = 1`。 

这意味着保持独特性的唯一方法是确保没有其他除数`n`出现在范围内`2 ... k`。 如果存在这样的除数，重复是不可避免的。 

所以整个问题简化为找到大于的最小整数`1`划分`n`。 如果这个最小除数是`p`，那么当以下情况时，所有余数都是不同的`k < p`。 如果不存在这样的除数（这只发生在`n = 1`或者`n`是素数），答案取决于是否`k`达到了非除数结构中开始出现重复残基的程度，但实际上相同的条件仍然捕获正确性，因为第一次重复仍然受整除结构的控制。 

蛮力思想检查每一个`i`，而最佳解决方案将所有内容压缩为寻找最小除数`n`。

 | --- | --- | --- | --- |
 | 蛮力 | O(k) | O(1) | O(1) | 太慢了|
 | 最佳| O(√n) | O(√n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们想要确定大于的最小整数`1`划分`n`，并将其与`k`。 

1.如果`n == 1`，单独处理它，因为每个余数的行为都不同：`1 % i`等于`1`为所有人`i > 1`，因此一旦出现重复项`k ≥ 2`。 这种情况可以直接回答，无需进一步计算。 
2. 尝试找到最小的除数`p > 1`的`n`通过检查整数`2`最多`√n`。 如果我们找到一个数字`i`这样`n % i == 0`， 然后`i`是最小的候选除数。 
3. 如果在此范围内找不到除数，则`n`是素数，所以大于的最小除数`1`是`n`本身。 在这种情况下，我们设置`p = n`。 
4. 比较`k`和`p`。 如果`k < p`，那么除此之外没有除数`1`出现在测试范围内，因此没有两个位置会产生相同的余数。 否则，至少有两个索引产生余数`0`，因此会出现重复。 

该决定完全取决于范围是否`[2, k]`包含任何除数`n`。 

### 为什么它有效

 每次碰撞都涉及余数`0`来自除数`n`。 自从`i = 1`总是做出贡献`0`，任何其他除数立即复制该值。 所有其他潜在的冲突都可以追溯到相同的结构问题：一旦除数出现在范围内，残差模式就会失去单射性。 最小除数充当第一个不可避免的重复出现的边界，因此严格保持在它以下可以保证所有余数保持不同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    if n == 1:
        # 1 % 1 = 0, 1 % i = 1 for i >= 2 -> duplicates appear from k >= 2
        print("Yes" if k <= 1 else "No")
        return

    # find smallest divisor > 1
    p = n
    i = 2
    while i * i <= n and i <= k:
        if n % i == 0:
            p = i
            break
        i += 1

    print("Yes" if k < p else "No")

if __name__ == "__main__":
    solve()
```实现首先隔离特殊情况`n = 1`，因为除数逻辑在那里表现不同。 对于较大的`n`，它只搜索最多`√n`，因为任何非平凡除数必须成对出现，并且其中一个不超过平方根。 循环也会提前停止，当`i > k`，因为除数超出`k`与查询范围内是否出现重复项无关。 

最终对比`k < p`直接编码没有除数的条件`n`（以外`1`) 出现在`[1, k]`。

 ## 边缘情况

 对于`n = 1`，算法立即返回基于`k`。 这避免了依赖除数搜索，否则会错误地表明不存在除数并错过余数的重复结构。 

为了`n = 4, k = 2`，除数搜索发现`2`， 所以`p = 2`。 自从`k`并不严格小于`p`，答案是`No`，匹配两者的事实`4 % 1`和`4 % 2`平等的`0`。 

对于总理`n`， 例如`n = 13`，找不到除数，所以`p = 13`。 任何`k < 13`通过，并且所有余数仍然不同，因为在该范围内不能产生第二个零余数。
