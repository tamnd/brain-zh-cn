 ## 解决方案
 ## 问题理解

 我们得到一串小写字母，我们将其解释为奇怪的“poman”数字系统中的数字。 每个字母对应于 2 的幂，其中`a`是 2^0 = 1，`b`是 2^1 = 2，`c`是 2^2 = 4，依此类推直到`z`= 2^25。 对于较长的字符串，该值是递归定义的：我们可以在任意位置拆分字符串，并将该值定义为第一部分加上第二部分的负数。 形式上，如果字符串的长度大于 1，我们选择一个索引`m`(1 ≤ m < n) 并将值计算为`-f(S[1..m]) + f(S[m+1..n])`。 目标是确定我们是否可以在每一步选择分割，以便最终结果等于给定的整数`T`。 

输入约束允许最多 10^5 个字母和最大 10^15 的目标值。 这排除了尝试所有可能的递归拆分的任何解决方案，因为拆分方式的数量随着字符串长度呈指数增长。 我们需要一个能够在线性或线性时间内计算最终答案的解决方案。 

出现不明显的边缘情况是因为该操作允许对任何前缀的和取反。 例如，第一个和最后一个字母具有 2 的大幂或所有字母都相同的字符串可能会误导天真的方法。 如果我们忽略最后一个字母只能做出积极贡献的事实，我们可能会错误地认为可以实现某些负总数。 一个具体的例子是字符串`ba`有目标`-1`。 第一个字母`b`= 2 和第二个字母`a`= 1. 正确的分割产量`-b + a = -2 + 1 = -1`，这是可以实现的，但是不考虑符号而粗心地对所有值求和将会失败。 

## 方法

 暴力解决方案是递归地尝试每个可能的分割，计算左右段的值，并查看是否有任何组合产生`T`。 这种方法是正确的，因为它详尽地探索了所有操作序列。 然而，分割的数量与字符串的长度呈指数关系。 对于一个长度的字符串`n`， 有`2^(n-1)`插入分割的方法，使得这种方法对于 n = 10^5 不可行。 

关键的观察结果是，每个运算都简化为与字母相对应的 2 次方的加法和减法的组合。 因为只有最后两个字母以特定顺序“强制”符号化，所以我们可以计算所有字母幂的总和，然后减去除最后两个字母之外的所有字母之和的两倍，以说明它们在递归应用程序中的固定位置。 这将问题简化为简单的算术检查：我们将所有字母的幂相加，适当减去最后两个，然后看看差异是否可以匹配`T`。 按幂降序对内部字母进行排序并将它们视为灵活的加法/减法允许我们使用简单的总和检查。

 ## 算法演练

 1. 将字符串中的每个字母转换为其对应的 2 的幂。 为了一封信`c`, 计算`2^(ord(c) - ord('a'))`。 将它们存储在数组中`vals`。 这会将字符串转换为数字贡献。 
2. 请注意，字符串的最后一个字母在最终计算中始终会产生正向贡献，倒数第二个字母始终会产生负向贡献。 调整目标`T`考虑到这两个贡献：减去最后一个值`T`，然后添加倒数第二个值。 这确保我们只需要检查剩余的字母。 
3. 计算除最后两个值之外的所有值的总和。 这是在递归分割中可以自由求反或相加的数字总数。 将该总和表示为`S`。 
4. 问题归结为检查我们是否可以对剩余字母进行划分，使得在选择符号后它们的总和等于调整后的字母`T`。 因为每个数都是2的幂，所以带有任意±号的数之和可以达到任意整数`-S`到`S`具有相同的奇偶性`S`。 因此，充分必要条件是`S >= |T_adjusted|`还有那个`(S - T_adjusted)`是均匀的。 
5. 如果这些条件成立，则打印“Yes”； 否则，打印“否”。 

为什么有效：递归拆分操作只会否定前缀并添加剩余的后缀。 这相当于为除最后两个字母之外的所有字母选择±符号，其贡献是固定的。 2 的幂和具有以下性质：如果奇偶校验对齐，则可以实现负总和与正总和之间的任何整数，因此简单的算术检查捕获所有可能的分割序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, T = map(int, input().split())
S = input().strip()

vals = [1 << (ord(c) - ord('a')) for c in S]

# Adjust target by last two letters
T_adjusted = T - vals[-1] + vals[-2]

# Sum of remaining letters
S_sum = sum(vals[:-2])

# Check if we can reach T_adjusted with ± signs
if S_sum >= abs(T_adjusted) and (S_sum - T_adjusted) % 2 == 0:
    print("Yes")
else:
    print("No")
```第一行使用有效地读取输入`sys.stdin.readline`。 第二行将字母转换为 2 的幂。 目标调整考虑了最后两个字母的强制贡献。 剩余字母的总和形成了自由符号分配的池。 最终检查确保满足幅度和奇偶校验条件； 任何一个失败都意味着目标无法实现。

 ## 边缘情况

 对于尽可能最小的字符串，`n = 2`， 输入`ba`和目标`-1`，算法计算`vals = [2,1]`，将目标调整为`0`，剩余字母的总和是`2`，检查通过和输出 是。 对于所有字母都相同的字符串，例如，`aaaa`和目标`0`，内部字母之和为2，调整目标为0，检查通过，输出Yes。 对于超过所有字母贡献总和的目标，检查将按预期失败。 该算法始终考虑最后两个字母的固定贡献，并使用 ± 符号的灵活性来处理其余字母，正确处理所有边缘情况。
