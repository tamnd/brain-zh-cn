 ## 解决方案
 ## 问题理解

 问题提出了一个数字时钟，显示一个整数$n$数字。 每个数字的范围从 0 到 9，并且显示包含前导零，因此数字始终具有长度$n$。 目标是通过尽可能少的操作将这个数字减少到零。 允许两种操作：将数字减 1 或交换显示中的任意两位数字。 

输入由多个测试用例组成。 每个测试用例给出$n$、位数以及表示当前时钟值的数字串。 每个测试用例的输出是一个整数：达到零的最小操作数。 

限制很温和：每个测试用例最多 100 个数字，最多 1000 个测试用例。 如果数字很小，则单独递减每个数字是可行的，但对于多位数的数字，我们需要利用交换来最小化递减。 当时钟已经显示为零时，就会出现边缘情况 - 不需要任何操作。 当数字中埋有零时，会出现另一种微妙的情况。 例如，给定`1000`，交换领先的`1`与朴素的递减相比，最后一个零大大减少了递减的数量`1000`下降到`0`。 

## 方法

 暴力方法考虑了所有交换和递减序列。 对于一个数字$n$数字，可以尝试每一种可能的交换配置以最小化递减的数量。 这种方法是正确的，因为它最终会找到以最少的步骤产生零的操作序列。 然而，其复杂性取决于$n$，使其不可行$n$最多 100 个。具体来说，交换次数为$O(n^2)$并且减量可能高达$10^n$，所以蛮力显然太慢了。 

关键的观察结果是，唯一与递减有关的数字是数字中的最后一个非零数字。 所有其他数字都可以交换到个位中，以更有效地减少数字。 实际中，我们只需要统计有多少个非零数字以及最右边的非零数字在哪里。 每个非零数字贡献一个减量，其中之一除外，在将其移动到最低有效位置后将减少到零。 交换次数计算为不在最后位置的非零数字的数量。 

因此，最佳方法是：计算非零数字的总数，如果最后一位非零则减一，然后加上需要交换的位数以将非零数字带入最后一个位置。 这将问题简化为简单的计数，而不是探索每个交换序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * 10^n) | O(n! * 10^n) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和表示时钟值的字符串。 
2. 如果数字已经全为零，则输出 0 并继续。 
3. 计算字符串中非零数字的总数。 这些数字中的每一个都需要至少一次操作：递减或交换+递减。 
4. 识别字符串中的最后一位数字。 如果它非零，则所有其他非零数字的递减需要交换以首先将它们移出最后一个位置。 所需的最小交换次数是除最右边的非零之外的非零数字的数量。 
5. 将总操作计算为以下总和：所需的交换次数加上将所有非零数字减少到零的递减总数。 
6. 打印测试用例的总操作。 

为什么有效：每个非零数字最终必须减少到零，要么直接递减，要么在交换到最低有效位置之后。 通过计算非零数字并调整最​​后一位数字，我们确保不会浪费任何操作。 该策略保证尽可能少的操作，因为仅在必要时才使用交换将非零数字带到最后一个位置以实现有效的递减。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        if s.count('0') == n:
            print(0)
            continue
        
        non_zero_count = sum(1 for ch in s if ch != '0')
        # Check if last digit is zero
        if s[-1] != '0':
            # All other non-zero digits except last require a swap
            swaps_needed = non_zero_count - 1
        else:
            # Last digit is zero, all non-zero digits need to be swapped somewhere
            swaps_needed = non_zero_count
        
        print(swaps_needed)

solve()
```该代码首先读取测试用例的数量并循环遍历每个测试用例。 它检查字符串是否全为零，如果是，则立即打印 0。 计算非零数字，并根据最后一位数字的位置计算交换。 使用`sum(1 for ch in s if ch != '0')`有效地计算非零数字。 该解决方案在计算交换时小心地避免差一错误，尤其是当最后一位数字非零时。 

## 工作示例

 输入样本`007`:

 | s | 非零计数 | 最后一位数字 | 需要交换 | 输出|
 | --- | --- | --- | --- | --- |
 | 007| 1 | 7 | 0 | 7 |

 说明：唯一的非零数字是`7`在最后一个位置。 无需交换； 执行 7 次递减。 

输入样本`1000`:

 | s | 非零计数 | 最后一位数字 | 需要交换 | 输出|
 | --- | --- | --- | --- | --- |
 | 1000 | 1000 1 | 0 | 1 | 2 |

 解释：非零`1`不在最后一个位置，因此一次交换将其移动到末尾，然后一次递减将其设置为零。 总共 2 次操作。

 ## 边缘情况

 当所有数字都为零时，例如输入`0000`，算法立即输出 0，无需进行不必要的计算。 当最后一位数字非零时，例如`007`，最后一位数字仅有助于递减且无交换，从而提供最少的操作。 对于像这样的数字`1000`，前导非零需要交换以将其移动到最低有效数字以进行递减。 该算法可以正确处理长度为 1、100 的字符串以及具有许多零交错的数字，因为它始终计算非零数字并根据最后一位数字位置调整交换。
