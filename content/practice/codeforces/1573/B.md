 ## 解决方案
 ## 问题理解

 我们有两个长度的数组$n$，其中数组$a$包含所有奇数$1$到$2n$按某种顺序和数组$b$包含来自的所有偶数$1$到$2n$按某种顺序。 我们的目标是制作数组$a$按字典顺序小于数组$b$通过重复交换单个数组中的相邻元素。 我们需要确定此类交换的最小数量。 

因为数组$a$只有奇数和数组$b$仅偶数，最终的字典比较取决于最小元素的相对位置。 如果最小的奇数在$a$位于最小偶数之前$b$,$a$已经更小了。 否则，需要交换来移动小元素$a$朝向前方和大元素$b$向后。 

约束条件意味着$n$可以大到$10^5$和总和$n$所有测试用例不超过$10^5$。 这排除了比以下更糟糕的算法$O(n \log n)$每个测试用例，因为直接模拟交换的简单方法是$O(n^2)$而且太慢了。 边缘情况包括数组最初按降序排序或$n=1$，这很简单，因为单个元素会自动按字典顺序变小或变大。 

粗心的方法可能会尝试从左到右贪婪地模拟交换，而无法有效地跟踪头寸。 例如，给定$a = [3,1]$和$b = [4,2]$，只需交换前两个元素$a$产生$[1,3]$，它立即小于$b$。 如果不仔细推理仓位，可能会过多计算掉期次数或错过最佳序列。 

## 方法

 暴力方法是模拟两个数组中所有可能的相邻交换，直到$a < b$。 每次交换、计数操作后我们都会检查字典顺序。 这是正确的，但速度非常慢，因为每次交换都会稍微改变数组，并且有$O(n^2)$可能的交换序列。 为了$n = 10^5$，这导致$O(n^2) \approx 10^{10}$操作，这远远超出了一秒钟可以运行的范围。 

关键的见解来自于认识到每次交换都会将元素移动一个位置。 如果我们将每个数字映射到数组的排序版本中的目标位置，则将该数字移动到正确位置的最小交换次数相当于计算当前在其前面有多少个较小的元素（对于$b$）或更大（对于$a$）。 这将问题简化为计算独立排序两个数组的最小交换次数，这可以使用坐标压缩技术和 Fenwick 树或通过两指针计数来完成。 

自从$a$包含所有奇数并且$b$所有偶数，为了方便起见，我们可以将它们标准化为从 0 开始的范围：$a_i' = (a_i - 1)/2$,$b_i' = b_i/2 - 1$。 然后我们跟踪元素的位置$a'$和$b'$并计算最小交换次数，以升序排列它们。 最佳策略是移动较小的元素$a$向前和更大的元素$b$落后。 使用两指针扫描，我们可以计算$O(n \log n)$最小总互换量。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 映射每个元素$a$和$b$到从 0 开始的排名：$a$，减去 1 再除以 2，对于$b$，除以 2 并减 1。这给出了两个从 0 到$n-1$。 此步骤将问题归一化为简单的索引排列。 
2.记录每个元素的位置$a$和$b$。 让$posa[x]$是元素的当前索引$x$在$a$， 和$posb[x]$在$b$。 这允许恒定时间查找每个数字的位置。 
3. 构建前缀最小数组$b$：对于每个索引$i$，跟踪移动所有较小元素所需的最小交换次数$b$向左转。 同样，执行此操作$a$反过来计算将较大元素向右移动的交换次数。 这将问题转化为单调两指针遍历。 
4.初始化两个指针：一个扫描$a$从左到右再扫描一次$b$从右到左。 维护每一方所需的交换的运行计数。 在每个位置，计算最小总交换量作为交换的总和$a$并交换为$b$。 
5. 输出扫描期间发现的最小总交换量。 

不变的是，在每个考虑的分割点之后，它之前的所有元素都在$a$小于它之后的所有元素$b$。 通过使用两个指针扫描并累积每个元素的最小交换，我们保证找到全局最小值，因为数组是排列，并且每个移动的每个相邻交换的成本为 1。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        a_pos = [0]*n
        b_pos = [0]*n
        for i, val in enumerate(a):
            a_pos[(val-1)//2] = i
        for i, val in enumerate(b):
            b_pos[val//2 - 1] = i
        
        a_swaps = [0]*n
        b_swaps = [0]*n
        
        for i in range(n):
            if i == 0:
                a_swaps[i] = a_pos[i]
                b_swaps[i] = n-1 - b_pos[i]
            else:
                a_swaps[i] = min(a_swaps[i-1], a_pos[i]-i)
                b_swaps[i] = min(b_swaps[i-1], b_pos[i]-i)
        
        res = n*2
        j = 0
        for i in range(n):
            while j < n and b_pos[j] - j + a_swaps[i] >= res:
                j += 1
            res = min(res, a_swaps[i] + b_pos[j]-j if j<n else a_swaps[i])
        print(res)

if __name__ == "__main__":
    solve()
```该代码首先规范化数组索引以便于操作。 它构建了`a_pos`和`b_pos`快速找到元素位置，然后预先计算所有元素的最小交换。 两指针方法扫描数组以找到最小化总交换的分割点。 计算时需要小心避免差一错误`a_pos`和`b_pos`正常化后。
