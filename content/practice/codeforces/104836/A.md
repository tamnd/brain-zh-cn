 ## 解决方案
 ## 问题理解

 我们被赋予了一个标准$n \times n$棋盘，左上角的方块为黑色，颜色在水平和垂直方向上完美交替。 这将创建通常的棋盘图案。 任务是确定有多少个正方形的大小$1 \times 1$是白色的。 

电路板尺寸由单个整数控制$n$。 输出只是这种交替模式中白细胞的计数。 

这些限制很重要，因为$n$可以大到$10^9$。 任何尝试构建网格或迭代所有单元格的解决方案都是立即不可能的。 完整的模拟需要$n^2$操作，达到$10^{18}$在最坏的情况下，即使对于$n \le 10^3$。 

当尝试显式地为行着色并逐行计算白色单元格时，会出现一个天真的陷阱。 例如，对于$n = 4$，人们可能会尝试构建网格：

 输入：```
4
```简单的模拟将填充 16 个单元格、交替颜色并计算白色。 这适用于小$n$，但同样的逻辑对于$n = 10^9$，其中内存或时间中不存在明确的构造。 

另一个微妙的边缘情况是奇数尺寸的板。 例如：

 输入：```
3
```输出：```
4
```一个天真的假设是一半的细胞总是白色的$4.5$，这没有意义。 奇偶校验结构很重要。 

## 方法

 蛮力方法是迭代每个单元格$(i, j)$，根据奇偶校验判断是否为白，并增加一个计数器。 如果单元格的坐标总和与左上角的黑色单元格具有相反的奇偶性，则该单元格为白色。 由于黑色开始于$(1,1)$，其中有总和$2$，当细胞为白色时$(i + j)$很奇怪。 

这个方法是正确的，因为它直接编码了着色规则。 然而，它需要$n^2$检查。 什么时候$n = 10^9$，这变成了$10^{18}$的操作，这是完全不可行的。 

关键的观察结果是，棋盘是完全周期性的。 每个 2 x 2 块恰好包含两个白色单元格和两个黑色单元格。 这消除了任何迭代的需要。 我们不需要单独计算单元格，而是只需要计算存在多少个完整的行和列对，以及剩余的行和列在以下情况下的表现：$n$很奇怪。 

如果$n$是均匀的，板子分成$2 \times 2$块，每个块恰好贡献 2 个白细胞。 如果$n$为奇数时，有额外的部分行和列保留交替结构，相对于偶数情况总共添加一个额外的白色单元格。 

这直接导致基于整数除法的封闭式表达式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 观察每个单元格的颜色仅取决于其坐标的奇偶性。 当给定起始配置下坐标和为奇数时，会出现白色单元格。 这消除了任何模拟的需要。 
2.将板子分割成完整的$2 \times 2$块。 每个这样的块恰好包含 2 个白细胞。 完整块的数量为$(n // 2)^2$。 这捕获了所有完全配对的结构。 
3.处理剩余的行和列$n$很奇怪。 如果有最后一行或最后一列，它们会按照交替模式提供额外的单元格，从而准确地产生$\lfloor n^2 / 2 \rfloor$整体白细胞。 
4. 将最终答案计算为整数除法$n \cdot n // 2$，它自然地处理偶数和奇数情况而无需分支。 

### 为什么它有效

 着色导致网格的严格奇偶分区：每个单元恰好属于基于以下两个类别之一：$(i + j) \bmod 2$。 因为网格以黑色单元格开始$(1,1)$，白色单元对应于均匀分布在网格上的奇偶校验类别之一。 在任何矩形区域上，奇偶校验都是完美交替的，当该区域为奇数时，最多只能有一个单元出现不平衡。 这保证了正好有一半的单元格（向下舍入）是白色的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
print((n * n) // 2)
```该解决方案完全依赖于棋盘的奇偶结构。 表达式$n * n$计算细胞总数。 使用整数除法除以 2 会通过向下舍入自动处理偶数和奇数情况，这与白细胞的精确计数相匹配。 

一个微妙的点是 Python 整数可以安全地处理大值，所以即使当$n = 10^9$, 计算$n^2$仍然有效。 在具有固定宽度整数的语言中，需要确保 64 位算术以避免溢出。

 ## 边缘情况

 对于$n = 1$，网格有一个黑色单元格。 公式给出$1 // 2 = 0$，这与不存在白细胞的事实相符。 即使在这种退化的情况下，奇偶校验论证仍然成立。 

对于奇数$n$， 例如$n = 5$，网格包含$25$细胞。 公式给出$12$，而天真的“一半是 12.5”是不正确的。 缺失的半单元通过地板来解决，这对应于奇数大小的正方形中奇偶校验类的精确分布。 

对于大型$n$， 例如$10^9$，没有发生结构变化。 计算仍然是单个乘法和除法，证实组合结构完全取代了任何几何推理。
