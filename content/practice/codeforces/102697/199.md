 ## 解决方案
 ## 问题理解

 该设施由一个`n × m`网格。 一个单元格包含`X`是一堵墙，而`.`是可步行的空地并且`P`是一个包含飞机的可步行单元。 仅允许在水平或垂直相邻单元格之间移动，因此禁止对角线移动。 房间实际上是细胞的连接区域，而不是墙壁。 由于团队可能只选择一个房间，所以答案是最大的房间数`P`属于可行走细胞的任何单个连接组件的细胞。 已发表的声明证实了飞机单元本身可以被遍历，这正是使得`P`表现得像`.`用于连接目的。 

该声明没有公布明确的界限`n`和`m`，但网格正好有`n × m`单元格，时间限制为 1 秒，内存为 256 MB。 因此，解决方案应该避免重复扫描整个网格。 线性或近线性地穿过细胞是自然目标。 一个`O((nm)^2)`一旦网格包含许多可步行的单元，解决方案就会变得昂贵，而`O(nm)`遍历对每个单元格进行固定次数。 

第一个边缘情况是一架飞机。 对于输入```
1 1
P
```正确的输出是`1`。 一个粗心的实现，只从`.`尽管声明明确允许穿过飞机，但细胞永远不会访问飞机`P`细胞。 

第二个边缘情况是由墙壁隔开的多架飞机：```
1 3
PXP
```正确的输出是`1`。 两架飞机位于不同的房间，因为中间的牢房是一堵无法逾越的墙。 计算整个网格中的每架飞机将错误地返回`2`。 

第三种边缘情况是飞机可以属于同一个房间，即使它们不相邻：```
3 3
P..
.X.
..P
```正确的输出是`2`。 两个都`P`单元通过墙壁周围的可行走单元连接。 仅当飞机直接接触时才对飞机进行分组的方法会错误地返回`1`。 

最后，边界上的细胞需要与内部细胞完全相同的处理。 为了```
2 2
PP
XX
```答案是`2`。 遍历必须在访问邻居之前检查边界，否则从第一行向上移动或从第二行向下移动可能会导致无效访问或意外地在索引行为允许的语言中回绕。 

## 方法

 一个直接但低效的解决方案是从每个飞机单元开始图搜索。 对于每个`P`，我们可以通过每个可到达的可步行单元运行 BFS 或 DFS 并计算遇到的飞机数量。 这是正确的，因为从起始飞机可到达的每个房间正是其连接的组件，因此搜索给出了该房间中的飞机数量。 

问题是许多起始飞机可以属于同一个大房间。 如果网格有`N = nm`单元格，几乎所有单元格都是可步行的包含飞机或空的单元格，一次搜索就可以触及`Θ(N)`细胞，并且可以有`Θ(N)`启动飞机。 因此最坏的情况是`Θ(N²) = Θ((nm)²)`细胞访问。 在考虑邻居检查之前，拥有 10,000 个单元的网格已经可以导致大约 1 亿次单元访问。 

暴力方法之所以有效，是因为遍历正确地识别了一个房间，但它重复解决了相同的连接组件问题。 关键的观察结果是连接的组件划分了所有可行走的单元。 一旦一次搜索完全探索了一个房间，该房间中的每个单元都已经被分类，因此没有理由再次探索它。 

我们可以通过扫描一次网格来利用这一点。 每当我们遇到未访问的非壁单元时，我们都会从它开始 BFS 或 DFS。 在遍历过程中，我们计算每一个`P`遭遇。 当遍历结束时，我们得到了该房间中飞机的确切数量，因此我们更新全局最大值。 每个可步行单元都被访问一次，从而给出网格单元数量的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O((nm)²)`|`O(nm)`| 太慢了 |
 | 最佳|`O(nm)`|`O(nm)`| 已接受 |

 ## 算法演练

 1. 读取网格并创建一个已访问的结构，其中每个单元格都有一个条目。 不需要穿过墙，但保持所访问的结构为矩形使得邻居处理变得简单。 
2. 从上到下、从左到右扫描每个单元格。 如果单元格是墙或已被访问过，请跳过它，因为它无法开始新房间。 
3. 当发现未访问的可步行单元时，从该单元启动 BFS 并立即将其标记为已访问。 起始单元格可以是`.`或者`P`，因为两者都是可步行的并且属于相同的连接图。 
4.维护当前房间的柜台。 每当 BFS 删除一个时就增加它`P`从队列中取出单元，或者等同于第一次发现单元时。 
5. 对于每个访问过的单元，检查其四个正交邻居。 如果邻居位于网格之外、是墙或者已经被访问过，则忽略该邻居。 每个剩余的邻居都属于同一个房间，因此将其标记为已访问并将其添加到 BFS 队列中。 
6. 当 BFS 队列变空时，整个连接组件已被探索过。 将其飞机数量与目前找到的最大值进行比较，保留较大的值。 
7. 继续外部扫描，直到考虑了每个网格单元。 存储的最大值是任何单个房间中包含的最大飞机数量，因此将其输出。 

### 为什么它有效

 不变的是，每当 BFS 启动时，其起始单元都属于以前未探索过的连接组件，并且 BFS 恰好访问该组件中的每个可步行单元。 因为单元在被发现时就被标记为已访问，所以单元不能被处理两次。 每一个`P`因此，该组件中的内容只被计算一次，而每个`P`组件之外的内容被排除。 由于外部扫描为每个先前未探索的组件启动 BFS，因此每个房间都被仅考虑一次。 因此，对这些组件进行最大计数可以为游览提供最佳的空间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]
    best = 0

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    for r in range(n):
        for c in range(m):
            if grid[r][c] == 'X' or visited[r][c]:
                continue

            queue = [(r, c)]
            visited[r][c] = True
            head = 0
            aircraft = 0

            while head < len(queue):
                cr, cc = queue[head]
                head += 1

                if grid[cr][cc] == 'P':
                    aircraft += 1

                for dr, dc in directions:
                    nr = cr + dr
                    nc = cc + dc

                    if not (0 <= nr < n and 0 <= nc < m):
                        continue
                    if visited[nr][nc] or grid[nr][nc] == 'X':
                        continue

                    visited[nr][nc] = True
                    queue.append((nr, nc))

            best = max(best, aircraft)

    print(best)

if __name__ == "__main__":
    solve()
```外部双循环实现步骤 2 和 7 中描述的组件发现。如果单元格是墙壁或已分配给先前探索的房间，则该单元格将被忽略。 

队列存储属于当前BFS的信元。 整数`head`指向下一个要处理的单元格，因此该实现避免了重复从 Python 列表的前面删除。 删除与`pop(0)`将移动所有剩余元素，并可能使遍历变得不必要的昂贵。 

当单元被添加到队列中而不是被删除时，它被标记为已访问。 这可以防止同一单元通过不同的相邻单元多次插入。 

四个方向对准确地代表了允许的运动。 边界检查在索引之前执行`grid[nr][nc]`，它安全地处理边界单元。 没有特殊情况`P`，因为飞机单元是可步行的，因此与空单元参与相同的 BFS。 

Python 整数具有任意精度，因此在计算飞机时不存在整数溢出问题。 最大计数最多为`n × m`。

 | 起始区域 | 遭遇飞机| 计数| 最佳|
 | ---| ---| ---| ---|
 | 左上区域|`(1,3)`| 1 | 1 |

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(nm)`| 每个细胞都经过外部扫描检查，每个可行走细胞都被 BFS 处理一次。 |
 | 空间|`O(nm)`| 访问矩阵和 BFS 队列可以分别包含`O(nm)`细胞。 |

 线性复杂度是合适的，因为输入本身包含`nm`网格字符，因此读取网格已经需要`O(nm)`时间。 该算法仅对每个单元执行恒定量的额外工作，因此避免了暴力方法的重复搜索。 256 MB 内存限制对于此问题支持的典型网格大小的网格、访问矩阵和队列来说足够了。 发布的声明给出了 1 秒的时间限制和 256 MB 的内存限制，尽管它没有明确指定`n`和`m`界限。

 ## 边缘情况

 对于单细胞情况```
1 1
P
```外部扫描看到`(0,0)`作为一个未访问的可步行单元并启动 BFS。 该单元被标记为已访问，飞机计数器变为`1`，队列变空。 全局最大变化从`0`到`1`，所以输出是`1`。 不需要对单细胞网格进行单独处理。 

对于断开连接的情况```
1 3
PXP
```第一个`P`启动一个仅包含其自身的组件，产生一个计数`1`。 中间`X`被跳过。 决赛`P`启动另一个单细胞组件，也生产`1`。 最大剩余量`1`。 一个简单计算每个的解决方案`P`不尊重墙壁会错误地返回`2`。 

对于连接但不相邻的情况```
3 3
P..
.X.
..P
```第一个 BFS 从左上角开始`P`。 它在周围移动`.`细胞并最终到达右下角`P`。 两架飞机在同一次遍历中都被计数，给出`2`。 由中央墙引起的对角线分离并不重要，因为它周围有一条正交路径。 

对于边界情况```
2 2
PP
XX
```BFS 开始于`(0,0)`，达到`(0,1)`，然后通过边界检查拒绝向上、向左和超出范围的邻居。 两人`P`细胞计数为一种成分，给出`2`。 该算法从不尝试访问网格之外的负行或列。 

对于大连通情况，每个单元格都是`P`，所以第一个 BFS 到达所有`n × m`细胞并对每架飞机进行一次计数。 每个后续的外循环位置都已被标记为已访问，因此不会启动额外的 BFS。 这是背后的关键行为`O(nm)`边界：即使在最密集的可步行区域，每个单元也仅进入队列一次。
