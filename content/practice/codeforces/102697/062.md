 ## 解决方案
 ## 问题理解

 该任务是一个直接的字符串过滤问题。 我们有一个字符串`S`，然后是一个集合`C`包含必须消失的字符。 每一次出现在`S`中列出的字符的`C`必须删除，而所有其他字符必须保持完全相同的相对顺序。 输出是所有此类删除后的结果字符串。 官方问题给出了例子`howdy`， 和`w`和`y`禁止, 生产`hod`。 

已发布的问题页面给出了 1 秒的时间限制和 256 MB 的内存，但它没有公开明确的长度限制`S`或为了`N`。 这意味着安全的解释是避免运行时间将字符串长度乘以要删除的字符数的算法。 输入的线性扫描是自然目标，因为每个字符都必须至少检查一次以确定它是否存活。 

主要的边缘情况来自这样一个事实：删除规则适用于每次出现，而不仅仅是第一次出现。 例如，使用输入```
banana
1
a
```正确的输出是```
bnn
```粗心的实现只删除了一次`a`会错误地离开`bnana`或者`banan`。 

另一种边界情况是不需要删除任何字符的情况。 有输入```
abc
0
```正确的输出是```
abc
```没有删除字符，因此必须准确保留原始字符串。 假设整数后面至少有一个字符的实现`N`可能会在这里失败。 

相反的情况是每个字符都属于删除集。 有输入```
abc
3
a
b
c
```正确的输出是空字符串。 正确构建结果但忘记打印终止换行符的解决方案仍然可以被大多数法官接受，但假设结果非空的解决方案可能会失败或意外保留字符。 

如果不信任输入来强制执行唯一性，则重复删除字符是另一个可能的实现陷阱。 例如，```
aaa
2
a
a
```仍然应该产生一个空字符串。 删除集中的成员资格应被视为布尔属性，因此插入相同的字符两次不会产生额外的效果。 

## 方法

 一个简单的暴力解决方案可以处理每个字符`S`并且，对于每一个，扫描整个删除列表，直到找到匹配项。 这是正确的，因为当一个字符没有出现在`C`。 如果`|S| = n`和`N`提供了字符，最坏的情况执行`nN`会员资格比较。 两个值都在附近`10^5`，这大约是`10^10`比较，远远超出了1秒的限制所能支持的。 

暴力破解之所以有效，是因为它直接检查删除的定义，但不需要重复搜索。 关键的观察是，成员资格是我们需要问的唯一问题`C`。 我们不关心某个字符在删除列表中出现的位置或出现了多少次。 我们可以将所有删除字符放入一个集合中，从而进行成员资格测试`O(1)`。 然后从左到右扫描一次`S`就足够了。 

对于中的每个字符`S`，我们检查它是否属于删除集。 如果是这样，我们就跳过它。 否则，我们将其附加到答案中。 由于字符是从左到右处理的，并且只跳过不需要的字符，因此剩余的字符会自动保留其原始顺序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(|S|N)| O(N) | 在最坏的情况下太慢|
 | 最佳 | O( | S | + N) 预期 | O(N + | S | ) | 已接受 |

 ## 算法演练

 1.读取原字符串`S`，然后阅读`N`和下一个`N`人物。 将这些字符存储在一个名为的集合中`deleted`。 集合为我们提供了直接的成员资格测试，而不是重复扫描删除列表。 
2. 创建一个空列表`answer`。 使用列表优于重复连接 Python 字符串，因为重复的字符串连接可能会导致不必要的复制。 
3. 扫描每个字符`ch`的`S`从左到右。 如果`ch`是在`deleted`，忽略它。 否则，附加`ch`到`answer`。 该决定仅取决于该角色是否被禁止，因此不需要有关早期位置的信息。 
4. 连接剩余的字符并打印结果字符串。 如果删除每个字符，则列表为空并且`''.join(answer)`正确生成空字符串。 

### 为什么它有效

 扫描过程中的不变式是`answer`完全包含已处理的前缀中的字符`S`那些不在`deleted`，按其原始顺序。 当下一个字符属于`deleted`，省略它正是所需的操作。 当它不属于`deleted`，保留它是强制性的，因为只能删除删除集中的字符。 因此，在每个字符之后以及在处理整个字符串之后，不变量仍然为真，`answer`正是所需的最终字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().rstrip('\n')
    n = int(input())
    deleted = {input().strip() for _ in range(n)}

    answer = [ch for ch in s if ch not in deleted]
    print(''.join(answer))

if __name__ == "__main__":
    solve()
```第一行读取将被过滤的字符串。`rstrip('\n')`仅删除行结尾，因此不会意外丢弃字符串中的其他字符。 

集合理解读取全部`N`删除字符并将它们存储在`deleted`。 该问题将它们描述为不同的字符，但使用集合也可以自然地处理意外重复。 

列表理解实现了算法演练中的扫描。 每个未出现的角色`deleted`被保留。 由于 Python 按顺序迭代字符串，因此结果列表已经具有正确的顺序。 

最后，`join`在一次操作中构造输出字符串。 没有索引计算，因此没有需要管理的相差一边界。 Python 整数也具有任意精度，尽管这个问题不需要足够大的算术来导致溢出问题。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |

 该算法对每个输入字符执行恒定量的预期工作，并且不包含字符串和删除列表上的嵌套循环。 由于官方限制仅为 1 秒，因此这种线性方法是合适的选择，特别是因为已发布的声明没有提供证明二次处理合理的小显式界限。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    s = input().rstrip('\n')
    n = int(input())
    deleted = {input().strip() for _ in range(n)}
    answer = [ch for ch in s if ch not in deleted]
    print(''.join(answer))

def run(inp: str) -> str:
    global input

    old_stdin = sys.stdin
    old_input = input

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    out = io.StringIO()
    old_stdout = sys.stdout
    sys.stdout = out

    try:
        solve()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout
        input = old_input

    return out.getvalue()

# Provided sample
assert run("""howdy
2
w
y
""") == "hod\n", "sample 1"

# Minimum-size string, one character deleted
assert run("""a
1
a
""") == "\n", "single character deleted"

# No characters are deleted
assert run("""abc
0
""") == "abc\n", "empty deletion set"

# All characters are deleted
assert run("""abcabc
3
a
b
c
""") == "\n", "all characters deleted"

# Repeated occurrences and alternating survivors
assert run("""banana
1
a
""") == "bnn\n", "repeated deleted characters"

# Boundary case where only the first and last characters survive
assert run("""xabcy
3
a
b
c
""") == "xy\n", "boundary characters"

# Large input to exercise linear behavior
large_s = "ab" * 50000
large_input = large_s + "\n1\nb\n"
assert run(large_input) == ("a" * 50000) + "\n", "large input"

 ## 边缘情况

 对于空删除集，确切的输入是```
abc
0
```套装`deleted`为空，因此每个成员资格测试都会返回 false。 扫描附加`a`,`b`， 和`c`, 生产`abc`。 该算法不需要特殊情况`N = 0`，这避免了引入不必要的边界逻辑。 

对于重复出现的已删除字符，请考虑```
banana
1
a
```套装是`{a}`。 扫描删除第二个、第四个和第六个字符，同时保留`b`,`n`， 和`n`, 生产`bnn`。 该决定是针对每个位置做出的，因此算法不会在第一次匹配出现后意外停止。 

要完全删除，请考虑```
abc
3
a
b
c
```每次会员测试都成功，所以`answer`在整个扫描过程中保持空白。 连接空列表会得到空字符串，这正是所需的输出。 不需要单独的空输出分支。 

对于在边界幸存的角色，请考虑```
xabcy
3
a
b
c
```第一个字符`x`被保留，中间的字符`a`,`b`， 和`c`被删除，最后的`y`被保留。 结果是`xy`。 由于该算法处理第一个和最后一个位置的方式与处理其他位置完全相同，因此不存在特殊的第一个字符或最后一个字符相差一个的情况。 

对于大输入，请考虑由以下组成的字符串`ab`仅重复 50,000 次`b`已删除。 100,000 个字符中的每一个字符都会被检查一次，并且每次设置的查找都需要恒定的时间。 结果正好包含 50,000`a`字符，演示了为什么算法线性缩放而不是通过删除列表搜索每个字符。
