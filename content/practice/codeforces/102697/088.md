 ## 解决方案
 ## 问题理解

 同位素包含与该问题相关的两种粒子：质子和中子。 它的质量数同时计算它们，所以

 [
 m = p + n，
 ]

 其中 (p) 是质子数，(n) 是中子数，(m) 是质量数。 

输入给出 (p) 和 (m)，其中 (p \le m)。 所需的输出是中子数。 重新排列定义立即给出

 [
 n = m - p。 
]

 已发布的声明指定了一秒的时间限制和 256 MB 的内存，但没有给出超出 (p \le m) 的两个整数的限制性上限。 计算本身是恒定的时间和恒定的额外空间，因此整数的大小是唯一的实际考虑因素。 Python的整数支持任意精度，因此在实现中不存在固定宽度溢出问题。 

主要的边缘情况是平等。 例如，使用输入`5 5`，质量数由五个质子组成，没有中子，所以正确的输出是`0`。 如果规定的条件允许相等，则假设答案必须为正的粗心解决方案将在此边界上失败，因为该语句将结果描述为正整数。 

另一种边界情况是只有一个中子时。 有输入`92 93`，正确的输出是`1`。 减法必须按正确的顺序进行，因为`p - m`会产生`-1`即使中子数为正。 

## 方法

 强力解释是以某种方式搜索可能的中子数量，并检查所得的总数是否与质量数匹配。 例如，我们可以尝试 (n=0,1,2,\ldots) 直到 (p+n=m)。 这是正确的，因为质量数的定义准确地告诉我们候选中子计数何时有效。 然而，在最坏的情况下，它可以执行 (m-p+1) 次迭代，这是不必要的工作，并且会变得任意大，因为该语句没有强加一个小的数值界限。 

问题的结构使得这种搜索变得不必要。 定义质量数的方程已经直接包含所需的值。 由于 (m=p+n)，从已知总数中减去已知的质子数就得到了中子数。 暴力破解之所以有效，是因为它会搜索满足方程的值，但会失败，因为它忽略了方程可以通过一次运算进行代数求解。 观察到这些量形成一个简单的和，将整个问题简化为一个减法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(m-p)) | (O(1)) | (O(1)) | 不必要的缓慢 |
 | 最佳 | (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取质子数 (p) 和质量数 (m)。 这是重建同位素中子计数所需的两个量。 
2. 计算 (m-p)。 质量数包含每个质子和每个中子，因此除去所有 (p) 质子就只剩下中子。 
3. 打印结果。 不需要额外的处理、搜索或数据结构。 

关键的不变量是定义 (m=p+n)。 在我们计算 (m-p) 时，我们正在用代数方法从总质量数中去除已知的质子贡献。 因此，剩余值恰好是 (n)，因此打印的答案不能代表除所需中子计数之外的任何内容。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

p, m = map(int, input().split())
print(m - p)
```第一行从唯一的输入行读取两个整数。`map(int, ...)`将它们转换为 Python 整数，这也避免了对固定宽度整数溢出的担忧。 

减法直接来自算法的第二步。 它被故意写成`m - p`， 不是`p - m`，因为质量数是总数，质子数是被移除的部分。 

没有循环，也没有辅助数据结构。 该程序执行一项输入操作、一项算术操作和一项输出操作。 

## 工作示例

 对于样品 1，同位素有 92 个质子，质量数为 238。 

| （页）| (男)| (m-p)| 输出|
 | ---| ---| ---| ---|
 | 92 | 92 238 | 238 146 | 146 146 | 146

 方程为(238=92+n)，因此(n=146)。 减法直接恢复中子计数。 

对于样品 2，同位素有 36 个质子，质量数为 85。 

| （页）| (男)| (m-p)| 输出|
 | ---| ---| ---| ---|
 | 36 | 36 85 | 85 49 | 49 49 | 49

 再次，(85=36+n)，给出(n=49)。 无需任何特殊处理即可应用相同的不变量。

## 边缘情况

 当质子数等于质量数时，不存在中子。 对于准确的输入```
5 5
```该算法读取 (p=5) 和 (m=5)、计算 (5-5=0) 并打印```
0
```这捕获了一个错误的假设，即答案必须严格为正。 算术定义允许只要 (p=m) 就有零中子。 

当只有一个中子时，考虑```
92 93
```该算法计算 (93-92=1) 并打印```
1
```这捕获了常见的操作数顺序错误。 质量数是总量，因此它必须是被减数。 

对于大输入，例如```
1000000000000000000 1000000000000000000
```同样的计算得出零。 Python 准确地表示这些整数，并且程序不会根据它们的大小进行循环。 因此结果是```
0
```对于大中子数，```
123456789 1000000000
```计算结果是

 [
 1{,}000{,}000{,}000-123{,}456{,}789=876{,}543{,}211,
 ]

 所以输出是```
876543211
```这证实了该解决方案通过定义方程而不是通过枚举来处理整个问题。
