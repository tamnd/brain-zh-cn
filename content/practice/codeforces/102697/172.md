 ## 解决方案
 ## 问题理解

 有(n)个人。 人 (i) 有外套颜色和靴子颜色。 在战斗中，当两个人的外套颜色和靴子颜色不同时，人（i）向人（j）扔了一个雪球。 一个人永远不会向自己扔东西。 

任务是计算所有这样的有序对 ((i,j))。 方向很重要：如果人（i）可以向人（j）投掷，则贡献一个雪球，如果也可以的话，反向投掷单独计算。 

输入给出人数，然后是按匹配顺序排列的 (n) 件外套颜色和 (n) 件靴子颜色。 输出是抛出的雪球总数。 

已发布的问题页面给出了 1 秒的时间限制和 256 MB 的内存，但没有公开 (n) 的明确上限。 这使得 (O(n^2)) 解决方案不安全，因为自然强力方法会检查每个有序对。 (O(n)) 解决方案更可取，并且仅使用频率信息，因此即使 (n) 很大，其性能也保持良好。 

第一个边缘情况是一个人。```
1
red
blue
```答案是`0`。 没有其他人可以扔。 一个简单地计算具有不同属性的人的公式必须小心，不要计算人本身。 

当每个人都有相同的外套颜色但不同的靴子时，就会出现第二种边缘情况。```
3
red red red
blue green yellow
```答案是`0`。 每对都穿着同样的外套，所以没有人是有效的目标。 仅检查靴子颜色的粗心解决方案会错误地计算所有六个有序对。 

相反的情况同样重要。```
3
red green blue
black black black
```答案是`0`，因为每双都共用相同的靴子。 这两个条件都是必须的。 

最后，人们可以共享这两种属性。```
3
red red blue
black black green
```唯一有效的有序对位于`red/black`组和`blue/green`人、给予`2`。 如果我们单独减去共享外套的人和共享靴子的人而不校正重叠，则共享这两种属性的一对人将被减去两次。 

## 方法

 直接方法考虑每对有序的不同人。 对于每一对，比较他们的外套颜色和靴子颜色，当两种颜色不同时，在答案中精确地添加一个。 这是正确的，因为每个可能的抛出恰好对应于一个有序对，并且每个有效的有序对恰好贡献一个抛出。 

有 (n(n-1)) 个有序对，因此暴力解决方案执行 (\Theta(n^2)) 个对检查。 例如，(n=100000) 意味着 (9,999,900,000) 次检查，远远超出一秒解决方案可以合理执行的范围。 

有用的观察是，我们实际上并不关心哪个特定的人有颜色。 对于固定的人 (i)，假设他们的外套颜色出现 (C_i) 次，靴子​​颜色出现 (B_i) 次，外套和靴子的精确组合出现 (P_i) 次。 

在所有（n）个可能的目标中，（C_i）有相同的外套，（B_i）有相同的靴子。 我们想删除这两个组。 拥有相同外套和相同靴子的人被删除了两次，所以我们将它们添加回来一次。 因此，人 (i) 的有效目标数量为

 [
 n-C_i-B_i+P_i。 
]

 此公式已正确处理该人自己的输入。 它们属于所有三个频率组，因此它们的贡献是

 [
 1-1-1+1=0。 
]

 我们可以通过哈希图一次性获得所有三个频率，然后对每个人的公式求和。 暴力破解之所以有效，是因为它显式地测试了每个可能的目标，但由于存在平方数，所以会失败。 频率观察使我们能够计算整个人的所有有效目标，而无需单独检查这些目标。 

等效的全局推导使用包含-排除。 从 (n(n-1)) 种可能的投掷开始，减去共享外套的有序对，减去共享靴子的有序对，然后添加回共享两者的有序对。 如果一种颜色出现 (k) 次，它会创建 (k(k-1)) 有序的不同人对。 按人计算的公式更容易实施，因为所有所需的频率都可以立即使用。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^2)) | (O(1)) | (O(1)) | 对于大 (n) 来说太慢 |
 | 最佳| (O(n)) 预期 | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 读取人数、外套颜色和靴子颜色。 同一索引处的三条信息描述一个人，因此我们在计算频率时保留他们的位置。 
2. 构建毛色的频率图。 对于每个人，记录有多少人拥有相同的外套。 
3. 构建靴子颜色的频率图。 这给出了因与每个人共用靴子而被排除在外的人数。 
4. 建立成对的频率图`(coat, boots)`。 这是必要的，因为共享两个房产的人都被计入两个排除组。 
5. 对于每个人，计算

 [
 n-\text{coat_count}-\text{boot_count}+\text{pair_count}。 
]

 这就是包含-排除：从每个可能的目标开始，删除具有相同外套的目标，删除具有相同靴子的目标，然后恢复删除两次的目标。 
6. 将这些值添加到答案中并打印结果。 从投掷者的角度来看，每个有效的有序对都只计算一次。 

### 为什么它有效

 对于每个人 (i)，每个可能的目标最初都包含在 (n) 个候选者中。 任何具有相同涂层的目标都必须被移除，给出(n-C_i)。 在剩下的候选人中，我们也必须把所有穿着同样靴子的人都除掉。 两次操作都删除了共享外套和靴子的人，因此必须将其添加回来一次。 结果值 (n-C_i-B_i+P_i) 正是同时穿着不同外套和不同靴子的人数。 

该人自己的条目位于所有三个频率组中，因此其贡献为零。 将每个人的精确计数相加，将每个有效的定向投掷计数一次，并且不会计算无效投掷。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import Counter

def solve():
    n = int(input())
    coats = input().split()
    boots = input().split()

    coat_count = Counter(coats)
    boot_count = Counter(boots)
    pair_count = Counter(zip(coats, boots))

    answer = 0

    for coat, boot in zip(coats, boots):
        answer += n - coat_count[coat] - boot_count[boot] + pair_count[(coat, boot)]

    print(answer)

if __name__ == "__main__":
    solve()
```三个`Counter`对象直接对应于算法中的三个频率。`coat_count[coat]`告诉我们 (C_i),`boot_count[boot]`告诉我们 (B_i)，并且`pair_count[(coat, boot)]`告诉我们（P_i）。 

这`zip`操作将属于同一个人的外套和靴子放在一起。 这在构建配对频率图时尤其重要，因为单独计算外套和靴子会丢失有关实际发生的组合的信息。 

表达式```
n - coat_count[coat] - boot_count[boot] + pair_count[(coat, boot)]
```直接实现包含排除。 不需要对当前人进行特殊的减法，因为公式已经考虑了该人自己的组合。 

Python 整数不会溢出，因此即使有序对的数量很大，答案也是安全的。 输入使用`sys.stdin.readline`根据要求，尽管输入本身足够小，普通输入也足够了。

 ## 边缘情况

 对于一个人来说，```
1
red
blue
```三个频率都是一。 公式给出（1-1-1+1=0），因此该算法正确地避免了对向自己扔东西的人进行计数。 

当每个人都有同样的外套时，```
3
red red red
blue green yellow
```每个人都有`coat_count = 3`。 他们的有效目标计数是（3-3-1+1=0）。 尽管靴子不同，但共用的外套足以防止每次摔倒。 

当每个人都有同样的靴子时，```
3
red green blue
black black black
```每个人都有`boot_count = 3`，给出 (3-1-3+1=0)。 共用靴子消除了所有可能的投掷情况。 

当几个人共享这两个房产时，```
3
red red blue
black black green
```前两个人的外套数为 2，靴子数为 2，一双鞋数为 2。 他们的有效目标数是（3-2-2+2=1），对应于`blue/green`人。 第三人有一个有效目标，总共给出`2`。 

最后一种情况是主要的包含-排除陷阱。 如果不加回精确配对频率，则前两个人将各自错误地收到零个有效目标，因为他们共享的外套和共享的靴子将被减去两次。
