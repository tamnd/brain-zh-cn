 ## 解决方案
 ## 问题理解

 输入描述了一组足球比赛的结果。 每场比赛包含两个球队名称和一个结果字符。 一个`W`表示第一队获胜，而`T`意味着球队平局。 胜队先队积 3 分，负队积 0 分，平局则双方各积 1 分。 任务是计算每个团队的总得分，并从最高分到最低分打印所有团队。 得分相同的球队按字母顺序排列。 官方声明给出了相同的评分规则和排序要求。 

一个团队可以简单地通过其名称来识别，因此字典是存储其当前得分的自然数据结构。 每场比赛只会影响两个条目，并且只需要在第一次出现在比赛中时创建球队。 处理完所有匹配后，最多有`2n`不同的队伍出现，因此不同的队伍数量也最多为`2n`。 

该声明没有公布明确的上限`n`在当前的 Codeforces 页面上。 时间限制为 1 秒，内存限制为 256 MB。 这使得算法与比赛数量成线性关系，然后是一种不同的球队，即适当的目标。 单独扫描每个球队的所有比赛的方法可能需要二次工作，随着比赛数量的增加，这会成为问题。 

第一个边缘情况是单个匹配。 为了```
1
A B W
```正确的输出是```
A 3
B 0
```一个粗心的实现，只在奖励积分后记录团队可能会忘记`B`，因为失败的球队获得零分，但仍然必须出现在输出中。 

第二个边缘情况是平局：```
1
A B T
```正确的输出是```
A 1
B 1
```一种解决方案可以治疗`T`因为第一队的胜利会错误地给出`A`三点和`B`零。 

第三个边缘情况是最终排名平局。 为了```
2
Bob Alice T
Charlie Alice T
```分数是`Alice = 2`,`Bob = 1`， 和`Charlie = 1`，所以输出是```
Alice 2
Bob 1
Charlie 1
```比分相同的球队必须按字母顺序排列，而不是按输入顺序排列。 在这种情况下，仅使用分数的排序键将失败。 

## 方法

 直接的暴力解决方案可以首先收集球队名称，然后针对每个球队扫描每场比赛以确定该球队获得了多少分。 这是正确的，因为在计算每支球队的总成绩时都会检查每场比赛，因此不会错过任何结果。 如果有`m`不同的团队和`n`游戏，但是，这执行`m * n`游戏检查。 自从`m`可以大到`2n`，最坏的情况大约是`2n²`检查。 之后，球队还需要进行排序。 

The brute force works because the scoring rule for one team can be determined independently by inspecting every match. The problem is that the same match gets inspected again and again for different teams. The key observation is that each match already tells us exactly how the scores of its two participants change. There is no reason to postpone those updates and scan the match later.

 我们可以只处理每个游戏一次。 当结果是`W`, add 3 to the first team's score and leave the second team's score unchanged. 当结果是`T`，给两队加 1。 最后，按分数降序排列字典条目，然后按队名升序排序，即可准确产生所需的排名。 

唯一的非线性部分是最终排序。 如果`m`团队出现，这需要花费`O(m log m)`，同时处理所有游戏费用`O(n)`。 自从`m <= 2n`，总计为`O(n log n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(mn + m log m)，最坏情况 O(n²) | O(米) | 对于大输入来说太慢 |
 | 最佳| O(n + m log m)，因此 O(n log n) | O(米) | 已接受 |

 ## 算法演练

 1.创建一个空字典`score`。 它的键是团队名称，其值是该团队当前的积分数。 即使第一次结果是失败的球队也必须被插入，因为每支参加比赛的球队都属于最终排名。 
2. 将每场比赛读作`team1`,`team2`， 和`result`。 如果之前没有出现过，则将字典中的两支球队初始化为零分。 
3. 如果结果是`W`，加3分`team1`。 第二队没有得分，但其字典条目仍然存在。 
4. 如果结果是`T`，两队各加1分。 根据输入规范，没有其他可能的结果。 
5. 将字典转换成对`(team, score)`并使用键对它们进行排序`(-score, team)`。 否定分数会给出降序的数字顺序，而球队名称仍保持正常的字母顺序。 
6. 将每个排序对打印为`team score`。 输出线的数量正是游戏中出现的不同球队的数量。 

### 为什么它有效

 处理输入的任何前缀后，字典不变式是存储在其中的每个球队都准确地拥有迄今为止处理的比赛中获得的分数。 一个`W`将获胜者更新为规则规定的 3 分，并且`T`两个参与者都更新了 1 点。 由于每场比赛都会处理一次，因此在决赛之后，每个字典值都是球队的完整比赛得分。 最终的排序键将这些完整分数从大到小排序，并按字母顺序打破相同的分数，因此每个打印行都满足所需的排名。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    score = {}

    for _ in range(n):
        team1, team2, result = input().split()

        if team1 not in score:
            score[team1] = 0
        if team2 not in score:
            score[team2] = 0

        if result == "W":
            score[team1] += 3
        else:
            score[team1] += 1
            score[team2] += 1

    teams = sorted(score.items(), key=lambda item: (-item[1], item[0]))

    sys.stdout.write(
        "\n".join(f"{team} {points}" for team, points in teams)
    )

if __name__ == "__main__":
    solve()
```字典是实现的核心部分。`score[team]`始终包含该团队迄今为止积累的分数，与算法演练中的不变量相匹配。 

两个团队在检查结果之前都会进行初始化。 这对于失败来说是必要的，因为失败的球队得到零分，但仍然需要打印。 初始化两侧也使绘图变得简单。 

为了`W`， 仅有的`team1`获得积分，因为该声明保证第一个列出的团队是获胜者。 为了`T`，两队各得一分。 没有必要`L`分支因为`L`不能出现在输入中。 

排序表达式使用`(-item[1], item[0])`。 如果两队得分为 7 和 4，则他们的键以`-7`和`-4`，所以 7 排在第一位。 如果两支球队都有 4 个球队，则他们的第一个关键组成部分相等，Python 会按字母顺序比较第二个组成部分，即球队名称。 

Python整数不会溢出，因此即使是大量游戏也不需要对分值进行特殊处理。 输出是用`join`，避免每个团队进行不必要的刷新或写入操作。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + m log m) | O(n + m log m) | 每个`n`游戏被处理一次，然后`m`不同的团队已排序 |
 | 空间| O(米) | 字典和排序的团队列表为每个不同的团队存储一个条目 |

 这里`m`是不同团队的数量，并且`m <= 2n`因为每场比赛都有两支球队。 因此总时间是`O(n log n)`在游戏数量方面，具有线性记忆。 这比在 1 秒限制内重复扫描每个球队的所有比赛要好得多。

 ## 边缘情况

 对于单场比赛的情况```
1
A B W
```在处理结果之前，两队都会被插入。 分数变为`A = 3`和`B = 0`。 排序地点`A`首先，给予```
A 3
B 0
```关键的细节是`B`即使其分数从未增加，也会被创建。 

为了平局```
1
A B T
```字典开头为`{A: 0, B: 0}`。 这`T`分支增加两个条目，产生`{A: 1, B: 1}`。 输出是```
A 1
B 1
```除了更新双方参与者之外，抽签不需要任何特殊情况。 

最终得分相同时，```
2
Bob Alice T
Charlie Alice T
```第一场比赛给出`Bob = 1`和`Alice = 1`。 第二个给出`Charlie = 1`和`Alice = 2`。 最终值为`Alice = 2`,`Bob = 1`， 和`Charlie = 1`。 Bob 和 Charlie 的排序键是`(-1, "Bob")`和`(-1, "Charlie")`，所以结果是```
Alice 2
Bob 1
Charlie 1
```输入的顺序不影响得分相同的球队的最终排序。 

对于重复的游戏，```
4
Zed Amy T
Amy Bob W
Bob Zed T
Zed Amy W
```分数演变为`Zed = 1, Amy = 1`， 然后`Amy = 4, Bob = 0`， 然后`Bob = 1, Zed = 2`，最后`Zed = 5, Amy = 4`。 因此输出是```
Zed 5
Amy 4
Bob 1
```团队的每次出现都会对相同的字典条目做出贡献，因此不假设两个团队最多会面一次。 

最后，每场比赛都输掉的球队绝不能消失。 在```
2
A B W
C B W
```更新产生`A = 3`,`C = 3`， 和`B = 0`。 自从`B`当读取第一个匹配项时插入，它保留在字典中并最后打印：```
A 3
C 3
B 0
```这是将完整积分榜解决方案与仅跟踪获得积分的球队的积分榜解决方案区分开来的主要实施细节。
